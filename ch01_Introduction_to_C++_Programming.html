Introduction to C++ Programming

C++ is a general-purpose programming language developed by Bjarne Stroustrup. It extends the C programming language with features such as classes, objects, inheritance, and polymorphism.

C++ supports procedural, object-oriented, and generic programming. It is widely used in system software, embedded systems, game engines, desktop applications, and performance-critical software.

1. History of C++

  • C++ was developed by Bjarne Stroustrup at Bell Labs.
  • Its development began around 1979 as an extension of C.
  • The language was initially known as "C with Classes".
  • The name C++ was adopted in 1983.
  • C++ has evolved through standards such as C++98, C++11, C++14, C++17, C++20, and C++23.

2. Features of C++

  • Object-oriented programming: Organizes code using classes and objects.
  • Encapsulation: Combines data and functions within a class.
  • Inheritance: Allows a class to reuse or extend another class.
  • Polymorphism: Enables one interface to support different implementations.
  • Abstraction: Exposes essential features while hiding implementation details.
  • Performance: Supports efficient compiled programs and low-level operations.
  • Standard Template Library (STL): Provides containers, algorithms, and iterators.
  • Portability: Standard-conforming code can be compiled on different platforms, subject to platform dependencies.

3. Applications of C++

  • Operating systems and system software
  • Embedded systems and firmware
  • Device drivers and hardware-oriented software
  • Game development and graphics engines
  • Database engines
  • Compilers and programming tools
  • Real-time and high-performance applications

For Embedded Systems and Systems Software Engineering, C++ is particularly useful for understanding memory, resource management, data structures, and performance.

4. C vs C++

Feature C C++
Programming approach Primarily procedural Procedural, object-oriented, and generic
Classes and objects Not built into the language Supported
Function overloading Not supported Supported
Templates Not supported Supported
Standard I/O examples printf(), scanf() cout, cin
Memory management malloc(), free() new, delete, and smart pointers

C++ retains many C language features, but C and C++ are separate languages with different rules.

5. Setting Up a C++ Development Environment

You need a text editor or IDE and a C++ compiler.

  • Compiler: GCC (g++), Clang, or MSVC.
  • Editor/IDE: Visual Studio Code, Visual Studio, or Dev-C++.
  • Terminal: Windows CMD or another terminal for compiling and running programs.

Check the compiler

Open CMD and run:

g++ --version

Compile a C++ program

Assuming your file is named hello.cpp, run:

g++ -std=c++11 -Wall -Wextra hello.cpp -o hello

Run the program on Windows CMD

hello.exe

6. Your First C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!" << endl;
    return 0;
}

Output

Hello, World!

Explanation

  • #include <iostream> provides standard input/output functionality.
  • using namespace std; makes standard-library names available without the std:: prefix.
  • int main() defines the program's entry point.
  • cout displays text.
  • endl inserts a newline and flushes the output stream.
  • return 0; indicates successful completion.

7. How a C++ Program Works

  1. Source code: Write code in a .cpp file.
  2. Preprocessing: Processes directives such as #include.
  3. Compilation: Translates source code into lower-level code.
  4. Linking: Combines object code with required libraries.
  5. Execution: The operating system runs the resulting executable.

8. Basic Programming Rules

  • C++ is case-sensitive.
  • Most statements end with a semicolon.
  • Curly braces { } define blocks.
  • Strings use double quotes, such as "Hello".
  • Character literals use single quotes, such as 'A'.
  • Comments can use // or /* ... */.
