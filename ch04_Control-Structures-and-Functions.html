1. Introduction to Control Structures

Control structures determine the order in which program statements execute.

  • Sequential: Statements execute one after another.
  • Selection: Selects a path based on a condition.
  • Iteration: Repeats statements using loops.
  • Jump statements: Change the normal flow of execution.

2. The if Statement

The if statement executes a block when its condition is true.

#include <iostream>
using namespace std;

int main() {
    int age = 20;

    if (age >= 18) {
        cout << "Eligible to vote";
    }

    return 0;
}

Expected Output

Eligible to vote

3. if-else Statement

The if-else statement selects one of two paths.

#include <iostream>
using namespace std;

int main() {
    int number = 7;

    if (number % 2 == 0) {
        cout << "Even number";
    } else {
        cout << "Odd number";
    }

    return 0;
}

Expected Output

Odd number

4. else-if Ladder

An else-if ladder checks multiple conditions in order. The first true branch executes.

#include <iostream>
using namespace std;

int main() {
    int marks = 82;

    if (marks >= 90) {
        cout << "Grade A+";
    } else if (marks >= 80) {
        cout << "Grade A";
    } else if (marks >= 70) {
        cout << "Grade B";
    } else if (marks >= 60) {
        cout << "Grade C";
    } else {
        cout << "Needs improvement";
    }

    return 0;
}

Expected Output

Grade A

5. Nested if Statement

A nested if is an if statement inside another if statement.

#include <iostream>
using namespace std;

int main() {
    int age = 22;
    bool hasLicense = true;

    if (age >= 18) {
        if (hasLicense) {
            cout << "Can drive legally";
        } else {
            cout << "License required";
        }
    } else {
        cout << "Not old enough";
    }

    return 0;
}

Expected Output

Can drive legally

6. switch Statement

The switch statement selects a matching case based on an integral, enumeration or suitable converted expression. A break normally prevents execution from falling through to the next case.

#include <iostream>
using namespace std;

int main() {
    int day = 3;

    switch (day) {
        case 1:
            cout << "Monday";
            break;
        case 2:
            cout << "Tuesday";
            break;
        case 3:
            cout << "Wednesday";
            break;
        default:
            cout << "Invalid day";
    }

    return 0;
}

Expected Output

Wednesday

7. The while Loop

A while loop checks its condition before each iteration. It may execute zero or more times.

#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 5) {
        cout << i << " ";
        i++;
    }

    return 0;
}

Expected Output

1 2 3 4 5

8. The do-while Loop

A do-while loop checks its condition after the loop body, so its body executes at least once.

#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        cout << i << " ";
        i++;
    } while (i <= 5);

    return 0;
}

Expected Output

1 2 3 4 5

9. The for Loop

A for loop combines initialization, condition and update in one statement.

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }

    return 0;
}

Expected Output

1 2 3 4 5

10. Nested Loops

A nested loop is a loop inside another loop. It is useful for patterns, tables and multidimensional data.

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            cout << "* ";
        }
        cout << '\n';
    }

    return 0;
}

Expected Output

* * *
* * *
* * *

11. break and continue

break

The break statement immediately terminates the nearest enclosing loop or switch statement.

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5)
            break;

        cout << i << " ";
    }

    return 0;
}

Output: 1 2 3 4

continue

The continue statement skips the remaining body of the current iteration and proceeds to the next iteration.

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3)
            continue;

        cout << i << " ";
    }

    return 0;
}

Output: 1 2 4 5

12. Introduction to Functions

A function is a reusable block of code that performs a specific task. Functions improve modularity, readability and testing.

Function Structure

return_type function_name(parameters) {
    // Statements
    return value;
}
  • Return type: Specifies the type of result, or void if no result is returned.
  • Function name: Identifies the function.
  • Parameters: Inputs accepted by the function.
  • Function body: Contains the statements to execute.

13. Function Declaration, Definition and Call

A declaration introduces a function signature. A definition provides the implementation. A function call executes it.

#include <iostream>
using namespace std;

int add(int, int);  // Declaration

int add(int a, int b) {  // Definition
    return a + b;
}

int main() {
    int result = add(10, 20);  // Call
    cout << result;

    return 0;
}

Expected Output

30

14. Parameters and Arguments

Parameters are variables listed in a function declaration or definition. Arguments are the values or expressions supplied when calling the function.

#include <iostream>
using namespace std;

void display(int number) {
    cout << number;
}

int main() {
    display(100);
    return 0;
}

Here, number is a parameter and 100 is an argument.

Output: 100

15. Pass by Value

Pass by value copies the argument into the parameter. Changes to the parameter do not change the original variable.

#include <iostream>
using namespace std;

void change(int x) {
    x = 100;
}

int main() {
    int number = 10;

    change(number);

    cout << number;
    return 0;
}

Expected Output

10

16. Pass by Reference

A reference parameter refers to the original variable. Changes through the reference affect the original object.

#include <iostream>
using namespace std;

void change(int& x) {
    x = 100;
}

int main() {
    int number = 10;

    change(number);

    cout << number;
    return 0;
}

Expected Output

100

17. Pass by Pointer

A pointer parameter can refer to an object through its address. A valid non-null pointer must be checked or guaranteed before dereferencing it.

#include <iostream>
using namespace std;

void change(int* x) {
    if (x != nullptr) {
        *x = 100;
    }
}

int main() {
    int number = 10;

    change(&number);

    cout << number;
    return 0;
}

Expected Output

100

18. Default Arguments

Default arguments provide values for parameters omitted in a function call. Parameters with defaults generally appear at the end of the parameter list.

#include <iostream>
using namespace std;

int add(int a, int b = 10) {
    return a + b;
}

int main() {
    cout << add(5) << '\n';
    cout << add(5, 20);

    return 0;
}

Expected Output

15
25

19. Function Overloading

Function overloading allows multiple functions to share a name when their parameter lists differ. Return type alone cannot distinguish overloaded functions.

#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int main() {
    cout << add(2, 3) << '\n';
    cout << add(2.5, 3.5);

    return 0;
}

Expected Output

5
6

20. Inline Functions

The inline keyword is a request related to function inlining and also permits certain definitions to appear in multiple translation units. It does not guarantee that the compiler will substitute the function body at every call.

#include <iostream>
using namespace std;

inline int square(int x) {
    return x * x;
}

int main() {
    cout << square(5);
    return 0;
}

Output: 25

21. Recursive Functions

A recursive function calls itself. It must have a suitable base case to stop recursion.

Example: Factorial

#include <iostream>
using namespace std;

long long factorial(int n) {
    if (n <= 1)
        return 1;

    return n * factorial(n - 1);
}

int main() {
    cout << factorial(5);
    return 0;
}

Expected Output

120

This example is intended for non-negative inputs within the range of the return type. Production code should validate the input and guard against overflow.

22. Scope and Lifetime

  • Local variable: Declared inside a block or function and normally accessible only within its scope.
  • Global variable: Declared outside functions and available according to its scope and linkage.
  • Static local variable: Retains its value between calls and has program-long storage duration.
  • Parameter: A function-local name for an input or reference used by that function.
#include <iostream>
using namespace std;

void counter() {
    static int count = 0;
    count++;
    cout << count << " ";
}

int main() {
    counter();
    counter();
    counter();

    return 0;
}

Output: 1 2 3

Chapter Summary

Control structures determine the flow of execution using conditions, loops and jump statements. Functions organize programs into reusable units and support different parameter-passing methods, overloading, recursion and default arguments.
