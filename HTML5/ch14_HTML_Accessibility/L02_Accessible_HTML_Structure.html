Lesson 2: Accessible HTML Structure

Chapter 14: HTML Accessibility

Learn how to organize web pages using semantic HTML, proper heading hierarchy, landmarks, lists and accessible navigation.

1. Introduction to Accessible HTML Structure

Accessible HTML structure means organizing the content of a web page so that browsers, users and assistive technologies can understand its purpose and relationships.

A well-structured page makes it easier for users to navigate between sections, identify important content and understand the page layout.

Important HTML Elements

  • <header> – Introductory content or a section header.
  • <nav> – A section containing navigation links.
  • <main> – The dominant content of the document.
  • <section> – A thematic grouping of content.
  • <article> – Self-contained content.
  • <aside> – Content indirectly related to surrounding content.
  • <footer> – Footer information for a page or section.
Semantic HTML provides meaning to content. It is generally better than using generic div elements for every part of a page.

2. Basic Structure of an Accessible HTML Document

An accessible HTML document should have a valid document structure, a meaningful title, a language declaration and logically organized content.

Example

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Learning Portal</title> </head> <body> <header> <h1>My Learning Portal</h1> </header> <main> <h2>Welcome</h2> <p>Explore educational resources.</p> </main> <footer> <p>Learning Portal</p> </footer> </body> </html>

Important Points

  • Use a meaningful page title.
  • Specify the correct language using the lang attribute.
  • Use semantic elements to organize page content.
  • Keep the document structure logical.
  • Use headings to identify content sections.

3. The HTML Lang Attribute

The lang attribute specifies the language of an element's content. It is commonly placed on the html element to identify the primary language of a page.

Example

<html lang="en">

The value en identifies English. Language information can help screen readers select suitable pronunciation rules.

Examples of Language Codes

Language Language Code
English en
Hindi hi
French fr
German de
Spanish es
Japanese ja

Language of a Specific Section

<p> Welcome to the learning portal. </p> <p lang="hi"> नमस्ते! हमारे शिक्षण पोर्टल में आपका स्वागत है। </p>
Use the correct language code for the actual content. Do not declare English if the page is primarily written in another language.

4. Semantic HTML and Accessibility

Semantic HTML elements communicate the meaning and purpose of content to browsers and assistive technologies.

Non-Semantic Structure

<div class="header"> <h1>My Website</h1> </div> <div class="navigation"> <a href="index.html">Home</a> </div> <div class="content"> <h2>Welcome</h2> <p>Welcome to our website.</p> </div>

Semantic Structure

<header> <h1>My Website</h1> </header> <nav aria-label="Main navigation"> <a href="index.html">Home</a> </nav> <main> <h2>Welcome</h2> <p>Welcome to our website.</p> </main>
Difference: Semantic elements communicate the purpose of each page region. Generic div elements do not provide that meaning by themselves.

5. Heading Hierarchy

HTML provides six heading levels: <h1> through <h6>. Headings organize content into sections and subsections.

Example

<h1>HTML5 Course</h1> <h2>HTML Accessibility</h2> <h3>Accessible HTML Structure</h3> <h4>Semantic Elements</h4> <h3>Keyboard Navigation</h3> <h2>HTML Forms</h2> <h3>Accessible Form Controls</h3>

Heading Structure

    • Keyboard Navigation

Heading Best Practices

  • Use headings to describe sections.
  • Maintain a logical hierarchy.
  • Do not select heading levels only for their visual size.
  • Use CSS when you want to change heading appearance.
  • Avoid unnecessary heading levels.
A page does not have a strict requirement to contain exactly one h1 element. The important practice is to provide a clear and logical heading structure.

6. The Header Element

The <header> element represents introductory content for a page or a section.

Example

<header> <h1>NS Learning Hub</h1> <p>Learn programming and technology.</p> </header>

A header can contain headings, introductory text, logos and navigation-related content.

A page may have a header, and individual article or section elements may also have their own headers.

7. The Nav Element

The <nav> element represents a section containing major navigation links.

Example

<nav aria-label="Main navigation"> <ul> <li><a href="index.html">Home</a></li> <li><a href="courses.html">Courses</a></li> <li><a href="projects.html">Projects</a></li> <li><a href="contact.html">Contact</a></li> </ul> </nav>

Why Use aria-label?

If a page has more than one navigation landmark, a descriptive label can help users distinguish them.

<nav aria-label="Main navigation"> <a href="index.html">Home</a> </nav> <nav aria-label="Course navigation"> <a href="html5/index.html">HTML5</a> <a href="cpp/index.html">C++</a> </nav>

8. The Main Element

The <main> element represents the dominant content of the body of a document.

Example

<body> <header> <h1>Programming Courses</h1> </header> <nav aria-label="Main navigation"> <a href="index.html">Home</a> <a href="courses.html">Courses</a> </nav> <main> <h2>Available Courses</h2> <p> Explore our programming courses. </p> </main> <footer> <p>Copyright Information</p> </footer> </body>
A document should generally have one visible main element representing its primary content. The main element should not be placed inside header, nav, article, aside or footer elements.

9. Section and Article Elements

Section Element

The <section> element represents a thematic grouping of content, usually with a heading.

<section> <h2>HTML Courses</h2> <p>Learn HTML from beginner to advanced.</p> </section>

Article Element

The <article> element represents self-contained content that can be distributed or reused independently.

<article> <h2>Introduction to HTML5</h2> <p> HTML is the standard markup language for structuring web content. </p> </article>

Difference Between Section and Article

Section Article
Groups related content into a thematic section. Represents self-contained content.
Usually has a heading. Often has its own heading.
May organize a larger page. May be independently distributed or reused.

10. Aside and Footer Elements

Aside Element

The <aside> element represents content that is indirectly related to the surrounding content.

<article> <h2>Introduction to HTML</h2> <p> HTML is used to structure web pages. </p> <aside> <h3>Related Topic</h3> <p>Learn about CSS and JavaScript.</p> </aside> </article>

Footer Element

The <footer> element represents footer information for a page or section.

<footer> <p>Contact: support@example.com</p> <p>Copyright 2026 NS Learning Hub</p> </footer>

11. Lists and Accessible Content Organization

HTML lists organize related items into meaningful groups. They can help users understand relationships between pieces of information.

Unordered List

<h2>Available Courses</h2> <ul> <li>HTML5</li> <li>CSS3</li> <li>JavaScript</li> <li>C++ Programming</li> </ul>

Ordered List

<h2>Learning Steps</h2> <ol> <li>Learn HTML basics</li> <li>Understand semantic elements</li> <li>Practice HTML forms</li> </ol>

Screen readers can identify list structures and communicate the number of items and their order.

12. Accessible Tables

Tables should be used for tabular information, not for controlling the visual layout of a page.

Example

<table> <caption>Course Details</caption> <thead> <tr> <th scope="col">Course</th> <th scope="col">Duration</th> </tr> </thead> <tbody> <tr> <td>HTML5</td> <td>4 Weeks</td> </tr> <tr> <td>CSS3</td> <td>3 Weeks</td> </tr> </tbody> </table>

Important Practices

  • Use caption to describe the table.
  • Use th for header cells.
  • Use scope to identify simple row and column headers.
  • Use thead and tbody to organize table sections.
  • Provide appropriate associations for complex tables.

13. Complete Example: Accessible Learning Portal

The following example combines semantic HTML elements to create an accessible page structure for an educational website.

Complete HTML Code

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>NS Learning Hub</title> </head> <body> <header> <h1>NS Learning Hub</h1> <p>Learn programming and technology.</p> </header> <nav aria-label="Main navigation"> <ul> <li><a href="#home">Home</a></li> <li><a href="#courses">Courses</a></li> <li><a href="#about">About</a></li> </ul> </nav> <main id="home"> <section> <h2>Welcome</h2> <p> Explore educational resources and improve your technical skills. </p> </section> <section id="courses"> <h2>Available Courses</h2> <ul> <li>HTML5</li> <li>CSS3</li> <li>JavaScript</li> <li>C++ Programming</li> </ul> </section> <article id="about"> <h2>About the Portal</h2> <p> This portal provides structured learning materials and practical examples. </p> </article> <aside> <h2>Learning Tip</h2> <p> Practice every topic with examples. </p> </aside> </main> <footer> <p>NS Learning Hub</p> <p>Copyright 2026</p> </footer> </body> </html>

Expected Structure

  • Header – Portal name and introduction.
  • Navigation – Links to important page sections.
  • Main – Primary page content.
  • Sections – Welcome and available courses.
  • Article – Information about the portal.
  • Aside – Related learning tip.
  • Footer – Footer information.

14. Common Mistakes

Mistake Correct Practice
Using div for every page region. Use appropriate semantic elements.
Missing lang attribute. Declare the document's primary language.
Using headings only for visual size. Use headings to represent content hierarchy.
Skipping heading levels without a structural reason. Organize headings logically.
Using multiple unrelated main elements. Use one primary main region per document.
Using tables for page layout. Use CSS layout techniques.
Using unclear navigation labels. Use descriptive navigation links and landmark labels where needed.
Using section without a meaningful theme. Use section for thematic content groupings.

16. Interview Questions and Answers

Q1. What is accessible HTML structure?
It is the logical organization of HTML content using appropriate elements so that users, browsers and assistive technologies can understand the page.
Q2. What is the purpose of the lang attribute?
It specifies the language of an element's content and helps assistive technologies determine suitable language pronunciation.
Q3. What are semantic HTML elements?
Elements that communicate the meaning and purpose of their content, such as header, nav, main and footer.
Q4. What is the purpose of the main element?
It represents the dominant content of the document body.
Q5. What is the purpose of the nav element?
It identifies a section containing major navigation links.
Q6. What is the difference between section and article?
Section groups thematically related content, while article represents self-contained content.
Q7. Why is heading hierarchy important?
It organizes content into logical sections and helps users navigate the page.
Q8. Can a page contain multiple header elements?
Yes. A page can contain a document header and headers for individual sections or articles.
Q9. Can a page contain multiple nav elements?
Yes. Multiple navigation sections can be used. Descriptive labels help distinguish their purposes when necessary.
Q10. What is the purpose of aside?
It represents content indirectly related to the surrounding content.
Q11. What is the purpose of footer?
It provides footer information for a page or section.
Q12. Why should tables not be used for page layout?
Tables represent tabular data. Using them for layout creates unnecessary structural complexity. CSS Grid and Flexbox are better layout tools.
Q13. What is a navigation landmark?
It is an identifiable navigation region that assistive technologies can expose for easier navigation.
Q14. How does semantic HTML improve accessibility?
It communicates the purpose and relationships of page content to browsers and assistive technologies.
Q15. What is the purpose of the title element?
It specifies the document title, which is commonly shown in browser tabs and used by assistive technologies to identify the page.
