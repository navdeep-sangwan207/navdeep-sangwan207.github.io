Lesson 3: Alt Text and Descriptive Labels

Chapter 14: HTML Accessibility

Learn how to provide meaningful alternative text for images and descriptive labels for links, buttons and other HTML elements.

1. Introduction to Alternative Text

Alternative text, commonly called alt text, is a textual description provided through the alt attribute of the HTML <img> element.

It communicates the purpose or relevant information of an image to users who cannot see it. Screen readers can announce this text, and browsers may display it when an image cannot be loaded.

Basic Syntax

<img src="computer.jpg" alt="Laptop computer on a desk">

Why Is Alt Text Important?

  • Helps screen reader users understand images.
  • Provides information when an image fails to load.
  • Supports users with visual disabilities.
  • Communicates important information contained in images.
  • Improves the accessibility of web content.
Alt text should communicate the image's relevant purpose or information in its context. It should not simply list visual details that are unrelated to the page content.

2. The HTML Alt Attribute

The alt attribute belongs to the <img> element. It provides a text alternative for the image.

Example 1: Informative Image

<img src="microcontroller.jpg" alt="LPC2129 ARM7 microcontroller development board">

Example 2: Educational Diagram

<img src="html-structure.png" alt="Diagram showing the HTML document structure: html contains head and body elements">

Example 3: Image of a Circuit

<img src="rectifier-circuit.png" alt="Bridge rectifier circuit with four diodes connected to an AC source and load resistor">

Example 4: Image Containing Important Text

<img src="safety-notice.png" alt="Safety notice: Disconnect the power supply before working on the circuit">
When an image contains important text, provide that information in the alternative text or in nearby page content.

3. Decorative Images and Empty Alt Text

Some images are used only for decoration. They do not communicate information necessary to understand the page.

For such images, use an empty alt attribute: alt="".

Example

<img src="decorative-line.png" alt="">

An empty alt attribute tells assistive technologies that the image does not need a text alternative announced.

Informative vs Decorative Images

Image Type Alt Text
Informative photograph Describe its relevant information.
Decorative background ornament Use alt="".
Image used as a link Describe the link's purpose or destination.
Image containing essential text Provide the text information.
Complex technical diagram Provide a concise alternative and a detailed explanation nearby.
Do not omit the alt attribute just because an image is decorative. Use alt="" to explicitly identify a decorative image.

4. Writing Effective Alt Text

Good alt text is concise, meaningful and appropriate to the surrounding content. The same image may need different alt text depending on how it is used.

Example: Poor and Better Alt Text

Poor Alt Text Better Alt Text
image Bridge rectifier circuit using four diodes.
photo Engineer testing a circuit with a multimeter.
computer Laptop displaying a C++ programming editor.
diagram Flowchart showing the steps of a program.
logo image NS Learning Hub home page.

Best Practices

  • Describe the relevant information, not every visual detail.
  • Keep the description concise where possible.
  • Avoid unnecessary phrases such as "image of" or "picture of".
  • Include important text shown inside an image.
  • Do not repeat information already available in nearby text.
  • Use empty alt text for purely decorative images.
  • Do not use filenames as alternative text.
  • Do not stuff alt text with unrelated keywords.

5. Alt Text for Linked Images

Sometimes an image is placed inside an anchor element to create an image link. In this case, the alternative text should communicate the purpose of the link.

Example

<a href="index.html"> <img src="logo.png" alt="NS Learning Hub home page"> </a>

A screen reader can communicate the link using the image's alternative text.

Decorative Image Inside a Text Link

<a href="courses.html"> <img src="book-icon.png" alt=""> View Courses </a>

Here, the visible link text already describes the destination. The icon is decorative, so it has empty alt text.

6. Alt Text for Complex Images

Some images contain complex information that cannot be explained adequately in a short alternative text.

Examples include:

  • Electronic circuit diagrams.
  • Engineering block diagrams.
  • Scientific graphs.
  • Statistical charts.
  • Detailed flowcharts.
  • Technical architecture diagrams.

Example: Circuit Diagram

<figure> <img src="power-supply-circuit.png" alt="Regulated DC power supply circuit containing a transformer, bridge rectifier, filter capacitor and voltage regulator"> <figcaption> Block diagram of a regulated DC power supply. </figcaption> </figure> <section> <h2>Circuit Description</h2> <p> The transformer reduces the AC voltage. The bridge rectifier converts AC into pulsating DC. The capacitor smooths the output, and the voltage regulator maintains a stable DC voltage. </p> </section>
For a complex image, provide a concise alt text and a complete explanation in nearby text, a data table or another accessible format. A figcaption alone is not always a sufficient detailed alternative.

7. Descriptive Labels for Links

A link should communicate its purpose or destination clearly. Users should be able to understand what a link does without relying only on surrounding visual content.

Poor Link Text

<a href="html5/index.html">Click here</a> <a href="cpp/index.html">Read more</a>

Better Link Text

<a href="html5/index.html"> Explore the HTML5 Course </a> <a href="cpp/index.html"> View the C++ Programming Course </a>

Why Descriptive Link Text Matters

  • Helps screen reader users understand links.
  • Makes navigation easier.
  • Improves clarity and usability.
  • Reduces ambiguity between different links.
Avoid using the same generic link text for different destinations when the purpose of each link is not clear.

8. Labels for Buttons

Buttons should have accessible names that clearly communicate their actions.

Example: Text Button

<button type="button"> Submit Application </button>

The visible text provides the button's accessible name.

Example: Icon-Only Button

<button type="button" aria-label="Close dialog"> &times; </button>

In this example, the aria-label provides an accessible name for a button that otherwise contains only a symbol.

Example: Search Button

<button type="submit" aria-label="Search courses"> &#128269; </button>
Prefer visible text when practical. Use aria-label when an element needs an accessible name that is not provided by its visible content.

9. Labels for Form Controls

Every form control should have an accessible name that identifies the information expected from the user.

Using the Label Element

<label for="username"> Username: </label> <input type="text" id="username" name="username">

The for attribute connects the label to the form control through its id attribute.

Using aria-label

<input type="search" aria-label="Search courses" name="search">

This gives the input an accessible name, but does not display a visible label.

Using aria-labelledby

<h2 id="search-heading"> Search Learning Resources </h2> <input type="search" aria-labelledby="search-heading">

The aria-labelledby attribute references another element's id to provide an accessible name.

A visible label is generally preferable because it helps all users, not only users of assistive technologies.

10. Title Attribute and Descriptive Information

The title attribute can provide advisory information about an element. Browsers may display it as a tooltip when a pointer hovers over the element.

Example

<a href="html5/index.html" title="Open the HTML5 course"> HTML5 Course </a>

However, title should not be used as the only way to provide important information. Some users may not be able to access hover-based tooltips.

Comparison

Attribute Purpose
alt Provides a text alternative for an image.
aria-label Provides an accessible name directly.
aria-labelledby Uses another element's text as the accessible name.
title Provides advisory information.
for Associates a label with a form control.

11. Figure and Figcaption with Alt Text

The <figure> element groups self-contained content such as images, diagrams and illustrations. The <figcaption> element provides a caption for that content.

Example

<figure> <img src="html-document-structure.png" alt="HTML document structure showing head and body inside the html element"> <figcaption> Figure 1: Basic HTML document structure. </figcaption> </figure>

Alt Text vs Figcaption

Alt Text Figcaption
Provides a text alternative for an image. Provides a visible caption for figure content.
Specified through the alt attribute. Specified using the figcaption element.
Important for non-visual access to images. Provides context for all readers.
Alt text and figcaption serve different purposes. A caption does not automatically replace the need for an appropriate alt attribute.

12. Complete Example: Accessible Course Page

This example combines informative images, decorative images, descriptive links, buttons and labelled form controls.

Complete HTML Code

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Accessible Course Page</title> </head> <body> <header> <h1>NS Learning Hub</h1> </header> <main> <section> <h2>HTML5 Course</h2> <figure> <img src="html-logo.png" alt="HTML5 logo"> <figcaption> Learn HTML5 from beginner to advanced. </figcaption> </figure> <p> Explore HTML elements and web accessibility. </p> <a href="html5/index.html"> Explore the HTML5 Course </a> </section> <section> <h2>Course Search</h2> <form action="#" method="get"> <label for="course-search"> Search for a course: </label> <input type="search" id="course-search" name="search"> <button type="submit"> Search Courses </button> </form> </section> <section> <h2>Course Actions</h2> <button type="button" aria-label="Show course information"> Course Information </button> </section> </main> <footer> <p>NS Learning Hub</p> </footer> </body> </html>

Expected Structure

  • Page title identifies the document.
  • HTML5 logo has alternative text.
  • Figure caption describes the course image.
  • Course link has descriptive link text.
  • Search input has a visible label.
  • Search button has a clear accessible name.
  • Page uses semantic HTML elements.
The example demonstrates HTML markup. The image file must exist at the specified path, and the form needs a suitable server-side endpoint to perform an actual search.

13. Common Mistakes

Mistake Correct Practice
Missing alt attribute. Provide an appropriate alt attribute.
Using alt="image". Describe the image's relevant information.
Using lengthy unrelated descriptions. Keep alt text focused and relevant.
Using descriptive alt text for decoration. Use alt="" for purely decorative images.
Using "Click here" for every link. Use meaningful link text.
Using placeholder text as the only form label. Provide a visible label.
Using title as the only accessible description. Provide information in accessible visible content.
Using an icon-only button without a name. Provide visible text or an accessible name.

15. Interview Questions and Answers

Q1. What is alt text?
Alt text is a textual alternative provided through the alt attribute of an img element.
Q2. Why is alt text important?
It communicates relevant image information to users who cannot see the image and supports assistive technologies.
Q3. What is the syntax of the alt attribute?
<img src="photo.jpg" alt="Description">
Q4. What is decorative image alt text?
A decorative image does not add meaningful information. Use alt="" so it can be ignored by assistive technologies.
Q5. Should every image have alt text?
Every img element should have an alt attribute. Its value may be descriptive text or an empty string for decorative images.
Q6. What makes good alt text?
It is concise, accurate and relevant to the image's purpose in the context of the page.
Q7. How should complex diagrams be described?
Provide concise alt text and a detailed explanation nearby, such as a paragraph, table or structured description.
Q8. What is descriptive link text?
Link text that clearly communicates the purpose or destination of a link.
Q9. What is aria-label?
It is an ARIA attribute that provides an accessible name directly to an element.
Q10. What is aria-labelledby?
It identifies another element or elements whose text provides the accessible name.
Q11. What is the purpose of the label element?
It provides a visible label for a form control and can associate with it using the for and id attributes.
Q12. What is the difference between alt and title?
Alt provides an image text alternative. Title provides advisory information and may be displayed as a tooltip.
Q13. What is the purpose of figcaption?
It provides a visible caption for content grouped inside a figure element.
Q14. Can aria-label replace every visible label?
No. Although it can provide an accessible name, visible labels are generally better because they help all users.
Q15. What is an accessible name?
It is the name exposed to accessibility APIs so assistive technologies can identify the purpose of an interface element.

16. Multiple Choice Questions (MCQs)

1. Which attribute provides alternative text for an image?
  1. title
  2. alt
  3. src
  4. href
Answer: B — alt
2. What should be used for a purely decorative image?
  1. alt="image"
  2. alt="decoration"
  3. alt=""
  4. No img element
Answer: C — alt=""
3. Which element provides a visible figure caption?
  1. caption
  2. figcaption
  3. label
  4. summary
Answer: B — figcaption
4. Which attribute directly provides an accessible name?
  1. aria-label
  2. width
  3. src
  4. target
Answer: A — aria-label
5. Which attribute references another element for its accessible name?
  1. aria-hidden
  2. aria-labelledby
  3. aria-expanded
  4. aria-live
Answer: B — aria-labelledby
6. Which element is used to create a visible form label?
  1. label
  2. span
  3. div
  4. aside
Answer: A — label
7. What should descriptive link text communicate?
  1. Only its color
  2. Its purpose or destination
  3. Its font size
  4. Its background
Answer: B — Its purpose or destination
8. Which attribute is commonly used to associate a label with an input?
  1. for
  2. src
  3. alt
  4. target
Answer: A — for
9. Which is generally not recommended as the only way to provide important information?
  1. Visible text
  2. Associated label
  3. Title tooltip
  4. Descriptive paragraph
Answer: C — Title tooltip
10. Which is the best practice for a complex technical diagram?
  1. Use no description
  2. Use only its filename
  3. Provide concise alt text and a detailed explanation
  4. Use alt="diagram"
Answer: C — Provide concise alt text and a detailed explanation
