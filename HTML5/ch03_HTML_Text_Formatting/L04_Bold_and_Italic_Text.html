Bold and Italic Text in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides elements to change the appearance of text. Two commonly used elements are:

  • <b> – Displays text in bold style.
  • <i> – Displays text in italic style.

These elements can make selected text visually different from surrounding content.

2. The Bold Element (<b>)

The <b> element draws attention to text without indicating that the text has greater importance. Browsers normally display its content in bold.

Syntax

<b>Bold text</b>

Example 1: Basic Bold Text

<p>
    Welcome to <b>HTML5</b> learning.
</p>

<p>
    This is a <b>bold statement</b>.
</p>
Expected Output:

Welcome to HTML5 learning.

This is a bold statement.

Example 2: Highlighting Technical Terms

<p>
    An <b>HTML element</b> consists of a start tag,
    content and an end tag in many cases.
</p>
Expected Output:

An HTML element consists of a start tag, content and an end tag in many cases.

Remember: Use <b> when you want to draw attention to text without assigning it additional importance or urgency.

3. The Italic Element (<i>)

The <i> element represents text set apart from normal prose for a reason such as an alternate voice, technical term, foreign-language phrase or taxonomic designation. Browsers normally display it in italic style.

Syntax

<i>Italic text</i>

Example 1: Basic Italic Text

<p>
    This is an <i>italic text example</i>.
</p>
Expected Output:

This is an italic text example.

Example 2: Foreign-Language Phrase

<p>
    The French phrase <i lang="fr">Bonjour</i>
    means hello.
</p>
Expected Output:

The French phrase Bonjour means hello.

Example 3: Scientific Name

<p>
    The scientific name of humans is
    <i>Homo sapiens</i>.
</p>
Expected Output:

The scientific name of humans is Homo sapiens.

Remember: Use <i> for text that is set apart from the surrounding prose, rather than using it simply as a general-purpose styling element.

4. Difference Between <b> and <i>

Feature <b> <i>
Purpose Draws attention to text Sets text apart from normal prose
Default appearance Bold Italic
Semantic role No added importance Alternate voice or mood, technical term, etc.
Closing tag Required Required

5. Difference Between b, i and CSS Styling

HTML defines the structure and meaning of content, while CSS controls its visual presentation.

Example

<p>
    This is <b>bold text</b>.
</p>

<p>
    This is <i>italic text</i>.
</p>

<p style="font-weight: bold;">
    This text is bold using CSS.
</p>

<p style="font-style: italic;">
    This text is italic using CSS.
</p>
Expected Output:

This is bold text.

This is italic text.

This text is bold using CSS.

This text is italic using CSS.

CSS can change the appearance of text without changing the semantic meaning of the HTML element.

6. Important Comparison: b vs strong and i vs em

HTML also provides <strong> and <em> elements. These are not simply alternative names for bold and italic formatting.

Element Meaning Typical Appearance
<b> Draws attention to text Bold
<strong> Indicates strong importance, seriousness or urgency Bold
<i> Sets text apart from normal prose Italic
<em> Indicates stress emphasis Italic
The visual appearance of these elements may look similar, but their semantic purposes are different. The next lesson explains <strong> and <em> in detail.

7. Combining Bold and Italic Elements

You can combine bold and italic formatting by nesting HTML elements correctly.

Example

<p>
    This is <b><i>bold and italic text</i></b>.
</p>

<p>
    This is <i><b>also bold and italic text</b></i>.
</p>
Expected Output:

This is bold and italic text.

This is also bold and italic text.

Always close nested elements in the reverse order in which they were opened.

8. Common Mistakes

  1. Using b for important warnings: Use <strong> when the text has strong importance.
  2. Using i for every italic style: Use CSS when you only want a visual style and no special semantic meaning.
  3. Forgetting closing tags: Write both opening and closing tags for b and i.
  4. Incorrect nesting: Close nested elements in the reverse order in which they were opened.

9. Practical Example

Create a technical introduction page using bold and italic text formatting.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Technology Introduction</title>
</head>
<body>

    <h1>Technology Introduction</h1>

    <p>
        <b>HTML5</b> is used to structure web pages.
    </p>

    <p>
        <i>HyperText Markup Language</i>
        is the full form of HTML.
    </p>

    <p>
        HTML is an important technology for
        <b>web development</b>.
    </p>

    <p>
        The term <i>frontend development</i>
        refers to the user-facing part of an application.
    </p>

</body>
</html>
Expected Output:

Technology Introduction

HTML5 is used to structure web pages.

HyperText Markup Language is the full form of HTML.

HTML is an important technology for web development.

The term frontend development refers to the user-facing part of an application.

11. Interview Questions and Answers

Q1. What is the purpose of the b element?

The b element draws attention to text without indicating additional importance.

Q2. What is the purpose of the i element?

The i element represents text set apart from normal prose, such as technical terms or foreign-language phrases.

Q3. What is the difference between b and strong?

b draws attention to text, whereas strong indicates strong importance, seriousness or urgency.

Q4. What is the difference between i and em?

i sets text apart from normal prose, whereas em indicates stress emphasis.

Q5. Which element normally displays text in bold?

The b and strong elements normally display bold text.

Q6. Which element normally displays text in italic?

The i and em elements normally display italic text.

Q7. Can CSS make text bold?

Yes. The CSS property font-weight can make text bold.

Q8. Can CSS make text italic?

Yes. The CSS property font-style can make text italic.

Q9. Do b and i require closing tags?

Yes. Both are normal HTML elements and require closing tags.

Q10. Can b and i be nested together?

Yes. They can be nested together, provided the HTML nesting rules are followed.

12. Multiple Choice Questions (MCQs)

  1. Which element normally displays text in bold?
    • A. <i>
    • B. <b>
    • C. <em>
    • D. <small>
    Answer: B. <b>
  2. Which element normally displays text in italic?
    • A. <b>
    • B. <strong>
    • C. <i>
    • D. <mark>
    Answer: C. <i>
  3. Which element indicates strong importance?
    • A. <b>
    • B. <strong>
    • C. <i>
    • D. <small>
    Answer: B. <strong>
  4. Which element indicates stress emphasis?
    • A. <em>
    • B. <b>
    • C. <hr>
    • D. <div>
    Answer: A. <em>
  5. Which CSS property controls boldness?
    • A. font-style
    • B. font-weight
    • C. text-align
    • D. text-decoration
    Answer: B. font-weight
  6. Which CSS property controls italic styling?
    • A. font-style
    • B. font-weight
    • C. margin
    • D. padding
    Answer: A. font-style
  7. Which element can be used for a foreign-language phrase set apart from normal prose?
    • A. <i>
    • B. <hr>
    • C. <br>
    • D. <input>
    Answer: A. <i>
  8. Which of the following requires a closing tag?
    • A. <br>
    • B. <hr>
    • C. <b>
    • D. <img>
    Answer: C. <b>
  9. What does the b element indicate?
    • A. Strong importance
    • B. A line break
    • C. Attention without added importance
    • D. A hyperlink
    Answer: C. Attention without added importance
  10. Can b and i elements be combined?
    • A. Yes
    • B. No
    • C. Only with JavaScript
    • D. Only with CSS
    Answer: A. Yes

13. Lesson Summary

  • <b> draws attention to text and normally displays it in bold.
  • <i> sets text apart from normal prose and normally displays it in italic.
  • <strong> indicates strong importance.
  • <em> indicates stress emphasis.
  • CSS can control visual text styling independently of HTML semantics.
  • Both b and i require opening and closing tags.
