Subscript and Superscript in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides two elements for displaying characters below or above the normal text baseline:

  • <sub> – Displays subscript text.
  • <sup> – Displays superscript text.

These elements are useful in chemical formulas, mathematical expressions, scientific notation, footnote references and other technical content.

2. The Subscript Element (<sub>)

The <sub> element represents subscript text. Browsers normally display its content slightly below the normal text baseline and in a smaller font.

Syntax

<sub>Subscript text</sub>

Example 1: Basic Subscript

<p>
    H<sub>2</sub>O
</p>
Expected Output:

H2O

Example 2: Chemical Formula

<p>
    Carbon dioxide: CO<sub>2</sub>
</p>

<p>
    Sulfuric acid: H<sub>2</sub>SO<sub>4</sub>
</p>

<p>
    Glucose: C<sub>6</sub>H<sub>12</sub>O<sub>6</sub>
</p>
Expected Output:

Carbon dioxide: CO2

Sulfuric acid: H2SO4

Glucose: C6H12O6

Example 3: Mathematical Index

<p>
    a<sub>1</sub> + a<sub>2</sub> + a<sub>3</sub>
</p>
Expected Output:

a1 + a2 + a3

Remember: Subscript text appears below the normal text baseline. It is commonly used for chemical formulas and indexed variables.

3. The Superscript Element (<sup>)

The <sup> element represents superscript text. Browsers normally display its content slightly above the normal text baseline and in a smaller font.

Syntax

<sup>Superscript text</sup>

Example 1: Basic Superscript

<p>
    X<sup>2</sup>
</p>
Expected Output:

X2

Example 2: Mathematical Expressions

<p>
    x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup>
</p>

<p>
    a<sup>3</sup> + b<sup>3</sup>
</p>
Expected Output:

x2 + y2 = z2

a3 + b3

Example 3: Ordinal Numbers

<p>
    1<sup>st</sup> position
</p>

<p>
    2<sup>nd</sup> position
</p>

<p>
    3<sup>rd</sup> position
</p>
Expected Output:

1st position

2nd position

3rd position

Example 4: Footnote Reference

<p>
    HTML is used to structure web pages.<sup>1</sup>
</p>

<p>
    <small>1. HTML stands for HyperText Markup Language.</small>
</p>
Expected Output:

HTML is used to structure web pages.1

1. HTML stands for HyperText Markup Language.

Remember: Superscript text appears above the normal text baseline. It is commonly used for exponents, mathematical powers and reference markers.

4. Difference Between Subscript and Superscript

Feature <sub> <sup>
Meaning Subscript Superscript
Position Below the baseline Above the baseline
Common usage Chemical formulas and indices Exponents and reference markers
Example H2O X2
Closing tag Required Required

5. Combining Subscript and Superscript

Both elements can be used in the same expression when the content requires characters at different vertical positions.

Example

<p>
    X<sub>1</sub><sup>2</sup>
</p>

<p>
    A<sub>n</sub><sup>2</sup>
</p>
Expected Output:

X12

An2

Use sub and sup only when their semantic purpose matches the content. For complex mathematical equations, consider MathML or a dedicated mathematics rendering solution.

6. Subscript and Superscript Using CSS

CSS can visually position text above or below the baseline. However, CSS styling does not provide the same semantic meaning as the sub and sup elements.

Example

<style>
    .subscript {
        vertical-align: sub;
        font-size: smaller;
    }

    .superscript {
        vertical-align: super;
        font-size: smaller;
    }
</style>

<p>
    H<span class="subscript">2</span>O
</p>

<p>
    X<span class="superscript">2</span>
</p>
Expected Output:

H2O

X2

Use semantic HTML elements when the content is genuinely subscript or superscript. Use CSS for purely visual positioning.

7. Common Mistakes

  1. Confusing subscript and superscript: Remember that sub appears below and sup appears above the baseline.
  2. Using CSS for semantic content: Prefer sub and sup when their semantic meaning is required.
  3. Forgetting closing tags: Both elements require opening and closing tags.
  4. Using these elements for complex equations: Use MathML or an appropriate mathematical notation system for complex expressions.

8. Practical Example

Create a science and mathematics page using subscript and superscript elements.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Science and Mathematics</title>
</head>
<body>

    <h1>Science and Mathematics</h1>

    <h2>Chemical Formulas</h2>

    <p>Water: H<sub>2</sub>O</p>

    <p>Carbon dioxide: CO<sub>2</sub></p>

    <p>
        Sulfuric acid:
        H<sub>2</sub>SO<sub>4</sub>
    </p>

    <h2>Mathematical Expressions</h2>

    <p>x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup></p>

    <p>10<sup>3</sup> = 1000</p>

    <h2>Indexed Variables</h2>

    <p>a<sub>1</sub> + a<sub>2</sub> + a<sub>3</sub></p>

</body>
</html>
Expected Output:

Science and Mathematics

Chemical Formulas

Water: H2O

Carbon dioxide: CO2

Sulfuric acid: H2SO4

Mathematical Expressions

x2 + y2 = z2

103 = 1000

Indexed Variables

a1 + a2 + a3

10. Interview Questions and Answers

Q1. What is the purpose of the sub element?

It represents subscript text, which is normally displayed below the text baseline.

Q2. What is the purpose of the sup element?

It represents superscript text, which is normally displayed above the text baseline.

Q3. What is the difference between sub and sup?

sub positions text below the baseline, whereas sup positions text above the baseline.

Q4. Where is sub commonly used?

It is commonly used in chemical formulas and mathematical indices.

Q5. Where is sup commonly used?

It is commonly used for mathematical exponents and reference markers.

Q6. How can we write H2O in HTML?

Write H followed by the sub element containing 2, followed by O.

Q7. How can we write X squared in HTML?

Write X followed by the sup element containing 2.

Q8. Do sub and sup require closing tags?

Yes. Both elements require opening and closing tags.

Q9. Can CSS create subscript and superscript appearances?

Yes. CSS can use vertical-align and font-size to reproduce their visual positioning.

Q10. What should be used for complex mathematical equations?

MathML or an appropriate mathematical rendering solution is suitable for complex equations.

11. Multiple Choice Questions (MCQs)

  1. Which element displays subscript text?
    • A. <sup>
    • B. <sub>
    • C. <small>
    • D. <mark>
    Answer: B. <sub>
  2. Which element displays superscript text?
    • A. <sub>
    • B. <sup>
    • C. <del>
    • D. <ins>
    Answer: B. <sup>
  3. Which element is suitable for the 2 in H2O?
    • A. <sup>
    • B. <sub>
    • C. <strong>
    • D. <em>
    Answer: B. <sub>
  4. Which element is suitable for the 2 in X squared?
    • A. <sub>
    • B. <sup>
    • C. <small>
    • D. <mark>
    Answer: B. <sup>
  5. Where does subscript text normally appear?
    • A. Above the baseline
    • B. Below the baseline
    • C. At the beginning
    • D. At the end
    Answer: B. Below the baseline
  6. Where does superscript text normally appear?
    • A. Below the baseline
    • B. Above the baseline
    • C. Inside a paragraph
    • D. Outside the document
    Answer: B. Above the baseline
  7. Which CSS property can position text vertically?
    • A. background-color
    • B. vertical-align
    • C. text-transform
    • D. border
    Answer: B. vertical-align
  8. Which HTML elements require closing tags?
    • A. sub only
    • B. sup only
    • C. Both sub and sup
    • D. Neither
    Answer: C. Both sub and sup
  9. Which technology is appropriate for complex mathematical notation?
    • A. MathML
    • B. FTP
    • C. SMTP
    • D. CSS Grid
    Answer: A. MathML
  10. Which element is appropriate for a mathematical index such as a1?
    • A. <sup>
    • B. <sub>
    • C. <mark>
    • D. <del>
    Answer: B. <sub>

12. Lesson Summary

  • <sub> represents subscript text.
  • <sup> represents superscript text.
  • Subscript appears below the normal text baseline.
  • Superscript appears above the normal text baseline.
  • Sub is commonly used in chemical formulas and indices.
  • Sup is commonly used in exponents and reference markers.
  • Both elements require opening and closing tags.
