Chapter 3: HTML Text Formatting

HTML5 – Complete Study Course | NS Learning Hub

Chapter Overview

This chapter explains how to structure and format text using HTML elements. You will learn headings, paragraphs, line breaks, horizontal rules, text emphasis, subscript, superscript, preformatted text, code elements, quotations and citation elements.

Total Lessons: 9

Level: Beginner to Intermediate

Learning Objectives

After completing this chapter, you will be able to:

  • Use HTML heading elements from h1 to h6.
  • Create paragraphs using the p element.
  • Insert line breaks and horizontal rules.
  • Format text using bold and italic elements.
  • Understand semantic emphasis using strong and em.
  • Use small, mark and del elements.
  • Display subscript and superscript text.
  • Display preformatted text and code snippets.
  • Represent quotations and citations correctly.

Chapter Lessons

LESSON 01

Headings in HTML

Learn heading elements h1 to h6, heading hierarchy, document outline concepts and best practices.

LESSON 02

Paragraph Element

Understand the p element, paragraph structure, whitespace handling and paragraph formatting.

LESSON 03

Line Break and Horizontal Rule

Learn the br and hr elements and how to create line breaks and thematic section breaks.

LESSON 04

Bold and Italic Text

Learn the b and i elements and understand their use in HTML text formatting.

LESSON 05

Strong and Emphasis Elements

Understand strong and em elements, semantic importance, stress emphasis and accessibility.

LESSON 06

Small, Mark and Deleted Text

Learn small, mark and del elements for fine print, highlighted text and deleted content.

LESSON 07

Subscript and Superscript

Learn sub and sup elements for chemical formulas, mathematical expressions and scientific notation.

LESSON 08

Preformatted Text and Code Elements

Understand pre, code, samp, kbd and var elements for displaying code and computer-related text.

LESSON 09

Quotation and Citation Elements

Learn blockquote, q, cite and related elements for quotations and source references.

Chapter Completion

Complete all 9 lessons and practice the HTML examples to understand text structure and semantic formatting.
