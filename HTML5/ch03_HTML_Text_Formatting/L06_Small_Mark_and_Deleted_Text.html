Small, Mark and Deleted Text in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides several elements for representing different types of text content. Three useful elements are:

  • <small> – Represents side comments and small print.
  • <mark> – Highlights text relevant to a particular context.
  • <del> – Represents text that has been deleted from a document.

These elements have semantic purposes in addition to their usual browser appearance.

2. The Small Element (<small>)

The <small> element represents side comments and small print, such as copyright information, legal disclaimers and terms and conditions.

Syntax

<small>Small print text</small>

Example 1: Basic Small Text

<p>
    Welcome to HTML5 learning.
    <small>Terms and conditions apply.</small>
</p>
Expected Output:

Welcome to HTML5 learning. Terms and conditions apply.

Example 2: Copyright Information

<footer>
    <small>
        Copyright &copy; 2026 NS Learning Hub.
        All rights reserved.
    </small>
</footer>
Expected Output:

Copyright © 2026 NS Learning Hub. All rights reserved.

Example 3: Disclaimer

<p>
    Course information is provided for educational purposes.
    <small>Content may be updated from time to time.</small>
</p>
Expected Output:

Course information is provided for educational purposes. Content may be updated from time to time.

Remember: The small element is intended for side comments and small print. It is not a general-purpose element for making any text smaller.

3. The Mark Element (<mark>)

The <mark> element represents text that is highlighted because it is relevant to the current context. Browsers normally display it with a yellow background.

Syntax

<mark>Highlighted text</mark>

Example 1: Basic Highlighting

<p>
    HTML stands for
    <mark>HyperText Markup Language</mark>.
</p>
Expected Output:

HTML stands for HyperText Markup Language.

Example 2: Highlighting a Search Result

<p>
    Search results for HTML:
    <mark>HTML5</mark> is used to structure web pages.
</p>
Expected Output:

Search results for HTML: HTML5 is used to structure web pages.

Example 3: Highlighting Important Study Content

<p>
    In HTML, the
    <mark>DOCTYPE declaration</mark>
    identifies the document type and standards mode.
</p>
Expected Output:

In HTML, the DOCTYPE declaration identifies the document type and standards mode.

Remember: Use mark when a portion of text is highlighted because it is relevant to the user's current activity or context, such as a search result.

4. The Deleted Text Element (<del>)

The <del> element represents text that has been deleted from a document. Browsers normally display deleted text with a strikethrough.

Syntax

<del>Deleted text</del>

Example 1: Basic Deleted Text

<p>
    Old price:
    <del>₹1,000</del>
</p>
Expected Output:

Old price: ₹1,000

Example 2: Showing a Revised Statement

<p>
    The course duration is
    <del>3 months</del>
    now 6 months.
</p>
Expected Output:

The course duration is 3 months now 6 months.

Example 3: Using datetime and cite Attributes

The del element supports attributes that can describe when the deletion occurred and the source explaining the change. 

<p>
    Course fee:
    <del datetime="2026-11-01"
         cite="https://example.com/fee-update">
        ₹5,000
    </del>
    ₹4,500
</p>
Expected Output:

Course fee: ₹5,000 ₹4,500

The datetime and cite attributes provide information about the change; they are not normally displayed.
Remember: The del element has semantic meaning. It indicates that the enclosed content has been removed from the document.

5. The cite and datetime Attributes of del

datetime Attribute

The datetime attribute specifies the date and optionally the time when the text was deleted. 

<del datetime="2026-11-06">
    Old information
</del>

cite Attribute

The cite attribute provides a URL pointing to a document that explains the reason for the deletion. 

<del cite="https://example.com/change-details">
    Old information
</del>
The cite attribute is a reference URL, not visible citation text. These attributes do not automatically display a date or explanation to visitors.

6. Difference Between small, mark and del

Feature <small> <mark> <del>
Purpose Side comments and small print Contextually highlighted text Deleted content
Default appearance Smaller text Usually yellow background Strikethrough
Semantic meaning Side information Relevant highlighted content Removed content
Closing tag Required Required Required

7. The Inserted Text Element (<ins>)

The <ins> element represents text that has been inserted into a document. It is commonly used together with <del> to show changes.

Syntax

<ins>Inserted text</ins>

Example: Showing Updated Information

<p>
    Course fee:
    <del>₹5,000</del>
    <ins>₹4,500</ins>
</p>
Expected Output:

Course fee: ₹5,000 ₹4,500

The browser normally displays inserted text with an underline.

datetime and cite Attributes of ins

<p>
    <del datetime="2026-11-01">
        Old schedule
    </del>

    <ins datetime="2026-11-06">
        Updated schedule
    </ins>
</p>
The ins element is included here because it is the natural counterpart of del. It is also part of HTML text-editing markup and is useful for representing document revisions.

8. Common Mistakes

  1. Using small for every small font: Use CSS font-size when only visual sizing is required.
  2. Using mark only for decoration: Use mark when the highlighted content is relevant to the current context.
  3. Using del to create strikethrough decoration: Use CSS text-decoration when the text has not actually been deleted.
  4. Forgetting ins: Use ins when you need to represent newly inserted content alongside deleted content.
  5. Using an invalid date: Provide a valid date or date-time value for datetime.

9. Practical Example

Create a course announcement page showing highlighted information, a revised fee and copyright information.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Course Announcement</title>
</head>
<body>

    <h1>HTML5 Course Announcement</h1>

    <p>
        <mark>New batch starting soon!</mark>
    </p>

    <h2>Course Fee</h2>

    <p>
        Previous fee:
        <del>₹5,000</del>
    </p>

    <p>
        Updated fee:
        <ins>₹4,500</ins>
    </p>

    <h2>Course Information</h2>

    <p>
        Learn HTML5 from basic to advanced level.
    </p>

    <footer>
        <small>
            Copyright &copy; 2026 NS Learning Hub.
            All rights reserved.
        </small>
    </footer>

</body>
</html>

HTML5 Course Announcement

New batch starting soon!

Course Fee

Previous fee: ₹5,000

Updated fee: ₹4,500

Course Information

Learn HTML5 from basic to advanced level.

Copyright © 2026 NS Learning Hub. All rights reserved.

11. Interview Questions and Answers

Q1. What is the purpose of the small element?

It represents side comments and small print, such as copyright information and legal disclaimers.

Q2. What is the purpose of the mark element?

It represents text highlighted because it is relevant to the current context.

Q3. What is the purpose of the del element?

It represents text that has been deleted from a document.

Q4. What is the purpose of the ins element?

It represents text that has been inserted into a document.

Q5. What is the default appearance of mark?

Browsers normally display marked text with a highlighted background.

Q6. What is the default appearance of del?

Browsers normally display deleted text with a strikethrough.

Q7. What is the purpose of the datetime attribute?

It specifies the date and optionally the time when content was inserted or deleted.

Q8. What is the purpose of the cite attribute?

It provides a URL pointing to a document that explains the change.

Q9. Can del and ins be used together?

Yes. They can represent removed and replacement content.

Q10. Should del be used only to create a strikethrough effect?

No. Use it when the content has actually been deleted. Use CSS for purely visual strikethrough styling.

12. Multiple Choice Questions (MCQs)

  1. Which element represents small print?
    • A. <mark>
    • B. <small>
    • C. <del>
    • D. <strong>
    Answer: B. <small>
  2. Which element highlights relevant text?
    • A. <mark>
    • B. <small>
    • C. <del>
    • D. <hr>
    Answer: A. <mark>
  3. Which element represents deleted content?
    • A. <ins>
    • B. <mark>
    • C. <del>
    • D. <small>
    Answer: C. <del>
  4. Which element represents inserted content?
    • A. <ins>
    • B. <del>
    • C. <hr>
    • D. <br>
    Answer: A. <ins>
  5. What is the usual appearance of del?
    • A. Bold
    • B. Italic
    • C. Strikethrough
    • D. Highlighted
    Answer: C. Strikethrough
  6. Which attribute specifies when text was deleted?
    • A. href
    • B. datetime
    • C. alt
    • D. class
    Answer: B. datetime
  7. Which attribute provides a URL explaining a change?
    • A. cite
    • B. src
    • C. title
    • D. id
    Answer: A. cite
  8. Which element is appropriate for copyright information?
    • A. <mark>
    • B. <small>
    • C. <del>
    • D. <hr>
    Answer: B. <small>
  9. Which element normally displays highlighted text?
    • A. <mark>
    • B. <del>
    • C. <small>
    • D. <ins>
    Answer: A. <mark>
  10. Which pair is commonly used to represent document revisions?
    • A. b and i
    • B. p and div
    • C. del and ins
    • D. br and hr
    Answer: C. del and ins

13. Lesson Summary

  • <small> represents side comments and small print.
  • <mark> highlights text relevant to the current context.
  • <del> represents deleted content.
  • <ins> represents inserted content.
  • datetime specifies when content was inserted or deleted.
  • cite provides a URL explaining a change.
