Quotation and Citation Elements in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides elements for representing quotations, citations and abbreviations. These elements help give text a meaningful structure.

The important elements covered in this lesson are:

  • <blockquote> – Represents an extended quotation.
  • <q> – Represents a short inline quotation.
  • <cite> – Represents the title of a creative work.
  • <abbr> – Represents an abbreviation or acronym.

2. The Blockquote Element (<blockquote>)

The <blockquote> element represents a section of content quoted from another source.

It is suitable for longer quotations that are displayed separately from the surrounding paragraph.

Syntax

<blockquote>
    Quoted content goes here.
</blockquote>

Example 1: Basic Blockquote

<blockquote>
    Learning never exhausts the mind.
</blockquote>
Expected Output:
Learning never exhausts the mind.

Example 2: Blockquote with Attribution

<blockquote>
    The only way to do great work is to love what you do.
</blockquote>

<p>
    — Steve Jobs
</p>
Expected Output:
The only way to do great work is to love what you do.

— Steve Jobs

Example 3: Using the cite Attribute

<blockquote cite="https://example.com/article">
    HTML provides the structure of a web page.
</blockquote>

The cite attribute can provide the URL of the source of the quotation. It does not automatically display the source as a visible link.

Important: Blockquote is intended for extended quotations. Browsers commonly indent it by default, but its visual appearance can be changed using CSS.

3. The Inline Quotation Element (<q>)

The <q> element represents a short quotation within a paragraph or another inline context.

Browsers typically insert quotation marks automatically around its content.

Syntax

<q>Short quoted text</q>

Example 1: Basic Inline Quotation

<p>
    He said, <q>HTML is easy to learn.</q>
</p>
Expected Output:

He said, HTML is easy to learn.

Example 2: Quotation in a Sentence

<p>
    The teacher said,
    <q>Practice makes a programmer better.</q>
</p>
Expected Output:

The teacher said, Practice makes a programmer better.

Example 3: Using the cite Attribute

<p>
    The article states:
    <q cite="https://example.com/article">
        Web development begins with HTML.
    </q>
</p>

The cite attribute identifies the source URL. It is not automatically shown to visitors.

Remember: Use q for short inline quotations and blockquote for longer, separately displayed quotations.

4. The Citation Element (<cite>)

The <cite> element represents the title of a creative work, such as a book, movie, research paper, song, painting or website publication.

Browsers commonly display cite content in italic text.

Example 1: Book Title

<p>
    I am reading
    <cite>The C Programming Language</cite>.
</p>
Expected Output:

I am reading The C Programming Language.

Example 2: Movie Title

<p>
    My favourite movie is
    <cite>The Social Network</cite>.
</p>
Expected Output:

My favourite movie is The Social Network.

Example 3: Research Paper Title

<p>
    The research paper
    <cite>A Study of Computer Networks</cite>
    discusses network communication.
</p>
Expected Output:

The research paper A Study of Computer Networks discusses network communication.

Important: Cite is for the title of a work, not simply the name of a person who said something. Use ordinary text for an author's name or speaker's name.

5. The Abbreviation Element (<abbr>)

The <abbr> element represents an abbreviation or acronym.

Its title attribute can provide the full expansion of the abbreviation.

Syntax

<abbr title="Full Form">ABBR</abbr>

Example 1: HTML

<p>
    <abbr title="HyperText Markup Language">HTML</abbr>
    is used to structure web pages.
</p>
Expected Output:

HTML is used to structure web pages.

Example 2: CSS and JavaScript

<p>
    <abbr title="Cascading Style Sheets">CSS</abbr>
    controls the presentation of web pages.
</p>

<p>
    <abbr title="JavaScript">JS</abbr>
    adds interactive behaviour to web pages.
</p>
Expected Output:

CSS controls the presentation of web pages.

JS adds interactive behaviour to web pages.

Example 3: Technical Abbreviations

<p>
    <abbr title="Central Processing Unit">CPU</abbr>
    performs processing operations.
</p>

<p>
    <abbr title="Random Access Memory">RAM</abbr>
    stores data temporarily.
</p>
Expected Output:

CPU performs processing operations.

RAM stores data temporarily.

Remember: The title attribute provides the full form as supplementary information. Browsers may display it as a tooltip when the user points to the abbreviation.

6. Difference Between blockquote, q, cite and abbr

Element Purpose Example
<blockquote> Represents an extended quotation. A separately displayed quotation.
<q> Represents a short inline quotation. A quoted phrase in a sentence.
<cite> Represents the title of a creative work. A book or movie title.
<abbr> Represents an abbreviation or acronym. HTML, CPU or RAM.

7. Common Mistakes

  1. Using blockquote for short quotations: Use q for short inline quotations.
  2. Using q for long quotations: Use blockquote for extended quoted sections.
  3. Using cite for an author's name: Cite represents the title of a creative work, not simply the person who created it.
  4. Forgetting the abbr title attribute: Provide the full form when it is useful to explain the abbreviation.
  5. Expecting cite to display a source link: Cite does not automatically create a hyperlink.

8. Practical Example

Create an educational web page containing quotations, book references and technical abbreviations.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Learning Page</title>
</head>
<body>

    <h1>HTML Learning Page</h1>

    <h2>Quotation</h2>

    <blockquote>
        Learning is a continuous process.
    </blockquote>

    <p>
        Our instructor said,
        <q>Keep practising HTML every day.</q>
    </p>

    <h2>Book Reference</h2>

    <p>
        Recommended book:
        <cite>The C Programming Language</cite>.
    </p>

    <h2>Technical Abbreviations</h2>

    <p>
        <abbr title="HyperText Markup Language">HTML</abbr>
        structures web pages.
    </p>

    <p>
        <abbr title="Cascading Style Sheets">CSS</abbr>
        styles web pages.
    </p>

    <p>
        <abbr title="Central Processing Unit">CPU</abbr>
        processes instructions.
    </p>

</body>
</html>
Expected Output:

HTML Learning Page

Quotation

Learning is a continuous process.

Our instructor said, Keep practising HTML every day.

Book Reference

Recommended book: The C Programming Language.

Technical Abbreviations

HTML structures web pages.

CSS styles web pages.

CPU processes instructions.

10. Interview Questions and Answers

Q1. What is the purpose of the blockquote element?

It represents an extended quotation from another source.

Q2. What is the purpose of the q element?

It represents a short inline quotation.

Q3. What is the difference between blockquote and q?

Blockquote represents an extended quotation, while q represents an inline quotation.

Q4. What is the purpose of the cite element?

It represents the title of a creative work, such as a book, movie or research paper.

Q5. What is the purpose of the abbr element?

It represents an abbreviation or acronym.

Q6. Which attribute is commonly used with abbr?

The title attribute can provide the full form of the abbreviation.

Q7. Does blockquote have a cite attribute?

Yes. Its cite attribute can specify the URL of the source of the quotation.

Q8. Does the cite attribute automatically create a hyperlink?

No. It identifies a source URL but does not create a visible hyperlink.

Q9. Does the q element normally display quotation marks?

Yes. Browsers commonly insert quotation marks around its content.

Q10. Can cite be used for the name of a person who said a quotation?

No. Cite represents the title of a creative work. A person's name should normally be written as ordinary text.

11. Multiple Choice Questions (MCQs)

  1. Which element represents an extended quotation?
    • A. <q>
    • B. <blockquote>
    • C. <cite>
    • D. <abbr>
    Answer: B. <blockquote>
  2. Which element represents an inline quotation?
    • A. <q>
    • B. <pre>
    • C. <var>
    • D. <small>
    Answer: A. <q>
  3. Which element represents the title of a creative work?
    • A. <abbr>
    • B. <cite>
    • C. <q>
    • D. <mark>
    Answer: B. <cite>
  4. Which element represents an abbreviation?
    • A. <abbr>
    • B. <cite>
    • C. <blockquote>
    • D. <del>
    Answer: A. <abbr>
  5. Which attribute can provide the full form of an abbreviation?
    • A. href
    • B. src
    • C. title
    • D. width
    Answer: C. title
  6. Which attribute can identify the source URL of a blockquote?
    • A. alt
    • B. cite
    • C. class
    • D. id
    Answer: B. cite
  7. Does the cite attribute create a visible hyperlink?
    • A. Yes
    • B. No
    • C. Only in Chrome
    • D. Only in Firefox
    Answer: B. No
  8. Which element is most appropriate for a short quotation inside a paragraph?
    • A. <blockquote>
    • B. <q>
    • C. <pre>
    • D. <code>
    Answer: B. <q>
  9. Which element is appropriate for the title of a book?
    • A. <cite>
    • B. <abbr>
    • C. <kbd>
    • D. <samp>
    Answer: A. <cite>
  10. Which statement about q is correct?
    • A. It represents an abbreviation.
    • B. It represents an inline quotation.
    • C. It represents program output.
    • D. It represents a variable.
    Answer: B. It represents an inline quotation.

12. Lesson Summary

  • <blockquote> represents an extended quotation.
  • <q> represents a short inline quotation.
  • <cite> represents the title of a creative work.
  • <abbr> represents an abbreviation or acronym.
  • The cite attribute can identify the source URL of a quotation.
  • The title attribute can provide the full form of an abbreviation.
  • These elements improve the semantic meaning of HTML content.
