Line Break and Horizontal Rule in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides two elements that help organize text and separate content visually and semantically:

  • <br> – Inserts a line break.
  • <hr> – Represents a thematic break between sections of content.

Both elements are void elements, meaning they do not have closing tags or contain child content.

2. The Line Break Element (<br>)

The <br> element creates a line break within text. The content following it starts on the next line.

Syntax

First line<br>
Second line

Example 1: Basic Line Break

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Line Break Example</title>
</head>
<body>

    <h2>My Introduction</h2>

    <p>
        My name is Rahul.<br>
        I am an engineering student.<br>
        I am learning HTML5.
    </p>

</body>
</html>
Expected Output:

My Introduction
My name is Rahul.
I am an engineering student.
I am learning HTML5.

Example 2: Address Using Line Breaks

<p>
    Navdeep Sangwan<br>
    Chandigarh, India<br>
    Email: example@email.com
</p>
Expected Output:

Navdeep Sangwan
Chandigarh, India
Email: example@email.com

When Should You Use <br>?

  • Displaying postal addresses.
  • Formatting poetry where line breaks are meaningful.
  • Displaying song or verse lines where the original line structure matters.
  • Breaking a line within a paragraph when necessary.
Important: Do not use multiple <br> elements to create large empty spaces between sections. Use CSS margin and padding for layout and spacing.

3. The Horizontal Rule Element (<hr>)

The <hr> element represents a thematic break between paragraph-level sections of content. Browsers commonly display it as a horizontal line.

Syntax

<hr>

Example 1: Basic Horizontal Rule

<h2>Introduction</h2>
<p>HTML is used to structure web pages.</p>

<hr>

<h2>CSS</h2>
<p>CSS is used to style web pages.</p>
Expected Output:

Introduction

HTML is used to structure web pages.

CSS

CSS is used to style web pages.

Example 2: Styling a Horizontal Rule with CSS

<style>
    hr {
        border: none;
        height: 2px;
        background-color: #174ea6;
        margin: 25px 0;
    }
</style>

<h2>First Section</h2>
<p>This is the first section.</p>

<hr>

<h2>Second Section</h2>
<p>This is the second section.</p>
Expected Output:

First Section

This is the first section.

Second Section

This is the second section.

Remember: The <hr> element has semantic meaning. It indicates a change in topic or a thematic separation, not simply a decorative line.

4. Difference Between <br> and <hr>

Feature <br> <hr>
Full meaning Line break Thematic break
Purpose Moves following text to a new line Separates thematic sections
Default appearance No visible line Usually a horizontal rule
Semantic meaning Line break within content Change in topic or section
Void element Yes Yes
Closing tag Not required Not required

5. Void Elements in HTML

A void element is an HTML element that cannot contain child content and does not require a closing tag.

Examples of HTML void elements include:

  • <br> – Line break.
  • <hr> – Thematic break.
  • <img> – Image.
  • <input> – Form input.
  • <meta> – Metadata.
  • <link> – External resource link.
In HTML5, write <br> and <hr>. The slash forms <br /> and <hr /> are also accepted in HTML syntax, but the slash is unnecessary.

6. Common Mistakes

  1. Using <br> for spacing: Use CSS margin and padding to control spacing between elements.
  2. Using <hr> only as decoration: Use it when there is a meaningful thematic change in content.
  3. Writing closing tags: Do not write </br> or </hr>.
  4. Putting content inside a void element: Do not place text or other elements inside <br> or <hr>.

7. Practical Example

Create a simple student profile page using headings, paragraphs, line breaks and horizontal rules.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Student Profile</title>
</head>
<body>

    <h1>Student Profile</h1>

    <p>
        Name: Rahul Sharma<br>
        Course: B.Tech<br>
        Branch: Electronics and Communication Engineering
    </p>

    <hr>

    <h2>About Me</h2>

    <p>
        I am an engineering student interested in
        programming and embedded systems.
    </p>

    <hr>

    <h2>Contact Information</h2>

    <p>
        City: Chandigarh<br>
        Country: India
    </p>

</body>
</html>
Expected Output:

Student Profile

Name: Rahul Sharma
Course: B.Tech
Branch: Electronics and Communication Engineering

About Me

I am an engineering student interested in programming and embedded systems.

Contact Information

City: Chandigarh
Country: India

9. Interview Questions and Answers

Q1. What is the purpose of the <br> element?

It inserts a line break within text, causing the following content to start on the next line.

Q2. What is the purpose of the <hr> element?

It represents a thematic break between sections of content. Browsers generally display it as a horizontal line.

Q3. Are <br> and <hr> void elements?

Yes. Both are void elements and do not require closing tags.

Q4. What is a void element?

A void element is an HTML element that cannot contain child content and has no closing tag.

Q5. Can we write </br>?

No. The br element does not have a closing tag.

Q6. Can we write </hr>?

No. The hr element does not have a closing tag.

Q7. What is the difference between br and hr?

br creates a line break within content, whereas hr represents a thematic separation between sections.

Q8. Can CSS style an hr element?

Yes. CSS properties such as border, height, background-color and margin can control its appearance.

Q9. Should br be used to create space between paragraphs?

No. Use CSS margin or padding to create spacing between elements.

Q10. Is hr only a decorative horizontal line?

No. It has semantic meaning and represents a thematic break in the content.

10. Multiple Choice Questions (MCQs)

  1. Which element creates a line break?
    • A. <p>
    • B. <br>
    • C. <hr>
    • D. <div>
    Answer: B. <br>
  2. Which element represents a thematic break?
    • A. <hr>
    • B. <br>
    • C. <span>
    • D. <strong>
    Answer: A. <hr>
  3. Which of these is a void element?
    • A. <div>
    • B. <p>
    • C. <br>
    • D. <h1>
    Answer: C. <br>
  4. Which element is commonly displayed as a horizontal line?
    • A. <br>
    • B. <hr>
    • C. <em>
    • D. <small>
    Answer: B. <hr>
  5. Which tag is unnecessary in HTML5?
    • A. <br>
    • B. <hr>
    • C. </br>
    • D. <p>
    Answer: C. </br>
  6. Which CSS property can create space around an element?
    • A. margin
    • B. title
    • C. href
    • D. alt
    Answer: A. margin
  7. Which element is appropriate for separating two thematic sections?
    • A. <br>
    • B. <hr>
    • C. <input>
    • D. <img>
    Answer: B. <hr>
  8. Can an hr element contain child elements?
    • A. Yes
    • B. No
    • C. Only paragraphs
    • D. Only headings
    Answer: B. No
  9. Which element is suitable for displaying address lines?
    • A. <br>
    • B. <hr>
    • C. <table>
    • D. <button>
    Answer: A. <br>
  10. Which element has semantic meaning as a thematic break?
    • A. <span>
    • B. <hr>
    • C. <b>
    • D. <i>
    Answer: B. <hr>

11. Lesson Summary

  • <br> inserts a line break within text.
  • <hr> represents a thematic break between sections.
  • Both are void elements and do not need closing tags.
  • Use CSS margin and padding for layout spacing.
  • Use <hr> when the content has a meaningful thematic separation.
