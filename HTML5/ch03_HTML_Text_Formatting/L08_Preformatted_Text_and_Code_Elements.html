Preformatted Text and Code Elements in HTML

HTML5 – Complete Study Course | Chapter 3: HTML Text Formatting

1. Introduction

HTML provides several elements for displaying source code, preformatted text, keyboard input, program output and programming variables.

The important elements covered in this lesson are:

  • <pre> – Preformatted text.
  • <code> – A fragment of computer code.
  • <kbd> – User keyboard input.
  • <samp> – Sample program output.
  • <var> – A variable or placeholder.

2. The Preformatted Text Element (<pre>)

The <pre> element represents a block of preformatted text. Browsers preserve the whitespace and line breaks present in its content.

Unlike normal HTML text, multiple spaces and line breaks inside a pre element are generally displayed as written.

Syntax

<pre>
    Preformatted text goes here.
    Spaces and line breaks are preserved.
</pre>

Example 1: Preserving Spaces and Line Breaks

<pre>
Name:     Navdeep
Course:   HTML5
Subject:  Web Development
</pre>
Expected Output: 
Name:     Navdeep
Course:   HTML5
Subject:  Web Development

Example 2: Displaying ASCII Art

<pre>
   *
  ***
 *****
*******
</pre>
Expected Output: 
   *
  ***
 *****
*******
Important: The pre element preserves whitespace and line breaks, but browsers normally use a monospace font for its default presentation.

3. The Code Element (<code>)

The <code> element represents a fragment of computer code. Browsers normally display it using a monospace font.

It can be used for inline code within a sentence or inside a pre element for a block of source code.

Example 1: Inline Code

<p>
    Use the <code>printf()</code> function in C.
</p>
Expected Output:

Use the printf() function in C.

Example 2: Displaying a C Program

<p>Example of a C program:</p>

<pre><code>
#include &lt;stdio.h&gt;

int main(void)
{
    printf("Hello, World!");

    return 0;
}
</code></pre>
Expected Output:

Example of a C program:

#include <stdio.h>

int main(void)
{
    printf("Hello, World!");

    return 0;
}
Important: The code element identifies computer code semantically. It does not automatically apply programming-language syntax highlighting.

4. Combining Pre and Code Elements

A common method for displaying a complete source-code block is to place the code element inside the pre element.

Syntax

<pre>
    <code>
        Source code goes here.
    </code>
</pre>

Example

<pre><code>
int main(void)
{
    int a = 10;
    int b = 20;

    int sum = a + b;

    return 0;
}
</code></pre>
Expected Output: 
int main(void)
{
    int a = 10;
    int b = 20;

    int sum = a + b;

    return 0;
}

In this combination, pre preserves the code formatting and code identifies the content as computer code.

5. The Keyboard Input Element (<kbd>)

The <kbd> element represents user input, typically entered using a keyboard or another input device.

Example 1: Keyboard Shortcut

<p>
    Press <kbd>Ctrl</kbd> + <kbd>S</kbd>
    to save a file.
</p>
Expected Output:

Press Ctrl + S to save a file.

Example 2: Multiple Keys

<p>
    Press <kbd>Ctrl</kbd> +
    <kbd>Alt</kbd> +
    <kbd>Delete</kbd>.
</p>
Expected Output:

Press Ctrl + Alt + Delete.

Example 3: Terminal Input

<p>
    Enter <kbd>gcc main.c -o main</kbd>
    in the terminal.
</p>
Expected Output:

Enter gcc main.c -o main in the terminal.

6. The Sample Output Element (<samp>)

The <samp> element represents sample output from a computer program or computing system.

Example 1: Program Output

<p>Program output:</p>

<samp>Hello, World!</samp>
Expected Output:

Program output:

Hello, World!

Example 2: Error Message

<p>System response:</p>

<samp>Error: File not found.</samp>
Expected Output:

System response:

Error: File not found.

Example 3: Command-Line Output

<p>Terminal output:</p>

<samp>Compilation successful.</samp>
Expected Output:

Terminal output:

Compilation successful.

7. The Variable Element (<var>)

The <var> element represents a variable or placeholder in a mathematical expression or programming context.

Browsers normally display its content in italic text.

Example 1: Mathematical Variable

<p>
    The value of <var>x</var> is 10.
</p>
Expected Output:

The value of x is 10.

Example 2: Mathematical Expression

<p>
    Area = <var>l</var> × <var>w</var>
</p>
Expected Output:

Area = l × w

Example 3: Programming Variable

<p>
    The variable <var>count</var>
    stores the number of items.
</p>
Expected Output:

The variable count stores the number of items.

8. Difference Between pre, code, kbd, samp and var

Element Purpose Example
<pre> Preserves whitespace and line breaks. Formatted text block
<code> Identifies computer code. printf()
<kbd> Represents user input. Ctrl + S
<samp> Represents program output. Hello!
<var> Represents a variable or placeholder. total

9. Common Mistakes

  1. Using pre for ordinary paragraphs: Use p for normal paragraphs and pre when whitespace and line breaks need to be preserved.
  2. Confusing code and pre: Code identifies computer code; pre preserves formatting. They are often used together.
  3. Forgetting HTML escaping: When displaying HTML source code, write characters such as less-than and greater-than using entities like &lt; and &gt;.
  4. Using kbd for program output: Use kbd for user input and samp for sample output.
  5. Expecting automatic syntax highlighting: The code element does not provide language-specific syntax highlighting by itself.
When writing HTML code examples inside a pre/code block, escape HTML tags so the browser displays them as text instead of interpreting them as actual HTML elements.

12. Interview Questions and Answers

Q1. What is the purpose of the pre element?

It represents preformatted text and preserves whitespace and line breaks.

Q2. What is the purpose of the code element?

It identifies a fragment of computer code.

Q3. What is the difference between pre and code?

Pre preserves formatting, whereas code identifies content as computer code.

Q4. Why are pre and code often used together?

Pre preserves the formatting of a code block, while code identifies the content as source code.

Q5. What is the purpose of the kbd element?

It represents keyboard or other user input.

Q6. What is the purpose of the samp element?

It represents sample output from a computer program or computing system.

Q7. What is the purpose of the var element?

It represents a variable or placeholder.

Q8. Does the code element automatically provide syntax highlighting?

No. Syntax highlighting requires additional styling or a suitable syntax-highlighting tool.

Q9. How do you display HTML tags as text inside a code block?

Use HTML character references such as &lt; and &gt; to display angle brackets.

Q10. Which element should be used to display a keyboard shortcut?

The kbd element should be used.

13. Multiple Choice Questions (MCQs)

  1. Which element preserves whitespace and line breaks?
    • A. <p>
    • B. <pre>
    • C. <strong>
    • D. <em>
    Answer: B. <pre>
  2. Which element identifies computer code?
    • A. <code>
    • B. <kbd>
    • C. <samp>
    • D. <var>
    Answer: A. <code>
  3. Which element represents keyboard input?
    • A. <samp>
    • B. <kbd>
    • C. <var>
    • D. <pre>
    Answer: B. <kbd>
  4. Which element represents sample program output?
    • A. <code>
    • B. <kbd>
    • C. <samp>
    • D. <var>
    Answer: C. <samp>
  5. Which element represents a programming variable?
    • A. <var>
    • B. <pre>
    • C. <mark>
    • D. <small>
    Answer: A. <var>
  6. Which combination is commonly used for a formatted source-code block?
    • A. p and strong
    • B. pre and code
    • C. h1 and h2
    • D. sub and sup
    Answer: B. pre and code
  7. Which character reference displays a less-than sign?
    • A. &gt;
    • B. &amp;
    • C. &lt;
    • D. &quot;
    Answer: C. &lt;
  8. Does code automatically provide syntax highlighting?
    • A. Yes
    • B. No
    • C. Only in Chrome
    • D. Only in Firefox
    Answer: B. No
  9. Which element is suitable for displaying Ctrl + S?
    • A. <kbd>
    • B. <samp>
    • C. <var>
    • D. <pre>
    Answer: A. <kbd>
  10. Which element is commonly displayed in a monospace font by default?
    • A. code
    • B. var
    • C. Both pre and code
    • D. Neither
    Answer: C. Both pre and code

14. Lesson Summary

  • <pre> preserves whitespace and line breaks.
  • <code> represents computer code.
  • <kbd> represents user input.
  • <samp> represents sample program output.
  • <var> represents a variable or placeholder.
  • Pre and code are commonly combined to display source-code blocks.
  • HTML character references are used to display HTML tags as text.
