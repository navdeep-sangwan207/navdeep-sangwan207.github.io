Chapter 8: HTML Forms and Input Elements

Lesson 8: Textarea and Button Elements

1. Introduction

HTML provides the <textarea> and <button> elements to create interactive form controls.

A textarea allows users to enter multiple lines of text, whereas a button performs an action such as submitting a form, resetting form fields, or triggering JavaScript.

Common Applications

  • Feedback and contact forms.
  • Comments and reviews.
  • Address and description fields.
  • Submit and reset buttons.
  • Interactive controls using JavaScript.

2. The Textarea Element

The <textarea> element creates a multi-line text input field.

Syntax

<label for="message">Enter Your Message:</label>

<textarea id="message"
          name="message"
          rows="5"
          cols="40"></textarea>

Output

Unlike a normal text input, a textarea supports multiple lines and can contain paragraphs of text.

3. Important Textarea Attributes

Attribute Purpose
name Identifies the field during form submission.
id Identifies the element and connects it to a label.
rows Specifies the visible number of text lines.
cols Specifies the approximate visible character width.
placeholder Displays a temporary hint when the field is empty.
required Requires the user to enter a value.
maxlength Limits the maximum number of characters.
minlength Specifies the minimum number of characters.
readonly Prevents editing while allowing the field to be submitted.
disabled Disables the field and excludes it from normal form submission.
wrap Controls how text wrapping is handled in submitted data.
autofocus Requests focus when the page loads.

4. Rows and Columns

The rows and cols attributes specify the textarea's initial visible dimensions.

Example

<textarea name="description"
          rows="6"
          cols="50"></textarea>
  • rows="6": Displays approximately six lines.
  • cols="50": Specifies an approximate width of fifty characters.
CSS properties such as width, height, and resize can be used to control the appearance and resizing behavior.

CSS Example

textarea {
    width: 100%;
    min-height: 120px;
    resize: vertical;
}

5. Placeholder, Required and Character Limits

These attributes help guide users and control the input.

Example

<label for="feedback">Your Feedback:</label>

<textarea id="feedback"
          name="feedback"
          rows="5"
          placeholder="Enter your feedback..."
          minlength="10"
          maxlength="200"
          required></textarea>

Minimum: 10 characters | Maximum: 200 characters

The placeholder is only a hint. It is not a replacement for a properly associated label.

6. Default Text Inside Textarea

Unlike the input element, the initial value of a textarea is written between its opening and closing tags.

Example

<textarea name="message" rows="4">Welcome to NS Learning Hub.
Learn HTML, CSS and JavaScript.</textarea>

The text between the tags appears as the initial content. The value attribute is not used to set a textarea's initial value.

7. The Button Element

The <button> element creates a clickable button. It can be used inside or outside a form.

Syntax

<button type="button">Click Me</button>

Output

A button can contain text and other permitted phrasing content, including icons and images.

8. Types of HTML Buttons

The type attribute specifies what a button does when activated.

1. Submit Button

A submit button submits its associated form. 

<button type="submit">Submit Form</button>

2. Reset Button

A reset button restores the form controls to their initial values. 

<button type="reset">Reset Form</button>

3. Normal Button

A normal button does not submit or reset a form automatically. It is commonly used with JavaScript. 

<button type="button">Click Me</button>
Always specify the button type explicitly inside forms. A button associated with a form can act as a submit button by default if its type is omitted.

9. Important Button Attributes

Attribute Purpose
type Specifies submit, reset, or button behavior.
name Provides a name for the button's submitted value.
value Specifies the button's submitted value.
disabled Disables the button.
autofocus Requests focus when the page loads.
form Associates the button with a form by its ID.
formaction Overrides the form's action for this submit button.
formmethod Overrides the form's submission method.
formnovalidate Skips constraint validation when submitting through this button.

10. Difference Between Button and Input Button

HTML provides both the <button> element and input elements with button-related types.

Button Element

<button type="submit">
    Submit Registration
</button>

Input Submit

<input type="submit" value="Submit Registration">

Input Reset

<input type="reset" value="Reset Form">
Button Input Button
Can contain text and other phrasing content. Uses the value attribute for its displayed label.
Supports flexible content. Is a void element and cannot contain child elements.
Uses the type attribute to define behavior. Uses types such as submit, reset and button.

11. Complete Practical Example: Feedback Form

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Feedback Form</title>
</head>
<body>

    <h2>Student Feedback Form</h2>

    <form action="#" method="post">

        <label for="name">Student Name:</label>
        <input type="text" id="name"
               name="student_name" required>

        <br><br>

        <label for="email">Email Address:</label>
        <input type="email" id="email"
               name="email" required>

        <br><br>

        <label for="feedback">Your Feedback:</label>

        <textarea id="feedback"
                  name="feedback"
                  rows="5"
                  cols="40"
                  placeholder="Enter your feedback..."
                  required></textarea>

        <br><br>

        <button type="submit">Submit Feedback</button>

        <button type="reset">Clear Form</button>

    </form>

</body>
</html>
Note: The example is a front-end demonstration. The form does not store feedback because no server-side processing endpoint is configured. A real application needs a backend to receive and process the submitted information.

Enter your name and feedback. Try submitting the form, then use the reset button to restore its initial state.

13. Common Mistakes

  1. Forgetting the closing </textarea> tag.
  2. Using the value attribute to set a textarea's initial text.
  3. Using placeholder instead of a proper label.
  4. Forgetting the name attribute when form submission is required.
  5. Using a reset button unintentionally.
  6. Omitting the button type inside a form.
  7. Assuming that a submit button automatically saves data to a database.
  8. Using disabled when readonly behavior is actually required.

15. Interview Questions and Answers

Q1. What is the textarea element?

It creates a multi-line text input field in an HTML document.

Q2. What is the difference between input and textarea?

Input generally creates a single-line control, whereas textarea supports multiple lines.

Q3. What is the purpose of the rows attribute?

It specifies the approximate number of visible text lines.

Q4. What is the purpose of the cols attribute?

It specifies the approximate visible character width of a textarea.

Q5. How is default text added to a textarea?

By placing the initial text between the opening and closing textarea tags.

Q6. What are the three common button types?

Submit, reset and button.

Q7. What is the purpose of a submit button?

It submits the associated form.

Q8. What is the purpose of a reset button?

It restores form controls to their initial values.

Q9. What is the difference between button and input type="button"?

The button element can contain child content, while an input button is a void element.

Q10. Why should button types be specified explicitly?

To avoid accidental form submission when a button is intended for another action.

16. Multiple Choice Questions (MCQs)

1. Which element creates a multi-line text field?

A. <input>   B. <textarea>   C. <text>   D. <message>

Correct Answer: B. <textarea>

2. Which attribute specifies visible lines in a textarea?

A. cols   B. size   C. rows   D. height

Correct Answer: C. rows

3. Which attribute specifies the approximate character width?

A. cols   B. rows   C. maxlength   D. width

Correct Answer: A. cols

4. Where is the initial textarea value written?

A. In value attribute   B. Between textarea tags   C. In placeholder   D. In name

Correct Answer: B. Between textarea tags

5. Which button type submits a form?

A. reset   B. button   C. submit   D. click

Correct Answer: C. submit

6. Which button type restores initial form values?

A. reset   B. submit   C. button   D. clear

Correct Answer: A. reset

7. Which button type does not submit a form automatically?

A. submit   B. button   C. reset   D. form

Correct Answer: B. button

8. Which attribute restricts the maximum textarea characters?

A. size   B. maxlength   C. rows   D. cols

Correct Answer: B. maxlength

9. Which attribute prevents editing but permits normal form submission?

A. disabled   B. readonly   C. hidden   D. locked

Correct Answer: B. readonly

10. Which element is a void element?

A. button   B. textarea   C. input   D. form

Correct Answer: C. input

17. Lesson Summary

  • <textarea> creates a multi-line text input.
  • rows and cols define its initial visible dimensions.
  • maxlength and minlength control text length.
  • placeholder provides a temporary hint.
  • Initial textarea content is placed between its tags.
  • <button> creates a clickable button.
  • type="submit" submits the associated form.
  • type="reset" restores initial form values.
  • type="button" creates a button for custom actions.
  • JavaScript can handle button clicks and form interactions.
