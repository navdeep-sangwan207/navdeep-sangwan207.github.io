Number, Range and Date Inputs

1. Introduction

HTML5 provides specialized input types for collecting numeric values, selecting values from a range and entering date or time information.

These input types include:

  • number: Accepts numeric values.
  • range: Selects a value from a specified range.
  • date: Selects a calendar date.
  • time: Selects a time of day.
  • month: Selects a month and year.
  • week: Selects a week of a year.
<input type="number">
<input type="range">
<input type="date">
<input type="time">
<input type="month">
<input type="week">
These input types provide suitable browser controls for different kinds of data. Their appearance may vary between browsers and devices.

2. Number Input

The type="number" input is used to collect numeric values such as age, quantity, marks and product prices.

Syntax

<input type="number" name="quantity">

Example

<label for="age">Enter Age:</label>

<input type="number"
       id="age"
       name="age"
       min="1"
       max="100"
       required>

Important Attributes

  • min: Specifies the minimum permitted value.
  • max: Specifies the maximum permitted value.
  • step: Specifies the permitted increment.
  • value: Specifies the initial value.
  • required: Makes the field mandatory.

Number Input with Step

<label for="quantity">Quantity:</label>

<input type="number"
       id="quantity"
       name="quantity"
       min="0"
       max="100"
       step="5"
       value="10">

In this example, the browser's number control uses increments of five. The initial value is ten.

Number inputs are intended for numerical quantities. They are generally not suitable for telephone numbers, postal codes or other identifiers where leading zeros and formatting matter.

3. Range Input

The type="range" input allows users to select a value by moving a slider between a minimum and maximum value.

Syntax

<input type="range">

Example

<label for="volume">Volume:</label>

<input type="range"
       id="volume"
       name="volume"
       min="0"
       max="100"
       value="50">

Important Attributes

  • min: Minimum slider value.
  • max: Maximum slider value.
  • step: Increment between selectable values.
  • value: Initial slider position.

Range Input with Step

<input type="range"
       name="brightness"
       min="0"
       max="100"
       step="10"
       value="50">

The slider moves in increments of ten, from zero to one hundred.

A range input is useful when an approximate value is sufficient. If users must enter an exact number, consider using a number input.

4. Date Input

The type="date" input allows users to select a calendar date.

Syntax

<input type="date" name="dob">

Example

<label for="dob">Date of Birth:</label>

<input type="date"
       id="dob"
       name="dob"
       required>

Date Input with Minimum and Maximum

<label for="appointment">Appointment Date:</label>

<input type="date"
       id="appointment"
       name="appointment"
       min="2026-01-01"
       max="2026-12-31">

The min and max attributes restrict the selectable date range.

The date value submitted by a date input uses the YYYY-MM-DD format, regardless of how the date may be displayed in the browser's interface.

5. Time Input

The type="time" input allows users to select a time of day.

Syntax

<input type="time" name="appointment_time">

Example

<label for="meeting">Meeting Time:</label>

<input type="time"
       id="meeting"
       name="meeting"
       required>

Time Input with Restrictions

<label for="opening">Opening Time:</label>

<input type="time"
       id="opening"
       name="opening"
       min="09:00"
       max="18:00"
       step="900">

The example restricts the time to the interval from 09:00 to 18:00. A step of 900 seconds represents 15-minute increments.

A time input represents a time of day, not a complete date and time. Use a suitable date-time control or separate date and time fields when both are required.

6. Month Input

The type="month" input allows users to select a month and year.

Syntax

<input type="month" name="billing_month">

Example

<label for="billing">Billing Month:</label>

<input type="month"
       id="billing"
       name="billing"
       required>

Month Input with Restrictions

<input type="month"
       name="semester"
       min="2026-01"
       max="2026-12">

Month values use the format YYYY-MM.

A month input represents a month and year, not a specific day.

7. Week Input

The type="week" input allows users to select a particular week of a year.

Syntax

<input type="week" name="study_week">

Example

<label for="week">Select Study Week:</label>

<input type="week"
       id="week"
       name="week">

Week Input with Restrictions

<input type="week"
       name="training_week"
       min="2026-W01"
       max="2026-W52">

Week values use the ISO week format: YYYY-Www, where ww represents the week number.

ISO week numbering is used. Some calendar years contain 52 weeks, while others contain 53 weeks.

8. Important Attributes: min, max, step and value

8.1 min

Defines the minimum allowed value.

<input type="number" min="1">

8.2 max

Defines the maximum allowed value.

<input type="number" max="100">

8.3 step

Defines the permitted increment between values.

<input type="number"
       min="0"
       max="50"
       step="5">

8.4 value

Sets the initial value of an input.

<input type="number" value="10">

8.5 required

Makes the input mandatory before form submission.

<input type="date" required>

8.6 readonly and disabled

These common input attributes also apply to these input types. 

<input type="number" value="50" readonly>

<input type="date" disabled>
  • readonly: The value cannot normally be edited, but the control remains focusable and is submitted if it has a name.
  • disabled: The control is disabled and is not submitted with the form.

9. Comparison of Number, Range and Date/Time Inputs

  • number: Numeric values such as age or quantity.
  • range: Slider-based selection of a numeric value.
  • date: Calendar date.
  • time: Time of day.
  • month: Month and year.
  • week: Week of an ISO week-numbering year.

Example Collection

<form>

    <input type="number" name="age">

    <input type="range"
           name="volume"
           min="0"
           max="100">

    <input type="date" name="dob">

    <input type="time" name="meeting">

    <input type="month" name="billing">

    <input type="week" name="week">

</form>

10. Complete Example: Student Information Form

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Information Form</title>
</head>
<body>

    <h2>Student Information Form</h2>

    <form action="/student" method="post">

        <label for="age">Age:</label>
        <input type="number"
               id="age"
               name="age"
               min="16"
               max="60"
               required>

        <br><br>

        <label for="marks">Marks:</label>
        <input type="number"
               id="marks"
               name="marks"
               min="0"
               max="100"
               step="0.5">

        <br><br>

        <label for="interest">Interest Level:</label>
        <input type="range"
               id="interest"
               name="interest"
               min="0"
               max="100"
               value="50">

        <br><br>

        <label for="dob">Date of Birth:</label>
        <input type="date"
               id="dob"
               name="dob">

        <br><br>

        <label for="class-time">Class Time:</label>
        <input type="time"
               id="class-time"
               name="class_time">

        <br><br>

        <label for="semester">Semester Month:</label>
        <input type="month"
               id="semester"
               name="semester">

        <br><br>

        <label for="study-week">Study Week:</label>
        <input type="week"
               id="study-week"
               name="study_week">

        <br><br>

        <button type="submit">Submit</button>

    </form>

</body>
</html>
The /student endpoint is illustrative. A server-side application is needed to process the submitted information.

12. Common Mistakes

  • Using number input for phone numbers or postal codes.
  • Forgetting min and max restrictions where they are needed.
  • Using step without understanding its effect on valid values.
  • Confusing date input with time input.
  • Assuming month input includes a specific day.
  • Assuming week input represents a calendar month or ordinary seven-day period starting on any chosen day.
  • Assuming every browser displays these controls identically.
  • Depending only on browser validation instead of validating data on the server.

14. Interview Questions and Answers

Q1. Which input type is used to collect numeric values?

<input type="number">.

Q2. What is the purpose of range input?

It allows users to select a numeric value from a range using a slider control.

Q3. Which input type is used to select a calendar date?

<input type="date">.

Q4. Which input type is used to select a time?

<input type="time">.

Q5. What is the purpose of the min attribute?

It defines the minimum permitted value.

Q6. What is the purpose of the max attribute?

It defines the maximum permitted value.

Q7. What does the step attribute do?

It specifies the permitted interval between values.

Q8. Which input type is used to select a month and year?

<input type="month">.

Q9. Which input type is used to select a week of the year?

<input type="week">.

Q10. What is the difference between number and range input?

Number input is designed for entering numeric values, while range input provides a slider for selecting a value within a range.
