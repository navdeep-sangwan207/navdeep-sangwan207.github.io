Chapter 8: HTML Forms and Input Elements

Lesson 9: Label, Fieldset and Legend

1. Introduction

HTML provides three important elements for organizing and improving the accessibility of forms:

  • <label> identifies a form control.
  • <fieldset> groups related form controls.
  • <legend> provides a caption for a fieldset.

Why Are These Elements Important?

  • Improve form organization and readability.
  • Help users understand the purpose of form controls.
  • Support screen readers and assistive technologies.
  • Make radio buttons and checkboxes easier to understand.
  • Improve the usability of forms on different devices.

2. The Label Element

The <label> element defines a caption for a form control such as input, textarea, or select.

Syntax

<label for="username">Username:</label>
<input type="text" id="username" name="username">

The for attribute of the label must match the id attribute of the associated form control.

Output

Clicking the label focuses its associated input control. For checkboxes and radio buttons, clicking the label can also toggle the control.

3. Two Methods of Associating Labels

Method 1: Explicit Association

In this method, the label uses the for attribute, which matches the control's id. 

<label for="email">Email Address:</label>
<input type="email" id="email" name="email">

Method 2: Implicit Association

In this method, the form control is placed inside the label element. 

<label>
    Email Address:
    <input type="email" name="email">
</label>

Output

Both methods are valid. Explicit association is commonly used because the label and control can be positioned separately in the page layout.

4. Labeling Radio Buttons

Labels make radio buttons easier to select. The user can click either the radio button or its associated text.

Example

<p>Select Gender:</p>

<input type="radio" id="male"
       name="gender" value="male">
<label for="male">Male</label>

<input type="radio" id="female"
       name="gender" value="female">
<label for="female">Female</label>

Output

Select Gender:

5. Labeling Checkboxes

Labels can also be associated with checkboxes so that users can select the checkbox by clicking its text.

Example

<input type="checkbox" id="terms" name="terms">
<label for="terms">I accept the terms and conditions</label>

Output

6. The Fieldset Element

The <fieldset> element groups related form controls together.

It is particularly useful when a form contains multiple sections, such as personal information, contact details, educational information, and technical skills.

Syntax

<fieldset>

    <label for="name">Full Name:</label>
    <input type="text" id="name" name="name">

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

</fieldset>

Output

7. The Legend Element

The <legend> element provides a caption or title for a fieldset.

Syntax

<fieldset>

    <legend>Personal Information</legend>

    <label for="student">Student Name:</label>
    <input type="text" id="student" name="student">

</fieldset>

Output

Personal Information
Remember:
  • Fieldset creates the group.
  • Legend provides the group's caption.
  • Legend should be the first child of its fieldset.

8. Grouping Radio Buttons Using Fieldset and Legend

Radio buttons belonging to the same question should be grouped together using a common name. Fieldset and legend provide the group with a meaningful accessible label.

Example

<fieldset>

    <legend>Select Your Qualification</legend>

    <input type="radio" id="qualification1"
           name="qualification" value="diploma">
    <label for="qualification1">Diploma</label>

    <input type="radio" id="qualification2"
           name="qualification" value="btech">
    <label for="qualification2">B.Tech</label>

    <input type="radio" id="qualification3"
           name="qualification" value="mtech">
    <label for="qualification3">M.Tech</label>

</fieldset>

Output

Select Your Qualification

9. Important Fieldset Attributes

Attribute Purpose
disabled Disables descendant form controls, with the exception of controls inside the fieldset's first legend.
form Associates the fieldset with a form by its ID.
name Specifies the fieldset's name.

Example: Disabled Fieldset

<fieldset disabled>

    <legend>Additional Information</legend>

    <label for="department">Department:</label>
    <input type="text" id="department" name="department">

    <label for="location">Location:</label>
    <input type="text" id="location" name="location">

</fieldset>

In this example, the form controls inside the fieldset are disabled. They cannot normally be edited or submitted.

10. Complete Practical Example: Student Registration Form

This example combines labels, fieldsets, legends, input controls, radio buttons, checkboxes, and a textarea.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Student Registration</title>
</head>
<body>

    <h2>Student Registration Form</h2>

    <form action="#" method="post">

        <fieldset>
            <legend>Personal Information</legend>

            <label for="name">Full Name:</label>
            <input type="text" id="name"
                   name="name" required>

            <br><br>

            <label for="email">Email Address:</label>
            <input type="email" id="email"
                   name="email" required>

            <br><br>

            <label for="phone">Phone Number:</label>
            <input type="tel" id="phone"
                   name="phone">
        </fieldset>

        <br>

        <fieldset>
            <legend>Educational Qualification</legend>

            <input type="radio" id="diploma"
                   name="qualification" value="Diploma">
            <label for="diploma">Diploma</label>

            <br>

            <input type="radio" id="btech"
                   name="qualification" value="B.Tech">
            <label for="btech">B.Tech</label>

            <br>

            <input type="radio" id="mtech"
                   name="qualification" value="M.Tech">
            <label for="mtech">M.Tech</label>
        </fieldset>

        <br>

        <fieldset>
            <legend>Technical Skills</legend>

            <input type="checkbox" id="c"
                   name="skills" value="C">
            <label for="c">C Programming</label>

            <br>

            <input type="checkbox" id="cpp"
                   name="skills" value="C++">
            <label for="cpp">C++ Programming</label>

            <br>

            <input type="checkbox" id="embedded"
                   name="skills" value="Embedded Systems">
            <label for="embedded">Embedded Systems</label>

            <br>

            <input type="checkbox" id="linux"
                   name="skills" value="Linux">
            <label for="linux">Linux</label>
        </fieldset>

        <br>

        <fieldset>
            <legend>Additional Information</legend>

            <label for="address">Address:</label>

            <textarea id="address"
                      name="address"
                      rows="4"
                      cols="40"></textarea>
        </fieldset>

        <br>

        <button type="submit">Register</button>
        <button type="reset">Reset Form</button>

    </form>

</body>
</html>
Note: The example demonstrates front-end form structure. It does not store registration data. A backend is required to process and save submissions.

12. Label vs Fieldset vs Legend

Element Purpose
label Provides a caption for an individual form control.
fieldset Groups related form controls.
legend Provides a caption for a fieldset.

13. Accessibility Best Practices

  1. Provide a meaningful label for every form control that needs one.
  2. Associate labels using matching for and id values, or by nesting the control inside the label.
  3. Use fieldset and legend to group related radio buttons and checkboxes.
  4. Use clear and descriptive legend text.
  5. Do not use placeholder text as the only label.
  6. Do not use fieldset only for visual styling; use it for meaningful groups of controls.
  7. Ensure form controls can be operated using a keyboard.
  8. Use appropriate instructions and validation messages.
A properly labelled control exposes its accessible name to assistive technology. Fieldset and legend communicate the context of a group of controls.

14. Common Mistakes

  1. Using a label's for attribute that does not match the control ID.
  2. Using duplicate IDs for multiple controls.
  3. Forgetting the legend inside a fieldset.
  4. Using fieldset without grouping related controls.
  5. Using placeholder instead of a visible label.
  6. Using the same radio button name for unrelated questions.
  7. Assuming fieldset automatically validates its controls.
  8. Assuming a disabled fieldset submits its disabled controls.

16. Interview Questions and Answers

Q1. What is the purpose of the label element?

It provides a caption for a form control and improves accessibility.

Q2. What is the purpose of the for attribute?

It associates a label with a form control whose ID matches its value.

Q3. What are explicit and implicit labels?

An explicit label uses matching for and id attributes; an implicit label contains its control inside the label element.

Q4. What is the purpose of fieldset?

It groups related form controls together.

Q5. What is the purpose of legend?

It provides a caption for a fieldset.

Q6. Can a fieldset contain multiple input elements?

Yes. It can contain multiple related form controls and other appropriate content.

Q7. Why are fieldset and legend useful for radio buttons?

They communicate the question or context shared by the radio button group.

Q8. Can a label be associated with a checkbox?

Yes. Clicking its associated label can toggle the checkbox.

Q9. What does the disabled attribute on fieldset do?

It disables descendant form controls, except controls inside the fieldset's first legend.

Q10. Why should every form control have a meaningful label?

It helps users understand the control and provides an accessible name for assistive technologies.

17. Multiple Choice Questions (MCQs)

1. Which element provides a caption for a form control?

A. <legend>   B. <label>   C. <fieldset>   D. <caption>

Correct Answer: B. <label>

2. Which attribute associates a label with an element?

A. id   B. name   C. for   D. value

Correct Answer: C. for

3. Which element groups related form controls?

A. <group>   B. <fieldset>   C. <legend>   D. <section>

Correct Answer: B. <fieldset>

4. Which element provides a caption for fieldset?

A. <label>   B. <title>   C. <legend>   D. <caption>

Correct Answer: C. <legend>

5. Which two attributes are matched for explicit label association?

A. name and value   B. for and id   C. class and name   D. type and value

Correct Answer: B. for and id

6. Where should legend normally appear inside fieldset?

A. Last child   B. First child   C. Outside fieldset   D. Inside a label

Correct Answer: B. First child

7. Which element improves the accessibility of a related radio button group?

A. fieldset and legend   B. div and span   C. table and tr   D. pre and code

Correct Answer: A. fieldset and legend

8. Which attribute disables descendant controls of a fieldset?

A. readonly   B. hidden   C. disabled   D. required

Correct Answer: C. disabled

9. Can one label be associated with multiple form controls using one for attribute?

A. Yes   B. No   C. Only radio buttons   D. Only checkboxes

Correct Answer: B. No. A label's for attribute identifies one labelable control.

10. What is a major benefit of using labels?

A. Database storage   B. Server-side processing   C. Accessibility and usability   D. Automatic encryption

Correct Answer: C. Accessibility and usability

18. Lesson Summary

  • <label> provides a caption for a form control.
  • Explicit labels use matching for and id attributes.
  • Implicit labels contain their controls inside the label element.
  • <fieldset> groups related form controls.
  • <legend> provides the fieldset caption.
  • Fieldset and legend improve the accessibility of radio and checkbox groups.
  • The disabled attribute on fieldset disables descendant controls, subject to the first-legend exception.
  • Good form structure improves usability and accessibility.
