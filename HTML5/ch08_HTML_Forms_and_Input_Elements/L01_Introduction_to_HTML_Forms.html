1. Introduction

An HTML form is a section of a web page that allows users to enter information and submit it for processing.

Forms are an essential part of interactive websites because they provide a way for users to communicate information to web applications.

Examples of information collected through forms include:

  • Name and personal details
  • Email address and telephone number
  • Username and password
  • Search queries
  • Feedback and comments
  • Registration and application details
  • Booking and payment-related information
Definition: An HTML form is created using the <form> element and contains form controls that allow users to provide data.

2. Why Are HTML Forms Used?

HTML forms are used to collect user input and send it to a web application.

Common Applications

  • Login forms: Collect usernames and passwords.
  • Registration forms: Collect new user information.
  • Contact forms: Allow visitors to send messages.
  • Search forms: Accept keywords for searching information.
  • Feedback forms: Collect opinions and suggestions.
  • Survey forms: Collect responses to questions.
  • Application forms: Collect educational or employment details.

3. The HTML Form Element

The <form> element is the main container used to create an HTML form.

Basic Syntax

<form>
    Form controls go here
</form>

The opening <form> tag starts the form, while the closing </form> tag marks its end.

Form controls such as input fields, checkboxes, radio buttons, dropdown lists and buttons are generally placed inside it.

Example

<form>
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <button type="submit">Submit</button>
</form>

4. Common HTML Form Elements

HTML provides several elements that can be used to create different types of form controls.

4.1 Input Element

The <input> element creates input controls. Its type attribute determines the kind of control. 

<input type="text" name="username">
<input type="password" name="password">
<input type="email" name="email">

4.2 Label Element

The <label> element provides a descriptive name for a form control. 

<label for="email">Email Address:</label>
<input type="email" id="email" name="email">

4.3 Textarea Element

The <textarea> element creates a multiline text input field. 

<textarea name="message" rows="4" cols="30"></textarea>

4.4 Select Element

The <select> element creates a dropdown list. Individual choices are defined using <option>. 

<select name="course">
    <option value="ece">Electronics</option>
    <option value="cse">Computer Science</option>
    <option value="me">Mechanical</option>
</select>

4.5 Button Element

The <button> element creates a clickable button. Inside a form, its type determines its behavior. 

<button type="submit">Submit</button>
<button type="reset">Reset</button>
<button type="button">Click Me</button>
Important: A button inside a form may act as a submit button by default. Specify its type explicitly to avoid unexpected form submission.

5. Basic Structure of an HTML Form

A typical HTML form contains the following parts:

  1. Form container
  2. Labels describing the fields
  3. Input controls for collecting data
  4. Optional selection controls
  5. Submit button

Example: Basic Registration Form

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Registration Form</title>
</head>
<body>

    <h2>Student Registration</h2>

    <form action="/register" method="post">

        <label for="name">Full Name:</label>
        <input type="text" id="name" name="name" required>

        <br><br>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>

        <br><br>

        <label for="phone">Phone Number:</label>
        <input type="tel" id="phone" name="phone">

        <br><br>

        <label for="course">Select Course:</label>

        <select id="course" name="course">
            <option value="ece">Electronics</option>
            <option value="cse">Computer Science</option>
        </select>

        <br><br>

        <button type="submit">Register</button>

    </form>

</body>
</html>
Note: The example uses action="/register" as a sample server endpoint. A real registration system requires a backend application to receive and process the submitted data.

6. Understanding Form Controls

Different form controls are used for different types of information.

  • Text field: Accepts ordinary text.
  • Password field: Masks entered characters visually.
  • Email field: Accepts email address input.
  • Radio button: Allows one selection from a group.
  • Checkbox: Allows independent selections.
  • Dropdown: Allows selection from a list.
  • Textarea: Accepts longer multiline text.
  • Submit button: Initiates form submission.
Form controls collect data in the browser. The form submission process sends successful controls to the configured destination when the user submits the form.

7. How Does an HTML Form Work?

  1. The browser displays the HTML form.
  2. The user enters information into the form controls.
  3. The browser performs applicable built-in validation.
  4. The user activates the submit button.
  5. The browser constructs the form data from successful controls.
  6. The browser sends the data according to the form's submission settings.
  7. A server-side application can process the submitted information.
  8. The server can return a response to the browser.

8. Important Form Concepts

8.1 Name Attribute

The name attribute identifies a form control when its data is submitted. 

<input type="text" name="username">

A control generally needs a name to contribute its value to the submitted form data.

8.2 Value Attribute

The value attribute specifies an initial or predefined value for a form control. 

<input type="text" name="city" value="Chandigarh">

8.3 Required Attribute

The required attribute indicates that a value must be provided before the browser allows form submission. 

<input type="text" name="fullname" required>

8.4 Action and Method

The action attribute specifies where form data is submitted. The method attribute specifies the HTTP method used for submission. 

<form action="/submit" method="post">
    ...
</form>

These attributes will be explained in detail in the upcoming lessons.

10. Advantages of HTML Forms

  • Provide a standard way to collect user information.
  • Support many types of input controls.
  • Include built-in browser validation features.
  • Work with server-side programming technologies.
  • Support interactive web applications.
  • Can be made accessible using proper labels and semantic elements.

11. Common Mistakes

  • Forgetting the closing </form> tag.
  • Using input controls without appropriate labels.
  • Forgetting the name attribute on controls that must submit data.
  • Using duplicate or mismatched id and for values.
  • Using a submit button when a normal button is required.
  • Assuming HTML validation replaces server-side validation.
  • Assuming an HTML form can process data without a server or other application logic.

13. Interview Questions and Answers

Q1. What is an HTML form?

An HTML form is a section of a web page used to collect user input through controls such as text fields, checkboxes and buttons.

Q2. Which HTML element is used to create a form?

The <form> element is used to create an HTML form.

Q3. What is the purpose of the input element?

The <input> element creates different types of form controls depending on its type attribute.

Q4. What is the purpose of the label element?

The <label> element provides a text description for a form control and improves usability and accessibility.

Q5. What is the purpose of the name attribute?

The name attribute identifies a form control in the submitted form data.

Q6. What is the difference between input and textarea?

An input element generally creates a single-line control, whereas textarea creates a multiline text field.

Q7. What is the purpose of a submit button?

A submit button initiates submission of the form.

Q8. What is the purpose of the required attribute?

It indicates that a control must have a value before the browser allows submission.

Q9. Can HTML forms work with backend languages?

Yes. HTML forms can submit data to server-side applications written using technologies such as PHP, Python, Java, Node.js and other backend frameworks.

Q10. Does HTML alone store submitted form data in a database?

No. HTML creates the form interface. A backend application and database integration are needed to process and store submitted data.

14. Multiple Choice Questions (MCQs)

Q1. Which element is used to create an HTML form?

  1. <input>
  2. <form>
  3. <table>
  4. <section>
Correct Answer: B — <form>

Q2. Which element is commonly used to collect single-line text?

  1. <textarea>
  2. <input type="text">
  3. <select>
  4. <button>
Correct Answer: B — <input type="text">

Q3. Which attribute identifies a control in submitted form data?

  1. class
  2. style
  3. name
  4. title
Correct Answer: C — name

Q4. Which element creates a multiline text field?

  1. <input>
  2. <textarea>
  3. <label>
  4. <option>
Correct Answer: B — <textarea>

Q5. Which element provides a description for a form control?

  1. <label>
  2. <div>
  3. <span>
  4. <footer>
Correct Answer: A — <label>

Q6. Which button type initiates form submission?

  1. reset
  2. button
  3. submit
  4. text
Correct Answer: C — submit

Q7. Which attribute specifies the destination for form submission?

  1. href
  2. action
  3. src
  4. alt
Correct Answer: B — action

Q8. Which attribute makes a form control mandatory?

  1. checked
  2. selected
  3. required
  4. disabled
Correct Answer: C — required

Q9. Which element creates a dropdown list?

  1. <select>
  2. <textarea>
  3. <form>
  4. <label>
Correct Answer: A — <select>

Q10. Which technology is generally responsible for server-side form processing?

  1. HTML only
  2. CSS only
  3. Backend programming
  4. Image editing software
Correct Answer: C — Backend programming

15. Lesson Summary

  • HTML forms collect information from users.
  • The <form> element acts as the form container.
  • Input elements provide different types of controls.
  • Labels describe form controls.
  • Textarea supports multiline text input.
  • Select and option elements create dropdown lists.
  • Submit buttons initiate form submission.
  • The browser can perform built-in form validation.
  • A backend application is required to process submitted data on the server.
