Radio Buttons and Checkboxes

Chapter 8: HTML Forms and Input Elements

HTML5 – Complete Study Course

1. Introduction

HTML forms provide radio buttons and checkboxes to allow users to select options.

These controls are useful for collecting information such as:

  • Gender or preferred title.
  • Payment method.
  • Course selection.
  • Technical skills.
  • Interests and preferences.
  • Terms and conditions acceptance.

HTML provides two commonly used selection controls:

  • Radio button: Selects one option from a group.
  • Checkbox: Allows independent selection of one or more options.
<input type="radio">

<input type="checkbox">
Radio buttons are used when options are mutually exclusive. Checkboxes are used when multiple selections are allowed.

2. Radio Buttons

A radio button is an input control that allows users to select one option from a group of related options.

Syntax

<input type="radio" name="gender" value="male">

Example

<form>

    <p>Select Gender:</p>

    <input type="radio"
           id="male"
           name="gender"
           value="male">

    <label for="male">Male</label>

    <br>

    <input type="radio"
           id="female"
           name="gender"
           value="female">

    <label for="female">Female</label>

    <br>

    <input type="radio"
           id="other"
           name="gender"
           value="other">

    <label for="other">Other</label>

</form>

How Radio Buttons Work

  • All related radio buttons should use the same name.
  • Each radio button should have a distinct value.
  • Selecting one option automatically deselects another option in the same group.
  • Only the selected radio button is submitted.
Radio buttons are grouped by their name and form ownership. Use the same name for options that belong to one selection group.

3. Checkbox

A checkbox is an input control that allows users to select or deselect an individual option.

Syntax

<input type="checkbox" name="skill" value="C">

Example

<form>

    <p>Select Programming Skills:</p>

    <input type="checkbox"
           id="c"
           name="skills"
           value="C">

    <label for="c">C</label>

    <br>

    <input type="checkbox"
           id="cpp"
           name="skills"
           value="C++">

    <label for="cpp">C++</label>

    <br>

    <input type="checkbox"
           id="python"
           name="skills"
           value="Python">

    <label for="python">Python</label>

</form>

How Checkboxes Work

  • Each checkbox can be selected independently.
  • Users can select multiple checkboxes.
  • Users can deselect a selected checkbox.
  • Only checked checkboxes are submitted.
  • Multiple checkboxes can use the same name to submit multiple values.
Unlike radio buttons, checkboxes do not automatically deselect other checkboxes when selected.

4. Important Attributes

4.1 type

Defines whether the input is a radio button or checkbox.

<input type="radio">

<input type="checkbox">

4.2 name

Identifies the form control during form submission. It also groups radio buttons. 

<input type="radio"
       name="payment"
       value="cash">

<input type="radio"
       name="payment"
       value="card">

4.3 value

Specifies the value submitted when a radio button is selected or a checkbox is checked. 

<input type="checkbox"
       name="skills"
       value="Embedded C">

4.4 checked

Selects a radio button or checkbox by default when the page loads. 

<input type="radio"
       name="course"
       value="embedded"
       checked>

For radio buttons, only one option in a group should normally be marked checked.

4.5 required

Requires a selection before the form can pass browser validation. 

<input type="radio"
       name="payment"
       value="upi"
       required>

<input type="radio"
       name="payment"
       value="card">

For radio buttons, applying required to one or more members of a group makes a selection in that group mandatory.

4.6 disabled

Disables the input control.

<input type="checkbox"
       name="offer"
       value="special"
       disabled>
Disabled controls are not submitted with the form.

5. Difference Between Radio Buttons and Checkboxes

  • Radio buttons: Select one option from a group.
  • Checkboxes: Select zero, one or multiple independent options.
  • Radio grouping: Uses the same name for related options.
  • Checkbox grouping: Can use the same name to submit multiple selected values.
  • Selection: Selecting another radio option deselects the previous one in the group; checkboxes remain independently selected.

Radio Button Example

<input type="radio" name="payment" value="cash">
<input type="radio" name="payment" value="card">
<input type="radio" name="payment" value="upi">

Checkbox Example

<input type="checkbox" name="skills" value="C">
<input type="checkbox" name="skills" value="C++">
<input type="checkbox" name="skills" value="Linux">

6. Grouping Options with Fieldset and Legend

The <fieldset> element groups related form controls, while <legend> provides a caption for that group.

Radio Button Group

<fieldset>

    <legend>Select Payment Method</legend>

    <input type="radio"
           id="cash"
           name="payment"
           value="cash">
    <label for="cash">Cash</label>

    <br>

    <input type="radio"
           id="card"
           name="payment"
           value="card">
    <label for="card">Card</label>

    <br>

    <input type="radio"
           id="upi"
           name="payment"
           value="upi">
    <label for="upi">UPI</label>

</fieldset>

Checkbox Group

<fieldset>

    <legend>Select Your Skills</legend>

    <input type="checkbox"
           id="embedded"
           name="skills"
           value="Embedded C">
    <label for="embedded">Embedded C</label>

    <br>

    <input type="checkbox"
           id="linux"
           name="skills"
           value="Linux">
    <label for="linux">Linux</label>

    <br>

    <input type="checkbox"
           id="cpp"
           name="skills"
           value="C++">
    <label for="cpp">C++</label>

</fieldset>
Fieldset and legend improve the semantic organization and accessibility of related form controls.

7. Radio Buttons with Required and Checked

Radio buttons can be configured to require a selection and provide a default choice. 

<form>

    <fieldset>

        <legend>Select Employment Type</legend>

        <input type="radio"
               id="fulltime"
               name="employment"
               value="fulltime"
               required
               checked>

        <label for="fulltime">Full Time</label>

        <br>

        <input type="radio"
               id="parttime"
               name="employment"
               value="parttime"
               required>

        <label for="parttime">Part Time</label>

    </fieldset>

    <button type="submit">Submit</button>

</form>

The Full Time option is selected initially. The user can change the selection before submitting.

8. Checkbox with Required

A required checkbox must be checked before the form can pass browser validation. 

<form>

    <input type="checkbox"
           id="terms"
           name="terms"
           value="accepted"
           required>

    <label for="terms">
        I accept the terms and conditions.
    </label>

    <br><br>

    <button type="submit">Submit</button>

</form>
A required checkbox must be checked. For a group of optional skills, applying required to each checkbox would require every one of those checkboxes to be checked. Use custom validation if at least one checkbox from a group must be selected.

11. Common Mistakes

  • Using different name values for radio buttons that should form one group.
  • Using the same value for every option when distinct values are required.
  • Assuming checkboxes automatically deselect other checkboxes.
  • Forgetting to add labels to radio buttons and checkboxes.
  • Using checked on multiple radio buttons in the same group.
  • Applying required to every checkbox when only one selection is needed.
  • Forgetting that unchecked checkboxes are not submitted.
  • Forgetting that disabled controls are not submitted.

13. Interview Questions and Answers

Q1. What is a radio button in HTML?

A radio button is a form control that allows users to select one option from a group of related options.

Q2. What is a checkbox in HTML?

A checkbox is a form control that allows users to select or deselect an individual option independently.

Q3. How are radio buttons grouped?

Related radio buttons use the same name attribute.

Q4. Can multiple checkboxes be selected?

Yes. Multiple checkboxes can be selected independently.

Q5. What is the purpose of the checked attribute?

It makes a radio button or checkbox selected by default.

Q6. What is the purpose of the value attribute?

It defines the value submitted when the control is selected.

Q7. What happens if radio buttons have different names?

They belong to different radio groups and can be selected independently.

Q8. What is the purpose of fieldset and legend?

Fieldset groups related form controls, while legend provides a caption for the group.

Q9. Are unchecked checkboxes submitted with a form?

No. Only checked checkboxes are successful controls and submitted.

Q10. What happens when a disabled checkbox is submitted?

A disabled checkbox is not submitted with the form, even if it is checked.

14. Multiple Choice Questions (MCQs)

Q1. Which input type creates a radio button?

  1. text
  2. radio
  3. checkbox
  4. button
Answer: B — radio

Q2. Which input type creates a checkbox?

  1. radio
  2. text
  3. checkbox
  4. submit
Answer: C — checkbox

Q3. How are radio buttons grouped?

  1. Using the same id
  2. Using the same name
  3. Using the same value
  4. Using the same class
Answer: B — Using the same name

Q4. How many options can normally be selected in one radio group?

  1. Only one
  2. Two
  3. All options
  4. None only
Answer: A — Only one

Q5. Which attribute selects a checkbox by default?

  1. selected
  2. active
  3. checked
  4. value
Answer: C — checked

Q6. Which element groups related form controls?

  1. section
  2. fieldset
  3. article
  4. footer
Answer: B — fieldset

Q7. Which element provides a caption for a fieldset?

  1. caption
  2. title
  3. legend
  4. label
Answer: C — legend

Q8. Which controls are submitted when a checkbox group is used?

  1. All checkboxes
  2. Only unchecked checkboxes
  3. Only checked checkboxes
  4. No checkboxes
Answer: C — Only checked checkboxes

Q9. Which attribute disables a checkbox?

  1. readonly
  2. disabled
  3. hidden
  4. checked
Answer: B — disabled

Q10. Which control is best for selecting multiple independent skills?

  1. Radio buttons
  2. Checkboxes
  3. Password input
  4. Submit button
Answer: B — Checkboxes

15. Lesson Summary

  • Radio buttons select one option from a group.
  • Checkboxes allow independent selections.
  • The name attribute groups radio buttons.
  • The value attribute defines the submitted value.
  • The checked attribute selects a control by default.
  • The required attribute enforces a selection.
  • Fieldset groups related controls.
  • Legend provides a caption for a fieldset.
  • Unchecked checkboxes are not submitted.
  • Disabled controls are not submitted.
