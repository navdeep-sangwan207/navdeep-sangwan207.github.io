Chapter 8: HTML Forms and Input Elements

Lesson 7: Select, Option and Optgroup Elements

1. Introduction

HTML provides the <select> element to create a dropdown list inside a form. Users can select one or more options from the available choices.

The <option> element defines an individual choice, while <optgroup> organizes related options into labelled groups.

Common Applications

  • Selecting a country or state.
  • Choosing an academic course.
  • Selecting a department or job role.
  • Choosing a payment method.
  • Selecting multiple technical skills.

2. The Select Element

The <select> element creates a dropdown control containing a list of options.

Syntax

<label for="course">Choose a Course:</label>

<select id="course" name="course">
    <option value="ece">Electronics Engineering</option>
    <option value="cse">Computer Science</option>
    <option value="me">Mechanical Engineering</option>
</select>

Output

By default, a standard select control allows the user to select one option at a time.

3. The Option Element

The <option> element defines an individual item inside a dropdown list or a datalist.

Syntax

<select name="city">
    <option value="chandigarh">Chandigarh</option>
    <option value="mohali">Mohali</option>
    <option value="panchkula">Panchkula</option>
</select>

Important Option Attributes

  • value: Specifies the value submitted with the form.
  • selected: Makes an option selected by default.
  • disabled: Makes an option unavailable for selection.
  • label: Provides a label for the option.

Example: Default Selected Option

<select name="city">
    <option value="chandigarh">Chandigarh</option>
    <option value="mohali" selected>Mohali</option>
    <option value="panchkula">Panchkula</option>
</select>

In this example, Mohali is selected when the page loads.

Important: If an option does not have a value attribute, its text content is used as the submitted value.

4. The Optgroup Element

The <optgroup> element groups related options inside a dropdown list. It makes long dropdown lists easier to understand and navigate.

Syntax

<select name="course">

    <optgroup label="Engineering">
        <option value="ece">Electronics Engineering</option>
        <option value="cse">Computer Science</option>
        <option value="me">Mechanical Engineering</option>
    </optgroup>

    <optgroup label="Management">
        <option value="mba">MBA</option>
        <option value="bba">BBA</option>
    </optgroup>

</select>

Output

Remember:
  • The label attribute identifies the group.
  • An optgroup is a grouping label, not a selectable option.
  • Users select individual option elements inside the group.
  • The disabled attribute can disable an entire group.

5. Important Select Attributes

Attribute Purpose
name Identifies the form field during submission.
id Identifies the element and connects it to a label.
required Requires a non-empty selection before submission.
multiple Allows multiple options to be selected.
size Specifies the number of visible options.
disabled Disables the entire dropdown control.
autofocus Requests focus when the page loads.
form Associates the select with a form by its ID.

Example: Required Dropdown

<label for="department">Select Department:</label>

<select id="department" name="department" required>
    <option value="" selected disabled>
        -- Select Department --
    </option>
    <option value="ece">ECE</option>
    <option value="cse">CSE</option>
    <option value="me">Mechanical</option>
</select>
For a required single-selection dropdown, an initial placeholder option with an empty value allows the browser to detect that the user has not made a meaningful selection.

6. Multiple Selection Using the Multiple Attribute

The multiple attribute allows users to select more than one option from a dropdown control.

Example

<label for="skills">Select Your Skills:</label>

<select id="skills" name="skills" multiple size="5">
    <option value="c">C Programming</option>
    <option value="cpp">C++ Programming</option>
    <option value="embedded">Embedded Systems</option>
    <option value="linux">Linux</option>
    <option value="rtos">RTOS</option>
</select>

Output

Tip: Use Ctrl (Windows/Linux) or Command (Mac) to select multiple individual options.

Important:
  • Without multiple, a select normally allows one selection.
  • With multiple, users can select several options.
  • The size attribute controls the visible list area.
  • Multiple selected values are submitted using the same field name.

7. Disabled Options and Groups

The disabled attribute can be applied to a select, option, or optgroup element.

Disable an Individual Option

<select name="status">
    <option value="available">Available</option>
    <option value="unavailable" disabled>
        Unavailable
    </option>
</select>

Disable an Entire Group

<select name="course">
    <optgroup label="Available Courses">
        <option value="ece">ECE</option>
        <option value="cse">CSE</option>
    </optgroup>

    <optgroup label="Currently Unavailable" disabled>
        <option value="me">Mechanical</option>
        <option value="civil">Civil</option>
    </optgroup>
</select>
Disabled controls and options cannot be selected normally. Disabled form controls are not submitted as successful controls.

8. Complete Practical Example: Student Registration Form

The following example combines select, option, optgroup, required, and multiple selection in one form.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Student Registration</title>
</head>
<body>

    <h2>Student Registration Form</h2>

    <form action="#" method="get">

        <label for="student-name">Student Name:</label>
        <input type="text" id="student-name"
               name="student_name" required>

        <br><br>

        <label for="course">Select Course:</label>

        <select id="course" name="course" required>
            <option value="" selected disabled>
                -- Select Course --
            </option>

            <optgroup label="Engineering">
                <option value="ece">ECE</option>
                <option value="cse">CSE</option>
                <option value="me">Mechanical</option>
            </optgroup>

            <optgroup label="Management">
                <option value="mba">MBA</option>
                <option value="bba">BBA</option>
            </optgroup>
        </select>

        <br><br>

        <label for="city">Select City:</label>

        <select id="city" name="city" required>
            <option value="" selected disabled>
                -- Select City --
            </option>
            <option value="chandigarh">Chandigarh</option>
            <option value="mohali">Mohali</option>
            <option value="panchkula">Panchkula</option>
        </select>

        <br><br>

        <label for="skills">Select Skills:</label>

        <select id="skills" name="skills" multiple size="4">
            <option value="c">C Programming</option>
            <option value="cpp">C++ Programming</option>
            <option value="linux">Linux</option>
            <option value="embedded">Embedded Systems</option>
        </select>

        <br><br>

        <button type="submit">Register</button>

    </form>

</body>
</html>
Note: The example uses action="#" for demonstration. It does not save student information to a database. A real registration system needs a server-side application and appropriate form-processing logic.

10. Difference Between Select, Option and Optgroup

Element Purpose
select Creates the dropdown or selection control.
option Defines an individual selectable choice.
optgroup Groups related options under a label.

11. Common Mistakes

  1. Forgetting the name attribute and expecting the selected value to be submitted.
  2. Using an incorrect or missing label association.
  3. Forgetting the empty-value placeholder in a required dropdown.
  4. Using multiple when only one selection is needed.
  5. Forgetting that option text becomes the submitted value when no value attribute is provided.
  6. Using optgroup as if it were an individually selectable option.
  7. Assuming the browser automatically saves submitted data.
  8. Forgetting that disabled controls are excluded from form submission.

13. Interview Questions and Answers

Q1. What is the purpose of the select element?

It creates a dropdown or selection control in an HTML form.

Q2. What is the purpose of the option element?

It defines an individual choice inside a select or datalist element.

Q3. What is the purpose of optgroup?

It groups related options under a common label.

Q4. What does the selected attribute do?

It specifies an option that is selected by default.

Q5. What does the multiple attribute do?

It allows the user to select multiple options.

Q6. What is the purpose of the size attribute?

It specifies how many options are visible in the selection control.

Q7. Can an optgroup be selected?

No. It groups options; users select the individual option elements inside it.

Q8. What happens if the option value attribute is omitted?

The option's text content is used as its value.

Q9. What is the difference between disabled and selected?

Disabled prevents normal selection; selected specifies the default selected option.

Q10. How are multiple selected options submitted?

They are submitted as multiple values associated with the same control name.

14. Multiple Choice Questions (MCQs)

1. Which element creates a dropdown list?

A. <input>   B. <select>   C. <option>   D. <list>

Correct Answer: B. <select>

2. Which element defines an individual dropdown choice?

A. <option>   B. <choice>   C. <item>   D. <value>

Correct Answer: A. <option>

3. Which element groups related options?

A. <group>   B. <fieldset>   C. <optgroup>   D. <optiongroup>

Correct Answer: C. <optgroup>

4. Which attribute permits multiple selections?

A. checked   B. multiple   C. selected   D. size

Correct Answer: B. multiple

5. Which attribute selects an option by default?

A. default   B. checked   C. selected   D. active

Correct Answer: C. selected

6. Which attribute specifies visible options?

A. rows   B. height   C. size   D. length

Correct Answer: C. size

7. Which attribute disables an option?

A. readonly   B. disabled   C. hidden   D. locked

Correct Answer: B. disabled

8. Which attribute is used to identify a form field during submission?

A. class   B. id   C. name   D. title

Correct Answer: C. name

9. Which attribute labels an optgroup?

A. name   B. label   C. title   D. value

Correct Answer: B. label

10. What is submitted if an option has no value attribute?

A. Nothing   B. The option text   C. Its index   D. Its ID

Correct Answer: B. The option text

15. Lesson Summary

  • <select> creates a dropdown or selection control.
  • <option> defines an individual choice.
  • <optgroup> groups related options.
  • value specifies the submitted value of an option.
  • selected defines the default selected option.
  • multiple permits more than one selection.
  • size controls the visible number of options.
  • required enforces a non-empty selection.
  • disabled prevents normal interaction with a control or option.
  • A backend is required to process and store submitted form data.
