2. HTML Fundamentals (Q1–Q10)

Q1. What is the full form of HTML?

  1. HyperText Machine Language
  2. HyperText Markup Language
  3. HighText Markup Language
  4. Hyper Transfer Markup Language
Correct Answer: B. HyperText Markup Language

HTML is the standard markup language used to structure web content.

Q2. HTML is primarily a:

  1. Programming language
  2. Markup language
  3. Database language
  4. Operating system
Correct Answer: B. Markup language

HTML describes the structure and meaning of web content.

Q3. Which organization maintains the HTML Living Standard?

  1. IEEE
  2. WHATWG
  3. ISO only
  4. ECMA only
Correct Answer: B. WHATWG

WHATWG maintains the HTML Living Standard.

Q4. Which declaration identifies an HTML document?

  1. <HTML>
  2. <DOCTYPE>
  3. <!DOCTYPE html>
  4. <DOCUMENT>
Correct Answer: C. <!DOCTYPE html>

It tells browsers to use standards mode.

Q5. Which element is the root element of an HTML document?

  1. body
  2. head
  3. html
  4. root
Correct Answer: C. html

The html element contains the head and body elements.

Q6. Which element contains metadata?

  1. body
  2. head
  3. footer
  4. main
Correct Answer: B. head

The head contains metadata, title, and resource references.

Q7. Which element defines the page title?

  1. meta
  2. header
  3. title
  4. h1
Correct Answer: C. title

The title element defines the document title.

Q8. How many heading levels are available in HTML?

  1. 3
  2. 4
  3. 5
  4. 6
Correct Answer: D. 6

HTML provides headings from h1 to h6.

Q9. Which element creates a paragraph?

  1. para
  2. p
  3. paragraph
  4. text
Correct Answer: B. p

The p element represents a paragraph.

Q10. Which element creates a line break?

  1. break
  2. lb
  3. br
  4. hr
Correct Answer: C. br

The br element creates a line break.

3. HTML Elements and Attributes (Q11–Q20)

Q11. Which attribute specifies additional information about an element?

  1. Attribute
  2. Tag
  3. Element
  4. DOCTYPE
Correct Answer: A. Attribute

Attributes provide additional information or configuration.

Q12. Which attribute should normally be unique within an HTML document?

  1. class
  2. id
  3. style
  4. title
Correct Answer: B. id

An id identifies an element and should not be duplicated in a document.

Q13. Which attribute can be shared by multiple elements?

  1. id
  2. class
  3. src
  4. href
Correct Answer: B. class

Multiple elements can share the same class name.

Q14. Which is the correct HTML comment syntax?

  1. // Comment
  2. /* Comment */
  3. <!-- Comment -->
  4. # Comment
Correct Answer: C. <!-- Comment -->

HTML comments use the less-than, exclamation, and hyphen syntax.

Q15. Which element is a void element?

  1. div
  2. p
  3. img
  4. section
Correct Answer: C. img

The img element has no end tag and cannot contain child content.

Q16. Which element represents preformatted text?

  1. code
  2. pre
  3. format
  4. text
Correct Answer: B. pre

The pre element preserves whitespace and line breaks in its text content.

Q17. Which element represents important text?

  1. b
  2. i
  3. strong
  4. small
Correct Answer: C. strong

Strong represents strong importance, seriousness, or urgency.

Q18. Which element represents emphasized text?

  1. em
  2. b
  3. mark
  4. del
Correct Answer: A. em

The em element represents stress emphasis.

Q19. Which element highlights text?

  1. small
  2. mark
  3. sub
  4. sup
Correct Answer: B. mark

The mark element represents text highlighted for reference or relevance.

Q20. Which element represents computer code?

  1. kbd
  2. samp
  3. code
  4. var
Correct Answer: C. code

The code element represents a fragment of computer code.

4. Links, Images, and Lists (Q21–Q30)

Q21. Which element creates a hyperlink?

  1. link
  2. a
  3. href
  4. url
Correct Answer: B. a

The anchor element creates hyperlinks.

Q22. Which attribute specifies the destination of a hyperlink?

  1. src
  2. target
  3. href
  4. link
Correct Answer: C. href

The href attribute specifies the URL destination.

Q23. Which attribute specifies an image resource?

  1. href
  2. src
  3. alt
  4. target
Correct Answer: B. src

The src attribute specifies the image URL.

Q24. What is the purpose of the alt attribute?

  1. Set image size
  2. Provide alternative text
  3. Open image in a new tab
  4. Change image colour
Correct Answer: B. Provide alternative text

Alt text communicates relevant image information or purpose.

Q25. Which element creates an ordered list?

  1. ul
  2. li
  3. ol
  4. dl
Correct Answer: C. ol

The ol element creates an ordered list.

Q26. Which element creates an unordered list?

  1. ul
  2. ol
  3. dl
  4. dt
Correct Answer: A. ul

The ul element creates an unordered list.

Q27. Which element defines an individual list item?

  1. item
  2. li
  3. list
  4. dt
Correct Answer: B. li

The li element represents a list item.

Q28. Which element represents a description list?

  1. ol
  2. ul
  3. dl
  4. menu
Correct Answer: C. dl

The dl element represents a description list.

Q29. Which target value commonly opens a link in a new tab or window?

  1. _self
  2. _parent
  3. _blank
  4. _top
Correct Answer: C. _blank

The _blank target requests a new browsing context.

Q30. Which element provides a caption for a figure?

  1. caption
  2. figcaption
  3. label
  4. summary
Correct Answer: B. figcaption

The figcaption element provides a caption for its figure.

5. HTML Tables and Forms (Q31–Q45)

Q31. Which element creates a table?

  1. tab
  2. table
  3. tr
  4. td
Correct Answer: B. table

The table element represents tabular data.

Q32. Which element creates a table row?

  1. td
  2. th
  3. tr
  4. row
Correct Answer: C. tr

The tr element represents a table row.

Q33. Which element defines a table header cell?

  1. td
  2. th
  3. thead
  4. header
Correct Answer: B. th

The th element represents a table header cell.

Q34. Which attribute merges a cell across multiple columns?

  1. rowspan
  2. colspan
  3. merge
  4. spanrow
Correct Answer: B. colspan

Colspan specifies the number of columns a cell spans.

Q35. Which element defines the table header section?

  1. thead
  2. th
  3. header
  4. head
Correct Answer: A. thead

The thead element groups header rows in a table.

Q36. Which element defines a form?

  1. input
  2. form
  3. fieldset
  4. label
Correct Answer: B. form

The form element groups controls used to submit data.

Q37. Which input type is used for an email address?

  1. text
  2. mail
  3. email
  4. address
Correct Answer: C. email

The email input type provides browser email-format validation.

Q38. Which input type hides the entered characters by default?

  1. text
  2. hidden
  3. password
  4. secret
Correct Answer: C. password

The password input type masks the entered characters visually.

Q39. Which input type is used for selecting one option from a group?

  1. checkbox
  2. radio
  3. select
  4. option
Correct Answer: B. radio

Radio inputs with the same name form a selection group.

Q40. Which input type allows multiple independent selections?

  1. radio
  2. checkbox
  3. submit
  4. button
Correct Answer: B. checkbox

Checkboxes allow independent selection of options.

Q41. Which element creates a drop-down selection control?

  1. select
  2. option
  3. textarea
  4. datalist
Correct Answer: A. select

The select element creates a selection control.

Q42. Which element creates a multiline text input?

  1. input
  2. textarea
  3. text
  4. multiline
Correct Answer: B. textarea

The textarea element accepts multiline text.

Q43. Which attribute makes a form field mandatory?

  1. validate
  2. mandatory
  3. required
  4. needed
Correct Answer: C. required

Required activates the corresponding constraint validation.

Q44. Which form method normally places submitted parameters in the URL?

  1. POST
  2. GET
  3. PUT
  4. PATCH
Correct Answer: B. GET

GET form data is normally encoded into the URL query string.

Q45. Which enctype is commonly required for uploading files?

  1. text/plain
  2. application/json
  3. multipart/form-data
  4. application/xml
Correct Answer: C. multipart/form-data

It is the standard form encoding used for file uploads.

6. Semantic HTML5 (Q46–Q55)

Q46. Which element represents the main content of a document?

  1. section
  2. main
  3. article
  4. aside
Correct Answer: B. main

The main element identifies the dominant content of the document body.

Q47. Which element represents introductory content?

  1. header
  2. footer
  3. nav
  4. aside
Correct Answer: A. header

The header element represents introductory or navigational content for a section or page.

Q48. Which element represents navigation links?

  1. menuitem
  2. nav
  3. links
  4. navigate
Correct Answer: B. nav

The nav element represents a major navigation section.

Q49. Which element represents a self-contained composition?

  1. article
  2. div
  3. span
  4. br
Correct Answer: A. article

Article represents independently distributable or reusable content.

Q50. Which element represents supplementary content?

  1. main
  2. aside
  3. header
  4. title
Correct Answer: B. aside

Aside represents content indirectly related to surrounding content.

Q51. Which element creates a disclosure widget?

  1. dialog
  2. details
  3. summary
  4. output
Correct Answer: B. details

The details element creates a disclosure widget, usually with a summary element.

Q52. Which element provides the visible label for a details disclosure widget?

  1. label
  2. summary
  3. caption
  4. legend
Correct Answer: B. summary

Summary provides the label that users activate to show or hide the details content.

Q53. Which element represents the footer of a section or page?

  1. bottom
  2. footer
  3. end
  4. aside
Correct Answer: B. footer

Footer contains closing or supplementary information for its nearest relevant section or page.

Q54. Which element is a generic block container?

  1. span
  2. div
  3. article
  4. nav
Correct Answer: B. div

Div is a generic container without inherent semantic meaning.

Q55. Which element is a generic inline container?

  1. div
  2. section
  3. span
  4. main
Correct Answer: C. span

Span is a generic container for phrasing content.

7. Multimedia and Graphics (Q56–Q65)

Q56. Which element embeds audio?

  1. sound
  2. audio
  3. music
  4. media
Correct Answer: B. audio

The audio element embeds audio content.

Q57. Which element embeds video?

  1. movie
  2. media
  3. video
  4. film
Correct Answer: C. video

The video element embeds video content.

Q58. Which attribute displays native playback controls?

  1. play
  2. controls
  3. controller
  4. interface
Correct Answer: B. controls

The controls attribute requests browser-provided playback controls.

Q59. Which element provides alternative media sources?

  1. source
  2. track
  3. media
  4. fallback
Correct Answer: A. source

The source element specifies alternative media resources.

Q60. Which element provides timed text tracks for media?

  1. caption
  2. subtitle
  3. track
  4. text
Correct Answer: C. track

The track element provides timed text such as captions and subtitles.

Q61. Which element provides a bitmap drawing surface?

  1. svg
  2. canvas
  3. draw
  4. graphic
Correct Answer: B. canvas

Canvas provides a bitmap drawing surface, commonly controlled using JavaScript.

Q62. Which format is vector-based?

  1. JPEG
  2. PNG
  3. SVG
  4. BMP
Correct Answer: C. SVG

SVG represents scalable vector graphics.

Q63. Which attribute makes an audio or video element start automatically when permitted?

  1. start
  2. autoplay
  3. automatic
  4. run
Correct Answer: B. autoplay

Autoplay requests automatic playback, but browser policies may block it.

Q64. Which attribute requests loading an image only when it approaches the viewport?

  1. preload
  2. defer
  3. loading="lazy"
  4. async
Correct Answer: C. loading="lazy"

It requests deferred loading of suitable off-screen images.

Q65. Which element embeds another browsing context?

  1. object
  2. iframe
  3. embed
  4. frame
Correct Answer: B. iframe

The iframe element embeds another browsing context in the current document.

8. HTML5 APIs and Browser Features (Q66–Q75)

Q66. Which browser API stores key-value data persistently?

  1. sessionStorage
  2. localStorage
  3. Geolocation
  4. History
Correct Answer: B. localStorage

localStorage persists data across browser sessions, subject to browser policies.

Q67. Which storage is associated with a particular page session?

  1. localStorage
  2. sessionStorage
  3. database
  4. cookies only
Correct Answer: B. sessionStorage

sessionStorage is associated with a particular browsing context and page session.

Q68. Which API can request the user's geographical position?

  1. Canvas API
  2. Geolocation API
  3. History API
  4. Storage API
Correct Answer: B. Geolocation API

Geolocation can request location information with user permission.

Q69. Which technology allows JavaScript tasks to run in a background worker thread?

  1. Web Workers
  2. HTML Tables
  3. CSS Grid
  4. iframes only
Correct Answer: A. Web Workers

Web Workers run JavaScript outside the main page thread.

Q70. Which API can modify the browser's session history?

  1. Canvas API
  2. History API
  3. Storage API
  4. Audio API
Correct Answer: B. History API

The History API provides methods such as pushState and replaceState.

Q71. Which protocol is commonly used for full-duplex WebSocket communication?

  1. FTP
  2. SMTP
  3. WebSocket
  4. POP3
Correct Answer: C. WebSocket

WebSocket supports persistent, bidirectional communication.

Q72. Which scheme is used for secure WebSocket connections?

  1. http
  2. ws
  3. wss
  4. ftp
Correct Answer: C. wss

wss uses WebSocket over a TLS-protected connection.

Q73. Which HTML element creates a built-in disclosure widget?

  1. details
  2. canvas
  3. output
  4. progress
Correct Answer: A. details

The details element provides expandable and collapsible content.

Q74. Which element represents the result of a calculation?

  1. result
  2. output
  3. meter
  4. progress
Correct Answer: B. output

The output element represents the result of a calculation or user action.

Q75. Which element represents task completion progress?

  1. meter
  2. progress
  3. output
  4. range
Correct Answer: B. progress

The progress element represents completion progress for a task.

9. Accessibility and SEO (Q76–Q85)

Q76. What does WCAG stand for?

  1. Web Content Accessibility Guidelines
  2. Web Coding Application Guidelines
  3. Website Content Application Guide
  4. World Computer Accessibility Group
Correct Answer: A. Web Content Accessibility Guidelines

WCAG provides guidance for accessible web content.

Q77. Which attribute identifies the language of an HTML document?

  1. charset
  2. lang
  3. language
  4. locale
Correct Answer: B. lang

The lang attribute identifies the language of content.

Q78. Which attribute provides an accessible name directly on an element?

  1. aria-label
  2. alt only
  3. placeholder
  4. title only
Correct Answer: A. aria-label

aria-label provides an accessible name when appropriate.

Q79. Which attribute associates a label with a form control?

  1. name
  2. for
  3. target
  4. rel
Correct Answer: B. for

The label's for value should match the control's id.

Q80. Which meta name is commonly used for a page description?

  1. keywords
  2. author
  3. description
  4. robots
Correct Answer: C. description

The description metadata provides a concise page summary.

Q81. Which element contains the document's character encoding declaration?

  1. charset
  2. meta
  3. encoding
  4. script
Correct Answer: B. meta

The charset attribute is used in a meta element.

Q82. Which character encoding is recommended for modern HTML documents?

  1. ASCII only
  2. UTF-8
  3. UTF-16 only
  4. Binary
Correct Answer: B. UTF-8

UTF-8 supports a broad range of characters and is the recommended encoding for HTML.

Q83. Which element is used to link an external favicon?

  1. favicon
  2. icon
  3. link
  4. img
Correct Answer: C. link

A link element with rel="icon" identifies a favicon resource.

Q84. What does a canonical link identify?

  1. The website logo
  2. The preferred URL for similar or duplicate content
  3. The page's CSS file
  4. The website's database
Correct Answer: B. The preferred URL for similar or duplicate content

A canonical link helps indicate the preferred URL to search engines.

Q85. Which tool checks HTML markup for conformance issues?

  1. W3C HTML Checker
  2. Task Manager
  3. Disk Cleanup
  4. Device Manager
Correct Answer: A. W3C HTML Checker

The HTML Checker reports markup errors and warnings.

10. Advanced and Practical HTML Questions (Q86–Q100)

Q86. Which element allows responsive image source selection?

  1. img only
  2. picture
  3. figure
  4. canvas
Correct Answer: B. picture

The picture element contains source elements and a fallback img element.

Q87. Which attribute provides multiple image candidates for different display conditions?

  1. srcset
  2. href
  3. target
  4. action
Correct Answer: A. srcset

Srcset provides multiple image candidates for browser selection.

Q88. Which attribute restricts iframe capabilities?

  1. secure
  2. protect
  3. sandbox
  4. restricted
Correct Answer: C. sandbox

The sandbox attribute applies restrictions to embedded content.

Q89. Which element can embed an external PDF or other resource with fallback content?

  1. object
  2. header
  3. label
  4. summary
Correct Answer: A. object

The object element can embed an external resource and provide fallback content.

Q90. Which element is used for an embedded external resource without an end tag?

  1. object
  2. embed
  3. iframe
  4. video
Correct Answer: B. embed

Embed is a void element used to embed external content.

Q91. Which HTTP response status is associated with a successful WebSocket upgrade handshake?

  1. 200
  2. 301
  3. 101
  4. 404
Correct Answer: C. 101

HTTP 101 Switching Protocols is used in the classic WebSocket upgrade handshake.

Q92. Which statement about localStorage is correct?

  1. It stores only images.
  2. It stores key-value strings.
  3. It automatically encrypts all data.
  4. It requires a database server.
Correct Answer: B. It stores key-value strings

Values are stored as strings; structured data can be serialized when needed.

Q93. Which method adds a new state to the browser session history?

  1. history.add()
  2. history.pushState()
  3. history.insert()
  4. history.new()
Correct Answer: B. history.pushState()

pushState adds a new history entry without a normal page navigation.

Q94. Which attribute can provide a regular-expression constraint for a text input?

  1. pattern
  2. regex
  3. validate
  4. match
Correct Answer: A. pattern

The pattern attribute specifies a regular expression for constraint validation.

Q95. Which attribute prevents a form control from being edited while keeping it generally submittable?

  1. disabled
  2. readonly
  3. hidden
  4. required
Correct Answer: B. readonly

Readonly controls are generally included in form submission; disabled controls are not.

Q96. Which attribute identifies the relationship of a link to its destination?

  1. href
  2. rel
  3. src
  4. name
Correct Answer: B. rel

The rel attribute describes the relationship between the current document and linked resource.

Q97. Which is the best practice for a decorative image?

  1. Omit the img element
  2. Use alt="image"
  3. Use alt=""
  4. Use title only
Correct Answer: C. Use alt=""

An empty alt attribute tells assistive technology that the image is decorative.

Q98. Which statement about robots.txt is correct?

  1. It encrypts private pages.
  2. It gives crawler access instructions.
  3. It validates HTML.
  4. It creates database backups.
Correct Answer: B. It gives crawler access instructions

robots.txt is not an authentication or security mechanism.

Q99. Which platform can host a static HTML5 website?

  1. GitHub Pages
  2. BIOS
  3. Device Manager
  4. Compiler only
Correct Answer: A. GitHub Pages

GitHub Pages supports hosting static websites.

Q100. Which technologies are commonly used together to develop modern websites?

  1. HTML only
  2. CSS only
  3. HTML, CSS, and JavaScript
  4. SQL and BIOS only
Correct Answer: C. HTML, CSS, and JavaScript

HTML structures content, CSS controls presentation, and JavaScript adds behaviour and interactivity.
