HTML Interview Questions

HTML5 Complete Study Course | Chapter 16

1. Introduction

HTML interview questions evaluate a candidate's understanding of web document structure, elements, attributes, hyperlinks, forms, multimedia, semantic HTML, accessibility, and modern browser features.

Interview preparation strategy: Understand the purpose of each HTML element, know its correct usage, and be able to write a small working example.

Topics Covered

  • HTML fundamentals and document structure
  • Elements, tags, and attributes
  • Text formatting, links, and lists
  • Tables and forms
  • Semantic HTML5 elements
  • Audio, video, Canvas, and SVG
  • HTML5 APIs and browser features
  • Accessibility, SEO, and validation
  • Practical coding and scenario-based questions

2. Beginner-Level HTML Interview Questions

Q1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

Q2. What is the full form of HTML?

Answer: HyperText Markup Language.

Q3. Is HTML a programming language?

Answer: No. HTML is a markup language. It describes the structure and meaning of web content. It does not provide general-purpose programming logic by itself.

Q4. What is the difference between a tag and an element?

Answer: A tag is markup such as <p> or </p>. An element is the complete HTML construct, including its tags, attributes, and content where applicable. 

<p>Welcome to HTML</p>

Here, the complete paragraph is an HTML element.

Q5. What is an HTML attribute?

Answer: An attribute provides additional information or configuration for an HTML element. 

<img src="photo.jpg" alt="A mountain">

Here, src and alt are attributes.

Q6. What is DOCTYPE in HTML?

Answer: The DOCTYPE declaration tells the browser to use standards mode for the document. 

<!DOCTYPE html>

Q7. What is the purpose of the html element?

Answer: It is the root element of an HTML document and contains the head and body elements.

Q8. What is the difference between head and body?

Answer: The head contains document metadata, resource links, and the title. The body contains the document's displayed content.

Q9. What is the purpose of the title element?

Answer: It defines the document title, commonly displayed in the browser tab and used in bookmarks and search result presentations.

Q10. What are heading elements in HTML?

Answer: HTML provides six heading levels, from <h1> to <h6>.

Q11. What is the difference between p and br?

Answer: The p element represents a paragraph. The br element creates a line break within text.

Q12. What is the difference between ol and ul?

Answer: ol creates an ordered list, while ul creates an unordered list.

Q13. Which element creates a hyperlink?

Answer: The anchor element <a> creates hyperlinks using its href attribute.

Q14. What is the purpose of the img element?

Answer: It embeds an image in an HTML document. The src attribute identifies the image resource and alt provides alternative text.

Q15. What is a comment in HTML?

Answer: A comment is a note in the source code that is not displayed as normal page content. 

<!-- This is an HTML comment -->

3. Intermediate-Level HTML Interview Questions

Q16. What is the difference between block-level and inline elements?

Answer: In traditional HTML layout terminology, block-level elements generally start on a new line and occupy the available width. Inline elements generally flow within text.

Examples: div, p, section, span, a, and strong.

CSS display properties can change how elements participate in layout.

Q17. What is the difference between div and span?

Answer: Both are generic containers. The div element is commonly used for grouping flow content, while span is commonly used for grouping phrasing content. Their default display behaviour differs.

Q18. What is semantic HTML?

Answer: Semantic HTML uses elements that describe the meaning or purpose of content. 

<header>
    <h1>Learning Portal</h1>
</header>

<main>
    <article>
        <h2>HTML Tutorial</h2>
        <p>Learn HTML fundamentals.</p>
    </article>
</main>

<footer>
    <p>Copyright information</p>
</footer>

Q19. What is the difference between strong and b?

Answer: strong indicates strong importance, seriousness, or urgency. b draws attention without adding that importance meaning. Both commonly render bold by default.

Q20. What is the difference between em and i?

Answer: em represents stress emphasis. i represents text set apart from normal prose, such as a technical term or a foreign phrase, depending on context.

Q21. What is the purpose of the table element?

Answer: It represents tabular data arranged in rows and columns.

Q22. What is the difference between th and td?

Answer: th represents a table header cell. td represents a regular data cell.

Q23. What is colspan?

Answer: The colspan attribute specifies how many columns a table cell spans. 

<td colspan="2">Combined Cell</td>

Q24. What is rowspan?

Answer: The rowspan attribute specifies how many rows a table cell spans. 

<td rowspan="2">Combined Rows</td>

Q25. What is the purpose of the form element?

Answer: It groups controls used to collect user input and submit form data.

Q26. What is the difference between GET and POST?

Answer: GET commonly retrieves a resource and places submitted parameters in the URL. POST sends submitted data in the request body. Their HTTP semantics differ; POST is not automatically encrypted. HTTPS is needed to protect data in transit.

Q27. What is the difference between id and class?

Answer: An id identifies an element within a document and should be unique. A class can be assigned to multiple elements. 

<h1 id="page-title">HTML Course</h1>

<p class="description">Introduction</p>
<p class="description">Advanced topics</p>

Q28. What is the difference between absolute and relative URLs?

Answer: An absolute URL specifies a complete URL, including the scheme and host when applicable. A relative URL is resolved with respect to the current document's URL.

Q29. What is the purpose of the label element?

Answer: It provides a text label for a form control. The for attribute can associate the label with a control having a matching id.

Q30. What is the purpose of the required attribute?

Answer: It indicates that a form control must have a value before the form can pass normal browser constraint validation.

4. Advanced HTML5 Interview Questions

Q31. What are the important features introduced with HTML5?

Answer: HTML5 introduced semantic elements, native audio and video elements, Canvas, improved form controls, and several features of the broader web platform.

Q32. What is the difference between HTML and HTML5?

Answer: HTML5 refers to the major evolution of HTML that introduced modern semantic elements, multimedia support, graphics elements, and improved form capabilities. HTML is now maintained as a continuously evolving Living Standard.

Q33. What is the purpose of the article element?

Answer: It represents a self-contained composition that could be independently distributed or reused, such as a news article, blog post, or forum post.

Q34. What is the difference between section and article?

Answer: A section groups content around a thematic topic. An article represents a self-contained composition.

Q35. What is the purpose of the picture element?

Answer: It provides alternative image sources, allowing the browser to select a suitable image based on media conditions or formats. 

<picture>
    <source srcset="image.avif" type="image/avif">
    <source srcset="image.webp" type="image/webp">
    <img src="image.jpg" alt="Electronic circuit">
</picture>

Q36. What is the difference between Canvas and SVG?

Answer: Canvas is a bitmap-based drawing surface commonly controlled through JavaScript. SVG is a vector graphics format with elements represented in a document structure.

Q37. What is localStorage?

Answer: localStorage is a browser storage API that stores string key-value pairs persistently for an origin, subject to browser policies. 

localStorage.setItem("username", "Student");

const user = localStorage.getItem("username");

console.log(user);

Q38. What is the difference between localStorage and sessionStorage?

Answer: localStorage generally persists across browser sessions. sessionStorage is associated with a particular browsing context and is cleared when that page session ends.

Q39. What is the Geolocation API?

Answer: It allows a website to request the user's geographical location through the browser, subject to permission and browser security requirements.

Q40. What is a Web Worker?

Answer: A Web Worker executes JavaScript in a background worker thread, allowing certain computational tasks to run without blocking the main page thread.

Q41. What is the purpose of the iframe element?

Answer: It embeds another browsing context within the current HTML document.

Q42. What is the sandbox attribute of iframe?

Answer: It applies restrictions to the embedded browsing context. Specific capabilities can be selectively permitted using sandbox tokens.

Q43. What is the purpose of the meta viewport tag?

Answer: It configures the layout viewport for mobile browsers. 

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Q44. What is the purpose of alt text?

Answer: Alternative text communicates the purpose or relevant information of an image when it cannot be perceived visually. Decorative images should generally use an empty alt attribute.

Q45. What is the purpose of ARIA?

Answer: WAI-ARIA provides roles, states, and properties that help communicate accessibility information to assistive technologies. Native semantic HTML should be preferred when available.

5. HTML Forms and Validation Questions

Q46. What is HTML form validation?

Answer: It is the process of checking whether form values satisfy specified constraints before normal form submission.

Q47. What is the pattern attribute?

Answer: It specifies a regular expression that a non-empty input value must match for constraint validation. 

<input type="text"
       pattern="[A-Za-z]{3,20}"
       title="Enter 3 to 20 letters">

Q48. What is the difference between readonly and disabled?

Answer: A readonly control cannot normally be edited by the user but is generally submitted with the form. A disabled control is unavailable for interaction and is generally excluded from form submission.

Q49. What is the difference between checkbox and radio button?

Answer: Checkboxes allow independent selection of multiple options. Radio buttons with the same name form a group in which normally one option can be selected.

Q50. What is the purpose of the datalist element?

Answer: It provides suggested options for an input element through its list attribute. It does not restrict the user to those suggestions. 

<label for="language">Programming Language:</label>

<input list="languages" id="language" name="language">

<datalist id="languages">
    <option value="C">
    <option value="C++">
    <option value="Java">
    <option value="Python">
</datalist>

6. Accessibility and SEO Interview Questions

Q51. What is web accessibility?

Answer: Web accessibility means designing and developing websites so that people with different abilities can perceive, understand, navigate, and interact with them.

Q52. What is WCAG?

Answer: Web Content Accessibility Guidelines are recommendations for making web content more accessible. They are organized around four principles: Perceivable, Operable, Understandable, and Robust.

Q53. What is the purpose of the lang attribute?

Answer: It identifies the primary language of the document or an element's content. 

<html lang="en">

Q54. What is SEO?

Answer: Search Engine Optimization is the practice of improving a website's discoverability and presentation in search engines.

Q55. What is the purpose of a meta description?

Answer: It provides a short description of the page. Search engines may use it when generating search result snippets, but they can also select different text.

Q56. What is a canonical URL?

Answer: It identifies the preferred URL for a page when multiple URLs contain duplicate or substantially similar content.

Q57. What is structured data?

Answer: Structured data is machine-readable information that describes page content using a defined vocabulary, such as Schema.org.

Q58. What is the difference between robots.txt and meta robots?

Answer: robots.txt provides crawler access instructions for paths on a site. A meta robots directive provides indexing-related instructions for a specific HTML page to compatible crawlers. Neither is a security mechanism.

7. Practical Coding Interview Questions

Q59. Write the basic structure of an HTML document.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
</head>
<body>

    <h1>Welcome</h1>
    <p>This is my first web page.</p>

</body>
</html>

Q60. Create a hyperlink that opens an external website in a new tab.

<a href="https://www.example.com"
   target="_blank"
   rel="noopener noreferrer">
    Visit Example
</a>

Q61. Create an HTML table with two columns.

<table>
    <caption>Student Information</caption>
    <thead>
        <tr>
            <th scope="col">Name</th>
            <th scope="col">Course</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Rahul</td>
            <td>ECE</td>
        </tr>
    </tbody>
</table>

Q62. Create a registration form with name and email fields.

<form action="/register" method="post">

    <label for="name">Name:</label>
    <input type="text" id="name" name="name" required>

    <br><br>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <br><br>

    <button type="submit">Register</button>

</form>

The example assumes that a server endpoint exists at /register. HTML alone does not implement the registration backend.

Q63. Embed an audio file in HTML.

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Your browser does not support HTML audio.
</audio>

Q64. Embed a video file in HTML.

<video controls width="640">
    <source src="video.mp4" type="video/mp4">
    Your browser does not support HTML video.
</video>

Q65. Create a semantic HTML5 layout.

<header>
    <h1>My Website</h1>
</header>

<nav aria-label="Main navigation">
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
</nav>

<main>
    <section>
        <h2>Introduction</h2>
        <p>Welcome to the website.</p>
    </section>

    <article>
        <h2>Latest Article</h2>
        <p>Article content goes here.</p>
    </article>
</main>

<footer>
    <p>Copyright information</p>
</footer>

8. Scenario-Based Interview Questions

Q66. A website image is not displaying. How would you troubleshoot it?

Answer:

  1. Check whether the image file exists.
  2. Verify the src path.
  3. Check filename spelling and capitalization.
  4. Verify the file extension and format.
  5. Check the browser developer tools and network errors.
  6. Confirm that the image is accessible from the deployed URL.

Q67. A navigation link works locally but fails on GitHub Pages. What could be wrong?

Answer:

  • The path may contain incorrect capitalization.
  • The destination file may not have been uploaded.
  • The relative path may be incorrect.
  • The link may assume a domain-root location that does not match the repository deployment path.

Q68. How would you make a website accessible to keyboard users?

Answer: Use native interactive elements, preserve logical tab order, provide visible focus indicators, avoid keyboard traps, and ensure all interactive functions are keyboard operable.

Q69. How would you improve a slow-loading HTML page?

Answer:

  • Optimize image dimensions and formats.
  • Use lazy loading for suitable below-the-fold images.
  • Reduce unnecessary resources.
  • Use efficient CSS and JavaScript loading strategies.
  • Set image width and height to reduce layout shifts.
  • Measure performance using browser developer tools.

Q70. How would you create a multipage educational website?

Answer: Plan the pages, create a directory structure, add consistent navigation, use semantic HTML, connect pages with correct relative links, test the site, validate the markup, and deploy it to a suitable hosting platform.

11. HTML Interview Preparation Checklist

  • Understand the complete HTML document structure.
  • Know the difference between tags, elements, and attributes.
  • Practice links, images, and relative paths.
  • Understand lists and tables.
  • Build forms using different input types.
  • Use semantic HTML5 elements correctly.
  • Understand audio, video, Canvas, and SVG.
  • Know the purpose of important HTML5 APIs.
  • Understand accessibility and SEO fundamentals.
  • Practice building a complete multipage website.
  • Validate HTML and troubleshoot broken resources.

13. Lesson Summary

  • HTML is a markup language used to structure web content.
  • HTML elements and attributes define document structure and behaviour.
  • Semantic HTML improves the meaning and organization of content.
  • Forms collect input and use browser validation constraints.
  • HTML5 supports multimedia and graphics elements.
  • Accessibility and SEO are important parts of HTML development.
  • Practical coding and troubleshooting are essential interview skills.
Preparation advice: Do not memorize answers alone. Practice writing HTML documents, building forms, creating tables, connecting multiple pages, and explaining why you selected particular elements.
