2. What is an HTML Document?

An HTML document is a text file containing HTML markup that defines the structure and meaning of a web page. It uses elements and attributes to organize content such as headings, paragraphs, images, links and forms.

An HTML document is generally saved with the .html or .htm extension.

Example

index.html

A browser reads the HTML document, parses its markup and constructs a Document Object Model (DOM).

3. Basic Structure of an HTML5 Document

A standard HTML5 document follows a basic structure containing a DOCTYPE declaration, an html root element, a head section and a body section.

Complete HTML5 Structure

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My First Web Page</title>
</head>

<body>

    <h1>Welcome to HTML5</h1>

    <p>This is my first HTML document.</p>

</body>

</html>

4. Understanding Each Part of the HTML Structure

1. DOCTYPE Declaration

<!DOCTYPE html>

The DOCTYPE declaration tells the browser that the document uses the HTML standard. It helps the browser render the page in standards mode.

In HTML5, the declaration is simply <!DOCTYPE html>.

Important: DOCTYPE is a declaration, not an HTML element. It does not have a closing tag.

2. HTML Root Element

<html lang="en">
    ...
</html>

The html element is the root element of an HTML document. All other HTML elements, apart from the DOCTYPE declaration, are contained within it.

The lang="en" attribute identifies English as the primary language of the document.

3. Head Element

<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>

The head element contains metadata and references to resources used by the document.

Common content inside head includes:

  • Character encoding declaration.
  • Viewport settings.
  • Document title.
  • CSS stylesheet references.
  • Metadata such as description and author.
  • Links to icons and other resources.
The head element is not the place for the main visible content of a web page. That content normally belongs inside the body element.

4. Body Element

<body>
    <h1>Welcome to HTML5</h1>
    <p>This is my first HTML document.</p>
</body>

The body element contains the document's main content that is rendered in the browser.

Examples of content inside body:

  • Headings
  • Paragraphs
  • Images
  • Hyperlinks
  • Tables
  • Lists
  • Forms
  • Audio and video

5. Important Elements Used in the HTML Head

A. Character Encoding

<meta charset="UTF-8">

This declaration specifies UTF-8 character encoding. It supports a wide range of characters and symbols used in different languages.

B. Viewport Metadata

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

The viewport declaration helps the page adapt to the device's screen width and establishes its initial scale.

C. Title Element

<title>My First Web Page</title>

The title element defines the document title. It is commonly displayed in the browser tab and used by bookmarks and search results.

D. Meta Description

<meta name="description"
      content="Learn HTML5 step by step.">

This provides a short description of the page. Search engines may use it when generating search result snippets.

E. External CSS Reference

<link rel="stylesheet" href="style.css">

The link element can connect an external stylesheet to the HTML document.

F. JavaScript Reference

<script src="script.js" defer></script>

The script element can load an external JavaScript file. The defer attribute tells the browser to execute the script after HTML parsing has completed.

6. HTML Document Structure – Hierarchy

HTML documents are organized in a hierarchical structure. Elements can contain other elements, forming a tree known as the Document Object Model (DOM). 

Document
   |
   └── html
       |
       ├── head
       |    |
       |    ├── meta
       |    ├── title
       |    └── link
       |
       └── body
            |
            ├── h1
            |
            ├── p
            |
            └── a

In this hierarchy:

  • html: Root element.
  • head: Contains document metadata.
  • body: Contains page content.
  • meta, title, link: Elements inside head.
  • h1, p, a: Elements inside body.

7. HTML Document Structure with Comments

Comments can be used to explain the purpose of different sections of an HTML document. 

<!DOCTYPE html>

<!-- Root HTML element -->
<html lang="en">

<!-- Document metadata -->
<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <!-- Page title -->
    <title>HTML Document Structure</title>

</head>

<!-- Visible page content -->
<body>

    <h1>HTML Document Structure</h1>

    <p>Learning HTML step by step.</p>

</body>

</html>

8. Difference Between Head and Body

Head Element Body Element
Contains document metadata. Contains the main page content.
Contains the title element. Contains headings and paragraphs.
Contains stylesheet references. Contains images, links and forms.
Generally does not contain the page's main visible content. Contains content rendered as part of the page.

9. HTML Document vs HTML Element

An HTML document is the complete file containing the page markup. An HTML element is an individual component within that document.

Example

<p>Learning HTML5</p>

Here, the paragraph is one HTML element. The complete file containing this paragraph and other markup is the HTML document.

11. Common Mistakes in HTML Document Structure

Mistake Correct Practice
Missing DOCTYPE declaration. Start the document with <!DOCTYPE html>.
Missing html root element. Wrap the document content inside html.
Placing the page title inside body. Place title inside head.
Placing the main heading inside head. Place visible content inside body.
Incorrect character encoding. Use UTF-8 unless another encoding is specifically required.
Missing viewport metadata. Include viewport metadata for responsive layouts.
Incorrect file extension. Save the file with .html or .htm.
Note: Browsers can recover from many HTML syntax errors and may automatically insert certain missing structural elements. However, writing a complete and well-structured document is the recommended practice.

13. Interview Questions and Answers

Q1. What is the basic structure of an HTML document?

It consists of a DOCTYPE declaration, an html root element, a head element and a body element.

Q2. What is the purpose of DOCTYPE?

It identifies the document type and helps the browser use standards mode.

Q3. What is the root element of HTML?

The html element is the root element of an HTML document.

Q4. What is the purpose of the head element?

It contains metadata and references to resources associated with the document.

Q5. What is the purpose of the body element?

It contains the main content rendered as part of the web page.

Q6. Why is UTF-8 used in HTML?

UTF-8 supports a wide range of characters and helps browsers interpret document text correctly.

Q7. What is the purpose of viewport metadata?

It controls the layout viewport and initial scale used by mobile browsers.

Q8. What is the extension of an HTML file?

Common extensions are .html and .htm.

Q9. Is DOCTYPE an HTML element?

No. It is a declaration that appears before the html root element.

Q10. What is the DOM?

DOM stands for Document Object Model. It represents the document as a tree of objects that scripts can access and manipulate.

14. Multiple Choice Questions (MCQs)

Q1. Which declaration is used at the beginning of an HTML5 document?

  1. <html5>
  2. <!DOCTYPE html>
  3. <doctype>
  4. <head>

Correct Answer: B. <!DOCTYPE html>

Q2. Which element is the root of an HTML document?

  1. <head>
  2. <body>
  3. <html>
  4. <title>

Correct Answer: C. <html>

Q3. Where is the title element placed?

  1. Inside body
  2. Inside head
  3. Outside html
  4. Inside footer

Correct Answer: B. Inside head

Q4. Which element contains the main page content?

  1. <head>
  2. <meta>
  3. <body>
  4. <title>

Correct Answer: C. <body>

Q5. Which character encoding is commonly recommended for HTML?

  1. UTF-8
  2. ASCII only
  3. UTF-1
  4. Binary

Correct Answer: A. UTF-8

Q6. Which attribute identifies the document language?

  1. charset
  2. lang

  4. content

Q7. Which element connects an external CSS stylesheet?

  1. <style>
  2. <link>

Q8. Which file extension is commonly used for HTML documents?
