2. What is an HTML File?

An HTML file is a text file containing HTML markup. A web browser reads this markup and displays the structured content as a web page.

HTML files generally use the .html file extension.

Example

index.html

The file above is an HTML document named index.

Common HTML File Extensions

Extension Description
.html Common extension for HTML documents.
.htm Alternative extension for HTML documents.
Important: Both .html and .htm are recognized as HTML file extensions. Prefer .html for modern web development.

4. Creating an HTML File Using Notepad

Windows Notepad can be used to write and save HTML code. No special HTML software is required.

Step 1 – Open Notepad

  1. Press the Windows key.
  2. Type Notepad in the search box.
  3. Open the Notepad application.

Step 2 – Write HTML Code

Enter the following program:

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first HTML page.</p>

</body>

</html>

Step 3 – Save the File

  1. Click File.
  2. Select Save As.
  3. Choose a folder.
  4. Enter the file name index.html.
  5. Set Save as type to All Files.
  6. Select UTF-8 encoding if available.
  7. Click Save.
Important: If you save the file as index.html.txt, Windows may treat it as a text file rather than an HTML document. Select All Files when saving through classic Notepad.

5. Creating an HTML File Using Visual Studio Code

Visual Studio Code provides a convenient environment for writing and managing HTML projects.

Step 1 – Open Visual Studio Code

  1. Install Visual Studio Code.
  2. Launch the application.
  3. Open the File menu.
  4. Select New Text File.

Step 2 – Select HTML Language Mode

Save the new file with the name index.html. VS Code normally detects HTML automatically from the file extension.

Step 3 – Write HTML Code

Enter the following code:

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My First HTML Page</title>
</head>

<body>

    <h1>Welcome to HTML5</h1>

    <p>I am learning web development.</p>

</body>

</html>

Step 4 – Save the File

Press Ctrl + S and save the file with the name index.html.

Step 5 – Use Emmet Abbreviation

VS Code supports Emmet, which can generate a basic HTML document structure.

  1. Create a new HTML file.
  2. Type ! in the editor.
  3. Select the Emmet abbreviation suggestion or press Tab when offered.
  4. VS Code generates a basic HTML document structure.
Emmet is a built-in abbreviation system in VS Code. It helps generate HTML and CSS code more quickly.

6. Opening an HTML File in a Web Browser

Once an HTML file has been saved, it can be opened in a web browser.

Method 1 – Double-Click the File

  1. Open File Explorer.
  2. Navigate to the folder containing the HTML file.
  3. Double-click index.html.
  4. The file opens in the default web browser.

Method 2 – Open With a Browser

  1. Right-click the HTML file.
  2. Select Open with.
  3. Choose Chrome, Edge or Firefox.

Method 3 – Open Through the Browser

  1. Open a web browser.
  2. Press Ctrl + O.
  3. Select the HTML file.
  4. Click Open.
HTML pages can be opened directly from the local file system. A web server is not required for basic HTML practice.

7. Understanding the Local File Path

A file path identifies the location of a file or folder on a computer.

Example Windows Path

C:\Users\Student\Documents\HTML\index.html

Explanation:

  • C: is the drive.
  • Users is a directory.
  • Student is a user folder.
  • Documents contains documents.
  • HTML is the project folder.
  • index.html is the HTML file.

Absolute File Path

An absolute path specifies the complete location of a file from the root of the file system. 

C:\Users\Student\Documents\HTML\index.html

Relative File Path

A relative path identifies a file location in relation to the current document or directory. 

images/logo.png
css/style.css
js/script.js

Relative paths are commonly used to connect HTML documents with CSS, JavaScript and images.

9. Connecting HTML with Other Files

An HTML document can reference external CSS files, JavaScript files and images using relative paths.

Example HTML

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <title>My Website</title>

    <link rel="stylesheet" href="css/style.css">

</head>

<body>

    <h1>My Website</h1>

    <img src="images/logo.png" alt="Website Logo">

    <script src="js/script.js"></script>

</body>

</html>

Explanation:

  • href="css/style.css" connects the CSS file.
  • src="images/logo.png" loads the image.
  • src="js/script.js" loads the JavaScript file.

10. Understanding the index.html File

The filename index.html is commonly used as the default entry page of a website or directory.

When a web server is configured with index.html as its default document, visiting a directory URL can automatically load that file.

Example Website Structure

MyWebsite/
│
├── index.html
├── about.html
└── contact.html

When the website is configured correctly, its root URL can display index.html automatically.

Note: index.html is a widely used convention, not a special HTML language requirement. The default document depends on server configuration.

11. Viewing and Inspecting HTML Source Code

Web browsers allow developers to inspect the HTML source code of a web page.

View Page Source

  1. Open a web page in Chrome or Edge.
  2. Right-click the page.
  3. Select View page source.
  4. The browser displays the HTML source.

Developer Tools

Press F12 or Ctrl + Shift + I to open browser developer tools in supported browsers.

Developer tools help inspect:

  • HTML elements and DOM structure.
  • CSS styles.
  • JavaScript errors.
  • Network requests.
  • Console messages.
View Page Source shows the original HTML response, while the Elements panel shows the current DOM, which may have been modified by JavaScript.

12. Common Errors While Creating HTML Files

Error Solution
File saved as index.html.txt Save using the .html extension and check the actual filename.
HTML code displayed as plain text Check the file extension and open it in a browser.
Changes are not visible Save the file and refresh the browser.
Image is not displayed Check the image path and filename.
CSS is not applied Check the stylesheet path and filename.
Wrong characters appear Save using UTF-8 encoding and include the charset declaration.
Browser cannot find a linked page Check the relative path and file name.

13. HTML File Naming Best Practices

  • Use meaningful file names.
  • Prefer lowercase file names.
  • Use hyphens or underscores to separate words.
  • Use the .html extension.
  • Avoid unnecessary spaces in file names.
  • Keep related files in organized folders.
  • Use consistent naming conventions throughout a project.

Good File Names

index.html
about-us.html
contact.html
student-registration.html
html-introduction.html

Names to Avoid

New File.html
My Website Final Final.html
page123.html

14. Practical Example – Create Your First HTML Project

Objective: Create and run a simple HTML project.

Step 1 – Create a Folder

Create a folder named:

MyFirstHTMLProject

Step 2 – Create an HTML File

Inside the folder, create:

index.html

Step 3 – Write the HTML Program

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My First HTML Project</title>

</head>

<body>

    <header>
        <h1>My First Website</h1>
    </header>

    <main>

        <h2>About Me</h2>

        <p>
            I am learning HTML5 and web development.
        </p>

        <h2>My Learning Goals</h2>

        <ul>
            <li>Learn HTML5</li>
            <li>Learn CSS3</li>
            <li>Learn JavaScript</li>
        </ul>

    </main>

    <footer>
        <p>My First HTML Project</p>
    </footer>

</body>

</html>

Step 4 – Save the File

Save the document as index.html inside the project folder.

Step 5 – Open in Browser

Double-click index.html or open it through Chrome, Edge or Firefox.

Expected Browser Output

My First Website

About Me

I am learning HTML5 and web development.

My Learning Goals

  • Learn HTML5
  • Learn CSS3
  • Learn JavaScript

My First HTML Project

17. Interview Questions and Answers

Q1. What is an HTML file?

An HTML file is a text document containing HTML markup that a browser parses to display a web page.

Q2. What is the file extension of an HTML document?

The commonly used extension is .html. The alternative .htm extension is also supported.

Q3. Can we create HTML files using Notepad?

Yes. HTML files can be created using any suitable plain-text editor, including Notepad.

Q4. What is Visual Studio Code?

Visual Studio Code is a source code editor used for writing and managing programming files.

Q5. How do you open an HTML file in a browser?

Double-click the file, use the browser's Open File option or open it through the editor's supported tools.

Q6. What is index.html?

It is a commonly used default entry-page filename for websites and directories.

Q7. What is a relative file path?

A relative path specifies a file location in relation to the current document or directory.

Q8. Is a web server required to open a basic HTML file?

No. A browser can open a basic HTML file directly from the local file system.

Q9. Why should we organize project files into folders?

Organized folders make project files easier to manage, locate, maintain and update.

Q10. What happens if an HTML file is saved with a .txt extension?

The operating system may treat it as a text file. Save it with the .html extension to identify it as an HTML document.
