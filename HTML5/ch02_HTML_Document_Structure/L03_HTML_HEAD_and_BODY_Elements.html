2. Introduction to HEAD and BODY

An HTML document is generally divided into two main sections:

  1. HEAD: Contains document metadata and references to resources.
  2. BODY: Contains the main content of the web page.

Basic Syntax

<!DOCTYPE html>
<html lang="en">

<head>
    <!-- Metadata and resource references -->
</head>

<body>
    <!-- Main page content -->
</body>

</html>
Remember: The head and body elements are children of the html root element. They serve different purposes and should not be confused.

3. The HEAD Element

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

The head element contains machine-readable information (metadata) about the HTML document and references to resources required by the page.

Most of the information inside head is not displayed as ordinary page content in the browser window.

Common Elements Inside HEAD

Element Purpose
<title> Defines the document title.
<meta> Provides metadata such as character encoding and description.
<link> References external resources such as CSS stylesheets and icons.
<style> Contains internal CSS rules.
<script> Embeds or references JavaScript.
<base> Specifies the base URL for relative URLs in the document.

4. Important Elements Inside HEAD

A. TITLE Element

<title>My First Website</title>

The title element defines the document's title. Browsers commonly display this title in the browser tab.

Example:

<head>
    <title>HTML5 Complete Course</title>
</head>
The title element is important for identifying a page in browser tabs, bookmarks and search results.

B. META Element

The meta element provides metadata about the HTML document. It is an empty element and does not have a closing tag.

1. Character Encoding

<meta charset="UTF-8">

Specifies UTF-8 character encoding for the document.

2. Viewport Metadata

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Helps the page use the device's viewport width and establishes its initial zoom level.

3. Description Metadata

<meta name="description"
      content="Learn HTML5 from beginner to advanced level.">

Provides a short description of the page. Search engines may use it to generate search result snippets.

4. Author Metadata

<meta name="author" content="NS Learning Hub">

Identifies the author or publisher of the document.

5. Robots Metadata

<meta name="robots" content="index, follow">

Provides instructions to search engine crawlers. Actual indexing and crawling also depend on other technical and search engine rules.

C. LINK Element

<link rel="stylesheet" href="style.css">

The link element establishes a relationship between the current document and an external resource. It is commonly used to connect CSS stylesheets.

Example

<head>
    <link rel="stylesheet" href="style.css">
</head>

The browser downloads and applies the stylesheet according to the resource loading rules.

D. STYLE Element

<style>
    body {
        background-color: lightblue;
    }

    h1 {
        color: darkblue;
    }
</style>

The style element contains internal CSS. These CSS rules control the presentation of HTML elements.

E. SCRIPT Element

The script element is used to embed JavaScript or reference an external JavaScript file.

External JavaScript

<script src="script.js" defer></script>

The defer attribute allows the browser to download the external classic script while parsing HTML and execute it after parsing is complete.

A script element can appear in different locations depending on how the script needs to load and execute. External scripts in head commonly use defer when they need the parsed document.

F. BASE Element

<base href="https://example.com/">

The base element specifies the base URL used to resolve relative URLs in a document.

A document can contain only one base element. It must be placed inside head and before elements that contain URL attributes.

5. The BODY Element

<body>
    <h1>Welcome to My Website</h1>
    <p>This is my web page.</p>
</body>

The body element contains the main content of an HTML document. This is the content that is rendered as part of the web page.

Common Elements Inside BODY

Element Purpose
<h1> to <h6> Define headings.
<p> Defines a paragraph.
<a> Creates a hyperlink.
<img> Embeds an image.
<ul> and <ol> Create lists.
<table> Creates a table.
<form> Creates a form for user input.
<audio> and <video> Embed audio and video content.
<div> and <span> Group content for structure and styling.
<header>, <main>, <footer> Provide semantic page structure.

6. Examples of Elements Inside BODY

A. Heading

<h1>Welcome to HTML5</h1>
<h2>Introduction</h2>

Headings organize the content into sections and subsections.

B. Paragraph

<p>
    HTML is used to structure web content.
</p>

The paragraph element represents a paragraph of text.

C. Hyperlink

<a href="https://www.example.com">
    Visit Example
</a>

The anchor element creates a hyperlink to another page or resource.

D. Image

<img src="logo.png" alt="Website Logo">

The img element embeds an image in the page. The alt attribute provides alternative text.

E. List

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Lists organize related information into ordered or unordered groups.

7. Difference Between HEAD and BODY

HEAD BODY
Contains document metadata. Contains main page content.
Contains the title element. Contains headings and paragraphs.
Contains metadata elements such as meta. Contains content elements such as img and a.
Can reference external CSS files. Can contain visible page content styled by CSS.
Can reference JavaScript files. Can contain elements manipulated by JavaScript.
Usually does not contain the main visible content. Contains the content rendered as part of the page.

8. Relationship Between HEAD, BODY and Browser

When a browser loads an HTML document, it processes the document structure and resources.

  1. The browser receives or reads the HTML document.
  2. It parses the HTML markup.
  3. It processes metadata and resource references in head.
  4. It constructs the DOM tree.
  5. It loads and applies CSS resources.
  6. It executes scripts according to their loading attributes and position.
  7. It renders the page content.
Important: The browser does not simply display the raw HTML source. It parses the markup and builds an internal representation called the DOM.

9. Complete Practical HTML5 Program

Create a file named head_body_example.html and write the following program. 

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="A practical example of HTML head and body.">

    <meta name="author" content="NS Learning Hub">

    <title>HEAD and BODY Example</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            background-color: #f0f4ff;
            padding: 20px;
        }

        h1 {
            color: #174ea6;
        }

        p {
            color: #333;
        }
    </style>

</head>

<body>

    <h1>Understanding HEAD and BODY</h1>

    <p>
        The head element contains metadata.
    </p>

    <p>
        The body element contains the main page content.
    </p>

    <a href="https://developer.mozilla.org/en-US/docs/Web/HTML">
        Learn HTML
    </a>

</body>

</html>

Expected Browser Output

Understanding HEAD and BODY

The head element contains metadata.

The body element contains the main page content.

11. Practical Exercise 2 – Add CSS and JavaScript

Objective: Understand how external resources are referenced from head.

HTML File: index.html

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>External Resources Example</title>

    <link rel="stylesheet" href="style.css">

    <script src="script.js" defer></script>
</head>

<body>

    <h1>External Resources</h1>

    <p id="message">JavaScript has not run yet.</p>

</body>

</html>

CSS File: style.css

body {
    font-family: Arial, sans-serif;
    background-color: #f4f6f9;
}

h1 {
    color: #174ea6;
}

JavaScript File: script.js

document.getElementById("message").textContent =
    "JavaScript loaded successfully.";

Expected Result

The heading appears in blue, and the paragraph displays:

JavaScript loaded successfully.

12. Common Mistakes

Mistake Correct Practice
Placing the title inside body. Place title inside head.
Placing meta elements inside body. Place document metadata inside head.
Placing the main heading inside head. Place visible page content inside body.
Using an incorrect stylesheet path. Check the href path in link.
Using an incorrect JavaScript path. Check the src path in script.
Using multiple title elements. Use one title element for the document.
Placing multiple base elements. Use no more than one base element.

13. Interview Questions and Answers

Q1. What is the purpose of the head element?

It contains metadata and references to resources associated with the HTML document.

Q2. What is the purpose of the body element?

It contains the main content of the web page.

Q3. What is metadata?

Metadata is information that describes the HTML document, such as character encoding, title and description.

Q4. Which element defines the browser tab title?

The title element.

Q5. What is the purpose of the meta element?

It provides metadata about the HTML document.

Q6. Which element connects an external CSS file?

The link element with rel="stylesheet".

Q7. What is the purpose of the style element?

It contains internal CSS rules.

Q8. What is the purpose of the script element?

It embeds JavaScript or references an external JavaScript file.

Q9. Can a script element be placed inside head?

Yes. External scripts in head commonly use defer when execution should wait until HTML parsing is complete.

Q10. What is the purpose of the base element?

It defines the base URL used to resolve relative URLs in the document.

14. Multiple Choice Questions (MCQs)

Q1. Which element contains document metadata?

  1. <body>
  2. <head>
  3. <footer>
  4. <main>

Correct Answer: B. <head>

Q2. Which element contains the main page content?

  1. <head>
  2. <meta>
  3. <body>
  4. <title>

Correct Answer: C. <body>

Q3. Which element defines the browser tab title?

  1. <title>
  2. <h1>
  3. <meta>
  4. <header>

Correct Answer: A. <title>

Q4. Which element provides character encoding information?

  1. <link>
  2. <meta>
  3. <p>
  4. <div>

Correct Answer: B. <meta>

Q5. Which element connects an external stylesheet?

  1. <script>
  2. <style>
  3. <link>
  4. <title>

Correct Answer: C. <link>

Q6. Which attribute is used to reference an external JavaScript file?

  1. href
  2. src
  3. rel
  4. charset

Correct Answer: B. src

Q7. Which element contains internal CSS?

  1. <style>
  2. <meta>
  3. <title>
  4. <body>

Correct Answer: A. <style>

Q8. Which attribute is commonly used to delay a classic external script until HTML parsing is complete?

  1. async
  2. defer
  3. hidden
  4. disabled

Correct Answer: B. defer

15. Lesson Summary

  • HTML documents are generally divided into head and body sections.
  • The head element contains metadata and resource references.
  • The body element contains the main page content.
  • The title element defines the document title.
  • The meta element provides document metadata.
  • The link element references external resources.
  • The style element contains internal CSS.
  • The script element embeds or references JavaScript.
  • The base element specifies the base URL for relative URLs.
  • HTML elements inside body create the page's content and structure.
