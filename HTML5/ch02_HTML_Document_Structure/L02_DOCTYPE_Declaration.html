2. What is DOCTYPE?

DOCTYPE stands for Document Type Declaration. It is a declaration placed at the beginning of an HTML document to identify the document type and help the browser determine how to render the page.

In modern HTML, DOCTYPE is used primarily to ensure that the browser renders the document in standards mode.

HTML5 DOCTYPE Syntax

<!DOCTYPE html>
Important: The HTML5 DOCTYPE declaration is short and simple. It does not contain a version number or a DTD URL.

3. Purpose of DOCTYPE Declaration

The DOCTYPE declaration serves important purposes:

  • Identifies the document type to the browser.
  • Helps the browser use standards mode.
  • Promotes consistent rendering according to modern HTML and CSS standards.
  • Helps avoid legacy rendering behavior associated with quirks mode.

Example

<!DOCTYPE html>
<html lang="en">
<head>
    <title>DOCTYPE Example</title>
</head>
<body>
    <h1>Hello HTML5</h1>
</body>
</html>

4. Position of DOCTYPE in an HTML Document

DOCTYPE should be placed at the very beginning of an HTML document, before the html root element.

Correct Structure

<!DOCTYPE html>
<html lang="en">

<head>
    <title>My Web Page</title>
</head>

<body>
    <h1>Welcome</h1>
</body>

</html>

Incorrect Structure

<html>

<!DOCTYPE html>

<head>
    <title>My Web Page</title>
</head>

<body>
    <h1>Welcome</h1>
</body>

</html>
Remember: Place the DOCTYPE declaration before the html element. Placing it after document content may cause the browser to use an unexpected rendering mode.

5. DOCTYPE in Different HTML Versions

Earlier versions of HTML used longer DOCTYPE declarations. These declarations often included a DTD (Document Type Definition) reference.

A. HTML 4.01 Strict

<!DOCTYPE HTML PUBLIC
"-//W3C//DTD HTML 4.01//EN"
"http://www.w3.org/TR/html4/strict.dtd">

HTML 4.01 Strict followed the HTML 4.01 specification while excluding deprecated presentational elements and attributes.

B. HTML 4.01 Transitional

<!DOCTYPE HTML PUBLIC
"-//W3C//DTD HTML 4.01 Transitional//EN"
"http://www.w3.org/TR/html4/loose.dtd">

Transitional allowed certain older presentational features to support migration from earlier HTML practices.

C. XHTML 1.0 Strict

<!DOCTYPE html PUBLIC
"-//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

XHTML 1.0 applied XML syntax rules to HTML 4.01. Its Strict version used a more restrictive document model.

D. HTML5

<!DOCTYPE html>

HTML5 uses a simplified DOCTYPE declaration. It does not require a public identifier or DTD URL.

Comparison Table

HTML Version DOCTYPE Format
HTML 4.01 Strict Long declaration with DTD reference
HTML 4.01 Transitional Long declaration with Transitional DTD
XHTML 1.0 Strict XML-based declaration with DTD reference
HTML5 <!DOCTYPE html>

6. What is a DTD?

DTD stands for Document Type Definition. It defines the permitted structure and elements of documents written in markup languages such as XML.

Older HTML DOCTYPE declarations referenced DTDs to identify the rules associated with a particular version or document type.

HTML5 does not require an external DTD in its DOCTYPE declaration. The modern HTML standard defines the parsing and rendering behavior.

7. Browser Rendering Modes

Browsers support different rendering modes to maintain compatibility with both modern web pages and older websites.

The main rendering modes are:

  1. Standards Mode
  2. Quirks Mode
  3. Limited Quirks Mode (also called Almost Standards Mode)

A. Standards Mode

Standards mode is the modern rendering mode in which the browser follows current HTML and CSS standards as closely as possible.

A correctly placed HTML5 DOCTYPE normally triggers standards mode. 

<!DOCTYPE html>
<html>
<head>
    <title>Standards Mode</title>
</head>
<body>
    <p>Standards mode example.</p>
</body>
</html>

B. Quirks Mode

Quirks mode is a legacy compatibility mode. Browsers use it to reproduce certain older browser rendering behaviors for pages created before modern web standards became widely adopted.

A missing or unrecognized DOCTYPE can cause a browser to enter quirks mode.

Quirks mode can produce layout differences. It is generally not recommended for newly developed web pages.

C. Limited Quirks Mode

Limited quirks mode is a compatibility mode between standards mode and quirks mode. It follows standards for most rendering behavior while preserving certain legacy behaviors, particularly related to table-cell image alignment.

Rendering Modes Comparison

Mode Purpose Typical Trigger
Standards Mode Modern standards-based rendering HTML5 DOCTYPE
Quirks Mode Legacy browser compatibility Missing or certain invalid DOCTYPE declarations
Limited Quirks Mode Mostly standards-based rendering with limited legacy behavior Certain legacy transitional or frameset DOCTYPEs

8. How to Check Browser Rendering Mode

You can check the rendering mode of a page using the browser's Developer Tools.

Steps in Chrome

  1. Open an HTML page in Google Chrome.
  2. Press F12 to open Developer Tools.
  3. Open the Console tab.
  4. Enter the following JavaScript command.
document.compatMode

Possible results:

Output Meaning
CSS1Compat Standards mode or limited quirks mode
BackCompat Quirks mode
Technical Note: The value CSS1Compat does not distinguish standards mode from limited quirks mode. It indicates that the document is not in full quirks mode.

9. What Happens When DOCTYPE is Missing?

Consider the following HTML document without a DOCTYPE: 

<html>
<head>
    <title>Missing DOCTYPE</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>

In common modern browsers, the absence of a DOCTYPE causes the document to be rendered in quirks mode.

Possible consequences include:

  • Different CSS box model behavior.
  • Differences in element dimensions and layout.
  • Legacy compatibility behavior.
  • Inconsistent rendering across older and newer pages.

10. Common DOCTYPE Mistakes

Incorrect Usage Correct Usage
<doctype html> <!DOCTYPE html>
Placing DOCTYPE after html. Place DOCTYPE before html.
Using an old HTML 4.01 declaration in a new HTML5 project. Use the HTML5 declaration.
Adding a closing DOCTYPE tag. DOCTYPE has no closing tag.
Assuming DOCTYPE is an HTML element. Remember that it is a declaration.

11. Practical Exercise 1 – Create a Valid HTML5 Document

Objective: Create an HTML5 document with a correct DOCTYPE declaration.

Program

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>DOCTYPE Practical</title>
</head>

<body>

    <h1>Understanding DOCTYPE</h1>

    <p>
        This document uses the HTML5 DOCTYPE declaration.
    </p>

</body>

</html>

Expected Result

The browser displays the heading Understanding DOCTYPE and the paragraph. The document is rendered in standards mode.

12. Practical Exercise 2 – Check Rendering Mode

Objective: Identify the rendering mode of an HTML document.

Steps

  1. Create an HTML file with <!DOCTYPE html>.
  2. Open it in Chrome.
  3. Open Developer Tools using F12.
  4. Enter document.compatMode in the Console.
  5. Observe the output.
  6. Remove the DOCTYPE declaration and reload the page.
  7. Run the command again and compare the results.

Expected Observation

13. Interview Questions and Answers

Q1. What is DOCTYPE?

DOCTYPE is a document type declaration that identifies the document type and helps the browser determine the appropriate rendering mode.

Q2. What is the HTML5 DOCTYPE declaration?

<!DOCTYPE html>

Q3. Where should DOCTYPE be placed?

It should be placed at the beginning of the HTML document, before the html root element.

Q4. Is DOCTYPE an HTML element?

No. It is a declaration and does not have an opening and closing element pair.

Q5. What is standards mode?

Standards mode is the browser rendering mode that follows modern web standards.

Q6. What is quirks mode?

Quirks mode is a legacy compatibility mode that reproduces certain older browser behaviors.

Q7. What does DTD stand for?

DTD stands for Document Type Definition.

Q8. Does HTML5 require an external DTD?

No. HTML5 uses a simplified DOCTYPE declaration without an external DTD reference.

Q9. How can you check whether a page is in quirks mode?

Run document.compatMode in the browser console. The value BackCompat indicates quirks mode.

Q10. What is limited quirks mode?

It is a rendering mode that follows standards for most behavior while retaining a limited set of legacy compatibility rules.

14. Multiple Choice Questions (MCQs)

Q1. Which is the correct HTML5 DOCTYPE?

  1. <doctype html>
  2. <!DOCTYPE html>
  3. <html doctype>
  4. <!html>

Correct Answer: B. <!DOCTYPE html>

Q2. Where should the DOCTYPE declaration appear?

  1. After body
  2. Inside head
  3. Before the html element
  4. Inside footer

Correct Answer: C. Before the html element

Q3. What does DTD stand for?

  1. Document Type Definition
  2. Data Type Declaration
  3. Document Text Design
  4. Digital Type Definition

Correct Answer: A. Document Type Definition

Q4. Which mode is intended for modern standards-based rendering?

  1. Quirks mode
  2. Standards mode
  3. Legacy mode
  4. Compatibility mode only

Correct Answer: B. Standards mode

Q5. What can happen if DOCTYPE is omitted?

  1. The browser cannot open the file.
  2. The browser always displays an error.
  3. The browser may enter quirks mode.
  4. JavaScript is disabled.

Correct Answer: C. The browser may enter quirks mode.

Q6. Which JavaScript property helps identify quirks mode?

  1. document.title
  2. document.compatMode
  3. document.charset
  4. document.URL

Correct Answer: B. document.compatMode

Q7. Which value of document.compatMode indicates quirks mode?

  1. CSS1Compat
  2. HTML5
  3. BackCompat
  4. Standards

Correct Answer: C. BackCompat

Q8. Does HTML5 DOCTYPE contain a DTD URL?

  1. Yes, always
  2. No
  3. Only in CSS
  4. Only in JavaScript

Correct Answer: B. No

15. Lesson Summary

  • DOCTYPE stands for Document Type Declaration.
  • It is placed before the html root element.
  • The HTML5 declaration is <!DOCTYPE html>.
  • DOCTYPE is a declaration, not an HTML element.
  • Older HTML versions used longer declarations with DTD references.
  • DTD stands for Document Type Definition.
  • Standards mode supports modern standards-based rendering.
  • Quirks mode provides legacy browser compatibility.
  • Limited quirks mode preserves selected legacy behaviors.
  • document.compatMode helps identify full quirks mode.
