1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand HTML attributes and their purpose.
  • Understand attribute name-value pairs.
  • Identify global and element-specific attributes.
  • Understand single-quoted, double-quoted and unquoted values.
  • Understand Boolean attributes.
  • Use the id and class attributes.
  • Use the href, src and alt attributes.
  • Understand the style and title attributes.
  • Use custom data attributes.
  • Write HTML elements with appropriate attributes.

2. What are HTML Attributes?

HTML attributes provide additional information about HTML elements. They are written inside the opening tag of an element.

Example

<a href="https://example.com">
    Visit Example
</a>

In this example:

  • a is the HTML element name.
  • href is the attribute name.
  • "https://example.com" is the attribute value.

The href attribute specifies the destination of the hyperlink.

Remember: Attributes are generally written in the opening tag, not in the closing tag.

3. Syntax of HTML Attributes

The general syntax is:

<element attribute="value">
    Content
</element>

Example

<img src="photo.jpg" alt="A photograph">

Here:

  • img is the element.
  • src specifies the image resource.
  • alt provides alternative text.

4. Attribute Values and Quotation Marks

HTML allows attribute values to be written in different ways. Quoted values are generally recommended for readability and reliability.

A. Double Quotes

<input type="text" name="username">

B. Single Quotes

<input type='text' name='username'>

C. Unquoted Values

<input type=text name=username>

Unquoted values are permitted only when they satisfy HTML's restrictions. They cannot contain spaces or certain special characters.

Prefer double quotes around attribute values. They make HTML easier to read and help prevent accidental parsing errors.

5. Multiple Attributes in One Element

An HTML element can contain multiple attributes.

Example

<img src="logo.png"
     alt="Company Logo"
     width="200"
     height="100">

Here the image element contains four attributes:

  1. src
  2. alt
  3. width
  4. height

Attributes are separated by whitespace. Their order generally does not affect their meaning.

6. Global Attributes

Global attributes can be used on most HTML elements. They provide common information or behavior.

Common Global Attributes

Attribute Purpose
id Provides a unique identifier for an element.
class Assigns one or more class names to an element.
style Applies inline CSS declarations.
title Provides advisory information about an element.
lang Specifies the language of an element's content.
hidden Indicates that an element is not currently relevant for display.
tabindex Controls an element's sequential keyboard focus behavior.
contenteditable Indicates whether the element's content can be edited.
draggable Indicates whether an element can be dragged.
data-* Stores custom data on an element.

7. The ID Attribute

The id attribute assigns an identifier to an HTML element. An id should be unique within the document.

Example

<h1 id="main-heading">
    Welcome to HTML5
</h1>

<p id="intro">
    Learn HTML step by step.
</p>

An id can be used by CSS, JavaScript and URL fragments to identify a particular element.

Using ID with CSS

<style>
    #main-heading {
        color: blue;
    }
</style>

Using ID with JavaScript

document.getElementById("intro").textContent =
    "Welcome to the HTML course.";
Avoid assigning the same id to multiple elements in one document. Use class when you need to identify a group of elements.

8. The CLASS Attribute

The class attribute assigns one or more class names to an element. Multiple elements can share the same class.

Example

<p class="highlight">First paragraph</p>

<p class="highlight">Second paragraph</p>

<h2 class="highlight">Important Heading</h2>

Using Class with CSS

<style>
    .highlight {
        color: darkblue;
        background-color: lightyellow;
    }
</style>

A single element can also have multiple class names. 

<p class="highlight important">
    Important information
</p>
ID: Used for a unique element identifier.
CLASS: Used to group elements for shared styling or scripting.

9. The HREF Attribute

The href attribute specifies the destination URL of a hyperlink.

Example

<a href="https://www.google.com">
    Visit Google
</a>

Relative URL Example

<a href="about.html">
    About Us
</a>

Email Link

<a href="mailto:info@example.com">
    Send Email
</a>

The href attribute is commonly used with the anchor element and link element, but its exact meaning depends on the element.

10. The SRC Attribute

The src attribute specifies the URL of an external resource to embed or load.

Image Example

<img src="images/photo.jpg" alt="A landscape">

Audio Example

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

Video Example

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
</video>

The src attribute is used by elements such as img, script, iframe, audio and video.

11. The ALT Attribute

The alt attribute provides alternative text for an image. This text can be used when the image cannot be displayed and by assistive technologies such as screen readers.

Example

<img src="computer.jpg"
     alt="A desktop computer on a table">

Decorative Image

<img src="decoration.png" alt="">

An empty alt value is appropriate for a purely decorative image that does not add meaningful information.

Write meaningful alternative text that describes the purpose or information conveyed by the image. Avoid using filenames as alternative text.

12. The STYLE Attribute

The style attribute is used to apply inline CSS directly to an HTML element.

Example

<h1 style="color: blue;">
    Welcome to HTML
</h1>

<p style="font-size: 18px; color: green;">
    Learn HTML attributes.
</p>

Inline CSS affects the presentation of the element. For larger projects, external stylesheets are generally easier to maintain.

13. The TITLE Attribute

The title attribute provides advisory information about an element.

Example

<p title="This is additional information">
    Move the pointer over this text.
</p>

Browsers commonly display the title value as a tooltip when a pointer hovers over the element.

Do not rely on title tooltips as the only way to provide important information. They may not be available to all users or devices.

14. Boolean Attributes

Boolean attributes represent true or false states. Their presence indicates true, and their absence indicates false.

Examples

<input type="text" required>

<input type="checkbox" checked>

<button disabled>Submit</button>

<video controls></video>

Common Boolean Attributes

Attribute Purpose
required Indicates that a form control must be completed.
disabled Disables a form control or button.
checked Indicates that a checkbox or radio button is selected by default.
readonly Prevents the user from editing the control's value.
multiple Allows multiple values or selections where supported.
autofocus Requests automatic focus when the page loads.
hidden Indicates that an element is not currently relevant for display.

Boolean Attribute Syntax

<button disabled>Submit</button>

<button disabled="">Submit</button>

<button disabled="disabled">Submit</button>

These forms all represent a present disabled attribute. Writing disabled="false" does not make it false; the attribute is still present.

15. Custom Data Attributes (data-*)

Custom data attributes allow developers to store application-specific data on HTML elements.

Example

<button id="product"
        data-product-id="101"
        data-category="electronics">
    View Product
</button>

Custom data attributes begin with data-.

Accessing Data Attributes with JavaScript

const product = document.getElementById("product");

console.log(product.dataset.productId);

console.log(product.dataset.category);

JavaScript exposes these attributes through the element's dataset property.

HTML data attributes are useful for storing small pieces of custom information associated with an element. Do not store sensitive information in them.

16. Element-Specific Attributes

Some attributes are designed for particular HTML elements.

Element Attribute Purpose
<img> src Specifies the image URL.
<img> alt Provides alternative text.
<a> href Specifies the hyperlink destination.
<input> type Specifies the input control type.
<input> placeholder Displays a short input hint.
<form> action Specifies where form data is submitted.
<form> method Specifies the HTTP method used for submission.
<script> src Specifies the external script URL.
<video> controls Displays media playback controls.

20. Common Mistakes

Mistake Correct Practice
Writing attributes outside the opening tag. Place attributes inside the opening tag.
Using spaces in an unquoted attribute value. Use quotation marks around values containing spaces.
Repeating the same id across multiple elements. Use unique ids within a document.
Using src for an anchor destination. Use href for an anchor destination.
Using href for an image source. Use src for an image source.
Leaving meaningful images without alternative text. Provide useful alt text.
Writing disabled="false" to enable a button. Remove the disabled attribute to enable it.
Using the same class and id interchangeably. Use class for groups and id for unique identification.

21. Interview Questions and Answers

Q1. What are HTML attributes?

Attributes provide additional information or configure the behavior of HTML elements.

Q2. Where are attributes written?

Attributes are generally written inside the opening tag.

Q3. What is the general syntax of an attribute?

The general syntax is name="value".

Q4. What is the difference between id and class?

An id identifies a particular element uniquely within a document, while a class can be shared by multiple elements.

Q5. What is the purpose of href?

The href attribute specifies the destination URL of a hyperlink.

Q6. What is the purpose of src?

The src attribute specifies the URL of an external resource used by an element.

Q7. What is the purpose of alt?

The alt attribute provides alternative text for images.

Q8. What are global attributes?

Global attributes are attributes that can be used on most HTML elements.

Q9. What are Boolean attributes?

Boolean attributes represent true or false states. Their presence means true; their absence means false.

Q10. What are data attributes?

Data attributes are custom attributes beginning with data- that store application-specific information.

22. Multiple Choice Questions (MCQs)

Q1. Where are HTML attributes written?

  1. Inside the closing tag
  2. Inside the opening tag
  3. Outside the element
  4. Inside the browser window

Correct Answer: B. Inside the opening tag

Q2. Which attribute specifies a hyperlink destination?

  1. src
  2. alt
  3. href
  4. id

Correct Answer: C. href

Q3. Which attribute provides alternative text for an image?

  1. title
  2. alt
  3. class
  4. style

Correct Answer: B. alt

Q4. Which attribute should be unique within an HTML document?

  1. class
  2. style
  3. id
  4. title

Correct Answer: C. id

Q5. Which attribute can be shared by multiple elements?

  1. class
  2. id
  3. src
  4. href

Correct Answer: A. class

Q6. Which of the following is a Boolean attribute?

  1. href
  2. src
  3. disabled
  4. alt

Correct Answer: C. disabled

Q7. Which prefix is used for custom data attributes?

  1. custom-
  2. data-
  3. info-
  4. value-

Correct Answer: B. data-

Q8. Which attribute applies inline CSS?

  1. class
  2. id
  3. style
  4. lang

Correct Answer: C. style

Q9. What happens when a Boolean attribute is present?

  1. It is always false.
  2. It represents true.
  3. It is ignored.
  4. It creates a new element.

Correct Answer: B. It represents true.

Q10. Which property is used in JavaScript to access data-* attributes?

  1. element.class
  2. element.dataset
  3. element.href
  4. element.title

Correct Answer: B. element.dataset
