2. What is an HTML Tag?

An HTML tag is a markup instruction written inside angle brackets. Tags are used to mark the beginning and, where applicable, the end of an HTML element.

Example

<p>

The above is a paragraph start tag. It indicates the beginning of a paragraph element.

Another Example

<h1>Welcome to HTML5</h1>

Here, <h1> is the start tag and </h1> is the end tag.

Remember: Tags are written using angle brackets: < and >.

3. What is an HTML Element?

An HTML element is a component of an HTML document. For a typical non-void element, it consists of:

  • Start tag
  • Content
  • End tag

Example

<p>HTML is easy to learn.</p>

In this example:

Part HTML Code Meaning
Start tag <p> Begins the paragraph.
Content HTML is easy to learn. Text inside the element.
End tag </p> Ends the paragraph.

Together, the start tag, content and end tag form a paragraph element.

4. Difference Between HTML Tag and HTML Element

HTML Tag HTML Element
A markup delimiter and element name enclosed in angle brackets. A complete component in the document structure.
Example: <p> Example: <p>Hello</p>
Marks the start or end of an element. Includes the element's tags and content, where applicable.
A tag is part of an element. An element is the complete structural component represented by its markup.

5. Opening Tag and Closing Tag

A. Opening Tag (Start Tag)

<h1>

An opening tag marks the beginning of an element.

B. Closing Tag (End Tag)

</h1>

A closing tag marks the end of an element's content and is written with a forward slash before the name.

Complete Example

<h1>Introduction to HTML</h1>

<p>HTML is a markup language.</p>

The h1 and p elements both have opening and closing tags.

6. Container Elements

Container elements are elements that have an opening tag, content and a closing tag.

Examples

<h1>HTML Tutorial</h1>

<p>Learn HTML step by step.</p>

<div>
    This is a container.
</div>

<strong>Important text</strong>

Common container elements include:

  • <html>
  • <head>
  • <body>
  • <h1> to <h6>
  • <p>
  • <div>
  • <span>
  • <a>
  • <strong>

7. Empty Elements and Void Elements

Some HTML elements do not contain child content and do not have closing tags. These are called void elements in HTML.

Examples of Void Elements

<br>
<hr>
<img src="photo.jpg" alt="A photograph">
<input type="text">
<meta charset="UTF-8">
<link rel="stylesheet" href="style.css">
Element Purpose
<br> Inserts a line break.
<hr> Represents a thematic break.
<img> Embeds an image.
<input> Creates a form input control.
<meta> Provides metadata.
<link> References an external resource.
<source> Provides a media resource for audio, video or picture.
Important: Void elements must not have end tags in HTML. For example, use <br>, not <br></br>.

Self-Closing Syntax

<img src="logo.png" alt="Logo">

<!-- XML-style slash is also accepted in HTML syntax,
     but it does not make the element self-closing. -->
<img src="logo.png" alt="Logo" />

In HTML, the trailing slash is unnecessary for void elements. HTML does not use XML-style self-closing syntax for ordinary non-void elements.

8. Nested HTML Elements

An HTML element placed inside another HTML element is called a nested element.

Example

<div>
    <h2>HTML Course</h2>

    <p>
        Learn <strong>HTML5</strong> step by step.
    </p>
</div>

In this example:

  • The div element is the parent element.
  • The h2 element is a child of div.
  • The p element is another child of div.
  • The strong element is nested inside p.
Proper nesting is important for creating a valid, predictable document structure.

9. Correct and Incorrect Nesting

Correct Nesting

<p>
    This is <strong>important</strong> text.
</p>

The strong element is closed before the paragraph ends.

Incorrect Nesting

<p>
    This is <strong>important</p>
</strong>

The paragraph closes before the strong element. This is a misnested structure.

Always close nested elements in the reverse order in which they were opened, where end tags are required.

10. Block-Level and Inline Elements

In traditional HTML teaching, elements are often described as block-level or inline elements. These terms describe common layout behavior.

A. Block-Level Elements

Block-level elements traditionally begin on a new line and occupy the available width of their containing block by default.

Examples

  • <div>
  • <p>
  • <h1> to <h6>
  • <ul>
  • <ol>
  • <section>
  • <article>

B. Inline Elements

Inline elements generally flow within a line of text and do not start a new line by default.

Examples

  • <span>
  • <a>
  • <strong>
  • <em>
  • <img>
  • <code>

Comparison

Block-Level Inline
Traditionally starts on a new line. Flows within the current line.
Typically occupies available width by default. Typically occupies only the space required by its content.
Examples: div, p, section. Examples: span, a, strong.
Modern HTML and CSS Note: Block and inline are CSS display concepts, not fixed categories of HTML elements. CSS can change an element's display behavior. HTML semantics and CSS layout should be understood separately.

11. HTML Elements with Attributes

Attributes provide additional information about an element. They are written inside the opening tag.

Example

<a href="https://example.com">
    Visit Example
</a>

In this example:

  • a is the element name.
  • href is the attribute name.
  • "https://example.com" is the attribute value.

Attributes are covered in detail in the next lesson.

12. HTML Elements and DOM Structure

When a browser parses HTML, it creates a Document Object Model (DOM) tree representing the document's structure.

Example HTML

<body>
    <h1>Welcome</h1>
    <p>Learn HTML5</p>
</body>

Simplified DOM Tree

Document
   |
   └── html
       |
       └── body
           |
           ├── h1
           |    |
           |    └── "Welcome"
           |
           └── p
                |
                └── "Learn HTML5"

The DOM represents elements and text as nodes. JavaScript can access and modify these nodes.

15. Interview Questions and Answers

Q1. What is an HTML tag?

An HTML tag is markup written inside angle brackets that marks the start or end of an element.

Q2. What is an HTML element?

An HTML element is a component of an HTML document, generally consisting of a start tag, content and an end tag.

Q3. What is the difference between a tag and an element?

A tag is a markup part of an element. An element is the complete structural component.

Q4. What is a void element?

A void element is an HTML element that cannot have child nodes and does not have an end tag.

Q5. Give examples of void elements.

Examples include br, hr, img, input, meta and link.

Q6. What is a nested element?

An element placed inside another element is called a nested element.

Q7. What is a parent element?

A parent element is an element that directly contains another element.

Q8. What is a child element?

A child element is an element directly contained within another element.

Q9. What is the difference between block and inline elements?

Block elements typically start on a new line, whereas inline elements flow within the current line by default. CSS can change this behavior.

Q10. What is the DOM?

DOM stands for Document Object Model. It represents an HTML document as a tree of nodes.

16. Multiple Choice Questions (MCQs)

Q1. Which brackets are used to write HTML tags?

  1. Square brackets
  2. Curly brackets
  3. Angle brackets
  4. Round brackets

Correct Answer: C. Angle brackets

Q2. Which is the correct paragraph element?

  1. <p>Hello</p>
  2. <p>Hello
  3. </p>Hello<p>
  4. <paragraph>Hello</paragraph>

Correct Answer: A. <p>Hello</p>

Q3. Which of the following is a void element?

  1. <div>
  2. <p>
  3. <img>
  4. <strong>

Correct Answer: C. <img>

Q4. Which symbol is used in a closing tag?

  1. Forward slash
  2. Backslash
  3. Hash
  4. At symbol

Correct Answer: A. Forward slash

Q5. Which element is commonly used as a generic block container?

  1. <span>
  2. <div>
  3. <br>
  4. <img>

Correct Answer: B. <div>

Q6. Which element is commonly used as a generic inline container?

  1. <div>
  2. <section>
  3. <span>
  4. <hr>

Correct Answer: C. <span>

Q7. Which of the following is a correct nesting structure?

  1. <p><strong>Text</p></strong>
  2. <p><strong>Text</strong></p>
  3. </strong><p>Text</p>
  4. <p></strong>Text</p>

Correct Answer: B

Q8. Which element inserts a line break?

  1. <hr>
  2. <br>
  3. <break>
  4. <line>

Correct Answer: B. <br>

17. Lesson Summary

  • HTML tags are written inside angle brackets.
  • An HTML element is a structural component of a document.
  • Most HTML elements have opening and closing tags.
  • Void elements do not have closing tags or child nodes.
  • Nested elements create parent-child relationships.
  • Proper nesting helps maintain valid document structure.
  • Block and inline describe common CSS display behavior.
  • Attributes provide additional information about elements.
  • The browser builds a DOM tree from parsed HTML.
