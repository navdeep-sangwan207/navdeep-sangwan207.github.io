Chapter 2: HTML Document Structure

HTML5 – Complete Study Course

Chapter Overview

In this chapter, you will learn the fundamental structure of an HTML document. You will understand the DOCTYPE declaration, HTML head and body elements, HTML tags, elements, attributes, nesting and comments. You will also learn how to create and save HTML files.

Learning Objectives

  • Understand the basic structure of an HTML document.
  • Learn the purpose of the DOCTYPE declaration.
  • Understand the HTML, head and body elements.
  • Differentiate between HTML tags and elements.
  • Understand HTML attributes and their usage.
  • Learn how to nest HTML elements correctly.
  • Understand HTML comments.
  • Create, save and open HTML files in a browser.
