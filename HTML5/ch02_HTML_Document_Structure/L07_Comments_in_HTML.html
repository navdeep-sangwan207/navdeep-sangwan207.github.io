After completing this lesson, you will be able to:

  • Understand HTML comments and their purpose.
  • Write single-line and multi-line comments.

  • Understand how browsers handle comments.
  • Identify common comment syntax errors.
  • Follow HTML comment best practices.

2. What are HTML Comments?

HTML comments are notes written inside HTML source code. They are not displayed as normal page content in the browser.

Developers use comments to explain code, identify sections, add reminders and temporarily exclude markup from rendering.

Example

<!-- This is an HTML comment -->

<h1>Welcome to HTML5</h1>

The browser displays the heading but does not display the comment as visible page content.

Remember: HTML comments are written between <!-- and -->.

3. Syntax of HTML Comments

The general syntax is:

<!-- Comment text goes here -->

Explanation:

  • <!-- starts the comment.
  • Comment text contains the comment content.
  • --> ends the comment.

Example

<!-- Main heading of the page -->

<h1>My Website</h1>

4. Single-Line Comments

A single-line comment contains a short note written on one line.

Example

<!-- This is the main heading -->
<h1>HTML Learning</h1>

Single-line comments are useful for short explanations or identifying individual elements.

5. Multi-Line Comments

A multi-line comment extends across multiple lines. HTML uses the same comment delimiters for both single-line and multi-line comments.

Example

<!--
    Website Name: NS Learning Hub
    Course: HTML5
    Chapter: HTML Document Structure
    Purpose: Educational learning portal
-->

<h1>Welcome to NS Learning Hub</h1>

Multi-line comments are useful for documenting larger sections of code.

6. Adding Comments to HTML Sections

Comments can be used to identify different sections of a web page.

Example

<body>

    <!-- Website Header -->

    <header>
        <h1>My Website</h1>
    </header>


    <!-- Main Navigation -->

    <nav>
        <a href="index.html">Home</a>
        <a href="about.html">About</a>
    </nav>


    <!-- Main Content -->

    <main>
        <h2>Welcome</h2>
        <p>Welcome to our website.</p>
    </main>


    <!-- Website Footer -->

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>

7. Temporarily Hiding HTML Elements

HTML comments can temporarily exclude markup from being rendered by the browser.

Example

<h1>Welcome to HTML5</h1>

<!--
<p>This paragraph is temporarily hidden.</p>
-->

<p>This paragraph is visible.</p>

Expected Browser Output

Welcome to HTML5

This paragraph is visible.

The paragraph inside the comment is not rendered as normal page content.

Comments are not a security mechanism. Commented-out content remains in the HTML source and can be viewed using browser developer tools or page source.

8. HTML Comments and Browser Processing

When a browser parses an HTML document, it recognizes comments as markup comments rather than normal visible page content.

Comments are represented in the DOM as comment nodes, but they are not rendered as ordinary text on the page.

Example

<!-- Page heading -->

<h1>Welcome</h1>

The heading becomes an element in the DOM. The comment can also be represented as a comment node.

9. HTML Comments in the HEAD Section

Comments can be written inside the head section to explain metadata or resource references.

Example

<head>

    <!-- Character encoding -->
    <meta charset="UTF-8">

    <!-- Responsive viewport -->
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <!-- Page title -->
    <title>My Website</title>

</head>

10. HTML Comments in CSS and JavaScript

HTML, CSS and JavaScript use different comment syntaxes. Their comment formats should not be confused.

Language Single-Line Comment Multi-Line Comment
HTML <!-- Comment --> <!-- Comment -->
CSS /* Comment */ /* Comment */
JavaScript // Comment /* Comment */

HTML Comment

<!-- This is an HTML comment -->

CSS Comment

<style>

    /* This is a CSS comment */

    body {
        background-color: lightblue;
    }

</style>

JavaScript Comment

<script>

    // This is a JavaScript comment

    /*
       This is a
       multi-line JavaScript comment
    */

    console.log("Hello HTML");

</script>

11. HTML Comments Cannot Be Nested

HTML comments do not support nested comment blocks. Starting another comment inside an existing comment can cause unexpected parsing results.

Incorrect Example

<!-- Outer comment

    <!-- Inner comment -->

    More text

-->

The inner comment closing delimiter can terminate the outer comment unexpectedly.

Correct Approach

<!--
    Outer explanation

    Inner explanation written as ordinary text

-->
Avoid placing HTML comment delimiters inside another HTML comment. HTML comments cannot be nested.

12. Common HTML Comment Mistakes

Incorrect Syntax Correct Syntax
<!-- Comment -- <!-- Comment -->
<! Comment --> <!-- Comment -->
<!-- Comment --!> <!-- Comment -->
Nesting one HTML comment inside another. Use separate, properly closed comments.
Assuming comments hide confidential information. Never put secrets in HTML comments.

13. Best Practices for HTML Comments

  • Write comments that explain the purpose of code.
  • Use comments to identify large page sections.
  • Keep comments short and meaningful.
  • Update comments when the related code changes.
  • Avoid unnecessary comments for obvious markup.
  • Do not place passwords, API keys or confidential information in comments.
  • Do not use comments as a substitute for proper documentation.
  • Avoid nested comment delimiters.

Create a file named comments_example.html.

Program

          content="width=device-width, initial-scale=1.0">

            color: blue;

            background-color: lightyellow;
            padding: 10px;
        }

<body>

    <!-- Main heading -->

    <h1>Welcome to NS Learning Hub</h1>


    <!-- Course introduction -->

17. Interview Questions and Answers

Q1. What are HTML comments?

HTML comments are notes written in source code that are not displayed as normal page content.

Q2. What is the syntax of an HTML comment?

<!-- Comment text -->

Q3. Are HTML comments visible in the browser?

They are not displayed as ordinary page content, but users can inspect them in the page source or developer tools.

Q4. Can HTML comments span multiple lines?

Yes. The same opening and closing delimiters can enclose comments spanning multiple lines.

Q5. Can HTML comments be nested?

No. HTML comments do not support nested comment blocks.

Q6. What is the purpose of HTML comments?

They help explain code, identify sections, add development notes and temporarily exclude markup.

Q7. What is the difference between HTML and CSS comments?

HTML comments use <!-- -->, while CSS comments use /* */.

Q8. Do HTML comments become DOM nodes?

Yes. The browser can represent comments as comment nodes in the DOM, although they are not rendered as ordinary page text.

Q9. Can comments be used to hide confidential information?

No. Comments remain available in the HTML source and should never contain passwords or secrets.

Q10. Can comments be used inside the head section?

Yes. Comments can be placed in both the head and body sections.

19. Lesson Summary

  • HTML comments are notes written in source code.
  • Comments use the syntax <!-- -->.
  • Comments are not displayed as normal page content.
  • Single-line and multi-line comments use the same syntax.
  • Comments can document different page sections.
  • Comments can temporarily exclude markup from rendering.
  • HTML comments cannot be nested.
  • Comments can be inspected using developer tools.
  • Never store confidential information in comments.
  • HTML, CSS and JavaScript have different comment syntaxes.
