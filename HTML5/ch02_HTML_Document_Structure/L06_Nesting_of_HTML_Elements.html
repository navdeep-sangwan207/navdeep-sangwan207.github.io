2. What is Nesting in HTML?

Nesting in HTML means placing one HTML element inside another HTML element.

An element containing another element is called the parent element, while the element placed inside it is called the child element.

Example

<div>
    <p>This is a paragraph.</p>
</div>

In this example:

  • div is the parent element.
  • p is the child element.
Remember: Nesting creates a hierarchical structure in an HTML document.

3. Parent and Child Elements

A parent element directly contains another element. The contained element is its child.

Example

<section>

    <h2>About Us</h2>

    <p>
        We provide educational resources.
    </p>

</section>

Relationship:

  • section is the parent of h2.
  • section is the parent of p.
  • h2 and p are siblings.

4. Understanding the HTML Element Hierarchy

HTML documents contain hierarchical relationships. Elements can have parents, children, siblings, ancestors and descendants.

Example

<div>

    <section>

        <h2>HTML Learning</h2>

        <p>
            Learn HTML step by step.
        </p>

    </section>

</div>

Element Relationships

Relationship Meaning
Parent An element that directly contains another element.
Child An element directly contained inside another element.
Sibling Elements that share the same parent.
Ancestor Any element higher in the hierarchy.
Descendant Any element nested inside another element, directly or indirectly.

5. Multiple Levels of Nesting

HTML elements can be nested at multiple levels. An element can be a child of one element and a parent of another element.

Example

<div>

    <section>

        <article>

            <h2>Introduction to HTML</h2>

            <p>
                HTML is used to structure web pages.
            </p>

        </article>

    </section>

</div>

Hierarchy:

  • div
    • section
      • article
        • h2
        • p

Here, the article element is a child of section and a descendant of div.

6. Proper Nesting Rules

HTML elements should follow the correct nesting order. An element must be closed before its parent element is closed.

Correct Nesting

<div>

    <p>
        This is a
        <strong>correctly nested</strong>
        paragraph.
    </p>

</div>

Incorrect Nesting

<div>

    <p>
        This is a
        <strong>paragraph.
    </p>

    </strong>

</div>

In the incorrect example, the strong element is closed after the paragraph has already been closed. The elements overlap instead of being properly nested.

Important Rule: Close nested elements in the reverse order in which they were opened.

Remember the Opening and Closing Order

Opening order:

<div>
    <p>
        <strong>

Closing order:

        </strong>
    </p>
</div>

7. Nesting Text Formatting Elements

Text formatting elements can be nested inside paragraphs and other suitable text containers.

Example

<p>
    HTML is a
    <strong>
        <em>very important</em>
    </strong>
    web technology.
</p>

Here:

  • p contains the text and strong element.
  • strong contains the em element.
  • em emphasizes the text.

Expected Output

HTML is a very important web technology.

8. Nesting Lists

One list can be nested inside a list item of another list. This is useful for creating hierarchical lists.

Example

<ul>

    <li>Programming Languages
        <ul>
            <li>C</li>
            <li>C++</li>
            <li>Java</li>
        </ul>
    </li>

    <li>Web Technologies
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

</ul>

Expected Output

  • Programming Languages
    • C
    • C++
    • Java
  • Web Technologies
    • HTML
    • CSS
    • JavaScript
A nested list should be placed inside an li element of the parent list.

9. Nesting HTML Elements in Tables

HTML tables contain a hierarchy of table-related elements. Table rows contain table cells, and cells can contain other suitable HTML elements.

Example

<table border="1">

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>
            <strong>HTML5</strong>
        </td>
    </tr>

</table>

Expected Output

Name Course
Rahul HTML5

10. Nesting Semantic HTML Elements

Semantic elements describe the meaning and purpose of different sections of a web page. They can be nested to organize page content.

Example

<main>

    <section>

        <h2>Web Development</h2>

        <article>

            <h3>Introduction to HTML</h3>

            <p>
                HTML provides structure to web pages.
            </p>

        </article>

    </section>

</main>

This structure uses main, section and article elements to organize the page content.

11. What is the DOM Tree?

DOM stands for Document Object Model. It is a programming interface that represents an HTML document as a hierarchical tree of nodes.

When a browser parses HTML, it constructs a DOM tree representing the document structure.

Example HTML

<html>

    <body>

        <h1>Welcome</h1>

        <p>Learn HTML</p>

    </body>

</html>

Simplified DOM Tree

Document
   |
   └── html
        |
        └── body
             |
             ├── h1
             |    |
             |    └── "Welcome"
             |
             └── p
                  |
                  └── "Learn HTML"

Each HTML element is represented by an element node. Text inside elements is represented by text nodes.

Important: HTML nesting describes the source document's element hierarchy. The DOM is the browser's object representation of that document.

12. Parent-Child Relationships in the DOM

JavaScript can access parent, child and sibling relationships through DOM properties.

Example HTML

<div id="container">

    <p id="message">
        Hello HTML
    </p>

</div>

JavaScript Example

const message = document.getElementById("message");

console.log(message.parentElement);

console.log(message.children);

console.log(message.parentElement.id);

Common DOM properties include:

Property Purpose
parentElement Returns the parent element.
children Returns the child elements.
firstElementChild Returns the first child element.
lastElementChild Returns the last child element.
nextElementSibling Returns the next sibling element.
previousElementSibling Returns the previous sibling element.

13. HTML Elements That Cannot Be Nested Arbitrarily

Not every HTML element can be placed inside every other HTML element. HTML defines content models that specify which kinds of content are permitted.

Example 1 – Paragraph Element

<p>
    This is a paragraph.
    <p>This is another paragraph.</p>
</p>

A paragraph cannot contain another paragraph. When the browser encounters the second opening p tag, it implicitly closes the first paragraph.

Example 2 – Anchor Elements

<a href="page1.html">
    First Link
    <a href="page2.html">Second Link</a>
</a>

An anchor element cannot contain another anchor element. Nested interactive links are invalid.

Browsers often try to recover from invalid HTML, but automatic error recovery does not make the source markup correct. Follow the HTML content model.

14. Common Nesting Errors

Incorrect Practice Correct Practice
Closing a parent before its child. Close child elements before parent elements.
Nesting a p element inside another p element. Use separate paragraph elements.
Nesting an anchor inside another anchor. Use separate anchor elements.
Placing a nested list directly inside ul. Place the nested list inside an li element.
Using elements in invalid parent-child combinations. Follow HTML content model rules.
Leaving required closing tags out of the markup. Write explicit closing tags where required.

18. Interview Questions and Answers

Q1. What is nesting in HTML?

Nesting means placing one HTML element inside another HTML element.

Q2. What is a parent element?

A parent element is an element that directly contains another element.

Q3. What is a child element?

A child element is an element directly contained inside another element.

Q4. What are sibling elements?

Sibling elements are elements that share the same parent element.

Q5. What is the correct nesting rule?

Elements should be closed in the reverse order in which they were opened.

Q6. What is the DOM?

DOM stands for Document Object Model. It represents a document as a hierarchical tree of nodes.

Q7. Can a paragraph contain another paragraph?

No. A p element cannot contain another p element.

Q8. Where should a nested list be placed?

A nested list should be placed inside an li element of the parent list.

Q9. What is the difference between a child and a descendant?

A child is directly contained by its parent. A descendant can be nested at any depth below an ancestor.

Q10. Does a browser always display invalid nesting exactly as written?

No. Browsers may automatically repair malformed markup during HTML parsing, so the resulting DOM may differ from the source code.

20. Lesson Summary

  • Nesting means placing one HTML element inside another.
  • A parent directly contains its child elements.
  • Sibling elements share the same parent.
  • Ancestors and descendants describe relationships at different hierarchy levels.
  • Nested elements should be closed in reverse opening order.
  • Lists can contain nested lists inside list items.
  • HTML elements must follow their permitted content models.
  • The browser constructs a DOM tree from parsed HTML.
  • JavaScript can access parent, child and sibling relationships.
  • Browsers may recover from invalid markup, but valid nesting is essential.
