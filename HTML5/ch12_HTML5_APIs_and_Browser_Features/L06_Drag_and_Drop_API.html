Lesson 6: Drag and Drop API

Chapter 12: HTML5 APIs and Browser Features

Learn how to move data and elements using browser-based drag-and-drop interactions.

1. Introduction to Drag and Drop API

HTML5 Drag and Drop API allows users to drag an element or data from one location and drop it into another location within a web page or between supported applications.

It provides events and a DataTransfer object that help developers manage the drag operation and transfer information.

Common applications include:

  • Moving items between lists.
  • Rearranging dashboard components.
  • Uploading files through a drop area.
  • Organizing tasks in project management tools.
  • Dragging images and text.
  • Building interactive educational applications.
The HTML Drag and Drop API is different from CSS positioning. CSS controls visual layout, while JavaScript drag events control the interaction and data transfer.

2. Basic Drag and Drop Concept

A typical drag-and-drop operation includes:

  1. Select an element to drag.
  2. Start dragging the element.
  3. Move it over a valid drop target.
  4. Allow the drop operation.
  5. Drop the element.
  6. Process the transferred data.

3. The draggable Attribute

The draggable attribute specifies whether an element can be dragged using the HTML Drag and Drop mechanism.

Syntax

<element draggable="true"> </element>

Possible values:

  • true: The element can be dragged.
  • false: The element cannot be dragged.
  • auto: Default behavior determined by the browser.

Example

<div draggable="true"> Drag this element </div> <img src="image.jpg" draggable="true" alt="Example image">
The draggable attribute is an enumerated attribute. Its value should be explicitly written as true or false. It is not a Boolean HTML attribute.

4. Important Drag and Drop Events

The browser generates events during different stages of a drag-and-drop operation.

Event Purpose
dragstart Fires when the user starts dragging an element.
drag Fires repeatedly while the element is being dragged.
dragend Fires when the drag operation ends.
dragenter Fires when the dragged item enters a drop target.
dragover Fires while the dragged item is over a drop target.
dragleave Fires when the dragged item leaves a drop target.
drop Fires when the dragged item is dropped on a valid target.

5. dragstart Event

The dragstart event occurs when the user begins dragging an element.

It is commonly used to place data into the DataTransfer object.

Example

<div id="item" draggable="true"> Drag Me </div> <script> const item = document.getElementById("item"); item.addEventListener("dragstart", function(event) { console.log("Dragging started."); }); </script>
Expected Output: 
Dragging started.

6. dragover Event

The dragover event fires repeatedly when a dragged item moves over a drop target.

By default, most HTML elements do not accept a drop. To make an element a valid drop target, prevent the default dragover behavior.

Example

const dropZone = document.getElementById("dropZone"); dropZone.addEventListener("dragover", function(event) { event.preventDefault(); });
Calling event.preventDefault() in the dragover handler is essential for the normal HTML drag-and-drop drop operation.

7. drop Event

The drop event fires when a dragged item is released over an eligible drop target.

The drop handler commonly retrieves the transferred information and processes it.

Example

dropZone.addEventListener("drop", function(event) { event.preventDefault(); console.log("Item dropped."); });

8. Understanding the DataTransfer Object

The DataTransfer object carries information during a drag-and-drop operation.

It is available through the dataTransfer property of drag events.

Accessing DataTransfer

event.dataTransfer

Important Methods

Method Purpose
setData() Stores data in the drag data store.
getData() Retrieves data from the drag data store.
clearData() Removes data of a specified type or all types.
setDragImage() Sets the image displayed during dragging.

Important Properties

  • types: Lists the available data formats.
  • files: Provides files involved in a file drag operation.
  • items: Provides the transferred data items.
  • effectAllowed: Specifies allowed drag operations.
  • dropEffect: Indicates the operation selected for a drop target.

9. setData() Method

setData() stores data in the drag data store under a specified format.

Syntax

event.dataTransfer.setData(format, data);

Example

event.dataTransfer.setData( "text/plain", "Hello HTML5" );

The format text/plain is commonly used for plain-text data.

10. getData() Method

getData() retrieves data stored under the specified format.

Syntax

event.dataTransfer.getData(format);

Example

const text = event.dataTransfer.getData("text/plain"); console.log(text);
Expected Output: 
Hello HTML5
Drag data is normally read in the drop handler, because access to transferred data is restricted during other stages of the drag operation.

11. clearData() Method

clearData() removes transferred data from the drag data store.

Syntax

event.dataTransfer.clearData(); event.dataTransfer.clearData("text/plain");
  • Without an argument, it removes all data types.
  • With a format, it removes data of that format.

12. setDragImage() Method

setDragImage() allows developers to customize the image displayed while an element is dragged.

Syntax

event.dataTransfer.setDragImage( imageElement, xOffset, yOffset );

Example

const image = new Image(); image.src = "drag-icon.png"; item.addEventListener("dragstart", function(event) { event.dataTransfer.setDragImage(image, 20, 20); });

The xOffset and yOffset values determine the position of the drag image relative to the pointer.

13. effectAllowed and dropEffect

effectAllowed

effectAllowed specifies which operations are permitted for the drag source.

Common values include:

  • none
  • copy
  • copyLink
  • copyMove
  • link
  • linkMove
  • move
  • all
  • uninitialized

dropEffect

dropEffect indicates the operation selected by the drop target.

Common values:

  • none
  • copy
  • link
  • move

Example

item.addEventListener("dragstart", function(event) { event.dataTransfer.effectAllowed = "move"; }); dropZone.addEventListener("dragover", function(event) { event.preventDefault(); event.dataTransfer.dropEffect = "move"; });

14. Complete Practical Program: Text Drag and Drop

This program transfers text from a draggable element into a drop target.

Complete HTML Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>HTML5 Drag and Drop</title> <style> #dragItem { width: 180px; padding: 15px; background: #174ea6; color: white; text-align: center; cursor: grab; } #dropZone { width: 300px; min-height: 120px; border: 2px dashed #174ea6; padding: 15px; margin-top: 20px; } </style> </head> <body> <h2>Drag and Drop Example</h2> <div id="dragItem" draggable="true"> Drag This Text </div> <div id="dropZone"> Drop Here </div> <script> const dragItem = document.getElementById("dragItem"); const dropZone = document.getElementById("dropZone"); dragItem.addEventListener("dragstart", function(event) { event.dataTransfer.setData( "text/plain", event.target.textContent ); event.dataTransfer.effectAllowed = "copy"; }); dropZone.addEventListener("dragover", function(event) { event.preventDefault(); }); dropZone.addEventListener("drop", function(event) { event.preventDefault(); const data = event.dataTransfer.getData("text/plain"); dropZone.textContent = "Dropped: " + data; }); </script> </body> </html>
Expected Result:
  1. A blue draggable text box appears.
  2. Drag it over the drop area.
  3. Release the mouse button.
  4. The drop area displays the transferred text.

16. Drag and Drop File Upload

HTML5 drag-and-drop events can also be used to accept files dropped from the user's operating system.

Important DataTransfer Property

event.dataTransfer.files

It provides a FileList containing the files involved in the drag operation.

Example

const dropZone = document.getElementById("dropZone"); dropZone.addEventListener("dragover", function(event) { event.preventDefault(); }); dropZone.addEventListener("drop", function(event) { event.preventDefault(); const files = event.dataTransfer.files; for (let i = 0; i < files.length; i++) { console.log(files[i].name); console.log(files[i].size); console.log(files[i].type); } });

File metadata can be inspected in the browser. Uploading the files to a server requires an additional network request.

17. Practical Program: File Drop Area

This program accepts files dropped into an area and displays their names and sizes.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>File Drop Area</title> <style> #dropArea { border: 2px dashed #174ea6; padding: 30px; text-align: center; width: 350px; } </style> </head> <body> <h2>Drop Files Here</h2> <div id="dropArea"> Drag files into this area. </div> <ul id="fileList"></ul> <script> const dropArea = document.getElementById("dropArea"); const fileList = document.getElementById("fileList"); dropArea.addEventListener("dragover", function(event) { event.preventDefault(); }); dropArea.addEventListener("drop", function(event) { event.preventDefault(); fileList.replaceChildren(); const files = event.dataTransfer.files; for (const file of files) { const listItem = document.createElement("li"); listItem.textContent = file.name + " - " + (file.size / 1024).toFixed(2) + " KB"; fileList.appendChild(listItem); } }); </script> </body> </html>
Expected Result:
  1. A file drop area appears.
  2. Drag one or more files from your computer.
  3. Drop them into the area.
  4. The file names and sizes are displayed.
This example only reads file metadata. It does not upload file contents to a server. Production upload systems must validate files on the server and enforce size and type restrictions.

18. Drag and Drop vs Clipboard API

Feature Drag and Drop API Clipboard API
Purpose Transfers data through drag-and-drop. Reads or writes clipboard data.
Interaction Drag and release. Copy and paste.
Events / Methods dragstart, dragover, drop. Clipboard read/write methods and events.
Data handling DataTransfer object. Clipboard interface.
Applications Reordering items, file drop areas. Copying and pasting text or other data.

19. Security Considerations

  • Do not trust transferred data automatically.
  • Validate file types and file sizes.
  • Do not insert untrusted data directly using innerHTML.
  • Use textContent for plain-text display.
  • Validate uploaded files on the server.
  • Do not assume file extensions guarantee file content.
  • Restrict permitted operations where appropriate.
Drag-and-drop data may originate outside the website. Treat transferred text, URLs and files as untrusted input.

20. Common Mistakes

  • Forgetting draggable="true" on a custom drag source.
  • Not calling preventDefault() in the dragover handler.
  • Forgetting preventDefault() in the drop handler.
  • Using different data formats in setData() and getData().
  • Trying to read drag data too early.
  • Assuming every element accepts dropped content by default.
  • Using innerHTML with untrusted transferred data.
  • Assuming a file drop automatically uploads files.

23. Interview Questions and Answers

Q1. What is the HTML5 Drag and Drop API?
It is a browser API that allows users to drag elements or data and drop them into supported target areas.
Q2. Which attribute makes an element draggable?
The draggable attribute with the value true.
Q3. What is the dragstart event?
It fires when a user starts dragging an element.
Q4. What is the dragover event?
It fires repeatedly while a dragged item is over a potential drop target.
Q5. Why is preventDefault() used in dragover?
It prevents the default behavior and allows the element to accept a normal drop operation.
Q6. What is the DataTransfer object?
It manages data and information transferred during drag-and-drop operations.
Q7. What is setData()?
It stores data in the drag data store using a specified data format.
Q8. What is getData()?
It retrieves transferred data using the specified format.
Q9. What is clearData()?
It removes data from the drag data store.
Q10. What is setDragImage()?
It specifies a custom image to display while an element is being dragged.
Q11. What is effectAllowed?
It specifies which drag operations are permitted by the drag source.
Q12. What is dropEffect?
It indicates the operation selected for the drop target, such as copy or move.
Q13. How can files be accessed during a drop?
Using event.dataTransfer.files.
Q14. Does dropping a file automatically upload it?
No. The application must implement a separate file-upload process.
Q15. Why should transferred data be validated?
Because transferred data can originate outside the application and must be treated as untrusted input.
