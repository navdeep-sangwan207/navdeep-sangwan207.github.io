Lesson 3: LocalStorage

Chapter 12: HTML5 APIs and Browser Features

Learn how to store, retrieve, update, and delete persistent data in a web browser.

1. Introduction to localStorage

localStorage is a browser storage mechanism provided by the Web Storage API. It allows JavaScript applications to save key-value data on the user's device.

Unlike temporary JavaScript variables, localStorage normally retains information even after the browser is closed and reopened.

Examples of information that can be stored:

  • User interface preferences.
  • Selected website theme.
  • Language preference.
  • Recently selected course.
  • Non-sensitive application settings.
localStorage is persistent browser storage, but users or browser policies can clear or restrict it. It should not be treated as permanent or guaranteed storage.

2. Characteristics of localStorage

  • Stores data as key-value pairs.
  • Both keys and values are strings.
  • Data is associated with a browser origin.
  • Data normally survives browser restarts.
  • Storage is accessible through JavaScript.
  • Operations are synchronous.
  • Storage capacity is limited by browser policies.
  • Data is not automatically sent to the web server.

Example

localStorage.setItem("username", "Student"); console.log( localStorage.getItem("username") );
Expected Output: 
Student

3. Accessing localStorage

The localStorage object is available through the browser's window object.

window.localStorage

Because window is the global object in a browser page, the following shorter form is also valid:

localStorage

Checking Availability

if ("localStorage" in window) { console.log("localStorage is available."); } else { console.log("localStorage is not available."); }

Checking for the API is useful, although actual storage operations can still fail because of browser restrictions or quota limits.

4. setItem() Method

The setItem() method stores a key-value pair in localStorage.

Syntax

localStorage.setItem(key, value);

Example

localStorage.setItem("username", "Rahul"); localStorage.setItem("course", "HTML5"); localStorage.setItem("city", "Chandigarh");

Explanation

  • username is a key.
  • Rahul is its value.
  • course is another key.
  • HTML5 is its value.
Stored Data: 
username = Rahul
course = HTML5
city = Chandigarh

5. getItem() Method

The getItem() method retrieves the value associated with a specified key.

Syntax

localStorage.getItem(key);

Example

localStorage.setItem("username", "Rahul"); const name = localStorage.getItem("username"); console.log(name);
Expected Output: 
Rahul

When a Key Does Not Exist

const result = localStorage.getItem("email"); console.log(result);
Expected Output: 
null

If the requested key does not exist, getItem() returns null.

6. Updating Stored Data

To update an existing value, call setItem() again using the same key.

Example

// Store initial value localStorage.setItem("username", "Rahul"); // Update the value localStorage.setItem("username", "Amit"); // Retrieve updated value console.log( localStorage.getItem("username") );
Expected Output: 
Amit

If a key already exists, setItem() replaces its associated value. It does not create a second entry with the same key.

7. removeItem() Method

The removeItem() method deletes a particular key-value pair from localStorage.

Syntax

localStorage.removeItem(key);

Example

localStorage.setItem("username", "Rahul"); localStorage.removeItem("username"); console.log( localStorage.getItem("username") );
Expected Output: 
null

The key is removed, so getItem() returns null.

8. clear() Method

The clear() method removes all key-value entries from the localStorage area belonging to the current origin.

Syntax

localStorage.clear();

Example

localStorage.setItem("username", "Rahul"); localStorage.setItem("course", "HTML5"); localStorage.setItem("city", "Chandigarh"); // Remove all entries localStorage.clear(); console.log(localStorage.length);
Expected Output: 
0
clear() removes every entry in localStorage for the current origin, not just entries created by the current webpage's script. Use it carefully.

9. length Property

The length property returns the number of key-value entries currently stored.

Example

localStorage.setItem("name", "Rahul"); localStorage.setItem("course", "HTML5"); localStorage.setItem("city", "Chandigarh"); console.log(localStorage.length);
Expected Output: 
3

10. key() Method

The key() method returns the key name at a specified storage index.

Syntax

localStorage.key(index);

Example

localStorage.setItem("username", "Rahul"); localStorage.setItem("course", "HTML5"); console.log(localStorage.key(0)); console.log(localStorage.key(1));
Possible Output: 
username
course

Storage key ordering should not be used as a dependable application-level sorting mechanism.

11. Complete localStorage Methods

Method / Property Purpose Example
setItem() Stores or updates a value. setItem("name", "Rahul")
getItem() Retrieves a value. getItem("name")
removeItem() Removes one entry. removeItem("name")
clear() Removes all entries. clear()
key() Gets a key by index. key(0)
length Gets the number of entries. localStorage.length

12. Storing Numbers and Boolean Values

localStorage converts supplied values into strings. Numbers and Boolean values therefore need conversion when retrieved if the application requires their original data types.

Example: Number

localStorage.setItem("age", 25); const age = Number( localStorage.getItem("age") ); console.log(age); console.log(typeof age);
Expected Output: 
25
number

Example: Boolean

localStorage.setItem("isLoggedIn", true); const loginStatus = localStorage.getItem("isLoggedIn") === "true"; console.log(loginStatus); console.log(typeof loginStatus);
Expected Output: 
true
boolean
Avoid converting a stored Boolean using Boolean(value) without checking its contents. Boolean("false") evaluates to true because it is a non-empty string.

13. Storing JavaScript Objects

localStorage cannot directly preserve JavaScript object types. Use JSON.stringify() to convert an object into a string.

Example: Store an Object

const student = { name: "Rahul", course: "HTML5", marks: 85 }; const studentJSON = JSON.stringify(student); localStorage.setItem("student", studentJSON);

Retrieve an Object

const storedStudent = localStorage.getItem("student"); const studentObject = JSON.parse(storedStudent); console.log(studentObject.name); console.log(studentObject.course); console.log(studentObject.marks);
Expected Output: 
Rahul
HTML5
85

Handling Invalid JSON

const storedData = localStorage.getItem("student"); try { const student = JSON.parse(storedData); console.log(student); } catch (error) { console.log("Invalid stored JSON."); }

JSON.parse() can throw a SyntaxError if the stored string is not valid JSON.

14. Practical Program: Student Information

This program stores a student's name and course in localStorage and retrieves the saved information.

Complete HTML Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Student Information</title> </head> <body> <h2>Student Information</h2> <input type="text" id="name" placeholder="Enter name"> <input type="text" id="course" placeholder="Enter course"> <button onclick="saveStudent()"> Save </button> <button onclick="showStudent()"> Retrieve </button> <p id="result"></p> <script> function saveStudent() { const student = { name: document.getElementById("name").value, course: document.getElementById("course").value }; localStorage.setItem( "student", JSON.stringify(student) ); document.getElementById("result").textContent = "Student information saved."; } function showStudent() { const data = localStorage.getItem("student"); if (data === null) { document.getElementById("result").textContent = "No student information found."; return; } try { const student = JSON.parse(data); document.getElementById("result").textContent = "Name: " + student.name + " | Course: " + student.course; } catch (error) { document.getElementById("result").textContent = "Stored information is invalid."; } } </script> </body> </html>
Expected Result:
  1. Enter a student name and course.
  2. Click Save.
  3. Click Retrieve.
  4. The saved student information is displayed.

16. Inspecting localStorage in Browser Developer Tools

Chrome and other modern browsers allow developers to inspect localStorage through Developer Tools.

Steps in Google Chrome

  1. Open your HTML page in Chrome.
  2. Press F12.
  3. Select the Application tab.
  4. Find Storage in the left sidebar.
  5. Expand Local Storage.
  6. Select the current website origin.
  7. Inspect stored keys and values.

You can also inspect localStorage through the browser console.

localStorage.getItem("username"); localStorage.length; Object.keys(localStorage);
When testing on a local HTML file, browser behavior for file origins can vary. For reliable testing, use a local development server or your HTTPS GitHub Pages website.

17. Security and Limitations

Security Risks

  • JavaScript in the same origin can access localStorage.
  • XSS attacks may expose stored information.
  • Users can inspect and modify stored values.
  • Data is not automatically encrypted by localStorage.
  • Client-side values must not be trusted as server-authoritative data.

Best Practices

  • Store only non-sensitive information.
  • Do not store passwords or private authentication secrets.
  • Validate data retrieved from storage.
  • Handle storage exceptions.
  • Use IndexedDB for larger structured data.
  • Use secure coding practices to prevent XSS.

18. Common Mistakes

  • Using getItem() with an incorrect key.
  • Forgetting that missing keys return null.
  • Assuming objects are stored directly.
  • Forgetting JSON.parse() when retrieving JSON data.
  • Using clear() when only one key should be removed.
  • Assuming data is shared between different origins.
  • Storing sensitive information.
  • Ignoring possible storage errors.

19. Lesson Summary

  • localStorage is part of the Web Storage API.
  • It stores key-value pairs as strings.
  • Data normally persists across browser restarts.
  • setItem() stores or updates a value.
  • getItem() retrieves a value.
  • removeItem() deletes one entry.
  • clear() deletes all entries for the current origin.
  • length returns the number of stored entries.
  • key() returns a key by index.
  • JSON.stringify() converts objects into strings.
  • JSON.parse() converts JSON strings into JavaScript values.
  • localStorage operations are synchronous.
  • Never use localStorage for passwords or private secrets.

21. Interview Questions and Answers

Q1. What is localStorage?
localStorage is a browser storage mechanism that stores key-value data associated with an origin and normally retains it until removed or cleared.
Q2. Which API provides localStorage?
The Web Storage API.
Q3. How do you store data in localStorage?
Use localStorage.setItem(key, value).
Q4. How do you retrieve stored data?
Use localStorage.getItem(key).
Q5. How do you update stored data?
Call setItem() again with the same key and the new value.
Q6. How do you delete one stored entry?
Use localStorage.removeItem(key).
Q7. How do you remove all stored entries?
Use localStorage.clear().
Q8. What happens when getItem() cannot find a key?
It returns null.
Q9. Can localStorage store objects directly?
No. Objects should be converted to JSON strings using JSON.stringify() before storage.
Q10. What is the difference between setItem() and getItem()?
setItem() saves or updates a value, whereas getItem() retrieves a stored value.
Q11. Does localStorage expire automatically?
It has no fixed built-in expiry time, but data can be removed by the application, user, or browser storage policies.
Q12. Is localStorage synchronous?
Yes. Its read and write operations are synchronous.
Q13. Can different websites access the same localStorage?
No. localStorage is separated by origin.
Q14. Why should sensitive information not be stored in localStorage?
Scripts executing in the same origin can access its contents. XSS vulnerabilities may expose sensitive stored data.
Q15. Where can localStorage be inspected?
It can be inspected in browser Developer Tools, generally under Application → Storage → Local Storage.
