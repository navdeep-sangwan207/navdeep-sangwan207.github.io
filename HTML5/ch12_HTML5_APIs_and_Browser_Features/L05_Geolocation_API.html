Lesson 5: Geolocation API

Chapter 12: HTML5 APIs and Browser Features

Learn how web applications can request and use the geographical location of a device.

1. Introduction to Geolocation API

The Geolocation API is a browser feature that allows a web application to request the geographical position of a device.

It can provide information such as latitude, longitude, altitude, accuracy, speed and heading, depending on the device and available location sources.

Common applications include:

  • Maps and navigation applications.
  • Nearby shops, restaurants and services.
  • Location-based weather applications.
  • Delivery and transportation applications.
  • Travel and tourism websites.
  • Location-aware fitness applications.
The Geolocation API is a JavaScript browser API. HTML provides the page structure, while JavaScript requests and processes location information.

2. How Geolocation Works

The browser acts as an intermediary between the web application and the device's location services.

  1. The user opens a web application.
  2. JavaScript checks whether Geolocation is supported.
  3. The application requests the user's position.
  4. The browser asks for permission when required.
  5. The user grants or denies permission.
  6. The browser obtains an available position.
  7. The success or error callback is executed.
Basic workflow: 
Web Page
   |
JavaScript
   |
Geolocation API
   |
Browser Permission
   |
Device Location Services
   |
Position Information

3. Checking Geolocation Support

The Geolocation API is available through navigator.geolocation.

Syntax

navigator.geolocation

Example

if ("geolocation" in navigator) { console.log("Geolocation is supported."); } else { console.log("Geolocation is not supported."); }
Possible Output: 
Geolocation is supported.

Support for the API does not guarantee that a position can be obtained. Permission, device settings and location availability also matter.

4. getCurrentPosition() Method

The getCurrentPosition() method requests the device's current geographical position.

Syntax

navigator.geolocation.getCurrentPosition( successCallback, errorCallback, options );

Parameters:

  • successCallback: Function executed when a position is successfully obtained.
  • errorCallback: Function executed when an error occurs.
  • options: Optional configuration object.

Basic Example

navigator.geolocation.getCurrentPosition( function(position) { console.log(position); }, function(error) { console.log(error.message); } );

The method works asynchronously. The browser executes the appropriate callback after the location request is processed.

5. Understanding the Position Object

When the location request succeeds, the success callback receives a Position object.

The Position object contains two important properties:

  • coords: Contains geographical coordinates.
  • timestamp: Time when the position was obtained.

Example

navigator.geolocation.getCurrentPosition( function(position) { console.log(position.coords.latitude); console.log(position.coords.longitude); console.log(position.timestamp); } );

6. Coordinates Object

The coords property contains information about the geographical position.

Property Description
latitude Latitude in decimal degrees.
longitude Longitude in decimal degrees.
accuracy Accuracy radius in metres.
altitude Altitude in metres, or null if unavailable.
altitudeAccuracy Altitude accuracy in metres, or null if unavailable.
heading Direction of travel in degrees, or null if unavailable.
speed Speed in metres per second, or null if unavailable.

Example

navigator.geolocation.getCurrentPosition( function(position) { const coordinates = position.coords; console.log("Latitude:", coordinates.latitude); console.log("Longitude:", coordinates.longitude); console.log("Accuracy:", coordinates.accuracy); console.log("Altitude:", coordinates.altitude); console.log("Speed:", coordinates.speed); } );
Some coordinate properties may be null if the device or location provider cannot determine them. Accuracy represents an estimated radius of uncertainty, not a guarantee of exact location.

7. Handling Geolocation Errors

The error callback receives a GeolocationPositionError object when the browser cannot provide the requested position.

Error Codes

Code Constant Description
1 PERMISSION_DENIED The user or browser denied access.
2 POSITION_UNAVAILABLE The device could not determine its position.
3 TIMEOUT The location request exceeded its allowed time.

Complete Error Handling Example

function showLocationError(error) { switch (error.code) { case error.PERMISSION_DENIED: console.log("User denied location permission."); break; case error.POSITION_UNAVAILABLE: console.log("Location information is unavailable."); break; case error.TIMEOUT: console.log("Location request timed out."); break; default: console.log("An unknown location error occurred."); } }

8. Geolocation Options

The optional configuration object controls how the browser attempts to obtain the position.

Option Purpose
enableHighAccuracy Requests a more accurate position when possible.
timeout Maximum time in milliseconds to wait for a position.
maximumAge Maximum acceptable age in milliseconds of a cached position.

Example

const options = { enableHighAccuracy: true, timeout: 10000, maximumAge: 0 }; navigator.geolocation.getCurrentPosition( function(position) { console.log(position.coords.latitude); console.log(position.coords.longitude); }, function(error) { console.log(error.message); }, options );

Explanation:

  • enableHighAccuracy: true requests higher accuracy where possible, but does not guarantee it.
  • timeout: 10000 specifies a maximum wait of 10 seconds.
  • maximumAge: 0 requests a position that is not older than zero milliseconds.

9. watchPosition() Method

The watchPosition() method monitors changes in the device's geographical position.

Whenever the browser obtains a new position according to its location updates, the success callback can be executed again.

Syntax

const watchId = navigator.geolocation.watchPosition( successCallback, errorCallback, options );

Example

const watchId = navigator.geolocation.watchPosition( function(position) { console.log("Latitude:", position.coords.latitude); console.log("Longitude:", position.coords.longitude); }, function(error) { console.log(error.message); } );

Common applications:

  • Live navigation.
  • Vehicle tracking with user permission.
  • Fitness and distance tracking.
  • Location-aware applications.

10. clearWatch() Method

The clearWatch() method stops a position watch that was previously started using watchPosition().

Syntax

navigator.geolocation.clearWatch(watchId);

Example

const watchId = navigator.geolocation.watchPosition( function(position) { console.log(position.coords.latitude); } ); // Stop watching the position. navigator.geolocation.clearWatch(watchId);
Store the watch ID returned by watchPosition() so that the application can stop the watch later.

11. getCurrentPosition() vs watchPosition()

Feature getCurrentPosition() watchPosition()
Purpose Requests a position. Monitors position updates.
Callback Called for the position request. Can be called repeatedly.
Return value Undefined. Watch ID.
Stop operation No watch to stop. Use clearWatch().
Typical application Find current location. Monitor movement.

12. Browser Permission and Secure Context

Location information is sensitive. Therefore, browsers control access to the Geolocation API.

Permission

  • The browser may ask the user for location permission.
  • The user can grant or deny access.
  • Permission can usually be changed in browser settings.
  • Websites should explain why location access is required.
  • Applications should request location only when needed.

Secure Context

Modern browsers generally require Geolocation API access from a secure context, such as HTTPS.

Localhost is generally treated as trustworthy for development, so developers can test Geolocation on local development servers.

A GitHub Pages website served through HTTPS can request Geolocation permission. Opening an ordinary HTML file directly through file:// may not provide a suitable secure context.

13. Complete Practical Program: Get Current Location

This program requests the current location and displays latitude, longitude, accuracy and additional available information.

Complete HTML Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Current Location</title> </head> <body> <h2>Geolocation Demonstration</h2> <button onclick="getLocation()"> Get My Location </button> <div id="result"></div> <script> function getLocation() { const result = document.getElementById("result"); if (!("geolocation" in navigator)) { result.textContent = "Geolocation is not supported."; return; } result.textContent = "Requesting location permission..."; navigator.geolocation.getCurrentPosition( function(position) { const coordinates = position.coords; result.innerHTML = "<p>Latitude: " + coordinates.latitude + "</p>" + "<p>Longitude: " + coordinates.longitude + "</p>" + "<p>Accuracy: " + coordinates.accuracy + " metres</p>" + "<p>Altitude: " + coordinates.altitude + "</p>" + "<p>Speed: " + coordinates.speed + "</p>"; }, function(error) { result.textContent = "Location error: " + error.message; }, { enableHighAccuracy: true, timeout: 10000, maximumAge: 0 } ); } </script> </body> </html>
Expected Result:
  1. A Get My Location button appears.
  2. Clicking the button requests location permission.
  3. If permission is granted, coordinates are displayed.
  4. If permission is denied or location is unavailable, an error message appears.

15. Displaying Location on a Map

Latitude and longitude can be used to create a map link. The Geolocation API itself does not provide a map display.

Example

navigator.geolocation.getCurrentPosition( function(position) { const latitude = position.coords.latitude; const longitude = position.coords.longitude; const mapURL = "https://www.google.com/maps?q=" + latitude + "," + longitude; window.open( mapURL, "_blank", "noopener,noreferrer" ); }, function(error) { console.log(error.message); } );

The map service receives the coordinates through the URL. Its own service and privacy policies apply when the link is opened.

16. Applications of Geolocation API

1. Navigation Applications

A navigation website can use the current position as the starting point for directions.

2. Nearby Services

A website can use latitude and longitude to search for nearby shops, hospitals or restaurants.

3. Delivery Applications

Location information can help users select delivery locations and follow delivery progress.

4. Weather Applications

A weather application can request local weather information based on geographical coordinates.

5. Fitness Applications

Applications can monitor location updates for outdoor activities, subject to permission and device capabilities.

17. Common Mistakes

  • Not checking whether navigator.geolocation exists.
  • Ignoring the permission request.
  • Not providing an error callback.
  • Using the wrong property names for coordinates.
  • Assuming altitude and speed are always available.
  • Assuming enableHighAccuracy guarantees exact results.
  • Forgetting to call clearWatch() when monitoring is no longer needed.
  • Testing on an insecure origin that does not support the API.
  • Requesting location without explaining its purpose.

18. Lesson Summary

  • Geolocation API provides access to device position information.
  • It is accessed using navigator.geolocation.
  • Modern browsers generally require a secure context.
  • User permission is required.
  • getCurrentPosition() requests a position.
  • watchPosition() monitors position updates.
  • clearWatch() stops a position watch.
  • Position contains coords and timestamp.
  • Coordinates include latitude, longitude and accuracy.
  • Error codes identify permission, availability and timeout problems.
  • Options configure accuracy, timeout and cached-position age.
  • Location information should be handled responsibly.

20. Interview Questions and Answers

Q1. What is the Geolocation API?
It is a browser API that allows web applications to request geographical position information from the device.
Q2. How do you access Geolocation?
Using navigator.geolocation.
Q3. Which method obtains the current position?
getCurrentPosition().
Q4. Which method monitors position changes?
watchPosition().
Q5. How do you stop position monitoring?
Use clearWatch() with the watch ID.
Q6. What does the Position object contain?
It contains coords and timestamp properties.
Q7. What is latitude?
Latitude represents the angular position north or south of the Equator.
Q8. What is longitude?
Longitude represents the angular position east or west of the Prime Meridian.
Q9. What does accuracy represent?
It represents an estimated accuracy radius in metres around the reported position.
Q10. What does PERMISSION_DENIED mean?
The user or browser denied access to location.
Q11. What does POSITION_UNAVAILABLE mean?
The browser could not determine the device's position.
Q12. What does TIMEOUT mean?
The position request exceeded its allowed time.
Q13. What is enableHighAccuracy?
It requests a more accurate position when the device and location provider can supply one.
Q14. Why is HTTPS required?
Modern browsers restrict sensitive APIs such as Geolocation to secure contexts, with localhost generally treated as trustworthy.
Q15. Does Geolocation API display a map?
No. It provides position information. A separate map service or mapping library can display that position.
