Div and Span Elements

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 8

1. Introduction

HTML provides two commonly used generic container elements: <div> and <span>.

  • div: A generic block-level container used to group larger sections of HTML content.
  • span: A generic inline container used to group a small portion of text or other inline content.

Both elements are non-semantic. They do not describe the meaning or purpose of their content.

They are commonly used with CSS classes and IDs to apply styling, organize layouts and identify elements for JavaScript.

2. The div Element

The <div> element represents a generic container for flow content. It is useful when no more appropriate semantic element describes the content.

Syntax

<div>
    Content goes here.
</div>

Example

<div>
    <h2>HTML5 Course</h2>
    <p>Learn HTML5 from beginner to advanced.</p>
</div>

The div groups the heading and paragraph into one container.

3. The Block-Level Layout Behavior of div

A div element normally generates a block-level box. It starts on a new line in the usual horizontal writing mode and typically occupies the available width of its containing block.

Example

<div>First container</div>
<div>Second container</div>
<div>Third container</div>

The block-level layout behavior is the browser's default styling. CSS can change the display behavior of a div.

4. Styling div Using CSS

CSS properties such as background-color, padding, margin, border, width and height can be applied to div.

HTML Code

<div class="course-card">
    <h2>Embedded Systems</h2>
    <p>Learn embedded programming.</p>
</div>

CSS Code

.course-card {
    background-color: #eaf3ff;
    padding: 20px;
    margin: 15px 0;
    border: 2px solid #2878d0;
    border-radius: 8px;
    width: 100%;
}

5. The span Element

The <span> element is a generic inline container. It is commonly used to style or identify a specific part of text.

Syntax

<span>Inline content</span>

Example

<p>
    HTML is a
    <span class="highlight">markup language</span>
    used to structure webpages.
</p>

Browser Preview

Only the selected text is highlighted. The rest of the paragraph remains unchanged.

6. Inline Behavior of span

Span normally generates an inline box. It does not start a new line and flows within the surrounding text.

Example

<p>
    Learn
    <span>HTML5</span>,
    <span>CSS3</span> and
    <span>JavaScript</span>.
</p>

7. Styling span Using CSS

CSS can style a span without changing the surrounding paragraph structure.

HTML Code

<p>
    Course Status:
    <span class="status">Completed</span>
</p>

CSS Code

.status {
    color: green;
    font-weight: bold;
    background-color: #e2f5e9;
    padding: 3px 8px;
    border-radius: 4px;
}

8. Difference Between div and span

Feature div span
Element type Generic container Generic inline container
Default display block inline
Line behavior Normally starts on a new line. Normally stays within the current line.
Common purpose Group larger content sections. Group small portions of inline content.
Common application Cards, containers and layouts. Text highlighting and inline styling.
Semantic meaning None by itself. None by itself.

9. Using class and id with div and span

The class and id attributes help identify elements for CSS styling and JavaScript operations.

Using class

<div class="course-card">
    <h2>C++ Programming</h2>
</div>

<div class="course-card">
    <h2>Linux Programming</h2>
</div>

The same class can be assigned to multiple elements.

Using id

<div id="main-content">
    <h2>Welcome to HTML5</h2>
</div>

<p>
    Course Level:
    <span id="course-level">Beginner</span>
</p>

An id should be unique within the HTML document.

10. Nested div Elements

A div can contain other div elements. This is called nesting. Nested containers are commonly used to organize webpage layouts.

Example

<div class="container">

    <div class="header">
        <h1>Learning Portal</h1>
    </div>

    <div class="content">

        <div class="course-card">
            <h2>HTML5</h2>
            <p>Learn HTML5.</p>
        </div>

        <div class="course-card">
            <h2>CSS3</h2>
            <p>Learn CSS3.</p>
        </div>

    </div>

</div>

11. Using div with CSS Flexbox and Grid

Div containers are often used with CSS Flexbox and CSS Grid to build responsive layouts.

Flexbox Example

<div class="course-container">
    <div class="card">HTML5</div>
    <div class="card">CSS3</div>
    <div class="card">JavaScript</div>
</div>
.course-container {
    display: flex;
    gap: 15px;
    flex-wrap: wrap;
}

.card {
    padding: 20px;
    background: #eaf3ff;
    flex: 1 1 150px;
}

Grid Example

.course-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}
Flexbox and Grid are CSS layout systems. Div provides containers that can participate in these layouts. Semantic HTML elements can also be used as Flexbox or Grid items.

12. Using div and span with JavaScript

JavaScript can access div and span elements through their IDs or classes and update their content.

HTML Code

<div id="message">
    Original message
</div>

<button onclick="changeMessage()">
    Change Message
</button>

<script>
function changeMessage() {
    document.getElementById("message").textContent =
        "Welcome to HTML5!";
}
</script>

13. When to Use div and span

Use div when:

  • You need to group multiple HTML elements.
  • You need a generic layout container.
  • You want to apply CSS to a larger content block.
  • You need a container for Flexbox or Grid.
  • No suitable semantic element describes the content.

Use span when:

  • You need to style a particular word or phrase.
  • You need to identify inline content for JavaScript.
  • You want to highlight a small part of a paragraph.
  • You need a generic inline wrapper.
Do not use div or span when a more meaningful semantic element is appropriate. For example, use nav for major navigation and main for the primary page content.

14. Common Mistakes

  1. Using div for every part of a webpage instead of appropriate semantic elements.
  2. Using span to group large page sections without changing its display behavior.
  3. Assuming div and span have built-in semantic meaning.
  4. Forgetting to close div or span elements.
  5. Using duplicate IDs in the same document.
  6. Confusing CSS display behavior with HTML semantic meaning.
  7. Using unnecessary nested div elements.
  8. Using div instead of article, section, nav or main when those elements fit the content.

16. Interview Questions and Answers

Q1. What is the div element?

Div is a generic container used to group flow content.

Q2. What is the span element?

Span is a generic inline container used to group inline content.

Q3. What is the default display behavior of div?

It normally generates a block-level box.

Q4. What is the default display behavior of span?

It normally generates an inline box.

Q5. Are div and span semantic elements?

No. They are generic non-semantic HTML elements.

Q6. Can div contain other div elements?

Yes. Div elements can be nested when the HTML content model permits it.

Q7. Can span be used inside a paragraph?

Yes. Span is commonly used to style or identify inline text inside paragraphs.

Q8. Can CSS change the default display behavior?

Yes. The CSS display property can change an element's layout behavior.

Q9. What is the difference between class and id?

Class can be shared by multiple elements, while an id should uniquely identify one element in a document.

Q10. When should div be avoided?

When a more suitable semantic element such as main, section, article or nav describes the content.

18. Lesson Summary

  • Div is a generic container for grouping larger content blocks.
  • Span is a generic inline container for grouping portions of inline content.
  • Both elements are non-semantic.
  • Div normally generates a block-level box.
  • Span normally generates an inline box.
  • CSS can change their display behavior.
  • Class and id attributes help identify elements.
  • Div and span are widely used with CSS and JavaScript.
  • Prefer semantic HTML elements whenever they appropriately describe the content.
