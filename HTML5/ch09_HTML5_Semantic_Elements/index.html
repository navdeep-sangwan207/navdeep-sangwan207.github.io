Chapter Overview

HTML5 semantic elements describe the meaning and purpose of different parts of a web page. They help browsers, search engines, developers and assistive technologies understand the structure of a document.

In this chapter, you will learn semantic elements such as header, footer, nav, main, section, article, aside, details and summary, along with non-semantic elements such as div and span.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand semantic HTML and its importance.
  • Identify semantic and non-semantic HTML elements.
  • Use header and footer elements correctly.
  • Create navigation areas using the nav element.
  • Understand the purpose of main and section elements.
  • Organize independent content using article.
  • Use aside for complementary content.
  • Create expandable content using details and summary.
  • Understand the difference between div, span and semantic elements.
  • Build accessible and logically structured web pages.
