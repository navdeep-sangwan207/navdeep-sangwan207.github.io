Article Element

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 5

1. Introduction

The HTML5 <article> element represents a self-contained composition that can be independently distributed, reused or understood.

It is commonly used for:

  • Blog posts
  • News articles
  • Forum posts
  • Product reviews
  • User comments
  • Independent tutorials
  • Community posts

The main purpose of article is to identify content that has its own meaning and can stand independently from the surrounding webpage.

2. Article Element Syntax

The article element is written using an opening <article> tag and a closing </article> tag.

Syntax

<article>
    <h2>Article Title</h2>
    <p>Article content goes here.</p>
</article>

Example

<article>
    <h2>Introduction to HTML5</h2>

    <p>
        HTML5 is used to structure content
        on modern webpages.
    </p>

    <p>
        It provides semantic elements,
        multimedia support and more.
    </p>
</article>
An article should represent a complete, meaningful piece of content rather than an arbitrary visual container.

3. Important Characteristics of article

  • It represents independent, self-contained content.
  • It can contain its own heading and paragraphs.
  • It can contain images, lists, links and other HTML elements.
  • It can contain header and footer elements.
  • It can be used multiple times on a webpage.
  • It can be nested when the content represents related independent compositions.
  • It provides semantic meaning to the document structure.
An article does not have to be a newspaper or magazine article. A self-contained forum post, review or blog entry can also be represented by this element.

4. Article for a Blog Post

A blog post is a common example of content that can be represented using the article element.

HTML Code

<article>

    <header>
        <h2>Introduction to Embedded Systems</h2>
        <p>Published on 6 November 2026</p>
    </header>

    <p>
        Embedded systems combine hardware
        and software to perform dedicated tasks.
    </p>

    <p>
        They are commonly used in automotive,
        industrial and consumer applications.
    </p>

    <footer>
        <p>Author: Technical Team</p>
    </footer>

</article>

5. Multiple Article Elements on a Webpage

A webpage can contain multiple articles. For example, a blog homepage may display several independent blog posts.

HTML Code

<main>

    <h1>Latest Articles</h1>

    <article>
        <h2>Learning C Programming</h2>
        <p>Introduction to C programming.</p>
    </article>

    <article>
        <h2>Learning C++ Programming</h2>
        <p>Introduction to C++ programming.</p>
    </article>

    <article>
        <h2>Learning Linux</h2>
        <p>Introduction to Linux operating system.</p>
    </article>

</main>

6. Nesting Article Elements

An article can contain another article when the inner composition is related to the outer article but can also be understood independently.

Example: Blog Post with Comments

<article>

    <h2>Introduction to HTML5</h2>

    <p>
        HTML5 provides semantic elements
        for webpage structure.
    </p>

    <section>
        <h3>Comments</h3>

        <article>
            <h4>Comment by Rahul</h4>
            <p>This tutorial is helpful.</p>
        </article>

        <article>
            <h4>Comment by Amit</h4>
            <p>I learned about semantic HTML.</p>
        </article>

    </section>

</article>

Here, the outer article represents the blog post. The nested articles represent individual comments.

7. Article vs Section

Both article and section are semantic elements, but they serve different purposes.

Feature article section
Purpose Represents independent content. Groups related content by topic.
Independence Can stand independently. Usually forms part of a larger document.
Common use Blog posts, news, reviews and comments. Introduction, features and chapters.
Multiple usage Yes. Yes.
Nesting Can contain related articles or sections. Can contain other sections and articles.

Example: Using Both Together

<main>

    <article>
        <h2>HTML5 Complete Guide</h2>

        <section>
            <h3>Introduction</h3>
            <p>Introduction to HTML5.</p>
        </section>

        <section>
            <h3>HTML5 Features</h3>
            <p>Important HTML5 features.</p>
        </section>

    </article>

</main>

In this example, article represents the complete guide, while the sections divide it into meaningful topics.

8. Article vs Div

article div
Semantic HTML element. Generic non-semantic container.
Represents independent content. Does not describe the meaning of its content.
Useful for blog posts and reviews. Useful for styling and layout.
Has a defined semantic purpose. Usually used with class or id for CSS and JavaScript.

Example: div for a Card Layout

<div class="course-card">
    <h3>HTML5 Course</h3>
    <p>Learn HTML5 from basics to advanced.</p>
    <a href="html5/index.html">View Course</a>
</div>
A course card is not automatically an article. Use article when the card represents independently distributable content; otherwise, div may be appropriate.

9. Complete Blog Page Example

The following example demonstrates a webpage containing multiple independent articles. 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Technical Blog</title>
</head>

<body>

    <header>
        <h1>NS Technical Blog</h1>
    </header>

    <nav aria-label="Main navigation">
        <a href="#home">Home</a>
        <a href="#articles">Articles</a>
    </nav>

    <main id="home">

        <h2 id="articles">Latest Articles</h2>

        <article>
            <header>
                <h3>Introduction to C++</h3>
                <p>Programming Tutorial</p>
            </header>

            <p>
                C++ is a general-purpose programming
                language supporting object-oriented
                and other programming paradigms.
            </p>

            <footer>
                <p>Category: Programming</p>
            </footer>
        </article>

        <article>
            <header>
                <h3>Introduction to Linux</h3>
                <p>Operating System Tutorial</p>
            </header>

            <p>
                Linux is an open-source operating
                system built around the Linux kernel.
            </p>

            <footer>
                <p>Category: Linux</p>
            </footer>
        </article>

    </main>

    <footer>
        <p>NS Technical Blog</p>
    </footer>

</body>
</html>

10. Accessibility and Best Practices

  • Use article for content that can stand independently.
  • Provide a meaningful heading for each article whenever appropriate.
  • Use section to organize the internal topics of an article.
  • Use header and footer for article-specific introductory and concluding information when appropriate.
  • Use semantic elements according to their meaning, not merely their appearance.
  • Use logical heading levels.
  • Use time with a datetime attribute for machine-readable publication dates when appropriate.
  • Do not use article as a generic replacement for div.

Example: time Element with article

<article>

    <h2>Latest Technology News</h2>

    <p>
        Published:
        <time datetime="2026-11-06">
            6 November 2026
        </time>
    </p>

    <p>Technology news content goes here.</p>

</article>

11. Common Mistakes

  1. Using article for every visual content box.
  2. Using article when the content is not independently meaningful.
  3. Confusing article with section.
  4. Using article only to apply CSS styling.
  5. Ignoring logical heading structure.
  6. Using multiple article elements without a meaningful content purpose.
  7. Assuming article automatically creates a bordered card or special layout.
  8. Forgetting that CSS is responsible for visual styling.

13. Interview Questions and Answers

Q1. What is the article element in HTML5?

It represents a self-contained composition that can be independently distributed or reused.

Q2. What are common uses of article?

Blog posts, news stories, forum posts, reviews and independent tutorials.

Q3. Can a webpage contain multiple article elements?

Yes. Each article should represent a meaningful independent composition.

Q4. Can article contain section elements?

Yes. Sections can organize the different topics within an article.

Q5. Can article elements be nested?

Yes. For example, a blog post can contain independently meaningful comment articles.

Q6. What is the difference between article and section?

Article represents independent content, while section represents a thematic grouping.

Q7. What is the difference between article and div?

Article is semantic; div is a generic container without inherent semantic meaning.

Q8. Can article contain header and footer elements?

Yes. They can represent introductory and concluding information for that article.

Q9. Is article a block-level element?

It is rendered as a block-level element by default in browsers, but its semantic purpose is more important than its default display style.

Q10. Does article automatically provide visual styling?

No. CSS is used to control its visual appearance.
