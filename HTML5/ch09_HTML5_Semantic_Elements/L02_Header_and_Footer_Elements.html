Header and Footer Elements

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 2

1. Introduction

HTML5 provides two important semantic elements: <header> and <footer>. They help organize introductory and closing information within a web page or a particular section.

  • header: Represents introductory content for a page or section.
  • footer: Represents footer information for a page or section.

These elements improve document structure and make HTML easier for developers and assistive technologies to understand.

2. HTML header Element

The <header> element represents introductory content or navigational assistance for its nearest relevant sectioning context or page.

A header commonly contains:

  • Website or section headings.
  • Logos or branding information.
  • Introductory paragraphs.
  • Author or publication information.
  • Navigation or introductory links.

Syntax

<header>
    Content goes here
</header>

Example 1: Website Header

<header>
    <h1>NS Learning Hub</h1>
    <p>My Learning Portal</p>
</header>

Example 2: Article Header

<article>

    <header>
        <h2>Introduction to HTML5</h2>
        <p>Published on 6 November 2026</p>
    </header>

    <p>
        HTML5 provides elements for structuring
        modern web pages.
    </p>

</article>
A header does not have to appear only at the top of the entire webpage. It can also introduce an article or another section.

3. HTML footer Element

The <footer> element represents footer information for its nearest relevant sectioning context or for the page itself.

A footer commonly contains:

  • Copyright information.
  • Author or contact information.
  • Related documents or resources.
  • Privacy policy links.
  • Terms and conditions links.
  • Related navigation links.

Syntax

<footer>
    Footer content goes here
</footer>

Example 1: Website Footer

<footer>
    <p>Copyright 2026 NS Learning Hub</p>
    <p>All rights reserved.</p>
</footer>

Example 2: Article Footer

<article>

    <h2>Introduction to C++</h2>

    <p>
        C++ is a general-purpose programming language.
    </p>

    <footer>
        <p>Written by the Course Author</p>
        <p>Category: Programming</p>
    </footer>

</article>
A footer does not have to appear only at the bottom of the entire webpage. It can also provide closing information for an individual article or section.

4. Difference Between header and footer

Feature header footer
Purpose Introduces a page or section Provides closing information
Common content Heading, logo, introductory content Copyright, author, related links
Position Often near the beginning of a section Often near the end of a section
Semantic role Introductory content Footer information
Usage Page or section Page or section

5. Multiple header and footer Elements

HTML allows multiple header and footer elements when they belong to different page or section contexts.

Example

<body>

    <header>
        <h1>Technology Blog</h1>
    </header>

    <main>

        <article>

            <header>
                <h2>Introduction to Linux</h2>
                <p>Published by Admin</p>
            </header>

            <p>
                Linux is an open-source operating system.
            </p>

            <footer>
                <p>Category: Operating Systems</p>
            </footer>

        </article>

    </main>

    <footer>
        <p>Copyright 2026 Technology Blog</p>
    </footer>

</body>

In this example, there is one website header, one article header, one article footer and one website footer.

Do not confuse the number of header and footer elements with the number of main elements. Multiple headers and footers are valid when appropriately used, but a document should generally have one visible main element.

6. Complete Practical Example

The following example demonstrates a website layout with a header, an article header, an article footer and a website footer.

HTML Code

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Header and Footer Example</title>
</head>

<body>

    <header>
        <h1>NS Learning Hub</h1>
        <p>Learn Programming and Electronics</p>
    </header>

    <main>

        <article>

            <header>
                <h2>Embedded Systems</h2>
                <p>Course Introduction</p>
            </header>

            <p>
                Embedded systems combine hardware
                and software to perform dedicated tasks.
            </p>

            <footer>
                <p>Category: Electronics</p>
            </footer>

        </article>

    </main>

    <footer>
        <p>Copyright 2026 NS Learning Hub</p>
        <p>All rights reserved.</p>
    </footer>

</body>
</html>

7. Styling header and footer with CSS

HTML defines the semantic structure. CSS can be used to control the appearance of header and footer elements.

Example

<style>
header {
    background-color: #174ea6;
    color: white;
    padding: 20px;
    text-align: center;
}

footer {
    background-color: #263238;
    color: white;
    padding: 15px;
    text-align: center;
}
</style>

Complete Example

<header class="site-header">
    <h1>My Website</h1>
</header>

<footer class="site-footer">
    <p>Copyright 2026</p>
</footer>

CSS selectors such as header and footer can target the corresponding elements. Classes can also be used when different headers or footers need different styles.

8. Important Technical Points

  • header and footer are semantic HTML elements.
  • Both elements can be used at the page level and inside appropriate sections.
  • A header can contain headings, introductory content and navigation-related material.
  • A footer can contain author information, copyright details and related links.
  • Multiple header and footer elements are permitted in a document.
  • header and footer elements must not be nested inside another header or footer element.
  • Neither element automatically creates a fixed position at the top or bottom of the browser window.
  • CSS is responsible for positioning, colors, spacing and other visual presentation.
  • These elements do not replace the need for proper heading structure.

9. Common Mistakes

  1. Using header only for the website logo and assuming it cannot introduce an article.
  2. Using footer only at the end of the entire document.
  3. Placing a header or footer inside another header or footer.
  4. Assuming header automatically appears at the top of the viewport.
  5. Assuming footer automatically stays at the bottom of the screen.
  6. Using these elements only for their default appearance instead of their semantic meaning.
  7. Forgetting to use CSS when custom visual styling is required.

11. Interview Questions and Answers

Q1. What is the header element in HTML5?

It represents introductory content or navigational assistance for a page or section.

Q2. What is the footer element?

It represents footer information for a page or section.

Q3. Can we use multiple header elements?

Yes. Different page sections and articles can have their own headers.

Q4. Can we use multiple footer elements?

Yes. A page and its individual sections can have separate footers.

Q5. Can header be used inside article?

Yes. It can introduce the article with a heading and publication information.

Q6. Can footer be used inside article?

Yes. It can contain author, category or related information about the article.

Q7. Does header always appear at the top of the screen?

No. Its position in the viewport depends on document order and CSS styling.

Q8. Does footer always remain at the bottom of the screen?

No. A normal footer appears according to document flow. CSS can be used to implement a sticky or fixed layout when required.

Q9. Can header contain navigation links?

Yes. A header can contain a nav element when navigation is part of the introductory content.

Q10. Can a header or footer be nested inside another header or footer?

No. A header or footer element must not contain another header or footer element.

13. Lesson Summary

  • <header> represents introductory content.
  • <footer> represents footer information.
  • Both elements can be used for a complete page or an individual section.
  • A document can contain multiple header and footer elements.
  • Header and footer elements must not be nested inside each other.
  • CSS controls their visual presentation and positioning.
  • Semantic usage improves document structure and accessibility.
