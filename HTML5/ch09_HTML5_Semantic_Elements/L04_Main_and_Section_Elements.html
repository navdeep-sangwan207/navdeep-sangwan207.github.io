Main and Section Elements

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 4

1. Introduction

HTML5 provides semantic elements to organize webpage content according to its meaning and purpose.

Two important semantic elements are:

  • <main> – represents the dominant content of a document.
  • <section> – represents a thematic grouping of related content.

These elements help developers create a meaningful document structure that is easier to understand, maintain and navigate.

2. The main Element

The HTML5 <main> element represents the dominant content of the body of a document or application.

It contains the central content that is directly related to the main purpose of the webpage.

Syntax

<main>
    Main page content goes here.
</main>

Example

<body>

    <header>
        <h1>My Learning Portal</h1>
    </header>

    <nav>
        <a href="index.html">Home</a>
        <a href="courses.html">Courses</a>
    </nav>

    <main>
        <h2>Available Courses</h2>
        <p>Explore different programming courses.</p>
    </main>

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>
The main element identifies the primary content of the page. It is not intended for repeated content such as site-wide navigation, logos or footers.

3. Important Rules for the main Element

  • A document should generally have one visible main element.
  • The main element should represent the dominant content of the page.
  • It should not be used for content repeated across multiple pages, such as global navigation.
  • It should not be placed inside article, aside, footer, header or nav elements.
  • It can contain section, article, div and other suitable content elements.
  • The main element does not automatically create a visual layout.
Do not use multiple visible main elements on the same page. The main element should identify the page's primary content.

4. The section Element

The HTML5 <section> element represents a thematic grouping of related content, usually with a heading.

A section can be used to divide a webpage into meaningful topics or subject areas.

Syntax

<section>
    <h2>Section Heading</h2>
    <p>Related content goes here.</p>
</section>

Example

<section>
    <h2>HTML5 Introduction</h2>
    <p>
        HTML5 is the modern version of HTML
        used to structure web content.
    </p>
</section>

<section>
    <h2>HTML5 Features</h2>
    <p>
        HTML5 provides semantic elements,
        multimedia support and browser APIs.
    </p>
</section>
A section should normally have a heading that describes its topic. A heading is not strictly required by the HTML specification, but it is a strong content-structure practice.

5. Using Multiple section Elements

A webpage can contain multiple section elements when its content is divided into different thematic areas.

Example

<main>

    <section>
        <h2>About HTML5</h2>
        <p>Introduction to HTML5.</p>
    </section>

    <section>
        <h2>HTML5 Elements</h2>
        <p>Learn about HTML5 elements.</p>
    </section>

    <section>
        <h2>HTML5 Forms</h2>
        <p>Learn how to create forms.</p>
    </section>

</main>

6. Nesting section Elements

A section can contain other section elements when a topic needs to be divided into smaller related topics.

Example

<main>

    <section>
        <h2>Programming Languages</h2>

        <section>
            <h3>C++</h3>
            <p>Learn C++ programming.</p>
        </section>

        <section>
            <h3>Java</h3>
            <p>Learn Java programming.</p>
        </section>

    </section>

</main>

In this example, the inner sections represent individual topics within the broader Programming Languages section.

7. Difference Between main and section

Feature main section
Purpose Represents the dominant page content. Groups related content by topic.
Usage Identifies the primary content area. Divides content into thematic areas.
Quantity Generally one visible main per page. Can have multiple sections.
Heading May contain headings. Normally has a descriptive heading.
Nesting Should not be nested inside other major page-sectioning elements. Can contain nested sections.
Typical content Main article, course content or dashboard content. Introduction, features, lessons or topics.

8. Difference Between section and div

Both section and div can group HTML content, but they have different semantic purposes.

section div
Semantic element. Generic non-semantic container.
Groups content around a specific topic. Groups content without expressing a specific meaning.
Normally has a heading. Does not normally require a heading.
Useful for meaningful document structure. Useful for styling and layout grouping.

Example: section

<section>
    <h2>About Our Courses</h2>
    <p>We provide programming courses.</p>
</section>

Example: div

<div class="course-card">
    <h3>HTML5</h3>
    <p>Learn HTML5 from basics to advanced.</p>
</div>
Use section when the grouped content forms a meaningful thematic part of the document. Use div when a generic container is needed for styling or scripting.

9. Complete Page Structure Using main and section

The following example demonstrates how main and section elements work together in a complete webpage.

HTML Code

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>HTML5 Course</title>
</head>

<body>

    <header>
        <h1>HTML5 Learning Portal</h1>
    </header>

    <nav aria-label="Main navigation">
        <a href="#home">Home</a>
        <a href="#features">Features</a>
        <a href="#courses">Courses</a>
    </nav>

    <main>

        <section id="home">
            <h2>Welcome</h2>
            <p>Learn HTML5 step by step.</p>
        </section>

        <section id="features">
            <h2>HTML5 Features</h2>
            <p>Explore semantic elements and multimedia.</p>
        </section>

        <section id="courses">
            <h2>Available Courses</h2>

            <section>
                <h3>HTML5</h3>
                <p>Learn webpage structure.</p>
            </section>

            <section>
                <h3>CSS3</h3>
                <p>Learn webpage styling.</p>
            </section>

        </section>

    </main>

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>
</html>

10. Accessibility and Best Practices

  • Use main to identify the primary content of the document.
  • Use section to group content around a meaningful topic.
  • Give sections descriptive headings whenever appropriate.
  • Maintain a logical heading hierarchy.
  • Do not use section only to apply CSS styling.
  • Use div when no semantic grouping is required.
  • Keep repeated site-wide navigation outside main.
  • Use semantic elements consistently throughout the document.

11. Common Mistakes

  1. Using multiple visible main elements in one document.
  2. Using main for the entire webpage including repeated navigation and footer content.
  3. Using section as a generic replacement for every div.
  4. Creating sections without a clear thematic purpose.
  5. Using headings in an illogical order.
  6. Confusing the meaning of section with its visual appearance.
  7. Assuming main or section automatically applies CSS styling.
  8. Placing main inside elements where it is not permitted, such as header, footer, nav, article or aside.

13. Interview Questions and Answers

Q1. What is the main element in HTML5?

It represents the dominant content of a document or application.

Q2. What is the section element?

It represents a thematic grouping of related content.

Q3. How many visible main elements should a document generally have?

Generally, one visible main element.

Q4. Can a webpage contain multiple section elements?

Yes. Multiple sections can organize different topics on a page.

Q5. Can section elements be nested?

Yes. A section can contain other sections when the content hierarchy requires it.

Q6. What is the difference between main and section?

Main identifies the dominant page content, while section groups related content by topic.

Q7. What is the difference between section and div?

Section has semantic meaning; div is a generic container.

Q8. Is a heading required inside section?

The HTML specification does not strictly require one, but a descriptive heading is normally recommended.

Q9. Can main contain section elements?

Yes. Main commonly contains sections that organize the primary page content.

Q10. Does section automatically style its content?

No. CSS is used to control the visual appearance of section elements.
