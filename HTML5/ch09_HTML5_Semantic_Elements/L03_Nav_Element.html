Nav Element

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 3

1. Introduction

The HTML5 <nav> element represents a section of a webpage that contains major navigation links.

Navigation allows users to move between different pages or different sections of the same webpage.

Common examples include:

  • Main website navigation menus.
  • Course navigation links.
  • Table of contents.
  • Breadcrumb navigation.
  • Important navigation links within an application.

2. What is the nav Element?

The <nav> element is a semantic HTML element used to identify a major navigation section.

Syntax

<nav>
    Navigation links go here
</nav>

Example

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="courses.html">Courses</a>
    <a href="contact.html">Contact</a>
</nav>

The links inside nav are created using the anchor element <a>.

The nav element identifies a navigation section. It does not create the links itself; anchor elements provide the actual navigation destinations.

3. Why Use the nav Element?

  • Identifies important navigation sections.
  • Improves the semantic structure of a webpage.
  • Helps screen-reader users locate navigation landmarks.
  • Makes HTML code easier to understand and maintain.
  • Clearly separates navigation from ordinary page content.
Not every group of links needs to be placed inside nav. Use it for major navigation blocks, not every collection of links appearing on a webpage.

4. Creating a Horizontal Navigation Menu

A horizontal navigation menu displays navigation links in a row. CSS Flexbox is commonly used to create this layout.

HTML Code

<nav class="main-nav">
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="courses.html">Courses</a>
    <a href="projects.html">Projects</a>
    <a href="contact.html">Contact</a>
</nav>

CSS Code

.main-nav {
    display: flex;
    gap: 20px;
    background-color: #174ea6;
    padding: 15px;
}

.main-nav a {
    color: white;
    text-decoration: none;
    font-weight: bold;
}

.main-nav a:hover {
    color: #ffcc80;
}

5. Creating a Vertical Navigation Menu

A vertical navigation menu displays links one below another. It is commonly used for sidebars and dashboard menus.

HTML Code

<nav class="sidebar-nav">
    <a href="index.html">Home</a>
    <a href="courses.html">Courses</a>
    <a href="projects.html">Projects</a>
    <a href="settings.html">Settings</a>
</nav>

CSS Code

.sidebar-nav {
    width: 220px;
    background-color: #edf3ff;
    padding: 15px;
}

.sidebar-nav a {
    display: block;
    padding: 10px;
    color: #174ea6;
    text-decoration: none;
}

.sidebar-nav a:hover {
    background-color: #dceaff;
}

6. Navigation Using an Unordered List

Navigation links are often organized using an unordered list. This provides a logical grouping of related links.

HTML Code

<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

CSS Code

nav ul {
    list-style: none;
    display: flex;
    gap: 20px;
    padding: 0;
    margin: 0;
}

nav a {
    text-decoration: none;
    color: #174ea6;
}

Using a list is not mandatory for every navigation menu, but it is a common and useful way to represent a collection of related navigation links.

7. Multiple nav Elements on a Webpage

A webpage can contain multiple nav elements when it has separate major navigation sections.

Example

<header>
    <h1>My Learning Portal</h1>

    <nav aria-label="Main navigation">
        <a href="index.html">Home</a>
        <a href="courses.html">Courses</a>
        <a href="projects.html">Projects</a>
    </nav>
</header>

<main>
    <h2>Available Courses</h2>
    <p>Explore learning materials.</p>

    <nav aria-label="Course navigation">
        <a href="html5/index.html">HTML5</a>
        <a href="css3/index.html">CSS3</a>
        <a href="javascript/index.html">JavaScript</a>
    </nav>
</main>
When a document contains multiple navigation landmarks, use aria-label to give each one a meaningful and distinct accessible name.

8. aria-label Attribute in Navigation

The aria-label attribute provides an accessible name for a navigation landmark.

Example

<nav aria-label="Main navigation">
    <a href="index.html">Home</a>
    <a href="courses.html">Courses</a>
</nav>

<nav aria-label="Footer navigation">
    <a href="privacy.html">Privacy Policy</a>
    <a href="terms.html">Terms and Conditions</a>
</nav>

A screen reader can use these labels to distinguish between the two navigation sections.

Do not add unnecessary ARIA attributes when native HTML already provides the required semantics. Use clear, meaningful labels when multiple navigation landmarks need to be distinguished.

9. Navigation with Internal Page Links

A nav element can contain links to specific sections within the same webpage using fragment identifiers.

HTML Code

<nav aria-label="Page contents">
    <a href="#introduction">Introduction</a>
    <a href="#features">Features</a>
    <a href="#advantages">Advantages</a>
</nav>

<main>

    <section id="introduction">
        <h2>Introduction</h2>
        <p>Introduction content goes here.</p>
    </section>

    <section id="features">
        <h2>Features</h2>
        <p>Features content goes here.</p>
    </section>

    <section id="advantages">
        <h2>Advantages</h2>
        <p>Advantages content goes here.</p>
    </section>

</main>

Clicking a navigation link moves the browser to the corresponding element with the matching ID.

The following example demonstrates a navigation menu suitable for a learning portal like NS Learning Hub.

11. Important Technical Points

  • The nav element is a semantic HTML element.
  • It represents a major navigation section.
  • Anchor elements create the actual navigation links.
  • Navigation links can point to other pages or locations within the same page.
  • Multiple nav elements can be used when a page has multiple major navigation sections.
  • Use aria-label or aria-labelledby to distinguish navigation landmarks when necessary.
  • Not every group of links needs a nav element.
  • CSS controls the appearance and layout of navigation menus.
  • Flexbox is commonly used for horizontal navigation layouts.
  • Use meaningful link text and ensure navigation is keyboard accessible.

12. Common Mistakes

  1. Using nav for every group of links on a webpage.
  2. Forgetting anchor elements inside the navigation section.
  3. Using meaningless link text such as "Click here" repeatedly.
  4. Using duplicate IDs for internal navigation destinations.
  5. Creating navigation that cannot be operated using a keyboard.
  6. Using multiple navigation landmarks without distinguishing their purpose when appropriate.
  7. Assuming nav automatically creates a horizontal menu.
  8. Confusing the nav element with the anchor element.

14. Interview Questions and Answers

Q1. What is the nav element in HTML5?

It represents a section containing major navigation links.

Q2. Is nav a semantic element?

Yes. It identifies the purpose of a navigation section.

Q3. Which element creates clickable navigation links?

The anchor element, written as a.

Q4. Can a webpage contain multiple nav elements?

Yes. A webpage can have separate navigation sections.

Q5. What is the purpose of aria-label in nav?

It provides an accessible name to identify a navigation landmark.

Q6. Is using ul and li mandatory inside nav?

No. They are commonly used but not mandatory.

Q7. How can we create a horizontal navigation menu?

CSS Flexbox or another layout technique can arrange links horizontally.

Q8. What is the difference between nav and a?

Nav identifies a navigation section, while a creates an individual hyperlink.

Q9. Can nav contain internal page links?

Yes. Anchor links can use fragment identifiers to navigate to elements within the same page.

Q10. Should every group of links be placed inside nav?

No. Nav should be reserved for major navigation blocks.

16. Lesson Summary

  • The nav element represents a major navigation section.
  • Anchor elements create the actual hyperlinks.
  • Navigation can be horizontal or vertical using CSS.
  • Unordered lists are commonly used to organize navigation links.
  • Multiple nav elements can exist on a webpage.
  • Accessible names help distinguish multiple navigation landmarks.
  • Internal navigation uses fragment identifiers.
  • Navigation should be meaningful and keyboard accessible.
