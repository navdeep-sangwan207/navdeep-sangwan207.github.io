Aside Element

HTML5 – Chapter 9: HTML5 Semantic Elements | Lesson 6

1. Introduction

The HTML5 <aside> element represents content that is indirectly related to the main content surrounding it.

It is commonly used for supplementary information such as:

  • Sidebars
  • Related articles
  • Additional resources
  • Author information
  • Glossaries
  • Advertisements
  • Related links
  • Additional tips and notes

The aside element provides semantic meaning to supplementary content. It does not automatically create a sidebar layout.

2. Aside Element Syntax

Syntax

<aside>
    Supplementary content goes here.
</aside>

Example

<main>

    <article>
        <h2>Introduction to HTML5</h2>

        <p>
            HTML5 is used to structure
            content on webpages.
        </p>
    </article>

    <aside>
        <h3>Related Topics</h3>
        <ul>
            <li>HTML Elements</li>
            <li>HTML Attributes</li>
            <li>HTML Forms</li>
        </ul>
    </aside>

</main>
The aside element is appropriate when content is related to the surrounding content but is not part of its main flow.

3. Aside as a Sidebar

One of the most common uses of aside is creating a sidebar containing supplementary information.

HTML provides the semantic structure, while CSS controls the position and appearance of the sidebar.

HTML Code

<main>

    <article>
        <h2>Embedded Systems</h2>

        <p>
            Embedded systems combine hardware
            and software for dedicated tasks.
        </p>
    </article>

    <aside>
        <h3>Related Courses</h3>

        <ul>
            <li>Embedded C</li>
            <li>ARM Architecture</li>
            <li>RTOS</li>
        </ul>
    </aside>

</main>

CSS Layout

main {
    display: grid;
    grid-template-columns: 2fr 1fr;
    gap: 20px;
}

aside {
    background: #eaf3ff;
    padding: 15px;
    border-left: 4px solid #e76f00;
}

4. Aside Inside an Article

Aside can also be placed inside an article when the supplementary content is specifically related to that article.

Example

<article>

    <h2>Introduction to Linux</h2>

    <p>
        Linux is an open-source operating system
        built around the Linux kernel.
    </p>

    <aside>
        <h3>Did You Know?</h3>
        <p>
            Linux is widely used in servers,
            embedded systems and supercomputers.
        </p>
    </aside>

</article>

Here, the aside content provides additional information directly related to the Linux article.

5. Aside Outside the Main Element

An aside can also be placed outside main when it contains supplementary information related to the overall page.

Example

<body>

    <header>
        <h1>Programming Portal</h1>
    </header>

    <main>
        <article>
            <h2>C++ Programming</h2>
            <p>Learn C++ programming concepts.</p>
        </article>
    </main>

    <aside>
        <h2>Popular Courses</h2>
        <ul>
            <li>HTML5</li>
            <li>Linux</li>
            <li>Embedded C</li>
        </ul>
    </aside>

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>

In this example, aside contains information related to the overall programming portal rather than one specific article.

6. Aside vs Section vs Article

Feature aside section article
Purpose Supplementary content. Thematic grouping. Independent composition.
Relationship Indirectly related to surrounding content. Groups related topics. Can stand independently.
Common use Sidebar and related links. Chapter and topic sections. Blog post and news article.
Can be repeated? Yes. Yes. Yes.
Can contain other semantic elements? Yes. Yes. Yes.

7. Aside vs Div

aside div
Semantic HTML element. Generic non-semantic container.
Represents supplementary content. Does not define a specific content relationship.
Useful for related links and sidebars. Useful for styling and layout grouping.
Has a defined semantic purpose. Usually used with class or id.

Example: Aside

<aside>
    <h3>Related Resources</h3>
    <a href="linux.html">Linux Tutorials</a>
</aside>

Example: Div

<div class="sidebar-container">
    <h3>Sidebar Design</h3>
    <p>This is a generic layout container.</p>
</div>

8. Accessibility Considerations

Aside has an implicit complementary landmark role when it is associated with the page's main content. Assistive technologies can use landmarks to help users navigate a page.

Using aria-label

<aside aria-label="Related courses">

    <h2>Related Courses</h2>

    <ul>
        <li>HTML5</li>
        <li>CSS3</li>
        <li>JavaScript</li>
    </ul>

</aside>

Using aria-labelledby

<aside aria-labelledby="resources-heading">

    <h2 id="resources-heading">
        Additional Resources
    </h2>

    <p>Explore more learning materials.</p>

</aside>
  • Use meaningful headings for supplementary content.
  • Use aria-label or aria-labelledby when a complementary landmark needs a distinct accessible name.
  • Avoid unnecessary landmark labels.
  • Keep sidebar links descriptive and understandable.
  • Do not use aside for content that is essential to the main topic.
When multiple complementary landmarks exist, give them distinguishable accessible names so users can identify their purposes.

9. Complete Webpage Example

The following example combines header, navigation, main, article, aside and footer elements. 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Technology Blog</title>
</head>

<body>

    <header>
        <h1>Technology Blog</h1>
    </header>

    <nav aria-label="Main navigation">
        <a href="#home">Home</a>
        <a href="#articles">Articles</a>
    </nav>

    <main id="home">

        <article id="articles">
            <h2>Introduction to Embedded Systems</h2>

            <p>
                Embedded systems combine hardware
                and software to perform dedicated tasks.
            </p>

            <section>
                <h3>Applications</h3>
                <p>
                    Embedded systems are used in
                    automotive and industrial applications.
                </p>
            </section>
        </article>

        <aside aria-label="Related resources">
            <h2>Related Resources</h2>
            <ul>
                <li>Embedded C</li>
                <li>ARM Architecture</li>
                <li>FreeRTOS</li>
            </ul>
        </aside>

    </main>

    <footer>
        <p>Copyright 2026 Technology Blog</p>
    </footer>

</body>
</html>

10. Common Mistakes

  1. Using aside for the primary content of a webpage.
  2. Using aside only to create a visual sidebar.
  3. Using aside for content that is essential to understanding the main topic.
  4. Confusing aside with section and article.
  5. Assuming aside automatically appears on the right side of a webpage.
  6. Using aside as a generic replacement for div.
  7. Ignoring accessible headings and landmark names when needed.
  8. Using unnecessary supplementary content that distracts from the main topic.

12. Interview Questions and Answers

Q1. What is the aside element in HTML5?

It represents supplementary content indirectly related to its surrounding content.

Q2. What are common uses of aside?

Sidebars, related links, author information, advertisements and additional resources.

Q3. Does aside automatically create a sidebar?

No. CSS is required to control its position and appearance.

Q4. Can aside be placed inside article?

Yes. It can contain supplementary information related to that article.

Q5. Can aside be placed outside main?

Yes. It can contain supplementary information related to the overall page.

Q6. What is the difference between aside and section?

Aside represents supplementary content, while section groups content around a theme.

Q7. What is the difference between aside and div?

Aside has semantic meaning; div is a generic container.

Q8. Can a webpage contain multiple aside elements?

Yes. Each should represent meaningful supplementary content.

Q9. What is the accessibility role of aside?

It has an implicit complementary landmark role when associated with the page's main content.

Q10. Which attributes can provide an accessible name to aside?

aria-label and aria-labelledby can provide an accessible name when needed.

14. Lesson Summary

  • aside represents supplementary content related to surrounding content.
  • It is commonly used for sidebars, related links and additional resources.
  • It can be placed inside or outside main, depending on its relationship to the content.
  • It can be placed inside an article when supplementary information relates to that article.
  • CSS controls its visual position and layout.
  • Aside is different from article, section and div.
  • It has an implicit complementary landmark role in appropriate contexts.
  • Accessible names can be provided using aria-label or aria-labelledby.
