Unordered Lists in HTML

HTML5 – Complete Study Course | Chapter 4: HTML Lists

1. Introduction to Unordered Lists

An unordered list is used to display a collection of related items when their sequence is not important. The browser normally displays a bullet marker before each list item.

Common applications include:

  • Lists of programming languages
  • Product categories
  • Navigation menus
  • Technical skills
  • Shopping lists
  • Features of a software application

The <ul> element defines the unordered list, and the <li> element defines each individual list item.

2. Basic Syntax of an Unordered List

<ul>
    <li>First item</li>
    <li>Second item</li>
    <li>Third item</li>
</ul>
Expected Output:
  • First item
  • Second item
  • Third item

Each list item is displayed on a separate line. The browser normally uses a filled circular bullet as the default marker.

3. Default Bullet Markers

Browsers typically display unordered list items using filled circular bullets by default. The appearance of these markers can be changed using CSS.

Example

<h3>Technical Skills</h3>

<ul>
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Embedded C</li>
    <li>Linux</li>
</ul>
Expected Output:

Technical Skills

  • C Programming
  • C++ Programming
  • Embedded C
  • Linux

4. Bullet Marker Styles Using CSS

The CSS list-style-type property controls the marker style of an unordered list.

Common values include:

CSS Value Marker Appearance
disc Filled circular bullet
circle Hollow circular bullet
square Square bullet
none No marker

Example 1: Disc Marker

<ul style="list-style-type: disc;">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Expected Output:
  • HTML
  • CSS
  • JavaScript

Example 2: Circle Marker

<ul style="list-style-type: circle;">
    <li>Computer Hardware</li>
    <li>Computer Software</li>
    <li>Computer Networks</li>
</ul>
Expected Output:
  • Computer Hardware
  • Computer Software
  • Computer Networks

Example 3: Square Marker

<ul style="list-style-type: square;">
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Python Programming</li>
</ul>
Expected Output:
  • C Programming
  • C++ Programming
  • Python Programming

Example 4: No Marker

<ul style="list-style-type: none;">
    <li>Home</li>
    <li>About</li>
    <li>Services</li>
    <li>Contact</li>
</ul>
Expected Output:
  • Home
  • About
  • Services
  • Contact
Important: The marker styles shown here are controlled by CSS, not by separate HTML list elements. The HTML ul element provides the list structure.

5. The type Attribute and Legacy HTML

Older HTML versions supported a type attribute on the ul element to specify marker styles. For example, values included disc, circle and square. 

<ul type="square">
    <li>HTML</li>
    <li>CSS</li>
</ul>
Important: Do not use the type attribute on ul in modern HTML. It is obsolete. Use the CSS list-style-type property instead.

Recommended Modern Approach

<style>
    .skills-list {
        list-style-type: square;
    }
</style>

<ul class="skills-list">
    <li>Embedded C</li>
    <li>C++</li>
    <li>Linux</li>
</ul>
Expected Output:
  • Embedded C
  • C++
  • Linux

6. Changing Marker Position

CSS provides the list-style-position property to control the position of list markers.

Value Meaning
outside Marker is placed outside the principal content box of the list item.
inside Marker is placed inside the list item's content area.

Example: Outside Position

<ul style="list-style-position: outside;">
    <li>This is an example of an unordered list item with outside marker positioning.</li>
    <li>The marker is placed outside the text content area.</li>
</ul>
Expected Output:
  • This is an example of an unordered list item with outside marker positioning.
  • The marker is placed outside the text content area.

Example: Inside Position

<ul style="list-style-position: inside;">
    <li>This is an example of an unordered list item with inside marker positioning.</li>
    <li>The marker is placed inside the text content area.</li>
</ul>
Expected Output:
  • This is an example of an unordered list item with inside marker positioning.
  • The marker is placed inside the text content area.

7. Removing Default List Indentation

Browsers normally apply padding or indentation to lists. CSS can change this spacing.

Example

<ul style="list-style-type: none; padding-left: 0;">
    <li>Home</li>
    <li>About</li>
    <li>Services</li>
    <li>Contact</li>
</ul>
Expected Output:
  • Home
  • About
  • Services
  • Contact

This technique is commonly used when creating navigation menus.

8. Unordered Lists with Links

Unordered lists are frequently used to organize navigation links on websites.

Example

<ul>
    <li><a href="index.html">Home</a></li>
    <li><a href="about.html">About</a></li>
    <li><a href="services.html">Services</a></li>
    <li><a href="contact.html">Contact</a></li>
</ul>
Expected Output:
  • Home
  • About
  • Services
  • Contact

Each list item contains an anchor element. The anchor element creates the clickable link, while the list organizes the navigation items.

9. Unordered Lists with Images

An unordered list can contain images along with text inside its list items.

Example

<ul>
    <li>
        <img src="html.png" alt="HTML logo" width="30">
        HTML
    </li>

    <li>
        <img src="css.png" alt="CSS logo" width="30">
        CSS
    </li>
</ul>

The image files must exist at the specified paths for this example to display correctly.

10. Unordered Lists and Accessibility

  • Use ul when the order of the items is not meaningful.
  • Use meaningful text for every list item.
  • Use proper list elements instead of manually typing bullet symbols.
  • Keep related items grouped within the same list.
  • Use CSS to change the marker appearance.
  • Avoid removing markers if doing so makes the list structure difficult to understand.
Accessibility Tip: Semantic ul and li elements allow assistive technologies to identify list structure and communicate list information.

11. Difference Between ul and ol

Feature Unordered List (ul) Ordered List (ol)
Purpose Groups items without a required sequence. Groups items in a meaningful sequence.
Default marker Bullet Decimal number
List item li li
Typical use Collection of skills or products Instructions or rankings

14. Interview Questions and Answers

Q1. What is an unordered list in HTML?

An unordered list displays a collection of related items without a required sequence.

Q2. Which element creates an unordered list?

The ul element creates an unordered list.

Q3. Which element represents each list item?

The li element represents each list item.

Q4. What is the default unordered list marker?

Browsers typically display a filled circular bullet by default.

Q5. Which CSS property changes bullet styles?

The list-style-type property changes marker styles.

Q6. Name four common list-style-type values.

disc, circle, square and none.

Q7. What does list-style-type: none do?

It removes the list markers.

Q8. What is the purpose of list-style-position?

It controls whether list markers are positioned inside or outside the list item's content area.

Q9. Can an unordered list contain hyperlinks?

Yes. Anchor elements can be placed inside li elements to create navigation links.

Q10. Is the ul type attribute recommended in HTML5?

No. It is obsolete. CSS list-style-type should be used to control marker appearance.

15. Multiple Choice Questions (MCQs)

  1. Which element creates an unordered list?
    • A. ol
    • B. ul
    • C. dl
    • D. dt
    Answer: B. ul
  2. Which element defines an individual list item?
    • A. li
    • B. dd
    • C. dt
    • D. p
    Answer: A. li
  3. What is the default unordered list marker in most browsers?
    • A. Number
    • B. Roman numeral
    • C. Filled circular bullet
    • D. Uppercase letter
    Answer: C. Filled circular bullet
  4. Which CSS property controls list marker style?
    • A. font-size
    • B. list-style-type
    • C. text-decoration
    • D. display
    Answer: B. list-style-type
  5. Which value creates a square marker?
    • A. circle
    • B. disc
    • C. square
    • D. none
    Answer: C. square
  6. Which value removes list markers?
    • A. none
    • B. disc
    • C. circle
    • D. square
    Answer: A. none
  7. Which CSS property controls marker position?
    • A. list-position
    • B. marker-position
    • C. list-style-position
    • D. position-list
    Answer: C. list-style-position
  8. Which value places markers inside the list item's content area?
    • A. outside
    • B. inside
    • C. none
    • D. hidden
    Answer: B. inside
  9. Which list is most suitable for a collection of technical skills?
    • A. Unordered list
    • B. Ordered list
    • C. Description list only
    • D. Table only
    Answer: A. Unordered list
  10. Which attribute should not be used on ul in modern HTML?
    • A. class
    • B. id
    • C. type

16. Lesson Summary

  • The ul element creates an unordered list.

  • Unordered lists are used when sequence is not important.
  • Browsers typically use filled circular bullets by default.
  • CSS list-style-type changes marker appearance.
  • CSS list-style-position controls marker placement.
  • The type attribute on ul is obsolete in modern HTML.
  • Unordered lists are frequently used in navigation menus.
