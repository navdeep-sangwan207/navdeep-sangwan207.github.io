Ordered Lists in HTML

HTML5 – Complete Study Course | Chapter 4: HTML Lists

1. Introduction to Ordered Lists

An ordered list is an HTML list used to display items in a meaningful sequence. The position of each item matters because the items follow a particular order.

Ordered lists are commonly used for:

  • Step-by-step instructions
  • Installation procedures
  • Cooking recipes
  • Rankings and positions
  • Sequential learning activities

The <ol> element defines an ordered list, and the <li> element defines each list item.

2. Basic Syntax of an Ordered List

<ol>
    <li>First item</li>
    <li>Second item</li>
    <li>Third item</li>
</ol>
Expected Output:
  1. First item
  2. Second item
  3. Third item

By default, browsers display ordered list items using decimal numbers starting from 1.

3. Ordered List Numbering Types

The type attribute of the <ol> element controls the numbering marker style.

Type Value Marker Style Example
1 Decimal numbers 1, 2, 3, 4
A Uppercase letters A, B, C, D
a Lowercase letters a, b, c, d
I Uppercase Roman numerals I, II, III, IV
i Lowercase Roman numerals i, ii, iii, iv

Example 1: Decimal Numbering

<ol type="1">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
Output:
  1. HTML
  2. CSS
  3. JavaScript

Example 2: Uppercase Letters

<ol type="A">
    <li>Introduction</li>
    <li>Basics</li>
    <li>Advanced Topics</li>
</ol>
Output:
  1. Introduction
  2. Basics
  3. Advanced Topics

Example 3: Lowercase Letters

<ol type="a">
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Java Programming</li>
</ol>
Output:
  1. C Programming
  2. C++ Programming
  3. Java Programming

Example 4: Uppercase Roman Numerals

<ol type="I">
    <li>Chapter One</li>
    <li>Chapter Two</li>
    <li>Chapter Three</li>
</ol>
Output:
  1. Chapter One
  2. Chapter Two
  3. Chapter Three

Example 5: Lowercase Roman Numerals

<ol type="i">
    <li>Hardware</li>
    <li>Software</li>
    <li>Networking</li>
</ol>
Output:
  1. Hardware
  2. Software
  3. Networking
Note: The type attribute changes the numbering marker. CSS list-style-type can also control marker presentation.

4. The start Attribute

The start attribute specifies the starting number of an ordered list.

Its value must be an integer. The numbering then continues according to the selected marker style.

Example

<ol start="5">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
Expected Output:
  1. HTML
  2. CSS
  3. JavaScript

Example with Alphabetic Numbering

<ol type="A" start="3">
    <li>First Topic</li>
    <li>Second Topic</li>
    <li>Third Topic</li>
</ol>
Expected Output:
  1. First Topic
  2. Second Topic
  3. Third Topic

5. The reversed Attribute

The reversed attribute specifies that the ordered list numbering should run in descending order.

It is a Boolean attribute. Its presence enables reverse numbering.

Example

<ol reversed>
    <li>Third Position</li>
    <li>Second Position</li>
    <li>First Position</li>
</ol>
Expected Output:
  1. Third Position
  2. Second Position
  3. First Position

When the list contains three items and no explicit starting value, the numbering starts at 3 and decreases to 1.

6. The value Attribute of the li Element

The value attribute of an <li> element specifies the item's ordinal value in an ordered list.

It can change the numbering at a particular item. Subsequent items continue from that value.

Example

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li value="10">JavaScript</li>
    <li>React</li>
</ol>
Expected Output:
  1. HTML
  2. CSS
  3. JavaScript
  4. React

The resulting markers are 1, 2, 10 and 11.

7. Combining Ordered List Attributes

The type, start and reversed attributes can be combined to control list numbering.

Example: Reverse Alphabetic Numbering

<ol type="A" start="5" reversed>
    <li>Topic One</li>
    <li>Topic Two</li>
    <li>Topic Three</li>
</ol>
Expected Output:
  1. Topic One
  2. Topic Two
  3. Topic Three

The markers are E, D and C because the list begins at the fifth ordinal position and counts backward.

8. Ordered List with CSS

CSS can be used to control the appearance of ordered list markers.

Example: Using list-style-type

<style>
    .roman-list {
        list-style-type: upper-roman;
    }

    .alphabet-list {
        list-style-type: lower-alpha;
    }
</style>

<ol class="roman-list">
    <li>Introduction</li>
    <li>HTML Basics</li>
    <li>HTML Elements</li>
</ol>

<ol class="alphabet-list">
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Java Programming</li>
</ol>
Expected Output:
  1. Introduction
  2. HTML Basics
  3. HTML Elements
  1. C Programming
  2. C++ Programming
  3. Java Programming
Important: HTML defines the list structure and numbering information. CSS controls visual presentation. CSS is covered separately in the CSS3 course.

9. Nested Ordered Lists

A nested ordered list is an ordered list placed inside a list item of another list.

Example

<ol>
    <li>Programming
        <ol>
            <li>C</li>
            <li>C++</li>
        </ol>
    </li>

    <li>Web Development
        <ol>
            <li>HTML</li>
            <li>CSS</li>
        </ol>
    </li>
</ol>
Expected Output:
  1. Programming
    1. C
    2. C++
  2. Web Development
    1. HTML
    2. CSS

Nested lists are useful for representing chapters, subtopics and hierarchical procedures.

More detailed nested-list examples are covered in Lesson 5 of this chapter.

10. Difference Between Ordered List Attributes

Attribute Element Purpose
type ol Changes the numbering marker style.
start ol Sets the starting ordinal value.
reversed ol Reverses the numbering direction.
value li Sets the ordinal value for a particular list item.

11. Accessibility and Best Practices

  • Use ordered lists when the sequence of items has meaning.
  • Use descriptive text for every list item.
  • Do not use ordered lists merely to obtain numbered visual formatting.
  • Use nested lists when items have a genuine parent-child relationship.
  • Keep list structure logical and easy to understand.
  • Use CSS for advanced visual styling instead of relying on deprecated HTML attributes.
Remember: Ordered lists are semantic structures. Their order should represent a meaningful sequence, ranking or relationship.

14. Interview Questions and Answers

Q1. What is an ordered list in HTML?

An ordered list is a list in which items are arranged in a meaningful sequence.

Q2. Which HTML element creates an ordered list?

The ol element creates an ordered list.

Q3. Which element represents each ordered list item?

The li element represents each list item.

Q4. What is the default numbering style?

Decimal numbering: 1, 2, 3, and so on.

Q5. What is the purpose of the type attribute?

It specifies the numbering marker style, such as decimal numbers, letters or Roman numerals.

Q6. What is the purpose of the start attribute?

It specifies the starting ordinal value of an ordered list.

Q7. What is the reversed attribute?

It is a Boolean attribute that makes the list numbering run in descending order.

Q8. What is the value attribute of li?

It sets the ordinal value of an individual list item in an ordered list.

Q9. Can an ordered list contain another ordered list?

Yes. A nested ordered list can be placed inside a parent li element.

Q10. What is the difference between start and value?

The start attribute sets the initial ordinal value of the entire list, while value changes the ordinal value at a particular list item.

  • The ol element creates an ordered list.
