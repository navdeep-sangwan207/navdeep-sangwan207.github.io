List Attributes and Customization in HTML

HTML5 – Complete Study Course | Chapter 4: HTML Lists

1. Introduction to List Attributes and Customization

HTML provides attributes for controlling the numbering of ordered lists and the numbering of individual list items. CSS provides additional control over list markers, indentation, spacing, and appearance.

In this lesson, you will learn:

  • The start attribute
  • The reversed attribute
  • The type attribute
  • The value attribute of li
  • The CSS list-style-type property
  • The CSS list-style-position property
  • The CSS list-style-image property
  • The list-style shorthand property
  • Custom markers using ::marker
  • List spacing and indentation

2. The start Attribute

The start attribute specifies the starting number of an ordered list.

It accepts an integer value and is applicable to the ol element.

Example 1: Starting from 5

<ol start="5">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
Expected Output:
  1. HTML
  2. CSS
  3. JavaScript

Example 2: Starting from 10

<ol start="10">
    <li>Introduction</li>
    <li>Fundamentals</li>
    <li>Advanced Topics</li>
</ol>
Expected Output:
  1. Introduction
  2. Fundamentals
  3. Advanced Topics
Remember: The start attribute changes the starting number of the list. It does not change the number of list items.

3. The reversed Attribute

The reversed attribute specifies that the numbering of an ordered list should proceed in descending order.

It is a Boolean attribute. When present, it enables reversed numbering.

Example

<ol reversed>
    <li>Third Step</li>
    <li>Second Step</li>
    <li>First Step</li>
</ol>
Expected Output:
  1. Third Step
  2. Second Step
  3. First Step

Using reversed with start

<ol reversed start="5">
    <li>Task A</li>
    <li>Task B</li>
    <li>Task C</li>
</ol>
Expected Output:
  1. Task A
  2. Task B
  3. Task C

Here, the list starts at 5 and counts down to 3.

4. The type Attribute of Ordered Lists

The type attribute specifies the numbering style used by an ordered list.

Value Numbering Style Example
1 Decimal numbers 1, 2, 3
A Uppercase letters A, B, C
a Lowercase letters a, b, c
I Uppercase Roman numerals I, II, III
i Lowercase Roman numerals i, ii, iii

Example 1: Uppercase Letters

<ol type="A">
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Java Programming</li>
</ol>
Expected Output:
  1. C Programming
  2. C++ Programming
  3. Java Programming

Example 2: Lowercase Letters

<ol type="a">
    <li>Linux</li>
    <li>Windows</li>
    <li>macOS</li>
</ol>
Expected Output:
  1. Linux
  2. Windows
  3. macOS

Example 3: Uppercase Roman Numerals

<ol type="I">
    <li>Introduction</li>
    <li>Main Content</li>
    <li>Conclusion</li>
</ol>
Expected Output:
  1. Introduction
  2. Main Content
  3. Conclusion

Example 4: Lowercase Roman Numerals

<ol type="i">
    <li>Chapter One</li>
    <li>Chapter Two</li>
    <li>Chapter Three</li>
</ol>
Expected Output:
  1. Chapter One
  2. Chapter Two
  3. Chapter Three

5. The value Attribute of the li Element

The value attribute specifies the ordinal value of an individual list item in an ordered list.

It accepts an integer and can change the numbering sequence from that item onward.

Example

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li value="10">JavaScript</li>
    <li>React</li>
</ol>
Expected Output:
  1. HTML
  2. CSS
  3. JavaScript
  4. React

The third item is numbered 10, and the following item is numbered 11.

Important: The value attribute belongs to the li element. It is especially useful when a list has skipped or customized numbering.

6. The list-style-type CSS Property

The list-style-type property specifies the marker style used for list items.

It can be applied to ul, ol, or li elements through CSS.

Common Values

Value Description
disc Filled circular bullet
circle Hollow circular bullet
square Square bullet
decimal 1, 2, 3
decimal-leading-zero 01, 02, 03
lower-alpha a, b, c
upper-alpha A, B, C
lower-roman i, ii, iii
upper-roman I, II, III
none No visible marker

Example 1: Square Bullets

<style>
    ul {
        list-style-type: square;
    }
</style>

<ul>
    <li>Keyboard</li>
    <li>Mouse</li>
    <li>Monitor</li>
</ul>
Expected Output:
  • Keyboard
  • Mouse
  • Monitor

Example 2: Decimal Leading Zero

<ol style="list-style-type: decimal-leading-zero;">
    <li>Introduction</li>
    <li>Basics</li>
    <li>Advanced Topics</li>
</ol>
Expected Output:
  1. Introduction
  2. Basics
  3. Advanced Topics

Example 3: Removing List Markers

<ul style="list-style-type: none;">
    <li>Home</li>
    <li>About</li>
    <li>Contact</li>
</ul>
Expected Output:
  • Home
  • About
  • Contact

7. The list-style-position CSS Property

The list-style-position property specifies where the list marker is positioned relative to the content of the list item.

It has two commonly used values:

  • outside: The marker is outside the main content box.
  • inside: The marker is included inside the content box.

Example 1: Outside Position

<ul style="list-style-position: outside;">
    <li>This is a long list item that demonstrates
        how text wraps when the marker is outside.</li>
    <li>Second item</li>
</ul>
Expected Output:
  • This is a long list item that demonstrates how text wraps when the marker is outside.
  • Second item

Example 2: Inside Position

<ul style="list-style-position: inside;">
    <li>This is a long list item that demonstrates
        how text wraps when the marker is inside.</li>
    <li>Second item</li>
</ul>
Expected Output:
  • This is a long list item that demonstrates how text wraps when the marker is inside.
  • Second item

The difference is more noticeable when list items contain multiple lines of text.

8. The list-style-image CSS Property

The list-style-image property specifies an image to be used as the list marker.

Example

<style>
    ul {
        list-style-image: url("bullet.png");
    }
</style>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Note: The file bullet.png must exist at the specified relative path. If it cannot be loaded, browsers may use another available marker style.

For more predictable marker sizing and positioning, CSS pseudo-elements such as ::before can also be used.

9. The list-style Shorthand Property

The list-style property is a shorthand for setting list marker type, position, and image.

Example 1

<ul style="list-style: square outside;">
    <li>C Programming</li>
    <li>C++ Programming</li>
    <li>Embedded C</li>
</ul>
Expected Output:
  • C Programming
  • C++ Programming
  • Embedded C

Example 2

<ol style="list-style: upper-roman inside;">
    <li>Introduction</li>
    <li>Fundamentals</li>
    <li>Conclusion</li>
</ol>
Expected Output:
  1. Introduction
  2. Fundamentals
  3. Conclusion

10. Customizing Markers with ::marker

The ::marker pseudo-element allows CSS to style list item markers.

It can customize supported marker properties such as color, font-size, and font-weight.

Example

<style>
    li::marker {
        color: #174ea6;
        font-size: 20px;
        font-weight: bold;
    }
</style>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Expected Output:
  • ● HTML
  • ● CSS
  • ● JavaScript

The code above shows the intended visual effect. The actual ::marker styling is applied by the CSS rule in a browser.

11. Custom Markers Using CSS ::before

The ::before pseudo-element can insert custom decorative content before each list item.

Example

<style>
    .custom-list {
        list-style: none;
        padding-left: 0;
    }

    .custom-list li::before {
        content: "✓";
        color: green;
        font-weight: bold;
        margin-right: 10px;
    }
</style>

<ul class="custom-list">
    <li>Learn HTML</li>
    <li>Practice CSS</li>
    <li>Study JavaScript</li>
</ul>
Expected Output:
  • ✓ Learn HTML
  • ✓ Practice CSS
  • ✓ Study JavaScript
Accessibility: Decorative CSS-generated markers should not be the only way to communicate essential information. Keep meaningful text in the actual HTML content.

12. Controlling List Spacing and Indentation

CSS properties such as margin, padding, and line-height can control the spacing and indentation of lists.

Example

<style>
    ul {
        padding-left: 30px;
        margin-top: 15px;
        margin-bottom: 20px;
    }

    li {
        margin-bottom: 10px;
        line-height: 1.6;
    }
</style>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Expected Output:
  • HTML
  • CSS
  • JavaScript
CSS Property Purpose
margin Controls space outside an element.
padding Controls space inside an element.
line-height Controls the height of text lines.
list-style-type Controls the list marker style.
list-style-position Controls marker positioning.

13. HTML List Attributes vs CSS List Properties

Feature HTML Attribute CSS Property
Starting number start Not directly provided by a standard list property
Reverse numbering reversed Not directly provided by a standard list property
Ordered-list numbering type type list-style-type
Individual item numbering value on li CSS counters for advanced presentation
Marker position Not provided as a list attribute list-style-position
Marker image Not provided as a list attribute list-style-image
Spacing Not provided as a list attribute margin, padding
Technical distinction: HTML attributes define list numbering and structure. CSS properties control presentation. The ol type attribute and CSS list-style-type may both influence numbering appearance.

14. Accessibility and Best Practices

  • Choose ordered lists when sequence or ranking matters.
  • Choose unordered lists when item order is not important.
  • Use meaningful list items rather than decorative text alone.
  • Use CSS for visual customization instead of misusing HTML structure.
  • Maintain sufficient color contrast for custom markers.
  • Do not remove markers from meaningful lists without providing a clear visual structure.
  • Use nested lists only when the content has a genuine hierarchy.
  • Keep numbering consistent and understandable.

15. Complete Practical Example

The following program demonstrates ordered-list attributes, nested lists, and CSS customization in one webpage.

Complete HTML Program

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Customized HTML Lists</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            margin: 30px;
        }

        h1 {
            color: #174ea6;
        }

        .topics {
            list-style-type: square;
            padding-left: 30px;
        }

        .topics li {
            margin-bottom: 8px;
        }

        .steps {
            list-style-type: upper-roman;
        }

        .steps li::marker {
            color: #174ea6;
            font-weight: bold;
        }
    </style>
</head>

<body>

    <h1>Web Development Course</h1>

    <h2>Course Topics</h2>

    <ul class="topics">
        <li>HTML
            <ul>
                <li>HTML Elements</li>
                <li>HTML Attributes</li>
                <li>HTML Forms</li>
            </ul>
        </li>

        <li>CSS
            <ul>
                <li>Selectors</li>
                <li>Box Model</li>
                <li>Flexbox</li>

    </ul>

        <li>Learn HTML</li>
        <li>Practice CSS</li>
        <li>Build a Project</li>

    <ol reversed start="3">
        <li>Complete Exercises</li>
        <li>Revise Concepts</li>
        <li value="1">Take the Final Test</li>
    </ol>

</body>
</html>

17. Interview Questions and Answers

Q1. What is the purpose of the start attribute?

It specifies the starting ordinal number of an ordered list.

Q2. What does the reversed attribute do?

It makes an ordered list use descending numbering.

Q3. What is the purpose of the type attribute in ol?

It specifies the numbering style, such as decimal, alphabetic, or Roman numerals.

Q4. What is the value attribute of li?

It sets the ordinal value of an individual list item in an ordered list.

Q5. What does list-style-type do?

It specifies the marker style for list items.

Q6. What is the difference between disc and circle?

Disc creates a filled circular marker, whereas circle creates a hollow circular marker.

Q7. What is list-style-position?

It controls whether the marker appears inside or outside the list item's content box.

Q8. What is the purpose of list-style-image?

It specifies an image to be used as a list marker.

Q9. What is the ::marker pseudo-element?

It represents the marker box of a list item and allows supported marker styles to be customized.

Q10. What is the difference between list-style and list-style-type?

list-style is a shorthand property that can set marker type, position, and image. list-style-type sets only the marker type.

  • CSS list-style-image allows an image marker.
