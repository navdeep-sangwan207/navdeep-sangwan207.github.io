Chapter 13: HTML Iframes and Embedded Content

HTML5 – Complete Study Course

Learn how to embed external web pages, videos, maps and other resources into HTML documents.

Total Lessons: 7

Chapter Overview

HTML provides several elements for embedding external content inside a web page. The iframe element creates a nested browsing context that can display another web page within the current document.

In this chapter, you will learn how to use iframes, configure their attributes, embed external websites, integrate YouTube videos and maps, and understand iframe security. You will also study the object and embed elements.

Important: Some websites prevent their pages from being displayed inside iframes using security policies. An iframe does not automatically allow every external website to be embedded.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand the concept of embedded content.
  • Explain the purpose of the HTML iframe element.
  • Use iframe attributes such as src, title, width and height.
  • Embed external web pages in HTML documents.
  • Embed YouTube videos using iframe.
  • Display maps and other external content.
  • Understand iframe sandbox and security restrictions.
  • Differentiate iframe, object and embed elements.
  • Apply responsive iframe techniques.
