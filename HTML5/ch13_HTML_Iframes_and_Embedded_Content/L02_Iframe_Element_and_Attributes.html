Lesson 2: Iframe Element and Attributes

Chapter 13: HTML Iframes and Embedded Content

Understand the iframe element, its attributes, configuration options, and practical implementation.

1. Introduction to the Iframe Element

The HTML <iframe> element is used to embed another HTML document inside the current web page.

It creates a nested browsing context that displays a separate document within a rectangular area of the parent page.

Basic Syntax

<iframe src="page.html" width="600" height="400" title="Embedded Page"> </iframe>

The iframe element has an opening tag and a closing tag. It is not a void element.

2. The src Attribute

The src attribute specifies the URL of the document or resource to be embedded inside the iframe.

Example

<iframe src="about.html" title="About Page"> </iframe>

The browser attempts to load about.html inside the iframe.

Using an Absolute URL

<iframe src="https://www.example.com" title="Example Website"> </iframe>

Using a Relative URL

<iframe src="pages/contact.html" title="Contact Page"> </iframe>
The src URL must identify a resource that can be embedded. External websites may prevent embedding through security policies.

3. The width Attribute

The width attribute specifies the width of the iframe's viewport.

Example

<iframe src="about.html" width="600" title="About Page"> </iframe>

The width value is normally specified as a number of CSS pixels when using the HTML attribute.

Using CSS for Width

<iframe src="about.html" title="About Page" style="width: 100%;"> </iframe>

CSS is preferable when you need flexible or responsive sizing.

4. The height Attribute

The height attribute specifies the height of the iframe viewport.

Example

<iframe src="about.html" width="600" height="350" title="About Page"> </iframe>

The height attribute uses a numeric value representing CSS pixels.

Using CSS for Height

<iframe src="about.html" title="About Page" style="width: 100%; height: 350px;"> </iframe>
Width and height define the iframe's visible viewport. They do not necessarily control the dimensions of the embedded document's internal content.

5. The title Attribute

The title attribute provides a descriptive name for the iframe.

It is important for accessibility because screen readers can use it to identify the embedded content.

Example

<iframe src="about.html" title="Company About Information"> </iframe>

Good and Poor Examples

<!-- Poor description --> <iframe src="about.html" title="Frame"> </iframe> <!-- Better description --> <iframe src="about.html" title="Company About Information"> </iframe>

Every iframe should have a meaningful title, including iframes that contain third-party applications or videos.

6. The name Attribute

The name attribute assigns a name to the iframe's browsing context.

A link or form can use this name as a target to load a document into the iframe.

Example

<iframe name="contentFrame" title="Content Display Area" width="600" height="300"> </iframe> <a href="about.html" target="contentFrame"> Load About Page </a> <a href="contact.html" target="contentFrame"> Load Contact Page </a>

When a user selects either link, the requested page is loaded into the iframe named contentFrame.

The name attribute identifies a browsing context. It is different from the title attribute, which describes the iframe for users and assistive technologies.

7. The loading Attribute

The loading attribute controls how the browser schedules the loading of an iframe.

Available Values

Value Description
eager Load the iframe immediately when processing the document.
lazy Defer loading until the iframe is near the viewport.

Example: Eager Loading

<iframe src="about.html" loading="eager" title="About Page"> </iframe>

Example: Lazy Loading

<iframe src="about.html" loading="lazy" title="About Page"> </iframe>

Lazy loading can reduce unnecessary initial loading work when embedded content is located farther down the page.

Lazy loading is a browser optimization hint. It is not an exact loading schedule and does not guarantee a specific loading time.

8. The allow Attribute

The allow attribute specifies a Permissions Policy for features that may be available to the iframe.

It can delegate permission for features such as autoplay, fullscreen and camera access, subject to browser rules and other security restrictions.

Example

<iframe src="https://example.com" title="Embedded Application" allow="fullscreen"> </iframe>

Example with Multiple Features

<iframe src="https://example.com" title="Embedded Application" allow="fullscreen; autoplay"> </iframe>
The allow attribute does not automatically grant every requested capability. Browser support, user permission, secure contexts and other policies may still apply.

9. The allowfullscreen Attribute

The allowfullscreen attribute indicates that the iframe content may be allowed to enter fullscreen mode.

Example

<iframe src="https://www.youtube.com/embed/VIDEO_ID" title="HTML Tutorial Video" allowfullscreen> </iframe>

This attribute is commonly encountered in video embedding code.

The modern Permissions Policy equivalent is generally expressed using allow="fullscreen". The legacy allowfullscreen attribute remains widely supported.

10. The sandbox Attribute

The sandbox attribute applies restrictions to content loaded inside an iframe.

It is an important security feature for reducing the capabilities of embedded content.

Basic Sandbox Example

<iframe src="https://example.com" title="Restricted Embedded Page" sandbox> </iframe>

An empty sandbox attribute applies a restrictive set of sandbox rules. The embedded content may need additional permissions to work correctly.

Important Sandbox Tokens

Token Purpose
allow-scripts Allows scripts to execute.
allow-forms Allows form submission.
allow-same-origin Allows the embedded content to retain its origin rather than being assigned an opaque origin by sandboxing.
allow-popups Allows pop-up browsing contexts.
allow-downloads Allows downloads, subject to browser restrictions.
allow-modals Allows modal dialogs.
allow-presentation Allows presentation sessions.

Allowing Scripts and Forms

<iframe src="application.html" title="Embedded Application" sandbox="allow-scripts allow-forms"> </iframe>
Use sandbox permissions carefully. Combining allow-scripts and allow-same-origin for same-origin content can significantly weaken the intended sandbox protections. Avoid granting unnecessary permissions.

11. The referrerpolicy Attribute

The referrerpolicy attribute controls how much referrer information the browser sends when requesting the iframe resource.

Common Values

Value Purpose
no-referrer Does not send a Referer header.
origin Sends only the origin.
strict-origin Sends the origin when the security level is not downgraded.
origin-when-cross-origin Sends the full URL for same-origin requests and only the origin for cross-origin requests.
strict-origin-when-cross-origin Sends the full URL for same-origin requests and the origin for secure cross-origin requests.

Example

<iframe src="https://example.com" title="External Website" referrerpolicy="no-referrer"> </iframe>

The referrer policy helps control the information shared with the embedded resource.

12. The srcdoc Attribute

The srcdoc attribute allows an HTML document to be specified directly inside the iframe element.

It is useful when you want to embed a small HTML document without creating a separate HTML file.

Example

<iframe title="Embedded HTML Example" srcdoc="<h2>Hello World</h2> <p>This is embedded HTML.</p>"> </iframe>

The browser displays the HTML supplied through srcdoc.

When srcdoc and src are both specified, srcdoc takes precedence for the iframe's initial document. HTML placed inside an attribute must be correctly escaped.

13. The frameborder Attribute and Modern CSS

Older iframe examples often use the frameborder attribute to control the iframe border.

<!-- Old example --> <iframe src="about.html" frameborder="0"> </iframe>

The frameborder attribute is obsolete in modern HTML. Use CSS instead.

Modern Example

<iframe src="about.html" title="About Page" style="border: none;"> </iframe>

CSS provides more control over borders, radius, dimensions and responsive layout.

15. Complete Practical Example

The following example demonstrates several iframe attributes together.

HTML Code

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Iframe Attributes Demo</title> <style> .frame-container { width: 100%; max-width: 700px; margin: 20px auto; } iframe { width: 100%; height: 300px; border: 2px solid #174ea6; border-radius: 8px; } </style> </head> <body> <h1>Iframe Attributes Demonstration</h1> <div class="frame-container"> <iframe srcdoc="<h2>Welcome</h2><p>This is an embedded document.</p>" title="Welcome Message" loading="lazy" sandbox> </iframe> </div> </body> </html>

Expected Result

Iframe Attributes Demonstration

Welcome

This is an embedded document.

Note: The iframe uses inline HTML through srcdoc and applies sandbox restrictions.

16. Best Practices

  • Always provide a meaningful title attribute.
  • Use responsive CSS for iframe dimensions.
  • Use loading="lazy" for suitable below-the-fold content.
  • Use sandbox to restrict untrusted embedded content.
  • Grant only the permissions that are required.
  • Choose an appropriate referrer policy.
  • Use HTTPS URLs for external embedded resources.
  • Check whether the external website permits embedding.
  • Provide alternative links when useful.

17. Common Mistakes

  1. Using href instead of src in an iframe.
  2. Forgetting the closing iframe tag.
  3. Using width and height as CSS percentages in HTML attributes.
  4. Leaving out the title attribute.
  5. Granting unnecessary sandbox permissions.
  6. Assuming allow automatically grants browser permissions.
  7. Using the obsolete frameborder attribute.
  8. Confusing name with title.
  9. Expecting an external website to allow iframe embedding.

19. Interview Questions and Answers

Q1. Which element is used to embed another HTML document?
The <iframe> element.
Q2. What is the purpose of src?
It specifies the URL of the resource to be embedded.
Q3. Why is title important?
It provides an accessible description of the embedded browsing context.
Q4. What is the difference between name and title?
Name identifies the browsing context for targeting. Title describes the iframe's purpose to users and assistive technologies.
Q5. What is lazy loading?
It defers loading an iframe until it approaches the browser viewport.
Q6. What is the purpose of sandbox?
It applies restrictions to the content loaded inside an iframe.
Q7. What does allow-scripts do?
It allows scripts to execute in the sandboxed iframe.
Q8. What is srcdoc?
It specifies an HTML document directly inside the iframe element.
Q9. What is referrerpolicy?
It controls the referrer information sent when requesting the embedded resource.
Q10. Is frameborder a modern HTML attribute?
No. It is obsolete. CSS should be used to style iframe borders.
Q11. What does allowfullscreen do?
It indicates that the iframe content may be allowed to enter fullscreen mode.
Q12. Can iframe dimensions be controlled using CSS?
Yes. CSS width, height, max-width and aspect-ratio can control iframe layout.
