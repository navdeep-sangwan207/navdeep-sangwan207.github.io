Lesson 1: Introduction to Iframes

Chapter 13: HTML Iframes and Embedded Content

Learn how to display another HTML document inside the current web page using the iframe element.

1. Introduction to Embedded Content

Embedded content refers to external or separate resources displayed within a web page. Instead of navigating away from the current page, users can view the embedded resource inside the same page.

HTML provides different elements for embedding content, including:

  • iframe: Embeds another HTML document as a nested browsing context.
  • object: Embeds an external resource, such as a document or other supported content.
  • embed: Embeds an external resource using an element with no closing tag.

In this lesson, we focus on the iframe element.

2. What is an Iframe?

Iframe stands for Inline Frame. It is an HTML element used to embed another HTML document inside the current document.

The iframe creates a separate browsing context within the current web page.

Basic Syntax

<iframe src="page.html"></iframe>

Example

<!DOCTYPE html> <html lang="en"> <head> <title>Iframe Example</title> </head> <body> <h1>My Main Web Page</h1> <iframe src="about.html" title="About Page" width="500" height="300"> </iframe> </body> </html>

Explanation

  • iframe: Creates the embedded browsing area.
  • src: Specifies the URL of the document to embed.
  • title: Provides an accessible description of the iframe.
  • width: Specifies the iframe width.
  • height: Specifies the iframe height.

3. How Does an Iframe Work?

When a browser loads an iframe, it creates a nested browsing context and loads the resource specified by its src attribute.

Working Process

  1. The browser loads the main HTML document.
  2. The browser encounters an iframe element.
  3. It creates a nested browsing context.
  4. It requests the resource specified in src.
  5. The embedded document is loaded inside the iframe area, if permitted.

Diagram

+--------------------------------------+
|          Main HTML Document          |
|                                      |
|       Main Page Content              |
|                                      |
|   +------------------------------+   |
|   |       Iframe Area            |   |
|   |                              |   |
|   |   Embedded HTML Document     |   |
|   |                              |   |
|   |   Its own page content       |   |
|   +------------------------------+   |
|                                      |
+--------------------------------------+

The embedded document has its own document and browsing context. It is not simply copied into the parent page.

4. Creating Your First Iframe

Create two HTML files in the same folder to understand iframe embedding.

File 1: index.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Main Page</title> </head> <body> <h1>Welcome to My Website</h1> <p>This is the main HTML document.</p> <h2>Embedded Page</h2> <iframe src="about.html" title="Embedded About Page" width="500" height="250"> </iframe> </body> </html>

File 2: about.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>About Page</title> </head> <body> <h2>About Us</h2> <p>This content is loaded inside an iframe.</p> </body> </html>

Expected Result

Welcome to My Website

This is the main HTML document.

Embedded Page

About Us

This content is loaded inside an iframe.

The content of about.html appears inside the iframe area of index.html.

5. Embedding an External Website

An iframe can also load a web page from another website by using an absolute URL.

Example

<iframe src="https://www.example.com" title="Example Website" width="600" height="400"> </iframe>

The browser attempts to load the external website inside the iframe.

Not every website permits iframe embedding. The external website may use HTTP response headers or Content Security Policy directives that prevent it from being displayed inside another website.

6. Iframe as a Nested Browsing Context

A browsing context is an environment in which a browser displays a document. An iframe creates a nested browsing context inside the parent document.

Important Characteristics

  • The iframe has its own document.
  • It has its own window object.
  • It can load a different URL from the parent page.
  • It can contain its own HTML, CSS and JavaScript.
  • It can have a different origin from the parent document.
  • Browser security policies restrict access between different origins.

Parent and Child Documents

Parent Document
      |
      |-- Parent HTML
      |
      |-- Parent CSS
      |
      |-- Parent JavaScript
      |
      +-- Iframe
              |
              |-- Child HTML
              |
              |-- Child CSS
              |
              +-- Child JavaScript

7. Iframe and Normal Hyperlinks

A hyperlink navigates to another resource, while an iframe displays another document inside the current page.

Feature Hyperlink Iframe
HTML Element <a> <iframe>
Purpose Navigate to another resource. Embed another document.
Display Usually opens in a browsing context. Displays inside the current page.
Nested Context Does not create one by itself. Creates a nested browsing context.
Example Website navigation link. Embedded document or video.

Hyperlink Example

<a href="about.html"> Open About Page </a>

Iframe Example

<iframe src="about.html" title="About Page"> </iframe>

8. Practical Applications of Iframes

1. Embedding Videos

YouTube videos can be embedded inside a web page using iframe.

<iframe src="https://www.youtube.com/embed/VIDEO_ID" title="HTML Tutorial Video" allowfullscreen> </iframe>

2. Embedding Maps

Map services can provide iframe embed code to display a location.

3. Embedding Documents

Some document viewers allow PDFs or presentations to be displayed inside an iframe.

4. Embedding External Applications

An iframe can display third-party widgets, dashboards or applications when the provider permits embedding.

5. Online Learning Platforms

An educational website can embed learning videos, maps, interactive resources and external demonstrations.

9. Advantages of Iframes

  • Display external documents within a page.
  • Integrate third-party content.
  • Keep the parent page visible while viewing embedded content.
  • Load a separate document with its own structure.
  • Support embedding videos, maps and other web resources.
  • Provide some isolation between parent and embedded documents.

10. Limitations of Iframes

  • Some websites block iframe embedding.
  • Embedded content may not adapt automatically to screen size.
  • Multiple large iframes can affect page performance.
  • Cross-origin restrictions limit access between documents.
  • Accessibility requires meaningful iframe titles.
  • Embedded content may have its own navigation and scrolling.
  • Security and permissions require careful configuration.

11. Iframe Accessibility

Accessibility is important when using embedded documents.

Use the title Attribute

<iframe src="about.html" title="Company About Information"> </iframe>

The title attribute provides a description that assistive technologies can use to identify the embedded content.

Other Good Practices

  • Use a meaningful title for every iframe.
  • Explain the purpose of important embedded content.
  • Provide a normal link as an alternative when appropriate.
  • Ensure the embedded content is usable with a keyboard.
  • Avoid unnecessary nested browsing contexts.

12. Common Iframe Mistakes

  1. Forgetting the src attribute.
  2. Using an incorrect URL or file path.
  3. Not providing a meaningful title.
  4. Assuming every external website allows embedding.
  5. Using fixed dimensions without considering mobile screens.
  6. Ignoring iframe security settings.
  7. Embedding too many external resources.
  8. Assuming the parent page can freely access a cross-origin iframe document.

14. Interview Questions and Answers

Q1. What is an iframe in HTML?
An iframe is an HTML element that embeds another HTML document inside the current document by creating a nested browsing context.
Q2. What is the full form of iframe?
Inline Frame.
Q3. Which HTML element is used to create an iframe?
The <iframe> element.
Q4. Which attribute specifies the embedded resource?
The src attribute.
Q5. What is a nested browsing context?
It is a browsing environment created inside another browsing context, such as an iframe inside a web page.
Q6. Can an iframe load another website?
Yes, if the external website permits embedding and the browser's security policies allow the resource to load.
Q7. What is the purpose of the title attribute?
It provides an accessible description of the iframe's content.
Q8. Can an iframe contain its own CSS and JavaScript?
Yes. The embedded document can have its own HTML, CSS and JavaScript.
Q9. Can every website be embedded using iframe?
No. A website can restrict embedding through HTTP headers and Content Security Policy.
Q10. What is the difference between an iframe and a hyperlink?
A hyperlink navigates to a resource, while an iframe displays another document within the current page.
Q11. Does an iframe create a separate document?
Yes. It creates a nested browsing context with its own document.
Q12. Name some applications of iframes.
YouTube videos, maps, external websites, document viewers and third-party widgets.
