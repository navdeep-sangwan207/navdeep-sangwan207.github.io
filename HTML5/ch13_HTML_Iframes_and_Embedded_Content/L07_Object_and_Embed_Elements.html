Lesson 7: Object and Embed Elements

Chapter 13: HTML Iframes and Embedded Content

Learn how to embed external resources such as PDF documents and other supported content using HTML.

1. Introduction to Object and Embed Elements

HTML provides the <object> and <embed> elements to include external resources inside a web page.

These elements can be used for resources such as PDF documents, images and other content supported by the browser.

Object Element

The <object> element represents an external resource that can be treated as an embedded object. It can also contain fallback content.

Embed Element

The <embed> element embeds an external resource at the specified location in the document.

Basic Syntax

<object data="document.pdf" type="application/pdf" width="600" height="400"> PDF preview is not available. </object> <embed src="document.pdf" type="application/pdf" width="600" height="400">

2. The HTML Object Element

The <object> element is used to embed an external resource into an HTML document.

Syntax

<object data="resource-url" type="media-type" width="600" height="400"> Fallback content goes here. </object>

Important Attributes

Attribute Purpose
data Specifies the URL of the external resource.
type Specifies the expected MIME type.
width Specifies the displayed width.
height Specifies the displayed height.
name Specifies a name for the embedded browsing context or object, where applicable.
form Associates the object with a form by its ID.

Example

<object data="sample.pdf" type="application/pdf" width="700" height="450"> <p> Your browser cannot display this PDF. <a href="sample.pdf"> Download the PDF </a> </p> </object>
The fallback content inside the object element can provide a message or alternative link when the resource cannot be presented.

3. Embedding PDF Documents Using Object

A PDF document can be embedded using the object element when the browser supports displaying the PDF resource.

Example

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>PDF Viewer</title> </head> <body> <h1>HTML Study Material</h1> <object data="notes.pdf" type="application/pdf" width="100%" height="600"> <p> PDF preview is unavailable. <a href="notes.pdf"> Open or download the PDF </a> </p> </object> </body> </html>

Expected Result

  • A heading displays: HTML Study Material.
  • The browser attempts to display notes.pdf.
  • If the resource cannot be displayed, fallback content provides a link.

The PDF file must exist at the specified relative path. Browser PDF support and server response configuration can affect the result.

4. The HTML Embed Element

The <embed> element is used to embed an external resource directly into a web page.

Syntax

<embed src="resource-url" type="media-type" width="600" height="400">

Important Attributes

Attribute Purpose
src Specifies the URL of the embedded resource.
type Specifies the MIME type of the resource.
width Specifies the width of the embedded content.
height Specifies the height of the embedded content.

PDF Example

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Embed PDF</title> </head> <body> <h1>Embedded PDF Document</h1> <embed src="notes.pdf" type="application/pdf" width="100%" height="600"> </body> </html>
Embed is a void element. It has no closing tag and cannot contain fallback child content.

5. Object vs Embed Elements

Both elements can embed external resources, but their HTML structures and fallback behavior are different.

Feature Object Embed
Element type Normal element with opening and closing tags Void element
Resource URL data src
MIME type type type
Fallback content Can contain fallback content Cannot contain child fallback content
Closing tag Required Not used
Common use PDF and supported external resources Supported embedded resources

Object Example

<object data="document.pdf" type="application/pdf"> PDF is not available. </object>

Embed Example

<embed src="document.pdf" type="application/pdf">

6. Understanding MIME Types

MIME types identify the format of a resource being transmitted or embedded.

Common MIME Types

Resource MIME Type
PDF application/pdf
HTML text/html
Plain Text text/plain
PNG Image image/png
JPEG Image image/jpeg
SVG Image image/svg+xml
MP3 Audio audio/mpeg
MP4 Video video/mp4

The type attribute provides the expected media type. It does not guarantee that the browser supports the resource.

7. Fallback Content in Object

Fallback content is alternative information provided when an embedded resource cannot be presented.

Example

<object data="manual.pdf" type="application/pdf" width="100%" height="500"> <h2>PDF Not Available</h2> <p> Your browser cannot display this document. </p> <a href="manual.pdf"> Open PDF </a> </object>

Benefits of Fallback Content

  • Provides an alternative when embedding fails.
  • Improves usability.
  • Provides a direct link to the resource.
  • Helps users access the content through another method.
Fallback content is not a guarantee that every resource failure will be detected. For important documents, provide a separate visible link outside the embedded element as well.

8. Object and Embed vs Iframe

The iframe, object and embed elements all allow external content to appear inside an HTML page, but they serve different purposes.

Feature Iframe Object Embed
Main purpose Embed another browsing context Embed an external resource Embed an external resource
URL attribute src data src
Fallback children Yes, for browsers that do not support iframe Yes No
Sandbox attribute Yes No No
Separate document context Yes Depends on the embedded resource Depends on the embedded resource

When to Use Each Element

  • iframe: Embedding another web page, map or video player.
  • object: Embedding supported external resources with fallback content, such as a PDF.
  • embed: Embedding a supported external resource directly.

9. Practical Example: Embedding a PDF in a Learning Portal

Consider an educational website that provides PDF study notes to students. The object element can be used to display a document with a fallback link.

Folder Structure

html5/ │ ├── ch13_HTML_Iframes_and_Embedded_Content/ │ └── L07_Object_and_Embed_Elements.html │ └── resources/ └── html5-notes.pdf

HTML Code

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>HTML5 Study Notes</title> <style> .pdf-container { width: 100%; height: 600px; border: 1px solid #ccc; } </style> </head> <body> <h1>HTML5 Study Notes</h1> <object class="pdf-container" data="../resources/html5-notes.pdf" type="application/pdf"> <p> PDF preview is unavailable. <a href="../resources/html5-notes.pdf"> Open or download notes </a> </p> </object> <p> <a href="../resources/html5-notes.pdf"> Open PDF separately </a> </p> </body> </html>
Expected Result:
  • A heading displays HTML5 Study Notes.
  • The browser attempts to display the PDF.
  • A separate link allows the student to open the PDF.
  • If inline display is unavailable, fallback text and link are provided.

The folder structure is illustrative. Adjust the relative path if your PDF is stored in a different folder.

10. Responsive Embedded Resources

Fixed dimensions may not fit small screens. CSS can be used to make embedded content responsive.

Example

<style> .document-viewer { width: 100%; height: 70vh; min-height: 400px; border: 1px solid #ccc; } </style> <object class="document-viewer" data="notes.pdf" type="application/pdf"> <a href="notes.pdf"> Open PDF </a> </object>

The width adjusts to the available container width. The height uses a viewport-relative value with a minimum height.

11. Security and Accessibility Considerations

Security

  • Embed resources only from trusted sources.
  • Use HTTPS when loading external resources.
  • Check the origin and reliability of external documents.
  • Do not assume object or embed provides iframe sandbox protection.
  • Keep browser and server software updated.
  • Use Content Security Policy to control permitted resource sources.

Accessibility

  • Provide a descriptive heading for embedded content.
  • Provide a visible link to important documents.
  • Explain the format and purpose of the embedded resource.
  • Ensure keyboard users can access alternative links.
  • Do not make important information available only through an embedded preview.
The object and embed elements do not provide the same title attribute mechanism as iframe. Use surrounding headings and descriptive text to explain the purpose of the resource.

12. Common Mistakes

Mistake Correct Practice
Using src with object. Use data with object.
Using data with embed. Use src with embed.
Adding a closing tag to embed. Remember embed is a void element.
Expecting fallback children inside embed. Use object or provide a separate link.
Assuming every browser displays every PDF. Provide an alternative link.
Using incorrect MIME types. Specify the correct expected media type.
Using fixed dimensions on every screen. Use responsive CSS dimensions.

14. Interview Questions and Answers

Q1. What is the object element in HTML?
It embeds an external resource into an HTML document and can provide fallback content.
Q2. What is the embed element?
It embeds an external resource directly into an HTML page.
Q3. Which attribute specifies the resource URL in object?
The data attribute.
Q4. Which attribute specifies the resource URL in embed?
The src attribute.
Q5. Can object contain fallback content?
Yes. Content inside object can provide an alternative when the resource cannot be presented.
Q6. Can embed contain fallback content?
No. Embed is a void element and cannot contain child elements.
Q7. Is embed a void element?
Yes. It does not have a closing tag.
Q8. What is a MIME type?
It identifies the format of a resource, such as application/pdf or image/png.
Q9. How can a PDF be embedded using object?
Use the data attribute with a PDF URL and type="application/pdf".
Q10. What is the main difference between object and iframe?
Iframe creates a nested browsing context for another document, while object embeds an external resource.
Q11. Why is fallback content useful?
It provides an alternative when an embedded resource cannot be displayed.
Q12. Does the type attribute guarantee browser support?
No. It identifies the expected MIME type but does not guarantee that the browser can display the resource.
Q13. Can object embed an image?
Yes, if the resource type is supported by the browser.
Q14. Which element is generally appropriate for embedding another web page?
The iframe element.
Q15. Why should an alternative PDF link be provided?
It gives users another way to access the document when inline PDF display is unavailable.
