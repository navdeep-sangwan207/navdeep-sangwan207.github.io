Lesson 3: Embedding Web Pages

Chapter 13: HTML Iframes and Embedded Content

Learn how to embed local HTML documents and external websites inside a web page using iframes.

1. Introduction to Embedding Web Pages

Embedding a web page means displaying another HTML document inside the current web page without navigating away from it.

HTML provides the <iframe> element for this purpose.

Basic Syntax

<iframe src="page.html" title="Embedded Web Page" width="600" height="400"> </iframe>

The src attribute identifies the document to embed. The browser loads that document inside the iframe's browsing context.

2. Embedding a Local HTML Page

A local HTML page is a document stored within the same website or project. It can be embedded by specifying its relative or absolute URL.

Example Folder Structure

my-website/
│
├── index.html
│
├── about.html
│
└── pages/
    └── contact.html

Main File: index.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Main Page</title> </head> <body> <h1>My Website</h1> <p>This is the main page.</p> <h2>About Us</h2> <iframe src="about.html" title="About Us" width="600" height="300"> </iframe> </body> </html>

Embedded File: about.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>About Us</title> </head> <body> <h2>About Our Company</h2> <p> We provide educational resources and technical learning materials. </p> </body> </html>

Expected Result

My Website

This is the main page.

About Us

About Our Company

We provide educational resources and technical learning materials.

The content of about.html appears inside the iframe area.

3. Embedding a Page from a Subfolder

If the HTML file is stored inside a subfolder, its relative path must be specified correctly.

Folder Structure

my-website/
│
├── index.html
│
└── pages/
    └── contact.html

Example

<iframe src="pages/contact.html" title="Contact Page" width="600" height="300"> </iframe>

Since index.html is in the root directory, the browser looks for contact.html inside the pages folder.

4. Understanding Relative Paths

A relative path identifies a resource based on the location of the current document or URL.

Path Meaning
about.html File in the same directory.
pages/about.html File inside the pages directory.
./about.html File in the current directory.
../about.html File in the parent directory.
../../about.html File two directory levels above.

Example: Parent Directory

my-website/
│
├── about.html
│
└── pages/
    └── index.html

From pages/index.html, use:

<iframe src="../about.html" title="About Page"> </iframe>

The ../ portion moves one directory level upward.

Relative paths are resolved against the document's URL, taking any applicable base URL into account. They are not necessarily resolved against the physical location of a file on the server.

5. Embedding an External Website

An external website is hosted on another domain or web server.

You can attempt to embed an external website using its absolute URL.

Example

<iframe src="https://www.example.com" title="Example Website" width="700" height="400"> </iframe>

The browser requests the external resource and attempts to display it inside the iframe.

An external website can prevent its pages from being embedded. Therefore, specifying a valid URL does not guarantee that the content will appear.

6. Absolute URLs and Relative URLs

Absolute URL

An absolute URL specifies the complete address of a resource, including its scheme and domain.

<iframe src="https://www.example.com/about.html" title="External About Page"> </iframe>

Relative URL

A relative URL specifies a resource location in relation to the current document's URL.

<iframe src="about.html" title="Local About Page"> </iframe>
Feature Absolute URL Relative URL
Complete Address Usually includes scheme and domain. Uses a path relative to a base URL.
Domain Can explicitly identify a domain. Inherits the applicable base URL's origin.
Example https://example.com/page.html pages/page.html
Typical Usage External resources. Resources within a website.

7. Embedding a Web Page with CSS

CSS can control the appearance and dimensions of an iframe.

Example

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Iframe Styling</title> <style> .embedded-page { width: 100%; height: 350px; border: 2px solid #174ea6; border-radius: 8px; } </style> </head> <body> <h1>Embedded Web Page</h1> <iframe class="embedded-page" src="about.html" title="Embedded About Page"> </iframe> </body> </html>

The CSS class controls the iframe's width, height, border and corner radius.

8. Responsive Iframes

A responsive iframe adjusts to the available width of its container. This is important for mobile devices and smaller screens.

Using width: 100%

<iframe src="about.html" title="About Page" style="width: 100%; height: 350px;"> </iframe>

Using the CSS aspect-ratio Property

<style> .responsive-frame { width: 100%; aspect-ratio: 16 / 9; border: none; } </style> <iframe class="responsive-frame" src="about.html" title="Responsive Embedded Page"> </iframe>

The aspect-ratio property maintains a 16:9 width-to-height ratio as the available width changes.

Responsive Container Example

<style> .iframe-container { width: 100%; max-width: 800px; margin: auto; } .iframe-container iframe { display: block; width: 100%; aspect-ratio: 16 / 9; border: 0; } </style> <div class="iframe-container"> <iframe src="about.html" title="Embedded Page"> </iframe> </div>

9. Cross-Origin Iframe Restrictions

A web page may embed a document from another origin, but browser security rules restrict how the parent page can access the embedded document.

What is an Origin?

An origin is determined by three components:

  • Scheme or protocol
  • Host or domain
  • Port

Example

Parent Page:

https://www.example.com/page.html

Embedded Page:

https://www.otherwebsite.com/content.html

These pages have different origins.

Same-Origin Policy

The same-origin policy is a browser security mechanism that restricts scripts from accessing certain resources belonging to a different origin.

For example, JavaScript running in the parent page cannot freely inspect or modify the DOM of a cross-origin iframe.

Example of Restricted Access

<iframe id="externalFrame" src="https://www.otherwebsite.com" title="External Website"> </iframe> <script> const frame = document.getElementById( "externalFrame" ); // Cross-origin access is restricted. // This can throw a SecurityError. console.log( frame.contentWindow.document.body ); </script>
Cross-origin iframe access is restricted by the same-origin policy. It is not necessarily impossible to communicate: the parent and embedded page can use window.postMessage() with appropriate origin validation.

10. Why Some Websites Cannot Be Embedded

Some websites intentionally prevent their pages from being displayed inside third-party iframes.

Two important security mechanisms are:

1. X-Frame-Options

The X-Frame-Options HTTP response header controls whether a page can be displayed inside a frame.

Common values include:

  • DENY: Prevents framing.
  • SAMEORIGIN: Allows framing only from the same origin.
  • ALLOW-FROM: An obsolete directive that is not supported by modern browsers.

2. Content Security Policy

The Content Security Policy (CSP) frame-ancestors directive specifies which origins may embed a page.

Example HTTP Header

Content-Security-Policy: frame-ancestors 'self' https://trusted.example;

This policy permits the page to be embedded by itself and the specified trusted origin.

These controls are sent by the server hosting the embedded document. Changing the iframe HTML on your own page cannot override the external website's framing restrictions.

11. Communication Between Parent and Iframe

The window.postMessage() API allows controlled communication between a parent window and an embedded iframe, including across different origins.

Parent Page Example

<iframe id="childFrame" src="child.html" title="Child Document"> </iframe> <script> const frame = document.getElementById( "childFrame" ); frame.addEventListener("load", function () { frame.contentWindow.postMessage( "Hello from parent", "https://parent.example" ); }); </script>

Important Note

The target origin must match the receiving document's actual origin. In production, use the exact trusted origin rather than a wildcard.

The receiving page must listen for the message and validate event.origin before trusting the message.

Child Page Example

<script> window.addEventListener( "message", function (event) { if ( event.origin !== "https://parent.example" ) { return; } console.log( "Message received:", event.data ); } ); </script>
This is a communication pattern, not a complete deployment example. Replace the example origins with the actual origins of the parent and child pages.

12. Practical Application in NS Learning Hub

An educational website can use iframes to display a separate HTML demonstration page inside a lesson.

    │

Embedding the About Page

<iframe src="examples/about.html" title="About Page Demonstration" loading="lazy" style="width: 100%; height: 300px; border: 2px solid #174ea6;"> </iframe>

Since the lesson and examples folder are inside the same chapter directory, examples/about.html is a valid relative path from this lesson.

Embedding the Contact Page

<iframe src="examples/contact.html" title="Contact Page Demonstration" style="width: 100%; height: 300px;"> </iframe>

This approach can be used to display separate practical demonstrations within your HTML5 lessons.

13. Advantages of Embedding Web Pages

  • Displays another document without leaving the current page.
  • Allows integration of external resources.
  • Supports separate HTML documents.
  • Can display learning demonstrations and examples.
  • Supports responsive layouts using CSS.
  • Allows controlled communication using postMessage().

14. Limitations and Security Considerations

  • External websites may block iframe embedding.
  • Cross-origin restrictions limit DOM access.
  • Embedded pages may have separate scrolling behavior.
  • Third-party content can affect page performance.
  • Untrusted content should be sandboxed appropriately.
  • Message receivers should validate event.origin.
  • Responsive behavior must be considered.
  • Embedded content requires meaningful accessibility descriptions.

15. Common Mistakes

  1. Using an incorrect relative file path.
  2. Confusing absolute and relative URLs.
  3. Assuming all external websites allow embedding.
  4. Using fixed iframe dimensions on every screen.
  5. Trying to access cross-origin iframe DOM directly.
  6. Using wildcard target origins unnecessarily with postMessage().
  7. Failing to validate the origin of received messages.
  8. Ignoring iframe accessibility and security.

17. Interview Questions and Answers

Q1. How do you embed another HTML page?
By using the iframe element with its src attribute pointing to the target document.
Q2. Can a local HTML page be embedded?
Yes. A local or same-site HTML document can be embedded using an appropriate relative or absolute URL.
Q3. What is an absolute URL?
An absolute URL identifies a resource using a complete address, including its scheme and domain.
Q4. What is a relative URL?
A relative URL identifies a resource in relation to the applicable base URL.
Q5. What is the same-origin policy?
It is a browser security mechanism that restricts scripts from accessing certain resources across different origins.
Q6. What is a cross-origin iframe?
It is an iframe whose embedded document has a different origin from its parent document.
Q7. Can every external website be embedded?
No. The external server may prevent framing through X-Frame-Options or CSP frame-ancestors.
Q8. What is X-Frame-Options?
It is an HTTP response header that controls whether a page can be displayed inside a frame.
Q9. What is CSP frame-ancestors?
It is a Content Security Policy directive that controls which origins may embed a page.
Q10. What is postMessage()?
It is a browser API for sending messages between browsing contexts, including cross-origin windows.
Q11. Why should event.origin be checked?
It helps verify that an incoming message was sent by an expected origin.
Q12. How can an iframe be made responsive?
CSS width: 100%, a suitable aspect-ratio, and a responsive container can be used.
