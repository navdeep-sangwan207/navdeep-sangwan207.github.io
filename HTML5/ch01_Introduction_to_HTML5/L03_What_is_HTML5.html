2. What is HTML5?

HTML5 is the major revision of HTML that introduced important features for building modern websites and web applications.

It provides standardized elements for structuring web content, embedding multimedia, drawing graphics, creating forms and interacting with browser capabilities.

Definition: HTML5 refers to the major HTML specification published as a W3C Recommendation in 2014. Modern HTML continues to evolve through the WHATWG HTML Living Standard.

Example

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>HTML5 Example</title>
</head>

<body>

    <header>
        <h1>My HTML5 Website</h1>
    </header>

    <main>
        <p>Welcome to modern web development.</p>
    </main>

</body>

</html>

3. Why was HTML5 Introduced?

Earlier HTML versions were designed mainly for document-based websites. As the Internet developed, websites required more advanced capabilities.

Modern websites needed:

  • Native audio and video playback.
  • Better support for interactive applications.
  • Improved form controls and validation.
  • Semantic document structure.
  • Graphics and drawing capabilities.
  • Browser-based storage.
  • Better support for mobile and responsive experiences.

HTML5 introduced standardized features that helped browsers support these requirements.

4. Major Features of HTML5

4.1 Semantic Elements

Semantic elements describe the meaning and purpose of different sections of a web page.

Examples:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

These elements make document structure easier to understand for developers, browsers and assistive technologies.

4.2 Audio Support

HTML provides the <audio> element to embed audio content without requiring a separate browser plugin. 

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

4.3 Video Support

The <video> element allows developers to embed video content directly into web pages. 

<video width="400" controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support video.
</video>

4.4 Canvas Graphics

The Canvas element provides a drawing area. JavaScript can draw shapes, text, images and animations on this area. 

<canvas id="myCanvas"
        width="300"
        height="150">
</canvas>

4.5 SVG Graphics

SVG stands for Scalable Vector Graphics. It is used to create resolution-independent vector graphics. 

<svg width="200" height="100">
    <circle cx="50"
            cy="50"
            r="40"
            fill="blue" />
</svg>

4.6 Improved Forms

HTML5 introduced additional input types and built-in form validation capabilities. 

<form>

    <label for="email">Email:</label>

    <input type="email"
           id="email"
           required>

    <button type="submit">
        Submit
    </button>

</form>

Examples of HTML5 input types:

  • email
  • url
  • number
  • range
  • date
  • time
  • color
  • search

4.7 Web Storage

Web Storage allows websites to store data in the user's browser.

Two main types are:

  • localStorage: Stores data across browser sessions until removed.
  • sessionStorage: Stores data for the lifetime of a page session.
Important: Web Storage is accessed using JavaScript APIs. HTML provides the overall document structure, but JavaScript performs the storage operations.

4.8 Geolocation

The Geolocation API allows a website to request the user's geographical location, subject to browser permissions and security requirements.

This capability is implemented through JavaScript, not through a standalone HTML tag.

4.9 Drag and Drop

HTML supports attributes such as draggable that can be used with JavaScript drag-and-drop event handling. 

<div draggable="true">
    Drag this element
</div>

5. HTML5 Semantic vs Non-Semantic Elements

Semantic Elements

Semantic elements clearly describe the purpose of their content. 

<header>Website Header</header>

<main>
    <article>
        Article Content
    </article>
</main>

<footer>Website Footer</footer>

Non-Semantic Elements

Non-semantic elements do not describe the specific meaning of their content. 

<div>A section of content</div>

<span>Some inline text</span>
Semantic Elements Non-Semantic Elements
<header> <div>
<footer> <span>
<article> <div>
<nav> <div>

6. HTML5 vs Earlier HTML

Earlier HTML HTML5
Limited standardized multimedia elements. Native audio and video elements.
Less semantic structure. Semantic elements such as article and section.
Fewer built-in input types. Additional input types and validation features.
Graphics often required external technologies. Canvas and SVG support.
Earlier document type declarations were longer. Simple HTML5 DOCTYPE declaration.

7. HTML5 DOCTYPE Declaration

The DOCTYPE declaration tells the browser that the document uses HTML. 

<!DOCTYPE html>

HTML5 uses a simple and short DOCTYPE declaration. It helps browsers render the document in standards mode.

Remember: DOCTYPE is a declaration, not an HTML element. It does not have a closing tag.

8. HTML5 and Modern Web Development

HTML5 capabilities form an important foundation for modern web development.

HTML is commonly combined with:

  • CSS3: Styling, layouts and responsive design.
  • JavaScript: Dynamic behavior and interactivity.
  • React.js: Building component-based user interfaces.
  • Node.js: Running JavaScript on the server.

HTML structures the content, CSS controls its appearance, and JavaScript adds behavior.

9. HTML5 Browser Compatibility

Modern browsers support most commonly used HTML features. However, browser support can differ for particular APIs, media formats and advanced capabilities.

Examples of modern browsers include:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Apple Safari
Best Practice: Check browser compatibility before using advanced browser features. Provide suitable fallback content where necessary.

10. Practical Program

Program: Create a Basic HTML5 Web Page

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>HTML5 Demonstration</title>
</head>

<body>

    <header>
        <h1>Welcome to HTML5</h1>
    </header>

    <nav>
        <a href="#about">About</a>
    </nav>

    <main>

        <section id="about">
            <h2>About HTML5</h2>
            <p>
                HTML5 provides modern features
                for web development.
            </p>
        </section>

        <article>
            <h2>HTML5 Features</h2>
            <p>
                Semantic elements, multimedia
                and improved forms.
            </p>
        </article>

    </main>

    <footer>
        <p>NS Learning Hub</p>
    </footer>

</body>

</html>

About

About HTML5

HTML5 provides modern features for web development.

HTML5 Features

Semantic elements, multimedia and improved forms.

12. Interview Questions and Answers

Q1. What is HTML5?

HTML5 is a major revision of HTML that introduced standardized features for modern web content and applications.

Q2. What is the purpose of HTML5?

It provides modern capabilities for structuring web content, multimedia, graphics, forms and browser-based applications.

Q3. What are semantic elements?

Semantic elements describe the meaning and purpose of content, such as header, nav, article and footer.

Q4. What is the purpose of the Canvas element?

Canvas provides a drawing area that JavaScript can use to draw graphics and animations.

Q5. What is SVG?

SVG stands for Scalable Vector Graphics. It represents vector graphics using XML-based markup.

Q6. What is Web Storage?

Web Storage provides browser-side storage through localStorage and sessionStorage.

Q7. Does HTML5 require JavaScript for every feature?

No. HTML provides native elements such as audio, video and forms. Other capabilities, such as Geolocation and Canvas drawing, generally use JavaScript.

Q8. What is the HTML Living Standard?

It is the continuously updated specification maintained by WHATWG that defines modern HTML.
