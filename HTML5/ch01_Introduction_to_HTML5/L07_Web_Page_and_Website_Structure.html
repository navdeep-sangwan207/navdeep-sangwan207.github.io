5. Basic Structure of an HTML Web Page

Every standard HTML document has a basic structure that defines its document type, root element, metadata and visible page content.

Basic HTML Structure

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My First Web Page</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first web page.</p>

</body>

</html>

Explanation of Each Element

Element Purpose
<!DOCTYPE html> Declares the HTML document type and enables standards mode.
<html> Root element of the HTML document.
<head> Contains document metadata and resource references.
<meta> Provides metadata such as character encoding and viewport settings.
<title> Defines the document title shown in the browser tab.
<body> Contains the page content rendered in the browser.
<h1> Defines a level-one heading.
<p> Defines a paragraph.

6. Main Sections of a Web Page

A typical website page may be divided into several logical sections.

HEADER

NAVIGATION MENU

MAIN CONTENT AREA
Article / Section / Content

SIDEBAR (Optional)

FOOTER

1. Header

The header usually contains the website logo, website name, introductory information or other introductory content. 

<header>
    <h1>NS Learning Hub</h1>
    <p>My Learning Portal</p>
</header>

2. Navigation

Navigation provides links to important pages or sections of a website. 

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="courses.html">Courses</a>
    <a href="contact.html">Contact</a>
</nav>

3. Main Content

The main element contains the primary content of the web page. 

<main>
    <h2>Welcome</h2>
    <p>Explore our learning resources.</p>
</main>

4. Section

The section element groups related content into a thematic section. 

<section>
    <h2>Our Courses</h2>
    <p>Explore technical courses.</p>
</section>

5. Article

The article element represents self-contained content that can be independently distributed or reused. 

<article>
    <h2>Introduction to HTML</h2>
    <p>HTML is a markup language.</p>
</article>

6. Aside

The aside element contains complementary content, such as related links, side notes or a sidebar. 

<aside>
    <h3>Related Topics</h3>
    <a href="css.html">CSS Basics</a>
</aside>

7. Footer

The footer commonly contains copyright information, contact details, related links or other closing content. 

<footer>
    <p>Copyright 2026 NS Learning Hub</p>
</footer>

7. Semantic HTML Page Layout

HTML5 introduced semantic elements that describe the meaning and purpose of different parts of a web page.

Example

<!DOCTYPE html>
<html lang="en">

    <title>Website Layout</title>
</head>

<body>

    <header>
        <h1>My Website</h1>
    </header>

    <nav>
        <a href="index.html">Home</a>
        <a href="about.html">About</a>
    </nav>

    <main>

        <section>
            <h2>Introduction</h2>
            <p>Welcome to my website.</p>
        </section>

        <article>
            <h2>Latest Article</h2>
            <p>Learn HTML step by step.</p>
        </article>

        <aside>
            <h3>Related Links</h3>
            <a href="courses.html">Courses</a>
        </aside>

    </main>

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>
</html>

9. How Web Pages Are Connected

Hyperlinks connect one web page to another. HTML uses the anchor element to create hyperlinks.

Example

<a href="about.html">About Us</a>

When a user clicks the link, the browser navigates to the resource specified by the href attribute.

Types of Links

Link Type Example
Internal Link about.html
External Link https://www.example.com
Section Link #contact
Email Link mailto:info@example.com
Telephone Link tel:+911234567890

10. Absolute URLs and Relative URLs

Absolute URL

An absolute URL provides the complete address of a resource, including its scheme and host. 

https://www.example.com/about.html

Relative URL

A relative URL identifies a resource in relation to the current document's location. 

about.html
courses/html5.html
../index.html

Relative Path Symbols

Symbol Meaning
file.html File in the current directory.
folder/file.html File inside a child directory.
../file.html File in the parent directory.
../../file.html File two directory levels above.
/index.html File from the website root.
Important: Relative links depend on the location of the current HTML document. Always check the folder depth when creating links between pages.

12. What is index.html?

The file index.html is commonly used as the default entry page of a website or directory.

When a visitor opens a website address without specifying a file, the web server is often configured to serve a default document such as index.html.

Example:

When someone visits https://example.com/, the server may return its configured default document, commonly index.html.

13. How HTML, CSS and JavaScript Work Together

Technology Role
HTML Defines the structure and meaning of content.
CSS Controls presentation, styling and layout.
JavaScript Provides behavior and interactivity.

Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>HTML CSS JavaScript</title>

    <style>
        h1 {
            color: blue;
        }
    </style>
</head>

<body>

    <h1 id="heading">Welcome</h1>

    <button onclick="changeText()">
        Click Me
    </button>

    <script>
        function changeText() {
            document.getElementById("heading").textContent =
                "Hello, Welcome to HTML!";
        }
    </script>

</body>
</html>

In this example:

  • HTML creates the heading and button.
  • CSS changes the heading color.
  • JavaScript changes the heading text when the button is clicked.

14. Practical: Create a Simple Multi-Page Website

Create the following files inside one folder: 

my-first-website/
│
├── index.html
├── about.html
└── contact.html

File 1: index.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Home Page</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a> |
        <a href="contact.html">Contact</a>
    </nav>

    <h2>Home Page</h2>
    <p>This is the home page of my website.</p>

</body>
</html>

File 2: about.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>About Page</title>
</head>

<body>

    <h1>About Us</h1>

    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a> |
        <a href="contact.html">Contact</a>
    </nav>

    <p>This page contains information about us.</p>

</body>
</html>

File 3: contact.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Contact Page</title>
</head>

<body>

    <h1>Contact Us</h1>

    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a> |
        <a href="contact.html">Contact</a>
    </nav>

    <p>You can contact us through this page.</p>

</body>
</html>

Execution Steps

  1. Create a folder named my-first-website.
  2. Create the three HTML files inside the folder.
  3. Copy the corresponding code into each file.
  4. Save all files.
  5. Open index.html in a web browser.
  6. Click Home, About and Contact links.
  7. Verify that navigation between pages works correctly.

16. Interview Questions and Answers

Q1. What is a web page?

A web page is a single document that can be accessed through a web browser using a URL.

Q2. What is a website?

A website is a collection of related web pages and resources available through a website address.

Q3. What is the purpose of the body element?

It contains the main content of an HTML document that is rendered in the browser.

Q4. What is the purpose of the head element?

It contains metadata, the document title, stylesheet references and other document-level information.

Q5. What is the purpose of index.html?

It is commonly used as the default entry document for a website or directory.

Q6. What is a hyperlink?

A hyperlink is a clickable reference that navigates to another resource or location.

Q7. What is the difference between an absolute and relative URL?

An absolute URL specifies a complete resource address, while a relative URL is resolved in relation to the current document's location.

Q8. What is semantic HTML?

Semantic HTML uses elements that communicate the meaning and purpose of the content.

Q9. What is a responsive website?

A responsive website adapts its layout and presentation to different screen sizes and devices.

Q10. What is the difference between header and footer?

Header generally contains introductory content, while footer contains closing or supplementary information.

17. Multiple Choice Questions (MCQs)

Q1. A collection of related web pages is called:

  1. Website
  2. Web browser
  3. URL
  4. Protocol

Correct Answer: A. Website

Q2. Which element contains the visible page content?

  1. <head>
  2. <body>
  3. <title>
  4. <meta>

Correct Answer: B. <body>

Q3. Which element defines navigation links?

  1. <footer>
  2. <nav>
  3. <article>
  4. <aside>

Correct Answer: B. <nav>

Q4. Which filename is commonly used as a website's default page?

  1. style.css
  2. script.js
  3. index.html
  4. image.png

Correct Answer: C. index.html

Q5. Which element represents the main content of a document?

  1. <main>
  2. <head>
  3. <title>
  4. <meta>

Correct Answer: A. <main>

Q6. Which symbol refers to the parent directory?

  1. ./
  2. ../
  3. //
  4. ##

Correct Answer: B. ../

Q7. Which element represents self-contained content?

  1. <article>
  2. <nav>
  3. <header>
  4. <footer>

Correct Answer: A. <article>

Q8. Which technology is primarily responsible for web page styling?

  1. HTML
  2. CSS
  3. DNS
  4. HTTP

Correct Answer: B. CSS
