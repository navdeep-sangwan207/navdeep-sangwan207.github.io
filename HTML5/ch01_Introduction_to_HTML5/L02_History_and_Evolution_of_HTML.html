2. Introduction to the History of HTML

HTML was created to make it possible to structure and connect documents on the World Wide Web.

The original idea was to allow researchers to share documents containing text and hyperlinks so that information could be accessed easily.

Over time, the web evolved from simple text documents into interactive websites containing images, audio, video, forms, graphics and complex applications.

Important: HTML was developed by Tim Berners-Lee while working at CERN. The early web focused on sharing linked documents over the Internet.

3. Origin of HTML

3.1 Tim Berners-Lee

Tim Berners-Lee proposed the World Wide Web in 1989 while working at CERN, the European Organization for Nuclear Research.

He developed the initial technologies required for the Web, including:

  • HTML – HyperText Markup Language.
  • HTTP – HyperText Transfer Protocol.
  • URL – Uniform Resource Locator.
  • The first web browser and web server.

3.2 First HTML Document

The first HTML documents were simple. They mainly contained headings, paragraphs and hyperlinks.

HTML provided a way to organize information and connect related documents.

4. Evolution of HTML Versions

HTML has evolved through several versions and standardization milestones.

1989 – World Wide Web Proposal

Tim Berners-Lee proposed the World Wide Web at CERN. This established the foundation for HTML and web technologies.

1991 – Early HTML

An early description of HTML was published. It supported basic document structures and hyperlinks.

1995 – HTML 2.0

HTML 2.0 was published as an early formal specification. It standardized important features of early HTML, including forms.

1997 – HTML 3.2

HTML 3.2 added wider support for tables, scripting, applets and presentation-related features.

1997 – HTML 4.0

HTML 4.0 introduced improvements in forms, scripting, style sheets, accessibility and document structure.

1999 – HTML 4.01

HTML 4.01 was a revision of HTML 4.0. It corrected and clarified parts of the earlier specification.

2000 – XHTML 1.0

XHTML 1.0 reformulated HTML 4.01 using XML syntax rules. It required stricter markup conventions.

2004 – WHATWG Formation

The Web Hypertext Application Technology Working Group (WHATWG) was formed to develop web technologies with a focus on modern browser requirements and web applications.

2008 – HTML5 First Public Draft

The HTML5 specification became publicly available as a working draft, introducing many capabilities for modern web applications.

2014 – HTML5 Recommendation

W3C published HTML5 as a Recommendation. It included semantic elements, multimedia, graphics and improved forms.

2016 – HTML 5.1

HTML 5.1 was published as a later revision with additional clarifications and features.

2017 – HTML 5.2

HTML 5.2 introduced further updates and refinements to the HTML specification.

2019 – WHATWG Living Standard Agreement

W3C and WHATWG agreed that WHATWG would maintain the HTML and DOM Living Standards as the continuously updated standards.

6. HTML 2.0

HTML 2.0 was published in 1995 as an early formal standard for HTML.

Important features included:

  • Basic text formatting.
  • Headings and paragraphs.
  • Hyperlinks.
  • Lists.
  • Forms and form controls.

It provided a common specification for early web browsers and web documents.

7. HTML 3.2

HTML 3.2 was published in January 1997. It expanded the capabilities of HTML.

Important features included:

  • Tables.
  • Applets.
  • Additional text presentation features.
  • Support for scripting.
  • Improved document formatting.

HTML 3.2 reflected the growing need for richer web documents.

8. HTML 4.0 and HTML 4.01

HTML 4.0 was published in December 1997. HTML 4.01 followed in December 1999.

Important developments included:

  • Better integration with CSS.
  • Improved scripting support.
  • Better form capabilities.
  • Accessibility improvements.
  • Support for internationalized documents.
  • Better separation of document structure and presentation.
Important concept: HTML provides structure, while CSS provides presentation. This separation makes websites easier to maintain.

9. XHTML 1.0

XHTML stands for Extensible HyperText Markup Language. XHTML 1.0 was published in 2000.

It reformulated HTML 4.01 using XML syntax rules. Therefore, XHTML documents followed stricter markup rules.

Important XHTML Rules

  • Element names must be written in lowercase.
  • Elements must be properly nested.
  • Elements must be properly closed.
  • Attribute values must be quoted.
  • Documents must follow XML well-formedness rules.

Example

<p>This is a paragraph.</p>

<br />

<img src="photo.jpg" alt="Photo" />
Note: XHTML is not simply another name for HTML5. It is a family of HTML reformulations using XML syntax.

10. Introduction to HTML5

HTML5 was developed to support the changing requirements of modern websites and web applications.

Earlier HTML versions relied more heavily on external plugins and additional technologies for certain multimedia and interactive capabilities.

HTML5 introduced standardized elements and browser capabilities for multimedia, graphics, semantic structure and improved forms.

Important HTML5 Features

  • Semantic elements such as header, footer, article and section.
  • Native audio and video elements.
  • Canvas graphics.
  • Improved form input types.
  • Local and session storage APIs.
  • Geolocation API.
  • Drag and Drop API.

These capabilities made it easier to develop richer browser-based applications.

11. W3C and WHATWG

11.1 W3C

W3C stands for World Wide Web Consortium. It was founded by Tim Berners-Lee in 1994.

W3C develops standards and guidelines to support the long-term growth of the World Wide Web.

11.2 WHATWG

WHATWG stands for Web Hypertext Application Technology Working Group.

It was formed in 2004 by browser vendors and other web technology participants to develop and maintain modern web standards.

11.3 Modern HTML Standard

In 2019, W3C and WHATWG agreed that WHATWG would maintain the HTML and DOM Living Standards.

The modern HTML specification is therefore continuously updated rather than being released only as a completely new numbered version every few years.

Remember: HTML5 remains a commonly used name for modern HTML, but the current specification is maintained as the HTML Living Standard by WHATWG.

12. HTML5 vs Modern HTML

HTML5 (2014) Modern HTML Living Standard
Published as a numbered specification. Continuously updated specification.
Introduced major modern HTML capabilities. Continues refining HTML features and behavior.
W3C published the Recommendation. WHATWG maintains the Living Standard.
Represents an important milestone in HTML history. Represents the current model of HTML development.
