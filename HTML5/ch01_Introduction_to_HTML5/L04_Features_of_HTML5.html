2. Overview of HTML5 Features

HTML5 introduced several important features that simplify the development of modern websites and web applications.

Feature Purpose
Semantic Elements Describe the meaning and structure of content.
Audio and Video Embed multimedia directly into web pages.
Canvas Provide a drawing area controlled by JavaScript.
SVG Create scalable vector graphics.
Improved Forms Provide additional input types and validation.
Web Storage Store data in the browser.
Geolocation API Request the user's geographical location.
Drag and Drop Support draggable content and drop interactions.
Web Workers Run JavaScript tasks in background threads.

3. Semantic Elements

Semantic elements provide meaningful names for different sections of a web document.

Important Semantic Elements

Element Purpose
<header> Represents introductory content or a section header.
<nav> Contains navigation links.
<main> Contains the main content of the document.
<section> Represents a thematic section.
<article> Represents independent, self-contained content.
<aside> Represents indirectly related or supplementary content.
<footer> Represents footer information.
<figure> Groups self-contained content such as an image or diagram.
<figcaption> Provides a caption for a figure.

Example

<!DOCTYPE html>
<html lang="en">

<head>
    <title>Semantic HTML</title>
</head>

<body>

    <header>
        <h1>My Website</h1>
    </header>

    <nav>
        <a href="#home">Home</a>
        <a href="#about">About</a>
    </nav>

    <main>

        <section id="home">
            <h2>Home Section</h2>
            <p>Welcome to my website.</p>
        </section>

        <article>
            <h2>Latest Article</h2>
            <p>Article content goes here.</p>
        </article>

        <aside>
            Related information
        </aside>

    </main>

    <footer>
        Copyright Information
    </footer>

</body>
</html>
Benefits: Semantic markup improves document organization, accessibility and the ability of search engines and other tools to interpret page structure.

4. Native Audio Support

HTML provides the <audio> element to embed audio files directly into a web page.

Basic Syntax

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

Important Audio Attributes

Attribute Description
controls Displays audio controls.
autoplay Requests automatic playback, subject to browser policies.
loop Repeats audio after playback finishes.
muted Starts the audio in a muted state.
preload Hints how much audio data should be loaded in advance.

Example

<audio controls loop>
    <source src="music.mp3" type="audio/mpeg">
</audio>
Note: Audio playback depends on the availability of the media file and browser-supported formats. Autoplay may be restricted by browsers.

5. Native Video Support

The <video> element allows developers to embed video content into web pages.

Basic Syntax

<video width="500" height="300" controls>
    <source src="video.mp4" type="video/mp4">
    Your browser does not support video.
</video>

Important Video Attributes

Attribute Description
controls Displays playback controls.
width Sets the video display width.
height Sets the video display height.
autoplay Requests automatic playback.
loop Repeats the video.
muted Mutes the video audio.
poster Specifies an image shown before playback.
preload Provides a hint about preloading video data.

Example with Poster

<video width="500"
       controls
       poster="thumbnail.jpg">

    <source src="lesson.mp4"
            type="video/mp4">

    Your browser does not support video.

</video>

6. Canvas Graphics

The <canvas> element creates a rectangular drawing area inside a web page. JavaScript is used to draw graphics on it.

Canvas Syntax

<canvas id="myCanvas"
        width="400"
        height="200">
</canvas>

Drawing a Rectangle Using JavaScript

<canvas id="myCanvas"
        width="400"
        height="200">
</canvas>

<script>

const canvas = document.getElementById("myCanvas");

const ctx = canvas.getContext("2d");

ctx.fillStyle = "blue";

ctx.fillRect(50, 50, 200, 100);

</script>

Common Canvas Methods

Method Purpose
fillRect() Draws a filled rectangle.
strokeRect() Draws a rectangle outline.
clearRect() Clears a rectangular area.
beginPath() Starts a new drawing path.
arc() Creates an arc or circle path.
fillText() Draws filled text.
stroke() Draws the outline of a path.

7. SVG Graphics

SVG stands for Scalable Vector Graphics. It is an XML-based vector graphics format that can be embedded directly into HTML.

Example: SVG Circle

<svg width="200" height="150">

    <circle
        cx="80"
        cy="70"
        r="50"
        fill="blue"
        stroke="black"
        stroke-width="3" />

</svg>

Common SVG Elements

Element Purpose
<svg> Defines an SVG drawing area.
<circle> Draws a circle.
<rect> Draws a rectangle.
<line> Draws a straight line.
<ellipse> Draws an ellipse.
<polygon> Draws a closed polygon.
<text> Displays text in SVG.

8. Canvas vs SVG

Canvas SVG
Pixel-based drawing surface. Vector-based graphics.
Uses JavaScript for drawing. Uses XML-based markup and can also be manipulated with JavaScript.
Individual shapes are not separate DOM elements. Individual graphical elements are part of the DOM.
Useful for games and frequently updated graphics. Useful for diagrams, icons and scalable illustrations.
May lose quality when enlarged. Scales without pixelation.

9. Improved HTML5 Forms

HTML5 introduced additional input types and built-in validation features.

Important Input Types

Input Type Purpose
email Accepts an email address.
url Accepts a URL.
number Accepts numerical input.
range Provides a slider control.
date Provides a date input control.
time Provides a time input control.
color Provides a color picker.
search Provides a search input field.
tel Provides an input intended for telephone numbers.

Example

<form>

    <label>Email:</label>
    <input type="email" required>

    <br><br>

    <label>Age:</label>
    <input type="number"
           min="18"
           max="60">

    <br><br>

    <label>Date of Birth:</label>
    <input type="date">

    <br><br>

    <button type="submit">
        Submit
    </button>

</form>

Important Form Attributes

Attribute Purpose
required Makes a field mandatory.
placeholder Displays a hint inside an input field.
min Sets the minimum permitted value.
max Sets the maximum permitted value.
maxlength Sets the maximum number of characters.
pattern Defines a regular expression for validation.
autocomplete Controls browser autocomplete behavior.
Important: Client-side validation improves usability but does not replace server-side validation. A server must validate submitted data independently.

10. Web Storage

Web Storage allows web applications to store key-value data in the browser.

Types of Web Storage

localStorage sessionStorage
Data remains after closing and reopening the browser, until removed. Data is associated with a page session and is normally cleared when that session ends.
Useful for persistent browser preferences. Useful for temporary session data.

Example: localStorage

// Store data
localStorage.setItem("username", "Student");

// Retrieve data
let name = localStorage.getItem("username");

console.log(name);

// Remove one item
localStorage.removeItem("username");

// Clear all items for this origin
localStorage.clear();

Example: sessionStorage

// Store data
sessionStorage.setItem("course", "HTML5");

// Retrieve data
let course = sessionStorage.getItem("course");

console.log(course);
Remember: localStorage and sessionStorage store strings. Objects and arrays generally need JSON.stringify() when storing and JSON.parse() when retrieving.

11. Geolocation API

The Geolocation API allows a website to request the geographical position of a user.

The browser normally asks the user for permission. Geolocation generally requires a secure context, such as HTTPS, or localhost during development.

Example

if ("geolocation" in navigator) {

    navigator.geolocation.getCurrentPosition(
        function(position) {

            console.log("Latitude:",
                position.coords.latitude);

            console.log("Longitude:",
                position.coords.longitude);

        },

        function(error) {

            console.log("Location error:",
                error.message);

        }
    );

} else {

    console.log("Geolocation is not supported.");

}
Privacy: A website must request permission before accessing the user's location. Location data should be handled responsibly.

12. Drag and Drop

HTML supports draggable elements through the draggable attribute. JavaScript event handling is commonly used to implement the complete drag-and-drop operation.

Example

<div id="item"
     draggable="true">
    Drag Me
</div>

<div id="target">
    Drop Here
</div>

<script>

const item = document.getElementById("item");

const target = document.getElementById("target");

item.addEventListener("dragstart", function(event) {
    event.dataTransfer.setData("text/plain", "item");
});

target.addEventListener("dragover", function(event) {
    event.preventDefault();
});

target.addEventListener("drop", function(event) {
    event.preventDefault();

    const data = event.dataTransfer.getData("text/plain");

    if (data === "item") {
        target.appendChild(item);
    }
});

</script>

13. Web Workers

Web Workers allow JavaScript code to run in background threads separate from the main page execution thread.

They are useful for computationally intensive tasks that should not block the user interface.

Example: Main HTML File

<button id="start">Start Worker</button>

<p id="result">Waiting...</p>

<script>

const worker = new Worker("worker.js");

document.getElementById("start")
    .addEventListener("click", function() {

        worker.postMessage("start");

    });

worker.onmessage = function(event) {

    document.getElementById("result").textContent =
        event.data;

};

</script>

Example: worker.js

onmessage = function(event) {

    if (event.data === "start") {

        let total = 0;

        for (let i = 1; i <= 1000000; i++) {
            total += i;
        }

        postMessage("Total = " + total);

    }

};
Important: A standard Web Worker runs in a separate global context and does not directly access the page DOM. It communicates with the main page using messages.

15. Benefits of HTML5

  • Provides a simpler document structure.
  • Supports native audio and video elements.
  • Introduces meaningful semantic elements.
  • Provides improved form controls and validation.
  • Supports Canvas and SVG graphics.
  • Works with browser storage APIs.
  • Supports modern interactive web applications.
  • Reduces dependence on certain external plugins.

16. Limitations and Considerations

  • Some browser features have different compatibility levels.
  • Media format support can vary across browsers.
  • Advanced features may require JavaScript.
  • Client-side validation is not a substitute for server-side validation.
  • Browser storage has capacity and security limitations.
  • Geolocation requires permission and careful privacy handling.

18. Interview Questions and Answers

Q1. What are the major features of HTML5?

Major features include semantic elements, native audio and video, Canvas, SVG, improved forms and integration with modern browser APIs.

Q2. What is the difference between Canvas and SVG?

Canvas uses a pixel-based drawing surface, while SVG represents graphics as scalable vector elements.

Q3. What is the difference between localStorage and sessionStorage?

localStorage persists until data is removed. sessionStorage is associated with a page session.

Q4. What is the purpose of the required attribute?

It makes a form field mandatory before the browser allows normal form submission.

Q5. What is the Geolocation API?

It allows a website to request the geographical location of a user, subject to permission.

Q6. What is a Web Worker?

A Web Worker executes JavaScript in a background thread without directly blocking the main page thread.

Q7. What is the purpose of the video element?

It embeds video content directly into an HTML document.

Q8. Does HTML5 replace JavaScript?

No. HTML defines document structure and native elements, while JavaScript provides programming logic and access to many browser APIs.
