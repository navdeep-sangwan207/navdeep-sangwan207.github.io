L05: HTML vs HTML5

Chapter 1 – Introduction to HTML5 | NS Learning Hub

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand the differences between earlier HTML specifications and HTML5.
  • Compare HTML and HTML5 document structures.
  • Understand DOCTYPE declarations.
  • Compare multimedia support.
  • Identify new semantic elements and form features.
  • Understand Canvas, SVG and browser APIs.
  • Explain why HTML5 became important in modern web development.

2. Introduction

HTML stands for HyperText Markup Language. It is used to structure content on web pages.

HTML has evolved through several specifications. Earlier versions such as HTML 4.01 provided the foundation for web documents, while HTML5 introduced important improvements for modern websites and applications.

Important: HTML5 is not a completely different language. It is an evolution of HTML that introduced additional elements, attributes and capabilities.

3. Basic Comparison: HTML vs HTML5

HTML (Earlier Specifications) HTML5
Earlier versions include HTML 2.0, 3.2 and 4.01. HTML5 was a major revision of HTML.
HTML 4.01 used longer DOCTYPE declarations. Uses a simple DOCTYPE declaration.
Limited standardized semantic elements. Provides elements such as header, nav, main and article.
Multimedia often depended on plugins or external technologies. Provides native audio and video elements.
Fewer standardized form input types. Provides additional input types and validation features.
No native Canvas element in HTML 4.01. Provides the Canvas element.
SVG was not part of HTML 4.01. SVG can be embedded directly in HTML documents.
Browser storage APIs were not part of HTML 4.01. Works with Web Storage and other modern browser APIs.

4. Difference in DOCTYPE Declaration

DOCTYPE tells the browser which document standard or parsing mode should be used.

HTML 4.01 DOCTYPE

HTML 4.01 Strict used the following declaration: 

<!DOCTYPE HTML PUBLIC
"-//W3C//DTD HTML 4.01//EN"
"http://www.w3.org/TR/html4/strict.dtd">

HTML5 DOCTYPE

<!DOCTYPE html>
Key Difference: HTML5 uses a much shorter DOCTYPE declaration. It is intended to trigger standards mode in browsers.

5. Difference in Document Structure

Earlier HTML Structure

<!DOCTYPE HTML PUBLIC
"-//W3C//DTD HTML 4.01//EN"
"http://www.w3.org/TR/html4/strict.dtd">

<html>

<head>
    <title>My Website</title>
</head>

<body>

    <div id="header">
        Website Header
    </div>

    <div id="navigation">
        Navigation Links
    </div>

    <div id="content">
        Main Content
    </div>

    <div id="footer">
        Footer Information
    </div>

</body>

</html>

HTML5 Structure

<!DOCTYPE html>

<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <header>
        Website Header
    </header>

    <nav>
        Navigation Links
    </nav>

    <main>
        Main Content
    </main>

    <footer>
        Footer Information
    </footer>

</body>

</html>

HTML5 provides meaningful semantic elements instead of requiring generic div elements for every structural section.

6. Difference in Semantic Elements

Earlier Common Approach HTML5 Semantic Element
<div id="header"> <header>
<div id="navigation"> <nav>
<div id="content"> <main>
<div class="article"> <article>
<div id="footer"> <footer>
Note: Earlier HTML versions allowed developers to use div elements for page structure. HTML5 introduced semantic alternatives; div remains valid and useful.

7. Difference in Multimedia Support

Earlier HTML

HTML 4.01 did not provide native audio and video elements. Websites commonly used browser plugins, embedded objects or other technologies.

HTML5

HTML5 introduced native audio and video elements. 

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
</audio>

<video width="400" controls>
    <source src="movie.mp4" type="video/mp4">
</video>
Earlier HTML HTML5
No native audio element in HTML 4.01. Uses <audio>.
No native video element in HTML 4.01. Uses <video>.
Often relied on plugins. Native browser media playback is available.

8. Difference in Form Features

HTML 4.01 supported common form controls such as text fields, password fields, radio buttons and checkboxes.

HTML5 added input types and validation features.

Earlier HTML Form

<form>

    Email:
    <input type="text" name="email">

    <input type="submit" value="Submit">

</form>

HTML5 Form

<form>

    Email:
    <input type="email"
           name="email"
           required>

    Age:
    <input type="number"
           min="18"
           max="60">

    Date:
    <input type="date">

    <input type="submit" value="Submit">

</form>
Earlier HTML Common Types Additional HTML5 Types
text email
password url
checkbox number
radio range
submit date, time, color, search

9. Difference in Graphics Support

Earlier HTML

HTML 4.01 did not include a native Canvas element. Graphics were commonly embedded as image files or created using external technologies.

HTML5

HTML5 supports Canvas and SVG within HTML documents.

Canvas Example

<canvas id="myCanvas"
        width="300"
        height="150">
</canvas>

<script>

const canvas = document.getElementById("myCanvas");

const ctx = canvas.getContext("2d");

ctx.fillStyle = "blue";

ctx.fillRect(30, 30, 150, 80);

</script>

SVG Example

<svg width="200" height="150">

    <circle cx="80"
            cy="70"
            r="50"
            fill="orange" />

</svg>

10. Difference in Browser Storage

HTML 4.01 did not define the Web Storage API. HTML5-era web platform specifications introduced standardized browser-side storage capabilities.

localStorage Example

localStorage.setItem("name", "Student");

let name = localStorage.getItem("name");

console.log(name);

sessionStorage Example

sessionStorage.setItem("course", "HTML5");

let course = sessionStorage.getItem("course");

console.log(course);
localStorage sessionStorage
Persists until removed. Associated with a page session.
Can be used across browser sessions. Normally cleared when the page session ends.

11. Difference in Browser APIs

HTML5-era web development includes browser APIs that provide additional capabilities.

API / Feature Purpose
Geolocation API Requests the user's geographical location.
Drag and Drop API Supports drag-and-drop interactions.
Web Storage API Stores data in the browser.
Web Workers API Runs JavaScript in background threads.
Technical distinction: These are web platform APIs, not all HTML elements. They are generally accessed through JavaScript. The HTML5 specification and related web platform specifications evolved together.

12. Difference in Character Encoding

Character encoding determines how text characters are represented in a document.

Earlier HTML

<meta http-equiv="Content-Type"
      content="text/html; charset=UTF-8">

HTML5

<meta charset="UTF-8">

HTML5 provides a simpler way to declare the document's character encoding.

13. Difference in Browser Compatibility

Earlier HTML features are supported by modern browsers. HTML5 introduced additional features whose support depends on the browser and the particular API.

  • Modern Chrome supports many HTML and browser API features.
  • Firefox supports modern HTML and web platform features.
  • Microsoft Edge supports modern HTML features.
  • Safari supports modern HTML features, with some API differences.

Developers should check compatibility when using advanced features and provide fallback behavior where appropriate.

14. HTML5 Advantages

  • Simpler document declaration.
  • Meaningful semantic elements.
  • Native multimedia support.
  • Improved form controls and validation.
  • Canvas and SVG graphics.
  • Integration with modern browser APIs.
  • Better support for modern web applications.
  • Reduced dependence on certain browser plugins.

15. Important Technical Clarifications

1. HTML5 is not a completely separate language. It is an evolution of HTML.
2. HTML5 does not replace CSS or JavaScript. CSS handles presentation, and JavaScript handles programming logic and interactivity.
3. Not every modern browser API is an HTML element. Geolocation, Web Storage and Web Workers are APIs accessed through JavaScript.
4. HTML5 is not the final version of HTML. Modern HTML is continuously maintained through the WHATWG HTML Living Standard.

17. Interview Questions and Answers

Q1. What is the main difference between HTML and HTML5?

HTML5 is a major evolution of HTML that introduced semantic elements, native multimedia, improved forms, graphics and support for modern web platform APIs.

Q2. What is the HTML5 DOCTYPE?

The HTML5 DOCTYPE is <!DOCTYPE html>. It helps the browser use standards mode.

Q3. Does HTML5 support audio and video?

Yes. HTML provides the audio and video elements for native multimedia playback.

Q4. What is the difference between div and section?

div is a generic container without inherent semantic meaning. section represents a thematic grouping of content.

Q5. What is the difference between Canvas and SVG?

Canvas is a pixel-based drawing surface, while SVG uses scalable vector graphics.

Q6. Does HTML5 support localStorage?

Modern HTML-based web applications can use the Web Storage API, which provides localStorage and sessionStorage.

Q7. Is HTML5 still the latest fixed version of HTML?

No. Modern HTML is maintained as a continuously updated Living Standard by WHATWG.

Q8. Why is HTML5 important?

It provides standardized features for structuring content, multimedia, graphics, forms and modern browser-based applications.

19. Lesson Summary

  • HTML5 is an evolution of earlier HTML specifications.
  • HTML5 uses a simple DOCTYPE declaration.
  • Semantic elements improve document structure.
  • Native audio and video elements support multimedia.
  • Canvas and SVG support graphics.
  • HTML5 forms provide additional input types and validation.
  • Modern web applications use APIs such as Web Storage and Geolocation.
  • Modern HTML continues to evolve through the WHATWG Living Standard.
