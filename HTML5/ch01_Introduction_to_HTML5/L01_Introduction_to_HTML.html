2. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on web pages.

HTML tells a web browser how different parts of a web page are organized, such as headings, paragraphs, images, links, lists, tables and forms.

Definition: HTML is a markup language that describes the structure and meaning of content displayed on web pages.

Example

Consider a simple web page containing a heading and a paragraph. HTML defines which text is the heading and which text is the paragraph. 

<h1>Welcome to NS Learning Hub</h1>

<p>This is my first web page.</p>

3. Full Form of HTML

HTML consists of three important terms:

3.1 HyperText

HyperText refers to text that contains links to other documents or resources. These links allow users to navigate between web pages.

For example, clicking a link named "About Us" can open another page of a website.

3.2 Markup

Markup means adding tags to content to identify its structure and meaning.

For example, the <h1> tag identifies a main heading, while the <p> tag identifies a paragraph.

3.3 Language

HTML is called a language because it follows a defined set of rules and syntax for describing web page content. However, it is a markup language, not a general-purpose programming language.

4. Why is HTML Used?

HTML is used to:

  • Create the structure of web pages.
  • Display headings and paragraphs.
  • Add images, audio and video.
  • Create hyperlinks between pages.
  • Organize information using lists and tables.
  • Build forms for collecting user information.
  • Provide semantic meaning to web content.

5. HTML as a Markup Language

A markup language uses tags to describe the structure or presentation of content.

HTML uses predefined elements written using angle brackets. Most HTML elements have an opening tag, content and a closing tag.

Example

<p>Learning HTML is easy.</p>

In this example:

  • <p> – Opening tag.
  • Learning HTML is easy. – Content.
  • </p> – Closing tag.
Important: HTML describes the structure and meaning of content. CSS controls presentation, while JavaScript provides programming logic and interactivity.

6. HTML, CSS and JavaScript

These three technologies are commonly used together to develop websites.

Technology Purpose Example
HTML Structure and content Heading, paragraph, image
CSS Styling and layout Colors, fonts, spacing
JavaScript Behavior and interactivity Button click, validation

7. HTML Tags and Elements

HTML Tag

A tag is a markup keyword enclosed within angle brackets.

Examples:

<h1>
<p>
<img>
<a>

HTML Element

An HTML element generally consists of an opening tag, content and a closing tag. Some elements are void elements and do not have closing tags. 

<h1>HTML Introduction</h1>

<p>HTML is a markup language.</p>

Void Elements

Void elements do not contain content and do not require closing tags. 

<br>
<hr>
<img src="photo.jpg" alt="A photograph">
<input type="text">
Remember: Do not write closing tags for void elements such as <br> and <img>.

8. HTML Attributes

Attributes provide additional information or configuration for HTML elements. They are generally written inside the opening tag.

Example

<a href="https://www.example.com">
    Visit Example
</a>

<img src="photo.jpg"
     alt="A sample photograph"
     width="300">

Here:

  • href specifies the link destination.
  • src specifies the image location.
  • alt provides alternative text.
  • width specifies the image width.

9. How Does HTML Work?

A web browser reads an HTML document, parses its markup and constructs a Document Object Model (DOM). The browser uses this structure to display the web page.

  1. A developer writes HTML code.
  2. The HTML file is saved with the .html extension.
  3. The browser loads the HTML document.
  4. The browser parses the HTML elements.
  5. The browser builds the DOM tree.
  6. The browser renders the page on the screen.
DOM: The Document Object Model represents an HTML document as a tree of objects. JavaScript can use the DOM to access and modify page content.

10. Your First HTML Program

Now create your first HTML document using any text editor, such as Notepad or Visual Studio Code.

Program: First HTML Web Page

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>

<body>

    <h1>Welcome to NS Learning Hub</h1>

    <p>This is my first HTML web page.</p>

</body>

</html>

Expected Output

Welcome to NS Learning Hub

This is my first HTML web page.

Steps to Execute

  1. Open Notepad or Visual Studio Code.
  2. Write the HTML code shown above.
  3. Save the file as index.html.
  4. Choose All Files as the file type in Notepad.
  5. Open the saved file in a web browser.
  6. Observe the heading and paragraph.
Important: Ensure the filename ends in .html, not .txt. For example, avoid accidentally saving it as index.html.txt.

12. Interview Questions and Answers

Q1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure web pages.

Q2. Is HTML a programming language?

No. HTML is a markup language. It describes the structure and meaning of content rather than implementing general-purpose programming logic.

Q3. What is HyperText?

HyperText is text containing links that allow users to navigate to other documents or resources.

Q4. What is an HTML tag?

An HTML tag is a markup keyword enclosed in angle brackets, such as <p> or <h1>.

Q5. What is an HTML element?

An HTML element is a document component represented by its tags and associated content, where applicable.

Q6. What is the purpose of a web browser?

A web browser retrieves web resources, processes HTML, CSS and JavaScript, and displays the resulting web page.

Q7. What is the difference between HTML and CSS?

HTML defines content and structure, whereas CSS controls the visual presentation and layout.

Q8. What is the extension of an HTML file?

The standard file extension is .html. The older .htm extension is also supported.
