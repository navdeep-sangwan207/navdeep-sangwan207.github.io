Lesson 6: Figure and Figcaption Elements

HTML5 – Complete Study Course

1. Introduction

HTML provides semantic elements to organize content and communicate its meaning to browsers, developers, and assistive technologies.

The <figure> and <figcaption> elements are used to group self-contained content with an optional caption.

Definition: The figure element represents self-contained content that is referenced from the main document, while figcaption provides a caption or legend for that figure.

Common uses

  • Photographs and illustrations.
  • Technical diagrams.
  • Charts and graphs.
  • Code examples.
  • Maps and drawings.
  • Tables or other self-contained content.

2. The <figure> Element

The <figure> element represents self-contained content that can be moved to another part of the document without affecting the main flow of the document.

Syntax

<figure>
    Content goes here.
</figure>

Example

<figure>
    <img src="solar-panel.jpg"
         alt="Solar panels installed on a rooftop">
</figure>

In this example, the image is grouped inside a figure element.

The figure element is not limited to images. It can also contain other self-contained content such as a diagram, code sample, chart, or table.

3. The <figcaption> Element

The <figcaption> element provides a caption or legend describing the content of its parent figure.

Syntax

<figure>
    <img src="circuit.jpg" alt="Electronic circuit">
    <figcaption>
        Figure 1: Electronic circuit on a breadboard.
    </figcaption>
</figure>

Important points

  • figcaption must be a child of figure.
  • A figure can contain at most one figcaption element.
  • The caption can appear before or after the other figure content.
  • A figure does not require a figcaption.
  • The caption may describe an image, chart, diagram, or other content.

4. Position of the Figcaption Element

The figcaption element can be placed either before or after the main content inside the figure.

4.1 Caption After the Image

<figure>
    <img src="computer.jpg"
         alt="Desktop computer on a table">

    <figcaption>
        Figure 1: Desktop computer setup.
    </figcaption>
</figure>

4.2 Caption Before the Image

<figure>
    <figcaption>
        Figure 2: A desktop computer setup.
    </figcaption>

    <img src="computer.jpg"
         alt="Desktop computer on a table">
</figure>
Both arrangements are valid. CSS can control the visual appearance and spacing of the caption.

5. Difference Between Figure and Figcaption

Figure Figcaption
Groups self-contained content. Provides a caption or legend for the figure.
Can contain an image, chart, diagram, or code sample. Contains descriptive caption text or other appropriate caption content.
Can exist without figcaption. Must be inside a figure element.
Represents the complete figure. Represents the figure's caption.

6. Figure with an Image and Caption

This example demonstrates how an image and its caption can be grouped semantically. 

<figure>
    <img
        src="microcontroller.jpg"
        alt="Microcontroller development board">

    <figcaption>
        Figure 1: Microcontroller development board
        used for embedded systems experiments.
    </figcaption>
</figure>

How it works

  1. The figure element groups the image and caption.
  2. The img element displays the image.
  3. The alt attribute provides a text alternative.
  4. The figcaption element provides a visible caption.

7. Figure with a Chart or Diagram

Figure is also useful for presenting charts and technical diagrams with explanatory captions.

Example: Rectifier Circuit Diagram

<figure>
    <img
        src="bridge-rectifier.png"
        alt="Bridge rectifier circuit containing four diodes">

    <figcaption>
        Figure 2: Full-wave bridge rectifier circuit.
    </figcaption>
</figure>

Example: Code Listing

<figure>
    <pre><code>
int main(void)
{
    return 0;
}
    </code></pre>

    <figcaption>
        Example 1: Basic C program structure.
    </figcaption>
</figure>
Use figure when the content forms a meaningful, self-contained unit that is referenced by the surrounding document. Do not wrap every ordinary image or paragraph in figure automatically.

8. Figure and Figcaption with CSS

CSS can be used to style the figure container and its caption.

HTML

<figure class="product-figure">
    <img
        src="laptop.jpg"
        alt="Laptop placed on a desk">

    <figcaption>
        Figure 3: Laptop used for programming.
    </figcaption>
</figure>

CSS

.product-figure {
    max-width: 500px;
    margin: 20px auto;
    padding: 15px;
    border: 1px solid #ccc;
    border-radius: 8px;
    text-align: center;
}

.product-figure img {
    max-width: 100%;
    height: auto;
}

.product-figure figcaption {
    margin-top: 10px;
    color: #555;
    font-style: italic;
    font-size: 14px;
}

What the CSS does

  • max-width limits the figure's width.
  • margin controls spacing around the figure.
  • padding adds inner spacing.
  • border adds a visible boundary.
  • text-align centres the content.
  • font-style makes the caption italic.

9. Difference Between Alt Text and Figcaption

The alt attribute and figcaption element both provide information about images, but they serve different purposes.

Alt Text Figcaption
Provided through the alt attribute of img. Provided through the figcaption element.
Acts as the image's text alternative. Provides a visible caption for the figure.
Important for users who cannot perceive the image. Useful for all readers who need context or a caption.
Not displayed as ordinary visible text below the image. Normally displayed as content on the webpage.

Example using both

<figure>
    <img
        src="processor.jpg"
        alt="Microprocessor mounted on a development board">

    <figcaption>
        Figure 4: Development board used for
        microprocessor programming.
    </figcaption>
</figure>
A figcaption does not automatically replace the alt attribute. Provide an appropriate alt value for the image, including an empty value when the image is decorative.

10. Figure vs. Div

Both figure and div can group HTML content, but they have different semantic purposes.

Figure Div
Semantic HTML element. Generic container without inherent semantic meaning.
Represents self-contained content. Groups content for styling or scripting.
Can contain a figcaption. Does not have a special caption relationship.
Communicates meaning to browsers and assistive technologies. Does not communicate a specific content role by itself.

11. Common Mistakes

Mistake Correction
Using figcaption outside figure Place figcaption inside its parent figure.
Using multiple figcaption elements in one figure Use at most one figcaption per figure.
Assuming every image needs figure Use figure only for self-contained content.
Using figcaption instead of alt Provide suitable alt text independently.
Using figure only for visual styling Use div when no figure semantics are intended.
Using captions unrelated to the content Ensure the caption describes or identifies the figure.

12. Practical Exercises

  1. Create a figure containing an image of a computer.
  2. Add a figcaption below the image.
  3. Move the figcaption above the image and test the result.
  4. Create a figure containing an electronic circuit diagram.
  5. Create a figure containing a code example.
  6. Style the figure using CSS borders, margins, and padding.
  7. Use both alt text and figcaption correctly.

13. Interview Questions and Answers

Q1. What is the figure element in HTML?

The figure element represents self-contained content that can be referenced from the main document.

Q2. What is the purpose of figcaption?

It provides a caption or legend for the content inside a figure element.

Q3. Can figure be used without figcaption?

Yes. The figcaption element is optional.

Q4. Can figcaption appear before an image?

Yes. It can appear before or after the other content inside figure.

Q5. Can a figure contain content other than an image?

Yes. It can contain charts, diagrams, code examples, tables, and other appropriate self-contained content.

Q6. How many figcaption elements can a figure contain?

A figure can contain at most one figcaption element.

Q7. What is the difference between alt and figcaption?

Alt provides a text alternative for an image, while figcaption provides a visible caption for a figure.

Q8. What is the difference between figure and div?

Figure has semantic meaning for self-contained content, while div is a generic container.

Q9. Is figure a block-level element?

Yes. Its default browser display behavior is block. CSS can change its display behavior.

Q10. Can figure contain multiple images?

Yes. A figure can contain multiple related images and a single caption describing the grouped content.

15. Lesson Summary

  • Figure represents self-contained content.
  • Figcaption provides a caption or legend for a figure.
  • Figcaption must be placed inside figure.
  • A figure can contain at most one figcaption.
  • Figcaption can appear before or after the main figure content.
  • Figure can contain images, charts, diagrams, and code examples.
  • Figure does not require a caption.
  • Alt text and figcaption serve different purposes.
  • CSS can control the visual appearance of figures and captions.
  • Use figure for meaningful self-contained content, not merely styling.
