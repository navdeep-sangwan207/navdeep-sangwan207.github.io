Chapter 6: HTML Images and Graphics

1. Introduction

Images are an important part of modern websites. They help communicate information visually, make web pages more attractive, and improve the presentation of products, services, tutorials, and other content.

HTML provides the <img> element to embed images into a web page. An image can be stored in the website's own folder or loaded from another web location.

For example, an educational website may use images for its logo, course banners, diagrams, illustrations, and project demonstrations.

Important: Images have been supported in HTML since the early versions of the language. HTML5 continues to support the <img> element and provides additional features for modern image handling.

2. Why Are Images Used on Websites?

Images serve several purposes on a website:

  • Visual communication: Explain information through pictures.
  • Brand identity: Display logos and brand graphics.
  • Product presentation: Show products and their features.
  • Education: Explain concepts using diagrams and illustrations.
  • Navigation: Use suitable graphical elements to support navigation.
  • Engagement: Make pages more visually interesting.
  • Documentation: Display screenshots and technical illustrations.

Common Examples

Image Type Typical Use
Logo Identifies a company, organization, or website.
Banner Displays a large graphic in a page header or promotional area.
Product Image Shows a product available for purchase.
Diagram Explains technical or educational concepts.
Thumbnail Provides a small preview of a larger image or resource.
Screenshot Demonstrates software interfaces or practical steps.

3. How Images Are Added to HTML

The HTML <img> element is used to embed an image in a web page. It uses the src attribute to specify the image location.

Basic Syntax

<img src="image.jpg" alt="Description of the image">

In this example:

  • <img> is the HTML image element.
  • src specifies the location of the image file.
  • alt provides alternative text describing the image.
The src and alt attributes will be studied in detail in the next lessons. For now, understand that the <img> element is the basic HTML mechanism for embedding an image.

4. Understanding How a Browser Displays an Image

When a browser loads an HTML document containing an image, it reads the image element, identifies the image location, and requests the image resource if necessary.

The general process is:

HTML Document
↓
Browser Reads <img>
↓
Finds Image Using src
↓
Loads Image Resource
↓
Displays Image
  1. The browser loads the HTML document.
  2. It encounters an <img> element.
  3. It reads the image location specified by src.
  4. It attempts to retrieve the image file.
  5. If the resource loads successfully, the browser displays it.
If the image path is incorrect, the file is missing, or the server cannot provide the image, the browser may display a broken-image indicator instead.

5. Types of Image Sources

HTML images commonly come from two types of locations.

5.1 Local Images

A local image is stored inside your website's project directory. The HTML file refers to it using a relative or absolute path.

Example project structure:

my-website/
│
├── index.html
│
└── images/
    ├── logo.png
    ├── banner.jpg
    └── circuit-diagram.png

To display the banner from index.html:

<img src="images/banner.jpg" alt="Website banner">

The browser looks for the images folder in the same directory as the HTML file and then looks for banner.jpg.

5.2 Remote Images

A remote image is stored on another web server and is referenced using a URL. 

<img
    src="https://example.com/images/banner.jpg"
    alt="Example website banner"
>

The browser uses the URL to request the image from the remote server. The image may not load if the URL is invalid, the server is unavailable, or access is restricted.

Do not use an image URL without checking whether you have permission to use that image. Remote images can also disappear if the original website changes or removes the resource.

6. Understanding Image File Formats

Images are stored in different file formats. Each format has characteristics that make it suitable for particular purposes.

Format Common Extension Typical Usage
JPEG .jpg, .jpeg Photographs and complex images.
PNG .png Logos, screenshots, and images requiring transparency.
GIF .gif Simple animations and small graphics.
SVG .svg Scalable logos, icons, and vector illustrations.
WebP .webp Web images with efficient compression.
AVIF .avif Modern compressed images with high visual quality.
Image formats will be examined in greater detail in Lesson 3: Image Formats and Usage.

7. Raster Images and Vector Images

Images can also be classified according to how their visual information is represented.

7.1 Raster Images

A raster image is made up of a grid of tiny picture elements called pixels. Each pixel contains colour information.

  • Common raster formats include JPEG, PNG, GIF, WebP, and AVIF.
  • Raster images have a fixed pixel resolution.
  • Enlarging them too much can make them appear blurry or pixelated.
  • They are commonly used for photographs and screenshots.

7.2 Vector Images

A vector image represents graphics using mathematical descriptions such as paths, curves, and shapes.

  • SVG is a common web vector format.
  • Vector graphics can be scaled without the same pixelation associated with raster images.
  • They are useful for logos, icons, diagrams, and illustrations.
Feature Raster Image Vector Image
Representation Pixels Mathematical shapes and paths
Scaling May lose sharpness when enlarged Can scale without pixelation
Common Uses Photographs and screenshots Logos, icons, and diagrams
Examples JPEG, PNG, WebP SVG

8. HTML Images and CSS Background Images

Images can be displayed using HTML or CSS. The correct approach depends on the purpose of the image.

HTML Image

Use the <img> element when an image is meaningful content, such as a product photograph, course diagram, or tutorial illustration. 

<img src="images/circuit-diagram.png"
     alt="Circuit diagram">

CSS Background Image

Use a CSS background image when the graphic is primarily decorative, such as a background texture or decorative banner. 

<div class="banner">
    Welcome to My Learning Hub
</div>
.banner {
    background-image: url("images/background.jpg");
    background-size: cover;
    background-position: center;
    padding: 60px 20px;
}
HTML Image CSS Background Image
Represents image content in the document. Provides visual styling or decoration.
Can have alternative text through the alt attribute. Does not provide an alt attribute.
Suitable for meaningful images. Suitable for decorative backgrounds.
A meaningful image should generally be represented using HTML rather than relying only on a CSS background. Accessibility and alternative text are covered in Lesson 4.

9. Organizing Images in a Website Project

Keeping image files organized makes a website easier to maintain. A separate folder named images is commonly used.

Example structure for a learning website:

NS-Learning-Hub/
│
├── index.html
├── about.html
├── style.css
│
└── html5/
    ├── index.html
    │
    ├── images/
    │   ├── html5-logo.png
    │   ├── html-course-banner.jpg
    │   └── html-diagram.png
    │
    └── ch06_HTML_Images_and_Graphics/
        ├── index.html
        ├── L01_Introduction_to_Images_in_HTML.html
        └── L02_Image_Element_and_Attributes.html

If an image is stored in html5/images/ and the HTML lesson is stored in html5/ch06_HTML_Images_and_Graphics/, the relative path from the lesson file to the image folder is: 

../images/html5-logo.png

Example:

<img src="../images/html5-logo.png"
     alt="HTML5 logo">
Relative paths depend on the location of the HTML file, not on the location from which you open the website in your browser. Also remember that GitHub Pages file and folder names are case-sensitive.

10. Basic Practical Example

Let us create a simple HTML page that displays an image from a local images folder.

Step 1: Create the Project Folder

image-practice/
│
├── index.html
│
└── images/
    └── course-banner.jpg

Step 2: Add an Image

Place an image file named course-banner.jpg inside the images folder. You can use your own image.

Step 3: Write the HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My First Image Page</title>
</head>
<body>

    <h1>Welcome to My Learning Website</h1>

    <p>This is an example of an image in HTML.</p>

    <img src="images/course-banner.jpg"
         alt="Course banner">

</body>
</html>

Expected Result

Expected browser output:
  • A heading: Welcome to My Learning Website
  • A paragraph describing the image.
  • The course banner image displayed below the paragraph, provided the image file exists at the specified path.

11. Image Performance and Good Practices

Images can make a web page larger and slower to load. Good image management improves the performance and usability of a website.

  • Choose an appropriate image format for the content.
  • Compress images to reduce unnecessary file size.
  • Avoid uploading unnecessarily large images.
  • Use descriptive file names such as html-course-banner.jpg.
  • Keep related images in organized folders.
  • Provide meaningful alternative text for informative images.
  • Use suitable image dimensions for the intended display area.
  • Respect image copyright and licensing conditions.

Image Copyright and Licensing

Not every image available on the internet is free to reuse. Before including an image in a website, check its copyright and licence conditions.

  • Use images that you created yourself.
  • Use images with licences that permit your intended use.
  • Follow attribution requirements when required by the licence.
  • Do not assume that an image is free to use just because it can be downloaded.

12. Common Mistakes

Mistake Explanation / Solution
Incorrect image path Verify the folder name, file name, and relative path.
Incorrect file extension Check whether the actual file is .jpg, .png, .webp, or another format.
Incorrect capitalization Match the exact file and folder capitalization, especially on GitHub Pages.
Missing image file Make sure the image has actually been uploaded to the project.
Using an inaccessible remote URL Check whether the remote image URL is valid and accessible.
Using large image files Resize or compress images when appropriate.
Missing alternative text Provide appropriate alt text for accessibility.

14. Interview Questions and Answers

Q1. What is the purpose of images in HTML?

Images are used to display visual content such as photographs, logos, diagrams, banners, and illustrations on web pages.

Q2. Which HTML element is used to display an image?

The <img> element is used to embed an image in an HTML document.

Q3. What is the purpose of the src attribute?

The src attribute specifies the URL or path of the image resource.

Q4. Can HTML display images stored on another server?

Yes. An image can be loaded from another server by specifying an accessible image URL in the src attribute.

Q5. What is a raster image?

A raster image is made up of pixels arranged in a grid. JPEG and PNG are common raster formats.

Q6. What is a vector image?

A vector image represents graphics using mathematical paths and shapes. SVG is a common vector format.

Q7. What is the difference between an HTML image and a CSS background image?

An HTML image is part of the document's content, while a CSS background image is generally used for decorative styling.

Q8. Why should images be optimized?

Image optimization reduces file size and can improve page loading speed and overall website performance.

Q9. What happens if an image path is incorrect?

The browser cannot retrieve the image and may display a broken-image indicator.

Q10. Why should a website use an images folder?

It keeps image resources organized and makes the project easier to maintain.
