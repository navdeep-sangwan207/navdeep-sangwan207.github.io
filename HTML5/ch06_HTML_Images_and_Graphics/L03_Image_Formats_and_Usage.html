Chapter 6: HTML Images and Graphics

1. Introduction

Images are available in different file formats. Each format uses a particular method to store image information and has different characteristics related to quality, file size, compression, transparency, and animation.

Selecting the right image format is important for website performance, visual quality, accessibility, and compatibility.

For example, JPEG is commonly used for photographs, PNG is useful for transparent graphics, SVG is suitable for scalable logos, and WebP and AVIF provide modern image compression options.

Learning objective: By the end of this lesson, you should be able to identify common image formats and select an appropriate format for a particular website requirement.

2. Understanding Image Formats

An image format defines how image data is encoded and stored in a file. The format determines how the image is represented and what features it supports.

Important Image Characteristics

  • Image quality: How accurately the image represents the original.
  • File size: How much storage space the image requires.
  • Compression: How image data is reduced to save space.
  • Transparency: Whether transparent or partially transparent pixels are supported.
  • Animation: Whether a file can contain multiple frames.
  • Browser support: Whether common browsers can display the format.
  • Scalability: Whether the graphic can be resized without pixelation.

3. JPEG Format

JPEG stands for Joint Photographic Experts Group. It is a widely used raster image format, particularly for photographs and images containing many colours and smooth variations.

File Extensions

.jpg
.jpeg

Characteristics of JPEG

  • Uses lossy compression.
  • Suitable for photographs.
  • Can produce relatively small file sizes.
  • Supports millions of colours.
  • Does not support transparency in standard JPEG files.
  • Repeated lossy re-encoding can reduce image quality.

Example Usage

<img src="images/landscape.jpg"
     alt="Mountain landscape">

Common Applications

  • Photographs.
  • Travel websites.
  • Product photography.
  • Blog illustrations.
  • Gallery images.
JPEG is generally a good choice for photographic images where reducing file size is important and some loss of image data is acceptable.

4. PNG Format

PNG stands for Portable Network Graphics. It is a raster image format commonly used for graphics that require lossless compression or transparency.

File Extension

.png

Characteristics of PNG

  • Uses lossless compression.
  • Supports transparency through an alpha channel.
  • Preserves sharp edges and text clearly.
  • Suitable for logos, diagrams, and screenshots.
  • Can produce larger files than lossy formats for photographic images.

Example Usage

<img src="images/logo.png"
     alt="Company logo">

Common Applications

  • Transparent logos.
  • Website icons.
  • Technical diagrams.
  • Screenshots.
  • Interface graphics.
PNG is a useful choice when image transparency or lossless preservation is important.

5. GIF Format

GIF stands for Graphics Interchange Format. It is an image format that supports simple animation and transparency.

File Extension

.gif

Characteristics of GIF

  • Supports a palette of up to 256 colours per frame.
  • Uses lossless compression for its indexed-colour image data.
  • Supports multiple frames for animation.
  • Supports simple binary transparency.
  • Not ideal for detailed photographs.

Example Usage

<img src="images/animation.gif"
     alt="Animated demonstration">

Common Applications

  • Simple animated graphics.
  • Small demonstrations.
  • Animated icons.
  • Short looping animations.
GIF supports animation, but it is limited to a maximum of 256 colours per frame. For many modern web animations, video formats or newer animated image formats may be more efficient.

6. SVG Format

SVG stands for Scalable Vector Graphics. It is an XML-based vector image format used to describe graphics using shapes, paths, lines, curves, and other graphical elements.

File Extension

.svg

Characteristics of SVG

  • Uses vector graphics rather than a fixed pixel grid.
  • Can scale without the pixelation associated with raster images.
  • Supports text, paths, shapes, and gradients.
  • Can be styled and animated using supported web technologies.
  • Can often produce small files for simple graphics.
  • Can be embedded directly in HTML or loaded as an image resource.

Example: Using an SVG File

<img src="images/logo.svg"
     alt="Website logo">

Example: Basic SVG Markup

<svg xmlns="http://www.w3.org/2000/svg"
     width="200"
     height="120"
     viewBox="0 0 200 120">

    <rect x="10" y="10"
          width="180" height="100"
          fill="lightblue"/>

    <circle cx="100" cy="60"
            r="30"
            fill="blue"/>

</svg>

Common Applications

  • Website logos.
  • Icons.
  • Technical diagrams.
  • Charts and illustrations.
  • Scalable interface graphics.
SVG is particularly useful when a graphic must remain sharp at different display sizes.

7. WebP Format

WebP is a modern image format developed by Google. It supports both lossy and lossless compression, transparency, and animation.

File Extension

.webp

Characteristics of WebP

  • Supports lossy compression.
  • Supports lossless compression.
  • Supports transparency.
  • Supports animation.
  • Often produces smaller files than comparable JPEG or PNG images.
  • Widely supported by modern web browsers.

Example Usage

<img src="images/product.webp"
     alt="Product photograph">

Common Applications

  • Product images.
  • Website banners.
  • Photographs.
  • Transparent graphics.
  • Animated images.

8. AVIF Format

AVIF stands for AV1 Image File Format. It is a modern image format based on the AV1 video codec technology.

File Extension

.avif

Characteristics of AVIF

  • Supports lossy and lossless image compression modes.
  • Supports transparency.
  • Supports high dynamic range image content.
  • Can provide high visual quality at relatively small file sizes.
  • Supports image sequences and animation.
  • Encoding and decoding requirements can be more demanding than simpler formats.

Example Usage

<img src="images/landscape.avif"
     alt="Mountain landscape">

Common Applications

  • High-quality website photographs.
  • Large image collections.
  • Performance-focused websites.
  • Modern image delivery systems.

9. Comparison of Common Image Formats

Format Compression Transparency Animation Typical Usage
JPEG Lossy No No Photographs
PNG Lossless Yes No Logos and screenshots
GIF Lossless indexed colour Binary transparency Yes Simple animations
SVG Vector representation Yes Can be animated Logos and icons

Actual file size and visual quality depend on image content, dimensions, encoder settings, and compression level. No format is always the smallest or best for every image.

10. Understanding Image Compression

Image compression reduces the amount of data required to store an image. It can help reduce storage requirements and improve website loading performance.

There are two major types of image compression.

10.1 Lossy Compression

Lossy compression reduces file size by removing some image information. Depending on the compression level, this can reduce visual quality.

Examples include:

  • JPEG.
  • Lossy WebP.
  • Lossy AVIF.

Advantages:

  • Can significantly reduce image file size.
  • Useful for large photographs.
  • Can improve image delivery performance.

Disadvantages:

  • Some image information is permanently discarded.
  • Excessive compression can create visible artefacts.
  • Repeated lossy re-encoding may further reduce quality.

10.2 Lossless Compression

Lossless compression reduces file size without discarding image information. The original image data can be reconstructed from the compressed file.

Examples include:

  • PNG.
  • Lossless WebP.
  • Lossless AVIF.

Advantages:

  • Preserves image information.
  • Useful for graphics and screenshots.
  • Suitable when exact pixel data must be retained.

Disadvantages:

  • May produce larger files than lossy compression.
  • Compression efficiency depends on image content.

Lossy vs Lossless Compression

Feature Lossy Lossless
Data removal Some image data is discarded. No image data is discarded.
Visual quality May decrease depending on compression. Preserves the original image data.
File size Often smaller. Often larger for comparable images.
Common usage Photographs. Logos, diagrams, and screenshots.

11. Understanding Transparency

Transparency allows an image to contain pixels that are partially or completely invisible. It is useful when placing logos, icons, and graphics over different backgrounds.

Alpha Channel

An alpha channel represents the opacity of pixels in an image. It allows a pixel to be fully opaque, fully transparent, or partially transparent.

  • Opaque: The pixel is fully visible.
  • Transparent: The pixel is invisible.
  • Partially transparent: The pixel allows some background to show through.

Formats Supporting Transparency

  • PNG.
  • WebP.
  • AVIF.
  • SVG.
  • GIF supports simple binary transparency.
Standard JPEG images do not support an alpha channel. Use a suitable format such as PNG, WebP, or SVG when transparency is required.

12. Understanding Animated Image Formats

Some image formats can store multiple frames and display them sequentially to create animation.

GIF Animation

GIF is traditionally used for simple looping animations. It supports multiple frames but has a limited colour palette. 

<img src="images/demo.gif"
     alt="Animated process demonstration">

Animated WebP

WebP supports animated images and can offer better compression than GIF for many types of animation. 

<img src="images/demo.webp"
     alt="Animated demonstration">

Animated AVIF

AVIF also supports image sequences and animation, depending on the encoder and browser support.

If an animation is intended to communicate an important process, provide suitable text or another accessible explanation.

13. Choosing the Right Image Format

The best format depends on the image content, required quality, transparency, animation, compatibility, and performance goals.

Requirement Suitable Format Reason
Photograph JPEG, WebP, AVIF Efficient compression for photographic content.
Transparent logo PNG, SVG, WebP Supports transparency.
Scalable icon SVG Remains sharp at different sizes.
Screenshot PNG, WebP Can preserve sharp edges and text.
Simple animation GIF, WebP, AVIF Supports animated image sequences.
Modern compressed photograph WebP, AVIF Can provide good visual quality at reduced file sizes.
Technical vector diagram SVG Scalable shapes and paths.

PNG Example

     alt="Website logo">

     alt="Website icon">

15. Using the picture Element for Format Alternatives

The HTML <picture> element allows developers to provide alternative image resources. The browser can select a suitable source based on supported formats or media conditions.

Example

<picture>

    <source
        srcset="images/photo.avif"
        type="image/avif">

    <source
        srcset="images/photo.webp"
        type="image/webp">

    <img
        src="images/photo.jpg"
        alt="Mountain landscape">

</picture>

In this example:

  • The browser checks the AVIF source first.
  • If it cannot use AVIF, it can try WebP.
  • The JPEG image is provided as the fallback through the img element.
The <picture> element and its responsive image capabilities are covered in detail in Lesson 7.

16. Image Optimization for Websites

Image optimization is the process of reducing image file size and improving delivery without unnecessarily sacrificing visual quality.

Important Optimization Techniques

  1. Choose the correct format: Use a format suited to the image content.
  2. Resize images: Avoid serving unnecessarily large images.
  3. Compress images: Choose an appropriate compression level.
  4. Use responsive images: Provide suitable image sizes for different screens.
  5. Lazy load suitable images: Defer images that are not immediately needed.
  6. Specify dimensions: Help browsers reserve layout space and reduce layout shifts.
  7. Use a CDN when appropriate: Deliver images efficiently from distributed servers.

18. Common Mistakes

Mistake Correct Approach
Using JPEG for transparent logos Choose PNG, WebP, or SVG.
Using GIF for detailed photographs Choose JPEG, WebP, or AVIF.
Using raster images for every logo Consider SVG for scalable graphics.
Uploading unnecessarily large images Resize and optimize them.
Assuming every format is supported by every browser Consider browser support and provide suitable alternatives when needed.
Using excessive compression Balance file size and visual quality.
Ignoring image dimensions Use appropriate dimensions and preserve aspect ratio.

19. Interview Questions and Answers

Q1. What is JPEG?

JPEG is a raster image format that uses lossy compression and is commonly used for photographs.

Q2. What is PNG?

PNG is a raster image format that uses lossless compression and supports transparency.

Q3. What is the main advantage of SVG?

SVG graphics can scale to different sizes without the pixelation associated with raster images.

Q4. Which image format supports animation?

GIF, animated WebP, and animated AVIF can support animation.

Q5. What is lossy compression?

Lossy compression reduces file size by permanently removing some image information.

Q6. What is lossless compression?

Lossless compression reduces file size without discarding image information.

Q7. What is an alpha channel?

An alpha channel represents the opacity of pixels and enables transparency.

Q8. What is WebP?

WebP is a modern image format that supports lossy and lossless compression, transparency, and animation.

Q9. What is AVIF?

AVIF is an image format based on AV1 technology that supports efficient image compression and modern image features.

Q10. Why is image optimization important?

It reduces image file sizes, saves bandwidth, and can improve website loading performance.
