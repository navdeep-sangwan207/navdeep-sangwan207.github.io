1. Introduction to Responsive Images

Modern websites are accessed through different devices such as desktop computers, laptops, tablets, and smartphones. These devices have different screen sizes, resolutions, and display capabilities.

A responsive image adapts to the available display space or allows the browser to select an appropriate image resource for the device and viewing conditions.

Definition: Responsive images are images designed to display appropriately across different screen sizes, resolutions, and device conditions while avoiding unnecessary image downloads where possible.

Why are responsive images important?

  • Improve the user experience on different devices.
  • Help prevent images from overflowing their containers.
  • Allow suitable image sizes to be selected.
  • Support high-resolution displays.
  • Can reduce unnecessary bandwidth consumption.
  • Help improve page-loading performance.

2. Basic Responsive Image Using CSS

The simplest way to make an image fit within its container is to use CSS.

HTML

<img
    src="laptop.jpg"
    alt="Laptop on a desk"
    class="responsive-image">

CSS

.responsive-image {
    max-width: 100%;
    height: auto;
}

Explanation

  • max-width: 100% prevents the image from exceeding the width of its container.
  • height: auto maintains the original aspect ratio.
CSS responsiveness changes how an image is displayed. It does not automatically select a smaller source file for a mobile device.

3. The <picture> Element

The HTML <picture> element allows developers to provide multiple image sources. The browser selects an appropriate source based on the source conditions and supported image formats.

Basic syntax

<picture>
    <source srcset="image.webp" type="image/webp">
    <source srcset="image.png" type="image/png">

    <img src="image.jpg" alt="Description of image">
</picture>

Important elements

Element Purpose
<picture> Groups alternative image sources and a fallback img element.
<source> Provides an alternative image resource and optional selection conditions.
<img> Displays the selected image and provides the fallback image and alt text.
The img element is required inside picture. It provides the fallback source and the image's alternative text.

4. The <source> Element

The <source> element specifies an alternative media resource. Inside picture, it helps the browser select an appropriate image source.

Important attributes

Attribute Purpose
srcset Specifies one or more candidate image URLs.
media Specifies a media condition for selecting a source.
type Specifies the media type of the source resource.
sizes Provides expected display sizes for width-descriptor candidates.

Example

<picture>
    <source
        srcset="image.webp"
        type="image/webp">

    <img
        src="image.jpg"
        alt="Mountain landscape">
</picture>

If the browser supports the WebP source, it can use that resource. Otherwise, it can fall back to the JPEG image.

5. The srcset Attribute

The srcset attribute allows developers to provide multiple image candidates. The browser can select an appropriate candidate according to the available display conditions.

Example using width descriptors

<img
    src="photo-800.jpg"
    srcset="
        photo-400.jpg 400w,
        photo-800.jpg 800w,
        photo-1200.jpg 1200w
    "
    sizes="(max-width: 600px) 100vw,
           (max-width: 1000px) 80vw,
           800px"
    alt="Mountain landscape">

Understanding width descriptors

Descriptor Meaning
400w Candidate image has an intrinsic width of 400 pixels.
800w Candidate image has an intrinsic width of 800 pixels.
1200w Candidate image has an intrinsic width of 1200 pixels.

The browser uses the candidate information together with the expected display size and device characteristics when choosing an image.

Density descriptors

The srcset attribute can also use pixel-density descriptors such as 1x and 2x. 

<img
    src="logo-1x.png"
    srcset="
        logo-1x.png 1x,
        logo-2x.png 2x
    "
    alt="Company logo">

Here, the browser can select a higher-density image for a high-density display.

Do not mix width descriptors such as 400w with density descriptors such as 2x in the same srcset candidate list.

6. The sizes Attribute

The sizes attribute tells the browser the expected display width of an image under different media conditions when width descriptors are used in srcset.

Example

<img
    src="photo-800.jpg"
    srcset="
        photo-400.jpg 400w,
        photo-800.jpg 800w,
        photo-1200.jpg 1200w
    "
    sizes="
        (max-width: 600px) 100vw,
        (max-width: 1000px) 80vw,
        800px
    "
    alt="Mountain landscape">

Understanding the sizes value

  • (max-width: 600px) 100vw: On viewports up to 600px wide, the image is expected to occupy the full viewport width.
  • (max-width: 1000px) 80vw: On wider viewports up to 1000px, the image is expected to occupy 80% of the viewport width.
  • 800px: Otherwise, the expected display width is 800px.
The sizes attribute describes the expected layout width. It does not directly set the rendered CSS width of the image.

7. Art Direction Using the Picture Element

Art direction means providing different image compositions for different display conditions.

For example, a wide landscape image may be suitable for a desktop screen, while a closely cropped portrait image may be more suitable for a mobile screen.

Example

<picture>

    <source
        media="(max-width: 600px)"
        srcset="portrait.jpg">

    <source
        media="(min-width: 601px)"
        srcset="landscape.jpg">

    <img
        src="landscape.jpg"
        alt="Mountain landscape">

</picture>

How it works

  1. The browser checks the source elements in order.
  2. It evaluates the media conditions.
  3. It selects an applicable supported source.
  4. The img element acts as the fallback.
This approach is useful when the mobile and desktop versions need different crops or compositions, not merely different file sizes of the same image.

8. Providing Multiple Image Formats

Different image formats offer different benefits in terms of compression, quality, transparency, and browser support. The picture element can provide multiple formats.

Example: AVIF, WebP, and JPEG

<picture>

    <source
        srcset="photo.avif"
        type="image/avif">

    <source
        srcset="photo.webp"
        type="image/webp">

    <img
        src="photo.jpg"
        alt="Mountain landscape">

</picture>

The browser checks the source elements in order and uses the first suitable source it supports. If no source is suitable, it uses the img fallback.

Format Common use
JPEG Photographs and general photographic images.
PNG Images requiring lossless compression or transparency.
WebP Web images with efficient compression.
AVIF Modern web images with efficient compression.
SVG Logos, icons, and scalable vector graphics.

9. Difference Between img and picture

img picture
Displays an image. Groups alternative image sources and an img fallback.
Uses src and optionally srcset. Contains source elements and an img element.
Can be used independently. Requires an img element inside it.
Can support resolution switching through srcset. Supports art direction and format selection.

10. Responsive Images and Performance

Images can significantly affect webpage loading time. Proper image selection and optimization can improve performance.

Performance best practices

  • Choose an appropriate image format.
  • Compress images without unacceptable quality loss.
  • Provide multiple image sizes where useful.
  • Use srcset and sizes for resolution switching.
  • Use picture for art direction and format selection.
  • Set width and height to help reserve layout space.
  • Use lazy loading for images that are not initially needed.
  • Avoid lazy-loading important above-the-fold images.

Example: Lazy loading

<img
    src="gallery-image.jpg"
    alt="Electronics project on a workbench"
    loading="lazy"
    width="800"
    height="500">

The loading="lazy" attribute allows the browser to defer loading an image until it is near the visible area.

Example: Eager loading

<img
    src="hero-image.jpg"
    alt="Welcome to the learning portal"
    loading="eager"
    width="1200"
    height="600">

Eager loading requests the image without lazy-loading deferral. It is suitable when an image needs to load immediately.

The browser normally loads images eagerly unless another loading strategy is specified. Use lazy loading selectively, particularly for images lower down a long page.

11. Complete Practical Example

The following example combines the picture element, source selection, responsive image candidates, and a fallback image. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Responsive Images</title>

    <style>
        img {
            max-width: 100%;
            height: auto;
        }
    </style>
</head>

<body>

    <h1>Responsive Image Example</h1>

    <picture>

        <source
            media="(max-width: 600px)"
            srcset="mobile-image.webp"
            type="image/webp">

        <source
            media="(min-width: 601px)"
            srcset="desktop-image.webp"
            type="image/webp">

        <img
            src="desktop-image.jpg"
            alt="Mountain landscape"
            width="1200"
            height="600">

    </picture>

</body>
</html>

Expected Result

  • A heading displays above the image.
  • On smaller viewports, the mobile image source is selected when applicable.
  • On larger viewports, the desktop image source is selected when applicable.
  • The JPEG image provides a fallback.
  • The image scales within its available container width.
Create the referenced image files in the same folder as the HTML file, or update the paths. The image dimensions and visual appearance should be appropriate for the selected viewport.

12. Common Mistakes

Mistake Correction
Using picture without img Include an img element inside picture.
Forgetting the alt attribute Provide appropriate alternative text on img.
Using incorrect image paths Check the filenames and relative paths.
Confusing srcset and sizes srcset lists image candidates; sizes describes expected display width for width-descriptor candidates.
Assuming CSS alone selects smaller files Use srcset and sizes when resolution switching is needed.
Using picture for every image Use img alone when alternative sources or art direction are unnecessary.
Lazy-loading every image Do not defer important above-the-fold images unnecessarily.

14. Interview Questions and Answers

Q1. What is a responsive image?

A responsive image adapts to different display conditions and can use suitable image resources for different devices and layouts.

Q2. What is the purpose of the picture element?

It allows developers to provide alternative image sources for art direction and format selection.

Q3. What is the purpose of the source element?

It specifies an alternative media resource that the browser can select when its conditions are satisfied.

Q4. What is the srcset attribute?

It provides multiple image candidates so that the browser can select a suitable resource.

Q5. What is the sizes attribute?

It describes the expected display width of an image under different conditions when width descriptors are used.

Q6. What is art direction?

Art direction means providing different image compositions or crops for different display conditions.

Q7. What is the difference between picture and img?

Img displays an image, while picture provides a container for alternative sources and an img fallback.

Q8. What does the type attribute specify in source?

It specifies the media type of the image resource, such as image/webp or image/avif.

Q9. What is the purpose of loading="lazy"?

It allows the browser to defer loading an image until it is near the visible area of the page.

Q10. What is the difference between 1x and 2x descriptors?

They represent image candidates intended for different pixel densities, such as standard-density and higher-density displays.
