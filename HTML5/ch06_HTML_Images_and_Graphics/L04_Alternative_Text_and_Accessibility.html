Lesson 4: Alternative Text and Accessibility

HTML5 – Complete Study Course

1. Introduction to Image Accessibility

Web accessibility means designing websites and web content so that people with different abilities can use and understand them. Accessibility is important for users who rely on assistive technologies such as screen readers.

Images often communicate important information. However, a user who cannot see an image may not receive that information unless the image has an appropriate text alternative.

Definition: Alternative text, commonly called alt text, is a textual description or replacement for an image that communicates its relevant meaning or purpose when the image cannot be visually perceived.

Why is image accessibility important?

  • Helps screen-reader users understand meaningful images.
  • Provides information when an image cannot be loaded.
  • Improves the usability of websites.
  • Supports users with different visual abilities.
  • Helps make web content more inclusive.

2. What is Alternative Text?

The alt attribute provides a text alternative for an image in the HTML <img> element.

Syntax

<img src="image.jpg" alt="Description of the image">

Example

<img src="laptop.jpg" alt="Silver laptop placed on a desk">

If a screen reader encounters this image, it can communicate the alternative text to the user.

Important: The alt attribute is not intended to be a tooltip, a filename, or a place to insert keywords. It should communicate the image's relevant purpose or information.

Alt text versus title attribute

Attribute Purpose
alt Provides a text alternative for an image.
title Provides advisory information, which browsers may show as a tooltip.

The title attribute must not be used as a replacement for meaningful alternative text.

3. Types of Images and Their Alternative Text

Not every image needs a descriptive alt value. The correct alternative depends on the purpose of the image in its context.

3.1 Informative Images

Informative images communicate meaningful information that is relevant to the surrounding content. Their alternative text should communicate the essential information.

Example: A photograph used in an article to show a solar panel installation. 
<img
    src="solar-panel.jpg"
    alt="Solar panels installed on a residential rooftop">

The description explains the relevant content instead of merely saying that the image is a photograph.

3.2 Decorative Images

Decorative images do not provide meaningful information and are included only for visual presentation.

Use an empty alt attribute for decorative images: 

<img src="decorative-pattern.png" alt="">

An empty alt value tells assistive technologies that the image can be ignored.

Important distinction: alt="" is different from omitting the alt attribute. For an ordinary HTML image, provide an alt attribute even when its value is empty.

3.3 Functional Images

A functional image performs an action or acts as a link. Its alternative text should describe the function, destination, or action rather than simply describing its appearance.

Example: Home link represented by an image

<a href="index.html">
    <img src="home-icon.png" alt="Home">
</a>

The alternative text communicates the destination or purpose of the link.

Example: Search button represented by an image

<button type="submit">
    <img src="search.png" alt="Search">
</button>

3.4 Images Containing Text

Sometimes an image contains text that communicates important information, such as a notice, instruction, or announcement. Whenever possible, use real HTML text instead of embedding important text in an image. 

<img
    src="event-banner.png"
    alt="Electronics Workshop, 20 November, Registration Open">

The alternative should convey the important text and purpose of the banner.

3.5 Complex Images

Complex images include charts, graphs, technical diagrams, maps, and illustrations containing substantial information.

A short alt value may identify the image, while a nearby description or data table communicates its detailed information. 

<img
    src="sales-chart.png"
    alt="Bar chart comparing monthly sales from January to June"
    aria-describedby="chart-description">

<div id="chart-description">
    Sales increased from 100 units in January to
    250 units in June, with a small decrease in April.
</div>
For complex diagrams, consider providing a detailed explanation, structured data table, or an accessible equivalent near the image. Do not place an excessively long explanation in the alt attribute.

4. Writing Effective Alternative Text

Good alt text is concise, meaningful, and appropriate to the context in which the image appears.

Guidelines

  1. Describe the relevant information or purpose of the image.
  2. Keep the description concise but sufficiently informative.
  3. Consider the surrounding text and page context.
  4. Avoid unnecessary phrases such as "image of" or "picture of".
  5. Do not repeat information already available in nearby text.
  6. Do not stuff alt text with search-engine keywords.
  7. Use an empty alt value for decorative images.
  8. Describe the action or destination for functional images.

Bad and Improved Examples

Image context Weak alternative text Improved alternative text
Solar installation image123.jpg Solar panels installed on a rooftop
Company logo linking to homepage Logo Company name or Home, depending on context
Search icon button Blue magnifying glass Search
Decorative background Blue decorative image Empty alt: alt=""
Technical circuit diagram Diagram Power supply circuit with a bridge rectifier and filter capacitor
Alt text is context-dependent. The same image may need different alternative text depending on how it is used on a particular page.

5. Alternative Text for Icons and Logos

Icons

An icon used as a control should have an accessible name that communicates its function. 

<button type="button">
    <img src="menu.png" alt="Open navigation menu">
</button>

If an icon is purely decorative and the control already has an accessible name, the icon image can use an empty alt value. 

<button type="button" aria-label="Open navigation menu">
    <img src="menu.png" alt="">
</button>

Logos

A company logo may communicate the organization’s identity. Use alternative text that identifies the organization when that information is relevant. 

<img src="company-logo.png" alt="ABC Electronics">

If the logo is inside a link to the homepage, its alternative text should communicate the link's purpose. The appropriate wording depends on the surrounding content.

6. Images Used as CSS Backgrounds

Images can also be added using CSS background properties. These are commonly used for decorative visual presentation. 

<div class="banner">
    Welcome to NS Learning Hub
</div>

<style>
.banner {
    background-image: url("background.jpg");
    background-size: cover;
    background-position: center;
    padding: 50px;
}
</style>

A CSS background image does not provide an HTML alt attribute.

If a background image communicates meaningful information, provide that information through accessible HTML text or another appropriate accessible method. Do not rely on the background image alone.

7. Alternative Text and WCAG Guidelines

WCAG stands for Web Content Accessibility Guidelines. These guidelines help developers make web content more accessible to people with disabilities.

WCAG Success Criterion 1.1.1 – Non-text Content

WCAG 2.2 includes Success Criterion 1.1.1 at Level A. In general, non-text content presented to users must have a text alternative that serves an equivalent purpose, subject to the criterion's specific exceptions.

Important concepts

  • Meaningful images need appropriate text alternatives.
  • Decorative images can use empty alternative text.
  • Functional images need alternatives describing their purpose.
  • Complex visual information may need a detailed text equivalent.
  • Some content has specific exceptions under WCAG.
Remember: An image's alternative text should communicate an equivalent purpose or information, not necessarily describe every visible detail.

8. Common Mistakes in Image Accessibility

Mistake Why it is a problem Better approach
Missing alt attribute Meaningful image information may not be available. Provide an appropriate alt value.
Using filenames as alt text Filenames rarely explain image meaning. Write meaningful descriptions.
Using alt="" for informative images Important information may be skipped. Describe the relevant information.
Writing very long alt text It can make navigation difficult. Use a short alternative and a detailed description nearby.
Using title instead of alt Title does not replace the image's text alternative. Use the alt attribute.
Repeating nearby text Can create unnecessary repetition. Consider the surrounding content.

9. Testing Image Accessibility

Developers should test images to check whether their purpose and information can be understood without relying only on visual presentation.

Useful testing methods

  1. Screen reader testing: Test with tools such as NVDA on Windows or VoiceOver on supported Apple devices.
  2. Inspect HTML: Check whether each meaningful image has suitable alt text.
  3. Check decorative images: Confirm that decorative images do not create unnecessary screen-reader announcements.
  4. Check functional images: Confirm that image links and buttons have understandable accessible names.
  5. Review complex images: Verify that charts and diagrams have an accessible text equivalent.
No single test is sufficient to establish full accessibility. Combine automated checks, manual inspection, and assistive technology testing.

10. Complete Practical Example

The following example demonstrates informative, decorative, and functional images in a simple HTML page. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Accessible Images</title>
</head>
<body>

    <h1>Electronics Learning</h1>

    <h2>Informative Image</h2>
    <img
        src="circuit.jpg"
        alt="Electronic circuit assembled on a breadboard">

    <h2>Decorative Image</h2>
    <img src="decoration.png" alt="">

    <h2>Functional Image</h2>
    <a href="index.html">
        <img src="home.png" alt="Home">
    </a>

</body>
</html>

Expected Result

  • A heading displays the title Electronics Learning.
  • The circuit image has a descriptive text alternative.
  • The decorative image is ignored by screen readers.
  • The home image provides an accessible link to index.html.
Replace the sample image filenames with actual image files available in your project folder before testing.

12. Interview Questions and Answers

Q1. What is alternative text in HTML?

Alternative text is a textual replacement for an image, provided using the alt attribute of the img element.

Q2. Which HTML attribute provides alternative text?

The alt attribute.

Q3. Why is alt text important?

It helps communicate image information to users who cannot perceive the image visually and supports accessible browsing.

Q4. What is an empty alt attribute?

An empty alt attribute is written as alt="". It indicates that an image is decorative and can be ignored by assistive technologies.

Q5. What is the difference between missing alt and empty alt?

Missing alt means the attribute is not provided. Empty alt explicitly indicates that the image does not need a text alternative because it is decorative.

Q6. What is a functional image?

A functional image performs an action or acts as a control, such as an image used as a link or button.

Q7. Should we use the title attribute instead of alt?

No. The title attribute does not replace the alt attribute.

Q8. What is WCAG?

WCAG stands for Web Content Accessibility Guidelines. It provides recommendations and testable success criteria for making web content accessible.

Q9. What is WCAG Success Criterion 1.1.1?

It is the Non-text Content criterion, which generally requires text alternatives for non-text content, subject to defined exceptions.

Q10. How should we provide alternatives for complex images?

Use concise alt text to identify the image and provide detailed information through nearby text, a description, or a data table.

13. Multiple Choice Questions (MCQs)

  1. title
  2. alt
  3. href
  4. src

Answer: B. alt

Q2. Which value is commonly used for a decorative image?

  1. alt="decoration"
  2. alt="none"
  3. alt=""
  4. alt="hidden"

Answer: C. alt=""

Q3. Which technology can read alternative text aloud?

  1. Compiler
  2. Screen reader
  3. Text editor
  4. Debugger

Answer: B. Screen reader

Q4. What should the alt text of a functional image communicate?

  1. Only its colour
  2. Its file size
  3. Its action or destination
  4. Its file extension

Answer: C. Its action or destination

Q5. Which attribute does not replace alt?

  1. src
  2. title

  1. Web Content Accessibility Guidelines

Answer: A. 1.1.1

  1. Use no alt text
  2. Put the entire report in alt
  3. Use concise alt and a detailed text equivalent

Q9. Which attribute is used to associate an image with a detailed description element?

  1. aria-describedby

14. Lesson Summary

  • Web accessibility makes websites usable by a wider range of people.
  • The alt attribute provides text alternatives for images.
  • Informative images need meaningful alternative text.
  • Decorative images should generally use alt="".
  • Functional images should communicate their action or destination.
  • Complex images may require a detailed text equivalent.
  • The title attribute is not a substitute for alt.
  • CSS background images do not have an alt attribute.
  • WCAG Success Criterion 1.1.1 addresses non-text content.
  • Screen reader testing helps evaluate image accessibility.
