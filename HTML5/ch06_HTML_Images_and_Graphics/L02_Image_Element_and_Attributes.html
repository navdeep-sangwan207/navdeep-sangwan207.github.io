Chapter 6: HTML Images and Graphics

1. Introduction

HTML provides the <img> element to embed images into a web page. It is one of the most commonly used elements in website development.

The image element uses attributes to specify the image source, alternative text, dimensions, loading behaviour, and other properties.

Basic syntax:

<img src="images/photo.jpg"
     alt="A photograph">
The <img> element is a void element. It does not have a closing tag and cannot contain child elements.

2. Understanding the img Element

The <img> element represents an image resource embedded in the current document.

Example

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Image Example</title>
</head>
<body>

    <h1>My First Image</h1>

    <img src="images/flower.jpg"
         alt="A red flower">

</body>
</html>

In this example, the browser attempts to load flower.jpg from the images folder.

3. The src Attribute

The src attribute specifies the URL of the image resource that the browser should load.

Syntax

<img src="image-file-path">

Example 1: Image from a Local Folder

<img src="images/logo.png"
     alt="Website logo">

Example 2: Image from a Parent Folder

<img src="../images/logo.png"
     alt="Website logo">

Example 3: Image from a Remote URL

<img src="https://example.com/images/photo.jpg"
     alt="Example photograph">
The path or URL must point to an accessible image resource. A wrong path, missing file, or inaccessible server can prevent the image from loading.

4. The alt Attribute

The alt attribute provides alternative text for an image. This text can be used when the image cannot be displayed and is important for users who access web pages using screen readers.

Example

<img src="images/computer.jpg"
     alt="Desktop computer on a table">

Why Is alt Important?

  • Supports accessibility for people using screen readers.
  • Provides a text alternative when an image cannot load.
  • Communicates the purpose or meaning of informative images.
  • Helps users understand the content without relying only on visuals.

Decorative Images

If an image is purely decorative and does not add meaningful information, an empty alternative text can be appropriate. 

<img src="images/decoration.png" alt="">
The detailed rules for writing alternative text, informative images, functional images, and decorative images are covered in Lesson 4: Alternative Text and Accessibility.

5. The width Attribute

The width attribute specifies the displayed width of an image in CSS pixels.

Example

<img src="images/flower.jpg"
     alt="A flower"
     width="300">

The browser uses the specified width to determine the displayed image width. If the height is not specified, the browser normally calculates it automatically to preserve the image's aspect ratio.

6. The height Attribute

The height attribute specifies the displayed height of an image in CSS pixels.

Example

<img src="images/flower.jpg"
     alt="A flower"
     height="200">

Using Both width and height

<img src="images/flower.jpg"
     alt="A flower"
     width="300"
     height="200">
Specifying width and height values with a different aspect ratio from the original image can distort it. Use dimensions that preserve the image's proportions unless distortion is intentional.

7. The title Attribute

The title attribute provides advisory information associated with an element. Browsers may display its value as a tooltip when a user points to the image.

Example

<img src="images/html-logo.png"
     alt="HTML logo"
     title="HTML technology logo">

The title attribute is optional. It should not replace meaningful alternative text because tooltips are not a reliable substitute for accessible image descriptions.

8. The loading Attribute

The loading attribute provides a browser hint about when an image should be loaded.

It commonly accepts the following values:

Value Meaning
eager Loads the image without intentionally deferring it.
lazy Allows the browser to defer loading until the image is near the viewport.

Example: Eager Loading

<img src="images/hero-banner.jpg"
     alt="Learning website banner"
     loading="eager">

Example: Lazy Loading

<img src="images/course-thumbnail.jpg"
     alt="Course thumbnail"
     loading="lazy">
Lazy loading can reduce unnecessary initial loading work for images that are not immediately visible. Avoid applying lazy loading to an important image that should appear immediately, such as a prominent above-the-fold hero image.

9. The decoding Attribute

The decoding attribute provides a hint to the browser about how an image should be decoded.

Value Meaning
sync Requests synchronous decoding.
async Requests asynchronous decoding.
auto Allows the browser to choose an appropriate strategy.

Example

<img src="images/diagram.png"
     alt="System architecture diagram"
     decoding="async">

The browser decides how to handle the decoding hint according to its implementation and rendering needs.

10. The fetchpriority Attribute

The fetchpriority attribute provides a relative priority hint for fetching an image resource.

Value Meaning
high Suggests higher fetch priority.
low Suggests lower fetch priority.
auto Lets the browser determine the priority.

Example

<img src="images/hero-banner.jpg"
     alt="Main website banner"
     fetchpriority="high">
Fetch priority is a hint, not a guarantee. Use high priority selectively for important images rather than assigning it to every image on the page.

11. The crossorigin Attribute

The crossorigin attribute controls how an image request handles cross-origin resource sharing (CORS).

Common values include:

Value Meaning
anonymous Uses a CORS request without cross-origin credentials.
use-credentials Uses a CORS request with credentials.

Example

<img
    src="https://example.com/image.png"
    alt="Remote image"
    crossorigin="anonymous"
>

The remote server must provide suitable CORS response headers when CORS access is required. This attribute is particularly relevant when image data needs to be accessed through technologies such as the HTML canvas.

12. The referrerpolicy Attribute

The referrerpolicy attribute specifies how much referrer information should be included when requesting an image.

Common Values

Value Description
no-referrer Does not send referrer information.
origin Sends only the origin of the referring page.
same-origin Sends referrer information for same-origin requests.
strict-origin Sends only the origin, subject to security restrictions.
strict-origin-when-cross-origin Sends full referrer information for same-origin requests and generally only the origin for cross-origin requests.

Example

<img
    src="https://example.com/photo.jpg"
    alt="Example photograph"
    referrerpolicy="no-referrer"
>

13. The usemap Attribute

The usemap attribute associates an image with a client-side image map. An image map allows different regions of an image to act as clickable areas.

Example

<img src="images/world-map.png"
     alt="World map"
     usemap="#worldmap">

<map name="worldmap">
    <area shape="rect"
          coords="20,20,120,100"
          href="asia.html"
          alt="Asia">
</map>

The image map uses a <map> element and one or more <area> elements to define interactive regions.

Image maps are covered in detail in Lesson 5: Image Maps.

14. The ismap Attribute

The ismap attribute indicates that an image is a server-side image map. It is used with an image inside a link.

Example

<a href="/image-map-handler">
    <img src="images/map.jpg"
         alt="Interactive map"
         ismap>
</a>

When the image is clicked, the browser can submit the clicked coordinates as part of the request to the linked resource. This technique is less common in modern web development.

15. The sizes and srcset Attributes

The srcset and sizes attributes allow browsers to select a suitable image resource based on available image candidates and display conditions.

srcset Attribute

The srcset attribute provides multiple image candidates, often with their intrinsic width descriptors. 

<img
    src="images/course-800.jpg"
    srcset="
        images/course-400.jpg 400w,
        images/course-800.jpg 800w,
        images/course-1200.jpg 1200w
    "
    alt="Online course illustration"
>

sizes Attribute

The sizes attribute describes the expected display width of the image under different media conditions. It helps the browser choose a suitable candidate from a width-descriptor srcset. 

<img
    src="images/course-800.jpg"
    srcset="
        images/course-400.jpg 400w,
        images/course-800.jpg 800w,
        images/course-1200.jpg 1200w
    "
    sizes="
        (max-width: 600px) 100vw,
        (max-width: 1000px) 50vw,
        400px
    "
    alt="Online course illustration"
>
Responsive image selection and the picture element are covered in detail in Lesson 7.

16. The Image Element Is a Void Element

A void element is an HTML element that cannot contain child content and does not have a closing tag.

The <img> element is a void element.

Correct Syntax

<img src="images/photo.jpg" alt="A photograph">

Self-Closing Style

<img src="images/photo.jpg" alt="A photograph" />

The trailing slash is optional in HTML. Both forms are valid.

Incorrect Syntax

<img src="images/photo.jpg">
    Some text
</img>
Do not write a closing </img> tag in HTML. The image element cannot wrap text or other HTML elements.

17. Combining Image Attributes

Multiple attributes can be used together in a single image element.

Example

<img
    src="images/html-course-banner.jpg"
    alt="HTML5 complete study course banner"
    width="800"
    height="300"
    title="HTML5 Course"
    loading="lazy"
    decoding="async"
>

This example combines:

  • src – Image location.
  • alt – Alternative text.
  • width – Displayed width.
  • height – Displayed height.
  • title – Advisory information.
  • loading – Loading behaviour hint.
  • decoding – Image decoding hint.

18. Complete Practical Example

Create a web page displaying a course banner and a course logo. Use multiple attributes to control the image elements.

Project Structure

image-attributes/
│
├── index.html
│
└── images/
    ├── course-banner.jpg
    └── html-logo.png

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Image Attributes Example</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            margin: 30px;
        }

        img {
            max-width: 100%;
            height: auto;
        }
    </style>
</head>

<body>

    <h1>Welcome to HTML5 Course</h1>

    <h2>Course Banner</h2>

    <img
        src="images/course-banner.jpg"
        alt="HTML5 course banner"
        width="800"
        height="300"
        loading="eager"
    >

    <h2>HTML Logo</h2>

    <img
        src="images/html-logo.png"
        alt="HTML technology logo"
        width="150"
        height="150"
        title="HTML Logo"
        loading="lazy"
        decoding="async"
    >

</body>
</html>

Expected Result

  • A heading displaying Welcome to HTML5 Course.
  • A course banner below the Course Banner heading.
  • An HTML logo below the HTML Logo heading.
  • The banner is requested with eager loading.
  • The logo uses lazy loading and asynchronous decoding hints.

The images will appear only if the corresponding files are present in the images folder with the specified names.

19. Common Mistakes

Mistake Correct Approach
Using a wrong image path Verify the file location and relative path.
Writing a closing img tag Remember that img is a void element.
Missing alt attribute Provide suitable alternative text.
Using incorrect dimensions Preserve the original aspect ratio.
Using lazy loading for every image Choose loading behaviour according to image position and importance.
Using title instead of alt Use alt for alternative text; title is optional advisory information.
Using high fetch priority everywhere Reserve high priority for important images.

21. Interview Questions and Answers

Q1. What is the img element?

The img element is an HTML element used to embed an image resource in a web page.

Q2. What is the purpose of the src attribute?

It specifies the URL or path of the image resource.

Q3. What is the purpose of the alt attribute?

It provides alternative text for an image, supporting accessibility and situations where the image cannot load.

Q4. Is img a paired element?

No. It is a void element and does not have a closing tag.

Q5. What do width and height attributes specify?

They specify the displayed width and height of the image in CSS pixels.

Q6. What is lazy loading?

Lazy loading allows the browser to defer loading an image until it is near the visible area of the page.

Q7. What is the difference between eager and lazy loading?

Eager loading does not intentionally defer loading, whereas lazy loading allows the browser to delay loading until needed.

Q8. What is the purpose of the title attribute?

It provides advisory information that browsers may display as a tooltip.

Q9. What is the purpose of srcset?

It provides multiple image resource candidates so the browser can select a suitable one.

Q10. What is the purpose of the decoding attribute?

It provides the browser with a hint about the image decoding strategy.

23. Lesson Summary

  • The <img> element embeds images in HTML.
  • src specifies the image resource location.
  • alt provides alternative text.
  • width and height specify image dimensions.
  • title provides optional advisory information.
  • loading controls the loading hint.
  • decoding provides an image decoding hint.
  • fetchpriority provides a fetch priority hint.
  • crossorigin controls CORS handling.
  • referrerpolicy controls referrer information.
  • usemap associates an image with a client-side image map.
  • srcset and sizes support responsive image selection.
  • The <img> element is a void element.
