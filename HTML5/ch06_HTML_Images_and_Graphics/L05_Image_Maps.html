Lesson 5: HTML Image Maps

HTML5 – Complete Study Course

1. Introduction to Image Maps

An image map is an image containing one or more clickable regions. Each region can link to a different webpage or resource.

Instead of making the entire image one hyperlink, an image map allows developers to define separate interactive areas within the same image.

Example: Imagine an image showing a computer. You can make the monitor, keyboard, and mouse separate clickable regions. Each region can open a different webpage.

Common applications

  • Clickable geographical maps.
  • Computer hardware diagrams.
  • Building floor plans.
  • Product diagrams.
  • Educational illustrations.
  • Interactive diagrams of electronic circuits.

2. HTML Elements Used in Image Maps

HTML image maps primarily use three elements:

Element Purpose
<img> Displays the image and connects it to an image map.
<map> Defines the image map and contains clickable areas.
<area> Defines an individual clickable region within the image.

Basic syntax

<img src="computer.jpg"
     alt="Computer hardware"
     usemap="#computer-map">

<map name="computer-map">
    <area shape="rect"
          coords="50,40,200,150"
          href="monitor.html"
          alt="Monitor">
</map>

The usemap attribute connects the image to the map using the map's name, prefixed with #.

3. The <map> Element

The <map> element defines a client-side image map. It contains one or more <area> elements.

Syntax

<map name="map-name">
    <area ...>
    <area ...>
</map>

Important attribute: name

The name attribute identifies the image map. Its value must match the value referenced by the image's usemap attribute. 

<img src="diagram.jpg"
     alt="Electronic components"
     usemap="#electronics">

<map name="electronics">
    ...
</map>
The value of usemap includes the # symbol, while the name attribute does not.

4. The <area> Element

The <area> element defines a clickable region inside an image map.

Important attributes

Attribute Purpose
shape Defines the shape of the clickable region.
coords Defines the coordinates of the region.
href Specifies the destination URL.
alt Provides alternative text for the area.
target Specifies where to open the linked resource.
download Suggests downloading the linked resource.

Example

<area
    shape="rect"
    coords="20,30,180,120"
    href="monitor.html"
    alt="Monitor">

5. Shapes Used in Image Maps

The shape attribute determines the geometry of the clickable region.

5.1 Rectangle – rect

A rectangular area is defined using four coordinates: left, top, right, and bottom. 

<area
    shape="rect"
    coords="50,40,200,150"
    href="monitor.html"
    alt="Monitor">

5.2 Circle – circle

A circular area is defined using three coordinates: center X, center Y, and radius. 

<area
    shape="circle"
    coords="150,120,50"
    href="mouse.html"
    alt="Computer mouse">

5.3 Polygon – poly

A polygon is defined using pairs of X and Y coordinates for its vertices. 

<area
    shape="poly"
    coords="50,50,150,30,200,100,100,150"
    href="keyboard.html"
    alt="Keyboard">

5.4 Default – default

The default shape represents the remaining image area that is not covered by other defined areas. 

<area
    shape="default"
    href="general.html"
    alt="General information">
Shape Coordinate format
rect x1, y1, x2, y2
circle center-x, center-y, radius
poly x1, y1, x2, y2, x3, y3, ...
default No coordinates required

6. Understanding Image Map Coordinates

Image map coordinates are measured in CSS-independent image coordinate units based on the image's intrinsic dimensions. The origin (0, 0) is at the top-left corner of the image.

  • X coordinates increase from left to right.
  • Y coordinates increase from top to bottom.
  • Coordinates are measured from the top-left origin.
Example: In a rectangular area, coords="50,40,200,150" means: left = 50, top = 40, right = 200, bottom = 150.

Coordinate diagram

(0,0) --------------------> X
  |
  |       (50,40) ----------- (200,40)
  |           |                    |
  |           |   Clickable        |
  |           |   Rectangle        |
  |           |                    |
  |       (50,150) ---------- (200,150)
  |
  |
  v
  Y

Important points

  • Coordinates should match the original image dimensions.
  • Incorrect coordinates can make clickable regions inaccurate.
  • Use an image editor or coordinate tool to identify positions.
  • Test the image map at different display sizes.
If an image is resized, image map coordinates do not automatically become a reliable proportional layout for the new dimensions. Responsive image maps may require a dedicated solution to scale their coordinates.

7. Complete Example: Computer Hardware Image Map

The following example creates three clickable regions: monitor, keyboard, and mouse. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Computer Image Map</title>
</head>
<body>

    <h1>Computer Hardware Image Map</h1>

    <p>Click a component in the image.</p>

    <img
        src="computer.jpg"
        alt="Computer showing monitor, keyboard and mouse"
        usemap="#computer-map"
        width="500"
        height="350">

    <map name="computer-map">

        <area
            shape="rect"
            coords="150,20,350,180"
            href="monitor.html"
            alt="Monitor">

        <area
            shape="rect"
            coords="100,230,400,300"
            href="keyboard.html"
            alt="Keyboard">

        <area
            shape="circle"
            coords="430,260,35"
            href="mouse.html"
            alt="Mouse">

    </map>

</body>
</html>

Expected Result

  • A computer image is displayed.
  • Clicking the monitor region opens monitor.html.
  • Clicking the keyboard region opens keyboard.html.
  • Clicking the mouse region opens mouse.html.
This example assumes that computer.jpg shows the components in positions matching the specified coordinates. You must adjust the coordinates for your actual image. The linked destination pages must also exist.

8. Responsive Image Maps

A responsive webpage adjusts its layout according to the available screen size. However, ordinary image map coordinates are based on the image's intrinsic dimensions.

If the image becomes smaller on a mobile screen, the clickable regions may no longer align correctly without additional handling.

Making the image responsive

<style>
img {
    max-width: 100%;
    height: auto;
}
</style>

This CSS makes the image itself responsive, but does not by itself guarantee that image map coordinates scale correctly.

Possible solutions

  • Use a responsive image-map library or coordinate-scaling script.
  • Test the image map at multiple viewport sizes.
  • Provide ordinary text links as an alternative.
  • Consider SVG for diagrams requiring scalable interactive regions.

9. Accessibility Considerations

Image maps must be usable by people who navigate using keyboards or assistive technologies.

Important practices

  • Provide meaningful alternative text for linked areas.
  • Make sure clickable areas are keyboard accessible.
  • Use descriptive link destinations.
  • Provide a separate list of text links when appropriate.
  • Do not communicate information through colour alone.
  • Test the image map with a screen reader.
An image map should not be the only way to access important information. Providing equivalent text links can improve usability and accessibility.

10. HTML Image Map vs. Normal Hyperlink

Normal Hyperlink Image Map
Usually makes a text or image link clickable. Allows multiple separate regions of one image to be clickable.
Uses the anchor element. Uses img, map, and area elements.
Does not require image coordinates. Uses coordinates to define clickable regions.
Suitable for ordinary navigation. Suitable for diagrams, maps, and interactive illustrations.

11. Common Mistakes

Mistake Correction
Missing # in usemap Use usemap="#computer-map".
Different map name and usemap value Match both names exactly.
Incorrect coordinates Measure coordinates against the original image dimensions.
Missing alt on linked areas Provide meaningful alternative text.
Assuming responsive images automatically scale map areas Use coordinate scaling or another suitable approach.
Using unavailable destination pages Create the destination pages or use valid URLs.

13. Interview Questions and Answers

Q1. What is an image map in HTML?

An image map is an image containing multiple clickable regions, each of which can have a different destination.

Q2. Which elements are used to create an image map?

The img, map, and area elements.

Q3. What is the purpose of the map element?

It defines the image map and contains the clickable area elements.

Q4. What is the purpose of the area element?

It defines an individual clickable region within an image map.

Q5. What is the usemap attribute?

It connects an image to a map element using the map's name, preceded by the # symbol.

Q6. Which shapes are supported by the area element?

Rectangle (rect), circle (circle), polygon (poly), and default.

Q7. What does the coords attribute specify?

It specifies the coordinates that define the clickable region.

Q8. How are coordinates measured?

They are measured from the top-left corner of the image, using X and Y coordinate values.

Q9. What is a client-side image map?

It is an image map whose clickable regions are defined in HTML and processed by the browser.

Q10. Do image map coordinates automatically scale when an image is resized?

No. Additional handling is generally required to keep the clickable regions aligned with a resized image.
