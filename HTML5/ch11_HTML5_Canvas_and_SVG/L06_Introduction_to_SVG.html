Lesson 6: Introduction to SVG

Chapter 11: HTML5 Canvas and SVG

Understand vector graphics, SVG structure, its features, and how to create scalable graphics in HTML5.

1. What is SVG?

SVG stands for Scalable Vector Graphics. It is an XML-based markup language used to describe two-dimensional vector graphics.

SVG defines graphical objects such as circles, rectangles, lines, paths, polygons, and text using XML elements and attributes.

SVG graphics can be displayed directly inside an HTML document using the <svg> element.

Examples of SVG graphics include:

  • Logos and icons.
  • Diagrams and technical illustrations.
  • Charts and graphs.
  • Maps and visualizations.
  • Scalable user interface graphics.
  • Animated vector illustrations.
Important: SVG is a vector graphics format. It describes shapes mathematically rather than storing the image as a fixed grid of colored pixels.

2. Understanding Vector Graphics

Vector graphics represent images using mathematical descriptions of geometric objects such as points, lines, curves, and shapes.

These descriptions allow the graphics to be scaled without the pixelation normally associated with enlarging raster images.

2.1 Vector Graphics

  • Represent shapes using geometric descriptions.
  • Can be enlarged or reduced without losing geometric clarity.
  • Often suitable for logos, icons, and diagrams.
  • Individual shapes can be styled and manipulated.

2.2 Raster Graphics

  • Represent images using a grid of pixels.
  • Have fixed pixel dimensions.
  • Enlarging them significantly may reveal pixelation.
  • Common formats include JPEG, PNG, GIF, and WebP.
Feature Vector Graphics Raster Graphics
Representation Mathematical shapes and paths Pixels
Scaling Maintains geometric clarity May become pixelated
Typical use Logos, icons, diagrams Photographs and detailed images
Editing Individual objects can be manipulated Usually involves editing pixel data
Examples SVG JPEG, PNG, GIF, WebP

3. History and Development of SVG

SVG was developed as an open standard for vector graphics on the web.

  • 1999: SVG 1.0 became a W3C Recommendation.
  • 2001: SVG 1.1 became a W3C Recommendation.
  • 2011: SVG 1.1 Second Edition was published.
  • 2018: SVG 2 became a W3C Candidate Recommendation.

SVG is maintained as a web graphics standard through ongoing specifications and browser implementations.

SVG 1.1 is a widely established version. SVG 2 develops the language further and aligns more closely with modern web platform behavior.

4. Features of SVG

4.1 Scalability

SVG graphics can be enlarged or reduced while retaining their geometric clarity.

4.2 Resolution Independence

SVG graphics are not tied to a fixed pixel grid in the same way as ordinary raster images.

4.3 XML-Based Structure

SVG uses XML syntax, which makes its graphical elements structured and readable.

4.4 CSS Styling

SVG elements can be styled using CSS properties such as fill, stroke, opacity, and other presentation properties.

4.5 JavaScript Interaction

SVG elements embedded in an HTML document can be accessed and manipulated through JavaScript and the DOM.

4.6 Animation

SVG graphics can be animated using CSS, JavaScript, and supported SVG animation features.

4.7 Accessibility and Searchability

SVG can contain text and descriptive metadata. When appropriately authored, its structure can help assistive technologies understand graphical content.

5. Basic Structure of an SVG Document

An SVG document normally begins with an XML declaration when stored as a standalone XML file. The main graphical content is enclosed inside the SVG root element.

Basic SVG Example

<svg xmlns="http://www.w3.org/2000/svg" width="300" height="200"> <rect x="30" y="30" width="200" height="100" fill="blue" /> </svg>

Explanation:

  • <svg> defines the SVG drawing area.
  • xmlns identifies the SVG XML namespace.
  • width specifies the viewport width.
  • height specifies the viewport height.
  • <rect> defines a rectangle.
  • fill specifies the rectangle's fill color.
Expected Result:

A blue rectangle appears inside an SVG drawing area with dimensions 300 × 200.

6. The SVG Element

The <svg> element is the root container for SVG graphics. It defines a viewport in which graphical objects are displayed.

Common SVG Attributes

Attribute Purpose
xmlns Identifies the SVG namespace.
width Defines the viewport width.
height Defines the viewport height.
viewBox Defines the internal SVG coordinate system.
preserveAspectRatio Controls how the viewBox fits into the viewport.
id Identifies the SVG element.
class Assigns one or more CSS classes.

Example

<svg width="400" height="250" viewBox="0 0 400 250" xmlns="http://www.w3.org/2000/svg"> <circle cx="200" cy="125" r="70" fill="orange" /> </svg>
Expected Result:

An orange circle appears at the center of the SVG drawing area.

7. Understanding the SVG Coordinate System

SVG uses a two-dimensional coordinate system. By default, the origin (0, 0) is located at the top-left corner of the SVG viewport.

  • X coordinates increase from left to right.
  • Y coordinates increase from top to bottom.
  • Coordinates describe positions within the SVG user space.
  • Shape dimensions are expressed using the same coordinate system.

Example

<svg width="300" height="200" xmlns="http://www.w3.org/2000/svg"> <circle cx="50" cy="50" r="20" fill="red" /> <circle cx="150" cy="100" r="20" fill="blue" /> <circle cx="250" cy="150" r="20" fill="green" /> </svg>
Expected Result:

Three circles appear at different positions: red at (50, 50), blue at (150, 100), and green at (250, 150).

8. Understanding viewBox

The viewBox attribute defines the coordinate system and visible region of an SVG drawing.

Syntax:

viewBox="min-x min-y width height"

Example:

<svg width="400" height="200" viewBox="0 0 200 100" xmlns="http://www.w3.org/2000/svg"> <rect x="10" y="10" width="180" height="80" fill="blue" /> </svg>

Explanation:

  • Minimum X coordinate is 0.
  • Minimum Y coordinate is 0.
  • ViewBox width is 200 units.
  • ViewBox height is 100 units.
  • Viewport width is 400 CSS pixels.
  • Viewport height is 200 CSS pixels.
Expected Result:

A blue rectangle fills most of the SVG viewport. The internal 200 × 100 coordinate system is displayed in a 400 × 200 viewport.

Important: viewBox does not directly set the physical display size. It defines the SVG user-space rectangle that is mapped into the viewport.

9. Adding SVG to HTML5

SVG can be included in an HTML document in several ways. Inline SVG is especially useful when individual graphical elements need to be styled or controlled with JavaScript.

9.1 Inline SVG

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Inline SVG</title> </head> <body> <h2>My First SVG Graphic</h2> <svg width="300" height="200" xmlns="http://www.w3.org/2000/svg"> <rect x="30" y="30" width="200" height="100" fill="blue" /> </svg> </body> </html>

9.2 External SVG Using img

A separately stored SVG file can be displayed using the HTML <img> element.

<img src="images/logo.svg" alt="Company logo" width="200">

9.3 External SVG Using Object

<object data="images/diagram.svg" type="image/svg+xml" width="400" height="300"> SVG image cannot be displayed. </object>

9.4 External SVG Using CSS Background

<div class="logo"></div> <style> .logo { width: 200px; height: 100px; background-image: url("images/logo.svg"); background-repeat: no-repeat; background-size: contain; } </style>
Inline SVG provides direct DOM access to its elements. An SVG loaded through img or CSS background is generally treated as an image rather than as part of the HTML DOM.

10. Styling SVG Graphics

SVG elements can use presentation attributes or CSS properties to control their appearance.

10.1 fill

Sets the interior paint of a shape.

<circle cx="100" cy="100" r="50" fill="green" />

10.2 stroke

Sets the outline paint of a shape.

<rect x="30" y="30" width="150" height="80" stroke="red" fill="none" />

10.3 stroke-width

Sets the thickness of the outline.

<circle cx="100" cy="100" r="50" fill="yellow" stroke="blue" stroke-width="5" />

10.4 opacity

Controls the transparency of an SVG element.

<rect x="30" y="30" width="150" height="80" fill="blue" opacity="0.5" />

11. Advantages of SVG

  • Graphics remain clear when scaled.
  • Suitable for responsive web design.
  • Supports individual graphical elements.
  • Can be styled using CSS.
  • Can be manipulated using JavaScript when inline.
  • Supports paths, text, gradients, and patterns.
  • Can be animated.
  • Often efficient for simple icons and diagrams.
  • SVG source is text-based and can be inspected or edited.

12. Limitations of SVG

  • Very complex vector scenes may require significant rendering work.
  • SVG is not generally the best format for photographic images.
  • Detailed SVG files can become large and difficult to maintain.
  • Untrusted SVG files can introduce security risks in certain embedding contexts.
  • Complex SVG accessibility requires appropriate structure and descriptions.

13. SVG Applications

  • Website logos and icons.
  • Technical diagrams and engineering drawings.
  • Interactive maps.
  • Data visualization and charts.
  • Infographics.
  • Responsive illustrations.
  • Animated user interface elements.
  • Scalable diagrams for educational platforms.

14. SVG vs Canvas: Basic Introduction

SVG and Canvas are two important technologies for displaying graphics in HTML5.

Feature SVG Canvas
Type Vector graphics Bitmap-based drawing surface
Structure XML-based elements Pixel drawing buffer
Drawing Elements and attributes JavaScript drawing commands
DOM access Individual inline SVG elements Drawn shapes are not separate DOM elements
Scaling Retains vector clarity May require redrawing at a new resolution
Interaction Individual elements can receive events Usually handled through coordinate calculations
Typical use Icons, diagrams, charts Games, pixel-based graphics, image processing

A detailed comparison of SVG and Canvas will be covered in Lesson 8.

15. Common SVG Mistakes

  • Missing namespace: Standalone SVG documents should declare the SVG namespace.
  • Incorrect coordinates: Shapes may appear outside the visible SVG viewport.
  • Incorrect viewBox: The visible region or scaling may not match expectations.
  • Incorrect element nesting: SVG uses XML-style element structure and requires proper nesting.
  • Incorrect attribute names: SVG attribute names and values must follow the relevant specification.
  • Confusing SVG with raster graphics: SVG describes vector shapes rather than a fixed pixel grid.

18. Interview Questions and Answers

Q1. What is SVG?
SVG stands for Scalable Vector Graphics. It is an XML-based language for describing two-dimensional graphics.
Q2. Is SVG a vector or raster format?
SVG is a vector graphics format.
Q3. What is the purpose of the svg element?
It defines the SVG drawing container and viewport.
Q4. What is the SVG namespace?
It identifies SVG elements within XML-based documents. Its namespace URI is http://www.w3.org/2000/svg.
Q5. What is viewBox?
It defines the internal coordinate rectangle that is mapped into the SVG viewport.
Q6. Can SVG be styled using CSS?
Yes. SVG supports CSS styling of its graphical elements.
Q7. Can JavaScript manipulate SVG?
Yes. Inline SVG elements can be accessed and manipulated through the DOM.
Q8. How can an external SVG file be included in HTML?
It can be included using elements such as img and object, or through CSS backgrounds.
Q9. What are common applications of SVG?
Logos, icons, diagrams, charts, maps, and illustrations.
Q10. What is one important difference between SVG and Canvas?
SVG represents individual graphical objects as elements, while Canvas drawing operations render into a bitmap surface.
