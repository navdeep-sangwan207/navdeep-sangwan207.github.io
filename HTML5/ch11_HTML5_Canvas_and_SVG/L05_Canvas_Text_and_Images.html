Lesson 5: Canvas Text and Images

Chapter 11: HTML5 Canvas and SVG

Learn how to display, format, measure, and position text and images using the Canvas 2D API.

1. Introduction to Canvas Text and Images

The HTML5 Canvas 2D API supports drawing text and images directly onto the Canvas bitmap. JavaScript controls the content, position, size, alignment, and appearance of these objects.

Canvas can be used to display:

  • Headings and labels.
  • Text with different fonts and sizes.
  • Colored and outlined text.
  • Images and photographs.
  • Scaled and cropped images.
  • Text and images combined in graphical applications.

The main methods used for these operations are fillText(), strokeText(), measureText(), and drawImage().

2. Drawing Text on Canvas

Canvas provides two primary methods for displaying text: fillText() and strokeText().

2.1 fillText()

The fillText() method draws filled text at a specified coordinate.

Syntax:

ctx.fillText(text, x, y, maxWidth);

Parameters:

  • text: The string to display.
  • x: Horizontal position.
  • y: Vertical position.
  • maxWidth: Optional maximum text width.

Example:

ctx.font = "30px Arial"; ctx.fillStyle = "blue"; ctx.fillText("Hello HTML5", 50, 80);
Expected Result:

Blue text displaying "Hello HTML5" appears at coordinate (50, 80).

2.2 strokeText()

The strokeText() method draws the outline of text without filling its interior.

Syntax:

ctx.strokeText(text, x, y, maxWidth);

Example:

ctx.font = "40px Arial"; ctx.strokeStyle = "red"; ctx.lineWidth = 2; ctx.strokeText("Canvas", 50, 100);
Expected Result:

The word Canvas appears with a red outline.

2.3 Drawing Filled and Outlined Text Together

ctx.font = "40px Arial"; ctx.fillStyle = "blue"; ctx.fillText("HTML5", 50, 80); ctx.strokeStyle = "red"; ctx.lineWidth = 1; ctx.strokeText("HTML5", 50, 150);
Expected Result:

The first word is filled blue, and the second word has a red outline.

3. Font Properties

The font property controls the font used when drawing Canvas text. Its value follows CSS font shorthand syntax.

3.1 Setting Font Size and Family

ctx.font = "24px Arial"; ctx.fillText("Canvas Text", 30, 60);

3.2 Setting Font Weight

ctx.font = "bold 30px Arial"; ctx.fillText("Bold Text", 30, 100);

3.3 Setting Font Style

ctx.font = "italic 28px Georgia"; ctx.fillText("Italic Text", 30, 150);

3.4 Different Font Examples

ctx.font = "20px Arial"; ctx.fillText("Arial Font", 30, 40); ctx.font = "bold 24px Verdana"; ctx.fillText("Verdana Font", 30, 90); ctx.font = "italic 28px Georgia"; ctx.fillText("Georgia Font", 30, 140);
Important: The font property accepts CSS font shorthand values. A font size must be specified. If the requested font is unavailable, the browser uses an appropriate fallback font.

4. Text Alignment and Baseline

4.1 textAlign

The textAlign property determines how text is horizontally aligned relative to the specified x-coordinate.

Common values:

  • left – Aligns text to the left.
  • right – Aligns text to the right.
  • center – Centers text around the x-coordinate.
  • start – Aligns according to text direction.
  • end – Aligns according to text direction.
ctx.font = "24px Arial"; ctx.textAlign = "left"; ctx.fillText("Left Aligned", 250, 50); ctx.textAlign = "center"; ctx.fillText("Center Aligned", 250, 100); ctx.textAlign = "right"; ctx.fillText("Right Aligned", 250, 150);

4.2 textBaseline

The textBaseline property controls the vertical alignment of text relative to the y-coordinate.

Common values include:

  • top
  • hanging
  • middle
  • alphabetic
  • ideographic
  • bottom
ctx.font = "25px Arial"; ctx.textBaseline = "middle"; ctx.fillText("Middle Baseline", 50, 100);
Remember: The default textAlign value is "start", and the default textBaseline value is "alphabetic". The y-coordinate normally refers to the text baseline, not the top edge of the text.

5. Measuring Text

The measureText() method measures the dimensions of a text string using the current Canvas font settings.

Syntax:

const metrics = ctx.measureText(text);

It returns a TextMetrics object containing information about the text, including its width.

Example

ctx.font = "30px Arial"; const text = "HTML5 Canvas"; const metrics = ctx.measureText(text); console.log("Text Width:", metrics.width); ctx.fillText(text, 30, 80);
Expected Result:

The text is displayed on Canvas, and its measured width is printed in the browser developer console.

Applications of measureText()

  • Centering text inside a Canvas.
  • Checking whether text fits inside a specified area.
  • Calculating label positions.
  • Creating graphical dashboards.
  • Positioning text dynamically.

Example: Centering Text

const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d"); const text = "Welcome"; ctx.font = "30px Arial"; ctx.textAlign = "center"; ctx.fillStyle = "blue"; ctx.fillText(text, canvas.width / 2, 100);
Expected Result:

The word Welcome is horizontally centered in the Canvas.

6. Introduction to Drawing Images

The Canvas 2D API uses the drawImage() method to display image content inside a Canvas.

The image must be available as a supported image source. Examples include:

  • HTMLImageElement created using an img element.
  • HTMLVideoElement containing video frames.
  • HTMLCanvasElement containing another Canvas image.
  • ImageBitmap objects.
  • Other supported image sources.

For ordinary web pages, images are commonly loaded using the JavaScript Image object.

7. Loading an Image Using JavaScript

The Image constructor creates a new HTML image object. Its src property specifies the image URL.

Example

const img = new Image(); img.src = "images/photo.jpg"; img.onload = function() { ctx.drawImage(img, 30, 30); };

Explanation:

  1. Creates an image object.
  2. Assigns an image file path to its src property.
  3. Waits for the image to load.
  4. Draws the loaded image using drawImage().
Important: Do not assume an image has loaded immediately after assigning its src. Use the load event before drawing it. Handle the error event to detect failed image loading.

8. drawImage() Method

The drawImage() method draws an image source onto the Canvas.

It supports three commonly used forms.

8.1 Drawing an Image at a Position

Syntax:

ctx.drawImage(image, dx, dy);

This form draws the image at the specified destination coordinates using its intrinsic dimensions.

Example:

const img = new Image(); img.onload = function() { ctx.drawImage(img, 50, 50); }; img.src = "images/photo.jpg";

8.2 Drawing an Image with Resizing

Syntax:

ctx.drawImage(image, dx, dy, dWidth, dHeight);

Parameters:

  • image: Source image.
  • dx: Destination x-coordinate.
  • dy: Destination y-coordinate.
  • dWidth: Destination width.
  • dHeight: Destination height.

Example:

const img = new Image(); img.onload = function() { ctx.drawImage(img, 50, 50, 200, 120); }; img.src = "images/photo.jpg";
Expected Result:

The image is drawn at position (50, 50) with a displayed width of 200 pixels and height of 120 pixels.

8.3 Drawing a Cropped Image

The nine-argument form allows a selected source region to be copied and drawn at a destination position.

Syntax:

ctx.drawImage( image, sx, sy, sWidth, sHeight, dx, dy, dWidth, dHeight );

Parameters:

  • sx, sy: Source region starting coordinates.
  • sWidth, sHeight: Source region dimensions.
  • dx, dy: Destination starting coordinates.
  • dWidth, dHeight: Destination dimensions.

Example:

const img = new Image(); img.onload = function() { ctx.drawImage( img, 50, 50, 150, 100, 200, 50, 150, 100 ); }; img.src = "images/photo.jpg";
Expected Result:

A selected 150 × 100 pixel region from the source image is drawn at destination position (200, 50).

Remember: The first five arguments after the image in the nine-argument form describe the source crop region and the remaining four describe its destination.

9. Complete Program: Drawing Text and an Image

Create a folder named canvas-text-image. Save the following HTML file inside it and create an images folder containing a picture named photo.jpg.

Folder structure:

canvas-text-image/ │ ├── index.html │ └── images/ └── photo.jpg

Complete HTML Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Canvas Text and Images</title> </head> <body> <h2>Canvas Text and Images</h2> <canvas id="myCanvas" width="500" height="400" style="border:1px solid black;"> Canvas is not supported. </canvas> <script> const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d"); // Draw heading ctx.font = "bold 28px Arial"; ctx.fillStyle = "blue"; ctx.textAlign = "center"; ctx.fillText( "Welcome to HTML5", canvas.width / 2, 45 ); // Draw subtitle ctx.font = "18px Arial"; ctx.fillStyle = "green"; ctx.fillText( "Canvas Text and Images", canvas.width / 2, 80 ); // Load image const img = new Image(); img.onload = function() { ctx.drawImage( img, 100, 110, 300, 200 ); // Draw image border ctx.strokeStyle = "red"; ctx.lineWidth = 3; ctx.strokeRect( 100, 110, 300, 200 ); }; img.onerror = function() { ctx.fillStyle = "red"; ctx.textAlign = "center"; ctx.fillText( "Image could not be loaded", canvas.width / 2, 180 ); }; img.src = "images/photo.jpg"; </script> </body> </html>

Program Explanation

  1. Creates a Canvas with dimensions 500 × 400.
  2. Sets the font, font size, and text color.
  3. Displays a centered heading and subtitle.
  4. Creates an image object.
  5. Loads the image from the images folder.
  6. Draws the image after successful loading.
  7. Draws a red border around the image.
  8. Displays an error message if the image fails to load.
Expected Result:

A Canvas displays a blue heading, green subtitle, and a photograph with a red border.

11. Applications of Canvas Text and Images

  • Graphical dashboards and monitoring systems.
  • Image editing applications.
  • Data visualization and chart labels.
  • Browser-based drawing applications.
  • Games and interactive graphics.
  • Image cropping and resizing tools.
  • Digital signatures and annotation tools.
  • Graphical user interfaces rendered on Canvas.

12. Common Mistakes

  • Drawing before image loading: Use the image load event before calling drawImage().
  • Incorrect image path: Check the filename, extension, and relative folder path.
  • Incorrect text position: Remember that the y-coordinate normally refers to the baseline.
  • Incorrect font syntax: Use valid CSS font shorthand values.
  • Incorrect drawImage() arguments: Distinguish between source coordinates and destination coordinates.
  • Ignoring image loading errors: Use an error handler when loading external images.

13. Canvas Accessibility Considerations

Text and images drawn onto Canvas become part of its bitmap. They do not automatically become individual HTML text or image elements in the DOM.

  • Provide meaningful fallback content inside the Canvas element.
  • Provide equivalent information outside Canvas when needed.
  • Use semantic HTML for important text and controls.
  • Do not rely only on color to communicate information.
  • Provide keyboard-accessible alternatives for interactive graphics.
Canvas is suitable for graphical rendering, but important information should also be available through accessible HTML content where appropriate.

16. Interview Questions and Answers

Q1. Which method displays filled text on Canvas?
fillText().
Q2. Which method draws outlined text?
strokeText().
Q3. What is the purpose of measureText()?
It measures a text string and returns a TextMetrics object.
Q4. Which property controls the font?
The font property.
Q5. What is the purpose of textAlign?
It controls horizontal text alignment relative to the x-coordinate.
Q6. Which method draws images on Canvas?
drawImage().
Q7. What does the Image constructor do?
It creates a new HTML image object that can be used as an image source.
Q8. Why is the image load event important?
It ensures that the image has loaded before drawing it onto Canvas.

Use the five-argument form with destination width and height.

Use the nine-argument form of drawImage() to specify the source crop region and destination dimensions.
