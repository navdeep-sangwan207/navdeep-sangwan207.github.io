Chapter 11: HTML5 Canvas and SVG

Learn how to create graphics using the HTML Canvas element and JavaScript.

1. Introduction to Canvas

HTML Canvas is a drawing surface provided by the HTML <canvas> element. It allows developers to generate graphics dynamically inside a web page.

Canvas does not automatically draw shapes or images. It provides a rectangular area on which JavaScript drawing commands render graphical content.

Developers can use Canvas to draw rectangles, lines, circles, paths, text, and images. It can also be used to create animations, charts, games, and interactive visual applications.

Important: Canvas is a drawing surface, not a drawing language. JavaScript is commonly used to perform the drawing operations.

2. What is the Canvas Element?

The <canvas> element defines a rectangular drawing area in an HTML document.

Basic syntax:

<canvas id="myCanvas" width="400" height="200"> Your browser does not support Canvas. </canvas>

Explanation:

  • canvas: Defines the drawing area.
  • id: Identifies the element for JavaScript access.
  • width: Defines the drawing buffer width.
  • height: Defines the drawing buffer height.
  • Fallback content: Provides alternative content when Canvas is unsupported.
Canvas width and height attributes define the internal drawing dimensions. CSS can change the displayed size, but scaling the element with CSS alone may stretch the rendered image.

3. How Canvas Works

The basic Canvas drawing process involves the following steps:

  1. Create a Canvas element in HTML.
  2. Assign an ID to identify the Canvas.
  3. Access the Canvas element using JavaScript.
  4. Obtain a rendering context.
  5. Set drawing properties such as color and line width.
  6. Execute drawing methods.
  7. Display the rendered graphics in the browser.

Canvas Working Flow

HTML Canvas Element | v JavaScript Access | v Get Rendering Context | v Set Drawing Properties | v Execute Drawing Commands | v Rendered Graphics

4. Canvas Rendering Context

A rendering context provides the methods and properties required to draw on a Canvas.

JavaScript accesses the rendering context using the getContext() method.

4.1 Two-Dimensional Context

The 2D context is commonly used for drawing two-dimensional graphics such as rectangles, lines, circles, text, and images.

const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d");

Here:

  • getElementById() selects the Canvas element.
  • getContext("2d") requests its 2D rendering context.
  • ctx stores the returned context object.

4.2 WebGL Context

WebGL is a separate graphics API available through Canvas. It is used to render interactive 2D and 3D graphics using GPU-accelerated techniques.

Context Purpose
2d Two-dimensional drawing operations.
webgl 3D and GPU-accelerated graphics using WebGL 1.
webgl2 Advanced graphics features provided by WebGL 2.
Note: This chapter focuses primarily on the Canvas 2D context. WebGL is a separate graphics topic.

5. Canvas Coordinate System

Canvas uses a two-dimensional coordinate system to identify positions inside its drawing area.

  • The origin (0, 0) is at the top-left corner.
  • The X-axis increases towards the right.
  • The Y-axis increases downwards.
  • Coordinates are measured in Canvas coordinate units, normally corresponding to CSS pixels when using the default bitmap scaling.

Example

ctx.fillRect(50, 30, 120, 60);

Parameters:

  • 50: X-coordinate of the rectangle's top-left corner.
  • 30: Y-coordinate of the rectangle's top-left corner.
  • 120: Rectangle width.
  • 60: Rectangle height.
The coordinate system is important for positioning shapes, images, text, and other graphical objects accurately.

6. First Canvas Program

The following complete HTML program creates a Canvas and draws a blue rectangle using JavaScript.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My First Canvas Program</title> </head> <body> <h2>My First Canvas Drawing</h2> <canvas id="myCanvas" width="400" height="200"> Your browser does not support Canvas. </canvas> <script> const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d"); ctx.fillStyle = "blue"; ctx.fillRect(50, 40, 200, 100); </script> </body> </html>

Program Explanation

  1. The HTML code creates a Canvas with dimensions 400 × 200.
  2. JavaScript selects the Canvas using its ID.
  3. getContext("2d") obtains the 2D context.
  4. fillStyle sets the fill color to blue.
  5. fillRect() draws the filled rectangle.
Expected Result:

A blue rectangle measuring 200 × 100 coordinate units appears at position (50, 40) inside the Canvas.

7. Canvas Drawing Methods: Introduction

The Canvas 2D context provides several methods for drawing graphical objects.

Method / Property Purpose
fillRect() Draws a filled rectangle.
strokeRect() Draws the outline of a rectangle.
clearRect() Clears a rectangular area.
beginPath() Starts a new path.
moveTo() Moves the current path position.
lineTo() Adds a straight line segment.
arc() Adds a circular or elliptical arc.
fill() Fills the current path.
stroke() Draws the outline of the current path.
fillText() Draws filled text.
drawImage() Draws an image on the Canvas.

These methods will be studied in detail in the following lessons.

8. Canvas vs Normal HTML Elements

Feature Canvas Normal HTML Elements
Purpose Graphics rendering Document structure and content
Drawing Performed through drawing commands Elements are laid out by the browser
JavaScript Used for drawing and interaction Can modify elements and content
Individual objects Usually not separate DOM elements Each element has its own DOM representation
Accessibility Requires suitable fallback and accessible alternatives Native semantic elements provide built-in accessibility features
Canvas drawings are generally rendered as pixels in a bitmap. Individual drawn shapes do not automatically become separate HTML DOM elements.

9. Advantages of Canvas

  • Supports dynamic graphics using JavaScript.
  • Suitable for drawing large numbers of graphical objects.
  • Useful for games and animations.
  • Supports text, images, paths, and shapes.
  • Works directly within modern web browsers.
  • Provides a flexible drawing API.

10. Limitations of Canvas

  • Individual drawing objects are not automatically represented as DOM elements.
  • Interaction with individual shapes requires coordinate calculations and custom event handling.
  • Accessibility requires additional design and alternative content.
  • Graphics generally need to be redrawn when their appearance changes.
  • Large or complex drawing operations can affect performance if not managed properly.

11. Applications of Canvas

  • Browser-based games.
  • Interactive drawing applications.
  • Data visualization and charts.
  • Image processing tools.
  • Animation systems.
  • Simulation and graphical demonstrations.
  • Real-time graphical dashboards.

  • Canvas is an HTML element that provides a drawing surface.

  • The getContext() method obtains a rendering context.
  • The 2D context is used for two-dimensional drawing.
  • WebGL and WebGL2 provide graphics APIs for more advanced rendering.
  • The Canvas origin is located at the top-left corner.
  • The X-axis increases rightwards and the Y-axis downwards.
  • Canvas drawings are generally bitmap-based.
  • Canvas is useful for games, charts, animations, and interactive applications.

14. Interview Questions and Answers

Q1. What is HTML5 Canvas?
Canvas is an HTML element that provides a drawing surface for generating graphics through JavaScript.
Q2. Which JavaScript method obtains a Canvas rendering context?
The getContext() method obtains the requested rendering context.
Q3. What does getContext("2d") return?
It returns the CanvasRenderingContext2D object when the 2D context is available.
Q4. Where is the origin of the Canvas coordinate system?
The origin (0, 0) is at the top-left corner of the Canvas.
Q5. What is the purpose of fillRect()?
fillRect() draws a filled rectangle using the current fill style.
Q6. What is the difference between fillRect() and strokeRect()?
fillRect() draws a filled rectangle, whereas strokeRect() draws only its outline.
Q7. Does Canvas automatically create DOM elements for drawn shapes?
No. Drawn shapes are rendered into the Canvas bitmap and are not automatically represented as separate DOM elements.
Q8. What is WebGL?
WebGL is a JavaScript graphics API that enables interactive 2D and 3D rendering using GPU-accelerated techniques.
Q9. What is the purpose of Canvas fallback content?
It provides alternative content when the browser does not support the Canvas element.
Q10. Mention two applications of Canvas.
Browser-based games and interactive charts are two common applications.
