Chapter Overview

HTML5 provides powerful technologies for creating graphics directly inside web pages. The Canvas element provides a drawing surface that can be controlled using JavaScript, while SVG (Scalable Vector Graphics) allows graphics to be defined using XML-based markup.

In this chapter, you will learn the fundamentals of HTML5 graphics, the Canvas element, drawing shapes, displaying text and images, SVG graphics, SVG shapes, and the differences between Canvas and SVG.

Learning Objectives

  • Understand the fundamentals of graphics in HTML5.
  • Understand the purpose and working of the Canvas element.
  • Learn Canvas attributes and drawing contexts.
  • Draw basic shapes using Canvas and JavaScript.
  • Display text and images on a Canvas.
  • Understand SVG and its role in web graphics.
  • Create SVG shapes using different attributes.
  • Compare Canvas and SVG and identify their applications.
