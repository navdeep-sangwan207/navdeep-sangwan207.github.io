Lesson 3: Canvas Element and Attributes

Chapter 11: HTML5 Canvas and SVG

Understand the Canvas element, its dimensions, attributes, fallback content, and JavaScript integration.

1. Introduction to the Canvas Element

The HTML <canvas> element provides a rectangular drawing area inside a web page. JavaScript is commonly used to create graphics within this area.

Canvas can display rectangles, lines, circles, paths, text, images, and animations. It is commonly used in games, charts, simulations, and interactive applications.

Basic syntax:

<canvas id="myCanvas" width="500" height="300"> Your browser does not support Canvas. </canvas>

The Canvas element itself creates the drawing surface. Actual graphical content is rendered using a drawing context.

2. Canvas Attributes

The Canvas element supports standard HTML global attributes and two important dimension attributes: width and height.

2.1 Width Attribute

The width attribute specifies the width of the Canvas drawing buffer.

<canvas id="myCanvas" width="400"> </canvas>

The drawing buffer is 400 coordinate units wide.

2.2 Height Attribute

The height attribute specifies the height of the Canvas drawing buffer.

<canvas id="myCanvas" height="200"> </canvas>

The drawing buffer is 200 coordinate units high.

2.3 Using Width and Height Together

<canvas id="myCanvas" width="500" height="300"> Canvas is not supported. </canvas>

This creates a drawing buffer with a width of 500 and a height of 300 coordinate units.

Important: If width and height are omitted, the Canvas drawing buffer defaults to 300 × 150 coordinate units. These attributes do not accept CSS units such as px; their values are numbers.

3. Canvas Dimensions and CSS Dimensions

Canvas has two different types of dimensions:

  • Intrinsic dimensions: The width and height of the internal drawing buffer.
  • CSS dimensions: The displayed size of the Canvas element on the web page.

Example 1: HTML Dimensions

<canvas id="canvas1" width="400" height="200"> </canvas>

The internal drawing buffer is 400 × 200 coordinate units. Without additional CSS, its displayed size normally matches these dimensions in CSS pixels.

Example 2: CSS Dimensions

<canvas id="canvas2" width="400" height="200" style="width: 600px; height: 300px;"> </canvas>

The drawing buffer remains 400 × 200, but the browser displays the Canvas at 600 × 300 CSS pixels. The rendered image is scaled to fit.

Important: Changing only the CSS dimensions can stretch or distort the Canvas output. For sharp graphics, especially on high-density displays, the drawing buffer may need to be scaled appropriately.

4. Canvas ID Attribute

The id attribute assigns a unique identifier to the Canvas element. JavaScript can use this ID to access the element.

<canvas id="drawingArea" width="400" height="200"> </canvas> <script> const canvas = document.getElementById("drawingArea"); </script>

Explanation:

  • id="drawingArea" identifies the Canvas.
  • getElementById() selects the element.
  • The variable canvas stores the element reference.
The id attribute is a standard HTML global attribute, not a Canvas-specific attribute. Its value should be unique within the document.

5. Fallback Content in Canvas

Fallback content is written between the opening and closing Canvas tags. It provides alternative content when a browser does not support the Canvas element.

Example

<canvas id="myCanvas" width="400" height="200"> Your browser does not support the HTML Canvas element. </canvas>

A browser that supports Canvas displays the drawing surface. The fallback content is used when Canvas is unsupported.

Fallback Link Example

<canvas id="myCanvas" width="400" height="200"> Canvas is not supported. <a href="alternative.html"> Open the alternative page </a> </canvas>
Fallback content is useful for compatibility, but it does not automatically make Canvas drawings accessible. Important graphical information should also have suitable text alternatives or accessible DOM content.

6. Accessing Canvas Using JavaScript

JavaScript can access the Canvas element through its ID and obtain a rendering context for drawing.

Basic JavaScript Syntax

const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d");

Explanation:

  • document represents the HTML document.
  • getElementById() selects the Canvas element.
  • getContext("2d") requests the 2D rendering context.
  • ctx stores the returned context object.

Checking Canvas Support

const canvas = document.getElementById("myCanvas"); if (canvas.getContext) { const ctx = canvas.getContext("2d"); if (ctx) { console.log("Canvas 2D is supported."); } else { console.log("Canvas 2D context is unavailable."); } } else { console.log("Canvas is not supported."); }

This example checks whether the Canvas element exposes the getContext method and whether a 2D context can be obtained.

7. Complete Program Using Canvas Attributes

This program demonstrates the use of Canvas width, height, ID, fallback content, and JavaScript rendering.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Canvas Attributes Example</title> <style> canvas { border: 2px solid black; } </style> </head> <body> <h2>Canvas Element and Attributes</h2> <canvas id="myCanvas" width="500" height="250"> Your browser does not support Canvas. </canvas> <script> const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d"); if (ctx) { ctx.fillStyle = "blue"; ctx.fillRect(50, 50, 200, 100); ctx.fillStyle = "black"; ctx.font = "20px Arial"; ctx.fillText("HTML5 Canvas", 270, 110); } </script> </body> </html>

Program Explanation

  1. Creates a Canvas element with ID myCanvas.
  2. Sets the internal drawing dimensions to 500 × 250.
  3. Uses CSS to add a black border.
  4. Accesses the Canvas using JavaScript.
  5. Obtains the 2D rendering context.
  6. Draws a blue rectangle using fillRect().
  7. Displays text using fillText().
Expected Result:

A bordered Canvas area measuring 500 × 250 coordinate units displays a blue rectangle and the text "HTML5 Canvas".

8. Important Canvas Properties

Property Description
canvas.width Gets or sets the internal drawing buffer width.
canvas.height Gets or sets the internal drawing buffer height.
ctx.fillStyle Specifies the fill color or other fill style.
ctx.strokeStyle Specifies the stroke color or other stroke style.
ctx.lineWidth Specifies the width of stroked lines.
ctx.font Specifies text font settings.
ctx.globalAlpha Specifies global drawing transparency.
Changing the Canvas width or height through HTML attributes or JavaScript resets the drawing buffer and its drawing state. Existing drawings are cleared.

9. Common Mistakes in Canvas

Mistake 1: Incorrect ID

<canvas id="myCanvas"></canvas> <script> const canvas = document.getElementById("mycanvas"); </script>

Problem: The ID uses different capitalization. HTML ID values are case-sensitive when matched by getElementById().

Mistake 2: Accessing the Canvas Before It Exists

<script> const canvas = document.getElementById("myCanvas"); </script> <canvas id="myCanvas"></canvas>

Problem: The script runs before the Canvas element has been parsed, so the reference may be null.

Solution: Place the script after the Canvas element or wait for the DOMContentLoaded event.

Mistake 3: Confusing CSS Size with Drawing Buffer Size

Changing only CSS width and height does not change the Canvas drawing buffer dimensions. It changes how the browser displays the existing drawing.

Mistake 4: Forgetting the Rendering Context

Drawing methods such as fillRect() belong to the 2D context, not directly to the Canvas HTML element.

10. Lesson Summary

  • The Canvas element creates a rectangular drawing surface.
  • Width and height define the internal drawing buffer dimensions.
  • The default Canvas dimensions are 300 × 150 coordinate units.
  • CSS dimensions control the displayed size.
  • The id attribute identifies the Canvas for JavaScript.
  • Fallback content provides an alternative when Canvas is unsupported.
  • getContext("2d") obtains the 2D rendering context.
  • Changing Canvas dimensions resets its drawing buffer and state.
  • Canvas graphics can be drawn using JavaScript methods.

12. Interview Questions and Answers

Q1. What is the Canvas element?
It is an HTML element that provides a drawing surface for creating graphics using JavaScript.
Q2. Which attributes define the Canvas drawing dimensions?
The width and height attributes define the internal drawing buffer dimensions.
Q3. What are the default Canvas dimensions?
The default dimensions are 300 coordinate units wide and 150 coordinate units high.
Q4. What is the purpose of the id attribute?
It uniquely identifies the Canvas element so JavaScript can access it.
Q5. What is fallback content?
It is alternative content placed inside the Canvas element for browsers that do not support Canvas.
Q6. What is the difference between Canvas width and CSS width?
Canvas width defines the internal drawing buffer width, while CSS width defines its displayed width.
Q7. How do you obtain a 2D rendering context?
Use canvas.getContext("2d").
Q8. What happens when Canvas dimensions are changed?
The drawing buffer is reset, clearing existing drawings and resetting the rendering state.
Q9. Can Canvas be resized using CSS?
Yes. CSS can change its displayed dimensions, but it does not change the internal drawing buffer dimensions.
Q10. Why is fallback content important?
It provides an alternative when Canvas is not supported. Additional accessible alternatives may still be needed for important graphical information.
