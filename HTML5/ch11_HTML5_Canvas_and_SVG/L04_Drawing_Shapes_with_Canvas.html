Lesson 4: Drawing Shapes with Canvas

Chapter 11: HTML5 Canvas and SVG

Learn to draw rectangles, lines, circles, arcs, paths, and polygons using JavaScript.

1. Introduction to Drawing Shapes

HTML5 Canvas provides a set of drawing methods that allow developers to create two-dimensional graphics using JavaScript. The Canvas 2D rendering context provides methods for drawing geometric shapes, lines, curves, and paths.

Common Canvas drawing operations include:

  • Drawing filled rectangles.
  • Drawing rectangular outlines.
  • Drawing straight lines.
  • Drawing circles and arcs.
  • Creating custom paths.
  • Drawing polygons and triangles.
  • Applying fill colors and stroke colors.

Before drawing shapes, JavaScript must access the Canvas element and obtain its 2D rendering context.

const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d");

2. Drawing Rectangles

Rectangles are among the simplest shapes that can be drawn using Canvas. Three important methods are available for rectangular drawing operations.

2.1 fillRect()

The fillRect() method draws a filled rectangle.

Syntax:

ctx.fillRect(x, y, width, height);

Parameters:

  • x: Horizontal coordinate of the top-left corner.
  • y: Vertical coordinate of the top-left corner.
  • width: Width of the rectangle.
  • height: Height of the rectangle.

Example:

ctx.fillStyle = "blue"; ctx.fillRect(30, 30, 200, 100);
Expected Result:

A filled blue rectangle appears at position (30, 30), with width 200 and height 100.

2.2 strokeRect()

The strokeRect() method draws the outline of a rectangle without filling its interior.

ctx.strokeStyle = "red"; ctx.lineWidth = 4; ctx.strokeRect(30, 30, 200, 100);
Expected Result:

A red rectangular outline with a line width of 4 appears.

2.3 clearRect()

The clearRect() method clears a rectangular region of the Canvas drawing buffer, making that area transparent.

ctx.fillStyle = "blue"; ctx.fillRect(30, 30, 200, 100); ctx.clearRect(80, 50, 60, 40);
Expected Result:

A blue rectangle appears with a transparent rectangular area removed from its interior.

Important: fillRect(), strokeRect(), and clearRect() draw or clear rectangles directly. They do not add rectangles to the current path.

3. Drawing Lines

Lines are created using Canvas path methods. A path is a sequence of connected or independent drawing segments.

3.1 beginPath()

The beginPath() method starts a new path by clearing the current sub-path collection.

3.2 moveTo()

The moveTo() method moves the current path position to a specified coordinate without drawing a line.

3.3 lineTo()

The lineTo() method adds a straight line segment from the current path position to a specified coordinate.

3.4 stroke()

The stroke() method draws the outline of the current path.

Example:

ctx.beginPath(); ctx.moveTo(50, 50); ctx.lineTo(250, 50); ctx.strokeStyle = "blue"; ctx.lineWidth = 5; ctx.stroke();
Expected Result:

A horizontal blue line appears from coordinate (50, 50) to coordinate (250, 50).

4. Drawing Circles and Arcs

The Canvas 2D context provides the arc() method for drawing circular arcs. A complete circle can be drawn by using an angular range of 0 to 2π radians.

4.1 arc() Method

Syntax:

ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise);

Parameters:

  • x: Horizontal coordinate of the circle's center.
  • y: Vertical coordinate of the circle's center.
  • radius: Radius of the circle.
  • startAngle: Starting angle in radians.
  • endAngle: Ending angle in radians.
  • anticlockwise: Optional direction flag; defaults to false.

4.2 Drawing a Circle

ctx.beginPath(); ctx.arc(150, 100, 50, 0, 2 * Math.PI); ctx.fillStyle = "green"; ctx.fill();
Expected Result:

A filled green circle with center (150, 100) and radius 50.

4.3 Drawing a Circular Outline

ctx.beginPath(); ctx.arc(150, 100, 50, 0, 2 * Math.PI); ctx.strokeStyle = "red"; ctx.lineWidth = 4; ctx.stroke();
Expected Result:

A red circular outline appears without a filled interior.

4.4 Drawing a Semicircle

ctx.beginPath(); ctx.arc(150, 100, 60, 0, Math.PI); ctx.strokeStyle = "blue"; ctx.lineWidth = 4; ctx.stroke();
Expected Result:

A semicircular arc is drawn from angle 0 to π radians.

Angle conversion: 180 degrees = π radians and 360 degrees = 2π radians. Canvas arc angles are specified in radians.

5. Drawing Custom Paths

Paths allow developers to create complex shapes by combining lines, curves, and other path segments.

Important path methods include:

Method Purpose
beginPath() Starts a new path.
moveTo() Moves to a specified coordinate without drawing.
lineTo() Adds a straight line segment.
closePath() Closes the current sub-path by connecting to its starting point.
fill() Fills the current path.
stroke() Draws the outline of the current path.
quadraticCurveTo() Adds a quadratic Bézier curve.
bezierCurveTo() Adds a cubic Bézier curve.

5.1 Drawing a Triangle

ctx.beginPath(); ctx.moveTo(150, 30); ctx.lineTo(250, 180); ctx.lineTo(50, 180); ctx.closePath(); ctx.fillStyle = "orange"; ctx.fill();
Expected Result:

An orange triangle appears with three connected sides.

5.2 Drawing a Polygon

ctx.beginPath(); ctx.moveTo(100, 30); ctx.lineTo(180, 80); ctx.lineTo(150, 170); ctx.lineTo(50, 170); ctx.lineTo(20, 80); ctx.closePath(); ctx.fillStyle = "purple"; ctx.fill(); ctx.strokeStyle = "black"; ctx.stroke();
Expected Result:

A filled purple five-sided polygon with a black outline.

6. Fill and Stroke Styles

Canvas supports fill and stroke properties to control the appearance of graphical objects.

6.1 fillStyle

The fillStyle property specifies the color, gradient, or pattern used to fill shapes.

ctx.fillStyle = "orange"; ctx.fillRect(30, 30, 150, 80);

6.2 strokeStyle

The strokeStyle property specifies the color, gradient, or pattern used to draw outlines and lines.

ctx.strokeStyle = "blue"; ctx.lineWidth = 5; ctx.strokeRect(30, 30, 150, 80);

6.3 lineWidth

The lineWidth property defines the thickness of stroked lines.

ctx.lineWidth = 8; ctx.strokeStyle = "red"; ctx.strokeRect(30, 30, 150, 80);

6.4 Global Alpha

The globalAlpha property controls the overall transparency of drawing operations.

ctx.globalAlpha = 0.5; ctx.fillStyle = "blue"; ctx.fillRect(30, 30, 150, 80);

A globalAlpha value of 1 means fully opaque, while 0 means fully transparent.

7. Line Cap and Line Join

7.1 lineCap

The lineCap property defines the appearance of the endpoints of stroked lines.

Available values:

  • butt – Flat endpoint at the exact endpoint.
  • round – Rounded endpoint.
  • square – Square endpoint extending beyond the endpoint.
ctx.beginPath(); ctx.moveTo(40, 70); ctx.lineTo(250, 70); ctx.lineWidth = 15; ctx.lineCap = "round"; ctx.strokeStyle = "blue"; ctx.stroke();

7.2 lineJoin

The lineJoin property controls how two connected line segments meet.

Available values:

  • miter – Sharp corner.
  • round – Rounded corner.
  • bevel – Beveled corner.
ctx.beginPath(); ctx.moveTo(50, 150); ctx.lineTo(120, 40); ctx.lineTo(190, 150); ctx.lineWidth = 15; ctx.lineJoin = "round"; ctx.strokeStyle = "green"; ctx.stroke();

8. Drawing Curves

Canvas supports curved paths using quadratic and cubic Bézier curve methods.

8.1 Quadratic Bézier Curve

A quadratic Bézier curve uses one control point and an endpoint, in addition to the starting point.

ctx.beginPath(); ctx.moveTo(50, 150); ctx.quadraticCurveTo( 150, 20, 250, 150 ); ctx.strokeStyle = "blue"; ctx.lineWidth = 4; ctx.stroke();

8.2 Cubic Bézier Curve

A cubic Bézier curve uses two control points and an endpoint, in addition to the starting point.

ctx.beginPath(); ctx.moveTo(50, 150); ctx.bezierCurveTo( 50, 20, 250, 20, 250, 150 ); ctx.strokeStyle = "red"; ctx.lineWidth = 4; ctx.stroke();
Quadratic curves use one control point, whereas cubic Bézier curves use two control points.

9. Complete Program: Multiple Canvas Shapes

The following program demonstrates rectangles, a circle, a line, and a triangle in one Canvas.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Canvas Shapes</title> </head> <body> <h2>Drawing Shapes with Canvas</h2> <canvas id="myCanvas" width="500" height="350" style="border:1px solid black;"> Canvas is not supported. </canvas> <script> const canvas = document.getElementById("myCanvas"); const ctx = canvas.getContext("2d"); // Filled rectangle ctx.fillStyle = "blue"; ctx.fillRect(30, 30, 120, 70); // Rectangle outline ctx.strokeStyle = "red"; ctx.lineWidth = 4; ctx.strokeRect(190, 30, 120, 70); // Circle ctx.beginPath(); ctx.arc(90, 190, 45, 0, 2 * Math.PI); ctx.fillStyle = "green"; ctx.fill(); // Line ctx.beginPath(); ctx.moveTo(190, 160); ctx.lineTo(350, 160); ctx.strokeStyle = "purple"; ctx.lineWidth = 5; ctx.stroke(); // Triangle ctx.beginPath(); ctx.moveTo(400, 180); ctx.lineTo(460, 280); ctx.lineTo(340, 280); ctx.closePath(); ctx.fillStyle = "orange"; ctx.fill(); </script> </body> </html>

Program Explanation

  1. Creates a Canvas with dimensions 500 × 350.
  2. Draws a filled blue rectangle.
  3. Draws a red rectangular outline.
  4. Draws a green circle using arc().
  5. Draws a purple straight line.
  6. Draws an orange triangle using path methods.
Expected Result:

The Canvas displays five graphical objects: a blue rectangle, red rectangle outline, green circle, purple line, and orange triangle.

11. Common Mistakes

  • Forgetting beginPath(): Old path segments may remain part of the current path.
  • Incorrect coordinates: Shapes may appear outside the visible Canvas area.
  • Incorrect angle units: The arc() method expects radians, not degrees.
  • Forgetting stroke() or fill(): Path commands alone do not render the path.
  • Incorrect line width: The lineWidth property must be a positive number.
  • Using closePath() incorrectly: It closes the current sub-path; it does not automatically fill it.

12. Lesson Summary

  • Canvas supports different geometric drawing operations.
  • fillRect() draws filled rectangles.
  • strokeRect() draws rectangle outlines.
  • clearRect() clears rectangular areas.
  • beginPath(), moveTo(), and lineTo() create paths.
  • arc() draws circles and circular arcs.
  • closePath() closes a sub-path.
  • fill() and stroke() render paths.
  • fillStyle and strokeStyle control graphical appearance.
  • lineCap and lineJoin control line endpoints and corners.
  • Bézier methods create curved paths.

14. Interview Questions and Answers

Q1. Which method draws a filled rectangle?
The fillRect() method.
Q2. Which method draws a rectangle outline?
The strokeRect() method.
Q3. What is the purpose of clearRect()?
It clears a rectangular region of the Canvas drawing buffer.
Q4. Which method starts a new path?
The beginPath() method.
Q5. What is the purpose of moveTo()?
It moves the current path position without drawing a line.
Q6. Which method adds a straight line segment?
The lineTo() method.
Q7. Which method is used to draw a circle?
The arc() method can draw a complete circle.
Q8. What is the difference between fill() and stroke()?
fill() fills the current path, while stroke() draws its outline.
Q9. What is the purpose of closePath()?
It connects the end of the current sub-path to its starting point.
Q10. How many control points does a cubic Bézier curve use?
It uses two control points, in addition to its starting and ending points.
