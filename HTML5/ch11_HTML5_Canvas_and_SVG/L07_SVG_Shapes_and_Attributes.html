Lesson 7: SVG Shapes and Attributes

Chapter 11: HTML5 Canvas and SVG

Learn to create and customize geometric graphics using SVG elements and attributes.

1. Introduction to SVG Shapes

SVG provides several built-in elements for drawing two-dimensional shapes. Each shape is represented by an SVG element with attributes that define its position, dimensions, appearance, and other properties.

Common SVG shape elements include:

  • <rect> – Rectangle and square.
  • <circle> – Circle.
  • <ellipse> – Ellipse.
  • <line> – Straight line.
  • <polygon> – Closed polygon.
  • <polyline> – Connected line segments.
  • <path> – Complex paths and curves.
SVG shapes are vector objects. Their geometry is described through attributes rather than being stored as a fixed collection of pixels.

2. Rectangle – rect Element

The <rect> element creates a rectangle. Its position is determined by the x and y attributes, while width and height specify its dimensions.

Important Attributes

Attribute Purpose
xHorizontal starting position.
yVertical starting position.
widthRectangle width.
heightRectangle height.
rxHorizontal corner radius.
ryVertical corner radius.
fillInterior color or paint.
strokeOutline color or paint.

Example 1: Basic Rectangle

<svg width="300" height="180" xmlns="http://www.w3.org/2000/svg"> <rect x="40" y="30" width="200" height="100" fill="blue" /> </svg>

Example 2: Rectangle with Border

<svg width="300" height="180" xmlns="http://www.w3.org/2000/svg"> <rect x="40" y="30" width="200" height="100" fill="lightblue" stroke="black" stroke-width="4" /> </svg>

Example 3: Rounded Rectangle

<svg width="300" height="180" xmlns="http://www.w3.org/2000/svg"> <rect x="40" y="30" width="200" height="100" rx="15" ry="15" fill="orange" /> </svg>
If only one of rx or ry is specified, SVG can use that value for both corner radii. The radii are constrained by the rectangle's dimensions.

3. Circle – circle Element

The <circle> element creates a circle. A circle is defined by its center coordinates and radius.

Important Attributes

Attribute Purpose
cxHorizontal center coordinate.
cyVertical center coordinate.
rRadius of the circle.
fillInterior paint.
strokeOutline paint.
stroke-widthOutline thickness.

Example

<svg width="300" height="200" xmlns="http://www.w3.org/2000/svg"> <circle cx="150" cy="100" r="60" fill="red" stroke="black" stroke-width="3" /> </svg>

Explanation:

  • cx="150" sets the horizontal center.
  • cy="100" sets the vertical center.
  • r="60" sets the radius to 60 units.
  • fill="red" fills the circle with red.
  • stroke="black" adds a black outline.
Expected Result: A red circle with a black outline appears at the center of the SVG drawing area.

4. Ellipse – ellipse Element

The <ellipse> element creates an ellipse. An ellipse has two radii: a horizontal radius and a vertical radius.

Important Attributes

  • cx – Horizontal center coordinate.
  • cy – Vertical center coordinate.
  • rx – Horizontal radius.
  • ry – Vertical radius.

Example

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <ellipse cx="175" cy="100" rx="120" ry="60" fill="lightgreen" stroke="green" stroke-width="3" /> </svg>
Expected Result: A horizontal green ellipse with a darker green outline.

5. Line – line Element

The <line> element creates a straight line between two points.

Important Attributes

  • x1 – Starting point's X coordinate.
  • y1 – Starting point's Y coordinate.
  • x2 – Ending point's X coordinate.
  • y2 – Ending point's Y coordinate.

Example

<svg width="300" height="180" xmlns="http://www.w3.org/2000/svg"> <line x1="40" y1="40" x2="250" y2="140" stroke="blue" stroke-width="5" /> </svg>
A line has no filled interior. Use stroke to make the line visible.

6. Polygon – polygon Element

The <polygon> element creates a closed shape using multiple connected points.

The points attribute contains pairs of X and Y coordinates.

Example: Triangle

<svg width="300" height="220" xmlns="http://www.w3.org/2000/svg"> <polygon points="150,20 40,180 260,180" fill="orange" stroke="black" stroke-width="3" /> </svg>

Example: Pentagon

<svg width="300" height="250" xmlns="http://www.w3.org/2000/svg"> <polygon points=" 150,20 280,110 230,230 70,230 20,110" fill="lightblue" stroke="blue" stroke-width="3" /> </svg>
A polygon automatically connects its final point to its first point, forming a closed shape.

7. Polyline – polyline Element

The <polyline> element creates a series of connected straight-line segments.

Unlike polygon, polyline does not automatically close the final point to the first point.

Example

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <polyline points=" 30,150 100,40 170,150 240,40 320,150" fill="none" stroke="red" stroke-width="5" /> </svg>
Expected Result: A red zigzag line consisting of connected line segments.

8. Path – path Element

The <path> element is one of the most powerful SVG elements. It can describe straight lines, curves, arcs, and complex shapes.

Its geometry is defined using the d attribute.

Common Path Commands

Command Meaning
MMove to an absolute coordinate.
mMove to a relative coordinate.
LDraw a line to an absolute coordinate.
lDraw a line to a relative coordinate.
HDraw a horizontal line.
VDraw a vertical line.
CDraw a cubic Bézier curve.
QDraw a quadratic Bézier curve.
ADraw an elliptical arc.
ZClose the current subpath.

Example 1: Triangle Using Path

<svg width="300" height="200" xmlns="http://www.w3.org/2000/svg"> <path d="M 150 20 L 40 170 L 260 170 Z" fill="lightblue" stroke="blue" stroke-width="3" /> </svg>

Example 2: Curved Path

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <path d="M 30 150 Q 175 -20 320 150" fill="none" stroke="green" stroke-width="5" /> </svg>

Example 3: Cubic Bézier Curve

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <path d="M 30 150 C 80 10, 250 10, 320 150" fill="none" stroke="purple" stroke-width="5" /> </svg>
Uppercase path commands generally use absolute coordinates. Lowercase commands generally use coordinates relative to the current point.

9. SVG Fill Attributes

The fill property controls the interior paint of a closed SVG shape or path.

Common Fill Values

  • Named colors such as red, blue, and green.
  • Hexadecimal colors such as #174ea6.
  • RGB color values.
  • RGBA color values.
  • none to remove the fill.

Example

<svg width="350" height="150" xmlns="http://www.w3.org/2000/svg"> <circle cx="70" cy="75" r="45" fill="red" /> <circle cx="175" cy="75" r="45" fill="#174ea6" /> <circle cx="280" cy="75" r="45" fill="none" stroke="green" stroke-width="4" /> </svg>

10. SVG Stroke Attributes

Stroke properties control the appearance of the outline around SVG shapes and paths.

Property Purpose
strokeOutline color or paint.
stroke-widthOutline thickness.
stroke-linecapShape of line endpoints.
stroke-linejoinAppearance of connected corners.
stroke-dasharrayDefines dashed or dotted patterns.
stroke-dashoffsetOffsets the dash pattern.

10.1 stroke-linecap

Common values:

  • butt – Straight, square-ended line termination at the endpoint.
  • round – Rounded line endpoints.
  • square – Square endpoints extending beyond the endpoint.
<svg width="350" height="180" xmlns="http://www.w3.org/2000/svg"> <line x1="40" y1="40" x2="300" y2="40" stroke="blue" stroke-width="15" stroke-linecap="butt" /> <line x1="40" y1="90" x2="300" y2="90" stroke="green" stroke-width="15" stroke-linecap="round" /> <line x1="40" y1="140" x2="300" y2="140" stroke="red" stroke-width="15" stroke-linecap="square" /> </svg>

10.2 stroke-linejoin

Common values:

  • miter – Sharp corner.
  • round – Rounded corner.
  • bevel – Flattened corner.
<svg width="350" height="180" xmlns="http://www.w3.org/2000/svg"> <polyline points="30,140 90,30 150,140" fill="none" stroke="blue" stroke-width="12" stroke-linejoin="miter" /> <polyline points="190,140 250,30 310,140" fill="none" stroke="green" stroke-width="12" stroke-linejoin="round" /> </svg>

10.3 stroke-dasharray

Creates dashed line patterns.

<svg width="350" height="150" xmlns="http://www.w3.org/2000/svg"> <line x1="30" y1="40" x2="320" y2="40" stroke="blue" stroke-width="4" stroke-dasharray="10 5" /> <line x1="30" y1="100" x2="320" y2="100" stroke="red" stroke-width="4" stroke-dasharray="2 6" /> </svg>

11. Opacity and Transparency

SVG supports transparency through opacity-related properties.

  • opacity – Controls overall element opacity.
  • fill-opacity – Controls fill opacity.
  • stroke-opacity – Controls stroke opacity.

Example

<svg width="350" height="180" xmlns="http://www.w3.org/2000/svg"> <rect x="30" y="30" width="130" height="100" fill="blue" opacity="1" /> <rect x="190" y="30" width="130" height="100" fill="red" opacity="0.4" /> </svg>

12. SVG Text – text Element

The <text> element displays text inside an SVG drawing area.

Common Text Attributes

  • x – Horizontal text position.
  • y – Vertical text position.
  • font-size – Text size.
  • font-family – Font family.
  • font-weight – Font thickness.
  • text-anchor – Horizontal text alignment.
  • fill – Text color.

Example

<svg width="400" height="150" xmlns="http://www.w3.org/2000/svg"> <text x="200" y="75" font-size="30" font-family="Arial" font-weight="bold" text-anchor="middle" fill="blue"> Hello SVG </text> </svg>
SVG text is positioned using its text baseline. Therefore, the y coordinate generally identifies the baseline rather than the top of the letters.

13. SVG Groups – g Element

The <g> element groups multiple SVG elements together. Attributes and transformations applied to the group can affect its child elements.

Example

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <g fill="orange" stroke="black" stroke-width="3"> <circle cx="80" cy="80" r="40" /> <rect x="150" y="40" width="100" height="80" /> </g> </svg>

Both shapes inherit the group's fill and stroke presentation properties unless overridden.

14. SVG Gradients

SVG supports gradients that gradually transition between colors. Two common gradient types are linear gradients and radial gradients.

14.1 Linear Gradient

A linear gradient changes color along a straight direction. It is defined using <linearGradient>.

<svg width="350" height="150" xmlns="http://www.w3.org/2000/svg"> <defs> <linearGradient id="myGradient" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" stop-color="blue" /> <stop offset="100%" stop-color="orange" /> </linearGradient> </defs> <rect x="30" y="30" width="290" height="90" fill="url(#myGradient)" /> </svg>

14.2 Radial Gradient

A radial gradient changes color outward from a central point or region.

<svg width="300" height="200" xmlns="http://www.w3.org/2000/svg"> <defs> <radialGradient id="radial"> <stop offset="0%" stop-color="yellow" /> <stop offset="100%" stop-color="red" /> </radialGradient> </defs> <circle cx="150" cy="100" r="80" fill="url(#radial)" /> </svg>

15. SVG Transformations

The transform attribute changes the position, orientation, or scale of SVG graphical elements.

Common Transformations

Transformation Purpose
translate() Moves an element.
rotate() Rotates an element.
scale() Changes element size.
skewX() Skews an element along the X direction.
skewY() Skews an element along the Y direction.

Example

<svg width="350" height="220" xmlns="http://www.w3.org/2000/svg"> <rect x="30" y="40" width="80" height="60" fill="blue" /> <rect x="30" y="40" width="80" height="60" fill="orange" transform="translate(130, 0)" /> <rect x="220" y="40" width="80" height="60" fill="green" transform="rotate(25 260 70)" /> </svg>

16. CSS Styling of SVG Elements

SVG elements can be styled through presentation attributes or CSS rules.

Example: CSS Classes

<svg width="350" height="200" xmlns="http://www.w3.org/2000/svg"> <style> .myCircle { fill: lightblue; stroke: blue; stroke-width: 4; } .myRect { fill: orange; stroke: black; stroke-width: 2; } </style> <circle class="myCircle" cx="90" cy="90" r="50" /> <rect class="myRect" x="180" y="40" width="110" height="100" /> </svg>

17. Complete SVG Shapes Program

The following HTML5 program combines several SVG elements in one drawing area.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>SVG Shapes</title> </head> <body> <h2>SVG Shapes Demonstration</h2> <svg width="500" height="400" viewBox="0 0 500 400" xmlns="http://www.w3.org/2000/svg"> <rect x="30" y="30" width="120" height="70" fill="blue" /> <circle cx="250" cy="65" r="40" fill="red" /> <ellipse cx="410" cy="65" rx="55" ry="35" fill="green" /> <line x1="30" y1="150" x2="180" y2="150" stroke="black" stroke-width="5" /> <polygon points="250,120 190,220 310,220" fill="orange" /> <polyline points="350,220 390,140 430,220 470,140" fill="none" stroke="purple" stroke-width="5" /> <text x="250" y="300" font-size="24" text-anchor="middle" fill="blue"> SVG Graphics </text> </svg> </body> </html>
Expected Result:

The page displays a blue rectangle, red circle, green ellipse, black line, orange triangle, purple polyline, and blue SVG text.

19. Common SVG Mistakes

  • Missing coordinates: Required geometry attributes are omitted.
  • Incorrect dimensions: Shape width, height, or radius is too large for the viewport.
  • Missing stroke: An unfilled line or shape may not be visible.
  • Incorrect points: Polygon and polyline coordinates are entered incorrectly.
  • Incorrect path syntax: Path commands or coordinate pairs are malformed.
  • Incorrect gradient reference: The fill URL does not match the gradient ID.
  • Confusing polygon and polyline: Polygon closes automatically; polyline does not.

22. Interview Questions and Answers

Q1. Which SVG element creates a rectangle?
The rect element.
Q2. Which attributes define a circle?
cx, cy, and r.
Q3. What is the difference between circle and ellipse?
A circle has one radius, whereas an ellipse has separate horizontal and vertical radii.
Q4. What is the difference between polygon and polyline?
Polygon automatically connects the last point to the first point. Polyline does not.
Q5. What is the purpose of the path element?
It defines complex shapes, straight lines, curves, and arcs using path commands.
Q6. What is the purpose of fill?
It defines the interior paint of an SVG shape.
Q7. What is the purpose of stroke?
It defines the outline paint of an SVG element.
Q8. What does stroke-width control?
It controls the thickness of the outline.
Q9. What is stroke-dasharray?
It defines the dash and gap pattern of an SVG stroke.
Q10. What is the purpose of the g element?
It groups multiple SVG elements so they can share properties and transformations.
Q11. What is a Bézier curve?
It is a mathematical curve defined using control points. SVG paths support quadratic and cubic Bézier curves.
Q12. Which element defines a linear gradient?
The linearGradient element.
Q13. Which attribute applies transformations?
The transform attribute.
Q14. Can SVG shapes be styled using CSS?
Yes. SVG supports CSS styling through selectors, classes, and presentation properties.
Q15. Which SVG element is used to display text?
The text element.
