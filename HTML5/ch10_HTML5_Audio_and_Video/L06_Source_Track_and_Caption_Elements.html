Lesson 6: Source, Track and Caption Elements

Multiple Media Resources, Subtitles and Accessibility in HTML5

1. Introduction

HTML5 provides the <source> and <track> elements to improve multimedia compatibility and accessibility.

The source element specifies alternative media resources for audio and video elements.

The track element adds timed text information such as subtitles, captions, descriptions and chapters.

In this lesson, we will study:

  • Source element and its attributes
  • Multiple media sources
  • Track element and its attributes
  • WebVTT subtitle files
  • Subtitles and captions
  • Audio descriptions and chapters
  • Multimedia accessibility

2. Source Element

The <source> element specifies an alternative media resource for the audio or video element.

It is useful when different browsers support different media containers or codecs.

Basic Syntax

<video controls> <source src="video.mp4" type="video/mp4"> </video>

Example with Multiple Sources

<video controls width="600"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> Your browser does not support video playback. </video>

The browser examines the available resources and attempts to select a format and codec that it can play.

The source element is a void element. It does not require a closing tag and cannot contain child elements.

3. Attributes of the Source Element

Attribute Purpose
src Specifies the URL of the media resource.
type Declares the media MIME type and may include codec information.
media Specifies media conditions for selecting a resource, particularly with picture sources.
srcset Provides image candidates in responsive picture sources; not a video source attribute.
sizes Provides image display-size hints for responsive picture sources; not a video source attribute.

src Attribute

<source src="movie.mp4">

type Attribute

<source src="movie.webm" type="video/webm">

Using Source with Audio

<audio controls> <source src="music.mp3" type="audio/mpeg"> <source src="music.ogg" type="audio/ogg"> </audio>

4. Track Element

The <track> element specifies timed text tracks for audio and video elements.

These tracks can provide subtitles, captions, descriptions, chapters and metadata.

Basic Syntax

<video controls> <source src="lecture.mp4" type="video/mp4"> <track src="subtitles-en.vtt" kind="subtitles" srclang="en" label="English"> </video>

In this example, the English subtitle track is linked to the video using a WebVTT file.

The track element is also a void element. It does not use a closing tag.

5. Attributes of the Track Element

Attribute Purpose
src Specifies the URL of the timed text file.
kind Defines the type of text track.
srclang Specifies the language of the track.
label Provides a readable track name for the user.
default Indicates that the track should be enabled by default when appropriate.

Example

<video controls> <source src="lecture.mp4" type="video/mp4"> <track src="english.vtt" kind="subtitles" srclang="en" label="English" default> </video>

Explanation:

  • src: Links the WebVTT file.
  • kind: Identifies the track type.
  • srclang: Declares the track language.
  • label: Names the track in the user interface.
  • default: Marks the preferred default track.

6. Values of the Kind Attribute

The kind attribute defines the purpose of the timed text track.

Value Purpose
subtitles Displays dialogue in another language or provides translated text.
captions Displays dialogue and relevant non-speech audio information.
descriptions Provides text descriptions of visual information.
chapters Provides navigation points within media content.
metadata Provides timed information intended for scripts or other processing.

Subtitles Example

<track src="english.vtt" kind="subtitles" srclang="en" label="English">

Captions Example

<track src="captions.vtt" kind="captions" srclang="en" label="English Captions">

Descriptions Example

<track src="descriptions.vtt" kind="descriptions" srclang="en" label="Visual Descriptions">

Chapters Example

<track src="chapters.vtt" kind="chapters" srclang="en" label="Chapters">

Metadata Example

<track src="metadata.vtt" kind="metadata" srclang="en" label="Video Metadata">

7. What is WebVTT?

WebVTT stands for Web Video Text Tracks.

It is a text-based format used to represent timed text information associated with audio and video.

WebVTT files normally use the .vtt extension.

Basic WebVTT Structure

WEBVTT 00:00:01.000 --> 00:00:04.000 Welcome to the HTML5 video lesson. 00:00:05.000 --> 00:00:08.000 Today we will learn about track elements.

Explanation:

  • WEBVTT identifies the file format.
  • The first timestamp specifies the cue start time.
  • The second timestamp specifies the cue end time.
  • The text below the timestamps is the cue content.
A WebVTT file is a separate text file. It is not written inside the HTML document.

8. WebVTT File Creation

Create a file named english.vtt using a text editor.

File Content

WEBVTT 00:00:00.000 --> 00:00:03.000 Welcome to NS Learning Hub. 00:00:03.500 --> 00:00:07.000 This is an HTML5 multimedia lesson. 00:00:07.500 --> 00:00:11.000 We are learning about subtitles and captions.

Saving the File

  1. Open Notepad or another text editor.
  2. Enter the WebVTT content.
  3. Select Save As.
  4. Enter the filename english.vtt.
  5. Choose All Files as the file type if needed.
  6. Save using UTF-8 encoding.
Ensure that the filename is english.vtt, not english.vtt.txt.

9. Subtitles vs Captions

Subtitles and captions both display text associated with media, but they serve different accessibility and language needs.

Subtitles Captions
Primarily represent spoken dialogue. Represent dialogue and relevant sound information.
Often used for language translation. Support people who are deaf or hard of hearing.
May not include sound effects. Can include sound effects and speaker identification.
Example: translated dialogue. Example: [Door closes] or [Music playing].

Caption Example

WEBVTT 00:00:01.000 --> 00:00:04.000 Speaker: Welcome to the lesson. 00:00:04.500 --> 00:00:07.000 [Background music playing] 00:00:07.500 --> 00:00:10.000 [Door closes]

10. Multiple Subtitle Languages

Multiple track elements can provide subtitles in different languages.

Example

<video controls width="600"> <source src="lecture.mp4" type="video/mp4"> <track src="english.vtt" kind="subtitles" srclang="en" label="English" default> <track src="hindi.vtt" kind="subtitles" srclang="hi" label="Hindi"> </video>

The user can select an available subtitle track through the browser's media controls when supported.

Track selection and display behavior depend on browser support and user settings.

11. Complete Practical Example

Create the following project structure:

multimedia-project/ │ ├── index.html │ ├── videos/ │ └── lecture.mp4 │ └── subtitles/ ├── english.vtt └── hindi.vtt

HTML File: index.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Video with Subtitles</title> </head> <body> <h1>HTML5 Video with Subtitles</h1> <video controls width="600"> <source src="videos/lecture.mp4" type="video/mp4"> <track src="subtitles/english.vtt" kind="subtitles" srclang="en" label="English" default> <track src="subtitles/hindi.vtt" kind="subtitles" srclang="hi" label="Hindi"> Your browser does not support video playback. </video> </body> </html>

English Subtitle File

Filename: subtitles/english.vtt

WEBVTT 00:00:01.000 --> 00:00:04.000 Welcome to HTML5 multimedia. 00:00:05.000 --> 00:00:08.000 We are learning about track elements.

Hindi Subtitle File

Filename: subtitles/hindi.vtt

WEBVTT 00:00:01.000 --> 00:00:04.000 HTML5 मल्टीमीडिया में आपका स्वागत है। 00:00:05.000 --> 00:00:08.000 हम ट्रैक एलिमेंट के बारे में सीख रहे हैं।

Expected Result

  • A video player appears on the webpage.
  • English and Hindi subtitle tracks are available.
  • English is marked as the default track.
  • Subtitles appear at their specified timestamps when enabled.
This example requires an actual video file and both WebVTT files at the specified paths. The video duration must cover the subtitle timestamps.

12. Multimedia Accessibility

Accessibility makes audio and video content usable by people with different abilities and requirements.

Important Accessibility Practices

  • Provide accurate captions for important audio information.
  • Provide subtitles when translated dialogue is needed.
  • Use descriptive track labels.
  • Use the correct language code in srclang.
  • Provide audio descriptions when important visual information needs explanation.
  • Make playback controls accessible through a keyboard.
  • Ensure text is readable and synchronized with media.
  • Provide a transcript where appropriate.
Captions and subtitles improve accessibility, but they must be accurate, synchronized and appropriate for the intended audience.

13. Source Element vs Track Element

Source Track
Provides media resources. Provides timed text information.
Used with audio, video and picture. Used with audio and video.
Can specify alternative media formats. Can specify subtitles and captions.
Uses src and type attributes. Uses src, kind, srclang and label attributes.
Does not provide subtitle timing. Uses timed text cues such as WebVTT.

14. Common Mistakes

  • Using an incorrect WebVTT file path.
  • Saving a subtitle file with a .txt extension.
  • Forgetting the WEBVTT header.
  • Writing invalid cue timestamps.
  • Using an incorrect language code.
  • Confusing subtitles with captions.
  • Placing track elements outside audio or video.
  • Using an unsupported track kind value.
  • Forgetting the label attribute for clear track selection.
  • Assuming subtitles will appear without a supported track selection mechanism.

16. Interview Questions and Answers

Q1. What is the source element?

It specifies a media resource for audio, video or picture elements.

Q2. Why are multiple source elements used?

They provide alternative media resources to improve compatibility across browsers.

Q3. What is the track element?

It adds timed text tracks to audio and video elements.

Q4. What is WebVTT?

WebVTT is a text-based format used for timed text information associated with media.

Q5. What is the purpose of kind?

It specifies the purpose of the track, such as subtitles, captions or chapters.

Q6. What does srclang specify?

It specifies the language of the text track.

Q7. What is the purpose of label?

It provides a readable name for a text track.

Q8. What does default do?

It marks a track as the default track when the browser's track-selection rules permit it.

Q9. What is the difference between subtitles and captions?

Subtitles primarily represent dialogue, often translated, while captions also describe relevant non-speech audio information.

Q10. Are source and track void elements?

Yes. Neither element requires a closing tag.
