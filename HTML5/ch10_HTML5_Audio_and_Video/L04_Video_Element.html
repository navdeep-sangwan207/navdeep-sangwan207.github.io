Lesson 4: Video Element

Embedding and Playing Video Files Using HTML5

1. Introduction to the Video Element

The HTML5 <video> element is used to embed video content directly into a webpage. It allows browsers to display and play video files without requiring a separate browser plugin.

Common applications include:

  • Online video tutorials
  • Educational lectures
  • Product demonstrations
  • Training videos
  • Recorded presentations
  • Video galleries

2. Basic Syntax of the Video Element

The basic syntax is:

<video controls width="500"> <source src="video.mp4" type="video/mp4"> Your browser does not support the video element. </video>

Explanation

  • <video>: Defines the video player.
  • controls: Displays browser playback controls.
  • width: Specifies the displayed video width.
  • <source>: Specifies the video file.
  • src: Specifies the media file location.
  • type: Declares the media MIME type.

3. Using the Video Element with the src Attribute

A video file can be specified directly using the src attribute on the video element.

Example

<video src="tutorial.mp4" controls width="500"> Your browser does not support video playback. </video>

In this example, the browser loads the file tutorial.mp4 and displays its playback controls.

Direct src is suitable for a single media resource. Use source elements when providing alternative video formats.

4. Using the Source Element with Video

The <source> element specifies a media resource for the video element.

Multiple source elements can provide alternative video files in different formats.

Example

<video controls width="500"> <source src="tutorial.mp4" type="video/mp4"> <source src="tutorial.webm" type="video/webm"> Your browser does not support video playback. </video>

The browser examines the available sources and attempts to use a supported media resource.

Multiple sources can improve compatibility across browsers, but actual playback still depends on the container, codecs and browser support.

5. Width and Height Attributes

The video element supports width and height attributes to specify the displayed dimensions of the video.

Width Attribute

<video controls width="600"> <source src="video.mp4" type="video/mp4"> </video>

Width and Height Together

<video controls width="600" height="350"> <source src="video.mp4" type="video/mp4"> </video>

These attributes define the displayed dimensions. If the specified dimensions do not match the video's aspect ratio, the video may appear stretched.

For responsive layouts, CSS is commonly used to make videos fit their available container while preserving their aspect ratio.

6. Video Playback Controls

The controls attribute asks the browser to display its built-in video playback interface.

Typical controls include:

  • Play and pause
  • Playback progress bar
  • Volume adjustment
  • Mute and unmute
  • Fullscreen playback
  • Playback speed controls in some browsers

Example

<video controls width="600"> <source src="lecture.mp4" type="video/mp4"> </video>
The appearance and available controls may differ between browsers and operating systems.

7. Video Element with Fallback Content

Fallback content is written between the opening and closing video tags.

It provides alternative content for browsers that do not support the video element.

Example

<video controls width="600"> <source src="tutorial.mp4" type="video/mp4"> Your browser does not support the video element. Please use a modern browser. </video>
Fallback text generally appears when the browser does not support the video element. It does not automatically appear whenever a video file fails to load or decode.

8. Understanding the Video Element Structure

<video controls width="600"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> Your browser does not support video playback. </video>

Structure explanation:

  • video: Creates the video player.
  • controls: Displays playback controls.
  • width: Sets the displayed width.
  • source: Provides an alternative video resource.
  • src: Specifies the video file URL.
  • type: Declares the media type.
  • Fallback content: Helps unsupported browsers.

9. Video File Paths

Video files can be stored in the same directory as the HTML file or in a separate folder.

Example Folder Structure

video-project/ │ ├── index.html │ └── videos/ ├── tutorial.mp4 └── tutorial.webm

Using a Relative Path

<video controls width="600"> <source src="videos/tutorial.mp4" type="video/mp4"> </video>

The browser looks for the video inside the videos folder relative to the HTML document.

Using an Absolute URL

<video controls width="600"> <source src="https://example.com/media/tutorial.mp4" type="video/mp4"> </video>
The URL above is an example placeholder. Replace it with a valid, accessible video URL.

10. Video Element vs Audio Element

Video Element Audio Element
Embeds video content. Embeds sound content.
Displays moving visual content. Does not display video frames.
Supports width and height attributes. Does not have equivalent visual dimensions.
Can display fullscreen controls. Normally displays audio playback controls.
Can contain source and track elements. Can contain source and track elements.

11. Practical Example: HTML5 Video Player

Create a file named video-demo.html and add the following code.

Complete HTML Code

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>HTML5 Video Player</title> </head> <body> <h1>My Video Player</h1> <p>Watch the video below:</p> <video controls width="600"> <source src="videos/tutorial.mp4" type="video/mp4"> <source src="videos/tutorial.webm" type="video/webm"> Your browser does not support video playback. </video> </body> </html>

Expected Result

My Video Player

Watch the video below:

A video player will appear when a supported video file is available at one of the specified paths.

Steps to Test

  1. Create a folder named video-project.
  2. Create an HTML file named index.html.
  3. Create a folder named videos.
  4. Place valid MP4 or WebM video files inside it.
  5. Save the HTML code.
  6. Open index.html in a browser.
  7. Press Play to test video playback.

12. Responsive Video Using CSS

Videos should adapt to different screen sizes. CSS can make the video fit the available container without exceeding its original dimensions.

Example

<style> video { max-width: 100%; height: auto; } </style> <video controls width="600"> <source src="tutorial.mp4" type="video/mp4"> </video>

The max-width property prevents the video from becoming wider than its containing area.

13. Common Mistakes

  • Using an incorrect video file path.
  • Forgetting the controls attribute.
  • Using an unsupported container or codec.
  • Declaring an incorrect MIME type.
  • Placing source elements outside the video element.
  • Using width and height values that distort the video.
  • Assuming fallback text appears whenever video loading fails.
  • Not considering responsive layouts.
  • Using large video files without optimization.

15. Interview Questions and Answers

Q1. What is the video element in HTML5?

It is an HTML element used to embed and play video content in a webpage.

Q2. What is the purpose of controls?

It displays browser-provided video playback controls.

Q3. What is the purpose of the src attribute?

It specifies the URL of the video resource.

Q4. What is the source element?

It specifies a media resource that the video element can use.

Q5. Can a video element contain multiple sources?

Yes. Multiple source elements can provide alternative media formats.

Q6. What are width and height attributes?

They specify the displayed dimensions of the video.

Q7. What is fallback content?

It is alternative content provided inside the video element for browsers that do not support it.

Q8. Name common video containers.

MP4, WebM and Ogg are common video containers.

Q9. How can a video be made responsive?

CSS such as max-width: 100% and height: auto can help the video fit its container.

Q10. Does HTML5 video require Flash Player?

No. HTML5 provides native video playback support.
