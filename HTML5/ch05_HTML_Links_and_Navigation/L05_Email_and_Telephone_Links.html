Chapter 5: HTML Links and Navigation

Lesson 5: Email and Telephone Links

1. Introduction to Email and Telephone Links

HTML allows developers to create hyperlinks that open an email application or initiate a telephone call on a compatible device.

These links use special URL schemes instead of ordinary HTTP or HTTPS webpage addresses.

  • mailto: is used to create email links.
  • tel: is used to create telephone links.
Examples:

Email link: mailto:info@example.com

Telephone link: tel:+911234567890

2. Creating an Email Link Using mailto:

The mailto: scheme allows users to open an available email application with a specified recipient address.

Basic Syntax

<a href="mailto:email-address">
    Send Email
</a>

Example

<a href="mailto:info@example.com">
    Contact Us by Email
</a>

How It Works

  1. The user opens a webpage containing the email hyperlink.
  2. The user activates the hyperlink.
  3. The operating system or browser handles the mailto URL.
  4. An available email application or configured email handler may open.
  5. The recipient address is usually filled in automatically.
Note: A mailto link does not send an email automatically. The user normally needs to review and send the message through an email application or handler.

3. Adding an Email Subject

You can add a subject to an email link using the subject parameter.

Syntax

<a href="mailto:info@example.com?subject=Website%20Enquiry">
    Send Enquiry
</a>

The question mark (?) introduces the query parameters. The subject value uses URL encoding.

Example

<a href="mailto:support@example.com?subject=Technical%20Support">
    Contact Technical Support
</a>

When activated, the email application may open a new message addressed to support@example.com with the subject "Technical Support".

4. Adding Email Body Text

You can use the body parameter to provide suggested message text.

Example

<a href="mailto:info@example.com?body=Hello,%20I%20need%20more%20information.">
    Send Message
</a>

The body text is supplied to the email application as a suggested message. It is not sent automatically.

5. Adding Subject and Body Together

Multiple email parameters can be combined using an ampersand (&).

Example

<a href="mailto:info@example.com?subject=Course%20Enquiry&body=Hello,%20I%20want%20to%20know%20about%20your%20courses.">
    Enquire About Courses
</a>
Part Purpose
mailto:info@example.com Recipient email address.
?subject=Course%20Enquiry Suggested email subject.
&body=Hello... Suggested email message body.

6. Adding Multiple Email Recipients

A mailto URL can specify multiple recipients separated by commas.

Example

<a href="mailto:admin@example.com,support@example.com">
    Email Administration and Support
</a>

You can also use query parameters such as cc and bcc to suggest additional recipients.

CC Example

<a href="mailto:admin@example.com?cc=manager@example.com">
    Contact Administration
</a>

BCC Example

<a href="mailto:admin@example.com?bcc=manager@example.com">
    Send Email
</a>
Important: Email client behaviour can vary. Not every application supports every mailto parameter consistently.

7. URL Encoding in Email Links

Special characters and spaces in mailto query parameters should be URL-encoded.

Character Encoded Form
Space %20
Comma %2C
Question mark %3F
Ampersand %26
New line %0D%0A

In HTML source code, write an ampersand separator between query parameters as &amp; when it is part of an attribute value.

8. Creating a Telephone Link Using tel:

The tel: scheme creates a hyperlink that can initiate a telephone call on devices with a compatible calling application.

Basic Syntax

<a href="tel:telephone-number">
    Call Us
</a>

Example

<a href="tel:+911234567890">
    Call +91 12345 67890
</a>

When activated on a compatible mobile device, the link may open the phone application with the specified number ready to call.

Note: The tel: link does not guarantee that a call will be placed. The device or browser must support a compatible telephone handler, and the user may need to confirm the call.

9. International Telephone Numbers

For international telephone links, use the international telephone number format with the country calling code.

Example

<a href="tel:+911234567890">
    Call India Number
</a>

In this example:

  • +91 is India's country calling code.
  • The remaining digits represent the subscriber number.
  • The visible link text can be formatted for readability.

10. Difference Between mailto: and tel:

mailto: tel:
Creates an email link. Creates a telephone link.
Opens an email handler. Opens a telephone handler.
Uses an email address. Uses a telephone number.
Can include subject and body parameters. Can specify a telephone number.
Example: mailto:info@example.com Example: tel:+911234567890

11. Creating a Contact Section

A contact section can contain email and telephone links so visitors can contact a website owner.

Example

<section>

    <h2>Contact Us</h2>

    <p>
        Email:
        <a href="mailto:info@example.com">
            info@example.com
        </a>
    </p>

    <p>
        Phone:
        <a href="tel:+911234567890">
            +91 12345 67890
        </a>
    </p>

</section>

Expected Output

Contact Us

Email: info@example.com

Phone: +91 12345 67890

These demonstration links use example contact details.

12. Complete Practical Example

The following complete HTML5 document demonstrates email links, telephone links, subject parameters, and suggested message text. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Contact Page</title>
</head>

<body>

    <h1>Contact Us</h1>

    <h2>Email Support</h2>

    <p>
        <a href="mailto:support@example.com">
            Email Support
        </a>
    </p>

    <p>
        <a href="mailto:info@example.com?subject=Website%20Enquiry">
            Send an Enquiry
        </a>
    </p>

    <p>
        <a href="mailto:info@example.com?subject=Course%20Enquiry&amp;body=Hello,%20I%20need%20course%20information.">
            Ask About Courses
        </a>
    </p>

    <h2>Telephone Support</h2>

    <p>
        <a href="tel:+911234567890">
            Call Support
        </a>
    </p>

</body>
</html>

Expected Output

Contact Us

Email Support

Email Support

Send an Enquiry

Ask About Courses

Telephone Support

Call Support

Activating these links depends on the email and telephone handlers available on your device.

13. Common Mistakes

Mistake Correct Approach
Using http: instead of mailto: Use the mailto scheme for email links.
Using mailto: for a telephone number Use the tel scheme for telephone links.
Incorrect email address Verify the recipient address.
Missing URL encoding Encode spaces and reserved characters in query values.
Assuming email sends automatically The user normally needs to send the prepared message.
Assuming every device supports tel links Test on devices with compatible telephone handlers.

15. Interview Questions and Answers

Q1. What is the mailto scheme?

It is a URL scheme used to create hyperlinks that open an email handler with a specified recipient.

Q2. What is the tel scheme?

It is a URL scheme used to create telephone links.

Q3. Which HTML element is used to create email links?

The anchor element <a> is used with a mailto: URL in its href attribute.

Q4. How do you create a basic email link?

Use <a href="mailto:info@example.com">Email</a>.

Q5. How do you add a subject to an email link?

Use the subject query parameter after the recipient address.

Q6. How do you add message text to an email link?

Use the body query parameter.

Q7. Which character separates multiple query parameters?

The ampersand (&) separates query parameters.

Q8. Does a mailto link send an email automatically?

No. It normally opens an email handler with a prepared message. The user generally needs to send it.

Q9. How do you create a telephone link?

Use an anchor element with a tel: URL in its href attribute.

Q10. What is the difference between mailto and tel?

mailto opens an email handler, whereas tel opens a compatible telephone handler.

16. Multiple Choice Questions (MCQs)

Q1. Which URL scheme is used for email links?

  1. http:
  2. mailto:
  3. tel:
  4. ftp:

Correct Answer: B. mailto:

Q2. Which URL scheme is used for telephone links?

  1. mailto:
  2. https:
  3. tel:
  4. file:

Correct Answer: C. tel:

Q3. Which parameter is used to specify an email subject?

  1. title
  2. subject
  3. heading
  4. name

Correct Answer: B. subject

Q4. Which parameter is used to specify suggested email text?

  1. body
  2. text
  3. message-id
  4. content

Correct Answer: A. body

Q5. Which character separates multiple query parameters?

  1. #
  2. /
  3. &
  4. :

Correct Answer: C. &

Q6. Which is a valid email link?

  1. <a href="tel:info@example.com">Email</a>
  2. <a href="mailto:info@example.com">Email</a>
  3. <a src="mailto:info@example.com">Email</a>
  4. <mailto>info@example.com</mailto>

Correct Answer: B

Q7. Which is a valid telephone link?

  1. <a href="tel:+911234567890">Call</a>
  2. <a href="mailto:+911234567890">Call</a>
  3. <a src="tel:+911234567890">Call</a>
  4. <tel>+911234567890</tel>

Correct Answer: A

Q8. What does %20 represent in a URL?

  1. Comma
  2. Space
  3. Hash
  4. Colon

Correct Answer: B. Space

Q9. Does a mailto link automatically send a message?

  1. Yes, always
  2. No, it normally opens an email handler
  3. It deletes the email
  4. It opens a telephone application

Correct Answer: B

Q10. Which HTML attribute contains the mailto or tel URL?

  1. src
  2. alt
  3. href
  4. id

Correct Answer: C. href

17. Lesson Summary

  • Email links use the mailto: URL scheme.
  • Telephone links use the tel: URL scheme.
  • The anchor element creates both types of hyperlinks.
  • The subject parameter specifies a suggested email subject.
  • The body parameter specifies suggested message text.
  • The ampersand separates multiple query parameters.
  • URL encoding is important for spaces and reserved characters.
  • Activating a mailto link does not automatically send an email.
  • Telephone links require a compatible telephone handler.
