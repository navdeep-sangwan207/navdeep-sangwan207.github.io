Chapter 5: HTML Links and Navigation

HTML5 – Complete Study Course

Learn hyperlinks, URLs, bookmarks, navigation menus and link attributes.

Chapter Overview

HTML hyperlinks connect webpages, websites, documents and other resources. The anchor element (a) is used to create links through the href attribute.

This chapter explains hyperlink fundamentals, absolute and relative URLs, internal page navigation, email and telephone links, opening links in new tabs, and creating navigation menus.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand hyperlinks and their purpose in HTML.

  • Use the target attribute to control link navigation.
  • Create structured navigation menus using HTML.
