Chapter 5: HTML Links and Navigation

Lesson 6: Target Attribute and New Tabs

1. Introduction to the Target Attribute

The target attribute is used with HTML hyperlinks to specify the browsing context in which the linked resource should open.

A browsing context can be a browser tab, window, or another navigable context such as an iframe.

The target attribute is commonly used to:

  • Open a link in the current tab.
  • Open a link in a new tab or window.
  • Navigate the parent browsing context.
  • Navigate the top-level browsing context.

2. Syntax of the Target Attribute

The target attribute is written inside the opening anchor tag.

Basic Syntax

<a href="URL" target="value">
    Link Text
</a>

Here:

  • a defines the hyperlink.
  • href specifies the destination URL.
  • target specifies the browsing context.
  • value determines where the destination opens.

3. Different Values of the Target Attribute

HTML supports four commonly used predefined target keywords.

Target Value Purpose
_self Opens the linked resource in the current browsing context.
_blank Opens the linked resource in a new browsing context, usually a new tab.
_parent Opens the linked resource in the parent browsing context.
_top Opens the linked resource in the top-level browsing context.

4. Using target="_self"

The _self value opens the linked webpage in the same browsing context in which the link was activated.

Example

<a href="https://www.example.com" target="_self">
    Open Example Website
</a>

The linked webpage replaces the current page in the same tab.

Important: Opening links in the current browsing context is also the default behaviour when the target attribute is omitted.

5. Using target="_blank"

The _blank value opens a linked resource in a new browsing context. In most modern browsers, this means a new tab.

Example

<a href="https://www.example.com" target="_blank">
    Open Example in New Tab
</a>

How It Works

  1. The browser displays the webpage containing the link.
  2. The user clicks the hyperlink.
  3. The browser creates or selects a new browsing context.
  4. The destination webpage loads in that context.
  5. The original webpage normally remains open.
Common Use Cases:
  • Opening external websites.
  • Opening documentation while keeping a lesson open.
  • Opening reference material separately.
  • Providing links to external learning resources.

6. Using target="_parent"

The _parent value opens the linked resource in the parent browsing context of the current document.

This is particularly relevant when a webpage is displayed inside an iframe.

Example

<a href="https://www.example.com" target="_parent">
    Open in Parent Context
</a>

If the document is inside an iframe, the destination replaces the parent context containing that iframe.

If no parent browsing context exists, _parent behaves like _self.

7. Using target="_top"

The _top value opens the linked resource in the top-level browsing context.

It is useful when a page inside nested frames needs to navigate the entire browser tab.

Example

<a href="https://www.example.com" target="_top">
    Open in Top-Level Context
</a>
If the current document is already in the top-level browsing context, _top behaves like _self.

8. Understanding Browsing Contexts

A browsing context is an environment in which a browser displays a document.

Examples include:

  • A normal browser tab.
  • A separate browser window.
  • An iframe embedded inside another webpage.

Conceptual Example

Top-Level Browser Tab
|
|-- Parent Webpage
    |
    |-- iframe
        |
        |-- Embedded Webpage

When an iframe contains a hyperlink:

  • _self navigates the iframe itself.
  • _parent navigates the parent context.
  • _top navigates the top-level context.
  • _blank opens a new browsing context.

9. Named Browsing Contexts

The target attribute can also use a custom name instead of a predefined keyword.

A named target allows multiple links to reuse the same named browsing context.

Example

<a href="https://www.example.com"
   target="learningWindow">
    Open Example
</a>

<a href="https://www.wikipedia.org"
   target="learningWindow">
    Open Wikipedia
</a>

Both links request navigation in the browsing context named learningWindow. Once that context exists, it can be reused rather than creating a new one for every click.

A custom target name is not the same as _blank. The browser can reuse an existing named context.

10. Security Considerations When Using _blank

When opening an external webpage in a new browsing context, developers should consider security and privacy.

Historically, a newly opened page could sometimes access the opening page through the window.opener property. This could create security risks.

Recommended Practice

<a href="https://www.example.com"
   target="_blank"
   rel="noopener noreferrer">
    Visit Example Website
</a>

Understanding the rel Values

Value Purpose
noopener Prevents the opened browsing context from receiving an opener reference to the originating page.
noreferrer Prevents sending the referrer information and also implies noopener behaviour.
Security Note: Modern browsers generally apply implicit noopener behaviour to links using target="_blank". Explicitly adding rel="noopener noreferrer" remains a clear and defensive practice, especially when referrer information should not be shared.

11. Difference Between _self and _blank

_self _blank
Uses the current browsing context. Requests a new browsing context.
Usually replaces the current page. Usually opens a new browser tab.
The original page is replaced. The original page normally remains open.
Common for internal navigation. Often used for external resources.

12. Practical Example: Learning Resource Links

The following example demonstrates how an educational website can open reference resources in new tabs.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Learning Resources</title>
</head>

<body>

    <h1>HTML Learning Resources</h1>

    <p>
        <a href="https://developer.mozilla.org/"
           target="_blank"
           rel="noopener noreferrer">
            Visit MDN
        </a>
    </p>

    <p>
        <a href="https://www.w3.org/"
           target="_blank"
           rel="noopener noreferrer">
            Visit W3C
        </a>
    </p>

    <p>
        <a href="https://html.spec.whatwg.org/"
           target="_blank"
           rel="noopener noreferrer">
            Read HTML Living Standard
        </a>
    </p>

</body>
</html>

Expected Output

HTML Learning Resources

Visit MDN

Visit W3C

Read HTML Living Standard

13. Common Mistakes

Mistake Correct Approach
Writing target="blank" Use target="_blank" for the predefined keyword.
Writing target outside the anchor element Place target inside the opening <a> tag.
Confusing _parent and _top Understand their different browsing-context levels.
Opening external links without considering security Consider rel="noopener noreferrer".
Assuming _blank always means a new tab The browser decides whether to use a tab or window.

15. Interview Questions and Answers

Q1. What is the target attribute in HTML?

It specifies the browsing context in which a linked resource should open.

Q2. What is the purpose of target="_self"?

It opens the linked resource in the current browsing context.

Q3. What is the purpose of target="_blank"?

It requests a new browsing context, commonly displayed as a new browser tab.

Q4. What is the purpose of target="_parent"?

It navigates the parent browsing context.

Q5. What is the purpose of target="_top"?

It navigates the top-level browsing context.

Q6. What is a browsing context?

It is an environment in which a browser displays a document, such as a tab, window, or iframe.

Q7. What is a named browsing context?

It is a browsing context identified by a custom name that can be reused by links.

Q8. Why is rel="noopener" used?

It prevents the opened page from receiving an opener reference to the originating page.

Q9. What is the purpose of rel="noreferrer"?

It prevents referrer information from being sent and also implies noopener behaviour.

Q10. Does target="_blank" always open a new tab?

No. It requests a new browsing context. The browser may display it in a new tab or a new window.

16. Multiple Choice Questions (MCQs)

Q1. Which attribute specifies where a linked resource opens?

  1. href
  2. target
  3. src
  4. alt

Correct Answer: B. target

Q2. Which target value opens a link in the current context?

  1. _blank
  2. _top
  3. _self
  4. _parent

Correct Answer: C. _self

Q3. Which target value requests a new browsing context?

  1. _self
  2. _blank
  3. _parent
  4. _top

Correct Answer: B. _blank

Q4. Which target value navigates the parent context?

  1. _parent
  2. _self
  3. _blank
  4. _top

Correct Answer: A. _parent

Q5. Which target value navigates the top-level context?

  1. _self
  2. _parent
  3. _top
  4. _blank

Correct Answer: C. _top

Q6. Which attribute value can prevent an opened page from receiving an opener reference?

  1. nofollow
  2. noopener
  3. external
  4. alternate

Correct Answer: B. noopener

Q7. Which HTML element commonly contains the target attribute?

  1. <img>
  2. <div>
  3. <a>
  4. <meta>

Correct Answer: C. <a>

Q8. Which is the correct syntax for opening a link in a new browsing context?

  1. <a href="page.html" target="blank">
  2. <a href="page.html" target="_blank">
  3. <a src="page.html" target="_blank">
  4. <a target="_blank">page.html</a>

Correct Answer: B

Q9. Which target value is commonly used with iframe navigation to replace the top-level page?

  1. _self
  2. _blank
  3. _parent
  4. _top

Correct Answer: D. _top

Q10. What does target="_blank" guarantee?

  1. A new tab in every browser
  2. A new window in every browser
  3. A request for a new browsing context
  4. Automatic downloading of the page

Correct Answer: C

17. Lesson Summary

  • The target attribute specifies where a linked resource opens.
  • _self opens the resource in the current context.
  • _blank requests a new browsing context.
  • _parent navigates the parent context.
  • _top navigates the top-level context.
  • Custom target names allow browsing contexts to be reused.
  • rel="noopener" prevents an opener reference.
  • rel="noreferrer" also prevents referrer information from being sent.
  • A new browsing context may appear as a tab or a window.
