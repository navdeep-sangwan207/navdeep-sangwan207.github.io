Chapter 5: HTML Links and Navigation

Lesson 4: Internal Page Links and Bookmarks

1. Introduction to Internal Page Links

Internal page links allow users to navigate directly to a particular section of the same webpage or another webpage.

They are especially useful for long webpages containing multiple headings, chapters, sections, and topics.

An internal page link is commonly called a bookmark link or in-page link when it navigates to a specific location within a document.

Example: A long HTML tutorial may contain a table of contents. Clicking "HTML Forms" takes the user directly to the HTML Forms section instead of requiring manual scrolling.

2. What Is a Bookmark in HTML?

A bookmark is a named location within an HTML document. It allows a hyperlink to navigate directly to that location.

HTML uses the id attribute to identify an element. A hyperlink can refer to that element by using its ID as a fragment identifier.

Basic Structure

<!-- Destination element -->
<h2 id="introduction">Introduction</h2>

<!-- Link to destination -->
<a href="#introduction">
    Go to Introduction
</a>

In this example:

  • id="introduction" identifies the destination element.
  • href="#introduction" refers to that element.
  • The browser navigates to the matching location when the link is activated.

3. Understanding the id Attribute

The id attribute assigns a unique identifier to an HTML element within a document.

It can be used by hyperlinks, CSS, and JavaScript to identify a particular element.

Example

<h1 id="main-heading">
    Welcome to HTML5
</h1>

<p id="description">
    Learn HTML5 step by step.
</p>

Rules and Good Practices for IDs

  • Each ID should be unique within its HTML document.
  • IDs are case-sensitive when matching fragment identifiers.
  • An ID should not contain unnecessary spaces.
  • Use meaningful names that describe the element.
  • IDs can be assigned to headings, paragraphs, sections, and other elements.
Important: Do not assign the same ID to multiple elements in one document. Use a different unique ID for each destination.

4. Understanding the Fragment Identifier (#)

The hash symbol (#) introduces a fragment identifier in a URL.

It identifies a specific location within a resource, commonly an HTML element with a matching ID.

Example

<a href="#contact">
    Go to Contact Section
</a>

<h2 id="contact">
    Contact Us
</h2>

When the link is activated, the browser navigates to the element whose ID is contact.

URL Example

https://www.example.com/about.html#contact
URL Component Meaning
https://www.example.com Website origin
/about.html Webpage path
#contact Fragment identifier for the target location

5. Creating a Bookmark Within the Same Page

A same-page bookmark allows users to jump to another section within the current HTML document.

Step 1: Create the Destination

<h2 id="about">About Us</h2>

<p>
    This section contains information about our website.
</p>

Step 2: Create the Hyperlink

<a href="#about">
    Go to About Us
</a>

How It Works

  1. The destination element receives a unique ID.
  2. The hyperlink uses the same ID with a preceding #.
  3. The browser finds the matching element.
  4. The browser navigates to that location.

6. Creating a Table of Contents

A table of contents is a list of hyperlinks that allows users to navigate directly to different sections of a webpage.

Example

<h1>HTML5 Tutorial</h1>

<h2>Table of Contents</h2>

<ul>
    <li><a href="#introduction">Introduction</a></li>
    <li><a href="#elements">HTML Elements</a></li>
    <li><a href="#attributes">HTML Attributes</a></li>
    <li><a href="#forms">HTML Forms</a></li>
</ul>

<h2 id="attributes">HTML Attributes</h2>
<p>Learn about HTML attributes.</p>

<h2 id="forms">HTML Forms</h2>

7. Creating a Back-to-Top Link

A Back-to-Top link allows users to return to the beginning of a long webpage.

Assign an ID to the top-level element and create a hyperlink pointing to that ID.

Example

<body id="top">

    <h1>My Website</h1>

    <p>Website content goes here.</p>

    <a href="#top">
        Back to Top
    </a>

</body>

When the user activates the link, the browser navigates to the element with the ID top.

8. Linking to a Section on Another Webpage

HTML also allows a hyperlink to point directly to a specific section on another webpage.

The URL contains the destination webpage followed by the fragment identifier.

Example

<a href="about.html#contact">
    Go to Contact Section
</a>

Here, the browser opens about.html and navigates to the element with id="contact", if that element exists.

Destination Page: about.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>About Us</title>
</head>
<body>

    <h1>About Our Website</h1>

    <p>Welcome to our website.</p>

    <h2 id="contact">Contact Us</h2>

    <p>Email: info@example.com</p>

</body>
</html>
Important: The destination page must contain the matching ID. Otherwise, the browser can load the page, but it will not find the requested fragment target.

9. Internal Navigation in a Multi-Page Website

A website may contain several pages, each with multiple sections. You can combine relative URLs and fragment identifiers to navigate between them.

Example Folder Structure

website/
│
├── index.html
│
├── about.html
│
└── courses/
    └── html5.html

From index.html, link to a section in about.html: 

<a href="about.html#contact">
    Contact Section
</a>

From courses/html5.html, link to the About page's Contact section: 

<a href="../about.html#contact">
    Contact Us
</a>

10. Important HTML and Accessibility Considerations

  • Use unique and meaningful IDs.
  • Use descriptive hyperlink text.
  • Place bookmark targets on appropriate elements, such as headings or sections.
  • Use logical heading levels to organize content.
  • Ensure that users can understand the destination from the link text.
  • Test fragment links after changing IDs or moving pages.
Common mistake: If the destination has id="contact", the hyperlink must use href="#contact". A different spelling or capitalization may prevent the intended match.

12. Common Mistakes

Mistake Correct Approach
Missing ID on the destination Assign an ID to the target element.
Incorrect fragment name Use the exact ID after the # symbol.
Duplicate IDs Use unique IDs within each document.
Wrong destination filename Verify the page path before the fragment.
Using vague link text Use meaningful text describing the target section.
Changing an ID without updating links Update every hyperlink that references the changed ID.

14. Interview Questions and Answers

Q1. What is an internal page link?

It is a hyperlink that navigates to a specific section within the same webpage or another page.

Q2. What is a bookmark in HTML?

A bookmark is a named location within a document that can be accessed using a fragment identifier.

Q3. Which attribute identifies a bookmark destination?

The id attribute identifies the destination element.

Q4. What does the # symbol represent in a URL?

It introduces a fragment identifier.

Q5. How do you link to a section on the same page?

Assign an ID to the target element and use href="#id-name" in the hyperlink.

Q6. Can two elements have the same ID in one document?

IDs should be unique within a document.

Q7. Can a link navigate to a section on another webpage?

Yes. Specify the destination page followed by the fragment, such as about.html#contact.

Q8. What is a table of contents in HTML?

It is a list of links that allows users to navigate directly to different sections of a document.

Q9. How do you create a Back-to-Top link?

Assign an ID to the top element and create a hyperlink pointing to that ID.

Q10. What happens if the fragment does not match any element ID?

The browser can still load the document, but it cannot navigate to the requested matching element.

15. Multiple Choice Questions (MCQs)

Q1. Which attribute is commonly used to identify a bookmark destination?

  1. class
  2. id
  3. src
  4. href

Correct Answer: B. id

Q2. Which symbol introduces a fragment identifier?

  1. ?
  2. /
  3. #
  4. &

Correct Answer: C. #

Q3. Which href value links to an element with id="about" on the same page?

  1. href="about"
  2. href="#about"
  3. href="/about"
  4. href="id-about"

Correct Answer: B. href="#about"

Q4. Which is the correct way to link to a section on another page?

  1. href="#about.html"
  2. href="about.html#contact"
  3. href="contact#"
  4. href="id=contact"

Correct Answer: B. href="about.html#contact"

Q5. Which statement about IDs is correct?

  1. IDs should be unique within a document.
  2. Every element must have an ID.
  3. IDs can contain spaces freely.
  4. IDs are used only for images.

Correct Answer: A. IDs should be unique within a document.

Q6. What is a table of contents used for?

  1. Changing text colour
  2. Navigating between document sections
  3. Adding images
  4. Creating tables only

Correct Answer: B. Navigating between document sections

Q7. Which is an example of a Back-to-Top link?

  1. <a href="#top">Back to Top</a>
  2. <a src="top">Back to Top</a>
  3. <top href="back">
  4. <a id="top">Back to Top</a>

Correct Answer: A. href="#top"

Q8. What happens if a fragment does not match an element ID?

  1. The browser always closes.
  2. The page cannot load.
  3. The browser cannot find the intended target element.
  4. The ID is created automatically.

Correct Answer: C. The browser cannot find the intended target element.

Q9. Which element is a suitable bookmark destination?

  1. A heading with a unique ID
  2. Only an image
  3. Only a button
  4. Only a form

Correct Answer: A. A heading with a unique ID

Q10. Which attribute is used in the hyperlink to navigate to a bookmark?

  1. src
  2. href
  3. alt
  4. width

Correct Answer: B. href

16. Lesson Summary

  • Internal links navigate to specific sections of a webpage.
  • Bookmarks identify locations within an HTML document.
  • The id attribute identifies the target element.
  • The # symbol introduces a fragment identifier.
  • href="#section-id" links to a section on the same page.
  • about.html#contact links to a section on another page.
  • Table of contents and Back-to-Top navigation use bookmark links.
  • IDs should be unique within each document.
