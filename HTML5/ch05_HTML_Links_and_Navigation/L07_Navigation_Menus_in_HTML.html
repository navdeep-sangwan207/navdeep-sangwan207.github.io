Chapter 5: HTML Links and Navigation

Lesson 7: Navigation Menus in HTML

1. Introduction to Navigation Menus

A navigation menu is a collection of hyperlinks that helps users move between different pages or sections of a website.

Navigation menus are important because they provide a clear structure and make website content easier to access.

Common Navigation Menu Items

  • Home
  • About Us
  • Services
  • Courses
  • Projects
  • Contact

2. The nav Element

HTML provides the semantic <nav> element to represent a section of a page whose purpose is to provide navigation links.

Syntax

<nav>
    Navigation Links
</nav>

The nav element identifies a major navigation section. It does not automatically create a menu layout or styling.

Important: Use <nav> for significant navigation sections, not necessarily for every individual link on a webpage.

3. Creating a Navigation Menu Using ul, li and a

A common and meaningful structure for a navigation menu uses an unordered list containing list items and anchor links.

HTML Structure

<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

Understanding the Elements

Element Purpose
<nav> Defines a navigation section.
<ul> Creates an unordered list.
<li> Represents an individual list item.
<a> Creates a hyperlink.
href Specifies the destination of a hyperlink.

4. Creating a Horizontal Navigation Menu

By default, list items are displayed vertically. CSS Flexbox can arrange them horizontally.

HTML Code

<nav>
    <ul class="menu">
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="projects.html">Projects</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

CSS Code

.menu {
    list-style: none;
    display: flex;
    gap: 15px;
    margin: 0;
    padding: 0;
}

.menu a {
    text-decoration: none;
    padding: 10px 15px;
}
The HTML creates the navigation structure. CSS controls its visual presentation. The CSS Flexbox technique is covered in greater detail in the separate CSS3 course.

5. Creating a Vertical Navigation Menu

A vertical navigation menu displays links one below another. It is useful for sidebars and dashboard navigation.

HTML Code

<nav>
    <ul class="sidebar-menu">
        <li><a href="index.html">Home</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="projects.html">Projects</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

CSS Code

.sidebar-menu {
    list-style: none;
    margin: 0;
    padding: 0;
}

.sidebar-menu li {
    margin-bottom: 8px;
}

.sidebar-menu a {
    display: block;
    padding: 10px;
    text-decoration: none;
}

6. Creating Navigation Menus with Internal Links

Navigation menus can link to different sections of the same webpage using fragment identifiers.

Example

<nav>
    <ul>
        <li><a href="#home">Home</a></li>
        <li><a href="#about">About</a></li>
        <li><a href="#courses">Courses</a></li>
        <li><a href="#contact">Contact</a></li>
    </ul>
</nav>

<section id="home">
    <h2>Home</h2>
</section>

<section id="about">
    <h2>About</h2>
</section>

<section id="courses">
    <h2>Courses</h2>
</section>

<section id="contact">
    <h2>Contact</h2>
</section>

When a user clicks a menu item, the browser navigates to the corresponding element with the matching id.

7. Creating Navigation Menus with Relative Links

A navigation menu can connect different HTML files within a website using relative URLs.

Example Folder Structure

website/
|
|-- index.html
|-- about.html
|-- courses.html
|-- contact.html
|
|-- projects/
    |-- index.html

Navigation Code in index.html

<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="projects/index.html">Projects</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>
Remember: Relative URLs depend on the location of the current HTML file. Always check the folder structure when writing navigation links.

8. Navigation Menus for NS Learning Hub

An educational website can provide navigation links to its main sections and learning resources.

Example

<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="html5/index.html">HTML5</a></li>
        <li><a href="cpp.html">C++</a></li>
        <li><a href="linux/index.html">Linux</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

This example assumes the listed files and folders exist at the website root.

9. Navigation Menu with an External Link

A navigation menu can also include external websites. Use an absolute URL for an external destination.

Example

<nav>
    <ul>
        <li>
            <a href="index.html">Home</a>
        </li>

        <li>
            <a href="https://developer.mozilla.org/"
               target="_blank"
               rel="noopener noreferrer">
                MDN Documentation
            </a>
        </li>
    </ul>
</nav>

10. Accessible Navigation Menus

Accessibility helps users with different abilities navigate and understand a website.

Accessibility Best Practices

  • Use the semantic <nav> element for major navigation.
  • Provide meaningful link text.
  • Use logical navigation order.
  • Ensure links can be accessed using a keyboard.
  • Maintain sufficient colour contrast.
  • Use visible focus indicators.
  • Avoid vague link labels such as "Click here" when a meaningful label is possible.
  • Use separate navigation sections for different major navigation groups when appropriate.

Accessible Example

<nav aria-label="Main navigation">
    <ul>
        <li>
            <a href="index.html">Home</a>
        </li>

        <li>
            <a href="courses.html">Browse Courses</a>
        </li>

        <li>
            <a href="contact.html">Contact Us</a>
        </li>
    </ul>
</nav>

The aria-label attribute provides an accessible name for the navigation landmark.

11. Difference Between nav and a

nav a
Defines a navigation section. Creates a hyperlink.
Groups navigation content. Points to a destination.
Does not create a link by itself. Uses href to specify a destination.
Semantic sectioning element. Interactive hyperlink element.

12. Complete Practical Example

Create a simple educational website navigation menu. The example below combines semantic HTML and basic CSS.

Complete HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>NS Learning Hub Navigation</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            margin: 0;
        }

        nav {
            background: #174ea6;
            padding: 12px;
        }

        nav ul {
            list-style: none;
            display: flex;
            flex-wrap: wrap;
            gap: 10px;
            margin: 0;
            padding: 0;
        }

        nav a {
            color: white;
            text-decoration: none;
            padding: 10px 15px;
            display: block;
        }

        nav a:hover,
        nav a:focus {
            background: #2878d0;
            text-decoration: underline;
        }

        main {
            padding: 20px;
        }

        @media (max-width: 600px) {
            nav ul {
                flex-direction: column;
            }
        }
    </style>
</head>

<body>

    <header>
        <h1>NS Learning Hub</h1>
    </header>

    <nav aria-label="Main navigation">
        <ul>
            <li><a href="index.html">Home</a></li>
            <li><a href="about.html">About</a></li>
            <li><a href="html5/index.html">HTML5</a></li>
            <li><a href="cpp.html">C++</a></li>
            <li><a href="linux/index.html">Linux</a></li>
            <li><a href="contact.html">Contact</a></li>
        </ul>
    </nav>

    <main>
        <h2>Welcome to NS Learning Hub</h2>

        <p>
            Explore courses, programming lessons,
            and technical learning resources.
        </p>
    </main>

</body>
</html>

Expected Output

NS Learning Hub

  • Home
  • About
  • HTML5
  • C++
  • Linux
  • Contact

Welcome to NS Learning Hub. Explore courses, programming lessons, and technical learning resources.

This is a visual demonstration of the navigation menu.

13. Common Mistakes

Mistake Correct Approach
Using nav without navigation content Use nav for a significant group of navigation links.
Forgetting anchor elements Use <a> to create actual hyperlinks.
Incorrect relative paths Check the current file's location and destination path.
Using meaningless link text Use descriptive link labels.
Using a button for ordinary page navigation Use an anchor for navigation and a button for actions.
Assuming HTML automatically creates a horizontal menu Use CSS to control menu layout and appearance.

15. Interview Questions and Answers

Q1. What is a navigation menu?

It is a collection of links that helps users move between different pages or sections of a website.

Q2. Which HTML element represents a navigation section?

The semantic <nav> element.

Q3. Which elements are commonly used to create a navigation menu?

<nav>, <ul>, <li>, and <a>.

Q4. Does the nav element automatically create a horizontal menu?

No. CSS is used to control the layout and appearance.

Q5. What is the purpose of the ul element in navigation?

It groups navigation links as an unordered list.

Q6. Can a navigation menu contain external links?

Yes. An anchor element can point to an external URL.

Q7. Can navigation links point to sections of the same webpage?

Yes. Fragment identifiers such as #about can link to elements with matching IDs.

Q8. What is aria-label used for in a nav element?

It provides an accessible name to distinguish navigation landmarks, such as Main Navigation and Footer Navigation.

Q9. What is the difference between an anchor and a button?

An anchor navigates to a destination, whereas a button performs an action.

Q10. Why is navigation accessibility important?

It helps users, including keyboard and assistive-technology users, navigate website content effectively.

Q1. Which HTML element defines a navigation section?

  4. <aside>

Correct Answer: B. nav

Q2. Which element creates a hyperlink?

  1. <a>
  2. <li>
  3. <ul>
  4. <nav>

Correct Answer: A. a

Q3. Which element represents an individual list item?

  1. <ol>

  4. <nav>

Correct Answer: C. li

Q4. Which attribute specifies the destination of a hyperlink?

  1. src

  4. class

Q5. Which CSS property removes default list markers?

  1. display
  2. text-decoration
  3. list-style

Correct Answer: C. list-style

Q6. Which CSS layout technique can arrange menu items horizontally?

  1. Flexbox
  2. Audio
  3. Metadata
  4. Form validation

Correct Answer: A. Flexbox

Q7. Which attribute can provide an accessible name for a navigation landmark?

  1. src
  2. aria-label

Correct Answer: B. aria-label

Q8. Which URL links to a section with id="about"?

  1. about.html
  2. /about
  3. #about

Q9. Which element is appropriate for ordinary navigation to another page?

  1. <button>
  2. <a>
  3. <input>

Q10. What is the main purpose of a navigation menu?

  1. To play audio
  2. To collect form data
  3. To help users move through a website

Correct Answer: C

17. Lesson Summary

  • The <nav> element defines a navigation section.
  • The <ul> element groups menu items in an unordered list.
  • The <li> element represents individual menu items.
  • The <a> element creates navigation hyperlinks.
  • Navigation links can point to internal and external destinations.
  • Fragment identifiers link to sections within a webpage.
  • CSS controls horizontal and vertical menu layouts.
  • Accessible navigation uses meaningful link text and appropriate semantics.
  • Use anchors for navigation and buttons for actions.
