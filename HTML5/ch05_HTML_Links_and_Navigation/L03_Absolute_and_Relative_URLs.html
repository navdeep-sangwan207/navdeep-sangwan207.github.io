Chapter 5: HTML Links and Navigation

Lesson 3: Absolute and Relative URLs

1. Introduction to URLs

A URL (Uniform Resource Locator) is an address used to identify and locate a resource on the web or another network-accessible location.

URLs are used in HTML to specify destinations for hyperlinks, images, scripts, stylesheets, and other resources.

Example URL:

https://www.example.com/about.html

In an HTML hyperlink, the URL is commonly specified using the href attribute. 

<a href="https://www.example.com/about.html">
    About Us
</a>

2. Components of a URL

A typical web URL may contain several components. Consider the following example: 

https://www.example.com:443/products/item.html?id=25#details
Component Example Purpose
Scheme https Identifies the protocol or URL scheme.
Host www.example.com Identifies the server or host.
Port 443 Identifies a network service port.
Path /products/item.html Identifies a resource path.
Query ?id=25 Provides query parameters.
Fragment #details Identifies a fragment within the resource.
Note: The example uses HTTPS. Port 443 is the default port for HTTPS, so it is commonly omitted from ordinary HTTPS URLs.

3. Absolute URL

An absolute URL specifies a complete destination address. For a typical web address, it includes the scheme and host, along with any required path, query, or fragment.

Example

<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

Another Example

<a href="https://www.example.com/contact.html">
    Contact Us
</a>

Characteristics of Absolute URLs

  • Identify a destination independently of the current document's directory.
  • Commonly contain a scheme and host for web resources.
  • Can point to external websites.
  • Can point to resources on the same website using a complete URL.
  • Are useful when linking to external resources.

4. Relative URL

A relative URL specifies a resource location in relation to a base URL, usually the current document's URL.

Relative URLs are commonly used to connect pages and resources within the same website.

Example Folder Structure

website/
│
├── index.html
├── about.html
│
├── courses/
│   ├── index.html
│   └── html5.html
│
└── images/
    └── logo.png

Suppose the current page is index.html.

<a href="about.html">About Us</a>

<a href="courses/index.html">Courses</a>

<a href="images/logo.png">View Logo</a>

Each destination is resolved relative to the current page's URL.

Characteristics of Relative URLs

  • Do not need to specify the complete website address.
  • Depend on the base URL used for resolution.
  • Are convenient for internal website navigation.
  • Can use directory paths to reach files in other folders.
  • May need updating when files or folders are moved.

5. Types of Relative Paths

Relative paths can be written in different ways depending on the location of the destination.

5.1 Same Directory

When the destination file is in the same directory as the current HTML file, use its filename. 

website/
├── index.html
└── about.html
<a href="about.html">About Us</a>

5.2 Child Directory

A child directory is a folder located inside the current directory. Use the folder name followed by the destination filename. 

website/
├── index.html
└── courses/
    └── html5.html
<a href="courses/html5.html">
    HTML5 Course
</a>

5.3 Parent Directory

The notation ../ moves one directory level upward from the current document's directory. 

website/
├── index.html
└── courses/
    └── html5.html

If the current page is courses/html5.html, use the following link to reach the root page: 

<a href="../index.html">
    Home
</a>

5.4 Current Directory

The notation ./ refers to the current directory. 

<a href="./about.html">
    About Us
</a>

If about.html is in the current directory, this resolves to the same destination as about.html.

5.5 Multiple Parent Directories

You can use multiple ../ segments to move upward through multiple directory levels. 

website/
├── index.html
└── courses/
    └── html5/
        └── lesson1.html

From lesson1.html, use: 

<a href="../../index.html">
    Website Home
</a>
Remember: One ../ moves up one directory level. Two ../../ segments move up two levels.

6. Root-Relative URLs

A root-relative URL begins with a forward slash (/). It is resolved from the root of the current website origin. 

<a href="/about.html">
    About Us
</a>

For a website hosted at https://www.example.com, this path resolves to: 

https://www.example.com/about.html
Important for GitHub Pages: A project site may be hosted under a repository path, such as https://username.github.io/project/. A root-relative path like /about.html points to the domain root, not automatically to the project directory. For project-site pages, ordinary relative paths are often safer.

7. Absolute URL vs Relative URL

Absolute URL Relative URL
Identifies a complete destination address. Identifies a destination relative to a base URL.
Commonly includes scheme and host. Usually contains a path or filename.
Independent of the current document's directory. Depends on the base URL.
Useful for external website links. Useful for links within a website.
Example: https://example.com/about.html Example: about.html

9. URL Resolution and Base URLs

A relative URL is resolved against a base URL. Usually, this is the current document's URL.

However, an HTML document can contain a <base> element in its head section. It can change the base URL used for resolving relative URLs. 

<head>
    <base href="https://www.example.com/courses/">
</head>

<body>
    <a href="html5.html">
        HTML5 Course
    </a>
</body>

In this example, the relative URL html5.html resolves against the base URL.

The base element affects relative URLs throughout the document. Use it carefully because it can change the behaviour of many links and resource references.

10. Common URL and Path Errors

Error Explanation
Incorrect filename The destination file may not exist.
Incorrect folder name The browser cannot locate the intended resource.
Missing ../ The relative path may resolve from the wrong directory.
Extra ../ The path may move above the intended directory.
Incorrect capitalization Case-sensitive hosting environments may treat differently capitalized names as different files.
Incorrect root-relative path A project site may require a path that includes its repository directory.
GitHub Pages Tip: Test links after deployment. A link that works on a local Windows computer may fail on GitHub Pages if filename capitalization or directory paths are incorrect.

11. Practical Example: Absolute and Relative URLs

The following complete HTML5 document demonstrates both types of URLs. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>URL Examples</title>
</head>
<body>

    <h1>URL Demonstration</h1>

    <h2>Absolute URL</h2>

    <a href="https://www.wikipedia.org">
        Visit Wikipedia
    </a>

    <h2>Relative URL</h2>

    <a href="about.html">
        About Us
    </a>

    <h2>Child Directory</h2>

    <a href="courses/html5.html">
        HTML5 Course
    </a>

    <h2>Parent Directory</h2>

    <a href="../index.html">
        Home Page
    </a>

</body>
</html>

Expected Output

URL Demonstration

Absolute URL

Visit Wikipedia

Relative URL

About Us

Child Directory

HTML5 Course

Parent Directory

Home Page

The relative links work only when their corresponding destination files exist at the specified locations.

13. Interview Questions and Answers

Q1. What is a URL?

A URL (Uniform Resource Locator) is an address used to identify and locate a resource.

Q2. What is an absolute URL?

An absolute URL specifies a complete destination address, independent of the current document's directory.

Q3. What is a relative URL?

A relative URL specifies a destination in relation to a base URL, usually the current document's URL.

Q4. What is the difference between absolute and relative URLs?

An absolute URL identifies a complete destination, whereas a relative URL is resolved against a base URL.

Q5. What does ../ mean in a relative path?

It moves one directory level upward.

Q6. What does ./ mean?

It refers to the current directory.

Q7. What is a root-relative URL?

It is a path beginning with a forward slash that is resolved from the root of the current website origin.

Q8. What is the purpose of the scheme in a URL?

It identifies how the resource is addressed, such as through the HTTP or HTTPS scheme.

Q9. What is the difference between a URL path and a query?

The path identifies a resource location, while the query contains parameters supplied to the resource.

Q10. Why are relative URLs useful in a website?

They make it easier to link pages and resources within a website without repeating the full domain name.

14. Multiple Choice Questions (MCQs)

Q1. What is the full form of URL?

  1. Uniform Resource Locator
  2. Universal Reference Link
  3. Unified Resource Link
  4. Uniform Routing Location

Correct Answer: A. Uniform Resource Locator

Q2. Which is an example of an absolute web URL?

  1. about.html
  2. ../index.html
  3. https://www.example.com
  4. ./contact.html

Correct Answer: C. https://www.example.com

Q3. Which notation moves one directory upward?

  1. ./
  2. ../
  3. //
  4. ./.././

Correct Answer: B. ../

Q4. Which notation represents the current directory?

  1. ../
  2. ./
  3. ../../
  4. /../

Correct Answer: B. ./

Q5. Which URL component identifies the host?

  1. Scheme
  2. Domain or host name
  3. Fragment
  4. Query

Correct Answer: B. Domain or host name

Q6. Which symbol introduces a URL fragment?

  1. ?
  2. &
  3. #
  4. /

Correct Answer: C. #

Q7. Which symbol introduces a URL query?

  1. ?
  2. #
  3. :
  4. @

Correct Answer: A. ?

Q8. Which path moves two directory levels upward?

  1. ../
  2. ./
  3. ../../
  4. ////

Correct Answer: C. ../../

Q9. A root-relative URL begins with which character?

  1. ?
  2. #
  3. /
  4. :

Correct Answer: C. /

Q10. Which HTML element can establish a base URL for relative URLs?

  1. <link>
  2. <base>
  3. <meta>
  4. <url>

Correct Answer: B. <base>

15. Lesson Summary

  • A URL identifies a resource location.
  • An absolute URL specifies a complete destination address.
  • A relative URL is resolved against a base URL.
  • ./ represents the current directory.
  • ../ moves one directory upward.
  • ../../ moves two directory levels upward.
  • A root-relative URL begins with /.
  • URL components include scheme, host, port, path, query, and fragment.
  • Correct relative paths are essential for GitHub Pages navigation.
