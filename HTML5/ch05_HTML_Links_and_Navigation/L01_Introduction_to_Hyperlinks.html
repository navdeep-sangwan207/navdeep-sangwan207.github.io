Chapter 5: HTML Links and Navigation

Lesson 1: Introduction to Hyperlinks

1. Introduction to Hyperlinks

A hyperlink, commonly called a link, is a reference that allows users to navigate from one resource to another. It connects web pages, websites, files, and other resources.

Hyperlinks are one of the fundamental features of the World Wide Web. They make it possible to move between related documents and explore information across different websites.

Example: When you click a link labelled "Visit Google", the browser can open the Google website.

2. What Is a Hyperlink?

A hyperlink is a clickable reference that points to a destination. The destination may be another webpage, a section of the current page, a downloadable file, or another type of resource.

In HTML, hyperlinks are generally created using the anchor element <a> with an href attribute. 

<a href="https://www.example.com">
    Visit Example Website
</a>

In this example:

  • <a> is the anchor element.
  • href specifies the destination.
  • https://www.example.com is the destination URL.
  • Visit Example Website is the visible link text.

The detailed syntax and attributes of the anchor element will be covered in the next lesson.

3. Why Are Hyperlinks Important?

Hyperlinks provide several important functions on the web:

  • Navigation: Allow users to move between webpages.
  • Connectivity: Connect related websites and resources.
  • Information access: Help users find additional information.
  • File access: Provide links to documents and other files.
  • User experience: Make websites easier to explore.
  • Website structure: Connect different sections and pages of a website.

4. How Do Hyperlinks Work?

A hyperlink contains a destination reference. When a user activates the link, the browser processes that reference and performs the appropriate navigation or action.

Basic working process

  1. The browser displays a webpage containing a hyperlink.
  2. The user clicks or otherwise activates the link.
  3. The browser reads the link's destination.
  4. The browser navigates to the destination or handles the requested resource.
  5. The destination content is displayed or the relevant action is performed.
Important: For a normal HTTP or HTTPS link, the browser typically requests the destination resource from a web server. Other URL schemes, such as email or telephone links, may invoke different browser or device behaviour.

5. Basic Structure of a Hyperlink

The basic HTML structure of a hyperlink uses an opening anchor tag, a destination attribute, visible content, and a closing anchor tag. 

<a href="destination">Link Text</a>
Component Purpose
<a> Defines an anchor element.
href Specifies the hyperlink destination.
Destination Identifies the resource to navigate to.
Link Text Visible content that users activate.
</a> Closes the anchor element.

6. Types of Hyperlinks

Hyperlinks can be classified according to the resource or destination they point to.

6.1 External Links

An external link points to a resource on another website or a different web origin. 

<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

6.2 Internal Links

An internal link connects pages or sections within the same website. It is useful for website navigation. 

<a href="about.html">
    About Us
</a>

The exact destination depends on the URL and the location of the current document.

6.3 File Links

A hyperlink can point to a file such as a PDF document, image, or other downloadable resource. 

<a href="notes.pdf">
    Open Study Notes
</a>

6.4 Email Links

A hyperlink can use an email URL scheme to open an email application or service. 

<a href="mailto:info@example.com">
    Send Email
</a>

6.5 Telephone Links

A hyperlink can use the telephone URL scheme to initiate a call on supported devices. 

<a href="tel:+911234567890">
    Call Us
</a>
Email and telephone links will be explained in detail in Lesson 5.

7. Hyperlinks Using Text and Images

A hyperlink can contain text or other suitable HTML content, including an image. The content inside the anchor element becomes the interactive link content.

7.1 Text Hyperlink

<a href="https://www.example.com">
    Visit Example
</a>

7.2 Image Hyperlink

<a href="https://www.example.com">
    <img src="logo.png"
         alt="Example website home page">
</a>

In the second example, clicking the image activates the hyperlink. The image's alternative text helps communicate its purpose when the image cannot be displayed and to users of assistive technology.

8. Hyperlinks and Buttons: Difference

Hyperlinks and buttons may both be clickable, but they serve different purposes in a webpage.

Hyperlink Button
Primarily used for navigation. Primarily used to perform an action.
Generally created using the <a> element with href. Created using the <button> element.
Can navigate to another page or resource. Can submit a form or trigger an operation. 
<!-- Hyperlink: navigation -->
<a href="contact.html">Contact Us</a>

<!-- Button: action -->
<button type="button">Submit</button>
Remember: Do not use a hyperlink as a substitute for a button when the purpose is to perform an action on the current page. Choose the HTML element according to its intended function.

9. Practical Example: Creating a Webpage with Hyperlinks

The following is a complete HTML5 example containing different hyperlinks. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My First Webpage with Links</title>
</head>
<body>

    <h1>Welcome to My Website</h1>

    <p>Explore the following resources:</p>

    <h2>External Website</h2>
    <a href="https://www.wikipedia.org">
        Visit Wikipedia
    </a>

    <h2>Internal Page</h2>
    <a href="about.html">
        About Us
    </a>

    <h2>Study Material</h2>
    <a href="notes.pdf">
        Open PDF Notes
    </a>

    <h2>Contact</h2>
    <a href="mailto:info@example.com">
        Send Email
    </a>

</body>
</html>

Expected Result

Welcome to My Website

Explore the following resources:

External Website

Visit Wikipedia

Internal Page

About Us

Study Material

Open PDF Notes

Contact

Send Email

This is an illustrative preview. The internal page and PDF require the corresponding files to exist in the correct location.

10. Good Practices for Creating Hyperlinks

  • Use meaningful and descriptive link text.
  • Make sure the destination is correct and accessible.
  • Use links for navigation and buttons for actions.
  • Provide meaningful alternative text for linked images.
  • Avoid vague link text such as "Click here" when a descriptive label is possible.
  • Check internal links after moving or renaming files.
  • Use HTTPS URLs when a secure website destination is available.

11. Common Mistakes

Mistake Explanation
Missing href An anchor element without href does not create a normal navigable hyperlink.
Incorrect destination The browser may display an error or navigate to the wrong resource.
Missing closing tag Incorrect markup can affect the structure and behaviour of the document.
Unclear link text Users may not understand where the link will take them.
Missing image alternative text Users relying on assistive technology may not understand the purpose of an image link.

13. Interview Questions and Answers

Q1. What is a hyperlink?

A hyperlink is a clickable reference that connects a webpage or resource to another destination.

Q2. Which HTML element is commonly used to create hyperlinks?

The anchor element, <a>, is commonly used to create hyperlinks.

Q3. What is the purpose of a hyperlink?

It allows users to navigate between webpages, websites, files, and other resources.

Q4. What is the role of the href attribute?

The href attribute specifies the destination of a hyperlink.

Q5. What is an external link?

An external link points to a resource on another website or web origin.

Q6. What is an internal link?

An internal link connects pages or sections within the same website.

Q7. Can an image be used as a hyperlink?

Yes. An image can be placed inside an anchor element to make it clickable.

Q8. What is the difference between a hyperlink and a button?

A hyperlink is primarily used for navigation, whereas a button is primarily used to perform an action.

Q9. Does an anchor element without href create a normal hyperlink?

No. An anchor element without an href attribute does not create a normal navigable hyperlink.

Q10. What is the importance of descriptive link text?

Descriptive link text helps users understand the destination or purpose of a link, including users of assistive technologies.

14. Multiple Choice Questions (MCQs)

Q1. Which HTML element is used to create a hyperlink?

  1. <link>
  2. <a>
  3. <href>
  4. <url>

Correct Answer: B. <a>

Q2. Which attribute specifies the destination of a hyperlink?

  1. src
  2. name
  3. href
  4. target

Correct Answer: C. href

Q3. What does an external link point to?

  1. Only the current paragraph
  2. A resource on another website or web origin
  3. Only an image
  4. Only a form

Correct Answer: B. A resource on another website or web origin

Q4. Which element is primarily used for an action such as submitting a form?

  1. <button>
  2. <a>
  3. <h1>
  4. <p>

Correct Answer: A. <button>

Q5. Can an image be used inside a hyperlink?

  1. No
  2. Only with JavaScript
  3. Yes
  4. Only with CSS

Correct Answer: C. Yes

Q6. Which URL scheme is used for email links?

  1. https:
  2. mailto:
  3. tel:
  4. file:

Correct Answer: B. mailto:

Q7. Which URL scheme is commonly used for telephone links?

  1. tel:
  2. mailto:
  3. http:
  4. ftp:

Correct Answer: A. tel:

Q8. What happens when a user activates a normal HTTP hyperlink?

  1. The browser processes the destination URL
  2. The HTML document is automatically deleted
  3. The browser closes permanently
  4. The operating system restarts

Correct Answer: A. The browser processes the destination URL

Q9. Which is the best example of descriptive link text?

  1. Click here
  2. Press this
  3. Read the HTML5 study guide
  4. Link

Correct Answer: C. Read the HTML5 study guide

Q10. Does an anchor element without href create a normal navigable hyperlink?

  1. Yes, always
  2. No
  3. Only in Chrome
  4. Only with CSS

Correct Answer: B. No

15. Lesson Summary

  • A hyperlink connects one resource to another.
  • The anchor element <a> is commonly used to create hyperlinks.
  • The href attribute specifies the destination.
  • Hyperlinks can point to webpages, files, email addresses, and telephone numbers.
  • Text and images can both be used as link content.
  • Links are primarily for navigation; buttons are primarily for actions.
  • Descriptive link text improves usability and accessibility.
