Chapter 5: HTML Links and Navigation

Lesson 2: Anchor Element and href Attribute

1. Introduction

In HTML, the anchor element is used to create hyperlinks. It allows users to navigate from one webpage or resource to another.

The anchor element is represented by the <a> tag. Its most important attribute is href, which specifies the destination of the hyperlink. 

<a href="https://www.example.com">
    Visit Example
</a>
Important: An anchor element without an href attribute does not create a normal navigable hyperlink.

2. Anchor Element (<a>)

The anchor element is an HTML element used to create hyperlinks to other webpages, files, sections of a document, and other URL-based resources.

Basic Syntax

<a href="URL">Link Text</a>

Consider the following example:

<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

Explanation:

  • <a> is the opening anchor tag.
  • href specifies the destination URL.
  • https://www.wikipedia.org is the destination.
  • Visit Wikipedia is the visible link text.
  • </a> is the closing anchor tag.
Expected Output:

Visit Wikipedia

3. href Attribute

The href attribute stands for Hypertext Reference. It specifies the URL or destination associated with a hyperlink.

When a user activates a link, the browser uses its destination to determine the appropriate navigation or resource action.

Syntax

<a href="destination">Link Text</a>

Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Href Example</title>
</head>
<body>

    <h1>Learning HTML</h1>

    <a href="https://www.google.com">
        Open Google
    </a>

</body>
</html>

Learning HTML

Open Google

4. Understanding the Components of an Anchor Element

Component Description
<a> Defines the anchor element.
href Specifies the hyperlink destination.
URL Identifies the destination resource.
Link Text Visible content that users can activate.
</a> Closes the anchor element.

5. Different Values of href

The href attribute can contain different types of URL values. The destination determines what happens when the link is activated.

5.1 Absolute URL

An absolute URL identifies a resource using a complete URL, generally including the scheme and domain. 

<a href="https://www.example.com/about.html">
    About Example
</a>

5.2 Relative URL

A relative URL identifies a resource in relation to the current document's URL. 

<a href="about.html">
    About Us
</a>
Absolute and relative URLs will be explained in detail in Lesson 3.

5.3 Email URL

The mailto: scheme can be used to create an email link. 

<a href="mailto:info@example.com">
    Send Email
</a>

5.4 Telephone URL

The tel: scheme can be used to create a telephone link. 

<a href="tel:+911234567890">
    Call Us
</a>

5.5 Empty href

An empty href value is written as href="". It resolves to the current document's URL. 

<a href="">
    Current Document
</a>
Avoid using an empty href as a placeholder. If a link does not have a meaningful destination, do not create a misleading link.

5.6 Missing href

<a>Not a Normal Hyperlink</a>

This is an anchor element, but it does not create a normal navigable hyperlink because the href attribute is absent.

6. Link Text

Link text is the visible content placed between the opening and closing anchor tags. 

<a href="courses.html">
    Explore Our Courses
</a>

The text "Explore Our Courses" is the link text.

Good Link Text Practices

  • Use meaningful and descriptive text.
  • Make the destination clear to users.
  • Avoid unnecessary long descriptions.
  • Avoid using only "Click here" or "Read more" when a clearer label is possible.
Better example:

Explore the Complete HTML5 Course

7. Opening and Closing Anchor Tags

The anchor element normally has an opening tag and a closing tag. The link content is placed between them. 

<a href="https://www.example.com">
    Visit Example
</a>

The content between these tags may be text, an image, or other suitable HTML content.

Example with an Image

<a href="https://www.example.com">
    <img src="logo.png"
         alt="Example website">
</a>

Here, the image becomes the clickable content of the hyperlink.

8. Important Attributes of the Anchor Element

The anchor element supports several attributes that control its destination, behaviour, and additional information.

Attribute Purpose
href Specifies the hyperlink destination.
target Specifies the browsing context where the destination opens.
title Provides advisory information about the link.
download Indicates that the linked resource is intended to be downloaded.
rel Describes the relationship between the current document and the linked resource.

The target attribute will be discussed in Lesson 6. The rel and download attributes are additional topics for further study.

9. Practical Example: Multiple Anchor Links

Create a webpage containing different types of hyperlinks. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Anchor Element Practice</title>
</head>
<body>

    <h1>My Learning Resources</h1>

    <p>Visit an external website:</p>

    <a href="https://www.wikipedia.org">
        Wikipedia
    </a>

    <p>Open the HTML5 course:</p>

    <a href="html5/index.html">
        HTML5 Course
    </a>

    <p>Open study material:</p>

    <a href="notes.pdf">
        Download Notes
    </a>

    <p>Contact us:</p>

    <a href="mailto:info@example.com">
        Send Email
    </a>

</body>
</html>

Expected Output

My Learning Resources

Visit an external website:

Wikipedia

Open the HTML5 course:

HTML5 Course

Open study material:

Download Notes

Contact us:

Send Email

Local files must exist at the specified paths for those links to work.

10. Common Mistakes

Mistake Correct Approach
Forgetting href Provide a valid destination when creating a normal hyperlink.
Incorrect URL Verify the destination URL.
Missing closing anchor tag Close the anchor element properly.
Unclear link text Use descriptive link text.
Using a button for navigation Use an anchor element for navigation.
Using an empty href as a placeholder Use a real destination or choose a more appropriate element.

12. Interview Questions and Answers

Q1. What is the anchor element in HTML?

The anchor element is represented by <a> and is used to create hyperlinks.

Q2. What is the href attribute?

The href attribute specifies the URL or destination of a hyperlink.

Q3. What is the full form of href?

href stands for Hypertext Reference.

Q4. Is href compulsory for a normal hyperlink?

Yes. An anchor element needs an href attribute to create a normal navigable hyperlink.

Q5. What is link text?

Link text is the visible content placed inside an anchor element.

Q6. Can an image be placed inside an anchor element?

Yes. An image can be placed inside an anchor element to make it clickable.

Q7. What happens when href is empty?

An empty href value resolves to the current document's URL.

Q8. What is the purpose of the title attribute?

It provides advisory information about the link. It should not replace clear and descriptive link text.

Q9. Can an anchor element link to a PDF file?

Yes. Its href attribute can point to a PDF file.

Q10. What is the difference between href and target?

href specifies the destination, while target specifies the browsing context in which that destination is opened.

13. Multiple Choice Questions (MCQs)

Q1. Which tag creates a hyperlink?

  1. <p>
  2. <a>
  3. <div>
  4. <h1>

Correct Answer: B. <a>

Q2. What is the purpose of href?

  1. To specify the destination
  2. To change font size
  3. To create a heading
  4. To insert an image

Correct Answer: A. To specify the destination

Q3. What does href stand for?

  1. Hypertext Reference
  2. Hyperlink Format
  3. High Reference
  4. HTML Reference File

Correct Answer: A. Hypertext Reference

Q4. Which attribute specifies where a link opens?

  1. href
  2. src
  3. target
  4. alt

Correct Answer: C. target

Q5. Which scheme is used for email hyperlinks?

  1. tel:
  2. mailto:
  3. https:
  4. file:

Correct Answer: B. mailto:

Q6. Which scheme is used for telephone hyperlinks?

  1. mailto:
  2. http:
  3. tel:
  4. ftp:

Correct Answer: C. tel:

Q7. What does an anchor element without href create?

  1. A normal hyperlink
  2. A normal navigable link with no destination
  3. An anchor element without a normal hyperlink destination
  4. An image

Correct Answer: C. An anchor element without a normal hyperlink destination

Q8. Which attribute provides advisory information about a link?

  1. title
  2. src
  3. width
  4. class

Correct Answer: A. title

Q9. Can an anchor element contain an image?

  1. No
  2. Yes
  3. Only with CSS
  4. Only with JavaScript

Correct Answer: B. Yes

Q10. Which attribute specifies the destination URL?

  1. target
  2. href
  3. title
  4. rel

Correct Answer: B. href

14. Lesson Summary

  • The anchor element is represented by <a>.
  • The href attribute specifies the hyperlink destination.
  • Link text is the visible content inside the anchor element.
  • Anchor elements can contain text and images.
  • href can contain absolute URLs, relative URLs, and other supported URL schemes.
  • An anchor element without href is not a normal navigable hyperlink.
  • Other useful attributes include target, title, rel, and download.
