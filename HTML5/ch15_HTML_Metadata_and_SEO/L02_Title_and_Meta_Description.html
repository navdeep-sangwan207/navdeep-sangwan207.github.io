Lesson 2: Title and Meta Description

Chapter 15: HTML Metadata and SEO

Learn how to define meaningful HTML page titles and meta descriptions, understand search result snippets and apply metadata best practices.

1. Introduction

Every web page should have a meaningful document title and an appropriate description. These help users understand the page and help browsers and search engines process its information.

HTML provides the <title> element and the <meta> element to define these details.

Basic Example

<head> <title>HTML5 Complete Course</title> <meta name="description" content="Learn HTML5 with practical examples and exercises."> </head>
The title element and meta description serve different purposes. The title defines the document's title, while the description provides a summary of the page.

2. Understanding the Title Element

The <title> element defines the title of an HTML document.

It must be placed inside the <head> element.

Syntax

<title>Page Title</title>

Example

<!DOCTYPE html> <html lang="en"> <head> <title>Introduction to HTML5</title> </head> <body> <h1>Introduction to HTML5</h1> <p> Welcome to the HTML5 learning course. </p> </body> </html>

Expected Result

The browser tab generally displays: Introduction to HTML5

The page body displays the heading and paragraph.

Where Is the Title Used?

  • Browser tabs and windows.
  • Browser bookmarks and favorites.
  • Search engine result titles, when selected by the search engine.
  • Link previews and other interfaces that use document title information.

3. Characteristics of a Good Page Title

A good page title should accurately describe the content of the page.

Important Characteristics

  1. It should describe the page accurately.
  2. It should be unique for each important page.
  3. It should be concise and meaningful.
  4. It should use important topic words naturally.
  5. It should avoid unnecessary repetition.
  6. It should match the actual page content.
  7. It should identify the website or brand when useful.

Good and Poor Examples

Page Title Evaluation
HTML5 Complete Course – NS Learning Hub Good: descriptive and relevant.
Home Poor: too generic.
HTML HTML HTML HTML HTML Poor: keyword repetition.
HTML Forms and Input Elements Good: clearly identifies the topic.
Welcome to Our Website Often too generic for a specific lesson.
There is no universal fixed character limit for HTML titles. Search engines may truncate or rewrite titles depending on the available display space and the user's device.

4. Understanding the Meta Description

The meta description provides a short summary of the content of a web page.

It is defined using the meta element with name="description".

Syntax

<meta name="description" content="Description of the web page.">

Example

<head> <title>HTML Forms – HTML5 Course</title> <meta name="description" content="Learn HTML forms, input types, validation and form submission."> </head>

Purpose of Meta Description

  • Summarizes the page content.
  • Helps users understand what a page offers.
  • May be displayed in search result snippets.
  • Can help users decide whether to visit a page.
Search engines are not required to display your meta description. They may generate a different snippet from the page content when it better matches a user's search.

5. Understanding a Search Result Snippet

A search result snippet is a short description displayed below a search result title.

Illustrative Search Result

NS Learning Hub
HTML5 Complete Course – NS Learning Hub
https://example.com/html5/
Learn HTML5 from beginner to advanced with practical lessons, examples, exercises and interview questions.

This is an illustrative example, not a live search engine result.

Components

  1. Title: Describes the page.
  2. URL: Identifies the page address.
  3. Snippet: Summarizes the page content.

6. Writing an Effective Meta Description

Best Practices

  1. Write a unique description for each important page.
  2. Summarize the actual content of the page.
  3. Use natural language.
  4. Include relevant topic terms naturally.
  5. Explain what the user can learn or do.
  6. Avoid keyword stuffing.
  7. Avoid duplicate descriptions across many pages.
  8. Do not promise content that the page does not provide.

Poor Description

<meta name="description" content="HTML HTML5 CSS JavaScript course HTML learning HTML tutorials best HTML">

Improved Description

<meta name="description" content="Learn HTML5 through structured lessons, practical examples, coding exercises and interview preparation.">
Google does not specify a fixed character limit for meta descriptions. Snippets are truncated as needed based on the display context.

7. Difference Between Title and Meta Description

Title Element Meta Description
Uses the title element. Uses the meta element.
Defines the document title. Summarizes page content.
Usually appears in the browser tab. Does not normally appear in the page body.
May be used as a search result title. May be used as a search result snippet.
Written between opening and closing tags. Written in the content attribute.

Combined Example

<head> <title>HTML Tables – HTML5 Course</title> <meta name="description" content="Learn HTML tables, rows, columns, captions and accessible table structures."> </head>

8. Title and Description for Different Website Pages

Different pages should have titles and descriptions that reflect their individual content.

Homepage

<title>NS Learning Hub – Technical Courses</title> <meta name="description" content="Explore technical courses in programming, embedded systems, Linux and electronics.">

HTML5 Course Page

<title>HTML5 Course – NS Learning Hub</title> <meta name="description" content="Study HTML5 from basic document structure to advanced APIs through organized lessons.">

Individual Lesson Page

<title>HTML Forms – Lesson 1 | HTML5 Course</title> <meta name="description" content="Understand HTML forms, form controls and how browsers collect user input.">
For a learning portal with many lesson pages, create a distinct title and description that accurately match each lesson.

9. Common Mistakes

Mistake Better Practice
Missing title element. Provide a meaningful document title.
Same title on every page. Write page-specific titles.
Missing description. Add a useful description to important pages.
Unrelated description. Describe the actual page content.
Keyword stuffing. Use natural language.
Assuming the description always appears in Google. Understand that search engines may generate another snippet.
Using a heading instead of a title element. Use both for their separate purposes.

10. Practical Exercise

Task: Create Metadata for a Course Website

Create an HTML page for a programming course. Add a meaningful title and meta description.

Requirements

  1. Set the document title to C Programming Course.
  2. Add a description about learning C programming.
  3. Add author metadata.
  4. Declare UTF-8 encoding.
  5. Add viewport metadata.
  6. Display a heading and paragraph in the body.

Sample Solution

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>C Programming Course</title> <meta name="description" content="Learn C programming fundamentals, functions, arrays, pointers and structures."> <meta name="author" content="NS Learning Hub"> </head> <body> <h1>C Programming Course</h1> <p> Learn C programming with practical examples. </p> </body> </html>
Expected Result:
  • The browser tab displays C Programming Course.
  • The page displays the C Programming Course heading.
  • The page displays the introductory paragraph.
  • The browser can read the declared metadata.

11. Interview Questions and Answers

Q1. What is the purpose of the title element?
It defines the title of an HTML document, generally displayed in the browser tab.
Q2. Where should the title element be placed?
Inside the head element.
Q3. What is a meta description?
It is a short summary of a web page defined using the meta element.
Q4. Which attribute identifies a meta description?
The name attribute with the value description.
Q5. Which attribute contains the description text?
The content attribute.
Q6. Does a meta description directly improve Google ranking?
Google does not use the meta description as a direct ranking factor. It can influence the snippet shown in search results.
Q7. What is a search result snippet?
It is the descriptive text displayed beneath a search result title.
Q8. Can search engines rewrite a meta description?
Yes. They may generate a snippet from page content that better matches the user's search.
Q9. Should every page have the same title?
No. Important pages should have unique, descriptive titles.
Q10. Is there a fixed title character limit?
There is no universal fixed HTML title limit. Search engines may truncate titles based on display width and context.
Q11. What is keyword stuffing?
It is the excessive or unnatural repetition of keywords in an attempt to influence search ranking.
Q12. Can a heading replace the title element?
No. The title defines the document title, while headings organize visible page content.
Q13. Where is the meta description written?
It is normally written inside the head element.
Q14. What makes a good page title?
A good title is unique, concise, descriptive and relevant to the page.
Q15. What makes a good meta description?
It accurately summarizes the page and explains its value using natural, useful language.

13. Lesson Summary

  • The title element defines the HTML document title.
  • The title element belongs inside head.
  • The browser usually displays the title in its tab.
  • The meta description summarizes page content.
  • The description uses name="description".
  • The content attribute contains the description text.
  • Search engines may use the description for result snippets.
  • Search engines can generate their own snippets.
  • Each important page should have a unique, relevant title.
  • Useful page content matters more than keyword stuffing.
