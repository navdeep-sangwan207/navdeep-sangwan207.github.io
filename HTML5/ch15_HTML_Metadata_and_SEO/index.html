Chapter 15: HTML Metadata and SEO

HTML5 – Complete Study Course

Chapter Overview

HTML metadata provides information about a web page that is not generally displayed as the main page content. It is primarily defined inside the <head> element.

Metadata helps browsers, search engines and social media platforms interpret and present web pages. Proper document titles, descriptions, character encoding and viewport settings also improve usability and discoverability.

Important: SEO (Search Engine Optimization) involves more than HTML metadata. Content quality, accessibility, page performance, mobile usability, security and external signals also influence search visibility.

Important HTML Elements and Attributes

  • <head> – Contains document metadata.
  • <title> – Defines the document title.
  • <meta> – Provides metadata.
  • <link> – Defines relationships with external resources.
  • charset – Specifies character encoding.
  • name – Identifies a metadata name.
  • content – Provides metadata content.
  • rel – Specifies a link relationship.
  • href – Specifies a resource URL.
  • lang – Identifies the language of content.
