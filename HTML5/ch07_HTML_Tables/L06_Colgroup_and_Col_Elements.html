Lesson 6: Colgroup and Col Elements

Grouping HTML table columns and applying column-level formatting

1. Introduction

HTML provides two elements that help organize and format table columns:

  • <colgroup> – Groups one or more columns in a table.
  • <col> – Represents one or more columns within a column group.

These elements allow developers to apply certain styles to entire columns without adding a class or style to every individual cell.

They are useful when creating marksheets, employee reports, financial tables, and other structured data tables.

2. The colgroup Element

The <colgroup> element stands for Column Group. It groups columns in an HTML table.

Syntax

<table>

    <colgroup>
        <col>
        <col>
    </colgroup>

    <!-- Table rows -->

</table>

The colgroup element is placed inside the table, normally after the optional caption and before the table row groups.

Example

<table border="1">

    <colgroup>
        <col>
        <col>
        <col>
    </colgroup>

    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>Physics</td>
        <td>85</td>
    </tr>

</table>

Expected Output

Name Subject Marks
Rahul Physics 85

The colgroup element groups the three columns. Individual col elements represent the columns within that group.

3. The col Element

The <col> element represents one or more columns in a table column group.

It is a void element, which means it does not have a closing tag or child content.

Syntax

<colgroup>
    <col>
    <col>
    <col>
</colgroup>

Each col element represents a column or a specified number of consecutive columns.

Example

<table>

    <colgroup>
        <col>
        <col>
        <col>
    </colgroup>

    <!-- Table content -->

</table>

In this example, the three col elements represent three consecutive table columns.

4. Applying Background Colors to Columns

One common use of colgroup and col is applying background colors to specific columns.

Example

<table border="1">

    <colgroup>
        <col style="background-color: lightblue;">
        <col style="background-color: lightyellow;">
        <col style="background-color: lightgreen;">
    </colgroup>

    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>Physics</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Priya</td>
        <td>Mathematics</td>
        <td>92</td>
    </tr>

</table>

Expected Output

Name Subject Marks
Rahul Physics 85
Priya Mathematics 92

Each column has a different background color.

5. Using the span Attribute

The span attribute specifies how many consecutive columns a col or colgroup element represents.

Syntax

<col span="number">

Example

<table border="1">

    <colgroup>
        <col span="2" style="background-color: lightblue;">
        <col style="background-color: lightyellow;">
    </colgroup>

    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>Physics</td>
        <td>85</td>
    </tr>

</table>

Expected Output

Name Subject Marks
Rahul Physics 85

Here, the first col element represents two columns. The second col element represents the third column.

Important: The span attribute specifies the number of columns represented. It does not merge cells. Cell merging is performed using rowspan and colspan.

6. Grouping Columns with colgroup

A table can contain multiple column groups to organize different sets of columns.

Example

<table border="1">

    <colgroup>
        <col span="2" style="background-color: lightblue;">
    </colgroup>

    <colgroup>
        <col style="background-color: lightyellow;">
        <col style="background-color: lightgreen;">
    </colgroup>

    <tr>
        <th>Name</th>
        <th>Department</th>
        <th>Salary</th>
        <th>Location</th>
    </tr>

    <tr>
        <td>Amit</td>
        <td>Engineering</td>
        <td>40000</td>
        <td>Delhi</td>
    </tr>

</table>

Expected Output

Name Department Salary Location
Amit Engineering 40000 Delhi

The first column group covers Name and Department. The second column group covers Salary and Location.

7. CSS Properties Supported on Columns

The col and colgroup elements have limited CSS styling support. They are not equivalent to ordinary table cells.

CSS properties that can affect columns include:

  • background – Sets a column background.
  • border – Applies borders under specific table border conditions.
  • visibility – Can hide a column using collapse.
  • width – Specifies a preferred column width.

Example

<style>
    table {
        width: 100%;
        border-collapse: collapse;
    }

    th, td {
        border: 1px solid #333;
        padding: 10px;
    }

    col.first-column {
        width: 30%;
    }

    col.second-column {
        width: 45%;
    }

    col.third-column {
        width: 25%;
    }
</style>

<table>
    <colgroup>
        <col class="first-column">
        <col class="second-column">
        <col class="third-column">
    </colgroup>

    <tr>
        <th>Name</th>
        <th>Department</th>
        <th>Salary</th>
    </tr>

    <tr>
        <td>Amit</td>
        <td>Engineering</td>
        <td>40000</td>
    </tr>
</table>
Important: Properties such as padding, text-align, and font-size generally do not apply directly to col elements. Apply those styles to the th and td cells instead.

8. Colgroup and Col Placement Rules

  • colgroup is placed inside the table element.
  • It appears after caption, if present, and before the table row groups.
  • col elements are placed inside colgroup when defining individual column groups.
  • A col element is a void element and has no closing tag.
  • A colgroup can contain col elements or use its own span attribute when it has no col children.
  • Do not use span on colgroup when it contains col elements.

Two Valid Approaches

Approach 1: Using col elements

<colgroup>
    <col>
    <col>
    <col>
</colgroup>

Approach 2: Using span on colgroup

<colgroup span="3">
</colgroup>

Both approaches can represent three columns. Do not combine the span attribute with child col elements in the same colgroup.

9. Difference Between colgroup and col

Feature colgroup col
Full form Column Group Column
Purpose Groups columns Represents columns

Can contain children? Can contain col elements No, it is a void element
Span attribute Yes, when it has no col children Yes

10. Common Mistakes

Mistake 1: Placing colgroup Inside tr

Incorrect:

<tr>
    <colgroup>
        <col>
    </colgroup>
</tr>

Correct:

<table>
    <colgroup>
        <col>
    </colgroup>

    <tr>
        <td>Data</td>
    </tr>
</table>

Mistake 2: Adding a Closing col Tag

The col element is a void element. Write <col>, not a separate closing tag.

Mistake 3: Confusing span with colspan

The span attribute on col represents multiple columns. The colspan attribute on a table cell merges cell positions.

Mistake 4: Applying Unsupported CSS Properties

Not every CSS property works directly on col or colgroup. Apply text formatting and padding to individual cells.

12. Interview Questions and Answers

Q1. What is the colgroup element?

It groups one or more columns in an HTML table.

Q2. What is the col element?

It represents one or more columns within a table's column group.

Q3. Where is colgroup placed?

It is placed inside the table, before the table row groups.

Q4. Is col a void element?

Yes. It does not have a closing tag or child content.

Q5. What is the purpose of the span attribute on col?

It specifies how many consecutive columns the col element represents.

Q6. Can colgroup contain multiple col elements?

Yes. It can contain multiple col elements.

Q7. Can colgroup use span?

Yes, when it does not contain col elements.

Q8. Can colgroup and col be used for background colors?

Yes. Their background styling can be used to format table columns.

Q9. Is col the same as td?

No. Col represents columns for column-level formatting, while td represents an actual data cell.

Q10. What is the difference between colspan and col span?

colspan merges a table cell across columns. The span attribute on col specifies how many columns that col represents.

Q10. What is the main purpose of colgroup and col?

In this lesson, you learned how to organize and format HTML table columns using colgroup and col.

  • colgroup groups table columns.
  • col represents one or more columns.
  • The span attribute specifies the number of columns represented.
  • Column-level background and width styling can be applied.
  • col is a void element.
  • colgroup is placed before the table row groups.
