Lesson 5: Rowspan and Colspan

Merging HTML table cells horizontally and vertically

1. Introduction

HTML tables normally display data in individual rows and columns. Sometimes, a table needs a cell that occupies more than one column or more than one row.

HTML provides two attributes for this purpose:

  • colspan: Merges a cell across multiple columns.
  • rowspan: Merges a cell across multiple rows.

Both attributes are used with the <td> and <th> elements.

2. Colspan Attribute

The colspan attribute specifies how many columns a table cell should span horizontally.

Syntax

<td colspan="number">
    Content
</td>

For example, colspan="2" makes one cell occupy the width of two columns.

Example: Merging Two Columns

<table border="1">
    <tr>
        <th colspan="2">Student Information</th>
    </tr>

    <tr>
        <td>Name</td>
        <td>Rahul</td>
    </tr>
</table>

Expected Output

Student Information
Name Rahul

The heading occupies both columns because its colspan value is 2.

3. Colspan with Multiple Columns

You can use colspan to merge three or more columns.

Example

<table border="1">
    <tr>
        <th colspan="3">Examination Result</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Aman</td>
        <td>Physics</td>
        <td>85</td>
    </tr>
</table>

Expected Output

Examination Result
Name Subject Marks
Aman Physics 85

The first heading spans all three columns.

4. Rowspan Attribute

The rowspan attribute specifies how many rows a table cell should span vertically.

Syntax

<td rowspan="number">
    Content
</td>

For example, rowspan="2" makes one cell occupy the space of two rows.

Example: Merging Two Rows

<table border="1">
    <tr>
        <th>Name</th>
        <th>Subject</th>
    </tr>

    <tr>
        <td rowspan="2">Rahul</td>
        <td>Physics</td>
    </tr>

    <tr>
        <td>Mathematics</td>
    </tr>
</table>

Expected Output

Name Subject
Rahul Physics
Mathematics

Rahul's cell occupies two rows, so the second row does not need another name cell.

5. Rowspan with Multiple Rows

The rowspan attribute can span more than two rows.

Example

<table border="1">
    <tr>
        <th>Department</th>
        <th>Employee</th>
    </tr>

    <tr>
        <td rowspan="3">Engineering</td>
        <td>Amit</td>
    </tr>

    <tr>
        <td>Neha</td>
    </tr>

    <tr>
        <td>Rohit</td>
    </tr>
</table>

Expected Output

Department Employee
Engineering Amit
Neha
Rohit

The Engineering cell spans three employee rows.

6. Difference Between Rowspan and Colspan

Feature Colspan Rowspan
Purpose Merges columns Merges rows
Direction Horizontal Vertical
Example colspan="2" rowspan="2"
Common use Group headings Group related records

7. Using Rowspan and Colspan Together

Both attributes can be used in the same table to create more complex layouts.

Example: Class Timetable

<table border="1">
    <tr>
        <th>Day</th>
        <th>9 AM - 10 AM</th>
        <th>10 AM - 11 AM</th>
        <th>11 AM - 12 PM</th>
    </tr>

    <tr>
        <th rowspan="2">Monday</th>
        <td>HTML</td>
        <td colspan="2">Programming Lab</td>
    </tr>

    <tr>
        <td>CSS</td>
        <td>JavaScript</td>
        <td>Revision</td>
    </tr>

    <tr>
        <th>Tuesday</th>
        <td colspan="3">Project Work</td>
    </tr>
</table>

Expected Output

Day 9 AM - 10 AM 10 AM - 11 AM 11 AM - 12 PM
Monday HTML Programming Lab
CSS JavaScript Revision
Tuesday Project Work

In this example:

  • Monday spans two rows using rowspan.
  • Programming Lab spans two columns using colspan.
  • Project Work spans three columns using colspan.

8. Using Colspan in a Table Footer

Colspan is frequently used in table footers to create summary rows.

Example: Invoice Table

<table border="1">
    <thead>
        <tr>
            <th>Product</th>
            <th>Quantity</th>
            <th>Price</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Keyboard</td>
            <td>2</td>
            <td>1000</td>
        </tr>

        <tr>
            <td>Mouse</td>
            <td>1</td>
            <td>500</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td colspan="2">Grand Total</td>
            <td>2500</td>
        </tr>
    </tfoot>
</table>

Expected Output

Product Quantity Price
Keyboard 2 1000
Mouse 1 500
Grand Total 2500

The Grand Total cell spans the Product and Quantity columns.

9. Important Rules

  • colspan specifies the number of columns occupied by a cell.
  • rowspan specifies the number of rows occupied by a cell.
  • Both attributes are used on td and th elements.
  • The default span for both attributes is one cell.
  • Use positive integer values for ordinary cell spans.
  • A cell spanning multiple columns or rows replaces the corresponding positions in the table grid.
  • Do not add extra cells where a previous cell already occupies that position.
Technical note: A colspan value of zero has special behavior in HTML and can span the remaining columns in its column group. For beginner-level tables, use explicit positive values such as 2 or 3.

10. Common Mistakes

Mistake 1: Incorrect Column Count

If a cell uses colspan="2", it occupies two column positions. Do not add two more cells in the same row unless the total grid is intended to contain additional columns.

Mistake 2: Adding an Extra Cell After Rowspan

If a cell spans two rows, do not create another cell for the same column in the following row.

Mistake 3: Confusing the Directions

  • colspan = horizontal merging.
  • rowspan = vertical merging.

Mistake 4: Using Invalid Values

Use appropriate integer values for the span attributes. Avoid zero or negative values when learning ordinary cell merging.

12. Interview Questions and Answers

Q1. What is colspan in HTML?

Colspan is an attribute that makes a table cell span multiple columns.

Q2. What is rowspan in HTML?

Rowspan is an attribute that makes a table cell span multiple rows.

Q3. Which direction does colspan work in?

It works horizontally across columns.

Q4. Which direction does rowspan work in?

It works vertically across rows.

Q5. Where can colspan be used?

It can be used with td and th elements.

Q6. What does colspan="3" mean?

The cell occupies three columns.

Q7. What does rowspan="2" mean?

The cell occupies two rows.

Q8. Can rowspan and colspan be used together?

Yes. Both attributes can be used in the same table.

Q9. What happens to the next row when a cell uses rowspan?

The spanning cell continues to occupy its column position, so another cell should not be added in that position.

Q10. Give one practical use of colspan.

It can be used to create a heading across several columns or a total label in an invoice.

13. Multiple Choice Questions (MCQs)

Q1. Which attribute merges columns?

A. rowspan

B. colspan

C. merge

D. column

Answer: B. colspan

Q2. Which attribute merges rows?

A. rowspan

B. colspan

C. merge

D. row

Answer: A. rowspan

Q3. What does colspan="3" mean?

A. Three rows

B. Three columns

C. Three tables

D. Three headings

Answer: B. Three columns

Q4. What does rowspan="2" mean?

A. Two columns

B. Two tables

C. Two rows

D. Two headings

Answer: C. Two rows

Q5. Which elements support rowspan and colspan?

A. html and body

B. td and th

C. head and title

D. div and span

Answer: B. td and th

Q6. Which attribute is suitable for a heading across four columns?

A. rowspan="4"

B. colspan="4"

C. width="4"

D. merge="4"

Answer: B. colspan="4"

Q7. Which attribute is useful for grouping a department across three employee rows?

A. colspan="3"

B. rowspan="3"

C. width="3"

D. height="3"

Answer: B. rowspan="3"

Q8. Can rowspan and colspan be used in one table?

A. Yes

B. No

C. Only with CSS

D. Only with JavaScript

Answer: A. Yes

Q9. Which attribute is commonly used for a Grand Total label spanning two columns?

A. rowspan="2"

B. colspan="2"

C. height="2"

D. rows="2"

Answer: B. colspan="2"

Q10. What should be avoided when using rowspan?

A. Using table rows

B. Adding another cell in an already occupied grid position

C. Using CSS

D. Using th elements

Answer: B. Adding another cell in an already occupied grid position

14. Lesson Summary

In this lesson, you learned how to merge HTML table cells using the rowspan and colspan attributes.

  • colspan merges cells horizontally.
  • rowspan merges cells vertically.
  • Both attributes work with td and th elements.
  • Both can be used together in complex tables.
  • They are useful for timetables, invoices, reports, and marksheets.
