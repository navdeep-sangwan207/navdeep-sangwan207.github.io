Lesson 1: Introduction to HTML Tables

Understanding the purpose, structure, and basic syntax of HTML tables

1. Introduction to HTML Tables

An HTML table is used to display structured data in rows and columns. It helps organize related information so that users can easily read, compare, and understand it.

HTML provides special elements for creating tables. These elements define the table itself, its rows, its data cells, and its header cells.

Common examples of information displayed using tables include:

  • Student marksheets and examination results.
  • Employee records and attendance details.
  • Product prices and comparison charts.
  • Monthly sales reports.
  • Financial and statistical information.
  • Class and examination timetables.

2. Why Do We Use HTML Tables?

Tables are useful when information has a meaningful relationship between rows and columns.

Example: Student Records

Suppose we want to display the names and marks of students:

Roll No. Name Subject Marks
101 Rahul Mathematics 85
102 Priya Mathematics 92
103 Aman Mathematics 78

Each row represents one student's record, while each column represents a particular category of information.

3. Basic Structure of an HTML Table

The main HTML elements used to create a basic table are:

  • <table> – Defines the table.
  • <tr> – Defines a table row.
  • <th> – Defines a header cell.
  • <td> – Defines a data cell.

Basic Syntax

<table>
    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
    </tr>

    <tr>
        <td>Data 1</td>
        <td>Data 2</td>
    </tr>
</table>

Explanation

  • <table> starts the table.
  • <tr> creates a row.
  • <th> creates a header cell.
  • <td> creates a normal data cell.
  • Closing tags mark the end of each element.

4. First HTML Table Example

Let's create a simple table containing three students and their marks.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Marks</title>
</head>
<body>

    <h2>Student Marks</h2>

    <table border="1">
        <tr>
            <th>Roll No.</th>
            <th>Name</th>
            <th>Marks</th>
        </tr>

        <tr>
            <td>101</td>
            <td>Rahul</td>
            <td>85</td>
        </tr>

        <tr>
            <td>102</td>
            <td>Priya</td>
            <td>92</td>
        </tr>

        <tr>
            <td>103</td>
            <td>Aman</td>
            <td>78</td>
        </tr>
    </table>

</body>
</html>

Expected Browser Output

Roll No. Name Marks
101 Rahul 85
102 Priya 92
103 Aman 78
Important: The border="1" attribute is an obsolete presentational attribute in modern HTML. It is shown here only to explain older examples. Use CSS border properties to style table borders in modern websites.

5. Understanding Rows and Columns

An HTML table organizes information using horizontal rows and vertical columns.

  • Row: A horizontal arrangement of cells.
  • Column: A vertical arrangement of cells.
  • Cell: An individual box containing data or a heading.

Example

Product Price Quantity
Laptop 50000 2
Keyboard 1200 5

This table contains three columns and three rows. The first row contains headings, and the remaining rows contain data.

6. Difference Between th and td

Feature th Element td Element
Purpose Defines a header cell Defines a data cell
Typical use Column or row heading Table information
Default appearance Usually bold and centered Usually normal weight and left-aligned

The default appearance is controlled by browser styles and can be changed using CSS. The semantic purpose of each element remains different.

7. HTML Tables vs Page Layout

HTML tables should be used for displaying tabular data, not for arranging the overall layout of a webpage.

Use tables for:

  • Student result sheets.
  • Product comparison data.
  • Financial reports.
  • Timetables and schedules.

Use CSS for:

  • Website navigation layouts.
  • Header and footer positioning.
  • Page columns and sidebars.
  • Responsive card layouts.
Best Practice: Use semantic HTML elements to describe the content and CSS Flexbox or Grid to control the visual layout of a webpage.

8. Important Points to Remember

  • HTML tables display structured information in rows and columns.
  • The <table> element defines a table.
  • The <tr> element defines a row.
  • The <th> element defines a header cell.
  • The <td> element defines a data cell.
  • A table can contain multiple rows and columns.
  • CSS is used for modern table styling.
  • Tables should not be used for general webpage layout.

10. Interview Questions and Answers

Q1. What is an HTML table?

An HTML table is used to organize and display structured information in rows and columns.

Q2. Which element is used to create a table?

The <table> element is used to create a table.

Q3. What is the purpose of the tr element?

The <tr> element defines a row in an HTML table.

Q4. What is the difference between th and td?

The <th> element defines a header cell, whereas <td> defines a data cell.

Q5. Can an HTML table contain multiple rows?

Yes. A table can contain any number of rows.

Q6. What is a table cell?

A table cell is an individual unit inside a row that contains a heading or data.

Q7. Can tables contain images and links?

Yes. Table cells can contain text, images, links, forms, and other suitable HTML content.

Q8. Should HTML tables be used for webpage layout?

No. CSS Flexbox and Grid are preferred for webpage layout. HTML tables should represent tabular data.

Q9. How can we add borders to an HTML table?

CSS border properties can be applied to the table, header cells, and data cells.

Q10. Is the border attribute recommended in modern HTML?

No. Use CSS to control table borders and appearance.
