Lesson 3: Table Headers and Captions

Learn how to define table headings and provide meaningful table titles

1. Introduction

HTML provides two important elements for describing table information: <th> and <caption>.

  • th: Defines a header cell that describes a row or column of data.
  • caption: Provides a title or description for the table as a whole.

These elements make tables easier to understand and improve their accessibility for users of assistive technologies.

2. The th Element

The <th> element stands for Table Header. It defines a cell containing heading information for a row or column.

Syntax

<th>Heading Text</th>

Example

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>City</th>
    </tr>
</table>

Expected Output

Name Age City

The three cells are header cells. By default, browsers usually display their text in bold and center-aligned.

Important: The default appearance of <th> is controlled by browser styles. Its semantic purpose is to identify a table heading, not simply to make text bold.

3. Difference Between th and td

Both elements define table cells, but they have different semantic purposes.

Feature th Element td Element
Full form Table Header Table Data
Purpose Defines a heading cell Defines a data cell
Typical usage Column or row headings Actual table information
Default appearance Usually bold and centered Usually normal weight and left-aligned

Example

<table>
    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>85</td>
    </tr>
</table>

Expected Output

Name Marks
Rahul 85

4. Column Headers

A column header describes the information displayed in a particular vertical column.

Example: Student Marks

<table>
    <tr>
        <th>Roll Number</th>
        <th>Student Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>101</td>
        <td>Rahul</td>
        <td>85</td>
    </tr>

    <tr>
        <td>102</td>
        <td>Priya</td>
        <td>92</td>
    </tr>
</table>

Expected Output

Roll Number Student Name Marks
101 Rahul 85
102 Priya 92

Each heading describes the data underneath it. This makes the table easier to interpret.

5. Row Headers

A row header describes the information contained in a particular horizontal row. A <th> element can also be used as a row header.

Example

<table>
    <tr>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <th>Mathematics</th>
        <td>90</td>
    </tr>

    <tr>
        <th>Physics</th>
        <td>85</td>
    </tr>

    <tr>
        <th>Chemistry</th>
        <td>88</td>
    </tr>
</table>

Expected Output

Subject Marks
Mathematics 90
Physics 85
Chemistry 88

Here, the subject names are row headers and the marks are their corresponding data cells.

6. The scope Attribute

The scope attribute is used with <th> to indicate which cells a header is associated with.

Common values include:

  • col: The header applies to the remaining cells in its column.
  • row: The header applies to the remaining cells in its row.
  • colgroup: The header applies to a group of columns.
  • rowgroup: The header applies to a group of rows.

Example: Column Scope

<table>
    <tr>
        <th scope="col">Name</th>
        <th scope="col">Age</th>
        <th scope="col">City</th>
    </tr>

    <tr>
        <td>Amit</td>
        <td>24</td>
        <td>Delhi</td>
    </tr>
</table>

Example: Row Scope

<table>
    <tr>
        <th scope="row">Mathematics</th>
        <td>90</td>
    </tr>

    <tr>
        <th scope="row">Physics</th>
        <td>85</td>
    </tr>
</table>
Best Practice: Use scope="col" for column headers and scope="row" for row headers when appropriate. This helps assistive technologies understand table relationships.

7. The caption Element

The <caption> element provides a title or short description for an entire table.

It helps users understand what information the table contains before reading its rows and columns.

Syntax

<table>
    <caption>Table Title</caption>

    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
    </tr>
</table>

Example

<table>
    <caption>Student Examination Results</caption>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Priya</td>
        <td>92</td>
    </tr>
</table>

Expected Output

Student Examination Results
Name Marks
Rahul 85
Priya 92

The caption appears above the table by default. CSS can change its visual position.

8. Positioning a Caption Using CSS

The CSS caption-side property controls whether a table caption is displayed above or below the table.

Example: Caption at the Bottom

<style>
    caption {
        caption-side: bottom;
        font-weight: bold;
        padding: 10px;
    }
</style>

<table>
    <caption>Employee Details</caption>

    <tr>
        <th>ID</th>
        <th>Name</th>
    </tr>

    <tr>
        <td>101</td>
        <td>Amit</td>
    </tr>
</table>
Remember: The caption is part of the table's semantic structure. Its visual position can be controlled with CSS.

9. Difference Between th and caption

Feature th caption
Purpose Defines a header cell Defines the table title or description
Location Inside a table row Direct child of table
Number Can be used multiple times At most one per table
Describes A row or column The entire table

10. Complete HTML Program

Let's create a student result table using captions, column headers, and row headers.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Results</title>

    <style>
        table {
            width: 100%;
            border-collapse: collapse;
        }

        caption {
            font-size: 20px;
            font-weight: bold;
            padding: 12px;
        }

        th, td {
            border: 1px solid #333;
            padding: 10px;
            text-align: left;
        }

        th {
            background-color: #dce8f8;
        }
    </style>
</head>

<body>

    <table>
        <caption>Student Examination Results</caption>

        <tr>
            <th scope="col">Roll No.</th>
            <th scope="col">Name</th>
            <th scope="col">Subject</th>
            <th scope="col">Marks</th>
        </tr>

        <tr>
            <th scope="row">101</th>
            <td>Rahul</td>
            <td>Mathematics</td>
            <td>85</td>
        </tr>

        <tr>
            <th scope="row">102</th>
            <td>Priya</td>
            <td>Physics</td>
            <td>92</td>
        </tr>

        <tr>
            <th scope="row">103</th>
            <td>Aman</td>
            <td>Chemistry</td>
            <td>78</td>
        </tr>
    </table>

</body>
</html>

Expected Browser Output

Student Examination Results
Roll No. Name Subject Marks
101 Rahul Mathematics 85
102 Priya Physics 92
103 Aman Chemistry 78

11. Accessibility Best Practices

Table headers and captions are important for users who access webpages through screen readers and other assistive technologies.

  • Use <th> for actual row and column headings.
  • Use <caption> to describe the table's purpose.
  • Use scope="col" for column headers where appropriate.
  • Use scope="row" for row headers where appropriate.
  • Use clear and meaningful heading text.
  • Avoid using empty or meaningless header cells.
  • Use the headers and id attributes for complex tables when necessary.
Accessibility Tip: A visually bold cell is not automatically a semantic table header. Use the <th> element to identify header cells.

12. Common Mistakes

Mistake 1: Using td for Every Cell

Incorrect when the first row contains column headings:

<tr>
    <td>Name</td>
    <td>Marks</td>
</tr>

Better:

<tr>
    <th scope="col">Name</th>
    <th scope="col">Marks</th>
</tr>

Mistake 2: Placing caption Outside the Table

The <caption> element should be a direct child of the <table> element.

Mistake 3: Using caption as a Column Heading

A caption describes the entire table. Use <th> for individual row and column headings.

Mistake 4: Using th Only for Bold Text

Do not use <th> simply to make text bold. Use CSS for visual formatting and reserve <th> for semantic table headings.

13. Important Points to Remember

  • <th> defines a table header cell.
  • <caption> defines the table's title or description.
  • Header cells can describe columns or rows.
  • The scope attribute identifies header direction or group.
  • Common scope values are col, row, colgroup, and rowgroup.
  • A table can have at most one caption element.
  • The caption is a direct child of the table element.
  • CSS controls the visual appearance of headers and captions.

15. Interview Questions and Answers

Q1. What is the th element?

It defines a table header cell that describes a row or column of information.

Q2. What is the caption element?

It provides a title or description for the entire table.

Q3. What is the difference between th and td?

th defines a header cell, while td defines a normal data cell.

Q4. Where should caption be placed?

It should be placed directly inside the table element, usually before the table rows.

Q5. Can a table contain multiple caption elements?

No. A table can contain at most one caption element.

Q6. What is the scope attribute?

It indicates whether a header applies to a row, column, row group, or column group.

Q7. What does scope="col" mean?

It identifies a header cell as a header for its column.

Q8. What does scope="row" mean?

It identifies a header cell as a header for its row.

Q9. How can we position a caption below a table?

Use the CSS property caption-side: bottom;.

Q10. Why are table headers important for accessibility?

They help assistive technologies identify relationships between headings and the corresponding data cells.

Q1. Which element defines a table header cell?

B. <thead>

D. <label>

Answer: C. <caption>

Q3. Which scope value identifies a column header?

A. row

B. col

C. group

D. cell

Answer: B. col

Q4. Which scope value identifies a row header?

A. row

B. col

C. table

D. data

Answer: A. row

Q5. Where should caption be placed?

A. Inside head

B. Inside body only

C. Directly inside table

D. Inside title

Answer: C. Directly inside table

Q6. How many caption elements can a table have?

A. One or more

B. At most one

C. Exactly two

D. Unlimited

Answer: B. At most one

Q7. Which CSS property positions a table caption?

A. text-align

B. caption-side

C. position

D. display

Answer: B. caption-side

Q8. Which scope value applies to a group of columns?

A. colgroup

B. row

C. cell

D. table

Answer: A. colgroup

Q9. Which element should be used for actual table headings?

A. <b>

B. <strong>

C. <th>

Answer: C. <th>

Q10. What is the main purpose of a table caption?

A. To define a table row

B. To describe the entire table

D. To merge columns

Answer: B. To describe the entire table
