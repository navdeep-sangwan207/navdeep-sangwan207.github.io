Chapter 7: HTML Tables

Learn how to organize and present tabular data using HTML5.

Chapter Overview

HTML tables are used to display structured data in rows and columns. In this chapter, you will learn how to create tables, define rows and cells, add headers and captions, group table sections, merge cells, and build accessible tables.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand the purpose and structure of HTML tables.
  • Create table rows and data cells.
  • Define table headers and captions.
  • Organize tables using thead, tbody, and tfoot.
  • Merge table cells using rowspan and colspan.
  • Group table columns using colgroup and col.
  • Create accessible tables using appropriate semantic markup.

Practical Applications

  • Displaying student marksheets and examination results.
  • Creating employee and attendance records.
  • Presenting product prices and comparison data.
  • Displaying financial and statistical information.
  • Organizing structured information in reports and dashboards.

Chapter Completion Checklist

After studying all seven lessons, practise creating:

  • A student marksheet using HTML tables.
  • A timetable with merged rows and columns.
