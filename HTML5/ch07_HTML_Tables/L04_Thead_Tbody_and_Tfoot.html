Lesson 4: Thead, Tbody and Tfoot

Organizing HTML tables using semantic table sections

1. Introduction

HTML provides three important elements for dividing a table into logical sections:

  • <thead> – Groups the table's header rows.
  • <tbody> – Groups the main data rows.
  • <tfoot> – Groups footer rows, such as totals or summaries.

These elements help organize large tables and make their structure easier for browsers, developers, and assistive technologies to understand.

2. The thead Element

The <thead> element stands for Table Head. It groups the rows that contain column headings or other header information.

Syntax

<thead>
    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
    </tr>
</thead>

Example

<table>
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
            <th>City</th>
        </tr>
    </thead>
</table>

Expected Output

Name Age City

The <thead> element groups the header row. It does not itself create the individual header cells; those are created using <th>.

3. The tbody Element

The <tbody> element stands for Table Body. It groups the main data rows of an HTML table.

Syntax

<tbody>
    <tr>
        <td>Data 1</td>
        <td>Data 2</td>
    </tr>
</tbody>

Example

<table>
    <tbody>
        <tr>
            <td>Rahul</td>
            <td>85</td>
        </tr>

        <tr>
            <td>Priya</td>
            <td>92</td>
        </tr>
    </tbody>
</table>

Expected Output

Rahul 85
Priya 92

The <tbody> groups the rows containing the main table data.

4. The tfoot Element

The <tfoot> element stands for Table Foot. It groups footer rows that contain summary information, totals, or other concluding data.

Syntax

<tfoot>
    <tr>
        <td>Total</td>
        <td>100</td>
    </tr>
</tfoot>

Example

<table>
    <tfoot>
        <tr>
            <td>Total Marks</td>
            <td>255</td>
        </tr>
    </tfoot>
</table>

Expected Output

Total Marks 255

The footer section is useful for displaying totals, summaries, and other information related to the table data.

5. Complete Table Structure

A well-organized HTML table can contain all three sections: thead, tbody, and tfoot.

General Structure

<table>

    <thead>
        Header rows
    </thead>

    <tbody>
        Main data rows
    </tbody>

    <tfoot>
        Footer rows
    </tfoot>

</table>

The elements group different parts of the table without changing the underlying meaning of the individual cells.

6. Complete Example: Student Marks Table

Let's create a student marks table with a header section, a body section, and a footer containing the total marks.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Marks Table</title>

    <style>
        table {
            width: 100%;
            border-collapse: collapse;
        }

        caption {
            font-size: 20px;
            font-weight: bold;
            padding: 12px;
        }

        th, td {
            border: 1px solid #333;
            padding: 10px;
            text-align: left;
        }

        thead {
            background-color: #dce8f8;
        }

        tfoot {
            background-color: #fff0d9;
            font-weight: bold;
        }
    </style>
</head>

<body>

    <table>
        <caption>Student Marks Report</caption>

        <thead>
            <tr>
                <th>Roll No.</th>
                <th>Name</th>
                <th>Marks</th>
            </tr>
        </thead>

        <tbody>
            <tr>
                <td>101</td>
                <td>Rahul</td>
                <td>85</td>
            </tr>

            <tr>
                <td>102</td>
                <td>Priya</td>
                <td>92</td>
            </tr>

            <tr>
                <td>103</td>
                <td>Aman</td>
                <td>78</td>
            </tr>
        </tbody>

        <tfoot>
            <tr>
                <td colspan="2">Total Marks</td>
                <td>255</td>
            </tr>
        </tfoot>

    </table>

</body>
</html>

Expected Browser Output

Student Marks Report
Roll No. Name Marks
101 Rahul 85
102 Priya 92
103 Aman 78
Total Marks 255

Explanation:

  • <caption> describes the complete table.
  • <thead> contains the column headings.
  • <tbody> contains three student records.
  • <tfoot> contains the total marks.
  • colspan="2" makes the Total Marks cell span two columns.

7. Multiple tbody Elements

An HTML table can contain more than one <tbody> element. This is useful when data needs to be divided into separate logical groups.

Example: Department-wise Employees

<table>
    <thead>
        <tr>
            <th>Employee</th>
            <th>Department</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Amit</td>
            <td>Engineering</td>
        </tr>

        <tr>
            <td>Neha</td>
            <td>Engineering</td>
        </tr>
    </tbody>

    <tbody>
        <tr>
            <td>Rohit</td>
            <td>Marketing</td>
        </tr>

        <tr>
            <td>Priya</td>
            <td>Marketing</td>
        </tr>
    </tbody>
</table>

Expected Output

Employee Department
Amit Engineering
Neha Engineering
Rohit Marketing
Priya Marketing

The two tbody elements represent separate groups of employee records. CSS can also target these groups independently.

8. Difference Between thead, tbody and tfoot

Feature thead tbody tfoot
Full form Table Head Table Body Table Foot
Purpose Groups header rows Groups main data rows Groups footer rows
Typical content Column headings Data records Totals and summaries
Number allowed At most one Zero or more At most one

9. Styling Table Sections with CSS

CSS selectors can target thead, tbody, and tfoot separately. This makes it possible to apply different styles to each section.

Example

<style>
    table {
        width: 100%;
        border-collapse: collapse;
    }

    th, td {
        border: 1px solid #333;
        padding: 10px;
    }

    thead {
        background-color: #dce8f8;
    }

    tbody {
        background-color: #ffffff;
    }

    tfoot {
        background-color: #fff0d9;
        font-weight: bold;
    }
</style>

This CSS gives the header, body, and footer different background colors.

Remember: CSS styling does not change the semantic purpose of these HTML elements.

10. Important HTML Rules

  • <thead>, <tbody>, and <tfoot> are children of <table>.
  • Each section contains table rows using <tr>.
  • Rows contain header cells or data cells.
  • A table can contain at most one thead and one tfoot.
  • A table can contain multiple tbody elements.
  • The thead section must precede tbody and tfoot in the table's HTML structure.
  • In modern HTML, tfoot is written after the tbody sections.
Browser behavior: Browsers may create an implicit tbody element when table rows are written directly inside a table without an explicit tbody. When inspecting the DOM, you may see this automatically inserted element.

11. Common Mistakes

Mistake 1: Placing td Directly Inside thead

Incorrect:

<thead>
    <td>Name</td>
</thead>

Correct:

<thead>
    <tr>
        <th>Name</th>
    </tr>
</thead>

Mistake 2: Forgetting tr Elements

Table sections contain rows. Place cells inside tr elements, not directly inside thead, tbody, or tfoot.

Mistake 3: Using tfoot for Ordinary Data

Use tbody for ordinary data records. Reserve tfoot for summary or footer information.

Mistake 4: Incorrect Section Order

Use thead first, followed by tbody sections, and then tfoot. Keep the table's source structure clear and consistent.

13. Interview Questions and Answers

Q1. What is the thead element?

It groups the header rows of an HTML table.

Q2. What is the tbody element?

It groups the main data rows of an HTML table.

Q3. What is the tfoot element?

It groups footer rows, such as totals and summaries.

Q4. Can a table contain multiple tbody elements?

Yes. Multiple tbody elements can group different sets of rows.

Q5. Can a table contain multiple thead elements?

No. A table can contain at most one thead element.

Q6. Can a table contain multiple tfoot elements?

No. A table can contain at most one tfoot element.

Q7. What is the purpose of tbody?

It groups the main rows containing the table's data.

Q8. Can CSS target thead and tfoot separately?

Yes. CSS element selectors can style each section independently.

Q9. What happens if tbody is omitted?

Browsers may insert an implicit tbody element when parsing rows directly inside a table.

Q10. What is the main advantage of table sections?

They organize table content into meaningful groups and make the structure easier to manage and understand.
