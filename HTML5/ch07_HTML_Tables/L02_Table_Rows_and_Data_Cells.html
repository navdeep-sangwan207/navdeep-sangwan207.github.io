Lesson 2: Table Rows and Data Cells

Understanding table, tr, and td elements in HTML5

1. Introduction

An HTML table is constructed using rows and cells. The <table> element defines the complete table, the <tr> element defines individual rows, and the <td> element defines data cells.

These elements work together to organize information into a structured row-and-column format.

  • <table> – Creates the table container.
  • <tr> – Creates a horizontal table row.
  • <td> – Creates a data cell inside a row.

2. The table Element

The <table> element is the main container for an HTML table. All table rows and their cells are placed inside this element.

Syntax

<table>
    Table content goes here
</table>

Example

<table>
    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>
</table>

In this example, the table contains one row with two data cells.

3. The tr Element

The <tr> element stands for Table Row. It defines a horizontal row inside an HTML table.

Each row can contain one or more header cells (<th>) or data cells (<td>).

Syntax

<tr>
    <td>Cell 1</td>
    <td>Cell 2</td>
</tr>

Example: Multiple Rows

<table>
    <tr>
        <td>Rahul</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Priya</td>
        <td>92</td>
    </tr>

    <tr>
        <td>Aman</td>
        <td>78</td>
    </tr>
</table>

Expected Output

Rahul 85
Priya 92
Aman 78

Three <tr> elements create three separate rows.

4. The td Element

The <td> element stands for Table Data. It defines an individual data cell inside a table row.

Syntax

<td>Cell Content</td>

Example

<table>
    <tr>
        <td>Laptop</td>
        <td>50000</td>
        <td>2</td>
    </tr>
</table>

Expected Output

Laptop 50000 2

This row contains three data cells. Each cell stores one piece of information.

5. Creating Rows and Columns

In a basic HTML table, each <tr> creates a row, and the cells inside that row determine its columns.

Example: Three Rows and Three Columns

<table>
    <tr>
        <td>Name</td>
        <td>Age</td>
        <td>City</td>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>22</td>
        <td>Delhi</td>
    </tr>

    <tr>
        <td>Priya</td>
        <td>23</td>
        <td>Chandigarh</td>
    </tr>
</table>

Expected Output

Name Age City
Rahul 22 Delhi
Priya 23 Chandigarh

This table contains three rows and three columns. Each row contains three cells.

6. Complete HTML Program

Let's create a complete webpage containing an employee table.

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Employee Records</title>

    <style>
        table {
            width: 100%;
            border-collapse: collapse;
        }

        td {
            border: 1px solid black;
            padding: 10px;
        }
    </style>
</head>

<body>

    <h2>Employee Records</h2>

    <table>
        <tr>
            <td>101</td>
            <td>Amit</td>
            <td>Engineering</td>
        </tr>

        <tr>
            <td>102</td>
            <td>Neha</td>
            <td>Marketing</td>
        </tr>

        <tr>
            <td>103</td>
            <td>Rohit</td>
            <td>Finance</td>
        </tr>
    </table>

</body>
</html>

Expected Browser Output

101 Amit Engineering
102 Neha Marketing
103 Rohit Finance

7. Adding Different Types of Content Inside td

A table data cell can contain more than plain text. It can contain many types of HTML content.

Example

<table>
    <tr>
        <td>
            <strong>HTML Course</strong>
        </td>

        <td>
            <a href="https://example.com">
                Visit Website
            </a>
        </td>

        <td>
            <img src="logo.png"
                 alt="Course Logo"
                 width="60">
        </td>
    </tr>
</table>

A table cell can contain:

  • Text and headings.
  • Images.
  • Hyperlinks.
  • Lists.
  • Form controls.
  • Other suitable HTML elements.

8. Table Styling Using CSS

CSS can control the appearance of tables, rows, and cells. Common properties include:

  • border – Adds borders around table elements.
  • border-collapse – Controls whether adjacent borders are merged.
  • padding – Adds space inside cells.
  • text-align – Aligns cell content horizontally.
  • background-color – Sets the background color.
  • width – Controls table or cell width.

Example

<style>
    table {
        width: 100%;
        border-collapse: collapse;
    }

    td {
        border: 1px solid #333;
        padding: 12px;
        text-align: left;
    }

    tr:nth-child(even) {
        background-color: #f2f2f2;
    }
</style>
Remember: HTML defines the table's structure, while CSS controls its presentation.

9. Common Mistakes

Mistake 1: Using td Outside a Row

Incorrect:

<table>
    <td>HTML</td>
</table>

Correct:

<table>
    <tr>
        <td>HTML</td>
    </tr>
</table>

Mistake 2: Forgetting to Close Elements

Always write clear and properly nested markup. Although browsers can recover from some missing end tags, relying on error recovery can cause unexpected results.

Mistake 3: Unequal Number of Cells

Rows do not always need the same number of cells, but an accidental mismatch can make data difficult to understand. Plan the table structure carefully.

Mistake 4: Using Tables for Page Layout

Do not use tables to arrange general webpage sections. Use CSS Grid or Flexbox instead.

10. Important Points to Remember

  • <table> defines the table container.
  • <tr> defines a table row.
  • <td> defines a data cell.
  • A row can contain multiple cells.
  • Multiple rows create the table's row structure.
  • Cells can contain text, links, images, and other HTML content.
  • CSS is used to style tables.
  • Use tables for tabular data, not general page layout.

12. Interview Questions and Answers

Q1. What is the purpose of the table element?

It defines the complete HTML table.

Q2. What does tr stand for?

It stands for Table Row.

Q3. What does td stand for?

It stands for Table Data.

Q4. Can a table contain multiple rows?

Yes. Multiple tr elements can be used inside a table.

Q5. Can a row contain multiple data cells?

Yes. A tr element can contain multiple td elements.

Q6. What is the difference between a row and a cell?

A row is a horizontal group of cells, while a cell is an individual unit containing data or a heading.

Q7. Can a td element contain an image?

Yes. An image element can be placed inside a td element.

Q8. Can a td element contain a hyperlink?

Yes. An anchor element can be placed inside a td element.

Q9. How do you add borders to table cells?

Use the CSS border property on the table cells.

Q10. Can CSS be used to style individual table rows?

Yes. CSS selectors can target tr elements and apply background colors, borders, and other styles.
