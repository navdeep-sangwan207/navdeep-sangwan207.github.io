1. Introduction to Exception Handling

An exception is an abnormal condition that occurs while a program is running. Exception handling allows a program to respond to certain errors without immediately terminating.

C++ provides three main keywords:

  • try: Contains code that may throw an exception.
  • throw: Signals an exception.
  • catch: Handles a matching exception.

2. Basic Exception Handling

Example: Division by Zero

#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 0;

    try {
        if (b == 0) {
            throw "Division by zero is not allowed";
        }

        cout << a / b;
    }
    catch (const char* message) {
        cout << "Error: " << message;
    }

    return 0;
}

Expected Output

Error: Division by zero is not allowed

Note: Integer division by zero is undefined behavior. Check the divisor before performing the division, as shown above.

3. Multiple Catch Blocks

A single try block can be followed by multiple catch blocks to handle different exception types.

#include <iostream>
using namespace std;

int main() {
    try {
        int choice = 2;

        if (choice == 1)
            throw 100;
        else if (choice == 2)
            throw 3.14;
        else
            throw 'A';
    }
    catch (int e) {
        cout << "Integer exception: " << e;
    }
    catch (double e) {
        cout << "Double exception: " << e;
    }
    catch (char e) {
        cout << "Character exception: " << e;
    }

    return 0;
}

Expected Output

Double exception: 3.14

4. Catch-All Handler

The catch (...) handler catches exceptions that were not handled by earlier catch blocks. Place it after specific handlers.

#include <iostream>
using namespace std;

int main() {
    try {
        throw 'X';
    }
    catch (int e) {
        cout << "Integer exception";
    }
    catch (...) {
        cout << "An unknown exception occurred";
    }

    return 0;
}

Expected Output

An unknown exception occurred

5. Standard Exceptions

The C++ Standard Library provides exception classes. Many common exceptions are defined in the <stdexcept> header.

  • std::exception — base class for many standard exceptions.
  • std::runtime_error — reports a runtime error.
  • std::invalid_argument — reports an invalid argument.
  • std::out_of_range — reports an out-of-range access.
  • std::overflow_error — reports an overflow condition in operations that explicitly detect it.

Example

#include <iostream>
#include <stdexcept>
using namespace std;

int main() {
    try {
        throw invalid_argument("Invalid input");
    }
    catch (const exception& e) {
        cout << "Exception: " << e.what();
    }

    return 0;
}

Expected Output

Exception: Invalid input

6. Creating a Custom Exception

You can define your own exception class when an application needs a specific error type.

#include <iostream>
#include <exception>
using namespace std;

class AgeException : public exception {
public:
    const char* what() const noexcept override {
        return "Age must be 18 or above";
    }
};

int main() {
    int age = 16;

    try {
        if (age < 18)
            throw AgeException();

        cout << "Eligible";
    }
    catch (const AgeException& e) {
        cout << "Error: " << e.what();
    }

    return 0;
}

Expected Output

Error: Age must be 18 or above

7. Introduction to File Handling

File handling allows a C++ program to store data in files and retrieve it later.

Include the <fstream> header to work with file streams.

  • ofstream — writes data to a file.
  • ifstream — reads data from a file.
  • fstream — supports reading and writing.

8. Writing to a File

This program creates or opens a file named example.txt and writes text into it.

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("example.txt");

    if (!file.is_open()) {
        cout << "Unable to open file";
        return 1;
    }

    file << "Hello, C++ File Handling!\n";
    file << "Learning file operations.";

    file.close();

    cout << "Data written successfully";
    return 0;
}

Expected Console Output

Data written successfully

Contents of example.txt

Hello, C++ File Handling!
Learning file operations.

Important: Opening an existing file with the default ofstream mode truncates its existing contents. Use ios::app to append instead.

9. Reading from a File

This program reads the contents of example.txt line by line.

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream file("example.txt");

    if (!file.is_open()) {
        cout << "Unable to open file";
        return 1;
    }

    string line;

    while (getline(file, line)) {
        cout << line << '\n';
    }

    file.close();
    return 0;
}

Expected Output

Hello, C++ File Handling!
Learning file operations.

Run the writing program first, then run the reading program from the same working directory.

10. Appending Data to a File

Appending adds new data at the end of a file without removing the existing contents.

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("example.txt", ios::app);

    if (!file.is_open()) {
        cout << "Unable to open file";
        return 1;
    }

    file << "\nNew data appended.";
    file.close();

    cout << "Data appended successfully";
    return 0;
}

Expected Console Output

Data appended successfully

11. Checking File Status

Check whether a file opened successfully before reading or writing. Common stream status functions include:

  • is_open() — checks whether a file is associated with the stream.
  • good() — checks whether the stream has no error flags set.
  • fail() — checks whether an operation has failed.
  • eof() — checks whether the end-of-file flag is set.

For reading, prefer testing the read operation directly, for example while (getline(file, line)), instead of checking eof() before each read.

12. File Opening Modes

  • ios::in — open for reading.
  • ios::out — open for writing.
  • ios::app — append writes at the end.
  • ios::ate — initially position at the end; seeking may move elsewhere.
  • ios::trunc — discard existing contents when opening, where applicable.
  • ios::binary — open in binary mode.

Modes can be combined, for example ios::out | ios::app.

13. Exception Handling vs File Error Checking

  • Exceptions help handle exceptional conditions reported through C++ exception mechanisms.
  • File streams commonly report open and read/write failures through stream status flags.
  • Always check whether a file opened and whether important operations succeeded.
  • File streams can be configured to throw exceptions for selected error states, but this is not enabled by default for all failures.

Chapter Summary

Exception handling uses try, throw and catch to respond to exceptions. File handling uses file streams to read, write and append persistent data. Reliable programs should validate inputs, handle exceptions appropriately and check file-operation status.
