Chapter Overview

The Runtime Environment (RTE) is an important part of the AUTOSAR Classic Platform. It acts as a communication and abstraction layer between Application Software Components (SWCs) and Basic Software (BSW).

RTE provides configured interfaces for communication between software components and access to selected BSW services. It also supports runnable activation according to configured events and mappings.

Chapter Objectives

  • Understand RTE architecture and responsibilities.
  • Understand RTE generation and configuration.
  • Learn important RTE APIs.
  • Understand runnable entity mapping.
  • Learn RTE events and OS task mapping.
  • Understand SWC interaction through RTE.
