Chapter 9: Diagnostics and Error Management

AUTOSAR Classic Platform

Learn how automotive ECUs detect faults, manage diagnostic events, store DTCs and communicate diagnostic information using the AUTOSAR diagnostic architecture.

Chapter Overview

Diagnostics and error management are important parts of automotive embedded software. An ECU must detect abnormal conditions, record diagnostic information and provide standardized access to diagnostic data.

AUTOSAR Classic provides diagnostic modules such as the Diagnostic Event Manager (DEM) and Diagnostic Communication Manager (DCM). These modules work with communication and application software to support fault monitoring and diagnostic services.

Learning Objectives

  • Understand automotive ECU diagnostics.
  • Explain DEM and DCM responsibilities.
  • Understand diagnostic events and Diagnostic Trouble Codes (DTCs).
  • Learn the basics of Unified Diagnostic Services (UDS).
  • Understand diagnostic communication using CAN and transport protocols.
  • Explain fault detection, status handling and diagnostic testing.

Practical Automotive Example

Engine Temperature Sensor Fault

Consider an engine ECU that monitors a temperature sensor. If the sensor signal remains outside its valid operating range, the application can report a diagnostic event.

  1. The application detects an abnormal sensor condition.
  2. The diagnostic event is reported to DEM.
  3. DEM processes the event status and configured fault criteria.
  4. A corresponding DTC can be stored according to its configuration.
  5. A diagnostic tester sends a UDS request to the ECU.
  6. DCM processes the request and provides the configured diagnostic response.
