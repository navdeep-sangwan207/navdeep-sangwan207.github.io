Chapter 10: AUTOSAR Methodology and Configuration Tools

Learn the AUTOSAR development methodology, ARXML description artifacts, ECU configuration, RTE generation, BSW configuration and commonly used AUTOSAR development tools.

Chapter Overview

AUTOSAR development follows a structured methodology involving software component design, system description, ECU allocation, ECU configuration, code generation, integration and testing.

This chapter explains how AUTOSAR models and configuration descriptions are used to generate the software infrastructure required for an automotive Electronic Control Unit (ECU).

Learning Objectives

  • Understand the AUTOSAR development methodology.
  • Understand the role of ARXML files and description artifacts.
  • Differentiate System Description and ECU Extract.
  • Understand SWC configuration and RTE generation.
  • Learn BSW configuration and code generation.
  • Identify commonly used AUTOSAR configuration tools.
  • Understand the complete ECU configuration workflow.
  • Prepare for AUTOSAR placement interviews.

Practical Application

Example: Automotive Temperature Monitoring ECU

Consider an ECU that reads temperature sensor data, processes the value and controls a cooling fan.

  1. Define the system requirements.
  2. Design the temperature sensor and fan-control SWCs.
  3. Define component ports and interfaces.
  4. Create system-level descriptions.
  5. Allocate software components to the target ECU.
  6. Prepare the ECU Extract.
  7. Configure the SWCs and generate the RTE.
  8. Configure the required BSW and MCAL modules.
  9. Generate configuration artifacts and integrate the software.
  10. Build, flash, test and debug the ECU.
