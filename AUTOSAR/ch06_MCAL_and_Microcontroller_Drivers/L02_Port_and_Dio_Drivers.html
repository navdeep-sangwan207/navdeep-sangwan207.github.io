Lesson 2: Port and DIO Drivers

AUTOSAR – Chapter 6: MCAL and Microcontroller Drivers

Focus: GPIO Configuration and Digital Input/Output

1. Introduction

Port and DIO are two important MCAL drivers used to configure and operate microcontroller digital pins.

  • Port Driver: Configures pin direction, mode and supported electrical characteristics.
  • DIO Driver: Reads and writes digital input/output channels.

These drivers are commonly used for LEDs, switches, relays, digital sensors and other GPIO-based interfaces.

2. What is the Port Driver?

The AUTOSAR Port Driver configures microcontroller port pins during initialization.

Typical configuration responsibilities include:

  • Pin direction: input or output.
  • Pin mode: GPIO or an alternate peripheral function.
  • Supported pull-up or pull-down configuration.
  • Supported input/output characteristics.
  • Pin configuration according to the microcontroller specification.

Exact configuration options depend on the microcontroller and the vendor's MCAL implementation.

3. What is the DIO Driver?

DIO stands for Digital Input Output. The DIO driver provides interfaces to read and write configured digital channels.

  • Read the logic state of a digital input.
  • Set a digital output to HIGH or LOW.
  • Read or write a configured group of channels.
  • Read or write a complete configured port where supported.

DIO normally uses the channel and port configuration established by the Port Driver or the relevant hardware configuration.

4. Port Driver vs DIO Driver

Port Driver DIO Driver
Configures microcontroller pins. Reads and writes digital channels.
Sets pin direction and mode. Controls digital logic states.
Typically used during initialization. Used during normal application operation.
Example: configure a pin as output. Example: switch an LED ON or OFF.

5. Digital Input and Output Concepts

Digital Input

A digital input reads a logic level from an external circuit. For example, a switch may connect a microcontroller pin to ground or a defined logic supply.

6. Important DIO APIs

Common AUTOSAR DIO API names include:

API Purpose
Dio_ReadChannel() Reads the state of a configured digital channel.
Dio_WriteChannel() Writes a logic state to a configured digital channel.
Dio_ReadPort() Reads a configured digital port.
Dio_WritePort() Writes a value to a configured digital port.
Dio_ReadChannelGroup() Reads a configured group of digital channels.
Dio_WriteChannelGroup() Writes a value to a configured channel group.

These APIs use configured symbolic identifiers and types defined by the AUTOSAR DIO specification and generated configuration.

7. Conceptual DIO Code Example

The following example demonstrates the logic of controlling an LED. It illustrates the DIO API usage pattern; it is not a complete project that can run without generated AUTOSAR configuration and headers. 

#include "Dio.h"

void LED_Control(void)
{
    /* Switch LED ON */
    Dio_WriteChannel(LED_CHANNEL, STD_HIGH);

    /* Switch LED OFF */
    Dio_WriteChannel(LED_CHANNEL, STD_LOW);
}

LED_CHANNEL represents a symbolic channel identifier generated or defined for the ECU configuration.

8. Port and DIO Initialization Workflow

  1. Identify the required microcontroller pins.
  2. Select GPIO or the required alternate peripheral function.
  3. Configure pin direction and supported electrical settings.
  4. Generate the Port and DIO configuration.
  5. Initialize the Port Driver during the configured startup sequence.
  6. Use DIO APIs to read inputs and control outputs.
  7. Test the pin behavior on the target hardware.
Port configuration and driver initialization must follow the selected MCU's requirements and the generated AUTOSAR startup sequence. Do not assume the same initialization order or configuration options for every MCU.

9. Automotive Applications

  • Dashboard indicator control.
  • Digital switch input monitoring.
  • Relay and actuator control through suitable driver circuits.
  • Door status detection.
  • Digital fault signal monitoring.
  • Wake-up or status signal interfaces where supported by the ECU design.

10. Common Interview Questions

Q1. What is the difference between Port and DIO?

Answer: Port configures pin properties, while DIO reads and writes digital channel states.

Q2. What is the full form of DIO?

Answer: Digital Input Output.

Q3. Which driver is used to turn an LED ON or OFF?

Answer: DIO Driver, using a configured output channel.

Q4. Which driver configures a pin as input or output?

Answer: Port Driver.

Q5. What does Dio_ReadChannel() do?

Answer: It reads the digital logic state of a configured channel.

Q6. What does Dio_WriteChannel() do?

Answer: It writes a digital logic state to a configured channel.

Q7. Can DIO configure a pin's alternate function?

Answer: Pin mode and alternate-function configuration are handled through Port configuration, not the DIO channel read/write APIs.

Q8. Is DIO an MCAL driver?

Answer: Yes. DIO is part of the AUTOSAR MCAL.

11. Lesson Summary

  • Port Driver configures microcontroller pins.
  • DIO Driver reads and writes digital channels.
  • Port configuration includes direction and pin mode.
  • DIO supports digital input and output operations.
  • Dio_ReadChannel() reads a channel.
  • Dio_WriteChannel() writes a channel.
  • Both drivers belong to MCAL.
