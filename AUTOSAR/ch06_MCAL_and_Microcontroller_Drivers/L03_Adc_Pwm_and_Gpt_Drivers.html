Lesson 3: ADC, PWM and GPT Drivers

AUTOSAR – Chapter 6: MCAL and Microcontroller Drivers

Focus: Analog Measurement, Signal Generation and Timers

1. Introduction

ADC, PWM and GPT are important AUTOSAR MCAL drivers used for analog signal measurement, pulse-width modulation and timer operations.

  • ADC: Converts analog signals into digital values.
  • PWM: Generates pulse-width modulated signals.
  • GPT: Provides general-purpose timer functionality.

2. ADC Driver – Analog to Digital Converter

ADC converts an analog voltage into a digital value that software can process.

ADC Working Principle

  1. An analog sensor provides a voltage signal.
  2. The configured ADC channel samples the voltage.
  3. The ADC converts the voltage into a digital value.
  4. The ADC driver makes the conversion result available to software.
  5. The application processes the measurement.

ADC Resolution

ADC resolution determines the number of possible digital output levels.

Resolution Number of Levels
8-bit256
10-bit1,024
12-bit4,096
16-bit65,536

ADC Calculation Example

Assume a 10-bit ADC with a reference voltage of 5 V.

Number of levels = \(2^{10} = 1024\)

Approximate digital result: \[ ADC = \frac{V_{in}}{V_{ref}} \times (2^N-1) \]

For an input voltage of 2.5 V:

\[ ADC = \frac{2.5}{5} \times 1023 \approx 512 \]

The ADC output is approximately 512.

3. Important ADC Driver Concepts

Concept Description
ADC Channel Represents a configured analog input.
ADC Group Groups ADC channels for conversion according to configuration.
Conversion Mode Defines how conversions are triggered and performed.
Result Buffer Stores converted digital values.
Notification Can notify software when a configured conversion completes.

Common ADC API Names

  • Adc_Init() – Initializes the ADC driver.
  • Adc_StartGroupConversion() – Starts a configured group conversion.
  • Adc_ReadGroup() – Reads conversion results.
  • Adc_StopGroupConversion() – Stops an ongoing group conversion.
  • Adc_GetGroupStatus() – Checks conversion group status.

4. PWM Driver – Pulse Width Modulation

PWM is a technique in which the width of a periodic digital pulse is varied to control the average power delivered to a load.

PWM MCAL Driver
↓
Microcontroller PWM / Timer Hardware
↓
Power Driver Circuit
↓
Motor / LED / Actuator

What is Duty Cycle?

Duty cycle is the percentage of one PWM period during which the signal remains HIGH.

\[ Duty\ Cycle = \frac{T_{ON}}{T_{Period}}\times100 \]

Duty Cycle HIGH Time Typical Interpretation
0%0Always LOW
25%One-quarter periodLow duty cycle
50%Half periodEqual HIGH and LOW time
75%Three-quarters periodHigh duty cycle
100%Entire periodAlways HIGH

PWM Example

Suppose a PWM signal has a period of 10 ms and an ON time of 5 ms.

\[ Duty\ Cycle = \frac{5}{10}\times100 = 50\% \]

The signal has a 50% duty cycle.

PWM Applications

  • DC motor speed control.
  • LED brightness control.
  • Cooling fan control.
  • Actuator control through suitable power electronics.
  • Automotive thermal management systems.

5. Important PWM Driver Concepts

Concept Description
PWM Channel Represents a configured PWM output.
Period Time required for one complete PWM cycle.
Duty Cycle Percentage of the period during which the output is active.
Polarity Defines the active output level.
Notification Optional configured notification associated with PWM events.

Common PWM API Names

  • Pwm_Init() – Initializes the PWM driver.
  • Pwm_SetDutyCycle() – Sets the duty cycle.
  • Pwm_SetPeriodAndDuty() – Sets period and duty cycle.
  • Pwm_SetOutputToIdle() – Sets the output to its configured idle state.
  • Pwm_GetOutputState() – Reads the configured output state where supported.

6. GPT Driver – General Purpose Timer

GPT stands for General Purpose Timer. The GPT MCAL driver provides access to configured hardware timer resources.

Typical uses include:

  • Starting a timer for a specified duration.
  • Stopping a running timer.
  • Reading timer values.
  • Receiving timer notifications.
  • Generating software timing events.
GPT MCAL Driver
↓
Microcontroller Timer Hardware
↓
Timer Expiry / Notification
↓
Configured Software Action

Timer Example

A timer can be configured to expire after 100 milliseconds. When the timer reaches its configured target, a notification may be generated if configured.

Common GPT API Names

  • Gpt_Init() – Initializes the GPT driver.
  • Gpt_StartTimer() – Starts a configured timer.
  • Gpt_StopTimer() – Stops a running timer.
  • Gpt_GetTimeElapsed() – Gets elapsed timer value.
  • Gpt_GetTimeRemaining() – Gets remaining timer value.
  • Gpt_EnableNotification() – Enables a configured notification.
  • Gpt_DisableNotification() – Disables a notification.

9. Conceptual AUTOSAR Code Examples

These snippets illustrate common API usage patterns. Symbolic identifiers, data types and configuration must come from the generated project.

#include "Adc.h"

PWM Duty Cycle

#include "Pwm.h"

void Set_Fan_Speed(void)
{
    Pwm_SetDutyCycle(FAN_PWM_CHANNEL, 32768);
}

In the standard AUTOSAR PWM interface, duty-cycle values commonly use a 0 to 32768 range to represent 0% to 100%. The exact channel configuration and supported resolution must be checked for the selected implementation.

GPT Timer

#include "Gpt.h"

void Start_Software_Timer(void)
{
    Gpt_StartTimer(GPT_TIMER_CHANNEL, 1000);
}

These are illustrative fragments, not complete standalone programs. Actual parameter types, channel identifiers, timer tick values and configuration depend on the generated MCAL headers and target microcontroller.

10. Common Placement Interview Questions

Q1. What is ADC?

Answer: ADC converts analog voltage into a digital value.

Q2. What is ADC resolution?

Answer: It determines the number of discrete digital output levels. An N-bit ADC has \(2^N\) levels.

Q3. What is PWM?

Answer: Pulse Width Modulation is a technique that varies pulse width to control the average power delivered to a load.

Q4. What is duty cycle?

Answer: It is the percentage of one signal period during which the signal is active.

Q5. What is GPT?

Answer: General Purpose Timer. It provides configured timer services such as starting, stopping and reading timers.

Q6. Which driver is used for motor speed control?

Answer: PWM driver, together with an appropriate motor power stage.

Q7. Which driver is used for battery voltage measurement?

Answer: ADC driver.

Q8. What is the difference between PWM and GPT?

Answer: PWM generates configured pulse-width modulated output signals, while GPT provides general-purpose timer services.

Q9. Can ADC directly measure current?

Answer: ADC measures voltage. Current can be measured indirectly using a suitable current-sensing circuit that produces a proportional voltage.

Q10. Are ADC, PWM and GPT part of MCAL?

Answer: Yes. They are standard MCAL driver modules in AUTOSAR Classic.

11. Lesson Summary

  • ADC converts analog signals into digital values.
  • ADC resolution determines the number of conversion levels.
  • PWM controls pulse width and duty cycle.
  • GPT provides general-purpose timer services.
  • ADC, PWM and GPT are MCAL drivers.
  • These drivers are widely used in automotive embedded systems.
