Chapter Overview

Software Components (SWCs) are the basic building blocks of the AUTOSAR application software. They implement application functionality and communicate through standardized ports and interfaces.

This chapter explains how AUTOSAR software components are structured, how they exchange data and services, and how runnable entities execute application logic.

Learning Objectives

  • Understand AUTOSAR Software Components (SWCs).
  • Identify atomic and composition software components.
  • Understand Sender-Receiver communication.
  • Understand Client-Server communication.
  • Identify ports, interfaces and their relationships.
  • Understand runnable entities and activation events.
