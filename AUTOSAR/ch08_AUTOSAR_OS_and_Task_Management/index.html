Chapter Overview

The AUTOSAR Operating System provides standardized operating-system services for managing ECU software execution. It supports task scheduling, event handling, resource management, alarms, counters and interrupt processing.

AUTOSAR Classic OS is based on concepts from the OSEK/VDX operating-system standard. It is designed for predictable execution in embedded automotive ECUs.

Practical Automotive Example

ECU Sensor Monitoring and Control

Consider an ECU that reads a temperature sensor, processes the value and controls a cooling fan.

  1. A timer or configured alarm activates a periodic task.
  2. The task reads the temperature signal.
  3. The application calculates the required fan speed.
  4. A higher-priority task can handle a time-critical operation.
  5. Interrupts can signal hardware events.
  6. The OS schedules eligible tasks according to configured priorities and scheduling rules.
