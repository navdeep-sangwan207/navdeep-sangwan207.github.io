Chapter 5: Basic Software (BSW) and Service Layer

AUTOSAR Classic Platform

BSW Architecture | Modules | Configuration | ECU Management

Chapter Overview

Basic Software (BSW) provides the common software infrastructure required by an AUTOSAR Classic ECU. It supports operating system services, communication, diagnostics, memory management and hardware access.

This chapter covers the major BSW modules, their responsibilities, configuration, integration and ECU startup and shutdown. The focus is on practical concepts frequently discussed in embedded automotive interviews.

Chapter Objectives

  • Understand BSW architecture and its position in AUTOSAR.
  • Identify important BSW modules and their functions.
  • Understand BSW configuration and integration.
  • Learn ECU startup and shutdown sequences.
  • Understand the Services Layer and its responsibilities.
  • Understand BSW interactions with RTE and MCAL.
