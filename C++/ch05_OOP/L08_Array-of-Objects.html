Lesson 8: Array of Objects in C++

Learn how to store, access, and manage multiple objects using arrays.

Home C++ Course OOP Chapter
Lesson Overview

An array of objects stores multiple objects of the same class under one array name. It makes it easier to manage records and process objects using loops.

Topics: Array of Objects · Object Access · Loops · Student Records · Constructors · Object Arrays

1. What Is an Array of Objects?

An array of objects is a collection of objects of the same class stored under one array name. Each object has its own copy of non-static data members.

For example, if we need to store the details of five students, we can create an array containing five Student objects.

Example
class Student {
public:
    int rollNo;
};

Student s[5];

Here, s is an array of five objects. We can access them using indexes from 0 to 4.

2. Why Do We Need an Array of Objects?

  • To manage multiple objects of the same class.
  • To avoid declaring many separate object variables.
  • To process records using loops.
  • To organize data such as students, employees, and products.
Without an Array
Student s1, s2, s3, s4, s5;
With an Array
Student students[5];

An array allows us to manage all five Student objects using one variable name and an index.

3. Accessing Array Objects

Use the array index and the dot operator (.) to access an object's public members.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int rollNo;
};

int main() {
    Student s[3];

    s[0].rollNo = 101;
    s[1].rollNo = 102;
    s[2].rollNo = 103;

    cout << s[0].rollNo << endl;
    cout << s[1].rollNo << endl;
    cout << s[2].rollNo << endl;

    return 0;
}

Expected Output

101
102
103

s[0] refers to the first object, s[1] to the second, and s[2] to the third.

4. Complete Example: Student Records

This program accepts and displays the roll number and marks of three students using an array of objects.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int rollNo;
    float marks;

    void input() {
        cout << "Enter roll number: ";
        cin >> rollNo;

        cout << "Enter marks: ";
        cin >> marks;
    }

    void display() {
        cout << "Roll Number: " << rollNo << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student s[3];

    cout << "--- Enter Student Details ---" << endl;

    for (int i = 0; i < 3; i++) {
        cout << endl << "Student " << i + 1 << endl;
        s[i].input();
    }

    cout << endl << "--- Student Records ---" << endl;

    for (int i = 0; i < 3; i++) {
        cout << endl << "Student " << i + 1 << endl;
        s[i].display();
    }

    return 0;
}
Sample Input
Student 1
Enter roll number: 101
Enter marks: 85.5

Student 2
Enter roll number: 102
Enter marks: 90

Student 3
Enter roll number: 103
Enter marks: 78

Sample Output

--- Student Records ---

Student 1
Roll Number: 101
Marks: 85.5

Student 2
Roll Number: 102
Marks: 90

Student 3
Roll Number: 103
Marks: 78

The two loops process each object. The first loop calls input() for every student, and the second calls display().

5. Initializing an Array of Objects

A class can have a constructor to initialize each object. The following example uses a constructor with parameters.

C++ Program
#include <iostream>
using namespace std;

class Employee {
public:
    int id;
    int salary;

    Employee(int i, int s) {
        id = i;
        salary = s;
    }

    void display() {
        cout << "ID: " << id
             << ", Salary: " << salary << endl;
    }
};

int main() {
    Employee e[3] = {
        Employee(1, 25000),
        Employee(2, 30000),
        Employee(3, 35000)
    };

    for (int i = 0; i < 3; i++) {
        e[i].display();
    }

    return 0;
}

Expected Output

ID: 1, Salary: 25000
ID: 2, Salary: 30000
ID: 3, Salary: 35000

Each element is initialized by calling the constructor with its own arguments. Because this class defines a parameterized constructor and no default constructor, each array element must be initialized appropriately.

6. Important Rules

  • All elements of an array have the same class type.
  • Array indexing starts at 0.
  • An array of size n has valid indexes from 0 to n - 1.
  • Use the dot operator to access a member of an individual object.
  • Loops are useful for processing every object.
  • Access control still applies: private members cannot be accessed directly from outside the class.
Common Mistake

If an array has three objects, accessing s[3] is out of bounds. The valid indexes are s[0], s[1], and s[2].

9. Practical Exercise

  • productId
  • price
  • quantity

Your program should:

  1. Create an array of five Product objects.
  2. Accept details for all five products.
  3. Display all product records.
  4. Calculate and display each product's total value using price * quantity.

10. Lesson Summary

  • An array of objects stores multiple objects of one class.
  • Use indexes to select individual objects.
  • Use the dot operator to access an object's public members.
  • Use loops to input, display, and process object data.
  • Constructors can initialize each object in the array.
