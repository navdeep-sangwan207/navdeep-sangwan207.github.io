Lesson 1: Procedural vs Object-Oriented Programming

Understand two important programming paradigms in C++.

Home C++ Course OOP Chapter
Lesson Overview

Programming paradigms are different approaches used to design and organize computer programs. Two important paradigms are procedural programming and object-oriented programming (OOP).

Topics: Procedural Programming · OOP · Comparison · Four OOP Concepts

1. Procedural Programming

Procedural programming organizes a program around functions and step-by-step instructions. Functions operate on data to complete specific tasks.

C++ Example
#include <iostream>
using namespace std;

int main() {
    int length = 5;
    int width = 3;

    int area = length * width;

    cout << "Area: " << area << '\n';

    return 0;
}

Expected Output

Area: 15

2. Object-Oriented Programming (OOP)

OOP organizes programs using classes and objects. A class groups related data and functions together. An object is an instance of a class.

C++ Example
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    int calculateArea() {
        return length * width;
    }
};

int main() {
    Rectangle r;

    r.length = 5;
    r.width = 3;

    cout << "Area: " << r.calculateArea() << '\n';

    return 0;
}

Expected Output

Area: 15

3. Differences Between Procedural Programming and OOP

Procedural Programming Object-Oriented Programming
Focuses on functions and procedures. Focuses on classes and objects.
Data and functions are often separate. Data and related functions can be grouped together.
Uses functions to organize operations. Uses classes and objects to organize a system.
Can suit straightforward, sequential tasks. Can help model larger, complex systems.
Examples include C-style procedural programs. C++ supports object-oriented programming.

4. Four Fundamental OOP Concepts

1. Encapsulation

Combining data and related functions into a class, while controlling access to internal data.

2. Abstraction

Showing essential features while hiding unnecessary implementation details.

3. Inheritance

Creating a new class based on an existing class to reuse and extend its behavior.

4. Polymorphism

Allowing a common interface to represent different behaviors, such as function overloading or virtual functions.

5. When Should You Use Each Approach?

  • Procedural approach: Useful for straightforward algorithms and tasks organized around a sequence of operations.
  • OOP approach: Useful when a program models entities with related state and behavior, such as students, sensors, or bank accounts.
