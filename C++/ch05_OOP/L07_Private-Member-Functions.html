Lesson 7: Private Member Functions in C++

Understand private functions and how they support encapsulation.

Home C++ Course OOP Chapter
Lesson Overview

Private member functions are internal functions of a class. They help hide implementation details and allow public member functions to control how internal operations are performed.

Topics: Private Functions · Helper Functions · Encapsulation · Internal Calculations · Data Validation · Public vs Private Functions

1. Learning Objectives

  • Understand private member functions.
  • Learn how to declare and define private functions.
  • Understand how public functions can call private functions.
  • Learn how private functions support encapsulation.

2. What Is a Private Member Function?

A private member function is a function declared under the private access specifier in a class.

It can be called directly by member functions and friends of that class, but it cannot be called directly from ordinary outside code through an object.

Syntax
class Example {
private:
    void showMessage() {
        // Private function body
    }

public:
    void display() {
        showMessage();
    }
};

Explanation: Here, display() can call showMessage() because both functions belong to the same class.

3. Program 1: Basic Private Member Function

C++ Program
#include <iostream>
using namespace std;

class Demo {
private:
    void showMessage() {
        cout << "Private function called" << endl;
    }

public:
    void display() {
        showMessage();
    }
};

int main() {
    Demo obj;
    obj.display();

    return 0;
}

Expected Output

Private function called

Explanation: The private function showMessage() is called by the public function display(). The public function provides controlled access to the operation.

4. Program 2: Private Function for Calculation

A private function can perform an internal calculation while a public function provides the result.

C++ Program
#include <iostream>
using namespace std;

class Rectangle {
private:
    int length;
    int width;

    int calculateArea() {
        return length * width;
    }

public:
    void setDimensions(int l, int w) {
        length = l;
        width = w;
    }

    void displayArea() {
        cout << "Area: " << calculateArea() << endl;
    }
};

int main() {
    Rectangle r;

    r.setDimensions(10, 5);
    r.displayArea();

    return 0;
}

Expected Output

Area: 50

Explanation:

  • length and width are private data members.
  • calculateArea() is a private function.
  • setDimensions() assigns the dimensions.
  • displayArea() calls the private calculation function and displays the result.

5. Program 3: Private Function for Validation

Private functions can validate data before a public operation uses it.

C++ Program
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance = 0;

    bool isValidAmount(double amount) {
        return amount > 0;
    }

public:
    void deposit(double amount) {
        if (isValidAmount(amount)) {
            balance += amount;
            cout << "Deposit successful" << endl;
        } else {
            cout << "Invalid amount" << endl;
        }
    }

    void displayBalance() {
        cout << "Balance: " << balance << endl;
    }
};

int main() {
    BankAccount account;

    account.deposit(1000);
    account.deposit(-200);
    account.displayBalance();

    return 0;
}

Expected Output

Deposit successful
Invalid amount
Balance: 1000

Explanation: The private function isValidAmount() checks whether the amount is positive. The public deposit() function uses this validation before updating the balance.

6. Calling a Private Function Directly

The following statement inside main() is invalid:

Incorrect Access
Demo obj;

obj.showMessage();  // Compilation error
Why does this cause an error?

The function is private, so ordinary outside code cannot call it directly. Instead, call a suitable public member function that uses it.

7. Defining a Private Function Outside the Class

A private member function can be declared inside the class and defined outside it using the scope resolution operator. Its private access level remains unchanged.

C++ Program
#include <iostream>
using namespace std;

class Calculator {
private:
    int square(int n);

public:
    void displaySquare(int n);
};

int Calculator::square(int n) {
    return n * n;
}

void Calculator::displaySquare(int n) {
    cout << "Square: " << square(n) << endl;
}

int main() {
    Calculator c;
    c.displaySquare(6);

    return 0;
}

Expected Output

Square: 36

Explanation: The definition Calculator::square() is outside the class, but the function is still private. The public displaySquare() function can call it.

8. Advantages of Private Member Functions

  • Encapsulation: Keeps internal operations hidden from ordinary outside code.
  • Code organization: Separates internal helper operations from the public interface.
  • Reusability: Multiple member functions can use the same private helper.
  • Maintainability: Internal implementation can change without changing the public interface.
  • Validation: Helps centralize internal checks and calculations.

9. Public vs Private Member Functions

Public Function Private Function
Can be called from ordinary outside code through an accessible object. Cannot be called directly from ordinary outside code.
Often provides the class's interface. Often implements internal helper operations.
Can call accessible private functions. Can call other accessible members of the class.
