Lesson 4: Static Data Members in C++

1. Learning Objectives

  • Understand static data members.
  • Differentiate static and non-static data members.
  • Declare and define a static data member.
  • Access a static member through a class or an object.
  • Understand how static data is shared among objects.

2. What Is a Static Data Member?

A static data member is a class member for which there is one shared variable per class, rather than a separate variable for every object.

All objects of the class access the same static data member. If its value changes, that change is visible when accessing it through any object.

Example: A college can use a static member to store the common college name shared by all student objects.

3. Syntax

class ClassName {

public:
static int count;
};

int ClassName::count = 0;

Explanation:

  • static int count; declares the static data member inside the class.
  • int ClassName::count = 0; defines and initializes it outside the class.
  • :: is the scope resolution operator.

In traditional C++ (before C++17), a static data member generally requires one out-of-class definition if it is odr-used. C++17 and later also support inline static data members.

4. Program 1: Basic Static Data Member

#include <iostream>

using namespace std;

class Student {
public:
static int count;
};

int Student::count = 0;

int main() {
cout << "Initial count: " << Student::count << endl;

Student::count = 10;

cout << "Updated count: " << Student::count << endl;

return 0;

}

Expected Output

Initial count: 0

Updated count: 10

Explanation: The static member can be accessed through the class name using Student::count, without creating an object.

5. Program 2: Sharing Data Between Objects

#include <iostream>

using namespace std;

class Employee {
public:
static int companyCode;
};

int Employee::companyCode = 100;

int main() {
Employee e1;
Employee e2;

cout << "e1 company code: "
     << e1.companyCode << endl;

cout << "e2 company code: "
     << e2.companyCode << endl;

e1.companyCode = 200;

cout << "After updating through e1:" << endl;
cout << "e1 company code: "
     << e1.companyCode << endl;
cout << "e2 company code: "
     << e2.companyCode << endl;

return 0;

}

Expected Output

e1 company code: 100

e2 company code: 100
After updating through e1:
e1 company code: 200
e2 company code: 200

Explanation: Both objects refer to the same static variable. Updating it through e1 also changes the value observed through e2.

6. Program 3: Count the Number of Objects

#include <iostream>

using namespace std;

class Counter {
public:
static int count;

Counter() {
    count++;
}

};

int Counter::count = 0;

int main() {
cout << "Objects: " << Counter::count << endl;

Counter c1;
cout << "Objects: " << Counter::count << endl;

Counter c2, c3;
cout << "Objects: " << Counter::count << endl;

return 0;

}

Expected Output

Objects: 0

Objects: 1
Objects: 3

Explanation: Each time a Counter object is constructed, the constructor increments the shared count. This simple example counts constructions; it does not track object destruction.

7. Static vs Non-Static Data Members

Static Data Member Non-Static Data Member
One shared variable per class. Each object has its own instance.
Can be accessed using the class name if accessible. Usually accessed through an object.
Lifetime generally spans the program's execution. Lifetime is tied to the object containing it.
Useful for shared counts or common class-wide data. Useful for object-specific values.

8. C++17: Inline Static Data Members

Since C++17, an inline static data member can be initialized directly inside the class. This avoids a separate definition for that member.

#include <iostream>

using namespace std;

class Product {
public:
inline static int totalProducts = 0;
};

int main() {
Product p1, p2;

Product::totalProducts = 2;

cout << "Total products: "
     << Product::totalProducts << endl;

return 0;

}

Expected Output

Total products: 2

Note: Compile this example using C++17 or later. For older C++ standards, use an in-class declaration and an out-of-class definition as shown in the earlier examples.

9. Important Points

  • Use the static keyword to declare a static data member.
  • A static data member is shared by all objects of its class.
  • Use ClassName::memberName to access a public static data member through the class.
  • Static data members exist independently of individual object instances.
  • A static data member does not make the entire object static.
  • Access control still applies: a private static member cannot be accessed directly from outside the class.

10. Real-World Applications

  • Counting objects created by a class.
  • Storing a shared configuration value.
  • Maintaining a common identifier or sequence counter.
  • Keeping class-wide statistics.
  • Sharing common information between objects.

12. Programming Exercise

Create a class named BankAccount with a static integer named accountCount.

  • Initialize accountCount to zero.
  • Increment it in the constructor.
  • Create three objects.
  • Display the count using BankAccount::accountCount.

Expected result: The final count should be 3.
