Lesson 11: Friend Classes in C++

Learn how to grant one class access to the private and protected members of another class using the friend keyword.

1. What Is a Friend Class?

A friend class is a class that is granted access to the private and protected members of another class.

To declare a friend class, use the friend keyword followed by the class name inside the class that grants access. 

class A {
private:
    int value;

    friend class B;
};

class B {
    // Member functions of B can access
    // private and protected members of A.
};

In this example, class B is a friend of class A. Therefore, member functions of B can access the private member value of an A object.

2. Why Do We Need Friend Classes?

  • To allow closely related classes to cooperate.
  • To provide access to internal data when required by a design.
  • To implement helper classes that work with another class's internals.
  • To support specialized operations across multiple classes.

Friendship should be used only when necessary because it weakens encapsulation and increases dependency between classes.

3. Syntax of a Friend Class

class Helper;

class MainClass {
private:
    int data;

    friend class Helper;
};

class Helper {
public:
    void show(MainClass obj);
};

The declaration friend class Helper; grants friendship to the entire class Helper, not just one of its functions.

The forward declaration class Helper; introduces the name before its full class definition. In this example, the friend declaration itself also introduces the class name, so the separate forward declaration is optional.

4. First Program: Accessing Private Data

#include <iostream>
using namespace std;

class A {
private:
    int value;

public:
    A() {
        value = 100;
    }

    friend class B;
};

class B {
public:
    void display(A obj) {
        cout << "Value: " << obj.value << endl;
    }
};

int main() {
    A a;
    B b;

    b.display(a);

    return 0;
}

Expected Output

Value: 100

Explanation

  1. Class A contains the private member value.
  2. Class A declares B as a friend.
  3. Class B defines the member function display().
  4. The function accesses obj.value, even though the member is private.
  5. In main(), b.display(a) passes an object of class A to the function.

5. Friend Class with Multiple Private Members

A friend class can access multiple private members of the class that grants friendship. 

#include <iostream>
using namespace std;

class Employee {
private:
    int id;
    double salary;

public:
    Employee(int i, double s) {
        id = i;
        salary = s;
    }

    friend class Manager;
};

class Manager {
public:
    void displayEmployee(const Employee &e) {
        cout << "Employee ID: " << e.id << endl;
        cout << "Salary: " << e.salary << endl;
    }

    void increaseSalary(Employee &e, double amount) {
        if (amount > 0) {
            e.salary += amount;
        }
    }
};

int main() {
    Employee e(101, 30000);
    Manager m;

    cout << "Before increment:" << endl;
    m.displayEmployee(e);

    m.increaseSalary(e, 5000);

    cout << endl << "After increment:" << endl;
    m.displayEmployee(e);

    return 0;
}

Expected Output

Before increment:
Employee ID: 101
Salary: 30000

After increment:
Employee ID: 101
Salary: 35000

The Manager class can read both private members and modify the salary because it is a friend of Employee. The salary changes in the original object because increaseSalary() receives it by reference.

6. Friendship Is Not Reciprocal

If class B is a friend of class A, class B can access the private and protected members of A. However, class A does not automatically gain access to the private members of B. 

class A {
private:
    int x;

    friend class B;
};

class B {
private:
    int y;

public:
    void show(A obj) {
        cout << obj.x;  // Allowed
    }
};

The friendship works in one direction only. To grant access in the opposite direction, class B must also declare class A as its friend.

7. Friendship Is Not Inherited

If class B is a friend of class A, a class derived from B does not automatically receive the same friendship privileges.

Friendship is granted explicitly by the class whose private or protected members need to be accessed.

This rule helps keep access permissions specific rather than automatically extending them to unrelated classes.

8. Friend Class vs. Friend Function

Feature Friend Function Friend Class
Access granted to A particular function Member functions of the entire friend class
Declaration example friend void show(A); friend class B;
Scope of friendship Specific function Class-wide access privilege
Typical use One operation involving private data A helper class requiring several operations

A friend class does not make its own private members public. It only receives access to the private and protected members of the class that declares it as a friend.

9. Important Rules

  • Declare a friend class using friend class ClassName;.
  • Friendship is granted by the class whose members need to be accessed.
  • Member functions of the friend class receive the access privilege.
  • Friendship is not reciprocal unless explicitly declared in both directions.
  • Friendship is not inherited.
  • Friendship does not make the granting class's private members public.
  • Use friend classes carefully to preserve encapsulation.

10. Common Mistakes

  • Declaring a class as a friend in the wrong class.
  • Assuming the granting class automatically becomes a friend in return.
  • Assuming a derived class automatically inherits friendship.
  • Confusing a friend class with inheritance.
  • Granting friendship to a whole class when only one function needs access.

12. Practical Exercise

Create a class named BankAccount with private members:

  • accountNumber
  • balance

Then create a class named BankManager.

Your program should:

  1. Declare BankManager as a friend of BankAccount.
  2. Use a constructor to initialize the account number and balance.
  3. Display the account details through a BankManager member function.
  4. Implement a deposit operation that updates the original account balance.
  5. Display the updated balance.

For a starting balance of 10000 and a deposit of 2000, the final balance should be 12000.

Lesson Summary

  • A friend class receives access to private and protected members of another class.
  • Use friend class ClassName; inside the granting class.
  • The friendship applies to member functions of the friend class.
  • Friendship is not automatically reciprocal or inherited.
  • Use friend classes only when the design genuinely requires this access.
