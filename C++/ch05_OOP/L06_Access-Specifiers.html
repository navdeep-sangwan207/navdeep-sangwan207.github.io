Lesson 6: Access Specifiers in C++

Understand public, private and protected access in C++ classes.

Home C++ Course OOP Chapter
Lesson Overview

Access specifiers control the visibility and accessibility of class and structure members. They help protect data, support encapsulation and define how members can be accessed from outside a class or through inheritance.

Topics: Public · Private · Protected · Access Control · Default Access · Encapsulation · Inheritance

1. Learning Objectives

  • Understand access specifiers in C++.
  • Differentiate public, private, and protected members.
  • Learn the default access levels of classes and structures.
  • Understand how access control supports encapsulation.

2. What Are Access Specifiers?

Access specifiers determine where class or structure members can be accessed in a C++ program.

C++ provides three main access specifiers:

  • public
  • private
  • protected

Key Concept: Access specifiers define which parts of a program can use particular class members.

3. Public Access Specifier

Members declared public can be accessed from outside the class through an object, provided the object itself is accessible.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int rollNo;

    void display() {
        cout << "Roll Number: " << rollNo << endl;
    }
};

int main() {
    Student s;

    s.rollNo = 101;
    s.display();

    return 0;
}

Expected Output

Roll Number: 101

Explanation: Both rollNo and display() are public, so they can be accessed through the object s.

4. Private Access Specifier

Members declared private can be accessed directly only by member functions and friends of that class. They cannot be accessed directly from ordinary outside code.

C++ Program
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    void setBalance(double amount) {
        balance = amount;
    }

    void displayBalance() {
        cout << "Balance: " << balance << endl;
    }
};

int main() {
    BankAccount account;

    account.setBalance(5000);
    account.displayBalance();

    return 0;
}

Expected Output

Balance: 5000

Explanation: The variable balance is private. The public functions provide controlled access to it.

The following statement would cause a compilation error if placed inside main(): 

// account.balance = 5000;
Remember: Private members are not directly accessible through an ordinary object outside the class.

5. Protected Access Specifier

Protected members can be accessed within the class, by its friends, and by members of derived classes subject to C++ inheritance access rules. They are not directly accessible through an ordinary outside object.

C++ Program
#include <iostream>
using namespace std;

class Animal {
protected:
    int age;
};

class Dog : public Animal {
public:
    void setAge(int a) {
        age = a;
    }

    void displayAge() {
        cout << "Age: " << age << endl;
    }
};

int main() {
    Dog d;

    d.setAge(3);
    d.displayAge();

    return 0;
}

Expected Output

Age: 3

Explanation: The derived class Dog can access the protected member age inherited from Animal.

6. Comparison of Access Specifiers

Access Specifier Inside Class Outside Class Derived Class
public Yes Yes, if accessible Yes, subject to inheritance rules
private Yes No direct access No direct access to the base class's private members
protected Yes No direct access Yes, subject to inheritance rules

Important: Inheritance access rules can further restrict access to inherited public and protected members. The table describes the general member access rules, not every inheritance-mode variation.

7. Default Access Specifiers

The default access level depends on whether you declare a class or a struct.

C++ Example
class ExampleClass {
    int value;  // Private by default
};

struct ExampleStruct {
    int value;  // Public by default
};

Default Access Rules:

  • Members of a class are private by default.
  • Members of a struct are public by default.

8. Program: Encapsulation Using Private Data

Encapsulation combines data and the functions that operate on it inside a class. Private data can be accessed through public member functions.

C++ Program
#include <iostream>
using namespace std;

class Employee {
private:
    double salary;

public:
    void setSalary(double amount) {
        if (amount >= 0) {
            salary = amount;
        }
    }

    void displaySalary() {
        cout << "Salary: " << salary << endl;
    }
};

int main() {
    Employee e;

    e.setSalary(25000);
    e.displaySalary();

    return 0;
}

Expected Output

Salary: 25000

Explanation: The private variable is accessed through public member functions. The setter checks the supplied value before assigning it.

Programming Note: In production code, define how invalid values are handled and initialize data members safely. For example, you can initialize salary to zero when declaring it.

9. Why Are Access Specifiers Important?

  • Encapsulation: Protects internal data from uncontrolled access.
  • Data integrity: Allows validation before changing values.
  • Maintainability: Separates the public interface from implementation details.
  • Inheritance: Controls which members derived classes can access.

10. Common Mistakes

  • Trying to access a private member directly from main().
  • Assuming protected members are publicly accessible through objects.
  • Forgetting that class members are private by default.
  • Confusing access specifiers with inheritance modes such as public or private inheritance.
