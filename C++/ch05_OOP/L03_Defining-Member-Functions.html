Lesson 3: Defining Member Functions in C++

1. Learning Objectives

  • Understand member functions.
  • Define functions inside a class.
  • Define functions outside a class using the scope resolution operator.
  • Pass arguments to member functions and return values.

2. What Is a Member Function?

A member function is a function associated with a class. It can access the class's members according to their access permissions.

Member functions can be defined inside the class or declared inside and defined outside it.

3. Defining a Function Inside a Class

A function can be defined directly inside the class body.

#include <iostream>

using namespace std;

class Calculator {
public:
int add(int a, int b) {
return a + b;
}
};

int main() {
Calculator c;

cout << "Sum: " << c.add(10, 20) << endl;

return 0;

}

Expected Output

Sum: 30

Explanation: The add() function accepts two integers and returns their sum. The object c calls it using the dot operator.

4. Defining a Function Outside a Class

A member function can be declared inside the class and defined outside it. The scope resolution operator :: specifies which class the function belongs to.

#include <iostream>

using namespace std;

class Calculator {
public:
int add(int a, int b);
};

int Calculator::add(int a, int b) {
return a + b;
}

int main() {
Calculator c;

cout << "Sum: " << c.add(15, 25) << endl;

return 0;

}

Expected Output

Sum: 40

Explanation:

  • int add(int a, int b); declares the function inside the class.
  • Calculator::add() defines the function outside the class.
  • :: is called the scope resolution operator.

5. Program: Function Without a Return Value

The return type void means the function does not return a value.

#include <iostream>

using namespace std;

class Student {
public:
void display() {
cout << "Welcome to C++ OOP!" << endl;
}
};

int main() {
Student s;
s.display();

return 0;

}

Expected Output

Welcome to C++ OOP!

6. Program: Function Using Data Members

A member function can use the data members of the object that calls it.

#include <iostream>

using namespace std;

class Rectangle {
public:
int length;
int width;

int calculateArea() {
    return length * width;
}

};

int main() {
Rectangle r;

r.length = 10;
r.width = 4;

cout << "Area: " << r.calculateArea() << endl;

return 0;

}

Expected Output

Area: 40

Explanation: The function calculateArea() uses the current object's length and width.

7. Program: Passing Arguments to a Member Function

#include <iostream>

using namespace std;

class Number {
public:
void checkEvenOdd(int n) {
if (n % 2 == 0) {
cout << n << " is even" << endl;
} else {
cout << n << " is odd" << endl;
}
}
};

int main() {
Number obj;

obj.checkEvenOdd(8);
obj.checkEvenOdd(5);

return 0;

}

Expected Output

8 is even

5 is odd

8. Inside vs Outside Function Definition

Inside the Class Outside the Class
Function body appears in the class definition. Function is declared in the class and defined separately.
Often convenient for short functions. Can make larger class definitions easier to read.
No separate class qualification is needed. Uses ClassName::functionName().

9. Important Points

  • A member function belongs to a class.
  • It can accept parameters and return a value.
  • A function declared inside the class must have a matching definition if defined outside it.
  • The scope resolution operator :: identifies the class scope.
  • Access to private members is permitted inside that class's member functions.
  • A non-static member function is normally called through an object.

11. Programming Exercise

Create a class named Circle with a data member radius.

  • Declare a member function named calculateArea() inside the class.
  • Define it outside the class using Circle::.
  • Return the area using the formula 3.14159 × radius × radius.
  • In main(), create a circle with radius 5 and display its area.

Expected result: The area should be approximately 78.54.
