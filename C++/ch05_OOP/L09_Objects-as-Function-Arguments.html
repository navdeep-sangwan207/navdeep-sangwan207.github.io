Lesson 9: Objects as Function Arguments in C++

Learn how to pass objects to functions to process, compare, or modify object data.

Home C++ Course OOP Chapter
Lesson Overview

In C++, objects can be passed to functions just like ordinary variables. A function can receive an object by value, reference, or constant reference.

Topics: Passing Objects · Pass by Value · Pass by Reference · Constant Reference · Comparing Objects · Practical Applications

1. What Does Passing an Object Mean?

In C++, an object can be passed as an argument to a function, just like an integer, float, or other value. The function can use the object's data through its accessible member functions or public data members.

Consider this class:

C++ Class
class Student {
public:
    int marks;
};

If s1 is an object of Student, we can pass it to a function like this:

Function Call
display(s1);

The way the function receives the object determines whether it works with a copy or with the original object.

2. Passing an Object by Value

When an object is passed by value, the function receives a separate copy of that object. Changes to the copy do not change the original object's data.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    Student(int m) {
        marks = m;
    }
};

void display(Student s) {
    cout << "Marks: " << s.marks << endl;
}

int main() {
    Student s1(85);

    display(s1);

    return 0;
}

Expected Output

Marks: 85

The function parameter s receives a copy of s1. This example only displays the copied object's marks.

3. Modifying a Copy: Pass by Value

The next example changes the function's local copy. The original object's value remains unchanged.

C++ Program
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }
};

void change(Number n) {
    n.value = 100;
    cout << "Inside function: " << n.value << endl;
}

int main() {
    Number n1(10);

    change(n1);

    cout << "In main: " << n1.value << endl;

    return 0;
}

Expected Output

Inside function: 100
In main: 10
Important:

The assignment n.value = 100 changes only the copy called n, not the original object n1.

4. Passing an Object by Reference

Passing by reference lets the function work directly with the original object. Changes made through the reference affect the original object's data.

C++ Program
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }
};

void change(Number &n) {
    n.value = 100;
}

int main() {
    Number n1(10);

    change(n1);

    cout << "Value: " << n1.value << endl;

    return 0;
}

Expected Output

Value: 100

The parameter Number &n is a reference to the original object. No separate Number object is created for this parameter.

5. Passing an Object by Constant Reference

A constant reference allows a function to read an object without making an object copy or modifying that object through the reference.

It is especially useful for larger objects that only need to be read.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    Student(int m) {
        marks = m;
    }
};

void display(const Student &s) {
    cout << "Marks: " << s.marks << endl;

    // s.marks = 100; // Not allowed through this const reference
}

int main() {
    Student s1(90);

    display(s1);

    return 0;
}

Expected Output

Marks: 90

The keyword const prevents modification of the object's data through this reference. It does not mean that the object can never be changed through another valid route.

6. Comparing Two Objects

A function can receive two objects and compare their data. The following example finds which student has higher marks.

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    Student(int m) {
        marks = m;
    }
};

void compare(const Student &s1, const Student &s2) {
    if (s1.marks > s2.marks) {
        cout << "First student has higher marks." << endl;
    } else if (s2.marks > s1.marks) {
        cout << "Second student has higher marks." << endl;
    } else {
        cout << "Both students have equal marks." << endl;
    }
}

int main() {
    Student a(85);
    Student b(92);

    compare(a, b);

    return 0;
}

Expected Output

Second student has higher marks.

Both objects are passed by constant reference, so the function can compare their marks without copying them or changing their data through the parameters.

7. Passing Objects: Comparison Table

Method Parameter Example Object Copy Can Modify Original Through Parameter?
By value Student s Yes No
By reference Student &s No Yes
By constant reference const Student &s No No, not through that reference
Note:

These examples assume ordinary object parameters and no unusual copy-constructor or overloaded-operator behavior.

8. When Should You Use Each Method?

  • Pass by value: Use when the function needs an independent copy and changes must not affect the original.
  • Pass by reference: Use when the function must modify the original object.
  • Pass by constant reference: Use when the function needs to read an object without copying it or modifying it through that parameter.

For a small built-in type such as int, passing by value is often simple and efficient. For larger class objects, constant references are commonly used for read-only parameters.

9. Common Mistakes

  • Expecting a by-value function to change the original object.
  • Forgetting & when a function must modify the original object through a reference parameter.
  • Trying to modify a member through a constant reference.
  • Accessing private data directly from a non-member function. Use public member functions or another appropriate interface.

Lesson Summary

  • Objects can be passed to functions as arguments.
  • Pass by value creates a separate object copy.
  • Pass by reference allows changes to the original object.
  • Pass by constant reference supports read-only access without copying the object.
  • Functions can accept multiple objects for comparison or processing.
