Lesson 10: Friend Non-Member Functions in C++

Understand how friend functions access private and protected class members.

Home C++ Course OOP Chapter
Lesson Overview

A friend function is a non-member function that is granted special access to a class's private and protected members. It is declared inside the class using the friend keyword.

Topics: Friend Functions · Private Member Access · Protected Member Access · Multiple Objects · Friend vs Member Function · Friendship Rules

1. What Is a Friend Function?

A friend function is a non-member function that is granted special access to a class's private and protected members. It is declared inside the class using the friend keyword.

Although the declaration appears inside the class, the function does not become a member of that class.

Friend Function Declaration
class Demo {
private:
    int value;

public:
    friend void display(Demo d);
};

Here, display() is a friend of Demo. It can access value even though value is private.

2. Why Do We Need Friend Functions?

  • To allow selected non-member functions to access private data.
  • To perform operations involving objects of different classes.
  • To support certain operator-overloading designs.
  • To provide access when a regular public member interface is not suitable.
Important:

Friendship should be used selectively because it reduces encapsulation by granting access to implementation details.

3. Basic Syntax

Friend Function Syntax
class ClassName {
private:
    int data;

public:
    friend void functionName(ClassName obj);
};

void functionName(ClassName obj) {
    // Can access private members of ClassName
}

The declaration has three important parts:

  1. friend grants special access.
  2. The function is declared in the class.
  3. The function is defined separately, outside the class.

A friend function is called like an ordinary function. You do not call it using an object and the dot operator.

4. First Program: Accessing a Private Member

C++ Program
#include <iostream>
using namespace std;

class Demo {
private:
    int value;

public:
    Demo() {
        value = 50;
    }

    friend void display(Demo d);
};

void display(Demo d) {
    cout << "Value: " << d.value << endl;
}

int main() {
    Demo obj;

    display(obj);

    return 0;
}

Expected Output

Value: 50

Explanation

  • value is a private data member.
  • display() is declared as a friend inside Demo.
  • The function receives an object as an argument.
  • It accesses d.value directly because it has friend access.
  • The function is called as display(obj).

5. Friend Function with Two Objects

A friend function can receive two objects of the same class and compare their private data members.

C++ Program
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) {
        value = v;
    }

    friend void compare(Number a, Number b);
};

void compare(Number a, Number b) {
    if (a.value > b.value) {
        cout << "First number is greater." << endl;
    } else if (b.value > a.value) {
        cout << "Second number is greater." << endl;
    } else {
        cout << "Both numbers are equal." << endl;
    }
}

int main() {
    Number n1(40);
    Number n2(25);

    compare(n1, n2);

    return 0;
}

Expected Output

First number is greater.

The function compare() can access the private member value of both objects because it is declared as a friend of Number.

6. Friend Function to Add Two Objects

This example adds the private values of two objects and displays their sum.

C++ Program
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) {
        value = v;
    }

    friend int add(Number a, Number b);
};

int add(Number a, Number b) {
    return a.value + b.value;
}

int main() {
    Number n1(10);
    Number n2(20);

    cout << "Sum: " << add(n1, n2) << endl;

    return 0;
}

Expected Output

Sum: 30

The friend function can read both private values and return their sum. It is still a non-member function.

7. Friend Function vs. Member Function

Feature Friend Function Member Function
Belongs to the class No Yes
Declaration May be declared using friend inside a class Declared as a class member
Access to private members Yes, for the class that grants friendship Yes, for its own class
Implicit this pointer No Available to non-static member functions
Typical call display(obj) obj.display()

8. Important Rules of Friend Functions

  • A friend function is not a member of the class.
  • It can access private and protected members of the class that declares it as a friend.
  • It is normally called like an ordinary function.
  • It does not have an implicit this pointer.
  • Friendship is not automatically reciprocal.
  • Friendship is not automatically inherited.
  • A class can grant friendship to a particular function without granting access to every other function.
Remember:

Friendship grants access; it does not turn a non-member function into a member function.

9. Common Mistakes

  • Trying to call a friend function using obj.display() when it is a non-member function.
  • Forgetting to declare the function as a friend in the class.
  • Assuming friendship with one class grants access to every class.
  • Assuming a friend function has an implicit this pointer.
  • Using friend functions unnecessarily when a public member function would provide a simpler interface.

  • width

Your program should:

  1. Initialize the length and width using a constructor.
  2. Declare a non-member function named area() as a friend.

Expected Result

Lesson Summary

  • A friend function is a non-member function granted special access by a class.
  • Declare it inside the class using the friend keyword.
  • Define it outside the class like an ordinary function.
  • It can access private and protected members of the class that declares it as a friend.
  • It can receive one or more objects as arguments.
  • Use friendship carefully to preserve encapsulation.
