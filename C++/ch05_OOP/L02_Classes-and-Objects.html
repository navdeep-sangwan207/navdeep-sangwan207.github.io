Lesson Overview

Classes and objects are fundamental concepts of C++. A class defines the structure and behaviour, while objects represent individual instances of that class.

Topics: Classes · Objects · Data Members · Member Functions · Multiple Objects

1. What Is a Class?

A class is a user-defined data type that combines data members and member functions into one unit.

  • Data members: Variables declared inside a class.
  • Member functions: Functions that define the behaviour of objects.

2. What Is an Object?

An object is an instance of a class. A class defines the structure, while objects hold their own data.

Example: Student is a class, and student1 is an object.

3. Basic Syntax

Class and Object Syntax
class ClassName {

public:
    int data;

    void display() {
        // Function body
    }

};

int main() {
    ClassName obj;
    obj.data = 10;
    obj.display();

    return 0;
}

The public keyword allows the members to be accessed from outside the class, subject to normal access rules.

The dot operator (.) accesses members through an object.

4. Program: Create a Class and an Object

C++ Program
#include <iostream>
using namespace std;

class Student {
public:
    int rollNo;

    void display() {
        cout << "Roll Number: " << rollNo << endl;
    }
};

int main() {
    Student student1;

    student1.rollNo = 101;
    student1.display();

    return 0;
}

Expected Output

Roll Number: 101

Explanation: The Student class contains a roll number and a display function. The student1 object stores the value 101.

5. Program: Multiple Data Members

C++ Program
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    int rollNo;
    string name;
    float marks;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNo << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student s1;

    s1.name = "Amit";
    s1.rollNo = 101;
    s1.marks = 85.5f;

    s1.display();

    return 0;
}

Expected Output

Name: Amit
Roll Number: 101
Marks: 85.5

6. Program: Multiple Objects

C++ Program
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    void displayArea() {
        cout << "Area: " << length * width << endl;
    }
};

int main() {
    Rectangle r1, r2;

    r1.length = 10;
    r1.width = 5;

    r2.length = 4;
    r2.width = 3;

    r1.displayArea();
    r2.displayArea();

    return 0;
}

Expected Output

Area: 50
Area: 12

Explanation: Both objects belong to the same class, but each has its own values for the non-static data members.

7. Program: Member Function Returning a Value

C++ Program
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    int calculateArea() {
        return length * width;
    }
};

int main() {
    Rectangle r;

    r.length = 8;
    r.width = 6;

    cout << "Area: " << r.calculateArea() << endl;

    return 0;
}

Expected Output

Area: 48
