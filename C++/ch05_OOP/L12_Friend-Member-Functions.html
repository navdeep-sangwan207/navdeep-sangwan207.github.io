Lesson 12: Friend Member Functions in C++

Learn how a specific member function of one class can access the private and protected members of another class using friendship.

1. What Is a Friend Member Function?

A friend member function is a member function of one class that is granted special access to the private and protected members of another class.

Unlike a friend class, which grants access to all its member functions, a friend member function grants access only to the specifically declared function. 

class A;

class B {
public:
    void display(A& obj);
};

class A {
private:
    int value;

    friend void B::display(A& obj);
};

Here, B::display() is declared as a friend of class A. It can access the private members of A.

2. Why Do We Need Friend Member Functions?

  • To grant access to one specific function instead of an entire class.
  • To allow closely related classes to cooperate.
  • To perform operations that require access to private data.
  • To provide more selective access than declaring a whole class as a friend.

Use this feature only when ordinary public member functions cannot provide a suitable interface.

3. Important Syntax and Declaration Order

To declare a member function of another class as a friend, the compiler must know the class and function declaration. A common approach is:

  1. Forward-declare the class whose object will be used.
  2. Declare the member function in its own class.
  3. Declare that specific member function as a friend in the target class.
  4. Define the function after the target class is fully defined.
class A;

class B {
public:
    void show(A& obj);
};

class A {
private:
    int data;

    friend void B::show(A& obj);
};

void B::show(A& obj) {
    // Can access A's private members.
}

The order matters because B::show() must be declared as a member of B before it can be named in the friend declaration inside A.

4. First Program: Accessing a Private Member

#include <iostream>
using namespace std;

class A;

class B {
public:
    void display(A& obj);
};

class A {
private:
    int value;

public:
    A() {
        value = 100;
    }

    friend void B::display(A& obj);
};

void B::display(A& obj) {
    cout << "Value: " << obj.value << endl;
}

int main() {
    A a;
    B b;

    b.display(a);

    return 0;
}

Expected Output

Value: 100

Explanation

  • Class A contains the private member value.
  • Class B declares the member function display().
  • Class A grants friendship specifically to B::display().
  • The function accesses obj.value directly.
  • The function is called using b.display(a) because it is still a member function of B.

5. Modifying Private Data Through a Friend Member Function

A friend member function can also modify private data when it receives the target object by reference. 

#include <iostream>
using namespace std;

class BankAccount;

class BankManager {
public:
    void deposit(BankAccount& account, double amount);
};

class BankAccount {
private:
    double balance;

public:
    BankAccount(double initialBalance) {
        balance = initialBalance;
    }

    friend void BankManager::deposit(
        BankAccount& account, double amount
    );

    void displayBalance() const {
        cout << "Balance: " << balance << endl;
    }
};

void BankManager::deposit(
    BankAccount& account, double amount
) {
    if (amount > 0) {
        account.balance += amount;
    }
}

int main() {
    BankAccount account(10000);
    BankManager manager;

    cout << "Before deposit:" << endl;
    account.displayBalance();

    manager.deposit(account, 2000);

    cout << "After deposit:" << endl;
    account.displayBalance();

    return 0;
}

Expected Output

Before deposit:
Balance: 10000
After deposit:
Balance: 12000

The function BankManager::deposit() is a friend of BankAccount. It can therefore modify the private member balance. Passing the account by reference ensures that the original object is updated.

6. Friend Member Function vs. Friend Class

Feature Friend Member Function Friend Class
Access granted to One specified member function Member functions of the friend class
Declaration example friend void B::show(A&); friend class B;
Access scope More restricted Broader
Best use Only one operation needs access Many operations require access

7. Friend Member Function vs. Friend Non-Member Function

Feature Friend Member Function Friend Non-Member Function
Belongs to a class Yes, to another class No
Typical declaration friend void B::show(A&); friend void show(A&);
Call style b.show(a) show(a)
Implicit this pointer Available because it is a non-static member function Not available

8. Important Rules

  • A friend member function remains a member of its original class.
  • Only the specifically declared member function receives the friendship privilege.
  • The declaration must identify the correct class and member function.
  • The function can access private and protected members of the class that declares it as a friend.
  • Friendship is not automatically reciprocal or inherited.
  • Friendship does not make private members public.
  • Use references when the function must modify the original object.

9. Common Mistakes

  • Declaring friend void display(A&); when the intention is to grant friendship to B::display().
  • Forgetting to declare the member function inside its original class before the friend declaration.
  • Defining the member function before the target class is fully defined when its private members need to be accessed.
  • Assuming every member function of the other class becomes a friend automatically.
  • Forgetting that friendship is granted by the class whose private data needs to be accessed.

11. Practical Exercise

Create a class named Rectangle with private members:

  • length
  • width

Create another class named Calculator.

Your program should:

  1. Declare a member function named calculateArea() inside Calculator.
  2. Declare only Calculator::calculateArea() as a friend of Rectangle.
  3. Calculate the area using the private length and width.
  4. Display the result.

Expected result for length 8 and width 5:

Area: 40

Lesson Summary

  • A friend member function belongs to one class but receives access to another class's private and protected members.
  • Declare the specific member function as a friend using its qualified name.
  • Declaration order matters when one class refers to another class's member function.
  • A friend member function is called using an object of its own class.
  • Friend member functions provide more selective access than friend classes.
