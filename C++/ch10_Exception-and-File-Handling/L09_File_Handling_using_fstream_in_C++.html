1. Introduction to fstream

C++ provides the fstream class to perform file input and output operations. It allows a program to read data from a file and write data to a file using the same file stream.

The fstream class is defined in the <fstream> header file.

Important: The fstream class supports both reading and writing. The file must be opened with suitable modes for the required operations.

2. Types of File Stream Classes

C++ provides three commonly used file stream classes:

Class Purpose Common Operations
ifstream Reading data from files >>, getline(), get()
ofstream Writing data to files <<, put()
fstream Reading and writing files Input and output operations
fstream does not automatically make every file operation possible. Choose appropriate opening modes such as ios::in and ios::out.

3. Including the fstream Header

Before using file stream classes, include the <fstream> header.

#include <iostream> #include <fstream> using namespace std;

The <iostream> header supports console input and output, while <fstream> provides file stream classes.

4. Opening a File using fstream

A file can be opened using the open() member function or directly through the fstream constructor.

Syntax using open()

fstream file; file.open("data.txt", ios::in | ios::out);

Syntax using constructor

fstream file("data.txt", ios::in | ios::out);

The ios::in mode enables reading, and ios::out enables writing.

Opening an existing file with ios::in | ios::out does not normally truncate it. If the file does not exist, this combination generally fails to open it. Use an appropriate creation mode when a new file is required.

5. File Opening Modes

File modes specify how a file should be opened. Multiple modes can be combined using the bitwise OR operator (|).

Mode Purpose
ios::in Opens a file for reading.
ios::out Opens a file for writing.
ios::app Directs every output operation to the end of the file.
ios::ate Initially positions the file position at the end.
ios::trunc Discards existing file contents when opening, where applicable.
ios::binary Opens a file in binary mode.

6. Writing Data using fstream

To write data using fstream, open the file with ios::out and use the insertion operator (<<).

Program

#include <iostream> #include <fstream> using namespace std; int main() { fstream file; file.open("student.txt", ios::out); if (!file.is_open()) { cout << "File opening failed"; return 1; } file << "Name: Rahul" << endl; file << "Course: C++" << endl; file << "Marks: 85" << endl; file.close(); cout << "Data written successfully"; return 0; }

Expected Output

Data written successfully

File Content

Name: Rahul Course: C++ Marks: 85
Opening with ios::out alone normally truncates an existing file. Use ios::app if previous contents must be preserved.

7. Reading Data using fstream

To read data using fstream, open the file with ios::in. The extraction operator (>>) can read formatted data.

Program

#include <iostream> #include <fstream> #include <string> using namespace std; int main() { fstream file; file.open("student.txt", ios::in); if (!file.is_open()) { cout << "File opening failed"; return 1; } string line; while (getline(file, line)) { cout << line << endl; } file.close(); return 0; }

Expected Output

Name: Rahul
Course: C++
Marks: 85
getline() reads a complete line, including spaces, until the newline delimiter is encountered.

8. Reading and Writing using the Same fstream Object

One important advantage of fstream is that the same object can be used for both reading and writing.

Program: Write and Then Read a File

#include <iostream> #include <fstream> #include <string> using namespace std; int main() { fstream file; file.open("example.txt", ios::in | ios::out | ios::trunc); if (!file.is_open()) { cout << "File opening failed"; return 1; } // Writing data file << "Welcome to C++" << endl; file << "Learning fstream" << endl; // Move the read position to the beginning file.seekg(0, ios::beg); // Reading data string line; while (getline(file, line)) { cout << line << endl; } file.close(); return 0; }

Expected Output

Welcome to C++
Learning fstream
Important: seekg() changes the input position, while seekp() changes the output position. After switching between reading and writing, manage stream positions and state carefully.

9. Understanding seekg() and seekp()

C++ provides functions to change the current file position.

Function Purpose
seekg() Moves the input (get) position.
seekp() Moves the output (put) position.
tellg() Returns the current input position.
tellp() Returns the current output position.

Common Positioning References

  • ios::beg – Beginning of the file.
  • ios::cur – Current file position.
  • ios::end – End of the file.

Example

file.seekg(0, ios::beg); file.seekp(0, ios::end);

The first statement moves the input position to the beginning. The second moves the output position to the end.

10. Difference Between ifstream, ofstream and fstream

Feature ifstream ofstream fstream
Reading Yes No Yes, with suitable mode
Writing No Yes Yes, with suitable mode
Header <fstream> <fstream> <fstream>
Typical use Read files Write files Read and write files

11. File Position and Stream State

File operations change the stream position and state. Understanding these concepts helps prevent reading and writing errors.

  • Input position: Location from which the next read occurs.
  • Output position: Location where the next write occurs.
  • EOF state: Indicates that an attempted read reached the end of the file.
  • Fail state: Indicates that an operation failed, such as an unsuccessful formatted extraction.
  • Bad state: Indicates a serious input/output error.
If a previous read operation sets a failure state, clear the stream state with clear() before attempting further operations, when appropriate. Also reposition the file pointer if needed.

12. Common Mistakes

  1. Forgetting to include the <fstream> header.
  2. Opening a file with the wrong mode.
  3. Using ios::out alone when existing data must be preserved.
  4. Not checking whether the file opened successfully.
  5. Trying to read from a file opened only for output.
  6. Trying to write to a file opened only for input.
  7. Ignoring file positions when switching between reading and writing.
  8. Not checking stream state after file operations.

13. Interview Questions

Q1. What is fstream in C++?

fstream is a file stream class used for both reading and writing data to files.

Q2. Which header file is required for fstream?

The <fstream> header file is required.

Q3. What is the difference between ifstream and fstream?

ifstream is used for reading, while fstream supports both reading and writing with suitable opening modes.

Q4. How do you open a file for both reading and writing?

Use fstream with ios::in | ios::out.

Q5. What is seekg()?

seekg() moves the input position in a file.

Q6. What is seekp()?

seekp() moves the output position in a file.

Q7. What is the difference between tellg() and tellp()?

tellg() reports the input position, while tellp() reports the output position.

Q8. Can fstream create a new file?

Yes. It can create a file when opened with suitable output modes.

  • File handling stores and retrieves data from files.
  • ifstream is used for reading files.
  • ofstream is used for writing files.
  • fstream supports both reading and writing.
  • ios::in enables input operations.
  • ios::out enables output operations.
  • ios::app appends data at the end.
  • seekg() and seekp() control file positions.
  • tellg() and tellp() report file positions.
