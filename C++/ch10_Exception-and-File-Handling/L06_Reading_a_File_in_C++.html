1. Introduction to Reading a File

Reading a file means retrieving previously stored data from a file and using it in a C++ program.

C++ provides the ifstream class to read data from files. It is available through the <fstream> header file.

File Reading: It is the process of accessing data stored in a file and transferring that data into a program for processing or display.

Applications of File Reading

  • Reading student and employee records.
  • Retrieving saved configuration settings.
  • Reading text documents and reports.
  • Loading data for calculations and processing.
  • Reading previously saved program information.

2. ifstream Class

The ifstream class stands for Input File Stream. It is mainly used to read data from files.

Header File

#include <fstream>

Declaring an ifstream Object

ifstream file;

Opening a File

file.open("data.txt");

A file can also be opened during object declaration: 

ifstream file("data.txt");
Note: The input file should normally exist. If the file cannot be opened, the stream enters a failure state. Always check the opening status before reading.

3. Reading Data Using the Extraction Operator (>>)

The extraction operator >> can read formatted data from a file. It reads values separated by whitespace, such as spaces, tabs, and newlines.

Example: Reading an Integer

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream file("number.txt");

    int number;

    if (file.is_open())
    {
        file >> number;

        cout << "Number: " << number << endl;

        file.close();
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Suppose number.txt contains:

150
Expected Output: 
Number: 150

The extraction operator reads the integer value from the file and stores it in the variable number.

4. Reading Multiple Values from a File

The extraction operator can read multiple values from a file, one after another.

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream file("numbers.txt");

    int a, b, c;

    if (file.is_open())
    {
        file >> a >> b >> c;

        cout << "First number: " << a << endl;
        cout << "Second number: " << b << endl;
        cout << "Third number: " << c << endl;

        file.close();
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Suppose numbers.txt contains:

10 20 30
Expected Output: 
First number: 10
Second number: 20
Third number: 30

5. Reading a File Line by Line Using getline()

The getline() function reads an entire line from a file, including spaces, until it encounters a newline character.

It is useful when reading names, addresses, sentences, and other text containing spaces.

Syntax

getline(file, line);

Example

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ifstream file("message.txt");

    string line;

    if (file.is_open())
    {
        getline(file, line);

        cout << line << endl;

        file.close();
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Suppose message.txt contains:

Welcome to C++ File Handling
Expected Output: 
Welcome to C++ File Handling

6. Reading an Entire File Line by Line

A loop with getline() can be used to read all lines of a text file until the end of the file is reached.

Example

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ifstream file("data.txt");

    string line;

    if (file.is_open())
    {
        while (getline(file, line))
        {
            cout << line << endl;
        }

        file.close();
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Suppose data.txt contains:

Name: Rahul
Course: C++
Subject: File Handling
Expected Output: 
Name: Rahul
Course: C++
Subject: File Handling

Explanation:

  • getline(file, line) reads one line.
  • The loop continues while a line is successfully read.
  • Each line is displayed using cout.
  • When no more lines can be read, the loop stops.
Important: Prefer while (getline(file, line)) over while (!file.eof()). The latter can process stale or invalid data after a failed read.

7. Reading Characters Using get()

The get() member function reads a single character from a file. It can also read whitespace characters such as spaces and newlines.

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream file("data.txt");

    char ch;

    if (file.is_open())
    {
        while (file.get(ch))
        {
            cout << ch;
        }

        file.close();
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Suppose data.txt contains:

Hello C++
Expected Output: 
Hello C++

The get() function reads one character at a time, including spaces and newline characters.

8. Checking End of File and Stream Status

During file reading, a program must determine whether reading is successful and whether more data is available. C++ provides several stream-state functions.

Function Purpose
eof() Returns true when the end-of-file state has been reached.
good() Returns true when no stream error flags are set.
fail() Returns true when an input or output operation fails in a way that sets the fail state.
bad() Returns true when a serious stream error occurs.
is_open() Checks whether the stream is associated with an open file.
Important: EOF is normally detected when a read operation attempts to go beyond the available input. Therefore, use the read operation itself as the loop condition instead of checking eof() before reading.

9. Complete Program: Read a Student Record

This program reads student information from a text file and displays it on the screen.

Suppose student.txt contains:

101
Amit Sharma
85

C++ Program

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ifstream file("student.txt");

    int rollNo, marks;
    string name;

    if (file.is_open())
    {
        file >> rollNo;

        file.ignore();

        getline(file, name);

        file >> marks;

        if (file)
        {
            cout << "Student Details" << endl;
            cout << "Roll Number: " << rollNo << endl;
            cout << "Name: " << name << endl;
            cout << "Marks: " << marks << endl;
        }
        else
        {
            cout << "Unable to read complete student record." << endl;
        }

        file.close();
    }
    else
    {
        cout << "Unable to open student file." << endl;
    }

    return 0;
}
Expected Output: 
Student Details
Roll Number: 101
Name: Amit Sharma
Marks: 85

Explanation:

  1. The program opens student.txt using ifstream.
  2. The roll number is read using the extraction operator.
  3. ignore() consumes the newline left after reading the roll number.
  4. getline() reads the complete student name, including spaces.
  5. The marks are read using the extraction operator.
  6. The stream state is checked before displaying the record.

10. Difference Between >>, getline() and get()

Feature >> getline() get()
Purpose Formatted input Reads a complete line Reads a character
Reads spaces Stops at whitespace Yes, within the line Yes, one character at a time
Common use Numbers and individual words Names and sentences Character-by-character processing

11. Common Mistakes in File Reading

Mistake Correct Practice
Reading without checking whether the file opened. Check is_open() or stream state.
Using >> to read a full name with spaces. Use getline().
Using while (!file.eof()) as the reading loop. Use while (getline(file, line)) or check each read operation.
Reading after a failed extraction. Check the stream state before using the extracted value.
Forgetting a leftover newline before getline(). Use ignore() when appropriate.

12. Interview Questions

Q1. Which class is used to read files in C++?

The ifstream class is primarily used to read data from files.

Q2. Which header file is required for file reading?

The <fstream> header file is required.

Q3. What is the purpose of getline()?

It reads a complete line from a stream, including spaces, until a newline delimiter is encountered.

Q4. What is the difference between >> and getline()?

The extraction operator normally stops at whitespace, whereas getline() reads the complete line.

Q5. What does get() do?

It reads a single character from an input stream, including whitespace characters.

Q6. Why should we avoid while(!file.eof())?

The EOF flag is generally set after a read operation attempts to read beyond the available input. A loop based on the actual read operation avoids processing stale data.

Q7. What is the purpose of ignore()?

It discards characters from the input stream. It is often used to remove a leftover newline before calling getline().
