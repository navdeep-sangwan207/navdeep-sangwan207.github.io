1. Introduction to File Handling

File handling in C++ allows a program to store data in files and retrieve it later. Unlike variables stored in memory, information saved in a file can remain available after the program terminates.

C++ provides file stream classes through the <fstream> header file.

File Handling: It is the process of creating, opening, reading, writing, and closing files using a program.

Why is File Handling Required?

  • To store data permanently.
  • To retrieve previously stored information.
  • To manage large amounts of data.
  • To maintain records such as student or employee details.
  • To exchange information between programs.

2. File Stream Classes in C++

C++ provides three commonly used file stream classes. These classes are available in the <fstream> header.

Class Purpose
ifstream Used to read data from a file.
ofstream Used to write data to a file.
fstream Used for both reading and writing data.

Basic Syntax

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream inputFile;
    ofstream outputFile;
    fstream file;

    return 0;
}

Each object represents a file stream that can be connected to a file.

3. Opening a File

Before reading or writing data, a file must be opened. C++ provides the open() member function to open a file.

Syntax

fileStreamObject.open("filename");

For example:

ofstream file;
file.open("data.txt");

This creates or opens data.txt for output. If the file does not exist, it is normally created.

Opening a File During Object Creation

A file can also be opened directly when declaring the file stream object. 

ofstream file("data.txt");
ifstream inputFile("data.txt");
Note: The file path is interpreted relative to the program's current working directory unless an absolute path is provided.

4. Closing a File

After completing file operations, the file should be closed using the close() member function.

Syntax

fileStreamObject.close();

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file;

    file.open("data.txt");

    cout << "File opened." << endl;

    file.close();

    cout << "File closed." << endl;

    return 0;
}
Expected Output: 
File opened.
File closed.

Closing a file releases the file stream's connection to that file. Any buffered output is flushed as part of normal stream closing.

File stream objects also close their associated files automatically when they are destroyed. However, explicitly calling close() is useful when you want to finish file operations before the object goes out of scope.

5. Complete Program: Open and Close a File

This program opens a file, checks whether it opened successfully, and then closes it. 

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file;

    file.open("student.txt");

    if (file.is_open())
    {
        cout << "File opened successfully." << endl;

        file.close();

        cout << "File closed successfully." << endl;
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}
Expected Output: 
File opened successfully.
File closed successfully.

Explanation:

  1. <fstream> provides file stream functionality.
  2. An ofstream object is declared.
  3. open() attempts to open student.txt.
  4. is_open() checks whether the file is associated with the stream.
  5. close() closes the file.

6. Checking File Opening Status

A file may fail to open because of an incorrect path, insufficient permissions, or another file-system error. It is important to check the stream state before performing file operations.

Using is_open()

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream file("data.txt");

    if (file.is_open())
    {
        cout << "File opened successfully." << endl;
        file.close();
    }
    else
    {
        cout << "File opening failed." << endl;
    }

    return 0;
}

The is_open() function returns true if the stream is associated with an open file; otherwise, it returns false.

Important: is_open() checks whether the file is open. Stream-state functions such as good(), fail(), and bad() provide additional information about the stream's state.

7. File Opening Modes

C++ provides file opening modes to control how a file is opened.

Mode Purpose
ios::in Opens a file for reading.
ios::out Opens a file for writing.
ios::app Writes new data at the end of the file.
ios::ate Opens the file and initially positions the file pointer at the end.
ios::trunc Discards existing contents when opening an output file.
ios::binary Opens a file in binary mode.

Example: Opening with a Mode

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file;

    file.open("data.txt", ios::out);

    if (file.is_open())
    {
        cout << "File opened in output mode." << endl;
        file.close();
    }

    return 0;
}

Combining File Modes

Multiple file modes can be combined using the bitwise OR operator (|). 

fstream file;

file.open("data.txt", ios::in | ios::out);
Note: Opening an existing file with ios::out generally truncates its contents unless a mode such as ios::app or ios::in changes the opening behavior. Choose the mode carefully to avoid losing existing data.

8. Difference Between ifstream, ofstream and fstream

Feature ifstream ofstream fstream
Full form Input File Stream Output File Stream File Stream
Reading Yes No, not by default Yes, when opened with input mode
Writing No, not by default Yes Yes, when opened with output mode
Header <fstream> <fstream> <fstream>

9. Common Mistakes in File Handling

Mistake Correct Practice
Using a file without opening it. Open the file before performing file operations.
Not checking whether the file opened. Use is_open() or check the stream state.
Using an incorrect file path. Verify the file path and working directory.
Using output mode without considering existing contents. Choose the appropriate opening mode to prevent accidental truncation.
Forgetting to finish file operations. Close the file explicitly when finished.

10. Interview Questions

Q1. What is file handling in C++?

File handling is the process of storing and retrieving data using files.

Q2. Which header file is required for file handling?

The <fstream> header is used for file input and output operations.

Q3. What is the purpose of ofstream?

ofstream is used to write data to files.

Q4. What is the purpose of ifstream?

ifstream is used to read data from files.

Q5. What is the purpose of fstream?

fstream supports both input and output file operations when opened with the appropriate modes.

Q6. What is the difference between open() and close()?

open() connects a file stream to a file. close() closes that connection.

Q7. What is is_open()?

It checks whether a file stream is currently associated with an open file.

Q8. What is ios::app?

It opens a file in append mode so that new output is written at the end of the file.
