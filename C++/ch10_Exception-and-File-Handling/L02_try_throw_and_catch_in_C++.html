Understanding the Three Fundamental Keywords of Exception Handling

1. Introduction to try, throw and catch

C++ provides three fundamental keywords for implementing exception handling: try, throw, and catch.

These keywords work together to detect exceptional conditions, transfer control, and handle exceptions without mixing all error-handling logic with normal program statements.

Basic Concept:
  • try: Contains code that may throw an exception.
  • throw: Signals an exception.
  • catch: Handles a matching exception.

2. try Block

The try block contains statements that may generate an exception. If an exception is thrown inside the try block, control is transferred to a matching catch handler.

Syntax

try { // Statements that may throw an exception }

Example

#include <iostream> using namespace std; int main() { try { cout << "Inside try block" << endl; } return 0; }
This example only demonstrates the try block. A complete exception-handling construct requires an associated catch handler.

Important Points

  • The try block defines a protected region of code.
  • It can contain multiple statements.
  • An exception may be thrown directly or by a function called inside it.
  • When an exception is thrown, the remaining statements in that try block are skipped.
  • A try block must be followed by at least one catch handler.

3. throw Keyword

The throw keyword is used to signal an exception. It transfers control from the point where the exception is thrown to a matching catch handler.

C++ allows values and objects of different types to be thrown as exceptions.

Syntax

throw expression;

Example: Throwing an Integer

#include <iostream> using namespace std; int main() { try { throw 100; } catch (int x) { cout << "Exception value: " << x; } return 0; }
Expected Output: 
Exception value: 100

Different Types of Values That Can Be Thrown

throw 10; // Integer throw 10.5; // Double throw 'A'; // Character throw "Error"; // String literal throw string("Error"); // std::string object
The type of the thrown expression is important because the catch handler must be compatible with that type. A string literal such as "Error" is thrown as a pointer to const char, not as an std::string object.

Important Points

  • The throw statement signals an exception.
  • It can throw built-in types or class objects.
  • Statements after a throw in the same execution path are skipped.
  • The exception is transferred to a matching handler.
  • Exception propagation can move through multiple function calls.

4. catch Block

The catch block handles an exception thrown from the associated try block. It receives the thrown value or object through its parameter.

Syntax

catch (data_type variable) { // Exception handling statements }

Example

#include <iostream> using namespace std; int main() { try { throw 50; } catch (int x) { cout << "Caught exception: " << x; } return 0; }
Expected Output: 
Caught exception: 50

Important Points

  • A catch block handles a matching exception.
  • Its parameter specifies the exception type.
  • Multiple catch blocks can handle different types.
  • A catch handler can receive an exception by reference.
  • A catch-all handler can be written using catch (...).

5. Complete Working of try, throw and catch

The following example demonstrates all three keywords working together.

Program

#include <iostream> using namespace std; int main() { int age = 15; try { if (age < 18) { throw age; } cout << "You are eligible." << endl; } catch (int x) { cout << "Exception caught!" << endl; cout << "Age is " << x << ". You are not eligible." << endl; } cout << "Program completed." << endl; return 0; }

Expected Output

Exception caught!
Age is 15. You are not eligible.
Program completed.

Explanation

  1. The variable age is initialized with value 15.
  2. The program enters the try block.
  3. The condition age < 18 is true.
  4. The statement throw age; throws the integer value 15.
  5. The remaining statements in the try block are skipped.
  6. The catch block receives the value in variable x.
  7. The exception message is displayed.
  8. Execution continues after the try-catch construct.

6. Exception Handling with Division

A common example of exception handling is checking whether a denominator is zero before performing integer division.

Program

#include <iostream> using namespace std; int main() { int a = 20; int b = 0; try { if (b == 0) { throw "Division by zero is not allowed."; } cout << "Result = " << a / b << endl; } catch (const char* message) { cout << "Exception: " << message << endl; } return 0; }

Expected Output

Exception: Division by zero is not allowed.

Explanation

  • The numerator is initialized to 20.
  • The denominator is initialized to 0.
  • The program checks the denominator before division.
  • If it is zero, a string literal exception is thrown.
  • The catch block receives it as const char*.
  • The error message is displayed instead of performing division.
Never perform integer division by zero and expect exception handling to detect it automatically. The condition must be checked before the division.

7. Exception Handling with Functions

An exception can be thrown from a function called inside a try block. The exception can then be caught by the caller.

Program

#include <iostream> using namespace std; void checkNumber(int num) { if (num < 0) { throw num; } cout << "Positive number: " << num << endl; } int main() { try { checkNumber(-5); } catch (int x) { cout << "Negative number exception: " << x << endl; } cout << "Program continues." << endl; return 0; }

Expected Output

Negative number exception: -5
Program continues.

Explanation

  1. The main function calls checkNumber(-5).
  2. The function checks whether the number is negative.
  3. The function throws the value -5.
  4. Control returns through exception propagation.
  5. The catch block in main handles the integer exception.
  6. The program continues after the handler.

8. Catching an Exception by Reference

C++ allows exceptions to be caught by value or by reference. Catching class-type exceptions by reference avoids unnecessary copying and helps preserve the original exception object's dynamic type.

Example

#include <iostream> #include <string> using namespace std; int main() { try { string message = "Invalid operation"; throw message; } catch (const string& error) { cout << "Exception: " << error << endl; } return 0; }
Expected Output: 
Exception: Invalid operation
For standard library exceptions and polymorphic exception hierarchies, catching by const reference is generally preferred.

9. Catch-All Handler

C++ provides a special catch-all handler using catch (...). It can handle an exception of any type.

Syntax

catch (...) { // Handles any exception type }

Example

#include <iostream> using namespace std; int main() { try { throw 10.5; } catch (...) { cout << "Unknown exception caught." << endl; } return 0; }
Expected Output: 
Unknown exception caught.
A catch-all handler should normally be placed after more specific catch handlers because it can match any exception type.

10. Difference Between try, throw and catch

Keyword Purpose Role
try Defines a block containing code that may throw. Protects code.
throw Signals an exception. Raises an exception.
catch Handles a matching exception. Handles an exception.

11. Common Mistakes in Exception Handling

1. Mismatched Exception Type

If an integer is thrown but only a handler for a different unrelated type is provided, that handler will not match.

2. Statements After throw

Statements after a throw statement in the same execution path are not executed.

3. Incorrect Catch Order

A general handler should not be placed before a more specific handler when the general handler would make the specific one unreachable.

4. Ignoring Unhandled Exceptions

If no matching handler is found, an exception propagates outward and may terminate the program.

5. Catching Exceptions by Value Unnecessarily

Catching polymorphic exception objects by value can cause object slicing. Prefer catching them by const reference.

12. Interview Questions and Answers

Q1. What is the purpose of the try block?

It contains code that may generate an exception.

Q2. What does the throw keyword do?

It signals an exception and transfers control to a matching exception handler.

Q3. What is the purpose of the catch block?

It receives and handles a matching thrown exception.

Q4. Can we throw different data types?

Yes. C++ allows built-in types and user-defined objects to be thrown.

Q5. Can a function throw an exception?

Yes. An exception thrown inside a function can propagate to a matching handler in its caller.

Q6. What is catch (...)?

It is a catch-all handler that can handle exceptions of any type.

Q7. What happens after an exception is caught?

After the catch handler finishes, execution continues after the complete try-catch construct.

Q8. Can we use multiple catch blocks?

Yes. Multiple catch blocks can handle different exception types. This is covered in Lesson 03.

Q9. What happens if no catch block matches?

The exception propagates to an enclosing handler. If it remains unhandled, the program terminates.

Q10. Why is catch by reference preferred?

It avoids unnecessary copying and prevents object slicing when handling polymorphic exception objects.

14. Lesson Summary

  • try defines the block containing potentially exceptional code.
  • throw signals an exception.
  • catch handles a matching exception.
  • Different data types and objects can be thrown.
  • Exceptions can propagate from functions to their callers.
  • catch (...) handles exceptions of any type.
  • Catching polymorphic exceptions by const reference is preferred.
