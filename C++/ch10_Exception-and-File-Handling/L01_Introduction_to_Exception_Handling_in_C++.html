1. Introduction to Exception Handling

Exception Handling is a mechanism in C++ used to handle runtime errors and unexpected situations that occur during program execution.

An exception represents an abnormal condition that interrupts the normal flow of program execution. Exception handling allows a program to detect such conditions and respond to them in a controlled manner.

Definition: Exception handling is a mechanism used to detect and handle runtime errors without allowing the program to terminate unexpectedly.

Why is Exception Handling Required?

Consider a program that performs division:

#include <iostream> using namespace std; int main() { int a = 10; int b = 0; int result = a / b; cout << "Result = " << result; return 0; }
Important: Integer division by zero has undefined behavior in C++. This program does not provide a valid division result. A division-by-zero check should be performed before carrying out the operation.

Exception handling provides a structured way to report and handle exceptional conditions. It does not automatically make every invalid operation safe; the programmer must identify and handle the condition.

2. What is an Exception?

An exception is an event or condition that occurs during program execution and requires special handling.

In C++, an exception can be thrown using the throw keyword. The thrown value or object is transferred to a matching exception handler.

Examples of Exceptional Conditions

  • Attempting to divide an integer by zero.
  • Trying to open a file that does not exist.
  • Accessing a resource that is unavailable.
  • Invalid input supplied to a program.
  • Memory allocation failure.
Not every programming error is automatically converted into a C++ exception. For example, accessing an array outside its valid bounds using the built-in subscript operator does not automatically throw an exception.

3. Types of Errors in Programming

Programming errors can be broadly classified into different categories.

Error Type Description Example
Syntax Error Occurs when program syntax rules are violated. Missing semicolon.
Compile-Time Error Detected by the compiler during compilation. Using an undeclared variable.
Runtime Error Occurs while the program is executing. Invalid resource operation.
Logical Error Program executes but produces an incorrect result. Using addition instead of subtraction.
Exception handling mainly deals with exceptional conditions during program execution. It does not correct syntax errors or logical mistakes automatically.

4. Traditional Error Handling

Before using exception handling, programmers often check conditions manually and return error codes or status values.

Example: Division Using if-else

#include <iostream> using namespace std; int main() { int a = 20; int b = 0; if (b == 0) { cout << "Error: Division by zero is not allowed."; } else { cout << "Result = " << a / b; } return 0; }
Expected Output: 
Error: Division by zero is not allowed.

Limitations of Traditional Error Handling

  • Error-checking code may be repeated in many places.
  • Error-handling logic can become mixed with normal program logic.
  • Returning error codes may make complex programs harder to manage.
  • Every function caller must correctly check the returned status.

C++ exception handling provides a separate mechanism for transferring control to code that handles exceptional conditions.

5. Exception Handling Mechanism in C++

C++ provides three main keywords for exception handling:

Keyword Purpose
try Defines a block of code in which exceptions may occur.
throw Signals an exception by throwing a value or object.
catch Defines a handler that receives a matching thrown exception.

Basic Syntax

try { // Code that may throw an exception throw exception_value; } catch (data_type variable) { // Exception handling code }

How Exception Handling Works

  1. The program enters the try block.
  2. If an exceptional condition occurs, an exception is thrown using throw.
  3. The remaining statements in that try block are skipped.
  4. The program searches for a matching catch handler.
  5. The matching catch block executes.
  6. After the handler finishes, execution continues after the handled try-catch construct.
If no matching handler is found, the exception propagates outward through the call stack. If it remains unhandled, the program terminates.

6. First Exception Handling Program

The following program demonstrates how an exception can be thrown and caught in C++.

#include <iostream> using namespace std; int main() { try { cout << "Inside try block" << endl; throw 100; cout << "This statement will not execute" << endl; } catch (int x) { cout << "Exception caught: " << x << endl; } cout << "Program continues..." << endl; return 0; }

Expected Output

Inside try block
Exception caught: 100
Program continues...

Explanation

  • The program enters the try block.
  • throw 100; throws an integer exception.
  • The statement immediately after throw is skipped.
  • catch (int x) receives the integer value.
  • The catch block prints the exception value.
  • Execution continues after the try-catch construct.

7. Advantages of Exception Handling

  • Separates error handling: Exceptional conditions can be handled separately from normal program logic.
  • Improves readability: Makes complex error-handling code easier to organize.
  • Exception propagation: An exception can travel through function calls until a suitable handler is found.
  • Supports different exception types: Different catch handlers can handle different types of exceptions.
  • Supports resource cleanup: C++ stack unwinding invokes destructors of automatic objects when an exception propagates.

8. Important Rules of Exception Handling

  1. A try block must be followed by at least one catch handler or another valid exception-handling arrangement.
  2. The throw statement transfers control away from the current block.
  3. A catch handler must match the thrown exception type or be a compatible handler.
  4. Multiple catch blocks can be used to handle different exception types.
  5. A catch-all handler can be written as catch (...).
  6. If an exception is not handled, it may cause program termination.
  7. Destructors of automatic local objects are called during stack unwinding.
Good Programming Practice: Catch exceptions by reference when handling polymorphic exception objects. For standard library exceptions, a common pattern is catch (const std::exception& e).

9. Difference Between Error Codes and Exceptions

Basis Error Codes Exceptions
Mechanism Returns status values. Uses throw and catch.
Control Flow Normal function return. Transfers control to a handler.
Handling Caller checks return values. Matching catch handler handles exception.
Organization Error checks may be repeated. Can separate normal and exceptional logic.

10. Interview Questions and Answers

Q1. What is exception handling in C++?

Exception handling is a mechanism used to detect and handle exceptional conditions during program execution.

Q2. Which keywords are used in exception handling?

The three main keywords are try, throw, and catch.

Q3. What is an exception?

An exception is an event or condition that interrupts normal program execution and requires special handling.

Q4. What is the purpose of the try block?

The try block contains code that may throw an exception.

Q5. What is the purpose of the throw keyword?

The throw keyword signals an exception and transfers control to a matching handler.

Q6. What is the purpose of the catch block?

The catch block handles an exception thrown from the associated try block.

Q7. What happens if an exception is not caught?

The exception propagates through the call stack. If no matching handler is found, the program terminates.

Q8. Does exception handling prevent all runtime errors?

No. It handles exceptions that are thrown, but it does not automatically detect every runtime error or undefined behavior.

Q9. What is stack unwinding?

Stack unwinding is the process of destroying automatic local objects while control moves out of scopes during exception propagation.

Q10. What is a catch-all handler?

A catch-all handler uses catch (...) to handle exceptions of any type.

Practice Tip: Compile and execute these programs using GCC or G++ with a C++ compiler standard such as C++11 or later.

12. Lesson Summary

  • Exception handling manages exceptional conditions during program execution.
  • An exception is signaled using the throw keyword.
  • The try block contains code that may throw exceptions.
  • The catch block handles matching exceptions.
  • Exception handling separates exceptional logic from normal program flow.
  • Unhandled exceptions can cause program termination.
  • Stack unwinding calls destructors of automatic local objects.
