1. Introduction to Writing a File

Writing to a file means storing data from a C++ program into a file. The stored information can be retrieved later, even after the program terminates.

C++ provides the ofstream class to write data into files. It is available through the <fstream> header file.

File Writing: It is the process of transferring data from a program into a file for permanent storage.

Applications of File Writing

  • Saving student and employee records.
  • Generating reports and text documents.
  • Storing program output for future use.
  • Maintaining application logs.
  • Saving configuration and settings information.

2. ofstream Class

The ofstream class stands for Output File Stream. It is primarily used to write data into files.

Header File

#include <fstream>

Declaring an ofstream Object

ofstream file;

Opening a File

file.open("data.txt");

A file can also be opened during object declaration: 

ofstream file("data.txt");
Important: Opening an existing file with the default output mode generally removes its previous contents. Use append mode when you want to preserve existing data.

3. Writing Data Using the Insertion Operator (<<)

The insertion operator << is used to write formatted data into a file.

Syntax

fileStreamObject << data;

Example: Writing Text to a File

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file("message.txt");

    if (file.is_open())
    {
        file << "Welcome to C++ File Handling";

        file.close();

        cout << "Data written successfully." << endl;
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}
Console Output: 
Data written successfully.

Contents of message.txt:

Welcome to C++ File Handling

The text is stored in the file instead of being displayed on the console.

4. Writing Multiple Lines to a File

Multiple lines can be written using the insertion operator and the newline manipulator endl, or the newline character \n.

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file("details.txt");

    if (file.is_open())
    {
        file << "Name: Rahul" << endl;
        file << "Course: C++" << endl;
        file << "Subject: File Handling" << endl;

        file.close();

        cout << "Multiple lines written successfully." << endl;
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}
Console Output: 
Multiple lines written successfully.

Contents of details.txt:

Name: Rahul
Course: C++
Subject: File Handling

5. Writing Different Data Types

The insertion operator can write different data types, including integers, floating-point values, characters, and strings.

Example

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ofstream file("student.txt");

    int rollNo = 101;
    string name = "Amit Sharma";
    float marks = 85.5f;

    if (file.is_open())
    {
        file << "Roll Number: " << rollNo << endl;
        file << "Name: " << name << endl;
        file << "Marks: " << marks << endl;

        file.close();

        cout << "Student record saved." << endl;
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Contents of student.txt:

Roll Number: 101
Name: Amit Sharma
Marks: 85.5

The program writes the values of different variables into the file using the same insertion operator.

6. Writing Data Using the put() Function

The put() member function writes a single character to an output stream.

Syntax

file.put(character);

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file("characters.txt");

    if (file.is_open())
    {
        file.put('H');
        file.put('E');
        file.put('L');
        file.put('L');
        file.put('O');

        file.close();

        cout << "Characters written successfully." << endl;
    }
    else
    {
        cout << "Unable to open file." << endl;
    }

    return 0;
}

Contents of characters.txt:

HELLO

7. Writing Data Using File Opening Modes

File opening modes determine how a file is accessed. Different modes can be used depending on whether existing contents should be replaced or preserved.

Mode Purpose
ios::out Opens a file for output. Existing contents are generally truncated.
ios::app Writes new data at the end of the file.
ios::ate Initially positions the file pointer at the end after opening.
ios::trunc Discards existing file contents when opening for output.
ios::binary Opens the file in binary mode.

Example: Writing with ios::out

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file;

    file.open("data.txt", ios::out);

    if (file.is_open())
    {
        file << "New file content";

        file.close();

        cout << "Data written successfully." << endl;
    }

    return 0;
}
Remember: The normal output mode ios::out generally truncates an existing file. Use ios::app to append new content.

8. Checking Writing Status

A program should check whether the file opened successfully and whether writing operations completed without errors.

Example

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file("output.txt");

    if (!file.is_open())
    {
        cout << "Unable to open file." << endl;
        return 1;
    }

    file << "Learning C++ File Handling";

    if (file)
    {
        cout << "Writing completed successfully." << endl;
    }
    else
    {
        cout << "Error while writing." << endl;
    }

    file.close();

    return 0;
}
Expected Console Output: 
Writing completed successfully.

Checking the stream after writing helps detect output failures. For critical file operations, also check the stream after closing because final buffered output may fail during flushing or closing.

9. Complete Program: Save Employee Details

This program accepts employee information from the keyboard and stores it in a text file.

C++ Program

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ofstream file("employee.txt");

    int id;
    string name;
    float salary;

    if (!file.is_open())
    {
        cout << "Unable to open file." << endl;
        return 1;
    }

    cout << "Enter Employee ID: ";
    cin >> id;

    cin.ignore();

    cout << "Enter Employee Name: ";
    getline(cin, name);

    cout << "Enter Employee Salary: ";
    cin >> salary;

    file << "Employee ID: " << id << endl;
    file << "Employee Name: " << name << endl;
    file << "Employee Salary: " << salary << endl;

    file.close();

    if (file)
    {
        cout << "Employee details saved." << endl;
    }
    else
    {
        cout << "Error while saving employee details." << endl;
    }

    return 0;
}

Sample Input:

Enter Employee ID: 101
Enter Employee Name: Amit Sharma
Enter Employee Salary: 25000
Expected Console Output: 
Employee details saved.

Contents of employee.txt:

Employee ID: 101
Employee Name: Amit Sharma
Employee Salary: 25000

10. Difference Between << and put()

Feature << Operator put() Function
Purpose Writes formatted data. Writes one character.
Data types Supports many data types through stream insertion. Writes a character.
Example file << "Hello"; file.put('A');
Common use Writing text, numbers, and formatted output. Writing individual characters.

11. Common Mistakes in File Writing

Mistake Correct Practice
Writing without opening the file. Open the file before writing.
Not checking whether the file opened. Use is_open() or check the stream state.
Accidentally overwriting existing data. Use ios::app when appending is required.
Using put() to write an entire string. Use the << operator for strings.
Assuming a successful open guarantees successful writing. Check the stream state after writing and closing.

12. Interview Questions

Q1. Which class is used to write data into a file?

The ofstream class is primarily used to write data into files.

Q2. Which header file is required for file writing?

The <fstream> header file is required.

Q3. What is the purpose of the insertion operator?

The << operator writes formatted data into an output stream.

Q4. What is the purpose of put()?

The put() function writes a single character into an output stream.

Q5. What happens when an existing file is opened in the default output mode?

Its existing contents are generally truncated.

Q6. What is the purpose of ios::app?

It opens a file in append mode so that new output is written at the end of the file.

Q7. Why should we check the stream after writing?

It helps detect errors that occur during output operations.
