Lesson Overview

Operator overloading is an important feature of C++ that allows existing operators to work with user-defined data types such as classes and objects.

It enables programmers to define how operators behave when they are used with objects, making programs easier to read and write.

1. Learning Objectives

  • Understand the meaning of operator overloading.
  • Learn why operator overloading is used in C++.
  • Understand how operators can work with class objects.
  • Learn the basic syntax of operator overloading.
  • Understand the difference between built-in and user-defined operations.

2. What is Operator Overloading?

Operator overloading is a feature in C++ that allows an operator such as +, -, * or == to be given a special meaning when used with objects of a user-defined class.

Normally, operators work with built-in data types such as int, float and double. With operator overloading, we can define their behaviour for class objects.

Definition: Operator overloading is the process of providing additional meaning to an existing C++ operator for user-defined data types.

3. Why Do We Need Operator Overloading?

Consider two objects representing complex numbers. We want to add them using the familiar + operator.

Without operator overloading, we might write:

result = c1.add(c2);

With operator overloading, we can write:

result = c1 + c2;

The overloaded operator makes the expression more natural and improves code readability.

4. Basic Syntax of Operator Overloading

The operator keyword is used to define an overloaded operator function.

return_type operator symbol (arguments) { // Function body }

Example of Function Declaration

class Sample { public: Sample operator+(const Sample& obj); };

In this declaration:

  • Sample is the return type.
  • operator+ defines the overloaded addition operator.
  • const Sample& obj is the argument.

5. First Program: Adding Two Objects Using Operator Overloading

This program overloads the + operator to add two objects of a class.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } Number operator+(const Number& obj) { Number temp; temp.value = value + obj.value; return temp; } void display() { cout << "Value: " << value << endl; } }; int main() { Number n1(10); Number n2(20); Number n3 = n1 + n2; cout << "First object: "; n1.display(); cout << "Second object: "; n2.display(); cout << "Result object: "; n3.display(); return 0; }

Expected Output

First object: Value: 10
Second object: Value: 20
Result object: Value: 30

Program Explanation

  1. The Number class contains a private integer member named value.
  2. The constructor initializes the value of each object.
  3. The operator+ function overloads the addition operator.
  4. It adds the current object's value to the argument object's value.
  5. The result is stored in a temporary object and returned.
  6. The expression n1 + n2 invokes the overloaded operator function.
Important: In the expression n1 + n2, the compiler treats the operation as n1.operator+(n2) for this member operator overload.

6. How Operator Overloading Works

Consider the expression:

Number n3 = n1 + n2;

The operation follows these steps:

  1. The compiler identifies the overloaded + operator.
  2. The left-hand object n1 calls the member operator function.
  3. The right-hand object n2 is passed as an argument.
  4. The function adds the two values.
  5. The function returns a new object containing the result.
Concept: Operator overloading does not create a new operator. It defines how an existing operator behaves with user-defined types.

7. Operators That Can Be Overloaded

Many existing C++ operators can be overloaded for user-defined types.

Category Operators
Arithmetic +, -, *, /, %
Relational ==, !=, <, >, <=, >=
Logical !, &&, ||
Assignment =, +=, -=, *=, /=
Increment / Decrement ++, --
Bitwise &, |, ^, ~, <<, >>
Other [], (), ->, new, delete

8. Operators That Cannot Be Overloaded

Some operators are not allowed to be overloaded in C++.

Operator Name
:: Scope resolution operator
. Member access operator
.* Pointer-to-member access operator
?: Conditional operator
sizeof Size operator
Remember: Operator overloading cannot change an operator's precedence, associativity or number of operands.

9. Rules of Operator Overloading

  • Only existing C++ operators can be overloaded.
  • At least one operand must be a user-defined type when overloading an operator.
  • Operator precedence cannot be changed.
  • Operator associativity cannot be changed.
  • The number of operands cannot be changed.
  • The meaning of operators for built-in types cannot be redefined.
  • Some operators, such as ::, . and ?:, cannot be overloaded.

10. Advantages of Operator Overloading

  • Improves code readability.
  • Makes expressions more natural.
  • Allows operators to work with user-defined objects.
  • Supports abstraction in object-oriented programming.
  • Can make mathematical operations on objects easier to express.

11. Limitations of Operator Overloading

  • Not every operator can be overloaded.
  • Operator precedence and associativity remain unchanged.
  • Unclear operator definitions can make code difficult to understand.
  • Overloading should preserve intuitive meaning wherever possible.

12. Interview Questions

Q1. What is operator overloading?

Operator overloading is a C++ feature that allows existing operators to work with user-defined data types.

Q2. Which keyword is used for operator overloading?

The operator keyword is used.

Q3. Can we overload all operators in C++?

No. Certain operators, such as ::, . and ?:, cannot be overloaded.

Q4. Can we change operator precedence?

No. Operator overloading cannot change precedence or associativity.

Q5. What is the purpose of operator overloading?

It allows operators to work with class objects and makes expressions more readable and natural.

Q6. Is operator overloading an example of compile-time polymorphism?

Yes. Operator overloading is a form of compile-time polymorphism.

14. Lesson Summary

  • Operator overloading gives existing operators additional meaning for user-defined types.
  • The operator keyword is used to define an overloaded operator function.
  • It makes object operations more readable.
