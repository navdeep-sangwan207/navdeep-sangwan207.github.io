Lesson Overview

Unary operators operate on a single operand. C++ allows us to overload unary operators so that they can perform operations on objects of user-defined classes.

In this lesson, we will learn how to overload unary operators such as increment (++), decrement (--), unary minus (-) and logical NOT (!).

1. Learning Objectives

  • Understand unary operators in C++.
  • Learn how unary operator overloading works.
  • Overload the increment operator (++).
  • Understand prefix and postfix increment.
  • Overload decrement and unary minus operators.
  • Understand the difference between prefix and postfix forms.

2. What Are Unary Operators?

Unary operators are operators that perform an operation on only one operand.

Examples of Unary Operators

Operator Name Example
++ Increment ++a
-- Decrement --a
- Unary minus -a
! Logical NOT !a
~ Bitwise NOT ~a
Definition: A unary operator performs an operation on a single operand. Unary operator overloading defines how such an operator behaves when applied to a class object.

3. Syntax of Unary Operator Overloading

A unary operator can be overloaded using a member function inside a class.

return_type operator symbol() { // Function body }

Example Declaration

class Number { public: void operator-(); };

Here, operator-() overloads the unary minus operator for objects of the Number class.

Important: For a unary operator overloaded as a member function, no explicit argument is required. The object on the left side invokes the function.

4. Overloading Unary Minus (-) Operator

The unary minus operator changes the sign of a number. We can overload it to change the sign of a data member inside an object.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v) { value = v; } void operator-() { value = -value; } void display() { cout << "Value: " << value << endl; } }; int main() { Number n1(10); cout << "Before overloading: "; n1.display(); -n1; cout << "After overloading: "; n1.display(); return 0; }

Expected Output

Before overloading: Value: 10
After overloading: Value: -10

Program Explanation

  1. The class Number contains a private integer member.
  2. The constructor initializes the value to 10.
  3. The operator-() function overloads unary minus.
  4. Inside the function, the sign of the value is reversed.
  5. The statement -n1 invokes the overloaded operator.

5. Overloading Prefix Increment (++) Operator

The increment operator increases a value by one. Prefix increment places the operator before the operand.

Example:

++a;

C++ Program

#include <iostream> using namespace std; class Counter { private: int count; public: Counter(int c = 0) { count = c; } void operator++() { ++count; } void display() { cout << "Count: " << count << endl; } }; int main() { Counter c1(5); cout << "Before increment: "; c1.display(); ++c1; cout << "After increment: "; c1.display(); return 0; }

Expected Output

Before increment: Count: 5
After increment: Count: 6

Explanation

  • operator++() overloads the prefix increment operator.
  • The function increases the object's count by one.
  • The statement ++c1 calls the overloaded function.

6. Overloading Postfix Increment (++) Operator

Postfix increment places the operator after the operand.

Example:

a++;

In a postfix operator overload, an unused integer parameter distinguishes it from prefix increment.

Syntax

return_type operator++(int) { // Function body }

C++ Program

#include <iostream> using namespace std; class Counter { private: int count; public: Counter(int c = 0) { count = c; } Counter operator++(int) { Counter temp = *this; count++; return temp; } void display() { cout << "Count: " << count << endl; } }; int main() { Counter c1(5); cout << "Before increment: "; c1.display(); c1++; cout << "After increment: "; c1.display(); return 0; }

Expected Output

Before increment: Count: 5
After increment: Count: 6

Explanation

  1. operator++(int) defines postfix increment.
  2. The integer parameter is a dummy parameter used to distinguish postfix from prefix.
  3. Counter temp = *this; saves the object's original state.
  4. count++ increments the current object's value.
  5. The saved object is returned.
Remember: The dummy integer parameter is not used to increment the value. It only distinguishes postfix from prefix operator overloading.

7. Prefix vs Postfix Increment

Feature Prefix Postfix
Syntax ++obj obj++
Function operator++() operator++(int)
Parameter No explicit parameter Dummy integer parameter
Typical behaviour Increment, then use updated value Use old value, then increment
Return convention Usually returns updated object by reference Usually returns old value by value
Key Difference: Prefix increment changes the value before the expression uses it. Postfix increment preserves the old value for the expression and then increments the object.

8. Overloading Decrement (--) Operator

The decrement operator decreases a value by one. It can be overloaded in both prefix and postfix forms.

Prefix Decrement Example

#include <iostream> using namespace std; class Counter { private: int count; public: Counter(int c) { count = c; } void operator--() { --count; } void display() { cout << "Count: " << count << endl; } }; int main() { Counter c1(10); --c1; c1.display(); return 0; }

Expected Output

Count: 9

The function operator--() overloads prefix decrement and reduces the object's count by one.

9. Overloading Logical NOT (!) Operator

The logical NOT operator reverses a Boolean condition. It can also be overloaded for user-defined objects.

C++ Program

#include <iostream> using namespace std; class Test { private: int value; public: Test(int v) { value = v; } bool operator!() { return value == 0; } }; int main() { Test t1(0); Test t2(10); cout << "!t1 = " << !t1 << endl; cout << "!t2 = " << !t2 << endl; return 0; }

Expected Output

!t1 = 1
!t2 = 0

Explanation

  • The operator!() function returns a Boolean value.
  • It returns true when the object's value is zero.
  • It returns false when the object's value is non-zero.

10. Important Rules

  • Unary operators work with one operand.
  • Unary operators can be overloaded using member functions or suitable non-member functions.
  • For a member unary operator, no explicit argument is needed.
  • Prefix and postfix increment/decrement have different function signatures.
  • The dummy integer parameter distinguishes postfix from prefix.
  • Operator overloading cannot change an operator's precedence or associativity.

11. Interview Questions

Q1. What is a unary operator?

An operator that performs an operation on a single operand.

Q2. Give examples of unary operators.

Increment (++), decrement (--), unary minus (-), logical NOT (!) and bitwise NOT (~).

Q3. How do we overload a unary operator?

We define an operator function using the operator keyword inside a class or as a suitable non-member function.

Q4. What is the difference between prefix and postfix increment?

Prefix increments before the expression uses the value. Postfix preserves the old value for the expression and then increments the object.

Q5. Why is an integer parameter used in postfix overloading?

It is a dummy parameter that distinguishes the postfix operator function from the prefix version.

Q6. Can we overload the unary minus operator?

Yes. The unary minus operator can be overloaded for class objects.

  • Unary operators operate on one operand.
