Lesson Overview

Binary operators perform operations on two operands. C++ allows programmers to overload binary operators so that they can operate on objects of user-defined classes.

In this lesson, we will learn how to overload arithmetic, relational and assignment operators using member functions.

1. Learning Objectives

  • Understand binary operators in C++.
  • Learn the syntax of binary operator overloading.
  • Overload arithmetic operators such as +, -, * and /.
  • Understand how two objects interact using operators.
  • Overload relational operators.
  • Understand member-function-based operator overloading.

2. What Are Binary Operators?

Binary operators are operators that perform an operation on two operands.

Examples of Binary Operators

Operator Name Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Modulus a % b
== Equal to a == b
< Less than a < b
> Greater than a > b
Definition: A binary operator performs an operation on two operands. Binary operator overloading defines how that operator behaves when used with user-defined objects.

3. Syntax of Binary Operator Overloading

A binary operator can be overloaded using a member function inside a class.

return_type operator symbol (arguments) { // Function body }

Example Declaration

class Number { public: Number operator+(const Number& obj); };

Here:

  • operator+ overloads the addition operator.
  • obj represents the right-hand operand.
  • The calling object represents the left-hand operand.
  • The function returns the resulting object.
Important: When a binary operator is overloaded as a member function, the function receives one explicit argument for the right-hand operand.

4. Overloading Addition (+) Operator

We can overload the addition operator to add the values stored in two objects.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } Number operator+(const Number& obj) { Number temp; temp.value = value + obj.value; return temp; } void display() { cout << "Value: " << value << endl; } }; int main() { Number n1(10); Number n2(20); Number n3 = n1 + n2; cout << "First object: "; n1.display(); cout << "Second object: "; n2.display(); cout << "Addition result: "; n3.display(); return 0; }

Expected Output

First object: Value: 10
Second object: Value: 20
Addition result: Value: 30

Program Explanation

  1. The Number class contains a private integer member.
  2. The constructor initializes the value of each object.
  3. The operator+ function overloads the addition operator.
  4. The current object's value is added to the argument object's value.
  5. The result is stored in a temporary object.
  6. The temporary object is returned to the calling expression.
Compiler interpretation: The expression n1 + n2 invokes n1.operator+(n2) for this member overload.

5. Overloading Subtraction (-) Operator

The subtraction operator can be overloaded to subtract the value of one object from another.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } Number operator-(const Number& obj) { Number temp; temp.value = value - obj.value; return temp; } void display() { cout << "Result: " << value << endl; } }; int main() { Number n1(50); Number n2(20); Number n3 = n1 - n2; n3.display(); return 0; }

Expected Output

Result: 30

6. Overloading Multiplication (*) Operator

The multiplication operator can be overloaded to multiply the values stored in two objects.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } Number operator*(const Number& obj) { Number temp; temp.value = value * obj.value; return temp; } void display() { cout << "Result: " << value << endl; } }; int main() { Number n1(5); Number n2(4); Number n3 = n1 * n2; n3.display(); return 0; }

Expected Output

Result: 20

7. Overloading Relational (==) Operator

Relational operators compare two values. We can overload them to compare objects.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v) { value = v; } bool operator==(const Number& obj) { return value == obj.value; } }; int main() { Number n1(10); Number n2(10); Number n3(20); if (n1 == n2) cout << "n1 and n2 are equal" << endl; else cout << "n1 and n2 are not equal" << endl; if (n1 == n3) cout << "n1 and n3 are equal" << endl; else cout << "n1 and n3 are not equal" << endl; return 0; }

Expected Output

n1 and n2 are equal
n1 and n3 are not equal

Program Explanation

  • The operator==() function overloads the equality operator.
  • It compares the values of two objects.
  • It returns true if both values are equal.
  • Otherwise, it returns false.

8. Binary Operator Overloading Using Member Functions

When a binary operator is overloaded using a member function, the left-hand operand calls the function and the right-hand operand is passed as an argument.

Example

Number result = n1 + n2;

This is interpreted as:

Number result = n1.operator+(n2);
Expression Part Meaning
n1 Calling object / left operand
operator+ Overloaded operator function
n2 Argument / right operand

9. Member Function vs Non-Member Function

Binary operators can be overloaded using member functions or non-member functions, including friend functions.

Feature Member Function Non-Member Function
Function location Inside the class Outside the class
Operands Left operand calls the function Both operands are explicit arguments
Example signature operator+(const Number&) operator+(const Number&, const Number&)
Private data access Direct access Requires public access or friendship
Note: A non-member operator function can be declared as a friend when it needs direct access to private or protected class members. This is covered in the next lesson.

10. Important Rules

  • Binary operators work with two operands.
  • A member-function overload for a binary operator normally takes one explicit argument.
  • A non-member overload normally takes two explicit arguments.
  • At least one operand must be a user-defined type.
  • Operator precedence and associativity cannot be changed.
  • The number of operands cannot be changed.
  • Operator overloading cannot redefine an operator's behaviour for two built-in types.

11. Advantages of Binary Operator Overloading

  • Makes operations on objects easier to express.
  • Improves program readability.
  • Supports mathematical operations on user-defined types.
  • Helps implement intuitive class interfaces.
  • Supports compile-time polymorphism.

12. Interview Questions

Q1. What is a binary operator?

An operator that performs an operation on two operands.

Q2. Give examples of binary operators.

+, -, *, /, %, ==, < and >.

Q3. How many explicit arguments are required for a member binary operator function?

Normally one explicit argument, representing the right-hand operand.

Q4. How is n1 + n2 interpreted for a member overload?

It is interpreted as n1.operator+(n2).

Q5. Can we overload the equality operator?

Yes. The == operator can be overloaded to compare objects.

Q6. Can binary operators be overloaded using non-member functions?

Yes. A non-member function can take both operands as arguments.

Q7. What is the difference between member and non-member operator overloading?

A member function is called by the left operand and receives the right operand as an argument. A non-member function receives both operands as arguments.

14. Lesson Summary

  • Binary operators perform operations on two operands.
  • Binary operator overloading defines their behaviour for class objects.
  • The operator keyword is used to define an overloaded operator function.
  • A member binary operator function normally takes one explicit argument.
  • Arithmetic and relational operators can be overloaded.
  • Binary operators can also be overloaded using non-member or friend functions.
  • Operator overloading is a form of compile-time polymorphism.
