Lesson Overview

In C++, binary operators can be overloaded using non-member functions. A friend function is a non-member function that is allowed to access the private and protected members of a class.

In this lesson, we will learn how to overload binary operators using friend functions and understand how they differ from member-function-based operator overloading.

1. Learning Objectives

  • Understand the meaning of friend functions.
  • Learn how friend functions access private class members.
  • Understand binary operator overloading using friend functions.
  • Overload the addition operator using a friend function.
  • Understand the difference between member and friend operator functions.
  • Learn when friend functions are useful.

2. What Is a Friend Function?

A friend function is a non-member function that is granted permission to access the private and protected members of a class.

It is declared inside the class using the friend keyword, but it is defined outside the class like an ordinary function.

Basic Syntax

class ClassName { private: int value; public: friend void display(ClassName obj); }; void display(ClassName obj) { // Can access private members of ClassName }
Definition: A friend function is a non-member function that can access the private and protected members of a class because the class has explicitly granted it friendship.

3. Important Characteristics of Friend Functions

  • A friend function is not a member of the class.
  • It is declared inside the class using the friend keyword.
  • It is generally defined outside the class.
  • It can access private and protected class members.
  • It is called like an ordinary function, not through an object using the member-function call syntax.
  • It does not have a this pointer.
  • Friendship is granted explicitly by the class.
Remember: Declaring a function as a friend does not make it a member function. It remains a non-member function.

4. Why Use a Friend Function for Operator Overloading?

A friend function is useful when an overloaded operator needs to access private data from two different objects.

Unlike a member operator function, a non-member operator function receives both operands as explicit arguments.

Member Function Approach

Number operator+(const Number& obj);

The left-hand object calls the function, and the right-hand object is passed as an argument.

Friend Function Approach

friend Number operator+( const Number& obj1, const Number& obj2 );

Both operands are passed explicitly to the function.

Key Difference: A friend operator function is a non-member function. It can access private members of the class because it has been declared as a friend.

5. Overloading Addition (+) Using a Friend Function

Let us create a class named Number and overload the addition operator using a friend function.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } friend Number operator+( const Number& obj1, const Number& obj2 ); void display() { cout << "Value: " << value << endl; } }; Number operator+( const Number& obj1, const Number& obj2 ) { Number temp; temp.value = obj1.value + obj2.value; return temp; } int main() { Number n1(10); Number n2(20); Number n3 = n1 + n2; cout << "First object: "; n1.display(); cout << "Second object: "; n2.display(); cout << "Addition result: "; n3.display(); return 0; }

Expected Output

First object: Value: 10
Second object: Value: 20
Addition result: Value: 30

Program Explanation

  1. The Number class contains a private integer member named value.
  2. The constructor initializes the value of each object.
  3. The friend declaration grants operator+ access to private members.
  4. The operator function is defined outside the class.
  5. Both objects are passed as arguments to the function.
  6. The function adds their private values and stores the result in a temporary object.
  7. The temporary object is returned to the calling expression.
Important: The expression n1 + n2 calls the non-member function operator+(n1, n2). It is not called as n1.operator+(n2).

6. How Friend Function Operator Overloading Works

Consider the expression:

Number n3 = n1 + n2;

For the friend-function overload, the compiler uses the operator function with both operands:

Number n3 = operator+(n1, n2);
Function Argument Meaning
obj1 First operand (left-hand object)
obj2 Second operand (right-hand object)
temp Temporary object containing the result

7. Overloading Subtraction (-) Using a Friend Function

We can also overload the subtraction operator using a friend function.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } friend Number operator-( const Number& a, const Number& b ); void display() { cout << "Result: " << value << endl; } }; Number operator-( const Number& a, const Number& b ) { Number temp; temp.value = a.value - b.value; return temp; } int main() { Number n1(50); Number n2(20); Number n3 = n1 - n2; n3.display(); return 0; }

Expected Output

Result: 30

8. Overloading Multiplication (*) Using a Friend Function

The multiplication operator can be overloaded to multiply the private values of two objects.

C++ Program

#include <iostream> using namespace std; class Number { private: int value; public: Number(int v = 0) { value = v; } friend Number operator*( const Number& a, const Number& b ); void display() { cout << "Result: " << value << endl; } }; Number operator*( const Number& a, const Number& b ) { Number temp; temp.value = a.value * b.value; return temp; } int main() { Number n1(5); Number n2(4); Number n3 = n1 * n2; n3.display(); return 0; }

Expected Output

Result: 20

9. Member Function vs Friend Function

Feature Member Function Friend Function
Function type Member of the class Non-member function
Declaration Declared as a class member Declared using the friend keyword
Explicit arguments for binary operator Normally one Normally two
Private data access Direct access Access granted through friendship
this pointer Available Not available
Function call model Left object calls the function Both operands are passed to the function

10. Advantages of Friend Function

  • Can access private and protected class members.
  • Useful for overloading binary operators.
  • Receives both operands explicitly.
  • Can support operations where the left operand is not a class object, provided the other operand is a suitable class type.
  • Allows related non-member functions to work with class internals.

11. Limitations of Friend Function

  • It is not a member function of the class.
  • It does not have a this pointer.
  • Friendship should be granted carefully because it exposes private implementation details to the friend.
  • Excessive use of friend functions can weaken encapsulation.

12. Important Rules

  • A friend function is declared inside the class using the friend keyword.
  • A friend function is not a member of the class.
  • It can access private and protected members of the class that grants friendship.
  • A non-member binary operator function normally takes two explicit operands.
  • Friend functions are called like ordinary functions.
  • At least one operand of an overloaded operator must be a user-defined type.
  • Operator precedence and associativity cannot be changed.

13. Interview Questions

Q1. What is a friend function?

A friend function is a non-member function that can access private and protected members of a class through friendship.

Q2. Is a friend function a member function?

No. It is a non-member function.

Q3. Why is a friend function used in operator overloading?

It allows an overloaded operator function to access private class members and receive both operands as explicit arguments.

Q4. How many arguments does a friend function take for a binary operator?

Normally two explicit arguments, one for each operand.

Q5. Does a friend function have a this pointer?

No. It is not a member function, so it has no this pointer.

Q6. Can a friend function access private data?

Yes, the class that declares it as a friend grants it that access.

Q7. What is the difference between a member and a friend operator function?

A member operator function is called by the left operand. A friend operator function is a non-member function that receives both operands as arguments.
