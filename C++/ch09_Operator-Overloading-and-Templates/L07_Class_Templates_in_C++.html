1. Introduction to Class Templates

A class template is a blueprint for creating classes that can work with different data types. It allows us to define a class once and use it with types such as int, float, double, char and other compatible types.

Instead of creating separate classes for different data types, we can use a single class template.

Example: A Box class template can store an integer, a floating-point number or a character using the same class definition.

Why Use Class Templates?

  • Improve code reusability.
  • Reduce repeated class definitions.
  • Support multiple data types.
  • Make generic data structures possible.
  • Provide compile-time type checking.

2. Syntax of Class Templates

The general syntax of a class template is:

template <typename T> class ClassName { private: T data; public: void setData(T value) { data = value; } T getData() { return data; } };
Element Meaning
template Declares a template.
typename Declares a type template parameter.
T Placeholder representing a data type.
class Defines the class.
data Data member whose type is T.
Remember: The keyword class can also be used instead of typename in a type template parameter declaration.

3. Simple Class Template Example

The following program creates a Box class template that stores and displays a value.

#include <iostream> using namespace std; template <typename T> class Box { private: T value; public: void setValue(T v) { value = v; } void display() { cout << "Value: " << value << endl; } }; int main() { Box<int> intBox; intBox.setValue(100); intBox.display(); Box<double> doubleBox; doubleBox.setValue(25.75); doubleBox.display(); Box<char> charBox; charBox.setValue('A'); charBox.display(); return 0; }
Expected Output:
Value: 100
Value: 25.75
Value: A

Explanation

  1. Box is declared as a class template.
  2. T represents the type of the data member.
  3. Box<int> creates a specialization for int.
  4. Box<double> creates a specialization for double.
  5. Box<char> creates a specialization for char.

4. Class Template with Constructor

A class template can have constructors just like an ordinary class. The constructor can accept a value of the template parameter type and initialize the data member.

Example

#include <iostream> using namespace std; template <typename T> class Number { private: T value; public: Number(T v) { value = v; } void display() { cout << "Number: " << value << endl; } }; int main() { Number<int> n1(50); Number<double> n2(12.5); n1.display(); n2.display(); return 0; }
Expected Output:
Number: 50
Number: 12.5

5. Class Template with Multiple Parameters

A class template can use more than one template parameter. This is useful when a class needs to store different data types in the same object.

Syntax

template <typename T1, typename T2> class ClassName { // Class members };

Example

#include <iostream> #include <string> using namespace std; template <typename T1, typename T2> class Student { private: T1 rollNumber; T2 name; public: Student(T1 r, T2 n) { rollNumber = r; name = n; } void display() { cout << "Roll Number: " << rollNumber << endl; cout << "Name: " << name << endl; } }; int main() { Student<int, string> s1(101, "Rahul"); s1.display(); return 0; }
Expected Output:
Roll Number: 101
Name: Rahul

Here, T1 represents the roll number type and T2 represents the name type.

6. Class Template with Default Parameters

A class template can specify default types for its template parameters. If the programmer does not provide a type, the default type is used.

Syntax

template <typename T = int> class ClassName { // Class members };

Example

#include <iostream> using namespace std; template <typename T = int> class Sample { private: T value; public: Sample(T v) { value = v; } void display() { cout << "Value: " << value << endl; } }; int main() { Sample<> s1(100); Sample<double> s2(25.75); s1.display(); s2.display(); return 0; }
Expected Output:
Value: 100
Value: 25.75

Sample<> uses the default type int, while Sample<double> explicitly uses double.

Important: The empty angle brackets are used here to request the default template argument. Default template arguments must follow the required template parameter declarations.

7. Defining Class Template Member Functions Outside the Class

Member functions of a class template can be defined outside the class body. The template declaration must be repeated, and the class name must include its template arguments.

Example

#include <iostream> using namespace std; template <typename T> class Calculator { private: T a, b; public: Calculator(T x, T y); T add(); }; template <typename T> Calculator<T>::Calculator(T x, T y) { a = x; b = y; } template <typename T> T Calculator<T>::add() { return a + b; } int main() { Calculator<int> c1(10, 20); cout << "Sum: " << c1.add() << endl; Calculator<double> c2(2.5, 3.5); cout << "Sum: " << c2.add() << endl; return 0; }
Expected Output:
Sum: 30
Sum: 6
Notice the syntax Calculator<T>::add(). The template parameter declaration is repeated before each out-of-class member function definition.

8. Class Template Argument Deduction (C++17)

Class Template Argument Deduction (CTAD) allows the compiler to infer class template arguments from constructor arguments in supported situations.

Example

#include <iostream> using namespace std; template <typename T> class Box { private: T value; public: Box(T v) { value = v; } void display() { cout << "Value: " << value << endl; } }; int main() { Box b1(100); Box b2(25.75); b1.display(); b2.display(); return 0; }
Expected Output:
Value: 100
Value: 25.75
Version Note: Class Template Argument Deduction was introduced in C++17. The earlier examples using Box<int> or Box<double> work without CTAD and are suitable for older C++ standards too.

9. Class Template vs Function Template

Function Template Class Template
Used to create generic functions. Used to create generic classes.
Defines reusable function logic. Defines reusable class structure and behavior.
Template arguments can often be deduced from function arguments. Template arguments are commonly supplied when declaring objects, or deduced using CTAD in C++17.
Example: findMax<int>(). Example: Box<int>.

10. Advantages of Class Templates

  • Reusability: One class definition can support multiple data types.
  • Less Duplication: Avoids creating separate classes for each type.
  • Type Safety: The compiler checks the types used during instantiation.
  • Flexibility: Supports single and multiple template parameters.
  • Generic Data Structures: Helps implement reusable containers and other data structures.

11. Important Rules and Limitations

  • The operations used by class members must be supported by the template types.
  • Each distinct set of template arguments represents a different class template specialization.
  • Template definitions generally need to be visible where the compiler instantiates them.
  • Class template definitions and member function definitions are commonly placed in header files.
  • Default template arguments can reduce the need to specify every template parameter.
Practical Tip: When creating a generic class, think about which operations the class needs from its data type. For example, a class that adds two values requires the supplied type to support the + operator.

12. Important Interview Questions

Q1. What is a class template in C++?

A class template is a blueprint for creating classes that can work with different data types.

Q2. What is the syntax of a class template?

A class template begins with template <typename T> followed by the class definition.

Q3. What is the difference between typename and class in templates?

Both can declare a type template parameter and are equivalent in this context.

Q4. Can a class template have multiple parameters?

Yes. A class template can use multiple parameters, such as T1 and T2.

Q5. Can a class template have a constructor?

Yes. A class template can have constructors, destructors and other member functions.

Q6. What are default template parameters?

They are default types or values assigned to template parameters when arguments are not explicitly provided.

Q7. Can class template member functions be defined outside the class?

Yes. The template declaration and qualified class name must be used in the member function definition.

Q8. What is Class Template Argument Deduction?

CTAD allows the compiler to infer class template arguments from constructor arguments. It was introduced in C++17.

Q9. Where are class template definitions commonly placed?

They are commonly placed in header files so that their definitions are visible during template instantiation.

Q10. Give an example of a class template.

Box<int> is an example of a class template specialization that stores an integer value.

14. Lesson Summary

  • A class template defines a reusable class structure.
  • It can work with different compatible data types.
  • Use template <typename T> to declare a type parameter.
  • Class templates can have multiple template parameters.
  • Constructors and member functions can use template types.
  • Default template arguments can be specified.
  • Member functions can be defined outside the class.
  • CTAD was introduced in C++17.
