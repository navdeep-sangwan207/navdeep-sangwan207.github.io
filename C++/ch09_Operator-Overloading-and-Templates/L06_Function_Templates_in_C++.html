1. Introduction to Function Templates

A function template is a general form of a function that can work with different data types. Instead of writing separate functions for int, float, double and other types, we can define one function template.

The compiler generates the appropriate function when the template is used with a particular type.

Example: A single function template can find the maximum of two integers, two floating-point numbers or two values of another compatible type.

Why Use Function Templates?

  • Reduce code duplication.
  • Improve code reusability.
  • Support multiple data types.
  • Make programs easier to maintain.
  • Provide compile-time type checking.

2. Syntax of Function Templates

A basic function template follows this syntax:

template <typename T> return_type function_name(T parameter) { // Function body }

Another valid form uses the keyword class:

template <class T> return_type function_name(T parameter) { // Function body }
Keyword / Term Meaning
template Declares a template.
typename Declares a type template parameter.
class Can also declare a type template parameter.
T A placeholder name representing a type.
function_name Name of the function being defined.
Remember: In a template parameter declaration, typename and class are equivalent. The name T is not a special keyword; it is a conventional name for a type parameter.

3. Function Template Example

The following example uses one function template to display values of different data types.

#include <iostream> using namespace std; template <typename T> void display(T value) { cout << "Value: " << value << endl; } int main() { display(10); display(25.75); display('A'); return 0; }
Expected Output:
Value: 10
Value: 25.75
Value: A

Explanation

  1. The template parameter T represents a data type.
  2. The function display() accepts a parameter of type T.
  3. When display(10) is called, T is deduced as int.
  4. When display(25.75) is called, T is deduced as double.
  5. When display('A') is called, T is deduced as char.

4. Function Template for Finding Maximum

A function template can be used to compare two values. The comparison operator must be supported by the type supplied to the template.

#include <iostream> using namespace std; template <typename T> T findMax(T a, T b) { if (a > b) return a; else return b; } int main() { cout << "Maximum Integer: " << findMax(10, 20) << endl; cout << "Maximum Double: " << findMax(12.5, 8.5) << endl; return 0; }
Expected Output:
Maximum Integer: 20
Maximum Double: 12.5
The same function template is reused for both int and double. The compiler creates the required specializations when the function is used.

5. Multiple Template Parameters

A function template can have more than one type parameter. This is useful when a function needs to accept arguments of different data types.

Syntax

template <typename T1, typename T2> return_type function_name(T1 a, T2 b) { // Function body }

Example

#include <iostream> using namespace std; template <typename T1, typename T2> void displayValues(T1 a, T2 b) { cout << "First value: " << a << endl; cout << "Second value: " << b << endl; } int main() { displayValues(10, 25.75); displayValues('A', 100); return 0; }
Expected Output:
First value: 10
Second value: 25.75
First value: A
Second value: 100

Here, T1 and T2 represent two independent type parameters. The first argument determines T1 and the second argument determines T2.

6. Template Argument Deduction

Template argument deduction allows the compiler to determine the template parameter types from the function arguments. In many cases, we do not need to specify the types explicitly.

Example 1: Automatic Deduction

#include <iostream> using namespace std; template <typename T> void show(T value) { cout << value << endl; } int main() { show(100); show(12.5); return 0; }
Expected Output:
100
12.5

Example 2: Explicit Template Arguments

#include <iostream> using namespace std; template <typename T> T square(T value) { return value * value; } int main() { cout << square<int>(5) << endl; cout << square<double>(2.5) << endl; return 0; }
Expected Output:
25
6.25

In this example, the template arguments int and double are explicitly supplied by the programmer.

7. Function Template Overloading

Function templates can be overloaded. This means multiple function templates or ordinary functions can have the same name but different parameter lists.

Example

#include <iostream> using namespace std; template <typename T> void display(T value) { cout << "Single value: " << value << endl; } template <typename T> void display(T a, T b) { cout << "Two values: " << a << " and " << b << endl; } int main() { display(10); display(20, 30); return 0; }
Expected Output:
Single value: 10
Two values: 20 and 30

The compiler selects the appropriate overload according to the function arguments.

8. Function Template Specialization

Function template specialization allows a programmer to provide a specific implementation for a particular type. The specialized function is used when that type is supplied.

Example: Specialization for char

#include <iostream> using namespace std; template <typename T> void display(T value) { cout << "General value: " << value << endl; } template <> void display<char>(char value) { cout << "Character value: " << value << endl; } int main() { display(100); display('A'); return 0; }
Expected Output:
General value: 100
Character value: A
Important: This is explicit full specialization of a function template. Function templates do not support partial specialization. Overloading is commonly used when different behavior is required for a subset of argument types.

9. Function Template vs Normal Function

Normal Function Function Template
Usually written for specific parameter types. Written using one or more type parameters.
May require separate functions for different types. Can support multiple compatible types.
Can involve repeated code. Reduces code duplication.
Uses concrete types in its definition. Uses template parameters such as T.

10. Advantages of Function Templates

  • Code Reusability: One template can work with many types.
  • Less Duplication: Avoids writing similar functions repeatedly.
  • Type Safety: The compiler checks types when templates are instantiated.
  • Maintainability: Common logic can be maintained in one place.
  • Generic Programming: Helps write reusable algorithms and libraries.

11. Limitations and Important Rules

  • The operations used inside a template must be supported by the types supplied to it.
  • Template argument deduction depends on the function parameters and the supplied arguments.
  • A function template is not a runtime mechanism for selecting arbitrary data types.
  • Template definitions generally need to be visible where they are instantiated. This is why template definitions are commonly placed in header files.
  • Templates are instantiated by the compiler as needed.
Practical Tip: When separating a template declaration and definition into different files, ensure the compiler can see the definition when it needs to instantiate the template. A common approach is to place both in a header file.

12. Important Interview Questions

Q1. What is a function template in C++?

A function template is a general function definition that can work with different data types using template parameters.

Q2. What is the syntax of a function template?

It begins with template <typename T>, followed by the function definition.

Q3. What is the difference between typename and class?

Both can declare a type template parameter. They are equivalent in this context.

Q4. What is template argument deduction?

It is the process by which the compiler determines template parameter types from function arguments.

Q5. Can a function template have multiple parameters?

Yes. A template can use multiple type parameters, such as T1 and T2.

Q6. Can function templates be overloaded?

Yes. Function templates can be overloaded using different parameter lists.

Q7. What is function template specialization?

It provides a specific implementation of a function template for a particular type.

Q8. Can function templates be partially specialized?

No. Function templates cannot be partially specialized. Function overloading can be used for alternative behavior.

Q9. Where are function template definitions commonly placed?

They are commonly placed in header files so that their definitions are visible when instantiation is required.

Q10. What is the main advantage of function templates?

They allow reusable functions for multiple compatible data types while reducing code duplication.

14. Lesson Summary

  • A function template provides a reusable function definition.
  • It can work with multiple compatible data types.
  • Use template <typename T> or template <class T>.
  • The compiler can deduce template arguments automatically.
  • Multiple template parameters can be used.
  • Function templates can be overloaded.
  • Explicit specialization provides a specific implementation for a type.
  • Template definitions generally need to be visible at instantiation.
