1. Introduction

Inheritance is one of the most important features of Object-Oriented Programming (OOP) in C++.

It allows a new class to acquire the properties (data members) and behaviours (member functions) of an existing class.

The existing class is called the Base Class, and the new class is called the Derived Class.

Example: Consider an Animal class containing common functions such as eating. A Dog class can inherit these functions and define its own behaviour, such as barking.

2. What is Inheritance?

Definition: Inheritance is an OOP mechanism in which a derived class acquires accessible data members and member functions from a base class.

It supports code reusability and helps organize related classes into a hierarchy.

Important Terminology

Term Description
Base Class The class whose members are inherited by another class.
Derived Class The class that inherits members from another class.
Parent Class Another name for the Base Class.
Child Class Another name for the Derived Class.
Inheritance The process of acquiring members from another class.

3. Syntax of Inheritance

class BaseClass { // Data members // Member functions }; class DerivedClass : access_specifier BaseClass { // Additional data members // Additional member functions };

Explanation

  • BaseClass: The existing class.
  • DerivedClass: The new class.
  • Colon (:): Specifies inheritance.
  • Access specifier: Determines the accessibility of inherited members.
  • The derived class can define its own members.

Example

#include <iostream> using namespace std; class Animal { public: void eat() { cout << "Animal is eating" << endl; } }; class Dog : public Animal { public: void bark() { cout << "Dog is barking" << endl; } };

Here, Dog inherits the eat() function from Animal and defines its own bark() function.

4. Base Class and Derived Class

Base Class

A base class is a class whose members are inherited by another class.

class Vehicle { public: void start() { cout << "Vehicle started" << endl; } };

Derived Class

A derived class is a class that inherits members from a base class.

class Car : public Vehicle { public: void drive() { cout << "Car is moving" << endl; } };
The Car class can use the public start() function inherited from Vehicle.

5. Complete C++ Program: Basic Inheritance

Objective

To understand how a derived class inherits and uses the public members of a base class.

Program

#include <iostream> using namespace std; // Base Class class Animal { public: void eat() { cout << "Animal is eating" << endl; } }; // Derived Class class Dog : public Animal { public: void bark() { cout << "Dog is barking" << endl; } }; int main() { Dog d; d.eat(); d.bark(); return 0; }

Expected Output

Output: 
Animal is eating
Dog is barking

Program Explanation

  1. Animal is the base class.
  2. Dog is the derived class.
  3. Dog : public Animal specifies public inheritance.
  4. The eat() function belongs to the Animal class.
  5. The bark() function belongs to the Dog class.
  6. An object d of the Dog class is created.
  7. The object calls both eat() and bark().
Important: A derived class can directly access inherited public and protected members, subject to inheritance access rules. It cannot directly access private members of the base class.

6. Why Do We Need Inheritance?

Inheritance is useful when multiple classes share common properties and behaviours.

Consider an application containing:

  • Vehicle
  • Car
  • Bike
  • Bus

These classes may share common functionality such as starting, stopping, and displaying speed.

Without Inheritance

class Car { public: void start() { cout << "Vehicle started" << endl; } }; class Bike { public: void start() { cout << "Vehicle started" << endl; } };

The same function is repeated in multiple classes.

With Inheritance

class Vehicle { public: void start() { cout << "Vehicle started" << endl; } }; class Car : public Vehicle { }; class Bike : public Vehicle { };

Now both Car and Bike can use the inherited start() function.

7. Advantages of Inheritance

  1. Code Reusability: Existing class members can be reused in derived classes.
  2. Reduced Code Duplication: Common functionality can be written once.
  3. Easy Maintenance: Shared functionality can be maintained in the base class.
  4. Extensibility: Derived classes can add their own data members and functions.
  5. Class Hierarchy: Related classes can be organized into a structured hierarchy.
  6. Supports Polymorphism: Inheritance provides the foundation for runtime polymorphism when used with virtual functions.

8. Types of Inheritance in C++

C++ supports five commonly discussed types of inheritance.

Type Description
Single Inheritance One derived class inherits from one base class.
Multilevel Inheritance A class inherits from another derived class.
Multiple Inheritance One derived class inherits from multiple base classes.
Hierarchical Inheritance Multiple derived classes inherit from one base class.
Hybrid Inheritance A combination of two or more inheritance types.
These types will be studied in detail in the upcoming lessons.

9. Important Points to Remember

  • Inheritance is a feature of Object-Oriented Programming.
  • The existing class is called the base class.
  • The new class is called the derived class.
  • A colon (:) is used to specify inheritance.
  • A derived class can have its own data members and functions.
  • Private members of a base class are not directly accessible in the derived class.
  • Public inheritance preserves public access and keeps inherited protected members protected.
  • Inheritance promotes code reusability.
  • C++ supports five commonly discussed types of inheritance.

10. Common Interview Questions

Q1. What is inheritance in C++?

Inheritance is an OOP mechanism through which a derived class acquires accessible members of a base class.

Q2. What is a base class?

A base class is the existing class from which another class inherits members.

Q3. What is a derived class?

A derived class is a new class that inherits members from a base class.

Q4. Which symbol is used for inheritance in C++?

The colon (:) symbol is used.

Q5. What is the main advantage of inheritance?

Code reusability is one of the main advantages of inheritance.

Q6. Can a derived class access private members of a base class directly?

No. Private members cannot be accessed directly by the derived class.

Q7. How many commonly discussed types of inheritance are supported in C++?

Five: Single, Multilevel, Multiple, Hierarchical, and Hybrid.

Q8. Can a derived class have its own member functions?

Yes. A derived class can define additional data members and member functions.
