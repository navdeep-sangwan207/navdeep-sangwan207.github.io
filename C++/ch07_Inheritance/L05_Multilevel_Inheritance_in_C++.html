1. Introduction to Multilevel Inheritance

Multilevel inheritance is a type of inheritance in C++ in which a class is derived from another derived class.

In this inheritance structure, one class acts as the base class for another class, and that derived class becomes the base class for a further class.

Definition: Multilevel inheritance is an inheritance mechanism in which a class inherits from a derived class, creating a chain of inheritance.

For example, class B inherits from class A, and class C inherits from class B. Therefore, class C can access the accessible inherited members of both class A and class B.

2. Structure of Multilevel Inheritance

Consider the following inheritance relationship:

Class A (Base Class)
↓
Class B (Derived Class)
↓
Class C (Derived Class)
  • Class A is the base class of class B.
  • Class B is derived from class A.
  • Class B becomes the base class of class C.
  • Class C is indirectly derived from class A through class B.

3. Syntax of Multilevel Inheritance

The general syntax is:

class A { // Base class members }; class B : public A { // Derived class B members }; class C : public B { // Derived class C members };

Here, class B inherits from class A, while class C inherits from class B.

Note: The inheritance access mode can be public, protected, or private. The example above uses public inheritance.

4. Basic Example of Multilevel Inheritance

In this example, class B inherits from class A, and class C inherits from class B.

#include <iostream> using namespace std; class A { public: void displayA() { cout << "Class A function" << endl; } }; class B : public A { public: void displayB() { cout << "Class B function" << endl; } }; class C : public B { public: void displayC() { cout << "Class C function" << endl; } }; int main() { C obj; obj.displayA(); obj.displayB(); obj.displayC(); return 0; }

Expected Output

Class A function
Class B function
Class C function

Explanation:

  • Class B inherits the public member function of class A.
  • Class C inherits the accessible members of class B.
  • Object obj of class C can call all three functions.

5. Multilevel Inheritance Using Data Members

Multilevel inheritance can also be used to inherit data members and member functions through multiple levels.

#include <iostream> using namespace std; class Student { public: int rollNo = 101; }; class Test : public Student { public: int marks = 85; }; class Result : public Test { public: void display() { cout << "Roll Number: " << rollNo << endl; cout << "Marks: " << marks << endl; cout << "Result: Pass" << endl; } }; int main() { Result obj; obj.display(); return 0; }

Expected Output

Roll Number: 101
Marks: 85
Result: Pass

Explanation: The Result class inherits from Test, and Test inherits from Student. Therefore, the Result class can access the inherited public data members.

6. Multilevel Inheritance with Constructors

When an object of the last derived class is created, constructors are executed from the topmost base class to the final derived class.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } }; class B : public A { public: B() { cout << "Constructor of B" << endl; } }; class C : public B { public: C() { cout << "Constructor of C" << endl; } }; int main() { C obj; return 0; }

Expected Output

Constructor of A
Constructor of B
Constructor of C
Constructor order: Base class A → Derived class B → Derived class C.

7. Multilevel Inheritance with Destructors

Destructors are executed in the reverse order of constructor execution when the object is destroyed.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } ~A() { cout << "Destructor of A" << endl; } }; class B : public A { public: B() { cout << "Constructor of B" << endl; } ~B() { cout << "Destructor of B" << endl; } }; class C : public B { public: C() { cout << "Constructor of C" << endl; } ~C() { cout << "Destructor of C" << endl; } }; int main() { C obj; return 0; }

Expected Output

Constructor of A
Constructor of B
Constructor of C
Destructor of C
Destructor of B
Destructor of A
Remember: Constructors execute from base to derived, while destructors execute from derived to base.

8. Access of Members in Multilevel Inheritance

The accessibility of inherited members depends on the inheritance mode and the access specifier used in the base classes.

Member in Base Class Public Inheritance Protected Inheritance Private Inheritance
Public Public Protected Private
Protected Protected Protected Private
Private Not directly accessible Not directly accessible Not directly accessible
Important: Private members of a base class are not directly accessible in derived classes. They may be accessed through accessible public or protected member functions provided by the base class.

9. Advantages of Multilevel Inheritance

  • Promotes code reusability across multiple levels.
  • Reduces code duplication.
  • Allows classes to extend existing functionality step by step.
  • Helps organize related classes in a hierarchy.
  • Supports gradual specialization of classes.

10. Applications of Multilevel Inheritance

  • Educational management systems.
  • Employee and organization management systems.
  • Vehicle classification systems.
  • Product and category hierarchies.
  • Software systems with multiple levels of specialization.

Example: Vehicle Hierarchy

Vehicle
↓
Car
↓
ElectricCar

An ElectricCar can inherit common vehicle features through the Car class, while also defining its own electric-vehicle features.

11. Important Points to Remember

  • Multilevel inheritance forms a chain of inheritance.
  • A derived class can become a base class for another class.
  • The final derived class can access inherited accessible members from earlier levels.
  • Private base-class members are not directly accessible in derived classes.
  • Constructors execute from the topmost base class to the final derived class.
  • Destructors execute in the reverse order.
  • Inheritance access modes affect member accessibility at each level.

12. Interview Questions

Q1. What is multilevel inheritance?

Multilevel inheritance is a type of inheritance in which a class is derived from another derived class.

Q2. How many classes are involved in multilevel inheritance?

Two or more classes can be involved. A common example uses three classes: A, B, and C.

Q3. What is the constructor execution order?

Constructors execute from the topmost base class to the final derived class.

Q4. What is the destructor execution order?

Destructors execute in reverse order, from the final derived class back to the base class.

Q5. Can a final derived class access private members of the first base class directly?

No. Private members of a base class are not directly accessible in derived classes.

Q6. Give an example of multilevel inheritance.

Class A → Class B → Class C, where B inherits from A and C inherits from B.

13. Practice Exercise

Create a C++ program using multilevel inheritance with three classes:

  1. Create a class Person with a name data member.
  2. Create a class Employee that inherits from Person and adds an employee ID.
  3. Create a class Manager that inherits from Employee and adds a department name.
  4. Display all three data members using an object of class Manager.
Expected learning outcome: Understand how data members and member functions can be inherited through multiple levels of a class hierarchy.

14. Lesson Summary

Multilevel inheritance allows a class to inherit from another derived class. It creates a sequence of inheritance relationships and supports code reusability across multiple levels.

In a multilevel hierarchy, constructors execute from base to derived, while destructors execute from derived to base. Understanding access specifiers and inheritance modes is important when designing such class hierarchies.
