Public, Private and Protected Inheritance in C++

Chapter 7: Inheritance

1. Introduction

In C++, inheritance allows a derived class to acquire accessible members from a base class.

The inheritance access specifier determines how the public and protected members of the base class are treated in the derived class.

C++ provides three inheritance modes:

  • Public Inheritance
  • Protected Inheritance
  • Private Inheritance
Important: The inheritance access specifier does not change the original access level of the base-class members. It controls their accessibility through the derived-class interface.

2. Syntax of Inheritance

class Base { // Base class members }; class Derived : access_specifier Base { // Derived class members };

Explanation

  • Base: The existing class.
  • Derived: The class that inherits from Base.
  • access_specifier: public, protected or private.
  • The colon (:) specifies the inheritance relationship.
If no inheritance access specifier is written for a class, C++ uses private inheritance by default for a class. For a struct, the default is public inheritance.

3. Public Inheritance

In public inheritance, public members of the base class remain public in the derived class, while protected members remain protected.

Private members of the base class are not directly accessible in the derived class.

Syntax

class Derived : public Base { // Derived class members };

Example Program

#include <iostream> using namespace std; class Animal { public: void eat() { cout << "Animal is eating" << endl; } protected: void sleep() { cout << "Animal is sleeping" << endl; } }; class Dog : public Animal { public: void display() { eat(); sleep(); } }; int main() { Dog d; d.eat(); d.display(); return 0; }

Expected Output

Animal is eating
Animal is eating
Animal is sleeping

Explanation

  1. Animal is the base class.
  2. Dog publicly inherits Animal.
  3. eat() is a public member of Animal.
  4. sleep() is a protected member of Animal.
  5. Dog can access both eat() and sleep() inside its member function.
  6. The main() function can directly call the public eat() function.
Public inheritance is commonly used to represent an "is-a" relationship. For example, a Dog is an Animal.

4. Protected Inheritance

In protected inheritance, both public and protected members of the base class become protected members in the derived class.

Private members of the base class remain inaccessible directly in the derived class.

Syntax

class Derived : protected Base { // Derived class members };

Example Program

#include <iostream> using namespace std; class Base { public: void showPublic() { cout << "Public member of Base" << endl; } protected: void showProtected() { cout << "Protected member of Base" << endl; } }; class Derived : protected Base { public: void display() { showPublic(); showProtected(); } }; int main() { Derived d; d.display(); return 0; }

Expected Output

Public member of Base
Protected member of Base

Explanation

  1. Base contains public and protected member functions.
  2. Derived inherits Base using protected inheritance.
  3. The inherited public member becomes protected in Derived.
  4. The inherited protected member remains protected.
  5. Derived can call both functions inside display().
  6. The main() function calls the public display() function.
The inherited showPublic() function cannot be called directly using an object of Derived because it becomes protected in the derived class.

5. Private Inheritance

In private inheritance, both public and protected members of the base class become private members in the derived class.

Private members of the base class remain inaccessible directly in the derived class.

Syntax

class Derived : private Base { // Derived class members };

Example Program

#include <iostream> using namespace std; class Base { public: void showPublic() { cout << "Public member of Base" << endl; } protected: void showProtected() { cout << "Protected member of Base" << endl; } }; class Derived : private Base { public: void display() { showPublic(); showProtected(); } }; int main() { Derived d; d.display(); return 0; }

Expected Output

Public member of Base
Protected member of Base

Explanation

  1. Base contains public and protected member functions.
  2. Derived privately inherits Base.
  3. The inherited public member becomes private in Derived.
  4. The inherited protected member also becomes private.
  5. Derived can call both functions inside display().
  6. The main() function accesses display() because it is public.
The inherited showPublic() and showProtected() functions cannot be called directly using an object of Derived.

6. Comparison of Inheritance Modes

The following table shows how public and protected base-class members are treated under each inheritance mode.

Base Class Member Public Inheritance Protected Inheritance Private Inheritance
Public Public Protected Private
Protected Protected Protected Private
Private Not directly accessible Not directly accessible Not directly accessible
Remember: Private members remain part of the base-class subobject, but derived-class member functions cannot access them directly. They may be accessed through public or protected base-class member functions.

7. Difference Between Public, Protected and Private Inheritance

Feature Public Protected Private
Base public members Remain public Become protected Become private
Base protected members Remain protected Remain protected Become private
Base private members Not directly accessible Not directly accessible Not directly accessible
Typical use Public "is-a" relationship Restricted inheritance interface Implementation reuse

8. Important Concept: Access in Further Derived Classes

The inheritance mode also affects the accessibility of inherited members in classes derived further down the hierarchy.

Example: Public Inheritance

class A { public: int x; }; class B : public A { }; class C : public B { public: void display() { x = 100; cout << x << endl; } };

Here, x remains public in B and C, so it can be accessed inside their member functions and through an appropriate public interface.

Example: Private Inheritance

class A { public: int x; }; class B : private A { }; class C : public B { public: void display() { // x = 100; // Error: inaccessible here } };

Here, x becomes private in B. Therefore, C cannot directly access it.

9. Advantages of Inheritance Access Specifiers

  1. Controlled Accessibility: They control how inherited members are exposed.
  2. Encapsulation: They help restrict access to implementation details.
  3. Code Reusability: Derived classes can reuse base-class functionality.
  4. Flexible Class Design: Different inheritance modes support different class relationships.
  5. Interface Control: They determine which inherited members remain publicly accessible.

10. Important Points to Remember

  • C++ supports public, protected and private inheritance.
  • Public inheritance preserves public and protected access levels.
  • Protected inheritance converts inherited public members into protected members.
  • Private inheritance converts inherited public and protected members into private members.
  • Private base-class members are never directly accessible in the derived class.
  • Inheritance mode affects further derived classes.
  • Public inheritance commonly models an "is-a" relationship.
  • Class inheritance defaults to private; struct inheritance defaults to public.

11. Common Interview Questions

Q1. What are the three types of inheritance access specifiers in C++?

Public, protected and private inheritance.

Q2. What happens in public inheritance?

Public base members remain public, and protected base members remain protected in the derived class.

Q3. What happens in protected inheritance?

Public and protected base members become protected in the derived class.

Q4. What happens in private inheritance?

Public and protected base members become private in the derived class.

Q5. Can derived classes directly access private members of a base class?

No. Private base-class members cannot be accessed directly by derived-class member functions.

Q6. What is the default inheritance mode for a class?

Private inheritance.

Q7. What is the default inheritance mode for a struct?

Public inheritance.

Q8. Which inheritance mode is commonly used to represent an "is-a" relationship?

Public inheritance.
