1. Introduction to Multiple Inheritance

Multiple inheritance is a type of inheritance in C++ in which a single derived class inherits from two or more base classes.

It allows a derived class to combine the accessible data members and member functions of multiple base classes.

Definition: Multiple inheritance is an inheritance mechanism in which one derived class inherits from more than one base class.

For example, a class can inherit features from both an Academic class and a Sports class.

2. Structure of Multiple Inheritance

Consider a derived class C that inherits from both class A and class B.

Class A
Class B
↘     ↙
Class C (Derived Class)
  • Class A is the first base class.
  • Class B is the second base class.
  • Class C inherits from both A and B.
  • An object of class C can access their accessible inherited members.

3. Syntax of Multiple Inheritance

The general syntax is:

class A { // Members of class A }; class B { // Members of class B }; class C : public A, public B { // Members of class C };

Here, class C inherits publicly from both class A and class B.

Note: Each base class can have its own inheritance access mode. For example, a class can inherit publicly from one base class and privately from another.

4. Basic Example of Multiple Inheritance

In this example, class C inherits member functions from both class A and class B.

#include <iostream> using namespace std; class A { public: void displayA() { cout << "Class A function" << endl; } }; class B { public: void displayB() { cout << "Class B function" << endl; } }; class C : public A, public B { public: void displayC() { cout << "Class C function" << endl; } }; int main() { C obj; obj.displayA(); obj.displayB(); obj.displayC(); return 0; }

Expected Output

Class A function
Class B function
Class C function

Explanation:

  • Class C inherits publicly from class A and class B.
  • Object obj belongs to class C.
  • It can call the accessible functions of both base classes.
  • It can also call its own member function.

5. Multiple Inheritance Using Data Members

A derived class can inherit data members from multiple base classes and use them in its own member functions.

#include <iostream> using namespace std; class Academic { public: int marks = 85; }; class Sports { public: int score = 90; }; class Result : public Academic, public Sports { public: void display() { cout << "Academic Marks: " << marks << endl; cout << "Sports Score: " << score << endl; cout << "Total: " << marks + score << endl; } }; int main() { Result obj; obj.display(); return 0; }

Expected Output

Academic Marks: 85
Sports Score: 90
Total: 175

Explanation: The Result class inherits from both Academic and Sports. It can use the accessible members of both classes.

6. Constructor Execution in Multiple Inheritance

When an object of a derived class is created, constructors of its direct base classes execute first, in the order in which the base classes are declared in the inheritance list.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } }; class B { public: B() { cout << "Constructor of B" << endl; } }; class C : public A, public B { public: C() { cout << "Constructor of C" << endl; } }; int main() { C obj; return 0; }

Expected Output

Constructor of A
Constructor of B
Constructor of C
Important: The order of base-class construction is determined by the order of base classes in the class inheritance declaration, not by the order in which they appear in the constructor initializer list.

7. Destructor Execution in Multiple Inheritance

Destructors execute in the reverse order of construction. Therefore, the derived-class destructor runs first, followed by the base-class destructors in reverse declaration order.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } ~A() { cout << "Destructor of A" << endl; } }; class B { public: B() { cout << "Constructor of B" << endl; } ~B() { cout << "Destructor of B" << endl; } }; class C : public A, public B { public: C() { cout << "Constructor of C" << endl; } ~C() { cout << "Destructor of C" << endl; } }; int main() { C obj; return 0; }

Expected Output

Constructor of A
Constructor of B
Constructor of C
Destructor of C
Destructor of B
Destructor of A

8. Ambiguity in Multiple Inheritance

Ambiguity occurs when two or more base classes contain members with the same name. The compiler cannot determine which member should be used when it is accessed without qualification.

Example of Ambiguity

#include <iostream> using namespace std; class A { public: void display() { cout << "Display from A" << endl; } }; class B { public: void display() { cout << "Display from B" << endl; } }; class C : public A, public B { }; int main() { C obj; // obj.display(); // Ambiguous obj.A::display(); obj.B::display(); return 0; }

Expected Output

Display from A
Display from B

Both base classes contain a function named display(). Therefore, calling obj.display() directly is ambiguous.

Solution: Use the scope resolution operator (::) to specify the base class whose function should be called.

9. Advantages of Multiple Inheritance

  • Combines functionality from multiple base classes.
  • Promotes code reusability.
  • Reduces duplication of common functionality.
  • Allows a class to represent multiple capabilities.
  • Supports flexible class design.

10. Disadvantages of Multiple Inheritance

  • Can create ambiguity when base classes contain members with identical names.
  • Can make class relationships more complex.
  • Can introduce the diamond problem when a class inherits from two classes that share a common base.
  • Requires careful design and access control.
Remember: Multiple inheritance is useful, but complicated inheritance hierarchies can make code harder to understand and maintain.

11. Applications of Multiple Inheritance

  • Combining different capabilities in a software class.
  • Student systems combining academic and sports information.
  • Software components that implement multiple interfaces or roles.
  • Modeling objects that have more than one independent capability.

12. Difference Between Single, Multilevel and Multiple Inheritance

Inheritance Type Description Structure
Single One derived class inherits from one base class. A → B
Multilevel A class inherits from another derived class. A → B → C
Multiple One derived class inherits from multiple base classes. A + B → C

13. Important Points to Remember

  • Multiple inheritance involves two or more base classes.
  • A derived class can inherit from multiple classes using a comma-separated inheritance list.
  • Each base class can have its own inheritance access mode.
  • Base-class constructors execute in declaration order.
  • Destructors execute in reverse construction order.
  • Name conflicts can cause ambiguity.
  • The scope resolution operator can resolve many member-name ambiguities.
  • Private members of base classes are not directly accessible in the derived class.

14. Interview Questions

Q1. What is multiple inheritance?

Multiple inheritance is a type of inheritance in which one derived class inherits from two or more base classes.

Q2. What is the syntax of multiple inheritance?

class C : public A, public B

Q3. What is ambiguity in multiple inheritance?

Ambiguity occurs when multiple base classes contain members with the same name and the compiler cannot determine which member is intended.

Q4. How can ambiguity be resolved?

The scope resolution operator can specify the base class, for example obj.A::display().

Q5. In what order are base-class constructors called?

They execute in the order in which the base classes are declared in the inheritance list.

Q6. What is the order of destructor execution?

Destructors execute in reverse order of construction.

Q7. What is the diamond problem?

It is an ambiguity that can occur when a derived class inherits from two classes that both inherit from the same common base class.

15. Practice Exercise

  1. Create a class PersonalInfo with a name and age.
  2. Create a class AcademicInfo with marks.
  3. Create a class Student that inherits from both classes.
  4. Display the student's name, age, and marks using an object of class Student.
Expected learning outcome: Understand how one derived class can combine accessible members from multiple independent base classes.

16. Lesson Summary

Multiple inheritance allows a derived class to inherit from more than one base class. It helps combine functionality from different classes and promotes code reusability.

Constructors execute in the order of base-class declaration, while destructors execute in reverse order. Ambiguity can occur when base classes contain members with identical names and can often be resolved using the scope resolution operator.
