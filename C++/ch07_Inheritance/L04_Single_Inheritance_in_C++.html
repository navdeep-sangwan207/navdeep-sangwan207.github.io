1. Introduction

Single inheritance is the simplest type of inheritance in C++. In this type, one derived class inherits from only one base class.

The derived class can use the accessible members of the base class and can also define its own additional data members and member functions.

Definition: Single inheritance is a type of inheritance in which one derived class inherits from one base class.

2. Structure of Single Inheritance

Single inheritance involves two main classes:

  • Base Class: The existing class.
  • Derived Class: The class that inherits from the base class.
Base Class
↓
Derived Class

One base class → One derived class

For example, a Student class can inherit common information from a Person class.

3. Syntax of Single Inheritance

class Base { // Base class members }; class Derived : public Base { // Derived class members };

Explanation

  • Base: The parent class.
  • Derived: The child class.
  • : The inheritance operator.
  • public: The inheritance access mode.
The access mode can be public, protected or private. Public inheritance is commonly used to represent an "is-a" relationship.

4. Basic Example of Single Inheritance

Program

#include <iostream> using namespace std; // Base Class class Animal { public: void eat() { cout << "Animal is eating" << endl; } }; // Derived Class class Dog : public Animal { public: void bark() { cout << "Dog is barking" << endl; } }; int main() { Dog d; d.eat(); d.bark(); return 0; }

Expected Output

Animal is eating
Dog is barking

Program Explanation

  1. Animal is the base class.
  2. Dog is the derived class.
  3. Dog publicly inherits from Animal.
  4. The eat() function belongs to Animal.
  5. The bark() function belongs to Dog.
  6. The Dog object can call both functions.

5. Single Inheritance Using Data Members

A derived class can use accessible data members inherited from its base class.

Program

#include <iostream> #include <string> using namespace std; // Base Class class Person { public: string name; void setName(string n) { name = n; } }; // Derived Class class Student : public Person { public: int rollNo; void display() { cout << "Name: " << name << endl; cout << "Roll Number: " << rollNo << endl; } }; int main() { Student s; s.setName("Rahul"); s.rollNo = 101; s.display(); return 0; }

Expected Output

Name: Rahul
Roll Number: 101

Explanation

  1. Person is the base class.
  2. Student inherits Person using public inheritance.
  3. name and setName() are inherited public members.
  4. Student defines its own rollNo data member.
  5. The display() function accesses both inherited and its own members.

6. Single Inheritance with Protected Members

A derived class can directly access protected members inherited from its base class.

Program

#include <iostream> using namespace std; // Base Class class Employee { protected: int salary; }; // Derived Class class Manager : public Employee { public: void setSalary(int s) { salary = s; } void displaySalary() { cout << "Salary: " << salary << endl; } }; int main() { Manager m; m.setSalary(50000); m.displaySalary(); return 0; }

Expected Output

Salary: 50000
The salary member is protected. It can be accessed inside Manager, but it cannot be accessed directly through the Manager object in main().

7. Constructor Execution in Single Inheritance

When an object of a derived class is created, the base-class constructor executes before the derived-class constructor.

Program

#include <iostream> using namespace std; class Base { public: Base() { cout << "Base class constructor" << endl; } }; class Derived : public Base { public: Derived() { cout << "Derived class constructor" << endl; } }; int main() { Derived obj; return 0; }

Expected Output

Base class constructor
Derived class constructor

Explanation

  1. An object of Derived is created.
  2. The Base constructor executes first.
  3. After Base construction completes, the Derived constructor executes.
Remember: Base-class construction takes place before derived-class construction.

8. Destructor Execution in Single Inheritance

Destructors execute in the reverse order of construction. Therefore, the derived-class destructor executes before the base-class destructor.

Program

#include <iostream> using namespace std; class Base { public: Base() { cout << "Base class constructor" << endl; } ~Base() { cout << "Base class destructor" << endl; } }; class Derived : public Base { public: Derived() { cout << "Derived class constructor" << endl; } ~Derived() { cout << "Derived class destructor" << endl; } }; int main() { Derived obj; return 0; }

Expected Output

Base class constructor
Derived class constructor
Derived class destructor
Base class destructor
The derived object is destroyed first, followed by its base-class subobject.

9. Advantages of Single Inheritance

  1. Code Reusability: The derived class can reuse existing base-class functionality.
  2. Reduced Duplication: Common members do not need to be rewritten.
  3. Simple Structure: It provides a straightforward class relationship.
  4. Easy Maintenance: Shared functionality can be maintained in the base class.
  5. Extensibility: The derived class can add its own features.

10. Applications of Single Inheritance

  • A Student class inheriting common details from Person.
  • A Car class inheriting common vehicle features from Vehicle.
  • A Manager class inheriting employee details from Employee.
  • A SavingsAccount class inheriting account functionality from Account.
  • A Dog class inheriting common animal behaviour from Animal.

11. Important Points to Remember

  • Single inheritance involves one base class and one derived class.
  • A derived class inherits accessible members from its base class.
  • The colon (:) is used to specify inheritance.
  • Public, protected and private inheritance modes can be used.
  • Private base-class members cannot be accessed directly by derived-class functions.
  • The base constructor executes before the derived constructor.
  • The derived destructor executes before the base destructor.
  • A derived class can add its own members and functions.

12. Common Interview Questions

Q1. What is single inheritance?

Single inheritance is a type of inheritance in which one derived class inherits from one base class.

Q2. How many base classes are involved in single inheritance?

Only one base class.

Q3. Can a derived class have its own data members?

Yes. A derived class can define its own data members and member functions.

Q4. Can a derived class access private members of its base class directly?

No. Private members of the base class cannot be accessed directly by derived-class member functions.

Q5. Which constructor executes first in single inheritance?

The base-class constructor executes first.

Q6. Which destructor executes first?

The derived-class destructor executes first, followed by the base-class destructor.

Q7. What is the main advantage of single inheritance?

Code reusability and a simple class hierarchy.

Q8. Can single inheritance use protected inheritance?

Yes. Single inheritance can use public, protected or private inheritance.

13. Practice Exercise

  3. Create a derived class Car using public inheritance.
  4. Add a public function drive() that displays "Car is moving".
  5. Create an object of Car in main().
  6. Call both functions using the derived-class object.

Expected Output

Vehicle started
Car is moving
