1. Introduction

In C++, access specifiers control the accessibility of class data members and member functions.

C++ provides three main access specifiers:

  • Public
  • Private
  • Protected

The protected access specifier allows class members to be accessed inside the same class and its derived classes, but not directly through an ordinary object from outside the class hierarchy.

Main idea: Protected members are useful when a base class needs to share selected members with its derived classes without making them publicly accessible.

2. What is the Protected Access Specifier?

The protected keyword is used to declare data members and member functions that can be accessed:

  • Inside the class in which they are declared.
  • Inside derived classes, subject to C++ access rules.

They cannot be accessed directly through an ordinary object from outside the class.

Syntax

class Base { protected: int value; void display() { cout << value; } };

Here, value and display() are protected members of the Base class.

3. Accessibility of Protected Members

Protected members are accessible within the class and its derived classes.

Access Location Protected Member Accessible?
Inside the same class Yes
Inside a derived class Yes
Outside the class using an object No
Inside an unrelated class No
Remember: A derived class can access inherited protected members, but an object of the derived class cannot directly access those members from outside the class.

4. Protected Access Specifier with Inheritance

A derived class can directly use protected members inherited from its base class.

Example Program

#include <iostream> using namespace std; // Base Class class Person { protected: int age; }; // Derived Class class Student : public Person { public: void setAge(int a) { age = a; } void displayAge() { cout << "Age: " << age << endl; } }; int main() { Student s; s.setAge(21); s.displayAge(); return 0; }

Expected Output

Output: 
Age: 21

Program Explanation

  1. Person is the base class.
  2. age is declared as a protected data member.
  3. Student publicly inherits Person.
  4. Student can access the inherited protected member age.
  5. setAge() assigns a value to age.
  6. displayAge() displays the value.
  7. The main() function uses public member functions of Student.
Notice that main() does not access age directly. It accesses age through the public functions of Student.

5. Difference Between Public, Private and Protected

C++ provides three access specifiers to control access to class members.

Access Specifier Same Class Derived Class Outside Class
Public Yes Yes, if accessible through inheritance Yes, through accessible public interface
Protected Yes Yes, subject to access rules No direct access
Private Yes No direct access No direct access
Important: The table describes access to members declared in a class. Inheritance mode can further change the accessibility of inherited public and protected members.

6. Protected Members Cannot Be Accessed Directly Outside the Class

A protected member cannot be accessed directly using an object in the main() function.

Example of Invalid Access

#include <iostream> using namespace std; class Employee { protected: int salary; }; int main() { Employee e; e.salary = 30000; // Error: protected member return 0; }
Compilation Error: salary is a protected member of Employee and cannot be accessed directly from main().

Correct Approach

Use a public member function to access or modify the protected data member.

#include <iostream> using namespace std; class Employee { protected: int salary; public: void setSalary(int s) { salary = s; } void displaySalary() { cout << "Salary: " << salary << endl; } }; int main() { Employee e; e.setSalary(30000); e.displaySalary(); return 0; }

Expected Output

Salary: 30000

7. Protected Members in Multilevel Inheritance

Protected members can also be accessed by further derived classes when the inheritance access rules preserve that access.

Example Program

#include <iostream> using namespace std; // Base Class class A { protected: int num; }; // Derived Class class B : public A { public: void setNumber(int n) { num = n; } }; // Further Derived Class class C : public B { public: void display() { cout << "Number: " << num << endl; } }; int main() { C obj; obj.setNumber(100); obj.display(); return 0; }

Expected Output

Number: 100

Program Explanation

  1. Class A declares num as protected.
  2. Class B publicly inherits from A.
  3. Class B accesses num through setNumber().
  4. Class C publicly inherits from B.
  5. Class C accesses num through its inherited protected access.
  6. The object of C calls the public functions.

8. Advantages of Protected Access Specifier

  1. Controlled Access: It allows derived classes to access selected base-class members.
  2. Data Protection: It prevents direct access to protected members from ordinary outside code.
  3. Code Reusability: Derived classes can reuse protected members.
  4. Inheritance Support: It is useful for sharing implementation details within a class hierarchy.
  5. Encapsulation: It helps control how class members are exposed.

9. Important Points to Remember

  • protected is an access specifier in C++.
  • Protected members can be accessed inside their own class.
  • Derived classes can access inherited protected members.
  • Protected members cannot be accessed directly through ordinary objects from outside the class.
  • Protected members are different from private members because derived classes can access them.
  • Inheritance mode affects the accessibility of inherited members.
  • Protected members are useful in class hierarchies.

10. Common Interview Questions

Q1. What is a protected access specifier in C++?

It allows members to be accessed inside the same class and its derived classes, subject to C++ access rules.

Q2. Can protected members be accessed outside a class?

No. They cannot be accessed directly through an ordinary object from outside the class.

Q3. What is the difference between private and protected?

Private members cannot be accessed directly by derived classes. Protected members can be accessed by derived classes.

Q4. Can a derived class access protected members of its base class?

Yes. A derived class can access inherited protected members, subject to the inheritance and object access rules.

Q5. Can a protected member be accessed using an object of a derived class?

Not directly from outside the class. A public member function can provide controlled access to it.

Q6. Why do we use protected instead of public?

Protected restricts direct outside access while allowing derived classes to use the member.

Q7. Can a member function be protected?

Yes. Both data members and member functions can be declared protected.

11. Practice Exercise

  1. Create a base class Account.
  2. Declare balance as a protected data member.
  3. Create a derived class SavingsAccount.
  4. Add a public function setBalance() to assign a value.
  5. Add a public function displayBalance() to display the balance.
  6. Create an object of SavingsAccount in main().
