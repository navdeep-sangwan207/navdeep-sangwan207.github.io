About This Chapter

Inheritance is an important feature of Object-Oriented Programming (OOP) in C++. It allows one class to acquire the properties and member functions of another class.

In this chapter, you will learn about access specifiers in inheritance, different types of inheritance, constructor and destructor execution order, and virtual base classes.
