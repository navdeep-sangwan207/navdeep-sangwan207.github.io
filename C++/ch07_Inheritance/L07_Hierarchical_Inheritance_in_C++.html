1. Introduction to Hierarchical Inheritance

Hierarchical inheritance is a type of inheritance in C++ in which multiple derived classes inherit from a single base class.

The common base class provides shared data members and member functions. Each derived class can also define its own additional members and functionality.

Definition: Hierarchical inheritance is an inheritance structure in which two or more derived classes inherit from the same base class.

For example, different employee categories can inherit common employee information from a single Employee class.

2. Structure of Hierarchical Inheritance

Consider one base class A and two derived classes B and C.

Class A (Base Class)
↙       ↘
Class B
Class C
  • Class A is the common base class.
  • Class B inherits from class A.
  • Class C also inherits from class A.
  • Both derived classes can use the accessible inherited members of class A.
  • Class B and class C are separate derived classes.

3. Syntax of Hierarchical Inheritance

The general syntax is:

class A { // Base class members }; class B : public A { // Derived class B members }; class C : public A { // Derived class C members };

Both class B and class C inherit publicly from class A.

Note: Each derived class independently inherits from the same base class. Class C does not inherit from class B.

4. Basic Example of Hierarchical Inheritance

In this example, classes B and C inherit from class A.

#include <iostream> using namespace std; class A { public: void displayA() { cout << "Base class A function" << endl; } }; class B : public A { public: void displayB() { cout << "Derived class B function" << endl; } }; class C : public A { public: void displayC() { cout << "Derived class C function" << endl; } }; int main() { B obj1; C obj2; obj1.displayA(); obj1.displayB(); obj2.displayA(); obj2.displayC(); return 0; }

Expected Output

Base class A function
Derived class B function
Base class A function
Derived class C function

Explanation:

  • Class B inherits from class A.
  • Class C also inherits from class A.
  • Object obj1 can access the accessible members of A and B.
  • Object obj2 can access the accessible members of A and C.

5. Hierarchical Inheritance Using Data Members

A common base class can store shared information that is used by multiple derived classes.

#include <iostream> using namespace std; class Employee { public: int employeeID = 101; void showID() { cout << "Employee ID: " << employeeID << endl; } }; class Manager : public Employee { public: void displayManager() { showID(); cout << "Role: Manager" << endl; } }; class Developer : public Employee { public: void displayDeveloper() { showID(); cout << "Role: Developer" << endl; } }; int main() { Manager m; Developer d; m.displayManager(); cout << endl; d.displayDeveloper(); return 0; }

Expected Output

Employee ID: 101
Role: Manager

Employee ID: 101
Role: Developer

Explanation: Both Manager and Developer inherit the common employee ID and showID() function from the Employee class.

6. Hierarchical Inheritance with Constructors

When an object of a derived class is created, the constructor of the base class executes first, followed by the constructor of that derived class.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } }; class B : public A { public: B() { cout << "Constructor of B" << endl; } }; class C : public A { public: C() { cout << "Constructor of C" << endl; } }; int main() { B obj1; cout << endl; C obj2; return 0; }

Expected Output

Constructor of A
Constructor of B

Constructor of A
Constructor of C
Important: Each object has its own base-class subobject. Therefore, constructing an object of B and then an object of C invokes the constructor of A once for each object.

7. Hierarchical Inheritance with Destructors

When a derived-class object is destroyed, its destructor executes first, followed by the destructor of its base class.

#include <iostream> using namespace std; class A { public: A() { cout << "Constructor of A" << endl; } ~A() { cout << "Destructor of A" << endl; } }; class B : public A { public: B() { cout << "Constructor of B" << endl; } ~B() { cout << "Destructor of B" << endl; } }; class C : public A { public: C() { cout << "Constructor of C" << endl; } ~C() { cout << "Destructor of C" << endl; } }; int main() { B obj1; cout << endl; C obj2; return 0; }

Expected Output

Constructor of A
Constructor of B

Constructor of A
Constructor of C
Destructor of C
Destructor of A
Destructor of B
Destructor of A

Explanation: Local objects are destroyed in reverse order of their creation. For each object, the derived destructor runs before its base-class destructor.

8. Advantages of Hierarchical Inheritance

  • Promotes code reusability through a common base class.
  • Reduces duplication of common data and functions.
  • Allows multiple classes to share common functionality.
  • Makes class organization easier.
  • Allows each derived class to implement specialized features.

9. Disadvantages of Hierarchical Inheritance

  • Changes in the base class can affect multiple derived classes.
  • A large base class can become difficult to maintain.
  • Unnecessary inheritance can make class relationships complicated.
  • Each derived class must be designed carefully to avoid inappropriate dependencies.
Remember: Use a common base class when the derived classes genuinely share common characteristics or behavior.

10. Applications of Hierarchical Inheritance

  • Employee management systems.
  • Educational management systems.
  • Vehicle classification systems.
  • Banking applications with different account types.
  • Software systems with multiple specialized object types.

11. Difference Between Multilevel and Hierarchical Inheritance

Feature Multilevel Inheritance Hierarchical Inheritance
Structure Inheritance forms a chain. Multiple derived classes share one base class.
Relationship A → B → C A → B and A → C
Base Classes A derived class becomes the base for another class. One base class is shared by multiple derived classes.
Example Person → Employee → Manager Employee → Manager and Developer

12. Important Points to Remember

  • Hierarchical inheritance has one common base class and multiple derived classes.
  • Each derived class independently inherits from the common base class.
  • Derived classes can have their own additional members.
  • Base-class constructors execute before derived-class constructors.
  • Derived-class destructors execute before base-class destructors.
  • Each derived object contains its own base-class subobject.
  • Access specifiers and inheritance modes determine member accessibility.

13. Interview Questions

Q1. What is hierarchical inheritance?

It is a type of inheritance in which multiple derived classes inherit from a single base class.

Q2. How many base classes are used in basic hierarchical inheritance?

One common base class is shared by two or more derived classes.

Q3. Can derived classes have different member functions?

Yes. Each derived class can define its own data members and member functions.

Q4. Does one derived class inherit from another in hierarchical inheritance?

Not necessarily. In the basic hierarchical structure, each derived class inherits independently from the same base class.

Q5. What is the constructor execution order?

The base-class constructor executes first, followed by the constructor of the derived class whose object is created.

Q6. Give a real-world example.

A Vehicle base class with Car, Bike, and Truck as derived classes.

14. Practice Exercise

Create a C++ program using hierarchical inheritance with three classes:

  1. Create a base class Person containing a name and age.
  2. Create a derived class Student containing a roll number.
  3. Create another derived class Teacher containing a subject name.
  4. Create one object of each derived class.
  5. Display the inherited and specialized information for both objects.
Expected learning outcome: Understand how multiple derived classes can reuse common members from one base class.

15. Lesson Summary

Hierarchical inheritance allows multiple derived classes to inherit from a common base class. It promotes code reusability and helps organize related classes that share common features.

Each derived class can extend the inherited functionality independently. Constructors execute from base to derived, while destructors execute from derived to base for each object.
