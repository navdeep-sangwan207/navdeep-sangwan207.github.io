1. Introduction to Functions

A function is a named, reusable block of code designed to perform a specific task. Functions help divide a large program into smaller, manageable parts.

Instead of writing the same statements repeatedly, we can place them inside a function and execute that function whenever required.

Why use functions?
  • Reduce code repetition.
  • Improve program readability.
  • Make programs easier to test and debug.
  • Divide complex problems into smaller tasks.
  • Promote code reusability and modular programming.

2. Three Main Steps of Using a Function

In C++, a function is commonly used through three operations:

  1. Function Declaration: Informs the compiler about the function's name, return type and parameters.
  2. Function Definition: Contains the actual statements that perform the task.
  3. Function Call: Executes the function.
A function can be defined before its first call, in which case a separate declaration immediately before the call is not necessary. A prior declaration is required when the definition appears later in the source file.

3. Function Declaration

A function declaration, also called a function prototype, tells the compiler that a function exists and specifies its interface.

Syntax

return_type function_name(parameter_list);

Example

#include <iostream> using namespace std; // Function declaration int add(int, int); int main() { return 0; }

In this example:

  • int is the return type.
  • add is the function name.
  • int, int represent the parameter types.
  • The semicolon terminates the declaration.
Parameter names may be included in a declaration, but only parameter types are required. For example, int add(int a, int b); is also valid.

4. Function Definition

A function definition provides the actual implementation of a function. It contains the function body enclosed within curly braces.

Syntax

return_type function_name(parameter_list) { // Statements return value; }

Example

int add(int a, int b) { int sum = a + b; return sum; }

Here:

  • int specifies the return type.
  • add is the function name.
  • a and b are parameters.
  • sum stores the addition result.
  • return sum; sends the result back to the caller.
A non-void function should return a value compatible with its declared return type on every execution path that returns to the caller.

5. Function Call

A function call transfers control to the function so that its statements can execute.

Syntax

function_name(arguments);

Example

int result = add(10, 20);

In this statement:

  • add is the function being called.
  • 10 and 20 are arguments.
  • The returned value is stored in result.
A function call may be used as a standalone statement or as part of an expression, depending on whether its return value is needed.

6. Complete Program: Declaration, Definition and Call

The following program demonstrates all three operations using a function that adds two integers.

#include <iostream> using namespace std; // Function declaration int add(int a, int b); int main() { int result; // Function call result = add(10, 20); cout << "Sum = " << result; return 0; } // Function definition int add(int a, int b) { return a + b; }

Expected Output

Sum = 30

Program Execution Flow

  1. The compiler processes the function declaration.
  2. Program execution begins from main().
  3. main() calls add(10, 20).
  4. Control transfers to the definition of add().
  5. The function calculates 10 + 20.
  6. The value 30 is returned to main().
  7. The result is displayed on the screen.

7. Function Parameters and Arguments

Parameters and arguments are related, but they represent different things.

Parameters Arguments
Variables listed in a function declaration or definition. Values or expressions supplied during a function call.
Receive the supplied values. Provide the values to the function.
Example: int a, int b Example: 10, 20

Example

#include <iostream> using namespace std; void display(int number) { cout << "Number = " << number; } int main() { display(50); return 0; }
Number = 50

Here, number is a parameter and 50 is an argument.

8. Types of Functions Based on Return Value

Functions can be classified according to whether they accept parameters and whether they return a value.

Function Type Description Example
No arguments, no return value Does not receive arguments or return a value. void show()
Arguments, no return value Receives arguments but returns nothing. void show(int x)
No arguments, returns a value Receives no arguments but returns a result. int getNumber()
Arguments and return value Receives arguments and returns a result. int add(int a, int b)

Example: Void Function

#include <iostream> using namespace std; void greet() { cout << "Welcome to C++ Functions!"; } int main() { greet(); return 0; }
Welcome to C++ Functions!

Example: Function Returning a Value

#include <iostream> using namespace std; int square(int n) { return n * n; } int main() { cout << "Square = " << square(5); return 0; }
Square = 25

9. Function Definition Before main()

A function can also be defined before main(). In this case, the compiler has already seen the function definition before it encounters the function call.

#include <iostream> using namespace std; // Function definition int multiply(int a, int b) { return a * b; } int main() { cout << "Product = " << multiply(5, 4); return 0; }
Product = 20
A separate prototype is not needed here because the complete function definition appears before its first use.

10. Function Definition After main()

When a function is defined after main(), declare it before main() so the compiler knows its interface when it encounters the call.

#include <iostream> using namespace std; // Function declaration int subtract(int a, int b); int main() { cout << "Difference = " << subtract(20, 8); return 0; } // Function definition int subtract(int a, int b) { return a - b; }
Difference = 12

11. Important Rules of Functions

  • A function name should follow C++ identifier naming rules.
  • A function declaration ends with a semicolon.
  • A function definition contains a body enclosed in curly braces.
  • The return type in a declaration must be compatible with the definition.
  • The function call must provide arguments compatible with the parameters.
  • A non-void function returns a value of a compatible type.
  • A function declared with void does not return a value.
  • Functions can call other functions.
  • Execution normally begins from main() in a hosted C++ program.
Common mistake: Calling a function before the compiler has seen a suitable declaration or definition causes a compilation error.

12. Common Errors and Their Corrections

Incorrect Code Problem Correction
int add(int, int) Missing semicolon in a declaration. int add(int, int);
add(10, 20) Missing semicolon when used as a statement. add(10, 20);
int add(int a, int b) { } No return statement providing a value. return a + b;
void show() { return 5; } Returning a value from a void function. Use return; or remove the return statement.

13. Practice Programs

Program 1: Find the Maximum of Two Numbers

#include <iostream> using namespace std; int maximum(int a, int b) { if (a > b) return a; return b; } int main() { int x = 15, y = 25; cout << "Maximum = " << maximum(x, y); return 0; }
Maximum = 25

Program 2: Check Even or Odd

#include <iostream> using namespace std; void checkEvenOdd(int number) { if (number % 2 == 0) cout << number << " is Even"; else cout << number << " is Odd"; } int main() { checkEvenOdd(17); return 0; }
17 is Odd

Program 3: Calculate Factorial Using a Function

#include <iostream> using namespace std; int factorial(int n) { int fact = 1; for (int i = 1; i <= n; i++) { fact = fact * i; } return fact; } int main() { int number = 5; cout << "Factorial = " << factorial(number); return 0; }
Factorial = 120

14. Interview Questions

Q1. What is a function in C++?

A function is a reusable block of code that performs a specific task.

Q2. What is a function declaration?

It informs the compiler about a function's name, return type and parameter types.

Q3. What is a function definition?

It contains the actual implementation of the function.

Q4. What is a function call?

It requests execution of a function by using its name and supplying the required arguments.

Q5. What is the difference between parameters and arguments?

Parameters are variables in a function interface, whereas arguments are values or expressions supplied during a call.

Q6. Why is a function prototype required?

It allows the compiler to check a function call when the function definition appears later in the source file.

Q7. What is the purpose of the return statement?

It terminates the function and, for a non-void function, provides a value to the caller.

Q8. Can a function be called multiple times?

Yes. A function can be called multiple times wherever it is accessible and its interface permits the call.
