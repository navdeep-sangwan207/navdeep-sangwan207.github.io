1. Introduction

Recursion is a programming technique in which a function calls itself to solve a problem. Each recursive call works on a smaller or simpler version of the original problem until a stopping condition is reached.

A function that calls itself is called a recursive function. Recursion is commonly used in mathematical calculations, searching, sorting, tree traversal and divide-and-conquer algorithms.

Definition: A recursive function is a function that calls itself directly or indirectly to solve a problem through smaller subproblems.

2. How Recursion Works

A recursive function generally has two important parts:

1. Base Case

The base case is the condition that stops further recursive calls. Without a proper base case, recursion may continue indefinitely until the program runs out of stack space.

2. Recursive Case

The recursive case is the part of the function where it calls itself with a smaller or simpler input.

**Basic Structure of Recursion**
return_type function_name(parameters) { if (base_condition) { return base_value; } return function_name(smaller_input); }
A correct recursive function must make progress toward its base case. Otherwise, it may not terminate.

3. Simple Example of Recursion

The following program demonstrates a function that prints numbers from 1 to 5 using recursion.

#include <iostream> using namespace std; void display(int n) { if (n == 0) { return; } display(n - 1); cout << n << " "; } int main() { display(5); return 0; }
Expected Output: 
1 2 3 4 5

Program Explanation

  1. The function starts with display(5).
  2. It calls display(4), then display(3), and continues.
  3. When n == 0, the base condition is reached.
  4. The function calls begin returning in reverse order.
  5. The numbers are printed as the calls return.

4. Factorial Using Recursion

The factorial of a positive integer is the product of all positive integers from 1 to that number.

Mathematical definition:

n! = n × (n − 1) × (n − 2) × ... × 1
0! = 1

Recursive formula:

factorial(n) = n × factorial(n − 1)
Base case: factorial(0) = 1

Program

#include <iostream> using namespace std; long long factorial(int n) { if (n == 0 || n == 1) { return 1; } return n * factorial(n - 1); } int main() { int n = 5; cout << "Factorial of " << n << " = " << factorial(n) << endl; return 0; }
Expected Output: 
Factorial of 5 = 120

Recursive Calculation

factorial(5) = 5 * factorial(4) = 5 * 4 * factorial(3) = 5 * 4 * 3 * factorial(2) = 5 * 4 * 3 * 2 * factorial(1) = 5 * 4 * 3 * 2 * 1 = 120
This example uses long long to hold larger factorial results than a typical 32-bit integer. Even long long has a limited range, so large factorials can overflow.

5. Fibonacci Series Using Recursion

The Fibonacci sequence is a series in which each term is the sum of the previous two terms.

Fibonacci sequence:
0, 1, 1, 2, 3, 5, 8, 13, 21, ...

Formula:
F(n) = F(n - 1) + F(n - 2)
Base cases: F(0) = 0 and F(1) = 1

Program

#include <iostream> using namespace std; int fibonacci(int n) { if (n == 0) { return 0; } if (n == 1) { return 1; } return fibonacci(n - 1) + fibonacci(n - 2); } int main() { int terms = 8; for (int i = 0; i < terms; i++) { cout << fibonacci(i) << " "; } return 0; }
Expected Output: 
0 1 1 2 3 5 8 13
This simple recursive Fibonacci implementation repeats many calculations. Its time complexity is exponential, so it is inefficient for large values of n. Iteration or memoization is more efficient for larger inputs.

6. Sum of Natural Numbers Using Recursion

The sum of the first n natural numbers can be calculated recursively.

Formula:

sum(n) = n + sum(n - 1)
Base case: sum(0) = 0

Program

#include <iostream> using namespace std; int sum(int n) { if (n == 0) { return 0; } return n + sum(n - 1); } int main() { int n = 5; cout << "Sum = " << sum(n) << endl; return 0; }
Expected Output: 
Sum = 15

Calculation:

sum(5) = 5 + sum(4) = 5 + 4 + sum(3) = 5 + 4 + 3 + sum(2) = 5 + 4 + 3 + 2 + sum(1) = 5 + 4 + 3 + 2 + 1 + sum(0) = 15

7. Types of Recursion

7.1 Direct Recursion

Direct recursion occurs when a function calls itself directly.

void count(int n) { if (n == 0) return; cout << n << " "; count(n - 1); }

7.2 Indirect Recursion

Indirect recursion occurs when one function calls another function, which eventually calls the first function again.

#include <iostream> using namespace std; void functionB(int n); void functionA(int n) { if (n <= 0) return; cout << "A: " << n << endl; functionB(n - 1); } void functionB(int n) { if (n <= 0) return; cout << "B: " << n << endl; functionA(n - 1); } int main() { functionA(3); return 0; }
Expected Output: 
A: 3
B: 2
A: 1

7.3 Tail Recursion

Tail recursion occurs when the recursive call is the final operation performed by the function.

void printNumbers(int n) { if (n == 0) return; cout << n << " "; printNumbers(n - 1); }

7.4 Non-Tail Recursion

Non-tail recursion occurs when the function performs additional operations after the recursive call returns.

int factorial(int n) { if (n == 0) return 1; return n * factorial(n - 1); }

The multiplication happens after the recursive call returns, so this is non-tail recursion.

C++ does not guarantee tail-call optimization. Do not assume that tail-recursive code will always use constant stack space.

8. Recursion and the Function Call Stack

Each active function call has its own execution context. Information such as parameters, local variables and return addresses is maintained as part of the function's call state.

Recursive calls create multiple active function calls. These calls are managed using the program's call stack.

Example: factorial(3)

factorial(3) factorial(2) factorial(1) returns 1 returns 2 * 1 = 2 returns 3 * 2 = 6

When the base case is reached, the calls return one by one in reverse order.

Call stack: A memory structure that manages active function calls and their execution information.

9. Recursion vs Iteration

Recursion Iteration
A function calls itself. Uses loops such as for, while and do-while.
Uses function-call stack space for active calls. Usually uses less call-stack space for repeated operations.
Can make recursive problem structures easier to express. Can be more straightforward for simple repetition.
May cause stack overflow if recursion is too deep. Does not create a new function call for every loop iteration.
Can involve repeated calculations if poorly designed. Often provides efficient control over repeated calculations.

10. Advantages of Recursion

  • Can produce short and readable solutions for naturally recursive problems.
  • Useful for tree and graph traversal.
  • Useful in divide-and-conquer algorithms.
  • Helps solve problems that can be divided into smaller subproblems.
  • Can simplify mathematical and hierarchical problem-solving logic.

11. Disadvantages of Recursion

  • Each active recursive call requires call-stack resources.
  • Deep recursion may cause stack overflow.
  • Function-call overhead may make recursion slower than iteration in some cases.
  • Missing or incorrect base cases can cause non-terminating recursion.
  • Some recursive algorithms repeat calculations unnecessarily.
Important: Always check the base condition and ensure that each recursive call moves toward it. Also consider the maximum recursion depth for large inputs.

12. Common Mistakes

  • Forgetting to write a base case.
  • Writing a recursive call that does not move toward the base case.
  • Using the wrong base-case return value.
  • Incorrectly handling the value returned by a recursive call.
  • Using recursion for very large inputs without considering stack usage.
  • Assuming every recursive algorithm is automatically efficient.

13. Important Points to Remember

  • Recursion is a technique in which a function calls itself.
  • A recursive function needs a suitable base case.
  • The recursive case must make progress toward the base case.
  • Recursive calls are managed using the function call stack.
  • Direct recursion involves a function calling itself.
  • Indirect recursion involves multiple functions calling one another.
  • Tail recursion performs its recursive call as the final operation.
  • Non-tail recursion performs additional work after the recursive call.
  • Recursion can simplify complex problems but may use additional memory.

15. Interview Questions

Q1. What is recursion?

Recursion is a programming technique in which a function calls itself to solve a problem through smaller subproblems.

Q2. What is a base case?

A base case is the stopping condition that prevents further recursive calls.

Q3. What happens if a recursive function has no base case?

It may continue making recursive calls until the program exhausts available call-stack resources.

Q4. What is direct recursion?

Direct recursion occurs when a function calls itself directly.

Q5. What is indirect recursion?

Indirect recursion occurs when one function calls another function that eventually calls the first function.

Q6. What is the call stack?

It is the memory structure used to manage active function calls and their execution information.

Q7. What is tail recursion?

Tail recursion occurs when the recursive call is the final operation performed by the function.

Q8. What is the difference between recursion and iteration?

Recursion uses function calls, whereas iteration uses loops to repeat a set of instructions.

Q9. Can recursion cause stack overflow?

Yes. Excessively deep recursion can exhaust available call-stack space.

Q10. Is recursion always better than iteration?

No. The best approach depends on the problem, performance requirements, memory usage and code clarity.
