1. Introduction

In C++, decision-making statements allow a program to execute different blocks of code depending on whether a condition is true or false.

The if-else statement is a decision-making statement used to select one of two possible execution paths.

If the condition evaluates to true, the if block executes. Otherwise, the else block executes.

Example: A program checks whether a student has passed an examination. If the marks are 40 or above, the result is Pass; otherwise, it is Fail.

2. Syntax of if Statement

The basic syntax of an if statement is:

if (condition) { // Statements executed when condition is true }
  • if: A keyword used to check a condition.
  • condition: An expression that evaluates to true or false.
  • if block: Contains statements executed when the condition is true.

Example: Simple if Statement

#include <iostream> using namespace std; int main() { int age = 20; if (age >= 18) { cout << "You are eligible to vote."; } return 0; }
Expected Output:
You are eligible to vote.

Since age is 20 and the condition age >= 18 is true, the statement inside the if block executes.

3. Syntax of if-else Statement

The if-else statement provides two alternative execution paths.

if (condition) { // Executes when condition is true } else { // Executes when condition is false }

Example: Check Even or Odd

#include <iostream> using namespace std; int main() { int number; cout << "Enter a number: "; cin >> number; if (number % 2 == 0) { cout << "Even number"; } else { cout << "Odd number"; } return 0; }
Expected Output (Example 1):
Enter a number: 8 Even number
Expected Output (Example 2):
Enter a number: 7 Odd number

The modulus operator (%) returns the remainder after division. If the remainder is zero when divided by 2, the number is even. Otherwise, it is odd.

4. if-else-if Ladder

An if-else-if ladder is used when multiple conditions need to be checked one after another.

The conditions are evaluated from top to bottom. The block associated with the first true condition executes. If no condition is true, the else block executes.

Syntax

if (condition1) { // Statements } else if (condition2) { // Statements } else if (condition3) { // Statements } else { // Default statements }

Example: Grade Calculation

#include <iostream> using namespace std; int main() { int marks; cout << "Enter your marks: "; cin >> marks; if (marks >= 90) { cout << "Grade A"; } else if (marks >= 75) { cout << "Grade B"; } else if (marks >= 60) { cout << "Grade C"; } else if (marks >= 40) { cout << "Grade D"; } else { cout << "Fail"; } return 0; }
Expected Output:
Enter your marks: 82 Grade B
Note: This example assumes marks are between 0 and 100. Input validation can be added to reject values outside this range.

5. Nested if-else Statement

A nested if-else statement means placing one if-else statement inside another if or else block.

It is useful when a decision depends on another decision.

Syntax

if (condition1) { if (condition2) { // Statements } else { // Statements } } else { // Statements }

Example: Check Eligibility

#include <iostream> using namespace std; int main() { int age; char citizen; cout << "Enter your age: "; cin >> age; cout << "Are you a citizen? (Y/N): "; cin >> citizen; if (age >= 18) { if (citizen == 'Y' || citizen == 'y') { cout << "Eligible to vote."; } else { cout << "Citizenship requirement not met."; } } else { cout << "Age requirement not met."; } return 0; }
Expected Output:
Enter your age: 20 Are you a citizen? (Y/N): Y Eligible to vote.

6. Flow of Execution

The general execution flow of an if-else statement is:

  1. The condition is evaluated.
  2. If the condition is true, the if block executes.
  3. If the condition is false, the else block executes.
  4. Execution continues with the statement after the if-else structure.
Remember: In an if-else structure, only one of the two blocks executes.

7. Difference Between if, if-else and else-if Ladder

Statement Purpose Execution
if Checks a single condition. Executes its block only when the condition is true.
if-else Selects between two alternatives. Executes either the if block or the else block.
if-else-if ladder Checks multiple conditions. Executes the block for the first true condition.
Nested if-else Checks dependent conditions. An if-else structure is placed inside another.

8. Common Mistakes

1. Using Assignment Instead of Comparison

Incorrect:
if (number = 10)
Correct:
if (number == 10)
The assignment operator (=) assigns a value, while the equality operator (==) compares two values.

2. Missing Braces

Braces are optional when a block contains only one statement, but using braces is recommended for clarity and to avoid accidental logic errors.

3. Incorrect Condition Order

In an if-else-if ladder, a broader condition placed before a more specific condition may prevent the later condition from being checked.

4. Dangling else

When nested if statements are written without braces, an else is associated with the nearest unmatched if. Use braces to make the intended structure clear.

9. Important Points

  • The if statement is used for decision-making.
  • The condition is evaluated as a Boolean result.
  • The else block executes when the if condition is false.
  • The else part is optional.
  • An if-else-if ladder can check multiple conditions.
  • Nested if-else statements allow dependent decisions.
  • Braces improve readability and help prevent logic errors.
  • Only the first matching branch executes in an if-else-if ladder.
