Call by Value and Call by Reference in C++

1. Introduction

Function arguments can be passed to functions in different ways. Two important techniques in C++ are call by value and call by reference.

The main difference is whether the function receives an independent copy of the argument or accesses the original object through a reference.

Call by Value: The function receives a copy of the argument.

Call by Reference: The function receives a reference to the original argument.

2. Call by Value

In call by value, a copy of the actual argument is passed to the function parameter.

The function works with its own parameter variable. Changes made to that parameter do not modify the original argument.

Syntax

return_type function_name(data_type parameter) { // Function body } function_name(argument);

Example

#include <iostream> using namespace std; void changeValue(int x) { x = 100; cout << "Inside function: " << x << endl; } int main() { int number = 10; changeValue(number); cout << "Inside main: " << number; return 0; }

Expected Output

Inside function: 100
Inside main: 10

Explanation

  1. The variable number contains 10.
  2. changeValue(number) passes a copy of its value.
  3. The function parameter x receives 10.
  4. The function changes its local parameter to 100.
  5. The original variable number remains 10.
Changes made to a normal value parameter do not affect the original argument.

3. Memory Concept of Call by Value

In call by value, the parameter is a separate object that receives the value of the argument.

Conceptual representation:
main(): number = 10 function changeValue(): x = 10 // Separate parameter object x = 100 // Changes only x After function call: number = 10 x = destroyed when function returns

The parameter has its own lifetime. When the function finishes, its local parameter is destroyed.

4. Call by Reference

In call by reference, a function parameter is declared as a reference to the original argument.

The parameter becomes another name for the original object. Therefore, changes made through the parameter directly affect the original variable.

Syntax

return_type function_name(data_type &parameter) { // Function body } function_name(argument);

Example

#include <iostream> using namespace std; void changeValue(int &x) { x = 100; cout << "Inside function: " << x << endl; } int main() { int number = 10; changeValue(number); cout << "Inside main: " << number; return 0; }

Expected Output

Inside function: 100
Inside main: 100

Explanation

  1. The variable number contains 10.
  2. changeValue(number) passes the original object by reference.
  3. The parameter x refers to number.
  4. Assigning 100 to x changes the original object.
  5. After the function returns, number contains 100.
A reference parameter is an alias for the original argument. It does not create a separate integer object.

5. Memory Concept of Call by Reference

In call by reference, the parameter refers to the same object as the argument.

Conceptual representation:
main(): number = 10 function changeValue(): x refers to number x = 100 After function call: number = 100

Both names access the same original object. There is no separate copy of the integer parameter.

6. Difference Between Call by Value and Call by Reference

Call by Value Call by Reference
A copy of the argument is passed. A reference to the original argument is passed.
Parameter is a separate object. Parameter is an alias for the original object.
Changes to the parameter do not modify the original argument. Changes through the parameter modify the original argument.
Ordinary value parameters are independent of the caller's variable. Reference parameters access the caller's variable directly.
Can involve copying larger objects. Can avoid copying larger objects.
Syntax: void show(int x) Syntax: void show(int &x)

7. Program to Swap Two Numbers Using Call by Value

This program demonstrates why call by value cannot modify the original variables during a swap operation.

#include <iostream> using namespace std; void swapNumbers(int a, int b) { int temp = a; a = b; b = temp; } int main() { int x = 10; int y = 20; swapNumbers(x, y); cout << "x = " << x << endl; cout << "y = " << y; return 0; }

Expected Output

x = 10
y = 20

Only the local copies a and b are swapped. The original variables remain unchanged.

8. Program to Swap Two Numbers Using Call by Reference

By passing the variables through reference parameters, the function can swap their original values.

#include <iostream> using namespace std; void swapNumbers(int &a, int &b) { int temp = a; a = b; b = temp; } int main() { int x = 10; int y = 20; swapNumbers(x, y); cout << "x = " << x << endl; cout << "y = " << y; return 0; }

Expected Output

x = 20
y = 10
The reference parameters a and b refer to x and y, respectively. Therefore, the swap modifies the original variables.

9. Call by Constant Reference

C++ also supports passing arguments through constant references.

A constant reference allows a function to access an original object without modifying it through that reference.

Syntax

void display(const data_type &parameter);

Example

#include <iostream> #include <string> using namespace std; void display(const string &text) { cout << "Message: " << text; // text = "New Message"; // Error } int main() { string message = "Welcome to C++"; display(message); return 0; }

Expected Output

Message: Welcome to C++

The function reads the original string without creating an ordinary string copy and cannot modify it through the constant reference.

Constant references are particularly useful when passing large objects such as strings, vectors and class objects to functions that only need to read them.

10. Call by Value with Pointer Arguments

C++ passes function arguments by value unless a reference parameter is explicitly declared. This also applies to pointers.

When a pointer is passed by value, the function receives a copy of the pointer. However, that copied pointer can still access and modify the object it points to.

Example

#include <iostream> using namespace std; void changeValue(int *ptr) { *ptr = 100; } int main() { int number = 10; changeValue(&number); cout << "Number = " << number; return 0; }

Expected Output

Number = 100

The pointer itself is copied, but both pointer values refer to the same original integer object. Therefore, changing *ptr modifies number.

Do not confuse modifying the object through a copied pointer with modifying the caller's pointer variable. Those are two different operations.

11. When to Use Each Method

Method When to Use
Call by Value When the function needs its own independent copy and should not modify the caller's object.
Call by Reference When the function needs to modify the original object.
Call by Constant Reference When the function needs to read an object without modifying it, especially for larger objects.

12. Advantages and Disadvantages

Call by Value

Advantages:

  • Protects the caller's original variable from direct modification through the parameter.
  • Provides an independent local parameter object.
  • Useful for small data types such as integers and characters.

Disadvantages:

  • Copying large objects can require additional time and memory.
  • Cannot directly modify the caller's original object through an ordinary value parameter.

Call by Reference

Advantages:

  • Allows modification of original variables.
  • Avoids copying the referred object.
  • Useful for swapping and updating multiple variables.
  • Efficient for passing large objects.

Disadvantages:

  • Changes can affect the caller's original data.
  • Requires careful handling of object lifetime.
  • Non-const references can make function side effects less obvious.

13. Common Mistakes

Mistake 1: Expecting Call by Value to Modify the Original Variable

void update(int x) { x = 50; }

Correction: Use a reference parameter if the original variable must be modified.

void update(int &x) { x = 50; }

Mistake 2: Forgetting the Ampersand in a Reference Parameter

void update(int x) // Call by value

This function receives a copy. To use call by reference, declare the parameter as int &x.

Mistake 3: Returning a Reference to a Local Variable

int& getValue() { int x = 10; return x; // Dangerous: x is destroyed after return }

Correction: Return a reference only when the referenced object is guaranteed to remain alive.

Mistake 4: Confusing Pointer Passing with Reference Passing

Passing a pointer by value copies the pointer. It does not automatically make the pointer parameter a reference.

15. Interview Questions

Q1. What is call by value?

Call by value passes a copy of the argument to the function. Changes to the parameter do not modify the original argument.

Q2. What is call by reference?

Call by reference uses a reference parameter that aliases the original argument.

Q3. What is the main difference between call by value and call by reference?

Call by value creates a separate parameter object, whereas call by reference provides access to the original object.

Q4. Can call by value modify the original variable?

An ordinary value parameter cannot directly modify the caller's variable. Other mechanisms, such as passing a pointer value, can provide indirect access to an object.

Q5. Why is call by reference useful?

It allows functions to modify original variables and avoids copying the referred object.

Q6. What is call by constant reference?

It passes an object through a constant reference, allowing access without modification through that reference.

Q7. Can a pointer be passed by value?

Yes. C++ copies the pointer value. The copied pointer can still access the object it points to.

Q8. Which method is suitable for swapping two variables?

Call by reference is suitable because it allows the function to modify the original variables.

Q9. Does C++ support traditional call by reference?

C++ supports reference parameters, which provide reference semantics when calling a function.

Q10. Is C++ strictly call by reference for reference parameters?

The function receives a reference parameter that aliases the original object. More precisely, C++ passes the reference argument to initialize that reference parameter.

16. Quick Revision

Concept Description
Call by Value Passes a copy of the argument.
Call by Reference Passes access to the original object through a reference parameter.
Value Parameter Separate parameter object.
Reference Parameter Alias for the original object.
Constant Reference Allows reading without modification through that reference.
Pointer by Value Copies the pointer, but can still access the pointed-to object.
Remember: Call by value works with a copy. Call by reference works with the original object through an alias. Use constant references when an object should be accessed without being modified through the function.
