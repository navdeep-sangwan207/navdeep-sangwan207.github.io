1. Introduction

The switch statement is a decision-making statement in C++ that allows a program to select one block of code from multiple alternatives.

It evaluates an expression and compares its value with different case labels. When a matching case is found, execution starts from that case.

The switch statement is useful when a variable or expression needs to be compared against several fixed values.

Example: A menu-driven program can use a switch statement to perform addition, subtraction, multiplication, or division based on the user's choice.

2. Syntax of switch Statement

switch (expression) { case constant1: // Statements break; case constant2: // Statements break; case constant3: // Statements break; default: // Default statements }

Explanation

  • switch: Keyword used to select among multiple alternatives.
  • expression: An integral, enumeration, or suitable class-type expression.
  • case: Defines a possible matching value.
  • constant: A compile-time constant case label.
  • break: Terminates the switch statement.
  • default: Executes when no case label matches.
Important: Case labels must be unique within the same switch statement. A switch statement does not directly support floating-point or string case labels.

3. Working of switch Statement

  1. The switch expression is evaluated once.
  2. Its value is compared with the case labels.
  3. If a matching case is found, execution begins from that case.
  4. The statements continue executing until a break or the end of the switch body is reached.
  5. If no case matches, the default block executes, if present.
Remember: The switch statement checks for matching values. It does not evaluate relational conditions such as greater than or less than in case labels.

4. Example: Display Day of the Week

This program displays the name of a day based on a number entered by the user.

#include <iostream> using namespace std; int main() { int day; cout << "Enter day number (1-7): "; cin >> day; switch (day) { case 1: cout << "Monday"; break; case 2: cout << "Tuesday"; break; case 3: cout << "Wednesday"; break; case 4: cout << "Thursday"; break; case 5: cout << "Friday"; break; case 6: cout << "Saturday"; break; case 7: cout << "Sunday"; break; default: cout << "Invalid day number"; } return 0; }
Expected Output:
Enter day number (1-7): 3 Wednesday

Since the entered value is 3, case 3 matches and Wednesday is displayed.

5. Importance of break Statement

The break statement is used to terminate the switch statement after executing a matching case.

Example Without break

#include <iostream> using namespace std; int main() { int choice = 1; switch (choice) { case 1: cout << "One" << endl; case 2: cout << "Two" << endl; case 3: cout << "Three" << endl; default: cout << "Default case"; } return 0; }
Expected Output:
One Two Three Default case

Because break statements are missing, execution continues through the following case labels. This behavior is called fall-through.

Warning: Forgetting break can cause unintended execution of multiple case blocks.

6. Fall-through in switch Statement

Fall-through occurs when execution continues from one case into the next because there is no break statement.

Sometimes fall-through is intentional, such as when multiple case labels should execute the same block of code.

Example: Multiple Cases with Common Statements

#include <iostream> using namespace std; int main() { int day; cout << "Enter day number (1-7): "; cin >> day; switch (day) { case 1: case 2: case 3: case 4: case 5: cout << "Weekday"; break; case 6: case 7: cout << "Weekend"; break; default: cout << "Invalid day"; } return 0; }
Expected Output:
Enter day number (1-7): 6 Weekend

Cases 1 through 5 share the same statements. Cases 6 and 7 also share the same statements.

7. Use of default Case

The default case is optional. It executes when none of the case labels matches the switch expression.

Example

#include <iostream> using namespace std; int main() { int choice = 5; switch (choice) { case 1: cout << "Start"; break; case 2: cout << "Stop"; break; default: cout << "Invalid choice"; } return 0; }
Expected Output:
Invalid choice

8. Example: Simple Calculator Using switch

A switch statement can be used to build a simple menu-driven calculator.

#include <iostream> using namespace std; int main() { double a, b; char op; cout << "Enter first number: "; cin >> a; cout << "Enter operator (+, -, *, /): "; cin >> op; cout << "Enter second number: "; cin >> b; switch (op) { case '+': cout << "Result = " << a + b; break; case '-': cout << "Result = " << a - b; break; case '*': cout << "Result = " << a * b; break; case '/': if (b != 0) { cout << "Result = " << a / b; } else { cout << "Error: Division by zero"; } break; default: cout << "Invalid operator"; } return 0; }
Expected Output:
Enter first number: 20 Enter operator (+, -, *, /): * Enter second number: 5 Result = 100
Note: The program checks for division by zero before performing division.

9. switch vs if-else

Feature switch if-else
Purpose Compares an expression against fixed case values. Checks conditions and expressions.
Conditions Uses matching case labels. Supports relational and logical conditions.
Data types Uses integral, enumeration, or suitable class-type expressions. Can use Boolean-convertible conditions.
break Commonly used to prevent fall-through. Not required for normal if-else execution.
Default branch Uses default. Uses else.
Best suited for Menu choices and fixed alternatives. Ranges and complex conditions.

10. Common Mistakes

1. Forgetting break

Without break, execution may continue into subsequent cases.

2. Duplicate case labels

Two case labels in the same switch statement cannot have the same value.

3. Using variables as case labels

Incorrect:
int x = 5; switch (number) { case x: cout << "Matched"; }
Correct:
switch (number) { case 5: cout << "Matched"; break; }
Case labels must be constant expressions.

4. Using an unsuitable switch expression

A switch expression must have an appropriate type. Ordinary floating-point values and std::string values cannot be used directly as switch expressions.

11. Important Points

  • switch is a multi-way decision-making statement.
  • Each case label represents a constant value.
  • Case labels must be unique within a switch.
  • break terminates the switch statement.
  • Without break, fall-through may occur.
  • The default case is optional.
  • Multiple case labels can share a common block.
  • switch is useful for menu-driven programs.
  • Use if-else for ranges and complex logical conditions.
