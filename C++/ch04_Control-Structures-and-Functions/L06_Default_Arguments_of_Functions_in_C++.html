1. Introduction to Default Arguments

In C++, a default argument is a value provided in a function declaration that is automatically used when the caller does not supply a corresponding argument.

Default arguments make function calls more flexible because the caller can omit some arguments without requiring separate overloaded functions.

Example: A function that displays a student's name and age can use a default age when the caller provides only the name.

2. Syntax of Default Arguments

return_type function_name( parameter1, parameter2 = default_value );

The default value is assigned using the assignment operator (=) in the function declaration.

Example

#include <iostream> using namespace std; // Function declaration with a default argument void display(int number = 10); int main() { display(); return 0; } // Function definition void display(int number) { cout << "Number = " << number; }
Number = 10

Since no argument is supplied in display(), the default value 10 is used.

3. How Default Arguments Work

When a function is called, C++ uses the supplied arguments first. If an argument is omitted and a default value is available for that parameter, the default value is used.

Example

#include <iostream> using namespace std; void show(int a, int b = 20) { cout << "a = " << a << ", b = " << b << endl; } int main() { show(10); show(10, 50); return 0; }

Expected Output

a = 10, b = 20
a = 10, b = 50

Explanation:

  • show(10) supplies only the first argument. The second uses its default value, 20.
  • show(10, 50) supplies both arguments. The default value is not used.

4. Rules of Default Arguments

Rule 1: Default Arguments Must Be Provided from Right to Left

Once a parameter has a default argument, all parameters appearing after it must also have default arguments.

// Correct void display(int a, int b = 10, int c = 20); // Incorrect void display(int a = 10, int b, int c = 20);
Remember: Default arguments must be assigned to trailing parameters, not to a parameter followed by a non-default parameter.

Rule 2: Arguments Are Omitted from the Right

void calculate(int a, int b = 10, int c = 20);

Valid function calls include:

calculate(5); calculate(5, 15); calculate(5, 15, 25);

You cannot omit the second argument while supplying the third argument positionally.

// Invalid calculate(5, , 25);

Rule 3: Specify Default Values Only Once in the Same Scope

If a function declaration already specifies a default argument, do not repeat that default value in the function definition in the same scope.

// Correct void display(int x = 10); void display(int x) { cout << x; }
// Incorrect void display(int x = 10); void display(int x = 10) { cout << x; }
Repeating a default argument in the same scope causes a compilation error.

5. Multiple Default Arguments

A function can have more than one default argument, provided the parameters follow the right-to-left rule.

Example

#include <iostream> using namespace std; void display(int a, int b = 10, int c = 20) { cout << "a = " << a << endl; cout << "b = " << b << endl; cout << "c = " << c << endl; } int main() { cout << "First Call:" << endl; display(5); cout << endl << "Second Call:" << endl; display(5, 15); cout << endl << "Third Call:" << endl; display(5, 15, 25); return 0; }

Expected Output

First Call:
a = 5
b = 10
c = 20

Second Call:
a = 5
b = 15
c = 20

Third Call:
a = 5
b = 15
c = 25

Each call supplies a different number of arguments. The omitted trailing arguments receive their default values.

6. Default Arguments with Function Declaration

Default arguments are commonly specified in the function declaration, especially when the function definition appears after main().

#include <iostream> using namespace std; // Function declaration int add(int a, int b = 5); int main() { cout << "Result = " << add(10); return 0; } // Function definition int add(int a, int b) { return a + b; }
Result = 15
The default value is specified in the declaration. The definition contains the parameter list without repeating the default value.

7. Default Arguments with Multiple Parameters

Example: Calculate Simple Interest

The rate of interest and time are given default values. The caller can override them when required.

#include <iostream> using namespace std; double simpleInterest(double principal, double rate = 5.0, double time = 2.0) { return (principal * rate * time) / 100.0; } int main() { cout << "Default Interest = " << simpleInterest(10000) << endl; cout << "Custom Interest = " << simpleInterest(10000, 8.0, 3.0); return 0; }

Expected Output

Default Interest = 1000
Custom Interest = 2400

In the first call, the default rate and time are used. In the second call, the supplied values replace the defaults.

8. Default Arguments vs Function Overloading

Default arguments and function overloading can both be used to support calls with different numbers of arguments, but they work differently.

Default Arguments Function Overloading
Uses default values for omitted trailing arguments. Uses multiple functions with the same name and different parameter lists.
One function declaration and definition can support multiple call forms. Multiple function definitions are provided.
Example: void show(int x = 10); Example: void show(); void show(int x);

Example of Function Overloading

#include <iostream> using namespace std; void display() { cout << "No argument" << endl; } void display(int x) { cout << "Value = " << x << endl; } int main() { display(); display(50); return 0; }
No argument
Value = 50
Avoid creating overloads that make a call ambiguous with default arguments. For example, combining void show(int x = 10) and void show() makes show() ambiguous.

9. Advantages of Default Arguments

  • Reduces the need for multiple overloaded functions.
  • Makes function calls shorter and simpler.
  • Provides flexibility to callers.
  • Improves code reusability.
  • Allows commonly used values to be specified once.

10. Common Errors

Error 1: Default Argument Before a Non-Default Parameter

// Incorrect void display(int a = 10, int b);

Correction: Give the trailing parameter a default value or remove the earlier default.

// Correct void display(int a, int b = 10);

Error 2: Repeating the Default Value

// Incorrect void show(int x = 5); void show(int x = 5) { cout << x; }

Correction: Specify the default value in the declaration only.

Error 3: Skipping a Middle Argument

// Invalid void calculate(int a, int b = 10, int c = 20); calculate(5, , 30);

Correction: Supply arguments from left to right. Positional function calls cannot skip a middle parameter.

12. Interview Questions

Q1. What are default arguments in C++?

Default arguments are predefined values used when the caller omits the corresponding trailing arguments.

Q2. Where are default arguments specified?

They are commonly specified in a function declaration or prototype.

Q3. Can all function parameters have default arguments?

Yes. If all parameters have default values, the function can be called without supplying any arguments.

Q4. Can a parameter without a default argument follow one with a default argument?

No. All parameters following the first defaulted parameter must also have default arguments.

Q5. Can default arguments be changed during a function call?

Yes. A caller can provide an explicit argument to override the default value.

Q6. Can default arguments be repeated in the function definition?

No. A default argument must not be redeclared in the same scope.

Q7. What is the main advantage of default arguments?

They allow flexible function calls and reduce the need for multiple overloaded functions.

Q8. Can we skip a middle argument when calling a function?

No. Arguments are supplied positionally, so only trailing arguments can be omitted.
