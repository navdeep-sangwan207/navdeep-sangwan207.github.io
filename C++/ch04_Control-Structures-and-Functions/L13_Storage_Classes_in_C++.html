1. Introduction to Storage Classes

In C++, a variable has several properties that determine how it behaves during program execution. These include its scope, lifetime, linkage and storage duration.

Storage-related specifiers help control or describe these properties. Understanding them is important when working with local variables, global variables, functions and objects.

Important: In modern C++, it is more accurate to understand variables through scope, storage duration and linkage rather than treating every declaration as one of a fixed list of traditional storage classes.

2. Important Concepts

2.1 Scope

Scope determines the region of a program where a name can be accessed.

  • Block scope: A name declared inside a block is generally accessible from its declaration to the end of that block.
  • Namespace scope: A name declared directly inside a namespace has namespace scope.
  • Class scope: Members declared inside a class have class scope.

2.2 Storage Duration

Storage duration determines the period during which an object's storage is guaranteed to exist.

Storage Duration Description
Automatic Typically associated with local variables; storage lasts until the block exits.
Static Storage lasts for the entire execution of the program.
Dynamic Storage is obtained and released through dynamic memory management.
Thread Storage lasts for the lifetime of the thread.

2.3 Linkage

Linkage determines whether the same name declared in different scopes or translation units refers to the same entity.

  • No linkage: The name is not connected to declarations in other scopes or translation units.
  • Internal linkage: The name can be referred to within the same translation unit.
  • External linkage: The name can be referred to from other translation units, subject to the applicable language rules.

3. The static Specifier

The static specifier has different effects depending on where it is used. A common use is to make a local variable retain its value between function calls.

Example: Static Local Variable

C++ Program
#include <iostream> using namespace std; void counter() { static int count = 0; count++; cout << "Count = " << count << endl; } int main() { counter(); counter(); counter(); return 0; }
Expected Output: 
Count = 1
Count = 2
Count = 3

Working

  1. The static variable count is initialized only once.
  2. It retains its value between function calls.
  3. Each call increments the same variable.
  4. Its storage duration lasts throughout the program.
A normal automatic local variable is created again when the function is called. A static local variable retains its stored value between calls.

Static Data Member

A static data member belongs to the class rather than to each individual object. All objects of the class share the same static data member.

C++ Program
#include <iostream> using namespace std; class Student { public: static int count; Student() { count++; } }; int Student::count = 0; int main() { Student s1; Student s2; Student s3; cout << "Total objects = " << Student::count; return 0; }
Expected Output: 
Total objects = 3
A static data member is shared by all objects of its class. It can be accessed using the class name and scope resolution operator.

4. The extern Specifier

The extern specifier is used to declare a variable or function that is defined elsewhere. It is commonly used to refer to a global variable defined in another source file.

Example: extern Declaration

File 1: main.cpp

#include <iostream> using namespace std; extern int number; int main() { cout << "Number = " << number; return 0; }

File 2: data.cpp

int number = 100;
Expected Output: 
Number = 100

Working

  • extern int number; declares that the variable is defined elsewhere.
  • int number = 100; provides the definition.
  • Both source files must be compiled and linked together.
An extern declaration generally does not create a new variable definition. It refers to an entity defined elsewhere.

5. The thread_local Specifier

The thread_local specifier gives a variable thread storage duration. Each thread has its own separate instance of the variable.

C++ Program (C++11 or later)
#include <iostream> #include <thread> using namespace std; thread_local int value = 0; void display() { value++; cout << "Value = " << value << endl; } int main() { thread t1(display); thread t2(display); t1.join(); t2.join(); return 0; }
Possible Output: 
Value = 1
Value = 1

The order of the two lines may vary because the threads execute independently.

Each thread has its own copy of value. Therefore, incrementing it in one thread does not increment the copy belonging to another thread.
This example requires C++11 or later and a compiler environment that supports the standard thread library.

6. The mutable Specifier

The mutable specifier allows a non-static data member of a class to be modified even when the containing object is accessed through a const object.

C++ Program
#include <iostream> using namespace std; class Test { public: int number = 10; mutable int count = 0; }; int main() { const Test obj; obj.count++; cout << "Number = " << obj.number << endl; cout << "Count = " << obj.count; return 0; }
Expected Output: 
Number = 10
Count = 1
Remember: mutable does not make every member modifiable. It applies only to the data member declared with the mutable specifier.

7. The auto Keyword in Modern C++

In modern C++, auto is primarily used for automatic type deduction. The compiler determines the variable's type from its initializer.

C++ Program
#include <iostream> using namespace std; int main() { auto number = 100; auto price = 25.5; auto letter = 'A'; cout << number << endl; cout << price << endl; cout << letter << endl; return 0; }
Expected Output: 
100
25.5
A

Working

  • auto number = 100; deduces an integer type.
  • auto price = 25.5; deduces a double type.
  • auto letter = 'A'; deduces a character type.
In modern C++, auto is a type-deduction keyword. It should not be confused with the older meaning of auto as a storage-class specifier.

8. The register Keyword and Modern C++

Historically, register was used as a hint that a variable should be stored in a CPU register for faster access. Modern compilers perform their own register allocation and optimization.

The register storage-class specifier was removed from C++ in C++17. Do not use it in modern C++ programs.

Instead of relying on register declarations, write clear code and allow the compiler to optimize it.

9. Comparison of Important Specifiers

Specifier Main Purpose Important Behaviour
static Static storage duration or class-level sharing, depending on context. A static local variable retains its value between function calls.
extern Refers to an entity defined elsewhere. Commonly used for declarations of global variables and functions.
thread_local Thread storage duration. Each thread has its own instance.
mutable Allows modification of a particular class data member. Can be modified even through a const object.
auto Automatic type deduction. Compiler determines the type from the initializer.
register Historical storage-class specifier. Removed in C++17.

10. Common Mistakes

  1. Assuming a static local variable is initialized every time its function is called.
  2. Confusing a static data member with an ordinary non-static data member.
  3. Using an extern declaration without providing the required definition when one is needed.
  4. Assuming thread_local variables are shared between threads.
  5. Thinking mutable makes an entire const object modifiable.
  6. Using register as a storage-class specifier in C++17 or later.
  7. Confusing modern auto type deduction with the historical storage-class meaning of auto.

11. Important Points to Remember

  • Scope determines where a name can be accessed.
  • Storage duration determines how long an object's storage exists.
  • Linkage determines how declarations can refer to the same entity.
  • Static local variables retain their values between calls.
  • Static data members are shared by all objects of a class.
  • Extern is commonly used to refer to a definition in another source file.
  • Thread_local creates a separate instance for each thread.
  • Mutable allows a particular class member to change through a const object.
  • Modern auto performs type deduction.
  • Register was removed as a storage-class specifier in C++17.

13. Interview Questions

Q1. What is a storage duration?

Storage duration describes the period during which an object's storage exists.

Q2. What is the difference between a normal local variable and a static local variable?

A normal local variable has automatic storage duration and is recreated when its block is entered. A static local variable retains its value throughout program execution.

Q3. What is a static data member?

It is a class member shared by all objects of that class.

Q4. What is the purpose of extern?

It declares an entity that is defined elsewhere, commonly in another source file.

Q5. What is thread_local?

It gives a variable thread storage duration, so each thread has its own instance.

Q6. What is the purpose of mutable?

It allows a specific non-static class data member to be modified even through a const object.

Q7. What does auto do in modern C++?

It enables the compiler to deduce a variable's type from its initializer.

Q8. Is register used in modern C++?

No. The register storage-class specifier was removed in C++17.
