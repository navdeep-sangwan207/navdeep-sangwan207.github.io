1. Introduction to Loops

A loop is a control structure that repeatedly executes a block of statements as long as a specified condition is satisfied.

Loops help avoid writing the same statements multiple times. They are commonly used for counting, processing arrays, calculating totals and performing repetitive operations.

Types of Loops in C++

  • for loop: Commonly used when the number of iterations is known.
  • while loop: Checks the condition before executing the loop body.
  • do-while loop: Executes the loop body at least once before checking the condition.
Important: The for and while loops are entry-controlled loops. The do-while loop is an exit-controlled loop.

2. for Loop

A for loop is used to execute a block of statements repeatedly. It is particularly useful when the number of iterations is known in advance.

Syntax

for (initialization; condition; update) { // Statements to be repeated }

Components of a for Loop

Component Purpose
Initialization Initializes the loop control variable.
Condition Determines whether the loop continues.
Update Changes the loop control variable after each iteration.

Working of for Loop

  1. Initialization executes once.
  2. The condition is checked.
  3. If true, the loop body executes.
  4. The update expression executes.
  5. The condition is checked again.
  6. The loop terminates when the condition becomes false.

Example 1: Print Numbers from 1 to 5

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 5; i++) { cout << i << endl; } return 0; }
Expected Output:
1 2 3 4 5

Example 2: Sum of First 10 Natural Numbers

#include <iostream> using namespace std; int main() { int sum = 0; for (int i = 1; i <= 10; i++) { sum = sum + i; } cout << "Sum = " << sum; return 0; }
Expected Output:
Sum = 55

3. while Loop

A while loop repeatedly executes a block of statements as long as its condition remains true.

The condition is checked before the loop body executes. Therefore, if the condition is initially false, the loop body will not execute.

Syntax

while (condition) { // Statements to be repeated }

Working of while Loop

  1. The condition is evaluated.
  2. If true, the loop body executes.
  3. The condition is checked again.
  4. The process continues while the condition is true.
  5. When the condition becomes false, the loop terminates.

Example 1: Print Numbers from 1 to 5

#include <iostream> using namespace std; int main() { int i = 1; while (i <= 5) { cout << i << endl; i++; } return 0; }
Expected Output:
1 2 3 4 5

Example 2: Reverse Counting

#include <iostream> using namespace std; int main() { int i = 5; while (i >= 1) { cout << i << endl; i--; } return 0; }
Expected Output:
5 4 3 2 1

4. do-while Loop

A do-while loop executes its body first and checks the condition afterward.

Therefore, the loop body executes at least once, even if the condition is false initially.

Syntax

do { // Statements to be repeated } while (condition);
Remember: A semicolon is required after the while condition in a do-while loop.

Working of do-while Loop

  1. The loop body executes first.
  2. The condition is evaluated.
  3. If true, the loop body executes again.
  4. If false, the loop terminates.

Example 1: Print Numbers from 1 to 5

#include <iostream> using namespace std; int main() { int i = 1; do { cout << i << endl; i++; } while (i <= 5); return 0; }
Expected Output:
1 2 3 4 5

Example 2: Condition Initially False

#include <iostream> using namespace std; int main() { int i = 10; do { cout << "Loop executed"; i++; } while (i < 5); return 0; }
Expected Output:
Loop executed

Although the condition is false initially, the loop body executes once before the condition is checked.

5. Difference Between for, while and do-while Loops

Feature for Loop while Loop do-while Loop
Condition checking Before execution Before execution After execution
Minimum executions Zero Zero One
Initialization Usually in loop header Usually before loop Usually before loop
Update Usually in loop header Usually inside loop body Usually inside loop body
Typical use Known iteration count Condition-based repetition At least one execution required
Key Difference: The do-while loop checks its condition after executing the body, whereas for and while loops check their conditions before executing the body.

6. Nested Loops

A nested loop is a loop placed inside another loop. The inner loop completes its iterations for every iteration of the outer loop.

Example: Print a Number Pattern

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 3; j++) { cout << j << " "; } cout << endl; } return 0; }
Expected Output:
1 2 3 1 2 3 1 2 3

The outer loop executes three times. For every outer iteration, the inner loop also executes three times.

7. Infinite Loops

An infinite loop is a loop that continues executing because its termination condition never becomes false.

Example: Infinite for Loop

for (;;) { cout << "Running..." << endl; }

Example: Infinite while Loop

while (true) { cout << "Running..." << endl; }
Warning: Infinite loops can prevent a program from terminating. Use them only when continuous execution is intended and provide an appropriate exit mechanism where necessary.

8. Common Loop Mistakes

1. Forgetting to Update the Loop Variable

Incorrect:
int i = 1; while (i <= 5) { cout << i; }
The value of i never changes, so the condition remains true.

2. Incorrect Loop Condition

Using an incorrect comparison operator can cause the loop to execute too many or too few times.

3. Off-by-One Error

An off-by-one error occurs when a loop executes one more or one fewer iteration than intended.

4. Missing Semicolon in do-while

The do-while structure must end with a semicolon after its while condition.

9. Important Points

  • Loops are used to execute statements repeatedly.
  • C++ provides for, while and do-while loops.
  • The for loop is commonly used for a known iteration count.
  • The while loop checks its condition before execution.
  • The do-while loop executes at least once.
  • Nested loops contain one loop inside another.
  • A loop variable must be updated appropriately.
  • An infinite loop continues until it is interrupted or terminated.
  • break and continue can control loop execution.
