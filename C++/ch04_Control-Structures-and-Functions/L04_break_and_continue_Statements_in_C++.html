1. Introduction

C++ provides control statements that allow programmers to change the normal flow of loop execution. Two important statements are break and continue.

  • break: Terminates the nearest enclosing loop or switch statement.
  • continue: Skips the remaining statements in the current loop iteration and proceeds to the next iteration.
Key Difference: break exits the loop, whereas continue skips the current iteration without terminating the loop.

2. break Statement

The break statement is used to immediately terminate the nearest enclosing loop or switch statement. Program execution continues with the statement following that loop or switch.

Syntax

break;

Working of break

  1. The program enters a loop or switch statement.
  2. The break statement is encountered.
  3. The nearest enclosing loop or switch is terminated.
  4. Execution continues after that construct.

Example 1: break in for Loop

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 10; i++) { if (i == 5) { break; } cout << i << endl; } cout << "Loop terminated"; return 0; }
Expected Output:
1 2 3 4 Loop terminated

When i becomes 5, the break statement terminates the loop. Numbers after 4 are not printed.

Example 2: break in while Loop

#include <iostream> using namespace std; int main() { int i = 1; while (i <= 10) { if (i == 6) { break; } cout << i << " "; i++; } return 0; }
Expected Output:
1 2 3 4 5

Example 3: break in switch Statement

#include <iostream> using namespace std; int main() { int choice = 2; switch (choice) { case 1: cout << "One"; break; case 2: cout << "Two"; break; case 3: cout << "Three"; break; default: cout << "Invalid choice"; } return 0; }
Expected Output:
Two

Here, break prevents execution from continuing into the following case labels.

3. continue Statement

The continue statement skips the remaining statements in the current iteration of a loop and moves to the next iteration.

Syntax

continue;

Working of continue

  1. The loop begins its current iteration.
  2. The continue statement is encountered.
  3. The remaining statements in the current iteration are skipped.
  4. Control proceeds to the next iteration according to the loop type.
  5. The loop condition is checked as appropriate.

Example 1: continue in for Loop

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 5; i++) { if (i == 3) { continue; } cout << i << endl; } return 0; }
Expected Output:
1 2 4 5

When i becomes 3, continue skips the cout statement for that iteration. The loop then proceeds with i = 4.

Example 2: continue in while Loop

#include <iostream> using namespace std; int main() { int i = 0; while (i < 5) { i++; if (i == 3) { continue; } cout << i << " "; } return 0; }
Expected Output:
1 2 4 5

The variable is incremented before continue is encountered. Therefore, the loop continues correctly.

Example 3: continue in do-while Loop

#include <iostream> using namespace std; int main() { int i = 0; do { i++; if (i == 3) { continue; } cout << i << " "; } while (i < 5); return 0; }
Expected Output:
1 2 4 5

In a do-while loop, continue transfers control to the condition check at the end of the loop.

4. Difference Between break and continue

Feature break continue
Purpose Terminates the nearest enclosing loop or switch. Skips the current loop iteration.
Loop execution Stops the loop. Allows the loop to continue.
Next execution Continues after the loop or switch. Moves to the next loop iteration.
Use in loops Yes Yes
Use in switch Yes No
Remember: continue applies to loops. It cannot be used to skip a switch case as a standalone switch control statement.

5. break in Nested Loops

When break is used inside a nested loop, it terminates only the nearest enclosing loop. The outer loop continues its execution.

Example

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 5; j++) { if (j == 3) { break; } cout << "i = " << i << ", j = " << j << endl; } } return 0; }
Expected Output:
i = 1, j = 1 i = 1, j = 2 i = 2, j = 1 i = 2, j = 2 i = 3, j = 1 i = 3, j = 2

The inner loop terminates when j becomes 3. The outer loop continues until all its iterations are completed.

6. continue in Nested Loops

When continue is used inside a nested loop, it skips the remaining statements of the current iteration of the nearest enclosing loop.

Example

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 3; j++) { if (j == 2) { continue; } cout << i << " " << j << endl; } } return 0; }
Expected Output:
1 1 1 3 2 1 2 3 3 1 3 3

For each outer iteration, the inner loop skips the iteration where j equals 2.

7. Practical Applications

Applications of break

  • Exiting a loop when a required value is found.
  • Terminating a menu-driven program loop when the user selects Exit.
  • Stopping a search when a matching element is found.
  • Terminating a switch case after executing the selected operation.

Applications of continue

  • Skipping unwanted values during iteration.
  • Processing only even or odd numbers.
  • Ignoring invalid records while processing data.
  • Skipping specific iterations without terminating the loop.

8. Common Mistakes

1. Confusing break and continue

break terminates the nearest enclosing loop, whereas continue skips only the current iteration.

2. Forgetting to Update a while Loop Variable

Incorrect:
int i = 1; while (i <= 5) { if (i == 3) { continue; } cout << i; i++; }
When i becomes 3, continue skips i++, causing the loop to repeat indefinitely.

3. Assuming break Exits All Nested Loops

An ordinary break exits only the nearest enclosing loop or switch, not every enclosing loop.

4. Using continue Outside a Loop

The continue statement must be used inside an iteration statement such as for, while or do-while.

9. Important Points

  • break terminates the nearest enclosing loop or switch.
  • continue skips the remaining statements of the current loop iteration.
  • break can be used in loops and switch statements.
  • continue can be used in for, while and do-while loops.
  • In nested loops, break and continue affect the nearest enclosing loop.
  • In a for loop, continue proceeds to the update expression before the next condition check.
  • In a while loop, continue proceeds to the condition check.
  • In a do-while loop, continue proceeds to the condition check at the end.
