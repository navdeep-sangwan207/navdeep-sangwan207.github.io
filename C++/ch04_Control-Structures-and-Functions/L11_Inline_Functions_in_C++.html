1. Introduction

An inline function is a function declared using the inline keyword. It allows the compiler to consider replacing a function call with the function's body at the point where the function is called.

This can reduce function-call overhead in suitable situations, especially for small and frequently called functions.

Definition: An inline function is a function declared with the inline specifier. The compiler may substitute its body at a call site, but it is not required to do so.
Important: The inline keyword does not guarantee that the compiler will generate inline machine code. The compiler makes the final optimization decision.

2. Why Inline Functions Are Used

A normal function call may involve operations such as passing arguments, transferring control to the function and returning control to the calling code.

For very small functions, this call overhead can be significant compared with the actual work performed by the function. Inline substitution may reduce this overhead.

  • Can reduce function-call overhead.
  • Useful for small and frequently called functions.
  • Can improve performance in suitable cases.
  • Maintains the readability and structure of function-based code.

3. Syntax of Inline Function

The general syntax is:

inline return_type function_name(parameters) { // Function body }

Example:

inline int square(int n) { return n * n; }

The inline keyword appears before the return type. The function accepts an integer and returns its square.

4. Simple Inline Function Program

#include <iostream> using namespace std; inline int square(int n) { return n * n; } int main() { int result; result = square(5); cout << "Square = " << result << endl; return 0; }
Expected Output: 
Square = 25

Program Explanation

  1. The inline keyword declares the function as inline.
  2. The function square() accepts one integer parameter.
  3. It calculates the square of the supplied number.
  4. The function is called with the argument 5.
  5. The returned value is stored in result and displayed.

5. Normal Function vs Inline Function

Normal Function

#include <iostream> using namespace std; int add(int a, int b) { return a + b; } int main() { cout << add(10, 20) << endl; return 0; }

Inline Function

#include <iostream> using namespace std; inline int add(int a, int b) { return a + b; } int main() { cout << add(10, 20) << endl; return 0; }
Expected Output for Both Programs: 
30

Both programs produce the same result. The difference is that the second function is declared with the inline specifier, which makes it eligible for inline substitution.

The presence of inline does not prove that the compiler actually removed the function call. Generated machine code depends on compiler decisions and optimization settings.

6. Inline Function Defined Inside a Class

A member function defined inside a class definition is implicitly an inline function, subject to the normal rules of the C++ language.

#include <iostream> using namespace std; class Calculator { public: int multiply(int a, int b) { return a * b; } }; int main() { Calculator obj; cout << "Product = " << obj.multiply(4, 5) << endl; return 0; }
Expected Output: 
Product = 20

Here, multiply() is defined inside the class definition. It is therefore implicitly declared inline.

7. Inline Function Defined Outside a Class

A member function can also be declared inside a class and defined outside the class using the scope resolution operator.

#include <iostream> using namespace std; class Calculator { public: inline int add(int a, int b); }; int Calculator::add(int a, int b) { return a + b; } int main() { Calculator obj; cout << "Sum = " << obj.add(15, 25) << endl; return 0; }
Expected Output: 
Sum = 40
The inline specifier is included in the declaration inside the class. The definition outside the class does not need to repeat it.

8. Advantages of Inline Functions

  • May reduce function-call overhead for small functions.
  • Can improve execution performance in suitable situations.
  • Provides a function-based alternative to many simple macros.
  • Supports type checking and normal C++ function rules.
  • Can make small operations easier to read and reuse.

9. Disadvantages and Limitations

  • Inline substitution is not guaranteed by the compiler.
  • Large functions may increase generated code size if expanded at many call sites.
  • Excessive code expansion can negatively affect instruction-cache performance.
  • Complex functions may not be suitable candidates for inline substitution.
  • Inline declarations do not automatically make a program faster.
Remember: Do not declare every function inline just to improve performance. Use it where appropriate and rely on compiler optimization and measurement.

10. Inline Functions vs Macros

Inline Function Macro
Processed according to C++ language rules. Processed by the preprocessor.
Supports parameter type checking. Does not provide normal function parameter type checking.
Follows normal function scope and access rules. Uses textual substitution.
Can be overloaded like other functions. Function-like macros cannot be overloaded by parameter types.
Compiler decides whether to inline machine code. Macro expansion occurs during preprocessing.

11. The Inline Specifier and the One Definition Rule

In C++, inline has an important language-level meaning beyond optimization.

An inline function with external or module linkage can have equivalent definitions in multiple translation units, provided the One Definition Rule (ODR) requirements are satisfied. This is useful when defining functions in header files included by multiple source files.

// calculator.h #ifndef CALCULATOR_H #define CALCULATOR_H inline int add(int a, int b) { return a + b; } #endif

The header can be included in multiple source files without causing a multiple-definition error, provided the inline definitions satisfy the ODR requirements.

Important: All definitions of the same externally linked inline function must satisfy the ODR, including having the same token sequence and corresponding name-lookup requirements.

12. Important Points to Remember

  • An inline function is declared using the inline specifier.
  • Inline substitution may reduce function-call overhead.
  • The compiler is not required to perform inline substitution.
  • Small and frequently called functions may be suitable candidates.
  • Functions defined inside a class definition are implicitly inline.
  • Inline functions are type-checked like normal functions.
  • The inline specifier also affects ODR rules across translation units.
  • Inline functions and macros are different language mechanisms.

14. Interview Questions

Q1. What is an inline function?

An inline function is a function declared using the inline specifier. The compiler may substitute its body at the function call site.

Q2. What is the main purpose of an inline function?

It can reduce function-call overhead in suitable cases, especially for small and frequently called functions.

Q3. Is inline substitution guaranteed?

No. The compiler decides whether to perform inline substitution.

Q4. Are functions defined inside a class inline?

Yes. A member function defined inside a class definition is implicitly inline.

Q5. What is the difference between an inline function and a macro?

An inline function follows C++ function rules and supports type checking, while a macro performs preprocessor text substitution.

Q6. Can a large function be declared inline?

Yes. The inline specifier can be used, but the compiler may decide not to substitute the function body at the call site.

Q7. What is the ODR significance of inline?

It permits qualifying inline function definitions to appear in multiple translation units when all One Definition Rule requirements are satisfied.
