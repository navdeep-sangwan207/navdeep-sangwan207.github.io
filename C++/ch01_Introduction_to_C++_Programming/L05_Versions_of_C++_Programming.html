1. Introduction to C++ Versions

C++ is a general-purpose programming language that has evolved continuously since its development in the early 1980s. New versions of C++ introduce additional language features, improvements, standard library facilities and corrections.

These versions are commonly called C++ standards. Each standard defines the language rules and the facilities that a conforming compiler should support.

Example: C++98, C++11, C++14, C++17, C++20 and C++23 are different versions of the C++ language standard.

Why are new versions introduced?

  • To introduce modern programming features.
  • To improve code readability and maintainability.
  • To improve performance and resource management.
  • To support modern hardware and software development.
  • To improve the standard library.
  • To correct defects and clarify language rules.

2. Evolution of C++ Standards

The C++ language has passed through several important stages. The following table shows the major standard milestones.

Version Year Description
Pre-standard C++ Before 1998 Early development and evolution of C++.
C++98 1998 First ISO standard for C++.
C++03 2003 Maintenance and defect corrections to C++98.
C++11 2011 Major update introducing many modern language features.
C++14 2014 Improvements and refinements to C++11.
C++17 2017 Additional language and standard library features.
C++20 2020 Major update including concepts, ranges and modules.
C++23 2023 Further improvements to the language and standard library.
C++26 Under standardization Next major standard generation, with ongoing standardization work.
Note: A standard's year identifies its edition. Compiler support for individual features may arrive gradually. A compiler does not necessarily support every feature of a standard immediately.

3. C++98 and C++03

C++98

C++98 was the first official ISO standard for C++. It established a common specification for the language and its standard library.

Important features and facilities:
  • Classes and objects.
  • Inheritance and polymorphism.
  • Function and operator overloading.
  • Templates.
  • Exception handling.
  • Standard Template Library (STL).
  • Namespaces.

C++03

C++03 was a maintenance update to C++98. It mainly focused on correcting defects, improving consistency and clarifying parts of the existing standard.

Remember: C++03 did not introduce a large collection of new programming features like C++11 did.

4. C++11 - Modern C++ Begins

C++11 was one of the most important updates in the history of C++. It introduced major language and library improvements. It is commonly considered the beginning of modern C++.

Important features of C++11

Feature Purpose
auto Allows the compiler to deduce a variable's type.
nullptr Provides a dedicated null pointer value.
Range-based for loop Simplifies iteration through arrays and containers.
Lambda expressions Allow small anonymous functions.
Smart pointers Help manage dynamically allocated memory.
Move semantics Can avoid unnecessary copying of resources.
Override and final Provide clearer control over virtual functions.
Multithreading support Introduces standard thread and synchronization facilities.

Example: auto keyword

#include <iostream>
using namespace std;

int main()
{
    auto number = 100;
    auto value = 25.5;

    cout << "Number: " << number << endl;
    cout << "Value: " << value << endl;

    return 0;
}
Expected Output: 
Number: 100
Value: 25.5
Explanation: The compiler automatically determines the type of each variable. Here, number is an integer and value is a floating-point value.

Example: Range-based for loop

#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    for (int n : numbers)
    {
        cout << n << " ";
    }

    return 0;
}
Expected Output: 
10 20 30 40 50
Explanation: The range-based for loop accesses each element of the array without requiring a separate index variable.

5. C++14

C++14 was a smaller update that improved and refined features introduced in C++11.

Important features

  • Generic lambda expressions.
  • Return type deduction for ordinary functions.
  • Digit separators in numeric literals.
  • Binary literals.
  • Improved constexpr functionality.
  • Additional standard library improvements.

Example: Binary literals

#include <iostream>
using namespace std;

int main()
{
    int number = 0b1010;

    cout << "Number: " << number;

    return 0;
}
Expected Output: 
Number: 10
Explanation: The prefix 0b represents a binary integer literal. The binary value 1010 is equal to decimal 10.

6. C++17

C++17 introduced several useful language and standard library features that make C++ code more expressive and convenient.

Important features

  • Structured bindings.
  • if constexpr.
  • Inline variables.
  • std::optional.
  • std::variant.
  • std::string_view.
  • Filesystem library.
  • Parallel algorithm support in the standard library.

Example: Structured bindings

#include <iostream>
#include <utility>
using namespace std;

int main()
{
    pair<int, string> student = {101, "Rahul"};

    auto [rollNumber, name] = student;

    cout << "Roll Number: " << rollNumber << endl;
    cout << "Name: " << name << endl;

    return 0;
}
Expected Output: 
Roll Number: 101
Name: Rahul
Explanation: Structured bindings allow multiple variables to be declared from the elements of a pair, tuple or other supported object.

7. C++20

C++20 was another major update. It introduced powerful features that improve generic programming, code organization and data processing.

Important features

  • Concepts.
  • Ranges library.
  • Modules.
  • Coroutines.
  • Three-way comparison operator (<=>).
  • Calendar and time-zone library improvements.
  • Additional constexpr capabilities.

Example: Concepts

#include <iostream>
#include <concepts>
using namespace std;

template <typename T>
requires integral<T>
T add(T a, T b)
{
    return a + b;
}

int main()
{
    cout << add(10, 20);

    return 0;
}
Expected Output: 
30
Explanation: The integral concept restricts the template function to integral types, such as int and long.
Compiler requirement: This example requires a compiler with C++20 support. Select the C++20 standard when compiling it.

8. C++23

C++23 continues the evolution of modern C++. It adds language improvements and useful standard library features.

Important features

  • std::expected for representing a value or an error.
  • std::print and std::println for formatted output.
  • std::ranges improvements.
  • Multidimensional subscript operator support.
  • Additional constexpr improvements.
  • Further standard library enhancements.

Example: std::expected

#include <expected>
#include <iostream>
#include <string>
using namespace std;

expected<int, string> divide(int a, int b)
{
    if (b == 0)
    {
        return unexpected(string("Division by zero"));
    }

    return a / b;
}

int main()
{
    auto result = divide(20, 4);

    if (result)
    {
        cout << "Result: " << *result;
    }
    else
    {
        cout << result.error();
    }

    return 0;
}
Expected Output: 
Result: 5
Explanation: std::expected can hold either a successful result or an error value. It is useful for functions that need to report failure without relying on exceptions.
Compiler requirement: This example requires C++23 library support for std::expected. Check your compiler and standard library versions.

9. C++26 and Future Development

C++26 is the next generation of the C++ standard. Its development includes proposals for new language and library features, along with improvements to existing facilities.

The C++ standardization process is handled through the ISO C++ committee. Proposed features are reviewed, discussed and refined before they become part of a published standard.

Important: A feature proposal is not automatically a feature of the final standard. Always check the published standard and compiler support before using a new feature in a project.

10. Comparison of Major C++ Versions

Standard Major Contribution Importance
C++98 First ISO standard, templates and STL. Established standard C++.
C++03 Defect corrections and clarifications. Improved reliability.
C++11 auto, nullptr, lambdas, smart pointers, threads. Beginning of modern C++.
C++14 Generic lambdas and language refinements. Improved C++11.
C++17 Structured bindings, optional and filesystem. More expressive programming.
C++20 Concepts, ranges, modules and coroutines. Major modern features.
C++23 Expected, print and library improvements. Further modernization.
C++26 Next standard generation. Continued evolution.

11. How to Select a C++ Standard in GCC

GCC allows you to select the C++ language standard using the -std compiler option.

Examples using CMD

g++ -std=c++11 program.cpp -o program
g++ -std=c++14 program.cpp -o program
g++ -std=c++17 program.cpp -o program
g++ -std=c++20 program.cpp -o program
g++ -std=c++23 program.cpp -o program

To execute the compiled program in Windows CMD: 

program.exe
Note: The compiler version and installed standard library determine which features are available. If a feature is not supported, compilation may fail even when the correct -std option is selected.

Check GCC version

g++ --version

Check the selected language standard in a program

#include <iostream>
using namespace std;

int main()
{
    cout << __cplusplus;

    return 0;
}

The __cplusplus predefined macro reports the language standard value used by the compiler. Typical values include:

Standard Typical __cplusplus value
C++98 199711L
C++11 201103L
C++14 201402L
C++17 201703L
C++20 202002L
C++23 202302L
Important: Older GCC versions may report a different value for a newer standard because of incomplete implementation or compiler-specific support.

12. Which C++ Version Should You Learn?

For learning and professional development, it is useful to understand both the fundamentals of C++ and the improvements introduced by modern standards.

  • C++98 fundamentals: Understand classes, objects, pointers, functions and STL basics.
  • C++11: Learn auto, nullptr, range-based loops, lambdas and smart pointers.
  • C++14 and C++17: Explore generic lambdas, structured bindings and standard library improvements.
  • C++20 and C++23: Study concepts, ranges, modules and newer library facilities.
For Embedded Systems and Systems Software: Learn the core language, pointers, memory management, data structures, object-oriented programming and standard library fundamentals. Also understand which C++ features are supported by your target compiler, microcontroller and development environment.
