1. What is Programming?

Programming is the process of writing instructions that tell a computer how to perform a particular task.

These instructions are written using a programming language. A computer follows the instructions to process data and produce the required output.

Example: A calculator program receives two numbers, performs an arithmetic operation and displays the result.

Basic Programming Process

  1. Understand the problem.
  2. Develop a solution or algorithm.
  3. Write the program using a programming language.
  4. Compile and execute the program.
  5. Test and debug the program.
  6. Obtain the required output.

2. What is C++?

C++ is a general-purpose, compiled programming language developed by Bjarne Stroustrup. It was designed as an extension of the C programming language and supports procedural, object-oriented and generic programming.

C++ provides features such as classes, objects, inheritance, polymorphism, templates and the Standard Template Library (STL).

Definition: C++ is a high-performance, general-purpose programming language used to develop system software, embedded applications, desktop applications, games and other performance-critical programs.

Why is C++ Important?

  • It provides efficient execution and control over system resources.
  • It supports object-oriented programming.
  • It provides low-level memory management features.
  • It supports reusable code through functions and classes.
  • It is widely used in software and embedded development.

3. Important Features of C++

Feature Description
Object-Oriented Supports classes, objects, inheritance and polymorphism.
Compiled Language Source code is compiled into executable machine code.
High Performance Provides efficient execution and resource management.
Portable Programs can be adapted to different platforms using suitable compilers.
Memory Management Provides pointers, dynamic memory allocation and other memory-management features.
Generic Programming Supports templates for writing reusable code.
STL Support Provides containers, iterators and algorithms through the Standard Template Library.

4. Applications of C++

C++ is used in many areas where performance, efficiency and control over hardware or system resources are important.

Application Area Examples
Operating Systems System components and performance-critical modules.
Embedded Systems Firmware, device-control applications and embedded software.
Game Development Game engines and real-time graphics applications.
Desktop Software Applications with graphical user interfaces.
Automotive Software Vehicle control and other automotive software components.
Financial Systems Performance-sensitive trading and processing systems.
Scientific Computing Simulation, numerical computation and data processing.
Note: C++ is particularly useful in embedded and systems software when efficient execution and direct resource management are important.

5. C++ Program Development Process

A C++ program generally passes through the following stages before it produces an output.

  1. Source Code: Write instructions in a C++ source file.
  2. Preprocessing: Process directives such as #include.
  3. Compilation: Translate source code into object code.
  4. Linking: Combine object code with required libraries.
  5. Execution: Run the resulting executable program.
Example workflow:

Source Code → Preprocessor → Compiler → Linker → Executable File → Output

A compiler such as GCC or the compiler included with Microsoft Visual Studio can be used to build C++ programs.

6. Structure of a Basic C++ Program

The following example demonstrates a simple C++ program that displays a message on the screen.

Example 1: Hello World Program

#include <iostream>

using namespace std;

int main()
{
    cout << "Hello, World!";

    return 0;
}

Expected Output

Hello, World!

Explanation of the Program

Statement Purpose
#include <iostream> Includes the standard input/output stream library.
using namespace std; Allows standard library names to be used without writing std:: each time.
int main() Defines the main function, where program execution begins.
cout Displays output on the screen.
return 0; Indicates successful program termination.
Important: The main() function is the entry point of a standard hosted C++ program. Execution normally begins from main().

7. Your First C++ Program Using GCC

If GCC is installed on your Windows computer through MSYS2, you can compile and execute a C++ program using the following commands.

Step 1: Create a Source File

Create a file named hello.cpp and write the Hello World program in it.

Step 2: Open CMD or MSYS2 UCRT64 Terminal

Step 3: Compile the Program

g++ -std=c++11 -Wall -Wextra hello.cpp -o hello.exe

Step 4: Execute the Program

hello.exe

Expected Output

Hello, World!
Compiler note: The g++ command compiles C++ source code. The -std=c++11 option selects the C++11 language standard, while -Wall -Wextra enables additional compiler warnings.

8. C++ and C: Basic Difference

Basis C C++
Programming Approach Primarily procedural Procedural, object-oriented and generic
Classes and Objects Not natively supported Supported
Function Overloading Not supported Supported
Templates Not supported Supported
Input/Output Commonly uses printf() and scanf() Commonly uses cout and cin
Remember: C++ is closely related to C, but it adds several programming features and abstractions.
