Key Terms in Programming

Learn the fundamental terminology used in programming and C++.

Home C++ Course Chapter 1

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the basic terminology of programming.
  • Differentiate between source code, object code and executable code.
  • Understand variables, constants and data types.
  • Identify operators, expressions and statements.
  • Understand algorithms, flowcharts and debugging.
  • Recognize the basic components of a C++ program.

1. Program

A program is a set of instructions written in a programming language to perform a specific task.

A program accepts input, processes data and produces output according to the instructions written by the programmer.

Example: A program that adds two numbers takes two values as input, performs addition and displays their sum. 
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 20;

    cout << a + b;

    return 0;
}

Expected Output

30

2. Source Code

Source code is the set of instructions written by a programmer using a programming language such as C++.

C++ source code is generally saved in a file with the .cpp extension.

Example

#include <iostream>
using namespace std;

int main()
{
    cout << "Welcome to C++";
    return 0;
}
Remember: The code written by the programmer before compilation is called source code.

3. Compiler

A compiler is a software tool that translates source code into a lower-level form, such as object code or machine code, so that it can be executed by a computer.

A C++ compiler also checks the program for syntax and other compilation errors.

Examples of C++ Compilers

  • GCC (GNU Compiler Collection)
  • Clang
  • Microsoft Visual C++ Compiler (MSVC)
  • Intel oneAPI DPC++/C++ Compiler
Example: The g++ command in GCC can compile a C++ source file named program.cpp. 
g++ program.cpp -o program.exe
Important: An IDE is not necessarily a compiler. An IDE provides an environment for writing and managing code, and may use a separate compiler to build the program.

4. Object Code

Object code is the output produced by the compiler during compilation. It contains machine-level instructions and related information.

Object files are commonly saved with extensions such as .o on Linux and .obj on Windows toolchains.

Example GCC Command

g++ -c program.cpp -o program.o
Explanation: The -c option compiles the source file without performing the final linking step.

5. Linker

A linker is a tool that combines object files and required libraries to produce the final executable program.

It also resolves references between different parts of a program, such as function definitions located in separate object files.

Basic Build Process

Source Code → Compiler → Object Code → Linker → Executable File 
g++ program.o -o program.exe
Remember: Compilation translates source code. Linking combines the required compiled components to create the final executable.

6. Executable File

An executable file contains a program in a format that the operating system can load and run.

On Windows, executable files commonly use the .exe extension. On Linux, executable files do not require a particular extension.

Example

g++ program.cpp -o program.exe
program.exe

Expected Output

Welcome to C++

7. Algorithm

An algorithm is a finite sequence of well-defined steps used to solve a problem or perform a task.

Example: Algorithm to Add Two Numbers

  1. Start.
  2. Declare two variables A and B.
  3. Read values of A and B.
  4. Calculate SUM = A + B.
  5. Display SUM.
  6. Stop.
Example: If A = 10 and B = 20, then SUM = 10 + 20 = 30.
Important characteristics: An algorithm should have clear steps, a defined input and output where applicable, and should terminate after a finite number of steps.

8. Flowchart

A flowchart is a graphical representation of an algorithm. It uses standard symbols to show the sequence of operations and decisions.

Common Flowchart Symbols

Symbol Name Purpose
Oval Terminator Represents Start or Stop.
Rectangle Process Represents a calculation or instruction.
Parallelogram Input / Output Represents reading input or displaying output.
Diamond Decision Represents a condition with possible branches.
Arrow Flow Line Shows the direction of execution.
Example flow: Start → Read A and B → Calculate SUM → Display SUM → Stop.

9. Variable

A variable is a named storage location used to hold a value that can change during program execution.

Example

int age = 25;

age = 26;

In this example, age is a variable of type int. Its value changes from 25 to 26.

Variable Naming Rules in C++

  • A variable name can contain letters, digits and underscores.
  • A variable name cannot begin with a digit.
  • Spaces are not allowed in variable names.
  • C++ keywords cannot be used as variable names.
  • Variable names are case-sensitive.
Valid Names Invalid Names
studentAge 2student
total_marks total marks
number1 float
_count my-name

10. Constant

A constant is a value that cannot be changed through that constant name after it has been initialized.

In C++, the const keyword is used to declare a constant object.

Example

#include <iostream>
using namespace std;

int main()
{
    const float PI = 3.14159;

    cout << PI;

    return 0;
}

Expected Output

3.14159
Important: Trying to assign a new value to a const variable causes a compilation error.

11. Data Type

A data type specifies the kind of value a variable can store and the operations that can be performed on that value.

Common Built-in Data Types in C++

Data Type Purpose Example
int Stores integer values. int age = 25;
float Stores single-precision floating-point values. float price = 10.5f;
double Stores double-precision floating-point values. double pi = 3.14159;
char Stores a character. char grade = 'A';
bool Stores true or false. bool isValid = true;
void Represents the absence of a value or type. void display();
Note: The exact storage size of some built-in types can depend on the compiler and target platform. Use sizeof() to check the size on your system.

12. Operator

An operator is a symbol that performs an operation on one or more operands.

Types of Operators

Operator Type Operators Purpose
Arithmetic +, -, *, /, % Performs mathematical operations.
Relational ==, !=, >, <, >=, <= Compares two values.
Logical &&, ||, ! Combines or reverses conditions.
Assignment =, +=, -=, *=, /= Assigns or updates a value.
Increment / Decrement ++, -- Increases or decreases a value by one.

Example

#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 5;

    cout << "Addition: " << a + b << endl;
    cout << "Subtraction: " << a - b << endl;
    cout << "Multiplication: " << a * b << endl;

    return 0;
}

Expected Output

Addition: 15
Subtraction: 5
Multiplication: 50

13. Expression and Statement

Expression

An expression is a combination of values, variables and operators that produces a value. 

a + b
x * 10
marks / 2

Statement

A statement is a complete instruction that performs an action in a program. 

int a = 10;
cout << a;
return 0;
Difference: An expression produces a value, while a statement represents an instruction. An expression can also form part of a statement.

14. Syntax and Syntax Error

Syntax refers to the rules that define how statements must be written in a programming language.

A syntax error occurs when the program violates the language's grammar rules.

Example of a Syntax Error

int main()
{
    cout << "Hello"
    return 0;
}

The output statement is missing a semicolon. The compiler will report an error.

Correct Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello";
    return 0;
}

Expected Output

Hello

15. Debugging

Debugging is the process of identifying, analyzing and correcting errors or defects in a program.

Common Types of Programming Errors

Error Type Description Example
Syntax Error Violation of language grammar rules. Missing semicolon.
Runtime Error An error that occurs while the program is running. Invalid memory access.
Logical Error The program runs but produces an incorrect result. Using subtraction instead of addition.
Debugging tools: Debuggers allow programmers to set breakpoints, execute code step by step, inspect variables and examine program behavior.

16. IDE (Integrated Development Environment)

An IDE is a software application that provides tools for writing, editing, building and debugging programs.

Common C++ IDEs and Development Tools

  • Visual Studio
  • Visual Studio Code with a suitable compiler and extensions
  • Code::Blocks
  • CLion
  • Dev-C++
  • Qt Creator
Remember: An IDE may include a compiler or use an externally installed compiler. Visual Studio Code, for example, is an editor that can be configured as a C++ development environment.
