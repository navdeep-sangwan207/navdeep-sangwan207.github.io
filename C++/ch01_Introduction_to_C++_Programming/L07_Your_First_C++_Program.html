1. Introduction

A computer program is a set of instructions that tells a computer what tasks to perform.

C++ programs are written using the syntax and rules of the C++ programming language. The source code is processed by a compiler to generate an executable program that can run on a computer.

Example: A simple C++ program can display a message, accept numbers from the user, perform calculations and display the result.

Basic steps in C++ programming

  1. Write the source code.
  2. Save the source file with the .cpp extension.
  3. Compile the source code.
  4. Correct any compilation errors.
  5. Execute the generated program.
  6. Check the output.

2. Your First C++ Program - Hello World

The Hello World program is traditionally the first program written when learning a new programming language.

Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!";

    return 0;
}

Expected Output

Hello World!
Explanation: This program displays the text "Hello World!" on the output screen and then terminates successfully.

3. Understanding the Structure of a C++ Program

Every C++ program follows a defined syntax. The following table explains the main components of the Hello World program.

Statement Purpose
#include <iostream> Includes the standard input/output stream declarations.
using namespace std; Allows standard library names to be used without writing std:: each time.
int main() Defines the main function, where program execution begins.
{ } Marks the beginning and end of a block of code.
cout Displays output on the standard output stream.
<< Insertion operator used with output streams.
return 0; Indicates successful termination of the program.
; Terminates a statement in C++.

3.1 Header File

#include <iostream>

The iostream header provides declarations for standard input and output stream objects such as cin and cout.

3.2 Namespace

using namespace std;

The standard library uses the namespace std. This statement allows us to write cout instead of std::cout.

Note: In larger projects, using std::cout explicitly can help avoid naming conflicts. Both styles are valid.

3.3 Main Function

int main()
{
    // Program statements
}

The main() function is the entry point of a standard C++ program. Execution begins here.

3.4 Return Statement

return 0;

Returning zero from main() indicates successful program termination to the operating system.

4. Displaying Output Using cout

The cout object is used to display information on the standard output stream.

Example 1: Display a message

#include <iostream>
using namespace std;

int main()
{
    cout << "Welcome to NS Learning Hub!";

    return 0;
}
Expected Output: 
Welcome to NS Learning Hub!

Example 2: Display multiple lines

#include <iostream>
using namespace std;

int main()
{
    cout << "Name: Rahul" << endl;
    cout << "Course: C++ Programming" << endl;
    cout << "Chapter: Introduction";

    return 0;
}
Expected Output: 
Name: Rahul
Course: C++ Programming
Chapter: Introduction

3. Using endl

endl inserts a newline into the output stream and flushes the stream.

4. Using the newline character

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello\n";
    cout << "Welcome to C++";

    return 0;
}
Expected Output: 
Hello
Welcome to C++
Difference: \n inserts a newline character. endl inserts a newline and flushes the output stream.

5. Taking Input Using cin

The cin object is used to receive input from the keyboard through the standard input stream.

Example: Read a number

#include <iostream>
using namespace std;

int main()
{
    int number;

    cout << "Enter a number: ";
    cin >> number;

    cout << "You entered: " << number;

    return 0;
}
Sample Output: 
Enter a number: 25
You entered: 25
Explanation:
  • int number; declares an integer variable.
  • cin >> number; reads input from the keyboard.
  • cout displays the entered value.

6. Variables and Data Types

A variable is a named memory location used to store data during program execution.

Basic C++ data types

Data Type Purpose Example
int Stores integer values. int age = 25;
float Stores single-precision floating-point values. float price = 25.5f;
double Stores double-precision floating-point values. double pi = 3.14159;
char Stores a character. char grade = 'A';
bool Stores true or false. bool status = true;
string Stores text. string name = "Rahul";

Example: Variables and data types

#include <iostream>
#include <string>
using namespace std;

int main()
{
    int age = 25;
    float temperature = 36.5f;
    double salary = 25000.75;
    char grade = 'A';
    bool status = true;
    string name = "Rahul";

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Temperature: " << temperature << endl;
    cout << "Salary: " << salary << endl;
    cout << "Grade: " << grade << endl;
    cout << "Status: " << status << endl;

    return 0;
}
Expected Output: 
Name: Rahul
Age: 25
Temperature: 36.5
Salary: 25000.8
Grade: A
Status: 1

The displayed decimal precision may vary. A Boolean value is displayed as 1 for true and 0 for false by default.

Note: The string type is provided by the <string> header.

7. Performing Basic Arithmetic Operations

C++ supports arithmetic operators that allow programs to perform mathematical calculations.

Operator Operation Example
+ Addition 10 + 5 = 15
- Subtraction 10 - 5 = 5
* Multiplication 10 * 5 = 50
/ Division 10 / 5 = 2
% Modulus (remainder) 10 % 3 = 1

Example: Arithmetic calculator

#include <iostream>
using namespace std;

int main()
{
    int a = 20;
    int b = 5;

    cout << "Addition: " << a + b << endl;
    cout << "Subtraction: " << a - b << endl;
    cout << "Multiplication: " << a * b << endl;
    cout << "Division: " << a / b << endl;
    cout << "Modulus: " << a % b << endl;

    return 0;
}
Expected Output: 
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4
Modulus: 0
Important: Integer division discards the fractional part. For example, 5 / 2 produces 2 when both operands are integers.

8. Comments in C++

Comments are notes written inside source code to explain the program. The compiler ignores comments during compilation.

Single-line comment

// This is a single-line comment

Multi-line comment

/*
   This is a multi-line comment.
   It can span multiple lines.
*/

Example

#include <iostream>
using namespace std;

int main()
{
    // Display a message
    cout << "Learning C++";

    /*
       Program execution
       ends successfully.
    */
    return 0;
}
Expected Output: 
Learning C++

9. Compilation and Execution Process

A C++ source file must be compiled before the generated executable can be run.

Basic development workflow

Step 1: Write the source code

Create a file named hello.cpp.

Step 2: Open CMD

Open Command Prompt and navigate to the folder containing the file.

Step 3: Compile the program 
g++ hello.cpp -o hello.exe
Step 4: Execute the program 
hello.exe
Step 5: Check the output

Verify that the expected message appears in the terminal.

Compilation stages

  1. Preprocessing: Processes directives such as #include and macros.
  2. Compilation: Translates the processed source into assembly or an equivalent intermediate representation.
  3. Assembly: Produces object code.
  4. Linking: Combines object code and required libraries to produce the executable.
Important: The exact internal implementation may vary by compiler, but preprocessing, compilation, assembly and linking describe the traditional GCC toolchain workflow.

10. Common Errors in C++ Programming

Beginners often encounter errors while writing and compiling their first programs. Understanding common errors makes troubleshooting easier.

Error Possible Cause Solution
Missing semicolon Statement does not end with a semicolon. Add ; where required.
Undefined reference to main Missing or incorrectly named main function. Check the main() function.
iostream not found Compiler installation or include path problem. Check compiler configuration.
cout was not declared Missing namespace qualification or declaration. Use std::cout or an appropriate namespace declaration.
Expected expression Invalid syntax or missing expression. Check the statement and operators.
File not found Incorrect filename or working directory. Check the source file path.

Example: Program with an error

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!"

    return 0;
}

The output statement is missing a semicolon.

Corrected program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!";

    return 0;
}
Expected Output: 
Hello World!

Lab 2: Add Two Numbers

Objective: Accept two integers and display their sum.

#include <iostream>
using namespace std;

int main()
{
    int a, b, sum;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter second number: ";
    cin >> b;

    sum = a + b;

    cout << "Sum = " << sum;

    return 0;
}
Sample Output: 
Enter first number: 10
Enter second number: 20
Sum = 30

Lab 3: Calculate Area of a Rectangle

Objective: Calculate the area using length and breadth.

#include <iostream>
using namespace std;

int main()
{
    float length, breadth, area;

    cout << "Enter length: ";
    cin >> length;

    cout << "Enter breadth: ";
    cin >> breadth;

    area = length * breadth;

    cout << "Area = " << area;

    return 0;
}
Sample Output: 
Enter length: 10
Enter breadth: 5
Area = 50

Lab 4: Swap Two Numbers Using a Temporary Variable

Objective: Exchange the values of two variables.

#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 20;
    int temp;

    cout << "Before swapping: " << a << " " << b << endl;

    temp = a;
    a = b;
    b = temp;

    cout << "After swapping: " << a << " " << b;

    return 0;
}
Expected Output: 
Before swapping: 10 20
After swapping: 20 10

Lab 5: Check Even or Odd

Objective: Determine whether a number is even or odd.

#include <iostream>
using namespace std;

int main()
{
    int number;

    cout << "Enter a number: ";
    cin >> number;

    if (number % 2 == 0)
    {
        cout << "Even number";
    }
    else
    {
        cout << "Odd number";
    }

    return 0;
}
Sample Output: 
Enter a number: 12
Even number
