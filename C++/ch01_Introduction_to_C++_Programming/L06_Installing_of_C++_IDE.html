1. What Is an IDE?

IDE stands for Integrated Development Environment. It is a software application that provides tools for writing, compiling, debugging and managing programs.

An IDE combines several development tools into a single working environment, making software development easier.

Common components of an IDE

  • Code Editor: Used to write and edit source code.
  • Compiler: Translates source code into machine code or another executable form.
  • Debugger: Helps identify and fix errors in a program.
  • Build Tools: Automate compilation and linking.
  • Terminal: Allows commands to be executed.
  • Project Explorer: Helps organize source files and project folders.
Example: Visual Studio, Code::Blocks and Dev-C++ are examples of C++ development environments. Visual Studio Code is primarily a code editor that can be configured with external compilers and debugging tools.

2. Difference Between IDE, Editor and Compiler

Term Meaning Example
Code Editor Software used to write and edit source code. Visual Studio Code
Compiler Translates source code into executable machine code or object code. GCC / G++
IDE Combines editing, building and debugging tools. Visual Studio
Debugger Helps inspect program execution and locate errors. GDB
Important: Installing a code editor alone does not necessarily install a C++ compiler. You need a compiler such as GCC/G++ or MSVC to build C++ programs.

4. Understanding GCC and G++

GCC stands for GNU Compiler Collection. It supports several programming languages, including C and C++.

G++ is the C++ compiler driver provided by GCC. It is commonly used to compile C++ source files.

Important commands

Command Purpose
gcc Compiler driver commonly used for C programs.
g++ Compiler driver commonly used for C++ programs.
gdb GNU debugger.
make Build automation tool.

Check whether G++ is installed

Open Windows Command Prompt and execute:

g++ --version

If the compiler is installed and configured correctly, the command displays the installed G++ version.

Example Output: 
g++ (RevX, Built by MSYS2 project) ...
Copyright (C) Free Software Foundation, Inc.

The exact version information depends on your installation.

5. Installing GCC/G++ Using MSYS2 on Windows

MSYS2 provides a development environment for Windows. It includes package management and access to tools such as GCC, G++, GDB and Make.

In this lesson, we use the UCRT64 environment to install and configure the GCC toolchain.

Step 1: Download MSYS2

Action:
  1. Open your web browser.
  2. Visit the official MSYS2 website.
  3. Download the Windows installer.

Official website: https://www.msys2.org/

Step 2: Install MSYS2

Action:
  1. Run the downloaded installer.
  2. Follow the installation instructions.
  3. Use the default installation location unless you have a specific reason to change it.
  4. Complete the installation.

Step 3: Open MSYS2 UCRT64

Action:
  1. Open the Windows Start menu.
  2. Search for MSYS2 UCRT64.
  3. Open the UCRT64 terminal.
Important: UCRT64 and MINGW64 are different MSYS2 environments. Use the UCRT64 environment consistently for the toolchain installed in this lesson.

Step 4: Update MSYS2

Execute the following command in the MSYS2 terminal:

pacman -Syu

If the terminal asks you to close it after updating, close it, reopen MSYS2 UCRT64 and run the update command again if instructed.

Step 5: Install GCC and G++

In the MSYS2 UCRT64 terminal, execute: 

pacman -S --needed base-devel mingw-w64-ucrt-x86_64-gcc

This installs the GCC toolchain and development utilities for the UCRT64 environment.

Step 6: Verify the compiler inside MSYS2

gcc --version
g++ --version
Expected Result:

Both commands should display compiler version information if installation is successful.

Step 7: Add the compiler to Windows PATH

To use G++ from Windows Command Prompt, add the UCRT64 binary directory to the Windows PATH variable. 

C:\msys64\ucrt64\bin
Windows configuration steps:
  1. Open the Windows Start menu.
  2. Search for Edit the system environment variables.
  3. Open the System Properties window.
  4. Click Environment Variables.
  5. Under User variables, select Path.
  6. Click Edit, then New.
  7. Add C:\msys64\ucrt64\bin.
  8. Click OK to save the changes.
  9. Close and reopen Command Prompt.
Warning: Add the exact directory where your MSYS2 UCRT64 compiler is installed. Do not replace the existing PATH entries.

Step 8: Test G++ in Windows CMD

g++ --version

If the version information appears, Windows can locate the compiler through PATH.

6. Installing Visual Studio Code

Visual Studio Code (VS Code) is a lightweight source code editor. It supports C++ development through extensions and an external compiler.

Step 1: Download VS Code

Visit the official website: https://code.visualstudio.com/

Action:
  1. Download the Windows installer.
  2. Run the installer.
  3. Follow the installation instructions.
  4. Open Visual Studio Code.

Step 2: Install the C/C++ Extension

Action:
  1. Open VS Code.
  2. Click the Extensions icon on the left sidebar.
  3. Search for C/C++.
  4. Install the Microsoft C/C++ extension.
Purpose of the extension: It provides features such as syntax highlighting, IntelliSense, code navigation and debugging integration. It does not install GCC/G++ automatically.

Step 3: Create a C++ project folder

Action:
  1. Create a folder named CPP_Practice.
  2. Open VS Code.
  3. Select File → Open Folder.
  4. Select the CPP_Practice folder.

Step 4: Create a C++ source file

Create a new file named: 

main.cpp

Enter the following program: 

#include <iostream>
using namespace std;

int main()
{
    cout << "Welcome to C++ Programming!";

    return 0;
}

Step 5: Compile the program

Open the integrated terminal in VS Code:

Terminal → New Terminal

Execute:

g++ -std=c++17 -Wall -Wextra main.cpp -o main

Step 6: Execute the program

In the VS Code terminal, execute:

.\main.exe
Expected Output: 
Welcome to C++ Programming!
Explanation:
  • g++ invokes the C++ compiler.
  • -std=c++17 selects the C++17 language standard.
  • -Wall enables many common warnings.
  • -Wextra enables additional warnings.
  • main.cpp is the source file.
  • -o main names the output executable main.exe on Windows.

7. Other C++ Development Environments

A. Visual Studio

Microsoft Visual Studio is a full-featured IDE. It includes the MSVC compiler, debugger, project management and other development tools.

Official website: https://visualstudio.microsoft.com/

B. Code::Blocks

Code::Blocks is an IDE designed for C, C++ and Fortran. It can work with GCC and other configured compilers.

Official website: https://www.codeblocks.org/

C. Dev-C++

Dev-C++ is a simple IDE used for learning and writing C and C++ programs. Some distributions include a bundled MinGW compiler.

Note: Some older Dev-C++ distributions bundle outdated compilers. For modern C++ standards, verify the compiler version and supported features.

D. CLion

CLion is a professional C and C++ IDE from JetBrains. It provides code analysis, navigation, refactoring and debugging tools.

Official website: https://www.jetbrains.com/clion/

8. Installing and Configuring a Compiler Is Not the Same as Installing an IDE

A compiler and an IDE perform different roles. You can compile a C++ program without installing a full IDE if you have a compiler and terminal.

Example: Compile using Windows CMD

Suppose your source file is named hello.cpp.

g++ hello.cpp -o hello.exe

Execute the compiled program:

hello.exe
Expected Output: 
Hello World!

Example source code

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!";

    return 0;
}
Remember: The source file is compiled first. The resulting executable is then run by the operating system.

9. Common Installation and Compilation Errors

Error Possible Cause Solution
g++ is not recognized Compiler directory is not in PATH. Check and configure the compiler PATH.
iostream: No such file or directory Compiler installation or include configuration problem. Verify the compiler installation and toolchain.
undefined reference to main Missing or incorrectly defined main function. Check the source code and function name.
Permission denied Executable may be running or access is restricted. Close the running program and check file permissions.
Compilation failed Syntax or compilation errors. Read the compiler error message and correct the code.
Unsupported C++ feature Compiler or standard library is too old. Update the compiler and check standard support.

10. C++ Development Environment for Embedded Systems

Embedded Systems development may require specialized IDEs, compilers, debuggers and hardware tools. A general-purpose C++ IDE is not always sufficient.

Tool Purpose
Keil uVision Embedded C/C++ development for supported microcontrollers.
GCC / G++ General-purpose C and C++ compilation.
ARM GNU Toolchain Compilation for supported ARM targets.
Visual Studio Code Source code editing and development workflow.
GDB Debugging supported target programs.
For LPC2129 development: Keil uVision is an appropriate environment for working with the LPC2129 using its supported ARM7 toolchain. The compiler and project configuration must match the target microcontroller.
Important distinction: A desktop GCC compiler installed through MSYS2 produces programs for Windows. It does not automatically produce executable firmware for the LPC2129. Embedded development requires a suitable cross-compiler and target configuration.

11. Practical Lab Exercise

Objective

Install or verify a C++ compiler and successfully compile and execute a basic C++ program.

Requirements

  • Windows computer.
  • GCC/G++ compiler.
  • Windows CMD or VS Code terminal.
  • Text editor or IDE.

Program: Basic Calculator

#include <iostream>
using namespace std;

int main()
{
    int a, b;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter second number: ";
    cin >> b;

    cout << "Addition: " << a + b << endl;
    cout << "Subtraction: " << a - b << endl;
    cout << "Multiplication: " << a * b << endl;

    if (b != 0)
    {
        cout << "Division: "
             << static_cast<double>(a) / b << endl;
    }
    else
    {
        cout << "Division is not possible." << endl;
    }

    return 0;
}

Compilation Command

g++ -std=c++17 -Wall -Wextra calculator.cpp -o calculator.exe

Execution Command

calculator.exe
Sample Output: 
Enter first number: 20
Enter second number: 5
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4

Expected Result

The program should compile successfully and perform addition, subtraction, multiplication and division for the entered numbers.
