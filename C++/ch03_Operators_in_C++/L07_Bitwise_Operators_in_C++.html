1. Introduction to Bitwise Operators

Bitwise operators in C++ perform operations directly on the individual bits of integer values. Computers represent integer values internally using binary digits (0 and 1).

These operators compare or manipulate corresponding bits of two operands, or modify the bits of a single operand.

Example: Decimal number 5 is represented in binary as 0101, and decimal number 3 is represented as 0011 (using four bits for illustration).

Bitwise operators are useful in embedded systems, device registers, low-level programming, hardware control and performance-sensitive applications.

2. Types of Bitwise Operators

Operator Name Operation
& Bitwise AND Sets a bit to 1 when both corresponding bits are 1.
| Bitwise OR Sets a bit to 1 when at least one corresponding bit is 1.
^ Bitwise XOR Sets a bit to 1 when corresponding bits are different.
~ Bitwise NOT Inverts every bit of the operand.
<< Left Shift Shifts bits towards the left.
>> Right Shift Shifts bits towards the right.

4. Bitwise AND Operator ( & )

The bitwise AND operator compares each corresponding bit of two operands. The result bit is 1 only when both input bits are 1.

Truth Table

A B A & B
000
010
100
111

Example

#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 3;

    cout << "Result: " << (a & b);

    return 0;
}

Binary calculation:

    0101    (5)
&   0011    (3)
------------
    0001    (1)
Output: 
Result: 1

5. Bitwise OR Operator ( | )

The bitwise OR operator compares corresponding bits. The result bit is 1 if at least one of the input bits is 1.

Truth Table

A B A | B
000
011
101
111

Example

#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 3;

    cout << "Result: " << (a | b);

    return 0;
}

Binary calculation:

    0101    (5)
|   0011    (3)
------------
    0111    (7)
Output: 
Result: 7

6. Bitwise XOR Operator ( ^ )

XOR stands for Exclusive OR. The bitwise XOR operator produces 1 when the corresponding bits are different. It produces 0 when they are the same.

Truth Table

A B A ^ B
000
011
101
110

Example

#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 3;

    cout << "Result: " << (a ^ b);

    return 0;
}

Binary calculation:

    0101    (5)
^   0011    (3)
------------
    0110    (6)
Output: 
Result: 6

7. Bitwise NOT Operator ( ~ )

The bitwise NOT operator inverts every bit of an operand. Each 0 becomes 1, and each 1 becomes 0.

Illustration using four bits:

    0101
~   ----
    1010

Example Program

#include <iostream>
using namespace std;

int main()
{
    unsigned int a = 5;

    cout << "Result: " << (~a);

    return 0;
}
Output on a typical 32-bit unsigned int system: 
Result: 4294967290
Important: The actual result of bitwise NOT depends on the width of the integer type. For an unsigned integer, all bits are inverted. The four-bit illustration is not the complete representation of a typical C++ unsigned int.

9. Applications of Bitwise Operators

  • Embedded Systems: Setting, clearing and checking hardware register bits.
  • Bit Masking: Selecting specific bits from an integer value.
  • Hardware Control: Configuring individual control and status bits.
  • Permissions and Flags: Storing multiple Boolean flags in a single integer.
  • Low-Level Programming: Manipulating binary data directly.
Embedded Systems Example: Bitwise operators are frequently used to set or clear individual bits in microcontroller registers. This is important when configuring GPIO pins, timers and peripherals.

10. Difference Between Logical and Bitwise Operators

Logical Operators Bitwise Operators
Operate on logical conditions. Operate on individual bits.
Examples: &&, ||, ! Examples: &, |, ^, ~
Used in decision-making. Used in bit manipulation.
Logical expressions produce Boolean results. Bitwise expressions produce integer results.

11. Common Interview Questions

Q1. What are bitwise operators?

Bitwise operators perform operations on individual bits of integer values.

Q2. What is the difference between AND and OR?

Bitwise AND produces 1 only when both corresponding bits are 1. Bitwise OR produces 1 when at least one corresponding bit is 1.

Q3. What is the XOR operator?

XOR produces 1 when corresponding bits are different and 0 when they are the same.

Q4. What does the NOT operator do?

It inverts every bit of an operand.

Q5. Where are bitwise operators used in embedded systems?

They are used for register configuration, bit masking, setting bits, clearing bits and checking hardware flags.

Q6. What is bit masking?

Bit masking is a technique used to select or modify specific bits using a mask and bitwise operators.

13. Lesson Summary

Bitwise operators allow C++ programmers to manipulate individual bits of integer values. The main operators are AND (&), OR (|), XOR (^), NOT (~), left shift (<<) and right shift (>>).

These operators are particularly important in embedded systems and low-level programming, where direct manipulation of bits is frequently required.
