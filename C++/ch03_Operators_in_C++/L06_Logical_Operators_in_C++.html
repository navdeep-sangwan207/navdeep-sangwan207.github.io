1. Introduction to Logical Operators

Logical operators in C++ are used to combine two or more conditions or to reverse the result of a condition. They are commonly used in decision-making statements such as if, if-else, and while.

Logical expressions produce a Boolean result: true (1) or false (0).

Example: A student can receive a certificate if their attendance is at least 75% AND their marks are at least 40%.

2. Types of Logical Operators

C++ provides three main logical operators:

Operator Name Description
&& Logical AND Returns true when both conditions are true.
|| Logical OR Returns true when at least one condition is true.
! Logical NOT Reverses the Boolean result of a condition.

3. Logical AND Operator ( && )

The logical AND operator returns true only when both conditions are true. If either condition is false, the result is false.

Truth Table

Condition A Condition B A && B
0 (False) 0 (False) 0 (False)
0 (False) 1 (True) 0 (False)
1 (True) 0 (False) 0 (False)
1 (True) 1 (True) 1 (True)

Example Program

#include <iostream>
using namespace std;

int main()
{
    int age = 25;
    int salary = 30000;

    if (age >= 18 && salary >= 20000)
    {
        cout << "Eligible";
    }
    else
    {
        cout << "Not Eligible";
    }

    return 0;
}
Output: 
Eligible

Both conditions are true, so the complete logical AND expression evaluates to true.

4. Logical OR Operator ( || )

The logical OR operator returns true when at least one condition is true. It returns false only when both conditions are false.

Truth Table

Condition A Condition B A || B
0 (False) 0 (False) 0 (False)
0 (False) 1 (True) 1 (True)
1 (True) 0 (False) 1 (True)
1 (True) 1 (True) 1 (True)

Example Program

#include <iostream>
using namespace std;

int main()
{
    int marks = 85;

    if (marks < 40 || marks > 80)
    {
        cout << "Condition satisfied";
    }
    else
    {
        cout << "Condition not satisfied";
    }

    return 0;
}
Output: 
Condition satisfied

The first condition is false, but the second condition is true. Therefore, the OR expression evaluates to true.

5. Logical NOT Operator ( ! )

The logical NOT operator reverses the result of a condition. If the condition is true, NOT makes it false. If the condition is false, NOT makes it true.

Truth Table

Condition A !A
0 (False) 1 (True)
1 (True) 0 (False)

Example Program

#include <iostream>
using namespace std;

int main()
{
    bool isRaining = false;

    if (!isRaining)
    {
        cout << "You can go outside";
    }
    else
    {
        cout << "Stay indoors";
    }

    return 0;
}
Output: 
You can go outside

Since isRaining is false, the expression !isRaining becomes true.

6. Combining Multiple Logical Operators

Multiple logical operators can be used together to evaluate complex conditions. Parentheses can be used to make the intended order of evaluation clear.

Example Program

#include <iostream>
using namespace std;

int main()
{
    int age = 22;
    int marks = 75;
    bool hasCertificate = true;

    if ((age >= 18 && marks >= 60) || hasCertificate)
    {
        cout << "Eligible for application";
    }
    else
    {
        cout << "Not eligible";
    }

    return 0;
}
Output: 
Eligible for application

The first grouped condition is true because both age and marks satisfy their requirements. The complete OR expression is therefore true.

7. Short-Circuit Evaluation

C++ uses short-circuit evaluation with logical AND and OR. This means the second condition may not be evaluated when the first condition already determines the final result.

For Logical AND ( && )

If the first condition is false, the second condition is not evaluated because the complete AND expression must be false. 

#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 0;

    if (b != 0 && a / b > 2)
    {
        cout << "Condition is true";
    }
    else
    {
        cout << "Condition is false";
    }

    return 0;
}
Output: 
Condition is false
The first condition b != 0 is false. Therefore, a / b is not evaluated. This avoids division by zero in this expression.

For Logical OR ( || )

If the first condition is true, the second condition is not evaluated because the complete OR expression must already be true. 

#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 0;

    if (a > 5 || b != 0)
    {
        cout << "At least one condition is true";
    }

    return 0;
}
Output: 
At least one condition is true
Remember:
  • AND skips the second condition when the first is false.
  • OR skips the second condition when the first is true.

8. Difference Between Logical AND and Bitwise AND

Logical AND (&&) and bitwise AND (&) are different operators. Logical AND evaluates conditions, whereas bitwise AND operates on individual bits of integer values.

Logical AND (&&) Bitwise AND (&)
Works with logical conditions. Works on individual bits.
Produces a Boolean result. Produces an integer bitwise result.
Uses short-circuit evaluation. Does not use logical short-circuit evaluation.
Do not confuse && with &, or || with |. They perform different operations.

9. Important Points

  • C++ provides three logical operators: AND, OR and NOT.
  • Logical AND is represented by &&.
  • Logical OR is represented by ||.
  • Logical NOT is represented by !.
  • Logical expressions produce true or false results.
  • Logical operators are frequently used in decision-making.
  • AND and OR use short-circuit evaluation.
  • Parentheses help make complex expressions easier to understand.

10. Common Interview Questions

Q1. What are logical operators in C++?

Logical operators combine conditions or reverse a condition's Boolean result. They include AND, OR and NOT.

Q2. What is the difference between AND and OR?

AND returns true only when both conditions are true. OR returns true when at least one condition is true.

Q3. What is the purpose of the NOT operator?

NOT reverses a Boolean result. True becomes false and false becomes true.

Q4. What is short-circuit evaluation?

It is a feature in which the second condition is skipped if the first condition already determines the result of a logical AND or OR expression.

Q5. What is the difference between && and &?

&& is logical AND and operates on conditions. & is bitwise AND and operates on individual bits.

Q6. What is the result of !true?

The result is false because the NOT operator reverses the Boolean value.

11. Practice Exercises

  1. Write a C++ program to check whether a number is between 10 and 100 using logical AND.
  2. Write a program to check whether a number is divisible by 3 or 5 using logical OR.
  3. Write a program using logical NOT to check whether a number is not equal to zero.
  4. Write a program to check whether a student has passed both Mathematics and Science.
  5. Predict the output of the following expression.
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 20;

    cout << (a < 15 && b > 15) << endl;
    cout << (a > 15 || b > 15) << endl;
    cout << !(a == 10) << endl;

    return 0;
}
Expected Output: 
1
1
0

12. Lesson Summary

Logical operators are essential for building conditions and controlling program execution in C++. The three operators are AND (&&), OR (||) and NOT (!).

Understanding their truth tables, short-circuit evaluation and practical use in conditional statements is important for writing effective C++ programs.
