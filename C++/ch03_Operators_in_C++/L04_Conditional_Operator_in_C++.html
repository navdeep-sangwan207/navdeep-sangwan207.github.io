1. Introduction to Conditional Operator

The conditional operator in C++ is also known as the ternary operator because it uses three operands.

It is used to make decisions based on a condition. Depending on whether the condition is true or false, one of two expressions is selected.

Operator symbol: ? :
Type: Ternary operator
Purpose: Selects one of two expressions based on a condition.

2. Syntax of Conditional Operator

The general syntax is:

condition ? expression1 : expression2;
Part Description
condition An expression evaluated as true or false.
? Separates the condition from the true expression.
expression1 Selected when the condition is true.
: Separates the true and false expressions.
expression2 Selected when the condition is false.
Only one of the two result expressions is evaluated: expression1 when the condition is true, or expression2 when the condition is false.

3. Simple Example of Conditional Operator

The following program checks whether a number is positive or not using the conditional operator.

Example Program

#include <iostream> using namespace std; int main() { int num = 10; (num > 0) ? cout << "Positive number" : cout << "Not a positive number"; return 0; }

Expected Output

Positive number

Explanation:

  • The variable num contains 10.
  • The condition num > 0 is evaluated.
  • Since the condition is true, the first expression is executed.
  • The message "Positive number" is displayed.

4. Conditional Operator with Assignment

The conditional operator can also be used to assign a value to a variable based on a condition.

Example Program: Find the Greater Number

#include <iostream> using namespace std; int main() { int a = 25, b = 40; int greater; greater = (a > b) ? a : b; cout << "Greater number = " << greater; return 0; }

Expected Output

Greater number = 40

Explanation:

  • Two integer variables a and b are declared.
  • The condition a > b is checked.
  • If true, a is selected; otherwise, b is selected.
  • The selected value is assigned to greater.

5. Check Even or Odd Using Conditional Operator

The modulus operator (%) can be combined with the conditional operator to check whether a number is even or odd.

Example Program

#include <iostream> using namespace std; int main() { int num = 7; (num % 2 == 0) ? cout << "Even number" : cout << "Odd number"; return 0; }

Expected Output

Odd number

Explanation:

  • The modulus operator calculates the remainder when num is divided by 2.
  • If the remainder is 0, the number is even.
  • Otherwise, the number is odd.

6. Nested Conditional Operator

A conditional operator can be used inside another conditional operator. This is called a nested conditional operator.

It can be used to select among more than two possible results.

Example Program: Find the Largest of Three Numbers

#include <iostream> using namespace std; int main() { int a = 20, b = 45, c = 30; int largest; largest = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c); cout << "Largest number = " << largest; return 0; }

Expected Output

Largest number = 45

Explanation:

  • First, a is compared with b.
  • Since a is not greater than b, the second condition is evaluated.
  • b is compared with c.
  • Since b is greater than c, b is selected.
  • The largest value is 45.
Nested conditional operators should be formatted clearly. For complicated decision-making, an if-else statement may be easier to understand.

7. Conditional Operator vs if-else Statement

Conditional Operator if-else Statement
Uses ? and : symbols. Uses if and else keywords.
Is an operator with three operands. Is a selection statement.
Produces a result value. Executes a selected statement block.
Useful for simple conditional expressions. Suitable for complex decision-making.
Can be concise. Can be easier to read for multiple statements.

Example Using if-else

#include <iostream> using namespace std; int main() { int a = 10, b = 20; int greater; if (a > b) { greater = a; } else { greater = b; } cout << "Greater number = " << greater; return 0; }

Expected Output

Greater number = 20

8. Applications of Conditional Operator

  • Finding the greater or smaller of two values.
  • Checking whether a number is even or odd.
  • Checking positive, negative or zero conditions.
  • Assigning values based on conditions.
  • Writing compact conditional expressions.
  • Making simple decisions in programs.

9. Important Points

  • The conditional operator is represented by ? :.
  • It is also known as the ternary operator.
  • It requires three operands.
  • The condition is evaluated first.
  • If the condition is true, the expression before : is selected.
  • If the condition is false, the expression after : is selected.
  • Only the selected result expression is evaluated.
  • Nested conditional operators are allowed.
  • The conditional operator is right-associative.
Programming caution: Avoid deeply nested conditional expressions because they can make code difficult to read and maintain.

10. Interview Questions

Q1. What is the conditional operator in C++?

It is an operator that selects one of two expressions depending on whether a condition is true or false.

Q2. Why is it called the ternary operator?

Because it uses three operands: a condition, a true expression and a false expression.

Q3. What is the symbol of the conditional operator?

The symbols are ? and :.

Q4. Can the conditional operator be nested?

Yes. A conditional operator can be placed inside another conditional operator.

Q5. What is the difference between the conditional operator and if-else?

The conditional operator is an expression that produces a result value, while if-else is a selection statement that executes statements based on a condition.

Q6. What is the associativity of the conditional operator?

The conditional operator has right-to-left associativity.

Q7. Is the conditional operator a unary, binary or ternary operator?

It is a ternary operator because it uses three operands.

12. Lesson Summary

The conditional operator is a compact decision-making operator in C++. It evaluates a condition and selects one of two expressions based on the result.

Remember the syntax:
result = (condition) ? value_if_true : value_if_false;

It is useful for simple decisions, comparisons and conditional assignments. Nested conditional operators can handle multiple alternatives, but complex logic is often clearer with if-else.
