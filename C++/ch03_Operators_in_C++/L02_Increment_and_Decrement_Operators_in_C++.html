1. Introduction

Increment and decrement operators are unary operators in C++ used to increase or decrease the value of a variable by one.

These operators are commonly used in loops, counting operations, array traversal and other programming tasks.

Increment: Increases the value of a variable by 1.
Decrement: Decreases the value of a variable by 1.

2. Types of Increment and Decrement Operators

Both increment and decrement operators have two forms: prefix and postfix.

Operator Type Meaning
++a Pre-increment Increments first, then uses the value.
a++ Post-increment Uses the current value, then increments.
--a Pre-decrement Decrements first, then uses the value.
a-- Post-decrement Uses the current value, then decrements.

3. Pre-increment Operator (++a)

The pre-increment operator increases the variable's value by one before its value is used in an expression.

Example

#include <iostream> using namespace std; int main() { int a = 5; cout << "Value of a: " << a << endl; cout << "Pre-increment: " << ++a << endl; cout << "Value after increment: " << a << endl; return 0; }

Expected Output

Value of a: 5
Pre-increment: 6
Value after increment: 6

Explanation:

  • Initially, a = 5.
  • The ++a operator increases a to 6.
  • The updated value 6 is displayed.

4. Post-increment Operator (a++)

The post-increment operator uses the current value of the variable in the expression and then increases it by one.

Example

#include <iostream> using namespace std; int main() { int a = 5; cout << "Value of a: " << a << endl; cout << "Post-increment: " << a++ << endl; cout << "Value after increment: " << a << endl; return 0; }

Expected Output

Value of a: 5
Post-increment: 5
Value after increment: 6

Explanation:

  • Initially, a = 5.
  • The current value 5 is displayed first.
  • After the expression, a becomes 6.

5. Pre-decrement Operator (--a)

The pre-decrement operator decreases the variable's value by one before its value is used in an expression.

Example

#include <iostream> using namespace std; int main() { int a = 5; cout << "Value of a: " << a << endl; cout << "Pre-decrement: " << --a << endl; cout << "Value after decrement: " << a << endl; return 0; }

Expected Output

Value of a: 5
Pre-decrement: 4
Value after decrement: 4

Explanation:

  • Initially, a = 5.
  • The --a operator decreases a to 4.
  • The updated value 4 is displayed.

6. Post-decrement Operator (a--)

The post-decrement operator uses the current value of the variable in the expression and then decreases it by one.

Example

#include <iostream> using namespace std; int main() { int a = 5; cout << "Value of a: " << a << endl; cout << "Post-decrement: " << a-- << endl; cout << "Value after decrement: " << a << endl; return 0; }

Expected Output

Value of a: 5
Post-decrement: 5
Value after decrement: 4

Explanation:

  • Initially, a = 5.
  • The current value 5 is displayed first.
  • After the expression, a becomes 4.

7. Difference Between Prefix and Postfix

Prefix Postfix
Operator is written before the variable. Operator is written after the variable.
Updates the variable before its value is used. Uses the old value before updating the variable.
Examples: ++a, --a Examples: a++, a--
Remember: When used as a standalone statement, both prefix and postfix increment the variable by one, or decrement it by one. Their difference is important when the operator's value is used in a larger expression.

8. Using Increment and Decrement in Loops

Increment and decrement operators are frequently used in loops to update loop-control variables.

Example: Increment in a for Loop

#include <iostream> using namespace std; int main() { for (int i = 1; i <= 5; i++) { cout << i << endl; } return 0; }

Expected Output

1
2
3
4
5

In this program, i++ increases the value of i by one after each loop iteration.

Example: Decrement in a while Loop

#include <iostream> using namespace std; int main() { int i = 5; while (i >= 1) { cout << i << endl; i--; } return 0; }

Expected Output

5
4
3
2
1

9. Important Points

  • Increment (++) increases a variable's value by one.
  • Decrement (--) decreases a variable's value by one.
  • Both are unary operators.
  • Prefix operators are written before the variable.
  • Postfix operators are written after the variable.
  • Prefix and postfix differ when their result is used in an expression.
  • These operators are commonly used in loops and counting operations.
  • The operators require a modifiable operand, such as a variable.
Programming caution: Avoid modifying the same variable multiple times in a single expression without a clear sequencing rule. Such expressions can produce undefined behavior in C++.

10. Interview Questions

Q1. What is an increment operator?

It is a unary operator (++) that increases a variable's value by one.

Q2. What is a decrement operator?

It is a unary operator (--) that decreases a variable's value by one.

Q3. What is the difference between ++a and a++?

++a increments first and then provides the updated value. a++ provides the current value and then increments.

Q4. What is the difference between --a and a--?

--a decrements first and then provides the updated value. a-- provides the current value and then decrements.

Q5. Can increment and decrement operators be used in loops?

Yes. They are commonly used to update loop-control variables.

Q6. Are increment and decrement unary operators?

Yes. They operate on a single modifiable operand.

12. Lesson Summary

Increment and decrement operators are used to increase or decrease a variable's value by one. C++ provides prefix and postfix forms for both operations.

Operator Operation
++a Pre-increment
a++ Post-increment
--a Pre-decrement
a-- Post-decrement

Understanding these operators is important for writing loops, controlling counters and developing efficient C++ programs.
