1. Introduction to Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations on numeric values and variables in C++. They are commonly used in calculations, formulas, mathematical expressions and programming logic.

C++ provides five basic arithmetic operators: addition, subtraction, multiplication, division and modulus.

Definition: Arithmetic operators are symbols that perform mathematical operations on operands.

2. Types of Arithmetic Operators

Operator Name Example Result
+ Addition 10 + 5 15
- Subtraction 10 - 5 5
* Multiplication 10 * 5 50
/ Division 10 / 5 2
% Modulus 10 % 3 1

3. Addition Operator (+)

The addition operator is used to add two or more numeric values. It returns their sum.

Syntax

result = operand1 + operand2;

Example

#include <iostream> using namespace std; int main() { int a = 10; int b = 20; int sum = a + b; cout << "Sum = " << sum; return 0; }

Expected Output

Sum = 30

4. Subtraction Operator (-)

The subtraction operator is used to subtract one numeric value from another. It returns the difference.

Syntax

result = operand1 - operand2;

Example

#include <iostream> using namespace std; int main() { int a = 50; int b = 20; int difference = a - b; cout << "Difference = " << difference; return 0; }

Expected Output

Difference = 30

5. Multiplication Operator (*)

The multiplication operator is used to multiply two numeric values.

Syntax

result = operand1 * operand2;

Example

#include <iostream> using namespace std; int main() { int a = 10; int b = 5; int product = a * b; cout << "Product = " << product; return 0; }

Expected Output

Product = 50

6. Division Operator (/)

The division operator divides one numeric value by another. The result depends on the data types of the operands.

Syntax

result = operand1 / operand2;

Example 1: Integer Division

#include <iostream> using namespace std; int main() { int a = 10; int b = 3; int result = a / b; cout << "Result = " << result; return 0; }

Expected Output

Result = 3

When both operands are integers, integer division discards the fractional part of the result.

Example 2: Floating-Point Division

#include <iostream> using namespace std; int main() { double a = 10; double b = 3; double result = a / b; cout << "Result = " << result; return 0; }

Expected Output

Result = 3.33333
Important: Division by zero is not valid for integer division and results in undefined behavior. Always ensure the divisor is non-zero.

7. Modulus Operator (%)

The modulus operator returns the remainder after dividing one integer by another.

Syntax

remainder = operand1 % operand2;

Example

#include <iostream> using namespace std; int main() { int a = 10; int b = 3; int remainder = a % b; cout << "Remainder = " << remainder; return 0; }

Expected Output

Remainder = 1

How It Works

10 ÷ 3 = 3 remainder 1 3 × 3 = 9 10 - 9 = 1 Therefore: 10 % 3 = 1
The modulus operator (%) is used with integral types. It is commonly used to check whether a number is even or odd and to calculate remainders.

8. Complete Arithmetic Operators Program

The following program demonstrates all five basic arithmetic operators in a single program.

Example Program

#include <iostream> using namespace std; int main() { int a = 20; int b = 6; cout << "Addition = " << a + b << endl; cout << "Subtraction = " << a - b << endl; cout << "Multiplication = " << a * b << endl; cout << "Division = " << a / b << endl; cout << "Modulus = " << a % b << endl; return 0; }

Expected Output

Addition = 26
Subtraction = 14
Multiplication = 120
Division = 3
Modulus = 2

9. Arithmetic Operators with Floating-Point Values

C++ supports arithmetic operations on floating-point data types such as float and double.

Example Program

#include <iostream> using namespace std; int main() { double a = 12.5; double b = 2.5; cout << "Addition = " << a + b << endl; cout << "Subtraction = " << a - b << endl; cout << "Multiplication = " << a * b << endl; cout << "Division = " << a / b << endl; return 0; }

Expected Output

Addition = 15
Subtraction = 10
Multiplication = 31.25
Division = 5

10. Applications of Arithmetic Operators

  • Addition: Calculating totals, sums and combined values.
  • Subtraction: Finding differences and remaining quantities.
  • Multiplication: Calculating area, product and repeated quantities.
  • Division: Calculating averages, ratios and unit values.
  • Modulus: Checking even or odd numbers and calculating remainders.

11. Important Points

  • Arithmetic operators perform mathematical operations.
  • The addition operator is represented by +.
  • The subtraction operator is represented by -.
  • The multiplication operator is represented by *.
  • The division operator is represented by /.
  • The modulus operator is represented by %.
  • Integer division discards the fractional part.
  • Floating-point division can produce a fractional result.
  • The modulus operator requires integral operands.
  • A zero divisor must be avoided.

12. Interview Questions

Q1. What are arithmetic operators in C++?

Answer: Operators used to perform mathematical operations on numeric values and variables.

Q2. Name the five basic arithmetic operators.

Answer: Addition (+), subtraction (-), multiplication (*), division (/) and modulus (%).

Q3. What is the difference between / and %?

Answer: Division returns the quotient, while modulus returns the remainder for integral operands.

Q4. What is the result of 10 / 3 using integer operands?

Answer: 3, because the fractional part is discarded.

Q5. What is the result of 10 % 3?

Answer: 1, because the remainder is 1.

Q6. Can the modulus operator be used with double values?

Answer: No. The built-in modulus operator requires integral operands.

Q7. What happens when an integer is divided by zero?

Answer: It results in undefined behavior.

Q8. What is the difference between integer and floating-point division?

Answer: Integer division discards the fractional part, while floating-point division can retain it.
