1. Introduction to Bitwise Shift Operators

Bitwise shift operators in C++ are used to move the individual bits of an integer value towards the left or right.

C++ provides two shift operators:

  • Left Shift (<<): Shifts bits towards the left.
  • Right Shift (>>): Shifts bits towards the right.
Example: The binary representation of decimal 5 using four bits is 0101. Shifting it one position to the left gives 1010, which represents decimal 10.

Shift operators are commonly used in bit manipulation, embedded systems, register operations and low-level programming.

2. Types of Shift Operators

Operator Name Function
<< Left Shift Moves bits towards the left.
>> Right Shift Moves bits towards the right.

General syntax: 

value << number_of_positions;
value >> number_of_positions;

3. Left Shift Operator ( << )

The left shift operator moves the bits of a value towards the left by the specified number of positions. For an unsigned integer, zeros are inserted into the vacant rightmost positions.

Example: Left Shift by One Position

Original value:

    0101    (Decimal 5)

After left shift by 1:

    1010    (Decimal 10)

Therefore:

5 << 1 = 10

Example Program

#include <iostream>
using namespace std;

int main()
{
    unsigned int num = 5;

    cout << "Original value: " << num << endl;
    cout << "After left shift: " << (num << 1);

    return 0;
}
Output: 
Original value: 5
After left shift: 10

4. Left Shift by Multiple Positions

We can shift bits by more than one position by specifying the required number after the shift operator.

Example: Left Shift by Two Positions

Original value:

    00000101    (5)

After left shift by 2:

    00010100    (20)

Therefore:

5 << 2 = 20

Example Program

#include <iostream>
using namespace std;

int main()
{
    unsigned int num = 5;

    cout << "Left shift by 1: " << (num << 1) << endl;
    cout << "Left shift by 2: " << (num << 2) << endl;
    cout << "Left shift by 3: " << (num << 3) << endl;

    return 0;
}
Output: 
Left shift by 1: 10
Left shift by 2: 20
Left shift by 3: 40
For unsigned integers, when the shifted result remains within the type's range, shifting left by one position corresponds to multiplying by 2. Shifting left by two positions corresponds to multiplying by 4.

5. Right Shift Operator ( >> )

The right shift operator moves the bits of a value towards the right by the specified number of positions.

For an unsigned integer, zeros are inserted into the vacant leftmost positions.

Example: Right Shift by One Position

Original value:

    1010    (Decimal 10)

After right shift by 1:

    0101    (Decimal 5)

Therefore:

10 >> 1 = 5

Example Program

#include <iostream>
using namespace std;

int main()
{
    unsigned int num = 10;

    cout << "Original value: " << num << endl;
    cout << "After right shift: " << (num >> 1);

    return 0;
}
Output: 
Original value: 10
After right shift: 5

6. Right Shift by Multiple Positions

We can shift bits towards the right by multiple positions.

Example: Right Shift by Two Positions

Original value:

    00010100    (20)

After right shift by 2:

    00000101    (5)

Therefore:

20 >> 2 = 5

Example Program

#include <iostream>
using namespace std;

int main()
{
    unsigned int num = 20;

    cout << "Right shift by 1: " << (num >> 1) << endl;
    cout << "Right shift by 2: " << (num >> 2) << endl;
    cout << "Right shift by 3: " << (num >> 3) << endl;

    return 0;
}
Output: 
Right shift by 1: 10
Right shift by 2: 5
Right shift by 3: 2
For unsigned integers, right shifting by one position is equivalent to integer division by 2. Any fractional part is discarded.

7. Comparison Between Left Shift and Right Shift

Left Shift (<<) Right Shift (>>)
Moves bits towards the left. Moves bits towards the right.
For unsigned values, zeros enter from the right. For unsigned values, zeros enter from the left.
Can multiply by powers of 2 when no overflow occurs. Can divide by powers of 2 for unsigned values.
Example: 5 << 1 = 10 Example: 10 >> 1 = 5

8. Shift Operators and Powers of 2

For unsigned integer values, shifting left by n positions corresponds to multiplication by 2 raised to n, provided the result fits within the type.

Similarly, right shifting an unsigned integer by n positions corresponds to integer division by 2 raised to n.

Expression Calculation Result
5 << 1 5 × 2 10
5 << 2 5 × 4 20
5 << 3 5 × 8 40
20 >> 1 20 ÷ 2 10
20 >> 2 20 ÷ 4 5
20 >> 3 20 ÷ 8 2

9. Applications of Shift Operators in Embedded Systems

Shift operators are particularly useful in embedded systems because microcontrollers frequently use individual bits to control hardware.

Application 1: Setting a Specific Bit

The expression below creates a mask with bit number 3 set. 

unsigned int mask = (1U << 3);

Its binary representation is: 

00001000

Application 2: Setting a Bit in a Register

Bitwise OR with a shifted mask can set a particular bit without changing the other bits. 

unsigned int reg = 0;

reg |= (1U << 3);

This sets bit number 3 of the variable.

Application 3: Checking a Specific Bit

A shifted mask combined with bitwise AND can check whether a particular bit is set. 

unsigned int reg = 8;

if (reg & (1U << 3))
{
    cout << "Bit 3 is set";
}
Output: 
Bit 3 is set

Application 4: Clearing a Specific Bit

A shifted mask can be inverted and combined with bitwise AND to clear a particular bit. 

unsigned int reg = 15;

reg &= ~(1U << 2);

This clears bit number 2 while preserving the other bits.

Embedded Systems Connection: These techniques are used when configuring GPIO registers, enabling or disabling peripheral features, and checking status flags in microcontrollers such as LPC2129.

10. Important Rules and Precautions

  • Shift operators work on integral types.
  • The left operand is the value whose bits are shifted.
  • The right operand specifies the number of bit positions.
  • Use unsigned integers for predictable bit manipulation.
  • Do not shift by a negative number of positions.
  • Do not shift by a count greater than or equal to the width of the promoted left operand.
  • Left shifting must be performed carefully to avoid an unrepresentable result.
Important C++ rule: A shift count that is negative or greater than or equal to the width of the promoted left operand causes undefined behavior. Avoid relying on shifts of negative signed values or on overflow.
In modern C++, right shift of a negative signed integer is defined as division rounded towards negative infinity. For portable low-level bit manipulation, unsigned integer types are generally preferred.

11. Common Interview Questions

Q1. What are bitwise shift operators?

They move the bits of an integer value towards the left or right.

Q2. What are the two shift operators in C++?

Left shift (<<) and right shift (>>).

Q3. What is the result of 5 << 1?

The result is 10.

Q4. What is the result of 20 >> 2?

The result is 5.

Q5. What is the use of shift operators in embedded systems?

They are used for bit masking, register configuration, setting bits, clearing bits and checking hardware flags.

Q6. What does 1U << 3 represent?

It creates an unsigned integer mask with bit number 3 set. Its decimal value is 8.

Q7. What happens when an invalid shift count is used?

A negative shift count or a count greater than or equal to the width of the promoted left operand causes undefined behavior.

13. Lesson Summary

Bitwise shift operators move individual bits towards the left or right. The left shift operator (<<) shifts bits towards the left, while the right shift operator (>>) shifts bits towards the right.

These operators are important for binary calculations, bit manipulation, embedded programming and microcontroller register configuration.
