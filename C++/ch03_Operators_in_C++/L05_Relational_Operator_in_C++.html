1. Introduction to Relational Operators

Relational operators in C++ are used to compare two values or expressions. They determine the relationship between the operands.

A relational expression produces a Boolean result: true or false.

Purpose: To compare values and make decisions in a program.
Result: Boolean value (true or false).

In C++, the Boolean value true is represented numerically as 1 when converted to an integer, and false as 0.

2. Types of Relational Operators

C++ provides six commonly used relational operators.

Operator Name Meaning Example
< Less than Checks whether the left operand is smaller. 5 < 10 → true
> Greater than Checks whether the left operand is greater. 10 > 5 → true
<= Less than or equal to Checks whether the left operand is smaller or equal. 5 <= 5 → true
>= Greater than or equal to Checks whether the left operand is greater or equal. 10 >= 5 → true
== Equal to Checks whether both operands are equal. 5 == 5 → true
!= Not equal to Checks whether both operands are different. 5 != 10 → true

3. Less Than Operator (<)

The less than operator checks whether the left operand is smaller than the right operand.

Example Program

#include <iostream> using namespace std; int main() { int a = 10, b = 20; cout << (a < b); return 0; }

Expected Output

1

Since 10 is less than 20, the expression is true. When displayed as an integer, true appears as 1.

4. Greater Than Operator (>)

The greater than operator checks whether the left operand is greater than the right operand.

Example Program

#include <iostream> using namespace std; int main() { int a = 30, b = 15; cout << (a > b); return 0; }

Expected Output

1

Since 30 is greater than 15, the result is true (1).

5. Less Than or Equal To Operator (<=)

The less than or equal to operator checks whether the left operand is smaller than or equal to the right operand.

Example Program

#include <iostream> using namespace std; int main() { int a = 10, b = 10; cout << (a <= b); return 0; }

Expected Output

1

Since both values are equal, the expression is true.

6. Greater Than or Equal To Operator (>=)

The greater than or equal to operator checks whether the left operand is greater than or equal to the right operand.

Example Program

#include <iostream> using namespace std; int main() { int a = 25, b = 20; cout << (a >= b); return 0; }

Expected Output

1

Since 25 is greater than 20, the result is true.

7. Equal To Operator (==)

The equal to operator checks whether two operands have the same value.

Example Program

#include <iostream> using namespace std; int main() { int a = 50, b = 50; cout << (a == b); return 0; }

Expected Output

1

Both values are equal, so the result is true.

8. Not Equal To Operator (!=)

The not equal to operator checks whether two operands have different values.

Example Program

#include <iostream> using namespace std; int main() { int a = 10, b = 20; cout << (a != b); return 0; }

Expected Output

1

Since 10 and 20 are different, the result is true.

9. Displaying Boolean Results

By default, C++ displays Boolean values as 1 for true and 0 for false when using cout.

The boolalpha manipulator displays the words true and false instead.

Example Program

#include <iostream> using namespace std; int main() { int a = 10, b = 20; cout << boolalpha; cout << "a < b: " << (a < b) << endl; cout << "a > b: " << (a > b) << endl; cout << "a == b: " << (a == b) << endl; return 0; }

Expected Output

a < b: true
a > b: false
a == b: false
Remember: The boolalpha manipulator changes how Boolean values are displayed. It does not change the actual Boolean result.

10. Relational Operators with if-else

Relational operators are frequently used with if-else statements to control program execution.

Example Program: Check Voting Eligibility

#include <iostream> using namespace std; int main() { int age = 20; if (age >= 18) { cout << "Eligible to vote"; } else { cout << "Not eligible to vote"; } return 0; }

Expected Output

Eligible to vote

The condition age >= 18 is true because the age is 20. Therefore, the if block is executed.

11. Difference Between = and ==

The assignment operator (=) and equal to operator (==) have different purposes.

Assignment Operator (=) Equal To Operator (==)
Assigns a value to a variable. Compares two values.
Changes the value stored in a variable. Produces a Boolean result.
Example: a = 10; Example: a == 10
Common mistake: Writing if (a = 10) performs an assignment, not an equality comparison. To compare a with 10, write if (a == 10).

12. Important Points

  • C++ provides six relational operators.
  • Relational operators compare two operands.
  • The result of a relational expression has type bool.
  • true is represented as 1 when converted to an integer.
  • false is represented as 0 when converted to an integer.
  • Relational operators are commonly used in conditions and loops.
  • The == operator compares values, while = assigns values.
  • Relational operators have left-to-right associativity.
Floating-point values can have precision limitations. Avoid assuming that two calculated floating-point values will always be exactly equal. Use an appropriate tolerance when comparing calculated floating-point results.

13. Interview Questions

Q1. What are relational operators in C++?

They are operators used to compare two values and produce a Boolean result.

Q2. How many relational operators are available in C++?

Six: <, >, <=, >=, == and !=.

Q3. What is the result of a relational expression?

It produces a Boolean value: true or false.

Q4. What is the difference between = and ==?

= is used for assignment, whereas == is used for comparison.

Q5. What is the purpose of the != operator?

It checks whether two operands are not equal.

Q6. What is boolalpha in C++?

It is an output manipulator that displays Boolean values as true and false instead of 1 and 0.

Q7. Can relational operators be used with if statements?

Yes. They are commonly used to form conditions in if, if-else and loop statements.
