Precedence and Associativity of Operators in C++

1. Introduction

A C++ expression can contain multiple operators. When an expression contains more than one operator, the compiler follows predefined rules to determine how the expression is grouped.

Two important concepts determine this grouping: operator precedence and operator associativity.

Operator Precedence: Determines which operator binds more tightly in an expression.
Operator Associativity: Determines how operators of the same precedence are grouped.

2. What Is Operator Precedence?

Operator precedence defines the priority of operators in an expression. Operators with higher precedence are grouped before operators with lower precedence.

Example

#include <iostream> using namespace std; int main() { int result = 10 + 5 * 2; cout << result; return 0; }
Output: 
20

Explanation:

  • Multiplication (*) has higher precedence than addition (+).
  • First, 5 * 2 = 10.
  • Then, 10 + 10 = 20.

3. What Is Operator Associativity?

Associativity determines how operators having the same precedence are grouped when they appear together in an expression.

Most arithmetic binary operators, such as addition, subtraction, multiplication and division, have left-to-right associativity. Assignment operators have right-to-left associativity.

Example 1: Left-to-right associativity

int result = 20 - 5 - 3;

Grouping:

(20 - 5) - 3 15 - 3 12
Result: 12

Example 2: Right-to-left associativity

int a, b, c; a = b = c = 10;

Grouping:

a = (b = (c = 10));

First, c receives 10. Then b receives the assigned value, followed by a.

Result: 
a = 10
b = 10
c = 10

4. Difference Between Precedence and Associativity

Operator Precedence Operator Associativity
Determines which operator binds more tightly. Determines grouping when operators have the same precedence.
Compares operators with different precedence levels. Applies to operators at the same precedence level.
Example: multiplication before addition. Example: grouping of subtraction from left to right.

6. Examples of Operator Precedence

Example 1: Multiplication and addition

int result = 5 + 4 * 3;

Evaluation:

5 + (4 * 3) 5 + 12 17
Result: 17

Example 2: Division and subtraction

int result = 20 - 12 / 4;

Evaluation:

20 - (12 / 4) 20 - 3 17
Result: 17

Example 3: Relational and logical operators

int a = 10; int b = 5; bool result = a > b && b > 0;

Evaluation:

(a > b) && (b > 0) true && true true
Result: true

7. Examples of Operator Associativity

Example 1: Subtraction

int result = 50 - 20 - 10;

Subtraction is left-associative:

(50 - 20) - 10 30 - 10 20
Result: 20

Example 2: Division

int result = 100 / 10 / 2;

Division is left-associative:

(100 / 10) / 2 10 / 2 5
Result: 5

Example 3: Assignment

int a, b, c; a = b = c = 25;

Assignment is right-associative:

a = (b = (c = 25));
Result: 
a = 25
b = 25
c = 25

8. Using Parentheses to Control Precedence

Parentheses () can be used to explicitly control how an expression is grouped. They also make expressions easier to read.

Example 1: Without parentheses

int result = 10 + 5 * 2;
Output: 20

Example 2: With parentheses

int result = (10 + 5) * 2;
Output: 30
Parentheses can change the grouping of an expression and therefore can change its result.

9. Complete C++ Program

The following program demonstrates precedence, associativity and the use of parentheses.

#include <iostream> using namespace std; int main() { int a = 10, b = 5, c = 2; int result1 = a + b * c; int result2 = (a + b) * c; int result3 = a - b - c; int x, y, z; x = y = z = 100; cout << "Result 1: " << result1 << endl; cout << "Result 2: " << result2 << endl; cout << "Result 3: " << result3 << endl; cout << "x = " << x << endl; cout << "y = " << y << endl; cout << "z = " << z << endl; return 0; }
Expected Output: 
Result 1: 20
Result 2: 30
Result 3: 3
x = 100
y = 100
z = 100

10. Precedence Does Not Always Determine Evaluation Order

Operator precedence and associativity determine how an expression is grouped. They do not, by themselves, determine the order in which every operand or function call is evaluated.

C++ has separate rules for evaluation order and sequencing. Some operands are evaluated in an unspecified order, while certain operators guarantee sequencing.

Example: Logical AND short-circuiting

#include <iostream> using namespace std; int main() { int a = 0; if (a != 0 && 10 / a > 1) { cout << "Condition is true"; } else { cout << "Condition is false"; } return 0; }
Output: 
Condition is false

The logical AND operator (&&) evaluates its left operand first. Since a != 0 is false, the right operand is not evaluated.

Do not assume that left-to-right associativity means all operands are evaluated from left to right. Associativity describes grouping, not general evaluation order.

11. Common Mistakes

  • Assuming addition is performed before multiplication.
  • Confusing precedence with associativity.
  • Assuming all operators have left-to-right associativity.
  • Forgetting that assignment operators are right-associative.
  • Ignoring parentheses in complex expressions.
  • Assuming associativity determines the evaluation order of operands.

12. Important Points to Remember

  • Precedence determines how tightly operators bind.
  • Associativity determines grouping among operators of equal precedence.
  • Multiplication has higher precedence than addition.
  • Most arithmetic binary operators are left-associative.
  • Assignment operators are right-associative.
  • Parentheses can explicitly change expression grouping.
  • Precedence and associativity do not generally specify operand evaluation order.
  • Logical AND and logical OR provide short-circuit evaluation.

13. Interview Questions

Q1. What is operator precedence?

It determines which operators bind more tightly in an expression.

Q2. What is operator associativity?

It determines how operators with the same precedence are grouped.

Q3. Which has higher precedence: multiplication or addition?

Multiplication has higher precedence than addition.

Q4. What is the associativity of assignment operators?

Assignment operators have right-to-left associativity.

Q5. What is the result of 10 + 5 * 2?

The result is 20 because multiplication has higher precedence.

Q6. What is the result of 20 - 5 - 3?

The result is 12 because subtraction is left-associative.

Q7. How can parentheses change an expression?

Parentheses explicitly change grouping and may change the result.

Q8. Does associativity determine operand evaluation order?

No. It determines grouping. C++ has separate rules for evaluation order.

Q9. What is short-circuit evaluation?

It is the behavior where the second operand of a logical operator is skipped when the result is already determined.

Q10. Which operator has lower precedence: logical AND or logical OR?

Logical OR (||) has lower precedence than logical AND (&&).
