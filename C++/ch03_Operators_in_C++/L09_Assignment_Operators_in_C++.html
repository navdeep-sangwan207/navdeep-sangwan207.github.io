1. Introduction to Assignment Operators

Assignment operators in C++ are used to assign values to variables. They can also perform an operation and assign the resulting value to the same variable.

The most basic assignment operator is the equal sign (=).

Example: 
int a = 10;
Here, the value 10 is assigned to variable a.

2. Types of Assignment Operators

C++ provides simple and compound assignment operators.

Operator Name Example Equivalent Expression
= Simple Assignment a = 10 Assigns 10 to a
+= Addition Assignment a += 5 a = a + 5
-= Subtraction Assignment a -= 5 a = a - 5
*= Multiplication Assignment a *= 5 a = a * 5
/= Division Assignment a /= 5 a = a / 5
%= Modulus Assignment a %= 5 a = a % 5
&= Bitwise AND Assignment a &= 5 a = a & 5
|= Bitwise OR Assignment a |= 5 a = a | 5
^= Bitwise XOR Assignment a ^= 5 a = a ^ 5
<<= Left Shift Assignment a <<= 2 a = a << 2
>>= Right Shift Assignment a >>= 2 a = a >> 2

3. Simple Assignment Operator ( = )

The simple assignment operator assigns the value on the right-hand side to the variable on the left-hand side.

Syntax

variable = value;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a;

    a = 10;

    cout << "Value of a: " << a;

    return 0;
}
Output: 
Value of a: 10

4. Addition Assignment Operator ( += )

The addition assignment operator adds a value to an existing variable and stores the result in that variable.

Example

int a = 10;

a += 5;

// Equivalent to:
// a = a + 5;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a = 10;

    a += 5;

    cout << "Result: " << a;

    return 0;
}
Output: 
Result: 15

5. Subtraction Assignment Operator ( -= )

The subtraction assignment operator subtracts a value from an existing variable and stores the result. 

int a = 20;

a -= 5;

// Equivalent to:
// a = a - 5;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a = 20;

    a -= 5;

    cout << "Result: " << a;

    return 0;
}
Output: 
Result: 15

6. Multiplication Assignment Operator ( *= )

The multiplication assignment operator multiplies the existing variable by a value and stores the result. 

int a = 5;

a *= 4;

// Equivalent to:
// a = a * 4;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a = 5;

    cout << "Result: " << a;

    return 0;
}
Output: 
Result: 20

7. Division Assignment Operator ( /= )

The division assignment operator divides the existing variable by a value and stores the result. 

int a = 20;

a /= 4;

// Equivalent to:
// a = a / 4;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a = 20;

    a /= 4;

    cout << "Result: " << a;

    return 0;
}
Output: 
Result: 5
Division by zero is not valid. Always ensure that the divisor is non-zero before using the division assignment operator.

8. Modulus Assignment Operator ( %= )

The modulus assignment operator calculates the remainder after division and stores that remainder in the variable. 

int a = 17;

a %= 5;

// Equivalent to:
// a = a % 5;

Example Program

#include <iostream>
using namespace std;

int main()
{
    int a = 17;

    a %= 5;

    cout << "Remainder: " << a;

    return 0;
}
Output: 
Remainder: 2

9. Bitwise Assignment Operators

Bitwise assignment operators perform bitwise operations and store the resulting value in the original variable.

9.1 Bitwise AND Assignment ( &= )

unsigned int a = 12;

a &= 10;

// Equivalent to:
// a = a & 10;

Binary calculation:

    1100    (12)
&   1010    (10)
------------
    1000    (8)
Result: 8

9.2 Bitwise OR Assignment ( |= )

unsigned int a = 12;

a |= 10;

// Equivalent to:
// a = a | 10;

Binary calculation:

    1100    (12)
|   1010    (10)
------------
    1110    (14)
Result: 14

9.3 Bitwise XOR Assignment ( ^= )

unsigned int a = 12;

a ^= 10;

// Equivalent to:
// a = a ^ 10;

Binary calculation:

    1100    (12)
^   1010    (10)
------------
    0110    (6)
Result: 6

10. Shift Assignment Operators

Shift assignment operators shift the bits of a variable and store the result back in that variable.

10.1 Left Shift Assignment ( <<= )

unsigned int a = 5;

a <<= 2;

// Equivalent to:
// a = a << 2;
Output value: 20

10.2 Right Shift Assignment ( >>= )

unsigned int a = 20;

a >>= 2;

// Equivalent to:
// a = a >> 2;
Output value: 5

11. Complete Assignment Operators Example

The following program demonstrates several assignment operators in a single C++ program. 

#include <iostream>
using namespace std;

int main()
{
    int a = 10;

    cout << "Initial value: " << a << endl;

    a += 5;
    cout << "After += 5: " << a << endl;

    a -= 3;
    cout << "After -= 3: " << a << endl;

    a *= 2;
    cout << "After *= 2: " << a << endl;

    a /= 4;
    cout << "After /= 4: " << a << endl;

    a %= 3;
    cout << "After %= 3: " << a << endl;

    return 0;
}
Output: 
Initial value: 10
After += 5: 15
After -= 3: 12
After *= 2: 24
After /= 4: 6
After %= 3: 0

12. Difference Between = and ==

The assignment operator (=) and equality operator (==) have different purposes.

Assignment Operator (=) Equality Operator (==)
Assigns a value to a variable. Compares two values.
Changes the variable's stored value. Does not modify the compared values.
Example: a = 10; Example: a == 10
Do not confuse = with ==. Using the wrong operator in a condition can cause unexpected program behavior.

13. Applications of Assignment Operators

  • Updating Variables: Changing values during program execution.
  • Loop Counters: Increasing or decreasing counter values.
  • Calculations: Updating totals, balances and measurements.
  • Bit Manipulation: Modifying individual bits using compound bitwise operators.
  • Embedded Systems: Updating register values and configuring hardware flags.
Embedded Systems Example: 
unsigned int GPIO = 0;

// Set bit 3
GPIO |= (1U << 3);

// Clear bit 3
GPIO &= ~(1U << 3);
These operations are commonly used when manipulating bits in microcontroller registers.

14. Important Points

  • The assignment operator is represented by =.
  • Compound assignment operators combine an operation with assignment.
  • += adds and assigns.
  • -= subtracts and assigns.
  • *= multiplies and assigns.
  • /= divides and assigns.
  • %= calculates the remainder and assigns.
  • Bitwise and shift assignment operators are useful for bit manipulation.
  • Always avoid division or remainder operations with a zero divisor.

15. Common Interview Questions

Q1. What are assignment operators in C++?

Assignment operators assign values to variables or perform an operation and store the result in a variable.

Q2. What is the difference between = and +=?

The = operator assigns a value directly, while += adds a value to the existing variable and stores the result.

Q3. What does a *= 5 mean?

It multiplies the current value of a by 5 and stores the result back in a.

Q4. What is the purpose of %=?

It calculates the remainder after division and stores the remainder in the variable.

Q5. What are compound assignment operators?

They combine an operation and assignment into a single operator, such as +=, -=, *= and /=.

Q6. Where are bitwise assignment operators used?

They are used in bit manipulation, embedded programming and microcontroller register configuration.

17. Lesson Summary

Assignment operators are used to assign values and update existing variables in C++. Simple assignment uses the equal sign (=), while compound assignment operators combine arithmetic, bitwise or shift operations with assignment.

These operators make programs shorter and are useful in calculations, loops, embedded programming and hardware register manipulation.
