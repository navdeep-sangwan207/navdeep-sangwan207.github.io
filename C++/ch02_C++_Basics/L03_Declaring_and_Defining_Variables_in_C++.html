1. Introduction

A variable is a named memory location used to store data during program execution. Before using a variable, we generally need to declare it with an appropriate data type.

In C++, declaration and definition are related concepts, but they do not always mean the same thing.

Learning Objectives:
  • Understand variable declaration and definition.
  • Learn the syntax of declaring variables.
  • Understand how memory is associated with variables.
  • Differentiate declaration, definition and initialization.
  • Practice writing variable declarations in C++.

2. Variable Declaration

A variable declaration introduces a variable name and specifies its data type to the compiler.

It tells the compiler what kind of value the variable represents and how it should be used.

Syntax

data_type variable_name;

Examples

int age; float temperature; double salary; char grade; bool isActive;

Each statement introduces a variable with a particular type.

Declaration Data Type Purpose
int age; int Stores an integer value.
float temperature; float Stores a floating-point value.
double salary; double Stores a double-precision value.
char grade; char Stores a character.
bool isActive; bool Stores true or false.
Note: A declaration does not necessarily create a new object. For example, an extern declaration can refer to an object defined elsewhere.

3. Variable Definition

A definition is a declaration that also establishes the variable itself. For an object definition, storage is provided as required by its storage duration and context.

Example

int marks;

This statement defines an integer variable named marks.

The compiler knows the variable's type and the program has an object associated with that definition.

Important: In ordinary C++ programs, statements such as int marks; are both declarations and definitions.

4. Declaration vs Definition

A declaration introduces a name and its type. A definition provides the entity itself. Every definition is a declaration, but not every declaration is a definition.

Declaration / Definition Meaning
extern int total; Declares an integer variable named total without defining it.
int total; Defines an integer variable named total.
int total = 100; Defines total and initializes it with 100.
Remember: An extern declaration without an initializer normally refers to an object whose definition is provided elsewhere in the program.

5. Variable Initialization

Initialization means providing an initial value to a variable when it is created.

Syntax

data_type variable_name = value;

Examples

int age = 25; float percentage = 85.5f; char grade = 'A'; bool isPassed = true;

In these examples, each variable is defined and initialized in the same statement.

Initialization gives a variable its initial value. It is different from assignment, which changes the value of an already existing variable.

6. Different Ways to Declare Variables

A. Single Variable Declaration

int number;

B. Multiple Variables of the Same Type

int a, b, c;

This statement declares three integer variables.

C. Multiple Variables with Initialization

int a = 10, b = 20, c = 30;

D. Separate Declarations

int a = 10; int b = 20; int c = 30;

Separate declarations can improve readability when variables have different purposes.

7. Declaration and Definition Using extern

The extern keyword can declare a variable that is defined elsewhere.

Example: Two Source Files

File 1: main.cpp

#include <iostream> extern int score; int main() { std::cout << "Score: " << score; return 0; }

File 2: data.cpp

int score = 95;

The extern int score; statement tells the compiler that the variable is defined elsewhere. The definition in data.cpp provides the actual variable.

Expected Output: 
Score: 95
Both source files must be compiled and linked together. If the required definition is missing, the linker will generally report an unresolved external symbol.

8. Important Rules for Variable Declaration

  • A variable must have a valid data type.
  • A variable name must follow C++ identifier rules.
  • A declaration normally ends with a semicolon.
  • Variables should be declared before they are used.
  • Variables in the same scope cannot be redeclared with the same name.
  • Use meaningful names to improve code readability.
  • Choose a data type appropriate for the required values.

Example

int studentAge = 21; double accountBalance = 15000.50; char section = 'B'; bool isRegistered = true;

9. Common Mistakes

1. Using a Variable Without Declaring It

int main() { age = 20; // Error: age is not declared return 0; }

2. Missing Semicolon

int marks = 90 // Error: missing semicolon

3. Using an Uninitialized Local Variable

int main() { int number; std::cout << number; // Do not read an indeterminate value return 0; }
An uninitialized local variable with automatic storage duration does not have a predictable value. Initialize it before reading it.

Correct Approach

int main() { int number = 10; std::cout << number; return 0; }

10. Complete C++ Program

The following program demonstrates variable declaration, definition and initialization.

#include <iostream> using namespace std; int main() { // Variable declarations and definitions int age; float percentage; char grade; // Initialization age = 22; percentage = 87.5f; grade = 'A'; // Display values cout << "Student Details" << endl; cout << "Age: " << age << endl; cout << "Percentage: " << percentage << endl; cout << "Grade: " << grade << endl; return 0; }

Expected Output

Student Details
Age: 22
Percentage: 87.5
Grade: A

Program Explanation

  1. int age; defines an integer variable.
  2. float percentage; defines a floating-point variable.
  3. char grade; defines a character variable.
  4. The assignment statements give values to the variables.
  5. cout displays the stored values.

11. Declaration, Definition, Initialization and Assignment

Concept Example Explanation
Declaration only extern int x; Introduces a variable declared elsewhere.
Definition int x; Defines the variable.
Initialization int x = 10; Defines and initializes the variable.
Assignment x = 20; Changes the value of an existing variable.

13. Interview Questions

Q1. What is a variable in C++?

A variable is a named object used to store data in a program.

Q2. What is variable declaration?

Declaration introduces a variable name and specifies its type.

Q3. What is variable definition?

A definition establishes the variable itself, including its object and required storage.

Q4. What is the difference between declaration and definition?

A declaration introduces a name and its type. A definition also establishes the entity. Every definition is a declaration.

Q5. What is initialization?

Initialization provides the initial value of a variable when it is created.

Q6. What is the purpose of extern?

The extern keyword can declare a variable that is defined in another source file or elsewhere.

Q7. What is the difference between initialization and assignment?

Initialization gives an object its initial value. Assignment changes the value of an existing object.

14. Quick Revision

  • A variable is a named object that stores data.
  • Declaration introduces a name and its type.
  • Definition establishes the entity itself.
  • Initialization provides an initial value.
  • Assignment changes the value of an existing variable.
  • extern can declare a variable defined elsewhere.
  • Initialize local variables before reading them.
