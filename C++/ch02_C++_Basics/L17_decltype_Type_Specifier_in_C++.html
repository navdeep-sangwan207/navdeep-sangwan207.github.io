1. Introduction

The decltype keyword in C++ is a type specifier that determines the type of an expression without evaluating that expression.

It allows the programmer to declare a variable using the exact type of another variable or expression.

The compiler examines the expression and determines its type during compilation.

Important: decltype performs compile-time type deduction. It does not execute the expression to determine the type.

2. Syntax of decltype

decltype(expression) variable_name;

Here:

  • decltype: Requests type deduction from an expression.
  • expression: An existing variable, function call, or other valid expression.
  • variable_name: Name of the newly declared variable.

Example

int number = 100; decltype(number) value = 200;

Since number has type int, value is also declared as int.

3. Basic Program Using decltype

#include <iostream> using namespace std; int main() { int number = 50; decltype(number) result = 100; cout << "Number: " << number << endl; cout << "Result: " << result << endl; return 0; }
Expected Output: 
Number: 50
Result: 100

The compiler identifies the type of number and uses the same type for result.

4. decltype with Different Data Types

The decltype specifier can be used with variables of different data types.

#include <iostream> #include <string> using namespace std; int main() { int a = 10; double b = 20.5; char c = 'A'; string name = "C++"; decltype(a) x = 100; decltype(b) y = 45.75; decltype(c) z = 'B'; decltype(name) language = "Programming"; cout << x << endl; cout << y << endl; cout << z << endl; cout << language << endl; return 0; }
Expected Output: 
100
45.75
B
Programming

Each new variable receives the type of the expression specified inside decltype.

5. decltype with Expressions

decltype can determine the type produced by an expression. The resulting type depends on the expression's type and value category.

Example: Arithmetic Expression

#include <iostream> using namespace std; int main() { int a = 10; double b = 5.5; decltype(a + b) result = a + b; cout << "Result: " << result << endl; return 0; }
Expected Output: 
Result: 15.5

The expression a + b has type double, so result is declared as a double.

Remember: The expression inside decltype is not evaluated merely to determine its type. In this example, the initializer a + b is evaluated when the variable is initialized.

6. decltype with const Variables

Unlike ordinary by-value auto deduction, decltype preserves the type and cv-qualification of an unparenthesized variable name.

#include <iostream> using namespace std; int main() { const int number = 100; decltype(number) value = 200; cout << "Number: " << number << endl; cout << "Value: " << value << endl; return 0; }

In this example, value is also const int.

Assigning a new value to value would produce a compilation error because it is const.

7. decltype and References

One important feature of decltype is that it can preserve reference types.

Example 1: Reference Variable

#include <iostream> using namespace std; int main() { int number = 10; int& reference = number; decltype(reference) value = number; value = 50; cout << "Number: " << number << endl; cout << "Reference: " << reference << endl; return 0; }
Expected Output: 
Number: 50
Reference: 50

Since reference has type int&, decltype(reference) is also int&. Therefore, value becomes another reference to the same integer.

8. Important Difference: decltype(x) and decltype((x))

This is one of the most important rules of decltype.

When the expression inside decltype is an unparenthesized id-expression (such as a variable name), the result is the declared type of that entity.

For other expressions, including parenthesized variables, the result depends on the expression's value category:

  • Lvalue expression: T&
  • Xvalue expression: T&&
  • PRvalue expression: T

Example

#include <iostream> using namespace std; int main() { int number = 10; decltype(number) a = 20; decltype((number)) b = number; b = 50; cout << "Number: " << number << endl; cout << "a: " << a << endl; cout << "b: " << b << endl; return 0; }
Expected Output: 
Number: 50
a: 20
b: 50

Explanation:

  • decltype(number) produces int.
  • decltype((number)) produces int& because (number) is an lvalue expression.
  • Therefore, changing b also changes number.
Interview Tip: Remember the difference between decltype(x) and decltype((x)). Parentheses can change the deduced type.

9. decltype with Function Calls

The return type of a function call expression can be examined using decltype.

#include <iostream> using namespace std; double calculate() { return 25.5; } int main() { decltype(calculate()) result = calculate(); cout << "Result: " << result << endl; return 0; }
Expected Output: 
Result: 25.5

Since the function calculate() returns double, the variable result is also declared as double.

The function call inside decltype is not executed merely for type deduction. The call used as the initializer is executed.

10. decltype with auto

Both auto and decltype support type deduction, but they follow different rules.

int number = 100; auto a = number; decltype(number) b = number;

Both a and b are integers in this example.

However, their behavior differs when the source expression includes const qualification or references.

Feature auto decltype
Purpose Deduces type from an initializer Determines type of an expression or entity
Reference handling By-value deduction normally drops references Can preserve reference types
Const handling By-value deduction normally drops top-level const Can preserve const qualification
Syntax auto x = expression; decltype(expression) x;

11. Advantages of decltype

  • Determines the type of an expression without evaluating it.
  • Preserves reference and const information according to its rules.
  • Useful when working with complex expressions.
  • Helps write generic and template-based programs.
  • Can be used to determine function return expression types.
  • Reduces the need to manually specify complex types.

Limitations and Considerations

  • Its rules can be confusing for beginners.
  • Parentheses can change the resulting type.
  • It requires a valid expression or entity whose type can be determined.
  • It does not automatically create a variable initializer.

12. Common Mistakes

  • Confusing decltype with auto.
  • Forgetting that decltype(x) and decltype((x)) can produce different types.
  • Assuming decltype always removes const qualification.
  • Assuming decltype always produces a simple value type.
  • Forgetting that an lvalue expression produces an lvalue reference type.
  • Assuming an expression inside decltype is evaluated to determine its type.

15. Important Points to Remember

  • decltype determines the type of an expression or entity.
  • Type determination happens at compile time.
  • The expression is not evaluated merely for type deduction.
  • Unparenthesized variable names produce their declared types.
  • Other expressions follow value-category rules.
  • An lvalue expression produces an lvalue reference type.
  • decltype((x)) commonly produces T& for an ordinary variable x.
  • decltype is useful in generic and template-based programming.
