1. Introduction

Initialization is the process of giving an initial value to a variable when it is created. In C++, variables can be initialized using different initialization forms.

Proper initialization helps prevent unintended values and makes programs more reliable.

Learning Objectives:
  • Understand variable initialization.
  • Learn copy, direct and list initialization.
  • Understand the difference between initialization and assignment.
  • Learn how initialization works with different data types.
  • Understand narrowing conversions.

2. What Is Variable Initialization?

Variable initialization provides the initial value of an object at the time it is created.

Syntax

data_type variable_name = value;

Example

int age = 25; float percentage = 85.5f; char grade = 'A'; bool isPassed = true;

Here, each variable is created and given an initial value.

Variable Data Type Initial Value
age int 25
percentage float 85.5
grade char 'A'
isPassed bool true

3. Types of Variable Initialization

C++ supports several initialization forms. The most commonly used forms are copy initialization, direct initialization and list initialization.

A. Copy Initialization

Copy initialization uses the assignment-style equals sign when initializing a variable.

int number = 100; float price = 25.5f; char letter = 'A';

The initial value is specified after the equals sign. This is called copy initialization.

B. Direct Initialization

Direct initialization uses parentheses to provide the initial value.

int number(100); float price(25.5f); char letter('A');

The value is placed inside parentheses after the variable name.

C. Direct List Initialization

Direct list initialization uses curly braces to initialize a variable.

int number{100}; float price{25.5f}; char letter{'A'};

List initialization provides additional compile-time protection against narrowing conversions.

D. Copy List Initialization

Copy list initialization uses an equals sign followed by curly braces.

int number = {100}; float price = {25.5f}; char letter = {'A'};
Initialization Form Syntax
Copy initialization int a = 10;
Direct initialization int a(10);
Direct list initialization int a{10};
Copy list initialization int a = {10};
Recommendation: Prefer brace initialization in many situations because it helps detect unintended narrowing conversions.

4. Initialization vs Assignment

Initialization and assignment are different operations. Initialization gives an object its initial value when it is created. Assignment changes the value of an already existing object.

Example

#include <iostream> using namespace std; int main() { // Initialization int number = 10; cout << "Initial value: " << number << endl; // Assignment number = 50; cout << "Updated value: " << number << endl; return 0; }
Expected Output: 
Initial value: 10
Updated value: 50
Initialization Assignment
Occurs when an object is created. Operates on an existing object.
int x = 10; x = 20;
Provides the initial value. Changes the stored value.

5. Initialization of Different Data Types

Integer Initialization

int count = 10; int temperature{25};

Floating-Point Initialization

float percentage = 87.5f; double distance{125.75};

Character Initialization

char grade = 'A'; char symbol{'#'};

Boolean Initialization

bool isActive = true; bool isCompleted{false};

String Initialization

#include <string> std::string studentName = "Rahul"; std::string city{"Chandigarh"};
Character literals use single quotation marks, such as 'A'. String literals use double quotation marks, such as "Hello".

6. Default Initialization

Default initialization occurs when an object is created without an explicitly supplied initializer.

Example

int main() { int number; return 0; }

For a local integer variable with automatic storage duration, default initialization does not give it a predictable numeric value. Its value is indeterminate.

Do not read an uninitialized local built-in variable. Reading an indeterminate value can result in undefined behavior in common cases.

Safe Approach

int main() { int number{}; // Value is initialized to 0 return 0; }
Value initialization with empty braces initializes an integer to zero. For a boolean it produces false, and for a character type it produces the zero value.

7. List Initialization and Narrowing Conversion

List initialization helps prevent narrowing conversions. A narrowing conversion may lose information when a value is converted to another type.

Example: Narrowing Conversion

int number = 10.75;

This copy initialization is allowed, but the fractional part is discarded when the floating-point value is converted to an integer.

Brace Initialization

int number{10.75}; // Compilation error: narrowing

The compiler rejects this initialization because converting 10.75 to an integer would lose information.

Correct Example

int number{10}; double value{10.75};
List initialization rejects narrowing conversions in cases where the language defines the conversion as narrowing. This makes many accidental data-loss errors easier to detect.

8. Initializing Multiple Variables

Multiple variables of the same data type can be initialized in one statement.

Example

int a = 10, b = 20, c = 30;

Each variable receives its own initial value.

Using Separate Statements

int a{10}; int b{20}; int c{30};

Separate statements can make programs easier to read and maintain.

9. Complete C++ Program

This program demonstrates different initialization forms and displays the values.

#include <iostream> #include <string> using namespace std; int main() { // Copy initialization int age = 22; // Direct initialization float percentage(87.5f); // Direct list initialization char grade{'A'}; // Copy list initialization bool isPassed = {true}; // String initialization string name{"Amit"}; cout << "Student Details" << endl; cout << "Name: " << name << endl; cout << "Age: " << age << endl; cout << "Percentage: " << percentage << endl; cout << "Grade: " << grade << endl; cout << "Passed: " << boolalpha << isPassed << endl; return 0; }

Expected Output

Student Details
Name: Amit
Age: 22
Percentage: 87.5
Grade: A
Passed: true

Program Explanation

  1. age uses copy initialization.
  2. percentage uses direct initialization.
  3. grade uses direct list initialization.
  4. isPassed uses copy list initialization.
  5. name is initialized using braces.
  6. cout displays the initialized values.

10. Common Mistakes

1. Confusing Assignment with Initialization

int number; number = 10;

The first statement defines the variable. The second statement assigns a value; it is not initialization.

2. Reading an Uninitialized Variable

int number; cout << number; // Incorrect: do not read this value

Correct approach:

int number = 10; cout << number;

3. Narrowing Conversion with Braces

int value{15.8}; // Compilation error

Use a compatible value or an appropriate type.

4. Incorrect Character Initialization

char grade = "A"; // Incorrect: string literal char grade = 'A'; // Correct: character literal

12. Interview Questions

Q1. What is initialization in C++?

Initialization is the process of providing an initial value to an object when it is created.

Q2. What are the common initialization forms in C++?

Copy initialization, direct initialization, direct list initialization and copy list initialization.

Q3. What is copy initialization?

It initializes a variable using an equals sign, for example int x = 10;.

Q4. What is direct initialization?

It initializes a variable using parentheses, for example int x(10);.

Q5. What is list initialization?

It initializes an object using curly braces, for example int x{10};.

Q6. What is narrowing conversion?

Narrowing conversion is a conversion that may lose information, such as converting a fractional value to an integer.

Q7. What is the difference between initialization and assignment?

Initialization provides an object's initial value at creation. Assignment changes the value of an existing object.

Q8. What happens when an integer is initialized with empty braces?

It is value-initialized to zero, for example int number{};.

13. Quick Revision

  • Initialization provides an object's initial value.
  • Copy initialization uses =.
  • Direct initialization uses parentheses.
  • List initialization uses curly braces.
  • Brace initialization helps prevent narrowing conversions.
  • Assignment changes the value of an existing object.
  • int number{}; initializes an integer to zero.
  • Initialize variables before reading their values.
