1. Introduction to Enumerated Constants

An enumeration is a user-defined data type in C++ that consists of a set of named integral constants called enumerators.

Enumerations make programs easier to read by replacing numeric values with meaningful names.

Example: Instead of using numbers such as 0, 1, 2 and 3 to represent days of the week, we can use names such as Monday, Tuesday, Wednesday and Thursday.

2. Why Do We Use Enumerations?

  • To represent a fixed set of related named constants.
  • To make source code more readable.
  • To avoid unexplained numeric values in programs.
  • To represent states, directions, days, months and options.
  • To make related constant values easier to manage.

Without Enumeration

#include <iostream> using namespace std; int main() { int day = 2; if (day == 2) { cout << "Tuesday"; } return 0; }

Here, the value 2 represents Tuesday, but its meaning is not immediately clear.

With Enumeration

#include <iostream> using namespace std; enum Day { Monday, Tuesday, Wednesday, Thursday }; int main() { Day today = Tuesday; if (today == Tuesday) { cout << "Today is Tuesday"; } return 0; }
Output:
Today is Tuesday

The enumerator name Tuesday makes the program easier to understand than using the number 2.

3. Syntax of Enumeration

enum EnumName { constant1, constant2, constant3 };

Explanation:

  • enum is the keyword used to declare an enumeration.
  • EnumName is the name of the enumeration type.
  • constant1, constant2 and constant3 are enumerators.
  • Each enumerator represents a named constant.
  • The declaration ends with a semicolon.

4. Unscoped Enumeration (enum)

A traditional enumeration declared using enum is called an unscoped enumeration.

Its enumerator names are available in the surrounding scope. They can be used directly without qualifying them with the enumeration type name.

#include <iostream> using namespace std; enum TrafficLight { Red, Yellow, Green }; int main() { TrafficLight signal = Red; cout << "Signal value: " << signal; return 0; }
Output:
Signal value: 0

By default, the first enumerator has the value 0, the second has the value 1, and the third has the value 2.

Note: Unscoped enumerators can be implicitly converted to integral types. Their names may also conflict with other names in the same scope.

5. Default Values of Enumerators

If explicit values are not assigned, C++ automatically assigns integer values starting from zero.

enum Level { Low, Medium, High, Critical };
Enumerator Assigned Value
Low 0
Medium 1
High 2
Critical 3
Each subsequent enumerator receives the previous enumerator's value plus one, unless an explicit value changes the sequence.

6. Assigning Explicit Values

We can assign specific integral values to enumerators using the assignment operator.

#include <iostream> using namespace std; enum Status { Success = 1, Failure = 0, Pending = 5, Cancelled = 10 }; int main() { cout << "Success: " << Success << endl; cout << "Failure: " << Failure << endl; cout << "Pending: " << Pending << endl; cout << "Cancelled: " << Cancelled << endl; return 0; }
Output:
Success: 1 Failure: 0 Pending: 5 Cancelled: 10

Combining Explicit and Automatic Values

enum Number { A = 10, B, C, D = 20, E };
Enumerator Value Reason
A 10 Explicitly assigned
B 11 Previous value + 1
C 12 Previous value + 1
D 20 Explicitly assigned
E 21 Previous value + 1

7. Scoped Enumeration (enum class)

C++11 introduced enum class, also known as a scoped enumeration.

Unlike traditional enumerations, scoped enumerators belong to the scope of their enumeration type. They must be accessed using the enumeration name and the scope resolution operator ::.

#include <iostream> using namespace std; enum class Direction { North, South, East, West }; int main() { Direction move = Direction::North; if (move == Direction::North) { cout << "Moving North"; } return 0; }
Output:
Moving North

Important Features of enum class

  • Enumerator names are scoped inside the enumeration type.
  • Enumerators must be qualified, such as Direction::North.
  • Scoped enumerations do not implicitly convert to integers.
  • They provide stronger type safety.
  • They help prevent naming conflicts.

8. Specifying the Underlying Type

An enumeration can use a specified integral type as its underlying type.

The underlying type determines how the enumeration's values are represented. For scoped enumerations, the default underlying type is int.

#include <iostream> #include <cstdint> using namespace std; enum class ErrorCode : uint8_t { None = 0, InvalidInput = 1, FileNotFound = 2, AccessDenied = 3 }; int main() { ErrorCode error = ErrorCode::FileNotFound; cout << "Error code: " << static_cast<int>(error); return 0; }
Output:
Error code: 2
Note: The static_cast is used because a scoped enumeration cannot be directly printed as an integer using cout.

9. enum vs enum class

Feature enum enum class
Scope Unscoped Scoped
Enumerator access Red, Green Color::Red, Color::Green
Implicit integer conversion Allowed Not allowed
Type safety Less strict Stronger
Default underlying type Implementation-dependent integral type int
Introduced Traditional C++ C++11
Recommendation: Prefer enum class in modern C++ when you want clear scope and stronger type safety.

10. Practical Example: Days of the Week

#include <iostream> using namespace std; enum class Day { Monday = 1, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday }; int main() { Day today = Day::Wednesday; switch (today) { case Day::Monday: cout << "Monday"; break; case Day::Tuesday: cout << "Tuesday"; break; case Day::Wednesday: cout << "Wednesday"; break; case Day::Thursday: cout << "Thursday"; break; case Day::Friday: cout << "Friday"; break; case Day::Saturday: cout << "Saturday"; break; case Day::Sunday: cout << "Sunday"; break; } return 0; }
Output:
Wednesday

This example uses a scoped enumeration to represent the seven days of the week.

11. Common Mistakes

Mistake 1: Using an unqualified scoped enumerator

enum class Color { Red, Green, Blue }; // Incorrect: Color c = Red; // Correct: Color c = Color::Red;

Mistake 2: Directly converting enum class to int

enum class Level { Low, Medium, High }; Level value = Level::High; // Incorrect: // int number = value; // Correct: int number = static_cast<int>(value);

Mistake 3: Using duplicate enumerator names in the same scope

// This causes a naming conflict: enum First { Red }; enum Second { Red };

Traditional unscoped enumerators are introduced into the surrounding scope. Using the same name in that scope causes a conflict. Scoped enumerations avoid this problem.

Always qualify scoped enumerators and choose meaningful, non-conflicting names.

12. Important Points to Remember

  • An enumeration is a user-defined type containing named constants.
  • enum creates an unscoped enumeration.
  • enum class creates a scoped enumeration.
  • By default, the first enumerator has value 0.
  • Subsequent enumerators normally increase by one.
  • Explicit values can be assigned to enumerators.
  • Scoped enumerators require qualification using ::.
  • enum class provides stronger type safety.
  • static_cast can explicitly convert a scoped enumeration to an integer.

14. Interview Questions

Q1. What is an enumeration in C++?

An enumeration is a user-defined data type that contains a set of named integral constants called enumerators.

Q2. What is the default value of the first enumerator?

The first enumerator has the value 0 by default if no explicit value is assigned.

Q3. What is the difference between enum and enum class?

Traditional enum is unscoped and allows implicit conversion to integers. enum class is scoped and does not allow implicit conversion to integers.

Q4. What is an enumerator?

An enumerator is a named constant declared inside an enumeration.

Q5. Can we assign explicit values to enumerators?

Yes. We can assign integral values using the assignment operator during the enumeration declaration.

Q6. Why is enum class preferred in modern C++?

It provides scoped names, stronger type safety and helps prevent naming conflicts.

Q7. What is the purpose of an underlying type?

It specifies the integral type used to represent the enumeration values.
