1. Introduction

Input and output operations allow a C++ program to communicate with users. Input operations receive data, while output operations display information or results.

In a console-based program, the keyboard is commonly used for input and the screen is commonly used for output.

Definition: Input is the process of receiving data into a program. Output is the process of displaying or sending information from a program.

Header File

#include <iostream>

The iostream header provides standard input and output stream objects such as cin and cout.

2. Displaying Output Using cout

The cout object is used to display information on the standard output stream.

Syntax

cout << "Message";

The << operator is called the insertion operator.

Example Program

#include <iostream> using namespace std; int main() { cout << "Welcome to C++ Programming!"; return 0; }

Output

Welcome to C++ Programming!

3. Taking Input Using cin

The cin object is used to receive input from the standard input stream, usually the keyboard.

Syntax

cin >> variable;

The >> operator is called the extraction operator.

Example Program

#include <iostream> using namespace std; int main() { int age; cout << "Enter your age: "; cin >> age; cout << "Your age is: " << age; return 0; }

Example Output

Enter your age: 25 Your age is: 25
Remember: The input value must be compatible with the variable's data type.

4. Taking Multiple Inputs

Multiple variables can be read using a single cin statement. The extraction operator can be chained.

Syntax

cin >> variable1 >> variable2;

Example Program

#include <iostream> using namespace std; int main() { int a, b, c; cout << "Enter three numbers: "; cin >> a >> b >> c; cout << "First number: " << a << endl; cout << "Second number: " << b << endl; cout << "Third number: " << c << endl; return 0; }

Example Output

Enter three numbers: 10 20 30 First number: 10 Second number: 20 Third number: 30

5. Reading Different Data Types

C++ input streams can extract values into variables of different data types.

Example Program

#include <iostream> using namespace std; int main() { int age; float height; double salary; char grade; cout << "Enter age: "; cin >> age; cout << "Enter height: "; cin >> height; cout << "Enter salary: "; cin >> salary; cout << "Enter grade: "; cin >> grade; cout << "\n--- Details ---\n"; cout << "Age: " << age << endl; cout << "Height: " << height << endl; cout << "Salary: " << salary << endl; cout << "Grade: " << grade << endl; return 0; }

Example Output

Enter age: 22 Enter height: 5.8 Enter salary: 25000.50 Enter grade: A --- Details --- Age: 22 Height: 5.8 Salary: 25000.5 Grade: A

6. Reading a Full Line Using getline()

The extraction operator >> stops reading a string at whitespace. To read a complete line containing spaces, use the getline() function.

Syntax

getline(cin, stringVariable);

Example Program

#include <iostream> #include <string> using namespace std; int main() { string fullName; cout << "Enter your full name: "; getline(cin, fullName); cout << "Your full name is: " << fullName; return 0; }

Example Output

Enter your full name: Rahul Kumar Your full name is: Rahul Kumar
Important: getline() reads characters until a newline is encountered. It can therefore accept spaces within the input.

7. Mixing cin and getline()

When cin >> is followed by getline(), a common problem can occur. Formatted extraction leaves the newline character in the input stream. The next getline() may consume that leftover newline immediately.

Incorrect Example

#include <iostream> #include <string> using namespace std; int main() { int age; string name; cout << "Enter age: "; cin >> age; cout << "Enter name: "; getline(cin, name); cout << "Age: " << age << endl; cout << "Name: " << name << endl; return 0; }

Correct Example

Use cin.ignore() to discard the remaining characters through the newline before calling getline().

#include <iostream> #include <string> #include <limits> using namespace std; int main() { int age; string name; cout << "Enter age: "; cin >> age; cin.ignore(numeric_limits<streamsize>::max(), '\n'); cout << "Enter full name: "; getline(cin, name); cout << "Age: " << age << endl; cout << "Name: " << name << endl; return 0; }

Example Output

Enter age: 22 Enter full name: Rahul Kumar Age: 22 Name: Rahul Kumar
Remember: This form of cin.ignore() discards the rest of the current input line. It is useful when the input operation before getline() is expected to finish at a newline.

8. Displaying Multiple Values

The insertion operator can be chained to display multiple variables, strings, and expressions in one statement.

Example Program

#include <iostream> using namespace std; int main() { int a = 10; int b = 20; cout << "First number: " << a << ", Second number: " << b << ", Sum: " << a + b << endl; return 0; }

Output

First number: 10, Second number: 20, Sum: 30

9. Formatting Output

C++ provides manipulators to control how output is displayed. Common manipulators are available through the <iomanip> header.

Manipulator Purpose
setw() Sets the minimum field width for the next output item.
setprecision() Controls floating-point precision.
fixed Displays floating-point values in fixed-point notation.
scientific Displays floating-point values in scientific notation.
setfill() Sets the fill character used with field width.
left / right Controls field alignment.

Example Program

#include <iostream> #include <iomanip> using namespace std; int main() { double price = 125.5678; cout << fixed << setprecision(2); cout << "Price: " << price << endl; cout << setw(10) << 100 << endl; cout << setfill('*') << setw(10) << 100 << endl; return 0; }

Output

Price: 125.57 100 *******100
Note: setw() affects the next formatted field only. Other manipulators, such as fixed and setprecision(), generally remain active until changed.

10. Performing Calculations with Input

Input values can be used directly in arithmetic expressions to calculate results.

Example: Addition of Two Numbers

#include <iostream> using namespace std; int main() { int num1, num2, sum; cout << "Enter first number: "; cin >> num1; cout << "Enter second number: "; cin >> num2; sum = num1 + num2; cout << "Sum = " << sum << endl; return 0; }

Example Output

Enter first number: 15 Enter second number: 25 Sum = 40

Other Arithmetic Operations

Addition +
Subtraction -
Multiplication *
Division /
Modulus %

11. Checking Input Errors

Input operations can fail when the entered data cannot be converted to the requested type. C++ streams provide state information to detect such failures.

Example Program

#include <iostream> using namespace std; int main() { int number; cout << "Enter an integer: "; if (cin >> number) { cout << "You entered: " << number << endl; } else { cerr << "Error: Invalid integer input." << endl; } return 0; }

Example Output 1: Valid Input

Enter an integer: 50 You entered: 50

Example Output 2: Invalid Input

Enter an integer: abc Error: Invalid integer input.
Important: A stream can enter a failure state when extraction fails. Further input operations require handling or clearing that state appropriately.

12. Common Mistakes

  • Forgetting to include the required header files.
  • Using the wrong operator with cin or cout.
  • Using an undeclared variable for input.
  • Expecting cin >> string to read a complete line.
  • Forgetting to handle the newline before getline().
  • Using an incompatible input value for a variable.
  • Ignoring stream failure after invalid input.
  • Forgetting to include iomanip for formatting manipulators.
  • Using setw() and expecting it to affect every later field.

15. Important Points to Remember

  • cin is used for standard input.
  • cout is used for standard output.
  • >> extracts data from an input stream.
  • << inserts data into an output stream.
  • getline() reads a complete line containing spaces.
  • cin.ignore() can discard leftover input characters.
  • endl inserts a newline and flushes the stream.
  • \n inserts a newline without explicitly flushing.
  • iomanip provides useful output formatting manipulators.
  • Always check input operations when invalid data is possible.
