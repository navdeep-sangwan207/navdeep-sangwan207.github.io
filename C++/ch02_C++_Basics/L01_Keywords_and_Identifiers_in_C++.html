1. Introduction

Every C++ program contains words and names that help the compiler understand the instructions written by the programmer. Two important elements of C++ syntax are keywords and identifiers.

  • Keywords are reserved words that have predefined meanings in the C++ language.
  • Identifiers are user-defined names given to program elements such as variables, functions, classes and objects.
Learning Objective: Understand the purpose of C++ keywords, identify valid and invalid identifiers, and distinguish between the two.

2. What are Keywords in C++?

Keywords are reserved words in C++ that have special meanings defined by the language. They are used to write statements, declare data types, control program execution and define classes and functions.

Since keywords have predefined meanings, they cannot be used as ordinary user-defined identifiers.

Examples of C++ Keywords

int float double char if else for while do switch case break continue return class public private protected void const static sizeof new delete

Example Program

C++ Program
#include <iostream> using namespace std; int main() { int age = 25; if (age >= 18) { cout << "Eligible to vote"; } return 0; }
Expected Output: 
Eligible to vote

Explanation

Keyword Purpose
int Declares an integer variable.
if Executes a statement based on a condition.
return Returns control from a function.
void Represents the absence of a value in certain contexts.
class Declares a class.
const Declares an object that cannot be modified through that name.

3. Characteristics of Keywords

  • Keywords have predefined meanings in C++.
  • They are reserved by the language.
  • They cannot be used as ordinary variable or function names.
  • They are generally written in lowercase.
  • They form the basic syntax of C++ programs.
C++ is case-sensitive. For example, int is a keyword, but Int and INT are not the same keyword.

4. What are Identifiers in C++?

An identifier is a name created by the programmer to identify a program element. Identifiers make it possible to refer to variables, functions, classes, objects and other named entities.

Examples of Identifiers

age total studentName calculateSum Employee number1 accountBalance

Example Program

C++ Program
#include <iostream> using namespace std; int main() { int marks = 85; int bonus = 5; int totalMarks = marks + bonus; cout << "Total Marks = " << totalMarks; return 0; }
Expected Output: 
Total Marks = 90

Explanation

Identifier Represents
main Function name.
marks Variable storing marks.
bonus Variable storing bonus marks.
totalMarks Variable storing the calculated total.

5. Rules for Naming Identifiers

C++ follows specific rules when creating identifiers. An identifier must follow these rules to be valid.

  1. An identifier can contain letters (A-Z, a-z), digits (0-9) and underscores (_).
  2. An identifier must begin with a letter or an underscore.
  3. An identifier cannot begin with a digit.
  4. Spaces are not allowed in identifiers.
  5. Special symbols such as @, #, %, ! and - are not allowed as identifier characters.
  6. A C++ keyword cannot be used as an ordinary identifier.
  7. C++ identifiers are case-sensitive.

Valid and Invalid Identifiers

Identifier Validity Reason
student Valid Starts with a letter.
student_name Valid Underscore is allowed.
marks2026 Valid Digits are allowed after the first character.
_count Valid in basic syntax Starts with an underscore, but some underscore names are reserved by the implementation.

student name Invalid Spaces are not allowed.

price@value Invalid @ is not allowed.
Important: Although some names beginning with underscores are syntactically valid, many such names are reserved for the implementation. Avoid using leading underscores in your own identifiers, especially names containing double underscores.

6. Case Sensitivity in C++

C++ is a case-sensitive programming language. This means uppercase and lowercase letters are treated as different characters in identifiers.

C++ Program
#include <iostream> using namespace std; int main() { int number = 10; int Number = 20; int NUMBER = 30; cout << number << endl; cout << Number << endl; cout << NUMBER << endl; return 0; }
Expected Output: 
10
20
30

Here, number, Number and NUMBER are three different identifiers.

9. Common Mistakes

  • Using a keyword as a variable name.
  • Starting an identifier with a digit.
  • Using spaces or unsupported special characters in identifiers.
  • Assuming uppercase and lowercase identifiers are identical.
  • Choosing unclear names that make code difficult to understand.
  • Using reserved underscore-based names for personal identifiers.

10. Important Points to Remember

  • Keywords are reserved words with predefined meanings.
  • Identifiers are names created by programmers.
  • Keywords cannot be used as ordinary identifiers.
  • Identifiers can contain letters, digits and underscores.
  • An identifier cannot begin with a digit.
  • Spaces and most special characters are not allowed.
  • C++ is case-sensitive.
  • Meaningful identifiers improve code readability.

12. Interview Questions

Q1. What are keywords in C++?

Keywords are reserved words that have predefined meanings in the C++ language.

Q2. What are identifiers?

Identifiers are user-defined names used to identify variables, functions, classes and other program elements.

Q3. Can a keyword be used as a variable name?

No. A keyword cannot be used as an ordinary user-defined identifier.

Q4. Can an identifier start with a digit?

No. An identifier must begin with a letter or underscore.

Q5. Is C++ case-sensitive?

Yes. Uppercase and lowercase letters are treated differently.

Q6. What is the difference between a keyword and an identifier?

A keyword is reserved by the language, whereas an identifier is a name created by the programmer.

Q7. Can an identifier contain an underscore?

Yes. An underscore can be used in an identifier, subject to the language's reserved-name rules.

Q8. Why should meaningful identifiers be used?

Meaningful identifiers improve program readability, understanding and maintainability.
