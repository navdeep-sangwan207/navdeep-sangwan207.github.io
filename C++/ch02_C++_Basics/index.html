Chapter Overview

This chapter introduces the fundamental concepts required to write C++ programs. You will learn about keywords, identifiers, variables, constants, macros, enumerated constants, literals and fundamental data types.

You will also understand basic input and output using iostream, type conversion, modern type specifiers such as auto and decltype, and the use of comments in C++.

These concepts form the foundation for understanding operators, control structures, functions and object-oriented programming.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand C++ keywords and identifiers.
  • Follow naming conventions and identifier best practices.
  • Declare, define and initialize variables.
  • Understand constant variables, macros and enumerations.
  • Identify different types of literal constants.
  • Understand the need for data types in C++.
  • Understand integer ranges and fundamental data types.
  • Perform basic input and output operations using iostream.
  • Understand implicit and explicit type conversion.
  • Use auto and decltype for type deduction.
  • Write and understand comments in C++ programs.
