1. Introduction

Every integer data type in C++ has a specific range of values that it can represent. The range depends on the number of bits used to represent the type and whether the type is signed or unsigned.

Understanding integer ranges helps programmers select suitable data types and avoid overflow and incorrect results.

Important: The exact size and range of integer types can vary between compilers and platforms. C++ specifies minimum requirements, not one universal size for every type.

2. Signed and Unsigned Integers

Signed Integer

A signed integer can represent both negative and positive numbers, including zero.

int temperature = -10; int balance = 500; int difference = 0;

Unsigned Integer

An unsigned integer represents only non-negative values, including zero. It does not represent negative numbers.

unsigned int age = 25; unsigned int count = 100; unsigned int total = 0;
Feature Signed Integer Unsigned Integer
Negative values Supported Not supported
Zero Supported Supported
Positive values Supported Supported
Typical use Temperature, balance, difference Non-negative counts and sizes

3. Integer Data Types and Their Ranges

C++ provides several integer types. Their ranges are related to their storage size and representation.

Data Type Minimum Standard Size Purpose
short At least 16 bits Small integer values
int At least 16 bits General-purpose integers
long At least 32 bits Larger integer values
long long At least 64 bits Very large integer values

Each of these types can also have an unsigned form, such as unsigned short, unsigned int, unsigned long, and unsigned long long.

Note: Do not assume that int always occupies 4 bytes or that long always has the same size on every operating system.

4. How Integer Range Is Calculated

For an unsigned integer type with N value bits, the range is:

Unsigned range:

0 to (2N - 1)

For a signed integer type using the standard binary representation with N value bits and one sign bit, the commonly used range is:

Signed range:

−2N to (2N − 1), where N is the number of value bits excluding the sign bit.

For example, a conventional 8-bit unsigned integer has a range of 0 to 255. A conventional 8-bit signed integer has a range of -128 to 127.

Remember: The number of bits and the representation determine the range. Modern C++ signed integers use the two's-complement representation.

5. Checking Integer Range Using numeric_limits

C++ provides the numeric_limits class template in the <limits> header. It allows us to obtain the minimum and maximum values supported by a type.

Syntax

std::numeric_limits<data_type>::min() std::numeric_limits<data_type>::max()

Example Program

#include <iostream> #include <limits> using namespace std; int main() { cout << "int minimum: " << numeric_limits<int>::min() << endl; cout << "int maximum: " << numeric_limits<int>::max() << endl; cout << "unsigned int minimum: " << numeric_limits<unsigned int>::min() << endl; cout << "unsigned int maximum: " << numeric_limits<unsigned int>::max() << endl; return 0; }

Expected Result

Typical output on a system with 32-bit int:
int minimum: -2147483648 int maximum: 2147483647 unsigned int minimum: 0 unsigned int maximum: 4294967295

The exact values depend on the implementation. The example shows the commonly used 32-bit integer ranges.

6. Checking Storage Size Using sizeof()

The sizeof() operator returns the storage size of a data type or object in bytes.

Example Program

#include <iostream> using namespace std; int main() { cout << "Size of short: " << sizeof(short) << " bytes" << endl; cout << "Size of int: " << sizeof(int) << " bytes" << endl; cout << "Size of long: " << sizeof(long) << " bytes" << endl; cout << "Size of long long: " << sizeof(long long) << " bytes" << endl; return 0; }

Expected Result

Example output on a common platform:
Size of short: 2 bytes Size of int: 4 bytes Size of long: 4 bytes Size of long long: 8 bytes
Note: This is an example, not a guaranteed output. The actual sizes depend on the compiler and platform.

7. Integer Overflow

Integer overflow occurs when an arithmetic operation produces a value outside the representable range of the integer type.

Example: Unsigned Integer Wraparound

#include <iostream> #include <limits> using namespace std; int main() { unsigned int number = numeric_limits<unsigned int>::max(); cout << "Maximum value: " << number << endl; number = number + 1; cout << "After adding 1: " << number << endl; return 0; }

Expected Result

Typical output with a 32-bit unsigned int:
Maximum value: 4294967295 After adding 1: 0

Unsigned integer arithmetic is performed modulo 2N, where N is the number of value bits.

Important: Signed integer overflow is undefined behavior in C++. Do not depend on it wrapping around to a negative value.

8. Choosing the Correct Integer Type

Requirement Possible Type
General integer calculations int
Small integer values short
Non-negative counts unsigned type, where appropriate
Large integer values long long
Exact-width integer requirements Types from <cstdint>, when available
Best practice: Choose a type based on the actual range required by the program. For fixed-width requirements, consider types such as int32_t and uint64_t from <cstdint> when the implementation provides them.

9. Common Mistakes

  • Assuming every compiler uses the same integer sizes.
  • Using an unsigned type when negative values are required.
  • Ignoring the possibility of integer overflow.
  • Assuming signed integer overflow wraps around.
  • Confusing the storage size of a type with its value range.
  • Using a type without checking the maximum expected value.

12. Important Points to Remember

  • Integer types have specific representable value ranges.
  • Signed integers support negative and positive values.
  • Unsigned integers represent non-negative values.
  • Integer ranges depend on the number of value bits.
  • numeric_limits provides minimum and maximum values.
  • sizeof() returns storage size in bytes.
  • Unsigned overflow follows modulo arithmetic.
  • Signed integer overflow results in undefined behavior.
  • Use a data type that can safely represent the required values.
