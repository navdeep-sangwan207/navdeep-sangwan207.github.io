1. Introduction

A literal is a fixed value written directly in a C++ program. Literals are used to represent numbers, characters, text, logical values and null pointers.

Every literal has a type determined by the C++ language rules. Understanding literal types helps us write correct expressions, assignments and calculations.

Example: In int age = 25;, the value 25 is an integer literal, and in double price = 99.50;, the value 99.50 is a floating-point literal.

2. Classification of Literals in C++

Type Description Examples
Integer Whole-number values 10, 250, 0x1A
Floating-point Fractional or scientific values 3.14, 2.5f
Character Individual character values 'A', 'x'
String Sequences of characters "Hello", "C++"
Boolean Logical values true, false
Null pointer Represents a null pointer nullptr

3. Integer Literals

Integer literals represent whole numbers without a fractional part. They can be written using different number systems.

3.1 Decimal Literals

Decimal literals use base 10 and contain digits from 0 to 9.

int a = 10; int b = 250; int c = 1000; cout << a << endl; cout << b << endl; cout << c;
Output:
10 250 1000

3.2 Octal Literals

Octal literals use base 8 and begin with a leading zero. They contain digits from 0 to 7.

int number = 012; cout << number;
Output:
10

The octal value 012 is equal to decimal 10.

3.3 Hexadecimal Literals

Hexadecimal literals use base 16 and begin with 0x or 0X. They use digits 0–9 and letters A–F.

int number = 0x1A; cout << number;
Output:
26

3.4 Binary Literals

Binary literals use base 2 and begin with 0b or 0B. They are supported from C++14.

int number = 0b1010; cout << number;
Output:
10

Comparison of Number Systems

Number System Base Prefix Example Decimal Value
Decimal 10 None 10 10
Octal 8 0 012 10
Hexadecimal 16 0x 0xA 10
Binary 2 0b 0b1010 10
A leading zero indicates octal notation. For example, 010 represents decimal 8, not decimal 10.

4. Integer Literal Suffixes

Integer literal suffixes can specify signedness and integer length. The compiler uses them to determine the literal's type.

Suffix Meaning Example
U or u Unsigned integer 100U
L or l Long integer 100L
LL or ll Long long integer 100LL
UL or ul Unsigned long integer 100UL
ULL or ull Unsigned long long integer 100ULL

Example Program

#include <iostream> using namespace std; int main() { unsigned int a = 100U; long int b = 500000L; long long int c = 9000000000LL; unsigned long long int d = 100000ULL; cout << a << endl; cout << b << endl; cout << c << endl; cout << d; return 0; }
Output:
100 500000 9000000000 100000
The actual sizes of integer types depend on the implementation. Do not assume that long always has the same size on every platform.

5. Floating-Point Literals

Floating-point literals represent values containing a fractional part or values written in scientific notation.

Examples

double a = 3.14; double b = 25.75; double c = 2.5e3; double d = 4.5E-2;

Scientific notation examples:

  • 2.5e3 = 2.5 × 10³ = 2500
  • 4.5E-2 = 4.5 × 10⁻² = 0.045

Floating-Point Suffixes

Suffix Type Example
f or F float 3.14f
No suffix double 3.14
l or L long double 3.14L

Example Program

#include <iostream> using namespace std; int main() { float temperature = 36.5f; double distance = 125.75; long double measurement = 987.654L; cout << temperature << endl; cout << distance << endl; cout << measurement; return 0; }
Output:
36.5 125.75 987.654

6. Character Literals

Character literals represent individual characters and are generally written inside single quotation marks.

char grade = 'A'; char letter = 'b'; char digit = '5'; char symbol = '#';

Character Literal Examples

Literal Description
'A' Uppercase character
'z' Lowercase character
'7' Digit character
'#' Special character
'\n' Newline character

Example Program

#include <iostream> using namespace std; int main() { char grade = 'A'; cout << "Grade: " << grade; return 0; }
Output:
Grade: A
A normal character literal such as 'A' has type char. A wide character literal uses the prefix L, such as L'A'.

7. String Literals

String literals represent sequences of characters and are written inside double quotation marks.

"Hello" "C++ Programming" "Welcome to NS Learning Hub"

A string literal has an array type containing its characters and a terminating null character. In most expressions, the array converts to a pointer to its first element.

Example Program

#include <iostream> using namespace std; int main() { cout << "Welcome to C++ Programming"; return 0; }
Output:
Welcome to C++ Programming

String Literal Prefixes

Prefix Literal Category Example
None Ordinary string literal "Hello"
L Wide string literal L"Hello"
u8 UTF-8 string literal u8"Hello"
u UTF-16 string literal u"Hello"
U UTF-32 string literal U"Hello"
String literal prefixes determine the character type used to represent the string. The u8 literal has type based on char in C++20 and later, and char8_t was introduced in C++20.

8. Boolean Literals

C++ provides two Boolean literals:

  • true represents logical true.
  • false represents logical false.

Example Program

#include <iostream> using namespace std; int main() { bool isActive = true; bool isComplete = false; cout << isActive << endl; cout << isComplete; return 0; }
Output:
1 0

Using boolalpha

#include <iostream> using namespace std; int main() { cout << boolalpha; cout << true << endl; cout << false; return 0; }
Output:
true false

9. Null Pointer Literal

nullptr is the null pointer literal introduced in C++11. It represents a pointer that does not point to an object or function.

Example Program

#include <iostream> using namespace std; int main() { int* ptr = nullptr; if (ptr == nullptr) { cout << "Pointer is null"; } return 0; }
Output:
Pointer is null
Prefer nullptr over NULL or integer literal 0 when representing a null pointer in modern C++.

10. Escape Sequence Literals

Escape sequences are special character combinations beginning with a backslash. They represent characters that cannot conveniently be written directly.

Escape Sequence Meaning
\n New line
\t Horizontal tab
\\ Backslash
\' Single quotation mark
\" Double quotation mark
\r Carriage return
\b Backspace
\0 Null character

Example Program

#include <iostream> using namespace std; int main() { cout << "Hello\nWorld\n"; cout << "Name:\tNavdeep\n"; cout << "C:\\Program Files"; return 0; }
Output:
Hello World Name: Navdeep C:\Program Files

11. Raw String Literals

Raw string literals allow backslashes and other characters to be written without interpreting ordinary escape sequences.

They begin with R"( and end with )".

Example Program

#include <iostream> using namespace std; int main() { cout << R"(C:\Users\Student\Documents)"; return 0; }
Output:
C:\Users\Student\Documents

Raw strings are useful for file paths, regular expressions and text containing multiple backslashes.

12. User-Defined Literals

C++11 introduced user-defined literals. They allow programmers to define custom literal suffixes for their own types or operations.

A user-defined literal is created by defining a literal operator function with a suffix beginning with an underscore.

Example Program

#include <iostream> using namespace std; constexpr unsigned long long operator"" _km(unsigned long long value) { return value * 1000; } int main() { auto distance = 5_km; cout << distance << " meters"; return 0; }
Output:
5000 meters
The suffix _km is user-defined. It converts the supplied kilometre value into metres in this example. User-defined suffixes must begin with an underscore.

13. Comparison of Literal Types

Literal Example Typical Type
Integer 100 int if representable
Unsigned integer 100U unsigned int
Long integer 100L long int if representable
Floating-point 3.14 double
Float 3.14f float
Character 'A' char
Boolean true bool
Null pointer nullptr std::nullptr_t
The type of an integer literal depends on its base, suffix and value. The table shows common cases, not every possible literal type rule.

14. Common Mistakes

Mistake 1: Confusing character and string literals

char letter = 'A'; // Character literal const char* text = "A"; // String literal

Mistake 2: Confusing octal and decimal numbers

int a = 10; // Decimal 10 int b = 010; // Octal 8

Mistake 3: Forgetting the floating-point suffix

float a = 3.14f; double b = 3.14;

Mistake 4: Using zero instead of nullptr

int* ptr = nullptr;

Mistake 5: Using an invalid binary digit

int a = 0b1010; // Valid // int b = 0b102; // Invalid binary digit

15. Important Points to Remember

  • Integer literals represent whole-number values.
  • Decimal, octal, hexadecimal and binary are integer literal notations.
  • Floating-point literals represent fractional or scientific values.
  • Character literals use single quotation marks.
  • String literals use double quotation marks.
  • Boolean literals are true and false.
  • nullptr represents a null pointer.
  • Literal suffixes can influence the type of a literal.
  • Escape sequences represent special characters.
  • Raw string literals do not interpret ordinary escape sequences.
  • User-defined literals allow custom suffixes.

17. Interview Questions

Q1. What are the different types of literals in C++?

Integer, floating-point, character, string, Boolean and null pointer literals.

Q2. What is the difference between decimal and octal literals?

Decimal literals use base 10, while octal literals use base 8 and begin with a leading zero.

Q3. What is a hexadecimal literal?

It is an integer literal represented in base 16 and begins with 0x or 0X.

Q4. What is the type of 3.14?

It is a double literal by default.

Q5. What is the difference between 3.14f and 3.14?

3.14f is a float literal, while 3.14 is a double literal.

Q6. What is nullptr?

It is a null pointer literal introduced in C++11.

Q7. What is a raw string literal?

It is a string literal in which ordinary escape sequences are not interpreted.

Q8. What are user-defined literals?

They allow programmers to define custom literal suffixes and associated operations.

Q9. What is the purpose of an integer suffix?

It specifies or influences the integer literal type, including signedness and length.
