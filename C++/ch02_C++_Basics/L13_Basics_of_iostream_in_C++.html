1. Introduction to iostream

The iostream library is a standard C++ library used to perform input and output operations. It provides facilities for reading data from input streams and writing data to output streams.

Using iostream, a program can accept information from the keyboard and display results on the screen.

Definition: iostream stands for Input/Output Stream. It provides stream-based input and output facilities in C++.

Header File

#include <iostream>

The <iostream> header provides standard stream objects such as cin, cout, cerr, and clog.

2. What Is a Stream?

A stream is a sequence of data flowing between a program and an input or output source.

Stream Type Direction Purpose
Input Stream Source to program Receives data.
Output Stream Program to destination Sends data.
Example: When a user enters a number using the keyboard, the data travels through an input stream. When the program displays a result, it uses an output stream.

3. Standard Stream Objects

C++ provides four commonly used standard stream objects through the iostream library.

Stream Object Purpose Standard Stream
cin Standard input stdin
cout Standard output stdout
cerr Standard error output stderr
clog Standard logging output stderr

3.1 cout – Standard Output

cout is used to display information on the standard output device, usually the console.

#include <iostream> using namespace std; int main() { cout << "Welcome to C++ Programming!"; return 0; }
Output:
Welcome to C++ Programming!

3.2 cin – Standard Input

cin is used to receive input from the standard input device, usually the keyboard.

#include <iostream> using namespace std; int main() { int age; cout << "Enter your age: "; cin >> age; cout << "Your age is: " << age; return 0; }
Example output (input: 25):
Enter your age: 25 Your age is: 25

3.3 cerr – Standard Error Output

cerr is used to display error messages. It is an unbuffered standard error stream, so output is generally sent immediately.

#include <iostream> using namespace std; int main() { cerr << "Error: Invalid input!"; return 0; }
Output:
Error: Invalid input!

3.4 clog – Standard Logging Output

clog is used to display logging and diagnostic information. Unlike cerr, clog is buffered.

#include <iostream> using namespace std; int main() { clog << "Program execution started."; return 0; }
Output:
Program execution started.

4. Insertion Operator (<<)

The insertion operator << is used with output streams to send data to the output destination.

Syntax

cout << value;

Example Program

#include <iostream> using namespace std; int main() { int age = 22; float marks = 85.5f; cout << "Age: " << age << endl; cout << "Marks: " << marks << endl; return 0; }

Output

Age: 22 Marks: 85.5
Remember: The insertion operator can be chained to display multiple values in a single statement.

5. Extraction Operator (>>)

The extraction operator >> is used with input streams to receive data from the input source and store it in variables.

Syntax

cin >> variable;

Example Program

#include <iostream> using namespace std; int main() { int number; cout << "Enter a number: "; cin >> number; cout << "You entered: " << number; return 0; }

Example Output

Enter a number: 100 You entered: 100
Remember: The extraction operator reads formatted input. For example, when reading a string into a std::string variable, it stops at whitespace.

6. Using endl and Newline Characters

C++ provides different ways to move output to a new line.

Using endl

endl inserts a newline and flushes the output stream.

cout << "Hello" << endl; cout << "World";

Using \n

The newline escape sequence \n moves output to the next line without explicitly flushing the stream.

cout << "Hello\n"; cout << "World";

Output

Hello World
Best practice: Use \n for ordinary line breaks. Use endl when you specifically need to flush the output stream.

7. Using Multiple Input and Output Operations

Multiple variables can be read using one cin statement, and multiple values can be displayed using one cout statement.

Example Program

#include <iostream> using namespace std; int main() { int a, b; cout << "Enter two numbers: "; cin >> a >> b; cout << "First number: " << a << endl; cout << "Second number: " << b << endl; cout << "Sum: " << a + b << endl; return 0; }

Example Output

Enter two numbers: 10 20 First number: 10 Second number: 20 Sum: 30

8. Using the std Namespace

Standard C++ library names such as cin, cout, and endl belong to the std namespace.

There are two common ways to access these names.

Method 1: Using std::

#include <iostream> int main() { std::cout << "Hello C++\n"; return 0; }

Method 2: Using namespace std

#include <iostream> using namespace std; int main() { cout << "Hello C++\n"; return 0; }
Best practice: Using explicit std:: qualification is often preferred in larger projects because it reduces naming conflicts.

9. Complete Program: Student Information

This program accepts a student's name, age, and marks and displays the entered information.

Program

#include <iostream> #include <string> using namespace std; int main() { string name; int age; float marks; cout << "Enter student name: "; cin >> name; cout << "Enter age: "; cin >> age; cout << "Enter marks: "; cin >> marks; cout << "\n--- Student Information ---\n"; cout << "Name: " << name << endl; cout << "Age: " << age << endl; cout << "Marks: " << marks << endl; return 0; }

Example Output

Enter student name: Rahul Enter age: 21 Enter marks: 88.5 --- Student Information --- Name: Rahul Age: 21 Marks: 88.5
Note: cin reads only one word into a string variable. To accept a full name containing spaces, use getline(), which is covered in the following input/output lessons.

10. Common Mistakes

  • Forgetting to include the iostream header.
  • Using << instead of >> for keyboard input.
  • Using >> instead of << for output.
  • Forgetting the semicolon after a statement.
  • Using cin without declaring the destination variable.
  • Forgetting std:: when not using namespace std.
  • Assuming cin reads an entire line into a string.
  • Using endl unnecessarily for every line break.

13. Important Points to Remember

  • iostream is used for standard input and output operations.
  • Include the iostream header to use standard stream objects.
  • cin reads input from the standard input stream.
  • cout writes output to the standard output stream.
  • cerr is used for error messages and is unbuffered.
  • clog is used for logging and is buffered.
  • << is the insertion operator.
  • >> is the extraction operator.
  • endl inserts a newline and flushes the stream.
  • \n inserts a newline without explicitly flushing.
  • Standard library objects belong to the std namespace.
