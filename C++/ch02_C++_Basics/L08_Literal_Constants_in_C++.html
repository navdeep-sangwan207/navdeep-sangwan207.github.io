1. Introduction to Literal Constants

A literal is a fixed value written directly in the source code of a program. It represents a value that is used by the program without requiring a variable name.

Literals are also commonly called literal constants because their written values are fixed.

Example: In int age = 25;, the value 25 is an integer literal.
#include <iostream> using namespace std; int main() { cout << 100 << endl; cout << 25.5 << endl; cout << 'A' << endl; cout << "Hello C++"; return 0; }
Output:
100 25.5 A Hello C++

2. Characteristics of Literals

  • Literals are written directly in source code.
  • They represent fixed values.
  • Every literal has a type determined by C++ rules.
  • Literals can be used in expressions and assignments.
  • Suffixes can be used to specify or influence certain literal types.

Example

int number = 50; double price = 99.99; char grade = 'A'; cout << number << endl; cout << price << endl; cout << grade;

Here, 50, 99.99 and 'A' are literals.

3. Types of Literals in C++

C++ provides several categories of literals. Common categories include:

Literal Type Examples
Integer literal 10, 250, -45
Floating-point literal 3.14, 2.5f, 6.02e23
Character literal 'A', 'x', '7'
String literal "Hello", "C++"
Boolean literal true, false
Null pointer literal nullptr
These literal categories are explained in greater detail in the following lessons.

4. Integer Literals

Integer literals represent whole-number values without a fractional part.

Decimal Integer Literals

Decimal literals use base 10 and contain digits from 0 to 9.

int a = 10; int b = 250; int c = 1000;

Octal Integer Literals

Octal literals use base 8 and begin with the prefix 0. They use digits from 0 to 7.

int value = 012; cout << value;
Output:
10

The octal number 012 represents decimal value 10.

Hexadecimal Integer Literals

Hexadecimal literals use base 16 and begin with 0x or 0X.

int value = 0x1A; cout << value;
Output:
26

Binary Integer Literals

Binary literals use base 2 and begin with 0b or 0B. They are supported from C++14.

int value = 0b1010; cout << value;
Output:
10
Number System Prefix Example Decimal Value
Decimal None 10 10
Octal 0 012 10
Hexadecimal 0x 0xA 10
Binary 0b 0b1010 10
Important: A leading zero in an integer literal indicates octal notation. For example, 010 represents decimal 8, not decimal 10.

5. Floating-Point Literals

Floating-point literals represent numbers that contain a fractional part or are written using scientific notation.

Examples

double a = 3.14; double b = 25.75; double c = 2.5e3;

Scientific notation uses e or E to represent powers of 10.

Example: 2.5e3 means 2.5 × 10³ = 2500.

Floating-Point Suffixes

Suffix Meaning Example
f or F float 3.14f
No suffix double 3.14
l or L long double 3.14L
float temperature = 36.5f; double distance = 125.75; long double measurement = 987.654L;

6. Character Literals

Character literals represent individual characters and are written inside single quotation marks.

char grade = 'A'; char letter = 'b'; char digit = '5'; char symbol = '#';

A normal character literal such as 'A' has type char in C++.

Character Literal vs Integer Literal

char ch = 'A'; int number = 65; cout << ch << endl; cout << number;
Output:
A 65

A character literal and an integer literal are different kinds of literals, even when a character has a corresponding numeric character encoding.

7. String Literals

A string literal represents a sequence of characters and is written inside double quotation marks.

"Hello" "C++ Programming" "Welcome to NS Learning Hub"

Example Program

#include <iostream> using namespace std; int main() { cout << "Welcome to C++ Programming"; return 0; }
Output:
Welcome to C++ Programming
A string literal is not the same as a character literal. 'A' is a character literal, whereas "A" is a string literal.

8. Boolean Literals

C++ provides two Boolean literals:

  • true represents logical true.
  • false represents logical false.
#include <iostream> using namespace std; int main() { bool isActive = true; bool isComplete = false; cout << isActive << endl; cout << isComplete; return 0; }
Output:
1 0

By default, cout displays true as 1 and false as 0. The boolalpha manipulator displays their textual forms.

cout << boolalpha; cout << true << endl; cout << false;
Output:
true false

9. Null Pointer Literal

The keyword nullptr is the null pointer literal introduced in C++11.

It represents a pointer that does not point to an object or function.

#include <iostream> using namespace std; int main() { int* ptr = nullptr; if (ptr == nullptr) { cout << "Pointer is null"; } return 0; }
Output:
Pointer is null
Prefer nullptr over the older NULL or integer literal 0 when representing a null pointer in modern C++.

10. Escape Sequences in Literals

Escape sequences are special character combinations beginning with a backslash (\). They are used to represent characters that are difficult or impossible to type directly.

Escape Sequence Meaning
\n New line
\t Horizontal tab
\\ Backslash
\' Single quotation mark
\" Double quotation mark
\r Carriage return
\b Backspace
\0 Null character

Example Program

#include <iostream> using namespace std; int main() { cout << "Hello\nWorld\n"; cout << "Name:\tNavdeep\n"; cout << "C:\\Program Files"; return 0; }
Output:
Hello World Name: Navdeep C:\Program Files

11. Raw String Literals

A raw string literal allows characters such as backslashes and quotation marks to be written without interpreting ordinary escape sequences.

Raw string literals begin with R"( and end with )".

#include <iostream> using namespace std; int main() { cout << R"(C:\Users\Student\Documents)"; return 0; }
Output:
C:\Users\Student\Documents
Raw string literals are particularly useful for file paths, regular expressions and text containing many backslashes.

12. Digit Separators

C++14 introduced the digit separator apostrophe (') to improve the readability of large numeric literals.

#include <iostream> using namespace std; int main() { int population = 1'000'000; long long distance = 12'345'678'901LL; cout << population << endl; cout << distance; return 0; }
Output:
1000000 12345678901

The apostrophe does not change the numeric value. It only improves readability.

13. Literal Suffixes

Suffixes are characters added to the end of certain literals to specify or influence their type.

Suffix Meaning Example
U or u Unsigned integer 100U
L or l Long integer 100L
LL or ll Long long integer 100LL
F or f Float literal 3.14F
U and LL Unsigned long long 100ULL

Example

unsigned int count = 100U; long int population = 500000L; long long int largeNumber = 9000000000LL; float temperature = 36.5F; cout << count << endl; cout << population << endl; cout << largeNumber << endl; cout << temperature;
Output:
100 500000 9000000000 36.5

14. Literal vs Variable vs Constant Variable

Term Meaning Example
Literal Value written directly in source code 100
Variable Named storage whose value can change int age = 20;
Constant variable Named object that cannot be modified through that name const int MAX = 100;
int number = 100; const int limit = 500; number = 200; // limit = 600; // Error: cannot modify a const object

Here, 100 and 500 are literals. number is a variable, and limit is a constant variable.

15. Common Mistakes

Mistake 1: Using double quotes for a character

// Character literal char grade = 'A'; // String literal const char* text = "A";

Mistake 2: Confusing octal and decimal notation

int a = 10; // Decimal ten int b = 010; // Octal eight

Mistake 3: Forgetting the floating-point suffix

float a = 3.14f; // Float literal double b = 3.14; // Double literal

Mistake 4: Using zero as a null pointer unnecessarily

int* ptr = nullptr;
Use the correct quotation marks, prefixes and suffixes. They affect how the compiler interprets a literal.

16. Important Points to Remember

  • A literal is a fixed value written directly in source code.
  • Integer literals represent whole-number values.
  • Floating-point literals represent fractional or scientific values.
  • Character literals use single quotation marks.
  • String literals use double quotation marks.
  • Boolean literals are true and false.
  • nullptr represents a null pointer.
  • Octal literals begin with a leading zero.
  • Hexadecimal literals begin with 0x or 0X.
  • Binary literals begin with 0b or 0B (C++14).
  • Escape sequences represent special characters.
  • Raw string literals preserve backslashes and other characters.
  • Suffixes can specify or influence literal types.

18. Interview Questions

Q1. What is a literal in C++?

A literal is a fixed value written directly in the source code, such as 10, 3.14, 'A' or "Hello".

Q2. What are the common types of literals?

Integer, floating-point, character, string, Boolean and null pointer literals.

Q3. What is the difference between a character and string literal?

A character literal uses single quotation marks, while a string literal uses double quotation marks.

Q4. What is an octal literal?

An octal integer literal uses base 8 and is written with a leading zero.

Q5. What is a hexadecimal literal?

A hexadecimal integer literal uses base 16 and begins with 0x or 0X.

Q6. What is the purpose of a literal suffix?

A suffix specifies or influences the type of a literal, such as f for float or U for unsigned integer.

Q7. What is nullptr?

nullptr is a C++ null pointer literal introduced in C++11.

Q8. What is a raw string literal?

A raw string literal allows characters such as backslashes to be written without interpreting ordinary escape sequences.
