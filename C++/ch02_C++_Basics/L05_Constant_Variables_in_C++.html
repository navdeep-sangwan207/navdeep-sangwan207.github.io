1. Introduction

In C++, a constant variable is an object whose value cannot be modified through that variable after initialization.

The const keyword is used to declare a variable as constant. It helps protect values that should remain unchanged during program execution.

Learning Objectives:
  • Understand constant variables.
  • Learn the use of the const keyword.
  • Understand declaration and initialization of constants.
  • Differentiate const and non-const variables.
  • Learn const with pointers and function parameters.
  • Understand the difference between const and constexpr.

2. What Is a Constant Variable?

A constant variable is a variable declared with const. Its value must be provided during initialization and cannot subsequently be changed through that variable.

Syntax

const data_type variable_name = value;

Examples

const int age = 25; const float PI = 3.14f; const double taxRate = 0.18; const char grade = 'A';

These variables are initialized when they are defined. Attempts to modify them directly will result in compilation errors.

Important: A const object must be initialized when it is defined.

3. Why Do We Use Constant Variables?

Constant variables are useful when a value should not change.

  • Data protection: Prevents accidental modification.
  • Readability: Makes fixed values easier to identify.
  • Maintainability: Gives important values meaningful names.
  • Reliability: Reduces unintended changes in program logic.
  • Documentation: Clearly communicates programming intent.

Example

const double PI = 3.14159; const int MAX_USERS = 100; const int DAYS_IN_WEEK = 7;

These values represent quantities that should remain fixed in the program.

4. Declaring and Initializing Constant Variables

A const variable must be initialized at the time of its definition.

Correct Declaration

const int number = 100; const float percentage{85.5f}; const char section{'A'};

Incorrect Declaration

const int number; // Compilation error

The compiler reports an error because the const variable has no initializer.

Incorrect Modification

const int number = 10; number = 20; // Compilation error
A const variable cannot be assigned a new value after initialization.

5. Difference Between Constant and Non-Constant Variables

Constant Variable Non-Constant Variable
Declared using const. Declared without const.
Must be initialized when defined. Can be initialized later through assignment.
Cannot be modified through that name. Can be modified.
Useful for fixed values. Useful for changing values.

Example

int age = 20; const int MAX_AGE = 100; age = 25; // Valid // MAX_AGE = 120; // Compilation error

6. Constant Variables with Different Data Types

Integer Constant

const int MAX_MARKS = 100;

Floating-Point Constant

const float PI = 3.14f; const double GST_RATE = 0.18;

Character Constant Variable

const char GRADE = 'A';

Boolean Constant

const bool isActive = true;

String Constant

#include <string> const std::string COURSE_NAME = "C++ Programming";

7. Constant Variables in Calculations

Constants are commonly used in mathematical calculations where certain values must remain fixed.

Example: Area of a Circle

#include <iostream> using namespace std; int main() { const double PI = 3.14159; double radius = 5.0; double area = PI * radius * radius; cout << "Radius: " << radius << endl; cout << "Area of circle: " << area << endl; return 0; }
Expected Output: 
Radius: 5
Area of circle: 78.5397

The value of PI remains unchanged, while the radius and calculated area can vary.

8. const with Pointers

The const keyword can also be used with pointers. Its position determines whether the pointed-to value, the pointer itself, or both are protected.

A. Pointer to Constant

int value = 10; const int* ptr = &value; // *ptr = 20; // Error through ptr value = 20; // Valid ptr = nullptr; // Valid

The pointer cannot modify the value through ptr, but the pointer itself can point to another address.

B. Constant Pointer

int first = 10; int second = 20; int* const ptr = &first; *ptr = 15; // Valid // ptr = &second; // Error

The pointer cannot be redirected to another address, but the pointed-to value can be modified.

C. Constant Pointer to Constant

int value = 10; const int* const ptr = &value; // *ptr = 20; // Error // ptr = nullptr; // Error

Neither the pointer nor the pointed-to value can be modified through this pointer.

Declaration Change Pointed Value Through Pointer? Change Pointer Address?
const int* ptr No Yes
int* const ptr Yes No
const int* const ptr No No

9. const in Function Parameters

The const keyword can be used in function parameters to prevent a function from modifying an argument through that parameter.

Example: Constant Reference Parameter

#include <iostream> using namespace std; void display(const int& number) { cout << "Number: " << number; // number = 50; // Compilation error } int main() { int value = 25; display(value); return 0; }
Expected Output: 
Number: 25

The function receives a reference to the original variable but cannot modify it through the const reference.

Passing a large object by const reference can avoid copying while preventing modification through that function parameter.

10. Difference Between const and constexpr

Both const and constexpr express that a value should not be modified. However, they have different compile-time requirements.

const

A const variable cannot be modified after initialization. Its initializer does not always have to be a compile-time constant expression.

int getValue() { return 50; } const int number = getValue();

constexpr

A constexpr variable must be initialized with a constant expression and is usable in contexts requiring a compile-time constant.

constexpr int MAX_SIZE = 100; constexpr int DAYS = 7;
const constexpr
Prevents modification through the variable. Declares a constant expression variable.
May be initialized at runtime. Must be initialized using a constant expression.
Used for read-only objects. Used when compile-time evaluation is required.
Remember: Every constexpr variable is const-qualified, but not every const variable is constexpr.

11. Complete C++ Program

This program demonstrates the use of constant variables in a simple bill calculation.

#include <iostream> using namespace std; int main() { const double TAX_RATE = 0.18; double productPrice = 1000.0; double taxAmount = productPrice * TAX_RATE; double totalAmount = productPrice + taxAmount; cout << "Product Price: " << productPrice << endl; cout << "Tax Rate: " << TAX_RATE * 100 << "%" << endl; cout << "Tax Amount: " << taxAmount << endl; cout << "Total Amount: " << totalAmount << endl; return 0; }

Expected Output

Product Price: 1000
Tax Rate: 18%
Tax Amount: 180
Total Amount: 1180

Program Explanation

  1. TAX_RATE is declared as a constant.
  2. productPrice stores the product price.
  3. taxAmount calculates the tax.
  4. totalAmount calculates the final amount.
  5. The program displays all calculated values.

12. Common Mistakes

1. Not Initializing a const Variable

const int value; // Compilation error

Correct approach:

const int value = 10;

2. Modifying a const Variable

const int number = 10; number = 20; // Compilation error

3. Confusing const Pointer with Pointer to const

const int* ptr1; // Pointer to constant integer int* const ptr2 = nullptr; // Constant pointer

4. Assuming const Always Means Compile-Time Constant

int getValue() { return 10; } const int number = getValue();

This is valid, but the initializer is evaluated at runtime. Use constexpr when a compile-time constant expression is required.

13. Practice Programs

#include <iostream> using namespace std; int main() { constexpr int DAYS_IN_WEEK = 7; constexpr int WEEKS = 4; constexpr int totalDays = DAYS_IN_WEEK * WEEKS; cout << "Total Days = " << totalDays; return 0; }
Expected Output: 
Total Days = 28

14. Interview Questions

Q1. What is a constant variable in C++?

A variable declared with const whose value cannot be modified through that variable after initialization.

Q2. Which keyword is used to declare a constant variable?

The const keyword.

Q3. Can a const variable be modified?

No. It cannot be modified through its const-qualified name.

Q4. Must a const variable be initialized?

Yes. A const object must be initialized when defined.

Q5. What is the difference between const and constexpr?

const prevents modification. constexpr additionally requires a constant expression initializer for a constexpr variable.

Q6. What is a pointer to constant?

A pointer through which the pointed-to object cannot be modified, such as const int* ptr.

Q7. What is a constant pointer?

A pointer whose stored address cannot be changed, such as int* const ptr.

Q8. Can const be used in function parameters?

Yes. It can prevent modification of an argument through that parameter.

15. Quick Revision

  • const declares a constant-qualified object.
  • A const object must be initialized when defined.
  • Its value cannot be modified through that const name.
  • Constants are useful for fixed values.
  • const int* ptr is a pointer to const int.
  • int* const ptr is a const pointer to int.
  • constexpr requires a constant expression initializer for variables.
  • Use const references to prevent modification through function parameters.
