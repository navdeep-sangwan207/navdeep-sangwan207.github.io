1. Introduction

Fundamental data types are the basic built-in types provided by C++. They specify what kind of value a variable can store and what operations can be performed on that value.

C++ provides fundamental types for representing integers, floating-point numbers, characters, Boolean values, and the absence of a value.

Definition: A fundamental data type is a built-in C++ type used to represent basic kinds of data.

2. Classification of Fundamental Data Types

Fundamental data types can be organized into the following major categories:

Category Types Purpose
Boolean bool Represents true or false.
Character char, wchar_t, char8_t, char16_t, char32_t Represents character code units.
Integer short, int, long, long long Represents whole numbers.
Floating-point float, double, long double Represents numbers with fractional parts.
Void void Represents the absence of a value.
Null pointer std::nullptr_t Represents the type of nullptr.
Note: The character types and integer types have additional variations. Some types are used for character encoding rather than directly representing complete human-readable characters.

3. Integer Data Types

Integer data types are used to store whole numbers without fractional parts. They can represent positive numbers, negative numbers, and zero.

Common Integer Types

Type Description
short Short integer type.
int General-purpose integer type.
long Long integer type.
long long Integer type with at least 64 bits.

Example Program

#include <iostream> using namespace std; int main() { short age = 22; int population = 50000; long distance = 150000L; long long largeNumber = 9000000000LL; cout << "Age: " << age << endl; cout << "Population: " << population << endl; cout << "Distance: " << distance << endl; cout << "Large Number: " << largeNumber << endl; return 0; }

Expected Result

Age: 22 Population: 50000 Distance: 150000 Large Number: 9000000000

Signed and Unsigned Integer Types

Integer types can be signed or unsigned. Signed types support negative and positive values, while unsigned types support only non-negative values.

int temperature = -15; unsigned int students = 60;
Use unsigned types only when the required domain is non-negative and their arithmetic behavior is appropriate for the application.

4. Character Data Types

Character types are used to store character code units. The basic char type is commonly used for ordinary single-byte character data.

Character Types

Type Purpose
char Basic character type.
wchar_t Wide character type.
char8_t UTF-8 code unit type.
char16_t UTF-16 code unit type.
char32_t UTF-32 code unit type.

Example Program

#include <iostream> using namespace std; int main() { char grade = 'A'; wchar_t wideCharacter = L'B'; char8_t utf8Character = u8'A'; char16_t utf16Character = u'A'; char32_t utf32Character = U'A'; cout << "Grade: " << grade << endl; cout << "Size of char: " << sizeof(char) << " byte" << endl; cout << "Size of wchar_t: " << sizeof(wchar_t) << " bytes" << endl; cout << "Size of char8_t: " << sizeof(char8_t) << " byte" << endl; cout << "Size of char16_t: " << sizeof(char16_t) << " bytes" << endl; cout << "Size of char32_t: " << sizeof(char32_t) << " bytes" << endl; return 0; }

Expected Result

Typical output:
Grade: A Size of char: 1 byte Size of wchar_t: 4 bytes Size of char8_t: 1 byte Size of char16_t: 2 bytes Size of char32_t: 4 bytes
Note: The size of wchar_t is implementation-dependent. The sizes shown for the other character types follow their standard minimum storage requirements.
Important: char8_t was introduced in C++20. Compile this example using C++20 or a later standard.

5. Floating-Point Data Types

Floating-point data types are used to represent numbers containing fractional parts or very large and very small values.

Types of Floating-Point Data Types

Type Typical Precision Description
float About 6–7 decimal digits Single-precision floating point.
double About 15–16 decimal digits Double-precision floating point.
long double Implementation-dependent Extended floating-point type.

Example Program

#include <iostream> #include <iomanip> using namespace std; int main() { float price = 99.50f; double pi = 3.141592653589793; long double value = 12345.6789L; cout << fixed << setprecision(2); cout << "Price: " << price << endl; cout << setprecision(15); cout << "Pi: " << pi << endl; cout << setprecision(4); cout << "Long double value: " << value << endl; return 0; }

Expected Result

Price: 99.50 Pi: 3.141592653589793 Long double value: 12345.6789
Remember: Floating-point calculations may introduce rounding errors. For example, many decimal fractions cannot be represented exactly in binary floating-point format.

6. Boolean Data Type

The bool data type is used to represent logical values. It has two possible values:

  • true – represents a true condition.
  • false – represents a false condition.

Example Program

#include <iostream> using namespace std; int main() { bool isPassed = true; bool isAbsent = false; cout << "Passed: " << isPassed << endl; cout << "Absent: " << isAbsent << endl; cout << boolalpha; cout << "Passed: " << isPassed << endl; cout << "Absent: " << isAbsent << endl; return 0; }

Expected Result

Passed: 1 Absent: 0 Passed: true Absent: false

By default, streams display Boolean values as 1 and 0. The boolalpha manipulator displays them as true and false.

7. Void Data Type

The void type represents the absence of a value. It is commonly used as a function return type when a function does not return a result.

Example Program

#include <iostream> using namespace std; void displayMessage() { cout << "Welcome to C++ Programming!" << endl; } int main() { displayMessage(); return 0; }

Expected Result

Welcome to C++ Programming!
Important: A variable cannot have type void. However, void pointers such as void* can hold the address of an object.

8. Null Pointer Type

C++ provides the nullptr keyword to represent a null pointer. Its type is std::nullptr_t, which is defined in the <cstddef> header.

Example Program

#include <iostream> #include <cstddef> using namespace std; int main() { int* ptr = nullptr; if (ptr == nullptr) { cout << "Pointer is null." << endl; } cout << "Size of nullptr_t: " << sizeof(nullptr_t) << " bytes" << endl; return 0; }

Expected Result

Pointer is null. Size of nullptr_t: 8 bytes
Note: The displayed size is illustrative. The size of nullptr_t depends on the implementation.

9. Modifiers of Integer Data Types

C++ provides type modifiers that change the range or representation of certain integer types.

Modifier Purpose
signed Allows negative and positive integer values.
unsigned Allows only non-negative integer values.
short Specifies a short integer type.
long Specifies a long integer type.

Example Program

#include <iostream> using namespace std; int main() { signed int temperature = -20; unsigned int count = 100; short int smallNumber = 25; long int distance = 100000L; long long int largeValue = 9000000000LL; cout << temperature << endl; cout << count << endl; cout << smallNumber << endl; cout << distance << endl; cout << largeValue << endl; return 0; }

Expected Result

-20 100 25 100000 9000000000

10. Checking Data Type Sizes

The sizeof() operator determines the size of a data type or object in bytes.

Example Program

#include <iostream> using namespace std; int main() { cout << "Size of bool: " << sizeof(bool) << endl; cout << "Size of char: " << sizeof(char) << endl; cout << "Size of int: " << sizeof(int) << endl; cout << "Size of float: " << sizeof(float) << endl; cout << "Size of double: " << sizeof(double) << endl; cout << "Size of long double: " << sizeof(long double) << endl; return 0; }

Expected Result

Example output on a common platform:
Size of bool: 1 Size of char: 1 Size of int: 4 Size of float: 4 Size of double: 8 Size of long double: 16
Important: These sizes are not guaranteed on every compiler or platform. Always use sizeof() when the actual size matters.

11. Difference Between Fundamental and Derived Types

Fundamental Types Derived Types
Built-in basic types. Types formed from other types.
Examples: int, char, float, bool. Examples: arrays, pointers, references, functions.
Provide basic data representation. Provide additional ways to organize or access data.
Remember: Classes, structures, unions, and enumerations are user-defined types, not fundamental types.

12. Common Mistakes

  • Assuming all data types have fixed sizes on every system.
  • Using int for values that may exceed its range.
  • Confusing char with a complete Unicode character.
  • Assuming floating-point calculations are always exact.
  • Using void as a variable type.
  • Using an uninitialized variable before assigning a value.
  • Assuming wchar_t has the same size on every platform.
  • Using char8_t without enabling C++20 or later.

15. Important Points to Remember

  • Fundamental types are built into the C++ language.
  • Integer types represent whole numbers.
  • Floating-point types represent fractional values.
  • Character types represent character code units.
  • bool represents true or false.
  • void represents the absence of a value.
  • nullptr represents a null pointer.
  • Type sizes can vary between platforms.
  • sizeof() checks the size of a type or object.
  • Select data types according to the requirements of the program.
