1. Introduction to STL List

In C++, std::list is a sequence container provided by the Standard Template Library (STL). It stores elements in the form of a doubly linked list.

Unlike a vector, a list does not store its elements in one continuous block of memory. Each element is stored in a separate node connected to the previous and next nodes.

Important: A list supports efficient insertion and deletion at known positions, but it does not support direct random access using an index.

Doubly Linked List Structure

NULL <-- [10] <--> [20] <--> [30] --> NULL Each node contains: 1. Previous node pointer 2. Data 3. Next node pointer

The previous pointer connects to the preceding node, while the next pointer connects to the following node.

2. Header File and Syntax

To use the STL list container, include the following header:

#include <list>

Declaration Syntax

list<data_type> list_name;

Example

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers; return 0; }

Here, numbers is a list container that stores integer values.

3. Initialization of a List

A list can be initialized in different ways.

#include <iostream> #include <list> using namespace std; int main() { list<int> list1 = {10, 20, 30, 40}; list<int> list2(5, 100); list<int> list3(list1); for (int x : list1) cout << x << " "; cout << endl; for (int x : list2) cout << x << " "; cout << endl; for (int x : list3) cout << x << " "; return 0; }
Expected Output 
10 20 30 40
100 100 100 100 100
10 20 30 40

list1: Initializes a list with specified values.
list2: Creates five elements, each initialized to 100.
list3: Creates a copy of list1.

4. Adding Elements to a List

The list container provides functions to add elements at the beginning and end.

Function Description
push_back() Adds an element at the end.
push_front() Adds an element at the beginning.
emplace_back() Constructs an element at the end.
emplace_front() Constructs an element at the beginning.

Example: push_back() and push_front()

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers; numbers.push_back(20); numbers.push_back(30); numbers.push_front(10); numbers.push_front(5); for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
5 10 20 30
Note: push_front() is available in list but not in std::vector.

5. Inserting Elements into a List

The insert() function inserts an element at a position specified by an iterator.

Example

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 20, 40}; auto it = numbers.begin(); advance(it, 2); numbers.insert(it, 30); for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
10 20 30 40

advance(it, 2) moves the iterator two positions forward. The value 30 is inserted before the element currently pointed to by the iterator.

Note: The list iterator is bidirectional. Moving it using advance() takes time proportional to the number of positions moved.

6. Deleting Elements from a List

Function Description
pop_back() Removes the last element.
pop_front() Removes the first element.
erase() Removes an element or a range of elements.
remove() Removes all elements equal to a specified value.
clear() Removes all elements.

Example

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 20, 30, 40, 50}; numbers.pop_front(); numbers.pop_back(); numbers.remove(30); for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
20 40

First, pop_front() removes 10. Then pop_back() removes 50. Finally, remove(30) removes the element with value 30.

7. Traversing a List

Traversal means accessing each element of a container one by one. A list can be traversed using a range-based for loop or iterators.

Method 1: Range-Based For Loop

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 20, 30, 40}; for (int x : numbers) { cout << x << " "; } return 0; }

Method 2: Using Iterators

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 20, 30, 40}; for (auto it = numbers.begin(); it != numbers.end(); ++it) { cout << *it << " "; } return 0; }
Expected Output (Both Methods) 
10 20 30 40
Iterator: An iterator is an object used to access and traverse elements of an STL container.

begin(): Returns an iterator to the first element.
end(): Returns an iterator to the position after the last element.
*it: Accesses the element pointed to by the iterator.

8. Accessing List Elements

A list provides front() and back() to access its first and last elements.

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 20, 30, 40}; cout << "First element: " << numbers.front() << endl; cout << "Last element: " << numbers.back(); return 0; }
Expected Output 
First element: 10
Last element: 40
Important: std::list does not support numbers[0] or direct indexing. Use iterators to access elements at other positions.

9. Important List Member Functions

Function Purpose
size() Returns the number of elements.
empty() Checks whether the list is empty.
front() Returns the first element.
back() Returns the last element.
begin() Returns an iterator to the first element.
end() Returns an iterator after the last element.
sort() Sorts the elements in ascending order by default.
reverse() Reverses the order of elements.
unique() Removes consecutive duplicate elements.
merge() Merges two sorted lists.
splice() Transfers elements from another list.

Example: sort() and reverse()

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {40, 10, 30, 20}; numbers.sort(); cout << "Sorted: "; for (int x : numbers) cout << x << " "; numbers.reverse(); cout << "\nReversed: "; for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
Sorted: 10 20 30 40
Reversed: 40 30 20 10

10. Special List Operations

unique()

Removes consecutive duplicate elements. It does not automatically remove duplicates that are separated by other values.

list<int> numbers = {10, 10, 20, 20, 30}; numbers.unique(); // Result: 10 20 30

remove_if()

Removes elements that satisfy a specified condition.

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {10, 15, 20, 25, 30}; numbers.remove_if([](int x) { return x % 2 == 0; }); for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
15 25

The lambda condition checks whether a number is even. All even numbers are removed from the list.

splice()

Transfers elements from one list to another without copying individual elements.

#include <iostream> #include <list> using namespace std; int main() { list<int> first = {10, 20}; list<int> second = {30, 40}; first.splice(first.end(), second); for (int x : first) cout << x << " "; cout << "\nSecond list size: " << second.size(); return 0; }
Expected Output 
10 20 30 40
Second list size: 0
Note: splice() transfers nodes. The source list becomes empty when all its elements are transferred.

11. Time Complexity of List Operations

Operation Typical Complexity
push_front() O(1)
push_back() O(1)
pop_front() O(1)
pop_back() O(1)
Insert at a known iterator O(1)
Erase at a known iterator O(1)
Access by position O(n)
Search by value O(n)
Traversal O(n)
sort() O(n log n)
Insertion and deletion are efficient when the required iterator is already available. Finding that position may still require O(n) traversal.

12. Difference Between Vector and List

Feature Vector List
Header <vector> <list>
Structure Dynamic array Doubly linked list
Memory Contiguous Non-contiguous nodes
Random access Supported Not supported
push_front() Not available Available
Insertion in middle Generally O(n) O(1) at a known iterator
Access by index O(1) O(n)
Memory overhead Generally lower Generally higher due to node links
When to use vector? Use vector when fast indexed access and cache-friendly traversal are important.

When to use list? Use list when frequent insertion and deletion at known positions are important and random access is not required.

13. Practical Program: List Operations

This program demonstrates inserting, deleting, sorting and displaying elements in a list.

#include <iostream> #include <list> using namespace std; int main() { list<int> numbers = {40, 10, 30, 20}; cout << "Original list: "; for (int x : numbers) cout << x << " "; numbers.push_front(5); numbers.push_back(50); cout << "\nAfter insertion: "; for (int x : numbers) cout << x << " "; numbers.pop_front(); numbers.pop_back(); numbers.sort(); cout << "\nAfter deletion and sorting: "; for (int x : numbers) cout << x << " "; return 0; }
Expected Output 
Original list: 40 10 30 20
After insertion: 5 40 10 30 20 50
After deletion and sorting: 10 20 30 40

14. Advantages and Limitations of List

Advantages

  • Efficient insertion and deletion at known positions.
  • Efficient insertion and deletion at both ends.
  • Iterators to existing elements generally remain valid after insertion.
  • Provides useful operations such as sort(), merge() and splice().

Limitations

  • No direct random access using an index.
  • Searching requires linear traversal.
  • Extra memory is needed for node pointers.
  • Non-contiguous storage can reduce cache efficiency.
Iterator validity: Insertion and operations such as splice generally preserve iterators to existing elements. Erasing an element invalidates iterators and references to that erased element.

15. Important Points to Remember

  • std::list is a sequence container in STL.
  • It is typically implemented as a doubly linked list.
  • Include the <list> header file.
  • It supports push_front() and push_back().
  • It does not support direct indexing.
  • It uses bidirectional iterators.
  • Insertion and deletion at a known iterator are O(1).
  • Use list.sort() instead of std::sort() for a list.
  • unique() removes consecutive duplicates.
  • splice() transfers elements between lists.
