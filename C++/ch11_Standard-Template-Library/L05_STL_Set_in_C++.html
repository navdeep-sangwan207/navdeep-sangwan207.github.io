Lesson 5: STL Set in C++

Understanding Unique Elements and the Set Container

1. Introduction to STL Set

In C++, std::set is an associative container provided by the Standard Template Library (STL). It stores unique elements in a sorted order.

Unlike vector and list, a set does not allow duplicate elements. When a new element is inserted, the set maintains its sorted order automatically.

Important: A set stores only unique values. If an element already exists, inserting the same value again does not create another element.

Example

Input values: 40, 10, 30, 20, 10, 30 Set elements: 10, 20, 30, 40

The duplicate values 10 and 30 are stored only once. The elements are automatically arranged in ascending order by default.

2. Internal Working of Set

A standard C++ set is typically implemented using a self-balancing binary search tree, commonly a Red-Black Tree.

This structure keeps elements sorted and supports efficient insertion, deletion and searching.

Conceptual Structure

Input: 40, 10, 30, 20, 10 SET +-------------+ | 10 20 30 40 | +-------------+ Properties: 1. Duplicate values are not stored. 2. Elements remain sorted. 3. Searching is efficient.
The diagram represents the sorted elements stored in a set. Internally, the set uses a balanced tree structure rather than a simple array.

3. Header File and Syntax

To use the set container, include the following header:

#include <set>

Declaration Syntax

set<data_type> set_name;

Example

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers; return 0; }

Here, numbers is a set container that stores unique integer values.

4. Initialization of a Set

A set can be initialized using an initializer list.

Example

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {40, 10, 30, 20, 10}; for (int x : numbers) { cout << x << " "; } return 0; }
Expected Output 
10 20 30 40

The duplicate value 10 is stored only once, and the elements are displayed in ascending order.

5. Inserting Elements into a Set

The insert() and emplace() functions are used to add elements to a set.

Function Description
insert() Inserts an element into the set.
emplace() Constructs an element directly in the set.

Example: insert()

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers; numbers.insert(30); numbers.insert(10); numbers.insert(20); numbers.insert(10); for (int x : numbers) { cout << x << " "; } return 0; }
Expected Output 
10 20 30

The second insertion of 10 does not create a duplicate.

Example: emplace()

set<int> numbers; numbers.emplace(50); numbers.emplace(20); numbers.emplace(30);
Note: Both insert() and emplace() preserve the uniqueness of elements.

6. Deleting Elements from a Set

The erase() function removes elements from a set. The clear() function removes all elements.

Function Description
erase(value) Removes the specified element.
erase(iterator) Removes the element pointed to by an iterator.
clear() Removes all elements.

Example

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {10, 20, 30, 40, 50}; numbers.erase(30); for (int x : numbers) { cout << x << " "; } return 0; }
Expected Output 
10 20 40 50

Removing All Elements

numbers.clear(); cout << numbers.size();
Expected Output 
0

7. Searching Elements in a Set

The find() function searches for an element in a set. It returns an iterator to the element if it exists.

If the element is not found, find() returns set.end().

Example: find()

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {10, 20, 30, 40}; auto it = numbers.find(30); if (it != numbers.end()) { cout << "Element found: " << *it; } else { cout << "Element not found"; } return 0; }
Expected Output 
Element found: 30

Using count()

if (numbers.count(20) == 1) { cout << "Element exists"; } else { cout << "Element does not exist"; }
Expected Output 
Element exists
Note: Since set stores unique elements, count() returns either 1 (element exists) or 0 (element does not exist).

8. Traversing a Set

A set can be traversed using a range-based for loop or iterators.

Method 1: Range-Based For Loop

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {40, 10, 30, 20}; for (int x : numbers) { cout << x << " "; } return 0; }

Method 2: Using Iterators

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {40, 10, 30, 20}; for (auto it = numbers.begin(); it != numbers.end(); ++it) { cout << *it << " "; } return 0; }
Expected Output (Both Methods) 
10 20 30 40
begin(): Returns an iterator to the first element.
end(): Returns an iterator after the last element.
*it: Accesses the element pointed to by the iterator.
Important: Set elements are treated as constant through their iterators. You cannot directly modify an element using an iterator. Remove the old value and insert the new value.

9. Accessing Elements in Reverse Order

A set provides reverse iterators to traverse its elements from largest to smallest.

Example

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {10, 20, 30, 40}; for (auto it = numbers.rbegin(); it != numbers.rend(); ++it) { cout << *it << " "; } return 0; }
Expected Output 
40 30 20 10
rbegin(): Returns a reverse iterator to the last element.
rend(): Returns the reverse iterator position before the first element.

10. Important Set Member Functions

Function Purpose
insert() Inserts an element.
emplace() Constructs an element in the set.
erase() Removes an element.
find() Searches for an element.
count() Checks whether an element exists.
size() Returns the number of elements.
empty() Checks whether the set is empty.
clear() Removes all elements.
begin() Returns an iterator to the first element.
end() Returns an iterator after the last element.
rbegin() Returns a reverse iterator to the last element.
rend() Returns the reverse iterator end position.
lower_bound() Finds the first element not less than a given value.
upper_bound() Finds the first element greater than a given value.

11. lower_bound() and upper_bound()

These functions are useful for finding positions in a sorted set.

lower_bound()

Returns an iterator to the first element that is not less than the specified value.

upper_bound()

Returns an iterator to the first element that is greater than the specified value.

Example

#include <iostream> #include <set> using namespace std; int main() { set<int> numbers = {10, 20, 30, 40, 50}; auto it1 = numbers.lower_bound(30); auto it2 = numbers.upper_bound(30); cout << "lower_bound: " << *it1 << endl; cout << "upper_bound: " << *it2; return 0; }
Expected Output 
lower_bound: 30
upper_bound: 40
Note: If no matching element exists, these functions may return end(). Always check the iterator before dereferencing it.

12. Set vs Unordered Set

C++ also provides unordered_set, another associative container that stores unique elements.

Feature set unordered_set
Header <set> <unordered_set>
Internal structure Typically Red-Black Tree Hash table
Element order Sorted No guaranteed order
Duplicate elements Not allowed Not allowed
Search complexity O(log n) Average O(1), worst O(n)
Insertion complexity O(log n) Average O(1), worst O(n)
When to use set? Use set when you need unique elements in sorted order.

When to use unordered_set? Use unordered_set when you need unique elements but sorted order is not important and average constant-time lookup is useful.

13. Time Complexity of Set Operations

Operation Typical Complexity
insert() O(log n)
emplace() O(log n)
find() O(log n)
erase(value) O(log n)
count() O(log n)
lower_bound() O(log n)
upper_bound() O(log n)
size() O(1)
empty() O(1)
clear() O(n)
Traversal O(n)
The logarithmic complexity of common set operations is due to its balanced tree structure. Here, n represents the number of elements.

14. Practical Program: Remove Duplicate Numbers

This program uses a set to remove duplicate values from a collection of numbers.

#include <iostream> #include <set> using namespace std; int main() { int values[] = {10, 20, 10, 30, 20, 40, 30}; set<int> uniqueNumbers; for (int x : values) { uniqueNumbers.insert(x); } cout << "Unique numbers: "; for (int x : uniqueNumbers) { cout << x << " "; } cout << "\nTotal unique numbers: " << uniqueNumbers.size(); return 0; }
Expected Output 
Unique numbers: 10 20 30 40
Total unique numbers: 4
The array contains seven values, including duplicates. Inserting these values into a set automatically removes duplicates and maintains sorted order.

15. Advantages and Limitations of Set

Advantages

  • Automatically stores unique elements.
  • Maintains elements in sorted order.
  • Provides efficient searching, insertion and deletion.
  • Useful for removing duplicate values.
  • Supports lower_bound() and upper_bound().

Limitations

  • Does not allow duplicate elements.
  • Does not support direct indexing.
  • Elements cannot be modified directly through iterators.
  • Operations generally take O(log n).
  • Maintaining sorted order requires additional overhead.

16. Important Points to Remember

  • std::set is an associative container in STL.
  • Include the <set> header file.
  • Set stores only unique elements.
  • Elements are sorted by default.
  • A standard set is typically implemented using a Red-Black Tree.
  • insert() and emplace() add elements.
  • erase() removes elements.
  • find() searches for an element.
  • count() checks whether an element exists.
  • Set iterators do not allow direct modification of elements.
  • lower_bound() finds the first element not less than a value.
  • upper_bound() finds the first element greater than a value.
  • Most searching, insertion and deletion operations take O(log n).
