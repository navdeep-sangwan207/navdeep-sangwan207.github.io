1. Introduction to STL Algorithms

STL algorithms are predefined functions provided by the C++ Standard Template Library. They perform common operations on data stored in containers such as vector, array and deque.

Instead of writing searching, sorting or counting logic manually, we can use ready-made algorithms from the standard library.

Example: If a vector contains 10 numbers and we want to sort them, we can use the sort() algorithm instead of writing our own sorting function.

Header Files

Header Purpose
<algorithm> Provides sorting, searching, modifying and comparison algorithms.
<numeric> Provides numerical algorithms such as accumulate.
<vector> Provides the vector container used in many examples.
<iostream> Provides input and output operations.

2. How STL Algorithms Work

Most STL algorithms work with iterators rather than directly depending on a particular container.

General Syntax

algorithm_name(begin_iterator, end_iterator);

For example:

sort(numbers.begin(), numbers.end());

Understanding the Iterator Range

STL algorithms commonly process a range written as [begin, end).

  • begin() points to the first element.
  • end() points one position after the last element.
  • The element pointed to by end() is not included.
Important: The end iterator is a boundary marker. It must not be dereferenced.

3. Sorting Algorithms

Sorting means arranging elements in a particular order, usually ascending or descending.

3.1 sort()

The sort() algorithm arranges elements in ascending order by default.

Syntax

sort(container.begin(), container.end());

Example: Ascending and Descending Order

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {50, 10, 40, 20, 30}; sort(numbers.begin(), numbers.end()); cout << "Ascending: "; for(int x : numbers) cout << x << " "; sort(numbers.begin(), numbers.end(), greater<int>()); cout << "\nDescending: "; for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
Ascending: 10 20 30 40 50 Descending: 50 40 30 20 10
greater<int>() provides descending comparison. It is available through the <functional> header; including <algorithm> and the relevant standard library headers is not a substitute for explicitly including <functional> when using it.

3.2 reverse()

The reverse() algorithm reverses the order of elements in a range.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 40, 50}; reverse(numbers.begin(), numbers.end()); for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
50 40 30 20 10
Note: sort() and reverse() work with random-access iterators. A vector supports them, but a list does not support std::sort(). For a list, use its member function list.sort().

4. Searching Algorithms

Searching algorithms help locate elements or determine whether a value exists in a container.

4.1 find()

The find() algorithm searches for a specified value in a range.

Syntax

find(begin_iterator, end_iterator, value);

Example

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 40, 50}; auto it = find(numbers.begin(), numbers.end(), 30); if(it != numbers.end()) cout << "Element found"; else cout << "Element not found"; return 0; }
Expected Output:
Element found
If the value is found, find() returns an iterator pointing to that element. Otherwise, it returns the end iterator.

4.2 binary_search()

The binary_search() algorithm checks whether a value exists in a sorted range.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 40, 50}; bool result = binary_search( numbers.begin(), numbers.end(), 40 ); if(result) cout << "Element found"; else cout << "Element not found"; return 0; }
Expected Output:
Element found
Important: The range must be sorted according to the same ordering used by the search operation.

4.3 lower_bound() and upper_bound()

Algorithm Meaning
lower_bound() Returns an iterator to the first element not less than the given value.
upper_bound() Returns an iterator to the first element greater than the given value.

Example

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 20, 30, 40, 50}; auto low = lower_bound( numbers.begin(), numbers.end(), 20 ); auto high = upper_bound( numbers.begin(), numbers.end(), 20 ); cout << "Lower bound index: " << low - numbers.begin() << endl; cout << "Upper bound index: " << high - numbers.begin() << endl; return 0; }
Expected Output:
Lower bound index: 1 Upper bound index: 3

5. Counting and Comparison Algorithms

5.1 count()

The count() algorithm counts how many times a particular value occurs in a range.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 10, 30, 10, 40}; int result = count( numbers.begin(), numbers.end(), 10 ); cout << "10 occurs " << result << " times"; return 0; }
Expected Output:
10 occurs 3 times

5.2 count_if()

The count_if() algorithm counts elements that satisfy a specified condition.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 15, 20, 25, 30}; int result = count_if( numbers.begin(), numbers.end(), [](int x) { return x > 20; } ); cout << "Numbers greater than 20: " << result; return 0; }
Expected Output:
Numbers greater than 20: 2
The expression [](int x) { return x > 20; } is a lambda function. It returns true for values greater than 20.

5.3 min_element() and max_element()

These algorithms return iterators pointing to the smallest and largest elements in a range.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {45, 12, 78, 23, 9}; auto minimum = min_element( numbers.begin(), numbers.end() ); auto maximum = max_element( numbers.begin(), numbers.end() ); cout << "Minimum: " << *minimum << endl; cout << "Maximum: " << *maximum; return 0; }
Expected Output:
Minimum: 9 Maximum: 78

5.4 all_of(), any_of() and none_of()

Algorithm Purpose
all_of() Returns true if every element satisfies the condition.
any_of() Returns true if at least one element satisfies the condition.
none_of() Returns true if no element satisfies the condition.

Example

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {2, 4, 6, 8}; cout << boolalpha; cout << all_of( numbers.begin(), numbers.end(), [](int x) { return x % 2 == 0; } ) << endl; cout << any_of( numbers.begin(), numbers.end(), [](int x) { return x > 6; } ) << endl; cout << none_of( numbers.begin(), numbers.end(), [](int x) { return x < 0; } ); return 0; }
Expected Output:
true true true

6. Modifying Algorithms

Modifying algorithms change values in a range or produce modified values in another range.

6.1 replace()

Replaces every occurrence of a specified old value with a new value.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 10, 30, 10}; replace( numbers.begin(), numbers.end(), 10, 99 ); for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
99 20 99 30 99

6.2 fill()

Assigns the same value to every element in a specified range.

fill(numbers.begin(), numbers.end(), 0);

6.3 transform()

Applies an operation to each element and stores the resulting values in an output range.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {1, 2, 3, 4, 5}; vector<int> squares(numbers.size()); transform( numbers.begin(), numbers.end(), squares.begin(), [](int x) { return x * x; } ); for(int x : squares) cout << x << " "; return 0; }
Expected Output:
1 4 9 16 25

7. Removing Elements: remove() and remove_if()

The remove() algorithm moves elements that do not match a specified value toward the beginning of the range. It returns a new logical end iterator.

Important: remove() does not actually reduce the size of a vector. Use the erase-remove idiom to remove elements from the container.

7.1 Erase-Remove Idiom

container.erase( remove(container.begin(), container.end(), value), container.end() );

Example: Remove a Value

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 20, 40}; numbers.erase( remove(numbers.begin(), numbers.end(), 20), numbers.end() ); for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
10 30 40

7.2 remove_if()

Removes elements based on a condition when combined with erase().

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 15, 20, 25, 30}; numbers.erase( remove_if( numbers.begin(), numbers.end(), [](int x) { return x % 2 == 0; } ), numbers.end() ); for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
15 25
For std::list, you can use its member functions remove() and remove_if() directly. These member functions actually erase matching list nodes.

8. unique() Algorithm

The unique() algorithm removes consecutive duplicate values from a range by moving the remaining elements toward the beginning. It returns the new logical end iterator.

Example

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 10, 20, 20, 30, 30}; auto newEnd = unique( numbers.begin(), numbers.end() ); numbers.erase(newEnd, numbers.end()); for(int x : numbers) cout << x << " "; return 0; }
Expected Output:
10 20 30
Remember: unique() removes only consecutive duplicates. To remove all duplicate values from a vector, sort it first and then apply unique() with erase().

9. Numeric Algorithm: accumulate()

The accumulate() algorithm calculates the sum of elements in a range. It is provided by the <numeric> header.

Syntax

accumulate(begin_iterator, end_iterator, initial_value);

Example

#include <iostream> #include <vector> #include <numeric> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 40}; int total = accumulate( numbers.begin(), numbers.end(), 0 ); cout << "Sum: " << total; return 0; }
Expected Output:
Sum: 100
The initial value is 0. The algorithm adds each element to this value and returns the final result.

10. for_each() Algorithm

The for_each() algorithm applies a function or callable operation to each element in a range.

Example

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> numbers = {10, 20, 30, 40}; for_each( numbers.begin(), numbers.end(), [](int x) { cout << x << " "; } ); return 0; }
Expected Output:
10 20 30 40

12. Important Concepts and Precautions

12.1 Algorithm and Container Relationship

STL algorithms generally operate on iterator ranges. They do not need to know the internal implementation of the container.

12.2 Iterator Requirements

Algorithm Important Requirement
sort() Requires random-access iterators.
find() Works with forward iterators and stronger iterator types.
binary_search() Requires a sorted range.
lower_bound() Requires a range partitioned according to the comparison.
accumulate() Works with input iterators.

12.3 Time Complexity Overview

Algorithm Typical Complexity
sort() O(N log N)
reverse() O(N)
find() O(N)
binary_search() O(log N) comparisons
count() O(N)
min_element() / max_element() O(N)
accumulate() O(N)
Note: Complexity describes how the number of operations grows with the number of elements. Actual performance also depends on the container, iterator type and operation.

15. Lesson Summary

  • STL algorithms provide reusable operations on iterator ranges.
  • sort() arranges elements in order.
  • find() and binary_search() locate values.
  • count() and count_if() count matching elements.
  • min_element() and max_element() find extreme values.
  • replace(), fill() and transform() modify or process values.
  • remove() and unique() use logical removal and may need erase().
