1. Introduction to STL

The Standard Template Library (STL) is a collection of reusable template classes and functions provided by C++.

STL provides ready-made data structures and algorithms that help programmers perform common programming tasks without implementing everything from scratch.

Definition: STL is a part of the C++ Standard Library that provides generic containers, iterators, algorithms, and related utilities for efficient programming.

Why Do We Need STL?

  • It reduces the amount of code required.
  • It provides reusable and tested components.
  • It supports generic programming using templates.
  • It provides efficient data structures and algorithms.
  • It improves code readability and maintainability.
Remember: STL is especially useful when working with collections of data, searching, sorting, inserting, and deleting elements.

2. Main Components of STL

STL is commonly studied through three major components: containers, iterators, and algorithms.

2.1 Containers

Containers are objects that store and organize collections of data. Different containers are designed for different storage and access requirements.

Examples: vector, list, map, set, stack, and queue.

2.2 Iterators

Iterators are objects that work like pointers. They are used to access and traverse elements stored in containers.

Examples: begin(), end(), and iterator.

2.3 Algorithms

Algorithms are predefined functions used to perform operations on data, usually through iterators.

Examples: sort(), find(), count(), and reverse().

STL Component Relationship

Containers store the data.

Iterators access and traverse the data.

Algorithms perform operations on the data.

3. Types of STL Containers

STL containers are classified into different categories based on how they organize and store elements.

3.1 Sequence Containers

Sequence containers store elements in a linear sequence. Their elements are arranged according to their position.

  • vector: Dynamic array.
  • list: Doubly linked list.
  • deque: Double-ended queue.
  • array: Fixed-size array.
  • forward_list: Singly linked list.

3.2 Associative Containers

Associative containers organize elements using keys. They generally maintain elements in sorted order.

  • set: Stores unique keys.
  • multiset: Allows duplicate keys.
  • map: Stores key-value pairs with unique keys.
  • multimap: Stores key-value pairs with duplicate keys.

3.3 Unordered Associative Containers

These containers use hash-based organization rather than maintaining sorted order.

  • unordered_set
  • unordered_multiset
  • unordered_map
  • unordered_multimap

3.4 Container Adapters

Container adapters provide restricted interfaces to underlying containers.

  • stack: Last In, First Out (LIFO).
  • queue: First In, First Out (FIFO).
  • priority_queue: Accesses the highest-priority element first by default.

Container Comparison

Container Purpose Important Feature
vector Dynamic array Fast random access
list Doubly linked list Efficient insertion and deletion at known positions
map Key-value storage Unique sorted keys
set Unique elements Sorted unique keys
stack LIFO storage Top element access
queue FIFO storage Front and rear operations

4. Introduction to Iterators

An iterator is an object used to point to elements inside a container. It allows a programmer to move through a container and access its elements.

Important Iterator Functions

Function Description
begin() Returns an iterator to the first element.
end() Returns an iterator to the position after the last element.
rbegin() Returns a reverse iterator to the last element.
rend() Returns a reverse iterator to the position before the first element.
Important: end() does not point to the last element. It points to the position immediately after the last element.

Example: Using an Iterator

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    vector<int>::iterator it;

    for (it = numbers.begin();
         it != numbers.end(); ++it) {
        cout << *it << " ";
    }

    return 0;
}

▶️ Expected Output

10 20 30 40

💡 Explanation

  • vector<int>::iterator declares an iterator for an integer vector.
  • begin() points to the first element.
  • end() represents the position after the last element.
  • *it accesses the element pointed to by the iterator.
  • ++it moves the iterator to the next element.

5. Introduction to STL Algorithms

STL algorithms are predefined functions available mainly through the <algorithm> header. They perform common operations on ranges of elements.

Common STL Algorithms

Algorithm Purpose
sort() Sorts elements in a range.
find() Searches for an element.
count() Counts occurrences of a value.
reverse() Reverses the order of elements.
max_element() Finds the largest element.
min_element() Finds the smallest element.

Example: Using sort() Algorithm

C++ Program
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {50, 10, 40, 20, 30};

    sort(numbers.begin(), numbers.end());

    cout << "Sorted elements: ";

    for (int x : numbers) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

Sorted elements:
10 20 30 40 50

💡 Explanation

  • <algorithm> provides the sort() function.
  • numbers.begin() identifies the starting position.
  • numbers.end() identifies the position after the last element.
  • sort() arranges the elements in ascending order by default.

6. Basic Syntax of STL

To use an STL container, include its corresponding header file and declare the container using the required data type.

General Syntax

#include <container_header>

container_name<data_type> variable_name;

Example: Declaring a Vector

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> marks;

    marks.push_back(85);
    marks.push_back(90);
    marks.push_back(95);

    cout << "First mark: " << marks[0];

    return 0;
}

▶️ Expected Output

First mark: 85

💡 Explanation

  • <vector> is the header used for the vector container.
  • vector<int> creates a vector that stores integers.
  • push_back() adds an element at the end.
  • marks[0] accesses the first element.

7. Advantages of STL

  • Code Reusability: Ready-made components can be reused in different programs.
  • Efficiency: STL provides well-designed containers and algorithms.
  • Generic Programming: Templates allow components to work with different data types.
  • Less Development Time: Common operations do not need to be implemented manually.
  • Maintainability: Standard components make programs easier to understand and maintain.
  • Flexibility: Different containers can be selected according to application requirements.

8. STL vs Traditional Programming

Traditional Programming STL Programming
Programmer may need to implement data structures manually. Provides ready-made containers.
Sorting logic may need to be written manually. Provides algorithms such as sort().
More code may be required for common operations. Often requires fewer lines of code.
Implementation and testing are the programmer's responsibility. Uses standardized library components.
Generic behavior may need additional implementation. Templates support generic programming.

9. Important STL Header Files

Header File Purpose
<vector> Provides the vector container.
<list> Provides the list container.
<map> Provides map and multimap.
<set> Provides set and multiset.
<stack> Provides the stack adapter.
<queue> Provides queue and priority_queue.
<algorithm> Provides common algorithms.
<iterator> Provides iterator utilities.
Note: Each container has its own header. Include the header corresponding to the component you use.

10. Important Points to Remember

  • STL stands for Standard Template Library.
  • STL supports generic programming through templates.
  • Containers store collections of elements.
  • Iterators provide access to container elements.
  • Algorithms perform operations on ranges of elements.
  • vector is a dynamic array.
  • list is generally implemented as a doubly linked list.
  • map stores key-value pairs with unique keys.
  • set stores unique keys.
  • sort() is commonly used to sort elements.
