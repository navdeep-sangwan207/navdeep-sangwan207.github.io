Lesson 4: STL Map in C++

Understanding Key-Value Pairs and the Map Container

  • Understand key-value pairs.

1. Introduction to STL Map

In C++, std::map is an associative container provided by the Standard Template Library (STL). It stores data in the form of key-value pairs.

Each element consists of a unique key and its associated value. A map automatically arranges its elements according to the sorted order of keys.

Key: Used to identify an element.
Value: The data associated with that key.

Example of Key-Value Pairs

Key (Roll Number) Value (Student Name)
101 Rahul
102 Amit
103 Priya

Here, each roll number is a key, and the corresponding student name is its value.

Important: A std::map stores unique keys. Multiple elements cannot have the same key.

2. Internal Working of Map

A standard C++ map is typically implemented using a self-balancing binary search tree, commonly a Red-Black Tree.

This structure keeps keys sorted and allows efficient searching, insertion and deletion.

Example Structure

map<int, string> students; students[101] = "Rahul"; students[102] = "Amit"; students[103] = "Priya"; KEY VALUE +-----+ +---------+ | 101 | ---> | Rahul | +-----+ +---------+ +-----+ +---------+ | 102 | ---> | Amit | +-----+ +---------+ +-----+ +---------+ | 103 | ---> | Priya | +-----+ +---------+
The diagram illustrates key-value relationships. Internally, a map maintains its elements in key-sorted order using its tree-based structure.

3. Header File and Syntax

To use the map container, include the following header:

#include <map>

Declaration Syntax

map<key_data_type, value_data_type> map_name;

Example

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students; return 0; }

Here, the map named students stores integer keys and string values.

4. Initialization of a Map

A map can be initialized using an initializer list containing key-value pairs.

Example

#include <iostream> #include <map> #include <string> using namespace std; int main() { map<int, string> students = { {103, "Priya"}, {101, "Rahul"}, {102, "Amit"} }; for (auto item : students) { cout << item.first << " : " << item.second << endl; } return 0; }
Expected Output 
101 : Rahul
102 : Amit
103 : Priya

Although the keys were inserted in the order 103, 101 and 102, the map displays them in ascending key order.

first: Accesses the key of a map element.
second: Accesses the value associated with that key.

5. Inserting Elements into a Map

Elements can be inserted into a map using insert(), emplace() or the subscript operator [].

Method Description
insert() Inserts a key-value pair.
emplace() Constructs an element directly in the map.
operator[] Accesses an existing key or inserts a default value for a missing key.

Example: insert()

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students; students.insert({101, "Rahul"}); students.insert({102, "Amit"}); students.insert({103, "Priya"}); for (auto item : students) { cout << item.first << " : " << item.second << endl; } return 0; }
Expected Output 
101 : Rahul
102 : Amit
103 : Priya

Example: emplace()

map<int, string> students; students.emplace(101, "Rahul"); students.emplace(102, "Amit");

Example: Subscript Operator []

map<int, string> students; students[101] = "Rahul"; students[102] = "Amit";
Note: If a key already exists, insert() and emplace() do not replace its existing value. The subscript operator can be used to update the value.

6. Accessing Map Elements

Map elements can be accessed using the subscript operator [] or the at() member function.

Method 1: Using []

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"} }; cout << students[101]; return 0; }
Expected Output 
Rahul

Method 2: Using at()

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"} }; cout << students.at(102); return 0; }
Expected Output 
Amit
Difference:
[] inserts a new element with a default value if the key does not exist.
at() accesses an existing key and throws out_of_range if the key does not exist.

7. Updating Map Values

The subscript operator or at() can be used to update the value associated with an existing key.

Example

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"} }; students[102] = "Aman"; students.at(101) = "Rohit"; for (auto item : students) { cout << item.first << " : " << item.second << endl; } return 0; }
Expected Output 
101 : Rohit
102 : Aman

8. Deleting Elements from a Map

The erase() function removes elements from a map. The clear() function removes all elements.

Function Description
erase(key) Removes the element with the specified key.
erase(iterator) Removes the element pointed to by an iterator.
clear() Removes all elements from the map.

Example

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"}, {103, "Priya"} }; students.erase(102); for (auto item : students) { cout << item.first << " : " << item.second << endl; } return 0; }
Expected Output 
101 : Rahul
103 : Priya

9. Searching Elements in a Map

The find() function searches for a key and returns an iterator to the element if it exists.

If the key is not found, find() returns map.end().

Example: find()

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"}, {103, "Priya"} }; auto it = students.find(102); if (it != students.end()) { cout << "Found: " << it->second; } else { cout << "Key not found"; } return 0; }
Expected Output 
Found: Amit

Using count()

if (students.count(101) == 1) { cout << "Key exists"; } else { cout << "Key does not exist"; }
Note: Since map keys are unique, count() returns either 1 (key exists) or 0 (key does not exist).

10. Traversing a Map

A map can be traversed using a range-based for loop or iterators.

Method 1: Range-Based For Loop

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"}, {103, "Priya"} }; for (auto item : students) { cout << item.first << " : " << item.second << endl; } return 0; }

Method 2: Using Iterators

#include <iostream> #include <map> using namespace std; int main() { map<int, string> students = { {101, "Rahul"}, {102, "Amit"}, {103, "Priya"} }; for (auto it = students.begin(); it != students.end(); ++it) { cout << it->first << " : " << it->second << endl; } return 0; }
Expected Output (Both Methods) 
101 : Rahul
102 : Amit
103 : Priya
begin(): Returns an iterator to the first element.
end(): Returns an iterator after the last element.
first: Accesses the key.
second: Accesses the value.
it->first: Accesses the key through an iterator.
it->second: Accesses the value through an iterator.

11. Important Map Member Functions

Function Purpose
insert() Inserts a key-value pair.
emplace() Constructs an element in the map.
erase() Removes an element.
find() Searches for a key.
count() Checks whether a key exists.
size() Returns the number of elements.
empty() Checks whether the map is empty.
clear() Removes all elements.
begin() Returns an iterator to the first element.
end() Returns an iterator after the last element.
at() Accesses the value for an existing key.
operator[] Accesses or inserts an element using a key.

12. Map vs Unordered Map

C++ provides another associative container called unordered_map. Both containers store key-value pairs, but their internal implementations differ.

Feature map unordered_map
Header <map> <unordered_map>
Internal structure Typically Red-Black Tree Hash table
Element order Sorted by key No guaranteed order
Key uniqueness Unique Unique
Search complexity O(log n) Average O(1), worst O(n)
Insertion complexity O(log n) Average O(1), worst O(n)
When to use map? Use map when you need elements in sorted key order or require ordered traversal.

When to use unordered_map? Use unordered_map when sorted order is not required and average constant-time lookup is useful.

13. Time Complexity of Map Operations

Operation Typical Complexity
insert() O(log n)
emplace() O(log n)
find() O(log n)
erase(key) O(log n)
at() O(log n)
operator[] O(log n)
size() O(1)
empty() O(1)
clear() O(n)
Traversal O(n)
The logarithmic complexity of common map operations is due to its balanced tree structure. Here, n represents the number of elements.

14. Practical Program: Student Record Management

This program uses a map to store student roll numbers and names. It demonstrates insertion, searching and traversal.

#include <iostream> #include <map> #include <string> using namespace std; int main() { map<int, string> students; // Insert student records students[101] = "Rahul"; students[102] = "Amit"; students[103] = "Priya"; // Display all records cout << "Student Records:\n"; for (auto item : students) { cout << "Roll No: " << item.first << ", Name: " << item.second << endl; } // Search for a student int rollNo = 102; auto it = students.find(rollNo); if (it != students.end()) { cout << "\nStudent Found: " << it->second; } else { cout << "\nStudent Not Found"; } return 0; }
Expected Output 
Student Records:
Roll No: 101, Name: Rahul
Roll No: 102, Name: Amit
Roll No: 103, Name: Priya

Student Found: Amit

15. Advantages and Limitations of Map

Advantages

  • Stores data as key-value pairs.
  • Maintains keys in sorted order.
  • Provides efficient searching, insertion and deletion.
  • Prevents duplicate keys.
  • Useful for dictionaries, student records and lookup tables.

Limitations

  • Does not allow duplicate keys.
  • Operations are generally O(log n), not average O(1).
  • Maintaining sorted order has some overhead.
  • Requires more memory than a simple array in many cases.

16. Important Points to Remember

  • std::map is an associative container in STL.
  • It stores data as key-value pairs.
  • Include the <map> header file.
  • Each key must be unique.
  • Elements are automatically sorted by key.
  • first represents the key and second represents the value.
  • insert() and emplace() add new elements.
  • erase() removes elements.
  • find() searches for a key.
  • at() throws an exception if the key does not exist.
  • operator[] can insert a missing key with a default value.
  • Most search, insertion and deletion operations take O(log n).
