1. Introduction to Vector

A vector is a sequence container in the C++ Standard Template Library (STL). It stores elements of the same data type in a dynamically resizable array.

Unlike a traditional fixed-size array, a vector can automatically grow or shrink when elements are added or removed.

Definition: A vector is a dynamic array that provides automatic memory management, fast random access, and convenient insertion and deletion operations.

Important Characteristics

  • Stores elements in a continuous memory block.
  • Automatically manages its storage capacity.
  • Supports random access using an index.
  • Allows duplicate elements.
  • Maintains the insertion order of elements.
  • Provides efficient insertion and deletion at the end.
Remember: A vector is similar to an array, but its size can change dynamically during program execution.

2. Vector Header File and Syntax

To use a vector, include the <vector> header file in your C++ program.

Syntax

#include <vector>

vector<data_type> vector_name;

Examples of Vector Declaration

Declaration Description
vector<int> v; Creates an empty integer vector.
vector<float> v; Creates an empty float vector.
vector<char> v; Creates an empty character vector.
vector<string> v; Creates an empty string vector.
Note: For vector<string>, include the <string> header as well.

3. Vector Initialization

A vector can be initialized in different ways depending on the values and initial size required.

3.1 Empty Vector

vector<int> numbers;

3.2 Initializer List

vector<int> numbers = {10, 20, 30, 40};

3.3 Vector with Fixed Initial Size

vector<int> numbers(5);

Creates a vector containing five integer elements, value-initialized to zero.

3.4 Vector with Same Initial Value

vector<int> numbers(5, 100);

Creates five elements, each initialized to 100.

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    cout << "Vector elements: ";

    for (int x : numbers) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

Vector elements:
10 20 30 40

💡 Explanation

  • The vector stores four integer values.
  • The range-based for loop accesses each element.
  • The variable x receives one element at a time.

4. Accessing Vector Elements

Vector elements can be accessed using index positions or member functions.

4.1 Using the Subscript Operator []

vector<int> v = {10, 20, 30};

cout << v[0];

The index starts from zero. Therefore, v[0] accesses the first element.

4.2 Using at()

cout << v.at(1);

at() accesses an element using a position and performs bounds checking. It throws std::out_of_range if the index is invalid.

4.3 Using front() and back()

cout << v.front();
cout << v.back();
  • front() returns the first element.
  • back() returns the last element.

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40};

    cout << "First element: " << v[0] << endl;
    cout << "Second element: " << v.at(1) << endl;
    cout << "Last element: " << v.back() << endl;

    return 0;
}

▶️ Expected Output

First element: 10
Second element: 20
Last element: 40
Important: Accessing an invalid index with [] results in undefined behavior. Use at() when runtime bounds checking is needed.

5. Adding Elements to a Vector

STL provides member functions to add new elements to a vector.

5.1 push_back()

Adds a new element at the end of the vector. 

vector<int> v = {10, 20};

v.push_back(30);

5.2 emplace_back()

Constructs a new element directly at the end of the vector. It is particularly useful for objects with constructors. 

vector<int> v;

v.emplace_back(10);
v.emplace_back(20);

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;

    v.push_back(10);
    v.push_back(20);
    v.emplace_back(30);

    cout << "Vector elements: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

Vector elements:
10 20 30

💡 Explanation

  • push_back() adds elements at the end.
  • emplace_back() constructs an element at the end.
  • The vector automatically manages its storage as needed.

6. Inserting Elements into a Vector

The insert() function adds elements at a specified position in the vector.

Syntax

vector_name.insert(position, value);

The position is specified using an iterator.

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 40};

    v.insert(v.begin() + 2, 30);

    cout << "After insertion: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

After insertion:
10 20 30 40

💡 Explanation

  • begin() points to the first element.
  • begin() + 2 identifies the third position.
  • insert() places 30 at that position.
  • Existing elements after that position are shifted.
Remember: Inserting in the middle of a vector can be slower because elements may need to be shifted.

7. Deleting Elements from a Vector

STL provides erase() and pop_back() to remove elements from a vector.

7.1 pop_back()

Removes the last element of the vector. 

v.pop_back();

7.2 erase()

Removes an element or a range of elements using iterators. 

v.erase(v.begin());

7.3 clear()

Removes all elements from the vector. 

v.clear();

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40};

    v.pop_back();

    cout << "After pop_back(): ";
    for (int x : v) {
        cout << x << " ";
    }

    v.erase(v.begin());

    cout << "\nAfter erase(): ";
    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

After pop_back():
10 20 30

After erase():
20 30

💡 Explanation

  • pop_back() removes 40.
  • erase(v.begin()) removes the first element, 10.
  • The remaining elements are 20 and 30.

8. Traversing a Vector

Traversal means accessing each element of a vector one by one.

8.1 Using a Traditional for Loop

for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}

8.2 Using a Range-Based for Loop

for (int x : v) {
    cout << x << " ";
}

8.3 Using an Iterator

for (vector<int>::iterator it = v.begin();
     it != v.end(); ++it) {
    cout << *it << " ";
}

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {5, 10, 15, 20};

    cout << "Using for loop: ";

    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }

    cout << "\nUsing range-based loop: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}

▶️ Expected Output

Using for loop:
5 10 15 20

Using range-based loop:
5 10 15 20

9. Important Vector Member Functions

Vector provides several useful member functions for accessing, modifying, and managing its elements.

Function Purpose
push_back() Adds an element at the end.
emplace_back() Constructs an element at the end.
pop_back() Removes the last element.
insert() Inserts an element at a specified position.
erase() Removes an element or range of elements.
clear() Removes all elements.
size() Returns the number of elements.
capacity() Returns the current storage capacity.
empty() Checks whether the vector contains no elements.
resize() Changes the number of elements.
reserve() Requests storage capacity for at least a specified number of elements.
front() Accesses the first element.
back() Accesses the last element.
at() Accesses an element with bounds checking.
begin() Returns an iterator to the first element.
end() Returns an iterator after the last element.

10. Difference Between Size and Capacity

Size and capacity are two important concepts in vector memory management.

Size

size() returns the number of elements currently stored in the vector.

Capacity

capacity() returns the number of elements the vector can hold in its currently allocated storage without requiring another allocation.

Example Program

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;

    v.reserve(5);

    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    cout << "Size: " << v.size() << endl;
    cout << "Capacity: " << v.capacity();

    return 0;
}

▶️ Expected Output

Size: 3
Capacity: 5

💡 Explanation

  • reserve(5) requests capacity for at least five elements.
  • Three elements are inserted.
  • Therefore, size() returns 3.
  • The requested capacity is at least 5.
Important: capacity() is implementation-dependent. reserve(5) guarantees capacity of at least 5, not necessarily exactly 5.
Size Capacity
Number of actual elements. Allocated storage for elements.
Changes when elements are added or removed. Changes when storage is reallocated or reserved.
Cannot exceed capacity. Can be greater than or equal to size.

11. resize() and reserve()

11.1 resize()

resize() changes the number of elements in the vector. If the vector grows, new elements are added and value-initialized when no fill value is supplied. 

vector<int> v = {10, 20, 30};

v.resize(5);

The resulting vector contains five elements: 10, 20, 30, 0, 0.

11.2 reserve()

reserve() requests enough storage capacity for at least the specified number of elements. It does not change the vector's size. 

vector<int> v;

v.reserve(100);
Key Difference: resize() changes the number of elements, whereas reserve() changes the storage capacity without changing the number of elements.

12. Vector Memory Management and Performance

A vector stores its elements in contiguous memory. When more storage is required, it may allocate a larger memory block and move or copy its elements.

Important Performance Characteristics

Operation Typical Complexity
Access by index O(1)
Insert at end Amortized O(1)
Remove from end O(1)
Search by value O(n)
Insert in middle O(n)
Erase from middle O(n)
Note: Reallocation can invalidate iterators, pointers, and references to vector elements. Insertions and erasures can also invalidate some or all of them depending on their positions.

13. Advantages and Disadvantages of Vector

Advantages

  • Dynamic resizing.
  • Fast random access.
  • Automatic memory management.
  • Supports iterators and STL algorithms.
  • Efficient insertion and deletion at the end.
  • Stores elements contiguously.

Disadvantages

  • Insertion and deletion in the middle can be costly.
  • Reallocation can require moving or copying elements.
  • Reallocation can invalidate existing iterators and references.
  • Capacity may be larger than the actual number of elements.

14. Practical Program: Find the Sum of Vector Elements

This program stores integer values in a vector and calculates their total sum.

C++ Program
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40, 50};

    int sum = 0;

    for (int x : numbers) {
        sum += x;
    }

    cout << "Sum of elements: " << sum;

    return 0;
}

▶️ Expected Output

Sum of elements: 150

💡 Explanation

  • The vector stores five integer values.
  • sum is initialized to zero.
  • The range-based loop visits every element.
  • Each element is added to sum.
  • The final sum is 150.

15. Important Points to Remember

  • Vector is a sequence container in STL.
  • Include <vector> to use vectors.
  • Vector elements are stored in contiguous memory.
  • Vector supports dynamic resizing.
  • Indexing starts from zero.
  • push_back() adds an element at the end.
  • pop_back() removes the last element.
  • insert() adds elements at a specified position.
  • erase() removes elements using iterators.
  • size() returns the number of elements.
  • capacity() returns allocated element capacity.
  • reserve() requests storage without changing size.
  • resize() changes the number of elements.
