Basics of Pointers in C++

Understand memory addresses, pointer variables, dereferencing, pointer initialization, and basic pointer operations in C++.

1. Introduction to Pointers

A pointer is a variable that stores the memory address of another variable.

Normally, a variable stores a data value. A pointer stores the address where that value is located in computer memory.

Example: Normal Variable

int number = 25;

Here, number stores the integer value 25.

Example: Pointer Variable

int number = 25; int *ptr = &number;

Here, ptr stores the memory address of number.

Remember: A normal variable stores a value, whereas a pointer variable stores a memory address.

2. Understanding Memory Addresses

Computer memory is divided into locations. Each memory location has an address that identifies it.

When a variable is created, memory is allocated for it. The address-of operator can be used to obtain its address.

Conceptual Memory Representation

Variable number
→
Value 25
Pointer ptr
→
Address Address of number
Note: The memory addresses shown by a real program depend on the execution environment. Never assume a fixed address for a variable.

3. Pointer Operators

C++ mainly uses two operators when working with basic pointers.

Operator Name Purpose
& Address-of operator Returns the memory address of a variable.
* Dereference operator Accesses the value stored at the address held by a pointer.

Address-of Operator (&)

int number = 25; cout << &number;

The expression &number gives the memory address of the variable number.

Dereference Operator (*)

int number = 25; int *ptr = &number; cout << *ptr;
Expected Output 
25

The expression *ptr accesses the value stored at the memory address held by ptr.

4. Declaration of Pointers

A pointer must be declared with a data type. The data type indicates the type of object the pointer can point to.

Syntax

data_type *pointer_name;

Examples

int *ptr1; float *ptr2; char *ptr3; double *ptr4;
Declaration Pointer Type
int *ptr1; Pointer to an integer
float *ptr2; Pointer to a float
char *ptr3; Pointer to a character
double *ptr4; Pointer to a double
Important: The pointer's data type determines the type of object it can point to and how pointer arithmetic is performed.

5. Pointer Initialization

Pointer initialization means assigning a valid memory address to a pointer variable.

Syntax

data_type variable = value; data_type *pointer = &variable;

Example Program

#include <iostream> using namespace std; int main() { int number = 100; int *ptr = &number; cout << "Value: " << number << endl; cout << "Address: " << &number << endl; cout << "Pointer value: " << ptr << endl; cout << "Value using pointer: " << *ptr << endl; return 0; }
Expected Output 
Value: 100
Address: (memory address)
Pointer value: (same memory address)
Value using pointer: 100
Explanation:
  • number stores 100.
  • &number obtains its address.
  • ptr stores that address.
  • *ptr accesses the value 100.

6. Accessing and Modifying Values Using Pointers

A pointer can be used to read and modify the value of the variable it points to.

Example Program

#include <iostream> using namespace std; int main() { int number = 50; int *ptr = &number; cout << "Original value: " << number << endl; *ptr = 200; cout << "Modified value: " << number << endl; return 0; }
Expected Output 
Original value: 50
Modified value: 200

The statement *ptr = 200; changes the value stored at the address held by ptr. Since ptr points to number, the value of number becomes 200.

7. Null Pointers

A null pointer is a pointer that does not point to a valid object or function.

In modern C++, use nullptr to initialize a pointer when it does not currently point to an object.

Example Program

#include <iostream> using namespace std; int main() { int *ptr = nullptr; if (ptr == nullptr) { cout << "Pointer is null." << endl; } return 0; }
Expected Output 
Pointer is null.
Important: Never dereference a null pointer. Accessing *ptr when ptr is null causes undefined behavior.

8. Pointer Arithmetic

Pointer arithmetic allows certain operations on pointers, such as incrementing and decrementing them.

When a pointer is incremented, it moves to the next element of its pointed-to type, not simply to the next byte.

Common Pointer Arithmetic Operations

Operation Meaning
ptr++ Moves the pointer to the next element.
ptr-- Moves the pointer to the previous element.
ptr + n Moves forward by n elements.
ptr - n Moves backward by n elements.
ptr2 - ptr1 Gives the number of elements between two pointers in the same array (when valid).

Example Program

#include <iostream> using namespace std; int main() { int arr[3] = {10, 20, 30}; int *ptr = arr; cout << "First element: " << *ptr << endl; ptr++; cout << "Second element: " << *ptr << endl; ptr++; cout << "Third element: " << *ptr << endl; return 0; }
Expected Output 
First element: 10
Second element: 20
Third element: 30
Explanation:
  • arr represents the address of the first array element in this expression.
  • ptr initially points to arr[0].
  • After ptr++, it points to arr[1].
  • After another increment, it points to arr[2].
Note: Pointer arithmetic must remain within the same array object or one position past its end. A one-past-the-end pointer must not be dereferenced.

9. Pointer and Array Relationship

In most expressions, an array name is converted into a pointer to its first element. This is called array-to-pointer conversion.

Example Program

#include <iostream> using namespace std; int main() { int numbers[4] = {10, 20, 30, 40}; int *ptr = numbers; for (int i = 0; i < 4; i++) { cout << *(ptr + i) << endl; } return 0; }
Expected Output 
10
20
30
40

The expression *(ptr + i) accesses the element at index i.

Remember: An array and a pointer are not the same thing. An array has its own fixed size, while a pointer is a separate variable that stores an address.

10. Pointer to Constant and Constant Pointer

C++ provides different ways to use const with pointers.

Pointer to Constant

int number = 10; const int *ptr = &number; // *ptr = 20; // Not allowed number = 20; // Allowed

A pointer to constant prevents modification of the pointed-to value through that pointer. The pointer itself can be changed to point to another compatible object.

Constant Pointer

int first = 10; int second = 20; int *const ptr = &first; *ptr = 15; // Allowed // ptr = &second; // Not allowed

A constant pointer cannot be reassigned to another address, but the pointed-to value can be modified if the object itself is not const.

Comparison

Type Change Pointer Address? Modify Value Through Pointer?
Pointer to constant Yes No
Constant pointer No Yes, if the object is not const

11. Common Pointer Errors

Incorrect pointer usage can cause unexpected behavior and program crashes.

1. Uninitialized Pointer

int *ptr; // *ptr = 10; // Incorrect

The pointer has not been initialized. It does not necessarily point to a valid object.

2. Dereferencing a Null Pointer

int *ptr = nullptr; // cout << *ptr; // Incorrect

A null pointer must not be dereferenced.

3. Dangling Pointer

int *ptr = nullptr; { int number = 50; ptr = &number; } // number no longer exists here. // ptr is now dangling.

A dangling pointer stores the address of an object whose lifetime has ended. Using it to access that object is undefined behavior.

Best Practice: Initialize pointers, check for null before dereferencing when necessary, and never access an object after its lifetime has ended.

12. Complete Pointer Program

The following program demonstrates pointer declaration, initialization, address access, dereferencing, and modification of a variable.

#include <iostream> using namespace std; int main() { int number = 25; int *ptr = &number; cout << "Original value: " << number << endl; cout << "Memory address: " << &number << endl; cout << "Address stored in pointer: " << ptr << endl; cout << "Value using pointer: " << *ptr << endl; *ptr = 75; cout << "Modified value: " << number << endl; return 0; }
Expected Output 
Original value: 25
Memory address: (memory address)
Address stored in pointer: (same memory address)
Value using pointer: 25
Modified value: 75

13. Practical Applications of Pointers

Pointers are important in C++ and systems programming. They are used in several areas, including:

  • Dynamic memory allocation: Managing memory allocated at runtime.
  • Arrays and strings: Accessing elements and working with character data.
  • Functions: Passing addresses to functions and modifying original objects.
  • Data structures: Building linked lists, trees, graphs, and other structures.
  • Object-oriented programming: Working with object pointers and runtime polymorphism.
  • Systems programming: Managing resources and interacting with low-level APIs.
Connection to Embedded Systems: Pointers are useful for working with arrays, buffers, data structures, and hardware-related interfaces. However, direct hardware register access requires platform-specific definitions and appropriate qualifiers such as volatile where applicable.

  1. NULLPTR
  2. null
  3. nullptr

  1. It always increases by one byte.

17. Lesson Summary

  • A pointer is a variable that stores a memory address.
