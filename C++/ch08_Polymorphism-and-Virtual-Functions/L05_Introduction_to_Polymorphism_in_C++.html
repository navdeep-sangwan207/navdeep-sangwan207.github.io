1. Introduction to Polymorphism

Polymorphism is one of the fundamental concepts of Object-Oriented Programming (OOP).

The word polymorphism comes from two Greek words:

  • Poly: Many
  • Morphism: Forms

Therefore, polymorphism means many forms. In C++, it allows the same function name, operator or interface to represent different behaviours depending on the context.

Real-life example: A person can behave as a student in a classroom, an employee in an office and a customer in a shop. The same person has different roles in different situations. This illustrates the general idea of many forms.

2. Why Do We Need Polymorphism?

Without polymorphism, a program may require separate function names and separate code for every type of object. Polymorphism helps organize related operations through a common interface.

  • Improves code reusability.
  • Reduces unnecessary code duplication.
  • Provides flexibility in program design.
  • Supports extensible object-oriented applications.
  • Allows common interfaces for different object types.
  • Helps implement runtime behaviour selection.

3. Types of Polymorphism in C++

Polymorphism in C++ is commonly classified into two major categories.

Type Also Known As Common Mechanisms
Compile-Time Polymorphism Static Polymorphism Function overloading, operator overloading
Runtime Polymorphism Dynamic Polymorphism Virtual functions and overriding
Important: Compile-time polymorphism is resolved during compilation. Runtime polymorphism allows the appropriate overridden virtual function to be selected during program execution.

4. Compile-Time Polymorphism

Compile-time polymorphism occurs when the compiler determines which function or operation to use during compilation.

Two common techniques are:

  • Function overloading
  • Operator overloading

4.1 Function Overloading

Function overloading means defining multiple functions with the same name but different parameter lists. The compiler selects the appropriate function based on the arguments supplied. 

#include <iostream>
using namespace std;

class Calculator
{
public:
    int add(int a, int b)
    {
        return a + b;
    }

    double add(double a, double b)
    {
        return a + b;
    }

    int add(int a, int b, int c)
    {
        return a + b + c;
    }
};

int main()
{
    Calculator obj;

    cout << obj.add(10, 20) << endl;
    cout << obj.add(2.5, 3.5) << endl;
    cout << obj.add(10, 20, 30) << endl;

    return 0;
}
Expected Output: 
30
6
60

Explanation

  • The first function accepts two integers.
  • The second function accepts two double values.
  • The third function accepts three integers.
  • The compiler selects the matching overload based on the arguments.
Functions cannot be overloaded by changing only their return type. Their parameter lists must differ.

4.2 Operator Overloading

Operator overloading allows operators such as +, - and == to be given suitable meanings for user-defined types. 

#include <iostream>
using namespace std;

class Number
{
private:
    int value;

public:
    Number(int v)
    {
        value = v;
    }

    Number operator+(const Number& obj)
    {
        return Number(value + obj.value);
    }

    void display()
    {
        cout << value << endl;
    }
};

int main()
{
    Number n1(10);
    Number n2(20);

    Number n3 = n1 + n2;

    n3.display();

    return 0;
}
Expected Output: 
30

Here, the + operator is overloaded to add two Number objects.

5. Runtime Polymorphism

Runtime polymorphism allows a function call to be associated with the appropriate overridden function during program execution.

In C++, runtime polymorphism is commonly implemented using inheritance, function overriding and virtual functions.

Example: Function Overriding Without virtual

#include <iostream>
using namespace std;

class Animal
{
public:
    void sound()
    {
        cout << "Animal makes a sound" << endl;
    }
};

class Dog : public Animal
{
public:
    void sound()
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d;
    d.sound();

    return 0;
}
Expected Output: 
Dog barks
This example demonstrates function overriding and name hiding, but it does not demonstrate runtime polymorphism through a base-class pointer. A virtual function is needed for that behaviour.

6. Function Overriding

Function overriding occurs when a derived class provides its own implementation of a virtual member function inherited from its base class. 

#include <iostream>
using namespace std;

class Animal
{
public:
    virtual void sound()
    {
        cout << "Animal makes a sound" << endl;
    }
};

class Dog : public Animal
{
public:
    void sound() override
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d;
    Animal* ptr = &d;

    ptr->sound();

    return 0;
}
Expected Output: 
Dog barks

The base-class pointer points to a Dog object. Because sound() is virtual, the derived class implementation is selected at runtime.

Note: The override keyword tells the compiler that the derived function is intended to override a virtual base-class function. It helps detect signature mismatches.

7. Virtual Functions and Polymorphism

A virtual function is a member function declared using the virtual keyword in a base class. It supports runtime polymorphism when called through a base-class pointer or reference. 

class Base
{
public:
    virtual void display()
    {
        cout << "Base class";
    }
};

class Derived : public Base
{
public:
    void display() override
    {
        cout << "Derived class";
    }
};

When a base-class pointer refers to a Derived object and calls display(), the Derived implementation is executed.

The next lessons explain derived-class pointers and virtual functions in greater detail.

8. Compile-Time vs Runtime Polymorphism

Feature Compile-Time Runtime
Resolution During compilation During execution
Common mechanisms Function and operator overloading Virtual functions and overriding
Inheritance required Not necessarily Usually used with inheritance
Selection Based on arguments and types Based on the dynamic type of the object
Typical example Multiple add() functions Overridden virtual sound() function

9. Advantages of Polymorphism

  • Improves code flexibility and reusability.
  • Allows a common interface for different classes.
  • Reduces code duplication.
  • Supports extensible software design.
  • Helps implement loosely coupled components.
  • Makes object-oriented programs easier to maintain.

10. Applications of Polymorphism

Application Example
Software Development Different classes implementing a common interface.
Graphics Applications Different shapes providing their own draw() implementation.
Embedded Systems Different hardware components accessed through common interfaces.
Device Drivers Different device implementations using common interfaces.
Game Development Different game objects implementing common behaviour.
Systems Software Different implementations of common software components.

12. Multiple Choice Questions (MCQs)

Q1. What does polymorphism mean?

A. One variable
B. Many forms
C. One class only
D. Data hiding

Answer: B. Many forms

Q2. Which is an example of compile-time polymorphism?

A. Function overloading
B. Virtual function dispatch
C. Runtime binding
D. Dynamic dispatch

Answer: A. Function overloading

Q3. Which keyword supports runtime polymorphism in C++?

A. static
B. const
C. virtual
D. friend

Answer: C. virtual

Q4. Which keyword indicates that a function overrides a virtual base-class function?

A. overload
B. override
C. friend
D. inline

Answer: B. override

Q5. Which feature allows the same function name with different parameter lists?

A. Function overloading
B. Encapsulation
C. Inheritance
D. Abstraction

Answer: A. Function overloading

Q6. Runtime polymorphism is commonly associated with:

A. Virtual functions
B. Local variables
C. Preprocessor directives
D. Macros

Answer: A. Virtual functions

14. Lesson Summary

  • Polymorphism means many forms.
  • It is a fundamental concept of object-oriented programming.
  • Compile-time polymorphism includes function and operator overloading.
  • Runtime polymorphism uses virtual functions and overriding.
  • The override keyword helps verify intended overriding.
  • Polymorphism improves flexibility, reuse and maintainability.
