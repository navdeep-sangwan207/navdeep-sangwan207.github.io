1. Introduction to Abstraction

Abstraction is an object-oriented programming concept that focuses on showing essential features while hiding unnecessary implementation details.

It allows a programmer to define what an object should do without requiring the user of that object to know every detail of how it works.

Real-Life Example

Consider an ATM machine. A user can withdraw money by following simple instructions. The user does not need to understand the internal banking software, database operations, or communication systems.

In C++: Abstract classes and pure virtual functions help implement abstraction by defining common operations that derived classes must implement.

Advantages of Abstraction

  • Hides unnecessary implementation details.
  • Provides a common interface for related classes.
  • Improves code organization.
  • Supports extensible and maintainable software design.
  • Reduces dependency on specific implementations.

2. What is a Pure Virtual Function?

A pure virtual function is a virtual member function declared in a base class using the = 0 syntax.

It specifies an operation that concrete derived classes are required to implement.

Syntax

class Base {
public:
    virtual void display() = 0;
};

Here:

  • virtual declares a virtual function.
  • void display() defines the function signature.
  • = 0 makes it a pure virtual function.
A pure virtual function does not have to be completely without a definition. C++ permits a pure virtual function to have an out-of-class definition, but the class remains abstract.

3. What is an Abstract Class?

An abstract class is a class that contains at least one pure virtual function.

An abstract class cannot be instantiated directly. It is generally used as a base class for other classes.

Basic Syntax

class Shape {
public:
    virtual void draw() = 0;
};

The Shape class is abstract because it contains a pure virtual function named draw().

You cannot create a direct object of Shape, but you can create a pointer or reference to Shape.

4. First Program Using an Abstract Class

In this example, the base class defines a pure virtual function. The derived class implements that function.

#include <iostream>
using namespace std;

class Animal {
public:
    virtual void sound() = 0;
};

class Dog : public Animal {
public:
    void sound() override {
        cout << "Dog barks" << endl;
    }
};

int main() {
    Dog d;

    d.sound();

    return 0;
}
Expected Output 
Dog barks

Explanation:

  1. Animal contains a pure virtual function named sound().
  2. Therefore, Animal is an abstract class.
  3. Dog inherits from Animal.
  4. Dog implements the pure virtual function.
  5. An object of Dog can now be created.

5. Attempting to Create an Abstract-Class Object

An abstract class cannot be instantiated directly.

#include <iostream>
using namespace std;

class Shape {
public:
    virtual void draw() = 0;
};

int main() {
    Shape s;

    return 0;
}
Result: Compilation error. An object of an abstract class cannot be created because the class has an unimplemented pure virtual function.

However, the following declarations are valid:

Shape *ptr;
Shape &ref = someDerivedObject;

A pointer or reference to an abstract class can be used to access a concrete derived-class object.

6. Implementing Multiple Pure Virtual Functions

An abstract class can contain more than one pure virtual function. A concrete derived class must implement all inherited pure virtual functions that remain unimplemented.

#include <iostream>
using namespace std;

class Device {
public:
    virtual void start() = 0;
    virtual void stop() = 0;
};

class Printer : public Device {
public:
    void start() override {
        cout << "Printer started" << endl;
    }

    void stop() override {
        cout << "Printer stopped" << endl;
    }
};

int main() {
    Printer p;

    p.start();
    p.stop();

    return 0;
}
Expected Output 
Printer started
Printer stopped
The Device class defines a common interface. The Printer class provides the actual implementation of both operations.

7. Abstract Class with Multiple Derived Classes

Different derived classes can implement the same pure virtual function in different ways.

#include <iostream>
using namespace std;

class Shape {
public:
    virtual void draw() = 0;
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "Drawing Circle" << endl;
    }
};

class Rectangle : public Shape {
public:
    void draw() override {
        cout << "Drawing Rectangle" << endl;
    }
};

int main() {
    Circle c;
    Rectangle r;

    Shape *ptr;

    ptr = &c;
    ptr->draw();

    ptr = &r;
    ptr->draw();

    return 0;
}
Expected Output 
Drawing Circle
Drawing Rectangle

Explanation: The abstract class provides a common interface. Each derived class implements the same function differently. The base-class pointer accesses the correct implementation through runtime polymorphism.

8. Abstract Class with a Normal Member Function

An abstract class can contain both normal member functions and pure virtual functions.

#include <iostream>
using namespace std;

class Employee {
public:
    void company() {
        cout << "Company: ABC Technologies" << endl;
    }

    virtual void calculateSalary() = 0;
};

class Developer : public Employee {
public:
    void calculateSalary() override {
        cout << "Developer salary calculated" << endl;
    }
};

int main() {
    Developer d;

    d.company();
    d.calculateSalary();

    return 0;
}
Expected Output 
Company: ABC Technologies
Developer salary calculated

The derived class inherits the normal company() function and implements the pure virtual calculateSalary() function.

9. Abstract Class and Constructors

An abstract class can have constructors and destructors even though its objects cannot be created directly.

Its constructor is called as part of constructing a derived-class object, and its destructor participates in destroying that object.

#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base constructor" << endl;
    }

    virtual void display() = 0;

    virtual ~Base() {
        cout << "Base destructor" << endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived constructor" << endl;
    }

    void display() override {
        cout << "Derived display" << endl;
    }

    ~Derived() override {
        cout << "Derived destructor" << endl;
    }
};

int main() {
    Derived d;

    d.display();

    return 0;
}
Expected Output 
Base constructor
Derived constructor
Derived display
Derived destructor
Base destructor
The base destructor is virtual so that derived objects are destroyed correctly when deleted through a base-class pointer.

10. Abstract Class vs Concrete Class

Abstract Class Concrete Class
Contains at least one pure virtual function. Has no unimplemented pure virtual functions.
Cannot be instantiated directly. Can be instantiated.
Often used as a base class. Can be used to create objects.
Can contain normal member functions. Can contain normal and virtual functions.
Defines an interface or common behaviour. Provides a complete implementation for its objects.

11. Abstract Class vs Interface

C++ does not have a separate language keyword called interface. An interface-like design can be created using an abstract class containing pure virtual functions.

Abstract Class Interface-like Abstract Class
Can contain data members. Usually focuses on function declarations.
Can contain constructors and normal functions. Typically defines operations that derived classes must implement.
Can contain pure virtual and implemented virtual functions. Often contains mostly pure virtual functions.
Can provide shared implementation. Usually emphasizes a common contract.
In C++, an interface is commonly represented by an abstract base class with pure virtual functions and a virtual destructor.

12. Real-World Applications

1. Embedded Systems

A common device interface can define operations such as initialize(), read(), and write(). Different hardware devices can implement these operations according to their requirements.

2. Operating Systems

Common interfaces can represent different types of system resources or device operations, while specific implementations handle their individual behaviour.

3. Graphics Applications

A Shape abstract class can define a pure virtual draw() function. Circle, Rectangle, and Triangle classes can implement it differently.

4. Payment Systems

A payment interface can define a common pay() operation. Different payment methods can implement their own processing logic.

5. Software Frameworks

Abstract classes can define common operations that developers implement when extending a framework.

13. Important Rules of Abstract Classes

  1. A class becomes abstract when it has at least one pure virtual function.
  2. A pure virtual function is declared using = 0.
  3. An abstract class cannot be instantiated directly.
  4. Abstract classes can have constructors and destructors.
  5. Abstract classes can contain normal member functions and data members.
  6. Abstract-class pointers and references are allowed.
  7. A derived class must implement all inherited pure virtual functions to become concrete.
  8. If a derived class leaves any pure virtual function unimplemented, it also remains abstract.
  9. A pure virtual function can have a separate definition in C++.
  10. Abstract classes are commonly used to define common interfaces.

16. Short Answer Questions

Q1. What is abstraction?

Abstraction is an OOP concept that exposes essential features while hiding unnecessary implementation details.

Q2. What is a pure virtual function?

A pure virtual function is a virtual member function declared with = 0 in a class.

Q3. What is an abstract class?

An abstract class is a class containing at least one pure virtual function. It cannot be instantiated directly.

Q4. Can an abstract class contain normal functions?

Yes. It can contain normal functions, data members, constructors, destructors, and virtual functions.

Q5. Can we create a pointer to an abstract class?

Yes. An abstract-class pointer can point to an object of a concrete derived class.

Q6. What happens if a derived class does not override a pure virtual function?

The derived class remains abstract if that pure virtual function is still unimplemented.

Q7. What is the difference between virtual and pure virtual functions?

A normal virtual function can have a base-class implementation. A pure virtual function declares an abstract operation using = 0.
