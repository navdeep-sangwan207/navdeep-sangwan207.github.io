Pointer to Object in C++

Learn how pointers store object addresses and how to access class data members and member functions using object pointers.

1. Introduction to Pointer to Object

A pointer to object is a pointer variable that stores the memory address of an object belonging to a class.

Just as a pointer can store the address of an integer variable, an object pointer can store the address of a class object.

Example

class Student { public: int rollNo; }; int main() { Student s1; Student *ptr = &s1; return 0; }

In this example:

  • Student is a class.
  • s1 is an object of the Student class.
  • ptr is a pointer to a Student object.
  • &s1 provides the address of the object.
Remember: An object pointer stores an object's address, not the object's complete data directly.

2. Declaration of Object Pointer

An object pointer is declared using the class name followed by the pointer variable name.

Syntax

ClassName *pointerName;

Examples

class Student { }; class Employee { }; Student *studentPtr; Employee *employeePtr;
Declaration Meaning
Student *ptr; Pointer to a Student object
Employee *ptr; Pointer to an Employee object
Car *ptr; Pointer to a Car object

3. Initialization of Object Pointer

An object pointer is initialized by assigning it the address of an existing object of a compatible class type.

Syntax

ClassName objectName; ClassName *pointerName = &objectName;

Example Program

#include <iostream> using namespace std; class Student { public: int rollNo; }; int main() { Student s1; s1.rollNo = 101; Student *ptr = &s1; cout << "Roll Number: " << s1.rollNo << endl; cout << "Object address: " << &s1 << endl; cout << "Pointer address: " << ptr << endl; return 0; }
Expected Output 
Roll Number: 101
Object address: (memory address)
Pointer address: (same memory address)
Note: The actual memory address varies each time a program runs. The address stored in ptr is the address of object s1.

4. Accessing Data Members Using Object Pointer

C++ provides the arrow operator (->) to access public members of an object through a pointer.

Syntax

pointerName->memberName;

Example Program

#include <iostream> using namespace std; class Student { public: int rollNo; float marks; }; int main() { Student s1; Student *ptr = &s1; ptr->rollNo = 101; ptr->marks = 85.5; cout << "Roll Number: " << ptr->rollNo << endl; cout << "Marks: " << ptr->marks << endl; return 0; }
Expected Output 
Roll Number: 101
Marks: 85.5
Explanation:
  • ptr points to object s1.
  • ptr->rollNo accesses the rollNo member.
  • ptr->marks accesses the marks member.

5. Arrow Operator and Dereference Operator

The arrow operator is a convenient way to access a member through a pointer.

The following two expressions are equivalent:

ptr->rollNo (*ptr).rollNo

Here:

  • *ptr accesses the object pointed to by ptr.
  • (*ptr).rollNo accesses its rollNo member.
  • ptr->rollNo performs the same operation more conveniently.

Example Program

#include <iostream> using namespace std; class Employee { public: int id; }; int main() { Employee e1; Employee *ptr = &e1; (*ptr).id = 5001; cout << "Employee ID: " << ptr->id << endl; return 0; }
Expected Output 
Employee ID: 5001
Important: Parentheses are necessary in (*ptr).id because the member access operator has higher precedence than the unary dereference operator.

6. Calling Member Functions Using Object Pointer

An object pointer can also be used to call public member functions of the object.

Syntax

pointerName->functionName();

Example Program

#include <iostream> using namespace std; class Student { public: int rollNo; void display() { cout << "Roll Number: " << rollNo << endl; } }; int main() { Student s1; Student *ptr = &s1; ptr->rollNo = 102; ptr->display(); return 0; }
Expected Output 
Roll Number: 102

The statement ptr->display(); calls the display() member function through the object pointer.

7. Multiple Objects and Object Pointers

An object pointer can point to different objects of the same class, one at a time.

Example Program

#include <iostream> using namespace std; class Student { public: int rollNo; void display() { cout << "Roll Number: " << rollNo << endl; } }; int main() { Student s1, s2; s1.rollNo = 101; s2.rollNo = 102; Student *ptr = &s1; ptr->display(); ptr = &s2; ptr->display(); return 0; }
Expected Output 
Roll Number: 101
Roll Number: 102
Explanation:
  • Initially, ptr points to s1.
  • The first function call displays s1's data.
  • Then ptr = &s2; changes the pointer to s2.
  • The second function call displays s2's data.

8. Dynamic Object Creation Using new

C++ allows objects to be created dynamically at runtime using the new operator.

The new operator allocates memory for an object and returns a pointer to that object.

Syntax

ClassName *pointerName = new ClassName;

Example Program

#include <iostream> using namespace std; class Student { public: int rollNo; void display() { cout << "Roll Number: " << rollNo << endl; } }; int main() { Student *ptr = new Student; ptr->rollNo = 103; ptr->display(); delete ptr; ptr = nullptr; return 0; }
Expected Output 
Roll Number: 103
Explanation:
  • new Student dynamically creates a Student object.
  • ptr stores the object's address.
  • ptr->rollNo assigns the roll number.
  • ptr->display() calls the member function.
  • delete ptr releases the dynamically allocated object.
  • ptr = nullptr prevents the pointer from retaining the old address.

9. Deleting Dynamically Created Objects

When an object is created using new, its memory should be released using delete when it is no longer required.

Operator Purpose
new Allocates memory and creates an object.
delete Destroys a dynamically allocated object and releases its memory.
new[] Allocates an array of objects.
delete[] Destroys a dynamically allocated array and releases its memory.

Example: Dynamic Array of Objects

#include <iostream> using namespace std; class Student { public: int rollNo; }; int main() { Student *ptr = new Student[3]; for (int i = 0; i < 3; i++) { ptr[i].rollNo = 101 + i; } for (int i = 0; i < 3; i++) { cout << ptr[i].rollNo << endl; } delete[] ptr; ptr = nullptr; return 0; }
Expected Output 
101
102
103
Important: Use delete for a single object allocated with new, and delete[] for an array allocated with new[]. Using the wrong form results in undefined behavior.

10. Object Pointer vs Normal Object

Normal Object Object Pointer
Represents an instance of a class. Stores the address of an object.
Declared using the class name. Declared using the class name and pointer operator.
Members are accessed using the dot operator. Members are commonly accessed using the arrow operator.
Example: Student s1; Example: Student *ptr = &s1;
Can be created as an automatic local object. Can point to existing objects or dynamically allocated objects.

11. Common Errors When Using Object Pointers

1. Using an Uninitialized Pointer

Student *ptr; // ptr->rollNo = 101; // Incorrect

The pointer has not been assigned the address of a valid Student object.

2. Dereferencing a Null Pointer

Student *ptr = nullptr; // ptr->rollNo = 101; // Incorrect

A null pointer does not refer to a valid object.

3. Accessing an Object After Deletion

Student *ptr = new Student; delete ptr; // ptr->rollNo = 101; // Incorrect

After deletion, the object no longer exists. Accessing it through the old pointer is undefined behavior.

Best Practice: Initialize object pointers, check that they refer to valid objects before use, and release dynamically allocated memory exactly once.

12. Complete Practical Program

This program combines object creation, pointer initialization, member access, member function calls, and dynamic memory management.

#include <iostream> using namespace std; class Employee { public: int id; float salary; void setData(int employeeId, float employeeSalary) { id = employeeId; salary = employeeSalary; } void display() { cout << "Employee ID: " << id << endl; cout << "Salary: " << salary << endl; } }; int main() { Employee *ptr = new Employee; ptr->setData(1001, 25000.50); cout << "Employee Details" << endl; ptr->display(); delete ptr; ptr = nullptr; return 0; }
Expected Output 
Employee Details
Employee ID: 1001
Salary: 25000.5

13. Practical Applications of Object Pointers

  • Dynamic object creation: Creating objects at runtime.
  • Data structures: Building linked lists, trees, and graphs using class objects.
  • Object-oriented programming: Working with objects through pointers.
  • Inheritance: Using base-class pointers to refer to derived-class objects.
  • Runtime polymorphism: Calling overridden virtual functions through base-class pointers.
  • Resource management: Managing dynamically allocated resources.
Connection to the Next Lessons: Object pointers are an important foundation for understanding pointers to derived classes and virtual functions. These concepts are used together to implement runtime polymorphism in C++.

15. Multiple Choice Questions

Q1. What does an object pointer store?

  1. Only an integer value
  2. The address of an object
  3. A class definition
  4. A function result

Answer: b) The address of an object

Q2. Which operator is commonly used to access members through an object pointer?

  1. .
  2. ::
  3. ->
  4. &

Answer: c) ->

Q3. Which statement creates a dynamic object?

  1. Student ptr;
  2. Student *ptr = new Student;
  3. Student &ptr;
  4. new ptr Student;

Answer: b) Student *ptr = new Student;

Q4. Which operator releases a single dynamically allocated object?

  1. remove
  2. free
  3. delete
  4. clear

Answer: c) delete

Q5. Which expression is equivalent to ptr->id?

  1. *ptr.id
  2. (*ptr).id
  3. &ptr.id
  4. ptr.id*

Answer: b) (*ptr).id
