Function Pointers in C++

Understanding how pointers can store and call function addresses

1. Introduction to Function Pointers

A function pointer is a pointer that stores the address of a function. Just as a normal pointer stores the memory address of a variable, a function pointer stores the address of a function.

Using a function pointer, we can call a function indirectly without directly writing its name in the function call.

Example: If a function named add() is stored at a particular memory address, a function pointer can store that address and use it to call add().

2. Basic Function Pointer Syntax

The general syntax for declaring a function pointer is:

return_type (*pointer_name)(parameter_types);

Example:

int (*ptr)(int, int);

Explanation:

  • int – Return type of the function.
  • *ptr – Declares a pointer named ptr.
  • (int, int) – Function parameter types.
Important: Parentheses around *ptr are essential. Without them, the declaration has a different meaning.

3. Declaring and Initializing a Function Pointer

Consider a function that adds two integers.

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int (*ptr)(int, int);

    ptr = add;

    cout << "Result: " << ptr(10, 20);

    return 0;
}
Expected Output: 
Result: 30

Explanation

  1. add() is a normal function.
  2. ptr is declared as a function pointer.
  3. ptr = add; assigns the function address to the pointer.
  4. ptr(10, 20) calls the function through the pointer.

4. Calling a Function Using a Pointer

A function can be called through a function pointer in two equivalent ways. 

ptr(10, 20);

(*ptr)(10, 20);

Both statements call the function whose address is stored in ptr.

The function name can be used to refer to its address in this assignment. Writing &add is also valid: ptr = &add;.

5. Function Pointer with Multiple Functions

A function pointer can point to different functions, provided their return types and parameter types match its declaration. 

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int main()
{
    int (*operation)(int, int);

    operation = add;
    cout << "Addition: " << operation(20, 10) << endl;

    operation = subtract;
    cout << "Subtraction: " << operation(20, 10) << endl;

    return 0;
}
Expected Output: 
Addition: 30
Subtraction: 10

The same pointer first calls add() and then calls subtract().

6. Passing a Function Pointer as an Argument

A function pointer can be passed as an argument to another function. This allows the receiving function to execute different operations depending on the function address supplied. 

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int calculate(int x, int y, int (*operation)(int, int))
{
    return operation(x, y);
}

int main()
{
    cout << "Result: " << calculate(15, 5, add);

    return 0;
}
Expected Output: 
Result: 20
How it works:
  • calculate() receives two integers.
  • It also receives a pointer to a function.
  • It calls the supplied function using operation(x, y).

7. Function Pointers and Callback Functions

A callback is a function that is passed to another function so that it can be called when required. Function pointers provide one way to implement callbacks in C++. 

#include <iostream>
using namespace std;

void displayMessage()
{
    cout << "Callback function executed." << endl;
}

void process(void (*callback)())
{
    cout << "Processing..." << endl;
    callback();
}

int main()
{
    process(displayMessage);

    return 0;
}
Expected Output: 
Processing...
Callback function executed.

Here, displayMessage() is passed to process() as a function pointer. The process() function invokes it.

8. Function Pointers vs Normal Pointers

Normal Pointer Function Pointer
Stores the address of a variable. Stores the address of a function.
Can access or modify data through dereferencing. Can call a function through the stored address.
Example: int *ptr; Example: int (*ptr)(int, int);

9. Function Pointer vs Function Reference

A function pointer is a variable that stores a function address. A function reference is an alias for a function. 

#include <iostream>
using namespace std;

void display()
{
    cout << "Hello C++";
}

int main()
{
    void (*ptr)() = display;
    void (&ref)() = display;

    ptr();
    cout << endl;
    ref();

    return 0;
}
Expected Output: 
Hello C++
Hello C++

10. Advantages of Function Pointers

  • Allow functions to be called indirectly.
  • Support callback mechanisms.
  • Help implement flexible function selection.
  • Can be used in event-handling systems.
  • Useful in embedded and system-level programming.
  • Can help build tables of function operations.

11. Applications of Function Pointers

Application Purpose
Callback Functions Pass a function to another function for later execution.
Embedded Systems Support callback and handler mechanisms in firmware.
Event Handling Associate functions with events or actions.
Function Tables Select an operation using an index or condition.
System Programming Support configurable function execution.
Modern C++ also provides alternatives such as std::function, lambdas and callable objects. Function pointers remain useful when a simple function address is sufficient.

12. Common Mistakes

  • Incorrect declaration: The pointer's return type and parameter types must match the function.
  • Calling an uninitialized pointer: Initialize the pointer before calling it.
  • Calling a null pointer: Check that the pointer is not nullptr.
  • Wrong function signature: Do not assign an incompatible function to the pointer. 
int (*ptr)(int, int) = nullptr;

// Check before calling
if (ptr != nullptr)
{
    cout << ptr(10, 20);
}

14. Multiple Choice Questions (MCQs)

Q1. What does a function pointer store?

A. Variable value
B. Function address
C. Class object
D. Array size

Answer: B. Function address

Q2. Which is a valid function pointer declaration?

A. int *ptr(int, int);
B. int (*ptr)(int, int);
C. int ptr*(int, int);
D. int ptr(int, int)*;

Answer: B. int (*ptr)(int, int);

Q3. Which operator is used to obtain a function's address?

A. *
B. &
C. ->
D. %

Answer: B. &

Q4. What is a callback function?

A. A function passed to another function for execution
B. A constructor
C. A destructor
D. A recursive variable

Answer: A. A function passed to another function for execution

Q5. Which value represents a null pointer in modern C++?

A. 0.5
B. nullptr
C. void
D. NULLPTR

Answer: B. nullptr
