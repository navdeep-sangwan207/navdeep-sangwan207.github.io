Pointer to Derived Class in C++

Understanding inheritance, object pointers and polymorphism

1. Introduction to Pointers in Inheritance

In C++, inheritance allows one class to acquire the properties and behaviours of another class. A derived class inherits accessible members from its base class.

A pointer to a derived class is a pointer variable that stores the address of an object belonging to that derived class.

Example: If Dog is derived from Animal, then a pointer declared as Dog* ptr can store the address of a Dog object.

2. Declaring and Initializing a Derived-Class Pointer

The general syntax is:

DerivedClass* pointer_name = &derived_object;

Example:

#include <iostream>
using namespace std;

class Animal
{
public:
    void eat()
    {
        cout << "Animal eats" << endl;
    }
};

class Dog : public Animal
{
public:
    void bark()
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d1;

    Dog* ptr = &d1;

    ptr->eat();
    ptr->bark();

    return 0;
}
Expected Output: 
Animal eats
Dog barks

Explanation

  • Animal is the base class.
  • Dog is the derived class.
  • d1 is an object of the Dog class.
  • ptr stores the address of d1.
  • The pointer can access accessible inherited and derived-class members.

3. Accessing Members Using a Derived-Class Pointer

The arrow operator (->) is used to access members through a pointer. 

#include <iostream>
using namespace std;

class Vehicle
{
public:
    int speed = 60;

    void showVehicle()
    {
        cout << "Vehicle speed: " << speed << endl;
    }
};

class Car : public Vehicle
{
public:
    int doors = 4;

    void showCar()
    {
        cout << "Number of doors: " << doors << endl;
    }
};

int main()
{
    Car c1;
    Car* ptr = &c1;

    ptr->showVehicle();
    ptr->showCar();

    return 0;
}
Expected Output: 
Vehicle speed: 60
Number of doors: 4
A derived-class pointer can access inherited public and protected members according to their access rules, along with its own accessible members. Private members of the base class cannot be accessed directly.

4. Base-Class Pointer Pointing to a Derived-Class Object

C++ allows a base-class pointer to store the address of an object of a publicly derived class. This is known as upcasting. 

#include <iostream>
using namespace std;

class Animal
{
public:
    void eat()
    {
        cout << "Animal eats" << endl;
    }
};

class Dog : public Animal
{
public:
    void bark()
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d1;

    Animal* ptr = &d1;

    ptr->eat();

    // ptr->bark(); // Error: bark() is not a member of Animal

    return 0;
}
Expected Output: 
Animal eats
Explanation:
  • ptr is declared as an Animal pointer.
  • It stores the address of a Dog object.
  • It can access members declared in Animal that are accessible through the pointer type.
  • It cannot directly access Dog-specific members such as bark().

5. Difference Between Base-Class and Derived-Class Pointers

Base-Class Pointer Derived-Class Pointer
Declared using the base-class type. Declared using the derived-class type.
Can point to a base object or a suitable derived object. Normally points to an object of its derived type or a further-derived type.
Can directly access accessible base-class members. Can directly access accessible inherited and derived-class members.
Useful for runtime polymorphism with virtual functions. Useful when derived-specific functionality is required.

6. Understanding Upcasting

Upcasting means converting a derived-class pointer to a base-class pointer.

This conversion is implicit and safe when the inheritance relationship and access rules permit it. 

#include <iostream>
using namespace std;

class Base
{
public:
    void display()
    {
        cout << "Base class function" << endl;
    }
};

class Derived : public Base
{
public:
    void show()
    {
        cout << "Derived class function" << endl;
    }
};

int main()
{
    Derived obj;

    Derived* dptr = &obj;

    Base* bptr = dptr;

    bptr->display();

    return 0;
}
Expected Output: 
Base class function
Upcasting is commonly used to work with different derived objects through a common base-class interface.

7. Understanding Downcasting

Downcasting means converting a base-class pointer to a derived-class pointer.

Unlike upcasting, downcasting is not generally safe without checking the actual object type.

Using dynamic_cast

In C++, dynamic_cast can be used for checked downcasting when the base class is polymorphic. A polymorphic class has at least one virtual function. 

#include <iostream>
using namespace std;

class Base
{
public:
    virtual ~Base() = default;

    virtual void display()
    {
        cout << "Base class" << endl;
    }
};

class Derived : public Base
{
public:
    void show()
    {
        cout << "Derived class function" << endl;
    }
};

int main()
{
    Base* bptr = new Derived();

    Derived* dptr = dynamic_cast<Derived*>(bptr);

    if (dptr != nullptr)
    {
        dptr->show();
    }
    else
    {
        cout << "Downcasting failed" << endl;
    }

    delete bptr;

    return 0;
}
Expected Output: 
Derived class function
Explanation:
  • A Derived object is created dynamically.
  • A Base pointer stores its address.
  • dynamic_cast checks whether the object is actually of the Derived type.
  • If the cast succeeds, the derived-class function can be called.
  • Deleting through the base pointer is safe here because Base has a virtual destructor.
For pointer downcasting, a failed dynamic_cast returns nullptr. For reference downcasting, a failed cast throws std::bad_cast.

8. Pointer to Derived Class with Virtual Functions

A base-class pointer can refer to a derived-class object. If a virtual function is called through that pointer, C++ selects the overridden implementation based on the actual object type. 

#include <iostream>
using namespace std;

class Animal
{
public:
    virtual void sound()
    {
        cout << "Animal makes a sound" << endl;
    }

    virtual ~Animal() = default;
};

class Dog : public Animal
{
public:
    void sound() override
    {
        cout << "Dog barks" << endl;
    }
};

class Cat : public Animal
{
public:
    void sound() override
    {
        cout << "Cat meows" << endl;
    }
};

int main()
{
    Dog d;
    Cat c;

    Animal* ptr;

    ptr = &d;
    ptr->sound();

    ptr = &c;
    ptr->sound();

    return 0;
}
Expected Output: 
Dog barks
Cat meows
Explanation:
  • Animal is the base class.
  • Dog and Cat are derived classes.
  • The base pointer refers to different derived objects.
  • The virtual function selects the appropriate implementation at runtime.

9. Pointer to Derived Class vs Object Slicing

A base-class pointer can refer to a derived object without copying or slicing that object.

However, assigning a derived object directly to a base-class object by value can cause object slicing. In that case, the derived-specific part is not retained in the resulting base object. 

#include <iostream>
using namespace std;

class Base
{
public:
    int x = 10;
};

class Derived : public Base
{
public:
    int y = 20;
};

int main()
{
    Derived d;

    Base* ptr = &d;

    Base b = d; // Object slicing

    cout << "Base pointer value: " << ptr->x << endl;
    cout << "Base object value: " << b.x << endl;

    return 0;
}
Expected Output: 
Base pointer value: 10
Base object value: 10

The base object b contains only the Base part. The derived member y is not part of that copied Base object.

10. Advantages of Base and Derived-Class Pointers

  • Support inheritance-based programming.
  • Allow common base-class interfaces.
  • Enable runtime polymorphism with virtual functions.
  • Reduce dependency on specific derived-class types.
  • Make programs easier to extend with new derived classes.

11. Applications in Embedded and Systems Programming

Application Example
Device Abstraction Different devices accessed through a common base interface.
Hardware Drivers Different driver implementations sharing common operations.
Communication Interfaces UART, SPI and I2C implementations exposed through a common interface.
Operating Systems Different system components using common interfaces.
Application Frameworks Different derived objects managed through base-class pointers.
These are design examples. Actual embedded driver implementations depend on the hardware architecture, operating system and performance requirements.

12. Common Mistakes

  • Wrong pointer type: A derived-class pointer cannot directly point to an unrelated base-class object.
  • Accessing derived members through a base pointer: A base pointer cannot directly access members declared only in the derived class.
  • Unsafe downcasting: Use dynamic_cast when checked runtime downcasting is required.
  • Missing virtual destructor: If objects may be deleted through a base-class pointer, the base class should generally have a virtual destructor.
  • Confusing static and dynamic binding: Runtime dispatch requires a virtual function.

14. Multiple Choice Questions (MCQs)

Q1. Which pointer stores the address of a derived-class object?

A. Derived-class pointer
B. Integer pointer
C. Character pointer
D. Void function

Answer: A. Derived-class pointer

Q2. What is upcasting?

A. Base pointer to derived pointer
B. Derived pointer to base pointer
C. Integer to pointer
D. Pointer to array

Answer: B. Derived pointer to base pointer

Q3. Which conversion is generally implicit and safe in public inheritance?

A. Downcasting
B. Upcasting
C. Unrelated casting
D. Reinterpret casting

Answer: B. Upcasting

Q4. Which operator accesses members through a pointer?

A. .
B. ::
C. ->
D. &

Answer: C. ->

Q5. Which C++ operator performs checked runtime pointer downcasting?

A. static_cast
B. dynamic_cast
C. sizeof
D. typeid

Answer: B. dynamic_cast

Q6. What is required for dynamic_cast to perform runtime downcasting?

A. A polymorphic base class
B. A static variable
C. A friend function
D. A constructor only

Answer: A. A polymorphic base class

Q7. Which feature enables runtime polymorphism through a base pointer?

A. Normal variable
B. Virtual function
C. Friend class
D. Namespace

Answer: B. Virtual function

  • A derived-class pointer stores the address of a derived-class object.
