The this Pointer in C++

Understanding the pointer to the current object

1. Introduction to the this Pointer

The this pointer is a special pointer available inside non-static member functions of a class. It stores the address of the current object that invokes the member function.

In simple terms, this refers to the object currently executing a member function.

Example: If an object named obj1 calls a member function, then this inside that function refers to obj1. 
class Student
{
public:
    void display()
    {
        cout << this;
    }
};

2. Why Do We Need the this Pointer?

The this pointer is useful when a member function needs to identify the object that called it.

  • To distinguish data members from local variables or parameters.
  • To access the current object's members explicitly.
  • To return the current object from a member function.
  • To compare the current object with another object.
  • To support method chaining.

3. Basic Example of the this Pointer

#include <iostream>
using namespace std;

class Student
{
public:
    int rollNo;

    void display()
    {
        cout << "Roll Number: " << rollNo << endl;
        cout << "Current object address: " << this << endl;
    }
};

int main()
{
    Student s1;

    s1.rollNo = 101;
    s1.display();

    return 0;
}
Expected Output: 
Roll Number: 101
Current object address: (address of s1)

The actual memory address varies each time the program runs.

Explanation

  1. s1 is an object of the Student class.
  2. s1.display() calls the member function.
  3. Inside display(), this refers to s1.
  4. Printing this displays the current object's address.

4. Using this to Resolve Naming Conflicts

One common application of the this pointer is resolving naming conflicts between class data members and function parameters.

If a parameter and a data member have the same name, the parameter normally hides the data member inside the function. We can use this-> to access the data member. 

#include <iostream>
using namespace std;

class Student
{
private:
    int marks;

public:
    void setMarks(int marks)
    {
        this->marks = marks;
    }

    void display()
    {
        cout << "Marks: " << marks;
    }
};

int main()
{
    Student s1;

    s1.setMarks(85);
    s1.display();

    return 0;
}
Expected Output: 
Marks: 85
Explanation:
  • marks on the left side is the class data member.
  • marks on the right side is the function parameter.
  • this->marks explicitly accesses the current object's data member.

5. Accessing Members Using this

The arrow operator (->) is used with the this pointer to access data members and member functions of the current object. 

#include <iostream>
using namespace std;

class Employee
{
public:
    int id;

    void show()
    {
        cout << "Employee ID: " << this->id;
    }

    void display()
    {
        this->show();
    }
};

int main()
{
    Employee e1;

    e1.id = 501;
    e1.display();

    return 0;
}
Expected Output: 
Employee ID: 501

6. Understanding *this

The expression this represents a pointer to the current object. The expression *this represents the current object itself. 

#include <iostream>
using namespace std;

class Test
{
public:
    int value;

    void display()
    {
        cout << "Value: " << (*this).value;
    }
};

int main()
{
    Test t1;

    t1.value = 100;
    t1.display();

    return 0;
}
Expected Output: 
Value: 100
Remember: this->value and (*this).value are equivalent ways to access the current object's data member.

7. Returning the Current Object Using *this

A member function can return a reference to the current object using *this. This is useful when multiple member functions need to be called in sequence. 

#include <iostream>
using namespace std;

class Number
{
private:
    int value;

public:
    Number(int value)
    {
        this->value = value;
    }

    Number& setValue(int value)
    {
        this->value = value;
        return *this;
    }

    void display()
    {
        cout << "Value: " << value << endl;
    }
};

int main()
{
    Number n1(10);

    n1.setValue(50).display();

    return 0;
}
Expected Output: 
Value: 50

The setValue() function returns a reference to the same object. Therefore, display() can be called immediately after it.

This technique is called method chaining. Returning *this by reference avoids making an unnecessary copy of the object.

8. this Pointer with Multiple Objects

Each object has its own identity. When different objects call the same non-static member function, the this pointer refers to the object that made the particular call. 

#include <iostream>
using namespace std;

class Demo
{
public:
    void showAddress()
    {
        cout << "Object address: " << this << endl;
    }
};

int main()
{
    Demo obj1, obj2;

    obj1.showAddress();
    obj2.showAddress();

    return 0;
}
Expected Output: 
Object address: (address of obj1)
Object address: (address of obj2)

The two addresses will be different because obj1 and obj2 are separate objects. Actual addresses vary at runtime.

9. Important Characteristics of the this Pointer

Characteristic Description
Special pointer It is implicitly available inside non-static member functions.
Current object It points to the object that invoked the member function.
Member access It accesses members using the arrow operator.
Static functions It cannot be used inside static member functions.
Object reference *this represents the current object.

10. this Pointer in Static Member Functions

Static member functions belong to the class rather than to a particular object. They can be called without creating an object.

Therefore, a static member function does not have a current object, and the this pointer is not available inside it. 

#include <iostream>
using namespace std;

class Demo
{
public:
    static void display()
    {
        cout << "Static member function";
        // this->display(); // Invalid: this is unavailable here
    }
};

int main()
{
    Demo::display();

    return 0;
}
Expected Output: 
Static member function
Do not use this inside a static member function.

11. Advantages of the this Pointer

  • Resolves naming conflicts between parameters and data members.
  • Provides access to the current object.
  • Allows a member function to return the current object.
  • Supports method chaining.
  • Helps write clear and maintainable class code.

12. Common Mistakes

  • Using this in a static function: Static member functions do not have a this pointer.
  • Confusing this and *this: this is a pointer, whereas *this refers to the current object.
  • Incorrect member access: Use -> with the pointer.
  • Returning a local object reference: Do not return a reference to a local variable that will be destroyed when the function ends.

Q4. What does *this represent?

A. Current object
B. Function address
