1. Introduction to Constructors

A constructor is a special member function of a class that is automatically called when an object of that class is created. Its main purpose is to initialize the data members of an object.

A constructor has the same name as its class and does not have a return type, not even void.

Important: A constructor is called automatically when an object is created. It helps ensure that an object starts with an appropriate initial state.

2. What is a Default Constructor?

A default constructor is a constructor that can be called without providing any arguments.

It may be written explicitly by the programmer, or the compiler may implicitly declare a default constructor if the class has no user-declared constructor.

Syntax

class ClassName { public: ClassName() { // Initialization statements } };

Here:

  • ClassName is the name of the class.
  • ClassName() is the default constructor.
  • It does not require arguments.
  • It is called when an object is created without constructor arguments.

3. Simple Program using Default Constructor

In this example, the default constructor initializes the id data member when an object is created.

Program

#include <iostream> using namespace std; class Student { public: int id; Student() { id = 101; cout << "Default constructor called" << endl; } void display() { cout << "Student ID: " << id << endl; } }; int main() { Student s1; s1.display(); return 0; }

Expected Output

Default constructor called
Student ID: 101

Explanation

  • Student is the class name.
  • Student() is the default constructor.
  • Student s1; creates an object.
  • The constructor automatically initializes id to 101.
  • display() prints the initialized value.

4. Default Constructor without Explicit Initialization

A default constructor can also execute statements without initializing any particular data member.

Program

#include <iostream> using namespace std; class Demo { public: Demo() { cout << "Object created successfully" << endl; } }; int main() { Demo obj1; Demo obj2; return 0; }

Expected Output

Object created successfully
Object created successfully

The constructor is called separately for each object.

5. Compiler-Provided Default Constructor

If a class does not declare any constructor, the compiler implicitly declares a default constructor.

Program

#include <iostream> using namespace std; class Student { public: int marks; void display() { cout << "Student object created" << endl; } }; int main() { Student s1; s1.display(); return 0; }

Expected Output

Student object created
Important: The compiler-provided default constructor does not automatically initialize ordinary built-in data members such as int to zero. Here, marks is not initialized by the constructor.

6. Explicitly Defaulted Constructor

C++11 introduced the = default syntax. It allows the programmer to explicitly request the compiler's default implementation of a constructor.

Program

#include <iostream> using namespace std; class Demo { public: Demo() = default; }; int main() { Demo obj; cout << "Object created successfully"; return 0; }

Expected Output

Object created successfully

The compiler generates the defaulted constructor implementation. It does not automatically assign zero to ordinary built-in data members.

7. Default Constructor and Data Member Initialization

A constructor can initialize multiple data members of a class.

Program

#include <iostream> using namespace std; class Employee { private: int id; float salary; public: Employee() { id = 1001; salary = 25000.0; } void display() { cout << "Employee ID: " << id << endl; cout << "Salary: " << salary << endl; } }; int main() { Employee e1; e1.display(); return 0; }

Expected Output

Employee ID: 1001
Salary: 25000

8. Constructor Initialization List

C++ also allows data members to be initialized using a constructor initialization list.

Syntax

ClassName() : dataMember(value) { // Constructor body }

Program

#include <iostream> using namespace std; class Student { private: int id; float marks; public: Student() : id(101), marks(85.5) { cout << "Constructor called" << endl; } void display() { cout << "ID: " << id << endl; cout << "Marks: " << marks << endl; } }; int main() { Student s1; s1.display(); return 0; }

Expected Output

Constructor called
ID: 101
Marks: 85.5
Remember: The initialization list initializes data members before the constructor body executes. Members are initialized in the order in which they are declared in the class.

9. Default Constructor vs Compiler-Provided Constructor

Feature User-Defined Default Constructor Compiler-Provided Default Constructor
Definition Written by the programmer. Implicitly declared by the compiler when permitted.
Initialization Can initialize members as required. Does not automatically zero-initialize ordinary built-in members.
Constructor body Can contain user-written statements. Compiler-generated.
Requirement Must be declared and defined by the programmer. Available when no user-declared constructor prevents its implicit declaration.

10. Important Rules of Default Constructors

  • A constructor has the same name as its class.
  • A constructor does not have a return type.
  • A default constructor can be called without arguments.
  • It is automatically called when an object is created without constructor arguments.
  • A class can have only one constructor with an empty parameter list.
  • A class can have multiple constructors through constructor overloading.
  • If a class has no user-declared constructors, the compiler can implicitly declare a default constructor.
  • Declaring a parameterized constructor prevents the compiler from implicitly declaring a default constructor.
If you define a parameterized constructor and still need an object to be created without arguments, you must also provide a default constructor or explicitly default it where permitted.

11. Common Mistakes

  1. Giving a constructor a return type such as void.
  2. Using a constructor name different from the class name.
  3. Assuming that built-in data members are automatically initialized to zero.
  4. Forgetting that a parameterized constructor prevents implicit declaration of a default constructor.
  5. Confusing a default constructor with a parameterized constructor that has default arguments.
  6. Initializing members in the constructor body when an initialization list is more appropriate.

12. Interview Questions

Q1. What is a constructor in C++?

A constructor is a special member function that is automatically called when an object is created.

Q2. What is a default constructor?

A default constructor is a constructor that can be called without providing any arguments.

Q3. Does a constructor have a return type?

No. A constructor does not have a return type.

Q4. When is a default constructor called?

It is called when an object is created without constructor arguments.

Q5. Can a constructor be private?

Yes. A constructor can be private. This is useful in designs where object creation must be controlled by the class.

Q6. What happens if we do not define a constructor?

If the class has no user-declared constructor, the compiler implicitly declares a default constructor when the language rules permit it.

Q7. Can we overload constructors?

Yes. A class can have multiple constructors with different parameter lists.

Q8. What is a constructor initialization list?

It is a syntax used to initialize data members and base classes before the constructor body executes.
