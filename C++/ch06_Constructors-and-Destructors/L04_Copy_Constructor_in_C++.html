1. Introduction to Copy Constructor

A copy constructor is a special constructor used to create a new object by initializing it from an existing object of the same class.

It copies the data members of one object into another object. The programmer can define how this copying should take place.

Definition: A copy constructor is a constructor that initializes an object using another object of the same class.

Example

Student s1(101); Student s2(s1);

Here, s2 is initialized using the existing object s1. The copy constructor is selected.

2. Syntax of Copy Constructor

class ClassName { public: ClassName(const ClassName &obj) { // Copy data members from obj } };

Important parts of the syntax:

  • ClassName is the constructor name.
  • const ClassName &obj is a reference to the source object.
  • The reference avoids creating another copy of the source object.
  • const prevents the constructor from modifying the source object through this reference.
Important: A copy constructor normally accepts its source object by reference. Passing it by value would require copying the argument, which would recursively require the copy constructor.

3. Basic Program: User-Defined Copy Constructor

This program demonstrates how a copy constructor copies a data member from one object to another.

#include <iostream> using namespace std; class Student { int rollNo; public: Student(int r) { rollNo = r; } Student(const Student &obj) { rollNo = obj.rollNo; cout << "Copy constructor called" << endl; } void display() { cout << "Roll Number: " << rollNo << endl; } }; int main() { Student s1(101); Student s2(s1); cout << "Original Object:" << endl; s1.display(); cout << "Copied Object:" << endl; s2.display(); return 0; }

Expected Output

Copy constructor called
Original Object:
Roll Number: 101
Copied Object:
Roll Number: 101

Explanation

  • Student s1(101); calls the parameterized constructor.
  • Student s2(s1); calls the copy constructor.
  • obj.rollNo accesses the source object's roll number.
  • The value is copied into the new object's rollNo.

4. Different Ways to Call a Copy Constructor

A copy constructor can be invoked through direct or copy initialization.

Method 1: Direct Initialization

Student s1(101); Student s2(s1);

Method 2: Copy Initialization

Student s1(101); Student s2 = s1;

Method 3: Direct List Initialization

Student s1(101); Student s2{s1};
Note: These forms can invoke the copy constructor. However, copy initialization may be subject to copy elision in applicable situations.

5. Default Copy Constructor

If a class does not declare a copy constructor, the compiler implicitly declares a copy constructor in many circumstances. This is commonly called the default or compiler-generated copy constructor.

It performs memberwise copying: each base-class and non-static data member is copied from the source object.

Program

#include <iostream> using namespace std; class Employee { public: int id; double salary; }; int main() { Employee e1; e1.id = 101; e1.salary = 25000; Employee e2 = e1; cout << "Original Employee:" << endl; cout << e1.id << " " << e1.salary << endl; cout << "Copied Employee:" << endl; cout << e2.id << " " << e2.salary << endl; return 0; }

Expected Output

Original Employee:
101 25000
Copied Employee:
101 25000
Remember: The compiler-generated copy constructor copies members individually. For pointer members, it copies the pointer value, not the dynamically allocated memory.

6. Copy Constructor with Multiple Data Members

A copy constructor can copy multiple data members from an existing object.

Program

#include <iostream> using namespace std; class Rectangle { int length; int breadth; public: Rectangle(int l, int b) { length = l; breadth = b; } Rectangle(const Rectangle &obj) { length = obj.length; breadth = obj.breadth; } void display() { cout << "Length: " << length << endl; cout << "Breadth: " << breadth << endl; cout << "Area: " << length * breadth << endl; } }; int main() { Rectangle r1(10, 5); Rectangle r2(r1); cout << "Original Rectangle:" << endl; r1.display(); cout << endl; cout << "Copied Rectangle:" << endl; r2.display(); return 0; }

Expected Output

Original Rectangle:
Length: 10
Breadth: 5
Area: 50

Copied Rectangle:
Length: 10
Breadth: 5
Area: 50

7. When Is a Copy Constructor Called?

A copy constructor may be selected in situations such as:

  1. Creating an object from another object of the same class.
  2. Passing an object by value to a function.
  3. Returning an object by value from a function, where copying is not elided.
  4. Using copy initialization, such as ClassName obj2 = obj1;.
Important: Modern C++ compilers can apply copy elision in certain situations. Therefore, a copy constructor is not guaranteed to execute for every apparent copy.

8. Copy Constructor vs Assignment Operator

A copy constructor and copy assignment operator both deal with copying objects, but they perform different operations.

Copy Constructor Copy Assignment Operator
Initializes a new object from an existing object. Assigns values to an already existing object.
Called during copy initialization. Called during copy assignment.
Example: Student s2 = s1; Example: s2 = s1;

Example

Student s1(101); // Copy constructor Student s2 = s1; // Copy assignment operator Student s3(102); s3 = s1;
Key Difference: In the first example, a new object is created. In the second example, an existing object receives the copied value.

9. Copy Constructor and Pointer Members

When a class contains a pointer that manages dynamically allocated memory, the compiler-generated copy constructor copies only the pointer value.

This means both objects may point to the same memory location. This behavior is called shallow copying.

class Sample { int *ptr; public: Sample(int value) { ptr = new int(value); } // Compiler-generated copying copies // the pointer address, not the pointed value. };
Problem: If both objects believe they own the same dynamically allocated memory, deleting it more than once can cause undefined behavior. A custom copy constructor may be needed to create an independent copy.

This topic is covered in detail in the next lessons: Shallow Copy and Deep Copy.

10. Important Rules of Copy Constructor

  • A copy constructor is a special member constructor.
  • It initializes an object from another object of the same class.
  • It commonly accepts a const reference to the source object.
  • It does not have a return type.
  • The compiler can generate a copy constructor if one is not user-declared.
  • The generated copy constructor performs memberwise copying.
  • A user-defined copy constructor can control how members are copied.
  • Copying pointer members requires special care when managing dynamic memory.

11. Common Mistakes

Mistake Correct Understanding
Passing the source object by value. Use a reference to avoid recursive copying.
Confusing copying with assignment. Copy construction initializes a new object; assignment updates an existing object.
Assuming pointer members are deeply copied. Default copying copies pointer values, not allocated memory.
Assuming the copy constructor always executes. Copy elision can remove some copy operations.

12. Interview Questions

Q1. What is a copy constructor?

It is a constructor that initializes a new object using another object of the same class.

Q2. What is the usual syntax of a copy constructor?

ClassName(const ClassName &obj)

Q3. What is a compiler-generated copy constructor?

It is a copy constructor implicitly declared by the compiler when appropriate. It performs memberwise copying.

Q4. What is memberwise copying?

It means copying each base-class and non-static data member from the source object.

Q5. Why is the source object passed by reference?

Passing by reference avoids creating another copy of the source object.

Q6. What is the difference between a copy constructor and assignment operator?

A copy constructor initializes a new object, while the assignment operator copies values into an existing object.

Q7. What happens when a class contains a pointer member?

The compiler-generated copy constructor copies the pointer value. Both objects may then point to the same memory.

Q8. What is copy elision?

Copy elision is a compiler optimization that omits certain copy or move operations when permitted by the language rules.

14. Summary

  • A copy constructor initializes an object from another object.
  • It commonly accepts a constant reference to the source object.
  • The compiler can generate a memberwise copy constructor.
  • A user-defined copy constructor controls the copying process.
  • Copy construction and copy assignment are different operations.
  • Pointer members require care because default copying does not duplicate dynamically allocated memory.
Remember: Copy constructor is an important concept in object initialization, memory management, and resource ownership in C++.
