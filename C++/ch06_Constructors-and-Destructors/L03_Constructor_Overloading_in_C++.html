1. Introduction to Constructor Overloading

Constructor overloading is a feature of C++ that allows a class to have more than one constructor with different parameter lists. Each constructor provides a different way to initialize objects.

The compiler selects the appropriate constructor based on the number, types, and order of arguments supplied when an object is created.

Definition: Constructor overloading is the process of defining multiple constructors in the same class with different parameter lists.

2. Why Do We Need Constructor Overloading?

Constructor overloading provides flexibility when creating objects.

  • It allows objects to be initialized in different ways.
  • It supports different numbers of initialization values.
  • It improves code flexibility and reusability.
  • It avoids creating separate initialization functions for every case.

Example

A Student object can be created using:

  • No arguments: initialize with default values.
  • One argument: initialize only the roll number.
  • Two arguments: initialize the roll number and marks.

3. Syntax of Constructor Overloading

class ClassName { public: ClassName() { // Default constructor } ClassName(int a) { // Constructor with one parameter } ClassName(int a, int b) { // Constructor with two parameters } };

All constructors have the same name as the class, but their parameter lists are different.

4. Program: Constructor Overloading with Different Parameters

This program demonstrates three constructors: a default constructor, a constructor with one parameter, and a constructor with two parameters.

#include <iostream> using namespace std; class Student { int rollNo; int marks; public: Student() { rollNo = 0; marks = 0; } Student(int r) { rollNo = r; marks = 0; } Student(int r, int m) { rollNo = r; marks = m; } void display() { cout << "Roll Number: " << rollNo << endl; cout << "Marks: " << marks << endl; cout << "------------------" << endl; } }; int main() { Student s1; Student s2(101); Student s3(102, 85); cout << "Student 1:" << endl; s1.display(); cout << "Student 2:" << endl; s2.display(); cout << "Student 3:" << endl; s3.display(); return 0; }

Expected Output

Student 1:
Roll Number: 0
Marks: 0
------------------
Student 2:
Roll Number: 101
Marks: 0
------------------
Student 3:
Roll Number: 102
Marks: 85
------------------

Explanation

  • Student s1; calls the default constructor.
  • Student s2(101); calls the one-parameter constructor.
  • Student s3(102, 85); calls the two-parameter constructor.
  • The compiler selects the constructor according to the arguments.

5. Constructor Overloading Using Different Data Types

Constructors can also be overloaded by using different parameter types, even when the number of parameters is the same.

Program

#include <iostream> using namespace std; class Display { public: Display(int x) { cout << "Integer value: " << x << endl; } Display(double x) { cout << "Double value: " << x << endl; } Display(char x) { cout << "Character value: " << x << endl; } }; int main() { Display d1(10); Display d2(15.5); Display d3('A'); return 0; }

Expected Output

Integer value: 10
Double value: 15.5
Character value: A

Explanation

All three constructors accept one argument, but their parameter types are different. The compiler selects the matching constructor for each object.

6. Constructor Overloading with Initialization Lists

Constructor overloading can also be implemented using member initializer lists. These lists initialize data members before the constructor body executes.

#include <iostream> using namespace std; class Rectangle { int length; int breadth; public: Rectangle() : length(0), breadth(0) { } Rectangle(int l) : length(l), breadth(l) { } Rectangle(int l, int b) : length(l), breadth(b) { } void area() { cout << "Area: " << length * breadth << endl; } }; int main() { Rectangle r1; Rectangle r2(5); Rectangle r3(10, 4); r1.area(); r2.area(); r3.area(); return 0; }

Expected Output

Area: 0
Area: 25
Area: 40
Note: The one-parameter constructor initializes both length and breadth with the same value, creating a square.

7. Constructor Overloading vs Function Overloading

Constructor Overloading Function Overloading
Multiple constructors have the same class name. Multiple functions have the same function name.
Used to initialize objects. Used to perform operations in different ways.
Called automatically when objects are created. Called explicitly through a function call.
Has no return type. Can have a return type.

8. Important Rules of Constructor Overloading

  • All constructors must have the same name as the class.
  • Constructors cannot have a return type.
  • Overloaded constructors must have distinguishable parameter lists.
  • Constructors can differ in the number, types, or order of parameters.
  • The compiler selects a constructor based on overload resolution.
  • Constructors cannot be overloaded using only different return types.
  • Constructors can use default arguments, but these can sometimes create ambiguity.
Important: Two constructors with identical parameter lists cannot be declared in the same class.

9. Constructor Overloading and Ambiguity

Sometimes the compiler cannot determine which overloaded constructor should be called. This situation is called constructor ambiguity.

Example of Ambiguity

#include <iostream> using namespace std; class Demo { public: Demo(int x, int y = 10) { cout << "Constructor 1" << endl; } Demo(int x) { cout << "Constructor 2" << endl; } }; int main() { // Demo d(5); // Ambiguous constructor call return 0; }
Explanation: Both constructors can accept a single integer argument. The first constructor can use its default value for the second parameter, while the second constructor directly accepts one parameter. Therefore, Demo d(5); is ambiguous and causes a compilation error.

10. Advantages of Constructor Overloading

  • Provides multiple ways to initialize objects.
  • Improves program flexibility.
  • Reduces the need for separate initialization functions.
  • Makes class interfaces easier to use.
  • Supports different initialization requirements.

11. Common Mistakes

Mistake Correct Understanding
Using a return type with a constructor. Constructors do not have return types.
Declaring two constructors with identical parameter lists. Use different parameter lists.
Assuming the compiler always selects the constructor by argument count alone. Types and overload resolution rules also matter.
Using default arguments without checking ambiguity. Ensure constructor calls have an unambiguous match.

12. Interview Questions

Q1. What is constructor overloading?

It is the process of defining multiple constructors in a class with different parameter lists.

Q2. Why is constructor overloading used?

It allows objects to be initialized in different ways.

Q3. Can constructors be overloaded?

Yes. Constructors can have different numbers or types of parameters.

Q4. Can constructors differ only by return type?

No. Constructors do not have return types, and overload resolution is based on parameter lists.

Q5. How does the compiler select an overloaded constructor?

It uses overload resolution based on the arguments supplied, including their types and possible conversions.

Q6. What is constructor ambiguity?

It occurs when a constructor call has no uniquely best matching constructor.

Q7. Can a class have both default and parameterized constructors?

Yes. They can be overloaded in the same class.

14. Summary

  • Constructor overloading allows multiple constructors in one class.
  • Each overloaded constructor has a different parameter list.
  • It provides different ways to initialize objects.
  • The compiler selects the appropriate constructor through overload resolution.
  • Ambiguous constructor calls result in compilation errors.
Remember: Constructor overloading is an example of compile-time polymorphism in C++.
