1. Introduction to Parameterized Constructor

A parameterized constructor is a constructor that accepts one or more arguments. It allows the programmer to initialize an object's data members with specific values at the time of object creation.

Unlike a default constructor, which can be called without arguments, a parameterized constructor receives values from the object creation statement.

Important: A parameterized constructor initializes an object using values supplied when the object is created.

2. Syntax of Parameterized Constructor

class ClassName { private: int value; public: ClassName(int x) { value = x; } };

Here:

  • ClassName is the name of the class.
  • ClassName(int x) is the parameterized constructor.
  • x is the constructor parameter.
  • value = x initializes the data member.

3. Simple Program using Parameterized Constructor

This program initializes a student's roll number by passing an argument to the constructor.

Program

#include <iostream> using namespace std; class Student { public: int rollNo; Student(int r) { rollNo = r; } void display() { cout << "Roll Number: " << rollNo << endl; } }; int main() { Student s1(101); s1.display(); return 0; }

Expected Output

Roll Number: 101

Explanation

  • Student(int r) is the parameterized constructor.
  • Student s1(101) creates an object and passes 101.
  • The value 101 is received by parameter r.
  • rollNo = r assigns the value to the data member.
  • display() prints the roll number.

4. Parameterized Constructor with Multiple Arguments

A parameterized constructor can accept multiple arguments to initialize several data members.

Program

#include <iostream> using namespace std; class Employee { private: int id; float salary; public: Employee(int i, float s) { id = i; salary = s; } void display() { cout << "Employee ID: " << id << endl; cout << "Salary: " << salary << endl; } }; int main() { Employee e1(1001, 35000.50); e1.display(); return 0; }

Expected Output

Employee ID: 1001
Salary: 35000.5

The constructor receives two arguments and initializes two data members.

5. Creating Multiple Objects with Different Values

The same parameterized constructor can initialize multiple objects with different values.

Program

#include <iostream> using namespace std; class Student { private: int rollNo; int marks; public: Student(int r, int m) { rollNo = r; marks = m; } void display() { cout << "Roll Number: " << rollNo << endl; cout << "Marks: " << marks << endl; cout << "----------------" << endl; } }; int main() { Student s1(101, 85); Student s2(102, 90); Student s3(103, 78); s1.display(); s2.display(); s3.display(); return 0; }

Expected Output

Roll Number: 101
Marks: 85
----------------
Roll Number: 102
Marks: 90
----------------
Roll Number: 103
Marks: 78
----------------
Each object receives its own constructor arguments and stores its own data member values.

6. Parameterized Constructor using Initialization List

A constructor initialization list provides another way to initialize data members. It initializes members before the constructor body executes.

Syntax

ClassName(int x, int y) : a(x), b(y) { // Constructor body }

Program

#include <iostream> using namespace std; class Rectangle { private: int length; int breadth; public: Rectangle(int l, int b) : length(l), breadth(b) { cout << "Rectangle object created" << endl; } void area() { cout << "Area: " << length * breadth << endl; } }; int main() { Rectangle r1(10, 5); r1.area(); return 0; }

Expected Output

Rectangle object created
Area: 50
Data members are initialized in their declaration order in the class, not the order in which they appear in the constructor initialization list.

7. Parameterized Constructor with User Input

Values entered by the user can be passed as arguments to a parameterized constructor.

Program

#include <iostream> using namespace std; class Product { private: int productId; float price; public: Product(int id, float p) { productId = id; price = p; } void display() { cout << "Product ID: " << productId << endl; cout << "Price: " << price << endl; } }; int main() { int id; float price; cout << "Enter Product ID: "; cin >> id; cout << "Enter Product Price: "; cin >> price; Product p1(id, price); p1.display(); return 0; }

Sample Input

Enter Product ID: 501 Enter Product Price: 2500

Expected Output

Product ID: 501
Price: 2500

8. Default Constructor vs Parameterized Constructor

Feature Default Constructor Parameterized Constructor
Arguments Can be called without arguments. Accepts one or more arguments.
Initialization Can initialize members with predefined values. Can initialize members using supplied values.
Object creation Student s1; Student s1(101);
Purpose Creates an object without passing arguments. Creates an object with specified values.

9. Important Rules of Parameterized Constructors

  • A parameterized constructor accepts one or more parameters.
  • It has the same name as its class.
  • It does not have a return type.
  • Arguments are supplied when the object is created.
  • Different objects can receive different constructor arguments.
  • A constructor can initialize multiple data members.
  • Constructor initialization lists can be used to initialize members.
  • A class with only a parameterized constructor does not automatically receive an implicit default constructor.
If you want to create an object without arguments while a parameterized constructor is present, provide a separate default constructor or explicitly default one where permitted.

10. Common Mistakes

  1. Passing a different number of arguments from those required by the constructor.
  2. Using incorrect argument data types.
  3. Giving a constructor a return type.
  4. Forgetting to initialize important data members.
  5. Assuming that a parameterized constructor automatically creates a default constructor.
  6. Confusing constructor parameters with class data members.
  7. Ignoring the declaration order of data members when using initialization lists.

11. Interview Questions

Q1. What is a parameterized constructor?

A parameterized constructor is a constructor that accepts arguments to initialize an object.

Q2. Can a parameterized constructor accept multiple arguments?

Yes. It can accept multiple arguments to initialize different data members.

Q3. Can multiple objects use the same parameterized constructor?

Yes. Multiple objects can use the same constructor with different argument values.

Q4. What is a constructor initialization list?

It is a mechanism used to initialize data members and base classes before the constructor body executes.

Q5. Can a class have both default and parameterized constructors?

Yes. A class can have both constructors. This is an example of constructor overloading.

Q6. What happens if we define only a parameterized constructor?

The compiler does not implicitly declare a default constructor. An object cannot be created without arguments unless a suitable default constructor is also provided.

Q7. Is a constructor called automatically?

Yes. The appropriate constructor is automatically called when an object is created.

13. Lesson Summary

  • A parameterized constructor accepts arguments.
  • It initializes objects with supplied values.
  • It is automatically called during object creation.
  • It can initialize one or more data members.
  • Multiple objects can use the same constructor with different values.
  • Constructor initialization lists provide direct member initialization.
  • A parameterized constructor alone does not provide an implicit default constructor.
