1. Introduction to Dynamic Memory Allocation

Dynamic memory allocation is the process of allocating memory during program execution rather than fixing all memory requirements at compile time.

C++ provides the new and delete operators to allocate and release dynamically allocated memory.

Definition: Dynamic memory allocation allows a program to request memory at runtime according to its needs.

Why Is Dynamic Memory Allocation Needed?

  • When the required memory size is not known in advance.
  • When memory requirements depend on user input.
  • When creating objects and arrays during program execution.
  • When implementing dynamic data structures such as linked lists and trees.

2. The new Operator

The new operator allocates memory dynamically and returns a pointer to the allocated object.

Syntax

data_type *pointer; pointer = new data_type;

Example

int *ptr = new int; *ptr = 100; cout << *ptr;

Here, new int allocates memory for one integer. The returned address is stored in the pointer ptr.

Note: A plain expression such as new int does not initialize the integer's value. Use new int() or new int{} to value-initialize it to zero.

3. The delete Operator

The delete operator releases memory previously allocated for a single object using new.

Syntax

delete pointer;

Example

int *ptr = new int(100); cout << *ptr << endl; delete ptr; ptr = nullptr;

After delete ptr;, the dynamically allocated integer's lifetime ends and its storage is released.

Important: Deleting memory does not automatically make the pointer variable disappear. The pointer may still contain the old address, so assigning nullptr can help prevent accidental use of that invalid address.

4. Program: Dynamic Memory Allocation for One Integer

This program allocates memory for one integer, stores a value, displays it, and releases the allocated memory.

#include <iostream> using namespace std; int main() { int *ptr = new int; *ptr = 50; cout << "Value: " << *ptr << endl; delete ptr; ptr = nullptr; return 0; }

Expected Output

Value: 50

Explanation

  1. new int allocates memory for an integer.
  2. The returned address is stored in ptr.
  3. *ptr = 50; stores 50 at the allocated location.
  4. delete ptr; releases the allocated memory.
  5. ptr = nullptr; makes the pointer null.

5. Dynamic Memory Allocation for an Array

C++ also supports dynamic allocation of arrays using new[].

Syntax

data_type *pointer = new data_type[size];

Program

#include <iostream> using namespace std; int main() { int n; cout << "Enter array size: "; cin >> n; if (n <= 0) { cout << "Invalid array size" << endl; return 0; } int *arr = new int[n]; cout << "Enter " << n << " elements:" << endl; for (int i = 0; i < n; i++) { cin >> arr[i]; } cout << "Array elements: "; for (int i = 0; i < n; i++) { cout << arr[i] << " "; } cout << endl; delete[] arr; arr = nullptr; return 0; }

Sample Input

Enter array size: 5
Enter 5 elements:
10 20 30 40 50

Expected Output

Array elements: 10 20 30 40 50
Important: Memory allocated using new[] must be released using delete[].

6. Difference Between new and new[]

new new[]
Allocates memory for one object. Allocates memory for an array of objects.
Example: new int(10) Example: new int[10]
Released using delete. Released using delete[].

7. Difference Between delete and delete[]

delete delete[]
Releases a single dynamically allocated object. Releases a dynamically allocated array.
Used with memory allocated by new. Used with memory allocated by new[].
delete ptr; delete[] arr;
Warning: Using delete for memory allocated with new[], or delete[] for memory allocated with new, results in undefined behavior.

8. Dynamic Memory Allocation for Objects

The new operator can also dynamically allocate memory for class objects. The object's constructor is called during allocation.

Program

#include <iostream> using namespace std; class Student { int rollNo; public: Student(int r) { rollNo = r; cout << "Constructor called" << endl; } void display() { cout << "Roll Number: " << rollNo << endl; } ~Student() { cout << "Destructor called" << endl; } }; int main() { Student *ptr = new Student(101); ptr->display(); delete ptr; ptr = nullptr; return 0; }

Expected Output

Constructor called
Roll Number: 101
Destructor called

Explanation

  • new Student(101) allocates memory for a Student object.
  • The parameterized constructor executes during object creation.
  • ptr->display() calls the object's member function through the pointer.
  • delete ptr; destroys the object and releases its storage.
  • The destructor executes when the object is deleted.

9. Memory Leak

A memory leak occurs when dynamically allocated memory is no longer accessible or needed but has not been released.

Example of Memory Leak

int *ptr = new int(100); // Memory is allocated. // delete is missing. ptr = nullptr;

In this example, assigning nullptr to ptr loses the address of the allocated memory. The memory cannot be released through this pointer afterward.

Correct Approach

int *ptr = new int(100); delete ptr; ptr = nullptr;
Remember: Every successful manual allocation should have a clear ownership and release strategy.

10. Dangling Pointer

A dangling pointer is a pointer that refers to memory whose lifetime has ended or which is no longer valid.

Example

int *ptr = new int(50); delete ptr; // ptr still contains the old address. // Do not dereference ptr here.

After deletion, the pointer does not automatically become null. Dereferencing it is invalid.

Safer Approach

int *ptr = new int(50); delete ptr; ptr = nullptr;
Note: Setting a pointer to nullptr prevents accidental dereferencing through that pointer, but it does not fix other pointers that may refer to the same released memory.

11. What Happens If Memory Allocation Fails?

A normal allocation using new throws an exception of type std::bad_alloc if the requested memory cannot be allocated.

Example

#include <iostream> #include <new> using namespace std; int main() { try { int *ptr = new int[100]; cout << "Memory allocated successfully" << endl; delete[] ptr; } catch (const bad_alloc &e) { cout << "Memory allocation failed" << endl; } return 0; }
Important: The allocation size in this example is small and will normally succeed. The catch block demonstrates how allocation failure can be handled.

Non-throwing Allocation

C++ also provides new (nothrow), which returns nullptr if allocation fails instead of throwing std::bad_alloc.

#include <iostream> #include <new> using namespace std; int main() { int *ptr = new (nothrow) int(100); if (ptr == nullptr) { cout << "Allocation failed" << endl; } else { cout << "Value: " << *ptr << endl; delete ptr; } return 0; }

12. Important Rules of new and delete

  • new allocates memory dynamically.
  • delete releases a single dynamically allocated object.
  • new[] allocates an array dynamically.
  • delete[] releases an array allocated using new[].
  • Objects created using new have their constructors called.
  • Deleting an object invokes its destructor.
  • Deleting nullptr is safe and has no effect.
  • Do not use a pointer after the object it points to has been deleted.
  • Do not release the same allocation more than once.
  • Do not mix new/delete with malloc/free.

13. Common Mistakes

Mistake Correct Understanding
Forgetting to release allocated memory. Use the matching delete operation or automatic resource management.
Using delete for an array. Use delete[] for memory allocated with new[].
Using a pointer after deletion. Do not dereference a pointer after its object has been destroyed.
Deleting the same allocation twice. Ensure each allocation is released exactly once.
Mixing new with free(). Use matching allocation and deallocation operations.

14. Modern C++ Alternative: Smart Pointers

Modern C++ provides smart pointers to manage dynamically allocated objects automatically. They help reduce memory leaks and ownership errors.

Example: unique_ptr

#include <iostream> #include <memory> using namespace std; int main() { unique_ptr<int> ptr = make_unique<int>(100); cout << "Value: " << *ptr << endl; return 0; }

Expected Output

Value: 100

The memory is automatically released when the unique_ptr goes out of scope.

Note: std::make_unique was introduced in C++14. Raw new and delete remain important to understand, especially for learning dynamic memory management.

15. Interview Questions

Q1. What is the new operator?

It dynamically allocates memory and returns a pointer to the allocated object.

Q2. What is the delete operator?

It destroys an object created with new and releases its storage.

Q3. What is the difference between new and new[]?

new allocates one object, while new[] allocates an array of objects.

Q4. What is the difference between delete and delete[]?

delete releases a single object, while delete[] releases an allocated array.

Q5. What is a memory leak?

It occurs when allocated memory is not released and the program loses the ability to access or reuse it.

Q6. What is a dangling pointer?

It is a pointer that refers to an object or memory whose lifetime has ended or which is otherwise invalid.

Q7. What happens when new cannot allocate memory?

Normal new throws std::bad_alloc if allocation fails.

Q8. Does new call a constructor?

Yes. When new successfully creates a class object, the appropriate constructor is called.

Q9. Does delete call a destructor?

Yes. Deleting a dynamically allocated class object invokes its destructor before releasing its storage.

Q10. What is the purpose of nullptr?

It represents a null pointer and can be used to indicate that a pointer does not point to an object.

17. Summary

  • Dynamic memory allocation happens during program execution.
  • new allocates a single object.
  • delete releases a single dynamically allocated object.
  • new[] allocates an array.
  • delete[] releases a dynamically allocated array.
  • Constructors and destructors are called for dynamically created class objects.
  • Memory leaks and dangling pointers are important memory-management problems.
  • Smart pointers provide safer automatic resource management in modern C++.
Remember: Always match every allocation with the correct deallocation operation. Prefer smart pointers and standard containers in modern C++ whenever possible.
