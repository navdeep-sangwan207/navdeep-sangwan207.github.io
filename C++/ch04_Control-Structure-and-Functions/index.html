About This Chapter

Control structures determine the flow of execution in a C++ program. They allow a program to make decisions, repeat statements and transfer control between different parts of the program.

Functions divide a program into smaller reusable blocks of code. They improve program organization, readability and maintainability.

Learning Objectives

  • Understand decision-making statements such as if-else and switch.
  • Learn different looping structures in C++.
  • Understand break and continue statements.
  • Learn function declaration, definition and function calls.
  • Understand default arguments and references.
  • Differentiate call by value and call by reference.
  • Understand function overloading and overload resolution.
  • Learn inline functions, recursion and storage classes.
