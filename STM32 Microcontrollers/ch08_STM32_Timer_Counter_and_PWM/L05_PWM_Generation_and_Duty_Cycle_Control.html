2. What Is PWM?

Pulse Width Modulation (PWM) is a technique in which a digital output signal switches between HIGH and LOW at a fixed repetition frequency, while its pulse width is varied.

PWM is commonly generated using the output channels of STM32 hardware timers.

PWM Signal


100% HIGH  ─────────────────────────

75%        ┌──────────────┐
           │              │
LOW  ──────┘              └──────────

50%        ┌────────┐
           │        │
LOW  ──────┘        └────────────────

25%        ┌───┐
           │   │
LOW  ──────┘   └─────────────────────

The time spent HIGH compared with the total PWM period determines the duty cycle.

3. PWM Parameters

1. PWM Period

The period is the time required to complete one complete PWM cycle.

2. PWM Frequency

Frequency is the number of PWM cycles generated per second.

Frequency = 1 / Period

3. Duty Cycle

Duty cycle is the percentage of one period during which the output remains HIGH.

Duty Cycle (%) = (HIGH Time / Total Period) × 100

Duty Cycle HIGH Time LOW Time
0% 0% of period 100% of period
25% 25% of period 75% of period
50% 50% of period 50% of period
75% 75% of period 25% of period
100% 100% of period 0% of period

Example: 50% Duty Cycle

  • Duty cycle = 50%

5. How STM32 Generates PWM

STM32 timers generate PWM using a counter, an auto-reload register (ARR), and a capture/compare register (CCR).

               |
               v

               |
               v

               |
               v

Important Registers

Register Function
PSC Divides the timer input clock.
ARR Sets the timer counting period.
CCR Sets the PWM compare value.
CCMR Configures the channel mode, including PWM mode.
CCER Enables the channel output and configures polarity.
CR1 Controls timer operation and counting mode.

6. PWM Frequency Calculation

For a typical edge-aligned, up-counting timer:

PWM Frequency = Timer Clock / [(PSC + 1) × (ARR + 1)]

Example: Generate 1 kHz PWM

Timer clock = 84 MHz

Prescaler = 83

Auto-reload value = 999

PWM frequency = 84,000,000 / (84 × 1000)

PWM frequency = 1000 Hz

PWM period = 1 ms

The actual timer clock must be calculated from the selected STM32 clock tree and timer bus configuration.

7. Duty Cycle Calculation Using CCR

For common edge-aligned PWM mode 1 with active-high polarity, the approximate duty cycle is:

Duty Cycle (%) = [CCR / (ARR + 1)] × 100

Example: 50% Duty Cycle

ARR = 999

CCR = 500

Duty cycle = (500 / 1000) × 100

Duty cycle = 50%

Duty Cycle Examples

ARR CCR Approximate Duty Cycle
999 250 25%
999 500 50%
999 750 75%
999 1000 100% equivalent in this common configuration
Exact boundary behavior at CCR = 0 or CCR = ARR + 1 can depend on timer mode and implementation. Verify the reference manual for the selected STM32.

8. PWM Modes

PWM Mode 1

In common up-counting operation, the output is active while CNT is less than CCR and inactive when CNT reaches the compare threshold.

PWM Mode 2

PWM Mode 2 provides the complementary comparison behavior relative to PWM Mode 1.

Output polarity settings determine whether the active state appears as HIGH or LOW at the pin.

10. PWM Generation Using STM32 HAL

Timer Configuration Example

void MX_TIM2_Init(void)
{
    TIM_OC_InitTypeDef sConfigOC = {0};

    htim2.Instance = TIM2;

    htim2.Init.Prescaler = 83;
    htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
    htim2.Init.Period = 999;

    htim2.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    htim2.Init.AutoReloadPreload =
        TIM_AUTORELOAD_PRELOAD_DISABLE;

    if (HAL_TIM_PWM_Init(&htim2) != HAL_OK)
    {
        Error_Handler();
    }

    sConfigOC.OCMode = TIM_OCMODE_PWM1;
    sConfigOC.Pulse = 500;
    sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
    sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;

    if (HAL_TIM_PWM_ConfigChannel(
            &htim2,
            &sConfigOC,
            TIM_CHANNEL_1) != HAL_OK)
    {
        Error_Handler();
    }
}

Start PWM Output

HAL_TIM_PWM_Start(
    &htim2,
    TIM_CHANNEL_1
);

The GPIO alternate-function setup and timer clock configuration must also be completed.

11. Changing Duty Cycle at Runtime

The duty cycle can be changed by updating the compare value in the CCR register.

HAL Macro Example

__HAL_TIM_SET_COMPARE(
    &htim2,
    TIM_CHANNEL_1,
    250
);

With ARR = 999, this gives approximately 25% duty cycle in the common PWM Mode 1, active-high configuration.

Changing Duty Cycle Function

void Set_PWM_Duty(uint16_t duty)
{
    if (duty > 100)
    {
        duty = 100;
    }

    uint32_t compare =
        ((uint32_t)(htim2.Init.Period + 1) * duty) / 100;

    __HAL_TIM_SET_COMPARE(
        &htim2,
        TIM_CHANNEL_1,
        compare
    );
}
For the common PWM Mode 1 configuration, this function uses CCR = ARR + 1 at 100% duty. Confirm the exact endpoint behavior for the selected timer. Preload configuration can affect when an updated compare value becomes active.

12. Practical Project: LED Brightness Control

Objective

Control LED brightness by changing the PWM duty cycle.

Working Principle

  • Configure a timer channel in PWM mode.
  • Connect an LED through a suitable current-limiting resistor.
  • Start the timer PWM output.
  • Change the compare value to adjust duty cycle.
  • Observe the change in perceived LED brightness.

Example Code

int main(void)
{
    HAL_Init();
    SystemClock_Config();

    MX_GPIO_Init();
    MX_TIM2_Init();

    HAL_TIM_PWM_Start(
        &htim2,
        TIM_CHANNEL_1
    );

    while (1)
    {
        Set_PWM_Duty(10);
        HAL_Delay(1000);

        Set_PWM_Duty(30);
        HAL_Delay(1000);

        Set_PWM_Duty(60);
        HAL_Delay(1000);

        Set_PWM_Duty(100);
        HAL_Delay(1000);
    }
}

The LED brightness changes as the duty cycle changes. Perceived brightness is not necessarily linear with duty cycle.

14. PWM vs DAC

PWM DAC
Produces a digital pulse waveform. Produces an analog voltage or current output.
Uses timer output channels. Uses a digital-to-analog converter.
Average output can be filtered to approximate an analog level. Provides a converted analog output directly.
Requires suitable filtering when a smooth analog signal is needed. May require output buffering or filtering depending on application.

15. Common PWM Problems

Problem Possible Cause Solution
No PWM output Channel not started. Check HAL_TIM_PWM_Start().
Wrong frequency Incorrect timer clock or PSC/ARR. Recalculate timer frequency.
Wrong duty cycle Incorrect CCR value. Check ARR and compare calculation.
Wrong output pin Incorrect alternate-function mapping. Check the device datasheet.
Output polarity reversed Incorrect channel polarity. Check OCPolarity and output configuration.
Duty update delayed Compare preload enabled. Understand update-event transfer behavior.

16. Placement-Oriented Interview Questions

Q1. What is PWM?

PWM is a technique that controls the width of digital pulses while maintaining a selected repetition frequency.

Q2. What is duty cycle?

Duty cycle is the percentage of one PWM period during which the signal remains in its active state.

Q3. How do you calculate PWM frequency?

For a typical edge-aligned up-counting timer, divide the timer clock by (PSC + 1) multiplied by (ARR + 1).

Q4. What is the function of CCR?

CCR stores the compare value used to determine the PWM pulse width.

Q5. What is the difference between PWM Mode 1 and Mode 2?

They provide opposite comparison behavior for the output state, subject to output polarity.

Q6. How can PWM control LED brightness?

Changing duty cycle changes the average power delivered to the LED, changing its perceived brightness.

Q7. Can PWM control DC motor speed?

Yes. PWM controls the average voltage or power supplied through a suitable motor driver.

Q8. What is the role of PSC?

PSC divides the timer input clock to control the timer counter frequency.

Q9. What is the role of ARR?

ARR determines the timer counting period in the configured counting mode.

Q10. What is the difference between PWM and DAC?

PWM produces a digital pulse waveform whose average can be filtered; a DAC converts a digital value into an analog output.
