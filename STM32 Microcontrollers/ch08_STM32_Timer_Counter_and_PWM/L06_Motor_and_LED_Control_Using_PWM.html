Lesson 6: Motor and LED Control Using PWM

Learn practical STM32 applications of PWM for LED brightness control and DC motor speed control using a suitable motor driver.

2. PWM-Based LED Brightness Control

An LED can be controlled using a timer-generated PWM signal. Changing the PWM duty cycle changes the average power delivered to the LED.

Working Principle

  • Configure a timer channel in PWM mode.
  • Connect the timer output to an LED circuit.
  • Start PWM generation.
  • Change the compare register value.
  • Observe the brightness variation.

Typical Brightness Levels

Duty Cycle Expected Appearance
0% LED off
25% Low brightness
50% Medium brightness
75% High brightness
100% Continuously on
Use a current-limiting resistor and observe the GPIO pin's current and voltage limits. Perceived brightness is not necessarily proportional to duty cycle.

HAL_TIM_PWM_Start(
    &htim2,
    TIM_CHANNEL_1
);

/* Set approximately 25% duty cycle */
__HAL_TIM_SET_COMPARE(
    &htim2,
    TIM_CHANNEL_1,
    250
);

/* Set approximately 50% duty cycle */
__HAL_TIM_SET_COMPARE(
    &htim2,

    500
);

/* Set approximately 75% duty cycle */
__HAL_TIM_SET_COMPARE(
    &htim2,
    TIM_CHANNEL_1,
    750
);

These compare values assume ARR = 999 and a common edge-aligned PWM Mode 1 configuration.

4. What Is a DC Motor?

A DC motor converts electrical energy into mechanical rotational energy.

Basic Motor Components

  • Stator
  • Rotor or armature
  • Windings
  • Commutator in a brushed DC motor
  • Brushes in a brushed DC motor
  • Shaft

Motor Control Parameters

Parameter Description
Voltage Electrical supply applied to the motor.
Current Current drawn by the motor.
Speed Rotational speed, often measured in RPM.
Torque Rotational force produced by the motor.

5. Why Is a Motor Driver Required?

An STM32 GPIO pin cannot directly supply the current required by most DC motors. A motor driver provides the power interface between the MCU and the motor.

Motor Driver Functions

  • Provides the required motor current.
  • Allows control of motor direction in supported drivers.
  • Accepts logic-level control signals from the MCU.
  • Provides switching devices for motor power control.
  • May include current limiting and protection features.
Never connect a motor directly to an STM32 GPIO pin. Select a driver according to motor supply voltage, stall current, thermal limits and logic compatibility.

6. H-Bridge Motor Driver

An H-bridge is a circuit that allows the voltage polarity across a DC motor to be reversed. This enables forward and reverse rotation. 


             Motor Supply
                  |
             +----+----+
             |         |
            Q1         Q2
             |         |
             +---MOTOR-+
             |         |
            Q3         Q4
             |         |
             +----+----+
                  |
                 GND

In a practical driver IC, the switching devices, gate control and protection circuitry are integrated.

Direction Control Concept

Input A Input B Typical Result
HIGH LOW Forward direction
LOW HIGH Reverse direction
LOW LOW Coast or stop, driver-dependent
HIGH HIGH Brake or another state, driver-dependent
The table is a general H-bridge concept, not a universal truth table for every driver IC. Always follow the selected driver's datasheet. Never command both high-side and low-side switches in the same bridge leg on simultaneously.

7. PWM-Based DC Motor Speed Control

PWM controls the average voltage applied to a motor through a suitable motor driver.

Increasing the duty cycle generally increases average motor voltage and can increase motor speed.

Typical Speed Control Levels

Actual motor speed depends on supply voltage, load torque, motor characteristics, driver voltage drop and control method.

9. STM32 HAL Motor Control Example

GPIO Direction Control

void Motor_Forward(void)
{
    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_0,
        GPIO_PIN_SET
    );

    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_1,
        GPIO_PIN_RESET
    );
}

void Motor_Reverse(void)
{
    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_0,
        GPIO_PIN_RESET
    );

    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_1,
        GPIO_PIN_SET
    );
}

void Motor_Stop(void)
{
    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_0,
        GPIO_PIN_RESET
    );

    HAL_GPIO_WritePin(
        GPIOB,
        GPIO_PIN_1,
        GPIO_PIN_RESET
    );
}

Motor Speed Control

void Motor_SetSpeed(uint16_t duty)
{
    if (duty > 100)
    {
        duty = 100;
    }

    uint32_t compare =
        ((uint32_t)(htim2.Init.Period + 1) * duty) / 100;

    __HAL_TIM_SET_COMPARE(
        &htim2,
        TIM_CHANNEL_1,
        compare
    );
}

Main Program Example

int main(void)
{
    HAL_Init();
    SystemClock_Config();

    MX_GPIO_Init();
    MX_TIM2_Init();

    HAL_TIM_PWM_Start(
        &htim2,
        TIM_CHANNEL_1
    );

    while (1)
    {
        Motor_Forward();
        Motor_SetSpeed(30);
        HAL_Delay(2000);

        Motor_SetSpeed(60);
        HAL_Delay(2000);

        Motor_SetSpeed(90);
        HAL_Delay(2000);

        Motor_Stop();
        HAL_Delay(1000);

        Motor_Reverse();
        Motor_SetSpeed(40);
        HAL_Delay(2000);

        Motor_Stop();
        HAL_Delay(1000);
    }
}
This is an application-level example. Configure GPIOB pins 0 and 1 as outputs, TIM2 Channel 1 as PWM, and the correct timer output pin as alternate function. Verify that the selected driver supports the chosen PWM and direction-control arrangement. Add suitable dead time or interlocking if required by the power stage.

10. Motor Speed Feedback

Open-loop PWM control changes the motor drive command without measuring actual motor speed.

Closed-loop speed control measures motor speed using a sensor such as an encoder and adjusts PWM based on the difference between desired and measured speed.

Important Terms

  • Setpoint: Desired motor speed.
  • Feedback: Measured motor speed.
  • Error: Difference between desired and measured speed.
  • Controller: Adjusts the motor drive command.
  • Encoder: Provides speed or position information.

11. Electrical and Hardware Safety

  • Do not power a motor from an MCU GPIO pin.
  • Use a suitable motor driver or power stage.
  • Check motor stall current before selecting the driver.
  • Use the recommended flyback or recirculation protection.
  • Follow the driver's decoupling capacitor recommendations.
  • Use a suitable external motor power supply.
  • Connect grounds correctly for non-isolated control.
  • Prevent excessive current and overheating.
  • Keep power wiring suitable for the motor current.
  • Check switching-device dead-time requirements.

12. Common Problems and Troubleshooting

Problem Possible Cause Solution
LED does not change brightness PWM not running or wrong pin. Check timer channel and GPIO alternate function.
Motor does not rotate Incorrect supply or driver wiring. Check driver supply, enable and motor connections.
Motor rotates in wrong direction Direction input logic reversed. Check driver truth table and wiring.
Motor speed does not change Incorrect PWM input or duty update. Check PWM signal at driver input.
MCU resets during motor operation Supply dip or electrical interference. Improve supply design, grounding and decoupling.
Driver overheats Excessive current or inadequate thermal design. Check motor current and driver ratings.
Motor produces noise PWM frequency or mechanical resonance. Review PWM frequency and motor characteristics.

13. Placement-Oriented Interview Questions

Q1. Why is PWM used for motor speed control?

PWM changes the average drive voltage or power supplied through a suitable motor driver.

Q2. Can an STM32 directly drive a DC motor?

No. A GPIO pin cannot normally provide the required motor current. A suitable motor driver is required.

Q3. What is an H-bridge?

An H-bridge is a switching circuit that reverses the voltage polarity across a motor to control its direction.

Q4. What happens when PWM duty cycle increases?

The average drive command generally increases. Motor speed may increase depending on load, supply and motor characteristics.

Q5. What is the difference between open-loop and closed-loop control?

Open-loop control does not use measured output feedback. Closed-loop control uses feedback to adjust the control signal.

Q6. Why is a common ground required?

A common ground provides a shared voltage reference for non-isolated control signals.

Q7. Why is motor stall current important?

A motor can draw a much higher current at stall than during normal operation. The driver must safely handle the required current.

Q8. What is the role of a flyback diode?

It provides a path for inductive current when a switching device turns off. Many motor drivers integrate suitable recirculation paths.

Q9. How can motor speed be measured?

Motor speed can be measured using an encoder, Hall sensor or another suitable speed sensor.

Q10. What is the advantage of closed-loop motor control?

It can maintain the desired speed more accurately despite changes in load and operating conditions.

15. Lesson Summary

  • PWM can control LED brightness and motor drive.
  • Duty cycle controls the average PWM drive level.
  • STM32 timer channels generate hardware PWM signals.
  • A motor driver interfaces the MCU with a motor.
  • An H-bridge can control DC motor direction.
  • Encoder feedback enables closed-loop speed control.
  • Motor current, voltage and thermal limits must be considered.
  • Electrical protection is essential in motor-control applications.
