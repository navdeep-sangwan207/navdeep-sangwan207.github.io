2. What Is Input Capture?

Input capture is a timer function that records the current counter value when a selected event occurs on a timer input channel.

The selected event can be a rising edge, falling edge or another supported input transition.

Working Principle


       External Input Signal
                |
                v
        Timer Input Channel
                |
                v
        Edge Detection Circuit
                |
                v
       Capture Event Occurs
                |
                v
       CNT Value Copied to CCR
                |
                v
       Firmware Reads Captured Value

The captured value is stored in a capture/compare register (CCR) associated with the timer channel.

3. Input Capture Registers and Channels

General-purpose STM32 timers commonly provide multiple capture/compare channels.

Register Purpose
CCMR Configures input capture or output compare channel mode.
CCER Controls channel enable and input/output polarity.
CCR1 Capture/compare register for channel 1.
CCR2 Capture/compare register for channel 2.
CCR3 Capture/compare register for channel 3.
CCR4 Capture/compare register for channel 4.
SR Contains capture/compare event flags.
The number of channels and available capture features depend on the selected timer instance and STM32 device.

4. Rising Edge and Falling Edge Detection

Rising Edge

A rising edge occurs when the signal changes from logic LOW to logic HIGH. 


LOW  ______
           |
           |____ HIGH
           ^
       Rising Edge

Falling Edge

A falling edge occurs when the signal changes from logic HIGH to logic LOW. 


HIGH ______
           |
           |____ LOW
           ^
       Falling Edge

Both-Edge Detection

Some timer channels support capture on both rising and falling edges. This can be useful for measuring pulse width and signal timing.

5. Measuring Signal Period Using Input Capture

To measure the period of a repetitive input signal, capture the timer count at two successive rising edges.

Period = Second Capture - First Capture

Frequency = 1 / Period

Example

Timer counter frequency = 1 MHz

First capture = 1000

Second capture = 3000

Difference = 3000 - 1000 = 2000 counts

Timer tick duration = 1 microsecond

Signal period = 2000 × 1 microsecond

Period = 2 milliseconds

Frequency = 500 Hz

6. Measuring Pulse Width

Input capture can measure the duration of a HIGH or LOW pulse by capturing different edges.

HIGH Pulse Width Measurement

  1. Capture the rising edge.
  2. Record the timer count.
  3. Capture the following falling edge.
  4. Record the second timer count.
  5. Calculate the difference.

HIGH pulse width = Falling capture - Rising capture

Example:

Counter frequency = 1 MHz

Rising capture = 1200

Falling capture = 1700

Pulse width = 500 microseconds

If the timer counter wraps between captures, use wraparound-aware arithmetic. For a timer with an ARR value of N in a simple up-counting configuration, the difference can be calculated modulo N + 1. Ensure that the actual timer configuration and number of wraps are known.

7. Input Capture Using STM32 HAL

Timer Configuration

Configure the selected timer channel in input capture mode using STM32CubeMX or the HAL initialization functions.

Start Input Capture with Interrupt

HAL_TIM_IC_Start_IT(
    &htim2,
    TIM_CHANNEL_1
);

Capture Callback

volatile uint32_t captured_value = 0;

void HAL_TIM_IC_CaptureCallback(
    TIM_HandleTypeDef *htim)
{
    if ((htim->Instance == TIM2) &&
        (htim->Channel == HAL_TIM_ACTIVE_CHANNEL_1))
    {
        captured_value =
            HAL_TIM_ReadCapturedValue(
                htim,
                TIM_CHANNEL_1
            );
    }
}

The callback receives the capture event. The captured counter value is read from the selected capture/compare channel.

Configure the timer channel GPIO in the correct alternate-function mode, select the input source, configure the input polarity and enable the corresponding NVIC interrupt. The timer IRQ handler must call HAL_TIM_IRQHandler().

8. What Is Output Compare?

Output compare is a timer function that compares the current counter value with a programmed compare value in a CCR register.

When the counter matches the compare value, the timer can generate an event, interrupt, DMA request or output-pin action depending on the configuration.

Working Principle


          Timer Counter (CNT)
                  |
                  v
       Compare with CCR Register
                  |
                  v
           Match Detected
                  |
          +-------+-------+
          |       |       |
          v       v       v
        Flag   Interrupt  Output
                          Action

9. Output Compare Modes

Mode Operation
Frozen No output-pin action on compare match.
Active on Match Sets the output active on compare match.
Inactive on Match Sets the output inactive on compare match.
Toggle on Match Toggles the output state on compare match.
Forced Active Forces the output to its active state.
Forced Inactive Forces the output to its inactive state.
PWM Modes Controls output state based on counter and compare values.

Available modes and their exact output behavior depend on the timer implementation and channel configuration.

10. Output Compare Timing Example

Suppose the timer counter increments at 1 MHz and the compare value is 2500.

Each counter tick takes 1 microsecond.

Compare match occurs after 2500 counter ticks from the counter's starting reference point.

Compare time = 2500 microseconds = 2.5 ms

The configured output action occurs when the counter matches the compare value.

12. Input Capture vs Output Compare

Input Capture Output Compare
Measures external signal timing. Generates timed events or output actions.
Captures CNT into CCR. Compares CNT with CCR.
Used for frequency measurement. Used for timed output generation.
Used for pulse-width measurement. Used for output toggling and timing control.
Input signal is connected to a timer input channel. Output signal may be generated on a timer channel pin.

14. Common Problems and Troubleshooting

Problem Possible Cause Solution
No capture value Incorrect GPIO alternate function. Check pin mapping and timer channel configuration.
Wrong frequency Incorrect timer clock or counter frequency. Verify clock tree and prescaler.
Capture callback not reached Interrupt or NVIC not enabled. Check channel interrupt configuration.
Incorrect pulse width Wrong edge polarity or counter wraparound. Check edge selection and elapsed-count calculation.
No output compare signal Incorrect channel mode or pin configuration. Inspect timer output configuration and GPIO alternate function.
Unexpected capture values Input noise or signal glitches. Check input filtering and electrical signal quality.

15. Placement-Oriented Interview Questions

Q1. What is input capture?

Input capture stores the current timer counter value in a capture register when a selected input event occurs.

Q2. What is output compare?

Output compare compares the timer counter with a programmed CCR value and generates a configured event or output action.

Q3. What is a CCR register?

CCR is a capture/compare register used to store captured counter values or programmed compare values.

Q4. How do you measure frequency using input capture?

Capture the timer count at two successive equivalent edges, calculate the count difference and convert the elapsed time into frequency.

Q5. How do you measure pulse width?

Capture the starting edge and ending edge, then calculate the difference between captured counter values.

Q6. What is the difference between rising and falling edges?

A rising edge changes from LOW to HIGH, while a falling edge changes from HIGH to LOW.

Q7. What is input capture filtering?

It is a configurable digital filtering mechanism used to reject short unwanted input transitions on supported timer channels.

Q8. What is the purpose of output compare?

It generates timed output events or actions when the timer counter matches a programmed value.

Q9. Can input capture measure an encoder signal?

Yes, timer input capture can measure pulse timing. Some STM32 timers also provide dedicated encoder interface mode for quadrature encoders.

Q10. What happens when the timer counter overflows?

The counter wraps according to its configured counting range. Software must account for wraparound when calculating elapsed time.
