Chapter Overview

Real-Time Operating Systems (RTOS) are used in embedded applications that require multitasking, predictable scheduling and coordination between software components.

This chapter introduces FreeRTOS and its integration with STM32 microcontrollers. It focuses on practical concepts commonly expected in embedded firmware interviews.

  • Bare-metal programming versus RTOS.
  • FreeRTOS kernel architecture.
  • Task creation and scheduling.
  • Queues, semaphores and mutexes.
  • Task notifications and interrupt integration.
  • Real-time embedded application design.
