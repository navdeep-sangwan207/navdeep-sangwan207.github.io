Lesson 1: ARM Cortex-M Architecture Overview

Processor Core, CPU Architecture, Instruction Execution and Embedded Applications

1. Learning Objectives

  • Understand ARM processor architecture.
  • Explain the ARM Cortex-M processor family.
  • Identify the major components of a Cortex-M processor.
  • Understand the instruction execution process.
  • Differentiate Cortex-M processor variants.
  • Understand the relationship between ARM Cortex-M and STM32.
  • Prepare for embedded systems placement interviews.

2. What is ARM?

ARM is a processor architecture and intellectual property ecosystem used in embedded systems, microcontrollers, smartphones and many other computing devices.

ARM processor designs are based on the Reduced Instruction Set Computer (RISC) approach. Modern ARM processors use sophisticated implementations, but the RISC design philosophy emphasizes efficient instruction execution.

ARM Architecture Characteristics

  • RISC-based instruction set architecture.
  • Large register-based programming model.
  • Efficient instruction execution.
  • Support for low-power embedded applications.
  • Different processor profiles for different applications.

3. What is ARM Cortex-M?

ARM Cortex-M is a family of processor cores designed primarily for microcontroller and embedded applications. It is commonly used in industrial control, automotive electronics, IoT devices, consumer electronics and real-time systems.

Semiconductor manufacturers integrate Cortex-M processor cores into their microcontrollers and add peripherals such as GPIO, timers, ADC, UART, SPI and I2C.

Important distinction: ARM designs the Cortex-M processor core architecture. STMicroelectronics integrates selected Cortex-M cores into STM32 microcontrollers along with its own memory and peripheral implementations.

4. Cortex-M Processor Architecture

A Cortex-M processor contains several functional units that work together to execute instructions and manage processor operations.

This is a conceptual diagram. The exact internal implementation and available features depend on the Cortex-M core version.

5. Major Functional Units

1. Instruction Fetch Unit

Retrieves instructions from program memory using the instruction address maintained by the processor.

2. Instruction Decode Unit

Interprets the fetched instruction and determines the operation to be performed.

3. Execution Unit

Performs arithmetic, logical, data-processing and control-flow operations.

4. Register Bank

Contains general-purpose and special-purpose registers used for temporary data, addresses, stack operation and program control.

5. NVIC

The Nested Vectored Interrupt Controller manages interrupt requests, priorities and exception handling.

6. Bus Interface

Provides access to memory and peripheral address spaces. Cortex-M implementations use different bus arrangements depending on the processor core.

6. Cortex-M Processor Variants

Processor Typical Characteristics Common Application Areas
Cortex-M0 Small, low-cost 32-bit processor core. Simple embedded controllers.
Cortex-M0+ Enhanced low-power microcontroller core. Low-power IoT and control devices.
Cortex-M3 General-purpose embedded processor core. Industrial control and embedded applications.
Cortex-M4 DSP-oriented extensions; optional floating-point unit. Motor control and signal processing.
Cortex-M7 Higher-performance core with advanced execution features. High-performance embedded systems.
Cortex-M23 Armv8-M architecture with security features. Secure, low-power embedded devices.
Cortex-M33 Armv8-M architecture with TrustZone support. Secure IoT and industrial applications.
Cortex-M55 Helium vector processing support. Embedded AI and signal processing.
Interview point: Not every Cortex-M4 implementation includes an FPU. Floating-point support depends on the specific processor implementation.

7. ARM Cortex-M and STM32 Relationship

STM32 microcontrollers use different Cortex-M processor cores depending on the product family and device.

STM32 Example Processor Core
STM32F103 ARM Cortex-M3
STM32F407 ARM Cortex-M4
STM32F746 ARM Cortex-M7
STM32G071 ARM Cortex-M0+
STM32H743 ARM Cortex-M7
STM32L476 ARM Cortex-M4

The processor core provides the CPU architecture, while STMicroelectronics adds device-specific Flash, SRAM, peripherals, clock systems and other features.

8. Instruction Execution Cycle

The processor repeatedly fetches and executes instructions from the program. A simplified explanation is:

  1. Fetch: Retrieve the next instruction.
  2. Decode: Interpret the instruction.
  3. Execute: Perform the required operation.
  4. Write back: Store the result when required.
Real Cortex-M implementations use different pipelines and instruction execution mechanisms. This four-stage sequence is a simplified teaching model, not a universal cycle-by-cycle description.

Example Assembly Instructions

MOVS R0, #10
MOVS R1, #20
ADDS R2, R0, R1

Explanation:

  • First instruction places 10 into R0.
  • Second instruction places 20 into R1.
  • Third instruction adds R0 and R1 and stores the result in R2.

Final result: R2 = 30.

9. RISC Architecture

RISC stands for Reduced Instruction Set Computer. It is an architectural design approach that emphasizes a relatively simple instruction set and efficient execution.

Important Characteristics

  • Register-based operations.
  • Load/store architecture for memory access.
  • Simple instruction formats in many instruction sets.
  • Efficient compiler support.
  • Suitable for a wide range of embedded applications.

Load/Store Example

LDR R0, [R1]
ADDS R2, R0, #5
STR R2, [R1]

The example loads a value from the memory address in R1, adds 5 and stores the result back to that memory address.

10. Advantages of Cortex-M Architecture

  • Designed for microcontroller and embedded applications.
  • 32-bit processor architecture.
  • Efficient interrupt and exception handling.
  • Low-power implementation options.
  • Broad development-tool support.
  • Useful for real-time control applications.
  • Large ecosystem of semiconductor manufacturers and software tools.

11. Embedded Applications

  • Industrial automation and process control.
  • Motor control and power electronics.
  • Automotive electronic control units.
  • Smart home and IoT devices.
  • Medical and measurement instruments.
  • Robotics and consumer electronics.
  • Communication and sensor systems.

12. Placement Interview Questions and Answers

Q1. What is ARM?

ARM is a processor architecture and IP ecosystem used in embedded and general-purpose computing systems.

Q2. What is Cortex-M?

Cortex-M is a family of ARM processor cores designed primarily for microcontrollers and embedded applications.

Q3. What does RISC stand for?

Reduced Instruction Set Computer.

Q4. Is Cortex-M a microcontroller?

No. Cortex-M is a processor core. A microcontroller integrates a processor core with memory and peripherals.

Q5. Which Cortex-M core is used in STM32F103?

ARM Cortex-M3.

Q6. Which Cortex-M core is used in STM32F407?

ARM Cortex-M4.

Q7. What is NVIC?

NVIC stands for Nested Vectored Interrupt Controller. It manages interrupt requests and priorities.

Q8. What is the function of the execution unit?

It performs arithmetic, logical and other operations specified by processor instructions.

Q9. What is a load/store architecture?

It is an architecture in which data is transferred between memory and registers using load and store instructions. Arithmetic operations generally use register operands.

Q10. Why is Cortex-M widely used in embedded systems?

It offers a microcontroller-oriented processor architecture, interrupt handling support, efficient implementations and a broad software ecosystem.

14. Lesson Summary

  • ARM Cortex-M is a family of processor cores for embedded applications.
  • STM32 devices integrate different Cortex-M cores.
  • The processor uses registers, execution logic and memory interfaces.
  • NVIC manages interrupts and exceptions.
  • RISC is the underlying architectural design philosophy.
  • Understanding processor architecture is important for firmware development and interviews.
