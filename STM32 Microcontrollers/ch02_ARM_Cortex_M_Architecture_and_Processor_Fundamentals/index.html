Chapter 2: ARM Cortex-M Architecture and Processor Fundamentals

Processor Core, Registers, Stack, Exceptions, NVIC and Memory Architecture

Chapter Overview

ARM Cortex-M processors are widely used in embedded systems and microcontroller applications. STM32 microcontrollers use different Cortex-M processor cores depending on their family and device.

This chapter explains the processor architecture, register organization, stack operation, exception handling, NVIC and memory organization required for embedded firmware development and technical interviews.
