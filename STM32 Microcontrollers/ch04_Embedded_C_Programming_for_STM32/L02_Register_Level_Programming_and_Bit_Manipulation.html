Lesson 2: Register-Level Programming and Bit Manipulation

Learn how to access microcontroller registers and control individual hardware bits using Embedded C.

2. What is a Register?

A register is a small storage location inside a microcontroller. Registers hold data, configuration settings, status information, and control information for the processor and peripherals.

Examples of STM32 Registers

Register Purpose
GPIOx_MODER Configures GPIO pin modes on STM32 families that use this register layout.
GPIOx_ODR Stores GPIO output data.
GPIOx_IDR Reads GPIO input data.
GPIOx_BSRR Sets or resets GPIO output bits atomically on supported STM32 GPIO implementations.
RCC registers Control clocks and reset signals for peripherals.
USART registers Configure and control serial communication.
TIM registers Configure timers and counters.
Register names, bit positions, and layouts vary across STM32 families. Always consult the reference manual for the exact device.

3. What is Register-Level Programming?

Register-level programming means configuring and controlling microcontroller hardware by directly accessing peripheral registers from firmware.

Example Tasks

  • Enable a peripheral clock.
  • Configure a GPIO pin as an output.
  • Set or reset a GPIO output.
  • Configure a timer prescaler.
  • Enable UART transmission.
  • Configure ADC conversion.

Programming Layers

Application Code
       |
       v
STM32 HAL / LL Libraries
       |
       v
CMSIS Device Definitions
       |
       v
Peripheral Registers
       |
       v
STM32 Hardware

Register-level programming gives direct control over hardware. HAL and LL libraries provide higher-level interfaces that ultimately configure peripheral registers.

4. Number Systems Used in Embedded Systems

Binary and hexadecimal number systems are essential when configuring hardware registers.

Number System Base Digits
Binary 2 0 and 1
Decimal 10 0 to 9
Hexadecimal 16 0 to 9 and A to F

Example: Binary to Hexadecimal

Binary:       0000 1010
Decimal:      10
Hexadecimal:  0x0A

One hexadecimal digit represents four binary bits. This makes hexadecimal notation convenient for reading 8-bit, 16-bit, and 32-bit register values.

5. Bitwise Operators in C

Bitwise operators perform operations directly on the individual bits of integer values.

Operator Name Purpose
& Bitwise AND Tests or retains selected bits.
| Bitwise OR Sets selected bits.
^ Bitwise XOR Toggles selected bits.
~ Bitwise NOT Inverts the bits.
<< Left Shift Shifts bits toward higher positions.
>> Right Shift Shifts bits toward lower positions.

6. Bitwise AND (&)

Bitwise AND produces 1 only when both corresponding bits are 1. 

  1010
& 1100
------
  1000

C Example

#include <stdint.h>

int main(void)
{
    uint8_t a = 0x0A;
    uint8_t b = 0x0C;

    uint8_t result = a & b;

    while (1)
    {
        (void)result;
    }
}

Result: 0x08

Use in Embedded Systems

AND is used to check whether a particular register bit is set. 

if (status_register & (1U << 3))
{
    /* Bit 3 is set */
}

7. Bitwise OR (|)

Bitwise OR produces 1 when at least one corresponding bit is 1. 

  1010
| 1100
------
  1110

Set a Particular Bit

register_value |= (1U << 5);

This operation sets bit 5 while preserving the other bits.

Example

#include <stdint.h>

int main(void)
{
    uint32_t reg = 0x00;

    reg |= (1U << 5);

    while (1)
    {
        (void)reg;
    }
}

Result: 0x00000020

8. Bitwise XOR (^)

XOR produces 1 when the corresponding bits are different. 

  1010
^ 1100
------
  0110

Toggle a Particular Bit

register_value ^= (1U << 2);

If bit 2 is 0, it becomes 1. If bit 2 is 1, it becomes 0.

9. Bitwise NOT (~)

The NOT operator inverts every bit of its operand. 

uint8_t value = 0x0F;

uint8_t result = (uint8_t)~value;

Result: 0xF0

Integer promotion occurs before many bitwise operations. Use suitable unsigned types and masks to avoid unexpected signedness or width problems.

10. Left Shift and Right Shift

Left Shift

uint32_t value = 1U;

value = value << 3;

Result: 8 (binary 0000 1000)

Right Shift

uint32_t value = 16U;

value = value >> 2;

Result: 4

Creating a Bit Mask

#define BIT_0   (1U << 0)
#define BIT_1   (1U << 1)
#define BIT_2   (1U << 2)
#define BIT_3   (1U << 3)
#define BIT_4   (1U << 4)

A bit mask selects one or more bits for testing or modification.

11. Set, Clear, Toggle and Read a Bit

Set a Bit

reg |= (1U << bit_position);

Clear a Bit

reg &= ~(1U << bit_position);

Toggle a Bit

reg ^= (1U << bit_position);

Read a Bit

if ((reg & (1U << bit_position)) != 0U)
{
    /* Bit is set */
}
else
{
    /* Bit is clear */
}
Operation Expression
Set bit 3 reg |= (1U << 3);
Clear bit 3 reg &= ~(1U << 3);
Toggle bit 3 reg ^= (1U << 3);
Read bit 3 (reg >> 3) & 1U

12. Read-Modify-Write Operation

A read-modify-write operation reads a register, modifies selected bits, and writes the updated value back. 

uint32_t value;

value = PERIPHERAL_REG;

value |= (1U << 4);

PERIPHERAL_REG = value;

Why It Is Used

  • Changes selected configuration bits.
  • Preserves unrelated bits when register semantics allow it.
  • Supports peripheral configuration.
Read-modify-write is not automatically atomic. It can be unsafe when an interrupt or another execution context modifies the same register, or when the register has special read/write behavior. Use peripheral-specific atomic set/reset registers where available.

13. Memory-Mapped Register Access

STM32 peripherals are accessed through memory-mapped addresses. A C program can access a register through a pointer to a volatile integer type.

Illustrative Example

#include <stdint.h>

#define REGISTER_ADDRESS  0x40000000UL

#define PERIPHERAL_REG \
    (*(volatile uint32_t *)REGISTER_ADDRESS)

int main(void)
{
    uint32_t value = PERIPHERAL_REG;

    PERIPHERAL_REG = value | (1U << 2);

    while (1)
    {
    }
}

The volatile qualifier tells the compiler that accesses to the register are observable and must not be treated like ordinary memory accesses that can be freely removed.

The address 0x40000000 is illustrative, not a universal register address. Use the exact register address and access width specified by the selected STM32 reference manual.

14. STM32 GPIO Register-Level Programming

The following example demonstrates the general register programming sequence for an STM32 family with the GPIO MODER, ODR, and RCC AHB1ENR register layout, such as STM32F4 devices.

Example: Configure PA5 as Output

#include "stm32f4xx.h"

int main(void)
{
    /* Enable GPIOA peripheral clock */
    RCC->AHB1ENR |= (1U << 0);

    /* Configure PA5 as general-purpose output */
    GPIOA->MODER &= ~(3U << (5U * 2U));
    GPIOA->MODER |=  (1U << (5U * 2U));

    while (1)
    {
        /* Set PA5 */
        GPIOA->ODR |= (1U << 5);

        for (volatile uint32_t i = 0; i < 500000U; i++)
        {
        }

        /* Clear PA5 */
        GPIOA->ODR &= ~(1U << 5);

        for (volatile uint32_t i = 0; i < 500000U; i++)
        {
        }
    }
}

Explanation

  1. Enable the GPIOA clock through the RCC register.
  2. Clear the two MODER bits associated with PA5.
  3. Set the mode bits to output mode (binary 01).
  4. Set the corresponding ODR bit to drive the output high.
  5. Clear the ODR bit to drive the output low.
This code is specific to STM32F4-style GPIO and RCC registers. Other STM32 families may use different RCC registers or clock enable bits. The delay loop is not a calibrated time delay; use a hardware timer or HAL_Delay() for reliable timing. Also verify the board's LED pin and electrical configuration.

15. Using BSRR to Set and Reset GPIO Pins

Many STM32 GPIO implementations provide a Bit Set/Reset Register (BSRR) to set or reset output bits without a software read-modify-write operation on ODR.

Example

/* Set GPIO pin 5 */
GPIOA->BSRR = (1U << 5);

/* Reset GPIO pin 5 */
GPIOA->BSRR = (1U << (5U + 16U));

The lower half of BSRR is used to set output bits, while the upper half is used to reset output bits on STM32 devices with this BSRR layout.

Confirm the BSRR layout in the selected device reference manual. BSRR writes are useful for avoiding certain read-modify-write race conditions on GPIO outputs.

16. Common Register Programming Mistakes

Mistake Correction
Using the wrong register address Check the device reference manual and CMSIS header.
Forgetting to enable peripheral clock Enable the correct clock before peripheral access.
Clearing unrelated bits Use the correct mask and register semantics.
Using an incorrect bit position Verify the register bit field definition.
Ignoring volatile Use appropriate volatile-qualified access for hardware registers.
Assuming all STM32 families use identical registers Check the selected family documentation.
Using read-modify-write on special registers Follow the register's documented access behavior.

17. Placement-Oriented Interview Questions and Answers

Q1. What is register-level programming?

It is the process of controlling microcontroller hardware by directly accessing peripheral registers.

Q2. What is a bit mask?

A bit mask is a value used to select specific bits in a register or integer.

Q3. How do you set a bit in C?

Use the bitwise OR operator: reg |= (1U << n);

Q4. How do you clear a bit?

Use: reg &= ~(1U << n);

Q5. How do you toggle a bit?

Use: reg ^= (1U << n);

Q6. What is the difference between AND and OR?

AND produces 1 only when both corresponding bits are 1. OR produces 1 when at least one corresponding bit is 1.

Q7. What is memory-mapped I/O?

It is a technique in which peripheral registers are assigned addresses in the processor's memory address space.

Q8. Why are registers declared volatile?

Hardware registers can change independently of normal program flow. Volatile ensures the compiler respects the required accesses to those objects.

Q9. What is read-modify-write?

It is an operation in which a register is read, selected bits are modified, and the updated value is written back.

Q10. Why is a peripheral clock enabled before register access?

Many STM32 peripherals require their clock to be enabled before they operate correctly and accept configuration.

Q11. What is BSRR?

BSRR is a GPIO Bit Set/Reset Register used to set or reset output pins through dedicated bit positions on supported STM32 devices.

Q12. What is the difference between HAL and register-level programming?

HAL provides higher-level peripheral APIs, whereas register-level programming directly accesses peripheral control and status registers.
