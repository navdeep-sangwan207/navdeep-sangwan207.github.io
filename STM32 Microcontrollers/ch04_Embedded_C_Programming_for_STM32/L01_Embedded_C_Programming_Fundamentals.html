2. What is Embedded C?

Embedded C is the use of the C programming language to develop software that runs on embedded systems such as microcontrollers.

Embedded firmware controls hardware components including:

  • GPIO pins
  • Timers and counters
  • UART, SPI, and I2C interfaces
  • ADC and DAC peripherals
  • Interrupt controllers
  • Memory and communication interfaces

Applications of Embedded C

  • Automotive electronic control units.
  • Industrial automation systems.
  • Consumer electronic devices.
  • Medical instruments.
  • IoT devices.
  • Robotics and motor controllers.

3. General C vs Embedded C

General-Purpose C Embedded C
Often runs on computers or operating systems. Runs on microcontrollers or embedded processors.
Frequently uses operating-system services. May directly access hardware registers.
Usually has comparatively larger memory resources. Often operates with limited memory and processing resources.
May use files, processes, and desktop libraries. Uses peripheral drivers, startup code, and device libraries.
Timing constraints vary by application. Timing and hardware response are often important.
Embedded C is not a completely separate programming language. It is C programming applied to embedded hardware, usually with device-specific libraries, compiler tools, and hardware access.

5. Structure of an Embedded C Program

A basic STM32 application commonly contains:

  • Header files.
  • Macro definitions.
  • Global variables.
  • Function declarations.
  • The main() function.
  • Initialization code.
  • The main application loop.

General C Program Example

#include <stdio.h>

int main(void)
{
    int number = 10;

    printf("Number = %d\n", number);

    return 0;
}

Expected Output

Number = 10

This example demonstrates basic C syntax. In a typical bare-metal STM32 application, printf() output requires a configured output interface such as UART or SWO.

6. Data Types in Embedded C

Data types determine the kind of data a variable can store and how much memory it uses.

Type Typical Use
char Character or small integer data.
int Integer calculations.
float Floating-point calculations.
double Higher-precision floating-point calculations, subject to target/compiler support.
uint8_t Unsigned 8-bit integer.
uint16_t Unsigned 16-bit integer.
uint32_t Unsigned 32-bit integer.
int32_t Signed 32-bit integer.

Fixed-Width Integer Example

#include <stdint.h>

int main(void)
{
    uint8_t temperature = 30;
    uint16_t adc_value = 2048;
    uint32_t system_tick = 100000;

    while (1)
    {
        /* Application code */
    }
}
Fixed-width types such as uint8_t and uint32_t are defined in stdint.h. Their widths are guaranteed when the types are provided by the implementation. The size of int and other basic types depends on the target compiler.

7. Variables and Constants

A variable stores data that can change during program execution. A constant represents a value that the program should not modify through that object.

Example

#include <stdint.h>

int main(void)
{
    uint32_t counter = 0;
    const uint32_t limit = 100;

    while (counter < limit)
    {
        counter++;
    }

    while (1)
    {
        /* Main application loop */
    }
}

The counter changes during execution, whereas the program cannot modify the object declared with const.

8. Operators in Embedded C

Arithmetic Operators

int a = 20;
int b = 5;

int sum = a + b;
int difference = a - b;
int product = a * b;
int quotient = a / b;

Relational Operators

if (temperature > 40)
{
    /* High temperature condition */
}

Logical Operators

if ((temperature > 20) && (temperature < 40))
{
    /* Normal temperature range */
}

Bitwise Operators

uint32_t value = 0x05;

value = value | 0x02;
value = value & 0x07;
value = value ^ 0x01;

Bitwise operators are particularly important when configuring microcontroller registers. They are covered in detail in Lesson 2.

9. Conditional Statements

if-else Example

#include <stdint.h>

int main(void)
{
    uint16_t adc_value = 2500;

    if (adc_value > 2000)
    {
        /* High ADC reading */
    }
    else
    {
        /* Normal ADC reading */
    }

    }

switch Example

uint8_t mode = 2;

switch (mode)
{
    case 1:
        /* Mode 1 */
        break;

    case 2:
        /* Mode 2 */
        break;

    default:
        /* Default mode */

10. Loops in Embedded C

for Loop

for (int i = 0; i < 5; i++)
{
    /* Repeat five times */
}

while Loop

while (1)
{
    /* Main embedded application loop */
}

do-while Loop

uint8_t count = 0;

do
{
    count++;
}
while (count < 5);
An infinite while loop is common in bare-metal firmware. It repeatedly executes the main application logic after system initialization.

11. Functions in Embedded C

Functions divide firmware into reusable and manageable sections.

Example

#include <stdint.h>

uint32_t add_numbers(uint32_t a, uint32_t b)
{
    return a + b;
}

int main(void)
{
    uint32_t result = add_numbers(10, 20);

    while (1)
    {
        (void)result;
    }
}

Benefits of Functions

  • Code reusability.
  • Improved readability.
  • Easier debugging.
  • Modular firmware design.
  • Simpler testing and maintenance.

12. Header Files and STM32 Device Libraries

Header files provide declarations, macros, data types, and function prototypes needed by a program.

Common Header Files

Header Purpose
stdint.h Fixed-width integer types.
stdbool.h Boolean type and values.
stddef.h Common definitions such as size_t and NULL.
string.h String and memory handling functions.
Device-specific CMSIS header Processor and device register definitions.
stm32xxxx_hal.h STM32 HAL declarations for the selected device family.
The exact STM32 header filename depends on the selected microcontroller family and project configuration.

13. Basic STM32 Firmware Structure

A typical STM32CubeIDE project generated with HAL contains initialization functions and an application loop. 

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        /* Application code */
    }
}

Explanation

  • HAL_Init() initializes the HAL library and its basic services.
  • SystemClock_Config() configures the system clock.
  • MX_GPIO_Init() initializes GPIO according to the generated configuration.
  • while(1) contains the main application loop.
This is a simplified example. A generated project may also initialize DMA, communication peripherals, timers, ADC, and other hardware modules.

14. Practical Example: LED Toggle Using STM32 HAL

This example demonstrates the general structure of an STM32 GPIO application using the HAL library. 

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);

        HAL_Delay(500);
    }
}

Working

  1. Initialize the HAL library.
  2. Configure the system clock.
  3. Initialize the GPIO pin as an output using the project configuration.
  4. Toggle the output pin.
  5. Wait approximately 500 milliseconds.
  6. Repeat continuously.
GPIOA pin 5 is used as an example. Confirm that the selected STM32 device and board expose this pin and that it is connected to an LED. The GPIO configuration must also be generated or written correctly before running the example.

15. Important Embedded C Programming Practices

  • Use fixed-width integer types when register widths matter.
  • Initialize variables before using them.
  • Use meaningful function and variable names.
  • Keep functions small and focused.
  • Use bit masks for register operations.
  • Understand volatile when accessing hardware or shared data.
  • Check return values and error conditions.
  • Consider execution time and memory usage.
  • Use debugging tools to verify firmware behavior.
  • Read the reference manual and datasheet for the selected STM32.

16. Placement-Oriented Interview Questions and Answers

Q1. What is Embedded C?

Embedded C is C programming used to develop firmware for microcontrollers and embedded processors.

Q2. What is firmware?

Firmware is software stored in a device's non-volatile memory that controls its operation and hardware.

Q3. Why is C widely used in embedded systems?

C provides efficient compiled code, low-level memory access, bitwise operations, and good control over hardware resources.

Q4. What is the purpose of main()?

In a typical C application, main() is the entry point called by startup/runtime code after required initialization.

Q5. What is the difference between a variable and a constant?

A variable can be modified during execution, while a const object cannot be modified through that object in C.

Q6. What is the purpose of uint32_t?

It represents an unsigned integer type that is exactly 32 bits wide when provided by the implementation.

Q7. What is an infinite loop?

It is a loop that continues indefinitely unless execution is interrupted or the loop is exited.

Q8. Why are functions used in embedded programming?

Functions improve modularity, reusability, readability, and maintainability.

Q9. What is a header file?

A header file contains declarations, macros, types, and function prototypes that can be included in source files.

Q10. What is the purpose of HAL_Init()?

It initializes the STM32 HAL library and its basic services, including the HAL time base setup used by functions such as HAL_Delay().

Q11. What is the main loop in embedded firmware?

It is the continuously executing loop that performs the application's main tasks in a typical bare-metal program.

Q12. What is the difference between compilation and linking?

Compilation translates source code into object code. Linking combines object files and libraries, resolves symbols, and produces the final executable image.
