2. What is a Pointer?

A pointer is a variable that stores the memory address of another object or function.

Example

#include <stdio.h>

int main(void)
{
    int number = 25;

    int *ptr = &number;

    printf("Value = %d\n", number);
    printf("Address = %p\n", (void *)ptr);
    printf("Value through pointer = %d\n", *ptr);

    return 0;
}

Explanation

  • number stores the value 25.
  • &number obtains the address of number.
  • ptr stores that address.
  • *ptr accesses the object through the pointer.

3. Pointer Declaration and Initialization

Syntax

data_type *pointer_name;

Examples

int *ptr1;
char *ptr2;
float *ptr3;
uint32_t *ptr4;

Initialization

int value = 100;

int *ptr = &value;

The pointer type determines the type of object accessed when the pointer is dereferenced.

An uninitialized pointer must not be dereferenced. Use a valid object address or initialize a pointer to NULL until it is assigned a valid target.

4. Address-of and Dereference Operators

Operator Name Purpose
& Address-of Obtains the address of an object.
* Dereference Accesses the object pointed to.

Example

#include <stdint.h>

int main(void)
{
    uint32_t value = 50U;

    uint32_t *ptr = &value;

    *ptr = 75U;

    while (1)
    {
    }
}

Result: The value of value becomes 75.

5. Pointer Arithmetic

Pointer arithmetic moves between elements of an array. The address increment depends on the size of the pointed-to type.

Example

#include <stdint.h>

int main(void)
{
    uint32_t data[3] = {10U, 20U, 30U};

    uint32_t *ptr = data;

    uint32_t first = *ptr;
    uint32_t second = *(ptr + 1);
    uint32_t third = *(ptr + 2);

    while (1)
    {
        (void)first;
        (void)second;
        (void)third;
    }
}

Pointer arithmetic is scaled by the size of the pointed-to type. For example, adding one to a pointer to uint32_t advances by one uint32_t element.

Pointer arithmetic is defined only within an array object and one position past its final element. Do not use it to navigate arbitrary hardware addresses.

6. Pointers and Arrays

In most expressions, an array name is converted to a pointer to its first element.

Example

#include <stdint.h>

int main(void)
{
    uint16_t adc_values[4] = {100U, 200U, 300U, 400U};

    uint16_t *ptr = adc_values;

    uint16_t value = *(ptr + 2);

    while (1)
    {
        (void)value;
    }
}

Result: value = 300

Embedded Application

  • ADC sample buffers.
  • UART receive buffers.
  • SPI data buffers.
  • DMA transfer buffers.

7. Pointers and Functions

Pointers allow a function to access and modify an object supplied by its caller.

Example

#include <stdint.h>

void update_value(uint32_t *ptr)
{
    *ptr = 500U;
}

int main(void)
{
    uint32_t value = 100U;

    update_value(&value);

    while (1)
    {
        (void)value;
    }
}

Result: value becomes 500.

Why This Matters in STM32

  • Passing buffers to communication functions.
  • Updating data structures.
  • Reading peripheral data into memory.
  • Sharing data between firmware modules.

8. What is a Structure?

A structure is a user-defined data type that groups multiple variables, potentially of different types, under one name.

Syntax

struct StructureName
{
    data_type member1;
    data_type member2;
};

Example

#include <stdint.h>

struct Sensor
{
    uint16_t temperature;
    uint16_t pressure;
    uint8_t status;
};

int main(void)
{
    struct Sensor sensor1;

    sensor1.temperature = 30U;
    sensor1.pressure = 101U;
    sensor1.status = 1U;

    while (1)
    {
    }
}

The structure groups related sensor data into one object.

9. Structure Pointers

A pointer can store the address of a structure object.

Example

#include <stdint.h>

struct Sensor
{
    uint16_t temperature;
    uint16_t pressure;
};

int main(void)
{
    struct Sensor sensor = {25U, 100U};

    struct Sensor *ptr = &sensor;

    uint16_t temp = ptr->temperature;
    uint16_t pressure = ptr->pressure;

    while (1)
    {
        (void)temp;
        (void)pressure;
    }
}

Arrow Operator

ptr->temperature

The arrow operator accesses a structure member through a pointer. It is equivalent to: 

(*ptr).temperature

10. What is Memory-Mapped I/O?

Memory-mapped I/O is a method in which peripheral registers are assigned addresses in the processor's memory address space.

The processor accesses peripheral registers using normal load and store instructions through appropriate memory accesses.

Typical STM32 Peripheral Examples

Peripheral Register Function
GPIO Pin configuration and input/output control.
RCC Clock and reset control.
USART Serial communication control and data.
TIM Timer and counter configuration.
ADC Analog conversion control and results.

11. Accessing a Register Using a Pointer

A pointer can be used to access a hardware register at a known address.

Illustrative Example

#include <stdint.h>

#define REGISTER_ADDRESS  0x40000000UL

#define PERIPHERAL_REG \
    (*(volatile uint32_t *)REGISTER_ADDRESS)

int main(void)
{
    uint32_t value;

    value = PERIPHERAL_REG;

    PERIPHERAL_REG = value | (1U << 3);

    while (1)
    {
    }
}

Explanation

  1. The address is converted to a pointer to uint32_t.
  2. The pointer is volatile-qualified for hardware access.
  3. The dereference operator accesses the register.
  4. The bitwise operation modifies the selected bit.
The address is only an illustration. Never copy an arbitrary address into real firmware. Verify the peripheral base address, register offset, access width, and register behavior in the selected STM32 reference manual.

12. Register Structures in CMSIS

STM32 CMSIS device headers define C structures that represent peripheral register layouts. A peripheral pointer refers to the base address of the corresponding hardware block.

Example

#include "stm32f4xx.h"

int main(void)
{
    /* Enable GPIOA clock */
    RCC->AHB1ENR |= (1U << 0);

    /* Configure PA5 as output */
    GPIOA->MODER &= ~(3U << 10);
    GPIOA->MODER |=  (1U << 10);

    /* Set PA5 */
    GPIOA->BSRR = (1U << 5);

    while (1)
    {
    }
}

How GPIOA->MODER Works

  • GPIOA is a CMSIS-defined peripheral pointer.
  • MODER is a member of the GPIO register structure.
  • The arrow operator accesses that member through the pointer.
  • The assignment writes to the hardware register.
This register example uses the STM32F4 GPIO and RCC layout. Other STM32 families can have different clock-enable registers and peripheral structures. Use the device-specific CMSIS header.

13. Understanding Register Structure Layout

A CMSIS peripheral structure uses members arranged to match the hardware register offsets. Reserved fields may be included to preserve the correct spacing.

Illustrative Structure

typedef struct
{
    volatile uint32_t CR;
    volatile uint32_t SR;
    volatile uint32_t DR;
    volatile uint32_t RESERVED;
    volatile uint32_t CONFIG;
} ExamplePeripheral_TypeDef;

Each member represents a register or reserved address region. The actual register structure must match the hardware layout.

Do not create a peripheral structure from guesswork. Register offsets, reserved areas, access permissions, and alignment must match the reference manual exactly.

14. Structure Padding and Alignment

The compiler may insert padding bytes between structure members to satisfy alignment requirements.

Example

#include <stdint.h>

struct Example
{
    uint8_t a;
    uint32_t b;
    uint16_t c;
};

int main(void)
{
    uint32_t size = sizeof(struct Example);

    while (1)
    {
        (void)size;
    }
}

The structure size may be larger than the sum of its member sizes because of padding and final alignment.

Why It Matters in Embedded Systems

  • Memory usage and RAM optimization.
  • Communication packet layouts.
  • DMA buffer formats.
  • Hardware register structure definitions.
Hardware register structures require exact layout. Use the compiler and CMSIS definitions supplied for the target device rather than relying on an ordinary application structure's default layout.

16. Common Pointer and Structure Errors

Error Correction
Dereferencing an uninitialized pointer Initialize it with a valid object address.
Using an incorrect pointer type Use the correct object type and access width.
Incorrect pointer arithmetic Stay within the valid array object.
Confusing dot and arrow operators Use dot for a structure object and arrow for a pointer.
Incorrect register address Verify the reference manual and device header.
Missing volatile on hardware access Use the device's volatile-qualified register definitions.
Incorrect register structure layout Match hardware offsets and reserved fields exactly.

17. Placement-Oriented Interview Questions and Answers

Q1. What is a pointer?

A pointer is a variable that stores the address of an object or function.

Q2. What is dereferencing?

Dereferencing means accessing the object stored at the address held by a pointer.

Q3. What is pointer arithmetic?

It is arithmetic on pointers that moves between elements of an array according to the pointed-to type.

Q4. What is a NULL pointer?

A null pointer is a pointer value that is guaranteed not to point to an object or function.

Q5. What is a structure in C?

A structure is a user-defined type that groups multiple members under one name.

Q6. What is the difference between dot and arrow operators?

Dot accesses a member through a structure object. Arrow accesses a member through a pointer to a structure.

Q7. What is memory-mapped I/O?

It is a technique in which peripheral registers are assigned addresses in the processor's memory address space.

Q8. Why are peripheral registers volatile?

Their values can change because of hardware activity, and software accesses to them must be preserved.

Q9. What is CMSIS?

CMSIS is the Arm Cortex Microcontroller Software Interface Standard. It provides standardized core interfaces and device-specific definitions where supplied by the device vendor.

Q10. What is a peripheral structure?

It is a C structure whose members represent peripheral registers at their corresponding hardware offsets.

Q11. Why is structure alignment important?

Alignment affects member offsets and memory access. Peripheral structures must match the hardware register layout.

Q12. How does GPIOA->ODR access a register?

GPIOA is a pointer to a GPIO register structure, and ODR is the output data register member accessed through that pointer.
