4. DAC Working Principle

A DAC maps a digital input code to an analog output. For an ideal unipolar N-bit voltage DAC, the output is approximately proportional to the digital code.

Ideal DAC equation:

Vout = (Digital Code / (2^N - 1)) × VREF

Where:

  • Vout = analog output voltage.
  • N = DAC resolution in bits.
  • Digital Code = input digital value.
  • VREF = effective DAC reference voltage.

Example: 12-bit DAC

Resolution = 12 bits

Maximum Code = 2^12 - 1

             = 4095

Reference Voltage = 3.3 V

Digital Code = 2048

Vout ≈ (2048 / 4095) × 3.3

     ≈ 1.65 V
This is an idealized transfer equation. Actual output depends on DAC offset, gain, linearity, output-buffer characteristics, loading and the reference arrangement.

5. DAC Resolution

DAC resolution determines the number of possible digital input codes and the granularity of the analog output.

Resolution Number of Codes
8-bit 256
10-bit 1024
12-bit 4096
16-bit 65536

For an ideal 12-bit DAC with a 3.3 V reference, the nominal voltage step is: 

Voltage Step ≈ 3.3 / 4096

             ≈ 0.000806 V

             ≈ 0.806 mV
The voltage step is not the same as guaranteed absolute accuracy. Actual accuracy is affected by DAC specifications and circuit conditions.

7. DAC Configuration Using STM32CubeMX

  1. Open the STM32CubeIDE project.
  2. Open the MCU configuration view.
  3. Check whether the selected MCU has a DAC peripheral.
  4. Enable the required DAC channel.
  5. Configure the associated GPIO pin in analog mode.
  6. Select the output-buffer setting if available.
  7. Configure the trigger source if required.
  8. Configure DMA if waveform streaming is required.
  9. Generate the initialization code.
Not every STM32 microcontroller includes an internal DAC. Pin assignments and DAC configuration options must be checked in the exact MCU datasheet and reference manual.

8. STM32 DAC HAL Functions

HAL Function Purpose
HAL_DAC_Start() Enables a DAC channel.
HAL_DAC_SetValue() Writes a digital value to a DAC channel.
HAL_DAC_Stop() Disables a DAC channel.
HAL_DAC_Start_DMA() Starts DAC data transfer using DMA.
HAL_DAC_Stop_DMA() Stops DAC DMA operation.
HAL function availability and parameters depend on the STM32 HAL family and selected DAC peripheral.

9. Generating a Fixed Analog Voltage

A fixed digital code can be written to a DAC channel to generate a corresponding analog output voltage.

Example Assumptions

  • STM32 device has an internal 12-bit DAC.
  • DAC channel 1 is configured.
  • DAC output pin is configured in analog mode.
  • DAC handle is named hdac.
  • CubeMX has generated DAC initialization.

HAL Code

#include "main.h"
#include <stdint.h>

extern DAC_HandleTypeDef hdac;

void DAC_Set_Output(uint16_t value)
{
    if (value > 4095U)
    {
        value = 4095U;
    }

    if (HAL_DAC_SetValue(
            &hdac,
            DAC_CHANNEL_1,
            DAC_ALIGN_12B_R,
            value) != HAL_OK)
    {
        Error_Handler();
    }
}

int main(void)
{
    HAL_Init();
    SystemClock_Config();

    MX_GPIO_Init();
    MX_DAC_Init();

    if (HAL_DAC_Start(&hdac, DAC_CHANNEL_1) != HAL_OK)
    {
        Error_Handler();
    }

    DAC_Set_Output(2048U);

    while (1)
    {
        /* DAC maintains the configured output. */
    }
}

Expected Result

With an ideal 12-bit DAC and an effective reference of 3.3 V, digital code 2048 produces approximately 1.65 V.

The output voltage must be measured at the actual DAC output pin. The effective reference and output-buffer configuration must be verified for the selected MCU.

By updating the DAC with a sequence of digital samples, an application can generate analog waveforms.

Example: Sine Wave Sample Table

#include <stdint.h>

#define SINE_SAMPLES 16

const uint16_t sine_table[SINE_SAMPLES] =
{
    2048, 2831, 3495, 3939,
    4095, 3939, 3495, 2831,
    2048, 1264, 600, 156,
    0, 156, 600, 1264
};

The table contains one approximate sine wave cycle for a 12-bit output range. A timer trigger and DMA can transfer the samples repeatedly to the DAC.

The output waveform frequency depends on the DAC sample update rate and number of samples per cycle:
Waveform frequency = Sample update rate / Samples per cycle.

13. DAC with DMA

DMA can transfer a sequence of digital samples to the DAC data register. This is useful for waveform generation without requiring the CPU to write every sample.

Working Sequence

  1. Prepare a waveform sample buffer.
  2. Configure the DAC channel and trigger.
  3. Configure DMA for the DAC request.
  4. Set the required transfer width and mode.
  5. Start DAC DMA.
  6. Timer events trigger sample updates.
  7. DMA transfers the next sample to the DAC.
  8. Repeat using circular DMA if supported and required.

Illustrative HAL Call

if (HAL_DAC_Start_DMA(
        &hdac,
        DAC_CHANNEL_1,
        (uint32_t *)sine_table,
        SINE_SAMPLES,
        DAC_ALIGN_12B_R) != HAL_OK)
{
    Error_Handler();
}
This call alone does not configure the complete waveform system. The DAC trigger, timer, DMA request mapping, transfer mode, data alignment and buffer lifetime must also be configured. Exact options vary by STM32 family.

15. Common DAC Problems

Problem Possible Cause Solution
No output voltage DAC channel not started or wrong pin. Check channel initialization and pin mapping.
Incorrect output voltage Wrong reference or digital scaling. Verify reference and resolution.
Unstable output Noise or unsuitable loading. Check grounding, loading and filtering.
Waveform distortion Insufficient update rate or settling time. Check timer frequency and DAC specifications.
DMA waveform stops Incorrect DMA or trigger configuration. Verify DMA mode, trigger and callbacks.
Output cannot drive load Load exceeds DAC output capability. Use a suitable external buffer or amplifier.

16. Placement Interview Questions and Answers

Q1. What is DAC?

DAC converts digital input data into a corresponding analog output.

Q2. What is the difference between ADC and DAC?

ADC converts analog signals into digital values, whereas DAC converts digital values into analog signals.

Q3. What is DAC resolution?

It is the number of bits used to represent the digital input code.

Q4. How many output codes are available in a 12-bit DAC?

A 12-bit DAC has 4096 possible codes, from 0 to 4095.

Q5. Which HAL function starts a DAC channel?

HAL_DAC_Start().

Q6. Which function writes a value to the DAC?

HAL_DAC_SetValue().

Q7. What is DAC triggering?

It controls when a new digital sample is transferred to the DAC output circuitry.

Q8. Why is DMA used with DAC?

DMA transfers waveform samples to the DAC automatically, reducing CPU workload.

Q9. How can an STM32 generate a sine wave?

By repeatedly sending sine-wave sample values to the DAC using a timer trigger and optionally DMA.

Q10. What determines DAC waveform frequency?

The sample update rate and the number of samples used for each waveform cycle.

Q11. Does every STM32 contain a DAC?

No. DAC availability and capabilities depend on the selected STM32 model.

Q12. Why might a DAC output require a buffer amplifier?

The buffer provides suitable drive capability when the external load exceeds the DAC output's specified capability.
