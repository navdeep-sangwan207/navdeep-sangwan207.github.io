2. What is Multi-Channel ADC?

Multi-channel ADC allows one ADC peripheral to measure multiple analog input sources using a configured sequence of channels.

It is useful when an embedded system needs to monitor several sensors or voltage signals. 

Sensor 1 --------> ADC Channel 1
Sensor 2 --------> ADC Channel 2
Sensor 3 --------> ADC Channel 3

                  | STM32 ADC   |

Example Applications

  • Battery voltage monitoring.
  • Temperature measurement.
  • Light intensity measurement.
  • Motor current monitoring.
  • Power supply monitoring.

3. ADC Scan Conversion

In scan mode, the ADC performs conversions across a configured sequence of channels. Each channel is assigned a rank or sequence position on ADC implementations that use ranked sequences.

ADC channel numbers and GPIO pin mappings differ across STM32 models and packages. Check the selected device datasheet.

4. Multi-Channel ADC Configuration Using CubeMX

  1. Open the STM32CubeIDE project.
  2. Open the device configuration view.
  3. Select the ADC peripheral.
  4. Enable the required ADC input channels.
  5. Configure the corresponding GPIO pins in analog mode.
  6. Enable scan mode if required by the ADC generation.
  7. Set the conversion sequence and channel ranks.
  8. Configure sampling time for each channel.
  9. Choose continuous or triggered conversion as required.
  10. Generate the initialization code.
Some newer STM32 ADCs configure channel sequences differently from older STM32 devices. Follow the configuration options and HAL API for the selected MCU.

5. Potentiometer Interfacing

A potentiometer is a variable resistor commonly used as an adjustable voltage divider.

Connection

       STM32 Board

3.3V -----------+
                |
             [ POT ]
                |
                +---------- ADC Input Pin
                |
             [ POT ]
                |
GND -------------+

The potentiometer's two outer terminals connect to the supply and ground. Its wiper provides an adjustable voltage to the ADC input.

Working

  • Turning the potentiometer changes the wiper voltage.
  • The ADC samples the wiper voltage.
  • The ADC converts it into a digital code.
  • The application uses the code for control or display.
Use a potentiometer and supply compatible with the STM32 ADC input limits. Never allow the wiper voltage to exceed the permitted analog input range.

6. Sensor Interfacing Fundamentals

Sensors convert physical quantities into electrical signals. Analog-output sensors can be connected to ADC inputs when their voltage range and electrical characteristics are compatible.

7. LM35 Temperature Sensor Interfacing

LM35 is an analog temperature sensor commonly specified with a nominal scale factor of 10 mV per degree Celsius.

Basic Connection

LM35 Sensor             STM32

VCC ------------------- Suitable Supply
GND ------------------- GND
VOUT ------------------ ADC Input

Temperature Calculation

Assuming a sensor output of 10 mV per °C: 

Temperature (°C) = Sensor Voltage (V) × 100

Example

Sensor Voltage = 0.25 V

Temperature = 0.25 × 100

            = 25 °C

STM32 Calculation Function

float LM35_GetTemperature(uint16_t adc_value)
{
    float voltage;

    voltage = ((float)adc_value / 4095.0f) * 3.3f;

    return voltage * 100.0f;
}
This example assumes a 12-bit ADC, a 3.3 V effective reference and an LM35 output scale of 10 mV/°C. Verify the exact LM35 variant, supply requirements, temperature range and output loading from its datasheet.

8. LDR Light Sensor Interfacing

An LDR changes its resistance according to the light falling on it. It is commonly connected in a voltage divider to generate an analog voltage.

Basic Voltage Divider

3.3V
 |
[LDR]
 |
 +---------- ADC Input
 |
[Fixed Resistor]
 |
GND

In this example, the ADC measures the voltage at the junction. The output voltage changes as the LDR resistance changes.

  • Light intensity changes the LDR resistance.
  • The divider converts resistance variation into voltage variation.
  • The ADC converts the voltage into a digital value.
  • The application can use the value for automatic lighting.
The direction of voltage change depends on the position of the LDR and fixed resistor in the divider.

9. Reading Multiple ADC Channels Using HAL

This illustrative example uses a sequence of three channels. The ADC handle and channel sequence must be configured using CubeMX for the exact STM32 device.

Example Assumptions

  • Three ADC channels are configured in sequence.
  • ADC scan conversion is enabled.
  • Each conversion result is read in sequence.
  • ADC resolution is 12 bits.
  • ADC handle is named hadc1.
#include "main.h"
#include <stdint.h>

extern ADC_HandleTypeDef hadc1;

uint16_t adc_values[3];

HAL_StatusTypeDef Read_ADC_Channels(void)
{
    HAL_StatusTypeDef status;

    for (uint32_t i = 0; i < 3; i++)
    {
        status = HAL_ADC_Start(&hadc1);

        if (status != HAL_OK)
        {
            return status;
        }

        status = HAL_ADC_PollForConversion(&hadc1, 100);

        if (status == HAL_OK)
        {
            adc_values[i] =
                (uint16_t)HAL_ADC_GetValue(&hadc1);
        }

        HAL_ADC_Stop(&hadc1);

        if (status != HAL_OK)
        {
            return status;
        }
    }

    return HAL_OK;
}
This simple example assumes the ADC is configured so that each start operation triggers the next channel in the sequence. On other configurations, start the complete sequence once and read all results using DMA or the device-specific conversion sequence behavior. Do not assume that repeated HAL_ADC_Start calls advance a channel sequence on every STM32 family.

10. Converting Multiple ADC Results into Voltage

#include <stdint.h>

#define ADC_MAX_CODE 4095.0f
#define ADC_REFERENCE 3.3f

float ADC_To_Voltage(uint16_t adc_value)
{
    return ((float)adc_value / ADC_MAX_CODE)
           * ADC_REFERENCE;
}

float voltage_1;
float voltage_2;
float voltage_3;

void Process_ADC_Values(void)
{
    voltage_1 = ADC_To_Voltage(adc_values[0]);
    voltage_2 = ADC_To_Voltage(adc_values[1]);
    voltage_3 = ADC_To_Voltage(adc_values[2]);
}

The conversion formula must use the actual reference voltage and ADC resolution. Sensor-specific scaling may also be required.

11. Sensor Signal Conditioning

A sensor output may need signal conditioning before it can safely and accurately connect to an ADC input.

Common Signal Conditioning Circuits

  • Voltage divider.
  • Operational amplifier buffer.
  • Gain amplifier.
  • Low-pass filter.
  • Current-to-voltage converter.
  • Level shifting circuit.

Why is Signal Conditioning Required?

  • To scale the sensor output to the ADC input range.
  • To reduce high-frequency noise.
  • To provide suitable source impedance.
  • To protect the microcontroller input.
  • To amplify small sensor signals where needed.

12. Common Multi-Channel ADC Problems

Problem Possible Cause Solution
Wrong channel values Incorrect channel sequence or result order. Verify channel ranks and data ordering.
Unstable sensor readings Noise or high source impedance. Improve filtering and sampling time.
ADC always reads zero Wrong pin or missing analog connection. Check pin mapping and sensor output.
Incorrect sensor units Wrong conversion formula. Check sensor datasheet and scaling.
Channels interfere Insufficient acquisition time or source settling. Increase sampling time where appropriate.
Missing conversions Incorrect sequence, trigger or DMA configuration. Verify ADC configuration and completion handling.

13. Placement Interview Questions and Answers

Q1. What is multi-channel ADC?

It is the use of one ADC peripheral to measure multiple analog input channels.

Q2. What is ADC scan mode?

Scan mode converts a configured sequence of multiple ADC channels.

Q3. What is an ADC channel rank?

It is the position of a channel in a conversion sequence on ADCs that use ranked channel sequences.

Q4. How does a potentiometer work with ADC?

It acts as a variable voltage divider. Its wiper supplies an adjustable voltage to the ADC input.

Q5. What is an LM35 sensor?

It is an analog temperature sensor with a nominal output scale factor of 10 mV/°C.

Q6. Why is a voltage divider used with an LDR?

It converts the LDR resistance variation into a measurable voltage.

Q7. What is signal conditioning?

It is the process of modifying a sensor signal to make it suitable for measurement by the ADC.

Q8. Why is sampling time important in multi-channel ADC?

Each input must settle sufficiently before its conversion, especially when source impedances differ.

Q9. What is the purpose of ADC sequence configuration?

It determines which channels are converted and their order.

Q10. Can multiple sensors be connected to one ADC?

Yes, if the STM32 provides the required ADC channels and the inputs are configured correctly.
