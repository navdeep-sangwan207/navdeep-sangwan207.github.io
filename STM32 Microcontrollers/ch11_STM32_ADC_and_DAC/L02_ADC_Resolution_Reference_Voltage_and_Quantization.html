2. What is ADC Resolution?

ADC resolution is the number of bits used to represent the converted analog input. It determines how many distinct digital codes are available.

An N-bit ADC can represent: 

Number of Digital Codes = 2^N

Maximum Digital Code = 2^N - 1

Examples

ADC Resolution Number of Codes Digital Code Range
8-bit 256 0 to 255
10-bit 1024 0 to 1023
12-bit 4096 0 to 4095
16-bit 65536 0 to 65535
A 12-bit ADC produces 4096 possible digital codes, numbered from 0 to 4095.

3. Understanding 8-Bit and 12-Bit ADC

8-Bit ADC

An 8-bit ADC has 256 digital codes. Its binary output contains eight bits. 

00000000 = 0
00000001 = 1
00000010 = 2
...
11111111 = 255

12-Bit ADC

A 12-bit ADC has 4096 digital codes. 

000000000000 = 0
000000000001 = 1
000000000010 = 2
...
111111111111 = 4095

Higher resolution provides more available digital levels, but does not automatically guarantee better measurement accuracy.

4. What is Reference Voltage?

Reference voltage is the voltage standard used by an ADC to determine its conversion range and digital output.

For a simplified unipolar ADC, the input range is commonly considered from 0 V to the reference voltage. 

ADC Input Range

0V ---------------------- VREF
 |                         |
Minimum input          Maximum input

Example

Assume a 12-bit ADC has an effective reference voltage of 3.3 V.

  • Minimum input: approximately 0 V.
  • Maximum input: approximately 3.3 V.
  • Minimum code: 0.
  • Maximum code: 4095.
The reference voltage is not necessarily equal to the microcontroller supply voltage. STM32 reference arrangements differ by device. Check the datasheet and reference manual for VREF+, VREF-, VDDA and internal reference options.

5. ADC Resolution or Voltage Step Size

The ideal ADC voltage step size, often called one LSB, can be approximated by: 

LSB Size = VREF / 2^N

Where:

  • VREF = ADC reference voltage.
  • N = ADC resolution in bits.

Example: 12-Bit ADC with 3.3 V Reference

VREF = 3.3 V
N = 12

Number of Codes = 2^12
                = 4096

LSB Size = 3.3 / 4096
         = 0.0008057 V

         = 0.8057 mV approximately
Each ideal ADC code step corresponds to approximately 0.806 mV for this example.

6. ADC Digital Output Calculation

For an ideal unipolar N-bit ADC, a commonly used approximate conversion equation is: 

ADC Code ≈ (VIN / VREF) × (2^N - 1)

The result is quantized to an integer code. Actual transition thresholds depend on the ADC transfer characteristics and error specifications.

Example 1: 12-Bit ADC

Given:

  • Reference voltage = 3.3 V
  • Input voltage = 1.65 V
  • Resolution = 12 bits
ADC Code ≈ (1.65 / 3.3) × 4095

         ≈ 0.5 × 4095

         ≈ 2047.5

Expected code is approximately 2048.

Example 2: Input Voltage = 2.5 V

ADC Code ≈ (2.5 / 3.3) × 4095

         ≈ 3102.27

Expected code is approximately 3102.

7. Calculating Analog Voltage from ADC Reading

The approximate input voltage can be calculated from the ADC digital result. 

VIN ≈ (ADC Code / (2^N - 1)) × VREF

Example

Given:

  • ADC resolution = 12 bits
  • ADC reading = 2048
  • Reference voltage = 3.3 V
VIN ≈ (2048 / 4095) × 3.3

    ≈ 1.6504 V

Therefore, the measured input is approximately 1.65 V under the ideal calculation model.

8. What is Quantization?

Quantization is the process of mapping a continuous sampled voltage to one of a finite number of digital codes.

An ADC cannot represent every possible analog voltage exactly. It assigns the sampled input to a nearby available code. 

Analog Voltage
      |
      v
+-------------------+
| Quantization      |
|                   |
| Map input to      |
| nearest code      |
+-------------------+
      |
      v
Digital Code

Example

If the ideal voltage step is approximately 0.806 mV, an input voltage between adjacent code transition levels is represented by one of those available codes.

9. Quantization Error

Quantization error is the difference between the sampled analog value and the value represented by its digital code.

For an ideal uniform quantizer with rounding to the nearest level, the quantization error is commonly bounded approximately by: 

Maximum Quantization Error ≈ ±0.5 LSB

Example

For the previous 12-bit example: 

LSB = 0.8057 mV

Maximum ideal quantization error
≈ ±0.4029 mV
Quantization error is only one component of measurement error. Offset error, gain error, integral nonlinearity, differential nonlinearity, reference noise and external circuit noise can also affect ADC accuracy.

10. Resolution vs Accuracy vs Precision

Term Meaning
Resolution Smallest nominal digital code step.
Accuracy How close the measured value is to the true value.
Precision How closely repeated measurements agree with one another.

Example

A 12-bit ADC may have more output codes than an 8-bit ADC, but a poorly calibrated or noisy 12-bit measurement system may be less accurate than a properly designed lower-resolution system.

11. Factors Affecting ADC Accuracy

  • Reference voltage stability and accuracy.
  • ADC offset and gain errors.
  • ADC nonlinearity.
  • Input signal noise.
  • Sampling time and source impedance.
  • Power supply and ground noise.
  • PCB layout and analog signal routing.
  • Temperature variation.
  • Sensor accuracy and signal conditioning.

Practical Design Recommendations

  • Use a stable reference arrangement.
  • Provide suitable analog input filtering.
  • Choose adequate sampling time.
  • Keep analog signal paths away from noisy switching signals.
  • Follow STM32 datasheet recommendations for VDDA and VREF connections.
  • Use calibration where supported and appropriate.

12. STM32 ADC Voltage Calculation in Embedded C

The following example converts a 12-bit ADC result into an approximate input voltage. 

#include <stdint.h>

#define ADC_MAX_VALUE  4095.0f
#define ADC_VREF       3.3f

float ADC_To_Voltage(uint16_t adc_value)
{
    return ((float)adc_value / ADC_MAX_VALUE) * ADC_VREF;
}

Example Usage

uint16_t adc_value = 2048;

float voltage = ADC_To_Voltage(adc_value);

/* Expected voltage approximately 1.6504 V */
This calculation assumes a 12-bit ADC and a known 3.3 V effective reference. For a real STM32 measurement, use the actual reference voltage and account for any voltage-divider or signal-conditioning circuit.

13. Placement Interview Questions and Answers

Q1. What is ADC resolution?

It is the number of bits used to represent the ADC conversion result.

Q2. How many levels are available in a 10-bit ADC?

2^10 = 1024 levels.

Q3. What is the maximum code of a 12-bit ADC?

4095.

Q4. What is LSB?

LSB is the least significant bit. In ADC calculations, one LSB commonly refers to one nominal voltage step.

Q5. What is reference voltage?

It is the voltage reference that defines the ADC's conversion range.

Q6. What is quantization error?

It is the difference between the sampled input and its quantized digital representation.

Q7. What is the ideal maximum quantization error?

Approximately ±0.5 LSB for an ideal uniform quantizer using rounding to the nearest level.

Q8. Does higher resolution guarantee higher accuracy?

No. Accuracy also depends on reference quality, noise, linearity, offset and gain errors.

Q9. What is the digital output range of a 12-bit ADC?

0 to 4095.

Q10. How can input voltage be calculated from ADC data?

Use the ADC code divided by the maximum code, multiplied by the effective reference voltage, as an approximate ideal conversion.

15. Lesson Summary

  • ADC resolution determines the number of available digital codes.
  • An N-bit ADC provides 2^N codes.
  • Maximum code is 2^N - 1.
  • Reference voltage defines the conversion range.
  • LSB size is approximately VREF divided by 2^N.
  • ADC voltage can be estimated from the digital result.
  • Quantization maps sampled voltage to discrete codes.
  • Quantization error is only one part of total measurement error.
  • Resolution and accuracy are different specifications.
