2. What Is PLL?

PLL stands for Phase-Locked Loop. It is a clock-generation circuit used to generate a higher or different frequency from a reference clock source.

STM32 microcontrollers use PLL circuits to generate system clock frequencies suitable for processor execution and peripheral operation.

Why Is PLL Required?

  • To generate higher system clock frequencies.
  • To derive different clock frequencies from one source.
  • To provide clocks for selected peripherals.
  • To meet application performance requirements.
Example:

An STM32 device may use an 8 MHz external oscillator as a PLL reference and generate a much higher system clock frequency.

4. PLL Frequency Calculation

A common STM32 PLL architecture uses input division, multiplication and output division.

\[ f_{VCO} = \frac{f_{input}}{M}\times N \] \[ f_{PLLout} = \frac{f_{VCO}}{P} \]

Where:

  • finput: PLL reference frequency.
  • M: PLL input divider.
  • N: PLL multiplication factor.
  • P: PLL output divider.
  • fVCO: Internal VCO frequency.
  • fPLLout: PLL output frequency.

Numerical Example

Assume the following values:

  • HSE = 8 MHz
  • M = 8
  • N = 336
  • P = 2

Step 1: Calculate PLL input frequency.

\[ f_{input} = \frac{8}{8} = 1\text{ MHz} \]

Step 2: Calculate VCO frequency.

\[ f_{VCO} = 1 \times 336 = 336\text{ MHz} \]

Step 3: Calculate PLL output.

\[ f_{PLLout} = \frac{336}{2} = 168\text{ MHz} \]

The resulting PLL output is 168 MHz, provided these parameters satisfy the target device's electrical and clock limits.

5. Important PLL Parameters

Parameter Purpose
PLL Source Selects HSI or HSE where supported.
PLLM Divides the reference input frequency.
PLLN Multiplies the divided reference frequency.
PLLP Divides VCO frequency for a PLL output.
PLLQ Provides another divided output on supported devices.
PLL parameter names and available outputs differ across STM32 families. Newer devices may use fractional PLLs, multiple PLLs or different divider arrangements.

6. PLL Configuration Example – STM32F4

The following example illustrates a common STM32F4 clock configuration using an 8 MHz HSE input. 

RCC_OscInitTypeDef RCC_OscInitStruct = {0};
RCC_ClkInitTypeDef RCC_ClkInitStruct = {0};

/* Enable power control clock */
__HAL_RCC_PWR_CLK_ENABLE();

/* Configure voltage scaling as required by the device */
__HAL_PWR_VOLTAGESCALING_CONFIG(
    PWR_REGULATOR_VOLTAGE_SCALE1
);

/* Configure HSE and PLL */
RCC_OscInitStruct.OscillatorType =
    RCC_OSCILLATORTYPE_HSE;

RCC_OscInitStruct.HSEState = RCC_HSE_ON;

RCC_OscInitStruct.PLL.PLLState = RCC_PLL_ON;
RCC_OscInitStruct.PLL.PLLSource = RCC_PLLSOURCE_HSE;

RCC_OscInitStruct.PLL.PLLM = 8;
RCC_OscInitStruct.PLL.PLLN = 336;
RCC_OscInitStruct.PLL.PLLP = RCC_PLLP_DIV2;
RCC_OscInitStruct.PLL.PLLQ = 7;

if (HAL_RCC_OscConfig(&RCC_OscInitStruct) != HAL_OK)
{
    Error_Handler();
}

/* Select PLL as system clock */
RCC_ClkInitStruct.ClockType =
    RCC_CLOCKTYPE_SYSCLK |
    RCC_CLOCKTYPE_HCLK |
    RCC_CLOCKTYPE_PCLK1 |
    RCC_CLOCKTYPE_PCLK2;

RCC_ClkInitStruct.SYSCLKSource =
    RCC_SYSCLKSOURCE_PLLCLK;

RCC_ClkInitStruct.AHBCLKDivider =
    RCC_SYSCLK_DIV1;

RCC_ClkInitStruct.APB1CLKDivider =
    RCC_HCLK_DIV4;

RCC_ClkInitStruct.APB2CLKDivider =
    RCC_HCLK_DIV2;

if (HAL_RCC_ClockConfig(
        &RCC_ClkInitStruct,
        FLASH_LATENCY_5) != HAL_OK)
{
    Error_Handler();
}

Resulting Clock Frequencies

Clock Frequency
SYSCLK 168 MHz
HCLK (AHB) 168 MHz
PCLK1 (APB1) 42 MHz
PCLK2 (APB2) 84 MHz
This is an illustrative STM32F4 configuration, not a universal STM32 setup. The exact MCU must support 168 MHz operation and these PLL parameters. Flash latency, voltage scaling, APB limits and peripheral clock requirements must be verified against its datasheet and reference manual.

  4. Enable the required HSI or HSE source.
  5. Select the PLL input source.
  6. Enter valid PLL divider and multiplier values.
  7. Set the required SYSCLK frequency.
  8. Configure AHB and APB prescalers.
  9. Check all peripheral clock limits.
  10. Generate the updated initialization code.

CubeMX checks many device-specific clock constraints and displays calculated frequencies.

8. PLL Lock and Ready Status

A PLL needs time to stabilize after it is enabled. The microcontroller provides status flags to indicate when the PLL is ready for use.

Typical Sequence

  1. Enable the PLL reference oscillator.
  2. Wait until the reference source is ready.
  3. Configure valid PLL parameters.
  4. Enable the PLL.
  5. Wait for the PLL-ready status flag.
  6. Switch the system clock to the PLL output.
  7. Verify that the clock switch completed.
Never assume that enabling the PLL means it is immediately stable. Use the readiness checks and timeout/error handling provided by the device HAL or reference manual.

9. PLL Output and Peripheral Clocks

The PLL output may be selected as SYSCLK. The system clock is then distributed through bus prescalers to produce clocks for the processor and peripherals.

Some STM32 devices provide additional PLL outputs directly to peripherals such as USB, SDMMC or other clock consumers. The available outputs vary by device.

10. Common PLL Configuration Errors

Error Possible Cause
PLL does not become ready Reference oscillator is not stable or PLL parameters are invalid.
System clock switch fails PLL is not ready or clock source selection is incorrect.
Unexpected CPU frequency Incorrect multiplier, divider or source frequency.
Peripheral communication errors Incorrect peripheral clock or prescaler calculation.
System instability Clock frequency exceeds device limits or Flash latency is incorrect.
USB clock error Required USB clock frequency is not achieved.

11. Placement-Oriented Interview Questions

Q1. What is PLL?

PLL stands for Phase-Locked Loop. It is used to generate a desired clock frequency from a reference clock.

Q2. Why is PLL used in STM32?

PLL is used to generate higher or different clock frequencies for the processor and supported peripherals.

Q3. What is the function of PLLM?

PLLM divides the reference clock before it enters the multiplier stage in the illustrated STM32F4 PLL.

Q4. What is the function of PLLN?

PLLN multiplies the divided input frequency to generate the VCO frequency.

Q5. What is the function of PLLP?

PLLP divides the VCO frequency to produce a PLL output.

Q6. What is PLL lock?

PLL lock indicates that the PLL has reached its required stable operating condition.

Q7. Can HSI be used as a PLL source?

Yes, if the particular STM32 device supports HSI as a PLL reference source.

Q8. What happens if the PLL is not ready?

The system should not switch to the PLL as its clock source until the required readiness condition is satisfied.

Q9. What is VCO frequency?

VCO frequency is the internal oscillation frequency generated by the voltage-controlled oscillator.

Q10. Why is Flash latency important at high clock speeds?

Flash memory access takes a finite time. The required wait states help ensure reliable instruction and data access at higher system clock frequencies.

Q11. What happens if APB prescalers are configured incorrectly?

Peripheral timing can become incorrect, affecting UART baud rates, timers and other bus-connected peripherals.

Q12. Is the PLL configuration identical across all STM32 families?

No. PLL architecture, parameters, frequency limits and output options vary by device.
