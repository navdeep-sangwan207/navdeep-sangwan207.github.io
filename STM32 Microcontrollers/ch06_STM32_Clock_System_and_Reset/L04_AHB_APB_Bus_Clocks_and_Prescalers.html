Lesson 4: AHB, APB Bus Clocks and Prescalers

Understand STM32 bus architecture, AHB and APB clocks, prescaler calculations, peripheral clock distribution and practical clock configuration.

2. What Is a Bus in a Microcontroller?

A bus is a communication pathway used to transfer information between the processor, memory and peripheral devices.

A typical bus system carries three categories of signals:

  • Address bus: Identifies the memory or peripheral location.
  • Data bus: Transfers data.
  • Control bus: Carries control and timing signals.

Why Does STM32 Use Different Buses?

  • To connect different classes of system components.
  • To manage data transfers efficiently.
  • To support different peripheral operating speeds.
  • To distribute clock signals across the microcontroller.

3. AHB – Advanced High-Performance Bus

AHB stands for Advanced High-performance Bus. It is part of the AMBA bus architecture and is commonly used for high-performance system communication.

Typical AHB Connections

  • Processor and system interconnect.
  • SRAM and Flash interfaces.
  • DMA controllers.
  • High-performance peripheral bridges.

The exact AHB architecture and connected components vary by STM32 family.

HCLK – AHB Clock

HCLK is the clock associated with the AHB domain. It is commonly derived from SYSCLK through the AHB prescaler.

\[ HCLK = \frac{SYSCLK}{AHB\ Prescaler} \]

4. APB – Advanced Peripheral Bus

APB stands for Advanced Peripheral Bus. It is designed for connecting peripherals that do not require the full performance of the high-speed system bus.

Common APB Peripherals

  • UART and USART.
  • SPI and I2C.
  • General-purpose timers.
  • Watchdog and other control peripherals.
  • Other low- or medium-speed peripheral interfaces.

APB1 and APB2

Many STM32 devices provide separate APB domains. APB1 and APB2 can operate at different frequencies and connect to different peripherals.

Clock Meaning
PCLK1 APB1 peripheral clock.
PCLK2 APB2 peripheral clock.
\[ PCLK1 = \frac{HCLK}{APB1\ Prescaler} \] \[ PCLK2 = \frac{HCLK}{APB2\ Prescaler} \]

6. What Is a Prescaler?

A prescaler is a frequency divider used to reduce an input clock frequency before supplying it to another clock domain or peripheral.

Example

If the input frequency is 100 MHz and the prescaler divides by 2:

\[ f_{out} = \frac{100}{2} = 50\text{ MHz} \]

Common Prescaler Values

Depending on the STM32 family and clock domain, common divider choices include:

  • Divide by 1.
  • Divide by 2.
  • Divide by 4.
  • Divide by 8.
  • Divide by 16.
  • Additional division values on supported devices.
The available divider settings are device-specific. Use the clock tree and reference manual for the exact microcontroller.

7. Numerical Example – Bus Clock Calculation

Given:

  • SYSCLK = 168 MHz
  • AHB prescaler = 1
  • APB1 prescaler = 4
  • APB2 prescaler = 2

Step 1: Calculate HCLK

\[ HCLK = \frac{168}{1} = 168\text{ MHz} \]

Step 2: Calculate PCLK1

\[ PCLK1 = \frac{168}{4} = 42\text{ MHz} \]

Step 3: Calculate PCLK2

\[ PCLK2 = \frac{168}{2} = 84\text{ MHz} \]

Final Results

Clock Frequency
SYSCLK 168 MHz
HCLK 168 MHz
PCLK1 42 MHz
PCLK2 84 MHz

8. APB Timer Clock Calculation

On many STM32 devices, timer clocks are derived from APB clocks using a special timer-clock rule.

On a common STM32F4 clock arrangement:

  • If the APB prescaler is 1, the timer clock equals PCLK.
  • If the APB prescaler is greater than 1, the timer clock is commonly 2 × PCLK.

Example

Assume:

  • HCLK = 168 MHz
  • APB1 prescaler = 4
  • PCLK1 = 42 MHz

For a timer on APB1 using the common STM32F4 rule:

\[ TIMCLK1 = 2 \times PCLK1 \] \[ TIMCLK1 = 2 \times 42 = 84\text{ MHz} \]
This timer-clock multiplication rule is not universal. Some STM32 devices provide additional timer clock selection or kernel-clock options. Always verify the selected timer's clock source in the reference manual.

9. Peripheral Clock Enable

A peripheral generally needs its clock enabled before software can use it.

For example, on STM32F4, GPIOA is connected to the AHB1 peripheral clock domain. 

/* Enable GPIOA peripheral clock */
__HAL_RCC_GPIOA_CLK_ENABLE();

/* Configure GPIOA pins after enabling its clock */

A peripheral's bus clock and its functional or kernel clock are not always the same thing. Some peripherals have independent clock-source selections.

10. Configure AHB and APB Prescalers in STM32CubeMX

  1. Open the STM32 project in STM32CubeIDE.
  2. Open the project's .ioc file.
  3. Select the Clock Configuration tab.
  4. Configure the system clock source.
  5. Set the AHB prescaler.
  6. Set the APB1 prescaler.
  7. Set the APB2 prescaler.
  8. Inspect HCLK, PCLK1 and PCLK2 values.
  9. Check peripheral clock limits.
  10. Generate the initialization code.

CubeMX displays the resulting clock frequencies and warns about many invalid configurations.

11. Common Bus Clock Problems

Problem Possible Cause
UART baud rate is incorrect Incorrect peripheral clock frequency.
Timer frequency is incorrect Incorrect timer clock or prescaler calculation.
Peripheral does not respond Peripheral clock gate is disabled.
System clock exceeds limits AHB prescaler or PLL configuration is incorrect.
APB peripheral malfunction APB frequency exceeds the device's specified limit.
Unexpected peripheral timing Peripheral uses a separate kernel clock source.

12. Placement-Oriented Interview Questions

Q1. What is AHB?

AHB stands for Advanced High-performance Bus. It connects high-performance system components.

Q2. What is APB?

APB stands for Advanced Peripheral Bus. It connects many lower-speed peripheral devices.

Q3. What is HCLK?

HCLK is the AHB clock derived from SYSCLK through the AHB prescaler.

Q4. What is PCLK1?

PCLK1 is the clock supplied to the APB1 domain.

Q5. What is PCLK2?

PCLK2 is the clock supplied to the APB2 domain.

Q6. What is a prescaler?

A prescaler divides an input clock frequency to produce a lower frequency.

Q7. Why are APB1 and APB2 separated?

They allow peripherals to operate in separate clock domains with different frequency limits.

Q8. What happens when the APB prescaler is changed?

The corresponding APB clock frequency changes, which can affect peripheral timing.

Q9. What is the relationship between SYSCLK and HCLK?

HCLK is obtained by dividing SYSCLK by the AHB prescaler.

Q10. Why can a timer clock be twice the APB clock?

Some STM32 clock architectures provide timer clock multiplication when the APB prescaler is greater than one.

Q11. Why must peripheral clocks be enabled?

Clock gating controls peripheral clock delivery. A peripheral may not operate correctly until its required clock is enabled.

Q12. Is the AHB/APB structure identical in every STM32?

No. Bus structure, clock domains and peripheral assignments vary across STM32 families.

  6. Enable a GPIO peripheral clock using HAL.

  8. Calculate the expected UART peripheral clock.
  9. Investigate an incorrect timer frequency.
  10. Compare bus clock architecture across two STM32 families.

14. Lesson Summary

  • AHB is commonly used for high-performance system communication.
  • APB connects many peripheral devices.
  • HCLK is derived from SYSCLK using the AHB prescaler.
  • PCLK1 and PCLK2 are APB peripheral clocks.
  • Prescalers divide clock frequencies.
  • Timer clocks may differ from APB clocks.
  • Peripheral clock gating must be configured.
  • Clock limits depend on the exact STM32 device.
