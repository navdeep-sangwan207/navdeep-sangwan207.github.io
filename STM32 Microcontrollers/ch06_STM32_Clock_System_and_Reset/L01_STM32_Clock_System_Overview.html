2. What Is a Clock Signal?

A clock signal is a periodic electrical signal used to synchronize operations inside a digital system.

A microcontroller uses clock signals to coordinate processor operations, memory access, peripheral activity and communication interfaces.

Important Clock Parameters

Parameter Meaning
Frequency Number of clock cycles per second.
Period Time required for one complete clock cycle.
Duty Cycle Percentage of a period for which the signal is HIGH.
Clock Source Oscillator or external source that generates a clock.

Frequency and Time Period

The relationship is:

\[ T = \frac{1}{f} \]

Where:

  • T = Clock period in seconds.
  • f = Clock frequency in hertz.
Example:

If the clock frequency is 16 MHz:

\[ T = \frac{1}{16 \times 10^6} \] \[ T = 62.5 \text{ ns} \]

One clock cycle takes 62.5 nanoseconds.

3. Why Does STM32 Need a Clock?

The clock provides the timing reference required for synchronous digital operations.

Major Uses

  • CPU: Executes processor instructions.
  • Memory: Coordinates memory operations.
  • Timers: Measures time and generates periodic events.
  • UART: Generates timing for serial communication.
  • SPI: Provides serial communication clock.
  • I2C: Provides timing for serial bus communication.
  • ADC: Controls conversion timing.
  • USB: Requires clock accuracy appropriate to its specification.

4. STM32 Clock System Architecture

STM32 microcontrollers contain a clock control system that selects, configures and distributes clock signals to the processor and peripherals.

A typical STM32 clock architecture contains:

  • Internal oscillators.
  • External oscillators or clock inputs.
  • Phase-Locked Loop (PLL).
  • System clock selection circuit.
  • AHB and APB prescalers.
  • Peripheral clock enable controls.

5. Main STM32 Clock Sources

STM32 devices provide different internal and external clock sources.

Clock Source Description
HSI High-Speed Internal oscillator.
HSE High-Speed External clock source.
LSI Low-Speed Internal oscillator.
LSE Low-Speed External oscillator.
PLL Generates derived clock frequencies from an input clock.

These sources are discussed in detail in the next lesson.

6. SYSCLK – System Clock

SYSCLK is the main system clock selected from the available clock sources or a PLL output.

It is commonly used as the input to the AHB prescaler, which generates HCLK.

Possible SYSCLK Sources

  • HSI oscillator.
  • HSE oscillator or external clock.
  • PLL output.
Example:

Suppose an STM32 device selects a PLL output of 84 MHz as its system clock.

Therefore:

\[ SYSCLK = 84 \text{ MHz} \]

The actual processor and bus clock frequencies depend on the configured prescalers.

7. HCLK – AHB Clock

HCLK is generated from SYSCLK through the AHB prescaler. It is used by the processor and various AHB-connected components, depending on the MCU architecture.

Formula

\[ HCLK = \frac{SYSCLK}{AHB\ Prescaler} \]
Example:

Given:

  • SYSCLK = 84 MHz
  • AHB prescaler = 1
\[ HCLK = \frac{84}{1} = 84 \text{ MHz} \]

Therefore, HCLK is 84 MHz.

8. PCLK – Peripheral Clock

PCLK is a peripheral bus clock. Many STM32 devices provide APB1 and APB2 clock domains.

  • PCLK1: Clock for APB1-connected peripherals.
  • PCLK2: Clock for APB2-connected peripherals.

Clock Calculation

\[ PCLK1 = \frac{HCLK}{APB1\ Prescaler} \] \[ PCLK2 = \frac{HCLK}{APB2\ Prescaler} \]
Example:

Given:

  • HCLK = 84 MHz
  • APB1 prescaler = 2
  • APB2 prescaler = 1
\[ PCLK1 = \frac{84}{2} = 42 \text{ MHz} \] \[ PCLK2 = \frac{84}{1} = 84 \text{ MHz} \]

Therefore, PCLK1 is 42 MHz and PCLK2 is 84 MHz.

Peripheral assignments to APB1 and APB2 vary by STM32 family. Always check the selected MCU's clock tree.

10. Why Clock Configuration Is Important

Incorrect clock configuration can affect almost every timing-dependent peripheral in an embedded application.

Common Effects

  • Incorrect UART baud rate.
  • Incorrect timer period.
  • Incorrect PWM frequency.
  • Incorrect ADC clock configuration.
  • Communication failures.
  • Unexpected system performance.
  • Clock-related startup failures.
Example – UART:

If the UART peripheral clock is configured incorrectly, the actual baud rate may differ from the requested baud rate.

This can cause corrupted or unreadable serial data.

11. Clock Configuration in STM32CubeIDE

STM32CubeMX integrated into STM32CubeIDE provides a graphical interface for configuring the clock tree.

Basic Procedure

  1. Create or open an STM32 project.
  2. Open the device configuration file.
  3. Select the Clock Configuration tab.
  4. Choose the required oscillator source.
  5. Configure PLL settings if required.
  6. Set system clock frequency.
  7. Configure AHB and APB prescalers.
  8. Check peripheral clock frequencies and device limits.
  9. Generate the initialization code.

12. Clock Tree Troubleshooting

Problem Possible Cause
System does not start correctly Clock source failure or incorrect initialization.
UART communication errors Incorrect peripheral clock or baud rate calculation.
Incorrect timer interval Wrong timer input clock or prescaler assumptions.
PLL does not lock Invalid PLL configuration or unavailable source clock.
Peripheral does not operate Peripheral clock not enabled or wrong clock source selected.

13. Placement-Oriented Interview Questions

Q1. What is a clock signal?

A periodic signal used to synchronize operations in a digital system.

Q2. Why does an STM32 require a clock?

It provides timing for CPU execution, memory operations and peripheral functions.

Q3. What is SYSCLK?

SYSCLK is the main system clock selected from an available clock source or PLL output.

Q4. What is HCLK?

HCLK is the AHB clock generated from SYSCLK through the AHB prescaler.

Q5. What is PCLK?

PCLK is a peripheral bus clock, commonly divided into PCLK1 and PCLK2 on many STM32 devices.

Q6. What is the purpose of PLL?

PLL generates a derived clock frequency from an input clock source using configurable multiplication and division factors.

Q7. What is the difference between HSI and HSE?

HSI is an internal high-speed oscillator, while HSE uses an external clock source or crystal arrangement.

Q8. What is a clock prescaler?

A circuit or configuration that divides an input clock frequency to generate a lower frequency.

Q9. What happens if the UART clock is incorrect?

The configured baud rate may be incorrect, causing serial communication errors.

Q10. What is a clock tree?

It is the arrangement of clock sources, selection circuits, PLLs, prescalers and clock distribution paths in a microcontroller.

Q11. Does every STM32 have the same clock tree?

No. Clock sources, domains, bus structures and maximum frequencies vary across STM32 families and devices.
