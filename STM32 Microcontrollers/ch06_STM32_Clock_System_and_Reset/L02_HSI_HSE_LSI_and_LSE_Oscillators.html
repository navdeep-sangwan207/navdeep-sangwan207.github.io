2. What Is an Oscillator?

An oscillator is an electronic circuit that generates a periodic electrical signal without requiring a continuously changing external input signal.

Microcontrollers use oscillators to generate timing signals required for processor execution and peripheral operation.

Common Oscillator Types

  • RC oscillator.
  • Crystal oscillator.
  • Ceramic resonator.
  • External clock generator.

Important Characteristics

Characteristic Meaning
Frequency Number of oscillations per second.
Accuracy How closely the actual frequency matches the nominal value.
Stability How well frequency remains constant over time and conditions.
Startup Time Time required for the oscillator to become stable.
Power Consumption Electrical power required for oscillator operation.

3. STM32 Clock Source Classification

STM32 microcontrollers commonly provide four named oscillator sources.

Clock Full Form Type Typical Application
HSI High-Speed Internal Internal System clock and PLL input on supported devices.
HSE High-Speed External External Accurate system clock and PLL input.
LSI Low-Speed Internal Internal Independent watchdog and low-speed functions.
LSE Low-Speed External External Real-time clock and accurate low-speed timing.
Available sources, frequencies, accuracy and peripheral connections differ across STM32 families and devices.

4. HSI – High-Speed Internal Oscillator

HSI is an internal high-speed oscillator integrated into the STM32 microcontroller.

It generally uses an internal RC oscillator circuit and does not require an external crystal.

Characteristics

  • Built inside the microcontroller.
  • Does not require an external crystal.
  • Usually available after reset on supported devices.
  • Convenient for simple applications.
  • Frequency accuracy is generally lower than a suitable external crystal.
  • Can be used as a PLL input on supported STM32 devices.

Applications

  • Basic microcontroller operation.
  • Simple embedded applications.
  • Low-cost systems without external clock components.
  • Fallback clock operation on supported devices.
Example:

Some STM32F4 devices provide a nominal 16 MHz HSI oscillator. The actual HSI frequency and tolerance must be checked in the device datasheet.

5. HSE – High-Speed External Oscillator

HSE is an external high-speed clock source used when a more accurate or externally synchronized clock is required.

Depending on the STM32 device, HSE can operate using an external crystal/resonator or an external clock signal.

Two Common HSE Configurations

A. Crystal or Resonator Mode

A crystal is connected to the dedicated oscillator pins of the STM32. The internal oscillator amplifier and external crystal form the oscillator circuit. 


       STM32 Microcontroller

          OSC_IN o----+----[ Crystal ]----+----o OSC_OUT
                      |                  |
                     C1                 C2
                      |                  |
                     GND                GND

The capacitors shown are conceptual. Their values and connection requirements depend on the crystal, oscillator circuit and STM32 datasheet.

B. External Clock Mode

An external clock generator supplies a clock signal to the designated HSE input pin. 


      External Clock Generator
                 |
                 |
                 v
          STM32 OSC_IN

Characteristics of HSE

  • Uses an external clock source or crystal arrangement.
  • Can provide better frequency accuracy than internal RC sources.
  • Useful for timing-sensitive applications.
  • Can serve as a PLL input where supported.
  • Requires suitable hardware design and configuration.

Applications

  • Accurate system clock generation.
  • Communication interfaces requiring precise timing.
  • Applications using PLL-derived high-speed clocks.
  • Systems requiring synchronization with an external reference.

6. LSI – Low-Speed Internal Oscillator

LSI is an internal low-speed oscillator, generally implemented using an RC oscillator circuit.

Characteristics

  • Built inside the microcontroller.
  • Does not require an external crystal.
  • Designed for low-speed timing functions.
  • Generally has lower accuracy than LSE.
  • Can operate independently of the main system clock on supported devices.

Applications

  • Independent Watchdog (IWDG).
  • Low-speed timing functions.
  • Selected low-power and peripheral functions.
Example:

Some STM32 devices provide an LSI frequency around 32 kHz. Its actual frequency and tolerance vary by device and operating conditions.

7. LSE – Low-Speed External Oscillator

LSE is a low-speed external oscillator designed primarily for accurate low-frequency timing.

It commonly uses a 32.768 kHz watch crystal connected to dedicated oscillator pins.

Why 32.768 kHz?

The frequency 32,768 Hz is a power of two:

\[ 32768 = 2^{15} \]

Dividing this frequency by 2 fifteen times produces one pulse per second.

\[ \frac{32768}{32768} = 1 \text{ Hz} \]

Characteristics

  • Uses an external low-frequency crystal or supported clock source.
  • Commonly operates at 32.768 kHz.
  • Provides accurate low-speed timing.
  • Useful for real-time clock applications.
  • Can support timekeeping during low-power operation on suitable devices.

Applications

  • Real-Time Clock (RTC).
  • Calendar and date functions.
  • Timekeeping during low-power modes.
  • Low-frequency timing reference.

10. Oscillator Frequency Accuracy

Oscillator accuracy indicates how closely the generated frequency matches its nominal value.

Accuracy is commonly specified in parts per million (ppm).

Frequency Error Calculation

\[ \text{Error (ppm)} = \frac{f_{actual}-f_{nominal}}{f_{nominal}} \times 10^6 \]
Example:

Suppose the nominal oscillator frequency is 8 MHz and the measured frequency is 8.0008 MHz.

\[ Error = \frac{8.0008-8}{8}\times 10^6 \] \[ Error = 100 \text{ ppm} \]

The oscillator has a positive frequency error of 100 ppm.

11. Selecting the Correct Clock Source

Application Possible Clock Source
Simple embedded control HSI
High-speed system clock HSE or HSI through PLL, if supported
Independent watchdog LSI on supported devices
RTC timekeeping LSE, where available and appropriate
External synchronization Suitable external clock input

The correct source depends on required accuracy, power consumption, hardware cost, operating frequency and peripheral requirements.

12. Oscillator Configuration Using STM32 HAL

STM32 HAL provides RCC configuration structures for enabling and selecting oscillator sources.

Example: Enable HSE and Configure PLL

RCC_OscInitTypeDef RCC_OscInitStruct = {0};

RCC_OscInitStruct.OscillatorType = RCC_OSCILLATORTYPE_HSE;
RCC_OscInitStruct.HSEState = RCC_HSE_ON;

/*
   PLL settings are device-specific.
   Configure PLL source and multiplication/division
   factors according to the selected MCU.
*/

RCC_OscInitStruct.PLL.PLLState = RCC_PLL_ON;
RCC_OscInitStruct.PLL.PLLSource = RCC_PLLSOURCE_HSE;

/* Example factors only: verify against the selected MCU */
RCC_OscInitStruct.PLL.PLLM = 8;
RCC_OscInitStruct.PLL.PLLN = 336;
RCC_OscInitStruct.PLL.PLLP = RCC_PLLP_DIV2;
RCC_OscInitStruct.PLL.PLLQ = 7;

if (HAL_RCC_OscConfig(&RCC_OscInitStruct) != HAL_OK)
{
    Error_Handler();
}
This PLL configuration illustrates a common STM32F4 pattern and is not universal. PLL parameter ranges, input limits, VCO limits and required voltage scaling must be checked for the exact STM32 part number.

Example: Enable LSE

RCC_OscInitTypeDef RCC_OscInitStruct = {0};

RCC_OscInitStruct.OscillatorType = RCC_OSCILLATORTYPE_LSE;
RCC_OscInitStruct.LSEState = RCC_LSE_ON;

if (HAL_RCC_OscConfig(&RCC_OscInitStruct) != HAL_OK)
{
    Error_Handler();
}

The backup-domain access requirements and oscillator configuration procedure must be followed for the selected STM32 family.

13. Common Oscillator Problems

Problem Possible Cause
HSE does not start Incorrect crystal, load capacitors or oscillator configuration.
PLL configuration fails Invalid PLL factors or unavailable input clock.
RTC loses accuracy Incorrect LSE configuration or unsuitable clock source.
Unexpected timing errors Oscillator tolerance or incorrect clock configuration.
System does not switch to HSE HSE readiness or clock-switching failure.
External clock not detected Incorrect pin, electrical level or clock mode.

14. Placement-Oriented Interview Questions

Q1. What is HSI?

HSI is the High-Speed Internal oscillator integrated into an STM32 microcontroller.

Q2. What is HSE?

HSE is the High-Speed External clock source, which can use an external crystal or clock signal.

Q3. What is LSI?

LSI is the Low-Speed Internal oscillator, commonly used for watchdog and low-speed timing functions.

Q4. What is LSE?

LSE is the Low-Speed External oscillator, commonly used for RTC applications.

Q5. Why is a 32.768 kHz crystal used for RTC?

Because it is 215, allowing a binary divider to generate a 1 Hz time base.

Q6. Which is generally more accurate: HSI or HSE?

A suitable external crystal or clock source is generally more accurate than the internal RC oscillator.

Q7. What is the difference between HSE crystal mode and external clock mode?

Crystal mode uses a crystal with the MCU oscillator circuit. External clock mode receives an already generated clock signal from another source.

Q8. What is oscillator startup time?

It is the time required for an oscillator to begin operating and reach its required stable condition.

Q9. What does ppm mean?

PPM means parts per million and is used to express frequency error or accuracy.

Q10. Can HSI be used as a PLL input?

Yes, on STM32 devices whose clock architecture supports HSI as a PLL input.

Q11. Why is LSE preferred for RTC applications?

A suitable 32.768 kHz LSE crystal provides a stable low-frequency reference for timekeeping.

Q12. Are oscillator frequencies identical across STM32 devices?

No. Frequency values and tolerances vary by STM32 family and individual device.
