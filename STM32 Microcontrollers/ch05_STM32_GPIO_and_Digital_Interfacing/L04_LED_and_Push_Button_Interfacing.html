2. LED Interfacing Fundamentals

An LED (Light Emitting Diode) is a semiconductor device that emits light when forward biased.

LED Terminals

  • Anode: Positive terminal.
  • Cathode: Negative terminal.

An LED must be connected with suitable polarity and current limiting.

Basic LED Circuit

STM32 GPIO Output
       |
   [Resistor]
       |
      LED
       |
      GND

When the GPIO output is HIGH, current can flow through the resistor and LED to ground, provided the circuit is connected with the correct polarity.

3. LED Current-Limiting Resistor

A resistor limits the current flowing through the LED. Without suitable current limiting, the LED or GPIO pin may be damaged.

Resistor Calculation

The approximate resistor value is calculated using: 

R = (VGPIO - VF) / ILED

Where:

  • VGPIO = GPIO output voltage.
  • VF = LED forward voltage.
  • ILED = Desired LED current.

Example Calculation

Assume:

  • GPIO voltage = 3.3 V
  • LED forward voltage = 2.0 V
  • LED current = 5 mA
R = (3.3 - 2.0) / 0.005

R = 1.3 / 0.005

R = 260 ohms

A nearby standard value such as 270 Ω may be considered, after checking the LED and GPIO electrical specifications.

This is an illustrative calculation. Account for GPIO output voltage drop, LED characteristics, resistor tolerance and the MCU's pin-current limits when designing a real circuit.

4. LED Interfacing Using STM32 GPIO

Configure a GPIO pin as an output and use HAL functions to control the LED.

LED ON

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

LED OFF

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

LED Toggle

HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);

These examples assume PA5 is configured as an output and the external LED circuit is connected appropriately.

5. Complete Program: LED Blinking

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

        HAL_Delay(500);

        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

        HAL_Delay(500);
    }
}

Expected Result

  • LED turns ON for approximately 500 ms.
  • LED turns OFF for approximately 500 ms.
  • The sequence repeats continuously.

7. Button Input Configuration Using HAL

Example: Input with Internal Pull-Up

void Button_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOC_CLK_ENABLE();

    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLUP;

    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
}

The input reads HIGH when released and LOW when pressed if the button connects the pin to ground.

8. Complete Program: Push Button Controls LED

The following program turns an LED ON while a button is pressed. The button uses an internal pull-up. 

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
        {
            /* Button pressed */
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
        }
        else
        {
            /* Button released */
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
        }
    }
}

Expected Result

  • Press button: LED turns ON.
  • Release button: LED turns OFF.
Verify the actual pin assignments and LED polarity for your development board. This example assumes the button connects PC13 to ground when pressed.

9. Button Debouncing

Mechanical switches do not always change state cleanly. When pressed or released, their contacts may rapidly connect and disconnect for a short time.

This behavior is known as switch bounce.

Conceptual Button Bounce

Ideal Signal:

HIGH  __________
               |
               |________ LOW


Bouncing Signal:

HIGH  __________
               |-|_|-|__
               |
               |________ LOW

The processor may detect several transitions from a single physical button press.

Debouncing Methods

  • Software delay-based debouncing.
  • Timer-based debouncing.
  • Hardware RC filtering.
  • Dedicated switch-debouncing circuits.

10. Software Debouncing Example

This example uses a simple delay after detecting a pressed button and verifies the input again. 

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
        {
            HAL_Delay(20);

            if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
            {
                HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

                /* Wait for button release */
                while (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
                {
                }

                HAL_Delay(20);

                HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
            }
        }
    }
}
This simple example blocks the main loop while waiting for button release. For responsive applications with multiple tasks, use timer-based or state-machine-based debouncing instead.

11. Complete Project: Button Toggles LED State

In this application, each valid button press changes the LED state. The LED remains in its new state after the button is released. 

#include "main.h"

int main(void)
{
    GPIO_PinState led_state = GPIO_PIN_RESET;

    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
        {
            HAL_Delay(20);

            if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
            {
                led_state = (led_state == GPIO_PIN_SET)
                            ? GPIO_PIN_RESET
                            : GPIO_PIN_SET;

                HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, led_state);

                while (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
                {
                }

                HAL_Delay(20);
            }
        }
    }
}

Expected Result

  • First valid press: LED turns ON.
  • Second valid press: LED turns OFF.
  • Each subsequent press changes the LED state.

14. Placement-Oriented Interview Questions

Q1. What is an LED?

An LED is a semiconductor diode that emits light when forward biased.

Q2. Why is a resistor connected in series with an LED?

It limits current and protects the LED and GPIO output.

Q3. What is LED forward voltage?

It is the voltage drop across the LED under a specified forward-current condition.

Q4. What is switch bouncing?

It is the rapid making and breaking of mechanical contacts during switching.

Q5. Why is debouncing required?

It prevents one physical button operation from being interpreted as multiple input events.

Q6. What is software debouncing?

It uses program logic, timing or repeated sampling to reject unwanted transitions caused by switch bounce.

Q7. What is the difference between active-HIGH and active-LOW buttons?

An active-HIGH button produces an asserted HIGH state. An active-LOW button produces an asserted LOW state.

Q8. Which HAL function reads a push button?

HAL_GPIO_ReadPin().

Q9. Which HAL function changes the LED output state?

HAL_GPIO_TogglePin().

Q10. Why should an LED not be connected directly without current limiting?

Excessive current can damage the LED or exceed the GPIO output's electrical limits.
