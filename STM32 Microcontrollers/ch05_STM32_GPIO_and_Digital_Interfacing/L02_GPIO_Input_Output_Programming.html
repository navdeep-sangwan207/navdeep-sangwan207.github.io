Lesson 2: GPIO Input/Output Programming

Learn how to configure STM32 GPIO pins, read digital inputs, control digital outputs and write practical HAL programs.

2. Digital Input and Output Fundamentals

A digital signal has two logical states: LOW and HIGH. STM32 GPIO pins can read these states from external devices or generate them to control external circuits.

Logic State Meaning
LOW Logic 0
HIGH Logic 1

The actual voltage ranges representing LOW and HIGH depend on the MCU's electrical specifications and supply voltage.

Input Operation

The processor reads the voltage level present on a configured GPIO input pin.

Output Operation

The processor writes a logic state to a configured GPIO output pin.

3. GPIO Programming Using STM32 HAL

The STM32 Hardware Abstraction Layer provides functions for configuring and controlling GPIO pins.

HAL Function Purpose
HAL_GPIO_Init() Initializes GPIO pin configuration.
HAL_GPIO_ReadPin() Reads the state of a GPIO input pin.
HAL_GPIO_WritePin() Sets or resets a GPIO output pin.
HAL_GPIO_TogglePin() Toggles the output state of a GPIO pin.

4. GPIO Output Programming

To control an external digital device, configure the GPIO pin as an output and write the required logic state.

Set Output HIGH

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

Set Output LOW

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

Toggle Output

HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);

These examples assume PA5 has already been configured as a GPIO output and its clock has been enabled.

5. Complete Program: LED Blinking Using GPIO

This program toggles an LED connected to PA5 every 500 ms. It assumes the selected board has a compatible LED circuit connected to PA5.

Program

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);

        HAL_Delay(500);
    }
}

GPIO Initialization

void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOA_CLK_ENABLE();

    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

    GPIO_InitStruct.Pin = GPIO_PIN_5;
    GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;

    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
}

Expected Result

  • LED turns ON.
  • After approximately 500 ms, LED changes state.
  • LED continues blinking repeatedly.
The LED's ON/OFF polarity depends on the board circuit. Some boards use active-low LEDs. Also verify the actual LED pin from the board schematic.

6. GPIO Input Programming

A GPIO input pin is used to read the state of external digital devices such as push buttons and digital sensors.

Reading an Input Pin

GPIO_PinState input_state;

input_state = HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13);

if (input_state == GPIO_PIN_SET)
{
    /* Input HIGH */
}
else
{
    /* Input LOW */
}

HAL_GPIO_ReadPin() returns either GPIO_PIN_SET or GPIO_PIN_RESET.

7. Complete Program: Push Button Controls LED

In this example, a push button connected to PC13 controls an LED connected to PA5.

Program

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_SET)
        {
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
        }
        else
        {
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
        }
    }
}

Expected Result

  • When the input reads HIGH, the LED output is set HIGH.
  • When the input reads LOW, the LED output is set LOW.
The example assumes the button circuit produces HIGH when pressed and LOW when released. If the button is wired with a pull-up and switches to ground, the logic will normally be reversed. Configure the input and pull resistor accordingly.

8. GPIO Input and Output Initialization Together

A single application can use one GPIO pin as an input and another as an output.

Example: Configure PC13 as Input and PA5 as Output

void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    /* Enable GPIO clocks */
    __HAL_RCC_GPIOA_CLK_ENABLE();
    __HAL_RCC_GPIOC_CLK_ENABLE();

    /* Initialize LED output */
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

    GPIO_InitStruct.Pin = GPIO_PIN_5;
    GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;

    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

    /* Initialize button input */
    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLDOWN;

    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
}

The pull-down configuration is appropriate only when it matches the external button wiring and the selected MCU's electrical requirements.

9. Polling-Based GPIO Programming

Polling means repeatedly checking the state of an input inside the main program loop. 

while (1)
{
    if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_SET)
    {
        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
    }
    else
    {
        HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
    }
}

Advantages

  • Simple to understand and implement.
  • Suitable for basic input monitoring.
  • Does not require interrupt configuration.

Limitations

  • CPU repeatedly checks the input.
  • Other tasks can be delayed by long polling loops.
  • Short input events may be missed if checking is not frequent enough.

10. HAL vs Direct Register Programming

HAL Programming Register-Level Programming
Uses library functions. Accesses peripheral registers directly.
Generally easier to read and maintain. Provides direct control over hardware registers.
Includes abstraction overhead. Can be more compact for simple operations.
Useful for rapid application development. Useful for low-level learning and specialized optimization.

Example: HAL Output

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);

Example: STM32F4 Register-Level Output

/* Set PA5 */
GPIOA->BSRR = (1U << 5);

/* Reset PA5 */
GPIOA->BSRR = (1U << (5 + 16));
The BSRR example uses the STM32F4 GPIO register layout. Confirm the reference manual and CMSIS device header for the exact STM32 family being used.

11. GPIO Programming Troubleshooting

Problem Possible Cause Solution
LED does not turn ON Incorrect pin or mode Verify pinout and initialization.
Input always reads HIGH Pull-up or wiring issue Check input circuit and pull configuration.
Input always reads LOW Incorrect connection Check supply, ground and button wiring.
GPIO does not respond Clock not enabled Enable the relevant GPIO peripheral clock.
LED logic appears reversed Active-low LED circuit Reverse the output logic as required.
Button produces multiple transitions Mechanical contact bounce Use suitable debouncing.

12. Placement-Oriented Interview Questions

Q1. Which HAL function is used to read a GPIO pin?

HAL_GPIO_ReadPin().

Q2. Which HAL function writes a GPIO output?

HAL_GPIO_WritePin().

Q3. Which function toggles a GPIO output?

HAL_GPIO_TogglePin().

Q4. What is polling?

Polling is repeatedly checking a hardware status or input condition in program execution.

Q5. What is the difference between SET and RESET?

SET writes a logic-high output state, while RESET writes a logic-low output state, subject to the pin configuration.

Q6. Why is GPIO initialization required?

It configures the pin's mode, pull resistor, output type and speed before the application uses it.

Q7. What does HAL_GPIO_TogglePin() do?

It changes the output state from its current state to the opposite state.

Q8. What is the difference between GPIO input and output?

Input reads an external digital signal, whereas output generates a digital signal for an external circuit.

Q9. What is the limitation of polling?

The CPU must repeatedly check the input, which can waste processing time and delay other work.

Q10. Why must GPIO clocks be enabled?

The peripheral clock supplies the GPIO hardware block with the clock required for its operation.
