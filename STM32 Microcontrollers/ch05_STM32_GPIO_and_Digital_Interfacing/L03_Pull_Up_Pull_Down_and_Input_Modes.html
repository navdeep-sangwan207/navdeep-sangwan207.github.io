Lesson 3: Pull-Up, Pull-Down and Input Modes

2. Why Do GPIO Inputs Need Pull Resistors?

A digital input pin should have a clearly defined logic voltage. If the input is disconnected or not driven by an external circuit, its voltage may become unpredictable.

This condition is known as a floating input.

Floating Input Characteristics

  • The input voltage is not reliably HIGH or LOW.
  • Electrical noise can affect the input state.
  • The processor may read changing or unpredictable values.
  • Connected applications may behave incorrectly.
A floating input is not necessarily a stable logic LOW. Its state must be defined using an appropriate circuit.

3. Pull-Up Resistor

A pull-up resistor connects a digital input weakly to the positive supply voltage. It establishes a default HIGH state when no external device pulls the line LOW.

Conceptual Circuit

       VDD
        |
     [Pull-up]
        |
        +---------- GPIO Input
        |
      [Switch]
        |
       GND

Operation

Switch Condition GPIO State
Released / Open HIGH
Pressed / Closed LOW

When the switch is open, the pull-up resistor holds the input HIGH. When the switch closes, the input is connected to ground and reads LOW.

4. Pull-Down Resistor

A pull-down resistor connects a digital input weakly to ground. It establishes a default LOW state when no external device drives the input HIGH.

Conceptual Circuit

       VDD
        |
      [Switch]
        |
        +---------- GPIO Input
        |
    [Pull-down]
        |
       GND

Operation

Switch Condition GPIO State
Released / Open LOW
Pressed / Closed HIGH

5. Pull-Up vs Pull-Down

Feature Pull-Up Pull-Down
Connection Input to VDD through resistor Input to GND through resistor
Default State HIGH LOW
Switch to Ground VDD
Pressed State LOW HIGH
Practical example: A button wired between an input pin and ground can use a pull-up resistor. The released state reads HIGH, and the pressed state reads LOW.

6. Internal and External Pull Resistors

Internal Pull Resistor

Many STM32 GPIO pins provide configurable internal pull-up and pull-down resistors.

  • Configured through GPIO settings.
  • Does not normally require an external resistor.
  • Useful for simple buttons and digital inputs.
  • Resistance value and availability are device-specific.

External Pull Resistor

An external resistor is physically connected between the input line and VDD or ground.

  • Allows the designer to select a suitable resistance.
  • Can provide stronger biasing than an internal pull resistor.
  • Useful for shared buses and noise-sensitive circuits.
  • Must be selected according to circuit requirements.
Do not assume every STM32 pin supports every pull configuration. Check the device reference manual and datasheet.

7. GPIO Input Modes

GPIO input configuration determines how an external signal is interpreted by the microcontroller.

Configuration Description
Input with no pull External circuit must define the logic level.
Input with pull-up Default input state is HIGH.
Input with pull-down Default input state is LOW.
Analog mode Used for supported analog functions; digital input behavior is typically disabled.

8. Configure Pull-Up Using STM32 HAL

The HAL GPIO initialization structure provides the Pull field for selecting the pull configuration.

Example: Configure PC13 as Input with Pull-Up

void Button_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOC_CLK_ENABLE();

    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLUP;

    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
}

The input will normally read HIGH when no external circuit pulls it LOW.

9. Configure Pull-Down Using STM32 HAL

Example: Configure PA0 as Input with Pull-Down

void Sensor_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOA_CLK_ENABLE();

    GPIO_InitStruct.Pin = GPIO_PIN_0;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLDOWN;

    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
}

The input will normally read LOW when no external circuit drives it HIGH.

10. Active-HIGH and Active-LOW Signals

Active-HIGH

An active-HIGH signal is considered asserted when its voltage represents logic HIGH.

Active-LOW

An active-LOW signal is considered asserted when its voltage represents logic LOW.

Signal Type Active Condition
Active-HIGH Logic HIGH
Active-LOW Logic LOW

Active-LOW signals are often indicated in documentation using names such as RESET_N, CS_N or an overbar.

11. Complete Program: Button with Internal Pull-Up

This example uses PC13 as a button input with an internal pull-up and PA5 as an LED output. 

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13) == GPIO_PIN_RESET)
        {
            /* Button pressed: input LOW */
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
        }
        else
        {
            /* Button released: input HIGH */
            HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
        }
    }
}

GPIO Initialization

void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOA_CLK_ENABLE();
    __HAL_RCC_GPIOC_CLK_ENABLE();

    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);

    GPIO_InitStruct.Pin = GPIO_PIN_5;
    GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;

    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLUP;

    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
}

Expected Result

  • Button released: input HIGH, LED OFF.
  • Button pressed: input LOW, LED ON.
This is an illustrative pin assignment. Verify the actual button and LED wiring before using the program on a board.

12. Selecting Pull Resistor Values

External pull-resistor selection involves balancing current consumption, input leakage, noise immunity and signal rise or fall time.

For example, a 10 kΩ pull-up connected to 3.3 V draws approximately 0.33 mA when the input is pulled to ground.

I = 0.00033 A

I = 0.33 mA

This current flows through the resistor while the switch holds the input LOW.

A 10 kΩ resistor is a common illustrative value, not a universal requirement. Select the resistance using the device specifications and circuit timing/noise requirements.

13. Common Input Problems and Troubleshooting

Problem Possible Cause Solution
Input changes randomly Floating input Configure a suitable pull resistor.
Button always reads HIGH Incorrect wiring or missing ground path Check switch connection and circuit.
Button always reads LOW Short to ground or incorrect pull configuration Inspect wiring and configuration.
Input voltage is incorrect Wrong supply or incompatible signal voltage Check MCU electrical specifications.
Input changes multiple times per press Mechanical switch bounce Apply hardware or software debouncing.

14. Placement-Oriented Interview Questions

Q1. What is a floating input?

A floating input has no defined logic level and can respond unpredictably to electrical noise.

Q2. What is a pull-up resistor?

A resistor that connects an input weakly to the positive supply to establish a default HIGH state.

Q3. What is a pull-down resistor?

A resistor that connects an input weakly to ground to establish a default LOW state.

Q4. What happens when a pull-up button is pressed?

If the switch connects the input to ground, the input changes from HIGH to LOW.

Q5. What is the difference between internal and external pull resistors?

Internal pull resistors are built into the MCU and software-configurable. External pull resistors are physical components connected to the circuit.

Q6. What is an active-LOW signal?

A signal that is considered asserted when its logic level is LOW.

Q7. Why should floating inputs be avoided?

They can cause unpredictable readings, false triggering and unreliable application behavior.

Q8. What does GPIO_PULLUP do in HAL?

It configures the GPIO input with an internal pull-up resistor, where supported.

Q9. What does GPIO_PULLDOWN do?

It configures the GPIO input with an internal pull-down resistor, where supported.

Q10. Why is a pull resistor called a weak connection?

It establishes a default voltage without directly forcing the input to that voltage with a low-resistance connection.

16. Lesson Summary

  • Floating inputs can produce unpredictable logic readings.
  • Pull-up resistors establish a default HIGH state.
  • Pull-down resistors establish a default LOW state.
  • STM32 devices may provide configurable internal pull resistors.
  • External pull resistors provide additional circuit flexibility.
  • Active-HIGH and active-LOW describe signal assertion levels.
  • HAL supports input pull configuration through GPIO_InitTypeDef.
  • Correct electrical design is essential for reliable input detection.
