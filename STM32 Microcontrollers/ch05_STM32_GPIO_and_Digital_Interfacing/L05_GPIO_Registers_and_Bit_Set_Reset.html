Lesson 5: GPIO Registers and Bit Set/Reset

Understand STM32 GPIO hardware registers, register-level programming, bit manipulation, BSRR operation and direct control of GPIO pins.

2. What Are GPIO Registers?

GPIO registers are special memory-mapped hardware registers used by the processor to configure and control GPIO pins.

In memory-mapped I/O, peripheral registers are assigned addresses within the processor's address space. The CPU accesses them using normal load and store instructions.

Purpose of GPIO Registers

  • Select pin operating mode.
  • Select output type.
  • Configure output speed.
  • Configure internal pull resistors.
  • Read input pin states.
  • Write output pin states.
  • Set or reset output bits.

3. Important STM32 GPIO Registers

The following register names and descriptions represent the GPIO architecture used by STM32F4 devices. Other STM32 families may use different layouts and register definitions.

Register Purpose
MODER Configures GPIO operating mode.
OTYPER Selects push-pull or open-drain output.
OSPEEDR Configures output speed characteristics.
PUPDR Configures pull-up and pull-down resistors.
IDR Reads GPIO input data.
ODR Reads or writes GPIO output data.
BSRR Sets or resets GPIO output bits.
AFRL / AFRH Selects alternate functions for GPIO pins.

4. MODER – GPIO Mode Register

MODER selects the operating mode of each GPIO pin. In the STM32F4 GPIO architecture, each pin uses two bits.

MODER Bits Mode
00 Input
01 General-purpose output
10 Alternate function
11 Analog

Example: Configure PA5 as Output

/* Clear PA5 mode bits */
GPIOA->MODER &= ~(3U << (5U * 2U));

/* Set PA5 mode to output: 01 */
GPIOA->MODER |= (1U << (5U * 2U));

The shift position is calculated as pin number multiplied by two because each pin occupies two MODER bits.

5. OTYPER – GPIO Output Type Register

OTYPER selects the output driver type for each GPIO pin. Each pin uses one bit in this register.

Bit Value Output Type
0 Push-pull
1 Open-drain

Example: Configure PA5 as Push-Pull

GPIOA->OTYPER &= ~(1U << 5U);

Example: Configure PA5 as Open-Drain

GPIOA->OTYPER |= (1U << 5U);

6. OSPEEDR – GPIO Output Speed Register

OSPEEDR configures the output switching characteristics. In STM32F4 devices, each pin uses two bits.

Bits Configuration
00 Low speed
01 Medium speed
10 High speed
11 Very high speed

Example: Configure PA5 for Low Speed

GPIOA->OSPEEDR &= ~(3U << (5U * 2U));
These are register encodings for the STM32F4 GPIO architecture. Output speed settings affect electrical edge characteristics; they do not specify a guaranteed signal frequency.

7. PUPDR – GPIO Pull-Up/Pull-Down Register

PUPDR selects the internal pull resistor configuration. In STM32F4 devices, each pin uses two bits.

Bits Configuration
00 No pull-up or pull-down
01 Pull-up
10 Pull-down
11 Reserved

Example: Configure PA5 with Pull-Up

GPIOA->PUPDR &= ~(3U << (5U * 2U));

GPIOA->PUPDR |= (1U << (5U * 2U));

Example: Configure PA5 with Pull-Down

GPIOA->PUPDR &= ~(3U << (5U * 2U));

GPIOA->PUPDR |= (2U << (5U * 2U));

8. IDR – Input Data Register

IDR is used to read the digital input state of GPIO pins. Each bit corresponds to one GPIO pin.

Example: Read PA0

if (GPIOA->IDR & (1U << 0U))
{
    /* PA0 is HIGH */
}
else
{
    /* PA0 is LOW */
}

Example: Read PA5

uint32_t input_state;

input_state = (GPIOA->IDR >> 5U) & 1U;

9. ODR – Output Data Register

ODR is used to read or write the output data state of GPIO pins.

Set PA5 HIGH

GPIOA->ODR |= (1U << 5U);

Set PA5 LOW

GPIOA->ODR &= ~(1U << 5U);

Toggle PA5

GPIOA->ODR ^= (1U << 5U);
ODR read-modify-write operations can be unsafe when multiple execution contexts or interrupts modify the same register. Consider BSRR for atomic bit set/reset operations.

10. BSRR – Bit Set/Reset Register

BSRR allows software to set or reset individual GPIO output bits without performing a read-modify-write operation on ODR.

In the STM32F4 GPIO architecture, BSRR is a 32-bit register.

Bits Operation
Bits 0–15 Set corresponding output bits.
Bits 16–31 Reset corresponding output bits.

Set PA5 HIGH

GPIOA->BSRR = (1U << 5U);

Reset PA5 LOW

GPIOA->BSRR = (1U << (5U + 16U));

Set PA0 and PA5 HIGH Together

GPIOA->BSRR = (1U << 0U) | (1U << 5U);

Reset PA0 and PA5 Together

GPIOA->BSRR = (1U << 16U) | (1U << 21U);
BSRR writes are designed to update selected output bits without changing other ODR bits. If software writes both set and reset commands for the same pin in one BSRR write, the reset command takes priority on STM32F4.

11. AFRL and AFRH – Alternate Function Registers

These registers select the alternate function connected to GPIO pins.

Register Pin Range
AFRL PA0 to PA7, for Port A
AFRH PA8 to PA15, for Port A

Each pin uses four bits for alternate function selection in the STM32F4 architecture.

Example: Configure PA5 Alternate Function Number 7

/* Clear PA5 alternate function field */
GPIOA->AFR[0] &= ~(0xFU << (5U * 4U));

/* Select AF7 */
GPIOA->AFR[0] |= (7U << (5U * 4U));
AF7 is used by certain USART signals on some STM32F4 devices, but the actual peripheral signal mapping must be verified using the selected MCU datasheet.

12. Bit Manipulation Fundamentals

Bitwise operators allow software to modify individual bits within a hardware register.

Operator Name Common Use
& Bitwise AND Clear or test bits.
| Bitwise OR Set bits.
^ Bitwise XOR Toggle bits.
~ Bitwise NOT Invert bits.
<< Left shift Position a bit.
>> Right shift Extract or shift bits.

Set a Bit

REG |= (1U << n);

Clear a Bit

REG &= ~(1U << n);

Toggle a Bit

REG ^= (1U << n);

Read a Bit

if (REG & (1U << n))
{
    /* Bit is set */
}

13. Complete Register-Level Program: Blink LED

The following example uses the STM32F4 GPIO register architecture and configures PA5 as a push-pull output. 

#include "stm32f4xx.h"

void GPIO_Init(void)
{
    /* Enable GPIOA clock */
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;

    /* Configure PA5 as output */
    GPIOA->MODER &= ~(3U << (5U * 2U));
    GPIOA->MODER |=  (1U << (5U * 2U));

    /* Push-pull output */
    GPIOA->OTYPER &= ~(1U << 5U);

    /* Low output speed */
    GPIOA->OSPEEDR &= ~(3U << (5U * 2U));

    /* No pull-up or pull-down */
    GPIOA->PUPDR &= ~(3U << (5U * 2U));
}

void Delay(volatile uint32_t count)
{
    while (count--)
    {
        __NOP();
    }
}

int main(void)
{
    GPIO_Init();

    while (1)
    {
        /* Set PA5 */
        GPIOA->BSRR = (1U << 5U);

        Delay(500000U);

        /* Reset PA5 */
        GPIOA->BSRR = (1U << 21U);

        Delay(500000U);
    }
}
This is an STM32F4-specific register example. The software delay is not a calibrated time delay. For accurate timing, use a hardware timer or a properly configured system tick.

14. HAL vs Register-Level GPIO Control

HAL Register-Level
Uses abstraction functions. Accesses peripheral registers directly.
More portable across supported STM32 families. Register details are family-specific.
Convenient for application development. Useful for understanding hardware operation.
Hides many register details. Provides detailed control over individual bits.

15. Register-Level Programming Precautions

  • Use the correct device header file.
  • Check the reference manual for register addresses and bit fields.
  • Enable the peripheral clock before accessing GPIO.
  • Use unsigned constants such as 1U for bit operations.
  • Do not write reserved register bits unless explicitly allowed.
  • Use BSRR for independent output bit set/reset operations where supported.
  • Consider interrupt and concurrent-access behavior.
  • Verify pin electrical limits before connecting external hardware.

16. Placement-Oriented Interview Questions

Q1. What is a memory-mapped register?

A peripheral register assigned a memory address that the processor can access using load and store instructions.

Q2. What is the purpose of MODER?

It selects the operating mode of GPIO pins.

Q3. What is the purpose of OTYPER?

It selects push-pull or open-drain output type.

Q4. What is the purpose of OSPEEDR?

It configures the output switching characteristics.

Q5. What is the purpose of PUPDR?

It configures pull-up and pull-down resistors.

Q6. What is the difference between IDR and ODR?

IDR reads input data, while ODR stores output data.

Q7. What is the purpose of BSRR?

It sets and resets selected output bits without requiring a read-modify-write operation on ODR.

Q8. Why is BSRR useful in interrupt-driven applications?

Its bit set/reset operation avoids the read-modify-write sequence that can cause lost updates when different execution contexts modify separate output bits.

Q9. How do you set a bit in a register?

Use REG |= (1U << n);.

Q10. How do you clear a bit?

Use REG &= ~(1U << n);.

Q11. How do you toggle a bit?

Use REG ^= (1U << n);.

Q12. Are GPIO register layouts identical across all STM32 families?

No. Register layouts and peripheral features can vary across STM32 families and devices.
