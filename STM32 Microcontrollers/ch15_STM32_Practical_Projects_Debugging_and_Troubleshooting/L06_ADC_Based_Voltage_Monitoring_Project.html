2. Project Overview

An Analog-to-Digital Converter (ADC) converts an analog input voltage into a digital value that can be processed by an STM32 microcontroller.

In this project, the STM32 measures an input voltage, calculates its equivalent voltage value and checks whether it is within a defined operating range.

Applications

  • Battery voltage monitoring.
  • Power supply monitoring.
  • Overvoltage and undervoltage detection.
  • Solar panel voltage measurement.
  • DC bus voltage monitoring.
  • Embedded power management systems.

4. Understanding ADC Conversion

An ADC samples an analog voltage and produces a corresponding digital code. The number of available digital levels depends on ADC resolution.

ADC Resolution

Resolution Number of Levels Digital Code Range
8-bit2560–255
10-bit10240–1023
12-bit40960–4095
16-bit655360–65535

A 12-bit ADC has 4096 possible output codes, ranging from 0 to 4095.

5. ADC Voltage Calculation

For an ideal N-bit ADC, the approximate input voltage is:

ADC Voltage ≈ (ADC Value × VREF) / (2^N - 1)

Where:

  • ADC Value = digital conversion result.
  • VREF = ADC reference voltage.
  • N = ADC resolution in bits.

Example: 12-bit ADC

Assume:

  • ADC resolution = 12 bits.
  • VREF = 3.3 V.
  • ADC result = 2048.
ADC Voltage ≈ (2048 × 3.3) / 4095

ADC Voltage ≈ 1.65 V

This is an idealized conversion calculation. Actual measurement accuracy depends on reference voltage, ADC characteristics, calibration and circuit design.

6. Voltage Divider Circuit

A voltage divider reduces a higher input voltage to a level suitable for the STM32 ADC input. 

       VIN
        |
       R1
        |
        +-----------> STM32 ADC Input
        |
       R2
        |
       GND

Output voltage:

VOUT = VIN × R2 / (R1 + R2)

Example

Assume:

  • Input voltage = 12 V.
  • R1 = 30 kΩ.
  • R2 = 10 kΩ.
VOUT = 12 × 10 / (30 + 10)

VOUT = 3 V

The ADC receives approximately 3 V, rather than the original 12 V.

Select resistor values so that the ADC pin remains within its permitted input range under all expected conditions, including transients and component tolerances. Also consider ADC input impedance, sampling time and divider loading.

8. HAL Functions Used

Function Purpose
HAL_ADC_Start() Starts ADC conversion.
HAL_ADC_PollForConversion() Waits for conversion completion.
HAL_ADC_GetValue() Reads the converted ADC value.
HAL_ADC_Stop() Stops ADC conversion.
HAL_ADC_Start_DMA() Starts ADC conversion using DMA.

9. Project 1: Read Analog Voltage Using STM32 ADC

HAL Program


#include "main.h"
#include 

extern ADC_HandleTypeDef hadc1;

uint32_t adc_value;
float adc_voltage;

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();
    MX_ADC1_Init();
    MX_USART2_UART_Init();

    while (1)
    {
        if (HAL_ADC_Start(&hadc1) == HAL_OK)
        {
            if (HAL_ADC_PollForConversion(
                    &hadc1, 100) == HAL_OK)
            {
                adc_value = HAL_ADC_GetValue(&hadc1);

                adc_voltage =
                    (adc_value * 3.3f) / 4095.0f;

                printf("ADC Value: %lu\r\n",
                       (unsigned long)adc_value);

                printf("ADC Voltage: %.3f V\r\n",
                       adc_voltage);
            }

            HAL_ADC_Stop(&hadc1);
        }

        HAL_Delay(500);
    }
}

Program Explanation

  • ADC1 is initialized using generated CubeMX code.
  • HAL_ADC_Start() starts the conversion.
  • HAL_ADC_PollForConversion() waits for the result.
  • HAL_ADC_GetValue() reads the ADC data.
  • The result is converted into voltage.
  • The voltage is printed through UART.

This example assumes a 12-bit ADC and a 3.3 V reference. Replace these values with the actual resolution and reference used by the selected STM32 device. UART printf retargeting must also be configured separately.

10. Project 2: Calculate the Original Input Voltage

If a voltage divider is used, the measured ADC pin voltage must be scaled back to estimate the original input voltage. 


#include "main.h"
#include 

extern ADC_HandleTypeDef hadc1;

#define VREF        3.3f
#define ADC_MAX     4095.0f
#define R1          30000.0f
#define R2          10000.0f

uint32_t adc_value;

float adc_pin_voltage;
float input_voltage;

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();
    MX_ADC1_Init();
    MX_USART2_UART_Init();

    while (1)
    {
        if (HAL_ADC_Start(&hadc1) == HAL_OK)
        {
            if (HAL_ADC_PollForConversion(
                    &hadc1, 100) == HAL_OK)
            {
                adc_value = HAL_ADC_GetValue(&hadc1);

                adc_pin_voltage =
                    (adc_value * VREF) / ADC_MAX;

                input_voltage =
                    adc_pin_voltage * (R1 + R2) / R2;

                printf("Input Voltage: %.2f V\r\n",
                       input_voltage);
            }

            HAL_ADC_Stop(&hadc1);
        }

        HAL_Delay(500);
    }
}

The resistor values in the program must match the actual voltage divider. The calculated input voltage is an estimate; resistor tolerance and reference accuracy affect the result.

11. Project 3: Overvoltage and Undervoltage Detection

The STM32 compares the measured input voltage against predefined thresholds and produces an indication.

Example Thresholds

  • Undervoltage threshold = 10 V.
  • Normal operating range = 10 V to 14 V.
  • Overvoltage threshold = 14 V.

HAL Program


#include "main.h"

extern ADC_HandleTypeDef hadc1;

#define VREF       3.3f
#define ADC_MAX    4095.0f
#define R1         30000.0f
#define R2         10000.0f

#define UNDER_LIMIT 10.0f
#define OVER_LIMIT  14.0f

float input_voltage;
uint32_t adc_value;

void Check_Voltage(void)
{
    if (input_voltage < UNDER_LIMIT)
    {
        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_0, GPIO_PIN_SET
        );

        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_1, GPIO_PIN_RESET
        );
    }
    else if (input_voltage > OVER_LIMIT)
    {
        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_0, GPIO_PIN_RESET
        );

        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_1, GPIO_PIN_SET
        );
    }
    else
    {
        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_0, GPIO_PIN_RESET
        );

        HAL_GPIO_WritePin(
            GPIOB, GPIO_PIN_1, GPIO_PIN_RESET
        );
    }
}

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();
    MX_ADC1_Init();

    while (1)
    {
        if (HAL_ADC_Start(&hadc1) == HAL_OK)
        {
            if (HAL_ADC_PollForConversion(
                    &hadc1, 100) == HAL_OK)
            {
                adc_value = HAL_ADC_GetValue(&hadc1);

                float adc_pin_voltage =
                    (adc_value * VREF) / ADC_MAX;

                input_voltage =
                    adc_pin_voltage * (R1 + R2) / R2;

                Check_Voltage();
            }

            HAL_ADC_Stop(&hadc1);
        }

        HAL_Delay(100);
    }
}

GPIOB pins 0 and 1 are illustrative output pins. Configure them as GPIO outputs and adapt the pins to the actual board. In a real protection system, use suitable filtering, hysteresis, fault latching and a safe hardware shutdown path where required.

12. ADC Noise and Filtering

ADC readings may fluctuate because of electrical noise, reference instability, grounding problems and input source impedance.

Moving Average Filter


#define SAMPLE_COUNT 10

uint32_t samples[SAMPLE_COUNT];

uint32_t Moving_Average(void)
{
    uint32_t sum = 0;

    for (uint32_t i = 0; i < SAMPLE_COUNT; i++)
    {
        sum += samples[i];
    }

    return sum / SAMPLE_COUNT;
}

The moving-average function calculates the average of the stored samples. A complete implementation must update the sample buffer with fresh ADC readings before calculating the average.

Other Noise Reduction Methods

  • Use suitable analog filtering.
  • Keep analog signal paths short.
  • Use proper grounding and decoupling.
  • Select an appropriate ADC sampling time.
  • Use averaging or digital filtering where suitable.
  • Keep switching noise away from sensitive analog inputs.

13. ADC Calibration and Accuracy

  • Verify the ADC reference voltage.
  • Check resistor divider tolerances.
  • Use the calibration procedure supported by the MCU family.
  • Allow sufficient ADC sampling time for the input source impedance.
  • Compare readings with a calibrated multimeter.
  • Check offset, gain and noise errors.

Not all STM32 families implement ADC calibration in the same way. Follow the reference manual and HAL documentation for the exact device.

14. Common ADC Problems and Troubleshooting

Problem 1: ADC Always Reads Zero

  • Check the analog input pin configuration.
  • Verify the selected ADC channel.
  • Check the input voltage and ground connection.
  • Confirm ADC clock and peripheral initialization.

Problem 2: ADC Reading Is Always Maximum

  • Check whether the input exceeds the permitted range.
  • Verify the voltage divider.
  • Check the reference voltage assumption.
  • Inspect the analog pin for shorts to the supply.

Problem 3: Unstable ADC Readings

  • Check supply and reference stability.
  • Inspect grounding and analog layout.
  • Increase sampling time if required.
  • Use filtering and suitable decoupling.

Problem 4: Incorrect Input Voltage Calculation

  • Verify the ADC resolution.
  • Use the actual VREF value.
  • Check R1 and R2 values.
  • Check resistor tolerance and measurement calibration.

15. Practical Testing Procedure

  1. Configure an ADC channel in STM32CubeMX.
  2. Build and flash the firmware.
  3. Start with a safe, known low-voltage input.
  4. Measure the ADC input using a multimeter.
  5. Read the ADC result through the debugger or UART.
  6. Calculate the ADC pin voltage.
  7. Calculate the original input voltage if a divider is used.
  8. Compare the calculated voltage with a multimeter reading.
  9. Test the undervoltage and overvoltage thresholds safely.
  10. Verify that the warning outputs respond correctly.

Never connect mains voltage directly to an MCU ADC input. Mains measurement requires an appropriately rated, isolated sensing and protection design performed with suitable electrical safety precautions.

16. Placement-Oriented Interview Questions and Answers

Q1. What is an ADC?

An Analog-to-Digital Converter converts an analog signal into a digital representation.

Q2. What is the resolution of a 12-bit ADC?

It provides 4096 possible output codes, from 0 to 4095.

Q3. What is VREF?

VREF is the reference voltage used by the ADC conversion process.

Q4. What is quantization?

Quantization maps a continuous input range to discrete digital levels.

Q5. Why is a voltage divider used?

It scales an input voltage to a level suitable for the ADC input.

Q6. What is ADC sampling time?

It is the time during which the ADC input sampling circuit acquires the analog signal before conversion.

Q7. What is ADC calibration?

It is a device-supported procedure that helps reduce certain ADC measurement errors.

Q8. Why are ADC readings noisy?

Noise can come from power supplies, references, grounding, switching circuits and analog input circuitry.

Q9. What is the purpose of ADC DMA?

DMA transfers conversion results to memory with reduced CPU involvement.

Q10. What is the difference between polling and interrupt-based ADC?

Polling checks conversion status in software, while interrupt-based operation notifies the CPU when a conversion event occurs.

Q11. How can overvoltage be detected?

Measure the scaled input voltage and compare it against a defined upper threshold.

Q12. Why should mains voltage not be connected directly to an ADC pin?

Mains voltage can cause lethal shock, destroy the MCU and create fire hazards. A suitably rated isolated measurement design is required.
