2. STM32 and Embedded Systems Fundamentals

Q1. What is an embedded system?

An embedded system is a combination of hardware and software designed to perform a dedicated function within a larger system.

Q2. What is a microcontroller?

A microcontroller integrates a CPU, memory and peripherals such as GPIO, timers and communication interfaces on a single chip.

Q3. What is STM32?

STM32 is a family of 32-bit microcontrollers manufactured by STMicroelectronics, based on ARM Cortex-M processor cores.

Q4. What is the difference between a microprocessor and a microcontroller?

A microprocessor generally requires external memory and peripheral components, whereas a microcontroller integrates important computing resources and peripherals on one chip.

Q5. What is ARM Cortex-M?

ARM Cortex-M is a processor-core family designed for microcontroller and embedded applications.

Q6. What is the difference between STM32 and ARM?

ARM designs processor architectures and cores. STM32 microcontrollers are products from STMicroelectronics that use ARM Cortex-M cores.

3. ARM Cortex-M Architecture Interview Questions

Q1. What is the Program Counter?

The Program Counter (PC) holds the address associated with the next instruction to be executed.

Q2. What is the Stack Pointer?

The Stack Pointer (SP) identifies the current top of the stack. Cortex-M processors commonly provide Main Stack Pointer (MSP) and Process Stack Pointer (PSP).

Q3. What is the Link Register?

The Link Register (LR) stores a return address during common function calls and is also used in exception-return mechanisms.

Q4. What is NVIC?

The Nested Vectored Interrupt Controller manages interrupt enabling, pending state and priority-based exception handling.

Q5. What is an exception?

An exception is an event that causes the processor to execute a dedicated handler.

Q6. What is the difference between MSP and PSP?

MSP is the Main Stack Pointer and PSP is the Process Stack Pointer. Handler mode always uses MSP, while Thread mode can use MSP or PSP.

Q7. What is a vector table?

It is a table containing the initial stack pointer value and exception-handler addresses used by the processor.

4. Embedded C Interview Questions

Q1. What is the difference between C and Embedded C?

Embedded C uses the C language for firmware development and includes device-specific hardware access, compiler extensions and peripheral programming.

Q2. What is volatile?

The volatile qualifier tells the compiler that an object's value may change in ways not apparent from ordinary program flow. It is commonly used for memory-mapped registers and variables shared with interrupt handlers.

Q3. Does volatile make a variable atomic?

No. Volatile does not guarantee atomicity, mutual exclusion or thread synchronization.

Q4. What is const?

The const qualifier prevents modification through the corresponding qualified access path.

Q5. What is static?

At block scope, static gives a local variable static storage duration. At file scope, static gives an object or function internal linkage.

Q6. What is a pointer?

A pointer is a variable that stores the address of another object or function, subject to the C language's pointer rules.

Q7. What is a function pointer?

A function pointer stores the address of a function and can be used to call that function indirectly.

Q8. What is a structure?

A structure is a user-defined data type that groups related variables, possibly of different types, under one name.

Q9. What is bit manipulation?

Bit manipulation uses bitwise operators to set, clear, toggle and test individual bits.

Q10. How do you set a bit?


REG |= (1U << 3);

Q11. How do you clear a bit?


REG &= ~(1U << 3);

Q12. How do you toggle a bit?


REG ^= (1U << 3);

Q13. How do you check a bit?


if (REG & (1U << 3))
{
    // Bit 3 is set
}

5. GPIO Interview Questions

Q1. What is GPIO?

General Purpose Input/Output pins are configurable pins used to interface with external digital devices.

Q2. What are GPIO operating modes?

Common modes include input, output, alternate function and analog mode.

Q3. What is an alternate function?

Alternate function mode connects a GPIO pin to a peripheral signal such as UART, SPI, I2C or a timer channel.

Q4. What is a pull-up resistor?

It holds a signal at a defined logic-high level when no external device actively drives the signal.

Q5. What is a pull-down resistor?

It holds a signal at a defined logic-low level when no external device actively drives the signal.

Q6. What is the difference between push-pull and open-drain?

Push-pull outputs actively drive both logic-high and logic-low levels. Open-drain outputs actively pull low and require a pull-up to produce a high level.

Q7. Why is a current-limiting resistor used with an LED?

It limits LED current to a safe value for the LED and its driving circuit.

6. Interrupt and NVIC Interview Questions

Q1. What is an interrupt?

An interrupt is an event that causes the processor to suspend its normal execution and run an interrupt service routine.

Q2. What is polling?

Polling is a technique in which software repeatedly checks a peripheral or event status.

Q3. What is an ISR?

An Interrupt Service Routine is a function executed in response to an interrupt or exception.

Q4. Why should an ISR be short?

A long ISR increases interrupt latency, blocks lower-priority work and can affect real-time performance.

Q5. What is interrupt priority?

It determines the relative urgency of interrupts. On the Cortex-M NVIC, a lower numerical priority value represents a higher priority.

Q6. What is interrupt latency?

It is the time between an interrupt request and the beginning of its handler execution.

Q7. What is interrupt nesting?

It occurs when a higher-priority interrupt preempts a lower-priority handler, when the configured priority rules permit it.

7. Timer and PWM Interview Questions

Q1. What is a timer?

A timer is a hardware peripheral used for time measurement, event generation, counting and waveform generation.

Q2. What is a prescaler?

A prescaler divides the timer input clock to produce a lower counter clock.

Q3. What is ARR?

The Auto-Reload Register defines the counter period in common timer counting modes.

Q4. What is CCR?

The Capture/Compare Register stores a compare value or captured timer value, depending on the timer configuration.

Q5. What is PWM?

Pulse Width Modulation controls the active fraction of a periodic signal.

Q6. How is PWM frequency calculated?

fPWM = fTIM / [(PSC + 1) × (ARR + 1)]

This formula applies to a common edge-aligned up-counting configuration. Other modes can use different relationships.

Q7. What is PWM duty cycle?

It is the percentage of the PWM period for which the output is active.

Q8. What are PWM applications?

LED dimming, motor speed control, power control and actuator interfacing.

8. UART, I2C and SPI Interview Questions

Q1. What is UART?

UART is an asynchronous serial communication interface commonly using separate transmit and receive lines.

Q2. What is baud rate?

Baud rate is the number of signal symbols transmitted per second. In common binary UART operation, the symbol rate equals the bit rate.

Q3. What is 8-N-1?

It means 8 data bits, no parity and 1 stop bit.

Q4. What is I2C?

I2C is a synchronous serial bus that uses two signal lines: SDA for data and SCL for clock.

Q5. What is SPI?

SPI is a synchronous serial interface commonly using SCLK, MOSI, MISO and chip-select signals.

Q6. What is the difference between UART and I2C?

UART is generally asynchronous and point-to-point, whereas I2C is synchronous and supports addressed devices on a shared bus.

Q7. What is the difference between I2C and SPI?

I2C uses two shared signal lines and addressing. SPI commonly uses separate clock and data lines with chip-select signals.

Q8. What is clock stretching?

It is an I2C mechanism in which a device holds SCL low to delay further bus activity.

Q9. What are CPOL and CPHA?

CPOL defines the SPI clock idle polarity, while CPHA defines the clock phase used for data sampling.

Q10. Why is a common ground important for UART?

It provides a common voltage reference for non-isolated communication between devices.

9. ADC and DMA Interview Questions

Q1. What is ADC?

ADC converts an analog input signal into a digital value.

Q2. What is ADC resolution?

It is the number of bits used to represent the conversion result.

Q3. What is a 12-bit ADC output range?

0 to 4095.

Q4. What is VREF?

It is the reference voltage used by the ADC conversion process.

Q5. What is sampling time?

It is the time allowed for the ADC input sampling circuit to acquire the analog signal.

Q6. What is DMA?

Direct Memory Access transfers data between memory and peripherals, or between memory regions where supported, with reduced CPU involvement.

Q7. What are the advantages of DMA?

It reduces CPU data-transfer workload and can support efficient continuous or high-rate data movement.

Q8. What is circular DMA?

In circular mode, the DMA transfer reloads or wraps according to its configuration so that data transfer can continue.

10. FreeRTOS Interview Questions

Q1. What is an RTOS?

A Real-Time Operating System provides scheduling and synchronization mechanisms for applications with timing requirements.

Q2. What is a task?

A task is an independently scheduled unit of execution managed by the RTOS.

Q3. What is task priority?

It represents the scheduling priority assigned to a task. The scheduler uses priorities according to its configuration.

Q4. What is a context switch?

It is the process of saving the state of one task and restoring the state of another.

Q5. What is a semaphore?

A semaphore is a synchronization mechanism used to signal events or control access to shared resources.

Q6. What is a mutex?

A mutex provides mutual exclusion for shared resources. FreeRTOS mutexes support priority inheritance.

Q7. What is a queue?

A queue transfers data or messages safely between tasks and, through ISR-safe APIs, between interrupts and tasks.

Q8. What is priority inversion?

It occurs when a higher-priority task is indirectly delayed by a lower-priority task holding a required resource.

Q9. What is a deadlock?

A deadlock occurs when tasks wait indefinitely for resources or events in a circular dependency.

Q10. Can an ISR call any FreeRTOS API?

No. Only APIs designed for interrupt context should be used from an ISR, and the interrupt priority must obey the FreeRTOS port's priority restrictions.

11. Debugging and Troubleshooting Interview Questions

Q1. What is debugging?

Debugging is the process of finding and correcting software defects.

Q2. What is a breakpoint?

A breakpoint pauses execution at a selected instruction.

Q3. What is SWD?

Serial Wire Debug is a debug interface commonly used to connect an STM32 target to a debugger.

Q4. What is HardFault?

HardFault is a Cortex-M exception used for faults that escalate or cannot be handled by a more specific fault handler.

Q5. What is stack overflow?

It occurs when stack usage exceeds the allocated stack space and can cause memory corruption or faults.

Q6. What is watchdog?

A watchdog is a hardware timer used to detect certain software failures and reset or otherwise recover the system.

Q7. Why is a watchdog useful?

It can help recover from firmware that stops making expected progress, provided it is supervised correctly.

Q8. What is the difference between IWDG and WWDG?

IWDG is an independent watchdog commonly clocked from a low-speed independent clock. WWDG uses a window-based refresh mechanism and a clock derived from the peripheral clock on common STM32 implementations.

12. Embedded C Programming Questions

Program 1: Set and Clear a Bit


#include 

int main(void)
{
    uint32_t reg = 0;

    reg |= (1U << 2);   // Set bit 2
    reg &= ~(1U << 2);  // Clear bit 2

    while (1)
    {
    }
}

Program 2: Count Set Bits


#include 

int count_set_bits(uint32_t value)
{
    int count = 0;

    while (value != 0U)
    {
        count += (int)(value & 1U);
        value >>= 1U;
    }

    return count;
}

int main(void)
{
    int result = count_set_bits(15U);

    while (1)
    {
    }
}

Expected result: result = 4.

Program 3: Reverse the Bits of an 8-Bit Value


#include 

uint8_t reverse_bits(uint8_t value)
{
    uint8_t result = 0;

    for (int i = 0; i < 8; i++)
    {
        result <<= 1;
        result |= (value & 1U);
        value >>= 1;
    }

    return result;
}

int main(void)
{
    uint8_t result = reverse_bits(0x12);

    while (1)
    {
    }
}

Expected result: 0x48 for input 0x12.

Program 4: Swap Two Numbers Without a Temporary Variable


#include 

int main(void)
{
    int a = 10;
    int b = 20;

    a = a ^ b;
    b = a ^ b;
    a = a ^ b;

    printf("a = %d, b = %d\n", a, b);

    return 0;
}

Expected result: a = 20, b = 10.

This XOR technique requires distinct objects and is mainly an interview exercise. A temporary variable is generally clearer and safer in normal application code.

13. STM32 Practical Project Questions

Q1. How do you interface an LED with STM32?

Configure a suitable GPIO as an output and drive the LED through a correctly sized current-limiting resistor.

Q2. How do you interface a push button?

Configure a GPIO as an input with an appropriate pull-up or pull-down and implement debouncing.

Q3. How do you generate PWM?

Configure a timer channel for PWM, calculate PSC and ARR, set the compare value and start the channel.

Q4. How do you interface an I2C sensor?

Configure I2C, check the sensor address, read its datasheet, initialize the device and read the required registers.

Q5. How do you interface an SPI sensor?

Configure SPI mode and clock, control chip select and implement the device-specific register read and write sequence.

Q6. How do you measure voltage?

Scale the voltage safely, read the ADC result and convert the digital value using the actual reference and ADC resolution.

Q7. How do you control a DC motor?

Generate PWM through a timer and use a suitable motor driver for the required voltage, current and direction control.

Q8. How do you debug a non-working peripheral?

Verify pin configuration, peripheral clock, initialization, registers, wiring, power and communication settings.

14. Project Explanation for Interviews

Interviewers may ask you to explain a project from architecture through implementation and testing. Prepare to describe the following points for every project:

  1. Project objective: What problem does it solve?
  2. Controller: Which STM32 MCU or development board was used?
  3. Peripherals: Which GPIO, timer, ADC or communication interfaces were used?
  4. Hardware: What sensors, drivers and external circuits were connected?
  5. Firmware: How was the software organized?
  6. Testing: How were outputs and measurements verified?
  7. Challenges: What problems occurred and how were they solved?
  8. Improvements: What would you improve in a future version?

Example: ADC-Based Voltage Monitoring

Project objective:

To measure a DC input voltage and detect overvoltage and undervoltage conditions.

Hardware:

  • STM32 development board.
  • Resistor voltage divider.
  • Low-voltage DC source.
  • LED indicators.
  • Multimeter for verification.

Software:

  • ADC configuration.
  • Voltage calculation.
  • Threshold comparison.
  • GPIO indication.
  • UART diagnostic output.

Testing:

Apply safe known input voltages, compare ADC-derived readings with a multimeter and verify the threshold indication.
