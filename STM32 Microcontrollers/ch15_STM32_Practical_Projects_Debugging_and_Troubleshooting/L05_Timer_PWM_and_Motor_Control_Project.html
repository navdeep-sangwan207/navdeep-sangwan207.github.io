2. Project Overview

Pulse Width Modulation (PWM) is commonly used in embedded systems to control the average power delivered to a load. STM32 timer peripherals can generate PWM signals with configurable frequency and duty cycle.

Applications

  • LED brightness control.
  • DC motor speed control.
  • Fan speed control.
  • Servo motor control.
  • Power converter control signals.
  • Heating element control through a suitable power stage.

4. Understanding PWM

PWM is a digital waveform in which the ON time and OFF time are varied while maintaining a selected period.

PWM Waveforms

25% Duty Cycle

HIGH  ┌───┐
      │   │
LOW ──┘   └──────────────

50% Duty Cycle

HIGH  ┌──────┐
      │      │
LOW ──┘      └───────────

75% Duty Cycle

HIGH  ┌───────────┐
      │           │
LOW ──┘           └──────

Important Terms

  • Period: Time for one complete PWM cycle.
  • Frequency: Number of cycles per second.
  • ON time: Duration for which the signal is active.
  • OFF time: Duration for which the signal is inactive.
  • Duty cycle: Percentage of the period for which the signal is active.

Duty cycle is calculated as: 

Duty Cycle (%) = (ON Time / Total Period) × 100

5. STM32 Timer Registers Used for PWM

Register Function
PSC Prescaler
ARR Auto-reload register
CNT Counter register
CCR Capture/Compare register
CCMR Capture/Compare mode configuration
CCER Capture/Compare enable and polarity

The timer counts according to its input clock and prescaler. The ARR value determines the counter period, while the capture/compare register controls the PWM active interval.

6. PWM Frequency Calculation

For a common edge-aligned, up-counting timer configuration: 

PWM Frequency =
Timer Clock / [(PSC + 1) × (ARR + 1)]

The timer counter frequency is: 

Counter Frequency = Timer Clock / (PSC + 1)

Example

Assume:

  • Timer clock = 84 MHz
  • PSC = 83
  • ARR = 999

Counter frequency:

84,000,000 / (83 + 1) = 1,000,000 Hz

PWM frequency:

1,000,000 / (999 + 1) = 1,000 Hz

Therefore, the PWM frequency is 1 kHz and its period is 1 millisecond.

The actual timer clock must be calculated from the selected STM32 clock tree. On many STM32F4 devices, the timer clock may be twice the APB peripheral clock when the APB prescaler is greater than one. Verify the exact device clock rules.

7. Duty Cycle Calculation

For common edge-aligned, up-counting PWM mode 1 with active-high output: 

Duty Cycle (%) ≈ [CCR / (ARR + 1)] × 100

Example

  • ARR = 999
  • CCR = 500
Duty Cycle ≈ (500 / 1000) × 100
           ≈ 50%
CCR Value Approximate Duty Cycle
250 25%
500 50%
750 75%
1000 100% in common configurations

Exact endpoint behavior depends on the timer mode and implementation. Confirm the selected timer's PWM behavior in the reference manual.

9. Project 1: LED Brightness Control Using PWM

An LED's apparent brightness can be controlled by changing the PWM duty cycle. A higher duty cycle generally produces greater average LED current and brightness when the circuit is configured appropriately.

HAL Program


#include "main.h"

extern TIM_HandleTypeDef htim2;

void Set_LED_Brightness(uint32_t duty)
{
    if (duty > 100U)
    {
        duty = 100U;
    }

    uint32_t arr =
        __HAL_TIM_GET_AUTORELOAD(&htim2);

    uint32_t compare =
        ((arr + 1U) * duty) / 100U;

    __HAL_TIM_SET_COMPARE(
        &htim2,
        TIM_CHANNEL_1,
        compare
    );
}

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();
    MX_TIM2_Init();

    HAL_TIM_PWM_Start(
        &htim2,
        TIM_CHANNEL_1
    );

    while (1)
    {
        Set_LED_Brightness(25);
        HAL_Delay(1000);

        Set_LED_Brightness(50);
        HAL_Delay(1000);

        Set_LED_Brightness(75);
        HAL_Delay(1000);

        Set_LED_Brightness(100);
        HAL_Delay(1000);

        Set_LED_Brightness(0);
        HAL_Delay(1000);
    }
}

Program Explanation

  • MX_TIM2_Init() initializes the configured timer.
  • HAL_TIM_PWM_Start() starts PWM output on Channel 1.
  • Set_LED_Brightness() converts a percentage into a compare value.
  • __HAL_TIM_SET_COMPARE() updates the PWM compare register through the HAL macro.

The example assumes that TIM2 Channel 1 is configured for PWM and connected to the selected LED pin. The timer period and channel must be configured correctly in CubeMX.

11. H-Bridge Direction Control

An H-bridge motor driver can reverse the polarity applied to a DC motor, allowing forward and reverse operation.

12. Project 2: DC Motor Speed and Direction Control

This example uses one PWM channel for speed control and two GPIO outputs for direction control.

Example HAL Program


#include "main.h"

extern TIM_HandleTypeDef htim2;

#define MOTOR_IN1_PORT GPIOB
#define MOTOR_IN1_PIN  GPIO_PIN_0

#define MOTOR_IN2_PORT GPIOB
#define MOTOR_IN2_PIN  GPIO_PIN_1

void Motor_Set_Speed(uint32_t duty)
{
    if (duty > 100U)
    {
        duty = 100U;
    }

    uint32_t arr =
        __HAL_TIM_GET_AUTORELOAD(&htim2);

    uint32_t compare =
        ((arr + 1U) * duty) / 100U;

    __HAL_TIM_SET_COMPARE(
        &htim2,
        TIM_CHANNEL_1,
        compare
    );
}

void Motor_Forward(void)
{
    HAL_GPIO_WritePin(
        MOTOR_IN1_PORT,
        MOTOR_IN1_PIN,
        GPIO_PIN_SET
    );

    HAL_GPIO_WritePin(
        MOTOR_IN2_PORT,
        MOTOR_IN2_PIN,
        GPIO_PIN_RESET
    );
}

void Motor_Reverse(void)
{
    HAL_GPIO_WritePin(
        MOTOR_IN1_PORT,
        MOTOR_IN1_PIN,
        GPIO_PIN_RESET
    );

    HAL_GPIO_WritePin(
        MOTOR_IN2_PORT,
        MOTOR_IN2_PIN,
        GPIO_PIN_SET
    );
}

void Motor_Stop(void)
{
    Motor_Set_Speed(0);
}

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();
    MX_TIM2_Init();

    HAL_TIM_PWM_Start(
        &htim2,
        TIM_CHANNEL_1
    );

    Motor_Forward();
    Motor_Set_Speed(40);

    HAL_Delay(3000);

    Motor_Set_Speed(70);

    HAL_Delay(3000);

    Motor_Stop();

    HAL_Delay(1000);

    Motor_Reverse();
    Motor_Set_Speed(40);

    HAL_Delay(3000);

    Motor_Stop();

    while (1)
    {
    }
}

Program Explanation

  • Motor_Forward() selects one direction.
  • Motor_Reverse() selects the opposite direction.
  • Motor_Set_Speed() changes the PWM duty cycle.
  • Motor_Stop() sets the PWM compare value to zero.

This is a basic open-loop demonstration. The duty cycle does not directly specify an exact motor speed. Actual speed depends on motor characteristics, supply voltage, mechanical load and driver losses.

The GPIO pins, PWM channel and driver truth table must be adapted to the selected hardware. A production design should also provide safe direction changes, current protection and appropriate fault handling.

13. Open-Loop and Closed-Loop Motor Control

Open-Loop Control

The controller applies a selected PWM duty cycle without measuring actual motor speed.

Closed-Loop Control

The controller measures motor speed using an encoder or another feedback sensor and adjusts PWM to approach a target speed. 

Target Speed
     |
     v
+----------------+
| Speed Control  |
| Algorithm      |
+----------------+
     |
     v
 PWM Output
     |
     v
 Motor + Driver
     |
     v
 Encoder Feedback
     |
     +----------> Speed Measurement
                       |
                       +---- Feedback

Closed-loop systems may use a PI or PID controller. Controller gains and sampling intervals must be tuned for the motor and mechanical system.

14. Motor Control Safety

  • Choose a driver rated for the motor supply and stall current.
  • Use a separate suitable motor supply when required.
  • Connect grounds appropriately for a non-isolated interface.
  • Use the protection and decoupling recommended by the driver datasheet.
  • Prevent H-bridge shoot-through using correct interlocking and dead-time where required.
  • Check thermal limits of the motor driver.
  • Do not change direction abruptly under unsafe conditions.
  • Provide emergency stop and fault handling where the application requires them.

15. Common PWM and Motor Control Problems

Problem 1: No PWM Output

  • Verify the timer channel configuration.
  • Check GPIO alternate-function selection.
  • Confirm that PWM was started.
  • Check timer and peripheral clock configuration.

Problem 2: Incorrect PWM Frequency

  • Check the actual timer input clock.
  • Verify PSC and ARR values.
  • Check APB prescaler and timer clock multiplication rules.
  • Confirm edge-aligned or center-aligned counting mode.

Problem 3: LED Brightness Does Not Change

  • Check whether the LED is connected to the configured timer channel.
  • Verify the compare register update.
  • Check output polarity.
  • Confirm the LED circuit and current-limiting resistor.

Problem 4: Motor Does Not Rotate

  • Check motor supply voltage.
  • Verify motor-driver enable and direction pins.
  • Check common ground where required.
  • Verify PWM input and driver compatibility.
  • Check whether the driver has entered a fault state.

Problem 5: Motor Speed Is Unstable

  • Check power supply stability.
  • Inspect motor current and mechanical load.
  • Check PWM frequency and driver behavior.
  • Use encoder feedback if accurate speed regulation is required.

16. Practical Testing Procedure

  1. Configure a timer channel for PWM generation.
  2. Calculate the timer clock, prescaler and ARR values.
  3. Start PWM on the selected output pin.
  4. Measure PWM frequency using an oscilloscope or logic analyzer.
  5. Change the CCR value and verify duty-cycle changes.
  6. Connect an LED through an appropriate circuit.
  7. Verify brightness changes at different duty cycles.
  8. Connect a suitable motor driver and DC motor.
  9. Test motor direction and speed at safe operating conditions.
  10. Inspect the driver for abnormal heating or fault indications.

17. Placement-Oriented Interview Questions and Answers

Q1. What is PWM?

Pulse Width Modulation is a technique that controls the active duration of a periodic signal.

Q2. What is duty cycle?

It is the percentage of one PWM period during which the output is active.

Q3. Which STM32 timer registers control PWM frequency?

The prescaler (PSC) and auto-reload register (ARR) determine the counter period in a common edge-aligned configuration.

Q4. What is the function of CCR?

The capture/compare register determines the compare point used to control PWM output timing.

Q5. How can LED brightness be controlled using PWM?

By changing the duty cycle of the PWM signal driving the LED circuit.

Q6. Why is a motor driver required?

An MCU GPIO cannot provide the voltage and current required by most motors. A suitable power driver supplies the required motor current.

Q7. What is an H-bridge?

An H-bridge is a switching circuit that can reverse the polarity applied to a DC motor.

Q8. What is open-loop motor control?

It controls the motor without measuring actual speed or position feedback.

Q9. What is closed-loop motor control?

It uses feedback to compare actual performance with the target and adjust the control output.

Q10. What is the difference between PWM frequency and duty cycle?

Frequency specifies how many cycles occur per second, while duty cycle specifies the active fraction of each cycle.

Q11. How can PWM be verified?

Use an oscilloscope or logic analyzer to inspect frequency, period, duty cycle and output level.

Q12. Why might a motor fail to start at a low duty cycle?

The applied average drive may be insufficient to overcome friction and the motor's starting load.
