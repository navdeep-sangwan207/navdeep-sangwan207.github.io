Lesson 1: Introduction to STM32 Microcontrollers

Understanding STM32 Architecture, Features and Embedded Applications

1. Learning Objectives

  • Understand what STM32 microcontrollers are.
  • Understand the basic working of a microcontroller.
  • Identify the major components of an STM32 device.
  • Understand the role of ARM Cortex-M processors.
  • Explore common STM32 peripherals and applications.
  • Understand the basic STM32 firmware development process.

2. What is a Microcontroller?

A microcontroller (MCU) is a compact integrated circuit designed to control electronic systems. It combines a processor, memory and input/output peripherals on a single chip.

A microcontroller executes a program stored in its memory, reads inputs from sensors or switches, processes the information and controls outputs such as LEDs, motors, displays and relays.

Example: In an automatic temperature-control system, a microcontroller reads a temperature sensor and switches a cooling fan ON or OFF according to the programmed temperature threshold.

3. What is STM32?

STM32 is a family of 32-bit microcontrollers developed by STMicroelectronics. Most STM32 devices use ARM Cortex-M processor cores.

STM32 microcontrollers are designed for applications requiring real-time control, communication, signal processing, low-power operation and embedded firmware execution.

Important STM32 Features

  • 32-bit ARM Cortex-M processor cores.
  • On-chip Flash program memory.
  • SRAM for runtime data storage.
  • GPIO pins for digital input and output.
  • Timers and PWM generation.
  • UART, USART, SPI and I2C communication interfaces.
  • ADC and, on supported devices, DAC peripherals.
  • Interrupt controller and DMA support on many devices.
  • Low-power operating modes on supported devices.
Important: Not every STM32 device has the same peripherals, memory capacity, clock speed or processor core. Always check the exact MCU datasheet.

4. Basic Architecture of an STM32 Microcontroller

An STM32 microcontroller contains a processor core connected to memory and peripheral interfaces through its internal bus architecture.

Major Architecture Components

Component Function
CPU Core Executes instructions and performs calculations.
Flash Memory Stores firmware and non-volatile program data.
SRAM Stores variables, stack and runtime data.
GPIO Interfaces with digital input and output devices.
Timers Generate timing events, measure signals and produce PWM.
ADC Converts analog input voltage into digital values.
Communication Interfaces Exchange data using UART, SPI, I2C and other protocols.
NVIC Manages processor exceptions and interrupt priorities.

5. What is ARM Cortex-M?

ARM Cortex-M is a family of processor cores designed primarily for embedded and microcontroller applications. STMicroelectronics integrates selected Cortex-M cores into different STM32 product families.

Common Cortex-M Processor Cores

Processor Core Typical Application Area
Cortex-M0 / M0+ Low-cost and low-power embedded systems.
Cortex-M3 General-purpose embedded control.
Cortex-M4 Control applications and DSP workloads; some variants include an FPU.
Cortex-M7 High-performance embedded processing.
Cortex-M33 Embedded systems with security-oriented features.
Cortex-M55 Machine-learning and signal-processing-oriented applications.

The exact core and features depend on the selected STM32 microcontroller. For example, STM32F103 uses Cortex-M3, while STM32F407 uses Cortex-M4.

6. Microcontroller vs Microprocessor

Microcontroller Microprocessor
CPU, memory and peripherals are integrated on a chip. Primarily a processor; external memory and peripherals may be required.
Commonly used for dedicated control applications. Commonly used for general-purpose computing.
Usually designed for lower system cost and power. Often used in systems with greater computing and memory requirements.
Examples: STM32, LPC2129, ATmega328P. Examples: desktop and application processors.

7. How Does an STM32 Microcontroller Work?

A typical embedded application follows this sequence:

  1. Power is supplied to the STM32 development board.
  2. The processor starts executing the startup code.
  3. The firmware initializes the system clock and peripherals.
  4. The processor reads sensor inputs or communication data.
  5. The firmware processes the received information.
  6. The microcontroller controls outputs based on program logic.
  7. The application continues executing its main loop and responding to events.

8. Practical Example – LED Blinking

One of the first STM32 exercises is controlling an LED using a GPIO pin. The processor configures the pin as an output and repeatedly changes its logic state.

Conceptual Embedded C Code

#include "main.h"

int main(void)
{
    HAL_Init();

    SystemClock_Config();

    MX_GPIO_Init();

    while (1)
    {
        HAL_GPIO_TogglePin(
            GPIOA,
            GPIO_PIN_5
        );

        HAL_Delay(500);
    }
}
Note: This is a conceptual STM32Cube HAL example. It assumes GPIOA pin 5 is configured as an output and the selected board connects an LED to that pin. The actual LED pin varies by board.

Expected Result

  • The LED turns ON.
  • After approximately 500 milliseconds, it changes state.
  • The process repeats continuously.
  • The LED visibly blinks.

9. Applications of STM32 Microcontrollers

  • Industrial Automation: Motor control, sensors and machine monitoring.
  • Automotive Electronics: Body control, sensor interfaces and embedded subsystems.
  • Consumer Electronics: Smart appliances and electronic controllers.
  • Medical Devices: Measurement and monitoring equipment.
  • IoT: Sensor nodes, connected devices and gateways.
  • Power Electronics: Digital control of converters and power systems.
  • Robotics: Motor control, sensing and real-time control systems.

11. STM32 Placement Interview Questions and Answers

Q1. What is STM32?

STM32 is a family of 32-bit microcontrollers developed by STMicroelectronics, primarily based on ARM Cortex-M processor cores.

Q2. Why is STM32 widely used in embedded systems?

It offers a broad range of processor performance levels, memory sizes, peripherals, development tools and low-power options for embedded applications.

Q3. What is the difference between a microcontroller and a microprocessor?

A microcontroller integrates a processor, memory and peripherals on a single chip, whereas a microprocessor primarily provides the processing unit and often requires external memory and peripherals.

Q4. What is ARM Cortex-M?

ARM Cortex-M is a family of processor cores designed for microcontroller and embedded applications.

Q5. What is GPIO?

GPIO stands for General Purpose Input/Output. It allows an STM32 device to interface with external digital devices.

Q6. What is Flash memory?

Flash is non-volatile memory used to store program code and other data that must remain available after power is removed.

Q7. What is SRAM?

SRAM is volatile memory used for temporary data during program execution, including variables and stack contents.

Q8. What is a peripheral?

A peripheral is a hardware module inside a microcontroller that performs a specific function, such as UART communication, ADC conversion or timer operation.

Q9. What is HAL in STM32?

HAL is the Hardware Abstraction Layer. It provides standardized APIs to configure and control supported STM32 peripherals.

Q10. What is the difference between STM32 and ARM?

ARM designs processor architectures and cores. STM32 is a microcontroller product family from STMicroelectronics that integrates ARM Cortex-M cores in many of its devices.

13. Lesson Summary

  • STM32 is a 32-bit microcontroller family from STMicroelectronics.
  • Most STM32 devices use ARM Cortex-M processor cores.
  • Flash stores firmware, while SRAM stores runtime data.
  • GPIO, timers, ADC and communication interfaces are important peripherals.
  • STM32 devices are widely used in industrial, automotive, IoT and control applications.
  • STM32 firmware can be developed using STM32CubeIDE and supported software libraries.
