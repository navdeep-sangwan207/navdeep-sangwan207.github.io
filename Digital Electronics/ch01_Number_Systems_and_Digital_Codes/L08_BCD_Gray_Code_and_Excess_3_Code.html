2. Introduction to Digital Codes

Digital codes are arrangements of binary digits (0 and 1) used to represent numbers, characters, symbols and other information in digital systems.

Common digital codes include:

  • Binary Coded Decimal (BCD)
  • Gray Code
  • Excess-3 Code
  • ASCII Code
  • Alphanumeric Codes
Placement focus: BCD, Gray code and Excess-3 are important topics in digital electronics interviews and digital system design.

3. Binary Coded Decimal (BCD)

Binary Coded Decimal (BCD) is a coding system in which each decimal digit is represented separately using a 4-bit binary number.

In standard 8421 BCD, each decimal digit is represented using the weights 8, 4, 2 and 1.

Important: Standard 8421 BCD uses only ten combinations, from 0000 to 1001. The remaining six combinations (1010 to 1111) are invalid BCD digit codes.

4. Decimal to BCD Conversion

To convert a decimal number into BCD, convert each decimal digit independently into its 4-bit BCD equivalent.

Example 1: Convert (25)₁₀ into BCD.

Decimal digit:    2       5
BCD equivalent: 0010    0101
Answer: (25)₁₀ = 0010 0101 (BCD)

Example 2: Convert (394)₁₀ into BCD.

Decimal digit:    3       9       4
BCD equivalent: 0011    1001    0100
Answer: (394)₁₀ = 0011 1001 0100 (BCD)

5. BCD to Decimal Conversion

Divide the BCD number into 4-bit groups and convert each group into its corresponding decimal digit.

Example: Convert 0101 1001 (BCD) into decimal.

BCD groups:       0101       1001
Decimal digits:      5          9
Answer: 0101 1001 (BCD) = (59)₁₀

6. BCD vs Pure Binary

BCD and pure binary are different ways of representing the same numerical value.

Example: Represent decimal 25.

Pure binary:
25 = 11001

BCD:
2 = 0010
5 = 0101

BCD = 0010 0101

7. BCD Addition

BCD addition is performed by adding each 4-bit BCD digit. A correction is required when the 4-bit sum is greater than 1001 (9) or when a carry is generated.

BCD correction rule: Add 0110 (decimal 6) when:
  • The 4-bit sum is greater than 1001.
  • A carry is generated from the 4-bit digit addition.

Example 1: Add 5 + 3 in BCD.

5 = 0101
3 = 0011

    0101
  + 0011
  -------
    1000

The result 1000 represents decimal 8. It is a valid BCD digit, so no correction is required.

Answer: 8 = 1000 (BCD)

Example 2: Add 7 + 8 in BCD.

7 = 0111
8 = 1000

    0111
  + 1000
  -------
    1111

1111 represents decimal 15 and is not a valid single BCD digit. Add the correction value 0110: 

    1111
  + 0110
  -------
  1 0101

The carry represents the tens digit 1, and 0101 represents the units digit 5.

Answer: 7 + 8 = 0001 0101 (BCD)

8. Gray Code

Gray code is a non-weighted binary code in which two consecutive code values differ by exactly one bit.

It is also known as a unit-distance code.

Important property: Only one bit changes between adjacent Gray code values. This reduces errors caused by multiple bits changing simultaneously during transitions.

8.1 Binary to Gray Code Conversion

Rules:

  1. The MSB of Gray code is the same as the MSB of binary.
  2. Each next Gray bit is obtained by XORing two adjacent binary bits.

XOR operation: same bits produce 0; different bits produce 1.

Example: Convert binary 1011 into Gray code.

Binary:       1  0  1  1

Gray MSB:     1

1 XOR 0 =     1
0 XOR 1 =     1
1 XOR 1 =     0

Gray code:    1  1  1  0
Answer: Binary 1011 = Gray 1110

8.2 Binary to Gray Formula

For binary bits B and Gray bits G:
  • GMSB = BMSB
  • Each remaining G bit = XOR of adjacent binary bits

9. Gray Code to Binary Conversion

Rules:

  1. The MSB of binary is the same as the MSB of Gray code.
  2. Each next binary bit is obtained by XORing the previous binary bit with the current Gray bit.

Example: Convert Gray code 1110 into binary.

Gray code:    1  1  1  0

Binary MSB:   1

1 XOR 1 =     0
0 XOR 1 =     1
1 XOR 0 =     1

Binary:       1  0  1  1
Answer: Gray 1110 = Binary 1011

11. Applications of Gray Code

  • Rotary and shaft position encoders.
  • Digital position measurement systems.
  • Analog-to-digital conversion systems.
  • Reducing transition errors in digital systems.
  • State assignment in digital circuit design.
  • Karnaugh map cell ordering.
Practical example: In a rotary encoder, Gray code helps reduce the possibility of incorrect position readings when the shaft moves between adjacent positions.

12. Excess-3 Code

Excess-3 is a non-weighted, self-complementing decimal code. It is obtained by adding 3 to each decimal digit and then converting the result into 4-bit binary.

Formula:

Excess-3 code = Binary representation of (Decimal digit + 3)

13. Decimal to Excess-3 Conversion

Add 3 to each decimal digit separately and convert the resulting value into 4-bit binary.

Example 1: Convert (25)₁₀ into Excess-3.

Digit 2: 2 + 3 = 5 = 0101
Digit 5: 5 + 3 = 8 = 1000

Excess-3 = 0101 1000
Answer: (25)₁₀ = 0101 1000 (Excess-3)

Example 2: Convert (394)₁₀ into Excess-3.

Digit 3: 3 + 3 = 6  = 0110
Digit 9: 9 + 3 = 12 = 1100
Digit 4: 4 + 3 = 7  = 0111

Excess-3 = 0110 1100 0111
Answer: (394)₁₀ = 0110 1100 0111 (Excess-3)

14. Excess-3 to Decimal Conversion

Divide the Excess-3 code into 4-bit groups, convert each group into decimal and subtract 3 from each resulting value.

Example: Convert 0101 1000 (Excess-3) into decimal.

First group:  0101 = 5
5 - 3 = 2

Second group: 1000 = 8
8 - 3 = 5

Decimal number = 25
Answer: 0101 1000 (Excess-3) = (25)₁₀

15. Self-Complementing Property of Excess-3

Excess-3 is called a self-complementing code because the bitwise complement of the Excess-3 code for a decimal digit represents the Excess-3 code for its 9's complement.

Example: Decimal 2 and its 9's complement.

Decimal 2:
2 + 3 = 5
Excess-3 = 0101

Bitwise complement:
1010

1010 = 10 in decimal
10 - 3 = 7

Decimal 7 is the 9's complement of 2.
Therefore, Excess-3 is self-complementing.

19. Lesson Summary

  • BCD represents each decimal digit using four binary bits.
  • Standard 8421 BCD has six invalid 4-bit combinations.
  • BCD addition requires correction by adding 0110 when necessary.
  • Gray code changes only one bit between consecutive values.
  • Binary-to-Gray conversion uses XOR of adjacent binary bits.
  • Gray-to-binary conversion uses cumulative XOR.
  • Excess-3 is generated by adding 3 to each decimal digit before binary encoding.
  • Excess-3 is a self-complementing code.
