2. What is the Binary Number System?

The binary number system is a number system that uses only two digits: 0 and 1.

It is also known as the base-2 number system because it contains two possible digits.

Definition: The binary number system is a positional number system in which each digit has a positional weight based on powers of 2.

Digital electronic circuits use two logical states, commonly represented by binary 0 and binary 1. Therefore, binary representation is fundamental to computers and digital systems.

3. Binary Digits

A binary digit is called a bit. There are only two possible bit values:

Binary Digit Logical State Meaning
0 LOW Logic LOW
1 HIGH Logic HIGH

A group of binary digits can represent numbers, characters, instructions and other types of information.

Example

1011 is a binary number containing four bits.

  • First bit from the right: 1
  • Second bit from the right: 1
  • Third bit from the right: 0
  • Fourth bit from the right: 1

4. Base of the Binary Number System

The base or radix of a number system represents the number of unique digits used in that system.

The binary number system has two digits, so its base is 2.

Binary Base = 2

Allowed digits: 0 and 1

Positional weights: 20, 21, 22, 23, and so on.

A binary number can be written with a subscript 2 to identify its base.

\[ (1011)_2 \]

The subscript 2 indicates that the number is in binary form.

5. Positional Weights of Binary Numbers

Each binary digit has a positional weight determined by its position, starting from the rightmost digit.

The rightmost position has weight 20, the next position has weight 21, and subsequent positions continue with increasing powers of 2.

Bit Position Power of 2 Decimal Weight
0 20 1
1 21 2
2 22 4
3 23 8
4 24 16
5 25 32
6 26 64
7 27 128

Example: Binary Number 1011

Assign positional weights:

Binary digits:     1    0    1    1
                   |    |    |    |
Powers of 2:       2³   2²   2¹   2⁰
Weights:           8    4    2    1

Multiply each bit by its corresponding weight:

\[ (1011)_2 = 1(8)+0(4)+1(2)+1(1) \]

\[ = 8+0+2+1 = 11 \]

Therefore, (1011)₂ = (11)₁₀.

6. MSB and LSB

6.1 Most Significant Bit (MSB)

The Most Significant Bit (MSB) is the leftmost bit of a binary number. It has the highest positional weight.

6.2 Least Significant Bit (LSB)

The Least Significant Bit (LSB) is the rightmost bit of a binary number. It has the lowest positional weight, which is 20.

Example

Binary number:  1  0  1  1
                ↑        ↑
               MSB      LSB
  • MSB = 1
  • LSB = 1

7. Binary to Decimal Conversion

To convert a binary number into decimal, multiply each bit by its positional weight and add the results.

Example 1: Convert (1101)₂ into decimal.

Step 1: Write the positional weights.

Binary:       1    1    0    1
Weight:       8    4    2    1

Step 2: Multiply each bit by its weight.

\[ = 1(8)+1(4)+0(2)+1(1) \]

Step 3: Add the results.

\[ = 8+4+0+1=13 \]

Answer: \[ (1101)_2=(13)_{10} \]

Example 2: Convert (10101)₂ into decimal.

\[ =1(16)+0(8)+1(4)+0(2)+1(1) \]

\[ =16+0+4+0+1=21 \]

Answer: \[ (10101)_2=(21)_{10} \]

8. Decimal to Binary Conversion

A common method for converting a positive decimal integer into binary is repeated division by 2.

Steps

  1. Divide the decimal number by 2.
  2. Write down the remainder.
  3. Divide the quotient again by 2.
  4. Repeat until the quotient becomes zero.
  5. Read the remainders from bottom to top.

Example: Convert (13)₁₀ into binary.

13 ÷ 2 = 6   Remainder 1
 6 ÷ 2 = 3   Remainder 0
 3 ÷ 2 = 1   Remainder 1
 1 ÷ 2 = 0   Remainder 1

Read remainders from bottom to top:

(13)₁₀ = (1101)₂

9. Range of Binary Numbers

An unsigned binary number containing n bits can represent values from 0 to 2n - 1.

Formula: \[ \text{Maximum value}=2^n-1 \]

Where n is the number of bits.

Number of Bits Minimum Value Maximum Value Total Values
1 0 1 2
2 0 3 4
4 0 15 16
8 0 255 256
16 0 65535 65536

Example

An 8-bit unsigned binary number can represent:

\[ 0 \text{ to } 2^8-1 \]

\[ 0 \text{ to } 255 \]

10. Applications of Binary Numbers

  • Microcontrollers: Store and process binary data.
  • Processors: Execute instructions represented internally in binary form.
  • Memory: Store data using binary states.
  • Communication: Represent and transmit digital information.
  • Digital Logic: Operate logic gates and digital circuits.
  • Embedded Systems: Represent sensor readings, control signals and program data.
