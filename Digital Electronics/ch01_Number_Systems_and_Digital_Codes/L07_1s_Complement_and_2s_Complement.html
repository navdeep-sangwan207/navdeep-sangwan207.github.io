2. Introduction to Signed Binary Numbers

Computers and digital systems must represent both positive and negative numbers. A binary number that represents only non-negative values is called an unsigned binary number.

Signed binary representation allows a system to represent positive and negative integers using a fixed number of bits.

Important: Modern processors commonly use two's complement representation for signed integer arithmetic.

Unsigned and Signed Binary Numbers

Representation 4-bit range
Unsigned binary 0 to 15
Signed 2's complement -8 to +7

In signed two's-complement representation, the most significant bit (MSB) has a negative weight. For a 4-bit number, the bit weights are: 

Bit position:    3    2    1    0
Weight:         -8    4    2    1

3. 1's Complement

The 1's complement of a binary number is obtained by changing every 0 into 1 and every 1 into 0.

Rule:
  • 0 becomes 1.
  • 1 becomes 0.

Example 1: Find the 1's complement of 10110010.

Original number:  10110010
1's complement:   01001101
Answer: 01001101

Example 2: Find the 1's complement of 00010101.

Original number:  00010101
1's complement:   11101010
Answer: 11101010

4. 2's Complement

The 2's complement of a binary number is obtained by adding 1 to its 1's complement.

Formula:

2's complement = 1's complement + 1

Example 1: Find the 2's complement of 10110010.

Original number:  10110010

1's complement:   01001101
Add 1:            00000001
                  --------
2's complement:   01001110
Answer: 01001110

Example 2: Find the 2's complement of 00000101.

Original number:  00000101

1's complement:   11111010
Add 1:            00000001
                  --------
2's complement:   11111011
Answer: 11111011

5. Shortcut Method for Finding 2's Complement

A quick method can be used to calculate the 2's complement without separately writing the 1's complement and adding 1.

  1. Start from the rightmost bit.
  2. Copy all bits up to and including the first 1.
  3. Invert all remaining bits to the left.

Example: Find the 2's complement of 10101000.

Original:       10101000
Copy from right:       1000
Invert remaining: 0101

2's complement: 01011000
Answer: 01011000

6. Representation of Negative Numbers

In two's-complement representation, a negative number is obtained by taking the 2's complement of the corresponding positive number using the same fixed bit width.

Example: Represent -5 using 8 bits.

Positive 5:       00000101

1's complement:   11111010
Add 1:            00000001
                  --------
2's complement:   11111011
Answer: -5 = 11111011 (8-bit 2's complement)

Example: Represent -12 using 8 bits.

Positive 12:      00001100

1's complement:   11110011
Add 1:            00000001
                  --------
2's complement:   11110100
Answer: -12 = 11110100

7. 1's Complement vs 2's Complement

Feature 1's Complement 2's Complement
Method Invert all bits Invert all bits and add 1
Zero representation Two representations One representation
Arithmetic Requires end-around carry Discard final carry-out
Modern processor usage Not commonly used Widely used
Signed range for n bits -(2^(n-1)-1) to +(2^(n-1)-1) -2^(n-1) to +(2^(n-1)-1)

8. Binary Subtraction Using 1's Complement

Subtraction can be performed by adding the 1's complement of the subtrahend to the minuend.

Procedure

  1. Find the 1's complement of the number being subtracted.
  2. Add it to the first number.
  3. If a carry is generated, add the carry to the least significant bit (end-around carry).
  4. If there is no carry, the result is negative. Take its 1's complement to find the magnitude and attach a negative sign.

Example 1: Calculate 9 − 5 using 4-bit 1's complement.

9 = 1001
5 = 0101

1's complement of 5 = 1010

       1001
     + 1010
     -------
      10011

A carry is generated. Add it to the least significant four bits: 

       0011
     + 0001
     -------
       0100
Answer: 9 − 5 = 0100₂ = 4₁₀

Example 2: Calculate 5 − 9 using 4-bit 1's complement.

5 = 0101
9 = 1001

1's complement of 9 = 0110

       0101
     + 0110
     -------
       1011

There is no end-around carry. Take the 1's complement of 1011: 

1's complement = 0100
Answer: 5 − 9 = -4

9. Binary Subtraction Using 2's Complement

In 2's-complement subtraction, subtraction is performed by adding the 2's complement of the subtrahend to the minuend.

Formula:

A − B = A + (2's complement of B)

Procedure

  1. Represent both numbers using the same number of bits.
  2. Find the 2's complement of the subtrahend.
  3. Add it to the minuend.
  4. If a carry-out occurs, discard it.
  5. If no carry-out occurs, interpret the result as negative in two's-complement form.

Example 1: Calculate 9 − 5 using 4-bit 2's complement.

9 = 1001
5 = 0101

1's complement of 5 = 1010
2's complement of 5 = 1011

       1001
     + 1011
     -------
      10100

Discard the final carry-out:

Result = 0100
Answer: 9 − 5 = 4

Example 2: Calculate 5 − 9 using 4-bit 2's complement.

5 = 0101
9 = 1001

1's complement of 9 = 0110
2's complement of 9 = 0111

       0101
     + 0111
     -------
       1100

There is no carry-out. The result is negative. Find its magnitude by taking the 2's complement of 1100: 

1's complement = 0011
Add 1          = 0001
                 ----
Magnitude      = 0100
Answer: 5 − 9 = -4

10. Range of 2's-Complement Numbers

For an n-bit two's-complement number, the range is:

Minimum value: -2n-1
Maximum value: 2n-1 − 1
Bit Width Minimum Maximum
4-bit -8 +7
8-bit -128 +127
16-bit -32768 +32767
32-bit -2147483648 +2147483647

11. Overflow in 2's-Complement Arithmetic

Signed overflow occurs when the mathematical result lies outside the range that can be represented using the available number of bits.

Example: Add 7 + 3 using 4-bit signed numbers.

  7 = 0111
  3 = 0011

      0111
    + 0011
    -------
      1010

The mathematical result is +10, but a 4-bit two's-complement number can represent only -8 to +7.

Result: Signed overflow occurs.
For signed addition, overflow occurs when two operands with the same sign produce a result with the opposite sign.

12. Application in Embedded C Programming

Embedded C programs commonly use signed integer variables to represent positive and negative values. Most modern microcontrollers use two's-complement representation for signed integers.

Example: Signed 8-bit integer

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int8_t a = 10;
    int8_t b = -5;

    int16_t result = (int16_t)a + b;

    printf("A = %d\n", a);
    printf("B = %d\n", b);
    printf("Result = %d\n", (int)result);

    return 0;
}

Expected Output:

A = 10
B = -5
Result = 5

Here, int8_t represents a signed 8-bit integer, while int16_t stores the result in a wider signed integer.

15. Lesson Summary

  • 1's complement is obtained by inverting every binary bit.
  • 2's complement is obtained by adding 1 to the 1's complement.
  • Two's complement is widely used for signed integer representation.
  • Negative numbers are represented by taking the 2's complement of their positive magnitude.
  • Binary subtraction can be performed using complement arithmetic.
  • Two's-complement arithmetic uses a fixed bit width.
  • Signed overflow occurs when the result exceeds the representable range.
