2. Introduction to De Morgan's Theorems

De Morgan's theorems are fundamental rules of Boolean algebra used to transform and simplify logical expressions. They explain how complementation interacts with AND and OR operations.

These theorems are especially useful when designing digital circuits using NAND and NOR gates.

Important concept: When a complete AND or OR expression is complemented, the operation changes to the other operation and each variable is complemented.

Two De Morgan's Theorems

First Theorem:

(A · B)̅ = A̅ + B̅

Second Theorem:

(A + B)̅ = A̅ · B̅

3. First De Morgan's Theorem

The complement of the AND operation is equal to the OR operation of the individual complemented variables.

(A · B)̅ = A̅ + B̅

Explanation

  • First perform the AND operation on A and B.
  • Take the complement of the AND output.
  • Alternatively, complement A and B individually.
  • Perform the OR operation on the complemented inputs.
  • Both methods produce the same output.

Truth Table Verification

A B A · B (A · B)̅ A̅ B̅ A̅ + B̅
0001 111
0101 101
1001 011
1110 000
Both output columns, (A · B)̅ and A̅ + B̅, are identical. Therefore, the first theorem is verified.

Equivalent Logic Circuits

A NAND gate directly implements the left-hand expression. The equivalent right-hand circuit uses an OR gate with both inputs inverted.

4. Second De Morgan's Theorem

The complement of the OR operation is equal to the AND operation of the individual complemented variables.

(A + B)̅ = A̅ · B̅

Explanation

  • First perform the OR operation on A and B.
  • Take the complement of the OR output.
  • Alternatively, complement A and B individually.
  • Perform the AND operation on the complemented inputs.
  • Both methods produce the same output.

Truth Table Verification

A B A + B (A + B)̅ A̅ B̅ A̅ · B̅
0001 111
0110 100
1010 010
1110 000
Both output columns, (A + B)̅ and A̅ · B̅, are identical. Therefore, the second theorem is verified.

Equivalent Logic Circuits

A NOR gate directly implements the left-hand expression. The equivalent right-hand circuit uses an AND gate with both inputs inverted.

5. De Morgan's Theorems for Multiple Variables

Both theorems can be extended to expressions containing three or more Boolean variables.

First Theorem

(A · B · C)̅ = A̅ + B̅ + C̅

Second Theorem

(A + B + C)̅ = A̅ · B̅ · C̅
General rule: Complement every variable, change AND to OR, and change OR to AND.

6. Boolean Expression Simplification Using De Morgan's Theorems

Example 1

Given: F = (A · B)̅

Applying the first theorem:

F = A̅ + B̅

Example 2

Given: F = (A + B)̅

Applying the second theorem:

F = A̅ · B̅

Example 3

Given: F = (A · B · C)̅

Applying the first theorem:

F = A̅ + B̅ + C̅

Example 4

Given: F = (A + B + C)̅

Applying the second theorem:

F = A̅ · B̅ · C̅

Example 5: Double Complement

Given: F = ((A · B)̅)̅

Using the double complement law:

F = A · B

Example 6: Mixed Expression

Given: F = (A + B̅)̅

Applying the second theorem:

F = A̅ · (B̅)̅

Using the double complement law:

F = A̅ · B

7. Bubble Pushing Technique

Bubble pushing is a graphical method used to transform logic circuits using De Morgan's theorems.

A small circle, called a bubble, at a gate input or output represents logical inversion.

Rules of Bubble Pushing

  1. Move a bubble through a gate.
  2. Change AND to OR or OR to AND.
  3. Keep the logical behavior unchanged by adding or moving the required inversion bubbles.
  4. Two consecutive inversions cancel each other.
Bubble pushing is useful when converting circuits into NAND-only or NOR-only implementations. It is a graphical application of De Morgan's theorems.

8. Applications in NAND and NOR Gate Design

NAND Implementation of OR

Required expression: Y = A + B

Invert both inputs:

A̅ = (A · A)̅
B̅ = (B · B)̅

Apply NAND to the inverted inputs:

Y = (A̅ · B̅)̅

Using De Morgan's theorem:

Y = A + B

NOR Implementation of AND

Required expression: Y = A · B

Invert both inputs:

A̅ = (A + A)̅
B̅ = (B + B)̅

Apply NOR to the inverted inputs:

Y = (A̅ + B̅)̅

Using De Morgan's theorem:

Y = A · B

9. Practical Experiment: Verification of De Morgan's Theorems

Objective

To verify both De Morgan's theorems using logic gates and compare the outputs using truth tables.

Required Components

  • IC 7400 – NAND gates
  • IC 7402 – NOR gates
  • IC 7404 – NOT gates
  • IC 7408 – AND gates
  • IC 7432 – OR gates
  • 5V regulated power supply
  • Breadboard and jumper wires
  • Input switches and LEDs with current-limiting resistors

Experiment A: First Theorem

Verify that:

(A · B)̅ = A̅ + B̅
  1. Connect A and B to an AND gate.
  2. Invert the AND output using a NOT gate.
  3. Build a second circuit by inverting A and B separately.
  4. Connect the inverted signals to an OR gate.
  5. Compare both outputs for all four input combinations.

Experiment B: Second Theorem

Verify that:

(A + B)̅ = A̅ · B̅
  1. Connect A and B to an OR gate.
  2. Invert the OR output using a NOT gate.
  3. Build a second circuit by inverting A and B separately.
  4. Connect the inverted signals to an AND gate.
  5. Compare both outputs for all four input combinations.
Practical precautions: Check the pinout of each IC before wiring. For standard 74xx DIP logic ICs, verify the supply and ground pins from the exact datasheet. Use valid input logic levels, avoid floating inputs and use appropriate LED resistors.

Expected Result

Both implementations of each theorem should produce identical outputs for every input combination.

14. Lesson Summary

  • De Morgan's theorems are fundamental Boolean algebra identities.
  • The first theorem is (A · B)̅ = A̅ + B̅.
  • The second theorem is (A + B)̅ = A̅ · B̅.
  • Complementing an expression changes AND to OR and OR to AND.
  • Each variable in the expression must also be complemented.
  • Both theorems can be verified using truth tables.
  • They are important for NAND-only and NOR-only circuit design.
  • Bubble pushing is a graphical application of these theorems.
