2. Introduction to Universal Gate Implementation

NAND and NOR gates are called universal gates because any Boolean function can be implemented using only NAND gates or only NOR gates.

In digital circuit design, this approach allows us to construct complete logic systems using a single type of basic gate.

Important: Universal gate implementation means replacing all required logic operations with NAND gates only or NOR gates only.

Common Universal Gate ICs

IC Number Gate Type Typical Configuration
7400 NAND Four 2-input NAND gates
7402 NOR Four 2-input NOR gates
4011 CMOS NAND Four 2-input NAND gates
4001 CMOS NOR Four 2-input NOR gates

3. Basic Logic Gates Using NAND Gates Only

3.1 NOT Gate Using NAND

Connect both NAND inputs to the same signal. The NAND gate behaves as an inverter.

Y = (A · A)̅ = A̅

Number of NAND gates required: 1

3.2 AND Gate Using NAND

Use the first NAND gate to produce the complemented AND output. Use the second NAND gate as an inverter.

First stage:

X = (A · B)̅

Second stage:

Y = (X · X)̅ = A · B

Number of NAND gates required: 2

3.3 OR Gate Using NAND

Invert both inputs using two NAND gates, then connect the inverted signals to a third NAND gate.

First inverter:

A̅ = (A · A)̅

Second inverter:

B̅ = (B · B)̅

Final stage:

Y = (A̅ · B̅)̅ = A + B

Number of NAND gates required: 3

NAND-Only Implementation Summary

Required Function NAND Gate Count Boolean Expression
NOT 1 A̅ = (A · A)̅
AND 2 A · B
OR 3 A + B

4. Basic Logic Gates Using NOR Gates Only

4.1 NOT Gate Using NOR

Connect both NOR inputs to the same signal. The NOR gate behaves as an inverter.

Y = (A + A)̅ = A̅

Number of NOR gates required: 1

4.2 OR Gate Using NOR

The first NOR gate produces the complemented OR output. The second NOR gate inverts that output.

First stage:

X = (A + B)̅

Second stage:

Y = (X + X)̅ = A + B

Number of NOR gates required: 2

4.3 AND Gate Using NOR

Invert both inputs using two NOR gates, then connect the inverted signals to a third NOR gate.

First inverter:

A̅ = (A + A)̅

Second inverter:

B̅ = (B + B)̅

Final stage:

Y = (A̅ + B̅)̅ = A · B

Number of NOR gates required: 3

NOR-Only Implementation Summary

Required Function NOR Gate Count Boolean Expression
NOT 1 A̅ = (A + A)̅
OR 2 A + B
AND 3 A · B

5. XOR Gate Using NAND Gates Only

An XOR gate produces HIGH output when its two inputs are different.

A two-input XOR function can be implemented using four NAND gates.

Boolean Implementation

First NAND gate:

N1 = (A · B)̅

Second NAND gate:

N2 = (A · N1)̅

Third NAND gate:

N3 = (B · N1)̅

Fourth NAND gate:

Y = (N2 · N3)̅

Final expression:

Y = A ⊕ B

Practical note: Four NAND gates are sufficient for a two-input XOR implementation. A 7400 IC contains four independent two-input NAND gates, so one IC can implement this circuit.

6. XNOR Gate Using NAND Gates Only

An XNOR gate produces HIGH output when its two inputs are equal.

First implement XOR using four NAND gates, then invert its output using one additional NAND gate.

First implement:

X = A ⊕ B

Then use one NAND gate as an inverter:

Y = (X · X)̅

Therefore:

Y = (A ⊕ B)̅ = A ⊙ B

Number of NAND gates required: 5

7. XOR Gate Using NOR Gates Only

An XOR function can also be implemented using five NOR gates.

Boolean Implementation

First NOR gate:

N1 = (A + B)̅

Second NOR gate:

N2 = (A + N1)̅

Third NOR gate:

N3 = (B + N1)̅

Fourth NOR gate:

N4 = (N2 + N3)̅

Fifth NOR gate:

Y = (N4 + N4)̅

Final expression:

Y = A ⊕ B
The first four NOR gates produce XNOR. The fifth NOR gate inverts the result to produce XOR.

8. Multi-Input Logic Function Using NAND Gates

Consider the Boolean expression:

Y = A · B + C

First implement the AND operation using a NAND gate. Then combine the result with C using a NAND-based OR implementation.

Implementation

Stage 1:

N1 = (A · B)̅

Stage 2: Invert N1 to obtain AB.

X = (N1 · N1)̅ = A · B

Stage 3: Invert X and C separately:

N2 = (X · X)̅ = X̅
N3 = (C · C)̅ = C̅

Stage 4:

Y = (N2 · N3)̅

Using De Morgan's theorem:

Y = X + C = A · B + C
Gate count: 5 NAND gates for this straightforward implementation. More efficient implementations may be possible by simplifying the circuit before constructing it.

11. Practical Experiment: Implement Logic Gates Using IC 7400

Objective

To construct NOT, AND, OR and XOR functions using NAND gates from IC 7400 and verify their outputs.

Required Components

  • IC 7400 – Quad 2-input NAND gate
  • 5V regulated power supply
  • Breadboard and jumper wires
  • Input switches or logic input sources
  • LEDs and current-limiting resistors

  • Pin 14 → +5V
  • Pin 7 → Ground

Suggested Gate Allocation for XOR

Gate Connections Output
Gate 1 A, B Pin 3 = N1
Gate 2 A, N1 Pin 6 = N2

Gate 4 N2, N3 Pin 11 = XOR
Practical precautions: Use the correct IC supply voltage and confirm the pinout from the manufacturer's datasheet. Avoid floating inputs and connect unused inputs to valid logic levels. Use suitable LED resistors and do not exceed output-current limits.

Expected Result

The constructed NAND-only circuits should produce the same truth tables as the corresponding basic logic gates.

15. Lesson Summary

  • NAND and NOR gates can implement all Boolean functions.
  • NOT, AND and OR can be constructed using NAND-only logic.
  • NOT, AND and OR can also be constructed using NOR-only logic.
  • XOR can be implemented using four NAND gates.
  • XNOR can be implemented by adding an inverter to XOR.
  • De Morgan's theorems are important for universal gate design.
  • Truth tables help verify equivalent logic circuits.
  • IC 7400 and IC 7402 are commonly used for practical experiments.
