2. What are Logic Gates?

A logic gate is a basic digital electronic circuit that performs a logical operation on one or more binary inputs and produces a single binary output.

Logic gates are the fundamental building blocks of digital electronic systems.

Definition: A logic gate is an electronic circuit that implements a Boolean function using binary input and output signals.

Logic gates are used in:

  • Microprocessors and microcontrollers.
  • Digital computers.
  • Memory circuits.
  • Arithmetic Logic Units (ALUs).
  • Digital control systems.
  • Communication and signal-processing circuits.

3. Binary Logic and Logic Levels

Digital electronic systems use two logical states: logic 0 and logic 1.

Logic State Meaning Typical Interpretation
Logic 0 LOW Low voltage level
Logic 1 HIGH High voltage level
Important: Logic 0 does not always mean exactly 0 volts, and logic 1 does not always mean 5 volts. Actual voltage ranges depend on the logic family and device specifications.

Example: 5V TTL Logic Levels

Input Voltage Interpretation
0 V to 0.8 V Guaranteed LOW
0.8 V to 2.0 V Undefined region
2.0 V to 5 V Guaranteed HIGH (within valid supply limits)

These are typical 5V TTL input thresholds. Always consult the datasheet for the actual voltage specifications of an IC.

4. Inputs and Outputs of Logic Gates

A logic gate receives binary signals through its input terminals and produces a binary output according to its logical operation.

5. What is a Truth Table?

A truth table is a table that shows all possible combinations of binary inputs and their corresponding output values.

For a logic circuit having n independent binary inputs, the total number of possible input combinations is:

Number of combinations = 2n

Example: Two Input Variables

Input A Input B
00
01
10
11

For two inputs, there are 2² = 4 possible combinations.

6. Introduction to Boolean Algebra

Boolean algebra is a mathematical system used to represent and simplify logical operations.

It uses two possible values: 0 and 1.

Basic Boolean Operations

Operation Symbol Meaning
AND A · B Logical multiplication
OR A + B Logical addition
NOT A̅ Logical inversion

Detailed Boolean algebra laws and theorems will be covered in Lesson 6 of this chapter.

7. Types of Logic Gates

Logic gates are commonly classified into three groups:

7.1 Basic Logic Gates

  • AND Gate
  • OR Gate
  • NOT Gate

7.2 Universal Logic Gates

  • NAND Gate
  • NOR Gate

7.3 Special Logic Gates

  • XOR Gate
  • XNOR Gate
NAND and NOR are called universal gates because any Boolean function can be implemented using only NAND gates or only NOR gates.

8. Logic Gate Symbols and Boolean Expressions

Each logic gate has a standard circuit symbol and a corresponding Boolean expression.

Logic Gate Boolean Expression Operation
AND Y = A · B Output 1 when all inputs are 1
OR Y = A + B Output 1 when at least one input is 1
NOT Y = A̅ Inverts the input
NAND Y = (A · B)̅ Inverts AND output
NOR Y = (A + B)̅ Inverts OR output
XOR Y = A ⊕ B Output 1 when inputs differ
XNOR Y = (A ⊕ B)̅ Output 1 when inputs are equal

9. Common Logic Gate IC Numbers

Logic gates are available as integrated circuits (ICs). Some commonly encountered 74-series TTL ICs include:

IC Number Function
7408 Quad 2-input AND gates
7432 Quad 2-input OR gates
7404 Hex inverter (NOT gates)
7400 Quad 2-input NAND gates
7402 Quad 2-input NOR gates
7486 Quad 2-input XOR gates
Practical note: These are common standard 74-series part numbers. Check the exact manufacturer's datasheet for supply voltage, pin configuration and electrical characteristics. Different logic-family variants may have different specifications.

10. Applications of Logic Gates

  • Computers: Used in processor and ALU design.
  • Memory: Used in storage and control circuits.
  • Microcontrollers: Used in internal digital logic.
  • Control systems: Used to implement decision-making logic.
  • Communication: Used in encoding and decoding circuits.
  • Embedded systems: Used in digital interfacing and control circuits.
