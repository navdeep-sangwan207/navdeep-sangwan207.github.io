2. XOR Gate (Exclusive-OR)

XOR stands for Exclusive-OR. It is a digital logic gate that produces logic 1 when its two inputs are different.

If both inputs are equal, the output is logic 0.

Boolean Expression

Y = A ⊕ B

The symbol ⊕ represents the exclusive-OR operation.

Expanded Boolean Expression

Y = A̅B + AB̅

The output is HIGH in either of these two cases:

  • A = 0 and B = 1
  • A = 1 and B = 0

Remember: XOR output is HIGH when the two inputs are different.

Applications of XOR Gate

  • Half adders and full adders.
  • Binary addition circuits.
  • Parity generation.
  • Error detection circuits.
  • Digital comparators.
  • Data encoding and encryption logic.

3. XNOR Gate (Exclusive-NOR)

XNOR stands for Exclusive-NOR. It is the complement of an XOR gate.

It produces logic 1 when its two inputs are equal and logic 0 when they are different.

Boolean Expression

Y = (A ⊕ B)̅

Expanded Boolean Expression

Y = AB + A̅B̅

The output is HIGH in either of these two cases:

  • A = 0 and B = 0
  • A = 1 and B = 1

Logic Symbol

The output bubble represents inversion of the XOR output.

Truth Table of XNOR Gate

Remember: XNOR output is HIGH when the two inputs are equal.

Applications of XNOR Gate

  • Equality comparison circuits.
  • Digital magnitude comparators.
  • Parity checking.
  • Error detection circuits.
  • Digital communication systems.

5. XOR Gate as a Controlled Inverter

An XOR gate can work as a controlled inverter. One input is used as the data signal and the other input controls whether the signal is inverted.

Control Input B Output Operation
0 Y = A Output follows input A
1 Y = A̅ Output is inverted
When B = 0, A ⊕ 0 = A. When B = 1, A ⊕ 1 = A̅.

6. XOR Gate in Parity Generation

Parity is a method used to detect errors during digital data transmission and storage.

An XOR gate can generate an even-parity bit for a data word.

Example: Three Data Bits

Consider the data:

A = 1, B = 0, C = 1

Even parity bit:

P = A ⊕ B ⊕ C

Calculation:

P = 1 ⊕ 0 ⊕ 1 = 0

The total number of 1s remains even: 1, 0, 1, 0.

Important: For even parity, the parity bit is selected so that the total number of 1s is even. For odd parity, it is selected so that the total number of 1s is odd.

7. XNOR Gate in Equality Comparison

An XNOR gate can compare two binary bits. Its output is HIGH when both bits are equal.

Example:

  • A = 1, B = 1 → Output = 1
  • A = 0, B = 0 → Output = 1
  • A = 1, B = 0 → Output = 0
  • A = 0, B = 1 → Output = 0

Multiple XNOR gates can be used to compare corresponding bits of two binary numbers. Their outputs can be combined using an AND gate to determine whether the complete numbers are equal.
