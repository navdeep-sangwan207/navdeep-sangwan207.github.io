2. What are Universal Gates?

A universal gate is a logic gate that can be used to implement any Boolean function without requiring any other type of logic gate.

The NAND and NOR gates are called universal gates because all basic logic operations can be constructed using only NAND gates or only NOR gates.

Important: NAND and NOR are functionally complete gates. Any combinational Boolean function can be implemented using either NAND-only or NOR-only logic.

Why are Universal Gates Important?

  • Reduce the number of different IC types required.
  • Simplify digital circuit implementation.
  • Support modular logic design.
  • Help implement complex Boolean expressions.
  • Are useful in digital IC design and hardware engineering.

3. NOT Gate Using NAND Gate

A NAND gate can operate as a NOT gate by connecting both its inputs together.

Boolean Derivation

Original NAND expression:

Y = (A · B)̅

Connect both inputs to A:

Y = (A · A)̅

Since A · A = A:

Y = A̅

4. AND Gate Using NAND Gates Only

An AND gate can be constructed using two NAND gates. The first NAND gate generates the complement of the AND operation. The second NAND gate works as an inverter to restore the original output.

Boolean Derivation

First NAND gate:

X = (A · B)̅

Second NAND gate, with both inputs connected to X:

Y = (X · X)̅

Therefore:

Y = X̅ = A · B

Number of NAND gates required: 2

5. OR Gate Using NAND Gates Only

An OR gate can be constructed using three NAND gates. First, invert both inputs using two NAND gates. Then connect the inverted inputs to a third NAND gate.

Boolean Derivation

Invert input A:

A̅ = (A · A)̅

Invert input B:

B̅ = (B · B)̅

Third NAND gate:

Y = (A̅ · B̅)̅

Using De Morgan's theorem:

Y = A + B

Number of NAND gates required: 3

6. NOT Gate Using NOR Gate

A NOR gate can be used as an inverter by connecting both inputs together.

Boolean Derivation

Original NOR expression:

Y = (A + B)̅

Connect both inputs to A:

Y = (A + A)̅

Since A + A = A:

Y = A̅

7. OR Gate Using NOR Gates Only

An OR gate can be implemented using two NOR gates. The first NOR gate produces the complement of OR. The second NOR gate works as an inverter.

Boolean Derivation

First NOR gate:

X = (A + B)̅

Second NOR gate:

Y = (X + X)̅

Therefore:

Y = X̅ = A + B

8. AND Gate Using NOR Gates Only

An AND gate can be implemented using three NOR gates. First, invert both inputs using two NOR gates. Then connect the inverted signals to a third NOR gate.

Boolean Derivation

Invert input A:

A̅ = (A + A)̅

Invert input B:

B̅ = (B + B)̅

Third NOR gate:

Y = (A̅ + B̅)̅

Using De Morgan's theorem:

Y = A · B

11. Practical Experiment: Basic Gates Using NAND IC 7400

Objective

To implement NOT, AND and OR functions using only NAND gates and verify their truth tables.

Required Components

  • IC 7400
  • 5V regulated supply
  • Breadboard and jumper wires
  • Input switches or logic input sources
  • LEDs and suitable current-limiting resistors

IC 7400 Pin Connections

7Ground
1, 2Gate 1 inputs

Implementation Plan

  1. NOT: Connect input A to both pins 1 and 2. Output is available at pin 3.
  2. AND: Use gate 1 for NAND. Connect its output to both inputs of gate 2. The final AND output is available at pin 6.
  3. OR: Use gate 1 and gate 2 as inverters for inputs A and B. Connect their outputs to gate 3. The final OR output is available at pin 8.
Safety and wiring: Use valid logic levels for every input. Do not leave unused inputs floating. Connect LEDs through suitable resistors and stay within the IC's output-current specifications. Verify the actual pinout and supply requirements using the datasheet.

Expected Result

The NAND-only circuits should produce the same truth tables as their corresponding NOT, AND and OR functions.

15. Lesson Summary

  • NAND and NOR are universal logic gates.
  • Any Boolean function can be implemented using NAND-only logic.
  • Any Boolean function can also be implemented using NOR-only logic.
  • NOT can be implemented using one NAND or one NOR gate.
  • AND requires two NAND gates in the standard implementation.
  • OR requires two NOR gates in the standard implementation.
  • De Morgan's theorems help derive universal gate circuits.
  • IC 7400 is a common NAND gate IC.
  • IC 7402 is a common NOR gate IC.
