Lesson 2: AND, OR and NOT Gates

Chapter 2 – Logic Gates and Boolean Algebra

1. Learning Objectives

  • Understand the operation of AND, OR and NOT gates.
  • Write Boolean expressions for basic gates.
  • Construct and interpret truth tables.
  • Understand logic gate symbols.
  • Learn practical applications of basic logic gates.
  • Identify commonly used AND, OR and NOT gate ICs.

2. AND Gate

An AND gate is a digital logic gate that produces logic 1 at its output only when all its inputs are logic 1.

Boolean Expression

Y = A · B

Here, A and B are inputs and Y is the output. The dot represents the logical AND operation.

Logic Symbol

Truth Table of AND Gate

A B Y = A · B
000
010
100
111
Remember: AND gate output is HIGH only when all inputs are HIGH.

Practical Example: Two-Switch Control

Consider a system in which a machine operates only when both the safety switch and the start switch are activated.

Let:

  • A = Safety condition satisfied
  • B = Start switch activated
  • Y = Machine enabled
Y = A · B

Applications of AND Gate

  • Digital control systems.
  • Enable and permission circuits.
  • Address decoding.
  • Data masking.
  • Digital arithmetic circuits.

3. OR Gate

An OR gate produces logic 1 at its output when at least one of its inputs is logic 1. Its output is 0 only when all inputs are 0.

Boolean Expression

Y = A + B

The plus sign represents the logical OR operation, not ordinary arithmetic addition.

Logic Symbol

Truth Table of OR Gate

A B Y = A + B
000
011
101
111
Remember: OR gate output is HIGH when at least one input is HIGH.

Practical Example: Alarm System

Consider an alarm system that activates when either a smoke sensor or a heat sensor detects a dangerous condition.

  • A = Smoke detected
  • B = High temperature detected
  • Y = Alarm activated
Y = A + B

Applications of OR Gate

  • Alarm and warning systems.
  • Interrupt request logic.
  • Fault detection circuits.
  • Control signal combination.
  • Digital decision-making circuits.

4. NOT Gate

A NOT gate is a single-input logic gate that produces the complement or inverse of its input.

It is also called an inverter.

Boolean Expression

Y = A̅

The bar above A represents logical inversion.

Logic Symbol

Truth Table of NOT Gate

Input A Output Y = A̅
01
10
Remember: NOT gate always produces the opposite logic state of its input.

Practical Example: Active-Low Signal

Suppose a control signal is HIGH when a system is inactive. An inverter can generate an active-HIGH signal when the system becomes active.

  • A = System inactive signal
  • Y = System active signal
Y = A̅

Applications of NOT Gate

  • Signal inversion.
  • Active-low to active-high conversion.
  • Complement generation.
  • Digital control circuits.
  • Logic circuit implementation.

5. Comparison of AND, OR and NOT Gates

Parameter AND OR NOT
Inputs Two or more Two or more One
Output HIGH All inputs HIGH At least one HIGH Input LOW
Output LOW At least one LOW All inputs LOW Input HIGH
Expression A · B A + B A̅

6. Practical Logic Gate ICs

Basic logic gates are available in standard 74-series integrated circuits.

IC Number Function Gate Quantity
7408 AND Gate Four 2-input gates
7432 OR Gate Four 2-input gates
7404 NOT Gate Six inverters
Practical note: The 7408, 7432 and 7404 are common 74-series TTL part numbers. Verify the exact IC variant, supply voltage and pinout using its datasheet. Do not leave unused logic inputs floating.

7. Combined Logic Gate Example

Consider a circuit in which two conditions must be satisfied, but a separate disable signal can turn the output OFF.

The Boolean expression is:

Y = (A · B) · C̅

Where:

  • A and B are required conditions.
  • C is a disable signal.
  • Y becomes HIGH only when A = 1, B = 1 and C = 0.

10. Lesson Summary

  • AND gate produces HIGH only when all inputs are HIGH.
  • OR gate produces HIGH when at least one input is HIGH.
  • NOT gate produces the complement of its input.
  • Boolean expressions represent the operation of logic gates.
  • Truth tables show all possible input-output combinations.
  • IC 7408 contains four 2-input AND gates.
  • IC 7432 contains four 2-input OR gates.
  • IC 7404 contains six NOT gates.
