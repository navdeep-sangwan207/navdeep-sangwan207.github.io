2. Introduction to Boolean Algebra

Boolean algebra is a mathematical system used to represent and simplify logical operations in digital electronics.

It was developed by George Boole and is based on two possible values:

  • 0: FALSE or LOW logic level.
  • 1: TRUE or HIGH logic level.

Basic Boolean Operations

Operation Symbol Meaning Logic Gate
AND A · B Both inputs must be 1 AND
OR A + B At least one input must be 1 OR
NOT A̅ Complement of input NOT
Important: In Boolean algebra, the symbols + and · represent logical OR and logical AND, respectively. They do not represent ordinary arithmetic addition and multiplication.

3. Identity Laws

The identity laws state that combining a Boolean variable with a particular constant does not change its value.

A + 0 = A
A · 1 = A

Explanation

  • OR with 0 leaves the variable unchanged.
  • AND with 1 leaves the variable unchanged.

Truth Table

A A + 0 A · 1
000
111

Example

F = A + 0

Therefore, F = A.

F = B · 1

Therefore, F = B.

4. Null or Domination Laws

The null laws state that a Boolean constant can determine the output regardless of the other input.

A + 1 = 1
A · 0 = 0

Truth Table

A A + 1 A · 0
010
110

Example

F = A + 1

Since OR with 1 always gives 1:

F = 1

5. Idempotent Laws

The idempotent laws state that applying the same Boolean variable repeatedly does not change its value.

A + A = A
A · A = A

Truth Table

A A + A A · A
000
111

Example

F = A + A + A

Using the idempotent law:

F = A

6. Complement Laws

The complement of a Boolean variable is its opposite logical value.

A + A̅ = 1
A · A̅ = 0

Truth Table

A A̅ A + A̅ A · A̅
0110
1010
A variable ORed with its complement always produces 1, while a variable ANDed with its complement always produces 0.

7. Involution or Double Complement Law

Taking the complement of a complemented variable gives the original variable.

(A̅)̅ = A

Example

F = ((A̅)̅)

Applying the double complement law:

F = A

8. Commutative Laws

The commutative laws state that changing the order of Boolean variables does not change the result.

A + B = B + A
A · B = B · A

Example

F = A + B

By the commutative law:

F = B + A

9. Associative Laws

The associative laws state that changing the grouping of Boolean variables does not change the result.

(A + B) + C = A + (B + C)
(A · B) · C = A · (B · C)

Example

F = (A · B) · C

By the associative law:

F = A · (B · C)

10. Distributive Laws

The distributive laws allow one Boolean operation to be distributed over another.

A · (B + C) = A · B + A · C
A + (B · C) = (A + B) · (A + C)

Example 1: AND Distributed Over OR

F = A · (B + C)

Expanding:

F = A · B + A · C

Example 2: OR Distributed Over AND

F = A + (B · C)

Expanding:

F = (A + B) · (A + C)

11. Absorption Laws

Absorption laws help remove redundant terms from Boolean expressions.

A + A · B = A
A · (A + B) = A

Derivation 1

F = A + A · B

Taking A as a common factor:

F = A · (1 + B)

Using the null law, 1 + B = 1:

F = A · 1 = A

Derivation 2

F = A · (A + B)

Using the distributive law:

F = A · A + A · B

Using the idempotent law:

F = A + A · B

Using the absorption law:

F = A

12. Redundancy or Covering Laws

These identities help eliminate unnecessary terms in Boolean expressions.

A + A̅ · B = A + B
A · (A̅ + B) = A · B

Derivation 1

F = A + A̅ · B

Using distributive law:

F = (A + A̅) · (A + B)

Using complement law:

F = 1 · (A + B) F = A + B

Derivation 2

F = A · (A̅ + B)

Using distributive law:

F = A · A̅ + A · B

Using complement law:

F = 0 + A · B F = A · B

13. Boolean Expression Simplification Examples

Example 1

Given: F = A + A · B

Using absorption law:

F = A

Example 2

Given: F = A · B + A · B̅

Taking A common:

F = A · (B + B̅)

Using complement law:

F = A · 1 F = A

Example 3

Given: F = (A + B) · (A + B̅)

Using the distributive law:

F = A · A + A · B̅ + A · B + B · B̅

Using idempotent and complement laws:

F = A + A · B̅ + A · B

Using absorption:

F = A

Example 4

Given: F = A · B + A̅ · B

Taking B common:

F = B · (A + A̅)

Using complement law:

F = B · 1 F = B

14. Boolean Algebra Laws – Quick Reference

15. Applications of Boolean Algebra

  • Digital logic circuit simplification.
  • Combinational circuit design.
  • Processor and controller design.
  • Arithmetic logic unit (ALU) implementation.
  • Memory and control logic design.
  • Embedded system hardware design.
  • Reducing logic gates, circuit complexity and hardware cost.

18. Lesson Summary

  • Boolean algebra operates on binary values 0 and 1.
  • AND, OR and NOT are the fundamental Boolean operations.
  • Identity, null, idempotent and complement laws simplify expressions.
  • Commutative and associative laws change ordering and grouping.
  • Distributive laws expand or factor Boolean expressions.
  • Absorption and redundancy laws remove unnecessary terms.
  • Boolean algebra is essential for efficient digital circuit design.
