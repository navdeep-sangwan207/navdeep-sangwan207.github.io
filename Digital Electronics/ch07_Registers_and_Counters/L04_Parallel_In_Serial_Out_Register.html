2. What Is a PISO Register?

PISO stands for Parallel-In Serial-Out. It is a type of shift register in which multiple bits are loaded simultaneously, but the stored data is shifted out one bit at a time.

A PISO register is useful when parallel data must be transmitted through a serial data line.

A PISO register performs parallel-to-serial conversion. It accepts a complete binary word at its parallel inputs and transmits that word sequentially through its serial output.

3. Construction of a 4-Bit PISO Register

A four-bit PISO register generally uses four D flip-flops and input-selection logic. The selection logic determines whether each flip-flop receives parallel input data or shifted data.

The functional circuit includes:

  • Four parallel data inputs: P3, P2, P1 and P0.
  • Four D flip-flops for storing the data bits.
  • Selection logic for parallel loading or shifting.
  • A common clock signal.
  • A load/shift control signal.
  • One serial data output.
The illustration is a conceptual register representation, not a complete gate-level circuit. A practical implementation needs multiplexers or equivalent logic at the flip-flop inputs, with a defined shift direction and control polarity.

4. Operating Modes of a PISO Register

A typical PISO register supports two main operations: parallel loading and shifting.

1. Parallel Load Mode

In parallel load mode, all input bits are transferred into their respective flip-flops simultaneously at the active clock edge.

2. Shift Mode

In shift mode, the stored bits move one position at each active clock edge. The bit at the serial-output stage leaves the register.

Operation Function
Parallel Load Loads multiple input bits simultaneously.
Shift Moves stored data toward the serial output.

5. Working Principle

Consider a four-bit PISO register with parallel input data 1011.

Assume the register is designed to shift toward the right, with Q0 providing the serial output. The operating sequence is:

  1. Apply the four parallel input bits.
  2. Select parallel load mode.
  3. Apply the active clock edge to load 1011.
  4. Select shift mode.
  5. Apply successive clock edges to shift out the bits.
In this example, Q0 is the first output bit. The selected shift direction determines the order in which the remaining bits appear.

6. Step-by-Step Operation of a 4-Bit PISO Register

The parallel input is 1011, where P3 = 1, P2 = 0, P1 = 1 and P0 = 1. The register shifts right, with Q0 as the serial output. Serial input during shifting is assumed to be 0.

Operation Q3 Q2 Q1 Q0 Serial Output
Parallel Load 1 0 1 1 –
Shift 1 0 1 0 1 1
Shift 2 0 0 1 0 1
Shift 3 0 0 0 1 0
Shift 4 0 0 0 0 1
Serial Output Sequence = 1101

The output sequence is the reverse of the displayed parallel word because Q0 is transmitted first in this right-shift arrangement.

7. Control Logic and Next-State Equations

A typical PISO register uses a mode-control signal to select between parallel loading and shifting.

Let L = 1 represent parallel load and L = 0 represent shift mode. Let SI be the serial input used during shifting.

For a four-bit register shifting right toward Q0:

D3 = L·P3 + L̅·SI
D2 = L·P2 + L̅·Q3
D1 = L·P1 + L̅·Q2
D0 = L·P0 + L̅·Q1

The serial output is taken from Q0. These equations assume the shift direction and mode-control convention described above.

The equations describe the D inputs of the flip-flops. All four flip-flops capture their selected input values simultaneously at the active clock edge.

8. Timing and Data Transfer

Parallel loading transfers all bits into the register at one active clock edge. Serial transmission then requires one clock edge per output bit.

For a four-bit word, four serial output bits require four shift clock edges.

If the shift clock frequency is 2 kHz:

Clock Period = 1 / 2000 = 0.5 ms
Four Shift Periods = 4 × 0.5 = 2 ms

Thus, the four-bit word takes four shift-clock intervals to be transmitted, excluding any additional setup or control overhead.

9. Advantages of PISO Registers

  • Converts parallel data into serial data.
  • Reduces the number of data lines needed for transmission.
  • Loads multiple bits simultaneously.
  • Useful for serial communication systems.
  • Can simplify wiring between digital devices.

10. Disadvantages of PISO Registers

  • Serial transmission takes multiple clock cycles.
  • Requires load and shift control logic.
  • Data must be loaded before serial transmission.
  • Output order depends on the selected shift direction.

11. Applications of PISO Registers

  • Parallel-to-serial data conversion.
  • Serial communication transmitters.
  • Microcontroller input/output expansion.
  • Reducing the number of communication wires.
  • Data transmission in digital systems.
  • Keyboard and switch input scanning circuits.
  • Embedded and industrial control systems.

12. SIPO vs PISO Register

Parameter SIPO PISO
Full Form Serial-In Parallel-Out Parallel-In Serial-Out
Input Serial Parallel
Output Parallel Serial
Main Function Serial-to-parallel conversion Parallel-to-serial conversion
Typical Application Output expansion Input scanning and serial transmission

13. Practical Example

Problem

A four-bit PISO register is loaded with 1100. It shifts right and sends the least significant bit first through the serial output. Find the output sequence.

Solution

The parallel word is:

Q3Q2Q1Q0 = 1100

The serial output is taken from Q0 first.

Serial Output = 0011

Therefore, the transmitted sequence is 0, 0, 1, 1.
