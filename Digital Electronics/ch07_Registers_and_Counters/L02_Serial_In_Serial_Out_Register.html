2. What Is a SISO Register?

SISO stands for Serial-In Serial-Out. It is a type of shift register in which data enters one bit at a time and leaves one bit at a time.

A SISO register is constructed by connecting multiple flip-flops in cascade. The output of one flip-flop is connected to the input of the next flip-flop.

In a SISO register, data shifts from one flip-flop stage to the next whenever the specified active clock edge occurs.

3. Construction of a 4-Bit SISO Register

A 4-bit SISO register can be constructed using four edge-triggered D flip-flops. All flip-flops receive a common clock signal.

The connections are:

  • Serial input connects to the D input of the first flip-flop.
  • Q0 connects to the D input of the second flip-flop.
  • Q1 connects to the D input of the third flip-flop.
  • Q2 connects to the D input of the fourth flip-flop.
  • Q3 provides the serial output.
  • All flip-flops receive the same clock signal.

4. Working Principle

Consider a 4-bit SISO register initially cleared to 0000. Let the serial input sequence be 1, 0, 1, 1.

At every active clock edge:

  • The first flip-flop captures the new serial input bit.
  • The second flip-flop captures the previous Q0 value.
  • The third flip-flop captures the previous Q1 value.
  • The fourth flip-flop captures the previous Q2 value.
Q0(next) = Serial Input
Q1(next) = Q0
Q2(next) = Q1
Q3(next) = Q2

Here, next-state values are calculated simultaneously from the values immediately before the active clock edge.

5. Step-by-Step Operation of a 4-Bit SISO Register

Assume the register starts at 0000 and receives the serial data sequence 1011. The first bit entered is 1.

Clock Pulse Serial Input Q3 Q2 Q1 Q0 Register State
Initial – 0 0 0 0 0000
1 1 0 0 0 1 0001
2 0 0 0 1 0 0010
3 1 0 1 0 1 0101
4 1 1 0 1 1 1011
After four clock pulses, the register contains 1011. The first bit entered has reached the last stage and is available at the serial output.

6. Output Delay in a SISO Register

In a four-stage SISO register, the first input bit reaches the output after four active clock edges when the output is taken from the fourth stage.

If the clock frequency is 1 kHz:

Clock Period = 1 / Frequency
T = 1 / 1000 = 1 ms

Therefore, the first input bit reaches the fourth-stage output after four clock edges, approximately 4 ms from the start of the first active edge to the fourth active edge.

This is the clock-edge-to-clock-edge transfer delay. Actual propagation from a clock edge to a flip-flop output also includes the flip-flop's clock-to-Q delay.

7. Advantages of SISO Registers

  • Simple construction using D flip-flops.
  • Requires only one serial data input and one serial output.
  • Useful for serial data storage and transfer.
  • Requires fewer data connections than parallel interfaces.
  • Can be cascaded to increase storage length.

8. Disadvantages of SISO Registers

  • Data transfer takes multiple clock cycles.
  • Accessing all stored bits simultaneously is not possible through the serial output alone.
  • Longer registers require more clock cycles for data to reach the output.
  • Not suitable when immediate parallel data access is required.

9. Applications of SISO Registers

  • Serial data transfer systems.
  • Temporary serial data storage.
  • Digital communication interfaces.
  • Delay elements in digital circuits.
  • Serial data processing.
  • Shift-based digital operations.
  • Educational digital electronics experiments.

10. SISO Register vs PIPO Register

Parameter SISO PIPO
Full Form Serial-In Serial-Out Parallel-In Parallel-Out
Input One bit at a time Multiple bits simultaneously
Output One bit at a time Multiple bits simultaneously
Data Transfer Serial Parallel
Clock Cycles Multiple cycles for a multi-bit word One loading edge for a parallel word

11. Practical Example

Problem

A 4-bit SISO register is initially cleared. The serial input sequence is 1101. Determine the register contents after four active clock edges.

Solution

Clock Input Register State Q3Q2Q1Q0
Initial–0000
110001
210011
300110
411101
Final Register Contents = 1101

The first bit entered has reached Q3, while the latest bit is stored at Q0.

14. Lesson Summary

  • SISO means Serial-In Serial-Out.
  • Data enters and leaves one bit at a time.
  • A SISO register is constructed using cascaded flip-flops.
  • Each active clock edge shifts data to the next stage.
  • A four-stage register requires four clock edges for the first input bit to reach the fourth stage.
  • SISO registers are used in serial data transfer and digital delay applications.
