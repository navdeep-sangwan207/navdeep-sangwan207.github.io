2. What Is a Full Subtractor?

A full subtractor is a combinational logic circuit that subtracts two binary input bits while also considering a borrow received from the previous lower-order stage.

It has three inputs:

  • A: Minuend bit.
  • B: Subtrahend bit.
  • Bin: Borrow input from the previous stage.

It produces two outputs:

  • Difference (D): Result bit of the subtraction.
  • Borrow-out (Bout): Borrow passed to the next higher-order stage.
A full subtractor performs A − B − Bin. Unlike a half subtractor, it can accept a borrow input from a previous stage.
Inputs: A, B, Bin
Outputs: Difference (D), Bout

3. Binary Subtraction with Borrow Input

A full subtractor considers three bits during subtraction. The borrow input represents a borrow received from the previous lower-order bit position.

A B Bin Subtraction Difference Bout
0000 − 0 − 000
0010 − 0 − 111
0100 − 1 − 011
0110 − 1 − 101
1001 − 0 − 010
1011 − 0 − 100
1101 − 1 − 000
1111 − 1 − 111
The Difference is the least significant bit of the three-input subtraction result. Bout indicates whether the result requires borrowing from the next higher bit.

5. Boolean Expression for Difference

The Difference output is 1 when an odd number of the three input bits are 1.

D = A ⊕ B ⊕ Bin

Expanded sum-of-products expression:

D = A̅B̅Bin + A̅BBin̅ + AB̅Bin̅ + ABBin
Two cascaded XOR operations generate the Difference output of a full subtractor.

6. Boolean Expression for Borrow-out

Borrow-out is generated when the minuend bit A is insufficient to subtract B and Bin.

Bout = A̅B + A̅Bin + BBin

An alternative factored expression is:

Bout = A̅B + (A ⊕ B)̅Bin

Another equivalent expression is:

Bout = A̅B + (A̅ + B)Bin
These expressions describe the same borrow function. The first is the sum-of-products form obtained directly from the truth table.

7. Full Subtractor Block Diagram

The circuit accepts the minuend, subtrahend and borrow-in inputs, then generates Difference and Borrow-out.

8. Full Subtractor Using Two Half Subtractors

A full subtractor can be constructed using two half subtractors and one OR gate.

First Half Subtractor

Inputs: A and B

D1 = A ⊕ B
B1 = A̅B

Second Half Subtractor

Inputs: D1 and Bin

D = D1 ⊕ Bin
B2 = D1̅Bin

Final Borrow-out

The two borrow outputs are combined using an OR gate.

Bout = B1 + B2

Complete Expressions

D = A ⊕ B ⊕ Bin
Bout = A̅B + (A ⊕ B)̅Bin
The first half subtractor calculates A − B. The second subtracts Bin from the intermediate difference. The OR gate combines both borrow outputs.

9. Full Subtractor Using Logic Gates

One implementation using the two-half-subtractor method requires:

  • Two XOR gates.
  • Two NOT gates.
  • Two AND gates.
  • One OR gate.
Gate Quantity Purpose
XOR2Generate Difference

AND2Generate borrow terms
OR1Combine borrow terms

Common Digital ICs

  • 7486: XOR gates.
  • 7404: NOT gates.
  • 7408: AND gates.
  • 7432: OR gates.

10. Worked Example

Consider the following inputs:

A = 0, B = 1, Bin = 1

Step 1: Calculate Difference

D = A ⊕ B ⊕ Bin
D = 0 ⊕ 1 ⊕ 1 = 0

Step 2: Calculate Borrow-out

Bout = A̅B + A̅Bin + BBin
Bout = 1·1 + 1·1 + 1·1 = 1

Final Result

Difference = 0, Borrow-out = 1

The subtraction 0 − 1 − 1 requires a borrow from the next higher bit. The current difference bit is 0.

12. Multi-Bit Binary Subtraction

Multiple full subtractors can be connected to subtract multi-bit binary numbers.

The Borrow-out of one lower-order stage becomes the Borrow-in of the next higher-order stage.

Example: Subtracting Two 4-Bit Numbers

       1001
     - 0011
     -------
       0110

In a cascaded subtractor, each stage performs subtraction using its own input bits and the borrow received from the preceding stage.

Cascading full subtractors forms a multi-bit ripple-borrow subtractor.

14. Practical Experiment – Full Subtractor Using ICs

Components Required

  • 7486 XOR gate IC.
  • 7404 NOT gate IC.
  • 7408 AND gate IC.
  • 7432 OR gate IC.
  • Regulated supply compatible with the selected IC family.
  • Three input switches.
  • Two LEDs with current-limiting resistors.
  • Breadboard and connecting wires.

Basic IC Pin Connections

7486 XOR IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 and Pin 2 – First XOR inputs.
  • Pin 3 – First XOR output (D1).
  • Pin 4 and Pin 5 – Second XOR inputs.
  • Pin 6 – Difference output.

7404 NOT IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 – A input.
  • Pin 2 – Complemented A output.
  • Pin 3 – D1 input for the second inverter.
  • Pin 4 – Complemented D1 output.

7408 AND IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 and Pin 2 – First AND inputs.
  • Pin 3 – First borrow output (B1).
  • Pin 4 and Pin 5 – Second AND inputs.
  • Pin 6 – Second borrow output (B2).

7432 OR IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 and Pin 2 – Borrow inputs B1 and B2.
  • Pin 3 – Final Borrow-out.

Procedure

  1. Connect the ICs to their appropriate supply and common ground.
  2. Connect A and B to the first XOR gate.
  3. Connect the first XOR output D1 and Bin to the second XOR gate.
  4. Observe the second XOR output as Difference.
  5. Generate B1 = A̅B using a NOT and AND gate.
  6. Generate B2 = D1̅Bin using a NOT and AND gate.
  7. Connect B1 and B2 to the OR gate.
  8. Observe the OR output as Borrow-out.
  9. Apply all eight input combinations and verify the truth table.
The pin numbers above refer to common 14-pin 74xx DIP devices. Verify the exact manufacturer's datasheet and logic-family requirements before wiring. Keep every input at a defined logic level and respect output-current limits.
