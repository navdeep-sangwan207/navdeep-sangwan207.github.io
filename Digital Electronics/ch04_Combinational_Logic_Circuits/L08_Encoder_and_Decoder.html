2. What Is an Encoder?

An encoder is a combinational logic circuit that converts an active input line into a coded binary output.

For a basic encoder with 2ⁿ input lines, the output generally contains n binary bits, assuming only one input is active at a time.

An encoder converts information from one of several input lines into a compact binary code.

Example

A 4-to-2 encoder has four input lines and two output bits.

4 Inputs → 2 Binary Outputs

3. Encoder Block Diagram

The encoder receives one active input and produces its corresponding binary code at the output.

4. 4-to-2 Binary Encoder

A 4-to-2 encoder has four input lines: D0, D1, D2 and D3.

Its two outputs are A1 and A0. The output represents the binary index of the active input.

Truth Table

D0 D1 D2 D3 A1 A0
100000
010001
001010
000111
This basic encoder assumes exactly one input is HIGH at a time. If multiple inputs are HIGH, the output may not represent a unique input.

5. Boolean Expressions for 4-to-2 Encoder

From the truth table, the output A1 is HIGH when D2 or D3 is active.

A1 = D2 + D3

The output A0 is HIGH when D1 or D3 is active.

A0 = D1 + D3

These equations assume a one-hot input condition: exactly one of D0–D3 is active.

6. Priority Encoder

A priority encoder is an encoder that assigns priority to input lines.

If more than one input is active simultaneously, the encoder produces the binary code of the highest-priority active input.

Priority encoders solve the multiple-active-input problem of a basic encoder.

Example: 4-to-2 Priority Encoder

Assume D3 has the highest priority, followed by D2, D1 and D0.

D3 D2 D1 D0 A1 A0 Valid
1XXX111
01XX101
001X011
0001001
0000XX0

X represents a don't-care input because its value does not affect the selected higher-priority input.

The Valid output indicates whether at least one input is active.

7. What Is a Decoder?

A decoder is a combinational logic circuit that converts an n-bit binary input into one of up to 2ⁿ output lines.

For a basic active-HIGH decoder, one output becomes HIGH for each valid binary input combination.

A decoder performs the reverse type of operation compared with an encoder: it converts a binary code into an individual output selection.

9. 2-to-4 Decoder

A 2-to-4 decoder has two binary inputs, A1 and A0, and four outputs, Y0 to Y3.

Truth Table

A1 A0 Y0 Y1 Y2 Y3
001000
010100
100010
110001
Only one output is HIGH for each input combination in this basic active-HIGH decoder.

10. Boolean Expressions for 2-to-4 Decoder

Each output represents one minterm of the two inputs.

Y0 = A1̅ · A0̅
Y1 = A1̅ · A0
Y2 = A1 · A0̅
Y3 = A1 · A0

Each output is selected by exactly one binary input combination.

11. 2-to-4 Decoder Using Logic Gates

A basic active-HIGH 2-to-4 decoder can be implemented using:

  • Two NOT gates.
  • Four AND gates.
Output Logic Expression
Y0A1̅A0̅
Y1A1̅A0
Y2A1A0̅
Y3A1A0
The NOT gates generate the complemented input signals. Each AND gate detects one unique binary input combination.

12. 3-to-8 Decoder

A 3-to-8 decoder has three binary inputs and eight output lines.

  • Inputs: A2, A1 and A0.
  • Outputs: Y0 to Y7.
  • Number of outputs: 2³ = 8.

Truth Table

A2 A1 A0 Active Output
000Y0
001Y1
010Y2
011Y3
100Y4
101Y5
110Y6
111Y7
The 74138 is a commonly used 3-to-8 decoder IC. It has active-LOW outputs and multiple enable inputs.

13. Encoder vs Decoder

14. Common Encoder and Decoder ICs

IC Number Function
74147 10-to-4 priority encoder (decimal-to-BCD, active-LOW logic)
74148 8-to-3 priority encoder (active-LOW logic)
74138 3-to-8 decoder
74139 Dual 2-to-4 decoder
74154 4-to-16 decoder
ICs may use active-LOW inputs or outputs and may include enable pins. Always verify the exact manufacturer's datasheet before circuit design.

15. Applications of Encoders and Decoders

Encoder Applications

  • Keyboard and keypad encoding.
  • Interrupt priority handling.
  • Rotary encoder signal processing.
  • Data compression into binary codes.
  • Digital control systems.

Decoder Applications

  • Memory address decoding.
  • Seven-segment display interfacing.
  • Device selection in microprocessor systems.
  • Digital display systems.
  • Control signal generation.
  • Microcontroller peripheral selection.

16. Worked Examples

Example 1: Encoder

In a 4-to-2 encoder, suppose D2 is the only active input.

D2 = 1

The binary output is:

A1A0 = 10

Example 2: Decoder

In a 2-to-4 decoder, suppose the inputs are:

A1 = 1, A0 = 1

The selected output is:

Y3 = 1

All other outputs are LOW.

17. Practical Experiment – 3-to-8 Decoder Using 74138

Components Required

  • 74138 decoder IC.
  • Regulated supply compatible with the selected IC.
  • Three input switches.
  • Enable control connections.
  • Logic indicators or LEDs with suitable interface circuitry.
  • Breadboard and connecting wires.

Procedure

  1. Identify the 74138 pin configuration from its datasheet.
  2. Connect VCC and GND according to the selected device.
  3. Configure its enable inputs to activate the decoder.
  4. Connect the three binary input switches.
  5. Observe the eight output lines using suitable logic indicators.
  6. Apply input combinations from 000 to 111.
  7. Record which output becomes active for each combination.
The 74138 has active-LOW outputs. The selected output goes LOW, while the non-selected outputs remain HIGH. Its enable conditions must also be satisfied. Verify all connections using the manufacturer's datasheet.

20. Lesson Summary

  • An encoder converts an active input into a binary code.
  • A decoder converts a binary input into an output selection.

  • A 2-to-4 decoder has two inputs and four outputs.
  • A 3-to-8 decoder has three inputs and eight outputs.

  • 74138 is a common 3-to-8 decoder IC.
