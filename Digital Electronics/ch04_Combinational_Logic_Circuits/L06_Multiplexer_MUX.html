2. What Is a Multiplexer?

A multiplexer (MUX) is a combinational logic circuit that selects one input from multiple data inputs and forwards the selected input to a single output.

The selection is controlled by select lines, also called selection inputs.

A multiplexer is also called a data selector because it selects one of several input signals and connects it to a common output.

Basic Multiplexer Structure

  • Data inputs: Signals available for selection.
  • Select lines: Determine which input is selected.
  • Output: Carries the selected input value.
For 2ⁿ data inputs, n select lines are required.

4. 2:1 Multiplexer

A 2:1 multiplexer selects one of two data inputs using one select line.

Inputs and Output

  • D0 – First data input.
  • D1 – Second data input.
  • S – Select line.
  • Y – Output.

Boolean Expression

Y = S̅D0 + SD1
When S = 0, the output is D0. When S = 1, the output is D1.

5. 2:1 MUX Logic Gate Implementation

A 2:1 multiplexer can be implemented using:

  • One NOT gate.
  • Two AND gates.
  • One OR gate.

The two AND gates generate S̅D0 and SD1. The OR gate combines these terms to produce the selected output.

6. 4:1 Multiplexer

A 4:1 multiplexer selects one of four data inputs and forwards it to a single output.

Inputs

  • D0, D1, D2 and D3 – Four data inputs.
  • S1 and S0 – Two select lines.
  • Y – Output.

Selection Table

S1 S0 Selected Input Output
00D0D0
01D1D1

Boolean Expression

Y = S1̅S0̅D0 + S1̅S0D1
+ S1S0̅D2 + S1S0D3
Two select lines provide four possible binary combinations, allowing one of four inputs to be selected.

7. 8:1 and 16:1 Multiplexers

8:1 Multiplexer

  • Eight data inputs: D0 to D7.
  • Three select lines: S2, S1 and S0.
  • One output: Y.
Number of select lines = log₂(8) = 3

16:1 Multiplexer

  • Sixteen data inputs: D0 to D15.
  • Four select lines: S3, S2, S1 and S0.
  • One output: Y.
Number of select lines = log₂(16) = 4

8. Multiplexer as a Universal Logic Function Generator

A multiplexer can be used to implement Boolean functions by connecting suitable constants or variables to its data inputs and using variables as select lines.

Example: Implement XOR Using a 4:1 MUX

Required Boolean function:

Y = A ⊕ B

Use A and B as the two select lines. Connect the data inputs as follows:

A B Selected Input Data Input Value
00D00
01D11
10D21
11D30
D0 = 0, D1 = 1, D2 = 1, D3 = 0
The output follows the XOR truth table. This demonstrates how a multiplexer can implement a Boolean function.

12. Practical Experiment – 4:1 Multiplexer

Components Required

  • 74153 dual 4:1 multiplexer IC.
  • Regulated supply compatible with the selected IC.
  • Four data input switches for one MUX section.
  • Two select input switches.
  • Enable control connection.
  • LED with suitable current-limiting resistor.
  • Breadboard and connecting wires.

Procedure

  1. Identify the selected 74153 IC and consult its datasheet.
  2. Connect VCC and GND according to the datasheet.
  3. Enable the required multiplexer section using its enable input.
  4. Connect D0, D1, D2 and D3 to defined logic levels.
  5. Connect S1 and S0 to the select switches.
  6. Connect the output to a suitable logic indicator.
  7. Change the select inputs through 00, 01, 10 and 11.
  8. Verify that the output follows the selected data input.
The 74153 has active-low enable inputs. For the selected section to operate, its enable input must be asserted LOW. Follow the exact datasheet pinout. Do not leave data or select inputs floating.

15. Lesson Summary

  • A multiplexer selects one input from multiple data inputs.
  • Select lines determine which data input reaches the output.
  • A 2:1 MUX requires one select line.
  • A 4:1 MUX requires two select lines.
  • An 8:1 MUX requires three select lines.
  • A 16:1 MUX requires four select lines.
  • A 2:1 MUX expression is Y = S̅D0 + SD1.
  • Multiplexers can implement Boolean functions.
  • Common ICs include 74157, 74153, 74151 and 74150.
