2. What Is a Half Adder?

A half adder is a combinational logic circuit used to add two single-bit binary numbers.

It has two inputs, A and B, and two outputs:

  • Sum (S): The least significant bit of the addition result.
  • Carry (C): The carry generated when both input bits are 1.
A half adder adds two binary bits but does not accept a carry input from a previous stage.
Inputs: A, B
Outputs: Sum (S), Carry (C)

3. Binary Addition Rules

The four basic binary addition rules are:

Operation Sum Carry
0 + 000
0 + 110
1 + 010
1 + 101

Example: 1 + 1

   1
 + 1
 ---
  10

The result is binary 10. Therefore, Sum = 0 and Carry = 1.

4. Half Adder Truth Table

A half adder has two binary inputs, so it produces four possible input combinations.

A B Sum (S) Carry (C)
0000
0110
1010
1101
Notice that the Sum output is 1 when the inputs are different, while the Carry output is 1 only when both inputs are 1.

5. Boolean Expression for Sum

From the truth table, Sum is HIGH for these input combinations:

  • A = 0, B = 1
  • A = 1, B = 0

Therefore, the Sum expression is:

S = A̅B + AB̅

This is the XOR operation:

S = A ⊕ B
The XOR gate produces HIGH output when its two inputs are different.

6. Boolean Expression for Carry

From the truth table, Carry is HIGH only when both A and B are 1.

C = A · B

Therefore, the Carry output is generated using an AND gate.

7. Half Adder Logic Circuit

A half adder can be implemented using two logic gates:

  • One XOR gate for Sum.
  • One AND gate for Carry.
Both gates receive the same two inputs. The XOR gate generates Sum, and the AND gate generates Carry.

8. Half Adder Using Logic Gates

Output Logic Gate Boolean Expression
Sum XOR S = A ⊕ B
Carry AND C = A · B

Common Digital ICs

  • 7486: Quad two-input XOR gate IC.
  • 7408: Quad two-input AND gate IC.

These ICs can be used together to build a practical half adder circuit.

9. Worked Example

Consider the inputs:

A = 1, B = 1

Step 1: Calculate Sum

S = A ⊕ B = 1 ⊕ 1 = 0

Step 2: Calculate Carry

C = A · B = 1 · 1 = 1

Final Result

Carry = 1, Sum = 0

The binary result is 10.

10. Limitations of a Half Adder

  • It accepts only two input bits.
  • It does not have a carry input.
  • It cannot directly add three bits.
  • It cannot independently handle the carry from a previous addition stage.
A full adder overcomes the carry-input limitation by accepting three inputs: A, B and carry-in (Cin).

11. Applications of Half Adders

  • Basic binary arithmetic circuits.
  • Arithmetic Logic Units (ALUs).
  • Digital calculators.
  • Adder circuit design.
  • Educational digital logic experiments.
  • First stage of some multi-bit adder designs.

12. Practical Experiment – Half Adder Using ICs

Components Required

  • 7408 AND gate IC.
  • 7486 XOR gate IC.
  • 5 V regulated DC supply compatible with the selected IC family.
  • Two input switches.
  • Two LEDs with suitable current-limiting resistors.
  • Breadboard and connecting wires.

Basic IC Connections

For 7486 XOR IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 – Input A.
  • Pin 2 – Input B.
  • Pin 3 – XOR output (Sum).

For 7408 AND IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 – Input A.
  • Pin 2 – Input B.
  • Pin 3 – AND output (Carry).

Procedure

  1. Connect both ICs to the regulated supply and common ground.
  2. Connect input A to pin 1 of both ICs.
  3. Connect input B to pin 2 of both ICs.
  4. Observe the XOR output at pin 3 of 7486.
  5. Observe the AND output at pin 3 of 7408.
  6. Apply all four possible input combinations.
  7. Compare the observed outputs with the truth table.
Use defined logic levels for both inputs; do not leave unused CMOS or TTL inputs floating. Check the exact manufacturer's datasheet, supply limits and output-current ratings. Connect LEDs through suitable resistors and use a compatible output-driving arrangement.

15. Lesson Summary

  • A half adder adds two single-bit binary numbers.
  • It has two inputs: A and B.
  • It has two outputs: Sum and Carry.
  • Sum is generated using an XOR gate.
  • Carry is generated using an AND gate.
  • Boolean expressions: S = A ⊕ B and C = A · B.
  • It cannot accept a carry input from a previous stage.
  • A full adder is used when a carry input is required.
