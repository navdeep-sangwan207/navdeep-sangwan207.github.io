Lesson 4: Half Subtractor

Chapter 4 – Combinational Logic Circuits

1. Learning Objectives

  • Understand the operation of a half subtractor.
  • Learn the difference and borrow outputs.
  • Construct the half subtractor truth table.
  • Derive Boolean expressions for difference and borrow.
  • Understand implementation using XOR, NOT and AND gates.
  • Learn practical applications and limitations.

2. What Is a Half Subtractor?

A half subtractor is a combinational logic circuit that subtracts one single-bit binary number from another single-bit binary number.

It has two inputs:

  • A: Minuend – the bit from which another bit is subtracted.
  • B: Subtrahend – the bit being subtracted.

It produces two outputs:

  • Difference (D): The result of the subtraction.
  • Borrow (Bout): Indicates whether a borrow is required from the next higher bit.
A half subtractor performs A − B. It does not accept a borrow input from a previous stage.
Inputs: A, B
Outputs: Difference (D), Borrow (Bout)

3. Binary Subtraction Rules

The basic binary subtraction rules are:

Operation Difference Borrow
0 − 000
0 − 111
1 − 010
1 − 100

Example: 0 − 1

A cannot directly subtract 1 from 0 in unsigned single-bit subtraction. It borrows from the next higher position. 

   10₂
 - 01₂
 -----
   01₂

For the current bit, Difference = 1 and Borrow = 1.

4. Half Subtractor Truth Table

Two binary inputs produce four possible combinations.

A B Difference (D) Borrow (Bout)
0000
0111
1010
1100
Difference is 1 when A and B are different. Borrow is 1 only when A = 0 and B = 1.

5. Boolean Expression for Difference

From the truth table, Difference is HIGH when the two inputs are different.

D = A̅B + AB̅

This is the XOR operation:

D = A ⊕ B
The difference output of a half subtractor is identical to the sum output of a half adder.

6. Boolean Expression for Borrow

Borrow is generated only when A = 0 and B = 1.

Bout = A̅B

This can be implemented using a NOT gate on A followed by an AND gate with B.

7. Half Subtractor Logic Circuit

A half subtractor requires:

  • One XOR gate for Difference.
  • One NOT gate to complement A.
  • One AND gate to generate Borrow.
The circuit diagram represents the Boolean functions: D = A ⊕ B and Bout = A̅B. The complemented A signal is used only in the borrow path.

8. Half Subtractor Using Logic Gates

Output Logic Gate Boolean Expression
Difference XOR D = A ⊕ B
Borrow NOT and AND Bout = A̅B

Common Digital ICs

  • 7486: Quad two-input XOR gate IC.
  • 7404: Hex inverter (NOT gate) IC.
  • 7408: Quad two-input AND gate IC.

9. Worked Example

Consider the following inputs:

A = 0, B = 1

Step 1: Calculate Difference

D = A ⊕ B = 0 ⊕ 1 = 1

Step 2: Calculate Borrow

Bout = A̅B = 1 · 1 = 1

Final Result

Difference = 1, Borrow = 1

10. Half Adder vs Half Subtractor

Parameter Half Adder Half Subtractor
Operation Addition Subtraction
Inputs A, B A, B
First Output Sum Difference
Second Output Carry Borrow
First Output Equation A ⊕ B A ⊕ B
Second Output Equation AB A̅B
Carry/Borrow Input Not available Not available
Both circuits use XOR for their first output. Their second outputs are different: AND generates carry in a half adder, while A̅B generates borrow in a half subtractor.

11. Limitations of a Half Subtractor

  • It subtracts only two single-bit inputs.
  • It does not accept a borrow input from a previous stage.
  • It cannot directly perform multi-bit subtraction on its own.
  • It must be extended with a borrow-input stage for multi-bit subtraction.
A full subtractor overcomes this limitation by accepting three inputs: A, B and borrow-in (Bin).

12. Applications of Half Subtractors

  • Basic binary subtraction circuits.
  • Arithmetic Logic Units (ALUs).
  • Digital calculators.
  • Subtractor circuit design.
  • Digital arithmetic learning and experimentation.

13. Practical Experiment – Half Subtractor Using ICs

Components Required

  • 7486 XOR gate IC.
  • 7404 NOT gate IC.
  • 7408 AND gate IC.
  • Regulated 5 V supply compatible with the selected IC family.
  • Two input switches.
  • Two LEDs with suitable current-limiting resistors.
  • Breadboard and connecting wires.

Basic IC Connections

7486 XOR IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 and Pin 2 – Inputs A and B.
  • Pin 3 – Difference output.

7404 NOT IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 – Input A.
  • Pin 2 – Complemented A output.

7408 AND IC:

  • Pin 14 – VCC.
  • Pin 7 – GND.
  • Pin 1 – Complemented A input.
  • Pin 2 – Input B.
  • Pin 3 – Borrow output.

Procedure

  1. Connect all ICs to the appropriate supply and common ground.
  2. Connect A and B to the XOR gate inputs.
  3. Connect A to the NOT gate input.
  4. Connect the NOT output and B to the AND gate.
  5. Observe the XOR output as Difference.
  6. Observe the AND output as Borrow.
  7. Apply all four input combinations.
  8. Verify the outputs against the truth table.
Ensure all inputs have defined logic levels. Check the IC datasheets for exact pinouts, voltage ratings and output-current limits. Use current-limiting resistors for LEDs.

16. Lesson Summary

  • A half subtractor performs A − B.
  • It has two inputs: A and B.
  • It produces Difference and Borrow outputs.
  • Difference = A ⊕ B.
