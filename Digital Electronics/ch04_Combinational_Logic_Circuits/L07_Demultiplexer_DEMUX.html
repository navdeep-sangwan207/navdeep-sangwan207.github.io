2. What Is a Demultiplexer?

A demultiplexer (DEMUX) is a combinational logic circuit that accepts a single data input and routes it to one of several output lines.

The output line is selected using selection inputs. Only the selected output receives the input data; the other outputs remain LOW in the basic active-high implementation.

A demultiplexer is also called a data distributor because it distributes one input signal to one of multiple output lines.

Basic DEMUX Structure

  • Data input (D): Signal to be distributed.
  • Select lines: Choose the destination output.
  • Outputs: Lines that receive the selected input.
For 2ⁿ outputs, n select lines are required.

4. 1:2 Demultiplexer

A 1:2 demultiplexer routes one data input to one of two outputs using a single select line.

Inputs and Outputs

  • D – Data input.
  • S – Select line.
  • Y0 – First output.
  • Y1 – Second output.

Selection Operation

Select S Y0 Y1
0D0
10D

Boolean Expressions

Y0 = D · S̅
Y1 = D · S
When S = 0, the input D appears at Y0. When S = 1, the input D appears at Y1.

6. 1:2 DEMUX Using Logic Gates

A 1:2 demultiplexer can be implemented using:

  • One NOT gate.
  • Two AND gates.

The inverter generates S̅. The first AND gate generates Y0 = D·S̅, while the second AND gate generates Y1 = D·S.

7. 1:4 Demultiplexer

A 1:4 demultiplexer routes one data input to one of four outputs using two select lines.

Inputs and Outputs

  • D – Single data input.
  • S1 and S0 – Select lines.
  • Y0, Y1, Y2 and Y3 – Four output lines.

Selection Table

S1 S0 Selected Output
00Y0
01Y1
10Y2
11Y3

Boolean Expressions

Y0 = D · S1̅ · S0̅
Y1 = D · S1̅ · S0
Y2 = D · S1 · S0̅
Y3 = D · S1 · S0
Each output is enabled by one unique combination of the select lines.

10. Demultiplexer vs Multiplexer

Parameter Multiplexer Demultiplexer
Function Selects one input Distributes one input
Data Inputs Multiple One
Outputs One Multiple
Operation Many-to-one One-to-many
Common Name Data selector Data distributor
Example 4:1 MUX 1:4 DEMUX
A multiplexer combines several possible data sources into one selected output. A demultiplexer routes one input to a selected destination.

11. Demultiplexer ICs

IC Number Function
74139 Dual 1:4 decoder/demultiplexer
74138 3-to-8 decoder, usable for data distribution
74154 4-to-16 decoder/demultiplexer
Decoder ICs such as 74138 and 74154 can perform demultiplexing when their enable inputs are used appropriately as data controls. Their output polarity and enable conditions must be checked in the datasheet.

12. Applications of Demultiplexers

  • Data distribution in digital communication systems.
  • Address decoding and memory selection.
  • Routing control signals to different devices.
  • Serial-to-parallel data distribution arrangements.
  • Microprocessor and microcontroller interfacing.
  • Selection of output devices in digital systems.
  • Communication channel distribution.
  • Digital control systems.

14. Practical Experiment – DEMUX Using 74139

Components Required

  • 74139 dual 1:4 decoder/demultiplexer IC.
  • Regulated supply compatible with the IC.
  • Data input switch.
  • Two select switches.
  • Enable control connection.
  • LED indicators with suitable current-limiting resistors.
  • Breadboard and connecting wires.

Procedure

  1. Identify the exact 74139 IC pin configuration using its datasheet.
  2. Connect VCC and GND according to the datasheet.
  3. Connect the data input to the enable control as specified for the selected section.
  4. Connect the two select inputs.
  5. Connect the four outputs to suitable logic indicators.
  6. Apply the select combinations 00, 01, 10 and 11.
  7. Observe the selected output for each combination.
Important: The 74139 has active-LOW enable inputs and active-LOW outputs. It is a decoder/demultiplexer with inverted output logic. Do not interpret its outputs as the active-HIGH outputs shown in the basic DEMUX truth table. Use the datasheet to verify enable polarity and output behavior.
