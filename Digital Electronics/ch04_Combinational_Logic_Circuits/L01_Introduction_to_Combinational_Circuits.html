2. What Is a Combinational Logic Circuit?

A combinational logic circuit is a digital circuit in which the output depends only on the present combination of input signals.

It does not store previous input information. Its outputs are determined by Boolean logic operations performed on the current inputs.

Definition: A combinational circuit is a logic circuit whose output is a function of its current inputs only.
Y = f(A, B, C, ...)

Here, A, B and C are input variables, Y is the output, and f represents the Boolean function.

3. Basic Block Diagram

A combinational circuit receives digital inputs and processes them through logic gates to produce outputs.

The circuit processes all input combinations according to its Boolean function and generates the corresponding output.

4. Characteristics of Combinational Circuits

  1. No memory: They do not store previous input values.
  2. No feedback required: Basic combinational designs do not depend on output feedback.
  3. Current input dependent: Outputs depend on present inputs.
  4. Logic gate based: Built using gates such as AND, OR, NOT, NAND and XOR.
  5. No clock requirement: They do not require a clock for state updates.
  6. Propagation delay: Outputs change after a finite gate propagation delay.
  7. Truth table representation: Their behavior can be described using truth tables.
Combinational circuits have no memory of previous inputs, but their outputs are not necessarily instantaneous. Gate propagation delay must be considered in real hardware.

5. Boolean Expression of a Combinational Circuit

Boolean expressions describe the logical relationship between input variables and output variables.

Example: Two-Input AND Circuit

Y = A · B

The output is HIGH only when both inputs are HIGH.

7. Design Procedure for Combinational Circuits

The general design process includes:

  1. Understand the problem statement.
  2. Identify the required input variables.
  3. Identify the required output variables.
  4. Construct the truth table.
  5. Derive the Boolean expression.
  6. Simplify the Boolean expression.
  7. Draw the logic circuit using suitable gates.
  8. Verify the output for all input combinations.

9. Combinational vs Sequential Circuits

10. Propagation Delay

Propagation delay is the time taken by a logic circuit to respond to a change in its input and produce the corresponding output change.

It occurs because practical logic gates require a finite amount of time to switch their outputs.

Types of Propagation Delay

  • tPLH: Delay when output changes from LOW to HIGH.
  • tPHL: Delay when output changes from HIGH to LOW.
Propagation delay is important in high-speed digital circuits. A combinational circuit may produce temporary glitches during transitions because different signal paths can have different delays.

15. Lesson Summary

  • A combinational circuit produces outputs based on present inputs.
  • It does not store previous input information.
  • It is constructed using logic gates.
  • Its behavior can be represented by truth tables and Boolean expressions.
  • The number of input combinations is 2ⁿ.
  • Common circuits include adders, subtractors, MUX, DEMUX, encoders and decoders.
  • Propagation delay is an important practical characteristic.
  • Combinational circuits are widely used in processors and embedded systems.
