Lesson 06: Flash ADC, Resolution and Quantization Error

Learn the working of flash ADCs, comparator banks, resistor ladder networks, thermometer codes, ADC resolution, quantization levels and quantization error.

1. Introduction to Flash ADC

A Flash ADC, also called a parallel ADC, is a high-speed analog-to-digital converter. It uses multiple comparators to compare an analog input voltage with several reference levels simultaneously.

The comparator outputs form a code that is converted into a binary number by an encoder.

A basic n-bit flash ADC requires 2ⁿ − 1 comparators. All comparisons occur in parallel, making this architecture extremely fast.

Applications

  • High-speed data acquisition.
  • Digital oscilloscopes.
  • Radar and communication receivers.
  • Video signal processing.
  • High-speed instrumentation.

2. Block Diagram of Flash ADC

A basic flash ADC contains:

  • Resistor ladder network.
  • Multiple comparators.
  • Priority encoder or thermometer-code encoder.
  • Digital output.
The diagram is conceptual. A practical resistor ladder creates reference thresholds, and each comparator receives the analog input and one corresponding threshold.

3. Working Principle of Flash ADC

  1. The resistor ladder generates equally spaced reference voltages.
  2. The analog input is applied to all comparators.
  3. Each comparator compares the input with its reference threshold.
  4. The comparator outputs form a thermometer code.
  5. The encoder converts this code into a binary output.

Why Is It Called a Parallel ADC?

All comparators evaluate their respective thresholds at approximately the same time. The ADC does not need to test each bit sequentially like a SAR ADC.

4. Number of Comparators Required

For an n-bit basic flash ADC, the number of output codes is 2ⁿ. The number of required comparators is:

Number of Comparators = 2ⁿ − 1
Resolution Output Codes Comparators
2-bit 4 3
3-bit 8 7
4-bit 16 15
8-bit 256 255
Comparator count grows exponentially with resolution. This is a major reason why basic flash ADCs are generally used at lower or moderate resolutions when very high conversion speed is required.

5. Thermometer Code

The outputs of the comparator bank form a thermometer code. As the input voltage increases, more comparators switch to the HIGH state.

For a 3-bit flash ADC, there are seven comparator thresholds. A simplified ideal thermometer-code sequence is shown below.

Number of Thresholds Crossed Thermometer Code
0 0000000
1 0000001
2 0000011
3 0000111
4 0001111
5 0011111
6 0111111
7 1111111

The bit ordering shown is illustrative. Actual comparator output polarity and bit ordering depend on the circuit.

Bubble Errors

Noise, comparator offset and timing differences can produce invalid thermometer patterns. For example, a pattern may contain a HIGH bit followed by a LOW bit in the expected transition region.

Practical encoders may use bubble correction techniques to improve reliable binary encoding.

6. ADC Resolution

Resolution indicates the smallest ideal input-voltage increment represented by one ADC code.

Number of Quantization Levels = 2ⁿ
Ideal LSB Size = Vref / 2ⁿ

Here, n is the number of output bits and Vref is the full-scale input range for a unipolar ADC whose range is 0 V to Vref.

Example: 8-bit ADC

Given:

  • Resolution = 8 bits.
  • Reference voltage = 5 V.
  • Input range = 0 V to 5 V.
Number of Levels = 2⁸ = 256
LSB = 5 / 256
LSB = 0.01953125 V

Therefore, the ideal voltage step is approximately 19.53 mV per code.

Resolution Comparison

12-bit 4096 1.221 mV
16-bit 65536 76.29 µV

7. Quantization Process

Quantization is the process of mapping a continuous analog input voltage to one of a finite number of digital levels.

An ADC cannot represent every possible analog voltage. It assigns the input to a digital code corresponding to a quantization interval.

Quantization Steps

  1. The ADC receives an analog input voltage.
  2. The input is compared with available quantization thresholds.
  3. The nearest applicable output interval is selected according to the ADC transfer characteristic.
  4. The corresponding digital code is generated.
Quantization is different from sampling. Sampling discretizes time, while quantization discretizes amplitude.

8. Quantization Error

Quantization error is the difference between the actual analog input and the voltage represented by its digital code.

Quantization Error = Vin − Vrepresented

For an ideal uniform quantizer using midpoint reconstruction, the quantization error is bounded by:

−0.5 LSB ≤ Error ≤ +0.5 LSB

The sign convention depends on how error is defined. The maximum absolute ideal quantization error is approximately half an LSB under this reconstruction convention.

Example: 8-bit ADC with 5 V Reference

LSB size:

LSB = 5 / 256 = 19.53125 mV

Maximum ideal absolute quantization error:

Errormax = LSB / 2
Errormax = 9.765625 mV
This ±0.5 LSB bound applies to an ideal quantizer with midpoint reconstruction. A real ADC can have additional errors due to offset, gain, INL, DNL, noise and reference inaccuracies.

9. Solved Numerical Example

Problem

A 4-bit ADC has a 0–16 V input range. Determine the ideal output code and quantization error for an input voltage of 10.6 V, using midpoint reconstruction.

Step 1: Calculate LSB

LSB = 16 / 16 = 1 V

Step 2: Determine the Quantization Interval

An input of 10.6 V falls in the interval:

10 V ≤ Vin < 11 V

Step 3: Determine the Digital Code

The interval corresponds to decimal code 10.

Digital Code = 1010₂

Step 4: Calculate Represented Voltage

Using the midpoint of the interval:

Vrepresented = 10.5 V

Step 5: Calculate Quantization Error

Error = 10.6 − 10.5
Error = +0.1 V

10. Flash ADC vs SAR ADC

Feature Flash ADC SAR ADC
Conversion Method Parallel comparison Successive approximation
Comparators 2ⁿ − 1 in a basic n-bit design Typically one main comparator
Speed Extremely high Moderate to high
Hardware Large comparator bank DAC, comparator and SAR logic
Power Often high Often lower
Typical Use High-speed acquisition Embedded measurement systems

11. Other ADC Error Parameters

11.1 Offset Error

Offset error is the deviation of the actual ADC transfer characteristic from its ideal position near zero input.

11.2 Gain Error

Gain error is the deviation in the slope of the transfer characteristic after accounting for offset error.

11.3 Integral Nonlinearity (INL)

INL describes the deviation of actual transition levels from a chosen ideal reference line after accounting for offset and gain, according to the datasheet's definition.

11.4 Differential Nonlinearity (DNL)

DNL describes the difference between an actual code width and one ideal LSB.

11.5 Missing Codes

A missing code occurs when an ADC never produces one or more digital output codes over its specified input range.

11.6 Signal-to-Noise Ratio (SNR)

SNR compares the signal power with noise power. It is commonly expressed in decibels.

15. Lesson Summary

  • Flash ADC is a high-speed parallel ADC architecture.
  • It uses a resistor ladder and multiple comparators.
  • A basic n-bit flash ADC requires 2ⁿ − 1 comparators.
  • Comparator outputs form a thermometer code.
  • An encoder converts the comparator pattern into binary.
  • Resolution determines the number of available output codes.
  • Ideal LSB size is the input range divided by 2ⁿ.
  • Quantization maps analog amplitudes to discrete digital codes.
  • Ideal quantization error is bounded by ±0.5 LSB with midpoint reconstruction.
  • Real ADCs also have offset, gain, INL, DNL and noise errors.
