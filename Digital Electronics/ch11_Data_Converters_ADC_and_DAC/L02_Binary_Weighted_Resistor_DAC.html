Lesson 02: Binary Weighted Resistor DAC

Learn the construction, working principle, circuit operation, output voltage equation, advantages, limitations and numerical problems of a binary weighted resistor digital-to-analog converter.

1. Introduction

A Binary Weighted Resistor DAC is a digital-to-analog converter that uses resistors having binary weighted resistance values to convert a digital binary input into an analog output voltage.

The resistor values are selected according to powers of two. For an n-bit DAC, the resistor branches commonly use values such as:

R, 2R, 4R, 8R, 16R, ...

Each digital input bit controls a switch that connects its resistor branch to a reference voltage or ground. The resulting currents are combined using an operational amplifier configured as an inverting summing amplifier.

The most significant bit (MSB) contributes the largest current, while the least significant bit (LSB) contributes the smallest current.

2. Construction of Binary Weighted Resistor DAC

A typical 4-bit binary weighted resistor DAC contains:

  • Four digital input bits: D3, D2, D1 and D0.
  • Four binary weighted resistors.
  • Four electronic switches.
  • A reference voltage source (Vref).
  • An operational amplifier.
  • A feedback resistor (Rf).

3. Working Principle

Each input bit controls a switch. When a bit is HIGH, its resistor branch is connected to the reference voltage. When it is LOW, its branch is connected to ground.

Since the resistors have different values, each HIGH bit contributes a different current to the summing node.

Current Contribution

  • MSB branch with resistance R contributes the largest current.
  • Next branch with resistance 2R contributes half that current.
  • Next branch with resistance 4R contributes one-fourth.
  • LSB branch with resistance 8R contributes one-eighth.

The operational amplifier combines these currents and converts their sum into an output voltage.

Vout = −Rf × (I3 + I2 + I1 + I0)

The negative sign indicates that the output polarity is inverted by the inverting summing amplifier.

4. Output Voltage Equation

For an ideal inverting summing amplifier, the output voltage is:

Vout = −Rf × (D3Vref/R + D2Vref/2R + D1Vref/4R + D0Vref/8R)

Taking Vref/R common:

Vout = −(RfVref/R) (D3 + D2/2 + D1/4 + D0/8)

Where:

  • Vout = Analog output voltage.
  • Vref = Reference voltage.
  • Rf = Feedback resistance.
  • R = Base resistance.
  • D3 = Most significant digital input bit.
  • D0 = Least significant digital input bit.
Each D input is either 0 or 1. The equation assumes an ideal op-amp, an ideal reference voltage and switches with negligible resistance.

5. Numerical Example

Problem

A 4-bit binary weighted resistor DAC has the following parameters:

  • Vref = 5 V
  • R = 10 kΩ
  • Rf = 10 kΩ
  • Digital input = 1010

Calculate the analog output voltage.

Solution

Given digital input:

D3 = 1, D2 = 0, D1 = 1, D0 = 0

Using the output equation:

Vout = −(RfVref/R) (D3 + D2/2 + D1/4 + D0/8)

Substituting the values:

Vout = −(10k × 5 / 10k) (1 + 0/2 + 1/4 + 0/8)
Vout = −5 × 1.25
Vout = −6.25 V

Answer: The ideal analog output is −6.25 V.

The op-amp must have sufficient supply-voltage range to produce this output. If its supply rails do not permit −6.25 V, the output will saturate and the calculated value cannot be obtained.

6. Digital Input and Output Relationship

For a 4-bit DAC with Rf = R and the stated inverting configuration, the ideal output is:

Vout = −Vref × (D3 + D2/2 + D1/4 + D0/8)
Digital Input Decimal Value Ideal Output for Vref = 5 V
0000 0 0 V
0001 1 −0.625 V
0010 2 −1.25 V
0011 3 −1.875 V
0100 4 −2.5 V
1000 8 −5 V
1111 15 −9.375 V

The output changes in equal steps for successive binary input codes in this ideal circuit.

7. Advantages

  • Simple operating principle.
  • Fast conversion can be achieved with suitable components.
  • Easy to understand and analyze mathematically.
  • Provides a direct weighted-current conversion method.

8. Disadvantages and Limitations

  • Requires a wide range of accurately matched resistor values.
  • Resistor tolerance affects conversion accuracy and linearity.
  • High-resolution designs require difficult resistor matching.
  • Switch resistance and op-amp limitations introduce errors.
  • Output voltage range may require additional supply rails or a different amplifier configuration.
The major limitation is the difficulty of maintaining accurate binary weighted resistor ratios as the number of bits increases.

9. Applications

  • Basic digital-to-analog conversion experiments.
  • Educational electronics laboratory circuits.
  • Low-resolution waveform generation.
  • Simple programmable analog voltage circuits.
  • Understanding weighted-current DAC architectures.

10. Binary Weighted DAC vs R-2R Ladder DAC

Feature Binary Weighted DAC R-2R Ladder DAC
Resistor Values R, 2R, 4R, 8R, etc. Only R and 2R values
Resistor Matching Requires a wide range of resistor ratios Requires accurate matching of R and 2R
High Resolution More difficult to implement Generally more practical
Circuit Structure Weighted resistor branches Resistor ladder network
Typical Use Basic and low-resolution designs Practical DAC architectures

12. Practice Problems

Problem 1

A 4-bit binary weighted DAC has Rf = R and Vref = 5 V. Calculate the output for input 1100.

Answer:

Vout = −5 × (1 + 1/2) = −7.5 V

Problem 2

Calculate the output for input 0011 when Vref = 4 V and Rf = R.

Answer:

Vout = −4 × (1/4 + 1/8) = −1.5 V

Problem 3

What happens to the current contribution when the branch resistance is doubled while the reference voltage remains constant?

Answer: The current is reduced to half, according to Ohm's law.

Problem 4

Why is an R-2R ladder DAC generally preferred over a binary weighted resistor DAC for higher-resolution designs?

Answer: It uses only two resistor values, R and 2R, making resistor matching and integrated-circuit implementation more practical.

13. Lesson Summary

  • Binary weighted resistor DAC converts binary data into analog output.
  • Resistor values follow binary weighting: R, 2R, 4R and 8R.
  • Each input bit controls a switch.
  • The MSB contributes the largest current.
  • An op-amp summing circuit combines the weighted currents.
  • The inverting configuration produces a negative output.
  • Resistor matching is a major limitation at higher resolutions.
  • R-2R ladder DACs use only two resistor values.
