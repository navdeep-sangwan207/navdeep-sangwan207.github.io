Lesson 01: Introduction to ADC and DAC

Understand analog and digital signals, the need for data conversion, ADC and DAC operation, conversion systems and their applications in embedded electronics.

1. Introduction to Data Conversion

Electronic systems interact with two major types of signals: analog signals and digital signals.

Physical quantities such as temperature, pressure, light intensity and sound are naturally represented by continuously varying analog signals.

Digital circuits and microcontrollers process information using discrete binary values, generally represented by logic 0 and logic 1.

Therefore, conversion circuits are required to exchange information between the analog and digital domains.

Data conversion: The process of converting information from analog form to digital form or from digital form to analog form.

2. Analog Signals

An analog signal is a continuously varying signal that can represent a range of values over time.

Characteristics

  • Amplitude can vary continuously within a range.
  • Time representation is generally continuous.
  • Can represent real-world physical quantities.
  • May be affected by noise and interference.

Examples

  • Temperature sensor output voltage.
  • Microphone output signal.
  • Pressure sensor voltage.
  • Light sensor analog output.
  • Battery voltage.

3. Digital Signals

A digital signal represents information using discrete signal levels. In binary digital systems, these levels are interpreted as logic 0 and logic 1.

Characteristics

  • Uses discrete logic levels.
  • Information is represented using binary data.
  • Can be processed by digital circuits and processors.
  • Supports digital storage and communication.
  • Can be regenerated to restore valid logic levels.
Logic HIGH and LOW voltage values depend on the digital logic family and device specifications. They are not universally fixed at 5 V and 0 V.

4. Why Are ADC and DAC Required?

A microcontroller cannot directly process a continuously varying analog voltage as an ordinary binary number. An ADC converts the analog input into a digital value.

Similarly, when a digital system needs to produce a continuously varying analog voltage or current, a DAC is used.

Practical Example: Temperature Monitoring

  1. A temperature sensor detects the surrounding temperature.
  2. The sensor produces an analog voltage.
  3. An ADC converts that voltage into a digital value.
  4. The microcontroller reads and processes the value.
  5. The digital system displays or stores the temperature.

Practical Example: Audio Output

  1. A digital audio file contains binary sample values.
  2. A DAC converts the digital samples into an analog signal.
  3. An amplifier increases the signal power.
  4. A speaker converts the electrical signal into sound.

5. Analog-to-Digital Converter (ADC)

An Analog-to-Digital Converter converts an analog input signal into a corresponding digital representation.

Basic ADC Block Diagram

Basic ADC Conversion Steps

  1. Sampling: The analog signal is measured at discrete time intervals.
  2. Quantization: Each sampled value is mapped to one of a finite number of digital levels.
  3. Encoding: The quantized level is represented using a binary code.

Important ADC Parameters

  • Resolution.
  • Sampling rate.
  • Conversion time.
  • Input voltage range.
  • Reference voltage.
  • Accuracy and linearity.
  • Quantization error.

6. Digital-to-Analog Converter (DAC)

A Digital-to-Analog Converter converts digital binary data into a corresponding analog voltage or current.

Basic DAC Block Diagram

DAC Applications

  • Audio playback systems.
  • Waveform generation.
  • Industrial process control.
  • Programmable voltage sources.
  • Signal generation equipment.
  • Motor control reference signals.

7. Difference Between ADC and DAC

Feature ADC DAC
Full Form Analog-to-Digital Converter Digital-to-Analog Converter
Conversion Analog to digital Digital to analog
Input Analog voltage or current Digital binary data
Output Digital code Analog voltage or current
Common Application Sensor interfacing Audio and waveform generation
Typical Use Measurement and data acquisition Analog signal generation and control

8. Introduction to Resolution

Resolution describes the number of discrete digital levels available in a converter.

For an ideal n-bit converter, the number of possible binary codes is:

Number of Digital Levels = 2n

Where n is the number of bits.

Examples

Resolution Number of Codes
8-bit 256
10-bit 1,024
12-bit 4,096
16-bit 65,536
Higher resolution provides more possible output codes, but does not automatically guarantee higher accuracy. Accuracy also depends on reference quality, noise, linearity and other converter specifications.

9. Applications in Embedded Systems

ADC Applications

  • Reading analog temperature sensors.
  • Measuring battery voltage.
  • Reading potentiometer positions.
  • Monitoring analog pressure sensors.
  • Acquiring analog signals for digital processing.

DAC Applications

  • Generating analog reference voltages.
  • Producing audio signals.
  • Generating test waveforms.
  • Controlling analog circuits.
  • Generating voltage or current setpoints.
Many microcontrollers include an internal ADC. A DAC may be integrated or provided through an external converter, depending on the microcontroller. PWM followed by a suitable low-pass filter can also approximate an analog output, but it is not a true DAC.

11. Practice Problems

Problem 1

Calculate the number of digital codes available in an 8-bit ADC.

Solution:

28 = 256 codes

Problem 2

How many possible codes are available in a 12-bit converter?

Solution:

212 = 4096 codes

Problem 3

Which converter is required to read the analog voltage generated by a temperature sensor?

Answer: ADC.

Problem 4

Which converter is used to generate an analog voltage from a digital value?

Answer: DAC.

Problem 5

A digital system contains a 10-bit DAC. How many different binary input codes can it accept?

Solution:

210 = 1024 codes

12. Lesson Summary

  • Analog signals vary continuously.
  • Digital signals use discrete logic levels.
  • ADC converts analog signals into digital codes.
  • DAC converts digital codes into analog signals.
  • ADC conversion involves sampling, quantization and encoding.
  • Resolution determines the number of available digital codes.
  • The number of codes for an n-bit converter is 2n.
  • ADCs are widely used for sensor interfacing.
  • DACs are used for analog signal generation and control.
