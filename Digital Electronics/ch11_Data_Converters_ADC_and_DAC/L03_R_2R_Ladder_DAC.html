Lesson 03: R-2R Ladder DAC

Understand the construction, working principle, resistor ladder network, output voltage equation, numerical problems and practical applications of the R-2R ladder digital-to-analog converter.

1. Introduction to R-2R Ladder DAC

An R-2R Ladder DAC is a digital-to-analog converter that uses a resistor network consisting of only two resistor values: R and 2R.

It converts a digital binary input into a proportional analog output voltage or current.

Unlike the binary weighted resistor DAC, which requires several different resistor values, the R-2R ladder uses a repeating resistor arrangement.

The main advantage of the R-2R ladder DAC is that it requires only two resistor values, making accurate resistor matching and integrated-circuit implementation more practical.

2. Construction of R-2R Ladder DAC

A typical R-2R ladder DAC contains:

  • A resistor network containing R and 2R resistors.
  • Digital input bits.
  • Electronic switches.
  • A reference voltage source.
  • An operational amplifier in common implementations.

Conceptual 4-Bit R-2R Ladder Network

This drawing illustrates the repeated R and 2R resistor pattern only. It is not a complete 4-bit DAC schematic. In a practical ladder, each bit controls a switch that selects Vref or ground, and the ladder is terminated appropriately and connected to an output or amplifier.

3. Working Principle

The R-2R ladder divides current or voltage according to the repeating resistor network.

Each digital input bit controls a switch:

  • Logic 1 connects the corresponding branch to Vref.
  • Logic 0 connects the corresponding branch to ground.

The ladder network produces binary weighted contributions from the individual input bits.

These contributions are combined to generate an analog output proportional to the digital input number.

Binary Weighting

Input Bit Position Ideal Weight
D3 MSB 1/2
D2 Second bit 1/4
D1 Third bit 1/8
D0 LSB 1/16
The weights above describe the common 4-bit, normalized R-2R DAC transfer function. The actual output polarity and gain depend on the circuit configuration.

4. Output Voltage Equation

For a common 4-bit inverting R-2R DAC with an ideal operational amplifier and Rf = R, the output is:

Vout = −Vref (D3/2 + D2/4 + D1/8 + D0/16)

For an n-bit DAC, the general equation for this inverting configuration is:

Vout = −Vref × (D(n−1)/2 + D(n−2)/4 + ... + D0/2ⁿ)

Where:

  • Vout = Analog output voltage.
  • Vref = Reference voltage.
  • D3 = Most significant bit.
  • D0 = Least significant bit.
  • Each digital bit has a value of 0 or 1.
The equation assumes the conventional inverting current-output ladder with an ideal virtual-ground summing node and feedback resistance Rf = R. Other ladder and buffer configurations can have different output polarity or scaling.

5. Numerical Example

Problem

A 4-bit R-2R ladder DAC has:

  • Vref = 8 V
  • Rf = R
  • Digital input = 1011

Calculate the analog output voltage.

Solution

Digital input:

D3 = 1, D2 = 0, D1 = 1, D0 = 1

Using the output equation:

Vout = −8 × (1/2 + 0/4 + 1/8 + 1/16)
Vout = −8 × 0.6875
Vout = −5.5 V

Answer: The ideal analog output is −5.5 V.

Problem 2

A 4-bit R-2R DAC has Vref = 5 V and input 1111. Find its ideal output when Rf = R.

Solution:

Vout = −5 × (1/2 + 1/4 + 1/8 + 1/16)
Vout = −5 × 15/16
Vout = −4.6875 V

6. Resolution of R-2R Ladder DAC

Resolution is the smallest ideal change in output caused by increasing the digital input code by one.

For an n-bit DAC using the normalized transfer function described above:

Ideal Step Size = Vref / 2ⁿ

For a 4-bit DAC with Vref = 5 V:

Step Size = 5 / 16 = 0.3125 V

The ideal output magnitude at code 1111 is:

15 × 0.3125 = 4.6875 V
The maximum code is 2ⁿ − 1, so the maximum ideal output magnitude is one step below Vref for this transfer function.

7. Advantages of R-2R Ladder DAC

  • Uses only two resistor values, R and 2R.
  • Suitable for integrated-circuit implementation.
  • Requires fewer distinct resistor values than a binary weighted DAC.
  • Provides predictable binary weighting.
  • Can be extended to different resolutions.
  • Offers a practical architecture for accurate resistor matching.

8. Disadvantages and Limitations

  • Resistor matching still affects accuracy and linearity.
  • Switch resistance can introduce conversion errors.
  • Parasitic capacitance can affect settling time.
  • Op-amp offset, bandwidth and output swing can limit performance.
  • Higher-resolution designs require careful layout and component matching.

9. Binary Weighted DAC vs R-2R Ladder DAC

Feature Binary Weighted DAC R-2R Ladder DAC
Resistor Values R, 2R, 4R, 8R, etc. Only R and 2R
Resistor Network Weighted branches Repeating ladder structure
Matching Wide range of resistor ratios Matching between two resistor values
High Resolution More difficult to implement Generally more practical
IC Implementation Less convenient for high resolution Well suited to integrated circuits

10. Applications

  • Digital waveform generation.
  • Audio signal conversion.
  • Programmable analog output circuits.
  • Digital control systems.
  • Function generators.
  • Embedded and instrumentation systems.

12. Practice Problems

Problem 1

A 4-bit R-2R DAC has Vref = 4 V and input 1001. Find the output voltage for Rf = R.

Answer:

Vout = −4 × (1/2 + 1/16) = −2.25 V

Problem 2

Calculate the ideal step size of an 8-bit DAC with Vref = 5 V.

Answer:

Step Size = 5 / 256 = 0.01953125 V

Approximately 19.53 mV.

Problem 3

How many digital input combinations are possible in a 10-bit R-2R DAC?

Answer:

2¹⁰ = 1024 combinations

13. Lesson Summary

  • R-2R ladder DAC converts digital input into analog output.
  • It uses only two resistor values: R and 2R.
  • Each input bit controls a reference or ground switch.
  • The ladder produces binary weighted contributions.
  • An op-amp is commonly used to convert the ladder current into voltage.
  • For the stated inverting configuration, output polarity is negative.
  • Ideal step size is Vref divided by 2ⁿ.
  • Resistor matching remains important for accuracy.
