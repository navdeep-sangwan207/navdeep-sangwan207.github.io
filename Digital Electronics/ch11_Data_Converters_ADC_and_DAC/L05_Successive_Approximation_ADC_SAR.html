Lesson 05: Successive Approximation ADC (SAR)

Understand the architecture and working of a SAR ADC, including its comparator, DAC, successive approximation register, conversion sequence, timing and numerical examples.

1. Introduction to SAR ADC

A Successive Approximation Register (SAR) ADC is a widely used analog-to-digital converter architecture. It converts an analog input voltage into a digital binary code by testing one bit at a time, starting with the most significant bit (MSB).

It uses a successive approximation process similar to a binary search.

A SAR ADC determines the digital output by repeatedly comparing the input voltage with the analog voltage generated by its internal DAC.

Common Applications

  • Microcontroller ADC peripherals.
  • Sensor measurement systems.
  • Battery monitoring.
  • Industrial control systems.
  • Data acquisition systems.
  • Portable instrumentation.

2. Block Diagram of SAR ADC

The main blocks of a typical SAR ADC are:

  • Sample-and-hold or input sampling circuit.
  • Comparator.
  • Internal DAC.
  • Successive Approximation Register (SAR).
  • Control and timing logic.
This is a conceptual functional diagram. Actual SAR ADCs may integrate the sampling network, DAC, comparator and control logic in different physical arrangements.

3. Main Components of SAR ADC

3.1 Sample-and-Hold Circuit

The input sampling circuit captures the analog input voltage and maintains it during the conversion process. This helps the comparator evaluate a stable input.

3.2 Comparator

The comparator compares the sampled input voltage with the DAC-generated trial voltage.

  • If Vin is greater than or equal to VDAC, the trial bit is retained.
  • If Vin is less than VDAC, the trial bit is cleared.

This describes a common SAR comparison convention. Exact equality and switching behavior depend on the converter implementation.

3.3 Internal DAC

The internal DAC converts the trial digital code generated by the SAR register into an analog voltage.

This voltage is fed back to the comparator for comparison with the sampled input.

3.4 SAR Register

The SAR register stores the trial code and updates one bit at a time according to the comparator output.

3.5 Control and Timing Logic

Control logic manages the conversion sequence, clock timing, register updates and conversion completion.

4. Working Principle of SAR ADC

A SAR ADC performs a sequence of comparisons, beginning with the MSB and proceeding toward the LSB.

Conversion Steps

  1. The analog input is sampled and held.
  2. The SAR register sets the MSB to 1 and other bits to 0.
  3. The internal DAC generates a trial voltage.
  4. The comparator compares the trial voltage with the input.
  5. If the trial voltage is acceptable, the bit is retained.
  6. Otherwise, the trial bit is cleared.
  7. The next lower bit is tested.
  8. The process continues until the LSB is evaluated.
  9. The final SAR register value becomes the digital result.
An ideal n-bit SAR conversion requires approximately n bit-decision steps after the input has been acquired. Actual conversion timing also includes acquisition, internal settling and control overhead.

5. Step-by-Step Numerical Example

Problem

Consider a 4-bit SAR ADC with:

  • Reference voltage = 8 V.
  • Analog input = 5.2 V.
  • Input range = 0 V to 8 V.

Determine the final digital output using the successive approximation method.

Step 1: Calculate the LSB Size

LSB = Vref / 2ⁿ
LSB = 8 / 16 = 0.5 V

Step 2: Test the MSB

Trial code = 1000.

VDAC = 8 × (8/16) = 4 V

Since 5.2 V is greater than 4 V, retain the MSB.

Step 3: Test the Next Bit

Trial code = 1100.

VDAC = 8 × (12/16) = 6 V

Since 5.2 V is less than 6 V, clear the second bit.

Step 4: Test the Third Bit

Trial code = 1010.

VDAC = 8 × (10/16) = 5 V

Since 5.2 V is greater than 5 V, retain the third bit.

Step 5: Test the LSB

Trial code = 1011.

VDAC = 8 × (11/16) = 5.5 V

Since 5.2 V is less than 5.5 V, clear the LSB.

Final Result

Digital Output = 1010₂
Decimal Code = 10

The ideal code represents the quantization interval from 5.0 V to below 5.5 V under this example's convention.

Step Trial Code DAC Voltage Decision
1 1000 4.0 V Retain MSB
2 1100 6.0 V Clear second bit
3 1010 5.0 V Retain third bit
4 1011 5.5 V Clear LSB

6. SAR ADC Conversion Timing

Each bit decision requires the DAC output to settle and the comparator to produce a reliable result. The SAR logic then updates the register.

A simplified conversion sequence for a 4-bit ADC is:

Decision Bit Tested Operation
1 MSB (D3) Test highest-weight bit
2 D2 Test next lower bit
3 D1 Test next lower bit
4 LSB (D0) Test lowest-weight bit
Ideal Bit Decisions = n

For a 12-bit SAR ADC, approximately 12 bit-decision steps are required for one conversion.

The conversion clock frequency does not necessarily equal the ADC sampling frequency. Acquisition time, conversion cycles and interface overhead determine the maximum conversion throughput.

Resolution is determined by the number of output bits.

8. Advantages of SAR ADC

  • Good balance between speed, resolution and power consumption.
  • Predictable conversion sequence.
  • Suitable for many embedded applications.
  • Generally lower power than many high-speed converter architectures.
  • Can provide moderate-to-high resolution.
  • Widely available as an integrated microcontroller peripheral.

9. Disadvantages and Limitations

  • Requires multiple bit-decision steps per conversion.
  • Generally slower than flash ADCs at comparable resolution.
  • DAC settling and comparator performance affect conversion speed.
  • Input acquisition time must be considered.
  • Reference voltage noise and input noise affect accuracy.
  • High-resolution performance requires careful circuit design.

10. SAR ADC vs Flash ADC

  • Motor control feedback systems.

12. SAR ADC in Embedded Systems

Many microcontrollers use SAR ADC peripherals to measure analog signals.

Typical Embedded ADC Workflow

  1. Configure the ADC peripheral.
  2. Select the analog input channel.
  3. Configure the reference and conversion clock.
  4. Start the conversion.
  5. Wait for conversion completion or handle an ADC interrupt.
  6. Read the digital result register.
  7. Convert the result into a voltage or physical measurement.

Example: ADC Voltage Calculation

A 10-bit ADC uses a 3.3 V reference and produces a digital code of 512.

Vin ≈ (512 / 1024) × 3.3
Vin ≈ 1.65 V

This is an ideal code-to-voltage estimate. Actual scaling should follow the microcontroller ADC datasheet and transfer characteristics.

15. Lesson Summary

  • SAR ADC converts analog input into a digital binary code.
  • It uses successive approximation beginning with the MSB.
  • The main blocks include a comparator, DAC and SAR register.
  • The comparator evaluates the trial DAC voltage against the input.
  • Each bit is retained or cleared according to the comparison.
  • An n-bit converter requires approximately n bit-decision steps.
  • Acquisition and settling time also affect total conversion time.
  • SAR ADCs are widely used in embedded systems and instrumentation.
