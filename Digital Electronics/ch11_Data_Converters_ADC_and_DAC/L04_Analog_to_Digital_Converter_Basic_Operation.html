Lesson 04: Analog-to-Digital Converter – Basic Operation

Learn ADC architecture, sampling, sample-and-hold, quantization, encoding, reference voltage, resolution, conversion time and practical ADC calculations.

1. Introduction to ADC

An Analog-to-Digital Converter (ADC) is an electronic circuit that converts an analog input voltage or current into a digital binary code.

Sensors and transducers generally produce analog signals. A microcontroller or digital processor uses digital representations of these signals for processing, storage and control.

An ADC acts as an interface between the analog environment and a digital processing system.

Examples of ADC Applications

  • Temperature measurement.
  • Battery voltage monitoring.
  • Pressure measurement.
  • Light intensity measurement.
  • Audio signal acquisition.
  • Industrial sensor monitoring.

2. Basic Block Diagram of ADC

A typical ADC signal path may contain signal conditioning, sampling circuitry, quantization and encoding.

Not every ADC has separate external blocks for all these functions. Sampling, quantization and encoding may be implemented within one integrated converter.

3. Signal Conditioning

Signal conditioning prepares the analog input for accurate conversion.

Common Signal Conditioning Functions

  • Amplification of small sensor signals.
  • Attenuation of signals exceeding the ADC input range.
  • Filtering unwanted noise.
  • Level shifting where required.
  • Protection against excessive input voltage.

Example

Suppose a sensor produces a voltage between 0 V and 1 V, while the ADC input range is 0 V to 5 V.

A suitable amplifier can scale the sensor output to use more of the ADC input range.

4. Sampling

Sampling is the process of measuring an analog signal at specific time intervals.

The continuous-time signal is represented by a sequence of sampled values.

Sampling Diagram

Sampling Frequency

Sampling frequency is the number of samples taken per second.

fs = 1 / Ts

Where:

  • fs = Sampling frequency in hertz.
  • Ts = Sampling period in seconds.

Nyquist Sampling Theorem

For an ideal band-limited signal with maximum frequency fmax, the sampling frequency must be greater than twice the highest signal frequency for theoretical reconstruction:

fs > 2 × fmax
In practical systems, an anti-aliasing filter is used before sampling. The sampling rate is generally selected with additional margin above the theoretical minimum.

Aliasing

Aliasing occurs when a signal is sampled too slowly. High-frequency components can then appear as lower frequencies in the sampled data.

5. Sample-and-Hold Circuit

A sample-and-hold circuit captures the instantaneous analog input voltage and holds it approximately constant for a specified period.

Two Operating Modes

  • Sample mode: The circuit follows or captures the input signal.
  • Hold mode: The captured voltage is maintained while conversion takes place.

Basic Block Diagram

A separate sample-and-hold circuit is not required in every ADC. Many modern ADCs integrate sampling circuitry internally.

6. Quantization

Quantization is the process of assigning each sampled analog value to one of a finite number of discrete amplitude levels.

An n-bit ADC provides:

Number of Levels = 2ⁿ

The analog input is mapped to one of the available digital output codes.

Quantization Example

Consider an ideal 3-bit ADC with an input range from 0 V to 8 V.

The number of codes is:

2³ = 8 codes

Using the ideal transition interval:

LSB = 8 / 8 = 1 V
Input Voltage Interval Digital Code
0 V to below 1 V 000
1 V to below 2 V 001
2 V to below 3 V 010
3 V to below 4 V 011
4 V to below 5 V 100
5 V to below 6 V 101
6 V to below 7 V 110
7 V to 8 V 111
This table uses an ideal uniform quantizer with 8 equal-width input intervals over a 0–8 V range. Real ADC transition levels and endpoint behavior depend on the converter architecture and datasheet.

7. Encoding

Encoding represents the quantized level using a binary digital code.

For example, in a 3-bit ADC:

Quantized Level 5 = Binary Code 101

The resulting binary code can be read by a digital processor, stored in memory or used in a control system.

8. Reference Voltage (Vref)

Reference voltage defines the voltage scale against which the ADC input is converted.

The ADC input range may be determined by a reference voltage, supply voltage or device-specific input limits.

Example

If an ADC uses a 5 V reference and accepts an input range from 0 V to 5 V, the digital code represents the input voltage relative to that range.

The ADC input must remain within the electrical limits specified by the device datasheet. Applying an excessive voltage can damage the input or cause incorrect conversion.

9. ADC Resolution and LSB Size

For an ideal n-bit ADC with a unipolar input range from 0 V to Vref, the nominal quantization interval is commonly calculated as:

LSB Size = Vref / 2ⁿ

This is the ideal input-voltage interval represented by one code step under the stated convention.

Numerical Example

Given:

  • ADC resolution = 8 bits.
  • Reference voltage = 5 V.

Number of codes:

2⁸ = 256

LSB size:

LSB = 5 / 256
LSB = 0.01953125 V

Answer: Approximately 19.53 mV per code interval.

The largest output code of an 8-bit ADC is 255, not 256. The ideal code intervals are 5/256 V wide under this convention; the maximum code multiplied by the LSB is 255/256 of the reference.

10. Quantization Error

Quantization error is the difference between the actual sampled input and the representative value assigned to its digital code.

For an ideal uniform quantizer using the midpoint of each quantization interval as its representative value, the maximum quantization error magnitude is:

Maximum Quantization Error = ±0.5 LSB

For an ideal 8-bit ADC with a 5 V reference:

Maximum Error = ±(19.53125 / 2) mV
Maximum Error ≈ ±9.77 mV
This is the ideal quantization error. Actual ADC measurement error can be larger because of offset, gain error, nonlinearity, noise and reference error.

11. Important ADC Parameters

Parameter Description
Resolution Number of digital bits or available codes.
Sampling Rate Number of samples taken per second.
Conversion Time Time required to complete one conversion.
Reference Voltage Voltage used to define the conversion scale.
Accuracy How closely the conversion result represents the actual input.
Offset Error Deviation from the ideal zero-input output.
Gain Error Difference in the slope of the actual and ideal transfer functions.
INL Integral nonlinearity; deviation from the ideal transfer line.
DNL Differential nonlinearity; deviation of code width from one ideal LSB.
Input Bandwidth Frequency range over which the ADC can meet specified performance.

12. Conversion Time

Conversion time is the time taken by an ADC to produce a digital result after a conversion is initiated.

Conversion time depends on the ADC architecture, clock frequency, resolution and device implementation.

Conversion time and sampling rate are related but are not identical. A converter may have additional acquisition, settling or recovery time between conversions.

13. Solved Numerical Problems

Problem 1: Number of Digital Codes

Find the number of digital codes available in a 10-bit ADC.

2¹⁰ = 1024 codes

Problem 2: LSB Size

Calculate the LSB size of a 12-bit ADC with a 3.3 V reference.

LSB = 3.3 / 4096
LSB ≈ 0.0008057 V

Approximately 0.806 mV.

Problem 3: Sampling Period

An ADC samples a signal at 10 kHz. Calculate its sampling period.

Ts = 1 / fs
Ts = 1 / 10000 = 0.0001 s

Answer: 100 microseconds.

Problem 4: Nyquist Sampling Rate

A band-limited input signal has a maximum frequency of 4 kHz. What is the theoretical minimum sampling rate for ideal reconstruction?

fs > 2 × 4 kHz

The sampling rate must be greater than 8 kHz. Practical systems generally use a higher rate and an anti-aliasing filter.

Problem 5: Maximum Ideal Quantization Error

Find the maximum ideal quantization error of an 8-bit ADC with Vref = 5 V.

LSB = 5 / 256 = 19.53125 mV
Error = ±0.5 LSB ≈ ±9.77 mV

14. Practical Embedded System Example

Reading a Sensor with a Microcontroller

  1. A sensor generates an analog voltage.
  2. The signal is conditioned and filtered if necessary.
  3. The ADC samples the input voltage.
  4. The ADC converts the sampled value into a binary code.
  5. The microcontroller reads the conversion result.
  6. Software scales the result into a useful physical quantity.

Example: 10-Bit ADC Reading

A 10-bit ADC uses a 3.3 V reference and returns a digital code of 512.

Using the ideal code-to-voltage estimate:

Vin ≈ (Code / 2¹⁰) × Vref
Vin ≈ (512 / 1024) × 3.3
Vin ≈ 1.65 V

Answer: The estimated input voltage is approximately 1.65 V.

This is an ideal code-to-voltage estimate using the stated convention. Actual conversion depends on the ADC transfer characteristics and datasheet.

17. Lesson Summary

  • ADC converts analog input into a digital code.
  • Signal conditioning prepares the input for conversion.
  • Sampling measures the analog signal at discrete time intervals.
  • Sample-and-hold maintains a sampled voltage during conversion when used.
  • Quantization maps sampled values to discrete levels.
  • Encoding represents quantized levels as binary codes.
  • Resolution determines the number of available codes.
  • LSB size is commonly Vref divided by 2ⁿ for an ideal unipolar ADC.
  • Nyquist sampling theory helps prevent aliasing.
  • ADC accuracy also depends on noise, reference quality and linearity.
