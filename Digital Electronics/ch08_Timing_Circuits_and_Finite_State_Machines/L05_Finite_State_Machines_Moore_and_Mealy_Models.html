2. What Is a Finite State Machine?

A Finite State Machine (FSM) is a mathematical model used to describe the behaviour of a digital system that can exist in a finite number of states.

The system changes from one state to another depending on its current state and the input conditions.

FSMs are widely used in:

  • Digital control systems.
  • Traffic light controllers.
  • Elevator control systems.
  • Vending machines.
  • Communication protocol controllers.
  • Microcontroller-based applications.
  • FPGA and ASIC designs.
An FSM is a sequential circuit whose behaviour is described using a finite set of states, inputs, outputs and state transitions.

3. Basic Components of an FSM

A typical finite state machine consists of the following components:

1. States

A state represents the current condition or operating mode of the system.

For example, a traffic light controller may have three states: RED, GREEN and YELLOW.

2. Inputs

Inputs are external signals or conditions that influence the state transitions.

3. Outputs

Outputs are the signals generated by the FSM according to its defined operation.

4. State Transitions

A state transition represents movement from one state to another based on the current state and input conditions.

5. Clock Signal

In a synchronous FSM, the state register normally updates at an active clock edge.

4. General FSM Block Diagram

A synchronous FSM can be divided into state memory, next-state logic and output logic.

The next-state logic determines the next state, while the output logic generates the required output signals.

The diagram is a conceptual representation. The exact connections and output logic depend on whether the FSM is a Moore or Mealy machine.

5. Types of Finite State Machines

Two commonly used FSM models are:

  1. Moore Machine.
  2. Mealy Machine.

The main difference between them is how their outputs are generated.

6. Moore Machine

A Moore machine is a finite state machine in which the output depends only on the present state.

Output = f(Present State)

The output does not depend directly on the current input.

Characteristics of Moore Machine

  • Output depends only on the present state.
  • Output is associated with each state.
  • Output changes when the state changes, subject to output logic and circuit delay.
  • Often provides simpler output timing.
  • May require more states than an equivalent Mealy machine.

Moore Machine Block Diagram

In a Moore machine, the output logic receives the present-state information. The output is determined by the state alone.

Example: Moore Traffic Light Controller

Consider a traffic light controller with three states:

State Output
S0 RED
S1 GREEN
S2 YELLOW

The output is determined by the current traffic light state. The input or timer condition controls the transition to the next state.

7. Mealy Machine

A Mealy machine is a finite state machine in which the output depends on both the present state and current input.

Output = f(Present State, Input)

Characteristics of Mealy Machine

  • Output depends on present state and input.
  • Output is associated with transitions.
  • Output can change when the input changes, even without a state change.
  • Often requires fewer states than an equivalent Moore implementation.
  • Output may respond faster to input changes.

Mealy Machine Block Diagram

In a Mealy machine, both the present state and current input are used to generate the output.

8. Example of a Mealy Machine

Consider a simple sequence detector that detects the input pattern 01.

Assume:

  • Input X is a serial binary input.
  • Output Z becomes 1 when the sequence 01 is detected.
  • Overlapping sequences are allowed.

States

  • S0: No relevant previous 0 is stored.
  • S1: A 0 has been received and is waiting for a 1.

Mealy State Transition Table

Present State Input X Next State Output Z
S0 0 S1 0
S0 1 S0 0
S1 0 S1 0
S1 1 S0 1

When the machine is in S1 and receives input 1, it detects the sequence 01 and generates output 1.

This is a Mealy machine because the output depends on the present state and the current input.

9. Moore vs Mealy Machine

Moore Machine Mealy Machine
Output depends only on present state. Output depends on present state and input.
Output is associated with states. Output is associated with transitions.
Output generally changes when the state changes. Output can change when the input changes.
Often requires more states. May require fewer states.
Output is less directly sensitive to input glitches. Input glitches can affect combinational output logic.
Often has simpler output timing. May provide faster response to input changes.

10. Moore and Mealy State Diagrams

Moore State Diagram Representation

In a Moore state diagram, outputs are written inside or alongside the state representation.

Mealy State Diagram Representation

In a Mealy state diagram, transitions are labelled with input/output pairs.

The labels show input/output. For example, 0/0 means input 0 produces output 0 on that transition.

11. State Encoding

State encoding is the process of assigning binary values to the states of an FSM.

Common encoding methods include:

1. Binary Encoding

Each state is represented using a binary code. For N states, the minimum number of state flip-flops is:

Number of Flip-Flops = ⌈log₂ N⌉

2. One-Hot Encoding

Each state is assigned its own flip-flop. Only one state bit is normally HIGH at a time.

3. Gray Encoding

State codes are assigned so that adjacent states differ by one bit where the encoding sequence permits.

Encoding Flip-Flops for N States Characteristic
Binary ⌈log₂ N⌉ Uses fewer flip-flops
One-Hot N Simple state decoding
Gray Depends on encoding width Adjacent codes differ by one bit

12. Applications of FSM in Embedded Systems

Finite state machines are widely used in embedded systems to control operations in a structured and predictable manner.

  • Traffic Light Controller: Controls RED, GREEN and YELLOW lights.
  • UART Controller: Manages transmission and reception states.
  • SPI Controller: Controls data transfer phases.
  • Elevator Controller: Manages floor selection and movement.
  • Vending Machine: Tracks inserted money and product selection.
  • Motor Controller: Controls start, stop and direction states.
  • Communication Protocol: Manages protocol sequences and responses.
FSM design is especially useful in embedded C programming. A software state machine can implement similar state-based control using switch-case statements and structured state variables.
