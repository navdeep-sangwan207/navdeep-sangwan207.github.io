2. What Is Tri-State Logic?

In ordinary binary logic, an output is interpreted as either logic HIGH (1) or logic LOW (0).

Tri-state logic introduces a third output condition called the High-Impedance (Hi-Z) state.

Therefore, a tri-state output can represent three conditions:

  • Logic HIGH (1).
  • Logic LOW (0).
  • High impedance (Z).
High impedance means that the output driver is electrically disconnected or disabled from actively driving the output line. It does not mean that the output is producing a third voltage level.

3. What Is High-Impedance State?

High impedance is a condition in which the output behaves approximately like an open circuit from the perspective of the connected logic bus.

In this state, the output neither actively drives the line HIGH nor actively drives it LOW.

Important Characteristics

  • The output driver is disabled.
  • The output does not intentionally force a logic level.
  • Another device can drive the shared line.
  • The bus voltage is determined by other active drivers or suitable biasing.
A high-impedance output does not guarantee a valid logic HIGH or LOW voltage. If no device drives the bus and no biasing is provided, the line may float.

4. Tri-State Buffer

A tri-state buffer is a digital circuit that transfers an input signal to its output when enabled and places its output in the high-impedance state when disabled.

Basic Block Diagram

Operation

  • When Enable = 1, the output follows the input.
  • When Enable = 0, the output enters the high-impedance state.

Truth Table

Enable (E) Input (A) Output (Y)
0 0 Z
0 1 Z
1 0 0
1 1 1
Y = A when E = 1; otherwise Y = Z

5. Tri-State Buffer Types

1. Active-HIGH Enable

The buffer operates when the enable input is HIGH. When enable is LOW, its output becomes Hi-Z.

2. Active-LOW Enable

The buffer operates when the enable input is LOW. When enable is HIGH, its output becomes Hi-Z.

3. Inverting Tri-State Buffer

An inverting tri-state buffer produces the complement of the input when enabled. When disabled, its output becomes Hi-Z.

Buffer Type Enable Condition Output When Enabled
Non-inverting, active-HIGH E = 1 Y = A
Non-inverting, active-LOW E = 0 Y = A
Inverting, active-HIGH E = 1 Y = A'

6. Applications of Tri-State Logic

  • Shared data buses.
  • Microprocessor data buses.
  • Memory interface circuits.
  • Digital communication systems.
  • Parallel data transfer.
  • Bus-oriented embedded systems.
Tri-state outputs allow multiple devices to share a common signal line, provided only one push-pull output driver is enabled at a time.

7. Tri-State Logic in Bus Systems

A bus is a group of shared electrical signal lines used to transfer data between digital devices.

Multiple devices can connect to a shared data bus through tri-state buffers.

Example: Shared Data Bus

Bus Operation

  1. Device 1 is enabled to transmit data.
  2. Devices 2 and 3 are disabled and remain in Hi-Z.
  3. Device 1 places its data on the bus.
  4. Control logic disables Device 1 before enabling another device.
  5. Device 2 or Device 3 can then transmit.
Never enable multiple ordinary push-pull tri-state drivers on the same bus simultaneously unless the interface is specifically designed to tolerate that condition. Conflicting HIGH and LOW drivers can cause excessive current and incorrect logic levels.

9. What Is an Open-Collector Output?

An open-collector output is a BJT-based output configuration in which the collector of the output transistor is available as the output terminal without an internal active pull-up transistor.

The output transistor can pull the output line LOW when it turns ON.

When the transistor turns OFF, the output is released. An external pull-up resistor is generally required to obtain a defined HIGH level.

An open-collector output actively pulls LOW but does not actively drive HIGH. The pull-up resistor provides the HIGH-level voltage.

10. Open-Collector Circuit Diagram

Working Principle

Case 1: Transistor ON

  • The NPN output transistor conducts.
  • The output is pulled towards ground.
  • The output becomes LOW.
  • Current flows from VCC through the pull-up resistor and transistor to ground.

Case 2: Transistor OFF

  • The output transistor does not conduct.
  • The output is no longer actively pulled LOW.
  • The pull-up resistor raises the output towards VCC.
  • The output becomes HIGH if the load and leakage conditions permit.

11. Role of Pull-Up Resistor

A pull-up resistor connects an open-collector output to a positive supply voltage.

It establishes a defined HIGH voltage when the output transistor is OFF.

Functions

  • Provides the HIGH logic level.
  • Prevents the output from floating.
  • Limits current when the output transistor turns ON.
  • Helps establish the required bus voltage.

Pull-Up Resistor Calculation

When the transistor is ON, the resistor current can be estimated using:

R = (VCC - VOL) / I

Where:

  • VCC = Pull-up supply voltage.
  • VOL = Output LOW voltage.
  • I = Desired pull-up current.

Numerical Example

Given:

  • VCC = 5 V.
  • VOL = 0.2 V.
  • Desired current = 2 mA.
R = (5 - 0.2) / 0.002
R = 2400 Ω = 2.4 kΩ

A nominal 2.4 kΩ resistor gives approximately 2 mA under the assumed conditions. The final resistor selection must satisfy the transistor current rating, logic LOW requirement, resistor power rating and rise-time needs.

12. Wired-AND Logic

Open-collector outputs can be connected together to form a shared logic line with a pull-up resistor.

When any output transistor turns ON, it pulls the shared line LOW. The line becomes HIGH only when all connected output transistors are OFF.

For active-LOW transistor outputs, this arrangement produces a wired-AND relationship between the released logic states.

Example: Two Open-Collector Outputs
Output A Output B Shared Line Y
1 1 1
1 0 0
0 1 0
0 0 0
Y = A · B
This truth table assumes each output represents its normal released-HIGH or transistor-ON LOW condition. Open-collector outputs can safely share a line when designed for wired logic, unlike ordinary push-pull outputs.

13. Open-Collector Applications

  • Shared interrupt lines.
  • Wired-AND logic circuits.
  • Reset signal distribution.
  • Level interfacing within device ratings.
  • Multiple-device control signals.
  • Communication buses designed for open-drain/open-collector operation.
I²C is a common embedded-systems example. Its SDA and SCL lines use open-drain outputs with pull-up resistors. Open-drain is the MOSFET-based equivalent of the BJT open-collector concept.

14. Open-Collector vs Tri-State Output

Output structure BJT collector available as output Output driver can be enabled or disabled

HIGH state Provided by pull-up resistor Actively driven HIGH when enabled
Hi-Z state Transistor OFF releases output Driver disabled

15. Advantages and Limitations

Advantages of Tri-State Logic

  • Allows multiple devices to share a common bus.
  • Reduces the need for separate data lines.
  • Supports controlled data transfer.
  • Useful in memory and processor interfaces.

Limitations of Tri-State Logic

  • Requires correct output-enable control.
  • Simultaneous conflicting drivers can cause excessive current.
  • Bus capacitance can affect switching speed.
  • A disabled bus may require suitable biasing.

Advantages of Open-Collector Outputs

  • Multiple compatible outputs can share one line.
  • Supports wired logic.
  • Can interface to a suitable higher pull-up voltage within device ratings.
  • Useful for shared interrupt and reset signals.

Limitations of Open-Collector Outputs

  • Requires a pull-up resistor.
  • Rising transitions depend on resistor and bus capacitance.
  • Resistor value affects power consumption and switching speed.
  • Output voltage and current must remain within device ratings.

16. Practical Embedded Systems Considerations

  1. Check whether an output is push-pull, open-drain or open-collector.
  2. Verify the required pull-up resistor and supply voltage.
  3. Check whether multiple devices are allowed to share the signal line.
  4. Ensure only one conflicting push-pull driver is enabled at a time.
  5. Check rise time and total bus capacitance.
  6. Verify voltage compatibility with the microcontroller GPIO.
  7. Use suitable pull-up values and signal routing.
Never assume that an open-drain or open-collector pin can be pulled up to any voltage. Check its maximum output-pin voltage, leakage current and other electrical ratings.

  • Tri-state logic has HIGH, LOW and high-impedance output conditions.
  • High impedance means the output driver is disabled.

  • Only one conflicting push-pull driver should be enabled at a time.
