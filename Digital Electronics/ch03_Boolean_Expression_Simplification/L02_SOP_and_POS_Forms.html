Chapter 3 – Boolean Expression Simplification

1. Learning Objectives

  • Understand standard Boolean expression forms.
  • Learn Sum of Products (SOP).
  • Learn Product of Sums (POS).
  • Identify product terms and sum terms.
  • Convert Boolean expressions into SOP and POS forms.
  • Understand the relationship between truth tables and SOP/POS.
  • Recognize NAND-NAND and NOR-NOR circuit implementations.

2. Introduction to SOP and POS

Boolean expressions can be written in different standard forms to make digital circuit design and analysis easier. Two commonly used forms are:

  • SOP: Sum of Products
  • POS: Product of Sums

These forms are useful in logic circuit implementation, Boolean simplification and digital system design.

SOP combines AND terms using OR operations. POS combines OR terms using AND operations.

3. Sum of Products (SOP)

Sum of Products is a Boolean expression in which two or more product terms are combined using the OR operation.

Product Term

A product term is formed by ANDing two or more variables or their complements.

Examples of product terms:

A · B
A̅ · B
A · B̅ · C

SOP Expression

Product terms are combined using OR operations.

Y = A·B + A̅·C + B·C

Here, A·B, A̅·C and B·C are product terms. The OR operation combines them.

Example 1: Identifying SOP

Given:

Y = A·B + A·C

Product terms:

  • A·B
  • A·C

Both product terms are connected through OR. Therefore, this is an SOP expression.

4. Product of Sums (POS)

Product of Sums is a Boolean expression in which two or more sum terms are combined using the AND operation.

Sum Term

A sum term is formed by ORing two or more variables or their complements.

Examples of sum terms:

A + B
A̅ + B
A + B̅ + C

POS Expression

Sum terms are combined using AND operations.

Y = (A+B) · (A̅+C) · (B+C)

Here, (A+B), (A̅+C) and (B+C) are sum terms. The AND operation combines them.

Example 2: Identifying POS

Given:

Y = (A+B) · (B+C)

Sum terms:

  • (A+B)
  • (B+C)

Both sum terms are connected through AND. Therefore, this is a POS expression.

5. Difference Between SOP and POS

Parameter SOP POS
Full Form Sum of Products Product of Sums
Basic Terms Product terms Sum terms
Operations AND followed by OR OR followed by AND
Grouping AND terms are ORed OR terms are ANDed
Typical Gate Structure AND-OR OR-AND
Universal Gate Form NAND-NAND NOR-NOR

6. Converting a Boolean Expression into SOP Form

An SOP expression can be obtained by distributing AND operations over OR operations until the expression becomes a sum of product terms.

Example

Given:

Y = A(B+C)

Step 1: Apply the distributive law.

Y = A·B + A·C

Both terms are product terms joined by OR.

Final SOP:

Y = AB + AC

Another Example

Given:

Y = (A+B)C

Apply the distributive law:

Y = AC + BC

Final SOP: Y = AC + BC

7. Converting a Boolean Expression into POS Form

A POS expression contains sum terms connected through AND operations. The distributive law can be used to transform suitable expressions into POS form.

Example

Given:

Y = AB + C

Apply the Boolean identity:

XY + Z = (X+Z)(Y+Z)

Therefore:

Y = (A+C)(B+C)

Final POS: (A+C)(B+C)

Another Example

Given:

Y = A + BC

Apply the distributive identity:

X + YZ = (X+Y)(X+Z)

Therefore:

Y = (A+B)(A+C)

8. Obtaining SOP from a Truth Table

To obtain an SOP expression from a truth table, identify every row where the output is 1. Write one AND term for each such row and combine the terms using OR.

Example

Consider this truth table:

A B Y
000
011
101
111

Rows with output 1 are:

  • A = 0, B = 1 → A̅B
  • A = 1, B = 0 → AB̅
  • A = 1, B = 1 → AB

Combining the terms:

Y = A̅B + AB̅ + AB

This is the canonical SOP expression. It can be simplified to:

Y = A + B

9. Obtaining POS from a Truth Table

To obtain a POS expression from a truth table, identify every row where the output is 0. Write one OR term for each such row and combine the terms using AND.

Example

A B Y
000
011
101
111

Only one row has output 0:

  • A = 0, B = 0 → (A+B)

Therefore:

Y = (A+B)

This expression is already in POS form.

10. Logic Circuit Implementation of SOP and POS

SOP Implementation

An SOP expression can be implemented using AND gates followed by an OR gate.

Y = AB + CD
  • AND gate 1 generates AB.
  • AND gate 2 generates CD.
  • OR gate combines both outputs.

POS Implementation

A POS expression can be implemented using OR gates followed by an AND gate.

Y = (A+B)(C+D)
  • OR gate 1 generates A+B.
  • OR gate 2 generates C+D.
  • AND gate combines both outputs.

Universal Gate Implementation

  • SOP expressions are naturally implemented using NAND-NAND structures.
  • POS expressions are naturally implemented using NOR-NOR structures.
  • Input complements can be generated using NAND or NOR gates.
NAND-NAND and NOR-NOR are common two-level implementations. Additional input inverters may be required depending on the expression.

11. Practical Digital Electronics Example

Two-Sensor Control Logic

Consider a system in which an output becomes HIGH when both sensor A and sensor B are active, or when a manual override input C is active.

Boolean expression:

Y = AB + C

Inputs:

  • A = Sensor A status
  • B = Sensor B status
  • C = Manual override
  • Y = Control output

The circuit can be implemented using two AND/OR logic stages, or using an equivalent NAND-only circuit.

14. Lesson Summary

  • SOP stands for Sum of Products.
  • POS stands for Product of Sums.
  • SOP combines product terms using OR operations.
  • POS combines sum terms using AND operations.
  • SOP is commonly implemented using AND-OR or NAND-NAND structures.
  • POS is commonly implemented using OR-AND or NOR-NOR structures.
  • SOP can be derived from truth table rows where output is 1.
  • POS can be derived from truth table rows where output is 0.
  • Both forms are important for digital circuit design and simplification.
