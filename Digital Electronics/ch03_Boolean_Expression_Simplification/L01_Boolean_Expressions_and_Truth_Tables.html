2. Introduction to Boolean Algebra

Boolean algebra is a mathematical system used to represent and manipulate logical values. It is the foundation of digital electronics and logic circuit design.

Unlike ordinary algebra, Boolean algebra uses only two possible values: 0 and 1.

Boolean Values

0 = LOW = FALSE
1 = HIGH = TRUE

Boolean algebra is used in logic gates, processors, microcontrollers, digital control systems and embedded hardware.

3. Boolean Variables and Constants

Boolean Variables

A Boolean variable represents a logical input or output. Common variable names include A, B, C, D and X.

For example:

A ∈ {0, 1}

This means variable A can have either value 0 or 1.

Boolean Constants

0 Logic LOW / FALSE
1 Logic HIGH / TRUE

4. Basic Boolean Operators

4.1 AND Operation

The AND operation produces output 1 only when all its inputs are 1.

Y = A · B

Example:

1 · 1 = 1
1 · 0 = 0

4.2 OR Operation

The OR operation produces output 1 when at least one input is 1.

Y = A + B

Example:

1 + 0 = 1
0 + 0 = 0

4.3 NOT Operation

The NOT operation produces the complement of the input.

Y = A̅

Example:

If A = 0, Y = 1
If A = 1, Y = 0

4.4 XOR Operation

XOR produces output 1 when its two inputs are different.

Y = A ⊕ B

4.5 XNOR Operation

XNOR produces output 1 when its two inputs are equal.

Y = (A ⊕ B)̅

5. What is a Truth Table?

A truth table is a tabular representation of a Boolean function. It lists every possible input combination and the corresponding output.

Truth tables are used to verify logic gate operations, analyze digital circuits and derive Boolean expressions.

9. Evaluating Boolean Expressions

Boolean expressions can be evaluated by substituting input values and applying the logical operations.

Example 1: Y = A · B + C

Given:
  • A = 1
  • B = 0
  • C = 1
Step 1: A · B = 1 · 0 = 0

Step 2: Y = 0 + 1 = 1

Final Output: Y = 1

Example 2: Y = (A + B) · C

Given:
  • A = 1
  • B = 0
  • C = 0
Step 1: A + B = 1 + 0 = 1

Step 2: Y = 1 · 0 = 0

Final Output: Y = 0

Example 3: Y = A̅ · B + C

Given:
  • A = 0
  • B = 1
  • C = 0
Step 1: A̅ = 1

Step 2: A̅ · B = 1 · 1 = 1

Step 3: Y = 1 + 0 = 1

Final Output: Y = 1
