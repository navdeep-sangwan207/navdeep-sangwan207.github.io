2. Introduction to Four-Variable K-map

A four-variable Karnaugh map is a graphical method used to simplify Boolean functions containing four variables: A, B, C and D.

Four variables produce 2⁴ = 16 possible input combinations. Therefore, a four-variable K-map contains 16 cells.

A four-variable K-map is arranged as a 4 × 4 grid. Rows represent AB combinations and columns represent CD combinations, both arranged in Gray code order.

3. Gray Code Arrangement

Both row and column labels follow the Gray code sequence:

00, 01, 11, 10

The arrangement ensures that adjacent cells differ in only one variable.

Position AB / CD
First00
Second01
Third11
Fourth10

4. Four-Variable K-map Structure

The rows are labelled AB and the columns are labelled CD. Each cell represents one minterm.

AB \ CD 00 01 11 10
00 m₀ m₁ m₃ m₂
01 m₄ m₅ m₇ m₆
11 m₁₂ m₁₃ m₁₅ m₁₄
10 m₈ m₉ m₁₁ m₁₀
Important: The minterm index is obtained by converting the binary combination ABCD into decimal. For example, 1010₂ = 10, so that cell is m₁₀.

5. Minterm Mapping

To map a minterm, divide its four-bit binary representation into two pairs:

  • First two bits identify the AB row.
  • Last two bits identify the CD column.

Example: Locate m₁₁

Decimal 11 in four-bit binary is 1011.

AB = 10, CD = 11

Locate row 10 and column 11. Their intersection represents m₁₁.

6. Valid Group Sizes

For SOP simplification, group adjacent cells containing 1. A valid group must contain a power-of-two number of cells.

Group Number of Cells Variables Eliminated
Single10
Pair21
Quad42
Octet83
Group of sixteen164

Grouping Rules

  1. Groups must contain 1, 2, 4, 8 or 16 cells.
  2. Groups must be rectangular.
  3. Diagonal grouping is not permitted.
  4. Every 1 must be covered at least once.
  5. Make groups as large as possible.
  6. Overlapping groups are allowed.
  7. Wrap-around adjacency is allowed.
  8. Groups may be repeated when needed to cover all 1s.

7. Adjacent Cells and Wrap-Around Grouping

In a four-variable K-map:

  • Horizontal neighboring cells are adjacent.
  • Vertical neighboring cells are adjacent.
  • First and last columns are adjacent.
  • Top and bottom rows are adjacent.
  • Corner cells are mutually adjacent through wrap-around.
  • Diagonal cells are not adjacent.
The four corner cells can form a valid group of four. This is possible because K-map edges wrap around.

8. Example 1 – Simplification Using an Octet

Given:

Y(A,B,C,D) = Σm(0,1,2,3,8,9,10,11)

Fill the K-map:

AB \ CD 00 01 11 10
00 1 1 1 1
01 0 0 0 0
11 0 0 0 0
10 1 1 1 1

Grouping

The first and last rows together form an octet because rows AB = 00 and AB = 10 are adjacent through wrap-around.

Across these eight cells, A = 0 and B changes. Both C and D also change.

Y = A̅

9. Example 2 – Simplification Using a Quad

Given:

Y(A,B,C,D) = Σm(0,1,4,5)
AB \ CD 00 01 11 10
00 1 1 0 0
01 1 1 0 0
11 0 0 0 0
10 0 0 0 0

Grouping

The four 1s form a quad across rows 00 and 01, and columns 00 and 01.

  • A remains 0.
  • B changes.
  • C remains 0.
  • D changes.
Y = A̅C̅

10. Example 3 – Simplification Using Multiple Groups

Given:

Y(A,B,C,D) = Σm(0,2,5,7,8,10,13,15)

The K-map can be simplified by forming two octets or equivalent overlapping groups.

Group 1

Minterms 0, 2, 8 and 10 form a group of four using the first and last columns and the first and last rows.

In this group:

  • B = 0
  • D = 0
  • A and C change
Group 1 = B̅D̅

Group 2

Minterms 5, 7, 13 and 15 form a group of four across rows 01 and 11 and columns 01 and 11.

In this group:

  • B = 1
  • D = 1
  • A and C change
Group 2 = BD

Final simplified expression:

Y = B̅D̅ + BD

This is the XNOR function of B and D.

11. SOP Simplification Procedure

  1. Write the Boolean function in minterm notation.
  2. Draw a four-variable K-map.
  3. Place 1 in the specified minterm cells.
  4. Place 0 in the remaining cells.
  5. Identify the largest possible groups of 1s.
  6. Cover every 1 at least once.
  7. Identify variables that remain constant in each group.
  8. Write the product term for each group.
  9. OR all product terms to obtain the simplified SOP.

12. POS Simplification Using a Four-Variable K-map

To obtain a simplified POS expression, group adjacent cells containing 0 instead of 1.

POS Grouping Rules

  • Group zeros in powers of two.
  • Use the largest possible groups.
  • For a variable that remains 0, write it uncomplemented.
  • For a variable that remains 1, write it complemented.
  • Combine the resulting sum terms using AND.

Consider:

Y(A,B,C,D) = ΠM(0,1,2,3,8,9,10,11)

These eight zero cells form an octet using the first and last rows.

In this group, A = 0 remains constant.

Y = A

13. Essential Prime Implicants

A prime implicant is a product term obtained from a group that cannot be expanded into a larger valid group.

An essential prime implicant covers at least one minterm that is not covered by any other prime implicant.

In K-map simplification, essential prime implicants must be selected to ensure all required 1s are covered.

Practical Group Selection

  1. Identify all possible largest groups.
  2. Find minterms covered by only one group.
  3. Select the corresponding essential prime implicants.
  4. Cover any remaining minterms with the fewest additional groups.

14. Applications of Four-Variable K-maps

  • Combinational logic circuit optimization.
  • Digital control system design.
  • Arithmetic and logic circuit simplification.
  • Multiplexer and decoder implementation.
  • Alarm and sensor control logic.
  • Reducing logic gates in embedded hardware.
  • Minimizing hardware cost and circuit complexity.

15. Common Mistakes

  • Using binary order instead of Gray code order.
  • Placing minterms in incorrect cells.
  • Grouping diagonal cells.
  • Forgetting wrap-around adjacency.
  • Making groups that are not powers of two.
  • Leaving required 1s uncovered.
  • Failing to identify all constant variables in a group.
  • Choosing smaller groups when larger groups are possible.

18. Lesson Summary

  • A four-variable K-map contains 16 cells.
  • Rows and columns follow Gray code order.
  • Each cell represents one minterm.
  • Valid group sizes are 1, 2, 4, 8 and 16.
  • For SOP, group 1s.
  • For POS, group 0s.
  • Wrap-around grouping is allowed.
  • Variables that change within a group are eliminated.
  • Essential prime implicants must be included in the final solution.
  • K-map simplification reduces logic circuit complexity.
