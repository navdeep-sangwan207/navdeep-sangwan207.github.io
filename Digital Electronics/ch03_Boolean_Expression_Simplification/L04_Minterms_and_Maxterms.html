2. Introduction to Minterms and Maxterms

Minterms and maxterms are fundamental terms used in Boolean algebra to represent digital logic functions. They provide a systematic way to convert truth tables into Boolean expressions.

  • Minterm: An AND term containing every variable exactly once.
  • Maxterm: An OR term containing every variable exactly once.
Remember:
  • Minterm = output 1 for exactly one input combination.
  • Maxterm = output 0 for exactly one input combination.

3. Minterms

A minterm is a product (AND) term in which every Boolean variable appears exactly once, either complemented or uncomplemented.

Example: Two Variables A and B

A B Minterm Index Minterm
00m₀A̅B̅
01m₁A̅B
10m₂AB̅
11m₃AB

Minterm Generation Rule

  • For input 0, write the variable in complemented form.
  • For input 1, write the variable in uncomplemented form.
  • Connect all variables using AND operations.

For input combination A = 0, B = 1, C = 0:

m₂ = A̅BC̅

The binary combination 010 is decimal 2, so the corresponding minterm is m₂.

4. Maxterms

A maxterm is a sum (OR) term in which every Boolean variable appears exactly once, either complemented or uncomplemented.

Example: Two Variables A and B

A B Maxterm Index Maxterm
00M₀(A+B)
01M₁(A+B̅)
10M₂(A̅+B)
11M₃(A̅+B̅)

Maxterm Generation Rule

  • For input 0, write the variable in uncomplemented form.
  • For input 1, write the variable in complemented form.
  • Connect all variables using OR operations.

For input combination A = 0, B = 1, C = 0:

M₂ = (A+B̅+C)

The binary combination 010 is decimal 2, so the corresponding maxterm is M₂.

5. Difference Between Minterms and Maxterms

Parameter Minterm Maxterm
Operation AND OR
Term Type Product term Sum term
Output 1 For one input combination For all except one combination
Output 0 For all except one combination For one input combination
Canonical Form SOP POS
Notation Σm ΠM

6. Three-Variable Minterm and Maxterm Table

For three variables A, B and C, there are 2³ = 8 possible input combinations.

A B C Index Minterm Maxterm
0000 A̅B̅C̅(A+B+C)
0011 A̅B̅C(A+B+C̅)
0102 A̅BC̅(A+B̅+C)
0113 A̅BC(A+B̅+C̅)
1004 AB̅C̅(A̅+B+C)
1015 AB̅C(A̅+B+C̅)
1106 ABC̅(A̅+B̅+C)
1117 ABC(A̅+B̅+C̅)

7. Canonical SOP Using Minterms

To obtain canonical SOP, select all truth table rows for which the output is 1. Write their corresponding minterms and combine them using OR.

Example

A B C Y
0000
0011
0100
0111
1001
1010
1100
1111

Output 1 occurs at indices 1, 3, 4 and 7.

Y = Σm(1,3,4,7)

Expanded expression:

Y = A̅B̅C + A̅BC + AB̅C̅ + ABC

8. Canonical POS Using Maxterms

To obtain canonical POS, select all truth table rows for which the output is 0. Write their corresponding maxterms and combine them using AND.

In the previous example, output 0 occurs at indices 0, 2, 5 and 6.

Y = ΠM(0,2,5,6)

Expanded expression:

Y = (A+B+C)(A+B̅+C)(A̅+B+C̅)(A̅+B̅+C)
The canonical SOP and canonical POS expressions represent the same function when derived from the same truth table.

9. Converting Between Minterm and Maxterm Indices

For a completely specified Boolean function, the set of minterm indices where output is 1 and the set of maxterm indices where output is 0 cover all possible input combinations without overlap.

For a three-variable function:

Y = Σm(1,3,4,7)

The remaining indices are 0, 2, 5 and 6.

Y = ΠM(0,2,5,6)

The total number of combinations for n variables is 2ⁿ, so the complete index range is 0 through 2ⁿ − 1.

10. Practical Digital Electronics Example

Three-Input Alarm System

Consider a digital alarm system with three inputs:

  • A = Door sensor
  • B = Window sensor
  • C = Manual alarm switch
  • Y = Alarm output

Suppose the alarm is activated for input combinations 001, 011, 100 and 111.

Canonical SOP representation:

Y = Σm(1,3,4,7)

Expanded expression:

Y = A̅B̅C + A̅BC + AB̅C̅ + ABC

This representation can be used to design and verify the corresponding digital logic circuit.

14. Lesson Summary

  • A minterm is an AND term containing all variables.
  • A maxterm is an OR term containing all variables.
  • Each minterm is HIGH for exactly one input combination.
  • Each maxterm is LOW for exactly one input combination.
  • Minterms are used to construct canonical SOP.
  • Maxterms are used to construct canonical POS.
  • Sigma notation represents minterm indices.
  • Pi notation represents maxterm indices.
  • Minterm and maxterm index sets are complementary for a fully specified function.
