Lesson 3: Canonical SOP and POS Forms

Chapter 3 – Boolean Expression Simplification

1. Learning Objectives

  • Understand canonical Boolean expressions.
  • Differentiate standard SOP and canonical SOP.
  • Differentiate standard POS and canonical POS.
  • Understand the relationship between minterms and canonical SOP.
  • Understand the relationship between maxterms and canonical POS.
  • Convert truth tables into canonical expressions.
  • Use sigma and pi notation for Boolean functions.

2. Introduction to Canonical Forms

A canonical Boolean expression is a standard representation in which every product term or sum term contains all the variables of the function, either in complemented or uncomplemented form.

The two canonical forms are:

  • Canonical SOP: Sum of Minterms.
  • Canonical POS: Product of Maxterms.
In canonical SOP, each product term contains every input variable. In canonical POS, each sum term also contains every input variable.

3. Standard Form vs Canonical Form

A standard SOP or POS expression does not necessarily contain every variable in each term. A canonical expression requires every term to contain all variables.

Example: SOP

Standard SOP:

Y = AB + C

The first term contains A and B, while the second term contains only C. Therefore, this is not canonical SOP for three variables.

Canonical SOP:

Y = A̅B̅C + AB̅C + ABC

Every product term contains A, B and C.

Example: POS

Standard POS:

Y = (A+B)(B+C)

Each sum term does not contain every variable.

Canonical POS:

Y = (A+B+C)(A+B̅+C)

Every sum term contains all three variables.

4. Minterms

A minterm is an AND product containing every input variable exactly once, either complemented or uncomplemented.

For three variables A, B and C, examples of minterms are:

A̅B̅C̅
A̅B̅C
A̅BC
ABC

A minterm has output 1 for exactly one input combination.

Three-Variable Minterm Table

A B C Index Minterm
000m₀A̅B̅C̅
001m₁A̅B̅C
010m₂A̅BC̅
011m₃A̅BC
100m₄AB̅C̅
101m₅AB̅C
110m₆ABC̅
111m₇ABC
Minterm rule:
  • Input 0 → complemented variable.
  • Input 1 → uncomplemented variable.

5. Maxterms

A maxterm is an OR sum containing every input variable exactly once, either complemented or uncomplemented.

A maxterm has output 0 for exactly one input combination.

Three-Variable Maxterm Table

A B C Index Maxterm
000M₀(A+B+C)
001M₁(A+B+C̅)
010M₂(A+B̅+C)
011M₃(A+B̅+C̅)
100M₄(A̅+B+C)
101M₅(A̅+B+C̅)
110M₆(A̅+B̅+C)
111M₇(A̅+B̅+C̅)
Maxterm rule:
  • Input 0 → uncomplemented variable.
  • Input 1 → complemented variable.

6. Canonical SOP Representation

Canonical SOP is obtained by adding all minterms corresponding to truth table rows where the output is 1.

Example

Consider the following truth table:

A B C Y
0000
0011
0100
0111
1001
1010
1100
1111

The output is 1 at rows 1, 3, 4 and 7.

Corresponding minterms:

  • m₁ = A̅B̅C
  • m₃ = A̅BC
  • m₄ = AB̅C̅
  • m₇ = ABC

Therefore:

Y = A̅B̅C + A̅BC + AB̅C̅ + ABC

In sigma notation:

Y(A,B,C) = Σm(1,3,4,7)

7. Canonical POS Representation

Canonical POS is obtained by multiplying all maxterms corresponding to truth table rows where the output is 0.

Using the same truth table, the output is 0 at rows 0, 2, 5 and 6.

Corresponding maxterms:

  • M₀ = (A+B+C)
  • M₂ = (A+B̅+C)
  • M₅ = (A̅+B+C̅)
  • M₆ = (A̅+B̅+C)

Therefore:

Y = (A+B+C)(A+B̅+C)(A̅+B+C̅)(A̅+B̅+C)

In pi notation:

Y(A,B,C) = ΠM(0,2,5,6)

8. Sigma and Pi Notation

Sigma (Σ) Notation

Sigma notation represents the sum of minterms for which the output is 1.

Y(A,B,C) = Σm(1,3,5)

This means the function is HIGH for minterms 1, 3 and 5.

Pi (Π) Notation

Pi notation represents the product of maxterms for which the output is 0.

Y(A,B,C) = ΠM(0,2,4,6,7)

This means the function is LOW for maxterms 0, 2, 4, 6 and 7.

The minterm and maxterm indices use the binary input combination as a decimal number, with the leftmost variable treated as the most significant bit.

9. Relationship Between Canonical SOP and POS

For a completely specified Boolean function, every truth table row has either output 1 or output 0.

  • Canonical SOP uses all rows where Y = 1.
  • Canonical POS uses all rows where Y = 0.

Therefore, the minterm indices and maxterm indices are complementary sets.

For example:

Y = Σm(1,3,4,7)
Y = ΠM(0,2,5,6)

Both expressions represent the same Boolean function.

10. Applications of Canonical Forms

  • Digital logic circuit design.
  • Logic circuit verification.
  • Karnaugh map simplification.
  • Programmable logic device design.
  • Combinational circuit implementation.
  • Digital system analysis and documentation.

13. Lesson Summary

  • Canonical SOP is the sum of minterms.
  • Canonical POS is the product of maxterms.
  • Every canonical term contains all input variables.
  • Minterms produce output 1 for exactly one input combination.
  • Maxterms produce output 0 for exactly one input combination.
  • Sigma notation represents the ON-set of a function.
  • Pi notation represents the OFF-set of a function.
  • Both canonical forms represent the same Boolean function when derived from the same truth table.
