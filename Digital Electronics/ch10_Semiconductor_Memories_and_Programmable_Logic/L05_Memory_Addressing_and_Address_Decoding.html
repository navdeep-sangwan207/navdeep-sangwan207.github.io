Lesson 05: Memory Addressing and Address Decoding

Understand memory address spaces, address buses, chip selection, address decoding techniques, memory interfacing and practical memory-mapping calculations.

1. Introduction to Memory Addressing

Memory addressing is the process of identifying and selecting a particular storage location in a memory device. Every addressable location has a unique binary address.

The processor generates an address through its address bus. The memory system uses this address to select the required location for reading or writing data.

Definition: Memory addressing is the method used by a processor or memory controller to identify a particular memory location using a binary address.

Why Is Memory Addressing Required?

  • To identify individual memory locations.
  • To read data from a selected address.
  • To write data into a selected address.
  • To connect multiple memory devices to a processor.
  • To organize RAM, ROM and peripheral address spaces.

2. Address Bus and Memory Capacity

An address bus consists of signals used to specify memory addresses. The number of address bits determines how many distinct addresses can be represented.

Number of Addressable Locations = 2n

Here, n represents the number of address bits.

Examples

Address Lines Number of Addresses Address Range
4 16 0 to 15
8 256 0 to 255
10 1024 0 to 1023
12 4096 0 to 4095
16 65536 0 to 65535
20 1048576 0 to 1048575

Example: 16 Address Lines

A processor has 16 address lines. Calculate the number of addressable locations.

Solution:

Number of locations = 216 = 65536.

If each address identifies one byte, the addressable space is 65536 bytes = 64 KiB.

3. Byte-Addressable and Word-Addressable Memory

3.1 Byte-Addressable Memory

In byte-addressable memory, each address identifies one byte (8 bits).

For example, addresses 1000H, 1001H and 1002H identify three consecutive bytes.

3.2 Word-Addressable Memory

In word-addressable memory, each address identifies one complete word. The word size depends on the processor or memory architecture.

Feature Byte Addressable Word Addressable
Address identifies One byte One word
Address increment Usually one byte Usually one word
Common use Most general-purpose processors Some specialized architectures
Do not confuse the width of the data bus with the number of addressable bytes. A processor may have a wide data bus while using byte-addressable memory.

4. What Is Address Decoding?

Address decoding is the process of examining address bits and generating a chip-select signal for a particular memory device or address range.

When multiple memory chips are connected to a processor, address decoding ensures that the correct chip responds to a particular address.

Definition: Address decoding is a combinational logic operation that converts selected address bits into memory or device selection signals.

5. Types of Address Decoding

5.1 Full Address Decoding

Full address decoding uses all address bits needed to distinguish a device's assigned address range.

This helps ensure that the device responds only to its intended address range.

  • Provides unique address selection.
  • Reduces unintended address overlap.
  • Requires more decoding logic in many designs.

5.2 Partial Address Decoding

Partial address decoding uses only some of the available address bits to generate chip-select signals.

  • Requires less decoding hardware.
  • Can simplify small memory systems.
  • May cause multiple addresses to select the same device.
When address bits are ignored, the device may appear at multiple addresses. These are called address aliases or mirrored addresses.

6. Using a Decoder IC for Memory Selection

A decoder IC converts a binary input into one of several active output lines. It can be used to select one memory chip from multiple devices.

3-to-8 Decoder

A 3-to-8 decoder has three input bits and eight output lines. For each valid input combination, one output is selected, subject to the enable and output polarity.

Truth Table

The truth table identifies the selected output logically. Actual decoder ICs may have active-LOW outputs, such as the 74HC138. Always check the manufacturer's datasheet.

7. Memory Interfacing with a Processor

Memory interfacing connects RAM or ROM devices to a processor using address, data and control signals.

Important Connections

  • Processor address lines connect to memory address inputs.
  • Processor data lines connect to memory data pins.
  • Chip-select logic selects the required memory device.
  • Read and write controls coordinate data transfers.
  • Power and ground connections provide the required supply.

8. Memory Address Mapping

A memory map defines the address ranges assigned to different memory devices and peripherals in a system.

Example Memory Map

Address Range Device Size
0000H – 1FFFH ROM 8 KiB
2000H – 27FFH RAM 2 KiB
2800H – 2FFFH Reserved 2 KiB
3000H – 30FFH Peripheral Registers 256 bytes
Address ranges are illustrative. A real processor's memory map is defined by its hardware architecture and system design.

9. Worked Example: Connecting RAM and ROM

Consider a processor with a 16-bit byte-addressed address bus. It has a 16-bit address space from 0000H to FFFFH.

Suppose the system contains:

  • 8 KiB ROM starting at 0000H.
  • 4 KiB RAM starting at 2000H.

Step 1: Calculate ROM Address Range

8 KiB = 8192 bytes = 2000H bytes.

Start address = 0000H.

End address = 0000H + 2000H - 1 = 1FFFH.

Step 2: Calculate RAM Address Range

4 KiB = 4096 bytes = 1000H bytes.

Start address = 2000H.

End address = 2000H + 1000H - 1 = 2FFFH.

Final Memory Map

Device Start Address End Address Capacity
ROM 0000H 1FFFH 8 KiB
RAM 2000H 2FFFH 4 KiB

11. Practice Problems

Problem 1

Calculate the number of addressable locations using 14 address lines.

Solution:

214 = 16384 locations.

Problem 2

A byte-addressable memory has 12 address lines. Calculate its total addressable capacity.

Solution:

212 = 4096 bytes = 4 KiB.

Problem 3

A 2 KiB memory chip starts at address 4000H. Find its ending address.

Solution:

2 KiB = 0800H bytes.

Ending address = 4000H + 0800H - 1.

Ending address = 47FFH.

Problem 4

How many output lines are available in a 4-to-16 decoder?

Answer: 16 output lines.

12. Lesson Summary

  • Memory addressing identifies individual storage locations.
  • n address lines can represent 2n addresses.
  • Byte-addressable memory assigns one address to each byte.
  • Address decoding generates chip-selection signals.
  • Full decoding uses the required address bits for unique selection.
  • Partial decoding can create mirrored address ranges.
  • Decoder ICs can select one device from multiple memory chips.
  • A memory map assigns address ranges to system devices.
  • Address ranges can be calculated using start address and capacity.
