Lesson 02: RAM – SRAM and DRAM

Understand Random Access Memory, Static RAM, Dynamic RAM, their internal storage principles, operation, differences and applications in digital and embedded systems.

1. Introduction to RAM

RAM stands for Random Access Memory. It is a type of volatile semiconductor memory used to temporarily store data and instructions required by a processor or digital system.

The term random access means that any addressable memory location can be accessed directly without having to read all the preceding locations.

RAM supports both read and write operations during normal operation.

Important: RAM is generally volatile. Its stored information is lost when power is removed. SRAM and DRAM are the two major types of RAM.

2. Types of RAM

2.1 Static RAM (SRAM)

Static RAM stores each bit using a bistable circuit, commonly implemented using a six-transistor (6T) CMOS memory cell.

As long as power is supplied, the stored state is retained without periodic refresh operations.

2.2 Dynamic RAM (DRAM)

Dynamic RAM stores each bit as electrical charge in a capacitor controlled by a transistor. The stored charge gradually leaks away, so the memory must be refreshed periodically.

DRAM is widely used for high-capacity main memory in computers and other digital systems.

3. Static RAM (SRAM)

3.1 SRAM Storage Principle

An SRAM cell uses a bistable latch formed by cross-coupled inverters. In a common 6T SRAM cell, four transistors form the storage latch and two access transistors connect the cell to the bit lines.

3.2 SRAM Operation

Hold operation: The cross-coupled latch maintains its stored logic state while power is supplied and the cell is not being accessed.

Read operation: The bit lines are typically precharged. The word line activates the access transistors, allowing the stored state to influence the bit-line voltages. Sense amplifiers detect the small voltage difference.

Write operation: Write circuitry drives the bit lines with the desired data and its complement. Activating the word line allows the new state to be stored in the latch.

3.3 Advantages of SRAM

  • Very fast access compared with conventional DRAM.
  • No periodic refresh operation is required.
  • Suitable for high-speed data storage.
  • Commonly used for processor cache memory.

3.4 Disadvantages of SRAM

  • Requires more transistors per bit.
  • Lower storage density than DRAM.
  • Higher cost per bit in typical implementations.
  • Still requires power to retain data.

3.5 Applications of SRAM

  • CPU cache memory.
  • Microcontroller internal RAM.
  • High-speed buffers.
  • Networking equipment.
  • Digital signal processing systems.

4. Dynamic RAM (DRAM)

4.1 DRAM Storage Principle

A conventional DRAM cell consists of one transistor and one capacitor, commonly called a 1T1C memory cell.

The capacitor stores electrical charge representing a binary state. The access transistor connects the capacitor to the bit line when the word line is activated.

4.2 DRAM Operation

Write operation: The bit line is driven to represent the required data. The word line activates the access transistor, allowing the capacitor to be charged or discharged.

Read operation: Activating the word line connects the capacitor to the bit line. Charge sharing produces a small voltage change, which is detected by a sense amplifier.

A conventional DRAM read is destructive because the original capacitor charge is disturbed. The sense amplifier restores the data after detecting it.

Refresh operation: DRAM periodically reads and restores stored data to compensate for capacitor leakage.

Important: Refresh is required even when the processor is not actively accessing the DRAM data. The refresh interval and procedure depend on the memory device.

4.3 Advantages of DRAM

  • High storage density.
  • Lower cost per bit in typical implementations.
  • Suitable for large memory capacities.
  • Widely used as computer main memory.

4.4 Disadvantages of DRAM

  • Requires periodic refresh.
  • More complex control circuitry.
  • Read operations require sensing and restoration.
  • Generally slower than SRAM for comparable access conditions.

4.5 Applications of DRAM

  • Computer main memory.
  • Laptop and desktop memory modules.
  • Graphics memory implementations.
  • Servers and data-processing systems.
  • Embedded systems requiring large working memory.

6. SDRAM and DDR SDRAM

6.1 SDRAM

SDRAM stands for Synchronous Dynamic Random Access Memory. It operates in synchronization with an external clock, allowing memory commands and data transfers to follow defined timing relationships.

6.2 DDR SDRAM

DDR stands for Double Data Rate. DDR SDRAM transfers data on both the rising and falling edges of the clock, enabling two data transfers per clock cycle on the data interface.

DDR generations include DDR, DDR2, DDR3, DDR4 and DDR5. They differ in data rates, voltage, architecture, signaling and other specifications.

DDR memory is still DRAM. DDR describes a synchronous interface and data-transfer technique, not a separate storage-cell principle.

7. SRAM in Processor Cache Memory

Processor cache is a small, high-speed memory that stores frequently or recently accessed instructions and data. SRAM is commonly used to implement processor caches.

  • L1 Cache: Usually the smallest and fastest cache.
  • L2 Cache: Provides additional cache capacity.
  • L3 Cache: Often larger and shared among processor cores.

Cache reduces the average time required for a processor to access data from slower main memory.

Cache organization varies by processor. Not every processor has all three cache levels, and some embedded processors use tightly coupled memory or other architectures.

8. SRAM and DRAM in Embedded Systems

Microcontroller Example

A microcontroller may contain internal SRAM for:

  • Global and local variables.
  • Stack and heap memory.
  • Communication buffers.
  • Sensor data and temporary calculations.
  • RTOS task stacks and queues.

Embedded Linux Example

An embedded Linux board commonly uses external DRAM as its main working memory for the operating system, application processes, buffers and caches.

Practical Example

Consider a sensor monitoring system:

  1. A sensor produces a temperature reading.
  2. The microcontroller reads the sensor data.
  3. The reading is temporarily stored in SRAM.
  4. The controller processes the reading.
  5. Important measurements may be saved to Flash or another non-volatile storage device.

10. Practice Questions

Problem 1

A memory chip is organized as 4096 × 8. Calculate its storage capacity in bytes.

Solution:

Capacity = 4096 × 8 = 32768 bits.

Capacity = 32768 / 8 = 4096 bytes = 4 KiB.

Problem 2

How many address lines are required for a memory containing 8192 locations?

Solution:

8192 = 213.

Therefore, 13 address lines are required.

Problem 3

Which memory is generally preferred for a high-speed processor cache: SRAM or DRAM?

Answer: SRAM, because it generally offers lower access latency and does not require periodic refresh.

11. Lesson Summary

  • SRAM stores data using a bistable latch.
  • A common SRAM cell uses six transistors.
  • DRAM stores data as charge in a capacitor.
  • A conventional DRAM cell uses one transistor and one capacitor.
  • DRAM requires periodic refresh.
  • SRAM is commonly used for processor caches.
  • DRAM is commonly used for main memory.
  • DDR SDRAM transfers data on both clock edges.
