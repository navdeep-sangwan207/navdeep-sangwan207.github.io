Lesson 04: Flash Memory and Memory Organization

Learn Flash memory technology, NAND and NOR Flash, memory arrays, storage organization, capacity calculations and practical applications in embedded systems.

1. Introduction to Flash Memory

Flash memory is a type of non-volatile semiconductor memory that stores information even when electrical power is removed. It is widely used in microcontrollers, USB drives, memory cards, solid-state drives and embedded systems.

Flash memory is based on charge-storage memory cells. Programming and erasing operations change the electrical state of these cells.

Definition: Flash memory is electrically programmable and erasable non-volatile memory that generally erases data in blocks rather than individual bytes.

Why is Flash Memory Used?

  • Retains information without continuous power.
  • Provides relatively high storage density.
  • Can be electrically programmed and erased.
  • Suitable for storing firmware and application data.
  • Available in compact integrated circuit packages.

2. Flash Memory Technology

Flash memory commonly uses floating-gate or charge-trap transistor structures to store information.

Stored charge changes the transistor's threshold voltage. The memory sensing circuitry detects the resulting electrical characteristics and interprets them as stored data.

Basic Operations

  • Read: Detects the stored state of memory cells.
  • Program: Changes the cell state to store new data.
  • Erase: Returns cells in an erase unit to an erased state.
Flash programming and erasing are device-specific operations. A controller must follow the manufacturer's command sequence, voltage, timing and endurance specifications.

3. Types of Flash Memory

3.1 NOR Flash

NOR Flash provides an architecture that supports direct access to individual memory locations for reading. It is commonly used where code execution directly from non-volatile memory is required.

Characteristics

  • Good random-read capability.
  • Suitable for storing firmware and boot code.
  • Often supports execute-in-place (XIP).
  • Typically lower storage density than NAND Flash.
  • Erase operations are performed in sectors or blocks.

Applications

  • Microcontroller program memory.
  • Boot firmware.
  • Embedded system firmware storage.
  • Industrial controllers.

3.2 NAND Flash

NAND Flash is designed for high-density data storage. Its memory cells are arranged in strings and organized into pages and blocks.

Characteristics

  • High storage density.
  • Cost-effective for large storage capacities.
  • Data is commonly read and programmed in pages.
  • Erasure is performed in larger blocks.
  • Requires management of bad blocks and error correction.

Applications

  • USB flash drives.
  • SD and microSD memory cards.
  • Solid-state drives (SSDs).
  • Smartphones and embedded storage.

4. Difference Between NOR and NAND Flash

Parameter NOR Flash NAND Flash
Architecture NOR-type cell arrangement NAND-type cell arrangement
Read access Good random-read capability Page-oriented access
Storage density Typically lower Typically higher
Cost per bit Typically higher Typically lower
Erase operation Sector/block based Block based
Common use Firmware and boot code Mass data storage
Direct execution Often supports XIP Generally requires data to be loaded into RAM for execution
Exact performance, erase size and access characteristics depend on the specific Flash device and its interface.

5. NAND Flash Memory Organization

NAND Flash is organized hierarchically. Its common organizational units are:

  • Cell: Stores one or more bits.
  • Page: Group of memory cells used for read and program operations.
  • Block: Group of pages used as the erase unit.
  • Die: A semiconductor chip containing memory arrays.
  • Package: Physical component that may contain one or more dies.
A typical NAND device allows page-level programming and block-level erasure. Some devices impose additional restrictions on page-program order and partial-page writes.

6. SLC, MLC, TLC and QLC Flash

NAND Flash can store different numbers of bits in each memory cell by using multiple threshold-voltage states.

Type Bits per Cell Number of States
SLC 1 2
MLC 2 4
TLC 3 8
QLC 4 16

Explanation

  • SLC: Single-Level Cell.
  • MLC: Multi-Level Cell, commonly two bits per cell in this classification.
  • TLC: Triple-Level Cell, three bits per cell.
  • QLC: Quad-Level Cell, four bits per cell.

Increasing the number of bits per cell increases storage density, but generally makes sensing and programming more complex and can reduce endurance and performance.

The term MLC is sometimes used broadly for multi-bit cells. In the SLC/MLC/TLC/QLC comparison above, MLC specifically means two bits per cell.

7. Memory Organization

Memory organization describes how storage locations and data bits are arranged inside a memory device.

Memory Organization = Number of Locations × Bits per Location

Example: 2K × 8 Memory

A memory organized as 2K × 8 contains:

  • 2K = 2048 addressable locations.
  • 8 bits per location.
  • 2048 × 8 = 16384 bits.
  • 16384 / 8 = 2048 bytes = 2 KiB.

Example: 4K × 16 Memory

  • Number of locations = 4096.
  • Word width = 16 bits.
  • Total capacity = 4096 × 16 = 65536 bits.
  • Total capacity = 8192 bytes = 8 KiB.

8. Address Lines and Data Lines

Address Lines

Address lines select a particular memory location. If a memory contains 2n locations, it requires n address bits to select one location.

Number of Locations = 2n

Data Lines

Data lines transfer information between the memory and the processor or memory controller. For a conventional parallel memory interface, an 8-bit data bus transfers one byte per data access.

Example: 8K × 8 Memory

  • 8K = 8192 locations.
  • 8192 = 213.
  • Address lines = 13.
  • Data lines = 8.
  • Total capacity = 8192 × 8 = 65536 bits = 8 KiB.

9. Memory Access and Control Signals

A memory device may use control signals to coordinate read, write, selection and output operations.

Signal Function
Address Selects a memory location.
Data Transfers information.
CE / CS Chip Enable / Chip Select; activates the memory device.
OE Output Enable; controls data output drivers on supported interfaces.
WE Write Enable; controls write operation on supported interfaces.
Signal names, polarity and timing differ between memory devices. NAND Flash also uses command, address and data cycles rather than a simple asynchronous RAM-style interface.

10. Flash Memory Endurance and Reliability

Flash memory has a finite number of program/erase cycles. Repeated programming and erasing gradually degrades the memory cells.

Important Reliability Concepts

  • Endurance: Number of program/erase cycles a memory can support under specified conditions.
  • Data retention: Ability to retain stored information over time.
  • Wear leveling: Distributes writes across memory blocks to reduce uneven wear.
  • Bad block management: Identifies and avoids unreliable NAND blocks.
  • ECC: Error Correction Code detects and corrects certain data errors.

Flash Translation Layer (FTL)

NAND Flash storage devices commonly use a Flash Translation Layer to map logical addresses to physical memory locations, manage block erasure, handle bad blocks and support wear leveling.

SSDs and managed NAND devices often include internal controllers that perform these operations. Raw NAND generally requires additional management by the host controller or software.

11. Flash Memory in Embedded Systems

Microcontroller Applications

  • Storing firmware and application code.
  • Storing bootloader programs.
  • Storing calibration and configuration data.
  • Saving logs and event information.
  • Supporting firmware updates.

Firmware Update Process

  1. The controller receives a new firmware image.
  2. The image is checked for integrity and authenticity as required.
  3. The target Flash region is erased.
  4. The new firmware is programmed.
  5. The programmed image is verified.
  6. The system boots from the updated firmware according to its boot design.
Firmware updates must account for power failure, memory partitioning, bootloader recovery and image validation. A robust update system may use separate firmware slots.

13. Practice Problems

Problem 1

A memory device contains 16K locations, with 8 bits per location. Calculate its capacity in bytes.

Solution:

16K = 16384 locations.

Capacity = 16384 × 8 = 131072 bits.

Capacity = 131072 / 8 = 16384 bytes = 16 KiB.

Problem 2

How many address lines are required to access 32768 memory locations?

Solution:

32768 = 215.

Therefore, 15 address lines are required.

Problem 3

A NAND Flash block contains 128 pages. Each page has a data capacity of 4096 bytes. Calculate the total data capacity of the block.

Solution:

Block capacity = 128 × 4096 = 524288 bytes.

524288 bytes = 512 KiB.

Problem 4

Which Flash architecture is generally preferred for high-density storage such as memory cards?

Answer: NAND Flash.

14. Lesson Summary

  • Flash memory is non-volatile semiconductor memory.
  • NOR and NAND are two major Flash architectures.
  • NOR Flash is commonly used for firmware and boot code.
  • NAND Flash is commonly used for high-density storage.
  • NAND is organized into pages and blocks.
  • SLC, MLC, TLC and QLC store different numbers of bits per cell.
  • Flash memory has finite program/erase endurance.
  • Wear leveling, bad block management and ECC improve reliability.
  • Memory organization specifies locations and bits per location.
  • Address lines select locations, while data lines transfer information.
