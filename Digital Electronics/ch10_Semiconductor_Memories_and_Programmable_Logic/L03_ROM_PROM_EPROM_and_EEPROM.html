Lesson 03: ROM, PROM, EPROM and EEPROM

Understand non-volatile semiconductor memories, their programming methods, erasing techniques, characteristics and applications in digital and embedded systems.

1. Introduction to ROM

ROM stands for Read Only Memory. It is a type of non-volatile semiconductor memory used to store information that must be retained even when electrical power is removed.

ROM is commonly used for firmware, boot programs, lookup tables, configuration information and other data that does not need frequent modification.

Definition: ROM is non-volatile memory designed primarily for reading stored information. Different ROM technologies provide different programming and erasing capabilities.

Why is ROM required?

  • To store firmware and program instructions.
  • To retain information without continuous power.
  • To store boot code and initialization routines.
  • To store fixed lookup tables and control information.
  • To retain configuration data in electronic devices.

2. Types of ROM

The major traditional ROM categories are:

  1. Mask ROM (MROM)
  2. Programmable ROM (PROM)
  3. Erasable Programmable ROM (EPROM)
  4. Electrically Erasable Programmable ROM (EEPROM)

3. Mask ROM (MROM)

Mask ROM is programmed during semiconductor manufacturing. Its stored information is determined by the physical mask pattern used during fabrication.

Once manufactured, its contents cannot normally be changed by the user.

Characteristics

  • Programmed during manufacturing.
  • Contents are fixed after fabrication.
  • Suitable for high-volume production.
  • No user programming operation is required.

Applications

  • Mass-produced electronic products.
  • Fixed firmware in consumer devices.
  • Predefined lookup tables.
  • Special-purpose embedded systems.

4. Programmable ROM (PROM)

PROM stands for Programmable Read Only Memory. It is supplied in an unprogrammed state and can be programmed by the user using a suitable PROM programmer.

Traditional PROM devices use programmable links or fuses. Programming permanently changes selected connections according to the data being stored.

Programming Principle

  1. The PROM is connected to a compatible programmer.
  2. The required data is loaded into the programming software.
  3. The programmer applies the specified programming conditions.
  4. Selected programmable links are permanently changed.
  5. The programmed data can subsequently be read.
Important: Traditional fuse-based PROM is generally one-time programmable. It cannot be erased and reprogrammed like EEPROM.

Advantages

  • Can be programmed after manufacturing.
  • Useful for fixed application data.
  • Does not require continuous power to retain data.

Limitations

  • Traditional PROM cannot be erased.
  • Programming errors generally require replacement.
  • Requires compatible programming equipment.

5. Erasable Programmable ROM (EPROM)

EPROM is a non-volatile memory that can be programmed electrically and erased using ultraviolet (UV) light in devices designed for UV erasure.

EPROM cells commonly use floating-gate MOS transistors to store electrical charge.

Working Principle

  1. Data is programmed into the memory using a suitable programmer.
  2. Electrical charge is stored in the floating-gate structure.
  3. The stored charge changes the transistor's threshold voltage.
  4. The memory read circuitry interprets the resulting state as data.
  5. UV exposure erases the stored information in the EPROM device.

Characteristics

  • Non-volatile storage.
  • Can be erased using UV light.
  • Typically erased as an entire chip.
  • Usually requires removal from the circuit for erasure.
  • Can be reprogrammed after erasure.

Advantages

  • Reusable after erasure.
  • Retains data without power.
  • Useful for firmware development and older electronic systems.

Limitations

  • Erasing requires UV exposure.
  • Erasure takes considerably longer than electrical programming.
  • Typically requires a special package with a transparent window.

6. Electrically Erasable Programmable ROM (EEPROM)

EEPROM is a non-volatile semiconductor memory that can be electrically erased and reprogrammed.

Unlike UV-erasable EPROM, EEPROM does not require exposure to ultraviolet light. It can generally be updated while installed in the target circuit, subject to the device's electrical and interface requirements.

Working Principle

EEPROM commonly uses charge-storage transistor structures. Electrical programming and erase operations change the stored charge, which affects the transistor's threshold voltage and therefore the interpreted logic state.

Characteristics

  • Non-volatile memory.
  • Electrically programmable and erasable.
  • Can support byte-level or page-level updates, depending on the device.
  • Suitable for storing configuration information.
  • Has a finite write/erase endurance.

Advantages

  • Can be erased electrically.
  • No UV lamp is required.
  • Can be updated in the circuit.
  • Suitable for storing frequently updated configuration data.

Limitations

  • Write operations are generally slower than RAM access.
  • Limited write/erase endurance.
  • Typically lower density and higher cost per bit than NAND Flash.

Applications

  • Microcontroller configuration storage.
  • Calibration constants.
  • Device identification data.
  • Small settings and parameters.
  • Industrial control equipment.

8. EEPROM in Embedded Systems

EEPROM is useful in embedded systems when a small amount of information must be retained even after power is removed.

Example: Storing a Device Setting

Consider a temperature controller that allows the user to configure a temperature limit.

  1. The user sets the temperature limit to 35°C.
  2. The microcontroller writes the setting to EEPROM.
  3. The system is powered off.
  4. Power is restored later.
  5. The microcontroller reads the stored value from EEPROM.
  6. The controller resumes operation using the saved setting.
Design consideration: EEPROM has limited write endurance. Avoid unnecessary repeated writes. Use suitable wear-management techniques when data is updated frequently.

10. Practice Questions

Problem 1

Which memory technology is erased using ultraviolet light?

Answer: EPROM.

Problem 2

Which memory can be electrically erased and reprogrammed without UV exposure?

Answer: EEPROM.

Problem 3

A controller must retain a small configuration value when power is removed. Which memory technology is suitable?

Answer: EEPROM is a suitable choice, provided its capacity and endurance meet the application requirements.

11. Lesson Summary

  • ROM is non-volatile semiconductor memory.
  • Mask ROM is programmed during manufacturing.
  • Traditional PROM is generally one-time programmable.
  • EPROM is erased using ultraviolet light.
  • EEPROM is electrically erasable and programmable.
  • EPROM and EEPROM commonly use floating-gate storage technology.
  • EEPROM is useful for embedded configuration and calibration data.
  • EEPROM devices have finite write/erase endurance.
