Lesson 01: Introduction to Semiconductor Memories

Understand the fundamentals of semiconductor memory, its internal organization, operation, classification and applications in digital and embedded systems.

1. Introduction to Semiconductor Memory

Semiconductor memory is an electronic storage device implemented using semiconductor integrated circuits. It stores binary information in the form of bits (0 and 1).

Semiconductor memories are widely used in computers, microcontrollers, smartphones, digital instruments, embedded systems and electronic control units.

A memory device stores information so that a processor or digital circuit can retrieve it when required.

Definition: Semiconductor memory is an electronic memory implemented using semiconductor devices that stores digital information in binary form.

2. Why Do Digital Systems Need Memory?

A digital system requires memory to store instructions, input data, intermediate results and output information.

Major purposes of memory

  • Store program instructions for a processor.
  • Store temporary data during program execution.
  • Store configuration and calibration information.
  • Store sensor readings and processing results.
  • Retain firmware and boot information.
  • Store data for later retrieval.

Example: Microcontroller

A microcontroller generally uses different types of memory:

  • Flash memory: Stores program firmware.
  • SRAM: Stores variables and temporary data.
  • EEPROM: Stores settings or parameters that must survive power loss, when provided by the device.
The exact memory technologies and their sizes depend on the microcontroller. Some devices emulate EEPROM using Flash memory.

3. Basic Memory Operations

Semiconductor memory mainly performs two basic operations: read and write. Read-only memory devices have different write or programming restrictions.

3.1 Read Operation

A read operation retrieves the information stored at a selected memory address.

  1. The processor places an address on the address bus.
  2. The memory selects the corresponding storage location.
  3. The read control signal is activated.
  4. The stored data appears on the data output lines.
  5. The processor receives the data.

3.2 Write Operation

A write operation stores new information at a selected memory address in a writable memory device.

  1. The processor places the target address on the address bus.
  2. The data to be stored is placed on the data bus.
  3. The write control signal is activated.
  4. The memory stores the supplied data at the selected location.
Important: Address, data and control signals are conceptual bus functions. Their physical arrangement and timing depend on the memory interface.

4. Classification of Semiconductor Memories

Semiconductor memories can be classified according to their ability to retain information when power is removed.

4.1 Volatile Memory

Volatile memory requires electrical power to retain its stored information. When power is removed, its stored data is lost.

Examples: SRAM and DRAM.

4.2 Non-Volatile Memory

Non-volatile memory retains stored information even when electrical power is removed.

Examples: ROM, PROM, EPROM, EEPROM and Flash memory.

5. Important Memory Characteristics

5.1 Memory Capacity

Memory capacity indicates the total amount of information that a memory device can store.

Memory Capacity = Number of Locations × Bits per Location

Capacity is commonly expressed in bits or bytes.

  • 1 byte = 8 bits
  • 1 KB = 1024 bytes (in conventional binary memory calculations)
  • 1 MB = 1024 KB
  • 1 GB = 1024 MB
In modern storage specifications, decimal units are also used: 1 kB = 1000 bytes and 1 MB = 1,000,000 bytes. Always check which convention is being used.

5.2 Access Time

Access time is the time required for a memory operation to retrieve data or complete a specified access, measured under defined conditions.

5.3 Memory Cycle Time

Memory cycle time is the minimum time interval required between successive memory operations of a specified type.

5.4 Data Width

Data width is the number of bits transferred in parallel during one memory access.

For example, an 8-bit-wide memory transfers 8 bits in one access, while a 16-bit-wide memory transfers 16 bits.

5.5 Power Consumption

Memory devices consume power during read, write, standby and retention operations. Actual consumption depends on memory technology, operating voltage, access frequency and device configuration.

5.6 Data Retention

Data retention describes how long stored information remains valid. Volatile memories require power, whereas non-volatile memories are designed to retain data without continuous power.

6. Memory Organization

A memory device is organized as a collection of storage locations. Each location has a unique address and stores a fixed number of bits.

Memory organization is commonly written in the form:

Number of Locations × Number of Bits per Location

Example: 1K × 8 Memory

  • Number of locations = 1024
  • Bits per location = 8
  • Total capacity = 1024 × 8 bits
  • Total capacity = 8192 bits
  • Total capacity = 1024 bytes = 1 KiB

Therefore, a 1K × 8 memory stores 1024 bytes and transfers 8 bits per addressed location.

Address Lines

Address lines select a particular memory location. If a memory has n address lines, it can select up to 2n unique locations.

Number of Addressable Locations = 2n

Data Lines

Data lines carry information into or out of the memory. The number of data lines generally determines the memory word width for a parallel memory interface.

7. Applications of Semiconductor Memories

  • Microcontrollers: Program storage and runtime data.
  • Computers: Main memory, cache and firmware storage.
  • Embedded systems: Configuration, logs and application data.
  • Consumer electronics: Storage in televisions, cameras and phones.
  • Automotive electronics: ECU firmware and calibration data.
  • Industrial automation: Controller programs and process data.
  • Digital instruments: Measurement data and device settings.

8. Volatile vs Non-Volatile Memory

Feature Volatile Memory Non-Volatile Memory
Data retention Requires power Retains data without power
Typical use Temporary storage Persistent storage
Examples SRAM, DRAM ROM, EEPROM, Flash
Typical applications RAM and working memory Firmware and data storage

10. Practice Problems

Problem 1

A memory has 10 address lines. Calculate the maximum number of addressable locations.

Solution:

Number of locations = 210 = 1024 locations.

Problem 2

A memory is organized as 2048 × 8. Calculate its total capacity in bytes.

Solution:

Capacity = 2048 × 8 = 16384 bits.

Capacity in bytes = 16384 / 8 = 2048 bytes = 2 KiB.

Problem 3

How many address lines are required to select 4096 memory locations?

Solution:

4096 = 212.

Therefore, 12 address lines are required.

11. Lesson Summary

  • Semiconductor memory stores binary information.
  • Read and write are the basic memory operations.
  • Volatile memory loses data when power is removed.
  • Non-volatile memory retains data without power.
  • SRAM and DRAM are common volatile memories.
  • ROM and Flash are examples of non-volatile memory.
  • Memory capacity depends on locations and bits per location.
  • Address lines select locations; data lines transfer information.
