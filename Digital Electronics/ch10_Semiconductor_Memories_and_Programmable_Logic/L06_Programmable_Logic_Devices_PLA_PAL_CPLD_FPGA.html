Lesson 06: Programmable Logic Devices – PLA, PAL, CPLD and FPGA

Understand programmable logic devices, their architecture, logic implementation, differences, applications and importance in digital electronics and embedded hardware design.

1. Introduction to Programmable Logic Devices

A Programmable Logic Device (PLD) is a digital integrated circuit whose internal logic can be configured by the designer to perform a required logical function.

Traditional digital circuits are often built using individual logic gates and fixed-function ICs. PLDs allow designers to implement multiple logic functions within a programmable device.

Definition: A Programmable Logic Device is an integrated circuit that can be configured to implement specified digital logic functions.

Why Are PLDs Used?

  • Reduce the number of separate logic ICs.
  • Implement custom digital logic.
  • Reduce circuit board complexity.
  • Allow design changes through reprogramming on supported devices.
  • Implement control logic and digital interfaces.
  • Support rapid hardware prototyping.

2. Classification of Programmable Logic Devices

Major Types

  1. Programmable Logic Array (PLA)
  2. Programmable Array Logic (PAL)
  3. Complex Programmable Logic Device (CPLD)
  4. Field-Programmable Gate Array (FPGA)

3. Programmable Logic Array (PLA)

A Programmable Logic Array is a programmable logic device in which both the AND array and OR array are programmable.

Basic Architecture

Features of PLA

  • Both AND and OR arrays are programmable.
  • Provides flexible product-term generation.
  • Can implement multiple Boolean expressions.
  • Useful for combinational logic design.

Example

Consider the Boolean function:

F = A'B + AC

The PLA can generate product terms A'B and AC in its AND array and combine them using its OR array.

PLA provides flexibility because both logic arrays are programmable, although practical device structures and available product terms depend on the specific IC.

4. Programmable Array Logic (PAL)

A Programmable Array Logic device has a programmable AND array and a fixed OR array in its basic architecture.

Basic Architecture

Features of PAL

  • Programmable AND array.
  • Fixed OR array in the basic PAL architecture.
  • Generally simpler structure than a comparable PLA.
  • Suitable for implementing combinational logic.

Example

Consider:

F1 = A'B + AC

The programmable AND array generates the required product terms. The fixed OR structure combines the product terms according to the device architecture.

A PAL has constraints on how many product terms can feed each output. The exact limits depend on the device.

5. Difference Between PLA and PAL

Feature PLA PAL
AND Array Programmable Programmable
OR Array Programmable Fixed in basic architecture
Flexibility Higher More constrained
Logic Structure More flexible product-term connections Predetermined OR connections
Typical Design Custom Boolean functions Structured sum-of-products logic

6. Complex Programmable Logic Device (CPLD)

A CPLD is a programmable logic device that contains multiple logic blocks connected through a programmable interconnection network.

It provides more logic capacity than simple PLDs and is commonly used for control logic, glue logic and interface management.

Basic Architecture

Features of CPLD

  • Contains multiple programmable logic blocks.
  • Uses programmable interconnections.
  • Often provides predictable timing for control logic.
  • Can include registers and combinational logic.
  • Useful for interface and system-control applications.

Applications

  • Address decoding.
  • Bus control logic.
  • Glue logic between digital ICs.
  • Simple state machines.
  • Industrial control interfaces.

7. Field-Programmable Gate Array (FPGA)

An FPGA is a highly configurable digital integrated circuit containing programmable logic blocks, programmable interconnections and input/output blocks.

Designers can configure an FPGA to implement complex digital systems, parallel processing circuits, communication interfaces and custom hardware.

Basic FPGA Architecture

Important FPGA Components

  • Lookup Tables (LUTs): Implement combinational logic functions.
  • Flip-Flops: Store sequential logic states.
  • Programmable Interconnect: Connects internal logic resources.
  • I/O Blocks: Interface with external digital signals.
  • Clock Resources: Distribute and manage clock signals.
  • Block RAM: Provides internal memory in many FPGA families.
  • DSP Blocks: Accelerate arithmetic and signal-processing operations in supported devices.

What Is a LUT?

A Lookup Table is a configurable memory-based logic element used to implement Boolean functions.

For example, a 4-input LUT can implement any Boolean function of four inputs by storing the required output values for all 16 input combinations.

Number of Input Combinations = 2n

For four inputs, the LUT requires 24 = 16 stored truth-table values for a single-output function.

FPGA Applications

  • Digital signal processing.
  • Communication protocols and interfaces.
  • Custom processors and hardware accelerators.
  • Video and image processing.
  • Industrial automation.
  • Hardware prototyping and verification.

8. Difference Between CPLD and FPGA

Feature CPLD FPGA
Architecture Multiple logic blocks or macrocells Configurable logic blocks and routing resources
Logic Capacity Generally lower Generally much higher
Logic Structure Often product-term based Typically LUT and register based
Applications Control and glue logic Complex digital systems
Internal Resources Usually more limited May include RAM, DSP and clock-management resources
Configuration Device-dependent Device-dependent
CPLDs and FPGAs are not interchangeable in every design. Selection depends on logic capacity, timing, power, configuration, cost and available resources.

9. Hardware Description Languages (HDL)

Hardware Description Languages are used to describe digital hardware behaviour and structure.

Two widely used HDLs are:

  • Verilog: A hardware description language widely used for digital design.
  • VHDL: A strongly typed hardware description language used in FPGA and ASIC design.

Simple Verilog Example: AND Gate

module and_gate (
    input  wire A,
    input  wire B,
    output wire Y
);

assign Y = A & B;

endmodule

Explanation

  • module defines a hardware module.
  • input declares input signals.
  • output declares the output signal.
  • assign describes continuous combinational logic.
  • & represents the bitwise AND operation.
HDL describes hardware rather than ordinary sequential software instructions. Synthesis tools translate supported HDL constructs into hardware resources.

10. FPGA Design Flow

  1. Design Specification: Define the required hardware functionality.
  2. RTL Design: Write the design using Verilog or VHDL.
  3. Simulation: Verify the logic using a testbench.
  4. Synthesis: Convert the HDL design into a logic representation.
  5. Implementation: Perform placement and routing.
  6. Timing Analysis: Check timing constraints and paths.
  7. Bitstream Generation: Generate the device configuration data.
  8. Programming: Configure the FPGA using the appropriate programming interface.
  9. Hardware Testing: Verify the design on the target board.
FPGA development commonly uses vendor tools such as AMD Vivado and Intel Quartus Prime. Tool availability and device support depend on the selected FPGA family.

13. Practice Problems

Problem 1

Which device has both programmable AND and programmable OR arrays?

Answer: PLA.

Problem 2

Which device has a programmable AND array and a fixed OR array in its basic architecture?

Answer: PAL.

Problem 3

How many truth-table combinations are possible for a four-input LUT?

Solution:

24 = 16 combinations.

Problem 4

Which programmable device is generally more suitable for implementing complex parallel digital systems?

Answer: FPGA.

Problem 5

Name two commonly used Hardware Description Languages.

Answer: Verilog and VHDL.

14. Lesson Summary

  • PLDs implement programmable digital logic functions.
  • PLA has programmable AND and OR arrays.
  • PAL has a programmable AND array and fixed OR array in its basic architecture.
  • CPLDs contain multiple programmable logic blocks.
  • FPGAs contain configurable logic blocks and programmable routing.
  • LUTs implement combinational logic functions in many FPGAs.
  • Flip-flops implement sequential logic.
  • Verilog and VHDL are widely used hardware description languages.
  • FPGA design includes simulation, synthesis, implementation and timing analysis.
