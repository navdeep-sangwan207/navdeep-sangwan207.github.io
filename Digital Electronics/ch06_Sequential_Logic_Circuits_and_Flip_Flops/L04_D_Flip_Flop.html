2. What Is a D Flip-Flop?

A D flip-flop (Data or Delay flip-flop) is a bistable sequential circuit that stores one bit of binary information.

It has one main data input, D, a clock input and complementary outputs Q and Q̅.

In a positive-edge-triggered D flip-flop, the input D is sampled at the rising edge of the clock signal.

At the active clock edge, the next output becomes equal to the data input:
Q⁺ = D

3. Logic Symbol of D Flip-Flop

Terminals

  • D: Data input.
  • CLK: Clock input.
  • Q: Normal output.
  • Q̅: Complementary output.

Some practical ICs also provide asynchronous preset and clear inputs. Their operation and active polarity depend on the selected device.

4. Working Principle

The D flip-flop samples its input at the specified active clock edge.

  1. Apply a binary value to the D input.
  2. Wait for the active clock edge.
  3. The flip-flop captures the input value.
  4. The output Q updates to that captured value.
  5. The output retains the stored value until the next valid update.
Example:

If D = 1 immediately before the active rising clock edge, Q becomes 1 after the clock-to-output propagation delay.

If D = 0 before the next rising edge, Q becomes 0 after that edge.

5. Truth Table of D Flip-Flop

The following table represents a positive-edge-triggered D flip-flop. The output is updated only at the active clock edge.

Clock Event D Present Q Next Q⁺
Rising edge 0 0 0
Rising edge 0 1 0
Rising edge 1 0 1
Rising edge 1 1 1
No active edge X Q Q
X means that the input can be either 0 or 1 when no active clock edge occurs. The stored output remains unchanged.

6. Characteristic Equation

The characteristic equation of a D flip-flop describes its next-state behavior.

Q⁺ = D

This equation means that the next state of the flip-flop is equal to the value present at the D input when the active clock edge occurs.

A positive-edge-triggered flip-flop captures the data input when the clock changes from LOW to HIGH.

A negative-edge-triggered flip-flop captures the data input when the clock changes from HIGH to LOW.

A timing diagram shows how input, clock and output signals change with time.

The output Q captures the D value at each rising clock edge. The diagram is illustrative; actual transitions include propagation delay.

9. Setup Time and Hold Time

Setup Time

Setup time is the minimum duration for which the data input must remain stable before the active clock edge.

Hold Time

Hold time is the minimum duration for which the data input must remain stable after the active clock edge.

Why Are They Important?

  • They help ensure reliable data capture.
  • They prevent timing violations.
  • They reduce the risk of metastability.
  • They influence maximum operating frequency.
Setup and hold values are specified in the manufacturer's datasheet and depend on the particular IC and operating conditions.

10. D Flip-Flop as a One-Bit Memory

A D flip-flop can store one bit of data. The stored value remains available at its output until the next active clock edge updates it.

11. D Flip-Flop IC Examples

74LS74

  • Dual D-type positive-edge-triggered flip-flop.
  • Contains two independent D flip-flop sections.
  • Provides Q and complementary outputs.
  • Includes asynchronous preset and clear inputs.

CD4013

  • Dual D-type flip-flop in the CMOS 4000 series.
  • Provides two independent storage sections.
  • Includes clock, data, set and reset inputs.
  • Useful in counters, dividers and control circuits.
Verify the exact IC variant, pinout, supply range, clock requirements and asynchronous control polarity from the manufacturer's datasheet before designing a circuit.

12. Applications of D Flip-Flop

  • One-bit data storage.
  • Digital registers.
  • Shift registers.
  • Data synchronization circuits.
  • Digital counters.
  • Finite state machines.
  • Serial communication circuits.
  • Pipeline registers in processors.
  • Embedded system control logic.

13. Advantages of D Flip-Flop

  • Simple single-data-input structure.
  • Stores one bit reliably when timing requirements are met.
  • Easy to connect in register structures.
  • Suitable for synchronous digital systems.
  • Widely available in integrated circuit form.

14. Limitations of D Flip-Flop

  • Stores only one bit per flip-flop.
  • Requires a clock for synchronous operation.
  • Has setup-time and hold-time requirements.
  • Consumes power and introduces propagation delay.
  • Large registers require multiple flip-flops.

15. Practical Experiment – D Flip-Flop Using 74LS74

Components Required

  • 74LS74 dual D flip-flop IC.
  • Input switch for D.
  • Push-button or suitable clock pulse source.
  • LED indicator.
  • Current-limiting resistor.
  • Regulated 5 V supply suitable for the selected LS-TTL device.
  • Breadboard and connecting wires.

Procedure

  1. Identify the IC pin configuration from its datasheet.
  2. Connect the IC supply and ground correctly.
  3. Connect the D input to a defined logic level through a switch arrangement.
  4. Keep the asynchronous preset and clear inputs inactive according to their active-low behavior.
  5. Connect the clock input to a suitable pulse source.
  6. Connect Q to an LED indicator using a suitable interface and resistor.
  7. Apply D = 1 and generate a rising clock edge.
  8. Observe Q becoming 1.
  9. Apply D = 0 and generate another rising clock edge.
  10. Observe Q becoming 0.
Do not leave asynchronous control inputs floating. A mechanical push-button can produce multiple transitions due to contact bounce; use a debounced clock source for reliable testing. Observe the IC's output-current limits.

18. Lesson Summary

  • A D flip-flop stores one bit of binary information.
  • It has a data input D and clock input CLK.
  • Its characteristic equation is Q⁺ = D.
  • A positive-edge-triggered device samples D on the rising clock edge.
  • A negative-edge-triggered device samples D on the falling clock edge.
  • The output retains its state between active clock edges.
  • Setup time and hold time are essential timing requirements.
  • 74LS74 and CD4013 are common dual D flip-flop IC examples.
