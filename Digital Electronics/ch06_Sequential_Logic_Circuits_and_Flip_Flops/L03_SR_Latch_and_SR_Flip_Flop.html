Lesson 3: SR Latch and SR Flip-Flop

Chapter 6 – Sequential Logic Circuits and Flip-Flops

1. Learning Objectives

  • Understand the working principle of an SR latch.
  • Learn NOR-based and NAND-based SR latch circuits.
  • Understand Set, Reset, Hold and forbidden conditions.
  • Study the truth tables of SR latches.
  • Understand the operation of a clocked SR flip-flop.
  • Learn characteristic equations and practical applications.

2. What Is an SR Latch?

An SR latch is a bistable memory circuit that stores one bit of binary information.

SR stands for:

  • S – Set: Forces the output Q to 1.
  • R – Reset: Forces the output Q to 0.

The circuit has two complementary outputs, usually represented by Q and Q̅.

An SR latch can retain its previous output even after the input signals are removed. This is the basic memory property of the circuit.

3. NOR-Based SR Latch

An SR latch can be constructed using two cross-coupled NOR gates.

For the standard NOR-based SR latch, both inputs are active HIGH.

Working Principle

  • S = 1, R = 0: Set operation.
  • S = 0, R = 1: Reset operation.
  • S = 0, R = 0: Hold operation.
  • S = 1, R = 1: Forbidden input condition.

Note: This is a conceptual feedback illustration, not a gate-pin-level wiring schematic. The two NOR outputs feed the opposite NOR inputs.

Truth Table – NOR-Based SR Latch

S R Q⁺ Operation
0 0 Q Hold
0 1 0 Reset
1 0 1 Set
1 1 Invalid Forbidden
When S = R = 1, both NOR outputs become 0. This violates the normal complementary-output relationship. When the inputs return to 0, the final state may be unpredictable because of internal propagation delays.

4. Characteristic Equation of NOR-Based SR Latch

The characteristic equation describes the relationship between present inputs, present state and next state.

For the active-HIGH NOR-based SR latch, excluding the forbidden input combination:

Q⁺ = S + R̅Q

The equation is valid for the legal input combinations S,R = 00, 01 and 10. It must not be used to assign a valid next state to S = R = 1.

Explanation

  • If S = 1, the next state becomes 1.
  • If R = 1 and S = 0, the next state becomes 0.
  • If S = 0 and R = 0, the previous state is retained.

5. NAND-Based SR Latch

An SR latch can also be constructed using two cross-coupled NAND gates.

Unlike the NOR-based implementation, the NAND-based latch uses active-LOW inputs. These inputs are commonly represented by S̅ and R̅.

Truth Table – NAND-Based SR Latch

S̅ R̅ Q⁺ Operation
11QHold
011Set
100Reset
00InvalidForbidden
Remember:
  • NOR SR latch: active-HIGH inputs.
  • NAND SR latch: active-LOW inputs.

6. NOR vs NAND SR Latch

Parameter NOR-Based NAND-Based
Gate Used NOR NAND
Input Polarity Active HIGH Active LOW
Hold Condition S = 0, R = 0 S̅ = 1, R̅ = 1
Set Condition S = 1, R = 0 S̅ = 0, R̅ = 1
Reset Condition S = 0, R = 1 S̅ = 1, R̅ = 0
Forbidden Condition S = 1, R = 1 S̅ = 0, R̅ = 0

7. What Is an SR Flip-Flop?

An SR flip-flop is a clock-controlled Set-Reset memory element.

In a clocked SR flip-flop, the S and R inputs determine the next state when the clock's specified active event occurs.

Depending on its implementation, the device may be edge-triggered or built using clock-controlled latch stages.

A clocked SR device differs from a basic unclocked SR latch because its state changes are controlled by a clock or enable condition.

8. Clocked SR Flip-Flop Truth Table

The following table represents a positive-edge triggered SR flip-flop. The inputs are sampled at the rising edge of the clock.

Clock Event S R Q⁺ Operation
Rising edge 0 0 Q Hold
Rising edge 0 1 0 Reset
Rising edge 1 0 1 Set
Rising edge 1 1 Invalid Forbidden

Between active clock edges, the stored state remains unchanged in an edge-triggered device, provided no asynchronous control input is activated.

9. Characteristic Table

A characteristic table shows the next state for each legal input combination and present state.

For an SR flip-flop:

S R Present State Q Next State Q⁺
0000
0011
0100
0110
1001
1011
11XInvalid

X represents either possible present state. The S = R = 1 condition remains forbidden.

10. Working Examples

Example 1 – Set Operation

Given:

S = 1, R = 0

The SR latch enters the Set state.

Q⁺ = 1

Example 2 – Reset Operation

Given:

S = 0, R = 1

The SR latch enters the Reset state.

Q⁺ = 0

Example 3 – Hold Operation

Suppose the present output is Q = 1 and:

S = 0, R = 0

The latch retains its previous state.

Q⁺ = 1

11. Applications of SR Latches and Flip-Flops

  • Basic one-bit memory circuits.
  • Switch debouncing circuits.
  • Set-reset control logic.
  • Digital control systems.
  • State storage in sequential circuits.
  • Control and status flag circuits.

12. Advantages

  • Simple circuit construction.
  • Stores one bit of information.
  • Can retain a state through feedback.
  • Useful for understanding bistable memory operation.
  • Can be implemented using basic logic gates.

13. Limitations

  • The basic SR latch has a forbidden input combination.
  • Input polarity must be considered during circuit design.
  • Clocked implementations require correct timing.
  • Asynchronous input transitions may create timing hazards.
  • More flexible storage applications may use D or JK flip-flops.

14. Practical Experiment – SR Latch Using NOR Gates

Components Required

  • Two NOR gates, such as a suitable 7402-family IC.
  • Two input switches for S and R.
  • LED indicator.
  • Suitable LED current-limiting resistor.
  • Regulated power supply compatible with the selected IC.
  • Breadboard and connecting wires.

Procedure

  1. Construct two cross-coupled NOR gates.
  2. Connect the output of each gate to one input of the opposite gate.
  3. Use the remaining inputs for S and R.
  4. Connect an indicator to the Q output through a suitable resistor and interface arrangement.
  5. Apply S = 1 and R = 0 to observe the Set state.
  6. Apply S = 0 and R = 1 to observe the Reset state.
  7. Apply S = 0 and R = 0 to observe the Hold state.
  8. Do not use S = 1 and R = 1 as a normal operating condition.
Never leave CMOS inputs floating. Use defined logic levels and verify the selected IC's supply voltage, pinout and output-current limits from its datasheet. Avoid connecting LEDs directly without current limiting.

17. Lesson Summary

  • An SR latch stores one bit using Set and Reset inputs.
  • A NOR-based SR latch uses active-HIGH inputs.
  • A NAND-based SR latch uses active-LOW inputs.
  • The basic SR latch has Set, Reset, Hold and Forbidden conditions.
  • The forbidden condition must be avoided in normal operation.
  • A clocked SR flip-flop updates its state according to the specified clock event.
  • SR memory elements are useful in basic control and storage circuits.
