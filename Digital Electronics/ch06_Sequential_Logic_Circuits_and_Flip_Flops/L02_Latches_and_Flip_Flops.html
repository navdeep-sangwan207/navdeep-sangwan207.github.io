2. What Is a Latch?

A latch is a basic bistable memory element used to store one bit of binary information.

It has two stable output states: logic 0 and logic 1.

A latch is generally level-sensitive. Its output can respond to input changes while its enable signal is at the active level.

A latch can store one bit of information and retain its state when it is disabled.

Basic Characteristics

  • Stores one binary bit.
  • Usually controlled by an enable signal.
  • Level-sensitive operation.
  • Can be constructed using cross-coupled logic gates.
  • Used in temporary data storage and control circuits.

3. What Is a Flip-Flop?

A flip-flop is a bistable memory element used to store one bit of binary information.

A standard edge-triggered flip-flop changes its stored output in response to a specified active clock edge.

Depending on the design, the active edge may be the rising edge or the falling edge.

Flip-flops are widely used in registers, counters, digital control systems and synchronous sequential circuits.

4. Difference Between Latch and Flip-Flop

Parameter Latch Flip-Flop
Basic Function Stores one bit Stores one bit
Sensitivity Level-sensitive Typically edge-triggered
Control Signal Enable or gate signal Clock signal
Output Change Can change while enabled Changes at the active clock edge
Timing Depends on enable level Depends on active clock edge
Applications Data holding and temporary storage Registers, counters and state machines
Important: Not every device called a flip-flop is edge-triggered. The term is commonly used for edge-triggered bistable storage elements in digital design.

5. Level-Sensitive Operation

A level-sensitive latch responds to its data input during the active level of its enable signal.

For an active-HIGH transparent D latch:

  • When EN = 1, the output follows the data input.
  • When EN = 0, the output retains its previous value.

6. Edge-Triggered Operation

An edge-triggered flip-flop samples its input at a particular transition of the clock signal.

Rising-Edge Triggering

The flip-flop responds when the clock changes from LOW to HIGH.

Falling-Edge Triggering

The flip-flop responds when the clock changes from HIGH to LOW.

7. Types of Latches

A. SR Latch

An SR latch is a Set-Reset latch with two control inputs: S and R.

  • S = 1, R = 0: Set the output.
  • S = 0, R = 1: Reset the output.
  • S = 0, R = 0: Hold the previous state.
  • S = 1, R = 1: Forbidden condition for the basic NOR implementation.

B. D Latch

A D latch uses a data input D and an enable input EN. It avoids the simultaneous set and reset condition found in a basic SR latch.

  • When EN = 1, Q follows D.
  • When EN = 0, Q retains its previous value.
SR and D latches are commonly used to understand the basic principles of binary storage.

8. Types of Flip-Flops

Four commonly studied flip-flops are:

Flip-Flop Inputs Basic Function
SR S, R Set and Reset
D D Data storage
JK J, K Set, Reset, Hold and Toggle
T T Toggle or Hold

These devices are covered individually in the following lessons.

9. Timing Parameters

Correct operation of latches and flip-flops requires signals to satisfy timing constraints.

Setup Time

Setup time is the minimum interval for which the data input must remain stable before the active clock edge.

Hold Time

Hold time is the minimum interval for which the data input must remain stable after the active clock edge.

Propagation Delay

Propagation delay is the time between the relevant input or clock transition and the corresponding output response.

Violating setup or hold requirements can cause metastability or unpredictable behavior. Timing values depend on the particular device and operating conditions.

10. Applications of Latches and Flip-Flops

  • Temporary data storage.
  • Digital registers.
  • Binary counters.
  • Frequency divider circuits.
  • Serial communication circuits.
  • Finite state machines.
  • Microprocessors and microcontrollers.
  • Digital control systems.

11. Practical Example – Data Storage

Example: D Latch

Consider an active-HIGH D latch.

  1. Apply D = 1 and EN = 1.
  2. The output Q becomes 1.
  3. Change D to 0 while EN remains 1.
  4. The output Q follows the new input and becomes 0.
  5. Set EN = 0.
  6. Change D again. The output retains its previous value.

14. Lesson Summary

  • A latch and flip-flop are bistable memory elements that store one bit.
  • Latches are generally level-sensitive.
  • Standard synchronous flip-flops are generally edge-triggered.
  • SR and D are common latch types.
  • SR, D, JK and T are commonly studied flip-flop types.
  • Clock edges determine when edge-triggered flip-flops update.
  • Setup time and hold time are important timing requirements.
  • These memory elements form the foundation of registers and counters.
