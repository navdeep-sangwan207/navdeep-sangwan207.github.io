2. Present State and Next State

A flip-flop is a bistable sequential circuit that stores one bit of binary information. Its output can be either 0 or 1.

  • Present state (Q): The current stored output.
  • Next state (Q⁺): The output after the active clock event.
  • Inputs: Signals that determine the next state.
  • Clock: Controls when the state transition occurs.
The next state depends on the present state and the input conditions applied to the flip-flop.

3. What Is a Characteristic Table?

A characteristic table describes the next state of a flip-flop for every possible combination of its inputs and present state.

It answers the question: Given the current state and inputs, what will the next state be?

Example: D Flip-Flop

D Present Q Next Q⁺
000
010
101
111

The next state of a D flip-flop always follows the D input at the active clock edge.

4. What Is a Characteristic Equation?

A characteristic equation is a Boolean expression that represents the next state of a flip-flop in terms of its inputs and present state.

It provides a mathematical description of the flip-flop's state transition behavior.

A characteristic equation is useful for analyzing and designing sequential logic circuits.

5. Characteristic Equation of SR Flip-Flop

The SR flip-flop has two inputs: Set (S) and Reset (R).

Q⁺ = S + R̅Q

This equation applies to the conventional active-HIGH SR flip-flop when the forbidden input combination S = R = 1 is excluded.

Characteristic Table

S R Present Q Next Q⁺ Operation
0000Hold
0011Hold
01X0Reset
10X1Set
11XInvalidForbidden
X means the present state does not affect the result. The S = R = 1 condition is excluded for the conventional NOR-based active-HIGH SR latch/flip-flop.

6. Characteristic Equation of JK Flip-Flop

The JK flip-flop has two inputs, J and K. It provides Hold, Reset, Set and Toggle operations.

Q⁺ = JQ̅ + K̅Q

Characteristic Table

J K Present Q Next Q⁺ Operation
0000Hold
0011Hold
01X0Reset
10X1Set
1101Toggle
1110Toggle

7. Characteristic Equation of D Flip-Flop

The D flip-flop has one input called D. Its next state is equal to the value of D at the active clock edge.

Q⁺ = D

Characteristic Table

D Present Q Next Q⁺
000
010
101
111

8. Characteristic Equation of T Flip-Flop

The T flip-flop has one input called T. It performs Hold when T = 0 and Toggle when T = 1.

Q⁺ = T ⊕ Q

Characteristic Table

T Present Q Next Q⁺ Operation

011Hold
101Toggle
110Toggle

9. What Is an Excitation Table?

An excitation table specifies the input conditions required to produce a desired transition from a present state to a next state.

It answers the question: Given the present and desired next state, what input should be applied?

Characteristic tables work from inputs to next state. Excitation tables work from desired state transition to required inputs.

10. Excitation Table of SR Flip-Flop

Present Q Next Q⁺ S R
000X
0110
1001
11X0

The forbidden condition S = R = 1 is avoided. X represents a don't-care input.

11. Excitation Table of JK Flip-Flop

Present Q Next Q⁺ J K
000X
011X
10X1
11X0

For example, if the present state is 0 and the desired next state is 1, J must be 1 while K can be either 0 or 1.

12. Excitation Table of D Flip-Flop

Present Q Next Q⁺ D
000
011
100
111
D = Q⁺

13. Excitation Table of T Flip-Flop

Present Q Next Q⁺ T
000
011
101
110
T = Q ⊕ Q⁺

15. Characteristic Table vs Excitation Table

Parameter Characteristic Table Excitation Table
Purpose Determines next state Determines required inputs
Known Values Inputs and present state Present and next state
Unknown Value Next state Required inputs
Application Analyzing flip-flop behavior Designing sequential circuits

16. Solved Example 1 – JK Flip-Flop

Problem

A JK flip-flop has present state Q = 0. Find the required J and K inputs to obtain next state Q⁺ = 1.

Solution

From the JK excitation table:

0 → 1 : J = 1, K = X

Therefore, J must be 1 and K may be either 0 or 1.

Answer: J = 1, K = X.

17. Solved Example 2 – D Flip-Flop

Problem

A D flip-flop must change its state from 1 to 0. Find the required D input.

Solution

The characteristic equation is:

Q⁺ = D

Since the desired next state is 0:

D = 0

Answer: D = 0.

18. Solved Example 3 – T Flip-Flop

Problem

A T flip-flop has present state Q = 1. Find T if the required next state is 0.

Solution

The excitation equation is:

T = Q ⊕ Q⁺

Substituting the values:

T = 1 ⊕ 0 = 1

Answer: T = 1.

19. Applications in Sequential Circuit Design

  • Designing synchronous counters.
  • Designing asynchronous counters.
  • Developing finite state machines.
  • Designing sequence detectors.
  • Implementing control circuits.
  • Analyzing state transitions.
  • Selecting suitable flip-flops for a required state sequence.

20. General Procedure for Sequential Circuit Design

  1. Understand the required circuit behavior.
  2. Prepare the state diagram or state table.
  3. Assign binary codes to the states.
  4. Identify present-state and next-state variables.
  5. Select the required flip-flop type.
  6. Use its excitation table to find the required inputs.
  7. Simplify the input Boolean expressions using Boolean algebra or Karnaugh maps.
  8. Draw the logic circuit.
  9. Verify the circuit using simulation or hardware.

23. Lesson Summary

  • Present state is the current stored output.
  • Next state is the output after the active clock event.
  • A characteristic table determines the next state from the inputs and present state.
  • A characteristic equation expresses the next state mathematically.
  • An excitation table determines the inputs required for a desired state transition.
  • SR, JK, D and T flip-flops have different excitation requirements.
  • Excitation tables are important in counter and finite state machine design.
