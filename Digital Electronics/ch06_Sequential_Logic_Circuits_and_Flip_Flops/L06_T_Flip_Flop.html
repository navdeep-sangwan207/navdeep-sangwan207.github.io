Lesson 6: T Flip-Flop

Chapter 6 – Sequential Logic Circuits and Flip-Flops

  • Understand the working principle of a T flip-flop.
  • Identify its input, clock and output terminals.
  • Understand Hold and Toggle operations.

2. What Is a T Flip-Flop?

A T flip-flop, also called a Toggle flip-flop, is a sequential logic circuit that stores one bit of information.

It has one main control input called T, a clock input and two outputs Q and Q̅.

The T flip-flop has two basic operations: Hold when T = 0 and Toggle when T = 1 at the active clock edge.

3. Logic Symbol of T Flip-Flop

Terminals

  • T: Toggle control input.
  • CLK: Clock input.
  • Q: Normal output.
  • Q̅: Complementary output.

4. Working Principle

The T flip-flop changes its output according to the value of T at the active clock edge.

Condition 1: Hold (T = 0)

When T = 0, the output does not change. The previous state is retained.

Q⁺ = Q

Condition 2: Toggle (T = 1)

When T = 1, the output changes to its complement at every active clock edge.

Q⁺ = Q̅

5. Truth Table of T Flip-Flop

Clock Event T Present Q Next Q⁺ Operation
Active edge 0 0 0 Hold
Active edge 0 1 1 Hold
Active edge 1 0 1 Toggle
Active edge 1 1 0 Toggle

6. Characteristic Equation

The characteristic equation defines the next state of the T flip-flop using its input T and present output Q.

Q⁺ = T ⊕ Q

Here, ⊕ represents the XOR operation.

Derivation

  • When T = 0: Q⁺ = 0 ⊕ Q = Q.
  • When T = 1: Q⁺ = 1 ⊕ Q = Q̅.
The XOR operation naturally produces the required Hold and Toggle behavior.

9. T Flip-Flop Using JK Flip-Flop

A T flip-flop can be implemented using a JK flip-flop by connecting both inputs together.

J = K = T

When T = 0, both J and K are 0, so the output holds its state.

When T = 1, both J and K are 1, so the output toggles.

The two JK inputs are connected to the same T signal. The clock remains connected to the JK flip-flop clock input.

10. T Flip-Flop Using D Flip-Flop

A T flip-flop can also be implemented using a D flip-flop with an XOR gate.

D = T ⊕ Q

The XOR gate combines the T input with the present output Q. Its result is applied to the D input.

  • When T = 0, D = Q, so the output holds.
  • When T = 1, D = Q̅, so the output toggles.

11. Timing Diagram and Toggle Sequence

When T remains HIGH, the output toggles at each active clock edge. When T is LOW, the output retains its previous state.

The output changes only at the active clock edge. It does not continuously toggle while the clock is HIGH in a properly edge-triggered T flip-flop.

12. T Flip-Flop as a Frequency Divider

A T flip-flop can be used as a divide-by-2 frequency divider by connecting T permanently to logic HIGH.

fQ = fCLK / 2

The output changes state at every active clock edge. One complete output cycle therefore requires two clock cycles.

Example

If the input clock frequency is 1000 Hz:

fQ = 1000 / 2 = 500 Hz

The output frequency is 500 Hz, assuming a continuously toggling flip-flop.

13. Applications of T Flip-Flop

  • Binary counters.
  • Frequency divider circuits.
  • Digital event counting.
  • Toggle control circuits.
  • Sequential logic systems.
  • Clock division stages.
  • Digital timing circuits.

14. Advantages

  • Simple Hold and Toggle operation.
  • Useful for binary counter design.
  • Can divide clock frequency by two.
  • Simple characteristic equation.
  • Can be implemented using JK or D flip-flops.

15. Limitations

  • Has only one main control input.
  • Does not provide independent Set and Reset control.
  • Requires a clock signal for state transitions.
  • Subject to propagation delay and timing constraints.
  • Multiple stages can introduce cumulative timing delays.

16. Practical Experiment – T Flip-Flop

Components Required

  • JK flip-flop IC or suitable digital logic simulator.
  • Input switch for T.
  • Clock pulse generator.
  • LED indicator for Q.
  • Current-limiting resistor.
  • Suitable regulated power supply.
  • Breadboard and connecting wires.

Procedure

  1. Use a JK flip-flop and connect J and K together.
  2. Connect the common input to the T signal.
  3. Connect the clock source to the clock input.
  4. Set asynchronous controls to inactive levels.
  5. Connect Q to an LED through a suitable resistor.
  6. Set T = 0 and apply clock pulses.
  7. Observe that Q remains unchanged.
  8. Set T = 1 and apply clock pulses.
  9. Observe that Q toggles at every active clock edge.
Verify the IC datasheet for its supply voltage, clock triggering, pin configuration and asynchronous control polarity. Use defined logic levels and do not leave inputs floating.

19. Lesson Summary

  • A T flip-flop stores one bit of binary information.
  • It has one main input called T.
  • T = 0 produces Hold operation.
  • T = 1 produces Toggle operation.
  • Its characteristic equation is Q⁺ = T ⊕ Q.
  • Its excitation equation is T = Q ⊕ Q⁺.
  • It can be implemented using JK or D flip-flops.
  • It can divide the input clock frequency by two.
  • It is widely used in counters and digital timing circuits.
