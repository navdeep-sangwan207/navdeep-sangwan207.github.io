2. What Is a Sequential Logic Circuit?

A sequential logic circuit is a digital circuit whose output depends on both the present inputs and the previously stored information (present state).

Unlike combinational circuits, sequential circuits contain memory elements that store binary information.

The output of a sequential circuit depends on:
  • Present input values.
  • Previously stored state information.

Examples include counters, registers, digital clocks, sequence detectors and control circuits.

3. Basic Block Diagram

Basic Operation

  1. The circuit receives external input signals.
  2. Combinational logic processes the inputs and present state.
  3. It generates the next-state information.
  4. Memory elements store the state according to their operating conditions.
  5. The stored state influences future circuit operation.

4. Combinational vs Sequential Circuits

Parameter Combinational Circuit Sequential Circuit
Output Dependency Present inputs only Present inputs and stored state
Memory No memory element Contains memory elements
Feedback Normally absent May use feedback
Clock Not required for basic operation May be clocked or unclocked
Output Timing After propagation delay Depends on inputs, state and timing behavior
Examples Adders, multiplexers, encoders Counters, registers, sequence detectors

5. Memory Elements in Sequential Circuits

A memory element stores one or more binary bits. It allows a digital circuit to retain information even after its input changes.

Common Memory Elements

  • Latch: A level-sensitive storage element.
  • Flip-Flop: An edge-triggered storage element in its standard synchronous form.
  • Register: A group of flip-flops used to store multiple bits.
A single flip-flop normally stores one bit: either logic 0 or logic 1.

6. Types of Sequential Circuits

A. Synchronous Sequential Circuits

Synchronous sequential circuits use a clock signal to coordinate state changes. In a typical edge-triggered design, the state updates at a specified active clock edge.

Examples:

  • Synchronous counters.
  • Shift registers.
  • Clocked finite state machines.

B. Asynchronous Sequential Circuits

Asynchronous sequential circuits do not rely on a single global clock to control every state change. Their operation depends on input changes and internal propagation and feedback delays.

Examples include:

  • Asynchronous control circuits.
  • Unclocked handshake circuits.
  • Some asynchronous counters.
An asynchronous ripple counter is an important example of a sequential circuit in which successive flip-flops are triggered by preceding stages rather than all sharing the same clock edge.

7. Role of Clock Signal

A clock is a periodic digital signal that provides timing reference for synchronous sequential circuits.

A clock signal alternates between logic HIGH and logic LOW.

Important Clock Terms

  • Clock Period (T): Time required to complete one cycle.
  • Frequency (f): Number of clock cycles per second.
  • Rising Edge: Transition from LOW to HIGH.
  • Falling Edge: Transition from HIGH to LOW.
  • Duty Cycle: Percentage of one period for which the clock remains HIGH.
f = 1 / T
Example:

If the clock period is 10 ms:

f = 1 / 0.01 = 100 Hz

8. State, Present State and Next State

The state of a sequential circuit represents the information currently stored in its memory elements.

  • Present State: Current stored binary information.
  • Next State: State that the circuit will enter after the required state-update event.
  • State Transition: Change from one state to another.
Example – One-Bit Toggle Operation

Consider a flip-flop configured to toggle its output on every active clock edge.

Present State Q Next State Q⁺
01
10

The output changes state on each active clock edge. This behavior is used in binary counters.

9. State Table

A state table describes the relationship between present inputs, present state and next state.

A simple conceptual state table for a toggle operation is shown below.

Present State Q Toggle Control T Next State Q⁺
000
011
101
110
Q⁺ = T ⊕ Q

This is the characteristic equation of a T flip-flop. It shows that the output remains unchanged when T = 0 and toggles when T = 1.

10. Applications of Sequential Circuits

  • Digital counters and frequency dividers.
  • Digital clocks and timers.
  • Data storage and registers.
  • Serial communication interfaces.
  • Traffic light controllers.
  • Finite state machine controllers.
  • Microprocessors and digital systems.
  • Embedded system control logic.

11. Advantages of Sequential Circuits

  • Can store binary information.
  • Can perform operations over multiple clock cycles.
  • Useful for designing counters and registers.
  • Can implement complex control sequences.
  • Provide the foundation for digital processing systems.

12. Practical Example – Binary State Storage

Consider a one-bit memory element storing the binary value 1.

  1. Apply the required input to set the memory element.
  2. Activate the required clock or enable condition.
  3. The memory element stores the value 1.
  4. Change the external input while keeping the storage element in its hold condition.
  5. The stored output remains 1 until another valid state-changing operation occurs.
This illustrates why sequential circuits are necessary: they retain information rather than calculating their outputs from present inputs alone.

15. Lesson Summary

  • Sequential circuits depend on present inputs and previously stored state.
  • Memory elements are essential components of sequential circuits.
  • Latches and flip-flops store binary information.
  • Synchronous circuits use clock signals for coordinated state changes.
  • Asynchronous circuits respond to input changes without requiring a global clock.
  • Present state and next state describe sequential circuit behavior.
  • Counters, registers and controllers are common applications.
