2. What Is a Code Converter?

A code converter is a combinational logic circuit that converts data represented in one digital code into another digital code.

Different digital systems use different coding schemes depending on their requirements.

A binary-to-Gray converter changes an ordinary binary number into Gray code, while a Gray-to-binary converter performs the reverse operation.

3. What Is Gray Code?

Gray code is a non-weighted binary coding system in which two consecutive code values differ by only one bit.

It is also known as a unit-distance code.

4. Characteristics of Gray Code

  • Only one bit changes between consecutive code values.
  • It is a non-weighted code.
  • It reduces ambiguity during certain digital transitions.
  • It is useful in rotary and position encoders.
  • It can be converted to and from binary using XOR operations.
  • It is not a direct replacement for ordinary binary arithmetic.

5. Binary to Gray Code Conversion

Binary-to-Gray conversion is performed using XOR operations between adjacent binary bits.

For a 4-bit binary input:

Binary = B3 B2 B1 B0

The Gray-code outputs are:

G3 = B3
G2 = B3 ⊕ B2
G1 = B2 ⊕ B1
G0 = B1 ⊕ B0
The most significant Gray bit is the same as the most significant binary bit. Every remaining Gray bit is obtained by XORing two adjacent binary bits.

6. Binary to Gray Conversion – Worked Example

Convert binary 1011 into Gray code.

Given:

Binary = 1011

Step 1: Copy the MSB.

G3 = B3 = 1

Step 2: XOR adjacent binary bits.

G2 = B3 ⊕ B2 = 1 ⊕ 0 = 1

G1 = B2 ⊕ B1 = 0 ⊕ 1 = 1

G0 = B1 ⊕ B0 = 1 ⊕ 1 = 0

Gray Code = 1110

8. Binary to Gray Converter – Logic Implementation

A 4-bit binary-to-Gray converter requires three XOR gates and one direct connection.

  • Connect B3 directly to G3.
  • Connect B3 and B2 to the first XOR gate to obtain G2.
  • Connect B2 and B1 to the second XOR gate to obtain G1.
  • Connect B1 and B0 to the third XOR gate to obtain G0.
The XOR gate performs the modulo-2 addition operation. Its output is 1 when its two inputs are different.

9. Gray to Binary Code Conversion

Gray-to-binary conversion is performed using successive XOR operations.

For a 4-bit Gray-code input:

Gray = G3 G2 G1 G0

The binary outputs are:

B3 = G3
B2 = B3 ⊕ G2
B1 = B2 ⊕ G1
B0 = B1 ⊕ G0
First copy the Gray-code MSB. Then calculate every following binary bit by XORing the previous binary bit with the current Gray bit.

10. Gray to Binary Conversion – Worked Example

Convert Gray code 1110 into binary.

Given:

Gray = 1110

Step 1: Copy the MSB.

B3 = G3 = 1

Step 2: Calculate the remaining bits.

B2 = B3 ⊕ G2 = 1 ⊕ 1 = 0

B1 = B2 ⊕ G1 = 0 ⊕ 1 = 1

B0 = B1 ⊕ G0 = 1 ⊕ 0 = 1

Binary = 1011

Therefore, Gray code 1110 represents binary 1011.

12. Gray to Binary Converter – Logic Implementation

A 4-bit Gray-to-binary converter can be implemented using three cascaded XOR gates and one direct connection.

  • Connect G3 directly to B3.
  • Connect B3 and G2 to the first XOR gate to obtain B2.
  • Connect B2 and G1 to the second XOR gate to obtain B1.
  • Connect B1 and G0 to the third XOR gate to obtain B0.
Unlike binary-to-Gray conversion, Gray-to-binary conversion uses the previously calculated binary output for each successive XOR operation.

13. Binary-to-Gray vs Gray-to-Binary Converter

Parameter Binary to Gray Gray to Binary
Input Binary code Gray code
Output Gray code Binary code
MSB Directly copied Directly copied
Logic XOR of adjacent binary bits Successive XOR operations
Implementation Parallel XOR operations Cascaded XOR operations

14. Advantages of Gray Code

  • Only one bit changes between consecutive code values.
  • Reduces transition ambiguity in position-encoding systems.
  • Useful in rotary encoders.
  • Helps reduce errors caused by simultaneous bit transitions.
  • Can be converted to and from binary using simple logic.

15. Applications of Gray Code

  • Rotary position encoders.
  • Digital angle measurement systems.
  • Analog-to-digital conversion systems where Gray coding is used for state transitions.
  • Asynchronous clock-domain crossing pointers, especially in FIFO designs.
  • Digital communication and error-reduction applications.
  • Karnaugh map cell ordering.

16. Practical Experiment – Binary to Gray and Gray to Binary

Components Required

  • XOR gate IC, such as 7486 or 74LS86.
  • Input switches.
  • LED indicators with suitable current-limiting resistors.
  • Regulated power supply.
  • Breadboard and connecting wires.

Procedure

  1. Construct a 4-bit binary-to-Gray converter using XOR gates.
  2. Connect the binary input switches.
  3. Observe the Gray-code outputs.
  4. Construct a Gray-to-binary converter using cascaded XOR gates.
  5. Apply Gray-code input combinations.
  6. Observe the corresponding binary outputs.
  7. Verify both converters using the conversion equations.

19. Lesson Summary

  • A code converter changes data from one digital code to another.
  • Gray code is a non-weighted, unit-distance code.
  • Only one bit changes between consecutive Gray-code values.
  • Binary-to-Gray conversion uses XOR operations between adjacent binary bits.
  • Gray-to-binary conversion uses successive XOR operations.
  • The MSB is copied directly in both conversions.
  • XOR gates are commonly used to implement these converters.
  • Gray code is used in rotary encoders, FIFO pointers and digital systems.
