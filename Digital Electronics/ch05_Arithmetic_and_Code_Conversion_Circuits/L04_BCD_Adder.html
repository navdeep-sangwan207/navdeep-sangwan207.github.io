2. What Is BCD?

Binary Coded Decimal (BCD) is a coding system in which each decimal digit is represented separately using a 4-bit binary code.

In standard 8421 BCD, decimal digits 0 to 9 are represented using the binary values 0000 to 1001.

BCD represents each decimal digit separately. For example, decimal 25 is represented as 0010 0101 in BCD, not as the ordinary binary representation 11001.

3. What Is a BCD Adder?

A BCD adder is a combinational logic circuit that adds two BCD digits and produces a valid BCD result.

It generally consists of a 4-bit binary adder followed by correction logic.

Why Is Correction Required?

A 4-bit binary adder can produce results from 0000 to 1111. However, valid 8421 BCD digits range only from 0000 to 1001.

Therefore, whenever the binary sum is greater than 1001, the result must be corrected.

The correction is performed by adding 0110 (decimal 6) to the four-bit binary sum. Any carry generated becomes the carry to the next BCD digit.

4. Invalid BCD Combinations

In 8421 BCD, the combinations from 1010 to 1111 are invalid because they represent decimal values 10 to 15 in ordinary binary.

5. BCD Correction Logic

Let the initial 4-bit binary sum be represented by D C B A, where D is the most significant bit. Let the carry output of the first binary adder be C4.

Correction is required if:

  • The initial binary adder produces a carry C4 = 1.
  • The 4-bit sum is greater than 1001.

The correction condition is:

K = C4 + D·C + D·B

Here, K = 1 means that 0110 must be added to the lower four sum bits.

The expression K = C4 + D(C + B) detects binary sums from 1010 through 1111 and also detects a carry from the first 4-bit adder.

Correction Operation

Corrected Sum = Initial Sum + 0110

When K = 0, no correction is needed. When K = 1, the correction value 0110 is added.

7. Working of a BCD Adder

  1. Apply two 4-bit BCD digits to the first binary adder.
  2. Add the two digits along with the incoming carry.
  3. Check the initial sum and carry output.
  4. Determine whether the result is greater than 9 or a carry was generated.
  5. If correction is required, add 0110.
  6. Take the corrected four-bit result as the valid BCD digit.
  7. Pass the decimal carry to the next digit position.

8. Worked Example 1 – Addition Without Correction

Perform BCD addition:

0011 + 0100

Decimal values:

3 + 4 = 7

Initial binary addition:

   0011
 + 0100
 -------
   0111

The result 0111 is a valid BCD digit because it is less than or equal to 1001.

No correction is required.

Final BCD Result = 0111

9. Worked Example 2 – Addition With Correction

Perform BCD addition:

0101 + 0111

Decimal values:

5 + 7 = 12

Step 1: Initial Binary Addition

   0101
 + 0111
 -------
   1100

The result 1100 is greater than 1001, so BCD correction is required.

Step 2: Add Correction Value 0110

   1100
 + 0110
 -------
 1 0010

The lower four bits are 0010, and the carry to the next decimal digit is 1.

Final BCD Result = 0001 0010
0001 represents decimal 1 and 0010 represents decimal 2. Therefore, the final BCD result represents decimal 12.

12. Advantages of BCD Adder

  • Directly performs arithmetic on decimal digits.
  • Produces valid 8421 BCD output.
  • Useful in decimal display systems.
  • Simplifies decimal digit handling in some applications.
  • Supports multi-digit decimal addition using carry between digit positions.

13. Limitations of BCD Adder

  • Requires additional correction logic.
  • Uses more hardware than a basic binary adder for equivalent digit operations.
  • BCD arithmetic can require more processing than pure binary arithmetic.
  • Only ten of the sixteen possible 4-bit combinations are valid in 8421 BCD.

14. Applications of BCD Adders

  • Digital clocks and timers.
  • Electronic calculators.
  • Digital measuring instruments.
  • Decimal counters and display systems.
  • Financial and accounting systems that require decimal arithmetic.
  • Digital systems using BCD-based data representation.

15. Practical Experiment – BCD Addition

Components Required

  • Two 4-bit binary adder circuits.
  • AND, OR and XOR gates for correction detection.
  • Input switches for BCD digits.
  • Logic indicators or LEDs.
  • Regulated power supply.
  • Breadboard and connecting wires.

Procedure

  1. Construct a 4-bit binary adder.
  2. Connect two BCD digit inputs to the adder.
  3. Implement correction detection using K = C4 + D·C + D·B.
  4. Connect the correction logic to the second adder.
  5. Apply 0110 when the correction signal K is HIGH.
  6. Observe the corrected BCD output and decimal carry.
  7. Verify the result using decimal addition.

18. Lesson Summary

  • BCD represents each decimal digit using four bits.
  • Valid 8421 BCD codes range from 0000 to 1001.
  • A BCD adder performs decimal digit addition.
  • A 4-bit binary adder first produces the initial sum.
  • Correction is required when the sum exceeds 9 or a carry is generated.
  • The correction value is 0110.
  • The correction condition is K = C4 + D·C + D·B.
  • The corrected output is a valid BCD digit with a decimal carry when required.
