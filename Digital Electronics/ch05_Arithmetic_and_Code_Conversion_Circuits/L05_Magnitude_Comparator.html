2. What Is a Magnitude Comparator?

A magnitude comparator is a combinational logic circuit that compares two binary numbers and determines their relative magnitudes.

It compares two binary inputs, A and B, and generates three possible outputs.

A digital magnitude comparator determines whether A is greater than B, A is less than B, or A is equal to B.

Three Comparison Outputs

  • A > B: HIGH when A is greater than B.
  • A < B: HIGH when A is less than B.
  • A = B: HIGH when both numbers are equal.

For valid binary inputs, exactly one of these three outputs is HIGH.

3. Basic Operation of a Magnitude Comparator

Consider two binary numbers A and B. The comparator checks their values and activates the corresponding output.

Example 1:

A = 1010 and B = 0110

Decimal values: 10 and 6

Therefore, A > B.

Example 2:

A = 0101 and B = 1001

Decimal values: 5 and 9

Therefore, A < B.

Example 3:

A = 1100 and B = 1100

Both numbers are equal.

Therefore, A = B.

4. 1-Bit Magnitude Comparator

A 1-bit comparator compares two single-bit inputs A and B.

Truth Table

A B A > B A = B A < B
00010
01001
10100
11010

Boolean Expressions

For the greater-than output:

G = A · B'

For the less-than output:

L = A' · B

For the equality output:

E = A'B' + AB
The equality expression is the XNOR operation: E = A XNOR B.

5. Logic Gate Implementation of a 1-Bit Comparator

A 1-bit comparator can be implemented using NOT, AND and XNOR gates.

  • Use an inverter to generate A' and B'.
  • Use an AND gate for G = A · B'.
  • Use an AND gate for L = A' · B.
  • Use an XNOR gate for E = A XNOR B.
The three outputs are mutually exclusive. Only one output is active for any valid pair of binary input bits.

6. 2-Bit Magnitude Comparator

A 2-bit comparator compares two 2-bit numbers:

A = A1A0
B = B1B0

The most significant bits are compared first. If they are equal, the least significant bits determine the final result.

Equality Condition

E = (A1 XNOR B1)(A0 XNOR B0)

Greater-Than Condition

G = A1B1' + (A1 XNOR B1)A0B0'

Less-Than Condition

L = A1'B1 + (A1 XNOR B1)A0'B0
The lower bit is considered only when the corresponding higher bits are equal.

7. 4-Bit Magnitude Comparator

A 4-bit magnitude comparator compares two 4-bit binary numbers:

A = A3 A2 A1 A0
B = B3 B2 B1 B0

Comparison begins at the most significant bit. If the bits are equal, the circuit moves to the next lower bit.

Comparison Priority

  1. Compare A3 and B3.
  2. If equal, compare A2 and B2.
  3. If equal, compare A1 and B1.
  4. If equal, compare A0 and B0.
  5. If all corresponding bits are equal, A = B.

Equality Equation

E = (A3 XNOR B3)(A2 XNOR B2)(A1 XNOR B1)(A0 XNOR B0)

Greater-Than Equation

G = A3B3' + X3A2B2' + X3X2A1B1' + X3X2X1A0B0'

Less-Than Equation

L = A3'B3 + X3A2'B2 + X3X2A1'B1 + X3X2X1A0'B0

Where:

Xi = Ai XNOR Bi

Each Xi indicates equality at its respective bit position.

9. Cascading of Magnitude Comparators

Cascading means connecting smaller comparator circuits to compare binary numbers with a larger number of bits.

For example, two 4-bit comparators can be cascaded to compare two 8-bit numbers.

General Cascading Principle

  • The higher-order comparator examines the more significant bits.
  • The lower-order comparator examines the less significant bits.
  • The higher-order comparison determines the result if its inputs differ.
  • The lower-order result is used only when the higher-order sections are equal.
Comparator ICs such as the 74LS85 provide cascading inputs and outputs to support comparison of wider binary numbers.

10. 7485 / 74LS85 Magnitude Comparator IC

The 7485 and 74LS85 are 4-bit magnitude comparator ICs from the 74-series logic family.

Features

  • Compares two 4-bit binary numbers.
  • Provides A greater than B output.
  • Provides A less than B output.
  • Provides A equal to B output.
  • Supports cascading for wider comparisons.
For standalone use, the cascading inputs must be set to the appropriate initial comparison state: I(A>B) = 0, I(A<B) = 0 and I(A=B) = 1. Verify the exact pin numbers and electrical ratings using the datasheet for the selected manufacturer and IC variant.

11. Advantages of Magnitude Comparators

  • Performs binary comparison automatically.
  • Provides three clear comparison outputs.
  • Can compare multi-bit binary numbers.
  • Supports cascading for wider data widths.
  • Useful in digital control and decision-making circuits.

12. Limitations of Magnitude Comparators

  • Requires additional logic for larger bit widths.
  • Propagation delay increases with comparator size and implementation.
  • Signed number comparison requires appropriate signed-comparison logic.
  • Large comparison circuits can consume more hardware resources.

13. Applications of Magnitude Comparators

  • Digital control systems.
  • Microprocessor and CPU decision-making circuits.
  • Address comparison circuits.
  • Digital sorting and selection systems.
  • Memory address and data comparison.
  • Digital measurement instruments.
  • Alarm and threshold detection circuits.

14. Practical Experiment – 4-Bit Magnitude Comparator

Components Required

  • 74LS85 magnitude comparator IC or equivalent.
  • Logic input switches.
  • LED indicators with suitable current-limiting resistors.
  • Regulated supply appropriate for the selected IC.
  • Breadboard and connecting wires.

Procedure

  1. Place the 4-bit comparator IC on the breadboard.
  2. Connect the supply and ground according to its datasheet.
  3. Connect the cascading inputs for standalone operation.
  4. Apply two 4-bit binary numbers to the A and B inputs.
  5. Observe the greater-than, less-than and equality outputs.
  6. Change the input combinations and record the results.
  7. Verify each result using manual binary comparison.
