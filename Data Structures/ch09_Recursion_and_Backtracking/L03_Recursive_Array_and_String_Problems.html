Recursive Array and String Problems

Data Structures and Algorithms Using C

Placement-Oriented Learning | C11

1. Introduction

Recursion can be applied to arrays and strings by processing one element or character at a time and recursively moving to the next position.

Instead of using a loop, a recursive function uses its parameters to track the current position.

Placement Focus: Array traversal, recursive searching, maximum and minimum, array reversal, string reversal, palindrome checking and recursive string comparison are common practice problems for entry-level technical interviews.

2. Recursive Array Traversal

Array traversal means visiting every element of an array. A recursive function can process the current element and then move to the next index.

Complete C11 Program

#include <stdio.h>

void displayArray(const int arr[], int n, int index)
{
    if (index == n)
        return;

    printf("%d ", arr[index]);

    displayArray(arr, n, index + 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Array elements: ");
    displayArray(arr, n, 0);

    printf("\n");

    return 0;
}

Expected Output

Array elements: 10 20 30 40 50

Dry Run

Recursive Call Action
displayArray(arr, 5, 0) Prints 10
displayArray(arr, 5, 1) Prints 20
displayArray(arr, 5, 2) Prints 30
displayArray(arr, 5, 3) Prints 40
displayArray(arr, 5, 4) Prints 50
displayArray(arr, 5, 5) Base case reached

Complexity:

  • Time: O(n)
  • Auxiliary space: O(n)

3. Print Array in Reverse Order

To print an array in reverse order, start from the last index and recursively move toward index zero. 

#include <stdio.h>

void printReverse(const int arr[], int index)
{
    if (index < 0)
        return;

    printf("%d ", arr[index]);

    printReverse(arr, index - 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Reverse array: ");
    printReverse(arr, n - 1);

    printf("\n");

    return 0;
}

Expected Output

Reverse array: 50 40 30 20 10

Complexity: Time O(n), auxiliary space O(n).

4. Sum of Array Elements Using Recursion

The sum of an array can be calculated by adding the current element to the sum of the remaining elements.

Recursive relation:

sum(arr, n) = arr[n - 1] + sum(arr, n - 1)
Base case: sum(arr, 0) = 0

Complete C11 Program

#include <stdio.h>

long long arraySum(const int arr[], int n)
{
    if (n == 0)
        return 0;

    return arr[n - 1] + arraySum(arr, n - 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Array sum = %lld\n", arraySum(arr, n));

    return 0;
}

Expected Output

Array sum = 150

Complexity: Time O(n), auxiliary space O(n).

5. Find Maximum Element in an Array

The recursive function finds the maximum of the first n-1 elements and compares it with the last element. 

#include <stdio.h>

int maximum(const int arr[], int n)
{
    if (n == 1)
        return arr[0];

    int previousMax = maximum(arr, n - 1);

    return (arr[n - 1] > previousMax)
           ? arr[n - 1]
           : previousMax;
}

int main(void)
{
    int arr[] = {12, 45, 7, 89, 23};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    if (n > 0)
        printf("Maximum = %d\n", maximum(arr, n));

    return 0;
}

Expected Output

Maximum = 89

Complexity: Time O(n), auxiliary space O(n).

This function requires n to be greater than zero. An empty array does not have a maximum element.

6. Recursive Linear Search

Recursive linear search checks the current element. If it does not match the target, it searches the remaining array.

Complete C11 Program

#include <stdio.h>

int recursiveSearch(const int arr[], int n, int key, int index)
{
    if (index == n)
        return -1;

    if (arr[index] == key)
        return index;

    return recursiveSearch(arr, n, key, index + 1);
}

int main(void)
{
    int arr[] = {10, 25, 30, 45, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int key = 45;

    int result = recursiveSearch(arr, n, key, 0);

    if (result != -1)
        printf("Element found at index %d\n", result);
    else
        printf("Element not found\n");

    return 0;
}

Expected Output

Element found at index 3

Complexity:

  • Best-case time: O(1)
  • Worst-case time: O(n)
  • Worst-case auxiliary space: O(n)

7. Reverse an Array In-Place Using Recursion

Two pointers can be used to reverse an array. One starts at the beginning and the other at the end. Swap their values and move both pointers toward the center. 

#include <stdio.h>

void reverseArray(int arr[], int left, int right)
{
    if (left >= right)
        return;

    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;

    reverseArray(arr, left + 1, right - 1);
}

void display(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5, 6};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Original array: ");
    display(arr, n);

    reverseArray(arr, 0, n - 1);

    printf("Reversed array: ");
    display(arr, n);

    return 0;
}

Expected Output

Original array: 1 2 3 4 5 6
Reversed array: 6 5 4 3 2 1

Complexity:

  • Time: O(n)
  • Auxiliary space: O(n), due to recursive calls.
  • Extra array storage: O(1).

8. Recursive String Traversal

A C string is a character array terminated by the null character '\0'. Recursive traversal continues until this terminator is reached. 

#include <stdio.h>

void printString(const char str[], int index)
{
    if (str[index] == '\0')
        return;

    putchar(str[index]);

    printString(str, index + 1);
}

int main(void)
{
    char str[] = "RECURSION";

    printf("String: ");
    printString(str, 0);

    printf("\n");

    return 0;
}

Expected Output

String: RECURSION

Complexity: Time O(n), auxiliary space O(n).

9. Find String Length Using Recursion

The length of a string is the number of characters before the null terminator. 

#include <stdio.h>

size_t stringLength(const char str[])
{
    if (str[0] == '\0')
        return 0;

    return 1 + stringLength(str + 1);
}

int main(void)
{
    char str[] = "PROGRAMMING";

    printf("Length = %zu\n", stringLength(str));

    return 0;
}

Expected Output

Length = 11

Complexity: Time O(n), auxiliary space O(n).

10. Reverse a String Using Recursion

One method is to print characters after the recursive call. The deepest call prints the last character first. 

#include <stdio.h>

void printReverse(const char str[], int index)
{
    if (str[index] == '\0')
        return;

    printReverse(str, index + 1);

    putchar(str[index]);
}

int main(void)
{
    char str[] = "HELLO";

    printf("Original string: %s\n", str);

    printf("Reverse string: ");
    printReverse(str, 0);

    printf("\n");

    return 0;
}

Expected Output

Original string: HELLO
Reverse string: OLLEH

Complexity: Time O(n), auxiliary space O(n).

This program prints the reverse without modifying the original string.

11. Check Whether a String is a Palindrome

A palindrome reads the same forward and backward. Recursive comparison checks the characters at both ends and moves inward.

Complete C11 Program

#include <stdio.h>
#include <string.h>

int isPalindrome(const char str[], size_t left, size_t right)
{
    if (left >= right)
        return 1;

    if (str[left] != str[right])
        return 0;

    return isPalindrome(str, left + 1, right - 1);
}

int main(void)
{
    char str[] = "MADAM";
    size_t length = strlen(str);

    if (isPalindrome(str, 0, length - 1))
        printf("%s is a palindrome.\n", str);
    else
        printf("%s is not a palindrome.\n", str);

    return 0;
}

Expected Output

MADAM is a palindrome.

Complexity:

  • Time: O(n)
  • Auxiliary space: O(n)
This implementation is case-sensitive and compares every character, including spaces and punctuation. It assumes the string is non-empty and null-terminated.

12. Compare Two Strings Recursively

Two strings can be compared character by character until a mismatch or the end of both strings is found. 

#include <stdio.h>

int compareStrings(const char a[], const char b[])
{
    if (a[0] != b[0])
        return (unsigned char)a[0] - (unsigned char)b[0];

    if (a[0] == '\0')
        return 0;

    return compareStrings(a + 1, b + 1);
}

int main(void)
{
    char a[] = "HELLO";
    char b[] = "HELLO";

    int result = compareStrings(a, b);

    if (result == 0)
        printf("Strings are equal.\n");
    else
        printf("Strings are different.\n");

    return 0;
}

Expected Output

Strings are equal.

Complexity: Time O(n), auxiliary space O(n).

13. Count Occurrences of a Character Recursively

This function counts how many times a specified character appears in a string. 

#include <stdio.h>

int countCharacter(const char str[], char target)
{
    if (str[0] == '\0')
        return 0;

    return (str[0] == target) +
           countCharacter(str + 1, target);
}

int main(void)
{
    char str[] = "PROGRAMMING";
    char target = 'M';

    printf("Occurrences of %c = %d\n",
           target, countCharacter(str, target));

    return 0;
}

Expected Output

Occurrences of M = 2

Complexity: Time O(n), auxiliary space O(n).

14. Sum of Digits Using Recursion

The last digit can be extracted using the modulo operator, and the remaining number can be obtained using integer division. 

#include <stdio.h>

unsigned int sumDigits(unsigned int n)
{
    if (n == 0)
        return 0;

    return (n % 10) + sumDigits(n / 10);
}

int main(void)
{
    unsigned int n = 12345;

    printf("Sum of digits = %u\n", sumDigits(n));

    return 0;
}

Expected Output

Sum of digits = 15

Complexity:

  • Time: O(d), where d is the number of decimal digits.
  • Auxiliary space: O(d).

16. Placement Interview Questions and Answers

Q1. How can an array be traversed using recursion?

Process the element at the current index and recursively call the function with the next index until the index reaches the array length.

Q2. What is the base case for recursive array traversal?

The base case is generally index == n, where n is the number of array elements.

Q3. How can an array be reversed recursively?

Swap the first and last elements, then recursively process the smaller range between them.

Q4. What is the complexity of recursive linear search?

Worst-case time is O(n), and worst-case auxiliary stack space is O(n).

Q5. How do you check a palindrome recursively?

Compare the first and last characters. If they match, recursively compare the remaining inner substring.

Q6. Why does recursive string reversal print after the recursive call?

The deepest call reaches the null terminator first. As calls return, characters are printed in reverse order.

Q7. What does the null terminator represent in C strings?

The character '\0' marks the end of a C string.

Q8. Does recursive array reversal require another array?

No. It can swap elements in the original array. Its recursive call stack still requires O(n) auxiliary space.

Q9. What is the difference between array reversal and reverse traversal?

Reverse traversal visits elements from the last index to the first without modifying the array. Reversal changes the order of elements in the array.

Q10. What is the main disadvantage of recursive array processing?

Deep recursion can consume significant stack memory and may cause stack exhaustion for large inputs.

A. O(1)

19. Lesson Summary

  • Recursion can process arrays one element at a time.
  • Array traversal uses an index as the recursive state.
  • Array reversal can use two recursive indices.
  • Recursive linear search checks one element per call.
  • C strings terminate at the null character.
  • String reversal can print characters during stack unwinding.
  • Palindrome checking compares characters from both ends.
  • Recursive implementations generally use call-stack space proportional to their depth.
