2. String Recursion Fundamentals

A C string is a character array terminated by the null character '\0'.

Example

char str[] = "HELLO";

Memory Representation

Index:     0    1    2    3    4    5
         +----+----+----+----+----+------+
Value:   | H  | E  | L  | L  | O  | '\0' |
         +----+----+----+----+----+------+

A recursive string function generally uses an index to process one character at a time.

3. Recursive String Traversal

Program 1: Print a String Character by Character

The function processes one character and then calls itself for the next character.

Complete C11 Program

#include <stdio.h>

void printString(const char str[], int index)
{
    if (str[index] == '\0')
        return;

    printf("%c ", str[index]);

    printString(str, index + 1);
}

int main(void)
{
    char str[] = "HELLO";

    printString(str, 0);

    printf("\n");

    return 0;
}

Expected Output

H E L L O

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

4. Reverse a String Using Recursion

Program 2: Print a String in Reverse Order

The recursive call reaches the end of the string first. Characters are printed during the returning phase.

Complete C11 Program

#include <stdio.h>

void reverseString(const char str[], int index)
{
    if (str[index] == '\0')
        return;

    reverseString(str, index + 1);

    printf("%c", str[index]);
}

int main(void)
{
    char str[] = "HELLO";

    printf("Original string: %s\n", str);

    printf("Reversed string: ");

    reverseString(str, 0);

    printf("\n");

    return 0;
}

Expected Output

Original string: HELLO
Reversed string: OLLEH

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)
Interview concept: The string is not modified. The characters are printed in reverse order using the recursion return phase.

5. Check Whether a String Is a Palindrome

A palindrome string reads the same forward and backward.

Examples:

MADAM
LEVEL
RADAR

Program 3: Recursive Palindrome Checking

Complete C11 Program

#include <stdio.h>
#include <stdbool.h>
#include <string.h>

bool isPalindrome(
    const char str[],
    int left,
    int right)
{
    if (left >= right)
        return true;

    if (str[left] != str[right])
        return false;

    return isPalindrome(
        str,
        left + 1,
        right - 1
    );
}

int main(void)
{
    char str[] = "MADAM";

    int length = (int)strlen(str);

    if (isPalindrome(str, 0, length - 1))
        printf("%s is a palindrome\n", str);
    else
        printf("%s is not a palindrome\n", str);

    return 0;
}

Expected Output

MADAM is a palindrome

Dry Run

isPalindrome("MADAM", 0, 4)

M == M

isPalindrome("MADAM", 1, 3)

A == A

isPalindrome("MADAM", 2, 2)

Base case reached.

Return TRUE.

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)
This implementation is case-sensitive and compares every character, including spaces and punctuation.

6. Count Vowels Recursively

Program 4: Count Vowels in a String

Complete C11 Program

#include <stdio.h>

int countVowels(const char str[], int index)
{
    if (str[index] == '\0')
        return 0;

    char ch = str[index];

    int current =
        (ch == 'a' || ch == 'e' ||
         ch == 'i' || ch == 'o' ||
         ch == 'u' || ch == 'A' ||
         ch == 'E' || ch == 'I' ||
         ch == 'O' || ch == 'U');

    return current +
           countVowels(str, index + 1);
}

int main(void)
{
    char str[] = "Embedded Systems";

    printf("Number of vowels = %d\n",
           countVowels(str, 0));

    return 0;
}

Expected Output

Number of vowels = 6

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

7. Count Consonants Recursively

Program 5: Count Alphabetic Consonants

Complete C11 Program

#include <stdio.h>
#include <ctype.h>

int countConsonants(const char str[], int index)
{
    if (str[index] == '\0')
        return 0;

    unsigned char ch = (unsigned char)str[index];

    int current = 0;

    if (isalpha(ch) &&
        ch != 'a' && ch != 'e' &&
        ch != 'i' && ch != 'o' &&
        ch != 'u' && ch != 'A' &&
        ch != 'E' && ch != 'I' &&
        ch != 'O' && ch != 'U')
    {
        current = 1;
    }

    return current +
           countConsonants(str, index + 1);
}

int main(void)
{
    char str[] = "Embedded Systems";

    printf("Number of consonants = %d\n",
           countConsonants(str, 0));

    return 0;
}

Expected Output

Number of consonants = 9

Spaces, digits and punctuation are not counted.

8. Remove a Particular Character Recursively

Program 6: Remove All Occurrences of a Character

Complete C11 Program

#include <stdio.h>

void removeCharacter(
    const char str[],
    char result[],
    int index,
    int outputIndex,
    char target)
{
    if (str[index] == '\0')
    {
        result[outputIndex] = '\0';
        return;
    }

    if (str[index] != target)
    {
        result[outputIndex] = str[index];
        outputIndex++;
    }

    removeCharacter(
        str,
        result,
        index + 1,
        outputIndex,
        target
    );
}

int main(void)
{
    char str[] = "programming";

    char result[sizeof(str)];

    removeCharacter(
        str,
        result,
        0,
        0,
        'm'
    );

    printf("Original string: %s\n", str);

    printf("Updated string: %s\n", result);

    return 0;
}

Expected Output

Original string: programming
Updated string: prograing

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Recursion Space: O(n)
  • Output Buffer Space: O(n)

9. Count Occurrences of a Character Recursively

Program 7: Character Frequency

Complete C11 Program

#include <stdio.h>

int countCharacter(
    const char str[],
    int index,
    char target)
{
    if (str[index] == '\0')
        return 0;

    int current = (str[index] == target);

    return current +
           countCharacter(
               str,
               index + 1,
               target
           );
}

int main(void)
{
    char str[] = "programming";

    char target = 'g';

    printf("Frequency of '%c' = %d\n",
           target,
           countCharacter(str, 0, target));

    return 0;
}

Expected Output

Frequency of 'g' = 2

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

10. Check Whether Two Strings Are Equal Recursively

Program 8: Recursive String Comparison

Complete C11 Program

#include <stdio.h>
#include <stdbool.h>

bool compareStrings(
    const char str1[],
    const char str2[],
    int index)
{
    if (str1[index] != str2[index])
        return false;

    if (str1[index] == '\0')
        return true;

    return compareStrings(
        str1,
        str2,
        index + 1
    );
}

int main(void)
{
    char str1[] = "DATA";

    char str2[] = "DATA";

    if (compareStrings(str1, str2, 0))
        printf("Strings are equal\n");
    else
        printf("Strings are not equal\n");

    return 0;
}

Expected Output

Strings are equal

Complexity Analysis

  • Best-case Time: O(1)
  • Worst-case Time: O(n)
  • Auxiliary Space: O(n)

11. Introduction to Subsequences

A subsequence is a sequence obtained by deleting zero or more characters from the original string without changing the relative order of the remaining characters.

Example

Original string = ABC

Possible Subsequences

""
"A"
"B"
"C"
"AB"
"AC"
"BC"
"ABC"

AC is valid because A occurs before C in the original string. CA is not valid because the character order has changed.

Difference Between Subsequence and Substring

Subsequence Substring
Characters need not be contiguous. Characters must be contiguous.
Relative order is preserved. Relative order is preserved.
AC from ABC is valid. AC from ABC is not a substring.
Number of subsequences is 2^n. Number of non-empty substrings is n(n+1)/2.

12. How to Generate Subsequences Using Recursion

For every character, there are two choices:

  1. Include the current character.
  2. Exclude the current character.

This is called the include/exclude technique.

Example: String ABC

                         ""
                       /    \
                      A      ""
                    /  \    /  \
                   AB   A  B    ""
                  / \  / \ / \  / \
                ABC AB AC A BC B C  ""

The resulting eight subsequences are:

ABC
AB
AC
A
BC
B
C
""
Important: Each character produces two choices. Therefore, a string of length n has 2^n subsequences, including the empty subsequence.

13. Generate All Subsequences of a String

Program 9: Recursive Subsequence Generation

Complete C11 Program

#include <stdio.h>

void generateSubsequences(
    const char str[],
    int index,
    char output[],
    int outputIndex)
{
    if (str[index] == '\0')
    {
        output[outputIndex] = '\0';

        printf("\"%s\"\n", output);

        return;
    }

    /* Choice 1: Include current character */

    output[outputIndex] = str[index];

    generateSubsequences(
        str,
        index + 1,
        output,
        outputIndex + 1
    );

    /* Choice 2: Exclude current character */

    generateSubsequences(
        str,
        index + 1,
        output,
        outputIndex
    );
}

int main(void)
{
    char str[] = "ABC";

    char output[sizeof(str)];

    printf("All subsequences:\n");

    generateSubsequences(
        str,
        0,
        output,
        0
    );

    return 0;
}

Expected Output

All subsequences:
"ABC"
"AB"
"AC"
"A"
"BC"
"B"
"C"
""

Complexity Analysis

  • Number of subsequences: O(2^n).
  • Number of recursive calls: O(2^n).
  • Time including printing characters: O(n * 2^n).
  • Auxiliary recursion and output-buffer space: O(n).

14. Count the Number of Subsequences

Every character has two choices: include or exclude.

Mathematical formula:

S(n) = 2 * S(n - 1)

S(0) = 1

Therefore:

S(n) = 2^n

Program 10: Count Subsequences Recursively

Complete C11 Program

#include <stdio.h>

unsigned long long countSubsequences(unsigned int n)
{
    if (n == 0)
        return 1;

    return 2 * countSubsequences(n - 1);
}

int main(void)
{
    unsigned int n = 3;

    printf("Number of subsequences = %llu\n",
           countSubsequences(n));

    return 0;
}

Expected Output

Number of subsequences = 8

For a string of length 3: 

2^3 = 8

The empty subsequence is included in this count.

Complexity Analysis

  • Time Complexity: O(2^n) for this recursive implementation.
  • Auxiliary Space: O(n).
The return type unsigned long long has a finite range. Large subsequence counts can overflow it.

15. Generate Subsequences with a Specific Sum

This problem introduces the include/exclude technique used in subset-sum problems.

For an integer array, determine whether some selection of elements has a specified sum.

Program 11: Check Whether a Subsequence with Target Sum Exists

Complete C11 Program

#include <stdio.h>
#include <stdbool.h>

bool subsetSum(
    const int arr[],
    int n,
    int index,
    int target)
{
    if (target == 0)
        return true;

    if (index == n)
        return false;

    /* Choice 1: Include current element */

    if (subsetSum(
            arr,
            n,
            index + 1,
            target - arr[index]))
    {
        return true;
    }

    /* Choice 2: Exclude current element */

    return subsetSum(
        arr,
        n,
        index + 1,
        target
    );
}

int main(void)
{
    int arr[] = {2, 4, 6, 8};

    int n = sizeof(arr) / sizeof(arr[0]);

    int target = 10;

    if (subsetSum(arr, n, 0, target))
        printf("Target sum is possible\n");
    else
        printf("Target sum is not possible\n");

    return 0;
}

Expected Output

Target sum is possible

One valid selection is:

2 + 8 = 10

Complexity Analysis

  • Worst-case Time: O(2^n).
  • Auxiliary Space: O(n).
This implementation assumes non-negative array elements and a non-negative target. For arbitrary signed integers, the early target-zero termination needs reconsideration.

16. Important Subsequence Interview Concepts

Concept Explanation
Subsequence Maintains relative order; characters need not be adjacent.
Include/exclude Two choices for every element.
Recursion tree Represents all possible choices.
Number of subsequences 2^n, including the empty subsequence.
Empty subsequence A subsequence containing no elements.
Subset sum Determines whether a selection reaches a target sum.

17. Common Mistakes

  1. Forgetting the null terminator when constructing a result string.
  2. Incorrectly updating the output index.
  3. Confusing subsequences with substrings.
  4. Forgetting that the empty subsequence is included in 2^n.
  5. Assuming subsequence generation has polynomial time complexity.
  6. Modifying the original string unintentionally.
  7. Ignoring recursion depth and output-buffer capacity.
  8. Using incorrect include/exclude recursive branches.

19. Placement Interview Questions and Answers

Q1. What is a subsequence?

A subsequence is obtained by deleting zero or more elements while preserving the relative order of the remaining elements.

Q2. How many subsequences does a string of length n have?

2^n, including the empty subsequence.

Q3. What is the difference between a substring and a subsequence?

A substring contains contiguous characters; a subsequence does not require contiguous characters.

Q4. What is the include/exclude technique?

For every element, recursively explore two choices: include it or exclude it.

Q5. What is the complexity of generating all subsequences?

There are 2^n subsequences. If each generated subsequence is printed, the total character-processing cost is O(n * 2^n).

Q6. Is an empty string a subsequence of every string?

Yes. It is obtained by deleting all characters.

Q7. Can recursion generate all subsets of an array?

Yes. The include/exclude technique can generate all subsets.

Q8. What is the relationship between subsequences and subset sum?

Subset sum explores selections of array elements to determine whether their sum equals a target.

Q9. Why is subsequence generation exponential?

Each element creates two independent choices, producing 2^n possible combinations.

Q10. Which technique is commonly used to solve subsequence generation problems?

Recursive include/exclude branching, often implemented as backtracking.
