2. Recursive Problems on Numbers

A recursive number problem processes an integer by repeatedly reducing it or transforming it into a smaller problem.

Program 1: Print Numbers from 1 to N

We make the recursive call first and print the current number during the returning phase.

Complete C11 Program

#include <stdio.h>

void printAscending(int n)
{
    if (n == 0)
        return;

    printAscending(n - 1);

    printf("%d ", n);
}

int main(void)
{
    int n = 5;

    printAscending(n);

    printf("\n");

    return 0;
}

Expected Output

1 2 3 4 5

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

Program 2: Sum of Digits

Example:

1234 = 1 + 2 + 3 + 4 = 10

Recursive formula:

sum(n) = (n % 10) + sum(n / 10)

Base case:
sum(0) = 0

Complete C11 Program

#include <stdio.h>

int sumDigits(unsigned int n)
{
    if (n == 0)
        return 0;

    return (int)(n % 10) + sumDigits(n / 10);
}

int main(void)
{
    unsigned int n = 1234;

    printf("Sum of digits = %d\n", sumDigits(n));

    return 0;
}

Expected Output

Sum of digits = 10

Complexity Analysis

  • Time Complexity: O(d)
  • Auxiliary Space: O(d)

Here, d represents the number of digits.

Program 3: Count Digits in a Number

Count the number of digits using recursive division by 10.

Complete C11 Program

#include <stdio.h>

int countDigits(unsigned int n)
{
    if (n < 10)
        return 1;

    return 1 + countDigits(n / 10);
}

int main(void)
{
    unsigned int n = 98765;

    printf("Number of digits = %d\n", countDigits(n));

    return 0;
}

Expected Output

Number of digits = 5
Important: This implementation counts zero as one digit.

Program 4: Reverse an Integer

The recursive function extracts the last digit and adds it to the reversed number.

Complete C11 Program

#include <stdio.h>

unsigned long long reverseDigits(
    unsigned int n,
    unsigned long long reversed)
{
    if (n == 0)
        return reversed;

    return reverseDigits(
        n / 10,
        reversed * 10 + n % 10
    );
}

int main(void)
{
    unsigned int n = 1234;

    unsigned long long result = reverseDigits(n, 0);

    printf("Original number = %u\n", n);
    printf("Reversed number = %llu\n", result);

    return 0;
}

Expected Output

Original number = 1234
Reversed number = 4321

Complexity Analysis

  • Time Complexity: O(d)
  • Auxiliary Space: O(d)
The accumulator can overflow for sufficiently large inputs. Production code should check overflow before multiplying by 10 and adding the next digit.

Program 5: Check Numeric Palindrome

A palindrome number reads the same from left to right and right to left.

Examples:

121
1331
12321

Complete C11 Program

#include <stdio.h>
#include <stdbool.h>

unsigned long long reverseDigits(
    unsigned int n,
    unsigned long long reversed)
{
    if (n == 0)
        return reversed;

    return reverseDigits(
        n / 10,
        reversed * 10 + n % 10
    );
}

bool isPalindrome(unsigned int n)
{
    return n == reverseDigits(n, 0);
}

int main(void)
{
    unsigned int n = 121;

    if (isPalindrome(n))
        printf("%u is a palindrome\n", n);
    else
        printf("%u is not a palindrome\n", n);

    return 0;
}

Expected Output

121 is a palindrome

Complexity Analysis

  • Time Complexity: O(d)
  • Auxiliary Space: O(d)

Program 6: Calculate Power Recursively

Calculate:

2^5 = 32

Recursive formula:

power(a, n) = a * power(a, n - 1)

Base case:
power(a, 0) = 1

Complete C11 Program

#include <stdio.h>

long long power(int base, unsigned int exponent)
{
    if (exponent == 0)
        return 1;

    return base * power(base, exponent - 1);
}

int main(void)
{
    int base = 2;
    unsigned int exponent = 5;

    printf("Result = %lld\n", power(base, exponent));

    return 0;
}

Expected Output

Result = 32

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

Program 7: Optimized Power Using Exponentiation by Squaring

This is an important placement problem. Instead of multiplying the base n times, divide the exponent by two at every recursive step.

Mathematical formula:

a^n = 1                         when n = 0

a^n = (a^(n/2)) * (a^(n/2))    when n is even

a^n = a * (a^(n/2)) * (a^(n/2))
                                  when n is odd

Complete C11 Program

#include <stdio.h>

long long fastPower(int base, unsigned int exponent)
{
    if (exponent == 0)
        return 1;

    long long half = fastPower(base, exponent / 2);

    if (exponent % 2 == 0)
        return half * half;

    return (long long)base * half * half;
}

int main(void)
{
    printf("2^10 = %lld\n", fastPower(2, 10));

    return 0;
}

Expected Output

2^10 = 1024

Complexity Comparison

Method Time Complexity Auxiliary Space
Basic Recursive Power O(n) O(n)
Exponentiation by Squaring O(log n) O(log n) 
Example: 2^10

2^10 = (2^5)^2
2^5  = 2 * (2^2)^2
2^2  = (2^1)^2
2^1  = 2

Result = 1024
Placement priority: Understand why halving the exponent changes the complexity from O(n) to O(log n).

Program 8: GCD Using Euclidean Algorithm

The Greatest Common Divisor (GCD) is the largest positive integer that divides two integers without leaving a remainder.

Recursive formula:

GCD(a, b) = GCD(b, a % b)

Base case:
GCD(a, 0) = a

Complete C11 Program

#include <stdio.h>

int gcd(int a, int b)
{
    if (b == 0)
        return a;

    return gcd(b, a % b);
}

int main(void)
{
    int a = 48;
    int b = 18;

    printf("GCD = %d\n", gcd(a, b));

    return 0;
}

Expected Output

GCD = 6

Complexity Analysis

  • Time Complexity: O(log(min(a,b))) for positive inputs.
  • Auxiliary Space: O(log(min(a,b))).
This example assumes non-negative inputs. A production implementation should normalize signs and consider the minimum representable signed integer.

3. Recursive Problems on Arrays

An array can be processed recursively by using an index to identify the current element.

Program 9: Print Array Elements

Complete C11 Program

#include <stdio.h>

void printArray(const int arr[], int n, int index)
{
    if (index == n)
        return;

    printf("%d ", arr[index]);

    printArray(arr, n, index + 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof(arr) / sizeof(arr[0]);

    printArray(arr, n, 0);

    printf("\n");

    return 0;
}

Expected Output

10 20 30 40 50

Program 10: Print Array in Reverse Order

Make the recursive call first, then print the current element during the returning phase.

Complete C11 Program

#include <stdio.h>

void printReverse(const int arr[], int n, int index)
{
    if (index == n)
        return;

    printReverse(arr, n, index + 1);

    printf("%d ", arr[index]);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof(arr) / sizeof(arr[0]);

    printReverse(arr, n, 0);

    printf("\n");

    return 0;
}

Expected Output

50 40 30 20 10

Program 11: Find Sum of Array Elements

Recursive formula:

sum(index) = arr[index] + sum(index + 1)

Base case:
sum(n) = 0

Complete C11 Program

#include <stdio.h>

long long arraySum(
    const int arr[],
    int n,
    int index)
{
    if (index == n)
        return 0;

    return arr[index] + arraySum(arr, n, index + 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Array sum = %lld\n", arraySum(arr, n, 0));

    return 0;
}

Expected Output

Array sum = 150

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space: O(n)

Program 12: Find Maximum Element in an Array

Complete C11 Program

#include <stdio.h>

int maximum(const int arr[], int n, int index)
{
    if (index == n - 1)
        return arr[index];

    int maxRest = maximum(arr, n, index + 1);

    return (arr[index] > maxRest)
           ? arr[index] : maxRest;
}

int main(void)
{
    int arr[] = {12, 45, 7, 89, 23};

    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Maximum = %d\n", maximum(arr, n, 0));

    return 0;
}

Expected Output

Maximum = 89

Program 14: Check Whether an Array Is Sorted

Determine whether the array is sorted in non-decreasing order.

Complete C11 Program

#include <stdio.h>
#include <stdbool.h>

bool isSorted(const int arr[], int n, int index)
{
    if (index >= n - 1)
        return true;

    if (arr[index] > arr[index + 1])
        return false;

    return isSorted(arr, n, index + 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof(arr) / sizeof(arr[0]);

    if (isSorted(arr, n, 0))
        printf("Array is sorted\n");
    else
        printf("Array is not sorted\n");

    return 0;
}

Expected Output

Array is sorted

Complexity Analysis

  • Time Complexity: O(n)
  • Worst-case Auxiliary Space: O(n)

Program 15: Recursive Linear Search

Search for a target value in an array using recursion. Return the index if found; otherwise return -1.

Complete C11 Program

#include <stdio.h>

int recursiveSearch(
    const int arr[],
    int n,
    int index,
    int target)
{
    if (index == n)
        return -1;

    if (arr[index] == target)
        return index;

    return recursiveSearch(
        arr, n, index + 1, target
    );
}

int main(void)
{
    int arr[] = {10, 25, 35, 45, 55};

    int n = sizeof(arr) / sizeof(arr[0]);

    int target = 45;

    int result = recursiveSearch(arr, n, 0, target);

    if (result == -1)
        printf("Element not found\n");
    else
        printf("Element found at index %d\n", result);

    return 0;
}

Expected Output

Element found at index 3

Complexity Analysis

  • Best-case Time: O(1)
  • Worst-case Time: O(n)
  • Worst-case Auxiliary Space: O(n)

4. Dry-Run Practice

Consider this recursive function:

int calculate(int n)
{
    if (n == 0)
        return 0;

    return n + calculate(n - 1);
}

For calculate(4):

Function Call Return Expression
calculate(4) 4 + calculate(3)
calculate(3) 3 + calculate(2)
calculate(2) 2 + calculate(1)
calculate(1) 1 + calculate(0)
calculate(0) 0

Returning Phase

calculate(1) = 1

calculate(2) = 2 + 1 = 3

calculate(3) = 3 + 3 = 6

calculate(4) = 4 + 6 = 10

Final Result

10

6. Common Mistakes

  1. Not checking the base case before accessing an array element.
  2. Forgetting to increment or decrement the recursive index.
  3. Using an invalid array index.
  4. Not handling empty arrays in minimum and maximum functions.
  5. Ignoring integer overflow in sums, powers and products.
  6. Assuming recursion is always faster than iteration.
  7. Forgetting that recursive calls consume stack resources.
  8. Using recursion when input size could cause excessive recursion depth.
Implementation assumptions: The maximum and minimum examples require a non-empty array. All array examples require a valid array length and index. Mathematical results must fit their declared return types.

7. Placement Interview Questions and Answers

Q1. How can you calculate the sum of digits recursively?

Use the last digit n % 10 and recursively process the remaining digits using n / 10.

Q2. What is the time complexity of recursive linear search?

O(n) in the worst case.

Q3. Which recursive power algorithm has O(log n) complexity?

Exponentiation by squaring.

Q4. What is the base case of the Euclidean GCD algorithm?

When the second argument becomes zero, return the first argument.

Q5. How can an array be printed in reverse using recursion without modifying it?

Make the recursive call for the next index first, then print the current element while returning.

Q6. What is the auxiliary space complexity of recursive array traversal?

O(n), because the maximum recursion depth is proportional to the array length.

Q7. Can recursive binary search work on an unsorted array?

No. Binary search requires sorted data.

Q8. What is the difference between basic power and fast power?

Basic power reduces the exponent by one on each call. Fast power halves the exponent, reducing time complexity from O(n) to O(log n).

Q9. What does a recursive linear search return when the element is not found?

It returns -1.

Q10. Why can recursive array processing cause stack overflow?

Each recursive call requires call-stack resources. Very large arrays can produce excessive recursion depth.
