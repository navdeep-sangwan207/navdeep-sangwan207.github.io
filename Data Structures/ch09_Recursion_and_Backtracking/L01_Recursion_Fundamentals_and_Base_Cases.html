Chapter 9 - Lesson 1

Recursion Fundamentals and Base Cases

Data Structures and Algorithms Using C

Placement-Oriented Learning | C11

1. What is Recursion?

Recursion is a programming technique in which a function calls itself to solve a problem by breaking it into smaller instances of the same problem.

A recursive function continues calling itself until it reaches a condition that stops further recursive calls.

Interview Definition: Recursion is a problem-solving technique in which a function calls itself with a smaller or simpler input until a base condition is satisfied.

Every recursive function should have two essential parts:

  • Base case: Stops recursion.
  • Recursive case: Calls the same function with a smaller or simpler problem.

2. How Recursion Works

Consider a function that prints numbers from 1 to 5 using recursion. 

#include <stdio.h>

void printNumbers(int n)
{
    if (n == 0)
        return;

    printNumbers(n - 1);

    printf("%d ", n);
}

int main(void)
{
    printNumbers(5);

    return 0;
}

Expected Output

1 2 3 4 5

Explanation

  1. printNumbers(5) calls printNumbers(4).
  2. printNumbers(4) calls printNumbers(3).
  3. printNumbers(3) calls printNumbers(2).
  4. printNumbers(2) calls printNumbers(1).
  5. printNumbers(1) calls printNumbers(0).
  6. At n = 0, the base case returns.
  7. The pending function calls resume and print their values.
Important: Statements after the recursive call execute while the function calls return. This is why the output is in ascending order.

3. Understanding the Base Case

A base case is the terminating condition of a recursive function. It prevents infinite recursive calls. 

void countDown(int n)
{
    if (n == 0)
        return;

    printf("%d\n", n);

    countDown(n - 1);
}

For this function, the base case is:

if (n == 0) return;

When n becomes zero, the function stops calling itself.

Why is a Base Case Necessary?

  • Prevents infinite recursion.
  • Ensures the recursive process terminates.
  • Controls the number of recursive calls.
  • Allows pending function calls to return.
Without a reachable base case, recursion may continue until the program exhausts its available call stack, typically resulting in a stack overflow or abnormal termination.

4. Understanding the Recursive Case

The recursive case is the part of a function that calls itself with a smaller or simpler input. 

void printNumbers(int n)
{
    if (n == 0)
        return;

    printf("%d\n", n);

    printNumbers(n - 1);
}

Here, printNumbers(n - 1) is the recursive case.

Each call reduces n by one, moving the function toward its base case.

5. First Important Recursive Problem: Factorial

The factorial of a non-negative integer n is the product of all positive integers from 1 to n.

Mathematical definition:

n! = n × (n - 1)!

Base case: 0! = 1

Complete C11 Program

#include <stdio.h>

unsigned long long factorial(int n)
{
    if (n == 0 || n == 1)
        return 1;

    return (unsigned long long)n * factorial(n - 1);
}

int main(void)
{
    int n = 5;

    if (n < 0 || n > 20)
    {
        printf("Input out of supported range.\n");
        return 1;
    }

    printf("Factorial of %d = %llu\n", n, factorial(n));

    return 0;
}

Expected Output

Factorial of 5 = 120

Dry Run

Function Call Operation
factorial(5) 5 × factorial(4)
factorial(4) 4 × factorial(3)
factorial(3) 3 × factorial(2)
factorial(2) 2 × factorial(1)
factorial(1) Returns 1

Returning calculations:

factorial(1) = 1
factorial(2) = 2 * 1 = 2
factorial(3) = 3 * 2 = 6
factorial(4) = 4 * 6 = 24
factorial(5) = 5 * 24 = 120

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space Complexity: O(n), due to recursive calls.
This implementation supports n from 0 to 20 because 20! fits in an unsigned long long on standard C11 implementations with at least 64-bit unsigned long long.

6. Sum of First N Natural Numbers

Write a recursive function to calculate the sum of numbers from 1 to n.

Recursive relation:

sum(n) = n + sum(n - 1)

Base case: sum(0) = 0

Complete C11 Program

#include <stdio.h>

long long sumNatural(int n)
{
    if (n == 0)
        return 0;

    return n + sumNatural(n - 1);
}

int main(void)
{
    int n = 5;

    if (n < 0 || n > 1000000)
    {
        printf("Invalid input.\n");
        return 1;
    }

    printf("Sum = %lld\n", sumNatural(n));

    return 0;
}

Expected Output

Sum = 15

Complexity Analysis

  • Time Complexity: O(n)
  • Auxiliary Space Complexity: O(n)
A very deep recursive call can exhaust the available stack. The input limit in this example is illustrative, not a guarantee that every system can safely execute one million recursive calls.

7. Statements Before and After Recursive Calls

The position of a statement relative to a recursive call changes the order in which output is produced.

Example A: Print Before Recursive Call

void printAscending(int n)
{
    if (n == 0)
        return;

    printf("%d ", n);

    printAscending(n - 1);
}

Input: 5
Output: 5 4 3 2 1

Example B: Print After Recursive Call

void printAscending(int n)
{
    if (n == 0)
        return;

    printAscending(n - 1);

    printf("%d ", n);
}

Input: 5
Output: 1 2 3 4 5
Placement Tip: Questions that ask you to predict recursive output frequently test whether you understand execution before and after the recursive call.

8. Recursion vs Iteration

Recursion Iteration
Function calls itself. Uses loops such as for and while.
Uses the call stack for function calls. Usually uses constant auxiliary space for simple loops.
Can make tree and divide-and-conquer problems easier to express. Often has lower function-call overhead.
Can cause stack overflow for excessive depth. Does not create one function call per iteration.
May be less memory-efficient for deep recursion. Often preferred for simple repetitive operations.

9. Time and Space Complexity of Recursion

Recursive algorithms must be analyzed for both execution time and the maximum number of simultaneously active function calls.

Problem Time Complexity Auxiliary Stack Space
Print numbers from 1 to n O(n) O(n)
Factorial O(n) O(n)
Sum of natural numbers O(n) O(n)
Recursive binary search O(log n) O(log n)
Important distinction: Auxiliary space includes memory used by active recursive calls. It is not necessarily the same as the input array or other data structures supplied to the function.

10. Placement Interview Questions and Answers

Q1. What is recursion?

Recursion is a technique in which a function calls itself to solve smaller instances of a problem.

Q2. What is a base case?

A base case is the condition that stops further recursive calls.

Q3. What happens if a recursive function has no base case?

If no terminating condition is reached, recursive calls may continue until the call stack is exhausted.

Q4. What is a recursive case?

It is the statement that calls the same function with a smaller or simpler input.

Q5. What is a call stack?

The call stack stores information about active function calls, including their local variables and return locations.

Q6. Does recursion always use more memory than iteration?

No. Memory use depends on the algorithm and its recursion depth. However, ordinary recursive calls generally require additional call-stack space.

Q7. Can every recursive algorithm be converted into iteration?

In principle, recursion can be simulated using iteration and an explicit stack, although the iterative version may be more complicated.

Q8. What is stack overflow in recursion?

It occurs when recursive calls consume more call-stack space than the program can use.

Q9. What is direct recursion?

Direct recursion occurs when a function calls itself directly.

Q10. What is indirect recursion?

Indirect recursion occurs when one function calls another function, which eventually calls the original function.

12. Multiple Choice Questions

Q1. Which condition terminates a recursive function?

A. Recursive case

B. Base case

C. Loop condition

D. Function prototype

Answer: B. Base case

Q2. Which memory structure manages ordinary function calls?

A. Heap

B. Queue

C. Call stack

D. Hash table

Answer: C. Call stack

Q3. What is the time complexity of recursive factorial?

A. O(1)

B. O(log n)

C. O(n)

D. O(n²)

Answer: C. O(n)

Q4. What is the auxiliary stack space of recursive factorial?

A. O(1)

B. O(log n)

C. O(n)

D. O(n²)

Answer: C. O(n)

Q5. What happens after a base case returns?

A. All function calls disappear immediately.

B. Pending calls resume and return.

C. The program always terminates.

D. The heap is cleared.

Answer: B. Pending calls resume and return.

13. Lesson Summary

  • Recursion means a function calls itself.
  • Every recursive solution needs a valid stopping condition.
  • The base case terminates recursive calls.
  • The recursive case reduces the problem.
  • Function calls are managed using the call stack.
  • Recursive algorithms require time and stack-space analysis.
  • Factorial and sum of natural numbers are basic recursive problems.
