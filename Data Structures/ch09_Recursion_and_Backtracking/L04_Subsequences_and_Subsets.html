2. What Is a Subsequence?

A subsequence is a sequence obtained by deleting zero or more elements from the original sequence without changing the relative order of the remaining elements.

Consider the string:

Original string: ABC

Some possible subsequences are:

  • Empty subsequence: ""
  • A
  • B
  • C
  • AB
  • AC
  • BC
  • ABC
Important: The relative order of selected elements must remain unchanged. For example, AC is a subsequence of ABC, but CA is not.

2.1 Number of Subsequences

For a sequence containing n elements, each element has two choices:

  1. Include the element.
  2. Exclude the element.

Therefore, the total number of subsequences is:

Total subsequences = 2n

For a string of length 3:

23 = 8 subsequences, including the empty subsequence.

3. Subsequence vs Substring vs Subset

Concept Meaning Example using ABC
Substring Contiguous characters in the original string. AB, BC, ABC
Subsequence Characters selected in their original relative order. AC, AB, BC
Subset A selection of elements where order is not important. {A, C}, {B}, {A, B, C}
Interview distinction: Every substring is a subsequence, but every subsequence is not a substring. A subset does not impose an ordering requirement.

4. Include/Exclude Recursion Technique

The most common approach to generating subsequences and subsets is the include/exclude technique.

At every index, make two recursive choices:

  • Include: Add the current element to the result.
  • Exclude: Do not add the current element.

4.1 General Algorithm

  1. Start from index 0.
  2. If the index reaches the sequence length, process the current selection.
  3. Make an include choice for the current element.
  4. Undo that choice when returning from recursion.
  5. Make an exclude choice.

4.2 Recursion Tree for ABC

                         Start
                       /       \
                  Include A   Exclude A
                   /    \       /    \
              Include B Exclude B Include B Exclude B
                 ...       ...      ...       ...

Every level represents a decision about one element. With n elements, the recursion tree has 2n leaf nodes.

Remember: The include/exclude technique explores every possible selection. Its number of combinations grows exponentially as the input size increases.

5. Program 1 – Generate All Subsequences of a String

This program generates all subsequences of a string using recursive include/exclude decisions.

Complete C11 Program

#include <stdio.h>
#include <string.h>

void generateSubsequences(
    const char str[],
    int index,
    int length,
    char result[],
    int resultIndex
) {
    /* Base case */
    if (index == length) {
        result[resultIndex] = '\0';
        printf("\"%s\"\n", result);
        return;
    }

    /* Choice 1: Include current character */
    result[resultIndex] = str[index];

    generateSubsequences(
        str,
        index + 1,
        length,
        result,
        resultIndex + 1
    );

    /* Choice 2: Exclude current character */
    generateSubsequences(
        str,
        index + 1,
        length,
        result,
        resultIndex
    );
}

int main(void) {
    char str[100];
    char result[100];

    printf("Enter a string: ");

    if (scanf("%99s", str) != 1) {
        printf("Invalid input.\n");
        return 1;
    }

    int length = (int)strlen(str);

    printf("\nAll subsequences:\n");

    generateSubsequences(
        str,
        0,
        length,
        result,
        0
    );

    return 0;
}

Expected Output

Enter a string: ABC

All subsequences:
"ABC"
"AB"
"AC"
"A"
"BC"
"B"
"C"
""

Dry Run

Input: ABC

Decision Current selection
Include A, B and CABC
Include A and B, exclude CAB
Include A, exclude B, include CAC
Include A, exclude B and CA
Exclude A, include B and CBC
Exclude A and C, include BB
Exclude A and B, include CC
Exclude A, B and CEmpty

Complexity Analysis

  • Time: O(n × 2n) when accounting for printing each subsequence.
  • Auxiliary space: O(n) for the recursion stack and result buffer.
  • Number of outputs: 2n.

6. Program 2 – Generate All Subsets of an Array

A subset contains selected elements from an array. In this implementation, we use the same include/exclude recursion.

Complete C11 Program

#include <stdio.h>

void generateSubsets(
    const int arr[],
    int n,
    int index,
    int subset[],
    int subsetSize
) {
    /* Base case */
    if (index == n) {
        printf("{ ");

        for (int i = 0; i < subsetSize; i++) {
            printf("%d ", subset[i]);
        }

        printf("}\n");
        return;
    }

    /* Include current element */
    subset[subsetSize] = arr[index];

    generateSubsets(
        arr,
        n,
        index + 1,
        subset,
        subsetSize + 1
    );

    /* Exclude current element */
    generateSubsets(
        arr,
        n,
        index + 1,
        subset,
        subsetSize
    );
}

int main(void) {
    int arr[] = {1, 2, 3};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int subset[3];

    printf("All subsets:\n");

    generateSubsets(arr, n, 0, subset, 0);

    return 0;
}

Expected Output

All subsets:
{ 1 2 3 }
{ 1 2 }
{ 1 3 }
{ 1 }
{ 2 3 }
{ 2 }
{ 3 }
{ }

Explanation

For the array {1, 2, 3}, every element has two choices.

  • Include 1 or exclude 1.
  • Include 2 or exclude 2.
  • Include 3 or exclude 3.

The program prints all 8 possible subsets, including the empty subset.

Complexity Analysis

  • Time: O(n × 2n) including printing all elements.
  • Auxiliary space: O(n).
  • Recursion depth: O(n).

7. Program 3 – Count Subsequences Without Generating Them

If every element can either be included or excluded, the total number of subsequences is 2n.

We can also calculate this count recursively. At each index, both recursive choices contribute to the total.

Complete C11 Program

#include <stdio.h>

unsigned long long countSubsequences(int n) {
    /* One empty subsequence */
    if (n == 0) {
        return 1;
    }

    return countSubsequences(n - 1)
         + countSubsequences(n - 1);
}

int main(void) {
    int n;

    printf("Enter number of elements: ");

    if (scanf("%d", &n) != 1 || n < 0 || n > 63) {
        printf("Enter a value between 0 and 63.\n");
        return 1;
    }

    unsigned long long count = countSubsequences(n);

    printf("Total subsequences = %llu\n", count);

    return 0;
}

Expected Output

Enter number of elements: 4
Total subsequences = 16

Complexity Analysis

  • Time: O(2n).
  • Auxiliary space: O(n).
Interview optimization: If only the count is required, calculate 2n directly using an appropriate integer type or checked arithmetic. There is no need to construct the recursion tree.

8. Program 4 – Subset Sum Problem

The Subset Sum Problem asks whether any subset of a given array has a sum equal to a specified target.

Example

Array: {3, 4, 5, 2}

Target: 9

One valid subset: {4, 5}

Answer: YES

Recursive Approach

For each element, consider two possibilities:

  1. Include the current element and subtract it from the target.
  2. Exclude the current element and keep the target unchanged.

If the remaining target becomes zero, a valid subset has been found. If all elements are processed and the target is not zero, that path does not produce a solution.

Complete C11 Program

#include <stdio.h>

int subsetSum(
    const int arr[],
    int n,
    int index,
    int target
) {
    /* A subset with the required sum has been found */
    if (target == 0) {
        return 1;
    }

    /* No elements remain */
    if (index == n) {
        return 0;
    }

    /* Choice 1: Include current element */
    if (subsetSum(
            arr,
            n,
            index + 1,
            target - arr[index]
        )) {
        return 1;
    }

    /* Choice 2: Exclude current element */
    return subsetSum(
        arr,
        n,
        index + 1,
        target
    );
}

int main(void) {
    int arr[] = {3, 4, 5, 2};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target = 9;

    if (subsetSum(arr, n, 0, target)) {
        printf("Subset with sum %d exists.\n", target);
    } else {
        printf("Subset with sum %d does not exist.\n", target);
    }

    return 0;
}

Expected Output

Subset with sum 9 exists.

Dry Run

Input array: {3, 4, 5, 2}, target = 9

  1. Include 3. Remaining target = 6.
  2. Try including 4. Remaining target = 2.
  3. Try including 5. Remaining target = -3.
  4. That selection does not solve the problem.
  5. Backtrack and exclude 5.
  6. Include 2. Remaining target = 0.
  7. A valid subset {3, 4, 2} is found.
The program returns as soon as it finds one valid subset. For the given input, {3, 4, 2} is also a valid answer, in addition to {4, 5}.

Complexity Analysis

  • Worst-case time: O(2n).
  • Auxiliary space: O(n) recursion depth.
Important limitation: This simple implementation is intended for non-negative array elements and a non-negative target. For arrays containing negative numbers, the target-zero early return and pruning assumptions need to be reconsidered. Integer overflow must also be considered for large values.

9. Program 5 – Generate Unique Subsets with Duplicates

Consider the array:

Array: {1, 2, 2}

If we generate subsets without handling duplicates, the same value combination can appear more than once.

A common solution is:

  1. Sort the array.
  2. Use include/exclude recursion.
  3. When excluding an element, skip subsequent equal elements at the same recursion level.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define MAX_SIZE 100

int compareIntegers(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

void generateUniqueSubsets(
    const int arr[],
    int n,
    int start,
    int subset[],
    int subsetSize
) {
    /* Print the current subset */
    printf("{ ");

    for (int i = 0; i < subsetSize; i++) {
        printf("%d ", subset[i]);
    }

    printf("}\n");

    for (int i = start; i < n; i++) {

        /* Skip duplicates at the same recursion level */
        if (i > start && arr[i] == arr[i - 1]) {
            continue;
        }

        /* Include current element */
        subset[subsetSize] = arr[i];

        generateUniqueSubsets(
            arr,
            n,
            i + 1,
            subset,
            subsetSize + 1
        );
    }
}

int main(void) {
    int arr[] = {1, 2, 2};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int subset[MAX_SIZE];

    qsort(
        arr,
        (size_t)n,
        sizeof(arr[0]),
        compareIntegers
    );

    printf("Unique subsets:\n");

    generateUniqueSubsets(
        arr,
        n,
        0,
        subset,
        0
    );

    return 0;
}

Expected Output

Unique subsets:
{ }
{ 1 }
{ 1 2 }
{ 1 2 2 }
{ 2 }
{ 2 2 }

Why Do We Sort the Array?

Sorting places equal elements next to each other. This allows us to detect repeated values by comparing the current element with the previous one.

Important Condition

if (i > start && arr[i] == arr[i - 1]) {
    continue;
}

The condition skips a duplicate only when it occurs after another equal element at the same recursion level. It does not prevent selecting multiple copies of a value along one recursion path.

Complexity Analysis

  • Sorting: O(n log n) with the usual library implementation, though the C standard does not guarantee a specific qsort algorithm complexity.
  • Subset generation: O(n × 2n) as a worst-case output-sensitive bound.
  • Auxiliary space: O(n) for the recursion and current subset, excluding sorting-library internals.

10. Important Recursion Patterns

Problem Recursive Choices Typical Complexity
Generate subsequences Include or exclude each character O(n × 2n) including output
Generate subsets Include or exclude each element O(n × 2n) including output
Count subsequences Add counts from both choices O(2n) recursively
Subset sum Include or exclude each element O(2n) worst case
Unique subsets Choose elements while skipping duplicates Output-sensitive, exponential worst case

11. Common Interview Questions and Answers

Q1. What is a subsequence?

A subsequence is obtained by deleting zero or more elements without changing the relative order of the remaining elements.

Q2. How many subsequences does a sequence of length n have?

It has 2n subsequences, including the empty subsequence.

Q3. Why does subset generation use recursion?

Each element has two independent choices: include it or exclude it. Recursion naturally explores these choices.

Q4. What is the difference between a subsequence and a substring?

A substring contains contiguous elements. A subsequence does not need to be contiguous, but it must preserve relative order.

Q5. What is the include/exclude pattern?

It is a recursive technique in which each element is either included in the current solution or excluded from it.

Q6. What is the base case in subsequence generation?

The base case is reached when the current index equals the sequence length. The current selection is then processed.

Q7. Why is subset generation exponential?

Each of n elements has two choices, producing 2n possible selections.

Q8. What is the subset-sum problem?

It asks whether a subset of the given elements has a sum equal to a specified target.

Q9. How can duplicate subsets be avoided?

Sort the array and skip equal elements at the same recursion level while generating subsets.

Q10. Can subset sum be optimized using dynamic programming?

Yes. For non-negative integers and a manageable target, dynamic programming can solve the decision version in O(n × target) time and O(target) space using a one-dimensional DP array.

Q11. Does the empty subset count?

Yes. Every set has an empty subset. It is also a subsequence of every sequence.

Q12. What is the auxiliary space complexity of recursive subset generation?

It is O(n) for the recursion stack and the current selection, excluding any separately stored output.

14. Lesson Summary

  • A subsequence preserves the relative order of selected elements.
  • A substring is a contiguous sequence of characters.
  • A subset represents a selection of elements without an ordering requirement.
  • Each element has two choices: include or exclude.
  • A sequence of length n has 2n subsequences and subsets when positions are treated as distinct.
  • Recursive subset generation requires O(n) auxiliary space, excluding output storage.
  • Subset sum is a classic include/exclude problem.
  • Sorting and skipping duplicates helps generate unique subsets.
  • Dynamic programming can optimize subset-sum problems when the target is suitably bounded.
