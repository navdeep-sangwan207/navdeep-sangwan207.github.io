2. What Is Recursion?

Recursion is a programming technique in which a function calls itself to solve a smaller version of the same problem.

Example: Factorial

5! = 5 * 4 * 3 * 2 * 1

Recursive definition:

factorial(n) = n * factorial(n - 1)

Base case:

factorial(0) = 1

Recursive C Function

long long factorial(int n)
{
    if (n == 0 || n == 1)
        return 1;

    return n * factorial(n - 1);
}

3. What Is Iteration?

Iteration means repeatedly executing a block of statements using loops such as for, while and do-while.

Iterative Factorial

long long factorial(int n)
{
    long long result = 1;

    for (int i = 2; i <= n; i++)
    {
        result *= i;
    }

    return result;
}

The iterative solution uses a loop instead of repeatedly calling the same function.

4. Recursion vs Iteration

Parameter Recursion Iteration
Mechanism Function calls itself Uses loops
Termination Base condition Loop condition
Memory Uses call stack Usually uses constant loop-control space
Function call overhead Repeated function calls No recursive call overhead
Code structure Often concise for hierarchical problems Often straightforward for repetitive tasks
Stack overflow risk Possible with deep recursion No recursive call-stack growth
Typical applications Trees, backtracking, divide and conquer Array traversal, counting, simple searching
Important: Recursion and iteration can have the same time complexity, but their auxiliary space requirements may be different.

5. Program 1: Factorial Using Recursion and Iteration

Both implementations calculate the factorial of a non-negative integer. The program restricts the input to a range that fits in unsigned long long.

Complete C11 Program

#include <stdio.h>

unsigned long long factorialRecursive(unsigned int n)
{
    if (n == 0 || n == 1)
        return 1;

    return n * factorialRecursive(n - 1);
}

unsigned long long factorialIterative(unsigned int n)
{
    unsigned long long result = 1;

    for (unsigned int i = 2; i <= n; i++)
    {
        result *= i;
    }

    return result;
}

int main(void)
{
    unsigned int n;

    printf("Enter a number (0 to 20): ");

    if (scanf("%u", &n) != 1 || n > 20)
    {
        printf("Invalid input\n");
        return 1;
    }

    printf("Recursive factorial = %llu\n",
           factorialRecursive(n));

    printf("Iterative factorial = %llu\n",
           factorialIterative(n));

    return 0;
}

Expected Output

Enter a number (0 to 20): 5
Recursive factorial = 120
Iterative factorial = 120

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(n) O(n)
Iterative O(n) O(1)

The recursive function creates approximately n active function calls. The iterative function only maintains loop variables and an accumulator.

6. Program 2: Sum of First N Natural Numbers

Recursive Approach

sum(n) = n + sum(n - 1)

Base case:

sum(0) = 0

Complete C11 Program

#include <stdio.h>

long long sumRecursive(unsigned int n)
{
    if (n == 0)
        return 0;

    return n + sumRecursive(n - 1);
}

long long sumIterative(unsigned int n)
{
    long long sum = 0;

    for (unsigned int i = 1; i <= n; i++)
    {
        sum += i;
    }

    return sum;
}

int main(void)
{
    unsigned int n;

    printf("Enter a number: ");

    if (scanf("%u", &n) != 1 || n > 1000000)
    {
        printf("Invalid input\n");
        return 1;
    }

    printf("Recursive sum = %lld\n",
           sumRecursive(n));

    printf("Iterative sum = %lld\n",
           sumIterative(n));

    printf("Formula result = %llu\n",
           (unsigned long long)n * (n + 1ULL) / 2ULL);

    return 0;
}

Expected Output

Enter a number: 5
Recursive sum = 15
Iterative sum = 15
Formula result = 15

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(n) O(n)
Iterative O(n) O(1)
Mathematical formula O(1) O(1)

7. Program 3: Array Traversal Using Recursion and Iteration

Complete C11 Program

#include <stdio.h>

void recursiveTraversal(
    const int arr[],
    int n,
    int index)
{
    if (index == n)
        return;

    printf("%d ", arr[index]);

    recursiveTraversal(arr, n, index + 1);
}

void iterativeTraversal(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Recursive traversal: ");

    recursiveTraversal(arr, n, 0);

    printf("\nIterative traversal: ");

    iterativeTraversal(arr, n);

    printf("\n");

    return 0;
}

Expected Output

Recursive traversal: 10 20 30 40 50
Iterative traversal: 10 20 30 40 50

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(n) O(n)
Iterative O(n) O(1)

8. Program 4: Linear Search Using Recursion and Iteration

Complete C11 Program

#include <stdio.h>

int recursiveLinearSearch(
    const int arr[],
    int n,
    int index,
    int key)
{
    if (index == n)
        return -1;

    if (arr[index] == key)
        return index;

    return recursiveLinearSearch(
        arr,
        n,
        index + 1,
        key
    );
}

int iterativeLinearSearch(
    const int arr[],
    int n,
    int key)
{
    for (int i = 0; i < n; i++)
    {
        if (arr[i] == key)
            return i;
    }

    return -1;
}

int main(void)
{
    int arr[] = {12, 25, 37, 48, 59};

    int n = sizeof(arr) / sizeof(arr[0]);

    int key = 37;

    int recursiveResult =
        recursiveLinearSearch(arr, n, 0, key);

    int iterativeResult =
        iterativeLinearSearch(arr, n, key);

    printf("Recursive search index = %d\n",
           recursiveResult);

    printf("Iterative search index = %d\n",
           iterativeResult);

    return 0;
}

Expected Output

Recursive search index = 2
Iterative search index = 2

Complexity Analysis

Approach Best Time Worst Time Auxiliary Space
Recursive O(1) O(n) O(n)
Iterative O(1) O(n) O(1)

9. Program 5: Power Calculation

Calculate x raised to the power n, where n is a non-negative integer.

Recursive Approach

power(x, n) = x * power(x, n - 1)

Base case:

power(x, 0) = 1

Complete C11 Program

#include <stdio.h>

long long powerRecursive(int x, unsigned int n)
{
    if (n == 0)
        return 1;

    return x * powerRecursive(x, n - 1);
}

long long powerIterative(int x, unsigned int n)
{
    long long result = 1;

    for (unsigned int i = 0; i < n; i++)
    {
        result *= x;
    }

    return result;
}

int main(void)
{
    int base = 2;

    unsigned int exponent = 5;

    printf("Recursive result = %lld\n",
           powerRecursive(base, exponent));

    printf("Iterative result = %lld\n",
           powerIterative(base, exponent));

    return 0;
}

Expected Output

Recursive result = 32
Iterative result = 32

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(n) O(n)
Iterative O(n) O(1)
These examples use small values so the result fits in long long. Signed integer overflow in C is undefined behavior.

10. Program 6: Binary Search Using Recursion and Iteration

Binary search works only on a sorted array. It repeatedly reduces the search interval by approximately half.

Recursive Binary Search

binarySearch(arr, low, high, key)

mid = low + (high - low) / 2

If arr[mid] == key:
    return mid

If key < arr[mid]:
    Search left half

Otherwise:
    Search right half

Complete C11 Program

#include <stdio.h>

int recursiveBinarySearch(
    const int arr[],
    int low,
    int high,
    int key)
{
    if (low > high)
        return -1;

    int mid = low + (high - low) / 2;

    if (arr[mid] == key)
        return mid;

    if (key < arr[mid])
    {
        return recursiveBinarySearch(
            arr,
            low,
            mid - 1,
            key
        );
    }

    return recursiveBinarySearch(
        arr,
        mid + 1,
        high,
        key
    );
}

int iterativeBinarySearch(
    const int arr[],
    int n,
    int key)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid;

        if (key < arr[mid])
            high = mid - 1;
        else
            low = mid + 1;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70};

    int n = sizeof(arr) / sizeof(arr[0]);

    int key = 50;

    printf("Recursive binary search index = %d\n",
           recursiveBinarySearch(arr, 0, n - 1, key));

    printf("Iterative binary search index = %d\n",
           iterativeBinarySearch(arr, n, key));

    return 0;
}

Expected Output

Recursive binary search index = 4
Iterative binary search index = 4

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(log n) O(log n)
Iterative O(log n) O(1)
Placement point: Both binary search implementations have O(log n) time complexity. The iterative version uses O(1) auxiliary space, while the recursive version uses O(log n) call-stack space.

11. Program 7: GCD Using Recursion and Iteration

The Euclidean algorithm calculates the greatest common divisor. 

GCD(a, b) = GCD(b, a % b)

Base case:

GCD(a, 0) = a

Complete C11 Program

#include <stdio.h>

int gcdRecursive(int a, int b)
{
    if (b == 0)
        return a;

    return gcdRecursive(b, a % b);
}

int gcdIterative(int a, int b)
{
    while (b != 0)
    {
        int remainder = a % b;

        a = b;
        b = remainder;
    }

    return a;
}

int main(void)
{
    int a = 48;
    int b = 18;

    printf("Recursive GCD = %d\n",
           gcdRecursive(a, b));

    printf("Iterative GCD = %d\n",
           gcdIterative(a, b));

    return 0;
}

Expected Output

Recursive GCD = 6
Iterative GCD = 6

Complexity Analysis

Approach Time Auxiliary Space
Recursive O(log(min(a,b))) O(log(min(a,b)))
Iterative O(log(min(a,b))) O(1)

This example assumes non-negative inputs and does not handle the absolute-value edge case for INT_MIN.

12. Understanding the Function Call Stack

Every active function call generally has an associated stack frame containing information such as local variables, parameters and return information. The exact implementation is compiler- and platform-dependent.

Example: factorial(4)

factorial(4)
    |
    +-- 4 * factorial(3)
                 |
                 +-- 3 * factorial(2)
                              |
                              +-- 2 * factorial(1)
                                           |
                                           +-- return 1

Call and Return Sequence

CALL PHASE:

factorial(4)
factorial(3)
factorial(2)
factorial(1)

RETURN PHASE:

factorial(1) = 1
factorial(2) = 2
factorial(3) = 6
factorial(4) = 24

Important Points

  • Function calls are nested.
  • Each call must eventually return.
  • Recursive calls use call-stack resources.
  • Deep recursion can exhaust available stack space.

13. Recursion Depth

Recursion depth is the maximum number of simultaneously active recursive calls during execution.

Example

void display(int n)
{
    if (n == 0)
        return;

    display(n - 1);
}

int main(void)
{
    display(5);
    return 0;
}

The function reaches a base case after five recursive calls beyond the initial invocation.

Space Complexity

If every call uses O(1) additional stack space and the maximum recursion depth is n, the auxiliary stack space is O(n).

C does not guarantee a particular maximum recursion depth. Available stack space depends on the environment, compiler, operating system and program configuration.

14. Tail Recursion vs Non-Tail Recursion

Tail Recursion

A function is tail-recursive when the recursive call is the last operation performed by that function. 

void printNumbers(int n)
{
    if (n == 0)
        return;

    printf("%d ", n);

    printNumbers(n - 1);
}

Non-Tail Recursion

A function is non-tail-recursive when additional work remains after the recursive call returns. 

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}
Tail Recursion Non-Tail Recursion
Recursive call is the final operation. Work remains after recursive return.
May be easier to transform into iteration. Often requires storing pending work.
Can potentially support tail-call optimization. Usually cannot use tail-call optimization for that call.
C11 does not require compilers to perform tail-call optimization. Do not assume tail recursion automatically uses O(1) stack space.

15. Recurrence Relations

A recurrence relation expresses the running time of a recursive algorithm in terms of smaller input sizes.

Example 1: Linear Recursion

T(n) = T(n - 1) + O(1)

T(0) = O(1)

Result: O(n)

Examples: factorial and recursive array traversal.

Example 2: Divide the Problem in Half

T(n) = T(n / 2) + O(1)

Result: O(log n)

Example: binary search.

Example 3: Two Recursive Calls on Nearly Equal Inputs

T(n) = 2T(n - 1) + O(1)

Result: O(2^n)

This is an upper-bound form for a recursion that creates two subproblems of size n-1. It illustrates exponential growth.

Example 4: Two Half-Sized Subproblems

T(n) = 2T(n / 2) + O(n)

Result: O(n log n)

Example: merge sort.

Recurrence Time Complexity Example
T(n) = T(n-1) + O(1) O(n) Factorial
T(n) = T(n/2) + O(1) O(log n) Binary search
T(n) = 2T(n-1) + O(1) O(2^n) Two-branch recursion example
T(n) = 2T(n/2) + O(n) O(n log n) Merge sort

16. Fibonacci: Recursive vs Iterative

The Fibonacci sequence is defined as: 

F(0) = 0
F(1) = 1

F(n) = F(n - 1) + F(n - 2)

Naive Recursive Implementation

unsigned long long fibonacciRecursive(unsigned int n)
{
    if (n <= 1)
        return n;

    return fibonacciRecursive(n - 1) +
           fibonacciRecursive(n - 2);
}

This implementation repeats many calculations. Its time complexity is O(2^n) as a simple upper bound, and its maximum recursion depth is O(n).

Iterative Implementation

unsigned long long fibonacciIterative(unsigned int n)
{
    if (n == 0)
        return 0;

    unsigned long long previous = 0;
    unsigned long long current = 1;

    for (unsigned int i = 2; i <= n; i++)
    {
        unsigned long long next = previous + current;

        previous = current;
        current = next;
    }

    return current;
}

The iterative implementation takes O(n) time and O(1) auxiliary space. Both examples require values small enough to fit in unsigned long long.

Complete C11 Program

#include <stdio.h>

unsigned long long fibonacciRecursive(unsigned int n)
{
    if (n <= 1)
        return n;

    return fibonacciRecursive(n - 1) +
           fibonacciRecursive(n - 2);
}

unsigned long long fibonacciIterative(unsigned int n)
{
    if (n == 0)
        return 0;

    unsigned long long previous = 0;
    unsigned long long current = 1;

    for (unsigned int i = 2; i <= n; i++)
    {
        unsigned long long next = previous + current;

        previous = current;
        current = next;
    }

    return current;
}

int main(void)
{
    unsigned int n = 10;

    printf("Recursive Fibonacci = %llu\n",
           fibonacciRecursive(n));

    printf("Iterative Fibonacci = %llu\n",
           fibonacciIterative(n));

    return 0;
}

Expected Output

Recursive Fibonacci = 55
Iterative Fibonacci = 55
Approach Time Auxiliary Space
Naive recursion O(2^n) upper bound O(n)
Iteration O(n) O(1)

17. When Should You Use Recursion?

Use Recursion When:

  • The problem naturally divides into smaller similar problems.
  • Working with tree structures.
  • Implementing depth-first search.
  • Solving backtracking problems.
  • Implementing divide-and-conquer algorithms.

Use Iteration When:

  • Simple repeated processing is required.
  • Processing large arrays sequentially.
  • Constant auxiliary space is important.
  • Deep recursion could cause stack exhaustion.
  • An iterative solution is clearer and easier to maintain.

18. Common Placement Interview Mistakes

  1. Comparing only time complexity and ignoring stack space.
  2. Assuming every recursive function takes O(n) time.
  3. Assuming every iterative algorithm takes O(1) space.
  4. Forgetting that recursive calls remain active until they return.
  5. Confusing recursion depth with total number of function calls.
  6. Assuming C automatically optimizes tail recursion.
  7. Using recursion without a correct base condition.
  8. Ignoring repeated work in naive recursive algorithms.

19. Interview Questions and Answers

Q1. What is the difference between recursion and iteration?

Recursion solves a problem through function calls, while iteration repeatedly executes statements using loops.

Q2. Which approach generally uses less auxiliary space?

An iterative solution often uses less auxiliary space because it does not require recursive call-stack frames.

Q3. Can recursion and iteration have the same time complexity?

Yes. Recursive and iterative factorial both take O(n) time.

Q4. What is recursion depth?

It is the maximum number of simultaneously active recursive function calls.

Q5. What is stack overflow?

Stack overflow occurs when the program exceeds the available call-stack resources.

Q6. What is tail recursion?

Tail recursion occurs when the recursive call is the last operation performed by the function.

Q7. Does C guarantee tail-call optimization?

No. C11 does not require a compiler to optimize tail-recursive function calls.

Q8. What is a recurrence relation?

It describes an algorithm's running time using the running time of smaller input instances.

Q9. What is the time complexity of recursive binary search?

O(log n).

Q10. What is the auxiliary space complexity of recursive binary search?

O(log n), due to the recursive call stack.

Q11. Why is naive recursive Fibonacci inefficient?

It repeatedly calculates the same Fibonacci values, causing exponential growth in the number of calls.

Q12. How can recursive Fibonacci be optimized?

Memoization or an iterative dynamic programming approach avoids repeated calculations.

Q13. What is the difference between total calls and recursion depth?

Total calls count every invocation made during execution. Recursion depth counts only the maximum number of simultaneously active calls.

Q14. Which binary search implementation is generally preferred when minimizing auxiliary space?

The iterative implementation, because it uses O(1) auxiliary space.

Q15. Is recursion always slower than iteration?

Not necessarily. Performance depends on the algorithm, compiler optimizations, function-call overhead and workload.
