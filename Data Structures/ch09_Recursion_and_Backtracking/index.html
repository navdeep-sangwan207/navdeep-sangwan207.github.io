Recursion and Backtracking

Data Structures and Algorithms Using C

Placement-Oriented Learning | C11

Chapter Overview

This chapter covers recursion, recursive problem solving, call-stack behavior, subsequences, subsets and backtracking. It also focuses on important placement coding problems involving permutations, combinations, N-Queens and maze solving.

All implementations use the C programming language (C11 standard).

What You Will Learn

  • Understand recursion and base cases.
  • Analyze recursion trees and function call stacks.
  • Solve recursive problems involving arrays and strings.
  • Generate subsequences and subsets.
  • Understand backtracking and state-space trees.
  • Generate permutations and combinations.
  • Solve N-Queens and maze problems.
  • Develop efficient solutions for recursion-based interview problems.
  • Analyze time and auxiliary space complexity.
