Chapter Overview

Recursion is a programming technique in which a function calls itself to solve a smaller instance of a problem. It is an important foundation for understanding divide-and-conquer algorithms, tree traversal, backtracking and many advanced programming problems.

Backtracking is a problem-solving technique that explores possible solutions step by step and abandons a path when it cannot lead to a valid solution.

This chapter covers recursion fundamentals, recursive problem-solving, the function call stack, backtracking, subsets, permutations, combinations and important interview problems.

Learning Outcomes

  • Understand how recursive functions execute.
  • Identify base cases and recursive cases.
  • Trace recursive calls using a call stack.
  • Write recursive solutions for numerical and array problems.
  • Analyze recursion time and space complexity.
  • Understand recursion trees and state-space trees.
  • Implement backtracking algorithms in C.
  • Solve subsets, permutations and combinations problems.
  • Approach N-Queens, Sudoku and maze problems.
