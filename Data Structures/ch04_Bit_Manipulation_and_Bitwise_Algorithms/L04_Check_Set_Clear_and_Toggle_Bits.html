Chapter 4: Bit Manipulation and Bitwise Algorithms

Lesson 4: Check, Set, Clear and Toggle Bits

Learn the four fundamental bit operations and implement reusable C functions for placement coding rounds.

1. Learning Objectives

  • Check whether a particular bit is set or clear.
  • Set a selected bit to 1.
  • Clear a selected bit to 0.
  • Toggle a selected bit.
  • Write reusable functions for bit operations.
  • Understand masks and bit positions.
  • Solve common placement coding questions.

2. Understanding Bit Positions

Bit positions are counted from right to left, starting at zero.

Binary:       1 0 1 1 0 1 0 1
Position:     7 6 5 4 3 2 1 0

Consider the unsigned integer 13:

Decimal: 13
Binary:  00001101

Its set bits are at positions 0, 2 and 3.

Remember: A set bit has value 1. A clear bit has value 0.

3. Operation 1: Check a Bit

Checking a bit means determining whether the selected bit is 1 or 0.

Formula

(number & (1U << position)) != 0U

Example: Check bit position 2 in 13

Number: 00001101
Mask:   00000100
AND:    00000100

The result is nonzero, so bit 2 is set.

Reusable C function

#include <stdio.h>
#include <limits.h>

int check_bit(unsigned int number, unsigned int position)
{
    unsigned int width =
        (unsigned int)(sizeof(number) * CHAR_BIT);

    if (position >= width)
        return -1;

    return (number & (1U << position)) != 0U;
}

int main(void)
{
    unsigned int number = 13U;
    unsigned int position = 2U;

    int result = check_bit(number, position);

    if (result == -1)
        printf("Invalid bit position\n");
    else if (result)
        printf("Bit %u is SET\n", position);
    else
        printf("Bit %u is CLEAR\n", position);

    return 0;
}
Expected output: 
Bit 2 is SET

4. Operation 2: Set a Bit

Setting a bit means changing the selected bit to 1, regardless of its original value.

Formula

number = number | (1U << position);

Example: Set bit position 1 in 8

Original: 00001000
Mask:     00000010
OR:       00001010

Result = 10.

Reusable C function

#include <stdio.h>
#include <limits.h>

int set_bit(unsigned int *number, unsigned int position)
{
    unsigned int width =
        (unsigned int)(sizeof(*number) * CHAR_BIT);

    if (number == NULL || position >= width)
        return 0;

    *number = *number | (1U << position);

    return 1;
}

int main(void)
{
    unsigned int number = 8U;

    if (set_bit(&number, 1U))
        printf("After setting bit = %u\n", number);
    else
        printf("Invalid input\n");

    return 0;
}
The example uses NULL, so include <stddef.h> in a standalone version of this program. The complete corrected version is shown below.

5. Operation 3: Clear a Bit

Clearing a bit means changing the selected bit to 0, regardless of its original value.

Formula

number = number & ~(1U << position);

Example: Clear bit position 2 in 13

Original: 00001101
Mask:     00000100
Inverted: 11111011

  00001101
& 11111011
----------
  00001001

Result = 9.

Reusable C function

#include <stdio.h>
#include <limits.h>

int clear_bit(unsigned int *number, unsigned int position)
{
    if (number == NULL)
        return 0;

    unsigned int width =
        (unsigned int)(sizeof(*number) * CHAR_BIT);

    if (position >= width)
        return 0;

    *number &= ~(1U << position);

    return 1;
}

int main(void)
{
    unsigned int number = 13U;

    if (clear_bit(&number, 2U))
        printf("After clearing bit = %u\n", number);
    else
        printf("Invalid input\n");

    return 0;
}
Expected output: 
After clearing bit = 9

For a standalone version, include <stddef.h> to use NULL, as in the next combined example.

6. Operation 4: Toggle a Bit

Toggling a bit means changing its value:

  • 0 becomes 1.
  • 1 becomes 0.

Formula

number = number ^ (1U << position);

Example: Toggle bit position 0 in 12

Original: 00001100
Mask:     00000001
XOR:      00001101

Result = 13.

Reusable C function

#include <stdio.h>
#include <stddef.h>
#include <limits.h>

int toggle_bit(unsigned int *number, unsigned int position)
{
    if (number == NULL)
        return 0;

    unsigned int width =
        (unsigned int)(sizeof(*number) * CHAR_BIT);

    if (position >= width)
        return 0;

    *number ^= (1U << position);

    return 1;
}

int main(void)
{
    unsigned int number = 12U;

    if (toggle_bit(&number, 0U))
        printf("After toggling bit = %u\n", number);
    else
        printf("Invalid input\n");

    return 0;
}
Expected output: 
After toggling bit = 13

Easy way to remember:
  • Check → AND
  • Set → OR
  • Clear → AND with inverted mask
  • Toggle → XOR

8. Complete Program: All Four Operations

This program combines the four operations into reusable functions. Each function validates the pointer and bit position before shifting.

#include <stdio.h>
#include <stddef.h>
#include <limits.h>

static int valid_position(unsigned int position)
{
    return position <
        (unsigned int)(sizeof(unsigned int) * CHAR_BIT);
}

int check_bit(unsigned int number, unsigned int position)
{
    if (!valid_position(position))
        return -1;

    return (number & (1U << position)) != 0U;
}

int set_bit(unsigned int *number, unsigned int position)
{
    if (number == NULL || !valid_position(position))
        return 0;

    *number |= (1U << position);
    return 1;
}

int clear_bit(unsigned int *number, unsigned int position)
{
    if (number == NULL || !valid_position(position))
        return 0;

    *number &= ~(1U << position);
    return 1;
}

int toggle_bit(unsigned int *number, unsigned int position)
{
    if (number == NULL || !valid_position(position))
        return 0;

    *number ^= (1U << position);
    return 1;
}

int main(void)
{
    unsigned int number = 10U;

    printf("Initial value = %u\n", number);

    printf("Check bit 1 = %d\n",
           check_bit(number, 1U));

    set_bit(&number, 0U);
    printf("After setting bit 0 = %u\n", number);

    clear_bit(&number, 3U);
    printf("After clearing bit 3 = %u\n", number);

    toggle_bit(&number, 2U);
    printf("After toggling bit 2 = %u\n", number);

    return 0;
}
Expected output: 
Initial value = 10
Check bit 1 = 1
After setting bit 0 = 11
After clearing bit 3 = 3
After toggling bit 2 = 7

Dry run

9. Important Placement Problem: Swap Two Numbers Using XOR

XOR can swap two distinct integer objects without a temporary variable, provided the operations are performed sequentially.

#include <stdio.h>

int main(void)
{
    unsigned int a = 10U;
    unsigned int b = 20U;

    if (&a != &b)
    {
        a = a ^ b;
        b = a ^ b;
        a = a ^ b;
    }

    printf("a = %u\n", a);
    printf("b = %u\n", b);

    return 0;
}
Expected output: 
a = 20
b = 10
Although this technique is a common interview question, a temporary variable is generally preferred in production code. It is clearer, easier to maintain and avoids problems when the two operands refer to the same object or have side effects.

10. Important Placement Problem: Count Set Bits

Count the number of 1 bits in an unsigned integer.

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= (number - 1U);
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int number = 29U;

    printf("Set bits = %u\n", count_set_bits(number));

    return 0;
}
Expected output: 
Set bits = 4

29 in binary = 11101. There are four set bits.

Time complexity: O(k), where k is the number of set bits.

11. Important Placement Problem: Reverse the Bits

Reverse the bits of an unsigned integer across the width of its type. The following program uses a 32-bit value and therefore requires uint32_t support.

#include <stdio.h>
#include <stdint.h>

uint32_t reverse_bits(uint32_t number)
{
    uint32_t result = 0U;

    for (unsigned int i = 0U; i < 32U; i++)
    {
        result = (result << 1) | (number & 1U);
        number >>= 1;
    }

    return result;
}

int main(void)
{
    uint32_t number = 13U;

    printf("Original = %u\n", (unsigned int)number);
    printf("Reversed = %u\n",
           (unsigned int)reverse_bits(number));

    return 0;
}
Expected output: 
Original = 13
Reversed = 2952790016

13 in 32-bit binary is:

00000000 00000000 00000000 00001101

After reversing all 32 bits:

10110000 00000000 00000000 00000000
This function reverses all 32 bits, including leading zeros in the original representation. It is not the same as reversing only the visible binary digits of a number.

13. Common Mistakes

  1. Using the wrong bit position because counting starts at 1 instead of 0.
  2. Using OR to clear a bit instead of AND with an inverted mask.
  3. Using XOR to set a bit when the bit might already be 1.
  4. Forgetting to validate the shift position.
  5. Passing a NULL pointer to a function that modifies a value.
  6. Assuming a toggle operation always sets a bit.
  7. Ignoring integer promotions for small integer types.
  8. Using signed integer values for operations requiring predictable unsigned bit behavior.

15. Placement Interview Questions and Answers

Q1. How do you check whether a bit is set?

Answer: Use AND with a mask for the required bit position and check whether the result is nonzero.

Q2. How do you set a bit?

Answer: Use OR with a mask containing 1 at the required position.

Q3. How do you clear a bit?

Answer: Use AND with the complement of the bit mask.

Q4. How do you toggle a bit?

Answer: Use XOR with the bit mask.

Q5. What is the difference between setting and toggling?

Answer: Setting always makes a bit 1. Toggling changes 0 to 1 and 1 to 0.

Q6. Which operator is used to clear a bit?

Answer: Bitwise AND combined with bitwise NOT.

Q7. Can XOR be used to swap two numbers?

Answer: Yes, for distinct integer objects using sequential XOR assignments. A temporary variable is generally clearer and preferred.

Q8. What is the complexity of checking one bit?

Answer: O(1).

Q9. What is the complexity of counting set bits using Brian Kernighan's algorithm?

Answer: O(k), where k is the number of set bits.

Q10. What happens when you XOR a bit with 1?

Answer: The bit is inverted.

Q11. What happens when you XOR a bit with 0?

Answer: The bit remains unchanged.

Q12. How do you set multiple bits at once?

Answer: OR the value with a mask containing 1s at all required positions.

Q13. How do you clear multiple bits at once?

Answer: AND the value with the complement of a mask containing 1s at the positions to clear.

Q14. Why should bit positions be validated?

Answer: Invalid shift counts cause undefined behavior in C.

Q15. Why are bitwise operations useful in programming?

Answer: They allow efficient inspection and manipulation of compact binary data, flags, masks and encoded values.

17. Multiple Choice Questions

1. Which operator is used to set a bit?

A. & B. | C. ^ D. ~

Answer: B. |

2. Which operator is used to toggle a bit?

A. & B. | C. ^ D. >>

Answer: C. ^

3. Which expression clears a selected bit?

A. n | mask
B. n & ~mask
C. n ^ mask
D. n << mask

Answer: B. n & ~mask

4. What does toggling a 0 bit produce?

A. 0 B. 1 C. 2 D. Undefined

Answer: B. 1

5. What does toggling a 1 bit produce?

A. 0 B. 1 C. 2 D. Undefined

Answer: A. 0

6. Which operation is used to check a bit?

A. AND B. OR C. XOR D. NOT

Answer: A. AND

7. What is the bit position of the LSB?

A. 1 B. 2 C. 0 D. 8

Answer: C. 0

8. What is the result of setting bit 1 in binary 1000?

A. 1000 B. 1010 C. 1100 D. 0000

Answer: B. 1010

9. Which operation is appropriate for clearing several selected bits?

A. OR with the mask
B. XOR with the mask
C. AND with the complemented mask
D. Left shift only

Answer: C

10. What is the time complexity of a single bit set operation on a fixed-width integer?

A. O(n) B. O(log n) C. O(1) D. O(n²)

Answer: C. O(1)
