2. Problem 1: Find the Unique Element

Problem: An array contains integers in which every element appears twice except one element. Find the element that appears only once.

Approach: XOR

  • a ^ a = 0
  • a ^ 0 = a
  • XOR is commutative and associative.

C Program

#include <stdio.h>

int find_unique(const int arr[], int size)
{
    int result = 0;

    for (int i = 0; i < size; i++)
        result ^= arr[i];

    return result;
}

int main(void)
{
    int arr[] = {4, 1, 2, 1, 2};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Unique element = %d\n",
           find_unique(arr, size));

    return 0;
}
Expected output: 
Unique element = 4

Dry Run

OperationResult
0 ^ 44
4 ^ 15
5 ^ 27
7 ^ 16
6 ^ 24

Time: O(n). Extra space: O(1).

This solution assumes exactly one element occurs once and every other value occurs exactly twice. It also works with negative int values because XOR operates on their integer representations.

3. Problem 2: Find Two Unique Elements

Problem: Every element appears twice except two elements. Find those two unique elements.

Approach

  1. XOR all array elements. The result is the XOR of the two unique values.
  2. Find one set bit in that XOR result.
  3. Partition the array into two groups based on that bit.
  4. XOR each group separately.

C Program

#include <stdio.h>
#include <limits.h>

int main(void)
{
    int arr[] = {2, 4, 7, 9, 2, 4};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    unsigned int combined = 0U;

    for (int i = 0; i < size; i++)
        combined ^= (unsigned int)arr[i];

    if (combined == 0U)
    {
        printf("Input does not contain two distinct unique values\n");
        return 0;
    }

    unsigned int mask = combined & (~combined + 1U);

    int first = 0;
    int second = 0;

    for (int i = 0; i < size; i++)
    {
        if (((unsigned int)arr[i] & mask) != 0U)
            first ^= arr[i];
        else
            second ^= arr[i];
    }

    printf("Unique elements = %d and %d\n", first, second);

    return 0;
}
Expected output: 
Unique elements = 7 and 9

Time: O(n). Extra space: O(1).

The input must contain exactly two distinct values occurring once, with all remaining values occurring twice.

4. Problem 3: Check Whether a Number Is a Power of Two

A positive integer is a power of two if its binary representation contains exactly one set bit.

Formula

n != 0U && (n & (n - 1U)) == 0U

C Program

#include <stdio.h>

int is_power_of_two(unsigned int number)
{
    return number != 0U &&
           (number & (number - 1U)) == 0U;
}

int main(void)
{
    unsigned int number = 16U;

    if (is_power_of_two(number))
        printf("%u is a power of 2\n", number);
    else
        printf("%u is not a power of 2\n", number);

    return 0;
}
Expected output: 
16 is a power of 2

Time: O(1). Extra space: O(1).

Dry Run

5. Problem 4: Check Whether a Number Is a Power of Four

A positive power of four has exactly one set bit, and that bit is at an even zero-based position.

C Program

#include <stdio.h>

int is_power_of_four(unsigned int number)
{
    unsigned int even_position_mask = 0x55555555U;

    return number != 0U &&
           (number & (number - 1U)) == 0U &&
           (number & even_position_mask) != 0U;
}

int main(void)
{
    unsigned int number = 64U;

    if (is_power_of_four(number))
        printf("%u is a power of 4\n", number);
    else
        printf("%u is not a power of 4\n", number);

    return 0;
}
Expected output: 
64 is a power of 4

Time: O(1). Extra space: O(1).

The mask 0x55555555 has 1s at even bit positions in a 32-bit representation. The condition is appropriate for the usual 32-bit unsigned integer environment used by this example.

6. Problem 5: Count the Number of Set Bits

Count the number of 1 bits in an unsigned integer.

Optimized Approach: Brian Kernighan's Algorithm

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= number - 1U;
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int number = 29U;

    printf("Number of set bits = %u\n",
           count_set_bits(number));

    return 0;
}
Expected output: 
Number of set bits = 4

29 = 11101 in binary. It contains four set bits.

Time: O(k), where k is the number of set bits. Space: O(1).

7. Problem 6: Find the Missing Number from 0 to N

Problem: An array contains distinct numbers from 0 to N, with one number missing. Find the missing number.

Approach: XOR

XOR all expected values from 0 to N and all array values. Equal values cancel each other.

C Program

#include <stdio.h>

int find_missing_number(const int arr[], int size)
{
    int result = size;

    for (int i = 0; i < size; i++)
    {
        result ^= i;
        result ^= arr[i];
    }

    return result;
}

int main(void)
{
    int arr[] = {3, 0, 1};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Missing number = %d\n",
           find_missing_number(arr, size));

    return 0;
}
Expected output: 
Missing number = 2

Time: O(n). Extra space: O(1).

The input must contain distinct values from 0 through size, with exactly one missing. The implementation uses int and assumes the input size and values fit in int.

8. Problem 7: Find the Number of Bits That Differ

Problem: Given two unsigned integers, count how many bit positions differ.

Approach

XOR produces 1 wherever corresponding bits are different. Count the set bits in the XOR result.

C Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= number - 1U;
        count++;
    }

    return count;
}

int hamming_distance(unsigned int a, unsigned int b)
{
    return (int)count_set_bits(a ^ b);
}

int main(void)
{
    unsigned int a = 10U;
    unsigned int b = 7U;

    printf("Different bit positions = %d\n",
           hamming_distance(a, b));

    return 0;
}
Expected output: 
Different bit positions = 3

10 = 1010 and 7 = 0111. Their XOR is 1101, which contains three set bits.

Time: O(k), where k is the number of set bits in the XOR result. Space: O(1).

9. Problem 8: Find the Rightmost Set Bit Position

Find the zero-based position of the lowest set bit.

C Program

#include <stdio.h>

int rightmost_set_bit_position(unsigned int number)
{
    if (number == 0U)
        return -1;

    int position = 0;

    while ((number & 1U) == 0U)
    {
        number >>= 1;
        position++;
    }

    return position;
}

int main(void)
{
    unsigned int number = 40U;

    printf("Rightmost set bit position = %d\n",
           rightmost_set_bit_position(number));

    return 0;
}
Expected output: 
Rightmost set bit position = 3

40 = 101000. The rightmost set bit is at position 3.

Time: O(w), where w is the integer width. Space: O(1).

10. Problem 9: Isolate the Rightmost Set Bit

Extract only the lowest set bit and make all other bits zero.

Formula

result = number & (~number + 1U);

C Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 40U;

    unsigned int result =
        number & (~number + 1U);

    printf("Original number = %u\n", number);
    printf("Isolated bit = %u\n", result);

    return 0;
}
Expected output: 
Original number = 40
Isolated bit = 8

Time: O(1). Extra space: O(1).

11. Problem 10: Check Whether a Number Is Even or Odd Using Bits

The least significant bit determines parity:

  • LSB = 0 means even.
  • LSB = 1 means odd.

C Program

#include <stdio.h>

int main(void)
{
    int number = 27;

    if (((unsigned int)number & 1U) == 0U)
        printf("Even number\n");
    else
        printf("Odd number\n");

    return 0;
}
Expected output: 
Odd number

Time: O(1). Extra space: O(1).

12. Problem 11: Update a Bit Field

A bit field is a group of consecutive bits used to store a value inside an integer.

For example, suppose bits 2 and 3 store a two-bit value. We want to replace those bits with the value 2 (binary 10).

C Program

#include <stdio.h>

int update_field(unsigned int *number,
                 unsigned int position,
                 unsigned int width,
                 unsigned int value)
{
    unsigned int total_bits =
        (unsigned int)(sizeof(*number) * 8U);

    if (number == NULL || width == 0U ||
        position >= total_bits ||
        width > total_bits - position)
        return 0;

    if (width < total_bits &&
        value >= (1U << width))
        return 0;

    unsigned int mask =
        (width == total_bits)
        ? ~0U
        : ((1U << width) - 1U);

    *number = (*number & ~(mask << position)) |
              ((value & mask) << position);

    return 1;
}

int main(void)
{
    unsigned int number = 0U;

    if (update_field(&number, 2U, 2U, 2U))
        printf("Updated value = %u\n", number);
    else
        printf("Invalid field parameters\n");

    return 0;
}
For strict portability, use CHAR_BIT from <limits.h> instead of assuming 8 bits per byte. The example above is intended for common 8-bit-byte systems; the corrected portable version follows. 
#include <stdio.h>
#include <stddef.h>
#include <limits.h>

int update_field(unsigned int *number,
                 unsigned int position,
                 unsigned int width,
                 unsigned int value)
{
    if (number == NULL)
        return 0;

    unsigned int total_bits =
        (unsigned int)(sizeof(*number) * CHAR_BIT);

    if (width == 0U ||
        position >= total_bits ||
        width > total_bits - position)
        return 0;

    unsigned int mask;

    if (width == total_bits)
        mask = ~0U;
    else
        mask = (1U << width) - 1U;

    if ((value & ~mask) != 0U)
        return 0;

    *number = (*number & ~(mask << position)) |
              ((value & mask) << position);

    return 1;
}

int main(void)
{
    unsigned int number = 0U;

    if (update_field(&number, 2U, 2U, 2U))
        printf("Updated value = %u\n", number);
    else
        printf("Invalid field parameters\n");

    return 0;
}
Expected output: 
Updated value = 8

Time: O(1). Extra space: O(1).

13. Problem 12: Implement a Simple Bit Flag System

Bit flags allow multiple independent Boolean states to be stored in a single integer.

Consider three flags:

  • Bit 0: POWER_ON
  • Bit 1: ERROR
  • Bit 2: READY

C Program

#include <stdio.h>

#define POWER_ON  (1U << 0)
#define ERROR     (1U << 1)
#define READY     (1U << 2)

int main(void)
{
    unsigned int status = 0U;

    status |= POWER_ON;
    status |= READY;

    printf("Power ON: %s\n",
           (status & POWER_ON) ? "YES" : "NO");

    printf("Error: %s\n",
           (status & ERROR) ? "YES" : "NO");

    printf("Ready: %s\n",
           (status & READY) ? "YES" : "NO");

    status &= ~READY;

    printf("Ready after clearing: %s\n",
           (status & READY) ? "YES" : "NO");

    return 0;
}
Expected output: 
Power ON: YES
Error: NO
Ready: YES
Ready after clearing: NO
Bit flags are widely used in configuration registers, permissions, status fields, protocol options and embedded software.

15. Common Interview Mistakes

  1. Forgetting that bit positions start from zero.
  2. Using XOR when the requirement is to set a bit unconditionally.
  3. Forgetting to exclude zero when checking a power of two.
  4. Using signed values where unsigned bitwise operations are more appropriate.
  5. Performing a shift by a negative count or a count greater than or equal to the promoted operand width.
  6. Assuming every XOR array problem has the same input conditions.
  7. Using a fixed-width mask without checking the integer width.
  8. Ignoring edge cases such as zero and one.

16. Placement Interview Questions and Answers

Q1. Why does XOR help find a unique element?

Answer: Duplicate values cancel because a ^ a = 0, leaving the value that occurs once.

Q2. How can you check whether a number is a power of two?

Answer: Check that the number is nonzero and that n & (n - 1) equals zero.

Q3. What is Brian Kernighan's algorithm?

Answer: It counts set bits by repeatedly clearing the lowest set bit using n & (n - 1).

Q4. How do you find two unique elements when all other elements occur twice?

Answer: XOR all values, isolate a set bit in the combined XOR, partition the elements into two groups and XOR each group.

Q5. How do you count differing bit positions?

Answer: XOR the two numbers and count the set bits in the result. This is called Hamming distance.

Q6. What is the lowest set bit?

Answer: It is the rightmost bit whose value is 1.

Q7. How do you isolate the lowest set bit?

Answer: For an unsigned integer n, use n & (~n + 1U).

Q8. Why must zero be excluded from the power-of-two check?

Answer: Zero is not a positive power of two, but n & (n - 1) evaluates to zero for n = 0 as well.

Q9. What is a bit mask?

Answer: A bit mask is a value used to select, inspect or modify particular bits.

Q10. Where are bit flags useful?

Answer: They are useful for compactly storing independent status values, configuration options and permissions.

Q11. What is the difference between bitwise and logical AND?

Answer: Bitwise AND operates on individual bits. Logical AND evaluates truth values and produces 0 or 1.

Q12. What is the complexity of XOR-based unique-element search?

Answer: O(n) time and O(1) auxiliary space.

Q13. What is Hamming distance?

Answer: It is the number of bit positions at which two equal-width binary representations differ.

Q14. Can bitwise operations be used to store multiple Boolean flags?

Answer: Yes. Each flag can be represented by a separate bit in an unsigned integer.

Q15. Does volatile make a bitwise read-modify-write operation atomic?

Answer: No. volatile does not guarantee atomicity or thread safety. Appropriate atomic operations or synchronization are required when concurrent access is involved.

18. Additional Advanced Problem: Unique Element When Others Occur Three Times

Problem: Every element in an array occurs three times except one element. Find the unique element.

Approach: Count Each Bit

Count the number of set bits at every bit position. The count modulo 3 gives the corresponding bit of the unique value.

C Program

#include <stdio.h>
#include <limits.h>

int find_unique_thrice(const int arr[], int size)
{
    unsigned int result = 0U;
    unsigned int width =
        (unsigned int)(sizeof(unsigned int) * CHAR_BIT);

    for (unsigned int bit = 0U; bit < width; bit++)
    {
        unsigned int count = 0U;
        unsigned int mask = 1U << bit;

        for (int i = 0; i < size; i++)
        {
            if (((unsigned int)arr[i] & mask) != 0U)
                count++;
        }

        if (count % 3U != 0U)
            result |= mask;
    }

    return (int)result;
}

int main(void)
{
    int arr[] = {6, 6, 6, 11, 4, 4, 4};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Unique element = %d\n",
           find_unique_thrice(arr, size));

    return 0;
}
Expected output: 
Unique element = 11
This implementation assumes the unique value and all array values are representable as int, and that every other value occurs exactly three times. It reconstructs the unsigned representation and converts it back to int; for a strictly portable solution across all possible C11 signed representations, use a separately specified representation or a suitable unsigned result type.

Time: O(n × w), where w is the number of bits in unsigned int. Extra space: O(1).
