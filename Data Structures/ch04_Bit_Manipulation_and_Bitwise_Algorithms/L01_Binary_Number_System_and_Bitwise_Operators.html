Lesson 1: Binary Number System and Bitwise Operators

Understand binary representation, number systems, integer storage and the fundamentals of bitwise operations using C.

2. What Is a Bit?

A bit (binary digit) is the smallest unit of digital information. It can have only two possible values:

  • 0 – OFF or LOW
  • 1 – ON or HIGH

Computers represent and process information using combinations of binary digits.

Important terminology
  • Bit: One binary digit.
  • Nibble: Four bits.
  • Byte: Eight bits on systems where a byte is defined as 8 bits; in C, the number of bits in a byte is CHAR_BIT.
  • Word: A processor's natural data-processing unit. Its size depends on the architecture.

Example of an 8-bit sequence:

1 0 1 1 0 0 1 0

This sequence contains eight binary digits.

3.1 Decimal Number System

The decimal system uses ten digits, from 0 to 9. Each position represents a power of 10.

Example:

572 = (5 × 100) + (7 × 10) + (2 × 1)

= 500 + 70 + 2 = 572

3.2 Binary Number System

The binary system uses only 0 and 1. Each position represents a power of 2.

3.3 Octal Number System

Octal uses digits from 0 to 7. Each position represents a power of 8.

Example: 17₈ = (1 × 8) + (7 × 1) = 15₁₀.

4. Decimal to Binary Conversion

To convert a positive decimal integer into binary, repeatedly divide it by 2 and record the remainder. Read the remainders from bottom to top.

Example: Convert 13 into binary

DivisionQuotientRemainder
13 ÷ 261
6 ÷ 230
3 ÷ 211
1 ÷ 201

Read remainders from bottom to top:

13₁₀ = 1101₂

Another example: Convert 25 into binary

25 ÷ 2 = 12 remainder 1

12 ÷ 2 = 6 remainder 0

6 ÷ 2 = 3 remainder 0

3 ÷ 2 = 1 remainder 1

1 ÷ 2 = 0 remainder 1

Therefore, 25₁₀ = 11001₂.

5. Binary to Decimal Conversion

Multiply each binary digit by its corresponding power of 2 and add the results.

Example: Convert 11010₂ into decimal

11010₂ = (1 × 16) + (1 × 8) + (0 × 4) + (1 × 2) + (0 × 1)

= 16 + 8 + 0 + 2 + 0

= 26₁₀

Placement tip: Be comfortable converting between decimal, binary and hexadecimal. These conversions frequently appear in C, computer organization, operating systems and embedded programming interviews.

7. Bit Positions: LSB and MSB

In a binary number, bit positions are counted from right to left, starting at zero.

Binary number:  1  0  1  1  0  1  0  1
Bit position:   7  6  5  4  3  2  1  0
  • LSB (Least Significant Bit): The rightmost bit, position 0.
  • MSB (Most Significant Bit): The leftmost bit in the represented bit width.

For the 8-bit value 10110101:

  • MSB = 1
  • LSB = 1
The MSB is not automatically a sign bit in every context. In an unsigned integer, it contributes to the value. In a signed representation, its interpretation depends on the signed integer representation.

8.1 Fixed-width integer types

The header <stdint.h> provides optional exact-width types when the implementation supports them.

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t a = 255;
    uint16_t b = 1000;
    uint32_t c = 100000;

    printf("a = %u\n", (unsigned int)a);
    printf("b = %u\n", (unsigned int)b);
    printf("c = %u\n", (unsigned int)c);

    printf("uint8_t size  = %zu byte(s)\n", sizeof(a));
    printf("uint16_t size = %zu byte(s)\n", sizeof(b));
    printf("uint32_t size = %zu byte(s)\n", sizeof(c));

    return 0;
}
Expected output:

b = 1000

uint16_t size = 2 byte(s)

Important: Exact-width types such as uint8_t and uint32_t are optional in C. They are available only when the implementation supports the corresponding exact-width integer type.

9. Unsigned and Signed Integers

9.1 Unsigned integers

An unsigned integer represents zero and positive values. For an unsigned integer with N value bits, the range is:

0 to 2N − 1

For example, an 8-bit unsigned integer can represent:

0 to 255.

9.2 Signed integers

Signed integer types represent both negative and positive values.

Modern C implementations use two's complement for signed integer representation, as required by C23. When working with C11 code, do not assume every implementation has the same signed representation unless your platform specifies it.

9.3 Two's complement example

For an 8-bit two's complement representation:

+5 = 00000101

To represent -5:

  1. Start with +5: 00000101.
  2. Invert the bits: 11111010.
  3. Add 1: 11111011.

Therefore, -5 is represented as 11111011 in an 8-bit two's complement system.

This is a conceptual representation example. Do not use signed overflow or out-of-range signed conversions to manipulate bit patterns in portable C code.

10.1 Logical operators versus bitwise operators

Logical operatorsBitwise operators
&& – Logical AND& – Bitwise AND
|| – Logical OR| – Bitwise OR
! – Logical NOT~ – Bitwise NOT

Logical operators evaluate conditions and produce either 0 or 1. Bitwise operators perform operations on individual bits.

Program 2: Logical and bitwise AND

#include <stdio.h>

int main(void)
{
    unsigned int a = 6;
    unsigned int b = 3;

    printf("Logical AND result = %d\n", (a && b));
    printf("Bitwise AND result = %u\n", (a & b));

    return 0;
}
Expected output: 
Logical AND result = 1
Bitwise AND result = 2

Explanation:

6 in binary = 0110

3 in binary = 0011

Bitwise AND:

  0110
& 0011
------
  0010

0010₂ = 2₁₀.

For logical AND, both operands are nonzero, so the result is 1.

12. Program 3: Display Binary Representation of an Unsigned Integer

C does not provide a standard printf conversion specifier for displaying an integer directly in binary. We can write a function to display its bits.

#include <stdio.h>
#include <limits.h>

void display_binary(unsigned int value)
{
    unsigned int bit_count =
        (unsigned int)(sizeof(value) * CHAR_BIT);

    for (unsigned int i = bit_count; i > 0; i--)
    {
        unsigned int bit = (value >> (i - 1)) & 1U;
        printf("%u", bit);

        if ((i - 1) % 4 == 0 && i != 1)
        {
            printf(" ");
        }
    }

    printf("\n");
}

int main(void)
{
    unsigned int number = 13;

    printf("Decimal value = %u\n", number);
    printf("Binary value  = ");
    display_binary(number);

    return 0;
}
Expected output on a system with 32-bit unsigned int: 
Decimal value = 13
Binary value  = 0000 0000 0000 0000 0000 0000 0000 1101

Dry run

For number = 13:

Binary representation in the lowest four bits = 1101.

  • 13 >> 3 gives 1; lowest bit is 1.
  • 13 >> 2 gives 3; lowest bit is 1.
  • 13 >> 1 gives 6; lowest bit is 0.
  • 13 >> 0 gives 13; lowest bit is 1.

Reading from the highest position to the lowest gives 1101.

The program uses unsigned integers for bit operations. Its displayed width depends on the size of unsigned int on the target implementation.

13. Common Placement Mistakes

  1. Confusing logical and bitwise AND: && evaluates conditions; & operates on bits.
  2. Assuming int is always 4 bytes: Check the implementation using sizeof(int).
  3. Assuming every byte is 8 bits: C defines the number of bits in a byte through CHAR_BIT.
  4. Using signed values carelessly: Prefer unsigned integer types for bit manipulation.
  5. Ignoring integer promotions: Types such as uint8_t may be promoted to int during expressions.
  6. Ignoring shift restrictions: A negative shift count or a shift count greater than or equal to the width of the promoted left operand causes undefined behavior.
  7. Assuming right shift of negative signed integers is portable: Its behavior is implementation-defined in C11.
  8. Assuming multiplication and shifting are always interchangeable: Signed overflow and type conversions can make them behave differently.
For portable C bit manipulation, use unsigned operands, keep shift counts within the valid range, and understand the width of the type being shifted.

15. Placement Interview Questions and Answers

Q1. What is a bit?

Answer: A bit is the smallest unit of binary information and can hold either 0 or 1.

Q2. What is the difference between a bit and a byte?

Answer: A bit is one binary digit. A byte consists of CHAR_BIT bits; on common systems, CHAR_BIT is 8.

Q3. What is the difference between binary and hexadecimal?

Answer: Binary uses base 2 and digits 0 and 1. Hexadecimal uses base 16 and digits 0–9 and A–F.

Q4. What is an LSB?

Answer: The least significant bit is the rightmost bit, at position zero.

Q5. What is an MSB?

Answer: The most significant bit is the leftmost bit within the selected representation width.

Q6. What is the difference between signed and unsigned integers?

Answer: Unsigned integer types represent non-negative values. Signed integer types represent negative and non-negative values.

Q7. What does the bitwise AND operator do?

Answer: It performs AND on each pair of corresponding bits. A result bit is 1 only when both input bits are 1.

Q8. What is the difference between & and &&?

Answer: & performs bitwise AND, while && performs logical AND and short-circuits when its first operand is false.

Q9. Does C have a binary format specifier for printf?

Answer: Standard C11 does not define a binary conversion specifier for printf. A custom function can print the bits.

Q10. Why are unsigned integers commonly used for bit manipulation?

Answer: Unsigned arithmetic has well-defined modulo behavior, and unsigned shifts avoid several problems associated with signed negative values.

Q11. What is two's complement?

Answer: It is a signed integer representation in which a negative value is formed by inverting the bits of the positive magnitude and adding one, for a fixed-width representation.

Q12. What is CHAR_BIT?

Answer: It is a macro from <limits.h> that specifies the number of bits in a C byte.

Q13. What is the purpose of stdint.h?

Answer: It provides integer types with specified width when supported, such as uint8_t and uint32_t.

Q14. What happens if the shift count is invalid?

Answer: A negative shift count or a count greater than or equal to the width of the promoted left operand causes undefined behavior.

Q15. Why is hexadecimal frequently used in low-level programming?

Answer: It provides a compact representation of binary values, making bit patterns easier to read and debug.

18. Lesson Summary

  • Binary uses two digits: 0 and 1.
  • Decimal uses base 10, octal base 8 and hexadecimal base 16.
  • One hexadecimal digit represents four binary bits.
  • Bit positions start at zero from the right.
  • LSB is the rightmost bit; MSB is the leftmost bit within the selected width.
  • C integer sizes depend on the implementation.
  • CHAR_BIT specifies the number of bits in a byte.
  • Logical operators and bitwise operators have different purposes.
  • Unsigned integer types are useful for portable bit manipulation.
