Chapter 4: Bit Manipulation and Bitwise Algorithms

Lesson 3: Bit Shifting and Bit Masking

Learn how to shift bits, construct masks, extract bit fields and solve common placement coding problems using C.

1. Learning Objectives

  • Understand left shift and right shift operators.
  • Predict the result of shifting unsigned integers.
  • Understand how bit masks work.
  • Extract and isolate selected bits.
  • Use masks to inspect, clear and modify selected bit fields.
  • Write placement-oriented C programs using bit manipulation.

2. What Is Bit Shifting?

Bit shifting moves the bit positions of an integer to the left or right.

C provides two shift operators:

OperatorNamePurpose
<<Left shiftMoves bits toward higher positions.
>>Right shiftMoves bits toward lower positions.

For the examples in this lesson, use unsigned integer operands. This avoids the implementation-defined behavior associated with right-shifting negative signed values.

3. Left Shift Operator (<<)

The left shift operator moves the bits toward the left by the specified number of positions. Vacated lower positions are filled with zero bits.

Example: 5 << 1

Original: 00000101
Shift 1:  00001010

00001010₂ = 10₁₀.

Therefore, 5 << 1 = 10.

Example: 5 << 2

Original: 00000101
Shift 1:  00001010
Shift 2:  00010100

00010100₂ = 20₁₀.

Therefore, 5 << 2 = 20.

Program 1: Left shift

#include <stdio.h>

int main(void)
{
    unsigned int number = 5;

    printf("Original value = %u\n", number);
    printf("Left shift by 1 = %u\n", number << 1);
    printf("Left shift by 2 = %u\n", number << 2);
    printf("Left shift by 3 = %u\n", number << 3);

    return 0;
}
Expected output: 
Original value = 5
Left shift by 1 = 10
Left shift by 2 = 20
Left shift by 3 = 40

Mathematical relationship

For unsigned values, a left shift by k positions corresponds to multiplication by 2k modulo 2w, where w is the width of the unsigned type.

Do not assume that left shifting always gives the same result as ordinary multiplication. Bits shifted beyond the width are discarded. Always check the width and shift count.

4. Right Shift Operator (>>)

The right shift operator moves bits toward the right. For unsigned integer operands, vacated higher positions are filled with zero bits.

Example: 20 >> 1

Original: 00010100
Shift 1:  00001010

00001010₂ = 10₁₀.

Example: 20 >> 2

Original: 00010100
Shift 1:  00001010
Shift 2:  00000101

00000101₂ = 5₁₀.

Program 2: Right shift

#include <stdio.h>

int main(void)
{
    unsigned int number = 20;

    printf("Original value = %u\n", number);
    printf("Right shift by 1 = %u\n", number >> 1);
    printf("Right shift by 2 = %u\n", number >> 2);
    printf("Right shift by 3 = %u\n", number >> 3);

    return 0;
}
Expected output: 
Original value = 20
Right shift by 1 = 10
Right shift by 2 = 5
Right shift by 3 = 2

Mathematical relationship

For an unsigned integer, right shifting by k positions is equivalent to integer division by 2k, with the fractional part discarded.

5. Difference Between Left Shift and Right Shift

Left shift (<<)Right shift (>>)
Moves bits toward higher positions.Moves bits toward lower positions.
Vacated lower positions become zero.For unsigned operands, vacated higher positions become zero.
Can discard bits beyond the type width.Discards bits shifted out on the right.
Often used to construct masks.Often used to inspect or extract bits.

6. What Is a Bit Mask?

A bit mask is a binary pattern used with bitwise operators to select, inspect or modify specific bits.

Consider an 8-bit value:

Data:  10110110
Mask:  00001111

Applying AND:

  10110110
& 00001111
----------
  00000110

The mask selects the lowest four bits. The extracted result is 6.

A mask can be created using a hexadecimal constant or by shifting an unsigned value. For example, 0x0FU represents the lowest four bits set to 1.

7. Creating a Bit Mask

To create a mask with one bit set at position p:

mask = 1U << p;

Example: Create a mask for bit position 3.

1 = 00000001
1U << 3
  = 00001000

Program 3: Create and display a bit mask

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int position = 3U;
    unsigned int mask = 1U << position;

    printf("Mask value = %u\n", mask);
    printf("Mask in hexadecimal = 0x%X\n", mask);

    return 0;
}
Expected output: 
Mask value = 8
Mask in hexadecimal = 0x8

Here, bit position 3 is set and all other bits are zero.

8. Extracting Specific Bits

To check whether a particular bit is set, create a mask and perform bitwise AND.

if ((number & (1U << position)) != 0U)
{
    printf("Bit is set\n");
}
else
{
    printf("Bit is clear\n");
}

Example

Let number = 10, whose binary representation is 1010.

Check bit position 3:

Number: 1010
Mask:   1000
AND:    1000

The result is nonzero, so bit 3 is set.

Program 4: Check a bit at a given position

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int number = 10U;
    unsigned int position = 3U;

    if (position >= sizeof(number) * CHAR_BIT)
    {
        printf("Invalid bit position\n");
        return 1;
    }

    unsigned int mask = 1U << position;

    if ((number & mask) != 0U)
        printf("Bit %u is SET\n", position);
    else
        printf("Bit %u is CLEAR\n", position);

    return 0;
}
Expected output: 
Bit 3 is SET

9. Extracting Multiple Bits

Suppose we want to extract the lowest four bits of an unsigned integer.

Use the mask 0x0F.

Number: 10110110
Mask:   00001111
AND:    00000110

Program 5: Extract the lowest four bits

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t number = 182U;
    uint8_t mask = 0x0FU;

    uint8_t result = (uint8_t)(number & mask);

    printf("Original value = %u\n", (unsigned int)number);
    printf("Extracted value = %u\n", (unsigned int)result);

    return 0;
}
Expected output: 
Original value = 182
Extracted value = 6

10. Extracting a Bit Field

A bit field is a group of consecutive bits within an integer.

To extract a field of width w beginning at position p:

field = (value >> p) & mask;

For example, extract four bits beginning at position 4.

Value:  10110110
Shift:  00001011
Mask:   00001111
Result: 00001011

The extracted field is 11.

Program 6: Extract a four-bit field

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t value = 182U;

    unsigned int position = 4U;
    unsigned int width = 4U;

    unsigned int mask = (1U << width) - 1U;

    unsigned int field =
        ((unsigned int)value >> position) & mask;

    printf("Original value = %u\n", (unsigned int)value);
    printf("Extracted field = %u\n", field);

    return 0;
}
Expected output: 
Original value = 182
Extracted field = 11
This simple mask construction is suitable here because width is 4 and the unsigned int type is wide enough. A reusable extraction function must separately handle width equal to the type width, validate the starting position and prevent invalid shifts.

11. Practical C Program: Display Every Bit

This program displays the bits of an unsigned integer from most significant to least significant.

#include <stdio.h>
#include <limits.h>

void display_bits(unsigned int value)
{
    unsigned int width =
        (unsigned int)(sizeof(value) * CHAR_BIT);

    for (unsigned int i = width; i > 0U; i--)
    {
        unsigned int bit =
            (value >> (i - 1U)) & 1U;

        printf("%u", bit);

        if ((i - 1U) % 4U == 0U && i != 1U)
            printf(" ");
    }

    printf("\n");
}

int main(void)
{
    unsigned int number = 25U;

    printf("Number = %u\n", number);
    printf("Binary = ");
    display_bits(number);

    return 0;
}
Expected output on a 32-bit unsigned int system: 
Number = 25
Binary = 0000 0000 0000 0000 0000 0000 0001 1001

12. Common Placement Problems

Problem 1: Check whether a number is a power of two

A positive integer is a power of two if it contains exactly one set bit.

Use:

n != 0U && (n & (n - 1U)) == 0U

Program:

#include <stdio.h>

int main(void)
{
    unsigned int n = 16U;

    if (n != 0U && (n & (n - 1U)) == 0U)
        printf("Power of two\n");
    else
        printf("Not a power of two\n");

    return 0;
}
Expected output: 
Power of two

Time complexity: O(1).

Problem 2: Count set bits using Brian Kernighan's algorithm

Repeatedly clear the lowest set bit using:

n = n & (n - 1U);

Each iteration removes one set bit.

#include <stdio.h>

unsigned int count_set_bits(unsigned int n)
{
    unsigned int count = 0U;

    while (n != 0U)
    {
        n = n & (n - 1U);
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int number = 13U;

    printf("Set bits = %u\n", count_set_bits(number));

    return 0;
}
Expected output: 
Set bits = 3

13 in binary = 1101. It contains three set bits.

Time complexity: O(k), where k is the number of set bits.

Extra space: O(1).

Problem 3: Clear the lowest set bit

Use:

n = n & (n - 1U);

For n = 12:

n     = 1100
n - 1 = 1011
AND   = 1000

Result = 8.

Problem 4: Check whether two unsigned integers differ in exactly one bit

Take XOR and check whether the XOR result contains exactly one set bit.

#include <stdio.h>

int differ_by_one_bit(unsigned int a, unsigned int b)
{
    unsigned int x = a ^ b;

    return x != 0U && (x & (x - 1U)) == 0U;
}

int main(void)
{
    unsigned int a = 10U;
    unsigned int b = 11U;

    if (differ_by_one_bit(a, b))
        printf("Exactly one bit differs\n");
    else
        printf("More than one bit differs or values are equal\n");

    return 0;
}
Expected output: 
Exactly one bit differs

14. Common Mistakes

  1. Using a negative shift count.
  2. Shifting by a count greater than or equal to the width of the promoted left operand.
  3. Assuming left shift always means ordinary multiplication without overflow concerns.
  4. Using signed negative integers for right shifting.
  5. Creating masks without checking the width of the integer type.
  6. Forgetting that bit positions start at zero.
  7. Using 1 << position when an unsigned mask is more appropriate.
  8. Using an expression such as (1U << width) - 1U when width equals the width of unsigned int.
  9. Forgetting integer promotions when operating on small integer types.
Portable C rule: The shift count must be non-negative and smaller than the width of the promoted left operand. Use unsigned operands and validate the position before shifting.

15. Placement Interview Questions and Answers

Q1. What is a left shift?

Answer: It moves bits toward higher positions and fills vacated lower positions with zero.

Q2. What is a right shift?

Answer: It moves bits toward lower positions. For unsigned values, vacated higher positions are filled with zero.

Q3. What is a bit mask?

Answer: A bit mask is a binary pattern used to select, inspect or modify particular bits.

Q4. How do you create a mask for bit position 4?

Answer: Use 1U << 4, provided the shift count is valid for the type.

Q5. How do you check whether a bit is set?

Answer: AND the number with a mask for that bit and check whether the result is nonzero.

Q6. How do you extract the lowest four bits?

Answer: Use number & 0x0FU.

Q7. What is the purpose of n & (n - 1)?

Answer: For an unsigned integer n greater than zero, it clears the lowest set bit.

Q8. How can you check whether a number is a power of two?

Answer: Check that n is nonzero and (n & (n - 1U)) == 0U.

Q9. What is Brian Kernighan's algorithm?

Answer: It counts set bits by repeatedly clearing the lowest set bit. It runs in O(k), where k is the number of set bits.

Q10. What happens when an unsigned integer is right-shifted?

Answer: Bits move toward lower positions and zero bits enter from the left.

Q11. Why is 1U used instead of 1 when creating a bit mask?

Answer: The U suffix makes the constant unsigned, which is useful for predictable unsigned bit operations.

Q12. What is a bit field?

Answer: It is a group of consecutive bits extracted from or stored within an integer value.

Q13. What is the complexity of counting set bits using Brian Kernighan's algorithm?

Answer: O(k), where k is the number of set bits. The extra space is O(1).

Q14. What is the danger of shifting by the type width?

Answer: A shift count equal to or greater than the width of the promoted left operand causes undefined behavior.

Q15. What is the difference between a bit position and a bit width?

Answer: A bit position identifies one bit, starting from zero. Bit width is the total number of bits in the representation.

18. Lesson Summary

  • Left shift moves bits toward higher positions.
  • Right shift of unsigned integers moves bits toward lower positions and fills with zeros.
  • Bit masks select particular bits.
  • AND is useful for inspecting or extracting bits.
  • Shift operations can create masks efficiently.
  • n & (n - 1U) clears the lowest set bit.
  • Brian Kernighan's algorithm counts set bits efficiently.
  • Always validate shift counts and use unsigned operands for bit manipulation.
