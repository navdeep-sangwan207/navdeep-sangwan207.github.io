3. A Reliable Coding-Round Strategy

  1. Read carefully: Identify the input, output, constraints and required behavior.
  2. Clarify assumptions: Ask whether duplicates, negative numbers, empty input or special cases are possible.
  3. Work through an example: Trace a small input manually.
  4. Start with a correct approach: Describe a brute-force solution if useful.
  5. Optimize: Consider hashing, sorting, two pointers, binary search, heaps or dynamic programming.
  6. Write modular code: Use meaningful function names and clear variable names.
  7. Test: Check normal, boundary and invalid inputs.
  8. Analyze complexity: State time and auxiliary-space complexity.
  9. Review: Check indexing, memory allocation, overflow and cleanup.
Interview communication: Explain your plan before writing code. Continue communicating important decisions while coding. Do not wait until the end to explain the algorithm.

5. Mock Coding Problem 1 – Two Sum

Problem: Given an integer array and a target, determine whether two distinct elements add up to the target.

Example:

Input: arr = {2, 7, 11, 15}, target = 9 Output: Yes Explanation: 2 + 7 = 9

Approach

Use a hash table to store previously visited values. For each element x, search for target - x before inserting x. This prevents using the same array element twice.

Complete C11 Implementation – Simple Hash Set

This implementation uses a fixed-size hash table with linear probing. It supports integer keys and reports capacity or allocation constraints through the fixed table design.

#include <stdio.h> #include <limits.h> #define TABLE_SIZE 10007 typedef struct { int key; int used; } Entry; static Entry table[TABLE_SIZE]; static unsigned int hashInt(int value) { return (unsigned int)value % TABLE_SIZE; } static int contains(int key) { unsigned int index = hashInt(key); for (int i = 0; i < TABLE_SIZE; i++) { unsigned int position = (index + i) % TABLE_SIZE; if (!table[position].used) return 0; if (table[position].key == key) return 1; } return 0; } static int insert(int key) { unsigned int index = hashInt(key); for (int i = 0; i < TABLE_SIZE; i++) { unsigned int position = (index + i) % TABLE_SIZE; if (!table[position].used) { table[position].key = key; table[position].used = 1; return 1; } if (table[position].key == key) return 1; } return 0; } int twoSumExists(const int arr[], int n, int target) { for (int i = 0; i < n; i++) { long long complement = (long long)target - arr[i]; if (complement >= INT_MIN && complement <= INT_MAX) { if (contains((int)complement)) return 1; } if (!insert(arr[i])) return -1; } return 0; } int main(void) { int arr[] = {2, 7, 11, 15}; int n = sizeof(arr) / sizeof(arr[0]); int target = 9; int result = twoSumExists(arr, n, target); if (result == 1) printf("Pair exists\n"); else if (result == 0) printf("Pair does not exist\n"); else printf("Hash table capacity exceeded\n"); return 0; }
Pair exists

Expected complexity: Average O(n) time under a suitable load factor; worst-case O(n²) with linear probing. Auxiliary space is O(TABLE_SIZE).

This demonstration uses a static table and does not support deletion. The table must be cleared before running another independent test. A production implementation should manage capacity and load factor explicitly.

6. Mock Coding Problem 2 – Maximum Subarray Sum

Problem: Find the maximum sum of a non-empty contiguous subarray.

Input: {-2, 1, -3, 4, -1, 2, 1, -5, 4} Output: 6 Subarray: {4, -1, 2, 1}

Approach – Kadane's Algorithm

At every position, either extend the previous subarray or start a new subarray at the current element.

#include <stdio.h> int maximumSubarraySum(const int arr[], int n) { int current = arr[0]; int best = arr[0]; for (int i = 1; i < n; i++) { if (current + arr[i] < arr[i]) current = arr[i]; else current += arr[i]; if (current > best) best = current; } return best; } int main(void) { int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4}; int n = sizeof(arr) / sizeof(arr[0]); printf("Maximum subarray sum = %d\n", maximumSubarraySum(arr, n)); return 0; }
Maximum subarray sum = 6

Time: O(n). Auxiliary space: O(1).

This sample assumes n > 0 and that intermediate sums fit in int. For production-quality code, validate the length and use a sufficiently wide checked sum type.

7. Mock Coding Problem 3 – Reverse a Linked List

Problem: Reverse a singly linked list in place.

Complete C11 Implementation

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; Node *createNode(int value) { Node *node = malloc(sizeof(*node)); if (node == NULL) return NULL; node->data = value; node->next = NULL; return node; } Node *reverseList(Node *head) { Node *previous = NULL; Node *current = head; while (current != NULL) { Node *nextNode = current->next; current->next = previous; previous = current; current = nextNode; } return previous; } void displayList(const Node *head) { while (head != NULL) { printf("%d ", head->data); head = head->next; } printf("\n"); } void freeList(Node *head) { while (head != NULL) { Node *nextNode = head->next; free(head); head = nextNode; } } int main(void) { int values[] = {10, 20, 30, 40}; int n = sizeof(values) / sizeof(values[0]); Node *head = NULL; Node **tail = &head; for (int i = 0; i < n; i++) { Node *node = createNode(values[i]); if (node == NULL) { freeList(head); printf("Memory allocation failed\n"); return 1; } *tail = node; tail = &node->next; } printf("Original: "); displayList(head); head = reverseList(head); printf("Reversed: "); displayList(head); freeList(head); return 0; }
Original: 10 20 30 40 Reversed: 40 30 20 10

Time: O(n). Auxiliary space: O(1).

8. Mock Coding Problem 4 – Balanced Parentheses

Problem: Check whether brackets in an expression are balanced. The input contains only bracket characters.

#include <stdio.h> #include <string.h> #define MAX 1000 int isMatching(char open, char close) { return (open == '(' && close == ')') || (open == '[' && close == ']') || (open == '{' && close == '}'); } int isBalanced(const char expression[]) { char stack[MAX]; int top = -1; for (int i = 0; expression[i] != '\0'; i++) { char ch = expression[i]; if (ch == '(' || ch == '[' || ch == '{') { if (top == MAX - 1) return 0; stack[++top] = ch; } else if (ch == ')' || ch == ']' || ch == '}') { if (top == -1) return 0; if (!isMatching(stack[top], ch)) return 0; top--; } else { return 0; } } return top == -1; } int main(void) { char expression[] = "{[()]}"; printf("%s\n", isBalanced(expression) ? "Balanced" : "Not balanced"); return 0; }
Balanced

Time: O(n). Auxiliary space: O(n).

9. How to Explain Complexity in an Interview

ComplexityExampleExplanation
O(1)Array access by indexConstant number of operations.
O(log n)Binary searchSearch space is repeatedly halved.
O(n)Linear traversalEach element is processed once.
O(n log n)Merge sortLogarithmic levels with linear work per level.
O(n²)Nested pair comparisonTwo nested loops over the input.
O(2ⁿ)Generating all subsetsEach element has two include/exclude choices.

Distinguish auxiliary space from total space. For example, an algorithm may use O(1) auxiliary space while receiving an input array of size O(n).

11. Debugging Checklist

  • Check array indexes and loop boundaries.
  • Check NULL before dereferencing pointers.
  • Check malloc() results.
  • Free dynamically allocated memory exactly once.
  • Check for integer overflow.
  • Initialize variables before reading them.
  • Check empty and single-element inputs.
  • Check duplicate values and negative values.
  • Check recursion base cases and termination.
  • Compile with warnings enabled.

Useful GCC Command

gcc -std=c11 -Wall -Wextra -Wpedantic -g program.c -o program

For runtime memory and undefined-behavior checks where supported:

gcc -std=c11 -Wall -Wextra -g \ -fsanitize=address,undefined program.c -o program
