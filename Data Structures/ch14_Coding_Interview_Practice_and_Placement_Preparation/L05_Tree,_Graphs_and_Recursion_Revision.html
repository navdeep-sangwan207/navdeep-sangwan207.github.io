Chapter 14 – Lesson 05

Tree, Graphs and Recursion Revision

Revise tree data structures, graph traversal algorithms, recursion and backtracking techniques commonly tested in fresher placement interviews.

1. Learning Objectives

  • Revise binary-tree terminology and properties.
  • Implement preorder, inorder, postorder and level-order traversal.
  • Understand Binary Search Tree operations.
  • Apply tree height, diameter and lowest common ancestor concepts.
  • Represent graphs using adjacency matrices and adjacency lists.
  • Implement BFS and DFS.
  • Understand cycle detection, topological sorting and shortest paths.
  • Apply recursion and backtracking to coding problems.
  • Analyze complexity and recognize common interview patterns.

2. Tree Fundamentals

A tree is a hierarchical, non-linear data structure made of nodes connected by edges. A binary tree allows each node to have at most two children.

TermMeaning
RootTopmost node of a tree.
ParentA node that has one or more children.
ChildA node directly connected below another node.
LeafA node with no children.
DepthNumber of edges from root to a node.
HeightMaximum number of edges from a node to a leaf.
SubtreeA node together with its descendants.

Important Binary Tree Properties

  • Maximum nodes at level L, with root at level 0: \(2^L\).
  • Maximum nodes in a binary tree of height H: \(2^{H+1}-1\).
  • For a non-empty tree, the number of edges is nodes minus one.
  • In a full binary tree, every node has either zero or two children.

3. Binary Tree Representation

A linked representation stores the node value and pointers to its left and right children.

typedef struct Node { int data; struct Node *left; struct Node *right; } Node;

Complete C11 Program – Create a Binary Tree and Count Nodes

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *left; struct Node *right; } Node; Node *createNode(int value) { Node *node = malloc(sizeof(Node)); if (node == NULL) return NULL; node->data = value; node->left = NULL; node->right = NULL; return node; } int countNodes(const Node *root) { if (root == NULL) return 0; return 1 + countNodes(root->left) + countNodes(root->right); } int countLeaves(const Node *root) { if (root == NULL) return 0; if (root->left == NULL && root->right == NULL) return 1; return countLeaves(root->left) + countLeaves(root->right); } void freeTree(Node *root) { if (root == NULL) return; freeTree(root->left); freeTree(root->right); free(root); } int main(void) { Node *root = createNode(10); if (root == NULL) return 1; root->left = createNode(20); root->right = createNode(30); if (root->left == NULL || root->right == NULL) { freeTree(root); return 1; } root->left->left = createNode(40); root->left->right = createNode(50); if (root->left->left == NULL || root->left->right == NULL) { freeTree(root); return 1; } printf("Total nodes = %d\n", countNodes(root)); printf("Leaf nodes = %d\n", countLeaves(root)); freeTree(root); return 0; }

Expected Output

Total nodes = 5 Leaf nodes = 3

Time: O(n) for each traversal-based count. Auxiliary space: O(h) recursion stack, where h is tree height.

5. Binary Search Tree (BST)

A Binary Search Tree maintains an ordering property:

  • Values in the left subtree are smaller than the node value.
  • Values in the right subtree are greater than the node value.
  • Both subtrees must also satisfy the BST property.

This lesson uses a duplicate-rejection policy.

Complete C11 Program – BST Search, Insertion and Inorder Traversal

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *left; struct Node *right; } Node; Node *createNode(int value) { Node *node = malloc(sizeof(Node)); if (node == NULL) return NULL; node->data = value; node->left = NULL; node->right = NULL; return node; } int insert(Node **root, int value) { while (*root != NULL) { if (value == (*root)->data) return 0; if (value < (*root)->data) root = &(*root)->left; else root = &(*root)->right; } *root = createNode(value); return *root != NULL; } int search(const Node *root, int target) { while (root != NULL) { if (root->data == target) return 1; if (target < root->data) root = root->left; else root = root->right; } return 0; } void inorder(const Node *root) { if (root == NULL) return; inorder(root->left); printf("%d ", root->data); inorder(root->right); } void freeTree(Node *root) { if (root == NULL) return; freeTree(root->left); freeTree(root->right); free(root); } int main(void) { Node *root = NULL; int values[] = {50, 30, 70, 20, 40, 60, 80}; int i; for (i = 0; i < 7; i++) { if (!insert(&root, values[i])) { printf("Insertion failed.\n"); freeTree(root); return 1; } } printf("BST inorder: "); inorder(root); printf("\n60 found: %s\n", search(root, 60) ? "Yes" : "No"); printf("25 found: %s\n", search(root, 25) ? "Yes" : "No"); freeTree(root); return 0; }

Expected Output

BST inorder: 20 30 40 50 60 70 80 60 found: Yes 25 found: No
OperationAverage on balanced BSTWorst case
SearchO(log n)O(n)
InsertionO(log n)O(n)
DeletionO(log n)O(n)

6. Binary Tree Height and Diameter

Using the edge-count convention:

  • Height of an empty tree = -1.
  • Height of a leaf = 0.
  • Diameter = maximum number of edges on a path between any two nodes.

Complete C11 Program – Optimized Diameter

#include <stdio.h> typedef struct Node { int data; struct Node *left; struct Node *right; } Node; int max(int a, int b) { return a > b ? a : b; } /* Returns height and updates diameter in edge count. */ int diameterHelper(const Node *root, int *diameter) { if (root == NULL) return -1; int leftHeight = diameterHelper(root->left, diameter); int rightHeight = diameterHelper(root->right, diameter); int throughRoot = leftHeight + rightHeight + 2; if (throughRoot > *diameter) *diameter = throughRoot; return 1 + max(leftHeight, rightHeight); } int diameter(const Node *root) { int result = 0; diameterHelper(root, &result); return result; } int main(void) { Node n1 = {10, NULL, NULL}; Node n2 = {20, NULL, NULL}; Node n3 = {30, NULL, NULL}; Node n4 = {40, NULL, NULL}; Node n5 = {50, NULL, NULL}; Node n6 = {60, NULL, NULL}; Node n7 = {70, NULL, NULL}; n1.left = &n2; n1.right = &n3; n2.left = &n4; n2.right = &n5; n3.right = &n6; n6.right = &n7; printf("Diameter = %d edges\n", diameter(&n1)); return 0; }

Expected Output

Diameter = 5 edges

Time: O(n), because each node is processed once. Auxiliary space: O(h).

7. Lowest Common Ancestor in a Binary Tree

The lowest common ancestor (LCA) of two nodes is the deepest node that is an ancestor of both.

Complete C11 Program – General Binary Tree

#include <stdio.h> typedef struct Node { int data; struct Node *left; struct Node *right; } Node; Node *lowestCommonAncestor(Node *root, int a, int b) { if (root == NULL) return NULL; if (root->data == a || root->data == b) return root; Node *left = lowestCommonAncestor(root->left, a, b); Node *right = lowestCommonAncestor(root->right, a, b); if (left != NULL && right != NULL) return root; return left != NULL ? left : right; } int contains(const Node *root, int value) { if (root == NULL) return 0; if (root->data == value) return 1; return contains(root->left, value) || contains(root->right, value); } int main(void) { Node n1 = {10, NULL, NULL}; Node n2 = {20, NULL, NULL}; Node n3 = {30, NULL, NULL}; Node n4 = {40, NULL, NULL}; Node n5 = {50, NULL, NULL}; n1.left = &n2; n1.right = &n3; n2.left = &n4; n2.right = &n5; int a = 40; int b = 50; if (contains(&n1, a) && contains(&n1, b)) { Node *answer = lowestCommonAncestor(&n1, a, b); printf("LCA = %d\n", answer->data); } else { printf("One or both nodes are absent.\n"); } return 0; }

Expected Output

LCA = 20

Time: O(n) for the LCA traversal, plus O(n) for validating node presence. Auxiliary space: O(h).

This implementation assumes node values are unique. The separate presence check ensures that the returned node is an ancestor of both requested values only when both exist in the tree.

9. Breadth-First Search (BFS)

BFS explores a graph level by level using a queue. It finds shortest paths in an unweighted graph.

Complete C11 Program – Adjacency Matrix

#include <stdio.h> #define V 6 void bfs(int graph[V][V], int start) { int visited[V] = {0}; int queue[V]; int front = 0; int rear = 0; visited[start] = 1; queue[rear++] = start; while (front < rear) { int current = queue[front++]; printf("%d ", current); for (int i = 0; i < V; i++) { if (graph[current][i] && !visited[i]) { visited[i] = 1; queue[rear++] = i; } } } } int main(void) { int graph[V][V] = {0}; graph[0][1] = graph[1][0] = 1; graph[0][2] = graph[2][0] = 1; graph[1][3] = graph[3][1] = 1; graph[1][4] = graph[4][1] = 1; graph[2][5] = graph[5][2] = 1; printf("BFS: "); bfs(graph, 0); printf("\n"); return 0; }

Expected Output

BFS: 0 1 2 3 4 5

Time with adjacency matrix: O(V²). Time with adjacency list: O(V+E). Auxiliary space: O(V).

10. Depth-First Search (DFS)

DFS explores one path as deeply as possible before backtracking. It can be implemented recursively or iteratively.

Complete C11 Program – Recursive DFS

#include <stdio.h> #define V 6 void dfs(int graph[V][V], int vertex, int visited[V]) { visited[vertex] = 1; printf("%d ", vertex); for (int i = 0; i < V; i++) { if (graph[vertex][i] && !visited[i]) dfs(graph, i, visited); } } int main(void) { int graph[V][V] = {0}; int visited[V] = {0}; graph[0][1] = graph[1][0] = 1; graph[0][2] = graph[2][0] = 1; graph[1][3] = graph[3][1] = 1; graph[1][4] = graph[4][1] = 1; graph[2][5] = graph[5][2] = 1; printf("DFS: "); dfs(graph, 0, visited); printf("\n"); return 0; }

Expected Output

DFS: 0 1 3 4 2 5

Time with adjacency matrix: O(V²). Time with adjacency list: O(V+E). Auxiliary space: O(V) including recursion stack and visited array.

11. Detect a Cycle in an Undirected Graph

During DFS, if a visited neighbor is found that is not the current node's parent, an undirected cycle exists. This method assumes a simple graph without parallel edges.

Complete C11 Program

#include <stdio.h> #define V 5 int hasCycleDFS(int graph[V][V], int current, int parent, int visited[V]) { visited[current] = 1; for (int i = 0; i < V; i++) { if (!graph[current][i]) continue; if (!visited[i]) { if (hasCycleDFS(graph, i, current, visited)) return 1; } else if (i != parent) { return 1; } } return 0; } int hasCycle(int graph[V][V]) { int visited[V] = {0}; for (int i = 0; i < V; i++) { if (!visited[i]) { if (hasCycleDFS(graph, i, -1, visited)) return 1; } } return 0; } int main(void) { int graph[V][V] = {0}; graph[0][1] = graph[1][0] = 1; graph[1][2] = graph[2][1] = 1; graph[2][0] = graph[0][2] = 1; graph[2][3] = graph[3][2] = 1; printf("Cycle detected: %s\n", hasCycle(graph) ? "Yes" : "No"); return 0; }

Expected Output

Cycle detected: Yes

Time with adjacency matrix: O(V²). With adjacency lists, O(V+E).

12. Topological Sorting

Topological sorting produces a linear ordering of vertices in a directed acyclic graph (DAG), such that every directed edge u → v places u before v.

Complete C11 Program – Kahn's Algorithm

#include <stdio.h> #define V 6 int topologicalSort(int graph[V][V]) { int indegree[V] = {0}; int queue[V]; int order[V]; int front = 0; int rear = 0; int count = 0; for (int i = 0; i < V; i++) { for (int j = 0; j < V; j++) { if (graph[i][j]) indegree[j]++; } } for (int i = 0; i < V; i++) { if (indegree[i] == 0) queue[rear++] = i; } while (front < rear) { int current = queue[front++]; order[count++] = current; for (int i = 0; i < V; i++) { if (graph[current][i]) { indegree[i]--; if (indegree[i] == 0) queue[rear++] = i; } } } if (count != V) return 0; printf("Topological order: "); for (int i = 0; i < count; i++) printf("%d ", order[i]); printf("\n"); return 1; } int main(void) { int graph[V][V] = {0}; graph[5][2] = 1; graph[5][0] = 1; graph[4][0] = 1; graph[4][1] = 1; graph[2][3] = 1; graph[3][1] = 1; if (!topologicalSort(graph)) printf("Graph contains a cycle.\n"); return 0; }

Expected Output

Topological order: 4 5 0 2 3 1

Time with adjacency matrix: O(V²). With adjacency lists, O(V+E).

13. Shortest Paths – Dijkstra's Algorithm

Dijkstra's algorithm finds shortest distances from a source vertex when all edge weights are nonnegative.

Complete C11 Program – Adjacency Matrix

#include <stdio.h> #define V 5 #define INF 1000000000 void dijkstra(int graph[V][V], int source) { int distance[V]; int visited[V] = {0}; for (int i = 0; i < V; i++) distance[i] = INF; distance[source] = 0; for (int count = 0; count < V; count++) { int u = -1; for (int i = 0; i < V; i++) { if (!visited[i] && (u == -1 || distance[i] < distance[u])) u = i; } if (u == -1 || distance[u] == INF) break; visited[u] = 1; for (int v = 0; v < V; v++) { if (graph[u][v] > 0 && !visited[v] && distance[u] + graph[u][v] < distance[v]) { distance[v] = distance[u] + graph[u][v]; } } } printf("Shortest distances from %d:\n", source); for (int i = 0; i < V; i++) { if (distance[i] == INF) printf("%d: Unreachable\n", i); else printf("%d: %d\n", i, distance[i]); } } int main(void) { int graph[V][V] = { {0, 10, 0, 5, 0}, {0, 0, 1, 2, 0}, {0, 0, 0, 0, 4}, {0, 3, 9, 0, 2}, {7, 0, 6, 0, 0} }; dijkstra(graph, 0); return 0; }

Expected Output

Shortest distances from 0: 0: 0 1: 8 2: 9 3: 5 4: 7

Time with adjacency matrix: O(V²). With adjacency list and a suitable min-heap: O((V+E) log V).

This matrix example uses 0 to mean no edge, so it cannot represent zero-weight edges. It also assumes nonnegative weights. Use a separate edge-presence matrix or an adjacency-list representation if zero-weight edges must be supported.

14. Recursion Fundamentals

Recursion occurs when a function calls itself to solve a smaller instance of the same problem.

Every correct recursive solution needs:

  • A base case that stops further recursive calls.
  • A recursive case that moves toward the base case.

Complete C11 Program – Factorial

#include <stdio.h> unsigned long long factorial(unsigned int n) { if (n <= 1) return 1; return n * factorial(n - 1); } int main(void) { unsigned int n = 5; printf("%u! = %llu\n", n, factorial(n)); return 0; }

Expected Output

5! = 120

Time: O(n). Auxiliary space: O(n) recursion stack.

15. Recursion on Arrays

A recursive array sum processes one element and delegates the remaining suffix to a recursive call.

Complete C11 Program

#include <stdio.h> long long arraySum(const int arr[], int n) { if (n <= 0) return 0; return arr[n - 1] + arraySum(arr, n - 1); } int main(void) { int arr[] = {10, 20, 30, 40, 50}; int n = 5; printf("Sum = %lld\n", arraySum(arr, n)); return 0; }

Expected Output

Sum = 150

Time: O(n). Auxiliary space: O(n) recursion stack.

16. Backtracking – Generate All Subsets

Backtracking explores a decision tree by choosing an option, exploring it, and undoing the choice when necessary.

Complete C11 Program

#include <stdio.h> #define MAX 20 void generateSubsets(const int arr[], int n, int index, int subset[], int size) { if (index == n) { printf("{ "); for (int i = 0; i < size; i++) printf("%d ", subset[i]); printf("}\n"); return; } /* Exclude current element. */ generateSubsets(arr, n, index + 1, subset, size); /* Include current element. */ subset[size] = arr[index]; generateSubsets(arr, n, index + 1, subset, size + 1); } int main(void) { int arr[] = {1, 2, 3}; int subset[MAX]; printf("All subsets:\n"); generateSubsets(arr, 3, 0, subset, 0); return 0; }

Expected Output

All subsets: { } { 3 } { 2 } { 2 3 } { 1 } { 1 3 } { 1 2 } { 1 2 3 }

Time: O(n × 2ⁿ) including printing each subset. Auxiliary space: O(n) recursion and subset storage, excluding output.

20. Common Interview Mistakes

  • Confusing tree height measured in edges with height measured in nodes.
  • Forgetting the base case in recursive functions.
  • Assuming every BST operation is O(log n).
  • Using inorder traversal as a BST validation method without checking strict ordering and duplicate policy.
  • Forgetting to mark graph vertices as visited.
  • Marking vertices too late in BFS and allowing duplicate queue entries.
  • Using DFS for shortest paths in unweighted graphs when BFS is required.
  • Using Dijkstra with negative edge weights.
  • Applying topological sorting to a cyclic directed graph.
  • Failing to distinguish directed and undirected cycle detection.
  • Ignoring disconnected graph components.
  • Forgetting to undo state during backtracking.
  • Ignoring recursion depth and stack limitations.

21. Interview Questions and Answers

Q1. What is the difference between a binary tree and a BST?

A binary tree allows up to two children per node. A BST additionally maintains an ordering property between left and right subtrees.

Q2. Which traversal produces sorted values in a BST?

Inorder traversal produces sorted values when the BST ordering and duplicate policy are respected.

Q3. What is the difference between BFS and DFS?

BFS explores level by level using a queue. DFS explores deeply using recursion or an explicit stack.

Q4. Which algorithm finds shortest paths in an unweighted graph?

BFS.

Q5. Can Dijkstra's algorithm handle negative edge weights?

No. Use Bellman-Ford when negative edge weights must be supported and negative cycles are handled appropriately.

Q6. What is a topological ordering?

A linear ordering of DAG vertices where every directed edge goes from an earlier vertex to a later vertex.

Q7. What is a recursion base case?

A condition that stops further recursive calls.

Q8. What is backtracking?

A search technique that explores choices and reverses them when a branch is complete or invalid.

Q9. What is the difference between a tree and a graph?

A tree is a connected, acyclic graph. General graphs may contain cycles and may be disconnected.

Q10. What is the time complexity of BFS using an adjacency list?

O(V+E), because vertices and edges are processed a bounded number of times.

24. Lesson Summary

  • Binary trees organize data hierarchically; BSTs add an ordering rule.
  • Tree traversal techniques include preorder, inorder, postorder and level order.
  • Tree diameter and LCA are important placement problems.
  • BFS uses a queue; DFS uses recursion or a stack.
  • Graph representation affects algorithm complexity.
  • Cycle detection depends on whether the graph is directed or undirected.
  • Topological sorting applies to DAGs.
  • Dijkstra requires nonnegative edge weights.
  • Recursion requires a base case and progress toward it.
  • Backtracking explores a decision tree and undoes choices.
