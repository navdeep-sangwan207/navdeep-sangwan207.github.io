Chapter 14 – Lesson 07

Important Coding Questions for Freshers

A placement-focused collection of frequently tested programming problems with C11 implementations, expected outputs, complexity analysis and practice questions.

1. Learning Objectives

  • Practice frequently asked fresher coding-round problems.
  • Improve problem-solving and implementation skills in C.
  • Apply arrays, strings, pointers and data structures.
  • Recognize common algorithmic patterns.
  • Write solutions with correct edge-case handling.
  • Analyze time and auxiliary space complexity.
  • Prepare for online assessments and technical interviews.

2. Coding Round Preparation Strategy

For every coding problem, follow this process:

  1. Read the problem statement carefully.
  2. Identify input constraints and edge cases.
  3. Understand the expected output.
  4. Start with a simple brute-force solution.
  5. Identify a more efficient algorithm or data structure.
  6. Write the C11 implementation.
  7. Dry-run the code with sample input.
  8. Test boundary cases and analyze complexity.

3. Array Coding Questions

Question 1: Find the Second Largest Distinct Element

Given an integer array, find the second largest distinct element. If it does not exist, report that fact.

Complete C11 Program

#include <stdio.h> #include <limits.h> int main(void) { int arr[] = {12, 35, 1, 10, 34, 1}; int n = sizeof(arr) / sizeof(arr[0]); int largest = INT_MIN; int secondLargest = INT_MIN; int foundLargest = 0; int foundSecond = 0; for (int i = 0; i < n; i++) { if (!foundLargest || arr[i] > largest) { if (foundLargest) { secondLargest = largest; foundSecond = 1; } largest = arr[i]; foundLargest = 1; } else if (arr[i] != largest && (!foundSecond || arr[i] > secondLargest)) { secondLargest = arr[i]; foundSecond = 1; } } if (foundSecond) printf("Second largest = %d\n", secondLargest); else printf("Second largest does not exist.\n"); return 0; }
Second largest = 34

Time: O(n). Auxiliary space: O(1).

Question 2: Rotate an Array to the Right by K Positions

Rotate the array to the right by k positions using the reversal algorithm.

Complete C11 Program

#include <stdio.h> void reverse(int arr[], int left, int right) { while (left < right) { int temp = arr[left]; arr[left] = arr[right]; arr[right] = temp; left++; right--; } } int main(void) { int arr[] = {1, 2, 3, 4, 5, 6, 7}; int n = sizeof(arr) / sizeof(arr[0]); int k = 3; if (n > 0) { k %= n; reverse(arr, 0, n - 1); reverse(arr, 0, k - 1); reverse(arr, k, n - 1); } printf("Rotated array: "); for (int i = 0; i < n; i++) printf("%d ", arr[i]); printf("\n"); return 0; }
Rotated array: 5 6 7 1 2 3 4

Time: O(n). Auxiliary space: O(1).

Question 3: Find the Missing Number

An array contains distinct values from 1 to n, with one value missing. Find the missing value.

Complete C11 Program – XOR Method

#include <stdio.h> int main(void) { int arr[] = {1, 2, 4, 5, 6}; int n = 6; int result = 0; for (int i = 1; i <= n; i++) result ^= i; for (int i = 0; i < n - 1; i++) result ^= arr[i]; printf("Missing number = %d\n", result); return 0; }
Missing number = 3

Time: O(n). Auxiliary space: O(1).

This solution assumes exactly one missing value, all other values are distinct and belong to the range 1 through n. It avoids the potential integer overflow of the sum formula.

Question 4: Maximum Subarray Sum – Kadane's Algorithm

Find the maximum sum of a non-empty contiguous subarray.

Complete C11 Program

#include <stdio.h> int main(void) { int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4}; int n = sizeof(arr) / sizeof(arr[0]); int currentSum = arr[0]; int maximumSum = arr[0]; for (int i = 1; i < n; i++) { if (currentSum + arr[i] < arr[i]) currentSum = arr[i]; else currentSum += arr[i]; if (currentSum > maximumSum) maximumSum = currentSum; } printf("Maximum subarray sum = %d\n", maximumSum); return 0; }
Maximum subarray sum = 6

One maximum subarray is [4, -1, 2, 1]. Time: O(n). Auxiliary space: O(1).

4. String Coding Questions

Question 5: Check Whether a String Is a Palindrome

A palindrome reads the same forward and backward.

Complete C11 Program

#include <stdio.h> #include <string.h> int isPalindrome(const char str[]) { size_t left = 0; size_t right = strlen(str); if (right == 0) return 1; right--; while (left < right) { if (str[left] != str[right]) return 0; left++; right--; } return 1; } int main(void) { char str[] = "madam"; if (isPalindrome(str)) printf("Palindrome\n"); else printf("Not a palindrome\n"); return 0; }
Palindrome

Time: O(n). Auxiliary space: O(1), excluding the input string.

Question 6: Find the Frequency of Each Character

Count the occurrences of each byte value in a string. This implementation uses an unsigned-byte frequency table and is case-sensitive.

Complete C11 Program

#include <stdio.h> int main(void) { char str[] = "programming"; int frequency[256] = {0}; for (int i = 0; str[i] != '\0'; i++) { unsigned char ch = (unsigned char)str[i]; frequency[ch]++; } printf("Character frequencies:\n"); for (int i = 0; i < 256; i++) { if (frequency[i] > 0) { if (i >= 32 && i <= 126) printf("%c = %d\n", i, frequency[i]); else printf("Byte %d = %d\n", i, frequency[i]); } } return 0; }
Character frequencies: a = 1 g = 2 i = 1 m = 2 n = 1 o = 1 p = 1 r = 2

Time: O(n + 256). Auxiliary space: O(256), effectively O(1) for byte data.

Question 7: Reverse a String Without a Library Reverse Function

Complete C11 Program

#include <stdio.h> #include <string.h> int main(void) { char str[] = "placement"; size_t left = 0; size_t right = strlen(str); if (right > 0) right--; while (left < right) { char temp = str[left]; str[left] = str[right]; str[right] = temp; left++; right--; } printf("Reversed string = %s\n", str); return 0; }
Reversed string = tnemecalp

Time: O(n). Auxiliary space: O(1).

5. Searching and Sorting Questions

Question 8: Binary Search

Find a target value in a sorted array.

Complete C11 Program

#include <stdio.h> int binarySearch(const int arr[], int n, int target) { int low = 0; int high = n - 1; while (low <= high) { int mid = low + (high - low) / 2; if (arr[mid] == target) return mid; if (arr[mid] < target) low = mid + 1; else high = mid - 1; } return -1; } int main(void) { int arr[] = {10, 20, 30, 40, 50, 60}; int n = sizeof(arr) / sizeof(arr[0]); int target = 40; int index = binarySearch(arr, n, target); if (index != -1) printf("Found at index %d\n", index); else printf("Not found\n"); return 0; }
Found at index 3

Time: O(log n). Auxiliary space: O(1).

Question 9: Sort an Array Using Insertion Sort

Complete C11 Program

#include <stdio.h> void insertionSort(int arr[], int n) { for (int i = 1; i < n; i++) { int key = arr[i]; int j = i - 1; while (j >= 0 && arr[j] > key) { arr[j + 1] = arr[j]; j--; } arr[j + 1] = key; } } int main(void) { int arr[] = {5, 2, 9, 1, 6, 3}; int n = sizeof(arr) / sizeof(arr[0]); insertionSort(arr, n); printf("Sorted array: "); for (int i = 0; i < n; i++) printf("%d ", arr[i]); printf("\n"); return 0; }
Sorted array: 1 2 3 5 6 9

Time: O(n²) average and worst case; O(n) best case. Auxiliary space: O(1).

6. Hashing and Array Pair Questions

Question 10: Two Sum – Find a Pair with a Given Target

Find two distinct array elements whose sum equals the target. This simple version uses brute force and returns the first pair found.

Complete C11 Program

#include <stdio.h> int main(void) { int arr[] = {2, 7, 11, 15}; int n = sizeof(arr) / sizeof(arr[0]); int target = 9; int found = 0; for (int i = 0; i < n && !found; i++) { for (int j = i + 1; j < n; j++) { if (arr[i] + arr[j] == target) { printf("Indices: %d and %d\n", i, j); printf("Values: %d and %d\n", arr[i], arr[j]); found = 1; break; } } } if (!found) printf("No pair found.\n"); return 0; }
Indices: 0 and 1 Values: 2 and 7

Time: O(n²). Auxiliary space: O(1).

For an O(n) average-time solution, use a hash table to store previously seen values and search for the complement target - currentValue. A production implementation must handle complement arithmetic overflow and hash-table allocation failures.

7. Linked List Questions

Question 11: Reverse a Singly Linked List

Reverse the links of a singly linked list using three pointers.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; Node *createNode(int value) { Node *node = malloc(sizeof(Node)); if (node == NULL) return NULL; node->data = value; node->next = NULL; return node; } Node *reverseList(Node *head) { Node *previous = NULL; Node *current = head; while (current != NULL) { Node *nextNode = current->next; current->next = previous; previous = current; current = nextNode; } return previous; } void display(const Node *head) { while (head != NULL) { printf("%d ", head->data); head = head->next; } printf("\n"); } void freeList(Node *head) { while (head != NULL) { Node *temp = head; head = head->next; free(temp); } } int main(void) { Node *head = NULL; Node **tail = &head; for (int i = 1; i <= 5; i++) { Node *node = createNode(i * 10); if (node == NULL) { freeList(head); return 1; } *tail = node; tail = &node->next; } printf("Original: "); display(head); head = reverseList(head); printf("Reversed: "); display(head); freeList(head); return 0; }
Original: 10 20 30 40 50 Reversed: 50 40 30 20 10

Time: O(n). Auxiliary space: O(1).

Question 12: Find the Middle Node of a Linked List

Use slow and fast pointers. For an even number of nodes, this implementation returns the second middle node.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; int main(void) { int values[] = {10, 20, 30, 40, 50}; int n = sizeof(values) / sizeof(values[0]); Node *head = NULL; Node **tail = &head; for (int i = 0; i < n; i++) { Node *node = malloc(sizeof(Node)); if (node == NULL) { while (head != NULL) { Node *temp = head; head = head->next; free(temp); } return 1; } node->data = values[i]; node->next = NULL; *tail = node; tail = &node->next; } Node *slow = head; Node *fast = head; while (fast != NULL && fast->next != NULL) { slow = slow->next; fast = fast->next->next; } if (slow != NULL) printf("Middle node = %d\n", slow->data); while (head != NULL) { Node *temp = head; head = head->next; free(temp); } return 0; }
Middle node = 30

Time: O(n). Auxiliary space: O(1).

8. Stack and Queue Questions

Question 13: Check Balanced Parentheses

Check whether parentheses, brackets and braces are correctly matched and nested. Non-bracket characters are ignored.

Complete C11 Program

#include <stdio.h> #include <string.h> #define MAX 100 int isMatching(char open, char close) { return (open == '(' && close == ')') || (open == '[' && close == ']') || (open == '{' && close == '}'); } int isBalanced(const char str[]) { char stack[MAX]; int top = -1; for (int i = 0; str[i] != '\0'; i++) { char ch = str[i]; if (ch == '(' || ch == '[' || ch == '{') { if (top == MAX - 1) return 0; stack[++top] = ch; } else if (ch == ')' || ch == ']' || ch == '}') { if (top == -1) return 0; if (!isMatching(stack[top], ch)) return 0; top--; } } return top == -1; } int main(void) { char expression[] = "{a + [b * (c + d)]}"; if (isBalanced(expression)) printf("Balanced parentheses\n"); else printf("Not balanced\n"); return 0; }
Balanced parentheses

Time: O(n). Auxiliary space: O(n).

9. Recursion and Mathematics Questions

Question 14: Find Factorial Using Recursion

Complete C11 Program

#include <stdio.h> unsigned long long factorial(unsigned int n) { if (n <= 1) return 1; return n * factorial(n - 1); } int main(void) { unsigned int n = 5; if (n > 20) { printf("Input is too large.\n"); return 1; } printf("Factorial = %llu\n", factorial(n)); return 0; }
Factorial = 120

Time: O(n). Auxiliary space: O(n).

Question 15: Check Whether a Number Is Prime

Complete C11 Program

#include <stdio.h> int isPrime(int n) { if (n < 2) return 0; for (int i = 2; i <= n / i; i++) { if (n % i == 0) return 0; } return 1; } int main(void) { int n = 29; if (isPrime(n)) printf("%d is prime.\n", n); else printf("%d is not prime.\n", n); return 0; }
29 is prime.

Time: O(√n). Auxiliary space: O(1).

Question 16: Find the Greatest Common Divisor (GCD)

Use the Euclidean algorithm.

Complete C11 Program

#include <stdio.h> int gcd(int a, int b) { while (b != 0) { int remainder = a % b; a = b; b = remainder; } return a; } int main(void) { int a = 48; int b = 18; printf("GCD = %d\n", gcd(a, b)); return 0; }
GCD = 6

Time: O(log(min(a,b))) for nonnegative inputs. Auxiliary space: O(1).

10. Tree and Graph Questions

Question 17: Find the Height of a Binary Tree

Use recursion to calculate the height in edges. An empty tree has height -1.

Complete C11 Program

#include <stdio.h> typedef struct Node { int data; struct Node *left; struct Node *right; } Node; int max(int a, int b) { return a > b ? a : b; } int height(const Node *root) { if (root == NULL) return -1; return 1 + max(height(root->left), height(root->right)); } int main(void) { Node n1 = {10, NULL, NULL}; Node n2 = {20, NULL, NULL}; Node n3 = {30, NULL, NULL}; Node n4 = {40, NULL, NULL}; n1.left = &n2; n1.right = &n3; n2.left = &n4; printf("Tree height = %d\n", height(&n1)); return 0; }
Tree height = 2

Time: O(n). Auxiliary space: O(h).

Question 18: Count Connected Components in an Undirected Graph

Use DFS to visit every vertex. Each new DFS traversal identifies one connected component.

Complete C11 Program

#include <stdio.h> #define V 6 void dfs(int graph[V][V], int vertex, int visited[V]) { visited[vertex] = 1; for (int i = 0; i < V; i++) { if (graph[vertex][i] && !visited[i]) dfs(graph, i, visited); } } int countComponents(int graph[V][V]) { int visited[V] = {0}; int components = 0; for (int i = 0; i < V; i++) { if (!visited[i]) { dfs(graph, i, visited); components++; } } return components; } int main(void) { int graph[V][V] = {0}; graph[0][1] = graph[1][0] = 1; graph[1][2] = graph[2][1] = 1; graph[3][4] = graph[4][3] = 1; printf("Connected components = %d\n", countComponents(graph)); return 0; }
Connected components = 3

Time: O(V²) with an adjacency matrix; O(V+E) with an adjacency list. Auxiliary space: O(V).

11. Dynamic Programming Questions

Question 19: Climbing Stairs

You can climb one or two steps at a time. Find the number of ways to reach step n.

Complete C11 Program

#include <stdio.h> unsigned long long climbingStairs(int n) { if (n <= 1) return 1; unsigned long long previous = 1; unsigned long long current = 2; for (int i = 3; i <= n; i++) { unsigned long long next = previous + current; previous = current; current = next; } return current; } int main(void) { int n = 5; if (n < 0 || n > 90) return 1; printf("Number of ways = %llu\n", climbingStairs(n)); return 0; }
Number of ways = 8

Time: O(n). Auxiliary space: O(1).

Question 20: Maximum Sum of Non-Adjacent Elements

Find the maximum sum by selecting elements such that no two selected elements are adjacent. Selecting no elements is allowed, so the answer is at least zero.

Complete C11 Program

#include <stdio.h> long long max(long long a, long long b) { return a > b ? a : b; } long long maximumNonAdjacentSum(const int arr[], int n) { long long previousTwo = 0; long long previousOne = 0; for (int i = 0; i < n; i++) { long long take = previousTwo + arr[i]; long long skip = previousOne; long long current = max(take, skip); previousTwo = previousOne; previousOne = current; } return previousOne; } int main(void) { int arr[] = {3, 2, 7, 10}; int n = sizeof(arr) / sizeof(arr[0]); printf("Maximum sum = %lld\n", maximumNonAdjacentSum(arr, n)); return 0; }
Maximum sum = 13

Time: O(n). Auxiliary space: O(1).

13. Common Coding Round Edge Cases

  • Empty arrays and empty strings.
  • Arrays containing one element.
  • All elements equal.
  • Negative values and zero values.
  • Duplicate elements.
  • Already sorted and reverse-sorted arrays.
  • Target value not present.
  • Very large input sizes.
  • Integer overflow in sums, products and indexes.
  • Memory allocation failure in linked-list and dynamic-array programs.
  • Null pointers and empty linked lists.
  • Disconnected graphs and isolated vertices.
  • Recursion depth and stack exhaustion.

14. Interview Questions and Answers

Q1. What should you do before coding?

Understand the input, output, constraints, examples and edge cases. Then select an appropriate algorithm.

Q2. What is brute force?

A straightforward solution that explores the possible choices directly, often without advanced optimization.

Q3. Why optimize a brute-force solution?

To reduce execution time or memory usage so that the solution handles larger inputs within the given constraints.

Q4. What is the difference between an array and a linked list?

Arrays store elements contiguously and support O(1) indexing. Linked lists use nodes connected by pointers and require traversal for positional access.

Q5. Why is binary search O(log n)?

It eliminates approximately half of the remaining search range in every iteration.

Q6. What is the purpose of hashing?

Hashing maps keys to table positions and can support average O(1) lookup, insertion and deletion under suitable conditions.

Q7. What is a two-pointer technique?

It uses two indexes or pointers to process a sequence efficiently, often reducing nested-loop solutions.

Q8. What is Kadane's algorithm used for?

Finding the maximum sum of a non-empty contiguous subarray in O(n) time.

Q9. What is the difference between a stack and a queue?

A stack follows LIFO; a queue follows FIFO.

Q10. Why should memory allocation be checked?

Because malloc can return NULL when allocation fails. Dereferencing a null pointer causes undefined behavior.

Q11. What is the difference between time and space complexity?

Time complexity describes how running time grows with input size. Space complexity describes how memory usage grows.

Q12. What should you explain after writing code in an interview?

Explain the approach, correctness reasoning, time complexity, auxiliary space and important edge cases.
