Chapter 14 – Lesson 04

Linked Lists, Stacks and Queues Revision

Revise pointer-based data structures and linear data structures frequently tested in fresher coding interviews and placement assessments.

1. Learning Objectives

  • Review singly, doubly and circular linked lists.
  • Perform linked-list insertion, deletion and reversal.
  • Find middle nodes and detect cycles.
  • Understand stack operations and applications.
  • Implement stacks using arrays and linked lists.
  • Understand queues, circular queues and deques.
  • Solve common stack and queue interview problems.
  • Analyze time complexity, memory usage and edge cases.

3. Singly Linked List Fundamentals

A singly linked list consists of nodes. Each node stores data and a pointer to the next node.

typedef struct Node { int data; struct Node *next; } Node;

Unlike arrays, linked-list nodes do not need to occupy contiguous memory locations.

Complete C11 Program – Insert, Delete and Display

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; Node *createNode(int value) { Node *newNode = malloc(sizeof(Node)); if (newNode == NULL) return NULL; newNode->data = value; newNode->next = NULL; return newNode; } int insertAtBeginning(Node **head, int value) { Node *newNode = createNode(value); if (newNode == NULL) return 0; newNode->next = *head; *head = newNode; return 1; } int insertAtEnd(Node **head, int value) { Node *newNode = createNode(value); Node *current; if (newNode == NULL) return 0; if (*head == NULL) { *head = newNode; return 1; } current = *head; while (current->next != NULL) current = current->next; current->next = newNode; return 1; } int deleteValue(Node **head, int value) { Node *current = *head; Node *previous = NULL; while (current != NULL && current->data != value) { previous = current; current = current->next; } if (current == NULL) return 0; if (previous == NULL) *head = current->next; else previous->next = current->next; free(current); return 1; } void display(const Node *head) { while (head != NULL) { printf("%d -> ", head->data); head = head->next; } printf("NULL\n"); } void freeList(Node *head) { while (head != NULL) { Node *next = head->next; free(head); head = next; } } int main(void) { Node *head = NULL; insertAtEnd(&head, 10); insertAtEnd(&head, 20); insertAtEnd(&head, 30); insertAtBeginning(&head, 5); printf("Original list: "); display(head); deleteValue(&head, 20); printf("After deletion: "); display(head); freeList(head); return 0; }

Expected Output

Original list: 5 -> 10 -> 20 -> 30 -> NULL After deletion: 5 -> 10 -> 30 -> NULL

Complexity: Insert at beginning O(1), insert at end O(n) without a tail pointer, delete by value O(n).

4. Reverse a Linked List

Reverse a singly linked list by changing the direction of its next pointers. The iterative technique uses three pointers:

  • previous: Previous node in the reversed portion.
  • current: Node being processed.
  • next: Saved next node before changing the link.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; Node *reverseList(Node *head) { Node *previous = NULL; Node *current = head; while (current != NULL) { Node *next = current->next; current->next = previous; previous = current; current = next; } return previous; } void append(Node **head, int value) { Node *node = malloc(sizeof(Node)); Node *current; if (node == NULL) return; node->data = value; node->next = NULL; if (*head == NULL) { *head = node; return; } current = *head; while (current->next != NULL) current = current->next; current->next = node; } void display(Node *head) { while (head != NULL) { printf("%d ", head->data); head = head->next; } printf("\n"); } void freeList(Node *head) { while (head != NULL) { Node *next = head->next; free(head); head = next; } } int main(void) { Node *head = NULL; append(&head, 10); append(&head, 20); append(&head, 30); append(&head, 40); printf("Before reversal: "); display(head); head = reverseList(head); printf("After reversal: "); display(head); freeList(head); return 0; }

Expected Output

Before reversal: 10 20 30 40 After reversal: 40 30 20 10

Time: O(n). Auxiliary space: O(1).

5. Find the Middle Node

Use slow and fast pointers. The slow pointer moves one node at a time; the fast pointer moves two nodes.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; Node *middleNode(Node *head) { Node *slow = head; Node *fast = head; while (fast != NULL && fast->next != NULL) { slow = slow->next; fast = fast->next->next; } return slow; } int main(void) { Node a = {10, NULL}; Node b = {20, NULL}; Node c = {30, NULL}; Node d = {40, NULL}; Node e = {50, NULL}; a.next = &b; b.next = &c; c.next = &d; d.next = &e; Node *middle = middleNode(&a); if (middle != NULL) printf("Middle node = %d\n", middle->data); return 0; }

Expected Output

Middle node = 30

Time: O(n). Auxiliary space: O(1).

For an even-length list, this implementation returns the second middle node.

6. Detect a Cycle in a Linked List

Floyd's cycle detection algorithm uses slow and fast pointers. If a cycle exists, the pointers eventually meet.

Complete C11 Program

#include <stdio.h> typedef struct Node { int data; struct Node *next; } Node; int hasCycle(Node *head) { Node *slow = head; Node *fast = head; while (fast != NULL && fast->next != NULL) { slow = slow->next; fast = fast->next->next; if (slow == fast) return 1; } return 0; } int main(void) { Node a = {10, NULL}; Node b = {20, NULL}; Node c = {30, NULL}; Node d = {40, NULL}; a.next = &b; b.next = &c; c.next = &d; d.next = &b; printf("Cycle detected: %s\n", hasCycle(&a) ? "Yes" : "No"); /* Break the cycle before the stack-allocated nodes go out of scope. */ d.next = NULL; return 0; }

Expected Output

Cycle detected: Yes

Time: O(n). Auxiliary space: O(1).

A doubly linked list stores both next and previous pointers.

typedef struct DNode { int data; struct DNode *prev; struct DNode *next; } DNode;

8. Stack Fundamentals

A stack follows LIFO: Last In, First Out.

Core Operations

  • push: Insert an element at the top.
  • pop: Remove the top element.
  • peek: Read the top element without removing it.
  • isEmpty: Check whether the stack is empty.
  • isFull: Check capacity in a fixed-size implementation.

Complete C11 Program – Array Stack

#include <stdio.h> #define MAX 100 typedef struct { int data[MAX]; int top; } Stack; void initialize(Stack *s) { s->top = -1; } int isEmpty(const Stack *s) { return s->top == -1; } int isFull(const Stack *s) { return s->top == MAX - 1; } int push(Stack *s, int value) { if (isFull(s)) return 0; s->data[++s->top] = value; return 1; } int pop(Stack *s, int *value) { if (isEmpty(s)) return 0; *value = s->data[s->top--]; return 1; } int peek(const Stack *s, int *value) { if (isEmpty(s)) return 0; *value = s->data[s->top]; return 1; } int main(void) { Stack s; int value; initialize(&s); push(&s, 10); push(&s, 20); push(&s, 30); if (peek(&s, &value)) printf("Top element = %d\n", value); if (pop(&s, &value)) printf("Popped = %d\n", value); if (peek(&s, &value)) printf("New top = %d\n", value); return 0; }

Expected Output

Top element = 30 Popped = 30 New top = 20

Push: O(1). Pop: O(1). Peek: O(1).

9. Stack Using a Linked List

A linked-list stack grows dynamically until memory allocation fails. Push and pop operate at the head node.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; int push(Node **top, int value) { Node *node = malloc(sizeof(Node)); if (node == NULL) return 0; node->data = value; node->next = *top; *top = node; return 1; } int pop(Node **top, int *value) { Node *temp; if (*top == NULL) return 0; temp = *top; *value = temp->data; *top = temp->next; free(temp); return 1; } void freeStack(Node *top) { while (top != NULL) { Node *next = top->next; free(top); top = next; } } int main(void) { Node *top = NULL; int value; push(&top, 10); push(&top, 20); push(&top, 30); if (pop(&top, &value)) printf("Popped = %d\n", value); if (pop(&top, &value)) printf("Popped = %d\n", value); freeStack(top); return 0; }

Expected Output

Popped = 30 Popped = 20

10. Balanced Parentheses

Use a stack to verify that opening brackets are matched by the correct closing brackets in the correct order.

Complete C11 Program

#include <stdio.h> #include <string.h> #define MAX 200 int isMatchingPair(char open, char close) { return (open == '(' && close == ')') || (open == '[' && close == ']') || (open == '{' && close == '}'); } int isBalanced(const char *expression) { char stack[MAX]; int top = -1; int i; for (i = 0; expression[i] != '\0'; i++) { char ch = expression[i]; if (ch == '(' || ch == '[' || ch == '{') { if (top == MAX - 1) return 0; stack[++top] = ch; } else if (ch == ')' || ch == ']' || ch == '}') { if (top == -1) return 0; if (!isMatchingPair(stack[top], ch)) return 0; top--; } } return top == -1; } int main(void) { const char *expression = "{a + [b * (c + d)]}"; if (isBalanced(expression)) printf("Balanced parentheses\n"); else printf("Not balanced\n"); return 0; }

Expected Output

Balanced parentheses

Time: O(n). Auxiliary space: O(n).

11. Next Greater Element

For each array element, find the first greater element to its right. A monotonic decreasing stack provides an O(n) solution.

Complete C11 Program

#include <stdio.h> #define MAX 100 int main(void) { int arr[] = {4, 5, 2, 10, 8}; int n = 5; int stack[MAX]; int result[MAX]; int top = -1; int i; for (i = 0; i < n; i++) result[i] = -1; for (i = n - 1; i >= 0; i--) { while (top != -1 && stack[top] <= arr[i]) top--; if (top != -1) result[i] = stack[top]; stack[++top] = arr[i]; } printf("Next greater elements: "); for (i = 0; i < n; i++) printf("%d ", result[i]); printf("\n"); return 0; }

Expected Output

Next greater elements: 5 10 10 -1 -1

Time: O(n), because each element is pushed and popped at most once. Auxiliary space: O(n).

12. Queue Fundamentals

A queue follows FIFO: First In, First Out.

  • enqueue: Insert at the rear.
  • dequeue: Remove from the front.
  • front: Read the first element.
  • rear: Read the last element.

Complete C11 Program – Circular Queue

#include <stdio.h> #define MAX 5 typedef struct { int data[MAX]; int front; int rear; int count; } Queue; void initialize(Queue *q) { q->front = 0; q->rear = -1; q->count = 0; } int isEmpty(const Queue *q) { return q->count == 0; } int isFull(const Queue *q) { return q->count == MAX; } int enqueue(Queue *q, int value) { if (isFull(q)) return 0; q->rear = (q->rear + 1) % MAX; q->data[q->rear] = value; q->count++; return 1; } int dequeue(Queue *q, int *value) { if (isEmpty(q)) return 0; *value = q->data[q->front]; q->front = (q->front + 1) % MAX; q->count--; if (q->count == 0) { q->front = 0; q->rear = -1; } return 1; } int main(void) { Queue q; int value; initialize(&q); enqueue(&q, 10); enqueue(&q, 20); enqueue(&q, 30); if (dequeue(&q, &value)) printf("Removed = %d\n", value); enqueue(&q, 40); enqueue(&q, 50); if (dequeue(&q, &value)) printf("Removed = %d\n", value); printf("Queue count = %d\n", q.count); return 0; }

Expected Output

Removed = 10 Removed = 20 Queue count = 3

Enqueue: O(1). Dequeue: O(1).

13. Deque

A double-ended queue (deque) allows insertion and deletion at both the front and rear.

OperationDescription
Insert frontAdd an element at the front.
Insert rearAdd an element at the rear.
Delete frontRemove the front element.
Delete rearRemove the rear element.

Common applications include sliding-window maximum/minimum, task scheduling and maintaining elements at both ends.

14. Sliding Window Maximum Using a Deque

For each window of size k, find its maximum. Store indices in a deque and maintain decreasing values from front to rear.

Complete C11 Program – Array-Based Index Deque

#include <stdio.h> #define MAX 100 int main(void) { int arr[] = {1, 3, -1, -3, 5, 3, 6, 7}; int n = 8; int k = 3; int deque[MAX]; int front = 0; int rear = -1; int i; if (k <= 0 || k > n) { printf("Invalid window size.\n"); return 1; } printf("Window maximums: "); for (i = 0; i < n; i++) { while (front <= rear && deque[front] <= i - k) front++; while (front <= rear && arr[deque[rear]] <= arr[i]) rear--; deque[++rear] = i; if (i >= k - 1) printf("%d ", arr[deque[front]]); } printf("\n"); return 0; }

Expected Output

Window maximums: 3 3 5 5 6 7

Time: O(n). Each index enters and leaves the deque at most once.

Auxiliary space: O(k) in the logical deque; the example reserves a fixed MAX-sized array.

15. Queue Using Two Stacks

One stack stores incoming elements. The second stack supplies the oldest element. Transfer elements only when the output stack is empty.

Complete C11 Program

#include <stdio.h> #define MAX 100 typedef struct { int data[MAX]; int top; } Stack; typedef struct { Stack input; Stack output; } Queue; void initializeStack(Stack *s) { s->top = -1; } int push(Stack *s, int value) { if (s->top == MAX - 1) return 0; s->data[++s->top] = value; return 1; } int pop(Stack *s, int *value) { if (s->top == -1) return 0; *value = s->data[s->top--]; return 1; } void initializeQueue(Queue *q) { initializeStack(&q->input); initializeStack(&q->output); } int enqueue(Queue *q, int value) { return push(&q->input, value); } int dequeue(Queue *q, int *value) { int temp; if (q->output.top == -1) { while (q->input.top != -1) { pop(&q->input, &temp); if (!push(&q->output, temp)) return 0; } } return pop(&q->output, value); } int main(void) { Queue q; int value; initializeQueue(&q); enqueue(&q, 10); enqueue(&q, 20); enqueue(&q, 30); if (dequeue(&q, &value)) printf("Removed = %d\n", value); enqueue(&q, 40); if (dequeue(&q, &value)) printf("Removed = %d\n", value); if (dequeue(&q, &value)) printf("Removed = %d\n", value); return 0; }

Expected Output

Removed = 10 Removed = 20 Removed = 30
This teaching implementation uses two independently fixed-size stacks. It is suitable for the shown sequence, but it is not a fully robust fixed-capacity queue: a transfer can fail after some elements have moved, and the two arrays do not enforce one shared total capacity. A production implementation should track total count and guarantee transfer capacity, or use dynamically allocated storage.

Amortized enqueue: O(1). Amortized dequeue: O(1). A single dequeue that triggers transfer can take O(n).

17. Common Mistakes

  • Dereferencing a NULL pointer in an empty linked list.
  • Forgetting to update the head pointer after insertion or deletion.
  • Losing the remaining list while reversing pointers.
  • Freeing a node before saving its next pointer.
  • Not checking malloc() for failure.
  • Leaving a cycle in a linked list before traversing or freeing it.
  • Popping from an empty stack.
  • Pushing into a full fixed-size stack.
  • Confusing FIFO and LIFO.
  • Failing to wrap indices in a circular queue.
  • Using an incorrect deque expiration condition in sliding-window problems.
  • Using a normal stack where a monotonic stack is required.

18. Interview Questions and Answers

Q1. What is the main difference between an array and a linked list?

Arrays provide O(1) indexed access and use contiguous storage. Linked lists use pointer-connected nodes and require O(n) traversal for indexed access.

Q2. Why use a doubly linked list?

It supports traversal in both directions and makes deletion of a known node easier when its previous and next links are maintained.

Q3. How does Floyd's cycle detection work?

Two pointers move at different speeds. If a cycle exists, they eventually meet.

Q4. What is the difference between stack and queue?

A stack follows LIFO, while a queue follows FIFO.

Q5. Why use a circular queue?

It reuses freed positions in a fixed-size array instead of wasting space at the front.

Q6. What is a monotonic stack?

A stack that maintains elements in increasing or decreasing order to solve nearest-greater or nearest-smaller problems efficiently.

Q7. What is a deque?

A double-ended queue that supports insertion and deletion at both ends.

Q8. What is the time complexity of reversing a linked list iteratively?

O(n) time and O(1) auxiliary space.

Q9. Why is a queue used in BFS?

A queue processes vertices in the order they are discovered, enabling level-by-level traversal.

Q10. How can a queue be implemented using stacks?

Use an input stack and an output stack. Transfer input elements only when the output stack is empty.

21. Lesson Summary

  • Linked lists provide flexible node-based storage.
  • Slow and fast pointers solve several linked-list problems.
  • Floyd's algorithm detects cycles in O(n) time and O(1) auxiliary space.
  • Stacks follow LIFO and are useful for parsing and monotonic-stack problems.
  • Queues follow FIFO and support BFS and scheduling.
  • Circular queues reuse array positions.
  • Deques support operations at both ends.
  • Monotonic stacks and deques solve several O(n) interview problems.
  • Always validate pointers, array boundaries and allocation results.
