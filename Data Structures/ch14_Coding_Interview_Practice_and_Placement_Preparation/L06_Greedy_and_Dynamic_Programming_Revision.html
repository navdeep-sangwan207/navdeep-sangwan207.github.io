2. Greedy Algorithm Fundamentals

A greedy algorithm makes the locally optimal choice at each step, hoping that these choices produce a globally optimal solution.

Typical Greedy Strategy

  1. Sort or prioritize available choices when necessary.
  2. Select the best currently feasible choice.
  3. Update the problem state.
  4. Repeat until the problem is complete.

When Does Greedy Work?

  • Greedy-choice property: A globally optimal solution can be constructed by making a locally optimal choice.
  • Optimal substructure: An optimal solution contains optimal solutions to its subproblems.
A greedy strategy needs a correctness argument. Passing a few sample inputs does not prove that greedy choices always produce an optimal answer.

3. Activity Selection Problem

Given activities with start and finish times, select the maximum number of mutually non-overlapping activities.

Greedy strategy: sort activities by finish time and repeatedly select the next activity whose start time is at least the finish time of the last selected activity.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct { int start; int finish; } Activity; int compareActivities(const void *a, const void *b) { const Activity *x = a; const Activity *y = b; if (x->finish < y->finish) return -1; if (x->finish > y->finish) return 1; return 0; } int main(void) { Activity activities[] = { {1, 3}, {2, 5}, {4, 6}, {6, 7}, {5, 8}, {8, 9} }; int n = sizeof(activities) / sizeof(activities[0]); qsort(activities, n, sizeof(Activity), compareActivities); int selected = 0; int lastFinish = 0; printf("Selected activities:\n"); for (int i = 0; i < n; i++) { if (selected == 0 || activities[i].start >= lastFinish) { printf("(%d, %d)\n", activities[i].start, activities[i].finish); lastFinish = activities[i].finish; selected++; } } printf("Maximum activities = %d\n", selected); return 0; }

Expected Output

Selected activities: (1, 3) (4, 6) (6, 7) (8, 9) Maximum activities = 4

Time: O(n log n) for sorting plus O(n) selection. Auxiliary space: Depends on the sorting implementation; the selection scan uses O(1).

4. Fractional Knapsack

In fractional knapsack, an item may be divided. Select items in decreasing order of value-to-weight ratio.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> typedef struct { double weight; double value; } Item; int compareRatio(const void *a, const void *b) { const Item *x = a; const Item *y = b; double r1 = x->value / x->weight; double r2 = y->value / y->weight; if (r1 > r2) return -1; if (r1 < r2) return 1; return 0; } int main(void) { Item items[] = { {10, 60}, {20, 100}, {30, 120} }; int n = sizeof(items) / sizeof(items[0]); double capacity = 50.0; double totalValue = 0.0; qsort(items, n, sizeof(Item), compareRatio); for (int i = 0; i < n && capacity > 0; i++) { if (items[i].weight <= capacity) { capacity -= items[i].weight; totalValue += items[i].value; } else { double fraction = capacity / items[i].weight; totalValue += fraction * items[i].value; capacity = 0; } } printf("Maximum value = %.2f\n", totalValue); return 0; }

Expected Output

Maximum value = 240.00

Time: O(n log n). Auxiliary space: Sorting-dependent.

Fractional Knapsack is solved optimally using the ratio-based greedy strategy. The same strategy does not solve 0/1 Knapsack optimally because items cannot be divided.

5. Minimum Number of Platforms

Given train arrival and departure times, determine the minimum number of platforms needed so that no train waits for an occupied platform.

Greedy strategy: sort arrival and departure times separately, then use two pointers to track simultaneous trains.

Complete C11 Program

#include <stdio.h> #include <stdlib.h> int compareInt(const void *a, const void *b) { int x = *(const int *)a; int y = *(const int *)b; return (x > y) - (x < y); } int main(void) { int arrival[] = {900, 940, 950, 1100, 1500, 1800}; int departure[] = {910, 1200, 1120, 1130, 1900, 2000}; int n = sizeof(arrival) / sizeof(arrival[0]); qsort(arrival, n, sizeof(int), compareInt); qsort(departure, n, sizeof(int), compareInt); int i = 0; int j = 0; int current = 0; int maximum = 0; while (i < n) { if (j == n || arrival[i] <= departure[j]) { current++; if (current > maximum) maximum = current; i++; } else { current--; j++; } } printf("Minimum platforms = %d\n", maximum); return 0; }

Expected Output

Minimum platforms = 3

Time: O(n log n). Auxiliary space: Sorting-dependent.

7. Dynamic Programming Fundamentals

Dynamic Programming (DP) solves problems by breaking them into overlapping subproblems and storing their results.

Two Main Properties

  • Overlapping subproblems: The same smaller problem is solved repeatedly.
  • Optimal substructure: The solution can be constructed from solutions to smaller subproblems.

Two Implementation Methods

MemoizationTabulation
Top-down approach.Bottom-up approach.
Starts with recursion.Starts from base cases.
Stores results in a cache.Stores results in a table.
Computes states when needed.Usually computes states in a planned order.
Uses recursion stack.Can avoid recursion stack.

DP Problem-Solving Framework

  1. Define the state.
  2. Write the recurrence relation.
  3. Identify base cases.
  4. Determine the order of computation.
  5. Calculate time and space complexity.
  6. Optimize memory if possible.

8. Fibonacci – Recursion, Memoization and Tabulation

Fibonacci recurrence:

F(n) = F(n-1) + F(n-2), with F(0) = 0 and F(1) = 1.

Complete C11 Program – Memoization

#include <stdio.h> #define MAX_N 90 unsigned long long memo[MAX_N + 1]; int computed[MAX_N + 1]; unsigned long long fib(int n) { if (n <= 1) return (unsigned long long)n; if (computed[n]) return memo[n]; memo[n] = fib(n - 1) + fib(n - 2); computed[n] = 1; return memo[n]; } int main(void) { int n = 10; if (n < 0 || n > MAX_N) return 1; printf("Fibonacci(%d) = %llu\n", n, fib(n)); return 0; }

Expected Output

Fibonacci(10) = 55

Complete C11 Program – Space-Optimized Tabulation

#include <stdio.h> int main(void) { int n = 10; if (n < 0 || n > 90) return 1; unsigned long long previous = 0; unsigned long long current = 1; if (n == 0) { printf("Fibonacci(%d) = 0\n", n); return 0; } for (int i = 2; i <= n; i++) { unsigned long long next = previous + current; previous = current; current = next; } printf("Fibonacci(%d) = %llu\n", n, current); return 0; }

Expected Output

Fibonacci(10) = 55
MethodTimeAuxiliary Space
Naive recursionO(2ⁿ) upper boundO(n)
MemoizationO(n)O(n)
TabulationO(n)O(n)
Space optimizedO(n)O(1)

9. Climbing Stairs

You can climb either one or two steps at a time. Find the number of distinct ways to reach step n.

Recurrence: ways(n) = ways(n-1) + ways(n-2).

Complete C11 Program

#include <stdio.h> unsigned long long countWays(int n) { if (n <= 1) return 1; unsigned long long previous = 1; unsigned long long current = 2; for (int i = 3; i <= n; i++) { unsigned long long next = previous + current; previous = current; current = next; } return current; } int main(void) { int n = 5; if (n < 0 || n > 90) return 1; printf("Ways to climb %d stairs = %llu\n", n, countWays(n)); return 0; }

Expected Output

Ways to climb 5 stairs = 8

Time: O(n). Auxiliary space: O(1).

10. House Robber

Given the money in each house, maximize the amount robbed without selecting two adjacent houses.

DP recurrence:

dp[i] = max(dp[i-1], dp[i-2] + money[i]).

Complete C11 Program – O(1) Space

#include <stdio.h> long long max(long long a, long long b) { return a > b ? a : b; } long long rob(const int money[], int n) { long long previousTwo = 0; long long previousOne = 0; for (int i = 0; i < n; i++) { long long take = previousTwo + money[i]; long long skip = previousOne; long long current = max(take, skip); previousTwo = previousOne; previousOne = current; } return previousOne; } int main(void) { int money[] = {2, 7, 9, 3, 1}; int n = sizeof(money) / sizeof(money[0]); printf("Maximum money = %lld\n", rob(money, n)); return 0; }

Expected Output

Maximum money = 12

Time: O(n). Auxiliary space: O(1).

11. Coin Change – Minimum Number of Coins

Given coin denominations and an amount, find the minimum number of coins required. Each denomination can be used unlimited times.

Complete C11 Program

#include <stdio.h> #include <limits.h> #define MAX_AMOUNT 10000 #define MAX_COINS 100 int main(void) { int coins[] = {1, 2, 5}; int n = sizeof(coins) / sizeof(coins[0]); int amount = 11; int dp[MAX_AMOUNT + 1]; if (amount < 0 || amount > MAX_AMOUNT || n > MAX_COINS) return 1; for (int i = 0; i < n; i++) { if (coins[i] <= 0) return 1; } for (int i = 0; i <= amount; i++) dp[i] = INT_MAX; dp[0] = 0; for (int i = 1; i <= amount; i++) { for (int j = 0; j < n; j++) { if (coins[j] <= i && dp[i - coins[j]] != INT_MAX) { int candidate = dp[i - coins[j]] + 1; if (candidate < dp[i]) dp[i] = candidate; } } } if (dp[amount] == INT_MAX) printf("Amount cannot be formed.\n"); else printf("Minimum coins = %d\n", dp[amount]); return 0; }

Expected Output

Minimum coins = 3

The selected coins are 5 + 5 + 1.

Time: O(amount × number of denominations). Space: O(amount).

12. 0/1 Knapsack

In 0/1 Knapsack, each item can be selected at most once. The objective is to maximize value without exceeding capacity.

Complete C11 Program – One-Dimensional DP

#include <stdio.h> #define MAX_CAPACITY 1000 #define MAX_ITEMS 100 int max(int a, int b) { return a > b ? a : b; } int main(void) { int weight[] = {1, 3, 4, 5}; int value[] = {1, 4, 5, 7}; int n = sizeof(weight) / sizeof(weight[0]); int capacity = 7; int dp[MAX_CAPACITY + 1] = {0}; if (n > MAX_ITEMS || capacity < 0 || capacity > MAX_CAPACITY) return 1; for (int i = 0; i < n; i++) { if (weight[i] <= 0 || value[i] < 0) return 1; } for (int i = 0; i < n; i++) { for (int w = capacity; w >= weight[i]; w--) { int candidate = value[i] + dp[w - weight[i]]; dp[w] = max(dp[w], candidate); } } printf("Maximum value = %d\n", dp[capacity]); return 0; }

Expected Output

Maximum value = 9

Time: O(n × capacity). Space: O(capacity).

The capacity loop runs backward in 0/1 Knapsack so that an item cannot be reused during the same iteration. For unbounded knapsack, the capacity loop generally runs forward.

13. Longest Common Subsequence (LCS)

The Longest Common Subsequence is the longest sequence appearing in both strings in the same relative order. Characters do not need to be contiguous.

Recurrence

  • If characters match: dp[i][j] = 1 + dp[i-1][j-1].
  • Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).

Complete C11 Program

#include <stdio.h> #include <string.h> #define MAX_LENGTH 100 int max(int a, int b) { return a > b ? a : b; } int main(void) { char a[] = "ABCBDAB"; char b[] = "BDCABA"; int m = (int)strlen(a); int n = (int)strlen(b); int dp[MAX_LENGTH + 1][MAX_LENGTH + 1] = {0}; if (m > MAX_LENGTH || n > MAX_LENGTH) return 1; for (int i = 1; i <= m; i++) { for (int j = 1; j <= n; j++) { if (a[i - 1] == b[j - 1]) { dp[i][j] = 1 + dp[i - 1][j - 1]; } else { dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); } } } printf("LCS length = %d\n", dp[m][n]); return 0; }

Expected Output

LCS length = 4

Time: O(mn). Space: O(mn).

14. Longest Increasing Subsequence (LIS)

The LIS is the longest subsequence in which each selected element is strictly greater than the previous selected element.

Complete C11 Program – O(n²) DP

#include <stdio.h> #define MAX_N 100 int max(int a, int b) { return a > b ? a : b; } int main(void) { int arr[] = {10, 9, 2, 5, 3, 7, 101, 18}; int n = sizeof(arr) / sizeof(arr[0]); int dp[MAX_N]; int answer = 0; if (n > MAX_N || n == 0) return 1; for (int i = 0; i < n; i++) { dp[i] = 1; for (int j = 0; j < i; j++) { if (arr[j] < arr[i]) dp[i] = max(dp[i], dp[j] + 1); } answer = max(answer, dp[i]); } printf("LIS length = %d\n", answer); return 0; }

Expected Output

LIS length = 4

Time: O(n²). Space: O(n).

An optimized LIS algorithm uses binary search and runs in O(n log n). Its maintained tail array is not necessarily the actual LIS sequence; reconstructing the sequence requires additional predecessor information.

15. Grid-Based Dynamic Programming

Grid DP commonly calculates the number of paths or minimum path cost from one cell to another.

Unique Paths – Complete C11 Program

Move only right or down from the top-left cell to the bottom-right cell.

#include <stdio.h> #define ROWS 10 #define COLS 10 int main(void) { int rows = 3; int cols = 3; unsigned long long dp[ROWS][COLS] = {0}; if (rows <= 0 || cols <= 0 || rows > ROWS || cols > COLS) return 1; dp[0][0] = 1; for (int i = 0; i < rows; i++) { for (int j = 0; j < cols; j++) { if (i > 0) dp[i][j] += dp[i - 1][j]; if (j > 0) dp[i][j] += dp[i][j - 1]; } } printf("Unique paths = %llu\n", dp[rows - 1][cols - 1]); return 0; }

Expected Output

Unique paths = 6

Time: O(rows × columns). Space: O(rows × columns).

18. Common Interview Mistakes

  • Assuming every optimization problem can be solved greedily.
  • Using fractional knapsack logic for 0/1 knapsack.
  • Sorting by the wrong property in interval problems.
  • Forgetting to define the DP state clearly.
  • Writing a recurrence without checking base cases.
  • Using the wrong iteration direction in one-dimensional knapsack.
  • Confusing subsequence with substring.
  • Ignoring integer overflow in DP values.
  • Using excessive memory when only previous states are required.
  • Assuming all coin systems can be solved optimally by selecting the largest coin first.
  • Forgetting whether the DP objective is minimum, maximum, count or feasibility.

19. Interview Questions and Answers

Q1. What is a greedy algorithm?

An algorithm that repeatedly makes a locally optimal feasible choice.

Q2. Does greedy always produce an optimal answer?

No. It works only when the problem has the required greedy-choice property and an appropriate correctness argument.

Q3. What is the difference between fractional and 0/1 knapsack?

Fractional knapsack allows partial items; 0/1 knapsack requires taking or rejecting each complete item.

Q4. What are overlapping subproblems?

The same smaller subproblems are encountered repeatedly during computation.

Q5. What is optimal substructure?

A problem has optimal substructure when its optimal solution can be built from optimal solutions to smaller subproblems.

Q6. What is memoization?

A top-down DP technique that stores results of recursive calls.

Q7. What is tabulation?

A bottom-up DP technique that calculates states in dependency order.

Q8. Why does 0/1 Knapsack use a backward capacity loop?

To prevent the current item from being reused within the same item iteration.

Q9. What is the time complexity of standard LCS DP?

O(mn), where m and n are the lengths of the two strings.

Q10. What is the difference between LIS and LCS?

LIS finds an increasing subsequence within one sequence. LCS finds a common subsequence between two sequences.

Q11. Can the coin change problem always be solved greedily?

No. Greedy works for some special coin systems, but dynamic programming is the general method for arbitrary positive denominations.

Q12. What is space optimization in DP?

Reducing stored states by retaining only the values required for future transitions.

23. Lesson Summary

  • Greedy algorithms make locally optimal choices and require a correctness proof.
  • Activity Selection and Fractional Knapsack are standard greedy problems.
  • Dynamic Programming stores solutions to overlapping subproblems.
  • Memoization is top-down; tabulation is bottom-up.
  • Fibonacci, Climbing Stairs and House Robber are common one-dimensional DP problems.
  • Knapsack, Coin Change, LCS and LIS are important placement problems.
  • Grid DP solves path and cost problems on two-dimensional grids.
  • Space optimization can reduce memory without changing the recurrence.
