1. Introduction to STL Algorithms

The C++ Standard Library provides algorithms that perform common operations on ranges of elements. Most of these algorithms are available through the <algorithm> header.

They work with iterators, which allows the same algorithm to operate on different containers such as vector, array, deque and list, provided the iterator requirements are satisfied. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {40, 10, 30, 20};

    sort(numbers.begin(), numbers.end());

    for (int value : numbers) {
        cout << value << " ";
    }

    return 0;
}

Output:

10 20 30 40

2. sort() – Sorting Elements

The sort() algorithm arranges elements in ascending order by default. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {50, 10, 40, 20, 30};

    sort(arr.begin(), arr.end());

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}

Output:

10 20 30 40 50

Complexity: O(N log N) comparisons in the general case for the standard sorting algorithm.

Descending Order

sort(arr.begin(), arr.end(), greater<int>());

Sort Only a Range

vector<int> arr = {50, 40, 30, 20, 10};

// Sort elements from index 1 to index 3.
// The second iterator is exclusive.
sort(arr.begin() + 1, arr.begin() + 4);

// Result: 50 20 30 40 10
The second iterator passed to sort() is exclusive. The algorithm sorts the half-open range [first, last).

3. reverse() – Reverse a Range

The reverse() algorithm reverses the order of elements in a specified range. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 20, 30, 40, 50};

    reverse(arr.begin(), arr.end());

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}

Output:

50 40 30 20 10

Time complexity: O(N).

4. find() – Search for an Element

The find() algorithm searches a range and returns an iterator to the first matching element. If no match exists, it returns the end iterator. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 20, 30, 40};

    auto it = find(arr.begin(), arr.end(), 30);

    if (it != arr.end())
        cout << "Found at index: "
             << (it - arr.begin());
    else
        cout << "Not found";

    return 0;
}

Time complexity: O(N).

The iterator subtraction in this example works because vector provides random-access iterators. For a list, use distance(arr.begin(), it) instead.

5. count() and count_if()

5.1 count()

Counts how many times a particular value occurs.

vector<int> arr = {10, 20, 10, 30, 10};

int result = count(arr.begin(), arr.end(), 10);

cout << result;  // 3

5.2 count_if()

Counts elements satisfying a condition.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 15, 20, 25, 30};

    int result = count_if(
        arr.begin(),
        arr.end(),
        [](int x) {
            return x % 2 == 0;
        }
    );

    cout << "Even elements: " << result;

    return 0;
}

Output:

Even elements: 3

Time complexity: O(N) for both algorithms.

6. min_element() and max_element()

These algorithms return iterators pointing to the minimum and maximum elements in a non-empty range. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {45, 10, 80, 20, 60};

    auto minIt = min_element(arr.begin(), arr.end());
    auto maxIt = max_element(arr.begin(), arr.end());

    cout << "Minimum: " << *minIt << endl;
    cout << "Maximum: " << *maxIt << endl;

    return 0;
}

Output:

Minimum: 10
Maximum: 80

Time complexity: O(N).

Check that the range is not empty before dereferencing the returned iterator. For an empty range, the result equals the end iterator.

7. min(), max() and swap()

These functions operate on individual values.

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a = 10;
    int b = 25;

    cout << min(a, b) << endl;
    cout << max(a, b) << endl;

    swap(a, b);

    cout << "After swapping: "
         << a << " " << b;

    return 0;
}

Output:

10
25
After swapping: 25 10

8. accumulate() – Sum of Elements

The accumulate() function is available in <numeric>. It calculates the accumulated result of a range, commonly used to find the sum. 

#include <iostream>
#include <vector>
#include <numeric>
using namespace std;

int main() {
    vector<int> arr = {10, 20, 30, 40};

    int total = accumulate(
        arr.begin(),
        arr.end(),
        0
    );

    cout << "Sum: " << total;

    return 0;
}

Output:

Sum: 100

Time complexity: O(N).

The initial value determines the accumulator type. For potentially large integer sums, use 0LL to accumulate into a long long value and reduce the risk of 32-bit overflow. 
long long total = accumulate(
    arr.begin(),
    arr.end(),
    0LL
);

9. Binary Search Algorithms

Binary-search-based STL algorithms require the input range to be partitioned with respect to the search condition. In typical placement problems, this means sorting the data first.

9.1 binary_search()

Returns true if the searched value exists in the sorted range.

vector<int> arr = {10, 20, 30, 40, 50};

bool found = binary_search(
    arr.begin(),
    arr.end(),
    30
);

cout << found;  // 1 (true)

9.2 lower_bound()

Returns an iterator to the first element that is not less than the given value. 

vector<int> arr = {10, 20, 20, 30, 40};

auto it = lower_bound(
    arr.begin(),
    arr.end(),
    20
);

cout << (it - arr.begin());  // 1

9.3 upper_bound()

Returns an iterator to the first element that is greater than the given value. 

auto it = upper_bound(
    arr.begin(),
    arr.end(),
    20
);

cout << (it - arr.begin());  // 3

9.4 equal_range()

Returns a pair of iterators representing the range of elements equivalent to the given value. 

auto range = equal_range(
    arr.begin(),
    arr.end(),
    20
);

int first = range.first - arr.begin();
int last  = range.second - arr.begin();

cout << first << " " << last;
// 1 3

Typical complexity with random-access iterators:

  • binary_search(): O(log N)
  • lower_bound(): O(log N)
  • upper_bound(): O(log N)
  • equal_range(): O(log N) comparisons

For non-random-access iterators, such as list iterators, these algorithms can perform O(N) iterator increments even though the number of comparisons is logarithmic.

10. unique() – Remove Consecutive Duplicates

The unique() algorithm moves consecutive duplicate elements to the end of the logical range and returns an iterator marking the new logical end. It does not physically reduce the container's size. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 10, 20, 20, 30, 30};

    auto newEnd = unique(arr.begin(), arr.end());

    arr.erase(newEnd, arr.end());

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}

Output:

10 20 30

Time complexity: O(N).

To remove all duplicates from an unsorted vector, sort it first and then apply unique() followed by erase().

11. remove() and erase-remove Idiom

The remove() algorithm does not change the container's physical size. It rearranges retained elements and returns a new logical end. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 20, 30, 20, 40};

    arr.erase(
        remove(arr.begin(), arr.end(), 20),
        arr.end()
    );

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}

Output:

10 30 40

Time complexity: O(N).

This pattern is called the erase-remove idiom. In C++20, the non-member std::erase() function can simplify removal from standard containers that support it.

12. for_each() – Apply an Operation to Each Element

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {1, 2, 3, 4};

    for_each(
        arr.begin(),
        arr.end(),
        [](int x) {
            cout << x * x << " ";
        }
    );

    return 0;
}

Output:

1 4 9 16

Time complexity: O(N) when the supplied operation takes constant time per element.

13. all_of(), any_of() and none_of()

These algorithms test whether elements satisfy a condition. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {2, 4, 6, 8};

    bool allEven = all_of(
        arr.begin(), arr.end(),
        [](int x) { return x % 2 == 0; }
    );

    bool anyOdd = any_of(
        arr.begin(), arr.end(),
        [](int x) { return x % 2 != 0; }
    );

    bool noneNegative = none_of(
        arr.begin(), arr.end(),
        [](int x) { return x < 0; }
    );

    cout << allEven << endl;
    cout << anyOdd << endl;
    cout << noneNegative << endl;

    return 0;
}

Output:

1
0
1
  • all_of(): true if every element satisfies the condition.
  • any_of(): true if at least one element satisfies the condition.
  • none_of(): true if no element satisfies the condition.

14. partition() and stable_partition()

These algorithms rearrange elements so that those satisfying a predicate appear before those that do not. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {1, 2, 3, 4, 5, 6};

    partition(
        arr.begin(),
        arr.end(),
        [](int x) {
            return x % 2 == 0;
        }
    );

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}

Even numbers are placed before odd numbers, but the relative order within each group is not guaranteed by partition().

stable_partition() preserves the relative order of elements within both groups.

15. nth_element() – Find the Kth Position

The nth_element() algorithm rearranges a range so that the element at the selected position is the same element that would occupy that position in a fully sorted range.

Elements before it are not greater than it, and elements after it are not less than it, according to the comparator. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {7, 2, 9, 1, 5, 3};

    nth_element(
        arr.begin(),
        arr.begin() + 2,
        arr.end()
    );

    cout << "Third smallest: "
         << arr[2];

    return 0;
}

Output:

Third smallest: 3

The value at index 2 is the third smallest element. The remaining elements are not necessarily fully sorted.

Typical average complexity: O(N).

16. Custom Comparators

A comparator defines how elements should be ordered. It is useful when sorting structures, pairs or objects according to custom rules.

16.1 Sorting in Descending Order

sort(
    arr.begin(),
    arr.end(),
    [](int a, int b) {
        return a > b;
    }
);

16.2 Sorting Pairs

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<pair<int, int>> values = {
        {2, 50},
        {1, 70},
        {3, 40},
        {1, 30}
    };

    sort(
        values.begin(),
        values.end(),
        [](const auto& a, const auto& b) {
            if (a.first != b.first)
                return a.first < b.first;

            return a.second < b.second;
        }
    );

    for (const auto& p : values) {
        cout << p.first << " "
             << p.second << endl;
    }

    return 0;
}

Output:

1 30
1 70
2 50
3 40
A comparator used by sorting algorithms must establish a strict weak ordering. Do not use a <= b as a sorting comparator. Use a < b instead.

17. Lambda Expressions

A lambda expression creates an anonymous function. It is frequently used with STL algorithms to define conditions and custom behavior. 

[](parameters) {
    // Statements
}

Example:

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 15, 20, 25, 30};

    int count = count_if(
        arr.begin(),
        arr.end(),
        [](int x) {
            return x > 15;
        }
    );

    cout << count;

    return 0;
}

Output:

3

Lambda Captures

[x]Capture x by value
[&x]Capture x by reference
[=]Capture used local variables by value
[&]Capture used local variables by reference

18. Useful Numeric Algorithms

The <numeric> header provides useful operations for numeric ranges.

18.1 iota()

Fills a range with consecutive values starting from a given value.

#include <iostream>
#include <vector>
#include <numeric>
using namespace std;

int main() {
    vector<int> arr(5);

    iota(arr.begin(), arr.end(), 1);

    for (int x : arr)
        cout << x << " ";

    return 0;
}

Output: 1 2 3 4 5

18.2 partial_sum()

Calculates cumulative sums.

vector<int> arr = {1, 2, 3, 4};
vector<int> prefix(arr.size());

partial_sum(
    arr.begin(),
    arr.end(),
    prefix.begin()
);

// prefix: 1 3 6 10

18.3 adjacent_difference()

Calculates differences between adjacent elements.

vector<int> arr = {2, 5, 9, 14};
vector<int> result(arr.size());

adjacent_difference(
    arr.begin(),
    arr.end(),
    result.begin()
);

// result: 2 3 4 5

21. Practical Placement Program: Second Largest Distinct Element

Find the second largest distinct element in an array using STL. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 50, 30, 50, 40};

    sort(arr.begin(), arr.end());

    auto it = unique(arr.begin(), arr.end());
    arr.erase(it, arr.end());

    if (arr.size() < 2) {
        cout << "Second largest does not exist";
    } else {
        cout << "Second largest: "
             << arr[arr.size() - 2];
    }

    return 0;
}

Output:

Second largest: 40

Time complexity: O(N log N).

Space complexity: Depends on sorting implementation; the vector itself uses O(N) storage.

An optimized one-pass solution can solve this problem in O(N) time and O(1) extra space. Interviewers may ask you to improve the STL solution.

25. Lesson Summary

  • STL algorithms operate on iterator ranges.
  • sort() arranges elements in a specified order.
  • find() and count() perform linear scans.
  • lower_bound() and upper_bound() support binary-search operations.
  • accumulate() calculates accumulated values.
  • unique() and remove() require erase when physical container size must shrink.
  • Custom comparators define ordering rules.
  • Lambda expressions provide short callable functions.
  • nth_element() is useful for Kth-order statistics.
  • STL algorithms help solve placement coding problems efficiently.
