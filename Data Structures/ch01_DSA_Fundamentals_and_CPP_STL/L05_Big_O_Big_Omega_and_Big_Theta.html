Lesson 5: Big O, Big Omega and Big Theta

Understand asymptotic notation, mathematical growth rates and how to describe algorithm efficiency in technical interviews.

1. Introduction to Asymptotic Notation

Asymptotic notation is a mathematical method used to describe how an algorithm's resource requirements grow as the input size becomes large.

It helps compare algorithms without depending on a particular computer, programming language or execution time.

The three fundamental asymptotic notations are:

  • Big O — O(g(N)): Asymptotic upper bound.
  • Big Omega — Ω(g(N)): Asymptotic lower bound.
  • Big Theta — Θ(g(N)): Asymptotically tight bound.
Big O is commonly used when discussing worst-case complexity, but mathematically it is an upper-bound notation. It does not automatically mean worst case. Similarly, Omega and Theta describe bounds, not particular input cases.

2. Big O Notation — O(g(N))

Big O describes an asymptotic upper bound on a function's growth.

Informally, if an algorithm requires no more than a constant multiple of a function g(N), for sufficiently large N, its growth is O(g(N)).

Formal Definition

A function f(N) belongs to O(g(N)) if there exist positive constants C and N₀ such that:

0 ≤ f(N) ≤ C × g(N)

for every N ≥ N₀.

Here:

  • f(N) represents the function being analyzed.
  • g(N) represents the comparison growth function.
  • C is a positive constant multiplier.
  • N₀ is the threshold beyond which the bound holds.

Example 1: f(N) = 3N + 5

We want to prove that:

f(N) = O(N)

For N ≥ 1:

3N + 5 ≤ 3N + 5N

3N + 5 ≤ 8N

Choose C = 8 and N₀ = 1.

Therefore:

3N + 5 = O(N)

Example 2: f(N) = 4N² + 3N + 10

For N ≥ 1, both N and 1 are at most N².

Therefore:

4N² + 3N + 10 ≤ 4N² + 3N² + 10N²

4N² + 3N + 10 ≤ 17N²

Choose C = 17 and N₀ = 1.

Therefore, f(N) = O(N²).

Big O gives an upper bound. A function may have more than one valid Big O bound. For example, N is also O(N²), although O(N) is a tighter description of its growth.

3. Big Omega Notation — Ω(g(N))

Big Omega describes an asymptotic lower bound on a function's growth.

Informally, it means the function grows at least as fast as a constant multiple of g(N), for sufficiently large N.

Formal Definition

A function f(N) belongs to Ω(g(N)) if there exist positive constants C and N₀ such that:

0 ≤ C × g(N) ≤ f(N)

for every N ≥ N₀.

Example: f(N) = 3N² + 2N + 7

For N ≥ 1:

3N² ≤ 3N² + 2N + 7

Choose C = 3 and N₀ = 1.

Therefore:

3N² + 2N + 7 = Ω(N²)

Omega is a mathematical lower bound. It should not automatically be interpreted as best-case complexity. To discuss best-case complexity, first define the best-case operation-count function, then analyze its asymptotic bound.

4. Big Theta Notation — Θ(g(N))

Big Theta describes a tight asymptotic bound. It means the function is bounded both above and below by constant multiples of g(N).

Formal Definition

A function f(N) belongs to Θ(g(N)) if there exist positive constants C₁, C₂ and N₀ such that:

0 ≤ C₁ × g(N) ≤ f(N) ≤ C₂ × g(N)

for every N ≥ N₀.

Example: f(N) = 5N + 8

For N ≥ 1:

5N ≤ 5N + 8

Also:

5N + 8 ≤ 13N

Choose C₁ = 5, C₂ = 13 and N₀ = 1.

Therefore:

5N + 8 = Θ(N)

Θ(N) tells us that the function grows proportionally to N, within constant factors, for sufficiently large N.

5. Difference Between O, Ω and Θ

Notation Meaning Mathematical Condition
O(g(N)) Upper bound f(N) ≤ C₂g(N)
Ω(g(N)) Lower bound f(N) ≥ C₁g(N)
Θ(g(N)) Tight bound C₁g(N) ≤ f(N) ≤ C₂g(N)

All conditions apply for sufficiently large N, with positive constants and an appropriate threshold N₀.

Example: f(N) = 4N² + 6N + 2

Its tight asymptotic growth is Θ(N²).

Consequently, it is also:

  • O(N²), because N² is an upper bound.
  • Ω(N²), because N² is a lower bound.
  • Θ(N²), because N² is a tight bound.

It is also O(N³) and Ω(N), but those are looser bounds.

6. Understanding the Notations With a Simple Example

Consider the function:

f(N) = N² + 4N + 10

Its asymptotic growth is Θ(N²).

Statement Valid? Reason
f(N) = O(N²) Yes N² is an upper bound.
f(N) = Ω(N²) Yes N² is a lower bound.
f(N) = Θ(N²) Yes N² is a tight bound.
f(N) = O(N³) Yes N³ is a looser upper bound.
f(N) = Ω(N) Yes N is a looser lower bound.
f(N) = O(N) No N cannot upper-bound quadratic growth by a constant factor.
f(N) = Ω(N³) No N³ grows faster than the function.

7. Asymptotic Growth and Dominant Terms

When analyzing polynomial functions, the highest-order term generally determines asymptotic growth.

Function Tight Bound
7N + 12 Θ(N)
5N² + 3N + 9 Θ(N²)
2N³ + 8N² + 4 Θ(N³)
6N log N + 10N Θ(N log N)
4 log N + 15 Θ(log N)

Rules for Simplification

  1. Ignore constant multipliers.
  2. Ignore lower-order terms when a higher-order term dominates.
  3. Retain logarithmic factors when they affect growth.
  4. For sums, identify the dominant growth term.
Example: 8N² + 5N + 100 is Θ(N²), not Θ(N).

9. Applying Asymptotic Notation to C++ Code

Example 1: Single Loop

void display(int n)
{
    for (int i = 0; i < n; i++)
    {
        cout << i;
    }
}

The loop executes N times.

Tight bound: Θ(N)

Example 2: Two Nested Loops

void displayPairs(int n)
{
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cout << i << " " << j;
        }
    }
}

The body executes N² times.

Tight bound: Θ(N²)

Example 3: Binary Search

int binarySearch(int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return -1;
}

Each iteration reduces the remaining search interval by approximately half.

Worst-case tight bound: Θ(log N)

Binary search requires sorted data or another structure that supports the required monotonic search condition.

10. Common Misconceptions

Misconception Correct Understanding
Big O always means worst case. Big O is an upper bound; it can describe any defined case function.
Omega always means best case. Omega is a lower bound, not automatically best-case complexity.
Theta means average case. Theta means a tight asymptotic bound.
O(N²) is always worse for every input. Asymptotic comparison concerns sufficiently large input sizes.
O(N) and Θ(N) mean exactly the same thing. O(N) is an upper bound; Θ(N) is a tight bound.
Constants never matter in practical programs. Constants are ignored in asymptotic notation but can matter in actual runtime.

13. Multiple-Choice Questions

Q1. Which notation represents an asymptotic upper bound?

  1. Ω
  2. Θ
  3. O
  4. Σ

Answer: C — Big O.

Q2. Which notation represents an asymptotic lower bound?

  1. Ω
  2. O
  3. Θ
  4. Π

Answer: A — Big Omega.

Q3. Which notation represents a tight asymptotic bound?

  1. O
  2. Ω
  3. Θ
  4. None

Answer: C — Big Theta.

Q4. What is the tight bound of 5N² + 3N + 10?

  1. Θ(N)
  2. Θ(N²)
  3. Θ(N³)
  4. Θ(log N)

Answer: B — Θ(N²).

Q5. Does O(N²) necessarily mean worst-case complexity?

  1. Yes, always
  2. No, it is an upper bound
  3. It means average case
  4. It means best case

Answer: B — It is an upper bound.

Q6. If f(N) = 4N² + 2N, which statement is correct?

  1. f(N) = Θ(N)
  2. f(N) = Θ(N²)
  3. f(N) = Θ(N³)
  4. f(N) = Θ(log N)

Answer: B — Θ(N²).

14. Lesson Summary

  • Asymptotic notation describes algorithm growth for sufficiently large input sizes.
  • Big O represents an asymptotic upper bound.
  • Big Omega represents an asymptotic lower bound.
  • Big Theta represents a tight asymptotic bound.
  • Big O, Omega and Theta do not inherently specify best, average or worst cases.
  • Dominant terms determine polynomial growth.
  • Constants and lower-order terms can be ignored when simplifying asymptotic bounds.
  • Understanding these notations is essential for evaluating coding interview solutions.
