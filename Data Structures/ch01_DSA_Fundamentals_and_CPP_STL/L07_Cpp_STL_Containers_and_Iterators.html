Chapter 1: DSA Fundamentals and C++ STL

Learn to use standard data structures efficiently in coding interviews.

1. Introduction to STL

The Standard Template Library (STL) is a part of the C++ Standard Library that provides reusable components for common programming tasks.

It includes containers, iterators, algorithms and function objects. STL helps developers write shorter, reusable and efficient code instead of implementing every data structure and algorithm manually.

Example: Instead of implementing a dynamic array manually, we can use vector. Instead of writing a sorting algorithm for every problem, we can use sort().

2. Main Components of STL

This lesson concentrates on containers and iterators. STL algorithms and useful functions are covered in the next lesson.

3. Types of STL Containers

STL containers are commonly grouped into three categories.

3.1 Sequence Containers

Sequence containers store elements in a linear sequence. Their elements are organized according to their position.

  • array – fixed-size sequence container.
  • vector – dynamically resizable array.
  • deque – double-ended sequence container.
  • list – doubly linked list.
  • forward_list – singly linked list.

3.2 Associative Containers

Associative containers organize elements using keys. Standard ordered associative containers are generally implemented using balanced search trees.

  • set – stores unique sorted keys.
  • multiset – stores sorted keys with duplicates.
  • map – stores unique sorted keys with mapped values.
  • multimap – stores sorted key-value pairs with duplicate keys.

3.3 Unordered Associative Containers

These containers use hashing and do not maintain elements in sorted order.

  • unordered_set
  • unordered_multiset
  • unordered_map
  • unordered_multimap

They generally provide average constant-time lookup, insertion and removal, subject to hashing and collision behavior.

4. Vector Container

A vector is a dynamic array that can automatically increase its capacity when additional elements are inserted. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    numbers.push_back(40);
    numbers.push_back(50);

    cout << "Elements: ";

    for (int value : numbers) {
        cout << value << " ";
    }

    cout << "\nSize: " << numbers.size();
    cout << "\nCapacity: " << numbers.capacity();

    return 0;
}

Important: A vector's size is the number of elements currently stored. Its capacity is the number of elements it can hold before requiring reallocation. Capacity is always at least size.

5. Array Container

std::array is a fixed-size container. Its size is determined at compile time and it provides the convenience of standard container operations. 

#include <iostream>
#include <array>
using namespace std;

int main() {
    array<int, 5> numbers = {10, 20, 30, 40, 50};

    for (int i = 0; i < numbers.size(); i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}

Important properties:

  • Fixed number of elements.
  • Random access in O(1).
  • Contiguous memory storage.
  • Supports standard iterators and algorithms.

6. Deque Container

A deque (double-ended queue) supports efficient insertion and removal at both the front and the back. 

#include <iostream>
#include <deque>
using namespace std;

int main() {
    deque<int> dq;

    dq.push_back(20);
    dq.push_back(30);
    dq.push_front(10);

    dq.pop_front();

    for (int value : dq) {
        cout << value << " ";
    }

    return 0;
}
OperationTypical complexity
push_front()O(1)
push_back()O(1)
pop_front()O(1)
pop_back()O(1)
Random accessO(1)

Unlike vector, deque does not guarantee that all elements occupy one contiguous memory block.

7. List and Forward List

7.1 List

std::list is a doubly linked list. Each node maintains links to the previous and next nodes. 

#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> values = {10, 20, 30};

    values.push_front(5);
    values.push_back(40);

    values.remove(20);

    for (int value : values) {
        cout << value << " ";
    }

    return 0;
}
  • Insertion and removal at known positions: O(1).
  • Searching for an element: O(N).
  • No direct random access by index.
  • Each element is stored in a separate node.

7.2 Forward List

std::forward_list is a singly linked list. It stores forward links and generally uses less per-node link storage than a doubly linked list. 

#include <iostream>
#include <forward_list>
using namespace std;

int main() {
    forward_list<int> values = {10, 20, 30};

    values.push_front(5);

    for (int value : values) {
        cout << value << " ";
    }

    return 0;
}

8. Set and Multiset

8.1 Set

A set stores unique elements in sorted order. 

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {30, 10, 20, 10, 40};

    numbers.insert(50);
    numbers.erase(20);

    for (int value : numbers) {
        cout << value << " ";
    }

    return 0;
}

Output:

10 30 40 50

Duplicate values are not stored. Search, insertion and deletion generally take O(log N).

8.2 Multiset

A multiset stores sorted elements but permits duplicates. 

#include <iostream>
#include <set>
using namespace std;

int main() {
    multiset<int> numbers = {10, 20, 10, 30, 20};

    for (int value : numbers) {
        cout << value << " ";
    }

    return 0;
}

Output:

10 10 20 20 30

9. Map and Multimap

9.1 Map

A map stores key-value pairs. Keys are unique and ordered according to the map's comparison function. 

#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int, string> students;

    students[101] = "Aman";
    students[102] = "Riya";
    students[103] = "Karan";

    for (const auto& item : students) {
        cout << item.first << " "
             << item.second << endl;
    }

    return 0;
}

Map lookup, insertion and deletion generally take O(log N).

9.2 Multimap

A multimap allows multiple elements to have equivalent keys. 

#include <iostream>
#include <map>
using namespace std;

int main() {
    multimap<string, int> marks;

    marks.insert({"Aman", 85});
    marks.insert({"Aman", 90});
    marks.insert({"Riya", 92});

    for (const auto& item : marks) {
        cout << item.first << " "
             << item.second << endl;
    }

    return 0;
}

10. Unordered Set and Unordered Map

10.1 Unordered Set

An unordered set stores unique elements using hashing. It does not maintain sorted order. 

#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    unordered_set<int> numbers;

    numbers.insert(10);
    numbers.insert(20);
    numbers.insert(10);

    cout << "Number of unique values: "
         << numbers.size();

    return 0;
}

10.2 Unordered Map

An unordered map stores unique keys with associated values. 

#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, int> frequency;

    frequency["apple"]++;
    frequency["banana"]++;
    frequency["apple"]++;

    for (const auto& item : frequency) {
        cout << item.first << " "
             << item.second << endl;
    }

    return 0;
}

Average lookup, insertion and removal are O(1), but worst-case operations can be O(N) due to collisions.

12. What Are Iterators?

An iterator is an object that provides a way to access elements stored in a container. Iterators allow STL algorithms to work with different container types through a common interface.

An iterator behaves similarly to a pointer in many common operations. The dereference operator * accesses the element, while incrementing an iterator moves it to the next position. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    vector<int>::iterator it;

    for (it = numbers.begin();
         it != numbers.end(); ++it) {

        cout << *it << " ";
    }

    return 0;
}

Output:

10 20 30 40

13. begin() and end()

  • begin() returns an iterator to the first element.
  • end() returns an iterator to the position just after the last element.
vector<int> numbers = {10, 20, 30};

auto first = numbers.begin();
auto last  = numbers.end();

cout << *first;  // 10

// Do not dereference end().
Important: The end iterator is a boundary marker, not an iterator to the last element. Dereferencing it is invalid. Use prev(container.end()) for the last element of a non-empty bidirectional or random-access range.

14. Types of Iterators

Iterator category Capabilities Examples
Input Read and move forward through a range Input stream iterators
Output Write and move forward through a range Output stream iterators
Forward Read/write and move forward; supports repeated traversal forward_list
Bidirectional Move forward and backward list, map, set
Random Access Jump to arbitrary positions in constant time vector, deque, array
Contiguous Random access with contiguous element storage vector, array

Contiguous iterators are a stronger category than random-access iterators. A deque supports random access but does not provide contiguous storage for all its elements.

15. Iterator Operations

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> values = {10, 20, 30, 40, 50};

    auto it = values.begin();

    cout << *it << endl;

    ++it;
    cout << *it << endl;

    it += 2;
    cout << *it << endl;

    cout << "Distance: "
         << values.end() - values.begin();

    return 0;
}

The operations it += 2 and iterator subtraction are supported by random-access iterators, such as vector iterators. They are not supported by list iterators.

16. Reverse Iterators

Reverse iterators traverse a container from its last element toward its first element. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    for (auto it = numbers.rbegin();
         it != numbers.rend(); ++it) {

        cout << *it << " ";
    }

    return 0;
}

Output:

40 30 20 10
  • rbegin() refers to the last element in reverse traversal.
  • rend() represents the position before the first element in reverse traversal.

17. const_iterator

A const_iterator allows reading elements but does not allow modifying the elements through that iterator. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    vector<int>::const_iterator it;

    for (it = numbers.cbegin();
         it != numbers.cend(); ++it) {

        cout << *it << " ";

        // *it = 100; // Not allowed
    }

    return 0;
}

The member functions cbegin() and cend() return const iterators.

18. Iterator Invalidation

An iterator becomes invalid when the container operation changes the underlying structure in a way that no longer permits its use. The rules depend on the container.

Vector Example

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> values = {10, 20, 30};

    auto it = values.begin();

    values.push_back(40);

    // If push_back caused reallocation,
    // the old iterator is invalid.
    // Do not use it here.

    for (auto current = values.begin();
         current != values.end(); ++current) {

        cout << *current << " ";
    }

    return 0;
}

Important rules:

  • Vector reallocation invalidates all iterators, pointers and references to its elements.
  • Vector insertion without reallocation can still invalidate iterators at or after the insertion position.
  • Vector erase invalidates iterators and references at or after the erased position.
  • List insertion generally preserves existing iterators.
  • List erasure invalidates iterators and references to the erased elements only.
  • Map and set insertion generally preserves existing iterators; erasure invalidates those referring to erased elements.

19. Choosing the Right Container in Coding Interviews

Problem requirement Suitable container
Dynamic array and index access vector
Fixed-size array array
Insert and remove at both ends deque
Frequent insertion/removal at known positions list
Unique sorted elements set
Key-value pairs with sorted keys map
Fast average key lookup unordered_map
Fast average membership testing unordered_set
Duplicate sorted values multiset
Duplicate keys with multiple values multimap
Placement tip: Do not select a container only because its operation is fast. Consider ordering, duplicate handling, memory layout, iterator requirements and the operations your problem performs.

20. Practical Coding Exercise: Frequency Counter

Use an unordered map to count how many times each number appears in an array. 

#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    int arr[] = {10, 20, 10, 30, 20, 10};
    int n = sizeof(arr) / sizeof(arr[0]);

    unordered_map<int, int> frequency;

    for (int i = 0; i < n; i++) {
        frequency[arr[i]]++;
    }

    for (const auto& item : frequency) {
        cout << item.first
             << " occurs "
             << item.second
             << " times" << endl;
    }

    return 0;
}

Expected frequency counts:

10 occurs 3 times
20 occurs 2 times
30 occurs 1 times

The output order can vary because unordered_map does not maintain sorted order.

Time complexity: Expected O(N) overall.

Space complexity: O(K), where K is the number of distinct values.

24. Lesson Summary

  • STL provides reusable containers, iterators and algorithms.
  • Sequence containers store elements in a sequence.
  • Associative containers maintain sorted keys.
  • Unordered containers use hashing.
  • Vector provides dynamic contiguous storage and random access.
  • List supports efficient insertion and deletion at known positions.
  • Map stores sorted key-value pairs with unique keys.
  • Unordered_map provides average constant-time lookup under suitable conditions.
  • Iterators provide a common way to traverse containers.
  • Iterator invalidation rules differ between containers.
