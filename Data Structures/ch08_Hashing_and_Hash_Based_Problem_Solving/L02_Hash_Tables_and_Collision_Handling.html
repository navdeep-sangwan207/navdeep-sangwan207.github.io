2. What Is a Hash Table?

A hash table is a data structure that stores keys or key-value pairs using a hash function to calculate the storage index.

Example

Table size = 10 Hash function = key % 10 Keys: 21, 32, 43, 54 Indexes: 21 % 10 = 1 32 % 10 = 2 43 % 10 = 3 54 % 10 = 4
Index Key 0 EMPTY 1 21 2 32 3 43 4 54 5 EMPTY 6 EMPTY 7 EMPTY 8 EMPTY 9 EMPTY

3. Why Is Collision Handling Required?

A collision occurs when two different keys generate the same hash index.

Hash function: h(key) = key % 10 Key 25: 25 % 10 = 5 Key 35: 35 % 10 = 5 Both keys map to index 5.

A hash table needs a collision resolution strategy to store both keys and retrieve them correctly.

Main Collision Handling Techniques

  1. Separate Chaining
  2. Linear Probing
  3. Quadratic Probing
  4. Double Hashing

4. Separate Chaining

Separate chaining stores multiple keys at the same hash index using a linked list or another collection.

Example

Let the hash function be:

h(key) = key % 7 Keys = 10, 17, 24, 31 10 % 7 = 3 17 % 7 = 3 24 % 7 = 3 31 % 7 = 3

All four keys are stored in a linked list at index 3.

Hash Table Index 0 -> NULL Index 1 -> NULL Index 2 -> NULL Index 3 -> 31 -> 24 -> 17 -> 10 -> NULL Index 4 -> NULL Index 5 -> NULL Index 6 -> NULL

How It Works

  • Calculate the hash index.
  • Access the linked list at that index.
  • Insert the new key into the list.
  • Search by traversing that list.
  • Delete a matching node when required.

C Program: Separate Chaining

#include <stdio.h>
#include <stdlib.h>

#define TABLE_SIZE 7

typedef struct Node
{
    int key;
    struct Node *next;
} Node;

Node *table[TABLE_SIZE] = {NULL};

int hashFunction(int key)
{
    int index = key % TABLE_SIZE;

    if (index < 0)
        index += TABLE_SIZE;

    return index;
}

int insert(int key)
{
    int index = hashFunction(key);

    Node *current = table[index];

    while (current != NULL)
    {
        if (current->key == key)
            return 0;

        current = current->next;
    }

    Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return -1;

    newNode->key = key;
    newNode->next = table[index];
    table[index] = newNode;

    return 1;
}

int search(int key)
{
    int index = hashFunction(key);
    Node *current = table[index];

    while (current != NULL)
    {
        if (current->key == key)
            return 1;

        current = current->next;
    }

    return 0;
}

int deleteKey(int key)
{
    int index = hashFunction(key);
    Node *current = table[index];
    Node *previous = NULL;

    while (current != NULL)
    {
        if (current->key == key)
        {
            if (previous == NULL)
                table[index] = current->next;
            else
                previous->next = current->next;

            free(current);
            return 1;
        }

        previous = current;
        current = current->next;
    }

    return 0;
}

void display(void)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        Node *current = table[i];

        printf("%d: ", i);

        while (current != NULL)
        {
            printf("%d -> ", current->key);
            current = current->next;
        }

        printf("NULL\n");
    }
}

void freeTable(void)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        Node *current = table[i];

        while (current != NULL)
        {
            Node *temp = current;
            current = current->next;
            free(temp);
        }

        table[i] = NULL;
    }
}

int main(void)
{
    int keys[] = {10, 17, 24, 31, 18};
    int n = (int)(sizeof keys / sizeof keys[0]);

    for (int i = 0; i < n; i++)
        insert(keys[i]);

    printf("Hash Table:\n");
    display();

    printf("\nSearch 24: %s\n",
           search(24) ? "Found" : "Not Found");

    printf("Delete 17: %s\n",
           deleteKey(17) ? "Deleted" : "Not Found");

    printf("\nAfter Deletion:\n");
    display();

    freeTable();

    return 0;
}

Expected Output

Hash Table: 0: NULL 1: NULL 2: NULL 3: 31 -> 24 -> 17 -> 10 -> NULL 4: NULL 5: NULL 6: 18 -> NULL Search 24: Found Delete 17: Deleted After Deletion: 0: NULL 1: NULL 2: NULL 3: 31 -> 24 -> 10 -> NULL 4: NULL 5: NULL 6: 18 -> NULL
This implementation uses separate chaining with insertion at the head of each linked list. Duplicate keys are rejected. It stores integer keys only; a key-value implementation can extend each node with a value field.

5. Open Addressing

Open addressing stores all entries directly inside the hash table array. When a collision occurs, the algorithm searches for another available position.

The main open addressing techniques are:

  • Linear probing
  • Quadratic probing
  • Double hashing
Unlike separate chaining, open addressing does not use a linked list for collision resolution. Each table slot holds at most one entry.

6. Linear Probing

Linear probing checks the next table position when a collision occurs.

h(key, i) = (h(key) + i) % m i = 0, 1, 2, 3, ... m = table size

Example

Table size = 7 h(key) = key % 7 Insert: 10, 17, 24, 31 10 % 7 = 3 17 % 7 = 3 -> collision Check index 4 24 % 7 = 3 -> collision Check 4 -> occupied Check 5 -> empty 31 % 7 = 3 -> collision Check 4 -> occupied Check 5 -> occupied Check 6 -> empty

Final Table

Index Key 0 EMPTY 1 EMPTY 2 EMPTY 3 10 4 17 5 24 6 31

C Program: Linear Probing

#include <stdio.h>

#define SIZE 7
#define EMPTY 0
#define OCCUPIED 1
#define DELETED 2

typedef struct
{
    int key;
    int state;
} Entry;

Entry table[SIZE];

int hashFunction(int key)
{
    int index = key % SIZE;

    if (index < 0)
        index += SIZE;

    return index;
}

int insert(int key)
{
    int start = hashFunction(key);
    int firstDeleted = -1;

    for (int i = 0; i < SIZE; i++)
    {
        int index = (start + i) % SIZE;

        if (table[index].state == OCCUPIED)
        {
            if (table[index].key == key)
                return 0;
        }
        else if (table[index].state == DELETED)
        {
            if (firstDeleted == -1)
                firstDeleted = index;
        }
        else
        {
            int target = (firstDeleted != -1)
                         ? firstDeleted : index;

            table[target].key = key;
            table[target].state = OCCUPIED;
            return 1;
        }
    }

    if (firstDeleted != -1)
    {
        table[firstDeleted].key = key;
        table[firstDeleted].state = OCCUPIED;
        return 1;
    }

    return -1;
}

int search(int key)
{
    int start = hashFunction(key);

    for (int i = 0; i < SIZE; i++)
    {
        int index = (start + i) % SIZE;

        if (table[index].state == EMPTY)
            return 0;

        if (table[index].state == OCCUPIED &&
            table[index].key == key)
            return 1;
    }

    return 0;
}

int deleteKey(int key)
{
    int start = hashFunction(key);

    for (int i = 0; i < SIZE; i++)
    {
        int index = (start + i) % SIZE;

        if (table[index].state == EMPTY)
            return 0;

        if (table[index].state == OCCUPIED &&
            table[index].key == key)
        {
            table[index].state = DELETED;
            return 1;
        }
    }

    return 0;
}

void display(void)
{
    for (int i = 0; i < SIZE; i++)
    {
        printf("%d: ", i);

        if (table[i].state == EMPTY)
            printf("EMPTY");
        else if (table[i].state == DELETED)
            printf("DELETED");
        else
            printf("%d", table[i].key);

        printf("\n");
    }
}

int main(void)
{
    int keys[] = {10, 17, 24, 31};

    for (int i = 0; i < 4; i++)
        insert(keys[i]);

    printf("Hash Table:\n");
    display();

    printf("\nSearch 24: %s\n",
           search(24) ? "Found" : "Not Found");

    printf("Delete 17: %s\n",
           deleteKey(17) ? "Deleted" : "Not Found");

    printf("\nAfter Deletion:\n");
    display();

    return 0;
}

Expected Output

Hash Table: 0: EMPTY 1: EMPTY 2: EMPTY 3: 10 4: 17 5: 24 6: 31 Search 24: Found Delete 17: Deleted After Deletion: 0: EMPTY 1: EMPTY 2: EMPTY 3: 10 4: DELETED 5: 24 6: 31
Important interview concept: In open addressing, deletion cannot simply mark a slot EMPTY. Doing so may break the search sequence for keys inserted beyond that position. A DELETED marker, also called a tombstone, preserves the probe sequence.

7. Quadratic Probing

Quadratic probing uses a quadratic function to calculate the next position after a collision.

h(key, i) = (h(key) + c1*i + c2*i*i) % m A common simplified form: h(key, i) = (h(key) + i*i) % m

Example

Table size = 11 h(key) = key % 11 Keys = 22, 33, 44 22 % 11 = 0 33 % 11 = 0 -> collision i = 1: (0 + 1*1) % 11 = 1 44 % 11 = 0 -> collision i = 1: index 1 occupied i = 2: (0 + 2*2) % 11 = 4

Final Table

Index 0 -> 22 Index 1 -> 33 Index 4 -> 44

C Program: Quadratic Probing

#include <stdio.h>

#define SIZE 11
#define EMPTY 0
#define OCCUPIED 1
#define DELETED 2

typedef struct
{
    int key;
    int state;
} Entry;

Entry table[SIZE];

int hashFunction(int key)
{
    int index = key % SIZE;

    if (index < 0)
        index += SIZE;

    return index;
}

int insert(int key)
{
    int start = hashFunction(key);
    int firstDeleted = -1;

    for (int i = 0; i < SIZE; i++)
    {
        int offset = (int)(((long long)i * i) % SIZE);
        int index = (start + offset) % SIZE;

        if (table[index].state == OCCUPIED)
        {
            if (table[index].key == key)
                return 0;
        }
        else if (table[index].state == DELETED)
        {
            if (firstDeleted == -1)
                firstDeleted = index;
        }
        else
        {
            int target = firstDeleted != -1
                         ? firstDeleted : index;

            table[target].key = key;
            table[target].state = OCCUPIED;
            return 1;
        }
    }

    if (firstDeleted != -1)
    {
        table[firstDeleted].key = key;
        table[firstDeleted].state = OCCUPIED;
        return 1;
    }

    return -1;
}

int search(int key)
{
    int start = hashFunction(key);

    for (int i = 0; i < SIZE; i++)
    {
        int offset = (int)(((long long)i * i) % SIZE);
        int index = (start + offset) % SIZE;

        if (table[index].state == EMPTY)
            return 0;

        if (table[index].state == OCCUPIED &&
            table[index].key == key)
            return 1;
    }

    return 0;
}

void display(void)
{
    for (int i = 0; i < SIZE; i++)
    {
        printf("%d: ", i);

        if (table[i].state == EMPTY)
            printf("EMPTY");
        else if (table[i].state == DELETED)
            printf("DELETED");
        else
            printf("%d", table[i].key);

        printf("\n");
    }
}

int main(void)
{
    int keys[] = {22, 33, 44};

    for (int i = 0; i < 3; i++)
        insert(keys[i]);

    printf("Quadratic Probing Table:\n");
    display();

    printf("\nSearch 44: %s\n",
           search(44) ? "Found" : "Not Found");

    return 0;
}

Expected Output

Quadratic Probing Table: 0: 22 1: 33 2: EMPTY 3: EMPTY 4: 44 5: EMPTY 6: EMPTY 7: EMPTY 8: EMPTY 9: EMPTY 10: EMPTY Search 44: Found
The simplified quadratic probe sequence does not necessarily visit every table slot for every table size. Even with an empty slot remaining, insertion may fail if that slot is not in the probe sequence. Table size and probing constants must be selected carefully.

8. Double Hashing

Double hashing uses two hash functions. The second hash function determines the step size used when resolving collisions.

h(key, i) = (h1(key) + i * h2(key)) % m Where: h1(key) = key % m h2(key) = R - (key % R) R is a positive integer smaller than m.

Example

Table size m = 11 R = 7 h1(key) = key % 11 h2(key) = 7 - (key % 7) Key = 22 h1(22) = 0 h2(22) = 6 Initial index = 0

Suppose index 0 is occupied:

i = 1 (0 + 1 * 6) % 11 = 6

The next position is index 6.

C Program: Double Hashing

#include <stdio.h>

#define SIZE 11
#define R 7
#define EMPTY 0
#define OCCUPIED 1

typedef struct
{
    int key;
    int state;
} Entry;

Entry table[SIZE];

int hash1(int key)
{
    int index = key % SIZE;

    if (index < 0)
        index += SIZE;

    return index;
}

int hash2(int key)
{
    int remainder = key % R;

    if (remainder < 0)
        remainder += R;

    return R - remainder;
}

int insert(int key)
{
    int first = hash1(key);
    int step = hash2(key);

    for (int i = 0; i < SIZE; i++)
    {
        int index = (first + i * step) % SIZE;

        if (table[index].state == OCCUPIED)
        {
            if (table[index].key == key)
                return 0;
        }
        else
        {
            table[index].key = key;
            table[index].state = OCCUPIED;
            return 1;
        }
    }

    return -1;
}

int search(int key)
{
    int first = hash1(key);
    int step = hash2(key);

    for (int i = 0; i < SIZE; i++)
    {
        int index = (first + i * step) % SIZE;

        if (table[index].state == EMPTY)
            return 0;

        if (table[index].key == key)
            return 1;
    }

    return 0;
}

void display(void)
{
    for (int i = 0; i < SIZE; i++)
    {
        printf("%d: ", i);

        if (table[i].state == EMPTY)
            printf("EMPTY");
        else
            printf("%d", table[i].key);

        printf("\n");
    }
}

int main(void)
{
    int keys[] = {22, 33, 44};

    for (int i = 0; i < 3; i++)
        insert(keys[i]);

    printf("Double Hashing Table:\n");
    display();

    printf("\nSearch 44: %s\n",
           search(44) ? "Found" : "Not Found");

    return 0;
}

Expected Output

Double Hashing Table: 0: 22 1: EMPTY 2: EMPTY 3: EMPTY 4: EMPTY 5: EMPTY 6: 33 7: EMPTY 8: 44 9: EMPTY 10: EMPTY Search 44: Found

For a table size of 11 and step sizes from 1 to 7, the step is relatively prime to the table size. This allows the probe sequence to visit every slot.

9. Clustering in Hash Tables

Primary Clustering

Primary clustering occurs in linear probing when consecutive occupied slots form long blocks. New colliding keys are likely to extend these blocks.

Example: [EMPTY] [10] [20] [30] [40] [EMPTY] A new key mapping to index 1 may extend this occupied cluster.

Secondary Clustering

Secondary clustering occurs when keys with the same initial hash index follow the same probe sequence. Quadratic probing can reduce primary clustering but may still exhibit secondary clustering.

How Double Hashing Helps

Double hashing uses a key-dependent step size, so keys with the same initial hash index can follow different probe sequences.

10. Load Factor and Resizing

Load Factor (α) = Number of stored entries / Table size

Example

Stored entries = 6 Table size = 10 α = 6 / 10 = 0.6

As a hash table fills, the probability of collisions generally increases.

Resizing a Hash Table

  1. Create a larger table.
  2. Recalculate the index for every existing key.
  3. Insert the keys into the new table.
  4. Release the old table.
Do not copy entries to the same numeric indexes during resizing. The table capacity has changed, so hash indexes must be recalculated.

11. Comparison of Collision Handling Techniques

Technique Storage Advantages Limitations
Separate Chaining Linked lists or other collections Handles multiple entries per bucket; deletion is straightforward Additional memory for links; pointer traversal
Linear Probing Array Simple; cache-friendly Primary clustering
Quadratic Probing Array Reduces primary clustering May not visit every slot
Double Hashing Array Reduces clustering compared with linear probing Requires a suitable second hash function

13. Important Interview Concepts

Why does linear probing cause primary clustering?

Because consecutive occupied positions form blocks, and new collisions can extend those blocks.

Why is deletion difficult in open addressing?

Marking a deleted position as empty can terminate searches prematurely. A tombstone marker is used instead.

Why is double hashing often preferred over linear probing?

It uses a key-dependent step size, reducing clustering caused by identical sequential probe patterns.

Can a hash table become full?

Yes. An open-addressed table cannot accept another distinct key when no usable slot remains. Separate chaining can store more entries than buckets, subject to available memory.

14. Common Mistakes

  1. Stopping a search at a DELETED slot.
  2. Marking a deleted open-addressing slot as EMPTY.
  3. Failing to check whether a key is already present.
  4. Assuming quadratic probing always visits every slot.
  5. Choosing a double-hash step that is not relatively prime to the table size.
  6. Ignoring table-full conditions.
  7. Forgetting to free dynamically allocated linked-list nodes.
  8. Resizing without recalculating hash indexes.

15. Placement Interview Questions and Answers

Q1. What is a hash table?

A data structure that stores keys or key-value pairs using hash-based indexing.

Q2. What is collision resolution?

The process of handling multiple keys that map to the same table index.

Q3. What is separate chaining?

A technique that stores colliding keys in a collection, commonly a linked list, at the same bucket.

Q4. What is open addressing?

A collision resolution method in which all entries are stored directly in the hash table array.

Q5. What is linear probing?

It checks consecutive positions until an available slot or matching key is found.

Q6. What is quadratic probing?

It checks positions based on a quadratic offset from the initial hash index.

Q7. What is double hashing?

It uses a second hash function to calculate the step size for probing.

Q8. What is primary clustering?

The formation of long consecutive occupied blocks, especially in linear probing.

Q9. What is secondary clustering?

Keys with the same initial hash index following the same probe sequence.

Q10. Which technique reduces primary clustering?

Quadratic probing and double hashing reduce primary clustering; double hashing also varies the step by key.

Q11. What is a tombstone?

A marker representing a deleted slot in an open-addressed hash table.

Q12. Why can't a deleted slot simply become empty?

Because a search for a later key in the same probe sequence could stop too early.

Q13. What is rehashing?

Rebuilding the table and reinserting its entries, often after increasing its capacity.

Q14. Can separate chaining exceed a load factor of 1?

Yes. Multiple entries can be stored in each bucket's linked list.

Q15. What is the main disadvantage of separate chaining?

It requires additional memory for links and may involve pointer traversal.

Q16. What is the main advantage of linear probing?

It is simple and uses contiguous array storage, which can improve cache locality.

Q17. Does quadratic probing always find an empty slot?

No. Its probe sequence may visit only a subset of the table positions.

Q18. What condition should double hashing satisfy?

The step size should be relatively prime to the table size to allow a full probe cycle.

Q19. What happens when an open-addressed hash table is full?

Insertion fails unless the table is resized or a deleted slot can be reused.

Q20. Which collision resolution technique is best?

There is no universally best technique. The choice depends on memory, load factor, deletion frequency, cache behavior and expected key distribution.

18. Lesson Summary

  • A hash table stores entries using hash-based indexes.
  • Collisions occur when different keys map to the same index.
  • Separate chaining uses a linked list or another collection per bucket.
  • Open addressing stores entries directly in the table.
  • Linear probing checks consecutive positions.
  • Quadratic probing uses quadratic offsets.
  • Double hashing uses a second hash function for its step size.
  • Tombstones preserve search sequences after deletion.
  • Load factor affects hash-table performance.
  • Rehashing rebuilds the table when needed.
