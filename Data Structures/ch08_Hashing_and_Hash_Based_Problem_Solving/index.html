1. Chapter Overview

Hashing is an important technique used to store and retrieve information efficiently.

It is widely used in coding interviews, database indexing, caches, symbol tables, duplicate detection, frequency counting and many real-world software applications.

In this chapter, we will understand hash functions, hash tables, collision handling techniques and their implementation using the C programming language.

2. Learning Objectives

  • Understand hashing and hash functions.
  • Understand hash tables and their internal working.
  • Learn collision handling techniques.
  • Implement hash tables using arrays and linked lists in C.
  • Understand separate chaining and open addressing.
  • Solve frequency counting and duplicate detection problems.
  • Use hashing to optimize array and string problems.
  • Analyze average-case and worst-case complexity.
  • Prepare for hashing-related placement interview questions.

Important interview areas:
