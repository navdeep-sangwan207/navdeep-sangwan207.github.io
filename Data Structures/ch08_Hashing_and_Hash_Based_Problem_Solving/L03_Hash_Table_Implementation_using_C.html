2. Hash Table Implementation Overview

In this lesson, we will implement a hash table using separate chaining.

Each table position contains a pointer to the first node of a linked list. Each node stores a key, a value and a pointer to the next node.

Node Structure

typedef struct Node { int key; int value; struct Node *next; } Node;

Hash Table Structure

typedef struct { Node *buckets[TABLE_SIZE]; } HashTable;

Conceptual Representation

Index 0 -> NULL Index 1 -> [101, 500] -> [111, 700] -> NULL Index 2 -> NULL Index 3 -> [103, 900] -> NULL Index 4 -> NULL Index 5 -> [105, 600] -> NULL

Each node represents one key-value pair.

3. Defining the Hash Function

We will use the division method.

h(key) = key % TABLE_SIZE

For negative integer keys, we normalize the remainder to obtain a valid array index.

C Function

int hashFunction(int key)
{
    int index = key % TABLE_SIZE;

    if (index < 0)
        index += TABLE_SIZE;

    return index;
}
The table size must be positive. This implementation uses a fixed table capacity to keep the focus on hash-table operations.

4. Creating the Hash Table

All bucket pointers must initially be NULL.

void initialize(HashTable *table)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        table->buckets[i] = NULL;
    }
}

Initialization prevents the program from treating uninitialized memory as valid linked-list pointers.

5. Insertion Operation

Insertion adds a key-value pair to the hash table.

Algorithm

  1. Calculate the hash index.
  2. Traverse the linked list at that index.
  3. If the key already exists, reject the duplicate.
  4. Allocate memory for a new node.
  5. Store the key and value.
  6. Insert the new node at the beginning of the list.

C Function

int insert(HashTable *table, int key, int value)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
            return 0;

        current = current->next;
    }

    Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return -1;

    newNode->key = key;
    newNode->value = value;

    newNode->next = table->buckets[index];

    table->buckets[index] = newNode;

    return 1;
}

Return Values

Return valueMeaning
1Insertion successful
0Duplicate key
-1Memory allocation failed

6. Searching Operation

Searching retrieves the value associated with a particular key.

Algorithm

  1. Calculate the hash index.
  2. Access the linked list at that index.
  3. Compare each node's key with the target key.
  4. If found, return its value through an output parameter.
  5. If the list ends, report that the key does not exist.

C Function

int search(HashTable *table, int key, int *value)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
        {
            *value = current->value;
            return 1;
        }

        current = current->next;
    }

    return 0;
}

The function returns 1 when the key exists and 0 otherwise. The value is written to the supplied output parameter only when a key is found.

7. Updating Operation

Updating changes the value associated with an existing key.

Algorithm

  1. Calculate the hash index.
  2. Traverse the linked list.
  3. Find the matching key.
  4. Replace its existing value.
  5. Return success.

C Function

int update(HashTable *table, int key, int newValue)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
        {
            current->value = newValue;
            return 1;
        }

        current = current->next;
    }

    return 0;
}
Updating an existing key does not create another node. It modifies the value in the existing node.

8. Deletion Operation

Deletion removes a key-value pair from the hash table.

Algorithm

  1. Calculate the hash index.
  2. Traverse the linked list.
  3. Find the node containing the key.
  4. Update the head pointer or previous node's next pointer.
  5. Free the allocated node.
  6. Return success.

C Function

int deleteKey(HashTable *table, int key)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];
    Node *previous = NULL;

    while (current != NULL)
    {
        if (current->key == key)
        {
            if (previous == NULL)
            {
                table->buckets[index] = current->next;
            }
            else
            {
                previous->next = current->next;
            }

            free(current);
            return 1;
        }

        previous = current;
        current = current->next;
    }

    return 0;
}
Always release the removed node using free(). Otherwise, repeated deletion and insertion can cause memory leaks.

9. Display Operation

The display function prints all buckets and their linked-list contents.

void display(HashTable *table)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        printf("%d: ", i);

        Node *current = table->buckets[i];

        while (current != NULL)
        {
            printf("[%d, %d] -> ",
                   current->key,
                   current->value);

            current = current->next;
        }

        printf("NULL\n");
    }
}

10. Releasing the Entire Hash Table

Every dynamically allocated node must be released before the program terminates.

void destroy(HashTable *table)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        Node *current = table->buckets[i];

        while (current != NULL)
        {
            Node *temp = current;
            current = current->next;

            free(temp);
        }

        table->buckets[i] = NULL;
    }
}

This function traverses every bucket, frees every node and resets the bucket pointer to NULL.

11. Complete C11 Program: Hash Table Using Separate Chaining

This program combines all operations into one complete implementation.

#include <stdio.h>
#include <stdlib.h>

#define TABLE_SIZE 10

typedef struct Node
{
    int key;
    int value;
    struct Node *next;
} Node;

typedef struct
{
    Node *buckets[TABLE_SIZE];
} HashTable;

int hashFunction(int key)
{
    int index = key % TABLE_SIZE;

    if (index < 0)
        index += TABLE_SIZE;

    return index;
}

void initialize(HashTable *table)
{
    for (int i = 0; i < TABLE_SIZE; i++)
        table->buckets[i] = NULL;
}

int insert(HashTable *table, int key, int value)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
            return 0;

        current = current->next;
    }

    Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return -1;

    newNode->key = key;
    newNode->value = value;

    newNode->next = table->buckets[index];
    table->buckets[index] = newNode;

    return 1;
}

int search(HashTable *table, int key, int *value)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
        {
            *value = current->value;
            return 1;
        }

        current = current->next;
    }

    return 0;
}

int update(HashTable *table, int key, int newValue)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];

    while (current != NULL)
    {
        if (current->key == key)
        {
            current->value = newValue;
            return 1;
        }

        current = current->next;
    }

    return 0;
}

int deleteKey(HashTable *table, int key)
{
    int index = hashFunction(key);

    Node *current = table->buckets[index];
    Node *previous = NULL;

    while (current != NULL)
    {
        if (current->key == key)
        {
            if (previous == NULL)
                table->buckets[index] = current->next;
            else
                previous->next = current->next;

            free(current);
            return 1;
        }

        previous = current;
        current = current->next;
    }

    return 0;
}

void display(HashTable *table)
{
    printf("\nHASH TABLE\n");

    for (int i = 0; i < TABLE_SIZE; i++)
    {
        printf("%d: ", i);

        Node *current = table->buckets[i];

        while (current != NULL)
        {
            printf("[%d, %d] -> ",
                   current->key,
                   current->value);

            current = current->next;
        }

        printf("NULL\n");
    }
}

void destroy(HashTable *table)
{
    for (int i = 0; i < TABLE_SIZE; i++)
    {
        Node *current = table->buckets[i];

        while (current != NULL)
        {
            Node *temp = current;
            current = current->next;
            free(temp);
        }

        table->buckets[i] = NULL;
    }
}

int main(void)
{
    HashTable table;
    int value;

    initialize(&table);

    printf("Inserting records...\n");

    printf("Insert 101: %s\n",
           insert(&table, 101, 500) == 1
           ? "Success" : "Failed");

    printf("Insert 111: %s\n",
           insert(&table, 111, 700) == 1
           ? "Success" : "Failed");

    printf("Insert 103: %s\n",
           insert(&table, 103, 900) == 1
           ? "Success" : "Failed");

    printf("Insert 105: %s\n",
           insert(&table, 105, 600) == 1
           ? "Success" : "Failed");

    printf("Insert duplicate 101: %s\n",
           insert(&table, 101, 999) == 0
           ? "Rejected" : "Unexpected result");

    display(&table);

    printf("\nSearching key 111...\n");

    if (search(&table, 111, &value))
        printf("Key found. Value = %d\n", value);
    else
        printf("Key not found.\n");

    printf("\nUpdating key 111...\n");

    if (update(&table, 111, 750))
        printf("Update successful.\n");
    else
        printf("Key not found.\n");

    printf("\nDeleting key 103...\n");

    if (deleteKey(&table, 103))
        printf("Deletion successful.\n");
    else
        printf("Key not found.\n");

    display(&table);

    destroy(&table);

    printf("\nHash table memory released.\n");

    return 0;
}

13. Complexity Analysis

OperationAverage CaseWorst Case
InsertionO(1) under suitable distributionO(n)
SearchingO(1) under suitable distributionO(n)
UpdatingO(1) under suitable distributionO(n)
DeletionO(1) under suitable distributionO(n)
DisplayO(m + n)O(m + n)

Here:

  • n = number of stored entries.
  • m = number of buckets.

For separate chaining, the expected operation cost is commonly expressed as O(1 + α), where α = n/m, assuming reasonably uniform hashing.

14. Memory Management Considerations

  • Every successful insertion allocates one node.
  • Duplicate-key insertion does not allocate another node.
  • Deletion releases the matching node.
  • Destroying the table releases all remaining nodes.
  • Failed malloc() must be handled before accessing the new node.
This implementation uses a fixed-size bucket array and dynamically allocated linked-list nodes. It does not implement automatic resizing. That is a useful next step when designing a production-style hash table.

15. Common Interview Questions and Answers

Q1. Why use a structure for a hash table node?

It groups the key, value and linked-list pointer into one logical record.

Q2. Why use separate chaining?

It allows multiple keys to be stored in the same bucket without requiring another array position.

Q3. Why insert at the head of a linked list?

Head insertion takes O(1) time once the bucket is selected.

Q4. How do you handle duplicate keys?

Search the bucket first and reject or update the existing key according to the chosen policy.

Q5. Why is malloc() used?

It allocates memory for a node dynamically while the program is running.

Q6. Why is free() required?

It releases dynamically allocated memory and prevents memory leaks.

Q7. What happens when malloc() fails?

It returns NULL. The program must handle the failure before dereferencing the pointer.

Q8. What is the role of the bucket array?

It stores the head pointer for each linked-list bucket.

Q9. Why does a hash table have worst-case O(n) lookup?

Many keys may collide and occupy one long linked list.

Q10. How can hash-table performance be improved?

Use a suitable hash function, control load factor and resize the table when appropriate.

18. Lesson Summary

  • A hash table can be implemented using an array of linked-list head pointers.
  • Each node stores a key-value pair.
  • Separate chaining handles collisions.
  • Insertion, search, update and deletion operate on the appropriate bucket.
  • malloc() allocates nodes dynamically.
  • free() releases deleted nodes and remaining table memory.
  • Average operations can be O(1) under suitable assumptions.
  • Worst-case operations can be O(n).
