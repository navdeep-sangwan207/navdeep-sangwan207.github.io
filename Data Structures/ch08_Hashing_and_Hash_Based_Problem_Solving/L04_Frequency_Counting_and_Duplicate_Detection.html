2. What Is Frequency Counting?

Frequency counting means calculating how many times each distinct element appears in a collection.

Consider this array:

int arr[] = {10, 20, 10, 30, 20, 10};

The frequency table is:

ElementFrequency
103
202
301

A hash table stores each distinct element as a key and its occurrence count as the associated value.

Important: Frequency counting is useful in array problems, string problems, duplicate detection, counting pairs and many coding-round questions.

3. Why Use Hashing for Frequency Counting?

A simple approach is to compare every element with every other element. This can require O(n²) time.

Using a hash table, we can generally count frequencies in O(n) expected time.

ApproachExpected TimeExtra Space
Nested loopsO(n²)O(1)
Hash tableO(n)O(n)
Direct count arrayO(n + R)O(R)

Here, R represents the size of the value range in a direct-address counting array.

4. Direct Frequency Array vs Hash Table

Direct frequency array

If values are known to be between 0 and 100, we can use an ordinary array:

int frequency[101] = {0};

for (int i = 0; i < n; i++) {
    frequency[arr[i]]++;
}

This method is simple and efficient when the value range is small and known.

Hash table

For arbitrary integers, including negative values and large values, a hash table is more flexible.

Interview distinction: Do not allocate a frequency array using the maximum input value when that value could be extremely large. A sparse hash table is usually more memory-efficient in that situation.

5. Hash-Based Frequency Counter in C

We will use separate chaining to store integer keys and their frequencies.

Each node contains:

  • key: The integer being counted.
  • frequency: Number of occurrences.
  • next: Pointer to the next node in the bucket.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <limits.h>
#include <stdbool.h>

#define TABLE_SIZE 101

typedef struct Node {
    int key;
    int frequency;
    struct Node *next;
} Node;

typedef struct {
    Node *bucket[TABLE_SIZE];
} HashTable;

/* Initialize all buckets */
void ht_init(HashTable *ht)
{
    for (int i = 0; i < TABLE_SIZE; i++) {
        ht->bucket[i] = NULL;
    }
}

/* Hash function supporting negative integer keys */
unsigned int hash_function(int key)
{
    uint32_t value = (uint32_t)key;

    value ^= value >> 16;
    value *= 0x7feb352dU;
    value ^= value >> 15;
    value *= 0x846ca68bU;
    value ^= value >> 16;

    return value % TABLE_SIZE;
}

/* Find a key and return its frequency */
bool ht_get(HashTable *ht, int key, int *frequency)
{
    unsigned int index = hash_function(key);
    Node *current = ht->bucket[index];

    while (current != NULL) {
        if (current->key == key) {
            *frequency = current->frequency;
            return true;
        }

        current = current->next;
    }

    return false;
}

/* Insert a new key or increment its frequency */
bool ht_increment(HashTable *ht, int key)
{
    unsigned int index = hash_function(key);
    Node *current = ht->bucket[index];

    while (current != NULL) {
        if (current->key == key) {
            if (current->frequency == INT_MAX) {
                return false;
            }

            current->frequency++;
            return true;
        }

        current = current->next;
    }

    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL) {
        return false;
    }

    newNode->key = key;
    newNode->frequency = 1;
    newNode->next = ht->bucket[index];

    ht->bucket[index] = newNode;

    return true;
}

/* Display all stored frequencies */
void ht_display(HashTable *ht)
{
    printf("\nElement Frequencies:\n");

    for (int i = 0; i < TABLE_SIZE; i++) {
        Node *current = ht->bucket[i];

        while (current != NULL) {
            printf("%d -> %d\n",
                   current->key,
                   current->frequency);

            current = current->next;
        }
    }
}

/* Free all dynamically allocated nodes */
void ht_destroy(HashTable *ht)
{
    for (int i = 0; i < TABLE_SIZE; i++) {
        Node *current = ht->bucket[i];

        while (current != NULL) {
            Node *temp = current;
            current = current->next;
            free(temp);
        }

        ht->bucket[i] = NULL;
    }
}

/* Check whether an array contains duplicates */
bool contains_duplicate(const int arr[], int n)
{
    HashTable ht;
    ht_init(&ht);

    for (int i = 0; i < n; i++) {
        int frequency;

        if (ht_get(&ht, arr[i], &frequency)) {
            ht_destroy(&ht);
            return true;
        }

        if (!ht_increment(&ht, arr[i])) {
            ht_destroy(&ht);
            return false;
        }
    }

    ht_destroy(&ht);
    return false;
}

/* Find the first element whose second occurrence appears first */
bool first_repeated(const int arr[], int n, int *answer)
{
    HashTable ht;
    ht_init(&ht);

    for (int i = 0; i < n; i++) {
        int frequency;

        if (ht_get(&ht, arr[i], &frequency)) {
            *answer = arr[i];
            ht_destroy(&ht);
            return true;
        }

        if (!ht_increment(&ht, arr[i])) {
            ht_destroy(&ht);
            return false;
        }
    }

    ht_destroy(&ht);
    return false;
}

/* Find the first element with frequency one */
bool first_non_repeating(const int arr[], int n, int *answer)
{
    HashTable ht;
    ht_init(&ht);

    for (int i = 0; i < n; i++) {
        if (!ht_increment(&ht, arr[i])) {
            ht_destroy(&ht);
            return false;
        }
    }

    for (int i = 0; i < n; i++) {
        int frequency;

        if (ht_get(&ht, arr[i], &frequency)
            && frequency == 1) {
            *answer = arr[i];
            ht_destroy(&ht);
            return true;
        }
    }

    ht_destroy(&ht);
    return false;
}

/* Find the most frequent element.
   Ties are resolved by choosing the first occurring element. */
bool most_frequent(const int arr[], int n, int *answer)
{
    HashTable ht;
    ht_init(&ht);

    int bestFrequency = 0;
    bool found = false;

    for (int i = 0; i < n; i++) {
        if (!ht_increment(&ht, arr[i])) {
            ht_destroy(&ht);
            return false;
        }

        int frequency;

        ht_get(&ht, arr[i], &frequency);

        if (frequency > bestFrequency) {
            bestFrequency = frequency;
            *answer = arr[i];
            found = true;
        }
    }

    ht_destroy(&ht);
    return found;
}

int main(void)
{
    int arr[] = {10, 20, 10, 30, 20, 10, 40};
    int n = sizeof(arr) / sizeof(arr[0]);

    HashTable ht;
    ht_init(&ht);

    /* Build frequency table */
    for (int i = 0; i < n; i++) {
        if (!ht_increment(&ht, arr[i])) {
            printf("Memory allocation or frequency error.\n");
            ht_destroy(&ht);
            return 1;
        }
    }

    printf("Input Array: ");

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    ht_display(&ht);

    ht_destroy(&ht);

    int result;

    printf("\nDuplicate Detection: %s\n",
           contains_duplicate(arr, n) ? "Yes" : "No");

    if (first_repeated(arr, n, &result)) {
        printf("First Repeated Element: %d\n", result);
    } else {
        printf("No repeated element found.\n");
    }

    if (first_non_repeating(arr, n, &result)) {
        printf("First Non-Repeating Element: %d\n", result);
    } else {
        printf("No non-repeating element found.\n");
    }

    if (most_frequent(arr, n, &result)) {
        printf("Most Frequent Element: %d\n", result);
    } else {
        printf("No result available.\n");
    }

    return 0;
}

Therefore, the first repeated element is 10.

Important distinction: The first repeated element is the element whose second occurrence is encountered earliest during a left-to-right scan. It is not necessarily the element whose first occurrence is earliest among all duplicates.

These problems use the same basic data structure but require different scanning strategies.

9. Complexity Analysis

OperationExpected TimeWorst Case
Hash insertion / incrementO(1)O(n)
Hash searchO(1)O(n)
Frequency counting of n elementsO(n)O(n²)
Duplicate detectionO(n)O(n²)
First repeated elementO(n)O(n²)
First non-repeating elementO(n)O(n²)
Most frequent elementO(n)O(n²)

For these operations, auxiliary space is O(n) in the worst case because up to n distinct keys may be stored.

The O(n) expected time assumes a reasonably distributed hash function and controlled load factor. This lesson uses a fixed-size table for clarity; a production hash table should resize as the number of entries grows.

10. Edge Cases to Test

  • Empty array: No repeated, non-repeating or most frequent element exists.
  • One element: That element is non-repeating and most frequent.
  • All elements distinct: Duplicate detection returns false.
  • All elements identical: Every element after the first is repeated.
  • Negative integers: The hash function must handle negative keys.
  • Large integer values: Avoid allocating a direct frequency array based on the maximum key.
  • Hash collisions: Different keys may map to the same bucket and must still be stored separately.
  • Memory allocation failure: Dynamic allocation must be checked before using a new node.

11. Common Interview Mistakes

  1. Using nested loops when a hash-based solution is expected.
  2. Confusing the first repeated element with the first duplicate value in sorted order.
  3. Finding the first non-repeating element by scanning only the hash table instead of the original array.
  4. Assuming that hash table entries are stored in input order.
  5. Ignoring negative values while designing the hash function.
  6. Forgetting to free dynamically allocated nodes.
  7. Assuming hashing always guarantees O(1) time, including worst-case collisions.

12. Placement Interview Questions and Answers

Q1. What is frequency counting?

Answer: Frequency counting determines how many times each distinct element occurs in a collection. A hash table can store each element as a key and its count as a value.

Q2. How can you detect duplicates efficiently?

Answer: Traverse the array and search for each element in a hash table. If it already exists, a duplicate has been found. Otherwise, insert it. Expected time complexity is O(n).

Q3. Why is hashing preferred over nested loops?

Answer: Nested-loop comparison generally takes O(n²) time, whereas hashing provides O(n) expected time for frequency counting and duplicate detection.

Q4. Can a hash table store negative integer keys?

Answer: Yes. A suitable hash function converts or maps the key to a valid non-negative bucket index while preserving key equality checks.

Q5. What happens when two keys generate the same hash index?

Answer: A collision occurs. Separate chaining stores both keys in the same bucket using a linked list. Other approaches include open addressing.

Q6. How do you find the first non-repeating element?

Answer: First count the frequency of each element using a hash table. Then scan the original array and return the first element whose frequency is one.

Q7. What is the worst-case time complexity of a hash table operation?

Answer: It can be O(n) when many keys collide into the same bucket in a table containing n keys.

Q8. When should you use a direct frequency array instead of hashing?

Answer: When the possible input values belong to a small, known range. Direct indexing is simple and has predictable O(1) access.

14. Multiple Choice Questions

Q1. Expected time complexity for counting n elements using a well-distributed hash table is:

  • A. O(1)
  • B. O(log n)
  • C. O(n)
  • D. O(n²)

Answer: C. O(n)

Q2. Which data structure is suitable for storing element-frequency pairs?

  • A. Stack
  • B. Hash table
  • C. Queue
  • D. Linked list only

Answer: B. Hash table

Q3. To find the first non-repeating element, we should:

  • A. Sort the array only
  • B. Scan only the hash buckets
  • C. Count frequencies and scan the original array
  • D. Reverse the array

Answer: C. Count frequencies and scan the original array

Q4. What is a collision?

  • A. Two keys map to the same bucket
  • B. A key is deleted
  • C. A node is freed
  • D. A table is initialized

Answer: A. Two keys map to the same bucket

Q5. Which method is suitable when the input range is small and known?

  • A. Direct frequency array
  • B. Recursion
  • C. Binary search tree only
  • D. Stack

Answer: A. Direct frequency array

15. Lesson Summary

  • Frequency counting stores occurrence counts for distinct elements.
  • Hash tables make frequency counting efficient for large or sparse value ranges.
  • Duplicate detection can be performed in O(n) expected time.
  • First repeated and first non-repeating problems require different scanning strategies.
  • Collision handling, memory allocation and cleanup are important in C implementations.
