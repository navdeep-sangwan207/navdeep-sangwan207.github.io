Chapter 11 – Heaps and Priority Queues

Lesson 1: Heap Concept and Array Representation

Understand heap data structures, complete binary trees, heap properties and array-based implementation using C.

1. Learning Objectives

  • Understand what a heap data structure is.
  • Understand complete binary trees.
  • Learn the structural properties of a heap.
  • Understand array representation of binary heaps.
  • Calculate parent, left child and right child indices.
  • Implement basic heap-related operations in C11.
  • Understand the time and space complexity of heap operations.

2. What Is a Heap?

A heap is a specialized tree-based data structure that satisfies two important properties:

  1. Structural property: It is a complete binary tree.
  2. Heap-order property: Parent nodes maintain a specific ordering relative to their children.

Heaps are generally implemented using arrays rather than dynamically allocated tree nodes.

Important: A heap is not necessarily a Binary Search Tree. It only guarantees the parent-child ordering required by its heap type.

Common applications include:

  • Priority queues
  • Heap sort
  • Kth largest and Kth smallest elements
  • Top K frequent elements
  • Graph algorithms such as Dijkstra's algorithm and Prim's algorithm

3. Complete Binary Tree

A complete binary tree is a binary tree in which:

  • Every level is completely filled except possibly the last level.
  • Nodes in the last level are filled from left to right.
  • There are no gaps between nodes at the last level.

Example of a complete binary tree:

             10
           /    \
          20     30
         /  \   /
        40  50 60

This tree is complete because the last level is filled from left to right.

Example of a tree that is not complete:

             10
           /    \
          20     30
           \    /
           50  60

This tree is not complete because a node is missing in the leftmost available position of the last level.

4. Properties of a Binary Heap

A binary heap follows these properties:

  1. It is a complete binary tree.
  2. It follows either the min-heap or max-heap ordering rule.
  3. It is usually stored in a contiguous array.
  4. The root contains the minimum or maximum element, depending on heap type.

Height of a Heap

For a heap containing n nodes, its height is O(log n).

This logarithmic height makes insertion and deletion efficient when implemented correctly.

5. Array Representation of a Heap

A complete binary tree can be stored efficiently in an array using level-order traversal.

Consider this binary tree:

             10
           /    \
          20     30
         /  \   /
        40  50 60

Its array representation is:

Index:  0   1   2   3   4   5
Value: 10  20  30  40  50  60

The array stores nodes level by level, from left to right. No explicit pointers are required to represent parent and child relationships.

Placement Tip: Memorize the zero-based indexing formulas. They are frequently tested in heap implementation and coding-round questions.

6. Parent and Child Index Formulas

For an array-based binary heap using zero-based indexing, the index formulas are:

Relationship Formula
Parent of index i (i - 1) / 2
Left child of index i 2 * i + 1
Right child of index i 2 * i + 2

Integer division is used in the parent formula. The root at index 0 has no parent.

Example

Array:

Index:  0   1   2   3   4   5
Value: 10  20  30  40  50  60

For the node at index 1:

  • Parent index = (1 - 1) / 2 = 0
  • Left child index = 2 × 1 + 1 = 3
  • Right child index = 2 × 1 + 2 = 4

Therefore:

  • Parent = 10
  • Left child = 40
  • Right child = 50

7. C Program: Display Heap Array and Relationships

This program stores a complete binary tree in an array and displays the parent and child relationships of every node. 

#include <stdio.h>

#define MAX_SIZE 100

void displayHeap(int heap[], int size)
{
    int i;

    printf("Heap Array: ");

    for (i = 0; i < size; i++)
    {
        printf("%d ", heap[i]);
    }

    printf("\n\n");
}

void displayRelationships(int heap[], int size)
{
    int i;
    int parent;
    int left;
    int right;

    for (i = 0; i < size; i++)
    {
        printf("Node: %d (Index: %d)\n", heap[i], i);

        if (i == 0)
        {
            printf("Parent: None\n");
        }
        else
        {
            parent = (i - 1) / 2;
            printf("Parent: %d\n", heap[parent]);
        }

        left = 2 * i + 1;
        right = 2 * i + 2;

        if (left < size)
        {
            printf("Left Child: %d\n", heap[left]);
        }
        else
        {
            printf("Left Child: None\n");
        }

        if (right < size)
        {
            printf("Right Child: %d\n", heap[right]);
        }
        else
        {
            printf("Right Child: None\n");
        }

        printf("\n");
    }
}

int main(void)
{
    int heap[MAX_SIZE] = {10, 20, 30, 40, 50, 60};
    int size = 6;

    displayHeap(heap, size);

    displayRelationships(heap, size);

    return 0;
}

8. C Program: Calculate Parent and Child Indices

This program accepts an array index and calculates its parent, left child and right child indices. 

#include <stdio.h>

int main(void)
{
    int size;
    int index;
    int parent;
    int left;
    int right;

    printf("Enter heap size: ");
    scanf("%d", &size);

    if (size <= 0)
    {
        printf("Invalid heap size.\n");
        return 1;
    }

    printf("Enter node index: ");
    scanf("%d", &index);

    if (index < 0 || index >= size)
    {
        printf("Invalid index.\n");
        return 1;
    }

    if (index == 0)
    {
        printf("Root node has no parent.\n");
    }
    else
    {
        parent = (index - 1) / 2;
        printf("Parent index: %d\n", parent);
    }

    left = 2 * index + 1;
    right = 2 * index + 2;

    if (left < size)
    {
        printf("Left child index: %d\n", left);
    }
    else
    {
        printf("Left child does not exist.\n");
    }

    if (right < size)
    {
        printf("Right child index: %d\n", right);
    }
    else
    {
        printf("Right child does not exist.\n");
    }

    return 0;
}

Expected Output

Enter heap size: 6
Enter node index: 1
Parent index: 0
Left child index: 3
Right child index: 4
This introductory program assumes the entered index is valid and small enough that the child-index arithmetic does not overflow an int. Production implementations should use appropriate size checks and size_t arithmetic.

9. Zero-Based vs One-Based Indexing

Heap implementations can use either zero-based or one-based indexing.

Relationship Zero-Based One-Based
Parent (i - 1) / 2 i / 2
Left child 2i + 1 2i
Right child 2i + 2 2i + 1

In this course, all heap implementations will use zero-based indexing, consistent with normal C arrays.

10. Heap vs Binary Search Tree

Feature Binary Heap Binary Search Tree
Structure Complete binary tree No completeness requirement
Ordering Parent-child ordering Left subtree and right subtree ordering
Root Minimum or maximum Depends on inserted values
Search for arbitrary key O(n) O(h)
Find minimum O(1) in min heap O(h)
Typical storage Array Linked nodes

11. Time and Space Complexity

Operation Complexity Explanation
Access root O(1) Root is at index 0.
Calculate parent index O(1) Direct arithmetic.
Calculate child indices O(1) Direct arithmetic.
Search arbitrary value O(n) No complete sorted order.
Array representation O(n) Stores n elements.

12. Common Interview Questions

Q1. What is a heap?

A heap is a complete binary tree that satisfies a heap-order property.

Q2. Why is a heap implemented using an array?

A complete binary tree has no gaps in its level-order representation, allowing parent and child relationships to be calculated directly using indices.

Q3. What is the height of a heap with n elements?

Its height is O(log n), because the tree is complete.

Q4. Can we search an arbitrary element in O(log n) in a heap?

No. A heap only guarantees parent-child ordering. Searching for an arbitrary value generally takes O(n).

Q5. What is the root of a min heap?

The smallest element.

Q6. What is the root of a max heap?

The largest element.

Q7. Is every complete binary tree a heap?

No. It must also satisfy the min-heap or max-heap ordering property.

Q1. A binary heap is always which type of tree?

A. Skewed binary tree

B. Complete binary tree

C. Binary Search Tree

D. AVL tree

Answer: B. Complete binary tree

Q2. What is the left child index of node i in a zero-based heap?

A. 2i

B. 2i + 1

C. 2i + 2

D. (i - 1) / 2

Answer: B. 2i + 1

Q3. What is the parent index of node i?

A. i / 2

B. 2i + 1

C. (i - 1) / 2

D. 2i + 2

Answer: C. (i - 1) / 2

Q4. What is the time complexity of searching an arbitrary element in a heap?

A. O(1)

B. O(log n)

C. O(n)

D. O(n log n)

Answer: C. O(n)

Q5. Which element is stored at the root of a max heap?

A. Minimum

B. Maximum

C. Median

D. Random element

Answer: B. Maximum

Q6. What is the height complexity of a binary heap?

A. O(1)

B. O(log n)

C. O(n)

D. O(n²)

Answer: B. O(log n)

Q7. Which representation is commonly used for a binary heap?

A. Array

B. Graph adjacency matrix

D. Queue only

Answer: A. Array

15. Lesson Summary

  • A heap is a complete binary tree with a heap-order property.
  • A min heap has its minimum element at the root.
  • A max heap has its maximum element at the root.
  • Heaps are commonly stored in arrays.
  • For zero-based indexing, parent = (i - 1) / 2.
  • Left child = 2i + 1.
  • Right child = 2i + 2.
  • The height of a heap is O(log n).
  • Searching an arbitrary value takes O(n).
