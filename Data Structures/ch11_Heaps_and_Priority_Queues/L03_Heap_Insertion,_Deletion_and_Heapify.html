Lesson 3: Heap Insertion, Deletion and Heapify

Learn how to insert and delete elements while maintaining heap properties using efficient C11 implementations.

1. Learning Objectives

  • Understand heap insertion.
  • Understand deletion of the root element.
  • Learn sift-up and sift-down operations.
  • Understand min-heap and max-heap heapify operations.

  • Analyze operation complexities.

2. What Is Heap Insertion?

Heap insertion adds a new element while preserving:

  1. The complete binary tree property.
  2. The min-heap or max-heap ordering property.

The insertion process has two main steps:

  1. Insert the new element at the end of the heap array.
  2. Restore heap order by moving the new element upward if necessary.

This upward adjustment is called:

Sift-up / Bubble-up / Percolate-up: Moving a newly inserted element toward the root until the heap-order property is restored.

3. Min Heap Insertion – Example

Consider the initial min heap:

             10
           /    \
          20     15
         /  \
        40  50

Array representation:

[10, 20, 15, 40, 50]

Insert the value 5.

Step 1: Insert at the End

             10
           /    \
          20     15
         /  \   /
        40  50 5

Array:

[10, 20, 15, 40, 50, 5]

Step 2: Compare with Parent

The new element 5 is at index 5. Its parent index is: 

(5 - 1) / 2 = 2

Parent value = 15.

Since 5 is smaller than 15, swap them.

[10, 20, 5, 40, 50, 15]

Step 3: Continue Upward

The element 5 is now at index 2. Its parent index is 0. 

(2 - 1) / 2 = 0

Since 5 is smaller than 10, swap them.

              5
           /    \
          20     10
         /  \   /
        40  50 15

Final array:

[5, 20, 10, 40, 50, 15]
The new element moves upward until its parent is no greater than it, or it becomes the root.

4. Max Heap Insertion

Max heap insertion follows the same procedure, but the comparison is reversed.

  1. Insert the element at the end.
  2. Compare it with its parent.
  3. If the new element is greater, swap it with the parent.
  4. Continue until the max-heap property is restored.

Example: Insert 60 into this max heap:

             50
           /    \
          30     40
         /  \
        10  20

After insertion and sift-up:

             60
           /    \
          30     50
         /  \   /
        10  20 40

Array representation:

[60, 30, 50, 10, 20, 40]

5. C Program: Min Heap Insertion

#include <stdio.h>

#define MAX_SIZE 100

typedef struct
{
    int arr[MAX_SIZE];
    int size;
} MinHeap;

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int insertMinHeap(MinHeap *heap, int value)
{
    int index;
    int parent;

    if (heap->size >= MAX_SIZE)
    {
        return 0;
    }

    index = heap->size;
    heap->arr[index] = value;
    heap->size++;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (heap->arr[parent] <= heap->arr[index])
        {
            break;
        }

        swap(&heap->arr[parent], &heap->arr[index]);
        index = parent;
    }

    return 1;
}

void displayHeap(const MinHeap *heap)
{
    int i;

    for (i = 0; i < heap->size; i++)
    {
        printf("%d ", heap->arr[i]);
    }

    printf("\n");
}

int main(void)
{
    MinHeap heap = {{0}, 0};

    insertMinHeap(&heap, 40);
    insertMinHeap(&heap, 20);
    insertMinHeap(&heap, 30);
    insertMinHeap(&heap, 10);
    insertMinHeap(&heap, 50);
    insertMinHeap(&heap, 5);

    printf("Min Heap: ");
    displayHeap(&heap);

    return 0;
}

Expected Output

Min Heap: 5 10 30 40 50 20

7. What Is Heap Deletion?

In a binary heap, the most common deletion operation removes the root element:

  • Min heap: removes the minimum element.
  • Max heap: removes the maximum element.

The deletion process is:

  1. Save the root element.
  2. Move the last element to the root position.
  3. Reduce the heap size by one.
  4. Restore heap order by moving the new root downward.
Sift-down / Heapify-down: Moving an element downward until its parent-child relationships satisfy the heap-order property.

8. Min Heap Deletion – Example

Initial min heap:

             5
           /   \
          10    8
         / \   /
        20 15 12

Array:

[5, 10, 8, 20, 15, 12]

Step 1: Remove the Root

The deleted value is 5.

Step 2: Move the Last Element to the Root

The last element is 12.

             12
           /    \
          10     8
         / \
        20 15

Step 3: Sift Down

Compare 12 with its children 10 and 8. The smallest child is 8.

Swap 12 and 8.

             8
           /   \
          10    12
         / \
        20 15

Final array:

[8, 10, 12, 20, 15]

9. Max Heap Deletion – Example

Initial max heap:

             90
           /    \
          70     80
         /  \   /
        20  50 60

Array:

[90, 70, 80, 20, 50, 60]

Delete the root value 90.

Move the last value 60 to the root:

             60
           /    \
          70     80
         /  \
        20  50

Compare 60 with its children. The larger child is 80. Swap 60 and 80. 

             80
           /    \
          70     60
         /  \
        20  50

Final array:

[80, 70, 60, 20, 50]

10. C Program: Complete Min Heap Insertion and Deletion

#include <stdio.h>

#define MAX_SIZE 100

typedef struct
{
    int arr[MAX_SIZE];
    int size;
} MinHeap;

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void siftDown(MinHeap *heap, int index)
{
    int smallest;
    int left;
    int right;

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < heap->size &&
            heap->arr[left] < heap->arr[smallest])
        {
            smallest = left;
        }

        if (right < heap->size &&
            heap->arr[right] < heap->arr[smallest])
        {
            smallest = right;
        }

        if (smallest == index)
        {
            break;
        }

        swap(&heap->arr[index], &heap->arr[smallest]);
        index = smallest;
    }
}

int insertMinHeap(MinHeap *heap, int value)
{
    int index;
    int parent;

    if (heap->size >= MAX_SIZE)
    {
        return 0;
    }

    index = heap->size;
    heap->arr[index] = value;
    heap->size++;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (heap->arr[parent] <= heap->arr[index])
        {
            break;
        }

        swap(&heap->arr[parent], &heap->arr[index]);
        index = parent;
    }

    return 1;
}

int deleteMin(MinHeap *heap, int *deletedValue)
{
    if (heap->size == 0)
    {
        return 0;
    }

    *deletedValue = heap->arr[0];

    heap->size--;

    if (heap->size > 0)
    {
        heap->arr[0] = heap->arr[heap->size];
        siftDown(heap, 0);
    }

    return 1;
}

void displayHeap(const MinHeap *heap)
{
    int i;

    for (i = 0; i < heap->size; i++)
    {
        printf("%d ", heap->arr[i]);
    }

    printf("\n");
}

int main(void)
{
    MinHeap heap = {{0}, 0};
    int deletedValue;

    insertMinHeap(&heap, 40);
    insertMinHeap(&heap, 20);
    insertMinHeap(&heap, 30);
    insertMinHeap(&heap, 10);
    insertMinHeap(&heap, 50);
    insertMinHeap(&heap, 5);

    printf("Initial Min Heap: ");
    displayHeap(&heap);

    if (deleteMin(&heap, &deletedValue))
    {
        printf("Deleted Minimum: %d\n", deletedValue);
    }

    printf("Heap After Deletion: ");
    displayHeap(&heap);

    return 0;
}

Expected Output

Initial Min Heap: 5 10 20 40 50 30
Deleted Minimum: 5
Heap After Deletion: 10 30 20 40 50

12. What Is Heapify?

Heapify is the process of restoring the heap-order property when a node may violate its relationship with its children.

Two important forms are:

  • Sift-up: Repairs a violation by moving a node toward the root.
  • Sift-down: Repairs a violation by moving a node toward the leaves.
Operation Typical use
Sift-up After inserting a new element.
Sift-down After deleting the root or replacing a node with a potentially invalid value.

13. Build Heap from an Unsorted Array

We can construct a heap from an unsorted array using bottom-up heap construction.

Consider:

[40, 10, 30, 50, 20]

The last non-leaf node is at: 

n / 2 - 1

Starting from that index, apply sift-down to every internal node moving backward to the root.

Why Start at the Last Non-Leaf Node?

Leaf nodes already satisfy the heap-order property because they have no children. Therefore, heap construction only needs to process internal nodes.

Complete C11 Program: Build a Min Heap

#include <stdio.h>

#define MAX_SIZE 100

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void minHeapify(int arr[], int n, int index)
{
    int smallest;
    int left;
    int right;

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < n && arr[left] < arr[smallest])
        {
            smallest = left;
        }

        if (right < n && arr[right] < arr[smallest])
        {
            smallest = right;
        }

        if (smallest == index)
        {
            break;
        }

        swap(&arr[index], &arr[smallest]);
        index = smallest;
    }
}

void buildMinHeap(int arr[], int n)
{
    int i;

    for (i = n / 2 - 1; i >= 0; i--)
    {
        minHeapify(arr, n, i);
    }
}

void display(int arr[], int n)
{
    int i;

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {40, 10, 30, 50, 20};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Original Array: ");
    display(arr, n);

    buildMinHeap(arr, n);

    printf("Min Heap: ");
    display(arr, n);

    return 0;
}

Expected Output

Original Array: 40 10 30 50 20
Min Heap: 10 20 30 50 40

15. Complexity Analysis

Operation Time Complexity Reason
Insert O(log n) At most one root-to-leaf height of upward movement.
Delete root O(log n) At most one root-to-leaf height of downward movement.
Sift-up O(log n) Moves toward the root.
Sift-down O(log n) Moves toward a leaf.
Build heap O(n) Bottom-up heap construction.
Peek root O(1) Root is stored at index 0.
Important placement question: Building a heap using bottom-up heapify takes O(n), not O(n log n). The reason is that most nodes are near the leaves and require very little downward movement.

16. Common Mistakes

  • Inserting an element directly at the root.
  • Forgetting to increase the heap size after insertion.
  • Forgetting to decrease the heap size after deletion.
  • Using the wrong comparison for min and max heaps.
  • Failing to compare both children during sift-down.
  • Accessing a child without checking whether its index is within the heap size.
  • Starting bottom-up heap construction from the last array element instead of the last internal node.
  • Assuming that building a heap takes O(n log n).

17. Placement Interview Questions

Q1. What is the time complexity of insertion in a binary heap?

O(log n), because the new element may move from a leaf to the root.

Q2. What is the time complexity of deleting the root?

O(log n), because the replacement element may move down the tree.

Q3. What is sift-up?

Sift-up moves an element toward the root to restore the heap-order property, typically after insertion.

Q4. What is sift-down?

Sift-down moves an element toward the leaves to restore heap order, typically after root deletion.

Q5. Why is the last element moved to the root during deletion?

It preserves the complete binary tree structure. Sift-down then restores the heap-order property.

Q6. What is the complexity of building a heap?

O(n) using bottom-up heap construction.

Q7. What is the last non-leaf node index in a zero-based heap?

n / 2 - 1, when n is positive.

Q8. Can heap insertion and deletion be performed in O(1)?

Not in the general case. They require O(log n) in a binary heap. Reading the root itself takes O(1).

20. Lesson Summary

  • Insertion adds an element at the end and uses sift-up.
  • Root deletion replaces the root with the last element and uses sift-down.
  • Min heap uses the smaller child during sift-down.
  • Max heap uses the larger child during sift-down.
  • Insertion and root deletion take O(log n).
  • Bottom-up heap construction takes O(n).
  • Heap operations preserve the complete binary tree structure.
