Chapter 11 – Heaps and Priority Queues

Lesson 2: Min Heap and Max Heap

Understand heap-order properties, compare min and max heaps, and implement heap validation using C11.

1. Learning Objectives

  • Understand the min-heap property.
  • Understand the max-heap property.
  • Represent min and max heaps using arrays.
  • Differentiate between heap ordering and complete-tree structure.
  • Validate min heaps and max heaps using C.
  • Understand common heap interview problems.

2. What Is a Min Heap?

A min heap is a complete binary tree in which every parent node is smaller than or equal to its children.

For every existing child of a node:

parent <= child

Example:

             10
           /    \
          20     15
         /  \   /
        40  50 30

Array representation:

Index:  0   1   2   3   4   5
Value: 10  20  15  40  50  30

The root contains the smallest element in the heap. However, the remaining elements are not necessarily sorted.

Important: A min heap guarantees that the root is the minimum element. It does not guarantee that the left child is smaller than the right child.

3. What Is a Max Heap?

A max heap is a complete binary tree in which every parent node is greater than or equal to its children.

For every existing child of a node:

parent >= child

Example:

             50
           /    \
          30     40
         /  \   /
        10  20 35

Array representation:

Index:  0   1   2   3   4   5
Value: 50  30  40  10  20  35

The root contains the largest element in the heap.

4. Min Heap vs Max Heap

Feature Min Heap Max Heap
Root element Minimum Maximum
Parent-child rule Parent ≤ Child Parent ≥ Child
Priority queue use Smallest priority first Largest priority first
Peek operation O(1) O(1)
Insert operation O(log n) O(log n)
Remove root O(log n) O(log n)

5. Understanding Heap Order

Consider the following min heap:

             5
           /   \
          10    8
         / \   /
        20 15 12

Check every parent-child relationship:

  • 5 ≤ 10: valid
  • 5 ≤ 8: valid
  • 10 ≤ 20: valid
  • 10 ≤ 15: valid
  • 8 ≤ 12: valid

Now consider this array:

5 10 8 3 15 12

This is not a min heap because the node 10 has a child with value 3, violating the min-heap property.

A tree can be complete but still not be a heap. Both the structural property and heap-order property must be satisfied.

6. C Program: Check Whether an Array Is a Min Heap

In a zero-based array, every parent at index i must be smaller than or equal to each existing child. 

#include <stdio.h>
#include <stdbool.h>

bool isMinHeap(const int arr[], int n)
{
    int i;

    for (i = 0; i < n / 2; i++)
    {
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < n && arr[i] > arr[left])
        {
            return false;
        }

        if (right < n && arr[i] > arr[right])
        {
            return false;
        }
    }

    return true;
}

int main(void)
{
    int heap[] = {10, 20, 15, 40, 50, 30};
    int n = (int)(sizeof(heap) / sizeof(heap[0]));

    if (isMinHeap(heap, n))
    {
        printf("The array represents a Min Heap.\\n");
    }
    else
    {
        printf("The array does not represent a Min Heap.\\n");
    }

    return 0;
}

Expected Output

The array represents a Min Heap.

8. C Program: Check Both Min Heap and Max Heap

This program accepts array elements and checks whether the array satisfies either heap-order property. 

#include <stdio.h>
#include <stdbool.h>

#define MAX_SIZE 100

bool isMinHeap(const int arr[], int n)
{
    int i;

    for (i = 0; i < n / 2; i++)
    {
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < n && arr[i] > arr[left])
            return false;

        if (right < n && arr[i] > arr[right])
            return false;
    }

    return true;
}

bool isMaxHeap(const int arr[], int n)
{
    int i;

    for (i = 0; i < n / 2; i++)
    {
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < n && arr[i] < arr[left])
            return false;

        if (right < n && arr[i] < arr[right])
            return false;
    }

    return true;
}

int main(void)
{
    int arr[MAX_SIZE];
    int n;
    int i;

    printf("Enter number of elements: ");
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX_SIZE)
    {
        printf("Invalid size.\\n");
        return 1;
    }

    printf("Enter array elements: ");

    for (i = 0; i < n; i++)
    {
        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid input.\\n");
            return 1;
        }
    }

    if (isMinHeap(arr, n))
    {
        printf("The array satisfies Min Heap ordering.\\n");
    }
    else
    {
        printf("The array does not satisfy Min Heap ordering.\\n");
    }

    if (isMaxHeap(arr, n))
    {
        printf("The array satisfies Max Heap ordering.\\n");
    }
    else
    {
        printf("The array does not satisfy Max Heap ordering.\\n");
    }

    return 0;
}

9. Time and Space Complexity

Operation Time Complexity
Check min-heap property O(n)
Check max-heap property O(n)
Access root O(1)
Search arbitrary element O(n)

Both validation algorithms use O(1) auxiliary space because they only use loop variables and index calculations.

10. Applications of Min Heap and Max Heap

Min Heap Applications

  • Finding the smallest element efficiently.
  • Implementing a priority queue where lower values have higher priority.
  • Dijkstra's shortest-path algorithm.
  • Finding K smallest elements.
  • Merging K sorted arrays or lists.

Max Heap Applications

  • Finding the largest element efficiently.
  • Implementing a priority queue where larger values have higher priority.
  • Heap sort.
  • Finding K largest elements.
  • Scheduling tasks based on maximum priority.

11. Common Mistakes

  • Assuming a heap is completely sorted.
  • Confusing a heap with a Binary Search Tree.
  • Checking only the left child and ignoring the right child.
  • Forgetting that the last node may have only one child.
  • Using one-based formulas with a zero-based C array.
  • Assuming every complete binary tree is a valid heap.

12. Placement Interview Questions

Q1. What is the main difference between min heap and max heap?

In a min heap, each parent is less than or equal to its children. In a max heap, each parent is greater than or equal to its children.

Q2. Is a min heap sorted in ascending order?

No. Only the parent-child ordering is guaranteed.

Q3. Can a node in a heap have only one child?

Yes. The last internal node of a complete binary tree can have only a left child.

Q4. What is the complexity of validating a heap?

O(n), because every internal node is checked against its existing children.

Q5. Can duplicate values exist in a heap?

Yes. Standard min and max heaps allow duplicate values. Their ordering rules use less-than-or-equal and greater-than-or-equal comparisons.

Q6. Can an array satisfy both min-heap and max-heap ordering?

Yes. For example, an array containing a single element satisfies both properties. An array with all equal elements also satisfies both.

Q7. Why is arbitrary search O(n) in a heap?

Because the heap property does not provide the complete left-versus-right ordering required for binary search.

15. Lesson Summary

  • A min heap stores its smallest element at the root.
  • A max heap stores its largest element at the root.
  • Both are complete binary trees.
  • Duplicate values are allowed.
  • Heap validation takes O(n) time.
  • Arbitrary search takes O(n) time.
  • Min and max heaps are widely used in priority queues and selection problems.
