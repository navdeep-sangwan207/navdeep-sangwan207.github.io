Lesson 5: Top K Elements and Kth Largest/Smallest

Solve important selection problems using min heaps, max heaps and efficient heap-based algorithms in C11.

1. Learning Objectives

  • Understand the Top K problem pattern.
  • Find the Kth largest and Kth smallest elements.
  • Use min heaps and max heaps for selection problems.
  • Find the K most frequent elements.
  • Find the K closest elements to a target.
  • Compare sorting, heap and Quickselect approaches.
  • Analyze time and space complexity.

2. Understanding the Top K Pattern

Many coding problems ask us to identify a limited number of elements from a larger collection.

Examples include:

  • Find the largest K elements.
  • Find the smallest K elements.
  • Find the Kth largest element.
  • Find the Kth smallest element.
  • Find the K most frequent elements.
  • Find the K closest points to a target.
Important pattern: When K is much smaller than N, maintaining a heap of size K can be more efficient than sorting the entire array.

3. Kth Largest Element

Given an array, find the Kth largest element. The Kth largest means the element at position K when values are arranged in descending order.

Example

Array = [7, 10, 4, 3, 20, 15]
K = 3

Descending order:
20, 15, 10, 7, 4, 3

Third largest = 10

Approach 1: Sorting

Sort the array in ascending order and access the element at index n-k.

Time complexity: O(n log n).

Approach 2: Min Heap of Size K

  1. Create a min heap with capacity K.
  2. Insert the first K elements.
  3. For every remaining element, compare it with the heap root.
  4. If it is larger than the root, replace the root and restore the heap.
  5. The root contains the Kth largest element.
A min heap is used because the smallest element among the current K largest candidates must remain at the root.

4. C Program: Kth Largest Element Using a Min Heap

#include <stdio.h>

#define MAX_SIZE 1000

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void minHeapify(int heap[], int size, int index)
{
    int smallest;
    int left;
    int right;

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < size && heap[left] < heap[smallest])
            smallest = left;

        if (right < size && heap[right] < heap[smallest])
            smallest = right;

        if (smallest == index)
            break;

        swap(&heap[index], &heap[smallest]);
        index = smallest;
    }
}

void insertMinHeap(int heap[], int *size, int value)
{
    int index = (*size)++;
    int parent;

    heap[index] = value;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (heap[parent] <= heap[index])
            break;

        swap(&heap[parent], &heap[index]);
        index = parent;
    }
}

int kthLargest(const int arr[], int n, int k, int *answer)
{
    int heap[MAX_SIZE];
    int size = 0;
    int i;

    if (n <= 0 || n > MAX_SIZE || k < 1 || k > n)
        return 0;

    for (i = 0; i < k; i++)
        insertMinHeap(heap, &size, arr[i]);

    for (i = k; i < n; i++)
    {
        if (arr[i] > heap[0])
        {
            heap[0] = arr[i];
            minHeapify(heap, size, 0);
        }
    }

    *answer = heap[0];
    return 1;
}

int main(void)
{
    int arr[] = {7, 10, 4, 3, 20, 15};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int k = 3;
    int answer;

    if (kthLargest(arr, n, k, &answer))
        printf("%dth Largest Element = %d\n", k, answer);
    else
        printf("Invalid input.\n");

    return 0;
}

Expected Output

3th Largest Element = 10

Complexity:

  • Time: O(n log k).
  • Auxiliary space: O(k), with the fixed array implementation reserving MAX_SIZE storage.

5. Kth Smallest Element

Given an array, find the Kth smallest element.

Example

Array = [7, 10, 4, 3, 20, 15]
K = 3

Ascending order:
3, 4, 7, 10, 15, 20

Third smallest = 7

Heap Approach

Use a max heap of size K. The root contains the largest value among the K smallest candidates.

  1. Insert the first K elements into a max heap.
  2. For each remaining element, compare it with the root.
  3. If it is smaller than the root, replace the root.
  4. Restore the max heap.
  5. The root is the Kth smallest element.

6. C Program: Kth Smallest Element Using a Max Heap

#include <stdio.h>

#define MAX_SIZE 1000

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void maxHeapify(int heap[], int size, int index)
{
    int largest;
    int left;
    int right;

    while (1)
    {
        largest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < size && heap[left] > heap[largest])
            largest = left;

        if (right < size && heap[right] > heap[largest])
            largest = right;

        if (largest == index)
            break;

        swap(&heap[index], &heap[largest]);
        index = largest;
    }
}

7. Top K Largest Elements

Given an array, return the K largest elements.

Example

Array = [3, 2, 1, 5, 6, 4]
K = 3

Top 3 largest elements:
4, 5, 6

A min heap of size K maintains the K largest candidates. The root is the smallest of those candidates.

Complete C11 Program

#include <stdio.h>

#define MAX_SIZE 1000

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void downHeap(int heap[], int size, int index)
{
    int smallest;
    int left;
    int right;

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < size && heap[left] < heap[smallest])
            smallest = left;

        if (right < size && heap[right] < heap[smallest])
            smallest = right;

        if (smallest == index)
            break;

        swap(&heap[index], &heap[smallest]);
        index = smallest;
    }
}

void upHeap(int heap[], int index)
{
    int parent;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (heap[parent] <= heap[index])
            break;

        swap(&heap[parent], &heap[index]);
        index = parent;
    }
}

int topKLargest(const int arr[], int n, int k, int result[])
{
    int heap[MAX_SIZE];
    int size = 0;
    int i;

    if (n <= 0 || n > MAX_SIZE || k < 1 || k > n)
        return 0;

    for (i = 0; i < n; i++)
    {
        if (size < k)
        {
            heap[size] = arr[i];
            upHeap(heap, size);
            size++;
        }
        else if (arr[i] > heap[0])
        {
            heap[0] = arr[i];
            downHeap(heap, size, 0);
        }
    }

    for (i = 0; i < k; i++)
        result[i] = heap[i];

    return k;
}

int main(void)
{
    int arr[] = {3, 2, 1, 5, 6, 4};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int k = 3;
    int result[MAX_SIZE];
    int count;
    int i;

    count = topKLargest(arr, n, k, result);

    if (count == 0)
    {
        printf("Invalid input.\n");
        return 1;
    }

    printf("Top %d largest elements: ", k);

    for (i = 0; i < count; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}

Expected Output

Top 3 largest elements: 4 5 6
The returned elements are not guaranteed to be sorted. If sorted output is required, sort the K results separately.

8. Top K Frequent Elements

Given an array, find the K values that occur most frequently.

Example

Array = [1, 1, 1, 2, 2, 3]
K = 2

Frequencies:
1 -> 3
2 -> 2
3 -> 1

Top 2 frequent elements:
1, 2

A common approach is:

  1. Count the frequency of each distinct value.
  2. Maintain a min heap of size K based on frequency.
  3. Replace the root when a new value has a higher frequency.
  4. Return the K values in the heap.
This problem combines hashing and heaps. Frequency counting identifies how often each value occurs; the heap selects the K most frequent values.

Complexity

  • Frequency counting with a suitable hash table: expected O(n).
  • Heap selection over U distinct values: O(U log K).
  • Additional space: O(U + K), where U is the number of distinct values.

9. K Closest Elements to a Target

Given an array and a target value X, find K elements having the smallest absolute difference from X.

Example

Array = [1, 2, 3, 4, 5]
X = 3
K = 2

Two closest elements:
2 and 3

Absolute differences:
|2 - 3| = 1
|3 - 3| = 0

One approach is to maintain a max heap of size K using the distance from the target as the priority.

When a new candidate is closer than the farthest element currently in the heap, replace the root.

For a general unsorted array, this approach takes O(n log K) time and O(K) additional space.

10. Heap vs Sorting vs Quickselect

Approach Typical Time Extra Space Best Use
Full Sorting O(n log n) Depends on sorting algorithm Need complete sorted order
Heap of Size K O(n log k) O(k) K is small compared with n
Quickselect Average O(n), worst O(n²) O(1) iterative partitioning Need one Kth element
Interview decision: If the question asks for only one Kth element, Quickselect is often a strong option. If it asks for the K largest or smallest elements, a size-K heap is often appropriate.

11. Important Edge Cases

  • K = 1: find the maximum or minimum element.
  • K = n: all elements are selected.
  • K = 0: invalid for these selection problems.
  • K greater than n: invalid input.
  • All elements equal: duplicates must be handled according to the problem statement.
  • Negative numbers: heap comparisons work normally.
  • Duplicate values: distinguish between Kth element by position and Kth distinct element.
Important distinction: In the standard Kth-largest problem, duplicate values count as separate positions unless the question explicitly asks for the Kth largest distinct value.

12. Common Interview Mistakes

  • Using a max heap of size K for the Kth largest problem when a min heap of size K is more efficient.
  • Using a min heap of size K for the Kth smallest problem instead of a max heap.
  • Forgetting to validate K.
  • Assuming the heap array is sorted.
  • Returning the wrong root after heap construction.
  • Ignoring duplicate-value requirements.
  • Sorting all N elements when only K elements are required.

13. Placement Interview Questions

Q1. Which heap is used to find the Kth largest element efficiently?

A min heap of size K.

Q2. Which heap is used to find the Kth smallest element efficiently?

A max heap of size K.

Q3. What is the time complexity of finding the Kth largest element using a size-K heap?

O(n log K), with O(K) auxiliary space.

Q4. Why does a min heap work for the Kth largest problem?

It keeps the K largest values seen so far. Its root is the smallest among those K values, which is the Kth largest candidate.

Q5. What is the difference between Kth largest and Kth largest distinct?

Kth largest counts duplicate values as separate positions. Kth largest distinct considers only unique values.

Q6. What is the Top K Frequent Elements problem?

It asks for the K distinct values with the highest occurrence frequencies, commonly solved using hashing and a heap.

Q7. When is Quickselect preferable to a heap?

When only one order statistic, such as the Kth smallest element, is needed and average linear-time selection is useful.

16. Lesson Summary

  • Top K problems are common heap-based interview patterns.
  • A min heap of size K finds Kth largest and Top K largest elements.
  • A max heap of size K finds Kth smallest and Top K smallest elements.
  • Hashing combined with a heap solves Top K Frequent Elements.
  • A heap of size K can process N elements in O(n log K) time.
  • Quickselect provides average O(n) selection time.
  • Always validate K and clarify duplicate handling.
