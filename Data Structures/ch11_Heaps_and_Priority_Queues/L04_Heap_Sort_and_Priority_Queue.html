2. What Is Heap Sort?

Heap sort is a comparison-based sorting algorithm that uses a binary heap to sort elements.

For sorting in ascending order, heap sort generally uses a max heap.

The algorithm works in two main phases:

  1. Build a max heap from the input array.
  2. Repeatedly move the maximum element to the end and restore the heap.
Key idea: The root of a max heap contains the largest element. Moving it to the end of the array places the largest remaining element in its final sorted position.

3. Heap Sort – Example

Consider the unsorted array:

[40, 10, 30, 50, 20]

Step 1: Build a Max Heap

             50
           /    \
          20     30
         /  \
        10  40

Array representation:

[50, 20, 30, 10, 40]

Step 2: Move the Root to the End

Swap 50 with the last element, 40.

[40, 20, 30, 10 | 50]

The vertical separator marks the sorted portion.

Step 3: Restore the Heap

Heapify the remaining four elements:

[40, 20, 30, 10 | 50]

40 is already the largest element in the active heap.

Step 4: Repeat

[30, 20, 10 | 40, 50]
[20, 10 | 30, 40, 50]
[10 | 20, 30, 40, 50]

Final sorted array:

[10, 20, 30, 40, 50]

4. Heap Sort Algorithm

  1. Start with an unsorted array of n elements.
  2. Build a max heap using bottom-up heap construction.
  3. Swap the root with the last element in the active heap.
  4. Reduce the active heap size by one.
  5. Apply max-heap sift-down to restore heap order.
  6. Repeat until the active heap contains one element.
Heap sort uses the original array for both the heap and sorted output. It does not require a separate output array.

5. C Program: Heap Sort in Ascending Order

This complete C11 program builds a max heap and sorts the array in ascending order. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void maxHeapify(int arr[], int n, int index)
{
    int largest;
    int left;
    int right;

    while (1)
    {
        largest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < n && arr[left] > arr[largest])
        {
            largest = left;
        }

        if (right < n && arr[right] > arr[largest])
        {
            largest = right;
        }

        if (largest == index)
        {
            break;
        }

        swap(&arr[index], &arr[largest]);
        index = largest;
    }
}

void buildMaxHeap(int arr[], int n)
{
    int i;

    for (i = n / 2 - 1; i >= 0; i--)
    {
        maxHeapify(arr, n, i);
    }
}

void heapSort(int arr[], int n)
{
    int i;

    buildMaxHeap(arr, n);

    for (i = n - 1; i > 0; i--)
    {
        swap(&arr[0], &arr[i]);

        maxHeapify(arr, i, 0);
    }
}

void displayArray(const int arr[], int n)
{
    int i;

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {40, 10, 30, 50, 20, 60, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Original Array: ");
    displayArray(arr, n);

    heapSort(arr, n);

    printf("Sorted Array: ");
    displayArray(arr, n);

    return 0;
}

Expected Output

Original Array: 40 10 30 50 20 60 5
Sorted Array: 5 10 20 30 40 50 60

6. C Program: Heap Sort in Descending Order

To sort in descending order, use a min heap instead of a max heap. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void minHeapify(int arr[], int n, int index)
{
    int smallest;
    int left;
    int right;

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < n && arr[left] < arr[smallest])
        {
            smallest = left;
        }

        if (right < n && arr[right] < arr[smallest])
        {
            smallest = right;
        }

        if (smallest == index)
        {
            break;
        }

        swap(&arr[index], &arr[smallest]);
        index = smallest;
    }
}

void buildMinHeap(int arr[], int n)
{
    int i;

    for (i = n / 2 - 1; i >= 0; i--)
    {
        minHeapify(arr, n, i);
    }
}

void heapSortDescending(int arr[], int n)
{
    int i;

    buildMinHeap(arr, n);

    for (i = n - 1; i > 0; i--)
    {
        swap(&arr[0], &arr[i]);

        minHeapify(arr, i, 0);
    }
}

void displayArray(const int arr[], int n)
{
    int i;

    for (i = 0; i < n; i++)

7. Heap Sort Complexity

Case Time Complexity
Best Case O(n log n)
Average Case O(n log n)
Worst Case O(n log n)
Auxiliary Space O(1) for this iterative implementation

Heap construction takes O(n), and the repeated root extraction operations take O(n log n) in total.

Important Characteristics

  • In-place sorting algorithm.
  • Guaranteed O(n log n) time.
  • Not stable in its standard implementation.
  • Does not require an additional array.

8. What Is a Priority Queue?

A priority queue is an abstract data type in which each element has a priority.

Elements are removed according to priority rather than the order in which they were inserted.

Two common types are:

  • Min-priority queue: Removes the element with the smallest key first.
  • Max-priority queue: Removes the element with the largest key first.
A binary heap is a common and efficient way to implement a priority queue.

9. Priority Queue vs Normal Queue

Feature Normal Queue Priority Queue
Removal order FIFO Based on priority
Insertion At rear According to heap implementation
Removal From front Highest or lowest priority
Typical implementation Array or linked list Binary heap

10. Priority Queue Operations

Operation Meaning Binary Heap Complexity
Insert Add an element O(log n)
Peek Read highest-priority element O(1)
Extract Remove highest-priority element O(log n)
Is Empty Check whether queue is empty O(1)
Search Find arbitrary element O(n)

11. C Program: Max Priority Queue Using a Binary Heap

This program implements a max-priority queue. The element with the highest priority value is extracted first. 

#include <stdio.h>

#define MAX_SIZE 100

typedef struct
{
    int arr[MAX_SIZE];
    int size;
} PriorityQueue;

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int isEmpty(const PriorityQueue *pq)
{
    return pq->size == 0;
}

int isFull(const PriorityQueue *pq)
{
    return pq->size == MAX_SIZE;
}

void siftUp(PriorityQueue *pq, int index)
{
    int parent;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (pq->arr[parent] >= pq->arr[index])
        {
            break;
        }

        swap(&pq->arr[parent], &pq->arr[index]);
        index = parent;
    }
}

void siftDown(PriorityQueue *pq, int index)
{
    int largest;
    int left;
    int right;

    while (1)
    {
        largest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < pq->size &&
            pq->arr[left] > pq->arr[largest])
        {
            largest = left;
        }

        if (right < pq->size &&
            pq->arr[right] > pq->arr[largest])
        {
            largest = right;
        }

        if (largest == index)
        {
            break;
        }

        swap(&pq->arr[index], &pq->arr[largest]);
        index = largest;
    }
}

int insert(PriorityQueue *pq, int value)
{
    int index;

    if (isFull(pq))
    {
        return 0;
    }

    index = pq->size;
    pq->arr[index] = value;
    pq->size++;

    siftUp(pq, index);

    return 1;
}

int peek(const PriorityQueue *pq, int *value)
{
    if (isEmpty(pq))
    {
        return 0;
    }

    *value = pq->arr[0];
    return 1;
}

int extractMax(PriorityQueue *pq, int *value)
{
    if (isEmpty(pq))
    {
        return 0;
    }

    *value = pq->arr[0];
    pq->size--;

    if (pq->size > 0)
    {
        pq->arr[0] = pq->arr[pq->size];
        siftDown(pq, 0);
    }

    return 1;
}

void display(const PriorityQueue *pq)
{
    int i;

    for (i = 0; i < pq->size; i++)
    {
        printf("%d ", pq->arr[i]);
    }

    printf("\n");
}

int main(void)
{
    PriorityQueue pq = {{0}, 0};
    int value;

    insert(&pq, 30);
    insert(&pq, 50);
    insert(&pq, 10);
    insert(&pq, 40);
    insert(&pq, 20);

    printf("Priority Queue: ");
    display(&pq);

    if (peek(&pq, &value))
    {
        printf("Highest Priority: %d\n", value);
    }

    if (extractMax(&pq, &value))
    {
        printf("Extracted Element: %d\n", value);
    }

    printf("After Extraction: ");
    display(&pq);

    return 0;
}

Expected Output

Priority Queue: 50 40 10 30 20
Highest Priority: 50
Extracted Element: 50
After Extraction: 40 30 10 20

12. C Program: Min Priority Queue

In a min-priority queue, the smallest value is extracted first. 

#include <stdio.h>

#define MAX_SIZE 100

typedef struct
{
    int arr[MAX_SIZE];
    int size;
} MinPriorityQueue;

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int insert(MinPriorityQueue *pq, int value)
{
    int index;
    int parent;

    if (pq->size == MAX_SIZE)
    {
        return 0;
    }

    index = pq->size;
    pq->arr[index] = value;
    pq->size++;

    while (index > 0)
    {
        parent = (index - 1) / 2;

        if (pq->arr[parent] <= pq->arr[index])
        {
            break;
        }

        swap(&pq->arr[parent], &pq->arr[index]);
        index = parent;
    }

    return 1;
}

int extractMin(MinPriorityQueue *pq, int *value)
{
    int index = 0;
    int left;
    int right;
    int smallest;

    if (pq->size == 0)
    {
        return 0;
    }

    *value = pq->arr[0];
    pq->size--;

    if (pq->size == 0)
    {
        return 1;
    }

    pq->arr[0] = pq->arr[pq->size];

    while (1)
    {
        smallest = index;
        left = 2 * index + 1;
        right = 2 * index + 2;

        if (left < pq->size &&
            pq->arr[left] < pq->arr[smallest])
        {
            smallest = left;
        }

        if (right < pq->size &&
            pq->arr[right] < pq->arr[smallest])
        {
            smallest = right;
        }

        if (smallest == index)
        {
            break;
        }

        swap(&pq->arr[index], &pq->arr[smallest]);
        index = smallest;
    }

    return 1;
}

int main(void)
{
    MinPriorityQueue pq = {{0}, 0};
    int value;

    insert(&pq, 30);
    insert(&pq, 50);
    insert(&pq, 10);
    insert(&pq, 40);
    insert(&pq, 20);

    printf("Extracting in priority order:\n");

    while (extractMin(&pq, &value))
    {
        printf("%d ", value);
    }

    printf("\n");

    return 0;
}

Expected Output

Extracting in priority order:
10 20 30 40 50

15. Common Mistakes

  • Using a min heap when ascending heap sort requires a max heap.
  • Forgetting to reduce the active heap size after extracting the root.
  • Heapifying the entire array instead of only the unsorted portion.
  • Confusing a priority queue with a normal FIFO queue.
  • Assuming a priority queue stores elements in completely sorted order.
  • Forgetting to check for empty and full conditions.
  • Assuming heap sort is stable.

16. Placement Interview Questions

Q1. What is heap sort?

Heap sort is a comparison-based sorting algorithm that builds a heap and repeatedly extracts its root element to place values in sorted order.

Q2. Why is a max heap used for ascending heap sort?

Because its root contains the largest remaining value. That value can be placed at the end of the unsorted portion.

Q3. Is heap sort stable?

No. The standard in-place heap sort can change the relative order of equal elements.

Q4. What is the auxiliary space complexity of iterative heap sort?

O(1).

Q5. What is a priority queue?

An abstract data type where elements are removed according to their priority rather than insertion order.

Q6. Can a priority queue be implemented using an array?

Yes. It can use an unsorted array, sorted array, linked list or binary heap. A binary heap gives O(log n) insertion and extraction, with O(1) access to the root.

Q7. What is the difference between peek and extract?

Peek reads the highest-priority element without removing it. Extract reads and removes that element.

Q8. Why is heap sort O(n log n) in the worst case?

Heap construction takes O(n), and extracting all elements requires O(n log n) total time.

19. Lesson Summary

  • Heap sort uses a binary heap to sort an array.
  • A max heap is used for ascending heap sort.
  • A min heap is used for descending heap sort.
  • Heap sort has O(n log n) best, average and worst-case time.
  • Standard iterative heap sort uses O(1) auxiliary space.
  • Heap sort is not stable.
  • A priority queue removes elements according to priority.
  • A binary heap supports insertion and extraction in O(log n).
