2. What Is a Priority Queue?

A priority queue is an abstract data type in which every element has an associated priority. Elements are removed according to priority rather than simply following insertion order.

Example

Consider a hospital emergency department:

Patient       Priority
----------------------
Patient A     3
Patient B     1
Patient C     2

If smaller number means higher priority:

Service order:
Patient B
Patient C
Patient A
A priority queue is not necessarily sorted internally. Its implementation only needs to ensure that the correct highest- or lowest-priority element is selected when required.

4. Types of Priority Queue

A. Min-Priority Queue

The element with the smallest priority value is removed first.

Elements:
Value       Priority
A           4
B           1
C           3
D           2

Removal order:
B -> D -> C -> A

B. Max-Priority Queue

The element with the largest priority value is removed first.

Elements:
Value       Priority
A           4
B           1
C           3
D           2

Removal order:
A -> C -> D -> B
In this lesson, smaller numeric values represent higher priority in the min-priority queue examples. Always check the priority convention specified in a problem.

5. Priority Queue Using an Unsorted Array

In an unsorted array, insertion is performed at the next available position. To remove the highest-priority element, the array must be searched.

Representation

Index:       0       1       2       3
          +-------+-------+-------+-------+
Value:    |  40   |  10   |  30   |  20   |
Priority: |   4   |   1   |   3   |   2   |
          +-------+-------+-------+-------+

Smallest priority = 1
Element selected = 10

Complexity

  • Insertion: O(1) amortized for a fixed-capacity array, assuming space exists.
  • Deletion: O(n) because the best-priority element must be found.
  • Peek: O(n) because the best-priority element must be found.

6. Complete C11 Program: Unsorted Array Priority Queue

This implementation uses a min-priority queue. Lower numeric priority means higher priority. Equal priorities are processed in insertion order.

#include <stdio.h>

#define MAX 10

struct Item
{
    int value;
    int priority;
    unsigned long long order;
};

struct PriorityQueue
{
    struct Item items[MAX];
    int size;
    unsigned long long nextOrder;
};

void initialize(struct PriorityQueue *pq)
{
    pq->size = 0;
    pq->nextOrder = 0;
}

int isEmpty(const struct PriorityQueue *pq)
{
    return pq->size == 0;
}

int isFull(const struct PriorityQueue *pq)
{
    return pq->size == MAX;
}

int higherPriority(const struct Item *a,
                   const struct Item *b)
{
    if (a->priority != b->priority)
        return a->priority < b->priority;

    return a->order < b->order;
}

int enqueue(struct PriorityQueue *pq,
            int value, int priority)
{
    if (isFull(pq))
        return 0;

    pq->items[pq->size].value = value;
    pq->items[pq->size].priority = priority;
    pq->items[pq->size].order = pq->nextOrder++;

    pq->size++;

    return 1;
}

int dequeue(struct PriorityQueue *pq,
            struct Item *removed)
{
    if (isEmpty(pq))
        return 0;

    int best = 0;

    for (int i = 1; i < pq->size; i++)
    {
        if (higherPriority(&pq->items[i],
                           &pq->items[best]))
        {
            best = i;
        }
    }

    *removed = pq->items[best];

    for (int i = best; i < pq->size - 1; i++)
    {
        pq->items[i] = pq->items[i + 1];
    }

    pq->size--;

    return 1;
}

int peek(const struct PriorityQueue *pq,
         struct Item *result)
{
    if (isEmpty(pq))
        return 0;

    int best = 0;

    for (int i = 1; i < pq->size; i++)
    {
        if (higherPriority(&pq->items[i],
                           &pq->items[best]))
        {
            best = i;
        }
    }

    *result = pq->items[best];

    return 1;
}

void display(const struct PriorityQueue *pq)
{
    if (isEmpty(pq))
    {
        printf("Priority Queue is Empty\n");
        return;
    }

    printf("Value  Priority\n");

    for (int i = 0; i < pq->size; i++)
    {
        printf("%5d  %8d\n",
               pq->items[i].value,
               pq->items[i].priority);
    }
}

int main(void)
{
    struct PriorityQueue pq;
    struct Item removed;
    struct Item first;

    initialize(&pq);

    enqueue(&pq, 100, 3);
    enqueue(&pq, 200, 1);
    enqueue(&pq, 300, 2);
    enqueue(&pq, 400, 1);

    printf("Priority Queue:\n");
    display(&pq);

    if (peek(&pq, &first))
    {
        printf("\nNext element: %d, Priority: %d\n",
               first.value, first.priority);
    }

    printf("\nDeletion order:\n");

    while (dequeue(&pq, &removed))
    {
        printf("Value: %d, Priority: %d\n",
               removed.value, removed.priority);
    }

    if (!dequeue(&pq, &removed))
        printf("Underflow: Queue is Empty\n");

    return 0;
}

Expected Output

Priority Queue:
Value  Priority
  100         3
  200         1
  300         2
  400         1

Next element: 200, Priority: 1

Deletion order:
Value: 200, Priority: 1
Value: 400, Priority: 1
Value: 300, Priority: 2
Value: 100, Priority: 3
Underflow: Queue is Empty

Compile and Run

./priority_array

7. Priority Queue Using a Sorted Array

Another approach is to keep elements sorted by priority during insertion.

  • Insertion requires finding the correct position and shifting elements.
  • Deletion of the highest-priority element can be performed from one end.
  • Equal priorities can be kept in insertion order if the insertion logic preserves stability.
OperationComplexity
InsertionO(n)
DeletionO(1)
PeekO(1)

8. Priority Queue Using a Linked List

A linked-list implementation stores a value and priority in every node. We maintain the list in priority order.

Node Representation

struct Node
{
    int data;
    int priority;
    struct Node *next;
};

Sorted Linked-List Logic

Head
 |
 v
+------+----------+------+
|  20  | Priority 1 |  o--+---+
+------+----------+------+   |
                             v
                       +------+----------+------+
                       |  30  | Priority 2 |  o--+---+
                       +------+----------+------+   |
                                                    v
                                              +------+----------+
                                              |  10  | Priority 3 |
                                              +------+----------+

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    int priority;
    struct Node *next;
};

struct Node *createNode(int value, int priority)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->priority = priority;
    newNode->next = NULL;

    return newNode;
}

int enqueue(struct Node **head, int value, int priority)
{
    struct Node *newNode = createNode(value, priority);

    if (newNode == NULL)
        return 0;

    /*
       Smaller priority number means higher priority.
       Insert after existing nodes with equal priority
       to preserve insertion order.
    */

    if (*head == NULL || priority < (*head)->priority)
    {
        newNode->next = *head;
        *head = newNode;
        return 1;
    }

    struct Node *current = *head;

    while (current->next != NULL &&
           current->next->priority <= priority)
    {
        current = current->next;
    }

    newNode->next = current->next;
    current->next = newNode;

    return 1;
}

int dequeue(struct Node **head, int *removed)
{
    if (*head == NULL)
        return 0;

    struct Node *temp = *head;

    *removed = temp->data;
    *head = temp->next;

    free(temp);

    return 1;
}

int peek(const struct Node *head, int *value)
{
    if (head == NULL)
        return 0;

    *value = head->data;

    return 1;
}

void display(const struct Node *head)
{
    if (head == NULL)
    {
        printf("Priority Queue is Empty\n");
        return;
    }

    printf("Value(Priority): ");

    while (head != NULL)
    {
        printf("%d(%d) ",
               head->data,
               head->priority);

        head = head->next;
    }

    printf("\n");
}

void freeQueue(struct Node **head)
{
    while (*head != NULL)
    {
        struct Node *temp = *head;
        *head = (*head)->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = NULL;
    int removed;
    int value;

    enqueue(&head, 100, 3);
    enqueue(&head, 200, 1);
    enqueue(&head, 300, 2);
    enqueue(&head, 400, 1);

    display(head);

    if (peek(head, &value))
        printf("Next element: %d\n", value);

    printf("Deletion order:\n");

    while (dequeue(&head, &removed))
        printf("%d ", removed);

    printf("\n");

    freeQueue(&head);

    return 0;
}

Expected Output

Value(Priority): 200(1) 400(1) 300(2) 100(3)
Next element: 200
Deletion order:
200 400 300 100

Complexity

OperationComplexity
InsertionO(n)
DeletionO(1)
PeekO(1)
DisplayO(n)

9. Binary Heap: The Efficient Priority Queue

A binary heap is a complete binary tree that satisfies the heap-order property. It is one of the most common implementations of a priority queue.

Min-Heap

Every parent node has a value less than or equal to its children.

             10
           /    \
         20      30
        /  \
      40    50

Parent <= Children

Max-Heap

Every parent node has a value greater than or equal to its children.

             90
           /    \
         70      80
        /  \
      40    50

Parent >= Children

Array Representation of a Binary Heap

For a zero-based array representation:

Parent index = (i - 1) / 2

Left child index = 2 * i + 1

Right child index = 2 * i + 2

For example:

Heap array:
Index:  0   1   2   3   4
Value: 10  20  30  40  50

Tree:
             10
           /    \
         20      30
        /  \
      40    50

10. Heap Insertion

To insert an element into a min-heap:

  1. Insert the new element at the end of the heap array.
  2. Compare it with its parent.
  3. If it is smaller than its parent, swap them.
  4. Continue until the heap property is restored or the root is reached.
Example:

Initial heap:
       10
      /  \
    20    30

Insert 5:

       10
      /  \
     5    30
    /
   20

After heapify-up:

        5
      /   \
    10     30
   /
  20

Time complexity: O(log n).

11. Heap Deletion

Deleting the root of a min-heap removes the minimum element.

  1. Save the root value.
  2. Move the final array element to the root.
  3. Reduce the heap size.
  4. Compare the root with its children.
  5. Swap with the smaller child when necessary.
  6. Continue until the heap property is restored.
Before deletion:

        5
      /   \
    10     30
   /
  20

Remove root 5 and move last element:

        20
      /   \
    10     30

After heapify-down:

        10
      /   \
    20     30

Time complexity: O(log n).

12. Complete C11 Program: Min-Heap Priority Queue

This is an array-based min-heap. The smallest value is always at the root.

#include <stdio.h>

#define MAX 100

struct MinHeap
{
    int data[MAX];
    int size;
};

void initialize(struct MinHeap *heap)
{
    heap->size = 0;
}

int isEmpty(const struct MinHeap *heap)
{
    return heap->size == 0;
}

int isFull(const struct MinHeap *heap)
{
    return heap->size == MAX;
}

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int insert(struct MinHeap *heap, int value)
{
    if (isFull(heap))
        return 0;

    int i = heap->size;
    heap->data[i] = value;
    heap->size++;

    /* Heapify upward */

    while (i > 0)
    {
        int parent = (i - 1) / 2;

        if (heap->data[parent] <= heap->data[i])
            break;

        swap(&heap->data[parent], &heap->data[i]);

        i = parent;
    }

    return 1;
}

void heapifyDown(struct MinHeap *heap, int i)
{
    while (1)
    {
        int smallest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heap->size &&
            heap->data[left] < heap->data[smallest])
        {
            smallest = left;
        }

        if (right < heap->size &&
            heap->data[right] < heap->data[smallest])
        {
            smallest = right;
        }

        if (smallest == i)
            break;

        swap(&heap->data[i],
             &heap->data[smallest]);

        i = smallest;
    }
}

int extractMin(struct MinHeap *heap, int *removed)
{
    if (isEmpty(heap))
        return 0;

    *removed = heap->data[0];

    heap->size--;

    if (heap->size > 0)
    {
        heap->data[0] = heap->data[heap->size];
        heapifyDown(heap, 0);
    }

    return 1;
}

int peek(const struct MinHeap *heap, int *value)
{
    if (isEmpty(heap))
        return 0;

    *value = heap->data[0];

    return 1;
}

void display(const struct MinHeap *heap)
{
    printf("Heap array: ");

    for (int i = 0; i < heap->size; i++)
        printf("%d ", heap->data[i]);

    printf("\n");
}

int main(void)
{
    struct MinHeap heap;
    int removed;
    int minimum;

    initialize(&heap);

    insert(&heap, 40);
    insert(&heap, 20);
    insert(&heap, 30);
    insert(&heap, 10);
    insert(&heap, 50);

    display(&heap);

    if (peek(&heap, &minimum))
        printf("Minimum: %d\n", minimum);

    printf("Extracted elements: ");

    while (extractMin(&heap, &removed))
        printf("%d ", removed);

    printf("\n");

    if (!extractMin(&heap, &removed))
        printf("Heap Underflow\n");

    return 0;
}

Expected Output

Heap array: 10 20 30 40 50
Minimum: 10
Extracted elements: 10 20 30 40 50
Heap Underflow

Compile and Run

gcc -std=c11 -Wall -Wextra -pedantic min_heap.c -o min_heap
./min_heap
A heap array is not completely sorted. It only satisfies the heap property. The extracted elements are in ascending order because each extraction removes the current minimum.

14. Applications of Priority Queue

  • CPU and process scheduling.
  • Hospital emergency management.
  • Dijkstra's shortest-path algorithm.
  • Prim's minimum spanning tree algorithm.
  • Huffman coding.
  • Event-driven simulation.
  • Task and job scheduling.
  • Finding the K largest or smallest elements.
  • Merging K sorted lists or arrays.

15. Common Programming Mistakes

  1. Confusing smaller priority numbers with higher priority when the problem defines the opposite convention.
  2. Using FIFO logic instead of comparing priorities.
  3. Forgetting to shift array elements after deletion in an unsorted array implementation.
  4. Failing to preserve insertion order for equal priorities when stability is required.
  5. Forgetting to update the heap size after insertion or deletion.
  6. Using the wrong parent or child index formula.
  7. Performing heapify-up when heapify-down is required, or vice versa.
  8. Assuming a heap array is fully sorted.
  9. Not checking empty and full conditions.
  10. Failing to check malloc results in linked-list implementations.

16. Placement Interview Questions and Answers

Q1. What is a priority queue?

Answer: A data structure in which elements are processed according to their associated priority.

Q2. What is the difference between a queue and a priority queue?

Answer: A normal queue follows FIFO. A priority queue selects elements according to priority.

Q3. What are the two main types of priority queues?

Answer: Min-priority queue and max-priority queue.

Q4. What is a min-priority queue?

Answer: A priority queue where the element with the smallest key or priority is removed first.

Q5. What is a max-priority queue?

Answer: A priority queue where the element with the largest key or priority is removed first.

Q6. Which data structure is commonly used to implement a priority queue efficiently?

Answer: A binary heap.

Q7. What is the insertion complexity of a binary heap?

Answer: O(log n).

Q8. What is the deletion complexity of a binary heap?

Answer: O(log n).

Q9. What is the peek complexity of a binary heap?

Answer: O(1), because the highest-priority element is at the root.

Q10. What is a complete binary tree?

Answer: A binary tree in which every level except possibly the last is completely filled, and the last level is filled from left to right.

Q11. What is heapify?

Answer: The process of restoring the heap property after insertion, deletion or modification.

Q12. What is heapify-up?

Answer: Comparing an inserted element with its parent and moving it upward until the heap property is restored.

Q13. What is heapify-down?

Answer: Moving a node downward by swapping it with the appropriate child until the heap property is restored.

Q14. What is the parent index formula in a zero-based heap?

Answer: (i - 1) / 2 using integer division.

Q15. What is the left child index formula?

Answer: 2 * i + 1.

Q16. What is the right child index formula?

Answer: 2 * i + 2.

Q17. Is a heap a sorted data structure?

Answer: No. It only maintains the heap-order property.

Q18. What is the complexity of building a binary heap using bottom-up heap construction?

Answer: O(n).

Q19. Which priority queue operation is used in Dijkstra's algorithm?

Answer: Extracting the vertex with the minimum tentative distance and inserting or updating candidate distances.

Q20. Which data structure is used in Huffman coding?

Answer: A min-priority queue, commonly implemented using a min-heap.

19. Lesson Summary

  • A priority queue processes elements according to priority.
  • It can be implemented using arrays, linked lists or binary heaps.
  • Unsorted arrays provide fast insertion but slower deletion.
  • Sorted arrays and linked lists provide fast deletion but slower insertion.
  • Binary heaps support O(log n) insertion and deletion and O(1) peek.
  • Min-heaps and max-heaps are important for placement coding problems.
  • Priority queues are used in graph algorithms, scheduling and optimization.
