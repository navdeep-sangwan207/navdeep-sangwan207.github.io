2. Why Do We Need a Circular Queue?

In a basic linear queue, deleted positions at the beginning of an array cannot be reused by a simple enqueue operation.

Example of Space Wastage

Capacity = 5

Initial queue:
[10] [20] [30] [40] [50]
 F                   R

After two dequeue operations:
[  ] [  ] [30] [40] [50]
             F         R

rear = 4

A basic linear queue cannot insert another element,
although two array positions are vacant.

A circular queue solves this problem by connecting the last array position logically back to the first position.

3. What Is a Circular Queue?

A circular queue is a queue in which the final array position is logically connected to the first position.

It follows FIFO (First In, First Out), just like an ordinary queue.

Circular Representation

             +-----+
             |  0  |
             +-----+
           /         \
      +-----+       +-----+
      |  4  |       |  1  |
      +-----+       +-----+
          \           /
           +-----+-----+
           |  3  |  2  |
           +-----+-----+

After index 4, the next index is 0.
The array remains linear in memory. Only the indexing is circular.

4. Circular Queue Representation

We use an array and two variables:

  • front: Index of the first element.
  • rear: Index of the last element.

Initial Conditions

front = -1
rear  = -1

Wrap-Around Formula

Next index: (next index) = (current index + 1) % MAX

For MAX = 5:

(0 + 1) % 5 = 1
(1 + 1) % 5 = 2
(2 + 1) % 5 = 3
(3 + 1) % 5 = 4
(4 + 1) % 5 = 0

5. Empty and Full Conditions

Queue Empty

front == -1

Queue Full

(rear + 1) % MAX == front

The full condition means the next position after rear is already occupied by the front element.

Example

MAX = 5

Index:  0    1    2    3    4
       +----+----+----+----+----+
       | 50 | 60 | 30 | 40 | 45 |
       +----+----+----+----+----+
         R         F

rear = 1
front = 2

(rear + 1) % MAX
= (1 + 1) % 5
= 2

Since 2 == front, queue is full.

6. Enqueue Operation in Circular Queue

Enqueue inserts an element at the rear.

Algorithm

  1. Check whether the queue is full.
  2. If full, report overflow.
  3. If the queue is empty, set front to 0.
  4. Update rear using the modulo formula.
  5. Insert the new value at queue[rear].

C Function

#define MAX 5

int queue[MAX];
int front = -1;
int rear = -1;

int enqueue(int value)
{
    if ((rear + 1) % MAX == front)
        return 0;

    if (front == -1)
        front = 0;

    rear = (rear + 1) % MAX;

    queue[rear] = value;

    return 1;
}

Time complexity: O(1).

7. Dequeue Operation in Circular Queue

Dequeue removes the front element.

Algorithm

  1. Check whether the queue is empty.
  2. Save the front element.
  3. If front equals rear, reset both to -1.
  4. Otherwise, advance front using modulo.

C Function

int dequeue(int *removed)
{
    if (front == -1)
        return 0;

    *removed = queue[front];

    if (front == rear)
    {
        front = -1;
        rear = -1;
    }
    else
    {
        front = (front + 1) % MAX;
    }

    return 1;
}

Time complexity: O(1).

8. Complete C11 Program: Circular Queue

#include <stdio.h>

#define MAX 5

int queue[MAX];
int front = -1;
int rear = -1;

int isEmpty(void)
{
    return front == -1;
}

int isFull(void)
{
    return (rear + 1) % MAX == front;
}

int enqueue(int value)
{
    if (isFull())
    {
        printf("Circular Queue Overflow\n");
        return 0;
    }

    if (isEmpty())
        front = 0;

    rear = (rear + 1) % MAX;
    queue[rear] = value;

    printf("%d inserted\n", value);

    return 1;
}

int dequeue(int *removed)
{
    if (isEmpty())
    {
        printf("Circular Queue Underflow\n");
        return 0;
    }

    *removed = queue[front];

    if (front == rear)
    {
        front = -1;
        rear = -1;
    }
    else
    {
        front = (front + 1) % MAX;
    }

    return 1;
}

int peek(int *value)
{
    if (isEmpty())
        return 0;

    *value = queue[front];

    return 1;
}

void display(void)
{
    if (isEmpty())
    {
        printf("Queue is Empty\n");
        return;
    }

    printf("Queue elements: ");

    int i = front;

    while (1)
    {
        printf("%d ", queue[i]);

        if (i == rear)
            break;

        i = (i + 1) % MAX;
    }

    printf("\n");
}

int main(void)
{
    int removed;
    int value;

    enqueue(10);
    enqueue(20);
    enqueue(30);
    enqueue(40);
    enqueue(50);

    display();

    if (dequeue(&removed))
        printf("Removed: %d\n", removed);

    if (dequeue(&removed))
        printf("Removed: %d\n", removed);

    enqueue(60);
    enqueue(70);

    display();

    if (peek(&value))
        printf("Front: %d\n", value);

    enqueue(80);

    while (dequeue(&removed))
        printf("Removed: %d\n", removed);

    display();

    return 0;
}

10. What Is a Deque?

A deque (Double-Ended Queue) is a linear data structure in which insertion and deletion are allowed at both ends.

Deque Representation

FRONT                           REAR
  |                               |
  v                               v
+------+     +------+     +------+
|  10  | <--> |  20  | <--> |  30  |
+------+     +------+     +------+

Insertion: FRONT or REAR
Deletion:  FRONT or REAR

Deque Operations

OperationMeaning
insertFront()Insert at front.
insertRear()Insert at rear.
deleteFront()Delete from front.
deleteRear()Delete from rear.
getFront()Read front element.
getRear()Read rear element.

11. Types of Deque

A. Input-Restricted Deque

Insertion is allowed at only one end, but deletion is allowed at both ends.

Insertion:
REAR only

Deletion:
FRONT or REAR

B. Output-Restricted Deque

Deletion is allowed at only one end, but insertion is allowed at both ends.

Insertion:
FRONT or REAR

Deletion:
FRONT only

12. Circular Array Representation of a Deque

A deque can be implemented using a circular array with front and rear indices.

Previous Index Formula

Previous index = (index - 1 + MAX) % MAX

Next Index Formula

Next index = (index + 1) % MAX

These formulas allow both ends to wrap around safely.

13. Deque Using a Circular Array: Complete C11 Program

#include <stdio.h>

#define MAX 5

struct Deque
{
    int data[MAX];
    int front;
    int rear;
};

void initialize(struct Deque *dq)
{
    dq->front = -1;
    dq->rear = -1;
}

int isEmpty(const struct Deque *dq)
{
    return dq->front == -1;
}

int isFull(const struct Deque *dq)
{
    return (dq->rear + 1) % MAX == dq->front;
}

int insertFront(struct Deque *dq, int value)
{
    if (isFull(dq))
        return 0;

    if (isEmpty(dq))
    {
        dq->front = 0;
        dq->rear = 0;
    }
    else
    {
        dq->front = (dq->front - 1 + MAX) % MAX;
    }

    dq->data[dq->front] = value;

    return 1;
}

int insertRear(struct Deque *dq, int value)
{
    if (isFull(dq))
        return 0;

    if (isEmpty(dq))
    {
        dq->front = 0;
        dq->rear = 0;
    }
    else
    {
        dq->rear = (dq->rear + 1) % MAX;
    }

    dq->data[dq->rear] = value;

    return 1;
}

int deleteFront(struct Deque *dq, int *removed)
{
    if (isEmpty(dq))
        return 0;

    *removed = dq->data[dq->front];

    if (dq->front == dq->rear)
    {
        dq->front = -1;
        dq->rear = -1;
    }
    else
    {
        dq->front = (dq->front + 1) % MAX;
    }

    return 1;
}

int deleteRear(struct Deque *dq, int *removed)
{
    if (isEmpty(dq))
        return 0;

    *removed = dq->data[dq->rear];

    if (dq->front == dq->rear)
    {
        dq->front = -1;
        dq->rear = -1;
    }
    else
    {
        dq->rear = (dq->rear - 1 + MAX) % MAX;
    }

    return 1;
}

void display(const struct Deque *dq)
{
    if (isEmpty(dq))
    {
        printf("Deque is Empty\n");
        return;
    }

    int i = dq->front;

    printf("Deque: ");

    while (1)
    {
        printf("%d ", dq->data[i]);

        if (i == dq->rear)
            break;

        i = (i + 1) % MAX;
    }

    printf("\n");
}

int main(void)
{
    struct Deque dq;
    int removed;

    initialize(&dq);

    insertRear(&dq, 20);
    insertRear(&dq, 30);
    insertFront(&dq, 10);
    insertRear(&dq, 40);

    display(&dq);

    if (deleteFront(&dq, &removed))
        printf("Deleted from front: %d\n", removed);

    if (deleteRear(&dq, &removed))
        printf("Deleted from rear: %d\n", removed);

    display(&dq);

    insertFront(&dq, 5);
    insertRear(&dq, 50);

    display(&dq);

    if (!insertRear(&dq, 60))
        printf("Deque Overflow\n");

    while (deleteFront(&dq, &removed))
        printf("Removed: %d\n", removed);

    display(&dq);

    return 0;
}

Expected Output

Deleted from front: 10
Deleted from rear: 40
Deque: 20 30
Deque: 5 20 30 50
Deque Overflow
Removed: 5
Removed: 20
Removed: 30
Removed: 50
Deque is Empty

16. Applications of Circular Queue and Deque

Circular Queue Applications

  • Round-robin CPU scheduling.
  • Keyboard buffers.
  • Network packet buffers.
  • Audio and video streaming buffers.
  • Producer-consumer systems.

Deque Applications

  • Sliding-window maximum and minimum.
  • Palindrome checking.
  • Task scheduling.
  • Implementing both stack-like and queue-like operations.
  • 0-1 BFS using a deque.

17. Common Programming Mistakes

  1. Using rear == MAX - 1 as the circular queue full condition.
  2. Forgetting modulo when advancing front or rear.
  3. Incorrectly resetting front and rear after deleting the final element.
  4. Confusing the full and empty conditions.
  5. Using index - 1 without adding MAX before modulo.
  6. Forgetting that a deque supports both-end operations.
  7. Updating front or rear before checking whether the deque is empty.
  8. Using ordinary linear indexing in circular display operations.
  9. Failing to distinguish input-restricted and output-restricted deques.
  10. Not testing wrap-around and single-element cases.

18. Placement Interview Questions and Answers

Q1. What is a circular queue?

Answer: A queue in which the final array position is logically connected to the first position to reuse vacant slots.

Q2. Why is a circular queue required?

Answer: It avoids the space wastage associated with a basic linear array queue.

Q3. What is the circular next-index formula?

Answer: (index + 1) % MAX.

Q4. What is the previous-index formula?

Answer: (index - 1 + MAX) % MAX.

Q5. What is the full condition in this implementation?

Answer: (rear + 1) % MAX == front.

Q6. What is the empty condition?

Answer: front == -1.

Q7. What is wrap-around?

Answer: Moving from the last array index back to index 0.

Q8. What is a deque?

Answer: A double-ended queue that supports insertion and deletion at both ends.

Q9. What does deque stand for?

Answer: Double-Ended Queue.

Q10. What is an input-restricted deque?

Answer: A deque where insertion is allowed at only one end but deletion is allowed at both ends.

Q11. What is an output-restricted deque?

Answer: A deque where deletion is allowed at only one end but insertion is allowed at both ends.

Q12. Can a deque be implemented using a circular array?

Answer: Yes. Circular indexing supports insertion and deletion at both ends.

Q13. What is the time complexity of circular queue enqueue?

Answer: O(1).

Q14. What is the time complexity of deque insertion at front?

Answer: O(1) in a circular array implementation.

Q15. What is the difference between a queue and a deque?

Answer: A standard queue inserts at rear and deletes at front. A deque permits both operations at either end.

Q16. What is the use of a circular queue in CPU scheduling?

Answer: It can support round-robin scheduling by cycling through processes.

Q17. Which structure is useful for sliding-window maximum?

Answer: A monotonic deque.

Q18. What is the complexity of displaying a circular queue?

Answer: O(n), where n is the number of stored elements.

Q19. What should happen when the last element is deleted?

Answer: Both front and rear should be reset to -1 in this representation.

Q20. Can a deque behave like a stack?

Answer: Yes. Inserting and deleting at the same end provides stack-like LIFO behavior.

21. Lesson Summary

  • A circular queue reuses vacant array positions through wrap-around indexing.
  • The modulo operator is used to calculate circular indices.
  • The full condition is (rear + 1) % MAX == front in this implementation.
  • A deque supports insertion and deletion at both ends.
  • Input-restricted and output-restricted deques limit different operations.
  • Circular queue and deque operations can run in O(1) time.
  • These structures are important in scheduling, buffering and sliding-window problems.
