3. Problem 1: Balanced Parentheses

Problem: Given a string containing brackets, determine whether the brackets are balanced.

Examples

Input:  { [ ( ) ] }
Output: Balanced

Input:  { [ ( ] ) }
Output: Not Balanced

Input:  ( ( ) )
Output: Balanced

Input:  ( ( )
Output: Not Balanced

Approach

  1. Traverse the string from left to right.
  2. Push opening brackets onto a stack.
  3. For every closing bracket, check the stack top.
  4. If the top is not its matching opening bracket, return false.
  5. At the end, the stack must be empty.

Complete C11 Program

#include <stdio.h>
#include <string.h>

#define MAX 1000

int isMatching(char open, char close)
{
    return (open == '(' && close == ')') ||
           (open == '[' && close == ']') ||
           (open == '{' && close == '}');
}

int isBalanced(const char *expression)
{
    char stack[MAX];
    int top = -1;

    for (int i = 0; expression[i] != '\0'; i++)
    {
        char ch = expression[i];

        if (ch == '(' || ch == '[' || ch == '{')
        {
            if (top == MAX - 1)
                return 0;

            stack[++top] = ch;
        }
        else if (ch == ')' || ch == ']' || ch == '}')
        {
            if (top == -1)
                return 0;

            if (!isMatching(stack[top], ch))
                return 0;

            top--;
        }
    }

    return top == -1;
}

int main(void)
{
    const char *expression = "{[()]}";

    if (isBalanced(expression))
        printf("Balanced\n");
    else
        printf("Not Balanced\n");

    return 0;
}

Expected Output

Balanced

Time complexity: O(n).

Space complexity: O(n).

Interview extension: Modify the solution to ignore ordinary characters and validate only bracket characters. The program above already follows this rule.

4. Problem 2: Evaluate a Postfix Expression

Problem: Evaluate a postfix expression using a stack.

Example

Infix:
5 + 3 * 2

Postfix:
5 3 2 * +

Evaluation:
3 * 2 = 6
5 + 6 = 11

Answer: 11

Algorithm

  1. Read tokens from left to right.
  2. If the token is an operand, push it.
  3. If the token is an operator, pop the right operand first, then the left operand.
  4. Perform the operation and push the result.
  5. After processing all tokens, exactly one value should remain.

Complete C11 Program

This implementation accepts single-digit non-negative operands separated by spaces and the operators +, -, * and /.

#include <stdio.h>
#include <ctype.h>

#define MAX 100

int evaluatePostfix(const char *expression, int *result)
{
    int stack[MAX];
    int top = -1;

    for (int i = 0; expression[i] != '\0'; i++)
    {
        char ch = expression[i];

        if (isspace((unsigned char)ch))
            continue;

        if (isdigit((unsigned char)ch))
        {
            if (top == MAX - 1)
                return 0;

            stack[++top] = ch - '0';
        }
        else
        {
            if (top < 1)
                return 0;

            int right = stack[top--];
            int left = stack[top--];
            int value;

            switch (ch)
            {
                case '+':
                    value = left + right;
                    break;

                case '-':
                    value = left - right;
                    break;

                case '*':
                    value = left * right;
                    break;

                case '/':
                    if (right == 0)
                        return 0;

                    if (left == (-2147483647 - 1) &&
                        right == -1)
                        return 0;

                    value = left / right;
                    break;

                default:
                    return 0;
            }

            stack[++top] = value;
        }
    }

    if (top != 0)
        return 0;

    *result = stack[top];

    return 1;
}

int main(void)
{
    const char expression[] = "5 3 2 * +";
    int result;

    if (evaluatePostfix(expression, &result))
        printf("Result = %d\n", result);
    else
        printf("Invalid expression\n");

    return 0;
}

Expected Output

Result = 11

Time complexity: O(n).

Space complexity: O(n).

This example supports only single-digit operands and does not detect general integer overflow. A production evaluator should tokenize multi-digit numbers and perform checked arithmetic.

5. Problem 3: Implement a Queue Using Two Stacks

Problem: Implement FIFO queue operations using two stacks.

Concept

Stack 1: Input stack
Stack 2: Output stack

Enqueue:
Push into Stack 1.

Dequeue:
If Stack 2 is empty:
    Move all elements from Stack 1 to Stack 2.

Pop from Stack 2.

Complete C11 Program

#include <stdio.h>

#define MAX 100

struct Queue
{
    int input[MAX];
    int output[MAX];
    int topInput;
    int topOutput;
};

void initialize(struct Queue *q)
{
    q->topInput = -1;
    q->topOutput = -1;
}

int enqueue(struct Queue *q, int value)
{
    if (q->topInput == MAX - 1)
        return 0;

    q->input[++q->topInput] = value;

    return 1;
}

int transfer(struct Queue *q)
{
    while (q->topInput != -1)
    {
        if (q->topOutput == MAX - 1)
            return 0;

        q->output[++q->topOutput] =
            q->input[q->topInput--];
    }

    return 1;
}

int dequeue(struct Queue *q, int *removed)
{
    if (q->topOutput == -1)
    {
        if (!transfer(q))
            return 0;
    }

    if (q->topOutput == -1)
        return 0;

    *removed = q->output[q->topOutput--];

    return 1;
}

int main(void)
{
    struct Queue q;
    int removed;

    initialize(&q);

    enqueue(&q, 10);
    enqueue(&q, 20);
    enqueue(&q, 30);

    if (dequeue(&q, &removed))
        printf("Removed: %d\n", removed);

    enqueue(&q, 40);

    while (dequeue(&q, &removed))
        printf("Removed: %d\n", removed);

    return 0;
}

Expected Output

Removed: 10
Removed: 20
Removed: 30
Removed: 40

Amortized enqueue: O(1).

Amortized dequeue: O(1).

Worst-case dequeue: O(n), when all input elements must be transferred.

6. Problem 4: Implement a Stack Using Two Queues

Problem: Implement LIFO stack operations using two FIFO queues.

Approach: Costly Push

  1. Insert the new value into the empty auxiliary queue.
  2. Move all existing elements from the main queue into the auxiliary queue.
  3. Swap the roles of the two queues.
  4. Pop from the front of the main queue.

Complete C11 Program

#include <stdio.h>

#define MAX 100

struct Queue
{
    int data[MAX];
    int front;
    int rear;
    int count;
};

struct Stack
{
    struct Queue q1;
    struct Queue q2;
};

void queueInit(struct Queue *q)
{
    q->front = 0;
    q->rear = -1;
    q->count = 0;
}

int queueEmpty(const struct Queue *q)
{
    return q->count == 0;
}

int queuePush(struct Queue *q, int value)
{
    if (q->count == MAX)
        return 0;

    q->rear = (q->rear + 1) % MAX;
    q->data[q->rear] = value;
    q->count++;

    return 1;
}

int queuePop(struct Queue *q, int *value)
{
    if (queueEmpty(q))
        return 0;

    *value = q->data[q->front];
    q->front = (q->front + 1) % MAX;
    q->count--;

    return 1;
}

void stackInit(struct Stack *s)
{
    queueInit(&s->q1);
    queueInit(&s->q2);
}

int push(struct Stack *s, int value)
{
    int temp;

    if (!queuePush(&s->q2, value))
        return 0;

    while (queuePop(&s->q1, &temp))
    {
        if (!queuePush(&s->q2, temp))
            return 0;
    }

    struct Queue swap = s->q1;
    s->q1 = s->q2;
    s->q2 = swap;

    return 1;
}

int pop(struct Stack *s, int *removed)
{
    return queuePop(&s->q1, removed);
}

int main(void)
{
    struct Stack s;
    int removed;

    stackInit(&s);

    push(&s, 10);
    push(&s, 20);
    push(&s, 30);

    while (pop(&s, &removed))
        printf("Popped: %d\n", removed);

    return 0;
}

Expected Output

Popped: 30
Popped: 20
Popped: 10

Push: O(n).

Pop: O(1).

7. Problem 5: Next Greater Element

Problem: For every element in an array, find the first greater element to its right. If no greater element exists, return -1.

Example

Input:
[4, 5, 2, 10, 8]

Output:
[5, 10, 10, -1, -1]

Approach

Use a monotonic decreasing stack of indices. Traverse the array from right to left. While the stack top points to a value less than or equal to the current value, remove it.

Complete C11 Program

#include <stdio.h>

void nextGreaterElement(const int a[], int n, int result[])
{
    int stack[n];
    int top = -1;

    for (int i = n - 1; i >= 0; i--)
    {
        while (top != -1 &&
               a[stack[top]] <= a[i])
        {
            top--;
        }

        result[i] = (top == -1) ? -1 : a[stack[top]];

        stack[++top] = i;
    }
}

int main(void)
{
    int a[] = {4, 5, 2, 10, 8};
    int n = (int)(sizeof(a) / sizeof(a[0]));
    int result[n];

    nextGreaterElement(a, n, result);

    printf("Next Greater Elements: ");

    for (int i = 0; i < n; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}

Expected Output

Next Greater Elements: 5 10 10 -1 -1

Time complexity: O(n) amortized.

Space complexity: O(n).

8. Problem 6: Sliding Window Maximum Using Deque

Problem: Given an array and window size K, find the maximum value in every contiguous window of size K.

Example

Array:
[1, 3, -1, -3, 5, 3, 6, 7]

K = 3

Windows:
[1, 3, -1] -> 3
[3, -1, -3] -> 3
[-1, -3, 5] -> 5
[-3, 5, 3] -> 5
[5, 3, 6] -> 6
[3, 6, 7] -> 7

Output:
[3, 3, 5, 5, 6, 7]

Approach

  1. Store array indices in a deque.
  2. Remove indices that have moved outside the current window.
  3. Remove indices from the rear while their values are less than or equal to the current value.
  4. Insert the current index at the rear.
  5. Once the first window is complete, the front index identifies its maximum.

Complete C11 Program

#include <stdio.h>

void slidingWindowMaximum(const int a[],
                          int n, int k, int result[])
{
    int deque[n];
    int front = 0;
    int rear = -1;
    int resultIndex = 0;

    for (int i = 0; i < n; i++)
    {
        /* Remove indices outside the window. */

        while (front <= rear &&
               deque[front] <= i - k)
        {
            front++;
        }

        /* Maintain decreasing values in deque. */

        while (front <= rear &&
               a[deque[rear]] <= a[i])
        {
            rear--;
        }

        deque[++rear] = i;

        if (i >= k - 1)
            result[resultIndex++] = a[deque[front]];
    }
}

int main(void)
{
    int a[] = {1, 3, -1, -3, 5, 3, 6, 7};
    int n = (int)(sizeof(a) / sizeof(a[0]));
    int k = 3;
    int result[n - k + 1];

    if (k < 1 || k > n)
    {
        printf("Invalid window size\n");
        return 1;
    }

    slidingWindowMaximum(a, n, k, result);

    printf("Sliding Window Maximum: ");

    for (int i = 0; i < n - k + 1; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}

Expected Output

Sliding Window Maximum: 3 3 5 5 6 7

Time complexity: O(n) amortized.

Space complexity: O(n).

Each index enters and leaves the deque at most once. This is why the overall algorithm runs in O(n), not O(n × K).

9. Problem 7: Design a Min Stack

Problem: Design a stack supporting push, pop, top and getMin in O(1) time.

Approach

Maintain two stacks:

  • Main stack stores all values.
  • Minimum stack stores the minimum value at each corresponding depth.

Complete C11 Program

#include <stdio.h>

#define MAX 100

struct MinStack
{
    int data[MAX];
    int minimum[MAX];
    int top;
};

void initialize(struct MinStack *s)
{
    s->top = -1;
}

int isEmpty(const struct MinStack *s)
{
    return s->top == -1;
}

int push(struct MinStack *s, int value)
{
    if (s->top == MAX - 1)
        return 0;

    s->top++;
    s->data[s->top] = value;

    if (s->top == 0 ||
        value <= s->minimum[s->top - 1])
    {
        s->minimum[s->top] = value;
    }
    else
    {
        s->minimum[s->top] =
            s->minimum[s->top - 1];
    }

    return 1;
}

int pop(struct MinStack *s, int *removed)
{
    if (isEmpty(s))
        return 0;

    *removed = s->data[s->top--];

    return 1;
}

int topValue(const struct MinStack *s, int *value)
{
    if (isEmpty(s))
        return 0;

    *value = s->data[s->top];

    return 1;
}

int getMin(const struct MinStack *s, int *minimum)
{
    if (isEmpty(s))
        return 0;

    *minimum = s->minimum[s->top];

    return 1;
}

int main(void)
{
    struct MinStack s;
    int value;

    initialize(&s);

    push(&s, 30);
    push(&s, 10);
    push(&s, 20);
    push(&s, 5);

    if (getMin(&s, &value))
        printf("Minimum: %d\n", value);

    if (pop(&s, &value))
        printf("Popped: %d\n", value);

    if (getMin(&s, &value))
        printf("Minimum: %d\n", value);

    if (topValue(&s, &value))
        printf("Top: %d\n", value);

    return 0;
}

Expected Output

Minimum: 5
Popped: 5
Minimum: 10
Top: 20

Push: O(1).

Pop: O(1).

Get minimum: O(1).

Space: O(n).

10. Problem 8: Reverse a Queue Using a Stack

Problem: Reverse the order of elements in a queue using a stack.

Approach

  1. Remove every queue element and push it onto a stack.
  2. Pop every stack element and insert it back into the queue.

Complete C11 Program

#include <stdio.h>

#define MAX 100

void reverseQueue(int queue[], int n)
{
    int stack[MAX];
    int top = -1;

    for (int i = 0; i < n; i++)
        stack[++top] = queue[i];

    for (int i = 0; i < n; i++)
        queue[i] = stack[top--];
}

int main(void)
{
    int queue[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(queue) / sizeof(queue[0]));

    reverseQueue(queue, n);

    printf("Reversed Queue: ");

    for (int i = 0; i < n; i++)
        printf("%d ", queue[i]);

    printf("\n");

    return 0;
}

Expected Output

Reversed Queue: 50 40 30 20 10

Time complexity: O(n).

Space complexity: O(n).

11. Problem 9: First Non-Repeating Character in a Stream

Problem: For every character arriving in a stream, report the first character that has appeared exactly once so far. Print -1 if no such character exists.

Example

Input:
a a b c

Output:
a -1 b b

Complete C11 Program

#include <stdio.h>

#define ALPHABET 256
#define MAX 100

void firstNonRepeating(const char *stream)
{
    int frequency[ALPHABET] = {0};
    unsigned char queue[MAX];
    int front = 0;
    int rear = -1;
    int count = 0;

    for (int i = 0; stream[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)stream[i];

        if (count == MAX)
        {
            printf("Input too long\n");
            return;
        }

        frequency[ch]++;

        queue[++rear] = ch;
        count++;

        while (count > 0 &&
               frequency[queue[front]] > 1)
        {
            front++;
            count--;
        }

        if (count == 0)
            printf("-1 ");
        else
            printf("%c ", queue[front]);
    }

    printf("\n");
}

int main(void)
{
    const char stream[] = "aabc";

    firstNonRepeating(stream);

    return 0;
}

Expected Output

a -1 b b

Time complexity: O(n).

Space complexity: O(n + 256).

14. Common Interview Mistakes

  1. Not identifying whether the problem requires LIFO or FIFO behavior.
  2. Using a stack when a monotonic deque is more efficient.
  3. Forgetting to pop the right operand before the left operand in postfix evaluation.
  4. Not handling empty stack and queue conditions.
  5. Using an incorrect comparison in next greater element problems.
  6. Forgetting to remove expired indices from a sliding-window deque.
  7. Ignoring duplicate values in minimum-stack design.
  8. Reporting O(n) complexity for an algorithm that can be optimized to O(n).
  9. Not testing a single-element input.
  10. Not testing duplicate, negative and empty inputs.

16. Technical Interview Questions and Answers

Q1. Why is a stack called a LIFO data structure?

Answer: Because the last inserted element is the first one removed.

Q2. Why is a queue called a FIFO data structure?

Answer: Because the first inserted element is the first one removed.

Q3. What is a monotonic stack?

Answer: A stack maintained in increasing or decreasing order to solve problems such as next greater and next smaller element efficiently.

Q4. What is a monotonic deque?

Answer: A deque that maintains elements in a monotonic order, commonly used for sliding-window maximum and minimum problems.

Q5. How can a queue be implemented using two stacks?

Answer: One stack handles insertion, and the second stack handles removal. Elements are transferred when the output stack becomes empty.

Q6. What is amortized complexity?

Answer: It analyzes the average cost per operation over a sequence of operations, even if individual operations have different costs.

Q7. What is the complexity of next greater element using a monotonic stack?

Answer: O(n) amortized because each index is pushed and popped at most once.

Q8. How can a stack be implemented using queues?

Answer: Using two queues, by rearranging elements during insertion or removal to maintain LIFO order.

Q9. What is a minimum stack?

Answer: A stack that supports retrieving its minimum element in O(1) time along with normal stack operations.

Q10. Why is a deque useful for sliding-window maximum?

Answer: It maintains candidate maximum indices in decreasing order and removes expired indices efficiently.

Q11. What is stack overflow?

Answer: An attempt to push an element into a stack that has no available capacity.

Q12. What is stack underflow?

Answer: An attempt to remove an element from an empty stack.

Q13. What is queue overflow?

Answer: An attempt to insert into a full fixed-capacity queue.

Q14. What is queue underflow?

Answer: An attempt to remove an element from an empty queue.

Q15. Which data structure is used in function-call management?

Answer: The call stack.
