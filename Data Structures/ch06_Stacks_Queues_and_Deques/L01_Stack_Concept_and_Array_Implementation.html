2. What Is a Stack?

A stack is a linear data structure in which insertion and deletion take place at one end, called the TOP.

It follows the LIFO principle.

LIFO: Last In, First Out.

Real-Life Examples

  • A stack of plates.
  • Undo and redo operations in text editors.
  • Function calls and recursion.
  • Browser navigation history.
  • Expression evaluation.

Stack Representation

        TOP
         |
         v
      +------+
      |  40  |  <-- Last inserted
      +------+
      |  30  |
      +------+
      |  20  |
      +------+
      |  10  |
      +------+
       Bottom

The element 40 will be removed first because it was inserted last.

4. Array Representation of a Stack

A stack can be implemented using a fixed-size array and an integer variable named top.

Initialization

#define MAX 5

int stack[MAX];
int top = -1;

Here:

  • MAX represents the maximum capacity.
  • stack stores the elements.
  • top = -1 indicates that the stack is empty.

Stack Index Representation

Index:    0    1    2    3    4
       +----+----+----+----+----+
Stack: | 10 | 20 | 30 | 40 |    |
       +----+----+----+----+----+
                         ^
                         |
                       TOP = 3
For an array of capacity MAX, the valid indexes are 0 to MAX-1. The stack is full when top == MAX-1.

5. PUSH Operation

The push operation inserts a new element at the top of the stack.

Algorithm

  1. Check whether the stack is full.
  2. If full, report stack overflow.
  3. Otherwise increment top.
  4. Insert the new element at stack[top].

C Function

#define MAX 5

int stack[MAX];
int top = -1;

int push(int value)
{
    if (top == MAX - 1)
    {
        printf("Stack Overflow\n");
        return 0;
    }

    top++;
    stack[top] = value;

    return 1;
}

Dry Run

Initially:
top = -1

push(10):
top = 0
stack[0] = 10

push(20):
top = 1
stack[1] = 20

push(30):
top = 2
stack[2] = 30

Stack:
30  <-- TOP
20
10

Time complexity: O(1).

6. POP Operation

The pop operation removes the top element from the stack.

Algorithm

  1. Check whether the stack is empty.
  2. If empty, report stack underflow.
  3. Otherwise read the top element.
  4. Decrement top.
  5. Return the removed element.

C Function

int pop(int *removed)
{
    if (top == -1)
    {
        printf("Stack Underflow\n");
        return 0;
    }

    *removed = stack[top];
    top--;

    return 1;
}

Dry Run

Before POP:

Index:  0    1    2
       +----+----+----+
       | 10 | 20 | 30 |
       +----+----+----+
                  ^
                TOP=2

pop()

Removed element = 30
top = 1

After POP:

Index:  0    1
       +----+----+
       | 10 | 20 |
       +----+----+
             ^
           TOP=1

Time complexity: O(1).

Decrementing top logically removes the element. The old value may still physically exist in the array, but it is no longer part of the stack.

7. PEEK Operation

The peek operation returns the top element without removing it.

C Function

int peek(int *value)
{
    if (top == -1)
    {
        printf("Stack is Empty\n");
        return 0;
    }

    *value = stack[top];

    return 1;
}

Time complexity: O(1).

Difference Between POP and PEEK

POPPEEK
Removes the top element.Does not remove the top element.
Decreases top.Does not change top.
Changes stack state.Only reads stack state.

9. Display Stack Elements

Display elements from top to bottom using a loop.

C Function

void display(void)
{
    if (isEmpty())
    {
        printf("Stack is Empty\n");
        return;
    }

    printf("Stack elements (TOP to BOTTOM):\n");

    for (int i = top; i >= 0; i--)
    {
        printf("%d\n", stack[i]);
    }
}

Time complexity: O(n).

11. Complete C11 Program: Stack Using Array

This program implements push, pop, peek, display, isEmpty and isFull operations.

#include <stdio.h>

#define MAX 5

int stack[MAX];
int top = -1;

int isEmpty(void)
{
    return top == -1;
}

int isFull(void)
{
    return top == MAX - 1;
}

int push(int value)
{
    if (isFull())
    {
        printf("Stack Overflow\n");
        return 0;
    }

    stack[++top] = value;

    printf("%d pushed into stack\n", value);

    return 1;
}

int pop(int *removed)
{
    if (isEmpty())
    {
        printf("Stack Underflow\n");
        return 0;
    }

    *removed = stack[top--];

    return 1;
}

int peek(int *value)
{
    if (isEmpty())
    {
        printf("Stack is Empty\n");
        return 0;
    }

    *value = stack[top];

    return 1;
}

void display(void)
{
    if (isEmpty())
    {
        printf("Stack is Empty\n");
        return;
    }

    printf("Stack elements (TOP to BOTTOM):\n");

    for (int i = top; i >= 0; i--)
        printf("%d\n", stack[i]);
}

int main(void)
{
    int removed;
    int value;

    push(10);
    push(20);
    push(30);
    push(40);

    display();

    if (peek(&value))
        printf("Top element: %d\n", value);

    if (pop(&removed))
        printf("Popped element: %d\n", removed);

    display();

    push(50);
    push(60);

    push(70);

    if (peek(&value))
        printf("Current top: %d\n", value);

    return 0;
}

Expected Output

20 pushed into stack
30 pushed into stack
40 pushed into stack
Stack elements (TOP to BOTTOM):
40
30
20
10
Top element: 40
Popped element: 40
Stack elements (TOP to BOTTOM):
30
20
10
50 pushed into stack
60 pushed into stack
Stack Overflow
Current top: 60

./stack_array

14. Common Programming Mistakes

  1. Initializing top to 0 instead of -1 for this implementation.
  2. Forgetting to check overflow before push.
  3. Forgetting to check underflow before pop.
  4. Accessing stack[top] when top is -1.
  5. Using an invalid array index.
  6. Confusing pop with peek.
  7. Decreasing top before saving the removed value.
  8. Assuming the array-based stack can grow beyond its declared capacity.
  9. Not handling an empty stack in display.

15. Placement Interview Questions and Answers

Q1. What is a stack?

Answer: A stack is a linear data structure in which insertion and deletion occur at one end called the top.

Q2. What is LIFO?

Answer: Last In, First Out. The most recently inserted element is removed first.

Q3. What is the top variable?

Answer: It stores the index of the current top element in an array-based stack.

Q4. Why is top initialized to -1?

Answer: Because no valid array element is present in the stack initially.

Q5. What is stack overflow?

Answer: An insertion attempt when the stack has reached its maximum capacity.

Q6. What is stack underflow?

Answer: A removal attempt when the stack is empty.

Q7. What is the time complexity of push?

Answer: O(1) for an array-based stack.

Q8. What is the time complexity of pop?

Answer: O(1).

Q9. What is the difference between pop and peek?

Answer: Pop removes the top element; peek reads it without removal.

Q10. Can a stack be implemented using an array?

Answer: Yes. A fixed-size array and a top variable can implement a stack.

Q11. Can a stack be implemented using a linked list?

Answer: Yes. Nodes can be inserted and deleted at the head of a singly linked list.

Q12. What is the limitation of an array-based stack?

Answer: Its capacity is fixed unless a dynamically resizable array is used.

Q13. What are the applications of stacks?

Answer: Function calls, recursion, expression evaluation, parentheses matching, DFS and undo operations.

Q14. Is stack a linear data structure?

Answer: Yes. Its elements are organized in a linear sequence.

Q15. What is the complexity of displaying a stack?

Answer: O(n), because all elements must be visited.

Q16. Does peek modify the stack?

Answer: No. It only reads the top element.

Q17. Can an empty stack have top equal to zero?

Answer: It can in a different implementation that uses a count or next-free-index convention. In this lesson's implementation, an empty stack has top = -1.

Q18. Which data structure manages recursive function calls?

Answer: A call stack.

Q19. What is the difference between static and dynamic stack allocation?

Answer: A static array has a fixed capacity. A dynamically allocated stack can allocate memory as needed, subject to available memory.

Q20. Why is a stack useful in expression evaluation?

Answer: It temporarily stores operators and operands while respecting precedence and evaluation order.
