2. Why Implement a Stack Using a Linked List?

An array-based stack normally has a fixed capacity. A linked-list-based stack allocates nodes dynamically as elements are inserted.

Example

TOP
 |
 v
+------+------+
|  30  |   *--|----> Node 20
+------+------+
                   |
                   v
              +------+------+
              |  20  |   *--|----> Node 10
              +------+------+
                                   |
                                   v
                              +------+------+
                              |  10  | NULL |
                              +------+------+

The top pointer always points to the first node of the linked list.

3. Node Structure

Each stack node contains:

  • data: Stores the element.
  • next: Stores the address of the next node.

C Structure

struct Node
{
    int data;
    struct Node *next;
};

struct Node *top = NULL;

Initially, top is NULL because the stack contains no nodes.

4. PUSH Operation

In a linked-list-based stack, push inserts a new node at the beginning of the linked list.

Algorithm

  1. Allocate memory for a new node.
  2. Check whether allocation succeeded.
  3. Store the new value in the node.
  4. Set newNode->next to the current top.
  5. Update top to point to the new node.

C Function

int push(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
    {
        printf("Memory allocation failed\n");
        return 0;
    }

    newNode->data = value;
    newNode->next = top;

    top = newNode;

    return 1;
}

Dry Run

Initially:
top = NULL

push(10):

TOP -> 10 -> NULL

push(20):

TOP -> 20 -> 10 -> NULL

push(30):

TOP -> 30 -> 20 -> 10 -> NULL

Time complexity: O(1).

5. POP Operation

The pop operation removes the first node of the linked list because that node represents the top element.

Algorithm

  1. Check whether top is NULL.
  2. If NULL, report stack underflow.
  3. Store the current top node in a temporary pointer.
  4. Read its data.
  5. Move top to the next node.
  6. Free the removed node.

C Function

int pop(int *removed)
{
    if (top == NULL)
    {
        printf("Stack Underflow\n");
        return 0;
    }

    struct Node *temp = top;

    *removed = temp->data;

    top = top->next;

    free(temp);

    return 1;
}

Dry Run

Before POP:

TOP -> 30 -> 20 -> 10 -> NULL

POP:

Removed element = 30

After POP:

TOP -> 20 -> 10 -> NULL

Time complexity: O(1).

Always save the current top node before changing the top pointer. Then free the saved node. Otherwise, the allocated memory may become inaccessible.

6. PEEK Operation

Peek returns the data stored in the top node without removing that node.

C Function

int peek(int *value)
{
    if (top == NULL)
    {
        printf("Stack is Empty\n");
        return 0;
    }

    *value = top->data;

    return 1;
}

Time complexity: O(1).

7. Check Whether the Stack Is Empty

int isEmpty(void)
{
    return top == NULL;
}

Unlike the array implementation, there is no need for a top index initialized to -1. The NULL pointer represents an empty stack.

8. Display Stack Elements

Traverse the linked list from top to bottom.

C Function

void display(void)
{
    if (top == NULL)
    {
        printf("Stack is Empty\n");
        return;
    }

    struct Node *temp = top;

    printf("Stack elements (TOP to BOTTOM):\n");

    while (temp != NULL)
    {
        printf("%d\n", temp->data);
        temp = temp->next;
    }
}

Time complexity: O(n).

9. Memory Management in Linked-List Stack

Every push operation allocates a node dynamically.

struct Node *newNode = malloc(sizeof *newNode);

Every successful pop operation releases the removed node.

free(temp);

When the complete stack is no longer required, all remaining nodes must be freed.

Clear Stack Function

void clearStack(void)
{
    while (top != NULL)
    {
        struct Node *temp = top;
        top = top->next;
        free(temp);
    }
}
A linked-list stack has no fixed array capacity, but it is still limited by available memory and allocation success. Always check the return value of malloc().

10. Complete C11 Program: Stack Using Linked List

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *top = NULL;

int isEmpty(void)
{
    return top == NULL;
}

int push(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
    {
        printf("Memory allocation failed\n");
        return 0;
    }

    newNode->data = value;
    newNode->next = top;

    top = newNode;

    printf("%d pushed into stack\n", value);

    return 1;
}

int pop(int *removed)
{
    if (isEmpty())
    {
        printf("Stack Underflow\n");
        return 0;
    }

    struct Node *temp = top;

    *removed = temp->data;

    top = top->next;

    free(temp);

    return 1;
}

int peek(int *value)
{
    if (isEmpty())
    {
        printf("Stack is Empty\n");
        return 0;
    }

    *value = top->data;

    return 1;
}

void display(void)
{
    if (isEmpty())
    {
        printf("Stack is Empty\n");
        return;
    }

    struct Node *temp = top;

    printf("Stack elements (TOP to BOTTOM):\n");

    while (temp != NULL)
    {
        printf("%d\n", temp->data);
        temp = temp->next;
    }
}

void clearStack(void)
{
    while (top != NULL)
    {
        struct Node *temp = top;
        top = top->next;
        free(temp);
    }
}

int main(void)
{
    int removed;
    int value;

    if (!push(10) ||
        !push(20) ||
        !push(30) ||
        !push(40))
    {
        clearStack();
        return 1;
    }

    display();

    if (peek(&value))
        printf("Top element: %d\n", value);

    if (pop(&removed))
        printf("Popped element: %d\n", removed);

    display();

    if (!push(50))
    {
        clearStack();
        return 1;
    }

    display();

    if (pop(&removed))
        printf("Popped element: %d\n", removed);

    if (pop(&removed))
        printf("Popped element: %d\n", removed);

    clearStack();

    printf("Stack cleared successfully\n");

    return 0;
}

  • Dynamic expression processing.
  • Function call and recursion management.
  • Undo and redo systems.
  • Depth-first search.
  • Backtracking algorithms.
  • Dynamic data processing where capacity is not known in advance.

14. Common Programming Mistakes

  1. Not initializing top to NULL.
  2. Forgetting to allocate memory before inserting a node.
  3. Not checking whether malloc() returns NULL.
  4. Changing top before saving the node that must be freed.
  5. Forgetting to call free() after pop.
  6. Dereferencing top when it is NULL.
  7. Forgetting to free all remaining nodes before program termination.
  8. Using a node after freeing it.
  9. Incorrectly changing the next pointer during push.

15. Placement Interview Questions and Answers

Q1. How can a stack be implemented using a linked list?

Answer: Use a singly linked list with a top pointer. Insert and delete nodes at the head.

Q2. What does top represent?

Answer: It points to the first node, which contains the most recently inserted element.

Q3. Why is top initialized to NULL?

Answer: Because the stack initially contains no nodes.

Q4. Where is a new node inserted during push?

Answer: At the beginning of the linked list.

Q5. Where is a node deleted during pop?

Answer: From the beginning of the linked list.

Q6. What is the time complexity of push?

Answer: O(1).

Q7. What is the time complexity of pop?

Answer: O(1).

Q8. Why is malloc() used?

Answer: It dynamically allocates memory for each new stack node.

Q9. Why is free() required?

Answer: It releases dynamically allocated memory when a node is removed or the stack is cleared.

Q10. What is stack underflow?

Answer: It occurs when pop or peek is attempted on an empty stack.

Q11. Does a linked-list stack have a fixed capacity?

Answer: No fixed array capacity is required. It grows dynamically until memory allocation fails.

Q12. Can a linked-list stack experience overflow?

Answer: Allocation can fail because available memory is exhausted or a system allocation limit is reached.

Q13. What is the main disadvantage of a linked-list stack?

Answer: Each node requires additional pointer memory and dynamic allocation can introduce overhead.

Q14. What is the difference between array and linked-list stack implementation?

Answer: An array stack uses indexed storage, while a linked-list stack uses dynamically allocated nodes connected by pointers.

Q15. Does peek modify the stack?

Answer: No. It only reads the data at the top node.

Q16. Why is insertion at the head preferred?

Answer: Because insertion at the head takes O(1) time without traversing the list.

Q17. What happens if free() is not called after pop?

Answer: The removed node's allocated memory becomes unavailable to the program, causing a memory leak.

Q18. Can a stack be implemented using a doubly linked list?

Answer: Yes, although a singly linked list is sufficient for standard stack operations.

Q19. Which implementation is preferable when stack size is unknown?

Answer: A linked-list stack or a dynamically resizable array, depending on memory and performance requirements.

Q20. Why are push and pop both O(1)?

Answer: Both operations modify only the first node and the top pointer; neither requires traversal.

18. Lesson Summary

  • A linked-list stack follows the LIFO principle.
  • The top pointer points to the first node.
  • Push inserts a node at the head.
  • Pop removes a node from the head.
  • Peek reads the top node without removing it.
  • malloc() allocates memory dynamically.
  • free() releases removed nodes.
  • Push and pop both take O(1) time.
  • Linked-list stacks grow dynamically subject to available memory.
