2. What Is Next Greater Element (NGE)?

For every element in an array, find the first element to its right that is strictly greater than it.

If no greater element exists, return -1.

Example

Input:
arr = {4, 5, 2, 10, 8}

Output:
NGE = {5, 10, 10, -1, -1}
ElementElements to its rightNext Greater Element
45, 2, 10, 85
52, 10, 810
210, 810
108-1
8None-1

3. Brute Force Approach

For every array element, scan all elements to its right until a greater element is found.

#include <stdio.h>

#define N 5

int main(void)
{
    int arr[N] = {4, 5, 2, 10, 8};

    for (int i = 0; i < N; i++)
    {
        int answer = -1;

        for (int j = i + 1; j < N; j++)
        {
            if (arr[j] > arr[i])
            {
                answer = arr[j];
                break;
            }
        }

        printf("%d -> %d\n", arr[i], answer);
    }

    return 0;
}

Output

4 -> 5
5 -> 10
2 -> 10
10 -> -1
8 -> -1

Time complexity: O(n²) in the worst case.

Auxiliary space: O(1).

4. Optimized Next Greater Element Using Stack

We can solve NGE in O(n) time using a stack of array indices.

Algorithm

  1. Traverse the array from right to left.
  2. While the stack is not empty and the top element is less than or equal to the current element, pop it.
  3. If the stack is empty, the answer is -1.
  4. Otherwise, the top element is the next greater element.
  5. Push the current element's index onto the stack.
We store indices rather than values so that we can access the corresponding array values and also distinguish elements with duplicate values.

C11 Program

#include <stdio.h>

#define N 5

void nextGreater(int arr[], int n, int result[])
{
    int stack[N];
    int top = -1;

    for (int i = n - 1; i >= 0; i--)
    {
        while (top != -1 && arr[stack[top]] <= arr[i])
        {
            top--;
        }

        if (top == -1)
            result[i] = -1;
        else
            result[i] = arr[stack[top]];

        stack[++top] = i;
    }
}

int main(void)
{
    int arr[N] = {4, 5, 2, 10, 8};
    int result[N];

    nextGreater(arr, N, result);

    printf("Next Greater Elements:\n");

    for (int i = 0; i < N; i++)
        printf("%d -> %d\n", arr[i], result[i]);

    return 0;
}

Expected Output

Next Greater Elements:
4 -> 5
5 -> 10
2 -> 10
10 -> -1
8 -> -1

Time complexity: O(n).

Auxiliary space: O(n).

6. Why Is the Optimized Algorithm O(n)?

Although a while loop is nested inside a for loop, the total work is linear.

  • Each index is pushed onto the stack exactly once.
  • Each index is popped at most once.
  • There are at most n pushes and n pops.

Total stack operations are bounded by 2n, so the time complexity is O(n).

This is an example of amortized analysis. It is a common interview question: a nested loop does not automatically imply O(n²).

7. Next Smaller Element (NSE)

For every element, find the first strictly smaller element to its right. If no smaller element exists, return -1.

Example

Input:
{4, 8, 5, 2, 25}

Output:
{2, 5, 2, -1, -1}

C11 Program

#include <stdio.h>

#define N 5

void nextSmaller(int arr[], int n, int result[])
{
    int stack[N];
    int top = -1;

    for (int i = n - 1; i >= 0; i--)
    {
        while (top != -1 && arr[stack[top]] >= arr[i])
            top--;

        result[i] = (top == -1) ? -1 : arr[stack[top]];

        stack[++top] = i;
    }
}

int main(void)
{
    int arr[N] = {4, 8, 5, 2, 25};
    int result[N];

    nextSmaller(arr, N, result);

    for (int i = 0; i < N; i++)
        printf("%d -> %d\n", arr[i], result[i]);

    return 0;
}

Expected Output

4 -> 2
8 -> 5
5 -> 2
2 -> -1
25 -> -1

Time complexity: O(n).

8. Previous Greater Element

For every element, find the nearest strictly greater element on its left. If none exists, return -1.

Example

Input:
{10, 4, 2, 20, 40, 12, 30}

Output:
{-1, 10, 4, -1, -1, 40, 40}

C11 Program

#include <stdio.h>

#define N 7

void previousGreater(int arr[], int n, int result[])
{
    int stack[N];
    int top = -1;

    for (int i = 0; i < n; i++)
    {
        while (top != -1 && arr[stack[top]] <= arr[i])
            top--;

        result[i] = (top == -1) ? -1 : arr[stack[top]];

        stack[++top] = i;
    }
}

int main(void)
{
    int arr[N] = {10, 4, 2, 20, 40, 12, 30};
    int result[N];

    previousGreater(arr, N, result);

    for (int i = 0; i < N; i++)
        printf("%d -> %d\n", arr[i], result[i]);

    return 0;
}

Expected Output

10 -> -1
4 -> 10
2 -> 4
20 -> -1
40 -> -1
12 -> 40
30 -> 40

Time complexity: O(n).

9. What Is a Monotonic Stack?

A monotonic stack is a stack that maintains its elements in a specific order.

TypeOrder from Bottom to TopTypical Use
Monotonic IncreasingIncreasing valuesNext smaller element patterns
Monotonic DecreasingDecreasing valuesNext greater element patterns

Elements that violate the required order are removed from the stack.

Monotonic Decreasing Example

Push 7:  10, 7
Push 5:  10, 7, 5

New value = 12

Pop 10

Push 12

Stack: 12

10. Stock Span Problem

The stock span for a day is the number of consecutive days ending on that day for which the stock price was less than or equal to the current day's price.

Example

Prices:
{100, 80, 60, 70, 60, 75, 85}

Span:
{1, 1, 1, 2, 1, 4, 6}

Explanation

  • Day 1: Price 100, span = 1.
  • Day 2: Price 80, previous price 100 is greater, span = 1.
  • Day 3: Price 60, previous price 80 is greater, span = 1.
  • Day 4: Price 70, previous price 60 is smaller, but 80 is greater, span = 2.
  • Day 5: Price 60, previous price 70 is greater, span = 1.
  • Day 6: Price 75, previous prices 60, 70 and 60 are all less than or equal to 75, while 80 is greater, span = 4.
  • Day 7: Price 85, previous prices 75, 60, 70, 60 and 80 are all less than or equal to 85, while 100 is greater, span = 6.

C11 Program

#include <stdio.h>

#define N 7

void calculateSpan(int price[], int n, int span[])
{
    int stack[N];
    int top = -1;

    for (int i = 0; i < n; i++)
    {
        while (top != -1 && price[stack[top]] <= price[i])
            top--;

        if (top == -1)
            span[i] = i + 1;
        else
            span[i] = i - stack[top];

        stack[++top] = i;
    }
}

int main(void)
{
    int price[N] = {100, 80, 60, 70, 60, 75, 85};
    int span[N];

    calculateSpan(price, N, span);

    printf("Stock spans:\n");

    for (int i = 0; i < N; i++)
        printf("%d ", span[i]);

    printf("\n");

    return 0;
}

Expected Output

Stock spans:
1 1 1 2 1 4 6

Time complexity: O(n).

Auxiliary space: O(n).

11. Largest Rectangle in a Histogram

Given histogram bar heights, find the largest rectangular area that can be formed using consecutive bars.

Example

Heights:
{2, 1, 5, 6, 2, 3}

Largest rectangle:
Height = 5
Width = 2

Area = 5 * 2 = 10

Core Idea

For each bar, determine how far it can extend to the left and right without encountering a shorter bar. A monotonic increasing stack of indices helps calculate these boundaries efficiently.

Formula

Width = Right boundary - Left boundary - 1 Area = Height × Width

C11 Program

#include <stdio.h>

#define N 6

int largestRectangle(int height[], int n)
{
    int stack[N + 1];
    int top = -1;
    int maxArea = 0;

    for (int i = 0; i <= n; i++)
    {
        int currentHeight = (i == n) ? 0 : height[i];

        while (top != -1 &&
               height[stack[top]] > currentHeight)
        {
            int h = height[stack[top--]];

            int leftBoundary = (top == -1) ? -1 : stack[top];
            int width = i - leftBoundary - 1;

            int area = h * width;

            if (area > maxArea)
                maxArea = area;
        }

        if (i < n)
            stack[++top] = i;
    }

    return maxArea;
}

int main(void)
{
    int height[N] = {2, 1, 5, 6, 2, 3};

    printf("Largest rectangle area: %d\n",
           largestRectangle(height, N));

    return 0;
}

Expected Output

Largest rectangle area: 10

Time complexity: O(n).

Auxiliary space: O(n).

This sample uses int for heights, area and indices. For production-quality code with large input values, validate dimensions and use a sufficiently wide integer type such as int64_t for area calculations, with overflow checks.

13. Common Programming Mistakes

  1. Using the wrong comparison operator when popping elements.
  2. Confusing next greater with previous greater.
  3. Forgetting to initialize the stack top to -1.
  4. Storing values when indices are required for distance calculations.
  5. Not handling duplicate elements correctly.
  6. Forgetting to assign -1 when no greater or smaller element exists.
  7. Assuming nested loops always mean O(n²).
  8. Using an incorrect width formula in histogram problems.
  9. Forgetting to process remaining histogram bars.
  10. Using int when larger area calculations require a wider type.

14. Placement Interview Questions and Answers

Q1. What is the Next Greater Element problem?

Answer: Find the first element greater than the current element on its right.

Q2. Which data structure is used to optimize NGE?

Answer: A stack, generally implemented using an array of indices.

Q3. What is the time complexity of optimized NGE?

Answer: O(n), because each index is pushed and popped at most once.

Q4. What is a monotonic stack?

Answer: A stack that maintains its elements in increasing or decreasing order.

Q5. What is the difference between NGE and NSE?

Answer: NGE searches for the next strictly greater element, whereas NSE searches for the next strictly smaller element.

Q6. Why do we store indices in NGE implementations?

Answer: Indices identify the positions of elements and support distance calculations.

Q7. What is the Stock Span problem?

Answer: It finds the number of consecutive previous days with prices less than or equal to the current day's price, including the current day.

Q8. What is the time complexity of Stock Span using a stack?

Answer: O(n).

Q9. What is the largest rectangle in a histogram problem?

Answer: It finds the maximum rectangular area formed by consecutive histogram bars.

Q10. Why is a monotonic increasing stack used in histogram problems?

Answer: It helps identify the first shorter bar that limits each bar's rectangle width.

Q11. What is amortized analysis?

Answer: It analyzes the average cost per operation over a sequence of operations, even when individual operations may have different costs.

Q12. Why can a nested-loop NGE solution be O(n)?

Answer: In the stack-based approach, each element is pushed once and popped at most once, giving total O(n) work.

Q13. What is the difference between next and previous greater element?

Answer: Next greater searches to the right, while previous greater searches to the left.

Q14. What happens when duplicate values occur in NGE?

Answer: For a strictly greater element, equal values must be removed from the candidate stack using a less-than-or-equal comparison.

Q15. What is the time complexity of histogram maximum rectangle?

Answer: O(n).

Q16. What is the width formula in the histogram problem?

Answer: Width = right boundary - left boundary - 1, where boundaries are the nearest strictly smaller bars.

Q17. Can a monotonic stack solve sliding-window maximum?

Answer: A monotonic deque is generally used for sliding-window maximum because elements must also be removed when they leave the window.

Q18. What does an empty stack mean in NGE?

Answer: No greater candidate exists to the right, so the answer is -1.

Q19. Why are indices important in Stock Span?

Answer: They allow the distance between the current day and the previous greater price to be calculated.

Q20. Name some common monotonic stack interview problems.

Answer: Next Greater Element, Next Smaller Element, Stock Span, Largest Rectangle in Histogram, Daily Temperatures and Trapping Rain Water variants.
