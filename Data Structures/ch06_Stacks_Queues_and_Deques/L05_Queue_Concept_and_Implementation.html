2. What Is a Queue?

A queue is a linear data structure that follows the FIFO (First In, First Out) principle.

The element inserted first is removed first.

Real-Life Example

Consider people waiting in a ticket-booking line. The person who arrives first is generally served first.

Queue Representation

FRONT                         REAR
  |                             |
  v                             v
+------+     +------+     +------+
|  10  | ---> |  20  | ---> |  30  |
+------+     +------+     +------+

Deletion happens at FRONT.
Insertion happens at REAR.

5. Enqueue Operation

Enqueue inserts a new element at the rear of the queue.

Algorithm

  1. Check whether the queue is full.
  2. If full, report overflow.
  3. If the queue is empty, initialize front to 0.
  4. Increment rear.
  5. Insert the new element at queue[rear].

C Function

#define MAX 5

int queue[MAX];
int front = -1;
int rear = -1;

int enqueue(int value)
{
    if (rear == MAX - 1)
    {
        printf("Queue Overflow\n");
        return 0;
    }

    if (front == -1)
        front = 0;

    queue[++rear] = value;

    return 1;
}

Time complexity: O(1).

6. Dequeue Operation

Dequeue removes the element at the front of the queue.

Algorithm

  1. Check whether the queue is empty.
  2. If empty, report underflow.
  3. Store the front element.
  4. If the removed element was the only element, reset front and rear to -1.
  5. Otherwise, increment front.

C Function

int dequeue(int *removed)
{
    if (front == -1)
    {
        printf("Queue Underflow\n");
        return 0;
    }

    *removed = queue[front];

    if (front == rear)
    {
        front = -1;
        rear = -1;
    }
    else
    {
        front++;
    }

    return 1;
}

Time complexity: O(1).

7. Front and isEmpty Operations

Front / Peek

int peek(int *value)
{
    if (front == -1)
        return 0;

    *value = queue[front];

    return 1;
}

isEmpty

int isEmpty(void)
{
    return front == -1;

8. Complete C11 Program: Linear Queue Using Array

#include <stdio.h>

#define MAX 5

int queue[MAX];
int front = -1;
int rear = -1;

int isEmpty(void)
{
    return front == -1;
}

int isFull(void)
{
    return rear == MAX - 1;
}

int enqueue(int value)
{
    if (isFull())
    {
        printf("Queue Overflow\n");
        return 0;
    }

    if (isEmpty())
        front = 0;

    queue[++rear] = value;

    printf("%d inserted into queue\n", value);

    return 1;
}

int dequeue(int *removed)
{
    if (isEmpty())
    {
        printf("Queue Underflow\n");
        return 0;
    }

    *removed = queue[front];

    if (front == rear)
    {
        front = -1;
        rear = -1;
    }
    else
    {
        front++;
    }

    return 1;
}

int peek(int *value)
{
    if (isEmpty())
        return 0;

    *value = queue[front];

    return 1;
}

void display(void)
{
    if (isEmpty())
    {
        printf("Queue is Empty\n");
        return;
    }

    printf("Queue elements: ");

    for (int i = front; i <= rear; i++)
        printf("%d ", queue[i]);

    printf("\n");
}

int main(void)
{
    int removed;
    int value;

    enqueue(10);
    enqueue(20);
    enqueue(30);
    enqueue(40);

    display();

    if (peek(&value))
        printf("Front element: %d\n", value);

    if (dequeue(&removed))
        printf("Removed element: %d\n", removed);

    display();

    enqueue(50);
    enqueue(60);

    display();

    enqueue(70);

    while (dequeue(&removed))
        printf("Removed: %d\n", removed);

    display();

    return 0;
}

20 inserted into queue
30 inserted into queue
40 inserted into queue
Queue elements: 10 20 30 40
Front element: 10
Removed element: 10
Queue elements: 20 30 40
50 inserted into queue
60 inserted into queue
Queue elements: 20 30 40 50 60
Queue Overflow

9. Limitation of a Linear Queue

A linear queue implemented with a simple array has a limitation: once rear reaches the final array index, no further insertion is possible, even if earlier positions have become empty due to dequeue operations.

Example

Initial queue:
[10] [20] [30] [40] [50]
 F                   R

After two dequeues:
[  ] [  ] [30] [40] [50]
             F         R

Now rear == MAX - 1.

A new enqueue is rejected,
even though positions 0 and 1 are unused.

This is called false overflow or space wastage in a linear queue. A circular queue solves this problem by reusing vacant positions.

10. Queue Using a Linked List

A linked-list queue uses dynamically allocated nodes. It maintains two pointers:

  • front: Points to the first node.
  • rear: Points to the last node.

Representation

FRONT                            REAR
  |                                |
  v                                v
+------+------+
|  10  |   *--|---> +------+------+
+------+------+     |  20  |   *--|---> +------+------+
                    +------+------+     |  30  | NULL |
                                         +------+------+

Node Structure

struct Node
{
    int data;
    struct Node *next;
};

struct Node *front = NULL;
struct Node *rear = NULL;

11. Enqueue in a Linked-List Queue

  1. Create a new node using malloc().
  2. Store the value and set its next pointer to NULL.
  3. If the queue is empty, set both front and rear to the new node.
  4. Otherwise, connect the current rear to the new node.
  5. Update rear to the new node.
int enqueue(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return 0;

    newNode->data = value;
    newNode->next = NULL;

    if (rear == NULL)
    {
        front = newNode;
        rear = newNode;
    }
    else
    {
        rear->next = newNode;
        rear = newNode;
    }

    return 1;
}

Time complexity: O(1).

12. Dequeue in a Linked-List Queue

  1. Check whether front is NULL.
  2. Save the front node in a temporary pointer.
  3. Store its data.
  4. Move front to the next node.
  5. If front becomes NULL, set rear to NULL too.
  6. Free the removed node.
int dequeue(int *removed)
{
    if (front == NULL)
        return 0;

    struct Node *temp = front;

    *removed = temp->data;

    front = front->next;

    if (front == NULL)
        rear = NULL;

    free(temp);

    return 1;
}

Time complexity: O(1).

13. Complete C11 Program: Queue Using Linked List

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Queue
{
    struct Node *front;
    struct Node *rear;
};

void initializeQueue(struct Queue *q)
{
    q->front = NULL;
    q->rear = NULL;
}

int isEmpty(const struct Queue *q)
{
    return q->front == NULL;
}

int enqueue(struct Queue *q, int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return 0;

    newNode->data = value;
    newNode->next = NULL;

    if (q->rear == NULL)
    {
        q->front = newNode;
        q->rear = newNode;
    }
    else
    {
        q->rear->next = newNode;
        q->rear = newNode;
    }

    return 1;
}

int dequeue(struct Queue *q, int *removed)
{
    if (isEmpty(q))
        return 0;

    struct Node *temp = q->front;

    *removed = temp->data;

    q->front = temp->next;

    if (q->front == NULL)
        q->rear = NULL;

    free(temp);

    return 1;
}

int peek(const struct Queue *q, int *value)
{
    if (isEmpty(q))
        return 0;

    *value = q->front->data;

    return 1;
}

void display(const struct Queue *q)
{
    if (isEmpty(q))
    {
        printf("Queue is Empty\n");
        return;
    }

    const struct Node *temp = q->front;

    printf("Queue elements: ");

    while (temp != NULL)
    {
        printf("%d ", temp->data);
        temp = temp->next;
    }

    printf("\n");
}

void clearQueue(struct Queue *q)
{
    while (q->front != NULL)
    {
        struct Node *temp = q->front;
        q->front = q->front->next;
        free(temp);
    }

    q->rear = NULL;
}

int main(void)
{
    struct Queue q;
    int removed;
    int value;

    initializeQueue(&q);

    if (!enqueue(&q, 10) ||
        !enqueue(&q, 20) ||
        !enqueue(&q, 30) ||
        !enqueue(&q, 40))
    {
        printf("Memory allocation failed\n");
        clearQueue(&q);
        return 1;
    }

    display(&q);

    if (peek(&q, &value))
        printf("Front element: %d\n", value);

    if (dequeue(&q, &removed))
        printf("Removed: %d\n", removed);

    display(&q);

    if (!enqueue(&q, 50))
    {
        printf("Memory allocation failed\n");
        clearQueue(&q);
        return 1;
    }

    display(&q);

    while (dequeue(&q, &removed))
        printf("Removed: %d\n", removed);

    display(&q);

    clearQueue(&q);

    return 0;
}

Expected Output

Queue elements: 10 20 30 40
Front element: 10
Removed: 10
Queue elements: 20 30 40
Queue elements: 20 30 40 50
Removed: 20
Removed: 30
Removed: 40
Removed: 50
Queue is Empty

17. Common Programming Mistakes

  1. Confusing front and rear.
  2. Inserting at front instead of rear.
  3. Removing elements from rear instead of front.
  4. Not resetting both indices when an array queue becomes empty.
  5. Not setting rear to NULL when the linked-list queue becomes empty.
  6. Not checking overflow in a fixed-capacity array queue.
  7. Not checking underflow before dequeue.
  8. Forgetting to free removed linked-list nodes.
  9. Not checking malloc() failure.
  10. Assuming a basic linear array queue automatically reuses vacant positions.

18. Placement Interview Questions and Answers

Q1. What is a queue?

Answer: A linear data structure that follows First In, First Out (FIFO).

Q2. What is FIFO?

Answer: First In, First Out. The element inserted first is removed first.

Q3. What is enqueue?

Answer: The operation of inserting an element at the rear.

Q4. What is dequeue?

Answer: The operation of removing an element from the front.

Q5. What is front?

Answer: The position or pointer referring to the first element.

Q6. What is rear?

Answer: The position or pointer referring to the last element.

Q7. What is queue overflow?

Answer: It occurs when insertion is attempted into a full fixed-capacity queue.

Q8. What is queue underflow?

Answer: It occurs when deletion is attempted from an empty queue.

Q9. What is the time complexity of enqueue?

Answer: O(1) for a standard array or linked-list queue implementation.

Q10. What is the time complexity of dequeue?

Answer: O(1) when the implementation advances the front index or pointer.

Q11. What is a linear queue?

Answer: A queue where insertion advances rear and deletion advances front in a linear array.

Q12. What is false overflow?

Answer: A condition in a linear array queue where rear reaches the final index even though unused positions exist before front.

Q13. How can false overflow be solved?

Answer: By using a circular queue or another implementation that reuses available positions.

Q14. What is the advantage of a linked-list queue?

Answer: It can grow dynamically without a fixed array capacity.

Q15. Why are both front and rear pointers required in a linked-list queue?

Answer: Front enables O(1) deletion, and rear enables O(1) insertion.

Q16. What happens when the final node is removed from a linked-list queue?

Answer: Both front and rear must become NULL.

Q17. Can a queue be used for BFS?

Answer: Yes. BFS uses a queue to process vertices level by level.

Q18. What is the difference between stack and queue?

Answer: Stack follows LIFO, whereas queue follows FIFO.

Q19. What is a priority queue?

Answer: A queue-like structure in which elements are removed according to priority rather than simple arrival order.

Q20. Name some applications of queues.

Answer: CPU scheduling, BFS, printer scheduling, network buffering and task processing.

21. Lesson Summary

  • A queue follows FIFO.
  • Enqueue inserts at rear.
  • Dequeue removes from front.
  • A queue can be implemented using arrays or linked lists.
  • Both enqueue and dequeue can take O(1) time.
  • A basic linear queue can waste array positions.
  • A circular queue addresses this space-reuse limitation.
  • Queues are widely used in BFS, scheduling and buffering.
