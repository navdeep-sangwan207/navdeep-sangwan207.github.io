Chapter 6: Stacks, Queues and Deques

Learn linear data structures, their implementations and important coding interview patterns using C.

Course: Data Structures and Algorithms Using C

Language: C11

Focus: Fresher Placements | Technical Interviews | Coding Rounds

Total Lessons: 8

1. Chapter Overview

Stacks, queues and deques are important linear data structures used in operating systems, expression processing, scheduling, memory management, algorithms and software development.

This chapter explains their concepts, implementations using arrays and linked lists, common operations, time complexity and frequently asked placement coding problems.

2. Learning Objectives

  • Understand the LIFO and FIFO principles.
  • Implement stacks using arrays and linked lists.
  • Perform push, pop and peek operations.
  • Detect stack overflow and underflow.
  • Check balanced parentheses using a stack.
  • Evaluate and convert arithmetic expressions.
  • Understand monotonic stack algorithms.
  • Implement queues using arrays and linked lists.
  • Understand circular queues and deques.
  • Implement priority queues.
  • Solve common stack and queue interview problems.
