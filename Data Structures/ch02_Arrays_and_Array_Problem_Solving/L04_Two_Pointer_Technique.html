Chapter 2: Arrays and Array Problem Solving

Lesson 4: Two Pointer Technique

Solve array problems efficiently using two indices that move through an array according to a defined condition.

1. Learning Objectives

  • Understand the two pointer technique.
  • Learn opposite-direction and same-direction pointers.
  • Solve pair-sum problems in sorted arrays.
  • Reverse an array using two pointers.
  • Remove duplicates from sorted arrays.
  • Move zeroes to the end of an array.
  • Analyze time and space complexity.
  • Apply two pointer patterns in placement coding rounds.

2. What Is the Two Pointer Technique?

The two pointer technique is an algorithmic approach in which two indices are used to traverse an array or sequence. Each pointer represents a position in the data structure.

Instead of repeatedly using nested loops, we move the pointers according to the problem's conditions. This can reduce the time complexity of many problems.

Example: 
Array = {10, 20, 30, 40, 50}

left  = 0
right = 4

left points to 10
right points to 50

Why use two pointers?

  • Reduce unnecessary comparisons.
  • Improve efficiency compared with some nested-loop solutions.
  • Perform in-place array operations.
  • Solve pair and subarray-related problems.

3. Types of Two Pointer Techniques

Type 1: Opposite-Direction Pointers

One pointer starts at the beginning and another starts at the end. They move toward each other. 

left = 0
right = size - 1

Common applications:

  • Reversing an array.
  • Finding a pair with a target sum in a sorted array.
  • Checking whether an array is a palindrome.

Type 2: Same-Direction Pointers

Both pointers move from left to right, but they may move at different speeds or serve different purposes. 

slow = 0
fast = 0

Common applications:

  • Removing duplicates from a sorted array.
  • Moving zeroes to the end.
  • Partitioning an array.

Type 3: Fast and Slow Pointers

One pointer moves faster than the other. This pattern is particularly useful in linked lists, although it can also be applied to arrays.

4. Reverse an Array Using Two Pointers

We use one pointer at the first index and another at the last index. Swap the elements and move both pointers inward.

Algorithm

  1. Initialize left to 0.
  2. Initialize right to size - 1.
  3. Swap arr[left] and arr[right].
  4. Increment left and decrement right.
  5. Continue while left is smaller than right.
#include <stdio.h>

void reverseArray(int arr[], int size)
{
    int left = 0;
    int right = size - 1;

    while (left < right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = sizeof(arr) / sizeof(arr[0]);

    reverseArray(arr, size);

    printf("Reversed array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Reversed array: 50 40 30 20 10

Dry Run

IterationLeftRightOperation
104Swap 10 and 50
213Swap 20 and 40
322Stop

Time Complexity: O(n)

Auxiliary Space: O(1)

5. Find a Pair With a Given Sum in a Sorted Array

Given a sorted array and a target sum, find two elements whose sum equals the target.

Example:

Array = {1, 2, 4, 6, 8, 9}
Target = 10

Answer: 2 + 8 = 10

Algorithm

  1. Initialize left = 0 and right = size - 1.
  2. Calculate arr[left] + arr[right].
  3. If the sum equals the target, return the pair.
  4. If the sum is smaller, increment left.
  5. If the sum is larger, decrement right.
  6. Repeat until left is no longer smaller than right.
#include <stdio.h>

int findPairSum(const int arr[], int size, int target)
{
    int left = 0;
    int right = size - 1;

    while (left < right)
    {
        int sum = arr[left] + arr[right];

        if (sum == target)
        {
            printf("Pair found: %d + %d = %d\n",
                   arr[left], arr[right], target);
            return 1;
        }
        else if (sum < target)
        {
            left++;
        }
        else
        {
            right--;
        }
    }

    return 0;
}

int main(void)
{
    int arr[] = {1, 2, 4, 6, 8, 9};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 10;

    if (!findPairSum(arr, size, target))
    {
        printf("No pair found\n");
    }

    return 0;
}
Expected Output: 
Pair found: 1 + 9 = 10

Dry Run

Left ValueRight ValueSumAction
1910Pair found
Important: This pointer movement is valid because the array is sorted in ascending order. Do not apply this exact approach to an arbitrary unsorted array without first establishing a suitable strategy.

Time Complexity: O(n)

Auxiliary Space: O(1)

6. Check Whether an Array Is a Palindrome

An array is a palindrome if it reads the same from left to right and from right to left. 

#include <stdio.h>

int isPalindrome(const int arr[], int size)
{
    int left = 0;
    int right = size - 1;

    while (left < right)
    {
        if (arr[left] != arr[right])
        {
            return 0;
        }

        left++;
        right--;
    }

    return 1;
}

int main(void)
{
    int arr[] = {1, 2, 3, 2, 1};
    int size = sizeof(arr) / sizeof(arr[0]);

    if (isPalindrome(arr, size))
    {
        printf("Array is a palindrome\n");
    }
    else
    {
        printf("Array is not a palindrome\n");
    }

    return 0;
}
Expected Output: 
Array is a palindrome

Time Complexity: O(n)

Auxiliary Space: O(1)

7. Remove Duplicates From a Sorted Array

Given a sorted array, remove duplicate values in-place and return the number of unique elements.

Example:

Input:  {1, 1, 2, 2, 3, 4, 4}
Output: {1, 2, 3, 4}
New size: 4

Approach

  • Use a slow pointer to track the position of the last unique element.
  • Use a fast pointer to examine the remaining elements.
  • When a new value is found, place it after the previous unique value.
#include <stdio.h>

int removeDuplicates(int arr[], int size)
{
    if (size == 0)
    {
        return 0;
    }

    int slow = 0;

    for (int fast = 1; fast < size; fast++)
    {
        if (arr[fast] != arr[slow])
        {
            slow++;
            arr[slow] = arr[fast];
        }
    }

    return slow + 1;
}

int main(void)
{
    int arr[] = {1, 1, 2, 2, 3, 4, 4};
    int size = sizeof(arr) / sizeof(arr[0]);

    int newSize = removeDuplicates(arr, size);

    printf("Unique elements: ");

    for (int i = 0; i < newSize; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\nNew size: %d\n", newSize);

    return 0;
}
Expected Output: 
Unique elements: 1 2 3 4
New size: 4
The original array capacity is unchanged. Only the first newSize positions contain the resulting unique elements. The remaining positions should not be treated as part of the logical array.

Time Complexity: O(n)

Auxiliary Space: O(1)

8. Move All Zeroes to the End

Given an array, move all zeroes to the end while maintaining the relative order of non-zero elements.

Example:

Input:  {0, 1, 0, 3, 12}
Output: {1, 3, 12, 0, 0}

Approach

Use a write pointer to indicate where the next non-zero value should be placed. Scan the array with another pointer. 

#include <stdio.h>

void moveZeroes(int arr[], int size)
{
    int write = 0;

    for (int read = 0; read < size; read++)
    {
        if (arr[read] != 0)
        {
            arr[write] = arr[read];
            write++;
        }
    }

    while (write < size)
    {
        arr[write] = 0;
        write++;
    }
}

int main(void)
{
    int arr[] = {0, 1, 0, 3, 12};
    int size = sizeof(arr) / sizeof(arr[0]);

    moveZeroes(arr, size);

    printf("Result: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Result: 1 3 12 0 0

Time Complexity: O(n)

Auxiliary Space: O(1)

9. Find Two Numbers With a Target Sum in an Unsorted Array

The opposite-direction two pointer approach requires sorted data for the pair-sum problem. For an unsorted array, one straightforward approach is to sort the array first or use a hash table.

A simple brute-force solution uses two nested loops. It is useful as a baseline interview solution. 

#include <stdio.h>

int findPairBruteForce(const int arr[], int size, int target)
{
    for (int i = 0; i < size; i++)
    {
        for (int j = i + 1; j < size; j++)
        {
            if (arr[i] + arr[j] == target)
            {
                printf("Pair found: %d and %d\n",
                       arr[i], arr[j]);
                return 1;
            }
        }
    }

    return 0;
}

int main(void)
{
    int arr[] = {8, 3, 5, 2, 7};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 10;

    if (!findPairBruteForce(arr, size, target))
    {
        printf("No pair found\n");
    }

    return 0;
}
Expected Output: 
Pair found: 8 and 2

Time Complexity: O(n²)

Auxiliary Space: O(1)

In a placement interview, explain why the sorted-array two pointer method is O(n), while this brute-force approach is O(n²). Sorting first can enable a two pointer solution, but the sorting cost must be included in the total complexity.

11. Common Mistakes

  • Using right = size instead of right = size - 1.
  • Using left <= right when the algorithm requires left < right.
  • Forgetting to move one or both pointers.
  • Using the sorted-array pair-sum method on unsorted data.
  • Overwriting array elements before reading their original values.
  • Returning the original array size after removing duplicates.
  • Ignoring empty and single-element arrays.
  • Assuming every two-pointer problem uses opposite-direction pointers.

12. Placement Interview Questions and Answers

Q1. What is the two pointer technique?

An algorithmic pattern that uses two indices to process a sequence efficiently.

Q2. What are the two main pointer movement patterns?

Opposite-direction pointers and same-direction pointers.

Q3. Where do opposite-direction pointers start?

One starts at index 0 and the other at index n - 1.

Q4. What is the time complexity of reversing an array using two pointers?

O(n).

Q5. What is the auxiliary space complexity of in-place reversal?

O(1).

Q6. Why must an array be sorted for the standard pair-sum two pointer method?

Sorted order makes it possible to determine which pointer to move based on whether the current sum is too small or too large.

Q7. What happens if the pair sum is smaller than the target?

Move the left pointer rightward to consider a larger value in an ascending sorted array.

Q8. What happens if the pair sum is larger than the target?

Move the right pointer leftward to consider a smaller value.

Q9. What is the complexity of pair sum using two pointers on sorted data?

O(n) time and O(1) auxiliary space.

Q10. What is the slow pointer used for in duplicate removal?

It tracks the position where the next unique element should be written.

Q11. Why does duplicate removal require a sorted array in this implementation?

Equal values are adjacent in a sorted array, so each value can be compared with the last retained unique value.

Q12. What is the complexity of removing duplicates from a sorted array?

O(n) time and O(1) auxiliary space.

Q13. What is a fast and slow pointer pattern?

Two pointers move through data at different speeds or with different responsibilities.

Q14. How can you move zeroes to the end of an array?

Copy non-zero elements forward using a write pointer, then fill the remaining positions with zeroes.

Q15. Does moving zeroes require an additional array?

No. It can be performed in-place using O(1) auxiliary space.

Q16. Can two pointers reduce O(n²) to O(n)?

Yes, for suitable problems where pointer movement eliminates unnecessary comparisons.

Q17. Is two pointer a data structure?

No. It is an algorithmic technique or problem-solving pattern.

Q18. Can two pointers be used with strings?

Yes. They are commonly used for palindrome checks, reversing strings and other string problems.

Q19. How do you avoid accessing outside array boundaries?

Use valid pointer initialization and carefully chosen loop conditions.

Q20. Which problems are common applications of two pointers?

Pair sum, array reversal, palindrome checking, duplicate removal and moving zeroes.

16. Lesson Summary

The two pointer technique uses two indices to solve array problems efficiently. Opposite-direction pointers are useful for reversal and pair-sum problems, while same-direction pointers are useful for duplicate removal and array rearrangement.

Many suitable problems can be solved in O(n) time and O(1) auxiliary space, making this technique important for placement coding rounds.
