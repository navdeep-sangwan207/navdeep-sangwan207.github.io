2. What Is Array Searching?

Array searching is the process of finding whether a particular element exists in an array and determining its position.

Important terminology:

  • Array: Collection of elements stored in contiguous memory.
  • Target or key: Value that we want to find.
  • Index: Position of an element, starting from zero.
  • Search result: Index of the element or -1 if absent.
Example: 
Array = {10, 20, 30, 40, 50}
Target = 30

Index = 2

3. Linear Search

Linear search checks each array element sequentially until the target is found or the array ends.

Algorithm

  1. Start from index 0.
  2. Compare the current element with the target.
  3. If equal, return the current index.
  4. Otherwise, move to the next element.
  5. If the end is reached, return -1.

C Program: Linear Search

#include <stdio.h>

int linearSearch(const int arr[], int size, int target)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            return i;
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 30;

    int result = linearSearch(arr, size, target);

    if (result != -1)
    {
        printf("Element found at index %d\n", result);
    }
    else
    {
        printf("Element not found\n");
    }

    return 0;
}
Expected Output: 
Element found at index 2

4. Finding the First Occurrence

When an array contains duplicate values, the first occurrence is the smallest index at which the target appears. 

#include <stdio.h>

int firstOccurrence(const int arr[], int size, int target)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            return i;
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 20, 40, 20};
    int size = sizeof(arr) / sizeof(arr[0]);

    int index = firstOccurrence(arr, size, 20);

    printf("First occurrence: %d\n", index);

    return 0;
}
Expected Output: 
First occurrence: 1

The function returns immediately after finding the first matching element.

5. Finding the Last Occurrence

The last occurrence is the greatest index at which the target appears. We continue searching even after finding a match. 

#include <stdio.h>

int lastOccurrence(const int arr[], int size, int target)
{
    int result = -1;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            result = i;
        }
    }

    return result;
}

int main(void)
{
    int arr[] = {10, 20, 30, 20, 40, 20};
    int size = sizeof(arr) / sizeof(arr[0]);

    int index = lastOccurrence(arr, size, 20);

    printf("Last occurrence: %d\n", index);

    return 0;
}
Expected Output: 
Last occurrence: 5
Interview distinction: First occurrence returns immediately on a match. Last occurrence stores the latest matching index and completes the search.

6. Counting Occurrences of an Element

Counting occurrences means calculating how many times a particular value appears in an array. 

#include <stdio.h>

int countOccurrences(const int arr[], int size, int target)
{
    int count = 0;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            count++;
        }
    }

    return count;
}

int main(void)
{
    int arr[] = {5, 10, 5, 20, 5, 30, 10};
    int size = sizeof(arr) / sizeof(arr[0]);

    int target = 5;

    printf("Occurrences of %d: %d\n",
           target,
           countOccurrences(arr, size, target));

    return 0;
}
Expected Output: 
Occurrences of 5: 3

7. Displaying All Occurrences

Sometimes we need every index where a target appears, rather than just the first or last occurrence. 

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 10, 30, 10, 40};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 10;
    int found = 0;

    printf("Target found at indices: ");

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            printf("%d ", i);
            found = 1;
        }
    }

    if (!found)
    {
        printf("No occurrence found");
    }

    printf("\n");

    return 0;
}
Expected Output: 
Target found at indices: 0 2 4

8. Updating an Array Element by Index

Updating means replacing an existing array element with a new value.

If the index is valid, updating an element takes constant time because direct indexing provides access to the element. 

#include <stdio.h>

int updateAtIndex(int arr[], int size, int index, int newValue)
{
    if (index < 0 || index >= size)
    {
        return 0;
    }

    arr[index] = newValue;
    return 1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = sizeof(arr) / sizeof(arr[0]);

    if (updateAtIndex(arr, size, 2, 99))
    {
        printf("Array updated successfully\n");
    }
    else
    {
        printf("Invalid index\n");
    }

    printf("Updated array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Array updated successfully
Updated array: 10 20 99 40 50

9. Searching and Updating by Value

In this operation, we search for a particular value and replace its first occurrence with a new value. 

#include <stdio.h>

int searchAndUpdate(int arr[], int size,
                    int target, int newValue)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            arr[i] = newValue;
            return i;
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 20, 40};
    int size = sizeof(arr) / sizeof(arr[0]);

    int index = searchAndUpdate(arr, size, 20, 99);

    if (index != -1)
    {
        printf("Updated first occurrence at index %d\n", index);
    }
    else
    {
        printf("Target not found\n");
    }

    printf("Array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Updated first occurrence at index 1
Array: 10 99 30 20 40

10. Updating All Occurrences

If the target appears multiple times, we can replace every occurrence using a single traversal. 

#include <stdio.h>

int updateAllOccurrences(int arr[], int size,
                         int target, int newValue)
{
    int count = 0;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            arr[i] = newValue;
            count++;
        }
    }

    return count;
}

int main(void)
{
    int arr[] = {10, 20, 10, 30, 10};
    int size = sizeof(arr) / sizeof(arr[0]);

    int count = updateAllOccurrences(arr, size, 10, 99);

    printf("Number of elements updated: %d\n", count);
    printf("Updated array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Number of elements updated: 3
Updated array: 99 20 99 30 99

13. Common Mistakes in Array Searching

  • Using an invalid index outside the range 0 to size - 1.
  • Forgetting to return -1 when the target is absent.
  • Stopping too early when searching for the last occurrence.
  • Forgetting to increment the occurrence counter.
  • Updating the wrong index after finding a target.
  • Using binary search on an unsorted array.
  • Assuming an empty array contains at least one element.

14. Placement Interview Questions and Answers

Q1. What is array searching?

It is the process of finding a target element in an array and determining its position.

Q2. What is linear search?

Linear search sequentially compares each element with the target until a match is found or the array ends.

Q3. What is the worst-case time complexity of linear search?

O(n), because all elements may need to be examined.

Q4. What is the best-case time complexity of linear search?

O(1), when the target is at the first index.

Q5. What does -1 indicate in a search function?

It conventionally indicates that the target element was not found.

Q6. Can linear search work on an unsorted array?

Yes. Linear search does not require sorted data.

Q7. What is the difference between first and last occurrence?

First occurrence is the smallest matching index; last occurrence is the largest matching index.

Q8. How do you count duplicate values?

Traverse the array and increment a counter whenever an element equals the target.

Q9. What is the complexity of counting occurrences?

O(n) time and O(1) auxiliary space.

Q10. What is array updating?

Replacing an existing element with a new value.

Q11. What is the complexity of updating by index?

O(1), provided the index is valid.

Q12. What is the difference between searching and updating?

Searching locates an element, whereas updating modifies an element's value.

Q13. Can an array contain duplicate elements?

Yes. Arrays can contain multiple elements with the same value.

Q14. Why is binary search unsuitable for an unsorted array?

Binary search depends on sorted order to eliminate half of the remaining search range at each step.

Q15. What happens when the target is absent?

A search function should return -1, or another clearly documented not-found result.

Q16. What is the auxiliary space complexity of iterative linear search?

O(1), because it uses a fixed number of additional variables.

Q17. How can you find all positions of a duplicate value?

Traverse the complete array and print or store every index that matches the target.

Q18. What should be checked before updating an array element?

Validate that the index is non-negative and smaller than the current array size.

Q19. Is updating every occurrence different from updating the first occurrence?

Yes. Updating the first occurrence stops after one match; updating all occurrences must inspect the entire array.

Q20. Which searching algorithm should be considered for a large sorted array?

Binary search is generally suitable because it has O(log n) time complexity.

16. Multiple Choice Questions

Q1. What is the worst-case complexity of linear search?

A. O(1)   B. O(log n)   C. O(n)   D. O(n²)

Answer: C. O(n)

Q2. Which index is checked first in a normal linear search?

A. 1   B. 0   C. n   D. n - 1

Answer: B. 0

Q3. What is conventionally returned when a target is absent?

A. 0   B. 1   C. -1   D. n

Answer: C. -1

Q4. What is the complexity of updating a valid array index?

A. O(1)   B. O(n)   C. O(log n)   D. O(n²)

Answer: A. O(1)

Q5. Which searching method requires sorted data?

A. Linear search   B. Binary search   C. Both   D. Neither

Answer: B. Binary search

Q6. How many times does 20 occur in {10, 20, 30, 20, 20}?

A. 1   B. 2   C. 3   D. 4

Answer: C. 3

Q7. What is the auxiliary space complexity of iterative linear search?

A. O(n)   B. O(log n)   C. O(1)   D. O(n²)

Answer: C. O(1)

Q8. Which operation must inspect the entire array to count all matches?

A. First occurrence   B. Count occurrences   C. Update by index   D. Direct access

Answer: B. Count occurrences

Q9. What is the valid index range for an array of size n?

A. 1 to n   B. 0 to n   C. 0 to n - 1   D. 1 to n - 1

Answer: C. 0 to n - 1

Q10. Which approach finds the last occurrence?

A. Return at the first match

B. Store each matching index and continue searching

C. Stop at index zero

D. Sort the array first

Answer: B. Store each matching index and continue searching

18. Lesson Summary

Array searching helps locate elements, while updating modifies existing values. Linear search works on both sorted and unsorted arrays and has O(n) worst-case time complexity. Updating an element by a valid index takes O(1) time.

These operations are fundamental to array-based coding problems and frequently appear in fresher placement interviews.
