Lesson 3: Array Searching and Updating

Master linear search, binary search, duplicate handling and efficient array updates for placement coding rounds.

1. Introduction to Array Searching

Searching is the process of finding whether a particular element exists in an array and, if it does, identifying its position.

Example:

Array:  {10, 20, 30, 40, 50}
Target: 30

Result: Found at index 2

Common searching techniques include:

  • Linear Search
  • Binary Search
  • Searching for the first or last occurrence
  • Counting occurrences
  • Searching in rotated sorted arrays

2. Linear Search

Linear search checks array elements sequentially until the target is found or all elements have been examined.

Algorithm

  1. Start from index 0.
  2. Compare the current element with the target.
  3. If equal, return the current index.
  4. Otherwise, move to the next element.
  5. If the end is reached, return -1.

Dry Run

Array:  {10, 20, 30, 40, 50}
Target: 40

Step 1: 10 == 40? No
Step 2: 20 == 40? No
Step 3: 30 == 40? No
Step 4: 40 == 40? Yes

Result: Index 3

C++ Program

#include <iostream>
using namespace std;

int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;
        }
    }

    return -1;
}

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;
    int target = 40;

    int result = linearSearch(arr, n, target);

    if (result != -1)
        cout << "Found at index " << result;
    else
        cout << "Element not found";

    return 0;
}

Output:

Found at index 3

Best Case: Θ(1)

Average Case: Θ(N), under common search assumptions.

Worst Case: Θ(N)

Auxiliary Space: O(1)

3. Linear Search in an Unsorted Array

Linear search works even when the array is not sorted. No special arrangement of elements is required. 

Array:  {45, 12, 89, 23, 67}
Target: 23

Comparisons:
45 → Not found
12 → Not found
89 → Not found
23 → Found

Index = 3

This is one important advantage of linear search. It can be used with both sorted and unsorted arrays.

4. Finding All Occurrences of an Element

An array may contain duplicate values. If the requirement is to find every occurrence, continue searching even after the first match.

C++ Program

#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 10, 30, 10, 40};
    int n = 6;
    int target = 10;
    int count = 0;

    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            cout << "Found at index " << i << endl;
            count++;
        }
    }

    cout << "Total occurrences: " << count;

    return 0;
}

Output:

Found at index 0
Found at index 2
Found at index 4
Total occurrences: 3

Time Complexity: O(N)

5. Finding the First and Last Occurrence

When duplicates exist, interview questions often ask for the first or last index of a target.

First Occurrence Using Linear Search

int firstOccurrence(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target)
            return i;
    }

    return -1;
}

Last Occurrence Using Linear Search

int lastOccurrence(int arr[], int n, int target) {
    for (int i = n - 1; i >= 0; i--) {
        if (arr[i] == target)
            return i;
    }

    return -1;
}

Example:

Array:  {10, 20, 20, 20, 30}
Target: 20

First occurrence = 1
Last occurrence  = 3

6. Binary Search

Binary search is an efficient searching algorithm that repeatedly divides the search interval into two halves.

Binary search requires data to be sorted according to the ordering used by the search algorithm. Applying ordinary binary search to an unsorted array is incorrect.

Algorithm

  1. Initialize low = 0 and high = N - 1.
  2. Calculate the middle index.
  3. If the middle element equals the target, return its index.
  4. If the target is greater, search the right half.
  5. Otherwise, search the left half.
  6. Continue until the target is found or the interval is empty.

Dry Run

Array:  {10, 20, 30, 40, 50, 60, 70}
Target: 60

Step 1:
low = 0, high = 6
mid = 3
arr[3] = 40

60 > 40
Search right half.

Step 2:
low = 4, high = 6
mid = 5
arr[5] = 60

Target found at index 5.

C++ Program: Iterative Binary Search

#include <iostream>
using namespace std;

int binarySearch(int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return -1;
}

int main() {
    int arr[] = {10, 20, 30, 40, 50, 60, 70};
    int n = 7;
    int target = 60;

    int result = binarySearch(arr, n, target);

    if (result != -1)
        cout << "Found at index " << result;
    else
        cout << "Element not found";

    return 0;
}

Output:

Found at index 5

Best Case: Θ(1)

Average Case: Θ(log N)

Worst Case: Θ(log N)

Auxiliary Space: O(1) for iterative implementation.

7. Recursive Binary Search

Binary search can also be implemented using recursion. Each recursive call searches either the left or right half. 

#include <iostream>
using namespace std;

int binarySearch(int arr[], int low, int high, int target) {
    if (low > high)
        return -1;

    int mid = low + (high - low) / 2;

    if (arr[mid] == target)
        return mid;

    if (target < arr[mid])
        return binarySearch(arr, low, mid - 1, target);

    return binarySearch(arr, mid + 1, high, target);
}

int main() {
    int arr[] = {10, 20, 30, 40, 50, 60};
    int n = 6;

    int result = binarySearch(arr, 0, n - 1, 50);

    cout << result;

    return 0;
}

Output:

4

Time Complexity: O(log N)
Auxiliary Space: O(log N) due to recursive call stack.

8. First Occurrence Using Binary Search

In a sorted array containing duplicates, ordinary binary search may return any matching index. To find the first occurrence, continue searching the left half after a match. 

int firstOccurrence(int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;
    int answer = -1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target) {
            answer = mid;
            high = mid - 1;
        }
        else if (arr[mid] < target) {
            low = mid + 1;
        }
        else {
            high = mid - 1;
        }
    }

    return answer;
}

Example:

Array: {10, 20, 20, 20, 30, 40}
Target: 20

First occurrence = 1

Time Complexity: O(log N)

9. Last Occurrence Using Binary Search

To find the last occurrence, continue searching the right half after finding a match. 

int lastOccurrence(int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;
    int answer = -1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target) {
            answer = mid;
            low = mid + 1;
        }
        else if (arr[mid] < target) {
            low = mid + 1;
        }
        else {
            high = mid - 1;
        }
    }

    return answer;
}

Time Complexity: O(log N)

10. Counting Occurrences in a Sorted Array

Once the first and last positions of a target are known, its total frequency can be calculated. 

count = lastIndex - firstIndex + 1

Example:

Array: {10, 20, 20, 20, 30, 40}

First index = 1
Last index  = 3

Count = 3 - 1 + 1
      = 3

Finding both positions with binary search takes O(log N) time.

11. Updating Array Elements

Updating means changing the value stored at a particular index. It requires direct access to the element. 

#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    int index = 2;
    int newValue = 100;

    if (index >= 0 && index < n) {
        arr[index] = newValue;
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 100 40 50

Time Complexity: O(1)

Auxiliary Space: O(1)

12. Search and Update an Element

Sometimes an interview problem asks us to search for a particular value and update it when found. 

#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    int target = 30;
    int newValue = 300;

    int index = -1;

    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            index = i;
            break;
        }
    }

    if (index != -1) {
        arr[index] = newValue;
        cout << "Element updated";
    }
    else {
        cout << "Element not found";
    }

    cout << endl;

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

Element updated
10 20 300 40 50

Time Complexity: O(N) for searching and O(1) for updating.

13. Binary Search Using C++ STL

C++ provides standard library algorithms for searching sorted ranges.

binary_search()

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    bool found = binary_search(arr, arr + n, 30);

    cout << (found ? "Found" : "Not found");

    return 0;
}

Output:

Found

lower_bound()

Returns an iterator to the first element that is not less than the target. 

auto it = lower_bound(arr, arr + n, 30);

if (it != arr + n) {
    cout << "Index: " << (it - arr);
}

upper_bound()

Returns an iterator to the first element strictly greater than the target. 

auto it = upper_bound(arr, arr + n, 30);

if (it != arr + n) {
    cout << "Index: " << (it - arr);
}
For arrays and vectors, these algorithms perform logarithmic comparisons and use random-access iterators. The range must be sorted according to the same ordering used by the search.

14. Searching in a Rotated Sorted Array

A sorted array may be rotated at an unknown pivot. A common interview problem asks us to search for a target without first sorting the array. 

Original:
{10, 20, 30, 40, 50, 60, 70}

Rotated:
{40, 50, 60, 70, 10, 20, 30}

A modified binary search can identify which half is sorted and determine which half may contain the target. 

int searchRotated(int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (arr[low] <= arr[mid]) {
            if (arr[low] <= target &&
                target < arr[mid]) {
                high = mid - 1;
            }
            else {
                low = mid + 1;
            }
        }
        else {
            if (arr[mid] < target &&
                target <= arr[high]) {
                low = mid + 1;
            }
            else {
                high = mid - 1;
            }
        }
    }

    return -1;
}

For a rotated sorted array with distinct elements, time complexity is O(log N).

Duplicate values can make it impossible to identify the sorted half unambiguously. Some duplicate-containing variants may require O(N) worst-case time.

15. Linear Search vs Binary Search

Feature Linear Search Binary Search
Data requirement Sorted or unsorted Sorted range
Best case O(1) O(1)
Worst case O(N) O(log N)
Approach Sequential checking Divide and conquer
Implementation Simple Requires careful boundaries
Suitable for Small or unsorted data Sorted data and large search ranges

16. Common Interview Mistakes

  • Applying binary search to an unsorted array.
  • Using incorrect low and high boundaries.
  • Forgetting to update low or high after comparison.
  • Using an unsafe middle-index calculation such as (low + high) / 2 for very large indexes.
  • Returning immediately when the first occurrence is required.
  • Failing to handle an empty array.
  • Forgetting to validate an index before updating an element.
  • Confusing an element's value with its index.

19. Multiple-Choice Questions

Q1. Which searching algorithm works on an unsorted array?

A) Binary Search   B) Linear Search   C) Both always   D) None

Answer: B) Linear Search

Q2. What is the worst-case complexity of binary search?

A) O(N)   B) O(N²)   C) O(log N)   D) O(1)

Answer: C) O(log N)

Q3. Which condition is required for ordinary binary search?

A) Array must be sorted   B) Array must contain duplicates   C) Array must be reversed   D) Array must be empty

Answer: A) Array must be sorted

Q4. What does lower_bound return?

A) Last equal element   B) First element not less than target   C) First element greater than target   D) Always index zero

Answer: B) First element not less than target

Q5. What is the time complexity of updating arr[i]?

A) O(N)   B) O(log N)   C) O(1)   D) O(N²)

Answer: C) O(1)

Q6. What is the worst-case complexity of searching a rotated sorted array with distinct elements using modified binary search?

A) O(N²)   B) O(log N)   C) O(N log N)   D) O(1)

Answer: B) O(log N)

20. Lesson Summary

  • Linear search checks elements sequentially.
  • Binary search repeatedly divides a sorted search range.
  • Linear search works on sorted and unsorted arrays.
  • Binary search has O(log N) worst-case time complexity.
  • First and last occurrences can be found using modified binary search.
  • lower_bound and upper_bound are useful C++ STL algorithms.
  • Searching a rotated sorted array is a common placement problem.
  • Updating an element by index takes O(1) time.
