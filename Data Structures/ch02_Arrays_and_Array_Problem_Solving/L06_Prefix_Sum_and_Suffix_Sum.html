2. What Is Prefix Sum?

Prefix sum is a technique in which each position stores the cumulative sum of all elements from the beginning of the array up to that position.

Mathematical definition:

prefix[i] = arr[0] + arr[1] + ... + arr[i]

Example: 
Original array:
arr = {2, 4, 1, 5, 3}

Prefix sum:
prefix = {2, 6, 7, 12, 15}
IndexArray ElementPrefix CalculationPrefix Sum
0222
142 + 46
212 + 4 + 17
352 + 4 + 1 + 512
432 + 4 + 1 + 5 + 315

3. Constructing a Prefix Sum Array

Formula:

prefix[0] = arr[0]

prefix[i] = prefix[i - 1] + arr[i]
#include <stdio.h>

int main(void)
{
    int arr[] = {2, 4, 1, 5, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long prefix[size];

    prefix[0] = arr[0];

    for (int i = 1; i < size; i++)
    {
        prefix[i] = prefix[i - 1] + arr[i];
    }

    printf("Prefix sum array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%lld ", prefix[i]);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Prefix sum array: 2 6 7 12 15

Time Complexity: O(n)

Auxiliary Space: O(n)

4. Range Sum Query Using Prefix Sum

A range-sum query asks for the sum of elements between two indices, usually represented by L and R.

Using prefix sums:

sum(L, R) = prefix[R] - prefix[L - 1]

For the special case L = 0:

sum(0, R) = prefix[R]
Example: 
Array = {2, 4, 1, 5, 3}
Prefix = {2, 6, 7, 12, 15}

Find sum from index 1 to 3.

sum(1, 3) = prefix[3] - prefix[0]
          = 12 - 2
          = 10

C Program: Range Sum Query

#include <stdio.h>

int rangeSum(const long long prefix[],
             int size, int left, int right,
             long long *result)
{
    if (left < 0 || right >= size || left > right)
    {
        return 0;
    }

    if (left == 0)
    {
        *result = prefix[right];
    }
    else
    {
        *result = prefix[right] - prefix[left - 1];
    }

    return 1;
}

int main(void)
{
    int arr[] = {2, 4, 1, 5, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long prefix[size];

    prefix[0] = arr[0];

    for (int i = 1; i < size; i++)
    {
        prefix[i] = prefix[i - 1] + arr[i];
    }

    long long result;

    if (rangeSum(prefix, size, 1, 3, &result))
    {
        printf("Range sum: %lld\n", result);
    }
    else
    {
        printf("Invalid range\n");
    }

    return 0;
}
Expected Output: 
Range sum: 10

Preprocessing Time: O(n)

Each Query: O(1)

Auxiliary Space: O(n)

5. Answering Multiple Range Sum Queries

Prefix sums are particularly useful when many range-sum queries are performed on an array that does not change. 

#include <stdio.h>

int main(void)
{
    int arr[] = {3, 2, 7, 10, 5, 1};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long prefix[size];

    prefix[0] = arr[0];

    for (int i = 1; i < size; i++)
    {
        prefix[i] = prefix[i - 1] + arr[i];
    }

    int queries[][2] = {
        {0, 2},
        {1, 4},
        {2, 5},
        {3, 3}
    };

    int queryCount = sizeof(queries) / sizeof(queries[0]);

    for (int i = 0; i < queryCount; i++)
    {
        int left = queries[i][0];
        int right = queries[i][1];

        long long sum;

        if (left == 0)
        {
            sum = prefix[right];
        }
        else
        {
            sum = prefix[right] - prefix[left - 1];
        }

        printf("Query %d: %lld\n", i + 1, sum);
    }

    return 0;
}
Expected Output: 
Query 1: 12
Query 2: 24
Query 3: 23
Query 4: 10
Placement relevance: Prefix sums are commonly used in range-query problems because they reduce each query from O(n) to O(1) after O(n) preprocessing.

6. What Is Suffix Sum?

Suffix sum stores the cumulative sum from the current position to the end of the array.

Mathematical definition:

suffix[i] = arr[i] + arr[i + 1] + ... + arr[n - 1]

Example: 
Original array:
arr = {2, 4, 1, 5, 3}

Suffix sum:
suffix = {15, 13, 9, 8, 3}
IndexElementSuffix CalculationSuffix Sum
022 + 4 + 1 + 5 + 315
144 + 1 + 5 + 313
211 + 5 + 39
355 + 38
4333

7. Constructing a Suffix Sum Array

Formula:

suffix[n - 1] = arr[n - 1]

suffix[i] = arr[i] + suffix[i + 1]
#include <stdio.h>

int main(void)
{
    int arr[] = {2, 4, 1, 5, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long suffix[size];

    suffix[size - 1] = arr[size - 1];

    for (int i = size - 2; i >= 0; i--)
    {
        suffix[i] = arr[i] + suffix[i + 1];
    }

    printf("Suffix sum array: ");

    for (int i = 0; i < size; i++)
    {
        printf("%lld ", suffix[i]);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Suffix sum array: 15 13 9 8 3

Time Complexity: O(n)

Auxiliary Space: O(n)

9. Find the Equilibrium Index

An equilibrium index is an index where the sum of elements strictly to its left equals the sum of elements strictly to its right.

Example:

Array = {1, 3, 5, 2, 2}

At index 2:
Left sum  = 1 + 3 = 4
Right sum = 2 + 2 = 4

Equilibrium index = 2

Approach

  1. Calculate the total sum of the array.
  2. Initialize leftSum to zero.
  3. For each index, calculate rightSum = totalSum - leftSum - arr[i].
  4. If leftSum equals rightSum, return the index.
  5. Otherwise, add the current element to leftSum.
#include <stdio.h>

int equilibriumIndex(const int arr[], int size)
{
    long long totalSum = 0;
    long long leftSum = 0;

    for (int i = 0; i < size; i++)
    {
        totalSum += arr[i];
    }

    for (int i = 0; i < size; i++)
    {
        long long rightSum =
            totalSum - leftSum - arr[i];

        if (leftSum == rightSum)
        {
            return i;
        }

        leftSum += arr[i];
    }

    return -1;
}

int main(void)
{
    int arr[] = {1, 3, 5, 2, 2};
    int size = sizeof(arr) / sizeof(arr[0]);

    int index = equilibriumIndex(arr, size);

    if (index != -1)
    {
        printf("Equilibrium index: %d\n", index);
    }
    else
    {
        printf("No equilibrium index found\n");
    }

    return 0;
}
Expected Output: 
Equilibrium index: 2

Time Complexity: O(n)

Auxiliary Space: O(1)

10. Find the Product of Array Except Self

Given an array, create a result array in which each position contains the product of every other element except the element at that position.

Example:

Input:  {1, 2, 3, 4}
Output: {24, 12, 8, 6}

We calculate prefix products and suffix products without dividing by the current element. 

#include <stdio.h>

void productExceptSelf(const int arr[], int result[], int size)
{
    long long prefixProduct = 1;

    for (int i = 0; i < size; i++)
    {
        result[i] = (int)prefixProduct;
        prefixProduct *= arr[i];
    }

    long long suffixProduct = 1;

    for (int i = size - 1; i >= 0; i--)
    {
        result[i] = (int)(result[i] * suffixProduct);
        suffixProduct *= arr[i];
    }
}

int main(void)
{
    int arr[] = {1, 2, 3, 4};
    int size = sizeof(arr) / sizeof(arr[0]);
    int result[size];

    productExceptSelf(arr, result, size);

    printf("Result: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", result[i]);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Result: 24 12 8 6
Integer range: This example uses int for the result array to keep the demonstration simple. Products must fit within the range of int; otherwise signed overflow is undefined in C. Production code should use a suitable wider type and define how overflow is handled.

Time Complexity: O(n)

Auxiliary Space: O(1) excluding the output array.

11. Count Subarrays With Sum Equal to K

Given an integer array and a target k, count the number of contiguous subarrays whose sum equals k.

A brute-force approach checks every subarray in O(n²). A more efficient approach uses prefix sums and a hash table.

Prefix Sum Observation

If the current prefix sum is S, a previous prefix sum of S - k means the elements between those two prefix positions have sum k.

Therefore, while scanning the array, count how many previous prefix sums equal S - k.

The following implementation uses a hash table with open addressing and linear probing. It supports negative values and handles repeated prefix sums. 
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

#define TABLE_SIZE 100003

typedef struct
{
    long long key;
    long long frequency;
    int used;
} HashEntry;

unsigned long long hashValue(long long key)
{
    return (unsigned long long)key % TABLE_SIZE;
}

long long getFrequency(HashEntry table[], long long key)
{
    unsigned long long index = hashValue(key);

    while (table[index].used)
    {
        if (table[index].key == key)
        {
            return table[index].frequency;
        }

        index = (index + 1) % TABLE_SIZE;
    }

    return 0;
}

int addFrequency(HashEntry table[], long long key)
{
    unsigned long long index = hashValue(key);

    while (table[index].used)
    {
        if (table[index].key == key)
        {
            table[index].frequency++;
            return 1;
        }

        index = (index + 1) % TABLE_SIZE;
    }

    table[index].used = 1;
    table[index].key = key;
    table[index].frequency = 1;

    return 1;
}

int main(void)
{
    int arr[] = {1, 2, 3, -2, 2};
    int size = sizeof(arr) / sizeof(arr[0]);
    int k = 3;

    HashEntry *table = calloc(TABLE_SIZE, sizeof(HashEntry));

    if (table == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    long long prefixSum = 0;
    long long count = 0;

    addFrequency(table, 0);

    for (int i = 0; i < size; i++)
    {
        prefixSum += arr[i];

        count += getFrequency(table, prefixSum - k);

        addFrequency(table, prefixSum);
    }

    printf("Subarrays with sum %d: %lld\n", k, count);

    free(table);
    return 0;
}
Expected Output: 
Subarrays with sum 3: 4

The four qualifying subarrays are:

  • {1, 2}
  • {3}
  • {1, 2, 3, -2, -1} — not present in this input, so not counted.
  • {3, -2, 2}
  • {2, 3, -2}
  • {1, 2, 3, -2, 2} — total is 6, so not counted.
Hash table note: The table above has a fixed capacity. A production-quality implementation must check for a full table and choose a capacity appropriate for the maximum number of distinct prefix sums. Its expected time complexity is O(n) with a suitable hash table; worst-case probing can be slower.

14. Common Mistakes

  • Forgetting that array indices start from zero.
  • Using prefix[L] - prefix[R] instead of the correct range formula.
  • Not handling the special case L = 0.
  • Building suffix sums in the wrong direction.
  • Using int when cumulative sums may exceed its range.
  • Confusing a subarray with a subsequence.
  • Forgetting to insert prefix sum zero before counting subarrays.
  • Failing to count repeated prefix sums correctly.
  • Using prefix arrays for a frequently updated array without considering the update cost.

15. Placement Interview Questions and Answers

Q1. What is a prefix sum?

A cumulative sum from the beginning of an array up to a particular index.

Q2. What is a suffix sum?

A cumulative sum from a particular index to the end of an array.

Q3. What is the prefix sum formula?

prefix[i] = prefix[i - 1] + arr[i], with prefix[0] = arr[0].

Q4. What is the suffix sum formula?

suffix[i] = arr[i] + suffix[i + 1], with suffix[n - 1] = arr[n - 1].

Q5. How do you calculate a range sum using prefix sums?

prefix[R] - prefix[L - 1] when L is greater than zero; otherwise use prefix[R].

Q6. What is the complexity of building a prefix array?

O(n) time and O(n) auxiliary space.

Q7. What is the complexity of a range query after prefix preprocessing?

O(1).

Q8. Can prefix sums handle negative values?

Yes. Prefix sums work with positive, negative and zero values.

Q9. What is an equilibrium index?

An index where the sum of elements on the left equals the sum of elements on the right.

Q10. How can an equilibrium index be found in O(n)?

Calculate the total sum, maintain a running left sum and derive the right sum at each index.

Q11. What is the difference between prefix sum and sliding window?

Prefix sums preprocess cumulative values for range calculations, whereas sliding window maintains a moving contiguous range.

Q12. Why is a prefix sum of zero initially inserted in the hash table for subarray sum equals K?

It allows subarrays beginning at index zero to be counted correctly.

Q13. How does prefix sum help count subarrays with sum K?

For current prefix S, count previous prefixes equal to S - K.

Q14. Can prefix sum be used for range XOR queries?

Yes. Prefix XOR values can answer a range XOR query using XOR properties.

Q15. What happens to prefix sums when an array element changes?

All later prefix sums may need updating in a simple prefix array implementation.

Q16. What is the product-except-self problem?

For each index, calculate the product of all array elements except the current element.

Q17. Why is division avoided in product-except-self solutions?

Division fails when zero is present and may introduce division-related edge cases.

Q18. What data structure can optimize subarray sum equals K?

A hash table storing frequencies of previously seen prefix sums.

Q19. What is the difference between a subarray and a subsequence?

A subarray is contiguous; a subsequence may skip elements while preserving their relative order.

Q20. When is prefix sum particularly useful?

When multiple range-sum or cumulative-value queries are performed on data that is not frequently updated.

19. Lesson Summary

Prefix and suffix sums are preprocessing techniques that store cumulative values in an array. They help answer range queries efficiently and provide a foundation for many important coding interview problems.

Prefix sums combined with hash tables can also solve subarray-sum problems efficiently, including cases involving negative numbers.
