2. Find the Second Largest Distinct Element

Given an array, find its second largest distinct element. Duplicate occurrences of the maximum must not be counted as a second distinct value. 

Input:
10 5 20 20 8

Output:
Second largest = 10

Approach

  • Maintain the largest and second largest values.
  • Update the second largest when a new maximum is found.
  • Ignore values equal to the current maximum.
#include <stdio.h>
#include <stdbool.h>

bool secondLargest(const int arr[], int n, int *answer)
{
    if (n < 2)
        return false;

    int largest = 0;
    int second = 0;

    bool hasLargest = false;
    bool hasSecond = false;

    for (int i = 0; i < n; i++)
    {
        if (!hasLargest || arr[i] > largest)
        {
            if (hasLargest)
            {
                second = largest;
                hasSecond = true;
            }

            largest = arr[i];
            hasLargest = true;
        }
        else if (arr[i] < largest &&
                 (!hasSecond || arr[i] > second))
        {
            second = arr[i];
            hasSecond = true;
        }
    }

    if (!hasSecond)
        return false;

    *answer = second;
    return true;
}

int main(void)
{
    int arr[] = {10, 5, 20, 20, 8};
    int n = sizeof(arr) / sizeof(arr[0]);
    int result;

    if (secondLargest(arr, n, &result))
        printf("Second largest = %d\n", result);
    else
        printf("Second largest distinct element not found\n");

    return 0;
}
Expected Output: 
Second largest = 10

Time: O(n)

Auxiliary Space: O(1)

3. Find the Majority Element

A majority element is an element that appears more than n/2 times in an array. 

Input:
2 2 1 1 2 2 2

Output:
Majority element = 2

Boyer-Moore Voting Algorithm

Maintain a candidate and a vote count. Increment the count when the current element matches the candidate; otherwise, decrement it. When the count becomes zero, select a new candidate.

The voting algorithm identifies a candidate, but does not prove that it is a majority element. A second pass is required to verify its frequency. 
#include <stdio.h>
#include <stdbool.h>

bool majorityElement(const int arr[], int n, int *answer)
{
    if (n <= 0)
        return false;

    int candidate = 0;
    int count = 0;

    for (int i = 0; i < n; i++)
    {
        if (count == 0)
            candidate = arr[i];

        if (arr[i] == candidate)
            count++;
        else
            count--;
    }

    int frequency = 0;

    for (int i = 0; i < n; i++)
    {
        if (arr[i] == candidate)
            frequency++;
    }

    if (frequency > n / 2)
    {
        *answer = candidate;
        return true;
    }

    return false;
}

int main(void)
{
    int arr[] = {2, 2, 1, 1, 2, 2, 2};
    int n = sizeof(arr) / sizeof(arr[0]);
    int result;

    if (majorityElement(arr, n, &result))
        printf("Majority element = %d\n", result);
    else
        printf("No majority element\n");

    return 0;
}
Expected Output: 
Majority element = 2

Time: O(n)

Auxiliary Space: O(1)

4. Find the Missing Number from 1 to N

An array contains distinct numbers from 1 to N, with exactly one number missing. Find the missing number. 

Input:
1 2 4 5

N = 5

Output:
Missing number = 3

Approach: Expected Sum

The sum of numbers from 1 to N is N × (N + 1) / 2. Subtract the actual array sum. 

#include <stdio.h>

int main(void)
{
    int arr[] = {1, 2, 4, 5};
    int n = 5;

    long long expected =
        (long long)n * (n + 1) / 2;

    long long actual = 0;

    for (int i = 0; i < n - 1; i++)
        actual += arr[i];

    printf("Missing number = %lld\n",
           expected - actual);

    return 0;
}
Expected Output: 
Missing number = 3

Time: O(n)

Auxiliary Space: O(1)

This method assumes exactly one number is missing and all other values are distinct and within 1 to N. For extremely large ranges, use a wider integer type or an overflow-safe approach.

5. Find a Duplicate Element

Given n+1 integers where each integer is between 1 and n, find the duplicate. Multiple occurrences of the same duplicated value are possible, but there is one distinct duplicated value. 

Input:
1 3 4 2 2

Output:
Duplicate = 2

Floyd's Cycle Detection Algorithm

Treat each array value as the next index in a linked structure. This creates a cycle because there are more array positions than possible values. 

#include <stdio.h>

int findDuplicate(const int arr[], int n)
{
    int slow = arr[0];
    int fast = arr[0];

    do
    {
        slow = arr[slow];
        fast = arr[arr[fast]];
    }
    while (slow != fast);

    slow = arr[0];

    while (slow != fast)
    {
        slow = arr[slow];
        fast = arr[fast];
    }

    return slow;
}

int main(void)
{
    int arr[] = {1, 3, 4, 2, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Duplicate = %d\n", findDuplicate(arr, n));

    return 0;
}
Expected Output: 
Duplicate = 2

Time: O(n)

Auxiliary Space: O(1)

This algorithm requires the exact problem constraints: n+1 elements, each in the range 1 to n, with at least one repeated value. It does not solve arbitrary duplicate detection problems.

6. Find All Duplicates in an Array

Given an array containing values from 1 to n, find the values that appear more than once. 

Input:
4 3 2 7 8 2 3 1

Output:
Duplicates: 3 2

Approach: Frequency Array

Maintain a frequency array. Each value is used as an index to count how many times it appears. 

#include <stdio.h>

int main(void)
{
    int arr[] = {4, 3, 2, 7, 8, 2, 3, 1};
    int n = sizeof(arr) / sizeof(arr[0]);

    int frequency[n + 1] = {0};

    printf("Duplicates: ");

    for (int i = 0; i < n; i++)
    {
        if (arr[i] < 1 || arr[i] > n)
        {
            printf("\nInvalid input\n");
            return 1;
        }

        frequency[arr[i]]++;
    }

    for (int i = 1; i <= n; i++)
    {
        if (frequency[i] > 1)
            printf("%d ", i);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Duplicates: 2 3

Time: O(n)

Auxiliary Space: O(n)

7. Find the Single Number

Every element appears twice except one element. Find the element that appears only once. 

Input:
4 1 2 1 2

Output:
Single number = 4

Approach: XOR

Useful properties of XOR:

  • a XOR a = 0
  • a XOR 0 = a
  • XOR is commutative and associative.
#include <stdio.h>

int main(void)
{
    int arr[] = {4, 1, 2, 1, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    int result = 0;

    for (int i = 0; i < n; i++)
        result ^= arr[i];

    printf("Single number = %d\n", result);

    return 0;
}
Expected Output: 
Single number = 4

Time: O(n)

Auxiliary Space: O(1)

8. Merge Two Sorted Arrays

Given two sorted arrays, merge them into a single sorted array. 

A = 1 3 5
B = 2 4 6

Merged:
1 2 3 4 5 6

Approach: Two Pointers

Compare the current elements of both arrays. Copy the smaller value into the result array. After one array is exhausted, copy the remaining elements from the other array. 

#include <stdio.h>

void mergeSorted(const int a[], int n,
                 const int b[], int m,
                 int result[])
{
    int i = 0;
    int j = 0;
    int k = 0;

    while (i < n && j < m)
    {
        if (a[i] <= b[j])
            result[k++] = a[i++];
        else
            result[k++] = b[j++];
    }

    while (i < n)
        result[k++] = a[i++];

    while (j < m)
        result[k++] = b[j++];
}

int main(void)
{
    int a[] = {1, 3, 5};
    int b[] = {2, 4, 6};

    int result[6];

    mergeSorted(a, 3, b, 3, result);

    for (int i = 0; i < 6; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}
Expected Output: 
1 2 3 4 5 6

Time: O(n + m)

Auxiliary Space: O(n + m) for the result array.

9. Product of Array Except Self

For every index, calculate the product of all array elements except the element at that index. 

Input:
1 2 3 4

Output:
24 12 8 6

Prefix and Suffix Product

First calculate products of elements to the left of each index. Then multiply by the product of elements to the right. 

#include <stdio.h>

void productExceptSelf(const int arr[], int n, int result[])
{
    int prefix = 1;

    for (int i = 0; i < n; i++)
    {
        result[i] = prefix;
        prefix *= arr[i];
    }

    int suffix = 1;

    for (int i = n - 1; i >= 0; i--)
    {
        result[i] *= suffix;
        suffix *= arr[i];
    }
}

int main(void)
{
    int arr[] = {1, 2, 3, 4};
    int n = sizeof(arr) / sizeof(arr[0]);

    int result[4];

    productExceptSelf(arr, n, result);

    for (int i = 0; i < n; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}
Expected Output: 
24 12 8 6

Time: O(n)

Auxiliary Space: O(1), excluding the output array.

The example uses int and assumes all intermediate products fit in int. For larger values, use a wider type such as long long and still check whether the product can overflow that type. The algorithm also handles zero elements without division.

10. Find the Best Time to Buy and Sell Stock

Given daily stock prices, choose one day to buy and a later day to sell to maximize profit. If no profit is possible, return zero. 

Prices:
7 1 5 3 6 4

Buy at: 1
Sell at: 6

Maximum profit = 5

Approach

  • Maintain the minimum price seen so far.
  • Calculate the profit at each day.
  • Update the maximum profit.
#include <stdio.h>

int maxProfit(const int prices[], int n)
{
    if (n < 2)
        return 0;

    int minPrice = prices[0];
    int bestProfit = 0;

    for (int i = 1; i < n; i++)
    {
        int profit = prices[i] - minPrice;

        if (profit > bestProfit)
            bestProfit = profit;

        if (prices[i] < minPrice)
            minPrice = prices[i];
    }

    return bestProfit;
}

int main(void)
{
    int prices[] = {7, 1, 5, 3, 6, 4};
    int n = sizeof(prices) / sizeof(prices[0]);

    printf("Maximum profit = %d\n", maxProfit(prices, n));

    return 0;
}
Expected Output: 
Maximum profit = 5

Time: O(n)

Auxiliary Space: O(1)

11. Find the Equilibrium Index

An equilibrium index is an index where the sum of elements on the left equals the sum of elements on the right. The current element is excluded. 

Input:
1 3 5 2 2

At index 2:
Left sum  = 1 + 3 = 4
Right sum = 2 + 2 = 4

Output:
Equilibrium index = 2

#include <stdio.h>

int equilibriumIndex(const int arr[], int n)
{
    long long total = 0;
    long long leftSum = 0;

    for (int i = 0; i < n; i++)
        total += arr[i];

    for (int i = 0; i < n; i++)
    {
        long long rightSum = total - leftSum - arr[i];

        if (leftSum == rightSum)
            return i;

        leftSum += arr[i];
    }

    return -1;
}

int main(void)
{
    int arr[] = {1, 3, 5, 2, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    int index = equilibriumIndex(arr, n);

    if (index != -1)
        printf("Equilibrium index = %d\n", index);
    else
        printf("No equilibrium index\n");

    return 0;
}
Expected Output: 
Equilibrium index = 2

Time: O(n)

Auxiliary Space: O(1)

12. Find the Longest Consecutive Sequence

Given an unsorted array, find the length of the longest sequence of consecutive integers. The numbers do not need to appear next to each other in the original array. 

Input:
100 4 200 1 3 2

Longest sequence:
1 2 3 4

Output:
Length = 4

Approach: Sort and Scan

Sort the array, ignore duplicates and count consecutive values. This approach is straightforward, although it takes O(n log n) time. 

#include <stdio.h>
#include <stdlib.h>

int compareInt(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

int longestConsecutive(int arr[], int n)
{
    if (n == 0)
        return 0;

    qsort(arr, (size_t)n, sizeof(arr[0]), compareInt);

    int currentLength = 1;
    int bestLength = 1;

    for (int i = 1; i < n; i++)
    {
        if (arr[i] == arr[i - 1])
            continue;

        if ((long long)arr[i] == (long long)arr[i - 1] + 1)
            currentLength++;
        else
            currentLength = 1;

        if (currentLength > bestLength)
            bestLength = currentLength;
    }

    return bestLength;
}

int main(void)
{
    int arr[] = {100, 4, 200, 1, 3, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Length = %d\n", longestConsecutive(arr, n));

    return 0;
}
Expected Output: 
Length = 4

Time: O(n log n)

Auxiliary Space: O(n) in the worst case for qsort implementation details.

An expected O(n) solution can use a hash set and only start counting from values that have no predecessor. That is an important optimization to study in the hashing chapter.

13. Trapping Rain Water

Given an array representing heights of bars, calculate how much rainwater can be trapped between them. 

Input:
0 1 0 2 1 0 1 3 2 1 2 1

Output:
Trapped water = 6

Two-Pointer Approach

Maintain left and right pointers and the maximum heights observed from each side. Process the side with the smaller maximum boundary because it determines the water level. 

#include <stdio.h>

long long trapRainWater(const int height[], int n)
{
    int left = 0;
    int right = n - 1;

    int leftMax = 0;
    int rightMax = 0;

    long long water = 0;

    while (left <= right)
    {
        if (height[left] <= height[right])
        {
            if (height[left] >= leftMax)
                leftMax = height[left];
            else
                water += leftMax - height[left];

            left++;
        }
        else
        {
            if (height[right] >= rightMax)
                rightMax = height[right];
            else
                water += rightMax - height[right];

            right--;
        }
    }

    return water;
}

int main(void)
{
    int height[] = {
        0, 1, 0, 2, 1, 0,
        1, 3, 2, 1, 2, 1
    };

    int n = sizeof(height) / sizeof(height[0]);

    printf("Trapped water = %lld\n",
           trapRainWater(height, n));

    return 0;
}
Expected Output: 
Trapped water = 6

Time: O(n)

Auxiliary Space: O(1)

This implementation assumes all heights are non-negative. Validate that condition if the input is not guaranteed.

14. Maximum Product Subarray

Find a contiguous subarray whose product is maximum. Negative values matter because multiplying two negative numbers produces a positive result. 

Input:
2 3 -2 4

Output:
Maximum product = 6

Approach

Maintain the maximum and minimum product ending at the current position. A negative number can exchange their roles, so both values are needed. 

#include <stdio.h>

long long maxProductSubarray(const int arr[], int n)
{
    if (n == 0)
        return 0;

    long long currentMax = arr[0];
    long long currentMin = arr[0];
    long long answer = arr[0];

    for (int i = 1; i < n; i++)
    {
        long long value = arr[i];

        if (value < 0)
        {
            long long temp = currentMax;
            currentMax = currentMin;
            currentMin = temp;
        }

        if (value > currentMax * value)
            currentMax = value;
        else
            currentMax *= value;

        if (value < currentMin * value)
            currentMin = value;
        else
            currentMin *= value;

        if (currentMax > answer)
            answer = currentMax;
    }

    return answer;
}

int main(void)
{
    int arr[] = {2, 3, -2, 4};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("Maximum product = %lld\n",
           maxProductSubarray(arr, n));

    return 0;
}
Expected Output: 
Maximum product = 6

Time: O(n)

Auxiliary Space: O(1)

Products can overflow long long for sufficiently large input values. A production implementation must establish numeric constraints or add checked multiplication.

15. Find the Minimum Number of Jumps to Reach the End

Each array element represents the maximum number of positions that can be jumped forward from that index. Find the minimum number of jumps to reach the last index. 

Input:
2 3 1 1 4

Output:
Minimum jumps = 2

One possible path:
Index 0 → Index 1 → Index 4

Greedy Approach

Track the farthest reachable index, the end of the current jump range, and the number of jumps. 

#include <stdio.h>

int minJumps(const int arr[], int n)
{
    if (n <= 1)
        return 0;

    if (arr[0] == 0)
        return -1;

    int jumps = 1;
    int currentEnd = arr[0];
    int farthest = arr[0];

    for (int i = 1; i < n - 1; i++)
    {
        if (i + arr[i] > farthest)
            farthest = i + arr[i];

        if (i == currentEnd)
        {
            if (farthest <= i)
                return -1;

            jumps++;
            currentEnd = farthest;

            if (currentEnd >= n - 1)
                return jumps;
        }
    }

    return currentEnd >= n - 1 ? jumps : -1;
}

int main(void)
{
    int arr[] = {2, 3, 1, 1, 4};
    int n = sizeof(arr) / sizeof(arr[0]);

    int result = minJumps(arr, n);

    if (result == -1)
        printf("End is not reachable\n");
    else
        printf("Minimum jumps = %d\n", result);

    return 0;
}
Expected Output: 
Minimum jumps = 2

Time: O(n)

Auxiliary Space: O(1)

The greedy solution assumes all jump lengths are non-negative. For arbitrary integer input, validate the constraints first. The implementation uses int for indices and jump lengths, so very large values need additional overflow protection.

16. Find the Pair with a Given Sum in a Sorted Array

Given a sorted array and a target sum, find two elements whose sum equals the target. 

Input:
1 2 4 6 8 9

Target = 10

Output:
Pair = 2, 8

#include <stdio.h>
#include <stdbool.h>

bool findPair(const int arr[], int n, int target,
              int *first, int *second)
{
    int left = 0;
    int right = n - 1;

    while (left < right)
    {
        long long sum =
            (long long)arr[left] + arr[right];

        if (sum == target)
        {
            *first = arr[left];
            *second = arr[right];
            return true;
        }

        if (sum < target)
            left++;
        else
            right--;
    }

    return false;
}

int main(void)
{
    int arr[] = {1, 2, 4, 6, 8, 9};
    int n = sizeof(arr) / sizeof(arr[0]);

    int first, second;

    if (findPair(arr, n, 10, &first, &second))
        printf("Pair = %d, %d\n", first, second);
    else
        printf("Pair not found\n");

    return 0;
}
Expected Output: 
Pair = 2, 8

Time: O(n)

Auxiliary Space: O(1)

18. Common Interview Mistakes

  • Not checking whether a second largest distinct element exists.
  • Forgetting to verify the majority element after Boyer-Moore voting.
  • Assuming a missing-number formula works with duplicate or out-of-range input.
  • Using Floyd's duplicate algorithm without its required constraints.
  • Ignoring integer overflow in sums and products.
  • Using two pointers on an unsorted array when the algorithm requires sorting.
  • Confusing subsequences with contiguous subarrays.
  • Not considering negative values in maximum-product problems.
  • Failing to handle empty and single-element arrays.
  • Not stating time and auxiliary space complexity.

19. Placement Interview Questions and Answers

Q1. What is a majority element?

An element that occurs strictly more than n/2 times.

Q2. What is Boyer-Moore Voting?

A linear-time, constant-space algorithm for identifying a possible majority element, followed by a verification pass.

Q3. What is the XOR property used in single-number problems?

x XOR x equals zero, and x XOR zero equals x.

Q4. How do you find a missing number from 1 to N?

Use the expected sum minus the actual sum, or use XOR to avoid some sum-overflow concerns.

Q5. What is Floyd's cycle detection algorithm?

A two-pointer algorithm that uses slow and fast pointers to detect a cycle in a linked structure.

Q6. How is Floyd's algorithm applied to duplicate arrays?

Array values are treated as next indices, creating a cycle whose entry corresponds to the duplicate under the required constraints.

Q7. How do you merge two sorted arrays efficiently?

Use two pointers and repeatedly copy the smaller current element.

Q8. What is product of array except self?

For each position, calculate the product of all other elements without using division.

Q9. What are prefix and suffix products?

Prefix products contain products of elements before an index; suffix products contain products after it.

Q10. How do you maximize stock profit with one transaction?

Track the minimum price so far and calculate the profit for each later price.

Q11. What is an equilibrium index?

An index where the sum of elements before it equals the sum of elements after it.

Q12. What is a consecutive sequence?

A sequence of integers in which each next value is exactly one greater than the previous value.

Q13. How can the longest consecutive sequence be found?

Sort and scan in O(n log n), or use a hash set for expected O(n) time.

Q14. What is the trapping rain water problem?

It calculates water held between bars using their heights and the maximum boundaries on both sides.

Q15. Why does maximum product subarray need both maximum and minimum products?

A negative value can turn the smallest negative product into the largest positive product.

Q16. What is the greedy approach to minimum jumps?

Expand the reachable range and make a jump whenever the current range ends.

Q17. When can two pointers find a pair sum in O(n)?

When the input is sorted, or after sorting if changing the original order is acceptable.

Q18. What is the difference between O(n) and O(n log n)?

O(n) grows linearly, whereas O(n log n) grows faster as input size increases.

Q19. What should be considered before optimizing an array solution?

Input constraints, correctness, time complexity, auxiliary space and integer overflow.

Q20. What should you explain after writing an interview solution?

Approach, correctness, edge cases, time complexity and auxiliary space complexity.
