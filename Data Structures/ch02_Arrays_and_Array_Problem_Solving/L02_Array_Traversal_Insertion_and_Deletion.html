Lesson 2: Array Traversal, Insertion and Deletion

Learn how to traverse arrays, insert elements at different positions and delete elements efficiently using C++.

1. Introduction

Array operations are fundamental in data structures and coding interviews. The most common operations include:

  • Traversal
  • Insertion
  • Deletion
  • Updating
  • Shifting elements

Understanding how these operations work internally helps in analyzing time complexity and solving array-based problems.

2. Array Traversal

Traversal means visiting each element of an array one by one to perform an operation such as printing, counting or calculating a sum.

Example

Array: {10, 20, 30, 40, 50}

Traversal:
10 → 20 → 30 → 40 → 50

C++ Program: Traverse and Print an Array

#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 30 40 50

Time Complexity: O(N)

Auxiliary Space Complexity: O(1)

3. Traversal in Forward and Reverse Order

Forward Traversal

for (int i = 0; i < n; i++) {
    cout << arr[i] << " ";
}

Reverse Traversal

for (int i = n - 1; i >= 0; i--) {
    cout << arr[i] << " ";
}

Example Output:

50 40 30 20 10

Both operations take O(N) time because each element is visited exactly once.

4. Insertion in an Array

Insertion means adding a new element at a specified position. For a built-in array, the allocated capacity must be sufficient to accommodate the new element.

Insertion can happen at:

  • Beginning
  • Middle
  • End

Example

Original Array:
{10, 20, 30, 40, 50}

Insert 25 at index 2:

Result:
{10, 20, 25, 30, 40, 50}

5. Insertion at the Beginning

To insert an element at index 0, shift all existing elements one position to the right, starting from the last element.

Dry Run

Original:
10 20 30 40 50

Shift:
_  10 20 30 40 50

Insert 5:
5  10 20 30 40 50

C++ Program

#include <iostream>
using namespace std;

int main() {
    int arr[10] = {10, 20, 30, 40, 50};
    int n = 5;
    int value = 5;

    for (int i = n; i > 0; i--) {
        arr[i] = arr[i - 1];
    }

    arr[0] = value;
    n++;

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

5 10 20 30 40 50

Time Complexity: O(N)

6. Insertion at a Specific Position

To insert at index pos, shift elements from the end toward pos one position to the right.

Algorithm

  1. Check whether there is available capacity.
  2. Validate the insertion index.
  3. Shift elements from the end to pos.
  4. Place the new value at pos.
  5. Increase the logical array size.

C++ Program

#include <iostream>
using namespace std;

int main() {
    int arr[10] = {10, 20, 30, 40, 50};
    int n = 5;

    int value = 25;
    int pos = 2;

    if (n >= 10 || pos < 0 || pos > n) {
        cout << "Invalid insertion";
        return 0;
    }

    for (int i = n; i > pos; i--) {
        arr[i] = arr[i - 1];
    }

    arr[pos] = value;
    n++;

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 25 30 40 50

Time Complexity: O(N) in the worst case.

Auxiliary Space: O(1)

In this example, pos is a zero-based index. Insertion at index n appends an element without shifting existing elements.

7. Insertion at the End

If free capacity is available, inserting at the end simply means assigning the value to the next available index. 

#include <iostream>
using namespace std;

int main() {
    int arr[10] = {10, 20, 30};
    int n = 3;

    if (n < 10) {
        arr[n] = 40;
        n++;
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 30 40

Time Complexity: O(1)

8. Deletion from an Array

Deletion means removing an element from a specified position. In a built-in array, the remaining elements are shifted to fill the gap.

Deletion can happen at:

  • Beginning
  • Middle
  • End

Example

Original:
10 20 30 40 50

Delete element at index 2:

Result:
10 20 40 50

9. Deletion at the Beginning

To delete the first element, shift every subsequent element one position to the left and decrease the logical size.

Dry Run

Original:
10 20 30 40 50

Shift left:
20 30 40 50

New logical size = 4

C++ Program

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int n = 5;

    if (n > 0) {
        for (int i = 0; i < n - 1; i++) {
            arr[i] = arr[i + 1];
        }

        n--;
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

20 30 40 50

Time Complexity: O(N)

10. Deletion from a Specific Position

To delete the element at index pos, shift all elements after that position one step to the left.

Algorithm

  1. Check that the array is not empty.
  2. Validate the deletion index.
  3. Shift subsequent elements to the left.
  4. Decrease the logical size by one.

C++ Program

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int n = 5;
    int pos = 2;

    if (pos < 0 || pos >= n) {
        cout << "Invalid position";
        return 0;
    }

    for (int i = pos; i < n - 1; i++) {
        arr[i] = arr[i + 1];
    }

    n--;

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 40 50

Time Complexity: O(N) in the worst case.

Auxiliary Space: O(1)

11. Deletion at the End

To remove the last logical element, decrease the logical size. No shifting is required. 

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int n = 5;

    if (n > 0) {
        n--;
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 30 40

Time Complexity: O(1)

Decreasing n changes the logical size. The old value may still physically remain in the allocated memory, but it is no longer part of the logical array.

12. Updating an Array Element

Updating means replacing the value at an existing index. Since the element can be accessed directly, updating takes constant time. 

#include <iostream>
using namespace std;

int main() {
    int arr[4] = {10, 20, 30, 40};

    arr[2] = 100;

    for (int i = 0; i < 4; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 100 40

Time Complexity: O(1)

13. Complete Array Operations Program

The following program combines traversal, insertion, deletion and updating using functions. 

#include <iostream>
using namespace std;

void display(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

bool insertAt(int arr[], int &n, int capacity,
              int pos, int value) {
    if (n >= capacity || pos < 0 || pos > n)
        return false;

    for (int i = n; i > pos; i--) {
        arr[i] = arr[i - 1];
    }

    arr[pos] = value;
    n++;

    return true;
}

bool deleteAt(int arr[], int &n, int pos) {
    if (pos < 0 || pos >= n)
        return false;

    for (int i = pos; i < n - 1; i++) {
        arr[i] = arr[i + 1];
    }

    n--;

    return true;
}

bool updateAt(int arr[], int n, int pos, int value) {
    if (pos < 0 || pos >= n)
        return false;

    arr[pos] = value;
    return true;
}

int main() {
    const int capacity = 10;
    int arr[capacity] = {10, 20, 30, 40, 50};
    int n = 5;

    cout << "Original array: ";
    display(arr, n);

    insertAt(arr, n, capacity, 2, 25);
    cout << "After insertion: ";
    display(arr, n);

    deleteAt(arr, n, 3);
    cout << "After deletion: ";
    display(arr, n);

    updateAt(arr, n, 1, 100);
    cout << "After update: ";
    display(arr, n);

    return 0;
}

Expected Output:

Original array: 10 20 30 40 50
After insertion: 10 20 25 30 40 50
After deletion: 10 20 25 40 50
After update: 10 100 25 40 50

The functions use a reference parameter for n so that insertion and deletion can update the caller's logical size.

14. Time Complexity Comparison

Operation Best Case Worst Case
Traversal Θ(N) Θ(N)
Access by index Θ(1) Θ(1)
Update by index Θ(1) Θ(1)
Insert at beginning Θ(N) Θ(N)
Insert at middle O(N) O(N)
Insert at end (with capacity) Θ(1) Θ(1)
Delete at beginning Θ(N) Θ(N)
Delete at middle O(N) O(N)
Delete at end Θ(1) Θ(1)

For insertion and deletion at a specified index, the actual number of shifted elements depends on the position. At the beginning, nearly all elements must move; at the end, no elements need to move.

15. Common Interview Mistakes

  • Using an incorrect index during shifting.
  • Shifting elements in the wrong direction.
  • Forgetting to update the logical size.
  • Inserting when the array has no free capacity.
  • Deleting from an empty array.
  • Allowing an invalid position.
  • Using an incorrect loop boundary.
For insertion, shift from right to left to avoid overwriting values that still need to be moved. For deletion, shift from left to right.

18. Multiple-Choice Questions

Q1. What is the time complexity of array traversal?

A) O(1)   B) O(N)   C) O(log N)   D) O(N²)

Answer: B) O(N)

Q2. What is the time complexity of insertion at the beginning?

A) O(1)   B) O(log N)   C) O(N)   D) O(N²)

Answer: C) O(N)

Q3. Which direction is used to shift elements during insertion?

A) Left to right   B) Right to left   C) Random   D) No shifting

Answer: B) Right to left

Q4. What is the complexity of deleting the last logical element?

A) O(N)   B) O(N²)   C) O(log N)   D) O(1)

Answer: D) O(1)

Q5. What must be updated after successful insertion?

A) Base address   B) Logical size   C) Data type   D) Index origin

Answer: B) Logical size

19. Lesson Summary

  • Traversal visits array elements one by one.
  • Insertion adds an element at a valid position.
  • Deletion removes an element and shifts subsequent values.
  • Insertion shifts elements from right to left.
  • Deletion shifts elements from left to right.
  • Insertion and deletion at the end can take O(1) time.
  • Operations at the beginning or middle may require O(N) shifting.
  • Always validate capacity, indexes and logical size.
