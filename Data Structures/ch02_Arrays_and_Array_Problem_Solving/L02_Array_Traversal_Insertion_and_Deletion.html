Lesson 2: Array Traversal, Insertion and Deletion

Learn how to traverse arrays, insert elements at different positions, delete elements and implement efficient array operations using C.

1. Introduction to Array Operations

An array stores elements in contiguous memory locations. Once an array is declared, its physical capacity is fixed.

Common array operations include:

  • Traversal
  • Insertion
  • Deletion
  • Updating
  • Searching
  • Sorting

This lesson concentrates on traversal, insertion and deletion.

2. Array Traversal

Traversal means visiting each element of an array one by one to read, display or process it.

Example Array

int arr[5] = {10, 20, 30, 40, 50};

Traversal Algorithm

  1. Start from index 0.
  2. Visit the current element.
  3. Move to the next index.
  4. Continue until index reaches the array size.

Pseudocode

START
    FOR i = 0 TO n - 1
        PRINT arr[i]
    END FOR
STOP

C Program: Array Traversal

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("Array elements:\n");

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Array elements:
10 20 30 40 50

Dry Run

Iteration Index i Element Output
101010
212020
323030
434040
545050

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

3. Traversal Using a Function

In C, array traversal can be implemented inside a separate function. 

#include <stdio.h>

void display_array(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {5, 10, 15, 20, 25};

    int n = sizeof arr / sizeof arr[0];

    display_array(arr, n);

    return 0;
}
5 10 15 20 25

The function receives the array address and the number of elements separately.

4. Insertion in an Array

Insertion means adding a new element at a specified position in an array.

Since an array uses contiguous memory, elements may need to be shifted to create space for the new element.

Example

Original array:

10 20 30 40 50

Insert 25 at index 2.

Result:

10 20 25 30 40 50

Insertion Algorithm

  1. Check whether the array has available capacity.
  2. Check whether the insertion index is valid.
  3. Start from the last existing element.
  4. Shift elements one position to the right.
  5. Insert the new element at the required index.
  6. Increase the logical array size by one.

Pseudocode

START
    IF size == capacity
        PRINT "Array is full"
        STOP
    END IF

    FOR i = size - 1 DOWN TO position
        arr[i + 1] = arr[i]
    END FOR

    arr[position] = value
    size = size + 1
STOP

5. Insertion at the Beginning

To insert an element at index 0, all existing elements must shift one position to the right.

Example

Before insertion:

10 20 30 40 50

Insert 5 at index 0.

After insertion:

5 10 20 30 40 50

C Implementation

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40, 50};
    int n = 5;
    int value = 5;

    if (n == 10)
    {
        printf("Array is full\n");
        return 1;
    }

    for (int i = n - 1; i >= 0; i--)
    {
        arr[i + 1] = arr[i];
    }

    arr[0] = value;
    n++;

    printf("Array after insertion: ");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Array after insertion: 5 10 20 30 40 50

Dry Run

Shift 4010 20 30 40 40 50
Shift 3010 20 30 30 40 50
Shift 2010 20 20 30 40 50
Shift 1010 10 20 30 40 50

Time Complexity: O(n)

6. Insertion at a Specific Position

An element can be inserted at any valid index between 0 and the current size.

Example

Original array:

10 20 30 40 50

Insert 25 at index 2.

Result:

10 20 25 30 40 50

Complete C Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40, 50};

    int n = 5;
    int position = 2;
    int value = 25;

    if (n >= 10)
    {
        printf("Array is full\n");
        return 1;
    }

    if (position < 0 || position > n)
    {
        printf("Invalid insertion position\n");
        return 1;
    }

    for (int i = n - 1; i >= position; i--)
    {
        arr[i + 1] = arr[i];
    }

    arr[position] = value;
    n++;

    printf("Array after insertion:\n");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Array after insertion:
10 20 25 30 40 50

Important Conditions

  • position = 0 means insertion at the beginning.
  • position = n means insertion at the end.
  • 0 through n are valid insertion indices.
  • Insertion requires unused array capacity.

7. Insertion at the End

Insertion at the end does not require shifting existing elements when unused capacity is available.

Example

Before insertion:

10 20 30 40

Insert 50 at the end.

After insertion:

10 20 30 40 50

C Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40};

    int n = 4;
    int value = 50;

    if (n >= 10)
    {
        printf("Array is full\n");
        return 1;
    }

    arr[n] = value;
    n++;

    printf("Array after insertion: ");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Array after insertion: 10 20 30 40 50

Time Complexity: O(1), assuming available capacity.

8. Deletion from an Array

Deletion means removing an element from a specified position.

After deletion, elements located to the right of the deleted element must shift one position to the left.

Example

Original array:

10 20 30 40 50

Delete the element at index 2.

Result:

10 20 40 50

Deletion Algorithm

  1. Check whether the array contains elements.
  2. Validate the deletion index.
  3. Shift elements after that index one position left.
  4. Decrease the logical size by one.

Pseudocode

START
    IF size == 0
        PRINT "Array is empty"
        STOP
    END IF

    IF position is invalid
        PRINT "Invalid position"
        STOP
    END IF

    FOR i = position TO size - 2
        arr[i] = arr[i + 1]
    END FOR

    size = size - 1
STOP

9. Deletion from the Beginning

To delete the first element, all remaining elements shift one position to the left.

Example

Before deletion:

10 20 30 40 50

After deletion:

20 30 40 50

C Program

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int n = 5;

    if (n == 0)
    {
        printf("Array is empty\n");
        return 1;
    }

    for (int i = 0; i < n - 1; i++)
    {
        arr[i] = arr[i + 1];
    }

    n--;

    printf("After deletion: ");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
After deletion: 20 30 40 50

Time Complexity: O(n)

12. Complete Reusable Array Insertion and Deletion Functions

In placement coding rounds, reusable functions are often preferable to writing every operation directly inside main().

Complete C11 Program

#include <stdio.h>

#define CAPACITY 100

int insert_at(int arr[], int *size, int capacity,
              int position, int value)
{
    if (*size >= capacity)
    {
        return 0;
    }

    if (position < 0 || position > *size)
    {
        return 0;
    }

    for (int i = *size; i > position; i--)
    {
        arr[i] = arr[i - 1];
    }

    arr[position] = value;
    (*size)++;

    return 1;
}

int delete_at(int arr[], int *size, int position)
{
    if (*size <= 0)
    {
        return 0;
    }

    if (position < 0 || position >= *size)
    {
        return 0;
    }

    for (int i = position; i < *size - 1; i++)
    {
        arr[i] = arr[i + 1];
    }

    (*size)--;

    return 1;
}

void display(const int arr[], int size)
{
    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[CAPACITY] = {10, 20, 30, 40, 50};
    int size = 5;

    printf("Original array: ");
    display(arr, size);

    if (insert_at(arr, &size, CAPACITY, 2, 25))
    {
        printf("After insertion: ");
        display(arr, size);
    }
    else
    {
        printf("Insertion failed\n");
    }

    if (delete_at(arr, &size, 3))
    {
        printf("After deletion: ");
        display(arr, size);
    }
    else
    {
        printf("Deletion failed\n");
    }

    return 0;
}
Original array: 10 20 30 40 50
After insertion: 10 20 25 30 40 50
After deletion: 10 20 25 40 50

Why Are Pointers Used for size?

The functions receive the address of the size variable. This allows them to update the original size in main(). 

int size = 5;

insert_at(arr, &size, CAPACITY, 2, 25);

The expression *size inside insert_at() accesses and modifies the caller's size variable.

13. Insertion and Deletion Complexity Comparison

Operation Time Complexity Reason
Traversal O(n) Visits all elements.
Insertion at beginning O(n) Shifts all existing elements.
Insertion at middle O(n) Shifts subsequent elements.
Insertion at end O(1) With available capacity.
Deletion at beginning O(n) Shifts remaining elements.
Deletion at middle O(n) Shifts subsequent elements.
Deletion at end O(1) Only reduces logical size.
Insertion and deletion at the beginning or middle require shifting elements. This is a common reason to consider linked lists when frequent insertions and deletions are required.

14. Common Mistakes in Array Insertion and Deletion

Mistake 1: Incorrect Shifting Direction During Insertion

for (int i = position; i < size; i++)
{
    arr[i + 1] = arr[i];
}

This shifts from left to right and can overwrite values before they are copied.

Correct approach: Shift from right to left.

for (int i = size - 1; i >= position; i--)
{
    arr[i + 1] = arr[i];
}

Mistake 2: Incorrect Shifting Direction During Deletion

Deletion should shift elements from left to right in increasing index order. 

for (int i = position; i < size - 1; i++)
{
    arr[i] = arr[i + 1];
}

Mistake 3: Forgetting to Update Logical Size

After successful insertion, increase size. After successful deletion, decrease size.

Mistake 4: Not Checking Capacity

Insertion into a full array can write outside the allocated array object.

Mistake 5: Incorrect Position Validation

For insertion, position may range from 0 through size. For deletion, position must range from 0 through size-1.

15. Placement Interview Questions and Answers

Q1. What is array traversal?

Traversal is the process of visiting each array element one by one.

Q2. What is the time complexity of traversal?

O(n).

Q3. Why is insertion at the beginning O(n)?

All existing elements must be shifted one position to the right.

Q4. Why is deletion at the beginning O(n)?

All remaining elements must be shifted one position to the left.

Q5. What is the complexity of insertion at the end?

O(1), assuming the array has unused capacity.

Q6. What is the complexity of deletion at the end?

O(1), because only the logical size needs to be decreased.

Q7. Why is insertion performed from right to left?

To prevent overwriting existing values before they have been moved.

Q8. Why is deletion performed from left to right?

Each element is copied from the next position to fill the deleted position.

Q9. What is the valid insertion position range?

0 through size, inclusive.

Q10. What is the valid deletion position range?

0 through size-1.

Q11. What happens when an array is full?

No more elements can be inserted unless additional storage is made available.

Q12. What is logical size?

It is the number of elements currently stored in the array.

Q13. What is array capacity?

It is the maximum number of elements that fit in the currently allocated array storage.

Q14. What is the difference between size and capacity?

Size represents the current number of elements. Capacity represents the available storage for elements.

Q15. Can an element be inserted at index size?

Yes, if capacity is available. This inserts the element at the end.

Q16. What is the role of a temporary variable in shifting?

It can preserve a value when an algorithm needs to exchange or rearrange elements. Direct shifting assignments often do not require a temporary variable.

Q17. Why is an array suitable for traversal?

Its contiguous memory layout and indexing allow sequential and direct element access.

Q18. What is the auxiliary space complexity of in-place insertion?

O(1).

Q19. What is the auxiliary space complexity of in-place deletion?

O(1).

Q20. Which data structure is often considered when frequent insertions and deletions are required?

A linked list may be suitable when the relevant node or position is already known. It avoids shifting subsequent elements, although locating a position may still take O(n).

16. Coding Practice for Placement Preparation

Beginner Level

  1. Traverse an array and print every element.
  2. Insert an element at the beginning.
  3. Insert an element at the end.
  4. Delete the first element.
  5. Delete the last element.

Intermediate Level

  1. Insert an element at a specified index.
  2. Delete an element from a specified index.
  3. Insert an element into a sorted array while preserving order.
  4. Delete all occurrences of a specified value.
  5. Remove duplicate elements from an array.
  6. Implement insertion and deletion using separate functions.

Advanced Level

  1. Implement a dynamic array with insertion and deletion.
  2. Implement insertion and deletion using a menu-driven program.
  3. Shift array elements efficiently for repeated operations.
  4. Compare array insertion and deletion with linked-list operations.
