Lesson 1: Array Basics and Memory Representation

Understand array fundamentals, indexing, contiguous memory allocation and address calculation in C++.

1. What is an Array?

An array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations. Each element can be accessed using its index.

Example:

int marks[5] = {85, 90, 78, 92, 88};

The array contains five integer elements:

Index:    0    1    2    3    4
Value:   85   90   78   92   88

Array indexing in C++ starts from zero. Therefore, the first element is at index 0 and the last element is at index N-1.

2. Why Do We Use Arrays?

  • Store multiple values using a single variable name.
  • Access elements directly using indexes.
  • Process collections using loops.
  • Represent tables, matrices and numerical data.
  • Build other data structures and algorithms.

Example Without an Array

int mark1 = 85;
int mark2 = 90;
int mark3 = 78;
int mark4 = 92;
int mark5 = 88;

Example Using an Array

int marks[5] = {85, 90, 78, 92, 88};

An array makes it easier to store, access and process related values.

3. Array Declaration and Initialization in C++

Declaration

int arr[5];

Creates an array capable of holding five integers.

Initialization

int arr[5] = {10, 20, 30, 40, 50};

Size Inference

int arr[] = {10, 20, 30, 40};

The compiler determines the array size as four.

Partial Initialization

int arr[5] = {10, 20};

The remaining elements are initialized to zero: 

{10, 20, 0, 0, 0}

Zero Initialization

int arr[5] = {};

All elements are initialized to zero.

A local built-in array declared as int arr[5]; without an initializer contains indeterminate values. Do not read those values before initializing the elements.

4. Array Indexing

Each array element is accessed using its index. For an array containing N elements, valid indexes are from 0 to N-1. 

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    cout << arr[0] << endl;
    cout << arr[2] << endl;
    cout << arr[4] << endl;

    return 0;
}

Output:

10
30
50

Updating an Element

arr[2] = 100;

The third element changes from 30 to 100.

Accessing an array outside its valid index range causes undefined behaviour in C++. Always validate indexes.

5. Contiguous Memory Allocation

Array elements are stored in consecutive memory locations. If an integer occupies four bytes, each next integer element is located four bytes after the previous one.

Suppose an integer array starts at address 1000:

Index Value Illustrative Address
0101000
1201004
2301008
3401012
4501016

These addresses are illustrative. Actual addresses depend on the program's memory layout and system.

Contiguous allocation provides efficient direct access.

6. Address Calculation Formula

The address of an array element can be calculated using the base address, index and size of each element. 

Address of arr[i] = Base Address + (i × Size of Element)

Where:

  • Base Address: Address of the first element.
  • i: Index of the required element.
  • Size of Element: Number of bytes occupied by one element.

Example

Suppose:

  • Base address = 2000
  • Index = 3
  • Integer size = 4 bytes
Address of arr[3]
= 2000 + (3 × 4)
= 2000 + 12
= 2012

Answer: 2012

The formula explains why array element access takes constant time: the address is calculated directly rather than searching through earlier elements.

7. Accessing Array Elements Using Pointers

In most expressions, an array name converts to a pointer to its first element. Pointer arithmetic can therefore access array elements. 

#include <iostream>
using namespace std;

int main() {
    int arr[4] = {10, 20, 30, 40};

    cout << *arr << endl;
    cout << *(arr + 1) << endl;
    cout << *(arr + 2) << endl;

    return 0;
}

Output:

10
20
30

The following expressions are equivalent for valid indexes:

arr[i]
*(arr + i)
An array name is not an ordinary modifiable pointer variable. It usually converts to a pointer in expressions, but you cannot assign a new address to the array name.

8. Types of Arrays

One-Dimensional Array

Stores elements in a single sequence.

int arr[5] = {1, 2, 3, 4, 5};

Two-Dimensional Array

Stores elements in rows and columns.

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Three-Dimensional Array

Stores elements across multiple two-dimensional layers.

int data[2][2][2] = {
    {
        {1, 2},
        {3, 4}
    },
    {
        {5, 6},
        {7, 8}
    }
};

9. Two-Dimensional Array Memory Representation

In C++, built-in two-dimensional arrays are stored in row-major order. All elements of the first row are stored before the elements of the second row. 

int matrix[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};

Memory order:

10 → 20 → 30 → 40 → 50 → 60

For a built-in array with R rows and C columns:

Address of matrix[i][j]
= Base Address + ((i × C + j) × Element Size)

Example

Suppose:

  • Base address = 1000
  • Number of columns = 3
  • Element size = 4 bytes
  • Required element = matrix[1][2]
Address = 1000 + ((1 × 3 + 2) × 4)
        = 1000 + (5 × 4)
        = 1020

Answer: 1020

10. Array Size and sizeof Operator

The sizeof operator returns the size in bytes of an object or type. 

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    cout << "Total bytes: " << sizeof(arr) << endl;
    cout << "Element bytes: " << sizeof(arr[0]) << endl;

    int n = sizeof(arr) / sizeof(arr[0]);

    cout << "Number of elements: " << n;

    return 0;
}

Typical output on a system with 4-byte int:

Total bytes: 20
Element bytes: 4
Number of elements: 5
This sizeof technique works when arr is an actual array in the current scope. When an array is passed to a function as a pointer parameter, sizeof on that parameter gives the pointer size, not the original array size.

11. Array vs Vector in C++

C++ provides built-in arrays and the standard library vector container. Both store elements contiguously, but their size-management behaviour differs.

Feature Built-in Array std::vector
Size Fixed after creation Can grow or shrink
Memory Contiguous Contiguous
Direct indexing O(1) O(1)
Automatic size tracking No built-in size member size() available
End insertion Not supported as a dynamic operation Amortized O(1)

Vector Example

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    numbers.push_back(40);

    for (int value : numbers) {
        cout << value << " ";
    }

    return 0;
}

Output:

10 20 30 40

12. Time Complexity of Basic Array Operations

Operation Time Complexity Reason
Access by index O(1) Direct address calculation
Update by index O(1) Direct access
Traversal O(N) Visit every element
Linear search O(N) May inspect every element
Insertion at beginning O(N) Shift existing elements
Deletion at beginning O(N) Shift remaining elements

13. Advantages and Limitations of Arrays

Advantages

  • Constant-time indexed access.
  • Contiguous memory layout.
  • Efficient traversal and cache locality.
  • Simple implementation.
  • Useful for sorting and searching algorithms.

Limitations

  • Built-in array size is fixed after creation.
  • Insertion and deletion in the middle may require shifting.
  • Searching an unsorted array generally takes O(N).
  • Incorrect index access can cause undefined behaviour.

Q2. What is the time complexity of accessing arr[5]?

A) O(N)   B) O(1)   C) O(log N)   D) O(N²)

Q3. How are built-in two-dimensional arrays stored in C++?

Q4. What is the valid index range of an array containing N elements?

A) 1 to N   B) 0 to N-1   C) 0 to N   D) 1 to N-1

A) O(1)   B) O(log N)   C) O(N)   D) O(N²)

Answer: C) O(N)

Q6. Which container supports dynamic resizing?

A) Built-in array   B) std::vector   C) int   D) char

17. Lesson Summary

  • An array stores elements of the same type in contiguous memory.
  • C++ array indexing starts at zero.
  • Array access by index takes O(1) time.
  • Address calculation uses the base address and element size.
  • Built-in two-dimensional arrays use row-major order.
  • Array traversal takes O(N) time.
  • Insertion and deletion may require shifting elements.
  • std::vector provides dynamic resizing and contiguous storage.
