Lesson 1: Array Basics and Memory Representation

Understand how arrays work, how elements are stored in memory, how addresses are calculated, and how to implement array operations in C.

1. What Is an Array?

An array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations.

Each element is accessed using an index. In C, array indexing starts from zero.

Example

int marks[5] = {75, 80, 65, 90, 85};

This declaration creates an integer array containing five elements.

Index Value
075
180
265
390
485
Remember: for an array of N elements, valid indices range from 0 to N-1.

2. Why Are Arrays Used?

Suppose we need to store marks for five students. Without an array, we might declare five separate variables. 

int mark1 = 75;
int mark2 = 80;
int mark3 = 65;
int mark4 = 90;
int mark5 = 85;

Managing a large number of separate variables becomes difficult. An array stores related values under one variable name. 

int marks[5] = {75, 80, 65, 90, 85};

Advantages

  • Stores multiple values using one variable name.
  • Provides direct access using an index.
  • Supports efficient traversal using loops.
  • Provides contiguous memory storage.
  • Forms the foundation for many other data structures and algorithms.

Limitations

  • Elements must have compatible declared types.
  • Ordinary fixed-size arrays cannot grow after creation.
  • Insertion and deletion in the middle require shifting elements.
  • Accessing an invalid index results in undefined behavior.

3. Declaration of an Array in C

General syntax:

data_type array_name[array_size];

Examples

int numbers[10];
float prices[5];
char letters[20];
double values[15];

The array size in these declarations must be a positive integer constant expression or, where supported by the language rules, a valid variable-length array size.

Declaration and Initialization

int arr[5] = {10, 20, 30, 40, 50};

Partial Initialization

int arr[5] = {10, 20};

Remaining elements are initialized to zero.

Index Value
010
120
20
30
40

Initialize All Elements to Zero

int arr[5] = {0};

Let the Compiler Determine the Size

int arr[] = {10, 20, 30, 40};

Here, the compiler determines the array length as four elements.

4. Accessing and Updating Array Elements

Array elements are accessed through their indices. 

int arr[5] = {10, 20, 30, 40, 50};

printf("%d", arr[2]);
30

Updating an Element

arr[2] = 100;

The third element changes from 30 to 100.

Complete Example

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("Original value: %d\n", arr[2]);

    arr[2] = 100;

    printf("Updated value: %d\n", arr[2]);

    return 0;
}
Original value: 30
Updated value: 100

5. Array Memory Representation

One of the most important properties of arrays is that their elements are stored in contiguous memory locations.

Consider:

int arr[5] = {10, 20, 30, 40, 50};

Assume for illustration that the base address is 1000 and sizeof(int) is 4 bytes.

Element Index Illustrative Address Value
arr[0]0100010
arr[1]1100420
arr[2]2100830
arr[3]3101240
arr[4]4101650
These addresses are illustrative, not actual addresses guaranteed by a C program.

Why Is Contiguous Memory Important?

  • Elements can be accessed directly using an index.
  • Address calculation is straightforward.
  • Sequential traversal is efficient.
  • Arrays are suitable for many searching and sorting algorithms.

6. Address Calculation Formula

For a one-dimensional array, the address of an element can be calculated using:

Address of arr[i] = Base Address + (i × Size of Each Element)

Where:

  • Base address is the address of the first element.
  • i is the element index.
  • Element size is measured in bytes.

Example

Given:

  • Base address = 2000
  • Size of integer = 4 bytes
  • Index = 3

Address of arr[3] = 2000 + (3 × 4)

Answer = 2012

C Program to Display Element Addresses

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("Size of integer: %zu bytes\n", sizeof(int));

    for (int i = 0; i < 5; i++)
    {
        printf("arr[%d] = %d, Address = %p\n",
               i, arr[i], (void *)&arr[i]);
    }

    return 0;
}

The actual addresses depend on the program's execution environment.

7. Relationship Between Arrays and Pointers

In most expressions, an array expression is converted to a pointer to its first element. This conversion is commonly called array-to-pointer decay. 

int arr[5] = {10, 20, 30, 40, 50};

printf("%d\n", arr[0]);
printf("%d\n", *arr);
printf("%d\n", *(arr + 1));
10
10
20

Important Relationships

arr[i] == *(arr + i)

This relationship explains why array indexing and pointer arithmetic are closely connected.

Array Name vs Pointer Variable

Array Pointer Variable
Represents an array object. Stores a pointer value.
Cannot be assigned a new address. Can be assigned another valid address.
sizeof(arr) gives total array size in its declaration scope. sizeof(ptr) gives the pointer object's size.
arr++ is invalid. ptr++ is valid when the result remains within the permitted array range or one past it.
An array is not simply a pointer variable. Array-to-pointer conversion occurs in most expressions, but arrays and pointers are different C language objects.

8. sizeof() Operator with Arrays

sizeof() returns the size in bytes of an object or type.

Example

#include <stdio.h>

int main(void)
{
    int arr[5];

    size_t total_size = sizeof arr;
    size_t element_size = sizeof arr[0];
    size_t count = total_size / element_size;

    printf("Total array size: %zu bytes\n", total_size);
    printf("One element size: %zu bytes\n", element_size);
    printf("Number of elements: %zu\n", count);

    return 0;
}

On a typical system where sizeof(int) is 4: 

Total array size: 20 bytes
One element size: 4 bytes
Number of elements: 5
The number of elements can be calculated using sizeof(arr) / sizeof(arr[0]) only where arr is still an array object, not a function parameter that has been adjusted to a pointer.

9. One-Dimensional Arrays

A one-dimensional array stores elements in a single sequence.

Example: Read and Display Array Elements

#include <stdio.h>

int main(void)
{
    int n;
    int arr[100];

    printf("Enter number of elements: ");
    scanf("%d", &n);

    if (n < 1 || n > 100)
    {
        printf("Invalid array size\n");
        return 1;
    }

    printf("Enter %d elements:\n", n);

    for (int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    printf("Array elements: ");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}

Sample Input

Enter number of elements: 5
Enter 5 elements:
10 20 30 40 50

Sample Output

Array elements: 10 20 30 40 50

10. Two-Dimensional Arrays

A two-dimensional array represents data in rows and columns. It is commonly used for matrices and tabular data.

Declaration

int matrix[3][3];

Initialization

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Matrix Representation

Column 0 Column 1 Column 2
Row 0 1 2 3
Row 1 4 5 6

Accessing Elements

printf("%d", matrix[1][2]);
6

Row-Major Memory Representation

C stores multidimensional arrays in row-major order. This means the elements of each row are stored consecutively before the next row. 

1  2  3  4  5  6

Address Formula for a Two-Dimensional Array

Address of A[i][j] = Base Address + ((i × Number of Columns + j) × Element Size)

Example:

  • Base address = 1000
  • Number of columns = 3
  • Element size = 4 bytes
  • Element = A[1][2]

Address = 1000 + ((1 × 3 + 2) × 4)

Answer = 1020

11. C Program for Matrix Traversal

#include <stdio.h>

int main(void)
{
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    printf("Matrix elements:\n");

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}

12. Variable-Length Arrays (VLA)

C99 introduced variable-length arrays. Their dimensions can be determined at runtime when the program creates the array.

Example

#include <stdio.h>

int main(void)
{
    int n;

    printf("Enter array size: ");
    scanf("%d", &n);

    if (n < 1 || n > 1000)
    {
        printf("Invalid size\n");
        return 1;
    }

    int arr[n];

    for (int i = 0; i < n; i++)
    {
        arr[i] = (i + 1) * 10;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Enter array size: 4
10 20 30 40
VLA support is optional in C11 implementations. VLAs have automatic storage duration and are not the same as heap-allocated arrays. For large or resizable arrays, dynamic allocation is often more appropriate.

13. Passing Arrays to Functions

When an array is passed to a function, its parameter is adjusted to a pointer type. Therefore, the function must receive the array length separately when it needs to know the number of elements.

Example: Display Array Using a Function

#include <stdio.h>

void display_array(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int n = sizeof arr / sizeof arr[0];

    display_array(arr, n);

    return 0;
}
10 20 30 40 50

Important Interview Concept

void display(int arr[], int n);

In a function parameter declaration, int arr[] is adjusted to int *arr.

The function does not receive a separate copy of the entire array.

14. Array Operation Complexity

Operation Time Complexity Explanation
Access by index O(1) Direct indexing.
Update by index O(1) Direct assignment.
Linear search O(n) May inspect every element.
Traversal O(n) Visits each element.
Insertion at beginning O(n) Requires shifting elements.
Deletion at beginning O(n) Requires shifting elements.
Insertion at end O(1) When unused capacity is available.

These complexities assume a fixed-size array with sufficient capacity for insertion.

15. Common Array Mistakes

1. Accessing an Invalid Index

int arr[5];

arr[5] = 100;  /* Invalid access */

Valid indices are 0 through 4. Out-of-bounds access causes undefined behavior.

2. Using an Uninitialized Local Array

int arr[5];

printf("%d", arr[0]);

The element is uninitialized. Reading it this way is not valid.

3. Incorrect Loop Condition

for (int i = 0; i <= 5; i++)
{
    printf("%d ", arr[i]);
}

For an array of five elements, the condition should be i < 5, not i <= 5.

4. Assuming sizeof() Gives Array Length in a Function

void display(int arr[])
{
    printf("%zu", sizeof arr);
}

Here sizeof arr gives the size of the pointer parameter, not the original array.

16. Placement Interview Questions and Answers

Q1. What is an array?

An array is a collection of elements of the same declared type stored in contiguous memory locations.

Q2. What is the starting index of an array in C?

Zero.

Q3. What is the last valid index of an array of size N?

N-1.

Q4. Why are arrays stored in contiguous memory?

Contiguous storage allows the address of an element to be calculated directly using its index and element size.

Q5. What is the time complexity of accessing an array element?

O(1).

Q6. What happens when an array index is out of bounds?

The program has undefined behavior. C does not automatically perform array bounds checking.

Q7. What is the difference between an array and a linked list?

Arrays use contiguous storage and provide constant-time indexed access. Linked lists use separately allocated nodes connected through pointers and do not provide direct indexed access.

Q8. What is the relationship between arr[i] and *(arr+i)?

They are equivalent expressions for accessing the element at index i.

Q9. What is the difference between sizeof(arr) and sizeof(arr[0])?

In the array's declaration scope, sizeof(arr) gives the total array size in bytes, while sizeof(arr[0]) gives the size of one element.

Q10. What is row-major order?

It is the memory layout in which all elements of one row are stored consecutively before the next row.

Q11. Can an array size be changed after declaration?

An ordinary fixed-size array cannot be resized. A dynamically allocated array can be resized using realloc(), subject to allocation success.

Q12. What is a two-dimensional array?

It is an array organized using rows and columns. In C, a two-dimensional array is an array whose elements are themselves arrays.

Q13. Does an array passed to a function get copied?

No. The array parameter is adjusted to a pointer, so the function accesses the original array elements.

Q14. What is array-to-pointer decay?

It is the conversion of an array expression into a pointer to its first element in most expression contexts.

Q15. What is the difference between an array and a pointer?

An array is an object containing a sequence of elements. A pointer is a separate object that stores an address.

Q16. What is the time complexity of traversing an array?

O(n), where n is the number of elements.

Q17. What is the address of arr[i]?

Base address + i multiplied by the size of one array element.

Q18. What is a VLA?

A variable-length array is an array whose size is determined at runtime. VLA support is optional in C11.

Q19. Why is insertion in the middle of an array O(n)?

Elements may need to be shifted to make space for the new element.

Q20. Why are arrays important in DSA?

Arrays are fundamental to searching, sorting, hashing, dynamic programming, matrix operations and many other algorithms.
