2. What Is a Subarray?

A subarray is a contiguous sequence of elements taken from an array. The elements must occupy consecutive positions in the original array.

Example:

arr = {1, 2, 3}

Possible non-empty subarrays:

{1}
{1, 2}
{1, 2, 3}
{2}
{2, 3}
{3}
Important: The subarray {1, 3} is invalid because the elements are not adjacent in the original array.

4. Generate All Possible Subarrays

Use two loops to select the starting and ending indices. A third loop can print the elements of each selected subarray.

Algorithm

  1. Choose a starting index from 0 to n - 1.
  2. Choose an ending index from the starting index to n - 1.
  3. Print all elements between the two indices.
  4. Repeat until every possible subarray has been generated.

C Program

#include <stdio.h>

void printAllSubarrays(const int arr[], int size)
{
    for (int start = 0; start < size; start++)
    {
        for (int end = start; end < size; end++)
        {
            printf("{ ");

            for (int i = start; i <= end; i++)
            {
                printf("%d ", arr[i]);
            }

            printf("}\n");
        }
    }
}

int main(void)
{
    int arr[] = {1, 2, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    printAllSubarrays(arr, size);

    return 0;
}
Expected Output: 
{ 1 }
{ 1 2 }
{ 1 2 3 }
{ 2 }
{ 2 3 }
{ 3 }

Time Complexity: O(n³), including printing all elements.

Auxiliary Space: O(1), excluding output.

There are O(n²) subarrays, but printing every element takes O(n³) total time in the worst case.

5. Calculate the Sum of Every Subarray

A straightforward optimized generation method maintains a running sum. Each new ending position adds only one element to the previous sum.

C Program

#include <stdio.h>

void printSubarraySums(const int arr[], int size)
{
    for (int start = 0; start < size; start++)
    {
        long long sum = 0;

        for (int end = start; end < size; end++)
        {
            sum += arr[end];

            printf("Subarray [%d, %d] Sum = %lld\n",
                   start, end, sum);
        }
    }
}

int main(void)
{
    int arr[] = {1, 2, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    printSubarraySums(arr, size);

    return 0;
}
Expected Output: 
Subarray [0, 0] Sum = 1
Subarray [0, 1] Sum = 3
Subarray [0, 2] Sum = 6
Subarray [1, 1] Sum = 2
Subarray [1, 2] Sum = 5
Subarray [2, 2] Sum = 3

Time Complexity: O(n²)

Auxiliary Space: O(1)

6. Find Whether a Subarray Has a Given Sum

Given an array and a target value K, determine whether any non-empty contiguous subarray has a sum equal to K.

Example:

Array = {2, 4, 1, 3, 6}
K = 8

Subarray {4, 1, 3}
Sum = 4 + 1 + 3 = 8

Answer: Found

Approach: Running Sum

Generate subarrays and maintain their running sums. Stop when a sum equal to K is found. 

#include <stdio.h>

int hasSubarrayWithSum(const int arr[], int size, long long target)
{
    for (int start = 0; start < size; start++)
    {
        long long sum = 0;

        for (int end = start; end < size; end++)
        {
            sum += arr[end];

            if (sum == target)
            {
                printf("Subarray found from index %d to %d\n",
                       start, end);
                return 1;
            }
        }
    }

    return 0;
}

int main(void)
{
    int arr[] = {2, 4, 1, 3, 6};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long target = 8;

    if (hasSubarrayWithSum(arr, size, target))
    {
        printf("Target sum found\n");
    }
    else
    {
        printf("Target sum not found\n");
    }

    return 0;
}
Expected Output: 
Subarray found from index 1 to 3
Target sum found

Time Complexity: O(n²)

Auxiliary Space: O(1)

7. Count Subarrays With Sum Equal to K

Instead of checking whether at least one matching subarray exists, this problem asks for the total number of matching subarrays.

Example:

Array = {1, 2, 1, 2}
K = 3

Matching subarrays:
{1, 2}
{2, 1}
{1, 2}

Count = 3

Approach 1: Brute Force With Running Sum

#include <stdio.h>

long long countSubarraysWithSum(
    const int arr[], int size, long long target)
{
    long long count = 0;

    for (int start = 0; start < size; start++)
    {
        long long sum = 0;

        for (int end = start; end < size; end++)
        {
            sum += arr[end];

            if (sum == target)
            {
                count++;
            }
        }
    }

    return count;
}

int main(void)
{
    int arr[] = {1, 2, 1, 2};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long target = 3;

    printf("Number of matching subarrays: %lld\n",
           countSubarraysWithSum(arr, size, target));

    return 0;
}
Expected Output: 
Number of matching subarrays: 3

Time Complexity: O(n²)

Auxiliary Space: O(1)

Approach 2: Prefix Sum and Hashing

Let the current prefix sum be S. A previous prefix sum equal to S - K indicates that the elements between the two prefix positions have sum K. 

Required previous prefix sum = current prefix sum - K

A hash table stores the frequency of each previously encountered prefix sum. This can reduce expected processing time to O(n).

The complete hash-table implementation was introduced in the previous Prefix Sum lesson. The hashing chapter will develop collision handling, hash-table design and implementation in greater depth.

8. Find the Longest Subarray With Sum Equal to K

Given an integer array and a target K, find the maximum length of a contiguous subarray whose sum is exactly K.

Example:

Array = {1, -1, 5, -2, 3}
K = 3

One matching subarray:
{1, -1, 5, -2}

Sum = 3
Length = 4

Answer = 4

Brute-Force Approach

Generate all subarrays, maintain their running sums and update the maximum length whenever the sum equals K. 

#include <stdio.h>

int longestSubarrayWithSum(
    const int arr[], int size, long long target)
{
    int maximumLength = 0;

    for (int start = 0; start < size; start++)
    {
        long long sum = 0;

        for (int end = start; end < size; end++)
        {
            sum += arr[end];

            if (sum == target)
            {
                int length = end - start + 1;

                if (length > maximumLength)
                {
                    maximumLength = length;
                }
            }
        }
    }

    return maximumLength;
}

int main(void)
{
    int arr[] = {1, -1, 5, -2, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Longest subarray length: %d\n",
           longestSubarrayWithSum(arr, size, 3));

    return 0;
}
Expected Output: 
Longest subarray length: 4

Time Complexity: O(n²)

Auxiliary Space: O(1)

Optimization: A prefix-sum hash table can solve this problem in expected O(n) time. For the longest length, store the earliest index at which each prefix sum appears. Do not overwrite that earliest index with later occurrences.

9. Find a Subarray With Zero Sum

Determine whether any non-empty contiguous subarray has a sum equal to zero.

Example:

Array = {4, 2, -3, 1, 6}

Subarray = {2, -3, 1}

Sum = 0

Answer: Zero-sum subarray exists

C Program: Brute Force

#include <stdio.h>

int hasZeroSumSubarray(const int arr[], int size)
{
    for (int start = 0; start < size; start++)
    {
        long long sum = 0;

        for (int end = start; end < size; end++)
        {
            sum += arr[end];

            if (sum == 0)
            {
                printf("Zero-sum subarray: ");

                for (int i = start; i <= end; i++)
                {
                    printf("%d ", arr[i]);
                }

                printf("\n");
                return 1;
            }
        }
    }

    return 0;
}

int main(void)
{
    int arr[] = {4, 2, -3, 1, 6};
    int size = sizeof(arr) / sizeof(arr[0]);

    if (hasZeroSumSubarray(arr, size))
    {
        printf("Zero-sum subarray exists\n");
    }
    else
    {
        printf("No zero-sum subarray exists\n");
    }

    return 0;
}
Expected Output: 
Zero-sum subarray: 2 -3 1
Zero-sum subarray exists

Time Complexity: O(n²)

Auxiliary Space: O(1)

Optimization: If the same prefix sum occurs at two different positions, the elements between those positions have a sum of zero. A hash set can detect this in expected O(n) time.

10. Maximum Sum Subarray of Fixed Length K

Given an array and an integer K, find the maximum sum among all contiguous subarrays containing exactly K elements.

Example:

Array = {2, 1, 5, 1, 3, 2}
K = 3

Possible windows:
{2, 1, 5} = 8
{1, 5, 1} = 7
{5, 1, 3} = 9
{1, 3, 2} = 6

Maximum sum = 9

Approach: Sliding Window

Calculate the sum of the first K elements. Then remove the element leaving the window and add the new element entering the window. 

newWindowSum = oldWindowSum - outgoingElement + incomingElement
#include <stdio.h>

int maximumFixedWindowSum(
    const int arr[], int size, int k, long long *result)
{
    if (k <= 0 || k > size)
    {
        return 0;
    }

    long long windowSum = 0;

    for (int i = 0; i < k; i++)
    {
        windowSum += arr[i];
    }

    long long maximumSum = windowSum;

    for (int i = k; i < size; i++)
    {
        windowSum += arr[i] - arr[i - k];

        if (windowSum > maximumSum)
        {
            maximumSum = windowSum;
        }
    }

    *result = maximumSum;
    return 1;
}

int main(void)
{
    int arr[] = {2, 1, 5, 1, 3, 2};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long answer;

    if (maximumFixedWindowSum(arr, size, 3, &answer))
    {
        printf("Maximum sum of window: %lld\n", answer);
    }
    else
    {
        printf("Invalid window size\n");
    }

    return 0;
}
Expected Output: 
Maximum sum of window: 9

Time Complexity: O(n)

Auxiliary Space: O(1)

This technique also works when the array contains negative values because the window size is fixed.

11. Find the Minimum Length Subarray With Sum at Least K

Given an array of positive integers and a target K, find the minimum length of a contiguous subarray whose sum is greater than or equal to K.

Example:

Array = {2, 3, 1, 2, 4, 3}
K = 7

Shortest qualifying subarray:
{4, 3}

Sum = 7
Length = 2

Approach: Variable-Size Sliding Window

  1. Expand the right boundary and add elements to the sum.
  2. When the sum becomes at least K, update the minimum length.
  3. Move the left boundary forward while the condition remains satisfied.
  4. Return the shortest valid length.
#include <stdio.h>
#include <limits.h>

int minimumSubarrayLength(
    const int arr[], int size, long long target)
{
    int left = 0;
    int minimumLength = INT_MAX;
    long long sum = 0;

    for (int right = 0; right < size; right++)
    {
        sum += arr[right];

        while (sum >= target)
        {
            int length = right - left + 1;

            if (length < minimumLength)
            {
                minimumLength = length;
            }

            sum -= arr[left];
            left++;
        }
    }

    return minimumLength == INT_MAX ? 0 : minimumLength;
}

int main(void)
{
    int arr[] = {2, 3, 1, 2, 4, 3};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Minimum subarray length: %d\n",
           minimumSubarrayLength(arr, size, 7));

    return 0;
}
Expected Output: 
Minimum subarray length: 2

Time Complexity: O(n)

Auxiliary Space: O(1)

Important limitation: This sliding-window solution assumes all array elements are positive. It is not generally correct when negative values are allowed. For arbitrary signed integers, use prefix sums with an appropriate algorithm.

14. Common Mistakes

  • Confusing subarrays with subsequences.
  • Starting the ending-index loop before the starting index.
  • Recalculating every subarray sum from scratch unnecessarily.
  • Using int when cumulative sums may exceed its range.
  • Forgetting that subarrays must be non-empty unless the problem says otherwise.
  • Using sliding-window sum techniques with negative numbers without checking their assumptions.
  • Counting only one matching subarray when the question asks for the total count.
  • Overwriting the earliest prefix-sum index when finding the longest subarray.
  • Failing to handle K = 0.
  • Ignoring invalid input sizes.

16. Placement Interview Questions and Answers

Q1. What is a subarray?

A contiguous sequence of elements from an array.

Q2. How many non-empty subarrays exist in an array of size n?

n(n + 1) / 2.

Q3. What is the difference between a subarray and a subsequence?

A subarray must be contiguous, whereas a subsequence can skip elements.

Q4. How can all subarrays be generated?

Use two nested loops to select the starting and ending indices.

Q5. What is the complexity of generating all subarray boundaries?

O(n²).

Q6. Why does printing every subarray take O(n³) time?

There are O(n²) subarrays, and printing each can require up to O(n) operations.

Q7. How can all subarray sums be calculated in O(n²) time?

Maintain a running sum for each starting index and extend it one element at a time.

Q8. How do you count subarrays with sum K?

Use running sums in O(n²), or prefix sums with a frequency hash table for expected O(n).

Q9. What is the prefix-sum relationship used for target-sum problems?

If current prefix sum is S, look for a previous prefix sum equal to S - K.

Q10. How do you find the longest subarray with sum K?

Use prefix sums and store the earliest index for each prefix sum in a hash table.

Q11. How can a zero-sum subarray be detected?

Check whether a prefix sum repeats. A repeated prefix sum indicates a zero-sum segment between the occurrences.

Q12. Which approach is suitable for maximum sum of exactly K consecutive elements?

A fixed-size sliding window.

Q13. Can a sliding window be used with negative numbers?

Some fixed-size sliding windows can. However, common variable-size sum strategies rely on positivity or non-negativity assumptions.

Q14. What is the difference between Kadane's Algorithm and a general subarray sum query?

Kadane finds the maximum-sum contiguous subarray; general subarray-sum problems may ask for a target sum, count or length.

Q15. What is a zero-sum subarray?

A non-empty contiguous segment whose elements add up to zero.

Q16. What happens when K is zero in a target-sum problem?

The algorithm must correctly identify zero-sum subarrays, including repeated prefix sums and zero-valued elements.

Q17. What is the benefit of prefix sums?

They allow range sums to be calculated in O(1) after O(n) preprocessing.

Q18. What is the difference between fixed and variable sliding windows?

A fixed window maintains a specified length; a variable window expands and contracts according to a condition.

Q19. Why should long long be considered for subarray sums in C?

Because adding many integer elements may exceed the range of int.

Q20. Which data structure is commonly used to optimize target-sum subarray problems?

A hash table storing prefix sums and their frequencies or earliest indices.

20. Lesson Summary

Subarray problems are among the most important array-based coding-round topics. They test contiguous-range reasoning, nested loops, running sums, prefix sums, hashing and sliding-window techniques.

The correct approach depends on the problem constraints: use brute force to establish correctness, then optimize using the appropriate data structure or algorithm.
