Lesson 5: Sliding Window Technique

Learn how to solve subarray problems efficiently by maintaining a window and updating its information as it moves through an array.

1. Learning Objectives

  • Understand the sliding window technique.
  • Differentiate fixed-size and variable-size windows.
  • Calculate subarray sums efficiently.
  • Find the maximum sum of a fixed-size subarray.

  • Understand when sliding window is applicable.
  • Analyze time and space complexity.
  • Solve placement-oriented sliding window problems in C.

2. What Is the Sliding Window Technique?

Sliding window is an algorithmic technique used to process contiguous portions of an array or string. A window represents a range of consecutive elements.

Instead of calculating the result independently for every subarray, we maintain information about the current window and update it when the window moves.

Example: 
Array = {2, 1, 5, 1, 3, 2}
Window size = 3

Window 1: {2, 1, 5}
Window 2:    {1, 5, 1}
Window 3:       {5, 1, 3}
Window 4:          {1, 3, 2}

Why use sliding window?

  • Avoid recalculating overlapping subarrays.
  • Reduce repeated work.
  • Improve many O(n × k) solutions to O(n).
  • Efficiently process contiguous ranges.

3. Types of Sliding Window

Type 1: Fixed-Size Sliding Window

The window always contains a fixed number of elements. For example, finding the maximum sum of every subarray containing exactly three elements. 

Window size = k
Right pointer moves forward.
Leftmost element leaves the window.
New rightmost element enters the window.

Type 2: Variable-Size Sliding Window

The window size changes according to a condition. We generally expand the right boundary and shrink the left boundary when a condition is satisfied or violated. 

Expand window: right++
Shrink window: left++
Fixed-size windows are useful for problems involving exactly k consecutive elements. Variable-size windows are useful for problems involving the shortest or longest valid contiguous range, when the problem's condition supports this approach.

4. Maximum Sum of a Subarray of Size K

Given an array and an integer k, find the maximum sum among all contiguous subarrays of exactly k elements.

Example:

Array = {2, 1, 5, 1, 3, 2}
k = 3

Subarray sums:
2 + 1 + 5 = 8
1 + 5 + 1 = 7
5 + 1 + 3 = 9
1 + 3 + 2 = 6

Maximum sum = 9

Approach

  1. Calculate the sum of the first k elements.
  2. Store it as the current sum and maximum sum.
  3. Move the window one position forward.
  4. Subtract the element leaving the window.
  5. Add the element entering the window.
  6. Update the maximum sum.
#include <stdio.h>

int maxSubarraySum(const int arr[], int size, int k,
                   long long *result)
{
    if (k <= 0 || k > size)
    {
        return 0;
    }

    long long windowSum = 0;

    for (int i = 0; i < k; i++)
    {
        windowSum += arr[i];
    }

    long long maxSum = windowSum;

    for (int right = k; right < size; right++)
    {
        windowSum += arr[right];
        windowSum -= arr[right - k];

        if (windowSum > maxSum)
        {
            maxSum = windowSum;
        }
    }

    *result = maxSum;
    return 1;
}

int main(void)
{
    int arr[] = {2, 1, 5, 1, 3, 2};
    int size = sizeof(arr) / sizeof(arr[0]);
    int k = 3;

    long long result;

    if (maxSubarraySum(arr, size, k, &result))
    {
        printf("Maximum subarray sum: %lld\n", result);
    }
    else
    {
        printf("Invalid window size\n");
    }

    return 0;
}
Expected Output: 
Maximum subarray sum: 9

Dry Run

Time Complexity: O(n)

Auxiliary Space: O(1)

6. Average of Every Subarray of Size K

Find the average of each contiguous subarray containing exactly k elements. 

#include <stdio.h>

int main(void)
{
    int arr[] = {1, 3, 2, 6, -1, 4, 1, 8, 2};
    int size = sizeof(arr) / sizeof(arr[0]);
    int k = 5;

    if (k <= 0 || k > size)
    {
        printf("Invalid window size\n");
        return 0;
    }

    long long windowSum = 0;

    for (int i = 0; i < k; i++)
    {
        windowSum += arr[i];
    }

    printf("Window averages: ");

    printf("%.2f ", (double)windowSum / k);

    for (int right = k; right < size; right++)
    {
        windowSum += arr[right];
        windowSum -= arr[right - k];

        printf("%.2f ", (double)windowSum / k);
    }

    printf("\n");
    return 0;
}
Expected Output: 
Window averages: 2.20 2.80 2.40 3.60 2.80

Time Complexity: O(n)

Auxiliary Space: O(1)

7. Maximum Number in Every Window of Size K

Given an array, find the maximum element in each contiguous subarray of size k.

Example:

Array = {1, 3, -1, -3, 5, 3, 6, 7}
k = 3

Output = {3, 3, 5, 5, 6, 7}

A simple O(nk) approach checks every element in each window. A more efficient solution uses a deque (double-ended queue) to maintain candidate indices in decreasing order of values. 

#include <stdio.h>

void slidingWindowMaximum(const int arr[], int size, int k)
{
    if (k <= 0 || k > size)
    {
        printf("Invalid window size\n");
        return;
    }

    int deque[size];
    int front = 0;
    int back = -1;

    for (int i = 0; i < size; i++)
    {
        /* Remove indices outside the current window. */
        while (front <= back && deque[front] <= i - k)
        {
            front++;
        }

        /* Remove smaller or equal values from the back. */
        while (front <= back &&
               arr[deque[back]] <= arr[i])
        {
            back--;
        }

        deque[++back] = i;

        if (i >= k - 1)
        {
            printf("%d ", arr[deque[front]]);
        }
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {1, 3, -1, -3, 5, 3, 6, 7};
    int size = sizeof(arr) / sizeof(arr[0]);
    int k = 3;

    printf("Window maximums: ");
    slidingWindowMaximum(arr, size, k);

    return 0;
}
Expected Output: 
Window maximums: 3 3 5 5 6 7
Each index enters and leaves the deque at most once. Therefore, the total time complexity is O(n), not O(nk). The deque uses O(k) auxiliary space.

8. Variable-Size Window: Smallest Subarray With Sum at Least Target

Given an array of positive integers and a target value, find the minimum length of a contiguous subarray whose sum is greater than or equal to the target.

Example:

Array = {2, 3, 1, 2, 4, 3}
Target = 7

Smallest qualifying subarray = {4, 3}
Minimum length = 2

Approach

  1. Expand the window by adding the next element.
  2. While the window sum is at least the target, record its length.
  3. Remove the leftmost element and shrink the window.
  4. Continue until the array is fully processed.
#include <stdio.h>
#include <limits.h>

int minSubarrayLength(const int arr[], int size,
                      long long target)
{
    int left = 0;
    int minLength = INT_MAX;
    long long windowSum = 0;

    for (int right = 0; right < size; right++)
    {
        windowSum += arr[right];

        while (windowSum >= target)
        {
            int currentLength = right - left + 1;

            if (currentLength < minLength)
            {
                minLength = currentLength;
            }

            windowSum -= arr[left];
            left++;
        }
    }

    return (minLength == INT_MAX) ? 0 : minLength;
}

int main(void)
{
    int arr[] = {2, 3, 1, 2, 4, 3};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 7;

    int result = minSubarrayLength(arr, size, target);

    if (result == 0)
    {
        printf("No qualifying subarray found\n");
    }
    else
    {
        printf("Minimum subarray length: %d\n", result);
    }

    return 0;
}
Expected Output: 
Minimum subarray length: 2
Important restriction: This expand-and-shrink method relies on all array elements being positive (or, more generally, non-negative for this minimum-length formulation). With negative values, shrinking the window does not have the same predictable effect. Other techniques, such as prefix sums with a monotonic deque, may be needed.

Time Complexity: O(n)

Auxiliary Space: O(1)

9. Longest Subarray With Sum at Most K

For an array of non-negative integers, find the length of the longest contiguous subarray whose sum is at most k. 

#include <stdio.h>

int longestSubarrayAtMostK(const int arr[], int size, long long k)
{
    int left = 0;
    int maxLength = 0;
    long long windowSum = 0;

    for (int right = 0; right < size; right++)
    {
        windowSum += arr[right];

        while (windowSum > k && left <= right)
        {
            windowSum -= arr[left];
            left++;
        }

        int currentLength = right - left + 1;

        if (currentLength > maxLength)
        {
            maxLength = currentLength;
        }
    }

    return maxLength;
}

int main(void)
{
    int arr[] = {1, 2, 1, 0, 1, 1, 0};
    int size = sizeof(arr) / sizeof(arr[0]);
    int k = 4;

    printf("Longest valid subarray length: %d\n",
           longestSubarrayAtMostK(arr, size, k));

    return 0;
}
Expected Output: 
Longest valid subarray length: 5

Time Complexity: O(n)

Auxiliary Space: O(1)

This implementation assumes non-negative elements. Negative values can make the window sum decrease when expanding, so the usual shrinking condition is no longer sufficient.

10. Brute Force vs Sliding Window

Consider finding the maximum sum of a subarray of exactly k elements.

Approach Time Complexity Auxiliary Space
Brute force: recompute every window O(n × k) O(1)
Sliding window: update running sum O(n) O(1)
Interview tip: First explain the straightforward approach. Then identify overlapping work between consecutive windows and eliminate repeated calculations using a running sum.

11. When Should You Use Sliding Window?

Look for these problem characteristics:

  • The problem involves a contiguous subarray or substring.
  • The question asks for a maximum or minimum range result.
  • The window has a fixed length k.
  • The window can be expanded and shrunk while maintaining a useful condition.
  • Adjacent windows overlap significantly.
Sliding window is not automatically applicable to every subarray problem. The condition must support incremental updates and valid pointer movement. Negative numbers, for example, can invalidate common sum-based shrinking logic.

13. Common Mistakes

  • Not validating whether k is between 1 and the array size.
  • Adding the new element without removing the outgoing element.
  • Removing the wrong element from the running sum.
  • Updating the maximum or minimum before the window is complete.
  • Using an incorrect window-length calculation.
  • Applying a positive-number sliding window algorithm to arbitrary negative values.
  • Confusing a subarray with a subsequence.
  • Ignoring integer overflow in large sums.

14. Placement Interview Questions and Answers

Q1. What is the sliding window technique?

An algorithmic technique that maintains a contiguous range and updates its information as the range moves.

Q2. What are the two main types of sliding window?

Fixed-size sliding window and variable-size sliding window.

Q3. What is a fixed-size window?

A contiguous range containing exactly k elements throughout the algorithm.

Q4. What is a variable-size window?

A range whose length changes according to a problem-specific condition.

Q5. Why is sliding window efficient?

It avoids recalculating information that consecutive overlapping windows share.

Q6. What is the time complexity of fixed-size maximum-sum sliding window?

O(n).

Q7. What is the auxiliary space complexity of a running-sum window?

O(1).

Q8. What happens when a fixed-size window moves one position forward?

The outgoing element is removed and the incoming element is added.

Q9. What is a subarray?

A contiguous sequence of elements from an array.

Q10. Is a subsequence necessarily contiguous?

No. A subsequence preserves relative order but may skip elements.

Q11. Why can negative values cause problems in sum-based variable windows?

Adding or removing a negative value can change the sum in ways that invalidate the usual expand-and-shrink decisions.

Q12. What data structure is commonly used for maximum in every window?

A deque that maintains candidate indices in decreasing value order.

Q13. What is the complexity of maximum in every window using a deque?

O(n) time and O(k) auxiliary space.

Q14. What is a running sum?

A sum maintained and updated as elements enter or leave the window.

Q15. How can you find the minimum-length subarray with sum at least a target?

For positive elements, expand the right boundary and shrink the left boundary while the sum satisfies the target.

Q16. Can sliding window solve string problems?

Yes. It is widely used for substring length, frequency and uniqueness problems.

Q17. What is the difference between two pointers and sliding window?

Sliding window is a specialized use of pointer or index movement that maintains a contiguous range and its associated state.

Q18. What should be checked before processing a fixed-size window?

Validate that k is positive and does not exceed the array size.

Q19. Why should large subarray sums use long long in C?

To reduce the risk of signed integer overflow when the sum exceeds the range of int.

Q20. What is the main interview optimization in sliding window problems?

Replace repeated range calculations with incremental updates as the window moves.

18. Lesson Summary

Sliding window is an important problem-solving pattern for contiguous subarray and substring problems. Fixed-size windows maintain a constant number of elements, while variable-size windows expand or shrink according to a condition.

Efficient implementations often achieve O(n) time by updating the current window instead of recalculating it from scratch. Understanding the input restrictions is essential when choosing a valid window-shrinking strategy.
