Lesson 7: Kadane's Algorithm and Maximum Subarray

Learn to find the maximum sum of a contiguous subarray efficiently using Kadane's Algorithm in C.

1. Learning Objectives

  • Understand the maximum subarray problem.
  • Compare brute-force and optimized approaches.
  • Implement Kadane's Algorithm using C11.
  • Handle arrays containing negative numbers.
  • Find the actual subarray, not just its sum.
  • Understand circular maximum subarray sum.
  • Solve common maximum-subarray interview variations.
  • Analyze time and space complexity.

2. What Is a Subarray?

A subarray is a contiguous sequence of elements taken from an array. The relative order of elements is preserved, and no element between the selected positions can be skipped.

Example:

Array = {2, -3, 4, -1, 2}

Valid subarrays:
{2}
{2, -3}
{4, -1}
{4, -1, 2}
{-3, 4, -1}
Important distinction: A subarray must be contiguous. A subsequence can skip elements while preserving their relative order.

3. Maximum Subarray Sum Problem

Given an integer array, find the contiguous subarray having the largest possible sum.

Example: 
Input:
arr = {-2, 1, -3, 4, -1, 2, 1, -5, 4}

Maximum subarray:
{4, -1, 2, 1}

Maximum sum:
4 + (-1) + 2 + 1 = 6

This is a classic placement problem and is commonly associated with Kadane's Algorithm.

4. Approach 1: Brute Force

The brute-force method generates every possible non-empty subarray and calculates its sum.

Algorithm

  1. Choose a starting index.
  2. Extend the subarray to each possible ending index.
  3. Maintain the running sum.
  4. Update the maximum sum whenever a larger sum is found.
#include <stdio.h>

long long maximumSubarraySum(const int arr[], int size)
{
    long long maximum = arr[0];

    for (int start = 0; start < size; start++)
    {
        long long currentSum = 0;

        for (int end = start; end < size; end++)
        {
            currentSum += arr[end];

            if (currentSum > maximum)
            {
                maximum = currentSum;
            }
        }
    }

    return maximum;
}

int main(void)
{
    int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Maximum subarray sum: %lld\n",
           maximumSubarraySum(arr, size));

    return 0;
}
Expected Output: 
Maximum subarray sum: 6

Time Complexity: O(n²)

Auxiliary Space: O(1)

This implementation is better than a three-loop brute-force approach because it maintains a running sum instead of recalculating each subarray from the beginning.

5. Approach 2: Kadane's Algorithm

Kadane's Algorithm solves the maximum subarray sum problem in linear time by maintaining a running subarray sum.

Core Idea

At each index, make one of two choices:

  • Extend the previous subarray by adding the current element.
  • Start a new subarray from the current element.

The recurrence relation is:

currentSum = max(arr[i], currentSum + arr[i])

maximumSum = max(maximumSum, currentSum)
Key observation: If the previous running sum is negative, including it can only reduce the sum of a subarray starting at the current position. Therefore, start a new subarray.

7. C Program: Kadane's Algorithm

#include <stdio.h>

long long kadane(const int arr[], int size)
{
    long long currentSum = arr[0];
    long long maximumSum = arr[0];

    for (int i = 1; i < size; i++)
    {
        if (currentSum + arr[i] > arr[i])
        {
            currentSum += arr[i];
        }
        else
        {
            currentSum = arr[i];
        }

        if (currentSum > maximumSum)
        {
            maximumSum = currentSum;
        }
    }

    return maximumSum;
}

int main(void)
{
    int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Maximum subarray sum: %lld\n",
           kadane(arr, size));

    return 0;
}
Expected Output: 
Maximum subarray sum: 6

Time Complexity: O(n)

Auxiliary Space: O(1)

8. Find the Actual Maximum Subarray

Some interview questions ask for the maximum sum as well as the starting and ending indices of the subarray.

We maintain three additional variables:

  • tempStart: Possible starting index of the current subarray.
  • start: Final starting index of the best subarray.
  • end: Final ending index of the best subarray.
#include <stdio.h>

void kadaneWithIndices(const int arr[], int size)
{
    long long currentSum = arr[0];
    long long maximumSum = arr[0];

    int start = 0;
    int end = 0;
    int tempStart = 0;

    for (int i = 1; i < size; i++)
    {
        if (arr[i] > currentSum + arr[i])
        {
            currentSum = arr[i];
            tempStart = i;
        }
        else
        {
            currentSum += arr[i];
        }

        if (currentSum > maximumSum)
        {
            maximumSum = currentSum;
            start = tempStart;
            end = i;
        }
    }

    printf("Maximum sum: %lld\n", maximumSum);
    printf("Starting index: %d\n", start);
    printf("Ending index: %d\n", end);

    printf("Subarray: ");

    for (int i = start; i <= end; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int size = sizeof(arr) / sizeof(arr[0]);

    kadaneWithIndices(arr, size);

    return 0;
}
Expected Output: 
Maximum sum: 6
Starting index: 3
Ending index: 6
Subarray: 4 -1 2 1

Time Complexity: O(n)

Auxiliary Space: O(1)

9. Important Edge Case: All Negative Numbers

Consider:

arr = {-8, -3, -6, -2, -5, -4}

The maximum subarray is the single element {-2}. Therefore, the maximum sum is -2.

Common interview trap: Do not initialize maximumSum to zero if the problem requires a non-empty subarray. Otherwise, an all-negative array incorrectly returns zero. 
#include <stdio.h>

int main(void)
{
    int arr[] = {-8, -3, -6, -2, -5, -4};
    int size = sizeof(arr) / sizeof(arr[0]);

    long long currentSum = arr[0];
    long long maximumSum = arr[0];

    for (int i = 1; i < size; i++)
    {
        if (currentSum + arr[i] > arr[i])
        {
            currentSum += arr[i];
        }
        else
        {
            currentSum = arr[i];
        }

        if (currentSum > maximumSum)
        {
            maximumSum = currentSum;
        }
    }

    printf("Maximum sum: %lld\n", maximumSum);

    return 0;
}
Expected Output: 
Maximum sum: -2

10. Maximum Circular Subarray Sum

In a circular array, the last element is considered adjacent to the first element. A maximum subarray can therefore wrap around the end of the array.

Example:

Array = {5, -3, 5}

Normal maximum subarray sum = 7
Circular maximum subarray sum = 10

Approach

There are two possibilities:

  1. The maximum subarray does not wrap around. Use Kadane's Algorithm.
  2. The maximum subarray wraps around. Subtract the minimum subarray sum from the total array sum.

Formula:

circularMaximum = totalSum - minimumSubarraySum

answer = max(normalMaximum, circularMaximum)
If all elements are negative, the circular formula must not be used as the answer because it would produce zero by removing the entire array. Return the normal Kadane result in that case.

C Program

#include <stdio.h>

long long maxValue(long long a, long long b)
{
    return (a > b) ? a : b;
}

long long minValue(long long a, long long b)
{
    return (a < b) ? a : b;
}

long long maximumCircularSubarray(const int arr[], int size)
{
    long long totalSum = arr[0];

    long long maxEnding = arr[0];
    long long maxSum = arr[0];

    long long minEnding = arr[0];
    long long minSum = arr[0];

    for (int i = 1; i < size; i++)
    {
        totalSum += arr[i];

        maxEnding = maxValue(arr[i], maxEnding + arr[i]);
        maxSum = maxValue(maxSum, maxEnding);

        minEnding = minValue(arr[i], minEnding + arr[i]);
        minSum = minValue(minSum, minEnding);
    }

    if (maxSum < 0)
    {
        return maxSum;
    }

    long long circularSum = totalSum - minSum;

    return maxValue(maxSum, circularSum);
}

int main(void)
{
    int arr[] = {5, -3, 5};
    int size = sizeof(arr) / sizeof(arr[0]);

    printf("Maximum circular subarray sum: %lld\n",
           maximumCircularSubarray(arr, size));

    return 0;
}
Expected Output: 
Maximum circular subarray sum: 10

Time Complexity: O(n)

Auxiliary Space: O(1)

13. Applications of Kadane's Algorithm

  • Maximum contiguous subarray sum.
  • Maximum circular subarray sum.
  • Maximum profit-like cumulative gain problems.
  • Maximum sum submatrix after reducing dimensions to a one-dimensional array.
  • Finding the best contiguous segment in a sequence.
  • Problems involving maximum cumulative performance or score.

14. Common Mistakes

  • Initializing maximumSum to zero when a non-empty subarray is required.
  • Not considering all-negative arrays.
  • Confusing a subarray with a subsequence.
  • Updating the maximum sum before updating the current sum.
  • Incorrectly tracking starting and ending indices.
  • Using int when the cumulative sum can exceed its range.
  • Applying the circular formula to an all-negative array without a special case.
  • Ignoring empty-array input when designing a reusable function.

16. Placement Interview Questions and Answers

Q1. What is Kadane's Algorithm?

An efficient dynamic programming approach for finding the maximum sum of a non-empty contiguous subarray in O(n) time.

Q2. What is the maximum subarray problem?

Find a contiguous, non-empty section of an array whose sum is maximum.

Q3. What is the time complexity of Kadane's Algorithm?

O(n), because the array is traversed once.

Q4. What is its auxiliary space complexity?

O(1), because only a fixed number of variables are maintained.

Q5. Can Kadane's Algorithm handle negative numbers?

Yes. Correct initialization with the first element allows it to handle negative values.

Q6. Why should maximumSum not be initialized to zero?

Because an all-negative array must return its largest negative element when the subarray must be non-empty.

Q7. What is the main recurrence relation?

currentSum = max(arr[i], currentSum + arr[i]).

Q8. What is the difference between Kadane and brute force?

Brute force checks all possible subarrays, whereas Kadane maintains an optimal running sum in one traversal.

Q9. Can Kadane's Algorithm find the actual subarray?

Yes. Track the temporary starting index and the best starting and ending indices.

Q10. What is a circular subarray?

A contiguous section that may wrap from the end of an array to its beginning.

Q11. How is maximum circular subarray sum calculated?

Compare the normal maximum subarray sum with total array sum minus the minimum subarray sum, handling all-negative arrays separately.

Q12. Why is the minimum subarray sum needed for the circular problem?

Removing the minimum-sum segment leaves the maximum-sum circular segment.

Q13. What is the difference between subarray and subsequence?

A subarray is contiguous; a subsequence need not be contiguous.

Q14. Is Kadane's Algorithm a dynamic programming algorithm?

Yes. It uses an optimal substructure and retains only the necessary previous state.

Q15. Can Kadane's Algorithm be used for a two-dimensional matrix?

Yes. Fix pairs of rows or columns, compress the values into a one-dimensional array, and apply Kadane's Algorithm.

Q16. What happens if the array contains only one element?

The answer is that element itself.

Q17. Why is a running sum reset?

When starting a new subarray at the current element gives a larger sum than extending the previous subarray.

Q18. What is the difference between maximum prefix sum and maximum subarray sum?

A maximum prefix must start at index zero, while a maximum subarray can start at any index.

Q19. Does Kadane's Algorithm require a sorted array?

No. It works on unsorted arrays.

Q20. Which important variations should be practiced?

Maximum circular subarray, index tracking, maximum sum submatrix, and maximum subarray under additional constraints.
