2. What Is Array Rotation?

Array rotation means shifting the elements of an array circularly by a specified number of positions. Elements that move beyond one end reappear at the other end.

Left Rotation

Original:       10 20 30 40 50
Left rotate 1:  20 30 40 50 10
Left rotate 2:  30 40 50 10 20

Right Rotation

Original:        10 20 30 40 50
Right rotate 1:  50 10 20 30 40
Right rotate 2:  40 50 10 20 30
Important: Rotation preserves the relative order of elements. It changes their positions but does not remove any elements.

3. Normalize the Number of Rotations

If an array contains n elements, rotating it by n positions produces the original array. Therefore, rotations can be reduced using the modulo operator. 

effectiveRotations = k % n

Example:

n = 5
k = 12

effectiveRotations = 12 % 5 = 2
Check that n is greater than zero before performing k % n. Also normalize negative rotation counts if the input permits them.

4. Left Rotation Using a Temporary Array

Store the first k elements temporarily, shift the remaining elements to the left, and copy the stored elements to the end.

Algorithm

  1. Normalize k using k % n.
  2. Copy the first k elements into a temporary array.
  3. Shift the remaining elements k positions left.
  4. Copy the temporary elements to the last k positions.

C Program

#include <stdio.h>

void leftRotate(int arr[], int n, int k)
{
    if (n <= 0)
        return;

    k %= n;

    if (k == 0)
        return;

    int temp[k];

    for (int i = 0; i < k; i++)
        temp[i] = arr[i];

    for (int i = k; i < n; i++)
        arr[i - k] = arr[i];

    for (int i = 0; i < k; i++)
        arr[n - k + i] = temp[i];
}

void printArray(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);

    leftRotate(arr, n, 2);

    printArray(arr, n);

    return 0;
}
Expected Output: 
30 40 50 10 20

Time Complexity: O(n)

Auxiliary Space: O(k)

This implementation uses a C variable-length array (VLA). It is supported by many C11 compilers, although VLA support is optional in C11.

5. Right Rotation Using a Temporary Array

For right rotation, store the last k elements, shift the remaining elements right, and place the stored elements at the beginning. 

#include <stdio.h>

void rightRotate(int arr[], int n, int k)
{
    if (n <= 0)
        return;

    k %= n;

    if (k == 0)
        return;

    int temp[k];

    for (int i = 0; i < k; i++)
        temp[i] = arr[n - k + i];

    for (int i = n - k - 1; i >= 0; i--)
        arr[i + k] = arr[i];

    for (int i = 0; i < k; i++)
        arr[i] = temp[i];
}

void printArray(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);

    rightRotate(arr, n, 2);

    printArray(arr, n);

    return 0;
}
Expected Output: 
40 50 10 20 30

Time Complexity: O(n)

Auxiliary Space: O(k)

6. Array Rotation Using the Reversal Algorithm

The reversal algorithm rotates an array using three reversals. It is a highly important placement technique because it requires constant auxiliary space.

Left Rotation Example

Original:
10 20 30 40 50

Reverse first k = 2 elements:
20 10 30 40 50

Reverse remaining elements:
20 10 50 40 30

Reverse the entire array:
30 40 50 10 20

Algorithm

  1. Reverse the first k elements.
  2. Reverse the remaining n-k elements.
  3. Reverse the entire array.

C Program: Left Rotation

#include <stdio.h>

void reverse(int arr[], int left, int right)
{
    while (left < right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}

void leftRotate(int arr[], int n, int k)
{
    if (n <= 0)
        return;

    k %= n;

    if (k == 0)
        return;

    reverse(arr, 0, k - 1);
    reverse(arr, k, n - 1);
    reverse(arr, 0, n - 1);
}

void printArray(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);

    leftRotate(arr, n, 2);

    printArray(arr, n);

    return 0;
}
Expected Output: 
30 40 50 10 20

Time Complexity: O(n)

Auxiliary Space: O(1)

Right Rotation Using Reversal

For right rotation, reverse these three sections:

  1. First n-k elements.
  2. Last k elements.
  3. The entire array.
#include <stdio.h>

void reverse(int arr[], int left, int right)
{
    while (left < right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}

void rightRotate(int arr[], int n, int k)
{
    if (n <= 0)
        return;

    k %= n;

    if (k == 0)
        return;

    reverse(arr, 0, n - k - 1);
    reverse(arr, n - k, n - 1);
    reverse(arr, 0, n - 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);

    rightRotate(arr, n, 2);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Expected Output: 
40 50 10 20 30

Time Complexity: O(n)

Auxiliary Space: O(1)

7. Move All Zeroes to the End

Given an array, move all zeroes to the end while maintaining the relative order of non-zero elements.

Example:

Input:
0 1 0 3 12

Output:
1 3 12 0 0

Approach: Two Pointers

Maintain a position that represents where the next non-zero element should be placed. Traverse the array and copy each non-zero element to that position. Finally, fill the remaining positions with zeroes. 

#include <stdio.h>

void moveZeroes(int arr[], int n)
{
    int position = 0;

    for (int i = 0; i < n; i++)
    {
        if (arr[i] != 0)
        {
            arr[position] = arr[i];
            position++;
        }
    }

    while (position < n)
    {
        arr[position] = 0;
        position++;
    }
}

int main(void)
{
    int arr[] = {0, 1, 0, 3, 12};
    int n = sizeof(arr) / sizeof(arr[0]);

    moveZeroes(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Expected Output: 
1 3 12 0 0

Time Complexity: O(n)

Auxiliary Space: O(1)

Stability: The relative order of non-zero elements is preserved.

8. Separate Even and Odd Numbers

Rearrange an array so that even numbers appear before odd numbers.

Example:

Input:
1 2 3 4 5 6

One valid output:
6 2 4 3 5 1

This version uses two pointers moving inward from opposite ends. It is an in-place partitioning approach. It does not preserve the original order within each group. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void separateEvenOdd(int arr[], int n)
{
    int left = 0;
    int right = n - 1;

    while (left < right)
    {
        while (left < right && arr[left] % 2 == 0)
            left++;

        while (left < right && arr[right] % 2 != 0)
            right--;

        if (left < right)
        {
            swap(&arr[left], &arr[right]);
            left++;
            right--;
        }
    }
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5, 6};
    int n = sizeof(arr) / sizeof(arr[0]);

    separateEvenOdd(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
One Possible Output: 
6 2 4 3 5 1

Time Complexity: O(n)

Auxiliary Space: O(1)

9. Rearrange Positive and Negative Numbers

Rearrange an array so that negative numbers appear before non-negative numbers.

Example:

Input:
-1 2 -3 4 -5 6

One possible output:
-1 -5 -3 4 2 6

In-Place Partitioning

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void rearrangeNegativeFirst(int arr[], int n)
{
    int left = 0;
    int right = n - 1;

    while (left < right)
    {
        while (left < right && arr[left] < 0)
            left++;

        while (left < right && arr[right] >= 0)
            right--;

        if (left < right)
        {
            swap(&arr[left], &arr[right]);
            left++;
            right--;
        }
    }
}

int main(void)
{
    int arr[] = {-1, 2, -3, 4, -5, 6};
    int n = sizeof(arr) / sizeof(arr[0]);

    rearrangeNegativeFirst(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
One Possible Output: 
-1 -5 -3 4 2 6

Time Complexity: O(n)

Auxiliary Space: O(1)

This is an unstable partition. If a problem requires relative order to be preserved, use a stable rearrangement approach, which may require additional storage or more complex in-place operations.

10. Sort an Array of 0s, 1s and 2s

Given an array containing only 0, 1 and 2, sort it without using a general-purpose sorting algorithm.

Example:

Input:
2 0 2 1 1 0

Output:
0 0 1 1 2 2

Dutch National Flag Algorithm

Maintain three regions:

  • Low: positions containing zeroes.
  • Middle: positions being examined.
  • High: positions containing twos.
#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void sort012(int arr[], int n)
{
    int low = 0;
    int mid = 0;
    int high = n - 1;

    while (mid <= high)
    {
        if (arr[mid] == 0)
        {
            swap(&arr[low], &arr[mid]);
            low++;
            mid++;
        }
        else if (arr[mid] == 1)
        {
            mid++;
        }
        else if (arr[mid] == 2)
        {
            swap(&arr[mid], &arr[high]);
            high--;
        }
        else
        {
            /* Input is outside the required 0, 1, 2 domain. */
            return;
        }
    }
}

int main(void)
{
    int arr[] = {2, 0, 2, 1, 1, 0};
    int n = sizeof(arr) / sizeof(arr[0]);

    sort012(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Expected Output: 
0 0 1 1 2 2

Time Complexity: O(n)

Auxiliary Space: O(1)

The algorithm assumes every input element is 0, 1 or 2. Its three-way partitioning technique is a common technical-interview question.

11. Rearrange Array in Alternating Positive and Negative Order

A common interview variation asks for alternating positive and negative values.

Example:

Input:
1 2 -3 -4 5 -6

One possible alternating output:
1 -3 2 -4 5 -6
Interview questions differ on whether the first element must be positive, whether order must be preserved, and what to do when positive and negative counts differ. Always clarify these conditions before implementing.

Stable Rearrangement Using an Auxiliary Array

This implementation places positive elements first in their original order, followed by negative elements in their original order, alternating while both groups have elements. 

#include <stdio.h>
#include <stdlib.h>

void rearrangeAlternating(const int arr[], int n, int result[])
{
    int *positive = malloc((size_t)n * sizeof(int));
    int *negative = malloc((size_t)n * sizeof(int));

    if (positive == NULL || negative == NULL)
    {
        free(positive);
        free(negative);
        return;
    }

    int pCount = 0;
    int nCount = 0;

    for (int i = 0; i < n; i++)
    {
        if (arr[i] >= 0)
            positive[pCount++] = arr[i];
        else
            negative[nCount++] = arr[i];
    }

    int p = 0;
    int q = 0;
    int index = 0;

    while (p < pCount && q < nCount)
    {
        result[index++] = positive[p++];
        result[index++] = negative[q++];
    }

    while (p < pCount)
        result[index++] = positive[p++];

    while (q < nCount)
        result[index++] = negative[q++];

    free(positive);
    free(negative);
}

int main(void)
{
    int arr[] = {1, 2, -3, -4, 5, -6};
    int n = sizeof(arr) / sizeof(arr[0]);
    int result[6];

    rearrangeAlternating(arr, n, result);

    for (int i = 0; i < n; i++)
        printf("%d ", result[i]);

    printf("\n");

    return 0;
}
Expected Output: 
1 -3 2 -4 5 -6

Time Complexity: O(n)

Auxiliary Space: O(n)

Zero is treated as non-negative in this implementation. The input array remains unchanged, and the output array must have capacity for n elements.

14. Common Mistakes

  • Forgetting to reduce k using k % n.
  • Performing modulo when n is zero.
  • Using the wrong reversal boundaries.
  • Confusing left rotation with right rotation.
  • Overwriting elements before they are moved.
  • Using an extra array when an in-place solution is required.
  • Assuming an unstable partition preserves order.
  • Forgetting to handle arrays containing only zeroes or only non-zeroes.
  • Not clarifying the treatment of zero in positive/negative rearrangement.
  • Ignoring the input constraints of the Dutch National Flag algorithm.

15. Placement Interview Questions and Answers

Q1. What is array rotation?

Array rotation circularly shifts elements by a specified number of positions.

Q2. What is the difference between left and right rotation?

Left rotation moves elements toward lower indices; right rotation moves them toward higher indices.

Q3. Why do we use k % n?

Because rotating an array by n positions produces the original array.

Q4. What is the reversal algorithm?

It performs three reversals to rotate an array in O(n) time and O(1) auxiliary space.

Q5. How many reversals are required for left rotation?

Three: reverse the first k elements, reverse the remaining elements, then reverse the entire array.

Q6. How can right rotation be performed using reversal?

Reverse the first n-k elements, reverse the last k elements, and reverse the entire array.

Q7. What is an in-place algorithm?

An algorithm that modifies the original data structure without requiring an additional data structure proportional to the input size.

Q8. How can zeroes be moved to the end?

Use a write pointer to place non-zero elements first, then fill remaining positions with zeroes.

Q9. Does moving zeroes to the end preserve order?

Yes, the write-pointer solution preserves the relative order of non-zero elements.

Q10. What is stable partitioning?

A partitioning operation that preserves the relative order of elements within each resulting group.

Q11. What is unstable partitioning?

It separates elements according to a condition without guaranteeing their original relative order.

Q12. What is the Dutch National Flag algorithm?

A three-pointer partitioning algorithm that sorts arrays containing 0, 1 and 2 in one pass.

Q13. What is its time complexity?

O(n), because each element is processed a constant number of times.

Q14. How can even and odd numbers be separated in-place?

Use two pointers from opposite ends and swap misplaced elements.

Q15. Can negative and positive numbers be rearranged in O(n) time?

Yes. An in-place partition can do it in O(n) time and O(1) auxiliary space, but it may not preserve order.

Q16. What is the difference between rotation and reversal?

Rotation circularly shifts positions; reversal changes the order of elements.

Q17. What happens when k is zero?

The array remains unchanged.

Q18. What happens when k is equal to n?

The array remains unchanged because k % n equals zero.

Q19. Which technique is useful for partitioning problems?

Two pointers, including the opposite-direction and three-pointer approaches.

Q20. Why is the reversal algorithm preferred in many placement problems?

It achieves linear time and constant auxiliary space without requiring a temporary array.
