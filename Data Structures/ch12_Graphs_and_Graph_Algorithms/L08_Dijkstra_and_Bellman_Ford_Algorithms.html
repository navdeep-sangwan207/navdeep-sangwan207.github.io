2. What Is a Weighted Graph?

A weighted graph is a graph in which every edge has an associated numerical value called a weight or cost. 

       4
  0 ------- 1
  |         |
  | 2       | 5
  |         |
  2 ------- 3
       1

Example edge weights:

  • 0 → 1 has weight 4.
  • 0 → 2 has weight 2.
  • 2 → 3 has weight 1.
  • 1 → 3 has weight 5.

A shortest path is a path whose total edge weight is minimum among all available paths between two vertices.

Shortest path does not necessarily mean the path containing the fewest edges. It means the path having the minimum total weight.

3. Shortest-Path Problem

Given a weighted graph and a source vertex, find the minimum distance from the source to every other vertex.

Example

0 --4--> 1
|        |
2        5
|        |
v        v
2 --1--> 3

Starting from vertex 0:

Destination Shortest Path Minimum Cost
0 0 0
1 0 → 1 4
2 0 → 2 2
3 0 → 2 → 3 3

4. Edge Relaxation

Relaxation is the central operation used by many shortest-path algorithms.

Suppose there is an edge from u to v with weight w. If reaching v through u produces a shorter distance, update the distance of v.

Relaxation condition:

if (dist[u] + weight < dist[v])

    dist[v] = dist[u] + weight;

Example:

dist[0] = 0
dist[1] = 10

Edge: 0 → 1
Weight = 4

New possible distance:

dist[0] + 4 = 0 + 4 = 4

Since 4 is less than 10:

dist[1] = 4
Relaxation improves a known distance when a shorter route is discovered.

5. Dijkstra's Algorithm

Dijkstra's algorithm finds the shortest distances from one source vertex to all other vertices in a weighted graph with non-negative edge weights.

Core Idea: Greedy Strategy

At every step, select the unvisited vertex having the smallest currently known distance from the source.

Algorithm Steps

  1. Initialize all distances to infinity.
  2. Set the source distance to zero.
  3. Select the unvisited vertex with the smallest distance.
  4. Mark it as visited.
  5. Relax all outgoing edges from that vertex.
  6. Repeat until all reachable vertices are processed.

Pseudocode

for every vertex:

    dist[vertex] = INFINITY
    visited[vertex] = false

dist[source] = 0

repeat V times:

    u = unvisited vertex with minimum distance

    if no reachable unvisited vertex exists:
        break

    visited[u] = true

    for every neighbor v of u:

        if not visited[v] and
           dist[u] + weight[u][v] < dist[v]:

            dist[v] = dist[u] + weight[u][v]

7. Complete C11 Program: Dijkstra Using Adjacency Matrix

This implementation uses a simple linear search to select the unvisited vertex with the smallest distance. 

#include <stdio.h>
#include <limits.h>

#define V 5
#define INF (LLONG_MAX / 4)

int minDistance(long long dist[V], int visited[V])
{
    long long minimum = INF;
    int minIndex = -1;
    int i;

    for (i = 0; i < V; i++)
    {
        if (!visited[i] && dist[i] < minimum)
        {
            minimum = dist[i];
            minIndex = i;
        }
    }

    return minIndex;
}

void dijkstra(int graph[V][V], int source)
{
    long long dist[V];
    int visited[V] = {0};
    int parent[V];
    int count, i, u, v;

    for (i = 0; i < V; i++)
    {
        dist[i] = INF;
        parent[i] = -1;
    }

    dist[source] = 0;

    for (count = 0; count < V; count++)
    {
        u = minDistance(dist, visited);

        if (u == -1)
        {
            break;
        }

        visited[u] = 1;

        for (v = 0; v < V; v++)
        {
            if (graph[u][v] > 0 &&
                !visited[v] &&
                dist[u] != INF &&
                dist[u] + graph[u][v] < dist[v])
            {
                dist[v] = dist[u] + graph[u][v];
                parent[v] = u;
            }
        }
    }

    printf("Shortest distances from source %d:\n", source);

    for (i = 0; i < V; i++)
    {
        if (dist[i] == INF)
        {
            printf("Vertex %d: Unreachable\n", i);
        }
        else
        {
            printf("Vertex %d: %lld\n", i, dist[i]);
        }
    }

    printf("\nParents:\n");

    for (i = 0; i < V; i++)
    {
        printf("Parent of %d: %d\n", i, parent[i]);
    }
}

int main(void)
{
    int graph[V][V] = {0};

    graph[0][1] = 4;
    graph[0][2] = 2;
    graph[2][1] = 1;
    graph[2][3] = 3;
    graph[1][3] = 2;
    graph[3][4] = 2;

    dijkstra(graph, 0);

    return 0;
}

Expected Output

Vertex 1: 3
Vertex 2: 2
Vertex 3: 5
Vertex 4: 7

Parents:
Parent of 0: -1
Parent of 1: 2
Parent of 2: 0
Parent of 3: 1
Parent of 4: 3
This matrix implementation uses 0 to represent no edge, so it cannot represent a zero-weight edge. It also assumes non-negative weights. For general graphs, an adjacency list with an explicit edge structure is more flexible.

8. Reconstructing the Shortest Path

The parent array stores the previous vertex on the shortest path to each destination.

For the previous example:

parent[4] = 3
parent[3] = 1
parent[1] = 2
parent[2] = 0
parent[0] = -1

Starting at vertex 4 and following parent links gives: 

4 ← 3 ← 1 ← 2 ← 0

Reverse the sequence:

0 → 2 → 1 → 3 → 4

Total cost:

2 + 1 + 2 + 2 = 7

9. Dijkstra Using a Min-Heap

The adjacency-matrix implementation selects the minimum-distance vertex by scanning all vertices. This takes O(V²) time.

For sparse graphs, a more efficient implementation uses an adjacency list and a min-priority queue.

Algorithm

  1. Initialize distances and insert the source into a min-heap.
  2. Extract the vertex with the smallest distance.
  3. Ignore the entry if it is stale compared with the current distance.
  4. Relax all outgoing edges.
  5. Insert improved distances into the heap.
  6. Continue until the heap is empty.

Complexity

Implementation Time Complexity
Adjacency matrix + linear selection O(V²)
Adjacency list + binary min-heap O((V + E) log V)
Adjacency list + Fibonacci heap (theoretical) O(E + V log V)
For most placement interviews, know the adjacency-list plus binary min-heap approach and its complexity.

10. Limitation of Dijkstra's Algorithm

Dijkstra's algorithm assumes that all edge weights are non-negative.

Negative edges can invalidate its greedy decision: a vertex marked as finalized may later have a shorter path discovered through a negative edge. 

0 --2--> 1
|        |
5       -10
|        |
v        v
2 ------> 1

A negative edge can make a previously selected distance smaller after the algorithm has already finalized it.

Do not use ordinary Dijkstra's algorithm when negative edge weights are present. Use Bellman-Ford when negative edges must be supported.

11. Bellman-Ford Algorithm

Bellman-Ford finds shortest paths from a single source in a weighted directed graph, including graphs with negative edge weights, provided no reachable negative cycle makes the shortest distance undefined.

Core Idea

Repeatedly relax every edge.

A shortest simple path can contain at most V - 1 edges. Therefore, after V - 1 full relaxation passes, all shortest distances have been found if no reachable negative cycle exists.

Algorithm Steps

  1. Initialize all distances to infinity.
  2. Set the source distance to zero.
  3. Repeat V - 1 times:
    • Examine every edge (u, v, w).
    • If dist[u] + w is smaller than dist[v], update dist[v].
  4. Perform one additional pass over all edges.
  5. If any reachable distance can still be improved, a reachable negative cycle exists.

Pseudocode

dist[source] = 0

all other distances = INFINITY

repeat V - 1 times:

    for each edge (u, v, weight):

        if dist[u] is finite and
           dist[u] + weight < dist[v]:

            dist[v] = dist[u] + weight

for each edge (u, v, weight):

    if dist[u] is finite and
       dist[u] + weight < dist[v]:

        report reachable negative cycle

13. Complete C11 Program: Bellman-Ford

This program supports negative edge weights and detects negative cycles reachable from the source. 

#include <stdio.h>
#include <limits.h>

#define V 5
#define E 8
#define INF (LLONG_MAX / 4)

typedef struct
{
    int src;
    int dest;
    int weight;
} Edge;

int bellmanFord(Edge edges[E], int source)
{
    long long dist[V];
    int parent[V];
    int i, j;

    for (i = 0; i < V; i++)
    {
        dist[i] = INF;
        parent[i] = -1;
    }

    dist[source] = 0;

    /* V - 1 relaxation passes */
    for (i = 1; i <= V - 1; i++)
    {
        int updated = 0;

        for (j = 0; j < E; j++)
        {
            int u = edges[j].src;
            int v = edges[j].dest;
            int w = edges[j].weight;

            if (dist[u] != INF &&
                dist[u] + w < dist[v])
            {
                dist[v] = dist[u] + w;
                parent[v] = u;
                updated = 1;
            }
        }

        if (!updated)
        {
            break;
        }
    }

    /* Check for reachable negative cycle */
    for (j = 0; j < E; j++)
    {
        int u = edges[j].src;
        int v = edges[j].dest;
        int w = edges[j].weight;

        if (dist[u] != INF &&
            dist[u] + w < dist[v])
        {
            printf("Reachable negative-weight cycle detected.\n");
            return 0;
        }
    }

    printf("Shortest distances from source %d:\n", source);

    for (i = 0; i < V; i++)
    {
        if (dist[i] == INF)
        {
            printf("Vertex %d: Unreachable\n", i);
        }
        else
        {
            printf("Vertex %d: %lld\n", i, dist[i]);
        }
    }

    printf("\nParent array:\n");

    for (i = 0; i < V; i++)
    {
        printf("Parent of %d: %d\n", i, parent[i]);
    }

    return 1;
}

int main(void)
{
    Edge edges[E] =
    {
        {0, 1, 4},
        {0, 2, 5},
        {1, 2, -2},
        {1, 3, 6},
        {2, 3, 3},
        {3, 4, 2},
        {4, 1, 4},
        {0, 4, 12}
    };

    bellmanFord(edges, 0);

    return 0;
}

Vertex 4: 7

Parent of 1: 0

Parent of 4: 3

14. Negative-Weight Cycle

A negative-weight cycle is a cycle whose total edge weight is negative.

Example

0 --1--> 1
^        |
|        |
-3       -1
|        v
2 <------+

Consider these edges:

0 → 1 = 1
1 → 2 = -3
2 → 0 = 1

Total cycle weight:

1 + (-3) + 1 = -1

Repeatedly traversing this cycle reduces the path cost without bound. Therefore, a finite shortest path does not exist for vertices reachable through this cycle.

Bellman-Ford detects a negative cycle only if the cycle is reachable from the chosen source. A negative cycle in a disconnected component will not be reported by a single-source run from another component.

15. Complete C11 Program: Negative Cycle Detection

The following example contains a negative cycle reachable from source vertex 0. 

#include <stdio.h>
#include <limits.h>

#define V 4
#define E 4
#define INF (LLONG_MAX / 4)

typedef struct
{
    int src;
    int dest;
    int weight;
} Edge;

int detectNegativeCycle(Edge edges[E], int source)
{
    long long dist[V];
    int i, j;

    for (i = 0; i < V; i++)
    {
        dist[i] = INF;
    }

    dist[source] = 0;

    for (i = 1; i <= V - 1; i++)
    {
        for (j = 0; j < E; j++)
        {
            int u = edges[j].src;
            int v = edges[j].dest;
            int w = edges[j].weight;

            if (dist[u] != INF &&
                dist[u] + w < dist[v])
            {
                dist[v] = dist[u] + w;
            }
        }
    }

    for (j = 0; j < E; j++)
    {
        int u = edges[j].src;
        int v = edges[j].dest;
        int w = edges[j].weight;

        if (dist[u] != INF &&
            dist[u] + w < dist[v])
        {
            return 1;
        }
    }

    return 0;
}

int main(void)
{
    Edge edges[E] =
    {
        {0, 1, 1},
        {1, 2, -3},
        {2, 0, 1},
        {2, 3, 2}
    };

    if (detectNegativeCycle(edges, 0))
    {
        printf("Negative-weight cycle detected.\n");
    }
    else
    {
        printf("No reachable negative-weight cycle.\n");
    }

    return 0;
}

Expected Output

Negative-weight cycle detected.

16. Dijkstra vs Bellman-Ford

Feature Dijkstra Bellman-Ford
Approach Greedy Repeated edge relaxation
Negative edges Not supported by the standard algorithm Supported
Negative cycle detection No Yes, reachable from source
Adjacency-list time O((V + E) log V) with binary heap O(VE)
Matrix implementation time O(V²) O(VE), using edge list
Typical use Non-negative weighted graphs Graphs with negative weights
Interview rule: Use Dijkstra when all edge weights are non-negative. Use Bellman-Ford when negative edge weights are possible or reachable negative-cycle detection is required.

17. Important Shortest-Path Concepts

Single-Source Shortest Path

Finds shortest distances from one source vertex to every other vertex.

Single-Pair Shortest Path

Finds the shortest distance between one specified source and one destination.

All-Pairs Shortest Path

Finds shortest distances between every pair of vertices. Floyd-Warshall is a common all-pairs shortest-path algorithm.

Shortest Path in an Unweighted Graph

BFS finds shortest paths in terms of number of edges when every edge has equal cost.

Parent Array

Stores the predecessor of each vertex in the selected shortest path tree. It can be used to reconstruct paths.

18. Common Interview Mistakes

  1. Applying Dijkstra to a graph with negative edge weights.
  2. Forgetting to initialize the source distance to zero.
  3. Relaxing edges from an unreachable vertex.
  4. Incorrectly using infinity in arithmetic.
  5. Forgetting the V - 1 passes in Bellman-Ford.
  6. Not performing the additional negative-cycle check.
  7. Confusing directed and undirected weighted graphs.
  8. Assuming shortest path means the fewest edges.
  9. Failing to store parent information when path reconstruction is required.
  10. Using an adjacency matrix when an adjacency list is more appropriate for a sparse graph.

19. Placement Interview Questions

Q1. What is Dijkstra's algorithm?

A greedy single-source shortest-path algorithm for weighted graphs with non-negative edge weights.

Q2. Why does Dijkstra fail with negative weights?

Its greedy finalization step may be invalidated by a later route containing a negative edge.

Q3. What is Bellman-Ford?

A shortest-path algorithm that repeatedly relaxes every edge and supports negative edge weights.

Q4. Why does Bellman-Ford use V - 1 passes?

A shortest simple path can contain at most V - 1 edges.

Q5. How does Bellman-Ford detect a negative cycle?

It checks whether any reachable edge can still improve a distance after V - 1 relaxation passes.

Q6. What is edge relaxation?

Updating a distance when a shorter path is found through another vertex.

Q7. Which algorithm is generally faster for non-negative sparse graphs?

Dijkstra with an adjacency list and binary min-heap is generally faster.

Q8. Can Bellman-Ford handle negative edges?

Yes.

Q9. Can Dijkstra detect a negative cycle?

Standard Dijkstra is not a negative-cycle detection algorithm.

Q10. What is the complexity of Bellman-Ford?

O(VE).

Q11. What happens when a reachable negative cycle exists?

There is no finite shortest distance for vertices reachable from that cycle.

Q12. Which algorithm finds shortest paths in an unweighted graph?

BFS.
