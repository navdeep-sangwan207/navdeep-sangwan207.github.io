Chapter 12 – Graphs and Graph Algorithms

Lesson 7: Topological Sorting

Learn how to arrange vertices of a Directed Acyclic Graph in a valid dependency order using Kahn's algorithm and DFS-based topological sorting.

1. Learning Objectives

  • Understand topological ordering and its applications.
  • Identify Directed Acyclic Graphs (DAGs).
  • Understand indegree and outdegree.
  • Implement Kahn's algorithm using BFS and a queue.
  • Implement topological sorting using DFS and a stack.
  • Detect cycles while performing topological sorting.
  • Understand why a topological order may not be unique.
  • Solve dependency and scheduling problems.

2. What Is Topological Sorting?

Topological sorting is a linear ordering of vertices in a directed graph such that for every directed edge u → v, vertex u appears before vertex v.

In simple terms, if one task depends on another task, the prerequisite task must appear first.

Example

0 → 2
|
↓
1 → 3

Edges:

0 → 1
0 → 2
1 → 3
2 → 3

One valid topological ordering is:

0 1 2 3

Another valid ordering is:

0 2 1 3
A topological ordering is not necessarily unique. Multiple valid orders can exist for the same DAG.

3. Directed Acyclic Graph (DAG)

A Directed Acyclic Graph (DAG) is a directed graph that does not contain any directed cycle.

Example of a DAG

0 → 1 → 3
 \      ↑
  → 2 ──┘

Example of a Graph with a Cycle

0 → 1 → 2
↑       |
|_______|
Topological sorting is possible only for a DAG. A directed graph containing a cycle does not have a valid topological ordering.

Important Properties

  • Every DAG has at least one topological ordering.
  • A DAG may have multiple valid topological orderings.
  • A directed cycle makes topological ordering impossible.
  • Every edge must point from an earlier vertex to a later vertex in the ordering.

4. Indegree and Outdegree

Indegree is the number of incoming edges to a vertex. Outdegree is the number of outgoing edges from a vertex.

Example

0 → 1 → 3
 \      ↑
  → 2 ──┘
Vertex Indegree Outdegree
002
111
211
320
Kahn's algorithm begins by inserting all vertices having indegree zero into a queue.

5. Kahn's Algorithm – BFS Approach

Kahn's algorithm uses indegree and a queue to construct a topological ordering.

Algorithm Steps

  1. Calculate the indegree of every vertex.
  2. Insert all vertices with indegree zero into a queue.
  3. Remove a vertex from the front of the queue.
  4. Add that vertex to the topological ordering.
  5. For every outgoing neighbor, decrease its indegree by one.
  6. If a neighbor's indegree becomes zero, insert it into the queue.
  7. Continue until the queue becomes empty.
  8. If fewer than V vertices were processed, the graph contains a cycle.

Pseudocode

calculate indegree of all vertices

enqueue every vertex with indegree 0

count = 0

while queue is not empty:

    current = dequeue()

    order[count] = current
    count = count + 1

    for each neighbor of current:

        indegree[neighbor]--

        if indegree[neighbor] == 0:

            enqueue(neighbor)

if count != V:

    report cycle

else:

    print topological order

7. Complete C11 Program: Kahn's Algorithm Using Adjacency Matrix

This program calculates indegrees, uses a queue and checks whether a directed cycle exists. 

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
}

int topologicalSort(int graph[V][V], int order[V])
{
    int indegree[V] = {0};
    int queue[V];
    int front = 0;
    int rear = 0;
    int count = 0;
    int i, j, current;

    /* Calculate indegree */
    for (i = 0; i < V; i++)
    {
        for (j = 0; j < V; j++)
        {
            if (graph[i][j] == 1)
            {
                indegree[j]++;
            }
        }
    }

    /* Add all zero-indegree vertices */
    for (i = 0; i < V; i++)
    {
        if (indegree[i] == 0)
        {
            queue[rear++] = i;
        }
    }

    /* Process vertices */
    while (front < rear)
    {
        current = queue[front++];

        order[count++] = current;

        for (j = 0; j < V; j++)
        {
            if (graph[current][j] == 1)
            {
                indegree[j]--;

                if (indegree[j] == 0)
                {
                    queue[rear++] = j;
                }
            }
        }
    }

    return count;
}

int main(void)
{
    int graph[V][V] = {0};
    int order[V];
    int count;
    int i;

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 2, 3);
    addEdge(graph, 3, 4);
    addEdge(graph, 4, 5);

    count = topologicalSort(graph, order);

    if (count != V)
    {
        printf("Cycle detected. Topological sorting is not possible.\n");
    }
    else
    {
        printf("Topological ordering: ");

        for (i = 0; i < count; i++)
        {
            printf("%d ", order[i]);
        }

        printf("\n");
    }

    return 0;
}

Expected Output

Topological ordering: 0 1 2 3 4 5

Test Cycle Detection

Add the following edge to the graph construction: 

addEdge(graph, 5, 2);

This creates a directed cycle involving vertices 2, 3, 4 and 5. 

Cycle detected. Topological sorting is not possible.

8. DFS-Based Topological Sorting

Another way to perform topological sorting is to use DFS and a stack.

A vertex is pushed onto the stack only after all its outgoing neighbors have been completely explored.

Algorithm

  1. Initialize every vertex as unvisited.
  2. Start DFS from every unvisited vertex.
  3. Mark the current vertex as visiting.
  4. Explore all outgoing neighbors.
  5. If a neighbor is currently visiting, a cycle exists.
  6. After all neighbors are processed, mark the current vertex as visited.
  7. Push the current vertex onto the stack.
  8. Pop the stack to obtain topological ordering.

Why Push After DFS?

Consider an edge u → v. Vertex v must appear before u is pushed onto the stack, so popping the stack places u before v.

Pseudocode

DFS(vertex):

    state[vertex] = VISITING

    for each neighbor:

        if state[neighbor] == VISITING:
            return false

        if state[neighbor] == UNVISITED:

            if DFS(neighbor) == false:
                return false

    state[vertex] = VISITED

    push(vertex)

    return true

9. Complete C11 Program: DFS Topological Sorting

This implementation uses an adjacency matrix, three-state DFS cycle detection and an explicit stack. 

#include <stdio.h>

#define V 6

enum
{
    UNVISITED,
    VISITING,
    VISITED
};

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
}

int DFS(int graph[V][V],
        int vertex,
        int state[V],
        int stack[V],
        int *top)
{
    int i;

    state[vertex] = VISITING;

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1)
        {
            if (state[i] == VISITING)
            {
                return 0;
            }

            if (state[i] == UNVISITED)
            {
                if (!DFS(graph, i, state, stack, top))
                {
                    return 0;
                }
            }
        }
    }

    state[vertex] = VISITED;

    stack[++(*top)] = vertex;

    return 1;
}

int topologicalSortDFS(int graph[V][V], int result[V])
{
    int state[V] = {UNVISITED};
    int stack[V];
    int top = -1;
    int i;

    for (i = 0; i < V; i++)
    {
        if (state[i] == UNVISITED)
        {
            if (!DFS(graph, i, state, stack, &top))
            {
                return 0;
            }
        }
    }

    for (i = 0; i < V; i++)
    {
        result[i] = stack[top--];
    }

    return 1;
}

int main(void)
{
    int graph[V][V] = {0};
    int result[V];
    int i;

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 2, 3);
    addEdge(graph, 3, 4);
    addEdge(graph, 4, 5);

    if (topologicalSortDFS(graph, result))
    {
        printf("Topological ordering using DFS: ");

        for (i = 0; i < V; i++)
        {
            printf("%d ", result[i]);
        }

        printf("\n");
    }
    else
    {
        printf("Cycle detected. Topological sorting is not possible.\n");
    }

    return 0;
}

Expected Output

Topological ordering using DFS: 0 2 1 3 4 5

This ordering differs from the Kahn's algorithm output, but it is also valid.

Cycle detected. Topological sorting is not possible.

10. Kahn's Algorithm vs DFS Approach

Feature Kahn's Algorithm DFS Approach
Traversal technique BFS DFS
Main data structure Queue Stack
Important concept Indegree Finishing time
Cycle detection Processed count less than V Back edge to a visiting vertex
Adjacency-list complexity O(V + E) O(V + E)
Ordering Queue-based order Reverse finishing order

11. Lexicographically Smallest Topological Order

Sometimes an interview problem asks for the lexicographically smallest valid topological ordering.

For example, if several vertices have indegree zero, select the smallest-numbered vertex first.

Use a min-priority queue instead of a normal queue in Kahn's algorithm to obtain the lexicographically smallest topological ordering.

A normal FIFO queue does not guarantee the smallest available vertex is selected.

A min-heap implementation can achieve O((V + E) log V) time with an adjacency list.

12. Real-World Applications

  • Course scheduling: Complete prerequisite courses before advanced courses.
  • Build systems: Compile dependent software modules in the correct order.
  • Task scheduling: Execute tasks after their dependencies are completed.
  • Package management: Install dependent software packages in a valid order.
  • Project planning: Arrange project activities according to dependencies.
  • Data processing: Execute dependent operations in the correct sequence.

13. Important Placement Problems

Problem 1: Course Schedule

Given a number of courses and prerequisite pairs, determine whether all courses can be completed.

Model courses as vertices and prerequisite relationships as directed edges. A valid schedule exists if the graph is a DAG.

Problem 2: Course Schedule II

Return an ordering of courses that satisfies all prerequisite relationships.

Use Kahn's algorithm or DFS topological sorting.

Problem 3: Find Eventual Dependency Order

Given tasks with dependencies, return an execution sequence satisfying all dependencies.

Problem 4: Alien Dictionary

Given a sorted dictionary of an unknown language, derive character precedence relationships and construct a valid character ordering.

Alien Dictionary is a popular advanced topological sorting interview problem. It also requires careful handling of invalid prefix relationships.

14. Complexity Analysis

Let V represent vertices and E represent directed edges.

Implementation Time Complexity Auxiliary Space
Kahn's algorithm with adjacency list O(V + E) O(V)
DFS with adjacency list O(V + E) O(V)
Kahn's algorithm with adjacency matrix O(V²) O(V)
DFS with adjacency matrix O(V²) O(V)

The graph storage itself requires O(V + E) for an adjacency list and O(V²) for an adjacency matrix.

15. Common Interview Mistakes

  1. Trying to topologically sort an undirected graph.
  2. Forgetting that topological sorting requires a DAG.
  3. Using an incorrect indegree calculation.
  4. Failing to check whether all vertices were processed.
  5. Pushing a vertex onto the DFS stack before processing its neighbors.
  6. Assuming there is only one valid topological order.
  7. Confusing a valid topological ordering with a shortest path.
  8. Forgetting to process disconnected components.
  9. Not detecting a back edge in DFS-based sorting.

16. Placement Interview Questions

Q1. What is topological sorting?

It is a linear ordering of vertices in a directed graph such that every vertex appears before all vertices reachable through its outgoing edges directly connected by an edge.

Q2. Which graphs support topological sorting?

Directed Acyclic Graphs (DAGs).

Q3. What is Kahn's algorithm?

A BFS-based topological sorting algorithm that uses indegree and a queue.

Q4. How does Kahn's algorithm detect a cycle?

If fewer than V vertices are processed, the graph contains a directed cycle.

Q5. What is the DFS approach to topological sorting?

Explore outgoing neighbors and push each vertex onto a stack after all its neighbors are processed.

Q6. Can a DAG have multiple topological orderings?

Yes, a DAG can have multiple valid orderings.

Q7. What is indegree?

The number of incoming edges to a vertex.

Q8. What is the time complexity of topological sorting?

O(V + E) using an adjacency list.

Q9. Which data structure does Kahn's algorithm use?

A queue.

Q10. Why is topological sorting useful in scheduling?

It ensures that prerequisite tasks are completed before dependent tasks.

19. Lesson Summary

  • Topological sorting arranges vertices according to directed dependencies.
  • It is possible only for directed acyclic graphs.
  • Kahn's algorithm uses indegree and a queue.
  • DFS-based topological sorting uses reverse finishing order.
  • Both algorithms can detect directed cycles.
