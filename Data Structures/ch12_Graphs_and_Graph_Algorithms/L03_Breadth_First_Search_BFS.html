2. What Is Breadth First Search?

Breadth First Search (BFS) is a graph traversal algorithm that visits vertices level by level, starting from a selected source vertex.

BFS first visits the source vertex, then all its immediate neighbors, followed by the neighbors of those vertices.

Important: BFS uses a queue data structure to maintain the order in which vertices are explored.

Example Graph

        0
       / \
      1   2
     / \   \
    3   4---5

Assume BFS starts from vertex 0.

One possible traversal order is:

0 -> 1 -> 2 -> 3 -> 4 -> 5

The exact order among vertices at the same level depends on the order in which neighbors are stored.

3. How BFS Works

BFS follows these steps:

  1. Select a starting vertex.
  2. Mark the starting vertex as visited.
  3. Insert it into the queue.
  4. Remove a vertex from the front of the queue.
  5. Process that vertex.
  6. Visit each unvisited neighbor and insert it into the queue.
  7. Repeat until the queue becomes empty.

BFS Pseudocode

BFS(graph, start):

    Create an empty queue
    Mark start as visited
    Enqueue(start)

    while queue is not empty:

        current = Dequeue()

        Process(current)

        for each neighbor of current:

            if neighbor is not visited:

                Mark neighbor as visited
                Enqueue(neighbor)
Mark a vertex as visited when it is enqueued, not when it is dequeued. This prevents the same vertex from being inserted multiple times by different neighbors.

5. Why Does BFS Use a Queue?

A queue follows FIFO (First In, First Out). The vertex discovered first is processed first.

This behavior ensures that BFS explores all vertices at distance 1 before vertices at distance 2, and so on.

Data Structure Processing Order Typical Traversal
Queue FIFO BFS
Stack LIFO Iterative DFS
Call Stack Recursive calls Recursive DFS

6. Complete C11 Program: BFS Using Adjacency List

This implementation uses an adjacency list, a circular queue and a visited array. 

#include <stdio.h>
#include <stdlib.h>

#define MAX_VERTICES 100

typedef struct Node
{
    int vertex;
    struct Node *next;
} Node;

typedef struct
{
    int items[MAX_VERTICES];
    int front;
    int rear;
    int count;
} Queue;

Node *adjacencyList[MAX_VERTICES];

void initializeGraph(int vertices)
{
    int i;

    for (i = 0; i < vertices; i++)
    {
        adjacencyList[i] = NULL;
    }
}

Node *createNode(int vertex)
{
    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL)
    {
        return NULL;
    }

    newNode->vertex = vertex;
    newNode->next = NULL;

    return newNode;
}

int addUndirectedEdge(int u, int v, int vertices)
{
    Node *first;
    Node *second;

    if (u < 0 || u >= vertices ||
        v < 0 || v >= vertices)
    {
        return 0;
    }

    first = createNode(v);

    if (first == NULL)
    {
        return 0;
    }

    second = createNode(u);

    if (second == NULL)
    {
        free(first);
        return 0;
    }

    first->next = adjacencyList[u];
    adjacencyList[u] = first;

    second->next = adjacencyList[v];
    adjacencyList[v] = second;

    return 1;
}

void initializeQueue(Queue *q)
{
    q->front = 0;
    q->rear = -1;
    q->count = 0;
}

int isQueueEmpty(Queue *q)
{
    return q->count == 0;
}

int enqueue(Queue *q, int value)
{
    if (q->count == MAX_VERTICES)
    {
        return 0;
    }

    q->rear = (q->rear + 1) % MAX_VERTICES;
    q->items[q->rear] = value;
    q->count++;

    return 1;
}

int dequeue(Queue *q, int *value)
{
    if (isQueueEmpty(q))
    {
        return 0;
    }

    *value = q->items[q->front];
    q->front = (q->front + 1) % MAX_VERTICES;
    q->count--;

    return 1;
}

void BFS(int start, int vertices)
{
    int visited[MAX_VERTICES] = {0};
    int current;
    Node *temp;
    Queue q;

    if (start < 0 || start >= vertices)
    {
        printf("Invalid starting vertex.\n");
        return;
    }

    initializeQueue(&q);

    visited[start] = 1;
    enqueue(&q, start);

    printf("BFS Traversal: ");

    while (!isQueueEmpty(&q))
    {
        dequeue(&q, &current);

        printf("%d ", current);

        temp = adjacencyList[current];

        while (temp != NULL)
        {
            if (!visited[temp->vertex])
            {
                visited[temp->vertex] = 1;
                enqueue(&q, temp->vertex);
            }

            temp = temp->next;
        }
    }

    printf("\n");
}

void freeGraph(int vertices)
{
    int i;
    Node *current;
    Node *nextNode;

    for (i = 0; i < vertices; i++)
    {
        current = adjacencyList[i];

        while (current != NULL)
        {
            nextNode = current->next;
            free(current);
            current = nextNode;
        }

        adjacencyList[i] = NULL;
    }
}

int main(void)
{
    int vertices = 6;
    int success = 1;

    initializeGraph(vertices);

    success &= addUndirectedEdge(0, 1, vertices);
    success &= addUndirectedEdge(0, 2, vertices);
    success &= addUndirectedEdge(1, 3, vertices);
    success &= addUndirectedEdge(1, 4, vertices);
    success &= addUndirectedEdge(2, 5, vertices);
    success &= addUndirectedEdge(4, 5, vertices);

    if (!success)
    {
        printf("Graph construction failed.\n");
        freeGraph(vertices);
        return 1;
    }

    BFS(0, vertices);

    freeGraph(vertices);

    return 0;
}

Expected Output

BFS Traversal: 0 2 1 5 4 3
The output order is determined by the insertion order of neighbors. This program inserts each new neighbor at the beginning of its linked list, so the traversal order differs from the earlier dry run.

Code Explanation

  • Node stores a neighbor and its next pointer.
  • adjacencyList stores the linked list for each vertex.
  • Queue implements a circular queue.
  • visited[] prevents repeated visits.
  • enqueue() inserts a discovered vertex.
  • dequeue() removes the next vertex to process.
  • BFS() performs the traversal.
  • freeGraph() releases allocated memory.

7. Complete C11 Program: BFS Using Adjacency Matrix

In this implementation, the algorithm scans each row of the matrix to find the neighbors of the current vertex. 

#include <stdio.h>

#define MAX_VERTICES 100

void addUndirectedEdge(
    int graph[MAX_VERTICES][MAX_VERTICES],
    int u,
    int v,
    int vertices)
{
    if (u < 0 || u >= vertices ||
        v < 0 || v >= vertices)
    {
        return;
    }

    graph[u][v] = 1;
    graph[v][u] = 1;
}

void BFS(
    int graph[MAX_VERTICES][MAX_VERTICES],
    int vertices,
    int start)
{
    int visited[MAX_VERTICES] = {0};
    int queue[MAX_VERTICES];
    int front = 0;
    int rear = 0;
    int current;
    int i;

    if (vertices <= 0 || vertices > MAX_VERTICES ||
        start < 0 || start >= vertices)
    {
        printf("Invalid graph or starting vertex.\n");
        return;
    }

    visited[start] = 1;
    queue[rear++] = start;

    printf("BFS Traversal: ");

    while (front < rear)
    {
        current = queue[front++];

        printf("%d ", current);

        for (i = 0; i < vertices; i++)
        {
            if (graph[current][i] == 1 &&
                !visited[i])
            {
                visited[i] = 1;
                queue[rear++] = i;
            }
        }
    }

    printf("\n");
}

int main(void)
{
    int graph[MAX_VERTICES][MAX_VERTICES] = {0};
    int vertices = 6;

    addUndirectedEdge(graph, 0, 1, vertices);
    addUndirectedEdge(graph, 0, 2, vertices);
    addUndirectedEdge(graph, 1, 3, vertices);
    addUndirectedEdge(graph, 1, 4, vertices);
    addUndirectedEdge(graph, 2, 5, vertices);
    addUndirectedEdge(graph, 4, 5, vertices);

    BFS(graph, vertices, 0);

    return 0;
}

Expected Output

BFS Traversal: 0 1 2 3 4 5

Complexity

  • Adjacency matrix: O(V²) time for a complete traversal.
  • Adjacency list: O(V + E) time for a complete traversal.
  • Visited array: O(V) auxiliary space.
  • Queue: O(V) maximum space.

8. BFS for Disconnected Graphs

A normal BFS starting from one vertex only visits the vertices reachable from that starting vertex.

If the graph is disconnected, some vertices will remain unvisited. To traverse every component, start BFS again from each unvisited vertex.

Example

0 --- 1 --- 2

3 --- 4

5

There are three connected components:

Component 1: 0, 1, 2
Component 2: 3, 4
Component 3: 5

Complete C11 Program: BFS of All Components

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void BFSComponent(int graph[V][V],
                  int visited[V],
                  int start)
{
    int queue[V];
    int front = 0;
    int rear = 0;
    int current;
    int i;

    visited[start] = 1;
    queue[rear++] = start;

    while (front < rear)
    {
        current = queue[front++];

        printf("%d ", current);

        for (i = 0; i < V; i++)
        {
            if (graph[current][i] == 1 &&
                !visited[i])
            {
                visited[i] = 1;
                queue[rear++] = i;
            }
        }
    }
}

void BFSAllComponents(int graph[V][V])
{
    int visited[V] = {0};
    int i;
    int component = 0;

    for (i = 0; i < V; i++)
    {
        if (!visited[i])
        {
            component++;

            printf("Component %d: ", component);

            BFSComponent(graph, visited, i);

            printf("\n");
        }
    }
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);
    addEdge(graph, 3, 4);

    BFSAllComponents(graph);

    return 0;
}

Expected Output

Component 1: 0 1 2
Component 2: 3 4
Component 3: 5

This technique is useful for counting connected components in an undirected graph.

Complexity: O(V²) for the adjacency matrix implementation.

9. Shortest Path in an Unweighted Graph Using BFS

BFS can find the shortest path in an unweighted graph because it explores vertices in increasing order of their distance from the source.

Maintain a distance array: 

distance[v] = shortest number of edges
               from source to vertex v

Initially:

distance[source] = 0

distance[all other vertices] = -1

When discovering an unvisited neighbor v from u: 

distance[v] = distance[u] + 1

Complete C11 Program: Shortest Distance from a Source

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void shortestDistances(int graph[V][V], int source)
{
    int distance[V];
    int queue[V];
    int front = 0;
    int rear = 0;
    int current;
    int i;

    for (i = 0; i < V; i++)
    {
        distance[i] = -1;
    }

    distance[source] = 0;
    queue[rear++] = source;

    while (front < rear)
    {
        current = queue[front++];

        for (i = 0; i < V; i++)
        {
            if (graph[current][i] == 1 &&
                distance[i] == -1)
            {
                distance[i] = distance[current] + 1;
                queue[rear++] = i;
            }
        }
    }

    printf("Shortest distances from vertex %d:\n", source);

    for (i = 0; i < V; i++)
    {
        printf("Vertex %d: %d\n", i, distance[i]);
    }
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 1, 4);
    addEdge(graph, 2, 5);
    addEdge(graph, 4, 5);

    shortestDistances(graph, 0);

    return 0;
}

Expected Output

Shortest distances from vertex 0:
Vertex 0: 0
Vertex 1: 1
Vertex 2: 1
Vertex 3: 2
Vertex 4: 2
Vertex 5: 2
BFS finds shortest paths by number of edges in an unweighted graph. For weighted graphs, algorithms such as Dijkstra's or Bellman-Ford are needed, depending on the edge weights.

Application How BFS Helps

Social networks Finds people within a given connection distance
Web crawling Explores links level by level

11. BFS vs DFS

Feature BFS DFS
Full form Breadth First Search Depth First Search
Traversal Level by level Depth first
Data structure Queue Stack or recursion
Unweighted shortest path Yes Not guaranteed
Adjacency list complexity O(V + E) O(V + E)
Auxiliary space O(V) O(V)

12. Common BFS Mistakes

  1. Forgetting to mark the starting vertex as visited.
  2. Marking vertices visited only after dequeuing them.
  3. Using a stack instead of a queue for BFS.
  4. Forgetting to check whether a vertex has already been visited.
  5. Assuming a single BFS visits every vertex in a disconnected graph.
  6. Using BFS to find shortest paths in arbitrary weighted graphs.
  7. Forgetting queue capacity and boundary checks.
  8. Failing to release dynamically allocated adjacency-list nodes.

13. Placement Interview Questions

Q1. What is BFS?

BFS is a graph traversal algorithm that explores vertices level by level from a starting vertex.

Q2. Which data structure is used by BFS?

Queue.

Q3. Why is a queue used in BFS?

FIFO ordering ensures that vertices discovered earlier are processed before vertices discovered later.

Q4. What is BFS complexity using an adjacency list?

O(V + E).

Q5. What is BFS complexity using an adjacency matrix?

O(V²).

Q6. Can BFS find the shortest path?

Yes, in an unweighted graph or when every edge has equal cost.

Q7. Why do we need a visited array?

It prevents repeated processing and infinite traversal in graphs containing cycles.

Q8. Does BFS work on disconnected graphs?

Yes, but a single BFS only visits the component reachable from its starting vertex. Repeat BFS from unvisited vertices to cover every component.

Q9. What is the maximum number of vertices in the BFS queue?

At most V, when each vertex is enqueued only once.

Q10. Can BFS be used on a grid?

Yes. Each valid cell can be treated as a vertex and valid moves as edges.

16. Lesson Summary

  • BFS explores a graph level by level.
  • BFS uses a FIFO queue.
  • A visited array prevents repeated processing.
  • Adjacency-list BFS takes O(V + E) time.
  • Adjacency-matrix BFS takes O(V²) time.
  • BFS finds shortest paths in unweighted graphs.
  • Disconnected graphs require BFS from each unvisited component.
  • BFS is useful in grid problems, networks and connected-component problems.
