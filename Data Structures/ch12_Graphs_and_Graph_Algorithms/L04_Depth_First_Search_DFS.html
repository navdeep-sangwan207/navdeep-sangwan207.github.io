2. What Is Depth First Search?

Depth First Search (DFS) is a graph traversal algorithm that explores as far as possible along one path before backtracking to explore other paths.

DFS starts from a selected vertex, visits an unvisited neighbor, and continues deeper until no unvisited neighbor remains.

Important: DFS uses a stack. The stack may be implemented explicitly or implicitly through recursive function calls.

Example Graph

        0
       / \
      1   2
     / \   \
    3   4---5

Starting from vertex 0, one possible DFS traversal is: 

0 -> 1 -> 3 -> 4 -> 5 -> 2

The exact order depends on the order in which neighbors are examined.

3. How DFS Works

  1. Select a starting vertex.
  2. Mark it as visited.
  3. Process the vertex.
  4. Choose an unvisited neighbor.
  5. Continue exploring that neighbor.
  6. When no unvisited neighbor remains, backtrack.
  7. Continue until all reachable vertices are visited.

DFS Pseudocode – Recursive

DFS(vertex):

    Mark vertex as visited

    Process(vertex)

    for each neighbor of vertex:

        if neighbor is not visited:

            DFS(neighbor)

DFS Pseudocode – Iterative

DFS(start):

    Create an empty stack

    Push(start)

    while stack is not empty:

        vertex = Pop()

        if vertex is not visited:

            Mark vertex as visited

            Process(vertex)

            Push all unvisited neighbors
In iterative DFS, marking a vertex when it is popped is valid when duplicate stack entries are allowed and checked before processing. An alternative is to mark vertices when pushing them, which prevents duplicate insertions but may produce a different traversal order.

4. DFS Step-by-Step Dry Run

Consider this graph:

        0
       / \
      1   2
     / \   \
    3   4---5

Adjacency list:

0: 1, 2
1: 0, 3, 4
2: 0, 5
3: 1
4: 1, 5
5: 2, 4

Assume neighbors are visited in the listed order.

Step Current Vertex Action
1 0 Visit 0, move to 1
2 1 Visit 1, move to 3
3 3 No unvisited neighbor; backtrack to 1
4 1 Visit next unvisited neighbor 4
5 4 Move to 5
6 5 Move to 2
7 2 No unvisited neighbor; backtrack

Final DFS Traversal

0 -> 1 -> 3 -> 4 -> 5 -> 2

5. Understanding Backtracking in DFS

Backtracking means returning to an earlier vertex when the current vertex has no unvisited neighbors.

Consider:

0
|
1
|
3

After visiting 3, DFS returns to 1. It then checks whether another unvisited neighbor is available.

Recursive DFS performs this return automatically when a function call completes.

6. Complete C11 Program: Recursive DFS Using Adjacency List

#include <stdio.h>
#include <stdlib.h>

#define MAX_VERTICES 100

typedef struct Node
{
    int vertex;
    struct Node *next;
} Node;

Node *adjacencyList[MAX_VERTICES];
int visited[MAX_VERTICES];

void initializeGraph(int vertices)
{
    int i;

    for (i = 0; i < vertices; i++)
    {
        adjacencyList[i] = NULL;
        visited[i] = 0;
    }
}

Node *createNode(int vertex)
{
    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL)
    {
        return NULL;
    }

    newNode->vertex = vertex;
    newNode->next = NULL;

    return newNode;
}

int addUndirectedEdge(int u, int v, int vertices)
{
    Node *first;
    Node *second;

    if (u < 0 || u >= vertices ||
        v < 0 || v >= vertices)
    {
        return 0;
    }

    first = createNode(v);

    if (first == NULL)
    {
        return 0;
    }

    second = createNode(u);

    if (second == NULL)
    {
        free(first);
        return 0;
    }

    first->next = adjacencyList[u];
    adjacencyList[u] = first;

    second->next = adjacencyList[v];
    adjacencyList[v] = second;

    return 1;
}

void DFS(int vertex)
{
    Node *temp;

    visited[vertex] = 1;

    printf("%d ", vertex);

    temp = adjacencyList[vertex];

    while (temp != NULL)
    {
        if (!visited[temp->vertex])
        {
            DFS(temp->vertex);
        }

        temp = temp->next;
    }
}

void freeGraph(int vertices)
{
    int i;
    Node *current;
    Node *nextNode;

    for (i = 0; i < vertices; i++)
    {
        current = adjacencyList[i];

        while (current != NULL)
        {
            nextNode = current->next;
            free(current);
            current = nextNode;
        }

        adjacencyList[i] = NULL;
    }
}

int main(void)
{
    int vertices = 6;
    int success = 1;

    initializeGraph(vertices);

    success &= addUndirectedEdge(0, 1, vertices);
    success &= addUndirectedEdge(0, 2, vertices);
    success &= addUndirectedEdge(1, 3, vertices);
    success &= addUndirectedEdge(1, 4, vertices);
    success &= addUndirectedEdge(2, 5, vertices);
    success &= addUndirectedEdge(4, 5, vertices);

    if (!success)
    {
        printf("Graph construction failed.\n");
        freeGraph(vertices);
        return 1;
    }

    printf("Recursive DFS Traversal: ");

    DFS(0);

    printf("\n");

    freeGraph(vertices);

    return 0;
}

Expected Output

Recursive DFS Traversal: 0 2 5 4 1 3

The adjacency list inserts new nodes at the beginning. Therefore, neighbors are explored in reverse insertion order.

7. Complete C11 Program: Iterative DFS Using a Stack

Recursive DFS uses the program's call stack. Iterative DFS uses an explicit stack implemented using an array. 

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void DFSIterative(int graph[V][V], int start)
{
    int visited[V] = {0};
    int stack[V];
    int top = -1;
    int current;
    int i;

    if (start < 0 || start >= V)
    {
        printf("Invalid starting vertex.\n");
        return;
    }

    stack[++top] = start;

    printf("Iterative DFS Traversal: ");

    while (top != -1)
    {
        current = stack[top--];

        if (visited[current])
        {
            continue;
        }

        visited[current] = 1;

        printf("%d ", current);

        /*
         * Push neighbors in reverse order so that
         * the smallest numbered neighbor is processed first.
         */
        for (i = V - 1; i >= 0; i--)
        {
            if (graph[current][i] == 1 &&
                !visited[i])
            {
                stack[++top] = i;
            }
        }
    }

    printf("\n");
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 1, 4);
    addEdge(graph, 2, 5);
    addEdge(graph, 4, 5);

    DFSIterative(graph, 0);

    return 0;
}

Expected Output

Iterative DFS Traversal: 0 1 3 4 5 2
This implementation marks vertices when popped. A vertex can therefore be pushed more than once before its first pop. The stack is sized to V, so this particular fixed-size implementation is not safe for every graph: duplicate entries can exceed its capacity. For a robust implementation, mark vertices when pushing them, or use a dynamically sized stack with a suitable capacity.

Safer Iterative DFS Implementation

The following version marks a vertex when it is pushed, ensuring that each vertex is pushed at most once. 

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void DFSIterativeSafe(int graph[V][V], int start)
{
    int visited[V] = {0};
    int stack[V];
    int top = -1;
    int current;
    int i;

    if (start < 0 || start >= V)
    {
        printf("Invalid starting vertex.\n");
        return;
    }

    visited[start] = 1;
    stack[++top] = start;

    printf("DFS Traversal: ");

    while (top != -1)
    {
        current = stack[top--];

        printf("%d ", current);

        for (i = V - 1; i >= 0; i--)
        {
            if (graph[current][i] == 1 &&
                !visited[i])
            {
                visited[i] = 1;
                stack[++top] = i;
            }
        }
    }

    printf("\n");
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 1, 4);
    addEdge(graph, 2, 5);
    addEdge(graph, 4, 5);

    DFSIterativeSafe(graph, 0);

    return 0;
}

Expected Output

DFS Traversal: 0 1 3 4 5 2

8. DFS for Disconnected Graphs

A single DFS visits only the vertices reachable from its starting vertex.

To visit every vertex in a disconnected graph, start DFS from each vertex that has not yet been visited.

Complete C11 Program

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void DFS(int graph[V][V], int vertex, int visited[V])
{
    int i;

    visited[vertex] = 1;

    printf("%d ", vertex);

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1 &&
            !visited[i])
        {
            DFS(graph, i, visited);
        }
    }
}

void DFSAllComponents(int graph[V][V])
{
    int visited[V] = {0};
    int i;
    int component = 0;

    for (i = 0; i < V; i++)
    {
        if (!visited[i])
        {
            component++;

            printf("Component %d: ", component);

            DFS(graph, i, visited);

            printf("\n");
        }
    }
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);
    addEdge(graph, 3, 4);

    DFSAllComponents(graph);

    return 0;
}

Expected Output

Component 1: 0 1 2
Component 2: 3 4
Component 3: 5

9. Finding a Path Between Two Vertices Using DFS

DFS can determine whether a path exists between a source vertex and a destination vertex.

Maintain a parent array to reconstruct the path after the destination is reached.

Complete C11 Program

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

int DFSPath(int graph[V][V],
            int current,
            int destination,
            int visited[V],
            int parent[V])
{
    int i;

    visited[current] = 1;

    if (current == destination)
    {
        return 1;
    }

    for (i = 0; i < V; i++)
    {
        if (graph[current][i] == 1 &&
            !visited[i])
        {
            parent[i] = current;

            if (DFSPath(graph, i, destination,
                        visited, parent))
            {
                return 1;
            }
        }
    }

    return 0;
}

void printPath(int parent[V], int source, int destination)
{
    int path[V];
    int count = 0;
    int current = destination;
    int i;

    while (current != -1 && count < V)
    {
        path[count++] = current;

        if (current == source)
        {
            break;
        }

        current = parent[current];
    }

    if (count == 0 || path[count - 1] != source)
    {
        printf("Path reconstruction failed.\n");
        return;
    }

    printf("Path: ");

    for (i = count - 1; i >= 0; i--)
    {
        printf("%d", path[i]);

        if (i > 0)
        {
            printf(" -> ");
        }
    }

    printf("\n");
}

int main(void)
{
    int graph[V][V] = {0};
    int visited[V] = {0};
    int parent[V];
    int source = 0;
    int destination = 5;
    int i;

    for (i = 0; i < V; i++)
    {
        parent[i] = -1;
    }

    addEdge(graph, 0, 1);
    addEdge(graph, 0, 2);
    addEdge(graph, 1, 3);
    addEdge(graph, 1, 4);
    addEdge(graph, 2, 5);
    addEdge(graph, 4, 5);

    if (DFSPath(graph, source, destination,
                visited, parent))
    {
        printPath(parent, source, destination);
    }
    else
    {
        printf("No path exists.\n");
    }

    return 0;
}

Expected Output

Path: 0 -> 2 -> 5
DFS can find a path, but it does not guarantee the shortest path in an unweighted graph. Use BFS when the shortest path by number of edges is required.

11. Recursive DFS vs Iterative DFS

Feature Recursive DFS Iterative DFS
Stack Call stack Explicit stack
Implementation Usually shorter Requires stack operations
Memory control Limited by call-stack resources Explicitly controlled
Risk Deep recursion may overflow stack Must handle explicit stack capacity
Time complexity O(V + E) with adjacency list O(V + E) with adjacency list

12. DFS Complexity Analysis

Let V be the number of vertices and E be the number of edges.

Representation Time Complexity
Adjacency list O(V + E)
Adjacency matrix O(V²)

Auxiliary space:

  • Visited array: O(V).
  • Recursion stack or explicit stack: O(V).
For an undirected graph, the adjacency list contains two entries for each ordinary edge. The complete DFS traversal still takes O(V + E) time.

13. Common DFS Mistakes

  1. Forgetting to mark a vertex as visited.
  2. Not checking visited neighbors before recursion.
  3. Confusing DFS with BFS.
  4. Assuming DFS always finds a shortest path.
  5. Ignoring disconnected components.
  6. Using recursion on extremely deep graphs without considering stack limits.
  7. Allowing an explicit stack to overflow.
  8. Assuming traversal order is fixed regardless of neighbor ordering.

14. Placement Interview Questions

Q1. What is DFS?

DFS is a graph traversal algorithm that explores one path as deeply as possible before backtracking.

Q2. Which data structure is used in DFS?

A stack, either explicit or through recursive function calls.

Q3. What is the difference between BFS and DFS?

BFS explores level by level using a queue. DFS explores deeply using a stack or recursion.

Q4. What is DFS time complexity using an adjacency list?

O(V + E).

Q5. What is DFS time complexity using an adjacency matrix?

O(V²).

Q6. What is backtracking in DFS?

Returning to an earlier vertex after exploring all available unvisited neighbors of the current vertex.

Q7. Can DFS detect cycles?

Yes. Cycle detection can be implemented using DFS with appropriate visited and parent or recursion-state tracking.

Q8. Can DFS find the shortest path in an unweighted graph?

It can find a path, but does not guarantee the shortest one. BFS is generally used for shortest paths in unweighted graphs.

Q9. What is the difference between recursive and iterative DFS?

Recursive DFS uses the call stack, while iterative DFS manages a stack explicitly.

Q10. Why is a visited array important?

It prevents repeated traversal and infinite recursion when cycles are present.

17. Lesson Summary

  • DFS explores graph paths deeply before backtracking.
  • Recursive DFS uses the call stack.
  • Iterative DFS uses an explicit stack.
  • A visited array prevents repeated processing.
  • Adjacency-list DFS takes O(V + E) time.
  • Adjacency-matrix DFS takes O(V²) time.
  • DFS can traverse disconnected graphs by restarting from unvisited vertices.
  • DFS is useful for path finding, cycle detection and connected components.
  • BFS, not DFS, is the standard choice for shortest paths in unweighted graphs.
