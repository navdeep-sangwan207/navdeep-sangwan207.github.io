Chapter 12 – Graphs and Graph Algorithms

Lesson 6: Connected Components and Bipartite Graphs

Learn to identify connected components, count disconnected groups, color graph vertices and detect bipartite graphs using BFS and DFS.

1. Learning Objectives

  • Understand connected and disconnected graphs.
  • Identify connected components in undirected graphs.
  • Count connected components using DFS and BFS.
  • Understand graph coloring and two-coloring.
  • Determine whether a graph is bipartite.
  • Implement bipartite detection using BFS in C11.
  • Understand odd cycles and their relationship with bipartite graphs.
  • Analyze time and space complexity.

2. Connected Graph

An undirected graph is connected if there is a path between every pair of vertices.

Example: Connected Graph

0 --- 1 --- 2
      |
      3

Every vertex can be reached from every other vertex through some path.

Example: Disconnected Graph

0 --- 1 --- 2

3 --- 4

5

There is no path connecting the first group to the second or third group.

A disconnected graph contains at least two connected components. An isolated vertex is also a connected component by itself.

3. What Are Connected Components?

A connected component is a maximal connected subgraph. It is a group of vertices where every vertex is reachable from every other vertex in that group, and no additional vertex can be included without losing that property.

Example

Component 1:       Component 2:

0 --- 1            3 --- 4
      |
      2

Component 3:

5 --- 6

The graph contains three connected components:

  • Component 1: {0, 1, 2}
  • Component 2: {3, 4}
  • Component 3: {5, 6}

Number of connected components = 3

4. Counting Connected Components Using DFS

DFS can explore all vertices belonging to one connected component.

Algorithm

  1. Initialize all vertices as unvisited.
  2. Set the component count to zero.
  3. Visit every vertex from 0 to V - 1.
  4. If a vertex is unvisited, increment the component count.
  5. Run DFS from that vertex.
  6. DFS marks all vertices reachable from that starting vertex.
  7. Continue until all vertices have been checked.

Pseudocode

count = 0

for each vertex:

    if vertex is not visited:

        count = count + 1

        DFS(vertex)

return count
Every new DFS call started by the outer loop identifies one new connected component.

6. Complete C11 Program: Connected Components Using DFS

This implementation uses an adjacency matrix and recursive DFS. It supports disconnected graphs and isolated vertices. 

#include <stdio.h>

#define V 7

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void DFS(int graph[V][V], int vertex, int visited[V])
{
    int i;

    visited[vertex] = 1;

    printf("%d ", vertex);

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1 && !visited[i])
        {
            DFS(graph, i, visited);
        }
    }
}

int countComponents(int graph[V][V])
{
    int visited[V] = {0};
    int count = 0;
    int i;

    for (i = 0; i < V; i++)
    {
        if (!visited[i])
        {
            count++;

            printf("Component %d: ", count);

            DFS(graph, i, visited);

            printf("\n");
        }
    }

    return count;
}

int main(void)
{
    int graph[V][V] = {0};
    int components;

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);

    addEdge(graph, 3, 4);

    addEdge(graph, 5, 6);

    components = countComponents(graph);

    printf("\nTotal connected components: %d\n",
           components);

    return 0;
}

Expected Output

Component 1: 0 1 2
Component 2: 3 4
Component 3: 5 6

Total connected components: 3

The exact DFS visitation order depends on the order in which adjacent vertices are examined.

7. Counting Components Using BFS

BFS can also count connected components. Instead of recursively exploring neighbors, it uses a queue.

Algorithm

  1. Initialize all vertices as unvisited.
  2. Check every vertex.
  3. If a vertex is unvisited, increment the component count.
  4. Insert that vertex into a queue and mark it visited.
  5. Process the queue and visit all reachable neighbors.
  6. Repeat for remaining unvisited vertices.

Complete C11 Program

#include <stdio.h>

#define V 7

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

void BFS(int graph[V][V],
         int start,
         int visited[V])
{
    int queue[V];
    int front = 0;
    int rear = 0;
    int current;
    int i;

    visited[start] = 1;
    queue[rear++] = start;

    while (front < rear)
    {
        current = queue[front++];

        printf("%d ", current);

        for (i = 0; i < V; i++)
        {
            if (graph[current][i] == 1 && !visited[i])
            {
                visited[i] = 1;
                queue[rear++] = i;
            }
        }
    }
}

int countComponents(int graph[V][V])
{
    int visited[V] = {0};
    int count = 0;
    int i;

    for (i = 0; i < V; i++)
    {
        if (!visited[i])
        {
            count++;

            printf("Component %d: ", count);

            BFS(graph, i, visited);

            printf("\n");
        }
    }

    return count;
}

int main(void)
{
    int graph[V][V] = {0};
    int components;

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);

    addEdge(graph, 3, 4);

    addEdge(graph, 5, 6);

    components = countComponents(graph);

    printf("\nTotal connected components: %d\n",
           components);

    return 0;
}

Expected Output

Component 1: 0 1 2
Component 2: 3 4
Component 3: 5 6

Total connected components: 3

8. What Is a Bipartite Graph?

A graph is bipartite if its vertices can be divided into two disjoint sets such that every edge connects a vertex from one set to a vertex from the other set.

No edge should connect two vertices belonging to the same set.

Example: Bipartite Graph

Set A              Set B

  0  ------------   3
   \              /
    \            /
     1 -------- 4

  2  ------------ 5

One valid coloring is:

  • Set A: {0, 1, 2}
  • Set B: {3, 4, 5}

Graph Coloring

Bipartite detection can be performed by assigning one of two colors to every vertex.

Color Meaning
0 First group
1 Second group
For every edge (u, v), a valid bipartite coloring must satisfy color[u] != color[v].

9. Bipartite Graph Detection Using BFS

Algorithm

  1. Initialize the color array with -1 for every vertex.
  2. Check each vertex to support disconnected graphs.
  3. If a vertex is uncolored, assign color 0.
  4. Insert it into the BFS queue.
  5. For every adjacent vertex:
    • If it is uncolored, assign the opposite color.
    • If it has the same color as the current vertex, the graph is not bipartite.
  6. If all components are processed without conflict, the graph is bipartite.

Pseudocode

for each vertex:

    if color[vertex] == -1:

        color[vertex] = 0

        enqueue(vertex)

        while queue is not empty:

            current = dequeue()

            for each neighbor:

                if color[neighbor] == -1:

                    color[neighbor] =
                        1 - color[current]

                    enqueue(neighbor)

                else if color[neighbor] == color[current]:

                    return NOT_BIPARTITE

return BIPARTITE

11. Complete C11 Program: Bipartite Detection Using BFS

This implementation uses an adjacency matrix and a queue. It handles disconnected graphs and isolated vertices. 

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

int isBipartite(int graph[V][V], int color[V])
{
    int queue[V];
    int front;
    int rear;
    int start;
    int current;
    int i;

    for (i = 0; i < V; i++)
    {
        color[i] = -1;
    }

    for (start = 0; start < V; start++)
    {
        if (color[start] == -1)
        {
            front = 0;
            rear = 0;

            color[start] = 0;
            queue[rear++] = start;

            while (front < rear)
            {
                current = queue[front++];

                for (i = 0; i < V; i++)
                {
                    if (graph[current][i] == 1)
                    {
                        if (color[i] == -1)
                        {
                            color[i] = 1 - color[current];
                            queue[rear++] = i;
                        }
                        else if (color[i] == color[current])
                        {
                            return 0;
                        }
                    }
                }
            }
        }
    }

    return 1;
}

int main(void)
{
    int graph[V][V] = {0};
    int color[V];
    int i;

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);
    addEdge(graph, 2, 3);
    addEdge(graph, 3, 0);

    addEdge(graph, 4, 5);

    if (isBipartite(graph, color))
    {
        printf("The graph is bipartite.\n");

        printf("Color 0: ");

        for (i = 0; i < V; i++)
        {
            if (color[i] == 0)
            {
                printf("%d ", i);
            }
        }

        printf("\nColor 1: ");

        for (i = 0; i < V; i++)
        {
            if (color[i] == 1)
            {
                printf("%d ", i);
            }
        }

        printf("\n");
    }
    else
    {
        printf("The graph is not bipartite.\n");
    }

    return 0;
}

Expected Output

The graph is bipartite.
Color 0: 0 2 4
Color 1: 1 3 5

Test a Non-Bipartite Graph

Replace the graph construction with a triangle: 

addEdge(graph, 0, 1);
addEdge(graph, 1, 2);
addEdge(graph, 2, 0);

Keep the remaining vertices disconnected. 

The graph is not bipartite.

12. Why Are Odd Cycles Important?

An undirected graph is bipartite if and only if it contains no odd-length cycle.

Triangle: Odd Cycle

      0
     / \
    1---2

A triangle contains a cycle of length 3. It cannot be colored using only two colors without two adjacent vertices receiving the same color.

A graph containing an odd cycle is not bipartite.

Square: Even Cycle

0 --- 1
|     |
3 --- 2

A cycle of length 4 can be colored using two colors.

Important interview fact: A graph is bipartite exactly when it has no odd cycle. Even cycles do not prevent bipartiteness.

13. Bipartite Detection Using DFS

Bipartite detection can also be implemented with DFS. Instead of using a queue, recursive DFS assigns opposite colors to adjacent vertices.

Complete C11 Program

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

int colorDFS(int graph[V][V],
             int vertex,
             int color[V])
{
    int i;

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1)
        {
            if (color[i] == -1)
            {
                color[i] = 1 - color[vertex];

                if (!colorDFS(graph, i, color))
                {
                    return 0;
                }
            }
            else if (color[i] == color[vertex])
            {
                return 0;
            }
        }
    }

    return 1;
}

int isBipartiteDFS(int graph[V][V], int color[V])
{
    int i;

    for (i = 0; i < V; i++)
    {
        color[i] = -1;
    }

    for (i = 0; i < V; i++)
    {
        if (color[i] == -1)
        {
            color[i] = 0;

            if (!colorDFS(graph, i, color))
            {
                return 0;
            }
        }
    }

    return 1;
}

int main(void)
{
    int graph[V][V] = {0};
    int color[V];

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);
    addEdge(graph, 2, 3);
    addEdge(graph, 3, 0);

    addEdge(graph, 4, 5);

    if (isBipartiteDFS(graph, color))
    {
        printf("Bipartite graph detected using DFS.\n");
    }
    else
    {
        printf("Graph is not bipartite.\n");
    }

    return 0;
}

Expected Output

Bipartite graph detected using DFS.

14. BFS vs DFS for Bipartite Detection

Feature BFS DFS
Data structure Queue Recursion stack or explicit stack
Color assignment Level-by-level During recursive traversal
Time with adjacency list O(V + E) O(V + E)
Auxiliary space O(V) O(V) worst case
Disconnected graphs Supported with an outer loop Supported with an outer loop

Both methods are correct. BFS is often convenient for two-coloring because it processes vertices level by level.

16. Complexity Analysis

Let V represent vertices and E represent edges.

Problem Adjacency List Adjacency Matrix
Connected components using DFS O(V + E) O(V²)
Connected components using BFS O(V + E) O(V²)
Bipartite detection using BFS O(V + E) O(V²)
Bipartite detection using DFS O(V + E) O(V²)

Auxiliary space: O(V) for visited or color arrays and the traversal queue or recursion stack.

17. Common Interview Mistakes

  1. Starting DFS or BFS only from vertex 0 when the graph may be disconnected.
  2. Forgetting that isolated vertices are connected components.
  3. Not initializing every color entry to -1 before bipartite detection.
  4. Assigning the same color to adjacent vertices.
  5. Checking only whether the graph contains a cycle instead of checking for an odd cycle.
  6. Assuming every cyclic graph is non-bipartite. Even cycles can be bipartite.
  7. Using directed-graph assumptions for an undirected bipartite problem.
  8. Failing to mark a vertex when it is inserted into the BFS queue.

18. Placement Interview Questions

Q1. What is a connected component?

A maximal connected subgraph in which every pair of vertices is connected by a path.

Q2. How do you count connected components?

Run DFS or BFS from each unvisited vertex and increment the component count for every new traversal.

Q3. Can an isolated vertex be a connected component?

Yes. It forms a component containing one vertex.

Q4. What is a bipartite graph?

A graph whose vertices can be divided into two sets such that every edge connects vertices from different sets.

Q5. How can a bipartite graph be detected?

Use BFS or DFS to assign two alternating colors. If adjacent vertices require the same color, the graph is not bipartite.

Q6. What is the relationship between odd cycles and bipartite graphs?

An undirected graph is bipartite if and only if it contains no odd-length cycle.

Q7. Is a tree bipartite?

Yes. Every tree is bipartite because it contains no cycles.

Q8. Is a triangle bipartite?

No. A triangle contains an odd cycle of length 3.

Q9. Can a disconnected graph be bipartite?

Yes. Every connected component must be bipartite.

Q10. What is the time complexity of bipartite detection?

O(V + E) using an adjacency list.
