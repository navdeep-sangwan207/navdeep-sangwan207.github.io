Lesson 5: Cycle Detection in Graphs

Learn how to detect cycles in directed and undirected graphs using DFS and recursion-state tracking.

1. Learning Objectives

  • Understand cycles in graph structures.
  • Distinguish cycles in directed and undirected graphs.
  • Detect cycles in undirected graphs using DFS and parent tracking.
  • Detect cycles in directed graphs using recursion states.
  • Understand the role of visited and recursion-stack arrays.
  • Identify self-loops and parallel-edge considerations.
  • Analyze cycle detection complexity.
  • Prepare for common graph-cycle interview problems.

2. What Is a Cycle in a Graph?

A cycle is a path that starts and ends at the same vertex, with at least one edge, without repeating intermediate vertices in a simple cycle.

Example: Graph Containing a Cycle

       0
      / \
     1---2

The path 0 → 1 → 2 → 0 forms a cycle.

Example: Graph Without a Cycle

       0
       |
       1
       |
       2
       |
       3

This graph is a tree-like structure and contains no cycle.

A tree is a connected undirected graph with no cycles. Cycle detection is therefore an important operation in graph and tree-related problems.

3. Directed vs Undirected Cycle Detection

Undirected Graph

In an undirected graph, an edge can be traversed in both directions. 

0 --- 1
|     |
3 --- 2

The path 0 → 1 → 2 → 3 → 0 is a cycle.

Directed Graph

In a directed graph, every edge has a direction. 

0 → 1 → 2
↑       |
|       ↓
└─── 3 ←┘

A directed cycle exists when following the directed edges eventually returns to a vertex already on the current traversal path.

Feature Undirected Graph Directed Graph
Edge direction No direction Has direction
DFS cycle check Visited neighbor other than parent Neighbor currently in recursion path
Important tracking Visited and parent Visited and recursion state
Typical applications Road networks, connections Dependencies, prerequisites

4. Cycle Detection in an Undirected Graph Using DFS

For an undirected graph, when DFS visits a vertex, it examines all adjacent vertices.

If an adjacent vertex is already visited and is not the parent of the current vertex, a cycle exists.

Algorithm

  1. Start DFS from an unvisited vertex.
  2. Mark the current vertex as visited.
  3. Examine each adjacent vertex.
  4. If the neighbor is unvisited, recursively call DFS.
  5. If the neighbor is visited and is not the parent, a cycle exists.
  6. Repeat for every unvisited component.

Pseudocode

DFS(vertex, parent):

    Mark vertex as visited

    for each neighbor of vertex:

        if neighbor is not visited:

            if DFS(neighbor, vertex) detects cycle:
                return true

        else if neighbor is not parent:

            return true

    return false
Why check the parent? In an undirected graph, the edge used to reach the current vertex also appears as an adjacent edge back to its parent. That reverse edge is not a cycle.

5. Dry Run: Undirected Cycle Detection

Consider this graph:

0 --- 1

Edges:

(0,1), (1,2), (2,3), (3,0)

Start DFS from vertex 0.

Step Current Vertex Observation

6. Complete C11 Program: Undirected Cycle Detection

This implementation uses an adjacency matrix and recursive DFS. It checks every connected component. 

#include <stdio.h>

#define V 6

void addEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
    graph[v][u] = 1;
}

int hasCycleDFS(int graph[V][V],
                int vertex,
                int parent,
                int visited[V])
{
    int i;

    visited[vertex] = 1;

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1)
        {
            if (!visited[i])
            {
                if (hasCycleDFS(graph, i, vertex, visited))
                {
                    return 1;
                }
            }
            else if (i != parent)
            {
                return 1;
            }
        }
    }

    return 0;
}

int containsCycle(int graph[V][V])
{
    int visited[V] = {0};
    int i;

    for (i = 0; i < V; i++)
    {
        if (!visited[i])
        {
            if (hasCycleDFS(graph, i, -1, visited))
            {
                return 1;
            }
        }
    }

    return 0;
}

int main(void)
{
    int graph[V][V] = {0};

    addEdge(graph, 0, 1);
    addEdge(graph, 1, 2);
    addEdge(graph, 2, 3);
    addEdge(graph, 3, 0);

    addEdge(graph, 3, 4);

    if (containsCycle(graph))
    {
        printf("Cycle detected in undirected graph.\n");
    }
    else
    {
        printf("No cycle found.\n");
    }

    return 0;
}

Expected Output

Cycle detected in undirected graph.

Test Without a Cycle

Replace the graph construction in main with: 

addEdge(graph, 0, 1);
addEdge(graph, 1, 2);
addEdge(graph, 2, 3);
addEdge(graph, 3, 4);
No cycle found.

This implementation assumes a simple undirected graph: no parallel edges. A self-loop is detected as a cycle.

7. Cycle Detection in a Directed Graph Using DFS

The parent technique used for undirected graphs does not work for directed graphs.

Instead, use three states for every vertex:

State Meaning
0 – Unvisited DFS has not visited the vertex.
1 – Visiting Vertex is currently in the recursion path.
2 – Visited All outgoing edges have been explored.
A directed cycle is detected when DFS encounters an edge to a vertex whose state is 1, meaning that vertex is already in the current recursion path.

Algorithm

  1. Initialize all vertex states to 0.
  2. Start DFS from an unvisited vertex.
  3. Mark the current vertex as state 1.
  4. Explore every outgoing edge.
  5. If a neighbor has state 1, a cycle exists.
  6. If a neighbor has state 0, recursively explore it.
  7. After exploring all neighbors, mark the vertex state 2.

Pseudocode

DFS(vertex):

    state[vertex] = 1

    for each directed neighbor:

        if state[neighbor] == 1:
            return true

        if state[neighbor] == 0:

            if DFS(neighbor):
                return true

    state[vertex] = 2

    return false

9. Complete C11 Program: Directed Cycle Detection

This program uses a three-state DFS implementation with an adjacency matrix. 

#include <stdio.h>

#define V 6

enum
{
    UNVISITED,
    VISITING,
    VISITED
};

void addDirectedEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
}

int directedCycleDFS(int graph[V][V],
                     int vertex,
                     int state[V])
{
    int i;

    state[vertex] = VISITING;

    for (i = 0; i < V; i++)
    {
        if (graph[vertex][i] == 1)
        {
            if (state[i] == VISITING)
            {
                return 1;
            }

            if (state[i] == UNVISITED)
            {
                if (directedCycleDFS(graph, i, state))
                {
                    return 1;
                }
            }
        }
    }

    state[vertex] = VISITED;

    return 0;
}

int containsDirectedCycle(int graph[V][V])
{
    int state[V] = {UNVISITED};
    int i;

    for (i = 0; i < V; i++)
    {
        if (state[i] == UNVISITED)
        {
            if (directedCycleDFS(graph, i, state))
            {
                return 1;
            }
        }
    }

    return 0;
}

int main(void)
{
    int graph[V][V] = {0};

    addDirectedEdge(graph, 0, 1);
    addDirectedEdge(graph, 1, 2);
    addDirectedEdge(graph, 2, 3);
    addDirectedEdge(graph, 3, 1);

    if (containsDirectedCycle(graph))
    {
        printf("Cycle detected in directed graph.\n");
    }
    else
    {
        printf("No cycle found.\n");
    }

    return 0;
}

Expected Output

Cycle detected in directed graph.

Test Without a Cycle

addDirectedEdge(graph, 1, 2);
addDirectedEdge(graph, 2, 3);
addDirectedEdge(graph, 3, 4);
No cycle found.

10. Cycle Detection Using Kahn's Algorithm

Kahn's algorithm is a BFS-based topological sorting technique for directed graphs.

It repeatedly removes vertices with indegree zero. If every vertex can be removed, the directed graph contains no cycle.

If fewer than V vertices are processed, a directed cycle exists.

Basic Steps

  1. Calculate the indegree of every vertex.
  2. Insert all vertices with indegree zero into a queue.
  3. Remove a vertex from the queue and count it as processed.
  4. Decrease the indegree of its outgoing neighbors.
  5. Insert a neighbor when its indegree becomes zero.
  6. Compare the processed count with the total number of vertices.

Complete C11 Program

#include <stdio.h>

#define V 6

void addDirectedEdge(int graph[V][V], int u, int v)
{
    graph[u][v] = 1;
}

int hasCycleKahn(int graph[V][V])
{
    int indegree[V] = {0};
    int queue[V];
    int front = 0;
    int rear = 0;
    int processed = 0;
    int i, j, current;

    for (i = 0; i < V; i++)
    {
        for (j = 0; j < V; j++)
        {
            if (graph[i][j] == 1)
            {
                indegree[j]++;
            }
        }
    }

    for (i = 0; i < V; i++)
    {
        if (indegree[i] == 0)
        {
            queue[rear++] = i;
        }
    }

    while (front < rear)
    {
        current = queue[front++];
        processed++;

        for (j = 0; j < V; j++)
        {
            if (graph[current][j] == 1)
            {
                indegree[j]--;

                if (indegree[j] == 0)
                {
                    queue[rear++] = j;
                }
            }
        }
    }

    return processed != V;
}

int main(void)
{
    int graph[V][V] = {0};

    addDirectedEdge(graph, 0, 1);
    addDirectedEdge(graph, 1, 2);
    addDirectedEdge(graph, 2, 3);
    addDirectedEdge(graph, 3, 1);

    if (hasCycleKahn(graph))
    {
        printf("Cycle detected using Kahn's algorithm.\n");
    }
    else
    {
        printf("No cycle found using Kahn's algorithm.\n");
    }

    return 0;
}

Expected Output

Cycle detected using Kahn's algorithm.
With an adjacency list, Kahn's algorithm takes O(V + E) time. This adjacency-matrix implementation takes O(V²) time.

12. Special Cases and Common Mistakes

Self-loop

0 ↻

An edge from a vertex to itself is a cycle in both directed and undirected graph models.

Disconnected Graph

A cycle may exist in a component that is not reachable from vertex 0. Always check all unvisited vertices.

Parallel Edges

Multiple edges between the same pair of vertices require special handling in undirected multigraphs. The simple adjacency-matrix implementations in this lesson assume a simple graph and do not represent parallel edges.

Common Mistakes

  1. Using the undirected parent check for a directed graph.
  2. Forgetting to check all disconnected components.
  3. Not distinguishing the recursion-path state from fully visited state.
  4. Failing to detect self-loops.
  5. Assuming every visited neighbor indicates a directed cycle.
  6. Using Kahn's algorithm without correctly calculating indegrees.
  7. Ignoring graph representation assumptions about parallel edges.

13. Complexity Analysis

Let V represent vertices and E represent edges.

Algorithm Adjacency List Adjacency Matrix
Undirected DFS O(V + E) O(V²)
Directed DFS O(V + E) O(V²)
Kahn's algorithm O(V + E) O(V²)

Auxiliary space: O(V) for visited/state arrays and the recursion stack or queue, excluding graph storage.

14. Placement Interview Questions

Q1. What is a cycle in a graph?

A path that starts and ends at the same vertex.

Q2. How do you detect a cycle in an undirected graph?

Use DFS with a visited array and parent tracking. A visited neighbor other than the parent indicates a cycle.

Q3. How do you detect a cycle in a directed graph?

Use DFS with three states: unvisited, visiting and visited. An edge to a visiting vertex indicates a cycle.

Q4. Why is parent tracking required in undirected graphs?

Because the edge back to the parent is already present in an undirected graph and should not be treated as a cycle.

Q5. What is a recursion stack?

It is the collection of active recursive function calls. It helps identify vertices currently on the DFS path.

Q6. What are the three DFS states for directed cycle detection?

Unvisited, Visiting and Visited.

Q7. Can BFS detect a directed cycle?

Yes. Kahn's algorithm detects a cycle when it cannot process all vertices.

Q8. What is the time complexity of cycle detection using DFS?

O(V + E) with an adjacency list.

Q9. What is a self-loop?

An edge that connects a vertex to itself.

Q10. What is the relationship between DAGs and cycles?

A Directed Acyclic Graph (DAG) is a directed graph containing no directed cycle.

17. Lesson Summary

  • A cycle is a path that returns to its starting vertex.
  • Undirected cycle detection commonly uses DFS with parent tracking.
  • Directed cycle detection uses recursion-path states.
  • Kahn's algorithm can detect directed cycles using indegrees.
  • Disconnected components must all be checked.
  • Adjacency-list implementations run in O(V + E) time.
  • A DAG is a directed graph without directed cycles.
