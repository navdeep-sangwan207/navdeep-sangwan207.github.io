2. What Is a Graph?

A graph is a non-linear data structure consisting of a collection of vertices and edges connecting those vertices.

A graph is mathematically represented as:

G = (V, E)

V = Set of vertices
E = Set of edges

A vertex represents an entity, while an edge represents a relationship or connection between two entities.

Example

       A
      / \
     B---C
      \
       D

Vertices:

V = {A, B, C, D}

Edges:

E = {(A,B), (A,C), (B,C), (B,D)}

Here, four vertices are connected by four edges.

Interview definition: A graph is a collection of vertices and edges that represents relationships between different entities.

3. Basic Graph Terminology

3.1 Vertex (Node)

A vertex is an individual element or point in a graph. It represents an object, location or entity.

3.2 Edge

An edge is a connection between two vertices. In an undirected graph, the connection has no direction. In a directed graph, the connection has a direction.

3.3 Adjacent Vertices

Two vertices are adjacent if an edge directly connects them.

3.4 Incident Edge

An edge is incident on a vertex if that vertex is one of the edge's endpoints.

3.5 Degree of a Vertex

In an undirected graph, the degree of a vertex is the number of edges connected to it. A self-loop contributes two to the degree. 

Example:

A --- B
|     |
C --- D

Degree(A) = 2
Degree(B) = 2
Degree(C) = 2
Degree(D) = 2

3.6 In-Degree and Out-Degree

In a directed graph:

  • In-degree: Number of incoming edges.
  • Out-degree: Number of outgoing edges.
A ----> B
^       |
|       v
C <---- D

For B:
In-degree = 1
Out-degree = 1

3.7 Path

A path is a sequence of vertices connected through edges. 

A -- B -- C -- D

A to D:
A -> B -> C -> D

3.8 Path Length

In an unweighted graph, path length is the number of edges in the path.

3.9 Cycle

A cycle is a path that starts and ends at the same vertex, with at least one edge. 

A --- B
|     |
D --- C

A -> B -> C -> D -> A

3.10 Self-Loop

A self-loop is an edge that connects a vertex to itself. 

A ---- B
|
|____
     |
     A

3.11 Parallel Edges

Parallel edges are multiple edges connecting the same pair of vertices.

3.12 Connected Vertices

Two vertices are connected if there is a path between them.

4. Types of Graphs

4.1 Undirected Graph

An undirected graph contains edges without direction. If A is connected to B, the connection works both ways. 

A ----- B
|       |
|       |
C ----- D

Example applications:

  • Friendship networks.
  • Two-way road networks.
  • Physical network connections.

4.2 Directed Graph (Digraph)

A directed graph contains edges with direction. A connection from A to B does not automatically imply a connection from B to A. 

A ----> B
^       |
|       v
D <---- C

Applications:

  • Web page links.
  • Task dependencies.
  • One-way road networks.
  • Following relationships in social networks.

4.3 Weighted Graph

A weighted graph assigns a numerical weight or cost to every edge. 

A --5-- B
|       |
2       7
|       |
C --3-- D

Weights may represent:

  • Distance.
  • Travel time.
  • Network cost.
  • Communication delay.

4.4 Unweighted Graph

An unweighted graph does not assign a separate cost to its edges. Every edge is generally treated equally when calculating the number of edges in a path.

4.5 Connected Graph

An undirected graph is connected if a path exists between every pair of vertices.

4.6 Disconnected Graph

An undirected graph is disconnected if at least one pair of vertices has no connecting path. 

A --- B       C --- D

Component 1   Component 2

4.7 Complete Graph

A simple undirected graph is complete if every pair of distinct vertices is connected by an edge.

Number of edges in a complete undirected graph:

E = V(V - 1) / 2

4.8 Cyclic and Acyclic Graphs

  • Cyclic graph: Contains at least one cycle.
  • Acyclic graph: Contains no cycles.

4.9 Directed Acyclic Graph (DAG)

A DAG is a directed graph that contains no directed cycles. It is commonly used for task dependencies and scheduling.

4.10 Sparse and Dense Graphs

  • Sparse graph: Has relatively few edges compared with the maximum possible.
  • Dense graph: Has a large number of edges relative to the maximum possible.

5. Important Graph Properties

5.1 Handshaking Lemma

In an undirected graph, the sum of degrees of all vertices is twice the number of edges. 

Sum of degrees = 2E

Example:

A ----- B
|       |
C ----- D

Each of the four vertices has degree 2. 

Sum of degrees = 2 + 2 + 2 + 2
               = 8

Number of edges = 4

2E = 2 * 4 = 8

5.2 Maximum Edges in a Simple Undirected Graph

Emax = V(V - 1) / 2

5.3 Maximum Edges in a Simple Directed Graph

Emax = V(V - 1)

These formulas assume no self-loops and no parallel edges.

5.4 Tree Property

A tree is a connected, undirected, acyclic graph. A tree with V vertices has exactly V - 1 edges.

Every tree is a graph, but not every graph is a tree.

6. Graph vs Tree

Feature Graph Tree
Structure General non-linear structure Connected acyclic structure
Cycles May contain cycles No cycles
Connectivity May be disconnected Connected
Edges Variable number V - 1
Direction May be directed or undirected Usually represented as an undirected graph in basic graph theory
Unique path Not guaranteed Exactly one simple path between every pair of vertices

8. Basic Graph Representation Using C

Before studying adjacency matrices and adjacency lists in detail, understand how a graph can be described using a list of edges.

Example Graph

Vertices = 5

Edges:
0 -- 1
0 -- 2
1 -- 3
2 -- 4

Complete C11 Program: Store and Display Edges

#include <stdio.h>

#define MAX_VERTICES 100
#define MAX_EDGES 200

typedef struct
{
    int source;
    int destination;
} Edge;

int main(void)
{
    Edge edges[MAX_EDGES];

    int vertices = 5;
    int edgeCount = 4;
    int i;

    if (vertices <= 0 || vertices > MAX_VERTICES ||
        edgeCount < 0 || edgeCount > MAX_EDGES)
    {
        printf("Invalid graph dimensions.\n");
        return 1;
    }

    edges[0].source = 0;
    edges[0].destination = 1;

    edges[1].source = 0;
    edges[1].destination = 2;

    edges[2].source = 1;
    edges[2].destination = 3;

    edges[3].source = 2;
    edges[3].destination = 4;

    printf("Vertices: %d\n", vertices);
    printf("Edges:\n");

    for (i = 0; i < edgeCount; i++)
    {
        printf("%d -- %d\n",
               edges[i].source,
               edges[i].destination);
    }

    return 0;
}

Expected Output

Vertices: 5
Edges:
0 -- 1
0 -- 2
1 -- 3
2 -- 4

Complexity:

  • Storing E edges: O(E).
  • Displaying all edges: O(E).
  • Space: O(E) for the edge array.
This is an edge-list representation. It is useful for algorithms such as Kruskal's minimum spanning tree. The next lesson compares adjacency matrices and adjacency lists.

10. Placement Interview Questions

Q1. What is a graph?

A graph is a non-linear data structure consisting of vertices and edges representing relationships.

Q2. What is the difference between directed and undirected graphs?

Directed graph edges have direction. Undirected graph edges represent bidirectional connections.

Q3. What is a weighted graph?

A graph in which each edge has an associated weight such as distance or cost.

Q4. What is a DAG?

A directed acyclic graph is a directed graph that contains no directed cycle.

Q5. What is the maximum number of edges in a simple undirected graph with V vertices?

V(V - 1) / 2.

Q6. What is the relationship between vertices and edges in a tree?

A tree with V vertices has V - 1 edges.

Q7. What is the handshaking lemma?

The sum of degrees of all vertices in an undirected graph equals twice the number of edges.

Q8. Can a graph contain multiple connected components?

Yes. Such a graph is disconnected.

Q9. What is a self-loop?

An edge connecting a vertex to itself.

Q10. What is the difference between a path and a cycle?

A path connects a sequence of vertices. A cycle is a closed path that returns to its starting vertex.

  • A graph is represented as G = (V, E).
  • Vertices represent entities and edges represent connections.
  • Graphs can be directed, undirected, weighted or unweighted.
  • Degree describes the number of incident edges.
  • Directed graphs use in-degree and out-degree.
  • A connected graph has a path between every pair of vertices.
  • A DAG is a directed graph without directed cycles.
  • A tree with V vertices has V - 1 edges.
  • The handshaking lemma states that the sum of degrees is 2E.
