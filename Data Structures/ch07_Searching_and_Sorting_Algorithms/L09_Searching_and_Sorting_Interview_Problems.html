2. Problem 1: Search in a Rotated Sorted Array

Problem Statement

An ascending sorted array is rotated at an unknown pivot. Find the index of a given target value.

Example

Array: 4 5 6 7 0 1 2 Target: 0
Output: Index = 4

Approach

Use modified Binary Search. At least one half of the current search interval is sorted.

Algorithm

  1. Calculate the middle index.
  2. If the middle element equals the target, return its index.
  3. Determine which half is sorted.
  4. Check whether the target belongs to that sorted half.
  5. Discard the other half and repeat.

Complete C11 Program

#include <stdio.h>

int searchRotated(const int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (arr[low] <= arr[mid])
        {
            if (target >= arr[low] &&
                target < arr[mid])
            {
                high = mid - 1;
            }
            else
            {
                low = mid + 1;
            }
        }
        else
        {
            if (target > arr[mid] &&
                target <= arr[high])
            {
                low = mid + 1;
            }
            else
            {
                high = mid - 1;
            }
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {4, 5, 6, 7, 0, 1, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    int target = 0;

    int result = searchRotated(arr, n, target);

    printf("Target index: %d\n", result);

    return 0;
}

Expected Output

Target index: 4

Complexity

  • Time: O(log n), when the elements are distinct.
  • Auxiliary space: O(1).
This implementation assumes distinct array elements. With duplicates, deciding which half is sorted can become ambiguous; a duplicate-aware version may require O(n) worst-case time.

3. Problem 2: Sort an Array Containing 0s, 1s and 2s

Problem Statement

Sort an array containing only 0, 1 and 2 without using a general-purpose sorting algorithm.

Example

Input: 2 0 2 1 1 0 Output: 0 0 1 1 2 2

Approach: Dutch National Flag Algorithm

Use three pointers:

  • low: boundary of the 0 region.
  • mid: current element.
  • high: boundary of the 2 region.

Algorithm

  1. If arr[mid] is 0, swap it with arr[low] and increment both low and mid.
  2. If arr[mid] is 1, increment mid.
  3. If arr[mid] is 2, swap it with arr[high] and decrement high.
  4. Continue until mid exceeds high.

Complete C11 Program

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void sort012(int arr[], int n)
{
    int low = 0;
    int mid = 0;
    int high = n - 1;

    while (mid <= high)
    {
        if (arr[mid] == 0)
        {
            swap(&arr[low], &arr[mid]);
            low++;
            mid++;
        }
        else if (arr[mid] == 1)
        {
            mid++;
        }
        else if (arr[mid] == 2)
        {
            swap(&arr[mid], &arr[high]);
            high--;
        }
        else
        {
            printf("Invalid array value: %d\n", arr[mid]);
            return;
        }
    }
}

int main(void)
{
    int arr[] = {2, 0, 2, 1, 1, 0};
    int n = sizeof(arr) / sizeof(arr[0]);

    sort012(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 0 0 1 1 2 2

Complexity

  • Time: O(n).
  • Auxiliary space: O(1).
This is a frequently asked placement problem because it tests three-pointer partitioning and in-place sorting.

4. Problem 3: Merge Overlapping Intervals

Problem Statement

Given a collection of intervals, merge all intervals that overlap.

Example

Input: [1,3] [2,6] [8,10] [9,12] Output: [1,6] [8,12]

Approach

  1. Sort intervals by their starting values.
  2. Maintain the most recently merged interval.
  3. If the next interval overlaps, extend the ending value.
  4. Otherwise, save the current interval and start a new one.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct
{
    int start;
    int end;
} Interval;

int compareIntervals(const void *a, const void *b)
{
    const Interval *x = a;
    const Interval *y = b;

    if (x->start < y->start)
        return -1;

    if (x->start > y->start)
        return 1;

    if (x->end < y->end)
        return -1;

    if (x->end > y->end)
        return 1;

    return 0;
}

int mergeIntervals(Interval arr[], int n)
{
    if (n <= 0)
        return 0;

    qsort(arr, (size_t)n, sizeof(arr[0]),
          compareIntervals);

    int merged = 0;

    for (int i = 0; i < n; i++)
    {
        if (arr[i].start > arr[i].end)
            return -1;

        if (merged == 0 ||
            arr[i].start > arr[merged - 1].end)
        {
            arr[merged++] = arr[i];
        }
        else if (arr[i].end > arr[merged - 1].end)
        {
            arr[merged - 1].end = arr[i].end;
        }
    }

    return merged;
}

int main(void)
{
    Interval arr[] =
    {
        {1, 3},
        {2, 6},
        {8, 10},
        {9, 12}
    };

    int n = sizeof(arr) / sizeof(arr[0]);

    int count = mergeIntervals(arr, n);

    if (count < 0)
    {
        printf("Invalid interval\n");
        return 1;
    }

    printf("Merged intervals:\n");

    for (int i = 0; i < count; i++)
    {
        printf("[%d, %d] ", arr[i].start, arr[i].end);
    }

    printf("\n");

    return 0;
}

Expected Output

Merged intervals: [1, 6] [8, 12]

Complexity

  • Sorting: O(n log n).
  • Merging: O(n).
  • Overall: O(n log n).
  • Auxiliary space: O(1) for the merging pass, excluding the implementation-dependent workspace used by qsort().
This implementation treats intervals sharing an endpoint as overlapping. For example, [1, 3] and [3, 5] merge into [1, 5].

5. Problem 4: Count Inversions Using Merge Sort

Problem Statement

An inversion is a pair of indexes (i, j) such that:

i < j arr[i] > arr[j]

Count the total number of inversions in an array.

Example

Input: 2 4 1 3 5 Inversions: (2,1) (4,1) (4,3) Output: 3

Approach

Use Merge Sort. When an element from the right half is placed before remaining elements of the left half, each of those remaining left elements forms an inversion with it.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

long long mergeAndCount(
    int arr[], int temp[],
    int left, int mid, int right)
{
    int i = left;
    int j = mid + 1;
    int k = left;

    long long inversions = 0;

    while (i <= mid && j <= right)
    {
        if (arr[i] <= arr[j])
        {
            temp[k++] = arr[i++];
        }
        else
        {
            temp[k++] = arr[j++];
            inversions += (long long)(mid - i + 1);
        }
    }

    while (i <= mid)
        temp[k++] = arr[i++];

    while (j <= right)
        temp[k++] = arr[j++];

    for (i = left; i <= right; i++)
        arr[i] = temp[i];

    return inversions;
}

long long mergeSortAndCount(
    int arr[], int temp[],
    int left, int right)
{
    if (left >= right)
        return 0;

    int mid = left + (right - left) / 2;

    long long count = 0;

    count += mergeSortAndCount(
        arr, temp, left, mid);

    count += mergeSortAndCount(
        arr, temp, mid + 1, right);

    count += mergeAndCount(
        arr, temp, left, mid, right);

    return count;
}

int main(void)
{
    int arr[] = {2, 4, 1, 3, 5};

    size_t n = sizeof(arr) / sizeof(arr[0]);

    if (n > (size_t)2147483647)
    {
        printf("Array too large for this implementation\n");
        return 1;
    }

    int *temp = malloc(n * sizeof(*temp));

    if (temp == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    long long count = mergeSortAndCount(
        arr, temp, 0, (int)n - 1);

    printf("Inversion count: %lld\n", count);

    printf("Sorted array: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    free(temp);

    return 0;
}

Expected Output

Inversion count: 3 Sorted array: 1 2 3 4 5

Complexity

  • Time: O(n log n).
  • Auxiliary space: O(n) for the temporary array, plus O(log n) recursion stack.

6. Problem 5: Kth Smallest Element Using Quickselect

Problem Statement

Find the Kth smallest element in an unsorted array without fully sorting the array.

Example

Array: 7 10 4 3 20 15 K = 3 Sorted order: 3 4 7 10 15 20 Output: 7

Approach

Quickselect uses partitioning similar to Quick Sort.

  1. Select a pivot.
  2. Partition the array around the pivot.
  3. Determine the pivot's final index.
  4. Continue searching only in the side containing the required index.

Complete C11 Program

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int partition(int arr[], int low, int high)
{
    int pivot = arr[high];
    int i = low;

    for (int j = low; j < high; j++)
    {
        if (arr[j] <= pivot)
        {
            swap(&arr[i], &arr[j]);
            i++;
        }
    }

    swap(&arr[i], &arr[high]);

    return i;
}

int quickSelect(
    int arr[], int low, int high, int target)
{
    while (low <= high)
    {
        int pivotIndex = partition(arr, low, high);

        if (pivotIndex == target)
            return arr[pivotIndex];

        if (pivotIndex > target)
            high = pivotIndex - 1;
        else
            low = pivotIndex + 1;
    }

    return 0;
}

int main(void)
{
    int arr[] = {7, 10, 4, 3, 20, 15};

    int n = sizeof(arr) / sizeof(arr[0]);
    int k = 3;

    if (k < 1 || k > n)
    {
        printf("Invalid K\n");
        return 1;
    }

    int result = quickSelect(
        arr, 0, n - 1, k - 1);

    printf("Kth smallest element: %d\n", result);

    return 0;
}

Expected Output

Kth smallest element: 7

Complexity

  • Average time: O(n).
  • Worst-case time: O(n²).
  • Auxiliary space: O(1) for this iterative implementation.
The program uses the last element as pivot, so an unfavorable pivot sequence can produce O(n²) time. Randomized pivot selection is a common practical improvement.

7. Problem 6: Find the Kth Largest Element Using a Min Heap

Problem Statement

Find the Kth largest element in an unsorted array.

Example

Array: 3 2 1 5 6 4 K = 2 Sorted descending: 6 5 4 3 2 1 Output: 5

Approach

Maintain a min heap containing the K largest elements encountered so far. Its root is the Kth largest element.

Complete C11 Program

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void minHeapify(int heap[], int size, int i)
{
    int smallest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < size &&
        heap[left] < heap[smallest])
        smallest = left;

    if (right < size &&
        heap[right] < heap[smallest])
        smallest = right;

    if (smallest != i)
    {
        swap(&heap[i], &heap[smallest]);
        minHeapify(heap, size, smallest);
    }
}

int kthLargest(const int arr[], int n, int k)
{
    if (k < 1 || k > n)
        return 0;

    int heap[k];

    for (int i = 0; i < k; i++)
        heap[i] = arr[i];

    for (int i = k / 2 - 1; i >= 0; i--)
        minHeapify(heap, k, i);

    for (int i = k; i < n; i++)
    {
        if (arr[i] > heap[0])
        {
            heap[0] = arr[i];
            minHeapify(heap, k, 0);
        }
    }

    return heap[0];
}

int main(void)
{
    int arr[] = {3, 2, 1, 5, 6, 4};

    int n = sizeof(arr) / sizeof(arr[0]);
    int k = 2;

    int result = kthLargest(arr, n, k);

    if (k < 1 || k > n)
    {
        printf("Invalid K\n");
        return 1;
    }

    printf("Kth largest element: %d\n", result);

    return 0;
}

Expected Output

Kth largest element: 5

Complexity

  • Heap construction: O(k).
  • Processing remaining elements: O((n-k) log k).
  • Overall: O(n log k).
  • Auxiliary space: O(k).
The example returns 0 as an invalid-input sentinel. A production-quality API should return a separate success/error status and write the answer through an output pointer, because 0 can also be a valid array element.

8. Problem 7: Minimum Number of Meeting Rooms

Problem Statement

Given meeting start and end times, determine the minimum number of rooms required so that no overlapping meetings share a room.

Example

Meetings: [0, 30] [5, 10] [15, 20] Output: 2 rooms

Approach

Sort start times and end times separately. Track how many meetings are active at each point.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

int compareInt(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

int minimumRooms(
    const int start[], const int end[], int n)
{
    if (n <= 0)
        return 0;

    int *starts = malloc((size_t)n * sizeof(*starts));
    int *ends = malloc((size_t)n * sizeof(*ends));

    if (starts == NULL || ends == NULL)
    {
        free(starts);
        free(ends);
        return -1;
    }

    for (int i = 0; i < n; i++)
    {
        if (start[i] >= end[i])
        {
            free(starts);
            free(ends);
            return -1;
        }

        starts[i] = start[i];
        ends[i] = end[i];
    }

    qsort(starts, (size_t)n, sizeof(starts[0]), compareInt);
    qsort(ends, (size_t)n, sizeof(ends[0]), compareInt);

    int i = 0;
    int j = 0;
    int active = 0;
    int maximum = 0;

    while (i < n)
    {
        if (active == 0 || starts[i] < ends[j])
        {
            active++;
            i++;

            if (active > maximum)
                maximum = active;
        }
        else
        {
            active--;
            j++;
        }
    }

    free(starts);
    free(ends);

    return maximum;
}

int main(void)
{
    int start[] = {0, 5, 15};
    int end[] = {30, 10, 20};

    int n = sizeof(start) / sizeof(start[0]);

    int result = minimumRooms(start, end, n);

    if (result < 0)
    {
        printf("Invalid input or allocation failure\n");
        return 1;
    }

    printf("Minimum rooms required: %d\n", result);

    return 0;
}

Expected Output

Minimum rooms required: 2

Complexity

  • Time: O(n log n).
  • Auxiliary space: O(n).
This implementation treats a meeting ending at time T as releasing its room for another meeting starting at exactly T. That is why the comparison uses starts[i] < ends[j].

9. Problem 8: Search in a Nearly Sorted Array

Problem Statement

In a nearly sorted array, each element may be displaced from its correct sorted position by at most one position.

Example

Array: 10 3 40 20 50 80 70 Target: 40 Output: Index = 2

Approach

At each midpoint, check the middle element and its immediate neighbors.

Complete C11 Program

#include <stdio.h>

int searchNearlySorted(
    const int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (mid > low && arr[mid - 1] == target)
            return mid - 1;

        if (mid < high && arr[mid + 1] == target)
            return mid + 1;

        if (target < arr[mid])
            high = mid - 2;
        else
            low = mid + 2;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 3, 40, 20, 50, 80, 70};

    int n = sizeof(arr) / sizeof(arr[0]);
    int target = 40;

    printf("Index: %d\n",
           searchNearlySorted(arr, n, target));

    return 0;
}

Expected Output

Index: 2

Complexity

  • Time: O(log n).
  • Auxiliary space: O(1).

10. Problem 9: Find the Median of Two Sorted Arrays

Problem Statement

Given two sorted arrays, find the median of the combined sorted sequence without fully merging the arrays.

Example

Array 1: 1 3 Array 2: 2 Combined order: 1 2 3 Median: 2.0

Approach

Use Binary Search on the smaller array to find a partition that divides the combined elements into left and right halves.

At the correct partition:

  • Every element on the left is less than or equal to every element on the right.
  • The left side contains the same number of elements as the right side, or one additional element.

Complete C11 Program

#include <stdio.h>
#include <limits.h>

double medianTwoSorted(
    const int a[], int m,
    const int b[], int n)
{
    if (m > n)
        return medianTwoSorted(b, n, a, m);

    if (m + n == 0)
        return 0.0;

    int low = 0;
    int high = m;

    while (low <= high)
    {
        int i = low + (high - low) / 2;
        int j = (m + n + 1) / 2 - i;

        int leftA = (i == 0) ? INT_MIN : a[i - 1];
        int rightA = (i == m) ? INT_MAX : a[i];

        int leftB = (j == 0) ? INT_MIN : b[j - 1];
        int rightB = (j == n) ? INT_MAX : b[j];

        if (leftA <= rightB && leftB <= rightA)
        {
            int leftMax =
                (leftA > leftB) ? leftA : leftB;

            if ((m + n) % 2 == 1)
                return (double)leftMax;

            int rightMin =
                (rightA < rightB) ? rightA : rightB;

            return ((double)leftMax + (double)rightMin) / 2.0;
        }

        if (leftA > rightB)
            high = i - 1;
        else
            low = i + 1;
    }

    return 0.0;
}

int main(void)
{
    int a[] = {1, 3};
    int b[] = {2};

    int m = sizeof(a) / sizeof(a[0]);
    int n = sizeof(b) / sizeof(b[0]);

    double median = medianTwoSorted(a, m, b, n);

    printf("Median: %.2f\n", median);

    return 0;
}

Expected Output

Median: 2.00

Complexity

  • Time: O(log(min(m, n))).
  • Auxiliary space: O(1).
This implementation assumes both arrays are sorted in ascending order, their lengths fit in int, and their combined length does not overflow int. The 0.0 return value is an illustrative invalid-input sentinel; a production API should return a status separately from the median.

12. Common Placement Interview Questions

Q1. What is the difference between Quick Sort and Quickselect?

Quick Sort recursively sorts both partitions. Quickselect continues only in the partition containing the required Kth position.

Q2. What is an inversion in an array?

A pair (i, j) where i is less than j but arr[i] is greater than arr[j].

Q3. What is the Dutch National Flag algorithm?

An in-place three-way partitioning algorithm commonly used to sort arrays containing 0, 1 and 2.

Q4. Why is Merge Sort useful for counting inversions?

During merging, it can count multiple inversions at once rather than checking every pair individually.

Q5. What is Quickselect?

A selection algorithm based on partitioning that finds an order statistic without completely sorting the array.

Q6. What is a rotated sorted array?

An originally sorted array whose elements have been shifted around a pivot.

Q7. How do you merge overlapping intervals?

Sort by starting point, then merge each interval with the last merged interval when they overlap.

Q8. How do you find the Kth largest element efficiently?

A min heap of size K gives O(n log k) time. Quickselect is another average O(n) option.

Q9. What is the meeting rooms problem?

It asks for the maximum number of simultaneous meetings, which determines the minimum number of rooms required.

Q10. How can you search in a nearly sorted array?

Check the middle element and its immediate neighbors before eliminating a portion of the search interval.

Q11. What is the complexity of counting inversions using Merge Sort?

O(n log n) time and O(n) auxiliary storage.

Q12. What is the average complexity of Quickselect?

O(n), although its worst-case complexity is O(n²) with unfavorable pivot choices.

Q13. Why use a heap for the Kth largest element?

A size-K min heap maintains only the K largest elements seen so far, with its root representing the Kth largest.

Q14. Can Binary Search be applied to an unsorted array?

Not directly. Standard Binary Search requires sorted data or another proven monotonic search condition.

Q15. What is the median of an array?

The middle value after sorting; for an even number of elements, it is the average of the two middle values.

Q16. What is the advantage of a two-pointer technique?

It can reduce extra storage and avoid repeated nested scans in suitable problems.

Q17. What is the time complexity of merging two sorted arrays?

O(n + m), where n and m are their respective lengths.

Q18. What is the difference between lower bound and upper bound?

Lower bound finds the first position whose value is greater than or equal to the target. Upper bound finds the first position whose value is strictly greater.

Q19. Can Quickselect modify the original array?

Yes. Its partitioning process rearranges elements in place.

Q20. Which searching and sorting topics should freshers prioritize?

Binary Search, sorting fundamentals, two pointers, merge intervals, Quickselect, hashing-assisted sorting problems and complexity analysis.
