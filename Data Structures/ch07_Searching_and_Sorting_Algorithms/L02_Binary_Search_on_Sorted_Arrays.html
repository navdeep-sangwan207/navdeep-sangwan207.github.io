2. Why Do We Need Binary Search Variations?

Ordinary Binary Search finds a matching element in a sorted array. However, when duplicates exist, it may return any matching index.

Array = {2, 4, 4, 4, 4, 7, 9} Target = 4 First occurrence = index 1 Last occurrence = index 4 Count = 4

Placement problems frequently ask for a particular boundary rather than just any matching element.

3. First Occurrence of an Element

Find the smallest index at which the target appears in a sorted array.

Algorithm

  1. Initialize low = 0 and high = n - 1.
  2. Calculate mid.
  3. If arr[mid] equals target, store mid as a possible answer.
  4. Continue searching the left half.
  5. If arr[mid] is smaller, search the right half.
  6. If arr[mid] is greater, search the left half.
  7. Return the stored answer.

Complete C11 Program

#include <stdio.h>

int firstOccurrence(const int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;
    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
        {
            answer = mid;
            high = mid - 1;
        }
        else if (arr[mid] < target)
        {
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return answer;
}

int main(void)
{
    int arr[] = {2, 4, 4, 4, 4, 7, 9};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target = 4;

    printf("First occurrence = %d\n",
           firstOccurrence(arr, n, target));

    return 0;
}

Expected Output

First occurrence = 1
Key idea: Finding a match does not end the search. Continue towards the left to find the earliest occurrence.

5. Count Occurrences in a Sorted Array

The number of occurrences can be calculated using the first and last occurrence indices.

Count = Last occurrence - First occurrence + 1

If the target is absent, the count is zero.

Complete C11 Program

#include <stdio.h>

int firstOccurrence(const int arr[], int n, int target)
{
    int low = 0, high = n - 1, answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
        {
            answer = mid;
            high = mid - 1;
        }
        else if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return answer;
}

int lastOccurrence(const int arr[], int n, int target)
{
    int low = 0, high = n - 1, answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
        {
            answer = mid;
            low = mid + 1;
        }
        else if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return answer;
}

int countOccurrences(const int arr[], int n, int target)
{
    int first = firstOccurrence(arr, n, target);

    if (first == -1)
        return 0;

    int last = lastOccurrence(arr, n, target);

    return last - first + 1;
}

int main(void)
{
    int arr[] = {1, 2, 2, 2, 2, 3, 4, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Occurrences of 2 = %d\n",
           countOccurrences(arr, n, 2));

    printf("Occurrences of 8 = %d\n",
           countOccurrences(arr, n, 8));

    return 0;
}

Expected Output

Occurrences of 2 = 4 Occurrences of 8 = 0

Time complexity: O(log n), because two Binary Searches are performed.

6. Lower Bound

Lower Bound is the index of the first element that is greater than or equal to the target.

Array = {1, 2, 4, 4, 4, 6, 8} Target = 4 Lower Bound = index 2

If every element is smaller than the target, the result is n.

Complete C11 Program

#include <stdio.h>

int lowerBound(const int arr[], int n, int target)
{
    int low = 0;
    int high = n;

    while (low < high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid;
    }

    return low;
}

int main(void)
{
    int arr[] = {1, 2, 4, 4, 4, 6, 8};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Lower bound of 4 = %d\n",
           lowerBound(arr, n, 4));

    printf("Lower bound of 5 = %d\n",
           lowerBound(arr, n, 5));

    return 0;
}

Expected Output

Lower bound of 4 = 2 Lower bound of 5 = 5
Notice that high starts at n, not n - 1. This allows the algorithm to return n when no element is greater than or equal to the target.

9. Insertion Position

Find the index where a target should be inserted to maintain ascending sorted order. If the target already exists, this implementation returns its first occurrence.

Complete C11 Program

#include <stdio.h>

int searchInsert(const int arr[], int n, int target)
{
    int low = 0;
    int high = n;

    while (low < high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid;
    }

    return low;
}

int main(void)
{
    int arr[] = {1, 3, 5, 6};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Position for 5 = %d\n",
           searchInsert(arr, n, 5));

    printf("Position for 2 = %d\n",
           searchInsert(arr, n, 2));

    printf("Position for 7 = %d\n",
           searchInsert(arr, n, 7));

    return 0;
}

Expected Output

Position for 5 = 2 Position for 2 = 1 Position for 7 = 4

10. Floor and Ceiling in a Sorted Array

Floor

The floor of a target is the greatest element that is less than or equal to the target.

Ceiling

The ceiling of a target is the smallest element that is greater than or equal to the target.

Array = {1, 3, 5, 7, 9} Target = 6 Floor = 5 Ceiling = 7

Complete C11 Program

#include <stdio.h>

int floorIndex(const int arr[], int n, int target)
{
    int low = 0, high = n - 1;
    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] <= target)
        {
            answer = mid;
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return answer;
}

int ceilingIndex(const int arr[], int n, int target)
{
    int low = 0, high = n - 1;
    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] >= target)
        {
            answer = mid;
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    return answer;
}

int main(void)
{
    int arr[] = {1, 3, 5, 7, 9};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target = 6;

    int f = floorIndex(arr, n, target);
    int c = ceilingIndex(arr, n, target);

    if (f == -1)
        printf("Floor does not exist\n");
    else
        printf("Floor = %d\n", arr[f]);

    if (c == -1)
        printf("Ceiling does not exist\n");
    else
        printf("Ceiling = %d\n", arr[c]);

    return 0;
}

Expected Output

Floor = 5 Ceiling = 7

Returning an index instead of a value makes it possible to distinguish a missing floor or ceiling from a legitimate value such as -1.

11. Binary Search in a Descending Sorted Array

Binary Search also works on descending arrays. The comparison directions must be reversed.

Complete C11 Program

#include <stdio.h>

int descendingBinarySearch(
    const int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid;

        if (target > arr[mid])
            high = mid - 1;
        else
            low = mid + 1;
    }

    return -1;
}

int main(void)
{
    int arr[] = {90, 70, 50, 30, 10};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Index = %d\n",
           descendingBinarySearch(arr, n, 50));

    return 0;
}

Expected Output

Index = 2

13. Common Mistakes

  • Stopping immediately after finding a duplicate when the question asks for its first or last occurrence.
  • Confusing lower bound with upper bound.
  • Using high = n - 1 in a lower-bound implementation that uses the half-open interval [low, high).
  • Forgetting that lower bound and upper bound can return n.
  • Returning a value when the problem expects an index.
  • Applying ascending-order comparisons to a descending array.
  • Using an incorrect formula for counting duplicate values.

14. Placement Interview Questions and Answers

Q1. What is the first occurrence of an element?

The smallest index where the target appears in a sorted array.

Q2. How do you find the last occurrence?

After finding a match, continue searching the right half while storing the latest matching index.

Q3. How do you count duplicates in a sorted array?

Use last occurrence - first occurrence + 1, provided the target exists.

Q4. Define lower bound.

It is the first index whose element is greater than or equal to the target.

Q5. Define upper bound.

It is the first index whose element is strictly greater than the target.

Q6. How are lower bound and upper bound used to count duplicates?

Subtract lower bound from upper bound.

Q7. Can lower bound return n?

Yes. It returns n when every element is smaller than the target.

Q8. Can upper bound return n?

Yes. It returns n when no element is greater than the target.

Q9. What is an insertion position?

It is the position where a target can be inserted while preserving sorted order.

Q10. What is the difference between floor and ceiling?

Floor is the greatest value less than or equal to the target; ceiling is the smallest value greater than or equal to it.

Q11. What is the complexity of finding the first occurrence?

O(log n) time and O(1) auxiliary space using an iterative implementation.

Q12. Can Binary Search work with duplicate values?

Yes. Modified Binary Search can locate the first and last matching positions.

Q13. Why does lower bound use high = n?

It uses a half-open interval so that n can represent the position after the final element.

Q14. What is the difference between [low, high] and [low, high)?

The first interval includes both endpoints; the second includes low but excludes high.

Q15. Can we use Binary Search on a descending array?

Yes, if the comparison directions are adapted to descending order.

Q16. What is the relationship between lower bound and first occurrence?

For a sorted array, if the lower-bound index is less than n and its element equals the target, it is the first occurrence.

Q17. What is the relationship between upper bound and last occurrence?

If the target exists, its last occurrence is one position before the upper-bound index.

Q18. What is the complexity of counting occurrences with two Binary Searches?

O(log n), because two logarithmic searches still have logarithmic combined complexity.

Q19. How do you handle an empty array?

Lower bound and upper bound return 0. First and last occurrence return -1.

Q20. Which Binary Search variation is useful for insertion problems?

Lower Bound, because it identifies the first position where the target can be placed without breaking ascending order.

17. Lesson Summary

  • First occurrence locates the earliest matching index.
  • Last occurrence locates the latest matching index.
  • Count = last - first + 1 when the target exists.
  • Lower bound finds the first element greater than or equal to the target.
  • Upper bound finds the first element strictly greater than the target.
  • Floor and ceiling identify neighboring values around a target.
  • All these iterative Binary Search variations run in O(log n) time.
