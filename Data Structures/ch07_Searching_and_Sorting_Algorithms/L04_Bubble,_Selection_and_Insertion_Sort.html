2. What Is Sorting?

Sorting is the process of arranging data in a particular order, usually ascending or descending.

Example: Ascending Order

Before sorting: {45, 12, 78, 23, 9} After sorting: {9, 12, 23, 45, 78}

Example: Descending Order

Before sorting: {45, 12, 78, 23, 9} After sorting: {78, 45, 23, 12, 9}

Sorting makes searching, data processing and many other operations easier.

3. Bubble Sort

Definition

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

After each complete pass, the largest remaining unsorted element moves to its correct position at the end.

Working Principle

  1. Start from the first element.
  2. Compare two adjacent elements.
  3. If the left element is greater than the right element, swap them.
  4. Move to the next adjacent pair.
  5. Repeat the process for multiple passes.
  6. Stop when the array is sorted.

Example

Initial array: 5 1 4 2 8 Pass 1: 1 4 2 5 8 Pass 2: 1 2 4 5 8 Pass 3: 1 2 4 5 8 Sorted array: 1 2 4 5 8

Complete C11 Program: Bubble Sort

#include <stdio.h>

void bubbleSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

void display(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
}

int main(void)
{
    int arr[] = {5, 1, 4, 2, 8};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Before sorting: ");
    display(arr, n);

    bubbleSort(arr, n);

    printf("After sorting: ");
    display(arr, n);

    return 0;
}

4. Optimized Bubble Sort

In ordinary Bubble Sort, all passes are performed even if the array becomes sorted earlier.

We can improve it by maintaining a flag that records whether any swap occurred during a pass.

Logic

  • Set swapped = 0 at the beginning of each pass.
  • Whenever a swap occurs, set swapped = 1.
  • After the pass, if swapped remains zero, the array is already sorted.
  • Terminate the algorithm early.

Complete C11 Program

#include <stdio.h>

void optimizedBubbleSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int swapped = 0;

        for (int j = 0; j < n - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;

                swapped = 1;
            }
        }

        if (swapped == 0)
            break;
    }
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    optimizedBubbleSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 1 2 3 4 5
Placement point: Optimized Bubble Sort has O(n) best-case time complexity when the input is already sorted. Its average and worst-case complexity remain O(n²).

5. Selection Sort

Definition

Selection Sort repeatedly selects the smallest element from the unsorted portion and places it at the beginning of that portion.

Working Principle

  1. Assume the first unsorted element is the minimum.
  2. Search the remaining unsorted portion for a smaller element.
  3. Update the minimum index whenever a smaller element is found.
  4. Swap the minimum element with the first unsorted element.
  5. Move the boundary of the sorted portion one position forward.
  6. Repeat until the array is sorted.

Example

Initial: 64 25 12 22 11 Pass 1: 11 25 12 22 64 Pass 2: 11 12 25 22 64 Pass 3: 11 12 22 25 64 Pass 4: 11 12 22 25 64

Complete C11 Program: Selection Sort

#include <stdio.h>

void selectionSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int minIndex = i;

        for (int j = i + 1; j < n; j++)
        {
            if (arr[j] < arr[minIndex])
            {
                minIndex = j;
            }
        }

        if (minIndex != i)
        {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}

int main(void)
{
    int arr[] = {64, 25, 12, 22, 11};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    selectionSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 11 12 22 25 64

Important Observation

Selection Sort performs approximately n(n - 1) / 2 comparisons regardless of the original order of the input.

It performs at most n - 1 swaps in this implementation.

6. Insertion Sort

Definition

Insertion Sort builds a sorted portion of the array one element at a time by inserting each new element into its correct position.

It works similarly to arranging playing cards in your hand.

Working Principle

  1. Consider the first element as already sorted.
  2. Select the next element as the key.
  3. Compare the key with elements in the sorted portion.
  4. Shift larger elements one position to the right.
  5. Insert the key at its correct position.
  6. Repeat until all elements are sorted.

Example

Initial: 5 3 4 1 2 Pass 1: 3 5 4 1 2 Pass 2: 3 4 5 1 2 Pass 3: 1 3 4 5 2 Pass 4: 1 2 3 4 5

Complete C11 Program: Insertion Sort

#include <stdio.h>

void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}

int main(void)
{
    int arr[] = {5, 3, 4, 1, 2};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    insertionSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 1 2 3 4 5
Important: Insertion Sort is especially useful for small arrays and arrays that are already nearly sorted.

9. Stable Sorting

A sorting algorithm is stable if equal-valued elements retain their original relative order after sorting.

Example

Consider records with marks and student IDs:

Original: (80, A) (70, B) (80, C) (60, D) Stable ascending sort by marks: (60, D) (70, B) (80, A) (80, C)

Records A and C have equal marks. A stable sorting algorithm preserves A before C.

  • Bubble Sort: Stable when it swaps only strictly out-of-order adjacent elements.
  • Selection Sort: Standard implementation is not stable.
  • Insertion Sort: Stable when it shifts only elements strictly greater than the key.

10. In-Place Sorting

An in-place sorting algorithm uses only a small, constant amount of additional working memory, excluding the input array and any required output storage.

All three algorithms in this lesson are in-place and use O(1) auxiliary space.

11. When Should You Use Each Algorithm?

Bubble Sort

  • Useful for understanding adjacent swapping.
  • Useful as a simple teaching algorithm.
  • Optimized version can terminate quickly on already sorted data.

Selection Sort

  • Useful when minimizing the number of swaps is important.
  • Performs at most n - 1 swaps.
  • Not efficient for large datasets.

Insertion Sort

  • Suitable for small datasets.
  • Efficient for nearly sorted arrays.
  • Useful as part of hybrid sorting algorithms.

12. Common Programming Mistakes

  • Using incorrect loop boundaries.
  • Forgetting to reset the swapped flag in Bubble Sort.
  • Updating minIndex incorrectly in Selection Sort.
  • Overwriting the key before inserting it in Insertion Sort.
  • Using greater-than-or-equal instead of greater-than in stable Insertion Sort.
  • Ignoring arrays with zero or one element.
  • Confusing the sorted and unsorted portions.

13. Complexity Analysis

Bubble Sort

Worst-case comparisons are proportional to n². Optimized Bubble Sort has O(n) best-case time when no swaps are needed in the first pass.

Selection Sort

It performs n(n - 1) / 2 comparisons, giving O(n²) time in the best, average and worst cases.

Insertion Sort

Best case is O(n) when the array is already sorted. Average and worst cases are O(n²).

14. Frequently Asked Placement Interview Questions

Q1. What is sorting?

Sorting arranges elements in a specified order, such as ascending or descending.

Q2. What is Bubble Sort?

It repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Q3. What is Selection Sort?

It repeatedly selects the smallest element from the unsorted portion and places it at the beginning.

Q4. What is Insertion Sort?

It builds a sorted portion by inserting each new element into its correct position.

Q5. Which algorithm is efficient for nearly sorted arrays?

Insertion Sort generally performs well because it needs relatively few shifts when the input is nearly sorted.

Q6. What is the best-case complexity of optimized Bubble Sort?

O(n).

Q7. What is the best-case complexity of Selection Sort?

O(n²), because it still scans the unsorted portion to find the minimum.

Q8. What is the best-case complexity of Insertion Sort?

O(n), when the array is already sorted.

Q9. Which of these algorithms are stable?

Bubble Sort and Insertion Sort, with the comparison conditions used in this lesson.

Q10. Is standard Selection Sort stable?

No. Its long-distance swaps can change the relative order of equal elements.

Q11. What is an in-place algorithm?

An algorithm that uses constant auxiliary working space, apart from its input and any excluded output storage.

Q12. Which algorithm performs the fewest swaps?

Selection Sort performs at most n - 1 swaps in its standard implementation.

Q13. Why is Insertion Sort called adaptive?

Its running time improves when the input is already partially sorted.

Q14. What happens after each Bubble Sort pass?

The largest remaining unsorted element reaches its correct final position.

Q15. What happens after each Selection Sort pass?

The smallest remaining unsorted element is placed at its correct position.

Q16. What is the purpose of the key variable in Insertion Sort?

It temporarily stores the element that must be inserted into the sorted portion.

Q17. What is the worst-case input for Insertion Sort in ascending order?

A reverse-sorted array.

Q18. What is the worst-case input for Bubble Sort in ascending order?

A reverse-sorted array.

Q19. What is the main disadvantage of these three algorithms?

Their average or worst-case time complexity is O(n²), making them unsuitable for large datasets.

Q20. Which sorting algorithms are commonly used for large datasets?

Algorithms such as Merge Sort, Quick Sort and Heap Sort are generally more suitable, depending on stability, memory and performance requirements.
