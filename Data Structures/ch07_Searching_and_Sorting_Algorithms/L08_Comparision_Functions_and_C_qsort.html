2. What Is qsort()?

qsort() is a standard C library function used to sort arrays.

It is declared in the stdlib.h header file.

Unlike manually implementing Bubble Sort, Selection Sort or Quick Sort, we can use qsort() by providing a comparator function.

#include <stdlib.h>

Why Use qsort()?

  • It can sort arrays of different data types.
  • It supports custom comparison rules.
  • It can sort structures based on selected fields.
  • It reduces the amount of sorting code we need to write.
  • It is useful in practical C programming and coding interviews.
Important: The C standard specifies the behavior of qsort(), but does not require a particular internal sorting algorithm or a specific time complexity.

3. Syntax of qsort()

qsort( base, number_of_elements, element_size, comparator );

Parameters

ParameterMeaning
basePointer to the first element of the array.
number_of_elementsNumber of elements to sort.
element_sizeSize of each array element in bytes.
comparatorFunction that compares two elements.

Comparator Return Values

Return valueMeaning
Negative valueFirst element should appear before second.
ZeroElements compare equal for the selected ordering.
Positive valueFirst element should appear after second.

4. Comparator Function

A comparator function receives pointers to two array elements and decides their relative ordering.

General Structure

int compare(const void *a, const void *b)
{
    /* Convert pointers to the appropriate type. */

    /* Compare the two elements. */

    /* Return negative, zero or positive. */
}

The comparator receives pointers of type const void * because qsort() is designed to work with arrays of different element types.

Example: Comparing Integers

int compareAscending(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

The comparator converts the generic pointers into pointers to integers and then compares their values.

5. Sorting Integers in Ascending Order

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

int compareAscending(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

int main(void)
{
    int arr[] = {50, 10, 40, 20, 30};

    size_t n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(arr[0]), compareAscending);

    printf("Sorted array: ");

    for (size_t i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 10 20 30 40 50

6. Sorting Integers in Descending Order

To sort in descending order, reverse the comparison result logically.

Comparator

int compareDescending(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x > y)
        return -1;

    if (x < y)
        return 1;

    return 0;
}

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

int compareDescending(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x > y)
        return -1;

    if (x < y)
        return 1;

    return 0;
}

int main(void)
{
    int arr[] = {15, 5, 40, 25, 10};

    size_t n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(arr[0]), compareDescending);

    printf("Descending order: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Descending order: 40 25 15 10 5

7. Why Should We Avoid Subtraction in Comparators?

A common but unsafe comparator is:

int compare(const void *a, const void *b)
{
    return *(const int *)a - *(const int *)b;
}

This may cause signed integer overflow when the values are far apart.

Example

a = INT_MAX b = -1 a - b may overflow int.

Signed integer overflow in C is undefined behavior.

Recommended approach: Use relational comparisons and return -1, 0 or 1. This avoids subtraction overflow.

8. Sorting Floating-Point Numbers

We can also sort arrays of floating-point values.

Comparator

int compareFloatAscending(
    const void *a,
    const void *b)
{
    float x = *(const float *)a;
    float y = *(const float *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

int compareFloatAscending(
    const void *a,
    const void *b)
{
    float x = *(const float *)a;
    float y = *(const float *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

int main(void)
{
    float arr[] = {4.5f, 1.2f, 8.6f, 2.3f, 3.1f};

    size_t n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(arr[0]), compareFloatAscending);

    printf("Sorted values: ");

    for (size_t i = 0; i < n; i++)
        printf("%.1f ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted values: 1.2 2.3 3.1 4.5 8.6
This comparator assumes all values are ordinary finite numbers. NaN values require an explicit ordering policy because comparisons with NaN are false.

9. Sorting Strings Using qsort()

Strings in C are character arrays terminated by the null character '\0'.

The standard library function strcmp() compares two strings lexicographically.

Comparator

int compareStrings(const void *a, const void *b)
{
    const char *const *s1 = a;
    const char *const *s2 = b;

    return strcmp(*s1, *s2);
}

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int compareStrings(const void *a, const void *b)
{
    const char *const *s1 = a;
    const char *const *s2 = b;

    return strcmp(*s1, *s2);
}

int main(void)
{
    const char *names[] = {
        "Ravi",
        "Aman",
        "Karan",
        "Deepak",
        "Neha"
    };

    size_t n = sizeof(names) / sizeof(names[0]);

    qsort(names, n, sizeof(names[0]), compareStrings);

    printf("Sorted names:\n");

    for (size_t i = 0; i < n; i++)
    {
        printf("%s\n", names[i]);
    }

    return 0;
}

Expected Output

Sorted names: Aman Deepak Karan Neha Ravi
The array contains pointers to strings, so the comparator must interpret each argument as a pointer to an array element, which is a pointer to char.

10. Sorting Structures Using qsort()

In practical C programs, we often store related information inside structures.

Consider an array of student records.

Structure Definition

struct Student
{
    int rollNo;
    char name[30];
    float marks;
};

We can sort students according to marks by writing a comparator function.

Complete C11 Program: Sort Students by Marks

#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int rollNo;
    char name[30];
    float marks;
};

int compareMarksDescending(
    const void *a,
    const void *b)
{
    const struct Student *s1 = a;
    const struct Student *s2 = b;

    if (s1->marks > s2->marks)
        return -1;

    if (s1->marks < s2->marks)
        return 1;

    return 0;
}

int main(void)
{
    struct Student students[] =
    {
        {101, "Aman", 85.5f},
        {102, "Ravi", 92.0f},
        {103, "Neha", 78.5f},
        {104, "Karan", 88.0f}
    };

    size_t n =
        sizeof(students) / sizeof(students[0]);

    qsort(
        students,
        n,
        sizeof(students[0]),
        compareMarksDescending
    );

    printf("Student records by marks:\n");

    for (size_t i = 0; i < n; i++)
    {
        printf(
            "%d %-10s %.2f\n",
            students[i].rollNo,
            students[i].name,
            students[i].marks
        );
    }

    return 0;
}

Expected Output

Student records by marks: 102 Ravi 92.00 104 Karan 88.00 101 Aman 85.50 103 Neha 78.50

11. Sorting Structures Using Multiple Fields

Sometimes records must be sorted according to more than one field.

Example Requirement

  • First sort students by marks in descending order.
  • If marks are equal, sort by roll number in ascending order.

Comparator

int compareStudents(const void *a, const void *b)
{
    const struct Student *s1 = a;
    const struct Student *s2 = b;

    if (s1->marks > s2->marks)
        return -1;

    if (s1->marks < s2->marks)
        return 1;

    if (s1->rollNo < s2->rollNo)
        return -1;

    if (s1->rollNo > s2->rollNo)
        return 1;

    return 0;
}

This is called multi-key or multi-field sorting.

Placement relevance: Similar requirements appear in employee records, product inventories, examination results and database-style sorting problems.

12. Sorting Structures by Name

We can sort structures using a character-array field with strcmp().

Comparator

int compareStudentNames(const void *a, const void *b)
{
    const struct Student *s1 = a;
    const struct Student *s2 = b;

    return strcmp(s1->name, s2->name);
}

This sorts records in ascending lexicographical order by name.

13. Sorting in Descending Order Without Changing the Data Type

For an integer array, descending order can be achieved by reversing the comparison direction.

For structures, compare the selected field in the opposite order.

Do not assume that reversing the sorted array always preserves the required order of records with equal keys.

14. Important qsort() Characteristics

  • Declared in stdlib.h.
  • Can sort arrays of arbitrary element types.
  • Uses a comparator function.
  • Modifies the array being sorted.
  • Does not return a new sorted array.
  • Does not guarantee stable sorting.
  • Does not specify a particular sorting algorithm.
  • Comparator results must provide a consistent ordering.
Do not rely on qsort() preserving the original order of elements that compare equal. If stability is required, use a stable sorting implementation or include an explicit original-position tie-breaker.

15. Common Comparator Mistakes

  1. Returning subtraction results that can overflow.
  2. Converting void pointers to the wrong data type.
  3. Forgetting that the comparator receives pointers to elements.
  4. Using the wrong element size in qsort().
  5. Comparing the wrong structure fields.
  6. Assuming qsort() is stable.
  7. Writing a comparator that violates consistent ordering.
  8. Ignoring special values such as NaN when sorting floating-point numbers.

16. Complexity Analysis

The C standard does not prescribe the internal algorithm or a guaranteed time complexity for qsort().

Many implementations provide average O(n log n) performance, but the exact guarantees depend on the C library implementation.

18. Frequently Asked Placement Interview Questions

Q1. What is qsort()?

qsort() is a standard C library function that sorts an array using a supplied comparator function.

Q2. Which header file declares qsort()?

stdlib.h.

Q3. What are the four parameters of qsort()?

Base address, number of elements, size of each element and comparator function.

Q4. What is a comparator function?

A function that determines the relative ordering of two array elements.

Q5. What does a negative comparator result mean?

The first element should appear before the second element.

Q6. What does a positive comparator result mean?

The first element should appear after the second element.

Q7. What does zero mean?

The two elements compare equal for the selected ordering.

Q8. Can qsort() sort structures?

Yes. The comparator can access the selected structure fields.

Q9. Can qsort() sort strings?

Yes. A comparator can use strcmp() to compare strings.

Q10. Is qsort() stable?

No stability guarantee is provided by the C standard.

Q11. Does qsort() return a sorted array?

No. It rearranges the original array.

Q12. Why should subtraction be avoided in integer comparators?

Subtraction can overflow signed integers, causing undefined behavior.

Q13. Can we sort in descending order?

Yes. Reverse the comparison direction in the comparator.

Q14. Can we sort by multiple fields?

Yes. Compare the primary field first, then use secondary fields to break ties.

Q15. Does qsort() always use Quick Sort?

No. Its internal sorting algorithm is implementation-dependent.

Q16. Is the comparator called with values or pointers?

It is called with pointers to the two elements being compared.

Q17. What does sizeof(arr[0]) provide?

The size in bytes of one array element.

Q18. Can qsort() sort floating-point arrays?

Yes, using an appropriate floating-point comparator and a defined policy for NaN values if they may occur.

Q19. Can qsort() be used before Binary Search?

Yes. Sorting an array first allows Binary Search to be applied.

Q20. What should we do when stable sorting is required?

Use a stable sorting algorithm or explicitly preserve original positions as a tie-breaker.
