2. What Is Searching?

Searching is the process of finding whether a particular element (called the key or target) exists in a collection of data.

If the element is present, a searching algorithm may return its index or position. Otherwise, it returns a value indicating that the element was not found.

Example

Array = {10, 20, 30, 40, 50} Target = 30 Result = Element found at index 2

Two fundamental searching techniques are:

  1. Linear Search
  2. Binary Search

3. Linear Search

Definition

Linear Search is a searching technique that checks each element sequentially until the target is found or all elements have been examined.

Working Principle

  1. Start from the first array element.
  2. Compare the current element with the target.
  3. If both are equal, return the current index.
  4. Otherwise, move to the next element.
  5. If the end of the array is reached, return -1.

Example

Array = {12, 25, 37, 48, 59} Target = 48 Index 0: 12 != 48 Index 1: 25 != 48 Index 2: 37 != 48 Index 3: 48 == 48 Element found at index 3.

Linear Search Algorithm

LINEAR_SEARCH(array, n, target) 1. For i = 0 to n - 1: If array[i] == target: Return i 2. Return -1

4. Linear Search Implementation in C

Complete C11 Program

#include <stdio.h>

int linearSearch(const int arr[], int n, int target)
{
    for (int i = 0; i < n; i++)
    {
        if (arr[i] == target)
        {
            return i;
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {12, 25, 37, 48, 59};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target;

    printf("Enter element to search: ");

    if (scanf("%d", &target) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    int result = linearSearch(arr, n, target);

    if (result != -1)
    {
        printf("Element found at index %d\n", result);
    }
    else
    {
        printf("Element not found\n");
    }

    return 0;
}

Important: Linear Search works on both sorted and unsorted arrays. It does not require the elements to be arranged in any particular order.

5. Binary Search

Definition

Binary Search is an efficient searching algorithm that repeatedly divides a sorted search range into two halves.

Instead of checking every element, it compares the target with the middle element and eliminates half of the remaining search range after each comparison.

Important interview condition: Standard Binary Search requires the search range to be sorted according to the ordering used by the algorithm.

Working Principle

  1. Initialize low = 0.
  2. Initialize high = n - 1.
  3. Calculate the middle index.
  4. Compare the middle element with the target.
  5. If equal, return the middle index.
  6. If the target is smaller, search the left half.
  7. If the target is larger, search the right half.
  8. Repeat until found or low > high.

6. Binary Search Example

Consider the sorted array:

Array = {10, 20, 30, 40, 50, 60, 70} Target = 60

Dry Run

Iteration Low High Mid Array[Mid] Decision
106340 60 > 40, search right half
246560 Target found
Initial: low = 0, high = 6 Iteration 1: mid = 0 + (6 - 0) / 2 = 3 arr[3] = 40 60 > 40 low = mid + 1 = 4 Iteration 2: mid = 4 + (6 - 4) / 2 = 5 arr[5] = 60 Target found at index 5.

7. Iterative Binary Search in C

Complete C11 Program

#include <stdio.h>

int binarySearch(const int arr[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
        {
            return mid;
        }
        else if (target < arr[mid])
        {
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target;

    printf("Enter element to search: ");

    if (scanf("%d", &target) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    int result = binarySearch(arr, n, target);

    if (result != -1)
    {
        printf("Element found at index %d\n", result);
    }
    else
    {
        printf("Element not found\n");
    }

    return 0;
}

Expected Output

Enter element to search: 60 Element found at index 5

Why use this middle-index formula?

int mid = low + (high - low) / 2;

The expression (low + high) / 2 can overflow when both indices are large. The alternative formula avoids that particular addition overflow when the indices are valid nonnegative integers.

8. Recursive Binary Search in C

Binary Search can also be implemented using recursion. Each recursive call operates on a smaller search interval.

Complete C11 Program

#include <stdio.h>

int binarySearchRecursive(
    const int arr[],
    int low,
    int high,
    int target)
{
    if (low > high)
    {
        return -1;
    }

    int mid = low + (high - low) / 2;

    if (arr[mid] == target)
    {
        return mid;
    }

    if (target < arr[mid])
    {
        return binarySearchRecursive(
            arr, low, mid - 1, target);
    }

    return binarySearchRecursive(
        arr, mid + 1, high, target);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));
    int target = 50;

    int result = binarySearchRecursive(
        arr, 0, n - 1, target);

    if (result != -1)
    {
        printf("Element found at index %d\n", result);
    }
    else
    {
        printf("Element not found\n");
    }

    return 0;
}

Expected Output

Element found at index 4
Recursive Binary Search uses O(log n) auxiliary stack space because of recursive function calls. Iterative Binary Search uses O(1) auxiliary space.

10. When Should You Use Each Algorithm?

Use Linear Search when:

  • The array is small.
  • The data is unsorted.
  • Sorting the data first would cost more than searching directly.
  • The data is stored in a sequential structure without efficient random access.

Use Binary Search when:

  • The data is already sorted.
  • The collection supports efficient random access, such as an array.
  • The collection is large enough for logarithmic search to be beneficial.
  • You need to solve boundary or range-searching problems.
Placement insight: If an interviewer provides an unsorted array, do not immediately apply Binary Search. First determine whether sorting is allowed and whether its cost is justified.

11. Important Edge Cases

  1. Empty array: searching must return -1.
  2. Single-element array: target may be present or absent.
  3. Target at the first index.
  4. Target at the last index.
  5. Target smaller than every element.
  6. Target greater than every element.
  7. Duplicate elements: ordinary Binary Search may return any matching occurrence.
  8. Binary Search on unsorted data: results are not reliable.
For duplicate values, finding the first or last occurrence requires a modified Binary Search. That topic is covered in Lesson 2.

12. Common Programming Mistakes

  • Applying Binary Search to an unsorted array.
  • Using low < high instead of low <= high in the standard iterative implementation.
  • Updating low = mid or high = mid without ensuring progress.
  • Using mid = (low + high) / 2 when overflow is possible.
  • Forgetting to return -1 when the element is absent.
  • Confusing array index with one-based position.
  • Ignoring the empty-array case in reusable implementations.

13. Time and Space Complexity Analysis

Linear Search

  • Best case: O(1), target is at the first position.
  • Average case: O(n), a linear number of comparisons.
  • Worst case: O(n), target is last or absent.
  • Iterative auxiliary space: O(1).

Binary Search

  • Best case: O(1), target is at the first middle position.
  • Average case: O(log n).
  • Worst case: O(log n).
  • Iterative auxiliary space: O(1).
  • Recursive auxiliary space: O(log n).

Why is Binary Search O(log n)?

After each iteration, the remaining search range is approximately half its previous size.

n n / 2 n / 4 n / 8 ... 1 After k iterations: n / 2^k = 1 2^k = n k = log2(n) Therefore, time complexity = O(log n)

14. Frequently Asked Placement Interview Questions

Q1. What is Linear Search?

Linear Search checks elements sequentially until the target is found or the collection is exhausted.

Q2. What is Binary Search?

Binary Search repeatedly divides a sorted search interval into halves to locate a target element.

Q3. Why does Binary Search require sorted data?

The algorithm decides which half to discard based on the comparison with the middle element. This decision is only reliable when the data is ordered.

Q4. What is the worst-case complexity of Linear Search?

O(n), because every element may need to be examined.

Q5. What is the worst-case complexity of Binary Search?

O(log n), because the search range is halved at each iteration.

Q6. Which search algorithm is faster?

Binary Search generally requires fewer comparisons on large, sorted arrays. Linear Search may be more appropriate for small or unsorted collections.

Q7. Can Binary Search work on a linked list?

It is possible to implement a binary-search-like procedure, but locating the middle node takes linear time in a linked list. Therefore, the usual O(log n) array performance advantage does not apply.

Q8. What is the difference between iterative and recursive Binary Search?

Iterative Binary Search uses a loop and O(1) auxiliary space. Recursive Binary Search uses function calls and O(log n) auxiliary stack space.

Q9. What happens when the target is not present?

The standard implementations return -1 after the search range becomes empty.

Q10. Can Binary Search find duplicate values?

Yes. Standard Binary Search can find a matching occurrence, but it does not guarantee the first or last occurrence.

Q11. Why is the loop condition low <= high?

It ensures that the final remaining element is also examined when low and high become equal.

Q12. What is the purpose of low = mid + 1?

It discards the middle element and the entire left portion when the target is greater than the middle element.

Q13. What is the purpose of high = mid - 1?

It discards the middle element and the entire right portion when the target is smaller than the middle element.

Q14. Can Binary Search be used for descending arrays?

Yes, but the comparison directions must be reversed to match the descending order.

Q15. What is the main limitation of Linear Search?

It may need to examine every element, resulting in O(n) worst-case time complexity.

Q16. What is the main limitation of Binary Search?

Standard Binary Search requires sorted data and efficient random access to the middle element.

Q17. What is the maximum number of comparisons in Binary Search?

It grows logarithmically with the number of elements. The exact number depends on the array size and target position.

Q18. Is Binary Search a divide-and-conquer algorithm?

Yes. It repeatedly reduces the problem to one smaller search interval.

Q19. What is the auxiliary space of iterative Binary Search?

O(1), because it uses only a fixed number of variables.

Q20. What is the first thing to check before applying Binary Search?

Verify that the search range is sorted according to the ordering assumed by the algorithm.

16. Multiple Choice Questions (MCQs)

Q1. What is the worst-case time complexity of Linear Search?

  1. O(1)
  2. O(log n)
  3. O(n)
  4. O(n log n)

Answer: (c) O(n)

Q2. Binary Search requires:

  1. Unsorted data
  2. Sorted data
  3. A linked list only
  4. A stack

Answer: (b) Sorted data

Q3. What is the worst-case complexity of Binary Search?

  1. O(n)
  2. O(n²)
  3. O(log n)
  4. O(1)

Answer: (c) O(log n)

Q4. Which algorithm can search an unsorted array without preprocessing?

  1. Binary Search
  2. Linear Search
  3. Merge Sort
  4. Heap Sort

Answer: (b) Linear Search

Q5. What is the iterative auxiliary space of Binary Search?

  1. O(n)
  2. O(log n)
  3. O(n log n)
  4. O(1)

Answer: (d) O(1)

Q6. Which condition is used in standard iterative Binary Search?

  1. low < high
  2. low <= high
  3. low == high
  4. high == 0

Answer: (b) low <= high

Q7. Which formula is safer for calculating the middle index?

  1. (low + high) * 2
  2. low + (high - low) / 2
  3. high - low / 2
  4. low * high

Answer: (b) low + (high - low) / 2

Q8. What does a standard search function return when the target is absent in this lesson?

  1. 0
  2. 1
  3. -1
  4. n

Answer: (c) -1

Q9. Which algorithm repeatedly halves the search interval?

  1. Linear Search
  2. Binary Search
  3. Bubble Sort
  4. Selection Sort

Answer: (b) Binary Search

Q10. Which searching algorithm is generally suitable for a small unsorted array?

  1. Linear Search
  2. Binary Search
  3. Heap Sort
  4. Merge Sort

Answer: (a) Linear Search

17. Lesson Summary

  • Linear Search checks elements sequentially.
  • Binary Search repeatedly divides a sorted search range.
  • Linear Search has O(n) worst-case time complexity.
  • Binary Search has O(log n) worst-case time complexity.
  • Iterative Binary Search uses O(1) auxiliary space.
  • Recursive Binary Search uses O(log n) auxiliary stack space.
  • Correct boundary updates and loop conditions are essential.
