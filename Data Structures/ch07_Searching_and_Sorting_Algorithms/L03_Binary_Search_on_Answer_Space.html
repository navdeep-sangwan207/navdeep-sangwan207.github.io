2. What Is Binary Search on Answer Space?

In ordinary Binary Search, we search for a target element in a sorted collection.

In Binary Search on Answer Space, we search for the smallest or largest answer satisfying a particular condition.

Example

Suppose we need to find the minimum speed required to finish a job within a given time limit.

Possible speeds might be:

Speed: 1 2 3 4 5 6 7 8 Can finish: N N N Y Y Y Y Y

Here, once a speed becomes feasible, all larger speeds are also feasible.

Therefore, we can search for the first feasible speed using Binary Search.

3. Understanding Monotonic Predicates

A predicate is a function that returns either true or false.

A monotonic predicate maintains a consistent transition as the candidate answer increases or decreases.

Type A: Minimum Feasible Answer

False False False True True True True

Find the first True.

Type B: Maximum Feasible Answer

True True True True False False False

Find the last True.

Important: Binary Search on Answer Space is useful only when feasibility is monotonic over the chosen candidate range.

4. General Template: Find Minimum Feasible Answer

int findMinimumAnswer(int low, int high)
{
    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (isFeasible(mid))
        {
            answer = mid;
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    return answer;
}

When the candidate is feasible, try a smaller candidate. Otherwise, increase the candidate.

5. General Template: Find Maximum Feasible Answer

int findMaximumAnswer(int low, int high)
{
    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (isFeasible(mid))
        {
            answer = mid;
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return answer;
}

When the candidate is feasible, try a larger candidate. Otherwise, decrease it.

For integer answer ranges, these templates assume that the bounds and feasibility checks are valid and that an answer exists in the searched range. If no feasible answer exists, return a clearly defined failure value.

6. Problem 1: Minimum Eating Speed

Problem Statement

A person has several piles of items. They can process at most k items from one pile per hour. The remaining items in a pile require another hour. Find the minimum integer processing speed required to finish all piles within h hours.

Example

Piles = {3, 6, 7, 11} Hours available = 8 Minimum speed = 4

Explanation

Speed = 4 Pile 3 -> 1 hour Pile 6 -> 2 hours Pile 7 -> 2 hours Pile 11 -> 3 hours Total = 8 hours

Feasibility Function

For a speed k, the hours required for a pile of size p are:

hours = p / k + (p % k != 0)

Complete C11 Program

#include <stdio.h>

int canFinish(const int piles[], int n,
              int speed, long long limit)
{
    long long hours = 0;

    for (int i = 0; i < n; i++)
    {
        hours += piles[i] / speed;

        if (piles[i] % speed != 0)
            hours++;

        if (hours > limit)
            return 0;
    }

    return 1;
}

int minimumSpeed(const int piles[], int n,
                 long long limit)
{
    if (n <= 0 || limit < n)
        return -1;

    int low = 1;
    int high = piles[0];

    for (int i = 1; i < n; i++)
    {
        if (piles[i] > high)
            high = piles[i];
    }

    int answer = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (canFinish(piles, n, mid, limit))
        {
            answer = mid;
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    return answer;
}

int main(void)
{
    int piles[] = {3, 6, 7, 11};
    int n = (int)(sizeof(piles) / sizeof(piles[0]));

    printf("Minimum speed = %d\n",
           minimumSpeed(piles, n, 8));

    return 0;
}

Expected Output

Minimum speed = 4

Complexity: O(n log M), where M is the maximum pile size. Auxiliary space: O(1).

7. Problem 2: Allocate Books

Problem Statement

Given an array representing the number of pages in each book, allocate books to a fixed number of students such that:

  • Every student receives at least one book.
  • Books are allocated in contiguous order.
  • Each book is allocated to exactly one student.
  • The maximum pages assigned to any student are minimized.

Example

Pages = {12, 34, 67, 90} Students = 2 One optimal allocation: Student 1: 12 + 34 + 67 = 113 Student 2: 90 Minimum possible maximum = 113

Approach

Search the answer between:

low = maximum pages in one book high = total pages in all books

For a candidate maximum page limit, greedily allocate contiguous books. If the number of students required is within the available number, the candidate is feasible.

Complete C11 Program

#include <stdio.h>

int canAllocate(const int pages[], int n,
                int students, long long limit)
{
    int usedStudents = 1;
    long long currentPages = 0;

    for (int i = 0; i < n; i++)
    {
        if (pages[i] > limit)
            return 0;

        if (currentPages + pages[i] > limit)
        {
            usedStudents++;
            currentPages = pages[i];

            if (usedStudents > students)
                return 0;
        }
        else
        {
            currentPages += pages[i];
        }
    }

    return 1;
}

long long allocateBooks(const int pages[], int n,
                        int students)
{
    if (n <= 0 || students <= 0 || students > n)
        return -1;

    long long low = pages[0];
    long long high = 0;

    for (int i = 0; i < n; i++)
    {
        if (pages[i] <= 0)
            return -1;

        if (pages[i] > low)
            low = pages[i];

        high += pages[i];
    }

    long long answer = -1;

    while (low <= high)
    {
        long long mid = low + (high - low) / 2;

        if (canAllocate(pages, n, students, mid))
        {
            answer = mid;
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    return answer;
}

int main(void)
{
    int pages[] = {12, 34, 67, 90};
    int n = (int)(sizeof(pages) / sizeof(pages[0]));

    printf("Minimum maximum pages = %lld\n",
           allocateBooks(pages, n, 2));

    return 0;
}

Expected Output

Minimum maximum pages = 113

Complexity: O(n log S), where S is the sum of all pages. Auxiliary space: O(1).

Important: The positive-page validation is necessary for this implementation. The standard problem also requires contiguous allocation and at least one book per student.

8. Problem 3: Aggressive Cows

Problem Statement

Given positions of stalls and a number of cows, place the cows in stalls so that the minimum distance between any two cows is as large as possible.

Example

Stall positions = {1, 2, 4, 8, 9} Number of cows = 3 One optimal placement: 1, 4, 8 Distances: 4 - 1 = 3 8 - 4 = 4 Minimum distance = 3 Maximum possible minimum distance = 3

Approach

  1. Sort the stall positions.
  2. Search possible minimum distances.
  3. For each candidate distance, greedily place cows from left to right.
  4. If all cows can be placed, try a larger distance.
  5. Otherwise, reduce the distance.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

int compareInt(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

int canPlace(const int stalls[], int n,
             int cows, long long distance)
{
    int placed = 1;
    int lastPosition = stalls[0];

    for (int i = 1; i < n; i++)
    {
        if ((long long)stalls[i] - lastPosition >= distance)
        {
            placed++;
            lastPosition = stalls[i];

            if (placed >= cows)
                return 1;
        }
    }

    return placed >= cows;
}

long long aggressiveCows(int stalls[], int n, int cows)
{
    if (n <= 0 || cows <= 0 || cows > n)
        return -1;

    qsort(stalls, (size_t)n, sizeof(stalls[0]), compareInt);

    if (cows == 1)
        return 0;

    long long low = 1;
    long long high = (long long)stalls[n - 1] - stalls[0];
    long long answer = 0;

    while (low <= high)
    {
        long long mid = low + (high - low) / 2;

        if (canPlace(stalls, n, cows, mid))
        {
            answer = mid;
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return answer;
}

int main(void)
{
    int stalls[] = {1, 2, 4, 8, 9};
    int n = (int)(sizeof(stalls) / sizeof(stalls[0]));

    printf("Maximum minimum distance = %lld\n",
           aggressiveCows(stalls, n, 3));

    return 0;
}

Expected Output

Maximum minimum distance = 3

Complexity: O(n log n + n log D), where D is the difference between the largest and smallest stall positions. Auxiliary space: O(1) for the search itself, excluding the library sorting implementation.

9. Minimum Maximum Workload

This is another common optimization pattern. Suppose a list of tasks must be divided among workers, with each worker receiving a contiguous group of tasks. Find the smallest possible maximum workload.

The pattern is identical to Allocate Books:

Minimum answer = largest individual task Maximum answer = sum of all tasks Feasibility: Can the tasks be completed using at most the available number of workers?

When the candidate workload is feasible, reduce the candidate to search for a smaller maximum workload.

11. How to Identify Binary Search on Answer Space

Look for problem statements containing phrases such as:

  • Minimum possible maximum value.
  • Maximum possible minimum distance.
  • Minimum speed required.
  • Smallest capacity sufficient.
  • Maximum number of units that can be produced.
  • Complete work within a specified time.
  • Find the smallest feasible value.
Interview approach: Define the answer range, write a feasibility function, verify that feasibility is monotonic, and then apply Binary Search.

12. Common Mistakes

  • Applying Binary Search without proving monotonicity.
  • Choosing incorrect lower and upper bounds.
  • Reversing the updates for minimum and maximum feasible answers.
  • Using int for sums that may exceed INT_MAX.
  • Forgetting to validate impossible inputs.
  • Using a greedy feasibility check without proving that it works for the problem.
  • Forgetting to sort positions before solving Aggressive Cows.
  • Failing to handle the case where only one cow is required.

14. Placement Interview Questions and Answers

Q1. What is Binary Search on Answer Space?

It is a technique that applies Binary Search to possible answer values rather than directly searching for an element.

Q2. What is a monotonic predicate?

A Boolean condition whose results transition in only one direction over an ordered candidate range.

Q3. What is a feasibility function?

A function that checks whether a candidate answer satisfies the problem constraints.

Q4. How do you find the minimum feasible answer?

When a candidate is feasible, store it and search the left half.

Q5. How do you find the maximum feasible answer?

When a candidate is feasible, store it and search the right half.

Q6. What is the key requirement for Binary Search on Answer Space?

The feasibility condition must be monotonic over the candidate range.

Q7. What is the Allocate Books problem?

It minimizes the maximum number of pages assigned to any student while preserving contiguous book allocation.

Q8. What is the Aggressive Cows problem?

It maximizes the minimum distance between cows placed in available stalls.

Q9. Why do we sort stall positions?

Sorting allows greedy placement from left to right while checking a candidate minimum distance.

Q10. What is the lower bound for the Allocate Books answer?

The maximum number of pages in any individual book.

Q11. What is the upper bound for the Allocate Books answer?

The sum of all pages.

Q12. What is the lower bound for the minimum eating speed?

One item per hour, assuming the piles are nonempty and the time constraint is feasible.

Q13. Why use long long in these programs?

Large sums and accumulated time values can exceed the range of a 32-bit int.

Q14. Is Binary Search on Answer Space always applicable to optimization problems?

No. The candidate feasibility condition must be monotonic, and its range must be searchable efficiently.

Q15. What is the complexity of Allocate Books?

O(n log S), where S is the sum of all pages.

Q16. What is the complexity of Aggressive Cows?

O(n log n + n log D), including sorting, where D is the coordinate range.

Q17. What does at most k workers mean in a feasibility check?

It means a candidate limit is acceptable if the greedy allocation needs no more than k workers, provided the problem permits unused workers and its other constraints are met.

Q18. What happens when a minimum feasible candidate is not feasible?

Search a larger candidate.

Q19. What happens when a maximum feasible candidate is not feasible?

Search a smaller candidate.

Q20. How do you explain this technique in an interview?

Explain the answer range, monotonic feasibility condition, greedy or mathematical check, Binary Search updates and complexity.

17. Lesson Summary

  • Binary Search can operate on possible answer values.
  • Monotonic feasibility is the central requirement.
  • Minimum feasible problems search towards smaller candidates after success.
  • Maximum feasible problems search towards larger candidates after success.
  • Allocate Books and Aggressive Cows are important placement examples.
  • Feasibility checks must be correct and efficient.
  • Use sufficiently wide integer types for large sums and calculations.
