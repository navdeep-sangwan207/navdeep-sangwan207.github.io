2. What Is a Binary Heap?

A Binary Heap is a complete binary tree that satisfies a special ordering property called the heap property.

A complete binary tree is a binary tree in which every level is completely filled except possibly the last level, and the last level is filled from left to right.

Types of Binary Heap

Max Heap

In a Max Heap, every parent node is greater than or equal to its children.

50 / \ 30 40 / \ / 10 20 35

The maximum element is at the root.

Min Heap

In a Min Heap, every parent node is less than or equal to its children.

10 / \ 20 15 / \ / 40 30 25

The minimum element is at the root.

3. Array Representation of a Heap

A Binary Heap can be stored efficiently in an array without using pointers.

For a zero-based array index i:

Parent index = (i - 1) / 2 Left child index = 2 * i + 1 Right child index = 2 * i + 2

Example

Heap: 50 / \ 30 40 / \ / 10 20 35 Array: Index: 0 1 2 3 4 5 Value: 50 30 40 10 20 35
Placement point: A Binary Heap is a complete binary tree, so its nodes can be stored compactly in an array.

4. What Is Heapify?

Heapify is the process of restoring the heap property when a node violates the Max Heap or Min Heap condition.

Max Heapify

Max Heapify ensures that the selected node is not smaller than either of its children, assuming the left and right subtrees are already Max Heaps.

Example

Before heapify: 10 / \ 50 30 After heapify: 50 / \ 10 30

The largest of the node and its children moves to the parent position.

5. Build Max Heap

Build Heap converts an unordered array into a Max Heap.

For an array of n elements, the last non-leaf node is:

lastNonLeaf = n / 2 - 1

We call Max Heapify from this index down to the root.

Example

Initial array: 4 10 3 5 1 Build Max Heap: 10 5 3 4 1

Build Heap takes O(n) time, not O(n log n).

6. Heap Sort

Definition

Heap Sort is a comparison-based sorting algorithm that uses a Binary Heap to sort elements.

Working Principle

  1. Convert the array into a Max Heap.
  2. The largest element is now at index 0.
  3. Swap the root with the last element in the active heap.
  4. Reduce the active heap size by one.
  5. Apply Max Heapify to restore the heap property.
  6. Repeat until the active heap contains one element.

Example

Initial array: 4 10 3 5 1 Build Max Heap: 10 5 3 4 1 Move 10 to the end: 5 4 3 1 10 Move 5 to its final position: 4 1 3 5 10 Move 4: 3 1 4 5 10 Final sorted array: 1 3 4 5 10

7. Complete C11 Program: Heap Sort

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

void maxHeapify(int arr[], int n, int i)
{
    int largest = i;

    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])
    {
        largest = left;
    }

    if (right < n && arr[right] > arr[largest])
    {
        largest = right;
    }

    if (largest != i)
    {
        swap(&arr[i], &arr[largest]);

        maxHeapify(arr, n, largest);
    }
}

void buildMaxHeap(int arr[], int n)
{
    for (int i = n / 2 - 1; i >= 0; i--)
    {
        maxHeapify(arr, n, i);
    }
}

void heapSort(int arr[], int n)
{
    buildMaxHeap(arr, n);

    for (int i = n - 1; i > 0; i--)
    {
        swap(&arr[0], &arr[i]);

        maxHeapify(arr, i, 0);
    }
}

int main(void)
{
    int arr[] = {4, 10, 3, 5, 1};

    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Before sorting: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    heapSort(arr, n);

    printf("After sorting: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Before sorting: 4 10 3 5 1 After sorting: 1 3 4 5 10
The program uses a recursive heapify function. Its recursion depth is O(log n) for a valid Binary Heap.

9. Is Heap Sort Stable?

No. Standard Heap Sort is not stable.

Swapping the root with the last element can change the relative order of equal-valued records.

Heap Sort Properties

  • Comparison-based algorithm.
  • In-place with respect to the array.
  • Not stable.
  • Guaranteed O(n log n) time complexity.
  • Uses a Binary Heap.

10. What Is Counting Sort?

Counting Sort is a non-comparison-based sorting algorithm.

Instead of repeatedly comparing elements, it counts how many times each value occurs.

It uses a frequency array to store the occurrence count of each value.

Example

Input: 4 2 2 8 3 3 1 Frequency: Value: 1 2 3 4 5 6 7 8 Frequency: 1 2 2 1 0 0 0 1 Sorted: 1 2 2 3 3 4 8

11. Counting Sort Working Principle

  1. Find the minimum and maximum values.
  2. Determine the range of input values.
  3. Allocate a frequency array for that range.
  4. Count the occurrences of each value.
  5. Traverse the frequency array in ascending order.
  6. Write each value into the original array according to its frequency.
Important: Counting Sort is most useful when the range of integer values is reasonably small compared with the number of input elements.

12. Complete C11 Program: Counting Sort

This implementation supports negative and positive integer values. It validates the range before allocating memory.

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <limits.h>

int countingSort(int arr[], size_t n)
{
    if (n < 2)
        return 1;

    int minValue = arr[0];
    int maxValue = arr[0];

    for (size_t i = 1; i < n; i++)
    {
        if (arr[i] < minValue)
            minValue = arr[i];

        if (arr[i] > maxValue)
            maxValue = arr[i];
    }

    int64_t range =
        (int64_t)maxValue - (int64_t)minValue + 1;

    /* Avoid an unreasonable allocation */
    if ((uint64_t)range > SIZE_MAX / sizeof(size_t))
        return 0;

    size_t *count = calloc((size_t)range, sizeof(*count));

    if (count == NULL)
        return 0;

    /* Count occurrences */
    for (size_t i = 0; i < n; i++)
    {
        size_t index =
            (size_t)((int64_t)arr[i] - (int64_t)minValue);

        count[index]++;
    }

    /* Reconstruct sorted array */
    size_t outputIndex = 0;

    for (size_t i = 0; i < (size_t)range; i++)
    {
        while (count[i] > 0)
        {
            int64_t value = (int64_t)minValue + (int64_t)i;

            arr[outputIndex++] = (int)value;

            count[i]--;
        }
    }

    free(count);

    return 1;
}

int main(void)
{
    int arr[] = {4, 2, 2, 8, 3, 3, 1};

    size_t n = sizeof(arr) / sizeof(arr[0]);

    printf("Before sorting: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    if (!countingSort(arr, n))
    {
        printf("Counting Sort failed.\n");
        return 1;
    }

    printf("After sorting: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}

Expected Output

Before sorting: 4 2 2 8 3 3 1 After sorting: 1 2 2 3 3 4 8

13. Counting Sort with Negative Numbers

Counting Sort can also sort negative integers by using an offset based on the minimum value.

Example

Input: -5 -2 0 -5 3 1 Minimum = -5 Maximum = 3 Range = 9 Sorted: -5 -5 -2 0 1 3

For any input value x, its frequency-array index is:

index = x - minimum

This converts the minimum value to index zero and keeps all other values within the allocated range.

14. Stable Counting Sort

The frequency-and-reconstruction implementation above sorts integer values correctly, but it does not preserve the original order of records with equal keys.

A stable Counting Sort uses cumulative counts and an output array.

Stable Counting Sort Implementation

#include <stdio.h>
#include <stdlib.h>

int stableCountingSort(const int arr[], int output[], int n)
{
    if (n < 0)
        return 0;

    if (n == 0)
        return 1;

    int maxValue = arr[0];

    for (int i = 1; i < n; i++)
    {
        if (arr[i] < 0)
            return 0;

        if (arr[i] > maxValue)
            maxValue = arr[i];
    }

    if ((size_t)maxValue + 1 >
        (size_t)-1 / sizeof(size_t))
        return 0;

    size_t range = (size_t)maxValue + 1;

    size_t *count = calloc(range, sizeof(*count));

    if (count == NULL)
        return 0;

    /* Count each value */
    for (int i = 0; i < n; i++)
    {
        count[arr[i]]++;
    }

    /* Convert counts into cumulative positions */
    for (size_t i = 1; i < range; i++)
    {
        count[i] += count[i - 1];
    }

    /* Traverse input backwards to preserve stability */
    for (int i = n - 1; i >= 0; i--)
    {
        size_t position = --count[arr[i]];

        output[position] = arr[i];
    }

    free(count);

    return 1;
}

int main(void)
{
    int arr[] = {4, 2, 2, 8, 3, 3, 1};

    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    int output[7];

    if (!stableCountingSort(arr, output, n))
    {
        printf("Sorting failed.\n");
        return 1;
    }

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", output[i]);

    printf("\n");

    return 0;
}

Expected Output

Sorted array: 1 2 2 3 3 4 8
Stability rule: When using cumulative counts, traverse the original input from right to left while placing elements in the output array.

This stable implementation supports non-negative integer keys. For negative keys, use an offset in the counting-array index, as in the earlier implementation.

15. Counting Sort Complexity

Let:

  • n = number of input elements.
  • k = number of possible values in the counting range.
Time Complexity = O(n + k)

The basic frequency-reconstruction version uses O(k) auxiliary space. The stable version uses O(n + k) auxiliary space because it also requires an output array.

17. When Should You Use These Algorithms?

Heap Sort

  • When guaranteed O(n log n) worst-case time is required.
  • When sorting in place is important.
  • When auxiliary array memory should be avoided.

Counting Sort

  • When sorting integers with a small or manageable range.
  • When duplicate values occur frequently.
  • When a non-comparison-based sorting method is appropriate.
  • As a stable subroutine in Radix Sort.

18. Common Programming Mistakes

  • Confusing Max Heap and Min Heap properties.
  • Using incorrect child indexes.
  • Forgetting to reduce the active heap size after extraction.
  • Calling heapify with an incorrect index.
  • Assuming Build Heap takes O(n log n).
  • Allocating an unnecessarily large Counting Sort frequency array.
  • Forgetting to offset negative values.
  • Failing to check dynamic memory allocation.
  • Forgetting to free allocated memory.
  • Confusing stable and unstable Counting Sort implementations.

19. Frequently Asked Placement Interview Questions

Q1. What is a Binary Heap?

A complete binary tree that satisfies the Max Heap or Min Heap property.

Q2. What is a Max Heap?

A heap in which every parent is greater than or equal to its children.

Q3. What is a Min Heap?

A heap in which every parent is less than or equal to its children.

Q4. Where is the maximum element stored in a Max Heap?

At the root, which is array index zero in a zero-based representation.

Q5. What is Heapify?

An operation that restores the heap property for a node and its affected subtree.

Q6. What is the time complexity of Max Heapify?

O(log n).

Q7. What is the time complexity of Build Heap?

O(n).

Q8. What is the time complexity of Heap Sort?

O(n log n) in best, average and worst cases.

Q9. Is Heap Sort stable?

No, the standard implementation is not stable.

Q10. Is Heap Sort in-place?

Yes, the iterative array implementation uses O(1) auxiliary array space.

Q11. What is Counting Sort?

A non-comparison-based sorting algorithm that sorts values using occurrence counts.

Q12. What is Counting Sort time complexity?

O(n + k), where n is the number of elements and k is the number of values in the counting range.

Q13. Can Counting Sort handle negative numbers?

Yes. An offset based on the minimum value can map negative values to valid counting-array indexes.

Q14. Is Counting Sort stable?

A stable version can be implemented using cumulative counts and an output array.

Q15. Why is Counting Sort not suitable for every dataset?

It may require excessive memory when the range of possible values is very large.

Q16. What is the difference between Heap Sort and Counting Sort?

Heap Sort compares elements and works for general comparable values. Counting Sort uses frequencies and is suitable for integer keys with a manageable range.

Q17. What is the parent index of an element at index i?

For a zero-based heap, the parent index is (i - 1) / 2 for non-root nodes.

Q18. What is the left child index?

2 * i + 1.

Q19. What is the right child index?

2 * i + 2.

Q20. Which sorting algorithm is used as a component of Radix Sort?

Stable Counting Sort is commonly used in Radix Sort.
