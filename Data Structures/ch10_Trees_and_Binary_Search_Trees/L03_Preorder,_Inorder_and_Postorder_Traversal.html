2. What is Tree Traversal?

Tree traversal is the process of visiting every node of a tree in a particular order.

Unlike arrays and linked lists, binary trees are non-linear data structures. Therefore, we need specific algorithms to visit all their nodes.

The two major categories are:

  1. Depth-First Search (DFS): Explores a subtree before moving to another subtree.
  2. Breadth-First Search (BFS): Visits nodes level by level.
Preorder, inorder and postorder are the three standard depth-first traversals of a binary tree. Level-order traversal is a breadth-first traversal and is covered separately in Lesson 4.

3. Example Binary Tree

Consider the following binary tree:

                 10
                /  \
               20   30
              / \   /
             40  50 60

The tree contains six nodes:

  • Root: 10
  • Left subtree: 20, 40 and 50
  • Right subtree: 30 and 60

4. Preorder Traversal

Preorder traversal visits the root node first, followed by the left subtree and then the right subtree.

Preorder = Root → Left → Right

Short form: NLR (Node, Left, Right).

Algorithm

  1. Visit the current node.
  2. Traverse the left subtree recursively.
  3. Traverse the right subtree recursively.

Dry Run

                 10
                /  \
               20   30
              / \   /
             40  50 60

Visiting sequence:

  1. Visit 10.
  2. Move left and visit 20.
  3. Move left and visit 40.
  4. Return to 20 and visit 50.
  5. Return to 10 and visit 30.
  6. Visit 60.
Preorder Output:

10 20 40 50 30 60

Recursive C Function

void preorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    printf("%d ", root->data);

    preorder(root->left);

    preorder(root->right);
}

5. Inorder Traversal

Inorder traversal visits the left subtree first, then the root node, followed by the right subtree.

Inorder = Left → Root → Right

Short form: LNR (Left, Node, Right).

Algorithm

  1. Traverse the left subtree recursively.
  2. Visit the current node.
  3. Traverse the right subtree recursively.

Dry Run

For the same binary tree:

                 10
                /  \
               20   30
              / \   /
             40  50 60

Visiting sequence:

  1. Go left from 10 to 20.
  2. Go left from 20 to 40.
  3. Visit 40.
  4. Return and visit 20.
  5. Visit 50.
  6. Return and visit 10.
  7. Visit 60.
  8. Visit 30.
Inorder Output:

40 20 50 10 60 30

Recursive C Function

void inorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    inorder(root->left);

    printf("%d ", root->data);

    inorder(root->right);
}
An important interview fact: Inorder traversal of a Binary Search Tree (BST) produces values in sorted order when the BST follows the usual ordering property.

6. Postorder Traversal

Postorder traversal visits the left subtree first, then the right subtree, and finally the root node.

Postorder = Left → Right → Root

Short form: LRN (Left, Right, Node).

Algorithm

  1. Traverse the left subtree recursively.
  2. Traverse the right subtree recursively.
  3. Visit the current node.

Dry Run

For the same binary tree:

                 10
                /  \
               20   30
              / \   /
             40  50 60

Visiting sequence:

  1. Visit 40.
  2. Visit 50.
  3. Visit 20.
  4. Visit 60.
  5. Visit 30.
  6. Visit 10.
Postorder Output:

40 50 20 60 30 10

Recursive C Function

void postorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    postorder(root->left);

    postorder(root->right);

    printf("%d ", root->data);
}

7. Comparison of Three DFS Traversals

Traversal Order Output
Preorder Root, Left, Right 10 20 40 50 30 60
Inorder Left, Root, Right 40 20 50 10 60 30
Postorder Left, Right, Root 40 50 20 60 30 10
All three traversals visit every node exactly once. Their time complexity is O(n), where n is the number of nodes.

8. Complete C11 Program – Recursive Traversals

This program constructs a binary tree and performs preorder, inorder and postorder traversal. 

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

void preorder(const struct Node *root) {
    if (root == NULL) {
        return;
    }

    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}

void inorder(const struct Node *root) {
    if (root == NULL) {
        return;
    }

    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

void postorder(const struct Node *root) {
    if (root == NULL) {
        return;
    }

    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *nodes[6] = {NULL};
    int values[6] = {10, 20, 30, 40, 50, 60};

    for (int i = 0; i < 6; i++) {
        nodes[i] = createNode(values[i]);

        if (nodes[i] == NULL) {
            printf("Memory allocation failed.\n");

            for (int j = 0; j < i; j++) {
                free(nodes[j]);
            }

            return 1;
        }
    }

    struct Node *root = nodes[0];

    root->left = nodes[1];
    root->right = nodes[2];

    nodes[1]->left = nodes[3];
    nodes[1]->right = nodes[4];

    nodes[2]->left = nodes[5];

    printf("Preorder: ");
    preorder(root);

    printf("\nInorder: ");
    inorder(root);

    printf("\nPostorder: ");
    postorder(root);

    printf("\n");

    freeTree(root);

    return 0;
}

Expected Output

Preorder: 10 20 40 50 30 60
Inorder: 40 20 50 10 60 30
Postorder: 40 50 20 60 30 10

Program Explanation

  • Six nodes are allocated dynamically.
  • The nodes are connected to construct the example tree.
  • Three recursive functions perform the traversals.
  • The traversal functions stop when they encounter NULL.
  • The tree is released using postorder memory cleanup.

9. Iterative Tree Traversal

Recursive traversal uses the function call stack automatically.

Iterative traversal uses an explicit stack data structure to control the traversal process.

Interviewers often ask for iterative inorder and preorder implementations because they test stack operations, pointer handling and traversal logic.

10. Iterative Preorder Traversal

Preorder can be implemented using one stack.

Algorithm

  1. Push the root onto the stack.
  2. While the stack is not empty, pop a node.
  3. Visit the popped node.
  4. Push its right child if it exists.
  5. Push its left child if it exists.
Push the right child before the left child because a stack follows LIFO (Last In, First Out). The left child must be processed first.

Algorithm Example

Initial stack: [10]

Pop 10, visit 10
Push 30, then 20

Pop 20, visit 20
Push 50, then 40

Pop 40, visit 40

Pop 50, visit 50

Pop 30, visit 30
Push 60

Pop 60, visit 60

Output: 10 20 40 50 30 60

C Function

void iterativePreorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    struct Node *stack[1000];
    int top = -1;

    stack[++top] = root;

    while (top != -1) {
        struct Node *current = stack[top--];

        printf("%d ", current->data);

        if (current->right != NULL) {
            stack[++top] = current->right;
        }

        if (current->left != NULL) {
            stack[++top] = current->left;
        }
    }
}

11. Iterative Inorder Traversal

Inorder traversal requires us to visit the leftmost node before visiting its parent.

Algorithm

  1. Start with the root node.
  2. Push the current node and continue moving left.
  3. When the current node becomes NULL, pop a node.
  4. Visit the popped node.
  5. Move to its right child.
  6. Repeat until both current is NULL and the stack is empty.

C Function

void iterativeInorder(struct Node *root) {
    struct Node *stack[1000];
    int top = -1;

    struct Node *current = root;

    while (current != NULL || top != -1) {

        while (current != NULL) {
            stack[++top] = current;
            current = current->left;
        }

        current = stack[top--];

        printf("%d ", current->data);

        current = current->right;
    }
}

Key Observation

The stack stores ancestors whose left subtrees are being processed. After visiting a node, the algorithm moves into its right subtree.

Inorder Output:

40 20 50 10 60 30

12. Iterative Postorder Traversal Using Two Stacks

Postorder is more complicated because the root must be visited after both subtrees.

One straightforward iterative approach uses two stacks.

Algorithm

  1. Push the root into the first stack.
  2. Pop a node from the first stack.
  3. Push that node into the second stack.
  4. Push its left child into the first stack if it exists.
  5. Push its right child into the first stack if it exists.
  6. Repeat until the first stack becomes empty.
  7. Pop and visit all nodes from the second stack.
The second stack reverses the processing order so that the final output follows Left → Right → Root.

C Function

void iterativePostorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    struct Node *stack1[1000];
    struct Node *stack2[1000];

    int top1 = -1;
    int top2 = -1;

    stack1[++top1] = root;

    while (top1 != -1) {
        struct Node *current = stack1[top1--];

        stack2[++top2] = current;

        if (current->left != NULL) {
            stack1[++top1] = current->left;
        }

        if (current->right != NULL) {
            stack1[++top1] = current->right;
        }
    }

    while (top2 != -1) {
        printf("%d ", stack2[top2--]->data);
    }
}
Postorder Output:

40 50 20 60 30 10

The three short iterative functions above use fixed-size stacks for illustration. A production implementation must check stack capacity before every push, or use a dynamically growing stack.

13. Complete C11 Program – All Iterative Traversals

The following complete program implements iterative preorder, inorder and postorder traversal. It checks stack capacity before every push. 

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Stack {
    struct Node *items[MAX_NODES];
    int top;
};

void initializeStack(struct Stack *s) {
    s->top = -1;
}

int isEmpty(const struct Stack *s) {
    return s->top == -1;
}

int push(struct Stack *s, struct Node *node) {
    if (s->top == MAX_NODES - 1) {
        return 0;
    }

    s->items[++s->top] = node;
    return 1;
}

struct Node *pop(struct Stack *s) {
    if (isEmpty(s)) {
        return NULL;
    }

    return s->items[s->top--];
}

struct Node *createNode(int value) {
    struct Node *node = malloc(sizeof *node);

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

void iterativePreorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    struct Stack s;
    initializeStack(&s);

    if (!push(&s, root)) {
        printf("Stack overflow.\n");
        return;
    }

    while (!isEmpty(&s)) {
        struct Node *current = pop(&s);

        printf("%d ", current->data);

        if (current->right != NULL) {
            if (!push(&s, current->right)) {
                printf("\nStack overflow.\n");
                return;
            }
        }

        if (current->left != NULL) {
            if (!push(&s, current->left)) {
                printf("\nStack overflow.\n");
                return;
            }
        }
    }
}

void iterativeInorder(struct Node *root) {
    struct Stack s;
    initializeStack(&s);

    struct Node *current = root;

    while (current != NULL || !isEmpty(&s)) {

        while (current != NULL) {
            if (!push(&s, current)) {
                printf("\nStack overflow.\n");
                return;
            }

            current = current->left;
        }

        current = pop(&s);

        printf("%d ", current->data);

        current = current->right;
    }
}

void iterativePostorder(struct Node *root) {
    if (root == NULL) {
        return;
    }

    struct Stack s1, s2;

    initializeStack(&s1);
    initializeStack(&s2);

    if (!push(&s1, root)) {
        printf("Stack overflow.\n");
        return;
    }

    while (!isEmpty(&s1)) {
        struct Node *current = pop(&s1);

        if (!push(&s2, current)) {
            printf("Stack overflow.\n");
            return;
        }

        if (current->left != NULL) {
            if (!push(&s1, current->left)) {
                printf("Stack overflow.\n");
                return;
            }
        }

        if (current->right != NULL) {
            if (!push(&s1, current->right)) {
                printf("Stack overflow.\n");
                return;
            }
        }
    }

    while (!isEmpty(&s2)) {
        printf("%d ", pop(&s2)->data);
    }
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *nodes[6] = {NULL};
    int values[6] = {10, 20, 30, 40, 50, 60};

    for (int i = 0; i < 6; i++) {
        nodes[i] = createNode(values[i]);

        if (nodes[i] == NULL) {
            printf("Memory allocation failed.\n");

            for (int j = 0; j < i; j++) {
                free(nodes[j]);
            }

            return 1;
        }
    }

    struct Node *root = nodes[0];

    root->left = nodes[1];
    root->right = nodes[2];

    nodes[1]->left = nodes[3];
    nodes[1]->right = nodes[4];

    nodes[2]->left = nodes[5];

    printf("Iterative Preorder: ");
    iterativePreorder(root);

    printf("\nIterative Inorder: ");
    iterativeInorder(root);

    printf("\nIterative Postorder: ");
    iterativePostorder(root);

    printf("\n");

    freeTree(root);

    return 0;
}

Expected Output

Iterative Preorder: 10 20 40 50 30 60
Iterative Inorder: 40 20 50 10 60 30
Iterative Postorder: 40 50 20 60 30 10

14. Recursive vs Iterative Traversal

Feature Recursive Iterative
Implementation Uses recursive function calls Uses an explicit stack
Stack management Handled by the runtime call stack Managed by the programmer
Code complexity Usually shorter Usually more detailed
Time complexity O(n) O(n)
Auxiliary space O(h) O(h) for preorder and inorder; O(n) for the two-stack postorder method
Stack overflow risk Deep recursion can exhaust the call stack Explicit stack capacity must be managed

15. Time and Space Complexity

Let:

  • n = number of nodes.
  • h = height of the tree.
Traversal Time Complexity Auxiliary Space
Recursive Preorder O(n) O(h)
Recursive Inorder O(n) O(h)
Recursive Postorder O(n) O(h)
Iterative Preorder O(n) O(h) worst case
Iterative Inorder O(n) O(h)
Iterative Postorder (two stacks) O(n) O(n)
For a balanced tree, h is approximately O(log n). For a completely skewed tree, h can be O(n).

16. Applications of Tree Traversals

Traversal Common Applications
Preorder Copying a tree, serializing a tree with NULL markers, prefix expression generation.
Inorder Retrieving sorted values from a BST, infix expression processing.
Postorder Deleting a tree, evaluating expression trees, calculating subtree results.

17. Common Interview Questions

Q1. What is preorder traversal?

Preorder visits Root, Left and Right in that order.

Q2. What is inorder traversal?

Inorder visits Left, Root and Right in that order.

Q3. What is postorder traversal?

Postorder visits Left, Right and Root in that order.

Q4. Which traversal of a BST produces sorted values?

Inorder traversal, provided the BST follows the standard ordering property.

Q5. Which traversal is useful for deleting a binary tree?

Postorder traversal, because child nodes are processed before their parent.

Q6. Which data structure is used for iterative DFS traversal?

Stack.

Q7. Why is the right child pushed before the left child in iterative preorder?

Because a stack follows LIFO. Pushing the right child first ensures that the left child is popped and processed first.

Q8. What is the time complexity of all three traversals?

O(n), because every node is visited exactly once.

Q9. What is the auxiliary space complexity of recursive traversal?

O(h), where h is the tree height.

Q10. Can a binary tree be reconstructed from preorder alone?

Not uniquely in general. Additional information, such as inorder traversal or explicit NULL markers, is needed to determine the tree structure.

Q11. What is the difference between DFS and BFS?

DFS explores a subtree deeply before backtracking, while BFS visits nodes level by level.

Q12. Which traversal is used to generate a postfix expression from an expression tree?

Postorder traversal.

20. Lesson Summary

  • Tree traversal visits every node in a defined order.
  • Preorder follows Root → Left → Right.
  • Inorder follows Left → Root → Right.
  • Postorder follows Left → Right → Root.
  • Recursive traversals use the function call stack.
  • Iterative DFS traversals use an explicit stack.
  • Inorder traversal of a BST produces sorted values.
  • Postorder is useful for safely freeing tree nodes.
  • All three traversals take O(n) time.
  • Recursive traversal uses O(h) auxiliary stack space.
