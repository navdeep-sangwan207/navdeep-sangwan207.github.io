Chapter 10: Trees and Binary Search Trees

Data Structures and Algorithms Using C

Placement-Oriented Learning | 11 Lessons

Chapter Overview

Learn tree data structures from fundamentals to advanced interview problems. This chapter covers binary trees, tree traversals, Binary Search Trees (BST), AVL trees, heaps and important tree-based coding problems.

Programming Language: C11

Prerequisites: C pointers, structures, dynamic memory allocation and recursion.
