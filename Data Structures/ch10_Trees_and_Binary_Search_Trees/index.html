Chapter 10: Trees and Binary Search Trees

Learn tree data structures, binary trees, tree traversals, Binary Search Trees (BST), tree algorithms and Trie data structures using C.

Course: Data Structures and Algorithms

Language: C11

Level: Placement Preparation

Total Lessons: 11

Chapter Overview

Trees are non-linear data structures used to represent hierarchical relationships. They are widely used in searching, indexing, databases, file systems, compilers and many other areas of computer science.

Placement Focus: Binary tree traversal, recursion, BST insertion and deletion, tree height, diameter, lowest common ancestor, path-sum problems, balanced trees and Trie operations.

What You Will Learn

  • Tree terminology and binary tree properties.
  • Binary tree representation and node implementation in C.
  • Preorder, inorder and postorder traversals.
  • Level-order and zigzag traversal.
  • Tree height, depth and diameter.
  • Binary Search Tree operations.
  • BST searching, insertion and deletion.
  • BST validation and lowest common ancestor.
  • Path sum and balanced binary tree problems.
  • Important placement-oriented tree problems.
  • Introduction to Trie data structures.
