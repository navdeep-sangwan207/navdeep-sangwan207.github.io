Chapter 10 – Lesson 10

Important Tree Interview Problems

Practise frequently asked binary-tree problems and learn reusable C11 solutions for technical interviews and coding assessments.

1. Learning Objectives

  • Understand top view and bottom view of a binary tree.
  • Implement left view and right view.
  • Perform boundary traversal.
  • Check whether two trees are identical or symmetric.
  • Determine whether one tree is a subtree of another.
  • Construct a binary tree from traversal arrays.
  • Serialize and deserialize a binary tree.
  • Analyse complexity and select suitable data structures.

2. Problem 1: Left View of a Binary Tree

The left view contains the first node visible at every level when the tree is observed from the left side.

Example

              1
            /   \
           2     3
          / \     \
         4   5     6
        /
       7

    Left View: 1 2 4 7

Approach: Recursive DFS

Visit the left subtree before the right subtree. Print a node the first time a new depth is reached.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define MAX_LEVELS 1000

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

void leftView(Node *root, int level, int *maxLevel)
{
    if (root == NULL) {
        return;
    }

    if (level >= MAX_LEVELS) {
        return;
    }

    if (level > *maxLevel) {
        printf("%d ", root->data);
        *maxLevel = level;
    }

    leftView(root->left, level + 1, maxLevel);
    leftView(root->right, level + 1, maxLevel);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(3);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(4);
    root->left->right = createNode(5);
    root->right->right = createNode(6);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left->left = createNode(7);

    if (root->left->left->left == NULL) {
        freeTree(root);
        return 1;
    }

    int maxLevel = 0;

    printf("Left View: ");
    leftView(root, 1, &maxLevel);
    printf("\n");

    freeTree(root);

    return 0;
}
Expected Output 
Left View: 1 2 4 7

Time Complexity: O(n).

Auxiliary Space: O(h).

4. Problem 3: Top View of a Binary Tree

The top view contains the first node encountered at each horizontal distance when the tree is viewed from above.

Horizontal distance (HD):

  • Root has HD = 0.
  • Left child has HD = parent HD - 1.
  • Right child has HD = parent HD + 1.

Example

              1
            /   \
           2     3
            \   /
             4 5

    Horizontal distances:

    Node 2: -1
    Node 1:  0
    Node 3: +1

    Top View: 2 1 3

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000
#define OFFSET 1000
#define MAP_SIZE 2001

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

typedef struct {
    Node *node;
    int hd;
} QueueItem;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

void topView(Node *root)
{
    if (root == NULL) {
        return;
    }

    int values[MAP_SIZE];
    int seen[MAP_SIZE] = {0};

    QueueItem queue[MAX_NODES];
    int front = 0;
    int rear = 0;

    int minHD = 0;
    int maxHD = 0;

    queue[rear++] = (QueueItem){root, 0};

    while (front < rear) {
        QueueItem current = queue[front++];

        int index = current.hd + OFFSET;

        if (index < 0 || index >= MAP_SIZE) {
            continue;
        }

        if (!seen[index]) {
            values[index] = current.node->data;
            seen[index] = 1;
        }

        if (current.hd < minHD) {
            minHD = current.hd;
        }

        if (current.hd > maxHD) {
            maxHD = current.hd;
        }

        if (current.node->left != NULL) {
            if (rear >= MAX_NODES) {
                printf("Queue capacity exceeded.\n");
                return;
            }

            queue[rear++] =
                (QueueItem){current.node->left,
                            current.hd - 1};
        }

        if (current.node->right != NULL) {
            if (rear >= MAX_NODES) {
                printf("Queue capacity exceeded.\n");
                return;
            }

            queue[rear++] =
                (QueueItem){current.node->right,
                            current.hd + 1};
        }
    }

    printf("Top View: ");

    for (int hd = minHD; hd <= maxHD; hd++) {
        int index = hd + OFFSET;

        if (seen[index]) {
            printf("%d ", values[index]);
        }
    }

    printf("\n");
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(3);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->right = createNode(4);
    root->right->left = createNode(5);

    if (root->left->right == NULL ||
        root->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    topView(root);

    freeTree(root);

    return 0;
}
Expected Output 
Top View: 2 1 3

Time Complexity: O(n + w), where w is the horizontal-distance range traversed for output.

Auxiliary Space: O(n + MAP_SIZE).

This demonstration uses fixed queue and horizontal-distance limits. It is intended for bounded interview examples. A scalable implementation should use dynamically sized storage or a hash map and handle queue capacity explicitly.

5. Problem 4: Bottom View of a Binary Tree

The bottom view contains the last node encountered at each horizontal distance during level-order traversal.

Key Difference

  • Top view stores only the first node at each horizontal distance.
  • Bottom view updates the stored node whenever another node at that horizontal distance is visited.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000
#define OFFSET 1000
#define MAP_SIZE 2001

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

typedef struct {
    Node *node;
    int hd;
} QueueItem;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

void bottomView(Node *root)
{
    if (root == NULL) {
        return;
    }

    int values[MAP_SIZE];
    int seen[MAP_SIZE] = {0};

    QueueItem queue[MAX_NODES];
    int front = 0;
    int rear = 0;

    int minHD = 0;
    int maxHD = 0;

    queue[rear++] = (QueueItem){root, 0};

    while (front < rear) {
        QueueItem current = queue[front++];

        int index = current.hd + OFFSET;

        if (index < 0 || index >= MAP_SIZE) {
            continue;
        }

        values[index] = current.node->data;
        seen[index] = 1;

        if (current.hd < minHD) {
            minHD = current.hd;
        }

        if (current.hd > maxHD) {
            maxHD = current.hd;
        }

        if (current.node->left != NULL) {
            if (rear >= MAX_NODES) {
                printf("Queue capacity exceeded.\n");
                return;
            }

            queue[rear++] =
                (QueueItem){current.node->left,
                            current.hd - 1};
        }

        if (current.node->right != NULL) {
            if (rear >= MAX_NODES) {
                printf("Queue capacity exceeded.\n");
                return;
            }

            queue[rear++] =
                (QueueItem){current.node->right,
                            current.hd + 1};
        }
    }

    printf("Bottom View: ");

    for (int hd = minHD; hd <= maxHD; hd++) {
        int index = hd + OFFSET;

        if (seen[index]) {
            printf("%d ", values[index]);
        }
    }

    printf("\n");
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(3);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->right = createNode(4);
    root->right->left = createNode(5);

    if (root->left->right == NULL ||
        root->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    bottomView(root);

    freeTree(root);

    return 0;
}
Expected Output 
Bottom View: 2 5 4

Time Complexity: O(n + w), where w is the horizontal-distance range traversed for output.

Auxiliary Space: O(n + MAP_SIZE).

When multiple nodes have the same horizontal distance, this implementation uses level-order processing and lets later visited nodes overwrite earlier ones. This is a common bottom-view convention.

6. Problem 5: Check Whether Two Binary Trees Are Identical

Two binary trees are identical if:

  • Both trees are empty, or both have a node at the same position.
  • Corresponding nodes contain equal values.
  • Their left subtrees are identical.
  • Their right subtrees are identical.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool areIdentical(Node *a, Node *b)
{
    if (a == NULL && b == NULL) {
        return true;
    }

    if (a == NULL || b == NULL) {
        return false;
    }

    return a->data == b->data &&
           areIdentical(a->left, b->left) &&
           areIdentical(a->right, b->right);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *tree1 = createNode(1);
    Node *tree2 = createNode(1);

    if (tree1 == NULL || tree2 == NULL) {
        freeTree(tree1);
        freeTree(tree2);
        return 1;
    }

    tree1->left = createNode(2);
    tree1->right = createNode(3);

    tree2->left = createNode(2);
    tree2->right = createNode(3);

    if (tree1->left == NULL ||
        tree1->right == NULL ||
        tree2->left == NULL ||
        tree2->right == NULL) {
        freeTree(tree1);
        freeTree(tree2);
        return 1;
    }

    if (areIdentical(tree1, tree2)) {
        printf("Trees are identical.\n");
    } else {
        printf("Trees are not identical.\n");
    }

    freeTree(tree1);
    freeTree(tree2);

    return 0;
}
Expected Output 
Trees are identical.

Time Complexity: O(n), where n is the number of nodes examined.

Auxiliary Space: O(h).

7. Problem 6: Check Whether a Binary Tree Is Symmetric

A binary tree is symmetric if its left and right subtrees are mirror images of each other.

Example

               1
             /   \
            2     2
           / \   / \
          3   4 4   3

    This tree is symmetric.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool isMirror(Node *a, Node *b)
{
    if (a == NULL && b == NULL) {
        return true;
    }

    if (a == NULL || b == NULL) {
        return false;
    }

    return a->data == b->data &&
           isMirror(a->left, b->right) &&
           isMirror(a->right, b->left);
}

bool isSymmetric(Node *root)
{
    if (root == NULL) {
        return true;
    }

    return isMirror(root->left, root->right);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(2);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(4);
    root->right->left = createNode(4);
    root->right->right = createNode(3);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    if (isSymmetric(root)) {
        printf("The tree is symmetric.\n");
    } else {
        printf("The tree is not symmetric.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
The tree is symmetric.

Time Complexity: O(n).

Auxiliary Space: O(h).

8. Problem 7: Check Whether One Tree Is a Subtree of Another

A tree S is a subtree of tree T if S matches a complete subtree of T, including its node values and structure.

Approach

  1. If the candidate subtree is empty, return true.
  2. If the main tree is empty while the candidate is non-empty, return false.
  3. Check whether both trees are identical at the current node.
  4. Otherwise, search the left and right subtrees of the main tree.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool areIdentical(Node *a, Node *b)
{
    if (a == NULL && b == NULL) {
        return true;
    }

    if (a == NULL || b == NULL) {
        return false;
    }

    return a->data == b->data &&
           areIdentical(a->left, b->left) &&
           areIdentical(a->right, b->right);
}

bool isSubtree(Node *root, Node *subtree)
{
    if (subtree == NULL) {
        return true;
    }

    if (root == NULL) {
        return false;
    }

    if (areIdentical(root, subtree)) {
        return true;
    }

    return isSubtree(root->left, subtree) ||
           isSubtree(root->right, subtree);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(3);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(4);
    root->right = createNode(5);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(1);
    root->left->right = createNode(2);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        return 1;
    }

    Node *subtree = createNode(4);

    if (subtree == NULL) {
        freeTree(root);
        return 1;
    }

    subtree->left = createNode(1);
    subtree->right = createNode(2);

    if (subtree->left == NULL ||
        subtree->right == NULL) {
        freeTree(root);
        freeTree(subtree);
        return 1;
    }

    if (isSubtree(root, subtree)) {
        printf("The second tree is a subtree.\n");
    } else {
        printf("The second tree is not a subtree.\n");
    }

    freeTree(root);
    freeTree(subtree);

    return 0;
}
Expected Output 
The second tree is a subtree.

Time Complexity: O(nm) in the worst case, where n is the number of nodes in the main tree and m is the number of nodes in the candidate tree.

Auxiliary Space: O(hT + hS) for recursive calls, where hT and hS are the respective tree heights.

9. Problem 8: Construct a Binary Tree from Inorder and Preorder Traversals

Given inorder and preorder arrays, reconstruct the original binary tree when all node values are distinct.

  • Preorder: Root → Left → Right.
  • Inorder: Left → Root → Right.

Example

    Preorder:  1 2 4 5 3
    Inorder:   4 2 5 1 3

    Constructed tree:

              1
            /   \
           2     3
          / \
         4   5

Algorithm

  1. The next preorder element is the root.
  2. Find that root in the inorder array.
  3. Elements before the root belong to the left subtree.
  4. Elements after the root belong to the right subtree.
  5. Recursively construct both subtrees.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int findIndex(int inorder[], int start,
              int end, int value)
{
    for (int i = start; i <= end; i++) {
        if (inorder[i] == value) {
            return i;
        }
    }

    return -1;
}

Node *buildTree(int inorder[], int preorder[],
                int inStart, int inEnd,
                int *preIndex)
{
    if (inStart > inEnd) {
        return NULL;
    }

    int rootValue = preorder[(*preIndex)++];

    int rootPosition =
        findIndex(inorder, inStart, inEnd, rootValue);

    if (rootPosition == -1) {
        return NULL;
    }

    Node *root = createNode(rootValue);

    if (root == NULL) {
        return NULL;
    }

    root->left = buildTree(inorder, preorder,
                           inStart, rootPosition - 1,
                           preIndex);

    root->right = buildTree(inorder, preorder,
                            rootPosition + 1, inEnd,
                            preIndex);

    return root;
}

void printInorder(Node *root)
{
    if (root == NULL) {
        return;
    }

    printInorder(root->left);
    printf("%d ", root->data);
    printInorder(root->right);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    int inorder[] = {4, 2, 5, 1, 3};
    int preorder[] = {1, 2, 4, 5, 3};

    int n = sizeof(inorder) / sizeof(inorder[0]);
    int preIndex = 0;

    Node *root = buildTree(inorder, preorder,
                           0, n - 1, &preIndex);

    if (root == NULL || preIndex != n) {
        printf("Tree construction failed.\n");
        freeTree(root);
        return 1;
    }

    printf("Constructed tree inorder: ");
    printInorder(root);
    printf("\n");

    freeTree(root);

    return 0;
}
Expected Output 
Constructed tree inorder: 4 2 5 1 3

Time Complexity: O(n²) in this implementation because each root is located using linear search.

Auxiliary Space: O(n) for the constructed tree and O(h) recursive stack, excluding the tree storage.

This compact implementation assumes valid, matching traversal arrays with distinct values. It is not a fully defensive parser: malformed traversals and allocation failures should be handled with explicit status propagation. An index map can reduce construction time to O(n) when implemented with suitable lookup storage.

10. Problem 9: Serialize and Deserialize a Binary Tree

Serialization converts a tree into a sequence that can be stored or transmitted.

Deserialization reconstructs the original tree from that sequence.

We use preorder traversal and a NULL marker (#) to preserve the tree structure.

Example

              1
            /   \
           2     3
                / \
               4   5

    Serialized form:

    1 2 # # 3 4 # # 5 # #

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define MAX_TOKENS 1000

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

typedef struct {
    char tokens[MAX_TOKENS][32];
    int count;
    int index;
} Serializer;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool serialize(Node *root, Serializer *s)
{
    if (s->count >= MAX_TOKENS) {
        return false;
    }

    if (root == NULL) {
        snprintf(s->tokens[s->count++],
                 32, "#");
        return true;
    }

    snprintf(s->tokens[s->count++],
             32, "%d", root->data);

    return serialize(root->left, s) &&
           serialize(root->right, s);
}

Node *deserialize(Serializer *s, bool *valid)
{
    if (!*valid || s->index >= s->count) {
        *valid = false;
        return NULL;
    }

    char *token = s->tokens[s->index++];

    if (token[0] == '#' && token[1] == '\0') {
        return NULL;
    }

    char *end;
    long value = strtol(token, &end, 10);

    if (*token == '\0' || *end != '\0' ||
        value < -2147483647L - 1 ||
        value > 2147483647L) {
        *valid = false;
        return NULL;
    }

    Node *root = createNode((int)value);

    if (root == NULL) {
        *valid = false;
        return NULL;
    }

    root->left = deserialize(s, valid);

    if (!*valid) {
        /* Free the partially constructed tree. */
        Node *left = root->left;
        root->left = NULL;
        free(root);
        freeTree(left);
        return NULL;
    }

    root->right = deserialize(s, valid);

    if (!*valid) {
        Node *left = root->left;
        Node *right = root->right;
        root->left = NULL;
        root->right = NULL;
        free(root);
        freeTree(left);
        freeTree(right);
        return NULL;
    }

    return root;
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

void printSerialized(Serializer *s)
{
    for (int i = 0; i < s->count; i++) {
        printf("%s ", s->tokens[i]);
    }

    printf("\n");
}

void printPreorder(Node *root)
{
    if (root == NULL) {
        return;
    }

    printf("%d ", root->data);
    printPreorder(root->left);
    printPreorder(root->right);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(3);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->left = createNode(4);
    root->right->right = createNode(5);

    if (root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    Serializer s = { .count = 0, .index = 0 };

    if (!serialize(root, &s)) {
        printf("Serialization capacity exceeded.\n");
        freeTree(root);
        return 1;
    }

    printf("Serialized tree: ");
    printSerialized(&s);

    bool valid = true;
    Node *copy = deserialize(&s, &valid);

    if (!valid || s.index != s.count) {
        printf("Deserialization failed.\n");
        freeTree(copy);
        freeTree(root);
        return 1;
    }

    printf("Deserialized preorder: ");
    printPreorder(copy);
    printf("\n");

    freeTree(root);
    freeTree(copy);

    return 0;
}
Expected Output 
Serialized tree: 1 2 # # 3 4 # # 5 # #
Deserialized preorder: 1 2 3 4 5

Time Complexity: O(n).

Auxiliary Space: O(n) for serialized tokens and reconstructed tree, plus O(h) recursion.

The example uses a fixed token array and fixed token width. A production implementation should use dynamically allocated serialization storage and range-safe integer parsing. The integer bounds shown are for conventional 32-bit int implementations.

13. Common Interview Questions and Answers

Q1. What is the left view of a binary tree?

Answer: The first visible node at every level when viewed from the left.

Q2. What is the difference between top view and bottom view?

Answer: Top view selects the first node at each horizontal distance, while bottom view selects the last node under the chosen traversal convention.

Q3. What is horizontal distance?

Answer: A coordinate used to group nodes vertically. The root has distance 0, left edges decrease it by 1, and right edges increase it by 1.

Q4. When are two binary trees identical?

Answer: When their structures and corresponding node values are equal.

Q5. What is a symmetric tree?

Answer: A tree whose left and right subtrees are mirror images.

Q6. What is a subtree?

Answer: A node together with all its descendants, preserving the original structure.

Q7. Why are NULL markers used in serialization?

Answer: They preserve missing-child positions, allowing the original structure to be reconstructed unambiguously.

Q8. Why do distinct values matter when constructing a tree from inorder and preorder traversals?

Answer: Distinct values allow the root's unique position in inorder traversal to be identified. Duplicate values can make reconstruction ambiguous.

Q9. Which traversal is commonly used for tree serialization?

Answer: Preorder traversal with NULL markers is a common choice.

Q10. What is the main advantage of level-order traversal for top and bottom views?

Answer: It processes nodes by increasing depth, making first-seen and last-seen horizontal-distance selection straightforward.

15. Lesson Summary

  • Tree views can be computed using DFS or BFS.
  • Horizontal distance helps solve top and bottom view problems.
  • Identical and symmetric tree checks use recursive comparisons.
  • Subtree checking combines tree traversal with structural matching.
  • Inorder and preorder traversals can reconstruct a tree when values are distinct.
  • Serialization requires structural markers to preserve missing children.
Placement priority: Focus on tree views, symmetry, subtree checking, traversal-based construction and serialization. Practise writing each solution without referring to notes.
