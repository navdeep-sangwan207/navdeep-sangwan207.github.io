Chapter 10 – Lesson 8

Validate BST and Lowest Common Ancestor

Learn to validate BST ordering and solve LCA problems using recursive and iterative approaches in C11.

1. Learning Objectives

  • Understand why validating a BST requires checking entire subtrees.
  • Validate a BST using minimum and maximum value boundaries.
  • Validate a BST using inorder traversal.
  • Understand the Lowest Common Ancestor problem.
  • Find LCA in a Binary Search Tree.
  • Find LCA in a general binary tree.
  • Distinguish between BST LCA and general binary tree LCA.
  • Analyze time and auxiliary space complexity.

2. Validate a Binary Search Tree

Given a binary tree, determine whether it satisfies the Binary Search Tree property.

For a strict BST with distinct keys:

  • Every key in the left subtree must be smaller than the current node.
  • Every key in the right subtree must be greater than the current node.
  • Both subtrees must independently satisfy the same condition.

Valid BST Example

              50
            /    \
           30     70
          / \    /  \
         20 40  60  80

This tree is a valid BST.

Invalid BST Example

              50
            /    \
           30     70
          / \    /  \
         20 60  65  80

Node 60 is in the left subtree of 50, but 60 is greater than 50.

Checking only the immediate children is insufficient. Every node must satisfy the ordering constraints inherited from all its ancestors.

3. Approach 1: Validate BST Using Minimum and Maximum Boundaries

The most useful recursive approach passes an allowed range to each node.

Algorithm

  1. If the node is NULL, return true.
  2. Check whether the node's key is strictly inside the allowed range.
  3. Validate the left subtree using the current key as its upper boundary.
  4. Validate the right subtree using the current key as its lower boundary.
  5. Return false if any node violates its range.

Example

              50
            /    \
           30     70
          / \    /  \
         20 40  60  80

    Root 50: allowed range (-∞, +∞)
    Node 30: allowed range (-∞, 50)
    Node 70: allowed range (50, +∞)
    Node 40: allowed range (30, 50)
    Node 60: allowed range (50, 70)

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <limits.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool isValidBSTRange(Node *root,
                     long long minValue,
                     long long maxValue)
{
    if (root == NULL) {
        return true;
    }

    if (root->data <= minValue ||
        root->data >= maxValue) {
        return false;
    }

    return isValidBSTRange(root->left,
                           minValue,
                           root->data) &&
           isValidBSTRange(root->right,
                           root->data,
                           maxValue);
}

bool isValidBST(Node *root)
{
    return isValidBSTRange(root, LLONG_MIN, LLONG_MAX);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(50);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(30);
    root->right = createNode(70);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(20);
    root->left->right = createNode(40);
    root->right->left = createNode(60);
    root->right->right = createNode(80);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    if (isValidBST(root)) {
        printf("The tree is a valid BST.\n");
    } else {
        printf("The tree is not a valid BST.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
The tree is a valid BST.

Time Complexity: O(n), because each node is checked at most once.

Auxiliary Space: O(h), due to recursion.

4. Approach 2: Validate BST Using Inorder Traversal

Inorder traversal of a valid BST with distinct keys must produce strictly increasing values.

Algorithm

  1. Traverse the left subtree.
  2. Compare the current node's value with the previously visited value.
  3. If the current value is not greater, the tree is invalid.
  4. Update the previous value.
  5. Traverse the right subtree.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <limits.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool inorderCheck(Node *root,
                  bool *hasPrevious,
                  long long *previous)
{
    if (root == NULL) {
        return true;
    }

    if (!inorderCheck(root->left,
                      hasPrevious,
                      previous)) {
        return false;
    }

    if (*hasPrevious && root->data <= *previous) {
        return false;
    }

    *previous = root->data;
    *hasPrevious = true;

    return inorderCheck(root->right,
                        hasPrevious,
                        previous);
}

bool isValidBST(Node *root)
{
    bool hasPrevious = false;
    long long previous = LLONG_MIN;

    return inorderCheck(root, &hasPrevious, &previous);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(50);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(30);
    root->right = createNode(70);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(20);
    root->left->right = createNode(40);
    root->right->left = createNode(60);
    root->right->right = createNode(80);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    if (isValidBST(root)) {
        printf("Valid BST using inorder traversal.\n");
    } else {
        printf("Invalid BST.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
Valid BST using inorder traversal.

Time Complexity: O(n).

Auxiliary Space: O(h).

The implementation uses a separate hasPrevious flag rather than treating INT_MIN as an unvisited sentinel. This also handles a BST containing INT_MIN correctly.

Technique Minimum and maximum boundaries Strictly increasing sequence
Time Complexity O(n) O(n)
Auxiliary Space O(h) O(h)

6. What is Lowest Common Ancestor?

The Lowest Common Ancestor (LCA) of two nodes is the deepest node that is an ancestor of both nodes.

A node can be considered an ancestor of itself.

Example

              50
            /    \
           30     70
          / \    /  \
         20 40  60  80

Consider nodes 20 and 40.

  • Ancestors of 20: 50, 30, 20.
  • Ancestors of 40: 50, 30, 40.
  • Common ancestors: 50 and 30.
  • Lowest common ancestor: 30.
LCA(20, 40) = 30

7. LCA in a Binary Search Tree

In a BST, the ordering property makes LCA calculation efficient.

Algorithm

  1. Start at the root.
  2. If both target keys are smaller than the current key, move left.
  3. If both target keys are greater than the current key, move right.
  4. Otherwise, the current node is the split point and is the LCA.

Example: LCA of 20 and 40

              50
            /
           30
          /  \
         20  40

    Both 20 and 40 are smaller than 50.
    Move left to 30.

    20 < 30 and 40 > 30.
    The paths split at 30.

    LCA = 30

Complete C11 Program: LCA in BST

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

Node *insert(Node *root, int key)
{
    if (root == NULL) {
        return createNode(key);
    }

    if (key < root->data) {
        Node *child = insert(root->left, key);

        if (child != NULL) {
            root->left = child;
        }
    }
    else if (key > root->data) {
        Node *child = insert(root->right, key);

        if (child != NULL) {
            root->right = child;
        }
    }

    return root;
}

Node *search(Node *root, int key)
{
    while (root != NULL) {
        if (key == root->data) {
            return root;
        }

        if (key < root->data) {
            root = root->left;
        } else {
            root = root->right;
        }
    }

    return NULL;
}

Node *lcaBST(Node *root, int n1, int n2)
{
    while (root != NULL) {
        if (n1 < root->data &&
            n2 < root->data) {
            root = root->left;
        }
        else if (n1 > root->data &&
                 n2 > root->data) {
            root = root->right;
        }
        else {
            return root;
        }
    }

    return NULL;
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = NULL;

    int values[] = {50, 30, 70, 20, 40, 60, 80};
    int count = sizeof(values) / sizeof(values[0]);

    for (int i = 0; i < count; i++) {
        Node *newRoot = insert(root, values[i]);

        if (root == NULL && newRoot == NULL) {
            freeTree(root);
            return 1;
        }

        root = newRoot;
    }

    int n1 = 20;
    int n2 = 40;

    if (search(root, n1) == NULL ||
        search(root, n2) == NULL) {
        printf("One or both keys are not present.\n");
    } else {
        Node *ancestor = lcaBST(root, n1, n2);

        if (ancestor != NULL) {
            printf("LCA of %d and %d is %d.\n",
                   n1, n2, ancestor->data);
        }
    }

    freeTree(root);

    return 0;
}
Expected Output 
LCA of 20 and 40 is 30.

Time Complexity: O(h).

Auxiliary Space: O(1), because the implementation is iterative.

The LCA routine assumes both target keys are present. The complete example checks their presence before calling it. Also, the insertion example is intended for this fixed sequence; for production code, use a status-returning insertion interface to distinguish duplicate keys and allocation failure.

8. LCA in a General Binary Tree

For a general binary tree, we cannot use BST ordering because smaller and greater values do not necessarily determine the search direction.

Recursive Algorithm

  1. If the current node is NULL, return NULL.
  2. If the current node matches either target, return the current node.
  3. Search for the first target in the left subtree.
  4. Search for the second target in the right subtree.
  5. If both results are non-NULL, the current node is the LCA.
  6. Otherwise, return whichever result is non-NULL.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

Node *lcaGeneral(Node *root, int n1, int n2)
{
    if (root == NULL) {
        return NULL;
    }

    if (root->data == n1 || root->data == n2) {
        return root;
    }

    Node *leftResult =
        lcaGeneral(root->left, n1, n2);

    Node *rightResult =
        lcaGeneral(root->right, n1, n2);

    if (leftResult != NULL && rightResult != NULL) {
        return root;
    }

    return leftResult != NULL ? leftResult : rightResult;
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(1);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(2);
    root->right = createNode(3);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(4);
    root->left->right = createNode(5);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->left = createNode(6);
    root->right->right = createNode(7);

    if (root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    int n1 = 4;
    int n2 = 5;

    Node *ancestor = lcaGeneral(root, n1, n2);

    if (ancestor != NULL) {
        printf("LCA of %d and %d is %d.\n",
               n1, n2, ancestor->data);
    } else {
        printf("LCA could not be determined.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
LCA of 4 and 5 is 2.

Time Complexity: O(n), because the algorithm may visit every node.

Auxiliary Space: O(h), due to recursion.

This basic recursive function assumes both target values exist in the tree and that values uniquely identify nodes. If one target is absent, it may return the other target as a partial result. A production implementation should verify the presence of both targets before reporting an LCA.

9. BST LCA vs General Binary Tree LCA

Parameter BST LCA General Binary Tree LCA
Uses ordering property Yes No
Search strategy Moves left, right or stops Searches both subtrees
Time Complexity O(h) O(n)
Auxiliary Space O(1) iterative O(h) recursive

10. Important Edge Cases

  • Empty tree: validation returns true; no LCA exists.
  • Single-node tree: it is a valid BST.
  • Duplicate keys: invalid under the strict BST policy used here.
  • INT_MIN and INT_MAX: boundary values must be handled without incorrect sentinel comparisons.
  • One LCA target equals the root.
  • Both targets lie in the same subtree.
  • Targets lie in different subtrees.
  • One or both targets are missing.
  • The two targets are the same node.

11. Common Interview Mistakes

  • Validating only parent-child relationships instead of entire subtree ranges.
  • Using inclusive boundaries when duplicates are not allowed.
  • Assuming inorder traversal is sorted for every binary tree.
  • Applying BST LCA logic to a general binary tree.
  • Forgetting that a node can be an ancestor of itself.
  • Reporting an LCA when one of the target nodes is missing.
  • Ignoring duplicate-value ambiguity when identifying nodes by data.

13. Common Interview Questions and Answers

Q1. Why is checking only immediate children insufficient for BST validation?

Answer: A node must satisfy constraints imposed by all its ancestors, not just its parent.

Q2. Which traversal can be used to validate a BST?

Answer: Inorder traversal. Its output must be strictly increasing for a strict BST with distinct keys.

Q3. What is the range-based validation method?

Answer: Every node is checked against an allowed minimum and maximum key inherited from its ancestors.

Q4. What is LCA?

Answer: The deepest node that is an ancestor of both target nodes.

Q5. How is LCA found efficiently in a BST?

Answer: Compare both keys with the current node and move left or right while both keys lie on the same side.

Q6. How is LCA found in a general binary tree?

Answer: Recursively search both subtrees. If both return non-NULL results, the current node is the LCA.

Q7. What is the time complexity of BST validation?

Answer: O(n), because every node may need to be visited.

Q8. What is the time complexity of LCA in a general binary tree?

Answer: O(n) in the worst case.

Q9. Can a node be its own ancestor for LCA purposes?

Answer: Yes. A node is considered an ancestor of itself in the standard LCA definition used here.

Q10. Why is BST LCA generally faster?

Answer: It uses the BST ordering property to avoid searching both subtrees.

  1. Level order
  2. Range-based validation
  3. Heapify
  4. Linear search

Q2. What should inorder traversal of a strict BST produce?

  1. Descending values
  2. Random values
  3. Strictly increasing values
  4. Only leaf values

Answer: C – O(n)

  2. Largest Common Array

15. Lesson Summary

  • BST validation must check the complete subtree ordering.
  • Range-based validation passes minimum and maximum boundaries.
  • Inorder traversal of a strict BST produces strictly increasing values.
  • LCA is the deepest common ancestor of two nodes.
  • BST LCA uses key comparisons and takes O(h) time.
  • General binary tree LCA may require O(n) time.
  • For reliable LCA results, verify that both target nodes exist.
Placement priority: Practise range-based BST validation and both versions of LCA. Be able to explain why BST ordering makes its LCA solution more efficient than the general binary tree solution.
