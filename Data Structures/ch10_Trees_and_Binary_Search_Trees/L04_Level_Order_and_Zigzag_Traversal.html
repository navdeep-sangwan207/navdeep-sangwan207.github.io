2. What is Breadth-First Search (BFS)?

Breadth-First Search is a traversal technique that visits nodes level by level, starting from the root.

BFS visits all nodes at the current level before moving to the next level.

Important: BFS uses a queue data structure because a queue follows FIFO (First In, First Out).

Example Binary Tree

                 10
                /  \
               20   30
              / \   / \
             40 50 60 70

Level Structure

Level Nodes
Level 0 10
Level 1 20, 30
Level 2 40, 50, 60, 70

Therefore, the level-order traversal is:

10 20 30 40 50 60 70

3. Queue Operations Used in BFS

A queue is a linear data structure that follows First In, First Out.

Its main operations are:

  • Enqueue: Insert an element at the rear.
  • Dequeue: Remove an element from the front.
  • Front: Access the next element to be removed.
  • isEmpty: Check whether the queue is empty.

Example Queue Operation

Enqueue 10:  [10]

Enqueue 20:  [10, 20]

Enqueue 30:  [10, 20, 30]

Dequeue:     [20, 30]

Dequeue:     [30]

BFS uses these queue operations to process tree nodes in the correct order.

4. Level Order Traversal Algorithm

Algorithm

  1. If the root is NULL, stop.
  2. Create an empty queue.
  3. Insert the root node into the queue.
  4. While the queue is not empty:
    • Remove the front node.
    • Visit the removed node.
    • Insert its left child if it exists.
    • Insert its right child if it exists.

Dry Run

Consider the following tree:

                 10
                /  \
               20   30
              / \   / \
             40 50 60 70
Step Dequeued Enqueued Queue after operation Output
Initial — 10 10 —
1 10 20, 30 20, 30 10
2 20 40, 50 30, 40, 50 10, 20
3 30 60, 70 40, 50, 60, 70 10, 20, 30
4 40 — 50, 60, 70 10, 20, 30, 40
5 50 — 60, 70 10, 20, 30, 40, 50
6 60 — 70 10, 20, 30, 40, 50, 60
7 70 — Empty 10, 20, 30, 40, 50, 60, 70

5. Complete C11 Program – Level Order Traversal

This program uses a circular queue to perform BFS. The queue has a fixed capacity and checks for overflow. 

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Queue {
    struct Node *items[MAX_NODES];
    int front;
    int rear;
    int count;
};

void initializeQueue(struct Queue *q) {
    q->front = 0;
    q->rear = 0;
    q->count = 0;
}

int isEmpty(const struct Queue *q) {
    return q->count == 0;
}

int isFull(const struct Queue *q) {
    return q->count == MAX_NODES;
}

int enqueue(struct Queue *q, struct Node *node) {
    if (isFull(q)) {
        return 0;
    }

    q->items[q->rear] = node;
    q->rear = (q->rear + 1) % MAX_NODES;
    q->count++;

    return 1;
}

struct Node *dequeue(struct Queue *q) {
    if (isEmpty(q)) {
        return NULL;
    }

    struct Node *node = q->items[q->front];

    q->front = (q->front + 1) % MAX_NODES;
    q->count--;

    return node;
}

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

int levelOrder(struct Node *root) {
    if (root == NULL) {
        return 1;
    }

    struct Queue q;
    initializeQueue(&q);

    if (!enqueue(&q, root)) {
        return 0;
    }

    while (!isEmpty(&q)) {
        struct Node *current = dequeue(&q);

        printf("%d ", current->data);

        if (current->left != NULL) {
            if (!enqueue(&q, current->left)) {
                return 0;
            }
        }

        if (current->right != NULL) {
            if (!enqueue(&q, current->right)) {
                return 0;
            }
        }
    }

    return 1;
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *nodes[7] = {NULL};
    int values[7] = {10, 20, 30, 40, 50, 60, 70};

    for (int i = 0; i < 7; i++) {
        nodes[i] = createNode(values[i]);

        if (nodes[i] == NULL) {
            printf("Memory allocation failed.\n");

            for (int j = 0; j < i; j++) {
                free(nodes[j]);
            }

            return 1;
        }
    }

    struct Node *root = nodes[0];

    root->left = nodes[1];
    root->right = nodes[2];

    nodes[1]->left = nodes[3];
    nodes[1]->right = nodes[4];

    nodes[2]->left = nodes[5];
    nodes[2]->right = nodes[6];

    printf("Level Order Traversal: ");

    if (!levelOrder(root)) {
        printf("\nQueue capacity exceeded.\n");
    } else {
        printf("\n");
    }

    freeTree(root);

    return 0;
}

Expected Output

Level Order Traversal: 10 20 30 40 50 60 70

Complexity Analysis

  • Time complexity: O(n).
  • Queue space: O(w), where w is the maximum width of the tree.
  • Overall auxiliary space: O(w).

6. Level-by-Level Traversal

Normal level-order traversal prints all nodes in one sequence. Sometimes interview problems require each level to be printed separately.

Expected Format

Level 0: 10
Level 1: 20 30
Level 2: 40 50 60 70

Important Technique: Capture Queue Size

At the beginning of each level, store the current queue size. Process exactly that many nodes before moving to the next level.

Complete C11 Program – Level-by-Level Traversal

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Queue {
    struct Node *items[MAX_NODES];
    int front;
    int rear;
    int count;
};

void initializeQueue(struct Queue *q) {
    q->front = 0;
    q->rear = 0;
    q->count = 0;
}

int enqueue(struct Queue *q, struct Node *node) {
    if (q->count == MAX_NODES) {
        return 0;
    }

    q->items[q->rear] = node;
    q->rear = (q->rear + 1) % MAX_NODES;
    q->count++;

    return 1;
}

struct Node *dequeue(struct Queue *q) {
    if (q->count == 0) {
        return NULL;
    }

    struct Node *node = q->items[q->front];

    q->front = (q->front + 1) % MAX_NODES;
    q->count--;

    return node;
}

struct Node *createNode(int value) {
    struct Node *node = malloc(sizeof *node);

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int printLevels(struct Node *root) {
    if (root == NULL) {
        printf("Tree is empty.\n");
        return 1;
    }

    struct Queue q;
    initializeQueue(&q);

    if (!enqueue(&q, root)) {
        return 0;
    }

    int level = 0;

    while (q.count > 0) {
        int levelSize = q.count;

        printf("Level %d: ", level);

        for (int i = 0; i < levelSize; i++) {
            struct Node *current = dequeue(&q);

            printf("%d ", current->data);

            if (current->left != NULL) {
                if (!enqueue(&q, current->left)) {
                    return 0;
                }
            }

            if (current->right != NULL) {
                if (!enqueue(&q, current->right)) {
                    return 0;
                }
            }
        }

        printf("\n");
        level++;
    }

    return 1;
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *nodes[7] = {NULL};
    int values[7] = {10, 20, 30, 40, 50, 60, 70};

    for (int i = 0; i < 7; i++) {
        nodes[i] = createNode(values[i]);

        if (nodes[i] == NULL) {
            printf("Memory allocation failed.\n");

            for (int j = 0; j < i; j++) {
                free(nodes[j]);
            }

            return 1;
        }
    }

    struct Node *root = nodes[0];

    root->left = nodes[1];
    root->right = nodes[2];

    nodes[1]->left = nodes[3];
    nodes[1]->right = nodes[4];

    nodes[2]->left = nodes[5];
    nodes[2]->right = nodes[6];

    printLevels(root);

    freeTree(root);

    return 0;
}

Expected Output

Level 0: 10
Level 1: 20 30
Level 2: 40 50 60 70

Why Does Capturing Queue Size Work?

Suppose the queue initially contains nodes 20 and 30. The stored level size is 2.

Processing node 20 may add 40 and 50 to the queue. Processing node 30 may add 60 and 70.

The loop still processes only the original two nodes. The newly inserted nodes are reserved for the next level.

This queue-size technique is one of the most important patterns used in BFS-based coding interview problems.

7. Zigzag Traversal

Zigzag traversal visits tree levels in alternating directions.

  • Level 0: Left to Right.
  • Level 1: Right to Left.
  • Level 2: Left to Right.
  • Level 3: Right to Left.

Example Binary Tree

                 10
                /  \
               20   30
              / \   / \
             40 50 60 70

Expected Zigzag Output

Level 0: 10
Level 1: 30 20
Level 2: 40 50 60 70

Zigzag: 10 30 20 40 50 60 70

Approach

  1. Use a queue to process nodes level by level.
  2. Maintain a direction flag.
  3. Store each level's values in a temporary array.
  4. If direction is left to right, store normally.
  5. If direction is right to left, store in reverse positions.
  6. Print the stored level.
  7. Toggle the direction for the next level.
Notice that the queue still inserts left child before right child. Zigzag order is achieved by changing the positions in which values are stored for each level.

8. Complete C11 Program – Zigzag Traversal

#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 1000

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Queue {
    struct Node *items[MAX_NODES];
    int front;
    int rear;
    int count;
};

void initializeQueue(struct Queue *q) {
    q->front = 0;
    q->rear = 0;
    q->count = 0;
}

int enqueue(struct Queue *q, struct Node *node) {
    if (q->count == MAX_NODES) {
        return 0;
    }

    q->items[q->rear] = node;
    q->rear = (q->rear + 1) % MAX_NODES;
    q->count++;

    return 1;
}

struct Node *dequeue(struct Queue *q) {
    if (q->count == 0) {
        return NULL;
    }

    struct Node *node = q->items[q->front];

    q->front = (q->front + 1) % MAX_NODES;
    q->count--;

    return node;
}

struct Node *createNode(int value) {
    struct Node *node = malloc(sizeof *node);

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int zigzagTraversal(struct Node *root) {
    if (root == NULL) {
        return 1;
    }

    struct Queue q;
    initializeQueue(&q);

    if (!enqueue(&q, root)) {
        return 0;
    }

    int leftToRight = 1;

    while (q.count > 0) {
        int levelSize = q.count;
        int values[MAX_NODES];

        for (int i = 0; i < levelSize; i++) {
            struct Node *current = dequeue(&q);

            int index;

            if (leftToRight) {
                index = i;
            } else {
                index = levelSize - 1 - i;
            }

            values[index] = current->data;

            if (current->left != NULL) {
                if (!enqueue(&q, current->left)) {
                    return 0;
                }
            }

            if (current->right != NULL) {
                if (!enqueue(&q, current->right)) {
                    return 0;
                }
            }
        }

        for (int i = 0; i < levelSize; i++) {
            printf("%d ", values[i]);
        }

        leftToRight = !leftToRight;
    }

    printf("\n");

    return 1;
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *nodes[7] = {NULL};
    int values[7] = {10, 20, 30, 40, 50, 60, 70};

    for (int i = 0; i < 7; i++) {
        nodes[i] = createNode(values[i]);

        if (nodes[i] == NULL) {
            printf("Memory allocation failed.\n");

            for (int j = 0; j < i; j++) {
                free(nodes[j]);
            }

            return 1;
        }
    }

    struct Node *root = nodes[0];

    root->left = nodes[1];
    root->right = nodes[2];

    nodes[1]->left = nodes[3];
    nodes[1]->right = nodes[4];

    nodes[2]->left = nodes[5];
    nodes[2]->right = nodes[6];

    printf("Zigzag Traversal: ");

    if (!zigzagTraversal(root)) {
        printf("\nQueue capacity exceeded.\n");
    }

    freeTree(root);

    return 0;
}

Expected Output

Zigzag Traversal: 10 30 20 40 50 60 70

Dry Run

Level Normal BFS order Direction Zigzag output
0 10 Left to Right 10
1 20, 30 Right to Left 30, 20
2 40, 50, 60, 70 Left to Right 40, 50, 60, 70

9. Maximum Width of a Binary Tree

The width of a level is the number of actual nodes present at that level.

The maximum width is the largest number of nodes present at any one level.

Example

                 10
                /  \
               20   30
              / \   /
             40 50 60
Level Nodes Width
0 10 1
1 20, 30 2
2 40, 50, 60 3

Maximum width = 3.

Complete C11 Function

int maximumWidth(struct Node *root) {
    if (root == NULL) {
        return 0;
    }

    struct Queue q;
    initializeQueue(&q);

    if (!enqueue(&q, root)) {
        return -1;
    }

    int maximum = 0;

    while (q.count > 0) {
        int levelSize = q.count;

        if (levelSize > maximum) {
            maximum = levelSize;
        }

        for (int i = 0; i < levelSize; i++) {
            struct Node *current = dequeue(&q);

            if (current->left != NULL) {
                if (!enqueue(&q, current->left)) {
                    return -1;
                }
            }

            if (current->right != NULL) {
                if (!enqueue(&q, current->right)) {
                    return -1;
                }
            }
        }
    }

    return maximum;
}

This function uses the same circular queue implementation from the earlier program.

Complexity

  • Time: O(n).
  • Auxiliary space: O(w).

10. DFS vs BFS

Feature DFS BFS
Full form Depth-First Search Breadth-First Search
Traversal Explores deeper before backtracking Visits level by level
Data structure Stack or recursion Queue
Common examples Preorder, inorder, postorder Level-order traversal
Time complexity O(n) O(n)
Auxiliary space O(h) for recursive traversal O(w) for queue-based traversal

11. Common Implementation Mistakes

  1. Using a stack instead of a queue: Standard level-order traversal requires FIFO processing.
  2. Incorrect child insertion order: Insert the left child before the right child for conventional left-to-right BFS.
  3. Not checking queue capacity: A fixed-size queue must detect overflow before insertion.
  4. Incorrect level-size handling: Capture the queue size before processing the current level.
  5. Reversing the entire traversal: Zigzag traversal reverses alternating levels, not the complete traversal sequence.
  6. Not handling an empty tree: Check whether the root is NULL before starting BFS.
  7. Forgetting to toggle direction: Change the zigzag direction after every completed level.

12. Time and Space Complexity

Let:

  • n = total number of nodes.
  • w = maximum width of the tree.
  • h = height of the tree.
Operation Time Auxiliary Space
Level-order traversal O(n) O(w)
Level-by-level traversal O(n) O(w)
Zigzag traversal O(n) O(w)
Maximum width O(n) O(w)

For a binary tree, the maximum width can be O(n). Therefore, BFS can require O(n) auxiliary memory in the worst case.

14. Common Interview Questions

Q1. What is BFS?

Breadth-First Search visits nodes level by level, starting from the root.

Q2. Which data structure is used in BFS?

A queue.

Q3. Why does BFS use a queue?

FIFO ordering ensures that nodes discovered earlier are processed before nodes discovered later.

Q4. What is level-order traversal?

It is the traversal of a binary tree level by level from left to right.

Q5. What is zigzag traversal?

It visits alternate levels in opposite directions.

Q6. How can we print each level separately?

Store the queue size at the beginning of a level and process exactly that many nodes.

Q7. What is the time complexity of BFS?

O(n), because every node is processed once.

Q8. What is the auxiliary space complexity of BFS?

O(w), where w is the maximum width of the tree.

Q9. What is the difference between BFS and DFS?

BFS explores level by level using a queue. DFS explores a branch deeply using recursion or a stack.

Q10. Can BFS be implemented using recursion?

It is possible, but a queue-based iterative implementation is the standard and most direct approach.

Q11. What is the maximum width of a binary tree?

It is the maximum number of actual nodes present at any single level.

Q12. Why is queue size captured before processing a level?

It separates the nodes belonging to the current level from the children being added for the next level.

16. Lesson Summary

  • BFS stands for Breadth-First Search.
  • BFS visits nodes level by level.
  • A queue is used for BFS.
  • Level-order traversal is the standard binary tree BFS traversal.
  • Capturing the queue size enables level-by-level processing.
  • Zigzag traversal reverses alternate levels.
  • Maximum width is the largest number of nodes at any level.
  • BFS takes O(n) time.
  • Its auxiliary space is O(w), where w is maximum tree width.
