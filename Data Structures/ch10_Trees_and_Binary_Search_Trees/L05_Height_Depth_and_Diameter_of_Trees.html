Chapter 10 – Lesson 5

Height, Depth and Diameter of Trees

Learn recursive tree measurements and solve an important tree interview problem efficiently using C.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Differentiate between depth and height of a node.
  • Calculate the height of a binary tree recursively.
  • Find the depth of a particular node.
  • Understand the diameter of a binary tree.
  • Implement the naive diameter algorithm.
  • Optimize diameter calculation from O(n²) to O(n).
  • Analyze recursion and auxiliary space complexity.

2. Example Binary Tree

                 10
               /    \
              20     30
             /  \      \
            40  50      60
                       /
                      70

We will use this tree to understand height, depth and diameter.

3. Depth of a Node

Depth is the number of edges from the root node to a particular node.

  • Depth of root node = 0
  • Depth of node 20 = 1
  • Depth of node 40 = 2
  • Depth of node 70 = 3
                 10          Depth = 0
               /    \
              20     30      Depth = 1
             /  \      \
            40  50      60   Depth = 2
                       /
                      70     Depth = 3
Important: Depth is measured from the root towards a node.

4. Height of a Node

Height of a node is the number of edges on the longest downward path from that node to a leaf.

  • Height of leaf nodes 40, 50 and 70 = 0
  • Height of node 20 = 1
  • Height of node 60 = 1
  • Height of node 30 = 2
  • Height of root node 10 = 3
Convention used throughout this lesson:
  • Height of a leaf node = 0
  • Height of an empty tree = -1
  • Height is measured in edges.

5. Difference Between Depth and Height

Depth Height
Measured from root to a node. Measured from a node to its deepest leaf.
Root has depth 0. Leaf has height 0.
Moves downward from root to target. Looks downward from target to a leaf.
Depends on the node's position from root. Depends on the longest downward path.

6. Height of a Binary Tree

The height of a binary tree is the height of its root node.

For every node, its height can be calculated using:

height(node) = 1 + max(height(node->left),
                       height(node->right))

Base condition:

height(NULL) = -1

For a leaf node:

height(leaf) = 1 + max(-1, -1)
             = 0

Recursive Algorithm

  1. If the current node is NULL, return -1.
  2. Calculate the height of the left subtree.
  3. Calculate the height of the right subtree.
  4. Return one plus the maximum of both heights.

7. Complete C11 Program: Calculate Tree Height

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int data)
{
    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = data;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

int height(Node *root)
{
    if (root == NULL) {
        return -1;
    }

    int leftHeight = height(root->left);
    int rightHeight = height(root->right);

    return 1 + (leftHeight > rightHeight
                ? leftHeight : rightHeight);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);
    root->right->right = createNode(60);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->right->left = createNode(70);

    if (root->right->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    printf("Height of binary tree: %d\n", height(root));

    freeTree(root);

    return 0;
}
Expected Output

Time Complexity: O(n)

Every node is visited exactly once.

Auxiliary Space: O(h)

The recursive call stack can contain up to h + 1 frames, where h is the tree height.

8. Finding the Depth of a Particular Node

To find the depth of a target value:

  1. Start from the root with depth 0.
  2. If the current node is NULL, report that the value was not found.
  3. If the current node contains the target, return the current depth.
  4. Search the left subtree, then the right subtree.
  5. Increase depth by one when moving to a child.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int data)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = data;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int findDepth(Node *root, int target, int depth)
{
    if (root == NULL) {
        return -1;
    }

    if (root->data == target) {
        return depth;
    }

    int result = findDepth(root->left, target, depth + 1);

    if (result != -1) {
        return result;
    }

    return findDepth(root->right, target, depth + 1);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);
    root->right->right = createNode(60);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->right->left = createNode(70);

    if (root->right->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    int target = 70;
    int depth = findDepth(root, target, 0);

    if (depth == -1) {
        printf("%d was not found in the tree.\n", target);
    } else {
        printf("Depth of %d: %d\n", target, depth);
    }

    freeTree(root);

    return 0;
}
Expected Output 
Depth of 70: 3

Time Complexity: O(n) in the worst case, because the search may visit every node.

Auxiliary Space: O(h) for the recursion stack.

This implementation assumes node values are unique. If duplicate values are allowed, a value alone may not identify one particular node.

9. Diameter of a Binary Tree

The diameter of a binary tree is the number of edges on the longest path between any two nodes.

The path does not necessarily pass through the root.

                 10
               /    \
              20     30
             /  \      \
            40  50      60
                       /
                      70

One longest path is:

        40 → 20 → 10 → 30 → 60 → 70

This path contains 5 edges. Therefore:

Diameter = 5 edges

If diameter is measured in nodes instead, the same path contains 6 nodes. This lesson consistently uses the edge-count convention.

10. Diameter Formula

For any node, the longest path passing through that node can be calculated using:

diameter through node =
    height(left subtree) + height(right subtree) + 2

The overall diameter is the maximum of:

  1. Diameter of the left subtree.
  2. Diameter of the right subtree.
  3. Longest path passing through the current node.
diameter(root) = max(
    diameter(left),
    diameter(right),
    height(left) + height(right) + 2
)

11. Naive Diameter Algorithm – O(n²)

The straightforward approach repeatedly calculates subtree heights while calculating the diameter.

Algorithm

  1. If the tree is empty, return 0.
  2. Calculate the height of the left subtree.
  3. Calculate the height of the right subtree.
  4. Calculate the diameter passing through the current node.
  5. Recursively calculate left and right subtree diameters.
  6. Return the maximum of all three values.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int data)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = data;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int max(int a, int b)
{
    return a > b ? a : b;
}

int height(Node *root)
{
    if (root == NULL) {
        return -1;
    }

    return 1 + max(height(root->left),
                   height(root->right));
}

int diameterNaive(Node *root)
{
    if (root == NULL) {
        return 0;
    }

    int leftHeight = height(root->left);
    int rightHeight = height(root->right);

    int throughRoot = leftHeight + rightHeight + 2;

    int leftDiameter = diameterNaive(root->left);
    int rightDiameter = diameterNaive(root->right);

    return max(throughRoot,
               max(leftDiameter, rightDiameter));
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);
    root->right->right = createNode(60);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->right->left = createNode(70);

    if (root->right->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    printf("Diameter (naive): %d edges\n",
           diameterNaive(root));

    freeTree(root);

    return 0;
}
Expected Output 
Diameter (naive): 5 edges

Complexity Analysis

Worst-case Time Complexity: O(n²)

At each node, the algorithm may calculate subtree heights again. In a skewed tree, this repeated work can result in quadratic time.

Auxiliary Space: O(h)

Space is used by recursive calls. The height and diameter calls execute sequentially rather than maintaining separate full-tree data structures.

12. Optimized Diameter Algorithm – O(n)

The main inefficiency in the naive solution is repeatedly calculating the same subtree heights.

We can optimize the solution by calculating height and diameter information together in a single postorder traversal.

Approach

  1. Recursively process the left subtree.
  2. Recursively process the right subtree.
  3. Calculate the current node's height.
  4. Calculate the longest path passing through the current node.
  5. Update the maximum diameter.
leftHeight  = height(left)
rightHeight = height(right)

currentHeight = 1 + max(leftHeight, rightHeight)

currentDiameter = leftHeight + rightHeight + 2
Key interview insight: Each node's height is calculated once. The algorithm avoids repeatedly traversing the same subtrees.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int data)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = data;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int max(int a, int b)
{
    return a > b ? a : b;
}

/*
   Returns subtree height.
   Updates the maximum diameter through
   the diameter pointer.
*/
int diameterOptimized(Node *root, int *diameter)
{
    if (root == NULL) {
        return -1;
    }

    int leftHeight =
        diameterOptimized(root->left, diameter);

    int rightHeight =
        diameterOptimized(root->right, diameter);

    int currentDiameter =
        leftHeight + rightHeight + 2;

    if (currentDiameter > *diameter) {
        *diameter = currentDiameter;
    }

    return 1 + max(leftHeight, rightHeight);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);
    root->right->right = createNode(60);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->right->left = createNode(70);

    if (root->right->right->left == NULL) {
        freeTree(root);
        return 1;
    }

    int diameter = 0;

    diameterOptimized(root, &diameter);

    printf("Diameter (optimized): %d edges\n", diameter);

    freeTree(root);

    return 0;
}
Expected Output 
Diameter (optimized): 5 edges

Complexity Analysis

Time Complexity: O(n)

Every node is processed exactly once.

Auxiliary Space: O(h)

The recursion stack requires space proportional to the height of the tree.

13. Naive vs Optimized Diameter

Parameter Naive Approach Optimized Approach
Technique Repeated height calculation Single postorder traversal
Time Complexity O(n²) worst case O(n)
Auxiliary Space O(h) O(h)
Height Calculation Repeated for subtrees Calculated once per node
Interview Preference Useful as a baseline Preferred efficient solution

14. Important Edge Cases

Tree Structure Height Diameter (edges)
Empty tree -1 0
Single node 0 0
Two connected nodes 1 1
Three-node skewed tree 2 2
Perfect binary tree with 7 nodes 2 4
Always clarify whether a problem measures height and diameter in edges or nodes. The numerical answers differ by one for a non-empty longest path when converting from edges to nodes.

15. Common Interview Mistakes

  • Confusing the depth of a node with its height.
  • Using 0 as the height of an empty tree while applying an edge-count formula that expects -1.
  • Assuming the diameter must pass through the root.
  • Returning only the height when the problem asks for diameter.
  • Recalculating subtree heights repeatedly instead of using a postorder solution.
  • Forgetting that a single-node tree has diameter 0 edges.
  • Ignoring recursion stack space for a highly skewed tree.

17. Common Interview Questions and Answers

Q1. What is the difference between height and depth?

Answer: Depth measures the number of edges from the root to a node. Height measures the number of edges on the longest downward path from a node to a leaf.

Q2. What is the height of an empty binary tree?

Answer: Under the edge-count convention used here, it is -1.

Q3. What is the height of a leaf node?

Answer: Zero, because there are no edges from the leaf to a lower node.

Q4. What is the diameter of a binary tree?

Answer: The number of edges on the longest path between any two nodes in the tree.

Q5. Does the diameter always pass through the root?

Answer: No. The longest path may lie entirely inside the left or right subtree.

Q6. What is the time complexity of the naive diameter algorithm?

Answer: O(n²) in the worst case because subtree heights are repeatedly calculated.

Q7. How can diameter be calculated in O(n)?

Answer: Use postorder traversal. Calculate the left and right subtree heights once and update the maximum diameter at each node.

Q8. Why is postorder traversal suitable for the optimized algorithm?

Answer: A node's height depends on the heights of its children, so both subtrees must be processed before the current node.

Q9. What is the auxiliary space complexity of recursive height calculation?

Answer: O(h), where h is the height of the tree, due to the recursion call stack.

Q10. What is the diameter of a single-node tree?

Answer: Zero edges.

19. Lesson Summary

  • Depth measures the distance from the root to a node.
  • Height measures the longest downward path from a node to a leaf.
  • Tree height is the height of the root.
  • Diameter is the longest path between any two nodes.
  • The naive diameter algorithm has O(n²) worst-case time complexity.
  • The optimized postorder algorithm calculates diameter in O(n) time.
  • Recursive tree algorithms use O(h) auxiliary stack space.
Placement priority: Be prepared to explain why the naive diameter algorithm is inefficient and how postorder traversal enables the O(n) solution.
