2. Introduction to Tree Data Structure

A Tree is a non-linear hierarchical data structure consisting of nodes connected through edges. It represents relationships between elements in a parent-child hierarchy.

Unlike arrays and linked lists, which generally organize data sequentially, trees organize information hierarchically.

Real-World Applications

  • File and directory systems in operating systems.
  • Database indexing.
  • HTML Document Object Model (DOM).
  • Organization management hierarchies.
  • Expression evaluation in compilers.
  • Searching and sorting algorithms.
  • Decision-making systems.
Placement Insight: Tree data structures are frequently tested in technical interviews, coding assessments and software development placement examinations.

4. Important Tree Terminology

Term Definition Example
Node An individual element in a tree. A, B, C
Root The topmost node of the tree. A
Edge A connection between two nodes. A-B
Parent A node that has one or more children. A is parent of B and C.
Child A node directly connected below a parent. B is child of A.
Sibling Nodes sharing the same parent. B and C
Leaf A node having no children. D, E, F, G
Internal Node A node having at least one child. A, B, C
Degree Number of children of a node. Degree of A = 2
Depth Number of edges from root to a node. Depth of D = 2
Height Number of edges on the longest downward path to a leaf. Height of root A = 2
Subtree A node together with all its descendants. Subtree rooted at B
Ancestor A node on the path from the root to another node. A is ancestor of D.
Descendant A node below another node in the hierarchy. D is descendant of A.
Interview Tip: Depth and height are different concepts. Depth is measured from the root down to a node. Height is measured from a node down to its deepest leaf.

5. Important Properties of a Tree

  1. A non-empty tree has exactly one root.
  2. A tree containing n nodes has exactly n - 1 edges.
  3. Every node except the root has exactly one parent.
  4. There is exactly one path from the root to any node.
  5. A tree does not contain cycles.
  6. Removing any edge from a tree disconnects it.
  7. Adding an edge between two existing nodes creates a cycle.

Example

If a tree contains 7 nodes, its number of edges is:

E = N - 1 = 7 - 1 = 6

6. Types of Trees

6.1 General Tree

A general tree allows a node to have any number of children. There is no fixed limit on the number of children.

6.2 Binary Tree

A binary tree is a tree in which each node can have at most two children, called the left child and right child.

Each node can have zero, one or two children.

6.3 Full Binary Tree

A full binary tree is a binary tree in which every node has either zero or exactly two children.

6.4 Complete Binary Tree

A complete binary tree has all levels completely filled except possibly the last level. The last level is filled from left to right.

6.5 Perfect Binary Tree

A perfect binary tree has every internal node with exactly two children, and all leaf nodes are at the same level.

6.6 Skewed Binary Tree

A skewed binary tree is a binary tree in which each node has only one child. It can be left-skewed or right-skewed.

Important Difference: Every perfect binary tree is both full and complete. However, every full or complete binary tree is not necessarily perfect.

7. Mathematical Properties of Binary Trees

Assume that the root is at level 0 and height is measured using the number of edges.

7.1 Maximum Nodes at Level L

Maximum nodes = 2L

Example: At level 3, the maximum number of nodes is:

23 = 8

7.2 Maximum Nodes in a Binary Tree of Height h

Maximum nodes = 2h+1 - 1

Example: For height 3:

24 - 1 = 15

7.3 Minimum Height for n Nodes

Minimum height = ceil(log2(n + 1)) - 1

7.4 Maximum Height for n Nodes

Maximum height = n - 1
These formulas use edge-based height. Some textbooks define height by counting nodes instead. Always identify the convention used in a question.

8. Binary Tree Node Representation in C

In C, a binary tree node is generally implemented using a structure containing:

  • One data field.
  • One pointer to the left child.
  • One pointer to the right child.
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

The left and right pointers connect the current node to its child nodes.

Creating a New Node

Node *createNode(int value) {
    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}
Why use malloc()? It dynamically allocates memory for each node. This allows the tree to grow or shrink during program execution.

9. Complete C11 Program - Basic Tree Representation

This program creates a binary tree, connects its nodes, displays preorder traversal, counts total nodes and leaf nodes, calculates height and releases allocated memory. 

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

/* Create a new tree node */
Node *createNode(int value) {
    Node *newNode = malloc(sizeof(Node));

    if (newNode == NULL) {
        printf("Memory allocation failed!\n");
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

/* Count total nodes */
int countNodes(const Node *root) {
    if (root == NULL) {
        return 0;
    }

    return 1 + countNodes(root->left)
             + countNodes(root->right);
}

/* Count leaf nodes */
int countLeafNodes(const Node *root) {
    if (root == NULL) {
        return 0;
    }

    if (root->left == NULL &&
        root->right == NULL) {
        return 1;
    }

    return countLeafNodes(root->left)
         + countLeafNodes(root->right);
}

/* Calculate height using edges */
int treeHeight(const Node *root) {
    if (root == NULL) {
        return -1;
    }

    int leftHeight = treeHeight(root->left);
    int rightHeight = treeHeight(root->right);

    return 1 + (leftHeight > rightHeight
                ? leftHeight : rightHeight);
}

/* Preorder traversal */
void displayPreorder(const Node *root) {
    if (root == NULL) {
        return;
    }

    printf("%d ", root->data);

    displayPreorder(root->left);
    displayPreorder(root->right);
}

/* Free all allocated nodes */
void freeTree(Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);

    free(root);
}

int main(void) {

    Node *root = createNode(10);

    if (root == NULL) {
        return EXIT_FAILURE;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL ||
        root->right == NULL) {
        freeTree(root);
        return EXIT_FAILURE;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        return EXIT_FAILURE;
    }

    printf("Preorder Traversal: ");
    displayPreorder(root);

    printf("\nTotal Nodes: %d", countNodes(root));
    printf("\nLeaf Nodes: %d", countLeafNodes(root));
    printf("\nTree Height: %d\n", treeHeight(root));

    freeTree(root);

    return EXIT_SUCCESS;
}

10. Expected Output

Preorder Traversal: 10 20 40 50 30 Total Nodes: 5 Leaf Nodes: 3 Tree Height: 2

11. Program Dry Run

The program creates the following tree:

Root = 10 | Left child = 20 | Right child = 30

Node Left Child Right Child
102030
204050
30NULLNULL
40NULLNULL
50NULLNULL

Preorder Traversal

Preorder follows the sequence: Root - Left - Right.

  1. Visit node 10.
  2. Move to the left subtree and visit 20.
  3. Visit 40.
  4. Backtrack and visit 50.
  5. Move to the right subtree and visit 30.
Result: 10 20 40 50 30

Node Counting

The tree contains five nodes: 10, 20, 30, 40 and 50.

Leaf Node Counting

Nodes 30, 40 and 50 do not have children.

Number of leaf nodes = 3

Height Calculation

The longest path from root 10 to a leaf is:

10 -> 20 -> 40

This path contains two edges. Therefore, tree height is 2.

12. Time and Space Complexity

Operation Time Complexity
Create one node O(1)
Count total nodes O(n)
Count leaf nodes O(n)
Calculate height O(n)
Preorder traversal O(n)
Free entire tree O(n)

Here, n represents the total number of nodes and h represents the height of the tree.

Auxiliary space for recursive operations is O(h), due to the recursive call stack. In a balanced tree, h is O(log n). In a skewed tree, h can be O(n).

13. Placement Interview Questions and Answers

Q1. What is a tree data structure?
A tree is a non-linear hierarchical data structure consisting of nodes connected through edges.
Q2. How many edges are present in a tree containing 100 nodes?
A tree with n nodes has n - 1 edges. Therefore, 100 - 1 = 99 edges.
Q3. What is the difference between a binary tree and a Binary Search Tree?
A binary tree allows at most two children per node. A BST additionally follows an ordering rule: smaller values are placed in the left subtree and larger values in the right subtree, under the distinct-key convention.
Q4. Can a binary tree contain duplicate values?
Yes. A binary tree allows duplicate values. A BST must define a consistent policy for handling duplicate keys.
Q5. What is a leaf node?
A leaf node is a node that does not have any children.
Q6. What is the maximum number of nodes at level 4?
Maximum nodes = 24 = 16.
Q7. What is the maximum number of nodes in a binary tree of height 3?
Maximum nodes = 24 - 1 = 15.
Q8. What is the worst-case height of a binary tree containing 10 nodes?
The maximum height is 9 edges, when the tree is completely skewed.
Q9. Why are pointers used in C tree implementation?
Pointers connect dynamically allocated nodes and allow the tree to grow or shrink during program execution.
Q10. What happens if dynamically allocated tree nodes are not freed?
The program causes a memory leak because allocated memory is not released for reuse during the process.
Q11. What is the difference between a full and complete binary tree?
In a full binary tree, every node has either zero or two children. In a complete binary tree, all levels except possibly the last are full, and the last level is filled from left to right.
Q12. What is the space complexity of recursive tree traversal?
O(h), where h is the height of the tree, due to recursive function calls.
