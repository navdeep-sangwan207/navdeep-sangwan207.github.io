Chapter 10 – Lesson 1: Tree Terminology and Binary Trees

Understand non-linear data structures, tree terminology, binary tree properties, different types of binary trees and their practical applications.

Course: Data Structures and Algorithms using C

Language: C11

Level: Placement Preparation

1. Learning Objectives

After completing this lesson, you should be able to:

  • Understand the concept of a tree data structure.
  • Differentiate linear and non-linear data structures.
  • Identify root, parent, child, sibling and leaf nodes.
  • Understand edges, paths, depth, height and levels.

  • Understand common tree applications and interview questions.

2. What Is a Tree Data Structure?

A tree is a non-linear hierarchical data structure consisting of nodes connected by edges.

Unlike arrays and linked lists, which organize elements sequentially, a tree represents parent-child relationships.

Example

                  A
                /   \
               B     C
              / \     \
             D   E     F

In this tree:

  • A is the root node.
  • B and C are children of A.
  • D and E are children of B.
  • F is a child of C.
  • D, E and F are leaf nodes.

Why Are Trees Required?

  • Represent hierarchical relationships.
  • Support efficient searching and sorting.
  • Represent file and directory structures.
  • Organize database indexes.
  • Represent expressions in compilers.
  • Support decision-making algorithms.

3. Linear vs Non-Linear Data Structures

Linear Data Structures Non-Linear Data Structures
Elements are arranged sequentially. Elements are arranged hierarchically or as networks.
Each element generally has a predecessor and successor, where applicable. A node can connect to multiple other nodes.
Traversal is generally sequential. Traversal can follow different paths.
Examples: arrays, linked lists, stacks and queues. Examples: trees and graphs.

4. Basic Tree Terminology

Consider the following tree:

                     A
                   /   \
                  B     C
                 / \   / \
                D   E F   G
                   /
                  H

4.1 Node

A node is an individual element of a tree that stores data and may contain links to child nodes.

4.2 Root Node

The root is the topmost node of a tree. It has no parent.

Example: A is the root.

4.3 Edge

An edge is a connection between two nodes.

The tree above has 7 edges.

4.4 Parent Node

A node that has one or more child nodes is called a parent.

Example: B is the parent of D and E.

4.5 Child Node

A node directly connected below another node is called its child.

Example: D and E are children of B.

4.6 Sibling Nodes

Nodes having the same parent are called siblings.

Example: D and E are siblings.

4.7 Leaf Node

A node with no children is called a leaf node or terminal node.

Example: D, F, G and H are leaf nodes.

4.8 Internal Node

A node having at least one child is called an internal node.

Example: A, B, C and E are internal nodes.

4.9 Ancestor

Any node on the path from the root to a particular node, excluding that node itself, is its ancestor.

Example: A and B are ancestors of D.

4.10 Descendant

A node that exists below another node in its subtree is called a descendant.

Example: D, E and H are descendants of B.

4.11 Path

A path is a sequence of nodes connected through edges.

Example: A → B → E → H.

4.12 Degree of a Node

The degree of a node is the number of its children.

Example: degree(A) = 2, degree(B) = 2, degree(E) = 1 and degree(D) = 0.

4.13 Degree of a Tree

The degree of a tree is the maximum degree of any node in that tree.

Example: The tree above has degree 2.

4.14 Subtree

A subtree is a tree formed by a node and all its descendants.

Example: The subtree rooted at B contains B, D, E and H.

5. Depth, Height and Level of a Node

These concepts are frequently asked in technical interviews. Be careful about the convention used when counting edges or nodes.

5.1 Depth of a Node

The depth of a node is the number of edges from the root to that node.

  • Depth of root A = 0.
  • Depth of B = 1.
  • Depth of E = 2.
  • Depth of H = 3.

5.2 Height of a Node

The height of a node is the number of edges in the longest downward path from that node to a leaf.

  • Height of leaf D = 0.
  • Height of E = 1.
  • Height of B = 2.
  • Height of A = 3.

5.3 Height of a Tree

The height of a tree is the height of its root node. Under the edge-count convention, a tree containing only one node has height 0.

5.4 Level of a Node

In this course, the root is considered to be at level 0. Therefore, level equals depth under this convention.

Some textbooks define the root as level 1 and height using node count instead of edge count. Always state the convention when answering an interview question.

6. What Is a Binary Tree?

A binary tree is a tree in which each node can have at most two children.

The two possible child references are:

  • Left child
  • Right child
                    10
                   /  \
                  20   30
                 / \     \
                40  50    60

A node can have zero, one or two children. It cannot have more than two children.

A binary tree does not automatically follow the Binary Search Tree ordering property. A Binary Search Tree is a special type of binary tree.

7. Types of Binary Trees

7.1 Full Binary Tree

A full binary tree is a binary tree in which every node has either zero or exactly two children. 

              1
             / \
            2   3
           / \
          4   5

Every internal node has exactly two children.

7.2 Complete Binary Tree

A complete binary tree has all levels completely filled except possibly the last level. Nodes at the last level are filled from left to right without gaps. 

              1
             / \
            2   3
           / \  /
          4  5 6

Complete binary trees are important in heap implementation.

7.3 Perfect Binary Tree

A perfect binary tree has all internal nodes with exactly two children, and all leaf nodes are at the same level. 

              1
             / \
            2   3
           / \ / \
          4  5 6  7

7.4 Balanced Binary Tree

A height-balanced binary tree is commonly defined as a binary tree in which, at every node, the heights of its left and right subtrees differ by at most one. 

              1
             / \
            2   3
           / \
          4   5

This is the local height-balance condition used by AVL trees. Other balanced-tree definitions may use different rules.

7.5 Skewed Binary Tree

A skewed binary tree is a tree in which every internal node has only one child.

Left-skewed example:

          1
         /
        2
       /
      3
     /
    4

Right-skewed example:

    1
     \
      2
       \
        3
         \
          4
A skewed tree can behave like a linked list. Its height can become n - 1 for n nodes.

8. Important Binary Tree Properties

8.1 Maximum Number of Nodes at Level L

If the root is at level 0, the maximum number of nodes at level L is:

Maximum nodes = 2L

Examples:

  • Level 0: 1 node.
  • Level 1: 2 nodes.
  • Level 2: 4 nodes.
  • Level 3: 8 nodes.
  • Level 4: 16 nodes.

8.2 Maximum Number of Nodes in a Binary Tree

For a binary tree with height h, where height is measured in edges, the maximum number of nodes is:

Maximum nodes = 2(h + 1) - 1

For height 3:

24 - 1 = 15 nodes.

8.3 Minimum Number of Nodes for a Given Height

The minimum number of nodes in a non-empty binary tree with height h is:

Minimum nodes = h + 1

This occurs in a completely skewed tree.

8.4 Number of Edges in a Tree

A tree containing n nodes has exactly:

Number of edges = n - 1

8.5 Number of Leaf Nodes in a Perfect Binary Tree

For a perfect binary tree of height h:

Leaf nodes = 2h

8.6 Total Nodes in a Perfect Binary Tree

Total nodes = 2(h + 1) - 1
These formulas use height measured in edges and root level 0. Do not mix them with formulas based on root level 1 or height measured in nodes.

9. Binary Tree vs Binary Search Tree

Binary Tree Binary Search Tree
Each node has at most two children. Each node has at most two children and follows an ordering rule.
No required ordering between node values. Left subtree values are smaller and right subtree values are larger under the distinct-key convention.
Searching may require O(n) time. Searching takes O(h), where h is the tree height.
Inorder traversal is not necessarily sorted. Inorder traversal produces sorted keys under the standard BST convention.
Used for hierarchical representation and many general tree problems. Used for ordered searching and maintaining sorted data.
A BST is a binary tree with an additional ordering property. Every BST is a binary tree, but every binary tree is not a BST.

10. Applications of Tree Data Structures

  • File systems: Represent folders and files hierarchically.
  • Databases: B-trees and B+ trees support indexing.
  • Compilers: Abstract syntax trees represent program structure.
  • Searching: Binary Search Trees organize ordered data.
  • Priority queues: Binary heaps support efficient priority operations.
  • Networking: Routing and decision structures can use tree representations.
  • Text processing: Tries support prefix-based searching.
  • Artificial intelligence: Decision trees represent possible decisions.

11. Program 1 – Calculate the Number of Nodes in a Binary Tree

This program demonstrates a simple recursive tree operation. It counts every node by adding:

  • One for the current node.
  • The number of nodes in the left subtree.
  • The number of nodes in the right subtree.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

int countNodes(const struct Node *root) {
    if (root == NULL) {
        return 0;
    }

    return 1
         + countNodes(root->left)
         + countNodes(root->right);
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *root = createNode(10);

    if (root == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Total nodes = %d\n", countNodes(root));

    freeTree(root);

    return 0;
}

Tree Created

             10
            /  \
           20   30
          / \
         40  50

Expected Output

Total nodes = 5

Complexity Analysis

  • Time: O(n), because each node is visited once.
  • Auxiliary space: O(h) for the recursive call stack, where h is the tree height.

12. Program 2 – Count Leaf Nodes in a Binary Tree

A leaf node has no left child and no right child.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

int countLeafNodes(const struct Node *root) {
    if (root == NULL) {
        return 0;
    }

    if (root->left == NULL &&
        root->right == NULL) {
        return 1;
    }

    return countLeafNodes(root->left)
         + countLeafNodes(root->right);
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *root = createNode(10);

    if (root == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Leaf nodes = %d\n", countLeafNodes(root));

    freeTree(root);

    return 0;
}

Expected Output

Leaf nodes = 3

The leaf nodes are 40, 50 and 30.

Complexity Analysis

  • Time: O(n).
  • Auxiliary space: O(h).

13. Program 3 – Find the Height of a Binary Tree

Using the edge-count convention, an empty tree has height -1 and a tree containing one node has height 0.

Recursive Formula

Height(root) = 1 + max(Height(left), Height(right))

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;

    return newNode;
}

int max(int a, int b) {
    return (a > b) ? a : b;
}

int height(const struct Node *root) {
    if (root == NULL) {
        return -1;
    }

    int leftHeight = height(root->left);
    int rightHeight = height(root->right);

    return 1 + max(leftHeight, rightHeight);
}

void freeTree(struct Node *root) {
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    struct Node *root = createNode(10);

    if (root == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left = createNode(20);
    root->right = createNode(30);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    root->left->left = createNode(40);
    root->left->right = createNode(50);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Tree height = %d\n", height(root));

    freeTree(root);

    return 0;
}

Expected Output

Tree height = 2

Complexity Analysis

  • Time: O(n).
  • Auxiliary space: O(h).

14. Common Tree Interview Questions

Q1. What is a tree?

A tree is a non-linear hierarchical data structure consisting of nodes connected by edges.

Q2. What is the root node?

The root is the topmost node and has no parent.

Q3. How many edges does a tree with n nodes have?

Exactly n - 1 edges.

Q4. What is a leaf node?

A node with no children.

Q5. What is the maximum number of children in a binary tree?

Two: a left child and a right child.

Q6. What is the difference between a full and complete binary tree?

A full binary tree requires every node to have either zero or two children. A complete binary tree fills all levels except possibly the last, which is filled from left to right.

Q7. What is a perfect binary tree?

A binary tree in which every internal node has two children and every leaf is at the same level.

Q8. What is the height of a single-node tree?

Zero under the edge-count convention.

Q9. What is the maximum number of nodes at level L?

2L, when the root is at level zero.

Q10. What is the maximum number of nodes in a binary tree of height h?

2(h + 1) - 1.

Q11. Is every binary tree a BST?

No. A BST must additionally satisfy an ordering rule for values in its left and right subtrees.

Q12. What is a skewed binary tree?

A binary tree in which each internal node has only one child.

Q13. What is the maximum degree of a binary tree?

Two.

Q14. What is the time complexity of counting all nodes?

O(n), because every node must be visited.

17. Lesson Summary

  • A tree is a non-linear hierarchical data structure.
  • The root is the topmost node.
  • A tree with n nodes has n - 1 edges.
  • Leaf nodes have no children.
  • Depth counts edges from the root to a node.
  • Height counts edges on the longest downward path to a leaf.
  • A binary tree has at most two children per node.
  • Full, complete, perfect and balanced trees have different definitions.
  • A BST is a binary tree with an additional ordering property.
  • Tree algorithms commonly use recursion and dynamic memory allocation.
