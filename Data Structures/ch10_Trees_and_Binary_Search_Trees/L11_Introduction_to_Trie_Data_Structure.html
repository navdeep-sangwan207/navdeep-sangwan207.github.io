2. What Is a Trie?

A Trie, also called a prefix tree, is a tree-based data structure used to store and search strings efficiently.

Each node represents a character transition. A path from the root represents a sequence of characters.

The word Trie is derived from the word retrieval. It is especially useful when many strings share common prefixes.

Example Words

Stored words:

CAR
CAT
CARE
DOG

Conceptual Trie:

                 ROOT
                /    \
               C      D
               |      |
               A      O
              / \     |
             R   T    G*
             |
             E*

C A R* represents CAR
C A T* represents CAT
C A R E* represents CARE
D O G* represents DOG

* = End of a stored word

The paths for CAR, CAT and CARE share the prefix CA. The Trie stores that shared prefix only once.

3. Trie Node Structure

For a lowercase English alphabet, each node can contain:

  • An array of 26 child pointers.
  • A Boolean flag indicating whether a complete word ends at that node.

C Structure

#define ALPHABET_SIZE 26

typedef struct TrieNode {
    struct TrieNode *children[ALPHABET_SIZE];
    int isEndOfWord;
} TrieNode;

Character Index Calculation

int index = character - 'a';

Examples:

CharacterIndex
a0
b1
c2
z25
This representation supports lowercase English letters only. Input validation is necessary before calculating the child index.

4. Trie Insertion

Insertion adds a word character by character.

Algorithm

  1. Start at the root.
  2. Read the next character.
  3. Calculate its index from 0 to 25.
  4. If the corresponding child does not exist, create a node.
  5. Move to the child node.
  6. Repeat until all characters have been processed.
  7. Mark the final node as the end of a word.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define ALPHABET_SIZE 26

typedef struct TrieNode {
    struct TrieNode *children[ALPHABET_SIZE];
    bool isEndOfWord;
} TrieNode;

TrieNode *createNode(void)
{
    TrieNode *node = malloc(sizeof(TrieNode));

    if (node == NULL) {
        return NULL;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        node->children[i] = NULL;
    }

    node->isEndOfWord = false;

    return node;
}

bool insertWord(TrieNode *root, const char *word)
{
    TrieNode *current = root;

    for (int i = 0; word[i] != '\0'; i++) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }

        int index = word[i] - 'a';

        if (current->children[index] == NULL) {
            current->children[index] = createNode();

            if (current->children[index] == NULL) {
                return false;
            }
        }

        current = current->children[index];
    }

    current->isEndOfWord = true;

    return true;
}

void freeTrie(TrieNode *root)
{
    if (root == NULL) {
        return;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        freeTrie(root->children[i]);
    }

    free(root);
}

int main(void)
{
    TrieNode *root = createNode();

    if (root == NULL) {
        return 1;
    }

    const char *words[] = {
        "car", "cat", "care", "dog"
    };

    int count = sizeof(words) / sizeof(words[0]);

    for (int i = 0; i < count; i++) {
        if (!insertWord(root, words[i])) {
            printf("Insertion failed: %s\n", words[i]);
            freeTrie(root);
            return 1;
        }
    }

    printf("Words inserted successfully.\n");

    freeTrie(root);

    return 0;
}
Expected Output 
Words inserted successfully.

Time Complexity: O(L) per word, where L is the word length.

Auxiliary Space: O(L) additional nodes in the worst case for a single insertion.

5. Trie Search

Trie search checks whether a complete word exists in the data structure.

Important Distinction

A path may exist without representing a complete stored word.

For example, if CARE is stored, searching for CAR succeeds only if CAR was also inserted and its final node was marked as a word.

Search care: Found
Search ca: Not Found
Search dog: Not Found

Time Complexity: O(L).

Auxiliary Space: O(1) excluding the Trie.

7. Trie Deletion

Deleting a word requires care because multiple words may share the same prefix.

Example

Suppose the Trie contains:

CAR
CARE
CAT

If CAR is deleted:

  • The terminal marker for CAR is removed.
  • The shared C → A → R path must remain because CARE uses it.
  • The nodes are removed only when they are no longer needed by any stored word.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define ALPHABET_SIZE 26

typedef struct TrieNode {
    struct TrieNode *children[ALPHABET_SIZE];
    bool isEndOfWord;
} TrieNode;

TrieNode *createNode(void)
{
    TrieNode *node = malloc(sizeof(TrieNode));

    if (node == NULL) {
        return NULL;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        node->children[i] = NULL;
    }

    node->isEndOfWord = false;

    return node;
}

bool insertWord(TrieNode *root, const char *word)
{
    TrieNode *current = root;

    for (int i = 0; word[i] != '\0'; i++) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }

        int index = word[i] - 'a';

        if (current->children[index] == NULL) {
            current->children[index] = createNode();

            if (current->children[index] == NULL) {
                return false;
            }
        }

        current = current->children[index];
    }

    current->isEndOfWord = true;
    return true;
}

bool hasNoChildren(TrieNode *node)
{
    for (int i = 0; i < ALPHABET_SIZE; i++) {
        if (node->children[i] != NULL) {
            return false;
        }
    }

    return true;
}

/*
 * Returns false if the word was not present.
 * Removes unnecessary nodes while unwinding recursion.
 */
bool deleteWordHelper(TrieNode *node,
                      const char *word,
                      int depth,
                      bool *deleted)
{
    if (word[depth] == '\0') {
        if (!node->isEndOfWord) {
            return false;
        }

        node->isEndOfWord = false;
        *deleted = true;

        return hasNoChildren(node);
    }

    int index = word[depth] - 'a';

    if (node->children[index] == NULL) {
        return false;
    }

    bool removeChild =
        deleteWordHelper(node->children[index],
                         word, depth + 1, deleted);

    if (removeChild) {
        free(node->children[index]);
        node->children[index] = NULL;
    }

    return !node->isEndOfWord && hasNoChildren(node);
}

bool deleteWord(TrieNode *root, const char *word)
{
    if (root == NULL || word[0] == '\0') {
        return false;
    }

    for (int i = 0; word[i] != '\0'; i++) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }
    }

    bool deleted = false;

    deleteWordHelper(root, word, 0, &deleted);

    return deleted;
}

bool searchWord(TrieNode *root, const char *word)
{
    TrieNode *current = root;

    for (int i = 0; word[i] != '\0'; i++) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }

        int index = word[i] - 'a';

        if (current->children[index] == NULL) {
            return false;
        }

        current = current->children[index];
    }

    return current->isEndOfWord;
}

void freeTrie(TrieNode *root)
{
    if (root == NULL) {
        return;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        freeTrie(root->children[i]);
    }

    free(root);
}

int main(void)
{
    TrieNode *root = createNode();

    if (root == NULL) {
        return 1;
    }

    if (!insertWord(root, "car") ||
        !insertWord(root, "care") ||
        !insertWord(root, "cat")) {
        freeTrie(root);
        return 1;
    }

    printf("Before deletion:\n");
    printf("car: %s\n",
           searchWord(root, "car") ? "Found" : "Not Found");
    printf("care: %s\n",
           searchWord(root, "care") ? "Found" : "Not Found");

    printf("\nDeleting car...\n");

    if (deleteWord(root, "car")) {
        printf("car deleted.\n");
    } else {
        printf("car not found.\n");
    }

    printf("\nAfter deletion:\n");
    printf("car: %s\n",
           searchWord(root, "car") ? "Found" : "Not Found");
    printf("care: %s\n",
           searchWord(root, "care") ? "Found" : "Not Found");
    printf("cat: %s\n",
           searchWord(root, "cat") ? "Found" : "Not Found");

    freeTrie(root);

    return 0;
}
Expected Output 
Before deletion:
car: Found
care: Found

Deleting car...
car deleted.

After deletion:
car: Not Found
care: Found
cat: Found

Time Complexity: O(L).

Auxiliary Space: O(L) recursion stack.

This deletion routine is designed for valid, non-empty lowercase words. It removes a child node only when that node is neither a word-ending node nor the parent of another child.

8. Autocomplete Using Trie

Autocomplete suggests stored words that begin with a user-provided prefix.

Example

Stored words:

apple
application
apply
banana
ball

Input prefix: app

Suggestions:

apple
application
apply

Approach

  1. Navigate to the Trie node representing the prefix.
  2. Start a depth-first traversal from that node.
  3. Build words by appending characters.
  4. Print a word whenever a terminal node is reached.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define ALPHABET_SIZE 26
#define MAX_WORD_LENGTH 100

typedef struct TrieNode {
    struct TrieNode *children[ALPHABET_SIZE];
    bool isEndOfWord;
} TrieNode;

TrieNode *createNode(void)
{
    TrieNode *node = malloc(sizeof(TrieNode));

    if (node == NULL) {
        return NULL;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        node->children[i] = NULL;
    }

    node->isEndOfWord = false;

    return node;
}

bool insertWord(TrieNode *root, const char *word)
{
    TrieNode *current = root;

    for (int i = 0; word[i] != '\0'; i++) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }

        int index = word[i] - 'a';

        if (current->children[index] == NULL) {
            current->children[index] = createNode();

            if (current->children[index] == NULL) {
                return false;
            }
        }

        current = current->children[index];
    }

    current->isEndOfWord = true;
    return true;
}

void printSuggestions(TrieNode *node,
                      char word[],
                      int depth)
{
    if (node == NULL || depth >= MAX_WORD_LENGTH) {
        return;
    }

    if (node->isEndOfWord) {
        word[depth] = '\0';
        printf("%s\n", word);
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        if (node->children[i] != NULL) {
            word[depth] = (char)('a' + i);

            printSuggestions(node->children[i],
                             word, depth + 1);
        }
    }
}

void autocomplete(TrieNode *root, const char *prefix)
{
    TrieNode *current = root;

    char word[MAX_WORD_LENGTH];

    int length = 0;

    for (int i = 0; prefix[i] != '\0'; i++) {
        if (prefix[i] < 'a' || prefix[i] > 'z' ||
            length >= MAX_WORD_LENGTH - 1) {
            printf("Invalid prefix.\n");
            return;
        }

        int index = prefix[i] - 'a';

        if (current->children[index] == NULL) {
            printf("No suggestions found.\n");
            return;
        }

        current = current->children[index];
        word[length++] = prefix[i];
    }

    printf("Suggestions for \"%s\":\n", prefix);

    printSuggestions(current, word, length);
}

void freeTrie(TrieNode *root)
{
    if (root == NULL) {
        return;
    }

    for (int i = 0; i < ALPHABET_SIZE; i++) {
        freeTrie(root->children[i]);
    }

    free(root);
}

int main(void)
{
    TrieNode *root = createNode();

    if (root == NULL) {
        return 1;
    }

    const char *words[] = {
        "apple",
        "application",
        "apply",
        "banana",
        "ball"
    };

    int count = sizeof(words) / sizeof(words[0]);

    for (int i = 0; i < count; i++) {
        if (!insertWord(root, words[i])) {
            freeTrie(root);
            return 1;
        }
    }

    autocomplete(root, "app");

    freeTrie(root);

    return 0;
}
Expected Output 
Suggestions for "app":
apple
application
apply

Time Complexity: O(P + V), where P is the prefix length and V is the number of Trie nodes visited while generating suggestions.

Auxiliary Space: O(L) recursion and word-buffer space, where L is the maximum word length.

9. Trie Complexity Analysis

Let L represent the length of the word or prefix being processed.

Operation Time Complexity
InsertionO(L)
Exact SearchO(L)
Prefix SearchO(L)
DeletionO(L)
AutocompleteO(P + V)

Space Complexity

For an alphabet of size K, an array-based Trie node stores K child pointers. With N total nodes, the pointer storage is O(NK).

For lowercase English letters, K = 26.

10. Trie vs Hash Table vs Binary Search Tree

Feature Trie Hash Table BST
Exact search O(L) O(L) average including hashing characters O(h) comparisons, with string comparison cost
Prefix search Efficient Not naturally supported Requires additional traversal
Ordering Lexicographic traversal No inherent ordering Inorder traversal for ordered keys
Memory Can be high Depends on table and collisions Depends on node count and structure

11. Applications of Trie

  • Autocomplete in search engines.
  • Dictionary and spell-checking applications.
  • Search suggestions.
  • IP routing using prefix matching.
  • Contact search applications.
  • Word games and word validation.
  • Prefix-based filtering.

12. Common Mistakes

  1. Confusing prefix existence with complete-word existence.
  2. Forgetting to initialize child pointers to NULL.
  3. Not validating characters before calculating array indexes.
  4. Deleting shared prefix nodes while deleting a word.
  5. Forgetting to release dynamically allocated nodes.
  6. Assuming an array-based Trie is always memory-efficient.
  7. Ignoring empty-string and maximum-word-length requirements.

14. Interview Questions and Answers

Q1. What is a Trie?

Answer: A tree-based data structure used to store and search strings by their prefixes.

Q2. Why is a Trie called a prefix tree?

Answer: Because strings with common prefixes share the same initial path.

Q3. What is the time complexity of Trie search?

Answer: O(L), where L is the search string length.

Q4. What is the purpose of isEndOfWord?

Answer: It identifies whether the path to a node represents a complete stored word.

Q5. Can a Trie contain both CAR and CARE?

Answer: Yes. The node representing R is marked as a word ending for CAR, and the path continues to E for CARE.

Q6. What is the difference between search and startsWith?

Answer: Search requires a complete word-ending marker. startsWith only requires the prefix path to exist.

Q7. What is the main disadvantage of an array-based Trie?

Answer: It can consume significant memory because each node reserves pointers for every alphabet character.

Q8. What is autocomplete?

Answer: A feature that suggests stored words beginning with the user's entered prefix.

Q9. Why must Trie deletion be handled carefully?

Answer: Different words may share prefixes. A node must not be removed if another word still depends on it.

Q10. What is a compressed Trie?

Answer: A Trie variant that combines chains of single-child nodes into edges labelled with multiple characters, reducing node overhead.

16. Lesson Summary

  • A Trie is a tree-based structure for string and prefix operations.
  • Each node represents a character transition.
  • Insertion, exact search, prefix search and deletion take O(L) time.
  • The end-of-word marker distinguishes complete words from prefixes.
  • Autocomplete uses prefix navigation followed by subtree traversal.
  • Array-based Tries provide fast child access but can use substantial memory.
Placement priority: Be able to implement insert, search, startsWith and delete from scratch. Understand why shared prefixes cannot be removed prematurely, and practise autocomplete and maximum-XOR Trie problems.
