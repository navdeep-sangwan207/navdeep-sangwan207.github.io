2. Understanding Root-to-Leaf Paths

A path is a sequence of connected nodes in a tree. A root-to-leaf path starts at the root and ends at a leaf node.

A leaf node is a node that has no left or right child.

Example Tree

                10
              /    \
             5      15
            / \       \
           3   7       20

    Root-to-leaf paths:

    10 → 5 → 3
    10 → 5 → 7
    10 → 15 → 20

The sums of these paths are:

  • 10 + 5 + 3 = 18
  • 10 + 5 + 7 = 22
  • 10 + 15 + 20 = 45

3. Problem 1: Path Sum – Check Whether a Root-to-Leaf Path Exists

Problem: Given a binary tree and a target sum, determine whether any root-to-leaf path has that sum.

Example

                10
              /    \
             5      15
            / \       \
           3   7       20

    Target sum = 22

    Path: 10 → 5 → 7

    Sum = 10 + 5 + 7 = 22

    Result = TRUE

Algorithm

  1. If the current node is NULL, return false.
  2. Subtract the current node's value from the remaining sum.
  3. If the node is a leaf, check whether the remaining sum becomes zero.
  4. Recursively check the left subtree.
  5. Recursively check the right subtree.
  6. Return true if either subtree contains a valid path.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

bool hasPathSum(Node *root, long long target)
{
    if (root == NULL) {
        return false;
    }

    target -= root->data;

    if (root->left == NULL &&
        root->right == NULL) {
        return target == 0;
    }

    return hasPathSum(root->left, target) ||
           hasPathSum(root->right, target);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(5);
    root->right = createNode(15);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(7);
    root->right->right = createNode(20);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    long long target = 22;

    if (hasPathSum(root, target)) {
        printf("A root-to-leaf path with sum %lld exists.\n",
               target);
    } else {
        printf("No root-to-leaf path with sum %lld exists.\n",
               target);
    }

    freeTree(root);

    return 0;
}
Expected Output 
A root-to-leaf path with sum 22 exists.

Time Complexity: O(n) in the worst case.

Auxiliary Space: O(h) for the recursive call stack.

This implementation checks only root-to-leaf paths. Reaching the target sum at an internal node does not count unless that node is also a leaf.

4. Problem 2: Print All Root-to-Leaf Paths

Problem: Print every path starting from the root and ending at a leaf.

Approach

  1. Maintain an array to store the current path.
  2. Add the current node to the path.
  3. If it is a leaf, print the path.
  4. Otherwise, recursively explore both children.
  5. Backtrack by reducing the path length when returning.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define MAX_PATH 1000

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

void printPath(int path[], int length)
{
    for (int i = 0; i < length; i++) {
        printf("%d", path[i]);

        if (i < length - 1) {
            printf(" -> ");
        }
    }

    printf("\n");
}

void printAllPaths(Node *root, int path[],
                   int length)
{
    if (root == NULL || length >= MAX_PATH) {
        return;
    }

    path[length++] = root->data;

    if (root->left == NULL &&
        root->right == NULL) {
        printPath(path, length);
        return;
    }

    printAllPaths(root->left, path, length);
    printAllPaths(root->right, path, length);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(5);
    root->right = createNode(15);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(7);
    root->right->right = createNode(20);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    int path[MAX_PATH];

    printf("Root-to-leaf paths:\n");
    printAllPaths(root, path, 0);

    freeTree(root);

    return 0;
}
Expected Output 
Root-to-leaf paths:
10 -> 5 -> 3
10 -> 5 -> 7
10 -> 15 -> 20

Time Complexity: O(n + total output size). Every node is visited once, and printing paths adds work proportional to the number of printed path elements.

Auxiliary Space: O(h) for the path and recursion stack.

5. Problem 3: Maximum Root-to-Leaf Path Sum

Problem: Find the maximum sum among all root-to-leaf paths.

Example

                10
              /    \
             5      15
            / \       \
           3   7       20

    Path sums:

    10 → 5 → 3  = 18
    10 → 5 → 7  = 22
    10 → 15 → 20 = 45

    Maximum path sum = 45

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <limits.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

long long maxValue(long long a, long long b)
{
    return a > b ? a : b;
}

long long maxRootToLeafSum(Node *root, bool *valid)
{
    if (root == NULL) {
        *valid = false;
        return 0;
    }

    if (root->left == NULL &&
        root->right == NULL) {
        *valid = true;
        return root->data;
    }

    bool leftValid = false;
    bool rightValid = false;

    long long leftSum =
        maxRootToLeafSum(root->left, &leftValid);

    long long rightSum =
        maxRootToLeafSum(root->right, &rightValid);

    if (!leftValid && !rightValid) {
        *valid = false;
        return 0;
    }

    *valid = true;

    if (!leftValid) {
        return root->data + rightSum;
    }

    if (!rightValid) {
        return root->data + leftSum;
    }

    return root->data + maxValue(leftSum, rightSum);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(5);
    root->right = createNode(15);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(7);
    root->right->right = createNode(20);

    if (root->left->left == NULL ||
        root->left->right == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    bool valid = false;
    long long result =
        maxRootToLeafSum(root, &valid);

    if (valid) {
        printf("Maximum root-to-leaf path sum = %lld\n",
               result);
    } else {
        printf("Tree is empty.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
Maximum root-to-leaf path sum = 45

Time Complexity: O(n).

Auxiliary Space: O(h).

6. Height-Balanced Binary Tree

A binary tree is height-balanced if, at every node, the height difference between its left and right subtrees is at most 1.

Mathematically:

    | height(left subtree) - height(right subtree) | ≤ 1

Balanced Tree

             10
            /  \
           5    15
          / \
         3   7

Unbalanced Tree

             10
            /
           5
          /
         3
        /
       1
A balanced tree does not need to be complete or perfect. The height difference condition must hold at every node, not just at the root.

7. Problem 4: Check Whether a Binary Tree Is Balanced

Approach 1: Repeated Height Calculation

For each node:

  1. Calculate the height of its left subtree.
  2. Calculate the height of its right subtree.
  3. Check whether their difference is at most 1.
  4. Recursively check both subtrees.

Complete C11 Program – Basic Approach

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int maxInt(int a, int b)
{
    return a > b ? a : b;
}

int height(Node *root)
{
    if (root == NULL) {
        return -1;
    }

    int leftHeight = height(root->left);
    int rightHeight = height(root->right);

    return 1 + maxInt(leftHeight, rightHeight);
}

bool isBalanced(Node *root)
{
    if (root == NULL) {
        return true;
    }

    int leftHeight = height(root->left);
    int rightHeight = height(root->right);

    int difference = leftHeight - rightHeight;

    if (difference < -1 || difference > 1) {
        return false;
    }

    return isBalanced(root->left) &&
           isBalanced(root->right);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(5);
    root->right = createNode(15);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(7);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        return 1;
    }

    if (isBalanced(root)) {
        printf("The binary tree is balanced.\n");
    } else {
        printf("The binary tree is not balanced.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
The binary tree is balanced.

Time Complexity: O(n²) in the worst case, because subtree heights are recalculated repeatedly.

Auxiliary Space: O(h).

8. Problem 5: Optimized Balanced Binary Tree Check

The optimized method calculates subtree heights while checking balance. It avoids repeatedly traversing the same nodes.

Important Idea

  • Return the subtree height if it is balanced.
  • Return -1 if the subtree is unbalanced.
  • If either child returns -1, immediately propagate -1.
  • Otherwise, calculate the current height and verify the difference.

Complete C11 Program – Optimized Approach

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

int maxInt(int a, int b)
{
    return a > b ? a : b;
}

/* Returns -1 if unbalanced; otherwise returns height. */
int checkHeight(Node *root)
{
    if (root == NULL) {
        return -1;
    }

    int leftHeight = checkHeight(root->left);

    if (leftHeight == -2) {
        return -2;
    }

    int rightHeight = checkHeight(root->right);

    if (rightHeight == -2) {
        return -2;
    }

    int difference = leftHeight - rightHeight;

    if (difference < -1 || difference > 1) {
        return -2;
    }

    return 1 + maxInt(leftHeight, rightHeight);
}

bool isBalanced(Node *root)
{
    return checkHeight(root) != -2;
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(5);
    root->right = createNode(15);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->left->left = createNode(3);
    root->left->right = createNode(7);

    if (root->left->left == NULL ||
        root->left->right == NULL) {
        freeTree(root);
        return 1;
    }

    if (isBalanced(root)) {
        printf("The binary tree is balanced.\n");
    } else {
        printf("The binary tree is not balanced.\n");
    }

    freeTree(root);

    return 0;
}
Expected Output 
The binary tree is balanced.

Time Complexity: O(n), because every node is visited at most once.

Auxiliary Space: O(h), due to recursion.

The code uses -2 as the unbalanced sentinel because an empty tree has height -1. This keeps the sentinel distinct from every valid height.

9. Problem 6: Maximum Path Sum Between Any Two Nodes

This is a more advanced interview problem. Unlike root-to-leaf maximum path sum, the path can start and end at any two nodes.

For each node, calculate the maximum downward contribution from its left and right children. Update a global maximum using:

    Current path sum =
        node value
        + maximum left contribution
        + maximum right contribution

Negative downward contributions are ignored because extending a path with a negative sum cannot improve the result.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

long long maxLong(long long a, long long b)
{
    return a > b ? a : b;
}

long long maxPathDown(Node *root, long long *best)
{
    if (root == NULL) {
        return 0;
    }

    long long leftGain =
        maxLong(0, maxPathDown(root->left, best));

    long long rightGain =
        maxLong(0, maxPathDown(root->right, best));

    long long throughNode =
        (long long)root->data + leftGain + rightGain;

    *best = maxLong(*best, throughNode);

    return (long long)root->data +
           maxLong(leftGain, rightGain);
}

long long maximumPathSum(Node *root)
{
    if (root == NULL) {
        return 0;
    }

    long long best = LLONG_MIN;

    maxPathDown(root, &best);

    return best;
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = createNode(-10);

    if (root == NULL) {
        return 1;
    }

    root->left = createNode(9);
    root->right = createNode(20);

    if (root->left == NULL || root->right == NULL) {
        freeTree(root);
        return 1;
    }

    root->right->left = createNode(15);
    root->right->right = createNode(7);

    if (root->right->left == NULL ||
        root->right->right == NULL) {
        freeTree(root);
        return 1;
    }

    printf("Maximum path sum = %lld\n",
           maximumPathSum(root));

    freeTree(root);

    return 0;
}
Expected Output 
Maximum path sum = 42

Maximum path: 15 → 20 → 7

Time Complexity: O(n).

Auxiliary Space: O(h).

This implementation assumes the mathematical path sums fit in long long. An empty tree is handled separately; for a non-empty tree containing only negative values, the answer is the largest individual node value.

11. Common Interview Mistakes

  • Checking the target sum at an internal node instead of requiring a leaf.
  • Forgetting negative node values in path-sum calculations.
  • Assuming the maximum path must pass through the root.
  • Ignoring the possibility that all node values are negative.
  • Checking balance only at the root.
  • Recalculating subtree heights repeatedly and producing O(n²) complexity.
  • Confusing height-balanced trees with complete or perfect trees.
  • Using an ambiguous sentinel value for both a valid height and an error.

13. Common Interview Questions and Answers

Q1. What is a root-to-leaf path?

Answer: A path that begins at the root and ends at a leaf node.

Q2. Does Path Sum require the target to be reached at a leaf?

Answer: In the standard root-to-leaf Path Sum problem, yes.

Q3. What is a height-balanced binary tree?

Answer: A binary tree in which the height difference between the left and right subtrees of every node is at most 1.

Q4. What is the complexity of the basic balance-checking approach?

Answer: O(n²) in the worst case because height is repeatedly calculated.

Q5. How can balance checking be optimized?

Answer: Use bottom-up recursion to calculate height and check balance in one traversal, giving O(n) time.

Q6. Can a maximum path sum be entirely within a subtree?

Answer: Yes. The maximum path does not have to pass through the root.

Q7. Can the maximum path sum be negative?

Answer: Yes. If all node values are negative, the maximum path is the single node with the greatest value.

Q8. What is the difference between root-to-leaf maximum sum and maximum path sum?

Answer: Root-to-leaf maximum sum must start at the root and end at a leaf. Maximum path sum can start and end at any nodes.

Q9. What is the auxiliary space of recursive tree algorithms?

Answer: Generally O(h), where h is the height of the tree.

Q10. Why is bottom-up recursion useful?

Answer: It allows each node to return information computed from its children, avoiding repeated work.

15. Lesson Summary

  • Root-to-leaf paths begin at the root and terminate at leaves.
  • Path Sum checks whether a complete root-to-leaf path has the required sum.
  • Backtracking can be used to print all root-to-leaf paths.
  • Maximum root-to-leaf sum is different from maximum path sum.
  • A height-balanced tree satisfies the height difference condition at every node.
  • Repeated height calculation can lead to O(n²) complexity.
  • Bottom-up recursion checks balance in O(n) time.
