Chapter 10 – Lesson 7

Search, Insertion and Deletion in BST

Master the three core Binary Search Tree operations with complete C11 implementations and interview-focused examples.

1. Learning Objectives

  • Review the Binary Search Tree ordering property.
  • Implement iterative and recursive searching.
  • Insert keys while maintaining BST properties.
  • Understand all three BST deletion cases.
  • Use inorder successor during deletion.
  • Implement complete BST operations in C11.
  • Analyze time and auxiliary space complexity.

2. Binary Search Tree Property

A Binary Search Tree is a binary tree in which:

  • Every key in the left subtree is smaller than the current node.
  • Every key in the right subtree is greater than the current node.
  • Both subtrees must also satisfy the BST property.

This lesson uses a strict BST policy: duplicate keys are rejected.

              50
            /    \
           30     70
          / \    /  \
         20 40  60  80
Inorder traversal of this tree produces ascending order: 20, 30, 40, 50, 60, 70, 80.

3. BST Node Structure

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

Node Creation

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

4. Searching in a BST

Searching compares the target key with the current node and selects only one subtree.

Algorithm

  1. Start from the root.
  2. If the current node is NULL, the key is not present.
  3. If the current key equals the target, return the node.
  4. If the target is smaller, move left.
  5. If the target is greater, move right.
  6. Continue until the key is found or NULL is reached.

Recursive Search

Node *searchRecursive(Node *root, int key)
{
    if (root == NULL || root->data == key) {
        return root;
    }

    if (key < root->data) {
        return searchRecursive(root->left, key);
    }

    return searchRecursive(root->right, key);
}

Iterative Search

Node *searchIterative(Node *root, int key)
{
    while (root != NULL) {
        if (key == root->data) {
            return root;
        }

        if (key < root->data) {
            root = root->left;
        } else {
            root = root->right;
        }
    }

    return NULL;
}

5. Insertion in a BST

Insertion places a new node at the correct empty child position.

Algorithm

  1. If the tree is empty, create the root.
  2. Compare the new key with the current node.
  3. If smaller, move to the left subtree.
  4. If greater, move to the right subtree.
  5. Continue until an empty position is found.
  6. Insert the new node there.
  7. If the key already exists, reject the duplicate.

Example: Insert 65

Initial tree:

              50
                \
                 70
                /
               60

Comparisons:

  • 65 is greater than 50: move right.
  • 65 is smaller than 70: move left.
  • 65 is greater than 60: move right.
  • Right child of 60 is NULL: insert 65.
              50
                \
                 70
                /
               60
                 \
                  65

Insertion Function

Node *insert(Node *root, int key)
{
    if (root == NULL) {
        return createNode(key);
    }

    if (key < root->data) {
        Node *child = insert(root->left, key);

        if (child != NULL) {
            root->left = child;
        }
    }
    else if (key > root->data) {
        Node *child = insert(root->right, key);

        if (child != NULL) {
            root->right = child;
        }
    }

    return root;
}
This short function does not distinguish a duplicate key from memory allocation failure. The complete program below uses a status-returning insertion function.

6. Deletion in a BST

Deletion is more complex than searching and insertion because removing a node must preserve the BST ordering property.

There are three important cases.

Case 1: Deleting a Leaf Node

A leaf node has no children.

Example: Delete 20.

          50                 50
         /  \               /  \
        30  70      →      30  70
       / \                / \
      20 40              NULL 40

Approach:

  1. Find the node.
  2. Since it has no children, free the node.
  3. Set its parent's corresponding child pointer to NULL.

Case 2: Deleting a Node With One Child

Replace the node with its only child.

Example: Delete 30.

          50                  50
         /  \                /  \
        30  70       →      40  70
          \
           40

Approach:

  1. Find the node to delete.
  2. Identify its only non-NULL child.
  3. Free the node.
  4. Return the child so the parent can reconnect it.

Case 3: Deleting a Node With Two Children

This is the most important BST deletion case.

Example: Delete 50.

              50
            /    \
           30     70
          / \    /  \
         20 40  60  80

We use the inorder successor, which is the smallest key in the right subtree.

For this tree:

  • Node to delete = 50.
  • Right subtree root = 70.
  • Smallest node in the right subtree = 60.
  • Replace 50 with 60.
  • Delete the original successor node 60 from the right subtree.

Result:

              60
            /    \
           30     70
          / \       \
         20 40      80
Inorder successor: The next larger key in inorder order. In a BST, it is the leftmost node in the right subtree.

7. Finding the Inorder Successor

The inorder successor of a node with a right subtree is the leftmost node of that right subtree.

Node *findMinimum(Node *root)
{
    if (root == NULL) {
        return NULL;
    }

    while (root->left != NULL) {
        root = root->left;
    }

    return root;
}

Example:

              50
                \
                 80
                /
               60
              /
             55

    Inorder successor of 50 = 55

8. BST Deletion Algorithm

The deletion algorithm follows these steps:

  1. If the root is NULL, return NULL.
  2. If the key is smaller, recursively delete from the left subtree.
  3. If the key is greater, recursively delete from the right subtree.
  4. Otherwise, the target node is found.
  5. If it has no left child, return its right child after freeing it.
  6. If it has no right child, return its left child after freeing it.
  7. If it has two children, copy its inorder successor's key and delete that successor from the right subtree.
  8. Return the updated root.

Complete Deletion Function

Node *deleteNode(Node *root, int key)
{
    if (root == NULL) {
        return NULL;
    }

    if (key < root->data) {
        root->left = deleteNode(root->left, key);
    }
    else if (key > root->data) {
        root->right = deleteNode(root->right, key);
    }
    else {
        /* Case 1 and Case 2 */
        if (root->left == NULL) {
            Node *temp = root->right;
            free(root);
            return temp;
        }

        if (root->right == NULL) {
            Node *temp = root->left;
            free(root);
            return temp;
        }

        /* Case 3: Two children */
        Node *successor = findMinimum(root->right);

        root->data = successor->data;

        root->right =
            deleteNode(root->right, successor->data);
    }

    return root;
}
Always assign the returned pointer: root = deleteNode(root, key); Deleting the root can change the tree's root pointer.

9. Complete C11 Program: Search, Insert and Delete

This program handles all three deletion cases, rejects duplicates, checks memory allocation and frees the complete tree.

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;

typedef enum {
    INSERT_OK,
    INSERT_DUPLICATE,
    INSERT_NO_MEMORY
} InsertStatus;

Node *createNode(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL) {
        return NULL;
    }

    node->data = value;
    node->left = NULL;
    node->right = NULL;

    return node;
}

InsertStatus insert(Node **root, int key)
{
    while (*root != NULL) {
        if (key == (*root)->data) {
            return INSERT_DUPLICATE;
        }

        if (key < (*root)->data) {
            root = &((*root)->left);
        } else {
            root = &((*root)->right);
        }
    }

    *root = createNode(key);

    if (*root == NULL) {
        return INSERT_NO_MEMORY;
    }

    return INSERT_OK;
}

Node *search(Node *root, int key)
{
    while (root != NULL) {
        if (key == root->data) {
            return root;
        }

        if (key < root->data) {
            root = root->left;
        } else {
            root = root->right;
        }
    }

    return NULL;
}

Node *findMinimum(Node *root)
{
    if (root == NULL) {
        return NULL;
    }

    while (root->left != NULL) {
        root = root->left;
    }

    return root;
}

Node *deleteNode(Node *root, int key)
{
    if (root == NULL) {
        return NULL;
    }

    if (key < root->data) {
        root->left = deleteNode(root->left, key);
    }
    else if (key > root->data) {
        root->right = deleteNode(root->right, key);
    }
    else {
        if (root->left == NULL) {
            Node *temp = root->right;
            free(root);
            return temp;
        }

        if (root->right == NULL) {
            Node *temp = root->left;
            free(root);
            return temp;
        }

        Node *successor = findMinimum(root->right);

        root->data = successor->data;

        root->right =
            deleteNode(root->right, successor->data);
    }

    return root;
}

void inorder(Node *root)
{
    if (root == NULL) {
        return;
    }

    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

void freeTree(Node *root)
{
    if (root == NULL) {
        return;
    }

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void)
{
    Node *root = NULL;

    int values[] = {50, 30, 70, 20, 40, 60, 80};
    int count = sizeof(values) / sizeof(values[0]);

    for (int i = 0; i < count; i++) {
        InsertStatus status = insert(&root, values[i]);

        if (status == INSERT_NO_MEMORY) {
            printf("Memory allocation failed.\n");
            freeTree(root);
            return 1;
        }
    }

    printf("Original BST: ");
    inorder(root);
    printf("\n");

    int key = 60;

    if (search(root, key) != NULL) {
        printf("%d found in BST.\n", key);
    } else {
        printf("%d not found in BST.\n", key);
    }

    /* Delete a leaf node */
    root = deleteNode(root, 20);

    printf("After deleting leaf 20: ");
    inorder(root);
    printf("\n");

    /* Delete a node with one child */
    root = deleteNode(root, 30);

    printf("After deleting node 30: ");
    inorder(root);
    printf("\n");

    /* Delete a node with two children */
    root = deleteNode(root, 70);

    printf("After deleting node 70: ");
    inorder(root);
    printf("\n");

    /* Delete the root node */
    root = deleteNode(root, 50);

    printf("After deleting root 50: ");
    inorder(root);
    printf("\n");

    freeTree(root);

    return 0;
}
Expected Output

60 found in BST.
After deleting leaf 20: 30 40 50 60 70 80
After deleting node 30: 40 50 60 70 80
After deleting node 70: 40 50 60 80
After deleting root 50: 40 60 80

10. Complexity Analysis

Let h be the height of the BST and n be the number of nodes.

Operation Average Case Worst Case
Search O(log n) O(n)
Insertion O(log n) O(n)
Deletion O(log n) O(n)
Find Minimum O(log n) O(n)

General time complexity: O(h) for search, insertion and deletion.

Recursive auxiliary space: O(h) for recursive operations.

Iterative search and insertion: O(1) auxiliary space in the implementations shown.

11. Important Deletion Interview Points

Deletion Case Action
Leaf node Free the node and return NULL.
One child Free the node and return its child.
Two children Replace with inorder successor and delete successor.

An alternative to the inorder successor is the inorder predecessor, which is the maximum value in the left subtree.

12. Common Interview Mistakes

  • Deleting a node without reconnecting its parent pointer.
  • Forgetting to return the child when deleting a node with one child.
  • Failing to update the root after deleting the root node.
  • Using the rightmost node of the right subtree instead of the leftmost node when finding the inorder successor.
  • Freeing a node before saving the pointer to its child.
  • Forgetting to delete the original successor after copying its key.
  • Ignoring memory allocation failure during insertion.
  • Assuming BST operations always take O(log n).

14. Common Interview Questions and Answers

Q1. What are the three cases of BST deletion?

Answer: Deleting a leaf node, deleting a node with one child, and deleting a node with two children.

Q2. What happens when a leaf node is deleted?

Answer: The node is freed and the parent's corresponding pointer becomes NULL.

Q3. How do you delete a node with one child?

Answer: Replace the node with its only child.

Q4. How do you delete a node with two children?

Answer: Replace its key with its inorder successor or predecessor, then delete that replacement node from its original location.

Q5. What is an inorder successor?

Answer: The smallest key greater than the current key. When a right subtree exists, it is the leftmost node in that subtree.

Q6. Why must the root pointer be updated after deletion?

Answer: Deleting the root may make one of its children the new root, or may make the entire tree empty.

Q7. Can BST deletion make the tree unbalanced?

Answer: Yes. An ordinary BST does not automatically maintain balance.

Q8. What is the complexity of BST deletion?

Answer: O(h), where h is the height of the tree. It is O(log n) in a balanced tree and O(n) in a skewed tree.

Q9. Can the inorder predecessor be used instead of the successor?

Answer: Yes. The predecessor is the maximum key in the left subtree.

Q10. Why is BST deletion considered more complex than searching?

Answer: Deletion must preserve the BST ordering property and correctly reconnect child pointers in all three cases.

16. Lesson Summary

  • BST search follows the ordering property.
  • Insertion places keys at the correct empty position.
  • Deletion has three cases: leaf, one child and two children.
  • Inorder successor is the minimum key in the right subtree.
  • Inorder predecessor is the maximum key in the left subtree.
  • Always reconnect child pointers and update the root after deletion.
  • Search, insertion and deletion take O(h) time.
Placement priority: Practise all three deletion cases independently. In interviews, be prepared to explain the pointer changes and draw the resulting BST after each deletion.
