2. Arrays in C

An array is a collection of elements of the same data type stored in contiguous memory locations.

Declaration and Initialization

int arr[5];

int numbers[5] = {10, 20, 30, 40, 50};

Array Indexing

Array indexing starts from zero. 

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
Index Value
010
120
230
340
450

Accessing Array Elements

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    return 0;
}
10 20 30 40 50

Array Memory Representation

If an integer occupies 4 bytes and the first element starts at address 1000, a typical representation is:

Element Illustrative Address
arr[0]1000
arr[1]1004
arr[2]1008
arr[3]1012
arr[4]1016

Actual addresses depend on the compiler and execution environment.

Important Formula:

Address of arr[i] = Base address + (i × sizeof(element type))

Array Complexity

  • Access by index: O(1)
  • Traversal: O(n)
  • Linear search: O(n)
  • Insertion at the beginning: O(n)
  • Deletion from the beginning: O(n)

3. Two-Dimensional Arrays

A two-dimensional array represents data in rows and columns. It is commonly used for matrices and grid-based problems. 

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Matrix Traversal

#include <stdio.h>

int main(void)
{
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
1 2 3
4 5 6

Time Complexity: O(rows × columns).

In C, two-dimensional arrays are stored in row-major order.

4. Introduction to Pointers

A pointer is a variable that stores the address of another object or function.

Pointer Declaration

int a = 10;
int *ptr = &a;

Here:

  • a stores the value 10.
  • &a gives the address of a.
  • ptr stores that address.
  • *ptr accesses the value at that address.

Pointer Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int *ptr = &a;

    printf("Value of a = %d\n", a);
    printf("Address of a = %p\n", (void *)&a);
    printf("Pointer value = %p\n", (void *)ptr);
    printf("Value using pointer = %d\n", *ptr);

    return 0;
}
Illustrative Output: 
Value of a = 10
Address of a = [memory address]
Pointer value = [same memory address]
Value using pointer = 10
The exact address varies between executions. The important point is that ptr stores the address of a, and *ptr accesses its value.

5. Pointer Arithmetic

Pointer arithmetic allows movement between elements of an array. 

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40};
    int *ptr = arr;

    printf("%d\n", *ptr);
    printf("%d\n", *(ptr + 1));
    printf("%d\n", *(ptr + 2));
    printf("%d\n", *(ptr + 3));

    return 0;
}
10
20
30
40

If ptr points to an integer, ptr + 1 points to the next integer element, not necessarily the next byte.

Important Pointer Expressions

Expression Meaning
ptr Address stored in ptr
*ptr Value pointed to by ptr
&ptr Address of the pointer variable itself
ptr + 1 Pointer to the next element
ptr - 1 Pointer to the previous element, if valid
Pointer arithmetic must remain within the same array object or one position past its end. Dereferencing a one-past-the-end pointer is invalid.

6. Relationship Between Arrays and Pointers

In most expressions, an array name is converted into a pointer to its first element. 

int arr[3] = {10, 20, 30};

int *ptr = arr;

These expressions access equivalent elements: 

arr[0] == *arr
arr[1] == *(arr + 1)
arr[2] == *(arr + 2)
An array is not a pointer variable. Array names are not assignable, and sizeof(arr) in the scope where arr is declared as an array gives the total array size rather than pointer size.

Array Passed to a Function

#include <stdio.h>

void display(const int *arr, int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }
}

int main(void)
{
    int numbers[] = {5, 10, 15, 20};

    display(numbers, 4);

    return 0;
}
5 10 15 20

When an array is passed as a function parameter, the parameter is adjusted to a pointer type. The function must receive the length separately when it needs to know how many elements are valid.

7. Double Pointers

A double pointer stores the address of another pointer. 

int a = 50;

int *ptr = &a;

int **pptr = &ptr;
  • ptr points to a.
  • pptr points to ptr.
  • *ptr gives 50.
  • **pptr gives 50.

Program

#include <stdio.h>

int main(void)
{
    int a = 50;

    int *ptr = &a;
    int **pptr = &ptr;

    printf("%d\n", a);
    printf("%d\n", *ptr);
    printf("%d\n", **pptr);

    return 0;
}
50
50
50

Application in DSA

  • Modifying a pointer through a function.
  • Dynamic two-dimensional data structures.
  • Graph adjacency structures.
  • Linked-list operations that update the head pointer.

8. Structures in C

A structure is a user-defined data type that groups variables of potentially different data types under one name.

Structure Declaration

struct Student
{
    int roll_no;
    char name[30];
    float marks;
};

Structure Initialization and Access

#include <stdio.h>

struct Student
{
    int roll_no;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student s1 = {
        101, "Rahul", 85.5f
    };

    printf("Roll Number: %d\n", s1.roll_no);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}
Roll Number: 101
Name: Rahul
Marks: 85.50

Accessing Structure Members

  • Dot operator (.) accesses members through a structure object.
  • Arrow operator (->) accesses members through a pointer to a structure.

9. Structure Pointers and the Arrow Operator

A structure pointer stores the address of a structure object. 

#include <stdio.h>

struct Student
{
    int roll_no;
    float marks;
};

int main(void)
{
    struct Student s1 = {101, 90.5f};

    struct Student *ptr = &s1;

    printf("Roll Number = %d\n", ptr->roll_no);
    printf("Marks = %.2f\n", ptr->marks);

    return 0;
}
Roll Number = 101
Marks = 90.50

The expression: 

ptr->roll_no

is equivalent to: 

(*ptr).roll_no
Structure pointers are fundamental to linked lists, binary trees and graph implementations.

10. Self-Referential Structures

A self-referential structure contains a pointer to another structure of the same type.

Example: Linked List Node

struct Node
{
    int data;
    struct Node *next;
};

Here:

  • data stores the node's value.
  • next stores the address of the next node.

A conceptual linked list: 

HEAD
 |
 v
+------+------+
|  10  | next | ----+
+------+------+
                   |
                   v
              +------+------+
              |  20  | next | ----+
              +------+------+     |
                                   v
                              +------+------+
                              |  30  | NULL |
                              +------+------+

A self-referential structure is one of the most important foundations for linked data structures.

11. Dynamic Memory Allocation

Dynamic memory allocation allows a program to request and release memory at runtime.

The main functions are declared in: 

#include <stdlib.h>
Function Purpose
malloc() Allocates a block of memory without initializing its contents.
calloc() Allocates memory for multiple elements and initializes all bytes to zero.
realloc() Changes the size of an allocated memory block.
free() Releases dynamically allocated memory.

Using malloc()

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        arr[i] = (i + 1) * 10;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);
    arr = NULL;

    return 0;
}
10 20 30 40 50

Using calloc()

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *arr = calloc(n, sizeof *arr);

    if (arr == NULL)
    {
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
0 0 0 0 0

calloc initializes the allocated bytes to zero. For ordinary integer types, this produces zero values.

Using realloc()

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(3 * sizeof *arr);

    if (arr == NULL)
    {
        return 1;
    }

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;

    int *temp = realloc(arr, 5 * sizeof *arr);

    if (temp == NULL)
    {
        free(arr);
        return 1;
    }

    arr = temp;

    arr[3] = 40;
    arr[4] = 50;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
10 20 30 40 50
Never directly overwrite the only pointer to an allocated block with realloc's result. If realloc fails, it returns NULL while the original block remains allocated. Use a temporary pointer.

12. Stack Memory and Heap Memory

C programs commonly use different memory regions for automatic storage and dynamic allocation.

Feature Automatic Storage (Often Stack) Dynamic Allocation (Heap)
Allocation Managed automatically Requested using allocation functions
Release When the object's lifetime ends Using free()
Typical example Local variable malloc() allocation
Size Often limited by stack resources Limited by available memory and implementation 
int main(void)
{
    int x = 10;

    int *ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        return 1;
    }

    *ptr = 20;

    free(ptr);

    return 0;
}

x has automatic storage duration. The memory allocated through malloc has allocated storage duration and must be released by the program.

13. Implementing a Linked List Using Structures and Pointers

This example connects all the concepts learned in this lesson.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *new_node =
        malloc(sizeof *new_node);

    if (new_node == NULL)
    {
        return NULL;
    }

    new_node->data = value;
    new_node->next = NULL;

    return new_node;
}

void display(struct Node *head)
{
    struct Node *current = head;

    while (current != NULL)
    {
        printf("%d -> ", current->data);
        current = current->next;
    }

    printf("NULL\n");
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *temp = head;
        head = head->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = create_node(10);

    if (head == NULL)
    {
        return 1;
    }

    head->next = create_node(20);

    if (head->next == NULL)
    {
        free_list(head);
        return 1;
    }

    head->next->next = create_node(30);

    if (head->next->next == NULL)
    {
        free_list(head);
        return 1;
    }

    display(head);

    free_list(head);

    return 0;
}
Expected Output: 
10 -> 20 -> 30 -> NULL

How This Program Works

  1. A structure defines the node.
  2. A pointer connects one node to another.
  3. malloc() dynamically allocates each node.
  4. The arrow operator accesses structure members.
  5. Traversal follows next pointers.
  6. free() releases each allocated node.
This is the foundation for the linked-list chapter that follows later in the course.

14. Common Pointer Errors and Memory Problems

1. Uninitialized Pointer

int *ptr;
*ptr = 10;  /* Undefined behavior */

The pointer does not point to a valid object. Initialize it before dereferencing.

2. NULL Pointer Dereference

int *ptr = NULL;
*ptr = 20;  /* Invalid */

3. Memory Leak

int *ptr = malloc(sizeof *ptr);

/* Missing free(ptr) */

Allocated memory is not released before the pointer is lost or its useful lifetime ends.

4. Dangling Pointer

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    free(ptr);
    ptr = NULL;
}

A pointer that still refers to an object after its lifetime has ended is dangling.

5. Buffer Overflow

int arr[5];

arr[5] = 100;  /* Out of bounds */

Valid indices are 0 through 4. Accessing arr[5] causes undefined behavior.

6. Double Free

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    free(ptr);
    ptr = NULL;
}

Do not call free() again on an already released allocation. Setting a pointer to NULL after freeing it can help avoid accidental reuse through that pointer.

16. Placement Interview Questions and Answers

Q1. What is an array in C?

An array is a collection of elements of the same data type stored in contiguous memory locations.

Q2. Why does array indexing start at zero?

The index represents an offset from the array's first element. The first element therefore has an offset of zero.

Q3. What is a pointer?

A pointer is a variable that stores the address of another object or function.

Q4. What is the difference between * and &?

The & operator obtains an object's address. The unary * operator dereferences a pointer to access the pointed-to object.

Q5. What is pointer arithmetic?

It is arithmetic on pointers that moves between elements of an array according to the size of the pointed-to type.

Q6. Is an array name a pointer?

No. An array is an array object. In most expressions, its name is converted into a pointer to its first element.

Q7. What is a double pointer?

A double pointer is a pointer that stores the address of another pointer.

Q8. What is a structure in C?

A structure is a user-defined type that groups related members, potentially of different data types.

Q9. What is a self-referential structure?

It is a structure containing a pointer to another object of the same structure type.

Q10. What is the difference between . and ->?

Dot accesses a structure member through an object. Arrow accesses a member through a pointer to a structure.

Q11. What is malloc()?

malloc() dynamically allocates a specified number of bytes and returns a pointer to the allocated memory, or NULL on failure.

Q12. What is the difference between malloc() and calloc()?

malloc() allocates a block without initializing its contents. calloc() allocates space for multiple elements and initializes all bytes to zero.

Q13. What is realloc()?

realloc() changes the size of an existing dynamically allocated memory block.

Q14. What is a memory leak?

A memory leak occurs when allocated memory is no longer reachable or managed properly and cannot be released by the program.

Q15. What is a dangling pointer?

It is a pointer that refers to an object whose lifetime has ended or whose allocation has been released.

Q16. Why are pointers required in linked lists?

Pointers connect dynamically allocated nodes and allow the list to grow or shrink at runtime.

Q17. Why is free() important?

It releases dynamically allocated memory when the program no longer needs it.

Q18. What is the difference between stack and heap memory?

Automatic local objects commonly use stack storage, while malloc(), calloc() and realloc() obtain dynamically allocated storage. Their lifetimes and management differ.

Q19. What is the purpose of a structure pointer?

It allows access to structure members through an address and is commonly used in dynamic data structures.

Q20. What is the purpose of a double pointer in a linked list?

It can allow a function to update the head pointer directly by receiving the address of the head pointer.
