Lesson 8: Dynamic Memory Allocation and C Data Handling

Learn how to allocate, resize, manage and release memory safely in C. Apply these techniques to real data structure implementations.

1. Introduction to Dynamic Memory Allocation

Dynamic memory allocation is the process of requesting memory during program execution rather than deciding the required storage size entirely at compile time.

Consider an application that accepts an unknown number of student records. A fixed-size array may waste memory or fail to accommodate all records. Dynamic allocation provides more flexibility.

Why Is Dynamic Allocation Needed?

  • When the number of elements is not known in advance.
  • When a data structure must grow or shrink at runtime.
  • When implementing linked lists and trees.
  • When allocating graph nodes and adjacency lists.
  • When managing variable-sized data.
Dynamic allocation is essential for data structures whose size changes during program execution.

2. Static Allocation vs Dynamic Allocation

Feature Fixed-Size Array Dynamic Allocation
Size Fixed after creation Can be resized with realloc()
Allocation Declared as an array object Requested using allocation functions
Memory release Automatic when its lifetime ends Program must release it using free()
Typical use Known-size data Runtime-sized data structures
Example int arr[100] malloc() or calloc()

Fixed-Size Array Example

int arr[100];

The array has space for 100 integers. Its size cannot be changed after it has been created.

Dynamic Array Example

int *arr = malloc(100 * sizeof *arr);

This requests enough memory for 100 integers. The allocation can later be resized using realloc().

3. malloc() – Memory Allocation

malloc() requests a specified number of bytes from the memory allocator.

Syntax:

pointer = malloc(number_of_bytes);

It returns a pointer to the allocated memory, suitably aligned for objects with fundamental alignment requirements, or NULL if allocation fails.

Example: Allocate Memory for One Integer

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d\n", *ptr);

    free(ptr);

    return 0;
}
Value = 100

Important Points

  • malloc() is declared in stdlib.h.
  • Its argument is a size in bytes.
  • The allocated contents are uninitialized.
  • Always check whether the returned pointer is NULL.
  • Release the allocation when it is no longer needed.

4. calloc() – Contiguous Memory Allocation

calloc() allocates memory for an array of elements. It initializes all allocated bytes to zero.

Syntax:

pointer = calloc(number_of_elements, size_of_each_element);

Example

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *arr = calloc(n, sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
0 0 0 0 0
calloc() initializes bytes to zero. This gives zero values for ordinary integer objects, but zero-filled bytes should not be assumed to represent every possible pointer or floating-point zero representation on every C implementation.

5. Difference Between malloc() and calloc()

Feature malloc() calloc()
Arguments One size argument Element count and element size
Initialization Uninitialized contents All allocated bytes set to zero
Typical use Allocate a block Allocate an array of elements
Return value Pointer or NULL Pointer or NULL

Both functions allocate dynamic memory and require appropriate release using free().

6. realloc() – Resizing Allocated Memory

realloc() changes the size of an existing dynamic allocation.

Syntax:

new_pointer = realloc(old_pointer, new_size);

The allocation may remain at the same address or be moved to a different address.

Example: Increase Array Size

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(3 * sizeof *arr);

    if (arr == NULL)
    {
        return 1;
    }

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;

    int *temp = realloc(arr, 5 * sizeof *arr);

    if (temp == NULL)
    {
        free(arr);
        return 1;
    }

    arr = temp;

    arr[3] = 40;
    arr[4] = 50;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
10 20 30 40 50

Why Use a Temporary Pointer?

int *temp = realloc(arr, new_size);

if (temp != NULL)
{
    arr = temp;
}
else
{
    /* Original allocation is still valid */
}

If realloc() fails for a nonzero requested size, the original allocation remains valid. Using a temporary pointer prevents losing access to it.

Do not write arr = realloc(arr, new_size) without preserving the original pointer. If the operation fails, the original allocation may become inaccessible through arr.

7. free() – Releasing Allocated Memory

free() releases memory that was obtained through a compatible dynamic allocation function.

Syntax:

free(pointer);

Example

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        return 1;
    }

    *ptr = 500;

    printf("Value = %d\n", *ptr);

    free(ptr);
    ptr = NULL;

    return 0;
}
Value = 500

Important Rules

  • Only release a valid allocation pointer.
  • Do not free the same allocation twice.
  • Do not access an object after freeing its memory.
  • Do not free ordinary local variables or array objects.
  • Setting a released pointer to NULL helps prevent accidental reuse through that pointer.

8. Dynamic Array Implementation

A dynamic array stores elements in a contiguous allocation and tracks the number of elements currently stored and the available capacity.

Important Terms

  • Size: Number of elements currently stored.
  • Capacity: Number of elements that can fit before resizing is required.

Complete Dynamic Array Program

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int capacity = 2;
    int size = 0;

    int *arr = malloc(capacity * sizeof *arr);

    if (arr == NULL)
    {
        return 1;
    }

    for (int value = 10; value <= 50; value += 10)
    {
        if (size == capacity)
        {
            int new_capacity = capacity * 2;

            int *temp = realloc(
                arr,
                new_capacity * sizeof *arr
            );

            if (temp == NULL)
            {
                free(arr);
                return 1;
            }

            arr = temp;
            capacity = new_capacity;
        }

        arr[size] = value;
        size++;
    }

    printf("Array elements: ");

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\nSize = %d\n", size);
    printf("Capacity = %d\n", capacity);

    free(arr);

    return 0;
}
Array elements: 10 20 30 40 50
Size = 5
Capacity = 8

How Resizing Works

Insertion Size Capacity Action
10 1 2 Insert normally
20 2 2 Array becomes full
30 3 4 Capacity doubled
40 4 4 Array becomes full
50 5 8 Capacity doubled

With geometric capacity growth, appending an element is O(1) amortized, although an individual resizing operation can take O(n) time.

9. Dynamic Two-Dimensional Arrays

A two-dimensional dynamic array can be represented using an array of pointers, with each row allocated separately.

Example: Dynamic Matrix

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int rows = 2;
    int cols = 3;

    int **matrix = malloc(rows * sizeof *matrix);

    if (matrix == NULL)
    {
        return 1;
    }

    int allocated_rows = 0;

    for (int i = 0; i < rows; i++)
    {
        matrix[i] = malloc(cols * sizeof *matrix[i]);

        if (matrix[i] == NULL)
        {
            for (int j = 0; j < allocated_rows; j++)
            {
                free(matrix[j]);
            }

            free(matrix);
            return 1;
        }

        allocated_rows++;
    }

    int value = 1;

    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
        {
            matrix[i][j] = value++;
        }
    }

    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    for (int i = 0; i < rows; i++)
    {
        free(matrix[i]);
    }

    free(matrix);

    return 0;
}
1 2 3
4 5 6
Each row is separately allocated here. Therefore, the rows are not guaranteed to be contiguous with one another.

10. Memory Management in Linked Lists

Linked lists are a practical example of dynamic memory allocation. Every node is created when needed and released when deleted.

Node Declaration

struct Node
{
    int data;
    struct Node *next;
};

Create a Node

struct Node *create_node(int value)
{
    struct Node *new_node =
        malloc(sizeof *new_node);

    if (new_node == NULL)
    {
        return NULL;
    }

    new_node->data = value;
    new_node->next = NULL;

    return new_node;
}

Delete a Node Safely

void delete_first_node(struct Node **head)
{
    if (head == NULL || *head == NULL)
    {
        return;
    }

    struct Node *temp = *head;

    *head = (*head)->next;

    free(temp);
}

The double pointer allows the function to update the caller's head pointer.

11. Memory Ownership and Lifetime

Memory ownership describes which part of a program is responsible for managing and releasing an allocation.

Example: Function Returns Allocated Memory

#include <stdio.h>
#include <stdlib.h>

int *create_array(int n)
{
    if (n <= 0)
    {
        return NULL;
    }

    int *arr = malloc((size_t)n * sizeof *arr);

    if (arr == NULL)
    {
        return NULL;
    }

    for (int i = 0; i < n; i++)
    {
        arr[i] = (i + 1) * 10;
    }

    return arr;
}

int main(void)
{
    int n = 5;

    int *arr = create_array(n);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
10 20 30 40 50

The function creates the allocation and returns its address. The caller becomes responsible for releasing it with free().

A useful programming rule is to define clearly who owns each allocation and which function releases it.

12. Common Memory Management Errors

Error Explanation Prevention
Memory leak Allocated memory is not released. Track allocations and call free().
Dangling pointer Pointer refers to an object whose lifetime ended. Do not access released objects.
Double free Same allocation is released more than once. Maintain clear ownership.
Buffer overflow Access beyond allocated bounds. Validate indices and lengths.
Allocation failure Allocation function returns NULL. Check every allocation result.
Use after free Access after releasing memory. Stop using the released object.

Example of an Unsafe Operation

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    free(ptr);

    /* Do not use *ptr here */
}

Safer Pointer Handling

free(ptr);
ptr = NULL;

Setting ptr to NULL prevents accidental access through that particular pointer, but it does not invalidate other aliases that may still contain the old address.

13. Debugging Memory Problems

Memory errors can cause crashes, incorrect results, security vulnerabilities and unpredictable program behavior.

Useful Compiler Options

When using GCC, compile with warnings and debugging information: 

gcc -std=c11 -Wall -Wextra -Wpedantic -g program.c -o program

AddressSanitizer

On supported GCC or Clang environments, AddressSanitizer can help detect memory errors. 

gcc -std=c11 -Wall -Wextra -g \
-fsanitize=address,undefined program.c -o program

Run the compiled program:

./program

Valgrind

Valgrind can help identify memory leaks and invalid memory operations on supported systems. 

valgrind --leak-check=full ./program
These tools are useful during C programming practice and technical project development.

14. Time and Space Complexity of Dynamic Memory Operations

Operation Typical Complexity Explanation
malloc() Not guaranteed O(1) Depends on allocator implementation and state.
calloc() Not guaranteed O(1) May need to initialize allocated memory.
free() Not guaranteed O(1) Depends on allocator implementation.
Access dynamic array element O(1) Direct indexing.
Resize dynamic array O(n) in the worst case Data may need to be moved.
Append with geometric growth O(1) amortized Occasional O(n) resizing is spread across insertions.

The exact performance of allocation functions depends on the system's memory allocator. Do not assume malloc() or free() always have a particular asymptotic complexity.

15. Placement Interview Questions and Answers

Q1. What is dynamic memory allocation?

It is the process of requesting memory during program execution using functions such as malloc(), calloc() and realloc().

Q2. Which header file is required for malloc()?

stdlib.h.

Q3. What does malloc() return?

It returns a pointer to allocated memory or NULL if allocation fails.

Q4. Is memory allocated by malloc() initialized?

No. Its contents are uninitialized.

Q5. What is the difference between malloc() and calloc()?

malloc() accepts one size argument and does not initialize the contents. calloc() accepts an element count and size and sets all allocated bytes to zero.

Q6. What is realloc() used for?

It changes the size of a previously allocated memory block.

Q7. What happens if realloc() fails?

For a nonzero requested size, it returns NULL and leaves the original allocation valid.

Q8. What is the purpose of free()?

It releases dynamically allocated memory.

Q9. What is a memory leak?

A memory leak occurs when allocated memory is no longer properly managed or released.

Q10. What is a dangling pointer?

It is a pointer that refers to an object whose lifetime has ended.

Q11. What is a double free error?

It occurs when the same allocation is released more than once.

Q12. Why should malloc() results be checked?

Allocation can fail. Dereferencing a NULL pointer causes undefined behavior.

Q13. Why is sizeof *ptr often preferred over sizeof(int)?

It ties the allocation size to the pointed-to type, making the code easier to maintain if the pointer type changes.

Q14. What is a dynamic array?

It is an array-like structure whose storage is dynamically allocated and can be resized.

Q15. What is amortized time complexity?

It is the average cost per operation over a sequence of operations, even when individual operations have different costs.

Q16. Why is dynamic memory important in linked lists?

It allows nodes to be created and removed individually as the list changes size.

Q17. Can free() release a normal local variable?

No. free() must receive a pointer returned by a compatible dynamic allocation function, or NULL.

Q18. What is memory ownership?

It describes which part of a program is responsible for managing and releasing dynamically allocated memory.

Q19. What is AddressSanitizer?

It is a runtime memory error detection tool that can identify problems such as out-of-bounds access and use-after-free.

Q20. What is the difference between size and capacity in a dynamic array?

Size is the number of stored elements. Capacity is the number of elements that can fit in the current allocation.
