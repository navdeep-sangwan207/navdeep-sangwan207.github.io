Lesson 2: Types of Data Structures

Learn how data structures are classified, how they organize information and when different structures are useful in programming.

1. Classification of Data Structures

Data structures can be classified into different categories based on the type of data they store, how elements are organized and how memory is allocated.

The major classifications are:

  • Primitive and non-primitive data structures.
  • Linear and non-linear data structures.
  • Static and dynamic data structures.
Interview Tip: Be prepared to explain each classification with examples and distinguish between linear and non-linear data structures.

2. Primitive Data Structures

Primitive data types are the basic built-in types provided by C. They store individual values.

Common Primitive Types in C

Data Type Purpose Example
int Stores integer values. int age = 25;
char Stores a character. char grade = 'A';
float Stores single-precision floating-point values. float price = 12.5f;
double Stores double-precision floating-point values. double pi = 3.14159;

The exact size of these types depends on the C implementation. Use the sizeof operator to determine their size on a particular system.

C Program: Display Data Type Sizes

#include <stdio.h>

int main(void)
{
    printf("Size of int    = %zu bytes\n", sizeof(int));
    printf("Size of char   = %zu byte\n", sizeof(char));
    printf("Size of float  = %zu bytes\n", sizeof(float));
    printf("Size of double = %zu bytes\n", sizeof(double));

    return 0;
}

Possible Output

Size of int    = 4 bytes
Size of char   = 1 byte
Size of float  = 4 bytes
Size of double = 8 bytes

These are common results on modern systems, not guaranteed sizes for every C implementation.

3. Non-Primitive Data Structures

Non-primitive data structures organize multiple values or relationships between data elements. They are commonly implemented using arrays, structures, pointers and dynamic memory allocation.

Examples include:

  • Array
  • Linked List
  • Stack
  • Queue
  • Tree
  • Graph
  • Hash Table
A data structure such as a linked list is not a built-in primitive C type. It is constructed using C language features such as structures and pointers.

4. Linear Data Structures

A linear data structure organizes elements in a sequential manner. Each element generally has a logical predecessor and successor, except at the boundaries.

Examples

  • Array
  • Linked List
  • Stack
  • Queue

4.1 Array

An array stores elements of the same type in contiguous memory locations. 

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
10 20 30 40 50

Important properties:

  • Elements are stored contiguously.
  • Index-based access is O(1).
  • Array size is fixed after declaration for an ordinary fixed-size array.
  • Insertion in the middle may require shifting elements.

4.2 Linked List

A linked list consists of nodes. Each node stores data and a pointer to another node. 

#include <stdio.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node first;
    struct Node second;

    first.data = 10;
    first.next = &second;

    second.data = 20;
    second.next = NULL;

    struct Node *current = &first;

    while (current != NULL)
    {
        printf("%d ", current->data);
        current = current->next;
    }

    return 0;
}
10 20

Important properties:

  • Nodes need not occupy contiguous memory.
  • Nodes are connected through pointers.
  • Insertion and deletion can be efficient when the relevant node position is known.
  • Accessing an arbitrary position requires traversal.

4.3 Stack

A stack follows the LIFO principle: Last In, First Out.

The most recently inserted element is removed first. Common operations are push, pop and peek.

Applications:

  • Function call management.
  • Expression evaluation.
  • Undo operations.
  • Parentheses matching.

4.4 Queue

A queue generally follows the FIFO principle: First In, First Out.

The first inserted element is removed first. Common operations are enqueue and dequeue.

Applications:

  • Printer job scheduling.
  • CPU scheduling concepts.
  • Task processing.
  • Request handling.

5. Non-Linear Data Structures

Non-linear data structures do not organize all elements in one simple sequential order. They represent hierarchical or network relationships.

5.1 Tree

A tree is a hierarchical data structure consisting of nodes connected by edges.

Common terminology:

  • Root – the topmost node.
  • Parent – a node that has child nodes.
  • Child – a node connected below a parent.
  • Leaf – a node with no children.
  • Subtree – a node and its descendants.
  • Height – the number of edges on the longest downward path from a node to a leaf.

Applications:

  • File system organization.
  • Database indexing.
  • Hierarchical data representation.
  • Searching and sorting structures.

5.2 Graph

A graph consists of vertices (nodes) and edges connecting pairs of vertices.

Applications:

  • Social networks.
  • Road and navigation networks.
  • Computer networks.
  • Dependency relationships.

5.3 Hash Table

A hash table stores key-value pairs and uses a hash function to determine where a key should be stored.

Applications:

  • Fast lookup by key.
  • Frequency counting.
  • Duplicate detection.
  • Symbol tables.

6. Static and Dynamic Data Structures

6.1 Static Data Structures

A static data structure has a size determined before its use and does not grow or shrink automatically during its lifetime.

Example: A fixed-size array.

int numbers[5] = {10, 20, 30, 40, 50};

Characteristics:

  • Fixed capacity.
  • Simple memory management.
  • Direct index access for arrays.
  • May waste space or become insufficient if the required capacity changes.

6.2 Dynamic Data Structures

Dynamic data structures can grow or shrink during program execution as memory is allocated or released.

Examples:

  • Linked List
  • Dynamic Stack
  • Dynamic Queue
  • Trees
  • Graphs
  • Resizable dynamic arrays

In C, dynamic memory allocation is commonly performed using malloc(), calloc(), realloc() and free().

Important distinction: Dynamic allocation and dynamic data structures are related but not identical concepts. A dynamically allocated array can still have a fixed capacity unless it is resized.

7. Comparison of Data Structures

Data Structure Category Organization Typical Application
Array Linear Contiguous elements Indexed storage
Linked List Linear Connected nodes Dynamic collections
Stack Linear LIFO Function calls
Queue Linear FIFO Task scheduling
Tree Non-linear Hierarchy Database indexing
Graph Non-linear Network relationships Navigation
Hash Table Associative Key-value mapping Fast lookup

8. Choosing the Right Data Structure

The choice depends on the operations that the application performs most frequently.

Requirement Suitable Data Structure
Fast indexed access Array
Frequent insertion and deletion at known positions Linked List
Last-in-first-out processing Stack
First-in-first-out processing Queue
Hierarchical relationships Tree
Network relationships Graph
Average-case fast key lookup Hash Table
No single data structure is best for every problem. Selection depends on access patterns, update frequency, memory constraints and required operations.

9. Placement Interview Questions and Answers

Q1. What are the major types of data structures?

Data structures are commonly classified as primitive and non-primitive. Non-primitive structures include linear and non-linear structures.

Q2. What is a linear data structure?

A linear data structure organizes elements in a sequential order. Examples include arrays, linked lists, stacks and queues.

Q3. What is a non-linear data structure?

A non-linear data structure represents hierarchical or interconnected relationships. Examples include trees and graphs.

Q4. What is the difference between an array and a linked list?

An array stores elements in contiguous memory and supports constant-time indexed access. A linked list stores nodes connected through pointers and requires traversal for positional access.

Q5. What is the difference between a stack and a queue?

A stack follows LIFO, whereas a queue follows FIFO.

Q6. Is a linked list static or dynamic?

A linked list is commonly implemented as a dynamic data structure because nodes can be allocated and released during execution.

Q7. Is an array always static?

No. A fixed-size array has a fixed capacity. A dynamically allocated array can be allocated at runtime and resized using realloc(), although resizing may move its storage.

Q8. Which data structure is used in recursion?

The call stack manages function calls and local execution state during recursion.

Q9. Which data structure is suitable for hierarchical data?

A tree is commonly used to represent hierarchical relationships.

Q10. What is a hash table?

A hash table stores key-value pairs and uses a hash function to map keys to storage locations.

Q11. Can a data structure be implemented using another data structure?

Yes. For example, a stack or queue can be implemented using an array or linked list.

Q12. Which data structure is used for breadth-first search?

A queue is used to process vertices level by level during breadth-first search.
