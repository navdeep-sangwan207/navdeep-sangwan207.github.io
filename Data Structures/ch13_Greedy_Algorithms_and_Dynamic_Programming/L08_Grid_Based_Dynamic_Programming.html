Chapter 13 – Lesson 08

Grid-Based Dynamic Programming

Learn how to solve matrix and grid problems using DP states, transitions, boundary conditions and space optimization.

1. Learning Objectives

  • Understand grid-based dynamic programming.
  • Define a DP state for each grid cell.
  • Count unique paths in a rectangular grid.
  • Solve path-counting problems with obstacles.
  • Calculate minimum and maximum path sums.
  • Reconstruct an optimal path.
  • Optimize two-dimensional DP to one-dimensional DP.
  • Recognize common grid DP interview patterns.

2. What Is Grid-Based Dynamic Programming?

Grid-based DP solves problems in which a solution is built by moving through cells of a two-dimensional matrix.

Typical movements include:

  • Right: (i, j + 1)
  • Down: (i + 1, j)
  • Diagonal: (i + 1, j + 1), when allowed
  • Up, left or four-directional movement in problems with additional constraints.

Example Grid

S . . . . . . . E

S represents the starting cell, E represents the destination, and each dot represents an ordinary cell.

A common grid DP state is dp[i][j], representing the answer for reaching or processing cell (i, j). The exact meaning depends on the problem.

3. Unique Paths Problem

Problem: A robot starts at the top-left corner of an m × n grid and must reach the bottom-right corner. It can move only right or down. Find the number of distinct paths.

Example

For a 3 × 3 grid, the robot can reach the destination in 6 ways.

S → → ↓ ↓ ↓ → → E

DP State

dp[i][j] represents the number of ways to reach cell (i, j).

Transition

A cell can be reached from:

  • The cell directly above: (i - 1, j).
  • The cell directly to the left: (i, j - 1).
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];

Base Cases

  • dp[0][0] = 1
  • Every cell in the first row has one way to be reached.
  • Every cell in the first column has one way to be reached.

Dry Run: 3 × 3 Grid

111
123
136

Therefore, the answer is 6.

4. Unique Paths – Two-Dimensional DP

Complete C11 Program

#include <stdio.h> #define MAX 100 int main(void) { int dp[MAX][MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid grid dimensions.\n"); return 1; } for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (i == 0 || j == 0) dp[i][j] = 1; else dp[i][j] = dp[i - 1][j] + dp[i][j - 1]; } } printf("Number of unique paths = %d\n", dp[m - 1][n - 1]); printf("DP Table:\n"); for (i = 0; i < m; i++) { for (j = 0; j < n; j++) printf("%5d", dp[i][j]); printf("\n"); } return 0; }

Expected Output

Enter rows and columns: 3 3 Number of unique paths = 6 DP Table: 1 1 1 1 2 3 1 3 6

Complexity

  • Time: O(m × n).
  • Space: O(m × n).

5. Unique Paths – Space Optimization

Each cell depends only on the value directly above and the value to its left. We can therefore use a single one-dimensional DP array.

Transition

dp[j] = dp[j] + dp[j - 1];

Before updating a cell:

  • dp[j] contains the value from the previous row.
  • dp[j-1] contains the updated value from the current row.

Complete C11 Program

#include <stdio.h> #define MAX 100 int main(void) { int dp[MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid grid dimensions.\n"); return 1; } for (j = 0; j < n; j++) dp[j] = 1; for (i = 1; i < m; i++) { for (j = 1; j < n; j++) dp[j] += dp[j - 1]; } printf("Number of unique paths = %d\n", dp[n - 1]); return 0; }

Expected Output

Enter rows and columns: 3 3 Number of unique paths = 6

Complexity

  • Time: O(m × n).
  • Auxiliary Space: O(n).
These examples use int for clarity and restrict dimensions to 100. The number of paths can grow very quickly. For larger constraints, use a wider integer type with overflow checks or an explicitly specified modulo.

6. Unique Paths With Obstacles

Problem: Some cells contain obstacles. The robot cannot enter an obstacle cell. Count the valid paths from the top-left to the bottom-right cell.

Example Grid

0 0 0 0 1 0 0 0 0

Here, 1 represents an obstacle and 0 represents an open cell.

Only two valid paths exist.

DP State and Transition

if (obstacle[i][j] == 1) dp[i][j] = 0; else dp[i][j] = dp[i - 1][j] + dp[i][j - 1];

Complete C11 Program

#include <stdio.h> #define MAX 100 int main(void) { int grid[MAX][MAX]; int dp[MAX][MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid dimensions.\n"); return 1; } printf("Enter grid (0=open, 1=obstacle):\n"); for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (scanf("%d", &grid[i][j]) != 1 || (grid[i][j] != 0 && grid[i][j] != 1)) { printf("Invalid grid value.\n"); return 1; } } } for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (grid[i][j] == 1) { dp[i][j] = 0; } else if (i == 0 && j == 0) { dp[i][j] = 1; } else { int fromTop = (i > 0) ? dp[i - 1][j] : 0; int fromLeft = (j > 0) ? dp[i][j - 1] : 0; dp[i][j] = fromTop + fromLeft; } } } printf("Number of valid paths = %d\n", dp[m - 1][n - 1]); return 0; }

Expected Output

Enter rows and columns: 3 3 Enter grid (0=open, 1=obstacle): 0 0 0 0 1 0 0 0 0 Number of valid paths = 2

Complexity

  • Time: O(m × n).
  • Space: O(m × n).

7. Minimum Path Sum

Problem: Given a grid containing nonnegative costs, find a path from the top-left to the bottom-right cell that has the minimum total cost. You can move only right or down.

Example

1 3 1 1 5 1 4 2 1

One minimum-cost path is:

1 → 3 → 1 ↓ 1 ↓ 1

Minimum cost = 1 + 3 + 1 + 1 + 1 = 7.

DP State

dp[i][j] represents the minimum cost required to reach cell (i, j), including that cell's cost.

Transition

dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1]);

Boundary Conditions

  • Start: dp[0][0] = grid[0][0].
  • First row: only the left cell is reachable.
  • First column: only the top cell is reachable.

8. Minimum Path Sum – Complete C11 Program

#include <stdio.h> #include <limits.h> #define MAX 100 int main(void) { int grid[MAX][MAX]; long long dp[MAX][MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid dimensions.\n"); return 1; } printf("Enter nonnegative grid costs:\n"); for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (scanf("%d", &grid[i][j]) != 1 || grid[i][j] < 0) { printf("Invalid grid cost.\n"); return 1; } } } dp[0][0] = grid[0][0]; for (j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j]; for (i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0]; for (i = 1; i < m; i++) { for (j = 1; j < n; j++) { long long top = dp[i - 1][j]; long long left = dp[i][j - 1]; long long best = (top < left) ? top : left; if (best > LLONG_MAX - grid[i][j]) { printf("Path cost overflow.\n"); return 1; } dp[i][j] = best + grid[i][j]; } } printf("Minimum path sum = %lld\n", dp[m - 1][n - 1]); return 0; }

Expected Output

Enter rows and columns: 3 3 Enter nonnegative grid costs: 1 3 1 1 5 1 4 2 1 Minimum path sum = 7

Complexity

  • Time: O(m × n).
  • Space: O(m × n).

9. Minimum Path Sum – Space Optimization

Only the previous row and the current row's previous cell are required. A one-dimensional array is sufficient.

Transition

dp[j] = grid[i][j] + min(dp[j], dp[j - 1]);

Complete C11 Program

#include <stdio.h> #include <limits.h> #define MAX 100 int main(void) { int grid[MAX][MAX]; long long dp[MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid dimensions.\n"); return 1; } printf("Enter nonnegative grid costs:\n"); for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (scanf("%d", &grid[i][j]) != 1 || grid[i][j] < 0) { printf("Invalid grid cost.\n"); return 1; } } } dp[0] = grid[0][0]; for (j = 1; j < n; j++) { if (dp[j - 1] > LLONG_MAX - grid[0][j]) { printf("Path cost overflow.\n"); return 1; } dp[j] = dp[j - 1] + grid[0][j]; } for (i = 1; i < m; i++) { if (dp[0] > LLONG_MAX - grid[i][0]) { printf("Path cost overflow.\n"); return 1; } dp[0] += grid[i][0]; for (j = 1; j < n; j++) { long long best = (dp[j] < dp[j - 1]) ? dp[j] : dp[j - 1]; if (best > LLONG_MAX - grid[i][j]) { printf("Path cost overflow.\n"); return 1; } dp[j] = best + grid[i][j]; } } printf("Minimum path sum = %lld\n", dp[n - 1]); return 0; }

Expected Output

Enter rows and columns: 3 3 Enter nonnegative grid costs: 1 3 1 1 5 1 4 2 1 Minimum path sum = 7

Complexity

  • Time: O(m × n).
  • Auxiliary Space: O(n).

10. Maximum Path Sum in a Grid

Problem: Given a grid of values, find the maximum sum along a path from the top-left to the bottom-right, moving only right or down.

DP State

dp[i][j] stores the maximum path sum ending at cell (i, j).

Transition

dp[i][j] = grid[i][j] + max(dp[i - 1][j], dp[i][j - 1]);

The boundary conditions are similar to Minimum Path Sum, but the transition selects the larger predecessor.

Complete C11 Program

#include <stdio.h> #include <limits.h> #define MAX 100 int main(void) { int grid[MAX][MAX]; long long dp[MAX][MAX]; int m, n; int i, j; printf("Enter rows and columns: "); if (scanf("%d %d", &m, &n) != 2 || m < 1 || n < 1 || m > MAX || n > MAX) { printf("Invalid dimensions.\n"); return 1; } printf("Enter grid values:\n"); for (i = 0; i < m; i++) { for (j = 0; j < n; j++) { if (scanf("%d", &grid[i][j]) != 1) { printf("Invalid input.\n"); return 1; } } } dp[0][0] = grid[0][0]; for (j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j]; for (i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0]; for (i = 1; i < m; i++) { for (j = 1; j < n; j++) { long long top = dp[i - 1][j]; long long left = dp[i][j - 1]; long long best = (top > left) ? top : left; if (best > LLONG_MAX - grid[i][j]) { printf("Path sum overflow.\n"); return 1; } if (best < LLONG_MIN - grid[i][j]) { printf("Path sum overflow.\n"); return 1; } dp[i][j] = best + grid[i][j]; } } printf("Maximum path sum = %lld\n", dp[m - 1][n - 1]); return 0; }

Expected Output

Enter rows and columns: 3 3 Enter grid values: 1 3 1 1 5 1 4 2 1 Maximum path sum = 12

Complexity: O(m × n) time and O(m × n) space.

11. Reconstructing an Optimal Path

Sometimes an interviewer asks for the actual path, not just its cost.

For Minimum Path Sum, store the predecessor chosen at every cell:

  • Choose the top cell if its DP value is smaller.
  • Otherwise choose the left cell.
  • Continue until the starting cell is reached.
  • Reverse the collected sequence to display it from start to destination.
if (dp[i - 1][j] < dp[i][j - 1]) { parent[i][j] = 'U'; } else { parent[i][j] = 'L'; }
A parent matrix or predecessor-direction array allows path reconstruction. A space-optimized DP array alone generally does not preserve enough information to reconstruct the entire path.

12. Grid DP With Diagonal Movement

Some problems allow movement right, down and diagonally down-right.

Possible Predecessors

  • Top: (i - 1, j)
  • Left: (i, j - 1)
  • Diagonal: (i - 1, j - 1)

Path Counting Transition

dp[i][j] = dp[i - 1][j] + dp[i][j - 1] + dp[i - 1][j - 1];

Boundary checks are required before accessing each predecessor.

Do not add diagonal movement unless the problem explicitly allows it. Changing the allowed movement changes the recurrence and the number of valid paths.

14. Minimum Falling Path Sum – Interview Pattern

Given a square matrix, start from any cell in the first row and move to the next row. From column j, you may move to column j-1, j or j+1. Find the minimum falling path sum.

Recurrence

dp[i][j] = grid[i][j] + min( dp[i - 1][j - 1], dp[i - 1][j], dp[i - 1][j + 1] );

Only valid predecessor columns should be considered.

Complete C11 Program

#include <stdio.h> #include <limits.h> #define MAX 100 int main(void) { int grid[MAX][MAX]; long long dp[MAX][MAX]; int n, i, j; long long answer = LLONG_MAX; printf("Enter matrix size: "); if (scanf("%d", &n) != 1 || n < 1 || n > MAX) { printf("Invalid matrix size.\n"); return 1; } printf("Enter matrix values:\n"); for (i = 0; i < n; i++) { for (j = 0; j < n; j++) { if (scanf("%d", &grid[i][j]) != 1) { printf("Invalid input.\n"); return 1; } } } for (j = 0; j < n; j++) dp[0][j] = grid[0][j]; for (i = 1; i < n; i++) { for (j = 0; j < n; j++) { long long best = dp[i - 1][j]; if (j > 0 && dp[i - 1][j - 1] < best) best = dp[i - 1][j - 1]; if (j + 1 < n && dp[i - 1][j + 1] < best) best = dp[i - 1][j + 1]; if (best > LLONG_MAX - grid[i][j]) { printf("Path sum overflow.\n"); return 1; } if (best < LLONG_MIN - grid[i][j]) { printf("Path sum overflow.\n"); return 1; } dp[i][j] = best + grid[i][j]; } } for (j = 0; j < n; j++) { if (dp[n - 1][j] < answer) answer = dp[n - 1][j]; } printf("Minimum falling path sum = %lld\n", answer); return 0; }

Expected Output

Enter matrix size: 3 Enter matrix values: 2 1 3 6 5 4 7 8 9 Minimum falling path sum = 13

Complexity: O(n²) time and O(n²) space.

15. Common Mistakes in Grid DP

  1. Accessing dp[i-1][j] when i is zero.
  2. Accessing dp[i][j-1] when j is zero.
  3. Forgetting to initialize the first row and first column.
  4. Counting paths through obstacle cells.
  5. Using min instead of max, or max instead of min.
  6. Updating a one-dimensional DP array in the wrong direction.
  7. Ignoring integer overflow in path counts and sums.
  8. Assuming every grid problem permits only right and down movement.
  9. Trying to apply ordinary grid DP to problems where movement can revisit cells without additional state or constraints.

16. Interview Questions and Answers

Q1. What is grid-based DP?

It is dynamic programming in which each cell represents a state and transitions connect neighboring cells.

Q2. What does dp[i][j] represent in Unique Paths?

The number of ways to reach cell (i, j) from the starting cell.

Q3. Why is dp[0][0] equal to 1 in Unique Paths?

There is exactly one way to be at the starting cell: start there.

Q4. How are obstacles handled?

An obstacle cell receives zero paths and cannot be used as a predecessor for a valid route.

Q5. What is the Minimum Path Sum recurrence?

Current cell cost plus the minimum of the top and left predecessor costs.

Q6. How can grid DP space be optimized?

If each state depends only on the previous row and the current row's previous cell, use a one-dimensional DP array.

Q7. What is the difference between path counting and path optimization?

Path counting adds the number of valid predecessor paths. Path optimization selects a minimum or maximum cost.

Q8. Why can a parent matrix be useful?

It records the predecessor selected for each state, allowing reconstruction of an optimal path.

Q9. What is the complexity of ordinary rectangular grid DP?

Usually O(m × n) time, because every cell is processed a constant number of times.

Q10. What changes when diagonal movement is allowed?

The recurrence gains a diagonal predecessor, provided the movement is permitted by the problem.

19. Lesson Summary

  • Grid DP represents each cell as a state.
  • Unique Paths counts ways using top and left predecessors.
  • Obstacles contribute zero valid paths.
  • Minimum and maximum path problems use min or max transitions.
  • One-dimensional DP can reduce auxiliary space from O(m × n) to O(n) when dependencies permit it.
  • Path reconstruction requires storing predecessor information.
  • Boundary conditions and movement rules determine the correct recurrence.
