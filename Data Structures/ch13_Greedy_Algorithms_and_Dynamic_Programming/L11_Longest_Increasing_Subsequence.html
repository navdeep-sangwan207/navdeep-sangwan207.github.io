Chapter 13 – Lesson 11

Longest Increasing Subsequence (LIS)

Master a frequently asked dynamic programming problem and learn how to optimize it from O(n²) to O(n log n).

1. Learning Objectives

  • Understand increasing subsequences.
  • Define the LIS dynamic programming state.
  • Solve LIS using recursion and memoization.
  • Implement the O(n²) tabulation solution.
  • Optimize LIS using binary search.
  • Reconstruct an actual longest increasing subsequence.
  • Understand related interview problems and variations.

2. What Is a Subsequence?

A subsequence is formed by selecting elements from an array while preserving their original relative order. Selected elements do not need to be adjacent.

Example

Array: 10 9 2 5 3 7 101 18 One longest increasing subsequence: 2 3 7 18 LIS length = 4

Another valid increasing subsequence is:

2 5 7 18
An increasing subsequence requires each selected element to be strictly greater than the previous selected element. Equal values cannot both appear in a strictly increasing subsequence.

3. Problem Definition

Given an array of integers, find the length of its longest strictly increasing subsequence.

Example 1

Input: arr = {10, 9, 2, 5, 3, 7, 101, 18} Output: 4

Example 2

Input: arr = {0, 1, 0, 3, 2, 3} Output: 4 One LIS: 0 1 2 3

Example 3

Input: arr = {7, 7, 7, 7} Output: 1

4. Recursive Approach

At each array index, we have two choices:

  1. Skip the current element.
  2. Take the current element if it is greater than the previously selected element.

We maintain two parameters:

  • index: current array position.
  • previous: index of the previously selected element, or -1 if none has been selected.

Recurrence

skip = LIS(index + 1, previous) take = 1 + LIS(index + 1, index) if previous == -1 or arr[index] > arr[previous] answer = max(skip, take)

Base Case

if (index == n) return 0;

Complete C11 Program – Recursion

#include <stdio.h> #define MAX 100 int max(int a, int b) { return (a > b) ? a : b; } int lisRecursive(const int arr[], int n, int index, int previous) { int skip, take = 0; if (index == n) return 0; skip = lisRecursive(arr, n, index + 1, previous); if (previous == -1 || arr[index] > arr[previous]) { take = 1 + lisRecursive( arr, n, index + 1, index ); } return max(skip, take); } int main(void) { int arr[MAX]; int n, i; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) { printf("Invalid size.\n"); return 1; } printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) { printf("Invalid input.\n"); return 1; } } printf("LIS length = %d\n", lisRecursive(arr, n, 0, -1)); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4

Complexity

  • Time: O(2ⁿ) upper bound.
  • Recursion stack: O(n).

This approach repeats many subproblems and becomes inefficient for larger arrays.

5. Memoization – Top-Down DP

Memoization stores the answer for each combination of current index and previous index.

DP State

dp[index][previous + 1]

The offset of one allows previous = -1 to be stored at column zero.

Complete C11 Program – Memoization

#include <stdio.h> #define MAX 100 int dp[MAX][MAX + 1]; int max(int a, int b) { return (a > b) ? a : b; } int lisMemo(const int arr[], int n, int index, int previous) { int skip, take = 0; int column = previous + 1; if (index == n) return 0; if (dp[index][column] != -1) return dp[index][column]; skip = lisMemo(arr, n, index + 1, previous); if (previous == -1 || arr[index] > arr[previous]) { take = 1 + lisMemo( arr, n, index + 1, index ); } dp[index][column] = max(skip, take); return dp[index][column]; } int main(void) { int arr[MAX]; int n, i, j; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { for (j = 0; j <= n; j++) dp[i][j] = -1; } printf("LIS length = %d\n", lisMemo(arr, n, 0, -1)); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4

Complexity

  • Time: O(n²).
  • DP storage: O(n²).
  • Recursion stack: O(n).

6. Tabulation – Bottom-Up DP

A simpler LIS solution defines the state based on the element that must be included as the last element of the subsequence.

DP State

dp[i] = length of the longest increasing subsequence ending at index i

Initialization

dp[i] = 1;

Every element forms an increasing subsequence of length one by itself.

Transition

For every previous index j:

if (arr[j] < arr[i]) { dp[i] = max(dp[i], dp[j] + 1); }

We calculate the maximum value in the DP array.

Complete C11 Program – Tabulation

#include <stdio.h> #define MAX 100 int max(int a, int b) { return (a > b) ? a : b; } int main(void) { int arr[MAX], dp[MAX]; int n, i, j; int answer = 0; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { dp[i] = 1; for (j = 0; j < i; j++) { if (arr[j] < arr[i]) { dp[i] = max(dp[i], dp[j] + 1); } } answer = max(answer, dp[i]); } printf("LIS length = %d\n", answer); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4

7. Reconstructing the Actual LIS

To print an actual LIS, maintain a parent array that stores the previous index in the selected subsequence.

Complete C11 Program

#include <stdio.h> #define MAX 100 int main(void) { int arr[MAX], dp[MAX], parent[MAX]; int sequence[MAX]; int n, i, j; int bestLength = 0; int lastIndex = -1; int count = 0; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { dp[i] = 1; parent[i] = -1; for (j = 0; j < i; j++) { if (arr[j] < arr[i] && dp[j] + 1 > dp[i]) { dp[i] = dp[j] + 1; parent[i] = j; } } if (dp[i] > bestLength) { bestLength = dp[i]; lastIndex = i; } } while (lastIndex != -1) { sequence[count++] = arr[lastIndex]; lastIndex = parent[lastIndex]; } printf("LIS length = %d\n", bestLength); printf("LIS = "); for (i = count - 1; i >= 0; i--) printf("%d ", sequence[i]); printf("\n"); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4 LIS = 2 3 7 18

The program prints one valid LIS. Other valid LIS sequences may also exist.

8. Optimized LIS – O(n log n)

The O(n²) approach compares each element with all previous elements. We can optimize the length calculation using binary search.

Maintain a Tails Array

Maintain an array called tails.

tails[k] represents the smallest possible ending value of an increasing subsequence of length k+1 found so far.

Algorithm

  1. Start with an empty tails array.
  2. Process each input element.
  3. Use binary search to find the first tails value greater than or equal to the current element.
  4. Replace that value with the current element.
  5. If no such position exists, append the current element.
  6. The final tails length is the LIS length.
The tails array does not necessarily contain the actual LIS. It stores minimum ending values for subsequences of different lengths. Use parent tracking if you need to reconstruct an actual sequence.

Complete C11 Program – O(n log n)

#include <stdio.h> #define MAX 100 int lowerBound(const int arr[], int size, int target) { int low = 0; int high = size; while (low < high) { int mid = low + (high - low) / 2; if (arr[mid] < target) low = mid + 1; else high = mid; } return low; } int main(void) { int arr[MAX], tails[MAX]; int n, i; int length = 0; int position; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { position = lowerBound( tails, length, arr[i] ); tails[position] = arr[i]; if (position == length) length++; } printf("LIS length = %d\n", length); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4

Complexity

  • Time: O(n log n).
  • Space: O(n).

9. Strictly Increasing vs Non-Decreasing Subsequence

This distinction is frequently tested in coding interviews.

TypeConditionBinary Search
Strictly increasingarr[j] < arr[i]Lower bound: first value ≥ target
Non-decreasingarr[j] ≤ arr[i]Upper bound: first value > target

Example

Array: 2 2 2 3 Strictly increasing LIS: 2 3 Length = 2 Longest non-decreasing subsequence: 2 2 2 3 Length = 4
For the non-decreasing variant, change the binary search condition from arr[mid] < target to arr[mid] <= target.

10. LIS Using Binary Search and Parent Tracking

The following complete C11 program reconstructs one LIS while maintaining O(n log n) time complexity.

#include <stdio.h> #define MAX 100 int lowerBound(const int tails[], int size, int target) { int low = 0; int high = size; while (low < high) { int mid = low + (high - low) / 2; if (tails[mid] < target) low = mid + 1; else high = mid; } return low; } int main(void) { int arr[MAX]; int tails[MAX]; int tailIndex[MAX]; int parent[MAX]; int sequence[MAX]; int n, i, position; int length = 0; int lastIndex; int count = 0; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { parent[i] = -1; position = lowerBound( tails, length, arr[i] ); if (position > 0) parent[i] = tailIndex[position - 1]; tails[position] = arr[i]; tailIndex[position] = i; if (position == length) length++; } if (length > 0) { lastIndex = tailIndex[length - 1]; while (lastIndex != -1) { sequence[count++] = arr[lastIndex]; lastIndex = parent[lastIndex]; } } printf("LIS length = %d\n", length); printf("LIS = "); for (i = count - 1; i >= 0; i--) printf("%d ", sequence[i]); printf("\n"); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 10 9 2 5 3 7 101 18 LIS length = 4 LIS = 2 3 7 18

12. Longest Bitonic Subsequence

A bitonic subsequence first increases and then decreases. Either side may contain only one element.

Example

Array: 1 11 2 10 4 5 2 1 One bitonic subsequence: 1 2 10 5 2 1 Length = 6

DP Idea

  • inc[i]: LIS length ending at index i.
  • dec[i]: longest decreasing subsequence starting at index i.

Formula

bitonicLength[i] = inc[i] + dec[i] - 1 Answer = maximum bitonicLength[i]

Complete C11 Program

#include <stdio.h> #define MAX 100 int max(int a, int b) { return (a > b) ? a : b; } int main(void) { int arr[MAX], inc[MAX], dec[MAX]; int n, i, j, answer = 0; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX) return 1; printf("Enter array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1) return 1; } for (i = 0; i < n; i++) { inc[i] = 1; for (j = 0; j < i; j++) { if (arr[j] < arr[i]) inc[i] = max(inc[i], inc[j] + 1); } } for (i = n - 1; i >= 0; i--) { dec[i] = 1; for (j = n - 1; j > i; j--) { if (arr[j] < arr[i]) dec[i] = max(dec[i], dec[j] + 1); } } for (i = 0; i < n; i++) { answer = max( answer, inc[i] + dec[i] - 1 ); } printf("Longest bitonic subsequence length = %d\n", answer); return 0; }

Expected Output

Enter number of elements: 8 Enter array elements: 1 11 2 10 4 5 2 1 Longest bitonic subsequence length = 6

Complexity

  • Time: O(n²).
  • Space: O(n).

14. Common Interview Mistakes

  1. Assuming an increasing subsequence must be contiguous.
  2. Using less-than-or-equal instead of strictly less-than.
  3. Forgetting to initialize each DP state to one.
  4. Returning dp[n-1] instead of the maximum over all DP states.
  5. Confusing the tails array with the actual LIS.
  6. Using upper bound instead of lower bound for strictly increasing LIS.
  7. Not tracking parent indices when reconstruction is required.
  8. Ignoring empty arrays and duplicate values.

15. Interview Questions and Answers

Q1. What is LIS?

The longest subsequence in which every selected element is strictly greater than the previous selected element.

Q2. Does LIS require adjacent elements?

No. A subsequence preserves relative order but can skip elements.

Q3. What is the O(n²) DP state?

dp[i] represents the length of the LIS ending at index i.

Q4. Why is every dp[i] initialized to one?

Every individual array element forms an increasing subsequence of length one.

Q5. Why do we take the maximum over all dp values?

The LIS can end at any array index.

Q6. How is LIS optimized to O(n log n)?

Maintain minimum possible ending values for subsequences of different lengths and use binary search for updates.

Q7. Does the tails array store the actual LIS?

Not necessarily. It stores useful ending values. Parent tracking is required to reconstruct an actual LIS.

Q8. What is the difference between LIS and longest non-decreasing subsequence?

LIS requires strict increases. Non-decreasing subsequences permit equal consecutive selected values.

Q9. How is LIS used in the bitonic subsequence problem?

Compute an increasing subsequence ending at each position and a decreasing subsequence starting at each position.

Q10. What is the minimum number of removals to make an array strictly increasing?

For an array of length n, the answer is n minus the LIS length.

18. Lesson Summary

  • LIS finds the longest strictly increasing subsequence.
  • The O(n²) DP state stores the LIS ending at each index.
  • Memoization and tabulation both solve LIS in O(n²).
  • Binary search reduces the length calculation to O(n log n).
  • Parent tracking reconstructs an actual LIS.
  • Lower bound handles strictly increasing subsequences.
  • Upper bound handles non-decreasing subsequences.
