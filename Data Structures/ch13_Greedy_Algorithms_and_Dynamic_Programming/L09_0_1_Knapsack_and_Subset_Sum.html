2. What Is the 0/1 Knapsack Problem?

Given a collection of items, each having a weight and a value, select items so that:

  • The total weight does not exceed the capacity of the knapsack.
  • The total value is maximized.
  • Each item can be selected at most once.

Example

ItemWeightValue
1115
2320
3430
4535

Knapsack capacity = 7.

Select item 1 and item 4:

  • Total weight = 1 + 5 = 6.
  • Total value = 15 + 35 = 50.

The maximum achievable value is 50.

The term 0/1 means an item is either selected (1) or not selected (0). An item cannot be selected fractionally or repeatedly.

3. Recursive Approach

For every item, there are two possible choices:

  1. Include the item if its weight does not exceed the remaining capacity.
  2. Exclude the item.

Recursive State

knapsack(n, capacity) represents the maximum value obtainable using the first n items and the given capacity.

Base Cases

if (n == 0 || capacity == 0) return 0;

Recurrence

If weight[n - 1] > capacity: return knapsack(n - 1, capacity); Otherwise: include = value[n - 1] + knapsack(n - 1, capacity - weight[n - 1]); exclude = knapsack(n - 1, capacity); return max(include, exclude);

Complete C11 Program – Recursive Knapsack

#include <stdio.h> #define MAX_ITEMS 100 int max(int a, int b) { return (a > b) ? a : b; } int knapsack(int n, int capacity, const int weight[], const int value[]) { int include, exclude; if (n == 0 || capacity == 0) return 0; if (weight[n - 1] > capacity) return knapsack(n - 1, capacity, weight, value); include = value[n - 1] + knapsack(n - 1, capacity - weight[n - 1], weight, value); exclude = knapsack(n - 1, capacity, weight, value); return max(include, exclude); } int main(void) { int weight[MAX_ITEMS]; int value[MAX_ITEMS]; int n, capacity, i; printf("Enter number of items: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of items.\n"); return 1; } printf("Enter knapsack capacity: "); if (scanf("%d", &capacity) != 1 || capacity < 0) { printf("Invalid capacity.\n"); return 1; } printf("Enter weights:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &weight[i]) != 1 || weight[i] <= 0) { printf("Weights must be positive.\n"); return 1; } } printf("Enter values:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &value[i]) != 1 || value[i] < 0) { printf("Values must be nonnegative.\n"); return 1; } } printf("Maximum value = %d\n", knapsack(n, capacity, weight, value)); return 0; }

Expected Output

Enter number of items: 4 Enter knapsack capacity: 7 Enter weights: 1 3 4 5 Enter values: 15 20 30 35 Maximum value = 50

Complexity

  • Time: O(2ⁿ) in the worst case.
  • Auxiliary recursion space: O(n).

Repeated subproblems make the plain recursive approach inefficient for larger inputs.

4. Memoization – Top-Down DP

Memoization stores the result of each state so that the same state is not calculated repeatedly.

DP State

dp[n][capacity]

It stores the maximum value obtainable using the first n items with the specified capacity.

Approach

  1. Initialize all memoization entries to -1.
  2. Check whether the current state has already been calculated.
  3. If yes, return the stored result.
  4. Otherwise calculate include and exclude choices.
  5. Store the result and return it.

Complete C11 Program – Memoization

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_CAPACITY 1000 int dp[MAX_ITEMS + 1][MAX_CAPACITY + 1]; int max(int a, int b) { return (a > b) ? a : b; } int knapsackMemo(int n, int capacity, const int weight[], const int value[]) { int include, exclude; if (n == 0 || capacity == 0) return 0; if (dp[n][capacity] != -1) return dp[n][capacity]; if (weight[n - 1] > capacity) { dp[n][capacity] = knapsackMemo(n - 1, capacity, weight, value); } else { include = value[n - 1] + knapsackMemo(n - 1, capacity - weight[n - 1], weight, value); exclude = knapsackMemo(n - 1, capacity, weight, value); dp[n][capacity] = max(include, exclude); } return dp[n][capacity]; } int main(void) { int weight[MAX_ITEMS]; int value[MAX_ITEMS]; int n, capacity, i, j; printf("Enter number of items: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of items.\n"); return 1; } printf("Enter capacity: "); if (scanf("%d", &capacity) != 1 || capacity < 0 || capacity > MAX_CAPACITY) { printf("Invalid capacity.\n"); return 1; } printf("Enter weights:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &weight[i]) != 1 || weight[i] <= 0) { printf("Invalid weight.\n"); return 1; } } printf("Enter values:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &value[i]) != 1 || value[i] < 0) { printf("Invalid value.\n"); return 1; } } for (i = 0; i <= n; i++) { for (j = 0; j <= capacity; j++) dp[i][j] = -1; } printf("Maximum value = %d\n", knapsackMemo(n, capacity, weight, value)); return 0; }

Expected Output

Enter number of items: 4 Enter capacity: 7 Enter weights: 1 3 4 5 Enter values: 15 20 30 35 Maximum value = 50

Complexity

  • Time: O(n × W).
  • Memoization table: O(n × W).
  • Recursion stack: O(n).

W represents the knapsack capacity.

5. Tabulation – Bottom-Up DP

Tabulation builds the answer from smaller states instead of using recursion.

DP Definition

dp[i][w] represents the maximum value obtainable using the first i items with capacity w.

Transition

if (weight[i - 1] > w) { dp[i][w] = dp[i - 1][w]; } else { int include = value[i - 1] + dp[i - 1][w - weight[i - 1]]; int exclude = dp[i - 1][w]; dp[i][w] = max(include, exclude); }

Complete C11 Program – Tabulation

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_CAPACITY 1000 int max(int a, int b) { return (a > b) ? a : b; } int main(void) { int weight[MAX_ITEMS]; int value[MAX_ITEMS]; int dp[MAX_ITEMS + 1][MAX_CAPACITY + 1]; int n, capacity, i, w; printf("Enter number of items: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of items.\n"); return 1; } printf("Enter capacity: "); if (scanf("%d", &capacity) != 1 || capacity < 0 || capacity > MAX_CAPACITY) { printf("Invalid capacity.\n"); return 1; } printf("Enter weights:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &weight[i]) != 1 || weight[i] <= 0) { printf("Invalid weight.\n"); return 1; } } printf("Enter values:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &value[i]) != 1 || value[i] < 0) { printf("Invalid value.\n"); return 1; } } for (i = 0; i <= n; i++) dp[i][0] = 0; for (w = 0; w <= capacity; w++) dp[0][w] = 0; for (i = 1; i <= n; i++) { for (w = 0; w <= capacity; w++) { if (weight[i - 1] > w) { dp[i][w] = dp[i - 1][w]; } else { int include = value[i - 1] + dp[i - 1][w - weight[i - 1]]; int exclude = dp[i - 1][w]; dp[i][w] = max(include, exclude); } } } printf("Maximum value = %d\n", dp[n][capacity]); return 0; }

Expected Output

Enter number of items: 4 Enter capacity: 7 Enter weights: 1 3 4 5 Enter values: 15 20 30 35 Maximum value = 50

Complexity

  • Time: O(n × W).
  • Space: O(n × W).

7. Space Optimization – One-Dimensional Knapsack

The two-dimensional DP table can be reduced to one dimension because each row depends only on the previous row.

Important Transition

for each item i: for (w = capacity; w >= weight[i]; w--) { dp[w] = max(dp[w], value[i] + dp[w - weight[i]]); }
The capacity loop must run backwards for 0/1 Knapsack. A forward loop could reuse the same item multiple times and would change the problem into an unbounded Knapsack variant.

Complete C11 Program

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_CAPACITY 1000 int max(int a, int b) { return (a > b) ? a : b; } int main(void) { int weight[MAX_ITEMS]; int value[MAX_ITEMS]; int dp[MAX_CAPACITY + 1] = {0}; int n, capacity, i, w; printf("Enter number of items: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of items.\n"); return 1; } printf("Enter capacity: "); if (scanf("%d", &capacity) != 1 || capacity < 0 || capacity > MAX_CAPACITY) { printf("Invalid capacity.\n"); return 1; } printf("Enter weights:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &weight[i]) != 1 || weight[i] <= 0) { printf("Invalid weight.\n"); return 1; } } printf("Enter values:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &value[i]) != 1 || value[i] < 0) { printf("Invalid value.\n"); return 1; } } for (i = 0; i < n; i++) { for (w = capacity; w >= weight[i]; w--) { int include = value[i] + dp[w - weight[i]]; dp[w] = max(dp[w], include); } } printf("Maximum value = %d\n", dp[capacity]); return 0; }

Expected Output

Enter number of items: 4 Enter capacity: 7 Enter weights: 1 3 4 5 Enter values: 15 20 30 35 Maximum value = 50

Complexity

  • Time: O(n × W).
  • Auxiliary Space: O(W).

8. Subset Sum Problem

Problem: Given an array of nonnegative integers and a target sum, determine whether any subset has a sum equal to the target.

Example

Array = {3, 4, 5, 2} Target = 9 One valid subset: 4 + 5 = 9 Answer = YES

DP State

dp[i][s] is true if a subset of the first i elements can form sum s.

Base Cases

  • dp[i][0] = true: an empty subset makes sum zero.
  • dp[0][s] = false for s greater than zero.

Transition

if (arr[i - 1] > s) { dp[i][s] = dp[i - 1][s]; } else { dp[i][s] = dp[i - 1][s] || dp[i - 1][s - arr[i - 1]]; }

The two possibilities are excluding or including the current element.

9. Subset Sum – Complete C11 Program

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_SUM 1000 int main(void) { int arr[MAX_ITEMS]; int dp[MAX_ITEMS + 1][MAX_SUM + 1]; int n, target, i, s; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of elements.\n"); return 1; } printf("Enter target sum: "); if (scanf("%d", &target) != 1 || target < 0 || target > MAX_SUM) { printf("Invalid target.\n"); return 1; } printf("Enter nonnegative array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1 || arr[i] < 0) { printf("Invalid array element.\n"); return 1; } } for (i = 0; i <= n; i++) dp[i][0] = 1; for (s = 1; s <= target; s++) dp[0][s] = 0; for (i = 1; i <= n; i++) { for (s = 1; s <= target; s++) { if (arr[i - 1] > s) { dp[i][s] = dp[i - 1][s]; } else { dp[i][s] = dp[i - 1][s] || dp[i - 1][s - arr[i - 1]]; } } } if (dp[n][target]) printf("Subset with target sum exists.\n"); else printf("Subset with target sum does not exist.\n"); return 0; }

Expected Output

Enter number of elements: 4 Enter target sum: 9 Enter nonnegative array elements: 3 4 5 2 Subset with target sum exists.

Complexity

  • Time: O(n × target).
  • Space: O(n × target).

10. Subset Sum – Space Optimization

We can reduce the two-dimensional Boolean DP table to one dimension.

Transition

for each array element x: for (s = target; s >= x; s--) { dp[s] = dp[s] || dp[s - x]; }

The descending iteration ensures that the current element is not reused.

Complete C11 Program

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_SUM 1000 int main(void) { int arr[MAX_ITEMS]; int dp[MAX_SUM + 1] = {0}; int n, target, i, s; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of elements.\n"); return 1; } printf("Enter target sum: "); if (scanf("%d", &target) != 1 || target < 0 || target > MAX_SUM) { printf("Invalid target.\n"); return 1; } printf("Enter nonnegative array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1 || arr[i] < 0) { printf("Invalid array element.\n"); return 1; } } dp[0] = 1; for (i = 0; i < n; i++) { for (s = target; s >= arr[i]; s--) { dp[s] = dp[s] || dp[s - arr[i]]; } } if (dp[target]) printf("Subset with target sum exists.\n"); else printf("Subset with target sum does not exist.\n"); return 0; }

Expected Output

Enter number of elements: 4 Enter target sum: 9 Enter nonnegative array elements: 3 4 5 2 Subset with target sum exists.

Complexity

  • Time: O(n × target).
  • Auxiliary Space: O(target).

11. Equal Subset Partition

Problem: Determine whether an array can be divided into two subsets whose sums are equal.

Example

Array = {1, 5, 11, 5} Total sum = 22 Required subset sum = 22 / 2 = 11 Subset 1 = {11} Subset 2 = {1, 5, 5} Answer = YES

Approach

  1. Calculate the total sum.
  2. If the total sum is odd, equal partition is impossible.
  3. Otherwise, solve Subset Sum with target = total / 2.

Complete C11 Program

#include <stdio.h> #define MAX_ITEMS 100 #define MAX_SUM 1000 int main(void) { int arr[MAX_ITEMS]; int dp[MAX_SUM + 1] = {0}; int n, i, total = 0, target, s; printf("Enter number of elements: "); if (scanf("%d", &n) != 1 || n < 0 || n > MAX_ITEMS) { printf("Invalid number of elements.\n"); return 1; } printf("Enter nonnegative array elements:\n"); for (i = 0; i < n; i++) { if (scanf("%d", &arr[i]) != 1 || arr[i] < 0) { printf("Invalid array element.\n"); return 1; } if (arr[i] > MAX_SUM - total) { printf("Total sum exceeds supported limit.\n"); return 1; } total += arr[i]; } if (total % 2 != 0) { printf("Equal partition is not possible.\n"); return 0; } target = total / 2; dp[0] = 1; for (i = 0; i < n; i++) { for (s = target; s >= arr[i]; s--) { dp[s] = dp[s] || dp[s - arr[i]]; } } if (dp[target]) printf("Equal partition is possible.\n"); else printf("Equal partition is not possible.\n"); return 0; }

Expected Output

Enter number of elements: 4 Enter nonnegative array elements: 1 5 11 5 Equal partition is possible.

Complexity

  • Time: O(n × totalSum).
  • Space: O(totalSum).

12. Important 0/1 Knapsack Variations

ProblemCore Idea
0/1 KnapsackMaximize value under a weight limit.
Subset SumDetermine whether a target sum is possible.
Equal PartitionFind a subset equal to half the total sum.
Count Subsets With Given SumCount the number of subsets producing a target.
Minimum Subset Sum DifferenceMinimize the difference between two subset sums.
Target SumAssign plus and minus signs to reach a target.
Last Stone Weight IITransform into a partition problem.

Count Subsets With Given Sum – Recurrence

count[i][s] = count[i - 1][s] + count[i - 1][s - arr[i - 1]];

The second term is included only when the current element does not exceed s.

When zero-valued elements are present, subset counting requires careful initialization: each zero can be either included or excluded without changing the sum, so it can double the count. Do not apply the Boolean Subset Sum initialization blindly to counting problems.

13. 0/1 Knapsack vs Unbounded Knapsack

Feature0/1 KnapsackUnbounded Knapsack
Item reuseAt most onceUnlimited times
Capacity loopDescendingAscending
Previous statePrevious item rowCurrent row can be reused
Common applicationOne-time item selectionUnlimited supply of resources

Why Does Loop Direction Matter?

For 0/1 Knapsack, descending capacity ensures that the value used for the current item comes from a state before that item was processed.

For Unbounded Knapsack, ascending capacity allows the current item to contribute multiple times.

14. Complexity Comparison

ApproachTimeAuxiliary Space
Recursive KnapsackO(2ⁿ)O(n) stack

W is knapsack capacity and S is the target sum.

O(nW) and O(nS) are pseudo-polynomial complexities. They depend on numeric capacity or target values, not just on the number of input elements.

15. Common Interview Mistakes

  1. Confusing 0/1 Knapsack with Unbounded Knapsack.
  2. Using an ascending capacity loop for 0/1 Knapsack.
  3. Forgetting the empty-item or zero-capacity base cases.
  4. Using the current row instead of the previous row in 2D 0/1 Knapsack.
  5. Allowing negative weights in a solution that assumes nonnegative weights.
  6. Ignoring integer overflow in value sums or subset counts.
  7. Using a fixed DP array without validating capacity or target bounds.
  8. Forgetting that an empty subset produces sum zero.
  9. Handling zero-valued elements incorrectly in subset-counting problems.

16. Interview Questions and Answers

Q1. What is 0/1 Knapsack?

A DP optimization problem where each item can be selected at most once to maximize total value without exceeding capacity.

Q2. Why is it called 0/1?

Each item is either excluded (0) or included (1).

Q3. What is the DP state?

dp[i][w] represents the maximum value obtainable using the first i items with capacity w.

Q4. Why is the recursive solution exponential?

Each item can generate two branches: include or exclude. This creates up to 2ⁿ combinations.

Q5. What does memoization improve?

It stores results for repeated states, reducing the time complexity to O(nW).

Q6. Why does 1D 0/1 Knapsack iterate backwards?

To prevent an item from being reused in the same iteration.

Q7. What is Subset Sum?

A decision problem that determines whether a subset of the input elements can produce a specified target sum.

Q8. How is Equal Partition related to Subset Sum?

If the total sum is even, find a subset with sum equal to half the total.

Q9. Is O(nW) polynomial in the input size?

It is pseudo-polynomial because W is a numeric value that may require only logarithmically many bits to represent.

Q10. What is the difference between 0/1 and Unbounded Knapsack?

0/1 allows each item once; Unbounded allows an item to be selected repeatedly.

19. Lesson Summary

  • 0/1 Knapsack selects each item at most once.
  • Recursion explores include and exclude choices.
  • Memoization stores repeated states.
  • Tabulation builds solutions from smaller states.
  • One-dimensional 0/1 Knapsack uses descending capacity iteration.
  • Subset Sum determines whether a target can be formed.
  • Equal Partition reduces to Subset Sum with half the total sum.
  • Capacity-based DP is commonly pseudo-polynomial.
