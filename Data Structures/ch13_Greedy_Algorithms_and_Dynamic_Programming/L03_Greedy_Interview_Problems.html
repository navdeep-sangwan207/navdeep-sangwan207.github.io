2. Fractional Knapsack Problem

Given a collection of items, each having a weight and value, maximize the total value placed into a knapsack with a limited capacity.

Unlike 0/1 Knapsack, items can be divided into fractions.

Greedy Strategy

Calculate the value-to-weight ratio of every item. Select items in descending order of this ratio.

Formula:

Ratio = Value / Weight

Example

ItemWeightValueRatio
A10606
B201005
C301204

Knapsack capacity = 50.

Selection:

Take all of A: weight 10, value 60
Take all of B: weight 20, value 100
Take 20/30 of C: value 80

Total weight = 50
Maximum value = 240

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define N 3

typedef struct
{
    double weight;
    double value;
    double ratio;
} Item;

int compareItems(const void *a, const void *b)
{
    const Item *x = a;
    const Item *y = b;

    if (x->ratio < y->ratio)
        return 1;

    if (x->ratio > y->ratio)
        return -1;

    return 0;
}

int main(void)
{
    Item items[N] =
    {
        {10.0, 60.0, 0.0},
        {20.0, 100.0, 0.0},
        {30.0, 120.0, 0.0}
    };

    double capacity = 50.0;
    double totalValue = 0.0;

    for (int i = 0; i < N; i++)
    {
        if (items[i].weight <= 0.0 ||
            items[i].value < 0.0)
        {
            printf("Invalid item data.\n");
            return 1;
        }

        items[i].ratio =
            items[i].value / items[i].weight;
    }

    qsort(items, N, sizeof(Item), compareItems);

    for (int i = 0; i < N && capacity > 0.0; i++)
    {
        if (items[i].weight <= capacity)
        {
            capacity -= items[i].weight;
            totalValue += items[i].value;
        }
        else
        {
            double fraction = capacity / items[i].weight;

            totalValue += items[i].value * fraction;
            capacity = 0.0;
        }
    }

    printf("Maximum value = %.2f\n", totalValue);

    return 0;
}
Maximum value = 240.00

Time Complexity: O(N log N).

Space Complexity: O(N) for storing items, excluding sorting implementation details.

This greedy strategy is optimal for Fractional Knapsack. It is not generally optimal for 0/1 Knapsack because indivisible items cannot be partially selected.

3. Job Sequencing with Deadlines

Each job has a deadline and a profit. Every job takes one unit of time. A job earns its profit only if it is completed no later than its deadline.

Objective

Maximize total profit by scheduling jobs.

Greedy Strategy

  1. Sort jobs by profit in descending order.
  2. For each job, find the latest available time slot on or before its deadline.
  3. If a slot is available, schedule the job.
  4. Otherwise, skip it.

Example

JobDeadlineProfit
J12100
J2119
J3227
J4125
J5315

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define N 5
#define MAX_SLOTS 100

typedef struct
{
    int id;
    int deadline;
    int profit;
} Job;

int compareJobs(const void *a, const void *b)
{
    const Job *x = a;
    const Job *y = b;

    if (x->profit != y->profit)
    {
        return (x->profit < y->profit) -
               (x->profit > y->profit);
    }

    return (x->id > y->id) -
           (x->id < y->id);
}

int main(void)
{
    Job jobs[N] =
    {
        {1, 2, 100},
        {2, 1, 19},
        {3, 2, 27},
        {4, 1, 25},
        {5, 3, 15}
    };

    int slots[MAX_SLOTS] = {0};
    int maxDeadline = 0;
    int totalProfit = 0;
    int jobCount = 0;

    for (int i = 0; i < N; i++)
    {
        if (jobs[i].deadline <= 0 || jobs[i].profit < 0)
        {
            printf("Invalid job data.\n");
            return 1;
        }

        if (jobs[i].deadline > maxDeadline)
            maxDeadline = jobs[i].deadline;
    }

    if (maxDeadline > MAX_SLOTS)
    {
        printf("Deadline exceeds supported limit.\n");
        return 1;
    }

    qsort(jobs, N, sizeof(Job), compareJobs);

    for (int i = 0; i < N; i++)
    {
        int lastSlot = jobs[i].deadline;

        if (lastSlot > maxDeadline)
            lastSlot = maxDeadline;

        for (int slot = lastSlot; slot >= 1; slot--)
        {
            if (slots[slot] == 0)
            {
                slots[slot] = jobs[i].id;
                totalProfit += jobs[i].profit;
                jobCount++;
                break;
            }
        }
    }

    printf("Scheduled jobs:\n");

    for (int i = 1; i <= maxDeadline; i++)
    {
        if (slots[i] != 0)
            printf("Time slot %d: Job J%d\n", i, slots[i]);
    }

    printf("Total jobs = %d\n", jobCount);
    printf("Maximum profit = %d\n", totalProfit);

    return 0;
}
Scheduled jobs:
Time slot 1: Job J3
Time slot 2: Job J1
Time slot 3: Job J5
Total jobs = 3
Maximum profit = 142

Time Complexity: O(N log N + N × D), where D is the maximum deadline. In the worst case D can be O(N) when deadlines are bounded by N, giving O(N²) after sorting.

Space Complexity: O(D) for the slot array.

A disjoint-set data structure can optimize the search for the latest available slot. This is a useful follow-up interview question.

4. Minimum Railway Platforms

Given train arrival and departure times, find the minimum number of platforms required so that no train has to wait for a platform.

Greedy Strategy

  1. Sort arrival times.
  2. Sort departure times.
  3. Track the next arrival and next departure.
  4. If the next arrival occurs before the earliest departure, allocate another platform.
  5. Otherwise, release a platform.
  6. Track the maximum platforms occupied simultaneously.
This example uses the convention that a platform is reusable when one train departs at the same time another arrives. If the problem specifies a different convention, adjust the equality comparison.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define N 6

int compareInt(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

int main(void)
{
    int arrival[N] = {900, 940, 950, 1100, 1500, 1800};
    int departure[N] = {910, 1200, 1120, 1130, 1900, 2000};

    qsort(arrival, N, sizeof(int), compareInt);
    qsort(departure, N, sizeof(int), compareInt);

    int i = 0;
    int j = 0;
    int platforms = 0;
    int maximum = 0;

    while (i < N)
    {
        if (arrival[i] < departure[j])
        {
            platforms++;
            if (platforms > maximum)
                maximum = platforms;

            i++;
        }
        else
        {
            platforms--;
            j++;
        }
    }

    printf("Minimum platforms required = %d\n", maximum);

    return 0;
}
Minimum platforms required = 3

Time Complexity: O(N log N).

Space Complexity: O(1) auxiliary space excluding sorting implementation details; the arrays occupy O(N).

5. Jump Game

Given an array where each element represents the maximum jump length from that position, determine whether the last index can be reached from the first index.

Example

Array = [2, 3, 1, 1, 4]

Output = Reachable

Greedy Strategy

Maintain the farthest index that can be reached. If the current index is beyond that boundary, the destination is unreachable.

Complete C11 Program

#include <stdio.h>

int canJump(const int arr[], int n)
{
    if (n <= 0)
        return 0;

    int farthest = 0;

    for (int i = 0; i < n; i++)
    {
        if (i > farthest)
            return 0;

        long long reach = (long long)i + arr[i];

        if (reach >= n - 1)
            return 1;

        if (reach > farthest)
            farthest = (int)reach;
    }

    return 1;
}

int main(void)
{
    int arr[] = {2, 3, 1, 1, 4};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    if (canJump(arr, n))
        printf("Last index is reachable.\n");
    else
        printf("Last index is not reachable.\n");

    return 0;
}
Last index is reachable.

Time Complexity: O(N).

Space Complexity: O(1).

This implementation assumes all jump lengths are nonnegative. For a nonempty array, a single-element array is already reachable.

6. Gas Station Problem

There are N gas stations arranged in a circular route. At station i, a vehicle receives gas[i] units of fuel. Travelling to the next station requires cost[i] units.

Find a starting station from which the vehicle can complete the entire circuit, or report that no solution exists.

Greedy Strategy

  • If total gas is less than total cost, no solution exists.
  • Maintain the current fuel balance.
  • If the balance becomes negative, the current candidate start cannot work.
  • Start again from the next station.

Complete C11 Program

#include <stdio.h>

int findStart(const int gas[], const int cost[], int n)
{
    long long total = 0;
    long long current = 0;
    int start = 0;

    if (n <= 0)
        return -1;

    for (int i = 0; i < n; i++)
    {
        if (gas[i] < 0 || cost[i] < 0)
            return -1;

        long long difference =
            (long long)gas[i] - cost[i];

        total += difference;
        current += difference;

        if (current < 0)
        {
            start = i + 1;
            current = 0;
        }
    }

    if (total < 0 || start == n)
        return -1;

    return start;
}

int main(void)
{
    int gas[] = {1, 2, 3, 4, 5};
    int cost[] = {3, 4, 5, 1, 2};

    int n = (int)(sizeof(gas) / sizeof(gas[0]));

    int result = findStart(gas, cost, n);

    if (result == -1)
        printf("No valid starting station.\n");
    else
        printf("Valid starting station = %d\n", result);

    return 0;
}
Valid starting station = 3

Time Complexity: O(N).

Space Complexity: O(1).

Station numbering in this program is zero-based. If a solution exists, the standard gas-station problem guarantees a unique starting index when the total gas and cost are interpreted under the usual constraints.

7. Non-overlapping Intervals

Given a collection of intervals, remove the minimum number of intervals so that the remaining intervals do not overlap.

Greedy Strategy

Sort intervals by finishing time. Keep the earliest finishing compatible interval and remove intervals that overlap with the last kept interval.

Example

Intervals:
[1,2), [2,3), [3,4), [1,3)

Remove [1,3)

Remaining:
[1,2), [2,3), [3,4)

Minimum removals = 1

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

#define N 4

typedef struct
{
    int start;
    int finish;
} Interval;

int compareIntervals(const void *a, const void *b)
{
    const Interval *x = a;
    const Interval *y = b;

    if (x->finish != y->finish)
    {
        return (x->finish > y->finish) -
               (x->finish < y->finish);
    }

    return (x->start > y->start) -
           (x->start < y->start);
}

int main(void)
{
    Interval intervals[N] =
    {
        {1, 2},
        {2, 3},
        {3, 4},
        {1, 3}
    };

    for (int i = 0; i < N; i++)
    {
        if (intervals[i].start >= intervals[i].finish)
        {
            printf("Invalid interval.\n");
            return 1;
        }
    }

    qsort(intervals, N, sizeof(Interval), compareIntervals);

    int kept = 0;
    int lastFinish = 0;

    for (int i = 0; i < N; i++)
    {
        if (kept == 0 ||
            intervals[i].start >= lastFinish)
        {
            kept++;
            lastFinish = intervals[i].finish;
        }
    }

    printf("Maximum non-overlapping intervals = %d\n", kept);
    printf("Minimum intervals to remove = %d\n", N - kept);

    return 0;
}
Maximum non-overlapping intervals = 3
Minimum intervals to remove = 1

Time Complexity: O(N log N).

Space Complexity: O(N) for storing intervals, excluding sorting implementation details.

9. Problems Where Greedy Needs Care

ProblemImportant Observation
0/1 Knapsack Choosing the highest value/weight ratio is not generally optimal. Use DP for the standard problem.
Coin Change Largest denomination first can fail for arbitrary denominations.
Weighted Interval Scheduling Earliest finish time alone does not maximize profit. Use DP.
Jump Game II A greedy layer/boundary strategy can find the minimum jumps; it is different from merely checking reachability.

10. Common Interview Mistakes

  1. Using greedy without proving that the choice is safe.
  2. Confusing Fractional Knapsack with 0/1 Knapsack.
  3. Forgetting to handle equal deadlines or finish times.
  4. Incorrectly handling simultaneous arrivals and departures.
  5. Ignoring negative or invalid input values.
  6. Using int for sums that may exceed its range.
  7. Forgetting zero-based versus one-based indexing.
  8. Not checking whether an interval is empty or invalid.

11. Placement Interview Questions

Q1. What is the difference between Fractional and 0/1 Knapsack?

Fractional Knapsack allows taking part of an item and is solved optimally by sorting value-to-weight ratios. 0/1 Knapsack requires taking an entire item or rejecting it; its standard optimal solution uses DP.

Q2. Why do we select the latest possible slot in Job Sequencing?

It preserves earlier slots for jobs with tighter deadlines.

Q3. What is the complexity of the standard Job Sequencing algorithm?

O(N log N + ND), where D is the maximum deadline. With D bounded by N, this is O(N²).

Q4. How is Minimum Platforms related to Meeting Rooms?

Both count the maximum number of overlapping intervals.

Q5. What does the farthest variable represent in Jump Game?

It stores the maximum index reachable from all positions processed so far.

Q6. Why does Gas Station reset the starting candidate?

If the fuel balance becomes negative at a station, none of the candidate starting stations since the previous reset can complete the segment.

Q7. What is the objective of Non-overlapping Intervals?

Remove the minimum number of intervals so that no remaining intervals overlap.

Q8. Does a greedy algorithm always produce an optimal answer?

No. Its selection rule must be proved correct for the particular problem.

14. Lesson Summary

  • Fractional Knapsack uses the highest value-to-weight ratio.
  • Job Sequencing sorts by profit and schedules each job in the latest available slot.
  • Minimum Platforms counts maximum simultaneous occupancy.
  • Jump Game maintains the farthest reachable index.
  • Gas Station uses total fuel balance and resets invalid candidates.
  • Non-overlapping Intervals uses earliest finishing time.
  • Greedy correctness must be established for each problem.
