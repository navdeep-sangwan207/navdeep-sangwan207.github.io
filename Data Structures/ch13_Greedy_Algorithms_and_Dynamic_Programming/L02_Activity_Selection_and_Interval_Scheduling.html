2. What Is the Activity Selection Problem?

Given a collection of activities, each having a start time and finish time, select the maximum number of mutually compatible activities.

Two activities are compatible if their time intervals do not overlap.

Placement objective: Maximize the number of activities that can be performed using a single resource, such as one classroom, one machine or one meeting room.

Example

Total selected activities = 4

3. Greedy Strategy: Earliest Finish Time

The standard greedy strategy is to select the activity that finishes earliest among the remaining compatible activities.

Algorithm

  1. Sort activities by finish time in ascending order.
  2. Select the first activity.
  3. Record its finish time.
  4. Examine the remaining activities in sorted order.
  5. Select an activity if its start time is greater than or equal to the last selected finish time.
  6. Update the last selected finish time.
  7. Continue until all activities have been examined.

Pseudocode

ACTIVITY_SELECTION(activities):

    sort activities by finish time

    selected = 0
    lastFinish = -infinity

    for each activity:
        if activity.start >= lastFinish:
            select activity
            lastFinish = activity.finish
            selected++

    return selected

5. Complete C11 Program – Activity Selection

This program accepts activities, sorts them by finish time and selects the maximum number of compatible activities. 

#include <stdio.h>
#include <stdlib.h>

#define MAX 100

typedef struct
{
    int start;
    int finish;
    int id;
} Activity;

int compareActivities(const void *a, const void *b)
{
    const Activity *x = a;
    const Activity *y = b;

    if (x->finish != y->finish)
    {
        return (x->finish > y->finish) -
               (x->finish < y->finish);
    }

    if (x->start != y->start)
    {
        return (x->start > y->start) -
               (x->start < y->start);
    }

    return (x->id > y->id) -
           (x->id < y->id);
}

int main(void)
{
    Activity activities[MAX];
    int n;

    printf("Enter number of activities: ");

    if (scanf("%d", &n) != 1 || n < 0 || n > MAX)
    {
        printf("Invalid number of activities.\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("Enter start and finish time for activity %d: ",
               i + 1);

        if (scanf("%d %d",
                  &activities[i].start,
                  &activities[i].finish) != 2)
        {
            printf("Invalid input.\n");
            return 1;
        }

        if (activities[i].start > activities[i].finish)
        {
            printf("Invalid interval.\n");
            return 1;
        }

        activities[i].id = i + 1;
    }

    qsort(activities, (size_t)n,
          sizeof(Activity), compareActivities);

    int selected = 0;
    int lastFinish = 0;

    printf("\nSelected activities:\n");

    for (int i = 0; i < n; i++)
    {
        if (selected == 0 ||
            activities[i].start >= lastFinish)
        {
            printf("Activity %d: [%d, %d)\n",
                   activities[i].id,
                   activities[i].start,
                   activities[i].finish);

            lastFinish = activities[i].finish;
            selected++;
        }
    }

    printf("\nMaximum compatible activities = %d\n",
           selected);

    return 0;
}

Sample Input

2 5
4 6
6 8
5 9

Activity 3: [4, 6)
Activity 4: [6, 8)
Activity 6: [8, 10)

Time Complexity: O(N log N) for sorting plus O(N) selection, therefore O(N log N).

Auxiliary Space: O(1) for the selection logic, excluding qsort implementation-specific stack space. The activity array uses O(N) storage.

6. Interval Scheduling

Interval scheduling is a broader class of problems where tasks or jobs occupy intervals of time.

An interval is generally represented as: 

[start, finish)

This convention includes the start time but excludes the finish time. Therefore, one interval ending at time 5 can be followed by another beginning at time 5.

Common Interval Problems

  • Maximum number of non-overlapping intervals.
  • Minimum number of rooms required for all meetings.
  • Merge overlapping intervals.
  • Check whether two intervals overlap.
  • Find the maximum number of simultaneous meetings.
  • Weighted interval scheduling.

7. Unweighted vs Weighted Interval Scheduling

Unweighted Interval Scheduling

Every activity has equal value. The objective is to select the maximum number of compatible activities.

The earliest-finish-time greedy algorithm solves this problem optimally.

Weighted Interval Scheduling

Each activity has a profit or weight. The objective is to maximize total profit rather than the number of selected activities.

Activity Interval Profit
A[1,3)5
B[3,5)5
C[1,5)15

Selecting A and B gives total profit 10. Selecting C gives total profit 15.

The earliest-finish-time rule is not sufficient for weighted interval scheduling. This problem is commonly solved using Dynamic Programming.

Weighted Interval Scheduling Recurrence

Sort jobs by finish time. Let p(i) be the index of the last job finishing no later than the start of job i.

The recurrence is:

DP[i] = max(
    DP[i - 1],
    profit[i] + DP[p(i)]
)

The two choices are:

  • Skip the current job.
  • Take the current job and combine its profit with the best compatible earlier solution.

8. Meeting Rooms Problem

Given meeting intervals, determine the minimum number of rooms required so that no overlapping meetings share a room.

Example

MeetingStartFinish
M1030
M2510
M31520

M1 overlaps with M2 and M3. M2 and M3 do not overlap.

Minimum rooms required = 2.

Greedy Approach

  1. Sort meeting start times.
  2. Sort meeting finish times separately.
  3. Track the next meeting start and the earliest occupied room finish.
  4. If the next meeting starts before the earliest finish, allocate another room.
  5. Otherwise, reuse a room.
  6. Track the maximum number of rooms used.

Complete C11 Program – Minimum Meeting Rooms

#include <stdio.h>
#include <stdlib.h>

#define MAX 100

int compareInt(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}

int main(void)
{
    int start[MAX], finish[MAX];
    int n;

    printf("Enter number of meetings: ");

    if (scanf("%d", &n) != 1 || n < 0 || n > MAX)
    {
        printf("Invalid number of meetings.\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("Enter start and finish of meeting %d: ",
               i + 1);

        if (scanf("%d %d", &start[i], &finish[i]) != 2)
        {
            printf("Invalid input.\n");
            return 1;
        }

        if (start[i] >= finish[i])
        {
            printf("Invalid meeting interval.\n");
            return 1;
        }
    }

    if (n == 0)
    {
        printf("Minimum rooms required = 0\n");
        return 0;
    }

    qsort(start, (size_t)n, sizeof(int), compareInt);
    qsort(finish, (size_t)n, sizeof(int), compareInt);

    int i = 0;
    int j = 0;
    int currentRooms = 0;
    int maximumRooms = 0;

    while (i < n)
    {
        if (start[i] < finish[j])
        {
            currentRooms++;

            if (currentRooms > maximumRooms)
            {
                maximumRooms = currentRooms;
            }

            i++;
        }
        else
        {
            currentRooms--;
            j++;
        }
    }

    printf("Minimum rooms required = %d\n",
           maximumRooms);

    return 0;
}

Sample Input

3
0 30
5 10
15 20

Expected Output

Minimum rooms required = 2

Time Complexity: O(N log N).

Space Complexity: O(N) for the two input arrays; the sorting implementation may use additional implementation-specific space.

The meeting-room program uses half-open intervals [start, finish). When a meeting starts exactly when another finishes, the previous room can be reused.

9. Interval Overlap Conditions

For two half-open intervals [s1, f1) and [s2, f2), they overlap when: 

s1 < f2 AND s2 < f1

They do not overlap when:

f1 <= s2 OR f2 <= s1

Example

Interval 1Interval 2Overlap?
[1,5)[3,7)Yes
[1,5)[5,8)No
[2,4)[6,9)No

10. Greedy vs Dynamic Programming for Scheduling

ProblemTypical Technique
Maximum number of compatible activities Greedy: earliest finish time
Maximum total profit from compatible jobs Dynamic Programming
Minimum meeting rooms Greedy with sorted events or min heap
Merge overlapping intervals Sorting and greedy scan
Maximum simultaneous intervals Line sweep / event sorting

11. Common Mistakes

  1. Sorting activities by start time instead of finish time for the classic activity-selection problem.
  2. Forgetting to update the finish time after selecting an activity.
  3. Using greater-than instead of greater-than-or-equal when touching intervals are compatible.
  4. Applying unweighted activity selection to weighted scheduling.
  5. Failing to handle empty input.
  6. Using an integer comparator based on subtraction.
  7. Confusing maximum compatible activities with minimum meeting rooms.
  8. Ignoring the interval convention used by the problem.

12. Placement Interview Questions

Q1. What is the greedy strategy for Activity Selection?

Select the compatible activity with the earliest finishing time.

Q2. Why do we sort by finishing time?

It leaves as much time as possible for the remaining activities.

Q3. What is the complexity of Activity Selection?

O(N log N), including sorting. The selection scan is O(N).

Q4. Can we sort by starting time?

Not for the standard earliest-finish-time greedy solution. Sorting by starting time does not guarantee the maximum number of compatible activities.

Q5. What is weighted interval scheduling?

It selects compatible intervals to maximize total profit or weight rather than the number of intervals.

Q6. Why is weighted interval scheduling commonly solved using DP?

The locally earliest-finishing interval may have a low profit, while a different combination may produce a higher total profit.

Q7. What is the minimum meeting rooms problem?

It finds the minimum number of rooms needed to accommodate all meetings without overlapping meetings sharing a room.

Q8. How can interval overlap be checked?

For half-open intervals, they overlap if s1 < f2 and s2 < f1.

15. Lesson Summary

  • Activity Selection maximizes the number of compatible activities.
  • Earliest finishing time is the standard greedy selection rule.
  • Sorting takes O(N log N), followed by an O(N) scan.
  • Interval scheduling includes several scheduling and overlap problems.
  • Weighted interval scheduling generally requires Dynamic Programming.
  • Minimum Meeting Rooms can be solved using sorted start and finish times.
  • Always check interval boundary conventions.
