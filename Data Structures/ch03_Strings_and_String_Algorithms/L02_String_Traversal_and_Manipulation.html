2. String Traversal

String traversal means visiting each character of a string sequentially, starting from index zero and stopping at the null terminator. 

#include <stdio.h>

int main(void)
{
    char str[] = "HELLO";

    for (int i = 0; str[i] != '\0'; i++)
    {
        printf("%c ", str[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
H E L L O

Time Complexity: O(n)

Auxiliary Space: O(1)

3. Traversing a String Using Pointers

A character pointer can access each character by moving through consecutive memory locations. 

#include <stdio.h>

int main(void)
{
    char str[] = "POINTER";
    char *ptr = str;

    while (*ptr != '\0')
    {
        printf("%c ", *ptr);
        ptr++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
P O I N T E R
Interview point: str[i] is equivalent to *(str + i). Both expressions access the character at index i.

4. Modifying Characters in a String

Characters in a modifiable character array can be changed individually. 

#include <stdio.h>

int main(void)
{
    char str[] = "hello";

    str[0] = 'H';
    str[1] = 'E';

    printf("%s\n", str);

    return 0;
}
Expected Output: 
HEllo
Do not modify a string literal through a pointer. Use a character array when the string contents need to be changed.

5. Find String Length Without strlen()

Traverse the string until '\0' is found. Count each character before the terminator. 

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";
    int length = 0;

    while (str[length] != '\0')
    {
        length++;
    }

    printf("Length = %d\n", length);

    return 0;
}
Expected Output: 
Length = 11

Time Complexity: O(n)

Auxiliary Space: O(1)

6. Copy a String Without strcpy()

String copying means transferring all characters from a source string into a destination array, including the null terminator. 

#include <stdio.h>

int main(void)
{
    char source[] = "Embedded";
    char destination[30];

    int i = 0;

    while (source[i] != '\0')
    {
        destination[i] = source[i];
        i++;
    }

    destination[i] = '\0';

    printf("Source: %s\n", source);
    printf("Destination: %s\n", destination);

    return 0;
}
Expected Output: 
Source: Embedded
Destination: Embedded

Time Complexity: O(n)

Auxiliary Space: O(n) for the destination array.

The destination must have enough capacity for every source character and the terminating '\0'.

7. Compare Two Strings Without strcmp()

Compare corresponding characters one by one. If they differ, the strings are not equal. If both reach '\0' together, the strings are equal. 

#include <stdio.h>

int main(void)
{
    char str1[] = "HELLO";
    char str2[] = "HELLO";

    int i = 0;

    while (str1[i] != '\0' &&
           str2[i] != '\0' &&
           str1[i] == str2[i])
    {
        i++;
    }

    if (str1[i] == '\0' && str2[i] == '\0')
        printf("Strings are equal\n");
    else
        printf("Strings are not equal\n");

    return 0;
}
Expected Output: 
Strings are equal

Time Complexity: O(n) worst case.

Auxiliary Space: O(1)

strcmp() returns zero for equal strings, a negative value when the first differing character in the first string compares lower, and a positive value when it compares higher. Do not assume the result is exactly -1 or 1.

8. Concatenate Two Strings Without strcat()

Concatenation means appending the second string to the end of the first string. 

#include <stdio.h>

int main(void)
{
    char str1[30] = "Data";
    char str2[] = "Structures";

    int i = 0;
    int j = 0;

    while (str1[i] != '\0')
    {
        i++;
    }

    while (str2[j] != '\0')
    {
        str1[i] = str2[j];
        i++;
        j++;
    }

    str1[i] = '\0';

    printf("Combined string: %s\n", str1);

    return 0;
}
Expected Output: 
Combined string: DataStructures

Time Complexity: O(n + m)

Auxiliary Space: O(1), excluding the destination buffer.

The destination array must have enough room for both strings and one null terminator. Here, the destination capacity is 30 bytes and the combined string requires 15 char elements including '\0'.

9. Convert Lowercase to Uppercase

The standard C library function toupper() converts a lowercase letter to uppercase when a corresponding uppercase form exists. 

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char str[] = "embedded systems";

    for (int i = 0; str[i] != '\0'; i++)
    {
        str[i] = (char)toupper((unsigned char)str[i]);
    }

    printf("%s\n", str);

    return 0;
}
Expected Output: 
EMBEDDED SYSTEMS

Time Complexity: O(n)

Auxiliary Space: O(1)

Passing an unsigned char value (converted to int) to toupper() avoids undefined behavior for negative signed char values other than EOF.

10. Count Vowels and Consonants

This program counts English vowels and alphabetic consonants. Other characters, including spaces and digits, are ignored. 

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char str[] = "Embedded Systems";
    int vowels = 0;
    int consonants = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        char ch = (char)tolower((unsigned char)str[i]);

        if (ch >= 'a' && ch <= 'z')
        {
            if (ch == 'a' || ch == 'e' ||
                ch == 'i' || ch == 'o' ||
                ch == 'u')
            {
                vowels++;
            }
            else
            {
                consonants++;
            }
        }
    }

    printf("Vowels = %d\n", vowels);
    printf("Consonants = %d\n", consonants);

    return 0;
}
Expected Output: 
Vowels = 5
Consonants = 10

Time Complexity: O(n)

Auxiliary Space: O(1)

11. Reverse a String Using Two Pointers

Two pointers can be placed at the beginning and end of a string. Swap their characters and move them toward the center. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PLACEMENT";

    int left = 0;
    int right = (int)strlen(str) - 1;

    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }

    printf("Reversed: %s\n", str);

    return 0;
}
Expected Output: 
Reversed: TNEMECALP

Time Complexity: O(n)

Auxiliary Space: O(1)

This program modifies the character array in place. It does not attempt to reverse a string literal.

12. Remove Spaces from a String

Use separate read and write indices. The read index scans every character, while the write index stores only characters that are not spaces. 

#include <stdio.h>

int main(void)
{
    char str[] = "Data Structures Using C";

    int read = 0;
    int write = 0;

    while (str[read] != '\0')
    {
        if (str[read] != ' ')
        {
            str[write] = str[read];
            write++;
        }

        read++;
    }

    str[write] = '\0';

    printf("%s\n", str);

    return 0;
}
Expected Output: 
DataStructuresUsingC

Time Complexity: O(n)

Auxiliary Space: O(1)

13. Safe String Manipulation with Capacity Checks

A string operation must not write beyond the destination array. The following function appends a source string only when sufficient destination capacity is available. 

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool append_string(char *destination,
                   size_t capacity,
                   const char *source)
{
    size_t dest_len = strlen(destination);
    size_t src_len = strlen(source);

    if (dest_len >= capacity)
        return false;

    if (src_len > capacity - dest_len - 1)
        return false;

    for (size_t i = 0; i <= src_len; i++)
    {
        destination[dest_len + i] = source[i];
    }

    return true;
}

int main(void)
{
    char text[20] = "Hello";

    if (append_string(text, sizeof(text), " World"))
        printf("%s\n", text);
    else
        printf("Insufficient capacity\n");

    return 0;
}
Expected Output: 
Hello World

Time Complexity: O(n + m)

Auxiliary Space: O(1)

This function assumes destination is already a valid null-terminated string within its declared capacity. It also assumes source and destination do not overlap. A pointer and capacity must be supplied consistently; C cannot discover the actual allocation size from a pointer.

17. Placement Interview Questions and Answers

Q1. What is string traversal?

Visiting each character in a string sequentially until the null terminator is reached.

Q2. How can you traverse a string without using an index?

Use a character pointer and increment it until *ptr becomes '\0'.

Q3. What is the difference between str[i] and *(str + i)?

Both access the character at index i using array indexing and pointer arithmetic respectively.

Q4. How do you calculate string length without strlen()?

Increment a counter until the null terminator is reached.

Q5. Why must string copying include '\0'?

The destination must be a valid null-terminated string after copying.

Q6. How do you compare two strings manually?

Compare corresponding characters until a mismatch or the end of both strings.

Q7. What does strcmp() return for equal strings?

Zero.

Q8. Why is destination capacity important in concatenation?

The combined characters and null terminator must fit in the destination array.

Q9. How can you reverse a string in place?

Use two pointers or indices at the beginning and end, swapping characters until they meet.

Q10. What is an in-place operation?

An operation that modifies the existing data without requiring another input-sized data structure.

Q11. What is the complexity of string traversal?

O(n), where n is the number of characters.

Q12. Can strcat() cause buffer overflow?

Yes. It does not check whether the destination has enough capacity.

Q13. What is the purpose of toupper()?

It converts a lowercase character to its uppercase form when a mapping exists.

Q14. What is the two-pointer technique in strings?

It uses two indices or pointers to process characters from different positions, often from opposite ends.

Q15. Why is a separate destination array required in a basic copy operation?

It provides storage for the copied string. The destination must have enough capacity and must not overlap the source for the simple implementation shown.

Q16. What is the difference between copying and concatenation?

Copying replaces the destination contents with the source. Concatenation appends source characters after the existing destination string.

Q17. How can you remove spaces from a string in place?

Use read and write indices. Copy only non-space characters toward the beginning, then terminate the result.

Q18. Why should ctype.h functions receive unsigned char values?

Passing a negative signed char value other than EOF to functions such as toupper() or tolower() causes undefined behavior.

Q19. Does strlen() include the null terminator?

No. It counts only characters before the first null terminator.

Q20. What is the most important rule in C string manipulation?

Maintain valid null termination and never access or write beyond the allocated array capacity.
