2. What Is String Reversal?

String reversal means changing the order of characters so that the last character becomes the first and the first character becomes the last.

Original StringReversed String
HELLOOLLEH
PLACEMENTTNEMECALP
LEVELLEVEL

3. Reverse a String Using Two Pointers

The two-pointer approach uses two indices:

  • left starts at index 0.
  • right starts at the last character.
  • Swap the characters at both indices.
  • Move left forward and right backward.
  • Stop when left is no longer smaller than right.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";

    int left = 0;
    int right = (int)strlen(str) - 1;

    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }

    printf("Reversed string: %s\n", str);

    return 0;
}
Expected Output: 
Reversed string: OLLEH

Time Complexity: O(n)

Auxiliary Space: O(1)

Interview point: This is an in-place reversal algorithm because it modifies the original character array without allocating another array.

4. Reverse a String Without strlen()

The string length can be found manually by traversing until '\0'. Then use two pointers to reverse the string. 

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAM";

    int length = 0;

    while (str[length] != '\0')
    {
        length++;
    }

    int left = 0;
    int right = length - 1;

    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }

    printf("%s\n", str);

    return 0;
}
Expected Output: 
MARGORP

Time Complexity: O(n)

Auxiliary Space: O(1)

5. Reverse a String Using a Separate Array

In this method, copy the source characters into a destination array in reverse order. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "COMPUTER";
    char reversed[sizeof(source)];

    int length = (int)strlen(source);

    for (int i = 0; i < length; i++)
    {
        reversed[i] = source[length - 1 - i];
    }

    reversed[length] = '\0';

    printf("Original: %s\n", source);
    printf("Reversed: %s\n", reversed);

    return 0;
}
Expected Output: 
Original: COMPUTER
Reversed: RETUPMOC

Time Complexity: O(n)

Auxiliary Space: O(n)

6. What Is a Palindrome String?

A palindrome is a string that reads the same from left to right and right to left.

StringPalindrome?
MADAMYes
LEVELYes
RADARYes
HELLONo
ABBAYes
ABCNo
A palindrome can have an even or odd number of characters. In an odd-length palindrome, the middle character does not need to be compared with another character.

7. Check Palindrome Using Two Pointers

Compare the first and last characters. If they are equal, move toward the center. If any pair differs, the string is not a palindrome. 

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

int main(void)
{
    char str[] = "MADAM";

    int left = 0;
    int right = (int)strlen(str) - 1;
    bool palindrome = true;

    while (left < right)
    {
        if (str[left] != str[right])
        {
            palindrome = false;
            break;
        }

        left++;
        right--;
    }

    if (palindrome)
        printf("Palindrome\n");
    else
        printf("Not a palindrome\n");

    return 0;
}
Expected Output: 
Palindrome

Time Complexity: O(n)

Auxiliary Space: O(1)

9. Case-Insensitive Palindrome Checking

A case-insensitive palindrome check treats uppercase and lowercase versions of the same English letter as equal. For example, "Madam" is considered a palindrome. 

#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stdbool.h>

int main(void)
{
    char str[] = "Madam";

    int left = 0;
    int right = (int)strlen(str) - 1;
    bool palindrome = true;

    while (left < right)
    {
        unsigned char a = (unsigned char)str[left];
        unsigned char b = (unsigned char)str[right];

        if (tolower(a) != tolower(b))
        {
            palindrome = false;
            break;
        }

        left++;
        right--;
    }

    printf("%s\n",
           palindrome ? "Palindrome" : "Not a palindrome");

    return 0;
}
Expected Output: 
Palindrome

Time Complexity: O(n)

Auxiliary Space: O(1)

10. Palindrome Ignoring Spaces and Punctuation

Some interview problems ask whether a sentence is a palindrome after ignoring spaces, punctuation and letter case.

Example:

A man, a plan, a canal: Panama

After ignoring non-alphanumeric characters and case differences, it becomes: 

amanaplanacanalpanama
#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stdbool.h>

int main(void)
{
    char str[] = "A man, a plan, a canal: Panama";

    int left = 0;
    int right = (int)strlen(str) - 1;
    bool palindrome = true;

    while (left < right)
    {
        while (left < right &&
               !isalnum((unsigned char)str[left]))
        {
            left++;
        }

        while (left < right &&
               !isalnum((unsigned char)str[right]))
        {
            right--;
        }

        if (tolower((unsigned char)str[left]) !=
            tolower((unsigned char)str[right]))
        {
            palindrome = false;
            break;
        }

        left++;
        right--;
    }

    printf("%s\n",
           palindrome ? "Palindrome" : "Not a palindrome");

    return 0;
}
Expected Output: 
Palindrome

Time Complexity: O(n)

Auxiliary Space: O(1)

This example uses the standard C character classification functions. Its alphanumeric handling is based on the active C locale; it is not a general Unicode palindrome implementation.

11. Check Whether a Number Is a Palindrome

A numeric palindrome reads the same when its decimal digits are reversed.

NumberPalindrome?
121Yes
1331Yes
123No
1001Yes
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    int number = 121;
    int original = number;
    int reversed = 0;

    if (number < 0)
    {
        printf("Not a palindrome\n");
        return 0;
    }

    while (number > 0)
    {
        int digit = number % 10;
        reversed = reversed * 10 + digit;
        number = number / 10;
    }

    if (original == reversed)
        printf("Palindrome number\n");
    else
        printf("Not a palindrome number\n");

    return 0;
}
Expected Output: 
Palindrome number

Time Complexity: O(d), where d is the number of digits.

Auxiliary Space: O(1)

The simple integer-reversal approach can overflow for sufficiently large integers. For production-quality code, check arithmetic before multiplying and adding, or use a half-reversal method.

12. Longest Palindromic Prefix: Introduction

A palindromic prefix is a prefix of a string that is itself a palindrome.

Example: For "abacxyz", the longest palindromic prefix is "aba".

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool is_palindrome(const char *str, int length)
{
    int left = 0;
    int right = length - 1;

    while (left < right)
    {
        if (str[left] != str[right])
            return false;

        left++;
        right--;
    }

    return true;
}

int main(void)
{
    char str[] = "abacxyz";
    int length = (int)strlen(str);

    for (int i = length; i > 0; i--)
    {
        if (is_palindrome(str, i))
        {
            printf("Longest palindromic prefix: ");

            for (int j = 0; j < i; j++)
                putchar(str[j]);

            putchar('\n');
            break;
        }
    }

    return 0;
}
Expected Output: 
Longest palindromic prefix: aba

Time Complexity: O(n²) worst case.

Auxiliary Space: O(1)

15. Common Mistakes

  1. Using the string array size instead of the actual string length.
  2. Including '\0' in the character comparisons incorrectly.
  3. Using a negative right index for an empty string.
  4. Modifying a string literal instead of a character array.
  5. Forgetting to handle uppercase and lowercase requirements.
  6. Ignoring the problem's whitespace and punctuation rules.
  7. Using a temporary array when an in-place solution is expected.
  8. Forgetting numeric overflow in integer reversal.

17. Placement Interview Questions and Answers

Q1. What is a palindrome?

A sequence that reads the same forward and backward.

Q2. What is the two-pointer technique?

It uses two indices or pointers to process elements from different positions, often from opposite ends.

Q3. What is the time complexity of reversing a string?

O(n), because each character is processed at most once.

Q4. What is the space complexity of in-place reversal?

O(1) auxiliary space.

Q5. How do you check a palindrome efficiently?

Compare characters from the beginning and end, moving toward the center.

Q6. Can an empty string be considered a palindrome?

Yes. Under the usual definition, it is a palindrome because there are no mismatching characters.

Q7. What is an odd-length palindrome?

A palindrome with an odd number of characters, such as MADAM.

Q8. What is an even-length palindrome?

A palindrome with an even number of characters, such as ABBA.

Q9. What is the difference between string reversal and palindrome checking?

Reversal changes character order. Palindrome checking determines whether the original sequence is symmetric.

Q10. Why is strlen() used before two-pointer reversal?

To locate the last character, which is at index strlen(str) - 1.

Q11. How do you perform case-insensitive palindrome checking?

Compare corresponding characters after converting them to a common case.

Q12. How do you ignore spaces and punctuation?

Move each pointer past non-alphanumeric characters before comparing the remaining characters.

Q13. Can a palindrome be checked without creating another string?

Yes. The two-pointer method uses O(1) auxiliary space.

Q14. What is a numeric palindrome?

A number whose decimal digits read the same in both directions, such as 121.

Q15. What happens if a string contains only one character?

It is a palindrome because the character matches itself.

Q16. What is the longest palindromic prefix?

The longest prefix of a string that is itself a palindrome.

Q17. Why should string literals not be reversed directly?

Modifying a string literal has undefined behavior. Copy it into a modifiable character array first.

Q18. What is the difference between a substring and a subsequence?

A substring uses consecutive characters. A subsequence preserves relative order but may skip characters.

Q19. What is the basic time complexity of finding the longest palindromic prefix using repeated checks?

O(n²) in the worst case.

Q20. Which approach is useful for palindrome checking in coding rounds?

The two-pointer approach is usually the simplest efficient solution for a single palindrome check.
