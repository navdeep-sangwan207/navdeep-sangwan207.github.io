2. What Is String Hashing?

String hashing converts a string into a numerical value called a hash value or hash code.

For example:

String = "CAT"
Hash value = Some integer generated from "CAT"

Hashing is useful in:

  • Fast string comparison in suitable applications.
  • Pattern searching.
  • Duplicate string detection.
  • Hash tables and dictionaries.
  • Competitive programming problems.
A hash value is a compact numerical representation of data. It does not uniquely identify every possible string.

3. Hash Function

A hash function maps input data to a numerical value. A simple illustrative function for a string is the sum of its character values. 

#include <stdio.h>

unsigned int simple_hash(const char *str)
{
    unsigned int hash = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        hash += (unsigned char)str[i];
    }

    return hash;
}

int main(void)
{
    char str[] = "CAT";

    printf("Hash value = %u\n", simple_hash(str));

    return 0;
}
Expected Output (ASCII-compatible system): 
Hash value = 216

Time Complexity: O(n).

Auxiliary Space: O(1).

This is only a demonstration hash function. It is not suitable for reliable pattern matching because many different strings produce the same sum.

4. Hash Collision

A collision occurs when two different strings produce the same hash value.

Consider the sum-based hash:

StringCharacter Sum
CAT216
ACT216
TAC216

All three strings produce the same hash because addition does not consider character order.

Hash collisions are normal in hashing. A correct hash-based pattern-searching algorithm must verify the actual characters after a hash match.

5. Polynomial Rolling Hash

A polynomial rolling hash considers both character values and their positions.

One common mathematical form is:

hash(s) = (s[0] × p⁰ + s[1] × p¹ + ... ) mod M

  • p: A chosen base.
  • M: A large modulus.
  • s[i]: Numeric value assigned to a character.

Modular arithmetic keeps the hash value within a manageable numerical range.

Polynomial hashes are useful because they support efficient updates when a fixed-length window moves through a string.

6. Implement a Polynomial Hash Function in C

#include <stdio.h>
#include <stdint.h>

uint64_t polynomial_hash(const char *str)
{
    const uint64_t base = 31;
    const uint64_t mod = 1000000007;
    uint64_t hash = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        uint64_t value = (uint64_t)ch + 1;

        hash = (hash * base + value) % mod;
    }

    return hash;
}

int main(void)
{
    char str[] = "hello";

    printf("Hash value = %llu\n",
           (unsigned long long)polynomial_hash(str));

    return 0;
}

Time Complexity: O(n).

Auxiliary Space: O(1).

This example uses uint64_t arithmetic. With the selected modulus and base, the multiplication remains within the range of uint64_t. A polynomial hash can still collide; it is not a cryptographic hash.

7. What Is Rolling Hash?

Rolling hash allows the hash of a fixed-length window to be updated when the window moves by one position, without recalculating the entire hash from scratch.

For a window of length m:

  1. Calculate the hash of the first window.
  2. Remove the contribution of the outgoing character.
  3. Shift the remaining hash values.
  4. Add the incoming character.
  5. Repeat for the next window.
Rolling hash is the central idea behind the efficient window-hashing approach used in Rabin-Karp.

8. Rabin-Karp Algorithm

Rabin-Karp searches for a pattern by comparing hash values instead of comparing every character at every possible position.

Algorithm Steps

  1. Calculate the hash of the pattern.
  2. Calculate the hash of the first text window of equal length.
  3. Compare the two hash values.
  4. If hashes match, verify the actual characters.
  5. Calculate the next window hash using rolling hash.
  6. Continue until all possible windows are processed.

9. Rabin-Karp Implementation in C

The following implementation uses modular rolling hash and verifies every candidate match to handle collisions. 

#include <stdio.h>
#include <string.h>
#include <stdint.h>

#define BASE 256ULL
#define MOD 1000000007ULL

void rabin_karp(const char *text, const char *pattern)
{
    size_t n = strlen(text);
    size_t m = strlen(pattern);

    if (m == 0)
    {
        printf("Empty pattern\n");
        return;
    }

    if (m > n)
    {
        printf("Pattern not found\n");
        return;
    }

    uint64_t pattern_hash = 0;
    uint64_t window_hash = 0;
    uint64_t highest_power = 1;

    for (size_t i = 1; i < m; i++)
        highest_power = (highest_power * BASE) % MOD;

    for (size_t i = 0; i < m; i++)
    {
        pattern_hash =
            (pattern_hash * BASE +
             (unsigned char)pattern[i] + 1) % MOD;

        window_hash =
            (window_hash * BASE +
             (unsigned char)text[i] + 1) % MOD;
    }

    int found = 0;

    for (size_t i = 0; i <= n - m; i++)
    {
        if (pattern_hash == window_hash)
        {
            if (memcmp(text + i, pattern, m) == 0)
            {
                printf("Pattern found at index %zu\n", i);
                found = 1;
            }
        }

        if (i < n - m)
        {
            uint64_t outgoing =
                ((uint64_t)(unsigned char)text[i] + 1)
                * highest_power % MOD;

            window_hash =
                (window_hash + MOD - outgoing) % MOD;

            window_hash =
                (window_hash * BASE +
                 (unsigned char)text[i + m] + 1) % MOD;
        }
    }

    if (!found)
        printf("Pattern not found\n");
}

int main(void)
{
    char text[] = "ABABABC";
    char pattern[] = "AB";

    rabin_karp(text, pattern);

    return 0;
}
Expected Output: 
Pattern found at index 0
Pattern found at index 2
Pattern found at index 4

Expected Time Complexity: O(n + m) for typical inputs with few hash collisions; worst case O(nm).

Auxiliary Space: O(1).

Hash equality alone does not prove a match. The memcmp() verification is essential for correctness.

10. What Is KMP (Knuth-Morris-Pratt)?

KMP is an efficient pattern-matching algorithm that avoids rechecking text characters unnecessarily.

When a mismatch occurs, KMP uses previously matched pattern information to decide where the next comparison should begin.

It uses an auxiliary array called LPS: Longest Proper Prefix which is also a Suffix.

KMP performs pattern searching in O(n + m) time, where n is the text length and m is the pattern length.

11. Understanding LPS Array

LPS[i] stores the length of the longest proper prefix of the pattern substring ending at index i that is also a suffix of that substring.

Consider:

Pattern = "ABABC"
Index Substring LPS Value
0A0
1AB0
2ABA1
3ABAB2
4ABABC0
LPS Array: 
[0, 0, 1, 2, 0]

12. LPS Array Construction Algorithm

Steps:

  1. Set LPS[0] to zero.
  2. Maintain a variable len for the current prefix-suffix length.
  3. Compare pattern[i] with pattern[len].
  4. If equal, increment len and assign LPS[i].
  5. If unequal and len is not zero, fall back to LPS[len - 1].
  6. Otherwise, assign zero and move to the next position.
#include <stdio.h>
#include <string.h>

void build_lps(const char *pattern, int lps[])
{
    int m = (int)strlen(pattern);

    if (m == 0)
        return;

    lps[0] = 0;

    int len = 0;
    int i = 1;

    while (i < m)
    {
        if (pattern[i] == pattern[len])
        {
            len++;
            lps[i] = len;
            i++;
        }
        else
        {
            if (len != 0)
            {
                len = lps[len - 1];
            }
            else
            {
                lps[i] = 0;
                i++;
            }
        }
    }
}

int main(void)
{
    char pattern[] = "ABABC";
    int lps[sizeof(pattern) - 1];

    build_lps(pattern, lps);

    printf("LPS: ");

    for (int i = 0; i < 5; i++)
        printf("%d ", lps[i]);

    printf("\n");

    return 0;
}
Expected Output: 
LPS: 0 0 1 2 0

Time Complexity: O(m).

Auxiliary Space: O(1), excluding the LPS output array.

13. KMP Pattern Searching Implementation in C

#include <stdio.h>
#include <string.h>

void build_lps(const char *pattern, int lps[])
{
    int m = (int)strlen(pattern);

    if (m == 0)
        return;

    lps[0] = 0;

    int len = 0;
    int i = 1;

    while (i < m)
    {
        if (pattern[i] == pattern[len])
        {
            len++;
            lps[i] = len;
            i++;
        }
        else if (len != 0)
        {
            len = lps[len - 1];
        }
        else
        {
            lps[i] = 0;
            i++;
        }
    }
}

void kmp_search(const char *text, const char *pattern)
{
    size_t n = strlen(text);
    size_t m = strlen(pattern);

    if (m == 0)
    {
        printf("Empty pattern\n");
        return;
    }

    if (m > n)
    {
        printf("Pattern not found\n");
        return;
    }

    int lps[m];

    build_lps(pattern, lps);

    size_t i = 0;
    size_t j = 0;
    int found = 0;

    while (i < n)
    {
        if (text[i] == pattern[j])
        {
            i++;
            j++;
        }

        if (j == m)
        {
            printf("Pattern found at index %zu\n", i - j);
            found = 1;
            j = (size_t)lps[j - 1];
        }
        else if (i < n && text[i] != pattern[j])
        {
            if (j != 0)
            {
                j = (size_t)lps[j - 1];
            }
            else
            {
                i++;
            }
        }
    }

    if (!found)
        printf("Pattern not found\n");
}

int main(void)
{
    char text[] = "ABABDABACDABABCABAB";
    char pattern[] = "ABABCABAB";

    kmp_search(text, pattern);

    return 0;
}
Expected Output: 
Pattern found at index 10

Time Complexity: O(n + m).

Auxiliary Space: O(m) for the LPS array.

This implementation uses a C11 variable-length array for the LPS buffer. A compiler that does not support optional variable-length arrays can use dynamically allocated memory instead. For extremely large patterns, check allocation sizes and index-type limits.

16. Common Mistakes

  1. Assuming two equal hash values guarantee equal strings.
  2. Forgetting collision verification in Rabin-Karp.
  3. Updating a rolling hash with an incorrect outgoing-character contribution.
  4. Confusing a prefix with a proper prefix.
  5. Building the LPS array incorrectly after a mismatch.
  6. Resetting the KMP pattern index to zero after every mismatch.
  7. Failing to handle empty patterns.
  8. Forgetting to continue KMP after a successful match when all occurrences are required.

17. Placement Interview Questions and Answers

Q1. What is string hashing?

It converts a string into a numerical hash value using a hash function.

Q2. What is a hash collision?

Two different inputs produce the same hash value.

Q3. What is a rolling hash?

A hash technique that updates the hash of a moving fixed-size window efficiently.

Q4. What is Rabin-Karp?

A pattern-searching algorithm that uses rolling hashes to identify candidate matches.

Q5. Why is character verification required in Rabin-Karp?

Because different strings can produce the same hash value.

Q6. What is the worst-case time complexity of Rabin-Karp?

O(nm), because hash collisions can cause repeated character verification.

Q7. What is KMP?

Knuth-Morris-Pratt, a linear-time string pattern-matching algorithm.

Q8. What does LPS stand for?

Longest Proper Prefix which is also a Suffix.

Q9. What is a proper prefix?

A prefix that is not equal to the entire string.

Q10. What does LPS[i] represent?

The length of the longest proper prefix that is also a suffix of the pattern prefix ending at index i.

Q11. What is the time complexity of building the LPS array?

O(m), where m is the pattern length.

Q12. What is KMP's pattern-searching complexity?

O(n + m).

Q13. Why does KMP not restart from the beginning after a mismatch?

It uses LPS information to retain the longest relevant prefix-suffix match.

Q14. Which algorithm uses rolling hash?

Rabin-Karp.

Q15. Which algorithm uses an LPS array?

KMP.

Q16. Can Rabin-Karp find multiple occurrences?

Yes. It can process every window and verify all matching hash candidates.

Q17. What is modular arithmetic used for in polynomial hashing?

It keeps hash values bounded and reduces arithmetic overflow risk when operations are designed correctly.

Q18. Is a polynomial rolling hash cryptographically secure?

No. It is designed for algorithmic matching and hashing, not security.

Q19. Which algorithm guarantees linear-time pattern searching?

KMP guarantees O(n + m) time.

Q20. When should you choose KMP over Rabin-Karp?

Choose KMP when deterministic linear-time single-pattern matching is required. Rabin-Karp is useful when hashing multiple windows or comparing multiple patterns is convenient.
