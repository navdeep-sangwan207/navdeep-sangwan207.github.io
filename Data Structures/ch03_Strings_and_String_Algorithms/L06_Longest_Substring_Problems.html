2. What Is a Longest Substring Problem?

A longest substring problem asks us to find the maximum-length contiguous portion of a string that satisfies a given condition.

Example:

String = "abcabcbb"

The longest substring without repeating characters is "abc", with length 3.

A substring must be contiguous. If characters are skipped, the result is a subsequence, not a substring.

3. Sliding-Window Technique

A sliding window maintains a range of characters in a string. Instead of checking every possible substring from scratch, we move the left and right boundaries to maintain a valid window.

Two pointers are commonly used:

  • Left: Starting index of the current window.
  • Right: Ending index of the current window.

Window length:

window_length = right - left + 1;

Typical steps:

  1. Initialize the left boundary.
  2. Expand the window by moving the right boundary.
  3. Check whether the current window satisfies the condition.
  4. If invalid, move the left boundary until valid again.
  5. Update the best answer.
Many variable-size sliding-window algorithms run in O(n) because each boundary moves forward at most n times.

4. Longest Substring Without Repeating Characters

Given a string, find the length of the longest substring that contains no repeated characters.

Example:

Input:  "abcabcbb"
Output: 3
Longest substring: "abc"

Approach: Sliding Window with Last-Seen Index

Maintain an array that records the most recent index of each byte character. When a repeated character appears inside the current window, move the left boundary beyond its previous occurrence. 

#include <stdio.h>
#include <string.h>

int longest_unique_substring(const char *str)
{
    int last_seen[256];

    for (int i = 0; i < 256; i++)
        last_seen[i] = -1;

    int left = 0;
    int max_length = 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        unsigned char ch = (unsigned char)str[right];

        if (last_seen[ch] >= left)
        {
            left = last_seen[ch] + 1;
        }

        last_seen[ch] = right;

        int current_length = right - left + 1;

        if (current_length > max_length)
            max_length = current_length;
    }

    return max_length;
}

int main(void)
{
    char str[] = "abcabcbb";

    printf("Longest length = %d\n",
           longest_unique_substring(str));

    return 0;
}
Expected Output: 
Longest length = 3

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1), using a fixed 256-element array.

6. Print the Longest Substring Without Repeating Characters

In some interview questions, returning only the length is insufficient. We must also print the actual substring. 

#include <stdio.h>
#include <string.h>

void print_longest_unique_substring(const char *str)
{
    int last_seen[256];

    for (int i = 0; i < 256; i++)
        last_seen[i] = -1;

    int left = 0;
    int best_start = 0;
    int max_length = 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        unsigned char ch = (unsigned char)str[right];

        if (last_seen[ch] >= left)
            left = last_seen[ch] + 1;

        last_seen[ch] = right;

        int current_length = right - left + 1;

        if (current_length > max_length)
        {
            max_length = current_length;
            best_start = left;
        }
    }

    printf("Longest substring: ");

    for (int i = 0; i < max_length; i++)
        putchar(str[best_start + i]);

    printf("\nLength: %d\n", max_length);
}

int main(void)
{
    char str[] = "pwwkew";

    print_longest_unique_substring(str);

    return 0;
}
Expected Output: 
Longest substring: wke
Length: 3

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

For "pwwkew", both "wke" and "kew" have length 3. This implementation returns the first longest substring encountered.

7. Longest Substring with At Most K Distinct Characters

Given a string and an integer K, find the length of the longest substring containing no more than K distinct characters.

Example:

String = "eceba"
K = 2

Output = 3
Longest substring = "ece"
#include <stdio.h>
#include <string.h>

int longest_k_distinct(const char *str, int k)
{
    if (k <= 0)
        return 0;

    int frequency[256] = {0};
    int left = 0;
    int distinct = 0;
    int max_length = 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        unsigned char ch = (unsigned char)str[right];

        if (frequency[ch] == 0)
            distinct++;

        frequency[ch]++;

        while (distinct > k)
        {
            unsigned char left_ch = (unsigned char)str[left];

            frequency[left_ch]--;

            if (frequency[left_ch] == 0)
                distinct--;

            left++;
        }

        int current_length = right - left + 1;

        if (current_length > max_length)
            max_length = current_length;
    }

    return max_length;
}

int main(void)
{
    char str[] = "eceba";
    int k = 2;

    printf("Longest length = %d\n",
           longest_k_distinct(str, k));

    return 0;
}
Expected Output: 
Longest length = 3

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

8. Longest Substring with Exactly K Distinct Characters

This problem differs from the previous one. The window must contain exactly K distinct characters, not fewer. 

#include <stdio.h>

int longest_exactly_k_distinct(const char *str, int k)
{
    if (k <= 0)
        return 0;

    int frequency[256] = {0};
    int left = 0;
    int distinct = 0;
    int max_length = 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        unsigned char ch = (unsigned char)str[right];

        if (frequency[ch] == 0)
            distinct++;

        frequency[ch]++;

        while (distinct > k)
        {
            unsigned char left_ch = (unsigned char)str[left];

            frequency[left_ch]--;

            if (frequency[left_ch] == 0)
                distinct--;

            left++;
        }

        if (distinct == k)
        {
            int current_length = right - left + 1;

            if (current_length > max_length)
                max_length = current_length;
        }
    }

    return max_length;
}

int main(void)
{
    char str[] = "aabacbebebe";
    int k = 3;

    printf("Longest length = %d\n",
           longest_exactly_k_distinct(str, k));

    return 0;
}
Expected Output: 
Longest length = 7

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

9. Longest Substring After Replacing at Most K Characters

Given a string containing uppercase English letters, find the longest substring that can be converted into a string of identical characters by replacing at most K characters.

Example:

String = "AABABBA"
K = 1

Output = 4

The window "AABA" can become "AAAA" by replacing one character. 

#include <stdio.h>
#include <string.h>

int longest_repeating_after_replacements(const char *str, int k)
{
    int frequency[26] = {0};
    int left = 0;
    int max_frequency = 0;
    int max_length = 0;

    if (k < 0)
        return 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        if (str[right] < 'A' || str[right] > 'Z')
            return -1;

        int index = str[right] - 'A';

        frequency[index]++;

        if (frequency[index] > max_frequency)
            max_frequency = frequency[index];

        int window_length = right - left + 1;

        while (window_length - max_frequency > k)
        {
            frequency[str[left] - 'A']--;
            left++;

            window_length = right - left + 1;
        }

        if (window_length > max_length)
            max_length = window_length;
    }

    return max_length;
}

int main(void)
{
    char str[] = "AABABBA";
    int k = 1;

    int result =
        longest_repeating_after_replacements(str, k);

    if (result == -1)
        printf("Invalid input\n");
    else
        printf("Longest length = %d\n", result);

    return 0;
}
Expected Output: 
Longest length = 4

Time Complexity: O(n + 26), effectively O(n).

Auxiliary Space: O(1).

The algorithm keeps a historical maximum character frequency for the sliding window. That value need not decrease when the left boundary moves. This is a valid optimization for finding the maximum length, although the current window may temporarily be less than fully valid according to that historical count.

10. Longest Substring Containing Only Two Distinct Characters

This is a special case of the at-most-K-distinct problem where K = 2. 

#include <stdio.h>

int longest_two_distinct(const char *str)
{
    int frequency[256] = {0};
    int left = 0;
    int distinct = 0;
    int max_length = 0;

    for (int right = 0; str[right] != '\0'; right++)
    {
        unsigned char ch = (unsigned char)str[right];

        if (frequency[ch] == 0)
            distinct++;

        frequency[ch]++;

        while (distinct > 2)
        {
            unsigned char left_ch = (unsigned char)str[left];

            frequency[left_ch]--;

            if (frequency[left_ch] == 0)
                distinct--;

            left++;
        }

        int current_length = right - left + 1;

        if (current_length > max_length)
            max_length = current_length;
    }

    return max_length;
}

int main(void)
{
    char str[] = "ccaabbb";

    printf("Longest length = %d\n",
           longest_two_distinct(str));

    return 0;
}
Expected Output: 
Longest length = 5

Time Complexity: O(n).

Auxiliary Space: O(1).

11. Brute Force vs Sliding Window

Approach Basic Idea Typical Complexity
Brute Force Generate and check possible substrings Often O(n²) or O(n³)
Sliding Window Maintain a valid range and move boundaries Often O(n)
Last-Seen Index Jump the left boundary past repeated characters O(n) for fixed alphabet
The main interview skill is recognizing when a problem can be solved by maintaining a valid window instead of repeatedly generating substrings.

12. Common Mistakes

  1. Confusing substring with subsequence.
  2. Using right - left instead of right - left + 1.
  3. Moving the left boundary backwards when processing repeated characters.
  4. Forgetting to update character frequencies when shrinking a window.
  5. Confusing at most K distinct with exactly K distinct.
  6. Updating the maximum length before restoring a valid window.
  7. Assuming the replacement problem uses a frequency of zero as its maximum.
  8. Ignoring the input character-set assumptions.

13. Placement Interview Questions and Answers

Q1. What is a sliding window?

A technique that maintains a contiguous range of elements and moves its boundaries to solve problems efficiently.

Q2. What is a variable-size sliding window?

A window whose length changes as the algorithm expands or shrinks it according to a condition.

Q3. What is the longest substring without repeating characters?

The longest contiguous portion of a string in which every character occurs only once.

Q4. Which data structure helps solve this problem efficiently?

A fixed-size frequency or last-seen-index array for a bounded character set.

Q5. What is the time complexity of the optimized solution?

O(n) for a fixed character set.

Q6. Why does sliding window often achieve O(n)?

Each boundary moves only forward, so the total number of boundary movements is linear.

Q7. What is the difference between at most K and exactly K distinct characters?

At most K allows fewer than K distinct characters; exactly K requires precisely K.

Q8. How do you find the longest substring with two distinct characters?

Use a variable-size sliding window and shrink it whenever the number of distinct characters exceeds two.

Q9. What is the purpose of a last-seen array?

It stores the most recent index of each character so the left boundary can skip past repeated characters.

Q10. What does K represent in the replacement problem?

The maximum number of characters that may be replaced.

Q11. What is a valid window?

A window that satisfies all constraints defined by the problem.

Q12. Can sliding window be used for every substring problem?

No. It is most useful when the problem has a maintainable window condition. Some problems require other techniques such as dynamic programming, hashing or binary search.

Q13. What is the maximum possible length of a unique-character substring over a fixed alphabet of size 256?

At most 256 byte characters.

Q14. Why do we use unsigned char for frequency indexing?

It prevents negative array indices caused by signed char values.

Q15. What is the difference between fixed-size and variable-size windows?

A fixed-size window has a predetermined length; a variable-size window expands and contracts according to a condition.

Q16. What is the longest substring without repeating characters in "pwwkew"?

The maximum length is 3. Examples include "wke" and "kew".

Q17. What happens when K is zero in an at-most-K-distinct problem?

The answer is zero for a non-empty string because no non-empty window can contain zero distinct characters.

Q18. What is the difference between a frequency array and a last-seen array?

A frequency array stores occurrence counts; a last-seen array stores the most recent position of each character.

Q19. What is the main advantage of the sliding-window technique?

It avoids repeatedly processing overlapping portions of the input.

Q20. Name common interview problems solved using sliding windows.

Longest unique substring, at most K distinct characters, longest repeating-character replacement, and minimum-window substring.
