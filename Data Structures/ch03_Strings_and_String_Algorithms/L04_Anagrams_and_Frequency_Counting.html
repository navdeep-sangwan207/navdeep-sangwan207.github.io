2. What Is an Anagram?

Two strings are anagrams if they contain exactly the same characters with the same frequencies, but possibly in a different order.

String 1String 2Result
listensilentAnagram
triangleintegralAnagram
helloworldNot anagram
racecareAnagram
appleapplyNot anagram
Character frequency matters. Merely containing the same distinct characters is not enough. For example, "aab" and "abb" are not anagrams.

3. Character Frequency Counting

Frequency counting means calculating how many times each character appears in a string.

Example string: "banana"

CharacterFrequency
a3
b1
n2

In C, an integer array can store the frequency of each ASCII character. For byte-sized character values, an array of 256 elements is commonly used. 

#include <stdio.h>

int main(void)
{
    char str[] = "banana";
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > 0)
        {
            printf("%c = %d\n", i, frequency[i]);
        }
    }

    return 0;
}
Expected Output: 
a = 3
b = 1
n = 2

Time Complexity: O(n + 256), effectively O(n) for byte characters.

Auxiliary Space: O(1), because the frequency array has fixed size.

4. Check Whether Two Strings Are Anagrams

One efficient approach is to increment the frequency of every character in the first string and decrement the frequency of every character in the second string. If every count becomes zero, the strings are anagrams. 

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool are_anagrams(const char *str1, const char *str2)
{
    int frequency[256] = {0};

    if (strlen(str1) != strlen(str2))
        return false;

    for (int i = 0; str1[i] != '\0'; i++)
    {
        frequency[(unsigned char)str1[i]]++;
        frequency[(unsigned char)str2[i]]--;
    }

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] != 0)
            return false;
    }

    return true;
}

int main(void)
{
    char str1[] = "listen";
    char str2[] = "silent";

    if (are_anagrams(str1, str2))
        printf("Anagrams\n");
    else
        printf("Not anagrams\n");

    return 0;
}
Expected Output: 
Anagrams

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1) for the fixed-size frequency array.

This implementation is case-sensitive and considers every byte value. It does not ignore spaces or punctuation.

5. Case-Insensitive Anagram Checking

If the problem says uppercase and lowercase letters should be treated equally, convert each character to a common case before counting. 

#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stdbool.h>

bool are_anagrams_ignore_case(const char *a, const char *b)
{
    int frequency[26] = {0};

    if (strlen(a) != strlen(b))
        return false;

    for (int i = 0; a[i] != '\0'; i++)
    {
        unsigned char x = (unsigned char)a[i];
        unsigned char y = (unsigned char)b[i];

        if (!isalpha(x) || !isalpha(y))
            return false;

        x = (unsigned char)tolower(x);
        y = (unsigned char)tolower(y);

        frequency[x - 'a']++;
        frequency[y - 'a']--;
    }

    for (int i = 0; i < 26; i++)
    {
        if (frequency[i] != 0)
            return false;
    }

    return true;
}

int main(void)
{
    char str1[] = "Listen";
    char str2[] = "Silent";

    printf("%s\n",
           are_anagrams_ignore_case(str1, str2)
           ? "Anagrams" : "Not anagrams");

    return 0;
}
Expected Output: 
Anagrams

Time Complexity: O(n + 26), effectively O(n).

Auxiliary Space: O(1).

This version is designed for English alphabetic characters in the C locale. It rejects spaces, punctuation and non-alphabetic characters instead of ignoring them.

6. Anagram Checking by Sorting

Another method is to sort both strings and compare the resulting character sequences. If the sorted strings are equal, the original strings are anagrams. 

#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <stdbool.h>

int compare_chars(const void *a, const void *b)
{
    unsigned char x = *(const unsigned char *)a;
    unsigned char y = *(const unsigned char *)b;

    return (x > y) - (x < y);
}

bool are_anagrams(char *a, char *b)
{
    size_t n = strlen(a);

    if (n != strlen(b))
        return false;

    qsort(a, n, sizeof(char), compare_chars);
    qsort(b, n, sizeof(char), compare_chars);

    return strcmp(a, b) == 0;
}

int main(void)
{
    char str1[] = "listen";
    char str2[] = "silent";

    if (are_anagrams(str1, str2))
        printf("Anagrams\n");
    else
        printf("Not anagrams\n");

    return 0;
}
Expected Output: 
Anagrams

Time Complexity: O(n log n) for typical comparison sorting.

Auxiliary Space: Depends on the qsort() implementation.

qsort() sorts the input arrays in place, so this example changes the original strings. Use copies if the original order must be preserved.

7. Count Occurrences of a Given Character

#include <stdio.h>

int main(void)
{
    char str[] = "programming";
    char target = 'm';
    int count = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        if (str[i] == target)
            count++;
    }

    printf("Occurrences of %c = %d\n", target, count);

    return 0;
}
Expected Output: 
Occurrences of m = 2

Time Complexity: O(n)

Auxiliary Space: O(1)

8. Find Duplicate Characters

A character is a duplicate if its frequency is greater than one. The following program prints each duplicated byte character once. 

#include <stdio.h>

int main(void)
{
    char str[] = "programming";
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    printf("Duplicate characters:\n");

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > 1)
        {
            printf("%c = %d\n", i, frequency[i]);
        }
    }

    return 0;
}
Expected Output: 
Duplicate characters:
g = 2
m = 2
r = 2

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

9. Find the First Non-Repeating Character

A non-repeating character appears exactly once. The first non-repeating character is the earliest character in the original string whose frequency is one. 

#include <stdio.h>

int main(void)
{
    char str[] = "swiss";
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int found = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        if (frequency[(unsigned char)str[i]] == 1)
        {
            printf("First non-repeating character: %c\n", str[i]);
            found = 1;
            break;
        }
    }

    if (!found)
        printf("No non-repeating character\n");

    return 0;
}
Expected Output: 
First non-repeating character: w

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

10. Find the First Repeating Character

The first repeating character is the first character encountered from the left whose frequency is greater than one in the complete string. 

#include <stdio.h>

int main(void)
{
    char str[] = "abccba";
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int found = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        if (frequency[(unsigned char)str[i]] > 1)
        {
            printf("First repeating character: %c\n", str[i]);
            found = 1;
            break;
        }
    }

    if (!found)
        printf("No repeating character\n");

    return 0;
}
Expected Output: 
First repeating character: a

Time Complexity: O(n + 256), effectively O(n).

Auxiliary Space: O(1).

"First repeating character" can have different meanings in different interview questions. Always check whether the question asks for the first character whose frequency exceeds one or the character whose second occurrence appears earliest.

11. Check Whether All Characters Are Unique

#include <stdio.h>
#include <stdbool.h>

bool all_unique(const char *str)
{
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (frequency[ch] > 0)
            return false;

        frequency[ch]++;
    }

    return true;
}

int main(void)
{
    char str[] = "abcdef";

    if (all_unique(str))
        printf("All characters are unique\n");
    else
        printf("Duplicate characters found\n");

    return 0;
}
Expected Output: 
All characters are unique

Time Complexity: O(n).

Auxiliary Space: O(1).

12. Check Whether Two Strings Have the Same Character Frequencies

This is the same frequency-counting principle used for anagram detection. It is useful in problems where the order of characters does not matter. 

#include <stdio.h>
#include <stdbool.h>

bool same_frequency(const char *a, const char *b)
{
    int frequency[256] = {0};

    for (int i = 0; a[i] != '\0'; i++)
        frequency[(unsigned char)a[i]]++;

    for (int i = 0; b[i] != '\0'; i++)
        frequency[(unsigned char)b[i]]--;

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] != 0)
            return false;
    }

    return true;
}

int main(void)
{
    char a[] = "aabbcc";
    char b[] = "abcabc";

    printf("%s\n",
           same_frequency(a, b)
           ? "Same frequencies" : "Different frequencies");

    return 0;
}
Expected Output: 
Same frequencies

Time Complexity: O(n + m + 256), where n and m are the two string lengths.

Auxiliary Space: O(1).

14. Frequency Array: ASCII Indexing

A character can be converted into an unsigned byte value and used as an array index. 

char ch = 'A';
int frequency[256] = {0};

frequency[(unsigned char)ch]++;

The cast to unsigned char ensures that the index is between 0 and UCHAR_MAX. The 256-element array is suitable on systems where unsigned char has 8 bits.

A 256-element frequency array is not a universal Unicode character counter. UTF-8 text can use multiple bytes for a single Unicode character. For standard English ASCII interview problems, byte-based counting is usually sufficient.

15. Common Mistakes

  1. Checking only whether characters exist instead of comparing their frequencies.
  2. Forgetting to compare string lengths when checking anagrams.
  3. Using signed char directly as an array index.
  4. Ignoring case-sensitivity requirements.
  5. Ignoring spaces or punctuation without checking the problem definition.
  6. Printing duplicate characters more than once unintentionally.
  7. Confusing first repeating with earliest second occurrence.
  8. Assuming a 256-entry array handles all Unicode characters.

17. Placement Interview Questions and Answers

Q1. What is an anagram?

Two strings containing exactly the same characters with the same frequencies, possibly in different orders.

Q2. How can you check anagrams efficiently?

Use a frequency array: increment counts for the first string and decrement them for the second.

Q3. Why is a frequency array useful?

It allows character occurrences to be counted efficiently using character values as array indices.

Q4. What is the size of a common byte-frequency array?

256 entries on systems with 8-bit bytes and 256 possible unsigned char values.

Q5. What is the time complexity of frequency-based anagram checking?

O(n + 256), which is O(n) for a fixed-size character set.

Q6. What is the space complexity of a fixed-size frequency array?

O(1), because its size does not grow with the input length.

Q7. Why use unsigned char as an array index?

It ensures that the index is non-negative and within the unsigned byte range.

Q8. What is the difference between a duplicate and a non-repeating character?

A duplicate appears more than once; a non-repeating character appears exactly once.

Q9. How do you find the first non-repeating character?

Count all character frequencies, then traverse the original string and return the first character with frequency one.

Q10. How do you find duplicate characters?

Count frequencies and report characters whose counts are greater than one.

Q11. Can two strings of different lengths be anagrams?

No, because anagrams must contain the same total number of characters.

Q12. What is the sorting approach to anagram checking?

Sort both strings and compare them. If the sorted sequences match, the strings are anagrams.

Q13. Which approach is generally faster for a fixed character set?

Frequency counting is generally O(n), while comparison sorting is typically O(n log n).

Q14. Does frequency counting preserve character order?

No. It stores occurrence counts, not the positions or order of characters.

Q15. What is a first repeating character?

In one common definition, it is the earliest character in the original string whose total frequency exceeds one. Some problems instead ask for the earliest second occurrence.

Q16. How can you check whether all characters are unique?

Track frequencies and return false as soon as a character is encountered for the second time.

Q17. What is the limitation of a 256-element frequency array?

It counts byte values, not general Unicode characters.

Q18. How can case-insensitive anagram checking be implemented?

Convert alphabetic characters to a common case before updating frequency counts.

Q19. Can frequency counting solve duplicate detection in arrays?

Yes. The same technique can count occurrences of integers when the value range is manageable.

Q20. Name common interview problems based on frequency counting.

Anagram checking, first non-repeating character, duplicate detection, character counts and unique-character checking.
