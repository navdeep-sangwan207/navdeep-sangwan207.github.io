Chapter 3: Strings and String Algorithms

Lesson 5: Substrings and String Matching

Learn substring operations and pattern-searching algorithms using C.

1. Learning Objectives

  • Understand substrings and their properties.
  • Differentiate substrings, subsequences and prefixes.
  • Generate all possible substrings of a string.
  • Extract a substring using starting index and length.
  • Search for a pattern inside a text.
  • Count occurrences of a pattern.
  • Understand overlapping pattern matches.
  • Analyze brute-force string matching complexity.

2. What Is a Substring?

A substring is a contiguous sequence of characters taken from an original string.

Consider the string:

str = "ABCDE"

Some valid substrings are:

  • A
  • AB
  • ABC
  • BCD
  • CDE
  • ABCDE

"ACE" is not a substring because its characters are not contiguous in the original string.

A string of length n has n(n + 1) / 2 non-empty substrings when counted by their positions. Identical substring values at different positions are counted separately.

3. Substring vs Subsequence vs Prefix vs Suffix

SubsequenceCharacters in original order, not necessarily contiguousACE

In coding interviews, substring and subsequence are different concepts. A common mistake is to treat them as interchangeable.

4. Generate All Substrings

Use two loops:

  1. The outer loop selects the starting index.
  2. The inner loop selects the ending index.
  3. Print characters from the starting index to the ending index.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "ABC";
    int n = (int)strlen(str);

    for (int start = 0; start < n; start++)
    {
        for (int end = start; end < n; end++)
        {
            for (int k = start; k <= end; k++)
            {
                printf("%c", str[k]);
            }

            printf("\n");
        }
    }

    return 0;
}
Expected Output: 
A
AB
ABC
B
BC
C

Time Complexity: O(n³) for this printing implementation, because each generated substring is printed character by character.

Auxiliary Space: O(1).

There are O(n²) substring positions, but printing all their characters takes O(n³) total time.

5. Generate Substrings Using a Temporary Array

A temporary character array can store each extracted substring before printing it. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "CAT";
    int n = (int)strlen(str);

    char sub[100];

    for (int start = 0; start < n; start++)
    {
        for (int len = 1; start + len <= n; len++)
        {
            int k;

            for (k = 0; k < len; k++)
            {
                sub[k] = str[start + k];
            }

            sub[k] = '\0';

            printf("%s\n", sub);
        }
    }

    return 0;
}
Expected Output: 
C
CA
CAT
A
AT
T

Time Complexity: O(n³) for copying and printing every substring character.

Auxiliary Space: O(n) for the temporary array.

The temporary array must be large enough to hold the longest substring plus the null terminator. This example uses a fixed buffer for a short demonstration.

6. Extract a Substring Using Start Index and Length

C does not provide a standard substring function. We can write our own function using array indexing. 

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool extract_substring(const char *source,
                       size_t start,
                       size_t length,
                       char *result,
                       size_t capacity)
{
    size_t n = strlen(source);

    if (start > n || length > n - start)
        return false;

    if (capacity <= length)
        return false;

    for (size_t i = 0; i < length; i++)
    {
        result[i] = source[start + i];
    }

    result[length] = '\0';

    return true;
}

int main(void)
{
    char str[] = "PROGRAMMING";
    char result[20];

    if (extract_substring(str, 3, 4, result, sizeof(result)))
        printf("Substring: %s\n", result);
    else
        printf("Invalid substring request\n");

    return 0;
}
Expected Output: 
Substring: GRAM

Time Complexity: O(n + k), including strlen and copying k characters.

Auxiliary Space: O(k) for the output buffer.

7. What Is String Matching?

String matching means finding whether a smaller string, called the pattern, occurs inside a larger string, called the text. 

Text    = "I LOVE PROGRAMMING"
Pattern = "PROGRAM"

The pattern occurs inside the text.

Important terms:

  • Text: The larger string being searched.
  • Pattern: The smaller string to find.
  • Match: An occurrence of the pattern.
  • Index: The starting position of a match.

8. Brute-Force Pattern Searching

The brute-force approach checks the pattern at every possible starting position in the text.

  1. Start at the first position of the text.
  2. Compare each pattern character with the corresponding text character.
  3. If all characters match, report the starting index.
  4. Otherwise, shift the pattern one position to the right.
  5. Continue until no valid starting position remains.
#include <stdio.h>
#include <string.h>

void search_pattern(const char *text, const char *pattern)
{
    size_t n = strlen(text);
    size_t m = strlen(pattern);
    int found = 0;

    if (m == 0)
    {
        printf("Empty pattern\n");
        return;
    }

    if (m > n)
    {
        printf("Pattern not found\n");
        return;
    }

    for (size_t i = 0; i <= n - m; i++)
    {
        size_t j;

        for (j = 0; j < m; j++)
        {
            if (text[i + j] != pattern[j])
                break;
        }

        if (j == m)
        {
            printf("Pattern found at index %zu\n", i);
            found = 1;
        }
    }

    if (!found)
        printf("Pattern not found\n");
}

int main(void)
{
    char text[] = "ABABABC";
    char pattern[] = "AB";

    search_pattern(text, pattern);

    return 0;
}
Expected Output: 
Pattern found at index 0
Pattern found at index 2
Pattern found at index 4

Time Complexity: O((n - m + 1) × m), worst case O(nm).

Auxiliary Space: O(1).

10. Find the First Occurrence of a Pattern

Sometimes an interview question asks only for the first matching position rather than every occurrence. 

#include <stdio.h>
#include <string.h>

int first_match(const char *text, const char *pattern)
{
    size_t n = strlen(text);
    size_t m = strlen(pattern);

    if (m == 0)
        return 0;

    if (m > n)
        return -1;

    for (size_t i = 0; i <= n - m; i++)
    {
        size_t j = 0;

        while (j < m && text[i + j] == pattern[j])
        {
            j++;
        }

        if (j == m)
            return (int)i;
    }

    return -1;
}

int main(void)
{
    char text[] = "WELCOME TO PROGRAMMING";
    char pattern[] = "PROGRAM";

    int index = first_match(text, pattern);

    if (index != -1)
        printf("First occurrence at index %d\n", index);
    else
        printf("Pattern not found\n");

    return 0;
}
Expected Output: 
First occurrence at index 11

Time Complexity: O(nm) worst case.

Auxiliary Space: O(1).

This function returns an int index. For extremely large strings whose positions cannot fit in int, use a size_t-based interface with a separate not-found status.

11. Count Pattern Occurrences

A pattern may appear multiple times in a text. The following program counts overlapping occurrences as well. 

#include <stdio.h>
#include <string.h>

int count_occurrences(const char *text, const char *pattern)
{
    size_t n = strlen(text);
    size_t m = strlen(pattern);
    int count = 0;

    if (m == 0 || m > n)
        return 0;

    for (size_t i = 0; i <= n - m; i++)
    {
        size_t j = 0;

        while (j < m && text[i + j] == pattern[j])
            j++;

        if (j == m)
            count++;
    }

    return count;
}

int main(void)
{
    char text[] = "AAAAA";
    char pattern[] = "AA";

    printf("Occurrences = %d\n",
           count_occurrences(text, pattern));

    return 0;
}
Expected Output: 
Occurrences = 4

Matches begin at indices 0, 1, 2 and 3. These matches overlap.

Time Complexity: O(nm) worst case.

Auxiliary Space: O(1).

12. String Matching Using strstr()

C provides the standard library function strstr() to find the first occurrence of a substring. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "Learning Data Structures";
    char pattern[] = "Data";

    char *result = strstr(text, pattern);

    if (result != NULL)
    {
        printf("Pattern found at index %td\n", result - text);
    }
    else
    {
        printf("Pattern not found\n");
    }

    return 0;
}
Expected Output: 
Pattern found at index 9

strstr() returns a pointer to the first matching occurrence or NULL if the pattern is not found.

Use strstr() when a standard library solution is allowed. In coding rounds, implement the algorithm yourself when the question specifically tests string matching.

13. Find All Occurrences Using strstr()

#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "cat scatter cat";
    char pattern[] = "cat";

    char *position = text;

    while ((position = strstr(position, pattern)) != NULL)
    {
        printf("Found at index %td\n", position - text);
        position++;
    }

    return 0;
}
Expected Output: 
Found at index 0
Found at index 6
Found at index 12

Incrementing the search pointer by one allows overlapping matches to be considered.

15. Common Mistakes

  1. Confusing a substring with a subsequence.
  2. Using an invalid starting index or substring length.
  3. Forgetting the null terminator when copying a substring.
  4. Allowing a pattern to be longer than the text.
  5. Using an incorrect loop boundary during pattern searching.
  6. Failing to define whether overlapping matches count.
  7. Assuming strstr() returns an integer index instead of a pointer.
  8. Using a fixed temporary buffer without checking its capacity.

16. Placement Interview Questions and Answers

Q1. What is a substring?

A contiguous sequence of characters from a string.

Q2. How many non-empty substrings does a string of length n have?

n(n + 1) / 2, counting occurrences by position.

Q3. What is the difference between substring and subsequence?

A substring must be contiguous; a subsequence preserves relative order but can skip characters.

Q4. Does C provide a standard substring function?

No. A custom function can copy the requested character range into an output buffer.

Q5. What does strstr() do?

It finds the first occurrence of a substring inside another string.

Q6. What does strstr() return if no match is found?

It returns NULL.

Q7. What is brute-force string matching?

It compares the pattern at each possible starting position in the text.

Q8. What is its worst-case time complexity?

O(nm), where n is text length and m is pattern length.

Q9. What is an overlapping match?

A match that shares one or more character positions with another match.

Q10. How many times does "AA" occur in "AAAAA" when overlapping matches count?

Four times, starting at indices 0, 1, 2 and 3.

Q11. What is the purpose of the null terminator?

It marks the end of a C string.

Q12. What is the difference between a prefix and a suffix?

A prefix starts at index zero; a suffix ends at the final character.

Q13. Which algorithm uses an LPS array?

The Knuth-Morris-Pratt (KMP) string-matching algorithm.

Q14. What is the main advantage of KMP?

It avoids rechecking text characters unnecessarily and achieves O(n + m) time.

Q15. Which algorithm uses rolling hashes?

Rabin-Karp.

Q16. What is a pattern in string matching?

The smaller string being searched for inside the text.

Q17. Why is the empty pattern a special case?

It can be considered to match at every boundary, so an implementation must define how to handle it.

Q18. What is the time complexity of generating all substring positions?

O(n²), because there are n(n + 1) / 2 possible non-empty substrings.

Q19. What is the time complexity of printing all substrings character by character?

O(n³) in total because the sum of the lengths of all substrings is cubic.

Q20. Why is string matching important?

It is used in text search, search engines, editors, data processing, DNA sequence analysis and pattern recognition.

20. Lesson Summary

Substrings are contiguous parts of strings. String matching is the process of finding a pattern inside a larger text. Brute-force matching is straightforward and useful for understanding the problem, while KMP and Rabin-Karp provide more efficient approaches for larger inputs.
