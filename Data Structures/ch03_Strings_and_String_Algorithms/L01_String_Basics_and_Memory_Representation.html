2. What Is a String?

A string is a sequence of characters terminated by a special character called the null terminator, represented by '\0'.

Unlike some other programming languages, C does not have a separate built-in string data type. Strings are represented using arrays of characters. 

#include <stdio.h>

int main(void)
{
    char name[] = "Navdeep";

    printf("%s\n", name);

    return 0;
}
Expected Output: 
Navdeep

4. Character Array Declaration

There are several ways to declare and initialize a string in C.

Method 1: Initialize using a string literal

char name[] = "Hello";

The compiler allocates enough space for the characters and the null terminator.

Method 2: Specify the array size

char name[10] = "Hello";

The array has 10 character positions, with unused positions initialized to zero.

Method 3: Initialize character by character

char name[] = {'H', 'e', 'l', 'l', 'o', '\0'};

Method 4: Declare an uninitialized array

char name[20];

This array can store up to 19 ordinary characters followed by the null terminator, provided it is properly initialized before being used as a string.

5. Null Terminator in C

The null terminator '\0' marks the end of a C string. Functions that process strings use it to determine where the string ends.

Important: '\0' is a character with numeric value zero. It is not the same as the character '0', whose numeric character code is different.

Memory Representation

Consider the declaration:

char str[] = "CAT";
Array Index Stored Character Meaning
0'C'First character
1'A'Second character
2'T'Third character
3'\0'String terminator

Required storage: 4 bytes when CHAR_BIT is 8.

If an array does not contain a null terminator within its allocated bounds, passing it to functions expecting a C string can cause out-of-bounds reads and undefined behavior.

6. String Length and Array Size

Two commonly used expressions are strlen() and sizeof(). They do different things.

Expression Purpose
strlen(str) Counts characters before the first null terminator.
sizeof(str) Returns the size in bytes of the array object when str is an array. 
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "Hello";

    printf("String length = %zu\n", strlen(str));
    printf("Array size = %zu\n", sizeof(str));

    return 0;
}
Expected Output: 
String length = 5
Array size = 6

Why is the result different?

  • "Hello" contains five visible characters.
  • The array also stores one null terminator.
  • Therefore, the array contains six char elements.
Interview point: strlen() returns the string length, while sizeof() returns the size of the array object in bytes. When an array is passed to a function, it usually converts to a pointer, so sizeof() inside that function measures the pointer, not the original array.

7. Character Array vs Character Pointer

Compare these declarations:

char str1[] = "Hello";
const char *str2 = "Hello";
Character Array Character Pointer
Stores an array of characters. Stores the address of a character.
Its elements can be modified. When pointing to a string literal, the characters must not be modified.
Example: char str[] = "Hello"; Example: const char *p = "Hello"; 
#include <stdio.h>

int main(void)
{
    char str1[] = "Hello";
    const char *str2 = "World";

    str1[0] = 'Y';

    printf("Array: %s\n", str1);
    printf("Pointer: %s\n", str2);

    return 0;
}
Expected Output: 
Array: Yello
Pointer: World
Modifying a string literal through a pointer is undefined behavior. Use const char * when a pointer refers to a string literal and does not need to modify it.

8. Reading Strings from the User

Method 1: scanf()

The %s conversion reads a sequence of non-whitespace characters. It stops at a space, tab or newline. 

#include <stdio.h>

int main(void)
{
    char name[30];

    printf("Enter your name: ");

    if (scanf("%29s", name) == 1)
        printf("Name: %s\n", name);

    return 0;
}
Example Input: 
Navdeep
Expected Output: 
Enter your name: Name: Navdeep

The width limit 29 prevents writing more than 29 characters into a 30-element array, leaving space for '\0'.

Method 2: fgets()

fgets() reads a line of input, including spaces, up to the specified limit or until a newline is encountered. 

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];

    printf("Enter your full name: ");

    if (fgets(name, sizeof(name), stdin) != NULL)
    {
        name[strcspn(name, "\n")] = '\0';
        printf("Name: %s\n", name);
    }

    return 0;
}
Example Input: 
Navdeep Sangwan
Expected Output: 
Enter your full name: Name: Navdeep Sangwan
Placement point: Prefer fgets() for bounded line input when spaces are allowed. Always check its return value and account for the possibility that the input line is longer than the destination buffer.

9. Printing Strings and Characters

Format SpecifierPurpose

#include <stdio.h>

int main(void)
{
    char str[] = "C Programming";

    printf("String: %s\n", str);

    for (int i = 0; str[i] != '\0'; i++)
    {

    }

    printf("\n");

    return 0;
}
Expected Output:

10. Traversing a String Using an Array Index

A string can be traversed one character at a time until the null terminator is reached. 

#include <stdio.h>

int main(void)
{
    char str[] = "PLACEMENT";

    int i = 0;

    while (str[i] != '\0')
    {
        printf("Index %d: %c\n", i, str[i]);
        i++;
    }

    return 0;
}
Expected Output: 
Index 0: P
Index 1: L
Index 2: A
Index 3: C
Index 4: E
Index 5: M
Index 6: E
Index 7: N
Index 8: T

Time Complexity: O(n)

Auxiliary Space: O(1)

11. Basic String Library Functions

The standard header string.h provides commonly used functions for handling null-terminated strings.

FunctionPurpose
strlen()Returns string length.
strcpy()Copies a string into a destination.
strncpy()Copies up to a specified number of characters; may not null-terminate.
strcat()Appends one string to another.
strcmp()Compares two strings lexicographically.
strchr()Finds the first occurrence of a character.
strstr()Finds the first occurrence of a substring.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "Hello";
    char second[] = "World";

    printf("Length = %zu\n", strlen(first));

    strcat(first, " ");
    strcat(first, second);

    printf("Combined = %s\n", first);

    printf("Comparison = %d\n",
           strcmp("ABC", "ABC"));

    return 0;
}
Expected Output: 
Length = 5
Combined = Hello World
Comparison = 0
strcat() and strcpy() do not check destination capacity. Ensure the destination has sufficient space before using them. strncpy() is not automatically a safe replacement: it may leave the destination without a null terminator.

12. String Storage and Memory Concepts

Consider the following declaration:

char city[] = "Delhi";
  • The array has six elements.
  • Five elements store visible characters.
  • The sixth element stores '\0'.
  • Array elements occupy consecutive memory locations.
  • Each element has type char.

The C standard guarantees that sizeof(char) is 1 byte. A byte contains CHAR_BIT bits, which is at least 8. On typical modern systems, CHAR_BIT is 8.

Strings are not separate objects with hidden length metadata in C. The null terminator is what allows standard string functions to identify the end of a string.

13. Common String Errors in C

  1. Forgetting space for the null terminator.
  2. Using %s without a field width for bounded input.
  3. Using gets(), which is unsafe and removed from the C standard.
  4. Modifying a string literal.
  5. Using strlen() on a character array that is not null-terminated.
  6. Writing beyond the allocated array size.
  7. Comparing strings with == instead of strcmp().
  8. Assuming sizeof() returns the original array size inside a function.
  9. Ignoring the return value of fgets().
  10. Assuming strncpy() always adds a null terminator.

14. Complete Practical Program: String Length Without strlen()

Write a program to calculate the length of a string without using the built-in strlen() function. 

#include <stdio.h>

int main(void)
{
    char str[100];
    int length = 0;

    printf("Enter a string: ");

    if (fgets(str, sizeof(str), stdin) == NULL)
        return 1;

    while (str[length] != '\0' && str[length] != '\n')
    {
        length++;
    }

    printf("String length = %d\n", length);

    return 0;
}
Example Input: 
Embedded Systems
Expected Output: 
Enter a string: String length = 16

Time Complexity: O(n)

Auxiliary Space: O(1)

17. Placement Interview Questions and Answers

Q1. Does C have a built-in string data type?

No. C represents strings using character arrays or pointers to character sequences terminated by '\0'.

Q2. What is a null terminator?

It is the character '\0', which marks the end of a C string.

Q3. What is the difference between '\0' and '0'?

'\0' has numeric value zero. '0' is the printable digit character and has a different character value.

Q4. How much memory is required for "HELLO"?

Six char elements: five characters plus the null terminator.

Q5. What is the difference between strlen() and sizeof()?

strlen() counts characters before the null terminator. sizeof() gives the size of an object in bytes.

Q6. What happens if a string has no null terminator?

String functions may read beyond the array boundary, resulting in undefined behavior.

Q7. What is the difference between char str[] and const char *str?

The first declares a character array. The second declares a pointer to characters that should not be modified through that pointer.

Q8. Why is gets() unsafe?

It does not limit the number of characters read and can cause buffer overflow. It was removed from the C standard.

Q9. Why is fgets() preferred for reading a line?

It accepts a buffer size and can read spaces, helping prevent writes beyond the destination array.

Q10. Does scanf("%s", str) read spaces?

No. The %s conversion stops at the first whitespace character.

Q11. Which header provides strlen()?

string.h

Q12. What does strcmp() return when strings are equal?

It returns zero.

Q13. Can two strings be compared using ==?

Not for content comparison. Use strcmp() to compare string contents.

Q14. What does a string literal represent?

A sequence of characters with a terminating null character. Modifying a string literal has undefined behavior.

Q15. What is the time complexity of strlen()?

O(n), because it scans the string until the null terminator.

Q16. Why must a string array have an extra position?

It needs one additional element for the null terminator.

Q17. What happens when a character array is passed to a function?

In a function parameter declaration, an array parameter is adjusted to a pointer parameter. The function does not automatically receive the array length.

Q18. What is a buffer overflow?

It occurs when a program writes beyond the allocated memory of a buffer.

Q19. Is strlen() constant time?

No. It normally scans the characters until the null terminator, so its time complexity is O(n).

Q20. How do you safely store a string of at most 20 characters?

Use a character array of at least 21 elements to reserve space for the null terminator.
