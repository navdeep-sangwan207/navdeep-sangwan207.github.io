2. What Is Linked List Reversal?

Reversing a linked list means changing the direction of its links so that the last node becomes the first node.

Before Reversal

head
 |
 v
10 -> 20 -> 30 -> 40 -> NULL

After Reversal

head
 |
 v
40 -> 30 -> 20 -> 10 -> NULL

The node values do not change. Only the next pointers are modified.

3. Iterative Reversal Using Three Pointers

The most important placement approach uses three pointers:

  • prev: Points to the previous node.
  • current: Points to the node currently being processed.
  • nextNode: Temporarily stores the next node before changing the link.

Algorithm

  1. Initialize prev = NULL.
  2. Initialize current = head.
  3. Store current->next in nextNode.
  4. Change current->next to prev.
  5. Move prev to current.
  6. Move current to nextNode.
  7. Repeat until current becomes NULL.
  8. Update head to prev.

Pointer Dry Run

Original:
10 -> 20 -> 30 -> NULL

Initially:
prev = NULL
current = 10

Iteration 1:
10 -> NULL
prev = 10
current = 20

Iteration 2:
20 -> 10 -> NULL
prev = 20
current = 30

Iteration 3:
30 -> 20 -> 10 -> NULL
prev = 30
current = NULL

Final:
head = prev

30 -> 20 -> 10 -> NULL

C Function

struct Node *reverse_iterative(struct Node *head)
{
    struct Node *prev = NULL;
    struct Node *current = head;
    struct Node *nextNode = NULL;

    while (current != NULL)
    {
        nextNode = current->next;
        current->next = prev;

        prev = current;
        current = nextNode;
    }

    return prev;
}

Time complexity: O(n).

Auxiliary space: O(1).

This is one of the most frequently asked linked-list coding questions. Practice writing it without looking at the code.

4. Why Is the nextNode Pointer Necessary?

Consider the following statement:

current->next = prev;

It overwrites the original next pointer. If we do not save the next node first, the remaining list becomes inaccessible.

Therefore, always save the next pointer before reversing the link:

nextNode = current->next;
current->next = prev;

5. Recursive Reversal of a Linked List

Recursion reverses the remaining list first and then connects the current node at the end.

Recursive Logic

  1. If head is NULL or only one node exists, return head.
  2. Recursively reverse the list beginning at head->next.
  3. Make the next node point back to head.
  4. Set head->next to NULL.
  5. Return the new head.

C Function

struct Node *reverse_recursive(struct Node *head)
{
    if (head == NULL || head->next == NULL)
        return head;

    struct Node *newHead =
        reverse_recursive(head->next);

    head->next->next = head;
    head->next = NULL;

    return newHead;
}

Example

Original:
10 -> 20 -> 30 -> NULL

Recursive calls reach:
30

Returning from recursion:
30 -> 20
30 -> 20 -> 10

Final:
30 -> 20 -> 10 -> NULL

Time complexity: O(n).

Auxiliary space: O(n) due to the recursion call stack.

Recursive reversal can cause stack overflow for very long lists. Iterative reversal is generally preferred when constant auxiliary space is required.

6. Find the Middle Node of a Linked List

The slow and fast pointer technique finds the middle node in one traversal.

  • slow: Moves one node at a time.
  • fast: Moves two nodes at a time.

Example: Odd Number of Nodes

10 -> 20 -> 30 -> 40 -> 50 -> NULL
              ^
            Middle

Algorithm

  1. Initialize slow = head and fast = head.
  2. Move slow by one node.
  3. Move fast by two nodes.
  4. Continue while fast and fast->next are not NULL.
  5. When the loop ends, slow points to the middle node.

C Function

struct Node *find_middle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}

Time complexity: O(n).

Auxiliary space: O(1).

7. What Happens When the Number of Nodes Is Even?

For an even-length list, there are two middle nodes. The function above returns the second middle node.

Example

10 -> 20 -> 30 -> 40 -> NULL
              ^
       Second middle node

The two middle nodes are 20 and 30. The function returns 30.

Find the First Middle Node Instead

struct Node *find_first_middle(struct Node *head)
{
    if (head == NULL)
        return NULL;

    struct Node *slow = head;
    struct Node *fast = head->next;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}

For an even-length list, this version returns the first of the two middle nodes.

8. Find the Nth Node from the End

This problem is frequently asked in placement coding rounds.

Example

List:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

N = 2

Answer:
40

Two-Pointer Algorithm

  1. Initialize first and second pointers at head.
  2. Move first pointer N nodes ahead.
  3. If first becomes NULL before completing N steps, N is invalid.
  4. Move both pointers one node at a time until first reaches NULL.
  5. Second points to the Nth node from the end.

C Function

struct Node *nth_from_end(struct Node *head, size_t n)
{
    if (n == 0)
        return NULL;

    struct Node *first = head;
    struct Node *second = head;

    for (size_t i = 0; i < n; i++)
    {
        if (first == NULL)
            return NULL;

        first = first->next;
    }

    while (first != NULL)
    {
        first = first->next;
        second = second->next;
    }

    return second;
}

Time complexity: O(n).

Auxiliary space: O(1).

The two pointers maintain a gap of N nodes. When the first pointer reaches the end, the second pointer identifies the required node.

9. Detect Whether a Linked List Has a Cycle

The Floyd's Cycle Detection Algorithm uses slow and fast pointers.

Example

10 -> 20 -> 30 -> 40
           ^       |
           |_______|

The fast pointer eventually meets the slow pointer.

C Function

int has_cycle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return 1;
    }

    return 0;
}

Return value:

  • 1 means a cycle exists.
  • 0 means no cycle exists.

Time complexity: O(n).

Auxiliary space: O(1).

10. Find the Starting Node of a Cycle

After slow and fast pointers meet, reset one pointer to head. Move both pointers one node at a time. Their next meeting point is the cycle's starting node.

C Function

struct Node *cycle_start(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            slow = head;

            while (slow != fast)
            {
                slow = slow->next;
                fast = fast->next;
            }

            return slow;
        }
    }

    return NULL;
}

Time complexity: O(n).

Auxiliary space: O(1).

11. Check Whether a Linked List Is a Palindrome

A palindrome linked list reads the same from left to right and right to left.

Example

1 -> 2 -> 3 -> 2 -> 1 -> NULL

Palindrome: YES

1 -> 2 -> 3 -> 4 -> NULL

Palindrome: NO

Approach

  1. Find the middle node using slow and fast pointers.
  2. Reverse the second half of the list.
  3. Compare nodes in the first and second halves.
  4. Restore the second half if the original list must remain unchanged.

C Function

struct Node *reverse_list(struct Node *head)
{
    struct Node *prev = NULL;
    struct Node *current = head;

    while (current != NULL)
    {
        struct Node *nextNode = current->next;
        current->next = prev;
        prev = current;
        current = nextNode;
    }

    return prev;
}

int is_palindrome(struct Node *head)
{
    if (head == NULL || head->next == NULL)
        return 1;

    struct Node *slow = head;
    struct Node *fast = head;
    struct Node *previous_slow = NULL;

    while (fast != NULL && fast->next != NULL)
    {
        previous_slow = slow;
        slow = slow->next;
        fast = fast->next->next;
    }

    struct Node *second_half;

    if (fast != NULL)
    {
        /* Odd number of nodes: skip the middle node. */
        second_half = slow->next;
    }
    else
    {
        /* Even number of nodes. */
        second_half = slow;
    }

    struct Node *reversed = reverse_list(second_half);

    if (fast != NULL)
        slow->next = reversed;
    else
        previous_slow->next = reversed;

    int result = 1;
    struct Node *first = head;
    struct Node *second = reversed;

    while (second != NULL)
    {
        if (first->data != second->data)
        {
            result = 0;
            break;
        }

        first = first->next;
        second = second->next;
    }

    /* Restore the original second half. */
    struct Node *restored = reverse_list(reversed);

    if (fast != NULL)
        slow->next = restored;
    else
        previous_slow->next = restored;

    return result;
}

Time complexity: O(n).

Auxiliary space: O(1).

This implementation temporarily changes the second half of the list and restores it before returning. It assumes the input is a finite, acyclic singly linked list.

12. Complete C11 Program

This program demonstrates iterative reversal, middle-node detection, Nth-node-from-end and cycle detection.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

int append_node(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;

    return 1;
}

void display_list(const struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

struct Node *reverse_iterative(struct Node *head)
{
    struct Node *prev = NULL;
    struct Node *current = head;

    while (current != NULL)
    {
        struct Node *nextNode = current->next;
        current->next = prev;
        prev = current;
        current = nextNode;
    }

    return prev;
}

struct Node *find_middle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}

struct Node *nth_from_end(struct Node *head, size_t n)
{
    if (n == 0)
        return NULL;

    struct Node *first = head;
    struct Node *second = head;

    for (size_t i = 0; i < n; i++)
    {
        if (first == NULL)
            return NULL;

        first = first->next;
    }

    while (first != NULL)
    {
        first = first->next;
        second = second->next;
    }

    return second;
}

int has_cycle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return 1;
    }

    return 0;
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *nextNode = head->next;
        free(head);
        head = nextNode;
    }
}

int main(void)
{
    struct Node *head = NULL;

    if (!append_node(&head, 10) ||
        !append_node(&head, 20) ||
        !append_node(&head, 30) ||
        !append_node(&head, 40) ||
        !append_node(&head, 50))
    {
        printf("Memory allocation failed\n");
        free_list(head);
        return 1;
    }

    printf("Original list:\n");
    display_list(head);

    struct Node *middle = find_middle(head);

    if (middle != NULL)
        printf("Middle node: %d\n", middle->data);

    struct Node *second = nth_from_end(head, 2);

    if (second != NULL)
        printf("Second node from end: %d\n", second->data);

    printf("Cycle present: %s\n",
           has_cycle(head) ? "Yes" : "No");

    head = reverse_iterative(head);

    printf("Reversed list:\n");
    display_list(head);

    head = reverse_iterative(head);

    printf("Restored list:\n");
    display_list(head);

    free_list(head);

    return 0;
}

Expected Output

Original list:
10 -> 20 -> 30 -> 40 -> 50 -> NULL
Middle node: 30
Second node from end: 40
Cycle present: No
Reversed list:
50 -> 40 -> 30 -> 20 -> 10 -> NULL
Restored list:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

Compile and Run

gcc -std=c11 -Wall -Wextra -pedantic linked_list_reverse.c -o linked_list_reverse
./linked_list_reverse

14. Common Interview Mistakes

  1. Changing current->next before saving the original next pointer.
  2. Forgetting to update head after reversal.
  3. Returning the old head instead of the new head.
  4. Using incorrect loop conditions in slow-fast pointer algorithms.
  5. Not checking fast->next before accessing fast->next->next.
  6. Confusing the first middle and second middle for even-length lists.
  7. Not checking whether N is zero or greater than the list length.
  8. Forgetting that recursion consumes stack space.
  9. Failing to restore the second half after a palindrome check when the input must remain unchanged.
  10. Applying ordinary NULL-terminated list algorithms to a circular list without adapting them.

15. Placement Interview Questions and Answers

Q1. How do you reverse a singly linked list?

Answer: Use three pointers: prev, current and nextNode. Reverse each link and finally return prev as the new head.

Q2. What is the time complexity of iterative reversal?

Answer: O(n), because each node is processed once.

Q3. What is the auxiliary space complexity of iterative reversal?

Answer: O(1), because only a fixed number of pointers are used.

Q4. What is the space complexity of recursive reversal?

Answer: O(n), due to the recursion call stack.

Q5. Why do we need three pointers for iterative reversal?

Answer: To preserve the next node, reverse the current link and move safely through the list.

Q6. How do you find the middle node in one traversal?

Answer: Use slow and fast pointers. Move slow one step and fast two steps.

Q7. What does the slow pointer return for an even-length list?

Answer: With both pointers initialized at head, the common implementation returns the second middle node.

Q8. What is Floyd's Cycle Detection Algorithm?

Answer: An algorithm using slow and fast pointers to detect a cycle in a linked list.

Q9. What is the time complexity of Floyd's algorithm?

Answer: O(n).

Q10. What is the space complexity of Floyd's algorithm?

Answer: O(1).

Q11. How do you find the Nth node from the end?

Answer: Move the first pointer N nodes ahead, then move both pointers together until the first pointer reaches NULL.

Q12. What if N is greater than the number of nodes?

Answer: The function should report an invalid position, for example by returning NULL.

Q13. How do you detect the starting node of a cycle?

Answer: After the slow and fast pointers meet, reset slow to head and move both one step at a time. Their next meeting point is the cycle start.

Q14. How can you check whether a linked list is a palindrome?

Answer: Find the middle, reverse the second half, compare both halves and restore the second half if required.

Q15. Why is iterative reversal often preferred over recursive reversal?

Answer: It uses O(1) auxiliary space and avoids recursion stack overflow.

Q16. Can a linked list be reversed without changing node data?

Answer: Yes. Change only the next pointers.

Q17. What is the two-pointer technique?

Answer: A problem-solving approach that uses two pointers moving at different speeds or from different positions.

Q18. What is the advantage of finding the middle in one traversal?

Answer: It avoids calculating the list length first and then traversing again.

Q19. What is the difference between a cycle and a circular linked list?

Answer: A circular linked list is intentionally structured as a cycle. A cycle in a general linked list may be accidental or caused by an incorrect link.

Q20. Which linked-list problems commonly use slow and fast pointers?

Answer: Middle node, cycle detection, cycle-start detection, palindrome checking and certain list-intersection problems.
