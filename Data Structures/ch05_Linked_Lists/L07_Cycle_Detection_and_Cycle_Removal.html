2. What Is a Cycle in a Linked List?

A cycle exists when a node's next pointer links to a previously visited node instead of eventually reaching NULL.

Normal Linked List

10 -> 20 -> 30 -> 40 -> NULL

Linked List with a Cycle

10 -> 20 -> 30 -> 40
           ^       |
           |_______|

Here, node 40 points back to node 30. Traversal never reaches NULL.

A circular linked list is intentionally cyclic. In a general singly linked list, a cycle is usually something an algorithm must detect and handle.

3. Why Is Cycle Detection Important?

  • Prevents infinite traversal loops.
  • Helps validate linked-list structures.
  • Detects accidental pointer connections.
  • Tests pointer manipulation skills in coding interviews.
  • Helps diagnose memory and data-structure bugs.

4. Floyd's Cycle Detection Algorithm

Floyd's Cycle Detection Algorithm is also called the Tortoise and Hare Algorithm.

  • Slow pointer moves one node at a time.
  • Fast pointer moves two nodes at a time.
  • If there is no cycle, fast eventually reaches NULL.
  • If a cycle exists, the two pointers eventually meet inside the cycle.

Algorithm

  1. Initialize slow = head.
  2. Initialize fast = head.
  3. Check that fast and fast->next are not NULL.
  4. Move slow one node forward.
  5. Move fast two nodes forward.
  6. If slow == fast, a cycle exists.
  7. If fast reaches NULL, no cycle exists.

C Function

int has_cycle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return 1;
    }

    return 0;
}

Return values:

  • 1: Cycle detected.
  • 0: No cycle detected.

Time complexity: O(n).

Auxiliary space: O(1).

6. Find the Starting Node of a Cycle

Detecting a cycle is not enough in many interview problems. We may also need to find the exact node where the cycle begins.

Example

10 -> 20 -> 30 -> 40 -> 50
           ^              |
           |______________|

Cycle starting node = 30

Algorithm

  1. Run Floyd's cycle detection.
  2. When slow and fast meet, a cycle is confirmed.
  3. Reset slow to head.
  4. Keep fast at the meeting node.
  5. Move both pointers one node at a time.
  6. The node where they meet again is the cycle starting node.

C Function

struct Node *cycle_start(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            slow = head;

            while (slow != fast)
            {
                slow = slow->next;
                fast = fast->next;
            }

            return slow;
        }
    }

    return NULL;
}

Time complexity: O(n).

Auxiliary space: O(1).

7. Why Does Resetting One Pointer Work?

Let:

  • L: Distance from head to cycle starting node.
  • C: Length of the cycle.
  • x: Distance from cycle start to the meeting point.

When the pointers meet, the fast pointer has travelled twice the distance of the slow pointer.

Let the slow pointer travel L + x distance. The fast pointer travels 2(L + x).

The difference between their travelled distances is a whole number of cycle lengths:

\[ 2(L+x)-(L+x)=kC \] \[ L+x=kC \] Therefore: \[ L=kC-x \] This means that moving one pointer from the head and the other from the meeting point at the same speed makes them meet at the cycle starting node.
For interviews, understand the pointer movement and the distance relationship. You do not need to memorize the proof without understanding it.

8. Calculate the Length of a Cycle

After detecting a cycle, keep one pointer at the meeting node and move another pointer around the cycle until it returns to the same node.

Algorithm

  1. Detect a cycle using slow and fast pointers.
  2. If no cycle exists, return 0.
  3. Keep one pointer at the meeting node.
  4. Move another pointer around the cycle.
  5. Count the number of steps until it returns to the meeting node.

C Function

size_t cycle_length(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            size_t length = 1;
            struct Node *temp = slow->next;

            while (temp != slow)
            {
                length++;
                temp = temp->next;
            }

            return length;
        }
    }

    return 0;
}

Time complexity: O(n).

Auxiliary space: O(1).

9. Remove a Cycle from a Linked List

Once the cycle starting node is known, find the last node inside the cycle and change its next pointer to NULL.

Example

Before:
10 -> 20 -> 30 -> 40 -> 50
           ^              |
           |______________|

After:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

Algorithm

  1. Find the cycle starting node.
  2. If no cycle exists, return 0.
  3. Start a pointer at the cycle starting node.
  4. Move around the cycle until finding the node whose next points to the cycle start.
  5. Set that node's next pointer to NULL.

C Function

int remove_cycle(struct Node *head)
{
    struct Node *start = cycle_start(head);

    if (start == NULL)
        return 0;

    struct Node *last = start;

    while (last->next != start)
        last = last->next;

    last->next = NULL;

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

This method works for cycles that begin at the head as well as cycles that begin in the middle. The final node in the cycle is found by checking which node points back to the cycle start.

10. Special Case: Cycle Starts at the Head

Consider this structure:

10 -> 20 -> 30 -> 40
^                 |
|_________________|

The cycle starts at the head itself. The same cycle-start and removal functions handle this case.

The last node is identified as the node whose next pointer equals head. Setting that pointer to NULL removes the cycle.

11. Special Case: Self-Loop

A node may point to itself.

+------+
|      |
v      |
[10] --+

This is a cycle of length 1.

The cycle detection function detects it, the cycle length function returns 1, and the removal function sets its next pointer to NULL.

12. Cycle Detection Using a Hash Set

Another approach is to store visited node addresses in a hash set.

Logic

  1. Start from head.
  2. Check whether the current node address has already been visited.
  3. If yes, a cycle exists.
  4. Otherwise, store the address and move to the next node.
  5. If NULL is reached, no cycle exists.

Complexity:

  • Expected time: O(n), assuming efficient hashing.
  • Auxiliary space: O(n).
Floyd's algorithm is usually preferred in interviews because it achieves O(1) auxiliary space and does not require a hash table.

13. Complete C11 Program: Detect, Measure and Remove a Cycle

This program creates a linked list, deliberately introduces a cycle, detects it, identifies the starting node, calculates the cycle length, removes the cycle and safely frees the list.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

int append_node(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;

    return 1;
}

int has_cycle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return 1;
    }

    return 0;
}

struct Node *cycle_start(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            slow = head;

            while (slow != fast)
            {
                slow = slow->next;
                fast = fast->next;
            }

            return slow;
        }
    }

    return NULL;
}

size_t cycle_length(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            size_t length = 1;
            struct Node *temp = slow->next;

            while (temp != slow)
            {
                length++;
                temp = temp->next;
            }

            return length;
        }
    }

    return 0;
}

int remove_cycle(struct Node *head)
{
    struct Node *start = cycle_start(head);

    if (start == NULL)
        return 0;

    struct Node *last = start;

    while (last->next != start)
        last = last->next;

    last->next = NULL;

    return 1;
}

void display_list(const struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *nextNode = head->next;
        free(head);
        head = nextNode;
    }
}

int main(void)
{
    struct Node *head = NULL;

    if (!append_node(&head, 10) ||
        !append_node(&head, 20) ||
        !append_node(&head, 30) ||
        !append_node(&head, 40) ||
        !append_node(&head, 50))
    {
        printf("Memory allocation failed\n");
        free_list(head);
        return 1;
    }

    struct Node *cycleNode = head->next->next;
    struct Node *last = head;

    while (last->next != NULL)
        last = last->next;

    /* Introduce a cycle: 50 points to 30. */
    last->next = cycleNode;

    printf("Cycle detected: %s\n",
           has_cycle(head) ? "Yes" : "No");

    struct Node *start = cycle_start(head);

    if (start != NULL)
        printf("Cycle starting node: %d\n", start->data);

    printf("Cycle length: %zu\n", cycle_length(head));

    if (remove_cycle(head))
        printf("Cycle removed successfully\n");
    else
        printf("No cycle was present\n");

    printf("Cycle detected after removal: %s\n",
           has_cycle(head) ? "Yes" : "No");

    printf("List after cycle removal:\n");
    display_list(head);

    free_list(head);

    return 0;
}

Expected Output

Cycle detected: Yes
Cycle starting node: 30
Cycle length: 3
Cycle removed successfully
Cycle detected after removal: No
List after cycle removal:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

Compile and Run

gcc -std=c11 -Wall -Wextra -pedantic cycle_detection.c -o cycle_detection
./cycle_detection

15. Common Mistakes

  1. Checking fast->next without first checking whether fast is NULL.
  2. Moving the fast pointer only one node instead of two.
  3. Assuming that a meeting point is the cycle starting node.
  4. Forgetting to reset one pointer to head when finding the cycle start.
  5. Incorrectly calculating the cycle length.
  6. Removing a cycle by setting the wrong node's next pointer to NULL.
  7. Attempting normal list traversal before removing a cycle.
  8. Freeing nodes while the cycle still exists.
  9. Failing to test a self-loop and a cycle beginning at head.
  10. Assuming every linked list contains a cycle.

16. Placement Interview Questions and Answers

Q1. What is a cycle in a linked list?

Answer: A cycle exists when a node points to a previously visited node rather than eventually pointing to NULL.

Q2. What is Floyd's Cycle Detection Algorithm?

Answer: An algorithm using slow and fast pointers to detect a cycle.

Q3. Why is it called the Tortoise and Hare Algorithm?

Answer: Because one pointer moves slowly and the other moves twice as fast.

Q4. What happens if there is no cycle?

Answer: The fast pointer eventually reaches NULL.

Q5. What happens if a cycle exists?

Answer: The slow and fast pointers eventually meet inside the cycle.

Q6. What is the time complexity of Floyd's algorithm?

Answer: O(n).

Q7. What is its auxiliary space complexity?

Answer: O(1).

Q8. How do you find the cycle starting node?

Answer: Reset one pointer to head after the meeting and move both pointers one step at a time.

Q9. How do you calculate cycle length?

Answer: Start from the meeting node and count steps until the pointer returns to that node.

Q10. How do you remove a cycle?

Answer: Find the cycle start, locate the node whose next points to the start, and set that next pointer to NULL.

Q11. Can a cycle begin at the head?

Answer: Yes. A linked list can have its last node point directly to the head.

Q12. What is a self-loop?

Answer: A node whose next pointer points to itself. Its cycle length is one.

Q13. Can hash tables detect cycles?

Answer: Yes. Store visited node addresses and check whether an address appears again.

Q14. Why is Floyd's algorithm generally preferred over hashing?

Answer: It uses O(1) auxiliary space instead of O(n) expected storage for a hash set.

Q15. What is the difference between cycle detection and cycle removal?

Answer: Detection determines whether a cycle exists. Removal changes a pointer so that the list becomes NULL-terminated.

Q16. Can ordinary traversal be used on a cyclic list?

Answer: Not with a NULL termination condition, because it may never terminate.

Q17. Does cycle detection modify the list?

Answer: Floyd's detection algorithm only moves pointers and does not modify the list links.

Q18. What is the difference between a circular linked list and an accidental cycle?

Answer: A circular linked list is intentionally designed to loop back. An accidental cycle is an unexpected pointer connection in a structure that should terminate at NULL.

Q19. Can Floyd's algorithm detect a cycle of length one?

Answer: Yes. A self-loop is detected by the slow and fast pointers.

Q20. Which pointer should be changed to remove a cycle?

Answer: The next pointer of the last node in the cycle should be changed to NULL.

19. Lesson Summary

  • A cycle occurs when a next pointer links to an earlier node.
  • Floyd's algorithm uses slow and fast pointers.
  • The algorithm detects cycles in O(n) time and O(1) auxiliary space.
  • The cycle starting node can be found by resetting one pointer to head.
  • The cycle length can be measured by one complete traversal around the cycle.
  • Cycle removal requires setting the last node's next pointer to NULL.
  • Always remove a cycle before using ordinary NULL-terminated traversal or freeing the list.
