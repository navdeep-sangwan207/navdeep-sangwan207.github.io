2. Merge Two Sorted Linked Lists

Merging two sorted linked lists means combining their nodes into one sorted linked list.

Example

List A:
10 -> 30 -> 50 -> NULL

List B:
20 -> 40 -> 60 -> NULL

Merged List:
10 -> 20 -> 30 -> 40 -> 50 -> 60 -> NULL

Both input lists are already sorted in ascending order. We compare their current nodes and select the smaller value each time.

3. Iterative Approach Using a Dummy Node

A dummy node simplifies the merging process because it provides a fixed starting point for the result.

Algorithm

  1. Create a dummy node.
  2. Maintain a tail pointer initially pointing to the dummy node.
  3. Compare the current nodes of both input lists.
  4. Attach the smaller node to tail->next.
  5. Move the selected input pointer forward.
  6. Move tail forward.
  7. When one list becomes empty, attach the remaining nodes of the other list.
  8. Return dummy.next.

Dry Run

List A: 10 -> 30 -> 50
List B: 20 -> 40 -> 60

Compare 10 and 20:
Select 10

Compare 30 and 20:
Select 20

Compare 30 and 40:
Select 30

Compare 50 and 40:
Select 40

Compare 50 and 60:
Select 50

List A is empty:
Attach remaining 60

Result:
10 -> 20 -> 30 -> 40 -> 50 -> 60

C Function

struct Node *merge_sorted(
    struct Node *a,
    struct Node *b)
{
    struct Node dummy;
    struct Node *tail = &dummy;

    dummy.next = NULL;

    while (a != NULL && b != NULL)
    {
        if (a->data <= b->data)
        {
            tail->next = a;
            a = a->next;
        }
        else
        {
            tail->next = b;
            b = b->next;
        }

        tail = tail->next;
    }

    if (a != NULL)
        tail->next = a;
    else
        tail->next = b;

    return dummy.next;
}

Time complexity: O(n + m), where n and m are the lengths of the two lists.

Auxiliary space: O(1).

This implementation reuses the existing nodes. It does not allocate new data nodes. The original input lists become part of the merged list, so their original head pointers should no longer be treated as independent lists.

4. Recursive Approach to Merge Two Sorted Lists

The recursive approach selects the smaller head node and recursively merges the remaining lists.

C Function

struct Node *merge_sorted_recursive(
    struct Node *a,
    struct Node *b)
{
    if (a == NULL)
        return b;

    if (b == NULL)
        return a;

    if (a->data <= b->data)
    {
        a->next =
            merge_sorted_recursive(a->next, b);

        return a;
    }
    else
    {
        b->next =
            merge_sorted_recursive(a, b->next);

        return b;
    }
}

Time complexity: O(n + m).

Auxiliary space: O(n + m) in the worst case because of recursive calls.

For very long lists, recursive merging may exhaust the call stack. The iterative implementation is generally safer when constant auxiliary space is required.

5. Important Conditions for Merging

  • Both input lists must be sorted.
  • Both lists must be valid, NULL-terminated linked lists.
  • The two lists must not share nodes when using the in-place merging function above.
  • Duplicate values are allowed.
  • Empty input lists must be handled correctly.

Example: Duplicate Values

List A:
10 -> 20 -> 30

List B:
10 -> 20 -> 40

Merged:
10 -> 10 -> 20 -> 20 -> 30 -> 40

Using less-than-or-equal comparison makes the merge stable with respect to nodes from the first list when values are equal.

6. Remove Duplicates from a Sorted Linked List

In a sorted linked list, duplicate values appear next to each other. We can remove them with one traversal.

Example

Before:
10 -> 10 -> 20 -> 30 -> 30 -> 40 -> NULL

After:
10 -> 20 -> 30 -> 40 -> NULL

C Function

void remove_duplicates_sorted(struct Node *head)
{
    struct Node *current = head;

    while (current != NULL && current->next != NULL)
    {
        if (current->data == current->next->data)
        {
            struct Node *duplicate = current->next;

            current->next = duplicate->next;
            free(duplicate);
        }
        else
        {
            current = current->next;
        }
    }
}

Time complexity: O(n).

Auxiliary space: O(1).

Do not move current forward immediately after deleting a duplicate. There may be more than two consecutive nodes containing the same value.

7. Remove Duplicates from an Unsorted Linked List

For an unsorted list, duplicate values may appear anywhere.

Example

Before:
10 -> 20 -> 10 -> 30 -> 20 -> NULL

After:
10 -> 20 -> 30 -> NULL

Approach Without a Hash Table

For each node, scan the remaining list and delete nodes with the same value.

C Function

void remove_duplicates_unsorted(struct Node *head)
{
    struct Node *current = head;

    while (current != NULL)
    {
        struct Node *previous = current;
        struct Node *runner = current->next;

        while (runner != NULL)
        {
            if (runner->data == current->data)
            {
                struct Node *duplicate = runner;

                previous->next = runner->next;
                runner = runner->next;

                free(duplicate);
            }
            else
            {
                previous = runner;
                runner = runner->next;
            }
        }

        current = current->next;
    }
}

Time complexity: O(n²).

Auxiliary space: O(1).

A hash-based solution can achieve expected O(n) time with O(n) extra space.

8. Find the Intersection Point of Two Linked Lists

Two linked lists intersect when they share the same node in memory, not merely when they contain equal data values.

Example

List A:
10 -> 20 \
          30 -> 40 -> NULL
List B:  15 /

Intersection:
Node containing 30

The nodes containing 30 and 40 are physically shared by both lists.

Two-Pointer Approach

  1. Initialize pointer A at the head of list A.
  2. Initialize pointer B at the head of list B.
  3. Move both pointers one node at a time.
  4. When a pointer reaches NULL, redirect it to the other list's head.
  5. If an intersection exists, both pointers meet at the same node.
  6. If no intersection exists, both eventually become NULL.

C Function

struct Node *find_intersection(
    struct Node *headA,
    struct Node *headB)
{
    struct Node *a = headA;
    struct Node *b = headB;

    while (a != b)
    {
        a = (a == NULL) ? headB : a->next;
        b = (b == NULL) ? headA : b->next;
    }

    return a;
}

Time complexity: O(n + m).

Auxiliary space: O(1).

Always compare node addresses (a == b), not data values. Two separate nodes can contain the same integer without being an intersection.

9. Find the Kth Node from the Beginning

This is a basic but frequently used linked-list operation.

C Function

struct Node *kth_from_beginning(
    struct Node *head,
    size_t k)
{
    if (k == 0)
        return NULL;

    size_t position = 1;

    while (head != NULL && position < k)
    {
        head = head->next;
        position++;
    }

    return head;
}

Time complexity: O(n).

Auxiliary space: O(1).

Positions in this function are one-based: k = 1 returns the first node.

10. Rotate a Linked List by K Positions

Right rotation moves the last K nodes to the beginning.

Example

Original:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

K = 2

After right rotation:
40 -> 50 -> 10 -> 20 -> 30 -> NULL

C Function

struct Node *rotate_right(struct Node *head, size_t k)
{
    if (head == NULL || head->next == NULL || k == 0)
        return head;

    size_t length = 1;
    struct Node *tail = head;

    while (tail->next != NULL)
    {
        tail = tail->next;
        length++;
    }

    k %= length;

    if (k == 0)
        return head;

    size_t steps = length - k;
    struct Node *newTail = head;

    for (size_t i = 1; i < steps; i++)
        newTail = newTail->next;

    struct Node *newHead = newTail->next;

    tail->next = head;
    newTail->next = NULL;

    return newHead;
}

Time complexity: O(n).

Auxiliary space: O(1).

The expression k %= length handles large rotation counts efficiently. Rotating a list by its full length produces the original list.

11. Sort a Linked List Using Merge Sort

Merge sort is particularly suitable for linked lists because merging can be performed by changing pointers instead of shifting array elements.

Example

Unsorted:
40 -> 10 -> 30 -> 20 -> NULL

Sorted:
10 -> 20 -> 30 -> 40 -> NULL

Merge Sort Steps

  1. Find the middle of the list using slow and fast pointers.
  2. Split the list into two halves.
  3. Recursively sort both halves.
  4. Merge the two sorted halves.

Complete Merge Sort Functions

struct Node *merge_for_sort(
    struct Node *a,
    struct Node *b)
{
    struct Node dummy;
    struct Node *tail = &dummy;

    dummy.next = NULL;

    while (a != NULL && b != NULL)
    {
        if (a->data <= b->data)
        {
            tail->next = a;
            a = a->next;
        }
        else
        {
            tail->next = b;
            b = b->next;
        }

        tail = tail->next;
    }

    tail->next = (a != NULL) ? a : b;

    return dummy.next;
}

struct Node *merge_sort(struct Node *head)
{
    if (head == NULL || head->next == NULL)
        return head;

    struct Node *slow = head;
    struct Node *fast = head->next;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;
    }

    struct Node *second = slow->next;
    slow->next = NULL;

    struct Node *left = merge_sort(head);
    struct Node *right = merge_sort(second);

    return merge_for_sort(left, right);
}

Time complexity: O(n log n).

Auxiliary space: O(log n) for recursion stack. The merge itself uses O(1) auxiliary space.

12. Complete C11 Program: Merge Two Sorted Lists

This program creates two sorted lists, merges them, removes duplicates and prints the final result.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

int append_node(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;

    return 1;
}

void display_list(const struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

struct Node *merge_sorted(
    struct Node *a,
    struct Node *b)
{
    struct Node dummy;
    struct Node *tail = &dummy;

    dummy.next = NULL;

    while (a != NULL && b != NULL)
    {
        if (a->data <= b->data)
        {
            tail->next = a;
            a = a->next;
        }
        else
        {
            tail->next = b;
            b = b->next;
        }

        tail = tail->next;
    }

    tail->next = (a != NULL) ? a : b;

    return dummy.next;
}

void remove_duplicates_sorted(struct Node *head)
{
    struct Node *current = head;

    while (current != NULL && current->next != NULL)
    {
        if (current->data == current->next->data)
        {
            struct Node *duplicate = current->next;

            current->next = duplicate->next;
            free(duplicate);
        }
        else
        {
            current = current->next;
        }
    }
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *nextNode = head->next;
        free(head);
        head = nextNode;
    }
}

int main(void)
{
    struct Node *listA = NULL;
    struct Node *listB = NULL;

    if (!append_node(&listA, 10) ||
        !append_node(&listA, 30) ||
        !append_node(&listA, 50) ||
        !append_node(&listB, 20) ||
        !append_node(&listB, 30) ||
        !append_node(&listB, 60))
    {
        printf("Memory allocation failed\n");
        free_list(listA);
        free_list(listB);
        return 1;
    }

    printf("First sorted list:\n");
    display_list(listA);

    printf("Second sorted list:\n");
    display_list(listB);

    struct Node *merged = merge_sorted(listA, listB);

    /* The original list heads are now part of merged. */
    listA = NULL;
    listB = NULL;

    printf("Merged sorted list:\n");
    display_list(merged);

    remove_duplicates_sorted(merged);

    printf("After removing duplicates:\n");
    display_list(merged);

    free_list(merged);

    return 0;
}

Expected Output

First sorted list:
10 -> 30 -> 50 -> NULL
Second sorted list:
20 -> 30 -> 60 -> NULL
Merged sorted list:
10 -> 20 -> 30 -> 30 -> 50 -> 60 -> NULL
After removing duplicates:
10 -> 20 -> 30 -> 50 -> 60 -> NULL

gcc -std=c11 -Wall -Wextra -pedantic merge_sorted_lists.c -o merge_sorted_lists
./merge_sorted_lists

14. Common Interview Mistakes

  1. Trying to merge lists that are not sorted.
  2. Forgetting to attach the remaining nodes after one list becomes empty.
  3. Allocating unnecessary new nodes when pointer reuse is sufficient.
  4. Not considering empty input lists.
  5. Confusing equal data values with a shared intersection node.
  6. Deleting duplicate nodes without freeing allocated memory.
  7. Using the sorted-list duplicate-removal algorithm on an unsorted list.
  8. Forgetting to split a list correctly before merge sort recursion.
  9. Using a recursive algorithm without considering stack usage.
  10. Attempting to free both original list heads after an in-place merge, causing double-free errors.

15. Placement Interview Questions and Answers

Q1. How do you merge two sorted linked lists?

Answer: Compare the current nodes of both lists, attach the smaller node to the result and advance that list's pointer.

Q2. What is the time complexity of merging two sorted lists?

Answer: O(n + m), where n and m are the lengths of the two lists.

Q3. Why is a dummy node useful?

Answer: It avoids separate handling for the first node of the result and simplifies pointer management.

Q4. Does iterative merging require new data nodes?

Answer: No. It can reuse existing nodes by changing their next pointers.

Q5. What happens to the original input lists after in-place merging?

Answer: Their nodes become part of one merged list. They should not be independently freed or traversed as separate lists.

Q6. Can duplicate values occur in a merged list?

Answer: Yes. Both input lists may contain equal values.

Q7. What is the difference between merging and concatenating?

Answer: Concatenation joins one list after another. Merging combines elements in sorted order.

Q8. How do you remove duplicates from a sorted linked list?

Answer: Compare each node with its next node and delete the next node when their values are equal.

Q9. How do you remove duplicates from an unsorted linked list without extra memory?

Answer: Use two nested traversals, resulting in O(n²) time and O(1) auxiliary space.

Q10. What is the intersection of two linked lists?

Answer: It is a node shared physically by both lists, meaning both lists refer to the same memory address.

Q11. Why compare node addresses when finding intersection?

Answer: Equal data values do not prove that two nodes are the same node.

Q12. What is the two-pointer method for finding intersection?

Answer: Each pointer traverses its own list and then the other list. If an intersection exists, the pointers meet at the shared node.

Q13. How do you sort a linked list efficiently?

Answer: Merge sort is commonly used because splitting and merging can be done through pointer changes.

Q14. What is the time complexity of merge sort on a linked list?

Answer: O(n log n).

Q15. Why is merge sort suitable for linked lists?

Answer: It does not require random access or shifting elements, unlike many array-oriented sorting approaches.

Q16. How do you rotate a linked list by K positions?

Answer: Find the length, reduce K modulo the length, locate the new tail and reconnect the links.

Q17. What happens when K equals the list length?

Answer: The list remains unchanged because K modulo length is zero.

Q18. What is the difference between iterative and recursive merging?

Answer: Iterative merging uses constant auxiliary space, while recursive merging uses stack space proportional to the number of selected nodes.

Q19. Can two lists intersect more than once?

Answer: For ordinary acyclic singly linked lists, once they share a node, all subsequent nodes are shared. They cannot separate and intersect again.

Q20. Which linked-list problems are commonly asked in fresher interviews?

Answer: Reversal, middle node, cycle detection, merging sorted lists, duplicate removal, intersection, rotation and merge sort.
