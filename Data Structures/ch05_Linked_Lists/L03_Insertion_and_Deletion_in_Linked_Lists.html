2. Node Structure

A singly linked list node contains data and a pointer to the next node.

struct Node
{
    int data;
    struct Node *next;
};

Example:

head
 |
 v
[10 | next] -> [20 | next] -> [30 | NULL]

Insertion creates a new node and adjusts links. Deletion removes a node and releases its allocated memory.

3. Creating a Node

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

The function returns NULL if memory allocation fails.

4. Insertion at the Beginning

In this operation, the new node becomes the first node of the list.

Example

Before:
20 -> 30 -> 40 -> NULL

Insert 10 at beginning

After:
10 -> 20 -> 30 -> 40 -> NULL

Algorithm

  1. Create a new node.
  2. Set newNode->next to the current head.
  3. Update head to newNode.

C Function

int insert_beginning(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = *head;
    *head = newNode;

    return 1;
}
A pointer-to-pointer is used because the function must update the caller's head pointer.

Time complexity: O(1).

Auxiliary space: O(1), excluding the newly allocated node.

5. Insertion at the End

In this operation, the new node is connected after the current last node.

Example

Before:
10 -> 20 -> 30 -> NULL

Insert 40 at end

After:
10 -> 20 -> 30 -> 40 -> NULL

Algorithm

  1. Create a new node.
  2. If the list is empty, make it the head.
  3. Otherwise, traverse until the last node.
  4. Set the last node's next pointer to the new node.

C Function

int insert_end(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;

    return 1;
}

Time complexity: O(n) without a tail pointer.

Auxiliary space: O(1), excluding the newly allocated node.

6. Insertion at a Specific Position

We use zero-based indexing in this lesson.

Example

Original list:
10 -> 20 -> 40 -> NULL

Insert 30 at position 2

Updated list:
10 -> 20 -> 30 -> 40 -> NULL

Position Rules

  • Position 0 means insertion at the beginning.
  • Position 1 means insertion after the first node.
  • Position equal to the current node count means insertion at the end.
  • Position greater than the node count is invalid.

C Function

int insert_at_position(struct Node **head,
                       int value,
                       size_t position)
{
    if (head == NULL)
        return 0;

    if (position == 0)
        return insert_beginning(head, value);

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        if (temp == NULL)
            return 0;

        temp = temp->next;
    }

    if (temp == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = temp->next;
    temp->next = newNode;

    return 1;
}

Time complexity: O(n) in the worst case.

Auxiliary space: O(1), excluding the newly allocated node.

The new node's next pointer must be assigned before changing temp->next. Otherwise, the remainder of the linked list could become unreachable.

7. Deletion from the Beginning

Deletion at the beginning removes the current head node.

Example

Before:
10 -> 20 -> 30 -> NULL

Delete first node

After:
20 -> 30 -> NULL

Algorithm

  1. Check whether the list is empty.
  2. Store the current head in a temporary pointer.
  3. Move head to head->next.
  4. Free the old first node.

C Function

int delete_beginning(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    *head = (*head)->next;

    free(temp);

    return 1;
}

Time complexity: O(1).

Auxiliary space: O(1).

8. Deletion from the End

Deletion at the end removes the last node.

Example

Before:
10 -> 20 -> 30 -> NULL

Delete last node

After:
10 -> 20 -> NULL

Algorithm

  1. Check whether the list is empty.
  2. If only one node exists, free it and set head to NULL.
  3. Otherwise, traverse until the second-last node.
  4. Free the last node.
  5. Set the second-last node's next pointer to NULL.

C Function

int delete_end(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    if (temp->next == NULL)
    {
        free(temp);
        *head = NULL;
        return 1;
    }

    while (temp->next->next != NULL)
        temp = temp->next;

    free(temp->next);
    temp->next = NULL;

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

A singly linked list cannot move backwards. Therefore, finding the second-last node requires traversal from the head.

9. Deletion at a Specific Position

Delete the node at a specified zero-based position.

Example

Original list:
10 -> 20 -> 30 -> 40 -> NULL

Delete position 2

Updated list:
10 -> 20 -> 40 -> NULL

Algorithm

  1. Check whether the list is empty.
  2. If position is zero, delete the first node.
  3. Otherwise, traverse to the node immediately before the target.
  4. Check whether the target node exists.
  5. Save the target node's address.
  6. Bypass the target node by changing the previous node's next pointer.
  7. Free the deleted node.

C Function

int delete_at_position(struct Node **head, size_t position)
{
    if (head == NULL || *head == NULL)
        return 0;

    if (position == 0)
        return delete_beginning(head);

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        if (temp == NULL)
            return 0;

        temp = temp->next;
    }

    if (temp == NULL || temp->next == NULL)
        return 0;

    struct Node *target = temp->next;

    temp->next = target->next;

    free(target);

    return 1;
}

Time complexity: O(n) in the worst case.

Auxiliary space: O(1).

10. Deletion by Value

Sometimes a coding problem asks us to delete the first node containing a particular value rather than deleting by position.

Example

Before:
10 -> 20 -> 30 -> 20 -> NULL

Delete first occurrence of 20

After:
10 -> 30 -> 20 -> NULL

C Function

int delete_by_value(struct Node **head, int value)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *current = *head;
    struct Node *previous = NULL;

    while (current != NULL && current->data != value)
    {
        previous = current;
        current = current->next;
    }

    if (current == NULL)
        return 0;

    if (previous == NULL)
        *head = current->next;
    else
        previous->next = current->next;

    free(current);

    return 1;
}

This function deletes only the first occurrence of the value.

Time complexity: O(n) worst case.

Auxiliary space: O(1).

11. Complete C11 Program: Insertion and Deletion Operations

The following program implements all the insertion and deletion operations covered in this lesson.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

void display_list(const struct Node *head)
{
    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

int insert_beginning(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = *head;
    *head = newNode;

    return 1;
}

int insert_end(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;

    return 1;
}

int insert_at_position(struct Node **head,
                       int value,
                       size_t position)
{
    if (head == NULL)
        return 0;

    if (position == 0)
        return insert_beginning(head, value);

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        if (temp == NULL)
            return 0;

        temp = temp->next;
    }

    if (temp == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = temp->next;
    temp->next = newNode;

    return 1;
}

int delete_beginning(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    *head = (*head)->next;

    free(temp);

    return 1;
}

int delete_end(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    if (temp->next == NULL)
    {
        free(temp);
        *head = NULL;
        return 1;
    }

    while (temp->next->next != NULL)
        temp = temp->next;

    free(temp->next);
    temp->next = NULL;

    return 1;
}

int delete_at_position(struct Node **head, size_t position)
{
    if (head == NULL || *head == NULL)
        return 0;

    if (position == 0)
        return delete_beginning(head);

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        if (temp == NULL)
            return 0;

        temp = temp->next;
    }

    if (temp == NULL || temp->next == NULL)
        return 0;

    struct Node *target = temp->next;

    temp->next = target->next;

    free(target);

    return 1;
}

int delete_by_value(struct Node **head, int value)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *current = *head;
    struct Node *previous = NULL;

    while (current != NULL && current->data != value)
    {
        previous = current;
        current = current->next;
    }

    if (current == NULL)
        return 0;

    if (previous == NULL)
        *head = current->next;
    else
        previous->next = current->next;

    free(current);

    return 1;
}

void free_list(struct Node **head)
{
    if (head == NULL)
        return;

    struct Node *temp;

    while (*head != NULL)
    {
        temp = *head;
        *head = (*head)->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = NULL;

    insert_end(&head, 20);
    insert_end(&head, 30);
    insert_end(&head, 40);

    printf("Initial list: ");
    display_list(head);

    insert_beginning(&head, 10);

    printf("After insertion at beginning: ");
    display_list(head);

    insert_end(&head, 50);

    printf("After insertion at end: ");
    display_list(head);

    if (insert_at_position(&head, 25, 2))
        printf("Insertion at position 2 successful\n");

    printf("After insertion at position: ");
    display_list(head);

    if (delete_beginning(&head))
        printf("First node deleted\n");

    printf("After deletion at beginning: ");
    display_list(head);

    if (delete_end(&head))
        printf("Last node deleted\n");

    printf("After deletion at end: ");
    display_list(head);

    if (delete_at_position(&head, 1))
        printf("Node at position 1 deleted\n");

    printf("After deletion at position: ");
    display_list(head);

    if (delete_by_value(&head, 30))
        printf("First occurrence of 30 deleted\n");

    printf("After deletion by value: ");
    display_list(head);

    free_list(&head);

    printf("All allocated nodes released\n");

    return 0;
}

14. Time Complexity Comparison

OperationTime ComplexityReason
Insert at beginningO(1)Only head and new node links change.
Insert at endO(n)Traverse to the last node.
Insert at positionO(n)Traverse to the previous node.
Delete at beginningO(1)Update head and free old node.
Delete at endO(n)Find the second-last node.
Delete at positionO(n)Find the previous node.
Delete by valueO(n)Search for the first matching node.

All these operations use O(1) auxiliary space in their iterative implementations, excluding the memory allocated for an inserted node.

15. Common Interview Mistakes

  1. Forgetting to update head after insertion or deletion at the beginning.
  2. Dereferencing head when the list is empty.
  3. Changing links in the wrong order during insertion.
  4. Freeing a node before saving the pointer needed to continue traversal.
  5. Forgetting to set the new last node's next pointer to NULL.
  6. Failing to handle a list containing only one node.
  7. Using an invalid position without checking whether the target exists.
  8. Forgetting to free deleted nodes, causing memory leaks.
  9. Accessing a node after it has been freed, causing use-after-free.
  10. Using a single pointer when the function needs to modify the caller's head pointer.

16. Placement Interview Questions and Answers

Q1. What is insertion in a linked list?

Answer: Insertion is the operation of adding a new node and connecting it to the existing linked-list structure.

Q2. What is deletion in a linked list?

Answer: Deletion removes a node by adjusting links and releasing its allocated memory.

Q3. What is the time complexity of insertion at the beginning?

Answer: O(1).

Q4. What is the time complexity of insertion at the end?

Answer: O(n) without a tail pointer.

Q5. Why is insertion at the beginning faster?

Answer: It does not require traversal. Only two pointer assignments are needed after allocation.

Q6. Why do we use a double pointer for insertion at the beginning?

Answer: The function needs to modify the original head pointer in the caller.

Q7. What happens when we delete the only node?

Answer: The node is freed and head is set to NULL.

Q8. Why must we free a deleted node?

Answer: Because dynamically allocated memory must be released to avoid memory leaks.

Q9. What is the complexity of deleting the last node in a singly linked list?

Answer: O(n), because the second-last node must be located.

Q10. Why can we not directly access the previous node?

Answer: A singly linked list stores only the next pointer, not a previous pointer.

Q11. What is zero-based indexing?

Answer: The first node is at position 0, the second at position 1, and so on.

Q12. What is the condition for insertion at the end by position?

Answer: The insertion position must equal the current number of nodes.

Q13. What is the condition for deleting a node at a position?

Answer: The position must be less than the current number of nodes.

Q14. What is a dangling pointer?

Answer: A pointer that still refers to memory after that memory has been freed.

Q15. What is a memory leak?

Answer: Dynamically allocated memory that is no longer reachable but has not been released.

Q16. Can insertion at the end be O(1)?

Answer: Yes, if the list maintains a tail pointer and updates it correctly.

Q17. What happens if malloc() fails during insertion?

Answer: It returns NULL. The function should report failure without modifying the existing list.

Q18. What is the difference between deletion by position and deletion by value?

Answer: Deletion by position removes a node at a specified index. Deletion by value searches for and removes a node containing the target value.

Q19. Why should we save target->next before freeing target?

Answer: The next node's address is needed to reconnect the list or continue traversal. Accessing a freed node is invalid.

Q20. What is the most important pointer operation during deletion?

Answer: Updating the previous node's next pointer so that it bypasses the deleted node.

19. Lesson Summary

  • Insertion adds a new node to a linked list.
  • Deletion removes an existing node and frees its memory.
  • Insertion and deletion at the beginning take O(1) time.
  • End and positional operations generally require O(n) traversal.
  • A pointer-to-pointer allows functions to modify the caller's head pointer.
  • Always handle empty lists, single-node lists and invalid positions.
  • Correct pointer-update order is essential to avoid losing nodes.
