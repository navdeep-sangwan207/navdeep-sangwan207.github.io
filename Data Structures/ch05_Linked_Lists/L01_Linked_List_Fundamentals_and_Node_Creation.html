2. What Is a Linked List?

A linked list is a linear data structure in which elements are stored in separate memory blocks called nodes.

Each node generally contains:

  1. Data: The actual value stored in the node.
  2. Link: A pointer containing the address of another node.

In a singly linked list, each node points to the next node.

Example

HEAD
 |
 v
+------+------+
|  10  |   o----+
+------+------+ |
               v
        +------+------+
        |  20  |   o----+
        +------+------+ |
                       v
                +------+------+
                |  30  | NULL |
                +------+------+

Here:

  • The first node stores 10.
  • The second node stores 20.
  • The third node stores 30.
  • The final node points to NULL.
  • HEAD stores the address of the first node.
Important: A linked list does not require its nodes to be stored in consecutive memory locations. The links connect nodes using their addresses.

3. Why Do We Need Linked Lists?

Arrays have a fixed size when declared with a fixed-length array, and inserting or deleting elements in the middle can require shifting elements.

Linked lists provide dynamic node allocation and allow insertion or deletion by changing links rather than shifting an entire sequence of elements.

Array vs Linked List

Feature Array Linked List
Memory layoutContiguous elementsNodes can be scattered
SizeFixed for a normal declared arrayCan grow or shrink dynamically
Access by indexO(1)O(n)
Insertion at beginningO(n) due to shiftingO(1) when head is available
Deletion at beginningO(n) due to shiftingO(1) when head is available
Memory overheadUsually no link pointer per elementRequires pointer storage per node
Binary searchEfficient on sorted arraysNot efficient because there is no direct middle access
Linked lists do not automatically make every insertion or deletion O(1). Finding the required position can take O(n). The O(1) operation applies when the required node or its predecessor is already available.

4. Types of Linked Lists

1. Singly Linked List

Each node contains data and a pointer to the next node.

HEAD
 |
 v
[10 | next] -> [20 | next] -> [30 | NULL]

2. Doubly Linked List

Each node contains a pointer to the previous node and another pointer to the next node.

NULL <- [10] <-> [20] <-> [30] -> NULL

3. Circular Singly Linked List

The last node points back to the first node instead of NULL.

HEAD
 |
 v
[10] -> [20] -> [30]
 ^                |
 |________________|

4. Circular Doubly Linked List

Each node has previous and next pointers. The last and first nodes are connected in both directions.

5. Understanding a Node in C

In C, we can create a node using a structure.

struct Node
{
    int data;
    struct Node *next;
};

Explanation:

  • struct Node defines a structure type.
  • int data stores the node's integer value.
  • struct Node *next stores the address of the next node.

Why Does a Structure Contain a Pointer to Its Own Type?

This is called a self-referential structure.

A structure cannot contain a complete object of its own type as a direct member because that would require infinite size. However, it can contain a pointer to its own type because the pointer has a known size.

Interview point: A linked-list node is commonly implemented as a self-referential structure in C.

6. Understanding the Head Pointer

The head pointer stores the address of the first node in a linked list.

struct Node *head = NULL;

Initially, the list is empty, so head is NULL.

After creating nodes, head points to the first node.

head
 |
 v
+------+------+
|  10  |   o----+
+------+------+ |
               v
        +------+------+
        |  20  | NULL |
        +------+------+

We use NULL to indicate that a pointer does not currently point to a valid node.

7. Dynamic Memory Allocation Using malloc()

Linked-list nodes are generally created dynamically at runtime using malloc().

Syntax

pointer = malloc(sizeof(struct Node));

malloc() allocates the requested number of bytes and returns a pointer to the allocated memory. It returns NULL if allocation fails.

Example

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node *newNode;

    newNode = malloc(sizeof(struct Node));

    if (newNode == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    newNode->data = 10;
    newNode->next = NULL;

    printf("Data = %d\n", newNode->data);

    free(newNode);

    return 0;
}
Expected output: 
Data = 10

Understanding the Arrow Operator

When a pointer points to a structure, use the arrow operator to access its members.

newNode->data = 10;

This is equivalent to:

(*newNode).data = 10;

8. Difference Between malloc() and calloc()

Featuremalloc()calloc()
PurposeAllocates a block of memoryAllocates memory for an array of elements
ArgumentsOne argument: total bytesTwo arguments: element count and element size
Initial contentsIndeterminateAll allocated bytes are initialized to zero
Return valuePointer to allocated memory or NULLPointer to allocated memory or NULL

Syntax

int *p = malloc(5 * sizeof *p);

int *q = calloc(5, sizeof *q);
Both functions return dynamically allocated memory that must eventually be released using free() when it is no longer required.

9. Creating the First Node

Let's create a single node dynamically.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node *head = NULL;

    head = malloc(sizeof *head);

    if (head == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    head->data = 100;
    head->next = NULL;

    printf("Node data: %d\n", head->data);
    printf("Next pointer: %p\n", (void *)head->next);

    free(head);
    head = NULL;

    return 0;
}
Expected output: 
Node data: 100
Next pointer: (nil)

The exact NULL pointer representation printed by %p is implementation-dependent. It may appear as (nil) or another representation.

10. Creating Multiple Nodes and Connecting Them

Now create three separate nodes and connect them using their next pointers.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node *head = NULL;
    struct Node *second = NULL;
    struct Node *third = NULL;

    head = malloc(sizeof *head);
    second = malloc(sizeof *second);
    third = malloc(sizeof *third);

    if (head == NULL || second == NULL || third == NULL)
    {
        printf("Memory allocation failed\n");

        free(head);
        free(second);
        free(third);

        return 1;
    }

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    printf("%d -> ", head->data);
    printf("%d -> ", head->next->data);
    printf("%d -> NULL\n", head->next->next->data);

    free(third);
    free(second);
    free(head);

    return 0;
}
Expected output: 
10 -> 20 -> 30 -> NULL

Memory Connection

head
 |
 v
+------+------+
|  10  |   o----+
+------+------+ |
               |
               v
        +------+------+
        |  20  |   o----+
        +------+------+ |
                       |
                       v
                +------+------+
                |  30  | NULL |
                +------+------+
The three nodes may be located at unrelated memory addresses. The next pointers maintain the logical order of the list.

11. Creating a Node Using a Function

In real programs, node creation is commonly placed inside a reusable function.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

int main(void)
{
    struct Node *head = create_node(10);

    if (head == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    struct Node *second = create_node(20);

    if (second == NULL)
    {
        free(head);
        printf("Memory allocation failed\n");
        return 1;
    }

    head->next = second;

    printf("First node = %d\n", head->data);
    printf("Second node = %d\n", head->next->data);

    free(second);
    free(head);

    return 0;
}
Expected output: 
First node = 10
Second node = 20

Why Return a Pointer?

The function returns the address of the dynamically allocated node. The caller can then connect it to the existing linked list.

12. Traversing a Linked List

Traversal means visiting each node from the head until NULL is reached.

Algorithm

  1. Initialize a temporary pointer with head.
  2. Check whether the temporary pointer is NULL.
  3. Print or process the current node's data.
  4. Move to the next node.
  5. Repeat until NULL is reached.

C Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node *head = malloc(sizeof *head);
    struct Node *second = malloc(sizeof *second);
    struct Node *third = malloc(sizeof *third);

    if (head == NULL || second == NULL || third == NULL)
    {
        free(head);
        free(second);
        free(third);
        return 1;
    }

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    struct Node *temp = head;

    while (temp != NULL)
    {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }

    printf("NULL\n");

    free(third);
    free(second);
    free(head);

    return 0;
}
Expected output: 
10 -> 20 -> 30 -> NULL

Time complexity: O(n), because every node is visited once.

Auxiliary space: O(1), because only one temporary pointer is used.

13. Understanding free() and Memory Management

Memory allocated using malloc() or calloc() remains allocated until it is released.

Use free() when dynamically allocated memory is no longer needed.

Example

struct Node *newNode = malloc(sizeof *newNode);

if (newNode != NULL)
{
    newNode->data = 50;
    newNode->next = NULL;

    free(newNode);
    newNode = NULL;
}

Important Memory Management Terms

  • Memory leak: Allocated memory is no longer reachable and has not been released.
  • Dangling pointer: A pointer still refers to memory that has been released or is otherwise no longer valid.
  • NULL pointer: A pointer that does not point to an object or function.
  • Double free: Releasing the same allocated block more than once without a new allocation in between.
  • Use-after-free: Accessing memory after it has been released.
Always release each allocated node exactly once. When freeing a linked list, save the next pointer before freeing the current node; otherwise, you may lose access to the remaining nodes.

Correct Method to Free an Entire List

void free_list(struct Node *head)
{
    struct Node *temp;

    while (head != NULL)
    {
        temp = head;
        head = head->next;
        free(temp);
    }
}

14. Complete Program: Create, Display and Free a Linked List

This program combines node creation, linking, traversal and memory cleanup.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

void display_list(const struct Node *head)
{
    const struct Node *temp = head;

    while (temp != NULL)
    {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }

    printf("NULL\n");
}

void free_list(struct Node *head)
{
    struct Node *temp;

    while (head != NULL)
    {
        temp = head;
        head = head->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = create_node(10);

    if (head == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    head->next = create_node(20);

    if (head->next == NULL)
    {
        free_list(head);
        printf("Memory allocation failed\n");
        return 1;
    }

    head->next->next = create_node(30);

    if (head->next->next == NULL)
    {
        free_list(head);
        printf("Memory allocation failed\n");
        return 1;
    }

    printf("Linked List: ");
    display_list(head);

    free_list(head);
    head = NULL;

    printf("Memory released successfully\n");

    return 0;
}
Expected output: 
Linked List: 10 -> 20 -> 30 -> NULL
Memory released successfully

Program Flow

StepOperation
1Create first node with value 10.
2Create second node with value 20.
3Connect first node to second node.
4Create third node with value 30.
5Connect second node to third node.
6Traverse and display all nodes.
7Release all allocated nodes.

16. Common Mistakes in Linked Lists

  1. Forgetting to initialize the next pointer to NULL.
  2. Using a pointer before allocating memory for a node.
  3. Not checking whether malloc() returned NULL.
  4. Accessing a node through a NULL pointer.
  5. Overwriting the head pointer and losing the list.
  6. Forgetting to connect newly created nodes.
  7. Freeing a node before saving its next pointer during traversal.
  8. Forgetting to release dynamically allocated memory.
  9. Accessing a node after it has been freed.
  10. Confusing the node's data with the pointer to the next node.

17. Placement Interview Questions and Answers

Q1. What is a linked list?

Answer: A linked list is a linear data structure made of nodes connected through pointers.

Q2. What is a node?

Answer: A node is an individual element containing data and one or more links to other nodes.

Q3. What is the head pointer?

Answer: It stores the address of the first node in the linked list.

Q4. What does NULL represent in a singly linked list?

Answer: It indicates that a pointer does not point to another valid node. The last node's next pointer is normally NULL.

Q5. What is a self-referential structure?

Answer: It is a structure containing a pointer to another object of its own structure type.

Q6. Why do we use malloc() in linked lists?

Answer: It allocates memory dynamically for nodes at runtime.

Q7. What is the difference between malloc() and calloc()?

Answer: malloc() allocates a block with indeterminate initial contents, whereas calloc() allocates an array-like block and initializes all its bytes to zero.

Q8. Why is free() important?

Answer: It releases dynamically allocated memory and helps prevent memory leaks.

Q9. Can a linked list grow dynamically?

Answer: Yes. Nodes can be allocated as needed, subject to available memory and allocation success.

Q10. What is the time complexity of linked-list traversal?

Answer: O(n), because each node is visited once.

Q11. Why is random access inefficient in a linked list?

Answer: Nodes must be visited sequentially from the head because there is no direct index-based access.

Q12. What is the difference between an array and a linked list?

Answer: Arrays store elements contiguously and provide direct indexing. Linked lists connect separately allocated nodes through pointers.

Q13. What is a dangling pointer?

Answer: A pointer that refers to memory that is no longer valid, such as memory that has been freed.

Q14. What happens if malloc() fails?

Answer: It returns NULL. The program should check the return value before using the pointer.

Q15. What is the difference between head and a temporary traversal pointer?

Answer: Head identifies the beginning of the list. A temporary pointer moves through the list without changing head.

Q16. Can a linked list be implemented without dynamic memory allocation?

Answer: Yes. Nodes can be stored in a preallocated array or static memory pool, but a conventional dynamically growing linked list commonly uses dynamic allocation.

Q17. Why is a linked list called a dynamic data structure?

Answer: Its number of nodes can change during program execution.

Q18. What is the last node in a singly linked list?

Answer: The node whose next pointer is NULL.

Q19. What is the space complexity of a linked list containing n nodes?

Answer: O(n), including the memory occupied by all nodes.

Q20. What is the difference between next and data members?

Answer: data stores the actual value, whereas next stores the address of the next node.
