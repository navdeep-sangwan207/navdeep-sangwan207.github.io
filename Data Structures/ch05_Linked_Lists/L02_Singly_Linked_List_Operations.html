2. Basic Structure of a Singly Linked List

A singly linked list contains nodes connected through next pointers.

struct Node
{
    int data;
    struct Node *next;
};

Example list:

head
 |
 v
[10 | next] -> [20 | next] -> [30 | NULL]

We will implement the following operations:

  1. Display or traverse the list.
  2. Count nodes.
  3. Search for an element.
  4. Update a node's value.
  5. Find the first and last nodes.
  6. Calculate the sum and maximum value.
  7. Free all nodes.

3. Creating a Reusable Node Creation Function

Instead of writing malloc() repeatedly, create a function that allocates and initializes a node.

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

This function:

  • Allocates memory for one node.
  • Checks whether allocation succeeded.
  • Stores the given value.
  • Initializes next to NULL.
  • Returns the node's address.

4. Traversal and Display Operation

Traversal means visiting every node, starting from head, until NULL is reached.

Algorithm

  1. Initialize temp with head.
  2. Check whether temp is NULL.
  3. Process or print temp->data.
  4. Move to temp->next.
  5. Repeat until temp becomes NULL.

C Function

void display_list(const struct Node *head)
{
    const struct Node *temp = head;

    if (temp == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (temp != NULL)
    {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }

    printf("NULL\n");
}

Example

10 -> 20 -> 30 -> NULL

Time complexity: O(n).

Auxiliary space: O(1).

The function accepts a pointer to a constant node because it only reads the list and does not modify node contents or links.

5. Counting the Number of Nodes

To count nodes, traverse the entire list and increment a counter for each node visited.

C Function

size_t count_nodes(const struct Node *head)
{
    size_t count = 0;

    while (head != NULL)
    {
        count++;
        head = head->next;
    }

    return count;
}

Dry Run

4NULLStop

Result: 3 nodes.

Time complexity: O(n).

Auxiliary space: O(1).

6. Searching for an Element

Searching means checking whether a particular value exists in the linked list.

Algorithm

  1. Start from head.
  2. Compare the current node's data with the target.
  3. If equal, report the position.
  4. Otherwise, move to the next node.
  5. If NULL is reached, the value is not present.

C Function

int search_value(const struct Node *head, int target)
{
    int position = 0;

    while (head != NULL)
    {
        if (head->data == target)
            return position;

        head = head->next;
        position++;
    }

    return -1;
}

This function returns a zero-based position. It returns -1 when the value is not found.

Example

List: 10 -> 20 -> 30 -> NULL
Target: 20

Position: 1

Best case: O(1), when the first node matches.

Worst case: O(n), when the value is at the end or absent.

Auxiliary space: O(1).

This function uses int for the position. For lists larger than INT_MAX nodes, a size_t-based result or a separate found/not-found status with an output parameter is more appropriate.

7. Updating a Node's Value

Updating means replacing the data stored in an existing node without changing the links.

C Function

int update_value(struct Node *head, int oldValue, int newValue)
{
    while (head != NULL)
    {
        if (head->data == oldValue)
        {
            head->data = newValue;
            return 1;
        }

        head = head->next;
    }

    return 0;
}

Return value:

  • 1 means the first matching node was updated.
  • 0 means the old value was not found.

Example

Before:
10 -> 20 -> 30 -> NULL

Update 20 to 25

After:
10 -> 25 -> 30 -> NULL

Time complexity: O(n).

Auxiliary space: O(1).

8. Finding the First and Last Nodes

First Node

The first node is directly available through head.

if (head != NULL)
    printf("First value = %d\n", head->data);

Time complexity: O(1).

Last Node

The last node is found by traversing until next becomes NULL.

const struct Node *find_last(const struct Node *head)
{
    if (head == NULL)
        return NULL;

    while (head->next != NULL)
    {
        head = head->next;
    }

    return head;
}

Time complexity: O(n).

Auxiliary space: O(1).

If a linked-list implementation maintains a tail pointer, the last node can be accessed in O(1). We will discuss that design when implementing insertion operations.

9. Calculating the Sum of All Nodes

Traverse the list and add each node's data to a running total.

long long sum_nodes(const struct Node *head)
{
    long long sum = 0;

    while (head != NULL)
    {
        sum += head->data;
        head = head->next;
    }

    return sum;
}

Example

List:
10 -> 20 -> 30 -> NULL

Sum = 10 + 20 + 30
Sum = 60

Time complexity: O(n).

Auxiliary space: O(1).

A long long accumulator can hold a wider range than int, but an extremely large list can still overflow it. Production code should consider the permitted input range or perform checked arithmetic.

10. Finding the Maximum Value

Initialize the maximum with the first node's value and compare every remaining node.

int find_maximum(const struct Node *head, int *result)
{
    if (head == NULL || result == NULL)
        return 0;

    int maximum = head->data;
    head = head->next;

    while (head != NULL)
    {
        if (head->data > maximum)
            maximum = head->data;

        head = head->next;
    }

    *result = maximum;
    return 1;
}

The function returns 1 on success and 0 for an empty list or invalid output pointer.

Example

List:
15 -> 8 -> 42 -> 19 -> NULL

Maximum = 42

Time complexity: O(n).

Auxiliary space: O(1).

11. Freeing the Entire Linked List

Every dynamically allocated node must eventually be released.

Correct C Function

void free_list(struct Node **head)
{
    if (head == NULL)
        return;

    struct Node *temp;

    while (*head != NULL)
    {
        temp = *head;
        *head = (*head)->next;
        free(temp);
    }
}

This function receives the address of the head pointer. It frees every node and sets the caller's head pointer to NULL.

Why Use a Double Pointer?

free_list(&head);
  • head is a pointer to the first node.
  • &head is the address of the head pointer.
  • *head inside the function accesses the caller's head pointer.
  • Setting *head = NULL updates the caller's pointer.

Time complexity: O(n).

Auxiliary space: O(1).

12. Complete Program: All Basic Singly Linked List Operations

This program combines node creation, display, counting, searching, updating, maximum value, sum calculation and memory cleanup.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

int append_node(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;
    return 1;
}

void display_list(const struct Node *head)
{
    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

size_t count_nodes(const struct Node *head)
{
    size_t count = 0;

    while (head != NULL)
    {
        count++;
        head = head->next;
    }

    return count;
}

int search_value(const struct Node *head, int target)
{
    int position = 0;

    while (head != NULL)
    {
        if (head->data == target)
            return position;

        head = head->next;
        position++;
    }

    return -1;
}

int update_value(struct Node *head, int oldValue, int newValue)
{
    while (head != NULL)
    {
        if (head->data == oldValue)
        {
            head->data = newValue;
            return 1;
        }

        head = head->next;
    }

    return 0;
}

long long sum_nodes(const struct Node *head)
{
    long long sum = 0;

    while (head != NULL)
    {
        sum += head->data;
        head = head->next;
    }

    return sum;
}

int find_maximum(const struct Node *head, int *result)
{
    if (head == NULL || result == NULL)
        return 0;

    int maximum = head->data;
    head = head->next;

    while (head != NULL)
    {
        if (head->data > maximum)
            maximum = head->data;

        head = head->next;
    }

    *result = maximum;
    return 1;
}

void free_list(struct Node **head)
{
    if (head == NULL)
        return;

    struct Node *temp;

    while (*head != NULL)
    {
        temp = *head;
        *head = (*head)->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = NULL;
    int maximum;

    if (!append_node(&head, 10) ||
        !append_node(&head, 20) ||
        !append_node(&head, 30) ||
        !append_node(&head, 40))
    {
        printf("Memory allocation failed\n");
        free_list(&head);
        return 1;
    }

    printf("Original list: ");
    display_list(head);

    printf("Total nodes: %zu\n", count_nodes(head));

    int position = search_value(head, 30);

    if (position != -1)
        printf("30 found at zero-based position %d\n", position);
    else
        printf("30 not found\n");

    if (update_value(head, 20, 25))
        printf("Value updated successfully\n");
    else
        printf("Value not found for update\n");

    printf("Updated list: ");
    display_list(head);

    printf("Sum of nodes: %lld\n", sum_nodes(head));

    if (find_maximum(head, &maximum))
        printf("Maximum value: %d\n", maximum);

    free_list(&head);

    if (head == NULL)
        printf("List released successfully\n");

    return 0;
}

Expected Output

Original list: 10 -> 20 -> 30 -> 40 -> NULL
Total nodes: 4
30 found at zero-based position 2
Value updated successfully
Updated list: 10 -> 25 -> 30 -> 40 -> NULL
Sum of nodes: 105
Maximum value: 40
List released successfully

Compile and Run

gcc -std=c11 -Wall -Wextra -pedantic linked_list.c -o linked_list
./linked_list

14. Common Mistakes

  1. Changing head while traversing when it must be preserved.
  2. Forgetting to check whether the list is empty.
  3. Dereferencing a NULL pointer.
  4. Forgetting to advance the traversal pointer, causing an infinite loop.
  5. Returning a node position without defining whether indexing starts at zero or one.
  6. Updating a node's next pointer accidentally while changing its data.
  7. Freeing a node before saving its next pointer.
  8. Not handling allocation failure while creating nodes.
  9. Assuming the list always contains at least one node.
  10. Failing to update the caller's head pointer when freeing the list.

15. Placement Interview Questions and Answers

Q1. What is traversal in a linked list?

Answer: Visiting each node sequentially from the head until NULL is reached.

Q2. What is the time complexity of traversal?

Answer: O(n).

Q3. How do you count the number of nodes?

Answer: Initialize a counter to zero and increment it for each visited node.

Q4. How do you search for an element?

Answer: Compare the target with each node's data while traversing from the head.

Q5. What is the worst-case search complexity?

Answer: O(n), when the target is at the last node or absent.

Q6. How do you update a node's value?

Answer: Locate the required node and assign the new value to its data member.

Q7. Why should we use a temporary pointer for traversal?

Answer: It allows traversal without losing the original head pointer.

Q8. How do you find the last node?

Answer: Traverse until the current node's next pointer becomes NULL.

Q9. What is the complexity of finding the last node without a tail pointer?

Answer: O(n).

Q10. How do you calculate the sum of all nodes?

Answer: Traverse the list and add each data value to an accumulator.

Q11. How do you find the maximum element?

Answer: Initialize the maximum using the first node and compare every remaining node.

Q12. Why should maximum not always be initialized to zero?

Answer: The list may contain only negative values. Initializing from the first node handles this correctly.

Q13. How can you free an entire linked list?

Answer: Save the next node, free the current node, and continue until NULL.

Q14. Why is a double pointer used in free_list()?

Answer: It allows the function to update the original head pointer in the caller.

Q15. What happens when the linked list is empty?

Answer: Head is NULL. Traversal and counting should safely handle this case.

Q16. Can a linked list contain duplicate values?

Answer: Yes. Each node is independent, and multiple nodes can store the same value.

Q17. What is the difference between searching and updating?

Answer: Searching locates a value. Updating modifies the data of a matching node.

Q18. Can traversal modify a linked list?

Answer: It can, if the implementation changes node data or links. Read-only traversal does not need to modify the list.

Q19. What is the benefit of maintaining a tail pointer?

Answer: It allows direct access to the last node and can make appending a node O(1).

Q20. What is the difference between a node pointer and a pointer-to-pointer?

Answer: A node pointer stores a node's address. A pointer-to-pointer stores the address of a node pointer, allowing a function to modify that pointer.

18. Lesson Summary

  • Traversal visits every node in a linked list.
  • Counting determines the total number of nodes.
  • Searching locates a target value.
  • Updating changes a node's stored data.
  • The head pointer provides direct access to the first node.
  • Finding the last node requires traversal without a tail pointer.
  • Sum and maximum operations can be performed in one traversal.
  • free_list() releases every allocated node safely.
  • Most full-list operations take O(n) time and O(1) auxiliary space.
