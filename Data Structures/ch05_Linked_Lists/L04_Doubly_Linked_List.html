2. What Is a Doubly Linked List?

A doubly linked list is a linear data structure in which each node contains three components:

  1. Data: stores the value.
  2. Previous pointer: points to the previous node.
  3. Next pointer: points to the next node.

Node Structure

struct Node
{
    int data;
    struct Node *prev;
    struct Node *next;
};

Representation

NULL <- [10] <-> [20] <-> [30] -> NULL
          ^
          |
         head

The first node has prev = NULL, and the last node has next = NULL.

4. Creating a Doubly Linked List Node

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *prev;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->prev = NULL;
    newNode->next = NULL;

    return newNode;
}

Both pointers are initialized to NULL because a newly created node is not yet connected to other nodes.

5. Forward Traversal

Forward traversal starts from the head and follows next pointers.

Function

void display_forward(const struct Node *head)
{
    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (head != NULL)
    {
        printf("%d <-> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

Example Output

10 <-> 20 <-> 30 <-> NULL

Time complexity: O(n).

Auxiliary space: O(1).

6. Backward Traversal

Backward traversal starts from the last node and follows prev pointers.

Function

void display_backward(const struct Node *tail)
{
    if (tail == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (tail != NULL)
    {
        printf("%d <-> ", tail->data);
        tail = tail->prev;
    }

    printf("NULL\n");
}

Example Output

30 <-> 20 <-> 10 <-> NULL

Time complexity: O(n).

Auxiliary space: O(1).

Backward traversal requires access to the tail pointer. If only head is available, first traverse to the last node.

7. Insertion at the Beginning

A new node becomes the first node of the list.

Example

Before:
NULL <- [20] <-> [30] -> NULL

Insert 10

After:
NULL <- [10] <-> [20] <-> [30] -> NULL

Function

int insert_beginning(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = *head;

    if (*head != NULL)
        (*head)->prev = newNode;

    *head = newNode;

    return 1;
}

Time complexity: O(1).

Auxiliary space: O(1), excluding the new node.

8. Insertion at the End

To insert at the end, traverse to the last node and connect the new node.

Function

int insert_end(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = newNode;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = newNode;
    newNode->prev = temp;

    return 1;
}

Time complexity: O(n) without a tail pointer.

Auxiliary space: O(1), excluding the new node.

9. Insertion at a Specific Position

Positions are zero-based. Insertion at position 0 means insertion at the beginning.

Example

Before:
10 <-> 20 <-> 40

Insert 30 at position 2

After:
10 <-> 20 <-> 30 <-> 40

Function

int insert_at_position(struct Node **head,
                       int value,
                       size_t position)
{
    if (head == NULL)
        return 0;

    if (position == 0)
        return insert_beginning(head, value);

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        if (temp == NULL)
            return 0;

        temp = temp->next;
    }

    if (temp == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = temp->next;
    newNode->prev = temp;

    if (temp->next != NULL)
        temp->next->prev = newNode;

    temp->next = newNode;

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1), excluding the new node.

10. Deletion from the Beginning

Remove the first node and update the new first node's prev pointer.

Function

int delete_beginning(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    *head = temp->next;

    if (*head != NULL)
        (*head)->prev = NULL;

    free(temp);

    return 1;
}

Time complexity: O(1).

Auxiliary space: O(1).

11. Deletion from the End

Traverse to the last node, disconnect it from its previous node and free it.

Function

int delete_end(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    if (temp->next == NULL)
    {
        free(temp);
        *head = NULL;
        return 1;
    }

    while (temp->next != NULL)
        temp = temp->next;

    temp->prev->next = NULL;

    free(temp);

    return 1;
}

Time complexity: O(n) without a tail pointer.

Auxiliary space: O(1).

12. Deletion at a Specific Position

Find the target node and reconnect its previous and next nodes.

Function

int delete_at_position(struct Node **head, size_t position)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *target = *head;

    for (size_t i = 0; i < position; i++)
    {
        if (target == NULL)
            return 0;

        target = target->next;
    }

    if (target == NULL)
        return 0;

    if (target->prev != NULL)
        target->prev->next = target->next;
    else
        *head = target->next;

    if (target->next != NULL)
        target->next->prev = target->prev;

    free(target);

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

This implementation handles deletion of the first node, last node, middle node and the only node in the list.

void display_forward(const struct Node *head)
{
    while (head != NULL)
    {
        printf("%d <-> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

void display_backward(const struct Node *head)
{
    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    while (head->next != NULL)
        head = head->next;

    while (head != NULL)
    {
        printf("%d <-> ", head->data);
        head = head->prev;
    }

    printf("NULL\n");
}

void free_list(struct Node **head)
{
    if (head == NULL)
        return;

    struct Node *temp;

    while (*head != NULL)
    {
        temp = *head;
        *head = (*head)->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = NULL;

    if (!insert_end(&head, 20) ||
        !insert_end(&head, 30) ||
        !insert_end(&head, 40))
    {
        printf("Memory allocation failed\n");
        free_list(&head);
        return 1;
    }

    printf("Initial forward list:\n");
    display_forward(head);

    if (!insert_beginning(&head, 10))
    {
        printf("Insertion failed\n");
        free_list(&head);
        return 1;
    }

    printf("After insertion at beginning:\n");
    display_forward(head);

    if (!insert_at_position(&head, 25, 2))
    {
        printf("Insertion failed\n");
        free_list(&head);
        return 1;
    }

    printf("After insertion at position 2:\n");
    display_forward(head);

    printf("Backward traversal:\n");
    display_backward(head);

    if (delete_beginning(&head))
        printf("Beginning node deleted\n");

    if (delete_end(&head))
        printf("End node deleted\n");

    if (delete_at_position(&head, 1))
        printf("Node at position 1 deleted\n");

    printf("Final forward list:\n");
    display_forward(head);

    printf("Final backward list:\n");
    display_backward(head);

    free_list(&head);

    printf("Memory released successfully\n");

    return 0;
}

14. Important Pointer Updates

For a middle-node insertion, four pointer relationships must be correct:

newNode->prev = temp;
newNode->next = temp->next;

if (temp->next != NULL)
    temp->next->prev = newNode;

temp->next = newNode;

For deletion of a middle node:

target->prev->next = target->next;
target->next->prev = target->prev;

free(target);
The simplified middle-node pointer statements assume both previous and next nodes exist. General deletion functions must separately handle the head and tail cases, as implemented earlier.

Each doubly linked list node requires additional memory for its prev pointer compared with a singly linked list node.

16. Advantages and Disadvantages

Advantages

  • Supports forward and backward traversal.
  • Deletion of a known node can be O(1), provided its links are valid and the head/tail references are maintained where necessary.
  • Useful for navigation in both directions.
  • Insertion before or after a known node is efficient.

Disadvantages

  • Requires extra memory for the prev pointer.
  • More pointer updates are required.
  • Implementation is more complex than a singly linked list.
  • Incorrect pointer updates can corrupt the list.

17. Common Applications

  • Browser forward and backward navigation.
  • Undo and redo operations in editors.
  • Music playlists with previous and next controls.
  • Deque implementations.
  • LRU cache implementations.
  • Navigation systems that require movement in both directions.

18. Placement Interview Questions and Answers

Q1. What is a doubly linked list?

Answer: A linked list in which every node contains data, a pointer to the previous node and a pointer to the next node.

Q2. How many pointers are present in a doubly linked list node?

Answer: Two: prev and next.

Q3. What is the advantage of a doubly linked list?

Answer: It supports traversal in both forward and backward directions.

Q4. What is the disadvantage of a doubly linked list?

Answer: It requires additional memory and more complex pointer management.

Q5. What is the initial value of prev in the first node?

Answer: NULL.

Q6. What is the initial value of next in the last node?

Answer: NULL.

Q7. What is the time complexity of insertion at the beginning?

Answer: O(1).

Q8. What is the time complexity of deletion at the beginning?

Answer: O(1).

Q9. Can a doubly linked list be traversed backward?

Answer: Yes, using prev pointers, starting from the tail node.

Q10. What is the difference between a singly and doubly linked list?

Answer: A singly linked list has only a next pointer, while a doubly linked list has both prev and next pointers.

Q11. Why do we update the next node's prev pointer during insertion?

Answer: To maintain the backward connection to the newly inserted node.

Q12. Why is deletion of a known middle node easier in a doubly linked list?

Answer: Its prev and next pointers provide direct access to both neighboring nodes.

Q13. What is the time complexity of deleting a known node when its pointer is available?

Answer: O(1), assuming it belongs to the list and the head/tail references are updated as required.

Q14. What is a tail pointer?

Answer: A pointer that stores the address of the last node.

Q15. How can insertion at the end be made O(1)?

Answer: Maintain a tail pointer and connect the new node directly to it.

Q16. Which data structure is useful for browser navigation?

Answer: A doubly linked list can support moving to previous and next pages.

Q17. What happens if prev is not updated during insertion?

Answer: Backward traversal may become incorrect or the list may become inconsistent.

Q18. What happens when the only node is deleted?

Answer: The node is freed and head becomes NULL. If a tail pointer is maintained, it must also become NULL.

Q19. Why is a double pointer used in insertion and deletion functions?

Answer: It allows the function to modify the caller's head pointer.

Q20. Is a doubly linked list always better than a singly linked list?

Answer: No. It depends on application requirements, memory constraints and the need for backward traversal.

21. Lesson Summary

  • A doubly linked list contains prev and next pointers.
  • It supports forward and backward traversal.
  • Insertion and deletion at the beginning take O(1) time.
  • Without a tail pointer, end operations require traversal.
  • Correctly maintaining both links is essential.
  • Dynamic memory must be released after deletion.
  • Doubly linked lists are useful for navigation, deques and LRU caches.
