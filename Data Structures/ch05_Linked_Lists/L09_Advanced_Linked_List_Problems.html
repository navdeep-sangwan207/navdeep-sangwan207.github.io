2. Reverse Nodes in Groups of K

Reverse every group of K nodes in a singly linked list. If the final group contains fewer than K nodes, leave it unchanged.

Example

Original:
1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8 -> NULL

K = 3

After reversal:
3 -> 2 -> 1 -> 6 -> 5 -> 4 -> 7 -> 8 -> NULL

Algorithm

  1. Check whether at least K nodes remain.
  2. Identify the Kth node.
  3. Reverse the links in that group.
  4. Connect the previous group's tail to the new group head.
  5. Continue with the remaining nodes.
  6. Leave an incomplete final group unchanged.

C Implementation

struct Node *reverse_k_group(struct Node *head, size_t k)
{
    if (head == NULL || k <= 1)
        return head;

    struct Node *current = head;
    size_t count = 0;

    while (current != NULL && count < k)
    {
        current = current->next;
        count++;
    }

    if (count < k)
        return head;

    struct Node *previous = NULL;
    current = head;

    for (size_t i = 0; i < k; i++)
    {
        struct Node *nextNode = current->next;
        current->next = previous;
        previous = current;
        current = nextNode;
    }

    head->next = reverse_k_group(current, k);

    return previous;
}

Time complexity: O(n).

Auxiliary space: O(n/k) recursive calls, approximately, for groups of K nodes.

This recursive version leaves an incomplete final group unchanged. For extremely long lists, an iterative implementation avoids recursive call-stack usage.

3. Swap Nodes in Pairs

Swap every two adjacent nodes without swapping their data values.

Example

Original:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

After pair swapping:
20 -> 10 -> 40 -> 30 -> 50 -> NULL

C Implementation

struct Node *swap_pairs(struct Node *head)
{
    struct Node dummy;
    dummy.next = head;

    struct Node *previous = &dummy;

    while (previous->next != NULL &&
           previous->next->next != NULL)
    {
        struct Node *first = previous->next;
        struct Node *second = first->next;

        first->next = second->next;
        second->next = first;
        previous->next = second;

        previous = first;
    }

    return dummy.next;
}

Time complexity: O(n).

Auxiliary space: O(1).

The nodes themselves are rearranged. Their data values are not exchanged.

4. Rearrange Odd and Even Positioned Nodes

Place nodes at odd positions first, followed by nodes at even positions. Positions are counted starting from 1.

Example

Original:
10 -> 20 -> 30 -> 40 -> 50 -> 60 -> NULL

Odd positions:
10 -> 30 -> 50

Even positions:
20 -> 40 -> 60

Result:
10 -> 30 -> 50 -> 20 -> 40 -> 60 -> NULL

C Implementation

struct Node *odd_even_positions(struct Node *head)
{
    if (head == NULL || head->next == NULL)
        return head;

    struct Node *odd = head;
    struct Node *even = head->next;
    struct Node *evenHead = even;

    while (even != NULL && even->next != NULL)
    {
        odd->next = even->next;
        odd = odd->next;

        even->next = odd->next;
        even = even->next;
    }

    odd->next = evenHead;

    return head;
}

Time complexity: O(n).

Auxiliary space: O(1).

This problem groups nodes by their positions, not by whether their data values are odd or even.

5. Partition a Linked List Around a Value

Rearrange nodes so that values smaller than a pivot appear before values greater than or equal to the pivot.

Example

Original:
3 -> 5 -> 8 -> 5 -> 10 -> 2 -> 1 -> NULL

Pivot = 5

One valid result:
3 -> 2 -> 1 -> 5 -> 8 -> 5 -> 10 -> NULL

C Implementation: Stable Partition

struct Node *partition_list(struct Node *head, int pivot)
{
    struct Node smallerDummy;
    struct Node largerDummy;

    struct Node *smallerTail = &smallerDummy;
    struct Node *largerTail = &largerDummy;

    smallerDummy.next = NULL;
    largerDummy.next = NULL;

    while (head != NULL)
    {
        struct Node *nextNode = head->next;
        head->next = NULL;

        if (head->data < pivot)
        {
            smallerTail->next = head;
            smallerTail = head;
        }
        else
        {
            largerTail->next = head;
            largerTail = head;
        }

        head = nextNode;
    }

    smallerTail->next = largerDummy.next;

    return smallerDummy.next != NULL
           ? smallerDummy.next
           : largerDummy.next;
}

Time complexity: O(n).

Auxiliary space: O(1).

This implementation preserves the relative order of nodes within each partition.

6. Delete a Node When Only That Node Is Given

Sometimes an interview question gives only a pointer to the node that must be deleted, without giving the head pointer.

Important Limitation

A normal singly linked-list node cannot be deleted directly if it is the final node and only its own pointer is available.

Technique

Copy the next node's data into the given node, then unlink and free the next node.

C Function

int delete_given_node(struct Node *node)
{
    if (node == NULL || node->next == NULL)
        return 0;

    struct Node *nextNode = node->next;

    node->data = nextNode->data;
    node->next = nextNode->next;

    free(nextNode);

    return 1;
}

Time complexity: O(1).

Auxiliary space: O(1).

This technique does not physically free the supplied node. It removes the next node and replaces the supplied node's value. It cannot delete the tail node when only that node pointer is available.

7. Clone a Linked List with Random Pointers

Consider a linked list where each node contains:

  • next: Points to the next node.
  • random: Points to any node in the list or NULL.

Node Structure

struct RandomNode
{
    int data;
    struct RandomNode *next;
    struct RandomNode *random;
};

Example

Node A:
next   -> Node B
random -> Node C

Node B:
next   -> Node C
random -> Node A

Node C:
next   -> NULL
random -> Node B

Three-Pass Cloning Algorithm

  1. Insert a cloned node immediately after every original node.
  2. Assign each cloned node's random pointer using the corresponding original node's random pointer.
  3. Separate the cloned list from the original list.

Time and Space Complexity

Time complexity: O(n).

Auxiliary space: O(1), excluding the newly allocated cloned nodes.

This is a popular advanced interview problem because it tests pointer relationships, memory allocation and careful list separation.

8. Find the Maximum Twin Sum

For an even-length linked list, pair the first node with the last, the second node with the second-last, and so on. Find the maximum pair sum.

Example

List:
5 -> 4 -> 2 -> 1 -> NULL

Pairs:
5 + 1 = 6
4 + 2 = 6

Maximum Twin Sum = 6

Approach

  1. Find the middle using slow and fast pointers.
  2. Reverse the second half.
  3. Compare corresponding nodes and calculate pair sums.
  4. Restore the original list if required.

Time complexity: O(n).

Auxiliary space: O(1).

For C implementations, use a sufficiently wide integer type for the sum and account for possible signed integer overflow when input values are unrestricted.

9. Flattening a Multilevel Linked List

A multilevel linked list may contain nodes that point to another linked list through a child pointer.

Example Structure

1 -> 2 -> 3 -> 4
     |
     v
     7 -> 8 -> 9

Flattening converts the multilevel structure into a single-level list according to a specified ordering rule.

Interview Considerations

  • Clarify whether child lists should be flattened depth-first or level-by-level.
  • Preserve node order according to the problem statement.
  • Update next and child pointers carefully.
  • Avoid losing references to unprocessed nodes.

This problem has multiple valid variants, so the required flattening order must be specified before implementation.

10. Complete C11 Program: Advanced Linked List Rearrangement

The following program demonstrates pair swapping, K-group reversal, odd/even position rearrangement and stable partitioning. Each operation is demonstrated on a separate list.

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *node = malloc(sizeof *node);

    if (node == NULL)
        return NULL;

    node->data = value;
    node->next = NULL;

    return node;
}

int append_node(struct Node **head, int value)
{
    struct Node *node = create_node(value);

    if (node == NULL)
        return 0;

    if (*head == NULL)
    {
        *head = node;
        return 1;
    }

    struct Node *temp = *head;

    while (temp->next != NULL)
        temp = temp->next;

    temp->next = node;
    return 1;
}

void display(struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}

struct Node *swap_pairs(struct Node *head)
{
    struct Node dummy;
    dummy.next = head;

    struct Node *previous = &dummy;

    while (previous->next != NULL &&
           previous->next->next != NULL)
    {
        struct Node *first = previous->next;
        struct Node *second = first->next;

        first->next = second->next;
        second->next = first;
        previous->next = second;

        previous = first;
    }

    return dummy.next;
}

struct Node *reverse_k_group(struct Node *head, size_t k)
{
    if (head == NULL || k <= 1)
        return head;

    struct Node *current = head;
    size_t count = 0;

    while (current != NULL && count < k)
    {
        current = current->next;
        count++;
    }

    if (count < k)
        return head;

    struct Node *previous = NULL;
    current = head;

    for (size_t i = 0; i < k; i++)
    {
        struct Node *next = current->next;
        current->next = previous;
        previous = current;
        current = next;
    }

    head->next = reverse_k_group(current, k);

    return previous;
}

struct Node *odd_even_positions(struct Node *head)
{
    if (head == NULL || head->next == NULL)
        return head;

    struct Node *odd = head;
    struct Node *even = head->next;
    struct Node *evenHead = even;

    while (even != NULL && even->next != NULL)
    {
        odd->next = even->next;
        odd = odd->next;

        even->next = odd->next;
        even = even->next;
    }

    odd->next = evenHead;

    return head;
}

struct Node *partition_list(struct Node *head, int pivot)
{
    struct Node smallerDummy;
    struct Node largerDummy;

    struct Node *smallerTail = &smallerDummy;
    struct Node *largerTail = &largerDummy;

    smallerDummy.next = NULL;
    largerDummy.next = NULL;

    while (head != NULL)
    {
        struct Node *next = head->next;
        head->next = NULL;

        if (head->data < pivot)
        {
            smallerTail->next = head;
            smallerTail = head;
        }
        else
        {
            largerTail->next = head;
            largerTail = head;
        }

        head = next;
    }

    smallerTail->next = largerDummy.next;

    return smallerDummy.next != NULL
           ? smallerDummy.next
           : largerDummy.next;
}

int main(void)
{
    struct Node *list1 = NULL;
    struct Node *list2 = NULL;
    struct Node *list3 = NULL;
    struct Node *list4 = NULL;

    int values1[] = {10, 20, 30, 40, 50};
    int values2[] = {1, 2, 3, 4, 5, 6, 7, 8};
    int values3[] = {10, 20, 30, 40, 50, 60};
    int values4[] = {3, 5, 8, 5, 10, 2, 1};

    for (size_t i = 0; i < sizeof values1 / sizeof values1[0]; i++)
    {
        if (!append_node(&list1, values1[i]))
            goto allocation_failure;
    }

    for (size_t i = 0; i < sizeof values2 / sizeof values2[0]; i++)
    {
        if (!append_node(&list2, values2[i]))
            goto allocation_failure;
    }

    for (size_t i = 0; i < sizeof values3 / sizeof values3[0]; i++)
    {
        if (!append_node(&list3, values3[i]))
            goto allocation_failure;
    }

    for (size_t i = 0; i < sizeof values4 / sizeof values4[0]; i++)
    {
        if (!append_node(&list4, values4[i]))
            goto allocation_failure;
    }

    printf("Original list 1:\n");
    display(list1);

    list1 = swap_pairs(list1);
    printf("After pair swapping:\n");
    display(list1);

    printf("\nOriginal list 2:\n");
    display(list2);

    list2 = reverse_k_group(list2, 3);
    printf("After reversing groups of 3:\n");
    display(list2);

    printf("\nOriginal list 3:\n");
    display(list3);

    list3 = odd_even_positions(list3);
    printf("After odd-even position rearrangement:\n");
    display(list3);

    printf("\nOriginal list 4:\n");
    display(list4);

    list4 = partition_list(list4, 5);
    printf("After partition around 5:\n");
    display(list4);

    free_list(list1);
    free_list(list2);
    free_list(list3);
    free_list(list4);

    return 0;

allocation_failure:
    printf("Memory allocation failed\n");

    free_list(list1);
    free_list(list2);
    free_list(list3);
    free_list(list4);

    return 1;
}

After pair swapping:

Original list 2:
1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8 -> NULL
After reversing groups of 3:

12. Common Interview Mistakes

  1. Reversing K-group links without saving the next node.
  2. Forgetting to connect the reversed group to the remaining list.
  3. Reversing an incomplete final group when the question requires it to remain unchanged.
  4. Confusing odd/even positions with odd/even data values.
  5. Overwriting a next pointer before saving the remaining list.
  6. Assuming a singly linked-list tail can be deleted with only its own pointer.
  7. Failing to preserve the relative order in a stable partition.
  8. Freeing a node before saving the pointer to the next node.
  9. Forgetting to separate original and cloned lists during random-pointer cloning.
  10. Ignoring recursion depth in large linked lists.

13. Placement Interview Questions and Answers

Q1. What is K-group reversal?

Answer: It reverses consecutive groups of K nodes in a linked list.

Q2. What happens to the final group if it has fewer than K nodes?

Answer: It depends on the problem statement. A common version leaves the incomplete group unchanged.

Q3. What is the time complexity of K-group reversal?

Answer: O(n), because each node is processed a constant number of times.

Q4. How can adjacent nodes be swapped without exchanging data?

Answer: Change their next pointers so the second node points to the first and the previous node points to the second.

Q5. What does odd-even position rearrangement mean?

Answer: All nodes at odd positions are placed before nodes at even positions, while preserving their relative order.

Q6. Does odd-even rearrangement depend on node values?

Answer: No. It depends on the node's position.

Q7. What is a stable partition?

Answer: A partition that preserves the original relative order of nodes within each resulting group.

Q8. Can a tail node be deleted if only its pointer is given?

Answer: Not in a normal singly linked list, because its predecessor cannot be found from the tail pointer alone.

Q9. What is a random pointer?

Answer: A pointer that may refer to any node in the same list or NULL.

Q10. What is the challenge in cloning a random-pointer list?

Answer: The cloned random pointers must point to cloned nodes, not original nodes.

Q11. What is the three-pass cloning approach?

Answer: Insert cloned nodes, assign random pointers, and separate the two lists.

Q12. What is the benefit of pointer rearrangement?

Answer: It avoids unnecessary data copying and can use constant auxiliary space.

Q13. What is a twin sum?

Answer: It is the sum of a node and its corresponding node from the opposite end of an even-length list.

Q14. How do you find the maximum twin sum efficiently?

Answer: Find the middle, reverse the second half, and compare corresponding nodes.

Q15. What is a multilevel linked list?

Answer: A linked structure in which nodes can contain additional pointers to child lists.

Q16. Why must the next pointer be saved before reversing a node?

Answer: Reversing the link would otherwise lose access to the remaining nodes.

Q17. What is the advantage of a dummy node?

Answer: It simplifies handling of the head node during insertion, deletion, swapping and merging.

Q18. What is the main risk of recursive linked-list algorithms?

Answer: Deep recursion can cause stack exhaustion.

Q19. How can linked-list problems be optimized?

Answer: Use slow-fast pointers, dummy nodes, pointer switching, in-place reversal and careful pointer updates.

Q20. Which advanced linked-list patterns should a fresher practice?

Answer: K-group reversal, pair swapping, stable partition, odd-even rearrangement, random-pointer cloning and merge sort.
