  • Understand circular linked list structure.

  • Implement a circular singly linked list using C.

2. What Is a Circular Linked List?

A circular linked list is a linked list in which the last node points back to the first node instead of pointing to NULL.

Linear Linked List

10 -> 20 -> 30 -> NULL

Circular Linked List

       +----------------------+
       |                      |
       v                      |
10 -> 20 -> 30 ----------------+

In a circular singly linked list:

  • The last node's next pointer points to head.
  • There is no NULL link at the end of a non-empty list.
  • Traversal must stop when it reaches the starting node again.

3. Node Structure

struct Node
{
    int data;
    struct Node *next;
};

The node structure is the same as a singly linked list. The difference is how the next pointers are connected.

Example

head
 |
 v
[10] -> [20] -> [30]
 ^                 |
 |_________________|

5. Creating a Node

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *create_node(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
        return NULL;

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

Initially, next is NULL. The circular link is established when the node is inserted into the list.

6. Creating a Circular Linked List

For a single-node circular linked list, the node points to itself.

struct Node *head = create_node(10);

if (head != NULL)
    head->next = head;

For multiple nodes, the last node must point back to head.

struct Node *first = create_node(10);
struct Node *second = create_node(20);
struct Node *third = create_node(30);

if (first != NULL && second != NULL && third != NULL)
{
    first->next = second;
    second->next = third;
    third->next = first;
}
The example above illustrates the links only. A complete program must handle partial allocation failures and free any nodes already allocated.

7. Traversal of a Circular Linked List

In a linear list, traversal stops at NULL. In a circular list, traversal stops when the pointer returns to the starting node.

Correct Algorithm

  1. Check whether head is NULL.
  2. Initialize temp with head.
  3. Process the current node.
  4. Move temp to temp->next.
  5. Continue until temp becomes head again.

C Function

void display_list(const struct Node *head)
{
    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    const struct Node *temp = head;

    do
    {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    while (temp != head);

    printf("(back to head)\n");
}

Expected Output

10 -> 20 -> 30 -> (back to head)
A do-while loop is useful because a non-empty circular list must process its starting node at least once.

Time complexity: O(n).

Auxiliary space: O(1).

8. Insertion at the Beginning

Insert a new node before the current head and update the last node's next pointer.

Example

Before:
10 -> 20 -> 30 -> back to 10

Insert 5

After:
5 -> 10 -> 20 -> 30 -> back to 5

Algorithm

  1. Create a new node.
  2. If the list is empty, point the new node to itself and make it head.
  3. Otherwise, find the last node.
  4. Set newNode->next to head.
  5. Set last->next to newNode.
  6. Update head to newNode.

C Function

int insert_beginning(struct Node **head, int value)
{
    if (head == NULL)
        return 0;

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    if (*head == NULL)
    {
        newNode->next = newNode;
        *head = newNode;
        return 1;
    }

    struct Node *last = *head;

    while (last->next != *head)
        last = last->next;

    newNode->next = *head;
    last->next = newNode;
    *head = newNode;

    return 1;
}

Time complexity: O(n) without a tail pointer.

Auxiliary space: O(1), excluding the new node.

10. Insertion at a Specific Position

Positions are zero-based.

Example

Before:
10 -> 20 -> 40 -> back to 10

Insert 30 at position 2

After:
10 -> 20 -> 30 -> 40 -> back to 10

C Function

int insert_at_position(struct Node **head,
                       int value,
                       size_t position)
{
    if (head == NULL)
        return 0;

    if (position == 0)
        return insert_beginning(head, value);

    if (*head == NULL)
        return 0;

    struct Node *temp = *head;

    for (size_t i = 0; i < position - 1; i++)
    {
        temp = temp->next;

        if (temp == *head)
            return 0;
    }

    struct Node *newNode = create_node(value);

    if (newNode == NULL)
        return 0;

    newNode->next = temp->next;
    temp->next = newNode;

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1), excluding the new node.

11. Deletion from the Beginning

Delete the current head and connect the last node to the new head.

Example

Before:
10 -> 20 -> 30 -> back to 10

Delete first node

After:
20 -> 30 -> back to 20

C Function

int delete_beginning(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *temp = *head;

    if (temp->next == temp)
    {
        free(temp);
        *head = NULL;
        return 1;
    }

    struct Node *last = *head;

    while (last->next != *head)
        last = last->next;

    *head = temp->next;
    last->next = *head;

    free(temp);

    return 1;
}

Time complexity: O(n) without a tail pointer.

Auxiliary space: O(1).

12. Deletion from the End

Find the last node and its previous node, then reconnect the previous node to head.

Example

Before:
10 -> 20 -> 30 -> back to 10

Delete last node

After:
10 -> 20 -> back to 10

C Function

int delete_end(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *current = *head;

    if (current->next == current)
    {
        free(current);
        *head = NULL;
        return 1;
    }

    struct Node *previous = NULL;

    while (current->next != *head)
    {
        previous = current;
        current = current->next;
    }

    previous->next = *head;

    free(current);

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

13. Deletion at a Specific Position

Locate the target node and reconnect the previous node to the target's next node.

C Function

int delete_at_position(struct Node **head, size_t position)
{
    if (head == NULL || *head == NULL)
        return 0;

    if (position == 0)
        return delete_beginning(head);

    struct Node *previous = *head;
    struct Node *current = previous->next;

    for (size_t i = 1; i < position; i++)
    {
        if (current == *head)
            return 0;

        previous = current;
        current = current->next;
    }

    if (current == *head)
        return 0;

    previous->next = current->next;

    free(current);

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

14. Deletion by Value

Delete the first node containing a given value.

C Function

int delete_by_value(struct Node **head, int value)
{
    if (head == NULL || *head == NULL)
        return 0;

    struct Node *current = *head;
    struct Node *previous = NULL;

    do
    {
        if (current->data == value)
            break;

        previous = current;
        current = current->next;
    }
    while (current != *head);

    if (current->data != value)
        return 0;

    if (current->next == current)
    {
        free(current);
        *head = NULL;
        return 1;
    }

    if (previous == NULL)
    {
        struct Node *last = *head;

        while (last->next != *head)
            last = last->next;

        *head = current->next;
        last->next = *head;
    }
    else
    {
        previous->next = current->next;
    }

    free(current);

    return 1;
}

Time complexity: O(n).

Auxiliary space: O(1).

15. Freeing a Circular Linked List

Free every node without accidentally following a link into memory that has already been released.

C Function

void free_list(struct Node **head)
{
    if (head == NULL || *head == NULL)
        return;

    struct Node *current = *head;
    struct Node *nextNode;

    do
    {
        nextNode = current->next;
        free(current);
        current = nextNode;
    }
    while (current != *head);

    *head = NULL;
}
The original head address is retained as the stopping value. The loop does not dereference the original head after it has been freed; it only compares pointer values to determine when the circle has been traversed.

Time complexity: O(n).

Auxiliary space: O(1).

        !insert_end(&head, 20) ||
        !insert_end(&head, 30))

        printf("Memory allocation failed\n");
        free_list(&head);
        return 1;

    display_list(head);

    {
        printf("Insertion failed\n");

        return 1;

        free_list(&head);

        free_list(&head);
        return 1;

17. Circular Linked List with a Tail Pointer

A common optimization is to maintain a tail pointer instead of only head.

tail
 |
 v
[30] -> [10] -> [20]
 ^                 |
 |_________________|

head = tail->next

When the list is non-empty, head can be obtained using tail->next.

Benefits

  • Insertion at the beginning can be O(1).
  • Insertion at the end can be O(1).
  • Deletion at the beginning can be O(1).
  • Maintaining a tail pointer makes some operations more efficient.

Deletion at the end still requires finding the node before tail in a singly linked circular list, so it remains O(n).

The tail-pointer representation is particularly useful in round-robin scheduling and queue implementations.

18. Applications of Circular Linked Lists

  • Round-robin CPU scheduling.
  • Multiplayer turn management.
  • Circular playlists.
  • Repeated task scheduling.
  • Token-ring style logical traversal.
  • Queue implementations using a tail pointer.

19. Common Mistakes

  1. Using temp != NULL as the traversal condition.
  2. Forgetting to connect the last node back to head.
  3. Forgetting to update the last node when inserting at the beginning.
  4. Not handling the single-node case during deletion.
  5. Failing to update head after deleting the first node.
  6. Freeing a node and then accessing its fields.
  7. Using an incorrect stopping condition and causing an infinite loop.
  8. Not freeing all nodes before terminating the program.
  9. Assuming the circular list's last node points to NULL.
  10. Forgetting to maintain the tail pointer if the implementation uses one.

20. Placement Interview Questions and Answers

Q1. What is a circular linked list?

Answer: A linked list in which the last node points back to the first node.

Q2. What is the difference between a circular and a singly linked list?

Answer: In a singly linked list, the last node points to NULL. In a circular linked list, it points to the head.

Q3. How do you identify the end of a circular linked list?

Answer: During traversal from a known starting node, stop when the current pointer returns to that starting node.

Q4. Why is a do-while loop suitable for circular traversal?

Answer: It processes the first node before checking whether traversal has returned to the starting node.

Q5. What is the main risk during circular linked list traversal?

Answer: An incorrect termination condition can cause an infinite loop.

Q6. What does the next pointer of a single-node circular list contain?

Answer: The address of the node itself.

Q7. Can a circular linked list be traversed continuously?

Answer: Yes. It can be traversed repeatedly because the last node links back to the first node.

Q8. What is the time complexity of traversal?

Answer: O(n) for one complete traversal.

Q9. How can insertion at the end be made O(1)?

Answer: Maintain a tail pointer and connect the new node directly after it.

Q10. What is the benefit of a tail pointer in a circular list?

Answer: It provides direct access to the last node, and head can be obtained through tail->next.

Q11. What is the complexity of deleting the last node in a circular singly linked list?

Answer: O(n), because the previous node must be found.

Q12. What is round-robin scheduling?

Answer: A scheduling approach in which tasks receive CPU time in repeated cycles.

Q13. Why is a circular linked list useful in round-robin scheduling?

Answer: The scheduler can move from one task to the next and return to the first task without restarting traversal from NULL.

Q14. How do you delete the only node in a circular linked list?

Answer: Free the node and set head to NULL.

Q15. Can a circular linked list contain duplicate values?

Answer: Yes. Duplicate values are allowed.

Q16. What happens if the last node points to NULL accidentally?

Answer: The list is no longer circular, and traversal logic expecting a circular link may fail.

Q17. How is a circular linked list different from a circular array?

Answer: A circular linked list uses dynamically allocated nodes and pointers, while a circular array uses indexed storage with wraparound indexing.

Q18. Is backward traversal directly possible in a circular singly linked list?

Answer: No. It requires a previous pointer or additional traversal logic.

Q19. What is the complexity of insertion at the beginning without a tail pointer?

Answer: O(n), because the last node must be located to update its next pointer.

Q20. What is the main advantage of circular linked lists?

Answer: They support cyclic processing without reaching a NULL end pointer.

23. Lesson Summary

  • A circular linked list connects the last node back to the first node.
  • Its node structure is similar to a singly linked list.
  • Traversal stops when the starting node is reached again.
  • Insertion and deletion require careful circular-link maintenance.
  • Single-node and empty-list cases need special handling.
  • A tail pointer can make insertion at the beginning and end O(1).
  • Circular linked lists are useful in cyclic scheduling and repeated processing.
