1. Introduction to Sysfs

Sysfs is a virtual filesystem in Linux, normally mounted at /sys. It provides a structured view of kernel objects, devices, buses, classes and their attributes.

Sysfs allows user-space applications to inspect and, where supported, configure kernel objects through attribute files.

Examples of sysfs locations include:

  • /sys/class/net/ – Network interfaces.
  • /sys/class/block/ – Block devices.
  • /sys/bus/ – Device buses and drivers.
  • /sys/devices/ – Device hierarchy.
  • /sys/module/ – Loaded kernel modules.

2. Project Objectives

  • Understand the purpose of sysfs.
  • Understand kernel objects and attributes.
  • Create a custom kernel object.
  • Create sysfs attributes using struct kobj_attribute.
  • Implement show() and store() callbacks.
  • Read and modify driver data from user space.

4. Important Sysfs Concepts

4.1 Kernel Object (kobject)

A kobject is a fundamental kernel object used to represent objects in the kernel object model. It supports object hierarchy, reference counting and sysfs representation.

4.2 Sysfs Attribute

An attribute represents a property of a kernel object. It appears as a file in sysfs.

4.3 show() Callback

The show callback formats kernel data and returns it to user space when the attribute is read.

4.4 store() Callback

The store callback receives data written by a user-space application and updates kernel state.

7. Complete Sysfs Driver Source Code

Create the source file:

nano sysfs_driver.c

File: sysfs_driver.c

#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/init.h>
#include <linux/kobject.h>
#include <linux/sysfs.h>
#include <linux/mutex.h>
#include <linux/errno.h>
#include <linux/kstrtox.h>

static struct kobject *my_kobj;

static int device_value = 0;
static DEFINE_MUTEX(value_mutex);

/* Show callback: read attribute */
static ssize_t value_show(
    struct kobject *kobj,
    struct kobj_attribute *attr,
    char *buf)
{
    int value;

    if (mutex_lock_interruptible(&value_mutex))
        return -ERESTARTSYS;

    value = device_value;

    mutex_unlock(&value_mutex);

    return sysfs_emit(buf, "%d\n", value);
}

/* Store callback: write attribute */
static ssize_t value_store(
    struct kobject *kobj,
    struct kobj_attribute *attr,
    const char *buf,
    size_t count)
{
    int new_value;
    int ret;

    ret = kstrtoint(buf, 10, &new_value);

    if (ret)
        return ret;

    if (new_value < 0 || new_value > 1000)
        return -ERANGE;

    if (mutex_lock_interruptible(&value_mutex))
        return -ERESTARTSYS;

    device_value = new_value;

    mutex_unlock(&value_mutex);

    pr_info("sysfs_driver: Value updated to %d\n",
            new_value);

    return count;
}

/* Define read/write attribute */
static struct kobj_attribute value_attribute =
    __ATTR(value, 0664, value_show, value_store);

/* Module initialization */
static int __init sysfs_driver_init(void)
{
    int ret;

    my_kobj = kobject_create_and_add(
        "my_device",
        kernel_kobj
    );

    if (!my_kobj) {
        pr_err("sysfs_driver: Failed to create kobject\n");
        return -ENOMEM;
    }

    ret = sysfs_create_file(
        my_kobj,
        &value_attribute.attr
    );

    if (ret) {
        pr_err("sysfs_driver: Failed to create attribute\n");
        kobject_put(my_kobj);
        my_kobj = NULL;
        return ret;
    }

    pr_info("sysfs_driver: /sys/kernel/my_device/value created\n");

    return 0;
}

/* Module cleanup */
static void __exit sysfs_driver_exit(void)
{
    if (my_kobj) {
        sysfs_remove_file(
            my_kobj,
            &value_attribute.attr
        );

        kobject_put(my_kobj);
        my_kobj = NULL;
    }

    pr_info("sysfs_driver: Sysfs interface removed\n");
}

module_init(sysfs_driver_init);
module_exit(sysfs_driver_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("NS Learning Hub");
MODULE_DESCRIPTION("Sysfs Based Device Interface Driver");
MODULE_VERSION("1.0");

8. Understanding the Driver Code

8.1 Creating a Kernel Object

my_kobj = kobject_create_and_add(
    "my_device",
    kernel_kobj
);

This creates a kernel object under /sys/kernel/.

8.2 Defining an Attribute

static struct kobj_attribute value_attribute =
    __ATTR(value, 0664, value_show, value_store);

The attribute is named value. The mode requests read and write access for the owner and group, and read access for others.

8.3 Reading with show()

return sysfs_emit(buf, "%d\n", value);

The callback returns the current integer value as text.

8.4 Writing with store()

ret = kstrtoint(buf, 10, &new_value);

This converts the input string into an integer. The example accepts values from 0 to 1000.

8.5 Cleanup

The attribute is removed first, then the kobject reference is released. This prevents the module from leaving its sysfs interface behind after unloading.

11. Load the Driver

sudo insmod sysfs_driver.ko

ls -l /sys/kernel/my_device/

sudo dmesg | tail -20

Expected sysfs entry:

/sys/kernel/my_device/value

12. Read the Attribute

Use cat to read the current value:

cat /sys/kernel/my_device/value

Expected output:

0

13. Write a New Value

Write an integer value:

echo 250 | sudo tee /sys/kernel/my_device/value

Read it again:

cat /sys/kernel/my_device/value

Expected output:

250

Check kernel messages:

sudo dmesg | tail -20

14. Test Input Validation

Try a value outside the accepted range:

echo 1500 | sudo tee /sys/kernel/my_device/value

The driver returns -ERANGE, so the write fails.

Try invalid text:

echo hello | sudo tee /sys/kernel/my_device/value

The conversion function kstrtoint() rejects invalid numeric input.

Try a negative value:

echo -10 | sudo tee /sys/kernel/my_device/value

The driver rejects it because the allowed range is 0 to 1000.

15. Remove the Driver

sudo rmmod sysfs_driver

ls /sys/kernel/my_device

Expected result: the custom sysfs directory and its attribute are no longer present.

Clean the project:

make clean
