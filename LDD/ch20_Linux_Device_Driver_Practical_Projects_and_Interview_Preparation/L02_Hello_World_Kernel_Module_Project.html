1. Introduction

A Hello World kernel module is the simplest practical project in Linux kernel development. It demonstrates how to write, compile, load, execute and remove an external kernel module.

A kernel module is a piece of code that can be loaded into and unloaded from a running Linux kernel without rebuilding the entire kernel.

In this project, we will create a module that prints a message when loaded and another message when removed.

2. Project Objective

Develop a basic Linux kernel module that performs the following operations:

  • Initialize the module when loaded.
  • Display a message in the kernel log.
  • Remain loaded until explicitly removed.
  • Execute the cleanup function when unloaded.
  • Display a removal message.

6. Write the Kernel Module Source Code

Create the source file:

nano hello_world.c

File: hello_world.c

#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/init.h>

/* Module initialization function */
static int __init hello_world_init(void)
{
    pr_info("Hello World: Kernel module loaded\n");

    return 0;
}

/* Module cleanup function */
static void __exit hello_world_exit(void)
{
    pr_info("Hello World: Kernel module removed\n");
}

/* Register initialization and cleanup functions */
module_init(hello_world_init);
module_exit(hello_world_exit);

/* Module information */
MODULE_LICENSE("GPL");
MODULE_AUTHOR("NS Learning Hub");
MODULE_DESCRIPTION("Hello World Linux Kernel Module");
MODULE_VERSION("1.0");

Code Explanation

CodePurpose
#include <linux/module.h>Provides kernel module definitions.
#include <linux/kernel.h>Provides kernel-related declarations and logging facilities.
#include <linux/init.h>Provides initialization and cleanup annotations.

7. Understand the Initialization Function

static int __init hello_world_init(void)
{
    pr_info("Hello World: Kernel module loaded\n");
    return 0;
}

The initialization function is called when the kernel successfully loads the module.

  • It is declared with the __init annotation.
  • It prints a message using pr_info().
  • It returns zero to indicate successful initialization.
  • A negative error code indicates initialization failure.

8. Understand the Cleanup Function

static void __exit hello_world_exit(void)
{
    pr_info("Hello World: Kernel module removed\n");
}

The cleanup function is called when the module is successfully unloaded.

  • It is declared with the __exit annotation.
  • It releases resources allocated by the module.
  • It unregisters devices and interfaces created by the module.
  • It performs necessary cleanup before removal.
Important: A simple Hello World module does not allocate memory or register devices, so its cleanup function only prints a message. Real drivers must release every resource they acquire.

9. Create the Makefile

Create a file named Makefile:

nano Makefile

File: Makefile

obj-m += hello_world.o

KDIR := /lib/modules/$(shell uname -r)/build
PWD := $(shell pwd)

all:
	$(MAKE) -C $(KDIR) M=$(PWD) modules

clean:
	$(MAKE) -C $(KDIR) M=$(PWD) clean

The command lines under all and clean must begin with a tab character.

10. Compile the Kernel Module

Execute the following command:

make

The kernel build system compiles the source code and generates the module.

Verify the generated module:

ls -l

Expected important output file:

hello_world.ko

Inspect the module:

file hello_world.ko
modinfo hello_world.ko

11. Load the Kernel Module

Load the module using insmod:

sudo insmod hello_world.ko

Check whether it is loaded:

lsmod | grep hello_world

Expected initialization message:

Hello World: Kernel module loaded

Display the kernel log:

sudo dmesg | tail -20

You can also follow new kernel messages using:

sudo dmesg -w

Press Ctrl+C to stop following the messages.

12. Remove the Kernel Module

Remove the module using rmmod:

sudo rmmod hello_world

Verify that it has been removed:

lsmod | grep hello_world

Inspect the cleanup message:

sudo dmesg | tail -20

Expected message:

Hello World: Kernel module removed

13. Complete Project Execution Sequence

Run the commands in the following order:

# Create project directory
mkdir -p ~/Linux_Driver_Projects/hello_world
cd ~/Linux_Driver_Projects/hello_world

# Create source file and Makefile
nano hello_world.c
nano Makefile

# Compile
make

# Inspect generated module
ls -l

# Load
sudo insmod hello_world.ko

# Verify
lsmod | grep hello_world
sudo dmesg | tail -20

# Remove
sudo rmmod hello_world

# Verify cleanup
sudo dmesg | tail -20

# Clean generated files
make clean

17. Lesson Summary

  • A kernel module can be dynamically loaded into a running Linux kernel.
  • The initialization function runs during module loading.
  • The cleanup function runs during module removal.
  • Kbuild compiles the external module using matching kernel headers.
  • insmod, rmmod, lsmod, modinfo and dmesg are essential development commands.
  • The Hello World module establishes the foundation for more advanced driver projects.
