1. Introduction

A character device driver provides an interface for applications to communicate with devices that transfer data as a stream of bytes. Examples include serial ports, terminal devices and many simple hardware controllers.

Before a character device can be accessed through the Linux device model, the driver must register a device number and associate a struct cdev object with its file operations.

In this project, we will develop a kernel module that dynamically allocates a device number and registers one character device using the Linux character device framework.

The device number identifies the registered character device, while the file operations structure defines how the kernel handles operations such as open, read, write and release.

4. Major and Minor Device Numbers

Major Number

The major number identifies the device driver associated with a device node. Linux uses it to route device operations to the appropriate driver.

Minor Number

The minor number distinguishes individual devices or instances managed by the same driver.

NumberPurpose
MajorIdentifies the driver.
MinorIdentifies a device instance handled by that driver.

Linux combines these numbers into a dev_t value.

5. Understanding dev_t

dev_t is a kernel data type used to represent a device number.

dev_t dev_num;

int major_number;
int minor_number;

major_number = MAJOR(dev_num);
minor_number = MINOR(dev_num);

Important macros:

MacroPurpose
MAJOR(dev)Extracts the major number.
MINOR(dev)Extracts the minor number.
MKDEV(major, minor)Constructs a device number.

6. Allocate a Device Number

Linux provides two commonly used functions for device-number allocation.

Dynamic allocation

int alloc_chrdev_region(
    dev_t *dev,
    unsigned baseminor,
    unsigned count,
    const char *name
);

This function dynamically allocates a range of device numbers.

Static registration

int register_chrdev_region(
    dev_t from,
    unsigned count,
    const char *name
);

This function registers a predefined device-number range. The requested range must be available.

Project choice: We will use alloc_chrdev_region() because dynamically allocating device numbers avoids hard-coding a major number.

7. Understand struct cdev

The struct cdev structure represents a character device inside the Linux kernel.

It connects a device number range with the driver's file operations.

struct cdev my_cdev;

Important functions:

FunctionPurpose
cdev_init()Initializes the cdev object and associates file operations.
cdev_add()Adds the character device to the kernel.
cdev_del()Removes the character device from the kernel.

9. Complete Character Device Registration Code

Create the source file:

nano char_register.c

File: char_register.c

#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/init.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/kdev_t.h>

#define DEVICE_NAME "mychar"
#define DEVICE_COUNT 1

static dev_t dev_num;
static struct cdev my_cdev;

/* File operations structure */
static const struct file_operations my_fops = {
    .owner = THIS_MODULE,
};

/* Module initialization */
static int __init char_register_init(void)
{
    int ret;

    /* Allocate a device number */
    ret = alloc_chrdev_region(
        &dev_num,
        0,
        DEVICE_COUNT,
        DEVICE_NAME
    );

    if (ret < 0) {
        pr_err("Failed to allocate device number\n");
        return ret;
    }

    pr_info("Allocated Major: %d Minor: %d\n",
            MAJOR(dev_num), MINOR(dev_num));

    /* Initialize the cdev structure */
    cdev_init(&my_cdev, &my_fops);

    my_cdev.owner = THIS_MODULE;

    /* Register the character device */
    ret = cdev_add(&my_cdev, dev_num, DEVICE_COUNT);

    if (ret < 0) {
        pr_err("Failed to add character device\n");
        unregister_chrdev_region(dev_num, DEVICE_COUNT);
        return ret;
    }

    pr_info("Character device registered successfully\n");

    return 0;
}

/* Module cleanup */
static void __exit char_register_exit(void)
{
    cdev_del(&my_cdev);

    unregister_chrdev_region(dev_num, DEVICE_COUNT);

    pr_info("Character device unregistered\n");
}

module_init(char_register_init);
module_exit(char_register_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("NS Learning Hub");
MODULE_DESCRIPTION("Character Device Registration Project");
MODULE_VERSION("1.0");

10. Code Explanation

10.1 Header Files

  • linux/module.h – Kernel module definitions.
  • linux/kernel.h – Kernel logging and related declarations.
  • linux/init.h – Initialization and cleanup annotations.
  • linux/fs.h – File operations and filesystem-related definitions.
  • linux/cdev.h – Character device structures and functions.
  • linux/kdev_t.h – Device-number definitions and macros.

10.2 Device Number Allocation

ret = alloc_chrdev_region(
    &dev_num, 0, DEVICE_COUNT, DEVICE_NAME
);

The kernel dynamically allocates one device number starting from minor number zero. The result is stored in dev_num.

10.3 Extract Major and Minor Numbers

MAJOR(dev_num)
MINOR(dev_num)

These macros extract the allocated major and minor numbers for logging.

10.4 Initialize cdev

cdev_init(&my_cdev, &my_fops);

This associates the character device object with the file operations structure.

10.5 Register cdev

cdev_add(&my_cdev, dev_num, DEVICE_COUNT);

This makes the character device available to the kernel character-device subsystem. It does not automatically create a device node in /dev.

10.6 Cleanup

cdev_del(&my_cdev);
unregister_chrdev_region(dev_num, DEVICE_COUNT);

The first function removes the cdev registration. The second releases the allocated device-number range.

14. Understanding Device Number Registration vs Device Node Creation

Registering a character device and creating a device node are two different operations.

OperationFunction
Allocate device numberalloc_chrdev_region()
Register cdevcdev_init() and cdev_add()
Create device node manuallymknod command
Create device node through device modeldevice_create()

For this lesson, we only register the character device. User-space read and write operations and device-node creation will be covered in subsequent projects.

18. Lesson Summary

  • A character device driver provides byte-oriented device access.
  • Linux identifies character devices using major and minor numbers.
  • The dev_t data type represents the combined device number.
  • alloc_chrdev_region() dynamically allocates a device-number range.
  • cdev_init() associates the cdev object with file operations.
