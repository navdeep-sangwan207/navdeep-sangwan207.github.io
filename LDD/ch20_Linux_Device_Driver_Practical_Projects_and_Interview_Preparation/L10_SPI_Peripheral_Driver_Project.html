1. Introduction to SPI

SPI stands for Serial Peripheral Interface. It is a synchronous serial communication protocol used to connect a microcontroller or processor with external peripherals.

SPI is commonly used with:

  • ADC and DAC devices.
  • Flash memory.
  • LCD and OLED displays.
  • Communication modules.
  • Digital sensors.

Unlike I2C, SPI generally uses separate data lines for transmission and reception and a chip-select signal for selecting a peripheral.

6. Project Introduction – MCP3008 ADC

The MCP3008 is an 8-channel, 10-bit analog-to-digital converter with an SPI interface.

FeatureDescription
Resolution10 bits
Channels8 single-ended inputs
InterfaceSPI
Output range0 to 1023
Supply/referenceMust follow device datasheet and board design
Example channelCH0

The ADC converts an analog voltage into a digital value. The Linux driver sends a command over SPI and receives the conversion result.

7. MCP3008 SPI Transaction

For a single-ended conversion, the controller sends a start bit, single-ended selection bit and channel selection bits.

TX bytes:
Byte 0: 0x01
Byte 1: 0x80 | (channel << 4)
Byte 2: 0x00

RX bytes:
Byte 1: contains conversion high bits
Byte 2: contains conversion low bits

ADC value:
((rx[1] & 0x03) << 8) | rx[2]
The exact transaction timing and bit positions must be checked against the MCP3008 datasheet. The example below uses a three-byte SPI transfer with the standard MCP3008 command format.

9. Device Tree Configuration

The following is an illustrative Device Tree node for an MCP3008 connected to an SPI controller.

&spi0 {
    status = "okay";

    adc@0 {
        compatible = "microchip,mcp3008";
        reg = <0>;
        spi-max-frequency = <1000000>;
    };
};

Explanation:

  • &spi0 identifies the board's SPI controller.
  • status = "okay" enables the controller.
  • adc@0 describes the peripheral using chip select 0.
  • compatible identifies the peripheral type.
  • reg = <0> selects chip-select index 0.
  • spi-max-frequency specifies the maximum SPI clock frequency in Hz.
This example assumes a board whose SPI controller uses the standard Device Tree SPI binding. Pin multiplexing, chip-select configuration and controller-specific properties must be added as required by the board.

10. Complete MCP3008 SPI Driver

Create the source file:

nano mcp3008_driver.c

File: mcp3008_driver.c

#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/init.h>
#include <linux/spi/spi.h>
#include <linux/slab.h>
#include <linux/sysfs.h>
#include <linux/device.h>

struct mcp3008_data {
    struct spi_device *spi;
};

/* Read one ADC channel */
static int mcp3008_read_channel(
    struct spi_device *spi,
    u8 channel,
    u16 *value)
{
    u8 tx[3];
    u8 rx[3];

    struct spi_transfer transfer = {
        .tx_buf = tx,
        .rx_buf = rx,
        .len = 3,
    };

    struct spi_message message;
    int ret;

    if (channel > 7)
        return -EINVAL;

    /*
     * MCP3008 command:
     * Start bit, single-ended mode,
     * followed by channel selection.
     */
    tx[0] = 0x01;
    tx[1] = 0x80 | (channel << 4);
    tx[2] = 0x00;

    spi_message_init(&message);
    spi_message_add_tail(&transfer, &message);

    ret = spi_sync(spi, &message);

    if (ret < 0)
        return ret;

    *value = ((rx[1] & 0x03) << 8) | rx[2];

    return 0;
}

/* Sysfs show callback */
static ssize_t adc_value_show(
    struct device *dev,
    struct device_attribute *attr,
    char *buf)
{
    struct spi_device *spi = to_spi_device(dev);
    u16 value;
    int ret;

    ret = mcp3008_read_channel(spi, 0, &value);

    if (ret)
        return ret;

    return sysfs_emit(buf, "%u\n", value);
}

static DEVICE_ATTR_RO(adc_value);

/* Probe callback */
static int mcp3008_probe(struct spi_device *spi)
{
    int ret;

    ret = device_create_file(
        &spi->dev,
        &dev_attr_adc_value
    );

    if (ret) {
        dev_err(&spi->dev,
                "Failed to create ADC attribute\n");
        return ret;
    }

    dev_info(&spi->dev,
             "MCP3008 SPI ADC driver initialized\n");

    return 0;
}

/* Remove callback */
static void mcp3008_remove(struct spi_device *spi)
{
    device_remove_file(
        &spi->dev,
        &dev_attr_adc_value
    );

    dev_info(&spi->dev,
             "MCP3008 driver removed\n");
}

/* Device Tree matching */
static const struct of_device_id mcp3008_of_match[] = {
    { .compatible = "microchip,mcp3008" },
    { }
};
MODULE_DEVICE_TABLE(of, mcp3008_of_match);

/* SPI driver definition */
static struct spi_driver mcp3008_driver = {
    .driver = {
        .name = "mcp3008_custom",
        .of_match_table = mcp3008_of_match,
    },
    .probe = mcp3008_probe,
    .remove = mcp3008_remove,
};

module_spi_driver(mcp3008_driver);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("NS Learning Hub");
MODULE_DESCRIPTION("MCP3008 SPI ADC Driver");
MODULE_VERSION("1.0");
Important: This is an educational example of a custom SPI driver. A production driver should also consider device-specific timing, SPI mode, maximum clock rate, error handling, channel configuration and the Linux IIO subsystem. For an actual ADC product, the standard IIO framework is generally preferable to inventing a private sysfs interface.

11. Understanding the Driver Code

11.1 SPI Transfer Buffers

u8 tx[3];
u8 rx[3];

The transmit buffer stores the command sent to the ADC. The receive buffer stores the bytes returned by the peripheral.

11.2 SPI Message

spi_message_init(&message);
spi_message_add_tail(&transfer, &message);

An SPI message contains one or more transfer objects. Transfers in a message are executed as a single message, normally keeping chip select asserted between transfers unless configured otherwise.

11.3 Synchronous Transfer

ret = spi_sync(spi, &message);

spi_sync() waits for the transfer to complete. It may sleep and must not be called from atomic context.

11.4 ADC Value Calculation

*value = ((rx[1] & 0x03) << 8) | rx[2];

The expression combines the two high-order result bits with the eight low-order bits to obtain the 10-bit ADC result.

11.5 Probe and Remove

The probe callback creates the sysfs attribute after the device matches. The remove callback deletes it when the device is detached.

sudo dmesg | tail -30

Find the SPI device:

ls /sys/bus/spi/devices/

For an SPI device on bus 0 and chip select 0, the device directory is commonly:

/sys/bus/spi/devices/spi0.0

Read the ADC value:

cat /sys/bus/spi/devices/spi0.0/adc_value

Example output:

512

This is an illustrative 10-bit ADC reading. Actual output depends on the analog input voltage.

15. Convert ADC Value into Voltage

For a 10-bit ADC, the output ranges from 0 to 1023.

The approximate voltage conversion is:

Voltage = (ADC_Value / 1023.0) × VREF

Example, assuming VREF = 3.3 V and ADC value = 512:

Voltage = (512 / 1023.0) × 3.3
        ≈ 1.652 V
The reference voltage must be measured or obtained from the actual circuit design. Never apply a voltage outside the MCP3008 input and supply limits.

19. Linux IIO Framework

The Industrial I/O (IIO) subsystem is the standard Linux framework for many ADCs, DACs and sensors.

A production MCP3008 driver should normally integrate with IIO so that applications can access standard channel and scale attributes through the IIO interface.

Important IIO concepts include:

  • struct iio_dev
  • devm_iio_device_alloc()
  • struct iio_chan_spec
  • iio_device_register()
  • iio_device_unregister()
  • read_raw() callback

20. VirtualBox SPI Hardware Limitations

Ubuntu running inside VirtualBox does not automatically access the laptop's physical SPI controller.

You can use the virtual machine to:

  • Study Linux SPI driver architecture.
  • Write and compile SPI driver source code.
  • Learn Device Tree bindings.
  • Study SPI message and transfer structures.

For real ADC measurements, use an embedded Linux board with an SPI controller and an MCP3008 connected to it.

23. Lesson Summary

  • SPI is a synchronous serial communication protocol.
  • Its common signals are SCLK, MOSI, MISO and CS.
  • Linux SPI drivers use spi_driver and spi_device.
  • spi_message and spi_transfer describe SPI operations.
  • spi_sync() performs synchronous transfers.
