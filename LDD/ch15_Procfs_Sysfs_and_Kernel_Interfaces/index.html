Chapter Overview

Linux provides virtual filesystems that allow user-space applications to interact with kernel information and device attributes. Procfs, Sysfs and Debugfs are important interfaces used in kernel development and device drivers.

This chapter covers the structure and purpose of /proc, /sys and /sys/kernel/debug. You will learn how drivers expose information, create attributes, communicate with user space and organize kernel objects through these interfaces.

Important Kernel Interfaces and Concepts

  • Procfs: Virtual filesystem traditionally used to expose process and kernel information through /proc.
  • Sysfs: Virtual filesystem representing kernel objects, devices, buses and drivers through /sys.
  • Debugfs: Debugging-oriented filesystem commonly mounted at /sys/kernel/debug.
  • proc_create(): Creates a Procfs entry.
  • proc_remove(): Removes a Procfs entry.
  • struct proc_ops: Defines operations for modern Procfs entries.
  • kobject: Core kernel object abstraction used by the kernel object model.
  • kobj_attribute: Represents a basic Sysfs attribute associated with a kobject.
  • DEVICE_ATTR: Helper macro for defining device attributes.
  • device_create_file(): Creates a Sysfs attribute file for a device.
  • device_remove_file(): Removes a device attribute file.

Understanding the Three Interfaces

  • /proc: Used for process and kernel information, and selected control interfaces.
  • /sys: Used for structured representation of devices, drivers, buses and kernel objects.
  • /sys/kernel/debug: Used for development and debugging information; it is not intended as a stable user-space ABI.

Practical Applications
