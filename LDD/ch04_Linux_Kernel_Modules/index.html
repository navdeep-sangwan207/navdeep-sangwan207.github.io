Chapter Overview

Linux kernel modules are pieces of code that can be loaded into or removed from the running Linux kernel without rebuilding the entire kernel. They provide a flexible way to extend kernel functionality.

Device drivers are commonly implemented as loadable kernel modules. This chapter explains module architecture, initialization and cleanup functions, module metadata, module loading and removal, and dependency management.

Important Kernel Module Concepts

  • Loadable Module: Kernel code that can be inserted into a running kernel.
  • Initialization Function: Performs setup when a module is loaded.
  • Cleanup Function: Releases resources when a module is removed.
  • Module Metadata: Provides information such as author, description and license.
  • Module Dependency: Represents a requirement for another kernel module.
  • Module Lifecycle: Covers module compilation, loading, operation and removal.

Important Linux Commands

  • insmod module.ko – Insert a kernel module.
  • rmmod module_name – Remove a loaded module.
  • lsmod – Display loaded kernel modules.
  • modinfo module.ko – Display module metadata.
  • depmod – Generate module dependency information.
  • modprobe module_name – Load a module with dependency handling.
  • dmesg – Inspect kernel messages.
