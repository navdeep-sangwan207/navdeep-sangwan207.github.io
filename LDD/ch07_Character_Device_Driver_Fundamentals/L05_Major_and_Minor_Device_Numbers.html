Lesson 5: Major and Minor Device Numbers
Level: Intermediate
Prerequisites: Character-device architecture, device nodes, Linux kernel modules and basic C programming.
Objective: Understand how Linux identifies character devices using major and minor numbers and how device numbers connect device nodes with registered drivers.

1. Introduction

Linux uses device numbers to identify device interfaces. These numbers are associated with special files called device nodes.

A device number consists of two logical components:

  • Major number
  • Minor number

The major number identifies a driver registration or device-number range. The minor number identifies a particular device or instance within that range.

These numbers allow the kernel to associate an opened device node with the appropriate registered device implementation.

2. What Is a Major Number?

A major number is the major component of a Linux device number.

It identifies the driver registration associated with a device-number range. Multiple device instances may be managed under the same major number.

Example

crw-rw-rw- 1 root root 1, 3 ... /dev/null

In this example:

  • Major number = 1
  • Minor number = 3

The major number 1 is associated with a group of miscellaneous memory-related character device interfaces on typical Linux systems.

3. What Is a Minor Number?

A minor number is the minor component of a device number.

It distinguishes individual devices or device instances handled by a driver registration.

Example

crw-rw-rw- 1 root root 1, 3 ... /dev/null

Here, minor number 3 identifies the particular device interface represented by /dev/null.

A driver can use different minor numbers to distinguish multiple devices that it manages.

4. Major Number vs Minor Number

Major Number Identifies the driver registration or device-number range.
Minor Number Identifies an individual device or instance within that range.
Feature Major Number Minor Number
Purpose Identifies a driver registration or range. Distinguishes device instances.
Scope Shared by devices within the registered range. Identifies a particular minor within that range.
Kernel representation Part of dev_t. Part of dev_t.
Extraction macro MAJOR(dev) MINOR(dev)
Construction macro MKDEV(major, minor)

5. Structure of a Device Number

Linux represents a device number using the dev_t data type.

Conceptually, it contains major and minor components.

Linux Device Number: dev_t
↓
Major Driver registration / range
Minor Device instance

The exact internal bit layout is defined by Linux kernel device-number conventions. Drivers should use kernel helper macros rather than manually shifting or masking the underlying representation.

6. Understanding Device Numbers Through Examples

Example 1: /dev/null

ls -l /dev/null

Typical output:

crw-rw-rw- 1 root root 1, 3 ... /dev/null
Property Value
Device type Character device
Major number 1
Minor number 3

Example 2: /dev/zero

ls -l /dev/zero

On typical Linux systems, this character device has major number 1 and minor number 5.

Example 3: /dev/tty

ls -l /dev/tty

On typical Linux systems, this device has major number 5 and minor number 0.

These are common Linux device-number assignments. Actual device numbers should always be checked on the target system.

7. How Device Numbers Connect a Device Node to a Driver

When an application opens a device node, the kernel uses the device-node information and registered device mappings to locate the relevant character-device implementation.

Application opens /dev/mydevice
↓
Device Node Contains Major and Minor Numbers
↓
Kernel Identifies Registered Character Device
↓
Associated struct cdev and file_operations
↓
Driver Callback Executes

The major and minor numbers therefore form an important part of the device identification and dispatch mechanism.

The device node is not the driver itself. A matching device-number registration must exist in the kernel for the device node to reach the intended driver.

8. Multiple Devices Under One Major Number

A character driver can manage multiple device instances using one major number and different minor numbers.

Illustrative Example

Device Node Major Minor
/dev/mydevice0 240 0
/dev/mydevice1 240 1
/dev/mydevice2 240 2
/dev/mydevice3 240 3
Major Number: 240
↓
Minor 0Device 0
Minor 1Device 1
Minor 2Device 2
Minor 3Device 3

The driver can inspect the minor number to determine which device instance the application is accessing. 

int minor = iminor(inode);

The iminor() helper extracts the minor number from an inode.

9. Linux Helper Macros for Device Numbers

Linux provides helper macros to construct and extract device numbers.

9.1 MKDEV()

Combines a major and minor number into a dev_t value. 

dev_t dev;

dev = MKDEV(240, 0);

9.2 MAJOR()

Extracts the major number. 

int major_number;

major_number = MAJOR(dev);

9.3 MINOR()

Extracts the minor number. 

int minor_number;

minor_number = MINOR(dev);

Complete Example

#include <linux/module.h>
#include <linux/fs.h>
#include <linux/kdev_t.h>
#include <linux/init.h>

static int __init device_number_init(void)
{
    dev_t dev;

    dev = MKDEV(240, 5);

    pr_info("Device number: %u:%u\n",
            MAJOR(dev), MINOR(dev));

    return 0;
}

static void __exit device_number_exit(void)
{
    pr_info("Device number example removed\n");
}

module_init(device_number_init);
module_exit(device_number_exit);

MODULE_LICENSE("GPL");
MODULE_DESCRIPTION("Device Number Macro Example");

This example constructs and displays a device number. It does not reserve that number or register a character device.

10. Device Number Allocation vs Device Registration

Two separate operations are important in character-driver development.

Device Number Allocation Reserves a major/minor number range.
Character Device Registration Associates a cdev with a device-number range and file operations.

Functions such as alloc_chrdev_region() and register_chrdev_region() handle device-number registration or allocation.

Functions such as cdev_init() and cdev_add() establish the character-device object and register it for the selected range.

Reserving a device number does not automatically create a device node or complete character-driver registration. These are separate stages.

11. Inspect Major and Minor Numbers in Ubuntu

Step 1: Inspect /dev/null

ls -l /dev/null

Step 2: Display Device Number Information

stat -c 'Major: %t, Minor: %T' /dev/null

The values displayed by these format specifiers are hexadecimal.

Step 3: Display Device Type and Numbers

stat -c 'Type: %F, Major: %t, Minor: %T' /dev/null

Step 4: Inspect Other Character Devices

ls -l /dev/zero
ls -l /dev/tty

Step 5: Inspect Sysfs Character Device Entries

ls -l /sys/dev/char/

Step 6: Inspect a Particular Device

cat /sys/dev/char/1:3/uevent

On a typical system, the path /sys/dev/char/1:3 refers to the device represented by major 1 and minor 3.

The decimal major/minor values shown by ls -l and the hexadecimal values shown by the stat format specifiers represent the same underlying device number components.

12. Important Rules and Best Practices

  • Do not assume that a major number is permanently assigned to your custom driver.
  • Prefer dynamic device-number allocation for new drivers.
  • Use MKDEV(), MAJOR() and MINOR() instead of manually manipulating the encoded number.
  • Check the return value of allocation and registration functions.
  • Keep the allocated device-number range consistent with the cdev registration.
  • Use minor numbers to distinguish device instances where appropriate.
  • Release device-number ranges during driver cleanup.
  • Do not confuse a device node with a registered kernel driver.

13. Summary

  • Linux identifies device interfaces using device numbers.
  • A device number contains major and minor components.
  • The major number identifies a driver registration or device-number range.
  • The minor number distinguishes individual device instances.
  • dev_t stores the device number.
  • MKDEV() constructs a device number.
  • MAJOR() extracts the major number.
  • MINOR() extracts the minor number.
  • Device nodes contain device-number information.
  • Device-number allocation and cdev registration are separate operations.
