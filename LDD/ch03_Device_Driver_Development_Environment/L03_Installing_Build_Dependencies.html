1. Introduction

Linux device driver development requires a properly configured software environment. Before writing and compiling kernel modules, we must install the compiler, build utilities, kernel headers and other supporting tools.

These tools work together to convert kernel module source code written in C into a loadable kernel module file with the .ko extension.

In this lesson, we will prepare an Ubuntu development environment for Linux device driver programming.

2. What Are Build Dependencies?

Build dependencies are software packages, tools and libraries required to compile and build a program.

For Linux kernel module development, common dependencies include:

  • GCC compiler.
  • GNU Make utility.
  • Essential development tools.
  • Matching Linux kernel headers.
  • Kernel build system (Kbuild).
  • Optional debugging and source-management tools.
C Source Code
↓
GCC Compiler
↓
Kbuild + Make
↓
Kernel Module (.ko)

Each tool performs a specific task in the development process.

3. GCC Compiler

GCC stands for GNU Compiler Collection. It supports several programming languages, including C and C++.

Linux kernel code is primarily written in C. GCC can compile C source files, but kernel modules must be compiled with the correct kernel build configuration and flags through Kbuild.

Check GCC installation

gcc --version

Check GCC location

which gcc

If GCC is installed, these commands display its version and executable location.

4. GNU Make Utility

GNU Make is a build automation utility. It reads instructions from a Makefile and executes the commands required to build software.

In kernel module development, Make is commonly used to invoke the kernel build system.

Check Make installation

make --version

Why is Make required?

  • Automates compilation steps.
  • Reads build instructions from Makefiles.
  • Invokes the kernel build system.
  • Helps manage dependencies between source files.
  • Reduces the need to execute compiler commands manually.

5. Build Essential Package

Ubuntu provides a package named build-essential. It installs common tools needed for software development.

It typically includes:

  • GCC compiler.
  • GNU Make.
  • Standard development utilities.
  • Development support packages required by the build environment.

Installation command

sudo apt update
sudo apt install build-essential

The apt update command refreshes package information. The second command installs the development toolchain.

Important: The build-essential package does not replace the Linux kernel headers. Both are needed for a typical external kernel module development setup.

6. Linux Kernel Headers

Kernel headers provide the declarations, structures, macros and interfaces required to compile external kernel modules.

For Ubuntu, install the headers matching the currently running kernel:

sudo apt install linux-headers-$(uname -r)

Check the running kernel version

uname -r

Verify the build directory

ls -l /lib/modules/$(uname -r)/build

The build directory normally provides access to the prepared kernel build environment.

7. Installing the Complete Basic Development Environment

On an Ubuntu system, the following commands install the core packages for external kernel module development.

# Step 1: Refresh package information
sudo apt update

# Step 2: Install common development tools
sudo apt install build-essential

# Step 3: Install headers for the running kernel
sudo apt install linux-headers-$(uname -r)

# Step 4: Install additional useful tools
sudo apt install git vim

These packages provide a basic development environment. Additional packages may be needed for particular kernel versions, architectures or driver projects.

9. Understanding the Kernel Build System

The Linux kernel uses a build system called Kbuild. It works with Makefiles to compile kernel source files and external modules.

Instead of directly compiling a kernel module using GCC, developers invoke the kernel build system.

Typical external module build command

make -C /lib/modules/$(uname -r)/build M=$PWD modules

Command explanation

PartMeaning
makeStarts the Make utility.
-CChanges to the specified directory before processing the build.
/lib/modules/$(uname -r)/buildKernel build directory for the running kernel.
M=$PWDSpecifies the directory containing the external module source and Makefile.
modulesRequests the build system to build external modules.

This command will be used in later practical lessons.

10. Verifying the Installed Development Tools

After installing dependencies, verify that the required tools are available.

# Check GCC
gcc --version

# Check Make
make --version

# Check kernel release
uname -r

# Check kernel headers package
dpkg -l | grep linux-headers

# Check kernel build directory
ls -l /lib/modules/$(uname -r)/build

# Check Git
git --version

# Check module information utility
modinfo --version

If a command is not found, identify which package provides it and install that package through APT.

12. Common Installation Problems

Problem 1: Unable to locate package

Possible reason: Package information is outdated or the required package is unavailable in the configured repositories.

Solution:

sudo apt update
apt search linux-headers

Problem 2: Matching headers are unavailable

Possible reason: The currently running kernel may be custom-built or its matching headers may not be available from the configured repositories.

Solution: Check the kernel version and available header packages. Do not substitute headers for an unrelated kernel version.

Problem 3: GCC command not found

Solution:

sudo apt install build-essential

Problem 4: Make command not found

Solution:

sudo apt install make

Problem 5: Permission denied during package installation

Solution: Use sudo for package installation commands on Ubuntu.

15. Important Points to Remember

  • Build dependencies are tools and packages required for compilation.
  • GCC is the compiler used to compile C source code.
  • GNU Make automates build operations.
  • build-essential installs common development tools on Ubuntu.
  • Kernel headers must match the target kernel build environment.
  • Kbuild is the Linux kernel build system.
  • External modules should be built using the kernel build directory.
  • A successful build produces a loadable module file with the .ko extension.
