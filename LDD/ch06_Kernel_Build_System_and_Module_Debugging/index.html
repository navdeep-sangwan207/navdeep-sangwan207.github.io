Chapter Overview

The Linux kernel build system, known as Kbuild, provides the infrastructure used to compile the Linux kernel and external kernel modules. It manages source files, compiler options, configuration settings and module dependencies.

This chapter explains how to create module Makefiles, use Kbuild variables, compile external modules and troubleshoot common build and loading errors. It also introduces kernel log analysis and a systematic module-debugging workflow.

Important Kbuild Concepts

  • Kbuild: The Linux kernel build infrastructure.
  • Makefile: Defines how external modules are built.
  • obj-m: Identifies modules to be built as loadable kernel modules.
  • obj-y: Identifies objects built into the kernel or the relevant built-in target.
  • M=: Specifies the external module source directory in common external-module builds.
  • modules: Kbuild target used to build external modules.
  • modules_install: Installs built modules into the configured module tree.

Example External Module Build Commands

  • uname -r – Check the running kernel version.
  • ls /lib/modules/$(uname -r)/build – Check the kernel build directory.
  • make – Run the Makefile build target.
  • make -C /lib/modules/$(uname -r)/build M=$PWD modules – Build an external module using the matching kernel build tree.
  • make clean – Run the project's cleanup target, if defined.
  • modinfo module.ko – Inspect the generated module.

Common Debugging Tools

  • dmesg: Inspect kernel messages and module output.
  • journalctl -k: Review kernel messages recorded by systemd-journald.
  • modinfo: Inspect module metadata and dependencies.
  • lsmod: Check whether a module is loaded.
  • modprobe: Load modules with dependency handling.
  • Dynamic Debug: Enable selected dynamic debug messages where supported.
