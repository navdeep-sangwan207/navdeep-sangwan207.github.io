Chapter Overview

Linux device drivers frequently allocate memory for device buffers, internal data structures, configuration information and temporary operations. Kernel memory management differs from user-space memory management because kernel code must follow allocation-context restrictions and handle allocation failures safely.

This chapter introduces kernel memory allocation APIs, including kmalloc(), kfree(), vmalloc(), vfree(), kzalloc() and kcalloc(). It also covers GFP allocation flags, kernel memory regions, physical and virtual memory, and the fundamentals of DMA-capable memory allocation.

Important Kernel Memory APIs

  • kmalloc(): Allocates physically contiguous kernel memory for a requested size.
  • kfree(): Releases memory allocated by compatible kernel allocation functions.
  • vmalloc(): Allocates virtually contiguous memory that need not be physically contiguous.
  • vfree(): Releases memory allocated by vmalloc().
  • kzalloc(): Allocates memory and initializes it to zero.
  • kcalloc(): Allocates an array and initializes its memory to zero.
  • GFP_KERNEL: Common allocation flag for contexts where sleeping is permitted.
  • GFP_ATOMIC: Allocation flag for contexts where sleeping is not permitted; allocation can fail under memory pressure.
  • dma_alloc_coherent(): Allocates memory for coherent DMA use.
  • dma_free_coherent(): Releases memory allocated by dma_alloc_coherent().

Memory Allocation Guidelines

  • Choose an allocation API based on the size and physical-contiguity requirements.
  • Choose GFP flags according to the execution context.
  • Always check whether an allocation returned NULL.
  • Release allocated memory using the matching deallocation function.
  • Avoid sleeping allocations in interrupt context.
  • Do not return kernel pointers directly to user space.
  • Use the DMA API rather than assuming that a CPU virtual address is a DMA address.
  • Ensure every allocated resource is released during error handling and module cleanup.

Practical Applications

  • Allocate and release a kernel buffer using kmalloc() and kfree().
  • Compare kmalloc() and vmalloc().
  • Allocate a zero-initialized buffer using kzalloc().
  • Allocate an array using kcalloc().
  • Inspect allocation failures and handle them safely.
  • Use appropriate GFP flags in different execution contexts.
  • Study DMA allocation and cleanup APIs.
  • Implement memory allocation and cleanup in a character driver.
