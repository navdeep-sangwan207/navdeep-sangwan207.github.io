1. What is OOP?

Object-Oriented Programming organizes programs using classes and objects. It helps structure code and reuse functionality.

2. Main OOP Concepts

  • Class: A blueprint for creating objects.
  • Object: An instance of a class.
  • Encapsulation: Combining data and functions in a class.
  • Abstraction: Exposing essential features while hiding implementation details.
  • Inheritance: Creating a class based on another class.
  • Polymorphism: Providing different behaviours through a common interface.

3. Example: Class and Object

#include <iostream>
using namespace std;

class Student {
public:
    string name;

    void display() {
        cout << "Student: " << name << endl;
    }
};

int main() {
    Student s1;
    s1.name = "Rahul";
    s1.display();

    return 0;
}

Expected output

Student: Rahul
