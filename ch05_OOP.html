5.1 Introduction to OOP

Object-Oriented Programming (OOP) is a programming approach that organizes software around objects containing data and functions.

Main concepts of OOP

  • Class: A blueprint for creating objects.
  • Object: An instance of a class.
  • Encapsulation: Combining data and functions while controlling access to internal data.
  • Abstraction: Exposing essential operations while hiding implementation details.
  • Inheritance: Creating a class based on another class.
  • Polymorphism: Providing a common interface for different behaviors.

5.2 Classes and Objects

A class defines members. An object is created from that class and can access its public members.

Program 1: Create a Class and Object

#include <iostream>
#include <string>
using namespace std;

class Student
{
public:
    string name;
    int age;

    void display()
    {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main()
{
    Student s1;
    s1.name = "Rahul";
    s1.age = 22;

    s1.display();
    return 0;
}

Expected Output

Name: Rahul
Age: 22

Explanation: Student is the class. s1 is an object. The dot operator accesses its public members.

5.3 Access Specifiers

  • public: Accessible from code that has access to the object.
  • private: Accessible only within the class and its friends.
  • protected: Accessible within the class, its friends, and derived classes, subject to inheritance rules.

Program 2: Encapsulation

#include <iostream>
using namespace std;

class BankAccount
{
private:
    double balance;

public:
    BankAccount()
    {
        balance = 0;
    }

    void deposit(double amount)
    {
        if (amount > 0)
            balance += amount;
    }

    double getBalance() const
    {
        return balance;
    }
};

int main()
{
    BankAccount account;
    account.deposit(1500);

    cout << "Balance: " << account.getBalance() << endl;
    return 0;
}

Expected Output

Balance: 1500

Explanation: The balance is private. External code cannot change it directly; it uses the public methods instead.

5.4 Constructors and Destructors

A constructor initializes an object. A destructor runs when an object's lifetime ends.

Program 3: Constructor

#include <iostream>
#include <string>
using namespace std;

class Device
{
private:
    string name;

public:
    Device(string deviceName)
    {
        name = deviceName;
        cout << "Device created: " << name << endl;
    }

    ~Device()
    {
        cout << "Device destroyed: " << name << endl;
    }
};

int main()
{
    Device d1("LPC2129");
    return 0;
}

Expected Output

Device created: LPC2129
Device destroyed: LPC2129

Remember: A constructor has the same name as the class and no return type. A destructor uses the class name preceded by ~ and has no parameters.

5.5 Inheritance

Inheritance lets a derived class reuse accessible members of a base class.

Program 4: Single Inheritance

#include <iostream>
using namespace std;

class Animal
{
public:
    void eat()
    {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal
{
public:
    void bark()
    {
        cout << "Dog is barking" << endl;
    }
};

int main()
{
    Dog d;
    d.eat();
    d.bark();

    return 0;
}

Expected Output

Animal is eating
Dog is barking

Common forms include single, multilevel, hierarchical, multiple and hybrid inheritance.

5.6 Polymorphism

Polymorphism allows a common interface to represent different behaviors. Function overloading is a form of compile-time polymorphism; virtual functions enable runtime polymorphism.

Program 5: Function Overloading

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

double add(double a, double b)
{
    return a + b;
}

int main()
{
    cout << add(2, 3) << endl;
    cout << add(2.5, 3.5) << endl;

    return 0;
}

Expected Output

5
6

5.7 Runtime Polymorphism with Virtual Functions

#include <iostream>
using namespace std;

class Shape
{
public:
    virtual void draw() const
    {
        cout << "Drawing a shape" << endl;
    }

    virtual ~Shape() = default;
};

class Circle : public Shape
{
public:
    void draw() const override
    {
        cout << "Drawing a circle" << endl;
    }
};

int main()
{
    Circle circle;
    Shape* shape = &circle;

    shape->draw();
    return 0;
}

Expected Output

Drawing a circle

The virtual function call uses the actual object type at runtime, even though the pointer is of type Shape*.

5.8 Abstraction

An abstract class has at least one pure virtual function. It cannot be instantiated directly; derived classes can implement its interface.

#include <iostream>
using namespace std;

class Device
{
public:
    virtual void start() = 0;
    virtual ~Device() = default;
};

class Motor : public Device
{
public:
    void start() override
    {
        cout << "Motor started" << endl;
    }
};

int main()
{
    Motor motor;
    motor.start();
    return 0;
}

Expected Output

Motor started

This pattern is useful when multiple devices must provide the same operation through a common interface.
