Chapter Overview

A scheduler determines which ready task receives CPU execution. Scheduling algorithms define how tasks are selected and how processor time is allocated. In real-time systems, scheduling must account for task priorities, execution requirements, periods and deadlines. This chapter introduces major scheduling algorithms and their suitability for real-time applications.

Practical Applications

  • Scheduling periodic sensor-reading tasks.
  • Assigning higher priority to time-critical control tasks.
  • Analyzing CPU utilization in embedded applications.
  • Comparing RMS and EDF scheduling for periodic tasks.
  • Understanding time slicing in multitasking systems.
  • Evaluating context-switch and scheduling overhead.
Important: RMS and EDF are theoretical scheduling policies with specific assumptions and analysis methods. A practical RTOS may implement a different scheduler. FreeRTOS normally uses fixed-priority preemptive scheduling, with optional time slicing among equal-priority ready tasks when configured.
