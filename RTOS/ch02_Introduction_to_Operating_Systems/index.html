Chapter Overview

An Operating System (OS) is system software that manages computer hardware and provides services to application programs. It manages processor time, memory, processes, threads, input/output devices and system resources. This chapter establishes the operating-system concepts needed to understand Real-Time Operating Systems (RTOS).

Practical Applications

  • Understanding process and thread management in Linux.
  • Observing running processes using Linux commands such as ps and top.
  • Understanding CPU scheduling and context switching.
  • Exploring kernel and user-space boundaries.
  • Relating operating system services to RTOS kernel functions.
Important: An RTOS is an operating system designed to provide predictable timing behavior. It uses operating-system concepts such as task management, scheduling, interrupts and synchronization, with additional emphasis on meeting timing constraints.
