Chapter Overview

In an RTOS, multiple tasks may execute concurrently and access shared resources. Without proper synchronization, race conditions and data corruption can occur. Semaphores provide synchronization mechanisms that help coordinate task execution and manage access to shared resources. This chapter explains critical sections, binary semaphores, counting semaphores and semaphore-based communication between tasks and interrupts.

Practical Applications

  • Synchronize two tasks using a binary semaphore.
  • Manage a limited number of identical resources using a counting semaphore.
  • Signal a processing task when a timer or GPIO interrupt occurs.
  • Protect shared data during concurrent task execution.
  • Coordinate producer and consumer tasks using semaphore counts.
  • Implement event-driven task synchronization in FreeRTOS.
Important: A binary semaphore is commonly used for task synchronization and event signaling, while a mutex is generally preferred for protecting shared resources because it supports priority inheritance in FreeRTOS. Mutexes must not be used from ISRs. Use the appropriate FromISR semaphore API when signaling from an interrupt.
