Chapter Overview

Inter-Task Communication (ITC) allows multiple tasks in an RTOS to exchange data, share information and coordinate their execution. Communication mechanisms include shared memory, message passing, mailboxes, queues, pipes and event-based signaling. This chapter introduces these mechanisms and explains their role in reliable multitasking applications.

Practical Applications

  • Send sensor readings from an acquisition task to a processing task.
  • Transfer UART received data to a communication-processing task.
  • Send control commands from a user-interface task to a motor-control task.
  • Use queues to transfer structured messages between tasks.
  • Implement a producer-consumer data-processing pipeline.
  • Use event notifications to signal task execution conditions.
Important: Shared memory does not automatically provide synchronization. When multiple tasks access shared data, suitable protection mechanisms such as mutexes, critical sections or other synchronization techniques may be required. FreeRTOS queues provide a structured way to transfer data between tasks.
