Chapter Overview

Event groups allow multiple tasks to synchronize using individual event bits stored in a shared event object. Tasks can wait for one or more event conditions before continuing execution. FreeRTOS software timers provide time-based callbacks without requiring a separate application task for every timer. This chapter explains event-bit operations, wait conditions, timer creation, timer control, callback execution and the timer service task.

Practical Applications

  • Synchronize sensor, communication and processing tasks using event bits.
  • Wait for multiple initialization events before starting an application operation.
  • Implement a one-shot timer for a timeout event.
  • Implement an auto-reload timer for periodic operations.
  • Use timer callbacks to signal tasks through queues or semaphores.
  • Build an event-driven monitoring application with software timers.
Important: Software timer callbacks execute in the timer service task, not directly in an ISR. They must not block or perform lengthy operations. Timer functionality requires the appropriate configuration, including configUSE_TIMERS, timer service task stack and priority settings. Event-group operations requested from an ISR may be deferred to the timer service task; use the appropriate ISR API and account for timer configuration and command-queue capacity.
