Chapter Overview

Tasks are the fundamental units of execution in FreeRTOS. Each task has its own stack, priority, execution state and task control block. FreeRTOS provides APIs to create, delete, suspend, resume and control tasks. This chapter explains task functions, task handles, scheduling activation, delay mechanisms and priority management through practical FreeRTOS programming concepts.

Practical Applications

  • Create two independent tasks using xTaskCreate().
  • Run tasks at different priority levels.
  • Implement periodic task execution using vTaskDelayUntil().
  • Suspend and resume tasks during application execution.
  • Change task priority dynamically.
  • Build a multitasking application with sensor-monitoring and communication tasks.
Important: In FreeRTOS, xTaskCreate() generally allocates task memory dynamically through the configured heap. Task stack depth is specified in units of StackType_t elements, not bytes. vTaskDelay() provides a delay relative to the call time, whereas vTaskDelayUntil() is intended for periodic execution using an absolute wake-time reference. The scheduler is normally started using vTaskStartScheduler() after the application creates its initial tasks.
