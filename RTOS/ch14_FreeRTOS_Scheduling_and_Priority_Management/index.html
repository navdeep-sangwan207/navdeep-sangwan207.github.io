Chapter Overview

The FreeRTOS scheduler determines which ready task executes on the processor. Scheduling decisions depend primarily on task priority, task state and kernel configuration. FreeRTOS supports preemptive scheduling and optional time slicing between equal-priority ready tasks. This chapter explains scheduler architecture, priority-based execution, task preemption, tick interrupts, idle task behavior and scheduler suspension and resumption.

Practical Applications

  • Create multiple tasks with different priority levels.
  • Observe how a higher-priority ready task preempts a lower-priority task.
  • Compare equal-priority task execution with time slicing enabled and disabled.
  • Configure the FreeRTOS tick rate for application timing requirements.
  • Explore idle task behavior and idle hook execution.
  • Study scheduler suspension and resumption in a controlled example.
Important: FreeRTOS normally schedules the highest-priority ready task. With preemption enabled, a newly ready higher-priority task can preempt the currently running lower-priority task. Time slicing among equal-priority ready tasks is controlled separately by configUSE_TIME_SLICING when supported by the port. Suspending the scheduler does not disable interrupts; it prevents task switching while the scheduler is suspended. Avoid lengthy suspension because it delays other ready tasks.
