Chapter Overview

Event groups allow multiple tasks to synchronize using a collection of event bits. Tasks can wait for one or more specified events before continuing execution. Software timers provide time-based operations without requiring a dedicated hardware timer for every application function. This chapter explains event flags, event groups, one-shot and auto-reload timers, callback functions and the FreeRTOS timer service task.

Practical Applications

  • Synchronize multiple tasks after system initialization.
  • Wait for sensor, communication and initialization events.
  • Implement a periodic monitoring operation using an auto-reload timer.
  • Generate a one-time timeout event using a one-shot timer.
  • Use timer callbacks to signal a task through a queue or notification.
  • Combine multiple event bits to coordinate embedded application tasks.
Important: FreeRTOS software timer callbacks execute in the timer service task, not directly in an ISR. Callback functions should remain short and must not block. Timer functionality requires the appropriate configuration, including configUSE_TIMERS and suitable timer task settings. Event-group operations from interrupts use ISR-specific APIs and may defer processing through the timer service task.
