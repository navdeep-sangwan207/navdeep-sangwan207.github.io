Chapter Overview

Queues are a fundamental inter-task communication mechanism in FreeRTOS. They allow tasks and interrupt service routines to exchange data safely without directly sharing application variables. A queue stores a finite number of fixed-size items and supports blocking operations, timeouts and data transfer. This chapter explains queue creation, sending, receiving, queue management, queue sets and communication from ISRs.

Practical Applications

  • Create a queue for transferring sensor readings between tasks.
  • Implement a producer-consumer application.
  • Transfer UART received data to a processing task.
  • Send interrupt-generated events to a task using an ISR-safe API.
  • Implement queue timeout handling.
  • Monitor multiple communication sources using queue sets.
Important: FreeRTOS queues copy items into and out of queue storage. Queue item size is fixed when the queue is created. xQueueSend() and xQueueReceive() are normally used in task context, while ISR context requires APIs such as xQueueSendFromISR() and xQueueReceiveFromISR(). When an ISR operation wakes a higher-priority task, use the port-specific yield mechanism, commonly portYIELD_FROM_ISR(). Queue sets require the corresponding FreeRTOS configuration option to be enabled.
