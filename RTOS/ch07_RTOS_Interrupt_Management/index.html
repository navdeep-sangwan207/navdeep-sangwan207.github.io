Chapter Overview

Interrupts allow a processor to respond to important hardware events without continuously polling peripheral devices. In an RTOS, interrupt handling must work correctly with task scheduling, synchronization and shared resources. This chapter explains interrupt architecture, ISR execution, latency, priority, nesting and deferred interrupt processing.

Practical Applications

  • Timer interrupt-based periodic task activation.
  • UART receive interrupt with queue-based data processing.
  • GPIO interrupt for push-button event detection.
  • ADC conversion-complete interrupt handling.
  • Sending ISR events to a high-priority processing task.
  • Reducing interrupt latency by deferring lengthy operations.
Important: FreeRTOS provides special ISR-safe APIs, such as xQueueSendFromISR() and xSemaphoreGiveFromISR(). Normal task-context APIs must not be substituted inside an ISR. Exact interrupt-priority restrictions depend on the processor port.
