Chapter Overview

A Real-Time System is a computing system in which the correctness of an operation depends not only on the logical result but also on the time at which that result is produced. This chapter introduces real-time system characteristics, classifications, timing constraints, performance metrics and practical applications.

Practical Applications

  • Automotive engine control and anti-lock braking systems.
  • Industrial automation and process-control systems.
  • Robotics and motion-control applications.
  • Medical monitoring and life-support equipment.
  • Communication systems and network equipment.
  • Embedded controllers and consumer electronics.
Important: A real-time system is not necessarily a fast system. Its essential requirement is predictable and correct behavior within specified timing constraints.
