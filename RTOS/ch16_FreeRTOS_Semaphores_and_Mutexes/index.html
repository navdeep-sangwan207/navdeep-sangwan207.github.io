Chapter Overview

Semaphores and mutexes are synchronization mechanisms used in FreeRTOS to coordinate task execution and manage shared resources. Binary semaphores are commonly used for event signaling, while counting semaphores can track multiple available resources or events. Mutexes provide mutual exclusion when tasks access shared resources and support priority inheritance to help address priority inversion. This chapter explains semaphore types, mutex operations, ISR communication and practical synchronization techniques.

Practical Applications

  • Synchronize a task with an external interrupt using a binary semaphore.
  • Manage a limited number of shared resources using a counting semaphore.
  • Protect shared variables and peripheral access using a mutex.
  • Implement recursive resource access using a recursive mutex.
  • Demonstrate priority inversion and priority inheritance.
  • Build a task synchronization application with multiple tasks.
Important: Mutexes and semaphores serve different purposes. A mutex has ownership and supports priority inheritance; a binary semaphore does not have mutex ownership semantics and is commonly used for signaling. Mutexes must not be taken or given from an ISR. Use ISR-specific semaphore APIs for interrupt communication. Recursive mutexes require matching recursive take and give operations by the owning task. Availability of APIs depends on the FreeRTOS configuration and version.
