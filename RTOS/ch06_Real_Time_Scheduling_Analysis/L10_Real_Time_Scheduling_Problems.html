1. Introduction

Real-time scheduling analysis is used to determine whether a set of tasks can complete within their specified timing constraints.

This lesson combines the mathematical methods introduced throughout Chapter 06:

  • Task timing parameters.
  • Execution time and response time.
  • Period and deadline calculations.
  • Worst-Case Execution Time (WCET).
  • CPU utilization and schedulability.
  • Rate Monotonic Scheduling (RMS).
  • Earliest Deadline First (EDF).
  • Response-time analysis.
  • Task jitter and deadline misses.
The problems are designed to develop practical scheduling-analysis skills for embedded systems and RTOS applications.

2. Important Formulas

2.1 CPU utilization

U = Σ (Cᵢ / Tᵢ)

2.2 RMS sufficient utilization bound

U ≤ n(21/n − 1)

2.3 EDF implicit-deadline utilization condition

U ≤ 1

Applies to independent periodic tasks on one ideal preemptive processor with deadlines equal to periods.

2.4 Absolute deadline

d = r + D

2.5 Response time

R = Completion Time − Release Time

2.6 Deadline margin

Margin = D − R

2.7 Hyperperiod

H = LCM(T₁, T₂, ..., Tₙ)

2.8 Fixed-priority response-time recurrence

Rᵢ = Cᵢ + Bᵢ + Σ ⌈Rᵢ / Tⱼ⌉ Cⱼ

2.9 Deadline-miss ratio

Miss Ratio = (Missed Jobs / Total Jobs) × 100%

3. Problem 1 – CPU Utilization

Consider three periodic tasks:

TaskExecution Time CPeriod T
T12 ms10 ms
T23 ms20 ms
T34 ms40 ms

Solution

Individual utilizations:

U1 = 2 / 10 = 0.20
U2 = 3 / 20 = 0.15
U3 = 4 / 40 = 0.10

Total utilization:

U = 0.20 + 0.15 + 0.10 = 0.45

Answer: Total CPU utilization is 45%.

Under the simplified ideal model, the remaining processor capacity is 55%.

5. Problem 3 – RMS Utilization Bound

A system contains five independent periodic tasks. The total processor utilization is 76%.

Step 1: Calculate the sufficient bound

Ubound = 5(21/5 − 1)
Ubound ≈ 0.7435 = 74.35%

Step 2: Compare utilization

76% > 74.35%

Answer: The task set does not pass the sufficient RMS utilization-bound test.

This result does not prove that the task set is unschedulable. Perform response-time analysis or another suitable exact test for the task model.

7. Problem 5 – Absolute Deadline and Response Time

A task has the following timing parameters:

ParameterValue
Release time12 ms
Relative deadline10 ms
Completion time19 ms

Step 1: Calculate absolute deadline

d = r + D = 12 + 10 = 22 ms

Step 2: Calculate response time

R = 19 − 12 = 7 ms

Step 3: Calculate deadline margin

Margin = 10 − 7 = 3 ms

Answer: The task meets its deadline with a 3 ms margin.

8. Problem 6 – Hyperperiod Calculation

Three tasks have periods of 5 ms, 10 ms, and 20 ms.

Solution

H = LCM(5, 10, 20)
H = 20 ms

Answer: The hyperperiod is 20 ms.

Within this interval, the release pattern repeats at the hyperperiod boundary for this periodic task set.

10. Problem 8 – Response Time with Blocking

A task has WCET 3 ms, blocking time 1 ms, and one higher-priority periodic task with WCET 1 ms and period 5 ms. The task deadline is 8 ms.

Solution

w0 = C + B = 3 + 1 = 4 ms
w1 = 3 + 1 + ⌈4/5⌉ × 1 = 5 ms
w2 = 3 + 1 + ⌈5/5⌉ × 1 = 5 ms

Converged response-time bound:

R = 5 ms

Deadline check:

5 ≤ 8 → Pass

Answer: The task meets its deadline with a 3 ms margin.

11. Problem 9 – Deadline-Miss Ratio

An embedded system executes 1,000 jobs. During testing, 12 jobs miss their deadlines.

Solution

Miss Ratio = (12 / 1000) × 100
Miss Ratio = 1.2%

Answer: The observed deadline-miss ratio is 1.2%.

An observed miss ratio is a testing metric. A low or zero observed miss ratio does not prove hard real-time correctness.

13. Problem 11 – Compare RMS and EDF

Consider the following implicit-deadline periodic tasks:

TaskWCETPeriod
T11 ms4 ms
T22 ms8 ms
T32 ms10 ms

Step 1: Calculate utilization

U = 1/4 + 2/8 + 2/10
U = 0.25 + 0.25 + 0.20 = 0.70

Step 2: RMS analysis

There are three tasks:

Ubound = 3(21/3 − 1) ≈ 77.98%

Since 70% is less than 77.98%, the task set passes the RMS sufficient utilization test.

Step 3: EDF analysis

0.70 ≤ 1.00

The task set also passes the classical EDF utilization test.

Conclusion

Both RMS and EDF pass their respective utilization tests for this task set under the stated ideal assumptions. RMS assigns priorities according to periods, whereas EDF selects jobs according to absolute deadlines.

14. Problem 12 – Embedded System Task Analysis

An embedded controller has three periodic activities:

TaskFunctionWCETPeriod
T1Sensor acquisition1 ms10 ms
T2Control calculation2 ms20 ms
T3Display update3 ms100 ms

Step 1: Calculate utilization

U = 1/10 + 2/20 + 3/100
U = 0.10 + 0.10 + 0.03 = 0.23

Total utilization is 23%.

Step 2: Assign RMS priorities

TaskPeriodPriority
Sensor acquisition10 msHighest
Control calculation20 msMedium
Display update100 msLowest

Step 3: Engineering considerations

  • Measure or bound sensor acquisition execution time.
  • Ensure the control task receives sufficiently fresh sensor data.
  • Prevent slow display operations from blocking critical control work.
  • Analyze shared-resource blocking.
  • Account for timer, UART, and ADC interrupt execution.
  • Define a safe response if a control deadline is missed.

Conclusion: The utilization is low in this simplified model. A complete design still requires response-time analysis, blocking analysis, interrupt analysis, and verification of the actual deadlines.
