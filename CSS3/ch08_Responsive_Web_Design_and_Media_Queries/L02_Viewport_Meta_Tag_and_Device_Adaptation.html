2. What Is a Viewport?

A viewport is the visible area through which a user views a web document in a browser.

The viewport provides the reference area for CSS layout and rendering. Its dimensions can change when the browser window is resized, the device is rotated or browser interface elements appear or disappear.

Example

Suppose a browser window has a layout viewport width of 1200 CSS pixels. A CSS element using width: 50% may occupy half of its containing block's available width.

Example visible layout area
CSS pixels are logical units used by the browser. They are not necessarily equal to physical hardware pixels.

3. Viewport vs Physical Screen Size

The physical screen is the hardware display of a device. The viewport is the browser's visible layout area.

Term Meaning
Physical screen The actual display hardware.
CSS pixel A logical unit used by CSS layout.
Device pixel ratio Relationship between physical pixels and CSS pixels.
Layout viewport The viewport used by the browser for layout calculations.
Visual viewport The currently visible portion of the page, which can differ from the layout viewport during zooming or when an on-screen keyboard appears.

Device Pixel Ratio

Device Pixel Ratio (DPR) describes the relationship between physical display pixels and CSS pixels.

For example, a device with a DPR of 2 may use approximately two physical pixels for each CSS pixel in each dimension. 

window.devicePixelRatio

This JavaScript expression returns the device pixel ratio of the current display environment.

DPR is useful when selecting high-resolution images and understanding display sharpness. It does not mean that CSS layout dimensions should simply be multiplied by DPR.

4. What Is the Viewport Meta Tag?

The viewport meta tag is an HTML metadata element that provides instructions to mobile browsers about the initial viewport configuration.

Standard Syntax

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

It is normally placed inside the document's head section.

Why Is It Needed?

Without an appropriate viewport configuration, some mobile browsers may use a wider virtual layout viewport for pages that do not provide mobile viewport instructions.

This can make a desktop-oriented page appear scaled down instead of being laid out at the device's CSS viewport width.

5. Understanding Viewport Meta Tag Properties

Property Purpose Example
width Sets the layout viewport width. width=device-width
initial-scale Sets the initial zoom scale. initial-scale=1.0
minimum-scale Specifies a minimum permitted zoom scale. minimum-scale=1.0
maximum-scale Specifies a maximum permitted zoom scale. maximum-scale=3.0
user-scalable Controls whether user zooming is permitted. user-scalable=yes
Avoid disabling user zoom. Users with low vision may depend on pinch-to-zoom. Accessibility guidance recommends allowing users to enlarge content.

6. Understanding width=device-width

The width=device-width setting tells the browser to use the device's available CSS viewport width as the layout viewport width.

Example

<meta name="viewport"
      content="width=device-width">

This helps the page use the available mobile layout width rather than being laid out as a wider desktop-style page.

Common Alternative

<meta name="viewport"
      content="width=1024">

This specifies a fixed layout viewport width of 1024 CSS pixels rather than adapting the layout viewport to the device width.

For normal responsive websites, width=device-width is the recommended choice.

7. Understanding initial-scale

initial-scale specifies the initial zoom level when the page is first displayed.

Example

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

A value of 1.0 represents the initial scale at the browser's normal CSS viewport scale.

Value General Meaning
initial-scale=1 Normal initial scale.
initial-scale=2 Initial view is zoomed in.
initial-scale=0.5 Initial view is zoomed out.

In typical responsive development, initial-scale=1.0 is used.

8. Minimum-Scale, Maximum-Scale and User-Scalable

These viewport settings can restrict how far a user can zoom.

Example

<meta name="viewport"
      content="width=device-width,
               initial-scale=1.0,
               minimum-scale=1.0,
               maximum-scale=3.0,
               user-scalable=yes">

This example permits user scaling within the specified range, subject to browser behaviour.

Do not use maximum-scale=1 or user-scalable=no as a routine responsive design technique. Restricting zoom can prevent users from enlarging content.

9. CSS Viewport Units

CSS provides viewport-relative units that allow elements to be sized in relation to viewport dimensions.

Unit Meaning
vw 1% of the large viewport width.
vh 1% of the large viewport height.
vmin 1% of the smaller viewport dimension.
vmax 1% of the larger viewport dimension.
svh / svw 1% of the small viewport height or width.
lvh / lvw 1% of the large viewport height or width.
dvh / dvw 1% of the dynamic viewport height or width.

Example: Viewport Width

.container {
    width: 80vw;
}

The container width is 80% of the large viewport width for the vw unit.

Example: Viewport Height

.hero {
    min-height: 100vh;
}

This gives the hero section a minimum height equal to 100% of the large viewport height.

Example: Dynamic Viewport Height

.mobile-panel {
    min-height: 100dvh;
}

The dvh unit responds to changes in the dynamic viewport height, which can change as mobile browser interface elements expand or collapse.

On mobile browsers, 100vh may not always match the currently visible height because browser interface elements can change the visual area. Consider 100dvh or 100svh where the design requires more predictable behaviour.

10. Complete Responsive HTML Document

HTML and CSS

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width,
                   initial-scale=1.0">

    <title>Responsive Page</title>

    <style>

        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            font-family: Arial, sans-serif;
        }

        header {
            background: #174ea6;
            color: white;
            padding: 20px;
            text-align: center;
        }

        .container {
            width: min(90%, 1100px);
            margin: 30px auto;
        }

        .cards {
            display: grid;

            grid-template-columns:
                repeat(auto-fit, minmax(220px, 1fr));

            gap: 20px;
        }

        .card {
            background: #eef5ff;
            padding: 20px;
            border-radius: 8px;
        }

        img {
            max-width: 100%;
            height: auto;
        }

    </style>

</head>

<body>

    <header>
        <h1>My Responsive Website</h1>
    </header>

    <main class="container">

        <h2>Our Courses</h2>

        <section class="cards">

            <article class="card">
                <h3>C++</h3>
                <p>Programming fundamentals.</p>
            </article>

            <article class="card">
                <h3>Linux</h3>
                <p>Linux commands and tools.</p>
            </article>

            <article class="card">
                <h3>Embedded Systems</h3>
                <p>Embedded development.</p>
            </article>

        </section>

    </main>

</body>
</html>

Expected Result

  • The document uses the device's CSS viewport width.
  • The page has a centered maximum-width content container.
  • Course cards automatically adapt to available width.
  • Images cannot exceed their containing block's width.
  • The layout can be viewed on mobile and desktop screens.

11. Common Viewport Configuration Problems

Problem Likely Cause Solution
Mobile page appears zoomed out. Missing or incorrect viewport meta tag. Add width=device-width and initial-scale=1.
Horizontal scrolling appears. Fixed-width elements or overflowing content. Inspect widths, minimum sizes and overflow.
Images extend beyond the screen. Image dimensions exceed the container. Use max-width: 100%.
Mobile page content is too small. Desktop-oriented layout or fixed dimensions. Use responsive sizing and appropriate breakpoints.
Full-height mobile section behaves unexpectedly. Dynamic browser interface changes viewport height. Consider svh or dvh where appropriate.

12. Debugging with Browser Developer Tools

  1. Open the website in Chrome.
  2. Press F12 to open Developer Tools.
  3. Enable the device toolbar using Ctrl + Shift + M.
  4. Select a device preset or enter a custom viewport size.
  5. Inspect the page at different widths.
  6. Check for horizontal overflow.
  7. Inspect elements with unexpected dimensions.
  8. Test portrait and landscape orientations.

Useful JavaScript Expressions

// Layout viewport width
document.documentElement.clientWidth;

// Layout viewport height
document.documentElement.clientHeight;

// Window inner width
window.innerWidth;

// Window inner height
window.innerHeight;

// Device pixel ratio
window.devicePixelRatio;

// Visual viewport information
window.visualViewport.width;
window.visualViewport.height;
These expressions can help diagnose viewport behaviour. The exact relationship between innerWidth, document dimensions and visualViewport depends on browser state and zoom.

13. Placement Interview Questions and Answers

Q1. What is a viewport?

Answer: It is the visible area through which the user views a web document in a browser.

Q2. What is the viewport meta tag?

Answer: It is an HTML metadata element that provides viewport configuration instructions to browsers, especially for mobile rendering.

Q3. Why do we use width=device-width?

Answer: It configures the layout viewport to use the device's available CSS viewport width.

Q4. What does initial-scale=1.0 mean?

Answer: It sets the initial page zoom scale to the normal scale.

Q5. What happens if the viewport meta tag is missing?

Answer: Some mobile browsers may use a wider virtual layout viewport, causing desktop-oriented pages to appear scaled down.

Q6. What is a CSS pixel?

Answer: A logical unit used by CSS for layout and rendering. It does not necessarily equal one physical display pixel.

Q7. What is devicePixelRatio?

Answer: It describes the relationship between physical display pixels and CSS pixels.

Q8. What is the difference between vw and vh?

Answer: vw is based on viewport width, while vh is based on viewport height.

Q9. What is the difference between 100vh and 100dvh?

Answer: 100vh uses the large viewport height basis, while 100dvh uses the dynamic viewport height, which can change with browser interface visibility.

Q10. Should we disable user zoom?

Answer: No. User zoom should generally remain available because it is important for accessibility.

Q11. What is the difference between layout viewport and visual viewport?

Answer: The layout viewport is used for page layout calculations, while the visual viewport represents the currently visible portion of the page.

Q12. Where should the viewport meta tag be placed?

Answer: Inside the head element of an HTML document.
