Lecture 5: Fluid Layouts and Responsive Units

Chapter 8 – Responsive Web Design and Media Queries

Learn to build flexible layouts that adapt naturally to available screen space.

1. Learning Objectives

  • Understand fixed and fluid layouts.
  • Understand percentage-based sizing.
  • Use em and rem units for scalable layouts.
  • Understand viewport-relative units.
  • Use vw, vh, svh, lvh and dvh appropriately.
  • Build flexible containers.
  • Use CSS Grid and Flexbox for fluid layouts.
  • Understand min(), max() and clamp() for responsive sizing.
  • Prevent horizontal overflow.
  • Build practical responsive page layouts.

2. What Is a Fixed Layout?

A fixed layout uses dimensions that remain constant regardless of the available viewport width.

Example

.container {
    width: 1000px;
    margin: auto;
}

The container remains 1000px wide. On a viewport narrower than 1000px, it may cause horizontal scrolling.

Limitations

  • Does not adapt naturally to different screen sizes.
  • Can create horizontal overflow.
  • May require many media queries.
  • Can waste available space on smaller or larger screens.

3. What Is a Fluid Layout?

A fluid layout uses flexible dimensions so that its components adapt to the available space.

Example

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
}

The container occupies 90% of its containing block's width but stops growing when it reaches 1200px.

Advantages

  • Adapts to different viewport widths.
  • Reduces unnecessary horizontal scrolling.
  • Works well with responsive Grid and Flexbox.
  • Can reduce the number of required breakpoints.
  • Supports flexible content arrangements.
A fluid layout does not mean every dimension should be percentage-based. Use flexible dimensions where useful and maximum or minimum constraints where necessary.

4. Fixed Layout vs Fluid Layout

Feature Fixed Layout Fluid Layout
Width Often fixed in px Often relative or flexible
Adaptability Limited Adapts to available space
Small screens May overflow Can fit available width
Common techniques Fixed width and height Percentages, Grid, Flexbox and constraints

5. Percentage-Based Sizing

Percentage values define dimensions relative to a reference size, commonly the corresponding dimension of the containing block.

Example

.parent {
    width: 800px;
}

.child {
    width: 50%;
}

The child width is 400px because 50% of the containing block's 800px width is 400px.

Common Uses

.container {
    width: 90%;
}

.sidebar {
    width: 30%;
}

.main-content {
    width: 70%;
}

img {
    max-width: 100%;
    height: auto;
}

Important Percentage Rules

  • Percentage width generally refers to the containing block's width.
  • Percentage height requires an appropriate definite containing-block height in common cases.
  • Percentage padding and margins are calculated relative to the containing block's inline size, including vertical padding and margins.
  • Percentage sizing can be affected by the formatting context and property being used.

6. em Unit

The em unit is relative to the computed font size of the element for font-size declarations, and generally to the element's own computed font size for other properties.

Example

.parent {
    font-size: 20px;
}

.child {
    font-size: 1.5em;
    padding: 1em;
}

The child font size is 30px. Its padding is also 30px because padding uses the child's computed font size.

Common Uses

.button {
    font-size: 1rem;
    padding: 0.7em 1.2em;
}

.card {
    padding: 1.5em;
}
Nested em-based font sizes can compound because each element's font-size may be calculated relative to its parent. This can be useful, but it requires careful control.

7. rem Unit

The rem unit is relative to the computed font size of the root element, normally the html element.

Example

html {
    font-size: 16px;
}

.heading {
    font-size: 2rem;
}

.container {
    padding: 1.5rem;
}

With a root font size of 16px:

  • 2rem = 32px.
  • 1.5rem = 24px.
  • 1rem = 16px.

em vs rem

Feature em rem
Reference Element or parent font size, depending on property Root element font size
Nesting Can compound Does not compound through nested font-size calculations
Common use Component-relative spacing Consistent global sizing

8. Viewport Width Unit (vw)

The vw unit represents 1% of the viewport's width.

Example

.hero {
    width: 80vw;
}

If the viewport width is 1000px, 80vw equals 800px.

Practical Uses

.hero {
    width: 100vw;
}

.heading {
    font-size: 5vw;
}
A width of 100vw can create horizontal overflow in some environments because viewport units may include the width of a vertical scrollbar. For normal full-width sections, width: 100% is often safer.

9. Viewport Height Unit (vh)

The vh unit represents 1% of the viewport's height.

Example

.hero {
    min-height: 100vh;
}

The section has a minimum height equal to the viewport height.

Practical Uses

  • Full-screen landing page sections.
  • Hero areas.
  • Fullscreen application panels.
  • Presentation-style interfaces.
On mobile browsers, the visible viewport can change as browser toolbars appear or disappear. A 100vh section may not always match the currently visible area exactly.

10. Modern Viewport Height Units

Modern CSS provides additional viewport-relative units to handle changing browser interface areas.

Unit Meaning
svh 1% of the small viewport height.
lvh 1% of the large viewport height.
dvh 1% of the dynamic viewport height.

Example

.hero {
    min-height: 100vh;
    min-height: 100svh;
}

.dynamic-panel {
    min-height: 100dvh;
}

The first declaration provides a fallback. Browsers supporting svh use the newer declaration.

  • svh uses the small viewport size, typically with browser UI expanded.
  • lvh uses the large viewport size, typically with browser UI retracted.
  • dvh follows the dynamic viewport size as browser UI changes.
Dynamic viewport units can change during scrolling and may cause layout movement. Choose the unit based on the intended interface behaviour rather than automatically replacing every vh declaration.

11. Other Useful Responsive Units

Unit Meaning Common Use
vmin 1% of the smaller viewport dimension Responsive square elements
vmax 1% of the larger viewport dimension Viewport-relative effects
ch Based on the width of the "0" glyph in the element's font Readable text line lengths
ex Based on the x-height of the font Font-relative sizing
lh Based on the element's computed line height Vertical spacing
rlh Based on the root element's computed line height Consistent vertical rhythm

Example: Readable Text Width

.article {
    max-width: 70ch;
    margin-inline: auto;
}

This constrains the article's width using a font-relative measure, often useful for readable paragraphs.

12. Flexible Width Using min() and max()

CSS provides min() and max() functions to calculate dimensions using the smaller or larger of multiple values.

min() Function

.container {
    width: min(90%, 1200px);
}

The browser chooses the smaller value between 90% and 1200px.

max() Function

.container {
    width: max(80%, 300px);
}

The browser chooses the larger value between 80% and 300px.

These functions are useful for responsive sizing without adding multiple media queries.

13. Responsive Containers Using clamp()

The clamp() function sets a preferred value between a minimum and maximum.

Syntax

clamp(minimum, preferred, maximum)

Example

.container {
    width: clamp(300px, 90%, 1200px);
    margin-inline: auto;
}

The width will not fall below 300px or exceed 1200px. Between those limits, it follows 90% of its containing block.

A fixed minimum width such as 300px can still overflow if the available space is narrower than 300px. Use a percentage-aware minimum or another suitable constraint when very narrow viewports must be supported.

14. Fluid Layout Using CSS Grid

CSS Grid can automatically create flexible columns according to the available space.

Example

.card-grid {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));

    gap: 20px;
}

Explanation

  • auto-fit adjusts the number of occupied columns.
  • minmax(220px, 1fr) sets a minimum and flexible maximum track size.
  • 1fr distributes available free space.
  • gap controls spacing between cards.

15. Fluid Layout Using Flexbox

Flexbox distributes available space between flexible items and supports wrapping when space becomes limited.

Example

.flex-container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.flex-item {
    flex: 1 1 220px;
    min-width: 0;
}

Explanation

  • display:flex creates a flex container.
  • flex-wrap:wrap allows items to move onto another line.
  • flex:1 1 220px provides a flexible basis.
  • min-width:0 permits shrinking below the automatic content-based minimum when appropriate.
Grid is often convenient for two-dimensional card layouts. Flexbox is often convenient for one-dimensional arrangements. Both can create responsive fluid interfaces.

16. Fluid Images and Media

Images should adapt to the available width without exceeding their containing blocks.

Common Responsive Image CSS

img,
video {
    max-width: 100%;
    height: auto;
}

For a Fixed-Height Card Image

.card-image {
    width: 100%;
    height: 180px;
    object-fit: cover;
}

object-fit: cover maintains the image aspect ratio while filling the specified dimensions. Some cropping may occur.

17. Preventing Horizontal Overflow

Horizontal overflow occurs when content becomes wider than the available viewport or containing block.

Common Causes

  • Fixed-width elements.
  • Large images without responsive sizing.
  • Long unbreakable text.
  • Grid tracks with excessive minimum sizes.
  • Flex items that cannot shrink.
  • Unnecessary 100vw widths.

Useful CSS Fixes

* {
    box-sizing: border-box;
}

img,
video {
    max-width: 100%;
    height: auto;
}

.container {
    width: 90%;
    max-width: 1200px;
    margin-inline: auto;
}

.grid {
    display: grid;
    grid-template-columns:
        repeat(2, minmax(0, 1fr));
}

.flex-item {
    min-width: 0;
}

.long-text {
    overflow-wrap: anywhere;
}
Avoid using overflow-x: hidden on the body as a universal fix. It can conceal the actual layout problem and may clip content. Find and correct the element causing overflow.

18. Practical Project: Fluid Course Portal Layout

Problem Statement

Build a responsive course portal with a flexible page container, responsive card grid and fluid spacing.

Complete HTML

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Fluid Course Portal</title>

    <style>

        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            font-family: Arial, sans-serif;
            background: #f5f7fb;
        }

        header {
            background: #174ea6;
            color: white;
            padding: 1.2rem 5%;
        }

        .container {
            width: min(90%, 1200px);
            margin: 2rem auto;
        }

        h1 {
            font-size: clamp(1.6rem, 4vw, 2.5rem);
        }

        .course-grid {
            display: grid;

            grid-template-columns:
                repeat(auto-fit,
                minmax(min(100%, 230px), 1fr));

            gap: 1.2rem;
        }

        .course-card {
            background: white;
            padding: 1.5rem;
            border-radius: 10px;
            box-shadow: 0 2px 8px
                        rgba(0,0,0,0.08);

            min-width: 0;
        }

        .course-card h2 {
            color: #174ea6;
        }

    </style>

</head>

<body>

    <header>
        <h1>My Learning Portal</h1>
    </header>

    <main class="container">

        <h1>Available Courses</h1>

        <section class="course-grid">

            <article class="course-card">
                <h2>C++ Programming</h2>
                <p>Learn programming fundamentals.</p>
            </article>

            <article class="course-card">
                <h2>Linux Systems</h2>
                <p>Learn Linux and shell scripting.</p>
            </article>

            <article class="course-card">
                <h2>Embedded Systems</h2>
                <p>Explore embedded development.</p>
            </article>

            <article class="course-card">
                <h2>CSS3</h2>
                <p>Build responsive interfaces.</p>
            </article>

        </section>

    </main>

</body>
</html>

Expected Result

  • The main container adapts to viewport width.
  • The container does not exceed 1200px.
  • Heading size adjusts within defined limits.
  • Course cards automatically rearrange.
  • Card spacing remains consistent.
  • The page avoids unnecessary fixed widths.

19. Common Mistakes and Debugging

Mistake Correction
Using fixed widths everywhere. Use fluid sizing with suitable constraints.
Confusing em and rem. Understand their font-size reference.
Using 100vw unnecessarily. Use width: 100% for ordinary full-width containers.
Using 100vh without considering mobile browser UI. Consider svh, lvh or dvh according to the requirement.
Using percentage height without a suitable reference height. Define the containing block height when required.
Ignoring Grid and Flexbox minimum sizing. Use minmax(0, 1fr) or min-width: 0 where appropriate.
Using a fixed minimum wider than the viewport. Use a responsive minimum that can fit narrow screens.
Hiding overflow without investigating the cause. Inspect and correct the oversized element.

20. Placement Interview Questions and Answers

Q1. What is a fluid layout?

Answer: A layout that uses flexible dimensions to adapt to available space.

Q2. What is the difference between fixed and fluid layouts?

Answer: Fixed layouts use constant dimensions, while fluid layouts adapt dimensions according to available space.

Q3. What does 50% width mean?

Answer: It generally means half the width of the element's containing block.

Q4. What is the difference between em and rem?

Answer: em is relative to the relevant element font size, while rem is relative to the root element's computed font size.

Q5. What does 1vw represent?

Answer: One percent of the viewport width.

Q6. What does 1vh represent?

Answer: One percent of the viewport height.

Q7. What is the difference between vh and dvh?

Answer: vh uses the default viewport-height definition, while dvh follows the dynamic viewport height as browser interface areas change.

Q8. What is the purpose of minmax() in CSS Grid?

Answer: It defines minimum and maximum sizing constraints for a grid track.

Q9. What does 1fr mean?

Answer: It represents a fractional unit used to distribute available grid track space.

Q10. What is the purpose of clamp()?

Answer: It constrains a preferred value between a minimum and maximum.

Q11. Why use max-width on a container?

Answer: It prevents a fluid container from becoming excessively wide.

Q12. Why use min-width: 0 on a flex item?

Answer: It allows the item to shrink below its automatic content-based minimum when the layout requires it.

Q13. What is the difference between auto-fit and auto-fill?

Answer: auto-fill preserves empty repeated tracks, while auto-fit collapses empty tracks so occupied tracks can expand.

Q14. How can you prevent images from overflowing?

Answer: Use max-width: 100% and height: auto for ordinary responsive images.

Q15. Why can 100vw cause horizontal scrolling?

Answer: In some environments, viewport width includes the scrollbar area, causing the element to become wider than the available content area.

  • vw represents viewport width.

  • svh, lvh and dvh provide modern viewport-height options.
