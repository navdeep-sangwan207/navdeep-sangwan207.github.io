Chapter 8 – Responsive Web Design and Media Queries

Display images, videos and other media correctly across mobile, tablet and desktop screens.

1. Learning Objectives

  • Understand responsive images.
  • Prevent images from overflowing containers.
  • Use max-width and height properties.
  • Understand object-fit and object-position.
  • Use the srcset and sizes attributes.
  • Understand the picture element and source element.
  • Apply lazy loading to images.
  • Embed responsive video and iframe content.
  • Understand aspect-ratio for media containers.
  • Optimize media for frontend projects.

2. What Are Responsive Images?

Responsive images automatically adapt to the available space in a layout. They should not overflow their containers or become distorted when the viewport changes.

Problem with Fixed Image Dimensions

img {
    width: 600px;
    height: 400px;
}

A fixed width can cause an image to overflow a narrow mobile screen. A fixed width and height can also distort an image if its original aspect ratio is different.

Responsive Image Solution

img {
    max-width: 100%;
    height: auto;
}
  • max-width: 100% prevents the image from exceeding its containing block's width.
  • height: auto preserves the intrinsic aspect ratio when width is constrained.
  • display: block removes the default inline-image baseline gap in common layouts.
This is a useful default for general content images. Images used as fixed-size thumbnails or card covers may need a defined container size with object-fit.

3. Understanding Image Dimensions

An image has intrinsic dimensions and an intrinsic aspect ratio. CSS controls how the image is displayed inside the layout.

Example

img {
    width: 100%;
    height: auto;
}

The image fills the available container width and its height adjusts proportionally.

max-width vs width

Property Behaviour
width: 100% Attempts to make the image as wide as its containing block.
max-width: 100% Prevents the image from becoming wider than its containing block.
height: auto Preserves the intrinsic aspect ratio when the width changes.
height: 200px Sets a fixed height; may distort the image if width is also constrained without object-fit.

4. The object-fit Property

object-fit controls how replaced content such as an image or video fits inside its specified content box.

Syntax

img {
    width: 100%;
    height: 200px;
    object-fit: cover;
}

Common Values

Value Description
fill Stretches content to fill the box, potentially distorting it.
contain Shows the entire content while preserving aspect ratio; empty space may remain.
cover Fills the box while preserving aspect ratio; some content may be cropped.
none Displays content at its natural size, subject to clipping.
scale-down Uses the smaller rendered result of none and contain.

Example

.thumbnail {
    width: 300px;
    height: 180px;
    object-fit: cover;
}

This is commonly used for product images, course thumbnails and profile photographs.

cover and contain preserve the image's aspect ratio. The visible difference is whether cropping or empty space is allowed.

5. The object-position Property

object-position controls the alignment of replaced content inside its box. It is particularly useful with object-fit: cover.

Syntax

img {
    object-fit: cover;
    object-position: center;
}

Common Values

object-position: center;
object-position: top;
object-position: bottom;
object-position: left;
object-position: right;
object-position: 50% 30%;
object-position: 20px 40px;

The values control which part of the image remains visible when cropping occurs.

Practical Example

.profile-image {
    width: 180px;
    height: 180px;
    object-fit: cover;
    object-position: center top;
    border-radius: 50%;
}

6. Image Layout Demonstration

The following examples use remote placeholder images. An internet connection is required to load them.

Cover

Fills the image box and may crop content.

Contain

Displays the full image, possibly leaving empty space.

Fill

Fills the box and may distort the image.

7. Responsive Images with srcset

The srcset attribute provides multiple image resources so the browser can choose an appropriate candidate.

Example

<img
    src="image-800.jpg"
    srcset="
        image-400.jpg 400w,
        image-800.jpg 800w,
        image-1200.jpg 1200w
    "
    sizes="(max-width: 600px) 100vw,
           (max-width: 1000px) 80vw,
           800px"
    alt="Mountain landscape"
>

Understanding srcset

  • src provides a fallback image resource.
  • srcset lists available image candidates.
  • 400w, 800w and 1200w describe the intrinsic pixel widths of the corresponding resources.
  • sizes tells the browser the expected rendered slot width under different conditions.

What Does sizes Do?

sizes describes the image's expected layout width. The browser uses this information along with the available candidates, device pixel ratio and other factors to choose a suitable resource.

Width descriptors in srcset must represent the actual intrinsic widths of the image files. Do not label a 400px image as 800w.

8. Resolution Switching with x Descriptors

The x descriptor identifies candidate images by pixel density.

Example

<img
    src="logo-1x.png"
    srcset="
        logo-1x.png 1x,
        logo-2x.png 2x,
        logo-3x.png 3x
    "
    alt="Company logo"
>

A browser can select a higher-density image for a high-density display.

Descriptor Meaning
1x 1 device pixel per CSS pixel.
2x 2 device pixels per CSS pixel.
3x 3 device pixels per CSS pixel.
Do not mix width descriptors such as 400w with density descriptors such as 2x in the same srcset attribute.

9. The picture Element

The picture element provides multiple image sources and allows the browser to select an appropriate source based on media conditions or supported image formats.

Syntax

<picture>

    <source
        media="(max-width: 600px)"
        srcset="mobile-image.jpg"
    >

    <source
        media="(max-width: 1000px)"
        srcset="tablet-image.jpg"
    >

    <img
        src="desktop-image.jpg"
        alt="Responsive landscape"
    >

</picture>

How It Works

  • The browser evaluates source elements in order.
  • The first supported source whose conditions match can be selected.
  • The img element provides the fallback and represents the image.
  • The img element must include meaningful alternative text when the image conveys information.

Format Selection Example

<picture>

    <source
        type="image/avif"
        srcset="photo.avif"
    >

    <source
        type="image/webp"
        srcset="photo.webp"
    >

    <img
        src="photo.jpg"
        alt="Product photograph"
    >

</picture>
Use picture when art direction or format selection is needed. Use srcset and sizes for selecting among different resolutions of the same visual image.

10. Art Direction in Responsive Images

Art direction means providing different image compositions for different viewport conditions.

For example, a wide desktop photograph may not work well as a mobile hero image. A separate portrait crop can improve the composition.

Example

<picture>

    <source
        media="(max-width: 600px)"
        srcset="hero-mobile.jpg"
    >

    <img
        src="hero-desktop.jpg"
        alt="Electronics learning workspace"
        class="responsive-image"
    >

</picture>

The browser uses the mobile source when the media condition matches. Otherwise, it uses the img fallback.

11. Lazy Loading Images

Lazy loading delays loading certain images until they are near the visible area of the page.

Example

<img
    src="course-thumbnail.jpg"
    alt="Embedded systems course"
    loading="lazy"
>

Loading Attribute Values

Value Description
lazy Allows the browser to defer loading until the image is near the viewport.
eager Requests loading without lazy-loading deferral.
auto Leaves the loading decision to the browser.

Important Practice

<!-- Important above-the-fold image -->

<img
    src="hero.jpg"
    alt="Learning portal homepage"
    fetchpriority="high"
>

<!-- Image farther down the page -->

<img
    src="course.jpg"
    alt="Course thumbnail"
    loading="lazy"
>
Do not lazy-load the main above-the-fold hero image by default. Delaying a prominent image can make the page appear slower. Use loading="lazy" for suitable off-screen images.

12. Image Dimensions and Layout Stability

Supplying image dimensions helps browsers reserve space before image loading completes.

Example

<img
    src="course-banner.jpg"
    width="1200"
    height="600"
    alt="Course banner"
    class="responsive-image"
>

The width and height attributes communicate the image's intrinsic dimensions and aspect ratio.

CSS Alternative

.course-banner {
    width: 100%;
    height: auto;
    aspect-ratio: 2 / 1;
}

Reserving appropriate space helps reduce unexpected layout movement while images load.

Use the actual intrinsic dimensions in HTML attributes when possible. Do not assign arbitrary width and height attributes that misrepresent the image.

13. Responsive Video Elements

The HTML video element supports embedded video playback.

Basic Video Example

<video
    controls
    width="100%"
    poster="video-thumbnail.jpg"
>

    <source
        src="lesson-video.mp4"
        type="video/mp4"
    >

    Your browser does not support HTML video.

</video>

Responsive Video CSS

video {
    display: block;
    width: 100%;
    height: auto;
}

Using aspect-ratio

.video-container {
    width: 100%;
    aspect-ratio: 16 / 9;
}

.video-container video {
    width: 100%;
    height: 100%;
    object-fit: contain;
}

aspect-ratio reserves a consistent shape for the video container.

14. Responsive iframe Embedding

An iframe embeds another webpage or media player inside the current document.

Basic Example

<iframe
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="Course introduction video"
    allowfullscreen
></iframe>

Responsive CSS

.video-wrapper {
    width: 100%;
    aspect-ratio: 16 / 9;
}

.video-wrapper iframe {
    width: 100%;
    height: 100%;
    border: 0;
}

Complete HTML Structure

<div class="video-wrapper">

    <iframe
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="CSS tutorial"
        loading="lazy"
        allowfullscreen
    ></iframe>

</div>
Replace VIDEO_ID with a valid video identifier. A normal YouTube watch-page URL is not the same as an embeddable player URL.

15. Responsive Media Layout

Images and videos often appear inside responsive card layouts.

Example

.media-grid {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(min(100%, 250px), 1fr));
    gap: 20px;
}

.media-card img {
    display: block;
    width: 100%;
    aspect-ratio: 16 / 9;
    object-fit: cover;
}

.media-card h3 {
    font-size: 1.2rem;
}

The Grid layout adjusts the number of columns according to available space, while images maintain a consistent visual ratio.

16. Accessibility for Images and Media

Alternative Text

<img
    src="microcontroller.jpg"
    alt="LPC2129 microcontroller development board"
>

Alternative text describes meaningful image content for users who cannot see the image.

Decorative Images

<img
    src="decoration.png"
    alt=""
>

An empty alt attribute is appropriate for purely decorative images so assistive technology can ignore them.

Video Accessibility

  • Provide captions for spoken content.
  • Provide controls for user playback.
  • Give iframe elements meaningful titles.
  • Provide transcripts when appropriate.
  • Avoid autoplay with sound.

Caption Example

<video controls>

    <source
        src="lesson.mp4"
        type="video/mp4"
    >

    <track
        src="captions-en.vtt"
        kind="captions"
        srclang="en"
        label="English"
        default
    >

</video>

17. Practical Project: Responsive Course Media Gallery

Problem Statement

Create a responsive course gallery containing image cards. Images should fit their containers without distortion, and the layout should adapt to different screen sizes.

Complete HTML

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Responsive Course Gallery</title>

    <style>

        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            padding: 20px;
            font-family: Arial, sans-serif;
            background: #f1f5fb;
        }

        h1 {
            text-align: center;
            color: #174ea6;
        }

        .gallery {
            max-width: 1100px;
            margin: auto;

            display: grid;

            grid-template-columns:
                repeat(auto-fit, minmax(min(100%, 250px), 1fr));

            gap: 20px;
        }

        .card {
            background: white;
            border-radius: 10px;
            overflow: hidden;
            box-shadow: 0 2px 8px rgba(0,0,0,0.1);
        }

        .card img {
            display: block;
            width: 100%;
            aspect-ratio: 16 / 9;
            object-fit: cover;
        }

        .card-content {
            padding: 15px;
        }

        .card h2 {
            font-size: 1.25rem;
            color: #174ea6;
        }

        .card p {
            line-height: 1.6;
        }

    </style>

</head>

<body>

    <h1>My Learning Portal</h1>

    <main class="gallery">

        <article class="card">

            <img
                src="embedded.jpg"
                alt="Embedded systems development board"
                loading="lazy"
            >

            <div class="card-content">
                <h2>Embedded Systems</h2>
                <p>
                    Learn microcontrollers,
                    peripherals and embedded C.
                </p>
            </div>

        </article>

        <article class="card">

            <img
                src="linux.jpg"
                alt="Linux command line interface"
                loading="lazy"
            >

            <div class="card-content">
                <h2>Linux Programming</h2>
                <p>
                    Learn Linux commands,
                    shell scripting and system tools.
                </p>
            </div>

        </article>

        <article class="card">

            <img
                src="cpp.jpg"
                alt="C++ programming code"
                loading="lazy"
            >

            <div class="card-content">
                <h2>C++ Programming</h2>
                <p>
                    Learn programming concepts
                    and object-oriented development.
                </p>
            </div>

        </article>

    </main>

</body>
</html>

Expected Result

  • Three cards can appear in a desktop layout when space permits.
  • Cards automatically wrap into fewer columns on smaller screens.
  • Images maintain a consistent 16:9 display ratio.
  • object-fit: cover fills image areas without distortion.
  • Images do not exceed their card width.
Replace embedded.jpg, linux.jpg and cpp.jpg with actual image files or valid image paths before running the project.

18. Common Mistakes and Debugging

Mistake Correction
Using a fixed image width on mobile. Use max-width: 100% or a responsive container.
Distorting images with fixed dimensions. Use height: auto or object-fit where appropriate.
Using object-fit without defined dimensions. Define the image's content box dimensions.
Using cover when the complete image must remain visible. Use contain instead.
Incorrect srcset width descriptors. Use actual intrinsic image widths.
Using srcset without understanding sizes. Describe the expected rendered image width.
Lazy-loading the main hero image. Prioritize important above-the-fold content.
Leaving out alt text. Provide meaningful alt text or empty alt for decorative images.
Embedding a video with fixed dimensions. Use a responsive wrapper with aspect-ratio.

19. Placement Interview Questions and Answers

Q1. What is a responsive image?

Answer: An image that adapts to its available layout space or uses suitable image resources for different display conditions.

Q2. Why use max-width: 100%?

Answer: It prevents an image from exceeding the width of its containing block.

Q3. What does height: auto do?

Answer: It allows the height to adjust proportionally when the image width changes.

Q4. What is object-fit?

Answer: It controls how replaced content fits inside its specified content box.

Q5. Difference between cover and contain?

Answer: cover fills the box and may crop content; contain shows the entire content and may leave empty space.

Q6. What is object-position?

Answer: It controls the alignment of replaced content inside its content box.

Q7. What is srcset?

Answer: An HTML attribute that provides multiple image candidates for browser selection.

Q8. What is sizes?

Answer: It describes the expected rendered width of an image slot for responsive image selection.

Q9. What is the picture element?

Answer: It provides multiple image sources for art direction or format selection.

Q10. Difference between img and picture?

Answer: img represents the image; picture provides alternative source choices through nested source elements.

Q11. What is lazy loading?

Answer: It defers loading suitable off-screen images until they are near the viewport.

Q12. What is the purpose of alt?

Answer: It provides alternative text for meaningful images.

Q13. Why use aspect-ratio?

Answer: It defines a preferred width-to-height ratio and helps reserve layout space.

Q14. How do you make an iframe responsive?

Answer: Place it inside a wrapper with a suitable aspect-ratio and set its width and height to 100%.

Q15. What is art direction?

Answer: Supplying different image compositions for different display conditions.

Q16. Why specify image dimensions?

Answer: Intrinsic dimensions help the browser reserve layout space and reduce layout shifts.
