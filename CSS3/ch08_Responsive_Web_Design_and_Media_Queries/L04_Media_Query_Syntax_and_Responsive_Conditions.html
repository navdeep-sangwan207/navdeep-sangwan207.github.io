2. What Is a CSS Media Query?

A CSS media query allows developers to apply CSS rules conditionally depending on the characteristics of the browsing environment.

Media queries are commonly used to change layouts according to viewport width, orientation, input capabilities and user preferences.

Example

@media (max-width: 600px) {

    body {
        background-color: lightblue;
    }

}

The background color changes when the media query condition matches.

3. Basic Media Query Syntax

General Syntax

@media media-type and (media-feature: value) {

    /* CSS rules */

}

Example

@media screen and (min-width: 768px) {

    .container {
        width: 90%;
        margin: auto;
    }

}

Parts of a Media Query

Part Purpose
@media Starts a media query rule.
screen Media type.
and Combines a media type or condition with another condition.
min-width Media feature specifying a minimum viewport width.
768px Condition value.
{ } Contains CSS rules applied when the query matches.

4. Media Types

A media type identifies the broad category of output environment.

Media Type Meaning
all Matches all media types.
screen Matches screen-based devices.
print Matches printed pages and print preview.

Screen Example

@media screen {

    body {
        font-family: Arial, sans-serif;
    }

}

Print Example

@media print {

    nav,
    .no-print {
        display: none;
    }

    body {
        color: black;
        background: white;
    }

}

The print query can remove navigation and decorative interface elements from printed documents.

The all media type is the default when no media type is specified. For most responsive layout queries, developers commonly write @media (min-width: 768px) without explicitly writing screen.

5. Media Features

Media features describe characteristics of the output environment or user interaction preferences.

Media Feature Purpose
width Current viewport width.
height Current viewport height.
min-width Minimum viewport width.
max-width Maximum viewport width.
orientation Portrait or landscape orientation.
hover Whether the primary input mechanism can conveniently hover.
pointer Accuracy of the primary pointing device.
prefers-color-scheme User's preferred light or dark color scheme.
prefers-reduced-motion User's preference for reduced motion.

6. Width-Based Media Queries

Width-based queries are widely used for responsive layouts.

Minimum Width

@media (min-width: 768px) {

    .container {
        max-width: 1100px;
        margin: auto;
    }

}

Applies when the viewport width is 768 CSS pixels or greater.

Maximum Width

@media (max-width: 600px) {

    .container {
        padding: 10px;
    }

}

Applies when the viewport width is 600 CSS pixels or less.

Exact Width

@media (width: 768px) {

    body {
        border: 2px solid blue;
    }

}

This matches a viewport width of exactly 768 CSS pixels. Exact-width queries are uncommon for ordinary responsive layout work.

7. Height-Based Media Queries

Media queries can also respond to viewport height.

Minimum Height

@media (min-height: 700px) {

    .hero {
        min-height: 500px;
    }

}

Maximum Height

@media (max-height: 500px) {

    .hero {
        padding-block: 10px;
    }

}

Height-based queries can be useful for short browser windows, landscape phones and limited vertical space.

Do not assume that a particular viewport height always identifies a particular device. Browser interface elements and user resizing can change the available height.

8. Combining Conditions Using AND

The and operator requires all combined conditions to match.

Example

@media screen and
       (min-width: 600px) and
       (max-width: 1000px) {

    .container {
        padding: 30px;
    }

}

This query applies when the media type is screen and the viewport width is between 600px and 1000px, inclusive.

Another Example

@media (min-width: 768px) and
       (orientation: landscape) {

    .sidebar {
        display: block;
    }

}

9. Combining Conditions Using OR

A comma-separated media query list works as a logical OR. The rules apply if any one of the listed queries matches.

Example

@media (max-width: 600px),
       (orientation: portrait) {

    .container {
        padding: 10px;
    }

}

The CSS applies if the viewport is at most 600px wide OR if the viewport is in portrait orientation.

A comma-separated media query list is the standard way to express OR between complete media queries.

10. Using NOT in Media Queries

The not keyword negates a media query.

Example

@media not screen {

    body {
        font-family: serif;
    }

}

This query matches media environments other than screen, such as print.

Example with a Feature Condition

@media not (hover: hover) {

    .tooltip {
        display: none;
    }

}

This query matches environments where the primary input mechanism does not support convenient hovering.

11. Using NOT and ONLY

NOT

The not keyword negates a media query and can be used to exclude matching environments.

ONLY

The only keyword is used to prevent older browsers that do not understand media queries from applying the associated styles as if the media type were simply present.

Example

@media only screen and (min-width: 768px) {

    .container {
        width: 90%;
    }

}
Modern browsers support media queries directly. The only keyword is mainly relevant to legacy compatibility and is rarely needed in current frontend projects.

12. Orientation Media Feature

The orientation feature checks whether the viewport is in portrait or landscape orientation.

Value Meaning
portrait Viewport height is greater than or equal to viewport width.
landscape Viewport width is greater than viewport height.

Example

@media (orientation: landscape) {

    .hero {
        min-height: 300px;
    }

}

@media (orientation: portrait) {

    .hero {
        min-height: 450px;
    }

}

Live Demonstration

Viewport orientation:

Resize the browser or change the device emulation orientation to observe the message.

Orientation refers to the viewport dimensions, not necessarily the physical orientation of the device. A narrow desktop window can match portrait orientation.

13. Hover and Pointer Media Features

Hover

The hover feature checks whether the primary input mechanism can conveniently hover over elements. 

@media (hover: hover) {

    .button:hover {
        background: #174ea6;
        color: white;
    }

}

Pointer

The pointer feature describes the accuracy of the primary pointing mechanism.

Value Meaning
fine Accurate pointing device, commonly a mouse.
coarse Less precise pointing device, commonly a touchscreen.
none No pointing device.

Example

@media (pointer: coarse) {

    .button {
        min-height: 44px;
        padding: 12px 18px;
    }

}

@media (pointer: fine) {

    .button:hover {
        transform: translateY(-2px);
    }

}
Hover and pointer features describe the primary input mechanism. Use any-hover and any-pointer when you need to check whether any available input device supports those capabilities, such as a touchscreen laptop with an attached mouse.

14. User Preference Media Features

Prefers Color Scheme

The prefers-color-scheme feature detects whether the user prefers a light or dark color scheme. 

@media (prefers-color-scheme: dark) {

    body {
        background: #121212;
        color: white;
    }

}

Prefers Reduced Motion

The prefers-reduced-motion feature detects whether the user has requested reduced motion effects. 

@media (prefers-reduced-motion: reduce) {

    * {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
    }

}

This helps reduce motion effects for users who prefer a less animated interface.

Respecting user preferences is an important part of accessible frontend development.

15. Practical Example: Complete Responsive Layout

Problem Statement

Create a page that:

  • Uses one column on narrow screens.
  • Uses two columns on medium screens.
  • Uses three columns on wide screens.
  • Adapts navigation for mobile.
  • Uses a different layout in landscape orientation.

Complete HTML

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Responsive Media Query Demo</title>

    <style>

        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            font-family: Arial, sans-serif;
        }

        header {
            background: #174ea6;
            color: white;
            padding: 20px;
        }

        nav {
            display: flex;
            flex-direction: column;
            gap: 12px;
        }

        .container {
            width: 90%;
            margin: 25px auto;
        }

        .cards {
            display: grid;
            grid-template-columns: 1fr;
            gap: 20px;
        }

        .card {
            background: #eef5ff;
            padding: 20px;
            border-radius: 8px;
        }

        @media (min-width: 600px) {

            .cards {
                grid-template-columns: repeat(2, 1fr);
            }

            nav {
                flex-direction: row;
            }

        }

        @media (min-width: 900px) {

            .cards {
                grid-template-columns: repeat(3, 1fr);
            }

        }

        @media (orientation: landscape) {

            header {
                padding: 12px 20px;
            }

        }

        @media (prefers-reduced-motion: reduce) {

            * {
                animation: none !important;
                transition: none !important;
            }

        }

    </style>

</head>

<body>

    <header>
        <nav>
            <strong>My Portal</strong>
            <span>Home</span>
            <span>Courses</span>
            <span>Projects</span>
        </nav>
    </header>

    <main class="container">

        <h1>Our Courses</h1>

        <section class="cards">

            <article class="card">
                <h2>C++</h2>
                <p>Programming fundamentals.</p>
            </article>

            <article class="card">
                <h2>Linux</h2>
                <p>Linux commands and scripting.</p>
            </article>

            <article class="card">
                <h2>Embedded Systems</h2>
                <p>Embedded development.</p>
            </article>

        </section>

    </main>

</body>
</html>

Expected Result

  • One card column below 600px.
  • Two card columns from 600px.
  • Three card columns from 900px.
  • Navigation changes direction at 600px.
  • Header spacing changes in landscape orientation.
  • Motion effects are reduced when requested by the user.

16. Common Media Query Mistakes

Mistake Correction
Missing parentheses around feature conditions. Use correct media query syntax.
Confusing min-width and max-width. Understand inclusive width conditions.
Using overlapping ranges unintentionally. Plan breakpoint boundaries carefully.
Ignoring CSS source order. Check specificity and cascade order.
Using orientation to identify device type. Remember orientation is based on viewport dimensions.
Using hover effects as the only interaction. Support keyboard focus and touch interaction.
Ignoring reduced-motion preferences. Provide reduced-motion styles where needed.

17. Debugging Media Queries

  1. Open the page in Chrome.
  2. Press F12 to open Developer Tools.
  3. Enable the device toolbar.
  4. Change the viewport width.
  5. Inspect the element whose style should change.
  6. Check whether the media query condition matches.
  7. Inspect crossed-out CSS declarations.
  8. Check specificity and source order.
  9. Test the layout just below and above each breakpoint.

Useful CSS Debugging Example

@media (min-width: 768px) {

    .container {
        outline: 3px solid red;
    }

}

The outline can temporarily help identify whether the media query is applying to the expected element. Remove debugging styles before release.

18. Placement Interview Questions and Answers

Q1. What is a media query?

Answer: A CSS rule that applies styles conditionally based on media features and environment characteristics.

Q2. What is the basic media query syntax?

Answer: @media followed by optional media type and conditions, with CSS rules inside braces.

Q3. What is the difference between min-width and max-width?

Answer: min-width matches widths at or above the specified value; max-width matches widths at or below it.

Q4. What does the and operator do?

Answer: It requires all combined media query conditions to match.

Q5. How do you express OR in media queries?

Answer: Use a comma-separated media query list.

Q6. What is the orientation feature?

Answer: It checks whether the viewport is in portrait or landscape orientation.

Q7. What is the difference between hover and pointer?

Answer: hover describes whether the primary input mechanism can conveniently hover; pointer describes pointing accuracy.

Q8. What does prefers-color-scheme detect?

Answer: It detects the user's preferred light or dark color scheme.

Q9. What does prefers-reduced-motion do?

Answer: It detects a user preference for reduced motion effects.

Q10. What is the print media type used for?

Answer: It applies CSS specifically for printed pages and print preview.

Q11. What is a comma-separated media query list?

Answer: It represents alternative queries. The rule applies if at least one query matches.

Q12. Does orientation identify a mobile phone?

Answer: No. It describes viewport dimensions, not the device category.

Q13. What does @media only screen mean?

Answer: It targets screen media and historically helps prevent older browsers from interpreting the rule incorrectly.

Q14. Can media queries be combined?

Answer: Yes. Conditions can be combined using and, comma-separated alternatives, and not.

Q15. How do you debug a media query?

Answer: Use browser Developer Tools to inspect viewport size, matching rules, specificity and CSS source order.
