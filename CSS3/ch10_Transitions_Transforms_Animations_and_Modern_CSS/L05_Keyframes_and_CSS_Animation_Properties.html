2. What is CSS Animation?

CSS animation allows an element to change its visual properties over time without requiring JavaScript to control every frame.

Animations are generally defined using the @keyframes rule and applied using animation properties.

Basic Example

@keyframes changeColor {
    from {
        background-color: blue;
    }

    to {
        background-color: green;
    }
}

.box {
    animation-name: changeColor;
    animation-duration: 3s;
}

How It Works

  1. Define the animation using @keyframes.
  2. Assign a name to the animation.
  3. Apply that name to an element.
  4. Specify its duration and other properties.
  5. The browser interpolates the animated values over time.

3. CSS Transition vs CSS Animation

CSS Transition CSS Animation
Usually responds to a change in property value. Can run automatically when applied.
Typically moves between two states. Supports multiple intermediate keyframes.
Commonly triggered by hover, focus or class changes. Can repeat, reverse and run in multiple directions.
Uses transition properties. Uses @keyframes and animation properties.
Does not provide a dedicated iteration-count property. Supports animation-iteration-count.
Use transitions for simple state changes, such as a button hover. Use animations when you need multiple stages, repeated motion or more control over the sequence.

4. Understanding @keyframes

The @keyframes rule defines the intermediate stages of a CSS animation.

Syntax

@keyframes animationName {
    from {
        /* Starting styles */
    }

    to {
        /* Ending styles */
    }
}

Example

@keyframes moveBox {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }
}

.box {
    animation-name: moveBox;
    animation-duration: 2s;
}

Expected Result

The box moves from its original position to a position 200px to the right over two seconds.

5. Using Percentage Keyframes

Percentage keyframes allow multiple stages within one animation.

Example

@keyframes colorAnimation {
    0% {
        background-color: blue;
    }

    25% {
        background-color: orange;
    }

    50% {
        background-color: red;
    }

    75% {
        background-color: purple;
    }

    100% {
        background-color: green;
    }
}

.box {
    animation: colorAnimation 5s infinite;
}

The percentage represents the position in the animation timeline.

Color changes continuously:

Color
from is equivalent to 0%, and to is equivalent to 100%. You can use either form or combine them with intermediate percentage keyframes.

6. animation-name

Specifies the name of the @keyframes animation to apply. 

@keyframes slide {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(100px);
    }
}

.box {
    animation-name: slide;
}

If the animation name does not match a defined @keyframes rule, the animation does not run.

7. animation-duration

Defines how long one complete animation cycle takes. 

.box {
    animation-name: slide;
    animation-duration: 2s;
}
Value Meaning
1s One second per iteration.
500ms Half a second per iteration.
3s Three seconds per iteration.
The initial value of animation-duration is 0s. A keyframe animation will not have a visible timed progression unless a non-zero duration is specified.

8. animation-timing-function

Controls the rate of change during an animation.

Value Behavior
linear Constant rate of change.
ease Starts slowly, speeds up and slows down at the end.
ease-in Starts slowly.
ease-out Ends slowly.
ease-in-out Starts and ends slowly.
steps() Changes in discrete steps.
cubic-bezier() Defines a custom cubic Bézier timing curve.

Example

.box {
    animation: slide 2s ease-in-out;
}

Custom Timing Function

.box {
    animation-timing-function:
        cubic-bezier(0.42, 0, 0.58, 1);
}

cubic-bezier() allows developers to control acceleration and deceleration more precisely.

9. animation-delay

Specifies how long the browser waits before starting an animation. 

.box {
    animation-name: slide;
    animation-duration: 2s;
    animation-delay: 1s;
}

A positive delay postpones the start. A negative delay starts the animation as though it had already been running for that amount of time.

Example

.box {
    animation: slide 2s ease 1s;
}

10. animation-iteration-count

Specifies how many times the animation should repeat.

Value Meaning
1 Runs once.
2 Runs twice.
5 Runs five times.
infinite Repeats continuously.

Example

.box {
    animation: pulse 1s infinite;
}

11. animation-direction

Defines the direction in which keyframes are played.

Value Behavior
normal Every iteration plays from 0% to 100%.
reverse Every iteration plays from 100% to 0%.
alternate Alternates between normal and reverse directions.
alternate-reverse Starts in reverse and alternates direction.

Example

.box {
    animation: slide 2s ease infinite alternate;
}

The element moves forward and then backward on successive iterations.

12. animation-fill-mode

Determines which styles apply before and after the animation executes.

Value Behavior
none No animation styles are retained outside the active animation period.
forwards Retains the styles from the final relevant keyframe after completion.
backwards Applies the appropriate starting keyframe during the delay period.
both Combines forwards and backwards behavior.

Example

@keyframes fadeIn {
    from {
        opacity: 0;
    }

    to {
        opacity: 1;
    }
}

.box {
    animation: fadeIn 2s ease forwards;
}

Animation uses forwards to retain its final state:

Fade In

13. animation-play-state

Controls whether an animation is running or paused.

Value Behavior
running Animation continues to play.
paused Animation pauses at its current point.

Example

.loader {
    animation: rotateBox 2s linear infinite;
}

.loader:hover {
    animation-play-state: paused;
}

This is useful when users need to pause decorative or continuous motion.

14. animation shorthand

The animation shorthand combines multiple animation properties into one declaration.

Syntax

animation:
    name
    duration
    timing-function
    delay
    iteration-count
    direction
    fill-mode
    play-state;

Example

.box {
    animation:
        slide 2s ease-in-out 1s infinite alternate both;
}
Value Property
slide animation-name
2s animation-duration
ease-in-out animation-timing-function
1s animation-delay
infinite animation-iteration-count
alternate animation-direction
both animation-fill-mode
In the shorthand, the first time value is duration and the second time value is delay. The order of several other values is flexible, but using the conventional order improves readability.

15. Multiple Animations on One Element

Multiple animations can be applied to the same element by separating animation definitions with commas.

Example

@keyframes move {
    to {
        translate: 100px 0;
    }
}

@keyframes fade {
    to {
        opacity: 0.4;
    }
}

.box {
    animation:
        move 2s ease-in-out infinite alternate,
        fade 1s linear infinite alternate;
}

Both animations run on the same element. When different animations affect the same property, their interactions must be considered.

Multiple animations can compete for the same property. Prefer separate properties or nested elements when independent effects are needed. Also remember that transform is one combined property, so two animations that both set transform may override one another according to animation composition and cascade rules.

18. CSS Animation Performance

Animation performance matters when building smooth interfaces.

Properties Commonly Suitable for Animation

  • transform
  • opacity

Properties That May Cause Layout or Paint Work

  • width and height
  • top, right, bottom and left
  • margin and padding
  • box-shadow and background properties
Transform and opacity are often efficient choices because browsers can frequently animate them without recalculating layout. Actual performance depends on the browser, device, rendering pipeline and page complexity.

Using will-change

.animated-card {
    will-change: transform;
}

will-change hints that a property is likely to change. Use it only when there is a measured need.

Avoid applying will-change to every element. Excessive use can consume memory and create additional rendering layers.

19. Accessibility and Reduced Motion

Some users prefer reduced animation because of motion sensitivity or accessibility requirements.

Using prefers-reduced-motion

@media (prefers-reduced-motion: reduce) {
    .animated-element {
        animation: none;
        transition: none;
    }
}

This media feature detects a user's operating-system or browser preference for reduced motion.

Good Practices

  • Avoid unnecessary continuous motion.
  • Provide a way to pause important ongoing animations.
  • Do not use flashing effects that may trigger seizures.
  • Respect prefers-reduced-motion.
  • Do not communicate essential information through animation alone.

20. Common Mistakes and Debugging

Problem Likely Cause or Solution
Animation does not run. Check the keyframe name, animation-name and non-zero duration.
Animation stops after one cycle. Use animation-iteration-count: infinite or a suitable count.
Element returns to its original style. Use animation-fill-mode: forwards when the final state must be retained.
Animation starts too early. Check animation-delay.
Animation moves in the wrong direction. Check animation-direction and keyframe values.
Animation feels abrupt. Adjust animation-timing-function and keyframe positions.
Motion is jerky. Prefer suitable transform and opacity animations; profile performance.
Animation overrides another effect. Check whether multiple animations modify the same property.

Browser DevTools Checklist

  1. Inspect the animated element.
  2. Check the computed animation properties.
  3. Verify that the @keyframes name exists.
  4. Inspect duration, delay and iteration count.
  5. Use the browser's animation inspection tools where available.
  6. Check reduced-motion preferences.
  7. Test on a slower device or throttled environment if necessary.

21. Placement Interview Questions

Q1. What is CSS animation?

Answer: CSS animation changes an element's visual properties over time using keyframes and animation properties.

Q2. What is @keyframes?

Answer: It defines the intermediate stages of an animation.

Q3. What is the difference between from and to?

Answer: from represents 0% of the animation timeline and to represents 100%.

Q4. What is animation-duration?

Answer: It specifies the duration of one animation iteration.

Q5. What is animation-delay?

Answer: It specifies the delay before the animation begins. Negative delays start the animation partway through its timeline.

Q6. What is animation-iteration-count?

Answer: It defines the number of times an animation repeats.

Q7. What is animation-direction?

Answer: It defines whether keyframes play normally, in reverse or in alternating directions.

Q8. What is animation-fill-mode?

Answer: It controls which keyframe styles apply outside the active animation interval.

Q9. What is animation-play-state?

Answer: It controls whether an animation is running or paused.

Q10. What is the difference between ease and linear?

Answer: linear maintains a constant rate of change, while ease accelerates and decelerates.

Q11. Can multiple animations be applied to one element?

Answer: Yes. Multiple animation definitions can be separated by commas.

Q12. Why is transform preferred for many animations?

Answer: Transform can often be animated without triggering layout recalculation, which may improve performance.

Q13. What is prefers-reduced-motion?

Answer: It is a media feature that detects a user's preference for reduced motion.

Q14. What is the purpose of will-change?

Answer: It hints to the browser that a property is expected to change, allowing possible rendering optimizations.

23. SVG Graph and Curve Animation Using CSS

CSS can animate SVG graphics, including graph axes, lines, polylines and path-based curves. The stroke-dasharray and stroke-dashoffset properties can create a drawing effect, making a curve appear progressively plotted.

23.1 Animating an SVG Path

/* SVG curve drawing animation */
.curve {
    fill: none;
    stroke: crimson;
    stroke-width: 3;
    stroke-dasharray: 500;
    stroke-dashoffset: 500;
    animation: drawCurve 3s ease forwards;
}

@keyframes drawCurve {
    to {
        stroke-dashoffset: 0;
    }
}

23.2 How the Drawing Effect Works

  • stroke-dasharray: Sets the stroke's dash pattern or dash length.
  • stroke-dashoffset: Offsets the dash pattern along the stroke.
  • Animation: Changing the offset gradually reveals the stroke.
  • forwards: Keeps the animation's final keyframe state after it finishes.

23.3 Animate Graph Axes and Curves Sequentially

/* Axes */
.axis {
    stroke-dasharray: 500;
    stroke-dashoffset: 500;
    animation: draw 2s ease forwards;
}

/* Curves begin after the axes animation delay */
.curve {
    stroke-dasharray: 500;
    stroke-dashoffset: 500;
    animation: draw 3s ease 2s forwards;
}

@keyframes draw {
    to {
        stroke-dashoffset: 0;
    }
}

Assign the axis class to SVG axis elements and the curve class to SVG path elements. The curves begin after the two-second delay while the axes animate.

23.4 Example: Animated Graph

<svg width="350" height="200"
     xmlns="http://www.w3.org/2000/svg">

    <polyline class="axis" points="
        10,100 10,90 0,100 10,110 10,100
        340,100 340,110 350,100 340,90 340,100" />

    <polyline class="axis" points="
        175,10 185,10 175,0 165,10 175,10
        175,190 165,190 175,200 185,190 175,190" />

    <path class="curve"
        d="M 175,100 Q 180 86,250 82 T 330 60" />

    <path class="curve"
        d="M 175,100 Q 60 117,40 120 T 20 180" />
</svg>
The CSS drawing technique works for many SVG strokes, but the dash length should be sufficiently large for the length of the path. For more precise effects, the path length can be measured or calculated and used for the dash values.

24. Lecture Summary

  • CSS animations are defined using @keyframes.
  • Keyframes can use from, to and percentage values.
  • animation-name selects the keyframe animation.
  • animation-duration defines one iteration's duration.
  • animation-timing-function controls the rate of change.
  • animation-delay controls the starting delay.
  • animation-iteration-count controls repetition.
  • animation-direction controls playback direction.
  • animation-fill-mode controls styles outside the active interval.
  • animation-play-state pauses or resumes an animation.
  • Multiple animations can be applied using comma-separated values.
  • Transform and opacity are often useful for performant animations.
  • prefers-reduced-motion supports accessibility.
  • SVG strokes such as graph axes and paths can be animated with CSS using stroke-dasharray and stroke-dashoffset.
