2. What Are CSS Transitions?

A CSS transition allows a property value to change gradually over a specified duration instead of changing immediately.

Without Transition

.button:hover {
    background-color: blue;
}

The background changes immediately when the pointer enters the button.

With Transition

.button {
    background-color: #174ea6;
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: #007bff;
}

The background color now changes smoothly over 0.3 seconds.

A transition needs a change in a transitionable property value. Hover is one common trigger, but transitions can also occur when classes, attributes or inline styles change.

3. CSS Transition Properties

CSS provides four main transition longhand properties.

Property Purpose Example
transition-property Specifies which CSS properties transition. transition-property: opacity;
transition-duration Specifies the transition time. transition-duration: 0.5s;
transition-timing-function Controls the rate of change over time. transition-timing-function: ease;
transition-delay Specifies how long to wait before starting. transition-delay: 0.2s;

4. transition-property

This property identifies the CSS properties that should transition.

Example

.box {
    background-color: #174ea6;
    opacity: 1;

    transition-property:
        background-color, opacity;
}

Multiple properties can be separated by commas.

Common Values

Value Meaning
none No properties are transitioned.
all All properties that support transitions are considered.
opacity Transitions opacity changes.
transform Transitions transform changes.
background-color Transitions background color changes.
Avoid using transition: all indiscriminately. It can animate unintended properties and make behavior harder to maintain. Prefer listing the properties that should transition.

5. transition-duration

The transition-duration property defines how long a transition takes.

Example

.box {
    transition-duration: 0.5s;
}
Value Duration
0.2s 200 milliseconds
0.5s 500 milliseconds
1s 1000 milliseconds
2s 2000 milliseconds

A zero duration means the transition occurs without a visible interpolation period.

6. transition-timing-function

The timing function controls how quickly a transition progresses during its duration.

Value Behavior
ease Starts slowly, speeds up and slows down near the end.
linear Maintains a constant rate.
ease-in Starts slowly.
ease-out Slows down toward the end.
ease-in-out Starts and ends slowly.
cubic-bezier() Defines a custom cubic Bézier timing curve.
steps() Changes in discrete steps.

Example

.box {
    transition-timing-function: ease-in-out;
}

Custom Timing Function

.box {
    transition-timing-function:
        cubic-bezier(0.25, 0.1, 0.25, 1);
}

The cubic-bezier() function allows more precise control over the transition curve.

7. transition-delay

The transition-delay property specifies how long the browser waits before starting the transition.

Example

.box {
    transition-property: transform;
    transition-duration: 0.5s;
    transition-delay: 0.2s;
}

The transform transition starts after a delay of 0.2 seconds.

8. The transition Shorthand

The transition shorthand combines the individual transition properties.

Syntax

transition:
    property duration timing-function delay;

Example

.button {
    transition: background-color 0.3s ease 0.1s;
}

Multiple Transitions

.card {
    transition:
        transform 0.3s ease,
        box-shadow 0.3s ease,
        background-color 0.3s ease;
}
When writing the shorthand, the first time value is the duration and the second time value, if supplied, is the delay.

9. What Are CSS Transforms?

The transform property modifies an element's visual coordinate system and appearance.

It can move, resize, rotate or skew an element without changing the normal document flow.

Syntax

transform: function(value);

Example

.box {
    transform: translateX(30px);
}

The element is visually moved 30px along the X axis.

A transformed element retains its original layout space. Its visual position changes, but neighboring elements are not rearranged to occupy the new position.

10. translate() – Moving Elements

The translate() function moves an element along the X and Y axes.

Syntax

transform: translate(x, y);

Examples

transform: translateX(30px);

transform: translateY(20px);

transform: translate(30px, 20px);
Function Effect
translateX() Moves along the horizontal coordinate axis.
translateY() Moves along the vertical coordinate axis.
translate() Moves along both axes.

11. scale() – Resizing Elements

The scale() function changes the visual size of an element.

Syntax

transform: scale(x, y);

Examples

transform: scale(1.2);

transform: scaleX(1.5);

transform: scaleY(0.8);

transform: scale(1.2, 1.2);
Value Effect
scale(1) Original visual size.
scale(1.2) 120% visual size.
scale(0.8) 80% visual size.
scale(0) Collapses the element visually to zero scale.
scale(-1) Mirrors the element along the scaled axis.

12. rotate() – Rotating Elements

The rotate() function rotates an element around its transform origin.

Syntax

transform: rotate(angle);

Examples

transform: rotate(45deg);

transform: rotate(-30deg);

transform: rotate(0.5turn);

Positive and negative angles rotate in opposite directions in the usual two-dimensional coordinate system.

14. Combining Multiple Transform Functions

Multiple transform functions can be included in a single transform declaration.

Example

.box:hover {
    transform:
        translateY(-8px)
        scale(1.08)
        rotate(2deg);
}

Transform functions are composed in the order in which they appear. Changing their order can change the resulting transformation.

15. transform-origin

The transform-origin property controls the point around which an element is transformed.

Syntax

transform-origin: x-position y-position;

Examples

transform-origin: center;

transform-origin: top left;

transform-origin: bottom right;

transform-origin: 50% 50%;

Practical Example

.door {
    transform-origin: left center;
}

.door:hover {
    transform: rotateY(25deg);
}

The transform origin is useful for creating realistic-looking rotations such as opening doors.

16. Interactive Button Example

This example combines transitions and transforms to create an interactive button.

CSS

.button {
    padding: 12px 20px;
    color: white;
    background: #174ea6;
    border: none;
    border-radius: 6px;
    cursor: pointer;

    transition:
        background-color 0.25s ease,
        transform 0.25s ease,
        box-shadow 0.25s ease;
}

.button:hover {
    background: #007bff;
    transform: translateY(-3px);
    box-shadow: 0 5px 12px rgba(0,0,0,0.2);
}

.button:active {
    transform: translateY(0);
}

Expected Behavior

  • The button moves slightly upward.
  • A shadow appears during hover.
  • The button returns to its original position when pressed.

18. Transition vs Transform

Transition Transform
Controls gradual property changes over time. Changes an element's visual coordinate transformation.
Uses duration and timing functions. Uses functions such as translate(), scale() and rotate().
Usually needs a change in property value to trigger it. Can be applied directly or changed by interaction.
Can transition transform values. Does not itself define animation duration.
Transitions and transforms are often used together: transform defines the visual change, while transition controls how smoothly that change occurs.

19. Performance and Accessibility

Performance

  • Prefer transform and opacity for many simple visual effects.
  • Avoid unnecessarily animating expensive layout properties.
  • Do not apply will-change to large numbers of elements without profiling.
  • Test interactions on lower-powered devices.
  • Check whether transformed elements overlap nearby content.

Accessibility

  • Do not make hover the only way to access important information.
  • Ensure interactive controls are keyboard accessible.
  • Provide visible focus indicators.
  • Respect the prefers-reduced-motion media query.
  • Avoid unnecessary large or continuous movement.

Reduced Motion Example

@media (prefers-reduced-motion: reduce) {
    .animated-element {
        transition: none;
        animation: none;
    }
}

This allows users who request reduced motion at the operating-system or browser level to receive a less animated experience.

20. Common Mistakes and Debugging

Mistake Correct Practice
Writing transition only on :hover. Usually declare transition on the base element so entering and leaving states both transition.
Forgetting transition-duration. Specify a non-zero duration for a visible transition.
Using transition: all everywhere. Specify only the properties that need transitions.
Using transform without checking overlap. Test nearby elements and clipping boundaries.
Expecting transform to change layout flow. Remember that transforms visually modify elements without rearranging normal flow.
Combining transforms in the wrong order. Test the order because transform composition is order-dependent.
Removing focus outlines. Preserve visible keyboard focus indicators.

Debugging Checklist

  1. Inspect the element in browser Developer Tools.
  2. Check whether the hover, focus or active state is applied.
  3. Check the computed transition property.
  4. Verify duration and timing function.
  5. Check whether another CSS rule overrides transform.
  6. Inspect overflow and stacking behavior if the element is clipped or overlaps another element.
  7. Test keyboard interaction and reduced-motion settings.

21. Placement Interview Questions

Q1. What is a CSS transition?

Answer: A CSS transition gradually interpolates a property's value over a specified duration when its value changes.

Q2. Name the four main transition properties.

Answer: transition-property, transition-duration, transition-timing-function and transition-delay.

Q3. What is the purpose of transition-duration?

Answer: It specifies how long the transition takes.

Q4. What is the difference between ease and linear?

Answer: ease changes speed during the transition, whereas linear maintains a constant rate.

Q5. What does transition-delay do?

Answer: It specifies the time to wait before a transition starts.

Q6. What is the CSS transform property?

Answer: It applies visual transformations such as translation, rotation, scaling and skewing.

Q7. What is the difference between translate() and scale()?

Answer: translate() moves an element, while scale() changes its visual size.

Q8. What does rotate() do?

Answer: It rotates an element around its transform origin.

Q9. What is transform-origin?

Answer: It defines the point around which a transform is applied.

Q10. Do transforms affect normal document flow?

Answer: No. They change the visual rendering of an element but do not cause surrounding elements to be laid out around the transformed position.

Q11. Can multiple transform functions be combined?

Answer: Yes. Multiple transform functions can be specified in one transform declaration, and their order affects the result.

Q12. Why are transform and opacity commonly used for UI effects?

Answer: They can often be animated efficiently without repeatedly recalculating layout, although actual performance should be verified in browser tools.

Q13. What is prefers-reduced-motion?

Answer: It is a media feature that detects whether the user has requested reduced motion through their system or browser settings.

Q14. Why should transition: all be used carefully?

Answer: It may transition unintended properties, make effects harder to control and introduce unnecessary animation work.

23. Lecture Summary

  • Transitions create gradual property changes.
  • transition-property selects the properties to transition.
  • transition-duration controls transition time.
  • transition-timing-function controls the rate of change.
  • transition-delay postpones the start.
  • translate() moves an element visually.
  • scale() changes visual size.
  • rotate() rotates an element.
  • skew() slants an element.
  • transform-origin controls the transformation point.
  • Transforms do not rearrange normal document flow.
  • Reduced-motion preferences should be respected.
