2. What Are CSS Custom Properties?

CSS custom properties are author-defined properties that store reusable CSS values. They are commonly called CSS variables.

Instead of repeating the same color, spacing or font value throughout a stylesheet, a developer can define it once and reuse it.

Without Variables

.header {
    background: #174ea6;
}

.button {
    background: #174ea6;
}

.card-title {
    color: #174ea6;
}

With Variables

:root {
    --primary-color: #174ea6;
}

.header {
    background: var(--primary-color);
}

.button {
    background: var(--primary-color);
}

.card-title {
    color: var(--primary-color);
}
A single variable update can change multiple components that reference it.

3. CSS Variable Declaration Syntax

Custom property names must begin with two hyphens.

Syntax

selector {
    --variable-name: value;
}

Examples

:root {
    --primary-color: #174ea6;
    --font-size: 16px;
    --card-padding: 20px;
    --border-radius: 10px;
    --main-font: Arial, sans-serif;
}

Common Variable Naming Examples

Variable Purpose
--primary-color Main brand color.
--secondary-color Secondary color.
--font-size Reusable font size.
--spacing-medium Standard spacing value.
--border-radius Reusable corner radius.
--box-shadow Reusable shadow definition.

4. The :root Selector

The :root pseudo-class selects the document's root element. In an HTML document, it selects the html element.

Developers commonly declare global design variables inside :root so they can be inherited by descendant elements.

Example

:root {
    --primary-color: #174ea6;
    --text-color: #222;
    --background-color: #f1f5fb;
}

body {
    color: var(--text-color);
    background: var(--background-color);
}

h1 {
    color: var(--primary-color);
}

Advantages

  • Centralized design values.
  • Consistent styling across pages.
  • Easy global theme changes.
  • Reduced duplication.

5. Using var() to Access Variables

The var() function retrieves the value of a custom property.

Syntax

var(--variable-name)

Example

:root {
    --primary-color: #174ea6;
}

button {
    background-color: var(--primary-color);
}

6. Local and Global Variable Scope

A custom property is available on the element where it is declared and can be inherited by descendants.

Global Variable

:root {
    --main-color: #174ea6;
}

h2 {
    color: var(--main-color);
}

button {
    background: var(--main-color);
}

Local Variable

.card {
    --card-color: #16834a;
}

.card h2 {
    color: var(--card-color);
}

.card button {
    background: var(--card-color);
}

Important Difference

Global Declaration Local Declaration
Usually declared in :root. Declared on a component or another element.
Inherited by descendants unless overridden. Available to the declaring element and its descendants through inheritance.
Useful for design tokens. Useful for component-specific values.

7. Variable Inheritance

Custom properties normally inherit. A descendant can use a custom property declared on an ancestor.

Example

.parent {
    --theme-color: #174ea6;
}

.parent h2 {
    color: var(--theme-color);
}

.parent button {
    background: var(--theme-color);
}

HTML

<div class="parent">
    <h2>Inherited Variable</h2>
    <button>Click</button>
</div>

Both the heading and button can access the variable through inheritance.

Custom properties declared with the ordinary --name syntax inherit by default. The @property at-rule can define registration details such as syntax, inheritance behavior and an initial value.

8. Fallback Values in var()

A fallback value can be provided in case a custom property is missing or invalid at computed value time.

Syntax

var(--variable-name, fallback-value)

Example

button {
    background: var(--button-color, #174ea6);
}

If --button-color does not have a usable value, the fallback color is used.

Multiple Fallback Values

p {
    color: var(--text-color, var(--fallback-color, black));
}
A fallback is not used merely because the declared variable contains a value that is invalid for the consuming property's grammar. For example, an existing --color: 20px used as background-color does not cause the var() fallback to be selected.

9. Overriding CSS Variables

A custom property can be redefined on a descendant. The more local value is then used within that element's inheritance scope.

Example

:root {
    --primary-color: #174ea6;
}

.card {
    --primary-color: #16834a;
}

button {
    background: var(--primary-color);
}

A button inside .card inherits the card's green variable, while a button outside that component uses the root value.

10. CSS Variables for Theme Switching

CSS custom properties make it easier to define light and dark theme values.

CSS

:root {
    --background: #ffffff;
    --text: #222222;
    --surface: #f1f5fb;
}

[data-theme="dark"] {
    --background: #17202b;
    --text: #ffffff;
    --surface: #263445;
}

body {
    background: var(--background);
    color: var(--text);
}

.card {
    background: var(--surface);
}

HTML

<body data-theme="dark">
    <div class="card">
        Dark theme card
    </div>
</body>

JavaScript can change the data-theme attribute to switch themes dynamically.

JavaScript Example

const button = document.querySelector("#themeButton");

button.addEventListener("click", () => {
    const currentTheme =
        document.body.getAttribute("data-theme");

    const nextTheme =
        currentTheme === "dark" ? "light" : "dark";

    document.body.setAttribute("data-theme", nextTheme);
});
CSS handles the theme values and appearance. JavaScript changes the theme attribute in response to user interaction.

11. CSS Variables for Design Tokens

Design tokens are reusable named values representing a design system's visual decisions.

Example Design Token System

:root {
    /* Colors */
    --color-primary: #174ea6;
    --color-secondary: #007bff;
    --color-success: #16834a;
    --color-danger: #b91c1c;

    /* Typography */
    --font-family: Arial, sans-serif;
    --font-size-small: 14px;
    --font-size-normal: 16px;
    --font-size-large: 24px;

    /* Spacing */
    --space-1: 4px;
    --space-2: 8px;
    --space-3: 16px;
    --space-4: 24px;

    /* Borders */
    --radius-small: 4px;
    --radius-medium: 8px;
    --radius-large: 12px;

    /* Shadows */
    --shadow-card: 0 3px 10px rgba(0,0,0,0.08);
}

Benefits

  • Consistent design decisions.
  • Centralized styling.
  • Easy theme management.
  • Reduced maintenance effort.
  • Reusable values across components.

12. CSS Custom Properties vs Preprocessor Variables

CSS custom properties and preprocessor variables both help avoid repeated values, but they work differently.

CSS Custom Properties Preprocessor Variables
Native CSS feature. Provided by tools such as Sass.
Available at runtime in the browser. Usually replaced during preprocessing.
Can be changed through CSS cascade and JavaScript. Not ordinary runtime CSS properties.
Support inheritance and cascading. Do not follow CSS property inheritance.
Declared using --name. Sass variables use $name.

CSS Custom Property

:root {
    --primary-color: #174ea6;
}

button {
    background: var(--primary-color);
}

Sass Variable

$primary-color: #174ea6;

button {
    background: $primary-color;
}

13. The @property Rule – Introduction

The @property at-rule allows developers to register a custom property with additional metadata.

It can specify the expected value syntax, whether the property inherits and its initial value.

Example

@property --progress {
    syntax: "<percentage>";
    inherits: false;
    initial-value: 0%;
}

.progress-bar {
    width: var(--progress);
}
Descriptor Purpose
syntax Defines the accepted value type or grammar.
inherits Specifies whether the registered property inherits.
initial-value Defines the initial value for the registered property.
For non-universal syntax definitions, the initial value generally needs to be computationally independent. Check browser support before using @property in production-critical code.

14. Common Mistakes and Debugging

Mistake Correct Practice
Using one hyphen instead of two. Declare custom properties with --.
Using a variable without var(). Access it with var(--name).
Declaring a variable outside the required scope. Place it on an ancestor or a suitable component.
Assuming every variable is global. Understand scope and inheritance.
Using an invalid value and expecting fallback. Ensure the custom property's value is valid for the consuming property.
Duplicating design values. Create a consistent design token system.
Using too many unrelated variables. Use meaningful and consistent naming.

Debugging with Browser Developer Tools

  1. Inspect the element in Developer Tools.
  2. Open the Styles panel.
  3. Find the custom property declaration.
  4. Check whether another declaration overrides it.
  5. Inspect inherited custom properties.
  6. Check the computed value of the consuming property.
  7. Modify the variable temporarily to test the result.

15. Placement Interview Questions

Q1. What are CSS custom properties?

Answer: They are author-defined CSS properties that store reusable values and can be accessed using var().

Q2. How do you declare a CSS variable?

Answer: Use two hyphens before the variable name, for example --primary-color: blue;.

Q3. What is the purpose of :root?

Answer: It selects the document root element and is commonly used to declare globally inherited custom properties.

Q4. How do you access a CSS variable?

Answer: Use the var() function, for example color: var(--primary-color);.

Q5. What is the purpose of a fallback value?

Answer: It provides an alternative value when a custom property is missing or invalid at computed value time.

Q6. Do CSS custom properties inherit?

Answer: Yes. Ordinary custom properties declared with -- inherit by default.

Q7. Can a CSS variable be overridden?

Answer: Yes. A custom property can be redeclared on a descendant or another element according to the cascade.

Q8. What is the difference between global and local variables?

Answer: Global variables are commonly declared on :root, while local variables are declared on a component or another element and are available through inheritance to its descendants.

Q9. Can JavaScript change CSS variables?

Answer: Yes. JavaScript can update custom properties using style.setProperty().

Q10. What is the difference between CSS variables and Sass variables?

Answer: CSS custom properties are browser-native runtime values with cascading and inheritance. Sass variables are generally resolved during preprocessing.

Q11. What are design tokens?

Answer: Design tokens are named reusable values representing visual design decisions such as colors, spacing, typography and shadows.

Q12. What is the purpose of @property?

Answer: It registers a custom property with defined syntax, inheritance behavior and an initial value.
