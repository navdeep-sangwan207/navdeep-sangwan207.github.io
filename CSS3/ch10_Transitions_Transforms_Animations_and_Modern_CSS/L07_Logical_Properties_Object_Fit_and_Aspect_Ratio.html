2. Physical CSS Properties

Traditional physical CSS properties refer directly to fixed directions: top, right, bottom and left.

Examples

.card {
    margin-top: 20px;
    margin-right: 15px;
    margin-bottom: 20px;
    margin-left: 15px;

    padding-left: 20px;
    border-left: 3px solid blue;
}

These properties are tied to physical sides. They do not automatically switch according to text direction or writing mode.

3. What are Logical Properties?

Logical properties describe layout in terms of the writing direction rather than fixed physical sides.

They use two important concepts:

  • Inline axis: The direction in which text and inline content generally progress.
  • Block axis: The direction in which block content is stacked.

Common Logical Directions

Logical Direction Meaning
inline-start Beginning of the inline axis.
inline-end End of the inline axis.
block-start Beginning of the block axis.
block-end End of the block axis.
In a common horizontal left-to-right writing mode, inline-start is left and block-start is top. In right-to-left text, inline-start is generally right. In vertical writing modes, the physical mapping changes.

4. Physical vs Logical Property Mapping

In the common horizontal writing mode, the following mappings apply.

Physical Property Logical Equivalent
margin-left margin-inline-start
margin-right margin-inline-end
margin-top margin-block-start
margin-bottom margin-block-end
padding-left padding-inline-start
padding-right padding-inline-end
border-left border-inline-start
border-top border-block-start
width inline-size
height block-size

5. Logical Margin Properties

Logical margin properties control spacing along the inline and block axes.

Individual Properties

.card {
    margin-inline-start: 20px;
    margin-inline-end: 20px;

    margin-block-start: 15px;
    margin-block-end: 15px;
}

Shorthand Properties

.card {
    margin-inline: 20px;
    margin-block: 15px;
}

margin-inline sets the inline-start and inline-end margins. margin-block sets the block-start and block-end margins.

6. Logical Padding Properties

Logical padding properties control internal spacing according to the writing direction.

Example

.panel {
    padding-inline-start: 20px;
    padding-inline-end: 20px;

    padding-block-start: 15px;
    padding-block-end: 15px;
}

Shorthand

.panel {
    padding-inline: 20px;
    padding-block: 15px;
}

This makes reusable components easier to adapt to different writing directions.

7. Logical Border Properties

Logical border properties allow borders to follow the logical directions of the writing mode.

Example

.notification {
    border-inline-start: 4px solid #174ea6;
    border-block-end: 1px solid #ccc;
}

In a left-to-right horizontal layout, the inline-start border appears on the left. In a right-to-left layout, it appears on the right.

8. Logical Sizing Properties

Logical sizing properties describe element dimensions relative to writing direction.

Logical Property Meaning
inline-size Size along the inline axis.
block-size Size along the block axis.
min-inline-size Minimum inline-axis size.
max-inline-size Maximum inline-axis size.
min-block-size Minimum block-axis size.
max-block-size Maximum block-axis size.

Example

.content {
    inline-size: 80%;
    max-inline-size: 900px;
    min-inline-size: 250px;

    min-block-size: 200px;
}
In a common horizontal writing mode, inline-size behaves like width and block-size behaves like height. In vertical writing modes, their physical dimensions are different.

9. Logical Positioning Properties

Logical inset properties replace physical positioning offsets.

Physical Positioning

.badge {
    position: absolute;
    top: 10px;
    right: 10px;
}

Logical Positioning

.badge {
    position: absolute;
    inset-block-start: 10px;
    inset-inline-end: 10px;
}

Logical Inset Shorthand

.element {
    inset-inline: 10px 20px;
    inset-block: 5px 15px;
}

Other useful properties include:

  • inset-inline-start
  • inset-inline-end
  • inset-block-start
  • inset-block-end
  • inset-inline
  • inset-block

10. Writing Mode and Direction

The writing-mode and direction properties influence how logical directions map to physical sides.

direction

.rtl-content {
    direction: rtl;
}

direction controls inline base direction, including the direction used for bidirectional text.

writing-mode

.vertical-content {
    writing-mode: vertical-rl;
}
Value Behavior
horizontal-tb Horizontal lines, block flow from top to bottom.
vertical-rl Vertical lines, block flow from right to left.
vertical-lr Vertical lines, block flow from left to right.
Use logical properties for direction-aware layout. Use direction and writing-mode only when the actual text direction or writing mode requires them; do not use them merely to reverse a visual layout.

11. Practical Project: Direction-Aware Notification

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Logical Properties Demo</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            padding: 20px;
            background: #edf2f8;
        }

        .notification {
            max-inline-size: 600px;
            margin-block: 20px;
            padding-block: 15px;
            padding-inline: 20px;
            border-inline-start: 5px solid #174ea6;
            background: white;
            border-radius: 6px;
        }

        .notification.rtl {
            direction: rtl;
            border-inline-start-color: #e67e22;
        }
    </style>
</head>

<body>

    <div class="notification">
        <strong>LTR Notification</strong>
        <p>This is a left-to-right example.</p>
    </div>

    <div class="notification rtl"
         lang="ar">
        <strong>RTL Notification</strong>
        <p>This is a right-to-left layout example.</p>
    </div>

</body>
</html>

Expected Result

  • The first notification uses left-to-right direction.
  • The second notification uses right-to-left direction.
  • The inline-start border moves according to the direction.
  • The same logical CSS works for both layouts.

12. What is object-fit?

The object-fit property controls how replaced content, such as an image or video, fits inside its specified content box.

Syntax

img {
    width: 300px;
    height: 200px;
    object-fit: cover;
}

Common Use Cases

  • Product images.
  • Profile pictures.
  • Portfolio thumbnails.
  • Video previews.
  • Responsive card layouts.

13. object-fit Values

Value Behavior
fill Fills the content box, potentially distorting the image.
contain Preserves the complete image while fitting inside the box. Empty space may remain.
cover Preserves aspect ratio and fills the box, cropping content when necessary.
none Displays the image at its natural object size, subject to clipping by the content box.
scale-down Uses the smaller result of none and contain.

Example

.product-image {
    width: 300px;
    height: 200px;
    object-fit: cover;
}
object-fit does not set the image element's width or height. It controls how the replaced content is fitted within the content box established by sizing.

15. object-position

object-position controls the alignment of the replaced content inside its content box.

Example

.profile-image {
    width: 250px;
    height: 200px;
    object-fit: cover;
    object-position: center;
}

Common Values

object-position: center;
object-position: top;
object-position: bottom;
object-position: left;
object-position: right;
object-position: 25% 50%;
object-position: 70% 30%;

object-position is particularly useful when the important subject in a photograph should remain visible after cropping.

Example: Focus on the Upper Part

.portrait {
    width: 250px;
    height: 180px;
    object-fit: cover;
    object-position: center top;
}

16. What is aspect-ratio?

The aspect-ratio property specifies the preferred width-to-height ratio of an element's box.

Syntax

aspect-ratio: width / height;

Examples

.video {
    aspect-ratio: 16 / 9;
}

.profile {
    aspect-ratio: 1 / 1;
}

.portrait {
    aspect-ratio: 3 / 4;
}

The browser uses the ratio when calculating an automatic dimension, subject to other sizing constraints.

17. Common Aspect Ratios

Ratio Typical Application
1 / 1 Profile pictures and square thumbnails.
4 / 3 Traditional image and video layouts.
16 / 9 Widescreen videos and previews.
3 / 2 Photography and landscape images.
3 / 4 Portrait cards and product images.

Live Demonstration

1:1

Expected Result

Each box maintains its specified width-to-height ratio as its available width changes.

18. aspect-ratio with Images

aspect-ratio and object-fit are frequently used together to create consistent image layouts.

Example

.product-image {
    width: 100%;
    aspect-ratio: 4 / 3;
    object-fit: cover;
    display: block;
}

The image box maintains a 4:3 ratio while the image content fills the box and may be cropped.

For images with intrinsic dimensions, browsers can use the intrinsic aspect ratio when width or height is automatic. An explicit aspect-ratio can provide a preferred ratio for layout before an image loads.

19. aspect-ratio with Responsive Cards

Complete Example

<div class="product-grid">

    <article class="product-card">
        <img
            src="product.jpg"
            alt="Product photograph"
            class="product-image">

        <h3>Product Name</h3>
        <p>Product description</p>
    </article>

</div>

<style>
.product-grid {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
}

.product-card {
    padding: 15px;
    background: white;
    border-radius: 10px;
}

.product-image {
    display: block;
    width: 100%;
    aspect-ratio: 4 / 3;
    object-fit: cover;
    border-radius: 8px;
}
</style>

Expected Result

  • Cards arrange into responsive Grid columns.
  • Each image maintains a consistent 4:3 ratio.
  • Images crop consistently without distortion.
  • The layout adapts to available screen width.

20. Common Mistakes and Debugging

Problem Possible Cause or Solution
Logical margin appears on an unexpected side. Check direction and writing-mode.
inline-size behaves differently from width. Check whether the writing mode is horizontal or vertical.
Image looks stretched. Use object-fit: cover or contain instead of fill.
Image subject is cropped incorrectly. Adjust object-position.
Image box has inconsistent dimensions. Use a consistent aspect-ratio.
aspect-ratio appears ineffective. Check whether both dimensions are explicitly constrained or other sizing constraints override the preferred ratio.
Image content is cropped unexpectedly. Check object-fit, object-position and the content box dimensions.
RTL component spacing is incorrect. Replace unnecessary physical margins and padding with logical properties.

DevTools Checklist

  1. Inspect the element's writing-mode and direction.
  2. Check computed logical dimensions.
  3. Inspect margin and padding values.
  4. Check object-fit and object-position.
  5. Inspect the rendered image box dimensions.
  6. Check aspect-ratio and competing width/height constraints.
  7. Test with different viewport sizes and text directions.

21. Placement Interview Questions

Q1. What are CSS logical properties?

Answer: Logical properties describe layout relative to inline and block directions rather than fixed physical sides.

Q2. What is the difference between physical and logical properties?

Answer: Physical properties refer to top, right, bottom and left. Logical properties refer to inline-start, inline-end, block-start and block-end.

Q3. What is inline-size?

Answer: It defines the size of an element along the inline axis.

Q4. What is block-size?

Answer: It defines the size of an element along the block axis.

Q5. What is writing-mode?

Answer: It controls whether text and inline content flow horizontally or vertically and determines the block-flow direction.

Q6. What is direction?

Answer: It establishes the base direction of inline content, such as left-to-right or right-to-left.

Q7. What is object-fit?

Answer: It controls how replaced content fits within its content box.

Q8. What is the difference between cover and contain?

Answer: cover fills the box and may crop content. contain shows the entire object and may leave empty space.

Q9. What does object-position do?

Answer: It controls how the replaced content is aligned inside its content box.

Q10. What is aspect-ratio?

Answer: It specifies the preferred ratio between an element's width and height.

Q11. Can aspect-ratio be used with images?

Answer: Yes. It can establish a preferred image box ratio, commonly combined with object-fit.

Q12. Why are logical properties useful in international websites?

Answer: They allow layouts to adapt more naturally to different text directions and writing modes without maintaining separate physical-side rules.

Q13. What is the difference between margin-inline and margin-block?

Answer: margin-inline controls spacing along the inline axis; margin-block controls spacing along the block axis.

Q14. Does object-fit change the image element's dimensions?

Answer: No. It controls how the image content fits inside the content box; the element's dimensions are controlled by sizing properties.
