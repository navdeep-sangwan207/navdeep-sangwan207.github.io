Inherit, Initial, Unset and Revert Keywords

Learn how CSS-wide keywords control property inheritance, restore initial values and remove declarations from the current cascade context.

1. Learning Objectives

  • Understand CSS-wide keywords.
  • Use the inherit keyword.
  • Understand the initial keyword.
  • Differentiate unset from initial and inherit.
  • Understand the revert keyword.
  • Understand revert-layer and cascade layers.
  • Compare all CSS-wide keywords.
  • Apply these keywords in practical frontend projects.
  • Solve placement-oriented interview problems.

2. What Are CSS-Wide Keywords?

CSS-wide keywords are special values that can be used with CSS properties to control how their values are determined by the cascade and inheritance system.

The main keywords covered in this lecture are:

  • inherit
  • initial
  • unset
  • revert
  • revert-layer

Basic Syntax

selector {
    property: inherit;
}

selector {
    property: initial;
}

selector {
    property: unset;
}

selector {
    property: revert;
}

selector {
    property: revert-layer;
}

These keywords are not ordinary property values. They instruct the browser how to determine the value for the specified property.

3. The inherit Keyword

The inherit keyword explicitly forces an element to use the computed value of that property from its parent element.

It can be used for both inherited and non-inherited properties.

Example 1: Inheriting Text Color

<div class="parent">
    <p class="child">Child paragraph</p>
</div>
.parent {
    color: blue;
}

.child {
    color: inherit;
}

Expected result: The paragraph is blue.

Example 2: Inheriting a Non-Inherited Property

<div class="parent">
    <div class="child">
        Child Box
    </div>
</div>
.parent {
    background-color: lightblue;
}

.child {
    background-color: inherit;
}

Normally, background-color does not inherit. The explicit inherit keyword makes the child use the parent's computed background color.

Expected result: Both parent and child have a light-blue background.

Important: inherit is useful when a child must follow a parent property even though that property does not inherit by default.

4. The initial Keyword

The initial keyword sets a property to its initial value as defined by the CSS specification.

It does not mean the value previously provided by the parent element or the browser's user-agent stylesheet.

Example 1: Resetting Color

<div class="parent">
    <p class="child">Child paragraph</p>
</div>
.parent {
    color: blue;
}

.child {
    color: initial;
}

The initial value of color is CanvasText. Therefore, the paragraph uses the initial color value rather than inheriting blue.

Example 2: Resetting Display

.box {
    display: initial;
}

The initial value of display is inline. Therefore, the element uses inline display behavior.

Example 3: Resetting Margin

.card {
    margin: 20px;
}

.card p {
    margin: initial;
}

The paragraph's margin is reset to the initial value of margin, which is 0.

initial does not restore browser-specific default styling. It restores the property's CSS-defined initial value.

5. The unset Keyword

The unset keyword combines the behavior of inherit and initial.

  • If the property is inherited by default, unset behaves like inherit.
  • If the property is non-inherited by default, unset behaves like initial.

Example 1: Inherited Property

.parent {
    color: blue;
}

.child {
    color: unset;
}

Because color is inherited by default, unset behaves like inherit.

Expected result: Blue text.

Example 2: Non-Inherited Property

.parent {
    background-color: yellow;
}

.child {
    background-color: unset;
}

Because background-color is non-inherited by default, unset behaves like initial.

Expected result: The child uses the initial background-color value, which is transparent.

6. The revert Keyword

The revert keyword rolls a property back to the value it would have received if the declarations from the current cascade origin had not applied.

It is useful when a developer wants to remove the effect of an author-level override and allow an earlier cascade origin to determine the property value.

Example

<button class="custom-button">
    Submit
</button>
button {
    color: blue;
    font-size: 18px;
}

.custom-button {
    color: revert;
}

The author-level color declaration on the custom button is reverted. The browser can use the applicable value from an earlier cascade origin.

The exact visible result depends on the available declarations in other cascade origins. If there is no applicable earlier-origin declaration, the property follows its normal default behavior.

Practical Use

button {
    all: unset;
    font: inherit;
    cursor: pointer;
}

This is a common custom button-reset pattern. The all property is discussed further in the practical section below.

7. The revert-layer Keyword

The revert-layer keyword rolls back a declaration to the value it would have received if declarations from the current cascade layer had not applied.

It is especially useful when CSS is organized using cascade layers.

Example

@layer base, components, overrides;

@layer base {
    button {
        background: gray;
        color: white;
    }
}

@layer components {
    button {
        background: blue;
    }
}

@layer overrides {
    button {
        background: revert-layer;
    }
}

The background declaration in the overrides layer is rolled back. The components layer's blue background becomes the winning normal declaration.

Expected result: Blue button background.

For normal declarations, later layers have higher precedence. revert-layer allows a declaration to step back from its current layer's contribution.

8. Comparison of CSS-Wide Keywords

Keyword Behavior
inherit Uses the parent's computed value.
initial Uses the property's CSS-defined initial value.
unset Behaves like inherit for inherited properties and initial for non-inherited properties.
revert Rolls back the current cascade origin's declarations.
revert-layer Rolls back the current cascade layer's declarations.

Quick Example

.parent {
    color: blue;
    background-color: yellow;
}

.child {
    color: inherit;
    background-color: initial;
}

Expected behavior:

  • Child text color is inherited from the parent.
  • Child background-color uses its initial value: transparent.

9. The all Property

The all shorthand resets almost all CSS properties of an element to a chosen CSS-wide keyword.

Syntax:

selector {
    all: initial;
}

Other common forms:

.component {
    all: unset;
}

.component {
    all: revert;
}

.component {
    all: revert-layer;
}

The all property does not reset direction or unicode-bidi. It also does not reset custom properties.

Example: Resetting a Button

<button class="custom-button">
    Click Me
</button>
.custom-button {
    all: unset;

    font: inherit;
    color: white;
    background: #174ea6;
    padding: 10px 18px;
    border-radius: 6px;
    cursor: pointer;
}

The all declaration resets the button's CSS properties. The following declarations provide the desired appearance.

Using all: unset or all: initial on form controls and interactive elements can remove useful native styling and focus indicators. Restore keyboard focus styles and other necessary accessibility behavior.

10. Practical Example: Resetting Course Card Styles

Imagine a learning portal with a course card that receives global styles but needs a specific local appearance.

HTML

<div class="portal">
    <div class="course-card">
        <h2>CSS3 Course</h2>
        <p>Learn frontend development.</p>
        <button>Start Learning</button>
    </div>
</div>

CSS

.portal {
    color: #174ea6;
    font-family: Arial, sans-serif;
}

.course-card {
    background: #f1f5fb;
    padding: 20px;
    border: 1px solid #ccc;
}

.course-card p {
    color: initial;
}

.course-card button {
    all: unset;
    display: inline-block;
    background: #007bff;
    color: white;
    padding: 10px 16px;
    border-radius: 5px;
    cursor: pointer;
}

.course-card button:focus-visible {
    outline: 3px solid #ffbf47;
    outline-offset: 3px;
}

Expected Result

  • The portal uses the specified global font family.
  • The course card has its own background and border.
  • The paragraph uses the initial color value.
  • The button receives a custom appearance.
  • The button retains a visible keyboard focus indicator.

11. Common Mistakes and Debugging

Mistake Correct understanding
Using initial to inherit from a parent Use inherit.
Assuming unset always means initial It depends on the property's inheritance behavior.
Confusing revert with initial revert rolls back an origin's declarations.
Confusing revert-layer with revert revert-layer rolls back the current layer's contribution.
Using all: unset without accessibility checks Restore focus and control styling as required.
Expecting all to reset custom properties Custom properties are not reset by all.

Developer Tools Debugging

  1. Open the webpage in Chrome.
  2. Press F12.
  3. Select the element in the Elements panel.
  4. Inspect the property being reset.
  5. Find the declaration using a CSS-wide keyword.
  6. Inspect the Computed panel for the final value.
  7. Temporarily disable declarations to compare results.

12. Placement-Oriented Coding Problems

Problem 1: Identify the Keyword

.parent {
    color: red;
}

.child {
    color: inherit;
}

Question: What does inherit do?

Answer: The child uses the parent's computed color.

Problem 2: Initial Value

.parent {
    color: blue;
}

.child {
    color: initial;
}

Answer: The child uses the initial value of color, CanvasText, rather than inheriting blue.

Problem 3: Unset

.parent {
    color: blue;
    padding: 20px;
}

.child {
    color: unset;
    padding: unset;
}

Answer:

  • color is inherited by default, so it behaves like inherit.
  • padding is non-inherited, so it behaves like initial.

Problem 4: Revert Layer

@layer base, components;

@layer base {
    p {
        color: red;
    }
}

@layer components {
    p {
        color: revert-layer;
    }
}

Answer: The component-layer declaration is rolled back, allowing the base-layer red declaration to determine the normal author-layer result.

Problem 5: Button Reset

Create a custom button using all: unset. Restore its font, padding, background, border radius, pointer cursor and keyboard focus indicator.

13. Interview Questions and Answers

Q1. What does inherit do?

It forces a property to use the parent's computed value.

Q2. What does initial do?

It sets a property to its CSS-defined initial value.

Q3. What does unset do?

It behaves like inherit for inherited properties and initial for non-inherited properties.

Q4. What is the difference between inherit and initial?

inherit uses the parent's computed value, while initial uses the property's defined initial value.

Q5. What is the difference between initial and unset?

initial always selects the initial value. unset depends on whether the property is inherited by default.

Q6. What does revert do?

It rolls back declarations from the current cascade origin, allowing an earlier origin to determine the value.

Q7. What does revert-layer do?

It rolls back declarations from the current cascade layer.

Q8. What is the all property?

It resets almost all CSS properties of an element to a selected CSS-wide keyword.

Q9. Does all reset custom properties?

No. Custom properties are excluded.

Q10. Does all reset direction?

No. direction and unicode-bidi are excluded.

Q11. When would you use inherit for background-color?

When a child element needs to explicitly use the parent's computed background color.

Q12. Why should all: unset be used carefully?

It can remove useful native styles and focus indicators from interactive elements.

14. Practical Exercises

Exercise 1: Test Inherit

  • Create a parent with color and background-color.
  • Apply inherit to both properties on the child.
  • Observe the resulting child styles.

Exercise 2: Test Initial

  • Apply initial to color, display and margin.
  • Inspect their resulting values.
  • Compare them with browser default styles.

Exercise 3: Test Unset

  • Apply unset to color and padding.
  • Observe the difference between inherited and non-inherited properties.

Exercise 4: Test Revert and Revert-Layer

  • Create two cascade layers.
  • Set conflicting values in both layers.
  • Apply revert-layer in the later layer.
  • Observe which earlier declaration becomes effective.

Exercise 5: Custom Button

  • Build a button using all: unset.
  • Restore typography and visual properties.
  • Add :focus-visible styling.
  • Test keyboard navigation using the Tab key.

15. Lecture Summary

  • inherit uses the parent's computed value.
  • initial uses the CSS-defined initial value.
  • unset behaves like inherit or initial depending on the property.
  • revert rolls back the current cascade origin's declarations.
  • revert-layer rolls back the current cascade layer's declarations.
  • all resets almost all CSS properties using a CSS-wide keyword.
  • all does not reset custom properties, direction or unicode-bidi.
  • Interactive controls need careful accessibility checks after resets.
Placement takeaway: Be able to distinguish inherit, initial and unset quickly. Also understand the difference between revert and revert-layer when discussing cascade origins and layers.
