Inheritance and Default Property Values

Understand how CSS properties pass from parent elements to child elements, which properties inherit automatically and how browsers determine initial and computed values.

1. Learning Objectives

  • Understand CSS inheritance.
  • Explain parent-child inheritance relationships.
  • Differentiate inherited and non-inherited properties.
  • Identify commonly inherited CSS properties.
  • Understand browser default styles.
  • Differentiate specified, computed and used values.
  • Understand how inheritance interacts with the cascade.
  • Debug inheritance problems using Developer Tools.
  • Solve inheritance-related placement interview questions.

2. What Is CSS Inheritance?

CSS inheritance is the mechanism through which certain CSS property values are passed from a parent element to its child elements.

For example, when a parent element has a text color, its child elements normally inherit that color unless another applicable declaration changes it.

Example

<div class="parent">
    <h2>CSS Learning</h2>
    <p>Understanding inheritance</p>
</div>
.parent {
    color: blue;
}

The heading and paragraph inherit the blue text color from their parent because color is an inherited property.

Expected result: Both child elements display blue text.

3. How CSS Inheritance Works

HTML elements form a parent-child hierarchy called the DOM tree. CSS inheritance follows this hierarchy for properties that support inheritance.

Example DOM Structure

body
 └── main
      └── section
           ├── h2
           └── p
                └── strong

If the body defines an inherited property such as font-family, descendant elements can receive that value through the inheritance chain.

Complete Example

<!DOCTYPE html>
<html lang="en">
<head>
    <style>
        body {
            color: darkblue;
            font-family: Arial, sans-serif;
        }
    </style>
</head>
<body>

    <main>
        <section>
            <h2>CSS Inheritance</h2>

            <p>
                This paragraph inherits the body text color
                and font family.
            </p>
        </section>
    </main>

</body>
</html>

Expected result: The heading and paragraph use the inherited font family and text color.

4. Inherited CSS Properties

Inherited properties generally affect text appearance and other characteristics that are useful to pass down through the document hierarchy.

Common Inherited Properties

Property Purpose
color Text foreground color
font-family Font family
font-size Text size
font-style Normal or italic font style
font-weight Font thickness
line-height Line box height behavior
text-align Text alignment
text-transform Text capitalization
letter-spacing Spacing between characters
word-spacing Spacing between words
visibility Element visibility
cursor Mouse cursor appearance
This is a practical list of commonly encountered inherited properties, not an exhaustive list of every CSS property.

5. Non-Inherited CSS Properties

Non-inherited properties do not normally pass their parent's specified value to child elements.

They usually receive their own initial value or another value determined by an applicable declaration.

Common Non-Inherited Properties

Property Purpose
margin Outer spacing
padding Inner spacing
border Element boundary
width Element width
height Element height
background-color Background color
display Display behavior
position Positioning method
top, right, bottom, left Position offsets
z-index Stacking order in applicable contexts
box-shadow Element shadow
border-radius Corner rounding

Example

<div class="parent">
    Parent Element

    <p>Child Element</p>
</div>
.parent {
    background-color: lightblue;
    padding: 20px;
    border: 2px solid blue;
}

The paragraph does not automatically receive the parent's background, padding or border declarations.

The paragraph is still positioned inside the parent's content area as part of normal document layout.

Expected result: The parent has the light-blue background, padding and blue border. The child does not independently receive these property values.

6. Inherited vs Non-Inherited Properties

Feature Inherited Non-Inherited
Default behavior Receives parent's computed value Uses initial or otherwise cascaded value
Typical examples color, font-family margin, padding, border
Text appearance Many text properties inherit Not generally responsible for layout inheritance
Explicit override Child declaration can override inheritance Child declaration can set its own value
Inheritance is the default behavior defined for each CSS property. It is not determined simply by whether a property affects text or layout.

7. Inheritance Through Multiple Levels

An inherited property can pass through several levels of descendants.

Example

<div class="outer">
    Outer Element

    <section>
        Section Element

        <p>
            Paragraph Element

            <span>Nested Span</span>
        </p>
    </section>
</div>
.outer {
    color: purple;
    font-family: Arial, sans-serif;
}

The section, paragraph and span inherit the applicable text color and font family through the DOM hierarchy.

Expected result: All descendant text uses purple text and Arial font.

8. Child Declarations Override Inherited Values

An inherited value is used only when the child does not have a winning declaration for that property.

Example

<div class="parent">
    <p class="child">
        Child paragraph
    </p>
</div>
.parent {
    color: blue;
}

.child {
    color: red;
}

The paragraph has its own color declaration. Therefore, it uses red instead of inheriting blue.

Expected result: Red paragraph text.

A declaration on a child element is not competing with the parent's declaration through selector specificity. Inheritance supplies a value only when the child does not have its own winning declaration for that property.

9. Browser Default Styles

Browsers provide built-in styles, commonly called user-agent stylesheets.

These styles establish default presentation for HTML elements even when developers do not write CSS.

Examples of Common Browser Defaults

HTML element Typical default behavior
h1 Large bold heading with block layout
p Block layout with vertical margins
a Link styling, often blue and underlined
ul List indentation and bullet markers
button Native control appearance
strong Bold text

Example

<h1>Main Heading</h1>
<p>A normal paragraph.</p>
<a href="#">Sample Link</a>
<ul>
    <li>First item</li>
    <li>Second item</li>
</ul>

Even without a custom stylesheet, these elements have browser-provided presentation.

Browser default styles are not the same as CSS inheritance. A browser may directly style an element, while another property may be inherited from its parent.

10. Initial Values of CSS Properties

Every CSS property has a defined initial value. When a property is not otherwise specified and does not inherit by default, its initial value is used.

Examples of initial values include:

Property Initial value
color CanvasText
display inline
position static
margin 0
padding 0
opacity 1
visibility visible
font-style normal

The initial value is defined by the CSS specification, not necessarily by the browser's visible default styling.

For example, an h1 normally appears as a block-level heading with a large font because of browser styles. The initial value of display is inline, but the user-agent stylesheet normally gives h1 a block display value.

11. Specified, Computed and Used Values

CSS values pass through different stages before the browser renders an element.

1. Specified Value

The specified value is the value assigned to a property after the cascade has determined the winning declaration or applicable default behavior.

2. Computed Value

The computed value is obtained after the browser performs the computations required by the property's definition. It is also the value generally used for inheritance.

3. Used Value

The used value is the value after the browser has resolved the necessary layout calculations for the element.

Example

.parent {
    font-size: 20px;
}

.child {
    font-size: 1.5em;
}

If the child inherits the relevant font-size context through the parent, the 1.5em declaration is resolved relative to the parent's computed font size.

Expected child font size: 30px.

For an ordinary computed length such as font-size, the browser resolves relative units into a computed length. Developer Tools can help inspect the final result.

12. Practical Example: Inheritance in a Learning Portal

A learning portal often uses global typography and text colors to maintain consistent styling.

HTML

<div class="portal">

    <header>
        <h1>My Learning Portal</h1>
    </header>

    <main>
        <section class="course-card">
            <h2>CSS3 Course</h2>

            <p>
                Learn selectors, layouts and responsive design.
            </p>

            <button>Start Learning</button>
        </section>
    </main>

</div>

CSS

.portal {
    color: #174ea6;
    font-family: Arial, sans-serif;
    line-height: 1.6;
}

.course-card {
    background: #f4f7fb;
    padding: 20px;
    border: 1px solid #ccc;
}

button {
    background: #007bff;
    color: white;
    padding: 10px 18px;
}

Expected Result

  • Portal text inherits the blue color.
  • Descendant text uses Arial.
  • Line height is inherited where applicable.
  • The course card has its own background and padding.
  • The button has its own background and padding.

This is a practical example of using inheritance for global typography while assigning layout properties directly to individual components.

13. Debugging Inheritance Using Developer Tools

Chrome Developer Tools can show whether a property is inherited, directly declared or coming from a browser stylesheet.

Debugging Steps

  1. Open the webpage in Chrome.
  2. Press F12 or Ctrl + Shift + I.
  3. Select the Elements panel.
  4. Inspect a child element.
  5. Open the Styles panel.
  6. Find the property you want to investigate.
  7. Check whether the declaration is inherited.
  8. Trace the inherited declaration to its parent.
  9. Check the Computed panel for the final value.
  10. Inspect any overriding declaration.

Common Debugging Questions

  • Is the property inherited by default?
  • Does the child have its own declaration?
  • Is the parent value overridden at an intermediate level?
  • Is a browser default stylesheet affecting the element?
  • Is the final value different from the specified value?

14. Common Inheritance Mistakes

Mistake Correct understanding
Assuming all CSS properties inherit Inheritance is property-specific.
Assuming background color inherits background-color is not inherited by default.
Assuming margin passes to children margin is not inherited by default.
Confusing inheritance with browser defaults User-agent styles directly style elements.
Assuming a parent always controls child text A child declaration can override inherited values.
Confusing initial and browser default values Initial values come from CSS property definitions.
Assuming inherited values are copied as raw text Inheritance generally passes the parent's computed value.

15. Placement-Oriented Coding Problems

Problem 1: Identify the Inherited Color

<div class="parent">
    <p>First paragraph</p>
    <span>Second text</span>
</div>
.parent {
    color: red;
}

Question: What is the text color of the paragraph and span?

Answer: Both inherit red.

Problem 2: Child Override

.parent {
    color: blue;
}

.child {
    color: green;
}

HTML:

<div class="parent">
    <p class="child">Hello CSS</p>
</div>

Answer: Green, because the child has its own color declaration.

Problem 3: Non-Inherited Background

.parent {
    background-color: yellow;
}

HTML:

<div class="parent">
    <p>Child paragraph</p>
</div>

Question: Does the paragraph receive its own yellow background?

Answer: No. background-color does not inherit by default. The parent's background is painted behind its content, which may visually cover the area behind the paragraph.

Problem 4: Font Inheritance

body {
    font-family: Arial, sans-serif;
    font-size: 18px;
}

main {
    font-size: 1.5em;
}

HTML:

<body>
    <main>
        <p>Learning CSS</p>
    </main>
</body>

Question: What is the computed font size of the paragraph if it has no overriding font-size declaration?

Answer: 27px. The main element computes to 27px (1.5 × 18px), and the paragraph inherits that value.

16. Interview Questions and Answers

Q1. What is CSS inheritance?

It is the mechanism through which certain property values pass from parent elements to child elements.

Q2. Name some commonly inherited properties.

color, font-family, font-size, font-weight, line-height and text-align.

Q3. Does background-color inherit?

No. It is non-inherited by default.

Q4. Does margin inherit?

No. Margin is non-inherited by default.

Q5. Can a child override an inherited property?

Yes. A winning declaration on the child element overrides the inherited value.

Q6. What is a user-agent stylesheet?

It is the browser's built-in stylesheet that provides default styling for HTML elements.

Q7. What is the initial value of a CSS property?

It is the default value defined for that property by the CSS specification.

Q8. What is the difference between inherited values and browser defaults?

Inherited values come from parent elements. Browser defaults are declarations supplied by the browser's user-agent stylesheet.

Q9. What is a computed value?

It is the value obtained after the browser performs the computations defined for a property.

Q10. Does every property have an initial value?

Yes. Every CSS property has a defined initial value.

Q11. Why is inheritance useful?

It reduces repeated declarations and maintains consistent typography and text styling across a webpage.

Q12. How can you inspect inherited properties?

Use the Styles and Computed panels in browser Developer Tools.

  • Verify that the properties do not inherit by default.

Exercise 3: Inheritance Through Multiple Levels

  • Create a nested HTML structure.
  • Set font-family and color on the outer element.
  • Inspect all descendant elements.
  • Override one property at an intermediate level.

Exercise 4: Browser Default Styles

  • Create h1, p, ul, a and button elements.
  • Open the page without a custom stylesheet.
  • Inspect their browser-provided styles.
  • Add custom CSS and observe the changes.

Exercise 5: Learning Portal Assignment

Build a course card with global typography inherited from the body element. Give the card its own background, border, padding and dimensions. Override the heading color independently.

18. Lecture Summary

  • Inheritance passes certain property values to descendants.
  • color and font-family are commonly inherited.
  • margin, padding and background-color are non-inherited.
  • A child can override an inherited value.
  • Browser styles are supplied through user-agent stylesheets.
  • Every CSS property has an initial value.
  • Specified, computed and used values represent different stages.
  • Developer Tools help trace inherited declarations.
Placement takeaway: Remember the distinction between inherited and non-inherited properties. A frequent interview question is whether background-color, margin or padding automatically passes from a parent to its child.
