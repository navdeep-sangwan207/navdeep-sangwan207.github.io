2. What Is CSS Grid?

CSS Grid Layout is a two-dimensional CSS layout system that arranges elements into rows and columns.

It allows developers to control both horizontal and vertical placement of elements within a layout.

Typical Applications

  • Website page structures.
  • Admin dashboards.
  • Product listing interfaces.
  • Image galleries.
  • Course and service card layouts.
  • Complex responsive interfaces.
CSS Grid is particularly useful when a layout requires coordinated control over both rows and columns.

3. CSS Grid vs Flexbox

Both Grid and Flexbox are modern CSS layout systems, but they solve different layout problems.

Feature CSS Grid Flexbox
Layout model Two-dimensional One-dimensional
Primary control Rows and columns Main and cross axes
Placement Rows, columns and areas Sequential flex items
Typical use Page layouts and dashboards Navigation and component alignment

Grid is generally suitable for two-dimensional structures, while Flexbox is generally suitable for arranging items in one dimension.

4. What Is a Grid Container?

An element becomes a grid container when its display property is set to grid or inline-grid.

Syntax

.container {
    display: grid;
}

The direct in-flow children of the grid container become grid items.

Example

<div class="container">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
</div>

.container {
    display: grid;
}
A grid container establishes a grid formatting context for its grid items. Nested elements do not automatically become grid items; only direct in-flow children participate as grid items.

5. Grid Container Display Values

Value Behaviour
display: grid Creates a block-level grid container.
display: inline-grid Creates an inline-level grid container.

Block-Level Grid

.container {
    display: grid;
}

The grid container participates as a block-level box in its parent formatting context.

Inline-Level Grid

.container {
    display: inline-grid;
}

The grid container participates as an inline-level box in its parent formatting context.

6. Grid Items

Grid items are the direct in-flow children of a grid container.

Example

<div class="grid-container">
    <div class="item">HTML</div>
    <div class="item">CSS</div>
    <div class="item">JavaScript</div>
</div>

Here:

  • grid-container is the grid container.
  • Each direct child is a grid item.
An absolutely positioned child of a grid container is not a grid item. It is positioned independently, although the grid container can still establish its containing block.

7. Understanding Rows and Columns

A grid is formed using horizontal rows and vertical columns.

  • Rows: Horizontal tracks.
  • Columns: Vertical tracks.
  • Grid cell: The intersection of one row and one column.
  • Grid track: A row or column in the grid.

8. Creating a Basic Grid

A basic grid can be created by defining columns using grid-template-columns.

HTML

<div class="container">
    <div>HTML</div>
    <div>CSS</div>
    <div>JavaScript</div>
    <div>React</div>
    <div>Node.js</div>
    <div>Linux</div>
</div>

CSS

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

.container > div {
    background: #174ea6;
    color: white;
    padding: 20px;
    text-align: center;
    border-radius: 6px;
}

9. Understanding Two-Dimensional Layout

Unlike a simple one-dimensional arrangement, Grid allows a developer to define both columns and rows.

CSS

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-template-rows: 90px 90px;
    gap: 10px;
}

10. Automatic Placement of Grid Items

When explicit placement is not specified, Grid automatically places items using its auto-placement algorithm.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

If there are seven grid items:

  • The first three occupy the first row.
  • The next three occupy the second row.
  • The seventh item starts the third row.

The automatically generated rows are part of the implicit grid.

Explicit grid tracks are defined by the author. Additional tracks generated by automatic placement belong to the implicit grid. Track sizing and implicit grid behaviour are covered in later lectures.

Problem Statement

Create a basic dashboard using CSS Grid with a full-width header, sidebar and main content area.

HTML

    <header class="header">

12. Common Mistakes and Debugging

Mistake Correction
Forgetting display: grid. Define the grid container first.
Expecting grandchildren to become grid items. Only direct in-flow children participate as grid items.
Confusing rows and columns. Rows are horizontal tracks; columns are vertical tracks.
Using Grid for every small alignment problem. Choose Grid or Flexbox according to the layout requirement.
Assuming every row is explicitly defined. Automatic placement can generate implicit rows.

13. Placement Interview Questions and Answers

Q1. What is CSS Grid?

Answer: CSS Grid is a two-dimensional layout system for arranging elements in rows and columns.

Q2. How do you create a grid container?

Answer: Apply display: grid or display: inline-grid to an element.

Q3. What is a grid item?

Answer: A direct in-flow child of a grid container.

Q4. What is the difference between Grid and Flexbox?

Answer: Grid provides two-dimensional row-and-column layout control, whereas Flexbox primarily arranges items along one dimension.

Q5. What is a grid track?

Answer: A grid track is a row or column between two adjacent grid lines.

Q6. What is a grid cell?

Answer: A grid cell is the smallest unit of a grid, formed by the intersection of one row and one column.

Q7. What is the difference between grid and inline-grid?

Answer: grid creates a block-level grid container, while inline-grid creates an inline-level grid container.

Q8. What is automatic placement?

Answer: It is the process by which Grid places items into available grid cells when explicit placement is not provided.

Q9. Can Grid contain nested grids?

Answer: Yes. A grid item can also become a grid container by applying display: grid to it.

Q10. What is an implicit grid?

Answer: It consists of additional rows or columns generated automatically when items need tracks beyond the explicitly defined grid.
