2. CSS Grid Quick Revision

Property Purpose
display: grid Creates a grid container.
grid-template-columns Defines explicit column tracks.
grid-template-rows Defines explicit row tracks.
grid-template-areas Defines named layout areas.
grid-column Controls column placement and spanning.
grid-row Controls row placement and spanning.
gap Defines spacing between grid tracks.
grid-auto-flow Controls automatic item placement direction.
grid-auto-rows Defines implicit row sizing.
grid-auto-columns Defines implicit column sizing.
minmax() Defines minimum and maximum track sizing.
repeat() Repeats a track definition.
justify-items Aligns items along the inline axis.
align-items Aligns items along the block axis.
justify-content Aligns the grid track structure along the inline axis.
align-content Aligns the grid track structure along the block axis.

3. Coding Challenge 1: Create a Three-Column Grid

Problem Statement

Create a grid containing six items arranged in three equal-width columns.

HTML

<div class="container">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
    <div>Item 6</div>
</div>

CSS

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 12px;
}

.container div {
    background: #174ea6;
    color: white;
    padding: 20px;
    text-align: center;
}

Expected Result

Item 1
Item 2
Item 3
Item 4
Item 5
Item 6

Six items are displayed in three columns and two rows.

4. Coding Challenge 2: Responsive Card Layout

Problem Statement

Create a responsive card layout that automatically adjusts the number of columns according to available space.

HTML

<div class="cards">
    <article class="card">
        <h3>HTML5</h3>
        <p>Web structure</p>
    </article>

    <article class="card">
        <h3>CSS3</h3>
        <p>Web styling</p>
    </article>

    <article class="card">
        <h3>JavaScript</h3>
        <p>Web programming</p>
    </article>

    <article class="card">
        <h3>React</h3>
        <p>Frontend library</p>
    </article>
</div>

CSS

.cards {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));

    gap: 20px;
}

.card {
    background: #eef5ff;
    padding: 20px;
    border-radius: 8px;
}

Expected Result

HTML5
CSS3
JavaScript
React

The number of columns changes automatically as the available container width changes.

5. Coding Challenge 3: Create a Dashboard Layout

Problem Statement

Create a dashboard with:

  • Header across the complete width.
  • Sidebar on the left.
  • Main content on the right.
  • Footer across the complete width.

HTML

<div class="dashboard">
    <header>Header</header>

    <aside>Sidebar</aside>

    <main>Main Content</main>

    <footer>Footer</footer>
</div>

CSS

.dashboard {
    display: grid;

    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";

    grid-template-columns: 220px 1fr;

    gap: 12px;
}

header {
    grid-area: header;
}

aside {
    grid-area: sidebar;
}

main {
    grid-area: main;
}

footer {
    grid-area: footer;
}

Expected Result

Header
Sidebar
Main Content
Footer

6. Coding Challenge 4: Span Multiple Columns

Problem Statement

Create a four-column layout where the first item spans two columns.

HTML

<div class="grid">
    <div class="wide">Wide Item</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
</div>

CSS

.grid {
    display: grid;

    grid-template-columns:
        repeat(4, 1fr);

    gap: 10px;
}

.grid div {
    background: #174ea6;
    color: white;
    padding: 20px;
    text-align: center;
}

.wide {
    grid-column: span 2;
}

Expected Result

  • The first item occupies two columns.
  • Other items occupy one column each.
  • Automatic placement positions remaining items.

7. Coding Challenge 5: Center an Item in Grid

Problem Statement

Center a login box horizontally and vertically inside a full-height container.

CSS

.container {
    display: grid;

    place-items: center;

    min-height: 100vh;
}

.login-box {
    width: min(90%, 350px);

    padding: 25px;

    background: #eef5ff;
}

Expected Result

The login box is centered along both alignment axes within the available container space.

9. Coding Challenge 7: Responsive Layout with Media Queries

Problem Statement

Build a layout with one column on mobile, two columns on tablets and three columns on larger screens.

CSS

.container {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

@media (min-width: 600px) {
    .container {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 900px) {
    .container {
        grid-template-columns: repeat(3, 1fr);
    }
}

Test the layout at different viewport widths and observe the change in columns.

10. Common CSS Grid Debugging Problems

Problem Possible Cause / Solution
Grid items are not appearing in expected columns. Check grid-template-columns and automatic placement.
Items overflow their tracks. Inspect intrinsic content sizing, min-width and overflow.
Grid areas are invalid. Check rectangular area shapes and equal row lengths.
Columns do not adapt on mobile. Check track minimum sizes and responsive rules.
Grid tracks do not center. Check available free space and use the appropriate content alignment property.
Unexpected extra rows appear. Inspect automatic placement and implicit track definitions.
Items overlap unexpectedly. Check explicit grid line placement and spanning.
Grid gaps appear too large. Inspect gap, row-gap and column-gap values.

Debugging Procedure

  1. Inspect the grid container.
  2. Confirm display: grid is applied.
  3. Inspect explicit column and row definitions.
  4. Check grid item placement properties.
  5. Inspect implicit tracks.
  6. Check minimum and maximum track sizing.
  7. Test the layout at different viewport widths.
  8. Use the browser's Grid overlay.

11. CSS Grid Interview Questions and Answers

Q1. What is CSS Grid?

Answer: CSS Grid is a two-dimensional CSS layout system for arranging elements in rows and columns.

Q2. How do you create a Grid container?

Answer: Apply display: grid or display: inline-grid to an element.

Q3. What is the difference between Grid and Flexbox?

Answer: Grid controls two-dimensional layouts, while Flexbox arranges items along one main axis at a time.

Q4. What is the fr unit?

Answer: It represents a flexible fraction of available grid space.

Q5. What is the difference between explicit and implicit grids?

Answer: Explicit tracks are defined by grid-template properties. Implicit tracks are created automatically when placement requires additional tracks.

Q6. What does grid-template-columns do?

Answer: It defines the column tracks of the explicit grid.

Q7. What is grid-template-areas?

Answer: It defines named rectangular areas that can be assigned to grid items using grid-area.

Q8. What is the difference between grid-auto-rows and grid-template-rows?

Answer: grid-template-rows defines explicit rows, while grid-auto-rows controls the sizing of implicit rows.

Q9. What is the purpose of gap?

Answer: It defines spacing between grid tracks.

Q10. What is minmax()?

Answer: It defines minimum and maximum sizing constraints for a grid track.

Q11. What is repeat()?

Answer: It repeats a specified grid track list.

Q12. Difference between auto-fit and auto-fill?

Answer: auto-fit collapses empty repeated tracks when possible; auto-fill preserves them.

Q13. What does grid-column: span 2 mean?

Answer: It makes the item span two column tracks.

Q14. What is the purpose of grid-area?

Answer: It can assign an item to a named grid area or specify row and column line placement using shorthand syntax.

Q15. What does grid-auto-flow do?

Answer: It controls how auto-placed items are inserted into the grid, such as row or column flow.

Q16. What is dense packing?

Answer: It is an automatic placement mode that attempts to fill earlier gaps with later items. It can cause visual order to differ from source order.

Q17. How can you center an item using Grid?

Answer: Use place-items: center on a grid container, or use justify-items and align-items separately.

Q18. What is a nested grid?

Answer: It is a grid container placed inside an item of another grid container.

Q19. What is subgrid?

Answer: Subgrid allows a nested grid to use the track sizing of its parent grid along the selected axis.

Q20. How do you create a responsive card grid without multiple breakpoints?

Answer: Use repeat(auto-fit, minmax(appropriate-minimum, 1fr)) with a suitable gap.
