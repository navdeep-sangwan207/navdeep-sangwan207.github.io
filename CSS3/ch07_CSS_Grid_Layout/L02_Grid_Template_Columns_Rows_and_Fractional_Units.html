2. Understanding Grid Tracks

A grid track is the space between two adjacent grid lines. A track can be either a row or a column.

  • Column track: A vertical track.
  • Row track: A horizontal track.

CSS Grid allows developers to specify the size of these tracks using grid-template properties.

The grid-template properties define explicit grid tracks. If automatic placement requires additional tracks, Grid can create implicit tracks whose sizing is controlled separately.

3. grid-template-columns

The grid-template-columns property defines the number and sizing of explicit column tracks.

Syntax

.container {
    display: grid;
    grid-template-columns: value1 value2 value3;
}

Each value describes the size of one column track.

Example: Three Fixed Columns

.container {
    display: grid;
    grid-template-columns: 150px 150px 150px;
    gap: 10px;
}
150px
150px
150px

Three columns are created, each with a specified track size of 150 pixels.

Fixed pixel widths may overflow a narrow viewport if the combined track sizes and gaps exceed the available space.

4. grid-template-rows

The grid-template-rows property defines the size of explicit row tracks.

Syntax

.container {
    display: grid;
    grid-template-rows: 80px 120px 100px;
}

Practical Example

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-template-rows: 70px 120px 90px;
    gap: 10px;
}

6. Understanding the fr Unit

The fr unit represents a fraction of the available flexible space in a grid container.

Example 1: Equal Columns

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}

The three columns receive equal shares of the available flexible space.

1fr
1fr
1fr

Example 2: Unequal Columns

.container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
}
1fr
2fr
1fr

The flexible sizing ratio is 1:2:1. The middle track receives twice the flexible share of either outer track, subject to Grid's sizing algorithm and track constraints.

The fr unit does not simply mean a percentage of the container's total width. It distributes available flexible space after other sizing requirements, fixed tracks and gaps are accounted for.

7. Combining Fixed and Flexible Units

A practical layout often combines fixed dimensions with flexible tracks.

Example: Sidebar and Main Content

.container {
    display: grid;
    grid-template-columns: 200px 1fr;
    gap: 15px;
}

The sidebar receives a 200px track. The main content receives the remaining flexible space, subject to its sizing constraints.

Example: Three-Column Layout

.container {
    display: grid;
    grid-template-columns: 150px 1fr 2fr;
    gap: 10px;
}
150px
1fr
2fr

The first column has a fixed track size. The remaining available flexible space is distributed between the second and third tracks according to their fr factors.

8. The repeat() Function

The repeat() function avoids writing the same track definition multiple times.

Syntax

repeat(count, track-size)

Without repeat()

.container {
    grid-template-columns:
        1fr 1fr 1fr 1fr;
}

With repeat()

.container {
    grid-template-columns: repeat(4, 1fr);
}
Column 1
Column 2
Column 3
Column 4

Repeat with Fixed Sizes

.container {
    grid-template-columns: repeat(3, 150px);
}

This creates three column tracks, each 150px wide.

9. The auto Keyword in Track Sizing

The auto track sizing keyword allows track sizes to be influenced by content and available space. 

.container {
    display: grid;
    grid-template-columns: auto 1fr auto;
}

In this example:

  • The first track uses automatic sizing.
  • The middle track receives flexible space.
  • The third track also uses automatic sizing.
The auto keyword does not always mean that a track takes only its content width. Its final size depends on the Grid track sizing algorithm, available space and other constraints.

11. Explicit and Implicit Grid Tracks

Tracks defined directly using grid-template-columns and grid-template-rows form the explicit grid.

Additional tracks created automatically when items need more space form the implicit grid.

Example

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-template-rows: 100px;
}

If five items are automatically placed, the first two occupy the first row, the next two occupy the second row, and the fifth item occupies a third row.

Only the first row was explicitly defined. The additional rows are implicit tracks.

The sizing of automatically created rows and columns can be controlled with grid-auto-rows and grid-auto-columns. These properties are covered in the lecture on implicit grids.

12. Common Mistakes and Debugging

Mistake Correction
Using grid-template-columns without display: grid. Make the element a grid container first.
Assuming fr is always a percentage of total width. Understand that fr distributes available flexible space.
Using too many fixed-width columns. Use flexible sizing where the layout needs to adapt.
Confusing grid-template-rows with grid-template-columns. Columns define vertical tracks; rows define horizontal tracks.
Writing repeated track sizes manually. Use repeat() for repeated patterns.
Assuming all rows are explicitly defined. Additional rows may be generated by automatic placement.

Debugging with Browser Developer Tools

  1. Open the page in a browser.
  2. Press F12 to open Developer Tools.
  3. Select the grid container in the Elements panel.
  4. Inspect the grid-related CSS rules.
  5. Enable the Grid overlay if your browser provides it.
  6. Inspect track dimensions and item placement.

13. Placement Interview Questions and Answers

Q1. What does grid-template-columns do?

Answer: It defines the sizing of explicit column tracks in a grid container.

Q2. What does grid-template-rows do?

Answer: It defines the sizing of explicit row tracks.

Q3. What is the fr unit?

Answer: It represents a fraction of the available flexible space in a grid container.

Q4. What is the difference between 1fr and 2fr?

Answer: When flexible space is distributed between tracks with these factors, the second track receives twice the flexible share of the first, subject to track sizing constraints.

Q5. What is repeat() in CSS Grid?

Answer: It is a function that repeats a track-size pattern a specified number of times or using an auto-repeat keyword.

Q6. How do you create three equal columns?

Answer:

grid-template-columns: repeat(3, 1fr);

Q7. What is the difference between px and fr?

Answer: px specifies a fixed CSS length, whereas fr distributes available flexible space according to fractional factors.

Q8. What is an explicit grid?

Answer: It is the grid structure explicitly defined by the author through grid-template properties.

Q9. What is an implicit grid?

Answer: It consists of additional tracks generated automatically when items require more tracks than the explicit grid provides.

Q10. Can fixed and flexible tracks be combined?

Answer: Yes. For example, grid-template-columns: 200px 1fr creates a fixed sidebar track and a flexible content track.
