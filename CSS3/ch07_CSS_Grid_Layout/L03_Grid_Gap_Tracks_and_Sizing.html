2. What Is Grid Gap?

Grid gap defines the spacing between adjacent grid rows and columns.

It helps maintain consistent spacing between grid items without adding margins to individual elements.

Available Properties

Property Purpose
gap Sets both row and column gaps.
row-gap Sets spacing between rows.
column-gap Sets spacing between columns.

3. The gap Property

The gap property is shorthand for row-gap and column-gap.

Syntax

.container {
    display: grid;
    gap: 15px;
}

This creates a 15px gap between both adjacent rows and adjacent columns.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;

4. row-gap Property

The row-gap property controls the spacing between adjacent rows.

Syntax

.container {
    display: grid;
    row-gap: 20px;
}

Only the vertical spacing between adjacent rows is controlled.

5. column-gap Property

The column-gap property controls the spacing between adjacent columns.

Syntax

.container {
    display: grid;
    column-gap: 25px;
}

Only the horizontal spacing between adjacent columns is controlled.

    display: grid;
    grid-template-columns: repeat(3, 1fr);

6. Understanding Grid Tracks

A grid track is a row or column between two adjacent grid lines.

Track sizing determines how much space each row or column occupies.

Example

.container {
    display: grid;
    grid-template-columns: 150px 1fr 2fr;
    grid-template-rows: 100px 200px;
    gap: 10px;
}

This defines:

  • Three explicit column tracks.
  • Two explicit row tracks.
  • One fixed column and two flexible columns.
  • Two rows with specified heights.
  • 10px spacing between adjacent tracks.
Gaps are separate from tracks. A 10px gap does not become part of either neighbouring track's size.

7. Understanding Automatic Track Sizing

CSS Grid supports automatic track sizing based on content, available space and sizing constraints.

Common track sizing keywords include:

Keyword Meaning
auto Automatic sizing influenced by content and available space.
min-content Minimum intrinsic size contribution of the content.
max-content Maximum intrinsic size contribution without soft wrapping opportunities.

Example

.container {
    display: grid;
    grid-template-columns:
        min-content auto max-content;
}

The three columns use different intrinsic and automatic sizing behaviour.

Intrinsic sizing can be affected by unbreakable content, images, minimum sizes and available space. Do not assume auto always means the same width as the content.

8. grid-auto-rows

The grid-auto-rows property specifies the sizing of implicitly created row tracks.

Syntax

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-auto-rows: 100px;
}

If automatic placement creates additional rows, each implicit row uses the specified 100px track sizing.

10. Understanding grid-auto-flow

The grid-auto-flow property controls how automatically placed items are inserted into the grid.

Value Behaviour
row Places items by filling rows first. This is the default.
column Places items by filling columns first.
row dense Allows later items to fill earlier holes when possible.
column dense Uses column-oriented placement with dense packing.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-flow: row;
}
Dense packing can visually place later items before earlier items in the layout. It does not change the DOM order or semantic reading order.

11. Difference Between Gap and Margin

Feature Grid Gap Margin
Purpose Spacing between adjacent grid tracks Space outside an element's border
Application Applied to the grid container Applied to individual elements
Outer container spacing Does not add space at the outer edges Can create outer spacing
Uniform spacing Convenient for consistent track spacing Requires individual margin rules

For consistent spacing between grid tracks, gap is usually simpler and easier to maintain.

12. Practical Project: Product Listing

Problem Statement

Create a product listing with three columns, consistent spacing and automatically generated rows.

HTML

<div class="products">
    <div class="product">Laptop</div>
    <div class="product">Keyboard</div>
    <div class="product">Mouse</div>
    <div class="product">Monitor</div>
    <div class="product">Headphones</div>
    <div class="product">Webcam</div>
</div>

CSS

.products {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: minmax(100px, auto);
    gap: 15px 20px;
}

.product {
    background: #174ea6;
    color: white;
    padding: 20px;
    text-align: center;
    border-radius: 8px;
}

Expected Result

  • Three columns are created.
  • Additional rows are generated automatically.
  • Rows have a minimum track size of 100px.
  • Rows can grow when their content requires more space.
  • Horizontal and vertical gaps are different.

13. Common Mistakes and Debugging

Mistake Correction
Using gap on a non-grid container. Make sure the element uses display: grid for this grid layout.
Confusing row-gap and column-gap. Remember that row-gap separates rows and column-gap separates columns.
Assuming grid-auto-rows controls all rows. It controls implicitly created rows, not explicitly sized rows.
Expecting grid-auto-columns to define explicit columns. Use grid-template-columns for explicit column tracks.
Ignoring large content inside a track. Inspect intrinsic sizing and consider minmax() or min-width constraints.
Using margins for every grid item. Use gap for consistent spacing between tracks.

Browser Debugging Steps

  1. Open Developer Tools using F12.
  2. Select the grid container.
  3. Inspect grid-template and grid-auto properties.
  4. Enable the Grid overlay if available.
  5. Check row and column track dimensions.
  6. Inspect gaps and automatically generated tracks.
  7. Check whether content is forcing unexpected sizing.

14. Placement Interview Questions and Answers

Q1. What is the gap property?

Answer: It defines spacing between adjacent rows and columns in a grid layout.

Q2. What is the difference between row-gap and column-gap?

Answer: row-gap controls spacing between rows, while column-gap controls spacing between columns.

Q3. What is a grid track?

Answer: A grid track is a row or column between adjacent grid lines.

Q4. What does grid-auto-rows do?

Answer: It defines the sizing of implicitly created row tracks.

Q5. What does grid-auto-columns do?

Answer: It defines the sizing of implicitly created column tracks.

Q6. What is grid-auto-flow?

Answer: It controls the direction and packing behaviour of automatic grid item placement.

Q7. What is the difference between grid-template-rows and grid-auto-rows?

Answer: grid-template-rows defines explicit row tracks, whereas grid-auto-rows controls implicitly generated row tracks.

Q8. What is min-content sizing?

Answer: It sizes a track using the minimum intrinsic size contribution of its contents.

Q9. Does gap add space around the outside of a grid?

Answer: No. Gap adds space between adjacent rows and columns, not around the outer edges of the grid.

Q10. What is dense packing in CSS Grid?

Answer: Dense packing allows the auto-placement algorithm to backtrack and fill earlier available holes when later items fit.
