2. Understanding Grid Alignment

CSS Grid provides alignment properties to control the position of grid items and the distribution of grid tracks within a grid container.

There are two important alignment categories:

  1. Item alignment: Positions items inside their grid areas.
  2. Track alignment: Positions the entire grid track structure inside the container.
In the common horizontal writing mode, justify properties generally operate along the inline axis, while align properties generally operate along the block axis. Their physical directions depend on writing mode and direction.

3. justify-items

The justify-items property controls the default inline-axis alignment of grid items inside their grid areas.

Syntax

.container {
    justify-items: start;
}

Common Values

Value Description
start Aligns items toward the inline start of their grid areas.
end Aligns items toward the inline end.
center Centers items along the inline axis.
stretch Stretches items to fill available space when sizing permits.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);

    justify-items: center;
}

Each grid item is centered along the inline axis inside its grid area.

4. align-items

The align-items property controls the default block-axis alignment of grid items inside their grid areas.

Syntax

.container {
    align-items: center;
}

Common Values

Value Description
start Aligns items toward the block start.
end Aligns items toward the block end.
center Centers items along the block axis.
stretch Stretches items when their sizing allows it.
baseline Aligns items using their text baselines.

Example

.container {
    display: grid;

    grid-template-columns: repeat(3, 1fr);

    align-items: center;
}

Items are centered along the block axis inside their grid areas.

5. place-items

The place-items property is a shorthand for:

  • align-items
  • justify-items

Syntax

.container {
    place-items: center;
}

This centers grid items along both alignment axes.

Different Values

.container {
    place-items: start center;
}

The first value applies to align-items, and the second applies to justify-items. If only one value is supplied, it is used for both.

Practical Example: Centering a Login Box

.login-wrapper {
    display: grid;
    place-items: center;
    min-height: 100vh;
}

.login-box {
    width: min(90%, 350px);
    padding: 25px;
    background: white;
    border-radius: 10px;
}

6. justify-self and align-self

These properties control alignment for an individual grid item instead of applying the same default alignment to every item.

justify-self

.item {
    justify-self: end;
}

Aligns an individual grid item along the inline axis.

align-self

.item {
    align-self: center;
}

Aligns an individual grid item along the block axis.

place-self

.item {
    place-self: center;
}

This is shorthand for align-self followed by justify-self.

An item's auto margins can absorb available space and affect alignment. Stretching also depends on the item's sizing and constraints.

7. justify-content

The justify-content property aligns the grid track structure along the inline axis within the grid container.

Syntax

.container {
    justify-content: center;
}

Common Values

Value Behaviour
start Places the grid tracks at the inline start.
end Places the grid tracks at the inline end.
center Centers the track structure.
space-between Distributes extra space between tracks.
space-around Distributes space around tracks.
space-evenly Distributes equal space between and around tracks.
stretch Stretches eligible auto-sized tracks.

Example

.container {
    display: grid;

    grid-template-columns:
        repeat(3, 120px);

    justify-content: center;

    gap: 10px;
}

The three fixed-width tracks are centered within the available inline space.

8. align-content

The align-content property aligns the grid track structure along the block axis inside the grid container.

Example

.container {
    display: grid;

    grid-template-columns: repeat(2, 120px);

    grid-template-rows: repeat(2, 60px);

    height: 300px;

    align-content: center;

    gap: 10px;
}

The complete set of grid rows is centered along the block axis.

Track alignment becomes noticeable when the grid tracks do not occupy all available space in the container. It does not mean that individual items are centered inside their own grid areas.

9. place-content

The place-content property is a shorthand for:

  • align-content
  • justify-content

Example

.container {
    display: grid;

    height: 400px;

    grid-template-columns:
        repeat(2, 120px);

    grid-template-rows:
        repeat(2, 80px);

    place-content: center;
}

The grid track structure is centered along both alignment axes.

10. Difference Between Item Alignment and Track Alignment

Item Alignment Track Alignment
Controls items inside their grid areas. Controls the grid tracks inside the container.
justify-items justify-content
align-items align-content
justify-self Not a track-alignment property
align-self Not a track-alignment property
place-items place-content
A common interview mistake is confusing justify-items with justify-content. Remember: items are aligned inside grid areas, while content alignment positions the grid tracks within the container.

11. CSS Grid vs Flexbox

Both CSS Grid and Flexbox are modern layout systems. They solve related but different layout problems.

CSS Grid

  • Two-dimensional layout system.
  • Controls rows and columns together.
  • Supports explicit grid placement.
  • Supports named grid areas.
  • Suitable for page-level structures.
  • Useful for dashboards and galleries.

Flexbox

  • One-dimensional layout system.
  • Organizes items along one main axis at a time.
  • Distributes available space between items.
  • Supports flexible growth and shrinking.
  • Suitable for navigation bars.
  • Useful for component-level alignment.

12. Detailed Grid vs Flexbox Comparison

Feature CSS Grid Flexbox
Layout dimension Two-dimensional One-dimensional
Primary layout control Rows and columns Main and cross axes
Item placement Grid lines, areas and tracks Flex direction, order and alignment
Space distribution Track sizing and alignment Flex grow, shrink and alignment
Named areas Supported Not supported as a native layout feature
Typical use Page layout and dashboards Navigation and component alignment

13. When Should You Use Grid or Flexbox?

Use CSS Grid When:

  • You need rows and columns controlled together.
  • You are designing a complete page layout.
  • You need explicit placement across tracks.
  • You need named layout regions.
  • You are building a dashboard or complex gallery.

Use Flexbox When:

  • You need a one-dimensional arrangement.
  • You are building a navigation bar.
  • You need flexible spacing between items.
  • You are aligning buttons or icons in a component.
  • You need flexible item growth and shrinking.
Grid and Flexbox can be combined in the same application. For example, Grid can define the overall dashboard structure, while Flexbox can align the controls inside each dashboard card.

14. Practical Project: Dashboard Using Grid and Flexbox

Problem Statement

Create a dashboard where:

  • CSS Grid controls the main page structure.
  • Grid creates responsive statistics cards.
  • Flexbox aligns the content inside each card.
  • Flexbox aligns action buttons.

HTML

<div class="dashboard">

    <header class="header">
        Learning Dashboard
    </header>

    <main class="content">

        <section class="stats">

            <article class="card">
                <h3>Courses</h3>
                <p>12 Active</p>
                <button>View</button>
            </article>

            <article class="card">
                <h3>Projects</h3>
                <p>4 Active</p>
                <button>View</button>
            </article>

        </section>

    </main>
</div>

CSS

.dashboard {
    display: grid;

    grid-template-columns: 1fr;

    gap: 20px;
}

.header {
    background: #174ea6;
    color: white;
    padding: 20px;
}

.stats {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));

    gap: 15px;
}

.card {
    display: flex;

    flex-direction: column;

    align-items: flex-start;

    gap: 10px;

    padding: 20px;

    background: #eef5ff;
    border-radius: 8px;
}

.card button {
    margin-top: auto;
    padding: 8px 15px;
}

Expected Result

  • Grid controls the responsive card structure.
  • Flexbox controls the internal card arrangement.
  • Cards can grow or shrink according to available space.
  • Buttons can be pushed toward the bottom using auto margin.

15. Common Mistakes and Debugging

Mistake Correction
Using justify-items to align the whole grid. Use justify-content for track alignment.
Using align-items to move all grid tracks. Use align-content for track alignment.
Expecting place-items to center the entire grid structure. Use place-content when track alignment is required.
Expecting stretch to override fixed item dimensions. Check width, height, min/max constraints and auto margins.
Using Grid for every small component. Use Flexbox when a one-dimensional arrangement is sufficient.
Using Flexbox for a complex row-and-column page layout. Consider Grid for explicit two-dimensional placement.

Debugging Checklist

  1. Identify whether the problem concerns items or tracks.
  2. Check the grid container's available dimensions.
  3. Inspect grid-template-columns and grid-template-rows.
  4. Check item dimensions and margins.
  5. Verify whether the grid has free space for alignment.
  6. Use the browser Grid overlay.
  7. Choose Grid or Flexbox based on the layout requirement.

16. Placement Interview Questions and Answers

Q1. What does justify-items do?

Answer: It controls the default inline-axis alignment of grid items within their grid areas.

Q2. What does align-items do in Grid?

Answer: It controls the default block-axis alignment of grid items inside their grid areas.

Q3. What is place-items?

Answer: It is shorthand for align-items and justify-items.

Q4. What is the difference between justify-content and justify-items?

Answer: justify-content aligns the grid track structure within the container. justify-items aligns items inside their grid areas.

Q5. What is align-content?

Answer: It aligns the grid track structure along the block axis within the grid container.

Q6. What is place-content?

Answer: It is shorthand for align-content and justify-content.

Q7. What is the difference between justify-self and justify-items?

Answer: justify-items sets the default alignment for grid items. justify-self controls one individual item's alignment.

Q8. Is CSS Grid one-dimensional or two-dimensional?

Answer: CSS Grid is a two-dimensional layout system because it controls rows and columns together.

Q9. Is Flexbox one-dimensional or two-dimensional?

Answer: Flexbox is one-dimensional because it lays out items along a main axis at a time.

Q10. Can Grid and Flexbox be used together?

Answer: Yes. Grid can control the overall page structure, while Flexbox can control the arrangement of elements inside individual components.

Q11. Which is better for a navigation bar?

Answer: Flexbox is generally a straightforward choice because navigation items usually form a one-dimensional row or column.

Q12. Which is better for a dashboard?

Answer: Grid is generally suitable for the overall dashboard structure because it needs coordinated rows and columns. Flexbox can still be used inside dashboard components.
