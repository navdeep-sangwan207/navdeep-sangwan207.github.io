2. What Are Grid Template Areas?

CSS Grid allows developers to assign names to rectangular areas of a grid.

These named areas make layouts easier to understand and maintain, particularly when building page structures.

Common page areas include:

  • header
  • navigation
  • main content
  • sidebar
  • footer

Property

grid-template-areas

It defines a visual arrangement of named grid areas using strings.

3. Basic Syntax of grid-template-areas

.container {
    display: grid;

    grid-template-columns: 2fr 1fr;

    grid-template-areas:
        "header header"
        "main   sidebar"
        "footer footer";
}

This creates three rows and two columns:

Row Column 1 Column 2
1 header header
2 main sidebar
3 footer footer
Each quoted string represents one grid row. Each name identifies a cell belonging to a named area.

4. Assigning Elements with grid-area

After defining named areas, assign each grid item to its corresponding area using the grid-area property.

Example

.header {
    grid-area: header;
}

.main {
    grid-area: main;
}

.sidebar {
    grid-area: sidebar;
}

.footer {
    grid-area: footer;
}

The value of grid-area matches the name used in grid-template-areas.

6. Rules for Named Grid Areas

Named areas must follow specific structural rules.

  • Each row must contain the same number of cells.
  • Each row is represented by a quoted string.
  • Area names are case-sensitive identifiers.
  • A named area must form one continuous rectangle.
  • The same name can appear in multiple adjacent cells.
  • Separate areas cannot use the same name.

Valid Example

grid-template-areas:
    "header header"
    "main sidebar"
    "footer footer";

Invalid Example: Non-Rectangular Area

grid-template-areas:
    "header header"
    "main   header";

The header area is not rectangular in this arrangement, so the declaration is invalid.

An invalid grid-template-areas value is ignored as a declaration. Other valid grid declarations on the container can still apply.

7. Empty Grid Cells Using Dot Notation

A period (.) represents an empty cell in the grid-template-areas declaration.

Example

.container {
    display: grid;

    grid-template-columns: repeat(3, 1fr);

    grid-template-areas:
        "header header header"
        "main   main   ."
        "footer footer footer";
}

The period reserves an unnamed cell in the second row and third column.

Use one or more periods to represent empty cells. The empty cells do not create named areas.

8. What Is an Explicit Grid?

The explicit grid is the part of the grid directly defined using properties such as:

  • grid-template-columns
  • grid-template-rows
  • grid-template-areas

Example

.container {
    display: grid;

    grid-template-columns: 200px 1fr;

    grid-template-rows: 100px 300px;
}

This explicitly defines two columns and two rows.

9. What Is an Implicit Grid?

An implicit grid is created when grid items require additional rows or columns beyond the explicit grid.

This can happen when:

  • There are more automatically placed items than available explicit cells.
  • An item is positioned outside the explicit grid.
  • An item spans beyond the explicit grid boundaries.

Example

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
}

.item {
    padding: 20px;
}

If six items are automatically placed, the grid creates additional rows when the two explicit columns are filled.

10. Explicit Grid vs Implicit Grid

Feature Explicit Grid Implicit Grid
Creation Defined directly by the developer Generated automatically when needed
Main properties grid-template-columns, grid-template-rows, grid-template-areas grid-auto-rows, grid-auto-columns, grid-auto-flow
Track count Specified through explicit definitions Depends on placement requirements
Typical use Page structure and planned layout Automatically generated additional tracks

11. Controlling Implicit Rows with grid-auto-rows

The grid-auto-rows property defines the sizing of automatically generated row tracks.

Example

.container {
    display: grid;

    grid-template-columns: repeat(2, 1fr);

    grid-auto-rows: 120px;

    gap: 10px;
}

When additional rows are generated, each implicit row receives a 120px track size.

Flexible Row Sizing

.container {
    grid-auto-rows: minmax(100px, auto);
}

Each implicit row has a minimum size of 100px and can grow when its content requires additional space.

12. Controlling Implicit Columns with grid-auto-columns

The grid-auto-columns property defines the sizing of automatically generated column tracks.

Example

.container {
    display: grid;

    grid-template-rows: repeat(2, 100px);

    grid-auto-flow: column;

    grid-auto-columns: 160px;

    gap: 10px;
}

When automatic placement generates additional columns, each implicit column uses the specified sizing.

13. Responsive Layout Using Named Areas

Named grid areas make responsive layout changes easier because the visual arrangement can be redefined inside media queries.

CSS

.page {
    display: grid;

    grid-template-columns: 2fr 1fr;

    grid-template-areas:
        "content sidebar";

    gap: 15px;
}

.content {
    grid-area: content;
}

.sidebar {
    grid-area: sidebar;
}

@media (max-width: 650px) {
    .page {
        grid-template-columns: 1fr;

        grid-template-areas:
            "content"
            "sidebar";
    }
}

15. Common Mistakes and Debugging

Mistake Correction
Using different numbers of cells in rows. Keep every grid-template-areas row the same number of cells.
Defining a non-rectangular named area. Ensure every named area forms one rectangle.
Using a different name in grid-area. Match the item name to the declared area name.
Expecting named areas to create HTML elements. Named areas only define CSS layout regions.
Assuming all tracks are explicit. Check whether automatic placement created implicit tracks.
Using grid-template-areas without defining columns. Define appropriate column sizing for the intended layout.

Debugging Checklist

  1. Inspect grid-template-areas.
  2. Check that each row has the same number of cells.
  3. Verify that named areas are rectangular.
  4. Check grid-area names on child elements.
  5. Inspect explicit and implicit tracks.
  6. Check grid-auto-rows and grid-auto-columns.
  7. Test the layout at different viewport widths.

16. Placement Interview Questions and Answers

Q1. What is grid-template-areas?

Answer: It defines named rectangular regions in a CSS Grid layout using strings.

Q2. What is grid-area?

Answer: It assigns an item to a named grid area or specifies its row and column line placement.

Q3. What does a period represent in grid-template-areas?

Answer: A period represents an empty grid cell without a named area.

Q4. What is an explicit grid?

Answer: It is the grid structure explicitly defined using grid-template properties.

Q5. What is an implicit grid?

Answer: It consists of automatically generated tracks created when grid placement requires space outside the explicit grid.

Q6. What is the purpose of grid-auto-rows?

Answer: It defines the sizing of implicit row tracks.

Q7. What is the purpose of grid-auto-columns?

Answer: It defines the sizing of implicit column tracks.

Q8. Can named grid areas be changed in a media query?

Answer: Yes. This is useful for changing a desktop layout into a mobile layout.

Q9. What happens if a named grid area is not rectangular?

Answer: The grid-template-areas declaration is invalid and is ignored.

Q10. Can an implicit grid contain additional columns?

Answer: Yes. Additional columns can be created by placement requirements and their sizing can be controlled using grid-auto-columns.
