Lecture 6: Auto Fit, Auto Fill and Minmax

Chapter 7 – CSS Grid Layout

Create flexible, responsive grid layouts using automatic track repetition and minimum/maximum sizing.

1. Learning Objectives

  • Understand the repeat() function.
  • Understand auto-fit and auto-fill.
  • Understand the minmax() function.
  • Combine repeat(), minmax() and fractional units.
  • Create responsive grids without numerous media queries.
  • Understand how available space affects track sizing.
  • Build practical responsive card layouts.

2. Understanding the repeat() Function

The repeat() function reduces repetition when defining grid tracks.

Without repeat()

.container {
    display: grid;
    grid-template-columns:
        1fr 1fr 1fr 1fr;
}

With repeat()

.container {
    display: grid;
    grid-template-columns:
        repeat(4, 1fr);
}

Both declarations define four equal fractional column tracks.

Syntax

repeat(number-of-repetitions, track-list)

Example with Fixed Width

.container {
    grid-template-columns:
        repeat(3, 150px);
}

This creates three columns, each 150px wide.

3. Understanding the minmax() Function

The minmax() function defines a minimum and maximum sizing range for a grid track.

Syntax

minmax(minimum, maximum)

Example

.container {
    display: grid;

    grid-template-columns:
        minmax(150px, 1fr) 2fr;
}

The first track has a minimum size of 150px and can grow according to the available space.

The second track receives a flexible share of the available space.

Common minmax() Examples

Declaration Meaning
minmax(100px, 300px) Track size is constrained between 100px and 300px.
minmax(150px, 1fr) At least 150px, with flexible maximum sizing.
minmax(0, 1fr) Flexible track with a zero minimum sizing function.
minmax(auto, 1fr) Automatic minimum with a flexible maximum.
minmax(200px, max-content) Minimum 200px, with a content-based maximum.
A common practical pattern is minmax(0, 1fr). It allows a flexible track to shrink below its automatic minimum content size, which can help prevent long content from forcing a grid wider than intended.

4. Understanding auto-fill

The auto-fill keyword automatically repeats tracks to fit as many track sizes as possible into the available grid space.

Syntax

.container {
    display: grid;

    grid-template-columns:
        repeat(auto-fill, minmax(150px, 1fr));

    gap: 15px;
}

The browser calculates how many columns can fit based on the minimum track size and available space.

Unlike auto-fit, auto-fill can preserve empty repeated tracks when there are fewer grid items than available tracks.

5. Understanding auto-fit

The auto-fit keyword also calculates how many repeated tracks can fit in the available space.

However, after placement, empty repeated tracks are collapsed when possible. The remaining tracks can expand to use the available space.

Syntax

.container {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(150px, 1fr));

    gap: 15px;
}

6. Difference Between auto-fill and auto-fit

Feature auto-fill auto-fit
Track repetition Creates as many repeated tracks as fit. Creates as many repeated tracks as fit.
Empty tracks Can preserve empty tracks. Collapses empty repeated tracks when possible.
Available space Empty tracks can continue occupying space. Occupied tracks can expand into freed space.
Typical use Layouts where maintaining potential track positions matters. Layouts where existing items should expand to fill space.
With enough items to fill all repeated tracks, auto-fill and auto-fit can look identical. Their difference becomes noticeable when the available space allows more tracks than there are items.

7. Combining repeat(), auto-fit and minmax()

A highly useful responsive Grid pattern combines all three features.

Example

.container {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));

    gap: 20px;
}

This creates columns that:

  • Have a minimum track size of 220px.
  • Expand according to available space.
  • Automatically adjust the number of columns.
  • Use consistent spacing between cards.

8. Practical Example: Responsive Course Cards

HTML

<div class="courses">
    <article class="course">
        <h3>C Programming</h3>
        <p>Learn programming fundamentals.</p>
    </article>

    <article class="course">
        <h3>C++ Programming</h3>
        <p>Learn object-oriented programming.</p>
    </article>

    <article class="course">
        <h3>Linux</h3>
        <p>Learn Linux commands and scripting.</p>
    </article>

    <article class="course">
        <h3>Embedded Systems</h3>
        <p>Learn embedded development.</p>
    </article>
</div>

CSS

.courses {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));

    gap: 20px;
}

.course {
    background: white;
    padding: 20px;
    border-radius: 10px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

Expected Result

  • Wide screens display multiple columns.
  • Narrow screens automatically display fewer columns.
  • Cards maintain a minimum track width of 220px.
  • Cards expand to use available space.
  • No separate breakpoint is required for this basic column adjustment.

9. Understanding minmax() with Fractional Units

The fr unit distributes available space among flexible grid tracks after accounting for fixed sizes and gaps.

Example

.container {
    display: grid;

    grid-template-columns:
        minmax(100px, 1fr)
        minmax(200px, 2fr)
        minmax(100px, 1fr);

    gap: 10px;
}

The three tracks have flexible maximum sizing factors of 1fr, 2fr and 1fr, subject to their minimum constraints.

10. minmax() for Responsive Rows

The minmax() function can also control row track sizing.

Example

.container {
    display: grid;

    grid-template-columns: repeat(2, 1fr);

    grid-template-rows:
        minmax(100px, auto)
        minmax(150px, auto);
}

The first row has a minimum size of 100px, and the second has a minimum size of 150px. Both can grow as needed by their content.

11. Practical Project: Responsive Dashboard Cards

Problem Statement

Create a dashboard containing cards for:

  • Total Courses
  • Active Projects
  • Completed Lessons
  • Pending Tasks

HTML

<div class="dashboard">
    <div class="card">
        <h3>Total Courses</h3>
        <p>12</p>
    </div>

    <div class="card">
        <h3>Active Projects</h3>
        <p>4</p>
    </div>

    <div class="card">
        <h3>Completed Lessons</h3>
        <p>85</p>
    </div>

    <div class="card">
        <h3>Pending Tasks</h3>
        <p>6</p>
    </div>
</div>

CSS

.dashboard {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));

    gap: 18px;
}

.card {
    background: #eef5ff;
    padding: 20px;
    border-radius: 10px;
    text-align: center;
}

.card p {
    font-size: 28px;
    font-weight: bold;
}

Expected Result

  • Cards automatically adjust their column count.
  • Each card has a minimum track width of 200px.
  • Available space is distributed among occupied tracks.
  • The layout adapts to different container widths.

12. Common Mistakes and Debugging

Mistake Correction
Using auto-fit without minmax(). For responsive card layouts, combine auto-fit with an appropriate minimum track size.
Confusing auto-fill and auto-fit. Remember that auto-fit collapses empty repeated tracks when possible.
Setting a minimum track size that is too large. Choose a minimum size that fits the intended container width.
Assuming 1fr always means equal width. Consider other track constraints, gaps and intrinsic sizing.
Ignoring long content. Use minmax(0, 1fr), min-width: 0 or suitable text wrapping where appropriate.
Using repeat() with an incompatible track definition. Check the allowed sizing syntax for auto-repeat.

Debugging Checklist

  1. Inspect grid-template-columns.
  2. Check the minimum and maximum values in minmax().
  3. Verify the container's available width.
  4. Check the number of grid items.
  5. Compare auto-fit and auto-fill.
  6. Inspect track sizes using browser Developer Tools.
  7. Test long text and narrow viewport widths.

13. Placement Interview Questions and Answers

Q1. What is the repeat() function?

Answer: It repeats a specified grid track list to reduce repetitive track definitions.

Q2. What is minmax()?

Answer: It defines minimum and maximum sizing constraints for a grid track.

Q3. What is auto-fit?

Answer: It creates as many repeated tracks as can fit and collapses empty repeated tracks when possible.

Q4. What is auto-fill?

Answer: It creates as many repeated tracks as can fit while retaining empty tracks where applicable.

Q5. What is the difference between auto-fit and auto-fill?

Answer: Auto-fit collapses empty repeated tracks, allowing occupied tracks to expand. Auto-fill preserves those empty tracks.

Q6. What does repeat(auto-fit, minmax(200px, 1fr)) do?

Answer: It creates as many columns as can fit with a minimum track size of 200px and flexible maximum sizing.

Q7. Can minmax() be used with rows?

Answer: Yes. It can define minimum and maximum sizing for both row and column tracks.

Q8. Why is minmax(0, 1fr) useful?

Answer: It allows a flexible track to shrink below its automatic minimum content sizing, helping prevent oversized tracks.

Q9. Does auto-fit always produce fewer columns than auto-fill?

Answer: No. Both can generate the same number of repeated tracks. Their difference is how empty repeated tracks are treated.

Q10. Can auto-fit reduce the need for media queries?

Answer: Yes. It can automatically adjust the number and width of columns based on available space, although media queries may still be needed for other design changes.

15. Quick Revision

  • repeat() reduces repeated track definitions.
  • minmax() defines minimum and maximum track sizing.
  • auto-fill creates as many repeated tracks as fit.
  • auto-fit collapses empty repeated tracks when possible.
  • Occupied auto-fit tracks can expand into available space.
  • Fractional units distribute available space.
  • minmax(0, 1fr) is useful for flexible tracks with constrained content.
  • Auto-repeat patterns are useful for responsive card grids.
  • Media queries may still be needed for more substantial layout changes.
