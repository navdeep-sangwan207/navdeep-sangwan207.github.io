2. Understanding Grid Lines

Grid lines are the dividing lines that separate rows and columns in a grid. Grid items can be positioned by referring to these lines.

A grid with three columns has four vertical grid lines. A grid with two rows has three horizontal grid lines.

Example: Three Columns

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

The vertical grid lines are numbered from 1 to 4 in the normal direction.

Grid line Position
Line 1 Before the first column
Line 2 Between column 1 and column 2
Line 3 Between column 2 and column 3
Line 4 After the third column
A grid with N explicit column tracks normally has N + 1 explicit column grid lines. The same principle applies to rows.

3. Understanding Grid Lines and Tracks

Grid lines define the boundaries of grid tracks.

  • Grid lines are boundaries.
  • Grid tracks are the spaces between lines.
  • Grid cells are formed by the intersection of row and column tracks.

Example

.container {
    display: grid;
    grid-template-columns: 100px 100px 100px;
    grid-template-rows: 80px 80px;
}

This creates three column tracks and two row tracks.

The explicit grid has four vertical grid lines and three horizontal grid lines.

4. grid-column Property

The grid-column property controls the starting and ending column grid lines of a grid item.

Syntax

grid-column: start-line / end-line;

Example

.item {
    grid-column: 1 / 3;
}

The item starts at column line 1 and ends at column line 3. It occupies two column tracks.

Live Layout Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);

6. Individual Start and End Properties

Grid placement can also be defined using separate start and end properties.

Property Purpose
grid-column-start Defines the column starting line.
grid-column-end Defines the column ending line.
grid-row-start Defines the row starting line.
grid-row-end Defines the row ending line.

Example

.featured {
    grid-column-start: 1;
    grid-column-end: 3;

    grid-row-start: 1;
    grid-row-end: 3;
}

The item occupies the first two columns and the first two rows.

7. Understanding the span Keyword

The span keyword specifies how many grid tracks an item should span rather than specifying both boundary lines.

Span Two Columns

.item {
    grid-column: span 2;
}

The item spans two column tracks. The Grid placement algorithm determines the relevant position if a start line has not been specified.

Span Two Rows

.item {
    grid-row: span 2;
}

The item spans two row tracks.

Combining a Start Line with Span

.item {
    grid-column: 2 / span 2;
}

The item starts at column line 2 and spans two column tracks.

span describes a distance in tracks, not a grid line number. For example, grid-column: 2 / span 2 starts at line 2 and extends across two column tracks.

8. Spanning Multiple Rows and Columns

An item can span both rows and columns simultaneously.

Example

    grid-column: 1 / 3;

9. The grid-area Shorthand for Line Placement

The grid-area property can specify all four grid line positions using a shorthand.

Syntax

grid-area: row-start / column-start /
           row-end / column-end;

Example

.featured {
    grid-area: 1 / 1 / 3 / 3;
}

This is equivalent to: 

.featured {
    grid-row: 1 / 3;
    grid-column: 1 / 3;
}
grid-area has another important use: assigning a named grid area. That usage is covered in the next lecture.

10. Practical Project: Dashboard with a Featured Panel

Problem Statement

Create a dashboard with a large main content panel and smaller supporting panels using grid item spanning.

HTML

<div class="dashboard">
    <div class="main">Main Dashboard</div>
    <div>Notifications</div>
    <div>Profile</div>
    <div>Recent Activity</div>
    <div>Quick Links</div>

    grid-row: 1 / 3;

11. Negative Grid Line Numbers

CSS Grid also supports negative grid line numbers.

Negative numbers count backwards from the end of the explicit grid.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

.featured {
    grid-column: 1 / -1;
}

In this three-column explicit grid, line -1 refers to the last explicit column grid line.

The item spans the entire explicit column grid.

Negative line numbers are useful when the total number of tracks may change. They refer to grid lines counting backwards from the end of the explicit grid.

12. Common Mistakes and Debugging

Mistake Correction
Confusing grid lines with grid tracks. Tracks are the spaces between grid lines.
Using the wrong end line. Remember that the end line is the boundary after the final occupied track.
Assuming span is a line number. span specifies a number of tracks.
Using grid-row for horizontal placement. Use grid-column for columns and grid-row for rows.
Overlapping grid items unintentionally. Inspect start and end lines for each item.
Assuming negative lines count from zero. Negative grid lines count backwards from the end of the explicit grid.

Debugging Checklist

  1. Inspect the grid container.
  2. Check the number of explicit rows and columns.
  3. Enable the browser Grid overlay.
  4. Identify the relevant start and end grid lines.
  5. Check whether an item spans multiple tracks.
  6. Inspect any unintended overlaps or implicit tracks.

13. Placement Interview Questions and Answers

Q1. What are grid lines?

Answer: Grid lines are the boundaries that separate grid tracks.

Q2. How many vertical grid lines exist in a three-column grid?

Answer: Four vertical grid lines exist in a grid with three explicit column tracks.

Q3. What does grid-column do?

Answer: It defines the column grid lines between which a grid item is placed.

Q4. What does grid-row do?

Answer: It defines the row grid lines between which a grid item is placed.

Q5. What is the span keyword?

Answer: It specifies how many grid tracks an item should span.

Q6. How do you make an item span two columns?

Answer:

grid-column: span 2;

Q7. How do you make an item occupy the entire explicit grid width?

Answer:

grid-column: 1 / -1;

Q8. What is grid-area?

Answer: It is a shorthand for grid placement and can also assign a named grid area.

Q9. What does grid-column: 2 / 4 mean?

Answer: The item starts at column line 2 and ends at column line 4, occupying two column tracks.

Q10. What are negative grid line numbers?

Answer: They identify grid lines by counting backwards from the end of the explicit grid.
