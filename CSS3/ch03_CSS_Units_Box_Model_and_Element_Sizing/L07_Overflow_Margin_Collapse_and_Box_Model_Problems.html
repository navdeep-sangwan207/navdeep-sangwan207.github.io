2. What is Overflow in CSS?

Overflow occurs when an element's content does not fit inside its available content area.

The overflow property controls how content outside an element's padding box is handled.

Syntax

selector {
    overflow: value;
}

Example

.container {
    width: 300px;
    height: 150px;
    overflow: auto;
}

If the content exceeds the available space, the browser can provide scrollbars.

3. Overflow Property Values

Value Behavior
visible Content is allowed to extend outside the element. This is the initial value.
hidden Overflowing content is clipped and is not directly accessible through user scrolling.
clip Content is clipped at the overflow clip edge. It does not create a scroll container.
scroll Creates a scroll container and allows scrolling even when content does not currently overflow. Scrollbar appearance depends on the platform.
auto Provides scrolling when needed.

Example

.box {
    width: 250px;
    height: 100px;
    overflow: hidden;
}

Content extending beyond the element's overflow area is clipped.

Important distinction: hidden creates a scroll container, even though the user cannot normally scroll it directly. clip does not create a scroll container.

4. Overflow: Visible

The default overflow behavior is generally visible.

Example

.box {
    width: 200px;
    height: 100px;
    overflow: visible;
}

When content exceeds the box, it can extend beyond the element's boundaries.

Typical Use

  • Content that should extend naturally beyond a box.
  • Decorative elements.
  • Dropdown content in layouts where clipping is not desired.
Overflowing content can overlap nearby elements. Check the layout before relying on visible overflow.

5. Overflow: Hidden

The hidden value clips content that exceeds the element's overflow area.

Example

.box {
    width: 250px;
    height: 100px;
    overflow: hidden;
}

Common Applications

  • Clipping image edges.
  • Containing certain visual effects.
  • Preventing unwanted visible overflow.
Do not use overflow: hidden as a universal layout fix. It can clip dropdown menus, shadows and focus indicators.

6. Overflow: Scroll and Auto

Overflow: Scroll

.panel {
    width: 300px;
    height: 150px;
    overflow: scroll;
}

The element becomes a scroll container. Scrollbar presentation varies between operating systems and browsers.

Overflow: Auto

.panel {
    width: 300px;
    height: 150px;
    overflow: auto;
}

Scrolling is provided when the content overflows.

Practical Demonstration

This is a scrollable content area. Add more text to see how overflow works. When the content exceeds the available height, the browser provides scrolling. Scroll to read the remaining content. This behavior is useful for message panels, logs and dashboard sections.

7. Overflow-X and Overflow-Y

CSS allows horizontal and vertical overflow to be controlled independently.

Property Purpose
overflow-x Controls horizontal overflow.
overflow-y Controls vertical overflow.

Example 1: Horizontal Scrolling

.table-container {
    overflow-x: auto;
}

Useful for wide tables on smaller screens.

Example 2: Vertical Scrolling

.message-panel {
    max-height: 300px;
    overflow-y: auto;
}

Useful for message lists and log panels.

Example 3: Control Both Directions

.container {
    overflow-x: hidden;
    overflow-y: auto;
}
When one overflow axis uses a value other than visible or clip, the computed behavior of the other axis can change. Inspect computed values in DevTools when behavior differs from the declarations.

8. Common Causes of Horizontal Page Overflow

Horizontal overflow is a frequent responsive-design problem.

Cause 1: Fixed Width

.container {
    width: 1200px;
}

This can exceed the viewport on smaller devices.

Improved Approach

.container {
    width: 100%;
    max-width: 1200px;
    margin-inline: auto;
}

Cause 2: Width: 100% with Additional Padding

.box {
    width: 100%;
    padding: 20px;
    border: 2px solid black;
}

With content-box, padding and borders are added outside the declared width.

Improved Approach

*,
*::before,
*::after {
    box-sizing: border-box;
}

Cause 3: Long Unbreakable Content

.text {
    overflow-wrap: anywhere;
}

Cause 4: Images Exceeding Containers

img {
    max-width: 100%;
    height: auto;
}

Cause 5: Flex Items Refusing to Shrink

.flex-item {
    min-width: 0;
}

This can allow a flex item to shrink below its automatic content-based minimum size when appropriate.

9. Understanding Margin Collapse

Margin collapsing occurs when certain adjacent vertical margins in normal block flow combine into a single margin rather than being added together.

Example

.first {
    margin-bottom: 30px;
}

.second {
    margin-top: 20px;
}

When these margins collapse, the resulting separation is generally 30px, not 50px.

For two positive adjoining margins, the larger margin is used rather than their sum.

Important Rules

  • Vertical margins of adjacent block-level elements in normal flow can collapse.
  • Horizontal margins do not collapse.
  • Flex and Grid item margins do not collapse with one another.
  • Floated and absolutely positioned elements do not participate in normal vertical margin collapsing in the same way.

10. Margin Collapse Between Parent and Child

A parent's top or bottom margin can collapse with a child's margin when the required conditions are satisfied.

Example

<div class="parent">
    <div class="child">
        Child content
    </div>
</div>
.parent {
    background: lightgreen;
}

.child {
    margin-top: 30px;
    background: lightblue;
}

If there is no border, padding, inline content or other relevant separator preventing collapse, the child's top margin can collapse through the parent.

11. How to Prevent Margin Collapse

There are several ways to prevent unwanted parent-child margin collapsing.

Method 1: Add Padding

.parent {
    padding-top: 1px;
}

Method 2: Add a Border

.parent {
    border-top: 1px solid transparent;
}

Method 3: Create a New Block Formatting Context

.parent {
    display: flow-root;
}

display: flow-root establishes a new block formatting context. It is a useful modern approach when a container needs to contain its contents and prevent relevant margin collapsing across its boundary.

Placement recommendation: Prefer a deliberate layout solution such as Flexbox, Grid or flow-root rather than adding arbitrary borders and padding only to correct unexpected spacing.

12. Positive and Negative Margin Collapse

Margin collapsing can involve positive and negative margins.

Margins Collapsed Result
30px and 20px 30px
-20px and -10px -20px
30px and -10px 20px
30px and -40px -10px

For positive margins, the largest positive value is used. For negative margins, the most negative value is used. When positive and negative margins collapse together, the negative amount is subtracted from the positive amount.

13. Margin Collapse vs Flexbox and Grid

Margins between Flexbox and Grid items do not collapse.

Flexbox Example

.container {
    display: flex;
    flex-direction: column;
}

.item {
    margin-bottom: 20px;
}

The vertical margins of separate flex items do not collapse.

Grid Example

.container {
    display: grid;
    gap: 20px;
}

For spacing between Grid items, using gap is usually clearer and more predictable than relying on margins.

14. Box Model Debugging with Browser DevTools

Browser Developer Tools help identify actual element dimensions and spacing.

Steps

  1. Open a webpage in Chrome or another modern browser.
  2. Right-click the element and choose Inspect.
  3. Select the required HTML element.
  4. Open the Computed panel.
  5. Inspect margin, border, padding and content dimensions.
  6. Check the computed box-sizing property.
  7. Temporarily modify CSS values to identify the problem.

Useful JavaScript Dimension Properties

Property Meaning
offsetWidth Integer layout width including padding, border and rendered vertical scrollbar, excluding margin.
offsetHeight Integer layout height including padding, border and rendered horizontal scrollbar, excluding margin.
clientWidth Inner width including padding but excluding borders and rendered vertical scrollbar.
clientHeight Inner height including padding but excluding borders and rendered horizontal scrollbar.
getBoundingClientRect() Returns the element's rendered bounding rectangle relative to the viewport.

JavaScript Example

<div id="box">CSS Box Model</div>

<script>
const box = document.getElementById("box");

console.log("Offset Width:", box.offsetWidth);
console.log("Offset Height:", box.offsetHeight);

console.log("Client Width:", box.clientWidth);
console.log("Client Height:", box.clientHeight);

console.log(
    "Bounding Rectangle:",
    box.getBoundingClientRect()
);
</script>

These measurements are useful when diagnosing unexpected layout dimensions.

15. Practical Box Model Problem 1

Question: An element has the following CSS:

.box {
    width: 400px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
    box-sizing: content-box;
}

Calculate the total horizontal space occupied.

Solution

  • Content width = 400px
  • Padding = 20 × 2 = 40px
  • Border = 5 × 2 = 10px
  • Margin = 10 × 2 = 20px

Total = 400 + 40 + 10 + 20 = 470px.

16. Practical Box Model Problem 2

Question: What is the total horizontal space occupied when the same element uses border-box?

.box {
    width: 400px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
    box-sizing: border-box;
}

Solution

  • Declared border-box width = 400px
  • Padding and border are already included.
  • Left and right margins = 20px

Total = 400 + 20 = 420px.

17. Practical Problem 3: Fix Horizontal Overflow

Problem: A webpage displays a horizontal scrollbar on mobile devices.

Problematic CSS

.container {
    width: 100%;
    padding: 30px;
    border: 5px solid blue;
}

Under content-box, padding and borders are added outside the 100% content width.

Solution

*,
*::before,
*::after {
    box-sizing: border-box;
}

.container {
    width: 100%;
    padding: 30px;
    border: 5px solid blue;
}

The declared width now includes padding and border, preventing this particular source of overflow.

18. Practical Problem 4: Fix an Image Overflow

Problem: An image is wider than its card on a mobile screen.

Solution

img {
    max-width: 100%;
    height: auto;
    display: block;
}

The image can shrink to fit its containing block while preserving its aspect ratio.

19. Practical Problem 5: Fix a Scrollable Table

Problem: A wide data table breaks the mobile layout.

Solution

.table-wrapper {
    width: 100%;
    overflow-x: auto;
}

table {
    min-width: 600px;
    border-collapse: collapse;
}

The table retains its useful minimum width while the wrapper provides horizontal scrolling when needed.

20. Placement Interview Questions and Answers

Q1. What is overflow in CSS?

Answer: Overflow occurs when content exceeds the available area of an element. The overflow property controls how that content is handled.

Q2. What is the difference between overflow: hidden and overflow: auto?

Answer: Hidden clips overflowing content without providing normal user scrolling. Auto provides scrolling when required.

Q3. What is overflow: clip?

Answer: It clips content at the overflow clip edge and does not create a scroll container.

Q4. What is margin collapse?

Answer: It is the behavior where certain adjoining vertical margins combine into one margin instead of being added together.

Q5. Do horizontal margins collapse?

Answer: No. Margin collapsing applies to certain adjoining vertical margins in normal block flow.

Q6. How can you prevent parent-child margin collapse?

Answer: Use a suitable separator such as padding or border, or establish a new block formatting context using display: flow-root.

Q7. Do margins between Flexbox items collapse?

Answer: No. Margins between flex items do not collapse.

Q8. How can you prevent horizontal image overflow?

Answer: Use max-width: 100% and height: auto.

Q9. What is the difference between offsetWidth and clientWidth?

Answer: offsetWidth includes padding and border, while clientWidth includes padding but excludes border and a rendered vertical scrollbar.

Q10. What does display: flow-root do?

Answer: It establishes a new block formatting context, which contains relevant floats and prevents certain margin-collapsing interactions across the boundary.

Q11. Why should overflow: hidden not be used everywhere?

Answer: It may clip dropdowns, shadows, focus indicators and other content that needs to extend beyond an element.

Q12. How do you make a wide table usable on mobile?

Answer: Wrap it in a container with overflow-x: auto.

22. Chapter 3 – Final Revision

  • CSS units define dimensions and spacing.
  • Relative units support flexible layouts.
  • The box model consists of content, padding, border and margin.
  • Content-box adds padding and border outside declared dimensions.
  • Border-box includes padding and border in declared dimensions.
  • Width and height control element dimensions.
  • Min and max properties constrain element sizing.
  • Margin creates external spacing.
  • Padding creates internal spacing.
  • Overflow controls content extending beyond an element's area.
  • Vertical margins can collapse in normal block flow.
  • Browser DevTools help diagnose actual dimensions and spacing.
