Lecture 4: Content Box, Border Box and Box Sizing

Chapter 3 – CSS Units, Box Model and Element Sizing

Learn how box-sizing controls element dimensions and prevents common layout calculation problems.

1. Learning Objectives

  • Understand the default content-box model.
  • Understand the border-box model.
  • Learn the CSS box-sizing property.
  • Calculate rendered element dimensions under both models.
  • Understand the universal box-sizing reset.
  • Apply box-sizing in responsive layouts.
  • Solve common box-sizing interview and coding problems.

2. What Is the box-sizing Property?

The CSS box-sizing property determines how the browser calculates the total dimensions of an element when width and height are specified.

Syntax

selector {
    box-sizing: content-box;
}

/* Or */

selector {
    box-sizing: border-box;
}

CSS provides two commonly used values:

  • content-box
  • border-box

The default value is content-box.

3. Understanding content-box

content-box is the default CSS box-sizing model.

When you specify width and height, those values apply only to the content area.

Padding and borders are added outside the declared content dimensions.

Syntax

.box {
    box-sizing: content-box;
    width: 300px;
    height: 150px;
    padding: 20px;
    border: 5px solid black;
}

Width Calculation

Content width = 300px

Left padding  = 20px
Right padding = 20px

Left border  = 5px
Right border = 5px

Total border-box width =
300 + 20 + 20 + 5 + 5

Total width = 350px

Height Calculation

Content height = 150px

Top padding    = 20px
Bottom padding = 20px

Top border    = 5px
Bottom border = 5px

Total border-box height =
150 + 20 + 20 + 5 + 5

Total height = 200px

Visual Example

content-box: declared width is 300px.

Content-box element

The rendered border-box width is 350px.

4. Understanding border-box

border-box changes the width and height calculation.

With this model, the specified width and height include:

  • Content
  • Padding
  • Border

Padding and borders are included inside the declared dimensions rather than added outside them.

Syntax

.box {
    box-sizing: border-box;
    width: 300px;
    height: 150px;
    padding: 20px;
    border: 5px solid black;
}

Width Calculation

Total border-box width = 300px

Left padding  = 20px
Right padding = 20px

Left border  = 5px
Right border = 5px

Content width =
300 - 20 - 20 - 5 - 5

Content width = 250px

Height Calculation

Total border-box height = 150px

Top padding    = 20px
Bottom padding = 20px

Top border    = 5px
Bottom border = 5px

Content height =
150 - 20 - 20 - 5 - 5

Content height = 100px

Visual Example

border-box: declared width is 300px.

Border-box element

The rendered border-box width remains 300px.

5. Difference Between content-box and border-box

Feature content-box border-box
Default value Yes No
Declared width includes content Yes Yes
Declared width includes padding No Yes
Declared width includes border No Yes
Padding increases border-box dimensions Yes No, provided the specified size is maintained
Border increases border-box dimensions Yes No, provided the specified size is maintained
Common layout usage Default browser behavior Commonly preferred for predictable layouts
Placement point: With border-box, the content area becomes smaller when padding or border is added while the specified width and height remain unchanged.

6. Practical Width Comparison

Consider the following CSS:

.box-one {
    width: 400px;
    padding: 30px;
    border: 10px solid black;
    box-sizing: content-box;
}

.box-two {
    width: 400px;
    padding: 30px;
    border: 10px solid black;
    box-sizing: border-box;
}

Calculation:

Measurement content-box border-box
Declared width 400px 400px

Content width 400px 320px
Total border-box width 480px 400px

7. Universal box-sizing Reset

In real-world frontend development, developers commonly use box-sizing: border-box to make element sizing more predictable.

Common CSS Reset

* {
    box-sizing: border-box;
}

This applies border-box sizing to all elements, including pseudo-elements when they are not separately overridden.

Recommended Inheritable Reset

html {
    box-sizing: border-box;
}

*,
*::before,
*::after {
    box-sizing: inherit;
}

In this approach:

  • The root element defines border-box.
  • All elements inherit the box-sizing value.
  • Pseudo-elements inherit the same sizing behavior.
  • Individual elements can override the value when required.
Practical recommendation: Use a consistent box-sizing strategy at the beginning of a project. The inheritable reset is a common and maintainable choice.

8. Practical Project Example – Responsive Cards

Suppose a card layout contains three cards, each intended to occupy one-third of the available row width.

Problem Without border-box

.card {
    width: 33.333%;
    padding: 20px;
    border: 2px solid #174ea6;
}

Under content-box, the padding and border increase each card's rendered width. Three cards may exceed the available row width.

Solution Using border-box

* {
    box-sizing: border-box;
}

.container {
    display: flex;
}

.card {
    width: 33.333%;
    padding: 20px;
    border: 2px solid #174ea6;
}

Now each card's border-box width is constrained to approximately one-third of the container width.

Complete Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Box Sizing Cards</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
            margin: 0;
            padding: 20px;
        }

        .container {
            display: flex;
            gap: 15px;
        }

        .card {
            flex: 1;
            min-width: 0;
            padding: 20px;
            border: 2px solid #174ea6;
            background: #eaf2ff;
            border-radius: 8px;
        }

        @media (max-width: 600px) {
            .container {
                flex-direction: column;
            }
        }
    </style>
</head>

<body>

    <h1>Responsive Card Layout</h1>

    <div class="container">
        <div class="card">
            <h2>HTML</h2>
            <p>Structure of web pages.</p>
        </div>

        <div class="card">
            <h2>CSS</h2>
            <p>Styling and layout of web pages.</p>
        </div>

        <div class="card">
            <h2>JavaScript</h2>
            <p>Behavior and interactivity.</p>
        </div>
    </div>

</body>
</html>

Expected Result

  • Three cards appear in a row on wider screens.
  • Each card receives an equal share of the available flex space.
  • Padding and borders are included in the card dimensions.
  • Cards stack vertically on smaller screens.

9. Common Mistakes and Debugging

  1. Assuming border-box includes margin: It includes padding and border, not margin.
  2. Forgetting the default value: The default box-sizing value is content-box.
  3. Applying border-box to only one component: Inconsistent sizing rules can make layouts difficult to maintain.
  4. Expecting content width to remain unchanged: In border-box, padding and border reduce the available content area.
  5. Ignoring the universal reset: Different components may unexpectedly calculate dimensions differently.

Browser DevTools Check

const box = document.querySelector(".card");

console.log(
    getComputedStyle(box).boxSizing
);

console.log(box.offsetWidth);

console.log(
    getComputedStyle(box).width
);

Use the Computed styles panel to verify the final box-sizing value and dimensions.

10. Placement Interview Questions and Answers

Q1. What is box-sizing in CSS?

Answer: It controls how the browser calculates an element's width and height.

Q2. What is the default value of box-sizing?

Answer: content-box.

Q3. What is content-box?

Answer: The declared width and height apply to the content area. Padding and border are added outside those dimensions.

Q4. What is border-box?

Answer: The declared width and height include content, padding and border.

Q5. Does border-box include margin?

Answer: No. Margin remains outside the border box.

Q6. What is the difference between content-box and border-box?

Answer: content-box adds padding and border to the declared dimensions, whereas border-box includes them within the declared dimensions.

Q7. Why do developers use universal box-sizing reset?

Answer: It makes width and height calculations more predictable and simplifies layout development.

Q8. What does box-sizing: inherit do?

Answer: It makes an element inherit the computed box-sizing value from its parent.

Q9. If width is 300px, padding is 20px on each side and border is 5px on each side, what is the content-box outer width?

Answer: 350px.

Q10. For the same dimensions, what is the content width under border-box?

Answer: 250px.

Q11. Which box-sizing model is commonly preferred for modern layouts?

Answer: border-box, because it makes declared dimensions include padding and borders.

Q12. Does changing box-sizing alter the margin?

Answer: No. Margin remains outside the border box in both models.

12. Quick Revision

  • box-sizing controls CSS dimension calculations.
  • content-box is the default model.
  • content-box excludes padding and border from declared width and height.
  • border-box includes padding and border in declared width and height.
  • Margin is excluded from both models' border-box dimensions.
  • Universal box-sizing reset improves consistency.
  • border-box is commonly used in responsive layouts.
  • Correct box sizing prevents many unexpected overflow problems.
