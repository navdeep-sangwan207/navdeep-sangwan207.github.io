Lecture 1: CSS Absolute and Relative Units

Chapter 3 – CSS Units, Box Model and Element Sizing

Learn how CSS measures dimensions and how to select appropriate units when building web interfaces.

1. Learning Objectives

  • Understand the purpose of CSS measurement units.
  • Differentiate absolute and relative CSS units.
  • Understand CSS pixels and physical device pixels.
  • Learn commonly used CSS absolute units.
  • Recognize when different units are appropriate.
  • Solve common CSS unit conversion and interview questions.

2. What Are CSS Units?

CSS units define the size, length, spacing and dimensions of elements on a web page.

They are used with properties such as:

width: 300px;
height: 200px;
margin: 20px;
padding: 1rem;
font-size: 16px;

A CSS dimension generally consists of a numeric value followed by a unit.

property: value + unit;

For example, in width: 300px;, 300 is the numeric value and px is the unit.

3. Classification of CSS Units

CSS units are commonly classified into two major categories:

Category Meaning Examples
Absolute units Use defined reference measurements that do not depend on the size of a parent element. px, cm, mm, in, pt, pc, Q
Relative units Derive their size from another measurement or context. %, em, rem, vw, vh

This chapter covers the fundamentals of both categories. Detailed treatment of percentages, em, rem and viewport units follows in Lecture 2.

4. Absolute CSS Units

Absolute units use defined CSS reference measurements. Their computed size does not change simply because the parent element becomes larger or smaller.

4.1 Pixel (px)

The pixel is the most commonly used CSS absolute unit.

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #333;
}

.heading {
    font-size: 24px;
}

In CSS, a pixel is a reference pixel. It is not necessarily equal to one physical pixel on a display.

CSS Pixel vs Physical Pixel

CSS Pixel Physical Pixel
A logical reference unit used by CSS. An actual hardware pixel on a display.
Used in CSS dimensions such as width and font-size. Part of the physical screen's pixel grid.
May map to multiple physical pixels. Represents a physical display element.

Device Pixel Ratio (DPR)

Device Pixel Ratio describes the relationship between physical device pixels and CSS pixels.

Device Pixel Ratio =
Physical Pixels / CSS Pixels

For example, if a device has a DPR of 2, one CSS pixel corresponds to approximately two physical pixels along each dimension.

Therefore, a square of 100 CSS pixels by 100 CSS pixels can occupy approximately 200 by 200 physical pixels on a DPR 2 display.

Placement point: Do not assume that 1 CSS px always equals 1 hardware pixel. CSS pixels are logical reference units.

4.2 Centimeter (cm)

The centimeter is a CSS absolute unit based on the CSS reference unit system.

.box {
    width: 5cm;
}

4.3 Millimeter (mm)

The millimeter is another absolute unit.

.box {
    width: 50mm;
}

4.4 Quarter-Millimeter (Q)

Q represents one quarter of a millimeter.

.box {
    width: 100Q;
}

4.5 Inch (in)

The inch is defined as 96 CSS pixels.

.box {
    width: 2in;
}

4.6 Point (pt)

The point is traditionally used in typography and print-related measurements.

.heading {
    font-size: 18pt;
}

4.7 Pica (pc)

A pica is a typographic measurement equal to 12 points.

.box {
    width: 10pc;
}

5. CSS Absolute Unit Conversion

CSS defines the following relationships between absolute units:

Conversion Relationship
Inch to pixel 1in = 96px
Inch to point 1in = 72pt
Pica to point 1pc = 12pt
Centimeter to pixel 1cm ≈ 37.8px
Millimeter to pixel 1mm ≈ 3.78px
Quarter-millimeter 1Q = 1/40cm

Example 1: Convert inches to pixels

Calculate the CSS pixel equivalent of 3 inches.

1in = 96px

3in = 3 × 96
    = 288px

Example 2: Convert points to pixels

Calculate the CSS pixel equivalent of 24pt.

1pt = 96 / 72px

24pt = 24 × (96 / 72)
     = 32px
Important: These are CSS reference-unit conversions. On screens, physical dimensions may not match the real-world centimeter or inch measurement because display scaling and device characteristics vary.

6. Relative CSS Units – Introduction

Relative units derive their size from another reference, such as the font size of an element, the root element's font size, a containing block or the viewport.

They are particularly useful when creating responsive and adaptable interfaces.

Unit Reference Typical use
% Depends on the relevant property's reference context. Fluid widths and proportions
em Font-size context of the element or inherited parent context, depending on the property. Component-relative sizing
rem Font size of the root element. Consistent typography and spacing
vw 1% of the viewport width. Viewport-relative layouts
vh 1% of the viewport height. Viewport-relative heights

These units will be explained with calculations and practical examples in the next lecture.

7. Practical Example – Absolute and Relative Units

The following example demonstrates different unit types in a simple web page.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>CSS Units Demo</title>

    <style>
        .pixel-box {
            width: 300px;
            padding: 15px;
            background-color: lightblue;
            border: 2px solid navy;
            margin-bottom: 15px;
        }

        .percentage-box {
            width: 80%;
            padding: 15px;
            background-color: lightgreen;
        }

        .root-text {
            font-size: 1.5rem;
        }
    </style>
</head>
<body>

    <h1>CSS Units Demonstration</h1>

    <div class="pixel-box">
        Fixed CSS pixel width
    </div>

    <div class="percentage-box">
        Percentage-based width
    </div>

    <p class="root-text">
        Text sized using rem
    </p>

</body>
</html>

Expected Result

  • The first box uses a fixed width of 300 CSS pixels.
  • The second box uses 80% of its containing block's width.
  • The paragraph uses a font size based on the root element's font size.
Practice: Save this example as units-demo.html and resize the browser window to observe the difference between fixed and percentage-based widths.

8. Choosing the Correct CSS Unit

Requirement Common choice Reason
Thin borders px Precise small measurements
Consistent typography rem Root-relative sizing
Fluid container width % Adapts to containing block
Viewport-relative sizing vw / vh Uses viewport dimensions
Component-relative sizing em Relates to font-size context
Print-oriented CSS in / cm / mm / pt Useful for print layouts

For modern responsive interfaces, developers commonly combine relative units with carefully selected pixel values rather than using only one unit throughout the stylesheet.

9. Common Mistakes

  1. Assuming CSS pixels are physical pixels: A CSS pixel is a logical reference unit.
  2. Using physical units for screen layouts: Centimeters and inches do not guarantee matching physical dimensions on every display.
  3. Using only px everywhere: Fixed values can make responsive adaptation harder.
  4. Confusing em and rem: They use different font-size reference contexts.
  5. Assuming every percentage uses parent width: The reference context depends on the CSS property.
  6. Ignoring viewport behavior: Viewport units can behave differently on mobile browsers, especially with dynamic browser interface areas.

10. Placement Interview Questions and Answers

Q1. What are CSS units?

Answer: CSS units specify measurements for properties such as width, height, font size, margin and padding.

Q2. What are absolute CSS units?

Answer: Absolute units use defined reference measurements. Examples include px, cm, mm, in, pt, pc and Q.

Q3. What are relative CSS units?

Answer: Relative units derive their size from another reference, such as a font size, containing block or viewport. Examples include %, em, rem, vw and vh.

Q4. Is one CSS pixel always equal to one physical pixel?

Answer: No. A CSS pixel is a logical reference unit. Its mapping to physical display pixels depends on device characteristics and scaling.

Q5. What is Device Pixel Ratio?

Answer: DPR is the ratio of physical device pixels to CSS pixels.

Q6. How many CSS pixels are there in one inch?

Answer: One CSS inch equals 96 CSS pixels.

Q7. How many points are there in one inch?

Answer: One inch equals 72 points.

Q8. What is the difference between em and rem?

Answer: em depends on the relevant element's font-size context, while rem is based on the root element's font size. Detailed calculations are covered in the next lecture.

Q9. Which units are commonly used in responsive web design?

Answer: %, rem, em, vw, vh and other viewport-relative units are commonly used, often together with px.

Q10. Should developers use cm and inches for normal web layouts?

Answer: Usually not. These units are more useful for print-oriented layouts. Screen layouts generally use CSS pixels and relative units.

  • One CSS inch equals 96 CSS pixels.
  • One inch equals 72 points.
