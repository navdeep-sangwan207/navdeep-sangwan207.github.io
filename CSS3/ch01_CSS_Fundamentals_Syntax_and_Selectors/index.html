Chapter Overview

CSS (Cascading Style Sheets) controls the presentation and layout of HTML documents. It is essential for building attractive, responsive and user-friendly websites.

This chapter covers stylesheet syntax, methods of applying CSS, selectors, selector combinations and combinators. Practical exercises will help you understand how CSS targets HTML elements.
