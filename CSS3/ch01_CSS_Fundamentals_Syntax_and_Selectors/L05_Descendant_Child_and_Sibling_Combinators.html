CSS3 Course | Chapter 1 | Lecture 05

Descendant, Child and Sibling Combinators

Understand how CSS selects elements through parent-child, ancestor-descendant and sibling relationships in the HTML DOM tree.

1. Learning Objectives

After completing this lecture, you will be able to:

  • Understand the relationship between HTML elements.
  • Explain parent, child, ancestor and descendant relationships.
  • Use the descendant combinator.
  • Use the child combinator.
  • Use the adjacent sibling combinator.
  • Use the general sibling combinator.
  • Differentiate between all four combinators.
  • Apply combinators to practical website components.
  • Debug incorrect selector relationships.

2. Understanding HTML Element Relationships

HTML documents are structured like a tree. Elements can have parent, child, ancestor, descendant and sibling relationships. CSS combinators use these relationships to select elements.

Example HTML Structure

<div class="container">

    <section class="course-section">

        <h2>CSS Course</h2>

        <div class="course-card">
            <h3>CSS Fundamentals</h3>
            <p>Learn CSS basics.</p>
        </div>

        <div class="course-card">
            <h3>CSS Layout</h3>
            <p>Learn Flexbox and Grid.</p>
        </div>

    </section>

</div>

Relationship Explanation

  • .container is the parent of .course-section.
  • .course-section is a child of .container.
  • .container is an ancestor of both course cards.
  • h3 is a descendant of .course-section.
  • The two .course-card elements are siblings.
  • The two course cards share the same parent.
Important: A direct child is also a descendant, but not every descendant is a direct child. This distinction is central to understanding CSS combinators.

3. Descendant Combinator (Space)

The descendant combinator selects elements that are nested anywhere inside another specified element. The relationship can be direct or through multiple levels.

Syntax

ancestor descendant {
    property: value;
}

A space between two selectors represents the descendant relationship.

Example

.container p {
    color: blue;
}

This selects every paragraph that is anywhere inside an element with the container class.

HTML

<div class="container">

    <p>Direct paragraph</p>

    <section>
        <p>Nested paragraph</p>

        <div>
            <p>Deeply nested paragraph</p>
        </div>
    </section>

</div>

<p>Outside paragraph</p>

Matching Result

  • Direct paragraph: selected.
  • Nested paragraph: selected.
  • Deeply nested paragraph: selected.
  • Outside paragraph: not selected.

Practical Applications

  • Styling all links inside a navigation container.
  • Styling paragraphs inside an article.
  • Applying styles to headings inside cards.
  • Targeting form labels and controls within a form section.

Real-World Example

.navigation a {
    color: white;
    text-decoration: none;
}

.article p {
    line-height: 1.7;
}

.course-card h3 {
    color: #174ea6;
}

4. Child Combinator (>)

The child combinator selects only elements that are direct children of the specified parent.

Syntax

parent > child {
    property: value;
}

Example

.container > p {
    color: red;
}

This selects paragraphs that are direct children of the container. Paragraphs nested inside another element are not selected by this rule.

HTML

<div class="container">

    <p>Direct paragraph</p>

    <section>
        <p>Nested paragraph</p>
    </section>

</div>

Matching Result

  • Direct paragraph: selected.
  • Nested paragraph: not selected.

Practical Applications

  • Styling only direct navigation items.
  • Controlling direct card content.
  • Targeting direct list items inside a list.
  • Applying layout rules to immediate children of a container.

Real-World Example

.navigation > ul {
    display: flex;
    gap: 20px;
}

.course-list > .course-card {
    margin-bottom: 15px;
}
Placement tip: Use the child combinator when the HTML hierarchy matters and you specifically want to avoid selecting deeply nested elements.

5. Adjacent Sibling Combinator (+)

The adjacent sibling combinator selects an element that immediately follows another specified element and shares the same parent.

Syntax

element1 + element2 {
    property: value;
}

The second selector is selected only when it is the next element sibling after the first selector.

Example

h2 + p {
    color: green;
}

This selects a paragraph that immediately follows an h2 element under the same parent.

HTML

<div>

    <h2>CSS Introduction</h2>

    <p>This paragraph immediately follows h2.</p>

    <p>This is the second paragraph.</p>

</div>

Matching Result

  • The first paragraph is selected.
  • The second paragraph is not selected.

Practical Applications

  • Adding spacing after headings.
  • Styling text immediately after a label or heading.
  • Creating consistent form layouts.
  • Styling a paragraph immediately following a section title.

Real-World Example

h2 + p {
    margin-top: 0;
}

label + input {
    margin-top: 5px;
}
The combinator follows element sibling order. Whitespace and comments in the HTML source do not become element siblings.

6. General Sibling Combinator (~)

The general sibling combinator selects all matching sibling elements that appear after a specified element and share the same parent.

Syntax

element1 ~ element2 {
    property: value;
}

Example

h2 ~ p {
    color: purple;
}

This selects every paragraph that comes after an h2 element among its siblings. The paragraphs do not have to be immediately adjacent to the h2.

HTML

<div>

    <h2>CSS Topics</h2>

    <p>First paragraph</p>

    <div>An intervening element</div>

    <p>Second paragraph</p>

    <p>Third paragraph</p>

</div>

Matching Result

  • First paragraph: selected.
  • Second paragraph: selected.
  • Third paragraph: selected.

Practical Applications

  • Styling all later paragraphs in a content group.
  • Applying styles to multiple elements following a heading.
  • Creating simple content-state styling patterns.

Real-World Example

h2 ~ p {
    line-height: 1.7;
}

.section-heading ~ .section-content {
    margin-top: 10px;
}

7. Comparison of All Four Combinators

Combinator Symbol Relationship Selection
Descendant Space Ancestor and descendant All matching descendants
Child > Parent and direct child Direct children only
Adjacent sibling + Immediate next sibling One next matching element sibling
General sibling ~ Following siblings All later matching element siblings

Quick Example

/* All descendants */
.container p { }

/* Direct children only */
.container > p { }

/* Immediately following sibling */
h2 + p { }

/* All following matching siblings */
h2 ~ p { }

8. Visualizing the Difference

Consider this HTML:

<div class="parent">

    <p class="item">Item A</p>

    <section>
        <p class="item">Item B</p>
    </section>

    <p class="item">Item C</p>

    <p class="item">Item D</p>

</div>
Selector Selected Elements
.parent .item Item A, B, C and D
.parent > .item Item A, C and D
section + .item Item C
section ~ .item Item C and D
Remember: Item B is a descendant of the parent, but it is not a direct child of the parent. Item C is the immediate element sibling after the section. Item D is a later sibling, but not the immediate next sibling.

9. Combining Multiple Combinators

CSS selectors can combine multiple relationships to target elements several levels deep.

Example 1: Nested Descendant

.container .card p {
    color: blue;
}

Selects paragraphs that are descendants of a card, where the card is a descendant of the container.

Example 2: Parent and Child Relationship

.navigation > ul > li {
    display: inline-block;
}

Selects list items that are direct children of a ul which is itself a direct child of the navigation element.

Example 3: Descendant and Adjacent Sibling

.article h2 + p {
    font-weight: bold;
}

Selects paragraphs immediately following h2 elements inside the article.

Example 4: Child and General Sibling

.course-list > h2 ~ .course-card {
    border: 1px solid #ccc;
}

Selects course-card siblings appearing after an h2 that is a direct child of course-list.

10. Practical Example: Course Navigation Menu

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Navigation Combinators</title>

    <style>
        body {
            font-family: Arial, sans-serif;
        }

        .navigation > ul {
            display: flex;
            gap: 20px;
            list-style: none;
            padding: 15px;
            background: #174ea6;
        }

        .navigation a {
            color: white;
            text-decoration: none;
        }

        .navigation li + li {
            border-left: 1px solid white;
            padding-left: 15px;
        }

        .course-menu p {
            color: #174ea6;
        }

        .course-menu > p {
            font-weight: bold;
        }
    </style>
</head>

<body>

    <nav class="navigation">
        <ul>
            <li><a href="#">Home</a></li>
            <li><a href="#">Courses</a></li>
            <li><a href="#">Projects</a></li>
            <li><a href="#">Contact</a></li>
        </ul>
    </nav>

    <div class="course-menu">

        <p>Available Courses</p>

        <section>
            <p>C Programming</p>
            <p>C++ Programming</p>
        </section>

    </div>

</body>
</html>

Expected Result

  • The navigation list appears horizontally.
  • Navigation links are white.
  • Adjacent navigation items receive a left border.
  • All paragraphs inside course-menu receive blue text.
  • The direct paragraph inside course-menu appears bold.

11. Practical Example: Article Content

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Article Combinator Example</title>

    <style>
        .article {
            max-width: 700px;
            margin: 30px auto;
            font-family: Arial, sans-serif;
        }

        .article > h1 {
            color: #174ea6;
        }

        .article h2 {
            margin-top: 25px;
        }

        .article h2 + p {
            font-weight: bold;
        }

        .article h2 ~ p {
            line-height: 1.7;
        }

        .article > section > p {
            color: #444;
        }
    </style>
</head>

<body>

    <article class="article">

        <h1>Learning CSS</h1>

        <section>

            <h2>Introduction</h2>

            <p>
                CSS controls the presentation of web pages.
            </p>

            <p>
                It is used to create responsive layouts.
            </p>

        </section>

    </article>

</body>
</html>

Expected Result

  • The main article heading is blue.
  • The paragraph immediately after the section heading is bold.
  • Paragraphs following the section heading receive line-height.
  • Direct paragraphs inside the article's section receive gray text.

12. Common Mistakes and Debugging

Mistake 1: Confusing Descendant and Child

/* All nested paragraphs */
.container p { }

/* Direct paragraphs only */
.container > p { }

Mistake 2: Confusing Adjacent and General Siblings

/* Immediate next matching sibling */
h2 + p { }

/* All later matching siblings */
h2 ~ p { }

Mistake 3: Forgetting the Same-Parent Requirement

<div>
    <h2>Heading</h2>
    <section>
        <p>Nested paragraph</p>
    </section>
</div>

The selector h2 + p does not match the nested paragraph because the paragraph is not a sibling of the h2.

Mistake 4: Assuming a General Sibling Selects Earlier Elements

h2 ~ p {
    color: red;
}

This selects matching paragraphs that appear after the h2. It does not select paragraphs that appear before it.

Mistake 5: Writing an Unnecessarily Long Selector

body main section div article p {
    color: blue;
}

Prefer a simpler and more maintainable class-based selector when it can target the same component.

Debugging Procedure

  1. Open Developer Tools using F12.
  2. Inspect the target HTML element.
  3. Check its parent and sibling elements.
  4. Verify whether the required relationship exists.
  5. Test the selector in the Styles panel.
  6. Check whether another CSS declaration overrides the rule.
Debugging tip: When a combinator does not match, inspect the actual DOM hierarchy. Do not assume that visual proximity on the webpage means two elements are siblings or parent and child.

13. Placement Interview Questions and Answers

Q1. What is a CSS combinator?

A CSS combinator defines a relationship between selectors, allowing elements to be selected according to their position in the document tree.

Q2. What are the four main CSS combinators?

Descendant (space), child (>), adjacent sibling (+) and general sibling (~).

Q3. What is the difference between descendant and child combinators?

Descendant selects matching elements at any nesting depth. Child selects only direct children.

Q4. What is the difference between + and ~?

The adjacent sibling combinator selects the immediately following matching element sibling. The general sibling combinator selects all matching following element siblings.

Q5. Do sibling combinators require elements to share the same parent?

Yes. Both adjacent and general sibling relationships require the selected elements to have the same parent.

Q6. Does the descendant combinator select direct children?

Yes. Direct children are also descendants.

Q7. Does the child combinator select grandchildren?

No. It selects only direct children.

Q8. Can sibling combinators select elements that appear before the reference element?

No. The + and ~ combinators select following siblings.

Q9. What does .container > p select?

Paragraph elements that are direct children of an element with the container class.

Q10. What does h2 + p select?

A paragraph that immediately follows an h2 as an element sibling.

Q11. What does h2 ~ p select?

All paragraph element siblings that appear after an h2 under the same parent.

Q12. Can multiple combinators be used in one selector?

Yes. For example, .container > section p combines child and descendant relationships.

Q13. Do sibling combinators consider text nodes?

No. CSS sibling combinators operate on element siblings. Text nodes and comments do not become matching element siblings.

Q14. How would you style only direct list items inside a navigation list?

Use .navigation > ul > li when the HTML hierarchy follows that structure.

14. Practical Exercises

Exercise 1: Descendant Selector

  • Create a container with paragraphs at different nesting levels.
  • Use a descendant selector to style all paragraphs inside it.
  • Add a paragraph outside the container and verify it is unaffected.

Exercise 2: Child Selector

  • Create a navigation container with a direct ul child.
  • Add a nested ul inside one list item.
  • Use a child selector to style only direct list items.

Exercise 3: Adjacent Sibling

  • Create multiple h2 and paragraph pairs.
  • Use h2 + p to style only the immediately following paragraph.
  • Insert a div between a heading and paragraph and observe the result.

Exercise 4: General Sibling

  • Create a heading followed by several paragraphs.
  • Insert another element between two paragraphs.
  • Use h2 ~ p to select all later paragraph siblings.

Exercise 5: Combined Combinators

  • Create a course section containing several course cards.
  • Use descendant and child combinators to style different levels.
  • Use adjacent sibling to add spacing after card headings.
  • Use general sibling to style later card elements.

Exercise 6: Placement-Oriented Mini Assignment

Build a responsive-style navigation and course listing structure using all four combinators. Include:

  • A navigation list with nested submenus.
  • A course section with multiple cards.
  • Heading and paragraph relationships.
  • At least one direct-child selector.
  • At least one adjacent sibling selector.
  • At least one general sibling selector.
