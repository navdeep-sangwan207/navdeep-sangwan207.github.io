Chapter 1 – CSS Fundamentals, Syntax and Selectors

After completing this lecture, you should be able to:

2. What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe how HTML elements should be displayed in a web browser.

HTML defines the structure and content of a webpage, whereas CSS controls its visual presentation and layout.

Example: HTML Without CSS

<!DOCTYPE html> <html> <head> <title>My Webpage</title> </head> <body> <h1>Welcome to My Website</h1> <p>This is my first webpage.</p> </body> </html>

The browser displays the content using its default styling because no custom CSS has been applied.

Example: HTML With CSS

<!DOCTYPE html> <html> <head> <title>My Webpage</title> <style> body { background-color: #f0f4ff; font-family: Arial, sans-serif; } h1 { color: blue; text-align: center; } p { color: #333333; font-size: 18px; } </style> </head> <body> <h1>Welcome to My Website</h1> <p>This is my first webpage.</p> </body> </html>

CSS changes the background, font, heading color, text alignment and paragraph size without changing the underlying HTML content.

Placement concept: HTML provides structure, CSS provides presentation, and JavaScript provides behavior and interactivity.

3. Why is CSS Important?

  • Visual design: Controls colors, fonts, borders and backgrounds.
  • Layout: Arranges elements using Flexbox, Grid and positioning.
  • Responsiveness: Adapts webpages to different screen sizes.
  • Consistency: Applies common styles across multiple pages.
  • Maintainability: Separates presentation from HTML structure.
  • User experience: Improves readability, navigation and interface appearance.

4. Basic CSS Syntax

A CSS rule consists of a selector followed by a declaration block. The declaration block contains one or more declarations.

selector { property: value; }

Example

h1 { color: blue; font-size: 32px; text-align: center; }

Here is the meaning of each part:

Component Example Purpose
Selector h1 Selects the HTML heading elements.
Declaration block { ... } Contains CSS declarations.
Property color Specifies what aspect to style.
Value blue Specifies the selected property's setting.
Declaration color: blue; Combines a property and its value.

5. Understanding CSS Declarations

A CSS declaration is written using a property, a colon, a value and usually a terminating semicolon.

p { color: green; font-size: 16px; background-color: lightyellow; margin: 10px; }

The selector p targets paragraph elements. Four declarations are applied to each matching paragraph.

Common CSS Properties

Property Purpose Example
color Sets text color. color: red;
background-color Sets background color. background-color: yellow;
font-size Sets text size. font-size: 20px;
font-family Sets the font family. font-family: Arial;
text-align Aligns inline content within a block. text-align: center;
margin Sets space outside an element's border. margin: 10px;
padding Sets space inside an element's border. padding: 15px;
border Sets an element's border. border: 1px solid black;

6. Multiple CSS Rules

A stylesheet can contain multiple CSS rules. Each rule targets one or more HTML elements.

h1 { color: navy; font-size: 30px; } p { color: #444444; line-height: 1.6; } button { background-color: blue; color: white; padding: 10px 20px; }

In this example, separate rules style headings, paragraphs and buttons.

7. CSS Comments

Comments are used to explain code or temporarily disable declarations. Browsers do not apply comment contents as CSS instructions.

/* This is a CSS comment */ h1 { color: blue; } /* This is a multiline comment */ p { /* Set paragraph text size */ font-size: 16px; }
Important: CSS comments use /* ... */. The HTML comment syntax <!-- ... --> should not be used as a CSS comment inside a stylesheet.

8. CSS Syntax Rules and Common Mistakes

Incorrect CSS Correct CSS
color = red; color: red;
font-size 20px; font-size: 20px;
color: red color: red;
h1 ( color: blue; ) h1 { color: blue; }

Common errors include:

  • Using an equals sign instead of a colon.
  • Forgetting the opening or closing curly brace.
  • Writing an invalid property name.
  • Using an invalid property value.
  • Missing semicolons, which can cause declarations to merge incorrectly.
  • Using the wrong CSS unit or omitting a required unit.
A browser generally ignores an invalid CSS declaration and continues parsing subsequent valid declarations. This is why a syntax error may affect only part of a stylesheet.

9. Practical Example: Styling a Profile Card

The following example combines HTML structure and CSS styling to create a simple profile card.

Complete HTML and CSS Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Profile Card</title> <style> body { font-family: Arial, sans-serif; background-color: #eef2f7; padding: 30px; } .profile-card { max-width: 350px; background-color: white; padding: 25px; margin: 20px auto; border: 1px solid #dddddd; border-radius: 10px; text-align: center; } .profile-card h2 { color: #174ea6; } .profile-card p { color: #555555; line-height: 1.6; } .profile-card button { background-color: #174ea6; color: white; border: none; padding: 10px 20px; border-radius: 5px; } </style> </head> <body> <div class="profile-card"> <h2>Web Developer</h2> <p> Learning HTML, CSS and JavaScript to build professional websites. </p> <button>View Profile</button> </div> </body> </html>

Expected Result

  • A light-colored webpage background.
  • A white profile card centered horizontally.
  • A blue heading and readable paragraph.
  • A blue button with white text.
  • Rounded corners and spacing around the card content.

11. Common Interview Questions

Q1. What is CSS?

CSS is a stylesheet language used to control the presentation, formatting and layout of HTML documents.

Q2. What does CSS stand for?

Cascading Style Sheets.

Q3. What is a CSS rule?

A CSS rule consists of a selector and a declaration block containing one or more declarations.

Q4. What is a CSS declaration?

A declaration is a property-value pair, such as color: blue;.

Q5. What is the difference between a property and a value?

A property identifies what aspect is being styled, while a value specifies how that property is configured.

Q6. What is the purpose of a CSS selector?

A selector identifies the HTML elements to which a CSS rule should apply.

Q7. Can one CSS rule contain multiple declarations?

Yes. Multiple declarations can be written inside the same declaration block.

Q8. How are CSS comments written?

CSS comments are written between /* and */.

13. Lecture Summary

  • CSS controls the presentation of HTML documents.
  • A CSS rule consists of a selector and declaration block.
  • A declaration contains a property and a value.
  • Multiple declarations can be included in one rule.
  • CSS comments help document stylesheets.
  • Correct syntax is essential for predictable styling.
