Lecture 2: Inline, Internal and External CSS

Chapter 1 – CSS Fundamentals, Syntax and Selectors

1. Learning Objectives

After completing this lecture, you should be able to:

  • Identify the three methods of applying CSS.
  • Write inline CSS using the HTML style attribute.
  • Write internal CSS using the style element.
  • Connect external stylesheets using the link element.
  • Compare the advantages and disadvantages of each method.
  • Understand how CSS rules from different sources interact.
  • Choose an appropriate stylesheet method for a project.

2. Methods of Applying CSS

CSS can be applied to HTML documents in three commonly taught ways:

  1. Inline CSS
  2. Internal CSS
  3. External CSS

All three methods can control the appearance of HTML elements, but they differ in where the CSS is written and how easily it can be maintained and reused.

3. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

Syntax

<element style="property: value;"> Content </element>

Example

<!DOCTYPE html> <html lang="en"> <head> <title>Inline CSS Example</title> </head> <body> <h1 style="color: blue; text-align: center;"> Welcome to CSS </h1> <p style="font-size: 18px; color: green;"> This paragraph uses inline CSS. </p> </body> </html>

Explanation

  • The style attribute contains CSS declarations.
  • The heading receives blue text and centered alignment.
  • The paragraph receives green text and an 18px font size.
  • The styles apply directly to the elements carrying those attributes.

Advantages of Inline CSS

  • Quick for testing a small style change.
  • Useful for isolated elements in limited situations.
  • No separate stylesheet is required for the declarations.

Disadvantages of Inline CSS

  • Styles are difficult to reuse across many elements.
  • Mixes presentation with HTML structure.
  • Can make HTML difficult to read and maintain.
  • Does not support normal selector-based styling inside the attribute.
  • Can make large projects harder to manage.
Practical usage: Inline CSS is generally avoided for normal application-wide styling. Prefer reusable stylesheets for maintainable projects.

4. Internal CSS

Internal CSS is written inside a <style> element, usually within the <head> section of an HTML document.

Syntax

<head> <style> selector { property: value; } </style> </head>

Example

<!DOCTYPE html> <html lang="en"> <head> <title>Internal CSS Example</title> <style> body { background-color: #f0f4ff; font-family: Arial, sans-serif; } h1 { color: navy; text-align: center; } p { color: #444444; font-size: 18px; } </style> </head> <body> <h1>Internal CSS</h1> <p> This webpage uses an internal stylesheet. </p> </body> </html>

Explanation

  • The CSS is placed inside the HTML document.
  • The body receives a background color and font family.
  • The heading is styled using an element selector.
  • The paragraph receives a text color and font size.

Advantages of Internal CSS

  • Allows multiple CSS rules in one location.
  • Supports selectors, combinators and media queries.
  • Useful for a single-page demonstration or small standalone page.
  • Does not require a separate CSS file.

Disadvantages of Internal CSS

  • Styles are normally limited to that HTML document.
  • Repeated styles across pages create duplication.
  • Large internal stylesheets make HTML documents difficult to maintain.
  • CSS and HTML presentation remain in the same file.

5. External CSS

External CSS is written in a separate file with the .css extension. The HTML document connects to that file using the <link> element.

Example Folder Structure

my-website/ │ ├── index.html └── css/ └── style.css

Step 1: Create the HTML File

File: index.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>External CSS Example</title> <link rel="stylesheet" href="css/style.css"> </head> <body> <h1>External CSS</h1> <p> This webpage uses an external stylesheet. </p> <button>Click Me</button> </body> </html>

Step 2: Create the CSS File

File: css/style.css

body { background-color: #f0f4ff; font-family: Arial, sans-serif; padding: 20px; } h1 { color: #174ea6; text-align: center; } p { color: #444444; font-size: 18px; } button { background-color: #174ea6; color: white; border: none; padding: 10px 20px; border-radius: 5px; }

Explanation

  • The stylesheet is stored separately from the HTML file.
  • The link element connects the HTML document to the stylesheet.
  • The href attribute specifies the stylesheet's relative or absolute URL.
  • The rel attribute identifies the linked resource as a stylesheet.
  • The same CSS file can be linked to multiple HTML pages.

Advantages of External CSS

  • Separates presentation from HTML structure.
  • Allows styles to be reused across multiple pages.
  • Makes larger projects easier to maintain.
  • Allows browsers to cache the stylesheet for reuse.
  • Supports consistent styling across an entire website.

Disadvantages of External CSS

  • Requires a separate stylesheet file.
  • An incorrect file path can prevent styles from loading.
  • A stylesheet may need to be downloaded before its styles are available.
Industry practice: External CSS is generally the preferred method for organizing styles in multi-page websites and maintainable frontend projects.

7. Understanding CSS Priority and Conflicts

A common beginner assumption is that inline CSS always wins, internal CSS comes second and external CSS comes third. This is an oversimplification.

The browser determines the winning declaration using the CSS cascade. Origin, importance, cascade layers, specificity and source order all matter.

Example: Inline Style and Stylesheet Rule

<!DOCTYPE html> <html lang="en"> <head> <style> p { color: blue; } </style> </head> <body> <p style="color: red;"> Understanding CSS priority </p> </body> </html>

Expected result: The paragraph text is red.

The inline declaration has greater priority than the normal author stylesheet rule in this example.

Example: External CSS with Important Declaration

HTML:

<link rel="stylesheet" href="style.css"> <p style="color: red;"> CSS priority example </p>

External stylesheet:

p { color: blue !important; }

Expected result: The paragraph is blue. An important author declaration takes precedence over a normal inline author declaration.

Do not memorize a fixed priority order of inline, internal and external CSS. Learn the cascade and specificity rules in Chapter 2.

8. External CSS File Path Basics

The href value in a link element must correctly identify the stylesheet location relative to the HTML document.

Path Meaning
style.css CSS file in the same directory.
css/style.css CSS file inside a child directory named css.
../style.css CSS file in the parent directory.
../../style.css CSS file two directory levels above.

Example: GitHub Pages Course Structure

NS-Learning-Hub/ │ ├── style.css │ └── CSS3/ ├── css3.html │ └── ch01_CSS_Fundamentals_Syntax_and_Selectors/ ├── index.html └── L01_Introduction_to_CSS_and_Stylesheet_Syntax.html

From css3.html, the correct stylesheet path is:

<link rel="stylesheet" href="../style.css">

From the chapter index and lecture pages, the correct path is:

<link rel="stylesheet" href="../../style.css">
Relative paths depend on the location of the HTML file, not the location of the browser's address bar.

9. Practical Project: Three CSS Methods

Create a small webpage that demonstrates all three stylesheet application methods.

Complete HTML Program

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>CSS Methods Demonstration</title> <link rel="stylesheet" href="style.css"> <style> h1 { color: navy; text-align: center; } .internal-text { background-color: #eaf2ff; padding: 12px; } </style> </head> <body> <h1>CSS Application Methods</h1> <p class="internal-text"> This paragraph uses internal CSS. </p> <p style="color: green; font-weight: bold;"> This paragraph uses inline CSS. </p> <div class="external-box"> This section uses external CSS. </div> </body> </html>

External Stylesheet

File: style.css

body { font-family: Arial, sans-serif; background-color: #f5f7fb; padding: 25px; } .external-box { background-color: #174ea6; color: white; padding: 18px; border-radius: 8px; margin-top: 15px; }

Expected Result

  • A centered navy heading.
  • A light-blue paragraph using internal CSS.
  • A green bold paragraph using inline CSS.
  • A blue section with white text using external CSS.

10. Common Mistakes and Debugging

Problem 1: External stylesheet is not loading

Possible causes:

  • Incorrect href path.
  • Incorrect filename or file extension.
  • Incorrect letter casing in a GitHub Pages path.
  • Stylesheet file not uploaded to the repository.

Problem 2: CSS rules are not affecting the element

Check the following:

  • Whether the selector matches the intended HTML element.
  • Whether another declaration overrides the rule.
  • Whether the CSS declaration is valid.
  • Whether the stylesheet has loaded successfully.

Using Browser Developer Tools

  1. Open the webpage in Chrome.
  2. Right-click the element and select Inspect.
  3. Open the Styles panel.
  4. Inspect the matched CSS declarations.
  5. Check crossed-out declarations and their winning rules.
  6. Use the Network panel to check whether the stylesheet loaded.

11. Common Interview Questions

Q1. What are the three ways to apply CSS?

Inline CSS, internal CSS and external CSS.

Q2. Which CSS method is preferred for large projects?

External CSS, because it improves reuse, separation of concerns and maintainability.

Q3. Which HTML element connects an external stylesheet?

The <link> element, usually placed inside the HTML document's head.

Q4. What is the purpose of the rel attribute?

It describes the relationship between the current document and the linked resource. For an external stylesheet, its value is stylesheet.

Q5. What is the purpose of the href attribute?

It specifies the URL or path of the external stylesheet.

Q6. Can one external CSS file be used by multiple HTML pages?

Yes. Multiple HTML documents can link to the same stylesheet.

Q7. Does inline CSS always override external CSS?

No. A normal inline declaration generally overrides normal author stylesheet declarations, but important declarations and the complete cascade determine the final result.

Q8. What happens if the external CSS path is incorrect?

The browser cannot load the intended stylesheet, so its styles will not be applied.

13. Lecture Summary

  • Inline CSS uses the HTML style attribute.
  • Internal CSS uses the style element.
  • External CSS uses a separate .css file.
  • External CSS is preferred for maintainable multi-page projects.
  • The link element connects an HTML page to an external stylesheet.
  • Correct relative paths are essential for loading CSS.
  • The CSS cascade, not a simplistic fixed ordering of methods, determines the winning declaration.
