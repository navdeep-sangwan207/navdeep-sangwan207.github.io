CSS3 Course | Chapter 1 | Lecture 04

Attribute, Grouping and Compound Selectors

Learn how to target HTML elements using attributes, combine selectors efficiently and write precise CSS rules for real-world frontend interfaces.

1. Learning Objectives

After completing this lecture, you will be able to:

  • Understand CSS attribute selectors.
  • Select elements based on attribute presence.
  • Match exact attribute values.
  • Use partial and prefix/suffix attribute matching.
  • Group multiple selectors into one CSS rule.
  • Understand compound selectors.
  • Combine element, class, ID and attribute selectors.
  • Debug selector-matching problems.

2. Attribute Selectors: Introduction

An attribute selector targets HTML elements based on the presence or value of an HTML attribute.

General syntax:

[attribute] {
    property: value;
}

Example HTML:

<input type="text">
<input type="password">
<input type="email">
<a href="https://example.com">Visit Website</a>

Attribute selectors are useful when you want to style elements according to their HTML attributes without adding extra classes to every element.

3. Attribute Presence Selector

This selector matches every element that contains a specified attribute, regardless of its value.

Syntax

[attribute-name] {
    property: value;
}

Example

input[required] {
    border: 2px solid red;
}

a[target] {
    color: green;
}

HTML

<input type="text" required>

<input type="email">

<a href="https://example.com" target="_blank">
    External Website
</a>

<a href="about.html">
    About Us
</a>

Explanation

  • input[required] selects inputs having the required attribute.
  • a[target] selects links having the target attribute.
  • Elements without those attributes are not selected by these rules.

Practical Applications

  • Highlighting required form fields.
  • Styling links that open in new tabs.
  • Targeting elements with accessibility attributes.

4. Exact Attribute Value Selector

The exact value selector matches an element when its specified attribute has exactly the given value.

Syntax

[attribute="value"] {
    property: value;
}

Example

input[type="text"] {
    background-color: #f0f7ff;
}

input[type="password"] {
    border: 2px solid orange;
}

a[target="_blank"] {
    color: darkgreen;
}

HTML

<input type="text" placeholder="Username">

<input type="password" placeholder="Password">

<input type="email" placeholder="Email">

<a href="https://example.com" target="_blank">
    Open Website
</a>

The first rule matches only text inputs. The second matches password inputs. The third rule matches links whose target value is exactly _blank.

5. Attribute Value Matching Operators

CSS provides several operators for matching complete or partial attribute values.

Operator Meaning Example
= Exact value match [type="email"]
~= One word in a whitespace-separated list [class~="active"]
|= Exact value or value followed by a hyphen [lang|="en"]
^= Value starts with specified text [href^="https"]
$= Value ends with specified text [href$=".pdf"]
*= Value contains specified text [href*="github"]

5.1 Word Matching: ~=

[class~="active"] {
    color: green;
}
<div class="menu active">Active Menu</div>

<div class="menu inactive">Inactive Menu</div>

The selector matches an attribute value containing active as a complete whitespace-separated word. It does not match inactive as that is a different word.

5.2 Hyphenated Value Matching: |=

[lang|="en"] {
    font-family: Arial, sans-serif;
}
<p lang="en">English content</p>

<p lang="en-US">US English content</p>

<p lang="fr">French content</p>

The selector matches en and values beginning with en-, such as en-US.

5.3 Starts With: ^=

a[href^="https"] {
    color: green;
}

Selects links whose href attribute starts with https.

5.4 Ends With: $=

a[href$=".pdf"] {
    color: red;
}

Selects links whose href attribute ends with .pdf.

5.5 Contains: *=

a[href*="github"] {
    font-weight: bold;
}

Selects links whose href attribute contains the text github anywhere within its value.

Placement tip: Attribute selectors are especially useful for form controls, external links, file links and HTML elements that already expose useful attributes.

6. Practical Attribute Selector Example

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Attribute Selector Example</title>

    <style>
        input[required] {
            border: 2px solid red;
        }

        input[type="email"] {
            background-color: #eaf3ff;
        }

        a[href$=".pdf"] {
            color: red;
            font-weight: bold;
        }

        a[href^="https"] {
            text-decoration: underline;
        }
    </style>
</head>

<body>

    <h2>Registration Form</h2>

    <input type="text" placeholder="Name" required>
    <input type="email" placeholder="Email">
    <input type="password" placeholder="Password" required>

    <h2>Resources</h2>

    <a href="https://example.com">External Website</a>

    <br>

    <a href="notes.pdf">Download Notes</a>

</body>
</html>

Expected Result

  • Required fields have red borders.
  • The email field has a light-blue background.
  • The PDF link appears red and bold.
  • The HTTPS link receives an underline.

7. Grouping Selectors

Grouping selectors allow multiple selectors to share the same CSS declarations. Separate the selectors with commas.

Syntax

selector1,
selector2,
selector3 {
    property: value;
}

Without Grouping

h1 {
    color: blue;
}

h2 {
    color: blue;
}

p {
    color: blue;
}

With Grouping

h1,
h2,
p {
    color: blue;
}

Both examples apply the same color to the selected elements. Grouping reduces repetition and makes stylesheets easier to maintain.

Practical Example

h1,
h2,
h3 {
    font-family: Arial, sans-serif;
    color: #174ea6;
}

input,
textarea,
select {
    width: 100%;
    padding: 10px;
    border: 1px solid #ccc;
}
Important: A comma separates independent selectors. Each selector in the group is matched independently.

8. Compound Selectors

A compound selector combines multiple simple selectors without spaces to target an element that satisfies all the conditions.

Example 1: Element and Class

p.highlight {
    color: red;
}

This selects paragraph elements that have the highlight class. 

<p class="highlight">Selected paragraph</p>

<h2 class="highlight">Not selected by p.highlight</h2>

<p>Normal paragraph</p>

Example 2: Multiple Classes

.card.featured {
    border: 2px solid blue;
}

This selects an element that has both card and featured classes.

Example 3: ID and Class

#main-header.sticky {
    position: sticky;
    top: 0;
}

This selects an element with ID main-header that also has the sticky class.

Example 4: Element and Attribute

input[type="email"] {
    border-color: blue;
}

This selects input elements whose type attribute is exactly email.

Example 5: Multiple Conditions

button.primary.large {
    padding: 14px 24px;
    font-size: 18px;
}

The selector requires a button element with both the primary and large classes.

9. Compound Selector vs Descendant Selector

This distinction is frequently tested in frontend interviews.

Selector Meaning
.card.featured One element having both classes
.card .featured A featured descendant inside a card
p.notice A paragraph having the notice class
p .notice An element with notice class inside a paragraph

Example HTML

<div class="card featured">
    Featured card
</div>

<div class="card">
    <p class="featured">
        Featured content inside a card
    </p>
</div>

The first element matches .card.featured. The paragraph inside the second element matches .card .featured.

Do not confuse a space with a comma. A space represents a descendant relationship; a comma groups independent selectors.

10. Combining Attribute and Class Selectors

Attribute selectors can be combined with classes, IDs and element selectors to create more precise rules.

Examples

input.required-field[required] {
    border: 2px solid red;
}

a.external-link[target="_blank"] {
    color: green;
}

button.primary[type="submit"] {
    background-color: blue;
}

#login-form input[type="password"] {
    background-color: #f5f5f5;
}

These selectors target:

  • Required inputs with the required-field class.
  • External links with the external-link class and target value.
  • Submit buttons with the primary class.
  • Password inputs inside the element with ID login-form.

11. Practical Example: Registration Form

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Registration Form</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
            background: #f4f7fb;
            padding: 20px;
        }

        h1,
        h2 {
            color: #174ea6;
        }

        .form-container {
            max-width: 450px;
            background: white;
            padding: 24px;
            border-radius: 10px;
        }

        input,
        select {
            width: 100%;
            padding: 10px;
            margin: 8px 0 15px;
        }

        input[required] {
            border: 1px solid red;
        }

        input[type="email"] {
            background: #eaf3ff;
        }

        .primary-button {
            background: #174ea6;
            color: white;
            border: 0;
            padding: 12px;
            cursor: pointer;
        }

        button.primary-button[type="submit"] {
            width: 100%;
        }

        .form-container .help-text {
            color: #666;
            font-size: 13px;
        }
    </style>
</head>

<body>

    <div class="form-container">

        <h1>Create Account</h1>

        <p class="help-text">
            Enter your details to register.
        </p>

        <form>

            <label for="name">Name</label>
            <input id="name" type="text" required>

            <label for="email">Email</label>
            <input id="email" type="email" required>

            <label for="password">Password</label>
            <input id="password" type="password" required>

            <button
                class="primary-button"
                type="submit">
                Register
            </button>

        </form>

    </div>

</body>
</html>

Expected Result

  • A centered registration form appears on a light background.
  • All form controls share consistent dimensions.
  • Required fields receive red borders.
  • The email input receives a light-blue background.
  • The submit button uses the primary blue styling.
  • The help text appears smaller and gray.

12. Selector Matching: Practical Reference

HTML Selector Match?
<p class="note"> p.note Yes
<h2 class="note"> p.note No
<div class="card active"> .card.active Yes
<div class="card"> .card.active No
<input type="email"> input[type="email"] Yes
<a href="notes.pdf"> a[href$=".pdf"] Yes
<a href="notes.html"> a[href$=".pdf"] No

13. Common Mistakes and Debugging

Mistake 1: Using a Space Instead of a Comma

/* Descendant selector */
h1 p {
    color: red;
}

/* Grouped selectors */
h1, p {
    color: red;
}

The first selector targets paragraphs inside h1 elements. The second independently targets h1 and p elements.

Mistake 2: Incorrect Compound Selector

/* Same element has both classes */
.card.active {
    color: green;
}

/* Active descendant inside card */
.card .active {
    color: green;
}

Mistake 3: Incorrect Attribute Operator

/* Exact value */
input[type="email"] {
    color: blue;
}

/* Attribute presence */
input[type] {
    color: blue;
}

These selectors have different matching conditions.

Mistake 4: Missing Quotes Around Attribute Values

/* Recommended */
input[type="email"] {
    border-color: blue;
}

Quoting attribute values is a good practice, especially when values contain special characters or spaces.

Mistake 5: Overusing Complex Selectors

/* Difficult to maintain */
body main section div.card article h2.title {
    color: blue;
}

/* Often easier to maintain */
.card-title {
    color: blue;
}

Prefer clear, maintainable selectors over unnecessarily long selector chains.

Debugging with Developer Tools

  1. Open Chrome Developer Tools using F12.
  2. Select an element in the Elements panel.
  3. Inspect its attributes and class names.
  4. Check whether the expected selector appears in the Styles panel.
  5. Verify the selector's matching conditions.
  6. Temporarily change the selector and observe the result.

14. Placement Interview Questions and Answers

Q1. What is an attribute selector in CSS?

It selects HTML elements based on the presence or value of their attributes.

Q2. How do you select all required input fields?

Use input[required].

Q3. What is the difference between [type] and [type="email"]?

[type] selects elements containing the type attribute. [type="email"] selects elements whose type value is exactly email.

Q4. What does the ^= operator do?

It matches an attribute value that starts with the specified text.

Q5. What does the $= operator do?

It matches an attribute value that ends with the specified text.

Q6. What does the *= operator do?

It matches an attribute value containing the specified text anywhere within the value.

Q7. What is selector grouping?

It allows multiple selectors to share the same CSS declarations by separating them with commas.

Q8. What is a compound selector?

It combines simple selectors without spaces to target an element satisfying all the specified conditions.

Q9. What is the difference between .box.active and .box .active?

The first selects one element having both classes. The second selects a descendant with the active class inside an element with the box class.

Q10. What is the difference between grouping and compound selectors?

Grouping uses commas to select multiple independent targets. Compound selectors combine conditions for the same element.

Q11. How would you select PDF links?

Use a[href$=".pdf"] to match anchor elements whose href attribute ends with .pdf.

Q12. How would you select external HTTPS links?

A basic approach is a[href^="https://"]. For production websites, this is a simple URL-pattern match, not a complete security validation mechanism.

Q13. How do you select an email input with a particular class?

Use input.email-field[type="email"].

Q14. Can attribute selectors be combined with class selectors?

Yes. For example, input.required-field[required].
