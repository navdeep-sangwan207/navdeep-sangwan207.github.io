CSS3 Course | Chapter 1 | Lecture 03

Element, Class, ID and Universal Selectors

Learn how to select HTML elements accurately using the four foundational CSS selectors used in real-world frontend development.

1. Learning Objectives

After completing this lecture, you will be able to:

  • Understand how CSS selectors identify HTML elements.
  • Apply element selectors to HTML tags.
  • Use class selectors to style reusable components.
  • Use ID selectors to target a specific element.
  • Apply the universal selector to all elements.
  • Use multiple classes on a single HTML element.
  • Choose appropriate selectors for practical projects.
  • Identify and correct common selector errors.

2. What Is a CSS Selector?

A CSS selector is a pattern used to identify one or more HTML elements that should receive a particular style.

General CSS rule syntax:

selector {
    property: value;
}

Example:

h1 {
    color: blue;
    font-size: 30px;
}

Here, h1 is the selector. The browser finds the matching HTML heading elements and applies the declarations inside the CSS rule.

Example HTML

<h1>Welcome to My Website</h1>
<h1>About Us</h1>
<p>This is a paragraph.</p>

The selector h1 matches both heading elements. It does not match the paragraph.

3. Element (Type) Selector

An element selector selects HTML elements based on their tag names. It applies the same rule to every matching element.

Syntax

element-name {
    property: value;
}

Example

h1 {
    color: navy;
}

p {
    font-size: 16px;
    line-height: 1.6;
}

button {
    background-color: blue;
    color: white;
}

HTML

<h1>CSS Fundamentals</h1>

<p>Learn CSS selectors.</p>

<p>Practice frontend development.</p>

<button>Learn More</button>

How It Works

  • The h1 selector matches all h1 elements.
  • The p selector matches all paragraph elements.
  • The button selector matches all button elements.

Practical Applications

  • Setting a default font for the body.
  • Applying consistent paragraph line-height.
  • Defining default heading styles.
  • Setting common styles for all buttons.
Placement tip: Element selectors are useful for global defaults. Use classes when different elements need reusable, component-specific styling.

4. Class Selector

A class selector targets HTML elements that have a particular class attribute. It is one of the most frequently used selectors in professional frontend development.

Syntax

.class-name {
    property: value;
}

A period (.) before the class name identifies a class selector in CSS.

Example

.highlight {
    color: darkblue;
    background-color: lightyellow;
    padding: 10px;
}

HTML

<p class="highlight">
    This paragraph is highlighted.
</p>

<h2 class="highlight">
    This heading is also highlighted.
</h2>

<div class="highlight">
    This division is highlighted too.
</div>

All three elements receive the same class-based styling, even though they use different HTML tags.

Why Are Classes Important?

  • They allow CSS styles to be reused.
  • Multiple HTML elements can share the same class.
  • They support reusable UI components.
  • They help maintain consistent designs.
  • They are convenient for responsive layouts.

Example: Reusable Card Class

.card {
    background-color: white;
    padding: 20px;
    border-radius: 10px;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}
<div class="card">
    <h2>HTML Course</h2>
    <p>Learn HTML fundamentals.</p>
</div>

<div class="card">
    <h2>CSS Course</h2>
    <p>Learn CSS fundamentals.</p>
</div>

Both cards share the same styling. If the card design changes, you can update one CSS rule instead of styling each card separately.

5. ID Selector

An ID selector targets an HTML element using its unique id attribute.

Syntax

#id-name {
    property: value;
}

The hash symbol (#) before the name identifies an ID selector in CSS.

Example

#main-heading {
    color: darkred;
    text-align: center;
    font-size: 32px;
}

HTML

<h1 id="main-heading">
    Welcome to My Learning Portal
</h1>

<p>This is a normal paragraph.</p>

The ID selector matches the element whose ID is main-heading.

Important ID Rules

  • An ID should be unique within an HTML document.
  • An element can have only one ID attribute.
  • An ID value should not contain whitespace.
  • IDs are case-sensitive in HTML and CSS matching.
  • IDs can also be used as fragment targets in URLs.
Important: Browsers may still match duplicate IDs, but duplicate IDs violate the uniqueness requirement and can cause problems with JavaScript, accessibility relationships and fragment navigation.

Example: ID as a Page Navigation Target

<a href="#contact">Go to Contact Section</a>

<section id="contact">
    <h2>Contact Us</h2>
    <p>Contact information goes here.</p>
</section>

Clicking the link navigates to the element with the contact ID.

6. Universal Selector

The universal selector selects all elements in the document. It is represented by an asterisk (*).

Syntax

* {
    property: value;
}

Example

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

This rule applies to all elements and is commonly used for basic CSS resets and predictable box sizing.

Example HTML

<h1>Welcome</h1>
<p>Learn CSS selectors.</p>
<button>Submit</button>
<div>Content area</div>

The universal selector matches all these elements.

Practical tip: The universal selector is frequently used for a small number of global reset rules. Avoid placing expensive or unnecessary styling on every element without a clear reason.

7. Multiple Classes on One Element

An HTML element can have multiple classes. Separate class names with spaces inside the same class attribute.

HTML

<button class="btn primary large">
    Submit
</button>

CSS

.btn {
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
}

.primary {
    background-color: blue;
    color: white;
}

.large {
    font-size: 20px;
}

The button receives styles from all three classes: btn, primary and large.

Combining Classes in a Selector

.btn.primary {
    background-color: darkblue;
    color: white;
}

This selector matches an element that has both the btn and primary classes. The two classes do not need to appear in a particular order in the HTML class attribute.

8. Comparing the Four Selectors

Selector CSS Syntax HTML Target Typical Usage
Element p All matching p elements Global element styling
Class .card Elements with class="card" Reusable component styling
ID #header Element with id="header" Unique page element targeting
Universal * All elements Reset and global rules

Specificity: Introductory Comparison

When multiple CSS rules target the same element, specificity is one factor used by the browser to determine which declaration wins.

For these four selector types, the general specificity order is:

9. Class vs ID: When Should You Use Each?

Feature Class ID
CSS symbol . #
Reuse Can be reused Should be unique per document
Elements targeted Multiple elements One intended element
Multiple values Multiple classes allowed One ID value per element
Specificity Lower than ID Higher than class
Common use Cards, buttons, layouts Unique sections and targets
Professional recommendation: Prefer classes for styling reusable UI components. Use IDs when an element needs a unique identifier, such as a page section, fragment target or JavaScript hook where appropriate.

10. Class and ID Naming Best Practices

Good Class Names

.course-card
.primary-button
.navigation-menu
.login-form
.profile-image

Good ID Names

#main-header
#contact-section
#login-form
#page-footer

Avoid Unclear Names

.x
.red1
.test123
.box2

Follow these guidelines:

  • Use meaningful names that describe purpose or role.
  • Prefer lowercase names.
  • Use hyphens to separate words.
  • Keep naming consistent across the project.
  • Avoid naming a class only after its current color or appearance.
  • Use a consistent naming convention for reusable components.

11. Practical Example: Learning Portal Components

The following example combines element, class, ID and universal selectors in a small learning portal interface.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Selector Demo</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
            margin: 20px;
            background: #f4f7fb;
        }

        h1 {
            color: #174ea6;
        }

        .course-card {
            background: white;
            padding: 20px;
            margin-bottom: 15px;
            border-radius: 8px;
        }

        .course-title {
            color: #007bff;
        }

        .button {
            padding: 10px 16px;
            border: none;
            border-radius: 5px;
            background: #174ea6;
            color: white;
        }

        #featured-course {
            border: 2px solid #007bff;
        }
    </style>
</head>

<body>

    <h1>My Learning Portal</h1>

    <div class="course-card" id="featured-course">
        <h2 class="course-title">C Programming</h2>
        <p>Learn programming fundamentals.</p>
        <button class="button">Start Learning</button>
    </div>

    <div class="course-card">
        <h2 class="course-title">CSS3</h2>
        <p>Learn modern website styling.</p>
        <button class="button">Start Learning</button>
    </div>

</body>
</html>

Expected Result

My Learning Portal

C Programming

Learn programming fundamentals.

CSS3

Learn modern website styling.

Observe how the selectors work:

  • * applies box sizing to all elements.
  • h1 styles the main heading.
  • .course-card styles both course cards.
  • .course-title styles both course titles.
  • .button styles both buttons.
  • #featured-course adds a border to the first card.

12. Common Mistakes and Debugging

Mistake 1: Forgetting the Dot in a Class Selector

/* Incorrect if targeting class="card" */
card {
    background: white;
}

/* Correct */
.card {
    background: white;
}

Mistake 2: Using the Wrong Symbol for an ID

/* Incorrect */
.featured {
    color: red;
}

/* Correct for id="featured" */
#featured {
    color: red;
}

Mistake 3: Class Name Mismatch

/* HTML */
<div class="course-card"></div>

/* Incorrect CSS */
.coursecard {
    background: white;
}

/* Correct CSS */
.course-card {
    background: white;
}

Mistake 4: Incorrectly Combining Classes

/* Targets an element with both classes */
.card.primary {
    color: blue;
}

/* Targets a descendant .primary inside .card */
.card .primary {
    color: blue;
}

The space changes the meaning of the selector. The first selector requires both classes on the same element. The second selects a matching descendant element.

Mistake 5: Reusing an ID

<div id="course">HTML</div>
<div id="course">CSS</div>

Use a reusable class instead when multiple elements need the same styling.

Browser Developer Tools

  1. Open the webpage in Chrome or another modern browser.
  2. Right-click an element and select Inspect.
  3. Find its class and ID in the Elements panel.
  4. Check the Styles panel for matching CSS rules.
  5. Inspect crossed-out declarations and active declarations.
  6. Temporarily edit selector rules to test your understanding.
Debugging tip: If a style does not appear, first verify the HTML class or ID spelling, the CSS selector symbol, stylesheet loading and whether another declaration is overriding the expected style.

13. Placement Interview Questions and Answers

Q1. What is a CSS selector?

A CSS selector is a pattern used to identify HTML elements to which CSS declarations should be applied.

Q2. What is the difference between an element selector and a class selector?

An element selector targets elements by their HTML tag name. A class selector targets elements by a class attribute and can be reused across different elements.

Q3. How do you select a class in CSS?

Use a period followed by the class name. For example, .container selects elements with class="container".

Q4. How do you select an ID in CSS?

Use a hash symbol followed by the ID name. For example, #header selects the element with id="header".

Q5. Can multiple elements have the same class?

Yes. A class is designed to be reusable and can be assigned to multiple elements.

Q6. Can multiple elements have the same ID?

An ID should be unique within a document. Duplicate IDs are invalid HTML usage, even though browsers may still match them.

Q7. Can one HTML element have multiple classes?

Yes. Multiple class names can be separated by spaces in the class attribute.

Q8. What does the universal selector do?

The universal selector (*) matches all elements in the document.

Q9. Which has higher specificity: class or ID?

An ID selector has higher specificity than a class selector.

Q10. What is the difference between .card.primary and .card .primary?

.card.primary selects one element having both classes. .card .primary selects an element with the primary class that is a descendant of an element with the card class.

Q11. Should IDs or classes generally be preferred for styling?

Classes are generally preferred for styling because they are reusable and make component styles easier to maintain.

Q12. Does the universal selector contribute to specificity?

No. The universal selector contributes zero specificity.
