2. Introduction to CSS Positioning

The CSS position property determines how an element is positioned within a webpage.

It works with offset properties such as top, right, bottom and left.

Position Property Values

Value Purpose
static Default positioning in normal flow.
relative Offsets an element from its normal position.
absolute Positions an element relative to its containing block.
fixed Usually positions relative to the viewport.
sticky Combines normal-flow placement with scroll-based sticking.

This lecture focuses on static, relative and absolute positioning. Fixed and sticky are covered in the next lecture.

3. Static Positioning

position: static is the default positioning behaviour of most HTML elements. 

.box {
    position: static;
}

Characteristics

  • Element participates in normal flow.
  • Its position follows normal document layout.
  • Top, right, bottom and left do not offset it.
  • It is not a positioned element for z-index positioning rules.

Example

<div class="box">First Box</div>
<div class="box">Second Box</div>
<div class="box">Third Box</div>
.box {
    position: static;
    background: #174ea6;
    color: white;
    padding: 14px;
    margin: 8px 0;
}

Expected Result

First Box
Second Box
Third Box

All three boxes remain in their normal document order.

4. Relative Positioning

position: relative positions an element relative to its normal position in the layout. 

.box {
    position: relative;
    top: 10px;
    left: 20px;
}

Characteristics

  • The element remains in normal flow.
  • Its original layout space is preserved.
  • Offsets move its visual position from its normal position.
  • It can establish a containing block for absolutely positioned descendants.
  • A non-auto z-index can apply and the element can establish a stacking context when appropriate.

Example

<div class="box">First Box</div>

<div class="relative">
    Relative Box
</div>

<div class="box">Third Box</div>
.relative {
    position: relative;
    top: 10px;
    left: 25px;
    background: #174ea6;
    color: white;
    padding: 14px;
}

Expected Result

First Box
Relative Box
Third Box

The relative box moves down and right, but its original space remains reserved. The following element does not move into that original space.

5. Offset Properties

The offset properties control the placement of positioned elements.

Property Purpose
top Sets the top inset.
right Sets the right inset.
bottom Sets the bottom inset.
left Sets the left inset.

Example

.box {
    position: relative;

    top: 10px;
    right: 15px;
    bottom: auto;
    left: 20px;
}

Offset values may use px, %, rem and other supported CSS length or percentage values.

For relative positioning, positive top moves the element downward and positive left moves it rightward. For absolute positioning, offsets define the element's inset from its containing block.

6. Absolute Positioning

position: absolute removes an element from normal flow and positions it relative to its containing block. 

.box {
    position: absolute;
    top: 20px;
    right: 20px;
}

Characteristics

  • The element is removed from normal flow.
  • It does not reserve its original position in normal flow.
  • It can overlap other elements.
  • Its position is determined by offsets and its containing block.
  • It can be layered using z-index when stacking rules permit.

Example

<div class="parent">

    Parent Container

    <div class="child">
        Absolute Element
    </div>

</div>
.parent {
    position: relative;
    min-height: 180px;
}

.child {
    position: absolute;
    top: 15px;
    right: 15px;
}

Expected Result

Parent Container
Absolute Element

The absolute element is positioned at the top-right of the positioned parent.

7. Understanding the Containing Block

A containing block is the reference area used to calculate the size and position of certain elements.

For an absolutely positioned element, the containing block is generally established by the nearest ancestor that establishes an absolute-positioning containing block.

Common examples include ancestors with:

  • position: relative
  • position: absolute
  • position: fixed
  • position: sticky

Certain other properties, including transforms, can also establish containing blocks for absolute and fixed descendants.

Example

<div class="outer">

    <div class="inner">

        <div class="child">
            Positioned Child
        </div>

    </div>

</div>
.outer {
    position: relative;
    padding: 30px;
    border: 2px solid blue;
}

.inner {
    padding: 30px;
    border: 2px solid green;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

The child uses the nearest qualifying ancestor as its containing block, which is the outer element in this example.

Do not assume that every parent automatically becomes the containing block. A normal static ancestor generally does not establish the absolute-positioning containing block.

8. Positioning an Element at the Center

A common frontend requirement is placing an element exactly in the center of a parent container.

Example

.parent {
    position: relative;
    height: 200px;
}

.child {
    position: absolute;

    top: 50%;
    left: 50%;

    transform: translate(-50%, -50%);
}

Expected Result

Parent Container
Centered Element

The top and left offsets place the child's top-left corner at the parent's center. The transform shifts the child back by half its own dimensions.

Flexbox and Grid also provide convenient ways to center elements. They are covered in later chapters.

9. Relative vs Absolute Positioning

Feature Relative Absolute
Normal flow Remains in flow Removed from flow
Original space Preserved Not reserved in normal flow
Position reference Normal position Containing block
Can overlap elements Yes Yes
Common use Positioning context and small adjustments Badges, overlays and dropdown panels

10. Practical Example: Notification Badge

Create a notification badge positioned at the top-right corner of a button or icon.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Notification Badge</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            padding: 40px;
        }

        .notification {
            position: relative;
            display: inline-block;

            padding: 20px;
            background: #eaf2ff;
            border-radius: 8px;
        }

        .badge {
            position: absolute;

            top: -8px;
            right: -8px;

            background: #d93025;
            color: white;

            padding: 5px 8px;
            border-radius: 20px;
            font-size: 12px;
        }
    </style>
</head>

<body>

    <div class="notification">

        Messages

        <span class="badge">5</span>

    </div>

</body>
</html>

Expected Result

Messages 5

The badge is positioned independently at the top-right of the notification container.

12. Practical Example: Dropdown Menu

An absolutely positioned dropdown panel can be placed below a relatively positioned button wrapper.

Example

.dropdown {
    position: relative;
    display: inline-block;
}

.menu {
    display: none;
    position: absolute;

    top: 100%;
    left: 0;

    min-width: 170px;
}

.dropdown:hover .menu,
.dropdown:focus-within .menu {
    display: block;
}

13. Common Mistakes and Debugging

  1. Absolute element moves relative to the wrong parent: Check the nearest ancestor establishing its containing block.
  2. Following content overlaps: Remember that absolute elements are removed from normal flow.
  3. Relative element leaves an unexpected gap: Its original layout space is preserved.
  4. Top and left do not work: Check whether the element is positioned or is otherwise subject to offset rules.
  5. Element appears outside its parent: Check offsets, containing block dimensions and overflow clipping.
  6. Centered element is not truly centered: Remember to compensate for its own dimensions, for example with translate(-50%, -50%).
  7. Dropdown appears behind another component: Inspect stacking contexts and z-index.
  8. Absolute child covers important content: Ensure the parent has enough space and the overlap is intentional.

Debugging Steps

  1. Inspect the element in Developer Tools.
  2. Check the computed position value.
  3. Inspect top, right, bottom and left.
  4. Identify the nearest containing block.
  5. Check parent dimensions and padding.
  6. Inspect overflow and stacking behaviour.

14. Placement Interview Questions and Answers

Q1. What is CSS positioning?

Answer: It controls how an element is placed within a webpage using positioning schemes and offset properties.

Q2. What is position: static?

Answer: It is the default positioning behaviour in which an element follows normal flow.

Q3. What is position: relative?

Answer: It offsets an element from its normal position while preserving its original layout space.

Q4. What is position: absolute?

Answer: It removes an element from normal flow and positions it relative to its containing block.

Q5. What is a containing block?

Answer: It is the reference area used to calculate the position and sometimes dimensions of an element.

Q6. Why is position: relative commonly applied to a parent?

Answer: It commonly establishes the containing block for absolutely positioned descendants.

Q7. Does relative positioning remove an element from normal flow?

Answer: No. Its original layout space remains reserved.

Q8. Does absolute positioning remove an element from normal flow?

Answer: Yes. It does not reserve its original position in normal flow.

Q9. What is the purpose of top, right, bottom and left?

Answer: They specify insets or offsets used to position an element.

Q10. How do you center an absolute element?

Answer: Use top: 50%, left: 50% and transform: translate(-50%, -50%).

Q11. Can a static element use z-index?

Answer: The ordinary positioned-element z-index rules do not apply to a static element. There are special cases for flex and grid items.

Q12. Can an absolutely positioned element overlap other elements?

Answer: Yes. It is removed from normal flow and can overlap other content.

Q13. What happens if no positioned ancestor exists?

Answer: The absolute element uses the initial containing block as its containing block, subject to the applicable containing-block rules.

Q14. What is the difference between relative and absolute positioning?

Answer: Relative positioning preserves normal-flow space, whereas absolute positioning removes the element from normal flow.

Q15. Give practical uses of absolute positioning.

Answer: Notification badges, image overlays, dropdown panels, tooltips and decorative UI elements.

16. Quick Revision

  • Static is the default position value.
  • Relative offsets an element from its normal position.
  • Relative positioning preserves layout space.
  • Absolute positioning removes an element from normal flow.
  • Absolute elements use a containing block as their positioning reference.
  • Positioned ancestors commonly establish containing blocks.
  • Top, right, bottom and left control insets.
  • Relative positioning is commonly used on component wrappers.
  • Absolute positioning is useful for badges, overlays and dropdowns.
  • Always inspect containing blocks when positioning behaves unexpectedly.
