2. What Is Overflow?

Overflow occurs when the content inside an element is larger than the space available for displaying it.

CSS provides the overflow property to control how content outside an element's padding box is handled.

Syntax

.container {
    width: 300px;
    height: 150px;
    overflow: auto;
}

Common Situations

  • A paragraph contains more text than its fixed-height container can display.
  • A table is wider than its parent.
  • A dropdown menu extends outside a panel.
  • An image is larger than its container.
  • A dashboard panel needs independent scrolling.

3. Overflow Property Values

Value Behaviour
visible Content can extend outside the element's box. This is the initial value.
hidden Excess content is clipped. The element becomes a scroll container and can be scrolled programmatically.
scroll Creates a scroll container and provides scrolling mechanisms even when content currently fits.
auto Creates a scroll container and provides scrolling when needed.
clip Clips content without creating a scroll container.
For visible overflow, content may paint outside the element's box. For hidden and clip, excess content is clipped.

4. Overflow: Visible

overflow: visible allows content to extend outside the element's box.

Example

.container {
    width: 300px;
    height: 125px;
    overflow: visible;
}

Expected Result

This content is wider and taller than its parent. With overflow visible, the excess content can extend outside the parent's visible box.

The content is not automatically clipped by the container.

5. Overflow: Hidden

overflow: hidden clips content that extends beyond the element's overflow area.

Example

.container {
    width: 300px;
    height: 125px;
    overflow: hidden;
}

Expected Result

This content extends beyond the parent. Overflow hidden clips the extra content. The user does not see ordinary scrollbars, but the scroll container can still be scrolled programmatically.

The extra content is not visible outside the container.

Overflow hidden is useful for clipping decorative content and managing scrollable regions. It does not mean the content is removed from the document.

6. Overflow: Scroll

overflow: scroll creates a scroll container and provides scrolling mechanisms even when the content does not currently overflow.

Example

.container {
    width: 300px;
    height: 125px;
    overflow: scroll;
}

Expected Result

Scrollable content. Move the scrollbar horizontally or vertically to inspect the complete content. Scrollbars may look different depending on the operating system and browser.

Scrollbars may be visible even if the content fits, depending on the platform's scrollbar style.

7. Overflow: Auto

overflow: auto creates a scroll container and provides scrolling when content exceeds the available area.

Example

.container {
    width: 300px;
    height: 150px;
    overflow: auto;
}

Expected Result

Dashboard notification one.

Dashboard notification two.

Dashboard notification three.

Dashboard notification four.

Dashboard notification five.

Dashboard notification six.

Dashboard notification seven.

Dashboard notification eight.

The container displays scrolling when the content exceeds its available height.

For many dashboard panels and responsive content regions, overflow: auto is a practical default.

8. Overflow: Clip

overflow: clip clips content outside the overflow clip edge.

Unlike hidden, it does not create a scroll container and does not support scrolling the clipped content through ordinary scrolling mechanisms.

Example

.container {
    width: 300px;
    height: 125px;
    overflow: clip;
}

Expected Result

This content extends beyond the parent. Overflow clip cuts off the excess content without creating a scroll container.
Do not use overflow: clip when users need to scroll through the hidden content.

9. Difference Between Hidden and Clip

Feature Hidden Clip
Clips excess content Yes Yes
Creates scroll container Yes No
Programmatic scrolling Possible Not through a scroll container
Scrollbars normally displayed No No
Can be combined with flow-root Yes, BFC behaviour applies Use display: flow-root separately when a BFC is required

Use hidden when you need clipping with a scroll container. Use clip when you need clipping without scrolling.

10. Overflow-X and Overflow-Y

CSS allows independent control over horizontal and vertical overflow.

Syntax

.container {
    overflow-x: auto;
    overflow-y: hidden;
}
Property Controls
overflow-x Horizontal overflow.
overflow-y Vertical overflow.

Practical Example: Responsive Table

.table-wrapper {
    max-width: 100%;
    overflow-x: auto;
}

table {
    min-width: 650px;
}

A wide table can scroll horizontally instead of forcing the entire page to become wider.

The two overflow axes are not always completely independent. Certain combinations of visible, clip and scrollable values affect the computed value of the other axis.

11. Overflow Axis Computation

A technical detail that can matter during debugging is that the computed values of overflow-x and overflow-y can change depending on the value used on the other axis.

  • If one axis is neither visible nor clip, visible on the other axis computes to auto.
  • If one axis is neither visible nor clip, clip on the other axis computes to hidden.

Example

.container {
    overflow-x: hidden;
    overflow-y: visible;
}

The computed vertical overflow value is auto, rather than visible.

When debugging unexpected scrolling, inspect computed overflow values in Developer Tools rather than relying only on the authored CSS declaration.

12. Scroll Containers

A scroll container is an element whose content can be scrolled within its scrollport.

Values such as auto, scroll and hidden establish scroll containers. Clip does not.

Example

.notifications {
    height: 200px;
    overflow-y: auto;
}

This creates an independently scrollable notification panel.

Common Applications

  • Notification lists.
  • Chat message panels.
  • Scrollable sidebars.
  • Data tables.
  • Dashboard widgets.
  • Long content previews.

13. Text Overflow and Ellipsis

The text-overflow property specifies how inline content that overflows its line box is signalled to the user.

The ellipsis value displays three dots when text is clipped at the end.

Required CSS Pattern

.title {
    width: 250px;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

Expected Result

This is a long course title that cannot fit inside this fixed-width box.

The text is displayed on one line and excess content is represented by an ellipsis.

Text-overflow does not independently create the clipping behaviour. A constrained line, overflow handling and appropriate white-space behaviour are normally required.

14. White-Space and Overflow

The white-space property controls how spaces and line breaks are handled.

Value Behaviour
normal Collapses whitespace and wraps text normally.
nowrap Prevents automatic wrapping.
pre Preserves whitespace and line breaks.
pre-wrap Preserves whitespace while allowing wrapping.
pre-line Preserves line breaks while collapsing spaces.

Example

.code-line {
    white-space: nowrap;
    overflow-x: auto;
}
This is a long line of content that stays on one line and can be scrolled horizontally.

15. Practical Example: Scrollable Sidebar

A dashboard sidebar can have a fixed available height and scroll independently when it contains many navigation links.

Example

.sidebar {
    height: 400px;
    overflow-y: auto;
}

.sidebar a {
    display: block;
    padding: 12px;
}

This technique is useful when a dashboard has many navigation options.

16. Practical Example: Clipped Card Shadow

An ancestor with overflow hidden can clip descendant content and visual effects.

Example

.card-wrapper {
    overflow: hidden;
}

.card {
    box-shadow: 0 0 20px rgba(0,0,0,0.4);
}

Expected Behaviour

Card with a shadow that may be clipped by its overflow-hidden ancestor.

The shadow may be cut off at the wrapper's clipping boundary.

If a shadow, dropdown or tooltip is unexpectedly clipped, inspect the overflow properties of every ancestor between the element and the page.

17. Common Mistakes and Debugging

  1. Unexpected horizontal scrollbar: Inspect fixed widths, large images, long text and child elements.
  2. Content disappears: Check whether an ancestor uses overflow hidden or clip.
  3. Dropdown is cut off: Inspect ancestor overflow and consider changing the component structure.
  4. Text ellipsis does not work: Check width constraints, white-space and overflow.
  5. Scrollbars appear unnecessarily: Consider overflow auto instead of scroll.
  6. Hidden content cannot be scrolled: Check whether the element uses clip instead of hidden.
  7. Shadow is clipped: Inspect ancestor clipping boundaries.
  8. Unexpected vertical scrolling: Inspect computed overflow-x and overflow-y values.

Debugging Checklist

  1. Inspect the element's width and height.
  2. Check its content dimensions.
  3. Inspect overflow-x and overflow-y.
  4. Check computed overflow values.
  5. Inspect all ancestor elements for clipping.
  6. Check white-space and text-overflow.
  7. Test the layout at different viewport sizes.

18. Placement Interview Questions and Answers

Q1. What is CSS overflow?

Answer: It controls how content that extends beyond an element's available area is handled.

Q2. What is the default overflow value?

Answer: Visible.

Q3. What is the difference between hidden and auto?

Answer: Both create scroll containers. Hidden clips excess content without ordinary scrollbars, while auto provides scrolling when needed.

Q4. What is the difference between hidden and clip?

Answer: Hidden creates a scroll container and permits programmatic scrolling. Clip clips content without creating a scroll container.

Q5. What is overflow-x?

Answer: It controls horizontal overflow.

Q6. What is overflow-y?

Answer: It controls vertical overflow.

Q7. What is a scroll container?

Answer: It is an element whose content can be scrolled within its scrollport.

Q8. What does text-overflow: ellipsis do?

Answer: It displays an ellipsis to indicate clipped inline content at the end of a line.

Q9. Why is white-space: nowrap used with ellipsis?

Answer: It prevents the text from wrapping onto multiple lines.

Q10. Can overflow hidden clip a box shadow?

Answer: Yes. It can clip descendant painting outside the clipping boundary.

Q11. Why might a dropdown menu be clipped?

Answer: An ancestor may have overflow hidden, clip or another clipping mechanism.

Q12. When should overflow auto be used?

Answer: When a content region should scroll only when its content exceeds the available space.
