2. Introduction to Float

The CSS float property was originally designed to allow text to wrap around images and other floated content.

It was also widely used to create multi-column webpage layouts before Flexbox and CSS Grid became standard layout tools.

Syntax

.image {
    float: left;
}

Float Property Values

Value Behaviour
none Default. Element does not float.
left Floats the element to the left of its containing block.
right Floats the element to the right of its containing block.
inline-start Floats toward the inline-start side.
inline-end Floats toward the inline-end side.

3. Float Left

float: left places an element toward the left side of its containing block. Inline content can wrap around the floated element.

Example

<div class="image">Image</div>

<p>
    This paragraph wraps around the floated element.
</p>
.image {
    float: left;
    width: 120px;
    height: 100px;
    margin-right: 15px;
}

Expected Result

Left Float

CSS float allows text to flow around an element. This behaviour is especially useful for article layouts, where an image appears alongside a paragraph. The text occupies available space beside the floated element and continues below it when necessary.

The paragraph wraps around the left-floated box.

4. Float Right

float: right places an element toward the right side of its containing block.

Example

.image {
    float: right;
    width: 120px;
    height: 100px;
    margin-left: 15px;
}

Expected Result

Right Float

A right-floated element is positioned toward the right edge of its containing block. Surrounding inline content can wrap around its left side. This technique was frequently used in older article and editorial layouts.

5. How Float Changes Normal Flow

A floated element is taken out of normal flow, but it is not positioned like an absolutely positioned element.

The following rules are important:

  • The float is shifted toward the left or right edge of its containing block.
  • Inline content wraps around the float.
  • Other block-level boxes generally behave as if the float were not in normal flow.
  • Their inline content still makes room for the float.
  • A float may extend beyond the height of its parent if the parent does not contain it.
Float is different from absolute positioning. Floats interact with surrounding inline content and influence text wrapping.

6. Clear Property

The clear property controls whether an element can be positioned beside earlier floated elements.

Syntax

.next-section {
    clear: both;
}

Clear Property Values

Value Purpose
none Default. Does not clear floats.
left Clears left floats.
right Clears right floats.
both Clears floats on both sides.
inline-start Clears floats on the inline-start side.
inline-end Clears floats on the inline-end side.

Example

<div class="image">Floated Box</div>

<div class="next-section">
    Next Section
</div>
.image {
    float: left;
}

.next-section {
    clear: both;
}

Expected Result

Float

Text can wrap beside this floated box.

This section clears both left and right floats.

7. The Float Parent Height Problem

One common legacy CSS problem occurs when a parent contains only floated children.

Since floats are taken out of normal flow, the parent may not automatically expand to contain their height.

Problem Example

<div class="parent">
    <div class="child">Float Child</div>
</div>

<div class="next">
    Next Section
</div>
.parent {
    background: #eaf2ff;
}

.child {
    float: left;
    width: 150px;
    height: 100px;
    background: #174ea6;
}

The parent may collapse to a height that does not contain the floated child.

This is a common reason why backgrounds and borders appear to disappear around floated elements in older CSS layouts.

8. Clearfix Technique

Clearfix is a traditional CSS technique used to make a parent contain its floated children.

Modern Clearfix Pattern

.clearfix::after {
    content: "";
    display: table;
    clear: both;
}

The generated pseudo-element clears the preceding floats and contributes to the parent's layout.

Complete Example

<div class="parent clearfix">

    <div class="child">Column One</div>
    <div class="child">Column Two</div>

</div>
.parent {
    background: #eaf2ff;
    border: 2px solid #174ea6;
}

.child {
    float: left;
    width: 45%;
    margin: 2%;
    padding: 15px;
    box-sizing: border-box;
    background: #174ea6;
    color: white;
}

.clearfix::after {
    content: "";
    display: table;
    clear: both;
}

Expected Result

Column One
Column Two
Column Three

The parent expands to contain the floated columns.

9. Block Formatting Context and Float Containment

A block formatting context (BFC) is an independent layout region that affects how block boxes and floats interact.

Establishing a BFC on a parent can make it contain its floated descendants.

Common Ways to Establish a BFC

  • display: flow-root
  • overflow: auto
  • overflow: hidden
  • Certain layout and positioning conditions, such as a flex or grid container.

Recommended Modern Solution: Flow-Root

.parent {
    display: flow-root;
}

Example

<div class="parent">
    <div class="float-child">
        Floated Content
    </div>

    <p>Parent contains the float.</p>
</div>
.parent {
    display: flow-root;
    border: 2px solid #174ea6;
    padding: 12px;
}

.float-child {
    float: left;
    width: 110px;
    height: 80px;
    background: #174ea6;
    color: white;
    margin-right: 12px;
}

Expected Result

Floated Content

The parent uses display: flow-root, creating a new block formatting context that contains the floated child.

Prefer display: flow-root when the specific requirement is float containment. Overflow hidden can unintentionally clip content, while overflow auto can introduce scrolling.

10. Legacy Multi-Column Layout Using Float

Before Flexbox and Grid, developers frequently created columns using floated elements.

Example

<div class="container clearfix">

    <div class="column">Column 1</div>
    <div class="column">Column 2</div>
    <div class="column">Column 3</div>

</div>
.column {
    float: left;
    width: 31%;
    margin-right: 2%;
    box-sizing: border-box;
}

.column:last-child {
    margin-right: 0;
}

Each column floats next to the previous one. The container needs float containment.

Float-based columns require careful width and margin calculations. They are not the recommended approach for new multi-column layouts.

11. Modern Alternative: Flexbox

Flexbox is designed for one-dimensional layouts. It provides straightforward alignment, spacing, ordering and flexible sizing.

Example

.container {
    display: flex;
    gap: 12px;
}

.column {
    flex: 1;
}

Expected Result

Column 1
Column 2
Column 3

Flexbox is suitable for navigation bars, toolbars, card rows and component alignment.

12. Modern Alternative: CSS Grid

CSS Grid is designed for two-dimensional layouts. It manages rows and columns together.

Example

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 12px;
}

Expected Result

Column 1
Column 2
Column 3

Grid is suitable for dashboards, page structures, galleries and complex card layouts.

13. Float vs Flexbox vs Grid

Feature Float Flexbox Grid
Primary purpose Text wrapping around elements One-dimensional layout Two-dimensional layout
Alignment Limited Built-in alignment controls Built-in row and column alignment
Spacing Usually margins Gap and margins Gap and margins
Responsive layouts Requires more manual work Strong support Strong support
Best use Article image wrapping Navigation and component rows Page and dashboard layouts
For placement preparation, understand float and clear because they appear in legacy code and interview questions. Use Flexbox and Grid for most new layout assignments.

14. Common Mistakes and Debugging

  1. Parent does not contain floated children: Use clearfix or display: flow-root.
  2. Next section appears beside a float: Apply clear: both where appropriate.
  3. Columns do not fit: Recheck widths, margins, padding and box-sizing.
  4. Float overlaps unexpected content: Inspect available width and surrounding inline content.
  5. Content gets clipped after overflow hidden: Consider display: flow-root instead.
  6. Layout breaks on small screens: Use responsive Flexbox or Grid instead of rigid float columns.
  7. Clearfix does not work: Check the clearfix class is applied to the correct parent.

Debugging Checklist

  1. Inspect computed float values.
  2. Check the width of floated elements.
  3. Inspect margins and box-sizing.
  4. Check whether the parent contains its floats.
  5. Inspect clear values on following elements.
  6. Check whether a BFC is required.
  7. Consider replacing layout floats with Flexbox or Grid.

15. Placement Interview Questions and Answers

Q1. What is the float property?

Answer: It positions an element toward the left or right side of its containing block and allows inline content to wrap around it.

Q2. What are the common float values?

Answer: none, left, right, inline-start and inline-end.

Q3. What is the purpose of clear?

Answer: It prevents an element from being positioned beside specified preceding floats.

Q4. What does clear: both do?

Answer: It clears both left and right floats.

Q5. What is clearfix?

Answer: It is a CSS technique that makes a parent contain floated children, commonly using an ::after pseudo-element.

Q6. Why can a parent collapse around floated children?

Answer: Floated elements are removed from normal flow, so the parent may not automatically account for their height.

Q7. What is a block formatting context?

Answer: It is an independent layout context that controls interactions between block boxes, floats and other layout features.

Q8. How can display: flow-root help?

Answer: It establishes a new block formatting context and allows a parent to contain its floated descendants.

Q9. Is float recommended for modern page layouts?

Answer: Generally no. Flexbox and Grid are better suited to modern component and page layouts.

Q10. When is float still useful?

Answer: It remains useful when text needs to wrap around an image or similar content.

Q11. What is the difference between float and absolute positioning?

Answer: Both are taken out of normal flow in different ways, but floats interact with surrounding inline content and cause text wrapping, while absolutely positioned elements do not participate in that wrapping behaviour.

Q12. What is the difference between Flexbox and Grid?

Answer: Flexbox primarily handles one-dimensional layouts, while Grid handles two-dimensional row-and-column layouts.

16. Practical Coding Challenges

  1. Create an article with an image floated left.

  3. Create three columns using float.

  10. Compare the maintainability of all three approaches.
