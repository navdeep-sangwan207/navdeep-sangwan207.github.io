2. Problem 1: Position a Badge on a Product Card

Problem Statement

Create a product card with a sale badge positioned in its top-right corner. The badge must remain attached to the card when the card moves or changes size.

Concepts Used

  • position: relative
  • position: absolute
  • top and right offsets

Complete Code

<div class="product-card">
    <span class="product-badge">SALE</span>

    <h3>Wireless Headphones</h3>
    <p>Comfortable headphones with clear sound.</p>
    <strong>₹1,499</strong>
</div>

.product-card {
    position: relative;
    max-width: 360px;
    padding: 22px;
    border: 1px solid #ccc;
}

.product-badge {
    position: absolute;
    top: 10px;
    right: 10px;
    background: red;
    color: white;
    padding: 5px 10px;
}

Expected Result

SALE

Wireless Headphones

Comfortable headphones with clear sound.

₹1,499

Why Does This Work?

The card establishes a containing block using position relative. The badge is absolutely positioned relative to that card.

Interview point: A positioned ancestor is a common way to establish the containing block for an absolutely positioned child. Other CSS properties can also establish containing blocks.

3. Problem 2: Create a Sticky Navigation Area

Problem Statement

Create a navigation bar that remains at the top of its scrolling content area.

Complete Code

.scroll-container {
    height: 250px;
    overflow-y: auto;
}

.navbar {
    position: sticky;
    top: 0;
    background: #174ea6;
    color: white;
    padding: 12px;
    z-index: 2;
}

Expected Result

Dashboard | Courses | Projects | Profile

Dashboard Content

Scroll inside this panel.

Section one: Course progress.

Section two: Recent activities.

Section three: Pending assignments.

Section four: Notifications.

Section five: Project updates.

Section six: Learning resources.

Section seven: Upcoming tasks.

Section eight: Account information.

Important Points

  • Sticky positioning requires an inset threshold such as top: 0.
  • It remains in normal flow.
  • Its behaviour is constrained by its containing block and relevant scroll container.
  • An ancestor's overflow settings can change which scroll container controls sticky behaviour.

4. Problem 3: Fix a Z-Index Overlap Problem

Problem Statement

Two elements overlap. One has z-index 2 and the other has z-index 1. Determine which element appears above.

Complete Code

.parent {
    position: relative;
    isolation: isolate;
}

.box-one {
    position: absolute;
    z-index: 2;
}

.box-two {
    position: absolute;
    z-index: 1;
}

Expected Result

Box One
z-index: 2
Box Two
z-index: 1

Debugging Points

  • Check whether the elements participate in different stacking contexts.
  • Inspect the z-index values.
  • Inspect opacity, transform and isolation on ancestors.
  • Remember that a child cannot escape its parent's stacking context simply by using a very large z-index.
Increasing z-index to an extremely large number is not a reliable solution when the element is trapped inside a lower stacking context.

5. Problem 4: Create a Modal Overlay

Problem Statement

Create a modal-style overlay that appears above the page content.

Complete Code

.modal-overlay {
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.55);
    display: flex;
    align-items: center;
    justify-content: center;
    z-index: 10;
}

.modal-box {
    background: white;
    padding: 20px;
    border-radius: 8px;
}

Expected Result

Course Dashboard

Dashboard content behind the overlay.

Confirm Action

Are you sure you want to continue?

Real-World Considerations

  • A production modal should manage keyboard focus.
  • It should support keyboard interaction and an accessible name.
  • It should provide a close action.
  • Background content should not remain interactable when the modal is active.
  • For a real application, consider the HTML dialog element and its modal behaviour.

6. Problem 5: Wrap Text Around an Image

Problem Statement

Display an image-like element on the left side and allow paragraph text to wrap around it.

Complete Code

.image {
    float: left;
    width: 100px;
    height: 80px;
    margin-right: 15px;
}

.article::after {
    content: "";
    display: table;
    clear: both;
}

Expected Result

IMAGE

CSS float allows inline content to wrap around an element. This behaviour is useful for articles, documentation and image-based content layouts. Modern page layouts should generally use Flexbox or Grid instead of float-based columns.

Key Point

Float is still useful for text wrapping, while Flexbox and Grid are generally better for application layouts.

7. Problem 6: Debug Unexpected Content Clipping

Problem Statement

A child element is wider than its parent, but part of the content is not visible.

Complete Code

.parent {
    width: 390px;
    height: 100px;
    overflow: hidden;
}

.child {
    width: 600px;
    height: 130px;
}

Expected Result

This child is wider than the parent. The extra content is clipped.

Debugging Steps

  1. Inspect the parent element.
  2. Check its overflow property.
  3. Inspect the child's dimensions.
  4. Check whether an ancestor also clips the content.
  5. Decide whether clipping or scrolling is the intended behaviour.
A larger z-index does not allow an element to paint outside an ancestor's overflow clipping boundary.

8. Problem 7: Prevent Horizontal Overflow in a Layout

Problem Statement

Create a two-column layout that changes into a single-column layout on smaller screens.

Complete Code

.layout {
    display: grid;
    grid-template-columns: 200px 1fr;
    gap: 15px;
}

.main-content {
    min-width: 0;
}

@media (max-width: 650px) {
    .layout {
        grid-template-columns: 1fr;
    }
}

Expected Result

Sidebar

Dashboard

Courses

Projects

Main Content

This layout uses Grid. On narrow screens, the columns become a single column.

The min-width: 0 declaration allows the grid item to shrink below its automatic minimum size when necessary.

Important Point

Grid and Flexbox items can have automatic minimum sizes that prevent them from shrinking as expected. Using min-width: 0 on a relevant item can solve many horizontal overflow problems.

10. Browser Developer Tools Debugging Workflow

Browser Developer Tools are essential for diagnosing CSS layout problems during frontend development and technical assessments.

  1. Open the page in Chrome or another modern browser.
  2. Press F12 to open Developer Tools.
  3. Use the element inspector to select the affected element.
  4. Inspect the Computed styles panel.
  5. Check display, position, inset and z-index.
  6. Inspect ancestor elements for overflow and transforms.
  7. Temporarily disable CSS declarations to identify the cause.
  8. Test changes at different viewport sizes.
  9. Verify the final layout and interaction.

12. Placement Interview Questions and Answers

Q1. What is the difference between relative and absolute positioning?

Answer: Relative positioning preserves the element's normal-flow space, while absolute positioning removes the element from normal flow.

Q2. Why is position relative commonly used on a card?

Answer: It commonly establishes a containing block for absolutely positioned descendants such as badges.

Q3. Why does z-index sometimes fail?

Answer: The element may be constrained by a stacking context or may not participate in the expected stacking order.

Q4. Can a child escape its parent's stacking context using a large z-index?

Answer: No. A child remains within its parent's stacking context in the overall stacking order.

Q5. What is the difference between fixed and sticky positioning?

Answer: Fixed positioning is removed from normal flow and is usually positioned relative to the viewport. Sticky positioning remains in flow and sticks within its scroll and containing-block constraints.

Q6. Why might position sticky not work?

Answer: Common causes include a missing inset threshold, insufficient scrolling space or an unexpected ancestor scroll container.

Q7. What does overflow hidden do?

Answer: It clips overflowing content while creating a scroll container that can still be scrolled programmatically.

Q8. What is the difference between overflow hidden and clip?

Answer: Hidden creates a scroll container; clip does not.

Q9. How do you clear floats?

Answer: Use the clear property, a clearfix technique or display: flow-root on a suitable parent.

Q10. What is a containing block?

Answer: It is the reference box used to calculate the position and dimensions of certain elements, especially positioned descendants.

Q11. Can overflow clipping be overridden by z-index?

Answer: No. A higher z-index does not remove an ancestor's clipping boundary.

Q12. When should Flexbox or Grid be preferred over float?

Answer: For modern application layouts, navigation, columns and card arrangements. Float remains useful for text wrapping around content.
