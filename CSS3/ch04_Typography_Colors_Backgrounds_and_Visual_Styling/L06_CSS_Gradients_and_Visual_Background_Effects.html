2. What Are CSS Gradients?

A CSS gradient is a gradual transition between two or more colors. It is generated by the browser and can be used as a CSS image.

Common applications include:

  • Website hero sections.
  • Navigation bars.
  • Buttons and cards.
  • Background decorations.
  • Progress indicators.
  • Decorative text effects.

CSS provides three main gradient functions:

Function Purpose
linear-gradient() Transitions along a straight line.
radial-gradient() Transitions outward from a central point or shape.
conic-gradient() Transitions around a central point by angle.
Gradients are CSS images. Therefore, they are commonly assigned using background-image or background.

3. Linear Gradient

The linear-gradient() function creates a transition between colors along a straight line.

Syntax

background-image: linear-gradient(
    direction,
    color1,
    color2
);

Example 1: Default Direction

.box {
    background-image: linear-gradient(
        red,
        blue
    );
}

The default direction is from top to bottom.

Linear Gradient: Left to Right

Example 2: Horizontal Gradient

.box {
    background-image: linear-gradient(
        to right,
        #174ea6,
        #007bff
    );
}

Example 3: Vertical Gradient

.box {
    background-image: linear-gradient(
        to bottom,
        red,
        orange
    );
}

Example 4: Diagonal Gradient

.box {
    background-image: linear-gradient(
        to bottom right,
        red,
        blue
    );
}
Diagonal Gradient with Multiple Colors

4. Linear Gradient Directions and Angles

A linear gradient can use directional keywords or an angle.

Direction Meaning
to right Left to right.
to left Right to left.
to bottom Top to bottom.
to top Bottom to top.
to bottom right Toward the bottom-right corner.

Using Angles

.gradient-one {
    background: linear-gradient(
        0deg,
        red,
        blue
    );
}

.gradient-two {
    background: linear-gradient(
        90deg,
        red,
        blue
    );
}

.gradient-three {
    background: linear-gradient(
        180deg,
        red,
        blue
    );
}

.gradient-four {
    background: linear-gradient(
        270deg,
        red,
        blue
    );
}

For linear gradients, 0deg points upward, 90deg points right, 180deg points downward and 270deg points left.

The angle describes the direction in which the gradient progresses. This is a common interview topic.

5. Color Stops

Color stops specify the colors and positions at which they appear in a gradient.

Example

.box {
    background: linear-gradient(
        to right,
        red 0%,
        orange 30%,
        yellow 60%,
        green 100%
    );
}

Percentage positions control where each color stop occurs along the gradient line.

Three or More Colors

.banner {
    background: linear-gradient(
        135deg,
        #174ea6 0%,
        #007bff 45%,
        #00c9a7 100%
    );
}

Hard Color Transitions

.stripes {
    background: linear-gradient(
        to right,
        red 50%,
        blue 50%
    );
}

When color stops share the same position, the transition becomes a sharp boundary.

6. Radial Gradient

The radial-gradient() function creates a gradient that spreads outward from a central point.

Syntax

background-image: radial-gradient(
    shape size at position,
    color1,
    color2
);

Basic Example

.box {
    background: radial-gradient(
        red,
        blue
    );
}
Radial Gradient

Circle Shape

.circle {
    background: radial-gradient(
        circle,
        yellow,
        orange,
        red
    );
}

Ellipse Shape

.ellipse {
    background: radial-gradient(
        ellipse,
        white,
        #174ea6
    );
}

Controlling Position

.box {
    background: radial-gradient(
        circle at top left,
        yellow,
        red
    );
}

Controlling Size

.box {
    background: radial-gradient(
        circle 100px at center,
        yellow,
        blue
    );
}

Radial gradients are useful for spotlight effects, decorative backgrounds and highlighted interface areas.

7. Conic Gradient

The conic-gradient() function creates a gradient that transitions around a central point based on angular positions.

Syntax

background-image: conic-gradient(
    color1,
    color2,
    color3
);

Example

.box {
    background: conic-gradient(
        red,
        yellow,
        green,
        blue,
        red
    );
}
Conic Gradient

Controlling the Starting Angle

.box {
    background: conic-gradient(
        from 45deg,
        red,
        yellow,
        green,
        blue
    );
}

Controlling the Center

.box {
    background: conic-gradient(
        at 30% 40%,
        red,
        yellow,
        blue
    );
}

Practical Applications

  • Pie-chart-like visual effects.
  • Color wheels.
  • Decorative circular designs.
  • Progress indicators.

8. Repeating Linear Gradient

The repeating-linear-gradient() function repeats a linear gradient pattern.

Example

.box {
    background: repeating-linear-gradient(
        45deg,
        #174ea6 0px,
        #174ea6 10px,
        #007bff 10px,
        #007bff 20px
    );
}
Repeating Linear Gradient

Applications:

  • Striped backgrounds.
  • Decorative separators.
  • Patterned cards.
  • Progress and status designs.

9. Repeating Radial Gradient

The repeating-radial-gradient() function repeats a radial gradient pattern.

Example

.box {
    background: repeating-radial-gradient(
        circle,
        #174ea6 0px,
        #174ea6 8px,
        #007bff 8px,
        #007bff 16px
    );
}
Repeating Radial Gradient

This function is useful for concentric circles and decorative circular patterns.

10. Transparency in Gradients

Gradients can use transparent colors to create overlays and fading effects.

Example Using RGBA

.hero {
    background: linear-gradient(
        rgba(0, 0, 0, 0.7),
        rgba(0, 0, 0, 0.1)
    );
}

Example Using Transparent

.box {
    background: linear-gradient(
        to right,
        #174ea6,
        transparent
    );
}

Transparent colors are useful when placing text over photographic backgrounds.

Practical Overlay

.hero {
    background-image:
        linear-gradient(
            rgba(0, 0, 0, 0.65),
            rgba(0, 0, 0, 0.25)
        ),
        url("images/hero.jpg");

    background-size: cover;
    background-position: center;
}

11. Gradient Text Effects

A gradient can be clipped to text to create decorative heading effects.

Example

.gradient-text {
    background: linear-gradient(
        90deg,
        #174ea6,
        #007bff
    );

    background-clip: text;
    -webkit-background-clip: text;
    color: transparent;
}

12. Gradient Buttons

14. Common Mistakes and Debugging

  1. Incorrect gradient syntax: Check commas, parentheses and color values.
  2. Unexpected gradient direction: Verify the angle or directional keyword.
  3. Colors transition too quickly: Adjust color-stop positions.
  4. Text becomes unreadable: Adjust overlay opacity and foreground contrast.
  5. Gradient does not appear: Check whether another background declaration overrides it.
  6. Multiple layers display incorrectly: Remember that the first background image is the top layer.
  7. Gradient text disappears: Provide a fallback text color and check browser support.
  8. Excessive visual effects: Use gradients consistently rather than decorating every element.

Debugging Checklist

  1. Inspect the element in Developer Tools.
  2. Check the computed background-image value.
  3. Verify gradient function syntax.
  4. Check color stops and gradient direction.
  5. Inspect background layers and overlays.
  6. Test text contrast and responsive behaviour.

15. Placement Interview Questions and Answers

Q1. What is a CSS gradient?

Answer: A gradient is a CSS-generated image that creates a transition between two or more colors.

Q2. Name the three main CSS gradient functions.

Answer: linear-gradient(), radial-gradient() and conic-gradient().

Q3. What is the default direction of linear-gradient()?

Answer: Top to bottom.

Q4. What does 90deg mean in a linear gradient?

Answer: The gradient progresses from left to right.

Q5. What are color stops?

Answer: Color stops define the colors and their positions along a gradient.

Q6. What is a radial gradient?

Answer: It creates a color transition outward from a central point.

Q7. What is a conic gradient?

Answer: It creates color transitions around a central point using angular positions.

Q8. What is the purpose of repeating-linear-gradient()?

Answer: It creates a repeating linear gradient pattern.

Q9. How can you create a dark overlay over a background image?

Answer: Use a semi-transparent linear gradient as the first background layer and the image as the second layer.

Q10. Are gradients CSS images?

Answer: Yes. Gradient functions generate CSS images and can be used with background-image.

Q11. What is the difference between linear and radial gradients?

Answer: A linear gradient transitions along a straight line, whereas a radial gradient transitions outward from a central point.

Q12. Can multiple gradients be combined?

Answer: Yes. Multiple gradient layers can be specified using comma-separated background-image values.

Q13. How do you create a gradient text effect?

Answer: Apply a gradient background, use background-clip: text and make the text color transparent.

Q14. How can you create diagonal gradients?

Answer: Use a diagonal direction such as to bottom right or an appropriate angle such as 135deg.

Q15. What is the difference between a gradient and a background image?

Answer: A gradient is generated by CSS, while a conventional background image usually loads an external image resource. Both can be combined as background layers.
