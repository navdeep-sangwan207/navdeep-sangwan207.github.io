2. What Is a CSS Border?

A border is a visible boundary around an element. It is positioned between the element's padding and margin in the CSS box model.

Borders are commonly used for:

  • Cards and content panels.
  • Form inputs and buttons.
  • Navigation components.
  • Tables and separators.
  • Image frames.
  • Highlighted interface elements.

A CSS border can be controlled through three primary properties:

  • border-width
  • border-style
  • border-color

3. The border-style Property

The border-style property specifies the appearance of a border.

Common Values

Value Description
none No border is displayed.
solid Single solid line.
dashed Dashed line.
dotted Dotted line.
double Two solid lines.
groove Three-dimensional grooved appearance.
ridge Three-dimensional ridged appearance.
inset Creates an inset appearance.
outset Creates an outset appearance.

Examples

.solid {
    border-style: solid;
}

.dashed {
    border-style: dashed;
}

.dotted {
    border-style: dotted;
}

.double {
    border-style: double;
}

Important: A border style other than none or hidden is generally required for a visible border. Setting only border-width or border-color is not enough when the style remains none.

4. The border-width Property

The border-width property controls the thickness of the border.

Common Values

  • thin
  • medium
  • thick
  • Length values such as 1px, 3px and 5px.

Example

.box {
    border-style: solid;
    border-width: 4px;
}

Different Widths for Each Side

.box {
    border-style: solid;
    border-width: 2px 4px 6px 8px;
}

Four-value shorthand follows this order:

  1. Top
  2. Right
  3. Bottom
  4. Left

5. The border-color Property

The border-color property specifies the color of an element's border.

Example

.box {
    border-style: solid;
    border-width: 3px;
    border-color: #174ea6;
}

Different Colors for Each Side

.box {
    border-style: solid;
    border-width: 3px;

    border-color:
        red
        blue
        green
        orange;
}

The four-value order is top, right, bottom and left.

Using currentColor

.card {
    color: #174ea6;
    border: 2px solid currentColor;
}

The currentColor keyword uses the element's computed text color.

6. The border Shorthand Property

The border shorthand combines border-width, border-style and border-color.

Syntax

selector {
    border: width style color;
}

Example

.card {
    border: 2px solid #174ea6;
}

The order of these three components is flexible. 

.box-one {
    border: 3px dashed red;
}

.box-two {
    border: solid 2px blue;
}

.box-three {
    border: double 5px green;
}
The border shorthand applies to all four sides and resets omitted border components to their initial values.

7. Individual Border Side Properties

CSS provides separate properties for controlling each side of an element.

Property Controls
border-top Top border.
border-right Right border.
border-bottom Bottom border.
border-left Left border.

Example

.card {
    border-top: 4px solid #174ea6;
    border-right: 1px solid #ddd;
    border-bottom: 1px solid #ddd;
    border-left: 1px solid #ddd;
}

This approach is useful for creating cards with a colored top edge.

Individual Border Components

.box {
    border-top-width: 3px;
    border-top-style: solid;
    border-top-color: blue;

    border-left-width: 2px;
    border-left-style: dashed;
    border-left-color: red;
}

8. Border Shorthand with Different Values

CSS allows shorthand declarations for all four sides using one, two, three or four values.

Values Application
One All four sides.
Two Top and bottom; left and right.
Three Top; left and right; bottom.
Four Top; right; bottom; left.

Example: border-width

.one {
    border-width: 3px;
}

.two {
    border-width: 3px 6px;
}

.three {
    border-width: 2px 4px 6px;
}

.four {
    border-width: 1px 2px 3px 4px;
}

The same one-to-four-value distribution applies to border-style and border-color.

9. The border-radius Property

The border-radius property rounds the corners of an element's border box.

Syntax

selector {
    border-radius: value;
}

Examples

.small-radius {
    border-radius: 5px;
}

.medium-radius {
    border-radius: 12px;
}

.large-radius {
    border-radius: 25px;
}
Rounded Border

Different Radius Values

.box {
    border-radius: 10px 20px 30px 40px;
}

The order is top-left, top-right, bottom-right and bottom-left.

Two-Value Example

.box {
    border-radius: 10px 30px;
}

The first value applies to top-left and bottom-right. The second applies to top-right and bottom-left.

10. Creating Circular Elements

A circular element can be created by applying border-radius: 50% to a square element.

Example

.circle {
    width: 120px;
    height: 120px;

    border: 4px solid #174ea6;
    border-radius: 50%;
}
Circle

Common applications:

  • Profile pictures.
  • User avatars.
  • Status indicators.
  • Round buttons.
  • Decorative interface elements.
For a perfect circle, use equal width and height. Applying 50% radius to a non-square element generally creates an ellipse.

11. Understanding CSS Outline

An outline is a line drawn outside an element's border. It can be used to highlight an element.

Outline properties include:

  • outline-width
  • outline-style
  • outline-color
  • outline-offset

Example

.box {
    border: 2px solid #174ea6;
    outline: 3px dashed #007bff;
}
Border with an external outline

12. The outline Shorthand

The outline shorthand combines outline-width, outline-style and outline-color.

Syntax

selector {
    outline: width style color;
}

Example

input {
    outline: 2px solid #007bff;
}

Unlike a border, an outline does not occupy space in the CSS box model.

Outlines are often used for keyboard focus indicators. Do not remove browser focus outlines without providing a clearly visible alternative.

13. The outline-offset Property

The outline-offset property controls the distance between the border edge and the outline.

Example

.box {
    border: 2px solid #174ea6;
    outline: 3px solid #007bff;
    outline-offset: 5px;
}

A positive offset moves the outline outward. A negative offset moves it inward.

Practical Application

button:focus-visible {
    outline: 3px solid #007bff;
    outline-offset: 3px;
}

The :focus-visible pseudo-class is useful for displaying focus indicators when keyboard-style focus indication is appropriate.

14. Difference Between Border and Outline

Border Outline
Part of the element's box dimensions. Does not occupy space in the box model.
Displayed around the padding area. Drawn outside the border edge.
Can have independently styled sides. Uses one outline around the element.
Supports border-radius. Does not provide an equivalent independent corner-radius property.
Can affect layout dimensions. Does not change layout dimensions.
A border is primarily used for component boundaries. An outline is especially useful for focus indication and highlighting without changing layout.

16. Common Mistakes and Debugging

  1. Border is not visible: Check whether border-style is set to a visible value.
  2. Unexpected border thickness: Inspect border-width and shorthand declarations.
  3. Wrong border side: Check the top-right-bottom-left order.
  4. Unexpected corner rounding: Verify border-radius value order.
  5. Circle appears oval: Set equal width and height.
  6. Outline changes visual appearance unexpectedly: Inspect outline-offset and focus styles.
  7. Layout shifts after adding a border: Check box-sizing and the element's dimensions.
  8. Keyboard focus is invisible: Avoid removing outlines without an accessible replacement.

Debugging Checklist

  1. Inspect border declarations in Developer Tools.
  2. Check border-style, border-width and border-color.
  3. Inspect shorthand declarations and source order.
  4. Verify border-radius values.
  5. Check the computed box dimensions.
  6. Test keyboard navigation and focus visibility.

17. Placement Interview Questions and Answers

Q1. What is a CSS border?

Answer: A border is a visible boundary surrounding an element, positioned between its padding and margin.

Q2. What are the three main border properties?

Answer: border-width, border-style and border-color.

Q3. What is the default border-style?

Answer: none.

Q4. What is the border shorthand?

Answer: It combines border-width, border-style and border-color in one declaration.

Q5. What is border-radius?

Answer: It rounds the corners of an element's border box.

Q6. How do you create a circle using CSS?

Answer: Give an element equal width and height and apply border-radius: 50%.

Q7. What is an outline?

Answer: An outline is a line drawn outside an element's border, commonly used for highlighting and focus indication.

Q8. Does an outline occupy space in the box model?

Answer: No. An outline does not occupy layout space.

Q9. What is outline-offset?

Answer: It controls the distance between an element's border edge and its outline.

Q10. Can borders be applied to individual sides?

Answer: Yes. Use border-top, border-right, border-bottom and border-left.

Q11. What is the difference between border and outline?

Answer: Borders are part of the box dimensions and can be styled independently on each side. Outlines do not occupy layout space and are drawn outside the border.

Q12. Does border-radius affect the outline?

Answer: An outline is not independently controlled by border-radius in the same way as a border. Its shape may follow the element's rounded geometry, depending on the browser's rendering.

Q13. What happens when border-style is none?

Answer: The border is not painted, even if a width or color is specified.

Q14. How do you create a card with only a colored top border?

Answer: Use border-top with the desired width, style and color, and apply other border sides separately if required.

Q15. Why should focus outlines not be removed carelessly?

Answer: Keyboard users need a visible focus indicator to identify which interactive element is currently selected.
