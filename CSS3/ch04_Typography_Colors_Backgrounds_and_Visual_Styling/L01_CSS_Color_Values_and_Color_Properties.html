Chapter 4 – Typography, Colors, Backgrounds and Visual Styling

Learn how to define, apply and control colors in modern web interfaces.

2. CSS Color Properties

CSS provides color-related properties to control the visual appearance of HTML elements.

Property Purpose
color Sets the foreground color, commonly used for text.
background-color Sets the background color of an element.
border-color Sets the color of an element's border.
outline-color Sets the outline color.
text-decoration-color Sets the color of text decorations.
text-emphasis-color Sets the color of text emphasis marks.

Example

h1 {
    color: #174ea6;
}

.card {
    background-color: #f2f5fa;
    border: 1px solid #174ea6;
}

These properties are used in almost every frontend interface.

3. Named Colors

CSS supports predefined color names.

Examples

h1 {
    color: blue;
}

p {
    color: black;
}

button {
    background-color: green;
    color: white;
}

Common Named Colors

Color Name Example Usage
red color: red;
blue color: blue;
green color: green;
black color: black;
white color: white;
gray color: gray;
orange color: orange;
purple color: purple;
Named colors are easy to read, but hexadecimal, RGB and HSL values provide more precise control over interface colors.

4. Hexadecimal Color Values

Hexadecimal color notation represents color using red, green and blue components.

Six-Digit Syntax

color: #RRGGBB;

Each pair represents a color component in hexadecimal notation.

Component Meaning Range
RR Red 00 to FF
GG Green 00 to FF
BB Blue 00 to FF

Examples

color: #ff0000; /* Red */
color: #00ff00; /* Green */
color: #0000ff; /* Blue */
color: #000000; /* Black */
color: #ffffff; /* White */

Short Hexadecimal Notation

Three-digit hexadecimal notation is a shorthand when each color pair contains repeated digits.

#f00  /* Equivalent to #ff0000 */
#0f0  /* Equivalent to #00ff00 */
#00f  /* Equivalent to #0000ff */
#fff  /* Equivalent to #ffffff */
#000  /* Equivalent to #000000 */

Hexadecimal with Alpha

Eight-digit hexadecimal notation adds an alpha channel.

color: #RRGGBBAA;

Example:

background-color: #174ea680;

The final pair represents alpha transparency. FF is fully opaque and 00 is fully transparent.

5. RGB Color Model

RGB stands for Red, Green and Blue.

Each component traditionally uses a range from 0 to 255 in the common integer form.

Syntax

color: rgb(red, green, blue);

Examples

color: rgb(255, 0, 0);   /* Red */
color: rgb(0, 255, 0);   /* Green */
color: rgb(0, 0, 255);   /* Blue */
color: rgb(0, 0, 0);     /* Black */
color: rgb(255, 255, 255); /* White */

Understanding RGB

Value Result
rgb(255, 0, 0) Pure red
rgb(0, 255, 0) Pure green
rgb(0, 0, 255) Pure blue
rgb(255, 255, 0) Yellow
rgb(255, 255, 255) White

Modern CSS also supports percentage components and space-separated RGB syntax.

6. RGBA and Transparency

RGBA adds an alpha channel to RGB colors.

Syntax

color: rgba(red, green, blue, alpha);

The alpha component controls transparency.

Alpha Value Meaning
0 Fully transparent
0.25 25% opaque
0.5 50% opaque
0.75 75% opaque
1 Fully opaque

Example

.overlay {
    background-color: rgba(0, 0, 0, 0.5);
}

This creates a black background with 50% opacity.

Practical Demonstration

Opaque Blue
50% Alpha Blue
Alpha transparency affects the color itself. It does not automatically make the entire element's text and child elements transparent.

7. HSL Color Model

HSL stands for Hue, Saturation and Lightness.

Syntax

color: hsl(hue, saturation, lightness);
Component Meaning
Hue Color angle, commonly represented from 0 to 360 degrees.
Saturation Color intensity, expressed as a percentage.
Lightness How light or dark the color is, expressed as a percentage.

Common Hue Values

Hue Approximate Color
0° Red
60° Yellow
120° Green
180° Cyan
240° Blue
300° Magenta

Examples

color: hsl(0, 100%, 50%);    /* Red */
color: hsl(120, 100%, 50%);  /* Green */
color: hsl(240, 100%, 50%);  /* Blue */

HSL is useful when you need to create lighter or darker variations of a base color.

8. HSLA and Alpha Transparency

HSLA adds alpha transparency to HSL.

Syntax

color: hsla(hue, saturation, lightness, alpha);

Example

.overlay {
    background-color: hsla(220, 80%, 40%, 0.5);
}

This creates a blue-toned background with 50% opacity.

Modern CSS also supports the equivalent space-separated HSL syntax with an optional slash-separated alpha value.

background-color: hsl(220 80% 40% / 50%);

9. Comparing CSS Color Formats

Format Example Use
Named red Simple predefined colors.
HEX #174ea6 Common design-system colors.
HEX with alpha #174ea680 Hexadecimal colors with transparency.
RGB rgb(23, 78, 166) Red, green and blue component control.
RGBA rgba(23, 78, 166, 0.5) RGB colors with transparency.
HSL hsl(220, 76%, 37%) Adjusting hue, saturation and lightness.
HSLA hsla(220, 76%, 37%, 0.5) HSL colors with transparency.
All these formats can represent colors in CSS. Choose the format that makes your styles easiest to understand and maintain.

10. The currentColor Keyword

currentColor represents the computed value of an element's color property.

Example

.button {
    color: #174ea6;
    border: 2px solid currentColor;
    box-shadow: 0 0 0 1px currentColor;
}

The border and shadow use the same color as the text.

Another Example

.icon {
    color: green;
    fill: currentColor;
}

This is useful for keeping text, icons and borders visually consistent.

11. CSS Color Variables

CSS custom properties allow reusable color values to be maintained centrally.

Example

:root {
    --primary-color: #174ea6;
    --secondary-color: #007bff;
    --background-color: #f2f5fa;
    --text-color: #263238;
}

body {
    background-color: var(--background-color);
    color: var(--text-color);
}

button {
    background-color: var(--primary-color);
    color: white;
}

This makes it easier to maintain consistent colors throughout a website.

CSS custom properties are covered in greater detail in Chapter 10. Here, the focus is on their practical use for reusable color values.

12. Practical Example: Website Color System

Create a simple interface using a consistent color palette.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>CSS Color System</title>

    <style>
        :root {
            --primary: #174ea6;
            --accent: #007bff;
            --background: #f2f5fa;
            --text: #263238;
            --white: #ffffff;
            --border: #dce3ed;
        }

        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            padding: 20px;
            background-color: var(--background);
            color: var(--text);
            font-family: Arial, sans-serif;
        }

        .card {
            max-width: 400px;
            margin: 20px auto;
            padding: 24px;
            background-color: var(--white);
            border: 1px solid var(--border);
            border-radius: 10px;
        }

        h1 {
            color: var(--primary);
        }

        .button {
            background-color: var(--primary);
            color: white;
            border: 0;
            padding: 10px 18px;
            border-radius: 6px;
            cursor: pointer;
        }

        .button:hover {
            background-color: var(--accent);
        }
    </style>
</head>

<body>

    <article class="card">
        <h1>CSS3 Course</h1>

        <p>
            Learn CSS colors and create consistent
            website interfaces using reusable values.
        </p>

        <button class="button">
            Explore Course
        </button>
    </article>

</body>
</html>

Expected Result

  • A light-colored page background.
  • A white card with a subtle border.
  • A blue heading.
  • A blue button with a hover color.
  • Reusable color values maintained using CSS variables.

13. Accessibility and Color Contrast

Color selection affects readability and accessibility.

  • Use sufficient contrast between text and background.
  • Avoid relying only on color to communicate important information.
  • Use additional labels, icons or text for status indicators.
  • Check text readability in both light and dark backgrounds.
  • Test interface colors with a contrast checker.

WCAG Contrast Reference

Text Type Minimum Contrast Ratio for AA
Normal text 4.5:1
Large text 3:1

Large text generally means at least 18pt regular or 14pt bold under WCAG's definition.

Do not assume that a visually attractive color combination is automatically accessible. Verify the contrast ratio.

14. Common Mistakes and Debugging

  1. Incorrect hexadecimal notation: Check that HEX values use valid hexadecimal digits and the correct number of characters.
  2. Incorrect RGB component values: Verify component values are within the supported range.
  3. Confusing alpha with percentage opacity: Alpha 0.5 means 50% opacity, not 50% transparency.
  4. Using low-contrast text: Check readability against the actual background color.
  5. Using opacity on an entire component: The opacity property affects the whole element, including descendants.
  6. Repeating color values: Use CSS custom properties to maintain consistency.
  7. Assuming currentColor means black: It represents the element's computed color property.

15. Placement Interview Questions and Answers

Q1. What are the different ways to define colors in CSS?

Answer: Named colors, HEX, RGB, RGBA, HSL, HSLA and other modern CSS color notations.

Q2. What is the difference between RGB and RGBA?

Answer: RGB defines red, green and blue components. RGBA additionally provides an alpha channel for transparency.

Q3. What does the alpha value represent?

Answer: It represents the opacity of a color, from 0 for fully transparent to 1 for fully opaque in the common decimal notation.

Q4. What is the difference between HEX and RGB?

Answer: Both represent RGB color components. HEX uses hexadecimal notation, while RGB uses numeric or percentage component values.

Q5. What does HSL stand for?

Answer: Hue, Saturation and Lightness.

Q6. What is the difference between HSL and RGB?

Answer: RGB defines colors through red, green and blue components, while HSL defines them through hue, saturation and lightness.

Q7. What is currentColor?

Answer: It represents the computed value of the element's color property.

Q8. What is the difference between opacity and RGBA?

Answer: RGBA applies alpha transparency to a specific color. The opacity property affects the entire element, including its descendants.

Q9. What does #ff0000 represent?

Answer: Red in six-digit hexadecimal color notation.

Q10. What is the difference between #fff and #ffffff?

Answer: Both represent white. The first is three-digit shorthand for the second.

Q11. How can you maintain consistent colors across a website?

Answer: Define reusable CSS custom properties and use them throughout the stylesheet.

Q12. Why is color contrast important?

Answer: Sufficient contrast improves readability and accessibility for users with different visual abilities.
