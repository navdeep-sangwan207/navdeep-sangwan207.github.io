2. The font-size Property

The font-size property specifies the size of characters displayed inside an element.

Syntax

selector {
    font-size: value;
}

Example

h1 {
    font-size: 32px;
}

p {
    font-size: 16px;
}

small {
    font-size: 12px;
}

Font size affects the rendered text dimensions and contributes to the visual hierarchy of a webpage.

3. Font Size Units

CSS supports multiple units for specifying font size. The choice depends on the design and scaling requirements.

Unit Description Example
px CSS pixel unit. font-size: 16px;
em Relative to the inherited or parent font size when used for font-size. font-size: 1.2em;
rem Relative to the root element's font size. font-size: 1rem;
% Relative to the inherited font size. font-size: 120%;
vw Relative to viewport width. font-size: 3vw;

Example Using rem

html {
    font-size: 16px;
}

h1 {
    font-size: 2rem;
}

p {
    font-size: 1rem;
}

small {
    font-size: 0.875rem;
}

If the root font size is 16px, then 2rem computes to 32px and 1rem computes to 16px.

The em unit used in font-size is relative to the parent's computed font size. The rem unit is relative to the root element's computed font size.

4. Relative Font Sizing and Inheritance

Font sizes can be inherited from parent elements. Relative units can also create nested scaling effects.

Example Using em

.parent {
    font-size: 20px;
}

.child {
    font-size: 1.5em;
}

The child font size becomes 30px because 1.5 × 20px = 30px.

Example Using rem

html {
    font-size: 16px;
}

.parent {
    font-size: 20px;
}

.child {
    font-size: 1.5rem;
}

The child font size is 24px because 1.5 × 16px = 24px. It does not depend on the parent's 20px font size.

5. The font-weight Property

The font-weight property controls the thickness or visual weight of text.

Common Values

Value Description
100 Thin
200 Extra Light
300 Light
400 Normal
500 Medium
600 Semi Bold
700 Bold
800 Extra Bold
900 Black or Heavy

These numeric values are supported by CSS. The actual appearance depends on the font's available weights and browser font matching.

Example

.normal-text {
    font-weight: 400;
}

.bold-text {
    font-weight: 700;
}

.heading {
    font-weight: 600;
}

Demonstration

Keyword Values

p {
    font-weight: normal;
}

h1 {
    font-weight: bold;
}
Normal commonly corresponds to 400 and bold commonly corresponds to 700.

6. The font-style Property

The font-style property controls whether text appears normal, italic or oblique.

Common Values

Value Description
normal Displays normal upright text.
italic Uses an italic typeface when available.
oblique Uses a slanted version of the typeface when available.

Example

.normal {
    font-style: normal;
}

.italic {
    font-style: italic;
}

.oblique {
    font-style: oblique;
}
Normal text example.
Italic text example.
Italic and oblique may look similar, but italic designs often have specially designed letterforms, whereas oblique is generally a slanted form.

7. The line-height Property

The line-height property controls the height of a line box. It is commonly used to improve vertical spacing and readability.

Syntax

selector {
    line-height: value;
}

Common Values

Value Type Example
Number line-height: 1.5;
Length line-height: 24px;
Percentage line-height: 150%;

Example

p {
    font-size: 16px;
    line-height: 1.5;
}

A unitless line-height of 1.5 generally produces a line height of 24px for text with a computed font size of 16px.

Why Use Unitless Line Height?

A unitless line-height is inherited as a number, which is then multiplied by each descendant's own font size. This often makes it more flexible for nested elements. 

body {
    line-height: 1.5;
}

h1 {
    font-size: 32px;
}

p {
    font-size: 16px;
}
Avoid setting an unnecessarily small line-height because it can cause text lines to overlap.

8. The font Shorthand Property

The font shorthand allows multiple font properties to be specified in one declaration.

Syntax

font: font-style font-variant font-weight
      font-size / line-height font-family;

The style, variant and weight components are optional, but font-size and font-family are required.

Example

p {
    font: italic 700 16px/1.5 Arial, sans-serif;
}

This declaration specifies:

  • Italic font style.
  • Font weight of 700.
  • Font size of 16px.
  • Line height of 1.5.
  • Arial with a sans-serif fallback.
The font shorthand resets omitted font-related subproperties to their initial values. Use it carefully when other font settings need to be preserved.

9. The text-transform Property

The text-transform property changes the capitalization of displayed text without changing the original HTML text.

Value Purpose
none Displays text without transformation.
uppercase Displays all letters in uppercase.
lowercase Displays all letters in lowercase.
capitalize Capitalizes the beginning of words according to CSS text transformation rules.

Example

.uppercase {
    text-transform: uppercase;
}

.lowercase {
    text-transform: lowercase;
}

.capitalize {
    text-transform: capitalize;
}

10. The text-decoration Property

The text-decoration property adds decorative lines to text.

Common Values

Value Purpose
underline Places a line below text.
overline Places a line above text.
line-through Places a line through text.
none Removes text decoration.

Example

a {
    text-decoration: none;
}

.important {
    text-decoration: underline;
}

.old-price {
    text-decoration: line-through;
}

Additional Decoration Properties

.custom-link {
    text-decoration-line: underline;
    text-decoration-color: blue;
    text-decoration-style: dashed;
    text-decoration-thickness: 2px;
}
Do not remove link underlines without providing another clear visual indication that the text is interactive.

}

word-spacing

Controls the spacing between words.

12. Additional Text Formatting Properties

text-indent

Sets the indentation of the first line of text in a block.

p {
    text-indent: 30px;
}

text-shadow

Adds a shadow effect to text.

h1 {
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
}

Detailed shadow effects are covered in Lecture 8.

white-space

Controls how whitespace and line breaks are handled.

.normal-text {
    white-space: normal;
}

.single-line {
    white-space: nowrap;
}

.preserve-lines {
    white-space: pre-line;
}
Value Behaviour
normal Collapses whitespace and wraps text normally.
nowrap Collapses whitespace but prevents normal wrapping.
pre Preserves whitespace and line breaks.
pre-line Preserves line breaks while collapsing repeated spaces.
pre-wrap Preserves whitespace and line breaks while allowing wrapping.

13. Practical Example: Article Typography

Build a readable article layout using font size, weight, line height and text formatting.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Article Typography</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            padding: 24px;
            background: #f2f5fa;
            color: #263238;
            font-family: Arial, sans-serif;
            line-height: 1.6;
        }

        .article {
            max-width: 750px;
            margin: auto;
            padding: 28px;
            background: white;
            border-radius: 10px;
        }

        h1 {
            color: #174ea6;
            font-size: 32px;
            font-weight: 700;
            line-height: 1.2;
        }

        h2 {
            font-size: 22px;
            font-weight: 600;
        }

        .subtitle {
            font-size: 14px;
            color: #666;
        }

        p {
            font-size: 16px;
            line-height: 1.7;
        }

        .highlight {
            font-weight: 700;
            text-decoration: underline;
        }

        .category {
            text-transform: uppercase;
            letter-spacing: 1px;

        }

<body>

    <article class="article">

        <div class="category">

14. Common Mistakes and Debugging

  1. Using excessive font sizes: Maintain a consistent typographic scale.
  2. Using too many font weights: Use only the weights required by the design.
  3. Setting line-height too small: Ensure adjacent text lines do not overlap.
  4. Confusing em and rem: Remember that em for font-size depends on the parent, while rem depends on the root.
  5. Using excessive letter spacing: Test text readability at normal viewing sizes.
  6. Removing link decoration without replacement: Keep interactive elements visually identifiable.
  7. Using the font shorthand carelessly: Remember that omitted font subproperties are reset.
  8. Using fixed font sizes everywhere: Consider relative units and responsive typography where appropriate.

15. Placement Interview Questions and Answers

Q1. What does font-size do?

Answer: It specifies the size of characters displayed by an element.

Q2. What is the difference between px, em and rem?

Answer: px is an absolute CSS length unit. em used in font-size is relative to the parent's computed font size, while rem is relative to the root element's computed font size.

Q3. What is font-weight?

Answer: It controls the thickness of text. Common values include 400 for normal and 700 for bold.

Q4. What is the difference between font-style and font-weight?

Answer: font-style controls normal, italic or oblique appearance. font-weight controls the thickness of characters.

Q5. What is line-height?

Answer: It controls the height of line boxes and the vertical spacing of text lines.

Q6. Why is unitless line-height useful?

Answer: It is inherited as a multiplier, so each child element applies it to its own font size.

Q7. What is the font shorthand?

Answer: It combines several font properties, including style, weight, size, line height and family, into one declaration.

Q8. What does text-transform do?

Answer: It changes the capitalization of displayed text without modifying the original HTML text.

Q9. What is text-decoration?

Answer: It controls decorative lines such as underline, overline and line-through.

Q10. What is letter-spacing?

Answer: It controls the spacing between characters.

Q11. What is word-spacing?

Answer: It controls the spacing between words.

Q12. What is white-space: nowrap?

Answer: It prevents normal text wrapping while collapsing whitespace.

Q13. What happens when font-weight: 600 is applied?

Answer: The browser attempts to use a font face with weight 600 or an appropriate available font weight.

Q14. Does text-transform change the original HTML content?

Answer: No. It changes the visual presentation of text.

Q15. Why is line-height important for paragraphs?

Answer: Appropriate line height improves readability by providing sufficient vertical spacing between lines.
