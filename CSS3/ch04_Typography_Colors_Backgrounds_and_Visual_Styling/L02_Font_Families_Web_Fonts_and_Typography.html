Lecture 2: Font Families, Web Fonts and Typography

Chapter 4 – Typography, Colors, Backgrounds and Visual Styling

Learn to select, load and manage fonts for professional web interfaces.

1. Learning Objectives

  • Understand the CSS font-family property.
  • Identify the five generic font families.
  • Understand font fallback stacks.
  • Differentiate web-safe fonts and web fonts.
  • Load external fonts using Google Fonts.
  • Load locally stored fonts using @font-face.
  • Understand font file formats and font loading.
  • Choose appropriate fonts for responsive interfaces.

2. What is Typography?

Typography is the arrangement and presentation of text. In web development, typography affects readability, visual hierarchy, usability and the overall appearance of an interface.

CSS provides several font-related properties, including:

Property Purpose
font-family Selects the typeface.
font-size Controls the size of text.
font-weight Controls the thickness of characters.
font-style Controls normal, italic or oblique styling.
line-height Controls the height of text lines.
font-variant Controls alternate typographic forms, such as small capitals.

This lecture focuses on font selection and font loading. Detailed font sizing and text formatting are covered in the next lecture.

3. The font-family Property

The font-family property specifies which typeface should be used to display text.

Syntax

selector {
    font-family: font-name, fallback-family;
}

Example

body {
    font-family: Arial, sans-serif;
}

h1 {
    font-family: Georgia, serif;
}

code {
    font-family: "Courier New", monospace;
}

Font names containing spaces should be enclosed in quotation marks.

Live Font Examples

Serif: Professional document-style typography.
Sans-serif: Clean typography for modern web interfaces.
Monospace: int main() { return 0; }
Cursive: Decorative handwritten-style text.
Fantasy: Decorative display typography.

4. Five Generic Font Families

CSS defines generic font-family categories. The browser selects an available font that belongs to the requested category.

Generic Family Description Typical Use
serif Characters have small finishing strokes. Articles and formal documents.
sans-serif Characters do not have finishing strokes. Websites and dashboards.
monospace Each character occupies equal horizontal space. Code editors and programming examples.
cursive Fonts designed to resemble handwriting. Decorative text.
fantasy Decorative or unusual typefaces. Creative headings and special designs.

Example

.article {
    font-family: Georgia, serif;
}

.dashboard {
    font-family: Arial, sans-serif;
}

.code {
    font-family: Consolas, monospace;
}
Generic families are fallback categories, not specific font files.

5. Web-Safe Fonts

Web-safe fonts are commonly available on many operating systems. They can be used without downloading an external font file.

Common Examples

Font Typical Category
Arial Sans-serif
Verdana Sans-serif
Tahoma Sans-serif
Georgia Serif
Times New Roman Serif
Courier New Monospace

Example

body {
    font-family: Arial, Helvetica, sans-serif;
}

The browser tries Arial first, then Helvetica, and finally an available sans-serif font.

6. Font Fallback Stacks

A font fallback stack contains multiple font choices. If the first font is unavailable, the browser tries the next available font.

Example

body {
    font-family:
        "Segoe UI",
        Arial,
        Helvetica,
        sans-serif;
}

How It Works

  1. The browser checks whether Segoe UI is available.
  2. If unavailable, it checks Arial.
  3. If Arial is unavailable, it checks Helvetica.
  4. If none of these are available, it uses a generic sans-serif font.

Common Fallback Stacks

/* Sans-serif */
font-family: Arial, Helvetica, sans-serif;

/* Serif */
font-family: Georgia, "Times New Roman", serif;

/* Monospace */
font-family: "Courier New", Consolas, monospace;

/* System interface font */
font-family: system-ui, sans-serif;
A fallback stack improves compatibility because the exact same font may not be installed on every user's device.

7. Web Fonts

Web fonts are font files that a website loads for use in its pages. They allow developers to use typefaces that may not be installed on the visitor's computer.

Common web font formats include:

Format Description
WOFF Web Open Font Format.
WOFF2 Modern compressed web font format, generally preferred where supported.
TTF TrueType Font.
OTF OpenType Font.

WOFF2 is generally the preferred format for modern web delivery because of its compression and browser support.

Only use font files that you are licensed or otherwise permitted to distribute and embed in your website.

8. Loading Fonts Using Google Fonts

Google Fonts provides hosted font families that can be included in a website.

Step 1: Choose a Font

Visit Google Fonts, select a font family and choose the required font weights and styles.

Step 2: Add the Font Link

For example, to load the Roboto font, add the following link inside the HTML head section: 

<link rel="preconnect"
      href="https://fonts.googleapis.com">

<link rel="preconnect"
      href="https://fonts.gstatic.com"
      crossorigin>

<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;700&display=swap"
      rel="stylesheet">

Step 3: Apply the Font

body {
    font-family: "Roboto", sans-serif;
}

Complete Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Google Fonts Example</title>

    <link rel="preconnect"
          href="https://fonts.googleapis.com">

    <link rel="preconnect"
          href="https://fonts.gstatic.com"
          crossorigin>

    <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;700&display=swap"
          rel="stylesheet">

    <style>
        body {
            font-family: "Roboto", sans-serif;
            padding: 25px;
        }

        h1 {
            font-weight: 700;
        }

        p {
            font-weight: 400;
        }
    </style>
</head>

<body>

    <h1>Welcome to CSS3</h1>

    <p>
        This page uses the Roboto font loaded from Google Fonts.
    </p>

</body>
</html>

Expected Result

  • The page requests the Roboto font from Google Fonts.
  • The heading uses the selected bold weight.
  • The paragraph uses the regular weight.
An external font requires a network connection unless it is already cached. Provide a fallback font in case the external request fails.

9. Loading Local Fonts Using @font-face

The @font-face rule allows developers to define and use font files stored within their own project.

Syntax

@font-face {
    font-family: "MyCustomFont";
    src: url("fonts/my-font.woff2") format("woff2");
    font-weight: normal;
    font-style: normal;
}

Applying the Font

body {
    font-family: "MyCustomFont", sans-serif;
}

Example Project Structure

font-project/
│
├── index.html
├── style.css
│
└── fonts/
    └── my-font.woff2

style.css

@font-face {
    font-family: "MyCustomFont";
    src: url("fonts/my-font.woff2") format("woff2");
    font-weight: 400;
    font-style: normal;
    font-display: swap;
}

body {
    font-family: "MyCustomFont", Arial, sans-serif;
}

The font URL is relative to the location of the CSS file. If the stylesheet is in another folder, adjust the path accordingly.

Using Multiple Font Weights

@font-face {
    font-family: "MyCustomFont";
    src: url("fonts/my-font-regular.woff2") format("woff2");
    font-weight: 400;
    font-style: normal;
    font-display: swap;
}

@font-face {
    font-family: "MyCustomFont";
    src: url("fonts/my-font-bold.woff2") format("woff2");
    font-weight: 700;
    font-style: normal;
    font-display: swap;
}

body {
    font-family: "MyCustomFont", sans-serif;
}

h1 {
    font-weight: 700;
}
Declare the correct font-weight and font-style for each font file. This helps the browser select the appropriate font face.

10. The font-display Property

The font-display descriptor in @font-face controls how text is displayed while a web font is loading.

Value General Behaviour
auto Uses browser-defined behaviour.
block Uses a short block period before fallback text is displayed.
swap Displays fallback text immediately and swaps to the web font when available.
fallback Uses a short block period and limited swap period.
optional Allows the browser to decide whether the web font should be used based on conditions such as connection speed.

Example

@font-face {
    font-family: "MyCustomFont";
    src: url("fonts/my-font.woff2") format("woff2");
    font-display: swap;
}

The swap value is commonly used to keep text visible while the custom font loads.

11. System Font Stack

A system font stack uses the operating system's interface font where available.

Example

body {
    font-family:
        system-ui,
        -apple-system,
        BlinkMacSystemFont,
        "Segoe UI",
        sans-serif;
}

Benefits include:

  • Uses familiar system typography.
  • Can reduce the need to download external font files.
  • Provides a native-looking interface.
  • Can improve initial rendering performance.

12. Practical Example: Professional Dashboard Typography

Create a simple dashboard with a consistent font family and fallback stack.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Dashboard Typography</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            padding: 24px;
            background: #f2f5fa;
            color: #263238;
            font-family:
                "Segoe UI",
                Arial,
                Helvetica,
                sans-serif;
        }

        .dashboard {
            max-width: 800px;
            margin: auto;
        }

        .dashboard h1 {
            color: #174ea6;
        }

        .card {
            background: white;
            padding: 20px;
            margin: 16px 0;
            border-radius: 8px;
        }

        .card h2 {
            margin-top: 0;
        }

        .card p {
            color: #555;
        }

        .button {
            background: #174ea6;
            color: white;
            border: none;
            padding: 10px 16px;
            border-radius: 5px;
            cursor: pointer;
            font: inherit;
        }
    </style>
</head>

<body>

    <main class="dashboard">

        <h1>My Learning Dashboard</h1>

        <section class="card">
            <h2>CSS3 Course</h2>

            <p>
                Learn CSS properties, layouts and
                responsive web development.
            </p>

            <button class="button">
                Continue Learning
            </button>
        </section>

    </main>

</body>
</html>

Expected Result

  • A dashboard with a consistent sans-serif typeface.
  • A blue heading with a white content card.
  • Readable paragraph text.
  • A button that inherits the selected font through font: inherit.

13. Font Loading Performance and Best Practices

  • Prefer WOFF2 for modern web font delivery.
  • Load only the font families and weights actually required.
  • Use suitable fallback fonts.
  • Use font-display: swap where appropriate.
  • Avoid loading many external font families unnecessarily.
  • Use locally hosted fonts when appropriate for the project.
  • Check font licensing before embedding font files.
  • Test the page when external font requests fail.
Excessive font files and unnecessary font weights can increase page loading time. A frontend developer should balance visual design with performance.

14. Common Mistakes and Debugging

  1. Missing quotation marks: Font names containing spaces should be quoted, such as "Times New Roman".
  2. Missing generic fallback: Always include an appropriate generic family at the end of the stack.
  3. Incorrect font path: Check the relative URL from the CSS file to the font file.
  4. Incorrect font weight: Verify that the requested weight is available or declared.
  5. Missing font format declaration: When using @font-face, provide a valid source and suitable format hint.
  6. External font not loading: Check the network request, URL, browser console and internet connection.
  7. Too many font requests: Reduce unnecessary families and font weights.

Debugging with Browser Developer Tools

  1. Open the page in a browser.
  2. Press F12 to open Developer Tools.
  3. Select an element in the Elements panel.
  4. Inspect its computed font-family and font-weight.
  5. Check the Network panel for failed font requests.
  6. Correct the font path or stylesheet declaration.

15. Placement Interview Questions and Answers

Q1. What is the font-family property?

Answer: It specifies the typeface used to display text in an element.

Q2. What are the five generic font families in CSS?

Answer: Serif, sans-serif, monospace, cursive and fantasy.

Q3. What is the difference between serif and sans-serif?

Answer: Serif fonts have small finishing strokes on characters, while sans-serif fonts do not.

Q4. What is a monospace font?

Answer: A font in which each character occupies the same horizontal advance width.

Q5. What is a font fallback stack?

Answer: It is a list of fonts that the browser tries in order until it finds an available font.

Q6. What is the difference between web-safe fonts and web fonts?

Answer: Web-safe fonts are commonly available on user devices. Web fonts are loaded from external or local font files.

Q7. What is Google Fonts?

Answer: It is a font library that provides hosted fonts which websites can load and use.

Q8. What is @font-face?

Answer: It is a CSS at-rule used to define custom fonts from font resources.

Q9. What is WOFF2?

Answer: It is a compressed web font format commonly used to deliver fonts efficiently to browsers.

Q10. What is font-display: swap?

Answer: It allows fallback text to be displayed while the custom font loads, then swaps to the custom font when available.

Q11. Why should we use fallback fonts?

Answer: They ensure text remains readable if the preferred font is unavailable or fails to load.

Q12. What is the system-ui font family?

Answer: It selects the system's default user-interface font.

Q13. How can you check whether a custom font has loaded?

Answer: Inspect the computed styles and font requests using browser Developer Tools.

Q14. Why should a website avoid loading too many font weights?

Answer: Each additional font resource can increase network requests and page loading cost.

Q15. What happens if the first font in a font-family declaration is unavailable?

Answer: The browser attempts to use the next font in the declared fallback list.
