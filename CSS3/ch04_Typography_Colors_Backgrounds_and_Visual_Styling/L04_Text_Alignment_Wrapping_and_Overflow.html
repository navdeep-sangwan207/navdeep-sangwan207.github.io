2. The text-align Property

The text-align property controls the horizontal alignment of inline content inside a block container.

Syntax

selector {
    text-align: value;
}

Common Values

Value Purpose
left Aligns text to the left.
right Aligns text to the right.
center Centers text.
justify Adjusts spacing so lines align with both container edges, except typically the final line.
start Aligns to the logical start edge based on text direction.
end Aligns to the logical end edge based on text direction.

Example

.left {
    text-align: left;
}

.center {
    text-align: center;
}

.right {
    text-align: right;
}

.justify {
    text-align: justify;
}

Demonstration

Left aligned text – used in many normal content layouts.
Center aligned text – commonly used for headings.
Right aligned text – useful for certain labels and numeric content.
Justified text adjusts the spacing between words so that lines generally align with both edges of the container. It is sometimes used in long-form documents and articles.
For international layouts, logical values such as start and end are generally more adaptable than hard-coded left and right.

3. The text-align-last Property

The text-align-last property controls the alignment of the last line of a block or line box.

Example

.article {
    text-align: justify;
    text-align-last: right;
}

The paragraph is justified, while its last line is aligned to the right.

Common values include:

  • auto
  • left
  • right
  • center
  • justify
  • start
  • end

4. The vertical-align Property

The vertical-align property controls the vertical alignment of inline-level, inline-block and table-cell elements.

Common Values

Value Purpose
baseline Aligns the element's baseline with the parent's baseline.
middle Aligns the middle of the element with the parent's baseline plus half the parent's x-height.
top Aligns the top of the element with the top of the line box.
bottom Aligns the bottom of the element with the bottom of the line box.
sub Aligns the element as subscript.
super Aligns the element as superscript.

Example

img {
    vertical-align: middle;
}

.icon {
    vertical-align: middle;
}

td {
    vertical-align: top;
}

Practical Example

<p>
    Course Status:
    <img src="status-icon.png"
         alt=""
         width="16"
         height="16"
         style="vertical-align: middle;">
    Completed
</p>
vertical-align does not generally center a block element inside another block element. Use Flexbox or Grid for common block-level layout alignment.

5. The white-space Property

The white-space property controls how spaces, tabs and line breaks are handled inside an element.

Common Values

Value Whitespace Behaviour Wrapping Behaviour
normal Collapses repeated whitespace. Wraps normally.
nowrap Collapses repeated whitespace. Prevents normal wrapping.
pre Preserves whitespace and line breaks. Does not wrap normally.
pre-wrap Preserves whitespace and line breaks. Allows wrapping.
pre-line Collapses repeated spaces but preserves line breaks. Wraps normally.

Example

.normal {
    white-space: normal;
}

.no-wrap {
    white-space: nowrap;
}

.preserve {
    white-space: pre;
}

.preserve-wrap {
    white-space: pre-wrap;
}

.preserve-lines {
    white-space: pre-line;
}

Demonstration

Normal:

This text uses normal whitespace handling and wraps according to the available width.

Pre-wrap:

First line Second line with extra spaces Third line

Use pre-wrap when displaying user-entered text or content where meaningful spaces and line breaks should be retained while still allowing wrapping.

6. Normal Text Wrapping

Browsers normally wrap text at appropriate break opportunities when content reaches the available width.

Example

.content {
    width: 300px;
    white-space: normal;
}

Normal wrapping helps paragraphs adapt to smaller screens without requiring horizontal scrolling.

Why It Matters

  • Prevents long paragraphs from exceeding container width.
  • Improves mobile readability.
  • Helps cards and content sections adapt to different widths.
  • Reduces unwanted horizontal scrolling.

7. The overflow-wrap Property

The overflow-wrap property controls whether the browser may break an otherwise unbreakable word or string to prevent overflow.

Common Values

Value Behaviour
normal Uses normal line-breaking opportunities.
break-word Allows emergency breaking of long strings when needed.
anywhere Allows emergency break opportunities anywhere when needed and considers them during min-content sizing.

Example

.description {
    overflow-wrap: break-word;
}

.card-content {
    overflow-wrap: anywhere;
}

Practical Use Case

A long email address, URL or generated identifier may overflow a small card. overflow-wrap helps prevent this.

Long content: thisisaverylongidentifierwithoutnormalwordbreakopportunitieswhichmayoverflowacontainer
overflow-wrap: anywhere is useful for flexible cards and user-generated content that may contain long unbroken strings.

8. The word-break Property

The word-break property controls how words are broken when they reach the edge of a line.

Common Values

Value Behaviour
normal Uses the normal line-breaking rules.
break-all Allows text to break between characters when needed.
keep-all Prevents normal word breaks for CJK text, except where permitted by other line-breaking rules.

Example

.long-string {
    word-break: break-all;
}

Demonstration

Thisisaverylongcontinuousstringthatcanbebrokenbetweencharacters.
word-break: break-all can break words at inconvenient positions. For ordinary English text and long URLs, overflow-wrap: break-word or anywhere is usually a better choice.

9. The hyphens Property

The hyphens property controls whether words may be hyphenated when wrapping.

Value Behaviour
none Prevents automatic hyphenation.
manual Allows breaks at explicitly provided hyphenation opportunities.
auto Allows browser-controlled automatic hyphenation when language and dictionary support are available.

Example

p {
    hyphens: auto;
}

For reliable automatic hyphenation, specify the language of the text using the HTML lang attribute. 

<html lang="en">
<p>
    Responsive typography improves readability.
</p>
</html>

10. The text-overflow Property

The text-overflow property specifies how clipped inline text is visually indicated when it overflows its container.

Common Values

Value Behaviour
clip Clips overflowing text.
ellipsis Displays an ellipsis to indicate clipped text.

Important: Three Properties Together

A common single-line truncation technique uses three declarations together. 

.title {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

Demonstration

This is a very long course title that will be truncated when it exceeds the available width.

Why Are All Three Needed?

  • white-space: nowrap prevents the text from wrapping.
  • overflow: hidden clips content outside the container.
  • text-overflow: ellipsis displays the ellipsis indicator.
text-overflow does not create overflow by itself. The content must actually overflow a constrained inline direction for the effect to appear.

11. Multi-Line Text Truncation

Single-line ellipsis is straightforward. Multi-line truncation can be implemented using line clamping.

Example

.description {
    display: -webkit-box;
    -webkit-box-orient: vertical;
    -webkit-line-clamp: 3;
    overflow: hidden;
}

This commonly used pattern displays up to three lines and clips additional content.

Demonstration

CSS is used to control the visual appearance of websites. It provides properties for layout, typography, colors, spacing, backgrounds and responsive behaviour. Text truncation is useful when displaying descriptions inside cards and dashboard components with limited space. Additional content is clipped after the specified number of lines.

The line-clamp pattern shown here is widely used in production interfaces. Test it in the browsers targeted by your project.

12. Overflow Behaviour and Text Containers

Text can overflow when its content is larger than the available space in its container.

The general overflow property controls how overflowing content is handled.

Value Behaviour
visible Overflowing content remains visible.
hidden Overflowing content is clipped.
scroll Provides scrollable overflow, with scrollbars or other scrolling mechanisms as appropriate.
auto Provides scrolling when required.

Example

.content {
    width: 250px;
    height: 100px;
    overflow: auto;
}

A constrained content area can become scrollable when its content exceeds the available dimensions.

Do not apply overflow: hidden indiscriminately. It may clip text, focus indicators, menus or other important interface elements.

13. Practical Example: Responsive Course Cards

Create course cards that handle long titles and descriptions without breaking the layout.

Complete HTML and CSS

<head>

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Responsive Course Cards</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            padding: 24px;

            font-family: Arial, sans-serif;
        }

            max-width: 900px;
            margin: auto;

            display: grid;

Expected Result

  • Responsive course cards arranged using CSS Grid.
  • Long titles truncated with an ellipsis.

  • Long unbroken content prevented from overflowing.
  • Cards adapt to smaller screen widths.
The min-width: 0 declaration allows grid items to shrink below their automatic minimum content size when necessary. This is particularly useful when handling long text.

14. Common Mistakes and Debugging

  1. Using vertical-align for block centering: Use Flexbox or Grid for common block-level alignment.
  2. Using text-align to position an entire container: text-align aligns inline content inside the container, not the container itself.
  3. Using text-overflow without overflow handling: Add overflow: hidden and a suitable white-space setting for single-line truncation.
  4. Using word-break: break-all unnecessarily: Prefer overflow-wrap for ordinary long unbroken strings.
  5. Forgetting container constraints: Text truncation needs an actual size constraint that creates overflow.
  6. Using nowrap on all paragraphs: This can cause horizontal scrolling on mobile devices.
  7. Ignoring long user-generated content: Use suitable wrapping rules for URLs, identifiers and email addresses.
  8. Clipping important controls: Check whether overflow rules hide menus, tooltips or keyboard focus indicators.

Debugging with Developer Tools

  1. Open the page in a browser and press F12.
  2. Select the element whose text is overflowing.
  3. Inspect its computed width and height.
  4. Check white-space, overflow and text-overflow.
  5. Inspect the parent container's width and min-width.
  6. Test the element at different viewport widths.

15. Placement Interview Questions and Answers

Q1. What is the text-align property?

Answer: It controls the horizontal alignment of inline content inside a block container.

Q2. What is the difference between text-align and vertical-align?

Answer: text-align controls horizontal alignment of inline content. vertical-align controls the vertical alignment of inline-level, inline-block and table-cell elements.

Q3. What does text-align: justify do?

Answer: It adjusts spacing between words so lines generally align with both edges of the container.

Q4. What is white-space: nowrap?

Answer: It prevents normal text wrapping while collapsing repeated whitespace.

Q5. What is the difference between pre and pre-wrap?

Answer: Both preserve whitespace and line breaks. pre does not wrap normally, while pre-wrap allows wrapping.

Q6. What is overflow-wrap?

Answer: It allows otherwise unbreakable strings to break when necessary to prevent overflow.

Q7. What is the difference between word-break and overflow-wrap?

Answer: word-break controls general word-breaking behaviour, while overflow-wrap provides emergency breaking of otherwise unbreakable strings to prevent overflow.

Q8. What does word-break: break-all do?

Answer: It allows text to break between characters when needed.

Q9. What is text-overflow: ellipsis?

Answer: It displays an ellipsis to indicate that overflowing text has been clipped.

Q10. Which properties are commonly used for single-line ellipsis?

Answer: white-space: nowrap, overflow: hidden and text-overflow: ellipsis.

Q11. How can you truncate text after three lines?

Answer: Use a line-clamp pattern with display: -webkit-box, -webkit-box-orient: vertical, -webkit-line-clamp: 3 and overflow: hidden.

Q12. Does text-overflow automatically hide overflowing text?

Answer: No. Overflow must be constrained and clipped separately, commonly using overflow: hidden.

Q13. How do you prevent a long URL from breaking a card layout?

Answer: Use overflow-wrap: break-word or overflow-wrap: anywhere, depending on the required layout behaviour.

Q14. What is the purpose of text-align-last?

Answer: It controls the alignment of the last line of a block or line box.

Q15. Why can text overflow occur inside a CSS Grid item?

Answer: Grid items have automatic minimum sizing behaviour. A long unbreakable string can prevent the item from shrinking. min-width: 0 and appropriate wrapping rules can solve this.
