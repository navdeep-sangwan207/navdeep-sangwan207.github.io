2. Understanding CSS Shadows

CSS shadows create the visual appearance of depth by displaying shaded areas around elements or text.

Shadows are commonly used for:

  • Cards and content panels.
  • Navigation bars.
  • Buttons and form controls.
  • Dropdown menus and popups.
  • Modal dialogs.
  • Text headings and decorative effects.

CSS provides two main shadow properties:

  • box-shadow – applies shadows to an element's box.
  • text-shadow – applies shadows to text.

3. The box-shadow Property

The box-shadow property adds shadow effects around an element's box.

Syntax

box-shadow:
    offset-x
    offset-y
    blur-radius
    spread-radius
    color;

Not every component is compulsory.

Example

.card {
    box-shadow: 5px 5px 10px gray;
}

Explanation:

  • 5px – horizontal offset.
  • 5px – vertical offset.
  • 10px – blur radius.
  • gray – shadow color.
Basic Box Shadow

4. Horizontal and Vertical Shadow Offsets

The first two values of box-shadow determine the horizontal and vertical positions.

Value Effect
Positive offset-x Moves shadow to the right.
Negative offset-x Moves shadow to the left.
Positive offset-y Moves shadow downward.
Negative offset-y Moves shadow upward.

Examples

.right-shadow {
    box-shadow: 8px 0 5px gray;
}

.left-shadow {
    box-shadow: -8px 0 5px gray;
}

.bottom-shadow {
    box-shadow: 0 8px 5px gray;
}

.top-shadow {
    box-shadow: 0 -8px 5px gray;
}

5. Blur Radius

The blur radius controls how soft or spread out the shadow appears.

Example

.shadow-small {
    box-shadow: 0 4px 2px gray;
}

.shadow-medium {
    box-shadow: 0 4px 10px gray;
}

.shadow-large {
    box-shadow: 0 4px 25px gray;
}

A larger blur radius generally creates a softer, more diffused shadow.

The blur radius cannot be negative.

6. Spread Radius

The spread radius controls how much the shadow expands or contracts before blurring.

Example

.shadow-small-spread {
    box-shadow: 0 4px 10px 0 gray;
}

.shadow-large-spread {
    box-shadow: 0 4px 10px 5px gray;
}

.shadow-negative-spread {
    box-shadow: 0 4px 10px -3px gray;
}

A positive spread expands the shadow. A negative spread contracts it.

7. Shadow Color and Transparency

Shadow colors can use named colors, HEX, RGB, RGBA and other supported CSS color formats.

Example

.card {
    box-shadow:
        0 5px 15px rgba(0,0,0,0.15);
}

RGBA is useful because it controls the transparency of the shadow color.

Subtle shadows using partially transparent colors are generally more suitable for professional interface design than dark, heavily saturated shadows.

8. Inset Box Shadow

The inset keyword creates an inner shadow inside the element's box.

Example

.box {
    box-shadow:
        inset 0 0 12px rgba(0,0,0,0.3);
}
Inset Shadow

Applications:

  • Pressed buttons.
  • Input fields.
  • Recessed panels.
  • Inner card effects.

9. Multiple Box Shadows

CSS allows multiple shadows on one element. Separate each shadow using a comma.

Example

.card {
    box-shadow:
        0 4px 8px rgba(0,0,0,0.12),
        0 12px 24px rgba(23,78,166,0.15);
}
Multiple Layered Shadows

Multiple shadows are useful for creating more natural depth and elevation effects.

The first listed shadow is painted on top of the subsequent shadows.

10. The text-shadow Property

The text-shadow property adds a shadow behind text characters.

Syntax

text-shadow:
    offset-x
    offset-y
    blur-radius
    color;

Example

h1 {
    text-shadow: 2px 3px 4px gray;
}

Explanation:

  • 2px – horizontal offset.
  • 3px – vertical offset.
  • 4px – blur radius.
  • gray – shadow color.

Demonstration

CSS Text Shadow

11. Multiple Text Shadows

Multiple text shadows can be specified using comma-separated values.

Example

h1 {
    color: white;

    text-shadow:
        1px 1px 2px black,
        0 0 10px #007bff,
        0 0 20px #174ea6;
}

Multiple shadows can create glowing, layered or decorative text effects.

12. Understanding the opacity Property

The opacity property controls the transparency of an entire element, including its contents.

Syntax

selector {
    opacity: value;
}

Valid range:

  • 0 – completely transparent.
  • 0.5 – 50% opacity.
  • 1 – completely opaque.

Example

.box {
    opacity: 0.5;
}
This entire element has 50% opacity.
Opacity affects the complete element and its descendants. Text inside a partially transparent element also becomes transparent.

13. Difference Between Opacity and RGBA Transparency

Both opacity and alpha colors can create transparency, but they behave differently.

Using Opacity

.card {
    background-color: blue;
    opacity: 0.5;
}

The entire card, including its text and child elements, becomes partially transparent.

Using RGBA Background

.card {
    background-color: rgba(0, 0, 255, 0.5);
    color: black;
}

Only the background color becomes transparent. The text remains fully opaque.

14. Transparent Backgrounds with Overlay Effects

Transparent colors are frequently used to place readable text over background images.

Example

.hero-content {
    background-color: rgba(0,0,0,0.55);
    color: white;
    padding: 25px;
}

This creates a dark transparent panel while keeping the text fully visible.

Other applications include:

  • Modal overlays.
  • Image captions.
  • Dropdown menus.
  • Highlighted panels.
  • Navigation backgrounds.

16. Common Mistakes and Debugging

  1. Shadow does not appear: Check box-shadow syntax and computed styles.
  2. Shadow looks too dark: Reduce alpha transparency in the shadow color.
  3. Shadow appears too large: Adjust blur and spread radius.
  4. Text becomes transparent: Check whether opacity is applied to a parent element.
  5. Text is difficult to read: Avoid excessive text-shadow and maintain sufficient contrast.
  6. Shadow is clipped: Inspect parent containers for overflow: hidden or overflow: clip.
  7. Multiple shadows look incorrect: Check comma-separated shadow declarations and their order.
  8. Hover effects feel abrupt: Use suitable transition properties and durations.

Debugging Checklist

  1. Inspect box-shadow and text-shadow declarations.
  2. Check offset, blur and spread values.
  3. Inspect shadow color and alpha values.
  4. Check opacity on parent and child elements.
  5. Inspect overflow on ancestor containers.
  6. Test hover and focus states.

17. Placement Interview Questions and Answers

Q1. What is box-shadow?

Answer: It adds shadow effects around an element's box.

Q2. What are the components of box-shadow?

Answer: Horizontal offset, vertical offset, optional blur radius, optional spread radius, color and optional inset keyword.

Q3. What is the difference between blur radius and spread radius?

Answer: Blur radius controls the softness of the shadow. Spread radius controls its expansion or contraction.

Q4. Can box-shadow have negative values?

Answer: Horizontal and vertical offsets and spread radius can be negative. Blur radius cannot be negative.

Q5. What is an inset shadow?

Answer: It is an inner shadow displayed inside an element's box.

Q6. Can multiple box shadows be applied?

Answer: Yes. Multiple shadows can be separated using commas.

Q7. What is text-shadow?

Answer: It adds a shadow effect behind text characters.

Q8. What is opacity?

Answer: It controls the transparency of an entire element, including its descendants.

Q9. What is the valid opacity range?

Answer: Values from 0 to 1, where 0 is transparent and 1 is fully opaque.

Q10. What is the difference between opacity and RGBA?

Answer: Opacity affects the entire element and its descendants, whereas RGBA alpha controls the transparency of the specified color.

Q11. How do you create a soft card shadow?

Answer: Use a moderate blur radius with a partially transparent shadow color, for example box-shadow: 0 5px 15px rgba(0,0,0,0.12).

Q12. Why might a shadow not be visible?

Answer: It may be overridden, clipped by an ancestor's overflow property, or hidden by another element.

Q13. Does opacity: 0 remove an element from the layout?

Answer: No. The element remains in the layout and can still receive pointer and keyboard interaction unless other properties or attributes change that behaviour.

Q14. How can you make only the background transparent?

Answer: Use an alpha color such as rgba() for background-color instead of applying opacity to the complete element.

Q15. What is the purpose of multiple shadows?

Answer: They help create layered depth and more detailed visual effects.
