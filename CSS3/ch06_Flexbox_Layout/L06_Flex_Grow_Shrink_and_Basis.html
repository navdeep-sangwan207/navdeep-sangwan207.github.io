2. Understanding Flex Item Sizing

Flexbox does more than arrange items in a row or column. It can also calculate how much space each item should occupy.

Three important properties control this behaviour:

Property Purpose
flex-grow Controls how items share positive free space.
flex-shrink Controls how items share negative free space.
flex-basis Defines the initial main size used in Flexbox sizing.

Basic Syntax

.item {
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: 200px;
}
These properties operate on the main axis. For a row container, they affect the horizontal main size in the usual horizontal writing mode. For a column container, they affect the vertical main size.

3. flex-grow Property

The flex-grow property determines how flex items share positive free space when the total base sizes are smaller than the available inner main size.

Syntax

.item {
    flex-grow: 1;
}

The default value is 0.

Example 1: flex-grow: 0

.item {
    flex-grow: 0;
}

The item does not receive a share of positive free space through flex growth.

Example 2: flex-grow: 1

.item {
    flex-grow: 1;
}

Items with equal grow factors share positive free space equally, subject to sizing constraints.

The second item receives twice the share of positive free space received by either of the other two items, assuming no min/max constraints interfere.

Grow Factor Calculation

Suppose the available positive free space is 400px and three items have grow factors:

  • Item A: 1
  • Item B: 2
  • Item C: 1

Total grow factor = 1 + 2 + 1 = 4.

Item Grow Factor Extra Space
A 1 100px
B 2 200px
C 1 100px
This is the basic proportional calculation. The actual Flexbox algorithm also accounts for min/max sizes, freezing items and other constraints.

4. flex-shrink Property

The flex-shrink property determines how flex items share negative free space when their total flex base sizes exceed the available inner main size.

Syntax

.item {
    flex-shrink: 1;
}

The default value is 1.

Example 1: flex-shrink: 1

.item {
    flex-shrink: 1;
    flex-basis: 220px;
}

Items can shrink when the available space is insufficient.

Example 2: flex-shrink: 0

.item {
    flex-shrink: 0;
    flex-basis: 220px;
}

The item does not shrink through the flex-shrink mechanism. It may cause the container to overflow.

How Shrinking Is Distributed

Shrinking is not necessarily divided equally by the numerical shrink factors alone. Flexbox uses scaled shrink factors based on each item's flex base size.

Basic calculation: 

Scaled shrink factor =
flex-shrink × flex base size

Example

Suppose two items have:

  • Item A: flex-basis 200px, flex-shrink 1.
  • Item B: flex-basis 400px, flex-shrink 1.

Their scaled shrink factors are 200 and 400. If the negative free space is 120px, the initial shrink distribution is:

Item Scaled Factor Initial Shrink
A 200 40px
B 400 80px

Before considering constraints, the resulting sizes would be 160px and 320px.

This example assumes neither item hits a min-size or max-size constraint. The browser's full flex algorithm can redistribute space if an item becomes frozen at a constraint.

5. flex-basis Property

The flex-basis property defines the initial main size of a flex item before free-space distribution.

Syntax

.item {
    flex-basis: 200px;
}

Common Values

Value Meaning
auto Uses the item's main-size property as the basis when specified; otherwise the basis is content-based.
0 Uses a zero flex base size.
200px Uses a 200px initial main size.
30% Uses a percentage of the flex container's inner main size when that size is definite.
content Uses the item's content-based size as its flex basis.

Example

.item-one {
    flex-basis: 100px;
}

.item-two {
    flex-basis: 200px;
}

.item-three {
    flex-basis: 300px;
}
100px basis
200px basis
300px basis

These are initial main-size preferences. The final rendered sizes can change due to growth, shrinking, available space and constraints.

6. Difference Between width and flex-basis

width flex-basis
Sets the preferred width of an element in horizontal writing mode. Sets the initial main size of a flex item.
Does not change its meaning when flex-direction changes. Follows the main axis.
Can influence flex-basis when flex-basis is auto. When not auto, it generally takes precedence over width for the flex base size.
Applies outside Flexbox too. Is specifically used in flex layout.

Important Example

.item {
    width: 300px;
    flex-basis: 150px;
}

Here, flex-basis supplies the initial main size for Flexbox sizing rather than width.

When flex-direction is column, flex-basis relates to the main-axis size, usually height in the normal horizontal writing mode. It is not always a width.

7. Understanding Positive and Negative Free Space

Positive Free Space

Positive free space exists when the available inner main size is greater than the total flex base sizes and relevant gaps.

The flex-grow property distributes this additional space among eligible items.

Negative Free Space

Negative free space exists when the total flex base sizes and gaps exceed the available inner main size.

The flex-shrink property determines how eligible items reduce their sizes.

Situation Property
Extra available space flex-grow
Insufficient available space flex-shrink
Initial main size flex-basis

8. Practical Example: Flexible Sidebar and Main Content

Problem Statement

Create a two-column layout where the sidebar has a fixed basis and the main content takes the remaining available space.

Complete Code

<div class="layout">
    <aside class="sidebar">
        Sidebar
    </aside>

    <main class="content">
        Main Content
    </main>
</div>

.layout {
    display: flex;
    gap: 12px;
}

.sidebar {
    flex: 0 0 180px;

    flex: 1 1 0;

10. The flex Shorthand

The flex shorthand combines flex-grow, flex-shrink and flex-basis.

Syntax

flex: grow shrink basis;

Common Examples

Declaration Meaning
flex: 1 Common shorthand for a growing and shrinking item with a zero percentage basis.
flex: 0 0 200px Does not grow or shrink; uses a 200px basis.
flex: 1 1 200px Can grow and shrink, starting from a 200px basis.
flex: 0 1 auto Does not grow, can shrink, and uses an automatic basis.
For the one-number shorthand flex: 1, browsers use a zero-percentage basis in the shorthand expansion. It is not identical in every sizing situation to writing flex: 1 1 0px.

11. Important Flexbox Sizing Behaviour

11.1 Automatic Minimum Size

Flex items often have an automatic minimum size that can prevent them from shrinking below their content-based minimum size.

This is a common reason why long text or wide content overflows a flex layout. 

.main-content {
    flex: 1;
    min-width: 0;
}

In a row flex container, min-width: 0 can allow an item to shrink below its content-based automatic minimum size.

11.2 Box Sizing and Flex Basis

Flex basis participates in the flex sizing algorithm. The final outer size also depends on padding, borders, margins, gaps and box sizing.

11.3 Min and Max Constraints

Properties such as min-width, max-width, min-height and max-height can limit the final size produced by the Flexbox algorithm.

12. Common Mistakes and Debugging

  1. Confusing flex-grow with width: flex-grow distributes available positive free space; it does not directly set a width.
  2. Assuming flex-shrink distributes equally: Shrinking uses scaled shrink factors based on flex base sizes.
  3. Forgetting flex-basis: Initial item sizes influence how free space is distributed.
  4. Expecting flex-shrink: 0 to prevent all overflow: It prevents shrinking through that factor, so the item may overflow the container.
  5. Ignoring min-width: auto: The automatic minimum size may prevent expected shrinking in a row layout.
  6. Assuming flex-basis always means width: It follows the main axis, which can be vertical.
  7. Ignoring gaps: Gaps consume available space and affect the remaining free space.

Debugging Checklist

  • Is the parent a flex container?
  • What is its flex-direction?
  • What is the flex-basis of each item?
  • Is positive or negative free space available?
  • What are the grow and shrink factors?
  • Are min-width or max-width constraints active?
  • Is min-width: auto preventing expected shrinking?
  • Are gaps and margins included in the sizing calculation?

13. Placement Interview Questions and Answers

Q1. What is flex-grow?

Answer: It determines how an item shares positive free space in a flex container.

Q2. What is the default value of flex-grow?

Answer: 0.

Q3. What is flex-shrink?

Answer: It determines how an item participates in distributing negative free space.

Q4. What is the default value of flex-shrink?

Answer: 1.

Q5. What is flex-basis?

Answer: It defines the initial main size used by the Flexbox sizing algorithm.

Q6. What is the default value of flex-basis?

Answer: auto.

Q7. What is the difference between flex-grow and flex-shrink?

Answer: flex-grow distributes positive free space, whereas flex-shrink distributes negative free space.

Q8. How does flex-shrink calculate the initial shrink distribution?

Answer: It uses scaled shrink factors, calculated from flex-shrink multiplied by the flex base size.

Q9. What happens when flex-shrink is zero?

Answer: The item does not shrink through the flex-shrink mechanism and may overflow if space is insufficient.

Q10. What is the difference between width and flex-basis?

Answer: width specifies a width, while flex-basis specifies the initial main size of a flex item.

Q11. What does flex: 1 mean?

Answer: It is a shorthand that enables growth and shrinking with a zero-percentage flex basis.

Q12. Why is min-width: 0 used in Flexbox?

Answer: It can allow a flex item in a row layout to shrink below its automatic content-based minimum size.

Q13. Does flex-basis work vertically?

Answer: Yes. With flex-direction: column, it controls the initial main size along the block axis in the usual horizontal writing mode.

Q14. Can min-width prevent an item from shrinking?

Answer: Yes. A minimum size constraint can prevent an item from shrinking below that limit.
