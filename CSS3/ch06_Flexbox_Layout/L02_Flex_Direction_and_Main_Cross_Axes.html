Lecture 2: Flex Direction and Main/Cross Axes

Chapter 6 – Flexbox Layout

Control the direction of flex items and understand the two axes of Flexbox.

1. Learning Objectives

  • Understand the flex-direction property.
  • Learn row, row-reverse, column and column-reverse.
  • Understand the main axis and cross axis.
  • Understand how flex-direction changes the axes.
  • Distinguish visual order from source order.
  • Apply direction properties to practical layouts.
  • Prepare for alignment properties covered in the next lecture.

2. What Is Flex Direction?

The flex-direction property defines the direction in which flex items are placed inside a flex container.

Syntax

.container {
    display: flex;
    flex-direction: row;
}

The default value is row.

Available Values

Value Direction
row Along the inline axis, in the inline-start to inline-end direction.
row-reverse Along the inline axis, in the opposite direction.
column Along the block axis, in the block-start to block-end direction.
column-reverse Along the block axis, in the opposite direction.

3. Flex Direction: Row

The row value places flex items along the inline axis.

In the usual horizontal writing mode used by English-language websites, items appear from left to right.

Example

.container {
    display: flex;
    flex-direction: row;
}

Expected Result

1
2
3

The items are arranged horizontally in the default left-to-right writing mode.

The exact direction of row depends on the writing direction. In an RTL context, the inline-start to inline-end direction is reversed.

4. Flex Direction: Row-Reverse

The row-reverse value reverses the direction of the main axis.

Example

.container {
    display: flex;
    flex-direction: row-reverse;
}

Expected Result

1
2
3

In the usual left-to-right writing mode, the first item is displayed on the right and subsequent items appear toward the left.

Reverse directions change visual presentation, not the underlying DOM source order. Avoid using them as a substitute for meaningful HTML order, especially when keyboard and screen-reader navigation matter.

5. Flex Direction: Column

The column value places flex items along the block axis.

In the usual horizontal writing mode, items appear vertically from top to bottom.

Example

.container {
    display: flex;
    flex-direction: column;
}

Expected Result

1
2
3

The items are arranged vertically.

6. Flex Direction: Column-Reverse

The column-reverse value reverses the direction of the column main axis.

Example

.container {
    display: flex;
    flex-direction: column-reverse;
}

Expected Result

1
2
3

In the usual horizontal writing mode, the first item appears at the bottom and subsequent items appear upward.

Do not reverse visual order to disguise incorrect source order. Keep the HTML sequence meaningful for reading and keyboard navigation.

7. Understanding the Main Axis and Cross Axis

Every Flexbox container has two axes:

  • Main axis: The direction in which flex items are laid out.
  • Cross axis: The axis perpendicular to the main axis.

The main axis is determined by flex-direction.

For Row Direction

  • Main axis: Horizontal in the usual horizontal writing mode.
  • Cross axis: Vertical in the usual horizontal writing mode.

  • Main axis: Vertical in the usual horizontal writing mode.

Important: Main axis and cross axis are logical directions. Their physical horizontal and vertical orientation depends on the flex direction and writing mode.

8. How Flex Direction Changes the Axes

Flex Direction Main Axis Cross Axis
row Inline axis, start to end Block axis
row-reverse Inline axis, end to start Block axis
column Block axis, start to end Inline axis
column-reverse Block axis, end to start Inline axis

Remember that reverse values change the direction of the main axis, not the identity of the main and cross axes.

9. Main Axis and Cross Axis: Why They Matter

The distinction between these axes is essential because Flexbox alignment properties operate relative to them.

Property Primary Axis Controlled
justify-content Main axis
align-items Cross axis
align-self Cross axis for an individual item
align-content Cross-axis distribution of multiple flex lines
The next lecture will cover justify-content and align-items in detail. Always identify the main axis first before deciding which alignment property to use.

10. Practical Example: Horizontal Navigation

Problem Statement

Create a horizontal navigation menu using the default row direction.

Complete Code

<nav class="navbar">
    <a href="#">Home</a>
    <a href="#">Courses</a>
    <a href="#">Projects</a>
    <a href="#">Contact</a>
</nav>

.navbar {
    display: flex;
    flex-direction: row;
    gap: 20px;
}

Expected Result

Home Courses Projects Contact

11. Practical Example: Vertical Sidebar

Problem Statement

Create a vertical sidebar menu using flex-direction: column.

Complete Code

.sidebar {
    display: flex;
    flex-direction: column;
    gap: 12px;
}

.sidebar a {
    display: block;
    padding: 12px;
}

Expected Result

Dashboard Courses Projects Settings

12. Common Mistakes

  1. Confusing main axis with horizontal axis: The main axis is horizontal for row in the usual horizontal writing mode, but vertical for column.
  2. Assuming row always means left to right: Writing direction affects inline direction.
  3. Confusing reverse direction with source order: Visual reversal does not change the HTML DOM order.
  4. Using justify-content on the cross axis: It controls the main axis, not the cross axis.
  5. Assuming column-reverse changes the HTML order: It changes visual layout direction only.
  6. Ignoring writing modes: Flexbox axes are logical and depend on writing mode.

13. Placement Interview Questions and Answers

Q1. What is flex-direction?

Answer: It defines the direction in which flex items are laid out inside a flex container.

Q2. What is the default value of flex-direction?

Answer: Row.

Q3. What are the four values of flex-direction?

Answer: Row, row-reverse, column and column-reverse.

Q4. What is the main axis?

Answer: It is the axis along which flex items are laid out.

Q5. What is the cross axis?

Answer: It is the axis perpendicular to the main axis.

Q6. What is the main axis for flex-direction: row?

Answer: The inline axis.

Q7. What is the main axis for flex-direction: column?

Answer: The block axis.

Q8. Does row-reverse change the HTML source order?

Answer: No. It changes visual layout direction, not DOM source order.

Q9. Which property controls alignment along the main axis?

Answer: justify-content.

Q10. Which property controls alignment along the cross axis?

Answer: align-items.

Q11. Can the main axis be vertical?

Answer: Yes. With flex-direction: column in the usual horizontal writing mode.

Q12. Do reverse values change the main axis into the cross axis?

Answer: No. They reverse the direction of the main axis.

15. Quick Revision

  • Flex-direction controls the direction of flex items.
  • Default direction is row.
  • Row follows the inline axis.
  • Column follows the block axis.
  • Reverse values reverse the main-axis direction.
  • Main axis is the direction of flex item layout.
  • Cross axis is perpendicular to the main axis.
  • Justify-content controls the main axis.
  • Align-items controls the cross axis.
  • Visual order does not change DOM source order.
