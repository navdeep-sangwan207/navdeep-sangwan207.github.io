2. Complete Flexbox Revision

Flex Container Properties

Property Purpose
display Creates a flex or inline-flex container.
flex-direction Defines the main-axis direction.
flex-wrap Controls whether items form multiple lines.
flex-flow Shorthand for direction and wrapping.
justify-content Distributes items along the main axis.
align-items Aligns items along the cross axis.
align-content Distributes multiple flex lines along the cross axis.
gap Controls spacing between items and lines.

Flex Item Properties

Property Purpose
flex-grow Controls distribution of positive free space.
flex-shrink Controls shrinking when space is insufficient.
flex-basis Defines the initial main size.
flex Shorthand for grow, shrink and basis.
align-self Overrides cross-axis alignment for one item.
order Controls visual ordering of flex items.

3. Coding Challenge 1: Center an Element

Problem Statement

Create a container with a fixed height and center a child element horizontally and vertically.

Expected properties:

  • display: flex
  • justify-content: center
  • align-items: center

Solution

<div class="container">
    <div class="box">Centered Element</div>
</div>

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 200px;
}

.box {
    padding: 20px;
    background: #174ea6;
    color: white;
}
Centered Element
This centers the child along the main and cross axes. With the default row direction, these are normally horizontal and vertical respectively.

4. Coding Challenge 2: Equal-Width Columns

Problem Statement

Create three columns that share the available horizontal space equally.

Solution

<div class="container">
    <div>Column 1</div>
    <div>Column 2</div>
    <div>Column 3</div>
</div>

.container {
    display: flex;
    gap: 10px;
}

.container > div {
    flex: 1;
}

Column 2
Column 3

Each column participates equally in distributing the available positive free space, subject to sizing constraints.

5. Coding Challenge 3: Responsive Card Layout

Problem Statement

Create cards that share the available space and wrap onto additional rows when necessary.

Solution

<div class="cards">
    <article class="card">HTML5</article>
    <article class="card">CSS3</article>
    <article class="card">JavaScript</article>
    <article class="card">React</article>
</div>

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

.card {
    flex: 1 1 200px;
    min-width: 0;
}

6. Coding Challenge 4: Fixed Sidebar and Flexible Content

Problem Statement

Create a two-column layout with a fixed sidebar and flexible main content.

Solution

<div class="layout">
    <aside class="sidebar">Sidebar</aside>
    <main class="content">Main Content</main>
</div>

.layout {
    display: flex;
    gap: 15px;
}

.sidebar {
    flex: 0 0 180px;
}

.content {
    flex: 1 1 0;
    min-width: 0;
}

The sidebar does not grow or shrink. The content takes the remaining space and can shrink when necessary.

7. Coding Challenge 5: Navigation Bar

Problem Statement

Build a navigation bar with a logo on the left and links grouped toward the right.

Solution

<nav class="navbar">
    <a class="logo" href="#">MyPortal</a>
    <a href="#">Home</a>
    <a href="#">Courses</a>
    <a href="#">Contact</a>
</nav>

.navbar {
    display: flex;
    align-items: center;
    gap: 18px;
}

.logo {
    margin-right: auto;
}

The auto margin consumes available main-axis space and separates the logo from the remaining links.

8. Coding Challenge 6: Card Buttons at the Bottom

Problem Statement

Arrange card content vertically and keep the action button near the bottom.

Solution

<article class="card">
    <h3>Course Name</h3>
    <p class="description">
        Course description goes here.
    </p>
    <a href="#">Explore</a>
</article>

.card {
    display: flex;
    flex-direction: column;
}

.description {
    flex: 1;
}

The description grows to consume the available space, pushing the action toward the bottom of cards sharing the same flex line height.

9. Coding Challenge 7: Individual Item Alignment

Problem Statement

Align one flex item differently from the other items along the cross axis.

Solution

.container {
    display: flex;
    align-items: center;
    min-height: 150px;
}

.special-item {
    align-self: flex-start;
}

The special item uses align-self to override the container's align-items setting.

10. Debugging Challenge: Identify the Error

Problem 1

Why are the items not displayed horizontally?

.container {
    display: block;
    justify-content: center;
}

Answer: The container is not a flex container. Use display: flex.

Problem 2

Why does align-content appear to have no effect?

.container {
    display: flex;
    flex-wrap: nowrap;
    align-content: center;
}

Answer: align-content distributes multiple flex lines. With nowrap, there is normally only one flex line. Use wrapping and provide sufficient cross-axis space to observe its effect.

Problem 3

Why does the fixed sidebar become narrower?

.sidebar {
    flex: 0 1 200px;
}

Answer: The shrink factor is 1. To prevent shrinking, use flex: 0 0 200px.

Problem 4

Why does the content overflow despite flex-shrink being enabled?

.content {
    flex: 1;
}

Answer: The automatic minimum size or unbreakable content may prevent further shrinking. Inspect the item and consider min-width: 0 and suitable text wrapping.

Problem 5

Why does order not change keyboard navigation order?

.second {
    order: -1;
}

Answer: order changes visual presentation, not DOM order or the normal keyboard focus sequence.

11. Technical Interview Questions

Q1. What is Flexbox?

Answer: Flexbox is a CSS one-dimensional layout model used to arrange and distribute space among items in a container.

Q2. What is the difference between display: flex and display: inline-flex?

Answer: flex creates a block-level flex container; inline-flex creates an inline-level flex container.

Q3. What are the main and cross axes?

Answer: They are the two layout axes established by the flex container. Their directions depend on flex-direction and writing direction.

Q4. What is the default flex-direction?

Answer: row.

Q5. What is the default flex-wrap?

Answer: nowrap.

Q6. What is the default value of justify-content?

Answer: normal, which behaves as flex-start for a flex container in the usual alignment context.

Q7. What is the default value of align-items?

Answer: normal, which behaves as stretch for flex items in the usual alignment context.

Q8. What is the difference between justify-content and align-items?

Answer: justify-content distributes items along the main axis, while align-items aligns items along the cross axis.

Q9. What is the difference between align-items and align-content?

Answer: align-items aligns items within their flex line; align-content distributes multiple flex lines along the cross axis.

Q10. What does flex-grow do?

Answer: It determines how an item receives a share of positive free space.

Q11. What does flex-shrink do?

Answer: It controls how items shrink when there is insufficient space.

Q12. What does flex-basis do?

Answer: It establishes the initial main size of a flex item before free-space distribution.

Q13. What does flex: 1 mean?

Answer: It commonly expands to flex: 1 1 0%, allowing the item to grow and shrink from a zero-percentage basis.

Q14. What is the difference between flex: auto and flex: none?

Answer: flex: auto expands to 1 1 auto; flex: none expands to 0 0 auto.

Q15. What is align-self?

Answer: It overrides the parent's align-items value for an individual flex item.

Q16. What does order do?

Answer: It changes the visual ordering of flex items.

Q17. What is gap?

Answer: It defines spacing between flex items and between flex lines.

Q18. Are absolutely positioned children flex items?

Answer: No. Absolutely positioned children are out of normal flow and do not participate as flex items.

Q19. Can Flexbox be nested?

Answer: Yes. A flex item can establish another flex container for its own children.

Q20. When should Grid be preferred over Flexbox?

Answer: Grid is generally preferred for coordinated two-dimensional row-and-column layouts. Flexbox is generally preferred for one-dimensional arrangements.

15. Chapter 6 Summary

Flexbox is an essential CSS layout model for frontend development. It is widely useful for navigation, component alignment, card layouts and responsive interfaces.

After completing this chapter, you should be able to implement common one-dimensional layouts, troubleshoot sizing problems and explain Flexbox behaviour in frontend interviews.
