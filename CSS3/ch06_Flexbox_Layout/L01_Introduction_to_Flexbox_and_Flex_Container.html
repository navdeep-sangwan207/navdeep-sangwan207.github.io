2. What Is CSS Flexbox?

CSS Flexible Box Layout, commonly called Flexbox, is a one-dimensional CSS layout model.

It is designed to arrange elements in a row or column and control their alignment, spacing and available space.

Why Do We Need Flexbox?

Before Flexbox, developers often relied on floats, inline-block elements and complicated positioning techniques to create layouts.

Flexbox provides a more direct way to:

  • Align elements horizontally or vertically.
  • Distribute available space between elements.
  • Make items grow or shrink.
  • Wrap items when space becomes insufficient.
  • Create navigation bars and card layouts.
  • Build responsive user interfaces.
Flexbox is a one-dimensional layout system. It primarily controls items along one main axis at a time. CSS Grid is generally more suitable when simultaneous row-and-column placement is required.

3. Basic Flexbox Structure

A Flexbox layout contains two important parts:

Term Meaning
Flex Container The parent element on which display: flex or inline-flex is applied.
Flex Items The direct in-flow children of a flex container.

Basic HTML

<div class="container">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
</div>

CSS

.container {
    display: flex;
}

The parent becomes the flex container. Its direct in-flow children become flex items.

4. Display: Flex

The display: flex declaration establishes a flex formatting context for an element's direct in-flow children.

Syntax

.container {
    display: flex;
}

Example

<div class="container">
    <div class="item">HTML</div>
    <div class="item">CSS</div>
    <div class="item">JavaScript</div>
</div>

.container {
    display: flex;
    gap: 15px;
}

.item {
    background: #174ea6;
    color: white;
    padding: 20px;
}

Expected Result

HTML
CSS
JavaScript

The three direct children are arranged along the default horizontal main axis.

5. Display: Inline-Flex

display: inline-flex also creates a flex container, but the container itself participates in its parent's inline formatting context.

Syntax

.container {
    display: inline-flex;
}

Example

<div class="container">
    <span>A</span>
    <span>B</span>
</div>

.container {
    display: inline-flex;
    gap: 8px;
}

Expected Result

Inline-flex container one: A B Inline-flex container two: C D

Difference Between Flex and Inline-Flex

Property Flex Inline-Flex
Container behaviour Block-level flex container Inline-level flex container
Children Flex items Flex items
Internal layout Flexbox Flexbox
Typical use Page sections and layout containers Compact inline components

6. Normal Flow vs Flexbox

In normal block flow, block-level elements generally appear one below another.

Normal Flow Example

.container div {
    display: block;
}

Flexbox Example

    display: flex;

Applying display: flex changes how the container's direct children are laid out.

Flexbox changes the formatting context of the container's direct children. It does not automatically make every descendant in the entire document a flex item.

7. Direct Children Become Flex Items

Only direct in-flow children of a flex container become flex items. Nested descendants remain inside their own parent unless that parent is also made a flex container.

Example

<div class="parent">
    <div>
        <span>Nested A</span>
        <span>Nested B</span>
    </div>

    <div>Item 2</div>
</div>

.parent {
    display: flex;
}

Expected Structure

Parent Item 1
Nested A | Nested B
Parent Item 2

The two outer div elements are flex items. The nested spans are not direct children of the outer flex container.

8. Nested Flex Containers

A flex item can also become a flex container by applying display: flex to it.

Example

<div class="outer">
    <div class="inner">
        <span>A</span>
        <span>B</span>
    </div>
</div>

.outer {
    display: flex;
}

.inner {
    display: flex;
    gap: 10px;
}

Expected Result

Nested Item A
Nested Item B

Nested Flexbox containers are commonly used for navigation bars, dashboard components, cards and application interfaces.

9. Important Flex Container Behaviour

  • A flex container establishes a flex formatting context for its direct in-flow children.
  • Flex items participate in flex layout instead of ordinary block or inline layout.
  • Direct text runs can form anonymous flex items.
  • Absolutely positioned children are not flex items.
  • A flex container creates a block-level or inline-level outer display type depending on whether flex or inline-flex is used.
  • Flex items can be aligned, reordered and resized using Flexbox properties.
Applying display: flex does not mean every child will automatically have equal width. Item sizing and distribution depend on the available space and Flexbox sizing rules.

11. Common Mistakes

  1. Applying display flex to the wrong element: Apply it to the parent whose direct children need to be arranged.
  2. Expecting all descendants to become flex items: Only direct in-flow children become flex items.
  3. Confusing flex and inline-flex: Both create Flexbox layouts internally, but their outer display behaviour differs.
  4. Expecting equal item widths automatically: Equal widths require suitable sizing rules.
  5. Using Flexbox for every layout: Grid is often more appropriate for two-dimensional layouts.
  6. Ignoring nested containers: A nested layout requires Flexbox to be applied to the relevant nested parent.

12. Placement Interview Questions and Answers

Q1. What is CSS Flexbox?

Answer: Flexbox is a one-dimensional CSS layout model used to arrange, align and distribute space among items in a row or column.

Q2. What is a flex container?

Answer: It is an element whose display property is set to flex or inline-flex.

Q3. What are flex items?

Answer: They are the direct in-flow children of a flex container.

Q4. What is the difference between display flex and inline-flex?

Answer: Both create Flexbox layouts internally. Flex creates a block-level flex container, while inline-flex creates an inline-level flex container.

Q5. Is Flexbox one-dimensional or two-dimensional?

Answer: One-dimensional. It primarily arranges items along one main axis at a time.

Q6. Can a flex item also become a flex container?

Answer: Yes. Apply display: flex or inline-flex to that item.

Q7. Do nested descendants automatically become flex items?

Answer: No. Only direct in-flow children become flex items.

Q8. Are absolutely positioned children flex items?

Answer: No. Absolutely positioned children are out of flow and do not participate as flex items.

Q9. Can Flexbox be used for navigation bars?

Answer: Yes. It is commonly used for horizontal navigation, logo placement and menu alignment.

Q10. What is the difference between Flexbox and Grid?

Answer: Flexbox is designed for one-dimensional layouts, while Grid is designed for two-dimensional row-and-column layouts.
