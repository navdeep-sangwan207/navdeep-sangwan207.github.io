Chapter 6 – Flexbox Layout

Control the cross-axis alignment of individual flex items.

2. What Is align-self?

The align-self property controls the cross-axis alignment of an individual flex item.

It allows one item to use a different alignment from the other items in the same flex container.

Syntax

.item {
    align-self: center;
}

For example, if the parent container uses align-items: flex-start, one particular child can use align-self: flex-end.

align-self is applied to a flex item, not to the flex container.

3. align-self Values

Value Behaviour
auto Uses the parent's align-items value. This is the default.
flex-start Aligns the item toward cross-start.
flex-end Aligns the item toward cross-end.
center Centers the item along the cross axis.
stretch Stretches the item when its cross size is auto and constraints allow.
baseline Aligns the item using baseline alignment.

The property also supports other alignment keywords from CSS Box Alignment, such as start, end, self-start, self-end, normal and safe/unsafe alignment modifiers.

The values most commonly required for entry-level Flexbox work are auto, flex-start, flex-end, center, stretch and baseline.

4. align-self: auto

The default value is auto. The item uses the container's align-items value. 

.container {
    display: flex;
    align-items: center;
}

.item {
    align-self: auto;
}

In this example, the item is centered along the cross axis because it inherits the parent's alignment setting.

10. Individual Alignment of Multiple Items

Different flex items can use different align-self values in the same container.

Complete Code

<div class="container">
    <div class="item one">Start</div>
    <div class="item two">Center</div>
    <div class="item three">End</div>
</div>

.container {
    display: flex;
    align-items: stretch;
    height: 180px;
    gap: 10px;
}

.one {
    align-self: flex-start;
}

.two {
    align-self: center;
}

.three {
    align-self: flex-end;
}

Each item is positioned independently along the cross axis.

11. Difference Between align-items and align-self

align-items align-self
Applied to the flex container. Applied to an individual flex item.
Sets the default cross-axis alignment for items. Controls the alignment of one selected item.
Can affect all items. Can override the parent's setting for a particular item.
Default is stretch. Default is auto.

Example

.container {
    display: flex;
    align-items: center;
}

.special-item {
    align-self: flex-end;
}

All items are centered by default, but the special item is aligned toward cross-end.

14. Important Limitations and Debugging

  • align-self controls the cross axis, not the main axis.
  • It does not change the position of an item along the main axis.
  • A flex item with an explicit cross size may not stretch.
  • min-height and max-height can constrain stretching in a row container.
  • Auto margins along the cross axis can absorb free space and take precedence over align-self for that item.
  • Absolutely positioned children are not flex items, so align-self does not control them as flex items.

Debugging Checklist

  1. Is the parent a flex container?
  2. Is align-self applied to the correct child?
  3. What is the current flex-direction?
  4. What is the cross axis in this layout?
  5. Does the container have available cross-axis space?
  6. Does the item have an explicit cross size?
  7. Are auto margins affecting the alignment?

15. Placement Interview Questions and Answers

Q1. What is align-self?

Answer: It controls the cross-axis alignment of an individual flex item.

Q2. Where is align-self applied?

Answer: It is applied to a flex item, not the flex container.

Q3. What is the default value of align-self?

Answer: auto.

Q4. What does align-self: auto do?

Answer: It uses the parent's align-items value.

Q5. Can align-self override align-items?

Answer: Yes. It can override the parent's cross-axis alignment for an individual item.

Q6. What is the difference between align-items and align-self?

Answer: align-items sets the default alignment for items in the container, whereas align-self controls an individual item's alignment.

Q7. Does align-self work along the main axis?

Answer: No. It controls cross-axis alignment.

Q8. When does align-self: stretch work?

Answer: It stretches an item with an automatic cross size when space is available and sizing constraints allow it.

Q9. Can different items have different align-self values?

Answer: Yes. Each flex item can have its own cross-axis alignment.

Q10. Does align-self work on an absolutely positioned child?

Answer: No, because an absolutely positioned child is not a flex item.

Q11. What does align-self: baseline do?

Answer: It aligns the item using baseline alignment.

Q12. Can auto margins affect align-self?

Answer: Yes. Auto margins along the cross axis can absorb free space and take precedence over align-self.
