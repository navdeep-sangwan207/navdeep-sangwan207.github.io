Chapter 6 – Flexbox Layout

2. The flex Shorthand Property

The flex property is a shorthand for three flex-item properties:

  • flex-grow
  • flex-shrink
  • flex-basis

Syntax

.item {
    flex: flex-grow flex-shrink flex-basis;
}

Example

.item {
    flex: 1 1 200px;
}

This means:

  • flex-grow: 1
  • flex-shrink: 1
  • flex-basis: 200px

3. Common flex Shorthand Values

Declaration Typical Expansion Use
flex: initial 0 1 auto Default flex-item behaviour.
flex: auto 1 1 auto Grow and shrink from an automatic basis.
flex: none 0 0 auto Neither grow nor shrink.
flex: 1 1 1 0% Common equal-space pattern.
flex: 0 0 200px 0 0 200px Fixed flex basis without growing or shrinking.
flex: 1 1 200px 1 1 200px Flexible item starting from 200px.
The one-number shorthand flex: 1 uses a zero-percentage basis in common browser implementations. A percentage basis and a zero-length basis can behave differently when the flex container's main size is indefinite.

4. Practical Example: Equal-Width Columns

Problem Statement

Create three columns that share the available main-axis space equally.

Complete Code

<div class="container">
    <div class="column">Column 1</div>
    <div class="column">Column 2</div>
    <div class="column">Column 3</div>
</div>

.container {
    display: flex;
    gap: 12px;
}

.column {
    flex: 1;
}

Expected Result

Column 1
Column 2
Column 3

All three items receive equal shares of the available positive free space, subject to sizing constraints.

5. Practical Example: Fixed Sidebar and Flexible Content

A sidebar often needs a stable width while the main content uses the remaining space.

Complete Code

<div class="layout">
    <aside class="sidebar">Sidebar</aside>
    <main class="content">Main Content</main>
</div>

.layout {
    display: flex;
    gap: 15px;
}

.sidebar {
    flex: 0 0 180px;
}

.content {
    flex: 1 1 0;
    min-width: 0;
}

Explanation:

  • Sidebar has a 180px flex basis.
  • Sidebar does not grow or shrink.
  • Main content can grow and shrink.
  • min-width: 0 allows content to shrink below its automatic minimum size when needed.

6. The order Property

The order property changes the visual order of flex items.

Syntax

.item {
    order: 2;
}

The default order value is 0.

Flex items are laid out in ascending order of their order values. Items with equal order values retain their relative order from the document source.

Example

.first {
    order: 2;
}

.second {
    order: 3;
}

.third {
    order: 1;
}

Expected Result

First in HTML
Second in HTML
Third in HTML

Visual order becomes:

  1. Third in HTML
  2. First in HTML
  3. Second in HTML

7. Important: Visual Order vs DOM Order

The order property changes visual presentation. It does not change the actual HTML document order.

Keyboard navigation and screen-reader reading generally follow the DOM order rather than the visually rearranged order.

Do not use order to create a meaningful reading sequence that contradicts the source order. Arrange the HTML logically first, then use CSS for presentation.

Example

<div class="container">
    <button>First</button>
    <button>Second</button>
    <button>Third</button>
</div>

button:first-child {
    order: 3;
}

The first button may appear last visually, but it remains first in the document and keyboard focus sequence.

Negative Order Values

.important-item {
    order: -1;
}

A negative order value places an item before items with the default value of zero.

8. The gap Property

The gap property creates spacing between flex items.

Syntax

.container {
    display: flex;
    gap: 20px;
}

Unlike margins, gap controls the spacing between adjacent flex items through the container.

CSS
JavaScript

The items have 15px of spacing between them. The gap does not add space before the first item or after the last item.

9. row-gap and column-gap

Flexbox also supports separate row and column spacing. 

.container {
    display: flex;
    flex-wrap: wrap;
    row-gap: 20px;
    column-gap: 10px;
}
Property Purpose
gap Sets row and column gaps together or individually.
row-gap Controls spacing between flex lines.
column-gap Controls spacing between items within a flex line.

10. Difference Between gap and margin

gap margin
Applied to the flex or grid container. Applied to individual elements.
Creates spacing between layout items. Creates space around an element.
Does not add spacing before the first or after the last item. Can add space around the outermost items.
Convenient for consistent layout spacing. Useful for element-specific spacing and alignment.

Example Using gap

.container {
    display: flex;
    gap: 20px;
}

Example Using margin

.item {
    margin-right: 20px;
}
For consistent spacing between Flexbox items, gap is usually simpler and easier to maintain.

11. Practical Example: Navigation Bar

Problem Statement

Create a navigation bar with a brand on the left, navigation links and a login button.

Complete Code

<nav class="navbar">
    <a class="brand" href="#">MyPortal</a>
    <a href="#">Home</a>
    <a href="#">Courses</a>
    <a href="#">Projects</a>
    <a class="login" href="#">Login</a>
</nav>

.navbar {
    display: flex;
    align-items: center;
    gap: 18px;
}

.brand {
    margin-right: auto;
}

.login {
    padding: 8px 12px;
}

Expected Result

MyPortal Home Courses Projects Login

The brand stays toward the beginning while the other links remain grouped toward the end. The auto margin consumes available free space.

12. Practical Example: Responsive Card Layout

Problem Statement

Create cards that share available space and wrap onto additional rows when the container becomes too narrow.

Complete Code

<div class="cards">
    <article class="card">HTML5</article>
    <article class="card">CSS3</article>
    <article class="card">JavaScript</article>
</div>

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.card {
    flex: 1 1 220px;
}

Expected Result

HTML5

Webpage structure and semantic markup.

CSS3

Styling, layout and responsive design.

JavaScript

Programming and browser interaction.

The cards can grow, shrink and wrap according to the available space.

13. Common Mistakes and Debugging

  1. Confusing shorthand values: Remember the order of grow, shrink and basis.
  2. Using order for semantic reordering: It changes visual presentation, not DOM order.
  3. Using margins for every spacing requirement: Prefer gap for consistent spacing between items.
  4. Forgetting flex-wrap: Gap alone does not make items wrap.
  5. Assuming order changes keyboard navigation: Keyboard navigation normally follows source order.
  6. Ignoring auto margins: An auto margin can consume available space and separate navigation groups.

Debugging Checklist

  • Is the correct shorthand value being used?
  • Is the item a direct flex child?
  • What is its order value?
  • Does the HTML source order remain logical?
  • Is gap applied to the correct container?
  • Is flex-wrap enabled when wrapping is required?
  • Are margins or auto margins affecting spacing?

14. Placement Interview Questions and Answers

Q1. What is the flex shorthand?

Answer: It combines flex-grow, flex-shrink and flex-basis.

Q2. What is the syntax of flex?

Answer: flex: grow shrink basis.

Q3. What does flex: 1 mean?

Answer: It enables growth and shrinking with a zero-percentage flex basis in the common shorthand expansion.

Q4. What is flex: none?

Answer: It is equivalent to flex: 0 0 auto.

Q5. What does the order property do?

Answer: It changes the visual ordering of flex items.

Q6. What is the default order value?

Answer: 0.

Q7. Does order change the HTML source order?

Answer: No. It changes visual presentation only.

Q8. Does order change keyboard tab order?

Answer: Normally no. Keyboard focus follows the document's focus order, not the visual order created by CSS.

Q9. What is gap in Flexbox?

Answer: It defines spacing between flex items and flex lines.

Q10. What is the difference between row-gap and column-gap?

Answer: row-gap controls spacing between flex lines; column-gap controls spacing between items along a line in a row-oriented layout.

Q11. Can gap replace all margins?

Answer: No. Gap handles spacing between layout items, while margins are still useful for element-specific outer spacing and alignment.

Q12. How can a brand be pushed to the left and navigation links to the right?

Answer: Use display: flex and margin-right: auto on the brand in a row layout.

Q13. Does gap make flex items wrap?

Answer: No. flex-wrap: wrap is needed to enable wrapping.

Q14. Can order have negative values?

Answer: Yes. Negative values place items before items with higher order values.
