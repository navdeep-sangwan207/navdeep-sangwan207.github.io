2. Understanding Flexbox Alignment

Flexbox provides alignment properties that position flex items along two axes:

  • Main axis: The axis along which flex items are laid out.
  • Cross axis: The axis perpendicular to the main axis.
Property Purpose
justify-content Distributes flex items along the main axis.
align-items Aligns flex items along the cross axis.
These properties do not always mean horizontal and vertical alignment. Their physical direction depends on flex-direction and the writing mode.

3. justify-content Property

The justify-content property controls the distribution of flex items along the main axis.

Syntax

.container {
    display: flex;
    justify-content: center;
}

Important Values

Value Behaviour
flex-start Items are grouped toward the main-start side.
flex-end Items are grouped toward the main-end side.
center Items are grouped at the center of the main axis.
space-between First and last items are at the ends; remaining free space is distributed between items.
space-around Equal space is distributed around each item; outer spaces are half the size of inner spaces.
space-evenly Equal space is distributed between items and at both ends.

4. align-items Property

The align-items property aligns flex items along the cross axis of the flex container.

Syntax

.container {
    display: flex;
    align-items: center;
}

Important Values

Value Behaviour
stretch Items stretch to fill the available cross-axis size when their cross size is auto.
flex-start Items align toward the cross-start side.
flex-end Items align toward the cross-end side.
center Items align at the center of the cross axis.
baseline Items align using their text baselines.

4.1 align-items: stretch

This is the default value. Flex items with an automatic cross size stretch to fill the available cross-axis space, subject to size constraints. 

.container {
    display: flex;
    align-items: stretch;
    height: 150px;
}

5. Difference Between justify-content and align-items

justify-content align-items
Works along the main axis. Works along the cross axis.
Distributes items or free space along the main axis. Aligns items within the cross axis.
Common values include center and space-between. Common values include center and stretch.
Depends on flex-direction. Also depends on flex-direction.

Important Interview Concept

If a container uses flex-direction: column in the usual horizontal writing mode:

  • justify-content controls vertical distribution.
  • align-items controls horizontal alignment.

6. Practical Example: Centering an Element

Problem Statement

Place a box at the horizontal and vertical center of its parent container.

Complete Code

<div class="container">
    <div class="box">Centered Content</div>
</div>

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 300px;
}

.box {
    padding: 25px;
    background: #174ea6;
    color: white;
}

Expected Result

Centered Content

This is one of the most commonly used Flexbox patterns in frontend development.

7. Practical Example: Header with Logo and Actions

Problem Statement

Create a header where the logo stays on the left and action links are grouped on the right.

Complete Code

<header class="header">
    <div class="logo">MyPortal</div>

    <div class="actions">
        <a href="#">Courses</a>
        <a href="#">Login</a>
    </div>
</header>

.header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 15px;
}

.actions {
    display: flex;
    align-items: center;
    gap: 15px;
}

Expected Result

MyPortal
Courses Login

8. Practical Example: Column Direction Alignment

When flex-direction is column, the main axis becomes the block axis in the usual horizontal writing mode. 

.container {
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    min-height: 250px;
}

In this example, justify-content centers the items vertically and align-items centers them horizontally.

9. Common Mistakes and Debugging

  1. Using the wrong alignment property: Identify the main and cross axes before choosing justify-content or align-items.
  2. Expecting vertical centering without height: The parent needs available cross-axis space. For a row container, this usually means a defined height or min-height.
  3. Expecting space-between to create space when there is none: It distributes positive free space; it does not create extra room if the items already fill the available space.
  4. Confusing stretch with center: Stretch expands eligible auto-sized items along the cross axis; center positions them without stretching them to fill that space.
  5. Forgetting flex-direction: Changing row to column changes which physical direction corresponds to each axis.
  6. Using align-items to align multiple flex lines: align-items aligns items within each line. align-content distributes multiple lines when wrapping creates them.

Debugging Checklist

  • Is the parent actually a flex container?
  • What is the current flex-direction?
  • Which axis is the main axis?
  • Does the container have free space to distribute?
  • Does the cross-axis dimension have available space?
  • Are item dimensions or min/max constraints preventing stretching?
  • Are margins or gaps affecting the visible spacing?

10. Placement Interview Questions and Answers

Q1. What is justify-content?

Answer: It distributes flex items along the main axis.

Q2. What is align-items?

Answer: It aligns flex items along the cross axis.

Q3. What is the default value of justify-content?

Answer: flex-start.

Q4. What is the default value of align-items?

Answer: stretch.

Q5. What is the difference between space-between and space-around?

Answer: space-between places no distributed space at the outer edges, while space-around provides space around each item, with half-sized outer spaces compared with the inner spaces.

Q6. What does space-evenly do?

Answer: It distributes equal space between items and at both ends.

Q7. How can you center an element horizontally and vertically using Flexbox?

Answer: Use display: flex, justify-content: center and align-items: center on the parent, with available space in both directions.

Q8. What happens to justify-content when flex-direction is column?

Answer: It controls distribution along the column main axis, which is usually vertical.

Q9. What is align-items: stretch?

Answer: It stretches items with an automatic cross size to fill the available cross-axis space, subject to constraints.

Q10. What is baseline alignment?

Answer: It aligns items using their text baselines.

Q11. Does justify-content control the cross axis?

Answer: No. It controls the main axis.

Q12. What is the difference between align-items and align-content?

Answer: align-items aligns items within a flex line, while align-content distributes flex lines along the cross axis when there are multiple lines and available space.

12. Quick Revision

  • justify-content controls the main axis.
  • align-items controls the cross axis.
  • Default justify-content is flex-start.
  • Default align-items is stretch.
  • space-between distributes free space between items.
  • space-around distributes space around items.
  • space-evenly creates equal distributed spacing.
  • center aligns items at the center of the relevant axis.
  • Flexbox can center content in both directions.
  • Always identify flex-direction before selecting alignment properties.
