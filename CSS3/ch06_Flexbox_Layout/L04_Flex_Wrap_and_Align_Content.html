2. What Is Flex Wrapping?

By default, Flexbox attempts to place all flex items on a single line. When the items need more space than the container provides, they may shrink.

The flex-wrap property controls whether flex items remain on one line or can move onto multiple lines.

Syntax

.container {
    display: flex;
    flex-wrap: wrap;
}

Available Values

Value Behaviour
nowrap All flex items remain on one flex line. This is the default.
wrap Items can move onto additional flex lines.
wrap-reverse Items wrap into multiple lines, with the cross-start and cross-end directions reversed.

nowrap keeps all flex items on a single flex line. It is the default value.

6. Understanding Flex Lines

A flex line is a group of flex items laid out together on one line.

When flex-wrap: wrap is enabled, the browser creates additional flex lines as necessary.

Each line is laid out independently for main-axis sizing and distribution. The lines are then positioned along the cross axis.

A single-line flex container has only one flex line. The behaviour of align-content becomes especially important when wrapping produces multiple lines.

7. What Is align-content?

The align-content property controls how multiple flex lines are distributed along the cross axis of a multi-line flex container.

Syntax

.container {
    display: flex;
    flex-wrap: wrap;
    align-content: center;
}

Important Values

Value Behaviour
stretch Flex lines stretch to use available cross-axis space when possible.
flex-start Lines are grouped toward cross-start.
flex-end Lines are grouped toward cross-end.
center Lines are grouped at the center of the cross axis.
space-between Lines are distributed with space between them.
space-around Equal space is distributed around each line.
space-evenly Equal space is distributed between lines and at both ends.
align-content does not align the individual items inside each line. That is the role of align-items. It also requires a multi-line flex container and available cross-axis space to show a visible distribution effect.

15. Difference Between align-items and align-content

align-items align-content
Aligns items within a flex line. Distributes multiple flex lines.
Works for single-line and multi-line containers. Has a meaningful line-distribution effect when multiple lines exist.
Controls cross-axis alignment of individual items. Controls cross-axis distribution of flex lines.
Commonly used for vertical alignment in a row container. Commonly used for spacing between wrapped rows.

Interview Example

.container {
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    align-content: space-between;
}

Here, align-items centers items within their respective flex lines, while align-content distributes the lines along the cross axis.

16. Practical Project: Responsive Course Cards

Problem Statement

Create a flexible course-card layout that automatically moves cards onto additional rows when the available width decreases.

Complete Code

<div class="course-grid">
    <div class="course-card">
        <h3>HTML5</h3>
        <p>Learn webpage structure.</p>
    </div>

    <div class="course-card">
        <h3>CSS3</h3>
        <p>Learn website styling.</p>
    </div>

    <div class="course-card">
        <h3>JavaScript</h3>
        <p>Learn programming for the web.</p>
    </div>

    <div class="course-card">
        <h3>React.js</h3>
        <p>Learn component-based UI development.</p>
    </div>
</div>

.course-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

.course-card {
    flex: 1 1 220px;
    min-width: 0;
    padding: 20px;
    border: 1px solid #ccc;
    border-radius: 8px;
}

Expected Result

Learn webpage structure.

CSS3

Learn website styling.

JavaScript

Learn programming for the web.

React.js

Learn component-based UI development.

The cards wrap onto additional rows as the available container width decreases.

The flex-basis in this example provides an initial preferred card width. The flex items can grow and shrink according to the available space. Actual card count per row depends on the container width, gaps and item sizing.

17. Common Mistakes and Debugging

  1. Forgetting flex-wrap: Items may remain on one line and shrink when wrapping was expected.
  2. Expecting align-content to work on one line: It distributes multiple flex lines, not individual items within a single line.
  3. Not providing cross-axis space: Without available space, line distribution may not produce a visible difference.
  4. Confusing align-items with align-content: One aligns items; the other distributes lines.
  5. Assuming nowrap always causes overflow: Flex items can shrink unless sizing constraints prevent sufficient shrinking.
  6. Using wrap-reverse to reorder content: It changes line placement, not DOM source order.
  7. Ignoring gaps: The gap property adds spacing between items and flex lines, affecting the available space.

Debugging Checklist

  • Is display set to flex?
  • Is flex-wrap set to the required value?
  • Are item widths or flex-basis values too large?
  • Are flex-shrink values preventing items from shrinking?
  • Does the container have sufficient cross-axis space?
  • Are multiple flex lines actually being created?
  • Is align-content being applied to the flex container?
  • Are gaps affecting line placement?

18. Placement Interview Questions and Answers

Q1. What is flex-wrap?

Answer: It controls whether flex items remain on one line or can wrap onto multiple lines.

Q2. What is the default value of flex-wrap?

Answer: nowrap.

Q3. What is the difference between wrap and wrap-reverse?

Answer: Both allow multiple lines, but wrap-reverse reverses their cross-axis placement direction.

Q4. What does align-content control?

Answer: It controls the distribution of multiple flex lines along the cross axis.

Q5. What is the default value of align-content?

Answer: stretch.

Q6. Can align-content align individual flex items?

Answer: No. It distributes flex lines. Use align-items for item alignment within a line.

Q7. Does align-content have a visible effect on a single-line flex container?

Answer: No meaningful multi-line distribution occurs because there is only one flex line.

Q8. Why might flex items not wrap?

Answer: The container may still use nowrap, or the available width and item sizing may allow all items to fit on one line.

Q9. What is the difference between align-items and align-content?

Answer: align-items aligns items within a line; align-content distributes multiple lines along the cross axis.

Q10. How do you create a responsive card layout using Flexbox?

Answer: Use display: flex, flex-wrap: wrap, gap and an appropriate flex-basis on the cards.

Q11. Does wrap-reverse change the DOM order?

Answer: No. It changes the cross-axis placement of flex lines.

Q12. Why is a fixed height sometimes used in align-content examples?

Answer: It creates available cross-axis space so that distribution of multiple lines can be observed.
