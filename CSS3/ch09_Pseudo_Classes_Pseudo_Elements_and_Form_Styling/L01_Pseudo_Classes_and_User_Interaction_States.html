2. What Is a CSS Pseudo-Class?

A pseudo-class is a CSS selector keyword that selects an element based on its state, position or relationship within the document.

Pseudo-classes allow developers to style elements without adding extra classes or modifying the HTML structure.

Syntax

selector:pseudo-class {
    property: value;
}

Example

button:hover {
    background-color: blue;
}

The above rule applies when the user points a supported pointing device at the button.

A pseudo-class begins with a single colon (:). A pseudo-element generally uses a double colon (::).

3. Link Pseudo-Classes

CSS provides pseudo-classes for styling hyperlinks according to their navigation state.

Pseudo-Class Purpose
:link Selects an unvisited hyperlink.
:visited Selects a hyperlink whose destination has been visited, subject to browser privacy restrictions.
:hover Selects an element while it matches the hover state.
:active Selects an element while it is being activated, such as during a mouse press.

Example

a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
}

a:active {
    color: orange;
}

Recommended Link State Order

a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
}

a:active {
    color: orange;
}

This ordering is commonly remembered as LVHA: Link, Visited, Hover, Active.

Browsers restrict which CSS properties can affect visited links to protect browsing history privacy. Do not depend on arbitrary styling differences in :visited.

4. The :hover Pseudo-Class

The :hover pseudo-class selects an element while the user's pointing device is over it.

Syntax

element:hover {
    property: value;
}

Example: Hover Button

.button {
    background-color: #174ea6;
    color: white;
    padding: 10px 18px;
    border: none;
    border-radius: 6px;
}

.button:hover {
    background-color: #007bff;
}

Live Demonstration

Move Pointer Here

Move the pointer over the button to observe its background change.

Practical Applications

  • Navigation menus.
  • Interactive buttons.
  • Course cards.
  • Product cards.
  • Image galleries.
Hover must not be the only way to communicate important information. Touchscreens and keyboard users may not experience hover in the same way.

5. The :active Pseudo-Class

The :active pseudo-class selects an element while it is being activated. For a button, this commonly occurs while the pointer button is held down.

Example

button {
    background: #174ea6;
    color: white;
    padding: 10px 18px;
}

button:active {
    background: #0b2f66;
    transform: scale(0.98);
}

Live Demonstration

Press and hold the button to see its active appearance.

Common Uses

  • Button press feedback.
  • Navigation link activation.
  • Interactive controls.
  • Touch interaction feedback.

6. The :focus Pseudo-Class

The :focus pseudo-class selects an element when it has keyboard or programmatic focus, or receives focus through another supported interaction.

Example

input:focus {
    border-color: #174ea6;
    outline: 3px solid #b8d5ff;
}

Live Demonstration



Click inside the input or navigate to it using the keyboard.

Practical Applications

  • Input field highlighting.
  • Keyboard navigation.
  • Accessible forms.
  • Interactive menus.

7. The :focus-visible Pseudo-Class

The :focus-visible pseudo-class styles focus when the browser determines that a visible focus indicator is appropriate, commonly during keyboard navigation.

Example

button:focus-visible {
    outline: 3px solid #ff9800;
    outline-offset: 3px;
}

Difference Between :focus and :focus-visible

:focus :focus-visible
Matches an element whenever it has focus. Matches focus when the browser determines a visible indicator should be shown.
May apply after mouse interaction. Commonly applies during keyboard navigation.
Useful for general focus styling. Useful for keyboard-focused visual indicators.
Do not remove browser focus outlines without providing a sufficiently visible replacement. Keyboard users must be able to identify the currently focused control.

8. The :focus-within Pseudo-Class

The :focus-within pseudo-class selects an element when it or one of its descendants has focus.

Example

.form-group:focus-within {
    border: 2px solid #174ea6;
    background: #eef5ff;
}

Complete Example

.form-group {
    padding: 15px;
    border: 1px solid #ccc;
    border-radius: 8px;
}

.form-group:focus-within {
    border-color: #174ea6;
    background: #eef5ff;
}

Live Demonstration



The form group can be styled whenever its input receives focus.

Applications

  • Highlighting active form groups.
  • Styling navigation containers.
  • Improving form interaction feedback.

9. The :target Pseudo-Class

The :target pseudo-class selects an element whose ID matches the fragment identifier in the current URL.

Example

#details:target {
    background: #eaf2ff;
    border: 2px solid #174ea6;
}

Complete HTML Example

<a href="#details">View Details</a>

<section id="details">
    <h2>Course Details</h2>
    <p>This section is the URL target.</p>
</section>

CSS

#details:target {
    background: #eaf2ff;
    padding: 20px;
    border-left: 4px solid #174ea6;
}

Live Demonstration

Go to Details

Target Section

This section is highlighted when its URL fragment is active.

Clicking the link changes the URL fragment and activates the target pseudo-class.

10. The :checked Pseudo-Class

The :checked pseudo-class selects checked checkboxes and selected radio buttons.

Example

input:checked {
    accent-color: #174ea6;
}

Live Demonstration




Select the checkbox or radio buttons to observe their checked states.

:checked selects the current checked or selected state. It does not validate whether the user has supplied correct information.

11. Other Useful Interaction and State Pseudo-Classes

Pseudo-Class Purpose
:enabled Selects enabled form controls.
:disabled Selects disabled form controls.
:required Selects controls with the required attribute.
:optional Selects controls without the required attribute where applicable.
:valid Selects controls that satisfy their applicable validity constraints.
:invalid Selects controls that fail their applicable validity constraints.
:placeholder-shown Selects an input or textarea while its placeholder is displayed.
:read-only Selects elements that are read-only.
:read-write Selects elements that are editable.

These form-related pseudo-classes will be studied in detail in Lecture 3.

12. Combining Pseudo-Classes

Multiple pseudo-classes can be combined to select elements matching more than one condition.

Example 1: Hover and Focus

button:hover,
button:focus-visible {
    background: #007bff;
    color: white;
}

Example 2: Enabled Button on Hover

button:enabled:hover {
    background: #007bff;
}

Example 3: Required Input on Focus

input:required:focus {
    border-color: #174ea6;
}

The selector applies only when the element matches all the specified pseudo-class conditions.

13. Pseudo-Class Specificity

A pseudo-class generally contributes the specificity of one class selector.

Selector Specificity
button 0-0-1
.button 0-1-0
:hover 0-1-0
button:hover 0-1-1
.nav a:focus 0-2-1
#menu a:hover 1-1-1

Example

button {
    background: gray;
}

.button:hover {
    background: blue;
}

The second selector has greater specificity than the first and applies when the hover condition matches.

Advanced selectors such as :is(), :not() and :has() have special specificity rules. They are covered in Lecture 2.

14. Practical Project: Interactive Button and Input

Objective

Create an interactive interface containing a button and an input field with suitable user interaction states.

Complete Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Interactive Controls</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            padding: 30px;
        }

        button {
            background: #174ea6;
            color: white;
            padding: 12px 20px;
            border: none;
            border-radius: 6px;
            cursor: pointer;
        }

        button:hover {
            background: #007bff;
        }

        button:active {
            transform: scale(0.97);
        }

        button:focus-visible {
            outline: 3px solid orange;
            outline-offset: 3px;
        }

        input {
            display: block;
            margin-top: 20px;
            padding: 10px;
            border: 1px solid #888;
            border-radius: 5px;
        }

        input:focus {
            border-color: #174ea6;
            outline: 2px solid #b8d5ff;
        }
    </style>
</head>

<body>

    <h2>Interactive Controls</h2>

    <button type="button">
        Submit
    </button>

    <input type="text"
           placeholder="Enter your name">

</body>
</html>

Expected Result

  • Button background changes on hover.
  • Button provides press feedback.
  • Keyboard focus has a visible outline.
  • Input border changes when focused.

15. Common Mistakes

Mistake Correct Approach
Using :hover as the only interaction indicator. Provide focus and other appropriate interaction states.
Removing outlines without replacement. Provide a visible focus indicator.
Using pseudo-classes instead of pseudo-elements. Understand the difference between element states and generated or typographic parts.
Using :active to represent permanent selection. Use appropriate state mechanisms such as :checked or application-managed classes.
Assuming every browser treats visited links identically. Respect browser privacy restrictions on :visited styling.
Using low-contrast focus indicators. Ensure focus is clearly visible against surrounding content.

16. CSS Pseudo-Class Interview Questions

Q1. What is a pseudo-class in CSS?

Answer: A selector keyword that selects elements based on their state, position or relationship within the document.

Q2. What is the syntax of a pseudo-class?

Answer: selector:pseudo-class, for example button:hover.

Q3. What is the difference between :hover and :active?

Answer: :hover matches while an element is hovered; :active matches while it is being activated.

Q4. What is the difference between :focus and :focus-visible?

Answer: :focus matches focused elements; :focus-visible matches when the browser determines that a visible focus indicator is appropriate.

Q5. What is :focus-within?

Answer: It selects an element when it or one of its descendants has focus.

Q6. What is :visited?

Answer: It selects hyperlinks whose destinations have been visited, subject to browser privacy restrictions.

Q7. What is :target?

Answer: It selects the element whose ID matches the current URL fragment identifier.

Q8. What is :checked?

Answer: It selects checked checkboxes and selected radio buttons.

Q9. What is the specificity of :hover?

Answer: It contributes one class-level specificity component: 0-1-0.

Q10. What is the difference between a pseudo-class and a pseudo-element?

Answer: A pseudo-class selects an element based on a condition or state; a pseudo-element targets a particular part of an element or generates a stylable pseudo-element.

Q11. Why should focus indicators not be removed?

Answer: They help keyboard users identify which element currently receives keyboard interaction.

Q12. Can multiple pseudo-classes be used together?

Answer: Yes. For example, button:enabled:hover selects enabled buttons in the hover state.

18. Lecture Summary

  • Pseudo-classes select elements based on states or conditions.
  • :link and :visited style hyperlink states.
  • :hover responds to pointer hover.
  • :active represents an active interaction.
  • :focus styles focused elements.
  • :focus-visible supports appropriate visible focus indication.
  • :focus-within selects a parent containing a focused descendant.
  • :target selects the current URL fragment target.
  • :checked selects checked controls.
  • Pseudo-classes contribute class-level specificity in general, with special rules for some functional pseudo-classes.
