2. What Are CSS Pseudo-Elements?

A pseudo-element allows CSS to style a specific part of an element or create a generated child-like box associated with an element.

Pseudo-elements are commonly used for decorative effects, visual indicators, icons, separators and generated content.

Syntax

selector::pseudo-element {
    property: value;
}

Examples

p::first-letter {
    font-size: 30px;
}

p::first-line {
    font-weight: bold;
}

h2::before {
    content: "★ ";
}
The double-colon notation (::) is the modern syntax for pseudo-elements. Some legacy pseudo-elements also support the older single-colon syntax.

3. Difference Between Pseudo-Classes and Pseudo-Elements

Pseudo-Class Pseudo-Element
Selects an element based on its state or position. Targets a particular part of an element or a generated box.
Commonly uses a single colon. Modern syntax uses a double colon.
Examples: :hover, :focus, :first-child. Examples: ::before, ::after, ::first-letter.

Example

/* Pseudo-class */
button:hover {
    background: blue;
}

/* Pseudo-element */
button::after {
    content: " →";
}

:hover selects a button in its hover state. ::after generates a content box associated with the button.

4. The ::before Pseudo-Element

The ::before pseudo-element generates a box as the first child-like generated content of the selected element.

Syntax

selector::before {
    content: "Generated content";
}

Example

h2::before {
    content: "★ ";
    color: orange;
}

5. The ::after Pseudo-Element

The ::after pseudo-element generates a box after the selected element's content.

Syntax

selector::after {
    content: "Generated content";
}

Example

a.external::after {
    content: " ↗";
    color: blue;
}

::before and ::after normally generate content boxes only when their content is not none. The generated boxes are not ordinary DOM elements.

6. Understanding the content Property

The content property specifies generated content for supported pseudo-elements.

Common Values

Value Purpose
content: "Text"; Generates a text string.
content: ""; Generates an empty content box.
content: none; Prevents the pseudo-element from generating a box.
content: normal; For ::before and ::after, computes to none.
content: attr(title); Uses the value of an attribute as generated content.
content: open-quote; Generates an opening quotation mark according to quotation settings.
content: close-quote; Generates a closing quotation mark according to quotation settings.

Example 1: Text Content

h3::after {
    content: " - Updated";
}

Example 2: Empty Content

.card::before {
    content: "";
    display: block;
    height: 4px;
    background: blue;
}

Example 3: Attribute Content

a::after {
    content: " (" attr(href) ")";
}

HTML

<a href="https://example.com">
    Example Website
</a>

The attribute function can retrieve an attribute value from the originating element.

Generated content is not a replacement for meaningful HTML content. Important information should remain available in the document's semantic content and accessible interface.

7. Creating an Empty Decorative Element

The content property can generate an empty box that can be styled using dimensions, backgrounds and positioning.

Example

.heading::after {
    content: "";
    display: block;
    width: 80px;
    height: 4px;
    background: #174ea6;
    margin-top: 8px;
}

HTML

<h2 class="heading">
    Our Services
</h2>

Expected Result

A short blue horizontal line appears below the heading.

A pseudo-element can provide custom visual markers for list items.

CSS

.feature-list li {

.feature-list li::before {
    content: "✓";
    position: absolute;
    left: 0;
    color: green;
    font-weight: bold;

9. Styling Form Labels with ::after

A common use of ::after is displaying an asterisk beside required form labels.

CSS

.required-label::after {
    content: " *";
    color: red;
    font-weight: bold;
}

HTML

<label class="required-label" for="username">
    Username
</label>

<input type="text" id="username" required>

Live Demonstration

For production forms, communicate required status programmatically as well, such as with the HTML required attribute. Do not rely only on a decorative asterisk.

11. Positioning Pseudo-Elements

Pseudo-elements can be positioned using position, inset, width, height and transform properties.

Example: Decorative Line

.heading {
    position: relative;
}

.heading::after {
    content: "";
    position: absolute;
    left: 0;
    bottom: -8px;
    width: 70px;
    height: 3px;
    background: blue;
}

Important Concepts

  • Use position: relative on the originating element when it should establish the containing block.
  • Use position: absolute on the pseudo-element for precise placement.
  • Use content: "" to generate an empty decorative box.
  • Use z-index carefully when generated boxes overlap other content.

12. Practical Project: Course Card with Generated Decorations

Build a reusable course card using pseudo-elements for a top accent bar, category badge and decorative arrow.

Complete HTML and CSS

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Course Card</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
            background: #f1f5fb;
            padding: 30px;
        }

        .course-card {
            max-width: 320px;
            background: white;
            padding: 24px;
            border-radius: 10px;
            position: relative;
            overflow: hidden;
            box-shadow: 0 3px 12px rgba(0,0,0,0.1);
        }

        .course-card::before {
            content: "";
            position: absolute;
            top: 0;
            left: 0;
            width: 100%;
            height: 5px;
            background: #174ea6;
        }

        .course-card h2::after {
            content: "POPULAR";
            font-size: 10px;
            color: white;
            background: #16834a;
            padding: 4px 7px;
            border-radius: 4px;
            margin-left: 8px;
            vertical-align: middle;
        }

        .course-card a::after {
            content: " →";
        }

        .course-card a {
            color: #174ea6;
            font-weight: bold;
            text-decoration: none;
        }
    </style>
</head>

<body>

    <article class="course-card">
        <h2>CSS3</h2>

        <p>
            Learn selectors, layouts,
            responsive design and modern CSS.
        </p>

        <a href="#">Explore Course</a>
    </article>

</body>
</html>

Expected Result

  • A white course card with rounded corners.
  • A blue decorative strip at the top.
  • A green POPULAR badge beside the heading.
  • An arrow after the Explore Course link.
This pattern is useful for course portals, product cards, dashboard widgets and reusable frontend components.

13. Other Important CSS Pseudo-Elements

Pseudo-Element Purpose
::before Generates a box before an element's content.
::after Generates a box after an element's content.
::first-letter Targets the typographic first letter of a block container's first formatted line where applicable.
::first-line Targets the first formatted line of a block container.
::selection Targets the portion of content selected by the user.
::placeholder Styles placeholder text in supported form controls.
::marker Styles list item markers and supported markers.
::file-selector-button Styles the button portion of file input controls in supporting browsers.

Example: Selection Styling

::selection {
    background: #174ea6;
    color: white;
}

Example: Placeholder Styling

input::placeholder {
    color: #777;
    font-style: italic;
}

Example: List Marker

li::marker {
    color: #174ea6;
    font-weight: bold;
}

14. Accessibility and Best Practices

  • Keep essential information in semantic HTML.
  • Do not use generated content as the only source of important instructions.
  • Do not use CSS-generated text as a replacement for form labels.
  • Ensure decorative content does not obscure text or controls.
  • Use sufficient color contrast.
  • Test generated content with assistive technologies when it conveys meaningful information.
  • Use real HTML elements when content needs interaction, semantics or independent behavior.
Generated content is not guaranteed to be exposed consistently by every browser and assistive-technology combination. Use HTML for meaningful content, accessible labels and interactive controls.

15. Common Mistakes and Debugging

Mistake Correct Understanding
Forgetting content. Use content: "" for an empty decorative ::before or ::after box.
Using ::before as a real HTML element. It creates generated content, not an ordinary DOM node.
Using generated content for important instructions. Keep meaningful information in semantic HTML.
Expecting width and height to work on an inline pseudo-element. Use display: inline-block or display: block when dimensions are required.
Using absolute positioning without a suitable containing block. Establish the intended containing block, often with position: relative on the originating element.
Expecting content: none to display a string. Use a quoted string for generated text.

Debugging Checklist

  1. Verify the selector matches the intended element.
  2. Check whether the content property is declared.
  3. Inspect display and positioning properties.
  4. Check width, height and overflow.
  5. Inspect z-index and stacking context if the pseudo-element is hidden behind another box.
  6. Check whether an ancestor clips the generated box.
  7. Use Developer Tools to inspect the generated pseudo-element.

16. Placement Interview Questions

Q1. What is a CSS pseudo-element?

Answer: A pseudo-element targets a specific part of an element or creates generated content associated with an element.

Q2. What is the difference between ::before and ::after?

Answer: ::before generates a box before the originating element's content, while ::after generates one after it.

Q3. What is the content property?

Answer: It specifies generated content for supported pseudo-elements.

Q4. Why is content: "" used?

Answer: It generates an empty content box that can be styled with dimensions, background and positioning.

Q5. What happens with content: none?

Answer: It prevents the pseudo-element from generating a box.

Q6. Can pseudo-elements be used to create icons?

Answer: Yes. Text symbols, CSS shapes and other generated decorations can be used, provided the design remains accessible.

Q7. Are ::before and ::after real DOM elements?

Answer: No. They are generated boxes associated with the originating element.

Q8. Can pseudo-elements be positioned?

Answer: Yes. They support positioning and layout properties appropriate to their generated boxes.

Q9. What does attr() do in content?

Answer: It retrieves an attribute value from the originating element for use as generated content.

Q10. What is the difference between a pseudo-class and a pseudo-element?

Answer: A pseudo-class selects an element based on its state or position, while a pseudo-element targets a part of an element or a generated box.

Q11. Can ::before and ::after replace HTML elements?

Answer: They are useful for decoration but should not replace semantic or interactive HTML elements.

Q12. What is ::selection?

Answer: It is a pseudo-element used to style the portion of text selected by the user.

Q13. What is ::marker?

Answer: It targets the marker box of list items and other supported markers.

Q14. Why might a pseudo-element not appear?

Answer: Common causes include missing content, content: none, selector mismatch, display issues, clipping or stacking problems.

18. Lecture Summary

  • Pseudo-elements target parts of elements or create generated boxes.
  • ::before generates content before the element's content.
  • ::after generates content after the element's content.
  • The content property controls generated content.
