Lecture 2: Structural Pseudo-Classes and Advanced Selectors

Chapter 9 – Pseudo-Classes, Pseudo-Elements and Form Styling

Learn to select elements based on document structure and relationships without adding unnecessary classes.

1. Learning Objectives

  • Understand structural pseudo-classes.
  • Use :first-child and :last-child.

  • Differentiate :nth-child() and :nth-of-type().
  • Use :first-of-type and :last-of-type.

  • Use :not(), :is(), :where() and :has().
  • Understand advanced selector specificity.
  • Apply selectors to practical frontend layouts.

2. What Are Structural Pseudo-Classes?

Structural pseudo-classes select elements based on their position or relationship within the document tree.

They are useful when styling lists, tables, navigation menus, cards and repeated interface components.

Basic Syntax

selector:pseudo-class {
    property: value;
}

Example

li:first-child {
    font-weight: bold;
}

This selects a list item only when it is the first element child of its parent.

3. The :first-child Pseudo-Class

:first-child selects an element when it is the first element child of its parent.

Syntax

element:first-child {
    property: value;
}

Example

li:first-child {
    color: blue;
    font-weight: bold;
}

4. The :last-child Pseudo-Class

:last-child selects an element when it is the last element child of its parent.

Example

li:last-child {
    color: red;
    font-weight: bold;
}

Practical Applications

  • Removing the bottom border from the final menu item.
  • Styling the last table row.
  • Removing unnecessary spacing after the final card.
.menu li:last-child {
    border-bottom: none;
}

5. The :nth-child() Pseudo-Class

:nth-child() selects elements based on their position among all element siblings.

Syntax

selector:nth-child(n) {
    property: value;
}

Common Patterns

Selector Meaning
:nth-child(1) Selects the first element child.
:nth-child(2) Selects the second element child.
:nth-child(odd) Selects positions 1, 3, 5, 7, and so on.
:nth-child(even) Selects positions 2, 4, 6, 8, and so on.
:nth-child(3n) Selects positions 3, 6, 9, and so on.
:nth-child(3n + 1) Selects positions 1, 4, 7, 10, and so on.
:nth-child(-n + 3) Selects the first three element children.

Example: Alternate Row Styling

tr:nth-child(even) {
    background: #eaf2ff;
}

6. Understanding the An+B Formula

The nth-child() function supports an An+B formula to select a repeating pattern of element positions.

In the expression An+B:

  • A represents a multiplier.
  • n represents a sequence of non-negative integers.
  • B represents an offset.

Example 1

li:nth-child(3n) {
    background: lightblue;
}

Matches positions 3, 6, 9, 12 and so on.

Example 2

li:nth-child(3n + 1) {
    background: lightgreen;
}

Matches positions 1, 4, 7, 10 and so on.

Example 3

li:nth-child(-n + 4) {
    font-weight: bold;
}

Matches the first four element children.

Example 4

li:nth-child(n + 4) {
    color: blue;
}

Matches the fourth and subsequent element children.

The formula is evaluated using non-negative integer values of n. Positions are counted starting from 1.

7. The :nth-last-child() Pseudo-Class

:nth-last-child() selects an element based on its position counted from the end of its parent's element children.

Example

li:nth-last-child(1) {
    color: red;
}

This is equivalent to selecting the last element child.

Example: Last Three Items

li:nth-last-child(-n + 3) {
    background: #eaf2ff;
}

This selects the final three element children.

8. The :first-of-type and :last-of-type Pseudo-Classes

:first-of-type selects the first sibling of its element type. :last-of-type selects the last sibling of its element type.

Example HTML

<div>
    <h2>Heading 1</h2>
    <p>Paragraph 1</p>
    <p>Paragraph 2</p>
    <h2>Heading 2</h2>
    <p>Paragraph 3</p>
</div>

CSS

p:first-of-type {
    color: blue;
}

p:last-of-type {
    color: red;
}

The first paragraph and final paragraph of their respective element type are selected.

:first-of-type and :last-of-type are based on element type, not the first or last occurrence of a particular class.

9. Difference Between :nth-child() and :nth-of-type()

This is an important CSS interview and debugging topic.

:nth-child() :nth-of-type()
Counts all element siblings. Counts siblings of the same element type.
Checks the element's overall position. Checks its position among elements of the same type.
Useful for general sibling positions. Useful when selecting a particular element type.

HTML Example

<div>
    <h2>Title</h2>
    <p>First paragraph</p>
    <h3>Subheading</h3>
    <p>Second paragraph</p>
</div>

CSS Example

p:nth-child(2) {
    color: blue;
}

p:nth-of-type(2) {
    color: red;
}

The first rule selects a paragraph only if it is the second element child overall.

The second rule selects the second paragraph among paragraph siblings.

10. :only-child and :only-of-type

:only-child

Selects an element when it is the only element child of its parent. 

p:only-child {
    color: green;
}

:only-of-type

Selects an element when it is the only sibling of its element type. 

p:only-of-type {
    font-weight: bold;
}

Difference

  • :only-child requires no other element siblings.
  • :only-of-type allows other sibling types but requires only one element of the selected type.

11. The :not() Pseudo-Class

:not() is a negation pseudo-class. It selects elements that do not match the selector argument.

Syntax

selector:not(selector-list) {
    property: value;
}

Example 1

button:not(.primary) {
    background: gray;
}

Selects buttons that do not have the primary class.

Example 2

input:not([type="submit"]) {
    border: 1px solid #888;
}

Selects input elements that do not have the submit type.

Example 3: Multiple Arguments

p:not(.important, .highlight) {
    color: #555;
}

Selects paragraphs that match neither .important nor .highlight.

:not() does not accept pseudo-elements as its selector arguments. Its specificity is determined by the most specific selector in its argument list.

12. The :is() Pseudo-Class

:is() groups multiple selectors into a selector list and applies the styles when an element matches at least one selector.

Without :is()

header h1,
header h2,
header h3,
footer h1,
footer h2,
footer h3 {
    color: #174ea6;
}

Using :is()

:is(header, footer) :is(h1, h2, h3) {
    color: #174ea6;
}

Practical Applications

  • Reducing repeated selectors.
  • Grouping related headings.
  • Simplifying component stylesheets.
:is() takes the specificity of its most specific selector argument, not the selector that happens to match.

13. The :where() Pseudo-Class

:where() works similarly to :is() but always contributes zero specificity for its argument list.

Example

:where(header, footer) h2 {
    color: #174ea6;
}

The selector can style headings inside header and footer elements without adding specificity from the :where() argument list.

Difference Between :is() and :where()

:is() :where()
Uses the specificity of the most specific argument. Always contributes zero specificity for the entire function.
Useful for grouping selectors. Useful for low-specificity base styles.

Practical Example

:where(article, section, aside) p {
    line-height: 1.6;
}

14. The :has() Relational Pseudo-Class

:has() selects an element when at least one relative selector inside its argument matches in relation to that element.

It is often described as a parent selector, but its functionality is broader.

Example 1: Parent with a Child Input

.form-group:has(input) {
    border: 1px solid #174ea6;
    padding: 15px;
}

Selects form groups containing an input descendant.

Example 2: Card with a Featured Element

.card:has(.featured) {
    border: 2px solid #174ea6;
}

Example 3: Heading Followed by a Paragraph

.content:has(h2 + p) {
    padding: 20px;
}

Example 4: Form with Invalid Input

form:has(input:invalid) {
    border-left: 4px solid red;
}
:has() is a powerful relational selector. Use it carefully with broad selectors and complex DOM structures to avoid unnecessary style recalculation and difficult-to-maintain CSS.

15. Specificity of Advanced Functional Pseudo-Classes

Selector Specificity Contribution
:not() Specificity of the most specific argument.
:is() Specificity of the most specific argument.
:has() Specificity of the most specific argument.
:where() Always zero.
:nth-child() One pseudo-class plus the specificity of its optional of-selector argument.

Example 1

:is(#main, .container) p {
    color: blue;
}

The :is() selector contributes the specificity of #main because it is the most specific argument.

Example 2

:where(#main, .container) p {
    color: blue;
}

:where() contributes zero. Only the p element selector contributes specificity here.

Example 3

li:nth-child(2 of .active) {
    color: red;
}

Specificity includes one pseudo-class component plus the specificity of .active.

16. Practical Project: Styling a Course List

Objective

Create a course list using structural and advanced pseudo-classes.

HTML

<section class="courses">

    <h2>Available Courses</h2>

    <ul class="course-list">
        <li>C++ Programming</li>
        <li class="featured">Embedded Systems</li>
        <li>Linux Programming</li>
        <li>Data Structures</li>
        <li>CSS3</li>
    </ul>

</section>

CSS

.course-list {
    list-style: none;
    padding: 0;
}

.course-list li {
    padding: 12px;
    border-bottom: 1px solid #ddd;
}

.course-list li:first-child {
    font-weight: bold;
}

.course-list li:nth-child(even) {
    background: #eef5ff;
}

.course-list li:last-child {
    border-bottom: none;
}

.course-list li:not(.featured) {
    color: #444;
}

.course-list:has(.featured) {
    border: 1px solid #174ea6;
    padding: 10px;
}

Expected Result

  • The first course is bold.
  • Even-numbered courses have a highlighted background.
  • The final course has no bottom border.
  • Non-featured courses receive the specified text color.
  • The list container receives a border because it contains a featured item.

17. Common Mistakes and Debugging

Mistake Correct Understanding
Assuming :nth-child() counts only matching element types. It counts all element siblings.
Confusing :nth-child() with :nth-of-type(). One counts all element siblings; the other counts siblings of the same type.
Using :first-child when the element is not the first element child. Check the actual DOM structure.
Assuming :is() and :where() have the same specificity. :where() always contributes zero; :is() uses its most specific argument.
Assuming :has() only selects parents. It is a relational selector that can express several relationships.
Overusing complex selectors. Prefer readable selectors that are easy to maintain.

Debugging Procedure

  1. Inspect the element in browser Developer Tools.
  2. Check its parent and sibling structure.
  3. Count element siblings, not whitespace or comments.
  4. Verify the selector's matching condition.
  5. Inspect specificity and overridden declarations.
  6. Test the selector on a small HTML example.

18. Placement Interview Questions

Q1. What are structural pseudo-classes?

Answer: Pseudo-classes that select elements based on their position or relationship in the document tree.

Q2. What is :first-child?

Answer: It selects an element when it is the first element child of its parent.

Q3. What is :last-child?

Answer: It selects an element when it is the last element child of its parent.

Q4. What does :nth-child(even) select?

Answer: It selects elements at even-numbered positions among the element children.

Q5. What does :nth-child(3n) select?

Answer: Elements at positions 3, 6, 9, 12 and so on.

Q6. What is the difference between :nth-child() and :nth-of-type()?

Answer: :nth-child() counts all element siblings, whereas :nth-of-type() counts siblings of the same element type.

Q7. What does :only-child select?

Answer: An element that is the only element child of its parent.

Q8. What is :not()?

Answer: A negation pseudo-class that selects elements not matching its selector argument.

Q9. What is :is()?

Answer: A selector-list pseudo-class that matches an element if it matches at least one argument selector.

Q10. What is :where()?

Answer: A selector-list pseudo-class similar to :is(), but it contributes zero specificity.

Q11. What is :has()?

Answer: A relational pseudo-class that selects an element when a relative selector matches in relation to it.

Q12. What is the specificity of :is()?

Answer: It takes the specificity of the most specific selector in its argument list.

Q13. What is the specificity of :where()?

Answer: Zero, regardless of the selectors inside its argument list.

Q14. Can :has() select a parent based on a child?

Answer: Yes. For example, .card:has(img) selects cards containing an image descendant.

Q15. What does :nth-child(-n + 3) select?

Answer: The first three element children.

Q16. What is the difference between :only-child and :only-of-type?

Answer: :only-child requires no other element siblings; :only-of-type requires only one sibling of the selected element type.

20. Lecture Summary

  • :first-child and :last-child select boundary element children.
  • :nth-child() uses element-child positions.
  • :nth-last-child() counts from the end.
  • :first-of-type and :last-of-type count by element type.
  • :nth-of-type() counts matching element types.
  • :only-child and :only-of-type identify unique sibling conditions.
  • :not() excludes matching elements.
  • :is() groups selectors using maximum argument specificity.
  • :where() groups selectors with zero specificity.
  • :has() selects elements based on relational conditions.
