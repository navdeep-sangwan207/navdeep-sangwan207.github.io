3. Important CSS Syntax Revision

Basic selector syntax

/* Element selector */
p {
    color: #333;
}

/* Class selector */
.card {
    padding: 20px;
}

/* ID selector */
#header {
    background: #174ea6;
}

/* Descendant selector */
.card p {
    line-height: 1.6;
}

/* Child selector */
.card > h2 {
    margin-top: 0;
}

/* Attribute selector */
input[type="email"] {
    border: 1px solid #ccc;
}

/* Pseudo-class */
button:hover {
    background: #007bff;
}

/* Pseudo-element */
.card::before {
    content: "";
    display: block;
}

Remember

  • . selects a class.
  • # selects an ID.
  • * selects all elements.
  • > selects direct children.
  • + selects the next adjacent sibling.
  • ~ selects subsequent sibling elements.
  • ::before and ::after create pseudo-elements.

4. Cascade, Specificity and Inheritance Revision

Specificity model

For the common selector categories, specificity is represented as: 

(ID, CLASS, TYPE)
Selector Specificity
p (0, 0, 1)
.card (0, 1, 0)
#header (1, 0, 0)
div.card (0, 1, 1)
#main .card p (1, 1, 1)

This is a simplified way to compare ordinary selectors. The complete cascade also considers origin, importance, cascade layers, specificity, scoping proximity and source order.

Special selector behavior

  • :where() contributes zero specificity.
  • :is() uses the highest specificity of its arguments.
  • :not() uses the specificity of its argument.
  • :has() uses the highest specificity of its arguments.

Inheritance keywords

color: inherit;
color: initial;
color: unset;
color: revert;
  • inherit: use the parent's computed value.
  • initial: use the property's initial value.
  • unset: behave as inherit for inherited properties and initial otherwise.
  • revert: roll the property back to an earlier cascade origin.

5. Box Model and Units Revision

CSS box model

/* Total width with content-box */
.total-width {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

/* Total width = 300 + 40 + 10 = 350px */

/* Total width with border-box */
.border-box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

/* Total border-box width = 300px */

Important units

Unit Meaning
px CSS pixel.
% Relative to the applicable containing-block dimension.
em Relative to the relevant computed font size.
rem Relative to the root element's computed font size.
vw One percent of viewport width.
vh One percent of the large viewport height in current viewport-unit definitions.
svh / lvh / dvh Small, large and dynamic viewport height units.

Useful global sizing rule

*,
*::before,
*::after {
    box-sizing: border-box;
}

This makes declared width and height include padding and border, but not margin.

6. Display, Positioning and Stacking Revision

Property Key Behavior
static Normal document flow; default positioning.
relative Remains in flow and can be visually offset.
absolute Removed from normal flow and positioned against its containing block.
fixed Removed from normal flow and positioned against its fixed-position containing block.
sticky Remains in flow and sticks within its scroll container when thresholds are reached.

Positioning example

.card {
    position: relative;
}

.badge {
    position: absolute;
    top: 10px;
    right: 10px;
    z-index: 2;
}

Important stacking context triggers

  • Positioned element with a non-auto z-index.
  • Opacity less than 1.
  • Transform other than none.
  • Filter other than none.
  • isolation: isolate.
  • Some flex and Grid items with non-auto z-index.
A child cannot escape its ancestor's stacking context merely by receiving a very large z-index. Inspect the stacking contexts of both elements.

7. Flexbox and Grid Revision

Flexbox properties

.container {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
    gap: 20px;
}

.item {
    flex: 1 1 220px;
    min-width: 0;
}

Important Flexbox concepts

  • Flexbox is primarily one-dimensional.
  • Main and cross axes depend on flex-direction and writing mode.
  • justify-content aligns along the main axis.
  • align-items aligns items along the cross axis.
  • align-content distributes multiple flex lines when cross-axis space is available.
  • flex-grow distributes positive free space.
  • flex-shrink controls shrinking when space is insufficient.
  • flex-basis establishes the flex base size.

Grid properties

.grid-container {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
}

.grid-item {
    min-width: 0;
}

Important Grid concepts

  • Grid controls rows and columns together.
  • fr distributes available track space.
  • gap creates spacing between tracks.
  • grid-template-areas defines named layout areas.
  • grid-column and grid-row control placement.
  • auto-fit and auto-fill support repeated responsive tracks.

8. Responsive Design Revision

Viewport configuration

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Mobile-first media query

/* Base styles are designed for narrow screens */

.layout {
    display: grid;
    grid-template-columns: 1fr;
    gap: 20px;
}

/* Enhance the layout when more width is available */

@media (min-width: 768px) {
    .layout {
        grid-template-columns: 2fr 1fr;
    }
}

Fluid typography

h1 {
    font-size: clamp(2rem, 5vw, 3.5rem);
}

Responsive images

img {
    max-width: 100%;
    height: auto;
}

.cover-image {
    width: 100%;
    aspect-ratio: 16 / 9;
    object-fit: cover;
}

Responsive design checklist

  • Use a viewport meta tag.
  • Avoid fixed widths that exceed the screen.
  • Use flexible Grid and Flexbox layouts.
  • Test text wrapping and long content.
  • Check image sizing.
  • Test navigation and forms on narrow screens.
  • Use breakpoints where the content needs them.

9. Pseudo-classes, Pseudo-elements and Forms

Common pseudo-classes

a:hover {
    color: #007bff;
}

button:focus-visible {
    outline: 3px solid #007bff;
}

input:invalid {
    border-color: #dc3545;
}

li:first-child {
    font-weight: bold;
}

li:nth-child(odd) {
    background: #f1f5fb;
}

Common pseudo-elements

.required::after {
    content: " *";
    color: red;
}

.quote::before {
    content: "“";
}

.quote::after {
    content: "”";
}

Accessible form styling

label {
    display: block;
    margin-bottom: 6px;
}

input,
textarea {
    width: 100%;
    padding: 12px;
    border: 1px solid #9ca3af;
    border-radius: 5px;
}

input:focus-visible,
textarea:focus-visible {
    outline: 3px solid #007bff;
    outline-offset: 2px;
}
CSS validation styles do not replace actual form validation. Client-side validation improves user experience, but server-side validation is necessary when processing submitted data.

10. Modern CSS Revision

CSS custom properties

:root {
    --primary: #174ea6;
    --spacing: 20px;
}

.card {
    padding: var(--spacing);
    border-color: var(--primary);
}

CSS calculation functions

.container {
    width: min(100% - 32px, 1100px);
    margin-inline: auto;
}

.heading {
    font-size: clamp(2rem, 5vw, 3.5rem);
}

.sidebar {
    width: min(100%, 300px);
}

Transitions

.button {
    background: #174ea6;
    transition:
        background-color 0.2s ease,
        transform 0.2s ease;
}

.button:hover {
    background: #007bff;
    transform: translateY(-2px);
}

Keyframe animation

@keyframes fade-in {
    from {
        opacity: 0;
        transform: translateY(10px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.message {
    animation: fade-in 0.4s ease both;
}

Reduced motion

@media (prefers-reduced-motion: reduce) {
    .message {
        animation: none;
    }

    .button {
        transition: none;
    }
}

Container queries

.card-container {
    container-type: inline-size;
}

@container (min-width: 500px) {
    .card-content {
        display: grid;
        grid-template-columns: 1fr 1fr;
        gap: 20px;
    }
}

11. CSS Architecture, Accessibility and Performance

Maintainable CSS practices

  • Use descriptive class names.
  • Keep related component styles together.
  • Use CSS custom properties for shared values.
  • Avoid unnecessarily deep selectors.
  • Limit excessive use of !important.
  • Separate global styles from component styles.
  • Remove unused declarations when safe to do so.

BEM naming example

/* Block */
.card { }

/* Element */
.card__title { }
.card__description { }

/* Modifier */
.card--featured { }

Accessibility essentials

  • Maintain sufficient text contrast.
  • Preserve visible keyboard focus indicators.
  • Do not communicate status through color alone.
  • Use semantic HTML and meaningful labels.
  • Respect reduced-motion preferences.
  • Ensure controls remain usable at different zoom levels.

WCAG contrast reference

Text category AA AAA
Normal text 4.5:1 7:1
Large text 3:1 4.5:1

Large text generally means at least 18pt regular or 14pt bold. Applicable non-text UI components and graphical objects generally need a 3:1 contrast ratio against adjacent colors.

Performance considerations

  • Prefer efficient selectors and avoid unnecessary complexity.
  • Use appropriately sized images.
  • Animate transform and opacity when suitable.
  • Avoid unnecessary layout-triggering animations.
  • Do not apply will-change without a measured reason.

14. Final CSS3 Interview Questions and Answers

Q1. What is CSS?

CSS stands for Cascading Style Sheets. It controls the presentation and layout of HTML documents.

Q2. What are the three ways to apply CSS?

Inline CSS, internal CSS and external CSS.

Q3. What is the CSS cascade?

The cascade is the process browsers use to resolve competing declarations based on origin, importance, cascade layers, specificity, scoping proximity and source order.

Q4. What is specificity?

Specificity is one of the cascade criteria used to determine which selector's declaration wins when competing declarations are otherwise comparable.

Q5. What is the box model?

It describes an element's content, padding, border and margin areas.

Q6. What is the difference between margin and padding?

Padding is space inside the border around content. Margin is space outside the border.

Q7. What is the difference between display: none and visibility: hidden?

display: none removes the element from layout. visibility: hidden preserves its layout space while hiding it.

Q8. What is the difference between relative and absolute positioning?

Relative positioning keeps the element in normal flow and offsets it visually. Absolute positioning removes it from normal flow and positions it against its containing block.

Q9. What is z-index?

It controls stack ordering within the applicable stacking context for elements that participate in stacking order.

Q10. What is Flexbox?

Flexbox is a one-dimensional layout model for arranging and distributing items along a main axis and cross axis.

Q11. What is CSS Grid?

CSS Grid is a two-dimensional layout system that controls rows and columns.

Q12. What is the difference between Flexbox and Grid?

Flexbox is primarily suited to one-dimensional layouts, while Grid is suited to layouts that need coordinated rows and columns.

Q13. What is a media query?

A media query conditionally applies CSS based on media features such as viewport width or user preferences.

Q14. What is mobile-first design?

It is a responsive design approach that starts with a narrow-screen layout and progressively enhances it for wider screens.

Q15. What is the difference between em and rem?

The em unit depends on the relevant computed font size, while rem is based on the root element's computed font size.

Q16. What is a pseudo-class?

A pseudo-class selects an element based on a state or relationship, such as :hover, :focus-visible or :first-child.

Q17. What is a pseudo-element?

A pseudo-element represents a particular part of an element or generates a styling-related box, such as ::before and ::after.

Q18. What is a CSS variable?

A CSS custom property stores a reusable value and is referenced using var().

Q19. What is the difference between transition and animation?

A transition interpolates between property values when a change occurs. An animation can define multiple stages using keyframes and animation properties.

Q20. What is object-fit?

It controls how replaced content, such as an image, fits within its element's content box.

Q21. What is the purpose of clamp()?

It constrains a value between a minimum, preferred and maximum value.

Q22. What is a container query?

It applies styles based on the size or other supported features of a containing element rather than only the viewport.

Q23. What is BEM?

BEM stands for Block, Element and Modifier. It is a naming convention for organizing CSS classes.

Q24. How do you improve CSS maintainability?

Use reusable components, clear naming, shared variables, organized stylesheets and controlled selector specificity.

Q25. How do you debug CSS?

Inspect the element in browser Developer Tools, review computed styles, identify overridden rules, test layout properties and examine console or network errors where relevant.

Q26. What is the purpose of min-width: 0?

It allows a Flexbox or Grid item to shrink below its automatic minimum size when its content would otherwise force overflow.

Q27. What is the difference between auto-fit and auto-fill?

Auto-fill retains empty repeated tracks, while auto-fit collapses empty tracks after placement.

Q28. Why should focus indicators not be removed?

Keyboard users need a visible indication of which interactive element currently has focus.

Q29. What is the purpose of prefers-reduced-motion?

It lets a website adapt motion effects to users who have requested reduced motion in their operating-system or browser settings.

Q30. Is CSS enough to implement authentication?

No. CSS only controls presentation. Authentication requires appropriate application logic and secure server-side or identity-provider integration.
