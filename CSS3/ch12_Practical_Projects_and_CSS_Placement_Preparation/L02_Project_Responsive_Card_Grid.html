Lecture 2: Project – Responsive Card Grid

Build a responsive collection of reusable cards using CSS Grid, Flexbox, minmax(), auto-fit, spacing, responsive images and modern component styling.

1. Project Objectives

Card grids are widely used in course portals, product listings, portfolios, dashboards and content websites. This project develops the ability to create reusable components that adapt to different viewport sizes.

  • Create a semantic card collection using HTML.
  • Build a responsive layout using CSS Grid.
  • Use repeat(), minmax() and auto-fit.
  • Control card width and spacing.
  • Make images responsive and consistent.
  • Use Flexbox to align content inside cards.
  • Add hover and keyboard focus states.
  • Prevent content overflow on small screens.

2. Understanding the Required Design

We will create a course-card grid. Each card contains an image, category, title, description and a link.

4. Step 1 – Create the HTML Structure

Use a section to group the cards and an article element for each independent course card. 

<section class="course-grid">

    <article class="course-card">
        <img src="images/cpp.jpg" alt="C++ course">

        <div class="card-content">
            <span class="category">Programming</span>
            <h2>C++ Programming</h2>
            <p>
                Learn programming fundamentals and
                object-oriented programming.
            </p>
            <a href="#">View Course</a>
        </div>
    </article>

</section>

Why use article?

An article is appropriate when a card represents self-contained content that could be understood independently of the surrounding grid.

Why use alt text?

The image's alternative text communicates its meaningful information to users who cannot see it. Decorative images should generally use an empty alt attribute.

5. Step 2 – Create the Grid Container

.course-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
    max-width: 1200px;
    margin: auto;
    padding: 24px;
}

This creates three equal-width columns with 24px spacing between rows and columns.

Important Grid properties

Property Purpose
display: grid Creates a grid formatting context.
grid-template-columns Defines the explicit column tracks.
repeat() Repeats a track definition.
1fr Allocates a share of available track space.
gap Creates spacing between grid tracks.

6. Step 3 – Make the Grid Responsive

A fixed three-column layout may become too narrow on tablets and mobile devices. CSS Grid provides a flexible solution. 

.course-grid {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(250px, 1fr));
    gap: 24px;
}

Understanding the expression

  • repeat() repeats the column pattern.
  • auto-fit fits as many columns as possible and collapses empty repeated tracks.
  • minmax(250px, 1fr) gives each track a minimum size of 250px and allows it to grow.
  • 1fr distributes available space among the tracks.
auto-fit vs auto-fill: Both can create responsive repeated tracks. auto-fill preserves empty repeated tracks, whereas auto-fit collapses empty tracks after placement so occupied tracks can expand.

7. Step 4 – Style Individual Cards

.course-card {
    background: white;
    border: 1px solid #dce3ec;
    border-radius: 10px;
    overflow: hidden;
    display: flex;
    flex-direction: column;
    min-width: 0;
    transition: transform 0.2s ease,
                box-shadow 0.2s ease;
}

.course-card:hover {
    transform: translateY(-5px);
    box-shadow: 0 8px 22px rgba(0, 0, 0, 0.12);
}

Flexbox is used inside each card to arrange the image and content vertically. The Grid container controls the overall card arrangement.

8. Step 5 – Make Images Responsive

.course-card img {
    width: 100%;
    aspect-ratio: 16 / 9;
    object-fit: cover;
    display: block;
}

The aspect ratio provides a consistent image area. object-fit: cover fills that area while preserving the image's proportions, cropping excess content when necessary.

Do not stretch images by assigning unrelated fixed width and height values without considering their aspect ratio. Use object-fit when a consistent image frame is required.

9. Step 6 – Align Card Content with Flexbox

.card-content {
    display: flex;
    flex-direction: column;
    flex: 1;
    padding: 18px;
}

.card-content h2 {
    margin: 8px 0;
    color: #174ea6;
}

.card-content p {
    color: #526174;
    line-height: 1.6;
}

.card-content a {
    align-self: flex-start;
    margin-top: auto;
    padding: 9px 15px;
    background: #174ea6;
    color: white;
    text-decoration: none;
    border-radius: 5px;
}

.card-content a:hover {
    background: #007bff;
}

The combination of flex: 1 and margin-top: auto helps align links toward the bottom of cards when their content areas have available vertical space.

12. Important CSS Concepts Used

Concept Application in Project
CSS Grid Arranges cards into responsive columns.
Flexbox Arranges content within individual cards.
minmax() Sets minimum and flexible maximum track sizes.
auto-fit Fits repeated tracks and collapses empty tracks.
aspect-ratio Maintains consistent image proportions.
object-fit Controls how images fill their frames.
transition Provides smooth visual feedback.
media query Applies a specific one-column mobile layout.

13. Common Problems and Debugging

Problem Possible Cause Correction
Cards overflow horizontally. Minimum track size is too large or content has intrinsic width. Review minmax(), min-width and long content.
Cards have unequal image heights. Images have different intrinsic dimensions. Use aspect-ratio and object-fit.
Only one column appears. Container width is insufficient for additional tracks. Check available width and minimum track size.
Card links are at different vertical positions. Content area is not using Flexbox. Use flex-direction: column and margin-top: auto.
Grid items do not shrink as expected. Automatic minimum sizing or intrinsic content width. Consider min-width: 0 and minmax(0, 1fr).
Images are distorted. Incorrect width and height combination. Use object-fit: cover.

Useful debugging steps

  1. Open Chrome Developer Tools.
  2. Select the grid container.
  3. Inspect the Grid overlay.
  4. Check computed grid-template-columns.
  5. Inspect the card's width and min-width.
  6. Test at multiple viewport widths.

14. Placement Interview Questions

Q1. What is the difference between Grid and Flexbox?

Grid is designed for two-dimensional layouts involving rows and columns. Flexbox is primarily one-dimensional, arranging items along a main axis.

Q2. What does repeat() do?

It repeats a specified track definition in a grid.

Q3. What is the difference between auto-fit and auto-fill?

auto-fill preserves empty repeated tracks, while auto-fit collapses empty tracks after placement.

Q4. What does minmax() do?

It defines a minimum and maximum size for a grid track.

Q5. Why use min-width: 0?

It allows a flex or grid item to shrink below its automatic min-content minimum where necessary.

Q6. What is object-fit: cover?

It scales replaced content to cover its content box while preserving its aspect ratio, potentially cropping it.

Q7. What is the purpose of aspect-ratio?

It establishes a preferred width-to-height ratio for an element's box.

Q8. Why use article for a card?

It represents a self-contained piece of content that can stand independently within a page.

Q9. What does gap do in CSS Grid?

It creates spacing between grid rows and columns, not around the outer edges of the grid container.

Q10. How would you prevent card content from overflowing?

Inspect intrinsic sizing, use appropriate track sizing, apply min-width: 0 where needed, and manage long text and media dimensions.

17. Key Takeaways

  • CSS Grid is effective for responsive card collections.
  • repeat() reduces repetitive track definitions.
  • auto-fit and minmax() support flexible layouts.
  • Flexbox can organize content inside individual cards.
  • aspect-ratio and object-fit help maintain consistent images.
  • min-width: 0 can solve common intrinsic sizing problems.
  • Responsive layouts must be tested at real viewport sizes.
