Analog Circuit Simulation Using LTspice

SPICE-based circuit analysis, schematic design, transient response and frequency-domain simulation.

2. What Is LTspice?

LTspice is a SPICE-based electronic circuit simulator used for analyzing analog circuits, especially power electronics, amplifiers, filters and semiconductor circuits.

Schematic editor

Draw circuits using symbols, wires, labels and component values.

SPICE engine

Solves circuit equations using numerical analysis methods.

Waveform viewer

Displays voltage and current results from simulations.

Model support

Uses component models and subcircuits to approximate real devices.

LTspice is useful for circuit analysis, but simulation results depend on the quality and accuracy of the models and the assumptions made by the designer.

4. Creating a New Schematic

  1. Install and open LTspice.
  2. Create a new schematic.
  3. Place the required components from the component library.
  4. Rotate and position components to make the circuit readable.
  5. Connect component pins using wires.
  6. Place a ground reference.
  7. Set resistor, capacitor, inductor and source values.
  8. Add required simulation commands.
  9. Save the schematic.
  10. Run the simulation and inspect the waveform viewer.
A circuit without the required ground reference may fail to simulate or produce floating-node errors. Grounding must match the intended circuit topology.

6. Understanding SPICE Netlists

A SPICE netlist describes a circuit through text statements. Each component statement specifies the component name, connected nodes and its value or model.

* Simple resistor divider V1 IN 0 DC 12 R1 IN OUT 10k R2 OUT 0 10k .op .end

Explanation:

  • V1 IN 0 DC 12: 12 V DC source between nodes IN and ground.
  • R1 IN OUT 10k: 10 kΩ resistor from IN to OUT.
  • R2 OUT 0 10k: 10 kΩ resistor from OUT to ground.
  • .op: Requests DC operating-point analysis.
  • .end: Ends the netlist.
In LTspice, many simulation directives can be placed through the graphical interface. The netlist is useful for understanding how the simulator represents the circuit.

9. DC Operating-Point Analysis

DC operating-point analysis determines the steady-state DC voltages and currents in a circuit.

Example: 12 V resistor divider

V1 IN 0 DC 12 R1 IN OUT 10k R2 OUT 0 10k .op

For equal resistors:

\[ V_{out}=12\times\frac{10k}{10k+10k}=6V \]

Current through both resistors:

\[ I=\frac{12}{20k}=0.6mA \]

In LTspice, run operating-point analysis and inspect the voltage at OUT and current through the resistors.

10. Transient Analysis

Transient analysis calculates how circuit voltages and currents change with time.

V1 IN 0 SINE(0 5 1k) R1 IN OUT 10k C1 OUT 0 100n .tran 0 10m 0 5u

This is an example of a sinusoidal input applied to a first-order RC low-pass filter. The transient command requests a 10 ms simulation interval with a specified maximum timestep.

What to observe

  • Input waveform amplitude and frequency.
  • Output waveform amplitude.
  • Phase difference between input and output.
  • Charging and discharging response.
  • Initial conditions and settling behaviour.

11. AC Frequency Sweep Analysis

AC analysis determines the small-signal frequency response of a circuit around its DC operating point.

V1 IN 0 AC 1 R1 IN OUT 10k C1 OUT 0 100n .ac dec 100 10 1Meg

Here, the AC input magnitude is 1 V. The simulator sweeps frequency logarithmically from 10 Hz to 1 MHz with 100 points per decade.

For a first-order RC low-pass filter:

\[ f_c=\frac{1}{2\pi RC} \]

At the cutoff frequency, the ideal magnitude is approximately −3 dB relative to its passband value.

14. Practical Simulation 1: Half-Wave Rectifier

Build a circuit using an AC voltage source, one diode and a load resistor.

V1 IN 0 SINE(0 10 50) D1 IN OUT D1N4007 R1 OUT 0 1k .tran 0 100m 0 20u

Use an appropriate diode model available in the installed LTspice library or define a suitable model. Plot input and output voltage.

Expected observations

  • Positive half-cycles produce forward conduction when the diode is forward biased.
  • Negative half-cycles are blocked in the idealized half-wave topology.
  • The output waveform is pulsating DC.
  • Peak output is lower than input peak by the diode's forward drop under the simulated operating condition.

15. Practical Simulation 2: Bridge Rectifier and Capacitor Filter

Use four diodes to create a bridge rectifier. Connect a load resistor and smoothing capacitor across the DC output.

Without capacitor

Output consists of full-wave rectified pulses.

With capacitor

Output is smoother because the capacitor discharges through the load between charging peaks.

Approximate peak-to-peak ripple:

\[ V_{r(pp)}\approx\frac{I_{load}}{2f_{line}C} \]

This approximation assumes a full-wave rectifier, reasonably small ripple and approximately constant load current. Actual ripple depends on diode conduction angle, transformer/source impedance and capacitor characteristics.

16. Practical Simulation 3: BJT Common-Emitter Amplifier

Simulate a common-emitter amplifier using a transistor, bias network, collector resistor, emitter resistor and coupling capacitors.

Analysis procedure

  1. Select a transistor model with suitable voltage and current ratings.
  2. Construct the DC bias network.
  3. Run .op analysis.
  4. Check collector current and collector-emitter voltage.
  5. Apply a small sinusoidal input.
  6. Run transient analysis.
  7. Plot input and output waveforms.
  8. Increase input amplitude carefully to observe clipping.
A correctly biased common-emitter amplifier generally produces an inverted output signal. Its actual gain depends on the operating point, transistor model, load and frequency.

17. Practical Simulation 4: MOSFET Switching Circuit

Use an appropriate MOSFET model to simulate a low-side switching circuit with a resistive load.

Important observations

  • Gate voltage relative to source.
  • Drain-source voltage during ON and OFF states.
  • Drain current and switching behaviour.
  • Power dissipation during switching.
  • Effect of gate resistor and load conditions.
MOSFET threshold voltage is not the voltage at which a device is guaranteed to be fully enhanced. Select a device with specified on-resistance at the actual gate-drive voltage.

18. Practical Simulation 5: Op-Amp Inverting Amplifier

Use a supported op-amp model with appropriate supply rails and negative feedback.

\[ A_v=-\frac{R_f}{R_{in}} \]

Example:

\[ R_f=100k\Omega,\quad R_{in}=10k\Omega \] \[ A_v=-10 \]

For a 100 mV peak input, the ideal output is −1 V peak, assuming the op-amp operates within its linear range.

Simulation checks

  • DC operating point.
  • Output saturation.
  • Gain and phase inversion.
  • Frequency-dependent gain.
  • Output waveform clipping and slew-rate limitation.

19. Practical Simulation 6: Switching Regulator

LTspice is particularly useful for analyzing switching power converters such as buck and boost regulators.

Buck converter observations

  • MOSFET switching waveform.
  • Inductor current ripple.
  • Output capacitor voltage ripple.
  • Diode or synchronous switch current.
  • Startup transient and settling behaviour.
  • Efficiency and component power dissipation.

For an ideal buck converter operating in continuous conduction mode:

\[ V_{out}\approx D V_{in} \]

where \(D\) is the switching duty ratio. Real converters have losses and control-loop behaviour that must be considered.

20. Measuring Results with the Waveform Viewer

  • Click a node to plot its voltage.
  • Select a component or branch to plot current where supported.
  • Add multiple traces to compare input and output signals.
  • Use cursors to measure time and voltage differences.
  • Zoom into switching edges or transient events.
  • Use logarithmic frequency axes for AC response plots.
  • Export or capture plots for design documentation.
Use consistent probe points and units when comparing theoretical, simulated and measured hardware results.

24. Placement Interview Questions

1. What is LTspice?
LTspice is a SPICE-based electronic circuit simulator used for analyzing analog and power electronic circuits.
2. What is a SPICE netlist?
A text-based description of circuit components, their node connections, model references and simulation commands.
3. What is the purpose of .op?
It calculates the DC operating point of the circuit.
4. What is the purpose of .tran?
It performs time-domain transient analysis.
5. What is AC analysis?
It calculates small-signal gain and phase response over a selected frequency range around the DC operating point.
6. What is the difference between transient and AC analysis?
Transient analysis shows time-domain behaviour, whereas AC analysis shows small-signal frequency-domain behaviour.
7. Why is ground required in many SPICE circuits?
The simulator needs a reference node for calculating node voltages. In SPICE, node 0 is the reference ground.
8. What is a semiconductor model?
A mathematical representation of semiconductor device behaviour used by the simulator.
9. Why can simulated and measured results differ?
Real components have tolerances, parasitic elements, temperature effects, layout effects and non-ideal behaviour that may not be fully represented by the model.
10. Does LTspice replace hardware testing?
No. Simulation helps predict circuit behaviour, but practical prototypes must still be tested for electrical, thermal, safety and manufacturing requirements.

26. Final Engineering Guidelines

  • Start with theoretical circuit calculations.
  • Use correct component models and parameter values.
  • Verify DC operating conditions before analyzing AC behaviour.
  • Choose simulation intervals and timestep carefully.
  • Use AC analysis for frequency response and transient analysis for time-domain waveforms.
  • Compare simulation results against expected calculations.
  • Record assumptions, model limitations and measurement results.
  • Verify important designs using suitable hardware tests.
For mains-powered, high-voltage and high-energy circuits, simulation does not replace electrical safety analysis, isolation design, component derating, protective-device coordination or qualified laboratory testing.
