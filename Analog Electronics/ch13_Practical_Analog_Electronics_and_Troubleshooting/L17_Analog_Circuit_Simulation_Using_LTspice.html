Lesson 17: Analog Circuit Simulation Using LTspice

SPICE Simulation, Circuit Analysis and Waveform Interpretation

1. Introduction to LTspice

LTspice is a SPICE-based electronic circuit simulation software developed by Analog Devices. It is used to design, simulate and analyze analog electronic circuits.

Engineers use LTspice to study circuit behavior before constructing physical hardware. It is particularly useful for analog circuits, power electronics, filters and switching converter designs.

Applications of LTspice

  • Analog circuit simulation.
  • Op-amp circuit analysis.
  • Diode and transistor circuit simulation.
  • Rectifier and filter analysis.
  • Voltage regulator simulation.
  • Power supply circuit design.
  • Frequency response analysis.
  • Switching converter analysis.
Learning Objective: Learn to create circuit schematics, configure simulation commands, run different types of analyses and interpret electrical waveforms using LTspice.

2. What is SPICE?

SPICE stands for Simulation Program with Integrated Circuit Emphasis.

It is a circuit simulation method used to calculate electrical behavior of electronic circuits using mathematical models.

SPICE Applications

  • DC operating-point calculation.
  • Transient response analysis.
  • AC frequency response analysis.
  • DC sweep analysis.
  • Semiconductor device modeling.
  • Power electronics simulation.

Common SPICE Elements

Element SPICE Identifier
Resistor R
Capacitor C
Inductor L
Independent Voltage Source V
Independent Current Source I
Diode D
BJT Q
MOSFET M

3. Installing and Opening LTspice

LTspice can be obtained from the official Analog Devices website.

Official website: Analog Devices – LTspice

Basic Installation Procedure

  1. Open the official Analog Devices LTspice page.
  2. Download the installer for your operating system.
  3. Run the installer.
  4. Follow the installation instructions.
  5. Launch LTspice.

LTspice is available for supported Windows and macOS systems. Check the official download page for current platform requirements and releases.

4. LTspice Interface and Basic Tools

LTspice provides a schematic editor, component library, simulation commands and waveform viewer.

Important Tools

  • New Schematic: Creates a new circuit design.
  • Component: Places electronic components.
  • Wire: Connects circuit terminals.
  • Ground: Defines the reference node.
  • Resistor: Places a resistor.
  • Capacitor: Places a capacitor.
  • Inductor: Places an inductor.
  • Voltage Source: Places a voltage source.
  • Run: Starts simulation.
  • SPICE Directive: Adds simulation commands or model statements.
Common keyboard shortcuts include: R for resistor, C for capacitor, L for inductor, G for ground, W for wire, F2 for component selection and Run to start simulation. Shortcuts may vary by version or configuration.

5. Creating a New Schematic

Procedure

  1. Open LTspice.
  2. Select File → New Schematic.
  3. Open the component selection tool.
  4. Select the required components.
  5. Place components on the schematic.
  6. Rotate components where required.
  7. Connect the components using wires.
  8. Add ground to the circuit.
  9. Set component values.
  10. Save the schematic file.

LTspice File Types

Extension Purpose
.asc Schematic file.
.raw Simulation waveform data.
.log Simulation log and messages.
.plt Waveform plot settings.
.lib / .sub Model library or subcircuit definitions.

7. Voltage Sources and Signal Configuration

Voltage sources provide the input signals required for circuit simulation.

Common Source Types

  • DC voltage source.
  • AC small-signal source.
  • Sine-wave source.
  • Pulse source.
  • Piecewise linear source.

SINE(0 1 1000)

A sine-wave source can be used to test amplifiers, filters and other analog circuits.

8. Ground and Circuit Connections

Every basic LTspice circuit requires an appropriate reference node. In SPICE, node 0 represents ground.

Ground Connection Procedure

  1. Select the ground symbol.
  2. Place it at the reference node.
  3. Connect the circuit return path to ground.
  4. Check that all intended connections are complete.
A missing ground reference commonly causes floating-node errors or prevents a circuit from solving correctly.

9. DC Operating Point Analysis

DC operating-point analysis calculates the steady-state voltages and currents in a circuit.

Applications

  • Checking transistor biasing.
  • Measuring DC node voltages.
  • Checking resistor currents.
  • Verifying operating conditions.

Simulation Command

.op

Add the operating-point command to the schematic and run the simulation. LTspice calculates the DC operating conditions of the circuit.

10. Transient Analysis

Transient analysis studies how voltage and current change with time.

Applications

  • Capacitor charging and discharging.
  • Rectifier output analysis.
  • Amplifier waveform analysis.
  • Switching circuit analysis.
  • Oscillator circuit analysis.

Simulation Command

.tran 10m

This command requests a transient simulation over a 10ms stop time.

After simulation, click a circuit node to display its voltage waveform. Click a component to inspect its current, where supported.

11. AC Sweep Analysis

AC analysis is used to study the frequency response of a circuit.

Applications

  • Low-pass filter analysis.
  • High-pass filter analysis.
  • Band-pass filter analysis.
  • Amplifier frequency response.
  • Gain and phase measurement.

Simulation Command Example

.ac dec 100 10 1Meg

This command performs a logarithmic frequency sweep with 100 points per decade from 10Hz to 1MHz.

AC analysis is a small-signal analysis around the calculated DC operating point. Set the source's AC amplitude, commonly to 1, when measuring a transfer function directly.

12. DC Sweep Analysis

DC sweep analysis changes a DC source over a selected range and calculates the circuit response.

Applications

  • Diode characteristic analysis.
  • Transistor input/output characteristics.
  • Voltage transfer characteristics.
  • Bias circuit analysis.
  • Comparator switching behavior.

Example Command

.dc V1 0 5 0.1

This command sweeps a voltage source named V1 from 0V to 5V in increments of 0.1V.

13. Practical Simulation 1: RC Low-Pass Filter

Objective

Simulate an RC low-pass filter and observe its frequency response.

Components Required

  • AC voltage source.
  • 1kΩ resistor.
  • 100nF capacitor.
  • Ground.

Circuit Connection

Connect the resistor between the input and output node. Connect the capacitor from the output node to ground.

Cutoff Frequency

\[ f_c = \frac{1}{2\pi RC} \] 
R = 1000 ohms
C = 100 nF

fc = 1 / (2 × 3.1416 × 1000 × 100 × 10^-9)

fc ≈ 1591.5 Hz

Simulation Procedure

  1. Create the RC circuit.
  2. Set the voltage source AC amplitude to 1V.
  3. Place the AC analysis command.
  4. Configure a logarithmic sweep.
  5. Run the simulation.
  6. Plot the output node voltage.
  7. Observe the gain reduction above the cutoff frequency.

Expected Result

The circuit passes low-frequency signals with relatively little attenuation. Signals above the cutoff frequency are increasingly attenuated.

14. Practical Simulation 2: RC High-Pass Filter

Objective

Simulate an RC high-pass filter and observe its frequency response.

Components Required

  • AC voltage source.
  • 100nF capacitor.
  • 1kΩ resistor.
  • Ground.

Circuit Connection

Connect the capacitor in series with the input signal. Connect the resistor between the output node and ground. Measure the output across the resistor.

Cutoff Frequency

\[ f_c = \frac{1}{2\pi RC} \]

For R = 1kΩ and C = 100nF, the cutoff frequency is approximately 1.59kHz.

Expected Result

Low-frequency signals are attenuated, while higher-frequency signals pass with relatively little attenuation.

15. Practical Simulation 3: Diode Rectifier

Objective

Simulate a half-wave rectifier using a diode and load resistor.

Components Required

  • Sinusoidal voltage source.
  • 1N4007 or suitable diode model.
  • 1kΩ resistor.
  • Ground.

Simulation Procedure

  1. Place a sinusoidal voltage source.
  2. Set the desired frequency and amplitude.
  3. Connect the diode in series with the load resistor.
  4. Connect the return path to the reference ground.
  5. Add a transient analysis command.
  6. Run the simulation.
  7. Plot input and output voltages.

Expected Result

The output waveform contains the conducting half-cycles of the input. The diode blocks the opposite half-cycles.

Add a capacitor across the load to study smoothing and ripple reduction.

16. Practical Simulation 4: BJT Switching Circuit

Objective

Simulate an NPN transistor as a low-side electronic switch.

Components Required

  • 2N2222 or suitable NPN transistor model.
  • 5V DC supply.
  • LED or suitable load model.
  • 330Ω load resistor for a low-current LED example.
  • 1kΩ base resistor.
  • Pulse voltage source.

Operating Principle

When sufficient base current is applied, the transistor turns ON and allows collector current to flow through the load. When the base drive is removed, the transistor turns OFF.

Simulation Procedure

  1. Place an NPN transistor model.
  2. Connect the emitter to ground.
  3. Connect the load between the positive supply and collector.
  4. Connect the input pulse source to the base through a resistor.
  5. Set the pulse source parameters.
  6. Run transient analysis.
  7. Observe base drive and collector voltage.

Expected Result

During the ON interval, collector voltage falls towards the saturation region. During the OFF interval, collector voltage rises towards the supply voltage through the load.

17. Practical Simulation 5: Op-Amp Inverting Amplifier

Objective

Simulate an inverting amplifier and verify its voltage gain.

Components Required

  • Suitable op-amp SPICE model.
  • Input resistor: 10kΩ.
  • Feedback resistor: 100kΩ.
  • Appropriate supply rails.
  • AC or transient input source.

Voltage Gain

\[ A_V = -\frac{R_f}{R_{in}} \] 
Rf = 100kΩ
Rin = 10kΩ

Av = -100k / 10k

Av = -10

Simulation Procedure

  1. Place a suitable op-amp model.
  2. Connect its power supply pins.
  3. Connect the non-inverting input to the reference node.
  4. Connect the input through 10kΩ to the inverting input.
  5. Connect 100kΩ feedback from output to inverting input.
  6. Apply a small input signal.
  7. Run transient analysis.
  8. Compare input and output amplitudes and phase.
The ideal gain equation assumes linear operation. Select an appropriate op-amp model and supply rails. Keep the input small enough to avoid output saturation or clipping.

18. Waveform Viewer and Measurements

LTspice provides a waveform viewer to display simulation results.

Common Measurements

  • Peak voltage.
  • Peak-to-peak voltage.
  • RMS voltage.
  • Frequency.
  • Time period.
  • Current waveform.
  • Phase difference.
  • Gain and phase response.

Important Equations

\[ V_{pp} = V_{max} - V_{min} \] \[ f = \frac{1}{T} \] \[ A_V = \frac{V_{out}}{V_{in}} \] \[ Gain(dB) = 20\log_{10}|A_V| \]

For a voltage gain of 10:

\[ Gain(dB) = 20\log_{10}(10)=20dB \]

19. Common LTspice Simulation Errors

Error Possible Cause Solution
Missing ground No reference node 0. Add a ground symbol.
Floating node Unconnected or undefined circuit node. Check circuit connections and DC paths.
Unknown subcircuit Missing model definition. Include the correct model file and reference.
Incorrect waveform Wrong source settings or circuit wiring. Verify source parameters and connections.
Convergence error Difficult operating point or numerical conditions. Inspect the circuit and simulation log.
No AC response AC source magnitude not configured. Set an AC amplitude on the input source.

20. LTspice and Proteus Comparison

Feature LTspice Proteus
Main Focus SPICE-based circuit simulation. Schematic capture, simulation and PCB design.
Analog Analysis Strong SPICE analysis capabilities. Supports analog circuit simulation.
Transient Analysis Yes Yes
AC Analysis Yes Supported analysis features depend on edition.
DC Sweep Yes Available through supported simulation features.
Microcontroller Simulation Not its main purpose. Supports selected microcontrollers and models.
PCB Design Not its main purpose. ARES PCB design environment.
Practical Difference: LTspice is particularly useful for detailed SPICE analysis of analog and power circuits. Proteus is useful when schematic simulation, selected microcontroller simulation and PCB design workflows are also required.

21. Advantages and Limitations of LTspice

Advantages

  • Free circuit simulation software.
  • Useful for analog and power electronics analysis.
  • Supports transient, AC and DC analyses.
  • Provides waveform plotting and measurement tools.
  • Supports custom SPICE models and subcircuits.
  • Useful for studying circuit behavior before hardware construction.

Limitations

  • Results depend on model accuracy.
  • Some manufacturer models may require additional setup.
  • Real PCB layout parasitics may not be included automatically.
  • EMI and thermal effects may require separate analysis.
  • Simulation cannot completely reproduce physical hardware behavior.

24. Lesson Summary

  • LTspice is a SPICE-based circuit simulation tool.
  • It is useful for analog and power electronics design.
  • Components are placed and connected in the schematic editor.
  • DC operating-point analysis calculates steady-state conditions.
  • Transient analysis studies circuit behavior over time.
  • AC sweep analysis studies frequency response.
  • DC sweep analysis studies circuit response to changing DC inputs.
  • Waveform viewer displays simulated voltage and current.
  • SPICE models represent electrical component behavior.
  • Physical testing is required to validate real-world performance.
Placement Tip: Practice explaining an RC filter, rectifier, BJT switch and op-amp amplifier using simulation results. Be prepared to explain the circuit equations, simulation commands, measured waveforms and practical limitations.

25. Safety and Simulation Precautions

  • Verify component models and pin connections.
  • Check voltage, current and power ratings.
  • Use realistic component values.
  • Check the simulation log when errors occur.
  • Do not treat simulation as proof of hardware safety.
  • Use isolation and appropriate protection when testing physical power circuits.
  • Validate important designs through controlled hardware testing.
