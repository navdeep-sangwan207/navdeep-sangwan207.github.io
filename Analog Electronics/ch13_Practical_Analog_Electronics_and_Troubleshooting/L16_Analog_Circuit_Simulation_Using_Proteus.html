Lesson 16: Analog Circuit Simulation Using Proteus

Schematic Design, Virtual Instruments and Circuit Analysis

1. Introduction to Proteus

Proteus is an electronic design automation (EDA) software suite used for schematic capture, circuit simulation and PCB design.

It is widely used by electronics students, engineers and designers to test circuit behavior before building physical hardware.

Proteus includes schematic capture and simulation capabilities through its ISIS environment. Its ARES environment is used for PCB layout design.

Applications of Proteus

  • Analog electronic circuit simulation.
  • Digital logic circuit simulation.
  • Microcontroller-based design and simulation.
  • Power supply circuit analysis.
  • Op-amp circuit testing.
  • Waveform observation.
  • PCB design and layout.
Learning Objective: Learn to create analog schematics, select components, connect virtual instruments, run simulations and analyze circuit waveforms using Proteus.

2. Proteus Software Environments

1. Proteus ISIS

ISIS is the schematic capture and circuit simulation environment.

It is used to:

  • Draw electronic circuit diagrams.
  • Select electronic components.
  • Connect wires and terminals.
  • Place virtual instruments.
  • Run circuit simulations.

2. Proteus ARES

ARES is used for PCB layout design. It helps arrange component footprints, route copper tracks and prepare PCB manufacturing outputs.

Environment Main Purpose
ISIS Schematic capture and circuit simulation.
ARES PCB layout and design.

3. Proteus Interface and Basic Tools

The Proteus schematic editor provides different tools for drawing, editing and simulating electronic circuits.

Important Interface Elements

  • Component Mode: Select and place components.
  • Terminals Mode: Place ground, power and other terminals.
  • Generator Mode: Add signal sources.
  • Virtual Instruments: Add meters and waveform instruments.
  • Wire Tool: Connect circuit components.
  • Simulation Controls: Start, pause and stop simulation.
  • Property Editor: Change component parameters.
The exact appearance and location of toolbar buttons can vary between Proteus versions. The underlying schematic and simulation workflow remains similar.

4. Creating a New Project

Basic Procedure

  1. Open Proteus Design Suite.
  2. Select the option to create a new project.
  3. Enter a project name.
  4. Select the project storage location.
  5. Choose schematic capture.
  6. Configure PCB layout if required.
  7. Complete the project creation wizard.
  8. Open the schematic editor.

For a basic analog circuit simulation, the schematic editor is sufficient. PCB layout is optional.

6. Wiring and Ground Connections

Components must be connected correctly to form a complete electrical circuit.

Basic Wiring Procedure

  1. Move the cursor to a component terminal.
  2. Start the wire connection.
  3. Move to the destination terminal.
  4. Complete the connection.
  5. Repeat for all circuit connections.
  6. Add ground and power terminals where required.

Importance of Ground

Ground provides the reference node for circuit voltage measurements and simulation. A missing or incorrect reference can cause simulation errors.

Do not assume that a visually nearby wire is electrically connected. Check junctions, component terminals and ground references before starting the simulation.

8. Virtual Oscilloscope

A virtual oscilloscope displays electrical waveforms against time.

Applications

  • Observing sine waves.
  • Measuring peak-to-peak voltage.
  • Measuring frequency and time period.
  • Observing amplifier output.
  • Checking rectifier ripple.
  • Comparing input and output signals.

Important Measurements

Peak-to-Peak Voltage:

Vpp = Vmax - Vmin

Time Period:

T = 1 / f

Frequency:

f = 1 / T

For a sine wave with zero DC offset:

\[ V_{RMS} = \frac{V_{peak}}{\sqrt{2}} \]

11. Practical Simulation 1: LED Circuit

Objective

Simulate a basic LED circuit using a DC voltage source and current-limiting resistor.

Components Required

  • 5V DC source.
  • Red LED.
  • 330Ω resistor.
  • Ground terminal.

Circuit Connection

Connect the positive terminal of the 5V source to the 330Ω resistor. Connect the resistor to the LED anode. Connect the LED cathode to ground.

Current Calculation

\[ I = \frac{V_S - V_F}{R} \]

Assume:

Supply voltage = 5 V
LED forward voltage = 2 V
Resistance = 330 ohms

I = (5 - 2) / 330

I = 0.00909 A

I = 9.09 mA

Simulation Procedure

  1. Place the DC source.
  2. Place the resistor and LED.
  3. Connect them in series.
  4. Connect the LED cathode to ground.
  5. Set the source voltage to 5V.
  6. Set resistor value to 330Ω.
  7. Start simulation.
  8. Observe the LED and measure branch current.

Expected Result

The LED should glow in the simulation and the branch current should be approximately 9.09mA under the stated assumptions.

12. Practical Simulation 2: Half-Wave Rectifier

Objective

Simulate a half-wave rectifier and observe its output waveform.

Components Required

  • AC voltage source.
  • 1N4007 diode.
  • 1kΩ load resistor.
  • Oscilloscope.
  • Ground terminal.

Circuit Operation

During the positive half-cycle, the diode conducts and current flows through the load. During the negative half-cycle, the diode blocks current.

Simulation Procedure

  1. Place an AC voltage source.
  2. Place a 1N4007 diode.
  3. Connect the diode in series with the load resistor.
  4. Connect the load return to the source reference.
  5. Set the source frequency and amplitude.
  6. Connect the oscilloscope to the input and output nodes.
  7. Run the simulation.
  8. Compare the input sine wave and rectified output.
The output is pulsating DC. A filter capacitor can be added across the load to reduce ripple.

13. Practical Simulation 3: Inverting Op-Amp

Objective

Simulate an inverting amplifier using an operational amplifier.

Components Required

  • LM358 or another suitable op-amp model.
  • Input resistor: 10kΩ.
  • Feedback resistor: 100kΩ.
  • Dual supply or suitable single supply.
  • Signal generator.
  • Oscilloscope.

Voltage Gain

\[ A_V = -\frac{R_f}{R_{in}} \] 
Feedback resistance = 100 kΩ
Input resistance = 10 kΩ

Av = -100k / 10k

Av = -10

If the input is a 100mV sine wave, the ideal output amplitude is 1V, inverted in phase, provided the amplifier operates within its supply and output-swing limits.

Simulation Procedure

  1. Place the op-amp model.
  2. Connect the supply pins correctly.
  3. Connect the non-inverting input to the reference ground.
  4. Connect the input signal through the 10kΩ resistor to the inverting input.
  5. Connect the 100kΩ feedback resistor between output and inverting input.
  6. Apply a low-amplitude sine wave.
  7. Connect the oscilloscope to input and output.
  8. Run the simulation and measure gain.
Check the exact pinout and power requirements of the selected op-amp model. An LM358 is not a rail-to-rail output device, and its output swing depends on load and supply.

14. Practical Simulation 4: Zener Voltage Regulator

Objective

Simulate a simple Zener shunt regulator and observe the regulated output voltage.

Components Required

  • 12V DC source.
  • 5.1V Zener diode.
  • 680Ω series resistor.
  • 1kΩ load resistor.

Working Principle

The Zener diode is connected in reverse bias across the load. When it operates in its breakdown region and has sufficient current, it maintains an approximately constant voltage across the load.

Basic Current Calculation

Supply voltage = 12 V
Zener voltage = 5.1 V
Series resistance = 680 ohms

Series current (without load):

Is = (12 - 5.1) / 680

Is = 10.15 mA

The load current must be subtracted from the series current to determine the Zener current. Check that the remaining Zener current is sufficient for regulation and that resistor and Zener power ratings are not exceeded.

15. Analog Simulation Analysis

After running a simulation, the circuit should be analyzed using measured values and waveform observations.

Important Parameters

  • Input voltage.
  • Output voltage.
  • Branch current.
  • Voltage gain.
  • Frequency response.
  • Ripple voltage.
  • Power dissipation.
  • Transient response.

Comparing Theoretical and Simulated Results

Calculate expected circuit values using electronic formulas and compare them with the simulation results.

\[ \%\ Error = \frac{|V_{theoretical}-V_{simulated}|} {|V_{theoretical}|}\times100 \]

Differences may result from component models, device parameters, numerical settings and non-ideal operating behavior.

16. Transient and Frequency Analysis

Transient Analysis

Transient analysis studies circuit behavior as it changes with time.

Applications:

  • Capacitor charging and discharging.
  • Rectifier startup behavior.
  • Switching response.
  • Amplifier output response.

Frequency Analysis

Frequency analysis studies how a circuit responds to different input frequencies.

Applications:

  • Low-pass filter response.
  • High-pass filter response.
  • Band-pass filter response.
  • Amplifier bandwidth analysis.
Proteus simulation features and analysis options depend on the installed edition and available licenses.

17. Common Proteus Simulation Errors

Error Possible Cause Solution
Simulation does not start Missing model or invalid circuit configuration. Check components and simulation messages.
Ground error Missing reference ground. Add the correct ground terminal.
Incorrect output Wrong connections or component values. Verify the schematic and component properties.
Unexpected waveform Incorrect source parameters or probe connection. Check amplitude, frequency and reference.
Model not found Unavailable simulation model. Select a supported component model.
Convergence problem Numerically difficult circuit conditions. Check circuit topology and simulation settings.

18. Advantages and Limitations of Proteus

Advantages

  • Allows circuit testing without immediately building hardware.
  • Provides virtual instruments.
  • Supports many common analog components.
  • Helps identify wiring mistakes.
  • Supports schematic and PCB design workflows.
  • Useful for education and prototyping.

Limitations

  • Simulation depends on the accuracy of component models.
  • Not every real-world parasitic effect is modeled.
  • Some components may not have available simulation models.
  • Thermal, EMI and layout effects may require additional analysis.
  • Simulation cannot replace physical testing and validation.

22. Safety and Simulation Precautions

  • Verify component pinouts and supply ratings.
  • Check all connections before running the simulation.
  • Use realistic component values.
  • Check current and power dissipation ratings.
  • Do not assume simulated circuits are safe to build directly.
  • Use appropriate isolation and safety procedures for mains-related designs.
  • Validate important designs through controlled hardware testing.
