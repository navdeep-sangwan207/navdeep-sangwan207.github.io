Analog Circuit Simulation Using Proteus

Schematic capture, virtual instruments, circuit simulation and waveform analysis.

1. Learning Objectives

  • Understand the purpose of electronic circuit simulation.
  • Identify the main areas of the Proteus Design Suite.
  • Create analog circuit schematics using component libraries.
  • Configure voltage sources, resistors, capacitors, diodes and transistors.
  • Use virtual instruments such as oscilloscopes and signal generators.
  • Perform DC operating-point and transient simulations.
  • Analyze rectifier, filter, amplifier and oscillator circuits.
  • Identify common simulation errors and troubleshoot them.

2. What Is Proteus?

Proteus Design Suite is an electronic design environment used for schematic capture, circuit simulation and PCB design. Its ISIS schematic environment is commonly used to construct and simulate electronic circuits.

Schematic capture

Create circuit diagrams by placing and wiring electronic components.

Simulation

Analyze supported analog and digital circuit behaviour.

Virtual instruments

Measure voltage, current, waveform and frequency in supported simulations.

PCB design

Transfer a schematic into PCB layout workflows using supported design features.

Proteus capabilities depend on the installed edition, libraries, simulation models and licensing. Not every physical component has a usable simulation model.

4. Creating a New Analog Project

  1. Open Proteus and create a new project.
  2. Enter a meaningful project name, such as Bridge_Rectifier_Simulation.
  3. Select the schematic capture workflow.
  4. Choose the required sheet and design settings.
  5. Open the component selection dialog.
  6. Search for components by name or device type.
  7. Place components on the schematic sheet.
  8. Rotate and arrange components according to the circuit design.
  9. Connect pins using the wiring tool.
  10. Add ground and power terminals as required.
  11. Save the project before simulation.
Use clear component names and reference designators. A readable schematic makes debugging and technical review easier.

  • Connect component pins using the wiring tool.
  • Use junctions to represent electrical connections.
  • Use net labels to identify related nodes where supported.
  • Check that wires terminate on actual component pins.
  • Connect the required ground reference.
  • Verify supply polarity before running the simulation.

7. Simulation Types

DC operating point

Finds steady-state node voltages and branch currents for a DC operating condition.

Transient analysis

Shows how voltages and currents vary with time.

AC analysis

Evaluates small-signal frequency response around an operating point.

Parameter sweep

Evaluates circuit behaviour as selected component or source values change, where supported.

9. Practical Simulation 1: Half-Wave Rectifier

A half-wave rectifier uses a diode to pass one polarity of an AC input waveform and block the other polarity.

Simulation procedure

  1. Place an AC sinusoidal source.
  2. Add a rectifier diode and load resistor.
  3. Connect the circuit according to the schematic.
  4. Set the source amplitude and frequency.
  5. Connect an oscilloscope to the input and output nodes.
  6. Run transient simulation for several input cycles.
  7. Compare the input sine wave with the rectified output.
A real diode has a forward voltage drop and reverse-recovery behaviour. Results depend on the selected diode model and simulation conditions.

10. Practical Simulation 2: Bridge Rectifier with Capacitor Filter

A bridge rectifier uses four diodes to produce full-wave rectification. A capacitor connected across the load reduces output ripple.

Observe these quantities

  • Input AC waveform.
  • Full-wave rectified waveform.
  • Filtered DC output waveform.
  • Ripple voltage across the load.

For a capacitor-input filter, a useful approximate ripple relation is:

\[ V_{r(pp)}\approx\frac{I_{load}}{f_{ripple}C} \]

For a full-wave rectifier, the ripple frequency is approximately twice the AC supply frequency.

11. Practical Simulation 3: RC Low-Pass Filter

An RC low-pass filter passes lower frequencies more readily and attenuates higher frequencies.

Cutoff frequency:

\[ f_c=\frac{1}{2\pi RC} \]

At the ideal first-order cutoff frequency, the magnitude is approximately 0.707 of the passband value, or −3 dB.

14. Practical Simulation 4: Inverting Op-Amp Amplifier

An inverting amplifier produces an output voltage with opposite polarity to the input.

\[ A_v=-\frac{R_f}{R_{in}} \]

For example, if \(R_f=100\,k\Omega\) and \(R_{in}=10\,k\Omega\), the ideal closed-loop gain is −10.

Simulation steps

  1. Select a suitable op-amp model.
  2. Connect the non-inverting input to the required reference.
  3. Connect the input resistor to the inverting input.
  4. Connect the feedback resistor between output and inverting input.
  5. Connect suitable supply rails for the selected op-amp model.
  6. Apply a small sinusoidal input.
  7. Observe the input and output waveforms on the oscilloscope.
  8. Compare the simulated gain and phase inversion with theoretical values.
The ideal gain equation does not guarantee that the physical output can reach the calculated voltage. Check op-amp supply voltage, input common-mode range, output swing, slew rate and bandwidth.

16. Practical Simulation 5: BJT Common-Emitter Amplifier

A common-emitter amplifier provides voltage amplification and typically produces an inverted output waveform.

Important simulation observations

  • Collector DC voltage and transistor operating point.
  • Base-emitter voltage and base current.
  • Collector current and load voltage.
  • Input and output AC waveforms.
  • Clipping caused by excessive input amplitude or incorrect bias.
  • Effect of coupling and bypass capacitors on low-frequency response.

Use a suitable transistor model, bias network, collector resistor, emitter resistor and coupling capacitors. Verify the operating point before applying a large AC input.

17. Practical Simulation 6: 555 Timer Astable Circuit

Proteus can be used to examine the output pulse train and capacitor charging/discharging behaviour of a supported 555 timer model.

For the standard astable configuration:

\[ f\approx\frac{1.44}{(R_A+2R_B)C} \]
  • Observe the output square wave.
  • Observe capacitor voltage rising and falling between threshold levels.
  • Measure the high and low output times.
  • Compare measured frequency with the theoretical estimate.

20. Placement Interview Questions

1. What is Proteus used for?
Proteus is an electronic design suite used for schematic capture, circuit simulation and PCB design workflows.
2. What is schematic capture?
It is the process of drawing an electronic circuit using symbols and electrical connections.
3. What is transient analysis?
Transient analysis calculates circuit behaviour as a function of time.
4. What is a virtual oscilloscope?
It is a simulated measurement instrument that displays voltage waveforms against time.
5. What is a DC operating point?
It is the steady-state DC voltage and current condition of a circuit.
6. Why does an op-amp output saturate?
The requested output may exceed the available output swing, or the input and feedback conditions may force the amplifier toward a supply limit.
7. What is the purpose of a signal generator?
It provides test signals such as sine waves, square waves and other supported waveforms.
8. Why might a simulation differ from hardware?
Models may omit parasitic effects, component tolerances, temperature variation, PCB layout effects and real instrument limitations.
9. What is a component simulation model?
It is a mathematical representation used by the simulator to approximate a component's electrical behaviour.
10. Does successful simulation guarantee hardware operation?
No. Hardware must still be checked for component ratings, PCB layout, parasitics, thermal behaviour, safety and manufacturing tolerances.

21. Numerical and Practical Exercises

  1. A 10 kΩ resistor and 100 nF capacitor form an RC low-pass filter. Calculate its cutoff frequency.
  2. An inverting amplifier has \(R_{in}=10\,k\Omega\) and \(R_f=47\,k\Omega\). Calculate its ideal gain.
  3. A full-wave rectifier operates from a 50 Hz AC source. Calculate the ripple frequency.
  4. A filter capacitor supplies 100 mA at 100 Hz ripple frequency. Estimate the ripple for a 1000 µF capacitor using the approximate capacitor-filter equation.
  5. Explain how you would verify an op-amp amplifier's simulated gain using a virtual oscilloscope.
  6. Describe how you would troubleshoot a Proteus circuit that displays no output waveform.

22. Important Engineering Practice

Simulation is a design and analysis tool, not a substitute for safe hardware testing. Before building a circuit, verify voltage ratings, current limits, component dissipation, thermal performance, isolation requirements and PCB clearances. Never use a simulation result as proof that a mains-powered circuit is safe.
  • Save project files and use meaningful revision names.
  • Record component values and source settings.
  • Capture waveforms and label measurement points.
  • Compare results against theoretical calculations.
  • Document assumptions and known model limitations.
