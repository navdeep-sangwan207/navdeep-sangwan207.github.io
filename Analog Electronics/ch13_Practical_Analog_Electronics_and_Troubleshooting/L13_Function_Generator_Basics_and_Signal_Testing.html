Lesson 13: Function Generator Basics and Signal Testing

Waveform Generation, Signal Parameters and Practical Testing

1. Introduction

A function generator is an electronic test instrument used to generate electrical signals with controlled waveform, frequency, amplitude and offset.

It is widely used to test amplifiers, filters, oscillators, comparators, sensors, control circuits and other electronic systems.

Engineers use a function generator to apply known input signals and observe how a circuit responds.

Learning Objective: Understand function generator controls, generate common waveforms, adjust signal parameters and test analog electronic circuits using a function generator and oscilloscope.

2. What is a Function Generator?

A function generator produces periodic electrical waveforms at selected frequencies and amplitudes.

Common Functions

  • Sine wave generation.
  • Square wave generation.
  • Triangle wave generation.
  • Pulse generation.
  • Ramp and sawtooth wave generation.
  • Arbitrary waveform generation on suitable instruments.

3. Types of Function Generators

Analog Function Generator

Analog function generators use electronic circuits such as oscillators, integrators and waveform-shaping networks to produce signals.

Direct Digital Synthesis (DDS) Generator

A DDS generator digitally creates waveforms using a phase accumulator, waveform data and a digital-to-analog conversion stage.

Arbitrary Waveform Generator (AWG)

An arbitrary waveform generator can create user-defined waveforms from stored digital samples.

Type Feature Application
Analog Generator Analog waveform generation Basic laboratory testing
DDS Generator Digitally controlled frequency and waveform Precision signal generation
AWG User-defined waveform generation Advanced circuit and system testing

4. Common Function Generator Controls

1. Frequency Control

Frequency control determines how many waveform cycles are generated per second. 

Frequency = Number of cycles per second

Unit = Hertz (Hz)

2. Amplitude Control

Amplitude controls the magnitude of the output waveform. Instruments commonly specify amplitude as peak-to-peak voltage.

3. DC Offset Control

DC offset shifts the waveform upward or downward relative to zero volts.

4. Waveform Selection

Selects sine, square, triangle, pulse or another available waveform.

5. Duty Cycle Control

Duty cycle controls the percentage of one period during which a pulse waveform remains HIGH.

6. Output Enable

Enables or disables the signal output.

5. Sine Wave Generation

A sine wave is a smooth periodic signal commonly used for testing amplifiers, filters and oscillator circuits.

Mathematical Expression

v(t) = Vm sin(2πft)

Where:

  • Vm = Peak amplitude.
  • f = Frequency.
  • t = Time.

Applications

  • Amplifier frequency response testing.
  • Active and passive filter testing.
  • Oscillator testing.
  • Audio circuit testing.

6. Square Wave Generation

A square wave alternates between HIGH and LOW voltage levels.

Applications

  • Digital circuit testing.
  • Clock input testing.
  • Switching circuit analysis.
  • Pulse response testing.
  • Logic-level circuit experiments.

7. Triangle Wave Generation

A triangle wave consists of approximately linear rising and falling voltage ramps.

Applications

  • Integrator circuit testing.
  • Waveform-shaping circuit testing.
  • Modulation experiments.
  • Comparator circuit testing.

8. Pulse and Duty Cycle Control

A pulse waveform consists of repeated HIGH and LOW intervals.

Duty Cycle Formula

Duty Cycle (%) = (Ton / T) x 100

T = Ton + Toff

Example

Ton = 2 ms
Toff = 8 ms

T = 2 + 8

T = 10 ms

Duty Cycle = (2 / 10) x 100

Duty Cycle = 20%

Duty cycle is important in pulse testing, digital electronics and PWM-based control.

9. Frequency and Time Period

Frequency and time period are inversely related. 

f = 1 / T

T = 1 / f

Example 1: 1 kHz Signal

f = 1000 Hz

T = 1 / 1000

T = 0.001 seconds

T = 1 ms

Example 2: 10 kHz Signal

f = 10000 Hz

T = 1 / 10000

T = 0.0001 seconds

T = 100 µs

10. Understanding Amplitude and DC Offset

A function generator's amplitude setting and DC offset determine the waveform's voltage range.

Example

Peak-to-peak amplitude = 4 V

DC offset = +2 V

Peak amplitude = 4 / 2

Peak amplitude = 2 V

Maximum voltage = +2 + 2 = +4 V

Minimum voltage = +2 - 2 = 0 V
Check whether the generator specifies amplitude for a 50 Ω load or a high-impedance load. The actual output voltage may differ depending on the termination and instrument output impedance.

11. Output Impedance and Load Matching

Function generator outputs commonly have a specified source impedance, often 50 Ω.

The load connected to the generator can affect the voltage measured at the output.

Important Points

  • Check the generator's specified output impedance.
  • Check whether the amplitude is displayed for 50 Ω or high impedance.
  • Use suitable termination when required.
  • Avoid connecting a low-impedance load that exceeds the output current rating.
  • Verify the actual signal using an oscilloscope.

12. Modulation Features

Some advanced function generators provide modulation capabilities.

Amplitude Modulation (AM)

In amplitude modulation, the amplitude of a carrier signal changes according to a modulating signal.

Frequency Modulation (FM)

In frequency modulation, the instantaneous frequency of a carrier signal changes according to a modulating signal.

Frequency Sweep

A frequency sweep gradually changes the output frequency over a selected range.

Burst Mode

Burst mode generates a selected number of waveform cycles or a controlled group of cycles.

13. Testing an Amplifier Using a Function Generator

A function generator can provide a known input signal to test an amplifier's gain and frequency response.

Procedure

  1. Connect the function generator output to the amplifier input.
  2. Set a low-amplitude sine wave.
  3. Set a suitable test frequency.
  4. Connect an oscilloscope to the amplifier input and output.
  5. Measure both signal amplitudes.
  6. Calculate voltage gain.
  7. Increase frequency gradually to evaluate frequency response.

Voltage Gain

Av = Vout / Vin

Example

Vin = 100 mV
Vout = 1 V

Av = 1 / 0.1

Av = 10

14. Testing Filters Using a Function Generator

A function generator is useful for testing low-pass, high-pass, band-pass and band-stop filters.

Testing Procedure

  1. Connect the generator to the filter input.
  2. Apply a sine wave at a low frequency.
  3. Measure input and output amplitudes.
  4. Increase the frequency in steps.
  5. Record the output amplitude at each frequency.
  6. Identify the passband and stopband behavior.
  7. Determine the cutoff frequency where applicable.
Gain (dB) = 20 log10(Vout / Vin)
For a first-order low-pass or high-pass filter, the cutoff frequency corresponds to an amplitude ratio of approximately 0.707 of the passband value, or -3 dB.

15. Testing a Comparator Using a Function Generator

A function generator can provide a variable input signal to test comparator switching behavior.

Procedure

  1. Connect a suitable reference voltage to one comparator input.
  2. Apply a low-frequency sine or triangular waveform to the other input.
  3. Observe the output using an oscilloscope.
  4. Identify the input voltage at which switching occurs.
  5. Compare the switching level with the reference voltage.

A triangle wave is particularly useful for observing switching thresholds.

16. Common Function Generator Problems

Problem Possible Cause Correction
No output signal Output disabled or incorrect connection. Enable output and check cables.
Incorrect amplitude Load impedance mismatch. Check output termination settings.
Wrong frequency Incorrect frequency setting. Verify using an oscilloscope.
Distorted waveform Overload or amplitude limitation. Reduce amplitude and check load.
Incorrect DC level Offset setting error. Check offset and waveform limits.
Unexpected waveform Wrong waveform selection. Verify waveform mode.
Unstable measurement Trigger or connection issue. Check oscilloscope triggering and grounding.

17. Practical Laboratory Exercise

Objective

Generate sine, square and triangle waveforms using a function generator and measure their parameters using an oscilloscope.

Required Instruments

  • Function generator.
  • Digital storage oscilloscope.
  • Oscilloscope probe.
  • BNC cables.
  • Suitable low-voltage test circuit.

Procedure

  1. Connect the function generator output to the oscilloscope input.
  2. Select sine waveform.
  3. Set frequency to 1 kHz.
  4. Set amplitude to 2 V peak-to-peak.
  5. Set DC offset to zero.
  6. Enable output.
  7. Measure voltage and frequency on the oscilloscope.
  8. Repeat using square and triangle waveforms.
  9. Compare measured values with generator settings.

Observation Table

Waveform Set Frequency Set Amplitude Measured Frequency
Sine 1 kHz 2 Vpp Record
Square 1 kHz 2 Vpp Record
Triangle 1 kHz 2 Vpp Record

Expected Result

The oscilloscope should display the selected waveforms with frequency and amplitude close to the generator settings, subject to instrument specifications and load conditions.

19. Lesson Summary

  • A function generator produces controlled electrical test signals.
  • Common outputs include sine, square, triangle and pulse waveforms.
  • Frequency controls the number of cycles per second.
  • Amplitude controls the signal magnitude.
  • DC offset shifts the waveform relative to zero volts.
  • Duty cycle describes the HIGH-time percentage of a pulse period.
  • Output impedance affects the voltage delivered to the load.
  • Function generators are useful for testing amplifiers, filters and comparators.
  • An oscilloscope verifies the actual output signal.
Placement Tip: Practice generating a 1 kHz sine wave, adjusting its amplitude and DC offset, and measuring the actual output with an oscilloscope. Also understand how a function generator is used for amplifier and filter testing.

20. Safety Precautions

  • Check the maximum input voltage of the circuit under test.
  • Start with a low signal amplitude.
  • Verify DC offset before connecting sensitive circuits.
  • Check the output impedance and termination settings.
  • Avoid exceeding the function generator output limits.
  • Use suitable grounding and shielded cables.
  • Switch OFF output before changing circuit connections where appropriate.
Never apply a high-amplitude signal directly to a sensitive IC input. Check the permitted input voltage and signal range before testing.
