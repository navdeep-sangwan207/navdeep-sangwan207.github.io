Lesson 4: BJT Testing Using a Multimeter

NPN and PNP Identification, Terminal Testing and Fault Diagnosis

1. Introduction

A Bipolar Junction Transistor (BJT) is a three-terminal semiconductor device used for amplification and switching. It consists of three semiconductor regions called emitter, base and collector.

BJTs are widely used in analog amplifiers, switching circuits, relay drivers, signal conditioning circuits and electronic control systems.

A digital multimeter can be used to perform basic transistor junction tests and identify common faults.

Learning Objective: Identify NPN and PNP transistors, understand their terminals, test their PN junctions using a multimeter and identify open, shorted and damaged transistors.

2. Basic Construction of a BJT

A BJT consists of three semiconductor regions:

  • Emitter: Supplies majority charge carriers.
  • Base: Controls the transistor operation.
  • Collector: Collects charge carriers.

A BJT contains two PN junctions:

  • Base-Emitter junction (BE).
  • Base-Collector junction (BC).

3. Types of BJT

BJTs are classified into two main types:

3.1 NPN Transistor

An NPN transistor has a P-type base region between two N-type regions. In normal active operation, the base is more positive than the emitter.

The emitter arrow points outward in an NPN transistor.

3.2 PNP Transistor

A PNP transistor has an N-type base region between two P-type regions. In normal active operation, the base is more negative than the emitter.

The emitter arrow points inward in a PNP transistor.

Remember: NPN = arrow Not Pointing iN. PNP = arrow Pointing iN. The arrow direction helps distinguish the two transistor types.

4. Common BJT Part Numbers

Part Number Type Typical Application

BC548 NPN Low-noise signal amplification
BC557 PNP Small-signal amplification and switching

Pin arrangements can differ between transistor types, manufacturers and package variants. Always check the exact datasheet before connecting a transistor.

5. BJT Terminal Identification

A transistor has three terminals: collector, base and emitter. Their physical positions depend on the transistor model and package.

Example: BC547

A common BC547 TO-92 package is specified with a C-B-E pin arrangement when viewed from the flat side, with the leads pointing downward. Verify the exact manufacturer's datasheet before use.

Do not assume that all TO-92 transistors use the same pin arrangement. Some devices use E-B-C, E-C-B or other arrangements.

6. BJT Operating Regions

A BJT operates in different regions depending on the biasing of its base-emitter and base-collector junctions.

Operating Region Junction Condition Application
Cutoff Both junctions reverse biased in the usual NPN case. OFF state in switching.
Active BE forward biased, BC reverse biased. Signal amplification.
Saturation Both junctions forward biased in the usual NPN case. ON state in switching.

7. Introduction to BJT Testing Using a DMM

A BJT can be treated as two PN junctions connected through a common base region for basic diode-mode testing.

A multimeter's diode mode can help identify the base terminal, transistor polarity and common junction faults.

Preparation

  1. Switch OFF the circuit power.
  2. Remove the transistor from the circuit or isolate its terminals where necessary.
  3. Discharge nearby capacitors safely.
  4. Identify the transistor part number.
  5. Check its package and datasheet.
  6. Set the DMM to diode mode.
In-circuit testing can give misleading readings because surrounding resistors, diodes and other components create parallel current paths. Isolate the transistor when accurate identification is required.

8. Testing an NPN Transistor

In an NPN transistor, the base is P-type while the emitter and collector are N-type.

Step 1: Identify the Base Terminal

  1. Set the multimeter to diode mode.
  2. Connect the red probe to one transistor terminal.
  3. Touch the black probe to each of the other two terminals in turn.
  4. Repeat for the remaining terminals if needed.
  5. Look for a terminal that gives forward-junction readings to both other terminals when the red probe is connected to it.

For a typical NPN transistor, the base is positive relative to the emitter and collector when testing the two junctions in forward bias.

Step 2: Test Base-Emitter Junction

  • Red probe to base.
  • Black probe to emitter.
  • Observe the forward voltage.

Step 3: Test Base-Collector Junction

  • Red probe to base.
  • Black probe to collector.
  • Observe the forward voltage.

Step 4: Reverse the Probe Connections

  • Black probe to base and red probe to emitter.
  • Black probe to base and red probe to collector.
  • Both junctions should normally block in reverse bias.
Test Red Probe Black Probe Expected Result
BE forward Base Emitter Forward junction voltage
BE reverse Emitter Base OL
BC forward Base Collector Forward junction voltage
BC reverse Collector Base OL

9. Testing a PNP Transistor

A PNP transistor has an N-type base between two P-type regions. Its diode-test probe polarity is opposite to that of an NPN transistor.

Step 1: Identify the Base Terminal

For a typical PNP transistor, the base is negative relative to the emitter and collector when testing the two junctions in forward bias.

Step 2: Test Base-Emitter Junction

  • Black probe to base.
  • Red probe to emitter.
  • Observe the forward voltage.

Step 3: Test Base-Collector Junction

  • Black probe to base.
  • Red probe to collector.
  • Observe the forward voltage.

Step 4: Reverse the Probe Connections

Reverse each pair of probes. Both junctions should normally show OL in reverse bias.

Test Red Probe Black Probe Expected Result
BE forward Emitter Base Forward junction voltage
BE reverse Base Emitter OL
BC forward Collector Base Forward junction voltage
BC reverse Base Collector OL

10. Typical BJT Junction Test Readings

A silicon BJT junction may show a forward voltage around 0.55 V to 0.8 V under typical multimeter diode-test conditions.

The actual reading depends on the transistor type, test current, temperature and multimeter. Use the datasheet for guaranteed device specifications.
Observation Possible Interpretation
Both junctions show forward voltage in the correct polarity. Junctions appear functional.
Both junctions show OL in both directions. Possible open junction or incorrect terminal identification.
Very low reading in both directions. Possible shorted junction.
One junction behaves abnormally. Possible damaged junction or measurement interference.

11. Testing BJT Gain (hFE)

Some digital multimeters include an hFE socket for measuring the approximate DC current gain of a transistor.

The DC current gain is defined as: 

hFE = IC / IB

Where:

  • IC = Collector current.
  • IB = Base current.

Procedure

  1. Check whether the DMM supports hFE measurement.
  2. Identify the transistor type: NPN or PNP.
  3. Identify the collector, base and emitter terminals using the datasheet.
  4. Insert the transistor into the correct hFE socket positions.
  5. Select the appropriate NPN or PNP setting.
  6. Read the displayed gain value.
The hFE socket provides an approximate measurement under the meter's own test conditions. It is not a complete transistor performance test and may differ from datasheet gain values measured at specified currents and voltages.

12. Common BJT Faults

12.1 Open Transistor Junction

An open base-emitter or base-collector junction can prevent the transistor from operating correctly.

12.2 Shorted Transistor

A shorted transistor may show very low resistance or conduction between terminals that should be isolated.

12.3 Leaky Transistor

A leaky transistor may allow excessive current through a reverse-biased junction. A basic diode test may not detect all leakage faults.

12.4 Reduced Gain

A damaged transistor may have lower current gain than expected. Gain must be checked under comparable operating conditions before deciding that a transistor is defective.

12.5 Thermal Damage

Excessive junction temperature, overload current or insufficient heat dissipation can permanently damage a transistor.

13. Difference Between NPN and PNP Testing

Parameter NPN PNP
Base type P-type N-type
Emitter type N-type P-type
Collector type N-type P-type
Forward BE test Red to base Black to base
Forward BC test Red to base Black to base
Conventional collector current Collector to emitter Emitter to collector

14. Practical Laboratory Exercise

Objective

Identify NPN and PNP transistors, test their base-emitter and base-collector junctions using a digital multimeter, and check their approximate hFE values if supported.

Required Components and Equipment

  • Digital multimeter with diode mode.
  • BC547 NPN transistor.
  • BC557 PNP transistor.
  • 2N2222 NPN transistor.
  • Datasheets for the selected transistors.
  • Connecting wires and breadboard.

Experiment A: NPN Transistor Testing

  1. Identify the BC547 transistor terminals using its datasheet.
  2. Set the multimeter to diode mode.
  3. Test the base-emitter junction in forward bias.
  4. Reverse the probes and record the reading.
  5. Repeat the process for the base-collector junction.

Experiment B: PNP Transistor Testing

  1. Identify the BC557 transistor terminals using its datasheet.
  2. Set the multimeter to diode mode.
  3. Test the base-emitter junction in forward bias.
  4. Reverse the probes and record the reading.
  5. Repeat the process for the base-collector junction.

16. Lesson Summary

  • A BJT has emitter, base and collector terminals.
  • NPN and PNP are the two main BJT types.
  • A BJT contains base-emitter and base-collector PN junctions.
  • Diode mode can be used for basic transistor junction testing.
  • NPN forward junction tests use red probe on the base.
  • PNP forward junction tests use black probe on the base.
  • Both junctions should normally block in reverse bias.
  • Some DMMs can measure approximate hFE.
  • Open, shorted and leaky junctions indicate possible faults.
  • Datasheets must be used to verify transistor pin arrangements.
