Lesson 12: Oscilloscope Basics and Waveform Measurement

Oscilloscope Controls, Signal Analysis and Practical Measurements

1. Introduction

An oscilloscope is an electronic test instrument used to display and measure electrical signals as waveforms with respect to time.

It helps engineers observe signal amplitude, frequency, time period, phase difference, noise, ripple, distortion and transient behavior.

Oscilloscopes are widely used in electronics R&D, embedded systems, power electronics, communication systems, automotive electronics and production testing.

Learning Objective: Understand oscilloscope controls, connect probes correctly, measure waveform parameters and use an oscilloscope to troubleshoot analog circuits.

2. What is an Oscilloscope?

An oscilloscope displays an electrical signal on a graph.

  • Horizontal axis represents time.
  • Vertical axis represents voltage.
  • The displayed waveform shows how voltage changes over time.

3. Types of Oscilloscopes

Analog Oscilloscope

An analog oscilloscope uses an electron beam in a cathode-ray tube to display electrical waveforms.

Digital Storage Oscilloscope (DSO)

A digital storage oscilloscope samples the input signal, converts it into digital data and stores the waveform for display and analysis.

Mixed Signal Oscilloscope (MSO)

A mixed signal oscilloscope combines analog waveform measurements with digital logic channel analysis.

Type Main Feature Application
Analog Oscilloscope Direct waveform display Basic signal observation
DSO Digital waveform storage Analog circuit testing
MSO Analog and digital channels Embedded and digital system debugging

4. Main Oscilloscope Controls

1. Vertical Controls

  • Volts/div: Controls vertical voltage scale.
  • Position: Moves waveform vertically.
  • Channel selection: Selects the input channel.
  • Coupling: Selects AC, DC or ground reference where available.

2. Horizontal Controls

  • Time/div: Controls horizontal time scale.
  • Horizontal position: Moves waveform horizontally.
  • Zoom: Expands a selected time region on supported instruments.

3. Trigger Controls

  • Trigger level: Sets the voltage level at which acquisition is triggered.
  • Trigger source: Selects the channel or source.
  • Trigger slope: Selects rising or falling edge.
  • Trigger mode: Common options include Auto, Normal and Single.
Proper trigger settings stabilize a repetitive waveform on the screen and help capture transient events.

5. Understanding Volts per Division

Volts/div specifies the voltage represented by one vertical grid division.

Example

Vertical scale = 2 V/div

Waveform height = 3 divisions

Peak-to-peak voltage:

Vpp = 2 x 3

Vpp = 6 V

For a symmetrical sine wave: 

Vp = Vpp / 2

Vp = 6 / 2

Vp = 3 V

6. Understanding Time per Division

Time/div specifies the time represented by one horizontal grid division.

Example

Time scale = 1 ms/div

One complete cycle = 4 divisions

T = 1 x 4

T = 4 ms

Frequency is the reciprocal of the time period. 

f = 1 / T

f = 1 / 0.004

f = 250 Hz

7. Oscilloscope Probes

An oscilloscope probe connects the test point to the oscilloscope input.

Common Probe Types

  • 1X passive probe.
  • 10X passive probe.
  • High-voltage probe.
  • Differential probe.
  • Current probe.
  • Active probe.

1X and 10X Probe Comparison

Feature 1X Probe 10X Probe
Attenuation 1:1 10:1
Signal at Scope Approximately same voltage One-tenth of probe-tip voltage
Input Loading Generally higher Generally lower
Bandwidth Usually lower Usually higher
Set the oscilloscope channel attenuation to match the probe switch position. Otherwise, displayed voltage measurements may be incorrect.

8. Probe Compensation

A passive oscilloscope probe may require compensation to match the oscilloscope input capacitance.

Procedure

  1. Connect the probe to the oscilloscope calibration output.
  2. Select the correct probe attenuation setting.
  3. Display the calibration square wave.
  4. Observe the waveform shape.
  5. Adjust the probe compensation screw if required.
  6. Repeat until the square wave has a flat top and sharp edges.
Waveform Appearance Condition
Flat square-wave top Correct compensation
Rounded edges Under-compensation
Overshoot or peaked edges Over-compensation

9. AC and DC Coupling

DC Coupling

DC coupling displays both the DC component and AC variations of the input signal.

AC Coupling

AC coupling blocks the DC component and displays the changing AC component.

Ground Coupling

On instruments that provide a ground coupling setting, it displays the channel's zero-voltage reference level.

Coupling Use
DC Measure total signal including DC offset.
AC Observe small AC ripple on a DC level.
Ground Locate the zero-voltage reference.

10. Measuring Peak and Peak-to-Peak Voltage

Peak voltage is measured from the waveform's reference level to its maximum positive or negative value.

Peak-to-peak voltage is the difference between the maximum and minimum waveform values. 

Vpp = Vmax - Vmin

For a symmetrical sine wave with no DC offset: 

Vp = Vpp / 2

Vrms = Vp / √2

Example

Vpp = 10 V

Vp = 10 / 2

Vp = 5 V

Vrms = 5 / 1.414

Vrms ≈ 3.54 V
These RMS relationships apply to a symmetrical sine wave without a DC offset. Do not use them directly for arbitrary waveforms.

11. Frequency and Time Period Measurement

The time period is the time taken by a periodic signal to complete one full cycle. 

f = 1 / T

Example

If a waveform completes one cycle in 2 milliseconds: 

T = 2 ms

T = 0.002 seconds

f = 1 / 0.002

f = 500 Hz

Practical Procedure

  1. Display a stable waveform.
  2. Adjust the time scale.
  3. Measure the horizontal divisions for one cycle.
  4. Multiply by the time/div setting.
  5. Calculate frequency using the reciprocal.

12. Phase Difference Measurement

Phase difference describes the angular displacement between two signals of the same frequency. 

Phase Difference (degrees) =
(Time Difference / Time Period) x 360°

Example

Time period = 10 ms
Time difference = 2.5 ms

Phase Difference =
(2.5 / 10) x 360°

= 90°

A two-channel oscilloscope can display both signals simultaneously and help measure their phase relationship.

13. Measuring Common Waveforms

Sine Wave

A sine wave is a periodic signal commonly found in AC power systems and oscillator circuits.

Square Wave

A square wave alternates between two voltage levels. It is commonly used in digital circuits and switching systems.

Triangle Wave

A triangle wave contains approximately linear rising and falling ramps.

Sawtooth Wave

A sawtooth waveform generally has a linear ramp in one direction followed by a rapid transition in the opposite direction.

Waveform Common Application
Sine Oscillators and AC signal testing.
Square Digital circuits and clock signals.
Triangle Waveform generators and modulation.
Sawtooth Timing and sweep circuits.

14. Measuring Power Supply Ripple

Ripple is the residual periodic variation present on a DC power supply output.

Measurement Procedure

  1. Connect the oscilloscope to the power supply output.
  2. Use the correct probe and channel settings.
  3. Select AC coupling to inspect small ripple on the DC output.
  4. Choose an appropriate volts/div setting.
  5. Adjust time/div to observe ripple cycles.
  6. Measure peak-to-peak ripple voltage.
  7. Record ripple frequency and operating load.
Use a safe ground reference. Many bench oscilloscopes have earth-referenced probe ground clips. Never connect them to a hazardous live point or a node that must remain isolated.

15. Triggering and Stable Waveform Display

Triggering controls when the oscilloscope begins displaying an acquired waveform.

Edge Trigger

Edge triggering starts acquisition when the signal crosses a selected voltage level in the chosen direction.

Trigger Slope

  • Rising edge: Trigger when the signal moves upward through the selected level.
  • Falling edge: Trigger when the signal moves downward through the selected level.

Trigger Modes

  • Auto: The scope can acquire even without a valid trigger.
  • Normal: Acquisition waits for a valid trigger.
  • Single: Captures one triggered event.

16. Common Oscilloscope Measurement Errors

Problem Possible Cause Correction
Incorrect voltage reading Probe attenuation mismatch. Match probe and channel settings.
Unstable waveform Incorrect trigger settings. Adjust trigger source and level.
Distorted waveform Probe compensation issue or excessive loading. Compensate probe and use suitable probe.
Unexpected noise Long ground lead or poor connections. Use a short ground connection and proper probing technique.
Wrong time measurement Incorrect time/div interpretation. Verify scale and count complete cycles.
Signal clipping Incorrect vertical scale or instrument range. Adjust scale and verify input limits.

17. Practical Laboratory Exercise

Objective

Measure voltage, time period and frequency of a sine wave using a digital storage oscilloscope.

Required Instruments

  • Digital storage oscilloscope.
  • Function generator.
  • 10X oscilloscope probe.
  • Connecting cables.

Procedure

  1. Switch ON the oscilloscope.
  2. Connect the probe to the calibration output.
  3. Verify probe compensation.
  4. Connect the function generator to the test channel.
  5. Generate a 1 kHz sine wave.
  6. Set a suitable voltage amplitude.
  7. Adjust volts/div and time/div.
  8. Set a stable edge trigger.
  9. Measure peak-to-peak voltage.
  10. Measure the time period and calculate frequency.
  11. Compare calculated and generator settings.

Observation Table

Parameter Measured Value
Waveform Type Sine Wave
Peak-to-Peak Voltage Record
Peak Voltage Record
Time Period Record
Calculated Frequency Record

Expected Result

The oscilloscope should display a stable sine waveform. The measured voltage and frequency should be reasonably close to the function generator settings, within instrument and setup tolerances.

19. Lesson Summary

  • An oscilloscope displays voltage against time.
  • Volts/div controls vertical scale.
  • Time/div controls horizontal scale.
  • Triggering helps produce a stable waveform display.
  • Probe attenuation must match channel settings.
  • Probe compensation improves measurement accuracy.
  • Frequency is the reciprocal of time period.
  • Phase difference can be measured using two channels.
  • Oscilloscopes are useful for ripple, noise and transient analysis.
Placement Tip: Practice measuring a 1 kHz waveform, calculating peak-to-peak voltage and frequency, and identifying ripple or clipping on an oscilloscope display.

20. Oscilloscope Safety Precautions

  • Check the maximum input voltage and probe rating.
  • Use a suitable probe attenuation setting.
  • Never exceed the oscilloscope channel limits.
  • Understand the grounding arrangement of the instrument.
  • Use differential or appropriately rated isolated measurement equipment where required.
  • Do not defeat the oscilloscope protective earth connection.
  • Switch OFF equipment before changing circuit connections where appropriate.
A standard passive probe is not automatically safe for measuring mains voltage or high-side switching nodes. Use properly rated differential or isolated probes and follow the instrument manufacturer's safety limits.
