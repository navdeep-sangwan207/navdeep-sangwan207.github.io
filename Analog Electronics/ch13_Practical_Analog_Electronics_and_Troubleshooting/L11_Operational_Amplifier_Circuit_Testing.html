Lesson 11: Operational Amplifier Circuit Testing

Op-Amp Measurements, Practical Testing and Fault Diagnosis

1. Introduction

An operational amplifier (op-amp) is a high-gain differential voltage amplifier widely used in analog electronic circuits.

Operational amplifiers are used in amplifiers, filters, comparators, oscillators, sensor interfaces, signal conditioning circuits and control systems.

Practical testing verifies whether an op-amp receives the correct supply voltage, responds to input signals and produces the expected output.

Learning Objective: Learn how to identify op-amp pins, verify power supplies, test basic amplifier circuits, measure signals and troubleshoot common op-amp faults.

Different op-amp ICs have different supply voltage ranges, pinouts, input common-mode ranges and output swing limits. Always check the specific datasheet.

5. Checking the Op-Amp Power Supply

Before testing an op-amp circuit, verify that the IC receives the correct supply voltage.

Dual-Supply Configuration

Some op-amps, such as the LM741, are commonly operated using positive and negative supply rails. 

Positive supply  = +12 V
Negative supply  = -12 V
Reference ground =  0 V

Single-Supply Configuration

Devices such as the LM358 can operate from a single positive supply within their specified limits. 

VCC = +5 V
GND =  0 V

Testing Procedure

  1. Identify the positive and negative supply pins.
  2. Check the IC datasheet for the allowed supply range.
  3. Apply the correct supply voltage.
  4. Measure the voltage directly at the IC supply pins.
  5. Verify that the supply is stable.
Never assume that every op-amp supports both single-supply and dual-supply operation. Also verify that the input and output voltages remain within the device's permitted ranges.

6. Testing an Op-Amp as an Inverting Amplifier

An inverting amplifier produces an output signal that is inverted relative to its input signal.

Voltage Gain

Av = -Rf / Rin

Vout = Av x Vin

Example:

Rin = 10 kΩ
Rf  = 100 kΩ
Vin = 0.1 V

Av = -100 / 10

Av = -10

Vout = -10 x 0.1

Vout = -1 V

Testing Procedure

  1. Construct the inverting amplifier using the required resistors.
  2. Connect the non-inverting input to the circuit reference.
  3. Apply a small input signal.
  4. Measure the input voltage.
  5. Measure the output voltage.
  6. Compare the measured gain with the calculated gain.
The calculated output is valid only while the op-amp remains within its input common-mode range, output swing and bandwidth limits.

7. Testing an Op-Amp as a Non-Inverting Amplifier

A non-inverting amplifier produces an output signal in phase with the input signal.

Voltage Gain

Av = 1 + (Rf / R1)

Example:

R1 = 10 kΩ
Rf = 40 kΩ
Vin = 0.2 V

Av = 1 + (40 / 10)

Av = 5

Vout = 5 x 0.2

Vout = 1 V

Testing Procedure

  1. Build the non-inverting amplifier circuit.
  2. Apply a small input signal to the non-inverting terminal.
  3. Measure the output voltage.
  4. Calculate the actual voltage gain.
  5. Compare it with the theoretical gain.

8. Testing an Op-Amp as a Voltage Follower

A voltage follower is a unity-gain buffer circuit in which the output is connected directly to the inverting input. 

Av ≈ 1

Vout ≈ Vin

Testing Procedure

  1. Connect the output to the inverting input.
  2. Apply a suitable input voltage to the non-inverting input.
  3. Measure the output voltage.
  4. Compare input and output values.
  5. Check that the output remains within the specified range.
A voltage follower is useful for checking basic buffer operation, but the test must respect the op-amp's input common-mode range, output swing and capacitive-load stability.

9. Testing an Op-Amp as a Comparator

An op-amp used in open-loop operation can produce an output that moves toward one of its output limits depending on the difference between its input voltages.

Basic Operation

  • If V+ is greater than V-, the output tends toward the positive output limit.
  • If V+ is less than V-, the output tends toward the negative output limit.

Testing Procedure

  1. Apply a reference voltage to one input.
  2. Apply a variable test voltage to the other input.
  3. Measure the output voltage.
  4. Change the input voltage around the reference level.
  5. Observe the output transition.
A general-purpose op-amp is not always suitable as a comparator. Check recovery time, input range and output characteristics. Use a dedicated comparator where fast or well-defined switching is required.

10. Input and Output Signal Testing

A function generator and oscilloscope are useful for checking whether an op-amp correctly amplifies an input signal.

Testing Steps

  1. Apply a low-amplitude sine wave from the function generator.
  2. Connect the oscilloscope to the input.
  3. Verify the input amplitude and frequency.
  4. Connect the second oscilloscope channel to the output.
  5. Observe output amplitude and phase.
  6. Check for clipping, distortion and unwanted oscillation.

Example Test Signal

Waveform   = Sine wave
Frequency  = 1 kHz
Input      = 100 mV peak
Gain       = 10

Expected output = 1 V peak

This is an ideal calculated value. Actual output depends on the supply voltage, load, bandwidth, slew rate and other device limitations.

11. Slew Rate and Bandwidth Testing

Slew Rate

Slew rate specifies the maximum rate at which an op-amp output voltage can change. 

Slew Rate = ΔVout / Δt

Unit = V/µs

If the input signal requires a faster output voltage transition than the device can provide, waveform distortion occurs.

Bandwidth

The bandwidth determines the frequency range over which the op-amp can operate with the required gain.

For many voltage-feedback op-amps, the gain-bandwidth product is approximately constant over the applicable operating region.

Practical Testing

  1. Apply a sine wave at a low frequency.
  2. Record the output amplitude.
  3. Increase the frequency gradually.
  4. Observe the output amplitude and waveform.
  5. Identify the frequency at which the gain begins to decrease.

12. Common Op-Amp Circuit Faults

Problem Possible Cause Testing Method
No output Missing supply or incorrect wiring. Check supply pins and ground connections.
Output saturated Incorrect input bias or feedback fault. Measure both input voltages and inspect feedback.
Incorrect gain Wrong resistor values or faulty components. Measure feedback resistors and calculate gain.
Distorted output Clipping, slew-rate limitation or overload. Inspect output waveform and load.
Unstable output Oscillation, poor layout or unsuitable capacitive load. Observe output with an oscilloscope.
Excessive noise Poor grounding or noisy power supply. Inspect supply ripple and grounding.
Unexpected offset Input offset voltage or bias-current effects. Measure input and output DC levels.
IC overheating Shorted output or excessive load current. Disconnect load and inspect output connections.

13. Step-by-Step Op-Amp Troubleshooting

  1. Identify the op-amp IC and obtain its datasheet.
  2. Check the IC orientation and pin connections.
  3. Verify positive and negative supply voltages.
  4. Check input signal and DC bias conditions.
  5. Measure the output DC voltage.
  6. Verify resistor and capacitor values.
  7. Inspect feedback connections.
  8. Observe input and output waveforms.
  9. Check for clipping, oscillation and excessive loading.
  10. Replace the IC only after external circuit faults have been ruled out.
In practical electronics troubleshooting, a faulty op-amp IC is only one possible cause. Incorrect supply voltage, feedback wiring, grounding and external components can produce similar symptoms.

14. Practical Laboratory Exercise

Objective

Test an operational amplifier in inverting, non-inverting and voltage follower configurations.

Required Components

  • LM358 or another suitable op-amp.
  • Regulated DC power supply.
  • 10 kΩ and 100 kΩ resistors.
  • Breadboard and connecting wires.
  • Function generator.
  • Digital multimeter.
  • Oscilloscope.

Procedure

  1. Read the op-amp datasheet and identify the pins.
  2. Connect the required power supply.
  3. Build the inverting amplifier circuit.
  4. Apply a small sine-wave input.
  5. Measure input and output amplitudes.
  6. Calculate the voltage gain.
  7. Repeat using a non-inverting configuration.
  8. Build a voltage follower and compare input and output voltages.
  9. Record the measurements.

Observation Table

Configuration Input Expected Gain Measured Output
Inverting Record -10 Record
Non-Inverting Record +5 Record
Voltage Follower Record +1 Record

Expected Result

The op-amp should produce the expected output response within the limits of its datasheet specifications and test circuit.

16. Lesson Summary

  • Operational amplifiers are widely used in analog signal processing.
  • Correct supply voltage and pin identification are essential.
  • Inverting and non-inverting amplifiers provide different phase relationships.
  • A voltage follower provides approximately unity voltage gain.
  • Function generators and oscilloscopes help evaluate signal response.
  • Slew rate and bandwidth affect high-frequency performance.
  • Feedback, grounding and power supply faults can cause unstable operation.
  • Systematic troubleshooting helps identify defective circuit stages.
Placement Tip: Be prepared to explain how to test an LM358 or LM741 circuit, calculate amplifier gain, identify a saturated output and diagnose an unstable waveform using an oscilloscope.

17. Safety Precautions

  • Verify the op-amp supply voltage before connecting the IC.
  • Check pin configuration before applying power.
  • Use current-limited supplies for laboratory testing.
  • Do not exceed input common-mode or differential input limits.
  • Avoid shorting the output to the supply rails.
  • Use suitable oscilloscope grounding practices.
  • Switch OFF the supply before modifying circuit connections.
