2. Introduction to Common-Base Configuration

In a common-base (CB) transistor configuration, the base terminal is common to both the input and output circuits.

  • Input signal is applied between emitter and base.
  • Output is taken between collector and base.
  • Base is the common reference terminal for the two circuits.
  • For normal NPN operation, the emitter-base junction is forward biased and collector-base junction is reverse biased.
Input: Emitter–Base
Output: Collector–Base
“Common” means electrically common to the input and output circuits for the signal analysis. In practical AC circuits, the base is normally held at AC ground using an appropriate bypass or reference arrangement.

4. Working Principle of CB Configuration

Consider an NPN transistor operating in the forward-active region.

  1. The emitter-base junction is forward biased.
  2. Electrons are injected from the heavily doped N-type emitter into the thin P-type base.
  3. Most injected electrons cross the base without recombining.
  4. The reverse-biased collector-base junction sweeps these electrons into the collector.
  5. A small fraction recombines in the base and contributes to base current.
IE = IC + IB

The collector current is therefore slightly smaller than the emitter current in magnitude.

6. Current Gain of CB Configuration

Common-base current gain is represented by alpha (α).

α = IC / IE

For a practical transistor in forward-active operation, α is less than but often close to unity.

Example

If emitter current is 5 mA and collector current is 4.9 mA:

α = 4.9 / 5 = 0.98

The base current is:

IB = IE − IC = 5 − 4.9 = 0.1 mA

7. Input Characteristics of CB Configuration

The input characteristic is the relationship between emitter current IE and emitter-base voltage VEB (or VBE, with a consistent polarity convention) at constant collector-base voltage.

For an NPN transistor, the emitter-base junction is forward biased. The input curve resembles the forward characteristic of a diode.

rin ≈ ΔVEB / ΔIE

The CB configuration generally has low input resistance compared with the CE configuration.

8. Output Characteristics of CB Configuration

The output characteristic is the relationship between collector current IC and collector-base voltage VCB at constant emitter current IE.

  • Each curve represents a fixed emitter current.
  • Collector current is approximately equal to alpha times emitter current in the active region.
  • Output resistance is relatively high.
  • At sufficiently high collector voltage, breakdown may occur.
rout ≈ ΔVCB / ΔIC (at constant IE)

Illustrative family of output curves. Actual output behavior depends on the transistor and operating conditions.

9. Voltage Gain of CB Configuration

The CB configuration has current gain slightly less than unity, but it can provide substantial voltage gain because of its low input resistance and relatively high output resistance.

Av = Vout / Vin

For a simplified small-signal common-base stage, a useful approximate magnitude is:

|Av| ≈ α × Rload / re

Here, Rload is the effective collector load and re is the small-signal intrinsic emitter resistance. This approximation assumes suitable biasing and a small signal.

A CB amplifier is generally non-inverting in voltage: the output voltage follows the input signal polarity. The current gain is below unity, but voltage gain can be high.

10. Phase Relationship

The common-base amplifier does not produce the 180° voltage phase reversal associated with a common-emitter voltage amplifier.

The waveforms are shown in phase for the conventional common-base voltage-amplifier arrangement. Exact signal polarity depends on how the input and output voltages are defined.

12. Advantages and Limitations

Advantages

  • High voltage gain is possible.
  • High-frequency performance can be excellent.
  • Low input resistance.
  • High output resistance.
  • No 180° voltage phase reversal in the usual amplifier arrangement.

Limitations

  • Current gain is slightly below unity.
  • Low input resistance can load a signal source.
  • Biasing and coupling need careful design.
  • Less commonly used as a general-purpose voltage amplifier than CE.

13. Applications of CB Configuration

  • High-frequency amplifier stages.
  • RF amplifier circuits.
  • Impedance transformation from a low-resistance source to a higher-resistance load.
  • Cascode amplifier stages, where a CB transistor is used above a CE transistor.
  • Circuits requiring reduced Miller-effect influence at the input of the amplifying stage.

14. Worked Numerical Problems

Example 1: Calculate alpha

IE = 8 mA and IC = 7.84 mA.

α = 7.84 / 8 = 0.98

Answer: α = 0.98.

Example 2: Calculate base current

IE = 6 mA and IC = 5.88 mA.

IB = 6 − 5.88 = 0.12 mA

Answer: IB = 120 µA.

Example 3: Calculate collector current

IE = 4 mA and α = 0.99.

IC = α × IE = 0.99 × 4 = 3.96 mA

Answer: IC = 3.96 mA.

Example 4: Estimate voltage gain

Assume α = 0.98, effective load = 2 kΩ and intrinsic emitter resistance re = 25 Ω.

|Av| ≈ 0.98 × 2000 / 25 = 78.4

Answer: Approximate voltage gain magnitude = 78.4.

This is an idealized small-signal estimate. Real gain depends on source resistance, transistor output resistance, bias and loading.

15. Practical Lab Exercise

Objective: Study the common-base configuration and determine its current gain.

Equipment: NPN transistor, regulated supplies, emitter and collector resistors, coupling capacitors, multimeters and signal generator (if available).

  1. Identify the transistor terminals using its datasheet.
  2. Build a CB circuit with the base held at a suitable DC bias and AC ground.
  3. Forward bias the emitter-base junction and reverse bias the collector-base junction.
  4. Apply a controlled emitter current.
  5. Measure emitter current and collector current.
  6. Calculate alpha = IC/IE.
  7. Apply a small AC input signal and observe the output waveform.
  8. Compare input and output phase and estimate voltage gain.

Expected result: Alpha should be slightly below unity in forward-active operation. The voltage gain can be greater than unity and the voltage waveforms are normally in phase for the usual CB amplifier arrangement.

Use current-limiting resistors and verify voltage/current ratings. Keep the transistor in its safe operating area. Avoid shorting the base reference to an inappropriate supply node.

17. Placement Interview Questions

Q1. What is a common-base configuration?

A BJT arrangement in which the base is common to the input and output circuits.

Q2. Where is the input applied?

Between emitter and base.

Q3. Where is the output taken?

Between collector and base.

Q4. Define alpha.

α = IC/IE.

Q5. Is alpha greater than one?

Normally no. It is slightly less than unity in practical forward-active operation.

Q6. What is the input resistance of CB?

It is generally low compared with CE.

Q7. What is its output resistance?

It is generally high.

Q8. Does CB provide voltage gain?

Yes. It can provide substantial voltage gain despite current gain below unity.

Q9. What is the phase relationship?

The usual CB voltage amplifier is non-inverting.

Q10. Why is CB useful at high frequencies?

Its circuit arrangement can reduce the impact of the Miller effect compared with a CE stage.

Q11. What is the main disadvantage of CB?

Its low input resistance and current gain below unity.

Q12. Where is CB used?

RF amplifiers, high-frequency stages and cascode circuits.

Q13. What is the current relationship?

IE = IC + IB using current magnitudes.

Q14. Why is base AC-grounded?

To make the base the common signal reference for input and output.

Q15. Can CB be used for impedance transformation?

Yes, it can couple a low-resistance source to a higher-resistance load in suitable designs.

19. Lecture Summary

  • Base is common to input and output circuits.
  • Input is between emitter and base; output is between collector and base.
  • Emitter-base junction is forward biased in normal NPN active operation.
  • Collector-base junction is reverse biased.
  • Current gain is α = IC/IE and is slightly less than unity.
  • Input resistance is low and output resistance is high.
  • Voltage gain can be high.
  • The usual CB voltage amplifier is non-inverting.
  • CB is useful in RF, high-frequency and cascode applications.
