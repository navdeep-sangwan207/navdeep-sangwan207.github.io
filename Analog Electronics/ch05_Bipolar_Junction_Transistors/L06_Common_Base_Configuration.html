Lesson 6: BJT Input and Output Characteristics

Characteristic Curves, CE Characteristics and Operating Regions

After completing this lesson, you will be able to:

  • Understand transistor input and output characteristics.
  • Explain the relationship between voltage and current in a BJT.
  • Interpret the input characteristic curve.
  • Interpret the output characteristic curve.
  • Understand CE input and output characteristics.

2. What are BJT Characteristics?

BJT characteristics describe the relationship between the voltage and current at the transistor terminals.

These characteristics are represented graphically using characteristic curves. They help us understand how a transistor behaves under different operating conditions.

The main characteristics are:

  1. Input characteristics.
  2. Output characteristics.
  3. Transfer characteristics.
Important: In this lesson, we primarily study the Common Emitter (CE) characteristics because CE is widely used in amplifier and switching circuits.

3. Common Emitter Input Characteristics

3.1 Definition

The input characteristic of a Common Emitter transistor is the graph between base current (IB) and base-emitter voltage (VBE), while collector-emitter voltage (VCE) is kept constant.

Input Characteristic: IB versus VBE

VCE = Constant

3.2 Input Characteristic Curve

Illustrative silicon BJT input characteristic. The curve resembles a forward-biased PN junction.

3.3 Explanation

  • At low VBE, base current is very small.
  • As VBE increases, base current starts increasing rapidly.
  • The base-emitter junction behaves similarly to a forward-biased diode.
  • For a silicon transistor, significant conduction commonly occurs around 0.6–0.7 V under ordinary conditions.
The 0.6–0.7 V value is an approximate operating guideline, not a fixed turn-on voltage. Actual VBE depends on collector current, transistor type and temperature.

3.4 Input Resistance

Input resistance is the ratio of a small change in base-emitter voltage to the corresponding change in base current, with VCE held constant.

rin = ΔVBE / ΔIB

It is calculated from the slope of the input characteristic curve over a selected operating range.

4. Common Emitter Output Characteristics

4.1 Definition

The output characteristic of a Common Emitter transistor is the graph between collector current (IC) and collector-emitter voltage (VCE), while base current (IB) is kept constant.

Output Characteristic: IC versus VCE

IB = Constant

4.2 Output Characteristic Curves

Illustrative CE output curves for different constant base currents. The exact curve shape depends on the transistor and measurement conditions.

4.3 Explanation of the Output Curve

For each fixed base current, collector current changes with collector-emitter voltage. The curve can be divided into different operating regions.

  • At very low VCE, the transistor operates near saturation.
  • After the knee region, collector current becomes relatively constant for a fixed IB.
  • At higher VCE, the transistor operates in the active region until breakdown conditions are approached.
  • When base current is zero, the transistor is approximately in cutoff.
Important: In the active region, IC is mainly controlled by IB. It is not perfectly independent of VCE; a small dependence can occur because of the Early effect.

4.4 Output Resistance

Output resistance is the ratio of a change in collector-emitter voltage to the corresponding change in collector current, with base current held constant.

rout = ΔVCE / ΔIC

A relatively flat output characteristic indicates high output resistance in that operating region.

5. Operating Regions on Output Characteristics

Region Transistor Behaviour Typical Application
Cutoff Base current is approximately zero and collector current is very small. Switch OFF state.
Active Collector current is controlled mainly by base current. Signal amplification.
Saturation Both junctions are forward biased; collector current is limited by the external circuit. Switch ON state.
Breakdown Collector current can rise sharply as voltage exceeds the breakdown limit. Normally avoided in standard operation.
Breakdown is not a normal operating region for a general-purpose BJT circuit. Exceeding datasheet voltage limits can permanently damage the transistor.

6. Transfer Characteristics

6.1 Definition

Transfer characteristics show the relationship between input current and output current while the relevant output voltage is kept constant.

For a CE transistor, the transfer characteristic is commonly:

IC versus IB

VCE = Constant

In the forward-active region, collector current is approximately proportional to base current.

IC ≈ β IB

7. Experimental Setup for Measuring CE Characteristics

A transistor characteristic experiment can be performed using a DC power supply, a transistor, resistors and measuring instruments.

Required Components

  • NPN BJT, such as BC547 or another suitable transistor.
  • Two adjustable DC power supplies or suitable bias circuits.
  • Base current limiting resistor.
  • Collector load resistor.
  • Digital multimeter or voltage/current measuring instruments.
  • Breadboard and connecting wires.

Procedure

  1. Connect the transistor in Common Emitter configuration.
  2. Keep the emitter at the common reference potential for the basic NPN test circuit.
  3. Apply a controlled base bias through a current-limiting resistor.
  4. Set a base current value and measure VBE, VCE and IC.
  5. Change VCE while keeping IB approximately constant.
  6. Record the collector current at each VCE value.
  7. Repeat the measurements for different base current values.
  8. Plot IC against VCE to obtain the output characteristics.
  9. Measure IB against VBE at fixed VCE to obtain the input characteristics.
Practical precaution: Use current-limiting resistors and stay within the transistor's datasheet voltage, current and power ratings. Do not connect a transistor directly to a supply without appropriate current limiting.

8. Numerical Examples

Example 1: Calculate Input Resistance

Given:

  • Change in VBE = 0.04 V
  • Change in IB = 20 µA
  • VCE is constant.

Formula:

rin = ΔVBE / ΔIB

Solution:

rin = 0.04 / (20 × 10-6)

rin = 2000 Ω = 2 kΩ

Answer: Input resistance = 2 kΩ.

Example 2: Calculate Output Resistance

Given:

  • Change in VCE = 5 V
  • Change in IC = 0.1 mA
  • IB is constant.

Formula:

rout = ΔVCE / ΔIC

Solution:

rout = 5 / (0.1 × 10-3)

rout = 50,000 Ω = 50 kΩ

Answer: Output resistance = 50 kΩ.

Example 3: Calculate Collector Current

Given:

  • Base current = 30 µA
  • β = 100
  • Transistor is in the active region.
IC ≈ β × IB

IC ≈ 100 × 30 µA

IC ≈ 3 mA

Answer: Collector current ≈ 3 mA.

9. Important Interview Questions

Q1. What is an input characteristic of a BJT?

It is the graph of input current against input voltage with output voltage kept constant.

Q2. What is the CE input characteristic?

A graph of base current (IB) versus base-emitter voltage (VBE), with VCE constant.

Q3. What is the CE output characteristic?

A graph of collector current (IC) versus collector-emitter voltage (VCE), with IB constant.

Q4. Why does the input characteristic resemble a diode curve?

Because the base-emitter junction behaves like a forward-biased PN junction.

Q5. What does a flat output characteristic indicate?

It indicates that collector current changes only slightly with VCE at a fixed base current, corresponding to relatively high output resistance.

Q6. What is the knee region?

It is the region near the transition from saturation toward the active region on the output characteristic.

Q7. What happens when base current is zero?

The transistor is approximately in cutoff, apart from leakage current.

Q8. What is transfer characteristic?

It describes the relationship between input current and output current under a specified constant output voltage.

Q9. How do you calculate input resistance from a graph?

Divide the change in input voltage by the corresponding change in input current at constant output voltage.

Q10. Why are BJT characteristic curves important?

They help determine operating regions, gain, resistance, biasing conditions and suitable operating points.

11. Lesson Summary

  • BJT characteristics describe the relationship between transistor voltages and currents.
  • Input characteristics show input current versus input voltage.
  • CE input characteristics plot IB against VBE at constant VCE.
  • CE output characteristics plot IC against VCE at constant IB.
  • Transfer characteristics show the relationship between input and output current.
  • Input resistance is calculated using ΔVBE / ΔIB.
  • Output resistance is calculated using ΔVCE / ΔIC.
  • Output curves help identify cutoff, active and saturation regions.
  • Characteristic curves are useful for transistor selection and circuit design.
Placement preparation tip: Practise drawing the CE input and output characteristics from memory. Be prepared to explain the axes, constant parameters, operating regions and resistance calculations.
