Lesson 7: BJT Current Gains

Common Base Alpha (α), Common Emitter Beta (β) and Common Collector Gamma (γ)

After completing this lesson, you will be able to:

  • Define alpha (α), beta (β) and gamma (γ).
  • Derive the mathematical relationship between the three current gains.
  • Convert alpha into beta and beta into alpha.

2. Introduction to BJT Current Gain

A Bipolar Junction Transistor (BJT) is a current-controlled semiconductor device in its forward-active operating region. A relatively small base current controls a larger collector current.

The relationship between the transistor currents is represented by:

IE = IC + IB

Where:

  • IE: Emitter current.
  • IC: Collector current.
  • IB: Base current.

Current gain describes the relationship between two of these currents. The three commonly studied current gains are:

  1. Alpha (α) — Common Base current gain.
  2. Beta (β) — Common Emitter current gain.
  3. Gamma (γ) — Common Collector current gain.
Important: Current gain is a dimensionless quantity because it is the ratio of two currents measured in the same unit.

3. Alpha (α) — Common Base Current Gain

3.1 Definition

Alpha is the ratio of collector current to emitter current in a Common Base transistor configuration.

α = IC / IE

3.2 Explanation

When the emitter injects charge carriers into the thin base region, most of these carriers reach the collector. A small portion contributes to base current.

Therefore, collector current is slightly smaller than emitter current in the normal forward-active operating region.

0 < α < 1

For many ordinary silicon BJTs, alpha is close to unity. Its actual value depends on the transistor and operating conditions.

3.3 Example

Given:

  • Collector current = 9.8 mA
  • Emitter current = 10 mA

Formula:

α = IC / IE

Solution:

α = 9.8 / 10
α = 0.98

Answer: Alpha = 0.98.

4. Beta (β) — Common Emitter Current Gain

4.1 Definition

Beta is the ratio of collector current to base current in a Common Emitter configuration.

β = IC / IB

4.2 Explanation

The base region of a BJT is thin and lightly doped. Consequently, only a small base current is needed to control a larger collector current under forward-active operating conditions.

Beta is generally greater than unity and can vary considerably between transistors of the same type.

IC ≈ β × IB

4.3 Example

Given:

  • Collector current = 5 mA
  • Base current = 50 µA

Solution:

β = IC / IB

β = 5 mA / 50 µA

β = 5000 / 50

β = 100

Answer: Beta = 100.

4.4 Factors Affecting Beta

  • Collector current.
  • Collector-emitter voltage.
  • Junction temperature.
  • Transistor manufacturing variations.
  • Transistor type and construction.
Practical point: Do not assume beta is a fixed value for every transistor. Always check the datasheet and design circuits with sufficient margin.

4.5 Applications and Significance

  • Common Emitter amplifier calculations.
  • Base current calculations.
  • Transistor switching circuit design.
  • Biasing and operating-point calculations.

5. Gamma (γ) — Common Collector Current Gain

5.1 Definition

Gamma is the ratio of emitter current to base current in a Common Collector configuration.

γ = IE / IB

5.2 Explanation

The emitter current is the sum of collector current and base current:

IE = IC + IB

Dividing both sides by base current:

IE / IB = IC / IB + 1

Since beta is IC / IB:

γ = β + 1

5.3 Example

Given:

  • Beta = 99

Solution:

γ = β + 1

γ = 99 + 1

γ = 100

Answer: Gamma = 100.

5.4 Applications

  • Common Collector circuit analysis.
  • Emitter follower calculations.
  • Buffer amplifier design.
  • Emitter current calculations.

6. Derivation of Relationship Between α and β

Start with the basic BJT current equation:

IE = IC + IB

Divide both sides by IC:

IE / IC = 1 + IB / IC

Using the definitions:

α = IC / IE

β = IC / IB

Therefore:

1 / α = 1 + 1 / β

Rearranging:

β = α / (1 − α)

Final Relationship

β = α / (1 − α)

α = β / (β + 1)
Remember: If alpha is known, use β = α / (1 − α). If beta is known, use α = β / (β + 1).

7. Complete Relationship Between α, β and γ

Relationship between the three BJT current-gain parameters.

α = β / (β + 1)

β = α / (1 − α)

γ = β + 1

γ = 1 / (1 − α)

9. DC Beta and AC Beta

9.1 DC Current Gain (βDC)

DC beta is the ratio of the DC collector current to the DC base current at a particular operating point.

βDC = IC / IB

9.2 AC Current Gain (βac)

AC beta is the ratio of a small change in collector current to the corresponding small change in base current around a chosen operating point.

βac = ΔIC / ΔIB

9.3 Difference Between DC and AC Beta

DC Beta AC Beta
Uses total DC current values. Uses small changes in current.
Describes the DC operating point. Describes small-signal current gain.
βDC = IC / IB βac = ΔIC / ΔIB
AC beta and DC beta are not necessarily equal. Their values depend on the transistor and operating conditions.

10. Numerical Problems

Example 1: Calculate Beta from Alpha

Given: α = 0.96

β = α / (1 − α)

β = 0.96 / (1 − 0.96)

β = 0.96 / 0.04

β = 24

Answer: β = 24.

Example 2: Calculate Alpha from Beta

Given: β = 149

α = β / (β + 1)

α = 149 / 150

α = 0.9933

Answer: α ≈ 0.9933.

Example 3: Calculate Gamma

Given: β = 75

γ = β + 1

γ = 75 + 1

γ = 76

Answer: γ = 76.

Example 4: Calculate Emitter Current

Given:

  • Collector current = 8 mA
  • Base current = 80 µA

Convert base current:

IB = 80 µA = 0.08 mA

Using the current equation:

IE = IC + IB

IE = 8 + 0.08

IE = 8.08 mA

Answer: Emitter current = 8.08 mA.

Example 5: Calculate All Three Current Gains

Given:

  • IC = 9.9 mA
  • IB = 0.1 mA

Step 1: Calculate emitter current

IE = 9.9 + 0.1 = 10 mA

Step 2: Calculate alpha

α = 9.9 / 10 = 0.99

Step 3: Calculate beta

β = 9.9 / 0.1 = 99

Step 4: Calculate gamma

γ = 10 / 0.1 = 100

Final Answers:

  • Alpha = 0.99
  • Beta = 99
  • Gamma = 100

11. Important Interview Questions

Q1. What is alpha in a BJT?

Alpha is the ratio of collector current to emitter current: α = IC / IE.

Q2. What is beta in a BJT?

Beta is the ratio of collector current to base current: β = IC / IB.

Q3. What is gamma in a BJT?

Gamma is the ratio of emitter current to base current: γ = IE / IB.

Q4. Which current gain is less than unity?

Alpha is less than unity in normal forward-active operation.

Q5. What is the relationship between alpha and beta?

β = α / (1 − α), and α = β / (β + 1).

Q6. What is the relationship between beta and gamma?

γ = β + 1.

Q7. Is beta constant for a transistor?

No. Beta varies with current, voltage, temperature and manufacturing variation.

Q8. What is the difference between DC beta and AC beta?

DC beta uses total current values, while AC beta uses incremental current changes.

Q9. Why is beta important in transistor circuits?

It helps estimate collector current from base current in the forward-active region.

Q10. What is the basic BJT current equation?

IE = IC + IB.

13. Lesson Summary

  • Alpha is the Common Base current gain.
  • Beta is the Common Emitter current gain.
  • Gamma is the Common Collector current gain.
  • α = IC / IE.
  • β = IC / IB.
  • γ = IE / IB.
  • IE = IC + IB.
  • β = α / (1 − α).
  • α = β / (β + 1).
  • γ = β + 1.
  • DC beta and AC beta describe different current relationships.
  • Beta varies with operating conditions and is not a fixed universal value.
