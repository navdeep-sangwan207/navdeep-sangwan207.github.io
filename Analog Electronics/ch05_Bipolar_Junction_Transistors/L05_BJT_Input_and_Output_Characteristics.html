2. What Are BJT Characteristics?

Transistor characteristics are graphical relationships between terminal currents and terminal voltages under specified circuit conditions.

In the common-emitter (CE) configuration:

  • Input voltage: base-emitter voltage, VBE.
  • Input current: base current, IB.
  • Output voltage: collector-emitter voltage, VCE.
  • Output current: collector current, IC.
Input: IB versus VBE at constant VCE
Output: IC versus VCE for different fixed IB values
Characteristic curves are measured under specified test conditions. The illustrative graphs in this lesson explain typical behavior; actual transistor curves vary by device and operating conditions.

3. Common-Emitter Test Circuit

The emitter is common to both the input and output circuits. A base supply controls base current, while a collector supply establishes the collector-emitter voltage.

In a laboratory, measure IB and IC with suitable meters connected in series in their respective branches. Measure VBE and VCE with voltmeters connected in parallel.

4. Input Characteristics of a CE Transistor

The input characteristic is the relationship between base current IB and base-emitter voltage VBE while VCE is held constant.

The base-emitter junction behaves approximately like a forward-biased PN junction. As VBE increases, IB rises rapidly after the junction begins conducting.

  • For a silicon BJT, conduction becomes significant around the familiar 0.6–0.7 V range, depending on current and temperature.
  • At a fixed VBE, the input current can change slightly with VCE due to transistor internal effects.
  • The input characteristic is nonlinear.
rin ≈ ΔVBE / ΔIB (at constant VCE)

This is the incremental input resistance around a selected operating point, not a constant value over the entire curve.

Illustrative curve only. Exact curve shape and voltage scale depend on device, current range and temperature.

5. Output Characteristics of a CE Transistor

The output characteristic is a family of curves showing collector current IC versus collector-emitter voltage VCE for different fixed base currents IB.

As base current increases, the collector current generally increases in the active region.

The graph is illustrative and not a manufacturer's measured curve. In a real transistor, the active-region curves are not perfectly horizontal.

6. Operating Regions on Output Characteristics

RegionBehaviorTypical use
CutoffBase drive is insufficient; collector current is approximately leakage current.OFF state of a switch
ActiveBase-emitter junction forward biased and collector-base junction reverse biased.Linear amplification
SaturationBoth junctions are forward biased; collector current is limited mainly by the external circuit.ON state of a switch
BreakdownCollector-emitter voltage exceeds the specified breakdown limit.Normally avoided
Do not operate a transistor in breakdown unless the datasheet explicitly permits the particular operating condition. Exceeding voltage or power ratings can damage the device.

8. Current Gain from Output Curves

In the active region, the vertical separation between curves corresponding to two base-current values can be used to estimate common-emitter current gain.

β ≈ ΔIC / ΔIB

For example, suppose the collector current changes from 2 mA to 5 mA when base current changes from 20 µA to 50 µA.

β ≈ (5 − 2) mA / (50 − 20) µA = 3 mA / 30 µA = 100
Use the slope between two curves at the same VCE and in the active region. Avoid estimating beta from points in saturation or cutoff.

9. Output Resistance and Early Effect

In the ideal active region, collector current would remain constant as VCE changes at fixed IB. Real output curves have a slight positive slope.

This behavior is associated with the Early effect, also called base-width modulation. Increasing reverse bias across the collector-base junction changes the effective base width and can increase collector current.

ro ≈ ΔVCE / ΔIC (at constant IB)

Output resistance is an incremental small-signal parameter around an operating point. It is not the same as the external collector resistor.

10. Load Line and Operating Point (Q-Point)

For a common-emitter circuit with collector resistor RC and supply VCC, Kirchhoff's Voltage Law gives:

VCC = ICRC + VCE

Rearranging:

IC = (VCC − VCE) / RC

The DC load line intersects the transistor output characteristics. The intersection for the selected base bias is the operating point, or Q-point.



IC at VCE = 0: 6 mA; VCE at IC = 0: 12 V

11. Solved Numerical Problems

Example 1: Calculate beta from a characteristic curve

At a fixed VCE, IC changes by 3.6 mA when IB changes by 30 µA.

β ≈ 3.6 mA / 0.03 mA = 120

Answer: Approximate current gain is 120.

Example 2: Calculate input resistance

At constant VCE, VBE changes by 20 mV when IB changes by 10 µA.

rin ≈ 20 mV / 10 µA = 2 kΩ

Answer: Incremental input resistance is approximately 2 kΩ.

Example 3: Calculate output resistance

At constant IB, VCE changes by 2 V and IC changes by 0.1 mA.

ro ≈ 2 V / 0.1 mA = 20 kΩ

Answer: Incremental output resistance is approximately 20 kΩ.

Example 4: Determine the load-line intercept

A CE circuit has VCC = 15 V and RC = 3 kΩ.

IC(sat, load line) = VCC/RC = 15/3k = 5 mA

At IC = 0, VCE = 15 V. These are the two ideal DC load-line intercepts.

12. Practical Lab Exercise

Objective: Plot the input and output characteristics of an NPN transistor in common-emitter configuration.

Equipment: NPN transistor, two regulated DC supplies or a suitable transistor characteristic test setup, resistors, breadboard and digital multimeters.

Procedure: Input characteristics

  1. Connect the transistor in common-emitter configuration.
  2. Set a fixed VCE value within the safe operating range.
  3. Vary VBE gradually using a current-limited base circuit.
  4. Record the corresponding IB values.
  5. Plot IB against VBE.
  6. Repeat at another VCE value if required by the experiment.

Procedure: Output characteristics

  1. Set a low, controlled base current.
  2. Vary VCE gradually and record IC.
  3. Repeat the VCE sweep for several base-current values.
  4. Plot IC against VCE for each fixed IB.
  5. Identify cutoff, saturation and active regions.
  6. Estimate beta from the active-region curve separation.
Use current-limiting resistors and monitor transistor power dissipation. Do not exceed the datasheet limits for VCEO, IC or power dissipation. Never leave the base drive uncontrolled.

13. Datasheet Interpretation

When examining a transistor datasheet, check the test conditions printed beside each characteristic graph.

  • Collector current and collector-emitter voltage ranges.
  • Fixed base current used for each output curve.
  • Temperature at which curves were measured.
  • Whether the graph is typical or a guaranteed limit.
  • Maximum ratings and safe operating area.
  • DC gain test conditions and saturation voltage test conditions.
A typical characteristic graph is useful for understanding behavior but is not necessarily a guaranteed production limit. Use maximum/minimum specifications for robust design.

15. Placement Interview Questions

Q1. What is a transistor characteristic?

A graphical relationship between terminal currents and voltages under specified conditions.

Q2. Define CE input characteristics.

IB versus VBE at constant VCE.

Q3. Define CE output characteristics.

IC versus VCE for different fixed values of IB.

Q4. Why does base current increase with VBE?

The base-emitter PN junction becomes increasingly forward biased, causing its current to rise nonlinearly.

Q5. What does each output curve represent?

A fixed base current while collector-emitter voltage is varied.

Q6. What is the active region used for?

Linear amplification.

Q7. What is the saturation region?

The region in which both transistor junctions are forward biased for a typical NPN device.

Q8. What is the cutoff region?

The region in which base drive is insufficient and collector current is approximately leakage current.

Q9. How can beta be estimated from output characteristics?

β ≈ ΔIC/ΔIB at the same VCE in the active region.

Q10. Define input resistance.

It is approximately ΔVBE/ΔIB at constant VCE for a small signal.

Q11. Define output resistance.

It is approximately ΔVCE/ΔIC at constant IB for a small signal.

Q12. What is the Early effect?

Base-width modulation caused by changing collector-base reverse bias.

Q13. What is the Q-point?

The quiescent DC operating point of the transistor with no input signal.

Q14. What is a DC load line?

The straight-line relationship between IC and VCE imposed by the external collector circuit.

Q15. Why are output curves not perfectly horizontal?

Because collector current varies somewhat with VCE, notably due to the Early effect.

Q16. Why should datasheet test conditions be checked?

Because measured gain and characteristic curves depend on current, voltage and temperature.

17. Lecture Summary

  • CE input characteristic: IB versus VBE at constant VCE.
  • CE output characteristic: IC versus VCE for different fixed IB values.
  • Input resistance is estimated from ΔVBE/ΔIB.
  • Output resistance is estimated from ΔVCE/ΔIC.
  • Beta can be estimated from ΔIC/ΔIB at fixed VCE in the active region.
  • Output curves identify cutoff, active and saturation behavior.
  • The Early effect causes a finite slope in the active region.
  • Load lines and characteristic curves help establish the transistor Q-point.
