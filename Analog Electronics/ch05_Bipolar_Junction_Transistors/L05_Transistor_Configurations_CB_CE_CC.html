Lesson 5: BJT Transistor Configurations

Common Base (CB), Common Emitter (CE) and Common Collector (CC)

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand the meaning of BJT transistor configurations.
  • Explain Common Base, Common Emitter and Common Collector configurations.
  • Identify the input and output terminals of each configuration.
  • Compare their input impedance and output impedance.
  • Understand current gain, voltage gain and phase relationship.
  • Identify practical applications of each configuration.
  • Answer placement-oriented questions related to BJT configurations.

2. What is a BJT Transistor Configuration?

A Bipolar Junction Transistor (BJT) has three terminals: Emitter (E), Base (B) and Collector (C).

A transistor configuration describes how these three terminals are connected in an electronic circuit.

In a basic transistor amplifier, one terminal is common to both the input and output circuits. Depending on which terminal is common, the three configurations are:

  1. Common Base (CB) configuration.
  2. Common Emitter (CE) configuration.
  3. Common Collector (CC) configuration.
Important: The word "common" refers to the transistor terminal shared by the input and output circuits (usually through the common reference or AC-ground connection).

3. Common Base (CB) Configuration

3.1 Definition

In Common Base configuration, the base terminal is common to both the input and output circuits.

  • Input is applied between emitter and base.
  • Output is taken between collector and base.
  • Base is the common terminal.

Simplified conceptual representation of a Common Base connection. The base is shared by the input and output circuits.

3.2 Characteristics of CB Configuration

  • Input impedance: Low.
  • Output impedance: High.
  • Current gain: Less than unity.
  • Voltage gain: Generally high.
  • Power gain: Possible because of voltage gain.
  • Phase relationship: No phase inversion.
Current Gain (α) = IC / IE

In Common Base configuration, the collector current is slightly smaller than the emitter current because a small portion of emitter current flows as base current.

Therefore, the CB current gain α is slightly less than 1.

3.3 Applications of CB Configuration

  • High-frequency amplifier circuits.
  • RF amplifier stages.
  • Impedance matching in selected applications.
  • Circuits requiring low input impedance.

4. Common Emitter (CE) Configuration

4.1 Definition

In Common Emitter configuration, the emitter terminal is common to both the input and output circuits.

  • Input is applied between base and emitter.
  • Output is taken between collector and emitter.
  • Emitter is the common terminal.

Simplified conceptual representation of a Common Emitter connection. The emitter is shared by input and output circuits.

4.2 Characteristics of CE Configuration

  • Input impedance: Moderate.
  • Output impedance: High.
  • Current gain: High.
  • Voltage gain: High.
  • Power gain: High.
  • Phase relationship: 180° phase inversion.
Current Gain (β) = IC / IB

The CE configuration provides both current gain and voltage gain. This makes it a widely used configuration for transistor amplifiers.

4.3 Phase Inversion in CE Configuration

In a typical Common Emitter amplifier with a collector resistor, an increase in input voltage increases base current and collector current. The increased collector current produces a larger voltage drop across the collector resistor.

As a result, the collector output voltage decreases. Therefore, the output signal is inverted relative to the input signal by approximately 180° in the normal operating range.

Interview point: Common Emitter configuration produces a 180° phase shift between input and output voltage.

4.4 Applications of CE Configuration

  • Voltage amplifier circuits.
  • Audio amplifier stages.
  • Signal amplification.
  • General-purpose transistor switching circuits.
  • Electronic control circuits.

5. Common Collector (CC) Configuration

5.1 Definition

In Common Collector configuration, the collector terminal is common to both the input and output circuits.

  • Input is applied between base and collector.
  • Output is taken between emitter and collector.
  • Collector is the common terminal.

The Common Collector configuration is also known as the Emitter Follower because the emitter output voltage follows the base input voltage.

Simplified conceptual representation of a Common Collector connection. The collector is shared by input and output circuits.

5.2 Characteristics of CC Configuration

  • Input impedance: High.
  • Output impedance: Low.
  • Current gain: High.
  • Voltage gain: Approximately unity, usually slightly less than 1.
  • Power gain: Greater than unity in practical amplifier operation.
  • Phase relationship: No phase inversion.
Current Gain ≈ β + 1

The emitter current is the sum of collector current and base current. Therefore, the current gain with respect to base current is approximately β + 1.

5.3 Why is it Called an Emitter Follower?

In a typical emitter follower, the emitter voltage changes in the same direction as the base voltage.

For a silicon NPN transistor operating in the active region, the emitter voltage is approximately one base-emitter voltage drop below the base voltage.

VE ≈ VB − VBE

For ordinary silicon BJT operating conditions, VBE is often around 0.6–0.7 V, although its value depends on current and temperature.

5.4 Applications of CC Configuration

  • Voltage buffer circuits.
  • Impedance matching.
  • Driving low-impedance loads from higher-impedance sources.
  • Output stages of amplifier circuits.
  • Signal isolation between circuit stages.

6. Comparison of CB, CE and CC Configurations

The following table is important for technical interviews, examinations and placement preparation.

Parameter Common Base (CB) Common Emitter (CE) Common Collector (CC)
Common terminal Base Emitter Collector
Input terminals Emitter–Base Base–Emitter Base–Collector
Output terminals Collector–Base Collector–Emitter Emitter–Collector
Input impedance Low Moderate High
Output impedance High High Low
Current gain Less than 1 (α) High (β) High (β + 1)
Voltage gain Generally high Generally high Approximately 1
Phase inversion No 180° No
Typical application High-frequency amplification Voltage amplification Buffer and impedance matching
Note: Impedance and gain values are qualitative comparisons. Actual values depend on the transistor, biasing, frequency, source resistance and load.

7. Relationship Between α, β and γ

The three current gains used in BJT analysis are related to emitter, collector and base currents.

The fundamental current relationship is:

IE = IC + IB

7.1 Common Base Current Gain (α)

α = IC / IE

7.2 Common Emitter Current Gain (β)

β = IC / IB

7.3 Common Collector Current Gain (γ)

γ = IE / IB

7.4 Conversion Formulas

β = α / (1 − α)

α = β / (β + 1)

γ = β + 1

γ = 1 / (1 − α)
Important: These relationships use current magnitudes and apply to the usual forward-active BJT model. Some textbooks use different symbols for current gains.

8. Numerical Examples

Example 1: Calculate α from β

Given:

  • β = 99

Formula:

α = β / (β + 1)

Solution:

α = 99 / (99 + 1)

α = 99 / 100

α = 0.99

Answer: α = 0.99

Example 2: Calculate β from α

Given:

  • α = 0.98

Formula:

β = α / (1 − α)

Solution:

β = 0.98 / (1 − 0.98)

β = 0.98 / 0.02

β = 49

Answer: β = 49

Example 3: Calculate Collector Current

Given:

  • Base current, IB = 40 µA
  • Current gain, β = 100

Formula:

IC = β × IB

Solution:

IC = 100 × 40 µA

IC = 4000 µA = 4 mA

Answer: Collector current = 4 mA.

These calculations assume the transistor remains in the forward-active region. The actual collector current is also limited by the supply voltage and collector circuit.

9. Practical Selection of BJT Configuration

Requirement Suitable Configuration Reason
High-frequency amplification CB Good high-frequency performance and low input impedance.
General voltage amplification CE Provides useful voltage, current and power gain.
High input impedance CC Provides high input impedance.
Low output impedance CC Useful as a buffer stage.
Voltage buffer CC Voltage gain is approximately unity.
180° phase inversion CE Collector output is inverted relative to input.

10. Important Interview Questions

Q1. What are the three BJT configurations?

Common Base, Common Emitter and Common Collector.

Q2. Which BJT configuration is most commonly used for voltage amplification?

Common Emitter configuration.

Q3. Which configuration is called an emitter follower?

Common Collector configuration.

Q4. Which configuration has current gain less than unity?

Common Base configuration.

Q5. Which configuration produces a 180° phase shift?

Common Emitter configuration.

Q6. Which configuration has high input impedance and low output impedance?

Common Collector configuration.

Q7. What is the current gain of CB configuration?

α = IC / IE.

Q8. What is the current gain of CE configuration?

β = IC / IB.

Q9. What is the approximate voltage gain of an emitter follower?

Approximately 1, usually slightly less than unity.

Q10. Why is a Common Collector circuit used as a buffer?

It provides high input impedance, low output impedance and approximately unity voltage gain.

12. Lesson Summary

  • CB has the base terminal common to input and output.
  • CE has the emitter terminal common to input and output.
  • CC has the collector terminal common to input and output.
  • CB has low input impedance and current gain below unity.
  • CE provides useful current, voltage and power gain.
  • CC provides high input impedance and low output impedance.
  • CE produces approximately 180° phase inversion.
  • CC is widely used as a voltage buffer.
  • α, β and γ are related current-gain parameters.
Placement preparation tip: Remember the common terminal, input/output impedance, current gain, phase relationship and application of all three configurations. These are frequently tested in electronics technical interviews.
