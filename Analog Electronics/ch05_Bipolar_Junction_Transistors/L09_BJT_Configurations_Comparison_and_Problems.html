2. The Three BJT Configurations

A bipolar junction transistor has three terminals: emitter, base and collector. Depending on which terminal is common to the input and output circuits, the transistor can be connected in three basic configurations.

Common Base (CB)

Base is common to input and output.

Typical use: High-frequency applications and low-input-impedance stages.

Common Emitter (CE)

Emitter is common to input and output.

Typical use: General-purpose voltage amplification.

Common Collector (CC)

Collector is common to input and output.

Typical use: Buffering and impedance matching.

4. Current Gain Relationships

For a transistor operating in the forward-active region:

α = IC / IE
β = IC / IB
IE = IC + IB

Therefore:

β = α / (1 − α)
α = β / (β + 1)
IE = (β + 1)IB

7. Gain and Impedance: Engineering Interpretation

Current gain

  • CB: current gain is approximately alpha and is less than unity.
  • CE: current gain is approximately beta.
  • CC: emitter current gain relative to base current is approximately beta + 1.

Voltage gain

  • CB: can provide high voltage gain.
  • CE: can provide high voltage gain and phase inversion.
  • CC: voltage gain is slightly less than unity.

Power gain

Ap = Pout / Pin
For a simplified resistive signal comparison: Ap ≈ |Av| × Ai

Power gain is the product of voltage gain and current gain when the corresponding voltage and current ratios are defined consistently at the same input and output ports. Practical power gain depends on impedance matching and power delivered to the load.

9. Solved Numerical Problems

Problem 1: Convert alpha to beta

Given α = 0.98. Calculate β.

β = α / (1 − α)
β = 0.98 / 0.02
β = 49

Answer: β = 49.

Problem 2: Convert beta to alpha

Given β = 99. Calculate α.

α = β / (β + 1)
α = 99 / 100 = 0.99

Answer: α = 0.99.

Problem 3: Calculate emitter current

Given β = 100 and IB = 30 µA.

IC = βIB = 100 × 30 µA = 3 mA
IE = IC + IB
IE = 3 mA + 0.03 mA = 3.03 mA

Answer: IC = 3 mA and IE = 3.03 mA.

Problem 4: Calculate collector current using alpha

Given α = 0.98 and IE = 5 mA.

IC = αIE = 0.98 × 5 mA
IC = 4.9 mA

Answer: Collector current = 4.9 mA.

Problem 5: Determine base current

Given IC = 6 mA and β = 120.

IB = IC / β
IB = 6 mA / 120 = 50 µA

Answer: Base current = 50 µA.

Problem 6: Calculate CE collector voltage

Given VCC = 15 V, RC = 2 kΩ and IC = 4 mA.

VRC = ICRC = 4 mA × 2 kΩ = 8 V
VCE = VCC − VRC = 15 − 8
VCE = 7 V

Answer: VCE = 7 V, assuming the emitter is at ground for DC analysis.

Problem 7: Estimate intrinsic emitter resistance

Given IE = 2.5 mA at room temperature.

re ≈ 25.9 mV / IE
re ≈ 25.9 mV / 2.5 mA
re ≈ 10.36 Ω

Answer: Small-signal intrinsic emitter resistance ≈ 10.36 Ω.

10. Practical Circuit Selection Scenarios

Scenario 1: A sensor has a high output resistance and must drive a lower-resistance stage.

Suggested stage: Common collector. Its high input impedance reduces loading on the sensor, while its low output impedance helps drive the next stage.

Scenario 2: A small AC signal needs substantial voltage amplification.

Suggested stage: Common emitter. It can provide voltage gain and current gain, with an inverted output.

Scenario 3: A low-impedance signal source must drive a high-impedance load at high frequency.

Suggested stage: Common base may be appropriate, depending on bandwidth, source/load impedances and the overall design.

Scenario 4: A circuit needs an output signal in phase with its input and with current gain.

Suggested stage: Common collector.

Procedure

  1. Build each configuration using a suitable transistor and correctly designed bias network.
  2. Verify DC operating conditions before applying the AC input.
  3. Apply a small sinusoidal signal.
  4. Measure input and output voltage amplitudes.
  5. Measure or estimate input and output impedances using an appropriate test method.
  6. Compare current gain and phase relationship.
  7. Record the results and compare them with theoretical expectations.

Use the same transistor type where practical, but do not assume that identical resistor values create equivalent bias conditions across different configurations. Design and verify each circuit separately.

13. Placement Interview Questions and Answers

1. Name the three basic BJT configurations.
Common-base, common-emitter and common-collector.
2. Which configuration has current gain less than unity?
Common-base, because its current gain is alpha, which is less than one in normal forward-active operation.
3. Which configuration provides a phase-inverted output?
Common-emitter.
4. Which configuration is called an emitter follower?
Common-collector.
5. Which configuration has high input impedance and low output impedance?
Common-collector, typically.
6. Which configuration is commonly used for voltage amplification?
Common-emitter.
7. State the relationship between alpha and beta.
β = α/(1−α), and α = β/(β+1).
8. Why is alpha less than unity?
Because emitter current includes both collector current and base current, so IC is less than IE.
9. Which configuration has high voltage gain but low current gain?
Common-base can have high voltage gain and current gain below unity.
10. What is the current gain of CC?
Approximately β + 1 when defined as emitter current divided by base current.
11. Why is CE widely used?
It can provide useful voltage, current and power gain.
12. What is impedance matching?
Interfacing circuits with different impedances to reduce unwanted loading and transfer the required signal or power effectively.
13. Why is CC suitable as a buffer?
It provides high input impedance, low output impedance and approximately unity voltage gain.
14. What is the typical phase shift of a CE amplifier?
Approximately 180°.
15. What is the approximate phase shift of CB and CC stages?
Both are normally non-inverting, with approximately 0° phase difference in their intended operating range.
16. Which configuration is often useful at high frequencies?
Common-base can be useful in high-frequency designs, depending on the circuit and device.
17. Define power gain.
The ratio of output signal power to input signal power.
18. Can a CC stage provide voltage gain greater than one?
A conventional emitter follower has voltage gain slightly below unity; it is not normally selected for voltage amplification.
19. What is the Early effect?
The change in effective base width with collector-base reverse bias, causing collector current to depend slightly on VCE.
20. Why must the Q-point be selected carefully?
To provide the required linear signal swing without entering cutoff or saturation.
