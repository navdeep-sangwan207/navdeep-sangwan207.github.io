2. Introduction to BJT Currents

A bipolar junction transistor has three terminals: emitter, base and collector. During normal forward-active operation, current flows through all three terminals.

For an NPN transistor, conventional current enters the collector and base and leaves through the emitter. The emitter current is therefore the sum of collector and base currents.

IE = IC + IB

This relationship follows from Kirchhoff's Current Law (KCL).

Important: The equation is written using current magnitudes and the normal NPN current directions. For a PNP transistor, the physical current directions reverse; use a consistent sign convention when applying KCL.

3. Emitter Current (IE)

Emitter current is the total current flowing through the emitter terminal. In forward-active operation, the emitter injects majority carriers into the thin base region.

  • For an NPN transistor, electrons are injected from the emitter into the base.
  • For a PNP transistor, holes are injected from the emitter into the base.
  • Most injected carriers cross the thin base and reach the collector junction.
  • A smaller fraction recombines in the base, contributing to base current.
IE = IC + IB

Emitter current is the largest of the three terminal-current magnitudes in normal forward-active operation.

4. Collector Current (IC)

Collector current is primarily due to carriers injected by the emitter and transported across the base into the collector region.

  • It is controlled by the base-emitter drive in forward-active operation.
  • It depends on device characteristics, collector voltage, temperature and operating point.
  • In a simplified forward-active model, collector current is approximately proportional to base current.
IC ≈ β IB
This gain relationship is an approximation for forward-active operation. It must not be used as a precise saturation-current equation.

5. Base Current (IB)

The base is thin and lightly doped compared with the emitter. A small proportion of carriers injected by the emitter recombine in the base. The external base terminal supplies or removes the charge associated with this recombination.

  • Base current is usually much smaller than collector current.
  • Base current is necessary to establish the transistor's normal forward-active operation.
  • Its value is affected by collector current, temperature and transistor gain.
  • In practical switching circuits, the base drive is selected with adequate margin to ensure saturation.
IB = IE − IC

7. Common-Base Current Gain (Alpha, α)

Common-base current gain is the ratio of collector current to emitter current in a common-base configuration.

α = IC / IE

In normal forward-active operation, alpha is slightly less than 1 because a small portion of the emitter-injected carriers contributes to base current rather than collector current.

Typical silicon transistor values are often close to 1, for example 0.98 to 0.998, but the actual value depends on the device and operating conditions.

Example

If IC = 9.8 mA and IE = 10 mA:

α = 9.8 / 10 = 0.98

8. Common-Emitter Current Gain (Beta, β)

Common-emitter current gain is the ratio of collector current to base current in a common-emitter configuration.

β = IC / IB

For example, if collector current is 5 mA and base current is 50 µA:

β = 5 mA / 50 µA = 100

Beta is dimensionless. It is often called hFE when referring to the DC current gain measured under specified test conditions.

Terminology: β or hFE generally denotes DC current gain. Small-signal AC current gain is commonly written as hfe. Datasheets specify test conditions because gain changes with collector current, collector-emitter voltage and temperature.

9. Relationship Between Alpha and Beta

Start with the KCL relationship:

IE = IC + IB

Divide by collector current:

IE/IC = 1 + IB/IC

Using α = IC/IE and β = IC/IB:

1/α = 1 + 1/β

Rearranging:

β = α / (1 − α)

Similarly:

α = β / (β + 1)
ParameterFormulaMeaning
Alphaα = IC / IECommon-base current gain
Betaβ = IC / IBCommon-emitter current gain
Beta from alphaβ = α / (1 − α)Convert α to β
Alpha from betaα = β / (β + 1)Convert β to α
A small change in alpha near 1 can produce a large change in beta. Do not round alpha too early when calculating beta.

12. Worked Numerical Problems

Example 1: Calculate emitter current

A transistor has collector current of 8 mA and base current of 80 µA. Find emitter current.

Convert base current:

80 µA = 0.08 mA
IE = IC + IB = 8 + 0.08 = 8.08 mA

Answer: IE = 8.08 mA.

Example 2: Calculate beta

A transistor has IC = 6 mA and IB = 60 µA. Calculate beta.

β = 6 mA / 0.06 mA = 100

Answer: β = 100.

Example 3: Calculate alpha from beta

A transistor has β = 99. Calculate alpha.

α = β / (β + 1) = 99 / 100 = 0.99

Answer: α = 0.99.

Example 4: Calculate beta from alpha

A transistor has α = 0.995. Calculate beta.

β = 0.995 / (1 − 0.995) = 199

Answer: β = 199.

Example 5: Calculate base current

A transistor has IE = 5.05 mA and IC = 5 mA. Calculate base current.

IB = IE − IC = 5.05 − 5 = 0.05 mA = 50 µA

Answer: IB = 50 µA.

13. Effect of Current Gain on Circuit Design

Current gain is useful for estimating base drive in an amplifier or switching circuit, but it is not a fixed constant across all operating conditions.

Amplifier design

  • Use the datasheet's gain range at the intended collector current and voltage.
  • Choose a bias network that establishes a stable operating point.
  • Do not assume that beta remains constant with temperature or collector current.

Switching design

  • For a switching transistor, select base current using a conservative forced beta.
  • Forced beta is the design ratio IC/IB used to drive the transistor into saturation.
  • It is commonly selected much lower than the datasheet's typical active-region gain.
IB(required) ≥ IC(load) / βforced
For switching, do not size the base resistor using only a typical hFE value. Check the datasheet's saturation test conditions and maximum ratings.

14. Practical Lab Exercise

Experiment: Measurement of BJT Current Gain

Objective: To measure base, collector and emitter currents and calculate alpha and beta.

Equipment:

  • BC547 or 2N2222 NPN transistor.
  • Regulated DC power supply.
  • Suitable base and collector resistors.
  • Digital multimeter.
  • Breadboard and connecting wires.

Procedure:

  1. Identify the transistor terminals from its datasheet.
  2. Build a common-emitter test circuit with current-limiting resistors.
  3. Set a low, safe base drive and verify that the transistor is in forward-active operation.
  4. Measure collector current using an appropriate series-current measurement method.
  5. Measure base current without disturbing the circuit operating point significantly.
  6. Calculate emitter current from IE = IC + IB, or measure it directly.
  7. Calculate α = IC/IE and β = IC/IB.
  8. Repeat at another safe operating point and compare the results.

Expected result: IE should approximately equal IC + IB. Alpha should be slightly less than 1 in normal forward-active operation. Beta should be greater than alpha numerically and is usually much larger than 1.

Power down before changing connections. Never connect a transistor directly across a supply without suitable current limiting. Ensure the transistor remains within its maximum collector current and power dissipation ratings.

16. Placement Interview Questions

Q1. What are the three terminal currents of a BJT?

Emitter current, base current and collector current.

Q2. State the BJT current equation.

IE = IC + IB, using the usual current magnitudes for an NPN transistor in normal operation.

Q3. Which terminal current is the largest?

Emitter current, because it is the sum of collector and base currents.

Q4. Define alpha.

Alpha is the common-base current gain, α = IC/IE.

Q5. Define beta.

Beta is the common-emitter DC current gain, β = IC/IB.

Q6. What is the relationship between alpha and beta?

β = α/(1 − α), and α = β/(β + 1).

Q7. Why is alpha less than one?

A small fraction of the emitter-injected carriers recombines in the base rather than reaching the collector.

Q8. Why is beta usually much greater than one?

Collector current is generally much larger than base current in forward-active operation.

Q9. What is hFE?

It is the DC common-emitter current gain specified under particular datasheet test conditions.

Q10. Is beta constant?

No. It varies with collector current, collector-emitter voltage, temperature and device variation.

Q11. What is forced beta?

It is the selected IC/IB ratio used for designing a saturated switching transistor.

Q12. Can alpha be equal to one?

In an idealized limiting model it can approach one, but a practical transistor has some base recombination and finite current gain.

Q13. Why does base current exist?

Primarily because some injected carriers recombine in the base region and because of other base-junction current components.

Q14. What happens to beta when alpha approaches one?

Beta increases sharply because β = α/(1 − α).

Q15. Which current gain is associated with the common-base configuration?

Alpha.

Q16. Which current gain is associated with the common-emitter configuration?

Beta.

19. Lecture Summary

  • IE = IC + IB.
  • Alpha is the common-base current gain: α = IC/IE.
  • Beta is the common-emitter DC current gain: β = IC/IB.
  • β = α/(1 − α).
  • α = β/(β + 1).
  • Alpha is slightly less than one in a practical forward-active transistor.
  • Beta varies with operating conditions and is not a fixed universal constant.
  • Forced beta is useful for designing reliable saturated transistor switches.
