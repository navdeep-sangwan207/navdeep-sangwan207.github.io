Lesson 7: Common Collector and Common Base Amplifiers

Understand emitter followers, common-base operation, amplifier gain and impedance characteristics.

Chapter 6: BJT Biasing and Amplifiers

1. Introduction

A BJT can be connected in three basic amplifier configurations:

  1. Common Emitter (CE).
  2. Common Collector (CC).
  3. Common Base (CB).

In the previous lesson, we studied the Common Emitter amplifier. This lesson focuses on the Common Collector and Common Base configurations.

Important: The common collector configuration is also called an emitter follower. The common base configuration is useful in applications requiring low input impedance and high-frequency performance.

2. Common Collector (CC) Amplifier

A Common Collector (CC) amplifier is a BJT configuration in which the collector terminal is common to both input and output circuits for AC signals.

The input signal is applied between the base and collector, while the output is taken between the emitter and collector.

The output voltage is taken from the emitter. Therefore, the circuit is commonly called an emitter follower.

2.1 Circuit Configuration

Conceptual Common Collector Circuit

Note: This is a conceptual illustration of the CC configuration. Practical circuits also require appropriate DC biasing and coupling components.

2.2 Working Principle

  1. The input signal is applied to the transistor base.
  2. The base voltage changes with the input signal.
  3. The emitter voltage follows the base voltage, with a small base-emitter voltage difference.
  4. The output is taken from the emitter.
  5. The output follows the input without phase inversion.
VE ≈ VB − VBE

For a silicon transistor, VBE is often around 0.6–0.7 V at typical operating currents, but the actual value depends on current and temperature.

3.1 Voltage Gain

The voltage gain of an emitter follower is slightly less than unity.

Av = vo / vi

Av ≈ 1

More precisely, for a simplified small-signal emitter follower with emitter load RE':

Av ≈ RE' / (RE' + re)

Here RE' represents the total effective emitter load, including the external load where applicable. The approximation neglects some base-loading and transistor output-resistance effects.

3.2 Current Gain

Ai ≈ β + 1

The emitter current is approximately the sum of base and collector currents.

IE = IC + IB

4. Applications of Common Collector Amplifier

  • Impedance matching.
  • Buffer amplifier stages.
  • Driving low-resistance loads from high-resistance sources.
  • Signal isolation between circuit stages.
  • Output stages in analog circuits.
Practical example: An emitter follower can be used between a high-output- impedance sensor circuit and a low-input-impedance load to reduce loading effects.

5. Common Base (CB) Amplifier

A Common Base (CB) amplifier is a BJT configuration in which the base terminal is common to both input and output circuits for AC signals.

The input signal is applied between the emitter and base, while the output is taken between the collector and base.

5.1 Circuit Configuration

Conceptual Common Base Circuit

Note: This diagram illustrates the common-base connection. A practical CB amplifier requires a suitable collector load, bias network and signal coupling.

5.2 Working Principle

  1. The base terminal is maintained at AC ground.
  2. The input signal is applied to the emitter.
  3. The input changes the emitter-base voltage.
  4. Collector current changes in response to the input.
  5. The varying collector current produces an output voltage across the collector load.

6. Characteristics of Common Base Amplifier

Parameter Characteristic
Voltage Gain Can be high
Current Gain Approximately α, less than 1
Power Gain Can be significant
Input Impedance Low
Output Impedance High
Phase Difference Approximately 0°

6.1 Current Gain

The common-base current gain is represented by α.

α = IC / IE

For a normal forward-active transistor:

α = β / (β + 1)

Since collector current is slightly less than emitter current, α is less than 1.

6.2 Voltage Gain

The CB configuration can provide substantial voltage gain because of its low input resistance and collector load.

A simplified midband approximation is:

Av ≈ α(RC || RL) / re

This assumes negligible transistor output conductance and a suitable AC-grounded base.

7. Applications of Common Base Amplifier

  • High-frequency amplifier circuits.
  • RF amplifier stages.
  • Impedance matching from a low-impedance source.
  • Wideband amplifier applications.
  • Cascode amplifier circuits.

10. Numerical Example: Common Base Current Gain

A transistor has:

  • Emitter current IE = 5 mA
  • Collector current IC = 4.95 mA

Calculate the common-base current gain α.

α = IC / IE

α = 4.95 / 5

α = 0.99
Answer: α = 0.99.

A transistor has a common-emitter current gain β = 100. Calculate the approximate common-collector current gain.

12. Interview Questions and Answers

Q1. What is a common collector amplifier?

It is a BJT amplifier in which the collector is common to input and output AC circuits.

Q2. Why is CC called an emitter follower?

Because its emitter output voltage follows the base input voltage with a small voltage difference.

Q3. What is the voltage gain of a CC amplifier?

It is approximately unity and slightly less than 1.

Q4. What is the main application of CC configuration?

Buffer amplification and impedance matching.

Q5. What is a common-base amplifier?

It is a BJT amplifier in which the base is common to input and output AC circuits.

Q6. What is the current gain of a CB amplifier?

It is approximately α, which is less than 1.

Q7. Why is CB configuration used in RF circuits?

It can provide useful high-frequency performance and has low input impedance.

Q8. Which BJT configuration provides the highest input impedance?

Common Collector.

Q9. Which configuration has low input impedance and high output impedance?

Common Base.

14. Lesson Summary

  • CC and CB are two basic BJT amplifier configurations.
  • CC is also called an emitter follower.
  • CC has high input impedance and low output impedance.
  • CC voltage gain is approximately unity.
  • CC current gain is approximately β + 1.
  • CB has low input impedance and high output impedance.
  • CB current gain is approximately α.
  • Both CC and CB have approximately zero phase inversion.
  • CC is used for buffering; CB is useful in RF and wideband stages.
Remember: Common Collector is mainly used as a buffer, while Common Base is useful where low input impedance and high-frequency performance are required.
