Understand CE amplifier operation, circuit design, voltage gain, impedance and phase inversion.

1. Introduction to Common Emitter Amplifier

A Common Emitter (CE) amplifier is a BJT amplifier configuration in which the emitter terminal is common to both the input and output circuits for AC signals.

The input signal is applied between the base and emitter, while the output signal is taken between the collector and emitter.

The CE configuration is widely used because it provides:

  • High voltage gain.
  • High current gain.
  • High power gain.
  • Moderate input impedance.
  • Relatively high output impedance.
Important: A common-emitter amplifier produces approximately 180° phase inversion between its input and output voltage signals.

2. Common Emitter Amplifier Circuit

A practical voltage-divider-biased CE amplifier generally contains:

  • R1 and R2: Base voltage-divider bias network.
  • RC: Collector resistor.
  • RE: Emitter resistor for DC stabilization.
  • CE: Emitter bypass capacitor.
  • Cin: Input coupling capacitor.
  • Cout: Output coupling capacitor.
  • RL: Output load resistor.
  • Q1: NPN transistor.

3. Working Principle of CE Amplifier

The transistor is biased in the forward-active region. A small AC input signal is applied to the base through the input coupling capacitor.

  1. The input signal changes the base-emitter voltage.
  2. The base current changes with the input signal.
  3. Collector current changes according to the transistor's small-signal response.
  4. The varying collector current produces a varying voltage drop across the collector load.
  5. The collector output voltage changes in the opposite direction to the input signal.
  6. The output coupling capacitor transfers the AC output to the load.
vo ≈ −ic(RC || RL)

This is a simplified midband expression when the emitter is AC-grounded, the transistor output resistance is neglected, and the load is coupled to the collector through a sufficiently large capacitor.

4. Phase Inversion in CE Amplifier

A CE amplifier produces approximately 180° phase inversion between its input and output voltage signals.

When the input voltage increases:

  • Base-emitter voltage increases.
  • Collector current increases.
  • Voltage drop across RC increases.
  • Collector voltage decreases.

Therefore, the output voltage decreases when the input voltage increases.

5. Voltage Gain of CE Amplifier

Voltage gain is the ratio of output AC voltage to input AC voltage.

Av = vo / vi

For a simplified CE amplifier with an AC-grounded emitter and negligible transistor output resistance:

Av ≈ −gm(RC || RL)

The negative sign indicates phase inversion.

For an unloaded amplifier, or when RL is much larger than RC:

Av ≈ −gmRC

If the emitter resistor is not bypassed, emitter degeneration reduces the gain. A useful approximate expression is:

Av ≈ −β(RC || RL) / [rπ + (β + 1)RE]

This expression assumes a simple midband hybrid-π model, negligible transistor output conductance, and an unbypassed emitter resistance.

6. Input Impedance of CE Amplifier

Input impedance describes the opposition offered by the amplifier input to an AC signal.

When the emitter is AC-grounded, the transistor's small-signal input resistance is approximately rπ.

For a voltage-divider-biased amplifier:

Rin ≈ R1 || R2 || rπ

The input impedance depends on the bias network and the transistor's small-signal parameters.

7. Output Impedance of CE Amplifier

Output impedance is the effective impedance looking back into the amplifier output with the input signal source set to zero.

When transistor output resistance is neglected:

Rout ≈ RC

When transistor output resistance ro is included:

Rout ≈ RC || ro

This is the approximate midband output resistance before the external load is connected.

8. Role of Emitter Resistor and Bypass Capacitor

8.1 Emitter Resistor (RE)

The emitter resistor provides DC negative feedback and improves bias stability.

It reduces the sensitivity of collector current to transistor parameter and temperature variations.

8.2 Emitter Bypass Capacitor (CE)

The bypass capacitor is connected in parallel with RE. At sufficiently high signal frequencies, its impedance becomes low and it bypasses RE for AC signals.

XC = 1 / (2πfCE)
Condition Effect
CE absent Higher AC emitter feedback and generally lower voltage gain
CE effective at signal frequency Lower AC emitter impedance and generally higher voltage gain
Low signal frequency Bypass capacitor impedance may become significant

9. Numerical Example: CE Amplifier Voltage Gain

A CE amplifier has the following small-signal parameters:

  • ICQ = 1 mA
  • VT = 25.9 mV
  • RC = 4.7 kΩ
  • RL = 10 kΩ

Assume the emitter is AC-grounded and transistor output resistance is neglected.

Step 1: Calculate Transconductance

gm = ICQ / VT

gm = 0.001 / 0.0259

gm ≈ 0.0386 S

Step 2: Calculate Effective Collector Load

RC || RL = (RC × RL) / (RC + RL)

= (4.7 × 10) / (4.7 + 10) kΩ

≈ 3.197 kΩ

Step 3: Calculate Voltage Gain

Av ≈ −gm(RC || RL)

Av ≈ −0.0386 × 3197

Av ≈ −123.4
Answer: Approximate voltage gain = −123.4. The negative sign indicates 180° phase inversion.

10. Advantages of CE Amplifier

  • High voltage gain.
  • High current gain.
  • High power gain.
  • Suitable for audio-frequency voltage amplification.
  • Widely used as a common amplifier stage.

11. Disadvantages of CE Amplifier

  • Produces 180° phase inversion.
  • Input and output impedances may require matching.
  • Gain can vary with transistor parameters.
  • High gain may increase distortion if the signal swing is excessive.
  • Frequency response is limited by coupling, bypass and parasitic capacitances.

12. Applications of CE Amplifier

Application Purpose
Audio preamplifier Amplifies low-level audio signals
Sensor signal conditioning Amplifies weak sensor outputs
Communication circuits Provides voltage amplification
Analog signal processing Provides gain between circuit stages
Transistor amplifier stages Used in multistage amplifier systems

13. Interview Questions and Answers

Q1. What is a common-emitter amplifier?

It is a BJT amplifier in which the emitter is common to the input and output circuits for AC signals.

Q2. Why is CE configuration widely used?

It provides useful voltage, current and power gain.

Q3. What is the phase difference in a CE amplifier?

Approximately 180° between input and output voltage signals.

Q4. What is the function of RC?

It converts collector-current variations into output-voltage variations.

Q5. What is the purpose of RE?

It provides DC negative feedback and improves bias stability.

Q6. What is the purpose of CE?

It bypasses the emitter resistor for AC signals over its effective frequency range, increasing voltage gain.

Q7. What is the approximate voltage gain of a bypassed CE amplifier?

Av ≈ −gm(RC || RL), when ro is neglected.

Q8. What is the input impedance of a voltage-divider-biased CE amplifier?

Approximately R1 || R2 || rπ when the emitter is AC-grounded.

15. Lesson Summary

  • CE is a widely used BJT amplifier configuration.
  • The emitter is common to input and output AC circuits.
  • It provides voltage, current and power gain.
  • It produces approximately 180° phase inversion.
  • RC converts collector-current changes into output-voltage changes.
  • RE improves DC bias stability.
  • CE bypasses RE for AC signals over its effective frequency range.
  • Input and output coupling capacitors block DC while passing AC.
  • Av ≈ −gm(RC || RL) under the stated midband assumptions.
Remember: The common-emitter amplifier is especially important in electronics because it provides substantial voltage gain and is widely used in practical analog amplifier stages.
