2. What Is Collector-to-Base Bias?

Collector-to-base bias is a BJT biasing technique in which the base resistor is connected between the collector and base terminals rather than directly between the supply and base.

The collector voltage provides the base-bias voltage. This arrangement introduces negative feedback, which helps oppose changes in collector current.

Important connection: RB connects from the collector node (the junction of RC and collector) to the base. The current through RC is therefore approximately IC + IB, not just IC.

3. Circuit Operation

  1. VCC supplies current through RC to the collector node.
  2. A portion of the collector-node current flows through RB into the base.
  3. The base-emitter junction becomes forward biased, allowing collector current to flow.
  4. The collector voltage establishes the base-bias voltage through RB.

Negative Feedback Mechanism

Consider an increase in temperature or transistor current gain that tends to increase IC:

  1. Collector current increases.
  2. The voltage drop across RC increases because the current through RC is approximately IC + IB.
  3. Collector voltage decreases.
  4. Voltage across RB decreases, reducing IB.
  5. The reduced base current opposes the original increase in collector current.
Core principle: An increase in collector current reduces the collector voltage, which reduces base drive. This is negative feedback.

4. DC Circuit Analysis and Derivation

For an NPN transistor operating in the forward-active region:

  • Base-emitter junction is forward biased.
  • Collector-base junction is reverse biased.
  • Emitter is connected to ground.

Base-loop KVL

Apply Kirchhoff's Voltage Law around the path from VCC through RC, RB and the base-emitter junction:

VCC = (IC + IB)RC + IBRB + VBE

Using the active-region relationship:

IC = βIB

Substitute into the KVL equation:

VCC − VBE = IB[RB + (β + 1)RC]

Therefore, the base current is:

IB = (VCC − VBE) / [RB + (β + 1)RC]

Collector and emitter currents

IC = βIB
IE = IC + IB = (β + 1)IB

Collector voltage

The current through RC is IE = IC + IB. Therefore:

VC = VCC − (IC + IB)RC

Since the emitter is grounded:

VCE = VC = VCC − (β + 1)IBRC
Common examination mistake: In this circuit, the current through RC includes both collector current and base current. Using VCC − ICRC alone gives a slightly incorrect collector voltage.

5. Worked Numerical Example

Given:

ParameterValue
Supply voltage VCC12 V
Base resistor RB470 kΩ
Collector resistor RC2.2 kΩ
Current gain β100
Base-emitter voltage VBE0.7 V

Step 1: Calculate base current

IB = (12 − 0.7) / [470k + 101 × 2.2k]
IB = 11.3 / 692.2k = 16.33 µA

Step 2: Calculate collector current

IC = 100 × 16.33 µA = 1.633 mA

Step 3: Calculate emitter current

IE = 1.633 + 0.01633 = 1.649 mA

Step 4: Calculate collector-emitter voltage

VCE = 12 − (1.649 mA × 2.2 kΩ)
VCE ≈ 8.37 V
Result: Q-point ≈ (VCE = 8.37 V, IC = 1.633 mA). This is consistent with forward-active operation for the assumed transistor model.

7. Q-Point and Load-Line Interpretation

The Q-point is the quiescent operating point of the transistor. It is specified by the DC values of IC and VCE.

For a given base-current operating condition, the collector circuit follows:

VCC = VCE + (IC + IB)RC

For a fixed IB, the collector-circuit line has approximate intercepts:

  • At IC = 0, VCE = VCC − IBRC.
  • At VCE = 0, IC = VCC/RC − IB.

8. Effect of β on the Operating Point

In fixed bias, collector current is strongly dependent on β. Collector-to-base feedback reduces this sensitivity because a change in collector voltage changes the base drive.

However, the operating point is not completely independent of β. RB, RC, supply voltage and temperature still influence the result.

Parameter changeExpected tendency
β increasesIC tends to increase; collector voltage falls and feedback reduces base drive.
β decreasesIC tends to decrease; collector voltage rises and more base drive becomes available.
RC increasesGreater collector voltage drop for a given current.
RB increasesBase current generally decreases.
VCC increasesBias currents and voltage headroom generally increase.

Collector-to-base bias improves stability compared with fixed bias, but voltage-divider bias with emitter stabilization is generally preferred for a more stable amplifier Q-point.

10. Practical Laboratory Exercise

Objective: Construct and verify an NPN collector-to-base feedback bias circuit.

Components

  • One general-purpose NPN transistor, such as BC547 or 2N2222 (verify the pinout for the exact part).
  • 12 V DC regulated supply.
  • RC = 2.2 kΩ, RB = 470 kΩ.
  • Breadboard, connecting wires and digital multimeter.

Procedure

  1. Identify the transistor's collector, base and emitter using its datasheet.
  2. Connect the emitter to ground.
  3. Connect RC between +12 V and the collector.
  4. Connect RB between the collector node and base.
  5. Apply the regulated supply with correct polarity.
  6. Measure base voltage, collector voltage and emitter voltage.
  7. Calculate VBE, VCE and approximate collector current.
  8. Compare measured results with theoretical calculations.

12. Placement Interview Questions and Answers

1. What is collector-to-base bias?

A BJT biasing method in which the base resistor is connected between collector and base.

2. Why is it called collector-feedback bias?

Because the collector voltage is fed back to the base through a resistor.

3. What type of feedback is present?

Negative feedback. A rise in collector current tends to lower collector voltage and reduce base drive.

4. What happens when collector current increases?

The voltage drop across RC increases, collector voltage decreases, and base current is reduced.

5. Derive the base-current equation.

Applying KVL gives VCC = (IC + IB)RC + IBRB + VBE. Substituting IC = βIB gives IB = (VCC − VBE)/[RB + (β + 1)RC].

6. Why does the equation contain (β + 1)RC?

Because RC carries emitter current IE = IC + IB = (β + 1)IB.

7. What is the relationship between IC and IB?

In forward-active operation, IC ≈ βIB.

8. Is β constant?

No. It varies with device, collector current, temperature and operating conditions.

9. Is collector-to-base bias more stable than fixed bias?

Generally yes, because it introduces negative feedback.

10. Is it more stable than voltage-divider bias?

Usually not. A properly designed voltage-divider network with emitter resistance provides stronger and more predictable stabilization.

11. What is the Q-point?

The DC quiescent operating point, commonly represented by ICQ and VCEQ.

12. What is the active-region condition?

The base-emitter junction is forward biased and the collector-base junction is reverse biased.

13. Why is the emitter grounded in this basic circuit?

It provides a common reference for the base-emitter and collector-emitter voltages.

14. What is the disadvantage of collector-feedback bias?

Its bias network loads the collector and couples collector-voltage changes back into the base circuit, which can affect amplifier input and gain.

15. Why must saturation be checked?

The equation IC = βIB is an active-region model. Once saturated, the external circuit limits collector current.

16. What is the approximate transistor power dissipation?

For a basic DC estimate, P ≈ VCE × IC. Check the device's safe operating area and thermal limits.

17. What happens if RB becomes open circuit?

Base drive is lost, so the transistor generally moves toward cutoff.

18. Why is this circuit not completely temperature independent?

VBE and transistor current gain vary with temperature; feedback reduces but does not eliminate these effects.
