Chapter 4: Rectifiers and Power Supply Circuits

Circuit operation, diode conduction, output waveforms and important rectifier calculations.

2. Introduction to Half-Wave Rectifier

A half-wave rectifier is the simplest type of rectifier circuit. It uses a single semiconductor diode to convert only one half-cycle of an AC input into a unidirectional output voltage.

During the other half-cycle, the diode blocks current. Therefore, the output consists of pulses separated by intervals of zero voltage.

Definition: A half-wave rectifier is a circuit that converts one half-cycle of an AC input signal into pulsating DC using a single diode.

3. Circuit Diagram

The basic half-wave rectifier consists of an AC source, one PN junction diode and a load resistor.

The circuit is shown in a simplified schematic style. The diode orientation determines which input half-cycle appears across the load.

4. Operation During Positive Half-Cycle

Consider the input AC voltage to be positive at the diode anode with respect to its cathode.

  • The diode becomes forward biased.
  • It starts conducting current.
  • Current flows through the load resistor.
  • A positive output voltage appears across the load.
Ideal diode: Vout = Vin

For a practical silicon diode, the output voltage is approximately the input voltage minus the diode forward voltage drop.

Vout ≈ Vin − VF

For a typical silicon diode, VF is often approximated as 0.7 V in basic circuit calculations. The actual value depends on current and temperature.

5. Operation During Negative Half-Cycle

During the negative half-cycle, the polarity of the AC input reverses.

  • The diode becomes reverse biased.
  • The diode blocks current, apart from small leakage.
  • Load current is approximately zero.
  • Output voltage across the load is approximately zero.
Important: The diode conducts during one half-cycle and blocks during the other. This is the fundamental reason why the circuit produces a half-wave output.

7. Mathematical Analysis

Let the input sinusoidal voltage be:

v = Vm sin(ωt)

For an ideal positive half-wave rectifier:

vo = Vm sin(ωt),   0 ≤ ωt ≤ π

vo = 0,   π ≤ ωt ≤ 2π

7.1 Average or DC Output Voltage

Average output voltage is calculated over one complete input cycle.

VDC = (1 / 2π) ∫0π Vm sin θ dθ

After integration:

VDC = Vm / π

Therefore:

VDC = 0.318 Vm

7.2 Average DC Output Current

For a purely resistive load RL and an ideal diode:

IDC = VDC / RL
IDC = Im / π

Where:

Im = Vm / RL

7.3 RMS Output Voltage

RMS voltage is the equivalent DC voltage that produces the same heating effect in a resistor.

VRMS = √[(1 / 2π) ∫0π Vm2 sin²θ dθ]

After simplification:

VRMS = Vm / 2

Similarly:

IRMS = Im / 2

7.4 Peak Inverse Voltage (PIV)

Peak inverse voltage is the maximum reverse voltage that a diode must withstand without entering breakdown.

PIV = Vm
Design consideration: Select a diode with a repetitive peak reverse voltage rating comfortably above the maximum expected reverse voltage, accounting for supply variations and transients.

7.5 Ripple Factor

Ripple factor measures the AC component present in the rectified output relative to its DC component.

r = √[(VRMS / VDC)² − 1]

For an ideal half-wave rectifier:

r ≈ 1.21

7.6 Rectification Efficiency

Rectification efficiency is the ratio of DC power delivered to the load to the AC input power consumed by the rectifier.

η = PDC / PAC × 100%

For an ideal half-wave rectifier with a resistive load:

ηmax ≈ 40.6%

9. Solved Numerical Example

Problem

A half-wave rectifier has a sinusoidal input with a peak voltage of 20 V and a load resistance of 1 kΩ. Assume an ideal diode. Calculate:

  1. Average DC output voltage.
  2. RMS output voltage.
  3. Average DC load current.
  4. RMS load current.
  5. Peak inverse voltage.

Given

Vm = 20 V
RL = 1000 Ω

Step 1: Average DC Output Voltage

VDC = Vm / π

= 20 / 3.1416

= 6.37 V

Step 2: RMS Output Voltage

VRMS = Vm / 2

= 20 / 2

= 10 V

Step 3: Average DC Load Current

IDC = VDC / RL

= 6.37 / 1000

= 6.37 mA

Step 4: RMS Load Current

IRMS = VRMS / RL

= 10 / 1000

= 10 mA

Step 5: Peak Inverse Voltage

PIV = Vm = 20 V
Final Answers:
  • Average DC voltage = 6.37 V
  • RMS voltage = 10 V
  • Average DC current = 6.37 mA
  • RMS current = 10 mA
  • PIV = 20 V

10. Advantages and Disadvantages

Advantages

  • Simple circuit design.
  • Requires only one diode.
  • Low component count and cost.
  • Easy to understand and troubleshoot.

Disadvantages

  • Uses only one half-cycle of the AC input.
  • Low rectification efficiency.
  • High ripple factor.
  • Lower average DC output for a given peak input voltage.
  • Not suitable for many applications requiring smooth DC.

11. Applications

  • Low-power signal demodulation circuits.
  • Simple signal detection circuits.
  • Basic AC-to-DC demonstration circuits.
  • Some low-current charging and control applications.
  • Educational rectifier experiments.
Half-wave rectifiers are generally not preferred for efficient general-purpose DC power supplies because they have high ripple and use only half of the AC cycle.

12. Interview Questions

Q1. How many diodes are used in a half-wave rectifier?

One diode.

Q2. What is the average output voltage of an ideal half-wave rectifier?

VDC = Vm / π.

Q3. What is its RMS output voltage?

VRMS = Vm / 2.

Q4. What is the PIV of its diode?

PIV = Vm.

Q5. What is the maximum rectification efficiency?

Approximately 40.6% for an ideal resistive-load circuit.

Q6. What is the ripple factor?

Approximately 1.21 for an ideal unfiltered half-wave rectifier.

Q7. What is the ripple frequency?

It is equal to the input AC frequency, f.

Q8. Why is the output called pulsating DC?

Because the output has only one polarity but its magnitude varies periodically and falls to zero during alternate half-cycles.
