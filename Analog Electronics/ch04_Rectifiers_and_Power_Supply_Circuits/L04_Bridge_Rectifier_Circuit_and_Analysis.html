2. Introduction to Bridge Rectifier

A bridge rectifier is a full-wave rectifier circuit that converts both positive and negative half-cycles of an AC input into a unidirectional pulsating DC output.

It uses four diodes connected in a bridge configuration. During each half-cycle, two diodes conduct while the remaining two diodes remain reverse-biased.

Important: A bridge rectifier does not require a centre-tapped transformer. This is one of its major advantages over a full-wave centre-tapped rectifier.

Basic Components

  • Four semiconductor diodes: D1, D2, D3 and D4.
  • AC input source or transformer secondary.
  • Load resistance (RL).
  • Optional filter capacitor for smoothing the output.

4. Working Principle of Bridge Rectifier

The bridge rectifier operates in two modes depending on the polarity of the AC input voltage.

4.1 Positive Half-Cycle

During the positive half-cycle, terminal A is positive with respect to terminal B.

  • Diodes D1 and D4 become forward-biased.
  • Diodes D2 and D3 become reverse-biased.
  • Current flows from terminal A through D1.
  • Current passes through the load resistance RL.
  • Current returns through D4 to terminal B.
Positive half-cycle: D1 and D4 conduct. Current flows through the load in the forward direction.

4.2 Negative Half-Cycle

During the negative half-cycle, terminal B becomes positive with respect to terminal A.

  • Diodes D2 and D3 become forward-biased.
  • Diodes D1 and D4 become reverse-biased.
  • Current flows from terminal B through D2.
  • Current passes through the load resistance RL.
  • Current returns through D3 to terminal A.
Negative half-cycle: D2 and D3 conduct. The current through the load still flows in the same direction.

4.3 Conduction Summary

AC Input Condition Conducting Diodes Non-Conducting Diodes Load Current
Positive half-cycle D1 and D4 D2 and D3 Same direction
Negative half-cycle D2 and D3 D1 and D4 Same direction

5. Input and Output Waveforms

5.1 AC Input Waveform

The input voltage is a sinusoidal AC waveform containing positive and negative half-cycles.

5.2 Rectified Output Waveform

Both half-cycles appear as positive pulses across the load. The output is therefore a full-wave pulsating DC waveform.

The output waveform is pulsating DC, not perfectly smooth DC. A filter capacitor can be added to reduce the ripple.

6. Mathematical Analysis of Bridge Rectifier

For an ideal bridge rectifier, assume the input voltage is:

v = Vm sin(ωt)

Here, Vm is the peak value of the AC input voltage. The output waveform is the absolute value of the input sinusoidal waveform.

6.1 Average DC Output Voltage

The average output voltage over one complete cycle is:

VDC = 2Vm / π

Approximately:

VDC = 0.637 Vm

6.2 RMS Output Voltage

VRMS = Vm / √2

Approximately:

VRMS = 0.707 Vm

6.3 Peak Inverse Voltage (PIV)

Peak Inverse Voltage is the maximum reverse voltage that a diode must withstand without entering breakdown.

PIV per diode = Vm
In an ideal bridge rectifier, the PIV rating required for each diode is equal to the peak AC input voltage.

6.4 Ripple Frequency

fr = 2f

The output ripple frequency is twice the AC supply frequency. For a 50 Hz supply, the ripple frequency is 100 Hz.

6.5 Practical Output Voltage

In a bridge rectifier, two diodes conduct in series during each half-cycle. Therefore, the approximate peak output voltage is:

Vout, peak ≈ Vm − 2VF

For silicon diodes, VF is commonly approximated as 0.7 V for basic calculations.

The ideal formulas above assume zero diode forward voltage drop. Practical average and RMS output values depend on diode characteristics, transformer impedance and load.

7. Numerical Example

A bridge rectifier is supplied with a sinusoidal AC voltage having a peak value of 20 V. Calculate the ideal average DC output voltage, RMS output voltage, PIV per diode and ripple frequency when the input frequency is 50 Hz.

Given Data

  • Peak input voltage, Vm = 20 V
  • Input frequency, f = 50 Hz

Step 1: Average DC Output Voltage

VDC = 0.637 × 20

VDC = 12.74 V

Step 2: RMS Output Voltage

VRMS = 20 / √2

VRMS ≈ 14.14 V

Step 3: PIV per Diode

PIV = Vm = 20 V

Step 4: Ripple Frequency

fr = 2 × 50 = 100 Hz
Final Answers:
  • Average DC output = 12.74 V
  • RMS output = 14.14 V
  • PIV per diode = 20 V
  • Ripple frequency = 100 Hz

8. Advantages of Bridge Rectifier

  • Uses both half-cycles of the AC input.
  • Does not require a centre-tapped transformer.
  • Provides higher rectification efficiency than a half-wave rectifier.
  • Has a lower PIV requirement per diode than a centre-tapped full-wave rectifier for the same peak output voltage.
  • Produces a ripple frequency twice the input frequency.
  • Can be implemented using four discrete diodes or a single bridge rectifier package.

9. Disadvantages of Bridge Rectifier

  • Requires four diodes.
  • Two diode forward voltage drops occur in the conducting path.
  • Power loss is higher than in a centre-tapped full-wave rectifier using one conducting diode at a time, for comparable diode characteristics.
  • Output is pulsating DC and requires filtering for smoother DC.

10. Bridge Rectifier vs Centre-Tapped Full-Wave Rectifier

Parameter Bridge Rectifier Centre-Tapped Rectifier
Number of diodes 4 2
Transformer Ordinary secondary winding Centre-tapped secondary winding
Diodes conducting per half-cycle 2 1
PIV per diode Vm 2Vm
Ripple frequency 2f 2f
Centre tap required No Yes
Placement Tip: Remember that two diodes conduct in a bridge rectifier during each half-cycle, while only one diode conducts in a centre-tapped full-wave rectifier.

11. Applications of Bridge Rectifier

  • DC power supply circuits.
  • Mobile phone and electronic device chargers.
  • Battery charging circuits.
  • Industrial control power supplies.
  • Embedded systems power supply units.
  • AC-to-DC conversion circuits.
  • Regulated power supply circuits.

12. Practical Troubleshooting

Problem Possible Cause Inspection
No DC output Open diode or disconnected AC input Check AC supply and all four diodes.
Low DC output Faulty diode or excessive loading Measure diode voltage drops and load current.
Excessive ripple Faulty or insufficient filter capacitor Inspect capacitor condition and capacitance.
Fuse blowing Shorted diode or output short circuit Test each diode and check the load.
Overheating Excessive current or inadequate rating Check load current and diode ratings.
Always disconnect the power supply before performing resistance or diode-mode measurements. Discharge filter capacitors safely before handling the circuit.
