Lesson 8: Class B and Class AB Power Amplifiers

Push-Pull Operation, Complementary Symmetry, Crossover Distortion and Efficiency

1. Introduction

Class B and Class AB amplifiers are widely used in audio power amplifier output stages because they offer better efficiency than Class A amplifiers.

A Class B amplifier uses an active device that conducts for approximately 180° of the input cycle. A Class AB amplifier is biased slightly above cutoff so that each output device conducts for more than 180° but less than 360°.

  • Class B: Each output transistor conducts for approximately one-half of the signal cycle.
  • Class AB: Each output transistor conducts for slightly more than one-half of the signal cycle.
  • Both commonly use push-pull output stages to reproduce the complete waveform.
  • Class AB reduces the crossover distortion associated with Class B.

2. Class B Amplifier Working Principle

In a basic complementary Class B push-pull stage, two complementary output transistors share the work of amplifying the input waveform.

  • The upper NPN transistor supplies current to the load during one half-cycle.
  • The lower PNP transistor conducts during the opposite half-cycle.
  • Each transistor ideally conducts for approximately 180°.
  • The combined output reproduces both halves of the input waveform.

Note: This is a functional concept diagram, not a complete transistor-level schematic. A real complementary emitter-follower output stage connects the NPN and PNP emitters to the common output node, with their collectors connected to the positive and negative supply rails respectively. Appropriate base-drive and bias networks are also required.

3. Complementary Symmetry Push-Pull Amplifier

A complementary symmetry amplifier uses an NPN transistor and a PNP transistor to amplify opposite halves of the input waveform.

Operation

  1. When the input becomes sufficiently positive, the NPN transistor conducts and supplies current to the load.
  2. When the input becomes sufficiently negative, the PNP transistor conducts and current flows in the opposite direction through the load.
  3. The two devices together reproduce the full output waveform.

Advantages

  • No centre-tapped input or output transformer is required in a conventional split-supply complementary emitter follower.
  • Better efficiency than Class A.
  • Suitable for audio power output stages.
  • Can drive relatively low-resistance loudspeaker loads when properly designed.

4. Crossover Distortion

Crossover distortion is a type of nonlinear distortion that occurs around the zero-crossing region of a Class B push-pull amplifier.

In a silicon transistor output stage, a base-emitter voltage of roughly 0.6–0.7 V is typically needed to begin significant conduction, depending on current and temperature. Around zero input, neither transistor may conduct sufficiently, creating a dead band in the output waveform.

The lower waveform is a simplified illustration of the dead band around zero. Actual distortion depends on transistor characteristics, bias and load.

Methods to reduce crossover distortion

  • Use Class AB biasing.
  • Apply suitable diode biasing or a VBE multiplier.
  • Use thermal compensation to stabilize bias current.
  • Apply negative feedback where appropriate.
  • Match complementary output devices and maintain correct quiescent current.

5. Class B Efficiency

For an ideal Class B push-pull amplifier delivering a sinusoidal output to a resistive load, the maximum theoretical efficiency is approximately 78.5%.

DC input power \[ P_{DC}=\frac{2V_{CC}I_m}{\pi} \] AC output power \[ P_{out}=\frac{V_m I_m}{2} \] Maximum efficiency \[ \eta_{max}=\frac{\pi}{4}\times100 \] \[ \boxed{\eta_{max}\approx78.5\%} \]

Here, \(V_m\) and \(I_m\) are the peak output voltage and current, and \(V_{CC}\) is the magnitude of each supply rail in an ideal split-supply circuit.

Example: Calculate output power

Given:

  • Output RMS voltage = 10 V
  • Load resistance = 8 Ω
\[ P_{out}=\frac{V_{rms}^{2}}{R_L} \] \[ P_{out}=\frac{10^2}{8} =\boxed{12.5W} \]

The load receives 12.5 W of AC power.

Example: Calculate theoretical DC input power and efficiency

Given: Ideal split supply of ±15 V, load resistance 8 Ω and output peak voltage 12 V.

\[ I_m=\frac{V_m}{R_L}=\frac{12}{8}=1.5A \] \[ P_{DC}=\frac{2(15)(1.5)}{\pi} \approx14.32W \] \[ P_{out}=\frac{12\times1.5}{2}=9W \] \[ \eta=\frac{9}{14.32}\times100 \approx\boxed{62.85\%} \]

This is an idealized calculation. Practical output stages have additional losses and voltage limitations.

6. Class AB Amplifier Working Principle

A Class AB amplifier combines the advantages of Class A and Class B operation. Its output transistors are biased slightly above cutoff so that both devices conduct for a short interval around the zero crossing.

  • Each transistor conducts for more than 180° but less than 360°.
  • A small quiescent current flows when there is no input signal.
  • The overlap in conduction reduces the crossover dead band.
  • Efficiency is generally lower than ideal Class B but higher than Class A.

Biasing methods

Two common methods for setting the output transistor bias are:

  • Diode biasing: Two suitably matched forward-biased diodes provide an approximate base-to-base bias voltage.
  • VBE multiplier: A transistor-based adjustable bias circuit establishes a controlled voltage between the output transistor bases.

Diode biasing is a simplified concept. A practical circuit requires correct diode orientation, suitable bias current, thermal coupling and an appropriate driver stage.

7. Class AB Efficiency

Class AB efficiency depends on the quiescent current, output power, supply voltage, load and circuit topology. It does not have one fixed maximum efficiency applicable to every implementation.

Because the output transistors conduct for more than 180°, the quiescent power consumption is greater than in an ideal Class B stage. However, the reduction in crossover distortion makes Class AB a widely used practical choice.

\[ \eta=\frac{P_{out}}{P_{DC}}\times100\% \]

For a split-supply output stage, DC input power should be calculated from the current drawn from both supply rails.

9. Applications

Class B

  • Push-pull audio output stages.
  • Efficiency-oriented power amplifier designs.
  • Signal amplification where crossover distortion can be tolerated or corrected.

Class AB

  • Home audio amplifiers.
  • Car audio power amplifiers.
  • Public address systems.
  • Operational amplifier output stages.
  • General-purpose linear power amplifier stages.

Output clippingInsufficient supply voltage or excessive inputObserve output waveform and supply rails.
Unequal positive and negative swingUnequal supply rails or mismatched devicesCheck rail voltages and transistor characteristics.

Practical testing procedure

  1. Check the supply rails before powering the amplifier.
  2. Inspect transistor orientation and output-stage wiring.
  3. Use a current-limited supply for initial testing.
  4. Measure the output DC offset with no load connected.
  5. Measure quiescent current using the manufacturer's recommended method.
  6. Apply a small sine-wave input and inspect the output waveform.
  7. Increase input gradually while monitoring clipping and temperature.
  8. Use a suitable dummy load rated for the expected power.
Safety: Power amplifiers can deliver high current. A short circuit at the output can damage transistors. Use a current-limited supply and a correctly rated dummy load. Never connect an oscilloscope ground clip to a point that is not at circuit ground.

11. Interview Questions and Answers

Q1. What is a Class B amplifier?

An amplifier in which each output device conducts for approximately 180° of the input cycle.

Q2. What is a push-pull amplifier?

An amplifier in which two devices operate on opposite halves of the signal to reproduce the complete output waveform.

Q3. What is crossover distortion?

Distortion near the zero crossing caused by the interval in which neither output transistor conducts sufficiently.

Q4. What is the maximum theoretical efficiency of Class B?

Approximately 78.5% for an ideal sinusoidal push-pull amplifier.

Q5. Why is Class AB preferred over Class B in many audio amplifiers?

Class AB biasing reduces crossover distortion while retaining relatively high efficiency.

Q6. What is the conduction angle of Class AB?

More than 180° but less than 360° for each output device.

Q7. What is the purpose of a VBE multiplier?

It provides an adjustable bias voltage to establish the required quiescent current in the output stage.

Q8. Why is thermal compensation necessary?

Because transistor base-emitter voltage and collector current vary with temperature. Poor compensation can cause excessive idle current and thermal runaway.

Q9. What is complementary symmetry?

It is the use of complementary NPN and PNP devices to amplify opposite halves of a signal.

Q10. Why should DC output offset be checked?

Excessive DC at the amplifier output can cause unwanted heating and damage to a loudspeaker or load.

13. Lesson Summary

  • Class B output devices conduct for approximately 180° each.
  • Push-pull operation combines the two half-cycles.
  • Class B has an ideal maximum efficiency of approximately 78.5%.
  • Crossover distortion occurs around the zero-crossing region.
  • Class AB uses a small bias current to reduce crossover distortion.
  • Thermal compensation is important for stable Class AB operation.
  • Class AB is widely used in practical audio power amplifiers.
