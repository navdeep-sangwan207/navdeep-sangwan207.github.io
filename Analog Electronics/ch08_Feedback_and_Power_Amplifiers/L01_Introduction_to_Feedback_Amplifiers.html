Lesson 1: Introduction to Feedback Amplifiers

Understand feedback principles, feedback loops, gain equations, block diagrams and practical applications in electronic circuits.

1. Introduction

A feedback amplifier is an electronic amplifier in which a portion of the output signal is returned to the input through a feedback network.

The returned signal is combined with the input signal. Depending on its phase and connection, feedback can increase or decrease the effective input signal.

Feedback is widely used in transistor amplifiers, operational amplifiers, audio amplifiers, voltage regulators and control systems.

Basic idea: A feedback amplifier uses a portion of its output to influence its own input and control its overall performance.

2. What is Feedback?

Feedback is the process of taking a fraction of the output signal and applying it back to the input of a system.

There are two basic types of feedback:

  • Positive feedback: Feedback signal supports or adds to the input signal.
  • Negative feedback: Feedback signal opposes or subtracts from the input signal.

The type of feedback depends on the phase relationship and how the feedback signal is combined with the input.

4. Important Components of a Feedback Amplifier

Component Meaning
Input signal (Vs) Original signal applied to the amplifier system.
Amplifier gain (A) Gain of the amplifier without feedback.
Output signal (Vo) Amplified output signal.
Feedback network Network that returns a portion of the output signal.
Feedback factor (β) Fraction of output signal returned to the input.
Feedback signal (Vf) Signal returned by the feedback network.
Error signal (Vi) Signal applied to the amplifier input after feedback combination.

5. Feedback Factor (β)

The feedback factor represents the fraction of the output signal that is returned to the input through the feedback network.

Feedback factor:

β = Vf / Vo

Therefore:

Vf = β × Vo

Where:

  • β = Feedback factor.
  • Vf = Feedback voltage.
  • Vo = Output voltage.

For example, if β = 0.1, then 10% of the output voltage is returned through the feedback network.

6. Gain of an Amplifier Without Feedback

The gain of an amplifier without feedback is called open-loop gain or basic amplifier gain in the feedback model.

Voltage gain:

A = Vo / Vi

Therefore:

Vo = A × Vi

Here, Vi is the actual error signal applied to the amplifier, not necessarily the original source voltage.

7. Closed-Loop Gain of a Feedback Amplifier

Closed-loop gain is the overall gain of an amplifier when the feedback network is connected.

For Negative Feedback

The error signal is:

Vi = Vs − Vf

Since:

Vf = βVo

Vo = AVi

Substituting:

Vo = A(Vs − βVo)

Vo = AVs − AβVo

Vo(1 + Aβ) = AVs

Closed-loop gain:

Af = Vo / Vs = A / (1 + Aβ)
The closed-loop gain of a negative-feedback amplifier is: Af = A / (1 + Aβ)

For Positive Feedback

In a positive-feedback system, the feedback signal adds to the input signal.

Vi = Vs + Vf

Closed-loop gain:

Af = A / (1 − Aβ)
The positive-feedback gain expression assumes a linear system with the indicated feedback polarity. As the loop gain approaches unity, the ideal expression becomes very large; real circuits are limited by saturation and may oscillate.

8. Loop Gain (Aβ)

Loop gain is the product of the amplifier gain and the feedback factor.

Loop Gain:

Loop Gain = Aβ

Loop gain determines how strongly the feedback network influences the amplifier's overall behavior.

  • A = Amplifier gain.
  • β = Feedback factor.
  • Aβ = Loop gain.

9. Numerical Example

Problem:

An amplifier has an open-loop voltage gain of 100. Its feedback factor is 0.05. Calculate its closed-loop gain when negative feedback is applied.

Given:

  • A = 100
  • β = 0.05

Formula:

Af = A / (1 + Aβ)

Step 1: Calculate loop gain.

Aβ = 100 × 0.05 = 5

Step 2: Calculate closed-loop gain.

Af = 100 / (1 + 5)

Af = 100 / 6

Af = 16.67
Answer: The closed-loop voltage gain is approximately 16.67.

10. Advantages of Feedback Amplifiers

  • Can improve gain stability.
  • Can reduce nonlinear distortion with negative feedback.
  • Can reduce the effect of internal noise generated within the amplifier.
  • Can increase bandwidth in many voltage-amplifier designs.
  • Can control input and output impedance.
  • Can improve predictable circuit performance.

11. Applications of Feedback Amplifiers

Application Purpose of Feedback
Audio amplifiers Improve gain accuracy and reduce distortion.
Voltage regulators Maintain a stable output voltage.
Operational amplifier circuits Set a predictable closed-loop gain.
Sensor signal conditioning Control amplification and improve accuracy.
Communication systems Control gain and frequency response.
Control systems Correct deviations from a desired output.

12. Important Interview Questions

Q1. What is a feedback amplifier?

A feedback amplifier is an amplifier in which a portion of the output signal is returned to the input through a feedback network.

Q2. What are the two types of feedback?

Positive feedback and negative feedback.

Q3. What is feedback factor?

It is the ratio of feedback signal to output signal: β = Vf / Vo.

Q4. What is loop gain?

Loop gain is the product of amplifier gain and feedback factor, represented by Aβ.

Q5. What is closed-loop gain?

It is the overall gain of an amplifier with its feedback network connected.

Q6. Write the closed-loop gain equation for negative feedback.

Af = A / (1 + Aβ).

Q7. Why is negative feedback used in amplifiers?

It can improve gain stability, reduce distortion and noise, increase bandwidth and control input/output impedance.

Q8. What is the difference between open-loop and closed-loop gain?

Open-loop gain is measured without feedback. Closed-loop gain is the overall gain with feedback connected.

14. Lesson Summary

  • Feedback returns a portion of the output signal to the input.
  • Positive feedback supports the input signal; negative feedback opposes it.
  • Amplifier gain without feedback is represented by A.
  • Feedback factor is represented by β.
  • Loop gain is represented by Aβ.
  • Negative-feedback closed-loop gain is A/(1 + Aβ).
  • Positive-feedback closed-loop gain is A/(1 − Aβ).
  • Negative feedback is widely used to improve amplifier performance.
