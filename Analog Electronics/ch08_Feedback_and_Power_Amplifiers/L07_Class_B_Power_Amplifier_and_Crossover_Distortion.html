2. Introduction to Class B Amplifiers

A Class B power amplifier is biased so that each output transistor conducts for approximately one-half of the input signal cycle.

Conduction angle per transistor = 180°

In a push-pull output stage, one device handles the positive half-cycle and the other handles the negative half-cycle.

Unlike Class A, a Class B output stage ideally draws no quiescent output-device current when the input signal is zero. This improves efficiency, but introduces a potential distortion problem around the zero-crossing point.

3. Complementary Push-Pull Class B Stage

A complementary push-pull stage uses an NPN transistor and a PNP transistor connected so that their emitter outputs drive the same load.

Working principle

  1. During the positive half-cycle, the NPN transistor supplies current to the load.
  2. During the negative half-cycle, the PNP transistor conducts and provides the opposite current direction.
  3. The load receives both halves of the signal.
  4. Ideally, each device conducts for 180° and the combined output reproduces the complete waveform.

5. Crossover Distortion

Crossover distortion occurs near the zero-crossing point when the input signal changes polarity and neither transistor conducts sufficiently.

For a silicon BJT, a base-emitter voltage of approximately 0.6–0.7 V is typically needed before significant conduction begins. In a simple Class B complementary stage, the input must cross the relevant base-emitter threshold before the opposite transistor turns on.

Important: Crossover distortion is a nonlinear distortion around the zero crossing. It is particularly noticeable at low signal levels.

6. Methods to Reduce Crossover Distortion

  • Use Class AB biasing to keep both output devices slightly conducting at idle.
  • Use a properly designed diode bias network or VBE multiplier.
  • Use emitter resistors to improve current sharing and thermal stability.
  • Use thermal compensation so bias voltage tracks transistor temperature.
  • Use negative feedback to reduce residual distortion, while ensuring loop stability.
  • Match complementary devices where appropriate.

Class AB operation is discussed in the next lecture.

7. Class B Efficiency Derivation

For an ideal sinusoidal push-pull Class B amplifier with a resistive load:

Pout = VmIm / 2

where Vm is the peak load voltage and Im is the peak load current.

For a symmetrical supply ±VCC, the average current drawn from each supply is:

IDC = Im / π

Total DC input power is:

PDC = 2VCCIm / π

Therefore:

η = Pout/PDC = (π/4)(Vm/VCC)

At the ideal maximum output swing, Vm approaches VCC:

ηmax = π/4 × 100 ≈ 78.5%

The 78.5% result assumes ideal devices, a sinusoidal output and an ideal symmetrical supply. Real output stages have voltage drops, quiescent and driver losses, and thermal limitations.

10. Transistor Power Dissipation

In a Class B push-pull stage, each output transistor conducts for approximately half the cycle. Its instantaneous power dissipation is:

p(t) = vCE(t) × iC(t)

Average transistor dissipation depends on the output amplitude and load. Maximum transistor dissipation does not necessarily occur at maximum output power.

For an ideal complementary Class B stage with a sinusoidal output, total average transistor dissipation is:

PD,total = (2VCCIm/π) − (VmIm/2)

For a symmetrical output stage, each transistor dissipates approximately half of this total over a complete cycle.

11. Worked Numerical Problems

Problem 1: Output Power

A Class B amplifier produces a peak output voltage of 8 V across an 8 Ω load. Calculate output power.

Vrms = Vm/√2 = 8/1.414 = 5.657 V

Pout = Vrms²/RL = 32/8 = 4 W

Problem 2: Peak Load Current

For the same circuit:

Im = Vm/RL = 8/8 = 1 A

Problem 3: DC Input Power

For an ideal symmetrical Class B stage with ±12 V supplies and Im = 1 A:

PDC = 2VCCIm/π

= 24/3.1416 = 7.64 W

Problem 4: Efficiency

η = Pout/PDC × 100

= 4/7.64 × 100 = 52.36%

This operating point is below the ideal maximum because the output peak is 8 V while the supply magnitude is 12 V.

13. Practical Lab: Observe Crossover Distortion

Objective

Observe the output waveform of a complementary Class B amplifier and identify crossover distortion.

Equipment

  • Low-voltage complementary transistor amplifier trainer or simulator.
  • Function generator.
  • Oscilloscope or waveform simulation.
  • Suitable resistive load.
  • Current-limited DC supply.

Procedure

  1. Configure a complementary Class B output stage in a simulator.
  2. Apply a low-amplitude sine-wave input.
  3. Observe the output around the zero-crossing point.
  4. Increase the input amplitude and note the relative visibility of the distortion.
  5. Adjust the bias toward Class AB operation in the simulator.
  6. Compare the waveform before and after bias adjustment.
  7. Record output power and distortion observations.

Expected result

A simple Class B stage may show a notch or flattening near zero crossing. Slight forward bias in Class AB operation reduces this dead zone.

Do not connect an experimental power amplifier directly to mains or an unknown speaker load. Use a low-voltage current-limited setup and verify transistor pinouts before powering the circuit.

17. Summary

  • Each Class B output transistor conducts for approximately 180°.
  • Push-pull operation combines the two half-cycles at the load.
  • The ideal maximum efficiency is approximately 78.5%.
  • Crossover distortion occurs around the zero crossing due to the devices' turn-on requirements.
  • Class AB biasing, thermal compensation and negative feedback can reduce distortion.
  • Thermal and safe-operating-area checks remain essential in practical power amplifiers.
