2. Class AB Power Amplifier

A Class AB power amplifier is biased so that each output transistor conducts for slightly more than 180° but less than 360° of the signal cycle.

Conduction angle: greater than 180° and less than 360° per output device.

Both devices conduct slightly around the zero-crossing region. This reduces the dead zone associated with a simple Class B stage.

Why Class AB is required

  • Class B offers high theoretical efficiency but may suffer from crossover distortion.
  • Class A avoids this type of crossover notch but consumes substantial quiescent power.
  • Class AB provides a practical compromise between linearity and efficiency.

3. Class AB Complementary Push-Pull Stage

A complementary output stage uses an NPN transistor for the positive half-cycle and a PNP transistor for the negative half-cycle. A small bias voltage is applied between their bases to establish a controlled idle current.

Biasing principle

For two silicon output BJTs, the base-to-base bias voltage is often around 1.2–1.4 V, depending on device current, temperature and circuit design. The actual voltage must be selected and adjusted for the desired quiescent current.

VBB ≈ VBE(NPN) + |VBE(PNP)|

A diode string or VBE multiplier can provide this bias. Thermal coupling to the output transistors helps compensate for changes in VBE with temperature.

5. Class AB Bias Network and Thermal Stability

The bias network sets a small base-to-base voltage that keeps the output pair slightly on at idle.

Diode bias network

  • Two forward-biased silicon diodes can provide approximately two base-emitter drops.
  • The diodes should be thermally coupled to the output devices where appropriate.
  • Emitter resistors help stabilize current and improve current sharing.
  • Incorrect bias can cause crossover distortion or excessive idle current.

VBE multiplier

A transistor-based bias spreader provides an adjustable base-to-base voltage.

Vbias ≈ VBE(1 + R1/R2)

This is an approximate relationship for a common VBE multiplier arrangement; exact resistor labeling and loading must be checked against the circuit schematic.

Too much bias can cause thermal runaway and damage the output transistors. Always measure idle current and follow the manufacturer's adjustment procedure.

6. Class C Power Amplifier

A Class C power amplifier is biased well below cutoff. The transistor conducts for less than 180° of the input signal cycle and produces short current pulses.

Conduction angle: less than 180°.

Class C operation is highly nonlinear at the transistor output. A tuned LC circuit is used to select the desired frequency and reconstruct an approximately sinusoidal output.

Class C circuit concept

How Class C works

  1. The transistor is biased below cutoff.
  2. It conducts only during a short part of each RF cycle.
  3. Short current pulses excite the resonant LC circuit.
  4. The tank circuit stores and exchanges energy between its inductor and capacitor.
  5. The resonant network produces a near-sinusoidal output at its resonant frequency.

7. Resonant Frequency of a Tuned LC Circuit

The resonant frequency of an ideal parallel or series LC network is:

f0 = 1 / (2π√LC)

Where:

  • L = inductance in henries (H)
  • C = capacitance in farads (F)
  • f0 = resonant frequency in hertz (Hz)

10. Worked Numerical Problems

Problem 1: LC Resonant Frequency

An LC tank has L = 10 µH and C = 100 pF. Calculate resonant frequency.

f0 = 1 / (2π√LC)

f0 ≈ 1 / (2π√(10 × 10−6 × 100 × 10−12))

f0 ≈ 5.03 MHz

Problem 2: Class AB Output Power

A Class AB amplifier produces 10 V RMS across an 8 Ω load.

Pout = Vrms²/RL = 100/8 = 12.5 W

Problem 3: Class AB Efficiency

If DC input power is 20 W:

η = 12.5/20 × 100 = 62.5%

This is an illustrative operating-point calculation, not a universal Class AB efficiency limit.

Problem 4: Class C Conduction Angle

A transistor conducts for 120° of each RF cycle. Since 120° is less than 180°, the stage operates in Class C.

11. Practical Design Considerations

Class AB

  • Set idle current according to the output-device and circuit specifications.
  • Ensure thermal tracking between the bias network and output devices.
  • Use emitter resistors and appropriate current limiting.
  • Verify stability, compensation and high-frequency oscillation behavior.
  • Check transistor SOA, supply voltage and heat-sink requirements.

Class C

  • Design the LC tank for the required operating frequency.
  • Account for loaded Q and output coupling.
  • Match the load impedance to the amplifier.
  • Use suitable RF transistors with adequate frequency and power ratings.
  • Check harmonic content, device dissipation and tank current.
  • Provide shielding and suitable RF measurement practices.

12. Practical Lab: Class AB Bias and Class C Resonance

Objective

Study crossover reduction in a Class AB stage and calculate the resonant frequency of a Class C tuned network.

Equipment

  • Low-voltage complementary amplifier simulator or trainer.
  • Function generator and oscilloscope.
  • LC components or circuit simulator.
  • Multimeter and current-limited supply.

Procedure

  1. Simulate a complementary Class B output stage and observe zero-crossing distortion.
  2. Introduce a suitable Class AB bias network in the simulator.
  3. Observe how the crossover notch changes.
  4. Measure the idle current and check that it remains within the design target.
  5. Build or simulate an LC resonant network.
  6. Change L or C and observe the resonant frequency shift.
  7. Compare the calculated resonant frequency with the simulation result.

Expected result

Proper Class AB bias reduces crossover distortion. Increasing L or C reduces the ideal LC resonant frequency.

Class C circuits may operate at radio frequencies and can generate significant RF voltage. Use a simulator or a low-power, shielded RF trainer. Do not connect experimental circuits to mains.

16. Summary

  • Class AB conduction angle is greater than 180° and less than 360°.
  • A small idle current reduces crossover distortion.
  • Diode networks and VBE multipliers can establish the required bias.
  • Thermal compensation is essential for stable Class AB operation.
  • Class C conduction angle is less than 180°.
  • Class C uses a tuned LC network to reconstruct the desired RF output.
  • LC resonant frequency is determined by inductance and capacitance.
