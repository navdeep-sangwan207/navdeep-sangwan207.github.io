Lesson 9: Class C and Class D Power Amplifiers

RF Tuned Amplifiers, Switching Operation, PWM and Output Filtering

1. Introduction

Class C and Class D amplifiers are designed for applications where efficiency is especially important.

  • Class C: The active device conducts for less than 180° of the input cycle. It is commonly used with a tuned resonant circuit in RF applications.
  • Class D: The output devices operate primarily as electronic switches, rather than as linear amplifiers. The output switching waveform is filtered to recover the required signal.

Class C is associated mainly with tuned RF amplification, whereas Class D is widely used in efficient audio and power-conversion applications.

2. Class C Power Amplifier

2.1 Operating principle

In a Class C amplifier, the transistor is biased well below cutoff. It conducts only when the input signal rises sufficiently to drive it into conduction.

  • Conduction angle is less than 180°.
  • The transistor conducts in short current pulses.
  • The collector current waveform is highly non-sinusoidal.
  • A tuned LC circuit selects the desired frequency component and produces a nearly sinusoidal output.
  • It is generally unsuitable for direct amplification of ordinary audio waveforms because of severe distortion without a suitable resonant output network.

The current pulses occur for only a small portion of each input cycle. The exact pulse width depends on bias and drive level.

2.2 Tuned Class C amplifier

A tuned Class C amplifier uses an LC resonant network at its output. The resonant circuit stores and exchanges energy between its inductor and capacitor, selecting the desired fundamental frequency.

\[ f_r=\frac{1}{2\pi\sqrt{LC}} \]

Where:

  • \(f_r\): Resonant frequency in hertz
  • \(L\): Inductance in henries
  • \(C\): Capacitance in farads

Concept: The transistor supplies current pulses to a resonant output network. A practical RF amplifier also needs a correctly designed bias network, DC feed or RF choke, matching network and suitable output load. The drawing is a functional illustration, not a complete construction schematic.

2.3 Applications

  • RF power amplifiers.
  • Radio transmitters.
  • RF oscillators and tuned stages.
  • Selected narrowband communication systems.

3. Class D Power Amplifier

3.1 Operating principle

A Class D amplifier is a switching amplifier. Its output transistors are operated mainly in two states:

  • ON state: The transistor acts like a closed switch with a small voltage drop.
  • OFF state: The transistor blocks current and ideally has negligible current flow.

Because voltage and current are not simultaneously large in an ideal switch, the output devices can dissipate much less power than a linear amplifier.

3.3 Pulse Width Modulation (PWM)

Many Class D amplifiers use pulse width modulation. The input signal controls the width of a high-frequency switching waveform.

  • Wider pulses represent a higher average output level.
  • Narrower pulses represent a lower average output level.
  • The switching frequency is generally much higher than the highest signal frequency being reproduced.
  • The output filter removes much of the switching-frequency component.

The pulse widths vary with the modulating signal. This illustration is conceptual and not to scale.

3.4 Output LC filter

The switching stage produces a high-frequency pulse waveform. An LC low-pass filter attenuates the switching component while allowing the desired audio-frequency signal to reach the load.

\[ f_c=\frac{1}{2\pi\sqrt{LC}} \]

This is the ideal resonant-frequency relationship for an LC network. The actual filter response and cutoff depend on topology, load impedance, damping and component values.

4. Class D Switching Losses

Although Class D amplifiers can be highly efficient, they are not lossless.

Loss typeCause
Conduction lossFinite ON-state resistance of MOSFETs or voltage drop in other switches.
Switching lossVoltage and current overlap during transitions between ON and OFF states.
Gate-drive lossEnergy required to charge and discharge MOSFET gate capacitances.
Filter lossResistance in inductors, capacitors and interconnections.
Control lossPower consumed by the modulator, driver and control circuitry.
\[ \eta=\frac{P_{out}}{P_{in}}\times100\% \]

Practical efficiency depends on output power, switching frequency, supply voltage, device selection and circuit design.

Example: Calculate Class D efficiency

Given:

  • DC input power = 30 W
  • AC output power = 27 W
\[ \eta=\frac{27}{30}\times100 \] \[ \boxed{\eta=90\%} \]

Answer: The amplifier efficiency is 90%.

Power loss is \(30-27=3W\).

Important design precautions

  • Use suitable MOSFET voltage and current ratings.
  • Provide adequate dead time in half-bridge and full-bridge switching stages to prevent shoot-through.
  • Use proper gate drivers.
  • Design the output filter for the intended load.
  • Keep switching-current paths short and minimize parasitic inductance.
  • Use suitable decoupling capacitors near the power stage.
  • Check electromagnetic interference (EMI) and thermal performance.
Important: Never connect an oscilloscope ground clip directly to a floating half-bridge switching node. Use an appropriately rated differential probe or isolated measurement method.

9. Interview Questions and Answers

Q1. What is a Class C amplifier?

An amplifier in which the active device conducts for less than 180° of the input cycle.

Q2. Why is a tuned circuit used in Class C?

It selects the desired frequency component from the transistor's current pulses and produces a nearly sinusoidal output.

Q3. What is the resonant frequency of an LC circuit?

\(f_r=1/(2\pi\sqrt{LC})\).

Q4. Why is Class C unsuitable for ordinary audio amplification?

Its output current is highly discontinuous and requires a tuned network; without suitable frequency-selective reconstruction it produces severe distortion.

Q5. What is a Class D amplifier?

A switching amplifier in which output devices operate mainly as electronic switches.

Q6. What is PWM?

Pulse Width Modulation is a technique in which pulse width is varied according to the input signal.

Q7. Why is an LC filter used in Class D?

To attenuate high-frequency switching components and recover the desired output signal.

Q8. What is shoot-through?

It occurs when the upper and lower switches of a bridge leg conduct simultaneously, creating a direct current path across the supply.

Q9. What is dead time?

A short interval between turning one switch off and the complementary switch on, used to reduce shoot-through risk.

Q10. Why is Class D suitable for portable devices?

Its high efficiency reduces power loss and heat generation, helping extend battery life and reduce cooling requirements.

11. Lesson Summary

  • Class C conducts for less than 180° of the input cycle.
  • Class C is commonly used in tuned RF power amplifiers.
  • An LC resonant network selects the desired frequency component.
  • Class D operates its output devices as switches.
  • PWM controls the switching waveform according to the input signal.
  • An output filter attenuates switching-frequency components.
  • Dead time helps prevent shoot-through in bridge switching stages.
  • Class D is widely used where high efficiency and compact size are important.
