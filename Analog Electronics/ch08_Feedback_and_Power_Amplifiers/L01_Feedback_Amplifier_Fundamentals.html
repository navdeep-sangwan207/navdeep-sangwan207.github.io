2. What Is Feedback?

Feedback is the process of returning a portion of an amplifier's output signal to its input.

The returned signal is combined with the original input signal. Depending on its phase and polarity, feedback can either increase or decrease the effective input signal.

Basic terms

  • Input signal (X): Original signal applied to the feedback system.
  • Amplifier gain (A): Gain of the forward amplifier.
  • Output signal (Y): Amplified output.
  • Feedback factor (β): Fraction of output returned to the input.
  • Feedback signal (βY): Signal returned by the feedback network.
The block diagram shows the feedback path. Whether the feedback is positive or negative depends on the way the returned signal is combined at the summing junction.

3. Open-Loop Amplifier

An open-loop amplifier operates without a feedback path from its output to its input.

Characteristics

  • No output-to-input feedback path.
  • Gain is determined by the amplifier's open-loop characteristics.
  • Gain may be sensitive to component variations, temperature and device parameters.
  • Distortion and bandwidth depend on the amplifier design.

4. Closed-Loop Amplifier

A closed-loop amplifier uses a feedback network to return a portion of the output to the input.

For negative feedback, the feedback signal is subtracted from the original input signal.

Negative-feedback relationship

Error signal = Input signal − Feedback signal

Xe = X − βY

The amplifier output is:

Y = A Xe

5. Derivation of Closed-Loop Gain

For a negative-feedback amplifier:

1. Error signal:

Xe = X − βY

2. Amplifier output:

Y = A Xe

3. Substitute the error signal:

Y = A(X − βY)

4. Expand:

Y = AX − AβY

5. Rearrange:

Y(1 + Aβ) = AX

6. Divide by input X:

Af = Y/X = A/(1 + Aβ)

Closed-loop gain for negative feedback:

Af = A / (1 + Aβ)

For positive feedback, the corresponding ideal linear relationship is:

Af = A / (1 − Aβ)

This expression assumes a linear feedback model and is not valid as a stable finite-gain description when the system approaches regenerative instability.

7. Worked Numerical Problem 1

Question: An amplifier has an open-loop gain of 100. A feedback network has a feedback factor of 0.1. Calculate the closed-loop gain for negative feedback.

Given:

  • A = 100
  • β = 0.1

Formula:

Af = A/(1+Aβ)

Substitution:

Af = 100/(1+100×0.1)

Af = 100/11

Af = 9.09

The amplifier's gain is reduced from 100 to approximately 9.09 by negative feedback.

8. Worked Numerical Problem 2

Question: An amplifier has a closed-loop gain of 20 and an open-loop gain of 200. Find the feedback factor.

Af = A/(1+Aβ)

20 = 200/(1+200β)

1+200β = 10

200β = 9

β = 0.045

11. Why Is Feedback Used?

Negative feedback is widely used in amplifier design because it can improve several important performance characteristics.

  • Stabilizes the closed-loop gain.
  • Can reduce nonlinear distortion.
  • Can increase usable bandwidth.
  • Can improve control of input and output impedance, depending on topology.
  • Can reduce sensitivity to component variations.
  • Can improve linearity over a suitable operating range.
Negative feedback does not automatically improve every parameter in every circuit. Its effects depend on the feedback topology, loop gain, frequency response and stability margins.

13. Practical Lab: Feedback Gain Verification

Objective

Verify the effect of negative feedback on the gain of a low-voltage amplifier or an amplifier simulation.

Equipment

  • Low-voltage amplifier circuit or circuit simulator.
  • Resistors for the feedback network.
  • Function generator or simulated AC source.
  • Oscilloscope or simulated waveform viewer.
  • DC supply appropriate to the amplifier.

Procedure

  1. Build or simulate an amplifier with a known forward gain.
  2. Measure the output with the feedback path disconnected, if the circuit permits safe open-loop operation.
  3. Connect the negative-feedback network.
  4. Apply a small input signal within the linear operating range.
  5. Measure input and output amplitudes.
  6. Calculate the closed-loop gain.
  7. Compare the measured gain with A/(1+Aβ).
  8. Observe the output waveform for clipping or oscillation.

Expected result

With negative feedback, the closed-loop gain is lower than the open-loop gain for positive A and β, while gain stability and linearity can improve when the loop is properly designed.

Do not connect an amplifier output directly to its input without a designed feedback network. Incorrect feedback connections can cause saturation or oscillation.

17. Summary

  • Feedback returns a portion of the output to the input.
  • Open-loop amplifiers have no output feedback path.
  • Closed-loop amplifiers use a feedback network.
  • Feedback factor is the ratio of feedback signal to output signal.
  • Loop gain is Aβ.
  • Negative-feedback gain is A/(1+Aβ).
  • Positive feedback can cause regeneration and oscillation.
  • Feedback is important in amplifier design and control systems.
