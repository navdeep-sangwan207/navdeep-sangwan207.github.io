Lesson 6: Introduction to Power Amplifiers

Understand power amplification, output stages, load matching, conduction angle, amplifier classes and practical applications.

1. Introduction to Power Amplifiers

A power amplifier is an electronic circuit designed to deliver sufficient power to a load such as a loudspeaker, motor, antenna or another output device.

Unlike a small-signal amplifier, which mainly increases signal voltage or current for further processing, a power amplifier is designed to deliver useful output power while managing efficiency, heat dissipation and load requirements.

Applications

  • Audio amplifier systems and loudspeakers.
  • Radio-frequency transmitters.
  • Industrial control and actuator circuits.
  • Motor-drive and power-control stages.
  • Communication and broadcasting equipment.
  • Electronic instrumentation.

2. Difference Between Voltage Amplifier and Power Amplifier

Parameter Voltage Amplifier Power Amplifier
Main purpose Increase signal voltage. Deliver useful power to a load.
Output power Generally low. Designed for higher output power.
Load Usually a high-impedance next stage. May drive a loudspeaker, antenna or other load.
Current capability Often relatively low. Designed for the required load current.
Heat dissipation Usually lower. Important design consideration.
Efficiency May not be the primary design objective. Important design parameter.

3. Basic Power Amplifier Block Diagram

A typical amplifier system uses multiple stages. Small-signal stages provide voltage gain, driver stages provide the required drive capability, and the output stage delivers power to the load.

Simplified multistage amplifier arrangement.

Functions of Each Stage

  • Input stage: Receives the small input signal.
  • Voltage amplifier: Increases signal voltage.
  • Driver stage: Supplies the drive required by the output stage.
  • Power stage: Delivers the required output power to the load.

4. Important Power Amplifier Parameters

A. Output Power

Output power is the average electrical power delivered to the load.

Pout = Vout(rms) × Iout(rms)

For a resistive load:
Pout = Vout(rms)² / RL

Also:
Pout = Iout(rms)² × RL

B. Input Power

Input power is the DC power drawn from the power supply. For a single supply:

PDC = VCC × IDC

For a dual supply, calculate the power drawn from both supply rails and add the contributions.

C. Power Dissipation

Power not delivered to the load is dissipated in the amplifier components, mainly as heat.

PD = PDC − Pout

D. Power Gain

Ap = Pout / Pin

Power gain in dB:
Ap(dB) = 10 log10(Pout / Pin)

5. Amplifier Efficiency

Efficiency indicates how effectively an amplifier converts DC supply power into useful AC output power.

η = (AC Output Power / DC Input Power) × 100%

η = (Pout / PDC) × 100%

A higher efficiency means a greater proportion of the supply power is delivered to the load rather than being dissipated inside the amplifier.

6. Conduction Angle

Conduction angle is the portion of one complete input signal cycle during which an active device conducts. It is measured in electrical degrees.

The conduction angle is used to classify power amplifier operating classes.

Amplifier Class Conduction Angle Operating Principle
Class A 360° Device conducts throughout the complete cycle.
Class B 180° Each device conducts for half a cycle in a typical push-pull stage.
Class AB Greater than 180° and less than 360° Each device conducts for slightly more than half a cycle.
Class C Less than 180° Device conducts for less than half a cycle.
Class D Switching operation Output devices operate mainly in ON and OFF states.
Class D is a switching amplifier class. Its operation is not classified using the same sinusoidal conduction-angle definition used for Classes A, B, AB and C.

7. Classification of Power Amplifiers

A. Class A Power Amplifier

In a Class A amplifier, the active device conducts during the entire 360° input cycle.

  • Low signal distortion when properly biased.
  • Simple operating principle.
  • High quiescent current.
  • Low efficiency compared with switching classes.
  • Used in some audio and small-signal output stages.

B. Class B Power Amplifier

In a typical Class B push-pull amplifier, one output device conducts during the positive half-cycle and the other conducts during the negative half-cycle.

  • Each device conducts for approximately 180°.
  • Higher theoretical efficiency than Class A.
  • Can suffer from crossover distortion.
  • Commonly implemented using a push-pull output stage.

C. Class AB Power Amplifier

Class AB operation uses a small bias current so that each output device conducts for slightly more than 180°.

  • Reduces crossover distortion compared with Class B.
  • Offers a compromise between efficiency and linearity.
  • Widely used in audio power amplifiers.

D. Class C Power Amplifier

A Class C amplifier conducts for less than 180° of the input cycle. A tuned resonant circuit helps reconstruct the desired sinusoidal output.

  • High theoretical efficiency.
  • High distortion without a suitable tuned output network.
  • Commonly used in RF applications.

E. Class D Power Amplifier

A Class D amplifier uses switching devices that operate mainly in ON and OFF states. Pulse-width modulation or another switching method controls the output waveform.

  • High efficiency.
  • Lower transistor conduction losses when properly designed.
  • Requires switching control and output filtering where appropriate.
  • Used in modern audio systems and compact power electronics.

9. Output Stage Configurations

A. Single-Ended Output Stage

A single-ended output stage uses one main active device to amplify the complete signal cycle. A Class A amplifier is a common example.

B. Push-Pull Output Stage

A push-pull stage uses two active devices to handle complementary portions of the signal waveform.

  • One device handles the positive half-cycle.
  • The other handles the negative half-cycle.
  • Both contributions combine to reproduce the output signal.
  • Commonly used in Class B and Class AB amplifiers.

Simplified functional representation of a push-pull output stage.

10. Load Impedance and Power Matching

A power amplifier must be designed to drive its intended load. The load impedance affects output current, voltage, power, efficiency and device stress.

For a resistive load:

P = V(rms)² / RL

I(rms) = V(rms) / RL

Lower load resistance requires more current for the same output voltage. This can increase power dissipation and stress on the output devices.

Maximum power transfer and efficient amplifier design are different concepts. A transistor output stage is not automatically designed by simply matching its output resistance to the load. Practical matching depends on the amplifier topology and load requirements.

11. Heat Dissipation and Thermal Management

Power devices dissipate heat because of conduction losses, switching losses and other internal losses.

Excessive junction temperature can reduce reliability, change operating characteristics or permanently damage the device.

Important Thermal Parameters

  • Power dissipation: Electrical power converted into heat.
  • Junction temperature: Temperature of the semiconductor junction.
  • Thermal resistance: Temperature rise per unit of dissipated power.
  • Heat sink: A component used to transfer heat to the surroundings.
Tj = Ta + P × RθJA

Where:
  • Tj = Junction temperature
  • Ta = Ambient temperature
  • P = Device power dissipation
  • RθJA = Junction-to-ambient thermal resistance

For a device mounted using a separate heat sink, a more detailed thermal calculation uses junction-to-case, interface and heat-sink-to-ambient thermal resistances.

12. Numerical Example: Output Power

A power amplifier delivers 10 V RMS across an 8 Ω resistive loudspeaker. Calculate output power and load current.

Given:

  • Vout = 10 V RMS
  • RL = 8 Ω

Step 1: Calculate Output Power

Pout = Vout² / RL

Pout = 10² / 8

Pout = 100 / 8

Pout = 12.5 W

Step 2: Calculate Load Current

Iout = Vout / RL

Iout = 10 / 8

Iout = 1.25 A RMS
Answer: Output power = 12.5 W and load current = 1.25 A RMS.

13. Numerical Example: Amplifier Efficiency

An amplifier draws 50 W from its DC supply and delivers 35 W to the load. Calculate its efficiency.

Given:

  • DC input power = 50 W
  • AC output power = 35 W
η = (Pout / PDC) × 100%

η = (35 / 50) × 100%

η = 70%

Calculate Power Dissipation

PD = PDC − Pout

PD = 50 − 35

PD = 15 W

14. Practical Power Amplifier Troubleshooting

Fault Possible Cause Checking Method
No output Missing supply, faulty driver or damaged output device Check supply rails and signal path.
Low output power Insufficient supply voltage, incorrect load or weak drive Measure output voltage and load current.
Distorted output Clipping, crossover distortion or incorrect bias Observe waveform on oscilloscope.
Overheating Excessive current, poor heat sinking or instability Measure current and check thermal design.
DC at output Bias fault or damaged output transistor Measure DC output offset.
Unwanted oscillation Feedback or layout problem Inspect output using a suitable oscilloscope setup.

Basic Testing Procedure

  1. Check the power supply voltage and polarity.
  2. Inspect the output devices and heat-sink mounting.
  3. Measure the amplifier's DC output offset before connecting a speaker.
  4. Use a suitable dummy load for controlled testing.
  5. Apply a low-level test signal.
  6. Observe the output waveform using an oscilloscope.
  7. Measure RMS output voltage and calculate delivered power.
  8. Monitor device temperature during testing.
Use a load rated for the expected power and observe the amplifier's minimum load impedance. Never connect or disconnect a high-power load while the amplifier is operating unless the equipment is designed for it.

15. Important Interview Questions

Q1. What is a power amplifier?

A power amplifier is a circuit designed to deliver useful electrical power to a load.

Q2. What is the main difference between a voltage amplifier and a power amplifier?

A voltage amplifier mainly increases signal voltage, while a power amplifier is designed to supply the required output power to a load.

Q3. Define amplifier efficiency.

Efficiency is the ratio of AC output power to DC input power, expressed as a percentage.

Q4. What is conduction angle?

It is the portion of one input signal cycle during which an active device conducts.

Q5. What is the conduction angle of Class A?

360°.

Q6. What is the conduction angle of Class B?

Approximately 180° for each device in a typical push-pull output stage.

Q7. Why is Class AB preferred in many audio amplifiers?

It provides a practical compromise between efficiency and linearity while reducing crossover distortion compared with Class B.

Q8. What is a push-pull amplifier?

It uses two active devices to amplify complementary portions of a signal waveform.

Q9. Why is a heat sink required?

It helps transfer heat away from power devices and keeps junction temperature within safe limits.

Q10. Which amplifier class is commonly used for RF power amplification?

Class C is commonly used in suitable tuned RF power amplifier applications.

17. Lesson Summary

  • A power amplifier delivers useful electrical power to a load.
  • Output power depends on load voltage, current and impedance.
  • Efficiency measures the conversion of DC input power into AC output power.
  • Conduction angle is used to classify linear power amplifier classes.
  • Class A conducts for 360°.
  • Class B conducts for approximately 180° per device.
  • Class AB conducts for more than 180° but less than 360° per device.
  • Class C conducts for less than 180°.
  • Class D uses switching operation.
  • Push-pull stages are commonly used in Class B and Class AB amplifiers.
  • Heat sinking and thermal design are essential for reliable power operation.
