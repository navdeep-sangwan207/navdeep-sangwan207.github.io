Lesson 3: Voltage and Current Feedback Topologies

Understand the four basic feedback topologies, their sampling and mixing methods, input/output impedance and practical uses.

1. Introduction

Feedback topology describes how the output signal is sampled and how the feedback signal is combined with the input signal.

In amplifier circuits, two important operations take place:

  • Output sampling: The feedback network senses either output voltage or output current.
  • Input mixing: The feedback signal is combined with the input in either series or parallel form.

Combining these two operations gives four basic negative-feedback topologies.

2. Two Methods of Output Sampling

A. Voltage Sampling (Shunt Sampling)

In voltage sampling, the feedback network is connected across the output terminals. It senses the output voltage.

  • The output voltage is sampled in parallel.
  • The feedback network ideally senses voltage without significantly loading the output.
  • Used in voltage amplifiers.

B. Current Sampling (Series Sampling)

In current sampling, the feedback network is connected in series with the load path so that it senses output current.

  • The feedback network senses load current.
  • A current-sensing element may be used.
  • Used in current amplifiers.

3. Two Methods of Input Mixing

A. Series Mixing

In series mixing, the feedback signal is connected in series with the input source. The feedback voltage is subtracted from the source voltage in a negative-feedback amplifier.

  • Input signals combine as voltages.
  • Input resistance generally increases.
  • Commonly used where high input impedance is desirable.

B. Shunt Mixing

In shunt mixing, the feedback signal is combined with the input signal at a common node. The signals combine as currents.

  • Input currents combine at a common node.
  • Input resistance generally decreases.
  • Used where lower input impedance is required.

5. Voltage-Series Feedback (Series-Shunt)

Voltage-series feedback is also known as series-shunt feedback. It samples the output voltage and mixes the feedback signal in series with the input voltage.

Conceptual voltage-series feedback arrangement.

Characteristics

  • Output voltage is sampled.
  • Feedback voltage is mixed in series with the input.
  • Input resistance increases.
  • Output resistance decreases.
  • Suitable for voltage amplifiers.
Voltage-series feedback is commonly used in voltage amplifiers because it produces high input impedance and low output impedance.

6. Voltage-Shunt Feedback (Shunt-Shunt)

Voltage-shunt feedback samples output voltage and returns a feedback current to the input node in parallel with the source.

Conceptual voltage-shunt feedback arrangement.

Characteristics

  • Output voltage is sampled.
  • Feedback is mixed in parallel with the input.
  • Input resistance decreases.
  • Output resistance decreases.
  • Suitable for transresistance amplifiers.

A transresistance amplifier converts an input current into an output voltage.

Transresistance gain:

Rm = Vo / Ii

Unit: Ohm (Ω)

7. Current-Series Feedback (Series-Series)

Current-series feedback samples output current and mixes the feedback voltage in series with the input signal.

Conceptual current-series feedback arrangement.

Characteristics

  • Output current is sampled.
  • Feedback voltage is mixed in series with the input.
  • Input resistance increases.
  • Output resistance increases.
  • Suitable for transconductance amplifiers.
Transconductance gain:

Gm = Io / Vi

Unit: Siemens (S)

8. Current-Shunt Feedback (Shunt-Series)

Current-shunt feedback samples output current and mixes the feedback current in parallel with the input.

Conceptual current-shunt feedback arrangement.

Characteristics

  • Output current is sampled.
  • Feedback current is mixed in parallel with the input.
  • Input resistance decreases.
  • Output resistance increases.
  • Suitable for current amplifiers.
Current gain:

Ai = Io / Ii

Unit: Dimensionless

9. Effect of Feedback Topology on Impedance

For the standard negative-feedback model, series mixing increases input resistance, while shunt mixing decreases input resistance. Voltage sampling decreases output resistance, while current sampling increases output resistance.

Feedback Topology Input Resistance Output Resistance
Voltage-Series Increases Decreases
Voltage-Shunt Decreases Decreases
Current-Series Increases Increases
Current-Shunt Decreases Increases
These are the standard ideal feedback-topology trends. Actual impedance changes depend on circuit configuration, loading, feedback factor and operating frequency.

11. Numerical Example

A voltage-series feedback amplifier has an input resistance of 10 kΩ and an output resistance of 20 kΩ without feedback. Its loop gain is 9. Calculate the input and output resistances with feedback.

Given:

  • Ri = 10 kΩ
  • Ro = 20 kΩ
  • Aβ = 9

For voltage-series feedback:

Input resistance with feedback:

Rif = Ri(1 + Aβ)

Rif = 10 × (1 + 9)

Rif = 100 kΩ
Output resistance with feedback:

Rof = Ro / (1 + Aβ)

Rof = 20 / 10

Rof = 2 kΩ
Answer: Input resistance increases from 10 kΩ to 100 kΩ, while output resistance decreases from 20 kΩ to 2 kΩ.

12. Practical Applications

Topology Typical Application
Voltage-Series Voltage amplifiers and audio amplifier stages.
Voltage-Shunt Transimpedance amplifiers, such as photodiode current-to-voltage converters.
Current-Series Voltage-controlled current sources.
Current-Shunt Current amplifiers and current-sensing systems.

13. Important Interview Questions

Q1. What is feedback topology?

It describes how the output is sampled and how the feedback signal is mixed with the input.

Q2. How many basic feedback topologies are there?

Four: voltage-series, voltage-shunt, current-series and current-shunt.

Q3. Which topology is used for voltage amplification?

Voltage-series feedback.

Q4. Which topology is used for transresistance amplification?

Voltage-shunt feedback.

Q5. Which topology is used for transconductance amplification?

Current-series feedback.

Q6. What happens to input resistance with series mixing?

Input resistance increases.

Q7. What happens to output resistance with voltage sampling?

Output resistance decreases.

Q8. Which topology is suitable for a photodiode amplifier?

Voltage-shunt feedback is commonly used in a transimpedance amplifier to convert photodiode current into output voltage.

15. Lesson Summary

  • Feedback topology depends on output sampling and input mixing.
  • Output sampling can be voltage or current sampling.
  • Input mixing can be series or shunt mixing.
  • Voltage-series feedback is used for voltage amplifiers.
  • Voltage-shunt feedback is used for transresistance amplifiers.
  • Current-series feedback is used for transconductance amplifiers.
  • Current-shunt feedback is used for current amplifiers.
  • Series mixing increases input resistance.
  • Shunt mixing decreases input resistance.
  • Voltage sampling decreases output resistance.
  • Current sampling increases output resistance.
