2. What Is a Feedback Topology?

A feedback topology describes two independent operations:

  1. Output sampling: The feedback network senses either output voltage or output current.
  2. Input mixing: The feedback signal is combined with the input in either series or shunt form.

Combining these choices gives four basic negative-feedback topologies.

Important: Series and shunt describe how signals are mixed at the input. Voltage and current describe what is sampled at the output.

3. Output Sampling: Voltage vs Current

A. Voltage sampling

The feedback network is connected across the output. It senses output voltage.

  • Feedback network is connected in parallel with the output terminals.
  • Output voltage is sensed.
  • Commonly used in voltage amplifiers and voltage regulators.

B. Current sampling

The feedback network senses output current. It is effectively placed in series with the output current path.

  • A current-sensing element is placed in series with the load path.
  • The feedback signal is proportional to output current.
  • Used in current sources, current regulators and transconductance amplifiers.
The diagrams are conceptual. A practical current-sensing resistor or current mirror must be designed for the required current, power dissipation and common-mode voltage.

4. Input Mixing: Series vs Shunt

A. Series mixing

The feedback voltage is connected in series with the input source. The error voltage is the difference between the source and feedback voltages.

Ve = Vs − Vf

  • Input signals are mixed as voltages.
  • Input resistance generally increases with series mixing under negative feedback.

B. Shunt mixing

The feedback current is combined with the source current at a common input node.

Ie = Is − If

  • Input signals are mixed as currents.
  • Input resistance generally decreases with shunt mixing under negative feedback.

5. Four Basic Feedback Topologies

Output sampling and input mixing can be combined in four ways.

A. Voltage-series feedback

  • Samples output voltage.
  • Uses series mixing at input.
  • Input resistance increases.
  • Output resistance decreases.
  • Suitable for voltage amplifiers.

B. Voltage-shunt feedback

  • Samples output voltage.
  • Uses shunt mixing at input.
  • Input resistance decreases.
  • Output resistance decreases.
  • Suitable for transresistance amplifiers.

C. Current-series feedback

  • Samples output current.
  • Uses series mixing at input.
  • Input resistance increases.
  • Output resistance increases.
  • Suitable for transconductance amplifiers.

D. Current-shunt feedback

  • Samples output current.
  • Uses shunt mixing at input.
  • Input resistance decreases.
  • Output resistance increases.
  • Suitable for current amplifiers.

6. Input and Output Resistance Effects

For a properly designed negative-feedback system, the idealized impedance trends are:

Feedback topologyInput resistanceOutput resistance
Voltage-seriesIncreasesDecreases
Voltage-shuntDecreasesDecreases
Current-seriesIncreasesIncreases
Current-shuntDecreasesIncreases
Memory aid:
  • Series mixing increases input resistance.
  • Shunt mixing decreases input resistance.
  • Voltage sampling decreases output resistance.
  • Current sampling increases output resistance.

For a simple idealized model, let T be the positive loop-gain magnitude. Then:

Series mixing: Ri,f ≈ Ri(1+T)

Shunt mixing: Ri,f ≈ Ri/(1+T)

Voltage sampling: Ro,f ≈ Ro/(1+T)

Current sampling: Ro,f ≈ Ro(1+T)

These are idealized low-frequency relationships. Actual impedance depends on the feedback network, loading, amplifier model and frequency. The topology must be identified correctly before applying them.

9. Worked Numerical Problem 1 – Voltage-Series Feedback

Question: An amplifier has input resistance 10 kΩ, output resistance 20 kΩ and loop gain T = 9. Calculate the approximate feedback input and output resistances for voltage-series feedback.

Voltage-series feedback uses series mixing and voltage sampling.

Input resistance:

Ri,f = Ri(1+T)

Ri,f = 10 × (1+9) = 100 kΩ

Output resistance:

Ro,f = Ro/(1+T)

Ro,f = 20/10 = 2 kΩ

10. Worked Numerical Problem 2 – Current-Series Feedback

Question: An amplifier has Ri = 5 kΩ, Ro = 10 kΩ and loop gain T = 4. Find the approximate input and output resistances for current-series feedback.

Current-series feedback uses series mixing and current sampling.

Input resistance:

Ri,f = Ri(1+T) = 5 × 5 = 25 kΩ

Output resistance:

Ro,f = Ro(1+T) = 10 × 5 = 50 kΩ

14. Practical Lab: Feedback Topology Identification

Objective

Identify the output sampling and input mixing methods in four feedback amplifier circuits.

Equipment

  • Low-voltage amplifier circuit or circuit simulator.
  • Resistors and feedback network components.
  • Function generator or simulated signal source.
  • Multimeter and oscilloscope or simulation instruments.

Procedure

  1. Inspect the output connection of the feedback network.
  2. Determine whether the network senses output voltage or output current.
  3. Inspect the input connection.
  4. Determine whether the feedback signal is mixed in series or shunt.
  5. Classify the circuit using the four-topology table.
  6. Estimate the expected input and output impedance changes.
  7. Compare the prediction with the simulation or measured result.

Expected result

You should be able to identify the feedback topology from the circuit connections and predict the idealized impedance trends.

Use low-voltage circuits and current-limited supplies. Do not short an amplifier output to measure current. Use an appropriate series sensing element.

18. Summary

  • Feedback topology is determined by output sampling and input mixing.
  • Voltage sampling senses output voltage.
  • Current sampling senses output current.
  • Series mixing generally increases input resistance.
  • Shunt mixing generally decreases input resistance.
  • Voltage sampling generally decreases output resistance.
  • Current sampling generally increases output resistance.
  • The four combinations are voltage-series, voltage-shunt, current-series and current-shunt.
