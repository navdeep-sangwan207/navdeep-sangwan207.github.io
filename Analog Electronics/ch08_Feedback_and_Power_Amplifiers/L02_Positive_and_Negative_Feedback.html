Lesson 2: Positive and Negative Feedback

Understand feedback polarity, working principles, closed-loop gain equations, performance changes and practical applications.

1. Introduction

Feedback is classified into two main types depending on the phase relationship between the input signal and the returned feedback signal:

  • Positive feedback: The feedback signal reinforces the input signal.
  • Negative feedback: The feedback signal opposes the input signal.

Both types are important in electronic systems, but they are used for different purposes.

2. Positive Feedback

Positive feedback occurs when the feedback signal is in phase with the input signal and is added to it.

This increases the effective input signal and can increase the overall gain of the system.

Input signal relationship:

Vi = Vs + Vf

Closed-loop gain:

Af = A / (1 − Aβ)

Working Principle

  1. An input signal is applied to the amplifier.
  2. The amplifier produces an output signal.
  3. A portion of the output is returned through the feedback network.
  4. The feedback signal adds to the original input signal.
  5. The effective input increases, producing a stronger output in the linear model.

Conceptual positive-feedback block diagram. Both summing inputs are positive.

Advantages of Positive Feedback

  • Can produce sustained oscillations.
  • Useful in oscillator circuits.
  • Used in Schmitt triggers for hysteresis.
  • Can increase effective gain under suitable conditions.

Disadvantages of Positive Feedback

  • Can make an amplifier unstable.
  • May cause unwanted oscillations.
  • Can drive an amplifier into saturation.
  • Can increase sensitivity to noise and disturbances.

Applications of Positive Feedback

  • RC and LC oscillators.
  • Schmitt trigger circuits.
  • Regenerative circuits.
  • Hysteresis-based switching circuits.

3. Negative Feedback

Negative feedback occurs when the feedback signal opposes the input signal.

It reduces the effective input signal and generally reduces amplifier gain, but improves several important performance characteristics.

Input signal relationship:

Vi = Vs − Vf

Closed-loop gain:

Af = A / (1 + Aβ)

Working Principle

  1. An input signal is applied to the amplifier.
  2. The amplifier produces an output signal.
  3. A fraction of the output is returned through the feedback network.
  4. The feedback signal opposes the original input signal.
  5. The effective input is reduced, controlling the overall output.

Conceptual negative-feedback block diagram. The feedback signal is applied to the subtracting input.

Advantages of Negative Feedback

  • Improves gain stability.
  • Reduces nonlinear distortion.
  • Can reduce internally generated noise.
  • Can increase bandwidth.
  • Can improve linearity.
  • Controls input and output impedance according to the feedback topology.

Disadvantages of Negative Feedback

  • Reduces the overall gain.
  • Requires additional feedback components.
  • Can cause instability if the feedback loop has insufficient phase margin.
  • May introduce unwanted oscillations if poorly designed.

Applications of Negative Feedback

  • Audio amplifiers.
  • Operational amplifier circuits.
  • Voltage regulators.
  • Signal conditioning circuits.
  • Power amplifier stages.

4. Comparison Between Positive and Negative Feedback

Parameter Positive Feedback Negative Feedback
Feedback phase Reinforces the input Opposes the input
Input relationship Vi = Vs + Vf Vi = Vs − Vf
Closed-loop gain A/(1 − Aβ) A/(1 + Aβ)
Gain Can increase Generally decreases
Stability Can reduce stability Can improve stability when properly designed
Distortion May increase nonlinear behavior Generally reduces nonlinear distortion

5. Gain Equations

Negative Feedback Gain

Af = A / (1 + Aβ)

Positive Feedback Gain

Af = A / (1 − Aβ)

Where:

  • Af = Closed-loop gain.
  • A = Open-loop amplifier gain.
  • β = Feedback factor.
  • Aβ = Loop gain.

6. Numerical Example – Negative Feedback

An amplifier has an open-loop gain of 200 and a feedback factor of 0.04. Calculate the closed-loop gain with negative feedback.

Given:

  • A = 200
  • β = 0.04

Formula:

Af = A / (1 + Aβ)

Step 1: Calculate loop gain.

Aβ = 200 × 0.04 = 8

Step 2: Calculate closed-loop gain.

Af = 200 / (1 + 8)

Af = 200 / 9

Af = 22.22
Answer: The closed-loop gain is approximately 22.22.

7. Numerical Example – Positive Feedback

An amplifier has an open-loop gain of 50 and a feedback factor of 0.01. Calculate its ideal closed-loop gain with positive feedback.

Given:

  • A = 50
  • β = 0.01

Formula:

Af = A / (1 − Aβ)

Step 1: Calculate loop gain.

Aβ = 50 × 0.01 = 0.5

Step 2: Calculate closed-loop gain.

Af = 50 / (1 − 0.5)

Af = 50 / 0.5

Af = 100
Answer: The ideal linear closed-loop gain is 100.

8. Practical Importance of Feedback

Consider an audio amplifier. Without suitable negative feedback, its gain may change due to transistor temperature, component variations and supply fluctuations.

With negative feedback, the circuit can maintain a more predictable gain and reduce distortion within its designed operating range.

Positive feedback, on the other hand, is useful when a circuit needs regenerative action, such as an oscillator or a Schmitt trigger.

9. Important Interview Questions

Q1. What is positive feedback?

Positive feedback occurs when the feedback signal reinforces the input signal.

Q2. What is negative feedback?

Negative feedback occurs when the feedback signal opposes the input signal.

Q3. Which feedback is commonly used in linear amplifiers?

Negative feedback is commonly used because it improves gain stability and reduces distortion.

Q4. Which feedback is used in oscillators?

Positive feedback is used to sustain oscillations when the required loop-gain and phase conditions are satisfied.

Q5. Does negative feedback increase or decrease gain?

It generally decreases the amplifier's closed-loop gain.

Q6. What happens when positive feedback becomes too strong?

The amplifier may become unstable, oscillate or reach saturation.

Q7. What is the main advantage of negative feedback?

It improves gain stability and can reduce distortion while improving bandwidth and other performance parameters.

11. Lesson Summary

  • Positive feedback reinforces the input signal.
  • Negative feedback opposes the input signal.
  • Positive feedback can increase gain and is used in oscillators.
  • Negative feedback generally reduces gain but improves stability and linearity.
  • Negative-feedback gain is A/(1 + Aβ).
  • Positive-feedback gain is A/(1 − Aβ).
  • Feedback polarity and loop phase determine system behavior.
  • Feedback networks are widely used in amplifiers and control circuits.
