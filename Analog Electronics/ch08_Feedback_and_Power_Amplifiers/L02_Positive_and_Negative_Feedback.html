2. What Is Feedback Polarity?

Feedback polarity describes how the returned signal combines with the original input signal at the summing junction.

  • Negative feedback: Returned signal opposes the input signal.
  • Positive feedback: Returned signal reinforces the input signal.

3. Negative Feedback

Negative feedback occurs when the feedback signal is subtracted from the input signal.

Error signal: Xe = X − βY

Closed-loop gain: Af = A/(1 + Aβ)

Characteristics

  • Reduces the overall gain for positive A and β.
  • Improves gain stability when loop gain is sufficiently high.
  • Can reduce nonlinear distortion.
  • Can increase bandwidth in suitable amplifier designs.
  • Can reduce sensitivity to component variations.
  • Can improve input or output impedance depending on feedback topology.
Negative feedback is called degenerative feedback because the returned signal opposes the original input.

4. Positive Feedback

Positive feedback occurs when the feedback signal is added to the input signal.

Error signal: Xe = X + βY

Closed-loop gain: Af = A/(1 − Aβ)

Characteristics

  • Reinforces the input signal.
  • Can increase effective gain.
  • Can produce regenerative behavior.
  • Can cause instability when loop conditions are appropriate.
  • Can sustain oscillations in oscillator circuits.
  • Can produce switching hysteresis in Schmitt trigger circuits.
Positive feedback is also called regenerative feedback.

5. Mathematical Derivation

A. Negative feedback

Start with:

Xe = X − βY

Y = A Xe

Substitute:

Y = A(X − βY)

Y = AX − AβY

Y(1 + Aβ) = AX

Af = Y/X = A/(1 + Aβ)

B. Positive feedback

Start with:

Xe = X + βY

Y = A Xe

Substitute:

Y = A(X + βY)

Y = AX + AβY

Y(1 − Aβ) = AX

Af = Y/X = A/(1 − Aβ)

The positive-feedback equation is a linear closed-loop expression. As the denominator approaches zero, the ideal gain becomes unbounded. Real circuits are limited by saturation, nonlinearities and dynamic stability.

7. Worked Numerical Problem 1 – Negative Feedback

Question: An amplifier has an open-loop gain of 200 and a feedback factor of 0.05. Calculate the closed-loop gain.

Given: A = 200, β = 0.05

Af = A/(1+Aβ)

Af = 200/(1+200×0.05)

Af = 200/11

Answer: Af = 18.18

8. Worked Numerical Problem 2 – Positive Feedback

Question: An amplifier has A = 50 and β = 0.01. Calculate its ideal positive-feedback gain.

Af = A/(1−Aβ)

Af = 50/(1−50×0.01)

Af = 50/0.5

Answer: Af = 100

The ideal gain doubles in this example, provided the assumed linear model remains applicable.

9. Regenerative Feedback and Oscillation

Positive feedback can sustain oscillations when the loop meets the required magnitude and phase conditions.

Barkhausen criterion

For an ideal sinusoidal oscillator at its oscillation frequency:

|Aβ| = 1

Total loop phase shift = 0° or 360° × n

In practical oscillator startup, loop gain is generally greater than unity initially. Nonlinear amplitude control eventually reduces the effective loop gain toward unity for steady oscillation.

Oscillator examples

  • RC phase-shift oscillator.
  • Wien bridge oscillator.
  • Hartley oscillator.
  • Colpitts oscillator.
  • Crystal oscillator circuits.

10. Positive Feedback in Schmitt Trigger

A Schmitt trigger uses positive feedback to create two different switching thresholds.

  • Upper threshold voltage (UTP).
  • Lower threshold voltage (LTP).
  • Hysteresis voltage = UTP − LTP.

Hysteresis improves noise immunity by preventing repeated switching when an input signal is near a single threshold.

The two thresholds provide hysteresis. The exact threshold values depend on the circuit topology, resistor ratios and supply voltages.

14. Practical Lab: Feedback Polarity

Objective

Observe the difference between positive and negative feedback using a low-voltage amplifier simulation.

Procedure

  1. Open a suitable amplifier simulation.
  2. Identify the amplifier input and output.
  3. Connect a feedback network with subtractive polarity.
  4. Apply a small input signal and observe the output.
  5. Record the closed-loop gain.
  6. Change the feedback polarity in the simulation.
  7. Observe whether the output becomes regenerative or unstable.
  8. Relate the results to the gain equations.

Expected observations

  • Negative feedback reduces closed-loop gain.
  • Positive feedback can increase gain and lead to regeneration.
  • Actual circuit behavior depends on frequency response, phase shift and nonlinear limits.
Do not experimentally connect positive feedback to an unknown amplifier without checking the circuit. It may drive the output into saturation or produce oscillation.

18. Summary

  • Negative feedback opposes the original input.
  • Positive feedback reinforces the original input.
  • Negative-feedback gain is A/(1+Aβ).
  • Positive-feedback gain is A/(1−Aβ) under the linear model.
  • Negative feedback is widely used in linear amplifiers.
  • Positive feedback is used in oscillators and Schmitt triggers.
  • Oscillation requires suitable loop magnitude and phase conditions.
  • Practical stability depends on frequency response and nonlinear behavior.
