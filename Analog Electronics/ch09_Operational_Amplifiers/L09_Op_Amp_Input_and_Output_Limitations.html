2. Introduction

An operational amplifier can perform mathematical operations such as addition, subtraction, integration and differentiation.

An integrator produces an output proportional to the time integral of its input signal, whereas a differentiator produces an output proportional to the rate of change of its input signal.

Integrator: Performs mathematical integration.

Differentiator: Performs mathematical differentiation.

3. Op-Amp Integrator

An Op-Amp integrator is an inverting amplifier circuit in which a capacitor is connected in the feedback path instead of a resistor.

The input signal is applied to the inverting terminal through a resistor R. The non-inverting terminal is connected to ground.

Ideal Op-Amp Integrator Circuit

Figure: Ideal inverting integrator.

4. Working Principle of Integrator

When an input voltage is applied, current flows through the input resistor R toward the inverting input node.

For an ideal Op-Amp operating with negative feedback:

  • The inverting input is approximately at virtual ground.
  • The Op-Amp input current is approximately zero.
  • The current through R flows through the feedback capacitor C.
  • The capacitor charges or discharges according to the input signal.
  • The output voltage changes with time.

5. Derivation of Integrator Output Equation

Input current through resistor R:

i = Vin/R

The current through a capacitor is:

i = C × dVC/dt

Since the inverting input is approximately at zero potential, the capacitor voltage is:

VC = 0 - Vout = -Vout

Therefore:

Vin/R = -C × dVout/dt

dVout/dt = -Vin/(RC)

Integrating both sides:

Ideal Integrator Equation:

Vout(t) = -1/(RC) ∫ Vin(t) dt + Vout(0)

Here, Vout(0) represents the initial output voltage determined by the initial charge on the feedback capacitor.

6. Integrator Response to Different Input Signals

A. DC Input

When a constant positive DC voltage is applied, the integrator output decreases linearly with time.

Vin = VDC

Vout = -(VDC/RC)t + Vout(0)

For a negative DC input, the output increases linearly. In a real circuit, the output eventually reaches a supply limit if the input remains constant.

B. Square-Wave Input

A square-wave input produces a triangular-wave output because the integrator generates a linear ramp during each constant-voltage portion of the input.

Square-Wave Input and Triangular Output

Figure: Conceptual integrator waveforms.

C. Sine-Wave Input

When a sinusoidal signal is applied, the output is a cosine-shaped waveform with inversion.

Vin = Vm sin(ωt)

Vout = -(1/RC) ∫ Vm sin(ωt) dt

Vout = (Vm/ωRC) cos(ωt)

7. Numerical Example 1: Integrator Output

Given:

  • Input voltage = 2 V
  • R = 100 kΩ
  • C = 10 µF
  • Initial output voltage = 0 V
  • Time = 1 second

Solution:

RC = 100000 × 10 × 10⁻⁶

RC = 1 second

Vout = -(1/RC) × Vin × t

Vout = -(1/1) × 2 × 1

Vout = -2 V

8. Practical Op-Amp Integrator

An ideal integrator has a capacitor in the feedback path. At DC, the capacitor behaves like an open circuit. Consequently, the ideal circuit has extremely high low-frequency gain and may saturate due to small input offset voltage and bias current.

A practical integrator connects a resistor Rf in parallel with the feedback capacitor C.

Practical Integrator Configuration

Figure: Practical integrator with Rf parallel to C.

The feedback resistor limits the DC gain and provides a DC feedback path.

Feedback impedance:

Zf = Rf / (1 + jωRfC)

Transfer function:

Vout/Vin = -Rf/[R(1 + jωRfC)]

At frequencies sufficiently above the lower break frequency, the circuit behaves approximately as an integrator.

Lower break frequency:

fL = 1/(2πRfC)

9. Op-Amp Differentiator

An Op-Amp differentiator is an inverting amplifier circuit in which a capacitor is connected at the input and a resistor is connected in the feedback path.

The output voltage is proportional to the rate of change of the input voltage.

Ideal Op-Amp Differentiator Circuit

Figure: Ideal inverting differentiator.

10. Working Principle of Differentiator

When the input voltage changes, current flows through the input capacitor.

The capacitor current depends on the rate of change of its voltage. Since the ideal Op-Amp input current is approximately zero, this current flows through the feedback resistor.

  • The capacitor responds to changes in input voltage.
  • The feedback resistor converts current into output voltage.
  • A faster input change produces a larger output magnitude.
  • A constant DC input ideally produces zero output after the transient.

11. Derivation of Differentiator Output Equation

Current through the input capacitor:

i = C × dVin/dt

The inverting input is approximately at virtual ground. Current through the feedback resistor is:

i = (0 - Vout)/Rf

i = -Vout/Rf

Equating the currents:

C × dVin/dt = -Vout/Rf
Ideal Differentiator Equation:

Vout = -RfC × dVin/dt

12. Differentiator Response to Different Input Signals

A. DC Input

For a constant DC input, the rate of change is zero. Therefore, the ideal differentiator output is zero after the input transition.

Vin = Constant

dVin/dt = 0

Vout = 0

B. Ramp Input

A ramp input has a constant slope. Therefore, its differentiated output is a constant voltage during the ramp.

Vin = kt

dVin/dt = k

Vout = -RfCk

C. Square-Wave Input

An ideal square wave contains sudden transitions. Its derivative consists of narrow positive and negative impulses at the transitions.

In a practical circuit, these appear as positive and negative pulses with finite amplitude and duration.

Square-Wave Input and Differentiated Output

Figure: Conceptual differentiator waveforms.

D. Sine-Wave Input

A sinusoidal input produces a cosine-related output with inversion.

Vin = Vm sin(ωt)

dVin/dt = ωVm cos(ωt)

Vout = -ωRfCVm cos(ωt)

13. Numerical Example 2: Differentiator Output

Given:

  • Rf = 100 kΩ
  • C = 0.01 µF
  • Input ramp slope = 2 V/ms

Step 1: Convert the slope.

dVin/dt = 2/0.001

dVin/dt = 2000 V/s

Step 2: Calculate RfC.

RfC = 100000 × 0.01 × 10⁻⁶

RfC = 0.001 s

Step 3: Calculate output.

Vout = -RfC × dVin/dt

Vout = -0.001 × 2000

Vout = -2 V

14. Practical Op-Amp Differentiator

An ideal differentiator has a capacitor directly at its input and a feedback resistor. Its gain increases with frequency, making it sensitive to high-frequency noise.

A practical differentiator uses:

  • A resistor in series with the input capacitor.
  • A capacitor in parallel with the feedback resistor.

Practical Differentiator Configuration

Figure: Practical differentiator.

The input resistor limits high-frequency input current, while the feedback capacitor reduces excessive high-frequency gain.

Input impedance:

Zin = R1 + 1/(jωC1)

Feedback impedance:

Zf = Rf/(1 + jωRfCf)

Transfer function:

Vout/Vin = -jωC1Rf / [(1 + jωR1C1)(1 + jωRfCf)]

The circuit behaves approximately as a differentiator over its intended operating frequency range.

15. Integrator vs Differentiator

Parameter Integrator Differentiator
Function Integration Differentiation
Input component Resistor Capacitor
Feedback component Capacitor Resistor
Output equation Vout = -(1/RC)∫Vin dt Vout = -RfC(dVin/dt)
Square-wave response Triangular waveform Alternating pulses
High-frequency behavior Gain decreases ideally Gain increases ideally
Typical application Ramp generation and signal processing Edge detection and transient detection

16. Applications of Integrators

  • Analog computers.
  • Ramp and triangular waveform generators.
  • Active low-pass filtering.
  • Signal processing.
  • Control-system integral action.
  • Measurement of accumulated signals.

17. Applications of Differentiators

  • Edge detection circuits.
  • Transient detection.
  • Wave-shaping circuits.
  • Active high-pass filtering.
  • Control-system derivative action.
  • Detection of rapid changes in sensor signals.

18. Embedded Systems and Control Applications

Integrators and differentiators are useful in analog signal conditioning and control systems.

Integrator in a Control System

An integrator accumulates an error signal over time. This is the integral action used in a PI or PID controller.

Integral action:

I(t) = Ki ∫ e(t) dt

Differentiator in a Control System

A differentiator responds to how quickly the error signal changes. This is the derivative action in a PID controller.

Derivative action:

D(t) = Kd × de(t)/dt
In digital embedded systems, integration and differentiation are commonly implemented in software using sampled sensor values. Analog Op-Amp circuits may still be used for front-end signal conditioning.

19. Practical Limitations and Troubleshooting

Problem Possible Cause Corrective Action
Integrator output saturated Input offset, bias current or excessive DC input. Use a practical integrator with feedback resistor and check input offset.
Integrator output drifting Capacitor leakage or offset voltage. Check capacitor quality and offset compensation.
Differentiator noisy output Excessive high-frequency gain. Use a practical differentiator with suitable limiting components.
Output clipping Output exceeds available voltage swing. Reduce input amplitude or gain and verify supply rails.
Unexpected waveform Incorrect component connection or unsuitable frequency range. Verify the circuit and component values.

20. Interview Questions and Answers

Q1. What is an Op-Amp integrator?

A circuit that produces an output proportional to the time integral of its input voltage.

Q2. Which component is used in the feedback path of an ideal integrator?

A capacitor.

Q3. Write the ideal integrator equation.

Vout = -(1/RC)∫Vin dt, with the initial output condition included when required.

Q4. What is the output of an integrator for a square-wave input?

A triangular waveform for an ideal symmetric square-wave input.

Q5. Why is a resistor connected parallel to the feedback capacitor in a practical integrator?

To provide a DC feedback path and limit low-frequency gain, reducing saturation and drift.

Q6. What is an Op-Amp differentiator?

A circuit that produces an output proportional to the rate of change of its input voltage.

Q7. Which component is connected at the input of an ideal differentiator?

A capacitor.

Q8. Write the ideal differentiator equation.

Vout = -RfC(dVin/dt).

Q9. Why is an ideal differentiator sensitive to noise?

Its gain increases with frequency, so high-frequency noise can be amplified significantly.

Q10. How does a practical differentiator reduce noise?

It uses an input series resistor and a feedback capacitor to limit the operating bandwidth.

22. Lesson Summary

  • An Op-Amp integrator performs mathematical integration.
  • The ideal integrator has an input resistor and feedback capacitor.
  • Its output is proportional to the negative time integral of the input.
  • A square-wave input produces a triangular output.
  • A practical integrator uses a resistor parallel to the feedback capacitor to limit DC gain.
  • An Op-Amp differentiator performs mathematical differentiation.
  • The ideal differentiator has an input capacitor and feedback resistor.
  • Its output is proportional to the negative derivative of the input.
  • A practical differentiator limits high-frequency gain and noise.
  • Both circuits are useful in analog signal processing and control systems.
