2. What Is an Operational Amplifier?

An operational amplifier (op-amp) is a high-gain, direct-coupled differential voltage amplifier. It amplifies the voltage difference between two input terminals and produces an output voltage.

It has two input terminals:

  • Non-inverting input (+): A positive change at this input tends to increase the output voltage.
  • Inverting input (−): A positive change at this input tends to decrease the output voltage.

The output is controlled by the differential input voltage:

Vout = AOL × (V+ − V−)

Here, AOL is the open-loop differential voltage gain.

Important: This equation describes the open-loop relationship. In practical circuits, the output cannot exceed the available supply-related output limits.

3. Op-Amp Circuit Symbol

The triangular symbol represents the amplifier. The two left-side connections are the differential inputs, while the right-side connection is the output.

The supply connections are often omitted from simplified circuit diagrams, but an actual op-amp IC requires appropriate power connections.

5. Internal Functional Block Diagram

A general-purpose op-amp contains several functional stages. The exact transistor-level circuit depends on the IC design.

Functional stages

1. Differential input stage

Amplifies the difference between the two input signals and provides high input impedance.

2. Intermediate gain stage

Provides a large portion of the voltage gain.

3. Level shifting stage

Establishes suitable DC operating levels between internal stages.

4. Output stage

Provides output drive capability and reduces output impedance.

This is a simplified functional representation, not a transistor-level schematic of a specific IC.

6. IC 741 Operational Amplifier

The 741 is a classic general-purpose, internally compensated operational amplifier. It is commonly used for studying basic op-amp configurations.

Always verify the manufacturer's data sheet and package pinout before wiring. Different op-amp ICs can have different pin assignments.

7. Power Supply Connections

A traditional 741 is commonly operated from dual supplies, such as +15 V and −15 V, subject to the exact device's recommended operating conditions.

The positive and negative supply rails allow the output to swing above and below the reference ground, within the device's actual output limits.

8. Differential Input Voltage

The differential input voltage is the voltage difference between the non-inverting and inverting inputs.

Vd = V+ − V−
Input conditionOutput tendency
V+ greater than V−Output moves positive
V+ less than V−Output moves negative
V+ equal to V−Ideal differential output is zero; practical offset and circuit conditions still matter
In a negative-feedback amplifier operating linearly, the differential input voltage is usually very small. It is not necessarily exactly zero in a real op-amp.

10. Practical Applications of Op-Amps

Signal amplification

Amplifies low-level sensor and instrumentation signals.

Voltage comparator

Compares two voltages and indicates which is greater.

Active filters

Implements low-pass, high-pass and other filter circuits.

Buffer circuits

Provides impedance isolation between circuit stages.

Summing amplifier

Combines multiple analog input signals.

Instrumentation

Used in measurement and signal-conditioning systems.

11. Practical Laboratory Exercise

Objective

To identify the pin configuration of a 741 op-amp and observe the relationship between its differential input and output.

Components

  • 741 operational amplifier IC
  • Suitable dual DC power supply
  • Resistors and potentiometers
  • Digital multimeter
  • Breadboard and connecting wires

Procedure

  1. Identify the IC notch and pin-1 position.
  2. Verify the pin assignments using the data sheet.
  3. Connect the recommended supply rails and common reference.
  4. Apply a small differential input using a suitable test arrangement.
  5. Measure the output and observe its polarity.
  6. Record the result for positive and negative differential inputs.
Do not apply arbitrary voltages directly to the input pins. Keep all inputs within the specified common-mode and absolute maximum ratings. Use current-limited supplies and check the IC data sheet before testing.

Expected Result

The output tends to move positive when V+ exceeds V− and negative when V+ is below V−. In open-loop operation, even a small differential input can drive the output into saturation.

13. Placement-Oriented Interview Questions

1. What is an operational amplifier?

A high-gain differential voltage amplifier that amplifies the difference between two input voltages.

2. Why is it called an operational amplifier?

Historically, it was used to perform mathematical operations such as addition, subtraction, integration and differentiation in analog computers.

3. What are the two input terminals?

The inverting (−) and non-inverting (+) terminals.

4. What is differential input voltage?

Vd = V+ − V−.

5. What happens when V+ is greater than V− in open-loop operation?

The output tends toward the positive saturation limit.

6. What is the function of the differential input stage?

It amplifies the difference between input signals and rejects common-mode components.

7. What is the function of the output stage?

It provides output drive capability and a relatively low output impedance.

8. What is the pin number of the 741 output?

Pin 6.

9. Which pins are the 741 input terminals?

Pin 2 is inverting and pin 3 is non-inverting.

10. Why does a 741 commonly use dual supplies?

Dual supplies allow its output to swing on either side of the ground reference, within its operating limits.

11. What does NC mean in an IC pinout?

No connection; the pin has no specified internal circuit connection.

12. Can an op-amp output exceed its supply rails?

No. The output is limited by its power supply and output-stage characteristics.

13. What is open-loop gain?

The voltage gain without an external feedback network.

14. Why is feedback used with op-amps?

Negative feedback controls gain and improves several circuit characteristics, including linearity and bandwidth trade-offs.

15. Is a real op-amp ideal?

No. It has finite gain, bandwidth, input impedance, output current capability and other non-ideal parameters.

14. Practice Problems

  1. An op-amp has V+ = 2.004 V and V− = 2.000 V. Calculate the differential input voltage.
  2. If open-loop gain is 80,000 and differential input is 100 µV, calculate the ideal output before saturation.
  3. Identify the inverting input, non-inverting input and output pins of a 741 IC.
  4. Explain why a small differential voltage can drive an open-loop op-amp into saturation.
  5. Draw and explain the functional block diagram of an operational amplifier.
Show answers
  1. Vd = 4 mV.
  2. Vout = 80,000 × 100 µV = 8 V.
  3. Pin 2, pin 3 and pin 6, respectively.
  4. Because its open-loop voltage gain is very high.
  5. Differential input stage → intermediate gain stage → level shifting stage → output stage.

15. Lecture Summary

  • An op-amp is a high-gain differential amplifier.
  • Its output depends on V+ − V−.
  • The inverting input is marked (−), and the non-inverting input is marked (+).
  • The internal functional stages provide differential amplification, voltage gain, level shifting and output drive.
  • The 741 is an 8-pin general-purpose op-amp.
  • Open-loop operation can drive the output into saturation for very small differential inputs.
