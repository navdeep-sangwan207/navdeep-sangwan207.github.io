2. Summing Amplifier

A summing amplifier is an Op-Amp circuit that combines two or more input voltages and produces an output proportional to their weighted sum.

The commonly used inverting summing amplifier applies multiple input signals to the inverting terminal through individual resistors. The non-inverting terminal is connected to ground or a reference voltage.

A summing amplifier is also called an Op-Amp adder because it performs analog addition of input signals.

4. Working Principle of Summing Amplifier

Each input voltage supplies current through its corresponding input resistor.

Under ideal negative-feedback operation, the inverting input is approximately at ground potential. This point is called virtual ground.

Since the ideal Op-Amp input current is zero, the currents from all input branches add at the summing node and flow through the feedback resistor.

I1 = V1 / R1
I2 = V2 / R2
I3 = V3 / R3

If = I1 + I2 + I3

5. Derivation of Summing Amplifier Output

Applying Kirchhoff's Current Law at the inverting summing node:

I1 + I2 + I3 = If

For an ideal Op-Amp with virtual ground:

Vout = -If × Rf

Substituting the input currents:

Vout = -Rf (V1/R1 + V2/R2 + V3/R3)

For n input signals, the general equation is:

Vout = -Rf × Σ(Vi/Ri)

where i ranges from 1 to n.

6. Equal-Resistor Summing Amplifier

If all input resistors have equal resistance R and the feedback resistor is also R, the output becomes the negative sum of the input voltages.

R1 = R2 = R3 = Rf = R

Vout = -(V1 + V2 + V3)

7. Numerical Example 1: Calculate Summing Output

Given:

  • V1 = 1 V
  • V2 = 2 V
  • V3 = 3 V
  • R1 = R2 = R3 = 10 kΩ
  • Rf = 10 kΩ

Solution:

Vout = -Rf (V1/R1 + V2/R2 + V3/R3)

Vout = -10k (1/10k + 2/10k + 3/10k)

Vout = -(1 + 2 + 3)

Vout = -6 V

8. Weighted Summing Amplifier

A weighted summing amplifier gives different importance or gain to different input signals by selecting different input resistor values.

Vout = -Rf (V1/R1 + V2/R2 + V3/R3)

The contribution of each input depends on the ratio Rf/Ri.

Numerical Example 2: Weighted Summation

Given:

  • V1 = 1 V, R1 = 10 kΩ
  • V2 = 2 V, R2 = 20 kΩ
  • V3 = 3 V, R3 = 30 kΩ
  • Rf = 30 kΩ
Vout = -30k (1/10k + 2/20k + 3/30k)

Vout = -(3 + 3 + 3)

Vout = -9 V

9. Averaging Amplifier

An averaging amplifier produces an output proportional to the average of multiple input voltages.

For n equal input resistors R, the inverting summing amplifier output is:

Vout = -(Rf/R)(V1 + V2 + ... + Vn)

To obtain the negative average:

Rf = R/n

Vout = -(V1 + V2 + ... + Vn)/n
This is an inverting average. If a positive average is required, an additional inverting stage or a suitable non-inverting averaging circuit can be used.

10. Applications of Summing Amplifier

  • Analog signal addition.
  • Audio mixer circuits.
  • Digital-to-analog conversion using weighted inputs.
  • Signal conditioning.
  • Combining sensor signals.
  • Analog computation and control systems.

11. Differential Amplifier

A differential amplifier is an Op-Amp circuit that amplifies the difference between two input voltages while ideally rejecting signals common to both inputs.

Differential input:

Vd = V2 - V1

It is commonly used to measure small voltage differences in the presence of common electrical noise.

A differential amplifier is useful when the required signal is the voltage difference between two points, rather than either voltage measured independently relative to ground.

13. Working Principle of Differential Amplifier

The inverting input receives V1 through resistor R1. The output is fed back through resistor R2.

The non-inverting input receives V2 through resistor R3. Resistor R4 connects the non-inverting input to ground.

The resistor network sets the differential gain. For accurate common-mode rejection, the resistor ratios must be properly matched.

14. Derivation of Differential Amplifier Output

First, calculate the voltage at the non-inverting input using the voltage divider rule.

V+ = V2 × R4/(R3 + R4)

For ideal negative-feedback operation:

V− = V+

Applying Kirchhoff's Current Law at the inverting node:

(V1 - V−)/R1 = (V− - Vout)/R2

Rearranging:

Vout = (1 + R2/R1)V− - (R2/R1)V1

Substituting V− = V+:

Vout = (1 + R2/R1) × [V2 × R4/(R3 + R4)] - (R2/R1)V1

When the resistor ratios satisfy:

R2/R1 = R4/R3

The output simplifies to:

Differential Amplifier Output:

Vout = (R2/R1)(V2 - V1)

15. Numerical Example 3: Differential Amplifier

Given:

  • V1 = 1 V
  • V2 = 3 V
  • R1 = R3 = 10 kΩ
  • R2 = R4 = 50 kΩ

Step 1: Check resistor ratios.

R2/R1 = 50/10 = 5
R4/R3 = 50/10 = 5

Ratios are matched.

Step 2: Calculate output.

Vout = (R2/R1)(V2 - V1)

Vout = 5(3 - 1)

Vout = 10 V
This is the ideal calculated output. The actual Op-Amp must have sufficient supply voltage and output swing to produce 10 V without saturation.

16. Common-Mode Signal

A common-mode signal is a voltage component that appears equally at both differential amplifier inputs.

For example, if both inputs contain the same unwanted 50 Hz interference voltage, an ideal differential amplifier rejects that common component.

V1 = Vcm - Vd/2
V2 = Vcm + Vd/2

Vd = V2 - V1

17. Common-Mode Rejection Ratio (CMRR)

CMRR measures the ability of a differential amplifier to amplify differential signals while rejecting common-mode signals.

CMRR = Ad / Acm

CMRR(dB) = 20 log10(Ad/Acm)

Where:

  • Ad = Differential-mode voltage gain.
  • Acm = Common-mode voltage gain.
A higher CMRR indicates better rejection of common-mode interference.

Numerical Example 4: Calculate CMRR

Given:

  • Differential gain Ad = 1000
  • Common-mode gain Acm = 0.01
CMRR = 1000 / 0.01

CMRR = 100000

CMRR(dB) = 20 log10(100000)

CMRR = 100 dB

18. Summing vs Differential Amplifier

Parameter Summing Amplifier Differential Amplifier
Main function Adds input signals with selected weights. Amplifies the difference between two signals.
Typical inputs Two or more signals. Two input signals.
Basic output Negative weighted sum for inverting type. Scaled difference.
Important property Signal addition. Common-mode rejection.
Applications Audio mixers and analog computation. Sensor measurement and noise rejection.

19. Practical Applications of Differential Amplifiers

  • Sensor signal measurement.
  • Bridge circuit measurement.
  • Instrumentation systems.
  • Noise rejection in measurement circuits.
  • Industrial signal conditioning.
  • Current-sense voltage measurement.
  • Audio and communication circuits.

Embedded Systems Application

A current-sense resistor produces a small voltage proportional to current. A differential amplifier can measure the voltage across the resistor.

Vsense = I × Rsense

Vout = Gain × Vsense

This conditioned voltage can be supplied to an ADC, provided that the amplifier output range and ADC input limits are compatible.

20. Practical Design Considerations

  • Use precision resistors for accurate differential gain.
  • Match resistor ratios to improve common-mode rejection.
  • Check the Op-Amp input common-mode range.
  • Check output voltage swing and supply requirements.
  • Consider input offset voltage and bias currents.
  • Use suitable filtering when the input contains high-frequency noise.
  • Consider an instrumentation amplifier for high-accuracy, high-CMRR measurements.
A basic four-resistor differential amplifier can have limited CMRR because of resistor mismatch. Instrumentation amplifiers are often preferred for precision sensor measurements, especially when input impedance and common-mode rejection are important.

21. Interview Questions and Answers

Q1. What is a summing amplifier?

An Op-Amp circuit that combines multiple input voltages to produce an output proportional to their weighted sum.

Q2. What is the output equation of an inverting summing amplifier?

Vout = -Rf(V1/R1 + V2/R2 + ...).

Q3. What is a virtual ground?

A node maintained approximately at ground potential by negative feedback, without a direct physical connection to ground.

Q4. What is a weighted summing amplifier?

A summing circuit in which different input resistors provide different gains or weights to the input signals.

Q5. What is a differential amplifier?

An amplifier that amplifies the voltage difference between two inputs.

Q6. What is common-mode voltage?

The voltage component that appears equally at both differential inputs.

Q7. What is CMRR?

Common-Mode Rejection Ratio is the ratio of differential gain to common-mode gain.

Q8. What does a high CMRR indicate?

Better rejection of common-mode interference.

Q9. Why should differential amplifier resistors be matched?

Matched resistor ratios help preserve common-mode rejection and differential accuracy.

Q10. When is an instrumentation amplifier preferred?

When high input impedance, accurate gain and high common-mode rejection are required for precision measurements.
