2. What is a Non-Inverting Amplifier?

A non-inverting amplifier is an Op-Amp circuit in which the input signal is applied directly to the non-inverting terminal.

A resistive feedback network connects the output to the inverting terminal. This network provides negative feedback and controls the closed-loop voltage gain.

The output signal has the same polarity as the input signal. For sinusoidal signals within the amplifier's operating bandwidth, the input and output are ideally in phase.

4. Components and Their Functions

Component Function
Vin Input signal applied to the non-inverting terminal.
Rf Feedback resistor connected between output and inverting input.
Rg Resistor connecting the inverting input to ground or a reference.
Op-Amp Amplifies the differential input voltage.
Power supply Provides operating energy to the Op-Amp.

5. Working Principle

The input voltage is directly applied to the non-inverting terminal.

A fraction of the output voltage is returned to the inverting terminal through the feedback network. This negative feedback forces the two input voltages to become approximately equal during linear operation.

V+ ≈ V−

Since V+ = Vin:
V− ≈ Vin

6. Negative Feedback in a Non-Inverting Amplifier

The feedback network consists of Rf and Rg. The voltage at the inverting terminal is a fraction of the output voltage.

V− = Vout × Rg / (Rf + Rg)

Because the Op-Amp operates with negative feedback:

Vin ≈ Vout × Rg / (Rf + Rg)

7. Derivation of Voltage Gain

Voltage gain is defined as the ratio of output voltage to input voltage.

Av = Vout / Vin

Step 1: Apply the Voltage Divider Rule

The feedback resistors Rf and Rg form a voltage divider between the output and ground.

V− = Vout × Rg / (Rf + Rg)

Step 2: Apply the Virtual Short Concept

V− ≈ V+

V+ = Vin

Therefore:
Vin = Vout × Rg / (Rf + Rg)

Step 3: Rearrange the Equation

Vout / Vin = (Rf + Rg) / Rg

Av = Rf/Rg + Rg/Rg
Final Voltage Gain Equation:

Av = 1 + (Rf / Rg)

Vout = Vin × [1 + (Rf / Rg)]

8. Important Characteristics

  • Output has the same polarity as input.
  • Voltage gain is positive.
  • Input impedance is very high in an ideal Op-Amp.
  • Negative feedback controls the gain.
  • Closed-loop gain is determined by Rf and Rg.
  • Ideal non-inverting voltage gain is always equal to or greater than 1 for positive resistors.

9. Numerical Example 1: Calculate Voltage Gain

Given:

  • Rf = 90 kΩ
  • Rg = 10 kΩ

Solution:

Av = 1 + (Rf/Rg)

Av = 1 + (90/10)

Av = 10

10. Numerical Example 2: Calculate Output Voltage

Given:

  • Vin = 0.5 V
  • Rf = 40 kΩ
  • Rg = 10 kΩ

Step 1: Calculate gain.

Av = 1 + (40/10)
Av = 5

Step 2: Calculate output voltage.

Vout = Av × Vin

Vout = 5 × 0.5

Vout = 2.5 V

11. Numerical Example 3: Find Feedback Resistance

Given:

  • Required gain = 11
  • Rg = 10 kΩ

Solution:

Av = 1 + (Rf/Rg)

11 = 1 + (Rf/10 kΩ)

10 = Rf/10 kΩ

Rf = 100 kΩ

12. Voltage Follower as a Special Case

A voltage follower is a special form of non-inverting amplifier in which the output is directly connected to the inverting input.

In the gain equation, the feedback network has effectively zero feedback resistance and direct output-to-input feedback.

Av = 1

Vout ≈ Vin

A voltage follower is mainly used as a buffer. It is discussed in detail in the next lesson.

13. Input and Output Resistance

Input Resistance

The signal source is connected directly to the non-inverting input. Since an ideal Op-Amp draws no input current, its input resistance is theoretically infinite.

Output Resistance

Negative feedback reduces the effective output resistance, allowing the amplifier to drive a load more effectively within its output current limits.

14. Inverting vs Non-Inverting Amplifier

Parameter Inverting Amplifier Non-Inverting Amplifier
Input terminal Inverting (−) Non-inverting (+)
Gain equation −Rf/R1 1 + Rf/Rg
Output phase 180° phase reversal Same phase ideally
Input impedance Approximately R1 Very high ideally
Minimum gain magnitude Can be below, equal to or above 1 At least 1
Applications Signal inversion and amplification High-input-impedance amplification

15. Practical Limitations

  • Output voltage is limited by the available supply and output swing.
  • Closed-loop bandwidth decreases as gain increases for typical voltage-feedback Op-Amps.
  • Slew-rate limitations affect fast signals.
  • Input offset voltage causes output offset.
  • Input common-mode range must include the applied input voltage.
  • Resistor tolerances affect the actual gain.
  • Load current must remain within the Op-Amp output capability.
The non-inverting amplifier gain formula assumes negative feedback and linear operation. If the output saturates, the ideal gain equation will not predict the actual output.

16. Practical Applications

  • Sensor signal amplification.
  • High-input-impedance signal conditioning.
  • Measurement and instrumentation circuits.
  • Active filter circuits.
  • Audio signal processing.
  • Analog interface circuits.
  • Voltage amplification in embedded electronics.
Embedded Systems Connection: A non-inverting amplifier can increase a small sensor voltage without loading the sensor significantly. It is useful before an ADC input, provided the output range is compatible with the ADC reference and input limits.

17. Interview Questions and Answers

Q1. What is a non-inverting amplifier?

An Op-Amp circuit in which the input signal is applied to the non-inverting terminal and negative feedback is connected to the inverting terminal.

Q2. What is its voltage gain equation?

Av = 1 + (Rf/Rg).

Q3. Is the output inverted?

No. The output is ideally in phase with the input.

Q4. Why is input impedance high?

Because the signal is applied to the Op-Amp input terminal, which draws very little input current.

Q5. What is the minimum ideal gain?

Unity gain, equal to 1.

Q6. What is the function of Rf?

It provides negative feedback and helps determine the closed-loop gain.

Q7. What is the function of Rg?

It connects the inverting input to ground or a reference and forms a feedback voltage divider with Rf.

Q8. What happens when Rf increases?

The closed-loop voltage gain increases, assuming Rg remains constant.

Q9. What is a voltage follower?

A unity-gain non-inverting amplifier with its output directly connected to its inverting input.

Q10. Why is a non-inverting amplifier useful for sensor circuits?

Its high input impedance reduces loading on the sensor while providing voltage amplification.
