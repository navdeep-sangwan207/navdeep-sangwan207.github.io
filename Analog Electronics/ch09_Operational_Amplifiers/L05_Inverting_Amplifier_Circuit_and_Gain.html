2. What is an Inverting Amplifier?

An inverting amplifier is an operational amplifier circuit in which the input signal is applied to the inverting terminal through an input resistor, while the non-inverting terminal is connected to ground or a reference voltage.

A feedback resistor connects the output terminal to the inverting input terminal. This creates negative feedback.

The output signal is amplified and inverted. Inversion means that the output is 180° out of phase with the input for sinusoidal signals within the amplifier's operating bandwidth.

4. Components and Their Functions

Component Function
R1 Input resistor that controls input current.
Rf Feedback resistor that determines closed-loop gain with R1.
Op-Amp Amplifies the differential input voltage.
Ground/reference Provides the reference voltage at the non-inverting terminal.
Power supply Provides operating energy to the Op-Amp.

5. Working Principle

The non-inverting terminal is grounded, so its voltage is zero volts.

Due to negative feedback and the very high open-loop gain, the inverting input is maintained at approximately the same voltage as the non-inverting input when the amplifier operates in its linear region.

Therefore, the inverting input is approximately at zero volts, even though it is not directly connected to ground.

6. Virtual Ground Concept

A virtual ground is a point that is maintained at approximately zero volts due to negative feedback, but is not physically connected to ground.

For an ideal Op-Amp operating with negative feedback:

V+ ≈ V−
V+ = 0 V

Therefore:
V− ≈ 0 V
Virtual ground is not a real ground connection. Current can flow through the resistor network connected to this node, but an ideal Op-Amp draws no input current.

7. Virtual Short Concept

Under negative feedback, the voltage difference between the two input terminals of an ideal Op-Amp is approximately zero.

V+ − V− ≈ 0

Therefore:
V+ ≈ V−

This condition is called a virtual short. It does not mean that the two input terminals are physically shorted.

8. Derivation of Voltage Gain

The voltage gain of an inverting amplifier is the ratio of output voltage to input voltage.

Av = Vout / Vin

Step 1: Apply Kirchhoff's Current Law

At the inverting input node, the ideal Op-Amp input current is zero.

Therefore, current through R1 is equal to current through Rf.

Step 2: Input Resistor Current

I1 = (Vin − 0) / R1

I1 = Vin / R1

Step 3: Feedback Resistor Current

If = (0 − Vout) / Rf

If = −Vout / Rf

Step 4: Equate Currents

I1 = If

Vin / R1 = −Vout / Rf

Vout / Vin = −Rf / R1
Final Voltage Gain Equation:

Av = −Rf / R1

Vout = −(Rf / R1) × Vin

9. Meaning of Negative Sign

The negative sign indicates phase inversion. The output voltage is opposite in polarity to the input voltage.

For a sinusoidal input, the output is ideally shifted by 180° relative to the input.

10. Numerical Example 1: Calculate Voltage Gain

Given:

  • Input resistor R1 = 10 kΩ
  • Feedback resistor Rf = 100 kΩ

Solution:

Av = −Rf / R1

Av = −100 kΩ / 10 kΩ

Av = −10

The circuit produces an output with ten times the input amplitude and opposite polarity, provided it remains within its linear operating range.

11. Numerical Example 2: Calculate Output Voltage

Given:

  • R1 = 10 kΩ
  • Rf = 47 kΩ
  • Vin = 0.2 V

Step 1: Calculate gain.

Av = −47 / 10
Av = −4.7

Step 2: Calculate output voltage.

Vout = Av × Vin

Vout = −4.7 × 0.2

Vout = −0.94 V

12. Numerical Example 3: Find Feedback Resistance

Given:

  • Desired gain magnitude = 20
  • Input resistor R1 = 5 kΩ

Solution:

|Av| = Rf / R1

Rf = |Av| × R1

Rf = 20 × 5 kΩ

Rf = 100 kΩ

13. Input and Output Resistance

Input Resistance

For an ideal inverting amplifier, the signal source effectively sees the input resistor R1 because the inverting node is maintained at virtual ground.

Rin ≈ R1

Output Resistance

Negative feedback reduces the effective output resistance compared with the open-loop output resistance. The actual value depends on the Op-Amp and feedback conditions.

14. Effect of Changing Resistor Values

Change Effect
Increase Rf Increases the magnitude of voltage gain.
Decrease Rf Decreases the magnitude of voltage gain.
Increase R1 Decreases the magnitude of voltage gain.
Decrease R1 Increases the magnitude of voltage gain.

15. Practical Limitations

  • Output voltage cannot exceed the usable output swing.
  • Bandwidth decreases as closed-loop gain increases for a typical voltage-feedback Op-Amp.
  • Slew-rate limitations can distort fast or large-amplitude signals.
  • Input offset voltage can produce output offset.
  • Input bias currents can cause additional errors.
  • Resistor tolerance affects the actual gain.
  • Stability depends on the Op-Amp and feedback network.
The gain equation Av = −Rf/R1 assumes ideal behavior and linear operation with negative feedback. If the output reaches saturation, the calculated linear gain no longer describes the actual output.

16. Practical Applications

  • Signal amplification.
  • Sensor signal conditioning.
  • Audio signal processing.
  • Active filter circuits.
  • Summing amplifier circuits.
  • Analog signal processing systems.
  • Measurement and instrumentation circuits.
Embedded Electronics Connection: An inverting amplifier can scale and invert a sensor voltage before it reaches an ADC interface. Check the ADC input range and ensure the Op-Amp output never goes outside the permitted voltage range.

18. Interview Questions and Answers

Q1. What is an inverting amplifier?

An Op-Amp circuit in which the input is applied to the inverting terminal through a resistor and negative feedback is provided through another resistor.

Q2. What is the voltage gain equation?

Av = −Rf/R1.

Q3. Why is the output inverted?

Because the signal is applied to the inverting terminal, producing an output with opposite polarity.

Q4. What is virtual ground?

A node maintained approximately at zero volts by negative feedback without a direct physical ground connection.

Q5. What is virtual short?

The condition in which the two Op-Amp input voltages are approximately equal under negative feedback.

Q6. Why is negative feedback used?

It controls the amplifier gain and provides predictable linear operation.

Q7. What determines the voltage gain?

The ratio of feedback resistance to input resistance.

Q8. What happens if feedback resistance increases?

The magnitude of voltage gain increases, assuming the other conditions remain unchanged.

Q9. What is the phase difference between input and output?

Ideally 180° for sinusoidal signals within the operating bandwidth.

Q10. Does virtual ground mean the input terminal is physically grounded?

No. It is maintained near ground potential through negative feedback.

20. Lesson Summary

  • An inverting amplifier uses negative feedback.
  • The input signal is applied to the inverting terminal through R1.
  • The non-inverting terminal is connected to ground or a reference voltage.
  • Rf connects the output to the inverting input.
  • The inverting input is approximately at virtual ground when the non-inverting input is grounded.
  • The voltage gain is Av = −Rf/R1.
  • The negative sign indicates phase inversion.
  • Gain depends on the ratio of feedback and input resistances.
  • Practical performance is limited by bandwidth, slew rate, output swing and other non-ideal characteristics.
