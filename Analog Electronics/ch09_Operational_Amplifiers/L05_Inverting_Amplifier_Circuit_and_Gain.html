2. Introduction to Inverting Amplifier

An inverting amplifier is an op-amp circuit in which the input signal is applied to the inverting terminal through an input resistor, while the non-inverting terminal is connected to ground or a reference voltage.

A feedback resistor is connected between the output and the inverting terminal.

The non-inverting terminal (+) is grounded. The input signal is applied to the inverting terminal (−) through Rin.

3. Circuit Components

ComponentFunction
Op-ampAmplifies the error signal between its inputs.
RinInput resistor that determines the input current.
RfFeedback resistor that controls closed-loop gain.
Ground/referenceEstablishes the reference at the non-inverting terminal.
Supply railsProvide power to the op-amp.

4. Working Principle

  1. Vin is applied through Rin to the inverting input.
  2. The non-inverting input is connected to ground.
  3. Rf connects the output back to the inverting input.
  4. Negative feedback causes the op-amp to adjust its output.
  5. Under linear operation, V− approaches V+.
  6. Since V+ is grounded, V− approaches 0 V.
  7. The input current flows through Rin and approximately through Rf because op-amp input current is very small.

5. Virtual Ground Concept

With negative feedback and an op-amp operating in its linear region:

V− ≈ V+ ≈ 0 V

The inverting input node is called a virtual ground.

Actual ground

A physical connection to the circuit reference node.

Virtual ground

A node held approximately at ground potential by feedback, without a direct ground connection.

Virtual ground is not a physical ground connection. The approximation is valid only while the op-amp operates correctly with negative feedback and within its limitations.

6. Gain Derivation Using Kirchhoff's Current Law

Assume an ideal op-amp operating in the linear region with negative feedback.

Step 1: Virtual ground

V− ≈ 0 V

Step 2: Input current through Rin

Iin = (Vin − 0) / Rin
Iin = Vin / Rin

Step 3: Op-amp input current

I− ≈ 0

Since almost no current enters the op-amp input terminal, the current through Rin approximately equals the current through Rf.

Step 4: Feedback current

If = (0 − Vout) / Rf

Step 5: Apply KCL

Vin / Rin = −Vout / Rf

Step 6: Rearrange

Vout / Vin = −Rf / Rin
Closed-loop voltage gain: Av = −Rf/Rin

7. Inverting Amplifier Gain

Av = Vout / Vin = −Rf / Rin

The negative sign represents phase inversion.

ParameterExpression
Voltage gainAv = −Rf/Rin
Gain magnitude|Av| = Rf/Rin
Output voltageVout = −(Rf/Rin)Vin
Input impedanceApproximately Rin, under ideal assumptions
Phase relationship180° inversion for sinusoidal signals within the operating bandwidth

8. Worked Numerical Example

Given:

  • Rin = 10 kΩ
  • Rf = 100 kΩ
  • Vin = 0.2 V

Step 1: Calculate gain

Av = −100kΩ / 10kΩ = −10

Step 2: Calculate output

Vout = −10 × 0.2 V
Vout = −2 V
Output voltage = −2 V

11. Resistor Selection

To design an inverting amplifier for a required gain magnitude:

Rf = |Av| × Rin

Example

Design an amplifier with gain −5 using Rin = 20 kΩ.

Rf = 5 × 20 kΩ
Rf = 100 kΩ
Lower Rin

May increase input loading of the source and increase input resistor noise.

Higher Rf

May increase resistor noise, parasitic effects and bias-current error.

12. Frequency Response and Bandwidth

A practical op-amp has a limited gain-bandwidth product (GBW).

For a single-pole op-amp and suitable closed-loop conditions, a rough bandwidth estimate is:

BW ≈ GBW / |Noise gain|

For an inverting amplifier, the noise gain is:

Noise gain = 1 + Rf/Rin

Example

If GBW = 1 MHz, Rin = 10 kΩ and Rf = 100 kΩ:

Noise gain = 1 + 100/10 = 11
BW ≈ 1 MHz / 11
BW ≈ 90.9 kHz
The estimate is approximate and assumes a suitable single-pole model. Actual bandwidth depends on the op-amp, loading and circuit implementation.

13. Practical Limitations

  • Output voltage swing cannot exceed the device's practical output limits.
  • Output current is limited.
  • Finite gain-bandwidth product limits frequency response.
  • Slew rate limits the speed of large signal changes.
  • Input offset voltage introduces output error.
  • Input bias current affects the circuit depending on resistor values.
  • Noise affects the output.
  • Resistor tolerance changes the actual gain.
  • Output loading can affect the circuit performance.

14. Practical Laboratory Exercise

Objective

To construct and verify an inverting amplifier using an op-amp.

Components

  • Op-amp IC suitable for the selected supply
  • Rin = 10 kΩ
  • Rf = 100 kΩ
  • Signal source
  • Oscilloscope
  • Current-limited power supply
  • Breadboard and connecting wires

Procedure

  1. Identify the op-amp pinout using its datasheet.
  2. Connect the non-inverting terminal to ground or the circuit reference.
  3. Connect Rin between the input signal and the inverting node.
  4. Connect Rf between output and the inverting node.
  5. Connect the recommended power supply.
  6. Apply a small sinusoidal input, such as 0.1 V peak, at a low frequency.
  7. Observe the input and output waveforms on the oscilloscope.
  8. Verify the gain and phase inversion.

Expected Result

Av = −100kΩ/10kΩ = −10

For a 0.1 V peak input, the ideal output is −1 V peak, subject to practical limits.

Verify the op-amp supply requirements before wiring. Do not connect the output directly to ground or a supply rail. Use appropriate current limiting.

16. Placement-Oriented Interview Questions

1. What is an inverting amplifier?

An op-amp configuration in which the input signal is applied to the inverting input through a resistor, with negative feedback from output.

2. What is the gain formula?

Av = −Rf/Rin.

3. Why is the gain negative?

It indicates the output is inverted relative to the input.

4. What is virtual ground?

A node maintained approximately at ground potential by negative feedback, without being directly connected to ground.

5. Why is the inverting node approximately zero volts?

The op-amp's negative feedback drives the differential input toward zero when operating linearly with the non-inverting input grounded.

6. Does current enter the op-amp input?

Ideally, no. Practical input bias current is small but nonzero.

7. What determines the gain?

The ratio of feedback resistor to input resistor.

8. What happens if Rf is doubled?

The gain magnitude approximately doubles, provided the circuit remains within its operating limits.

9. What happens if Rin is doubled?

The gain magnitude approximately halves if Rf is unchanged.

10. What is the input impedance?

Approximately Rin in the ideal inverting configuration.

11. Why does the output saturate?

The required output voltage exceeds the op-amp's available output swing.

12. What is noise gain?

Noise gain is 1+Rf/Rin for the standard inverting amplifier and is relevant to stability and bandwidth.

13. What is the difference between signal gain and noise gain?

Signal gain is −Rf/Rin. Noise gain is 1+Rf/Rin.

14. How does GBW affect bandwidth?

For a suitable single-pole model, increasing closed-loop noise gain reduces bandwidth.

15. What is slew rate?

The maximum rate at which the output voltage can change with time.

16. Can the virtual ground be used to draw unlimited current?

No. Current is limited by the resistors, output capability, feedback and device operating conditions.

17. Why is negative feedback important?

It establishes a controlled closed-loop gain and improves linear operation within suitable operating conditions.

18. How can an inverting amplifier be used as a summing amplifier?

Multiple input resistors can feed the inverting node, producing a weighted sum of input voltages.

17. Numerical Practice

  1. Rin = 5 kΩ and Rf = 25 kΩ. Find the voltage gain.
  2. Vin = 0.4 V, Rin = 10 kΩ and Rf = 50 kΩ. Calculate Vout.
  3. Design a gain of −8 using Rin = 10 kΩ. Find Rf.
  4. Rin = 20 kΩ, Rf = 100 kΩ and Vin = −0.5 V. Calculate Vout.
  5. GBW = 2 MHz, Rin = 10 kΩ and Rf = 90 kΩ. Estimate bandwidth.
  6. Explain why the input impedance of an inverting amplifier is approximately Rin.
Show answers
  1. Av = −25/5 = −5.
  2. Av = −5, so Vout = −2 V.
  3. Rf = 8 × 10 kΩ = 80 kΩ.
  4. Av = −5, so Vout = +2.5 V.
  5. Noise gain = 1 + 90/10 = 10. BW ≈ 2 MHz/10 = 200 kHz.
  6. The source supplies current through Rin into the virtual-ground node. Feedback maintains the node near reference potential, making the source see approximately Rin.

18. Lecture Summary

  • The inverting amplifier uses negative feedback.
  • The non-inverting input is connected to ground or a reference.
  • The inverting node behaves approximately as a virtual ground.
  • Closed-loop gain is −Rf/Rin.
  • The output is inverted relative to the input.
  • Signal gain and noise gain are different.
  • Practical output swing, bandwidth, slew rate and loading limit performance.
