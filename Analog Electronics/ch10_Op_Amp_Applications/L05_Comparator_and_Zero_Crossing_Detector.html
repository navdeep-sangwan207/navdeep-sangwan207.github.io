2. What is a Comparator?

A comparator is an electronic circuit that compares two input voltages and changes its output state according to which input is higher.

It is commonly used to convert an analog voltage into a digital-like HIGH or LOW output.

Non-inverting input (+)

The voltage applied to the positive input.

Inverting input (−)

The voltage applied to the negative input.

Reference voltage

The threshold against which the signal is compared.

Output

Switches toward the high or low output level depending on the input comparison.

If V+ > V− → Output HIGH
If V+ < V− → Output LOW

These rules describe the ideal switching polarity. Actual output levels depend on the device, its supply rails and its output stage.

3. Op-Amp Used as a Comparator

A comparator is often implemented using an op-amp in open-loop operation, without a linear negative-feedback network.

Because the open-loop gain is very large, even a small difference between the two inputs can drive the output toward one of its output limits.

Vout ≈ +Vsat when V+ > V−
Vout ≈ −Vsat when V+ < V−
An op-amp's output is not necessarily equal to its supply voltage. Output swing, recovery time from saturation and common-mode input range must be checked in its datasheet.

4. Inverting Comparator

In an inverting comparator, the input signal is applied to the inverting terminal and the reference voltage is applied to the non-inverting terminal.

For this configuration:

V+ = Vref ; V− = Vin
Vin < Vref → Output HIGH
Vin > Vref → Output LOW

When Vin crosses Vref from below, the output changes from HIGH to LOW.

5. Non-Inverting Comparator

In a non-inverting comparator, the input signal is applied to the non-inverting terminal and the reference voltage is applied to the inverting terminal.

Vin > Vref → Output HIGH
Vin < Vref → Output LOW

When Vin crosses Vref from below, the output changes from LOW to HIGH.

7. Reference Voltage Generation

A comparator can use a fixed reference voltage or an adjustable reference voltage. A resistor divider is a common way to generate a reference from a regulated supply.

For a divider connected between VCC and ground:

Vref = VCC × R2/(R1+R2)

Example: VCC = 12 V, R1 = 10 kΩ and R2 = 10 kΩ.

Vref = 12 × 10/(10+10) = 6 V
For accurate thresholds, consider resistor tolerance, reference-source accuracy, input bias current, noise and loading. A precision reference IC may be preferable to an unbuffered divider.

8. Zero Crossing Detector

A zero-crossing detector is a comparator whose reference voltage is zero. It detects when an input signal crosses the ground reference level.

Vref = 0 V

For a non-inverting zero-crossing detector:

Vin > 0 → Output HIGH
Vin < 0 → Output LOW

For a sinusoidal input, the output changes state at each zero crossing, producing a rectangular waveform.

In an actual circuit, the switching point may differ slightly from zero due to input offset voltage, noise, input bias effects and propagation delay.

A dedicated comparator IC is generally preferred for fast switching. Many op-amps have slow overload recovery, limited output swing or output stages unsuitable for direct logic interfacing.

13. Practical Design Considerations

  • Input common-mode range: Ensure both input voltages are within the allowed common-mode range.
  • Output levels: Check output swing and whether the output is push-pull or open-collector/open-drain.
  • Logic compatibility: Confirm that the output voltage and current are compatible with the receiving logic input.
  • Propagation delay: Select a comparator fast enough for the signal frequency and edge requirements.
  • Input offset: Include offset voltage in threshold accuracy calculations.
  • Noise: Add suitable filtering or hysteresis if the signal is noisy.
  • Supply decoupling: Place suitable bypass capacitors close to the IC supply pins.
  • Input protection: Protect inputs against voltages outside the absolute maximum ratings.

15. Practical Laboratory

Objective

Construct a non-inverting comparator and observe its output when an input signal crosses a reference voltage.

Components

  • Suitable comparator IC or an op-amp specifically verified for comparator operation.
  • Regulated power supply.
  • Resistors for reference voltage generation.
  • Function generator or adjustable low-voltage DC source.
  • Oscilloscope and multimeter.
  • LED with a correctly calculated current-limiting resistor, if the output stage supports the load.

Procedure

  1. Read the device datasheet and identify the input and output pin configuration.
  2. Generate a reference voltage using a resistor divider or precision reference.
  3. Connect the reference to the inverting input.
  4. Connect the signal source to the non-inverting input.
  5. Power the device using suitable supply voltages.
  6. Apply a low-frequency sine wave within the input range.
  7. Observe the input and output waveforms simultaneously.
  8. Record the voltage at which the output changes state.
  9. Change the reference voltage and repeat.
  10. Compare the measured threshold with the theoretical value.

Expected Result

The output changes state when the input crosses the reference voltage. With a zero reference, the circuit detects zero crossings.

Never assume that an op-amp output can directly drive an LED or microcontroller input. Verify output current, voltage levels, output topology and logic compatibility first.

17. Placement-Oriented Interview Questions

1. What is a comparator?

A circuit that compares two voltages and produces an output state according to their relative magnitudes.

2. What is the comparator output when V+ is greater than V−?

It moves toward the HIGH output state.

3. What is open-loop operation?

Operation without a linear negative-feedback network.

4. What is an inverting comparator?

A comparator with the signal applied to the inverting input and reference applied to the non-inverting input.

5. What is a non-inverting comparator?

A comparator with the signal applied to the non-inverting input and reference applied to the inverting input.

6. What is a reference voltage?

The threshold voltage used for comparison.

7. What is a zero-crossing detector?

A comparator circuit that detects when an input signal crosses zero volts.

8. What is the reference voltage in a zero-crossing detector?

Zero volts.

9. What is the output of a non-inverting zero-crossing detector for a positive input?

HIGH, subject to actual device output levels.

10. What happens when Vin is greater than Vref in an inverting comparator?

The output moves toward LOW.

11. Why does a comparator saturate?

Its large open-loop gain drives the output toward an output limit when the input difference is nonzero.

12. What is propagation delay?

The time between an input crossing the threshold and the corresponding output transition.

13. Why is a dedicated comparator preferred?

It is designed for switching operation and often provides faster recovery and more suitable output characteristics.

14. What is input offset voltage?

The small differential input voltage required to make the actual device switch at its effective threshold.

15. Why is hysteresis used?

It creates separate rising and falling thresholds to prevent repeated switching due to noise near the threshold.

16. What is an open-collector output?

An output stage that requires an external pull-up resistor to produce a HIGH level.

17. Can every op-amp be used as a comparator?

No. Input range, saturation recovery, output stage and speed must be checked.

18. Mention two applications of comparators.

Overvoltage detection and zero-crossing detection.

19. Lecture Summary

  • A comparator compares two input voltages.
  • It commonly operates without linear negative feedback.
  • An inverting comparator switches LOW when Vin exceeds Vref.
  • A non-inverting comparator switches HIGH when Vin exceeds Vref.
  • A zero-crossing detector uses a zero-volt reference.
  • A resistor divider can generate a comparison threshold.
  • Noise near the threshold can cause repeated switching.
  • Hysteresis, propagation delay, input range and output topology are important practical considerations.
  • A dedicated comparator is often preferable to a general-purpose op-amp for switching applications.
