Lesson 02: Op-Amp Differentiator

Chapter 10 – Op-Amp Applications

Analog Electronics

1. Learning Objectives

  • Define an operational amplifier differentiator.
  • Understand its circuit configuration and working principle.
  • Derive the output voltage equation.
  • Understand input and output waveform relationships.
  • Differentiate between ideal and practical differentiators.
  • Identify practical applications of differentiator circuits.

2. Introduction to Op-Amp Differentiator

An operational amplifier differentiator is an analog circuit that produces an output voltage proportional to the rate of change of the input voltage with respect to time.

It is constructed using an operational amplifier, an input capacitor and a feedback resistor.

Output voltage ∝ Rate of change of input voltage

Differentiators are useful in edge detection, wave-shaping, transient detection and signal-processing circuits.

3. Op-Amp Differentiator Circuit Diagram

The basic inverting differentiator consists of:

  • Input capacitor (C)
  • Feedback resistor (R)
  • Operational amplifier
  • Non-inverting terminal connected to ground
Important: This is an idealized conceptual circuit. A practical differentiator adds a resistor in series with the input capacitor and a capacitor in parallel with the feedback resistor to control high-frequency gain and improve stability.

4. Working Principle

The input voltage is applied to the inverting terminal through capacitor C. The feedback resistor R connects the output to the inverting terminal.

  1. The non-inverting terminal is connected to ground.
  2. Negative feedback maintains the inverting terminal near virtual ground during linear operation.
  3. The changing input voltage causes current to flow through the input capacitor.
  4. Since the op-amp input current is approximately zero, the capacitor current flows through the feedback resistor.
  5. The voltage across the feedback resistor determines the output voltage.

Therefore, the output depends on how quickly the input voltage changes.

5. Mathematical Derivation

For an ideal op-amp with negative feedback:

V− ≈ V+ = 0 V

Current through the input capacitor:

IC = C × d(Vin − V−)/dt

Since V− is approximately zero:

IC = C × dVin/dt

Current through the feedback resistor:

IR = (V− − Vout)/R
IR = −Vout/R

Applying Kirchhoff's Current Law:

C × dVin/dt = −Vout/R

Final Output Equation

Vout = −RC × dVin/dt

This equation shows that the output voltage is proportional to the negative derivative of the input voltage.

6. Input and Output Waveforms

Case 1: Constant DC Input

When a constant DC input is applied after the transient response has settled, its rate of change is zero. Therefore, the ideal differentiator output is zero.

Case 2: Square-Wave Input

A square wave contains rapid voltage transitions. An ideal differentiator produces narrow positive and negative pulses at the transitions. The polarity depends on whether the input is rising or falling.

Case 3: Triangular-Wave Input

A triangular input has constant positive and negative slopes. Its differentiated output is approximately a square wave.

Case 4: Sine-Wave Input

For a sinusoidal input:

Vin = Vm sin(ωt)

Differentiating:

dVin/dt = ωVm cos(ωt)

Therefore:

Vout = −ωRCVm cos(ωt)

The output amplitude increases with frequency. The ideal output lags the input by 90 degrees.

7. Practical Op-Amp Differentiator

An ideal differentiator has increasing gain with frequency. This makes it highly sensitive to high-frequency noise and can cause instability.

A practical differentiator uses:

  • A resistor Rs in series with the input capacitor C.
  • A feedback capacitor Cf in parallel with feedback resistor Rf.

Purpose of the Components

  • Rs: Limits high-frequency input current and gain.
  • Cf: Reduces high-frequency feedback impedance.
  • Rf: Provides a DC feedback path.
  • C: Provides the differentiating action.

Important Frequency Relationships

fL = 1/(2πRsC)
fH = 1/(2πRfCf)

The practical differentiator is designed to operate as a differentiator over a selected frequency range. Its exact response depends on all four components and the op-amp characteristics.

Do not confuse the ideal differentiator equation Vout = −RC(dVin/dt) with the complete frequency response of a practical differentiator.

8. Applications of Op-Amp Differentiator

  • Edge detection circuits.
  • Wave-shaping circuits.
  • Detection of rapidly changing signals.
  • Pulse generation and transient detection.
  • Analog signal processing.
  • Control and measurement systems.

9. Advantages and Limitations

Advantages

  • Detects rapid changes in input voltage.
  • Useful for pulse and edge detection.
  • Performs analog differentiation.
  • Can be used in waveform shaping.

Limitations

  • Amplifies high-frequency noise.
  • May become unstable without frequency compensation.
  • Performance is limited by op-amp bandwidth.
  • Component tolerances affect accuracy.

10. Numerical Example

Question:

An ideal op-amp differentiator has R = 100 kΩ and C = 0.01 μF. The input voltage is increasing linearly at a rate of 2 V/ms. Calculate the output voltage.

Given

  • R = 100 kΩ = 100 × 10³ Ω
  • C = 0.01 μF = 0.01 × 10⁻⁶ F
  • dVin/dt = 2 V/ms = 2000 V/s

Formula

Vout = −RC × dVin/dt

Substitution

RC = 100 × 10³ × 0.01 × 10⁻⁶
RC = 0.001 seconds
Vout = −0.001 × 2000

Final Answer

Vout = −2 V

11. Placement-Oriented Interview Questions

Q1. What is an op-amp differentiator?

It is an op-amp circuit whose output voltage is proportional to the negative rate of change of the input voltage.

Q2. Which component is connected at the input?

A capacitor is connected at the input of the basic differentiator.

Q3. Which component is used in the feedback path?

A resistor is used in the feedback path of an ideal differentiator.

Q4. What is the output for a triangular-wave input?

The output is approximately a square wave.

Q5. What is the output for a constant DC input?

After transients settle, the ideal output is zero.

Q6. Why is an ideal differentiator rarely used directly in practical circuits?

Because its gain increases with frequency, making it sensitive to high-frequency noise and potentially unstable.

Q7. How is a practical differentiator improved?

By adding a resistor in series with the input capacitor and a capacitor in parallel with the feedback resistor.

13. Lesson Summary

  • An op-amp differentiator performs mathematical differentiation.
  • The input capacitor and feedback resistor form the basic circuit.
  • Its output equation is Vout = −RC(dVin/dt).
  • A triangular input produces an approximately square output.
  • A square-wave input produces pulses at its transitions.
  • Practical differentiators use additional components to limit noise and improve stability.
