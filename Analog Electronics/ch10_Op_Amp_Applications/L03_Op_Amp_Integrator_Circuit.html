2. What is an Op-Amp Integrator?

An op-amp integrator is an analog circuit whose output voltage is proportional to the negative time integral of its input voltage.

Vout(t) = −1/(RC) ∫ Vin(t) dt

It uses a resistor at the input and a capacitor in the feedback path of an inverting op-amp configuration.

Input component

Resistor R connects the input signal to the inverting terminal.

Feedback component

Capacitor C connects the output to the inverting terminal.

Non-inverting terminal

Usually connected to ground in the basic circuit.

Output

Represents the accumulated, inverted input signal over time.

4. Working Principle

  1. The input voltage is applied through resistor R.
  2. Negative feedback keeps the inverting input approximately at virtual ground, provided the op-amp operates linearly.
  3. Current through R is approximately Vin/R.
  4. Since the op-amp input current is approximately zero, this current flows through the feedback capacitor.
  5. The capacitor voltage changes with time, causing the output voltage to ramp.
IR = Vin/R
IC = C × d(VC)/dt

For the inverting integrator, the output slope is:

dVout/dt = −Vin/(RC)
A positive constant input produces a negative-going output ramp. A negative constant input produces a positive-going output ramp.

5. Mathematical Derivation

For an ideal op-amp under negative feedback:

V− ≈ V+ = 0 V

Input current through R:

IR = (Vin − 0)/R = Vin/R

Op-amp input current is approximately zero. Therefore, the resistor current flows through capacitor C.

IC = C × d(V− − Vout)/dt

Since V− is approximately zero:

IC = −C × dVout/dt

Equating the currents:

Vin/R = −C × dVout/dt

Rearranging:

dVout/dt = −Vin/(RC)

Integrating both sides:

Vout(t) = Vout(0) − 1/(RC) ∫₀ᵗ Vin(τ)dτ

For zero initial capacitor voltage:

Vout(t) = −1/(RC) ∫₀ᵗ Vin(τ)dτ

A smaller RC gives a steeper output ramp for the same input voltage. A larger RC gives a slower output ramp.

7. Response to a Constant DC Input

For a constant input voltage Vin:

Vout(t) = Vout(0) − (Vin/RC)t

Example:

  • Vin = 1 V
  • R = 100 kΩ
  • C = 10 µF
  • RC = 1 second
Slope = −1/(1) = −1 V/s

After 2 seconds, assuming zero initial output:

Vout = −1 × 2 = −2 V
Output after 2 seconds = −2 V

8. Response to a Square-Wave Input

A symmetrical square-wave input alternates between positive and negative voltage levels. The integrator converts this into a triangular waveform, provided the circuit remains within its linear operating range.

The output slope is negative when the input is positive and positive when the input is negative. The exact waveform depends on input duty cycle, initial capacitor voltage and output limits.

9. Response to a Sinusoidal Input

For a sinusoidal input:

Vin = Vm sin(ωt)

Ideal integration gives:

Vout = Vm/(ωRC) cos(ωt) + K

For zero integration constant:

Vout = Vm/(ωRC) cos(ωt)
  • The output amplitude is Vm/(ωRC).
  • The output leads the input by 90° in the ideal sinusoidal steady-state case.
  • Output amplitude decreases as input frequency increases.

11. Practical Integrator

An ideal integrator has a capacitor in the feedback path without a DC feedback resistor. At DC, the capacitor behaves approximately as an open circuit. Consequently, small input offset voltage and bias-current effects can cause the output to drift into saturation.

A practical integrator places a resistor Rf in parallel with the feedback capacitor C.

Feedback impedance

Zf = Rf || 1/(sC)

Transfer function

Vout/Vin = −(Rf/R)/(1+sRfC)

At sufficiently high frequencies compared with the practical integrator corner frequency, the circuit approaches ideal integration.

fc = 1/(2πRfC)
The practical circuit is not an ideal integrator at all frequencies. Below its corner frequency, the feedback resistor limits the DC gain and reduces output drift.

14. Applications of Op-Amp Integrators

Waveform Generation

Converts square-wave signals into triangular waveforms.

Analog Computing

Performs mathematical integration in analog systems.

Ramp Generation

Generates a voltage ramp from a constant input.

Active Filters

Integration is a fundamental operation in several active filter structures.

Signal Processing

Used in analog signal conditioning and processing systems.

Control Systems

Integral action is used in controllers to reduce steady-state error.

16. Practical Laboratory

Objective

Construct an op-amp integrator and observe its response to a square-wave input.

Components

  • Op-amp suitable for the chosen supply voltage.
  • R = 100 kΩ.
  • C = 1 µF.
  • Function generator or low-voltage signal source.
  • Oscilloscope.
  • Regulated dual supply, if required by the selected device.

Procedure

  1. Check the op-amp datasheet and pin configuration.
  2. Connect the non-inverting input to the reference ground.
  3. Connect the input resistor between the signal source and inverting input.
  4. Connect the capacitor from output to inverting input.
  5. Power the circuit using a suitable regulated supply.
  6. Apply a low-frequency square-wave input with a suitable amplitude and zero DC offset.
  7. Observe the input and output simultaneously on an oscilloscope.
  8. Measure the output ramp slope.
  9. Change R or C and observe the change in slope.
  10. Compare the measured output with the theoretical equation.

Expected Result

The square-wave input produces an approximately triangular output while the op-amp remains in its linear operating region.

Do not exceed the op-amp's supply, input common-mode, differential-input or output limits. A practical feedback resistor is recommended for a real circuit to reduce DC drift and saturation.

18. Placement-Oriented Interview Questions

1. What is an op-amp integrator?

A circuit that produces an output proportional to the negative time integral of its input.

2. Which component is used in the feedback path?

A capacitor.

3. Which component is connected at the input?

A resistor.

4. Write the ideal integrator equation.

Vout = −1/(RC) ∫Vin dt, with an initial-condition term where applicable.

5. What is the output for a constant positive input?

A negative-going ramp, assuming the circuit starts within its linear range.

6. What is the output for a constant negative input?

A positive-going ramp.

7. What is the response to a square-wave input?

An approximately triangular waveform for a symmetrical square wave under suitable conditions.

8. What is the response to a sine-wave input?

A cosine-shaped output with amplitude scaled by 1/(ωRC), for ideal sinusoidal steady-state operation.

9. What is the time constant?

τ = RC.

10. What happens when RC decreases?

The output ramp becomes steeper for the same input voltage.

11. Why does an ideal integrator saturate?

Offset voltage and bias current can charge the feedback capacitor over time.

12. How can saturation due to DC drift be reduced?

Place a resistor in parallel with the feedback capacitor to provide a DC feedback path.

13. What is the practical integrator corner frequency?

fc = 1/(2πRfC).

14. What is virtual ground?

A node held approximately at ground potential by negative feedback, despite not being directly connected to ground.

15. Does the op-amp input terminal absorb the resistor current?

Ideally no; the current flows through the feedback capacitor.

16. What limits the maximum output ramp slope?

Output swing and the op-amp's slew rate, among other practical limitations.

17. Where are integrators used?

Analog computing, ramp generation, waveform generation, signal processing and control systems.

18. What is the difference between an integrator and a differentiator?

An integrator accumulates the input over time; a differentiator produces an output proportional to the input's rate of change.

  7. Explain why the output of an integrator can saturate even when the input is nearly zero.
Show answers

  2. Slope=−0.5/(0.5)=−1 V/s.
  3. τ=220000×4.7×10⁻⁶=1.034 s.
  4. fc≈15.9 Hz.
  5. Output change=−(−1/0.5)×2=+4 V.
  6. It provides a DC feedback path and limits low-frequency gain.
  7. Input offset voltage and bias current can gradually charge the capacitor.

20. Lecture Summary

  • An op-amp integrator uses an input resistor and a feedback capacitor.
  • The ideal output is the negative time integral of the input.
  • The output slope is −Vin/(RC).
  • A constant input produces a ramp output.
  • A symmetrical square wave produces an approximately triangular output.
  • A practical integrator uses a resistor in parallel with the feedback capacitor.
  • Offset voltage, bias current, slew rate and output swing affect practical operation.
  • RC determines the integration coefficient and ramp slope.
