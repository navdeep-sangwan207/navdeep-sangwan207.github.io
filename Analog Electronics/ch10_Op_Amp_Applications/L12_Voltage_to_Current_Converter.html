Lesson 12: Voltage-to-Current Converter

Analog Electronics | Chapter 10: Op-Amp Applications

Understand how an operational amplifier converts an input voltage into a proportional output current.

1. Learning Objectives

  • Understand the concept of voltage-to-current conversion.
  • Explain the working principle of an op-amp current source.
  • Understand the role of the sensing resistor.
  • Derive the output current equation.
  • Differentiate between floating-load and grounded-load converters.
  • Identify practical applications.

2. Introduction

A Voltage-to-Current Converter is an electronic circuit that converts an input voltage into a proportional output current.

It is also known as a voltage-controlled current source. An operational amplifier can be used to maintain a controlled current through a load.

Output Current:

Iout ∝ Vin

The output current is determined by the input voltage and the value of a sensing resistor in the circuit.

3. Basic Voltage-to-Current Converter

A common op-amp voltage-to-current converter uses a sensing resistor in the feedback path.

Important: This is a conceptual floating-load current-source arrangement. The load is placed in the feedback path, and the op-amp adjusts its output voltage to maintain the required current. The actual current direction and polarity depend on the selected input polarity and supply rails.

4. Working Principle

  1. An input voltage is applied to the non-inverting input.
  2. Negative feedback causes the inverting input voltage to approximately follow the non-inverting input voltage.
  3. The sensing resistor develops a voltage corresponding to the required current.
  4. The op-amp adjusts its output voltage to maintain this condition.
  5. As a result, the load current is controlled by the input voltage.

In the ideal closed-loop condition, the op-amp maintains a small voltage difference between its two input terminals.

5. Mathematical Derivation

Consider a current-source configuration in which the voltage across the sensing resistor Rs is equal to the applied control voltage Vin.

Using Ohm's law:

V = I × R

Vin = Iout × Rs

Therefore:

Iout = Vin / Rs

This is the basic relationship for the ideal voltage-controlled current source.

  • Vin = Input control voltage in volts
  • Rs = Sensing resistance in ohms
  • Iout = Output current in amperes

6. Effect of Input Voltage

The output current changes proportionally with the input voltage, provided the circuit remains within its operating limits.

Input Voltage Sensing Resistor Output Current
1 V 1 kΩ 1 mA
2 V 1 kΩ 2 mA
3 V 1 kΩ 3 mA
4 V 1 kΩ 4 mA
The table assumes an ideal converter with sufficient output-voltage compliance and no current limiting.

7. Numerical Example

Given:

  • Input voltage Vin = 2 V
  • Sensing resistor Rs = 1 kΩ

Step 1: Apply the current equation

Iout = Vin / Rs

Iout = 2 / 1000

Iout = 0.002 A

Step 2: Convert into milliamperes

Iout = 2 mA

Final Answer: Output current = 2 mA.

8. Floating-Load and Grounded-Load Converters

1. Floating-Load Converter

In a floating-load converter, the load is not directly connected to ground. The load is usually placed in the feedback path of the op-amp circuit.

2. Grounded-Load Converter

A grounded-load converter is designed so that one terminal of the load is connected to ground. A suitable op-amp circuit senses the load current and adjusts its output to maintain the required value.

Grounded-load current sources require a different circuit arrangement from the basic floating-load configuration. The simple equation Iout = Vin/Rs applies when the circuit forces Vin across Rs.

9. Current Source Characteristics

An ideal current source supplies constant current regardless of the load resistance, as long as the required voltage is available.

Important Characteristics

  • Output current is controlled by input voltage.
  • Load current should remain nearly constant over the operating range.
  • The op-amp output voltage changes according to load requirements.
  • The circuit has a limited compliance-voltage range.
Ideal Output Resistance → Infinite

Output Current → Constant

10. Practical Limitations

  • Output voltage swing: The op-amp cannot generate unlimited output voltage.
  • Load resistance: A large load resistance may require more output voltage than the op-amp can provide.
  • Output current limit: The op-amp has a maximum current capability.
  • Resistor tolerance: Sensing-resistor variations affect current accuracy.
  • Input offset voltage: Offset can produce current errors.
  • Temperature: Component temperature coefficients can affect accuracy.

11. Applications

  • LED drivers: Provides controlled LED current within the circuit's operating limits.
  • Industrial instrumentation: Used in voltage-controlled current interfaces.
  • Sensor excitation: Supplies controlled current to suitable sensors.
  • Battery charging circuits: Used in current-control stages.
  • Analog signal processing: Converts voltage signals into current signals.
  • Transmitter circuits: Forms part of voltage-to-current interface designs.

12. Advantages and Limitations

Advantages

  • Simple voltage-controlled current relationship.
  • Can provide controlled load current.
  • Useful in sensor and instrumentation circuits.
  • Can be designed for different current ranges.

Limitations

  • Limited by op-amp output current capability.
  • Limited by available output-voltage swing.
  • Current accuracy depends on resistor accuracy and op-amp errors.
  • Some configurations require a floating load.

13. Interview Questions

Q1. What is a voltage-to-current converter?

It is a circuit that converts an input voltage into a proportional output current.

Q2. What is another name for a voltage-to-current converter?

Voltage-controlled current source.

Q3. What is the basic output current equation?

Iout = Vin/Rs, for the basic sensing-resistor arrangement.

Q4. What is the function of the sensing resistor?

It converts the controlled voltage into a measurable current according to Ohm's law.

Q5. What is a floating load?

A load that is not directly connected to ground.

Q6. What is compliance voltage?

It is the available voltage range over which the current source can maintain the required current.

Q7. Why can the output current become inaccurate?

Due to resistor tolerances, op-amp offset voltage, output limitations, and temperature variations.

Q8. Give two applications of a voltage-to-current converter.

LED current control and industrial instrumentation interfaces.

15. Summary

  • A voltage-to-current converter converts input voltage into output current.
  • It is also called a voltage-controlled current source.
  • The basic current relationship is Iout = Vin/Rs.
  • The sensing resistor determines the current scale.
  • Op-amp output swing and current capability limit practical operation.
  • Floating-load and grounded-load converters use different circuit arrangements.
  • Applications include LED drivers, instrumentation, and sensor interfaces.
