Lesson 13: Current-to-Voltage Converter

Analog Electronics | Chapter 10: Op-Amp Applications

Understand how an operational amplifier converts an input current into a proportional output voltage.

1. Learning Objectives

  • Understand the concept of current-to-voltage conversion.
  • Explain the working principle of a transimpedance amplifier.
  • Understand the role of the feedback resistor.
  • Derive the output voltage equation.
  • Understand photodiode signal conditioning.
  • Identify practical applications and limitations.

2. Introduction

A Current-to-Voltage Converter is an electronic circuit that converts an input current into a proportional output voltage.

It is commonly implemented using an operational amplifier with a feedback resistor. This circuit is also called a Transimpedance Amplifier (TIA).

Output Voltage ∝ Input Current

Vout = -Iin × Rf

The negative sign indicates that the output voltage is inverted relative to the direction of the input current as defined in the circuit.

3. Basic Current-to-Voltage Converter Circuit

The input current is applied to the inverting terminal of the op-amp. A feedback resistor Rf connects the output to the inverting terminal. The non-inverting terminal is grounded.

The circuit uses negative feedback through Rf. The inverting input is maintained near virtual ground when the op-amp operates within its linear range.

4. Working Principle

  1. The non-inverting terminal is connected to ground.
  2. Negative feedback keeps the inverting terminal approximately at zero volts.
  3. The input current flows through the feedback resistor because the ideal op-amp input current is approximately zero.
  4. A voltage develops across the feedback resistor.
  5. The op-amp adjusts its output voltage to maintain the virtual-ground condition.

Therefore, the input current is converted into an output voltage across the feedback resistor.

5. Mathematical Derivation

Using Kirchhoff's Current Law at the inverting input:

For an ideal op-amp, input current into the inverting terminal is approximately zero.

Iin = If

If = (0 - Vout) / Rf

Rearranging:

Iin = -Vout / Rf

Vout = -Iin × Rf

Where:

  • Vout = Output voltage in volts
  • Iin = Input current in amperes
  • Rf = Feedback resistance in ohms

6. Effect of Feedback Resistance

The feedback resistor determines the conversion gain of the transimpedance amplifier.

Transimpedance Gain = Vout / Iin = -Rf
Input Current Feedback Resistor Output Voltage
1 µA 100 kΩ -0.1 V
2 µA 100 kΩ -0.2 V
5 µA 100 kΩ -0.5 V
10 µA 100 kΩ -1.0 V

Increasing Rf increases the magnitude of the output voltage for the same input current.

7. Numerical Example

Given:

  • Input current Iin = 5 µA
  • Feedback resistor Rf = 200 kΩ

Step 1: Apply the equation

Vout = -Iin × Rf

Step 2: Substitute the values

Vout = -(5 × 10⁻⁶) × (200 × 10³)

Vout = -1 V

Final Answer: Output voltage = -1 V.

8. Photodiode Application

One of the most important applications of a current-to-voltage converter is photodiode signal conditioning.

A photodiode produces a current that depends on the incident light intensity. This current is generally small and may be difficult to measure directly using ordinary voltage-measuring circuits.

A transimpedance amplifier converts this small photodiode current into a measurable voltage.

Working

  1. Light falls on the photodiode.
  2. The photodiode generates a photocurrent.
  3. The current enters the op-amp summing node.
  4. The feedback resistor converts the current into voltage.
  5. The output voltage is processed by the next circuit stage or ADC.
Vout = -Iphotodiode × Rf
Photodiode circuits may also use a feedback capacitor in parallel with Rf to improve stability and control high-frequency noise. The exact design depends on photodiode capacitance and required bandwidth.

9. Practical Considerations

  • Feedback resistance: Determines the current-to-voltage conversion gain.
  • Feedback capacitance: Helps control bandwidth and stability.
  • Input bias current: Can create output-voltage errors, especially for very small input currents.
  • Input offset voltage: Produces measurement errors.
  • Noise: Resistor thermal noise and op-amp noise affect sensitivity.
  • Output swing: The output cannot exceed the op-amp's available voltage range.
  • Bandwidth: Depends on the op-amp, feedback components, and input capacitance.

10. Applications

  • Photodiode amplifiers: Converts photocurrent into voltage.
  • Optical communication: Processes signals from photodetectors.
  • Light measurement: Used in light-intensity measurement equipment.
  • Instrumentation: Converts sensor currents into voltage signals.
  • Radiation detection: Used with suitable current-output detectors.
  • Electrochemical sensors: Measures small currents generated by sensor reactions.

11. Advantages and Limitations

Advantages

  • Converts very small currents into measurable voltages.
  • Provides a useful interface between current-output sensors and voltage-based circuits.
  • Conversion gain can be adjusted using the feedback resistor.
  • Suitable for precision measurement applications when properly designed.

Limitations

  • Noise can affect low-current measurements.
  • High feedback resistance can reduce bandwidth.
  • Input capacitance can affect stability.
  • Op-amp offset and bias currents can cause errors.

12. Interview Questions

Q1. What is a current-to-voltage converter?

It is a circuit that converts an input current into a proportional output voltage.

Q2. What is another name for this circuit?

Transimpedance amplifier.

Q3. What is the output voltage equation?

Vout = -Iin × Rf.

Q4. What is the function of the feedback resistor?

It converts the input current into a proportional output voltage and provides negative feedback.

Q5. What is virtual ground?

It is a point maintained approximately at ground potential by negative feedback, even though it is not directly connected to ground.

Q6. Why is a transimpedance amplifier used with a photodiode?

A photodiode generates current, and the amplifier converts this current into a measurable voltage.

Q7. What happens when feedback resistance increases?

The output-voltage magnitude increases for the same input current, but bandwidth and stability must also be considered.

Q8. Why is a feedback capacitor sometimes added?

It can improve stability and limit high-frequency noise and bandwidth.

14. Summary

  • A current-to-voltage converter converts input current into output voltage.
  • It is also known as a transimpedance amplifier.
  • The basic output equation is Vout = -Iin × Rf.
  • The feedback resistor determines conversion gain.
  • Virtual ground is maintained at the inverting input under normal closed-loop operation.
  • Photodiode signal conditioning is a major application.
  • Noise, bandwidth, stability, and output swing are important design considerations.
