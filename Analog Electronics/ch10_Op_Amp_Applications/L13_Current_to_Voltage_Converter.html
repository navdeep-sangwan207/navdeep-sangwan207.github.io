2. What Is a Current-to-Voltage Converter?

A current-to-voltage converter produces an output voltage proportional to an input current. It is commonly called a transimpedance amplifier (TIA).

Vout = −Iin × Rf

For the conventional inverting TIA, the non-inverting input is grounded and the input current enters the inverting summing node. Negative feedback keeps that node near virtual ground.

Input

Small current from a photodiode, sensor or current-output device.

Conversion

An op-amp and feedback resistor convert current into voltage.

Output

A voltage signal suitable for measurement or further signal processing.

3. Basic Op-Amp Transimpedance Amplifier

The feedback resistor connects the op-amp output to its inverting input. The input current flows into the summing node and, ideally, through the feedback resistor.

Working principle

  1. The non-inverting input is connected to ground.
  2. Negative feedback holds the inverting input close to virtual ground, provided the amplifier operates linearly.
  3. The input current flows through the feedback resistor.
  4. The op-amp output moves to establish the voltage required across the feedback resistor.
  5. The output voltage is proportional to the input current.
Important: The virtual-ground node is not a physical ground connection. It is maintained near ground potential by negative feedback under valid operating conditions.

4. Derivation of the Output Voltage

Assume an ideal op-amp, zero input bias current, negative feedback and operation within the output voltage limits.

Since the non-inverting terminal is grounded:

V− ≈ V+ = 0 V

Applying Kirchhoff's Current Law at the inverting node:

Iin = If

Feedback current is:

If = (V− − Vout) / Rf

Substituting V− ≈ 0:

Iin = −Vout / Rf
Vout = −Iin × Rf

The negative sign indicates inversion: a positive current entering the inverting summing node produces a negative output voltage.

5. Role of Feedback Resistance

The feedback resistor determines the transimpedance gain, measured in ohms (V/A).

Transimpedance gain = Vout / Iin = −Rf

10 kΩ−0.1 V
100 kΩ−1 V
1 MΩ−10 V

A higher feedback resistance increases output sensitivity but also increases the risk of saturation and can affect bandwidth and noise.

6. Photodiode Current-to-Voltage Converter

A photodiode produces a current related to incident light. A TIA converts this small current into a voltage that can be measured by an ADC or other electronic circuit.

Photodiode operating modes

Photovoltaic mode

Photodiode operates without external reverse bias. It can provide low-noise operation in suitable applications.

Photoconductive mode

Photodiode is reverse biased. This can improve response speed and reduce junction capacitance, depending on the device and operating point.

The photodiode polarity and current direction must be selected so that the required output polarity is obtained without forcing the op-amp into saturation.

7. Feedback Capacitor and Stability

A practical TIA often uses a small feedback capacitor Cf in parallel with Rf. The capacitor compensates for input and photodiode capacitance and can improve stability.

Zf(s) = Rf / (1 + sRfCf)

For this simple feedback network, the feedback impedance magnitude falls as frequency increases.

fc = 1 / (2πRfCf)

This is the pole frequency of the feedback network alone. It is not necessarily the complete TIA bandwidth; actual bandwidth and stability depend on op-amp gain-bandwidth, input capacitance, feedback network and layout.

Do not select Cf only from the desired cutoff frequency. Use the op-amp datasheet and a TIA stability calculation or simulation, accounting for total input capacitance.

8. Bandwidth and Noise Considerations

  • Increasing Rf increases transimpedance gain but generally reduces bandwidth for a given capacitance.
  • Photodiode junction capacitance contributes to the total input capacitance.
  • Op-amp input capacitance and PCB stray capacitance also affect stability.
  • Feedback-resistor thermal noise increases with resistance and temperature.
  • Op-amp input voltage noise can be converted into output noise by the circuit's frequency-dependent noise gain.
  • Low input bias current is important when measuring very small currents.
  • Low input offset voltage helps reduce output offset and error.

9. Output Saturation and Dynamic Range

The output must remain within the op-amp's permitted output swing. For the ideal inverting TIA:

|Vout| = |Iin| × Rf

Therefore, a simplified maximum input current before output saturation is:

Imax ≈ |Vout,max| / Rf

Use the actual output swing under the intended load, not simply the supply rail voltage.

Example

If the available linear output magnitude is 8 V and Rf=200 kΩ:

Imax ≈ 8 / 200000 = 40 µA
Approximate maximum input current = 40 µA.

12. Worked Numerical Examples

Example 1: Output Voltage

Given Iin=20 µA and Rf=100 kΩ:

Vout = −20×10⁻⁶ × 100×10³ = −2 V

Example 2: Feedback Resistor

Required output magnitude is 3 V for a 15 µA input current:

Rf = |Vout| / Iin = 3 / 15×10⁻⁶ = 200 kΩ

Example 3: Feedback Resistor Power

For 50 µA input current and 100 kΩ feedback resistance:

PRf = I²Rf = (50×10⁻⁶)² × 100×10³ = 0.25 mW

14. Practical Design Workflow

  1. Determine the minimum and maximum sensor current.
  2. Choose the required output voltage range.
  3. Calculate an initial feedback resistance using Rf=|Vout|/Iin.
  4. Check output swing, input common-mode range and supply requirements.
  5. Choose an op-amp with suitable input bias current, offset voltage, voltage noise and gain-bandwidth.
  6. Estimate total input capacitance, including sensor and PCB capacitance.
  7. Determine whether a feedback capacitor is required for stability.
  8. Check bandwidth, noise and saturation over the full signal range.
  9. Build and test the circuit with a controlled input-current source or sensor.
  10. Verify response using an oscilloscope and precision measurement equipment.

15. Laboratory Experiment

Objective

Study the conversion of a small input current into an output voltage using a transimpedance amplifier.

Components

  • Op-amp suitable for the selected supply and input-current range.
  • Feedback resistors of suitable values.
  • Optional feedback capacitor selected for stability.
  • Photodiode or a safe, controlled low-current test source.
  • Regulated supply, multimeter and oscilloscope.

Procedure

  1. Build the TIA using a verified schematic and observe the op-amp pinout.
  2. Connect the non-inverting input to the appropriate reference.
  3. Connect the feedback resistor between output and inverting input.
  4. Connect the photodiode with the intended polarity.
  5. Apply a controlled light level to the photodiode.
  6. Measure the output voltage.
  7. Change the light level and record the output change.
  8. Repeat with a different feedback resistance.
  9. Compare the measured transimpedance with the theoretical value.
  10. Observe noise, response time and any signs of oscillation.

17. Placement-Oriented Interview Questions

1. What is a current-to-voltage converter?

A circuit that converts an input current into a proportional output voltage.

2. What is a transimpedance amplifier?

An amplifier whose input is current and output is voltage, typically implemented using an op-amp and feedback resistor.

3. What is the ideal TIA equation?

Vout=−IinRf for the conventional inverting configuration and stated current direction.

4. What is transimpedance gain?

The ratio Vout/Iin, with units of ohms (V/A).

5. Why is the inverting input called a virtual ground?

Negative feedback holds it near the grounded non-inverting input voltage, even though it is not physically connected to ground.

6. Why is a feedback resistor used?

It converts input current into a proportional output voltage.

7. What happens when feedback resistance increases?

Transimpedance gain increases, but output saturation risk and bandwidth/noise trade-offs also increase.

8. Why is a photodiode connected to a TIA?

To convert its light-dependent current into a measurable voltage.

9. What is the purpose of the feedback capacitor?

It can improve stability and limit high-frequency response in the feedback network.

10. What is photodiode dark current?

The small current that flows in a photodiode even when no light is incident.

11. What causes TIA oscillation?

Excessive phase shift and inadequate phase margin due to feedback and input capacitances, among other factors.

12. Why is low input bias current important?

It reduces errors when measuring very small input currents.

13. What determines the maximum measurable current?

Feedback resistance and the available linear output voltage swing, along with other circuit limits.

14. What is the difference between a transconductance amplifier and a transimpedance amplifier?

A transconductance amplifier converts voltage to current; a transimpedance amplifier converts current to voltage.

15. Why does photodiode capacitance matter?

It affects bandwidth, noise gain and stability.

16. What is the unit of transimpedance gain?

Ohms, equivalent to volts per ampere.

17. What is the difference between photovoltaic and photoconductive operation?

Photovoltaic mode operates without external reverse bias, while photoconductive mode uses reverse bias.

18. How would you debug an output stuck at a rail?

Check supply connections, photodiode polarity, feedback continuity, input current and output swing limits.

18. Numerical Practice

  1. A TIA receives 5 µA with Rf=200 kΩ. Calculate its output voltage.
  2. Find Rf for an output magnitude of 4 V with an input current of 20 µA.
  3. Calculate the output voltage for 25 µA and 47 kΩ.
  4. A TIA has an available output magnitude of 9 V and Rf=300 kΩ. Estimate its maximum input current.
  5. Calculate feedback-resistor power for 30 µA through 100 kΩ.
  6. Explain how photodiode capacitance affects TIA stability.
  7. Explain the trade-off between feedback resistance and bandwidth.
Show answers
  1. Vout=−5×10⁻⁶×200×10³=−1 V.
  2. Rf=4/(20×10⁻⁶)=200 kΩ.
  3. Vout=−25×10⁻⁶×47×10³=−1.175 V.
  4. Imax≈9/(300×10³)=30 µA.
  5. P=(30×10⁻⁶)²×100×10³=90 µW.
  6. Photodiode capacitance adds to the amplifier input capacitance and changes the feedback loop's frequency response and phase margin.
  7. Higher feedback resistance increases transimpedance gain but generally makes bandwidth and stability more difficult to maintain.
