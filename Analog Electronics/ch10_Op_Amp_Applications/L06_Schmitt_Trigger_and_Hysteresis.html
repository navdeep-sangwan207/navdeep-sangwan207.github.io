2. Why is Hysteresis Required?

A basic comparator switches its output when the input crosses a reference voltage. If the input contains noise or changes slowly near the threshold, the output may switch repeatedly.

This repeated switching is called chattering.

Without hysteresis

A small amount of noise near the threshold can cause multiple output transitions.

With hysteresis

Separate rising and falling thresholds prevent unwanted repeated transitions.

A Schmitt trigger is a comparator circuit with positive feedback that creates two different switching thresholds.

3. What is a Schmitt Trigger?

A Schmitt trigger is a regenerative comparator. Its output is fed back to an input through a positive-feedback network. The feedback changes the effective reference voltage depending on the current output state.

The circuit has two thresholds:

  • Upper Trigger Point (UTP): Threshold for one direction of input transition.
  • Lower Trigger Point (LTP): Threshold for the opposite direction.
Hysteresis Width = UTP − LTP

4. Positive Feedback

Positive feedback means that a portion of the output is fed back in phase with the input or reinforces the existing output state.

In a Schmitt trigger, positive feedback makes the circuit switch decisively and establishes different thresholds for rising and falling input signals.

Positive feedback is intentionally used in a Schmitt trigger. It is not the same as unwanted positive feedback in a linear amplifier, where it can cause instability or oscillation.

5. Non-Inverting Schmitt Trigger

In the common non-inverting Schmitt trigger, the input signal is connected to the inverting terminal. The non-inverting terminal receives a feedback voltage from the output through a resistor divider.

For the standard divider arrangement between output and ground:

V+ = βVout
β = R2/(R1 + R2)

Here, R1 is connected from output to the non-inverting input, and R2 is connected from the non-inverting input to ground.

For symmetric output saturation levels of +Vsat and −Vsat:

UTP = +βVsat
LTP = −βVsat
VH = 2βVsat

When the input rises above UTP, the output switches LOW. When the input falls below LTP, the output switches HIGH.

This is an inverting Schmitt-trigger response because the signal is applied to the inverting terminal, even though the feedback divider is connected to the non-inverting terminal.

6. Inverting Schmitt Trigger – Switching Behavior

For the standard circuit described above, the output state depends on the previous state while the input lies between LTP and UTP.

UTP = +βVsat
LTP = −βVsat

7. General Threshold Design with a Reference Voltage

When the resistor divider is connected between the output and a reference voltage Vref rather than ground, the feedback-node voltage is:

Vthreshold = (R2 × Vout + R1 × Vref)/(R1 + R2)

In this arrangement, R1 connects the feedback node to Vout and R2 connects it to Vref.

Define:

β = R2/(R1 + R2)

Then:

Vthreshold = βVout + (1 − β)Vref

For output saturation levels VOH and VOL:

UTP = βVOH + (1 − β)Vref
LTP = βVOL + (1 − β)Vref
VH = β(VOH − VOL)
The threshold equations assume the output has settled to its high or low state and the input draws negligible current. Use actual output levels, not supply rails, for accurate design.

8. Hysteresis Transfer Characteristic

The transfer characteristic shows how output depends on input voltage. The switching threshold depends on the direction from which the input approaches.

The two transition paths form a hysteresis loop. The gap between the thresholds is the hysteresis width.

9. Worked Numerical Example

A Schmitt trigger uses R1 = 90 kΩ, R2 = 10 kΩ, and symmetric output saturation levels of ±12 V. The feedback node is connected to ground through R2.

Step 1: Calculate feedback factor.

β = 10/(90 + 10) = 0.1

Step 2: Calculate upper threshold.

UTP = 0.1 × 12 = +1.2 V

Step 3: Calculate lower threshold.

LTP = 0.1 × (−12) = −1.2 V

Step 4: Calculate hysteresis width.

VH = 1.2 − (−1.2) = 2.4 V
UTP = +1.2 V | LTP = −1.2 V | Hysteresis width = 2.4 V

13. Practical Applications

Switch Debouncing

Helps convert slow or noisy switch transitions into cleaner logic transitions.

Sensor Signal Conditioning

Prevents repeated switching when a sensor signal fluctuates near a threshold.

Waveform Shaping

Converts slowly changing waveforms into rectangular signals.

Battery Monitoring

Provides separate rising and falling voltage thresholds for battery-status detection.

Industrial Threshold Detection

Improves switching stability in noisy measurement environments.

Oscillator Circuits

Provides switching thresholds in relaxation oscillator designs.

14. Practical Design Procedure

  1. Determine the required upper and lower input switching thresholds.
  2. Select a comparator or op-amp suitable for the supply and input-voltage range.
  3. Obtain realistic output HIGH and LOW levels from the datasheet.
  4. Calculate the feedback factor using the threshold equations.
  5. Select resistor values while considering input bias current and loading.
  6. Check the hysteresis width against the expected noise amplitude.
  7. Verify switching frequency and propagation delay requirements.
  8. Check output compatibility with the load or digital logic input.
  9. Build and test the circuit using a current-limited supply.
For a noisy signal, hysteresis should be large enough to prevent unwanted transitions but not so large that valid signal changes are missed.

15. Practical Laboratory

Objective

Construct an inverting Schmitt trigger and observe its upper and lower switching thresholds.

Components

  • Comparator IC or suitable op-amp.
  • Two feedback resistors.
  • Regulated power supply.
  • Function generator.
  • Oscilloscope and multimeter.
  • Breadboard and connecting wires.

Procedure

  1. Read the device datasheet and verify its supply and input-voltage limits.
  2. Connect the input signal to the inverting input.
  3. Connect the output to the non-inverting input through R1.
  4. Connect the non-inverting input to ground through R2.
  5. Apply a suitable dual supply if required by the selected device.
  6. Apply a low-frequency triangular input signal.
  7. Increase the input slowly and record the rising switching threshold.
  8. Decrease the input and record the falling switching threshold.
  9. Calculate hysteresis width from the measured thresholds.
  10. Compare measured and calculated results.

Expected Result

The output switches at two different input voltages. Between the thresholds, the output retains its previous state.

Use a comparator with verified input common-mode range and output ratings. Do not connect a device output directly to a microcontroller or LED without checking its electrical compatibility.

17. Placement-Oriented Interview Questions

1. What is a Schmitt trigger?

A comparator with positive feedback that produces hysteresis.

2. What is hysteresis?

The difference between the upper and lower switching thresholds.

3. Why is positive feedback used?

To create regenerative switching and two distinct thresholds.

4. What is UTP?

Upper Trigger Point, the higher switching threshold.

5. What is LTP?

Lower Trigger Point, the lower switching threshold.

6. What is the hysteresis-width equation?

VH = UTP − LTP.

7. Why does a basic comparator chatter?

Noise near its threshold can repeatedly reverse the input comparison.

8. How does a Schmitt trigger improve noise immunity?

It requires the signal to cross a different threshold before changing the output in the opposite direction.

9. What is regenerative switching?

A rapid transition reinforced by positive feedback.

10. What happens between UTP and LTP?

The output retains its previous state.

11. What is the feedback factor?

The fraction of output voltage returned to the comparator input through the feedback network.

12. How can hysteresis width be increased?

Increase the feedback factor or the output voltage difference, subject to circuit constraints.

13. What is the difference between a comparator and a Schmitt trigger?

A Schmitt trigger has positive feedback and two switching thresholds.

14. What is a common application?

Noisy sensor threshold detection and switch debouncing.

15. Can a Schmitt trigger convert a sine wave into a square wave?

Yes, if the sine wave crosses both switching thresholds.

16. What determines the actual threshold voltages?

Feedback resistor ratios, reference voltage and actual output levels.

17. Why should output saturation be considered?

Actual output levels may not reach the supply rails, changing the thresholds.

18. What happens if hysteresis is too large?

The input may fail to cross both thresholds, preventing expected switching.

  4. For β=0.15, VOH=+9 V, VOL=−8 V and Vref=1 V, calculate UTP and LTP.
  5. Explain the output state behavior when the input remains between the two thresholds.
  6. Why should actual output saturation voltages be used in a practical design?
Show answers
  1. UTP=+2 V, LTP=−2 V, VH=4 V.
  2. VH=2.5−(−1.5)=4 V.
  3. β=10/(47+10)=0.1754 approximately.
  4. UTP=0.15×9+0.85×1=2.05 V; LTP=0.15×(−8)+0.85×1=−0.35 V.
  5. The output retains its previous state.
  6. Because real output levels depend on device characteristics and load conditions, not just supply voltage.

19. Lecture Summary

  • A Schmitt trigger is a comparator with positive feedback.
  • Positive feedback produces two switching thresholds.
  • UTP is the upper trigger point and LTP is the lower trigger point.
  • Hysteresis width is UTP minus LTP.
  • The output retains its state between the two thresholds.
  • Hysteresis improves immunity to noise near the switching threshold.
  • Actual output levels and resistor ratios determine practical thresholds.
  • Schmitt triggers are used in sensor interfaces, waveform shaping and switch debouncing.
