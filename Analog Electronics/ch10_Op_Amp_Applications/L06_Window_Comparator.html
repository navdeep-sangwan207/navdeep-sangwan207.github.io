Lesson 6: Window Comparator

Analog Electronics | Chapter 10: Op-Amp Applications

Understand how two comparators detect whether a signal is within a specified voltage range.

1. Learning Objectives

  • Understand the working principle of a window comparator.
  • Explain upper and lower reference voltage levels.
  • Understand the role of two comparators.
  • Analyze the output using a truth table.
  • Understand window detection circuits and applications.

2. Introduction

A Window Comparator is an electronic circuit used to determine whether an input voltage lies within a specified voltage range.

This circuit uses two comparators:

  • One comparator checks whether the input exceeds the lower threshold.
  • The other comparator checks whether the input is below the upper threshold.

The circuit produces an output indicating whether the input voltage is inside or outside the defined voltage window.

Lower Threshold < Vin < Upper Threshold

VL < Vin < VU

3. Basic Block Diagram

The two comparator outputs are combined using logic circuitry. An AND gate is used in this conceptual arrangement when both comparator outputs are HIGH inside the voltage window.

The comparator input connections and output polarities must be selected correctly to obtain the required window-detection logic.

4. Circuit Configuration

Consider a window comparator with:

  • Lower reference voltage = VL
  • Upper reference voltage = VU
  • Input voltage = Vin

The lower comparator produces a HIGH output when:

Vin > VL

The upper comparator produces a HIGH output when:

Vin < VU

Both conditions must be satisfied for the input to be inside the voltage window.

Window Output = (Vin > VL) AND (Vin < VU)

5. Working Principle

Case 1: Input Below the Lower Threshold

When Vin is less than VL, the lower comparator condition is not satisfied. The window output becomes LOW.

Vin < VL → Output = LOW

Case 2: Input Inside the Voltage Window

When Vin is greater than VL and less than VU, both comparator conditions are satisfied.

VL < Vin < VU → Output = HIGH

Case 3: Input Above the Upper Threshold

When Vin is greater than VU, the upper comparator condition is not satisfied. The window output becomes LOW.

Vin > VU → Output = LOW

6. Truth Table

Input Condition Lower Comparator Upper Comparator Window Output
Vin < VL LOW HIGH LOW
VL < Vin < VU HIGH HIGH HIGH
Vin > VU HIGH LOW LOW
This table assumes comparator outputs are HIGH when their respective input conditions are satisfied. At the exact threshold voltages, real switching behavior depends on comparator offset, noise, and any hysteresis.

7. Voltage Window Example

Consider a window comparator designed with:

Lower Threshold: VL = 3 V

Upper Threshold: VU = 7 V

The circuit should produce a HIGH output when the input voltage is between 3 V and 7 V.

Input Voltage Condition Output
1 V Below 3 V LOW
4 V Inside 3–7 V HIGH
5 V Inside 3–7 V HIGH
8 V Above 7 V LOW

The shaded region represents the acceptable input voltage range. Outside this region, the window output is LOW.

9. Applications

  • Voltage monitoring: Checks whether a supply voltage remains within safe limits.
  • Battery monitoring: Detects under-voltage and over-voltage conditions.
  • Power supplies: Monitors output voltage regulation.
  • Temperature monitoring: Detects whether a sensor voltage is within an acceptable range.
  • Industrial control: Detects whether process signals remain within specified limits.
  • Protection circuits: Generates fault signals when voltage exceeds permitted limits.
  • Sensor systems: Identifies whether an analog sensor output is within a valid operating range.

10. Advantages and Limitations

Advantages

  • Detects both under-voltage and over-voltage conditions.
  • Uses a simple two-comparator arrangement.
  • Provides a clear logic output for range detection.
  • Useful in monitoring and protection systems.

Limitations

  • Requires two comparators.
  • Threshold accuracy depends on reference voltage accuracy and comparator offset.
  • No inherent hysteresis unless additional feedback is provided.
  • Noise near threshold voltages may cause unwanted switching.

11. Practical Design Considerations

  • Choose accurate reference voltage sources for VL and VU.
  • Ensure VL is lower than VU.
  • Check comparator input common-mode voltage range.
  • Check output voltage compatibility with the following digital circuit.
  • Use pull-up resistors when required by open-collector or open-drain comparator outputs.
  • Add hysteresis if the input is noisy around either threshold.
  • Use suitable filtering and decoupling to reduce unwanted switching.
A window comparator is a voltage-range detector. It does not automatically provide over-voltage or under-voltage protection; additional control circuitry may be needed to disconnect or limit the load.

12. Interview Questions

Q1. What is a window comparator?

A window comparator is a circuit that determines whether an input voltage lies between two reference voltages.

Q2. How many comparators are used?

Two comparators are normally used.

Q3. What are the upper and lower thresholds?

They define the maximum and minimum voltage limits of the acceptable input range.

Q4. When is the window output HIGH?

When the input voltage is greater than the lower threshold and less than the upper threshold.

Q5. What happens when the input exceeds the upper threshold?

The window output becomes LOW in the described configuration.

Q6. What is the difference between a comparator and a window comparator?

A basic comparator compares an input against one reference voltage, while a window comparator checks whether the input lies within a range defined by two references.

Q7. Can a window comparator be used for battery protection?

Yes. It can detect whether battery voltage is within specified limits and generate a fault or control signal.

Q8. How can unwanted switching near the thresholds be reduced?

By adding hysteresis, filtering, or suitable input conditioning.

14. Summary

  • A window comparator detects whether an input voltage lies within a specified range.
  • It normally uses two comparators.
  • The lower comparator checks whether Vin exceeds VL.
  • The upper comparator checks whether Vin is below VU.
  • The output is HIGH when both conditions are satisfied.
  • It is widely used in voltage monitoring, battery monitoring, and protection systems.
  • Hysteresis can improve noise immunity near threshold voltages.
