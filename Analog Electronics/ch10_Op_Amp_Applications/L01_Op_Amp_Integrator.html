2. Introduction to Op-Amp Integrator

An operational amplifier integrator is an analog circuit that produces an output voltage proportional to the time integral of the input voltage.

It is constructed using an operational amplifier, an input resistor and a feedback capacitor.

The integrator is commonly used in waveform generation, analog computation, signal processing and control systems.

Output voltage ∝ Integral of input voltage

3. Op-Amp Integrator Circuit Diagram

The basic inverting integrator consists of:

  • Input resistor (R)
  • Feedback capacitor (C)
  • Operational amplifier
  • Non-inverting terminal connected to ground
Important: This is an idealized conceptual circuit. A practical integrator commonly uses a resistor in parallel with the feedback capacitor to limit DC gain.

4. Working Principle

The input voltage is applied to the inverting terminal through resistor R. The capacitor C is connected between the output and inverting terminal.

  1. The non-inverting terminal is grounded.
  2. Negative feedback maintains the inverting terminal near virtual ground, within the linear operating region.
  3. The input voltage produces current through resistor R.
  4. Since the op-amp input current is approximately zero, this current flows through the feedback capacitor.
  5. The capacitor accumulates charge, causing the output voltage to change with time.

Therefore, the output voltage represents the negative time integral of the input voltage.

5. Mathematical Derivation

For an ideal op-amp operating with negative feedback:

V− ≈ V+ = 0 V

Input current through resistor R:

IR = (Vin − 0) / R

Current through the feedback capacitor:

IC = C × d(V− − Vout)/dt

Since V− is approximately zero:

IC = −C × dVout/dt

Applying Kirchhoff's Current Law at the inverting node:

Vin/R = −C × dVout/dt

Rearranging:

dVout/dt = −Vin/(RC)

Integrating both sides:

Vout(t) = −1/(RC) ∫ Vin(t) dt + Vout(0)

Here, Vout(0) is the initial output voltage determined by the initial capacitor voltage.

Final Output Equation

Vout(t) = −1/(RC) ∫₀ᵗ Vin(τ) dτ + Vout(0)

If the initial capacitor voltage is zero, the initial output voltage is also zero.

6. Input and Output Waveforms

Case 1: Constant DC Input

When a constant positive voltage is applied, the output decreases linearly with time, provided the amplifier remains within its output voltage limits.

Vout = −(Vin/RC)t + Vout(0)

Case 2: Square-Wave Input

A symmetrical square-wave input produces a triangular output waveform under ideal integration conditions.

Case 3: Sine-Wave Input

A sinusoidal input produces a sinusoidal output with a phase shift of 90 degrees. For an ideal inverting integrator, the output leads the input by 90 degrees.

Vin = Vm sin(ωt)
Vout = (Vm/ωRC) cos(ωt)

The output amplitude decreases as the input frequency increases.

7. Practical Op-Amp Integrator

An ideal integrator has extremely high gain at DC. Even a small input offset voltage or bias current can charge the feedback capacitor and drive the output into saturation.

To overcome this problem, a resistor Rf is connected in parallel with the feedback capacitor.

  • It provides a DC feedback path.
  • It limits the low-frequency gain.
  • It reduces unwanted output saturation caused by offsets.
  • It makes the circuit more stable in practical operation.

Low-Frequency Cutoff

fL = 1/(2πRfC)

Above the low-frequency transition region, the circuit behaves approximately as an integrator over its useful operating frequency range.

The practical integrator does not perform ideal integration at all frequencies. Its response depends on R, Rf, C and the op-amp's bandwidth.

8. Applications of Op-Amp Integrator

  • Analog computers and mathematical computation.
  • Ramp and triangular waveform generation.
  • Signal processing circuits.
  • Active filter circuits.
  • Control systems and PID controllers.
  • Measurement and instrumentation systems.

9. Advantages and Limitations

Advantages

  • Performs mathematical integration electronically.
  • Useful for waveform generation.
  • Can process continuous analog signals.
  • Simple circuit using a resistor and capacitor.

Limitations

  • Ideal integrators are sensitive to DC offsets.
  • Output can saturate due to accumulated errors.
  • Practical performance is limited by op-amp bandwidth.
  • Component tolerances affect circuit accuracy.

10. Numerical Example

Question:

An ideal op-amp integrator has R = 100 kΩ and C = 0.1 μF. A constant input voltage of +2 V is applied for 10 ms. Find the output voltage, assuming zero initial output voltage.

Given

  • R = 100 kΩ = 100 × 10³ Ω
  • C = 0.1 μF = 0.1 × 10⁻⁶ F
  • Vin = +2 V
  • t = 10 ms = 0.01 s

Solution

Vout = −(Vin × t)/(RC)
RC = 100 × 10³ × 0.1 × 10⁻⁶
RC = 0.01 seconds
Vout = −(2 × 0.01)/0.01

Final Answer

Vout = −2 V

11. Placement-Oriented Interview Questions

Q1. What is an op-amp integrator?

It is an operational amplifier circuit whose output voltage is proportional to the negative time integral of its input voltage.

Q2. Which component is used in the feedback path?

A capacitor is used in the feedback path of an ideal integrator.

Q3. What is the output of an integrator for a square-wave input?

It produces a triangular waveform for a symmetrical square-wave input.

Q4. Why is the output negative?

Because the basic integrator is an inverting op-amp configuration.

Q5. Why is a resistor connected in parallel with the capacitor in a practical integrator?

It provides DC feedback, limits low-frequency gain and helps prevent output saturation.

Q6. What happens when a constant positive input is applied?

The output decreases linearly with time until it reaches an output voltage limit or the input changes.

Q7. What is the phase relationship for a sinusoidal input?

The ideal integrator output leads the input by 90 degrees.
