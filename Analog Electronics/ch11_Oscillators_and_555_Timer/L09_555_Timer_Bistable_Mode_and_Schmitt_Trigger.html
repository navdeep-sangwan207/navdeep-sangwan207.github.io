2. What Is a Bistable Multivibrator?

A bistable multivibrator is a circuit with two stable output states. It remains in its present state until an external control signal causes it to change state.

State 1 – SET

Output HIGH. The internal latch is set.

State 2 – RESET

Output LOW. The internal latch is reset.

Unlike a monostable circuit, a bistable circuit does not automatically return to its previous state after a fixed time. Unlike an astable circuit, it does not continuously oscillate.

ModeStable statesOperation
MonostableOneOne timed pulse after a trigger
AstableNoneContinuous oscillation
BistableTwoState retained until another control event

3. Internal 555 Latch and Comparator Operation

The 555 contains two comparators connected to an internal SR latch. The lower comparator responds to the trigger input and the upper comparator responds to the threshold input.

Comparator conditions

Trigger below 1/3 VCCSET latchHIGH

Neither threshold crossedRetain previous stateNo change
RESET pin LOWExternal reset overrides normal operationLOW
Simultaneous conditions: If trigger and threshold conditions are both active, the internal comparator/latch interaction must be considered. Do not assume both commands can be applied without conflict. For a clean external bistable design, use properly conditioned SET and RESET inputs and avoid simultaneous active commands.

4. 555 Bistable Circuit Using SET and RESET Inputs

A bistable circuit can use the trigger comparator as SET and the threshold comparator as RESET. The two inputs are controlled independently.

  • Pressing the RESET button raises pin 6 above 2/3 VCC and makes the output LOW.
  • Releasing the RESET button leaves the output LOW until another SET event.

6. What Is a Schmitt Trigger?

A Schmitt trigger is a comparator circuit with positive feedback that creates two different switching thresholds. It converts a slowly changing or noisy input into a clean digital-like output.

The two switching thresholds are:

Upper threshold (VUT) = 2/3 VCC
Lower threshold (VLT) = 1/3 VCC

For the standard 555 configuration with pins 2 and 6 connected together, the input is compared against both thresholds.

Input rising

When input rises above 2/3 VCC, output switches LOW.

Input falling

When input falls below 1/3 VCC, output switches HIGH.

Input between thresholds

Output retains its previous state.

7. Schmitt Trigger Circuit Using a 555

Connect the trigger and threshold pins together and apply the input signal to this common node.

How it works

  1. When input voltage is below 1/3 VCC, the lower comparator sets the latch and output becomes HIGH.
  2. As input rises, the output remains HIGH while input is between the two thresholds.
  3. When input exceeds 2/3 VCC, the upper comparator resets the latch and output becomes LOW.
  4. As input falls, the output remains LOW until input falls below 1/3 VCC.
  5. The cycle repeats as the input rises and falls.

8. Hysteresis and Hysteresis Width

Hysteresis is the difference between the upper and lower switching thresholds.

VH = VUT − VLT

For a standard 555 Schmitt trigger:

VH = 2/3 VCC − 1/3 VCC

VH = VCC/3

Example

For VCC = 9 V:

  • Upper threshold = 2/3 × 9 = 6 V.
  • Lower threshold = 1/3 × 9 = 3 V.
  • Hysteresis width = 6 − 3 = 3 V.
Hysteresis width = 3 V

12. Why Is Hysteresis Important?

Without hysteresis, a slowly varying or noisy input near a single switching threshold can cause rapid output transitions. This is called chatter or multiple switching.

Hysteresis creates a voltage band between two switching points. Small input disturbances inside this band do not change the output state.

Without hysteresis

Noise near the threshold can cause repeated switching and unstable output.

With hysteresis

The input must cross the opposite threshold before the output changes state again.

Applications

  • Switch debouncing and signal conditioning.
  • Slow sensor signal conversion into clean logic transitions.
  • Noise-resistant threshold detection.
  • Wave shaping and square-wave generation.
  • Battery voltage monitoring and threshold alarms.
  • Interface circuits between analogue sensors and digital logic.

13. Worked Numerical Problems

Example 1: Calculate Schmitt trigger thresholds

A 555 Schmitt trigger operates from a 15 V supply.

Upper threshold = 2/3 × 15 = 10 V.

Lower threshold = 1/3 × 15 = 5 V.

VUT = 10 V, VLT = 5 V
VH = 10 − 5 = 5 V

Example 2: Determine output state

For VCC = 9 V, input rises from 2 V to 5 V.

  • At 2 V, input is below 3 V. Output becomes HIGH.
  • At 5 V, input is between 3 V and 6 V.
  • Output remains HIGH because the upper threshold has not been crossed.
Final output = HIGH

Example 3: Falling input

For VCC = 9 V, assume the output is LOW and the input falls from 8 V to 4 V.

  • At 8 V, input is above 6 V. Output is LOW.
  • At 4 V, input is between 3 V and 6 V.
  • Output remains LOW because the lower threshold has not been crossed.
Final output = LOW

14. Practical Lab – Bistable and Schmitt Trigger

Experiment A: Bistable operation

Objective: Demonstrate SET and RESET operation using a 555 timer.

Components

  • 555 timer IC
  • Regulated DC supply within the IC datasheet limits
  • Push buttons for SET and RESET
  • Pull-up or pull-down resistors as required by the input circuits
  • LED with current-limiting resistor or oscilloscope
  • 0.1 µF supply decoupling capacitor

Procedure

  1. Connect pin 1 to ground, pin 8 to VCC and pin 4 to VCC.
  2. Configure pin 2 as a normally HIGH input using a pull-up resistor.
  3. Use a push button to pull pin 2 LOW momentarily for SET.
  4. Configure pin 6 so it can be driven above 2/3 VCC for RESET.
  5. Apply the SET signal and observe pin 3 becoming HIGH.
  6. Apply the RESET signal and observe pin 3 becoming LOW.
  7. Release each input and verify that the output retains its state.
Do not leave pin 2 floating. Design the pin 6 reset input so it has a defined inactive level and can safely exceed the upper threshold when commanded. Avoid simultaneous SET and RESET commands. Verify the complete wiring against the selected IC datasheet before powering the circuit.

Experiment B: Schmitt trigger operation

Objective: Observe hysteresis using a 555 timer.

Procedure

  1. Connect pins 2 and 6 together.
  2. Apply a variable DC voltage to the common input node using a suitable current-limited source.
  3. Keep pin 4 HIGH and connect pin 1 to ground.
  4. Increase input voltage slowly from zero and record the output transition point.
  5. Decrease input voltage slowly and record the second transition point.
  6. Calculate the difference between the two switching voltages.

Expected result

These are nominal ideal threshold values. Actual switching levels depend on the timer variant and its electrical specifications.

16. Design Considerations

  • Input conditioning: Use suitable pull-up or pull-down resistors so inputs never float.
  • Noise: Keep input wiring short and use proper grounding and supply decoupling.
  • Input range: Ensure input voltage remains within the IC's permitted pin voltage limits.
  • Output drive: Use a transistor or MOSFET when controlling loads beyond the timer's output capability.
  • Threshold accuracy: Actual thresholds are approximate and vary with the timer variant and operating conditions.
  • Switch bounce: A mechanical switch may require additional debounce design.
  • Reset priority: Pin 4 is a separate active-LOW reset input. Its operation must be considered in addition to comparator-driven latch control.

17. Placement Interview Questions and Answers

1. What is a bistable multivibrator?

A circuit with two stable states that changes state when an appropriate control signal is applied.

2. How many stable states does a bistable circuit have?

Two.

3. Does a bistable multivibrator require a timing capacitor?

Not necessarily. Its state can be controlled by SET and RESET inputs without an external timing network.

4. What is a Schmitt trigger?

A comparator circuit with hysteresis, using two different switching thresholds.

5. What are the standard 555 Schmitt trigger thresholds?

Approximately 1/3 VCC and 2/3 VCC.

6. What is hysteresis?

The difference between the upper and lower switching thresholds.

7. Calculate hysteresis for a 12 V supply.

Upper = 8 V, lower = 4 V, hysteresis = 4 V.

8. Why is hysteresis useful?

It prevents unwanted repeated switching due to small noise variations near a threshold.

9. What happens when pin 2 falls below 1/3 VCC?

The lower comparator sets the latch and the output becomes HIGH.

10. What happens when pin 6 rises above 2/3 VCC?

The upper comparator resets the latch and the output becomes LOW.

11. What is the difference between pin 4 reset and pin 6 threshold reset?

Pin 4 is an external active-LOW reset input. Pin 6 is the upper comparator input and resets the latch when it exceeds approximately 2/3 VCC.

12. What happens when the Schmitt trigger input is between its two thresholds?

The output retains its previous state.

13. Why are two thresholds better than one for noisy signals?

Noise must cross the opposite threshold to cause another transition, reducing chatter.

14. What is the role of the internal SR latch?

It stores the current output state until a SET or RESET condition occurs.

15. Give applications of a Schmitt trigger.

Switch debouncing, sensor conditioning, waveform shaping and noise-resistant threshold detection.

16. Can a 555 Schmitt trigger convert a slow ramp into a square wave?

Yes. The output changes state when the ramp crosses the upper and lower thresholds.

17. What is the difference between a comparator and a Schmitt trigger?

A basic comparator has one switching threshold, while a Schmitt trigger has hysteresis and two switching thresholds.

18. Why should unused inputs not float?

Floating inputs can respond unpredictably to noise and cause unintended switching.
