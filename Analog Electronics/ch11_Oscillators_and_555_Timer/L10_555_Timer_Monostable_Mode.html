2. What is Monostable Mode?

In monostable mode, the 555 timer has one stable state and one quasi-stable state.

When a valid trigger pulse is applied, the output changes temporarily from LOW to HIGH. After a predetermined time, the output automatically returns to LOW.

Important: Monostable mode is also called one-shot mode because one valid trigger produces one output pulse.

3. Circuit Components

A standard 555 timer monostable circuit uses:

  • 555 timer IC.
  • Timing resistor R connected between VCC and the timing node.
  • Timing capacitor C connected between the timing node and ground.
  • Pin 6 (THRESHOLD) connected to the timing node.
  • Pin 7 (DISCHARGE) connected to the timing node.
  • Pin 2 (TRIGGER) receives the external negative-going trigger pulse.
  • Pin 4 (RESET) connected to VCC when reset is not required.
  • Pin 3 provides the output pulse.

4. Working Principle

Step 1: Stable State

  • Initially, the output at pin 3 is LOW.
  • The discharge transistor at pin 7 is ON.
  • The timing capacitor remains discharged.

Step 2: Trigger Input

  • A negative-going trigger pulse is applied to pin 2.
  • The trigger voltage falls below 1/3 VCC.
  • The lower comparator sets the internal latch.
  • The output becomes HIGH.
  • The discharge transistor turns OFF.

Step 3: Capacitor Charging

  • The capacitor begins charging through resistor R.
  • The capacitor voltage rises exponentially toward VCC.
  • The output remains HIGH during this interval.

Step 4: Threshold Reached

  • When the capacitor voltage reaches approximately 2/3 VCC, the upper comparator resets the latch.
  • The output becomes LOW.
  • The discharge transistor turns ON.
  • The capacitor discharges through pin 7.

Step 5: Return to Stable State

The circuit returns to its initial stable state and waits for the next valid trigger pulse.

6. Pulse Width Formula

The output pulse duration depends on the timing resistor and capacitor.

T = 1.1 RC

Where:

  • T = Output pulse width in seconds.
  • R = Timing resistance in ohms (Ω).
  • C = Timing capacitance in farads (F).

The factor 1.1 comes from the capacitor charging from approximately 0 V to 2/3 VCC through resistor R.

Capacitor charging equation:

VC(t) = VCC(1 - e-t/RC)

At the threshold:

2/3 VCC = VCC(1 - e-T/RC)

e-T/RC = 1/3

T = RC ln(3)

T ≈ 1.1 RC

7. Numerical Example 1: Pulse Width

Question: A 555 timer monostable circuit uses R = 100 kΩ and C = 10 µF. Calculate the output pulse width.

Given:

  • R = 100,000 Ω
  • C = 10 × 10-6 F
T = 1.1 RC

T = 1.1 × 100,000 × 10 × 10-6

T = 1.1 seconds

Answer: Output pulse width = 1.1 seconds

8. Numerical Example 2: Calculate Timing Resistor

Question: A monostable 555 timer must generate a pulse of 0.5 seconds using a 10 µF capacitor. Calculate the timing resistor.

Given:

  • T = 0.5 seconds
  • C = 10 × 10-6 F
T = 1.1 RC

R = T / (1.1 C)

R = 0.5 / (1.1 × 10 × 10-6)

R ≈ 45,455 Ω

Answer: R ≈ 45.5 kΩ

10. Applications

  • Time-delay circuits.
  • Push-button one-shot pulse generation.
  • Switch debouncing circuits.
  • LED timing circuits.
  • Pulse stretching.
  • Alarm and control circuits.
  • Sensor-triggered timing systems.
  • Digital control applications.

11. Advantages and Limitations

Advantages

  • Simple timing circuit.
  • Adjustable pulse width.
  • Low component count.
  • Useful for one-shot pulse generation.
  • Easy to interface with many digital circuits, within electrical limits.

Limitations

  • Timing accuracy depends on resistor and capacitor tolerances.
  • Electrolytic capacitor leakage can affect long timing intervals.
  • Trigger input requires suitable pulse width and voltage levels.
  • Retriggering behavior depends on the input waveform and circuit implementation.

12. Monostable vs. Astable Mode

Parameter Monostable Astable
Stable states One None
Trigger required Yes, for each pulse No external trigger required for continuous oscillation
Output One timed pulse per valid trigger Continuous pulses
Timing formula T = 1.1 RC T = 0.693(R1 + 2R2)C
Applications Time delay and pulse stretching Clock and waveform generation

15. Lesson Summary

  • Monostable mode has one stable state and one quasi-stable state.
  • A valid negative trigger pulse starts the output pulse.
  • The output becomes HIGH during the timing interval.
