2. Why Use a Series-Pass Transistor?

A simple Zener shunt regulator can regulate low-current loads, but its current capability and efficiency may be limited. A transistor can be added as a series pass element to supply a larger load current.

The transistor is connected between the input supply and output. It operates in its active region and controls the voltage drop between collector and emitter.

Input supply

Provides the energy needed by the load and regulator.

Pass transistor

Controls the current delivered to the load.

Reference

Provides a voltage against which the regulated output is established.

Output

Provides a more stable voltage to the connected load.

3. Basic Series-Pass Regulator Circuit

A simple series-pass regulator uses an NPN transistor in a common-collector (emitter-follower) configuration. The base voltage is established by a Zener reference network.

The circuit above is a conceptual schematic illustration of a basic emitter-follower regulator. For actual breadboard construction, use a clean schematic and verify every transistor connection and Zener polarity against the selected component datasheets before powering the circuit.

Basic operation

  1. The input voltage is applied to the collector of the pass transistor.
  2. The resistor RZ supplies current to the Zener reference and transistor base.
  3. The Zener diode maintains an approximately constant base reference voltage.
  4. The emitter follows the base voltage, minus the base-emitter voltage.
  5. The transistor supplies the load current, reducing the current demand placed directly on the Zener reference.

4. Emitter-Follower Regulator Operation

The NPN transistor in a common-collector configuration is called an emitter follower because the emitter voltage approximately follows the base voltage.

VOUT ≈ VB − VBE

For a silicon transistor under typical operating conditions, VBE may be around 0.6–0.8 V. The actual voltage depends on current and temperature.

With a Zener reference:

VOUT ≈ VZ − VBE
Base

Receives the reference voltage.

Collector

Connected to the unregulated input.

Emitter

Provides the regulated output.

5. Why the Transistor Increases Load Capability

The base current controls a much larger collector and emitter current. The transistor current gain allows the reference network to supply only a fraction of the load current.

IC ≈ β × IB
IE ≈ IC + IB

In an emitter-follower regulator, the base current must still be provided by the reference resistor. The reference circuit must be designed so that sufficient current is available at maximum load and minimum input voltage.

Do not design using a transistor's typical β alone. Use an appropriate minimum gain from the datasheet for the expected collector current and operating conditions.

6. Derivation of Basic Regulator Equations

Output voltage

VOUT ≈ VZ − VBE

Load current

For a resistive load:

IL = VOUT / RL

Pass transistor base current

For an approximate transistor current gain β:

IB ≈ IL / (β + 1)

Reference resistor current

IRZ = (VIN − VZ) / RZ

Zener current

IZ = IRZ − IB

The reference resistor current must be sufficient to supply both the Zener current required for regulation and the transistor base current.

Pass transistor power

PQ ≈ (VIN − VOUT) × IL

This approximation neglects small additional currents and voltage drops. For thermal analysis, use actual transistor current, collector-emitter voltage, operating conditions and worst-case load.

7. Worked Numerical Example

Given:

  • Input voltage: 12 V
  • Zener reference: 6.2 V
  • Assumed VBE: 0.7 V
  • Load resistance: 100 Ω
  • Transistor β: 50 (illustrative assumption)
  • Reference resistor: 470 Ω

Step 1 – Estimate output voltage

VOUT ≈ 6.2 − 0.7 = 5.5 V

Step 2 – Calculate load current

IL = 5.5 / 100 = 55 mA

Step 3 – Estimate base current

IB ≈ 55 mA / 51 ≈ 1.08 mA

Step 4 – Calculate reference resistor current

IRZ = (12 − 6.2)/470 ≈ 12.34 mA

Step 5 – Estimate Zener current

IZ ≈ 12.34 − 1.08 = 11.26 mA

This nominal calculation suggests that the Zener has current available for regulation. A real design must check the minimum input voltage, maximum load current, transistor gain variation, resistor tolerance and Zener current requirements.

Step 6 – Estimate pass transistor power

PQ ≈ (12 − 5.5) × 0.055 = 0.358 W

The transistor dissipates approximately 358 mW in this operating condition. Check the transistor's thermal resistance, temperature, safe operating area and derating before selecting the device.

10. Line and Load Regulation

Line regulation

Line regulation describes how the output voltage changes when the input voltage changes while the load remains constant.

Line regulation = ΔVOUT / ΔVIN

For discrete regulators, the output can be affected by changes in input voltage because the pass transistor and reference network have non-ideal characteristics.

Load regulation

Load regulation describes output-voltage variation with load current.

Load regulation = ΔVOUT / ΔIL

The transistor provides current gain, but the regulator is not a precision feedback regulator unless an active control loop is used. A simple emitter follower still has output variation due to base-emitter voltage and source/reference impedance.

11. Transistor Power Dissipation and Thermal Design

A series-pass transistor drops the difference between input and output voltage while carrying load current. This voltage drop is converted into heat.

PQ ≈ VCE × IC
VCE ≈ VIN − VOUT
PQ ≈ (VIN − VOUT) × IL

Thermal relationship

TJ ≈ TA + PQ × θJA
TermMeaning
TJTransistor junction temperature.
TAAmbient temperature.
θJAJunction-to-ambient thermal resistance.
PQPower dissipated in the pass transistor.

When a heatsink is used, thermal calculations may need to include junction-to-case, case-to-heatsink and heatsink-to-ambient thermal resistances.

Thermal resistance and safe operating area are separate checks. A transistor may exceed its safe operating area even when a simplified junction-temperature estimate appears acceptable.

12. Advantages and Limitations

Advantages
  • Greater load-current capability than a basic Zener shunt regulator.
  • Simple discrete circuit.
  • Low component count.
  • Useful for understanding linear regulator operation.
  • Can be implemented using common transistor components.
Limitations
  • Output voltage depends on VBE.
  • Limited regulation accuracy without feedback.
  • Pass transistor dissipates heat.
  • Reference current must support base current.
  • Output is below reference voltage in an emitter follower.
  • May require thermal protection and current limiting.

13. Practical Lab – Emitter-Follower Regulator

Objective: Construct a basic series-pass transistor regulator and measure output voltage and power dissipation.

Components

  • NPN power transistor suitable for the current and power.
  • 6.2 V Zener diode with suitable rating.
  • 470 Ω reference resistor, suitably rated.
  • 100 Ω load resistor, suitably rated for approximately 5.5 V and 55 mA.
  • Current-limited DC supply, multimeter and breadboard or suitable test fixture.

Procedure

  1. Switch off the supply and assemble the circuit.
  2. Verify transistor pinout and Zener polarity using the selected datasheets.
  3. Connect the collector to the input supply and emitter to the output/load.
  4. Connect the reference resistor and Zener circuit to establish base voltage.
  5. Check the circuit for wiring errors before applying power.
  6. Set the current-limited supply to a low voltage initially.
  7. Gradually increase the input to the intended operating range.
  8. Measure base, emitter and collector voltages.
  9. Calculate load current and pass transistor dissipation.
  10. Change the load and input voltage within the design range and record output changes.
  11. Monitor temperature and switch off if abnormal heating occurs.

15. Placement Interview Questions and Answers

1. What is a series-pass regulator?

A voltage regulator that uses a control element in series with the load to regulate output voltage.

2. Why is a transistor used?

It provides current amplification and controls the current delivered to the load.

3. What is an emitter follower?

A common-collector transistor configuration where emitter voltage approximately follows base voltage minus VBE.

4. What is the output voltage of a Zener-referenced emitter follower?

Approximately VZ − VBE.

5. Why is the output voltage lower than the Zener voltage?

Because a base-emitter voltage drop exists between base and emitter.

6. What is the role of the reference resistor?

It supplies current to the Zener reference and transistor base.

7. How does the transistor increase load-current capability?

Its base current controls a larger collector/emitter current.

8. What is the approximate base current?

For a simplified emitter follower, IB ≈ IL/(β+1).

9. Why should minimum β be considered?

Gain varies with current, temperature and device variation. Minimum gain ensures the reference network can supply the required base current.

10. What is the power dissipated by the pass transistor?

Approximately VCE × IC.

11. Why does the transistor heat up?

It dissipates the voltage drop between input and output while supplying current.

12. What is the difference between a shunt regulator and a series-pass regulator?

A shunt regulator diverts current in a parallel element, whereas a series-pass regulator controls load current using an element in series with the load.

13. Does an emitter-follower regulator provide perfect regulation?

No. Output voltage depends on VBE, reference impedance, load current, temperature and input conditions.

14. What is the safe operating area?

A set of voltage, current and thermal conditions within which a transistor can operate without damage.

15. Why may a heatsink be required?

To reduce junction temperature by lowering the thermal resistance to ambient.

16. How can you test the regulator?

Measure input, reference, base and output voltages and load current while varying input and load.

17. What is the limitation of a simple emitter-follower regulator?

It lacks a high-gain error-control loop, so its output is less precise than a properly designed feedback regulator.

18. Why is feedback used in integrated regulators?

Feedback compares output with a reference and adjusts the control element to reduce output error.

16. Numerical Practice

  1. A 5.6 V Zener is used with an NPN emitter follower. Assume VBE = 0.7 V. Calculate output voltage.
  2. A regulator supplies 100 mA with β = 40. Estimate the required base current.
  3. VIN = 15 V, VOUT = 8 V and load current = 200 mA. Calculate transistor power dissipation.
  4. A 6.2 V reference is used in an emitter follower with VBE = 0.75 V. Calculate output voltage.
  5. Explain why a transistor regulator may fail when the input voltage increases substantially.
  6. Explain how insufficient reference current can cause the output voltage to fall.
Show answers
  1. VOUT ≈ 5.6 − 0.7 = 4.9 V.
  2. IB ≈ 100 mA / 41 ≈ 2.44 mA.
  3. PQ ≈ (15 − 8) × 0.2 = 1.4 W.
  4. VOUT ≈ 6.2 − 0.75 = 5.45 V.
  5. Increasing input voltage raises the voltage drop across the pass transistor and can increase dissipation beyond its thermal or safe operating limits.
  6. The reference network may fail to supply the required base current and minimum Zener current, causing the reference voltage to lose regulation.

18. Lecture Summary

  • A series-pass transistor regulator uses a transistor in series with the load.
  • A simple NPN emitter follower can be referenced using a Zener diode.
  • Output voltage is approximately VZ − VBE.
  • Base current must be provided by the reference network.
  • The pass transistor provides current amplification but dissipates power.
  • Thermal resistance and safe operating area must be checked.
  • Feedback-based integrated regulators provide better regulation than simple discrete emitter followers.
