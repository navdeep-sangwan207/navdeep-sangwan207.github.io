2. Introduction to Line and Load Regulation

An ideal voltage regulator would maintain exactly the same output voltage under all permitted input and load conditions.

In practical circuits, the output voltage changes slightly when the input voltage or load current changes. These variations are described using two important specifications:

  • Line Regulation: Output voltage variation due to input voltage variation.
  • Load Regulation: Output voltage variation due to load current variation.
Placement concept: Line regulation deals with changes in the input supply. Load regulation deals with changes in the current drawn by the connected load.

3. What is Line Regulation?

Line regulation is the ability of a voltage regulator to maintain a constant output voltage when its input voltage changes, while the load current remains constant.

A change in input voltage may cause a small change in the regulator output voltage.

Example

Consider a regulator whose input voltage changes from 10 V to 15 V while the load current remains constant.

Suppose the output voltage changes from 5.00 V to 5.02 V.

The output variation is 20 mV for a 5 V input variation.

Change in input voltage:
ΔVin = 15 - 10 = 5 V

Change in output voltage:
ΔVout = 5.02 - 5.00 = 0.02 V

Line regulation = ΔVout / ΔVin

4. Line Regulation Formula

Line regulation is commonly expressed as the change in output voltage divided by the corresponding change in input voltage.

Line Regulation = ΔVout / ΔVin

Unit: V/V or mV/V

Where:

  • ΔVout = Change in output voltage.
  • ΔVin = Change in input voltage.

Line Regulation in mV/V

When the output voltage change is expressed in millivolts and the input voltage change in volts, the result is expressed in mV/V.

Line Regulation = Output Voltage Change (mV) / Input Voltage Change (V)

Percentage Line Regulation

When percentage line regulation is required, the output voltage change can be referred to the nominal output voltage.

Percentage Line Regulation =
(ΔVout / Vout nominal) × 100%
Different manufacturers may specify line regulation using different test conditions and units, such as mV/V or percentage over a stated input range. Always check the datasheet definition.

5. Numerical Example 1: Line Regulation

Question: The input voltage of a regulator changes from 12 V to 18 V. The output voltage changes from 5.00 V to 5.03 V. Calculate line regulation in mV/V.

Given

  • Initial input voltage = 12 V
  • Final input voltage = 18 V
  • Initial output voltage = 5.00 V
  • Final output voltage = 5.03 V
Step 1: Calculate input voltage change.

ΔVin = 18 - 12
ΔVin = 6 V

Step 2: Calculate output voltage change.

ΔVout = 5.03 - 5.00
ΔVout = 0.03 V = 30 mV

Step 3: Calculate line regulation.

Line Regulation = 30 / 6

Line Regulation = 5 mV/V

Answer

The line regulation is 5 mV/V.

6. What is Load Regulation?

Load regulation is the ability of a voltage regulator to maintain a constant output voltage when the load current changes, while the input voltage remains constant.

When a load draws more current, the output voltage may decrease slightly because of internal voltage drops and regulator limitations.

Example

Suppose a 5 V regulator provides:

  • 5.05 V at no load.
  • 5.00 V at full load.

The output voltage difference is 0.05 V. This variation is used to calculate load regulation.

Important: No-load output voltage is measured with minimum specified load current, and full-load output voltage is measured at the specified maximum load current. Actual datasheet test conditions must be followed.

7. Load Regulation Formula

A commonly used percentage load regulation formula is based on the no-load and full-load output voltages.

Load Regulation (%) =

[(VNL - VFL) / VFL] × 100%

Where:

  • VNL = Output voltage at no load.
  • VFL = Output voltage at full load.

Absolute Load Regulation

Absolute Load Regulation = VNL - VFL

Unit: Volts (V) or millivolts (mV)

Load Regulation in mV

Some datasheets specify load regulation as an absolute output voltage change over a stated load-current range.

Load Regulation = ΔVout
Unit: mV, over the specified load-current range.
Datasheets may also express load regulation as mV/mA or percentage over a specified current range. These specifications should not be confused with the no-load-to-full-load percentage formula.

8. Numerical Example 2: Load Regulation

Question: A voltage regulator provides 5.10 V at no load and 5.00 V at full load. Calculate the percentage load regulation.

Given

  • No-load voltage, VNL = 5.10 V
  • Full-load voltage, VFL = 5.00 V
Load Regulation (%) = [(VNL - VFL) / VFL] × 100%

= [(5.10 - 5.00) / 5.00] × 100%

= (0.10 / 5.00) × 100%

= 2%

Answer

The percentage load regulation is 2%.

9. Effect of Load Current on Output Voltage

A voltage regulator is designed to maintain its output voltage as the load current changes. However, practical regulators have a finite output impedance and operating limits.

As the load current increases, the output voltage may decrease. When the load current decreases, the output voltage may increase slightly.

Factors Affecting Load Regulation

  • Internal output resistance of the regulator.
  • Current capability of the pass element.
  • Input voltage available to the regulator.
  • Temperature and component characteristics.
  • Operation near current or thermal limits.

10. Difference Between Line and Load Regulation

Parameter Line Regulation Load Regulation
Definition Change in output voltage due to input voltage variation. Change in output voltage due to load current variation.
Variable changed Input voltage. Load current.
Constant condition Load current is kept constant. Input voltage is kept constant.
Common unit mV/V or percentage. mV, mV/mA or percentage.
Main purpose Measures rejection of input supply variations. Measures output stability under changing loads.

11. Voltage Regulator Datasheet Specifications

When selecting a voltage regulator for a practical circuit, engineers check its electrical characteristics in the manufacturer's datasheet.

Specification Meaning
Output Voltage Nominal regulated output voltage.
Input Voltage Range Permitted input voltage range.
Output Current Maximum specified output current under stated conditions.
Line Regulation Output variation caused by input voltage changes.
Load Regulation Output variation caused by load current changes.
Dropout Voltage Minimum input-to-output voltage difference needed for regulation.
Quiescent Current Current consumed internally by the regulator.
Thermal Shutdown Protection that limits operation when junction temperature becomes excessive.
Ripple Rejection Ability to suppress input ripple appearing at the output.
Operating Temperature Specified temperature range for operation.
Datasheet specifications are valid under their stated test conditions. Always check input voltage, output current, temperature and capacitor requirements before selecting a regulator.

12. Numerical Example 3: Percentage Line Regulation

Question: A 12 V regulator has an output voltage change of 24 mV when the input voltage changes from 15 V to 19 V. Calculate percentage line regulation using the nominal output voltage.

Given

  • Nominal output voltage = 12 V
  • Output voltage change = 24 mV = 0.024 V
  • Input voltage change = 19 - 15 = 4 V
Step 1: Calculate line regulation.

Line Regulation = 0.024 / 4
= 0.006 V/V

Step 2: Calculate percentage line regulation.

Percentage Line Regulation = (0.024 / 12) × 100%

= 0.2%

Answer

Line regulation = 6 mV/V.

Percentage line regulation, using nominal output voltage as the reference, = 0.2%.

13. Practical Measurement of Line and Load Regulation

Measuring Line Regulation

  1. Connect the voltage regulator to a suitable DC input supply.
  2. Connect a fixed load to the regulator output.
  3. Measure the output voltage at the minimum specified input voltage.
  4. Increase the input voltage within the regulator's specified range.
  5. Record the output voltage at each input voltage.
  6. Calculate the change in output voltage relative to the input voltage change.

Measuring Load Regulation

  1. Keep the regulator input voltage constant.
  2. Connect a suitable variable load or electronic load.
  3. Measure the output voltage at the minimum specified load current.
  4. Increase the load current gradually.
  5. Record the output voltage at each load condition.
  6. Calculate the output voltage variation between the specified load limits.
Safety: Do not exceed the regulator's maximum input voltage, output current or power dissipation ratings. Use appropriate current limiting and thermal management during practical testing.

16. Lesson Summary

  • Line regulation measures output voltage variation due to input voltage changes.
  • Load regulation measures output voltage variation due to load current changes.
  • During a line regulation test, load current is kept constant.
  • During a load regulation test, input voltage is kept constant.
  • Line regulation is commonly expressed in mV/V or percentage.
  • Load regulation may be expressed in mV, mV/mA or percentage.
  • No-load voltage and full-load voltage are used in a common percentage load regulation calculation.
  • Regulator datasheets provide the conditions and limits for these specifications.
  • Good line and load regulation help maintain a stable DC supply.
