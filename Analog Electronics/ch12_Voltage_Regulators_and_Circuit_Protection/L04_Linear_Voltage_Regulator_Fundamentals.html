2. What Is a Linear Voltage Regulator?

A linear voltage regulator maintains a relatively constant DC output voltage despite changes in input voltage, load current and temperature within its operating limits.

It uses a controlled semiconductor element operating in its linear region to drop the difference between the input voltage and output voltage. A feedback system adjusts the pass element to reduce output voltage error.

Input voltage

Unregulated DC voltage supplied to the regulator.

Control system

Compares a scaled output with a reference.

Pass element

Controls the voltage drop and current delivered to the load.

Regulated output

Provides a more stable voltage within the regulator's limits.

3. Block Diagram of a Linear Regulator

A typical linear regulator consists of a reference source, error amplifier, pass element and feedback network.

Function of each block

4. Reference Voltage

The reference voltage is the standard against which the output is compared. Its stability directly influences regulator accuracy.

Reference sources may use:

  • Zener diode references.
  • Bandgap reference circuits.
  • Integrated reference circuitry.
  • Precision reference ICs.

Reference source requirements

  • Low temperature variation.
  • Low noise.
  • Good long-term stability.
  • Suitable operating current.
  • Appropriate accuracy.

5. Error Amplifier

The error amplifier compares the reference voltage with the feedback voltage. The difference between these two signals determines the control action applied to the pass element.

VERROR = VREF − VFB

In a typical negative-feedback regulator, a change in output voltage changes the feedback signal. The error amplifier responds by adjusting the pass element in the direction that reduces the error.

Example

If output voltage falls, the feedback voltage falls. The error amplifier responds by increasing pass-element conduction in a typical regulator, raising output voltage back toward its setpoint.

If output voltage rises, the feedback voltage rises. The control action reduces pass-element conduction, helping lower the output.

The exact polarity of the control signal depends on the circuit architecture. The regulator must be designed so the overall loop provides negative feedback.

6. Pass Element

The pass element is the semiconductor device that controls energy transfer from the input supply to the output.

BJT pass element

A bipolar transistor can control current through base-drive adjustment.

MOSFET pass element

A MOSFET controls current through gate-voltage adjustment.

In a linear regulator, the pass element operates in a region where it controls the voltage drop and load current. It dissipates power as heat.

PPASS ≈ (VIN − VOUT) × IOUT

This is a first-order approximation for a regulator under steady-state load conditions. Additional currents and losses may need to be included in detailed design.

7. Negative Feedback in a Linear Regulator

Negative feedback helps correct output variation. The feedback network returns a scaled output voltage to the control system.

VFB = β × VOUT

At equilibrium, a regulator with a sufficiently high-gain error amplifier and a properly designed loop attempts to maintain:

VFB ≈ VREF

Therefore:

VOUT ≈ VREF / β

Here β represents the feedback-divider fraction. It is not the transistor current gain.

Feedback divider

A two-resistor divider can provide the feedback voltage:

For a conventional divider, where R1 connects from output to feedback and R2 from feedback to ground:

VFB = VOUT × R2 / (R1 + R2)
VOUT = VREF × (1 + R1/R2)

This is the standard relationship for a regulator whose control loop holds the divider feedback voltage near VREF.

9. Dropout Voltage

Dropout voltage is the minimum difference between input and output voltage required for a regulator to maintain regulation under specified conditions.

VDROPOUT = VIN(min) − VOUT

When the input voltage approaches the output voltage too closely, the pass element can no longer provide the required control action.

Example

A regulator requires a minimum input of 7 V to maintain a 5 V output at a particular load.

VDROPOUT = 7 − 5 = 2 V

If the input falls below the required headroom, the output may fall below its specified regulated value.

Conventional regulator

May require a relatively large input-output voltage difference.

Low-dropout (LDO) regulator

Designed to maintain regulation with a smaller input-output voltage difference under specified conditions.

10. Line Regulation and Load Regulation

Line regulation

Line regulation describes how output voltage changes with input voltage when the load is held constant.

Line regulation = ΔVOUT / ΔVIN

It may be expressed in mV/V or percentage per volt, depending on the datasheet.

Load regulation

Load regulation describes output voltage change with load current.

Load regulation = ΔVOUT / ΔIL

Datasheets may express load regulation as a voltage change, percentage, or normalized value. Always check the manufacturer's definition and measurement conditions.

11. Ripple Rejection and Noise

A linear regulator can reduce input ripple appearing at its output. This ability is described by power-supply rejection ratio or ripple rejection, depending on the specification.

PSRR(dB) = 20 log10(VRIPPLE,in / VRIPPLE,out)

For the same measurement convention and frequency, higher PSRR generally indicates better ripple rejection.

Example

If input ripple is 100 mV and output ripple is 1 mV:

PSRR = 20 log10(100/1) = 40 dB

PSRR varies with frequency, load current, headroom, regulator architecture and other conditions. It is not a single constant for all operating conditions.

12. Efficiency and Power Dissipation

A linear regulator converts excess voltage into heat while supplying load current. Its idealized efficiency is:

η ≈ (VOUT × IOUT) / (VIN × IIN)

For an idealized series regulator where input current is approximately load current:

η ≈ VOUT / VIN × 100%

Example

VIN = 12 V, VOUT = 5 V and IOUT = 200 mA. Ignoring quiescent current:

η ≈ 5/12 × 100 ≈ 41.7%
PLOSS ≈ (12 − 5) × 0.2 = 1.4 W
The pass element dissipates 1.4 W in this example. Thermal design must consider ambient temperature, package thermal resistance, heatsink conditions and safe operating area.

14. Practical Lab – Feedback and Regulation

Objective: Investigate the operation of a feedback-controlled linear regulator and measure regulation and thermal characteristics.

Equipment

  • Suitable linear regulator IC or a laboratory regulator circuit.
  • Current-limited DC supply.
  • Multimeter.
  • Oscilloscope.
  • Load resistors of suitable ratings or an electronic load.
  • Datasheet for the selected regulator.

Procedure

  1. Identify regulator input, output and ground pins from the datasheet.
  2. Check recommended capacitor values and ESR requirements.
  3. Connect the circuit with power off.
  4. Set a current-limited input voltage with sufficient headroom.
  5. Measure output voltage at the nominal load.
  6. Change input voltage within specified limits and measure line regulation.
  7. Change load current within specified limits and measure load regulation.
  8. Observe output ripple and noise using an appropriate oscilloscope setup.
  9. Calculate regulator power dissipation.
  10. Monitor temperature under a steady load.
  11. Compare measured values with datasheet specifications.

16. Placement Interview Questions and Answers

1. What is a linear voltage regulator?

A regulator that controls the voltage drop across a pass element to maintain a stable output.

2. What are the main blocks?

Reference source, error amplifier, pass element and feedback network.

3. What is the purpose of the reference?

It provides a stable voltage used as the regulator's control target.

4. What does an error amplifier do?

It compares reference and feedback signals and controls the pass element.

5. What is negative feedback?

A control action in which changes are fed back in a direction that reduces the error.

6. What is a pass element?

A controlled semiconductor that regulates energy transfer from the input to output.

7. What is dropout voltage?

The minimum input-output voltage difference required to maintain regulation under specified conditions.

8. What is an LDO?

A linear regulator designed to maintain regulation with relatively small input-output headroom.

9. What is line regulation?

Output voltage variation with input voltage under specified load conditions.

10. What is load regulation?

Output voltage variation as load current changes under specified input conditions.

11. What is PSRR?

A measure of how effectively a regulator suppresses disturbances or ripple from its input at the output.

12. Why does a linear regulator dissipate heat?

It drops excess voltage while carrying current, converting electrical power into heat.

13. What is the approximate pass-element loss?

Approximately (VIN − VOUT) × IOUT under a simplified steady-state model.

14. What is loop stability?

The ability of a feedback system to settle without sustained oscillation or excessive transient behavior.

15. Why are capacitors used at regulator input and output?

They help filter disturbances and support stability or transient response according to the regulator design.

16. Why can a regulator oscillate?

Inadequate loop phase margin, unsuitable capacitor ESR/capacitance, layout or load conditions can cause instability.

17. What is the difference between linear and switching regulators?

Linear regulators control voltage drop, whereas switching regulators convert energy using switching and energy-storage components.

18. How do you select a regulator?

Check output voltage, input range, load current, dropout, accuracy, thermal performance, ripple rejection, stability, protection and capacitor requirements.

19. What is thermal shutdown?

A protective mechanism that reduces or disables operation when internal temperature reaches a specified threshold.

20. How do you test a regulator?

Measure output voltage, ripple, line regulation, load regulation, current, temperature and transient behavior within specified limits.

17. Numerical Practice

  1. A linear regulator has VIN = 12 V, VOUT = 5 V and IOUT = 150 mA. Calculate pass-element power loss.

  5. Calculate idealized efficiency for a 9 V input and 5 V output, ignoring quiescent current.

  7. Explain why a linear regulator may become thermally overloaded even though the output current is below its current rating.
Show answers

  2. VIN(min) = 5 + 2 = 7 V.
  3. PSRR = 20 log10(200/2) = 40 dB.
  4. VOUT = 1.25 × (1 + 3/1) = 5 V.
  5. η ≈ 5/9 × 100 = 55.6%.
  6. The feedback voltage falls, the error amplifier adjusts the pass element to increase output delivery, and the output is driven back toward its setpoint.
  7. Power loss depends on voltage drop and current, not current rating alone. A large VIN − VOUT can cause excessive dissipation.
