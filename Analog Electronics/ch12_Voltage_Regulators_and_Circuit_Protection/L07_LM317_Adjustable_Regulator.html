Lesson 07: LM317 Adjustable Regulator

Understand the operation, voltage adjustment, resistor selection and practical applications of the LM317 adjustable positive voltage regulator.

1. Learning Objectives

  • Understand the LM317 adjustable voltage regulator.
  • Identify its terminals and basic connections.
  • Understand the voltage adjustment principle.
  • Calculate output voltage using external resistors.
  • Design a variable DC power supply.
  • Understand dropout voltage and power dissipation.
  • Identify common applications and troubleshooting issues.

2. Introduction to LM317

The LM317 is a three-terminal adjustable positive linear voltage regulator. Unlike fixed regulators such as the 7805 and 7812, its output voltage can be adjusted using external resistors.

A typical LM317 device can regulate an output voltage over approximately 1.25 V to 37 V, depending on the manufacturer, input voltage, load current and thermal limits.

The LM317 is a positive adjustable regulator. It cannot directly generate a negative regulated output voltage.

3. LM317 Pin Configuration

The three terminals of a common LM317 TO-220 package are:

Common TO-220 front-view arrangement: Pin 1 = ADJ, Pin 2 = OUT, Pin 3 = IN.

Pin Name Function
1 ADJ Adjusts the regulated output voltage through an external resistor network.
2 OUT Provides the regulated output voltage.
3 IN Receives the unregulated positive input voltage.
This is the common TO-220 pin arrangement. Verify the datasheet for the exact package and manufacturer before making circuit connections.

4. Working Principle of LM317

The LM317 maintains a nearly constant reference voltage between its OUT and ADJ terminals.

This reference voltage is typically approximately 1.25 V. An external resistor network determines the output voltage.

Basic Operation

  1. Unregulated DC voltage is applied to the IN terminal.
  2. A resistor is connected between OUT and ADJ.
  3. A second resistor is connected between ADJ and ground.
  4. The regulator maintains approximately 1.25 V between OUT and ADJ.
  5. The resistor network determines the regulated output voltage.

5. LM317 Voltage Adjustment Circuit

Conceptual resistor-adjustment arrangement. Refer to the connection steps and equations below for the correct circuit wiring.

External Resistor Connections

  • Connect R1 between OUT and ADJ.
  • Connect R2 between ADJ and ground.
  • Take the regulated output from OUT.
  • Apply the unregulated supply to IN.

6. LM317 Output Voltage Formula

The output voltage is calculated using the external resistor values and the adjustment current.

Vout = Vref × (1 + R2/R1) + Iadj × R2

Where:

  • Vout: Regulated output voltage.
  • Vref: Reference voltage, typically about 1.25 V.
  • R1: Resistor connected between OUT and ADJ.
  • R2: Resistor connected between ADJ and ground.
  • Iadj: Adjustment terminal current.
For many basic calculations, Iadj is neglected as a first approximation. For accurate design, use the adjustment-current specification from the datasheet.

7. Numerical Example

Calculate the approximate output voltage when:

  • Reference voltage = 1.25 V
  • R1 = 240 Ω
  • R2 = 720 Ω
  • Adjustment current is neglected.
Vout = 1.25 × (1 + 720/240)

Vout = 1.25 × (1 + 3)

Vout = 1.25 × 4

Vout = 5 V

Therefore, the approximate regulated output voltage is 5 V.

8. Role of R1 and R2

Resistor R1

  • Connected between OUT and ADJ.
  • Establishes a current through the reference voltage.
  • Commonly selected near 240 Ω in many standard designs.

Resistor R2

  • Connected between ADJ and ground.
  • Controls the output voltage adjustment.
  • Increasing R2 generally increases the output voltage.
The resistor values must also satisfy minimum load-current requirements and the regulator's datasheet specifications.

9. Adjustable DC Power Supply

An LM317 can be used to build a variable DC power supply. A potentiometer can be used as the adjustment resistor R2.

Rectifier and Filter
→
LM317
→
Variable DC Output

Working

  1. An AC source is stepped down using a transformer where required.
  2. A rectifier converts AC into pulsating DC.
  3. A filter capacitor smooths the rectified voltage.
  4. The LM317 regulates the DC voltage.
  5. A potentiometer adjusts the output voltage.
The filtered input must remain above the required output voltage by the regulator's dropout margin, including ripple and load variations.

10. Dropout Voltage

Dropout voltage is the minimum difference required between the input and output terminals for the regulator to maintain proper regulation.

Vin(min) ≈ Vout + Vdropout

The LM317 is not a low-dropout regulator. Its required input-output headroom depends on load current and temperature and must be checked using the datasheet.

11. Power Dissipation and Heatsink

The LM317 is a linear regulator. The voltage difference between input and output produces heat inside the device.

PD ≈ (Vin − Vout) × Iout

Numerical Example

Given:

  • Input voltage = 15 V
  • Output voltage = 5 V
  • Load current = 200 mA
PD = (15 − 5) × 0.2

PD = 10 × 0.2

PD = 2 W

Approximately 2 W of power is dissipated as heat. Thermal design must be checked before operating the regulator at this load.

12. Protection Features

Many LM317 versions include internal protection features. These commonly include:

  • Current limiting: Limits excessive output current.
  • Thermal overload protection: Protects against excessive junction temperature.
  • Safe operating area protection: Helps protect the internal pass element under specified conditions.

External protection diodes may be needed in some circuits, especially when large capacitors are connected to the output or adjustment terminal. Follow the manufacturer's application circuit.

13. Advantages

  • Adjustable positive output voltage.
  • Simple three-terminal device.
  • Requires relatively few external components.
  • Useful for variable power supply circuits.
  • Provides regulated output over its specified operating range.
  • Internal protection is included in many versions.

14. Limitations

  • Linear regulator with power loss as heat.
  • Requires sufficient input-output voltage headroom.
  • Heatsink may be required at higher load currents.
  • Maximum output current depends on thermal and electrical conditions.
  • Cannot directly provide a negative regulated output.
  • Not as efficient as a suitable switching regulator for large voltage differences.

15. Applications

  • Variable DC power supplies.
  • Adjustable laboratory power supplies.
  • Battery charger circuits designed around its operating limits.
  • Analog circuit power supplies.
  • Embedded system development circuits.
  • Current regulator circuits.
  • Voltage adjustment circuits.

16. Common Faults and Troubleshooting

Problem Possible Cause Check
No output voltage Incorrect pin connection or missing input supply Check IN, OUT and ADJ terminals.
Output voltage too low Insufficient input headroom or overload Measure input voltage and load current.
Output voltage too high Incorrect resistor network Check R1 and R2 values and connections.
IC overheating Excessive voltage drop or load current Calculate power dissipation and check heatsinking.
Unstable output Incorrect capacitor selection or wiring Follow the datasheet's capacitor recommendations.
