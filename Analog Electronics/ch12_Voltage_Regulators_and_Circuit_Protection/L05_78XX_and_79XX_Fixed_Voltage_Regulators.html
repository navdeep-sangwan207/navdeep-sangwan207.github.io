Lesson 05: Transistor-Based Voltage Regulators

Learn how BJTs are used as series pass elements and control devices to maintain a stable DC output voltage.

1. Learning Objectives

  • Understand transistor-based voltage regulation.
  • Explain the operation of a series pass transistor.
  • Understand emitter follower voltage regulation.
  • Study Zener-controlled transistor regulators.
  • Understand feedback-based transistor regulators.
  • Calculate output voltage and transistor power dissipation.
  • Identify practical limitations and applications.

2. Introduction

A transistor-based voltage regulator uses a transistor as a controlling element to maintain a nearly constant output voltage.

A Zener diode can provide a stable reference voltage, while a transistor supplies or controls the current delivered to the load.

Compared with a simple Zener regulator, a transistor-based regulator can provide improved load-current capability.

3. Series Pass Transistor Regulator

In a series pass transistor regulator, a transistor is connected in series between the unregulated input supply and the load.

The transistor operates in its active region and controls the current flowing to the load.

→
Pass Transistor
→
Load

A reference and control circuit adjusts the transistor's base drive to stabilize the output.

3.2 Basic Circuit Concept

Simplified conceptual diagram of a series pass regulator.

3.3 Working Principle

  1. The unregulated DC voltage is applied to the transistor.
  2. The transistor acts as a variable series resistance.
  3. The output voltage is sensed by a control circuit.
  4. The control circuit adjusts the transistor base current.
  5. The transistor changes its conduction to correct output voltage variations.

3.4 When Input Voltage Increases

The control circuit reduces the effective conduction of the pass transistor so that a larger voltage drop appears across it. This helps keep the output voltage stable.

3.5 When Load Current Increases

The output voltage tends to fall. The control circuit increases transistor conduction, allowing more current to flow to the load and helping restore the output voltage.

4. Zener-Controlled Transistor Regulator

A simple transistor regulator can use a Zener diode as a reference voltage source and an NPN transistor as an emitter follower.

4.1 Circuit Arrangement

  • The collector of the NPN transistor is connected to the unregulated supply.
  • The base is held at an approximately constant reference voltage using a Zener diode.
  • The emitter provides the regulated output.
  • The load is connected between the emitter output and ground.
Zener Reference
→
Transistor Base
→
Emitter Output

The transistor provides current gain so the Zener diode does not need to supply the entire load current.

4.2 Output Voltage

Vout ≈ VZ − VBE

VZ = Zener reference voltage
VBE = Base-emitter voltage

For a silicon transistor, VBE is often approximated as 0.7 V for basic calculations. Its actual value depends on current and temperature.

4.3 Numerical Example

A Zener-controlled emitter follower uses a 6.2 V Zener diode. Assume the transistor base-emitter voltage is 0.7 V.

Vout = VZ − VBE

= 6.2 − 0.7

= 5.5 V

Therefore, the approximate output voltage is 5.5 V.

5. Emitter Follower as a Voltage Regulator

An emitter follower is a common-collector BJT configuration. Its emitter voltage follows the base voltage with an approximately one base-emitter voltage drop.

VE ≈ VB − VBE

It has high input impedance and low output impedance compared with a simple reference source. This makes it useful as a current buffer.

Important Characteristics

  • Voltage gain is approximately unity.
  • Current gain is high.
  • Output is taken from the emitter.
  • Base voltage determines the approximate emitter voltage.
  • It can supply more load current than the reference source alone.
A basic Zener-emitter-follower circuit is not a precision regulator. Changes in base-emitter voltage, transistor temperature, Zener current and load conditions affect the output.

6. Feedback-Based Transistor Regulator

A feedback-based regulator uses a sensing circuit, reference voltage and error amplifier to control a series pass transistor.

6.1 Main Blocks

  • Reference source: Provides a stable reference voltage.
  • Sampling network: Senses a fraction of the output voltage.
  • Error amplifier: Compares the sensed voltage with the reference.
  • Pass transistor: Controls the current supplied to the load.
Reference
→
Error Amplifier
→
Pass Transistor
→
Load

Output feedback is returned to the error amplifier.

6.2 Working Principle

  1. The sampling network measures the output voltage.
  2. The error amplifier compares the sampled voltage with the reference.
  3. An error signal is generated.
  4. The error signal controls the pass transistor.
  5. The transistor adjusts its conduction to reduce the output error.

7. Transistor Power Dissipation

A series pass transistor dissipates power because there is a voltage difference between its collector and emitter while load current flows through it.

PQ ≈ (Vin − Vout) × IL

This approximation assumes the transistor's input current is small compared with the load current. For a more accurate calculation, use the transistor's actual collector-emitter voltage and collector current.

Numerical Example

Given:

  • Input voltage = 12 V
  • Output voltage = 5 V
  • Load current = 200 mA
PQ ≈ (12 − 5) × 0.2

= 7 × 0.2

= 1.4 W

The transistor dissipates approximately 1.4 W and may require a suitable heatsink depending on its package, thermal resistance and operating environment.

8. Advantages

  • Higher load-current capability than a simple Zener regulator.
  • Can provide improved output regulation with feedback.
  • Relatively simple circuit construction.
  • Useful for learning linear regulator design.
  • Can be designed for different output voltages and currents.

9. Limitations

  • Power dissipation in the pass transistor.
  • Heat generation at high load currents.
  • Efficiency decreases with large input-output voltage differences.
  • Output voltage may vary with temperature and transistor characteristics.
  • Requires protection against overload and short circuits.
  • Needs sufficient input-output voltage headroom.

10. Applications

  • Linear regulated power supplies.
  • Low-voltage DC power supply circuits.
  • Microcontroller and embedded system supplies.
  • Analog circuit power supplies.
  • Reference and buffer circuits.
  • Industrial electronic equipment.

13. Lesson Summary

  • A transistor can act as a series pass element in a voltage regulator.
  • A Zener diode can provide the reference voltage for a simple transistor regulator.
  • An emitter follower provides current gain and an output approximately one VBE below its base voltage.
  • Feedback-based regulators compare the output with a reference and correct voltage variations.
  • Pass transistor power dissipation must be checked during design.
  • Thermal management and protection are important in practical regulator circuits.
