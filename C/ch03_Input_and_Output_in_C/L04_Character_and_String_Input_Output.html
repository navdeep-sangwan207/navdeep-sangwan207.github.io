2. Character and String I/O Overview

C provides standard library functions for reading and writing characters and strings.

These functions are declared in stdio.h.

fgets() Reads a bounded sequence of characters from a stream.
puts() Writes a string to standard output and appends a newline.
fputs() Writes a string to a specified output stream without automatically appending a newline.

3. getchar() – Reading a Character

getchar() reads the next character from the standard input stream, normally the keyboard.

Syntax

int getchar(void);

Return value:

  • Returns the next input character as an unsigned char converted to int.
  • Returns EOF when end-of-file is encountered or an input error occurs.

Example: Read and Display One Character

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter a character: ");

    ch = getchar();

    if (ch != EOF)
    {
        printf("You entered: ");
        putchar(ch);
        putchar('\n');
    }
    else
    {
        printf("No character was read.\n");
    }

    return 0;
}
Sample Interaction: 
Enter a character: A
You entered: A
Store the result of getchar() in an int, not a char. The int type must be able to represent every possible unsigned-char value as well as EOF. Storing the result in char before checking EOF can make the distinction unreliable.

4. putchar() – Displaying a Character

putchar() writes one character to the standard output stream, normally the terminal.

Syntax

int putchar(int ch);

Return value:

  • Returns the character written, represented as an unsigned char converted to int, on success.
  • Returns EOF if a write error occurs.

Example: Display Characters

#include <stdio.h>

int main(void)
{
    putchar('H');
    putchar('E');
    putchar('L');
    putchar('L');
    putchar('O');
    putchar('\n');

    return 0;
}
Expected Output: 
HELLO

Example: Check putchar() Return Value

#include <stdio.h>

int main(void)
{
    if (putchar('A') == EOF)
    {
        fprintf(stderr, "Output error.\n");
        return 1;
    }

    if (putchar('\n') == EOF)
    {
        fprintf(stderr, "Output error.\n");
        return 1;
    }

    return 0;
}
Expected Output: 
A

5. Reading Characters Using a Loop

getchar() can be used inside a loop to process input one character at a time.

Example: Read Until EOF

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter text. Send EOF to finish:\n");

    while ((ch = getchar()) != EOF)
    {
        if (putchar(ch) == EOF)
        {
            fprintf(stderr, "Output error.\n");
            return 1;
        }
    }

    if (ferror(stdin))
    {
        fprintf(stderr, "Input error.\n");
        return 1;
    }

    return 0;
}

How it works:

  1. getchar() reads one character.
  2. The character is stored in an int variable.
  3. The loop continues while the result is not EOF.
  4. putchar() writes each character to standard output.
  5. The loop stops when EOF is returned.
On many terminal environments, Ctrl+D signals end-of-file on Unix-like systems and Ctrl+Z followed by Enter is commonly used on Windows. The exact terminal behavior depends on the environment.

6. puts() – Displaying a String

puts() writes a null-terminated string to standard output and automatically appends a newline character.

Syntax

int puts(const char *str);

Return value:

  • Returns a nonnegative value on success.
  • Returns EOF if a write error occurs.

Example

#include <stdio.h>

int main(void)
{
    char message[] = "Welcome to C Programming";

    puts(message);

    return 0;
}
Expected Output: 
Welcome to C Programming

Important Behavior

puts() appends a newline automatically. You do not need to include \n in the string to move to the next line.

puts("First line");
puts("Second line");
Expected Output: 
First line
Second line

7. fgets() – Safe String Input

fgets() reads a bounded sequence of characters from a specified input stream.

It is generally preferred over unbounded string input because the maximum number of characters to store is specified.

Syntax

char *fgets(char *str, int n, FILE *stream);

Parameters:

  • str: Destination character array.
  • n: Maximum number of characters to store, including the terminating null character.
  • stream: Input stream, normally stdin.

Return value:

  • Returns the destination pointer when at least one character is successfully read.
  • Returns NULL if an error occurs or EOF is encountered before any character is read.

How fgets() Works

  • Reads at most n - 1 characters.
  • Stops after reading a newline, if one is encountered within the limit.
  • Stores the newline character in the array when it is read.
  • Appends the null terminator '\0'.

Example: Read a Complete Line

#include <stdio.h>

int main(void)
{
    char name[50];

    printf("Enter your full name: ");

    if (fgets(name, sizeof name, stdin) != NULL)
    {
        printf("Your name is: %s", name);
    }
    else
    {
        fprintf(stderr, "Input failed.\n");
        return 1;
    }

    return 0;
}
Sample Interaction: 
Enter your full name: Rahul Sharma
Your name is: Rahul Sharma

Unlike scanf("%s", name), fgets() can preserve spaces within the input line.

Passing sizeof name is a convenient way to supply the capacity of a character array when it is declared in the same scope.

8. Removing the Newline from fgets() Input

When fgets() reads a newline within its size limit, it stores that newline in the destination array.

Sometimes a program needs the string without the trailing newline.

Example: Remove a Trailing Newline

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];

    printf("Enter your name: ");

    if (fgets(name, sizeof name, stdin) == NULL)
    {
        fprintf(stderr, "Input failed.\n");
        return 1;
    }

    name[strcspn(name, "\n")] = '\0';

    printf("Name: %s\n", name);

    return 0;
}
Sample Interaction: 
Enter your name: Rahul Sharma
Name: Rahul Sharma

Understanding the statement:

name[strcspn(name, "\n")] = '\0';
  • strcspn() finds the first position containing a character from the specified set.
  • The set in this example contains only the newline character.
  • If a newline exists, it is replaced with the null terminator.
  • If no newline exists, strcspn() returns the string length, so the existing terminator is written again.
If the input line is longer than the available array capacity, fgets() may return only part of the line. The remaining characters stay in the input stream. A robust program must detect and handle this condition rather than assuming the entire line was read.

9. fputs() – Writing a String to a Stream

fputs() writes a null-terminated string to a specified output stream.

Syntax

int fputs(const char *str, FILE *stream);

Return value:

  • Returns a nonnegative value on success.
  • Returns EOF if a write error occurs.

Example

#include <stdio.h>

int main(void)
{
    char message[] = "C Programming is useful.";

    if (fputs(message, stdout) == EOF)
    {
        fprintf(stderr, "Output error.\n");
        return 1;
    }

    if (putchar('\n') == EOF)
    {
        fprintf(stderr, "Output error.\n");
        return 1;
    }

    return 0;
}
Expected Output: 
C Programming is useful.

Unlike puts(), fputs() does not automatically append a newline.

10. Difference Between puts() and fputs()

Feature puts() fputs()
Output destination Always stdout Specified stream
Automatic newline Yes No
Return value on success Nonnegative Nonnegative
Return value on error EOF EOF

Example: Compare Both Functions

#include <stdio.h>

int main(void)
{
    puts("Using puts()");

Using fputs()

11. getchar() vs scanf("%c")

Both getchar() and scanf("%c", &variable) can read one character from standard input, but their interfaces differ.

Feature getchar() scanf("%c")
Header stdio.h stdio.h
Input type One character One character
Whitespace handling Reads whitespace as input %c reads whitespace as input
Return value Character as int or EOF Number of assigned items or EOF
Destination variable No destination pointer required Requires char pointer

Example Using getchar()

int ch = getchar();

Example Using scanf()

char ch;
scanf("%c", &ch);
getchar() is convenient for character-by-character processing, while scanf() is useful when character input is part of a larger formatted input operation.

12. fgets() vs scanf("%s")

Feature fgets() scanf("%s")
Reads spaces Yes, until newline or limit No
Maximum input length Controlled by size argument Controlled by field width, if specified
Newline handling Stores newline if read within limit Skips leading whitespace and stops at whitespace
Input stream Specified through FILE * Reads from stdin
Typical use Complete-line input Single whitespace-delimited token

Example: Read a Full Name

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[60];

    printf("Enter full name: ");

    if (fgets(name, sizeof name, stdin) == NULL)
    {
        fprintf(stderr, "Input failed.\n");
        return 1;
    }

    name[strcspn(name, "\n")] = '\0';

    printf("Full name: %s\n", name);

    return 0;
}
Sample Interaction: 
Enter full name: Rahul Kumar Sharma
Full name: Rahul Kumar Sharma

13. Handling Long Input Lines

fgets() prevents writing beyond the specified array capacity, but it does not automatically guarantee that an entire input line fits into the array.

The following example detects whether a newline was read. If the line did not fit, it discards the remaining characters through the next newline or EOF.

Example: Read and Detect an Overlong Line

#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[20];
    int ch;

    printf("Enter a line (maximum 19 characters): ");

    if (fgets(line, sizeof line, stdin) == NULL)
    {
        fprintf(stderr, "Input failed.\n");
        return 1;
    }

    if (strchr(line, '\n') == NULL)
    {
        ch = getchar();

        if (ch != '\n' && ch != EOF)
        {
            while ((ch = getchar()) != '\n' && ch != EOF)
            {
                /* Discard remaining characters. */
            }

            fprintf(stderr, "Input line is too long.\n");
            return 1;
        }
    }

    line[strcspn(line, "\n")] = '\0';

    printf("Accepted line: %s\n", line);

    return 0;
}
Sample Interaction 1: 
Enter a line (maximum 19 characters): Embedded C
Accepted line: Embedded C
Sample Interaction 2: 
Enter a line (maximum 19 characters): This input is much longer than allowed
Input line is too long.

Important logic:

  1. fgets() reads at most 19 characters into the 20-element array.
  2. If a newline is present, the line ended within the buffer.
  3. If no newline is present, the program checks whether more input remains.
  4. If additional characters exist, the rest of the line is discarded.
  5. The program reports that the line exceeded the permitted length.

14. Common Character and String I/O Mistakes

Mistake 1: Storing getchar() Result in char

Risky: 
char ch;
ch = getchar();

This can prevent reliable distinction between an input character and EOF.

Correct: 
int ch;
ch = getchar();

Mistake 2: Forgetting the Newline from fgets()

When fgets() reads a newline, that character remains in the string. Remove it when the application requires a newline-free string.

Mistake 3: Assuming puts() and fputs() Behave Identically

puts() appends a newline, whereas fputs() does not.

Mistake 4: Using an Incorrect Array Size

Incorrect: 
char name[10];
fgets(name, 20, stdin);

The requested input capacity exceeds the actual array capacity.

Correct: 
char name[10];
fgets(name, sizeof name, stdin);

Mistake 5: Assuming fgets() Always Reads the Whole Line

A long line can be split across multiple reads. Check whether a newline was captured when the complete line is required.

Mistake 6: Ignoring Input and Output Errors

Check return values from input/output functions, especially in programs that process files or external streams.

15. Practical Program: Count Characters, Words and Lines

This program reads input until EOF and counts characters, words and lines.

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    int ch;
    int in_word = 0;
    int characters = 0;
    int words = 0;
    int lines = 0;

    printf("Enter text. Send EOF to finish:\n");

    while ((ch = getchar()) != EOF)
    {
        characters++;

        if (ch == '\n')
        {
            lines++;
        }

        if (isspace((unsigned char)ch))
        {
            in_word = 0;
        }
        else if (!in_word)
        {
            in_word = 1;
            words++;
        }
    }

    if (ferror(stdin))
    {
        fprintf(stderr, "Input error.\n");
        return 1;
    }

    printf("\nCharacters: %d\n", characters);
    printf("Words: %d\n", words);
    printf("Newline characters: %d\n", lines);

    return 0;
}
Sample Input: 
C Programming
Embedded Systems
Expected Output: 
Characters: 30
Words: 4
Newline characters: 2

Explanation:

  • Every successfully read character increments the character count.
  • Every newline increments the line-ending count.
  • isspace() identifies whitespace characters.
  • A word is counted when a non-whitespace character follows whitespace or the beginning of input.
This program counts newline characters, not necessarily logical text lines. If the final line does not end with a newline, it is not included in the newline count.

16. Technical Interview Questions

Q1. What is getchar()?

It reads the next character from stdin and returns that character as int, or EOF when end-of-file or an input error occurs.

Q2. Why does getchar() return int instead of char?

The return type must represent every possible input character value as well as the special EOF value.

Q3. What is putchar()?

It writes one character to stdout and returns the written character as int or EOF on error.

Q4. What is the difference between puts() and printf()?

puts() writes a string and appends a newline. printf() supports formatted output and does not automatically append a newline.

Q5. What is the difference between puts() and fputs()?

puts() writes to stdout and appends a newline. fputs() writes to a specified stream without automatically adding a newline.

Q6. Why is fgets() safer than an unbounded %s conversion?

fgets() accepts a maximum input size, allowing the programmer to limit how many characters are stored in the destination array.

Q7. Does fgets() store the newline character?

Yes, if it encounters a newline within the permitted input length, it stores that newline in the destination array.

Q8. How do you remove a newline from a string read by fgets()?

One common method is to use strcspn() to locate the newline and replace it with the null terminator.

Q9. What happens when the input line is longer than the fgets() buffer?

Only the permitted number of characters is read. The remaining input stays in the stream for subsequent reads.

Q10. Can getchar() read spaces and newline characters?

Yes. getchar() reads the next character in the stream, including spaces, tabs and newlines.

Q11. What does fputs() return on success?

It returns a nonnegative value. It returns EOF if a write error occurs.

Q12. What is EOF?

EOF is a negative integer constant used to indicate end-of-file or an input failure in relevant standard I/O operations. Its exact value is implementation-defined.

  • getchar() reads one character from stdin and returns int.
