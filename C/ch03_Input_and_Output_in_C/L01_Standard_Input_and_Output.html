2. Introduction to Input and Output in C

Input and output operations allow a program to communicate with its external environment.

  • Input: Receiving data from a source such as a keyboard or file.
  • Output: Sending data to a destination such as a terminal or file.

For example, a program may accept two integers from the user, calculate their sum and display the result.

Basic Input/Output Flow

        User
         |
         | Input
         v
   C Program

         | Processing
         v
   Result Generation
         |
         | Output
         v
       User

Example: Basic Output

#include <stdio.h>

    printf("Hello, C Programming!\n");

    return 0;
}

3. The stdio.h Header File

stdio.h is a standard C header file that declares functions, types and macros used for input and output operations.

The name stands for Standard Input/Output.

Commonly Used Functions

Function Purpose
printf() Displays formatted output.
scanf() Reads formatted input.
getchar() Reads one character from standard input.
putchar() Writes one character to standard output.
fgets() Reads a string or line from a stream.
puts() Writes a string followed by a newline.
fprintf() Writes formatted output to a specified stream.
fscanf() Reads formatted input from a specified stream.
Important: The declarations provided by stdio.h allow the compiler to check calls to standard I/O functions correctly.

4. Standard I/O Streams

C provides three predefined standard streams for basic program communication.

Stream Meaning Default Purpose
stdin Standard Input Receives input, normally from the keyboard.
stdout Standard Output Displays normal program output, normally on the terminal.
stderr Standard Error Displays diagnostic and error messages.

These streams are associated with the FILE type and are made available through stdio.h.

4.1 Standard Input (stdin)

stdin is the standard input stream. It is normally connected to the keyboard when a program runs interactively.

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter a character: ");

    ch = getchar();

    printf("You entered: ");
    putchar(ch);
    putchar('\n');

    return 0;
}
Sample Interaction: 
Enter a character: A
You entered: A

4.2 Standard Output (stdout)

stdout is used for normal program output. Functions such as printf() and putchar() write to this stream.

#include <stdio.h>

int main(void)
{
    fputs("Program executed successfully.\n", stdout);

    return 0;
}
Expected Output: 
Program executed successfully.

4.3 Standard Error (stderr)

stderr is intended for diagnostic messages and error reporting.

#include <stdio.h>

int main(void)
{
    fprintf(stderr, "Error: Invalid input detected.\n");

    return 1;
}
Typical Terminal Message: 
Error: Invalid input detected.
Placement relevance: Standard streams are important in command-line applications, Linux programming, shell pipelines and system programming.

5. getchar() Function

getchar() reads the next character from the standard input stream.

Syntax

int getchar(void);

Return Value

  • Returns the character read, converted to an unsigned char value and then to int.
  • Returns EOF if the end of input is reached or a read error occurs.
The return type is int, not char. This allows the function to represent every possible unsigned character value as well as the special EOF value.

Example 1: Reading One Character

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter a character: ");

    ch = getchar();

    printf("Character entered: ");
    putchar(ch);
    putchar('\n');

    return 0;
}
Sample Interaction: 
Enter a character: K
Character entered: K

Example 2: Read Until Newline or EOF

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter a line: ");

    while ((ch = getchar()) != '\n' && ch != EOF)
    {
        putchar(ch);
    }

    putchar('\n');

    return 0;
}
Sample Interaction: 
Enter a line: Embedded C Programming
Embedded C Programming

The loop reads characters until it encounters a newline or EOF.

Use an int variable to store the result of getchar(). This is necessary to distinguish an actual character value from EOF.

6. putchar() Function

putchar() writes a single character to the standard output stream.

Syntax

int putchar(int character);

Return Value

  • Returns the character written, converted to an unsigned char value and then to int, on success.
  • Returns EOF if a write error occurs.

Example 1: Display One Character

#include <stdio.h>

int main(void)
{
    putchar('A');
    putchar('\n');

    return 0;
}
Expected Output: 
A

Example 2: Display Multiple Characters

#include <stdio.h>

int main(void)
{
    char text[] = "HELLO";
    int i = 0;

    while (text[i] != '\0')
    {
        putchar(text[i]);
        i++;
    }

    putchar('\n');

    return 0;
}
Expected Output: 
HELLO

The loop displays each character until it encounters the null terminator.

7. Understanding EOF

EOF stands for End Of File. It is a negative integer constant used to indicate that an input operation has reached the end of the stream or encountered a read error.

It is declared in stdio.h.

Important Characteristics

  • EOF is not an ordinary character stored at the end of every file.
  • It is returned by input functions when no further input can be read or an error occurs.
  • Its value is guaranteed to be negative.
  • Use an int variable to store function results when checking EOF.

Example: Read Input Until EOF

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter text (send EOF to finish):\n");

    while ((ch = getchar()) != EOF)
    {
        putchar(ch);
    }

    return 0;
}

The program continues reading input until EOF is received.

Sending EOF from a Terminal

Operating System Common Keyboard Shortcut
Linux Ctrl + D at the beginning of an input line.
Windows console Ctrl + Z followed by Enter in common console environments.
Terminal shortcuts are environment-dependent. EOF is a stream condition, not a special keyboard character that C reads as ordinary input.

8. Difference Between getchar() and putchar()

Feature getchar() putchar()
Purpose Reads one character. Writes one character.
Default stream stdin stdout
Syntax getchar(void) putchar(int)
Return type int int
Failure/end condition Returns EOF on end-of-file or read error. Returns EOF on write error.

Combined Example

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter a character: ");

    ch = getchar();

    if (ch != EOF)
    {
        printf("Output character: ");
        putchar(ch);
        putchar('\n');
    }

    return 0;
}

9. Basic Console Input and Output Program

This program demonstrates the basic communication between a user and a C program using standard input and output.

#include <stdio.h>

int main(void)
{
    int first;
    int second;
    int sum;

    printf("Enter first number: ");

    if (scanf("%d", &first) != 1)
    {
        fprintf(stderr, "Invalid first number.\n");
        return 1;
    }

    printf("Enter second number: ");

    if (scanf("%d", &second) != 1)
    {
        fprintf(stderr, "Invalid second number.\n");
        return 1;
    }

    sum = first + second;

    printf("Sum = %d\n", sum);

    return 0;
}
Sample Interaction: 
Enter first number: 10
Enter second number: 20
Sum = 30

The program uses:

  • printf() to display prompts and results.
  • scanf() to read integers.
  • stderr to report invalid input.
  • return 1 to indicate unsuccessful execution.

The next lectures will explain printf() and scanf() in detail.

10. Common Mistakes in Standard I/O

Mistake 1: Storing getchar() Result in char

Risky approach: 
char ch;

ch = getchar();

This is unsuitable when the program must distinguish all possible character values from EOF.

Correct approach: 
int ch;

ch = getchar();

Mistake 2: Forgetting the Header File

Functions such as printf() and getchar() are declared in stdio.h.

#include <stdio.h>

Mistake 3: Assuming getchar() Reads a Whole Line

getchar() reads one character at a time. To read a complete line, a suitable line-input function such as fgets() should be used.

Mistake 4: Ignoring Input Errors

Input functions can fail. Programs should check return values, especially when processing user input or files.

Mistake 5: Confusing Newline and EOF

A newline character '\n' is an ordinary character. EOF is a separate negative return value indicating that no further input is available or a read error occurred.

12. Technical Interview Questions

Q1. What is standard I/O in C?

Standard I/O is the set of facilities provided by the C standard library for input and output operations through streams.

Q2. What is stdio.h?

It is the standard C header file that declares input/output functions, stream types and related macros.

Q3. What are stdin, stdout and stderr?

They are the three predefined standard streams for input, normal output and diagnostic output.

Q4. What is getchar()?

It reads one character from the standard input stream and returns an int.

Q5. Why does getchar() return int instead of char?

It must represent every possible character value as well as the special EOF value.

Q6. What is putchar()?

It writes one character to the standard output stream and returns an int indicating success or failure.

Q7. What is EOF?

EOF is a negative integer constant used by input functions to indicate end-of-file or a read error.

Q8. Is EOF a character?

No. It is a special integer value returned by input functions.

Q9. What is the difference between stdout and stderr?

stdout is used for normal output, while stderr is intended for diagnostic and error messages.

Q10. Can standard streams be redirected?

Yes. Operating systems and execution environments commonly allow standard input, output and error streams to be redirected.

Q11. What happens when getchar() reaches EOF?

It returns EOF. A program should check the return value using an int variable.

Q12. Can standard I/O be used in embedded systems?

Yes, if the embedded compiler and runtime provide suitable support. Standard streams can be redirected to interfaces such as UART.

15. Lecture Summary

  • Input and output operations allow a program to communicate with its environment.
  • stdio.h provides declarations for standard I/O functions.
  • stdin, stdout and stderr are predefined standard streams.
