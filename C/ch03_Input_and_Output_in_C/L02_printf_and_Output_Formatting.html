2. Introduction to printf()

printf() is a standard C library function used to display formatted output on the standard output stream, normally the terminal.

It is declared in the stdio.h header file.

Syntax

int printf(const char *format, ...);

Parameters:

  • format: A string containing ordinary characters and conversion specifications.
  • ...: Optional arguments whose values are formatted according to the conversion specifications.

Return value:

  • Returns the number of characters transmitted on success.
  • Returns a negative value if an output error occurs.

Basic Example

#include <stdio.h>

int main(void)
{
    printf("Welcome to C Programming!\n");

    return 0;
}
Expected Output: 
Welcome to C Programming!

3. Format Specifiers

A format specifier tells printf() how to convert an argument into its textual representation.

It generally begins with the percentage symbol (%).

3.1 Common Format Specifiers

Specifier Expected Argument Type Purpose
%d or %i int Display a signed decimal integer.
%u unsigned int Display an unsigned decimal integer.
%o unsigned int Display an unsigned octal integer.
%x unsigned int Display an unsigned hexadecimal integer using lowercase letters.
%X unsigned int Display an unsigned hexadecimal integer using uppercase letters.
%f double Display a floating-point value in decimal notation.
%e or %E double Display a floating-point value in scientific notation.
%g or %G double Choose between decimal and scientific notation.
%c int Display a character value.
%s Pointer to a character array Display a null-terminated string.
%p void pointer Display a pointer value.
%zu size_t Display an unsigned size value.
%% No additional argument Display the percentage symbol.
Format specifiers must match the actual argument types after the default argument promotions. A mismatch can cause undefined behavior. Do not rely on the compiler to detect every mismatch.

3.2 Example: Display Different Data Types

#include <stdio.h>

int main(void)
{
    int age = 25;
    unsigned int count = 100;
    float temperature = 36.5f;
    double salary = 45000.75;
    char grade = 'A';
    char name[] = "Rahul";

    printf("Name: %s\n", name);
    printf("Age: %d\n", age);
    printf("Count: %u\n", count);
    printf("Temperature: %.1f\n", temperature);
    printf("Salary: %.2f\n", salary);
    printf("Grade: %c\n", grade);

    return 0;
}
Expected Output: 
Name: Rahul
Age: 25
Count: 100
Temperature: 36.5
Salary: 45000.75
Grade: A
A float argument is promoted to double when passed through the variadic arguments of printf(). Therefore, %f is used for both float variables and double variables in printf().

4. Integer Output Formatting

Integer format specifiers can display values in decimal, octal and hexadecimal representations.

Example: Decimal, Octal and Hexadecimal

#include <stdio.h>

int main(void)
{
    unsigned int number = 255;

    printf("Decimal: %u\n", number);
    printf("Octal: %o\n", number);
    printf("Hexadecimal: %x\n", number);
    printf("Uppercase Hexadecimal: %X\n", number);

    return 0;
}
Expected Output: 
Decimal: 255
Octal: 377
Hexadecimal: ff
Uppercase Hexadecimal: FF

Example: Display a Percentage

#include <stdio.h>

int main(void)
{
    int marks = 85;

    printf("Marks: %d%%\n", marks);

    return 0;
}
Expected Output: 
Marks: 85%

5. Floating-Point Output Formatting

Floating-point values can be displayed in decimal, scientific or automatically selected notation.

5.1 Decimal Notation (%f)

#include <stdio.h>

int main(void)
{
    double value = 123.456789;

    printf("Value: %f\n", value);

    return 0;
}
Value: 123.456789

5.2 Scientific Notation (%e)

#include <stdio.h>

int main(void)
{
    double value = 12345.6789;

    printf("Scientific: %e\n", value);

    return 0;
}
Scientific: 1.234568e+04

5.3 General Format (%g)

%g selects either decimal or scientific notation depending on the value and precision.

#include <stdio.h>

int main(void)
{
    double a = 123.456;
    double b = 0.0000123456;

    printf("%g\n", a);
    printf("%g\n", b);

    return 0;
}
123.456
1.23456e-05

6. Field Width

Field width specifies the minimum number of character positions reserved for an output value.

If the formatted value is shorter than the specified width, padding is added. By default, numeric output is right-aligned.

Syntax

%widthspecifier

Example

#include <stdio.h>

int main(void)
{
    int a = 25;
    int b = 1000;

    printf("|%5d|\n", a);
    printf("|%5d|\n", b);

    return 0;
}
Expected Output: 
|   25|
| 1000|

The width is five positions. The number is not truncated if it requires more positions than the specified width.

Left Alignment

The minus flag (-) aligns the output to the left within the specified field width.

#include <stdio.h>

int main(void)
{
    printf("|%-10s|\n", "C");
    printf("|%-10s|\n", "Embedded");

    return 0;
}
|C         |
|Embedded  |

7. Precision in printf()

Precision controls the number of digits displayed for floating-point conversions and the maximum number of characters displayed for strings.

7.1 Floating-Point Precision

For %f, precision specifies the number of digits after the decimal point. The default precision is six.

#include <stdio.h>

int main(void)
{
    double value = 12.345678;

    printf("%f\n", value);
    printf("%.2f\n", value);
    printf("%.4f\n", value);

    return 0;
}
12.345678
12.35
12.3457

7.2 String Precision

For %s, precision specifies the maximum number of characters to be printed.

#include <stdio.h>

int main(void)
{
    char name[] = "Embedded Systems";

    printf("%.8s\n", name);

    return 0;
}
Embedded

7.3 Combining Width and Precision

#include <stdio.h>

int main(void)
{
    double value = 45.6789;

    printf("|%10.2f|\n", value);

    return 0;
}
|     45.68|

Here:

  • 10 specifies the minimum field width.
  • .2 specifies two digits after the decimal point.

8. Formatting Flags

Flags modify the appearance of formatted output.

Flag Meaning
- Left-align the output within the field width.
+ Always display a sign for signed numeric conversions.
Space Prefix a positive signed value with a space when no sign is printed.
0 Pad numeric output with leading zeros where applicable.
# Use an alternative representation for applicable conversions.

8.1 Plus Flag

#include <stdio.h>

int main(void)
{
    printf("%+d\n", 25);
    printf("%+d\n", -25);

    return 0;
}
+25
-25

8.2 Zero Flag

#include <stdio.h>

int main(void)
{
    printf("%05d\n", 42);

    return 0;
}
00042

8.3 Alternative Form (#)

#include <stdio.h>

int main(void)
{
    printf("%#x\n", 255);
    printf("%#o\n", 8);
    printf("%#.2f\n", 12.0);

    return 0;
}
0xff
010
12.00

The alternative form adds a hexadecimal prefix for nonzero hexadecimal values, ensures an octal representation has the appropriate leading zero, and retains a decimal point for floating-point output where applicable.

The zero flag is ignored when the minus flag is present. It is also not used for conversions such as strings and characters.

9. Length Modifiers

Length modifiers adjust the type expected by an integer or floating-point conversion specifier.

Modifier Example Typical Use
hh %hhd signed char argument after promotion.
h %hd short int argument after promotion.
l %ld long int.
ll %lld long long int.
z %zu size_t.
j %jd intmax_t.
t %td ptrdiff_t.
L %Lf long double.

Example: Long and Long Long Integers

#include <stdio.h>

int main(void)
{
    long int population = 500000L;
    long long int distance = 9000000000LL;

    printf("Population: %ld\n", population);
    printf("Distance: %lld\n", distance);

    return 0;
}
Population: 500000
Distance: 9000000000

Example: sizeof() with %zu

#include <stdio.h>

int main(void)
{
    int number = 10;

    printf("Size of int: %zu bytes\n", sizeof(number));

    return 0;
}

The numeric result depends on the implementation's size of int.

Interview Tip: sizeof returns a value of type size_t. Use %zu to print it in C99 and later, including C11.

10. Escape Sequences

Escape sequences are special character combinations beginning with a backslash (\). They represent characters that cannot always be written directly in a string literal.

Escape Sequence Meaning
\nNewline
\tHorizontal tab
\rCarriage return
\bBackspace
\aAlert character
\\Backslash
\"Double quotation mark
\'Single quotation mark
\0Null character

Example: Escape Sequences

#include <stdio.h>

int main(void)
{
    printf("Name\tAge\n");
    printf("Amit\t25\n");
    printf("Path: C:\\Projects\\C\n");
    printf("He said, \"Hello!\"\n");

    return 0;
}
Expected Output: 
Name    Age
Amit    25
Path: C:\Projects\C
He said, "Hello!"
The exact visual width of a tab depends on the terminal or output environment.

11. Dynamic Field Width and Precision

The asterisk (*) allows field width or precision to be supplied as an additional integer argument.

Example

#include <stdio.h>

int main(void)
{
    int width = 10;
    int precision = 3;
    double value = 123.456789;

    printf("|%*.*f|\n", width, precision, value);

    return 0;
}
|   123.457|

Argument order:

  1. Field width: 10
  2. Precision: 3
  3. Value: 123.456789

12. printf() Return Value

printf() returns the number of characters transmitted to the output stream, excluding the terminating null character of the format string. A negative value indicates an output error.

Example

#include <stdio.h>

int main(void)
{
    int count;

    count = printf("Hello");

    printf("\nCharacters printed: %d\n", count);

    return 0;
}
Expected Output: 
Hello
Characters printed: 5

The word Hello contains five characters, so the return value is 5.

13. Important Rules and Common Mistakes

13.1 Format Specifier Mismatch

Incorrect: 
double value = 12.5;
printf("%d", value);

This has undefined behavior because %d expects an int argument, but a double is supplied.

Correct: 
double value = 12.5;
printf("%f", value);

13.2 Incorrect Pointer Formatting

Use %p for pointer values. The corresponding argument should be converted to void *.

#include <stdio.h>

int main(void)
{
    int number = 10;
    int *ptr = &number;

    printf("Address: %p\n", (void *)ptr);

    return 0;
}

The actual address is implementation-dependent.

13.3 Missing Arguments

Incorrect: 
printf("Age: %d\n");

The format string requires an int argument, but none is provided. This results in undefined behavior.

13.4 Incorrect Use of Percentage Symbol

To display a percentage symbol, use %%.

printf("Completion: 90%%\n");
Completion: 90%

13.5 Unbounded String Output

The %s conversion expects a pointer to a valid null-terminated character sequence. If the string is not properly terminated or accessible, behavior is undefined.

14. Practical Program: Formatted Student Report

This program combines strings, integers, floating-point values, field width and precision to display a simple student report.

#include <stdio.h>

int main(void)
{
    char name[] = "Amit";
    int roll_number = 101;
    float marks = 87.456f;

    printf("----------------------------------\n");
    printf("          STUDENT REPORT\n");
    printf("----------------------------------\n");

    printf("%-15s : %s\n", "Name", name);
    printf("%-15s : %d\n", "Roll Number", roll_number);
    printf("%-15s : %.2f\n", "Marks", marks);

    printf("----------------------------------\n");

    return 0;
}
Expected Output: 
----------------------------------
          STUDENT REPORT
----------------------------------
Name            : Amit
Roll Number     : 101
Marks           : 87.46
----------------------------------

This type of formatting is useful when generating readable reports, logs and command-line application output.

15. Technical Interview Questions

Q1. What is printf()?

printf() is a standard C library function used to display formatted output on stdout.

Q2. What is the return type of printf()?

It returns int: the number of characters transmitted on success, or a negative value on output error.

Q3. What is a format specifier?

It is a conversion specification that determines how an argument is represented in the output.

Q4. What is the difference between %d and %u?

%d formats a signed decimal integer, while %u formats an unsigned decimal integer.

Q5. What is the difference between %f and %e?

%f uses decimal notation, while %e uses scientific notation.

Q6. Why is %zu used with sizeof()?

sizeof returns size_t, and %zu is the corresponding format for that type.

Q7. What is field width?

It specifies the minimum number of character positions reserved for a formatted value.

Q8. What is precision in printf()?

For floating-point conversions it controls displayed precision. For strings it limits the maximum number of characters printed.

Q9. What does the minus flag do?

It left-aligns the output within the specified field width.

Q10. How do you print a percentage symbol?

Use %% in the format string.

Q11. What happens if the format specifier does not match the argument type?

It can result in undefined behavior. The format specification and argument type must be compatible.

Q12. What is the purpose of %p?

It is used to display a pointer value. The argument should have type void *.

Q13. What does %g do?

It selects between fixed decimal and scientific notation based on the value and precision.

Q14. What is the difference between width and precision?

Width controls the minimum output field size. Precision controls numeric detail or the maximum number of characters for string output.

17. Multiple-Choice Questions (MCQs)

1. Which format specifier is used for an unsigned int?
  1. %d
  2. %u
  3. %f
  4. %c

Answer: B — %u

2. What does %.2f specify?
  1. Two digits before the decimal point
  2. Two digits after the decimal point
  3. Two characters in total
  4. Two floating-point values

Answer: B — Two digits after the decimal point

3. Which specifier is appropriate for size_t?
  1. %d
  2. %f
  3. %zu
  4. %c

Answer: C — %zu

4. What does %% display?
  1. Backslash
  2. Percentage symbol
  3. Newline
  4. Null character

Answer: B — Percentage symbol

5. What does the minus flag do?
  1. Right-aligns output
  2. Left-aligns output
  3. Removes decimal places
  4. Displays a negative sign

Answer: B — Left-aligns output

6. What does printf() return on successful output?
  1. Always 0
  2. Number of arguments
  3. Number of characters transmitted
  4. Number of format specifiers

Answer: C — Number of characters transmitted

7. Which specifier is used for a long long int?
  1. %ld
  2. %lld
  3. %d
  4. %zu

Answer: B — %lld

8. Which specifier is used for a pointer?
  1. %s
  2. %c
  3. %p
  4. %x

Answer: C — %p
