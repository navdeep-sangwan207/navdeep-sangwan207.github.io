After completing this lecture, you will be able to:

2. Introduction to scanf()

scanf() is a standard C library function used to read formatted input from the standard input stream, normally the keyboard.

It is declared in the stdio.h header file.

Syntax

int scanf(const char *format, ...);

Parameters:

  • format: A string containing conversion specifications and optional whitespace or literal characters.
  • ...: Addresses of objects where successfully converted input values are stored.

Return value:

  • Returns the number of input items successfully matched and assigned.
  • Returns EOF if an input failure occurs before the first conversion completes.
  • Returns zero if no conversion is assigned and an input item does not match the format.

Basic Example

#include <stdio.h>

int main(void)
{
    int age;

    printf("Enter your age: ");

    if (scanf("%d", &age) == 1)
    {
        printf("Your age is %d\n", age);
    }
    else
    {
        printf("Invalid input.\n");
    }

    return 0;
}
Sample Interaction: 
Enter your age: 25
Your age is 25

3. Understanding the Address-of Operator (&)

Most scanf() conversions require the address of the destination variable because the function must store the converted input value in the variable.

Example

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("Number = %d\n", number);

    return 0;
}

Consider the statement:

scanf("%d", &number);
  • number represents the value stored in the variable.
  • &number represents the memory address of the variable.
  • scanf() uses that address to store the converted input.

Memory Concept

Variable: number

Address:  0x1000
Value:    25

scanf("%d", &number);

The address of number is passed
so scanf() can store the input.
The %s conversion for a character array is an important exception: the array expression is converted to a pointer to its first element, so & is not used in the usual form.

4. Common scanf() Format Specifiers

Specifier Destination Type Purpose
%d int * Read a signed decimal integer.
%i int * Read an integer with base detection.
%u unsigned int * Read an unsigned decimal integer.
%o unsigned int * Read an unsigned octal integer.
%x unsigned int * Read an unsigned hexadecimal integer.
%f float * Read a float.
%lf double * Read a double.
%Lf long double * Read a long double.
%c char * Read a character.
%s char * Read a sequence of non-whitespace characters.
%p void ** Read a pointer representation into a void pointer object.
%zu size_t * Read a size_t value.
The scanf() and printf() format rules are not identical. For example, scanf() uses %f for float* and %lf for double*, whereas printf() uses %f for both float and double arguments.

Example: Reading Different Data Types

#include <stdio.h>

int main(void)
{
    int age;
    float height;
    double salary;
    char grade;

    printf("Enter age, height, salary and grade: ");

    if (scanf("%d %f %lf %c",
              &age, &height, &salary, &grade) == 4)
    {
        printf("Age: %d\n", age);
        printf("Height: %.2f\n", height);
        printf("Salary: %.2f\n", salary);
        printf("Grade: %c\n", grade);
    }
    else
    {
        printf("Input conversion failed.\n");
    }

    return 0;
}
Sample Interaction: 
Enter age, height, salary and grade: 25 5.8 35000.50 A
Age: 25
Height: 5.80
Salary: 35000.50
Grade: A

5. Reading Multiple Values

Multiple variables can be read in a single scanf() statement by supplying matching conversion specifications and destination addresses.

Example: Read Two Integers

#include <stdio.h>

int main(void)
{
    int a, b;

    printf("Enter two integers: ");

    if (scanf("%d %d", &a, &b) == 2)
    {
        printf("First number: %d\n", a);
        printf("Second number: %d\n", b);
        printf("Sum: %d\n", a + b);
    }
    else
    {
        printf("Invalid input.\n");
    }

    return 0;
}
Sample Interaction: 
Enter two integers: 10 20
First number: 10
Second number: 20
Sum: 30

The conversion specifications are processed from left to right, and the corresponding addresses receive the converted values.

6. Difference Between %d and %i in scanf()

Both %d and %i read signed integers, but they differ in how the input base is interpreted.

Specifier Input Interpretation
%d Decimal representation.
%i Base is detected from the input representation.

Example

#include <stdio.h>

int main(void)
{
    int decimal_value;
    int detected_value;

    printf("Enter a number for %%d: ");
    if (scanf("%d", &decimal_value) != 1)
        return 1;

    printf("Enter a number for %%i: ");
    if (scanf("%i", &detected_value) != 1)
        return 1;

    printf("%%d result: %d\n", decimal_value);
    printf("%%i result: %d\n", detected_value);

    return 0;
}
Sample Interaction: 
Enter a number for %d: 012
Enter a number for %i: 012
%d result: 12
%i result: 10

With %i, a leading zero indicates octal input. The value 012 in octal is decimal 10.

7. Character Input Using %c

The %c conversion reads a character. Unlike most numeric conversions, it does not automatically skip leading whitespace.

Example: Read a Character

#include <stdio.h>

int main(void)
{
    char grade;

    printf("Enter grade: ");

    if (scanf("%c", &grade) == 1)
    {
        printf("Grade: %c\n", grade);
    }
    else
    {
        printf("Character input failed.\n");
    }

    return 0;
}
Sample Interaction: 
Enter grade: A
Grade: A

Skipping Leading Whitespace Before %c

Place a space before %c when the intention is to skip whitespace characters before reading the next non-whitespace character.

#include <stdio.h>

int main(void)
{
    int age;
    char grade;

    printf("Enter age: ");

    if (scanf("%d", &age) != 1)
        return 1;

    printf("Enter grade: ");

    if (scanf(" %c", &grade) != 1)
        return 1;

    printf("Age: %d\n", age);
    printf("Grade: %c\n", grade);

    return 0;
}
Sample Interaction: 
Enter age: 25
Enter grade: A
Age: 25
Grade: A
The leading space in " %c" consumes any number of input whitespace characters, including spaces, tabs and newlines, before the character conversion.

8. String Input Using %s

The %s conversion reads a sequence of non-whitespace characters and stores them in a character array followed by a null terminator.

Example: Read a Name

#include <stdio.h>

int main(void)
{
    char name[30];

    printf("Enter your name: ");

    if (scanf("%29s", name) == 1)
    {
        printf("Welcome, %s!\n", name);
    }
    else
    {
        printf("Input failed.\n");
    }

    return 0;
}
Sample Interaction: 
Enter your name: Rahul
Welcome, Rahul!

The width of 29 ensures that at most 29 input characters are stored, leaving one array element for the null terminator.

Important: Never use an unbounded %s conversion with a fixed-size character array. Excessive input can write beyond the array and cause undefined behavior.

Limitation of %s

%s stops at the first whitespace character. Therefore, it does not read a complete line containing spaces.

For example, entering Rahul Sharma stores only Rahul in the array during that conversion. Complete-line input will be covered in Lecture 4.

9. Field Width in scanf()

Field width limits the maximum number of input characters consumed by a conversion.

Example: Limit String Input

#include <stdio.h>

int main(void)
{
    char name[10];

    printf("Enter name: ");

    if (scanf("%9s", name) == 1)
    {
        printf("Name: %s\n", name);
    }
    else
    {
        printf("Input failed.\n");
    }

    return 0;
}
Sample Interaction: 
Enter name: Alexander
Name: Alexander

The array has ten elements. At most nine input characters are stored, and the remaining element is used for '\0'.

A field width limits the current conversion. Any remaining input characters stay in the stream and may affect subsequent input operations.

10. Whitespace Handling in scanf()

Whitespace handling is one of the most important concepts for understanding formatted input.

10.1 Numeric Conversions

Most numeric conversions, including %d, %i, %f and %lf, skip leading whitespace automatically.

10.2 Character Conversion

%c does not skip leading whitespace automatically.

10.3 String Conversion

%s skips leading whitespace but stops when it encounters the next whitespace character.

Conversion Skips Leading Whitespace?
%d Yes
%f Yes
%lf Yes
%c No
%s Yes

Example: Character After Integer Input

#include <stdio.h>

int main(void)
{
    int number;
    char ch;

    printf("Enter an integer: ");

    if (scanf("%d", &number) != 1)
        return 1;

    printf("Enter a character: ");

    if (scanf("%c", &ch) != 1)
        return 1;

    printf("Number: %d\n", number);
    printf("Character code: %d\n", (unsigned char)ch);

    return 0;
}

If the user enters an integer followed by Enter, the newline character may be consumed by %c. The output therefore displays the numeric code of that newline character rather than the next visible character.

Corrected Version

scanf("%d", &number);
scanf(" %c", &ch);

The leading whitespace in the second format string skips the pending newline and other whitespace.

11. Return Value and Input Validation

Checking the return value of scanf() is essential for reliable programs.

Example: Validate an Integer

#include <stdio.h>

int main(void)
{
    int number;
    int result;

    printf("Enter an integer: ");

    result = scanf("%d", &number);

    if (result == 1)
    {
        printf("Valid integer: %d\n", number);
    }
    else if (result == 0)
    {
        printf("Input does not match an integer.\n");
    }
    else
    {
        printf("Input failure or end-of-file.\n");
    }

    return 0;
}
Sample Interaction 1: 
Enter an integer: 50
Valid integer: 50
Sample Interaction 2: 
Enter an integer: Hello
Input does not match an integer.

Meaning of Return Values

Return Value Meaning
1 One input item was successfully converted and assigned.
2 Two input items were successfully converted and assigned.
0 No conversion was assigned because the next input item did not match the format.
EOF Input failure occurred before the first conversion completed.
scanf() returning zero does not necessarily mean the stream has ended. The invalid input character may remain unread, so repeating the same scanf() call without consuming or otherwise handling the input can cause an infinite loop.

12. Assignment Suppression

The asterisk (*) in a conversion specification tells scanf() to read and convert an input item but not assign it to a variable.

Example

#include <stdio.h>

int main(void)
{
    int day;
    int year;

    printf("Enter date in DD-MM-YYYY format: ");

    if (scanf("%d-%*d-%d", &day, &year) == 2)
    {
        printf("Day: %d\n", day);
        printf("Year: %d\n", year);
    }
    else
    {
        printf("Invalid date format.\n");
    }

    return 0;
}
Sample Interaction: 
Enter date in DD-MM-YYYY format: 20-11-2026
Day: 20
Year: 2026

The middle numeric field is converted but not assigned. Suppressed conversions do not contribute to the return value.

13. Scansets in scanf()

A scanset allows scanf() to read a sequence of characters from a specified set.

It uses square brackets in the conversion specification.

Example: Read Until a Comma

#include <stdio.h>

int main(void)
{
    char name[30];

    printf("Enter name followed by comma: ");

    if (scanf("%29[^,]", name) == 1)
    {
        printf("Name: %s\n", name);
    }
    else
    {
        printf("Input failed.\n");
    }

    return 0;
}
Sample Interaction: 
Enter name followed by comma: Rahul Sharma,Engineer
Name: Rahul Sharma

Common Scanset Forms

Format Purpose
%[abc] Accepts a sequence containing a, b or c.
%[A-Z] Accepts characters in the specified range according to the execution character set.
%[^,] Accepts characters until a comma is encountered.
%[^ ] Accepts characters until a space is encountered.
Always use a field width with scansets when reading into a fixed-size character array. The width must leave room for the terminating null character.

14. Common scanf() Errors

Error 1: Missing Address Operator

Incorrect: 
int number;
scanf("%d", number);

The conversion expects an int pointer, but the expression supplies an int value. This causes undefined behavior.

Correct: 
int number;
scanf("%d", &number);

Error 2: Wrong Floating-Point Specifier

Incorrect: 
double value;
scanf("%f", &value);

%f expects a float pointer in scanf().

Correct: 
double value;
scanf("%lf", &value);

Error 3: Unbounded String Input

Unsafe: 
char name[10];
scanf("%s", name);
Safer: 
char name[10];
scanf("%9s", name);

Error 4: Ignoring Return Values

Using variables without checking whether scanf() assigned them successfully can lead to the use of uninitialized values.

Error 5: Assuming %s Reads a Complete Line

%s stops at whitespace. Use a suitable line-reading function when spaces must be preserved.

Error 6: Assuming %c Skips Newline

Use a leading whitespace character in the format string when whitespace should be skipped before a character conversion.

15. Practical Program: Student Data Entry

This program reads a student's roll number, age, percentage and grade, and validates the number of successful conversions.

#include <stdio.h>

int main(void)
{
    int roll_number;
    int age;
    float percentage;
    char grade;

    printf("Enter roll number: ");

    if (scanf("%d", &roll_number) != 1)
    {
        fprintf(stderr, "Invalid roll number.\n");
        return 1;
    }

    printf("Enter age: ");

    if (scanf("%d", &age) != 1)
    {
        fprintf(stderr, "Invalid age.\n");
        return 1;
    }

    printf("Enter percentage: ");

    if (scanf("%f", &percentage) != 1)
    {
        fprintf(stderr, "Invalid percentage.\n");
        return 1;
    }

    printf("Enter grade: ");

    if (scanf(" %c", &grade) != 1)
    {
        fprintf(stderr, "Invalid grade.\n");
        return 1;
    }

    printf("\n------ STUDENT DETAILS ------\n");
    printf("Roll Number: %d\n", roll_number);
    printf("Age: %d\n", age);
    printf("Percentage: %.2f\n", percentage);
    printf("Grade: %c\n", grade);

    return 0;
}
Sample Interaction: 
Enter roll number: 101
Enter age: 22
Enter percentage: 87.5
Enter grade: A

------ STUDENT DETAILS ------
Roll Number: 101
Age: 22
Percentage: 87.50
Grade: A

This program demonstrates:

  • Reading multiple data types.
  • Matching conversion specifiers with destination types.
  • Checking scanf() return values.
  • Skipping whitespace before character input.
  • Displaying diagnostic messages through stderr.

16. Technical Interview Questions

Q1. What is scanf()?

scanf() is a standard C library function used to read formatted input from stdin.

Q2. Why is the address-of operator used with scanf()?

Most conversions require a pointer to the destination object so the converted value can be stored in that object.

Q3. What is the return type of scanf()?

It returns int, representing the number of successfully assigned input items or EOF in the specified input-failure condition.

Q4. What is the difference between %d and %i?

%d reads decimal input, while %i detects the input base from its representation.

Q5. What is the difference between %f and %lf in scanf()?

%f expects float*, whereas %lf expects double*.

Q6. Does %c skip whitespace?

No. A leading whitespace character in the format string can be used to skip input whitespace before %c.

Q7. Does %s read spaces?

No. It reads a sequence of non-whitespace characters.

Q8. How do you prevent buffer overflow when using %s?

Specify a field width that is one less than the destination array capacity.

Q9. What does scanf() return when the input does not match the first conversion?

It returns zero if a matching failure occurs before any assignment.

Q10. What is assignment suppression?

It allows an input field to be converted and consumed without assigning it to a destination variable.

Q11. What is a scanset?

A scanset specifies a set of characters that a conversion can accept, or a set of characters to exclude.

Q12. What is the difference between scanf() and printf()?

scanf() reads formatted input, while printf() writes formatted output.

4. What does scanf() return when the first conversion encounters a matching failure?
  1. EOF

20. Lecture Summary

  • scanf() reads formatted input from stdin.
  • Most conversions require the address of the destination variable.
  • %d reads decimal integers, while %i detects the base.
  • %f reads float and %lf reads double.
  • %c does not automatically skip leading whitespace.
  • %s reads non-whitespace characters and appends a null terminator.
  • Field width helps limit the number of input characters.
  • Scansets allow controlled character input.
  • Assignment suppression consumes an input field without assigning it.
  • Always check scanf() return values before using input variables.
