2. What Is Input Validation?

Input validation is the process of checking whether user-provided data satisfies the requirements of a program before using it.

For example, suppose a program asks for a student's age.

Input Validation Result Reason
21 Valid Numeric value within the permitted range.
-5 Invalid Negative age is not accepted by the application.
abc Invalid Not a valid integer.
150 Invalid Outside the application's permitted range.
21abc Invalid Contains unwanted trailing characters.

Input Validation Process

      Receive Input
           |
           v
     Check Input Format
           |
           v
     Check Numeric Range
           |
           v
    Check Application Rules
           |
       +---+---+
       |       |
     Valid   Invalid
       |       |
       v       v
    Process  Report Error
     Input   and Recover
Input validation is important in embedded systems, command-line applications, data-processing programs and software that receives external data.

3. Understanding scanf() Return Values

scanf() returns the number of input items successfully assigned.

Syntax

int scanf(const char *format, ...);

Important return-value cases:

Return Value Meaning
Positive integer Number of successfully assigned input items.
0 Matching failure: the next input item did not match the required conversion.
EOF Input failure occurred before the first conversion completed.

Example: Check scanf() Return Value

#include <stdio.h>

int main(void)
{
    int age;

    printf("Enter your age: ");

    if (scanf("%d", &age) != 1)
    {
        printf("Invalid age input.\n");
        return 1;
    }

    printf("Age: %d\n", age);

    return 0;
}
Valid Input: 
Enter your age: 25
Age: 25
Invalid Input: 
Enter your age: Hello
Invalid age input.
Never assume scanf() has successfully assigned a value. Check its return value before using variables that depend on the conversion.

4. Detecting Partial Input Conversion

When scanf() contains multiple conversion specifications, some conversions may succeed while others fail.

Example

#include <stdio.h>

int main(void)
{
    int number;
    float price;

    printf("Enter an integer and a price: ");

    int result = scanf("%d %f", &number, &price);

    if (result == 2)
    {
        printf("Number: %d\n", number);
        printf("Price: %.2f\n", price);
    }
    else
    {
        printf("Input conversion failed.\n");
    }

    return 0;
}
Valid Input: 
Enter an integer and a price: 10 45.75
Number: 10
Price: 45.75
Partial Conversion: 
Enter an integer and a price: 10 abc
Input conversion failed.

In the second example, the integer conversion succeeds, but the floating-point conversion fails. scanf() returns 1.

A return value of 1 does not mean that the complete input operation succeeded. It means only one item was successfully assigned.

5. Problem: Invalid Input Remaining in the Stream

When a scanf() conversion fails because of a matching failure, the offending input character is generally left unread.

Example of a Repeated Failure

#include <stdio.h>

int main(void)
{
    int number;

    while (scanf("%d", &number) != 1)
    {
        printf("Invalid input. Try again: ");
    }

    printf("Accepted: %d\n", number);

    return 0;
}

If the user enters abc, the integer conversion fails. The characters remain in the stream, so the next scanf() attempts to read the same invalid input again.

Retrying a failed scanf() without consuming or otherwise handling the offending input can create an infinite loop.

6. Recovering from Invalid Input

For simple formatted input, a program can discard the remaining input line before asking again.

Example: Retry Integer Input

#include <stdio.h>

void discard_line(void)
{
    int ch;

    while ((ch = getchar()) != '\n' && ch != EOF)
    {
        /* Discard remaining input. */
    }
}

int main(void)
{
    int number;

    while (1)
    {
        printf("Enter an integer: ");

        if (scanf("%d", &number) == 1)
        {
            discard_line();
            break;
        }

        if (feof(stdin))
        {
            printf("\nEnd of input.\n");
            return 1;
        }

        if (ferror(stdin))
        {
            fprintf(stderr, "\nInput error.\n");
            return 1;
        }

        printf("Invalid input. Try again.\n");
        discard_line();
    }

    printf("Accepted number: %d\n", number);

    return 0;
}
Sample Interaction: 
Enter an integer: abc
Invalid input. Try again.
Enter an integer: 45
Accepted number: 45

Important: This example accepts the first integer conversion on a line and discards the rest of that line. It does not reject additional text such as 45abc. Strict complete-line validation is covered next.

7. Robust Integer Validation Using fgets() and strtol()

A better approach for strict command-line input is to:

  1. Read the complete line using fgets().
  2. Convert the numeric portion using strtol().
  3. Check whether any digits were converted.
  4. Check for range errors.
  5. Check that no unwanted characters remain.

Important Function

long strtol(const char *str, char **endptr, int base);
Parameter Purpose
str String containing the number.
endptr Receives the address of the first unconverted character.
base Number base; 10 means decimal.

Example: Strict Integer Validation

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>
#include <ctype.h>

int main(void)
{
    char line[100];
    char *end;
    long value;

    printf("Enter an integer: ");

    if (fgets(line, sizeof line, stdin) == NULL)
    {
        printf("Input failed or no input available.\n");
        return 1;
    }

    errno = 0;
    value = strtol(line, &end, 10);

    if (end == line)
    {
        printf("No valid integer found.\n");
        return 1;
    }

    while (isspace((unsigned char)*end))
    {
        end++;
    }

    if (errno == ERANGE)
    {
        printf("Integer is outside the range of long.\n");
        return 1;
    }

    if (*end != '\0')
    {
        printf("Unexpected characters in input.\n");
        return 1;
    }

    if (value < INT_MIN || value > INT_MAX)
    {
        printf("Value is outside the range of int.\n");
        return 1;
    }

    printf("Valid integer: %d\n", (int)value);

    return 0;
}
Valid Input: 
Enter an integer: 250
Valid integer: 250
Invalid Input: 
Enter an integer: 25abc
Unexpected characters in input.
Invalid Input: 
Enter an integer: hello
No valid integer found.
strtol() accepts leading whitespace and an optional sign. The end pointer allows the program to check whether the entire remaining input contains only permitted whitespace.

8. Numeric Range Validation

Successful numeric conversion does not automatically mean that the value is valid for the application.

For example, a program may accept an age only between 1 and 120.

Example: Validate an Age Range

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <ctype.h>

int main(void)
{
    char line[100];
    char *end;
    long age;

    printf("Enter your age (1 to 120): ");

    if (fgets(line, sizeof line, stdin) == NULL)
    {
        printf("Input failed.\n");
        return 1;
    }

    errno = 0;
    age = strtol(line, &end, 10);

    if (end == line)
    {
        printf("Please enter a valid integer.\n");
        return 1;
    }

    while (isspace((unsigned char)*end))
    {
        end++;
    }

    if (errno == ERANGE || *end != '\0')
    {
        printf("Invalid numeric input.\n");
        return 1;
    }

    if (age < 1 || age > 120)
    {
        printf("Age must be between 1 and 120.\n");
        return 1;
    }

    printf("Accepted age: %ld\n", age);

    return 0;
}
Valid Input: 
Enter your age (1 to 120): 25
Accepted age: 25
Out-of-Range Input: 
Enter your age (1 to 120): 150
Age must be between 1 and 120.

There are two separate checks:

  • Conversion validation: Is the text a valid integer?
  • Application validation: Is the integer permitted by the program's rules?

9. Detecting EOF and Input Errors

Standard input can end normally or fail because of an input error.

C provides the following functions and macros:

Function / Macro Purpose
EOF Special negative integer value used by certain input operations to indicate end-of-file or input failure.
feof(stream) Checks whether the end-of-file indicator is set for a stream.
ferror(stream) Checks whether the error indicator is set for a stream.
clearerr(stream) Clears both the EOF and error indicators.

Example: Check Input Status

#include <stdio.h>

int main(void)
{
    int ch;

    printf("Enter characters. Send EOF to finish:\n");

    while ((ch = getchar()) != EOF)
    {
        putchar(ch);
    }

    if (ferror(stdin))
    {
        fprintf(stderr, "\nInput error occurred.\n");
        return 1;
    }

    if (feof(stdin))
    {
        printf("\nEnd of input reached.\n");
    }

    return 0;
}

Important distinction:

  • EOF is the return value used to report end-of-file or an input failure.
  • feof() checks the stream's EOF indicator after an input operation has encountered end-of-file.
  • ferror() checks whether a stream error has occurred.
Do not use feof() as the condition for a normal input loop. Attempt the input operation first and check its return value, then inspect feof() or ferror() if needed.

10. Common Input Errors

Error Cause Prevention
Invalid numeric input Letters or malformed data supplied for numeric conversion. Check return values or parse a line with strtol().
Uninitialized variable use Using a variable after failed conversion without assigning a valid value. Check conversion success before using it.
Infinite retry loop Invalid characters remain unread in the stream. Consume invalid input or use line-based parsing.
Unexpected newline Previous input operation left a newline unread. Understand whitespace behavior and consume input deliberately.
Buffer overflow Input exceeds destination capacity. Use bounded input functions such as fgets().
Incomplete line Input line is longer than the destination array. Detect missing newline and handle remaining input.
Unexpected EOF Input stream ends before expected data is received. Check input return values and EOF status.

11. Common Output Errors

Input validation is only one part of reliable I/O. Output operations can also fail.

Examples of Output Problems

  • Writing to a file that cannot be created or opened.
  • Writing to a device or stream that is no longer available.
  • Insufficient storage space while writing a file.
  • Output errors reported by the operating system.

Checking printf() and putchar()

printf() returns the number of characters transmitted, or a negative value if an output error occurs.

putchar() returns the character written or EOF on a write error.

#include <stdio.h>

int main(void)
{
    if (printf("C Programming\n") < 0)
    {
        fprintf(stderr, "Output error.\n");
        return 1;
    }

    if (putchar('A') == EOF)
    {
        fprintf(stderr, "Character output failed.\n");
        return 1;
    }

    return 0;
}

Checking Output Stream Errors

For output operations involving streams, ferror() can be used to check the error indicator.

if (fputs("Hello\n", stdout) == EOF)
{
    fprintf(stderr, "Output operation failed.\n");
    return 1;
}
Buffered output errors may be detected only when the buffer is flushed or the stream is closed. For important file output, check both write operations and the result of fclose().

12. File I/O Error Handling

When working with files, the program should check whether the file was opened successfully before performing input or output.

Example: Safe File Opening and Writing

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("student.txt", "w");

    if (fp == NULL)
    {
        perror("Unable to open file");
        return 1;
    }

    if (fprintf(fp, "Student Record\n") < 0)
    {
        perror("File write failed");

        if (fclose(fp) == EOF)
        {
            perror("File close failed");
        }

        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("File close failed");
        return 1;
    }

    printf("File written successfully.\n");

    return 0;
}

Important checks:

  1. Check whether fopen() returned NULL.
  2. Check whether fprintf() reported a write failure.
  3. Check whether fclose() succeeded.
  4. Use perror() to display an implementation-provided error description when appropriate.
Detailed file operations are covered in Chapter 14: File Handling. Here, the focus is on recognizing and checking I/O errors.

13. Practical Program: Repeated Input with Validation

This program repeatedly asks for a valid integer between 1 and 100. It uses fgets() and strtol() to validate each complete input line.

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <ctype.h>

int main(void)
{
    char line[100];
    char *end;
    long number;

    while (1)
    {
        printf("Enter a number (1 to 100): ");

        if (fgets(line, sizeof line, stdin) == NULL)
        {
            if (ferror(stdin))
            {
                fprintf(stderr, "Input error.\n");
            }
            else
            {
                printf("\nNo more input available.\n");
            }

            return 1;
        }

        errno = 0;
        number = strtol(line, &end, 10);

        if (end == line)
        {
            printf("Invalid input. Enter digits.\n");
            continue;
        }

        while (isspace((unsigned char)*end))
        {
            end++;
        }

        if (errno == ERANGE || *end != '\0')
        {
            printf("Invalid number format.\n");
            continue;
        }

        if (number < 1 || number > 100)
        {
            printf("Number must be between 1 and 100.\n");
            continue;
        }

        printf("Accepted number: %ld\n", number);
        break;
    }

    return 0;
}
Sample Interaction: 
Enter a number (1 to 100): hello
Invalid input. Enter digits.
Enter a number (1 to 100): 150
Number must be between 1 and 100.
Enter a number (1 to 100): 25abc
Invalid number format.
Enter a number (1 to 100): 75
Accepted number: 75
This example assumes each input line fits in the 100-character buffer. A production-grade line reader should also detect an overlong line and discard or process its remaining characters before attempting the next input.

14. Common Interview Questions

Q1. What is input validation?

Input validation checks whether received data satisfies the required format, range and application rules.

Q2. What does scanf() return?

It returns the number of successfully assigned input items or EOF if an input failure occurs before the first conversion completes.

Q3. What is a matching failure in scanf()?

It occurs when the next input item does not match the required conversion specification, such as entering letters where an integer is expected.

Q4. What happens when scanf() fails?

The failed conversion does not assign a value. The offending input may remain unread, so a retry without input recovery can repeat the same failure.

Q5. What is the difference between EOF and NULL?

EOF is an integer constant used by certain input operations. NULL is a null pointer constant used for pointer values.

Q6. What is the purpose of strtol()?

It converts the initial portion of a string to a long integer and provides an end pointer for checking the remaining characters.

Q7. Why is errno checked after strtol()?

It helps detect range errors. The program should set errno to zero before conversion and check whether it becomes ERANGE.

Q8. What is the purpose of feof()?

It checks whether the EOF indicator has been set for a stream after an input operation encounters end-of-file.

Q9. What is the purpose of ferror()?

It checks whether an error indicator has been set for a stream.

Q10. Why is fgets() useful for validation?

It reads a bounded input line, allowing the program to inspect and validate the complete text separately.

Q11. What is the difference between conversion validation and range validation?

Conversion validation checks whether the input can be interpreted as the expected type. Range validation checks whether the resulting value is permitted.

Q12. Why should fclose() be checked after writing a file?

Buffered output may be delivered during stream closure. fclose() can report an error that was not detected by an earlier write call.

16. Multiple-Choice Questions (MCQs)

1. What does scanf() return when two input items are successfully assigned?
  1. 0
  2. 1
  3. 2
  4. EOF

Answer: C — 2

2. What does scanf() return when a matching failure occurs before any assignment?
  1. 0
  2. 1
  3. 2
  4. NULL

Answer: A — 0

3. Which function converts a string into a long integer?
  1. strcpy()
  2. strtol()
  3. strlen()
  4. strcat()

Answer: B — strtol()

4. Which macro indicates a range error in strtol()?
  1. EOF
  2. NULL
  3. ERANGE
  4. EXIT_FAILURE

Answer: C — ERANGE

5. Which function checks a stream's error indicator?
  1. feof()
  2. ferror()
  3. fclose()
  4. fgets()

Answer: B — ferror()

6. Which function checks the EOF indicator of a stream?
  1. feof()
  2. ferror()
  3. fprintf()
  4. fputs()

Answer: A — feof()

7. Which is a good approach for validating a complete input line?
  1. gets() only
  2. fgets() followed by parsing
  3. putchar()
  4. puts()

Answer: B — fgets() followed by parsing

8. Why should fclose() be checked after writing?
  1. It changes the file name
  2. It may report buffered output errors
  3. It converts text to binary
  4. It initializes the file pointer

18. Lecture Summary

  • Input validation checks format, range and application requirements.
  • scanf() returns the number of successfully assigned items.
  • A matching failure may leave invalid characters unread.
  • Always check input function return values.
  • Use fgets() to read bounded lines.
  • Use strtol() for controlled integer conversion.
  • Check errno for range errors after conversion.
  • Use the end pointer to detect unwanted trailing characters.
  • Use feof() and ferror() to inspect stream status.
  • Check output functions and fclose() when writing files.
