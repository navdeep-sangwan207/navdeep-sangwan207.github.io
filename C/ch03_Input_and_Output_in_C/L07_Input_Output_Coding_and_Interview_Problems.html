2. Quick Revision: Standard I/O Functions

Function Purpose Important Detail
printf() Formatted output Returns number of characters written, or a negative value on error.
scanf() Formatted input Returns number of successfully assigned items, or EOF in an input-failure case.
getchar() Reads one character Returns int so that EOF can be distinguished from character values.
putchar() Writes one character Returns the written character or EOF on error.
fgets() Reads a bounded string Can retain the newline if it fits in the buffer.
puts() Writes a string Appends a newline.
fputs() Writes a string to a stream Does not automatically append a newline.
For placement interviews, understand not only what each function does, but also its return value, input limitations and error-handling requirements.

3. Coding Problem 1: Read and Display Student Details

Problem: Write a program to accept a student's name, roll number and percentage, then display the entered details.

Concepts tested: fgets(), strcspn(), scanf(), format specifiers and basic input validation.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[100];
    int roll;
    float percentage;

    printf("Enter student name: ");

    if (fgets(name, sizeof name, stdin) == NULL)
    {
        printf("Name input failed.\n");
        return 1;
    }

    name[strcspn(name, "\n")] = '\0';

    printf("Enter roll number: ");

    if (scanf("%d", &roll) != 1)
    {
        printf("Invalid roll number.\n");
        return 1;
    }

    printf("Enter percentage: ");

    if (scanf("%f", &percentage) != 1)
    {
        printf("Invalid percentage.\n");
        return 1;
    }

    printf("\n--- Student Details ---\n");
    printf("Name       : %s\n", name);
    printf("Roll No.   : %d\n", roll);
    printf("Percentage : %.2f%%\n", percentage);

    return 0;
}
Expected Output: 
Enter student name: Rahul Sharma
Enter roll number: 105
Enter percentage: 82.5

--- Student Details ---
Name       : Rahul Sharma
Roll No.   : 105
Percentage : 82.50%

Interview observation: fgets() is used for the name because a name can contain spaces. The numeric inputs are checked using scanf() return values.

4. Coding Problem 2: Character Frequency Counter

Problem: Read a line of text and count the number of characters, excluding the newline character.

Concepts tested: getchar(), character processing, EOF and loops.

#include <stdio.h>

int main(void)
{
    int ch;
    int count = 0;

    printf("Enter a line of text: ");

    while ((ch = getchar()) != '\n' && ch != EOF)
    {
        count++;
    }

    printf("Number of characters: %d\n", count);

    return 0;
}
Expected Output: 
Enter a line of text: Embedded Systems
Number of characters: 16

Why is ch declared as int? getchar() can return every possible unsigned-character value as well as EOF. An int variable preserves the distinction.

5. Coding Problem 3: Count Vowels, Consonants and Digits

Problem: Accept a line of text and count vowels, consonants and digits.

Concepts tested: fgets(), character classification and type-safe character handling.

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main(void)
{
    char text[200];
    int vowels = 0;
    int consonants = 0;
    int digits = 0;

    printf("Enter text: ");

    if (fgets(text, sizeof text, stdin) == NULL)
    {
        printf("Input failed.\n");
        return 1;
    }

    for (int i = 0; text[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)text[i];

        if (isalpha(ch))
        {
            ch = (unsigned char)tolower(ch);

            if (ch == 'a' || ch == 'e' || ch == 'i' ||
                ch == 'o' || ch == 'u')
            {
                vowels++;
            }
            else
            {
                consonants++;
            }
        }
        else if (isdigit(ch))
        {
            digits++;
        }
    }

    printf("Vowels     : %d\n", vowels);
    printf("Consonants : %d\n", consonants);
    printf("Digits     : %d\n", digits);

    return 0;
}
Expected Output: 
Enter text: Hello C 2026
Vowels     : 2
Consonants : 4
Digits     : 4
Functions from ctype.h should receive EOF or a value representable as unsigned char. Casting the character to unsigned char before calling isalpha(), tolower() or isdigit() avoids undefined behavior for negative plain-char values.

6. Coding Problem 4: Safe Integer Input

Problem: Accept an integer from the user and reject invalid text, extra characters and values outside the int range.

Concepts tested: fgets(), strtol(), errno, ERANGE and input validation.

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>
#include <ctype.h>

int main(void)
{
    char line[100];
    char *end;
    long value;

    printf("Enter an integer: ");

    if (fgets(line, sizeof line, stdin) == NULL)
    {
        printf("Input failed.\n");
        return 1;
    }

    errno = 0;
    value = strtol(line, &end, 10);

    if (end == line)
    {
        printf("No integer found.\n");
        return 1;
    }

    while (isspace((unsigned char)*end))
    {
        end++;
    }

    if (errno == ERANGE)
    {
        printf("Value exceeds long range.\n");
        return 1;
    }

    if (*end != '\0')
    {
        printf("Unexpected characters found.\n");
        return 1;
    }

    if (value < INT_MIN || value > INT_MAX)
    {
        printf("Value exceeds int range.\n");
        return 1;
    }

    printf("Accepted integer: %d\n", (int)value);

    return 0;
}
Valid Input: 
Enter an integer: 125
Accepted integer: 125
Invalid Input: 
Enter an integer: 125abc
Unexpected characters found.

7. Coding Problem 5: Menu-Driven Calculator

Problem: Create a calculator that accepts two numbers and an operator, then performs the selected operation.

Concepts tested: scanf(), switch, arithmetic operators, input validation and division-by-zero checking.

#include <stdio.h>

int main(void)
{
    double a, b;
    char operator;

    printf("Enter first number: ");

    if (scanf("%lf", &a) != 1)
    {
        printf("Invalid first number.\n");
        return 1;
    }

    printf("Enter operator (+, -, *, /): ");

    if (scanf(" %c", &operator) != 1)
    {
        printf("Invalid operator input.\n");
        return 1;
    }

    printf("Enter second number: ");

    if (scanf("%lf", &b) != 1)
    {
        printf("Invalid second number.\n");
        return 1;
    }

    switch (operator)
    {
        case '+':
            printf("Result = %.2f\n", a + b);
            break;

        case '-':
            printf("Result = %.2f\n", a - b);
            break;

        case '*':
            printf("Result = %.2f\n", a * b);
            break;

        case '/':
            if (b == 0.0)
            {
                printf("Division by zero is not allowed.\n");
            }
            else
            {
                printf("Result = %.2f\n", a / b);
            }
            break;

        default:
            printf("Invalid operator.\n");
    }

    return 0;
}
Expected Output: 
Enter first number: 20
Enter operator (+, -, *, /): *
Enter second number: 5
Result = 100.00
Notice the space before %c in scanf(" %c", &operator). It skips leading whitespace, including a leftover newline, before reading the operator.

8. Coding Problem 6: Read a Line and Remove Its Newline

Problem: Read a complete line into a character array and remove the newline if fgets() stored one.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char message[100];

    printf("Enter a message: ");

    if (fgets(message, sizeof message, stdin) == NULL)
    {
        printf("Input failed.\n");
        return 1;
    }

    size_t pos = strcspn(message, "\n");

    if (message[pos] == '\n')
    {
        message[pos] = '\0';
    }

    printf("Message: %s\n", message);
    printf("Length: %zu\n", strlen(message));

    return 0;
}
Expected Output: 
Enter a message: Learn C Programming
Message: Learn C Programming
Length: 19

Important: If the input line fills the buffer before a newline is read, the newline is not present in the array. The program must not blindly remove the final character.

9. Coding Problem 7: Read Characters Until EOF

Problem: Read characters from standard input until EOF and count the total number of characters.

#include <stdio.h>

int main(void)
{
    int ch;
    unsigned long count = 0;

    printf("Enter text. Send EOF to finish:\n");

    while ((ch = getchar()) != EOF)
    {
        count++;
    }

    if (ferror(stdin))
    {
        fprintf(stderr, "Input error occurred.\n");
        return 1;
    }

    printf("\nTotal characters: %lu\n", count);

    return 0;
}

On common systems:

  • Windows: Ctrl+Z followed by Enter sends the console EOF indication.
  • Linux/macOS: Ctrl+D at the beginning of a line sends the terminal EOF indication.
EOF is not an ordinary character stored in the input. It is a special return value reported by input functions.

11. Debugging Problems

Problem 1: Missing Address Operator

int number;
scanf("%d", number);

What is wrong?

scanf() requires the address of the destination integer. Passing an uninitialized integer value instead of its address causes undefined behavior.

Correction:

int number;
scanf("%d", &number);

Problem 2: Incorrect Format Specifier

float price = 25.5f;
printf("%d", price);

What is wrong?

The %d conversion expects an int argument, but price is promoted to double when passed to printf(). The mismatch results in undefined behavior.

Correction:

printf("%.2f", price);

Problem 3: Reading a Character After Numeric Input

int age;
char grade;

scanf("%d", &age);
scanf("%c", &grade);

What is wrong?

The second scanf() may read the newline left by the first input operation instead of the intended grade.

Correction:

scanf("%d", &age);
scanf(" %c", &grade);

Problem 4: Unsafe String Input

char name[10];
scanf("%s", name);

What is wrong?

A long input token can exceed the array capacity and cause a buffer overflow.

Correction for a single word:

char name[10];
scanf("%9s", name);

Correction for a complete line:

char name[100];
fgets(name, sizeof name, stdin);

Problem 5: Ignoring Input Failure

int number;
scanf("%d", &number);
printf("%d\n", number);

What is wrong?

If conversion fails, number has not been assigned by scanf(). Using its uninitialized value results in undefined behavior.

Correction:

int number;

if (scanf("%d", &number) == 1)
{
    printf("%d\n", number);
}
else
{
    printf("Invalid input.\n");
}

12. Technical Interview Questions

Q1. What is the difference between printf() and scanf()?

printf() performs formatted output, while scanf() performs formatted input.

Q2. Why does scanf() require the address operator for ordinary variables?

It needs the destination address to store the converted input value. Array names used for string input are a special case because an array expression generally converts to a pointer to its first element.

Q3. Why should getchar() be assigned to an int variable?

Because getchar() returns either an unsigned-character value converted to int or EOF. An int preserves the distinction.

Q4. What is the difference between getchar() and scanf("%c", &ch)?

Both can read a character. getchar() reads directly from stdin, while scanf() uses a format string. The %c conversion does not skip leading whitespace unless whitespace is specified in the format string.

Q5. Why is fgets() generally safer than gets()?

fgets() limits the number of characters read according to the destination buffer size. gets() has no size limit and was removed from the C11 standard.

Q6. What is the difference between puts() and fputs()?

puts() writes to stdout and appends a newline. fputs() writes to a specified stream and does not append a newline.

Q7. What is the difference between %f and %lf in scanf()?

In scanf(), %f expects a float pointer and %lf expects a double pointer. In printf(), a float argument is promoted to double, and %f is used for double output.

Q8. Why is a space used before %c in scanf(" %c", &ch)?

Whitespace in the format string consumes any amount of input whitespace before the character conversion.

Q9. What is the purpose of strcspn() in string input?

It can locate the first newline in a string read by fgets(), allowing the program to replace that newline with a null character.

Q10. What is the difference between EOF and '\0'?

EOF is a special negative integer constant returned by certain input functions. '\0' is the null character with value zero, used to terminate C strings.

Q11. Does fgets() always store a newline?

No. It stores a newline only if one is encountered within the maximum number of characters it can read. The buffer can fill first, or input can end before a newline.

Q12. What is the difference between feof() and ferror()?

feof() checks the stream's end-of-file indicator. ferror() checks its error indicator.

Q13. Why should fflush(stdin) be avoided in portable C?

The C standard does not define fflush() for clearing an input stream such as stdin. Its use for this purpose is not portable.

Q14. What is a format-string vulnerability?

It can occur when untrusted input is used directly as the printf() format string. For example, printf(userInput) can interpret format directives unexpectedly. Use printf("%s", userInput) instead.

Q15. How do you safely validate a numeric string?

Read a bounded line with fgets(), convert it using strtol() or an appropriate conversion function, check the end pointer and errno, then validate the permitted range.

Advanced / Interview Level

  4. Build a menu-driven student record input program with validation for every field.
  5. Write a program that reads from stdin and copies characters to stdout while checking stream errors.
