Chapter 16 – C Coding Interview and Placement Preparation

Level: Intermediate to Advanced | Standard: C11

1. Learning Objectives

After completing this lecture, you should be able to:

  • Solve coding problems using pointers instead of array indexing.
  • Modify caller variables through pointer parameters.
  • Traverse and reverse arrays using pointer arithmetic.
  • Implement string operations using character pointers.
  • Understand and use double pointers.
  • Write functions that accept other functions as arguments.
  • Use function pointers and standard library callbacks.
  • Identify common pointer errors during coding interviews.

2. Pointer-Based Problem Solving

A pointer stores the address of an object. In coding interviews, pointers are commonly used to:

  • Modify variables inside functions.
  • Traverse arrays and strings.
  • Pass large data structures efficiently.
  • Work with dynamically allocated memory.
  • Implement linked lists, trees and other data structures.

Example: Swap Two Numbers Using Pointers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Before swap: x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swap: x = %d, y = %d\n", x, y);

    return 0;
}
Before swap: x = 10, y = 20 After swap: x = 20, y = 10
Interview concept: C uses pass-by-value. The function receives copies of the pointer values, but those pointers refer to the caller's objects. Dereferencing them allows the function to modify those objects.

Time Complexity: O(1)

Space Complexity: O(1)

3. Find Array Sum, Minimum and Maximum Using Pointers

This problem tests pointer traversal, dereferencing and boundary handling.

#include <stdio.h>

int main(void)
{
    int arr[] = {12, 5, 28, 9, 17};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    int *ptr = arr;
    int sum = 0;
    int min = *ptr;
    int max = *ptr;

    for (size_t i = 0; i < n; i++)
    {
        int value = *(ptr + i);

        sum += value;

        if (value < min)
            min = value;

        if (value > max)
            max = value;
    }

    printf("Sum = %d\n", sum);
    printf("Minimum = %d\n", min);
    printf("Maximum = %d\n", max);

    return 0;
}
Sum = 71 Minimum = 5 Maximum = 28

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

The array must contain at least one element before initializing minimum and maximum from its first element. This example uses a non-empty array.

4. Reverse an Array Using Two Pointers

Two-pointer techniques are frequently used in array and string interview problems.

#include <stdio.h>

void reverseArray(int *arr, size_t n)
{
    if (arr == NULL || n < 2)
        return;

    int *left = arr;
    int *right = arr + n - 1;

    while (left < right)
    {
        int temp = *left;
        *left = *right;
        *right = temp;

        left++;
        right--;
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    reverseArray(arr, n);

    printf("Reversed array: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Reversed array: 50 40 30 20 10

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

Both pointers refer to elements of the same array. Their comparisons and increments remain within the array's valid bounds.

5. String Length Using a Character Pointer

Implementing string length manually is a common pointer exercise.

#include <stdio.h>
#include <stddef.h>

size_t stringLength(const char *str)
{
    size_t length = 0;

    if (str == NULL)
        return 0;

    while (*str != '\0')
    {
        length++;
        str++;
    }

    return length;
}

int main(void)
{
    const char text[] = "Embedded C";

    printf("String: %s\n", text);
    printf("Length: %zu\n", stringLength(text));

    return 0;
}
String: Embedded C Length: 10

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

A C string is a sequence of characters terminated by the null character '\0'. The terminating null character is not included in the returned length.

6. Copy a String Using Pointers

This problem checks whether you understand destination capacity and null termination.

#include <stdio.h>
#include <stddef.h>
#include <stdbool.h>

bool copyString(char *dest, size_t capacity, const char *src)
{
    if (dest == NULL || src == NULL || capacity == 0)
        return false;

    size_t i = 0;

    while (src[i] != '\0')
    {
        if (i >= capacity - 1)
        {
            dest[0] = '\0';
            return false;
        }

        dest[i] = src[i];
        i++;
    }

    dest[i] = '\0';
    return true;
}

int main(void)
{
    const char source[] = "Microcontroller";
    char destination[30];

    if (copyString(destination, sizeof(destination), source))
        printf("Copied string: %s\n", destination);
    else
        printf("Copy failed: insufficient capacity\n");

    return 0;
}
Copied string: Microcontroller

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

The source and destination regions must not overlap for this implementation. If overlapping regions must be supported, use a suitable memmove-based approach after determining the required length and capacity.

7. Compare Two Strings Using Pointers

String comparison is another common interview problem. The function below returns:

  • 0 when both strings are equal.
  • A negative value when the first differing unsigned character in the first string is smaller.
  • A positive value when it is larger.
#include <stdio.h>

int compareStrings(const char *a, const char *b)
{
    while (*a != '\0' && *a == *b)
    {
        a++;
        b++;
    }

    return (unsigned char)*a - (unsigned char)*b;
}

int main(void)
{
    const char first[] = "Linux";
    const char second[] = "Linux";
    const char third[] = "Embedded";

    printf("first vs second: %d\n",
           compareStrings(first, second));

    printf("first vs third: %d\n",
           compareStrings(first, third));

    return 0;
}
first vs second: 0 first vs third: 9

Time Complexity: O(min(n, m)) in the worst case up to the first mismatch or terminator.

Auxiliary Space Complexity: O(1)

This function assumes both arguments point to valid null-terminated strings. It does not accept NULL pointers.

8. Double Pointers: Pointer to Pointer

A double pointer stores the address of another pointer. It is useful when a function must change the caller's pointer variable.

Example: Modify a Pointer Through a Double Pointer

#include <stdio.h>

void updatePointer(int **ptr, int *newTarget)
{
    if (ptr != NULL)
        *ptr = newTarget;
}

int main(void)
{
    int a = 10;
    int b = 50;

    int *p = &a;

    printf("Before: %d\n", *p);

    updatePointer(&p, &b);

    printf("After: %d\n", *p);

    return 0;
}
Before: 10 After: 50

Explanation:

  • p stores the address of a.
  • &p is the address of pointer p.
  • int **ptr receives that pointer-to-pointer value.
  • *ptr = newTarget changes the caller's pointer variable.

9. Dynamic Memory Allocation Through a Double Pointer

A common interview requirement is to allocate memory inside a function and return the resulting pointer through an output parameter.

#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

bool createArray(int **out, size_t count)
{
    if (out == NULL || count == 0)
        return false;

    *out = NULL;

    if (count > (size_t)-1 / sizeof **out)
        return false;

    int *memory = malloc(count * sizeof *memory);

    if (memory == NULL)
        return false;

    for (size_t i = 0; i < count; i++)
        memory[i] = (int)(i + 1) * 10;

    *out = memory;

    return true;
}

int main(void)
{
    int *arr = NULL;
    size_t count = 5;

    if (!createArray(&arr, count))
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (size_t i = 0; i < count; i++)
        printf("%d ", arr[i]);

    printf("\n");

    free(arr);
    arr = NULL;

    return 0;
}
10 20 30 40 50

Time Complexity: O(n)

Auxiliary Space Complexity: O(n) for allocated storage.

The caller owns the allocated memory and must release it using free(). The allocation helper initializes the output pointer to NULL before attempting allocation.

10. Function Pointers: Fundamentals

A function pointer stores the address of a function. It can be used to call a function indirectly.

Declaration Syntax

return_type (*pointer_name)(parameter_types);

Example: Function Pointer for Arithmetic Operations

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operation)(int, int);

    operation = add;
    printf("Addition: %d\n", operation(10, 5));

    operation = multiply;
    printf("Multiplication: %d\n", operation(10, 5));

    return 0;
}
Addition: 15 Multiplication: 50

Key points:

  • The function pointer's return type and parameter types must match the target function's type.
  • A function pointer can be reassigned to another compatible function.
  • Calling through a null or invalid function pointer causes undefined behavior.

11. Callback Functions

A callback is a function passed to another function so that it can be invoked when required.

Callbacks are useful in:

  • Sorting and searching libraries.
  • Event-driven programming.
  • Embedded firmware and interrupt-related software design.
  • Operating system and driver interfaces.
  • Reusable generic algorithms.

Example: Passing an Operation as a Callback

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int calculate(int a, int b, int (*operation)(int, int))
{
    if (operation == NULL)
        return 0;

    return operation(a, b);
}

int main(void)
{
    printf("Addition: %d\n",
           calculate(20, 5, add));

    printf("Subtraction: %d\n",
           calculate(20, 5, subtract));

    return 0;
}
Addition: 25 Subtraction: 15
The calculate() function does not need to know how the operation is implemented. It only needs a function with the expected signature.

12. Function Pointers with qsort()

The standard C library provides qsort(), which sorts an array using a comparison callback.

Example: Sort Integers in Ascending Order

#include <stdio.h>
#include <stdlib.h>

int compareIntegers(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

int main(void)
{
    int arr[] = {40, 10, 50, 20, 30};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(arr[0]), compareIntegers);

    printf("Sorted array: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Sorted array: 10 20 30 40 50

Important interview points:

  • qsort() is declared in stdlib.h.
  • The comparison function receives pointers to two elements.
  • The comparison function returns a negative, zero or positive result.
  • Do not implement the comparator as x - y; signed integer subtraction can overflow.
  • The C standard does not guarantee a particular sorting algorithm or O(n log n) worst-case complexity for qsort().

13. Array of Function Pointers

An array of function pointers can be used to build a menu-driven operation dispatcher.

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operations[3])(int, int) = {
        add, subtract, multiply
    };

    int a = 12;
    int b = 4;

    for (int i = 0; i < 3; i++)
    {
        printf("Operation %d result = %d\n",
               i + 1, operations[i](a, b));
    }

    return 0;
}
Operation 1 result = 16 Operation 2 result = 8 Operation 3 result = 48

Placement relevance: This pattern appears in command dispatchers, protocol handlers, state machines and embedded software modules.

14. Pointer Output Prediction and Common Traps

Problem 1: Pointer Arithmetic

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40};
    int *p = arr;

    printf("%d\n", *p);
    printf("%d\n", *(p + 2));

    p++;

    printf("%d\n", *p);

    return 0;
}
10 30 20

Explanation: Incrementing an int pointer moves it to the next int element, not necessarily the next byte.

Problem 2: Pointer and Array Relationship

#include <stdio.h>

int main(void)
{
    int arr[] = {5, 10, 15};
    int *p = arr;

    printf("%d\n", *p++);
    printf("%d\n", *p);

    return 0;
}
5 10

Explanation: *p++ is interpreted as *(p++). The current value is read, and then the pointer advances.

Problem 3: Pointer to Constant and Constant Pointer

Declaration Meaning Allowed operation
const int *p; Pointer to constant int Pointer can change; value cannot be modified through p.
int *const p = &x; Constant pointer to int Pointer cannot change; pointed value can change.
const int *const p = &x; Constant pointer to constant int Neither pointer nor pointed value can be modified through p.

Common Pointer Errors

Error Explanation
Uninitialized pointer Contains an indeterminate value and must not be dereferenced.
NULL dereference Dereferencing a null pointer has undefined behavior.
Dangling pointer Points to an object whose lifetime has ended or whose storage has been released.
Out-of-bounds access Accessing an element outside the valid array object is undefined behavior.
Memory leak Allocated storage is no longer reachable but has not been freed.
Double free Releasing the same allocated storage more than once is undefined behavior.
Pointer arithmetic is only defined within an array object and one position past its final element. The one-past pointer may be compared or used in permitted pointer arithmetic, but it must never be dereferenced.

15. Pointer and Function Interview Questions

Q1. What is the difference between a pointer and an array?

An array is an object containing a fixed sequence of elements. A pointer is a separate object that stores an address. In most expressions, an array expression converts to a pointer to its first element, but arrays and pointers are not interchangeable in every context.

Q2. What is pointer arithmetic?

Pointer arithmetic moves between elements of the pointed-to array. Adding one to an int pointer advances it by one int element.

Q3. What is a double pointer?

A double pointer stores the address of another pointer. It is useful when a function must modify a caller's pointer variable.

Q4. What is a function pointer?

A function pointer stores the address of a function and allows the function to be called indirectly.

Q5. What is a callback function?

A callback is a function supplied to another function, typically through a function pointer, so that the receiving function can invoke it.

Q6. What is the difference between NULL and a dangling pointer?

NULL represents a null pointer value. A dangling pointer is a pointer whose former target object is no longer valid.

Q7. Can a function return a pointer?

Yes. It can return a pointer to an object whose lifetime remains valid after the function returns, such as dynamically allocated memory or a static object. It must not return the address of an ordinary local automatic variable.

Q8. Why should a qsort comparator avoid subtraction?

Subtracting two signed integers can overflow. A comparator should instead use relational comparisons and return negative, zero or positive values.

Q9. What is the difference between a pointer to an array and an array of pointers?

A pointer to an array points to one complete array object. An array of pointers contains multiple pointer elements, each of which can point to a separate object.

Q10. Does passing an array to a function pass the complete array?

No. In a function parameter declaration, an array parameter is adjusted to a pointer parameter. The function does not automatically receive the array length, so the length should be passed separately.

Attempt these problems without referring to the solutions above.

  2. Reverse a string in place using two character pointers.
  3. Write a function to count vowels and consonants using a character pointer.

  5. Write a function that dynamically allocates an integer array and returns it through a double pointer.
  6. Create a calculator using an array of function pointers.
  7. Use qsort() to sort an array of structures by a selected integer field.

17. Practical Compilation and Debugging

Compile the programs using a C11-compatible compiler such as GCC:

gcc -std=c11 -Wall -Wextra -Wpedantic -g pointer_practice.c -o pointer_practice
./pointer_practice

For supported GCC or Clang toolchains, use sanitizers during testing:

gcc -std=c11 -Wall -Wextra -Wpedantic -g \
-fsanitize=address,undefined \
pointer_practice.c -o pointer_practice

./pointer_practice

Sanitizers can help detect certain memory errors and undefined behavior during execution. Their availability and coverage depend on the compiler and platform.

Debugging Checklist

  • Check whether every pointer is initialized before use.
  • Verify that pointer arithmetic stays within valid array bounds.
  • Check the lifetime of every pointed-to object.
  • Verify that allocated memory is released exactly once.
  • Check string buffer capacity and null termination.
  • Verify function pointer signatures before invoking callbacks.

18. Key Placement Takeaways

  • Pointer-based array traversal and two-pointer techniques are common coding-round topics.
  • Double pointers are important when functions must modify pointer variables.
  • Function pointers enable callbacks and flexible operation dispatch.
  • Standard library functions such as qsort() demonstrate practical callback usage.
  • Pointer safety requires correct initialization, bounds, lifetime and ownership management.
  • Always consider time complexity, auxiliary space and edge cases when presenting a solution.
