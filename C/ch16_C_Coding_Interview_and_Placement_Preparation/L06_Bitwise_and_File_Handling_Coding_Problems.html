2. Bitwise Operators: Quick Revision

Bitwise operators work on individual bits of integer operands.

Operator Name Purpose
& Bitwise AND Sets a result bit when both operand bits are 1.
| Bitwise OR Sets a result bit when either operand bit is 1.
^ Bitwise XOR Sets a result bit when operand bits differ.
~ Bitwise NOT Inverts each bit.
<< Left shift Shifts bits toward higher positions.
>> Right shift Shifts bits toward lower positions.
Bitwise operations are particularly important in embedded C for register configuration, status flags, peripheral control and compact data representation.

3. Set, Clear, Toggle and Check a Bit

Assume bit positions are numbered from zero, starting at the least significant bit.

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint32_t reg = 0x00000005U;
    unsigned int bit = 2U;

    /* Set bit 2 */
    reg |= (UINT32_C(1) << bit);
    printf("After setting: 0x%08X\n", (unsigned int)reg);

    /* Clear bit 2 */
    reg &= ~(UINT32_C(1) << bit);
    printf("After clearing: 0x%08X\n", (unsigned int)reg);

    /* Toggle bit 1 */
    reg ^= (UINT32_C(1) << 1);
    printf("After toggling: 0x%08X\n", (unsigned int)reg);

    /* Check bit 0 */
    if ((reg & UINT32_C(1)) != 0U)
        printf("Bit 0 is SET\n");
    else
        printf("Bit 0 is CLEAR\n");

    return 0;
}
After setting: 0x00000005 After clearing: 0x00000001 After toggling: 0x00000003 Bit 0 is SET

Interview formulas:

  • Set bit: x | (1U << n)
  • Clear bit: x & ~(1U << n)
  • Toggle bit: x ^ (1U << n)
  • Check bit: (x & (1U << n)) != 0
The shift count must be smaller than the width of the promoted left operand. For a 32-bit mask, use an appropriate unsigned 32-bit operand and validate that the bit position is between 0 and 31.

4. Count the Number of Set Bits

A set bit is a bit whose value is 1. This problem is also called population count or Hamming weight.

Method 1: Check Every Bit

#include <stdio.h>
#include <stdint.h>

unsigned int countSetBits(uint32_t n)
{
    unsigned int count = 0;

    while (n != 0U)
    {
        count += (unsigned int)(n & 1U);
        n >>= 1;
    }

    return count;
}

int main(void)
{
    uint32_t value = 29U;

    printf("Number of set bits: %u\n",
           countSetBits(value));

    return 0;
}
Number of set bits: 4

Binary representation of 29 is 11101, which contains four set bits.

Time Complexity: O(w), where w is the number of bits in the integer type.

Method 2: Brian Kernighan's Algorithm

#include <stdio.h>
#include <stdint.h>

unsigned int countSetBits(uint32_t n)
{
    unsigned int count = 0;

    while (n != 0U)
    {
        n &= (n - 1U);
        count++;
    }

    return count;
}

int main(void)
{
    uint32_t value = 29U;

    printf("Set bits: %u\n", countSetBits(value));

    return 0;
}
Set bits: 4
The expression n & (n - 1) clears the lowest set bit. The loop executes once for every set bit.

Time Complexity: O(k), where k is the number of set bits.

5. Check Whether a Number Is a Power of Two

A positive power of two has exactly one set bit in its binary representation.

#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>

bool isPowerOfTwo(uint32_t n)
{
    return n != 0U && (n & (n - 1U)) == 0U;
}

int main(void)
{
    uint32_t a = 16U;
    uint32_t b = 18U;

    printf("16: %s\n", isPowerOfTwo(a) ? "Yes" : "No");
    printf("18: %s\n", isPowerOfTwo(b) ? "Yes" : "No");

    return 0;
}
16: Yes 18: No

Time Complexity: O(1)

Auxiliary Space Complexity: O(1)

Zero is not a power of two. That is why the explicit n != 0U condition is necessary.

6. Find the Unique Element Using XOR

Every element in an array appears twice except one element. Find the unique element.

#include <stdio.h>

int main(void)
{
    int arr[] = {4, 2, 7, 2, 4};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    int result = 0;

    for (size_t i = 0; i < n; i++)
        result ^= arr[i];

    printf("Unique element: %d\n", result);

    return 0;
}
Unique element: 7

Why does it work?

  • x ^ x = 0
  • x ^ 0 = x
  • XOR is associative and commutative.

All repeated pairs cancel, leaving the unique value.

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

The input must satisfy the stated condition: exactly one value occurs once and every other value occurs exactly twice.

7. Swap Two Integers Using XOR

XOR can swap two integer variables without a temporary variable, although the conventional temporary-variable approach is usually clearer and safer.

#include <stdio.h>

void xorSwap(unsigned int *a, unsigned int *b)
{
    if (a == NULL || b == NULL || a == b)
        return;

    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

int main(void)
{
    unsigned int x = 10U;
    unsigned int y = 20U;

    xorSwap(&x, &y);

    printf("x = %u, y = %u\n", x, y);

    return 0;
}
x = 20, y = 10
XOR swap is mainly an interview exercise. A temporary variable is generally preferable because it is easier to understand and avoids aliasing problems when both pointers refer to the same object.

8. Reverse the Bits of a 32-Bit Integer

Reverse the order of all 32 bits, including leading zero bits.

#include <stdio.h>
#include <stdint.h>

uint32_t reverseBits(uint32_t n)
{
    uint32_t result = 0U;

    for (unsigned int i = 0; i < 32U; i++)
    {
        result = (result << 1) | (n & 1U);
        n >>= 1;
    }

    return result;
}

int main(void)
{
    uint32_t value = 1U;

    printf("Original: %u\n", (unsigned int)value);
    printf("Reversed: %u\n",
           (unsigned int)reverseBits(value));

    return 0;
}
Original: 1 Reversed: 2147483648

Time Complexity: O(32), effectively O(1).

Auxiliary Space Complexity: O(1).

The least significant bit of the input becomes the most significant bit of the result.

9. Embedded C: Register Bit Manipulation

Bitwise operations are central to embedded firmware because peripheral registers often contain multiple control and status bits.

Example: Simulated 8-Bit Control Register

#include <stdio.h>
#include <stdint.h>

#define LED_BIT       0U
#define MOTOR_BIT     2U
#define SENSOR_BIT    5U

int main(void)
{
    uint8_t controlReg = 0U;

    /* Enable LED */
    controlReg |= (uint8_t)(1U << LED_BIT);

    /* Enable motor */
    controlReg |= (uint8_t)(1U << MOTOR_BIT);

    printf("Register: 0x%02X\n",
           (unsigned int)controlReg);

    /* Disable LED */
    controlReg &= (uint8_t)~(1U << LED_BIT);

    /* Check sensor status */
    if ((controlReg & (uint8_t)(1U << SENSOR_BIT)) != 0U)
        printf("Sensor active\n");
    else
        printf("Sensor inactive\n");

    printf("Final register: 0x%02X\n",
           (unsigned int)controlReg);

    return 0;
}
Register: 0x05 Sensor inactive Final register: 0x04
This is a normal RAM simulation, not direct hardware register access. Real peripheral registers have device-specific addresses, access widths and read/write semantics. Some registers also require atomic set/clear mechanisms or special handling.

10. File Handling: Quick Revision

11. Write Data to a Text File

Create a file and write employee details using fprintf().

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("employee.txt", "w");

    if (fp == NULL)
    {
        perror("Unable to open file");
        return 1;
    }

    fprintf(fp, "Employee ID: 101\n");
    fprintf(fp, "Name: Amit\n");
    fprintf(fp, "Salary: %.2f\n", 35000.0);

    if (fclose(fp) == EOF)
    {
        perror("Error closing file");
        return 1;
    }

    printf("Data written successfully\n");

    return 0;
}
Data written successfully

Expected employee.txt content:

Employee ID: 101
Name: Amit
Salary: 35000.00
The "w" mode creates a new file or truncates an existing file. The file is created relative to the program's working directory unless a different path is supplied.

12. Read Data from a Text File

Use fgets() to read text safely into a bounded buffer.

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("employee.txt", "r");

    if (fp == NULL)
    {
        perror("Unable to open file");
        return 1;
    }

    char line[100];

    while (fgets(line, sizeof line, fp) != NULL)
    {
        printf("%s", line);
    }

    if (ferror(fp))
    {
        perror("Error reading file");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Error closing file");
        return 1;
    }

    return 0;
}

Expected output:

Employee ID: 101 Name: Amit Salary: 35000.00

Important: fgets() reads at most one less than the buffer capacity and adds a terminating null character when successful.

13. Count Characters, Words and Lines in a File

This is a common file-processing coding problem.

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    FILE *fp = fopen("sample.txt", "r");

    if (fp == NULL)
    {
        perror("Unable to open file");
        return 1;
    }

    int ch;
    size_t characters = 0;
    size_t words = 0;
    size_t lines = 0;
    int inWord = 0;
    int lastWasNewline = 1;

    while ((ch = fgetc(fp)) != EOF)
    {
        characters++;

        if (ch == '\n')
        {
            lines++;
            lastWasNewline = 1;
        }
        else
        {
            lastWasNewline = 0;
        }

        if (isspace((unsigned char)ch))
        {
            inWord = 0;
        }
        else if (!inWord)
        {
            words++;
            inWord = 1;
        }
    }

    if (ferror(fp))
    {
        perror("File reading error");
        fclose(fp);
        return 1;
    }

    if (characters != 0 && !lastWasNewline)
        lines++;

    if (fclose(fp) == EOF)
    {
        perror("File closing error");
        return 1;
    }

    printf("Characters: %zu\n", characters);
    printf("Words: %zu\n", words);
    printf("Lines: %zu\n", lines);

    return 0;
}

Sample file content:

C programming
File handling
Embedded systems
Characters: 43 Words: 6 Lines: 3

Time Complexity: O(n), where n is the number of bytes read.

Auxiliary Space Complexity: O(1).

This implementation counts bytes read, whitespace-separated words and logical text lines. It assumes a text file whose final line may or may not end in a newline. It is not a Unicode character counter.

14. Copy One Text File to Another

This problem tests file reading, writing and error handling.

#include <stdio.h>

int main(void)
{
    FILE *source = fopen("source.txt", "rb");

    if (source == NULL)
    {
        perror("Unable to open source");
        return 1;
    }

    FILE *destination = fopen("destination.txt", "wb");

    if (destination == NULL)
    {
        perror("Unable to open destination");
        fclose(source);
        return 1;
    }

    int ch;
    int failed = 0;

    while ((ch = fgetc(source)) != EOF)
    {
        if (fputc(ch, destination) == EOF)
        {
            failed = 1;
            break;
        }
    }

    if (ferror(source))
        failed = 1;

    if (fclose(source) == EOF)
        failed = 1;

    if (fclose(destination) == EOF)
        failed = 1;

    if (failed)
    {
        printf("File copy failed\n");
        return 1;
    }

    printf("File copied successfully\n");

    return 0;
}
File copied successfully
Binary modes "rb" and "wb" are used here so that file bytes are copied without text-mode newline translation on implementations where text and binary modes differ.

15. Binary File Handling Using fwrite() and fread()

Binary file operations are useful when storing structured records or raw data representations.

Example: Write and Read a Structure

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student original = {
        101,
        "Neha",
        91.5f
    };

    FILE *fp = fopen("student.dat", "wb");

    if (fp == NULL)
    {
        perror("Unable to create file");
        return 1;
    }

    if (fwrite(&original, sizeof original, 1, fp) != 1)
    {
        printf("Write failed\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Close failed");
        return 1;
    }

    struct Student loaded;

    fp = fopen("student.dat", "rb");

    if (fp == NULL)
    {
        perror("Unable to read file");
        return 1;
    }

    if (fread(&loaded, sizeof loaded, 1, fp) != 1)
    {
        printf("Read failed\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Close failed");
        return 1;
    }

    printf("Roll Number: %d\n", loaded.rollNo);
    printf("Name: %s\n", loaded.name);
    printf("Marks: %.2f\n", loaded.marks);

    return 0;
}
Roll Number: 101 Name: Neha Marks: 91.50
Writing a structure directly to a binary file is not a portable serialization format. Structure padding, byte order, type sizes and floating-point representation may differ across systems. Structures containing pointers must not be stored this way for later reconstruction. For portable storage, serialize fields explicitly using a defined format.

16. Find the Largest Number in a File

Assume the file contains valid integer values separated by whitespace.

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("numbers.txt", "r");

    if (fp == NULL)
    {
        perror("Unable to open file");
        return 1;
    }

    int value;
    int maximum;
    int result;

    result = fscanf(fp, "%d", &maximum);

    if (result != 1)
    {
        printf("File contains no valid integer\n");
        fclose(fp);
        return 1;
    }

    while ((result = fscanf(fp, "%d", &value)) == 1)
    {
        if (value > maximum)
            maximum = value;
    }

    if (result != EOF)
    {
        printf("Invalid data encountered\n");
        fclose(fp);
        return 1;
    }

    if (ferror(fp))
    {
        perror("File reading error");
        fclose(fp);
        return 1;
    }

    fclose(fp);

    printf("Maximum value: %d\n", maximum);

    return 0;
}

Sample numbers.txt:

12 45 7 89 23 56
Maximum value: 89

Time Complexity: O(n).

Auxiliary Space Complexity: O(1).

17. Important File Handling Concepts

Mode Meaning
r Open an existing file for reading.
w Open for writing; create or truncate.
a Open for appending; create if needed.
r+ Open an existing file for reading and writing.
w+ Open for reading and writing; create or truncate.
a+ Open for reading and appending; create if needed.
rb, wb Binary read and write modes.

EOF and Error Handling

  • EOF is a special negative integer value used to indicate end-of-file or an input failure in applicable functions.
  • fgetc() returns int so it can represent every unsigned char value and EOF.
  • feof() checks whether the end-of-file indicator is set.
  • ferror() checks whether the error indicator is set.
  • fclose() should be checked when successful completion of output matters.
Do not use while (!feof(fp)) as the primary file-reading loop. Attempt the read first and test its return value, as shown in the examples.

18. Bitwise and File Handling Interview Questions

Q1. What is the difference between bitwise AND and logical AND?

Bitwise AND operates on individual bits. Logical AND evaluates truth values and produces either 0 or 1.

Q2. How can you check whether a bit is set?

Use a mask and test whether the result of bitwise AND is nonzero.

Q3. Why does n & (n - 1) clear the lowest set bit?

Subtracting one changes the lowest set bit to zero and changes the trailing zeros below it to ones. ANDing with the original value clears that lowest set bit.

Q4. How do you check whether a number is a power of two?

For an unsigned integer n, check that n is nonzero and (n & (n - 1)) equals zero.

Q5. What is a bit mask?

A bit mask is an integer pattern used to select, set, clear or test specific bits in another integer.

Q6. What is the purpose of fopen()?

fopen() opens a file using a specified path and mode and returns a FILE pointer on success or NULL on failure.

Q7. What is the difference between text and binary file modes?

Text mode may perform implementation-specific text transformations. Binary mode is intended to transfer bytes without those text transformations.

Q8. Why does fgetc() return int instead of char?

It must represent every possible unsigned char value as well as the distinct EOF value.

Q9. What is the difference between feof() and ferror()?

feof() checks the end-of-file indicator; ferror() checks the error indicator. Both are typically examined after a read operation fails.

Q10. Why is raw structure storage not always portable?

Structure layout, padding, endianness and representations can differ between implementations.

Q11. What is the purpose of fseek()?

fseek() changes the file position indicator for a stream when the requested positioning operation is supported.

Q12. Why should a file be closed?

Closing a file releases associated resources and allows buffered output to be finalized. The return value should be checked when write errors matter.

20. Practical Compilation and Debugging

Compile using a C11-compatible compiler:

gcc -std=c11 -Wall -Wextra -Wpedantic -g bitwise_file.c -o bitwise_file
./bitwise_file

For supported GCC or Clang toolchains, enable runtime checks:

gcc -std=c11 -Wall -Wextra -Wpedantic -g \
-fsanitize=address,undefined \
bitwise_file.c -o bitwise_file

./bitwise_file

Debugging Checklist

  • Use unsigned operands for predictable bit manipulation.
  • Validate shift counts against the operand width.
  • Check integer widths and use fixed-width types where appropriate.
  • Check every fopen() result.
  • Test file-reading function return values.
  • Check ferror() after failed reads.
  • Check fclose() when output integrity matters.
  • Use binary mode for byte-oriented file copying.
  • Do not assume raw structure files are portable across systems.

  • Bit manipulation is important in C interviews and embedded firmware development.
  • Set, clear, toggle and test operations should be familiar.
  • XOR is useful for problems involving pairs and unique values.
  • Brian Kernighan's algorithm efficiently counts set bits.
  • File handling requires correct return-value and error checking.
  • fgets(), fread(), fwrite() and fgetc() are important standard I/O functions.
  • Memory layout and binary representation must be considered when storing structured data.
