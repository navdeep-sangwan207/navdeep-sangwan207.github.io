2. String Fundamentals in C

A string in C is a sequence of characters terminated by the null character '\0'.

char str[] = "HELLO";

Its memory representation is:

Index:   0   1   2   3   4    5
Value:  'H' 'E' 'L' 'L' 'O' '\0'

The null terminator indicates where the string ends. It is not the same as the character digit zero, '0'.

Important interview concept: The declared array capacity and the string length are different. An array of 100 characters can hold at most 99 ordinary string characters when space is reserved for the null terminator.

Safe input using fgets()

char str[100];

if (fgets(str, sizeof str, stdin) != NULL)
{
    /* Process the input string */
}

fgets() may retain the newline character when there is room for it. Remove it when necessary:

#include <string.h>

str[strcspn(str, "\n")] = '\0';

3. Find String Length Without strlen()

Problem

Calculate the number of characters before the null terminator.

Logic

Start at index zero and count characters until '\0' is encountered.

C11 Program

#include <stdio.h>

int main(void)
{
    char str[100];
    size_t length = 0;

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    while (str[length] != '\0' && str[length] != '\n')
    {
        length++;
    }

    printf("String length = %zu\n", length);

    return 0;
}

Expected Result

Enter a string: Embedded C String length = 10

Time complexity: O(n)

Auxiliary space: O(1)

4. Reverse a String

Problem

Reverse a string in-place without using strrev().

Logic

  1. Find the string length.
  2. Use one index at the beginning and another at the end.
  3. Swap the characters.
  4. Move both indices toward the center.

C11 Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[100];

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    str[strcspn(str, "\n")] = '\0';

    size_t length = strlen(str);

    for (size_t i = 0; i < length / 2; i++)
    {
        char temp = str[i];
        str[i] = str[length - 1 - i];
        str[length - 1 - i] = temp;
    }

    printf("Reversed string = %s\n", str);

    return 0;
}

Expected Result

Enter a string: PROGRAM Reversed string = MARGORP

Time complexity: O(n)

Auxiliary space: O(1)

5. Check Whether a String Is a Palindrome

Problem

Determine whether a string reads the same from left to right and right to left.

Examples

  • MADAM – Palindrome
  • LEVEL – Palindrome
  • HELLO – Not a palindrome

C11 Program – Case-Sensitive Comparison

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[100];
    int is_palindrome = 1;

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    str[strcspn(str, "\n")] = '\0';

    size_t length = strlen(str);

    for (size_t i = 0; i < length / 2; i++)
    {
        if (str[i] != str[length - 1 - i])
        {
            is_palindrome = 0;
            break;
        }
    }

    if (is_palindrome)
        printf("Palindrome string.\n");
    else
        printf("Not a palindrome string.\n");

    return 0;
}

Expected Result

Enter a string: MADAM Palindrome string.

Time complexity: O(n)

Auxiliary space: O(1)

This implementation is case-sensitive and includes spaces and punctuation in the comparison. A phrase-based palindrome check that ignores spaces and punctuation requires additional filtering.

6. Count Vowels, Consonants, Digits and Special Characters

Problem

Classify characters in an input string.

C11 Program

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char str[200];
    size_t vowels = 0;
    size_t consonants = 0;
    size_t digits = 0;
    size_t spaces = 0;
    size_t special = 0;

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    for (size_t i = 0; str[i] != '\0' && str[i] != '\n'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (isalpha(ch))
        {
            ch = (unsigned char)tolower(ch);

            if (ch == 'a' || ch == 'e' || ch == 'i' ||
                ch == 'o' || ch == 'u')
                vowels++;
            else
                consonants++;
        }
        else if (isdigit(ch))
        {
            digits++;
        }
        else if (isspace(ch))
        {
            spaces++;
        }
        else
        {
            special++;
        }
    }

    printf("Vowels = %zu\n", vowels);
    printf("Consonants = %zu\n", consonants);
    printf("Digits = %zu\n", digits);
    printf("Spaces = %zu\n", spaces);
    printf("Special characters = %zu\n", special);

    return 0;
}

Expected Result

Enter a string: Embedded C 2026! Vowels = 3 Consonants = 6 Digits = 4 Spaces = 2 Special characters = 1

Time complexity: O(n)

Auxiliary space: O(1)

7. Character Frequency in a String

Problem

Count how many times each byte-valued character occurs in a string.

Logic

Use a frequency array of 256 entries. Convert each input character to unsigned char before using it as an array index.

C11 Program

#include <stdio.h>

int main(void)
{
    char str[200];
    size_t frequency[256] = {0};

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    for (size_t i = 0; str[i] != '\0' && str[i] != '\n'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    printf("Character frequencies:\n");

    for (size_t i = 0; i < 256; i++)
    {
        if (frequency[i] > 0)
        {
            if (i >= 32 && i <= 126)
                printf("%c = %zu\n", (int)i, frequency[i]);
            else
                printf("Byte %zu = %zu\n", i, frequency[i]);
        }
    }

    return 0;
}

Expected Result

Enter a string: banana Character frequencies: a = 3 b = 1 n = 2

Time complexity: O(n + 256), effectively O(n).

Auxiliary space: O(256), constant space.

This technique counts individual bytes. It is suitable for basic ASCII-oriented C interview problems, but it does not count Unicode characters correctly in multibyte encodings such as UTF-8.

8. Remove Duplicate Characters

Problem

Remove repeated byte-valued characters while preserving the first occurrence of each character.

Example

Input:  programming
Output: progamin

C11 Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[200];
    unsigned char seen[256] = {0};
    size_t write = 0;

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    str[strcspn(str, "\n")] = '\0';

    for (size_t read = 0; str[read] != '\0'; read++)
    {
        unsigned char ch = (unsigned char)str[read];

        if (!seen[ch])
        {
            seen[ch] = 1;
            str[write] = str[read];
            write++;
        }
    }

    str[write] = '\0';

    printf("After removing duplicates: %s\n", str);

    return 0;
}

Expected Result

Enter a string: programming After removing duplicates: progamin

Time complexity: O(n + 256), effectively O(n).

Auxiliary space: O(256), constant space.

9. Check Whether Two Strings Are Anagrams

Definition

Two strings are anagrams if they contain the same characters with the same frequencies, irrespective of order.

Example

String 1: listen
String 2: silent

Result: Anagrams

C11 Program – Case-Insensitive English Letters

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main(void)
{
    char first[200], second[200];
    int frequency[26] = {0};
    int is_anagram = 1;

    printf("Enter first string: ");

    if (fgets(first, sizeof first, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    printf("Enter second string: ");

    if (fgets(second, sizeof second, stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    first[strcspn(first, "\n")] = '\0';
    second[strcspn(second, "\n")] = '\0';

    for (size_t i = 0; first[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)first[i];

        if (!isalpha(ch) || ch > 127)
        {
            printf("Only English letters are supported.\n");
            return 1;
        }

        ch = (unsigned char)tolower(ch);
        frequency[ch - 'a']++;
    }

    for (size_t i = 0; second[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)second[i];

        if (!isalpha(ch) || ch > 127)
        {
            printf("Only English letters are supported.\n");
            return 1;
        }

        ch = (unsigned char)tolower(ch);
        frequency[ch - 'a']--;
    }

    for (size_t i = 0; i < 26; i++)
    {
        if (frequency[i] != 0)
        {
            is_anagram = 0;
            break;
        }
    }

    if (is_anagram)
        printf("Strings are anagrams.\n");
    else
        printf("Strings are not anagrams.\n");

    return 0;
}

Expected Result

Enter first string: Listen Enter second string: Silent Strings are anagrams.

Time complexity: O(n + m + 26), where n and m are the two string lengths.

Auxiliary space: O(26), constant space.

This implementation ignores letter case but does not ignore spaces or punctuation. Those rules must be explicitly defined in an interview problem before implementing an anagram checker.

10. Compare Two Strings Without strcmp()

Problem

Compare two strings lexicographically without using strcmp().

Logic

Compare corresponding characters until a difference is found or both strings reach their null terminators.

C11 Program

#include <stdio.h>

int compare_strings(const char *a, const char *b)
{
    while (*a != '\0' && *a == *b)
    {
        a++;
        b++;
    }

    return (unsigned char)*a - (unsigned char)*b;
}

int main(void)
{
    char first[100];
    char second[100];

    printf("Enter first string: ");

    if (fgets(first, sizeof first, stdin) == NULL)
        return 1;

    printf("Enter second string: ");

    if (fgets(second, sizeof second, stdin) == NULL)
        return 1;

    size_t i = 0;

    while (first[i] != '\0' && first[i] != '\n')
        i++;

    first[i] = '\0';

    i = 0;

    while (second[i] != '\0' && second[i] != '\n')
        i++;

    second[i] = '\0';

    int result = compare_strings(first, second);

    if (result == 0)
        printf("Strings are equal.\n");
    else if (result < 0)
        printf("First string is lexicographically smaller.\n");
    else
        printf("First string is lexicographically greater.\n");

    return 0;
}

Expected Result

Enter first string: Apple Enter second string: Banana First string is lexicographically smaller.

Time complexity: O(min(n,m)) for equal prefixes; O(k) generally, where k is the number of compared characters.

Auxiliary space: O(1) for the comparison function.

11. Concatenate Two Strings Without strcat()

Problem

Append one string to another, ensuring that the destination array has sufficient capacity.

C11 Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[200];
    char second[100];

    printf("Enter first string: ");

    if (fgets(first, sizeof first, stdin) == NULL)
        return 1;

    printf("Enter second string: ");

    if (fgets(second, sizeof second, stdin) == NULL)
        return 1;

    first[strcspn(first, "\n")] = '\0';
    second[strcspn(second, "\n")] = '\0';

    size_t len1 = strlen(first);
    size_t len2 = strlen(second);
    size_t capacity = sizeof first;

    if (len2 >= capacity - len1)
    {
        printf("Insufficient destination capacity.\n");
        return 1;
    }

    for (size_t i = 0; i <= len2; i++)
        first[len1 + i] = second[i];

    printf("Concatenated string: %s\n", first);

    return 0;
}

Expected Result

Enter first string: Embedded Enter second string: Systems Concatenated string: EmbeddedSystems

Time complexity: O(n + m), including length calculation.

Auxiliary space: O(1).

12. Find a Substring Without strstr()

Problem

Determine whether a pattern occurs inside a larger string.

Example

Text:      Embedded Systems
Pattern:   Systems
Result:    Found

C11 Program

#include <stdio.h>
#include <string.h>

int contains_substring(const char *text, const char *pattern)
{
    if (*pattern == '\0')
        return 1;

    for (size_t i = 0; text[i] != '\0'; i++)
    {
        size_t j = 0;

        while (pattern[j] != '\0' &&
               text[i + j] != '\0' &&
               text[i + j] == pattern[j])
        {
            j++;
        }

        if (pattern[j] == '\0')
            return 1;
    }

    return 0;
}

int main(void)
{
    char text[200];
    char pattern[100];

    printf("Enter text: ");

    if (fgets(text, sizeof text, stdin) == NULL)
        return 1;

    printf("Enter pattern: ");

    if (fgets(pattern, sizeof pattern, stdin) == NULL)
        return 1;

    text[strcspn(text, "\n")] = '\0';
    pattern[strcspn(pattern, "\n")] = '\0';

    if (contains_substring(text, pattern))
        printf("Substring found.\n");
    else
        printf("Substring not found.\n");

    return 0;
}

Expected Result

Enter text: Embedded Systems Enter pattern: Systems Substring found.

Time complexity: O(n × m) worst case for text length n and pattern length m.

Auxiliary space: O(1).

For larger inputs, more advanced algorithms such as Knuth-Morris-Pratt (KMP) can reduce worst-case matching time to O(n + m).

13. Find the First Non-Repeating Character

Problem

Find the first character that occurs exactly once in a string.

Example

Input:  swiss
Output: w

C11 Program

#include <stdio.h>

int main(void)
{
    char str[200];
    size_t frequency[256] = {0};

    printf("Enter a string: ");

    if (fgets(str, sizeof str, stdin) == NULL)
        return 1;

    for (size_t i = 0; str[i] != '\0' && str[i] != '\n'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    int found = 0;

    for (size_t i = 0; str[i] != '\0' && str[i] != '\n'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (frequency[ch] == 1)
        {
            printf("First non-repeating character = %c\n", ch);
            found = 1;
            break;
        }
    }

    if (!found)
        printf("No non-repeating character found.\n");

    return 0;
}

Expected Result

Enter a string: swiss First non-repeating character = w

Time complexity: O(n + 256), effectively O(n).

Auxiliary space: O(256), constant space.

14. Reverse Words in a Sentence

Problem

Reverse the order of words in a sentence while preserving the characters within each word.

Example

Input:  C programming is powerful
Output: powerful is programming C

Approach

  1. Reverse the entire character sequence.
  2. Reverse each individual word.
  3. The word order is reversed, but each word is restored.

C11 Program

#include <stdio.h>
#include <string.h>

void reverse_range(char str[], size_t left, size_t right)
{
    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;
        left++;
        right--;
    }
}

int main(void)
{
    char str[200];

    printf("Enter a sentence: ");

    if (fgets(str, sizeof str, stdin) == NULL)
        return 1;

    str[strcspn(str, "\n")] = '\0';

    size_t length = strlen(str);

    if (length > 0)
        reverse_range(str, 0, length - 1);

    size_t start = 0;

    while (start < length)
    {
        while (start < length && str[start] == ' ')
            start++;

        size_t end = start;

        while (end < length && str[end] != ' ')
            end++;

        if (end > start)
            reverse_range(str, start, end - 1);

        start = end;
    }

    printf("Reversed word order: %s\n", str);

    return 0;
}

Expected Result

Enter a sentence: C programming is powerful Reversed word order: powerful is programming C

Time complexity: O(n)

Auxiliary space: O(1)

This version preserves the original spaces in reversed positions. It does not normalize multiple spaces or tabs into single separators.

16. Frequently Asked String Interview Questions

Q1. Why are strings null-terminated in C?

The null character indicates the end of the string, allowing string-processing functions to determine its length.

Q2. What is the difference between strlen() and sizeof()?

strlen() returns the number of characters before the null terminator. sizeof returns the size in bytes of the object or type expression it is applied to. For a character array, that includes the entire array capacity.

Q3. What is the difference between a character array and a character pointer?

A character array owns its storage. A character pointer stores an address and may point to an array or another character sequence.

Q4. Why should an unsigned char be used as an array index for character frequency?

On implementations where plain char is signed, some character values may be negative. Converting to unsigned char ensures a non-negative index from 0 to UCHAR_MAX.

Q5. What is the difference between strcmp() and strncmp()?

strcmp() compares strings until a difference or null terminator. strncmp() compares at most the specified number of characters.

Q6. What is an anagram?

Two strings are anagrams when they contain the same characters with identical frequencies, subject to the problem's rules about case, spaces and punctuation.

Q7. Why is gets() unsafe?

It does not limit the number of characters read, so input can overflow the destination array. It was removed from the C standard library in C11. Use fgets() instead.

Q8. What is the time complexity of string reversal?

O(n), because each character is processed at most a constant number of times.

Q9. What is the difference between ASCII and Unicode?

ASCII is a limited character encoding. Unicode defines a much larger character repertoire and can be encoded using formats such as UTF-8. A C char array is not automatically a Unicode character array.

Q10. Why should string buffer capacity be checked?

Writing beyond the allocated array bounds causes undefined behavior and can introduce serious security vulnerabilities.

19. Lecture Summary

  • C strings are character sequences terminated by '\0'.
  • fgets() is preferable to unsafe unbounded input functions.
  • String length can be calculated using traversal.
  • Reversal and palindrome checking use two-pointer techniques.
  • Frequency arrays solve many character-counting problems efficiently.
  • Anagram checking can be implemented using character frequencies.
  • Substring searching can be performed with nested loops or KMP.
  • Pointer-based string operations are important for C interviews.
  • String buffer capacity and null termination must always be handled correctly.
Placement tip: Be prepared to implement strlen(), strcpy(), strcat() and strcmp() manually. Interviewers often use these problems to evaluate pointer arithmetic, array boundaries and null-terminator handling.
