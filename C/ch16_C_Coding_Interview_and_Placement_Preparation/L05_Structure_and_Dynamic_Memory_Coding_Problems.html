1. Learning Objectives

After completing this lecture, you should be able to:

  • Design structures for real-world programming problems.
  • Process arrays of structures and nested structures.
  • Pass structures and structure pointers to functions.
  • Sort and search records using structure fields.
  • Allocate and resize arrays of structures dynamically.
  • Build a simple dynamic record-management program.
  • Manage memory ownership and avoid common allocation errors.
  • Explain structure-related and memory-related interview concepts.

2. Structure-Based Problem Solving

A structure groups related variables of different data types under one user-defined type.

In placement coding rounds, structures are commonly used for:

  • Student and employee records.
  • Bank account information.
  • Inventory and product management.
  • Embedded device configuration.
  • Protocol packets and data representations.

Example: Student Record

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[40];
    float marks;
};

int main(void)
{
    struct Student s = {
        101,
        "Amit",
        86.5f
    };

    printf("Roll Number: %d\n", s.rollNo);
    printf("Name: %s\n", s.name);
    printf("Marks: %.2f\n", s.marks);

    return 0;
}
Roll Number: 101 Name: Amit Marks: 86.50
A structure groups fields, but it does not automatically allocate dynamic memory for pointer members. Memory ownership must be managed separately when structures contain pointers.

3. Find the Student with the Highest Marks

This problem tests structure arrays, traversal and comparison.

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student students[] = {
        {101, "Amit", 78.5f},
        {102, "Neha", 92.0f},
        {103, "Rahul", 85.5f},
        {104, "Priya", 88.0f}
    };

    size_t n = sizeof(students) / sizeof(students[0]);
    size_t highest = 0;

    for (size_t i = 1; i < n; i++)
    {
        if (students[i].marks > students[highest].marks)
            highest = i;
    }

    printf("Topper: %s\n", students[highest].name);
    printf("Roll Number: %d\n", students[highest].rollNo);
    printf("Marks: %.2f\n", students[highest].marks);

    return 0;
}
Topper: Neha Roll Number: 102 Marks: 92.00

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

If multiple students have equal highest marks, this implementation returns the first one encountered.

4. Sort Structures by a Field

Sorting records by marks, salary, age or another field is a frequently used interview problem.

Example: Sort Students by Marks in Descending Order

#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int rollNo;
    char name[30];
    float marks;
};

int compareMarksDescending(const void *a, const void *b)
{
    const struct Student *s1 = a;
    const struct Student *s2 = b;

    if (s1->marks < s2->marks)
        return 1;

    if (s1->marks > s2->marks)
        return -1;

    return 0;
}

int main(void)
{
    struct Student students[] = {
        {101, "Amit", 78.5f},
        {102, "Neha", 92.0f},
        {103, "Rahul", 85.5f},
        {104, "Priya", 88.0f}
    };

    size_t n = sizeof(students) / sizeof(students[0]);

    qsort(students, n, sizeof(students[0]),
          compareMarksDescending);

    printf("Students sorted by marks:\n");

    for (size_t i = 0; i < n; i++)
    {
        printf("%d %-10s %.2f\n",
               students[i].rollNo,
               students[i].name,
               students[i].marks);
    }

    return 0;
}
Students sorted by marks: 102 Neha 92.00 104 Priya 88.00 103 Rahul 85.50 101 Amit 78.50

Important: The comparator returns negative, zero or positive values according to the required order. It avoids subtracting floating-point marks to prevent an incorrect comparison strategy.

Time Complexity: Depends on the implementation of qsort(); the C standard does not guarantee a particular sorting complexity.

5. Pass a Structure to a Function

A structure can be passed by value. The function receives a copy of the structure.

#include <stdio.h>

struct Rectangle
{
    float length;
    float width;
};

float calculateArea(struct Rectangle r)
{
    return r.length * r.width;
}

int main(void)
{
    struct Rectangle rect = {10.0f, 5.0f};

    printf("Area = %.2f\n", calculateArea(rect));

    return 0;
}
Area = 50.00

Pass a Structure Using a Pointer

#include <stdio.h>

struct Rectangle
{
    float length;
    float width;
};

float calculateArea(const struct Rectangle *r)
{
    if (r == NULL)
        return 0.0f;

    return r->length * r->width;
}

int main(void)
{
    struct Rectangle rect = {12.0f, 4.0f};

    printf("Area = %.2f\n", calculateArea(&rect));

    return 0;
}
Area = 48.00
The arrow operator (->) accesses a structure member through a pointer. The expression r->length is equivalent to (*r).length.

Passing a pointer can avoid copying a large structure. The const qualifier indicates that the function will not modify the structure through that pointer.

6. Nested Structures

A structure can contain another structure as a member.

Example: Employee with Address Information

#include <stdio.h>

struct Address
{
    char city[30];
    int pinCode;
};

struct Employee
{
    int id;
    char name[30];
    struct Address address;
};

int main(void)
{
    struct Employee emp = {
        201,
        "Karan",
        {"Chandigarh", 160001}
    };

    printf("Employee ID: %d\n", emp.id);
    printf("Name: %s\n", emp.name);
    printf("City: %s\n", emp.address.city);
    printf("PIN Code: %d\n", emp.address.pinCode);

    return 0;
}
Employee ID: 201 Name: Karan City: Chandigarh PIN Code: 160001

Placement application: Nested structures are useful when modelling employees, addresses, device configurations and communication records.

7. Structure Pointer and Dynamic Structure Allocation

Dynamic allocation is useful when the number of records is not known at compile time.

#include <stdio.h>
#include <stdlib.h>

struct Employee
{
    int id;
    float salary;
};

int main(void)
{
    struct Employee *emp = malloc(sizeof *emp);

    if (emp == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    emp->id = 301;
    emp->salary = 45000.0f;

    printf("Employee ID: %d\n", emp->id);
    printf("Salary: %.2f\n", emp->salary);

    free(emp);
    emp = NULL;

    return 0;
}
Employee ID: 301 Salary: 45000.00

Important points:

  • malloc() allocates storage for the structure.
  • The returned pointer must be checked against NULL.
  • The arrow operator accesses members through the pointer.
  • free() releases the allocated storage.
  • Setting the local pointer to NULL after freeing helps avoid accidental reuse through that variable.

8. Dynamic Array of Structures

This is a common placement problem because it combines structures, pointers, allocation and array traversal.

Example: Dynamically Allocate Employee Records

#include <stdio.h>
#include <stdlib.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    size_t n = 3;

    struct Employee *employees =
        malloc(n * sizeof *employees);

    if (employees == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    employees[0] = (struct Employee){101, "Amit", 30000.0f};
    employees[1] = (struct Employee){102, "Neha", 42000.0f};
    employees[2] = (struct Employee){103, "Rahul", 38000.0f};

    printf("Employee Records:\n");

    for (size_t i = 0; i < n; i++)
    {
        printf("%d %-10s %.2f\n",
               employees[i].id,
               employees[i].name,
               employees[i].salary);
    }

    free(employees);
    employees = NULL;

    return 0;
}
Employee Records: 101 Amit 30000.00 102 Neha 42000.00 103 Rahul 38000.00

Time Complexity: O(n) for initializing and displaying n records.

Space Complexity: O(n) for dynamically allocated records.

9. Resize a Dynamic Structure Array Using realloc()

realloc() can change the size of an allocated memory block. A temporary pointer should be used so that the original allocation is not lost if resizing fails.

#include <stdio.h>
#include <stdlib.h>

struct Product
{
    int id;
    float price;
};

int main(void)
{
    size_t count = 2;

    struct Product *products =
        malloc(count * sizeof *products);

    if (products == NULL)
    {
        printf("Initial allocation failed\n");
        return 1;
    }

    products[0] = (struct Product){1, 100.0f};
    products[1] = (struct Product){2, 200.0f};

    size_t newCount = 4;

    if (newCount > (size_t)-1 / sizeof *products)
    {
        free(products);
        return 1;
    }

    struct Product *temp =
        realloc(products, newCount * sizeof *products);

    if (temp == NULL)
    {
        printf("Resize failed\n");
        free(products);
        return 1;
    }

    products = temp;

    products[2] = (struct Product){3, 300.0f};
    products[3] = (struct Product){4, 400.0f};

    for (size_t i = 0; i < newCount; i++)
    {
        printf("ID: %d, Price: %.2f\n",
               products[i].id,
               products[i].price);
    }

    free(products);
    products = NULL;

    return 0;
}
ID: 1, Price: 100.00 ID: 2, Price: 200.00 ID: 3, Price: 300.00 ID: 4, Price: 400.00
Do not directly overwrite the original pointer with realloc() before checking its result. If realloc() fails for a nonzero requested size, the original allocation remains valid. Also, after successful realloc(), use the returned pointer; the old pointer must not be used.

10. Search an Employee by ID

Searching records by a unique identifier is a practical record-management problem.

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    struct Employee employees[] = {
        {101, "Amit", 30000.0f},
        {102, "Neha", 42000.0f},
        {103, "Rahul", 38000.0f}
    };

    size_t n = sizeof(employees) / sizeof(employees[0]);
    int searchId = 102;
    int found = 0;

    for (size_t i = 0; i < n; i++)
    {
        if (employees[i].id == searchId)
        {
            printf("Employee found\n");
            printf("Name: %s\n", employees[i].name);
            printf("Salary: %.2f\n", employees[i].salary);
            found = 1;
            break;
        }
    }

    if (!found)
        printf("Employee not found\n");

    return 0;
}
Employee found Name: Neha Salary: 42000.00

Time Complexity: O(n)

Auxiliary Space Complexity: O(1)

For large sorted record arrays, binary search can reduce search time to O(log n), provided the records are sorted by the searched key.

11. Structure with Dynamically Allocated String

Sometimes a structure must store a string whose length is not known in advance. A pointer member can refer to dynamically allocated storage.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Employee
{
    int id;
    char *name;
};

int main(void)
{
    struct Employee emp;
    const char source[] = "Embedded Engineer";

    emp.id = 501;
    emp.name = malloc(sizeof source);

    if (emp.name == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    memcpy(emp.name, source, sizeof source);

    printf("ID: %d\n", emp.id);
    printf("Name: %s\n", emp.name);

    free(emp.name);
    emp.name = NULL;

    return 0;
}
ID: 501 Name: Embedded Engineer
Copying a structure that contains an owning pointer creates a shallow copy of that pointer. Two structures may then refer to the same allocated string. Freeing both copies independently would cause a double free. Define clear ownership rules or implement an appropriate deep-copy operation.

12. Mini Project: Dynamic Employee Record Manager

This program combines structure design, dynamic allocation, searching and memory cleanup.

#include <stdio.h>
#include <stdlib.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    size_t n;

    printf("Enter number of employees: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid employee count\n");
        return 1;
    }

    if (n > (size_t)-1 / sizeof(struct Employee))
    {
        printf("Requested size is too large\n");
        return 1;
    }

    struct Employee *employees =
        malloc(n * sizeof *employees);

    if (employees == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (size_t i = 0; i < n; i++)
    {
        printf("\nEnter ID, name and salary for employee %zu:\n",
               i + 1);

        if (scanf("%d %29s %f",
                  &employees[i].id,
                  employees[i].name,
                  &employees[i].salary) != 3)
        {
            printf("Invalid input\n");
            free(employees);
            return 1;
        }
    }

    printf("\nEmployee Records:\n");

    for (size_t i = 0; i < n; i++)
    {
        printf("%d %-15s %.2f\n",
               employees[i].id,
               employees[i].name,
               employees[i].salary);
    }

    free(employees);
    employees = NULL;

    return 0;
}

Sample Input

3
101 Amit 30000
102 Neha 42000
103 Rahul 38000

Expected Output

Employee Records: 101 Amit 30000.00 102 Neha 42000.00 103 Rahul 38000.00
This example uses names without spaces to keep input parsing straightforward. For names containing spaces, use a line-based input approach with fgets() and validate the parsed fields.

13. Memory Management and Structure Interview Traps

Concept Interview explanation
Structure padding Compilers may insert padding bytes to satisfy member alignment requirements.
Shallow copy Copies pointer values rather than the pointed-to data.
Deep copy Creates independent storage for dynamically owned data.
malloc() Allocates storage without initializing its contents.
calloc() Allocates storage for an array and initializes all bytes to zero.
realloc() Resizes an allocated block, potentially moving it.
free() Releases allocated storage when ownership is no longer needed.
Memory leak Allocated storage is not released when it is no longer needed.

Common Errors to Avoid

  • Using a structure pointer before allocating or assigning it.
  • Accessing structure members through a NULL pointer.
  • Forgetting to free dynamically allocated arrays.
  • Using a pointer after successful realloc() when the allocation may have moved.
  • Freeing the same allocation more than once.
  • Assuming sizeof(struct) equals the sum of member sizes.
  • Copying structures with owning pointers without considering ownership.
  • Calculating allocation sizes without checking for size_t overflow.

14. Structure and Dynamic Memory Interview Questions

Q1. What is the difference between a structure and a union?

Each structure member has its own storage within the structure object, subject to padding and alignment. Union members share the same storage area, and the union is large enough and suitably aligned for its members.

Q2. Why does structure padding occur?

Padding may be inserted to satisfy alignment requirements for members and the structure itself. This can improve access efficiency on a target architecture.

Q3. What is the difference between dot and arrow operators?

The dot operator accesses a member through a structure object. The arrow operator accesses a member through a pointer to a structure.

Q4. Why use a pointer to a structure instead of passing the structure by value?

Passing a pointer can avoid copying a large structure and allows the function to modify the original object if the pointer is not const-qualified.

Q5. What happens when realloc() fails?

For a nonzero requested size, realloc() returns NULL while the original allocation remains valid and unchanged. Use a temporary pointer to preserve access to it.

Q6. What is the difference between shallow copy and deep copy?

A shallow copy duplicates member values, including pointer addresses. A deep copy also allocates and copies the data referenced by owning pointers.

Q7. Can a structure contain a pointer to its own type?

Yes. This is used in self-referential structures such as linked-list nodes and tree nodes.

Q8. What is the difference between malloc() and calloc()?

malloc() allocates a specified number of bytes without initializing them. calloc() allocates an array of elements and initializes all allocated bytes to zero.

Q9. Why should sizeof *ptr often be preferred in allocation expressions?

It keeps the allocation size tied to the pointed-to type. If the pointer type changes, the expression remains consistent with that type.

Q10. What is memory ownership?

Memory ownership defines which part of a program is responsible for releasing dynamically allocated storage and when that storage may safely be used or released.

16. Practical Compilation and Debugging

Compile using a C11-compatible compiler:

gcc -std=c11 -Wall -Wextra -Wpedantic -g structure_practice.c -o structure_practice
./structure_practice

For supported GCC or Clang environments, enable memory and undefined-behavior checks:

gcc -std=c11 -Wall -Wextra -Wpedantic -g \
-fsanitize=address,undefined \
structure_practice.c -o structure_practice

./structure_practice

Debugging Checklist

  • Verify structure initialization and member access.
  • Check the allocated element count and total byte calculation.
  • Check every allocation result.
  • Use temporary pointers when resizing allocations.
  • Track ownership of pointer members.
  • Release every owned allocation exactly once.
  • Test empty, invalid and unusually large input cases.

17. Key Placement Takeaways

  • Structures are essential for modelling real-world records and embedded data.
  • Structure arrays support searching, sorting and record processing.
  • Structure pointers provide efficient access without copying large objects.
  • Dynamic arrays of structures are common practical programming exercises.
  • realloc() must be handled carefully to avoid losing the original allocation.
  • Pointer members require clear ownership and copying rules.
  • Memory safety, allocation failure handling and cleanup are important interview evaluation areas.
