2. Round 1 – C Programming Fundamentals

Q1. What is C programming?

Suggested interview answer

C is a general-purpose, procedural programming language. It provides low-level memory access through pointers while supporting structured programming through functions and control statements. It is widely used in operating systems, embedded systems, firmware, compilers and performance-sensitive applications.

Follow-up: Why is C commonly used in embedded systems?

Because it provides efficient compiled code, direct access to memory-mapped hardware through implementation-specific mechanisms, predictable data representation on a given platform, and relatively small runtime requirements.

Q2. What are the differences between C and C++?

Suggested interview answer
CC++
Primarily proceduralSupports procedural and object-oriented programming, among other paradigms
No built-in classesSupports classes and objects
No function overloadingSupports function overloading
No references as a language featureSupports references
Uses malloc/free for dynamic allocation in common C codeSupports new/delete and standard containers
Does not support templatesSupports templates

C and C++ share syntax and concepts, but they are distinct languages with different language rules.

Q3. What is the difference between declaration and definition?

Suggested interview answer

A declaration introduces an identifier and its type. A definition provides the entity itself, such as a function body or storage for an object.

extern int count;   /* Declaration */

int count = 10;     /* Definition */

int add(int, int);  /* Function declaration */

int add(int a, int b)
{
    return a + b;   /* Function definition */
}

Q4. What is the difference between a compiler and an interpreter?

Suggested interview answer

A compiler translates source code into another representation, commonly machine code or object code, before execution. An interpreter executes program instructions through an interpreter runtime. Real-world language implementations can combine compilation and interpretation techniques.

Q5. What are the stages involved in building a C program?

Suggested interview answer
  1. Preprocessing: Processes directives such as #include and #define.
  2. Compilation: Translates the processed source into assembly or another intermediate representation.
  3. Assembly: Produces object files containing machine code and related information.
  4. Linking: Resolves external symbols and combines object files and libraries into an executable or another target.

The compiler driver, such as GCC, coordinates these stages and invokes the necessary tools.

Q6. What is the difference between a keyword and an identifier?

Suggested interview answer

A keyword is a reserved language token with a predefined meaning, such as int, return, if and while. An identifier is a programmer-defined name for a variable, function, structure or other declared entity.

3. Round 2 – Variables, Operators and Functions

Q7. What is the difference between a local and global variable?

Suggested interview answer

A local variable is declared inside a block or function and has block scope. A file-scope variable is declared outside functions and has file scope. Their storage duration and linkage depend on their declarations and storage-class specifiers.

Q8. What is the difference between static and automatic variables?

Suggested interview answer

An ordinary block-scope variable has automatic storage duration. A block-scope variable declared static has static storage duration, retains its value between function calls, and is initialized to zero if no explicit initializer is provided.

#include <stdio.h>

void counter(void)
{
    static int count = 0;
    count++;

    printf("%d\n", count);
}

int main(void)
{
    counter();
    counter();
    counter();

    return 0;
}
Output
1
2
3

Q9. What is the difference between call by value and passing an address?

Suggested interview answer

C passes function arguments by value. When a pointer is passed, the pointer value is copied into the parameter, but the function can use that pointer to modify the original object.

#include <stdio.h>

void update(int *value)
{
    if (value != NULL)
        *value = 100;
}

int main(void)
{
    int number = 10;

    update(&number);

    printf("%d\n", number);

    return 0;
}
Output
100

Q10. What is recursion?

Suggested interview answer

Recursion occurs when a function calls itself, directly or indirectly. A correct recursive function requires a base case and progress toward that base case.

Each active recursive call consumes implementation resources, typically through a call stack. Excessive recursion can exhaust available stack space.

Q11. What is the difference between break and continue?

Suggested interview answer

break terminates the nearest enclosing loop or switch statement. continue skips the remaining statements in the current loop iteration and proceeds to the next iteration according to that loop's rules.

Q12. What is the difference between while and do-while?

Suggested interview answer

while checks the condition before executing the loop body. do-while checks the condition after executing the body, so the body executes at least once.

4. Round 3 – Arrays, Strings and Pointers

Q13. What is an array?

Suggested interview answer

An array is a contiguous sequence of elements of the same type. Its elements are accessed using indices starting at zero. An array expression often converts to a pointer to its first element, except in contexts such as sizeof and unary &.

Q14. What is the difference between an array and a pointer?

Suggested interview answer

An array is an object containing a fixed number of elements. A pointer is an object that stores a pointer value. Although arrays often convert to pointers in expressions, they are not interchangeable.

#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *ptr = arr;

    printf("Array size = %zu\n", sizeof(arr));
    printf("Pointer size = %zu\n", sizeof(ptr));

    return 0;
}

The two sizes are not necessarily equal. The array size is five times sizeof(int), while pointer size depends on the implementation.

Q15. What is a NULL pointer?

Suggested interview answer

A null pointer is a pointer value that is guaranteed not to point to an object or function. It is commonly represented in source code using NULL.

int *ptr = NULL;

if (ptr != NULL)
{
    printf("%d\n", *ptr);
}

Dereferencing a null pointer has undefined behavior.

Q16. What is a dangling pointer?

Suggested interview answer

A dangling pointer is a pointer whose referenced object has ceased to exist or whose storage is no longer valid for access. Dereferencing it is invalid.

int *ptr = malloc(sizeof(*ptr));

if (ptr != NULL)
{
    *ptr = 50;
    free(ptr);
    ptr = NULL;
}

Setting ptr to NULL prevents later accidental use through that particular pointer variable. It does not update other aliases that might still contain the old address.

Q17. What is a double pointer?

Suggested interview answer

A double pointer stores the address of another pointer object.

#include <stdio.h>

int main(void)
{
    int number = 25;
    int *ptr = &number;
    int **dptr = &ptr;

    printf("%d\n", **dptr);

    return 0;
}
Output
25

Double pointers are useful when a function must modify a caller's pointer variable, such as when allocating a data structure and returning its address through an output parameter.

Q18. What is a function pointer?

Suggested interview answer

A function pointer stores a pointer to a function with a compatible function type. It enables callbacks, dispatch tables and configurable behavior.

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*operation)(int, int) = add;

    printf("%d\n", operation(10, 20));

    return 0;
}
Output
30

Q19. What is the difference between strcpy and strncpy?

Suggested interview answer

strcpy copies a source string including its terminating null character, assuming the destination has sufficient space. strncpy copies up to a specified number of characters, but may not append a null character if the source length reaches or exceeds the limit.

Neither function automatically checks the actual destination capacity. Safer code explicitly validates sizes and ensures null termination where required.

5. Round 4 – Memory Management and Data Structures

Q20. What is the difference between malloc and calloc?

Suggested interview answer
malloc()calloc()
Allocates a requested number of bytes.Allocates space for an array of elements.
Allocated bytes have indeterminate values.Allocated storage is initialized to all bits zero.
One size argument.Element count and element size arguments.

Always check the returned pointer before accessing allocated storage.

Q21. What is realloc?

Suggested interview answer

realloc changes the size of an allocated memory block. It may extend the existing block or move the allocation to another location. If it fails for a nonzero requested size, the original allocation remains valid.

int *temp = realloc(array, new_count * sizeof(*array));

if (temp != NULL)
{
    array = temp;
}
else
{
    /* Original array remains valid. */
}

Before calculating the requested byte count, verify that the multiplication cannot overflow SIZE_MAX.

Q22. What is a memory leak?

Suggested interview answer

A memory leak occurs when dynamically allocated memory is no longer reachable or cannot be released because the program loses track of its allocation. Repeated leaks can increase memory consumption and eventually cause allocation failures.

Q23. What is the difference between stack and heap memory?

Suggested interview answer
StackHeap

Limited by implementation resources.Limited by available memory and implementation constraints.

The C standard does not require a particular physical memory layout or require automatic objects to be implemented using a hardware stack.

Q24. What is a linked list?

Suggested interview answer

A linked list is a collection of nodes connected through pointers. Each node typically contains data and a pointer to another node. Unlike an array, its nodes need not occupy contiguous memory locations.

Q30. Undefined behavior

#include <stdio.h>

int main(void)
{
    int x = 5;

    printf("%d %d\n", x++, x++);

    return 0;
}
Show answer
There is no portable, well-defined output. This expression modifies x twice without the required sequencing between those modifications. Its behavior is undefined in C.

Do not predict a specific result based on one compiler's output. Separate the operations into different full expressions.

7. Round 6 – Debugging and Error Identification

Q31. Identify the problem in this code

int *ptr = malloc(sizeof(int));
*ptr = 10;
free(ptr);
printf("%d", *ptr);
Show answer

The code dereferences ptr after the allocated object has been freed. This is a use-after-free error and results in undefined behavior.

Read the value before freeing the allocation, or copy it into a separate valid object first.

Q32. Identify the problem in this function

int divide(int a, int b)
{
    return a / b;
}
Show answer

The function does not handle b == 0. Integer division by zero has undefined behavior. A robust interface should validate the divisor and report failure.

Q33. Identify the problem in this array access

int arr[5] = {1, 2, 3, 4, 5};

for (int i = 0; i <= 5; i++)
{
    printf("%d ", arr[i]);
}
Show answer

The loop accesses arr[5], which is outside the valid indices 0 through 4. Use i < 5.

Q34. Identify the problem in this input operation

int number;
scanf("%d", number);
Show answer

scanf requires the address of the destination object. The corrected call is:

scanf("%d", &number);

Also check the return value to verify successful input conversion.

8. Round 7 – Coding Interview Questions

Q35. Write a function to reverse an integer array in place.

Expected approach: Use two indices, one at the beginning and one at the end. Swap their elements and move both indices toward the center.

Show C11 solution 
#include <stdio.h>
#include <stddef.h>

void reverse_array(int arr[], size_t n)
{
    size_t left = 0;
    size_t right = n;

    while (left < right && left < --right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    reverse_array(arr, n);

    for (size_t i = 0; i < n; i++)
        printf("%d ", arr[i]);

    printf("\n");
    return 0;
}
50 40 30 20 10

Complexity: O(n) time and O(1) auxiliary space. The function requires a valid array when n is nonzero.

Q36. Write a function to find the second-largest distinct element.

Expected approach: Maintain the largest and second-largest distinct values in a single traversal.

Show C11 solution 
#include <stdio.h>
#include <stddef.h>

int second_largest(const int arr[], size_t n, int *result)
{
    if (arr == NULL || result == NULL || n < 2)
        return 0;

    int largest = arr[0];
    int second = arr[0];
    int has_second = 0;

    for (size_t i = 1; i < n; i++)
    {
        if (arr[i] > largest)
        {
            second = largest;
            largest = arr[i];
            has_second = 1;
        }
        else if (arr[i] < largest)
        {
            if (!has_second || arr[i] > second)
            {
                second = arr[i];
                has_second = 1;
            }
        }
    }

    if (!has_second)
        return 0;

    *result = second;
    return 1;
}

int main(void)
{
    int arr[] = {10, 50, 30, 50, 40};
    size_t n = sizeof(arr) / sizeof(arr[0]);
    int answer;

    if (second_largest(arr, n, &answer))
        printf("Second largest = %d\n", answer);
    else
        printf("No second distinct value\n");

    return 0;
}
Second largest = 40

Complexity: O(n) time and O(1) auxiliary space.

The algorithm correctly handles negative values and duplicate maximum values.

Q37. Write a function to count set bits in an unsigned integer.

Expected approach: Repeatedly clear the lowest set bit using n = n & (n - 1).

Show C11 solution 
#include <stdio.h>

unsigned int count_set_bits(unsigned int n)
{
    unsigned int count = 0;

    while (n != 0U)
    {
        n &= n - 1U;
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int n;

    if (scanf("%u", &n) != 1)
        return 1;

    printf("Set bits = %u\n", count_set_bits(n));

    return 0;
}

Complexity: O(k), where k is the number of set bits; O(1) auxiliary space.

9. Round 8 – Advanced C Concepts

Q38. What is the difference between const and volatile?

Suggested interview answer

const prevents modification of an object through an expression that uses a const-qualified lvalue.

volatile tells the implementation that accesses to the volatile-qualified object are observable side effects according to the language rules. The compiler must respect volatile access requirements.

volatile does not guarantee atomicity, mutual exclusion or inter-thread synchronization.

Q39. What is a memory-mapped register?

Suggested interview answer

A memory-mapped register is a hardware control or status register exposed through an address in the processor's address space. Embedded software accesses it using addresses and types defined by the device and compiler environment.

#include <stdint.h>

#define GPIO_REGISTER_ADDRESS ((uintptr_t)0x40020000U)

volatile uint32_t * const GPIO_REG =
    (volatile uint32_t *)GPIO_REGISTER_ADDRESS;
This is an illustrative embedded example, not portable hosted C code. The address, register width, access permissions, alignment, and required barriers are platform-specific. Do not execute it on a normal desktop system.

Q40. What is the difference between a macro and an inline function?

Suggested interview answer

A macro is expanded by the preprocessor and does not provide normal function type checking or argument evaluation rules. An inline function is a language-level function with type checking and normal function semantics. The inline keyword does not guarantee that the compiler will eliminate the function call.

Q41. What is undefined behavior?

Suggested interview answer

Undefined behavior occurs when the C standard imposes no requirements on the result of a program execution. Examples include signed integer overflow, dereferencing an invalid pointer, accessing an array outside its bounds and dividing an integer by zero.

Compilers may optimize on the assumption that undefined behavior does not occur in valid programs.

Q42. What is the difference between undefined and implementation-defined behavior?

Suggested interview answer

For undefined behavior, the C standard imposes no requirements. For implementation-defined behavior, the implementation must document which permitted behavior it chooses.

Unspecified behavior is another category: the implementation may choose among permitted alternatives, and it need not document the choice.

10. Round 9 – Embedded C Interview Questions

Q43. What is Embedded C?

Suggested interview answer

Embedded C refers to C programming used to develop firmware and software for embedded systems. It involves interaction with microcontrollers, peripheral registers, interrupts, timers, communication interfaces and memory-constrained hardware.

Q44. What is the role of volatile in embedded programming?

Suggested interview answer

volatile is commonly used for memory-mapped peripheral registers and objects that may change outside the normal program flow, such as certain interrupt-shared variables. It prevents the compiler from treating accesses as ordinary removable or freely cached accesses.

It does not itself provide atomicity or synchronization. Correct interrupt and concurrency handling may require architecture-specific mechanisms, critical sections or C11 atomics where supported and appropriate.

Q45. What is an interrupt?

Suggested interview answer

An interrupt is an event that causes the processor to suspend its current execution flow and transfer control to an interrupt service routine or handler, subject to the processor architecture and interrupt controller.

After handling the event, execution generally resumes according to the architecture's interrupt-return mechanism.

Q46. What is an ISR?

Suggested interview answer

An Interrupt Service Routine (ISR) is a function or handler executed in response to an interrupt. It should generally execute quickly, acknowledge or service the event, and defer lengthy processing when appropriate.

Q47. What is the difference between polling and interrupts?

Suggested interview answer
PollingInterrupts
CPU repeatedly checks a device or status flag.Hardware or an interrupt controller signals an event.
Can waste CPU time while waiting.Can allow the CPU to perform other work between events.
Simple to implement in some systems.Requires interrupt configuration and careful shared-state handling.

Q48. What is a watchdog timer?

Suggested interview answer

A watchdog timer is a hardware or software mechanism that detects when a system fails to make expected progress. If the watchdog is not serviced within a configured interval, it can trigger a reset or another recovery action.

Q49. What is the difference between UART, SPI and I2C?

Suggested interview answer
InterfaceSignalsTypical characteristics
UARTTX and RXAsynchronous serial communication; commonly point-to-point.
SPISCLK, MOSI, MISO and CSSynchronous, typically full-duplex; separate chip-select lines are common.
I2CSCL and SDASynchronous two-wire bus with addressing and shared bus operation.

Q50. What is the difference between a microprocessor and a microcontroller?

Suggested interview answer

A microprocessor is primarily a CPU and generally relies on external components for memory and peripherals. A microcontroller integrates a CPU, memory and peripheral interfaces into one chip, making it suitable for dedicated control applications.

12. How to Answer Technical Questions

Use this structure when answering a technical question:

  1. Definition: Give a precise one- or two-sentence definition.
  2. Mechanism: Explain how the concept works.
  3. Example: Provide a small code or practical example.
  4. Application: Explain where the concept is used.
  5. Limitation: Mention important restrictions or risks.

14. Final Interview Checklist

  • Can you explain the compilation and linking process?
  • Can you distinguish arrays, pointers and function pointers?
  • Can you write and debug pointer-based programs?
  • Can you explain storage duration, scope and linkage?
  • Can you use malloc(), calloc(), realloc() and free() safely?
  • Can you implement arrays, stacks, queues and linked lists?
  • Can you predict output while identifying undefined behavior?
  • Can you explain time and space complexity?
  • Can you explain const and volatile accurately?
  • Can you discuss interrupts, ISRs and communication peripherals?
  • Can you write a complete C11 program without relying on memorized fragments?
Final preparation advice: A strong fresher candidate should be able to write working code, explain why it works, identify edge cases, and discuss memory and performance. For embedded roles, connect C language concepts to practical hardware examples such as GPIO, UART, timers, ADC, interrupts and memory-mapped registers.
