1. Learning Objectives

After completing this lecture, you should be able to:

  • Find maximum, minimum and second-largest array elements.
  • Search for elements using linear and binary search.
  • Sort arrays using common sorting algorithms.
  • Remove duplicates from a sorted array.
  • Rotate an array efficiently.
  • Find pairs and subarrays that satisfy given conditions.
  • Perform common matrix operations.
  • Analyze array and matrix algorithms using time and space complexity.

2. Array Problem-Solving Fundamentals

An array stores multiple elements of the same type in contiguous memory locations. Array problems commonly involve traversal, comparison, searching, rearrangement and aggregation.

Basic traversal

for (size_t i = 0; i < n; i++)
{
    printf("%d ", array[i]);
}

Important considerations

  • Check whether the array contains zero elements before accessing it.
  • For an array of length n, valid indices are 0 through n - 1.
  • Do not access an element outside the array bounds.
  • Choose a suitable data type for values and calculations.
  • Understand whether the input array is sorted or unsorted.
Interview approach: Before writing code, identify the input size, whether the array is sorted, whether duplicates are allowed, and whether the solution must modify the original array.

3. Find the Largest and Smallest Elements

Problem

Find the maximum and minimum elements in an integer array using one traversal.

Logic

  1. Initialize both maximum and minimum with the first element.
  2. Traverse the remaining elements.
  3. Update maximum when a larger value is found.
  4. Update minimum when a smaller value is found.

C11 Program

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    int maximum = array[0];
    int minimum = array[0];

    for (size_t i = 1; i < n; i++)
    {
        if (array[i] > maximum)
            maximum = array[i];

        if (array[i] < minimum)
            minimum = array[i];
    }

    printf("Maximum = %d\n", maximum);
    printf("Minimum = %d\n", minimum);

    return 0;
}

Expected Result

Enter number of elements: 6 Enter array elements: 12 45 7 89 23 5 Maximum = 89 Minimum = 5

Time complexity: O(n)

Auxiliary space: O(1)

4. Find the Second-Largest Distinct Element

Problem

Find the second-largest distinct value in an array. If no such value exists, report that fact.

Example

Input:  10 40 20 40 30
Output: 30

C11 Program

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    int largest = array[0];
    int second_largest = 0;
    int found_second = 0;

    for (size_t i = 1; i < n; i++)
    {
        if (array[i] > largest)
        {
            second_largest = largest;
            largest = array[i];
            found_second = 1;
        }
        else if (array[i] < largest)
        {
            if (!found_second || array[i] > second_largest)
            {
                second_largest = array[i];
                found_second = 1;
            }
        }
    }

    if (found_second)
        printf("Second-largest distinct element = %d\n", second_largest);
    else
        printf("No second-largest distinct element exists.\n");

    return 0;
}

Expected Result

Enter number of elements: 5 Enter array elements: 10 40 20 40 30 Second-largest distinct element = 30

Time complexity: O(n)

Auxiliary space: O(1)

The distinction between second-largest and second-largest distinct is important. For example, in 10, 20, 20, the second-largest distinct element is 10, not 20.

5. Linear Search

Problem

Search for a target value in an unsorted array and return its first index.

C11 Program

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;
    int target;
    int position = -1;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    printf("Enter target: ");

    if (scanf("%d", &target) != 1)
    {
        printf("Invalid target.\n");
        return 1;
    }

    for (size_t i = 0; i < n; i++)
    {
        if (array[i] == target)
        {
            position = (int)i;
            break;
        }
    }

    if (position != -1)
        printf("Element found at index %d\n", position);
    else
        printf("Element not found.\n");

    return 0;
}

Expected Result

Enter number of elements: 5 Enter array elements: 10 20 30 40 50 Enter target: 30 Element found at index 2

Time complexity: O(n) in the worst case.

Auxiliary space: O(1)

6. Binary Search

Problem

Search for a target element in a sorted array using binary search.

Working Principle

  1. Find the middle index.
  2. If the middle element equals the target, return its index.
  3. If the target is smaller, search the left half.
  4. If the target is larger, search the right half.
  5. Repeat until the target is found or the search interval becomes empty.

C11 Program – Iterative Binary Search

#include <stdio.h>

int binary_search(const int array[], size_t n, int target)
{
    size_t low = 0;
    size_t high = n;

    while (low < high)
    {
        size_t mid = low + (high - low) / 2;

        if (array[mid] == target)
            return (int)mid;

        if (array[mid] < target)
            low = mid + 1;
        else
            high = mid;
    }

    return -1;
}

int main(void)
{
    int array[100];
    size_t n;
    int target;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter elements in ascending order:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }

        if (i > 0 && array[i] < array[i - 1])
        {
            printf("Array must be sorted in ascending order.\n");
            return 1;
        }
    }

    printf("Enter target: ");

    if (scanf("%d", &target) != 1)
    {
        printf("Invalid target.\n");
        return 1;
    }

    int result = binary_search(array, n, target);

    if (result != -1)
        printf("Element found at index %d\n", result);
    else
        printf("Element not found.\n");

    return 0;
}

Expected Result

Enter number of elements: 6 Enter elements in ascending order: 10 20 30 40 50 60 Enter target: 40 Element found at index 3

Time complexity: O(log n)

Auxiliary space: O(1) for the iterative implementation.

Binary search requires sorted input. Applying it directly to an unsorted array can produce incorrect results.

7. Bubble Sort

Problem

Sort an array in ascending order using bubble sort.

Working Principle

Compare adjacent elements and swap them if they are in the wrong order. After each pass, the largest remaining element moves to its correct position at the end.

C11 Program

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    for (size_t i = 0; i + 1 < n; i++)
    {
        int swapped = 0;

        for (size_t j = 0; j + 1 < n - i; j++)
        {
            if (array[j] > array[j + 1])
            {
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
                swapped = 1;
            }
        }

        if (!swapped)
            break;
    }

    printf("Sorted array: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", array[i]);

    printf("\n");
    return 0;
}

Expected Result

Enter number of elements: 5 Enter array elements: 50 20 40 10 30 Sorted array: 10 20 30 40 50
CaseTime complexity
Best case with early terminationO(n)
Average caseO(n²)
Worst caseO(n²)

Auxiliary space: O(1)

8. Remove Duplicates from a Sorted Array

Problem

Remove repeated values from a sorted array in-place and return the number of unique elements.

Example

Input:  1 1 2 2 3 4 4 5
Output: 1 2 3 4 5
Length: 5

C11 Program

#include <stdio.h>

size_t remove_duplicates(int array[], size_t n)
{
    if (n == 0)
        return 0;

    size_t unique_count = 1;

    for (size_t i = 1; i < n; i++)
    {
        if (array[i] != array[unique_count - 1])
        {
            array[unique_count] = array[i];
            unique_count++;
        }
    }

    return unique_count;
}

int main(void)
{
    int array[100];
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter sorted array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }

        if (i > 0 && array[i] < array[i - 1])
        {
            printf("Array must be sorted.\n");
            return 1;
        }
    }

    size_t new_length = remove_duplicates(array, n);

    printf("Unique elements: ");

    for (size_t i = 0; i < new_length; i++)
        printf("%d ", array[i]);

    printf("\nNew length = %zu\n", new_length);

    return 0;
}

Expected Result

Enter number of elements: 8 Enter sorted array elements: 1 1 2 2 3 4 4 5 Unique elements: 1 2 3 4 5 New length = 5

Time complexity: O(n)

Auxiliary space: O(1)

This is a common two-pointer technique. The write position tracks where the next unique element should be stored.

9. Rotate an Array to the Right by k Positions

Problem

Rotate an array to the right by k positions.

Example

Original: 1 2 3 4 5 6 7
k = 3
Result:   5 6 7 1 2 3 4

Reversal Algorithm

  1. Reverse the entire array.
  2. Reverse the first k elements.
  3. Reverse the remaining elements.

C11 Program

#include <stdio.h>

void reverse(int array[], size_t left, size_t right)
{
    while (left < right)
    {
        int temp = array[left];
        array[left] = array[right];
        array[right] = temp;

        left++;
        right--;
    }
}

int main(void)
{
    int array[100];
    size_t n;
    size_t k;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    printf("Enter rotation count: ");

    if (scanf("%zu", &k) != 1)
    {
        printf("Invalid rotation count.\n");
        return 1;
    }

    k %= n;

    if (k != 0)
    {
        reverse(array, 0, n - 1);
        reverse(array, 0, k - 1);
        reverse(array, k, n - 1);
    }

    printf("Rotated array: ");

    for (size_t i = 0; i < n; i++)
        printf("%d ", array[i]);

    printf("\n");
    return 0;
}

Expected Result

Enter number of elements: 7 Enter array elements: 1 2 3 4 5 6 7 Enter rotation count: 3 Rotated array: 5 6 7 1 2 3 4

Time complexity: O(n)

Auxiliary space: O(1)

10. Find a Pair with a Given Sum

Problem

Find whether an unsorted array contains two distinct elements whose sum equals a target value.

Example

Array: 2 7 11 15
Target: 9
Pair: 2 and 7

C11 Program – Brute Force

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;
    int target;
    int found = 0;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n < 2 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    printf("Enter target sum: ");

    if (scanf("%d", &target) != 1)
    {
        printf("Invalid target.\n");
        return 1;
    }

    for (size_t i = 0; i < n - 1; i++)
    {
        for (size_t j = i + 1; j < n; j++)
        {
            long long sum = (long long)array[i] + array[j];

            if (sum == target)
            {
                printf("Pair found: %d and %d\n",
                       array[i], array[j]);
                found = 1;
            }
        }
    }

    if (!found)
        printf("No pair found.\n");

    return 0;
}

Expected Result

Enter number of elements: 4 Enter array elements: 2 7 11 15 Enter target sum: 9 Pair found: 2 and 7

Time complexity: O(n²)

Auxiliary space: O(1)

For a sorted array, a two-pointer technique can solve the pair-sum problem in O(n) time. For an unsorted array, a hash table can provide an expected O(n) approach with additional space.

11. Maximum Subarray Sum – Kadane's Algorithm

Problem

Find the maximum sum of a contiguous, non-empty subarray.

Example

Input:  -2 1 -3 4 -1 2 1 -5 4
Output: 6
Subarray: 4 -1 2 1

Logic

At each position, either start a new subarray from the current element or extend the previous subarray.

current_sum = max(array[i], current_sum + array[i]);
maximum_sum = max(maximum_sum, current_sum);

C11 Program

#include <stdio.h>

int main(void)
{
    int array[100];
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0 || n > 100)
    {
        printf("Invalid array size.\n");
        return 1;
    }

    printf("Enter array elements:\n");

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &array[i]) != 1)
        {
            printf("Invalid element.\n");
            return 1;
        }
    }

    long long current_sum = array[0];
    long long maximum_sum = array[0];

    for (size_t i = 1; i < n; i++)
    {
        long long extend = current_sum + array[i];

        if (array[i] > extend)
            current_sum = array[i];
        else
            current_sum = extend;

        if (current_sum > maximum_sum)
            maximum_sum = current_sum;
    }

    printf("Maximum subarray sum = %lld\n", maximum_sum);

    return 0;
}

Expected Result

Enter number of elements: 9 Enter array elements: -2 1 -3 4 -1 2 1 -5 4 Maximum subarray sum = 6

Time complexity: O(n)

Auxiliary space: O(1)

The algorithm must initialize its running and maximum sums from the first element, not zero. This correctly handles arrays containing only negative values.

12. Matrix Addition

Problem

Add two matrices of the same dimensions.

C11 Program

#include <stdio.h>

int main(void)
{
    int a[10][10], b[10][10], result[10][10];
    size_t rows, cols;

    printf("Enter rows and columns: ");

    if (scanf("%zu %zu", &rows, &cols) != 2 ||
        rows == 0 || cols == 0 || rows > 10 || cols > 10)
    {
        printf("Invalid matrix dimensions.\n");
        return 1;
    }

    printf("Enter first matrix:\n");

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            if (scanf("%d", &a[i][j]) != 1)
            {
                printf("Invalid input.\n");
                return 1;
            }
        }
    }

    printf("Enter second matrix:\n");

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            if (scanf("%d", &b[i][j]) != 1)
            {
                printf("Invalid input.\n");
                return 1;
            }
        }
    }

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
            result[i][j] = a[i][j] + b[i][j];
    }

    printf("Result matrix:\n");

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
            printf("%d ", result[i][j]);

        printf("\n");
    }

    return 0;
}

Expected Result

Enter rows and columns: 2 2 Enter first matrix: 1 2 3 4 Enter second matrix: 5 6 7 8 Result matrix: 6 8 10 12

Time complexity: O(rows × columns)

Auxiliary space: O(rows × columns) for the result matrix.

13. Matrix Transpose

Problem

Find the transpose of a matrix by interchanging its rows and columns.

For a matrix A, the transpose is defined as:

transpose[j][i] = A[i][j]

C11 Program

#include <stdio.h>

int main(void)
{
    int matrix[10][10];
    int transpose[10][10];
    size_t rows, cols;

    printf("Enter rows and columns: ");

    if (scanf("%zu %zu", &rows, &cols) != 2 ||
        rows == 0 || cols == 0 || rows > 10 || cols > 10)
    {
        printf("Invalid matrix dimensions.\n");
        return 1;
    }

    printf("Enter matrix elements:\n");

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            if (scanf("%d", &matrix[i][j]) != 1)
            {
                printf("Invalid input.\n");
                return 1;
            }
        }
    }

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
            transpose[j][i] = matrix[i][j];
    }

    printf("Transpose matrix:\n");

    for (size_t i = 0; i < cols; i++)
    {
        for (size_t j = 0; j < rows; j++)
            printf("%d ", transpose[i][j]);

        printf("\n");
    }

    return 0;
}

Expected Result

Enter rows and columns: 2 3 Enter matrix elements: 1 2 3 4 5 6 Transpose matrix: 1 4 2 5 3 6

Time complexity: O(rows × columns)

Auxiliary space: O(rows × columns) for the transpose matrix.

14. Matrix Multiplication

Problem

Multiply two matrices when the number of columns in the first matrix equals the number of rows in the second matrix.

If A has dimensions m × n and B has dimensions n × p, the result has dimensions m × p.

Mathematical Formula

C[i][j] = sum of A[i][k] * B[k][j]

C11 Program

#include <stdio.h>

int main(void)
{
    int a[10][10], b[10][10];
    long long result[10][10] = {0};

    size_t r1, c1, r2, c2;

    printf("Enter rows and columns of first matrix: ");

    if (scanf("%zu %zu", &r1, &c1) != 2 ||
        r1 == 0 || c1 == 0 || r1 > 10 || c1 > 10)
    {
        printf("Invalid first matrix dimensions.\n");
        return 1;
    }

    printf("Enter rows and columns of second matrix: ");

    if (scanf("%zu %zu", &r2, &c2) != 2 ||
        r2 == 0 || c2 == 0 || r2 > 10 || c2 > 10)
    {
        printf("Invalid second matrix dimensions.\n");
        return 1;
    }

    if (c1 != r2)
    {
        printf("Matrix multiplication is not possible.\n");
        return 1;
    }

    printf("Enter first matrix:\n");

    for (size_t i = 0; i < r1; i++)
    {
        for (size_t j = 0; j < c1; j++)
        {
            if (scanf("%d", &a[i][j]) != 1)
            {
                printf("Invalid input.\n");
                return 1;
            }
        }
    }

    printf("Enter second matrix:\n");

    for (size_t i = 0; i < r2; i++)
    {
        for (size_t j = 0; j < c2; j++)
        {
            if (scanf("%d", &b[i][j]) != 1)
            {
                printf("Invalid input.\n");
                return 1;
            }
        }
    }

    for (size_t i = 0; i < r1; i++)
    {
        for (size_t j = 0; j < c2; j++)
        {
            for (size_t k = 0; k < c1; k++)
            {
                result[i][j] +=
                    (long long)a[i][k] * b[k][j];
            }
        }
    }

    printf("Product matrix:\n");

    for (size_t i = 0; i < r1; i++)
    {
        for (size_t j = 0; j < c2; j++)
            printf("%lld ", result[i][j]);

        printf("\n");
    }

    return 0;
}

Expected Result

Enter rows and columns of first matrix: 2 2 Enter rows and columns of second matrix: 2 2 Enter first matrix: 1 2 3 4 Enter second matrix: 5 6 7 8 Product matrix: 19 22 43 50

Time complexity: O(r1 × c1 × c2)

Auxiliary space: O(r1 × c2) for the result matrix.

This example uses long long for the result, but extremely large input values can still overflow. Production code should validate the permitted input range and use checked arithmetic where required.

16. Frequently Asked Technical Interview Questions

Q1. What is the difference between linear search and binary search?

Linear search checks elements sequentially and works on unsorted arrays. Binary search repeatedly halves the search interval and requires sorted data.

Q2. Why does binary search have O(log n) complexity?

Each comparison reduces the remaining search interval to approximately half its previous size.

Q3. What is a stable sorting algorithm?

A stable sorting algorithm preserves the relative order of elements having equal keys. Bubble sort is stable when equal elements are not swapped.

Q4. What is an in-place algorithm?

An in-place algorithm performs its operation using constant or very small auxiliary storage, rather than allocating another data structure proportional to the input size.

Q5. What is the two-pointer technique?

It uses two indices to process an array efficiently. It is useful for sorted pair-sum problems, duplicate removal and partitioning.

Q6. What is Kadane's algorithm?

It finds the maximum sum of a non-empty contiguous subarray in O(n) time by maintaining a best subarray sum ending at each position.

Q7. Can binary search be applied to a linked list efficiently?

Not in the same way as an array. A linked list does not provide constant-time random access to its middle element, so repeatedly finding middle nodes can remove binary search's practical advantage.

Q8. What is the difference between a row-major and column-major layout?

In C, multidimensional arrays are stored in row-major order. Elements of each row are contiguous in memory.

Q9. What is the time complexity of multiplying two square matrices using the basic algorithm?

For two n × n matrices, the standard triple-loop algorithm takes O(n³) time.

Q10. Why should array bounds be checked?

Accessing an element outside the array's valid range causes undefined behavior in C.

19. Lecture Summary

  • Array traversal and comparison are foundational coding techniques.
  • Linear search works with unsorted arrays.
  • Binary search requires sorted data and takes O(log n) time.
  • Bubble sort is simple but inefficient for large arrays.
  • Two-pointer methods can reduce unnecessary nested loops.
  • Array rotation can be performed in-place using reversal.
  • Kadane's algorithm solves maximum subarray sum in O(n).
  • Matrix operations require careful dimension handling.
  • C stores multidimensional arrays in row-major order.
  • Always validate array sizes and prevent out-of-bounds access.
