2. Basic Mathematical Operations on Integers

Integer division and remainder are fundamental to number-based coding problems.

OperatorExampleResult
/25 / 102
%25 % 105

To extract the last digit of a non-negative integer:

digit = number % 10;

To remove the last digit:

number = number / 10;

Example for 583:

583 % 10 = 3
583 / 10 = 58
58 % 10  = 8
58 / 10  = 5
5 % 10   = 5
Interview concept: The combination of % 10 and / 10 is commonly used in digit extraction, reversal, palindrome, Armstrong and digit-sum problems.

3. Sum of Digits

Problem

Write a program to calculate the sum of all digits of a non-negative integer.

Logic

  1. Extract the last digit using remainder by 10.
  2. Add the digit to the sum.
  3. Remove the last digit using integer division by 10.
  4. Repeat until the number becomes zero.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number;
    unsigned int sum = 0;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &number) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    while (number > 0)
    {
        sum += number % 10;
        number /= 10;
    }

    printf("Sum of digits = %u\n", sum);

    return 0;
}

Expected Result

Enter a non-negative integer: 5832 Sum of digits = 18

Complexity: O(d) time, where d is the number of digits. O(1) auxiliary space.

4. Count the Number of Digits

Problem

Count the number of decimal digits in a non-negative integer. Zero is considered a one-digit number.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number;
    unsigned int count = 0;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &number) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (number == 0)
    {
        count = 1;
    }
    else
    {
        while (number > 0)
        {
            count++;
            number /= 10;
        }
    }

    printf("Number of digits = %u\n", count);

    return 0;
}

Expected Result

Enter a non-negative integer: 90876 Number of digits = 5

Complexity: O(d) time and O(1) auxiliary space.

An alternative is to use logarithms, but repeated integer division avoids floating-point rounding issues and handles zero explicitly.

5. Reverse a Number

Problem

Reverse the digits of a non-negative integer.

Logic

For each digit, shift the current reversed value one decimal place to the left and append the extracted digit.

reverse = reverse * 10 + digit;

C11 Program with Overflow Checking

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int number;
    unsigned int reverse = 0;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &number) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    while (number > 0)
    {
        unsigned int digit = number % 10;

        if (reverse > (UINT_MAX - digit) / 10)
        {
            printf("Reversed value exceeds unsigned int range.\n");
            return 1;
        }

        reverse = reverse * 10 + digit;
        number /= 10;
    }

    printf("Reversed number = %u\n", reverse);

    return 0;
}

Expected Result

Enter a non-negative integer: 12345 Reversed number = 54321

Complexity: O(d) time and O(1) auxiliary space.

Leading zeros disappear in an integer representation. For example, reversing 1200 produces 21, not 0021.

6. Palindrome Number

Problem

Check whether a non-negative integer reads the same forward and backward.

Examples:

  • 121 – Palindrome
  • 1331 – Palindrome
  • 123 – Not a palindrome
  • 10 – Not a palindrome

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number;
    unsigned int original;
    unsigned int reverse = 0;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &number) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    original = number;

    do
    {
        unsigned int digit = number % 10;

        if (reverse > (UINT_MAX - digit) / 10)
        {
            printf("Reversed value exceeds unsigned int range.\n");
            return 1;
        }

        reverse = reverse * 10 + digit;
        number /= 10;

    } while (number > 0);

    if (original == reverse)
        printf("Palindrome number.\n");
    else
        printf("Not a palindrome number.\n");

    return 0;
}

Note: Include <limits.h> in this program for UINT_MAX.

Expected Result

Enter a non-negative integer: 1331 Palindrome number.

Complexity: O(d) time and O(1) auxiliary space.

7. Factorial of a Number

Definition

Factorial of a non-negative integer n is the product of all positive integers from 1 to n.

n! = n * (n - 1) * (n - 2) * ... * 1
0! = 1

C11 Program with Overflow Detection

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int n;
    unsigned long long factorial = 1;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &n) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    for (unsigned int i = 1; i <= n; i++)
    {
        if (factorial > ULLONG_MAX / i)
        {
            printf("Factorial exceeds unsigned long long range.\n");
            return 1;
        }

        factorial *= i;
    }

    printf("Factorial = %llu\n", factorial);

    return 0;
}

Expected Result

Enter a non-negative integer: 5 Factorial = 120

Important Interview Facts

  • 0! = 1.
  • Factorial grows very quickly.
  • For a typical 64-bit unsigned long long, 20! fits, but 21! does not.
  • Iterative factorial uses O(n) time and O(1) auxiliary space.

8. Fibonacci Series

Definition

In the Fibonacci sequence, each term after the first two is the sum of the previous two terms.

0, 1, 1, 2, 3, 5, 8, 13, 21, ...

C11 Program

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int terms;
    unsigned long long first = 0;
    unsigned long long second = 1;

    printf("Enter number of terms: ");

    if (scanf("%u", &terms) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    for (unsigned int i = 0; i < terms; i++)
    {
        printf("%llu ", first);

        if (i + 1 < terms)
        {
            if (ULLONG_MAX - first < second)
            {
                printf("\nNext Fibonacci term exceeds the data type range.\n");
                return 1;
            }

            unsigned long long next = first + second;
            first = second;
            second = next;
        }
    }

    printf("\n");
    return 0;
}

Expected Result

Enter number of terms: 8 0 1 1 2 3 5 8 13

Complexity: O(n) time and O(1) auxiliary space.

9. Prime Number Check

Definition

A prime number is a positive integer greater than 1 that has exactly two positive divisors: 1 and itself.

Examples: 2, 3, 5, 7, 11, 13.

Optimized Logic

To determine whether n is prime, it is sufficient to test possible divisors up to the square root of n. If a factor larger than the square root exists, its corresponding factor must be smaller than the square root.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int n;
    int is_prime = 1;

    printf("Enter a positive integer: ");

    if (scanf("%u", &n) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (n < 2)
    {
        is_prime = 0;
    }
    else
    {
        for (unsigned int i = 2; i <= n / i; i++)
        {
            if (n % i == 0)
            {
                is_prime = 0;
                break;
            }
        }
    }

    if (is_prime)
        printf("%u is prime.\n", n);
    else
        printf("%u is not prime.\n", n);

    return 0;
}

Expected Result

Enter a positive integer: 29 29 is prime.

Complexity: O(√n) time and O(1) auxiliary space.

The condition i <= n / i avoids the potential overflow of i * i in the loop condition.

10. Print Prime Numbers in a Range

Problem

Display all prime numbers between two given non-negative integers.

C11 Program

#include <stdio.h>

int is_prime(unsigned int n)
{
    if (n < 2)
        return 0;

    for (unsigned int i = 2; i <= n / i; i++)
    {
        if (n % i == 0)
            return 0;
    }

    return 1;
}

int main(void)
{
    unsigned int start, end;

    printf("Enter starting and ending values: ");

    if (scanf("%u %u", &start, &end) != 2)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (start > end)
    {
        printf("Invalid range.\n");
        return 1;
    }

    printf("Prime numbers: ");

    for (unsigned int n = start; ; n++)
    {
        if (is_prime(n))
            printf("%u ", n);

        if (n == end)
            break;
    }

    printf("\n");
    return 0;
}

Expected Result

Enter starting and ending values: 10 30 Prime numbers: 11 13 17 19 23 29

Complexity: For each candidate number, primality testing takes O(√n) time. The total work depends on the range.

11. Armstrong Number

Definition

An Armstrong number is a non-negative integer equal to the sum of its digits, each raised to the power of the total number of digits.

Example: 153 has three digits.

1³ + 5³ + 3³
= 1 + 125 + 27
= 153

C11 Program

#include <stdio.h>

unsigned int count_digits(unsigned int n)
{
    unsigned int count = 0;

    do
    {
        count++;
        n /= 10;
    } while (n > 0);

    return count;
}

unsigned long long integer_power(unsigned int base,
                                 unsigned int exponent)
{
    unsigned long long result = 1;

    for (unsigned int i = 0; i < exponent; i++)
        result *= base;

    return result;
}

int main(void)
{
    unsigned int number;
    unsigned int temp;
    unsigned int digits;
    unsigned long long sum = 0;

    printf("Enter a non-negative integer: ");

    if (scanf("%u", &number) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    digits = count_digits(number);
    temp = number;

    do
    {
        unsigned int digit = temp % 10;
        unsigned long long term = integer_power(digit, digits);

        if (ULLONG_MAX - sum < term)
        {
            printf("Calculation exceeds supported range.\n");
            return 1;
        }

        sum += term;
        temp /= 10;

    } while (temp > 0);

    if (sum == number)
        printf("%u is an Armstrong number.\n", number);
    else
        printf("%u is not an Armstrong number.\n", number);

    return 0;
}
Add #include <limits.h> at the beginning of this program for ULLONG_MAX. For extremely large input values, the digit-power calculation itself also needs overflow checking; the program is intended for ordinary placement-sized inputs.

Expected Result

Enter a non-negative integer: 153 153 is an Armstrong number.

12. Perfect Number

Definition

A perfect number is a positive integer equal to the sum of its positive proper divisors, excluding itself.

Example:

6 = 1 + 2 + 3

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int n;
    unsigned long long sum = 0;

    printf("Enter a positive integer: ");

    if (scanf("%u", &n) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    for (unsigned int i = 1; i <= n / 2; i++)
    {
        if (n % i == 0)
            sum += i;
    }

    if (n > 0 && sum == n)
        printf("%u is a perfect number.\n", n);
    else
        printf("%u is not a perfect number.\n", n);

    return 0;
}

Expected Result

Enter a positive integer: 28 28 is a perfect number.

Complexity: O(n) time and O(1) auxiliary space.

A more advanced solution can enumerate divisor pairs up to √n, reducing the number of iterations to O(√n).

13. GCD Using Euclidean Algorithm

Definition

The Greatest Common Divisor (GCD) is the largest positive integer that divides two integers without leaving a remainder.

Example: GCD(48, 18) = 6.

Euclidean Algorithm

Repeatedly replace the pair (a, b) with (b, a % b) until b becomes zero.

while (b != 0)
{
    remainder = a % b;
    a = b;
    b = remainder;
}

C11 Program

#include <stdio.h>

unsigned int gcd(unsigned int a, unsigned int b)
{
    while (b != 0)
    {
        unsigned int remainder = a % b;
        a = b;
        b = remainder;
    }

    return a;
}

int main(void)
{
    unsigned int a, b;

    printf("Enter two non-negative integers: ");

    if (scanf("%u %u", &a, &b) != 2)
    {
        printf("Invalid input.\n");
        return 1;
    }

    printf("GCD = %u\n", gcd(a, b));

    return 0;
}

Expected Result

Enter two non-negative integers: 48 18 GCD = 6

Complexity: O(log(min(a,b))) time in the general case, with O(1) auxiliary space.

By convention, gcd(a, 0) = a for non-negative a. This implementation also returns zero for gcd(0, 0).

14. LCM of Two Numbers

Definition

The Least Common Multiple (LCM) is the smallest positive integer that is divisible by both input numbers.

Relationship between GCD and LCM:

LCM(a, b) = (a / GCD(a, b)) * b

C11 Program

#include <stdio.h>
#include <limits.h>

unsigned int gcd(unsigned int a, unsigned int b)
{
    while (b != 0)
    {
        unsigned int remainder = a % b;
        a = b;
        b = remainder;
    }

    return a;
}

int main(void)
{
    unsigned int a, b;
    unsigned int divisor;
    unsigned long long lcm;

    printf("Enter two non-negative integers: ");

    if (scanf("%u %u", &a, &b) != 2)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (a == 0 || b == 0)
    {
        printf("LCM = 0\n");
        return 0;
    }

    divisor = gcd(a, b);
    lcm = (unsigned long long)(a / divisor) * b;

    printf("LCM = %llu\n", lcm);

    return 0;
}

Expected Result

Enter two non-negative integers: 12 18 LCM = 36

Complexity: O(log(min(a,b))) time for the GCD calculation and O(1) auxiliary space.

15. Check Whether a Number Is a Power of Two

Problem

Determine whether a positive unsigned integer is a power of two.

Examples: 1, 2, 4, 8, 16, 32 are powers of two.

Bitwise Technique

A positive power of two contains exactly one set bit in its binary representation.

(n & (n - 1)) == 0

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int n;

    printf("Enter a positive integer: ");

    if (scanf("%u", &n) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (n != 0 && (n & (n - 1)) == 0)
        printf("%u is a power of two.\n", n);
    else
        printf("%u is not a power of two.\n", n);

    return 0;
}

Expected Result

Enter a positive integer: 64 64 is a power of two.

Complexity: O(1) time and O(1) auxiliary space.

This bitwise technique is frequently asked in C, embedded systems and low-level programming interviews.

16. Swap Two Numbers Without a Third Variable

Problem

Swap two unsigned integers using XOR operations.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int a, b;

    printf("Enter two integers: ");

    if (scanf("%u %u", &a, &b) != 2)
    {
        printf("Invalid input.\n");
        return 1;
    }

    a = a ^ b;
    b = a ^ b;
    a = a ^ b;

    printf("After swapping:\n");
    printf("a = %u\n", a);
    printf("b = %u\n", b);

    return 0;
}

Expected Result

Enter two integers: 10 20 After swapping: a = 20 b = 10
XOR swapping is mainly an interview exercise. In production code, a temporary variable is usually clearer and safer. XOR swapping also fails when both operands refer to the same storage location.

17. Common Placement Interview Questions

Q1. Why is 1 not a prime number?

Because a prime number must have exactly two distinct positive divisors. The number 1 has only one positive divisor.

Q2. What is the difference between GCD and LCM?

GCD is the greatest common divisor of two numbers. LCM is the smallest positive common multiple when both inputs are positive.

Q3. Why is the Euclidean algorithm efficient?

It reduces the problem size after every remainder operation and has logarithmic time complexity.

Q4. Why should factorial programs check overflow?

Factorial grows rapidly and can exceed the maximum value supported by the selected integer data type.

Q5. What is the difference between a palindrome and an Armstrong number?

A palindrome reads identically in both directions. An Armstrong number equals the sum of each digit raised to the total number of digits.

Q6. Why is checking divisors only up to √n sufficient for prime testing?

If n = a × b, at least one of the two factors must be less than or equal to √n.

Q7. What is the complexity of reversing a number?

O(d), where d is the number of decimal digits.

Q8. Can unsigned integer arithmetic overflow?

Yes. Unsigned integer arithmetic wraps modulo one more than the maximum representable value. This is defined behavior in C, but it may still produce an incorrect result for an application.

20. Lecture Summary

  • Digit extraction uses remainder and integer division.
  • Number reversal builds a new number digit by digit.
  • Palindrome numbers remain identical after reversal.
  • Factorial and Fibonacci are common mathematical problems.
  • Prime checking can be optimized to O(√n).
  • Armstrong and perfect numbers use digit or divisor properties.
  • Euclidean algorithm efficiently calculates GCD.
  • LCM can be calculated using GCD.
  • Bitwise operations provide compact solutions to certain problems.
  • Overflow and boundary conditions are important in reliable C programs.
