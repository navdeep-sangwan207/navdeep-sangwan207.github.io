2. C Language Fundamentals

Q1. What is C programming language?

Answer: C is a general-purpose, procedural, compiled programming language. It provides low-level memory access through pointers while also supporting structured programming through functions, loops and control statements.

Applications:

  • Embedded systems and microcontrollers.
  • Operating systems and kernels.
  • Device drivers.
  • Compilers and interpreters.
  • Networking and system utilities.
  • Real-time and performance-critical software.

Q2. What are the main features of C?

  • Procedural and structured programming.
  • Portable source code when written according to the standard and supported by implementations.
  • Efficient compiled execution.
  • Pointers and direct memory access capabilities.
  • Dynamic memory allocation.
  • Rich operators and standard library functions.
  • Modular development using functions and multiple source files.

Q3. Is C a low-level or high-level language?

Answer: C is commonly described as a middle-level language because it combines high-level programming constructs with low-level facilities such as pointers and bitwise operations. This is a descriptive classification, not a formal C language category.

Q4. What is the difference between a compiler and an interpreter?

CompilerInterpreter
Translates source code into another form, commonly machine code or object code.Executes program instructions through an interpreter runtime.
Compilation commonly happens before execution.Execution commonly involves interpreting instructions at runtime.
C is normally compiled.Some scripting languages commonly use interpreters or virtual machines.

Q5. What are the stages of C program compilation?

  1. Preprocessing: Expands macros and processes include directives.
  2. Compilation: Translates the preprocessed source into assembly or an equivalent intermediate representation.
  3. Assembly: Produces object code.
  4. Linking: Combines object files and required libraries to create an executable or another linkable output.
gcc -std=c11 -E program.c -o program.i
gcc -std=c11 -S program.c -o program.s
gcc -std=c11 -c program.c -o program.o
gcc program.o -o program

Q6. What is the difference between a header file and a source file?

A source file, usually ending in .c, contains function definitions and other implementation code. A header file, usually ending in .h, commonly contains declarations, type definitions, macros and interface information shared between source files.

Q7. What is the difference between declaration and definition?

A declaration introduces an identifier and describes its properties. A definition provides the entity itself, such as allocating storage for an object or providing a function body.

extern int count;     /* Declaration */
int count = 10;       /* Definition */

int add(int, int);    /* Function declaration */

int add(int a, int b) /* Function definition */
{
    return a + b;
}

3. Data Types, Variables and Operators

Q8. What are the basic data types in C?

The fundamental arithmetic types include:

  • char
  • short int
  • int
  • long int
  • long long int
  • float
  • double
  • long double
  • _Bool

C also provides derived types such as arrays, pointers, structures, unions and function types. Enumerations are another important type category.

Q9. What is the difference between signed and unsigned integers?

Signed integer types represent negative, zero and positive values. Unsigned integer types represent zero and positive values, using the available bits for nonnegative values.

#include <stdio.h>

int main(void)
{
    signed int a = -10;
    unsigned int b = 10U;

    printf("%d\n", a);
    printf("%u\n", b);

    return 0;
}

Q10. What is sizeof?

sizeof is an operator that returns the size in bytes of a type or object. Its result type is size_t.

#include <stdio.h>

int main(void)
{
    int a = 10;

    printf("%zu\n", sizeof(a));
    printf("%zu\n", sizeof(double));

    return 0;
}

Exact sizes depend on the implementation. Use %zu to print a size_t value.

Q11. What is the difference between implicit and explicit type conversion?

  • Implicit conversion: Performed automatically according to C conversion rules.
  • Explicit conversion: Requested by the programmer using a cast.
int a = 10;
double x = a;          /* Implicit conversion */

double y = (double)a / 3; /* Explicit conversion */

Q12. What is the difference between = and ==?

  • = assigns a value to an object.
  • == compares two operands for equality.

Q13. What is the difference between logical and bitwise operators?

Logical operatorsBitwise operators
&&, ||, !&, |, ^, ~
Operate on logical truth values.Operate on individual bits of integer operands.
&& and || use short-circuit evaluation.Bitwise operators do not use logical short-circuit evaluation.

Q14. What is the difference between pre-increment and post-increment?

  • ++i increments the object and produces its new value.
  • i++ produces the old value and then increments the object.
#include <stdio.h>

int main(void)
{
    int i = 5;

    printf("%d\n", ++i);

    i = 5;
    printf("%d\n", i++);

    printf("%d\n", i);

    return 0;
}

4. Control Statements, Loops and Functions

Q15. What is the difference between while and do-while?

Q16. What is the difference between break and continue?

  • break terminates the nearest enclosing loop or switch statement.
  • continue skips the remaining statements in the current loop iteration and proceeds to the next iteration.

Q17. What is recursion?

Recursion occurs when a function calls itself directly or indirectly. A recursive function requires a base case to terminate the recursive process.

#include <stdio.h>

int factorial(int n)
{
    if (n <= 1)
        return 1;

    return n * factorial(n - 1);
}

int main(void)
{
    printf("%d\n", factorial(5));
    return 0;
}
120

Q18. Does C support call by reference?

C uses pass-by-value. A function can modify an object in the caller by receiving its address through a pointer. This is commonly called passing by address, but it is not a separate call-by-reference mechanism in the C language.

#include <stdio.h>

void update(int *p)
{
    *p = 100;
}

int main(void)
{
    int x = 10;

    update(&x);

    printf("%d\n", x);
    return 0;
}
100

Q19. What is the difference between local and global variables?

Q20. What is a static variable?

A static-storage-duration object exists for the entire execution of the program. A local variable declared with static retains its value between function calls. A file-scope object declared static has internal linkage.

5. Arrays and Strings

Q21. What is an array?

An array is a contiguous sequence of elements of the same type. Its elements are accessed using indices starting from zero.

Q22. What is the difference between an array and a pointer?

ArrayPointer
An array is an object containing a sequence of elements.A pointer is an object that stores a pointer value.
Its size is the total size of its elements.Its size is the size of the pointer object.
An array expression usually converts to a pointer to its first element.A pointer can be reassigned to point elsewhere.
Cannot be assigned as a whole array using ordinary assignment.Can be assigned another compatible pointer value.

Q23. What is a string in C?

A C string is a sequence of characters terminated by a null character, '\0'. C does not have a separate built-in string data type.

Q24. What is the difference between strlen and sizeof?

  • strlen() counts characters before the terminating null character.
  • sizeof returns the size in bytes of the operand's type or object.

Q25. What is the difference between strcpy and strncpy?

strcpy() copies a string including its terminating null character, assuming the destination is large enough. strncpy() copies up to a specified number of characters, but may not null-terminate the destination if the source length is at least the specified limit.

Neither function automatically knows the destination capacity. Always ensure the destination buffer is large enough and explicitly guarantee null termination where required.

6. Pointers and Memory

Q26. What is a pointer?

A pointer is an object whose value refers to another object or function, or represents a null pointer. Pointers are used for indirect access, arrays, dynamic memory and function callbacks.

Q27. What is a NULL pointer?

A null pointer is a pointer value that is guaranteed not to compare equal to a pointer to any object or function. It can be written using the NULL macro or initialized with zero in a pointer context.

Q28. What is a void pointer?

A void * is a generic object pointer. It can hold a pointer to any object type. Before dereferencing it, convert it to an appropriate object pointer type. Standard C does not permit arithmetic directly on a void *.

Q29. What is a wild pointer?

A wild pointer is an informal term for an uninitialized pointer. Its value is indeterminate, and using it can cause undefined behavior.

Q30. What is a dangling pointer?

A dangling pointer refers to an object whose lifetime has ended or memory that is no longer valid. Dereferencing it is invalid.

Q31. What is a double pointer?

A double pointer is a pointer to another pointer. It is commonly used to modify a pointer in a function, work with arrays of strings and construct dynamic data structures.

#include <stdio.h>

int main(void)
{
    int x = 50;
    int *p = &x;
    int **pp = &p;

    printf("%d\n", **pp);

    return 0;
}
50

Q32. What is a function pointer?

A function pointer stores a pointer to a function with a compatible type. It supports callbacks, dispatch tables and configurable behavior.

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*operation)(int, int) = add;

    printf("%d\n", operation(10, 20));

    return 0;
}
30

Q33. What is the difference between pointer arithmetic and normal arithmetic?

Adding an integer to a pointer advances it by that many elements of the pointed-to type. Normal integer arithmetic operates on numeric values. Pointer arithmetic is only valid within the same array object or one position past its end, subject to the C rules.

7. Dynamic Memory Allocation

Q34. What is dynamic memory allocation?

Dynamic memory allocation requests storage during program execution. The standard C allocation functions are declared in <stdlib.h>.

Q35. Explain malloc and calloc.

malloc()calloc()
Allocates a specified number of bytes.Allocates space for a specified number of elements.
Allocated storage has indeterminate contents.All bits in the allocated storage are initialized to zero.
Returns a pointer to allocated storage or NULL on failure.Returns a pointer to allocated storage or NULL on failure.

Q36. Explain realloc.

realloc() changes the size of an allocated memory block. The block may be moved to a new location. On failure, the original allocation remains valid when a nonzero size is requested.

Q37. What is the purpose of free?

free() releases dynamically allocated storage. After freeing a block, do not access it through pointers to that allocation.

Q38. What is a memory leak?

A memory leak occurs when dynamically allocated memory is no longer reachable or its ownership is lost without releasing it. Repeated leaks can cause increasing memory consumption.

Q39. What is the difference between stack and heap?

StackHeap
Commonly used for function call frames and automatic objects.Commonly used for dynamically allocated storage.
Lifetime is generally managed by scope and function execution.Lifetime is managed through allocation and deallocation.
Usually managed automatically by the implementation.Managed explicitly through allocation functions in C.

These are common implementation concepts; the C standard does not mandate a particular physical stack and heap layout.

8. Structures, Unions and Enumerations

Q40. What is a structure?

A structure is a user-defined type that groups multiple named members, which can have different types.

Q41. What is the difference between a structure and a union?

StructureUnion
Each member has its own storage within the structure.Members share overlapping storage.
Members can hold values simultaneously.Typically one member's stored value is used at a time.
Size includes member storage and possible padding.Size is sufficient for its largest member, including alignment requirements.

Q42. What is structure padding?

Structure padding is extra storage inserted by an implementation to satisfy alignment requirements. It can affect structure size and member offsets.

Q43. What is a self-referential structure?

A self-referential structure contains a pointer to another object of the same structure type. It is commonly used in linked lists, trees and graphs.

struct Node
{
    int data;
    struct Node *next;
};

Q44. What is an enum?

An enumeration defines named integer constants. It improves readability when a variable represents a limited set of named states.

enum State
{
    OFF,
    ON,
    ERROR
};

9. Storage Classes, Scope and Linkage

Q45. What are storage classes in C?

Storage-class specifiers affect properties such as storage duration, linkage and type qualification. Commonly discussed specifiers include:

  • auto
  • register
  • static
  • extern
  • typedef (a storage-class specifier in C syntax, but it does not allocate storage)
  • _Thread_local (introduced in C11)

Q46. What is the difference between static and extern?

  • At file scope, static gives an identifier internal linkage.
  • extern is commonly used to declare an object or function defined elsewhere, with external linkage where applicable.
  • For local variables, static gives static storage duration.

Q47. What is the difference between scope, lifetime and linkage?

10. File Handling

Q48. What is a FILE pointer?

FILE * is a pointer to a stream object used by the C standard I/O library. It is used with functions such as fopen(), fclose(), fprintf() and fscanf().

Q49. What are the common file opening modes?

ModePurpose
"r"Open an existing file for reading.
"w"Open for writing; create or truncate the file.
"a"Open for appending; create if necessary.
"r+"Open an existing file for reading and writing.
"w+"Open for reading and writing; create or truncate.
"a+"Open for reading and appending; create if necessary.
"rb"Open a file for binary reading.
"wb"Open a file for binary writing.

Q50. What is EOF?

EOF is a negative integer constant used to indicate an end-of-file condition or certain input failures. Functions such as fgetc() return an int so that all unsigned character values and EOF can be represented.

Q51. Why should we not use while(!feof(file))?

The end-of-file indicator is set only after an input operation attempts to read beyond the available data. Instead, test the return value of the input function.

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    int ch;

    while ((ch = fgetc(fp)) != EOF)
    {
        putchar(ch);
    }

    if (ferror(fp))
        printf("Read error\n");

    fclose(fp);
    return 0;
}

11. Advanced C and Language Behavior

Q52. What is undefined behavior?

Undefined behavior occurs when the C standard imposes no requirements on the behavior of a program. Examples include signed integer overflow, out-of-bounds array access and dereferencing an invalid pointer.

Q53. What is the difference between undefined, unspecified and implementation-defined behavior?

TermExplanation
UndefinedNo requirements are imposed by the standard.
UnspecifiedOne of multiple permitted possibilities is chosen; documentation is not required.
Implementation-definedThe implementation chooses and documents the behavior.

Q54. What is the volatile keyword?

volatile tells the implementation that accesses to an object may have observable effects beyond ordinary program flow. It is useful for certain memory-mapped hardware registers and objects modified by external mechanisms.

volatile does not make operations atomic, does not provide general thread synchronization and does not replace mutexes or C11 atomic operations.

Q55. What is the const keyword?

const qualifies a type so that an object cannot be modified through an ordinary lvalue expression using that qualified type.

const int value = 10;

/* value = 20;  Invalid modification */

Q56. What is the restrict keyword?

restrict is a C99 type qualifier used to express a particular non-aliasing promise for accesses to an object through a pointer during a block execution. It can help the compiler optimize code, but violating the restrict-based requirements can cause undefined behavior.

Q57. What is a macro?

A macro is a preprocessor replacement rule defined using #define. Macros can represent constants or function-like substitutions.

#define PI 3.14159
#define SQUARE(x) ((x) * (x))

Parentheses help avoid common precedence problems in function-like macros. Macro arguments with side effects can still be evaluated multiple times, so use care.

Q58. What is the difference between a macro and a function?

MacroFunction
Expanded by the preprocessor.Called through normal language function semantics.
Does not provide ordinary function type checking of arguments.Function prototype provides type checking.
Can evaluate an argument multiple times depending on its replacement text.Each argument expression is evaluated once as part of the call.
Can increase generated code size.May involve call overhead, though optimization can inline functions.

Q59. What is the difference between a library function and a user-defined function?

A library function is provided by a library, such as printf(), malloc() or strlen(). A user-defined function is written by the programmer to implement application-specific behavior.

12. Practical Coding and Debugging Questions

Q60. How do you swap two numbers without a temporary variable?

One method uses arithmetic, but it risks signed overflow. Another uses XOR for suitable integer values, but it needs care when both operands refer to the same object. In production code, a temporary variable is generally clearer and safer.

Q61. How do you find the size of an array?

int arr[] = {10, 20, 30, 40};

size_t count = sizeof(arr) / sizeof(arr[0]);

This works only where arr is an actual array, not after it has been converted to a pointer or adjusted as a function parameter.

Q62. How do you reverse a string?

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";
    size_t len = strlen(str);

    for (size_t i = 0; i < len / 2; i++)
    {
        char temp = str[i];
        str[i] = str[len - 1 - i];
        str[len - 1 - i] = temp;
    }

    printf("%s\n", str);
    return 0;
}
OLLEH

Q63. How do you detect a memory allocation failure?

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t count = 10;
    int *ptr = malloc(count * sizeof(*ptr));

    if (ptr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    free(ptr);
    ptr = NULL;

    return 0;
}

Q64. How do you avoid buffer overflow?

  • Track buffer capacity explicitly.
  • Validate input lengths before copying.
  • Prefer bounded input functions such as fgets().
  • Check array indices and pointer arithmetic.
  • Use compiler warnings and sanitizers during development.

13. Embedded C and Systems Programming Interview Questions

Q65. What is Embedded C?

Embedded C refers to C programming used to develop firmware for embedded systems. It uses the C language along with processor-specific headers, compiler extensions, hardware register definitions and development tools.

Q66. What is a memory-mapped register?

A memory-mapped register is a hardware control or status register accessed through a particular address in the processor's address space. Firmware commonly accesses such registers through appropriately qualified pointers or device-header definitions.

Q67. Why is volatile used for hardware registers?

Hardware registers can change independently of the normal program flow. volatile helps ensure that the compiler does not treat accesses as ordinary removable or reusable memory operations when the qualified object is accessed.

Q68. What is an interrupt?

An interrupt is an event that causes the processor to suspend its current execution flow and transfer control to an interrupt handler or associated exception mechanism, according to the processor architecture.

Q69. What is an ISR?

An Interrupt Service Routine is a function or handler executed in response to an interrupt. ISR requirements depend on the processor, compiler and real-time operating system.

Q70. What is the difference between polling and interrupts?

PollingInterrupts
Processor repeatedly checks a status condition.Hardware or another event signals the processor.
Can waste processor time while waiting.Can allow the processor to perform other work while waiting.
Often simpler to implement.Requires careful interrupt configuration and handler design.

Q71. What is the difference between UART, SPI and I2C?

InterfaceTypical characteristics
UARTAsynchronous serial communication using transmit and receive signals.
SPISynchronous serial communication commonly using clock, data and chip-select signals.
I2CSynchronous two-wire bus using SDA and SCL, with device addressing.

Q72. What is a watchdog timer?

A watchdog timer is a hardware or software-supported timer used to detect situations where a system stops making expected progress. If firmware fails to service the watchdog within the configured interval, the system may reset or take another configured recovery action.

Embedded interview focus: Be prepared to explain pointers, bit manipulation, volatile, register access, interrupt handling, memory constraints, UART, SPI, I2C and debugging on the target platform.

15. Technical Interview Answering Strategy

Use a structured approach when explaining technical concepts:

  1. Definition: State what the concept means.
  2. Mechanism: Explain how it works.
  3. Example: Give a short C code example or practical use case.
  4. Limitation: Mention an important constraint or common mistake.

Example: How to explain a pointer

Interview-ready answer:

A pointer is a variable that stores a pointer value referring to another object or function. It allows indirect access to data and is commonly used for arrays, dynamic memory allocation and passing addresses to functions. For example, an integer pointer can store the address of an integer variable, and dereferencing the pointer accesses that variable. A pointer must be initialized appropriately and must only be dereferenced when it points to a valid object.
