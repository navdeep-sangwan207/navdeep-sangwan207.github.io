Chapter 10: Storage Classes and Linkage

Understand variable scope, lifetime, storage duration, linkage and how C programs share variables and functions across multiple source files.

Chapter Overview

Storage classes and linkage determine how identifiers behave in a C program. They help explain where variables can be accessed, how long objects exist and whether identifiers can be shared between different source files.

These concepts are important when developing modular applications, embedded firmware, device drivers and larger C projects.

C11 Standard Placement Preparation Memory Concepts Multi-file Programming

Learning Outcomes

  • Differentiate scope, lifetime and storage duration.
  • Understand automatic and static storage duration.
  • Use auto and register storage-class specifiers correctly.
  • Understand static local and file-scope variables.
  • Use extern declarations to access external objects.
  • Differentiate internal and external linkage.
  • Organize C programs using header and source files.
  • Identify common linkage and multiple-definition errors.

Recommended Practice

Create a small C project containing main.c, calculator.c and calculator.h. Define functions in the source file, declare their interfaces in the header and compile the project as separate translation units. 

gcc -std=c11 -Wall -Wextra -Wpedantic \
    main.c calculator.c -o application

Also practice identifying the difference between a file-scope static variable, a static local variable and an externally linked global variable.
