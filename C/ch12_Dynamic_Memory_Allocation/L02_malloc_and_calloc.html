Lecture 02: malloc() and calloc()

Learn how to allocate memory dynamically, calculate allocation sizes, initialize allocated storage and handle allocation failures safely in C.

1. Learning Objectives

  • Understand dynamic memory allocation in C.
  • Learn the syntax and working of malloc().
  • Learn the syntax and working of calloc().
  • Understand the difference between malloc() and calloc().
  • Calculate memory requirements using sizeof.
  • Allocate memory for individual variables and arrays.
  • Check allocation failures using NULL.
  • Understand common allocation mistakes.
  • Solve placement-oriented coding problems.

2. What Is Dynamic Memory Allocation?

Dynamic memory allocation is the process of requesting memory during program execution rather than determining all storage requirements in advance.

C provides four main standard allocation and deallocation functions:

Function Purpose
malloc() Allocates a specified number of bytes.
calloc() Allocates space for an array of objects and initializes all allocated bytes to zero.
realloc() Changes the size of an existing allocated block.
free() Releases dynamically allocated storage.

These functions are declared in the standard header file: 

#include <stdlib.h>

3. malloc() Function

malloc() stands for memory allocation. It requests a block of memory containing the specified number of bytes.

Syntax

void *malloc(size_t size);

Example:

int *ptr = malloc(sizeof(int));

Explanation

  • malloc() receives the required size in bytes.
  • It returns a pointer to the allocated storage if successful.
  • It returns NULL if allocation fails.
  • The allocated bytes have indeterminate values.
  • The allocated storage must eventually be released when no longer needed.
In C, conversion from void * to another object pointer type is automatic. Therefore, an explicit cast of malloc() is not required.

4. Example: Allocate Memory for One Integer

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr;

    ptr = malloc(sizeof(int));

    if (ptr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d\n", *ptr);

    free(ptr);

    return 0;
}
Output: 
Value = 100

Program Explanation

  1. A pointer to int is declared.
  2. malloc() requests enough storage for one int.
  3. The returned pointer is checked against NULL.
  4. The allocated object is assigned the value 100.
  5. The value is displayed using the dereference operator.
  6. free() releases the allocated storage.

5. Understanding sizeof with malloc()

The sizeof operator determines the size of an object or type in bytes. 

int *ptr = malloc(sizeof(int));

This requests enough bytes for one int.

A commonly preferred form is: 

int *ptr = malloc(sizeof *ptr);

This form automatically uses the type pointed to by ptr.

Example with Different Data Types

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *iptr;
    float *fptr;
    double *dptr;

    iptr = malloc(sizeof *iptr);
    fptr = malloc(sizeof *fptr);
    dptr = malloc(sizeof *dptr);

    if (iptr == NULL || fptr == NULL || dptr == NULL)
    {
        printf("Allocation failed\n");

        free(iptr);
        free(fptr);
        free(dptr);

        return 1;
    }

    *iptr = 10;
    *fptr = 12.5f;
    *dptr = 45.75;

    printf("Integer = %d\n", *iptr);
    printf("Float = %.2f\n", *fptr);
    printf("Double = %.2f\n", *dptr);

    free(iptr);
    free(fptr);
    free(dptr);

    return 0;
}
Output: 
Integer = 10
Float = 12.50
Double = 45.75
sizeof returns a value of type size_t. Use size_t for object sizes and array element counts rather than assuming that every size fits in int.

6. malloc() for Dynamic Arrays

malloc() can allocate storage for multiple objects of the same type.

Syntax

pointer = malloc(number_of_elements * sizeof *pointer);

Example: Dynamic Integer Array

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n;
    size_t i;
    int *arr;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid array size\n");
        return 1;
    }

    if (n > (size_t)-1 / sizeof *arr)
    {
        printf("Requested size is too large\n");
        return 1;
    }

    arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (i = 0; i < n; i++)
    {
        arr[i] = (int)(i + 1) * 10;
    }

    printf("Array elements:\n");

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}
Sample Input: 
5
Output: 
Array elements:
10 20 30 40 50

The expression n * sizeof *arr calculates the total number of bytes required.

The overflow check prevents the multiplication from wrapping around size_t before allocation.

7. calloc() Function

calloc() stands for contiguous allocation. It allocates storage for an array of objects and initializes every byte in the allocated storage to zero.

Syntax

void *calloc(size_t num, size_t size);

The two arguments are:

  • num: Number of elements.
  • size: Size of each element in bytes.

Example

int *ptr = calloc(5, sizeof *ptr);

This requests storage for five int objects. Every byte in the allocated storage is initialized to zero.

calloc() performs byte-wise zero initialization. Do not assume that an all-bits-zero representation necessarily represents every possible C type's semantic zero value, such as every null pointer or floating-point zero representation.

8. Example: calloc() for an Integer Array

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n = 5;
    size_t i;

    int *arr = calloc(n, sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    printf("Initial array values:\n");

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}
Output on a conventional system: 
0 0 0 0 0

For this int array, the all-bits-zero representation corresponds to integer zero.

9. malloc() vs calloc()

malloc() calloc()
Takes one argument. Takes two arguments.
Specifies total allocation size in bytes. Specifies element count and size of each element.
Allocated bytes have indeterminate values. All allocated bytes are initialized to zero.
Useful when existing initialization is unnecessary. Useful when byte-wise zero initialization is desired.
malloc(n * sizeof *ptr) calloc(n, sizeof *ptr)
Do not claim that calloc() is always slower or malloc() is always faster. Performance depends on the allocator and system.

10. Practical Comparison Program

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *a;
    int *b;
    size_t n = 5;
    size_t i;

    a = malloc(n * sizeof *a);
    b = calloc(n, sizeof *b);

    if (a == NULL || b == NULL)
    {
        printf("Allocation failed\n");

        free(a);
        free(b);

        return 1;
    }

    for (i = 0; i < n; i++)
    {
        a[i] = (int)(i + 1) * 10;
    }

    printf("malloc array after assignment:\n");

    for (i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    printf("\ncalloc array:\n");

    for (i = 0; i < n; i++)
    {
        printf("%d ", b[i]);
    }

    printf("\n");

    free(a);
    free(b);

    return 0;
}
Output: 
malloc array after assignment:
10 20 30 40 50

calloc array:
0 0 0 0 0

The malloc() array is assigned values before reading. The calloc() array has zero-initialized bytes.

11. Handling Allocation Failure

Memory allocation is not guaranteed to succeed. Every allocation result must be checked before accessing the allocated storage.

Correct Pattern

int *ptr = malloc(10 * sizeof *ptr);

if (ptr == NULL)
{
    printf("Allocation failed\n");
    return 1;
}

/* Use allocated storage */

free(ptr);

Common Mistake

int *ptr = malloc(10 * sizeof *ptr);

*ptr = 100;

If malloc() returns NULL, dereferencing ptr does not access a valid allocated object.

12. Understanding Pointer Size vs Allocated Size

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr = malloc(10 * sizeof *ptr);

    if (ptr == NULL)
    {
        return 1;
    }

    printf("Pointer size = %zu bytes\n", sizeof ptr);
    printf("Element size = %zu bytes\n", sizeof *ptr);

    free(ptr);

    return 0;
}

The value of sizeof ptr is the size of the pointer object. The value of sizeof *ptr is the size of one pointed-to int object.

sizeof ptr does not report the total number of bytes allocated by malloc(). Keep track of the allocated element count separately.

13. Common Mistakes in malloc() and calloc()

Mistake Correct Approach
Not checking the returned pointer. Check whether it is NULL.
Using sizeof(pointer) for array allocation. Use number of elements multiplied by sizeof *pointer.
Reading malloc() memory before initialization. Initialize allocated objects before reading them.
Forgetting to include stdlib.h. Include the required standard header.
Writing beyond allocated array bounds. Use valid indices from zero through n - 1.
Forgetting to release storage. Call free() when the allocation is no longer needed.
Multiplication overflow in allocation size. Validate the requested count before multiplying.

14. Embedded Systems and Placement Relevance

Dynamic allocation is especially important to understand in embedded systems because many embedded devices operate with limited RAM.

Important Considerations

  • Available RAM may be very limited.
  • Allocation failure must be handled safely.
  • Repeated allocation and deallocation can contribute to heap fragmentation.
  • Unpredictable allocation latency may be unsuitable for some real-time paths.
  • Some embedded projects prefer static allocation for deterministic memory usage.
  • Interrupt service routines should generally avoid dynamic allocation unless the platform explicitly supports and permits it.
In RTOS-based systems, tasks may have separate stacks. Interrupt stacks and task stacks depend on the processor, RTOS and port configuration. Stack sizing is an important embedded design and debugging activity.

Typical Embedded Interview Question

Why might an embedded developer avoid frequent malloc() and free() calls?

Because dynamic allocation can introduce allocation failure, fragmentation and variable execution time. In systems with strict real-time requirements, these characteristics can make memory behavior harder to predict.

15. Placement-Oriented Interview Questions

Q1. What is malloc()?

malloc() is a standard C library function that requests a specified number of bytes of allocated storage.

Q2. What is calloc()?

calloc() requests storage for a specified number of elements and initializes all allocated bytes to zero.

Q3. What does malloc() return?

It returns a void pointer to the allocated storage or NULL if the allocation fails.

Q4. Why is malloc() not cast in C?

C automatically converts void pointers to other object pointer types.

Q5. What is the difference between malloc() and calloc()?

malloc() takes a total byte count and leaves the allocated bytes uninitialized. calloc() takes an element count and element size and initializes all allocated bytes to zero.

Q6. Which header file declares malloc() and calloc()?

stdlib.h.

Q7. What happens if malloc() cannot allocate memory?

It returns NULL.

Q8. Can malloc() allocate memory for an array?

Yes. Multiply the element count by the size of one element.

Q9. Does malloc() initialize allocated memory?

No. The allocated bytes have indeterminate values until initialized by the program.

Q10. Does calloc() set every object to semantic zero?

It initializes all allocated bytes to zero. An all-bits-zero representation is not guaranteed to represent semantic zero for every possible C type.

Q11. Can allocated memory be accessed using array notation?

Yes. A pointer to the first element of allocated array storage can be accessed using valid array-style indexing.

Q12. What is the purpose of sizeof *ptr?

It obtains the size of the object type pointed to by ptr and helps avoid hardcoding a type name.

16. Coding Interview Problems

Problem 1: Allocate and Display an Integer Array

Write a program that dynamically allocates an array of five integers and displays its elements. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr;
    size_t i;
    size_t n = 5;

    arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    for (i = 0; i < n; i++)
    {
        arr[i] = (int)(i + 1) * 5;
    }

    for (i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return 0;
}
Output: 
5 10 15 20 25

Problem 2: Calculate Sum of Dynamically Allocated Array

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n;
    size_t i;
    int *arr;
    long long sum = 0;

    printf("Enter array size: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid size\n");
        return 1;
    }

    if (n > (size_t)-1 / sizeof *arr)
    {
        printf("Requested size is too large\n");
        return 1;
    }

    arr = calloc(n, sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    printf("Enter %zu elements:\n", n);

    for (i = 0; i < n; i++)
    {
        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid input\n");
            free(arr);
            return 1;
        }

        sum += arr[i];
    }

    printf("Sum = %lld\n", sum);

    free(arr);

    return 0;
}
Sample Input: 
5
10 20 30 40 50
Output: 
Sum = 150

Problem 3: Find Maximum Element

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n;
    size_t i;
    int *arr;
    int max;

    printf("Enter array size: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid size\n");
        return 1;
    }

    if (n > (size_t)-1 / sizeof *arr)
    {
        printf("Requested size is too large\n");
        return 1;
    }

    arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    for (i = 0; i < n; i++)
    {
        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid input\n");
            free(arr);
            return 1;
        }
    }

    max = arr[0];

    for (i = 1; i < n; i++)
    {
        if (arr[i] > max)
        {
            max = arr[i];
        }
    }

    printf("Maximum = %d\n", max);

    free(arr);

    return 0;
}
Sample Input: 
5
12 45 7 89 23
Output: 
Maximum = 89

19. Quick Revision Checklist

  • malloc() allocates a specified number of bytes.
  • calloc() allocates storage for an array of elements.
  • malloc() does not initialize the allocated bytes.
  • calloc() initializes all allocated bytes to zero.
  • Both functions are declared in stdlib.h.
  • Both return NULL if allocation fails.
  • Use sizeof to calculate allocation requirements.
  • Use sizeof *ptr to avoid hardcoding the pointed-to type.
  • Check multiplication overflow in allocation-size calculations.
  • Use free() when allocated storage is no longer required.
