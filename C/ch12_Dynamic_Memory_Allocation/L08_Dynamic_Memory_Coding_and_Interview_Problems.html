2. Dynamic Memory Allocation: Quick Revision

Function Purpose Important Behavior
malloc() Allocates a block of memory. Allocated bytes are uninitialized.
calloc() Allocates an array of elements. All allocated bytes are initialized to zero.
realloc() Changes the size of an allocation. May move the allocation to a new address.
free() Releases an allocation. Must receive NULL or a valid allocated pointer not already freed.

Important Syntax

int *a = malloc(n * sizeof *a);

int *b = calloc(n, sizeof *b);

int *temp = realloc(a, new_n * sizeof *a);

free(a);
Always validate the allocation size before multiplication and check allocation results. For realloc(), use a temporary pointer.

3. Problem 1: Find the Sum and Average of Dynamic Array Elements

Problem Statement

Read the number of elements, dynamically allocate an integer array, accept values and calculate their sum and average.

Approach

  1. Read the number of elements.
  2. Validate the input size.
  3. Check allocation-size multiplication.
  4. Allocate memory using malloc().
  5. Read array elements.
  6. Calculate sum and average.
  7. Release allocated memory.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t n;

    printf("Enter number of elements: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid input\n");
        return EXIT_FAILURE;
    }

    if (n > SIZE_MAX / sizeof(int))
    {
        printf("Requested size is too large\n");
        return EXIT_FAILURE;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed\n");
        return EXIT_FAILURE;
    }

    long long sum = 0;

    printf("Enter %zu elements:\n", n);

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid element\n");
            free(arr);
            return EXIT_FAILURE;
        }

        sum += arr[i];
    }

    double average = (double)sum / (double)n;

    printf("Sum = %lld\n", sum);
    printf("Average = %.2f\n", average);

    free(arr);

    return EXIT_SUCCESS;
}
Sample Input: 
Enter number of elements: 5
Enter 5 elements:
10 20 30 40 50
Output: 
Sum = 150
Average = 30.00

Complexity

  • Time Complexity: O(n)
  • Space Complexity: O(n)
The example uses long long for the sum, but extremely large input values and element counts still require a range analysis to prevent sum overflow.

4. Problem 2: Find the Largest and Smallest Elements

Problem Statement

Dynamically allocate an array and find its minimum and maximum values.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t n;

    printf("Enter array size: ");

    if (scanf("%zu", &n) != 1 || n == 0)
    {
        printf("Invalid size\n");
        return EXIT_FAILURE;
    }

    if (n > SIZE_MAX / sizeof(int))
    {
        printf("Size too large\n");
        return EXIT_FAILURE;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < n; i++)
    {
        if (scanf("%d", &arr[i]) != 1)
        {
            printf("Invalid input\n");
            free(arr);
            return EXIT_FAILURE;
        }
    }

    int maximum = arr[0];
    int minimum = arr[0];

    for (size_t i = 1; i < n; i++)
    {
        if (arr[i] > maximum)
        {
            maximum = arr[i];
        }

        if (arr[i] < minimum)
        {
            minimum = arr[i];
        }
    }

    printf("Maximum = %d\n", maximum);
    printf("Minimum = %d\n", minimum);

    free(arr);

    return EXIT_SUCCESS;
}
Sample Input: 
Enter array size: 6
12 45 7 89 23 5
Output: 
Maximum = 89
Minimum = 5

Complexity

  • Time Complexity: O(n)
  • Space Complexity: O(n)

5. Problem 3: Implement a Dynamic Array with Append

Problem Statement

Implement a dynamic array that increases its capacity whenever the existing storage becomes full.

Structure Design

typedef struct
{
    int *data;
    size_t size;
    size_t capacity;
} DynamicArray;

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

typedef struct
{
    int *data;
    size_t size;
    size_t capacity;
} DynamicArray;

int init(DynamicArray *a)
{
    a->data = NULL;
    a->size = 0;
    a->capacity = 0;

    return 1;
}

int append(DynamicArray *a, int value)
{
    if (a->size == a->capacity)
    {
        size_t new_capacity;

        if (a->capacity == 0)
        {
            new_capacity = 2;
        }
        else
        {
            if (a->capacity > SIZE_MAX / 2)
            {
                return 0;
            }

            new_capacity = a->capacity * 2;
        }

        if (new_capacity > SIZE_MAX / sizeof *a->data)
        {
            return 0;
        }

        int *temp = realloc(
            a->data,
            new_capacity * sizeof *a->data
        );

        if (temp == NULL)
        {
            return 0;
        }

        a->data = temp;
        a->capacity = new_capacity;
    }

    a->data[a->size] = value;
    a->size++;

    return 1;
}

void display(const DynamicArray *a)
{
    for (size_t i = 0; i < a->size; i++)
    {
        printf("%d ", a->data[i]);
    }

    printf("\n");
}

void destroy(DynamicArray *a)
{
    free(a->data);

    a->data = NULL;
    a->size = 0;
    a->capacity = 0;
}

int main(void)
{
    DynamicArray a;

    init(&a);

    for (int i = 1; i <= 5; i++)
    {
        if (!append(&a, i * 10))
        {
            printf("Append failed\n");
            destroy(&a);
            return EXIT_FAILURE;
        }
    }

    display(&a);

    printf("Size = %zu\n", a.size);
    printf("Capacity = %zu\n", a.capacity);

    destroy(&a);

    return EXIT_SUCCESS;
}
Output: 
10 20 30 40 50
Size = 5
Capacity = 8

Complexity Analysis

Operation Time Complexity
Access by index O(1)
Append without resizing O(1)
Append with resizing O(n) in the worst case
Append over a sequence of operations Amortized O(1) per append

6. Problem 4: Insert an Element into a Dynamic Array

Problem Statement

Insert a new element at a specified position in a dynamic array. Shift existing elements to make space.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int insertElement(
    int **arr,
    size_t *size,
    size_t *capacity,
    size_t position,
    int value
)
{
    if (position > *size)
    {
        return 0;
    }

    if (*size == SIZE_MAX)
    {
        return 0;
    }

    if (*size == *capacity)
    {
        size_t new_capacity;

        if (*capacity == 0)
        {
            new_capacity = 2;
        }
        else
        {
            if (*capacity > SIZE_MAX / 2)
            {
                return 0;
            }

            new_capacity = *capacity * 2;
        }

        if (new_capacity > SIZE_MAX / sizeof **arr)
        {
            return 0;
        }

        int *temp = realloc(
            *arr,
            new_capacity * sizeof **arr
        );

        if (temp == NULL)
        {
            return 0;
        }

        *arr = temp;
        *capacity = new_capacity;
    }

    for (size_t i = *size; i > position; i--)
    {
        (*arr)[i] = (*arr)[i - 1];
    }

    (*arr)[position] = value;
    (*size)++;

    return 1;
}

int main(void)
{
    size_t size = 4;
    size_t capacity = 4;

    int *arr = malloc(capacity * sizeof *arr);

    if (arr == NULL)
    {
        return EXIT_FAILURE;
    }

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 40;
    arr[3] = 50;

    if (!insertElement(&arr, &size, &capacity, 2, 30))
    {
        printf("Insertion failed\n");
        free(arr);
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return EXIT_SUCCESS;
}
Output: 
10 20 30 40 50

Complexity

  • Insertion at the end without resizing: O(1).
  • Insertion at an arbitrary position: O(n).
  • Resizing may also require O(n) time.

7. Problem 5: Delete an Element from a Dynamic Array

Problem Statement

Delete an element at a given index and shift the remaining elements toward the beginning of the array.

C11 Program

#include <stdio.h>
#include <stdlib.h>

int deleteElement(
    int arr[],
    size_t *size,
    size_t position
)
{
    if (position >= *size)
    {
        return 0;
    }

    for (size_t i = position; i + 1 < *size; i++)
    {
        arr[i] = arr[i + 1];
    }

    (*size)--;

    return 1;
}

int main(void)
{
    size_t size = 5;

    int *arr = malloc(size * sizeof *arr);

    if (arr == NULL)
    {
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < size; i++)
    {
        arr[i] = (int)(i + 1) * 10;
    }

    if (!deleteElement(arr, &size, 2))
    {
        printf("Invalid position\n");
        free(arr);
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return EXIT_SUCCESS;
}
Output: 
10 20 40 50
This implementation reduces the logical size but does not reduce the allocated capacity. Shrinking the allocation is a separate operation and is not always necessary.

8. Problem 6: Dynamically Allocate and Add Two Matrices

Problem Statement

Allocate two matrices dynamically, read their elements, calculate their sum and display the resulting matrix.

Memory Representation

This solution uses one contiguous allocation for each matrix. 

matrix[row * cols + column]

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t rows = 2;
    size_t cols = 2;

    if (rows == 0 || cols == 0 ||
        rows > SIZE_MAX / cols)
    {
        return EXIT_FAILURE;
    }

    size_t count = rows * cols;

    if (count > SIZE_MAX / sizeof(int))
    {
        return EXIT_FAILURE;
    }

    int *a = malloc(count * sizeof *a);
    int *b = malloc(count * sizeof *b);
    int *sum = malloc(count * sizeof *sum);

    if (a == NULL || b == NULL || sum == NULL)
    {
        printf("Allocation failed\n");

        free(sum);
        free(b);
        free(a);

        return EXIT_FAILURE;
    }

    printf("Enter first matrix:\n");

    for (size_t i = 0; i < count; i++)
    {
        if (scanf("%d", &a[i]) != 1)
        {
            printf("Invalid input\n");
            free(sum);
            free(b);
            free(a);
            return EXIT_FAILURE;
        }
    }

    printf("Enter second matrix:\n");

    for (size_t i = 0; i < count; i++)
    {
        if (scanf("%d", &b[i]) != 1)
        {
            printf("Invalid input\n");
            free(sum);
            free(b);
            free(a);
            return EXIT_FAILURE;
        }
    }

    for (size_t i = 0; i < count; i++)
    {
        sum[i] = a[i] + b[i];
    }

    printf("Resultant matrix:\n");

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            printf("%4d", sum[i * cols + j]);
        }

        printf("\n");
    }

    free(sum);
    free(b);
    free(a);

    return EXIT_SUCCESS;
}
Sample Input: 
Enter first matrix:
1 2 3 4
Enter second matrix:
5 6 7 8
Output: 
Resultant matrix:
   6   8
  10  12

Complexity

  • Time Complexity: O(rows × cols)
  • Space Complexity: O(rows × cols) for each matrix.

9. Problem 7: Find the Transpose of a Dynamic Matrix

Problem Statement

Allocate a matrix dynamically and display its transpose.

For an original matrix with dimensions rows × cols, the transpose has dimensions cols × rows.

Index Relationship

transpose[column * rows + row]
    = matrix[row * cols + column];

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t rows = 2;
    size_t cols = 3;

    if (rows > SIZE_MAX / cols)
    {
        return EXIT_FAILURE;
    }

    size_t count = rows * cols;

    if (count > SIZE_MAX / sizeof(int))
    {
        return EXIT_FAILURE;
    }

    int *matrix = malloc(count * sizeof *matrix);
    int *transpose = malloc(count * sizeof *transpose);

    if (matrix == NULL || transpose == NULL)
    {
        printf("Allocation failed\n");
        free(transpose);
        free(matrix);
        return EXIT_FAILURE;
    }

    printf("Enter matrix elements:\n");

    for (size_t i = 0; i < count; i++)
    {
        if (scanf("%d", &matrix[i]) != 1)
        {
            printf("Invalid input\n");
            free(transpose);
            free(matrix);
            return EXIT_FAILURE;
        }
    }

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            transpose[j * rows + i] =
                matrix[i * cols + j];
        }
    }

    printf("Transpose:\n");

    for (size_t i = 0; i < cols; i++)
    {
        for (size_t j = 0; j < rows; j++)
        {
            printf("%4d", transpose[i * rows + j]);
        }

        printf("\n");
    }

    free(transpose);
    free(matrix);

    return EXIT_SUCCESS;
}
Sample Input: 
1 2 3
4 5 6
Output: 
   1   4
   2   5
   3   6

10. Problem 8: Allocate a Matrix Using int **

Problem Statement

Allocate a matrix as an array of row pointers. Each row is allocated independently.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t rows = 3;
    size_t cols = 2;

    if (rows == 0 || cols == 0 ||
        rows > SIZE_MAX / sizeof(int *))
    {
        return EXIT_FAILURE;
    }

    int **matrix = calloc(rows, sizeof *matrix);

    if (matrix == NULL)
    {
        printf("Row pointer allocation failed\n");
        return EXIT_FAILURE;
    }

    size_t allocated_rows = 0;

    for (size_t i = 0; i < rows; i++)
    {
        if (cols > SIZE_MAX / sizeof **matrix)
        {
            break;
        }

        matrix[i] = malloc(cols * sizeof **matrix);

        if (matrix[i] == NULL)
        {
            break;
        }

        allocated_rows++;
    }

    if (allocated_rows != rows)
    {
        printf("Matrix allocation failed\n");

        for (size_t i = 0; i < allocated_rows; i++)
        {
            free(matrix[i]);
        }

        free(matrix);

        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            matrix[i][j] = (int)(i * cols + j + 1);
        }
    }

    for (size_t i = 0; i < rows; i++)
    {
        for (size_t j = 0; j < cols; j++)
        {
            printf("%4d", matrix[i][j]);
        }

        printf("\n");
    }

    for (size_t i = 0; i < rows; i++)
    {
        free(matrix[i]);
    }

    free(matrix);

    return EXIT_SUCCESS;
}
Output: 
   1   2
   3   4
   5   6

Important Difference

Contiguous Matrix Pointer-to-Pointer Matrix
One allocation for all elements. One allocation for row pointers and separate allocations for rows.
Access using matrix[r * cols + c]. Access using matrix[r][c].
One free() call. Free every allocated row, then the row pointer array.
Elements are contiguous in memory. Rows need not be adjacent in memory.
int ** is not interchangeable with a pointer to a contiguous two-dimensional array. They have different memory representations and types.

11. Problem 9: Reverse an Array Using Pointer Arithmetic

Problem Statement

Dynamically allocate an array and reverse its elements using pointers instead of array indexing.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void)
{
    size_t n = 5;

    if (n > SIZE_MAX / sizeof(int))
    {
        return EXIT_FAILURE;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < n; i++)
    {
        arr[i] = (int)(i + 1) * 10;
    }

    int *left = arr;
    int *right = arr + n - 1;

    while (left < right)
    {
        int temp = *left;

        *left = *right;
        *right = temp;

        left++;
        right--;
    }

    for (size_t i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return EXIT_SUCCESS;
}
Output: 
50 40 30 20 10

Complexity

  • Time Complexity: O(n)
  • Extra Space Complexity: O(1)

12. Problem 10: Return Dynamically Allocated Memory from a Function

Problem Statement

Write a function that allocates an integer array and returns its address to the calling function.

C11 Program

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int *createArray(size_t n)
{
    if (n == 0 || n > SIZE_MAX / sizeof(int))
    {
        return NULL;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        return NULL;
    }

    for (size_t i = 0; i < n; i++)
    {
        arr[i] = (int)(i + 1) * 10;
    }

    return arr;
}

int main(void)
{
    size_t n = 5;

    int *arr = createArray(n);

    if (arr == NULL)
    {
        printf("Array creation failed\n");
        return EXIT_FAILURE;
    }

    for (size_t i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    free(arr);

    return EXIT_SUCCESS;
}
Output: 
10 20 30 40 50
The returned allocation remains valid after createArray() returns. The caller receives ownership and must eventually release it with free().

13. Pointer and Memory Output-Prediction Questions

Question 1: What Does calloc() Initialize?

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *p = calloc(3, sizeof *p);

    if (p == NULL)
    {
        return EXIT_FAILURE;
    }

    printf("%d %d %d\n", p[0], p[1], p[2]);

    free(p);

    return 0;
}
Output: 
0 0 0

Question 2: What Happens After free()?

int *p = malloc(sizeof *p);

if (p != NULL)
{
    *p = 100;
    free(p);
    p = NULL;
}

The allocated memory is released. Assigning NULL to p prevents accidental use of the old pointer value through p.

Question 3: Is This realloc() Safe?

int *temp = realloc(p, 20 * sizeof *p);

if (temp != NULL)
{
    p = temp;
}

Yes. If realloc() fails, p still identifies the original allocation. If it succeeds, p is updated to the returned address.

Question 4: What Is Wrong Here?

int *p = malloc(5 * sizeof *p);

free(p);

printf("%d", p[0]);

The program accesses released memory. This is a use-after-free error and causes undefined behavior.

Question 5: What Is Wrong Here?

int *p = malloc(sizeof *p);

free(p);
free(p);

The second free() attempts to release an already released allocation. This is undefined behavior.

14. Memory Debugging Scenarios

Scenario 1: Memory Leak

int *p = malloc(10 * sizeof *p);

p = malloc(20 * sizeof *p);

free(p);

The first allocation address is lost when p is overwritten by the second allocation. The first allocation cannot be released through p.

This causes a memory leak.

Correct Approach

int *p = malloc(10 * sizeof *p);

if (p == NULL)
{
    return EXIT_FAILURE;
}

int *temp = realloc(p, 20 * sizeof *p);

if (temp == NULL)
{
    free(p);
    return EXIT_FAILURE;
}

p = temp;

free(p);

Scenario 2: Dangling Pointer

int *p = malloc(sizeof *p);

if (p == NULL)
{
    return EXIT_FAILURE;
}

*p = 25;

free(p);

/* p is now dangling */
p = NULL;

A dangling pointer is a pointer whose former target object no longer exists or whose allocated storage has been released.

Scenario 3: Incorrect Array Size

int *p = malloc(5 * sizeof *p);

for (int i = 0; i <= 5; i++)
{
    p[i] = i;
}

The allocation contains five integers, with valid indexes from 0 to 4. The loop also writes to index 5, causing an out-of-bounds access.

Correct Loop

for (int i = 0; i < 5; i++)
{
    p[i] = i;
}

15. Dynamic Memory Time and Space Complexity

Operation Typical Time Complexity Notes
malloc() Allocator-dependent No universal complexity guarantee in C.
calloc() Allocator-dependent Zero-initialization also involves work proportional to the storage initialized.
realloc() Allocator-dependent May extend in place or move and copy data.
free() Allocator-dependent Releases a valid allocated block.
Array indexing O(1) Direct access by index.
Array insertion O(n) Elements may need shifting.
Array deletion O(n) Elements may need shifting.
Dynamic array append Amortized O(1) With geometric capacity growth.
C does not specify a universal time complexity for the standard allocation functions. Their performance depends on the implementation and allocator.

16. Frequently Asked Technical Interview Questions

Q1. What is dynamic memory allocation?

Dynamic memory allocation is the process of requesting and releasing memory during program execution.

Q2. What is the difference between malloc() and calloc()?

malloc() allocates a specified number of bytes without initializing them. calloc() allocates an array and initializes its allocated bytes to zero.

Q3. What is the difference between realloc() and malloc()?

malloc() creates a new allocation. realloc() changes the size of an existing allocation or allocates storage when its input pointer is NULL.

Q4. Can realloc() move memory?

Yes. It may extend the allocation in place or allocate a new block, copy the existing contents and release the old block.

Q5. What happens if malloc() fails?

For a nonzero allocation request, malloc() returns NULL.

Q6. Can free() accept NULL?

Yes. Calling free(NULL) has no effect.

Q7. What happens if memory is freed twice?

A second free() on the same already released allocation causes undefined behavior.

Q8. What is a memory leak?

A memory leak occurs when allocated storage is no longer reachable through the program's ownership references and is not released.

Q9. What is a dangling pointer?

It is a pointer that refers to storage whose lifetime has ended or which has been released.

Q10. Why is realloc() assigned to a temporary pointer?

To preserve the original allocation if resizing fails.

Q11. Can a function return a pointer to dynamically allocated memory?

Yes. The allocation remains valid after the function returns, until it is released or its lifetime otherwise ends.

Q12. What is a memory fragmentation problem?

Fragmentation occurs when free memory is divided into separate blocks, which can make some allocation requests difficult to satisfy.

Q13. What is the difference between stack and heap?

These are common implementation concepts. Automatic storage duration is commonly associated with a stack, while dynamic allocations are commonly managed through a heap. The C language itself does not mandate these physical memory regions.

Q14. What is a memory pool?

A memory pool is a preallocated region divided into blocks that can be reused according to a defined allocation policy.

Q15. Why is dynamic memory allocation carefully controlled in embedded systems?

Embedded systems may have limited RAM, real-time deadlines and long operating lifetimes. Unpredictable allocation, fragmentation and allocation failure can affect system reliability.

Run on Linux

./dynamic_memory

Run on Windows

dynamic_memory.exe

Compile with AddressSanitizer

gcc -std=c11 -Wall -Wextra -g -fsanitize=address -fno-omit-frame-pointer dynamic_memory.c -o dynamic_memory

Useful Debugging Tools

  • GDB: step through programs and inspect pointers.
  • AddressSanitizer: detect many invalid memory accesses.
  • Valgrind: detect memory leaks and invalid memory operations on supported platforms.
  • Compiler warnings: identify suspicious code and type errors.
