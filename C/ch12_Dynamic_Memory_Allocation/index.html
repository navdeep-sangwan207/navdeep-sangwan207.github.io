Chapter 12: Dynamic Memory Allocation

Learn how C programs allocate, resize and release memory at runtime. Develop practical memory-management skills required for systems programming, embedded software and technical interviews.

Chapter Overview

Dynamic memory allocation allows a program to request memory during execution rather than relying only on fixed-size objects declared at compile time.

Primary topics:

  • Stack and heap memory concepts.
  • malloc() and calloc().
  • realloc() and dynamic resizing.
  • free() and memory deallocation.
  • Dynamic arrays and multidimensional arrays.
  • Memory leaks and dangling pointers.
  • Safe allocation and error handling.

Programming standard: C11

Placement focus: Pointer-based memory management, debugging, coding problems and technical interview questions.

Chapter Completion Goals

After completing this chapter, you should be able to:

  • Explain the difference between automatic and dynamic storage duration.
  • Allocate memory using malloc() and calloc().
  • Resize allocated memory safely using realloc().
  • Release memory using free().
  • Create dynamic one-dimensional and multidimensional arrays.
  • Identify memory leaks and dangling pointers.
  • Handle allocation failure and cleanup correctly.
  • Debug common dynamic memory errors.
  • Write C11 programs using safe memory-management practices.
