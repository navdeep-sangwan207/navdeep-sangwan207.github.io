Lecture 01: Binary Representation and Bitwise Operators

Understand how integer values are represented in binary and how C bitwise operators manipulate individual bits.

1. Learning Objectives

  • Understand binary, decimal and hexadecimal number systems.
  • Convert decimal values into binary.
  • Understand binary representation of integers.
  • Identify bit positions and their weights.
  • Understand bitwise AND, OR, XOR and NOT.
  • Differentiate logical and bitwise operators.
  • Write C programs using bitwise operators.
  • Solve output-prediction and interview questions.
  • Understand why bitwise operations are important in embedded systems.

2. Number Systems

A number system defines how numerical values are represented using a set of symbols or digits.

Common Number Systems

Number System Base Allowed Digits
Binary 2 0, 1
Octal 8 0 to 7
Decimal 10 0 to 9
Hexadecimal 16 0 to 9, A to F

Binary Number System

Binary is a base-2 number system. It uses only two digits:

  • 0: Binary zero
  • 1: Binary one

Computers and microcontrollers process digital information using binary states.

Example: Binary 1011

Each binary digit represents a power of 2.

Bit Position 3 2 1 0
Bit Value 1 0 1 1
Weight 8 4 2 1

Therefore: 

1011₂ = (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1)

       = 8 + 0 + 2 + 1

       = 11₁₀

3. Decimal to Binary Conversion

To convert a positive decimal integer into binary, repeatedly divide the number by 2 and record the remainders.

Example: Convert 25 into Binary

Division Quotient Remainder
25 / 2 12 1
12 / 2 6 0
6 / 2 3 0
3 / 2 1 1
1 / 2 0 1

Read the remainders from bottom to top: 

25₁₀ = 11001₂

Example: Convert 13 into Binary

13 / 2 = 6 remainder 1
 6 / 2 = 3 remainder 0
 3 / 2 = 1 remainder 1
 1 / 2 = 0 remainder 1

13₁₀ = 1101₂

4. Binary to Decimal Conversion

Multiply every binary digit by its corresponding power of 2 and add the resulting values.

Example: Convert 11010 into Decimal

Binary = 11010

= (1 × 2⁴) + (1 × 2³) + (0 × 2²)
  + (1 × 2¹) + (0 × 2⁰)

= 16 + 8 + 0 + 2 + 0

= 26
Binary conversion is essential for understanding bit positions, masks, hardware registers and bitwise output-prediction questions.

Hexadecimal is a base-16 number system. It uses digits from 0 to 9 and letters from A to F.

2F₁₆

= (2 × 16¹) + (15 × 16⁰)

int value = 0x2F;

printf("%d\n", value);
printf("%X\n", value);
Output: 
47

Hexadecimal notation is widely used in embedded systems to represent hardware register addresses, masks, memory values and peripheral settings.

6. Bits and Bit Positions

A bit is the smallest unit of digital information. It can represent either 0 or 1.

In an unsigned integer, bit positions are numbered from right to left, starting from position zero.

Example: 8-Bit Value

Bit Position:  7 6 5 4 3 2 1 0

Binary Value:  0 0 0 0 1 0 1 1

Bit Weight:   128 64 32 16 8 4 2 1

The binary value 00001011 represents decimal 11.

Bit Position Formula

Bit mask = 1U << position

For example, a mask for bit position 3: 

00000001
    << 3
----------
00001000

The resulting mask has only bit 3 set.

Bit positions must be valid for the width of the promoted left operand. Never shift by a negative amount or by an amount greater than or equal to that width.

7. What Are Bitwise Operators?

Bitwise operators perform operations directly on the individual bits of integer operands.

Bitwise Operators in C

Operator Name Operation
& Bitwise AND AND operation on corresponding bits.
| Bitwise OR OR operation on corresponding bits.
^ Bitwise XOR Exclusive OR on corresponding bits.
~ Bitwise NOT Inverts each bit.
<< Left Shift Shifts bits toward higher positions.
>> Right Shift Shifts bits toward lower positions.

This lecture covers AND, OR, XOR and NOT in detail. Shift operators are covered in the next lecture.

8. Bitwise AND (&) Operator

The bitwise AND operator produces 1 only when both corresponding bits are 1.

Truth Table

A B A & B
000
010
100
111

Example

  12 = 1100
   10 = 1010
  -----------
&     = 1000

1000₂ = 8₁₀

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 12U;
    unsigned int b = 10U;

    unsigned int result = a & b;

    printf("AND result = %u\n", result);

    return 0;
}
Output: 
AND result = 8

Applications

  • Checking whether a bit is set.
  • Extracting selected bits.
  • Applying bit masks.
  • Checking hardware status flags.

9. Bitwise OR (|) Operator

The bitwise OR operator produces 1 when at least one of the corresponding bits is 1.

Truth Table

A B A | B
000
011
101
111

Example

  12 = 1100
  10 = 1010
  -----------
|     = 1110

1110₂ = 14₁₀

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 12U;
    unsigned int b = 10U;

    unsigned int result = a | b;

    printf("OR result = %u\n", result);

    return 0;
}
Output: 
OR result = 14

Applications

  • Setting one or more selected bits.
  • Combining configuration flags.
  • Enabling multiple hardware features.
  • Building bit masks.

10. Bitwise XOR (^) Operator

XOR stands for Exclusive OR. It produces 1 when the corresponding bits are different.

Truth Table

A B A ^ B
000
011
101
110

Example

  12 = 1100
  10 = 1010
  -----------
^     = 0110

0110₂ = 6₁₀

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 12U;
    unsigned int b = 10U;

    unsigned int result = a ^ b;

    printf("XOR result = %u\n", result);

    return 0;
}
Output: 
XOR result = 6

Important XOR Properties

A ^ 0 = A
A ^ A = 0
A ^ B = B ^ A
(A ^ B) ^ C = A ^ (B ^ C)

These properties are useful for finding unique elements, detecting differences and solving coding interview problems.

XOR-based coding problems are covered in detail in Lecture 06.

11. Bitwise NOT (~) Operator

The bitwise NOT operator inverts every bit of its operand.

Truth Table

A ~A
01
10

Example with an Unsigned Integer

unsigned int a = 5U;
unsigned int result = ~a;

The result depends on the width of unsigned int. If unsigned int is 32 bits: 

a  = 00000000 00000000 00000000 00000101

~a = 11111111 11111111 11111111 11111010

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 5U;

    unsigned int result = ~a;

    printf("Original value = %u\n", a);
    printf("NOT result = %u\n", result);

    return 0;
}

The numerical result depends on the width of unsigned int. On a system with 32-bit unsigned int, the output is:

Output on a 32-bit unsigned int system: 
Original value = 5
NOT result = 4294967290
Do not assume every C implementation uses 32-bit int. Use sizeof and appropriate unsigned types when writing portable code.

12. Complete Program Using All Four Operators

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 12U;
    unsigned int b = 10U;

    printf("A = %u\n", a);
    printf("B = %u\n", b);

    printf("A & B = %u\n", a & b);
    printf("A | B = %u\n", a | b);
    printf("A ^ B = %u\n", a ^ b);
    printf("~A = %u\n", ~a);

    return 0;
}
Output on a 32-bit unsigned int system: 
A = 12
B = 10
A & B = 8
A | B = 14
A ^ B = 6
~A = 4294967283

13. Bitwise Operators vs Logical Operators

Bitwise operators and logical operators are different, even though some symbols look similar.

Bitwise Operators Logical Operators
& &&
| ||
~ !
Operate on integer bits. Evaluate truth values.
Do not provide logical short-circuiting. && and || use short-circuit evaluation.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 3;

    printf("Bitwise AND = %d\n", a & b);
    printf("Logical AND = %d\n", a && b);

    return 0;
}
Output: 
Bitwise AND = 1
Logical AND = 1

The outputs happen to be equal here, but the operations have different meanings.

Another Example

#include <stdio.h>

int main(void)
{
    int a = 4;
    int b = 2;

    printf("%d\n", a & b);
    printf("%d\n", a && b);

    return 0;
}
Output: 
0
1

Explanation: 

4 = 100
2 = 010

4 & 2 = 000 = 0

Both 4 and 2 are nonzero,
so 4 && 2 = 1.

14. Practical Example: Checking a Bit Using AND

Problem Statement

Check whether bit position 2 is set in an unsigned integer.

Logic

mask = 1U << 2

result = number & mask

If the result is nonzero, the selected bit is set.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 10U;
    unsigned int mask = 1U << 2;

    if ((number & mask) != 0U)
    {
        printf("Bit is set\n");
    }
    else
    {
        printf("Bit is not set\n");
    }

    return 0;
}
Output: 
Bit is not set

Explanation:

10 = 1010
 4 = 0100
     ----
AND  0000

Bit position 2 is zero in binary representation of 10.

This technique is commonly used when reading status flags and configuration bits.

15. Bitwise Operators in Embedded Systems

Microcontrollers contain hardware registers whose individual bits control peripherals and device features.

Example: Configure a GPIO Direction Register

Assume a hypothetical GPIO direction register where bit 5 controls the direction of a pin. 

#include <stdint.h>

#define GPIO_DIRECTION (*(volatile uint32_t *)0x40000000U)

void configurePin5AsOutput(void)
{
    GPIO_DIRECTION |= (1U << 5);
}

The OR operation sets bit 5 while preserving the other register bits.

The register address above is illustrative only. Never use an arbitrary address on real hardware. Use the microcontroller's datasheet, reference manual and device header.

Example: Clear a Register Bit

GPIO_DIRECTION &= ~(1U << 5);

This clears bit 5 while preserving other bits in the register.

Why volatile?

Hardware registers can change independently of ordinary program execution. The volatile qualifier tells the compiler that accesses to the object are observable and must follow the abstract-machine rules for volatile accesses.

Volatile does not provide atomicity, synchronization or a universal hardware memory barrier.

16. Common Bitwise Coding Mistakes

Mistake 1: Using Logical AND Instead of Bitwise AND

if (number && mask)

This checks whether both expressions are nonzero. It does not test whether a particular bit is set.

Correct:

if ((number & mask) != 0U)

Mistake 2: Incorrect Bit Position

unsigned int mask = 1U << 8;

This selects bit position 8, not bit position 7.

Mistake 3: Ignoring Integer Promotions

Small integer types such as unsigned char are generally promoted to int or unsigned int before many arithmetic and bitwise operations.

Mistake 4: Shifting by an Invalid Amount

unsigned int result = 1U << 32;

This is undefined behavior on an implementation where unsigned int has width 32.

Mistake 5: Assuming int Is Always 32 Bits

The C language does not require int to be exactly 32 bits. Select an appropriate unsigned integer type and check its width when fixed-width behavior is needed.

18. Technical Interview Questions

Q1. What is a bit?

A bit is a binary digit that can represent either zero or one.

Q2. What is a bitwise operator?

A bitwise operator performs an operation on individual bits of integer operands.

Q3. What is the difference between & and &&?

& performs bitwise AND. && performs logical AND and uses short-circuit evaluation.

Q4. What is the difference between | and ||?

| performs bitwise OR. || performs logical OR and uses short-circuit evaluation.

Q5. What is XOR?

XOR produces one when two corresponding bits are different.

Q6. What is the result of A ^ A?

Zero, because every bit is XORed with itself.

Q7. Why is hexadecimal commonly used in embedded systems?

Each hexadecimal digit represents exactly four binary bits, making register values and memory addresses easier to read.

Q8. Why are unsigned integers commonly used for bit manipulation?

Unsigned integer operations have well-defined modulo arithmetic behavior, and bitwise operations are easier to reason about without signed representation complications.

Q9. What is a bit mask?

A bit mask is a value used with bitwise operators to select, set, clear or modify particular bits.

Q10. What is the least significant bit?

The least significant bit is the rightmost bit, with position zero.

21. Lecture Summary

  • Binary uses base 2.
  • Decimal uses base 10.
  • Hexadecimal uses base 16.
  • Bit positions start from zero at the rightmost bit.
  • AND produces one when both bits are one.
  • OR produces one when at least one bit is one.
  • XOR produces one when bits are different.
  • NOT inverts each bit.
  • Bitwise and logical operators are different.
  • Bit masks are important in register manipulation.
  • Unsigned types are generally preferred for bit-level operations.
