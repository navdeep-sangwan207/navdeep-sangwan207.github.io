Lecture 03: Bit Masking and Bit Positions

Learn how to create bit masks, select specific bits, extract bit fields and manipulate selected bits without disturbing the remaining bits.

1. Learning Objectives

  • Understand bit masking and its purpose.
  • Understand bit positions and bit numbering.
  • Create masks using left shift.
  • Use AND, OR and XOR with masks.
  • Extract individual bits and multiple-bit fields.
  • Preserve unrelated bits while modifying a value.
  • Understand mask width and shift-count restrictions.
  • Apply masking to hardware registers and status flags.
  • Solve placement-oriented bit manipulation problems.

2. What Is Bit Masking?

Bit masking is a technique used to select, inspect, set, clear or modify particular bits of an integer using a specially constructed binary value called a mask.

A mask contains 1s and 0s in positions that determine which bits participate in an operation.

Example

Suppose the original value is:

Original value = 10110110

Mask           = 00001111

Applying bitwise AND selects the lower four bits: 

  10110110
& 00001111
------------
  00000110

The resulting value is 6.

Bit masking is especially important in embedded systems because hardware registers often contain multiple independent control and status fields.

3. Understanding Bit Positions

Bit positions are normally counted from right to left, starting at zero.

The rightmost bit is called the Least Significant Bit (LSB). The leftmost bit is the Most Significant Bit (MSB) within the chosen width.

Eight-Bit Example

Bit position 7 6 5 4 3 2 1 0
Binary value 1 0 1 1 0 1 1 0

For the binary value 10110110:

  • Bit 0 = 0
  • Bit 1 = 1
  • Bit 2 = 1
  • Bit 3 = 0
  • Bit 4 = 1
  • Bit 5 = 1
  • Bit 6 = 0
  • Bit 7 = 1
Bit positions start at zero, not one. Confusing bit position with bit number is a common source of embedded programming errors.

4. Creating a Single-Bit Mask

A mask containing exactly one set bit can be created using left shift.

General Formula

mask = 1U << position;

Example: Create a Mask for Bit 3

1U = 00000001

1U << 3

Result = 00001000

The decimal value of this mask is 8.

Common Single-Bit Masks

Position Binary mask (8-bit illustration) Decimal
0 00000001 1
1 00000010 2
2 00000100 4
3 00001000 8
4 00010000 16
5 00100000 32
6 01000000 64
7 10000000 128

C Program

#include <stdio.h>

int main(void)
{
    unsigned int position = 5U;

    unsigned int mask = 1U << position;

    printf("Mask = %u\n", mask);

    return 0;
}
Output: 
Mask = 32

5. Using AND Masking to Test a Bit

Bitwise AND can determine whether a particular bit is set or cleared.

Formula

if ((number & mask) != 0U)
{
    /* Bit is set */
}
else
{
    /* Bit is clear */
}

Example

Consider the value 13: 

Number = 13 = 00001101

Mask for bit 2:

Mask   =       00000100

AND:

                00001101
              & 00000100
              ------------
                00000100

The result is nonzero, so bit 2 is set.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 13U;
    unsigned int position = 2U;

    unsigned int mask = 1U << position;

    if ((number & mask) != 0U)
    {
        printf("Bit %u is SET\n", position);
    }
    else
    {
        printf("Bit %u is CLEAR\n", position);
    }

    return 0;
}
Output: 
Bit 2 is SET

6. Using OR Masking to Set a Bit

Bitwise OR can set a selected bit to 1 without changing the other bits.

Formula

number = number | mask;

The compound assignment form is: 

number |= mask;

Example: Set Bit 2

Original = 00001001

Mask     = 00000100

OR:

           00001001
         | 00000100
         ------------
           00001101

The result is 13.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 9U;

    unsigned int position = 2U;

    unsigned int mask = 1U << position;

    number |= mask;

    printf("Updated value = %u\n", number);

    return 0;
}
Output: 
Updated value = 13

7. Using AND with Complement to Clear a Bit

To clear a particular bit, create a mask and complement it using the bitwise NOT operator.

Formula

number = number & ~(1U << position);

The compound assignment form is: 

number &= ~mask;

Example: Clear Bit 2

Original = 00001101

Mask     = 00000100

~Mask    = 11111011

AND:

           00001101
         & 11111011
         ------------
           00001001

The result is 9.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 13U;

    unsigned int position = 2U;

    unsigned int mask = 1U << position;

    number &= ~mask;

    printf("Updated value = %u\n", number);

    return 0;
}
Output: 
Updated value = 9
The complement operator is applied to the unsigned mask. This makes the operation suitable for unsigned bit manipulation.

8. Using XOR Masking to Toggle a Bit

XOR changes a selected bit from 0 to 1 or from 1 to 0.

Formula

number ^= mask;

Example: Toggle Bit 1

Original = 00001001

Mask     = 00000010

XOR:

           00001001
         ^ 00000010
         ------------
           00001011

The value changes from 9 to 11.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 9U;

    unsigned int position = 1U;

    unsigned int mask = 1U << position;

    number ^= mask;

    printf("Updated value = %u\n", number);

    return 0;
}
Output: 
Updated value = 11

9. Summary of Single-Bit Operations

Operation Expression Purpose
Test (number & mask) != 0U Check whether a bit is set.
Set number |= mask Make a bit 1.
Clear number &= ~mask Make a bit 0.
Toggle number ^= mask Invert a bit.

These four operations form the foundation of practical bit manipulation.

10. Creating a Multi-Bit Mask

Sometimes we need to select multiple consecutive bits rather than a single bit.

Example: Select the Lower Four Bits

Mask = 00001111

In hexadecimal: 

Mask = 0x0F

Example: Select Four Bits Starting at Position 4

Base mask = 00001111

Shift left by 4:

Mask      = 11110000

The corresponding expression is: 

unsigned int mask = 0x0FU << 4U;

C Program

#include <stdio.h>

int main(void)
{
    unsigned int mask = 0x0FU << 4U;

    printf("Mask = 0x%X\n", mask);

    return 0;
}
Output: 
Mask = 0xF0

11. Extracting a Multi-Bit Field

To extract a field:

  1. Shift the required field to the least significant position.
  2. Apply a mask that retains only the required number of bits.

General Formula

field = (number >> start_position) & field_mask;

Example

Suppose: 

number = 0xB0

Binary = 10110000

Extract four bits starting at position 4. 

number >> 4:

10110000 >> 4 = 00001011

Apply mask:

00001011
& 00001111
------------
00001011

Result = 11 = 0xB

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 0xB0U;

    unsigned int field =
        (number >> 4U) & 0x0FU;

    printf("Extracted field = 0x%X\n", field);

    return 0;
}
Output: 
Extracted field = 0xB

12. Updating a Multi-Bit Field

Suppose a register contains several fields and we need to update only one field without changing the others.

The process is:

  1. Create a mask for the target field.
  2. Clear the target field in the original value.
  3. Shift the new field value to the correct position.
  4. Combine the values using OR.

General Formula

updated = (original & ~mask)
        | ((new_value & field_mask) << position);

Example

Assume a four-bit field begins at bit position 4. We want to replace it with the value 5. 

Original value = 0xB0

Original binary = 10110000

Field mask = 00001111

Shifted field mask = 11110000

New field value = 5 = 0101

Shifted new value = 01010000

Clear the old field:

10110000
& 00001111
------------
00000000

Insert the new field:

00000000
| 01010000
------------
01010000

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int original = 0xB0U;

    unsigned int new_value = 5U;

    unsigned int position = 4U;

    unsigned int field_mask = 0x0FU;

    unsigned int mask = field_mask << position;

    unsigned int updated =
        (original & ~mask) |
        ((new_value & field_mask) << position);

    printf("Original = 0x%X\n", original);
    printf("Updated  = 0x%X\n", updated);

    return 0;
}
Output: 
Original = 0xB0
Updated  = 0x50
Masking is essential when a register contains multiple fields and changing one field must not disturb the others.

13. Combining Multiple Bit Masks

Multiple masks can be combined using bitwise OR.

Example

Create a mask that selects bit positions 1, 3 and 5. 

Mask for bit 1 = 00000010
Mask for bit 3 = 00001000
Mask for bit 5 = 00100000

Combined mask:

00000010
00001000
00100000
----------
00101010

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int mask =
        (1U << 1U) |
        (1U << 3U) |
        (1U << 5U);

    printf("Combined mask = 0x%X\n", mask);

    return 0;
}
Output: 
Combined mask = 0x2A

14. Practical Embedded Systems Application

Scenario: Control Register

Consider a hypothetical control register with these bit definitions:

Bit Function
Bit 0 Peripheral enable
Bit 1 Interrupt enable
Bit 2 Operating mode
Bits 4–7 Configuration field

Define Masks

#define PERIPHERAL_ENABLE_MASK (1U << 0U)
#define INTERRUPT_ENABLE_MASK  (1U << 1U)
#define MODE_MASK              (1U << 2U)
#define CONFIG_MASK            (0x0FU << 4U)

Enable the Peripheral

control_register |= PERIPHERAL_ENABLE_MASK;

Disable the Interrupt

control_register &= ~INTERRUPT_ENABLE_MASK;

Read the Mode Bit

unsigned int mode =
    (control_register & MODE_MASK) != 0U;

Update the Configuration Field

control_register =
    (control_register & ~CONFIG_MASK) |
    ((configuration & 0x0FU) << 4U);
This is a software example using a hypothetical register. Actual hardware registers may have read-only bits, write-one-to-clear bits, reserved bits or special access requirements. Always follow the device datasheet and reference manual before modifying a real register.

15. Reusable Bit Manipulation Functions

Frequently used masking operations can be implemented as functions.

C11 Program

#include <stdio.h>
#include <limits.h>

#define UINT_BITS ((unsigned int)(sizeof(unsigned int) * CHAR_BIT))

int is_valid_position(unsigned int position)
{
    return position < UINT_BITS;
}

int test_bit(unsigned int value, unsigned int position)
{
    if (!is_valid_position(position))
    {
        return -1;
    }

    return (value & (1U << position)) != 0U;
}

int set_bit(unsigned int *value, unsigned int position)
{
    if (value == NULL || !is_valid_position(position))
    {
        return 0;
    }

    *value |= (1U << position);

    return 1;
}

int clear_bit(unsigned int *value, unsigned int position)
{
    if (value == NULL || !is_valid_position(position))
    {
        return 0;
    }

    *value &= ~(1U << position);

    return 1;
}

int toggle_bit(unsigned int *value, unsigned int position)
{
    if (value == NULL || !is_valid_position(position))
    {
        return 0;
    }

    *value ^= (1U << position);

    return 1;
}

int main(void)
{
    unsigned int value = 10U;

    printf("Initial value = %u\n", value);

    set_bit(&value, 0U);
    printf("After set = %u\n", value);

    clear_bit(&value, 1U);
    printf("After clear = %u\n", value);

    toggle_bit(&value, 3U);
    printf("After toggle = %u\n", value);

    printf("Bit 0 = %d\n", test_bit(value, 0U));

    return 0;
}
Output: 
Initial value = 10
After set = 11
After clear = 9
After toggle = 1
Bit 0 = 1

The functions validate bit positions before performing shift operations. The test function returns -1 for an invalid position.

16. Common Mistakes and Important Rules

1. Using the Wrong Bit Position

Remember that bit positions start from zero at the least significant bit.

2. Forgetting to Clear Before Updating a Field

Using OR alone to insert a new field can leave old set bits unchanged. Clear the destination field first.

3. Using an Invalid Shift Count

A shift count must be smaller than the width of the promoted left operand.

4. Ignoring Integer Promotions

Small integer types such as unsigned char are generally promoted before shifting. Always reason about the promoted type.

5. Using Signed Values for Masks

Use unsigned integer types for portable bit manipulation.

6. Forgetting Field Width

When inserting a field, mask the incoming value so that bits outside the field width cannot affect neighboring positions.

7. Modifying Hardware Registers Carelessly

Some hardware registers do not support ordinary read-modify-write operations. Check register access rules in the device documentation.

18. Technical Interview Questions

Q1. What is a bit mask?

A bit mask is a binary value used to select or manipulate specific bits of another value.

Q2. How do you set a bit?

number |= (1U << position);

Q3. How do you clear a bit?

number &= ~(1U << position);

Q4. How do you toggle a bit?

number ^= (1U << position);

Q5. How do you test whether a bit is set?

(number & (1U << position)) != 0U

Q6. Why is AND used for clearing bits?

AND with a mask containing zero at the target position forces that bit to zero while preserving other positions.

Q7. Why is OR used for setting bits?

OR with one forces the selected bit to one without changing other bit positions.

Q8. Why is XOR used for toggling bits?

XOR with one inverts the selected bit, while XOR with zero preserves it.

Q9. How do you extract a four-bit field?

field = (value >> position) & 0x0FU;

Q10. Why must a field be cleared before inserting a new value?

Clearing removes the previous field contents so the new value can be inserted without unwanted old bits.

Q11. What is the difference between LSB and MSB?

LSB is the least significant bit at position zero. MSB is the highest-order bit within the selected integer width.

Q12. Where is bit masking used in embedded systems?

It is used for peripheral control, status checking, interrupt flags, communication registers and configuration fields.
