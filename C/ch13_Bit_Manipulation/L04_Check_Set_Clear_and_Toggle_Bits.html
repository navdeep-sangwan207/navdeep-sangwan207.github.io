Lecture 04: Check, Set, Clear and Toggle Bits

Master the four fundamental bit manipulation operations using reusable C functions, practical examples and embedded-system applications.

1. Learning Objectives

  • Understand the purpose of checking, setting, clearing and toggling bits.
  • Implement these operations using bitwise operators.
  • Write reusable C functions for bit manipulation.
  • Validate bit positions before performing shifts.
  • Manipulate multiple bits using combined masks.
  • Manage status flags using bit masks.
  • Understand read-modify-write operations.
  • Apply bit manipulation to embedded systems.
  • Solve placement-oriented coding and output questions.

2. Revision of Bitwise Operators

Bit manipulation operations are built using bitwise AND, OR, XOR, NOT and left shift.

Operator Meaning Purpose
& Bitwise AND Test or clear selected bits
| Bitwise OR Set selected bits
^ Bitwise XOR Toggle selected bits
~ Bitwise NOT Complement all bits
<< Left shift Create bit masks

A single-bit mask for position n is generally created using: 

1U << n

The shift position must be valid for the width of the unsigned type.

3. The Four Fundamental Operations

Operation Expression Function
Check (value & mask) != 0U Determine whether a bit is set
Set value |= mask Make a bit 1
Clear value &= ~mask Make a bit 0
Toggle value ^= mask Invert a bit

These operations are used in operating systems, embedded firmware, device drivers, communication protocols and hardware register programming.

4. Checking Whether a Bit Is Set or Clear

Checking a bit means determining whether its current value is 1 or 0.

Formula

if ((value & (1U << position)) != 0U)
{
    /* Bit is set */
}
else
{
    /* Bit is clear */
}

Example

Value = 13 = 00001101

Check bit 2:

Mask  =       00000100

AND:

                00001101
              & 00000100
              ------------
                00000100

The result is nonzero, so bit 2 is set.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int value = 13U;
    unsigned int position = 2U;

    unsigned int mask = 1U << position;

    if ((value & mask) != 0U)
    {
        printf("Bit is SET\n");
    }
    else
    {
        printf("Bit is CLEAR\n");
    }

    return 0;
}
Output: 
Bit is SET

Check Whether Any Selected Bit Is Set

if ((value & mask) != 0U)
{
    printf("At least one selected bit is set");
}

Check Whether All Selected Bits Are Set

if ((value & mask) == mask)
{
    printf("All selected bits are set");
}
The distinction is important: a nonzero AND result means at least one selected bit is set. Equality with the mask means every bit represented by the mask is set.

5. Setting a Bit

Setting a bit means changing its value to 1, regardless of whether it was previously 0 or 1.

Formula

value |= (1U << position);

Example

Original = 00001001

Mask     = 00000100

OR:

           00001001
         | 00000100
         ------------
           00001101

The value changes from 9 to 13.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int value = 9U;

    unsigned int position = 2U;

    value |= (1U << position);

    printf("Updated value = %u\n", value);

    return 0;
}
Output: 
Updated value = 13

Important Property

Setting an already-set bit does not change the value. 

value = 13U;

value |= (1U << 2U);

/* Value remains 13 */

6. Clearing a Bit

Clearing a bit means forcing its value to 0.

Formula

value &= ~(1U << position);

Example

Original = 00001101

Mask     = 00000100

~Mask    = 11111011

AND:

           00001101
         & 11111011
         ------------
           00001001

The value changes from 13 to 9.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int value = 13U;

    unsigned int position = 2U;

    value &= ~(1U << position);

    printf("Updated value = %u\n", value);

    return 0;
}
Output: 
Updated value = 9

Important Property

Clearing an already-clear bit does not change the value.

7. Toggling a Bit

Toggling means reversing the current value of a selected bit.

Original bit After toggle
0 1
1 0

Formula

value ^= (1U << position);

Example

Original = 00001001

Mask     = 00000010

XOR:

           00001001
         ^ 00000010
         ------------
           00001011

The value changes from 9 to 11.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int value = 9U;

    unsigned int position = 1U;

    value ^= (1U << position);

    printf("Updated value = %u\n", value);

    return 0;
}
Output: 
Updated value = 11

Toggle Twice

Applying XOR with the same mask twice restores the original value. 

value ^= mask;
value ^= mask;

/* Original value is restored */

8. Implementing Reusable Bit Functions

Instead of writing bitwise expressions repeatedly, we can create functions for each operation.

This example uses unsigned int and checks the valid bit position before shifting.

Complete C11 Program

#include <stdio.h>
#include <limits.h>

#define UINT_WIDTH \
    ((unsigned int)(sizeof(unsigned int) * CHAR_BIT))

int valid_position(unsigned int position)
{
    return position < UINT_WIDTH;
}

int check_bit(unsigned int value,
              unsigned int position)
{
    if (!valid_position(position))
    {
        return -1;
    }

    return (value & (1U << position)) != 0U;
}

int set_bit(unsigned int *value,
            unsigned int position)
{
    if (value == NULL || !valid_position(position))
    {
        return 0;
    }

    *value |= (1U << position);

    return 1;
}

int clear_bit(unsigned int *value,
              unsigned int position)
{
    if (value == NULL || !valid_position(position))
    {
        return 0;
    }

    *value &= ~(1U << position);

    return 1;
}

int toggle_bit(unsigned int *value,
               unsigned int position)
{
    if (value == NULL || !valid_position(position))
    {
        return 0;
    }

    *value ^= (1U << position);

    return 1;
}

int main(void)
{
    unsigned int number = 10U;

    printf("Initial value: %u\n", number);

    if (check_bit(number, 1U) == 1)
    {
        printf("Bit 1 is SET\n");
    }
    else
    {
        printf("Bit 1 is CLEAR\n");
    }

    set_bit(&number, 0U);
    printf("After setting bit 0: %u\n", number);

    clear_bit(&number, 1U);
    printf("After clearing bit 1: %u\n", number);

    toggle_bit(&number, 3U);
    printf("After toggling bit 3: %u\n", number);

    return 0;
}
Output: 
Initial value: 10
Bit 1 is SET
After setting bit 0: 11
After clearing bit 1: 9
After toggling bit 3: 1

Understanding the Function Parameters

  • unsigned int value passes a copy of the value for checking.
  • unsigned int *value allows a function to modify the caller's variable.
  • position specifies the zero-based bit position.
  • The return value indicates success or failure for modifying functions.
A pointer is used in set, clear and toggle functions because changes must be reflected in the original variable in the calling function.

9. Setting and Clearing Multiple Bits

We can modify several bits at once by combining individual masks.

Set Bits 0, 2 and 4

unsigned int mask =
    (1U << 0U) |
    (1U << 2U) |
    (1U << 4U);

value |= mask;

Clear Bits 1 and 3

unsigned int mask =
    (1U << 1U) |
    (1U << 3U);

value &= ~mask;

Toggle Bits 0 and 5

unsigned int mask =
    (1U << 0U) |
    (1U << 5U);

value ^= mask;

Check Whether All Selected Bits Are Set

if ((value & mask) == mask)
{
    printf("All selected bits are set\n");
}

Check Whether Any Selected Bit Is Set

if ((value & mask) != 0U)
{
    printf("At least one selected bit is set\n");
}

10. Managing Status Flags

A flag is a bit that represents a particular condition or state.

Instead of using separate variables for many Boolean conditions, multiple flags can be stored in one unsigned integer.

Example: System Status Flags

#include <stdio.h>

#define FLAG_READY      (1U << 0U)
#define FLAG_ERROR      (1U << 1U)
#define FLAG_BUSY       (1U << 2U)
#define FLAG_CONNECTED  (1U << 3U)

int main(void)
{
    unsigned int status = 0U;

    /* Set ready and connected flags */
    status |= FLAG_READY;
    status |= FLAG_CONNECTED;

    /* Check ready flag */
    if ((status & FLAG_READY) != 0U)
    {
        printf("System is ready\n");
    }

    /* Set busy flag */
    status |= FLAG_BUSY;

    /* Clear connected flag */
    status &= ~FLAG_CONNECTED;

    /* Set error flag */
    status |= FLAG_ERROR;

    printf("Status register = 0x%X\n", status);

    return 0;
}
Output: 
System is ready
Status register = 0x7

Why Use Status Flags?

  • Multiple conditions can be stored in one variable.
  • Individual conditions can be checked independently.
  • Multiple flags can be set or cleared together.
  • Memory usage can be reduced compared with separate integer variables.
  • Flags are useful in embedded firmware and operating systems.

11. Practical Embedded Systems Applications

1. GPIO Control

A GPIO output register may contain control bits for several pins. 

/* Illustrative register operations */

GPIO_OUTPUT |= (1U << 5U);   /* Set pin 5 */

GPIO_OUTPUT &= ~(1U << 5U); /* Clear pin 5 */

GPIO_OUTPUT ^= (1U << 5U);  /* Toggle pin 5 */

2. UART Status Checking

A UART status register may contain flags such as transmit-ready, receive-ready and error status. 

#define UART_RX_READY (1U << 0U)
#define UART_TX_READY (1U << 1U)

if ((uart_status & UART_RX_READY) != 0U)
{
    /* Receive data can be processed */
}

if ((uart_status & UART_TX_READY) != 0U)
{
    /* Transmit data can be sent */
}

3. Timer Control

A timer control register may use individual bits for enabling, disabling or selecting timer modes. 

#define TIMER_ENABLE (1U << 0U)

timer_control |= TIMER_ENABLE;

timer_control &= ~TIMER_ENABLE;

4. Interrupt Flags

Peripheral interrupt status registers can contain multiple pending interrupt flags. 

#define INTERRUPT_FLAG_0 (1U << 0U)
#define INTERRUPT_FLAG_1 (1U << 1U)

if ((interrupt_status & INTERRUPT_FLAG_0) != 0U)
{
    /* Handle interrupt source 0 */
}
Hardware register semantics are device-specific. Some interrupt flags are cleared by writing a 1, some by writing a 0, and some are cleared by reading a register. Do not blindly apply ordinary software read-modify-write expressions to hardware registers.

12. Volatile and Read-Modify-Write Operations

Memory-mapped peripheral registers are commonly declared using volatile qualified types. 

volatile unsigned int * const GPIO_REG =
    (volatile unsigned int *)0x40020000U;

An operation such as: 

*GPIO_REG |= (1U << 5U);

is a read-modify-write operation. It reads the register, modifies the value and writes the result.

Important Limitations

  • volatile tells the compiler that accesses are observable and must not be treated as ordinary removable accesses.
  • It does not guarantee atomicity.
  • It does not make an operation safe against concurrent modification.
  • It does not replace hardware memory barriers or synchronization where required.
  • Register-specific access rules must be followed.
In real embedded firmware, use the microcontroller's official register definitions and follow its reference manual. The example address above is illustrative only.

13. Important C Programming Mistakes

Mistake 1: Incorrect Operator Precedence

Incorrect:

if (value & mask == mask)

Correct:

if ((value & mask) == mask)

Parentheses ensure that the bitwise AND operation is evaluated before the comparison.

Mistake 2: Invalid Shift Position

A shift count equal to or greater than the width of the promoted left operand causes undefined behavior.

Validate the position before evaluating the shift expression.

Mistake 3: Using Signed Integers for Masks

Prefer unsigned types for bitwise operations, especially when working with the most significant bit.

Mistake 4: Forgetting the Pointer

Incorrect when the original value must change:

void set_bit(unsigned int value, unsigned int position)
{
    value |= (1U << position);
}

This modifies only a local copy.

Correct approach:

void set_bit(unsigned int *value, unsigned int position)
{
    *value |= (1U << position);
}

Mistake 5: Using OR to Replace a Field

OR alone cannot reliably replace a field containing old set bits. Clear the field before inserting its new value.

14. Placement-Oriented Coding Problems

Problem 1: Check Whether a Number Is Even or Odd Using Bits

The least significant bit determines whether an integer is even or odd. 

#include <stdio.h>

int main(void)
{
    unsigned int number = 27U;

    if ((number & 1U) != 0U)
    {
        printf("Odd");
    }
    else
    {
        printf("Even");
    }

    return 0;
}
Output: 
Odd

Problem 2: Check Whether a Number Is a Power of Two

A positive power of two contains exactly one set bit. 

#include <stdio.h>

int main(void)
{
    unsigned int number = 32U;

    if (number != 0U &&
        (number & (number - 1U)) == 0U)
    {
        printf("Power of two");
    }
    else
    {
        printf("Not a power of two");
    }

    return 0;
}
Output: 
Power of two

Problem 3: Count Set Bits

Brian Kernighan's algorithm repeatedly clears the lowest set bit. 

#include <stdio.h>

int main(void)
{
    unsigned int number = 29U;
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= (number - 1U);
        count++;
    }

    printf("Set bits = %u\n", count);

    return 0;
}
Output: 
Set bits = 4

Problem 4: Clear the Lowest Set Bit

#include <stdio.h>

int main(void)
{
    unsigned int number = 28U;

    number &= (number - 1U);

    printf("Result = %u\n", number);

    return 0;
}
Output: 
Result = 24

Problem 5: Find Whether Two Numbers Have Different Bits

XOR identifies bit positions where two values differ. 

#include <stdio.h>

int main(void)
{
    unsigned int a = 12U;
    unsigned int b = 10U;

    unsigned int difference = a ^ b;

    if (difference != 0U)
    {
        printf("Numbers have different bit patterns");
    }
    else
    {
        printf("Bit patterns are identical");
    }

    return 0;
}
Output: 
Numbers have different bit patterns

15. Time and Space Complexity

Operation Time Complexity Extra Space
Check one bit O(1) O(1)
Set one bit O(1) O(1)
Clear one bit O(1) O(1)
Toggle one bit O(1) O(1)
Check all bits in a fixed-width integer O(1) O(1)
Count set bits using Kernighan's algorithm O(k) O(1)

Here, k represents the number of set bits in the integer. For a fixed-width integer, k is bounded by that width.

16. Technical Interview Questions

Q1. What is the difference between setting and toggling a bit?

Setting always makes the selected bit 1. Toggling reverses its current value.

Q2. Which operator is used to clear a bit?

Bitwise AND with the complement of the required mask.

Q3. How do you check whether a bit is clear?

(value & mask) == 0U

Q4. What happens if you toggle a bit twice?

The original bit value is restored.

Q5. How do you check whether all selected bits are set?

(value & mask) == mask

Q6. How do you check whether any selected bit is set?

(value & mask) != 0U

Q7. Why are pointers used in modifying functions?

Passing a pointer allows the function to modify the original variable instead of modifying only a copy.

Q8. What is a status flag?

A status flag is a bit representing a condition or state, such as ready, busy or error.

Q9. Is a volatile read-modify-write operation atomic?

No. Volatile does not guarantee atomicity. Additional synchronization or hardware-specific operations may be necessary.

Q10. Why is bit manipulation important in embedded C?

It allows firmware to control individual hardware features, inspect peripheral status and configure registers efficiently.
