2. Quick Revision of Bitwise Operators

Operator Name Purpose
& Bitwise AND Set bits present in both operands
| Bitwise OR Set bits present in either operand
^ Bitwise XOR Set bits where operands differ
~ Bitwise NOT Invert every bit
<< Left shift Shift bits towards higher positions
>> Right shift Shift bits towards lower positions

Example

unsigned int a = 12U;
unsigned int b = 10U;

a & b = 8
a | b = 14
a ^ b = 6
Bit positions are counted from right to left, starting at position 0.

3. Problem 1: Check Whether a Number Is Odd or Even Using Bits

Concept

The least significant bit determines whether an integer is odd or even.

  • Even number: least significant bit is 0.
  • Odd number: least significant bit is 1.

Logic

if ((number & 1U) == 0U)
{
    /* Even */
}
else
{
    /* Odd */
}

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 17U;

    if ((number & 1U) == 0U)
    {
        printf("Even number\n");
    }
    else
    {
        printf("Odd number\n");
    }

    return 0;
}
Output: 
Odd number

Complexity: O(1) time and O(1) space.

4. Problem 2: Check Whether the K-th Bit Is Set

Concept

A bit mask can identify a specific bit position. 

mask = 1U << k;

Use bitwise AND to check whether that position is set.

C11 Program

#include <stdio.h>
#include <limits.h>

int is_bit_set(unsigned int number, unsigned int k)
{
    if (k >= sizeof(number) * CHAR_BIT)
    {
        return 0;
    }

    return (number & (1U << k)) != 0U;
}

int main(void)
{
    unsigned int number = 10U;
    unsigned int position = 1U;

    if (is_bit_set(number, position))
    {
        printf("Bit %u is set\n", position);
    }
    else
    {
        printf("Bit %u is not set\n", position);
    }

    return 0;
}
Output: 
Bit 1 is set

Binary representation of 10: 

10 = 1010

Bit 3 = 1
Bit 2 = 0
Bit 1 = 1
Bit 0 = 0
A shift count greater than or equal to the width of the promoted left operand causes undefined behavior. Always validate the bit position.

5. Problem 3: Set the K-th Bit

Setting a bit means making the selected bit equal to 1 without changing the other bits.

Formula

number = number | (1U << k);

C11 Program

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int number = 8U;
    unsigned int k = 1U;

    if (k >= sizeof(number) * CHAR_BIT)
    {
        return 1;
    }

    number |= (1U << k);

    printf("Result = %u\n", number);

    return 0;
}
Output: 
Result = 10

Toggling means changing:

8. Problem 6: Count the Number of Set Bits

Problem Statement

Count how many bits are equal to 1 in the binary representation of an unsigned integer.

Example

Number = 13

Binary = 1101

Set bits = 3

Method 1: Check Every Bit

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        count += number & 1U;
        number >>= 1U;
    }

    return count;
}

int main(void)
{
    unsigned int number = 13U;

    printf("Set bits = %u\n",
           count_set_bits(number));

    return 0;
}
Output: 
Set bits = 3

Method 2: Brian Kernighan's Algorithm

This algorithm repeatedly clears the rightmost set bit. 

number = number & (number - 1U);

Each iteration removes one set bit.

C11 Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= number - 1U;
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int number = 29U;

    printf("Set bits = %u\n",
           count_set_bits(number));

    return 0;
}
Output: 
Set bits = 4

Complexity

  • Method 1: O(w), where w is the width of unsigned int.
  • Method 2: O(k), where k is the number of set bits.
  • Auxiliary space: O(1).

9. Problem 7: Check Whether a Number Is a Power of Two

Concept

A positive power of two has exactly one set bit in its binary representation.

Number Binary Power of Two?
20010Yes
40100Yes
81000Yes
101010No
121100No

Formula

number != 0U &&
(number & (number - 1U)) == 0U

C11 Program

#include <stdio.h>

int is_power_of_two(unsigned int number)
{
    return number != 0U &&
           (number & (number - 1U)) == 0U;
}

int main(void)
{
    unsigned int number = 32U;

    if (is_power_of_two(number))
    {
        printf("Power of two\n");
    }
    else
    {
        printf("Not a power of two\n");
    }

    return 0;
}
Output: 
Power of two

Complexity: O(1) time and O(1) space.

10. Problem 8: Check Whether Two Numbers Differ by Exactly One Bit

Concept

XOR identifies all bit positions where two values differ.

If the XOR result contains exactly one set bit, the original values differ in exactly one bit position.

Formula

difference = a ^ b;

difference != 0U &&
(difference & (difference - 1U)) == 0U

C11 Program

#include <stdio.h>

int differ_by_one_bit(unsigned int a,
                      unsigned int b)
{
    unsigned int difference = a ^ b;

    return difference != 0U &&
           (difference & (difference - 1U)) == 0U;
}

int main(void)
{
    unsigned int a = 8U;
    unsigned int b = 10U;

    if (differ_by_one_bit(a, b))
    {
        printf("Exactly one bit differs\n");
    }
    else
    {
        printf("More than one bit differs or values are equal\n");
    }

    return 0;
}
Output: 
Exactly one bit differs

11. Problem 9: Find the Unique Element Using XOR

Problem Statement

Every array element appears exactly twice except one element. Find that element without using an additional frequency array.

C11 Program

#include <stdio.h>

int find_unique(const int array[], int size)
{
    int result = 0;

    for (int i = 0; i < size; i++)
    {
        result ^= array[i];
    }

    return result;
}

int main(void)
{
    int array[] = {6, 3, 8, 3, 6};

    int size = (int)(sizeof(array) / sizeof(array[0]));

    printf("Unique element = %d\n",
           find_unique(array, size));

    return 0;
}
Output: 
Unique element = 8

Complexity: O(n) time and O(1) auxiliary space.

12. Problem 10: Reverse the Bits of an Unsigned Integer

Concept

Bit reversal rearranges all bits so that the least significant bit becomes the most significant bit, and vice versa.

The following implementation reverses all bits in an unsigned int, including leading zero bits.

C11 Program

#include <stdio.h>
#include <limits.h>

unsigned int reverse_bits(unsigned int number)
{
    unsigned int result = 0U;

    for (unsigned int i = 0U;
         i < sizeof(number) * CHAR_BIT;
         i++)
    {
        result <<= 1U;
        result |= number & 1U;
        number >>= 1U;
    }

    return result;
}

int main(void)
{
    unsigned int number = 13U;

    printf("Original number = %u\n", number);
    printf("Reversed bit value = %u\n",
           reverse_bits(number));

    return 0;
}
Output on a system with 32-bit unsigned int: 
Original number = 13
Reversed bit value = 2952790016
The numeric output depends on the width of unsigned int. The program reverses the full width of that type, not just the significant bits of the original number.

13. Problem 11: Find the XOR of a Range Using Prefix XOR

Concept

Prefix XOR stores the cumulative XOR of array elements from index 0 to the current index. 

prefix[i] = array[0] ^ array[1] ^ ... ^ array[i]

The XOR of a range from index L to R can be obtained as follows: 

range_xor(L, R) =
    prefix[R] ^ prefix[L - 1]

For L equal to zero, the answer is simply prefix[R].

C11 Program

#include <stdio.h>

void build_prefix_xor(const unsigned int array[],
                      unsigned int prefix[],
                      unsigned int size)
{
    prefix[0] = array[0];

    for (unsigned int i = 1U; i < size; i++)
    {
        prefix[i] = prefix[i - 1U] ^ array[i];
    }
}

unsigned int range_xor(const unsigned int prefix[],
                       unsigned int left,
                       unsigned int right)
{
    if (left == 0U)
    {
        return prefix[right];
    }

    return prefix[right] ^ prefix[left - 1U];
}

int main(void)
{
    unsigned int array[] = {2U, 4U, 6U, 8U, 10U};
    unsigned int prefix[5];

    build_prefix_xor(array, prefix, 5U);

    printf("Range XOR = %u\n",
           range_xor(prefix, 1U, 3U));

    return 0;
}
Output: 
Range XOR = 10

Calculation: 

4 ^ 6 ^ 8 = 10

Complexity

  • Prefix construction: O(n).
  • Each range query: O(1).
  • Additional storage: O(n).
The example assumes a non-empty array and valid range indices satisfying left <= right < size. A reusable production function should validate these conditions.

14. Problem 12: Find the Maximum XOR of Two Array Elements

Problem Statement

Given an array of non-negative integers, find the maximum XOR value produced by any pair of distinct array positions.

Example

Array = {3, 10, 5, 25, 2, 8}

Maximum XOR = 28

5 ^ 25 = 28

Basic C11 Solution

#include <stdio.h>

unsigned int maximum_pair_xor(const unsigned int array[],
                              unsigned int size)
{
    unsigned int maximum = 0U;

    for (unsigned int i = 0U; i < size; i++)
    {
        for (unsigned int j = i + 1U; j < size; j++)
        {
            unsigned int current = array[i] ^ array[j];

            if (current > maximum)
            {
                maximum = current;
            }
        }
    }

    return maximum;
}

int main(void)
{
    unsigned int array[] = {3U, 10U, 5U, 25U, 2U, 8U};

    unsigned int size =
        (unsigned int)(sizeof(array) / sizeof(array[0]));

    printf("Maximum pair XOR = %u\n",
           maximum_pair_xor(array, size));

    return 0;
}
Output: 
Maximum pair XOR = 28

Complexity Analysis

  • Time complexity: O(n²).
  • Auxiliary space: O(1).
For larger arrays, a binary trie can improve the approach by searching for values that maximize differing high-order bits. This is an important advanced coding-round technique.

17. Frequently Asked Technical Interview Questions

Q1. What is bit manipulation?

Bit manipulation means directly operating on individual bits using bitwise operators and shifts.

Q2. What is a bit mask?

A bit mask is a value used with bitwise operations to select or modify particular bit positions.

Q3. How do you set a particular bit?

number |= (1U << position);

Q4. How do you clear a particular bit?

number &= ~(1U << position);

Q5. How do you toggle a particular bit?

number ^= (1U << position);

Q6. How do you check whether a number is odd?

(number & 1U) != 0U

Q7. What is Brian Kernighan's algorithm?

It counts set bits by repeatedly clearing the rightmost set bit using n & (n - 1).

Q8. How can you check a power of two?

n != 0U && (n & (n - 1U)) == 0U

Q9. Why is XOR used to find a unique element?

Because equal values cancel each other when XORed.

Q10. What is the difference between logical and bitwise operators?

Logical operators operate on truth values and produce 0 or 1. Bitwise operators operate on individual bits of integer operands.

Q11. What is the use of prefix XOR?

It supports efficient XOR queries over array ranges after O(n) preprocessing.

Q12. Why should shift positions be validated?

A shift count greater than or equal to the width of the promoted left operand results in undefined behavior.

Q13. What is the use of bit manipulation in embedded systems?

It is used for configuring registers, controlling peripheral bits, checking status flags and handling hardware control fields.

Q14. What is the difference between arithmetic and logical right shift?

A logical right shift inserts zeros into the high-order positions. An arithmetic right shift typically replicates the sign bit. In C11, right-shifting a negative signed integer has implementation-defined behavior, so unsigned operands are preferable for portable bit operations.

Q15. What is the difference between a bit field and a bit mask?

A bit field is a structure member declared with a specified number of bits. A bit mask is an integer value used to select or manipulate bits.
