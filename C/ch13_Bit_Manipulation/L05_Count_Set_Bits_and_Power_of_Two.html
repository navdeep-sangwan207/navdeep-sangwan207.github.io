Lecture 05: Count Set Bits and Power of Two

Learn efficient algorithms to count the number of set bits, identify powers of two and solve important bit manipulation coding problems.

2. What Are Set Bits?

A set bit is a binary digit whose value is 1. A clear bit is a binary digit whose value is 0.

Example

Decimal value = 13

Binary representation:

00001101

The binary representation contains three set bits.

Bit position Bit value State
0 1 Set
1 0 Clear
2 1 Set
3 1 Set
Counting set bits is also called population count or popcount. It is a common operation in algorithms, embedded programming, cryptography and computer architecture.

3. Counting Set Bits Using a Simple Loop

One straightforward approach is to examine every bit using the bitwise AND operator and then shift the number right.

Algorithm

  1. Initialize a counter to zero.
  2. Check the least significant bit using number & 1U.
  3. If the bit is 1, increment the counter.
  4. Shift the number right by one position.
  5. Repeat until the number becomes zero.

Pseudocode

count = 0

while number != 0
    if number & 1
        count++

    number = number >> 1

C11 Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        if ((number & 1U) != 0U)
        {
            count++;
        }

        number >>= 1U;
    }

    return count;
}

int main(void)
{
    unsigned int number = 13U;

    printf("Number = %u\n", number);

    printf("Set bits = %u\n",
           count_set_bits(number));

    return 0;
}
Output: 
Number = 13
Set bits = 3

Dry Run

Consider number = 13.

Iteration Current number LSB Counter
1 1101 1 1
2 110 0 1
3 11 1 2
4 1 1 3

Final count = 3.

Complexity

  • Time complexity: O(w), where w is the number of bits processed.
  • Auxiliary space: O(1).

4. Brian Kernighan's Algorithm

Brian Kernighan's algorithm is an efficient technique for counting set bits.

It repeatedly removes the lowest set bit instead of checking every bit position.

Important Expression

number = number & (number - 1U);

This expression clears the rightmost set bit of an unsigned integer.

Why Does It Work?

Consider the binary number 12: 

12 = 00001100

11 = 00001011

Perform AND:

  00001100
& 00001011
------------
  00001000

The lowest set bit has been removed.

Step-by-Step Example

Count set bits in 13.

Initial:

13 = 00001101

First iteration:

13 & 12

00001101
& 00001100
------------
00001100

Result = 12

Second iteration:

12 & 11

00001100
& 00001011
------------
00001000

Result = 8

Third iteration:

8 & 7

00001000
& 00000111
------------
00000000

Result = 0

The loop executes three times. Therefore, the number contains three set bits.

C11 Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= (number - 1U);
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int number = 13U;

    printf("Set bits = %u\n",
           count_set_bits(number));

    return 0;
}
Output: 
Set bits = 3
The number of loop iterations equals the number of set bits in the input.

5. Comparing Set-Bit Counting Algorithms

Algorithm Time Complexity Key Idea
Simple right-shift loop O(w) Check every processed bit
Brian Kernighan's algorithm O(k) Remove one set bit per iteration

Here:

  • w = number of bits in the integer representation.
  • k = number of set bits.

For a fixed-width integer, both algorithms have bounded execution time. Kernighan's algorithm is particularly useful when the number contains relatively few set bits.

Do not describe Kernighan's algorithm as always faster in every practical situation. Actual performance depends on processor instructions, compiler optimization, input data and implementation.

6. Checking Whether a Number Is a Power of Two

A positive power of two has exactly one set bit in its binary representation.

Examples

Number Binary Power of Two?
1 00000001 Yes (2⁰)
2 00000010 Yes (2¹)
4 00000100 Yes (2²)
8 00001000 Yes (2³)
16 00010000 Yes (2⁴)
12 00001100 No
18 00010010 No

Important Formula

number != 0U &&
(number & (number - 1U)) == 0U

The expression removes the lowest set bit. If the original number had exactly one set bit, the result becomes zero.

The nonzero condition is essential because zero also satisfies the second expression but is not a power of two.

C11 Program

#include <stdio.h>

int is_power_of_two(unsigned int number)
{
    return number != 0U &&
           (number & (number - 1U)) == 0U;
}

int main(void)
{
    unsigned int number = 32U;

    if (is_power_of_two(number))
    {
        printf("%u is a power of two\n", number);
    }
    else
    {
        printf("%u is not a power of two\n", number);
    }

    return 0;
}
Output: 
32 is a power of two

Complexity

  • Time complexity: O(1).
  • Auxiliary space: O(1).

The expression uses a fixed number of integer operations.

7. Power of Two Using a Loop

Another approach repeatedly divides the number by two.

Algorithm

  1. Reject zero.
  2. Check whether the number is divisible by two.
  3. Divide it by two while it remains even.
  4. If the final value is one, it is a power of two.

C11 Program

#include <stdio.h>

int is_power_of_two(unsigned int number)
{
    if (number == 0U)
    {
        return 0;
    }

    while ((number % 2U) == 0U)
    {
        number /= 2U;
    }

    return number == 1U;
}

int main(void)
{
    unsigned int number = 64U;

    if (is_power_of_two(number))
    {
        printf("Power of two");
    }
    else
    {
        printf("Not a power of two");
    }

    return 0;
}
Output: 
Power of two

Time complexity is O(log n) for a positive input, while auxiliary space is O(1).

8. Finding the Lowest Set Bit

The lowest set bit is the rightmost bit whose value is 1.

Example

Number = 40

Binary = 00101000

Lowest set bit:

       00001000

Value = 8

Method 1: Using Two's Complement Identity

lowest_set_bit = number & (~number + 1U);

For unsigned integers, this expression isolates the lowest set bit.

Method 2: Using Unsigned Arithmetic

lowest_set_bit = number & (0U - number);

Unsigned arithmetic is defined modulo one more than the maximum value of the unsigned type.

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 40U;

    if (number != 0U)
    {
        unsigned int lowest =
            number & (0U - number);

        printf("Lowest set bit value = %u\n", lowest);
    }
    else
    {
        printf("No set bit exists\n");
    }

    return 0;
}
Output: 
Lowest set bit value = 8

9. Finding the Position of the Lowest Set Bit

We can determine the zero-based position of the lowest set bit by shifting the number until its least significant bit becomes 1.

C11 Program

#include <stdio.h>

int lowest_set_bit_position(unsigned int number)
{
    int position = 0;

    if (number == 0U)
    {
        return -1;
    }

    while ((number & 1U) == 0U)
    {
        number >>= 1U;
        position++;
    }

    return position;
}

int main(void)
{
    unsigned int number = 40U;

    int position =
        lowest_set_bit_position(number);

    printf("Position = %d\n", position);

    return 0;
}
Output: 
Position = 3

The binary representation of 40 is 00101000. Its lowest set bit is at position 3.

Time complexity: O(w), where w is the number of bits in the integer. Auxiliary space: O(1).

10. Checking Whether a Number Has Exactly One Set Bit

A positive integer has exactly one set bit if and only if it is a power of two.

C11 Program

#include <stdio.h>

int has_exactly_one_set_bit(unsigned int number)
{
    return number != 0U &&
           (number & (number - 1U)) == 0U;
}

int main(void)
{
    unsigned int numbers[] = {1U, 4U, 7U, 8U, 12U, 16U};

    unsigned int count =
        sizeof(numbers) / sizeof(numbers[0]);

    for (unsigned int i = 0U; i < count; i++)
    {
        printf("%u: %s\n",
               numbers[i],
               has_exactly_one_set_bit(numbers[i])
                   ? "Exactly one set bit"
                   : "Not exactly one set bit");
    }

    return 0;
}
Output: 
1: Exactly one set bit
4: Exactly one set bit
7: Not exactly one set bit
8: Exactly one set bit
12: Not exactly one set bit
16: Exactly one set bit

11. Finding Whether Two Numbers Have the Same Set-Bit Count

Two integers can have different binary representations but the same number of set bits.

Example

A = 9  = 00001001

B = 10 = 00001010

Both values contain two set bits.

C11 Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= number - 1U;
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int a = 9U;
    unsigned int b = 10U;

    if (count_set_bits(a) == count_set_bits(b))
    {
        printf("Same number of set bits\n");
    }
    else
    {
        printf("Different number of set bits\n");
    }

    return 0;
}
Output: 
Same number of set bits

12. Counting Set Bits in an Array

In coding rounds, the problem may require counting set bits for every element in an array.

C11 Program

#include <stdio.h>

unsigned int count_set_bits(unsigned int number)
{
    unsigned int count = 0U;

    while (number != 0U)
    {
        number &= number - 1U;
        count++;
    }

    return count;
}

int main(void)
{
    unsigned int numbers[] = {3U, 7U, 8U, 15U, 16U};

    unsigned int size =
        sizeof(numbers) / sizeof(numbers[0]);

    for (unsigned int i = 0U; i < size; i++)
    {
        printf("%u has %u set bits\n",
               numbers[i],
               count_set_bits(numbers[i]));
    }

    return 0;
}
Output: 
3 has 2 set bits
7 has 3 set bits
8 has 1 set bits
15 has 4 set bits
16 has 1 set bits

Complexity

If there are n array elements and each element has at most w bits, the worst-case time complexity is O(n × w). Auxiliary space is O(1), excluding the input array.

13. Using Compiler Built-in Functions

Some compilers provide built-in functions to count set bits.

GCC Example

#include <stdio.h>

int main(void)
{
    unsigned int number = 29U;

    int count = __builtin_popcount(number);

    printf("Set bits = %d\n", count);

    return 0;
}
Output: 
Set bits = 4

Important Built-ins

Function Purpose
__builtin_popcount Count set bits in unsigned int
__builtin_popcountl Count set bits in unsigned long
__builtin_popcountll Count set bits in unsigned long long
These are GCC/Clang compiler extensions, not standard C11 library functions. Use a portable implementation when compiler independence is required.

14. Common Mistakes

1. Forgetting the Zero Check

Zero is not a power of two. 

/* Correct */
number != 0U &&
(number & (number - 1U)) == 0U

2. Using Signed Integers for Bit Manipulation

Unsigned integers provide predictable modulo arithmetic and avoid several signed-shift problems.

3. Incorrectly Counting Bits

Ensure the counter increments only when the examined bit is actually 1.

4. Confusing Set-Bit Count with Bit Width

A 32-bit integer does not necessarily contain 32 set bits. Its set-bit count can range from zero to 32.

5. Modifying the Original Input Accidentally

Both counting algorithms above shift or modify their local parameter. The original caller's variable remains unchanged because the value is passed by value.

16. Technical Interview Questions

Q1. What is a set bit?

A set bit is a bit whose binary value is 1.

Q2. What is population count?

It is the number of set bits in an integer's binary representation.

Q3. What does n & (n - 1) do?

For an unsigned integer n, it clears the lowest set bit.

Q4. Explain Brian Kernighan's algorithm.

It repeatedly clears the lowest set bit and increments a counter until the number becomes zero.

Q5. Why does Brian Kernighan's algorithm use O(k) time?

Each iteration removes exactly one set bit. Therefore, it performs k iterations for k set bits.

Q6. How do you check whether a number is a power of two?

n != 0U && (n & (n - 1U)) == 0U

Q7. Why must zero be excluded?

Zero contains no set bits and is not equal to 2 raised to any nonnegative integer power.

Q8. What is popcount?

Popcount is the number of 1 bits in a binary representation.

Q9. How do you isolate the lowest set bit?

n & (0U - n)

Q10. What is the difference between O(w) and O(k)?

O(w) processes the bit width, whereas O(k) performs one iteration for each set bit.

Q11. Is __builtin_popcount() standard C11?

No. It is a compiler extension supported by GCC and Clang.

Q12. Where is population count useful?

It is useful in bitmaps, permission masks, error detection, embedded firmware, data compression and algorithmic problems.
