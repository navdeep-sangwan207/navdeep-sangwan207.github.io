Lecture 02: Left and Right Bit Shifting

Understand how integer bits move left and right, how shift operators work in C, and how they are used in coding problems and embedded systems.

1. Learning Objectives

  • Understand the left shift operator (<<).
  • Understand the right shift operator (>>).
  • Trace binary values after shifting.
  • Understand shift operations on unsigned integers.
  • Understand signed right-shift behavior.
  • Use shifting for powers of two and bit masks.
  • Identify invalid shift operations.
  • Solve shift-based output-prediction problems.
  • Apply shift operators in embedded programming.

2. Introduction to Bit Shifting

Bit shifting is an operation that moves the binary digits of an integer toward the left or right by a specified number of positions.

C provides two shift operators:

Operator Name Purpose
<< Left Shift Moves bits toward higher positions.
>> Right Shift Moves bits toward lower positions.

General Syntax

result = number << positions;

result = number >> positions;

The left operand is the value whose bits are shifted. The right operand specifies the number of positions.

3. Left Shift Operator (<<)

The left shift operator moves the bits of its left operand toward higher bit positions.

Vacated positions on the right are filled with zero bits.

Example: Shift 5 Left by One Position

Original value:

00000101

Shift left by 1:

00001010

Decimal result = 10

Therefore: 

5 << 1 = 10

Example: Shift 5 Left by Two Positions

Original:

00000101

After first shift:

00001010

After second shift:

00010100

Decimal result = 20
5 << 2 = 20

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 5U;

    printf("Original value = %u\n", a);
    printf("Left shift by 1 = %u\n", a << 1);
    printf("Left shift by 2 = %u\n", a << 2);
    printf("Left shift by 3 = %u\n", a << 3);

    return 0;
}
Output: 
Original value = 5
Left shift by 1 = 10
Left shift by 2 = 20
Left shift by 3 = 40
For an unsigned integer, shifting left by one position corresponds to multiplication by 2 when the mathematical result is representable in the unsigned type.

4. Mathematical Interpretation of Left Shift

For an unsigned value x and a valid shift count n, left shifting corresponds to multiplication by 2 to the power n, with the result reduced modulo one more than the maximum value of the unsigned type. 

x << n

Equivalent mathematical idea:

x × 2ⁿ

Examples

Expression Calculation Result
3 << 1 3 × 2 6
3 << 2 3 × 4 12
4 << 3 4 × 8 32
6 << 2 6 × 4 24
Do not assume that left shifting a signed integer is always equivalent to multiplication. Signed left-shift operations have additional constraints in C and can produce undefined behavior.

5. Right Shift Operator (>>)

The right shift operator moves bits toward lower bit positions.

Right Shift of an Unsigned Integer

For unsigned integers, vacated positions on the left are filled with zeros.

Example: Shift 20 Right by One Position

Original:

00010100

Shift right by 1:

00001010

Decimal result = 10
20 >> 1 = 10

Example: Shift 20 Right by Two Positions

Original:

00010100

After first shift:

00001010

After second shift:

00000101

Decimal result = 5
20 >> 2 = 5

C Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 20U;

    printf("Original value = %u\n", a);
    printf("Right shift by 1 = %u\n", a >> 1);
    printf("Right shift by 2 = %u\n", a >> 2);
    printf("Right shift by 3 = %u\n", a >> 3);

    return 0;
}
Output: 
Original value = 20
Right shift by 1 = 10
Right shift by 2 = 5
Right shift by 3 = 2

6. Mathematical Interpretation of Right Shift

For an unsigned integer, right shifting by n positions is equivalent to integer division by 2 to the power n. 

x >> n

Equivalent mathematical idea:

floor(x / 2ⁿ)

Examples

Expression Calculation Result
20 >> 1 20 / 2 10
20 >> 2 20 / 4 5
25 >> 1 25 / 2 12
31 >> 2 31 / 4 7

Fractional portions are discarded in unsigned right-shift operations.

7. Left Shift vs Right Shift

Left Shift Right Shift
<< >>
Moves bits toward higher positions. Moves bits toward lower positions.
Vacated right positions become zero. For unsigned values, vacated left positions become zero.
Unsigned values can scale by powers of two, modulo the type range. Unsigned values are divided by powers of two, discarding remainders.
Used to construct masks and position bit fields. Used to extract fields and process bit patterns.

8. Signed and Unsigned Right Shift

One important C interview topic is the difference between shifting signed and unsigned integer values.

Unsigned Right Shift

Unsigned right shift always fills the vacated high-order bits with zero. 

unsigned int value = 20U;

unsigned int result = value >> 2;

Result:

20 >> 2 = 5

Signed Right Shift

For a negative signed integer, right shifting is implementation-defined in C.

A common implementation performs an arithmetic right shift, copying the sign bit into the vacated high-order positions.

However, this behavior must not be assumed in portable C code.

For portable bit manipulation, prefer unsigned integer operands. Do not rely on the behavior of right shifting negative signed values.

9. Integer Promotions and Shift Counts

Before a shift operation is performed, integer promotions are applied to the operands.

The type and width of the promoted left operand determine the valid range of the shift count.

Example

unsigned char value = 1U;

unsigned int result = value << 3;

The unsigned char operand is promoted to int on implementations where int can represent all values of unsigned char. The shift is performed using the promoted type.

Invalid Shift Counts

unsigned int value = 1U;

value << 32;  /* Undefined if unsigned int is 32 bits */

value >> 32;  /* Undefined if unsigned int is 32 bits */

value << -1;  /* Undefined behavior */
The shift count must be nonnegative and smaller than the width of the promoted left operand. Otherwise, the behavior is undefined.

10. Using Left Shift to Generate Bit Masks

Left shift is commonly used to generate a mask containing a single set bit.

Syntax

unsigned int mask = 1U << position;

Examples

Expression Binary Pattern in 8 Bits Decimal Value
1U << 0 00000001 1
1U << 1 00000010 2
1U << 2 00000100 4
1U << 3 00001000 8
1U << 4 00010000 16
1U << 5 00100000 32

C Program

#include <stdio.h>

int main(void)
{
    unsigned int position = 4U;

    unsigned int mask = 1U << position;

    printf("Mask = %u\n", mask);

    return 0;
}
Output: 
Mask = 16

This mask can be used in later operations to set, clear or test bit position 4.

11. Extracting Bits Using Right Shift and AND

Right shift can move a selected bit into the least significant position. AND with 1 extracts that bit.

Formula

bit = (number >> position) & 1U;

Example

number = 13

Binary = 1101

Extract bit position 2:

1101 >> 2 = 0011

0011 & 0001 = 0001

Extracted bit = 1

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 13U;
    unsigned int position = 2U;

    unsigned int bit =
        (number >> position) & 1U;

    printf("Bit at position %u = %u\n",
           position, bit);

    return 0;
}
Output: 
Bit at position 2 = 1

12. Display Binary Representation Using Right Shift

Problem Statement

Write a C program to display the binary representation of an unsigned integer.

Approach

  1. Determine the number of bits in unsigned int.
  2. Start from the most significant bit.
  3. Right shift the number to the selected position.
  4. Use AND with 1U to extract the bit.
  5. Print the extracted bit.

C11 Program

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int number = 25U;

    unsigned int width =
        (unsigned int)(sizeof number * CHAR_BIT);

    for (unsigned int i = width; i > 0U; i--)
    {
        unsigned int position = i - 1U;

        unsigned int bit =
            (number >> position) & 1U;

        printf("%u", bit);
    }

    printf("\n");

    return 0;
}
Output on a system with 32-bit unsigned int: 
00000000000000000000000000011001
This program uses CHAR_BIT and sizeof to determine the width of unsigned int instead of assuming that it is always 32 bits.

13. Swap Two Values Using Bit Shifting?

Shift operations are sometimes incorrectly suggested as a replacement for swapping two values.

Shifting generally loses bits and does not preserve both original values. XOR has a separate swap trick, covered in Lecture 06.

Do not use left and right shifts as a general method to swap two integer variables.

14. Shift-Based Coding Problem: Multiply by a Power of Two

Problem Statement

Multiply an unsigned integer by 8 using a left shift.

Logic

8 = 2³

number × 8

number << 3

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int number = 7U;

    unsigned int result = number << 3;

    printf("Result = %u\n", result);

    return 0;
}
Output: 
Result = 56

This operation is equivalent to multiplication by 8 modulo the range of unsigned int.

16. Embedded Systems Application: Extract a Register Field

Problem Statement

Assume a hardware status register contains a four-bit status field starting at bit position 4.

Extract the four-bit field using right shift and AND.

Logic

unsigned int field =
    (register_value >> 4U) & 0x0FU;

Example C Program

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint32_t register_value = 0x000000B0U;

    uint32_t field =
        (register_value >> 4U) & 0x0FU;

    printf("Register = 0x%08X\n",
           (unsigned int)register_value);

    printf("Extracted field = 0x%X\n",
           (unsigned int)field);

    return 0;
}
Output: 
Register = 0x000000B0
Extracted field = 0xB

This technique is useful when reading peripheral status registers, configuration registers and communication control fields.

17. Common Errors in Shift Operations

Error 1: Negative Shift Count

unsigned int x = 5U;

x << -1;

This produces undefined behavior.

Error 2: Shift Count Equal to Type Width

unsigned int x = 5U;

x >> 32;

If unsigned int has width 32, the shift count is invalid and the behavior is undefined.

Error 3: Signed Left Shift Overflow

int x = 1;

int result = x << 31;

This is not a portable signed arithmetic operation. If the mathematical result cannot be represented in the signed result type, behavior is undefined.

Error 4: Assuming Negative Right Shift Is Portable

int x = -8;

int result = x >> 1;

The result is implementation-defined. Do not rely on a particular answer in portable C code.

Error 5: Using Signed Types for Masks

Signed integer representations and conversions can make bit-level expressions harder to reason about. Prefer unsigned operands for masks and shifts.

19. Technical Interview Questions

Q1. What is left shifting?

Left shifting moves the bits of an integer toward higher bit positions.

Q2. What is right shifting?

Right shifting moves the bits toward lower bit positions.

Q3. What is the result of x << 1 for unsigned x?

It is equivalent to multiplying x by 2 modulo the range of the unsigned result type.

Q4. What is the result of x >> 1 for unsigned x?

It is equivalent to integer division by 2, discarding the remainder.

Q5. What happens to the rightmost bits during left shift?

Vacated low-order bit positions are filled with zeros.

Q6. What happens to the leftmost bits during unsigned right shift?

Vacated high-order positions are filled with zeros.

Q7. Is right shifting a negative signed integer portable?

No. The result is implementation-defined.

Q8. What happens if the shift count is negative?

The behavior is undefined.

Q9. What happens if the shift count is equal to the operand width?

The behavior is undefined.

Q10. Why is left shift used in bit masking?

It moves a single set bit to the required bit position to create a mask.

Q11. Why are unsigned types preferred for bit shifting?

Unsigned shifts have clearer, well-defined behavior and avoid several complications associated with signed integer operations.

Q12. How is a bit extracted using right shift?

Use: 

(number >> position) & 1U
