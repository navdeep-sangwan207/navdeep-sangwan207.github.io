Understand XOR properties and solve common placement coding problems using efficient bitwise techniques in C.

2. What Is the XOR Operator?

XOR stands for Exclusive OR. It is a bitwise operator represented by the symbol ^ in C.

XOR produces 1 when the two corresponding bits are different. It produces 0 when they are the same.

XOR Truth Table

A B A ^ B
000
011
101
110

Example

  0101
^ 0011
------
  0110

The decimal values are: 

5 ^ 3 = 6

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 5U;
    unsigned int b = 3U;

    unsigned int result = a ^ b;

    printf("XOR result = %u\n", result);

    return 0;
}
Output: 
XOR result = 6

3. Important Properties of XOR

Property 1: XOR with Zero

A ^ 0 = A

XOR with zero does not change the value.

Property 2: XOR with Itself

A ^ A = 0

A value XORed with itself produces zero.

Property 3: Commutative Property

A ^ B = B ^ A

The order of operands does not matter.

Property 4: Associative Property

(A ^ B) ^ C = A ^ (B ^ C)

The grouping of operands does not change the result.

Property 5: Self-Inverse Property

(A ^ B) ^ B = A

XORing the same value twice restores the original value.

These properties are the foundation of XOR-based coding problems. In particular, duplicate values cancel each other when XORed.

4. Finding a Non-Repeating Element in an Array

This is one of the most frequently asked XOR problems in technical interviews.

Problem Statement

Given an array in which every element appears exactly twice except one element, find the element that appears only once.

Example

Array = {4, 1, 2, 1, 2}

4 ^ 1 ^ 2 ^ 1 ^ 2

= 4 ^ (1 ^ 1) ^ (2 ^ 2)

= 4 ^ 0 ^ 0

= 4

Algorithm

  1. Initialize the result to zero.
  2. Traverse every array element.
  3. XOR each element with the result.
  4. Return the final result.

C11 Program

#include <stdio.h>

int find_unique(const int array[], int size)
{
    int result = 0;

    for (int i = 0; i < size; i++)
    {
        result ^= array[i];
    }

    return result;
}

int main(void)
{
    int array[] = {4, 1, 2, 1, 2};

    int size = (int)(sizeof(array) / sizeof(array[0]));

    int unique = find_unique(array, size);

    printf("Non-repeating element = %d\n", unique);

    return 0;
}
Output: 
Non-repeating element = 4

Complexity Analysis

  • Time complexity: O(n).
  • Auxiliary space: O(1).
This solution assumes exactly one element occurs once and every other value occurs exactly twice. It does not solve the general problem where duplicate frequencies are arbitrary.

5. Finding Two Non-Repeating Elements

Consider an array in which exactly two distinct elements occur once and every other element occurs exactly twice. Find both unique elements.

Example

Array = {2, 4, 7, 9, 2, 4}

Unique elements = 7 and 9

Step 1: XOR All Elements

2 ^ 4 ^ 7 ^ 9 ^ 2 ^ 4

= 7 ^ 9

= 14

The result contains the XOR of the two unique values.

Step 2: Find a Set Bit

Since the two unique values are different, their XOR is nonzero. At least one bit position differs between them.

Isolate the lowest set bit: 

rightmost_set_bit = xor_result & (0U - xor_result);

Step 3: Divide Elements into Two Groups

Divide array elements into two groups based on whether they contain the selected bit.

  • Group 1: Selected bit is set.
  • Group 2: Selected bit is clear.

Equal elements go into the same group and cancel out. The two unique values end up in different groups.

C11 Program

#include <stdio.h>

void find_two_unique(const int array[],
                     int size,
                     int *first,
                     int *second)
{
    unsigned int xor_result = 0U;

    for (int i = 0; i < size; i++)
    {
        xor_result ^= (unsigned int)array[i];
    }

    unsigned int rightmost_set_bit =
        xor_result & (0U - xor_result);

    unsigned int group1 = 0U;
    unsigned int group2 = 0U;

    for (int i = 0; i < size; i++)
    {
        unsigned int value = (unsigned int)array[i];

        if ((value & rightmost_set_bit) != 0U)
        {
            group1 ^= value;
        }
        else
        {
            group2 ^= value;
        }
    }

    *first = (int)group1;
    *second = (int)group2;
}

int main(void)
{
    int array[] = {2, 4, 7, 9, 2, 4};

    int size = (int)(sizeof(array) / sizeof(array[0]));

    int first;
    int second;

    find_two_unique(array, size, &first, &second);

    printf("Unique elements: %d and %d\n",
           first, second);

    return 0;
}
Output: 
Unique elements: 7 and 9

Complexity Analysis

  • Time complexity: O(n).
  • Auxiliary space: O(1).
This implementation assumes the unique values are representable as int and that the input satisfies the stated frequency condition. A production implementation should also validate input pointers and array size.

6. Swapping Two Numbers Using XOR

XOR can swap two integer variables without using a temporary variable.

Algorithm

a = a ^ b;
b = a ^ b;
a = a ^ b;

Explanation

Assume:

a = 5
b = 9

First operation:

a = a ^ b

a = 5 ^ 9

Second operation:

b = a ^ b

b = (5 ^ 9) ^ 9
b = 5

Third operation:

a = a ^ b

a = (5 ^ 9) ^ 5
a = 9

C11 Program

#include <stdio.h>

int main(void)
{
    unsigned int a = 5U;
    unsigned int b = 9U;

    printf("Before swapping:\n");
    printf("a = %u, b = %u\n", a, b);

    if (&a != &b)
    {
        a ^= b;
        b ^= a;
        a ^= b;
    }

    printf("After swapping:\n");
    printf("a = %u, b = %u\n", a, b);

    return 0;
}
Output: 
Before swapping:
a = 5, b = 9

After swapping:
a = 9, b = 5
XOR swapping is mainly an interview exercise. In production C code, a temporary variable is generally clearer and avoids aliasing problems when both expressions refer to the same object.

7. Finding a Missing Number Using XOR

Problem Statement

An array contains distinct numbers from 1 to n, but one number is missing. Find the missing number.

Example

n = 5

Array = {1, 2, 4, 5}

Missing number = 3

Logic

XOR all numbers from 1 to n and XOR all array elements.

Numbers appearing in both groups cancel out. The missing number remains.

C11 Program

#include <stdio.h>

unsigned int find_missing(const unsigned int array[],
                          unsigned int n)
{
    unsigned int result = 0U;

    for (unsigned int i = 1U; i <= n; i++)
    {
        result ^= i;
    }

    for (unsigned int i = 0U; i < n - 1U; i++)
    {
        result ^= array[i];
    }

    return result;
}

int main(void)
{
    unsigned int array[] = {1U, 2U, 4U, 5U};

    unsigned int n = 5U;

    printf("Missing number = %u\n",
           find_missing(array, n));

    return 0;
}
Output: 
Missing number = 3

Complexity Analysis

  • Time complexity: O(n).
  • Auxiliary space: O(1).
This example assumes n is positive, the array contains exactly n - 1 distinct values from 1 to n, and exactly one value is missing. The function does not validate these assumptions or protect against an invalid array pointer.

8. Finding the XOR of All Array Elements

XOR can be used to calculate the combined XOR of every element in an array.

C11 Program

#include <stdio.h>

unsigned int array_xor(const unsigned int array[],
                       unsigned int size)
{
    unsigned int result = 0U;

    for (unsigned int i = 0U; i < size; i++)
    {
        result ^= array[i];
    }

    return result;
}

int main(void)
{
    unsigned int array[] = {3U, 5U, 7U, 3U, 5U};

    unsigned int size =
        (unsigned int)(sizeof(array) / sizeof(array[0]));

    printf("Array XOR = %u\n",
           array_xor(array, size));

    return 0;
}
Output: 
Array XOR = 7

9. Finding the XOR of Numbers from 1 to n

XOR of consecutive integers from 1 to n follows a repeating pattern based on n modulo 4.

n % 4 XOR from 1 to n
0 n
1 1
2 n + 1
3 0

Example

1 ^ 2 ^ 3 ^ 4 ^ 5 ^ 6

= 7

Since 6 % 4 = 2, the result is 6 + 1 = 7.

C11 Program

#include <stdio.h>

unsigned int xor_1_to_n(unsigned int n)
{
    switch (n % 4U)
    {
        case 0U:
            return n;

        case 1U:
            return 1U;

        case 2U:
            return n + 1U;

        default:
            return 0U;
    }
}

int main(void)
{
    unsigned int n = 6U;

    printf("XOR from 1 to %u = %u\n",
           n, xor_1_to_n(n));

    return 0;
}
Output: 
XOR from 1 to 6 = 7
This formula uses unsigned arithmetic. For the case n % 4 == 2, n + 1U can wrap around if n is UINT_MAX. The mathematical result may then not be representable by unsigned int.

Complexity

  • Time complexity: O(1).
  • Auxiliary space: O(1).

10. XOR and Embedded Systems

XOR is useful in embedded programming for changing selected bits and comparing bit patterns.

1. Toggling a GPIO Output Bit

GPIO_DATA ^= (1U << 5U);

This toggles bit 5 in a software representation of a register. For a real hardware register, use the microcontroller's documented register interface and ensure that read-modify-write access is supported.

2. Comparing Two Status Values

unsigned int difference = status_a ^ status_b;

Every set bit in difference identifies a bit position where the two status values differ.

3. Checking Whether Two Bit Patterns Match

if ((status_a ^ status_b) == 0U)
{
    /* Bit patterns are identical */
}
XOR-based read-modify-write operations on memory-mapped registers are not automatically atomic. Some hardware registers have special write-one-to-clear, write-one-to-toggle or other semantics. Follow the microcontroller reference manual rather than applying ordinary variable operations blindly.

11. Common Mistakes

1. Confusing XOR with OR

XOR produces 0 when both bits are 1, whereas OR produces 1.

2. Forgetting the Duplicate-Pair Condition

The single-unique-element algorithm requires every other element to occur exactly twice.

3. Using XOR Swap on the Same Variable

If both operands refer to the same object, the XOR swap sequence sets that object to zero. Use a temporary variable or check that the addresses are different.

4. Ignoring Input Constraints

XOR algorithms depend on exact assumptions about element frequencies, ranges and missing values.

5. Using Signed Values Without Considering Their Representation

Prefer unsigned types for bitwise arithmetic when the problem concerns bit patterns. Conversion from unsigned values to signed types outside the signed range can be implementation-defined in C11.

13. Technical Interview Questions

Q1. What is XOR?

XOR is a bitwise operator that produces 1 when corresponding bits are different.

Q2. What is the result of A XOR A?

The result is zero.

Q3. What is the result of A XOR 0?

The result is A.

Q4. How can XOR find a unique element?

Equal pairs cancel because A XOR A equals zero. The remaining value is the unique element.

Q5. What is the time complexity of finding a unique element?

O(n) time and O(1) auxiliary space.

Q6. How can XOR be used to find two unique elements?

XOR all values, isolate a differing bit and divide the elements into two groups based on that bit.

Q7. Can XOR swap two variables?

Yes, but it is generally less readable than swapping with a temporary variable. It must not be used when both operands refer to the same object.

Q8. How can XOR find a missing number?

XOR the expected range with all array elements. Matching values cancel, leaving the missing value.

Q9. Is XOR useful in embedded systems?

Yes. It is useful for toggling bits, comparing status registers and manipulating bit patterns.

Q10. What is the difference between XOR and OR?

OR produces 1 if either input bit is 1. XOR produces 1 only when the input bits differ.

Q11. Why is XOR useful in array problems?

Its cancellation property can eliminate duplicate pairs without requiring an additional frequency array or hash table.

Q12. Does XOR provide encryption by itself?

XOR is used in some cryptographic constructions, but XOR alone does not provide secure encryption.

14. Practical Coding Exercises

Basic Level

  1. Find the XOR of two integers.
  2. Demonstrate all XOR truth-table combinations.
  3. Find the single non-repeating element in an array.
  4. Swap two distinct integer variables using XOR.
  5. Find the XOR of all elements in an array.

Intermediate Level

  1. Find two non-repeating elements in an array where all others occur twice.
  2. Find a missing number from the range 1 to n.
  3. Find XOR of all integers from 1 to n in O(1) time.
  4. Find the element that appears an odd number of times when all other elements appear an even number of times.
  5. Find the XOR difference between two status values.

Advanced Level

  1. Find two unique elements using a bit-partitioning algorithm.
  2. Find the missing and repeated elements in an array using XOR, with appropriate input constraints.
  3. Find the XOR of elements over multiple array ranges using prefix XOR.
  4. Find the maximum XOR of any pair in an array.
  5. Implement a binary trie to solve maximum pair XOR efficiently.
