Chapter 13: Bit Manipulation

Binary representation, bitwise operators, bit masking, register manipulation and placement-oriented coding problems.

Chapter Overview

Bit manipulation is an important topic in C programming, embedded systems, firmware development and technical interviews.

It involves directly operating on individual bits of integer values using bitwise operators and bit masks.

Learning Objectives

  • Understand binary representation of integers.
  • Use bitwise AND, OR, XOR and NOT operators.
  • Understand left and right bit shifting.
  • Check, set, clear and toggle individual bits.
  • Use bit masks for efficient data manipulation.
  • Count set bits and solve power-of-two problems.
  • Apply XOR properties to coding problems.
  • Understand bit manipulation in hardware registers.
  • Solve common placement interview questions.

Lecture List

Lecture 01: Binary Representation and Bitwise Operators Binary and hexadecimal number systems, bit positions, AND, OR, XOR and NOT, truth tables and operator applications. Lecture 02: Left and Right Bit Shifting Left shift, right shift, shift expressions, signed and unsigned behavior, common shift-based problems and precautions. Lecture 03: Bit Masking and Bit Positions Constructing masks, selecting individual bits, masking multiple bits, extracting bit fields and register-oriented examples. Lecture 04: Check, Set, Clear and Toggle Bits Bit testing, setting, clearing and toggling, reusable macros and functions, and practical hardware register operations. Lecture 05: Count Set Bits and Power of Two Count set bits, Brian Kernighan's algorithm, power-of-two checks, parity and efficient bit-counting techniques. Lecture 06: XOR-Based Bit Manipulation Problems XOR properties, finding unique elements, swapping values, missing-number problems and other interview applications. Lecture 07: Bit Manipulation Interview Problems Placement coding questions, output prediction, debugging, embedded-oriented problems and a final chapter assessment.

Placement Preparation Focus

Important Coding Problems

  • Check whether a number is even or odd using bits.
  • Check whether a particular bit is set.
  • Set, clear and toggle a given bit position.
  • Count the number of set bits in an integer.
  • Check whether a number is a power of two.
  • Find the unique element using XOR.
  • Find the missing number in a sequence using XOR.
  • Reverse the bits of an integer.
  • Swap two values using XOR and explain its limitations.
  • Extract and update a selected group of bits.

Embedded Systems Applications

  • Set and clear microcontroller control-register bits.
  • Configure GPIO pins using bit masks.
  • Read hardware status flags.
  • Enable and disable peripheral features.
  • Extract fields from hardware register values.
  • Understand bitwise operations in device drivers.
Preparation approach: Focus on understanding the binary operation first, then write the C implementation. Practice both interview coding questions and hardware-register examples.
