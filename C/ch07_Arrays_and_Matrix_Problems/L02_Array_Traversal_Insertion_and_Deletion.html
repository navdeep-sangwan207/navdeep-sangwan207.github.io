Lecture 2: Array Traversal, Insertion and Deletion

Chapter 7 – Arrays and Matrix Problems

Learn how to visit array elements, insert new values, delete existing values and shift elements while maintaining a valid logical array size.

1. Learning Objectives

  • Understand array traversal using loops.
  • Perform forward and reverse traversal.
  • Insert elements at the beginning, end and a specified position.
  • Delete elements from the beginning, end and a specified position.
  • Understand shifting elements during insertion and deletion.
  • Differentiate array capacity from logical size.
  • Handle invalid positions and full-array conditions.
  • Analyze time complexity of array operations.

2. Array Traversal

Traversal means visiting each element of an array one by one to read, display or process its value.

Forward Traversal

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 30 40 50

Reverse Traversal

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    for (int i = size - 1; i >= 0; i--)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
50 40 30 20 10

Traversal Using Pointer Arithmetic

#include <stdio.h>

int main(void)
{
    int arr[] = {5, 10, 15, 20};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    for (int i = 0; i < size; i++)
    {
        printf("%d ", *(arr + i));
    }

    printf("\n");

    return 0;
}
Output: 
5 10 15 20

Time complexity: O(n)

Auxiliary space: O(1)

3. Array Capacity and Logical Size

Capacity is the maximum number of elements that an allocated array can hold. Logical size is the number of elements currently considered valid.

Example

int arr[10] = {10, 20, 30, 40};
int size = 4;
int capacity = 10;
Property Value
Capacity 10 elements
Logical size 4 elements
Valid logical indices 0 to 3
Next insertion index 4
In a fixed-size array, insertion and deletion do not automatically change the allocated capacity. The program maintains the logical size separately.

4. Insertion at the End

If unused capacity is available, a new element can be placed at the index equal to the current logical size.

Algorithm

  1. Check whether the array is full.
  2. Store the new value at arr[size].
  3. Increment size.

Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40};
    int size = 4;
    int value = 50;

    if (size < 10)
    {
        arr[size] = value;
        size++;
    }
    else
    {
        printf("Array is full.\n");
        return 1;
    }

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 30 40 50

Time complexity: O(1)

Auxiliary space: O(1)

5. Insertion at the Beginning

To insert an element at index zero, all existing elements must be shifted one position to the right.

Example

Original array:

10 20 30 40

Insert 5 at the beginning:

5 10 20 30 40

Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40};
    int size = 4;
    int capacity = 10;
    int value = 5;

    if (size >= capacity)
    {
        printf("Array is full.\n");
        return 1;
    }

    for (int i = size; i > 0; i--)
    {
        arr[i] = arr[i - 1];
    }

    arr[0] = value;
    size++;

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
5 10 20 30 40

Time complexity: O(n)

Auxiliary space: O(1)

6. Insertion at a Specified Position

In this lesson, positions are one-based: position 1 means index 0, position 2 means index 1, and so on.

Algorithm

  1. Check whether the array has available capacity.
  2. Validate that position is between 1 and size + 1.
  3. Convert the position into an index.
  4. Shift elements to the right from the end.
  5. Insert the new value.
  6. Increment the logical size.

Program

#include <stdio.h>

int insertAtPosition(int arr[], int *size,
                     int capacity, int position, int value)
{
    int index;

    if (*size >= capacity)
        return 0;

    if (position < 1 || position > *size + 1)
        return 0;

    index = position - 1;

    for (int i = *size; i > index; i--)
    {
        arr[i] = arr[i - 1];
    }

    arr[index] = value;
    (*size)++;

    return 1;
}

int main(void)
{
    int arr[10] = {10, 20, 30, 40};
    int size = 4;

    if (!insertAtPosition(arr, &size, 10, 3, 25))
    {
        printf("Insertion failed.\n");
        return 1;
    }

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 25 30 40

Time complexity: O(n)

Auxiliary space: O(1)

Passing &size allows the function to update the caller's logical size. The array parameter provides access to the original array elements.

7. Deletion from the End

Deleting the final logical element only requires reducing the logical size by one.

Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40, 50};
    int size = 5;

    if (size == 0)
    {
        printf("Array is empty.\n");
        return 1;
    }

    size--;

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 30 40

Time complexity: O(1)

Auxiliary space: O(1)

Reducing logical size does not erase the old value from memory. It simply excludes that position from the active logical array.

8. Deletion from the Beginning

To delete the first element, shift every remaining element one position to the left.

Example

Original array:

10 20 30 40 50

After deleting the first element:

20 30 40 50

Program

#include <stdio.h>

int main(void)
{
    int arr[10] = {10, 20, 30, 40, 50};
    int size = 5;

    if (size == 0)
    {
        printf("Array is empty.\n");
        return 1;
    }

    for (int i = 0; i < size - 1; i++)
    {
        arr[i] = arr[i + 1];
    }

    size--;

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
20 30 40 50

Time complexity: O(n)

Auxiliary space: O(1)

9. Deletion at a Specified Position

Deletion at a specified position requires shifting all elements after the deleted element one position to the left.

Algorithm

  1. Check whether the array is empty.
  2. Validate the deletion position.
  3. Convert the position into a zero-based index.
  4. Shift subsequent elements to the left.
  5. Decrement the logical size.

Program

#include <stdio.h>

int deleteAtPosition(int arr[], int *size, int position)
{
    int index;

    if (*size == 0)
        return 0;

    if (position < 1 || position > *size)
        return 0;

    index = position - 1;

    for (int i = index; i < *size - 1; i++)
    {
        arr[i] = arr[i + 1];
    }

    (*size)--;

    return 1;
}

int main(void)
{
    int arr[10] = {10, 20, 30, 40, 50};
    int size = 5;

    if (!deleteAtPosition(arr, &size, 3))
    {
        printf("Deletion failed.\n");
        return 1;
    }

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 40 50

Time complexity: O(n)

Auxiliary space: O(1)

10. Complete Program: Array Insertion and Deletion

This program combines traversal, insertion at a position and deletion at a position into one reusable implementation. 

#include <stdio.h>

#define CAPACITY 10

void display(const int arr[], int size)
{
    if (size == 0)
    {
        printf("Array is empty.\n");
        return;
    }

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int insertAtPosition(int arr[], int *size,
                     int position, int value)
{
    int index;

    if (*size >= CAPACITY)
        return 0;

    if (position < 1 || position > *size + 1)
        return 0;

    index = position - 1;

    for (int i = *size; i > index; i--)
    {
        arr[i] = arr[i - 1];
    }

    arr[index] = value;
    (*size)++;

    return 1;
}

int deleteAtPosition(int arr[], int *size, int position)
{
    int index;

    if (*size == 0)
        return 0;

    if (position < 1 || position > *size)
        return 0;

    index = position - 1;

    for (int i = index; i < *size - 1; i++)
    {
        arr[i] = arr[i + 1];
    }

    (*size)--;

    return 1;
}

int main(void)
{
    int arr[CAPACITY] = {10, 20, 30, 40, 50};
    int size = 5;

    printf("Original array: ");
    display(arr, size);

    if (insertAtPosition(arr, &size, 3, 25))
    {
        printf("After insertion: ");
        display(arr, size);
    }
    else
    {
        printf("Insertion failed.\n");
    }

    if (deleteAtPosition(arr, &size, 4))
    {
        printf("After deletion: ");
        display(arr, size);
    }
    else
    {
        printf("Deletion failed.\n");
    }

    return 0;
}
Output: 
Original array: 10 20 30 40 50
After insertion: 10 20 25 30 40 50
After deletion: 10 20 25 40 50

11. Time Complexity of Array Operations

Operation Time Complexity Reason
Access by index O(1) Direct element access.
Forward traversal O(n) Visits every element.
Reverse traversal O(n) Visits every element.
Insertion at end O(1) Writes at the next free index.
Insertion at beginning O(n) Shifts existing elements.
Insertion at arbitrary position O(n) May shift many elements.
Deletion at end O(1) Reduces logical size.
Deletion at beginning O(n) Shifts remaining elements.
Deletion at arbitrary position O(n) May shift remaining elements.
Insertion and deletion at the end are O(1) when capacity is already available and only the logical size changes. This does not include allocating or resizing storage.

12. Common Errors and Boundary Conditions

Error 1: Shifting in the Wrong Direction During Insertion

Incorrect approach:

for (int i = 0; i < size; i++)
{
    arr[i + 1] = arr[i];
}

This overwrites values before they are moved. Insertion requires shifting from right to left, starting at the last occupied index.

Error 2: Incorrect Deletion Loop

Incorrect approach:

for (int i = index; i < size; i++)
{
    arr[i] = arr[i - 1];
}

This shifts elements in the wrong direction and may access an invalid previous position.

Correct approach:

for (int i = index; i < size - 1; i++)
{
    arr[i] = arr[i + 1];
}

Error 3: Insertion Without Capacity Validation

arr[size] = value;
size++;

This is unsafe if size is already equal to capacity. Always check available capacity first.

Error 4: Deleting from an Empty Array

A deletion operation must check size before accessing any element.

Important Boundary Cases

  • Insertion into an empty array at position 1.
  • Insertion into a full array.
  • Insertion at the first and last valid positions.
  • Deletion from an empty array.
  • Deletion of the only element.
  • Deletion at the first and last positions.
  • Invalid position such as zero or a position beyond the logical size.

13. Technical Interview Questions

Q1. What is array traversal?

Visiting each array element to read, display or process its value.

Q2. What is the time complexity of array traversal?

O(n).

Q3. Why does insertion at the beginning take O(n)?

Existing elements must be shifted one position to the right.

Q4. Why is insertion at the end O(1)?

When capacity is available, the new value is placed directly at the next free index.

Q5. What is logical size?

The number of elements currently considered valid in the array.

Q6. What happens to array capacity after deletion?

Capacity remains unchanged. Only the logical size is reduced.

Q7. Why do we shift elements during insertion?

To create an empty position without overwriting existing elements.

Q8. Why do we shift elements during deletion?

To fill the gap left by the removed element.

Q9. What is the difference between array size and capacity?

Capacity is the maximum allocated number of elements. Logical size is the current number of valid elements.

Q10. Can an array dynamically grow automatically?

No. A fixed-size array has a fixed capacity. Dynamic resizing requires allocating new storage and copying elements, typically using dynamic memory allocation.

16. Key Concepts for Placement Interviews

  • Traversal visits each valid element.
  • Logical size and capacity are different.
  • Insertion at the end takes O(1) when capacity is available.
  • Insertion at the beginning or middle may take O(n).
  • Deletion at the end takes O(1).
  • Deletion at the beginning or middle may take O(n).
  • Insertion shifts elements from right to left.
  • Deletion shifts elements from left to right.
  • Always validate array capacity, logical size and position.
