Lecture 6: Two-Dimensional Arrays and Memory Layout

Understand matrix representation, declaration, initialization, row-major memory storage, address calculation and pointer relationships in two-dimensional arrays.

1. Learning Objectives

  • Understand two-dimensional arrays and their applications.
  • Declare and initialize matrices in C.
  • Access matrix elements using row and column indexes.
  • Understand row-major memory layout.
  • Calculate the address of a matrix element.
  • Understand the relationship between arrays and pointers.
  • Use nested loops to traverse matrices.
  • Understand how multidimensional arrays are passed to functions.

2. Introduction to Two-Dimensional Arrays

A two-dimensional array is a collection of elements arranged in rows and columns. It is commonly used to represent matrices, tables, grids and tabular data.

Example: A 3 × 3 Matrix

        Column
          0   1   2

Row 0    10  20  30
Row 1    40  50  60
Row 2    70  80  90

The element at row 1 and column 2 is 60. Its C expression is: 

arr[1][2]

Applications

  • Matrix calculations.
  • Student marks tables.
  • Game boards and grid-based problems.
  • Image pixel representation.
  • Tabular data processing.
  • Embedded systems lookup tables.

3. Declaration of a Two-Dimensional Array

The general syntax is:

data_type array_name[rows][columns];

Example:

int matrix[3][4];

This declares an array containing 3 rows and 4 columns. The total number of elements is: 

3 * 4 = 12 elements

If each int occupies 4 bytes on a particular implementation, the array occupies 48 bytes. The exact size depends on the implementation.

Accessing Individual Elements

matrix[0][0] = 10;
matrix[0][1] = 20;
matrix[1][0] = 30;
matrix[2][3] = 40;
C array indexing starts from zero. For matrix[3][4], valid row indexes are 0 to 2 and valid column indexes are 0 to 3.

4. Initialization of Two-Dimensional Arrays

Method 1: Initialize Row by Row

int matrix[2][3] =
{
    {10, 20, 30},
    {40, 50, 60}
};

Method 2: Initialize Without Inner Braces

int matrix[2][3] =
{
    10, 20, 30,
    40, 50, 60
};

Method 3: Partial Initialization

int matrix[2][3] =
{
    {10, 20},
    {30}
};

The resulting matrix is:

10  20  0
30   0  0

Elements not explicitly initialized in this aggregate initialization are initialized to zero.

Method 4: Initialize All Elements to Zero

int matrix[3][3] = {0};

All elements are initialized to zero.

5. Reading and Displaying Matrix Elements

Nested loops are used to access each element of a two-dimensional array.

Example: Input and Display a Matrix

#include <stdio.h>

int main(void)
{
    int matrix[2][3];

    printf("Enter 6 elements:\n");

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            if (scanf("%d", &matrix[i][j]) != 1)
            {
                printf("Invalid input\n");
                return 1;
            }
        }
    }

    printf("Matrix:\n");

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
Sample Input: 
10 20 30
40 50 60
Expected Output: 
Matrix:
10 20 30
40 50 60

Understanding the Nested Loops

  • The outer loop controls the rows.
  • The inner loop controls the columns.
  • After processing one row, the inner loop completes.
  • The outer loop then moves to the next row.

6. Memory Layout of a Two-Dimensional Array

In C, a two-dimensional array is stored in contiguous memory in row-major order.

This means all elements of the first row are stored first, followed by all elements of the second row, and so on.

Example

int arr[2][3] =
{
    {10, 20, 30},
    {40, 50, 60}
};

Conceptual memory sequence:

arr[0][0]  arr[0][1]  arr[0][2]  arr[1][0]  arr[1][1]  arr[1][2]

   10         20         30         40         50         60

Memory Address Example

Suppose the base address of the array is 1000 and each integer occupies 4 bytes.

Element Byte Offset Example Address
arr[0][0] 0 1000
arr[0][1] 4 1004
arr[0][2] 8 1008
arr[1][0] 12 1012
arr[1][1] 16 1016
arr[1][2] 20 1020

These addresses are illustrative. Actual addresses depend on the program's memory layout and implementation.

7. Address Calculation Formula

For a row-major two-dimensional array, the address of element arr[i][j] can be calculated as: 

Address =
Base Address + ((i × Number of Columns) + j) × Element Size

Example

Consider:

int arr[3][4];

Assume:

  • Base address = 1000
  • Number of columns = 4
  • Element size = 4 bytes
  • Required element = arr[2][1]

Calculation:

Address = 1000 + ((2 × 4) + 1) × 4

        = 1000 + (9 × 4)

        = 1036
Interview Tip: In a two-dimensional array, the number of columns is essential for calculating the address of an element.

8. sizeof Operator with Two-Dimensional Arrays

The sizeof operator can calculate the total storage size of a two-dimensional array and the size of its rows.

Example

#include <stdio.h>

int main(void)
{
    int arr[3][4];

    printf("Total array size = %zu bytes\n", sizeof(arr));

    printf("One row size = %zu bytes\n",
           sizeof(arr[0]));

    printf("One element size = %zu bytes\n",
           sizeof(arr[0][0]));

    printf("Number of rows = %zu\n",
           sizeof(arr) / sizeof(arr[0]));

    printf("Number of columns = %zu\n",
           sizeof(arr[0]) / sizeof(arr[0][0]));

    return 0;
}

On an implementation where int occupies 4 bytes, the expected output is: 

Total array size = 48 bytes
One row size = 16 bytes
One element size = 4 bytes
Number of rows = 3
Number of columns = 4

The size values depend on the implementation, but the element-count calculations are valid while arr is still an actual array object.

9. Relationship Between Two-Dimensional Arrays and Pointers

A two-dimensional array is an array of arrays. For example: 

int arr[2][3];

This means arr contains two elements, and each element is itself an array of three integers.

Pointer to an Array

int (*ptr)[3] = arr;

Here, ptr is a pointer to an array of three integers. Incrementing ptr moves to the next row.

Accessing Elements Using the Pointer

ptr[0][0] = 10;
ptr[0][1] = 20;
ptr[1][0] = 30;

The expression ptr[i][j] accesses the same element as arr[i][j].

Example Program

#include <stdio.h>

int main(void)
{
    int arr[2][3] =
    {
        {10, 20, 30},
        {40, 50, 60}
    };

    int (*ptr)[3] = arr;

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", ptr[i][j]);
        }

        printf("\n");
    }

    return 0;
}
Expected Output: 
10 20 30
40 50 60
Important Pointer Difference:
int *ptr[3] declares an array of three pointers to int.

int (*ptr)[3] declares a pointer to an array of three integers.

Parentheses change the meaning of the declaration.

10. Row Traversal and Column Traversal

A matrix can be traversed row by row or column by column. Both approaches access the same elements but in different orders.

Row-Wise Traversal

for (int i = 0; i < rows; i++)
{
    for (int j = 0; j < cols; j++)
        printf("%d ", arr[i][j]);
}

Column-Wise Traversal

for (int j = 0; j < cols; j++)
{
    for (int i = 0; i < rows; i++)
        printf("%d ", arr[i][j]);
}

Why Does Traversal Order Matter?

Row-wise traversal follows the order in which elements are stored in memory. It generally provides better cache locality than column-wise traversal for a conventional row-major array.

In performance-sensitive C programs, memory access patterns matter. Sequential access often makes better use of CPU cache lines.

11. Three-Dimensional Arrays: Basic Understanding

A three-dimensional array extends the same concept by adding another index. 

int arr[2][3][4];

This array contains:

  • 2 blocks
  • 3 rows per block
  • 4 columns per row
  • 24 integer elements in total

Element access:

arr[0][1][2] = 100;

Three-dimensional arrays can be used for layered data, scientific calculations and multi-channel image data.

12. Common Mistakes and Interview Traps

Mistake 1: Incorrect Indexing

int arr[2][3];

arr[2][0] = 10;  /* Invalid row index */

Valid row indexes are 0 and 1. Valid column indexes are 0, 1 and 2.

Mistake 2: Confusing a Pointer to an Array with an Array of Pointers

int *p[3];      /* Array of 3 int pointers */

int (*q)[3];    /* Pointer to an array of 3 ints */

Mistake 3: Incorrect Function Parameter

void display(int arr[][]);

This is not a valid complete parameter declaration for a conventional two-dimensional array. The second dimension must be specified, or a suitable variable-length array parameter must be used.

Mistake 4: Assuming Column-Wise Storage

C stores multidimensional arrays in row-major order, not column-major order.

Mistake 5: Confusing sizeof with Pointer Size

sizeof(arr) gives the complete array size when arr is an actual array object. It gives the pointer size when arr is a pointer parameter.
