Lecture 4: Array Sorting and Rearrangement

Learn sorting algorithms, compare their time and space complexity, and solve practical array rearrangement problems using C11.

After completing this lecture, you should be able to:

  • Compare sorting algorithms using time and space complexity.

2. Introduction to Sorting

Sorting is the process of arranging elements in a particular order. The most common orders are ascending and descending.

Ascending Order

Elements are arranged from smallest to largest.

Original:  40  10  30  20  50
Sorted:    10  20  30  40  50

Descending Order

Elements are arranged from largest to smallest.

Original:  40  10  30  20  50
Sorted:    50  40  30  20  10

Why Is Sorting Important?

  • Binary search requires sorted data.
  • It helps organize records and databases.
  • It makes duplicate detection easier.
  • It is frequently used in coding interviews.
  • It helps solve problems involving minimum and maximum values.

In-Place Sorting

An in-place sorting algorithm rearranges elements within the original array and uses only a small, constant amount of additional storage.

3. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Example

Consider the array:

5  3  8  4  2

Pass 1:

Compare 5 and 3: swap
3  5  8  4  2

Compare 5 and 8: no swap
3  5  8  4  2

Compare 8 and 4: swap
3  5  4  8  2

Compare 8 and 2: swap
3  5  4  2  8

After the first pass, the largest element reaches its correct position at the end.

Algorithm

  1. Start from the first element.
  2. Compare adjacent elements.
  3. Swap them if the left element is greater.
  4. Continue until the end of the unsorted portion.
  5. Repeat until the array is sorted or no swaps occur.

C11 Implementation: Optimized Bubble Sort

#include <stdio.h>

void bubbleSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int swapped = 0;

        for (int j = 0; j < n - 1 - i; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;

                swapped = 1;
            }
        }

        /* Stop if this pass made no swaps */
        if (swapped == 0)
            break;
    }
}

int main(void)
{
    int arr[] = {5, 3, 8, 4, 2};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    bubbleSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
Sorted array: 2 3 4 5 8

Why Use the swapped Variable?

If a complete pass finishes without swapping any elements, the array is already sorted. The algorithm can stop early.

4. Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it at the beginning of that portion.

Example

Original:  64  25  12  22  11

Pass 1:    11  25  12  22  64
Pass 2:    11  12  25  22  64
Pass 3:    11  12  22  25  64
Pass 4:    11  12  22  25  64

Sorted:    11  12  22  25  64

C11 Implementation

#include <stdio.h>

void selectionSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int minIndex = i;

        for (int j = i + 1; j < n; j++)
        {
            if (arr[j] < arr[minIndex])
                minIndex = j;
        }

        if (minIndex != i)
        {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}

int main(void)
{
    int arr[] = {64, 25, 12, 22, 11};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    selectionSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
Sorted array: 11 12 22 25 64

Important Observation

Selection Sort performs approximately the same number of comparisons regardless of whether the input array is already sorted or randomly arranged. However, it performs at most n - 1 swaps.

5. Insertion Sort

Insertion Sort builds a sorted portion of the array one element at a time. Each new element is inserted into its correct position in the already sorted portion.

Example

Original:  5  3  4  1  2

Step 1:    3  5  4  1  2
Step 2:    3  4  5  1  2
Step 3:    1  3  4  5  2
Step 4:    1  2  3  4  5

Sorted:    1  2  3  4  5

C11 Implementation

#include <stdio.h>

void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}

int main(void)
{
    int arr[] = {5, 3, 4, 1, 2};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    insertionSort(arr, n);

    printf("Sorted array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
Sorted array: 1 2 3 4 5

Why Is Insertion Sort Useful?

  • It is efficient for small arrays.
  • It performs well when data is already or nearly sorted.
  • It is an online algorithm: it can insert new elements into an already sorted sequence.
  • It requires constant auxiliary space.

6. Comparison of Sorting Algorithms

Property Bubble Sort Selection Sort Insertion Sort
Best Time O(n) O(n²) O(n)
Average Time O(n²) O(n²) O(n²)
Worst Time O(n²) O(n²) O(n²)
Auxiliary Space O(1) O(1) O(1)
Stable Yes No Yes
Adaptive Yes, with early exit No Yes
In-place Yes Yes Yes

Important Sorting Terminology

Stable Sorting: A stable algorithm preserves the relative order of equal elements.

For example, if two employee records have the same salary, a stable sort by salary preserves their original order.

Adaptive Sorting: An adaptive algorithm can perform fewer operations when the input is already or nearly sorted.

In-place Sorting: The algorithm rearranges the original array using O(1) auxiliary storage.

Placement Tip: Insertion Sort is often preferred for small or nearly sorted arrays. Selection Sort is useful when minimizing the number of swaps is important. Bubble Sort is primarily useful for understanding sorting fundamentals.

7. Sorting in Descending Order

To sort in descending order, reverse the comparison condition. For example, in Bubble Sort, swap when the left element is smaller than the right element. 

if (arr[j] < arr[j + 1])
{
    int temp = arr[j];
    arr[j] = arr[j + 1];
    arr[j + 1] = temp;
}

The same principle applies to Selection Sort and Insertion Sort: select the largest element or shift smaller elements as needed.

Do not compare integers by subtracting them, such as return a - b; in a comparator. The subtraction can overflow for extreme integer values. Use relational comparisons instead.

8. Array Rearrangement Problems

Array rearrangement means changing the positions of elements according to a required condition. Unlike sorting, the goal may not be to arrange all values in numerical order.

Problem 1: Move All Zeros to the End

Move all zero elements to the end while preserving the relative order of non-zero elements. 

Input:  0  1  0  3  12
Output: 1  3  12  0  0
        
#include <stdio.h>

void moveZeros(int arr[], int n)
{
    int position = 0;

    for (int i = 0; i < n; i++)
    {
        if (arr[i] != 0)
        {
            arr[position] = arr[i];
            position++;
        }
    }

    while (position < n)
    {
        arr[position] = 0;
        position++;
    }
}

int main(void)
{
    int arr[] = {0, 1, 0, 3, 12};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    moveZeros(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
1 3 12 0 0

Complexity: O(n) time and O(1) auxiliary space.

Problem 2: Reverse an Array

Reverse an array by exchanging elements from opposite ends and moving toward the center. 

Input:  10  20  30  40  50
Output: 50  40  30  20  10
        
#include <stdio.h>

void reverseArray(int arr[], int n)
{
    int left = 0;
    int right = n - 1;

    while (left < right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    reverseArray(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
50 40 30 20 10

Complexity: O(n) time and O(1) auxiliary space.

Problem 3: Rotate an Array Left by One Position

In a left rotation, each element moves one position to the left, and the first element moves to the last position. 

Input:  1  2  3  4  5
Output: 2  3  4  5  1
        
#include <stdio.h>

void rotateLeftByOne(int arr[], int n)
{
    if (n <= 1)
        return;

    int first = arr[0];

    for (int i = 0; i < n - 1; i++)
        arr[i] = arr[i + 1];

    arr[n - 1] = first;
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    rotateLeftByOne(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
2 3 4 5 1

Complexity: O(n) time and O(1) auxiliary space.

Problem 4: Rotate an Array Right by One Position

In a right rotation, the last element moves to the first position and all other elements shift one position right. 

Input:  1  2  3  4  5
Output: 5  1  2  3  4
        
#include <stdio.h>

void rotateRightByOne(int arr[], int n)
{
    if (n <= 1)
        return;

    int last = arr[n - 1];

    for (int i = n - 1; i > 0; i--)
        arr[i] = arr[i - 1];

    arr[0] = last;
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    rotateRightByOne(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
5 1 2 3 4

Complexity: O(n) time and O(1) auxiliary space.

Problem 5: Separate Even and Odd Elements

Rearrange an array so that even elements appear before odd elements. The order within each group is not guaranteed. 

Input:  1  2  3  4  5  6
Output: 6  2  4  3  5  1
        
#include <stdio.h>

void separateEvenOdd(int arr[], int n)
{
    int left = 0;
    int right = n - 1;

    while (left < right)
    {
        while (left < right && arr[left] % 2 == 0)
            left++;

        while (left < right && arr[right] % 2 != 0)
            right--;

        if (left < right)
        {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;

            left++;
            right--;
        }
    }
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5, 6};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    separateEvenOdd(arr, n);

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
One Possible Output: 
6 2 4 3 5 1

Complexity: O(n) time and O(1) auxiliary space.

9. Important Edge Cases

Always consider the following cases when implementing sorting and rearrangement algorithms:

  • Empty array: No elements to process.
  • Single element: Already sorted; no rearrangement required.
  • Already sorted array: Optimized Bubble Sort and Insertion Sort should finish in O(n) time.
  • Reverse sorted array: Tests the worst-case behavior of these algorithms.
  • Duplicate values: Verify that the algorithm handles equal elements correctly.
  • All zeros: Moving zeros should leave the array unchanged.
  • Negative values: Sorting comparisons should work for negative and positive integers.
  • All elements equal: The algorithm should not access invalid positions.
Array Bounds: For an array of length n, valid indexes are 0 through n - 1. Always check loop conditions before accessing neighboring elements such as arr[j + 1].

10. Common Interview Questions

Q1. Which sorting algorithm has O(n) best-case time complexity?

Optimized Bubble Sort and Insertion Sort both have O(n) best-case time complexity when the input is already sorted.

Q2. Which of these algorithms is generally stable?

Bubble Sort and Insertion Sort are stable with the implementations shown. Selection Sort is generally unstable.

Q3. Why is Selection Sort useful when writes are expensive?

It performs at most n - 1 swaps, even though it still performs O(n²) comparisons.

Q4. Why is Insertion Sort good for nearly sorted arrays?

Most elements are already close to their correct positions, so only a small number of shifts may be needed.

Q5. What is the difference between comparison and swapping?

A comparison checks the relationship between two values. A swap exchanges their positions. Sorting algorithms can perform many comparisons but relatively few swaps.

Q6. Can an array be sorted without using another array?

Yes. Bubble Sort, Selection Sort and Insertion Sort are in-place algorithms and require O(1) auxiliary space.

Q7. Does a stable sorting algorithm preserve the original order of duplicate values?

Yes. Equal elements retain their relative order from the original input.

Q8. What is the time complexity of moving all zeros to the end?

The implementation in this lecture uses O(n) time and O(1) auxiliary space.

12. Lecture Summary

  • Sorting arranges elements in ascending or descending order.
  • Bubble Sort repeatedly exchanges adjacent elements.
  • Selection Sort repeatedly selects the minimum element.
  • Insertion Sort inserts each element into its correct position.
  • All three algorithms have O(n²) average and worst-case time complexity.
  • Optimized Bubble Sort and Insertion Sort have O(n) best-case time complexity.
  • All three algorithms use O(1) auxiliary space.
  • Array rearrangement problems use controlled movement of elements to satisfy a condition.
