2. What Is an Array?

An array is a collection of elements of the same data type stored in contiguous memory locations.

Each element can be accessed using its index. In C, array indexing starts from zero.

Example: Without an Array

#include <stdio.h>

int main(void)
{
    int mark1 = 70;
    int mark2 = 80;
    int mark3 = 90;
    int mark4 = 85;
    int mark5 = 95;

    printf("%d\n", mark1);
    printf("%d\n", mark2);
    printf("%d\n", mark3);
    printf("%d\n", mark4);
    printf("%d\n", mark5);

    return 0;
}

Managing a large number of separate variables becomes difficult. An array provides a convenient way to store related values under one name.

Equivalent Array Representation

int marks[5] = {70, 80, 90, 85, 95};
An array stores multiple elements of one compatible element type. It does not store unrelated data types in the same ordinary array.

3. Array Declaration

General syntax:

data_type array_name[array_size];

Examples

int numbers[5];
float temperatures[10];
char name[20];
double measurements[8];
Declaration Meaning
int numbers[5]; Array of 5 integers.
float temperatures[10]; Array of 10 floating-point values.
char name[20]; Array of 20 characters.
double measurements[8]; Array of 8 double values.
For an ordinary array object, its size must be known when its storage is allocated. A block-scope variable length array may use a runtime size in C11 implementations that support this optional feature. Its bound must be greater than zero.

4. Array Initialization

Initialization means assigning initial values to array elements when the array is declared.

Method 1: Complete Initialization

int numbers[5] = {10, 20, 30, 40, 50};

Method 2: Partial Initialization

int numbers[5] = {10, 20};

The remaining elements are initialized to zero.

Array contents: 
10 20 0 0 0

Method 3: Size Inference

int numbers[] = {10, 20, 30, 40};

The compiler determines the number of elements from the initializer. Here, the array contains four integers.

Method 4: Initialize All Elements to Zero

int numbers[5] = {0};

All five elements are initialized to zero.

Method 5: Designated Initializers in C

int numbers[6] = {
    [0] = 10,
    [3] = 40,
    [5] = 60
};
Array contents: 
10 0 0 40 0 60
Designated initializers are supported in C99 and later, including C11.

5. Accessing Array Elements

Individual elements are accessed using the array name followed by an index inside square brackets.

Syntax:

array_name[index];

Example

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[2]);
    printf("%d\n", numbers[4]);

    return 0;
}
Output: 
10
30
50

Array Index Mapping

Index Element
010
120
230
340
450
For an array of five elements, valid indices are 0 through 4. Accessing index 5 or a negative index is outside the valid array range and results in undefined behavior.

6. Modifying Array Elements

An array element can be modified by assigning a new value to its indexed location. 

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    numbers[2] = 100;
    numbers[4] = 200;

    printf("Updated array:\n");

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Output: 
Updated array:
10 20 100 40 200

7. Contiguous Memory Allocation

Array elements are stored in consecutive memory locations without gaps between successive elements of the same array.

Consider:

int numbers[5] = {10, 20, 30, 40, 50};

Assuming sizeof(int) is 4 bytes and the first element begins at address 1000, the conceptual layout is:

Element Index Illustrative Address Value
numbers[0]0100010
numbers[1]1100420
numbers[2]2100830
numbers[3]3101240
numbers[4]4101650
The addresses above are illustrative. Actual addresses depend on the program's execution environment and memory layout.

Why Is Contiguous Storage Important?

  • Allows direct indexed access to elements.
  • Supports efficient traversal.
  • Enables pointer arithmetic.
  • Improves cache locality in many access patterns.

8. Address Calculation of Array Elements

The address of an array element can be calculated using the base address and element size.

Formula:

Address of A[i] = Base Address + (i * sizeof(A[0]))

Example

Suppose:

  • Base address = 2000
  • Size of each integer = 4 bytes
  • Required index = 3
Address of A[3]
= 2000 + (3 * 4)
= 2012
This formula assumes a zero-based index and contiguous element storage. It is useful for understanding how the compiler computes an element's address.

9. Finding the Size of an Array Using sizeof

The sizeof operator returns the size of an object or type in bytes. 

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    size_t totalBytes = sizeof(numbers);
    size_t elementBytes = sizeof(numbers[0]);
    size_t count = sizeof(numbers) / sizeof(numbers[0]);

    printf("Total size = %zu bytes\n", totalBytes);
    printf("Element size = %zu bytes\n", elementBytes);
    printf("Number of elements = %zu\n", count);

    return 0;
}
Example output on a system where sizeof(int) is 4: 
Total size = 20 bytes
Element size = 4 bytes
Number of elements = 5
Do not assume that sizeof(int) is always 4 bytes. Its size is implementation-dependent. Use sizeof when calculating storage requirements.

Important Interview Concept

void display(int arr[])
{
    printf("%zu\n", sizeof(arr));
}

Inside this function, arr is adjusted to a pointer parameter. Therefore, sizeof(arr) gives the size of the pointer, not the size of the original array.

Pass the array length separately when a function needs to know the number of elements.

10. Relationship Between Arrays and Pointers

In most expressions, an array expression is converted to a pointer to its first element.

Example

#include <stdio.h>

int main(void)
{
    int numbers[3] = {10, 20, 30};

    printf("%d\n", *numbers);
    printf("%d\n", *(numbers + 1));
    printf("%d\n", *(numbers + 2));

    return 0;
}
Output: 
10
20
30

Equivalent Expressions

Array Notation Equivalent Pointer Notation
numbers[0]*(numbers + 0)
numbers[1]*(numbers + 1)
numbers[2]*(numbers + 2)
The expression a[i] is defined in terms of pointer arithmetic and dereferencing: *(a + i). However, an array is not itself a pointer variable.

11. Important Difference: Array Name and Pointer Variable

Array Pointer Variable
Represents an array object containing elements. Stores an address value.
Cannot be assigned a new address. Can be reassigned to point to another compatible object.
sizeof(array) gives total array size in its declaration scope. sizeof(pointer) gives the size of the pointer object.
Array elements occupy the array's storage. The pointer variable has its own storage.

Example

#include <stdio.h>

int main(void)
{
    int numbers[3] = {10, 20, 30};
    int *ptr = numbers;

    printf("First element = %d\n", numbers[0]);
    printf("Pointer value = %d\n", *ptr);

    ptr++;

    printf("Next element = %d\n", *ptr);

    return 0;
}
Output: 
First element = 10
Pointer value = 10
Next element = 20

12. Array Initialization and Storage Duration

Initialization behavior depends on the storage duration of the array object.

Array Declaration Initial State
int a[5] = {0}; All elements are zero.
int a[5] = {1, 2}; Remaining elements are zero.
File-scope int a[5]; All elements are zero-initialized.
Block-scope static int a[5]; All elements are zero-initialized.
Block-scope automatic int a[5]; Elements have indeterminate values until initialized.
Never read an uninitialized automatic array element. Initialize it before using its value.

13. Common Array Errors

Error 1: Accessing Outside Array Bounds

int numbers[5];

numbers[5] = 100;  /* Invalid access */

Valid indices are 0 through 4. The assignment above accesses outside the array.

Error 2: Incorrect Loop Condition

int numbers[5];

for (int i = 0; i <= 5; i++)
{
    printf("%d ", numbers[i]);
}

The condition i <= 5 permits access to index 5. Use i < 5 instead.

Error 3: Assuming Array Size from a Pointer

void process(int *arr)
{
    size_t count = sizeof(arr) / sizeof(arr[0]);
}

This does not calculate the original array's element count. The parameter is a pointer.

Correct approach:

void process(const int arr[], size_t count)
{
    for (size_t i = 0; i < count; i++)
    {
        printf("%d ", arr[i]);
    }
}

14. Complete Program: Read and Display Array Elements

#include <stdio.h>

int main(void)
{
    int numbers[5];
    int i;

    printf("Enter 5 integers:\n");

    for (i = 0; i < 5; i++)
    {
        if (scanf("%d", &numbers[i]) != 1)
        {
            printf("Invalid input.\n");
            return 1;
        }
    }

    printf("Array elements:\n");

    for (i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Example input: 
10 20 30 40 50
Output: 
Array elements:
10 20 30 40 50

The program validates each input conversion before using the corresponding array element.

Technical Interview Questions

Q1. What is an array in C?

An array is a collection of elements of the same type stored in contiguous memory locations.

Q2. Why does array indexing start from zero?

Array indexing corresponds to an offset from the first element. Index zero refers to the first element, which has an offset of zero.

Q3. What is the valid index range of an array of size n?

0 to n - 1.

Q4. Are array elements stored in contiguous memory?

Yes, successive elements are stored contiguously.

Q5. What happens when an array is partially initialized?

The remaining elements are initialized to zero.

Q6. What is the difference between an array and a pointer?

An array is an object containing elements. A pointer is a variable that stores an address. Array expressions are converted to pointers in most expressions, but arrays and pointers are not interchangeable types.

Q7. Can the size of an array be calculated using sizeof?

Yes, when sizeof is applied to an actual array object in a scope where it is still an array. Divide its total size by the size of one element.

Q8. Does C automatically check array bounds?

No. The programmer must ensure every access is within the valid range.

Q9. What is the time complexity of accessing an array element by index?

O(1).

Q10. Why are arrays useful in programming?

They allow efficient storage, indexing and processing of collections of same-type elements.

17. Key Concepts for Placement Interviews

  • An array stores elements of the same type.
  • Array elements occupy contiguous memory locations.
  • Array indexing begins at zero.
  • Array access by index takes O(1) time.
  • Partial initialization sets remaining elements to zero.
  • Automatic local arrays are not automatically initialized.
  • Array names are converted to pointers in most expressions.
  • sizeof(array) and sizeof(pointer) are different concepts.
  • C does not perform automatic array-bound checking.
