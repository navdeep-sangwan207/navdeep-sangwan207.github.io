Lecture 5: Array Passing to Functions

Understand how arrays are passed to functions in C, how array parameters work, and how functions access and modify array elements.

1. Learning Objectives

  • Understand why arrays are passed to functions.
  • Learn array parameters and function declarations.
  • Understand array-to-pointer conversion in function calls.
  • Pass array size explicitly to a function.
  • Modify array elements inside functions.
  • Pass multidimensional arrays to functions.
  • Understand const array parameters and common mistakes.

2. Why Pass Arrays to Functions?

When a program contains many array operations, writing all operations inside main() makes the program difficult to understand and maintain.

Functions allow us to divide array operations into reusable tasks such as:

  • Displaying array elements.
  • Calculating the sum and average.
  • Finding the minimum and maximum values.
  • Searching for an element.
  • Sorting an array.
  • Reversing an array.

Example: Without a Separate Function

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Example: Using a Function

#include <stdio.h>

void displayArray(int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    displayArray(arr, n);

    return 0;
}
Expected Output: 
10 20 30 40 50

3. Array as a Function Parameter

An array can be declared as a function parameter using square brackets. 

void display(int arr[], int n);

The following parameter declarations are equivalent in a function parameter list:

void display(int arr[], int n);

void display(int arr[5], int n);

void display(int *arr, int n);

In these declarations, the array parameter is adjusted to a pointer parameter. The function receives a pointer to the first element, not a complete copy of the array.

Important: The number written inside the brackets of a normal array parameter, such as int arr[5], does not make the function receive a five-element array by value. It is still adjusted to a pointer parameter.

Function Declaration and Definition

#include <stdio.h>

void displayArray(int arr[], int size);

int main(void)
{
    int numbers[] = {10, 20, 30, 40};
    int size = (int)(sizeof(numbers) / sizeof(numbers[0]));

    displayArray(numbers, size);

    return 0;
}

void displayArray(int arr[], int size)
{
    for (int i = 0; i < size; i++)
        printf("%d ", arr[i]);
}
Expected Output: 
10 20 30 40

4. Array-to-Pointer Conversion

In most expressions, an array expression is converted into a pointer to its first element. 

int arr[] = {10, 20, 30, 40};

int *ptr = arr;

Here, arr is converted into a pointer to arr[0].

The following expressions refer to the same first element:

arr[0]
*arr
*ptr

Example: Accessing Array Elements Through a Pointer Parameter

#include <stdio.h>

void display(int *ptr, int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", *(ptr + i));
}

int main(void)
{
    int arr[] = {5, 10, 15, 20};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    display(arr, n);

    return 0;
}
Expected Output: 
5 10 15 20

Pointer arithmetic allows access to array elements using expressions such as *(ptr + i).

5. Why Must We Pass Array Size Separately?

When an array is passed to a function, the function receives a pointer to its first element. It does not automatically receive the original array length.

Consider this example:

void display(int arr[])
{
    int n = sizeof(arr) / sizeof(arr[0]);
}

This does not calculate the original array length. Inside the function, arr is a pointer parameter, so sizeof(arr) gives the size of that pointer.

Common Interview Question: Why does sizeof(arr) / sizeof(arr[0]) work in main() but not inside a function that receives int arr[]?

Because the original array exists as an array object in main(), whereas the function parameter is adjusted to a pointer.

Correct Approach

void display(int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);
}

Pass both the array and its number of elements:

display(arr, n);

6. Modifying an Array Inside a Function

Since the function accesses the original array elements through a pointer, changes made to those elements are visible to the calling function.

Example: Multiply Every Element by Two

#include <stdio.h>

void multiplyByTwo(int arr[], int n)
{
    for (int i = 0; i < n; i++)
        arr[i] = arr[i] * 2;
}

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    multiplyByTwo(arr, n);

    printf("Modified array: ");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Expected Output: 
Modified array: 2 4 6 8 10

Important Distinction

The function can modify array elements, but assigning a different pointer to the local parameter does not change the caller's array variable. 

void example(int *ptr)
{
    ptr = NULL;
}

This changes only the local pointer parameter. It does not set the caller's array or pointer variable to NULL.

7. Passing a Read-Only Array Using const

If a function should read array elements but must not modify them, use the const qualifier. 

void display(const int arr[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);
}

The function can read the elements but cannot assign new values to them through this parameter.

Example: Calculate the Sum of an Array

#include <stdio.h>

int calculateSum(const int arr[], int n)
{
    int sum = 0;

    for (int i = 0; i < n; i++)
        sum += arr[i];

    return sum;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Sum = %d\n", calculateSum(arr, n));

    return 0;
}
Expected Output: 
Sum = 150
Use const int arr[] for functions that should not modify array elements. This communicates the function's intent and helps the compiler detect accidental modifications.

8. Returning Results from Array Functions

A function can return a single value calculated from an array, such as its sum, minimum or maximum.

Example: Find the Maximum Element

#include <stdio.h>

int findMaximum(const int arr[], int n)
{
    int maximum = arr[0];

    for (int i = 1; i < n; i++)
    {
        if (arr[i] > maximum)
            maximum = arr[i];
    }

    return maximum;
}

int main(void)
{
    int arr[] = {25, 10, 75, 40, 60};
    int n = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Maximum = %d\n", findMaximum(arr, n));

    return 0;
}
Expected Output: 
Maximum = 75

The function assumes that the array contains at least one element. A production-quality interface should also define how an empty array is handled.

Can a Function Return an Array Directly?

A C function cannot return an array type directly. Common alternatives include:

  • Modify an array supplied by the caller.
  • Return a pointer to dynamically allocated memory.
  • Return a pointer to static storage when appropriate.
  • Return a structure containing an array.
Never return the address of an ordinary local array. Its lifetime ends when the function returns, so the returned pointer would become invalid.

9. Passing Two Arrays to a Function

A function can receive multiple arrays and their sizes. This is useful for operations such as comparing or merging arrays.

Example: Compare Two Arrays

#include <stdio.h>

int areEqual(const int a[], const int b[], int n)
{
    for (int i = 0; i < n; i++)
    {
        if (a[i] != b[i])
            return 0;
    }

    return 1;
}

int main(void)
{
    int first[] = {10, 20, 30, 40};
    int second[] = {10, 20, 30, 40};

    int n = (int)(sizeof(first) / sizeof(first[0]));

    if (areEqual(first, second, n))
        printf("Arrays are equal\n");
    else
        printf("Arrays are not equal\n");

    return 0;
}
Expected Output: 
Arrays are equal

This function assumes both arrays contain at least n accessible elements. A general-purpose comparison function should receive both array lengths and check them first.

10. Passing a Two-Dimensional Array to a Function

A two-dimensional array is stored in row-major order in C. When passing it to a function, the compiler must know the size of the second dimension to calculate element addresses correctly.

Function Syntax

void displayMatrix(int arr[][3], int rows);

The number of columns is specified in the parameter declaration. The number of rows can be passed separately.

Example: Display a Matrix

#include <stdio.h>

void displayMatrix(int arr[][3], int rows)
{
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", arr[i][j]);
        }

        printf("\n");
    }
}

int main(void)
{
    int matrix[2][3] =
    {
        {1, 2, 3},
        {4, 5, 6}
    };

    displayMatrix(matrix, 2);

    return 0;
}
Expected Output: 
1 2 3
4 5 6

Using a Variable-Length Array Parameter (C11)

C supports variable-length array parameters when the implementation supports variable-length arrays. This allows the column count to be supplied at runtime. 

#include <stdio.h>

void displayMatrix(int rows, int cols,
                   const int arr[rows][cols])
{
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
            printf("%d ", arr[i][j]);

        printf("\n");
    }
}

int main(void)
{
    int matrix[2][3] =
    {
        {1, 2, 3},
        {4, 5, 6}
    };

    displayMatrix(2, 3, matrix);

    return 0;
}
Expected Output: 
1 2 3
4 5 6
Variable-length arrays are an optional feature in C11. Some compilers do not support them. The fixed-column parameter form is a useful alternative when the dimensions are known at compile time.

11. Array Parameter Declaration: Quick Comparison

Declaration Meaning
int arr[] Adjusted to an int pointer parameter.
int *arr Pointer to int parameter.
const int arr[] Pointer parameter that does not permit modification of elements through it.
int arr[][3] Pointer to an array of 3 integers.
int (*arr)[3] Pointer to an array of 3 integers.

12. Common Mistakes and Interview Traps

Mistake 1: Expecting the Function to Know the Array Length

void display(int arr[])
{
    /* The original array length is not available here */
}

Solution: Pass the element count as a separate argument.

Mistake 2: Using sizeof to Find the Length Inside the Function

sizeof(arr) / sizeof(arr[0])

This does not give the original array length when arr is a pointer parameter.

Mistake 3: Accessing Elements Beyond the Array

for (int i = 0; i <= n; i++)
    printf("%d ", arr[i]);

The condition should normally be i < n. Using i <= n accesses an invalid element when i becomes n.

Mistake 4: Returning a Local Array

A local array ceases to exist when its function returns. Returning its address creates a dangling pointer.

Mistake 5: Forgetting the Column Dimension

A two-dimensional array parameter needs its column dimension specified or supplied through a suitable variable-length array parameter.

15. Lecture Summary

  • Arrays are commonly passed to functions using array or pointer parameter syntax.
  • Array parameters are adjusted to pointer parameters.
  • The function receives access to the original array elements, not a complete array copy.
  • Pass the array length separately because it is not automatically available.
  • Use const when a function should only read array elements.
  • A function can return calculated values but cannot directly return an array type.
  • Two-dimensional array parameters require the column dimension to be known.
