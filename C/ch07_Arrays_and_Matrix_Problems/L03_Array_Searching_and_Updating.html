2. What Is Array Searching?

Searching is the process of finding whether a particular value exists in an array and determining its position when it is present.

Consider the array:

int arr[] = {10, 25, 30, 45, 60};
Index Value
010
125
230
345
460

If the search key is 30, the element is found at index 2.

Common Searching Techniques

  • Linear search.
  • Binary search.

3. Linear Search

Linear search checks each element sequentially until the required value is found or the array has been completely examined.

Algorithm

  1. Start from the first element.
  2. Compare the current element with the search key.
  3. If they match, return the index.
  4. Otherwise, move to the next element.
  5. If all elements are checked, report not found.

Example

Array:  10  25  30  45  60
Index:   0   1   2   3   4

Search key = 45

Check 10 != 45
Check 25 != 45
Check 30 != 45
Check 45 == 45

Result: Found at index 3

C Program: Linear Search

#include <stdio.h>

int linearSearch(const int arr[], int size, int key)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == key)
            return i;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 25, 30, 45, 60};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));
    int key = 45;

    int result = linearSearch(arr, size, key);

    if (result != -1)
        printf("Element found at index %d\n", result);
    else
        printf("Element not found\n");

    return 0;
}
Output: 
Element found at index 3

Best-case time complexity: O(1)

Average-case time complexity: O(n)

Worst-case time complexity: O(n)

Auxiliary space: O(1)

Linear search works on both sorted and unsorted arrays. It is useful for small arrays or when data is not sorted.

4. Finding the First Occurrence

When duplicate values exist, a normal linear search returns the first matching element because it scans from left to right.

Program

#include <stdio.h>

int firstOccurrence(const int arr[], int size, int key)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == key)
            return i;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 20, 40, 20};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    int index = firstOccurrence(arr, size, 20);

    printf("First occurrence = %d\n", index);

    return 0;
}
Output: 
First occurrence = 1

5. Finding the Last Occurrence

To find the last occurrence, scan the array from right to left. 

#include <stdio.h>

int lastOccurrence(const int arr[], int size, int key)
{
    for (int i = size - 1; i >= 0; i--)
    {
        if (arr[i] == key)
            return i;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 20, 40, 20};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    int index = lastOccurrence(arr, size, 20);

    printf("Last occurrence = %d\n", index);

    return 0;
}
Output: 
Last occurrence = 5

Time complexity: O(n)

Auxiliary space: O(1)

6. Counting Occurrences of an Element

To count how many times a value appears, traverse the complete array and increment a counter whenever a match is found. 

#include <stdio.h>

int countOccurrences(const int arr[], int size, int key)
{
    int count = 0;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == key)
            count++;
    }

    return count;
}

int main(void)
{
    int arr[] = {5, 10, 5, 20, 5, 30, 5};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("Occurrences = %d\n",
           countOccurrences(arr, size, 5));

    return 0;
}
Output: 
Occurrences = 4

Time complexity: O(n)

Auxiliary space: O(1)

7. Binary Search

Binary search repeatedly divides a sorted search range into two halves to locate a required value.

Binary search requires the array to be sorted according to the same ordering used by the search comparisons. It must not be applied directly to an arbitrary unsorted array.

Example

Array:  10  20  30  40  50  60  70
Index:   0   1   2   3   4   5   6

Search key = 50

low = 0
high = 6
mid = 3

arr[3] = 40

40 < 50
Search right half.

low = 4
high = 6
mid = 5

arr[5] = 60

60 > 50
Search left half.

low = 4
high = 4
mid = 4

arr[4] = 50

Result: Found at index 4

8. Iterative Binary Search

Algorithm

  1. Initialize low to 0.
  2. Initialize high to size - 1.
  3. Calculate the middle index.
  4. Compare the middle element with the search key.
  5. If equal, return the middle index.
  6. If the key is smaller, search the left half.
  7. If the key is larger, search the right half.
  8. Continue while low is less than or equal to high.

Program

#include <stdio.h>

int binarySearch(const int arr[], int size, int key)
{
    int low = 0;
    int high = size - 1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid;

        if (arr[mid] < key)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));
    int key = 50;

    int result = binarySearch(arr, size, key);

    if (result != -1)
        printf("Element found at index %d\n", result);
    else
        printf("Element not found\n");

    return 0;
}
Output: 
Element found at index 4

Best-case time complexity: O(1)

Average-case time complexity: O(log n)

Worst-case time complexity: O(log n)

Auxiliary space: O(1)

The middle-index expression low + (high - low) / 2 avoids the potential overflow of (low + high) / 2 when indices are large nonnegative values.

9. Recursive Binary Search

Recursive binary search applies the same divide-and- conquer approach, but each smaller search range is processed through another function call. 

#include <stdio.h>

int binarySearchRecursive(const int arr[],
                          int low, int high, int key)
{
    if (low > high)
        return -1;

    int mid = low + (high - low) / 2;

    if (arr[mid] == key)
        return mid;

    if (key < arr[mid])
    {
        return binarySearchRecursive(
            arr, low, mid - 1, key);
    }

    return binarySearchRecursive(
        arr, mid + 1, high, key);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));
    int key = 60;

    int result = binarySearchRecursive(
        arr, 0, size - 1, key);

    if (result != -1)
        printf("Found at index %d\n", result);
    else
        printf("Not found\n");

    return 0;
}
Output: 
Found at index 5

Time complexity: O(log n)

Auxiliary call-stack space: O(log n)

Iterative binary search uses O(1) auxiliary space, whereas recursive binary search requires call-stack space for its active function calls.

10. First Occurrence Using Binary Search

In a sorted array with duplicates, ordinary binary search may return any matching occurrence. To find the first occurrence, continue searching the left half after finding a match. 

#include <stdio.h>

int firstOccurrence(const int arr[], int size, int key)
{
    int low = 0;
    int high = size - 1;
    int result = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
        {
            result = mid;
            high = mid - 1;
        }
        else if (arr[mid] < key)
        {
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    return result;
}

int main(void)
{
    int arr[] = {10, 20, 20, 20, 30, 40};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    printf("First occurrence = %d\n",
           firstOccurrence(arr, size, 20));

    return 0;
}
Output: 
First occurrence = 1

12. Updating Array Elements

Updating means changing the value stored at an existing array index.

Direct Index-Based Update

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    arr[2] = 100;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
10 20 100 40 50

Update an Element After Searching

#include <stdio.h>

int linearSearch(const int arr[], int size, int key)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == key)
            return i;
    }

    return -1;
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    int key = 30;
    int newValue = 300;

    int index = linearSearch(arr, size, key);

    if (index != -1)
    {
        arr[index] = newValue;
        printf("Element updated.\n");
    }
    else
    {
        printf("Element not found.\n");
    }

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
Element updated.
10 20 300 40 50

Searching complexity: O(n)

Updating after finding the index: O(1)

Total complexity: O(n)

13. Updating All Matching Elements

If duplicate values exist, a program may need to update every occurrence rather than only the first. 

#include <stdio.h>

int updateAll(int arr[], int size,
              int oldValue, int newValue)
{
    int count = 0;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == oldValue)
        {
            arr[i] = newValue;
            count++;
        }
    }

    return count;
}

int main(void)
{
    int arr[] = {10, 20, 10, 30, 10, 40};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));

    int count = updateAll(arr, size, 10, 99);

    printf("Updated occurrences = %d\n", count);

    for (int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Output: 
Updated occurrences = 3
99 20 99 30 99 40

14. Linear Search vs Binary Search

Feature Linear Search Binary Search
Data requirement Sorted or unsorted Sorted
Best case O(1) O(1)
Average case O(n) O(log n)
Worst case O(n) O(log n)
Iterative auxiliary space O(1) O(1)
Implementation Simple sequential checking Divide-and-conquer
Binary search is asymptotically faster for large sorted arrays. However, if data is unsorted, sorting it first has a cost. For a single search, linear search may be the better choice.

15. Common Errors and Debugging

Error 1: Binary Search on Unsorted Data

int arr[] = {30, 10, 50, 20, 40};

Binary search cannot be relied upon with this array because the elements are not sorted.

Error 2: Incorrect Loop Condition

while (low < high)

This condition can skip the final remaining element. For the standard inclusive search range, use low <= high.

Error 3: Incorrect Middle Index

int mid = (low + high) / 2;

For large indices, low + high may overflow. Prefer: 

int mid = low + (high - low) / 2;

Error 4: Incorrect Range Update

low = mid;
high = mid;

This can cause an infinite loop because the search range may not shrink.

Correct updates:

low = mid + 1;
high = mid - 1;

Error 5: Confusing Index and Position

Array indices start at zero. If an interview question asks for a one-based position, return index + 1 when an element is found.

17. Technical Interview Questions

Q1. What is linear search?

A sequential searching technique that compares the search key with each array element.

Q2. What is binary search?

A searching algorithm that repeatedly halves a sorted search range.

Q3. Why must an array be sorted for binary search?

Binary search decides which half to discard using the ordering of elements. Without sorted order, this decision is not reliable.

Q4. What is the worst-case complexity of linear search?

O(n).

Q5. What is the worst-case complexity of binary search?

O(log n).

Q6. What is the difference between iterative and recursive binary search?

Iterative binary search uses a loop and O(1) auxiliary space. Recursive binary search uses function calls and O(log n) call-stack space.

Q7. Can binary search find duplicate values?

Yes. Modified binary search can locate the first or last occurrence of a duplicate value in a sorted array.

Q8. What is the lower bound concept?

The first position at which an element is greater than or equal to a target value in a sorted sequence.

Q9. What is the upper bound concept?

The first position at which an element is strictly greater than a target value in a sorted sequence.

Q10. Can binary search be used on a linked list efficiently?

Not in the same way as an array. A linked list does not provide constant-time random access, so reaching middle elements requires traversal.

19. Key Concepts for Placement Interviews

  • Linear search works on sorted and unsorted arrays.
  • Binary search requires sorted data.
  • Linear search has O(n) worst-case time complexity.
  • Binary search has O(log n) worst-case time complexity.
  • Iterative binary search uses O(1) auxiliary space.
  • Recursive binary search uses O(log n) call-stack space.
  • Modified binary search can find first and last occurrences.
  • Updating an element after finding its index takes O(1).
  • Always handle empty arrays and missing search keys.
