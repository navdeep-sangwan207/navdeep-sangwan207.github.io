2. General Structure of a C Program

A C program consists of declarations, function definitions, statements and other language elements. A typical beginner-level program includes a header file and a main() function.

Basic Program Structure

/* Documentation section */

#include <stdio.h>

#define MESSAGE "Hello from C"

int main(void)
{
    /* Declaration section */
    int number = 10;

    /* Executable statements */
    printf("%s\n", MESSAGE);
    printf("Number = %d\n", number);

    return 0;
}

Expected Output

Hello from C
Number = 10

Explanation of Program Sections

Program Element Purpose
Documentation comments Describe the program and its purpose.
#include Includes declarations from a header file.
#define Defines a preprocessing macro.
main() Defines the entry point of a hosted C program.
Variable declaration Introduces an object and its type.
Statements Perform operations during execution.
return 0; Indicates successful termination from main().
These are common logical sections, not mandatory fixed sections that every C program must contain. A program only needs the language elements required for its task.

3. Understanding the main() Function

In a hosted C environment, program execution begins by calling the function named main. It is the designated entry point of a hosted C program.

Standard Form

int main(void)
{
    return 0;
}

Meaning of Each Part

  • int: Specifies the return type of main().
  • main: The function name recognized as the program entry point.
  • void: Indicates that the function takes no parameters.
  • { }: Enclose the function body.
  • return 0; Reports successful program termination.

main() with Command-Line Arguments

C also supports a standard form of main() that receives command-line arguments. 

#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("Number of arguments: %d\n", argc);

    if (argc > 1) {
        printf("First argument: %s\n", argv[1]);
    }

    return 0;
}

Here, argc represents the argument count and argv is an array of pointers to argument strings.

The two standard hosted forms are int main(void) and int main(int argc, char *argv[]). Some environments also support implementation-specific forms.

4. Declarations, Statements and Expressions

4.1 Declaration

A declaration introduces an identifier and specifies information about it, such as its type. 

int age;
float salary;
char grade;

4.2 Initialization

Initialization gives an object its initial value when it is defined. 

int age = 25;
float salary = 25000.50f;
char grade = 'A';

4.3 Statement

A statement is an instruction that forms part of program execution. 

int number = 10;
number = number + 5;
printf("%d\n", number);

4.4 Expression

An expression combines operands and operators to produce a value or perform an operation. 

int result = 10 + 20 * 2;

The expression evaluates to 50 because multiplication has higher precedence than addition.

Concept Example
Declaration int count;
Initialization int count = 5;
Assignment statement count = 10;
Expression count + 5
Function call statement printf("%d", count);

5. Blocks and Compound Statements

A block is a sequence of declarations and statements enclosed within opening and closing braces. A block is also called a compound statement. 

#include <stdio.h>

int main(void)
{
    int number = 10;

    {
        int value = 20;
        printf("Value = %d\n", value);
    }

    printf("Number = %d\n", number);

    return 0;
}
Value = 20
Number = 10

The variable value is declared inside the inner block and is accessible only within its scope. The variable number is declared in the outer block and remains accessible throughout the remainder of that block.

6. Comments in C

Comments are notes written in source code for programmers. They are ignored by the compiler during normal compilation.

6.1 Single-Line Comment

// This is a single-line comment

int number = 10; // Store a value

6.2 Multi-Line Comment

/*
   This is a multi-line comment.
   It can span multiple lines.
*/

int result = 100;

Important Comment Rules

  • Single-line comments begin with //.
  • Multi-line comments begin with /* and end with */.
  • Traditional block comments cannot be nested.
  • Comments should explain intent or non-obvious logic.
Avoid placing important executable code inside comments. Commented-out code can become confusing and difficult to maintain.

7. Semicolons, Braces and Syntax Rules

Semicolon (;)

A semicolon terminates most expression statements and declaration statements in C. 

int number = 10;
number = number + 5;
printf("%d\n", number);

Braces ({ })

Braces group statements into a block, such as a function body, conditional body or loop body.

Case Sensitivity

C is case-sensitive. Identifiers that differ in letter case are treated as different identifiers. 

int value = 10;
int Value = 20;
int VALUE = 30;

These are three distinct identifiers.

Whitespace

Spaces, tabs and newlines generally separate tokens or improve readability. They do not usually change the meaning of a program when placed between tokens appropriately.

Statement Termination

int a = 10;       // Correct
int b = 20        // Missing semicolon

if (a > b) {
    printf("A is greater\n");
}
Do not add a semicolon immediately after an if condition unless you intentionally want an empty statement. For example, if (a > b); does not control the following block.

8. Functions: Declaration, Definition and Calling

A function is a named unit of code that performs a specific task. Functions help divide a program into reusable and manageable parts.

8.1 Function Declaration (Prototype)

A function declaration tells the compiler the function's name, return type and parameter types. 

int add(int, int);

8.2 Function Definition

A function definition contains the actual implementation. 

int add(int a, int b)
{
    return a + b;
}

8.3 Function Call

A function call transfers control to the function to perform the required operation. 

int result = add(10, 20);

Complete Example

#include <stdio.h>

int add(int, int);

int main(void)
{
    int result;

    result = add(15, 25);

    printf("Sum = %d\n", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}
Sum = 40
Term Meaning
Declaration Introduces the function interface.
Definition Provides the function implementation.
Call Invokes the function.

9. Scope of Variables: Basic Introduction

Scope determines where an identifier can be accessed in a program. This lecture introduces block scope; storage duration and linkage are covered in detail in Chapter 10. 

#include <stdio.h>

int main(void)
{
    int outer = 100;

    if (outer > 50) {
        int inner = 200;
        printf("Inner = %d\n", inner);
    }

    printf("Outer = %d\n", outer);

    return 0;
}
Inner = 200
Outer = 100

The variable inner is accessible only inside the if block. Attempting to use it after that block results in a scope error.

Incorrect Code Problem Correction
int a = 10 Missing semicolon int a = 10;
Printf("Hello"); Incorrect case printf("Hello");
int main() Empty parameter list is not the clearest C11 prototype form int main(void)
printf("Hello); Missing closing quote printf("Hello");
return 0 Missing semicolon return 0;
{ printf("Hi"); Missing closing brace { printf("Hi"); }
Compile with warnings enabled: 
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main
Compiler warnings help identify suspicious code even when it does not produce a compilation error.

11. Program Execution Flow

In a hosted C program, execution begins in main(). When a function is called, control transfers to that function. After it returns, execution continues from the point following the call. 

#include <stdio.h>

void display(void)
{
    printf("Inside display function\n");
}

int main(void)
{
    printf("Program starts\n");

    display();

    printf("Back inside main\n");

    return 0;
}
Program starts
Inside display function
Back inside main

Execution Sequence

  1. Program execution begins by calling main().
  2. The first printf() statement executes.
  3. display() is called.
  4. Control moves to display().
  5. display() executes its statement and returns.
  6. Execution resumes in main().
  7. The final printf() executes.
  8. main() returns 0 and the program terminates successfully.

12. Placement Interview Questions

Q1. What is the purpose of the main() function?
In a hosted C program, main() is the designated entry-point function from which program execution begins.
Q2. Why is int main(void) preferred in C11?
It explicitly specifies that main() accepts no parameters and returns an integer status to the execution environment.
Q3. What is the difference between a declaration and a definition?
A declaration introduces an identifier and its properties. A definition provides the entity itself, such as allocating storage for an object or providing a function body.
Q4. What is a function prototype?
A function prototype is a declaration that specifies the function's name, return type and parameter types.
Q5. Why are braces used in C?
Braces group declarations and statements into a compound statement or block.
Q6. Is C case-sensitive?
Yes. For example, total, Total and TOTAL are different identifiers.
Q7. What is the difference between a statement and an expression?
An expression computes a value or performs an operation. A statement is a complete unit of execution or declaration in the program.
Q8. What is the purpose of return 0 in main()?
It indicates successful termination of a hosted program.
Q9. What happens if a semicolon is omitted?
If the semicolon is required at that location, the compiler will generally report a syntax error.
Q10. Can a C program contain multiple functions?
Yes. A C program can contain many functions, with main() serving as the entry point in a hosted environment.

13. Output Prediction Practice

Q1. Predict the output: 
#include <stdio.h>

void show(void)
{
    printf("A\n");
}

int main(void)
{
    printf("B\n");
    show();
    printf("C\n");

    return 0;
}
Expected Output: 
B
A
C
Reason: The function call executes show() before main() continues to the final printf().
Q2. Predict the output: 
#include <stdio.h>

int main(void)
{
    int x = 10;

    {
        int x = 20;
        printf("%d\n", x);
    }

    printf("%d\n", x);

    return 0;
}
Expected Output: 
20
10
Reason: The inner block declares a separate variable x that hides the outer x within that block.

14. Programming Exercises

Beginner Exercises

  1. Write a C program that prints your name, qualification and city.
  2. Write a program that displays five separate lines of text.
  3. Write a program using single-line and multi-line comments.
  4. Write a program that declares three variables and prints their values.

  3. Write a function that calculates the square of an integer.

Debugging Exercises

  1. Correct a program containing a missing semicolon.
  2. Correct a program containing mismatched braces.
  3. Correct a program with an incorrectly written function name.
  4. Identify an attempt to access a variable outside its block scope.

15. Lesson Summary

  • A C program consists of declarations, functions and statements.
  • main() is the entry point of a hosted C program.
  • Declarations introduce identifiers and their properties.
  • Statements represent complete program instructions.
  • Expressions produce values or perform operations.
  • Braces define blocks and compound statements.
  • Comments improve source-code readability.
  • Functions make programs modular and reusable.
  • C is case-sensitive and follows specific syntax rules.
