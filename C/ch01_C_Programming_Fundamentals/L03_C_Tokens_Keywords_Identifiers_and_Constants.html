Lecture 03: C Tokens, Keywords, Identifiers and Constants

Chapter 1: C Programming Fundamentals

Placement-Oriented C Programming | ISO C11

1. Learning Objective

After completing this lecture, you should be able to:

  • Define tokens in the C programming language.
  • Identify the different categories of C tokens.
  • Recognize C11 keywords and their purposes.
  • Apply identifier naming rules.
  • Differentiate variables, constants and literals.
  • Understand integer, floating-point, character and string literals.
  • Use const and #define appropriately.
  • Identify common token-related errors in C programs.

2. What Are Tokens in C?

Tokens are the smallest meaningful lexical elements recognized by the C compiler during the translation of a source program.

Definition: A token is a sequence of characters that is recognized as a single lexical unit by the C compiler.

Example Program

int total = 10 + 20;

Token Identification

Token Category
int Keyword
total Identifier
= Operator
10 Integer constant (literal)
+ Operator
20 Integer constant (literal)
; Punctuator

The spaces between tokens help separate them but are not themselves tokens in this example.

3. Types of Tokens in C

C tokens can be grouped into the following major categories for learning and analysis.

3.1 Keywords

Keywords are reserved words that have predefined meanings in the C language. They cannot be used as ordinary identifiers. 

int age;
if (age > 18) {
    return 1;
}

Here, int, if and return are keywords.

3.2 Identifiers

Identifiers are names given to program elements such as variables, functions, arrays and structures. 

int studentAge;
float salary;

void display(void)
{
    printf("Welcome\n");
}

studentAge, salary and display are identifiers.

3.3 Constants and Literals

Literals are fixed values written directly in source code. Examples include integer, floating-point and character literals. 

int count = 100;
float price = 25.50f;
char grade = 'A';

3.4 String Literals

A string literal is a sequence of characters enclosed in double quotation marks. 

printf("Hello World");

3.5 Operators

Operators perform operations on operands. 

int sum = a + b;
int remainder = a % b;

3.6 Punctuators

Punctuators help organize C program syntax. 

int main(void)
{
    int value = 10;
    printf("%d\n", value);
    return 0;
}

Examples include:

  • Parentheses: ( )
  • Braces: { }
  • Brackets: [ ]
  • Semicolon: ;
  • Comma: ,
  • Colon: :

4. C11 Keywords

5. Identifiers in C

An identifier is a user-defined name used to identify a variable, function, array, structure, enumeration constant or another program entity.

5.1 Rules for Naming Identifiers

  • An identifier can contain letters, digits and underscores.
  • The first character must be a letter or underscore.
  • An identifier cannot begin with a digit.
  • Keywords cannot be used as ordinary identifiers.
  • Identifiers are case-sensitive.
  • Spaces and special characters such as @ and # are not allowed.

5.2 Valid Identifiers

age
student_name
totalMarks
value1
_count
MAX_SIZE

5.3 Invalid Identifiers

Identifier Reason
1value Starts with a digit.
student name Contains a space.
float It is a keyword.
total@value Contains an invalid special character.
first-name Contains a hyphen.

5.4 Case Sensitivity

#include <stdio.h>

int main(void)
{
    int value = 10;
    int Value = 20;

    printf("%d\n", value);
    printf("%d\n", Value);

    return 0;
}
10
20

value and Value are treated as two different identifiers.

5.5 Good Naming Practices

  • Use meaningful names such as totalMarks instead of x.
  • Use consistent naming conventions throughout the project.
  • Choose names that describe the purpose of variables and functions.
  • Avoid names that are too long or difficult to understand.

6. Constants and Literals

A literal is a value written directly in source code. A constant is a value that is not intended to change during its relevant use.

6.1 Integer Literals

Integer literals represent whole-number values. 

int decimal = 100;
int octal = 0144;
int hexadecimal = 0x64;

All three initializers represent the decimal value 100.

6.2 Floating-Point Literals

Floating-point literals represent values containing a fractional part or an exponent. 

float price = 25.50f;
double pi = 3.141592;
double distance = 1.5e3;

The suffix f or F specifies a float literal. Without it, a floating-point literal has type double by default.

6.3 Character Literals

Character constants are written inside single quotation marks. 

char grade = 'A';
char digit = '5';
char newline = '\n';

6.4 Escape Sequences

Escape sequences represent special characters inside character and string literals.

Escape Sequence Meaning
\nNewline
\tHorizontal tab
\\Backslash
\"Double quotation mark
\'Single quotation mark
\0Null character
\rCarriage return

6.5 String Literals

String literals are sequences of characters enclosed in double quotation marks. In C, a string literal is represented by an array of characters that includes a terminating null character. 

char message[] = "Hello";
printf("%s\n", message);
The array initialized from "Hello" contains six characters: H, e, l, l, o and the terminating '\0'.

7. Symbolic Constants Using const

The const type qualifier indicates that an object cannot be modified through the declared const-qualified lvalue. 

#include <stdio.h>

int main(void)
{
    const float PI = 3.14159f;
    float radius = 5.0f;

    float area = PI * radius * radius;

    printf("Area = %.2f\n", area);

    return 0;
}
Area = 78.54

Important Points

  • const is a type qualifier.
  • A const-qualified object cannot be modified through that const-qualified expression.
  • A const object must be initialized appropriately when required by its storage duration and declaration context.
  • const does not automatically make every object a compile-time constant expression in C.
This is invalid: 
const int number = 10;
number = 20;  // Constraint violation
A conforming compiler must issue a diagnostic for this violation.

8. Symbolic Constants Using #define

The #define directive creates a preprocessing macro. It can be used to give a meaningful name to a replacement sequence. 

#include <stdio.h>

#define MAX_MARKS 100

int main(void)
{
    int marks = 85;

    printf("Maximum marks = %d\n", MAX_MARKS);
    printf("Obtained marks = %d\n", marks);

    return 0;
}
Maximum marks = 100
Obtained marks = 85

const vs #define

Feature const #define
Processing Handled as a C declaration Handled by the preprocessor
Type Has a declared type Macro replacement has no declared C type by itself
Storage Object storage depends on its declaration and use Does not create an object merely by being defined
Scope Follows C scope and linkage rules Controlled by preprocessing directives
Typical use Read-only objects Macros and conditional compilation
Prefer const-qualified objects when a typed object is required. Use macros when preprocessing behavior is needed, such as conditional compilation or function-like macros.

9. Integer Literal Suffixes and Character Types

Integer literals can use suffixes to influence their type. Common suffixes include U, L and LL, with combinations such as UL and ULL. 

unsigned int count = 100U;
long int population = 1000000L;
long long int distance = 9000000000LL;
unsigned long long int id = 123456789ULL;

The compiler determines the type of an integer literal using its value, base and suffix according to the C language rules.

Character Constants

In C, an ordinary character constant such as 'A' has type int, not char. It can still be assigned to a char object when the value is representable. 

#include <stdio.h>

int main(void)
{
    char letter = 'A';

    printf("Character = %c\n", letter);
    printf("Code value = %d\n", letter);

    return 0;
}

The numeric value printed for a character depends on the execution character set. ASCII-compatible environments commonly print 65 for 'A'.

10. Token Recognition and Common Errors

Example 1: Missing Space Between Tokens

intmain(void)
{
    return 0;
}

intmain is treated as one identifier, not as the keyword int followed by main. It therefore does not define the required main function.

Example 2: Using a Keyword as an Identifier

int return = 10;

This is invalid because return is a reserved keyword.

Example 3: Invalid Identifier

int 2value = 10;

An identifier cannot begin with a digit.

Example 4: Incorrect Character Literal

char grade = "A";

"A" is a string literal, while 'A' is an integer character constant. For a single character variable, use: 

char grade = 'A';

Example 5: Incorrect Macro Usage

#define SQUARE(x) x * x

int result = SQUARE(2 + 3);

The macro expands to 2 + 3 * 2 + 3, producing 11 instead of 25. Parentheses are needed around both the parameter and the complete replacement expression. 

#define SQUARE(x) ((x) * (x))
Function-like macros perform textual substitution. They do not provide the same type checking or argument evaluation behavior as ordinary functions. A macro argument used more than once may also be evaluated more than once.

11. Placement Interview Questions

Q1. What are tokens in C?
Tokens are the smallest meaningful lexical elements recognized by the compiler, such as keywords, identifiers, constants, string literals, operators and punctuators.
Q2. How many keywords are there in C11?
C11 defines 44 core language keywords.
Q3. Can a keyword be used as a variable name?
No. Keywords are reserved and cannot be used as ordinary identifiers.
Q4. Is C case-sensitive?
Yes. Names that differ in uppercase and lowercase letters are treated as different identifiers.
Q5. What is an identifier?
An identifier is a name used to identify a program entity such as a variable, function or structure.
Q6. What is the difference between a character and a string literal?
A character constant uses single quotation marks, such as 'A'. A string literal uses double quotation marks, such as "A", and includes a terminating null character in its array representation.
Q7. What is the difference between const and #define?
const declares a typed, qualified object. #define creates a preprocessing macro through textual replacement.
Q8. What is a punctuator?
A punctuator is a lexical token used to organize program syntax, such as braces, parentheses, brackets and semicolons.
Q9. Is sizeof a keyword?
Yes. sizeof is a C keyword and operator that yields the size in bytes of its operand's type or expression.
Q10. What is the type of an ordinary character constant like 'A'?
It has type int in C.
Q11. What is the difference between a literal and a variable?
A literal is a value written directly in source code. A variable is a named object whose stored value may change, subject to its type and qualifiers.
Q12. Can an identifier contain an underscore?
Yes. Underscores are permitted in identifiers, subject to the language's reserved identifier rules.

12. Output Prediction Practice

Q1. Predict the output: 
#include <stdio.h>

int main(void)
{
    int value = 10;
    int Value = 20;

    printf("%d %d\n", value, Value);

    return 0;
}
Expected Output: 
10 20
Reason: Identifiers are case-sensitive.
Q2. Predict the output: 
#include <stdio.h>

#define NUMBER 25

int main(void)
{
    int result = NUMBER + 5;

    printf("%d\n", result);

    return 0;
}
Expected Output: 
30
Reason: The preprocessor replaces NUMBER with 25 before compilation.

15. Lesson Summary

  • Tokens are the smallest meaningful lexical units of C source code.
  • The major token categories include keywords, identifiers, constants, string literals, operators and punctuators.
  • C11 defines 44 core language keywords.
  • Identifiers follow naming rules and are case-sensitive.
  • Literals represent values written directly in source code.
  • const declares qualified objects, while #define creates preprocessing macros.
  • Ordinary character constants have type int in C.
  • String literals include a terminating null character in their array representation.
