2. What Are Function Arguments and Parameters?

A function can receive data from the calling function. This data is supplied through arguments and received through parameters.

Example

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result = add(10, 20);

    printf("Sum = %d\n", result);

    return 0;
}
Output: 
Sum = 30

In this program:

  • a and b are formal parameters.
  • 10 and 20 are actual arguments.
  • The values are passed when add() is called.
  • The function calculates and returns their sum.

3. Actual Arguments and Formal Parameters

Actual Arguments

Actual arguments are the values or expressions supplied in a function call. 

add(10, 20);

Here, 10 and 20 are actual arguments.

Formal Parameters

Formal parameters are the variables declared in the function definition that receive the argument values. 

int add(int a, int b)
{
    return a + b;
}

Here, a and b are formal parameters.

Actual Arguments Formal Parameters
Appear in the function call. Appear in the function definition.
Supply values or expressions. Receive the corresponding values.
Example: add(10, 20) Example: int add(int a, int b)
In C, arguments are passed by value. The function parameters receive values derived from the corresponding arguments. Pointer arguments can be used to access and modify objects belonging to the caller.

4. Types of Function Arguments

Arguments may be constants, variables or expressions, provided they produce values compatible with the corresponding parameter types.

A. Constant Arguments

int result = add(10, 20);

B. Variable Arguments

int x = 10;
int y = 20;

int result = add(x, y);

C. Expression Arguments

int result = add(5 + 5, 10 * 2);

The expressions are evaluated before their resulting values are used as arguments.

Complete Program

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Constants: %d\n", add(5, 15));
    printf("Variables: %d\n", add(x, y));
    printf("Expressions: %d\n", add(x + 5, y * 2));

    return 0;
}
Output: 
Constants: 20
Variables: 30
Expressions: 55

5. Matching Arguments with Parameters

The arguments in a function call correspond to parameters by their position in the parameter list. 

#include <stdio.h>

void display(int number, char letter)
{
    printf("Number = %d\n", number);
    printf("Letter = %c\n", letter);
}

int main(void)
{
    display(100, 'A');

    return 0;
}
Output: 
Number = 100
Letter = A

The first argument corresponds to the first parameter, and the second argument corresponds to the second parameter.

C does not match function arguments by parameter names. Their positions and types matter. Passing an incompatible argument can produce a diagnostic or result in undefined behavior, depending on the types and conversions.

6. Functions With Multiple Parameters

A function can accept multiple parameters to perform operations involving several input values.

Example: Find the Largest of Three Numbers

#include <stdio.h>

int findMaximum(int a, int b, int c)
{
    int maximum = a;

    if (b > maximum)
    {
        maximum = b;
    }

    if (c > maximum)
    {
        maximum = c;
    }

    return maximum;
}

int main(void)
{
    int result = findMaximum(25, 80, 45);

    printf("Maximum = %d\n", result);

    return 0;
}
Output: 
Maximum = 80

Important Observation

  • The function receives three integer arguments.
  • The parameters are a, b and c.
  • The function compares all three values.
  • The maximum value is returned to main().

7. Understanding the return Statement

The return statement terminates the current function and, when an expression is supplied, provides a value to the caller.

Syntax

return expression;

Example

int square(int number)
{
    return number * number;
}

If square(5) is called, the function returns 25.

Returning a Variable

int calculateSum(int a, int b)
{
    int sum = a + b;

    return sum;
}

Returning an Expression

int calculateDifference(int a, int b)
{
    return a - b;
}
A return expression is converted to the function's declared return type according to C's conversion rules. Choose return types carefully to avoid unintended truncation or loss of information.

8. Using Returned Values

A returned value can be stored in a variable, printed directly, or used as part of another expression.

A. Store in a Variable

int result = add(10, 20);

B. Print Directly

printf("%d\n", add(10, 20));

C. Use in an Expression

int result = add(10, 20) * 2;

Complete Program

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result;

    result = add(10, 20);

    printf("Stored result = %d\n", result);
    printf("Direct result = %d\n", add(5, 15));
    printf("Expression result = %d\n", add(2, 3) * 4);

    return 0;
}
Output: 
Stored result = 30
Direct result = 20
Expression result = 20

9. Void Functions and Return Values

A void function performs an operation without returning a value to the caller.

Example

#include <stdio.h>

void displaySum(int a, int b)
{
    int sum = a + b;

    printf("Sum = %d\n", sum);
}

int main(void)
{
    displaySum(10, 20);

    return 0;
}
Output: 
Sum = 30

Returning from a Void Function

void checkNumber(int number)
{
    if (number < 0)
    {
        printf("Negative number\n");
        return;
    }

    printf("Non-negative number\n");
}

The statement return; exits the function without returning a value.

A void function cannot return an expression value. For example, return 10; is invalid in a function declared with return type void.

10. Returning Values of Different Data Types

Integer Return

int getCount(void)
{
    return 100;
}

Floating-Point Return

float calculateAverage(float total, int count)
{
    if (count <= 0)
    {
        return 0.0f;
    }

    return total / count;
}

Character Return

char getGrade(void)
{
    return 'A';
}

Double Return

double calculateSquare(double value)
{
    return value * value;
}
The type of the returned expression should be compatible with the declared return type. The compiler may perform permitted conversions, but implicit conversions should not be relied upon when they lose important precision.

11. Returning a Structure

A C function can return a structure value. This is useful when a calculation produces several related results.

Example: Return Quotient and Remainder

#include <stdio.h>

struct DivisionResult
{
    int quotient;
    int remainder;
};

struct DivisionResult divideNumbers(int dividend, int divisor)
{
    struct DivisionResult result = {0, 0};

    if (divisor != 0)
    {
        result.quotient = dividend / divisor;
        result.remainder = dividend % divisor;
    }

    return result;
}

int main(void)
{
    struct DivisionResult answer = divideNumbers(17, 5);

    printf("Quotient = %d\n", answer.quotient);
    printf("Remainder = %d\n", answer.remainder);

    return 0;
}
Output: 
Quotient = 3
Remainder = 2

This example checks for a zero divisor before performing division or remainder operations.

12. Function Result and Expression Evaluation

A function call that returns a value can participate in a larger expression. 

#include <stdio.h>

int getValue(void)
{
    return 10;
}

int main(void)
{
    int result;

    result = getValue() + 5;

    printf("Result = %d\n", result);

    return 0;
}
Output: 
Result = 15

Important: Avoid Unspecified Evaluation Order

Do not assume that function calls or modifications inside a complex expression are evaluated in a particular left-to-right order.

For example, avoid expressions such as printf("%d %d", functionA(), functionB()); when the functions modify shared state and the result depends on which one executes first. The order of evaluating function arguments is unspecified in C.

13. Example: Calculator Using Return Values

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int first = 20;
    int second = 4;

    printf("Addition = %d\n", add(first, second));
    printf("Subtraction = %d\n", subtract(first, second));
    printf("Multiplication = %d\n", multiply(first, second));

    return 0;
}
Output: 
Addition = 24
Subtraction = 16
Multiplication = 80

14. Common Errors in Arguments and Return Values

Error Explanation
Wrong number of arguments The call does not supply the required number of arguments.
Incorrect argument type An argument may not be compatible with its parameter type.
Incorrect parameter order Values are assigned to parameters according to position.
Ignoring a return value A calculated result may be discarded when it should be used.
Wrong return type The declared return type may not represent the intended result.
Missing return path A non-void function may reach its end without producing a required value.
Using an uninitialized variable An indeterminate value may be passed as an argument.

16. Technical Interview Questions

Q1. What is the difference between an argument and a parameter?

An argument is supplied in a function call. A parameter is declared in the function definition and receives the corresponding value.

Q2. What is the purpose of a return statement?

It terminates the current function and can provide a value to the calling expression.

Q3. Can a function return a float value?

Yes. A function can declare float as its return type.

Q4. Can a function return an array directly?

A C function cannot return an array type directly. It can return a pointer or a structure containing an array, subject to object lifetime and ownership considerations.

Q5. Can a function return a structure?

Yes. C functions can return structure values.

Q6. Can a void function return a value?

No. It can use return; to exit early but cannot return an expression value.

Q7. Can a function have multiple return statements?

Yes. A function may contain multiple return statements. Only the one reached during execution is executed.

Q8. Does C support call by reference?

C passes arguments by value. A function can receive a pointer value and use it to modify the object referenced by that pointer.

Q9. What happens if a function returns an integer but its result is assigned to a float variable?

The integer result is converted to float during assignment.

Q10. Can a function call be used directly in printf()?

Yes, if the function returns a value compatible with the corresponding format specifier and the call has no problematic side effects.
