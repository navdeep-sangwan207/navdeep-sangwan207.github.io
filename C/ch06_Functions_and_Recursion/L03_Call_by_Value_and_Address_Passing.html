2. How C Passes Function Arguments

C uses pass by value for all function arguments. This means that a function receives a value derived from the corresponding argument, rather than automatically receiving access to the original variable.

When the argument is a pointer, the pointer value itself is copied. The function can use that copied pointer to access the object it points to.

C does not have native call-by-reference parameter semantics. What is commonly called address passing or call by reference in C is implemented by passing pointer values.

3. Call by Value

In call by value, the function parameter receives a copy of the argument's value. Changing that parameter does not change the original variable in the calling function.

Example

#include <stdio.h>

void changeValue(int number)
{
    number = 100;

    printf("Inside function = %d\n", number);
}

int main(void)
{
    int value = 10;

    printf("Before function call = %d\n", value);

    changeValue(value);

    printf("After function call = %d\n", value);

    return 0;
}
Output: 
Before function call = 10
Inside function = 100
After function call = 10

Explanation

  1. value in main() contains 10.
  2. changeValue(value) passes the value 10.
  3. The parameter number receives its own copy.
  4. number is changed to 100.
  5. The original value in main() remains 10.

4. Memory Concept of Call by Value

Conceptually, the caller's object and the function's parameter are separate objects.

Object Value Role
value in main() 10 Original variable
number in changeValue() 10 initially Separate parameter object

Updating number changes only the parameter object. It does not update value.

A compiler may optimize how objects are represented internally. The important C-language rule is that the parameter is a distinct object with a copied value.

5. Passing an Address to a Function

If a function needs to modify a caller's variable, pass the address of that variable.

Two operators are important:

Operator Meaning Example
& Address-of operator &number
* Dereference operator *ptr

Example

#include <stdio.h>

void changeValue(int *ptr)
{
    *ptr = 100;
}

int main(void)
{
    int value = 10;

    printf("Before function call = %d\n", value);

    changeValue(&value);

    printf("After function call = %d\n", value);

    return 0;
}
Output: 
Before function call = 10
After function call = 100

Explanation

  1. value stores 10.
  2. &value produces the address of value.
  3. The address is passed to changeValue().
  4. ptr receives a copy of that address.
  5. *ptr accesses the object at that address.
  6. Assigning 100 through *ptr modifies value.

6. Understanding Pointer Parameter Syntax

void update(int *ptr)
{
    *ptr = 50;
}

Here:

  • int *ptr declares ptr as a pointer to int.
  • ptr stores an address of an int object.
  • *ptr accesses the pointed-to integer object.
  • Assigning to *ptr changes that object.

Calling the Function

int number = 20;

update(&number);
A pointer must point to a valid object before it is dereferenced. Dereferencing a null, uninitialized, dangling or otherwise invalid pointer causes undefined behavior.

7. Call by Value vs Address Passing

Feature Call by Value Address Passing
Function argument Ordinary value Pointer value, often produced using &
Parameter Ordinary variable Pointer variable
Access to caller object Not through the copied scalar parameter Possible through the pointer
Can modify caller object? Not by modifying the parameter alone Yes, by dereferencing a valid pointer
Typical use Input values Output parameters and in-place modification

8. Swapping Two Numbers Using Call by Value

Consider a function that attempts to swap two numbers using ordinary parameters. 

#include <stdio.h>

void swap(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    swap(x, y);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
Output: 
x = 10
y = 20

The function swaps only its local parameter copies. The variables in main() remain unchanged.

9. Swapping Two Numbers Using Pointers

To swap the original variables, pass their addresses. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Before swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    return 0;
}
Output: 
Before swapping:
x = 10, y = 20
After swapping:
x = 20, y = 10

How Swapping Works

Statement Effect
temp = *a Save the first original value.
*a = *b Copy the second value into the first object.
*b = temp Copy the saved first value into the second object.

10. Returning Multiple Results Using Output Parameters

A C function has one return value. However, a function can update multiple caller-owned variables through pointer parameters.

Example: Calculate Sum and Difference

#include <stdio.h>

void calculate(int a, int b, int *sum, int *difference)
{
    *sum = a + b;
    *difference = a - b;
}

int main(void)
{
    int x = 20;
    int y = 8;

    int sum;
    int difference;

    calculate(x, y, &sum, &difference);

    printf("Sum = %d\n", sum);
    printf("Difference = %d\n", difference);

    return 0;
}
Output: 
Sum = 28
Difference = 12

The function uses two pointer parameters to write the results into variables belonging to main().

11. Example: Quotient and Remainder

This program uses output parameters to return both quotient and remainder. 

#include <stdio.h>

int divideNumbers(int dividend, int divisor,
                  int *quotient, int *remainder)
{
    if (divisor == 0)
    {
        return 0;
    }

    *quotient = dividend / divisor;
    *remainder = dividend % divisor;

    return 1;
}

int main(void)
{
    int quotient;
    int remainder;

    if (divideNumbers(17, 5, &quotient, &remainder))
    {
        printf("Quotient = %d\n", quotient);
        printf("Remainder = %d\n", remainder);
    }
    else
    {
        printf("Division by zero is not allowed.\n");
    }

    return 0;
}
Output: 
Quotient = 3
Remainder = 2

The function returns a status value:

  • 1 indicates success.
  • 0 indicates failure because the divisor is zero.
  • The output parameters receive the quotient and remainder on success.
A status return combined with output parameters is a common C interface design. It separates error reporting from the calculated output values.

12. Pointer Parameters and Arrays

When an array is passed to a function, the array expression is converted to a pointer to its first element in this context. The function receives a pointer value, not a complete copy of the array.

Example: Modify Array Elements

#include <stdio.h>

void doubleElements(int arr[], int size)
{
    for (int i = 0; i < size; i++)
    {
        arr[i] = arr[i] * 2;
    }
}

int main(void)
{
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);

    doubleElements(numbers, size);

    for (int i = 0; i < size; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Output: 
2 4 6 8 10
The function parameter arr[] is adjusted to a pointer parameter. It does not carry the array's length. Pass the size separately to avoid accessing elements outside the array bounds.

13. Using const with Pointer Parameters

Sometimes a function needs to read data through a pointer but should not modify the pointed-to object.

Example: Calculate Array Sum

#include <stdio.h>

int calculateSum(const int arr[], int size)
{
    int sum = 0;

    for (int i = 0; i < size; i++)
    {
        sum += arr[i];
    }

    return sum;
}

int main(void)
{
    int numbers[] = {10, 20, 30, 40};
    int size = sizeof(numbers) / sizeof(numbers[0]);

    printf("Sum = %d\n", calculateSum(numbers, size));

    return 0;
}
Output: 
Sum = 100

const int arr[] prevents this function from modifying array elements through arr.

14. Pointer Safety in Function Calls

Check for NULL When Appropriate

#include <stdio.h>

int updateValue(int *ptr)
{
    if (ptr == NULL)
    {
        return 0;
    }

    *ptr = 500;

    return 1;
}

int main(void)
{
    int number = 100;

    if (updateValue(&number))
    {
        printf("Updated value = %d\n", number);
    }

    return 0;
}
Output: 
Updated value = 500

Important Safety Rules

  • Do not dereference a NULL pointer.
  • Do not dereference an uninitialized pointer.
  • Do not pass the address of an object that no longer exists.
  • Do not access memory outside an object's lifetime.
  • Ensure output parameters point to writable objects.
  • Document whether pointer parameters may be NULL.

15. Common Mistakes

Mistake Why It Is Wrong Correction
Passing value instead of address The function receives only a scalar copy. Pass &variable when a pointer parameter is required.
Using int instead of int * The parameter cannot receive an int pointer correctly. Declare the parameter as a pointer.
Using ptr instead of *ptr This accesses the pointer value rather than the pointed-to integer. Dereference ptr when modifying the object.
Passing an invalid address The function may access an object that does not exist or is not writable. Pass a valid object address.
Ignoring array size The function cannot reliably determine the array length from the pointer. Pass the element count separately.
Dereferencing NULL Causes undefined behavior. Check pointer validity before dereferencing when NULL is permitted.

17. Technical Interview Questions

Q1. Does C support call by reference?

No. C uses pass by value. Pointer values can be passed so that a function can access and modify caller-owned objects.

Q2. Why does changing a function parameter not change the original variable?

Because the parameter receives a separate copy of the argument value.

Q3. How can a function modify a caller's variable?

Pass the variable's address and modify the object through a valid pointer parameter.

Q4. What is the difference between ptr and *ptr?

ptr represents the pointer value, while *ptr accesses the object pointed to by ptr.

Q5. Why is a pointer used in a swap function?

It allows the function to modify the original variables rather than only swapping local parameter copies.

Q6. Can a function return multiple values in C?

It can communicate multiple results through output parameters or return a structure containing related values.

Q7. Why should array size be passed separately?

An array function parameter is adjusted to a pointer. The pointer does not automatically contain the array length.

Q8. What is an output parameter?

An output parameter is a function parameter, commonly a pointer, through which the function writes a result back to the caller.
