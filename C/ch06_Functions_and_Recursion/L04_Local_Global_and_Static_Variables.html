2. What Is Variable Scope?

Scope determines the region of a program in which an identifier can be accessed directly.

In C, the main kinds of identifier scope are:

  • Block scope
  • File scope
  • Function scope (for labels)
  • Function prototype scope

For ordinary variables, block scope and file scope are especially important.

Example

#include <stdio.h>

int globalValue = 100;

void display(void)
{
    int localValue = 20;

    printf("Local = %d\n", localValue);
    printf("Global = %d\n", globalValue);
}

int main(void)
{
    display();

    printf("Global in main = %d\n", globalValue);

    return 0;
}
Output: 
Local = 20
Global = 100
Global in main = 100

globalValue is declared outside all functions and can be accessed by functions in the same translation unit after its declaration. localValue is declared inside display() and is accessible only within its block.

3. Local Variables

A local variable is declared inside a function or block. It has block scope and is normally associated with automatic storage duration when declared without the static storage-class specifier.

Example

#include <stdio.h>

void calculate(void)
{
    int number = 50;

    printf("Number = %d\n", number);
}

int main(void)
{
    calculate();

    return 0;
}
Output: 
Number = 50

Important Characteristics

  • Declared inside a block.
  • Accessible only within its scope.
  • Normally has automatic storage duration.
  • Its lifetime ends when execution leaves its block.
  • An uninitialized automatic variable has an indeterminate value.
Do not use an uninitialized local variable. Reading its indeterminate value can result in undefined behavior for common scalar types.

4. Block Scope and Nested Blocks

A block is a group of declarations and statements enclosed in braces.

Example

#include <stdio.h>

int main(void)
{
    int x = 10;

    {
        int y = 20;

        printf("x = %d\n", x);
        printf("y = %d\n", y);
    }

    printf("x = %d\n", x);

    return 0;
}
Output: 
x = 10
y = 20
x = 10

The variable y is accessible only inside the inner block. The variable x is accessible in both the outer and inner blocks.

5. Variable Shadowing

A variable declared in an inner block can have the same name as a variable in an outer block. The inner declaration hides the outer declaration within its scope.

Example

#include <stdio.h>

int main(void)
{
    int number = 10;

    {
        int number = 50;

        printf("Inner number = %d\n", number);
    }

    printf("Outer number = %d\n", number);

    return 0;
}
Output: 
Inner number = 50
Outer number = 10
The two declarations refer to different objects. The inner declaration shadows the outer declaration only within the inner block.

6. Global Variables

A global variable is commonly understood as an object declared outside all functions. In C terminology, such an object has file scope.

Example

#include <stdio.h>

int count = 100;

void display(void)
{
    printf("Count in display = %d\n", count);
}

int main(void)
{
    printf("Count in main = %d\n", count);

    display();

    return 0;
}
Output: 
Count in main = 100
Count in display = 100

Characteristics

  • Declared outside functions and blocks.
  • Has file scope.
  • Has static storage duration.
  • Has external linkage by default when declared at file scope without static.
  • If not explicitly initialized, it is zero-initialized.
  • Its lifetime lasts for the entire program execution.
Global variables can make programs harder to maintain because many functions may modify shared state. Prefer parameters and return values when they provide a clearer interface.

7. Static Local Variables

A static local variable is declared inside a function or block using the static keyword.

It has block scope, but static storage duration. Its value is retained between function calls.

Example

#include <stdio.h>

void counter(void)
{
    static int count = 0;

    count++;

    printf("Count = %d\n", count);
}

int main(void)
{
    counter();
    counter();
    counter();

    return 0;
}
Output: 
Count = 1
Count = 2
Count = 3

Explanation

  1. count is initialized to zero before program execution.
  2. The first call increments it to one.
  3. The second call continues from one.
  4. The third call continues from two.
  5. The value remains stored between calls.
A static local variable is initialized only once. Its initialization must use a constant expression in C11 for a static-storage-duration object.

8. Static Local vs Automatic Local Variable

#include <stdio.h>

void test(void)
{
    int normal = 0;
    static int persistent = 0;

    normal++;
    persistent++;

    printf("Normal = %d, Static = %d\n",
           normal, persistent);
}

int main(void)
{
    test();
    test();
    test();

    return 0;
}
Output: 
Normal = 1, Static = 1
Normal = 1, Static = 2
Normal = 1, Static = 3
Automatic Local Static Local
Block scope Block scope
Automatic storage duration Static storage duration
New lifetime on each block entry Exists throughout program execution
Not automatically initialized to zero Zero-initialized if no explicit initializer is provided
Does not retain its previous value after its lifetime ends Retains its stored value between calls

9. Static Global Variables

The static keyword can also be used with a file-scope variable. In this case, it gives the identifier internal linkage.

Example

#include <stdio.h>

static int deviceCount = 5;

void displayCount(void)
{
    printf("Device count = %d\n", deviceCount);
}

int main(void)
{
    displayCount();

    return 0;
}
Output: 
Device count = 5

Characteristics

  • Declared outside all functions.
  • Has file scope.
  • Has static storage duration.
  • Has internal linkage.
  • Can be accessed by functions in the same translation unit after its declaration.
  • Cannot be referred to by that identifier from another translation unit.
File-scope static is useful for hiding implementation details inside a C source file.

10. Scope, Lifetime and Storage Duration

These terms describe different properties of an object or identifier.

Concept Meaning
Scope Where an identifier can be accessed directly.
Lifetime The period during execution when an object exists.
Storage duration The storage-duration category that determines the object's lifetime.
Linkage Whether declarations of the same identifier can refer to the same entity across scopes or translation units.
Scope and lifetime are not the same thing. A static local variable has block scope but exists for the entire program execution.

11. Initialization of Variables

Variable Type Without Explicit Initializer
Uninitialized automatic local variable Indeterminate value
Static local variable Zero-initialized
Global variable Zero-initialized
Static global variable Zero-initialized

Example

#include <stdio.h>

int globalNumber;

void display(void)
{
    static int staticNumber;

    printf("Global = %d\n", globalNumber);
    printf("Static = %d\n", staticNumber);
}

int main(void)
{
    display();

    return 0;
}
Output: 
Global = 0
Static = 0

Both objects have static storage duration and are automatically zero-initialized.

12. Storage Duration Categories in C

C11 defines four storage-duration categories.

Storage Duration Typical Example Lifetime
Automatic Ordinary local variable Associated block execution
Static Global or static local variable Entire program execution
Allocated Object created by malloc() From allocation until deallocation
Thread _Thread_local object Associated thread execution
Allocated storage duration is covered in detail in the Dynamic Memory Allocation chapter. Thread storage duration is an advanced C11 concept.

13. Example: Function Call Counter

A static local variable is useful when a function needs to remember information between calls. 

#include <stdio.h>

void processRequest(void)
{
    static unsigned int requestCount = 0;

    requestCount++;

    printf("Request number = %u\n", requestCount);
}

int main(void)
{
    processRequest();
    processRequest();
    processRequest();
    processRequest();

    return 0;
}
Output: 
Request number = 1
Request number = 2
Request number = 3
Request number = 4

Embedded Systems Relevance

A persistent function-local counter can be useful for tracking function calls, event counts or diagnostic statistics in embedded software.

A static local variable is not automatically safe for concurrent access from multiple threads or interrupt contexts. Synchronization or other protection may be necessary when shared updates can occur concurrently.

15. Common Programming Mistakes

  1. Using an uninitialized local variable: initialize automatic local variables before reading them.
  2. Confusing scope with lifetime: a variable may have limited scope but long lifetime.
  3. Expecting a normal local variable to retain its value: its lifetime ends when its block execution ends.
  4. Using global variables unnecessarily: prefer explicit function interfaces where practical.
  5. Confusing static local and static global: their scope and linkage are different.
  6. Assuming static means constant: static variables can be modified unless declared const.

16. Placement-Oriented Coding Problems

Basic Problems

  1. Write a function with a local variable and observe its value on repeated calls.
  2. Write a function using a static local counter.
  3. Declare a global variable and access it from two functions.
  4. Demonstrate variable shadowing using nested blocks.
  5. Compare an automatic local variable with a static local variable.

Intermediate Problems

  1. Implement a function call counter using static storage duration.
  2. Write a program that maintains a persistent sequence number.
  3. Use a file-scope static variable to maintain private module state.
  4. Predict output from nested blocks containing same-named variables.
  5. Separate a program into two source files and compare external and internal linkage.

17. Technical Interview Questions

Q1. What is the scope of a local variable?

A local variable declared in a block normally has block scope and is accessible from its declaration to the end of that block, subject to nested declarations.

Q2. What is the lifetime of an automatic local variable?

Its lifetime is associated with execution of the block in which it is declared.

Q3. Why does a static local variable retain its value?

It has static storage duration, so its object exists throughout program execution.

Q4. What is the difference between a static local and a global variable?

A static local variable has block scope, while a file-scope global variable has file scope. Both have static storage duration.

Q5. What is the default value of a global integer?

It is zero-initialized.

Q6. What happens if a local integer is not initialized?

It has an indeterminate value. Reading it before assigning a valid value is unsafe and can cause undefined behavior.

Q7. Does static make a variable constant?

No. static specifies storage duration or linkage depending on declaration context. const specifies that the object cannot be modified through that identifier.

Q8. What is variable shadowing?

It occurs when an inner-scope declaration hides an outer-scope declaration with the same name.

Q9. What is internal linkage?

It means an identifier refers to the same entity only within the current translation unit.

Q10. What is the difference between scope and lifetime?

Scope controls where an identifier can be used. Lifetime controls when the object exists.
