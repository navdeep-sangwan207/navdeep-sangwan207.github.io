2. Function Fundamentals – Quick Revision

A function is a named block of code that performs a specific task.

Three Main Components

Component Purpose
Declaration / Prototype Informs the compiler about the function name, return type and parameters.
Definition Contains the actual implementation.
Function Call Transfers control to the function for execution.

Example

#include <stdio.h>

int add(int a, int b);

int main(void)
{
    int result = add(10, 20);

    printf("Sum = %d\n", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}
Output: 
Sum = 30

3. Function Arguments and Return Values

Arguments provide input to a function, while the return statement sends a result back to the caller.

Example: Different Function Forms

#include <stdio.h>

void display(void)
{
    printf("Hello\n");
}

void printNumber(int n)
{
    printf("Number = %d\n", n);
}

int getNumber(void)
{
    return 100;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    display();

    printNumber(25);

    printf("Returned number = %d\n", getNumber());

    printf("Product = %d\n", multiply(5, 4));

    return 0;
}
Output: 
Hello
Number = 25
Returned number = 100
Product = 20
In C, a function can return one value directly. Multiple results can be communicated through pointer parameters or a returned structure.

4. Call by Value and Address Passing

C passes function arguments by value. When a pointer is passed, the pointer value is copied, but the function can use that pointer to modify the original object.

Example: Call by Value

#include <stdio.h>

void changeValue(int x)
{
    x = 100;
}

int main(void)
{
    int number = 10;

    changeValue(number);

    printf("Number = %d\n", number);

    return 0;
}
Output: 
Number = 10

Example: Modify Through a Pointer

#include <stdio.h>

void changeValue(int *x)
{
    *x = 100;
}

int main(void)
{
    int number = 10;

    changeValue(&number);

    printf("Number = %d\n", number);

    return 0;
}
Output: 
Number = 100

Interview Comparison

Call by Value Address Through Pointer
Function receives a copy of the value. Function receives a copy of an address.
Changes to the parameter do not modify the caller's object. Dereferencing a valid pointer can modify the caller's object.
No pointer is required. Pointer parameter is required.

5. Swap Two Numbers Using a Function

This is a frequently asked C programming interview problem that tests pointers and function arguments. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    swap(&x, &y);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
Output: 
x = 20
y = 10

Time complexity: O(1)

Auxiliary space: O(1)

6. Local, Global and Static Variables

Variable scope determines where a variable can be accessed. Storage duration determines how long its object exists.

Example: Static Local Variable

#include <stdio.h>

void counter(void)
{
    static int count = 0;

    count++;

    printf("%d\n", count);
}

int main(void)
{
    counter();
    counter();
    counter();

    return 0;
}
Output: 
1
2
3

The static local variable retains its value between function calls. It has block scope and static storage duration.

A static local variable is initialized once. If no explicit initializer is provided, it is initialized to zero.

7. Recursion – Quick Revision

Recursion occurs when a function calls itself directly or indirectly to solve a smaller version of a problem.

Two Essential Components

  1. Base case: Stops further recursive calls.
  2. Recursive case: Reduces the problem toward the base case.

Example: Factorial

#include <stdio.h>

unsigned int factorial(unsigned int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

int main(void)
{
    printf("Factorial = %u\n", factorial(5));

    return 0;
}
Output: 
Factorial = 120

Call Flow

factorial(5)
    factorial(4)
        factorial(3)
            factorial(2)
                factorial(1)
                    factorial(0)
                    return 1
                return 1
            return 2
        return 6
    return 24
return 120

8. Recursion vs Iteration

Recursion Iteration
Uses repeated function calls. Uses loops such as for and while.
Uses call-stack space for active calls. Often uses constant auxiliary space.
Can express divide-and-conquer algorithms naturally. Often preferred for straightforward repeated operations.
May cause stack exhaustion for deep recursion. Does not create one function call per iteration.
Can be harder to trace for beginners. Often easier to debug for simple loops.
Recursion is not automatically faster or more memory efficient than iteration. Choose the approach that makes the algorithm clear while meeting performance and resource requirements.

9. Placement Coding Problem: Prime Number Using a Function

#include <stdio.h>

int isPrime(int n)
{
    int i;

    if (n < 2)
        return 0;

    for (i = 2; i <= n / i; i++)
    {
        if (n % i == 0)
            return 0;
    }

    return 1;
}

int main(void)
{
    int number = 29;

    if (isPrime(number))
        printf("Prime number\n");
    else
        printf("Not a prime number\n");

    return 0;
}
Output: 
Prime number

Time complexity: O(√n)

Auxiliary space: O(1)

10. Placement Coding Problem: GCD Using Recursion

#include <stdio.h>

unsigned int gcd(unsigned int a, unsigned int b)
{
    if (b == 0)
        return a;

    return gcd(b, a % b);
}

int main(void)
{
    unsigned int a = 48;
    unsigned int b = 18;

    printf("GCD = %u\n", gcd(a, b));

    return 0;
}
Output: 
GCD = 6

Time complexity: O(log(min(a, b))) for positive inputs.

Auxiliary call-stack space: O(log(min(a, b))).

11. Placement Coding Problem: Reverse an Array Recursively

#include <stdio.h>

void reverseArray(int arr[], int left, int right)
{
    int temp;

    if (left >= right)
        return;

    temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;

    reverseArray(arr, left + 1, right - 1);
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = (int)(sizeof(arr) / sizeof(arr[0]));
    int i;

    reverseArray(arr, 0, size - 1);

    for (i = 0; i < size; i++)
        printf("%d ", arr[i]);

    printf("\n");

    return 0;
}
Output: 
50 40 30 20 10

Time complexity: O(n)

Auxiliary call-stack space: O(n)

13. Debugging and Error Identification

Problem 1: Missing Base Case

int sum(int n)
{
    return n + sum(n - 1);
}

Problem: There is no termination condition.

Correction:

int sum(int n)
{
    if (n == 0)
        return 0;

    return n + sum(n - 1);
}

Problem 2: Incorrect Recursive Progress

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n);
}

Problem: The argument never moves toward the base case.

Correction:

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

Problem 3: Incorrect Pointer Usage

void update(int *p)
{
    p = 100;
}

Problem: The code attempts to assign an integer to a pointer. It does not modify the pointed-to integer.

Correction:

void update(int *p)
{
    if (p != NULL)
        *p = 100;
}

Problem 4: Reading an Uninitialized Local Variable

int calculate(void)
{
    int total;

    total++;

    return total;
}

Problem: total has an indeterminate value. Reading it before initialization causes undefined behavior.

Correction:

int calculate(void)
{
    int total = 0;

    total++;

    return total;
}

14. Function and Recursion Interview Questions

Q1. What is a function prototype?

A declaration that specifies a function's name, return type and parameter types.

Q2. Does C support call by reference?

No. C uses pass-by-value. Passing a pointer allows a function to modify an object through its address.

Q3. What happens when a function returns void?

It does not return a value to its caller.

Q4. What is recursion?

A technique in which a function calls itself to solve smaller instances of a problem.

Q5. What is a base case?

A condition that stops further recursive calls.

Q6. What happens if a recursive function has no valid base case?

It may continue calling itself until execution fails, commonly because of stack exhaustion.

Q7. What is direct recursion?

A function directly calls itself.

Q8. What is indirect recursion?

One function calls another function that eventually calls the first function again.

Q9. What is tail recursion?

A recursive call is the final operation performed by the function.

Q10. Does standard C guarantee tail-call optimization?

No. A compiler may optimize certain tail calls, but the C standard does not require it.

Q11. What is a static local variable?

A block-scope variable with static storage duration that retains its value between function calls.

Q12. What is the difference between scope and lifetime?

Scope determines where an identifier can be accessed. Lifetime describes the period during which its object exists.

Q13. What is the time complexity of recursive binary search?

O(log n).

Q14. What is memoization?

Storing previously computed results to avoid repeated calculations.

Q15. When should recursion be avoided?

When recursion depth may become excessive, stack resources are limited, or an iterative solution is simpler and more efficient.
