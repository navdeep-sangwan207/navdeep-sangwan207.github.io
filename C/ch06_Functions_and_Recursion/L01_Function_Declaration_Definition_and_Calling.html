2. What Is a Function in C?

A function is a named, reusable block of code that performs a particular task. A C program can contain multiple functions, each responsible for a specific operation.

For example, a program may contain separate functions for:

  • Reading input from the user.
  • Calculating the sum of two numbers.
  • Finding the largest number.
  • Displaying a result.

Example Without a Separate User-Defined Function

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;
    int sum;

    sum = a + b;

    printf("Sum = %d\n", sum);

    return 0;
}

The calculation is performed directly inside main(). As a program grows, placing all operations in one function can make it difficult to maintain and test.

Example Using a User-Defined Function

#include <stdio.h>

int calculateSum(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result;

    result = calculateSum(10, 20);

    printf("Sum = %d\n", result);

    return 0;
}
Output: 
Sum = 30

The calculation is separated into calculateSum(). The main() function calls it and uses its returned value.

3. Advantages of Functions

Advantage Explanation
Code Reusability A function can be called multiple times.
Modularity A large program can be divided into smaller units.
Readability Meaningful function names make code easier to understand.

Maintenance Changes can often be made in one function without rewriting the entire program.

4. Three Main Parts of Function Usage

In a typical C program, a user-defined function is used through three main steps:

  1. Function declaration (prototype).
  2. Function definition.
  3. Function call.

General Structure

// Function declaration
return_type function_name(parameter_types);

// Function definition
return_type function_name(parameters)
{
    // Function body
}

// Function call
function_name(arguments);
A declaration informs the compiler about the function's name, return type and parameter types. The definition supplies the function body. A call requests the function to execute.

5. Function Declaration or Prototype

A function declaration tells the compiler that a function exists and specifies its interface.

Syntax

return_type function_name(parameter_types);

Example

int add(int, int);

This declaration specifies:

  • Function name: add
  • Return type: int
  • Number of parameters: 2
  • Parameter types: int and int

Parameter names may also be included in the prototype. 

int add(int first, int second);

The parameter names in the declaration are optional. The types and their order form part of the function interface.

Why Is a Function Prototype Required?

A prototype allows the compiler to check calls to a function before it encounters the function's definition. 

#include <stdio.h>

int add(int, int);  // Function prototype

int main(void)
{
    int result = add(10, 20);

    printf("Result = %d\n", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}
Output: 
Result = 30
Without a visible declaration, calling a function before its definition is not valid in modern standard C. C11 does not support implicit function declarations.

6. Function Definition

A function definition contains the actual implementation of the function. It specifies what the function does.

Syntax

return_type function_name(parameter_list)
{
    // Statements
    return value;
}

Example

int multiply(int a, int b)
{
    int result;

    result = a * b;

    return result;
}

Explanation:

  • int is the return type.
  • multiply is the function name.
  • a and b are parameters.
  • The function body performs multiplication.
  • return sends the result to the calling expression.

Complete Program

#include <stdio.h>

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int answer = multiply(6, 7);

    printf("Product = %d\n", answer);

    return 0;
}
Output: 
Product = 42

7. Function Calling

A function call transfers program control to the specified function. After the function finishes, execution resumes at the point following the call, subject to the function's return behavior.

Syntax

function_name(arguments);

Example

#include <stdio.h>

void displayMessage(void)
{
    printf("Welcome to C Programming!\n");
}

int main(void)
{
    displayMessage();

    printf("Back inside main().\n");

    return 0;
}
Output: 
Welcome to C Programming!
Back inside main().

The program enters displayMessage(), executes its statements and returns to main().

8. Understanding the Program Execution Flow

Consider this program:

#include <stdio.h>

void first(void);
void second(void);

int main(void)
{
    printf("Start\n");

    first();

    printf("End\n");

    return 0;
}

void first(void)
{
    printf("Inside first\n");

    second();
}

void second(void)
{
    printf("Inside second\n");
}
Output: 
Start
Inside first
Inside second
End

Execution Sequence

  1. Program execution begins in main().
  2. main() prints Start.
  3. main() calls first().
  4. first() prints Inside first.
  5. first() calls second().
  6. second() prints Inside second.
  7. second() returns to first().
  8. first() returns to main().
  9. main() prints End.

9. Function Return Types

The return type specifies the type of value a function provides to its caller.

Return Type Purpose
int Returns an integer value.
float Returns a floating-point value.
double Returns a double-precision floating-point value.
char Returns a character value.
void Does not return a value.

Example: Integer Return Type

int square(int number)
{
    return number * number;
}

Example: Double Return Type

double calculateArea(double radius)
{
    const double PI = 3.141592653589793;
    return PI * radius * radius;
}

Example: Void Return Type

void printLine(void)
{
    printf("--------------------\n");
}
A void function performs an operation without returning a value. It can use return; to exit early, but it cannot return an expression value.

10. Functions With and Without Parameters

A function may receive information through parameters, or it may operate without parameters.

Function Without Parameters

#include <stdio.h>

void display(void)
{
    printf("C Programming\n");
}

int main(void)
{
    display();

    return 0;
}

Function With Parameters

#include <stdio.h>

void displayNumber(int number)
{
    printf("Number = %d\n", number);
}

int main(void)
{
    displayNumber(100);

    return 0;
}
In C, use void inside the parameter list to explicitly indicate that a function accepts no parameters: void display(void). An empty parameter list in a declaration, such as void display();, does not provide a prototype specifying that there are no parameters.

11. Library Functions and User-Defined Functions

C programs use both standard library functions and functions written by the programmer.

Library Function Purpose Header File
printf() Formatted output stdio.h
scanf() Formatted input stdio.h
strlen() String length string.h
sqrt() Square root math.h

User-Defined Function Example

#include <stdio.h>

int findMaximum(int a, int b)
{
    if (a > b)
    {
        return a;
    }

    return b;
}

int main(void)
{
    int maximum = findMaximum(25, 40);

    printf("Maximum = %d\n", maximum);

    return 0;
}
Output: 
Maximum = 40

12. Complete Example: Modular Calculator

This program demonstrates how multiple user-defined functions can organize a single application. 

#include <stdio.h>

int add(int a, int b);
int subtract(int a, int b);
int multiply(int a, int b);

int main(void)
{
    int first = 20;
    int second = 5;

    printf("Addition = %d\n", add(first, second));
    printf("Subtraction = %d\n", subtract(first, second));
    printf("Multiplication = %d\n", multiply(first, second));

    return 0;
}

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}
Output: 
Addition = 25
Subtraction = 15
Multiplication = 100

Why This Design Is Useful

  • Each operation has a separate function.
  • The main() function controls the overall program.
  • Each operation can be tested independently.
  • Additional operations can be added without placing all logic in main().

13. Common Function Errors

Error Problem Correct Approach
Missing prototype Function is called before a declaration is visible. Provide a compatible declaration before the call.
Wrong return type Returned expression does not match the intended type. Use a suitable return type and value.
Wrong arguments Call does not match the function interface. Pass compatible arguments in the correct order.
Missing return A non-void function reaches its end without returning a value that its caller uses. Ensure every required execution path returns a value.
Incorrect function name Function is called using a different identifier. Use consistent function names.
Missing header A standard library function is used without its declaration. Include the appropriate standard header.
Reaching the closing brace of a non-void function without returning a value is undefined behavior if the caller uses the function's returned value. Design all normal execution paths to return appropriately.

16. Technical Interview Questions

Q1. What is a function in C?

A function is a named block of code that performs a particular task and can be called from other parts of a program.

Q2. What is a function prototype?

It is a declaration that specifies a function's name, return type and parameter types.

Q3. What is the difference between declaration and definition?

A declaration introduces the function interface. A definition provides the actual implementation.

Q4. Can a function call another function?

Yes. A function can call another function whose declaration is visible and whose call is otherwise valid.

Q5. Can a C function return multiple values directly?

A C function has one return value. Multiple results can be communicated through output parameters, pointers or a structure returned by the function.

Q6. What is the purpose of void?

void indicates that a function does not return a value. In a parameter list, void explicitly indicates no parameters.

Q7. Is main() a user-defined function?

main() is the program's designated entry-point function in a hosted C implementation. The programmer defines it.

Q8. Can a function be defined inside another function in standard C?

No. Standard C does not support nested function definitions. Functions are defined at file scope.
