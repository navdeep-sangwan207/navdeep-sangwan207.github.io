Lecture 02: Array of Structures and Nested Structures

Learn to manage multiple records using arrays of structures and represent complex hierarchical information using nested structures.

1. Learning Objectives

  • Understand why arrays of structures are needed.
  • Declare and initialize arrays of structures.
  • Access and modify individual records.
  • Traverse structure arrays using loops.
  • Search records using a key such as ID.
  • Sort records based on structure members.
  • Understand nested structure declarations.
  • Access members of nested structures.
  • Solve placement-oriented record-management problems.

2. Why Do We Need an Array of Structures?

In the previous lecture, we created a structure for storing one student's details. 

struct Student
{
    int roll;
    char name[30];
    float marks;
};

struct Student s1;

What if an application needs to store details of 100 students?

Declaring 100 separate structure variables would be inconvenient. An array of structures provides a better solution.

An array of structures stores multiple structure objects of the same structure type in an indexed sequence.

3. Declaring an Array of Structures

General syntax:

struct StructureName
{
    data_type member1;
    data_type member2;
};

struct StructureName array_name[size];

Example:

struct Student
{
    int roll;
    char name[30];
    float marks;
};

struct Student students[5];

The array students contains five independent structure objects.

Expression Meaning
students[0] First student record
students[1] Second student record
students[2] Third student record
students[4] Fifth student record

4. Accessing Members of an Array of Structures

First select an array element, then access its member using the dot operator. 

students[0].roll = 101;
students[0].marks = 85.5f;

The expression students[0].roll means the roll member of the first structure object.

Complete Program

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student students[3] = {
        {101, "Amit", 85.5f},
        {102, "Ravi", 90.0f},
        {103, "Neha", 88.5f}
    };

    for (int i = 0; i < 3; i++)
    {
        printf("Roll: %d\n", students[i].roll);
        printf("Name: %s\n", students[i].name);
        printf("Marks: %.2f\n\n", students[i].marks);
    }

    return 0;
}
Expected Output: 
Roll: 101
Name: Amit
Marks: 85.50

Roll: 102
Name: Ravi
Marks: 90.00

Roll: 103
Name: Neha
Marks: 88.50

5. Taking Input into an Array of Structures

A loop can be used to accept details for multiple records. 

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    struct Employee emp[3];

    for (int i = 0; i < 3; i++)
    {
        printf("Enter ID, name and salary for employee %d:\n",
               i + 1);

        if (scanf("%d %29s %f",
                  &emp[i].id,
                  emp[i].name,
                  &emp[i].salary) != 3)
        {
            printf("Invalid input\n");
            return 1;
        }
    }

    printf("\n--- Employee Records ---\n");

    for (int i = 0; i < 3; i++)
    {
        printf("%d %s %.2f\n",
               emp[i].id,
               emp[i].name,
               emp[i].salary);
    }

    return 0;
}

Sample Input

101 Amit 25000
102 Ravi 30000
103 Neha 35000
Expected Output: 
--- Employee Records ---
101 Amit 25000.00
102 Ravi 30000.00
103 Neha 35000.00

The format %29s prevents writing more than 29 characters into the 30-character name array, leaving room for the null terminator.

6. Searching Records in an Array of Structures

Searching is a common operation in record-management applications.

Suppose we want to find an employee using an employee ID.

Linear Search Program

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    struct Employee emp[4] = {
        {101, "Amit", 25000.0f},
        {102, "Ravi", 30000.0f},
        {103, "Neha", 35000.0f},
        {104, "Karan", 40000.0f}
    };

    int key;
    int found = 0;

    printf("Enter employee ID to search: ");

    if (scanf("%d", &key) != 1)
    {
        printf("Invalid input\n");
        return 1;
    }

    for (int i = 0; i < 4; i++)
    {
        if (emp[i].id == key)
        {
            printf("Employee found\n");
            printf("ID: %d\n", emp[i].id);
            printf("Name: %s\n", emp[i].name);
            printf("Salary: %.2f\n", emp[i].salary);

            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("Employee not found\n");
    }

    return 0;
}
Sample Input: 
103
Expected Output: 
Employee found
ID: 103
Name: Neha
Salary: 35000.00

Time Complexity: O(n) in the worst case, where n is the number of records.

7. Sorting an Array of Structures

Structure records can be sorted based on a particular member, such as ID or salary.

Sort Employees by Salary

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

int main(void)
{
    struct Employee emp[4] = {
        {101, "Amit", 35000.0f},
        {102, "Ravi", 25000.0f},
        {103, "Neha", 40000.0f},
        {104, "Karan", 30000.0f}
    };

    struct Employee temp;

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3 - i; j++)
        {
            if (emp[j].salary > emp[j + 1].salary)
            {
                temp = emp[j];
                emp[j] = emp[j + 1];
                emp[j + 1] = temp;
            }
        }
    }

    printf("Employees sorted by salary:\n");

    for (int i = 0; i < 4; i++)
    {
        printf("%d %s %.2f\n",
               emp[i].id,
               emp[i].name,
               emp[i].salary);
    }

    return 0;
}
Expected Output: 
Employees sorted by salary:
102 Ravi 25000.00
104 Karan 30000.00
101 Amit 35000.00
103 Neha 40000.00

The complete structure objects are exchanged during sorting, so the employee ID, name and salary remain associated with each other.

Time Complexity: O(n²) for this bubble-sort implementation.

8. What Are Nested Structures?

A structure can contain another structure as one of its members. This is known as a nested structure.

Nested structures are useful when a record contains smaller groups of related information.

Example: Student and Address

struct Address
{
    char city[30];
    int pin;
};

struct Student
{
    int roll;
    char name[30];
    struct Address address;
};

Here, the Student structure contains an Address structure as one of its members.

9. Accessing Members of Nested Structures

Use multiple dot operators to access members inside nested structures. 

student.address.pin = 124001;

The expression means:

  • Access the address member of student.
  • Access the pin member of address.

Complete Program

#include <stdio.h>

struct Address
{
    char city[30];
    int pin;
};

struct Student
{
    int roll;
    char name[30];
    struct Address address;
};

int main(void)
{
    struct Student s1 = {
        101,
        "Amit",
        {"Rohtak", 124001}
    };

    printf("Roll: %d\n", s1.roll);
    printf("Name: %s\n", s1.name);
    printf("City: %s\n", s1.address.city);
    printf("PIN: %d\n", s1.address.pin);

    return 0;
}
Expected Output: 
Roll: 101
Name: Amit
City: Rohtak
PIN: 124001

10. Nested Structures with Multiple Members

A structure can contain multiple other structure objects. 

#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Employee
{
    int id;
    char name[30];
    struct Date joining_date;
    struct Date birth_date;
};

int main(void)
{
    struct Employee e1 = {
        101,
        "Ravi",
        {10, 6, 2024},
        {15, 8, 2000}
    };

    printf("Employee: %s\n", e1.name);

    printf("Joining Date: %02d-%02d-%04d\n",
           e1.joining_date.day,
           e1.joining_date.month,
           e1.joining_date.year);

    printf("Birth Date: %02d-%02d-%04d\n",
           e1.birth_date.day,
           e1.birth_date.month,
           e1.birth_date.year);

    return 0;
}
Expected Output: 
Employee: Ravi
Joining Date: 10-06-2024
Birth Date: 15-08-2000

11. Array of Nested Structures

An array of structures can contain nested structures in every element. 

#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Employee
{
    int id;
    char name[30];
    struct Date joining_date;
};

int main(void)
{
    struct Employee emp[2] = {
        {101, "Amit", {1, 1, 2023}},
        {102, "Neha", {15, 6, 2024}}
    };

    for (int i = 0; i < 2; i++)
    {
        printf("ID: %d\n", emp[i].id);
        printf("Name: %s\n", emp[i].name);

        printf("Joining Date: %02d-%02d-%04d\n\n",
               emp[i].joining_date.day,
               emp[i].joining_date.month,
               emp[i].joining_date.year);
    }

    return 0;
}
Expected Output: 
ID: 101
Name: Amit
Joining Date: 01-01-2023

ID: 102
Name: Neha
Joining Date: 15-06-2024

12. Practical Application: Product Inventory

This example combines arrays of structures, searching and record calculations. 

#include <stdio.h>

struct Product
{
    int id;
    char name[30];
    int quantity;
    float price;
};

int main(void)
{
    struct Product products[3] = {
        {1, "Keyboard", 10, 750.0f},
        {2, "Mouse", 20, 350.0f},
        {3, "Monitor", 5, 6500.0f}
    };

    float total_value = 0.0f;

    printf("--- Product Inventory ---\n");

    for (int i = 0; i < 3; i++)
    {
        float value =
            products[i].quantity * products[i].price;

        printf("ID: %d\n", products[i].id);
        printf("Name: %s\n", products[i].name);
        printf("Quantity: %d\n", products[i].quantity);
        printf("Price: %.2f\n", products[i].price);
        printf("Stock Value: %.2f\n\n", value);

        total_value += value;
    }

    printf("Total Inventory Value: %.2f\n",
           total_value);

    return 0;
}
Expected Output: 
--- Product Inventory ---
ID: 1
Name: Keyboard
Quantity: 10
Price: 750.00
Stock Value: 7500.00

ID: 2
Name: Mouse
Quantity: 20
Price: 350.00
Stock Value: 7000.00

ID: 3
Name: Monitor
Quantity: 5
Price: 6500.00
Stock Value: 32500.00

Total Inventory Value: 47000.00

13. Common Errors and Important Considerations

Error 1: Incorrect Member Access

students.roll = 101;

If students is an array, the expression is incorrect because a particular element must be selected first.

Correct:

students[0].roll = 101;

Error 2: Incorrect Array Index

struct Student students[5];

students[5].roll = 101;

Valid indices are 0 through 4. Accessing students[5] is outside the array bounds.

Error 3: Incorrect Nested Member Access

student.pin = 124001;

If pin belongs to the nested address structure, use: 

student.address.pin = 124001;

Error 4: Incorrect Structure Array Assignment

students1 = students2;

Arrays cannot be assigned directly as whole objects in C. Copy individual structure elements using a loop or another suitable method.

Always validate array indices and input sizes. Accessing outside an array's bounds can cause undefined behavior.

14. Time Complexity of Common Operations

Operation Typical Complexity
Access a record by index O(1)
Traverse all records O(n)
Linear search by ID O(n)
Bubble sort by a member O(n²)
Calculate total of all records O(n)

These complexities describe the example algorithms, not an inherent complexity of the structure data type.

15. Technical Interview Questions

Q1. What is an array of structures?

It is an array whose elements are objects of the same structure type.

Q2. How do you access a member of the third structure object?

Use array_name[2].member_name.

Q3. Can an array of structures be initialized at declaration?

Yes. Each array element can be initialized with a corresponding structure initializer.

Q4. What is a nested structure?

A structure containing another structure as one or more of its members.

Q5. How do you access a nested structure member?

Use chained dot operators, such as employee.address.pin.

Q6. Can an array of structures contain nested structures?

Yes. Every element can contain its own nested structure members.

Q7. How can records be sorted using structures?

Compare a selected member and swap complete structure objects.

Q8. What is the benefit of nested structures?

They represent logically grouped and hierarchical information.

Q9. What is the difference between an array of structures and a structure containing an array?

An array of structures stores multiple records. A structure containing an array stores an array as one member of a single record.

Q10. Give an embedded C example of nested structures.

A device configuration structure can contain separate UART, GPIO and timer configuration structures.

17. Quick Revision

  • An array of structures stores multiple records of the same type.
  • Use array_name[index].member to access a record member.
  • Loops are commonly used to input and display structure arrays.
  • Linear search can locate a record by its ID.
  • Sorting should exchange complete structure objects.
  • A nested structure contains another structure as a member.
  • Use chained dot operators to access nested members.
  • Always validate array indices and input lengths.
