Lecture 06: Enums and typedef

Learn how to define named integer constants using enumerations and create convenient type aliases using typedef. Apply these concepts to state machines, embedded firmware and structured C programs.

1. Learning Objectives

  • Understand enumeration types in C.
  • Declare enum types and enum variables.
  • Understand implicit and explicit enum values.
  • Learn how enum values are assigned.
  • Use enums in switch statements and conditional logic.
  • Understand enum scope and identifier conflicts.
  • Learn the purpose and syntax of typedef.
  • Create aliases for basic data types.
  • Use typedef with structures, unions and enums.
  • Understand common typedef and enum interview questions.

2. What Is an Enumeration in C?

An enumeration, declared using the enum keyword, is a user-defined type consisting of named integer constants.

It makes programs easier to read by replacing unexplained numeric values with meaningful names.

Without Enum

#include <stdio.h>

int main(void)
{
    int status = 1;

    if (status == 1)
    {
        printf("System is running\n");
    }

    return 0;
}

The value 1 does not clearly explain what state it represents.

With Enum

#include <stdio.h>

enum SystemStatus
{
    STOPPED,
    RUNNING,
    ERROR
};

int main(void)
{
    enum SystemStatus status = RUNNING;

    if (status == RUNNING)
    {
        printf("System is running\n");
    }

    return 0;
}
Output: 
System is running
Enums improve code readability and make groups of related constant values easier to manage.

3. Enum Declaration Syntax

enum EnumName
{
    CONSTANT1,
    CONSTANT2,
    CONSTANT3
};

An enum declaration defines an enumeration type and its named constants.

Example

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
};

Variables can then be declared using the enum type: 

enum Day today;

today = WEDNESDAY;

4. Default Values of Enum Constants

If no values are explicitly assigned, the first enumerator has value 0. Each following enumerator is one greater than the previous enumerator. 

#include <stdio.h>

enum Color
{
    RED,
    GREEN,
    BLUE,
    YELLOW
};

int main(void)
{
    printf("RED = %d\n", RED);
    printf("GREEN = %d\n", GREEN);
    printf("BLUE = %d\n", BLUE);
    printf("YELLOW = %d\n", YELLOW);

    return 0;
}
Output: 
RED = 0
GREEN = 1
BLUE = 2
YELLOW = 3

The compiler assigns these values according to the enumeration declaration.

5. Assigning Explicit Values to Enum Constants

You can assign specific integer values to enumerators. 

#include <stdio.h>

enum ErrorCode
{
    SUCCESS = 0,
    INVALID_INPUT = 10,
    MEMORY_ERROR = 20,
    FILE_ERROR = 30
};

int main(void)
{
    printf("SUCCESS = %d\n", SUCCESS);
    printf("INVALID_INPUT = %d\n", INVALID_INPUT);
    printf("MEMORY_ERROR = %d\n", MEMORY_ERROR);
    printf("FILE_ERROR = %d\n", FILE_ERROR);

    return 0;
}
Output: 
SUCCESS = 0
INVALID_INPUT = 10
MEMORY_ERROR = 20
FILE_ERROR = 30

Explicit values are useful when working with defined error codes, hardware states or protocol constants.

6. Mixing Explicit and Implicit Enum Values

When an enumerator is assigned a value, the next enumerator without an explicit value receives one greater than the immediately preceding enumerator. 

#include <stdio.h>

enum Number
{
    A = 5,
    B,
    C,
    D = 20,
    E,
    F
};

int main(void)
{
    printf("A = %d\n", A);
    printf("B = %d\n", B);
    printf("C = %d\n", C);
    printf("D = %d\n", D);
    printf("E = %d\n", E);
    printf("F = %d\n", F);

    return 0;
}
Output: 
A = 5
B = 6
C = 7
D = 20
E = 21
F = 22

This is a common output-prediction question in C interviews.

7. Enum Variables and Assignment

Variables can be declared using an enumeration type. 

#include <stdio.h>

enum TrafficLight
{
    RED,
    YELLOW,
    GREEN
};

int main(void)
{
    enum TrafficLight signal;

    signal = RED;

    printf("Signal value: %d\n", signal);

    signal = GREEN;

    printf("Signal value: %d\n", signal);

    return 0;
}
Output: 
Signal value: 0
Signal value: 2

In C, enumerated types are integer types. The implementation determines the compatible integer type used to represent an enum, subject to the C standard's requirements.

C does not provide the same strict enum type checking as some other programming languages. Do not assume an enum variable can contain only one of its named constants.

8. Using Enum with switch Statements

Enums work particularly well with switch statements because their named constants make each case easier to understand. 

#include <stdio.h>

enum Operation
{
    ADD = 1,
    SUBTRACT,
    MULTIPLY,
    DIVIDE
};

int main(void)
{
    enum Operation op = MULTIPLY;

    int a = 10;
    int b = 5;

    switch (op)
    {
        case ADD:
            printf("Result = %d\n", a + b);
            break;

        case SUBTRACT:
            printf("Result = %d\n", a - b);
            break;

        case MULTIPLY:
            printf("Result = %d\n", a * b);
            break;

        case DIVIDE:
            if (b != 0)
            {
                printf("Result = %d\n", a / b);
            }
            break;

        default:
            printf("Invalid operation\n");
    }

    return 0;
}
Output: 
Result = 50

9. Enum Scope and Identifier Rules

Enumeration constants are identifiers with scope and namespace rules defined by C. 

enum State
{
    IDLE,
    ACTIVE,
    FAILED
};

int main(void)
{
    enum State current = ACTIVE;

    return 0;
}

The enumerator names IDLE, ACTIVE and FAILED are declared in the ordinary identifier namespace.

You cannot reuse an enumerator name as another ordinary identifier in the same scope. Plan enum constant names carefully to avoid naming conflicts.

Enumeration constants have the scope associated with their declaration. A block-scope enum declaration can limit the visibility of its enumerators to that block.

10. What Is typedef in C?

The typedef keyword creates an alias for an existing type.

It does not create a completely new independent data type. It provides another name for an existing type.

Syntax

typedef existing_type new_name;

Example Without typedef

unsigned int count;

int main(void)
{
    count = 100;
    return 0;
}

Example With typedef

typedef unsigned int UINT;

int main(void)
{
    UINT count = 100;

    return 0;
}

UINT is an alias for unsigned int.

typedef can make complex declarations shorter and improve readability when used consistently.

11. typedef with Basic Data Types

#include <stdio.h>

typedef unsigned int UINT;
typedef float REAL;
typedef char CHARACTER;

int main(void)
{
    UINT count = 100;
    REAL temperature = 28.5f;
    CHARACTER grade = 'A';

    printf("Count: %u\n", count);
    printf("Temperature: %.2f\n", temperature);
    printf("Grade: %c\n", grade);

    return 0;
}
Output: 
Count: 100
Temperature: 28.50
Grade: A

The aliases represent their original types and can be used in declarations and function interfaces.

12. typedef with Structures

A typedef alias can simplify structure variable declarations.

Without typedef

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s1;

    return 0;
}

With typedef

#include <stdio.h>

typedef struct Student
{
    int roll;
    float marks;
} Student;

int main(void)
{
    Student s1;

    s1.roll = 101;
    s1.marks = 87.5f;

    printf("Roll: %d\n", s1.roll);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}
Output: 
Roll: 101
Marks: 87.50

Student can now be used without writing the struct keyword before the type name.

13. typedef with Unions

typedef can also simplify union declarations. 

#include <stdio.h>

typedef union Data
{
    int number;
    float decimal;
    char character;
} Data;

int main(void)
{
    Data value;

    value.number = 250;

    printf("Number: %d\n", value.number);

    return 0;
}
Output: 
Number: 250

14. typedef with Enums

An enum type can also be given a shorter alias using typedef. 

#include <stdio.h>

typedef enum
{
    OFF,
    ON
} SwitchState;

int main(void)
{
    SwitchState state = ON;

    if (state == ON)
    {
        printf("Switch is ON\n");
    }

    return 0;
}
Output: 
Switch is ON

The type name SwitchState can be used directly when declaring variables.

15. typedef with Pointers

typedef is useful when working with pointer types. 

#include <stdio.h>

typedef int *IntPointer;

int main(void)
{
    int number = 100;

    IntPointer ptr = &number;

    printf("Value: %d\n", *ptr);

    return 0;
}
Output: 
Value: 100

Important Pointer Declaration Difference

typedef int *IntPointer;

IntPointer p1, p2;

Both p1 and p2 are pointers to int.

Compare with:

int *p1, p2;

Here p1 is a pointer to int, but p2 is an ordinary int.

A typedef alias represents the complete declared type. This is particularly important when the alias is a pointer.

16. typedef with Function Pointers

Function pointer declarations can become difficult to read. typedef provides a convenient alias.

Without typedef

int (*operation)(int, int);

With typedef

#include <stdio.h>

typedef int (*Operation)(int, int);

int add(int a, int b)
{
    return a + b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    Operation operation;

    operation = add;
    printf("Addition: %d\n", operation(10, 5));

    operation = multiply;
    printf("Multiplication: %d\n", operation(10, 5));

    return 0;
}
Output: 
Addition: 15
Multiplication: 50

This technique is useful for callbacks, driver interfaces and modular software.

17. Practical Embedded C Example: System States

Embedded applications frequently use enums to represent operating states. 

#include <stdio.h>

typedef enum
{
    SYSTEM_INIT,
    SYSTEM_IDLE,
    SYSTEM_RUNNING,
    SYSTEM_ERROR
} SystemState;

void process_state(SystemState state)
{
    switch (state)
    {
        case SYSTEM_INIT:
            printf("Initializing system\n");
            break;

        case SYSTEM_IDLE:
            printf("System is idle\n");
            break;

        case SYSTEM_RUNNING:
            printf("System is running\n");
            break;

        case SYSTEM_ERROR:
            printf("System error detected\n");
            break;

        default:
            printf("Unknown state\n");
            break;
    }
}

int main(void)
{
    SystemState current_state = SYSTEM_RUNNING;

    process_state(current_state);

    return 0;
}
Output: 
System is running

This approach is commonly used in firmware state machines, device drivers and control applications.

18. Practical Embedded C Example: Error Codes

#include <stdio.h>

typedef enum
{
    ERROR_NONE = 0,
    ERROR_SENSOR = 1,
    ERROR_UART = 2,
    ERROR_TIMEOUT = 3
} ErrorCode;

void report_error(ErrorCode error)
{
    switch (error)
    {
        case ERROR_NONE:
            printf("No error\n");
            break;

        case ERROR_SENSOR:
            printf("Sensor error\n");
            break;

        case ERROR_UART:
            printf("UART communication error\n");
            break;

        case ERROR_TIMEOUT:
            printf("Timeout error\n");
            break;

        default:
            printf("Unknown error code\n");
            break;
    }
}

int main(void)
{
    ErrorCode error = ERROR_UART;

    report_error(error);

    return 0;
}
Output: 
UART communication error

Named error codes make firmware diagnostics easier to understand and maintain.

19. Enum vs #define

Feature Enum #define
Purpose Defines named integer constants grouped in an enumeration. Defines a preprocessor macro.
Processing Handled as part of C language translation. Processed by the preprocessor.
Grouping Related constants are grouped together. No inherent grouping.
Scope Enumerator names follow C identifier scope rules. Macro remains active from definition until undefined or end of preprocessing unit.
Type behavior Enumerators have integer constant semantics. Textual substitution; no inherent type.
Typical use States, modes and related integer constants. Macros, conditional compilation and symbolic substitutions.
Prefer enums when representing a related set of named integer constants. Use preprocessor macros when preprocessing functionality is actually required.

20. Common Mistakes and Pitfalls

Mistake Explanation
Assuming the first enum value is always 1 The default first value is 0.
Ignoring implicit values Each implicit value follows the preceding enumerator.
Reusing enumerator names Enumerator names occupy the ordinary identifier namespace.
Assuming enum size is always int size The compatible integer type is implementation-dependent.
Thinking typedef creates a new independent type typedef creates an alias for an existing type.
Confusing pointer typedef declarations Pointer aliases represent pointer types, not the pointed-to type.
Using unclear typedef names Unnecessary aliases can make code harder to understand.

21. Placement-Oriented Interview Questions

Q1. What is an enum in C?

An enumeration is a user-defined type consisting of named integer constants.

Q2. What is the default value of the first enumerator?

Zero, if no explicit value is assigned.

Q3. Can enum constants have explicit values?

Yes. Explicit integer constant values can be assigned to enumerators.

Q4. Can two enum constants have the same value?

Yes. Different enumerator names can have equal integer values.

Q5. What happens when an enum value is not specified?

It is one greater than the value of the preceding enumerator.

Q6. What is typedef?

typedef creates an alias for an existing type.

Q7. Does typedef create a new data type?

No. It provides another name for an existing type.

Q8. Can typedef be used with structures?

Yes. It can create a shorter alias for a structure type.

Q9. Can typedef be used with function pointers?

Yes. It simplifies complex function pointer declarations.

Q10. What is the difference between enum and #define?

An enum declares named integer constants as part of the C language, while #define performs preprocessor macro substitution.

Q11. Can an enum variable be assigned an integer?

C permits assignments involving compatible integer values, although using declared enumerators is clearer and safer for program logic.

Q12. Where are enums useful in embedded systems?

They are useful for operating states, error codes, communication modes, peripheral states and state machines.
