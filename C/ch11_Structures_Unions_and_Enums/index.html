Chapter 11: Structures, Unions and Enums

Learn how to create user-defined data types, organize related information, work with structure pointers and understand memory representation in C.

Chapter Overview

Structures, unions and enumerations are essential C programming concepts used to organize data and represent complex information efficiently.

This chapter emphasizes practical coding, memory layout, pointer operations, embedded C applications and technical interview preparation.

Programming standard: C11

Placement focus: Structure-based coding, memory alignment, pointer handling, data representation, debugging and embedded firmware applications.

Chapter Learning Outcomes

  • Declare, initialize and access structures.
  • Work with arrays of structures and nested structures.
  • Pass structures to functions and use structure pointers.
  • Understand structure padding and memory alignment.
  • Differentiate structures and unions.
  • Use enumerations and typedef effectively.
  • Understand bit fields and self-referential structures.
  • Solve structure and union interview problems.

Practical and Placement Preparation

Important Programming Tasks

  • Create and display employee or student records using structures.
  • Search and update records stored in an array of structures.
  • Pass structure variables and pointers to functions.
  • Calculate structure sizes and analyze padding.
  • Compare structure and union memory usage.
  • Use enums to represent states and operating modes.
  • Create self-referential structures for linked data.
  • Analyze structure and union output-prediction problems.

Embedded C Applications

  • Represent peripheral configuration data using structures.
  • Organize UART, SPI and I2C configuration parameters.
  • Use enumerations for device states and error codes.
  • Understand bit fields and their implementation-dependent layout.
  • Use unions for controlled access to alternative data representations.

Recommended Learning Sequence

  1. First understand structure declaration and member access.
  2. Practice arrays and nested structures.
  3. Learn structure pointers and function arguments.
  4. Study memory alignment and padding.
  5. Understand unions and compare their memory behavior with structures.
  6. Learn enums and typedef.
  7. Study bit fields and self-referential structures.
  8. Complete the interview and coding practice lecture.
