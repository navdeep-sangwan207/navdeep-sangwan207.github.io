Lecture 01: Structure Declaration, Initialization and Access

Learn how to create user-defined data types in C, organize related variables into a single record and access individual structure members.

1. Learning Objectives

  • Understand the need for structures in C.
  • Learn structure declaration and definition.
  • Create structure variables.
  • Initialize structure members.
  • Access and modify members using the dot operator.
  • Understand structure assignment and copying.
  • Use character arrays and other arrays inside structures.
  • Solve practical structure-based programming problems.

2. Why Do We Need Structures?

Consider an employee record containing:

  • Employee ID
  • Employee name
  • Salary
  • Department code

Without structures, we could declare separate variables for every employee. 

int id;
char name[50];
float salary;
int department;

When multiple employee records are required, managing separate variables becomes difficult. A structure groups related variables under one user-defined type.

A structure is a user-defined composite data type that groups multiple members, which may have different data types, under one name.

3. Structure Declaration Syntax

The general syntax is:

struct StructureName
{
    data_type member1;
    data_type member2;
    data_type member3;
};

Example: 

struct Employee
{
    int id;
    char name[50];
    float salary;
};

Here:

  • struct is the structure keyword.
  • Employee is the structure tag.
  • id, name and salary are structure members.
The structure definition describes a type. It does not, by itself, declare an object that stores an employee record.

4. Declaring Structure Variables

After defining a structure type, variables can be declared using the structure tag. 

struct Employee
{
    int id;
    char name[50];
    float salary;
};

int main(void)
{
    struct Employee emp1;
    struct Employee emp2;

    return 0;
}

emp1 and emp2 are separate structure objects. Each contains its own id, name and salary members.

Declaring Variables Along with the Definition

struct Employee
{
    int id;
    char name[50];
    float salary;
} emp1, emp2;

Both emp1 and emp2 are declared as part of the structure definition.

5. Accessing Structure Members

The dot operator (.) is used to access individual members of a structure object. 

emp1.id = 101;
emp1.salary = 35000.0f;

A complete example: 

#include <stdio.h>

struct Employee
{
    int id;
    char name[50];
    float salary;
};

int main(void)
{
    struct Employee emp1;

    emp1.id = 101;
    emp1.salary = 35000.0f;

    printf("Employee ID: %d\n", emp1.id);
    printf("Salary: %.2f\n", emp1.salary);

    return 0;
}
Expected Output: 
Employee ID: 101
Salary: 35000.00
The dot operator is used with a structure object. The arrow operator (->) is used with a pointer to a structure and will be covered in Lecture 03.

6. Initializing Structure Variables

Method 1: Initialization at Declaration

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student s1 = {101, "Rahul", 87.5f};

    printf("Roll: %d\n", s1.roll);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}
Expected Output: 
Roll: 101
Name: Rahul
Marks: 87.50

Method 2: Designated Initializers (C99 and Later)

Designated initializers allow members to be initialized by name. 

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student s1 = {
        .name = "Amit",
        .marks = 91.5f,
        .roll = 102
    };

    printf("%d %s %.2f\n",
           s1.roll, s1.name, s1.marks);

    return 0;
}
Expected Output: 
102 Amit 91.50

Method 3: Partial Initialization

struct Student s1 = {101};

The first member receives 101. All remaining members are initialized as if they have static zero initialization. In particular, the character array begins with a null character and marks becomes 0.0.

Method 4: Zero Initialization

struct Student s1 = {0};

This initializes all members to their zero values.

An ordinary automatic structure variable declared without an initializer does not automatically have all members set to zero. Do not read its uninitialized members.

7. Modifying Structure Members

Structure members can be modified individually after the structure object has been declared. 

#include <stdio.h>

struct Product
{
    int code;
    float price;
};

int main(void)
{
    struct Product p1 = {501, 1200.0f};

    printf("Before update: %.2f\n", p1.price);

    p1.price = 1450.0f;

    printf("After update: %.2f\n", p1.price);

    return 0;
}
Expected Output: 
Before update: 1200.00
After update: 1450.00

8. Structure Assignment and Copying

Two compatible structure objects of the same structure type can be assigned directly. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s1 = {101, 88.5f};
    struct Student s2;

    s2 = s1;

    printf("Roll: %d\n", s2.roll);
    printf("Marks: %.2f\n", s2.marks);

    return 0;
}
Expected Output: 
Roll: 101
Marks: 88.50

Structure assignment copies the values of all members. When members include pointers, the pointer values are copied; the memory they point to is not duplicated.

C does not provide direct comparison of two complete structure objects using ==. Compare individual members when required.

9. Arrays Inside Structures

A structure can contain arrays as its members. This is useful for storing names, codes, fixed-size data and measurement samples. 

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    int marks[3];
};

int main(void)
{
    struct Employee e1 = {
        101,
        "Ravi",
        {80, 85, 90}
    };

    printf("ID: %d\n", e1.id);
    printf("Name: %s\n", e1.name);

    for (int i = 0; i < 3; i++)
    {
        printf("Marks %d: %d\n",
               i + 1, e1.marks[i]);
    }

    return 0;
}
Expected Output: 
ID: 101
Name: Ravi
Marks 1: 80
Marks 2: 85
Marks 3: 90

10. Structure vs Array

Feature Structure Array
Data types Members can have different types. All elements have the same element type.
Access Using member names. Using array indices.
Purpose Groups related fields into a record. Stores a sequence of elements.
Assignment Compatible structure objects can be assigned. Arrays cannot be assigned directly as whole objects.
Example Employee record List of employee IDs

11. Practical Program: Student Record Management

Create a program to accept and display the details of one student. 

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main(void)
{
    struct Student s1;

    printf("Enter roll number: ");

    if (scanf("%d", &s1.roll) != 1)
    {
        printf("Invalid roll number\n");
        return 1;
    }

    printf("Enter name: ");

    if (scanf("%49s", s1.name) != 1)
    {
        printf("Invalid name\n");
        return 1;
    }

    printf("Enter marks: ");

    if (scanf("%f", &s1.marks) != 1)
    {
        printf("Invalid marks\n");
        return 1;
    }

    printf("\n--- Student Details ---\n");

    printf("Roll: %d\n", s1.roll);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}

Sample Input

101
Amit
89.5
Expected Output: 
--- Student Details ---
Roll: 101
Name: Amit
Marks: 89.50

This program uses a structure to group three related fields into one student record. The input checks prevent the program from using values when scanf fails.

12. Practical Program: Calculate Total and Average

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks[3];
};

int main(void)
{
    struct Student s = {
        101,
        "Amit",
        {80.0f, 90.0f, 85.0f}
    };

    float total = 0.0f;
    float average;

    for (int i = 0; i < 3; i++)
    {
        total += s.marks[i];
    }

    average = total / 3.0f;

    printf("Student: %s\n", s.name);
    printf("Total: %.2f\n", total);
    printf("Average: %.2f\n", average);

    return 0;
}
Expected Output: 
Student: Amit
Total: 255.00
Average: 85.00

13. Structure Memory: Basic Understanding

Structure members are stored as part of the same structure object. However, the compiler may insert padding bytes between members or at the end of the structure. 

#include <stdio.h>

struct Example
{
    char a;
    int b;
    char c;
};

int main(void)
{
    printf("Size: %zu bytes\n",
           sizeof(struct Example));

    return 0;
}

The exact size is implementation-dependent. It depends on the target's type sizes and alignment requirements.

Structure padding and memory alignment are covered in detail in Lecture 04. Do not assume a particular structure size across all compilers and processors.

14. Common Interview Questions

Q1. What is a structure in C?

A structure is a user-defined type that groups multiple named members, potentially of different data types, into one object.

Q2. Which operator accesses structure members?

The dot operator (.).

Q3. Can a structure contain different data types?

Yes. A structure can contain members of different types, including arrays and other structure types.

Q4. Can one structure variable be assigned to another?

Yes, when both objects have compatible structure types.

Q5. Can two structures be compared using ==?

No. C does not support direct whole-structure equality comparison.

Q6. Can a structure contain an array?

Yes. Arrays can be declared as structure members.

Q7. Can a structure contain another structure?

Yes. This is called a nested structure and is covered in Lecture 02.

Q8. What is the difference between . and ->?

The dot operator accesses a member through a structure object. The arrow operator accesses a member through a structure pointer.

Q9. Does sizeof(struct) always equal the sum of member sizes?

No. Padding and alignment may increase the total size.

Q10. What is the purpose of structures in embedded C?

They organize related configuration values, device information, communication data and driver state.

15. Output Prediction Questions

Question 1

#include <stdio.h>

struct Data
{
    int x;
    int y;
};

int main(void)
{
    struct Data d = {10, 20};

    d.x = d.x + d.y;

    printf("%d %d\n", d.x, d.y);

    return 0;
}
Expected Output: 
30 20

Question 2

#include <stdio.h>

struct Test
{
    int a;
    int b;
};

int main(void)
{
    struct Test t1 = {5, 10};
    struct Test t2;

    t2 = t1;
    t2.a = 50;

    printf("%d %d\n", t1.a, t2.a);

    return 0;
}
Expected Output: 
5 50

Structure assignment copies member values. Modifying t2 does not modify t1.

Question 3

#include <stdio.h>

struct Sample
{
    int a;
    int b;
    int c;
};

int main(void)
{
    struct Sample s = {10};

    printf("%d %d %d\n", s.a, s.b, s.c);

    return 0;
}
Expected Output: 
10 0 0

Remaining members are zero-initialized because the aggregate has an initializer.

Basic Level

  1. Create a structure for storing employee ID, name and salary.
  2. Accept and display student details using a structure.
  3. Initialize a structure using positional initialization.
  4. Initialize a structure using designated initializers.
  5. Copy one structure object into another and modify a member.

Intermediate Level

  1. Store three subject marks inside a student structure and calculate the average.
  2. Create a structure for a product and calculate its discounted price.
  3. Store date information using day, month and year members.
  4. Create a structure containing an array of five sensor readings.
  5. Write a program to compare two student records member by member.

Advanced Level

  1. Design a structure to represent a UART configuration.
  2. Create a structure for an embedded device configuration.
  3. Analyze the memory layout of a structure containing char, int and float members.
  4. Develop a simple record-management program using structures.

17. Important Points to Remember

  • A structure groups related members into one user-defined type.
  • Use the struct keyword to declare a structure type.
  • Use the dot operator to access members through an object.
  • Structure members can have different data types.
  • Compatible structure objects can be assigned directly.
  • Whole structures cannot be compared directly using ==.
  • Structures can contain arrays and nested structures.
  • Structure padding can affect sizeof results.
  • Structure pointers and the arrow operator are covered next.
