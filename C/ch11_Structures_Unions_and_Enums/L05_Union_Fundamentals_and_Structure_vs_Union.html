Lecture 05: Union Fundamentals and Structure vs Union

Learn how unions share memory among different members, how union size and alignment are determined, and when to use unions in practical C and embedded programming.

1. Learning Objectives

  • Understand what a union is in C.
  • Learn union declaration and initialization.
  • Understand how union members share memory.
  • Determine union size using sizeof.
  • Understand union alignment and padding.
  • Learn how to access and modify union members.

  • Learn tagged unions and practical applications.
  • Explore union use cases in embedded systems.

2. What Is a Union in C?

A union is a user-defined data type that allows multiple members of different types to share the same memory location.

Unlike a structure, where each member has its own storage, union members overlap in memory.

Syntax

union UnionName
{
    data_type member1;
    data_type member2;
    data_type member3;
};

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char character;
};

int main(void)
{
    union Data value;

    value.number = 100;

    printf("Number: %d\n", value.number);

    return 0;
}
Output: 
Number: 100

The union variable value provides shared storage for number, decimal and character.

3. How Does Union Memory Allocation Work?

All union members begin at the same address. Their storage overlaps. 

union Data
{
    int number;
    float decimal;
    char character;
};

Consider a typical implementation where:

  • int occupies 4 bytes.
  • float occupies 4 bytes.
  • char occupies 1 byte.

A simplified conceptual view is: 

Shared union storage
+-------------------------------+
|                               |
|  int number                   |
|  float decimal                |
|  char character               |
|                               |
+-------------------------------+

The members occupy overlapping storage, rather than separate independent memory regions.

A union provides enough storage for its largest member, with alignment and possible padding also taken into account.

4. Understanding sizeof with Unions

The sizeof operator returns the total size of a union object. 

#include <stdio.h>

union Data
{
    int a;
    float b;
    char c;
};

int main(void)
{
    printf("Size of int: %zu\n", sizeof(int));
    printf("Size of float: %zu\n", sizeof(float));
    printf("Size of char: %zu\n", sizeof(char));

    printf("Size of union: %zu\n",
           sizeof(union Data));

    return 0;
}

On a common implementation where int and float each occupy 4 bytes, the output may be:

Illustrative Output: 
Size of int: 4
Size of float: 4
Size of char: 1
Size of union: 4

The union must be large enough for its largest member and must satisfy its alignment requirement.

Do not assume union size is always exactly the size of its largest member. Alignment and implementation-specific layout rules can affect the result.

5. Accessing Union Members

Union members are accessed using the dot operator, just like structure members. 

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char character;
};

int main(void)
{
    union Data value;

    value.number = 50;

    printf("Number: %d\n", value.number);

    value.decimal = 25.5f;

    printf("Decimal: %.2f\n", value.decimal);

    value.character = 'A';

    printf("Character: %c\n", value.character);

    return 0;
}
Output: 
Number: 50
Decimal: 25.50
Character: A

Each assignment stores a value in the shared union storage. The newly written member becomes the active value for ordinary program use.

Do not expect previously stored member values to remain independently available after another member is written.

6. Structure vs Union: Memory Difference

Structure Example

struct Data
{
    int number;
    float decimal;
    char character;
};

Each member has its own storage. 

Structure memory (conceptual)

+----------------------+
| int number           |
+----------------------+
| float decimal        |
+----------------------+
| char character       |
+----------------------+
| Possible padding     |
+----------------------+

Union Example

union Data
{
    int number;
    float decimal;
    char character;
};

All members share the same storage. 

Union memory (conceptual)

+----------------------+
|                      |
| int number           |
| float decimal        |
| char character       |
|                      |
+----------------------+

7. Structure vs Union: Complete Comparison

Feature Structure Union
Memory allocation Separate storage for each member Shared storage for all members
Member addresses Members can have different offsets All members begin at the same address
Size Includes member sizes and possible padding Enough for the largest member, including alignment needs
Member values All members can hold values simultaneously Only the currently stored member should normally be interpreted
Use case Grouping related data Representing alternative data types in shared storage
Memory efficiency May require more storage Can save storage when only one alternative is needed at a time

8. Comparing Structure and Union Sizes

#include <stdio.h>

struct SampleStruct
{
    int number;
    float decimal;
    char character;
};

union SampleUnion
{
    int number;
    float decimal;
    char character;
};

int main(void)
{
    printf("Structure size: %zu\n",
           sizeof(struct SampleStruct));

    printf("Union size: %zu\n",
           sizeof(union SampleUnion));

    return 0;
}

On a common ABI where int and float occupy 4 bytes and char occupies 1 byte:

Illustrative Output: 
Structure size: 12
Union size: 4

The structure stores all three members separately. The union reuses the same storage for its alternatives.

Exact values depend on the implementation.

9. Initializing a Union

A union can be initialized using a designated initializer or by initializing its first named member.

Method 1: Initialize First Member

#include <stdio.h>

union Value
{
    int number;
    float decimal;
};

int main(void)
{
    union Value v = {100};

    printf("Number: %d\n", v.number);

    return 0;
}

Method 2: Designated Initializer

#include <stdio.h>

union Value
{
    int number;
    float decimal;
};

int main(void)
{
    union Value v = {
        .decimal = 15.5f
    };

    printf("Decimal: %.2f\n", v.decimal);

    return 0;
}
A designated initializer makes it clear which union member is being initialized.

10. Array of Unions

An array can contain multiple union objects. Each element has its own shared storage. 

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

int main(void)
{
    union Data values[3];

    values[0].number = 10;
    values[1].decimal = 20.5f;
    values[2].number = 30;

    printf("%d\n", values[0].number);
    printf("%.2f\n", values[1].decimal);
    printf("%d\n", values[2].number);

    return 0;
}
Output: 
10
20.50
30

Each array element is a separate union. Writing one element does not overwrite another element.

11. Nested Structures and Unions

A structure can contain a union as one of its members. 

#include <stdio.h>

struct Sensor
{
    int id;

    union
    {
        int digital_value;
        float analog_value;
    } reading;
};

int main(void)
{
    struct Sensor s;

    s.id = 101;
    s.reading.analog_value = 3.75f;

    printf("Sensor ID: %d\n", s.id);
    printf("Analog value: %.2f\n",
           s.reading.analog_value);

    return 0;
}
Output: 
Sensor ID: 101
Analog value: 3.75

The structure stores the sensor ID separately, while its reading member can represent either an integer or floating-point value.

12. Tagged Unions (Discriminated Unions)

A union does not automatically record which member currently contains the meaningful value.

A common safe design is to combine a union with an additional member called a tag or discriminator. 

#include <stdio.h>

enum ValueType
{
    TYPE_INTEGER,
    TYPE_FLOAT
};

struct TaggedValue
{
    enum ValueType type;

    union
    {
        int integer;
        float decimal;
    } value;
};

int main(void)
{
    struct TaggedValue data;

    data.type = TYPE_FLOAT;
    data.value.decimal = 12.75f;

    if (data.type == TYPE_INTEGER)
    {
        printf("Integer: %d\n",
               data.value.integer);
    }
    else if (data.type == TYPE_FLOAT)
    {
        printf("Float: %.2f\n",
               data.value.decimal);
    }

    return 0;
}
Output: 
Float: 12.75

The type field tells the program which union member should be interpreted.

Tagged unions are useful in interpreters, communication systems, protocol parsers, embedded firmware and event-processing applications.

13. Union Alignment

A union must satisfy the alignment requirements of its members. 

#include <stdio.h>

union Data
{
    char a;
    int b;
    double c;
};

int main(void)
{
    printf("Alignment of char: %zu\n",
           _Alignof(char));

    printf("Alignment of int: %zu\n",
           _Alignof(int));

    printf("Alignment of double: %zu\n",
           _Alignof(double));

    printf("Alignment of union: %zu\n",
           _Alignof(union Data));

    return 0;
}

The union's alignment requirement must be sufficient for its members. The exact values depend on the target implementation.

14. Accessing Union Members Through Pointers

A pointer can point to a union object. Its members can then be accessed using the arrow operator. 

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

int main(void)
{
    union Data value;
    union Data *ptr = &value;

    ptr->number = 250;

    printf("Number: %d\n", ptr->number);

    return 0;
}
Output: 
Number: 250

The arrow operator accesses a union member through a pointer to the union.

15. Type Punning and Union Members

Type punning means interpreting stored data through a different type.

For example, programmers sometimes write one union member and read another member to inspect the same storage. 

union Number
{
    unsigned int integer;
    float decimal;
};
Reading a union member other than the one most recently written has implementation-defined aspects in C. It is not a portable way to convert an integer into a floating-point value.

For portable representation inspection, use memcpy and examine the resulting bytes with suitable types.

Portable Byte Inspection Example

#include <stdio.h>
#include <stdint.h>
#include <string.h>

int main(void)
{
    float value = 12.5f;
    unsigned char bytes[sizeof value];

    memcpy(bytes, &value, sizeof value);

    printf("Object representation bytes:\n");

    for (size_t i = 0; i < sizeof value; i++)
    {
        printf("%02X ", (unsigned int)bytes[i]);
    }

    printf("\n");

    return 0;
}

This program copies the object representation into a byte array. The printed bytes depend on the floating-point representation and byte order of the implementation.

16. Practical Applications of Unions

1. Embedded Sensor Data

A sensor may provide alternative representations of a reading, such as an integer count or floating-point value. A union can store one selected form.

2. Communication Protocols

Protocol parsers may use tagged unions to represent different message payload types. Explicit serialization and deserialization should still handle the wire format.

3. Memory-Constrained Systems

When multiple data alternatives are mutually exclusive, a union can reduce storage compared with allocating separate fields for every alternative.

4. Operating Systems and Firmware

Unions can represent alternative states, command payloads and hardware-related data formats where the design explicitly defines which member is active.

5. State Machines

A state machine can use a tag with a union to store state-specific data.

17. Common Mistakes and Pitfalls

Mistake Why It Is a Problem
Assuming all union members have separate memory Union members overlap in storage.
Expecting all old values to remain available Writing another member changes the shared storage.
Assuming union size equals the largest member exactly Alignment and padding can affect the size.
Reading an inactive member without understanding the rules The interpretation may not be portable.
Using a union as a portable type-conversion mechanism Representation and implementation rules vary.
Forgetting which member is active The program may interpret the stored representation incorrectly.

18. Placement-Oriented Interview Questions

Q1. What is a union in C?

A user-defined data type whose members share the same memory storage.

Q2. What is the main difference between a structure and a union?

A structure provides separate storage for each member, whereas a union uses overlapping storage for its members.

Q3. How is union size determined?

It must be sufficient to store its largest member and satisfy the union's alignment requirements.

Q4. Can we access all union members independently?

No. They share storage. A program should track which member currently contains the meaningful value.

Q5. Can a union contain a structure?

Yes. A structure can be declared as a union member.

Q6. Can a structure contain a union?

Yes. This is commonly used to represent alternative data within a larger record.

Q7. What is a tagged union?

A union combined with a separate tag that identifies which member is active.

Q8. Can a union contain an array?

Yes. An array can be declared as a union member.

Q9. Why are unions useful in embedded systems?

They can represent alternative data formats while sharing storage, which can be useful when RAM is limited.

Q10. What is type punning?

It is interpreting an object's stored representation through a different type. Union-based type punning has portability considerations in C.
