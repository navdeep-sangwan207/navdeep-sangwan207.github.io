Lecture 03: Structure Pointers and Function Arguments

Understand pointers to structures, the arrow operator, passing structures to functions, modifying records through pointers and practical pointer-based programming.

1. Learning Objectives

  • Understand pointers to structure objects.
  • Declare and initialize structure pointers.
  • Access members using the arrow operator.
  • Understand the relationship between . and ->.
  • Pass structures to functions by value.
  • Pass structure addresses to functions.
  • Modify structure members through pointers.
  • Return structures from functions.
  • Work with arrays of structures using pointers.
  • Apply structure pointers in embedded C programs.

2. Why Do We Need Pointers to Structures?

Consider a structure containing employee information: 

struct Employee
{
    int id;
    char name[30];
    float salary;
};

struct Employee emp = {101, "Amit", 35000.0f};

We can access its members directly using the dot operator. 

printf("%d", emp.id);

However, when a structure needs to be passed to another function or modified through its address, a pointer to that structure becomes useful.

A structure pointer is a pointer variable that stores the address of a structure object.

3. Declaring a Pointer to a Structure

General syntax:

struct StructureName *pointer_name;

Example:

struct Employee
{
    int id;
    char name[30];
    float salary;
};

struct Employee emp;

struct Employee *ptr = &emp;

Here:

  • emp is a structure object.
  • ptr is a pointer to struct Employee.
  • &emp gives the address of emp.
  • ptr stores that address.

Basic Memory Relationship

struct Employee emp;
struct Employee *ptr = &emp;
        ptr
         |
         v
    +-------------------+
    |   emp             |
    |-------------------|
    | id                |
    | name              |
    | salary            |
    +-------------------+

The pointer refers to the complete structure object. Its members can be accessed through the pointer.

4. Accessing Members Using the Arrow Operator

C provides the arrow operator (->) to access structure members through a pointer.

Syntax:

pointer_name->member_name;

Example

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

int main(void)
{
    struct Employee emp;

    struct Employee *ptr = &emp;

    ptr->id = 101;
    ptr->salary = 35000.0f;

    printf("ID: %d\n", ptr->id);
    printf("Salary: %.2f\n", ptr->salary);

    return 0;
}
Expected Output: 
ID: 101
Salary: 35000.00

5. Difference Between Dot and Arrow Operators

Feature Dot Operator (.) Arrow Operator (->)
Used with Structure object Pointer to structure
Syntax emp.id ptr->id
Purpose Direct member access Member access through pointer

Important Relationship

ptr->id

is equivalent to:

(*ptr).id
Parentheses are important. The expression (*ptr).id accesses the member of the structure object pointed to by ptr.

Program Demonstrating Both Operators

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main(void)
{
    struct Student s = {101, 88.5f};

    struct Student *ptr = &s;

    printf("Using dot: %d\n", s.roll);

    printf("Using arrow: %d\n", ptr->roll);

    printf("Using dereference: %d\n", (*ptr).roll);

    return 0;
}
Expected Output: 
Using dot: 101
Using arrow: 101
Using dereference: 101

6. Modifying Structure Members Through Pointers

A structure pointer can modify the original structure object when it points to a valid modifiable object. 

#include <stdio.h>

struct Product
{
    int id;
    float price;
};

int main(void)
{
    struct Product p = {501, 1200.0f};

    struct Product *ptr = &p;

    printf("Before update: %.2f\n", p.price);

    ptr->price = 1500.0f;

    printf("After update: %.2f\n", p.price);

    return 0;
}
Expected Output: 
Before update: 1200.00
After update: 1500.00

ptr->price modifies the price member of the original object p.

7. Passing a Structure to a Function by Value

A structure can be passed directly as a function argument.

In this method, the function receives its own structure parameter initialized from the argument. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

void display(struct Student s)
{
    printf("Roll: %d\n", s.roll);
    printf("Marks: %.2f\n", s.marks);
}

int main(void)
{
    struct Student s1 = {101, 90.5f};

    display(s1);

    return 0;
}
Expected Output: 
Roll: 101
Marks: 90.50

The function receives a separate structure parameter. Changes to its ordinary members do not modify the original structure object.

Demonstration

#include <stdio.h>

struct Data
{
    int value;
};

void modify(struct Data d)
{
    d.value = 100;
}

int main(void)
{
    struct Data x = {10};

    modify(x);

    printf("%d\n", x.value);

    return 0;
}
Expected Output: 
10

8. Passing a Structure Pointer to a Function

Instead of passing the complete structure, we can pass its address to a function.

This allows the function to access and modify the original structure object. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

void update(struct Student *s)
{
    s->marks = 95.0f;
}

int main(void)
{
    struct Student s1 = {101, 80.0f};

    update(&s1);

    printf("Roll: %d\n", s1.roll);
    printf("Marks: %.2f\n", s1.marks);

    return 0;
}
Expected Output: 
Roll: 101
Marks: 95.00
The address of s1 is passed to update(). The function parameter points to the original structure, so changes are visible after the function returns.

9. Structure by Value vs Structure Pointer

Feature Pass by Value Pass Pointer
Function argument Structure object Address of structure object
Function parameter struct Student s struct Student *s
Access operator Dot operator Arrow operator
Modify original members No, not through the parameter itself Yes, when the pointer refers to a modifiable object
Data passed Structure value Pointer value
Common application Read-only processing of a small record Updating records and avoiding structure copies
C always passes function arguments by value. Passing a pointer means the pointer value (the address) is copied into the function parameter. It is not a separate pass-by-reference mechanism in the C language.

10. Using const with Structure Pointers

A const-qualified structure pointer parameter can prevent a function from modifying the structure through that pointer. 

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

void display(const struct Employee *emp)
{
    printf("ID: %d\n", emp->id);
    printf("Salary: %.2f\n", emp->salary);
}

int main(void)
{
    struct Employee e = {101, 45000.0f};

    display(&e);

    return 0;
}
Expected Output: 
ID: 101
Salary: 45000.00

The function can read the members through emp, but cannot modify the structure members through this pointer.

Passing const structure pointers is a useful convention for functions that only need to inspect records.

11. Returning a Structure from a Function

A function can return a structure object by value. 

#include <stdio.h>

struct Point
{
    int x;
    int y;
};

struct Point create_point(void)
{
    struct Point p = {10, 20};

    return p;
}

int main(void)
{
    struct Point result = create_point();

    printf("X: %d\n", result.x);
    printf("Y: %d\n", result.y);

    return 0;
}
Expected Output: 
X: 10
Y: 20

Returning a structure by value is valid. The returned structure is a value, not a pointer to a local object.

Do not return the address of an ordinary local structure variable. Its lifetime ends when the function returns, so the returned pointer would become invalid.

12. Passing an Array of Structures to a Function

An array of structures can be processed by a function using a pointer parameter and an element count. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

void display_students(const struct Student *s, int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("%d %.2f\n", s[i].roll, s[i].marks);
    }
}

int main(void)
{
    struct Student students[3] = {
        {101, 80.5f},
        {102, 90.0f},
        {103, 85.5f}
    };

    display_students(students, 3);

    return 0;
}
Expected Output: 
101 80.50
102 90.00
103 85.50

When an array is passed to a function, the parameter receives a pointer to its first element. The function also needs the number of elements to traverse safely.

13. Pointer Arithmetic with Structure Arrays

A pointer to a structure can traverse an array of structure objects. 

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

int main(void)
{
    struct Employee emp[3] = {
        {101, 25000.0f},
        {102, 30000.0f},
        {103, 35000.0f}
    };

    struct Employee *ptr = emp;

    for (int i = 0; i < 3; i++)
    {
        printf("%d %.2f\n",
               (ptr + i)->id,
               (ptr + i)->salary);
    }

    return 0;
}
Expected Output: 
101 25000.00
102 30000.00
103 35000.00

ptr + 1 points to the next structure element, not merely the next byte. Pointer arithmetic automatically accounts for sizeof(struct Employee).

14. Practical Program: Employee Salary Update

Create a function that updates an employee's salary using a structure pointer. 

#include <stdio.h>

struct Employee
{
    int id;
    char name[30];
    float salary;
};

void increase_salary(struct Employee *emp, float amount)
{
    if (emp != NULL && amount >= 0.0f)
    {
        emp->salary += amount;
    }
}

int main(void)
{
    struct Employee e = {
        101,
        "Amit",
        30000.0f
    };

    printf("Before: %.2f\n", e.salary);

    increase_salary(&e, 5000.0f);

    printf("After: %.2f\n", e.salary);

    return 0;
}
Expected Output: 
Before: 30000.00
After: 35000.00

The function checks the pointer before dereferencing it and modifies the original employee record.

15. Practical Embedded C Application

Structure pointers are useful when passing peripheral configuration information to driver functions.

Example: UART Configuration Data

#include <stdio.h>

struct UART_Config
{
    unsigned int baud_rate;
    unsigned int data_bits;
    unsigned int stop_bits;
};

void UART_DisplayConfig(const struct UART_Config *config)
{
    if (config == NULL)
    {
        return;
    }

    printf("Baud Rate: %u\n", config->baud_rate);
    printf("Data Bits: %u\n", config->data_bits);
    printf("Stop Bits: %u\n", config->stop_bits);
}

int main(void)
{
    struct UART_Config uart0 = {
        9600,
        8,
        1
    };

    UART_DisplayConfig(&uart0);

    return 0;
}
Expected Output: 
Baud Rate: 9600
Data Bits: 8
Stop Bits: 1

A driver can accept a pointer to a configuration structure rather than receiving every configuration parameter separately.

In real embedded firmware, the driver would use these settings to configure the peripheral registers. This example demonstrates the data organization and function interface, not actual UART hardware initialization.

16. Common Errors and Debugging

Error 1: Using an Uninitialized Structure Pointer

struct Employee *ptr;

ptr->id = 101;

Problem: ptr does not point to a valid structure object.

Correction:

struct Employee emp;
struct Employee *ptr = &emp;

ptr->id = 101;

Error 2: Incorrect Operator

ptr.id = 101;

If ptr is a pointer, use: 

ptr->id = 101;

Error 3: Missing Parentheses

*ptr.id

This is not equivalent to accessing a member through a structure pointer.

Correct:

(*ptr).id

Error 4: Returning the Address of a Local Structure

struct Employee *create(void)
{
    struct Employee emp;

    return &emp;
}

Problem: emp has automatic storage duration. Its lifetime ends when create() returns.

Correction: Return a structure value, or use caller-provided storage or dynamically allocated memory with an appropriate ownership policy.

Error 5: Dereferencing a NULL Pointer

struct Employee *ptr = NULL;

ptr->id = 101;

Problem: A NULL pointer does not refer to a valid structure object.

Correction:

if (ptr != NULL)
{
    ptr->id = 101;
}

18. Technical Interview Questions

Q1. What is a pointer to a structure?

It is a pointer variable that stores the address of a structure object.

Q2. What is the arrow operator?

The arrow operator accesses a structure member through a pointer to that structure.

Q3. What is the difference between ptr->x and (*ptr).x?

They are equivalent expressions for accessing member x through a structure pointer.

Q4. Can a structure be passed to a function?

Yes. It can be passed by value or through a pointer argument.

Q5. Does passing a structure by value modify the original object?

No. The function parameter is a separate structure object.

Q6. How can a function modify the original structure?

Pass the address of the structure and modify its members through a valid pointer.

Q7. Can a function return a structure?

Yes. A structure can be returned by value.

Q8. Why should a function accept a const structure pointer?

It allows the function to inspect a structure without modifying its members through that pointer.

Q9. What happens when a structure pointer is incremented?

It advances to the next structure element, scaled by the size of the pointed-to type.

Q10. Why are structure pointers useful in embedded systems?

They allow configuration data and device state to be passed efficiently to driver and service functions.

Q11. Does C support pass by reference?

No. C uses pass by value. A pointer can be passed by value to allow a function to modify the object it points to.

Q12. Can a structure pointer point to a const structure?

Yes. For example: const struct Employee *ptr. The object cannot be modified through ptr.

20. Important Points to Remember

  • A structure pointer stores the address of a structure object.
  • Use the arrow operator to access members through a pointer.
  • ptr->member is equivalent to (*ptr).member.
  • Passing a structure by value creates a separate parameter object.
  • Passing a structure pointer allows access to the original object.
  • C passes all function arguments by value, including pointers.
  • A function can return a structure by value.
  • Never return a pointer to an expired automatic local object.
  • Use const structure pointers for read-only function interfaces.
  • Structure pointers can traverse arrays of structures.
  • Always validate pointers before dereferencing when they may be NULL.
