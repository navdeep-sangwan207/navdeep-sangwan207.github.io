2. Structure Fundamentals: Interview Revision

A structure is a user-defined data type that groups multiple members, potentially of different data types, under one name. 

#include <stdio.h>

struct Employee
{
    int id;
    char grade;
    float salary;
};

int main(void)
{
    struct Employee e = {101, 'A', 35000.0f};

    printf("ID: %d\n", e.id);
    printf("Grade: %c\n", e.grade);
    printf("Salary: %.2f\n", e.salary);

    return 0;
}
Output: 
ID: 101
Grade: A
Salary: 35000.00

Important Interview Points

  • Each structure object has its own members.
  • Structure members are accessed using the dot operator.
  • Structures can contain arrays, pointers and other structures.
  • Structure assignment is permitted between compatible structure types.
  • Structures cannot be compared directly using == or !=.

3. Problem 1: Structure Assignment

Can one structure variable be assigned to another variable of the same structure type? 

#include <stdio.h>

struct Point
{
    int x;
    int y;
};

int main(void)
{
    struct Point p1 = {10, 20};
    struct Point p2;

    p2 = p1;

    printf("%d %d\n", p2.x, p2.y);

    return 0;
}
Output: 
10 20

Structure assignment copies the value of each member. If a member is a pointer, its pointer value is copied, not the dynamically allocated object it points to.

Structure assignment is not automatically a deep copy. Pointer members may continue to refer to the same memory.

4. Problem 2: Why Cannot We Compare Structures Directly?

struct Point
{
    int x;
    int y;
};

int main(void)
{
    struct Point p1 = {10, 20};
    struct Point p2 = {10, 20};

    /* Invalid:
       if (p1 == p2)
       {
       }
    */

    return 0;
}

C does not provide built-in equality comparison for complete structure objects.

Correct Approach

#include <stdio.h>

struct Point
{
    int x;
    int y;
};

int main(void)
{
    struct Point p1 = {10, 20};
    struct Point p2 = {10, 20};

    if (p1.x == p2.x && p1.y == p2.y)
    {
        printf("Equal\n");
    }
    else
    {
        printf("Not equal\n");
    }

    return 0;
}
Output: 
Equal

5. Problem 3: Passing a Structure to a Function

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

void display(struct Employee e)
{
    printf("ID: %d\n", e.id);
    printf("Salary: %.2f\n", e.salary);
}

int main(void)
{
    struct Employee e = {101, 45000.0f};

    display(e);

    return 0;
}
Output: 
ID: 101
Salary: 45000.00

Passing a structure by value provides the function with its own parameter object. Changes to that parameter do not modify the original structure object.

6. Problem 4: Modifying a Structure Through a Pointer

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

void updateSalary(struct Employee *e)
{
    e->salary = 60000.0f;
}

int main(void)
{
    struct Employee emp = {101, 40000.0f};

    updateSalary(&emp);

    printf("%.2f\n", emp.salary);

    return 0;
}
Output: 
60000.00

The arrow operator accesses a structure member through a pointer. 

e->salary

It is equivalent to:

(*e).salary

7. Problem 5: Array of Structures

#include <stdio.h>

struct Student
{
    int roll;
    int marks;
};

int main(void)
{
    struct Student s[3] =
    {
        {1, 85},
        {2, 90},
        {3, 78}
    };

    int i;

    for (i = 0; i < 3; i++)
    {
        printf("%d %d\n", s[i].roll, s[i].marks);
    }

    return 0;
}
Output: 
1 85
2 90
3 78

Interview Concept

An array of structures stores multiple structure objects in contiguous array storage. Each element has the same structure type.

9. Problem 7: Structure Padding and sizeof

#include <stdio.h>

struct Sample
{
    char a;
    int b;
    char c;
};

int main(void)
{
    printf("Size: %zu\n", sizeof(struct Sample));

    return 0;
}

The structure may contain padding between members and at the end to satisfy the implementation's alignment requirements.

Do not assume a universal numeric output. Structure size depends on the implementation, target ABI, alignment rules and compiler options.

Reordering Members

struct SampleA
{
    char a;
    int b;
    char c;
};

struct SampleB
{
    int b;
    char a;
    char c;
};

Reordering members can change the amount of padding and therefore the structure size on a particular implementation. It does not guarantee a smaller structure on every platform.

10. Problem 8: Union Memory Sharing

#include <stdio.h>

union Data
{
    int i;
    float f;
    char c;
};

int main(void)
{
    union Data d;

    d.i = 100;

    printf("%d\n", d.i);

    d.c = 'A';

    printf("%c\n", d.c);

    return 0;
}
Output: 
100
A

Union members share storage. Assigning a new member changes the stored representation of the union.

Do not assume that all union members contain simultaneously preserved values. Reading a different member from the one most recently written requires careful attention to C's union representation and implementation rules.

11. Problem 9: Structure vs Union

Structure Union
Members have distinct storage within the object. Members share the same storage region.
Multiple members can hold values simultaneously. Typically one member's value is active at a time.
Size is sufficient for all members plus padding. Size is sufficient for its largest member plus alignment requirements.
Useful for grouping related data. Useful for representing alternative data forms.

Interview Question

Which generally requires less memory: a structure or a union containing the same members?

A union often requires less storage because its members share storage. However, exact sizes and alignment depend on the implementation.

12. Problem 10: Union with a Structure

#include <stdio.h>

struct IntegerData
{
    int value;

{

union Data
{

    struct FloatData float_data;

A union can contain structures as members. The same storage-sharing rules apply.

16. Problem 14: Self-Referential Structure

#include <stdio.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node second = {20, NULL};
    struct Node first = {10, &second};

    printf("%d\n", first.data);
    printf("%d\n", first.next->data);

    return 0;
}
Output: 
10
20

A pointer to the same structure type allows objects to be connected without creating an infinitely sized structure.

17. Problem 15: Reverse a Singly Linked List

This is a frequently asked linked-list coding problem.

Complete C11 Program

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *createNode(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);

    if (newNode == NULL)
    {
        return NULL;
    }

    newNode->data = value;
    newNode->next = NULL;

    return newNode;
}

void display(struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

struct Node *reverse(struct Node *head)
{
    struct Node *previous = NULL;
    struct Node *current = head;
    struct Node *nextNode;

    while (current != NULL)
    {
        nextNode = current->next;

        current->next = previous;

        previous = current;
        current = nextNode;
    }

    return previous;
}

void freeList(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *temp = head;
        head = head->next;
        free(temp);
    }
}

int main(void)
{
    struct Node *head = createNode(10);

    if (head == NULL)
    {
        return 1;
    }

    head->next = createNode(20);

    if (head->next == NULL)
    {
        freeList(head);
        return 1;
    }

    head->next->next = createNode(30);

    if (head->next->next == NULL)
    {
        freeList(head);
        return 1;
    }

    printf("Original list:\n");
    display(head);

    head = reverse(head);

    printf("Reversed list:\n");
    display(head);

    freeList(head);

    return 0;
}
Output: 
Original list:
10 -> 20 -> 30 -> NULL

Reversed list:
30 -> 20 -> 10 -> NULL

Algorithm

  1. Initialize previous to NULL.
  2. Set current to the head node.
  3. Save the next node before changing the link.
  4. Make current point to previous.
  5. Move previous and current one node forward.
  6. Return previous as the new head.

Time complexity: O(n).

Auxiliary space complexity: O(1).

18. Problem 16: Find the Length of a Linked List

#include <stdio.h>

struct Node
{
    int data;
    struct Node *next;
};

int length(struct Node *head)
{
    int count = 0;

    while (head != NULL)
    {
        count++;
        head = head->next;
    }

    return count;
}

int main(void)
{
    struct Node c = {30, NULL};
    struct Node b = {20, &c};
    struct Node a = {10, &b};

    printf("Length: %d\n", length(&a));

    return 0;
}
Output: 
Length: 3

Time complexity: O(n).

Auxiliary space complexity: O(1).

19. Problem 17: Detect a Cycle in a Linked List

Floyd's cycle detection algorithm uses two pointers:

  • Slow moves one node at a time.
  • Fast moves two nodes at a time.
#include <stdio.h>
#include <stdbool.h>

struct Node
{
    int data;
    struct Node *next;
};

bool hasCycle(struct Node *head)
{
    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
        {
            return true;
        }
    }

    return false;
}

int main(void)
{
    struct Node third = {30, NULL};
    struct Node second = {20, &third};
    struct Node first = {10, &second};

    printf("%s\n",
           hasCycle(&first) ? "Cycle detected" : "No cycle");

    return 0;
}
Output: 
No cycle

Time complexity: O(n).

Auxiliary space complexity: O(1).

21. Debugging Problems

Problem 1: Incorrect Pointer Initialization

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    struct Node *head;

    head->data = 10;

    return 0;
}

Problem:

head is an uninitialized pointer. Dereferencing it results in undefined behavior.

Correction:

struct Node *head = NULL;

head = malloc(sizeof *head);

if (head != NULL)
{
    head->data = 10;
    head->next = NULL;

    free(head);
}

Problem 2: Missing NULL Check

struct Node *newNode = malloc(sizeof *newNode);

newNode->data = 10;

The allocation can fail. Always check whether malloc returned NULL before dereferencing the pointer.

Problem 3: Memory Leak

struct Node *node = malloc(sizeof *node);

/* Use node */

/* Missing free(node); */

If dynamically allocated memory is no longer needed, release it using free.

22. Frequently Asked Technical Interview Questions

Q1. What is the difference between a structure and an array?

An array stores elements of the same type. A structure groups members that can have different types.

Q2. Can a structure contain a pointer to itself?

Yes. A pointer to the same structure type is valid.

Q3. Can a structure contain another structure?

Yes, provided the nested structure type is complete when used as an ordinary structure member.

Q4. Can a structure contain a function?

No. C structures cannot contain function members, but they can contain function pointers.

Q5. Can a structure be returned from a function?

Yes. A function can return a structure by value.

Q6. Can a union contain a structure?

Yes. A structure can be a union member.

Q7. What determines the size of a union?

Its size must be sufficient for its largest member, including applicable alignment requirements.

Q8. What is structure padding?

Padding consists of additional bytes inserted to satisfy alignment requirements.

Q9. What is the purpose of typedef?

It introduces an alias for an existing type.

Q10. What is a bit field?

A structure member declared with a specified number of bits.

Q11. What is a dangling pointer in a linked list?

A pointer that refers to an object whose lifetime has ended or whose allocated memory has been released.

Q12. What is the time complexity of linked-list traversal?

O(n), where n is the number of nodes.

Q13. What is the difference between malloc and calloc?

malloc allocates a block of uninitialized storage. calloc allocates storage for an array of objects and initializes all allocated bytes to zero.

Q14. Why is a linked list called a dynamic data structure?

Nodes can be allocated and released during program execution, allowing the structure to grow or shrink.

Q15. Why might an array be preferred over a linked list?

Arrays provide constant-time indexed access and generally better cache locality.
