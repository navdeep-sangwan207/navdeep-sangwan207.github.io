2. Categories of File I/O Functions

C provides different functions for handling character data, strings and formatted values in files.

Category Input Function Output Function
Character I/O fgetc() fputc()
String I/O fgets() fputs()
Formatted I/O fscanf() fprintf()

These functions operate on a stream opened using fopen().

3. Character Input Using fgetc()

The fgetc() function reads one character from a specified file stream.

Syntax

int fgetc(FILE *stream);

Important Points

  • Reads one character from the stream.
  • Advances the stream position after a successful read.
  • Returns the character converted to unsigned char and then to int.
  • Returns EOF when end-of-file is reached or a read error occurs.
Store the result of fgetc() in an int, not a char. This allows the program to distinguish every possible character value from the special EOF value.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;
    int ch;

    fp = fopen("message.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    ch = fgetc(fp);

    if (ch != EOF)
    {
        printf("First character: %c\n", ch);
    }
    else
    {
        if (ferror(fp))
            fprintf(stderr, "File reading error.\n");
        else
            printf("File is empty.\n");
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    return 0;
}

Suppose message.txt contains:

Hello C Programming

Expected Output

First character: H

4. Character Output Using fputc()

The fputc() function writes one character to a specified file stream.

Syntax

int fputc(int character, FILE *stream);

Important Points

  • Writes one character to the stream.
  • Returns the written character as an unsigned-char value converted to int on success.
  • Returns EOF if a write error occurs.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;
    const char message[] = "C FILE";
    int i;

    fp = fopen("characters.txt", "w");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    for (i = 0; message[i] != '\0'; i++)
    {
        if (fputc((unsigned char)message[i], fp) == EOF)
        {
            fprintf(stderr, "Character writing failed.\n");
            fclose(fp);
            return 1;
        }
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    printf("Characters written successfully.\n");

    return 0;
}

Expected Output

Characters written successfully.

Content of characters.txt

5. Reading a Complete File Character by Character

A common file-processing task is reading every character until the end of the file.

Program

#include <stdio.h>

int main(void)
{
    FILE *fp;
    int ch;

    fp = fopen("message.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    while ((ch = fgetc(fp)) != EOF)
    {
        if (putchar(ch) == EOF)
        {
            fprintf(stderr, "Output error.\n");
            fclose(fp);
            return 1;
        }
    }

    if (ferror(fp))
    {
        fprintf(stderr, "Error while reading file.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    return 0;
}

If message.txt contains:

Welcome to C Programming. File handling is important.

Expected Output

Welcome to C Programming. File handling is important.
Placement point: The expression (ch = fgetc(fp)) != EOF is a common file-reading pattern. The variable must be an int. Use ferror() after the loop to distinguish a read error from normal end-of-file.

6. String Input Using fgets()

The fgets() function reads a string from a file stream. It reads at most a specified number of characters and stores the result in a character array.

Syntax

char *fgets(char *str, int n, FILE *stream);

Parameters

Parameter Meaning
str Destination character array.
n Maximum number of characters including the terminating null character.
stream File stream from which input is read.

Important Behavior

  • Reads at most n - 1 characters.
  • Stops after reading a newline, if one is encountered.
  • Stores the newline character if it is read.
  • Adds a terminating '\0' after the characters read.
  • Returns the destination pointer on success.
  • Returns NULL if an error occurs or end-of-file is encountered before any character is read.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;
    char buffer[100];

    fp = fopen("message.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    if (fgets(buffer, sizeof(buffer), fp) != NULL)
    {
        printf("Read line: %s", buffer);
    }
    else if (ferror(fp))
    {
        fprintf(stderr, "Reading error.\n");
    }
    else
    {
        printf("No data available.\n");
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    return 0;
}

7. String Output Using fputs()

The fputs() function writes a string to a file stream.

Syntax

int fputs(const char *str, FILE *stream);

Important Points

  • Writes the string until its terminating null character.
  • Does not write the terminating '\0'.
  • Does not automatically append a newline character.
  • Returns a non-negative value on success.
  • Returns EOF on a write error.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;

    fp = fopen("student.txt", "w");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    if (fputs("Name: Rahul\n", fp) == EOF ||
        fputs("Course: C Programming\n", fp) == EOF ||
        fputs("Status: Learning\n", fp) == EOF)
    {
        fprintf(stderr, "Writing failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    printf("Student information saved.\n");

    return 0;
}

Expected Output

Student information saved.

Content of student.txt

Name: Rahul Course: C Programming Status: Learning

8. Formatted Output Using fprintf()

The fprintf() function writes formatted data to a file stream. Its format string works similarly to printf().

Syntax

int fprintf(FILE *stream, const char *format, ...);

Important Points

  • Writes formatted data to the specified stream.
  • Supports format specifiers such as %d, %f, %c and %s.
  • Returns the number of characters transmitted on success.
  • Returns a negative value if an output error occurs.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;

    int roll = 101;
    char name[] = "Rahul";
    float marks = 87.5f;

    fp = fopen("student_record.txt", "w");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    if (fprintf(fp,
                "Roll Number: %d\nName: %s\nMarks: %.2f\n",
                roll, name, marks) < 0)
    {
        fprintf(stderr, "Formatted writing failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    printf("Record saved successfully.\n");

    return 0;
}

Expected Output

Record saved successfully.

Content of student_record.txt

Roll Number: 101 Name: Rahul Marks: 87.50

9. Formatted Input Using fscanf()

The fscanf() function reads formatted input from a file stream.

Syntax

int fscanf(FILE *stream, const char *format, ...);

Important Points

  • Reads formatted values from a file.
  • Uses format specifiers to determine the expected input types.
  • Returns the number of successfully assigned input items.
  • Returns EOF if input failure occurs before the first conversion completes.

Example

Assume student_data.txt contains:

101 Rahul 87.5
#include <stdio.h>

int main(void)
{
    FILE *fp;
    int roll;
    char name[30];
    float marks;

    fp = fopen("student_data.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    if (fscanf(fp, "%d %29s %f", &roll, name, &marks) != 3)
    {
        fprintf(stderr, "Invalid or incomplete student record.\n");
        fclose(fp);
        return 1;
    }

    printf("Roll Number: %d\n", roll);
    printf("Name: %s\n", name);
    printf("Marks: %.2f\n", marks);

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    return 0;
}

Expected Output

Roll Number: 101 Name: Rahul Marks: 87.50
Security and correctness: The width limit %29s prevents the input from exceeding the 30-byte destination array, leaving room for the terminating null character. Always check the number of successful assignments returned by fscanf().

10. Difference Between printf() and fprintf()

printf() fprintf()
Writes formatted output to standard output. Writes formatted output to a specified stream.
Does not require a stream argument. Requires a stream argument as its first parameter.
printf("%d", value); fprintf(fp, "%d", value);

11. Difference Between scanf() and fscanf()

scanf() fscanf()
Reads formatted input from standard input. Reads formatted input from a specified stream.
Uses stdin implicitly. Requires a stream argument.
scanf("%d", &x); fscanf(fp, "%d", &x);

12. Practical Program: Copy a Text File

This program reads a source file line by line and writes each line into a destination file.

Program

#include <stdio.h>

int main(void)
{
    FILE *source;
    FILE *destination;
    char buffer[256];

    source = fopen("source.txt", "r");

    if (source == NULL)
    {
        perror("Opening source file");
        return 1;
    }

    destination = fopen("destination.txt", "w");

    if (destination == NULL)
    {
        perror("Opening destination file");
        fclose(source);
        return 1;
    }

    while (fgets(buffer, sizeof(buffer), source) != NULL)
    {
        if (fputs(buffer, destination) == EOF)
        {
            fprintf(stderr, "Writing to destination failed.\n");
            fclose(source);
            fclose(destination);
            return 1;
        }
    }

    if (ferror(source))
    {
        fprintf(stderr, "Reading source file failed.\n");
        fclose(source);
        fclose(destination);
        return 1;
    }

    if (fclose(source) == EOF)
    {
        perror("Closing source file");
        fclose(destination);
        return 1;
    }

    if (fclose(destination) == EOF)
    {
        perror("Closing destination file");
        return 1;
    }

    printf("File copied successfully.\n");

    return 0;
}

Suppose source.txt contains:

Expected Output

File copied successfully.

Content of destination.txt

13. Practical Program: Count Characters, Words and Lines

This program demonstrates character-by-character file processing and basic text analysis.

Program

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    FILE *fp;
    int ch;
    int characters = 0;
    int words = 0;
    int lines = 0;
    int in_word = 0;
    int last_char = '\n';

    fp = fopen("analysis.txt", "r");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    while ((ch = fgetc(fp)) != EOF)
    {
        characters++;
        last_char = ch;

        if (ch == '\n')
        {
            lines++;
        }

        if (isspace((unsigned char)ch))
        {
            in_word = 0;
        }
        else if (!in_word)
        {
            words++;
            in_word = 1;
        }
    }

    if (ferror(fp))
    {
        fprintf(stderr, "File reading error.\n");
        fclose(fp);
        return 1;
    }

    if (characters > 0 && last_char != '\n')
    {
        lines++;
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    printf("Characters: %d\n", characters);
    printf("Words: %d\n", words);
    printf("Lines: %d\n", lines);

    return 0;
}

Assume analysis.txt contains exactly:

C programming File handling

Expected Output

Characters: 28 Words: 4 Lines: 2
Note: The character count includes the newline between the two lines. The word-count logic treats sequences of non-whitespace characters as words. This is a basic whitespace-based word counter, not a complete natural-language tokenizer.

14. Common Errors and Best Practices

Error Best Practice
Storing fgetc() result in char. Use int to distinguish characters from EOF.
Using fgets() without specifying a buffer size. Pass the actual array capacity using sizeof(buffer).
Assuming fputs() automatically adds a newline. Add \n explicitly when needed.
Using an unbounded %s in fscanf(). Specify a width limit appropriate for the destination array.
Ignoring the return value of fscanf(). Check the expected number of successful assignments.
Assuming EOF always means a normal end-of-file condition. Use ferror() to check for read errors.
Not checking output errors. Check return values of output functions and fclose().

15. Placement-Oriented Interview Questions

Q1. What is the difference between fgetc() and getchar()?

fgetc() reads from a specified stream, while getchar() reads from standard input.

Q2. What is the difference between fputc() and putchar()?

fputc() writes a character to a specified stream, while putchar() writes to standard output.

Q3. Why does fgetc() return int instead of char?

It must represent every possible character value as well as the special EOF value.

Q4. Does fgets() store the newline character?

Yes, if a newline is encountered before the size limit is reached, it is included in the stored string.

Q5. Does fputs() automatically append a newline?

No. The newline must be included explicitly in the string.

Q6. What is the difference between fgets() and fscanf()?

fgets() reads a bounded sequence of characters, usually a line. fscanf() interprets input according to format specifiers.

Q7. What does fscanf() return?

It returns the number of successfully assigned input items. It may return EOF if input failure occurs before the first conversion completes.

Q8. What is the difference between fprintf() and fputs()?

fprintf() supports formatted output, whereas fputs() writes a string without format conversion.

Q9. How can you detect a file read error?

Use ferror() on the stream after a read operation indicates failure or reaches EOF.

Q10. Why should a width limit be used with %s in fscanf()?

It prevents the input from exceeding the destination array capacity and helps avoid buffer overflow.
