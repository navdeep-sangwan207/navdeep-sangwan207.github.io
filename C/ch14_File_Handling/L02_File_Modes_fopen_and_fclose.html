2. fopen() Function

The fopen() function opens a file and associates it with a stream. It is declared in the <stdio.h> header.

Syntax

FILE *fopen(const char *filename, const char *mode);

Parameters

Parameter Description
filename Name or path of the file to open.
mode Specifies the intended file operation.

Return Value

  • Returns a valid FILE * pointer if successful.
  • Returns NULL if the file cannot be opened.
FILE *fp = fopen("data.txt", "r");

if (fp == NULL)
{
    perror("fopen");
    return 1;
}
Always verify the return value before performing file operations. A failed fopen() must not be followed by operations using the invalid stream pointer.

3. Basic File Opening Modes

The mode string determines whether a file is opened for reading, writing or appending.

3.1 Read Mode – "r"

FILE *fp = fopen("data.txt", "r");
  • Opens an existing file for reading.
  • Fails if the file does not exist or cannot be opened.
  • Does not create a missing file.
  • Does not discard existing contents.

3.2 Write Mode – "w"

FILE *fp = fopen("data.txt", "w");
  • Opens a file for writing.
  • Creates the file if it does not exist.
  • Discards the previous contents if the file already exists.
  • Starts writing from the beginning of the file.
Important: Opening an existing file in "w" mode truncates its contents. Do not use this mode when existing data must be preserved.

3.3 Append Mode – "a"

FILE *fp = fopen("data.txt", "a");
  • Opens a file for writing at the end.
  • Creates the file if it does not exist.
  • Preserves existing contents.
  • Newly written data is appended to the file.

Comparison

Mode File Exists? File Missing? Existing Contents
"r" Opens for reading Fails Preserved
"w" Opens for writing Creates file Discarded
"a" Opens for appending Creates file Preserved

4. Update Modes Using +

The + modifier allows both reading and writing. It is commonly called an update mode.

4.1 Read and Write Mode – "r+"

FILE *fp = fopen("data.txt", "r+");
  • Opens an existing file for both reading and writing.
  • Fails if the file does not exist.
  • Does not truncate the file automatically.
  • The initial file position is at the beginning.

4.2 Write and Read Mode – "w+"

FILE *fp = fopen("data.txt", "w+");
  • Opens a file for both reading and writing.
  • Creates the file if it does not exist.
  • Discards existing contents if the file already exists.
  • The initial file position is at the beginning.

4.3 Append and Read Mode – "a+"

FILE *fp = fopen("data.txt", "a+");
  • Opens a file for both reading and writing.
  • Creates the file if it does not exist.
  • Preserves existing contents.
  • Writes are directed to the end of the file.
  • The initial reading position is at the beginning.
In "a+" mode, reading does not automatically begin at the end. The initial reading position is at the beginning, but writes are forced to the end of the file.

Update Mode Comparison

Mode Must Exist? Truncates? Write Behavior
"r+" Yes No At current file position
"w+" No Yes, if existing At current file position
"a+" No No Always at end

5. Text Mode and Binary Mode

C supports text and binary file streams. The character b in the mode string requests binary mode.

Text Mode Examples

FILE *fp1 = fopen("records.txt", "r");
FILE *fp2 = fopen("records.txt", "w");
FILE *fp3 = fopen("records.txt", "a");

Binary Mode Examples

FILE *fp1 = fopen("records.dat", "rb");
FILE *fp2 = fopen("records.dat", "wb");
FILE *fp3 = fopen("records.dat", "ab");

Common binary modes include:

Mode Purpose
"rb"Read binary data.
"wb"Write binary data.
"ab"Append binary data.
"rb+"Read and write binary data.
"wb+"Write and read binary data, truncating an existing file.
"ab+"Read and append binary data.
The b modifier is relevant on implementations that distinguish text and binary streams. On some systems, such as common Unix-like systems, the distinction has no practical effect on the underlying stream representation.

7. fclose() Function

The fclose() function closes a stream that was previously opened by a file-opening function.

Syntax

int fclose(FILE *stream);

Return Value

Return Value Meaning
0 Stream closed successfully.
EOF An error occurred while closing the stream.

Example

#include <stdio.h>

int main(void)
{
    FILE *fp;

    fp = fopen("sample.txt", "w");

    if (fp == NULL)
    {
        perror("fopen");
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("fclose");
        return 1;
    }

    printf("File closed successfully.\n");

    return 0;
}

Expected Output

File closed successfully.
Important: A stream must not be used again after it has been closed. Calling fclose() again on the same already-closed stream is not valid.

8. Understanding File Truncation

9. Practical Program: Compare Write and Append Modes

This program first writes two lines using "w", then adds another line using "a".

Program

#include <stdio.h>

int main(void)
{
    FILE *fp;

    /* Open in write mode */
    fp = fopen("mode_test.txt", "w");

    if (fp == NULL)
    {
        perror("Write mode");
        return 1;
    }

    if (fputs("First line\n", fp) == EOF ||
        fputs("Second line\n", fp) == EOF)
    {
        fprintf(stderr, "Writing failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Closing after write");
        return 1;
    }

    /* Open in append mode */
    fp = fopen("mode_test.txt", "a");

    if (fp == NULL)
    {
        perror("Append mode");
        return 1;
    }

    if (fputs("Third line\n", fp) == EOF)
    {
        fprintf(stderr, "Appending failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Closing after append");
        return 1;
    }

    printf("Write and append operations completed.\n");

    return 0;
}

Expected Console Output

Write and append operations completed.

Final Contents of mode_test.txt

First line Second line Third line

The first two lines are written using "w". The third line is added using "a", without deleting the previous contents.

10. Practical Program: Read and Update an Existing File

The "r+" mode allows both reading and writing without automatically deleting existing contents.

Program

#include <stdio.h>

int main(void)
{
    FILE *fp;
    char buffer[100];

    /* Create initial file contents */
    fp = fopen("update.txt", "w");

    if (fp == NULL)
    {
        perror("Initial fopen");
        return 1;
    }

    if (fputs("Original content\n", fp) == EOF)
    {
        fprintf(stderr, "Initial write failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Initial fclose");
        return 1;
    }

    /* Reopen in update mode */
    fp = fopen("update.txt", "r+");

    if (fp == NULL)
    {
        perror("Update fopen");
        return 1;
    }

    if (fgets(buffer, sizeof(buffer), fp) != NULL)
    {
        printf("Existing data: %s", buffer);
    }

    /*
       Move to the end before writing.
       This example is intentionally simple;
       file positioning is covered in a later lecture.
    */
    if (fseek(fp, 0L, SEEK_END) != 0)
    {
        fprintf(stderr, "File positioning failed.\n");
        fclose(fp);
        return 1;
    }

    if (fputs("New content\n", fp) == EOF)
    {
        fprintf(stderr, "Update failed.\n");
        fclose(fp);
        return 1;
    }

    if (fclose(fp) == EOF)
    {
        perror("Final fclose");
        return 1;
    }

    return 0;
}

Expected Output

Existing data: Original content

Final Contents of update.txt

Original content New content
Important: In update modes, switching between reading and writing requires attention to the C stream positioning and buffering rules. This example uses fseek() before writing.

11. Switching Between Reading and Writing in Update Modes

When using modes such as "r+", "w+" and "a+", a program may need to alternate between reading and writing.

The C standard imposes sequencing requirements for update streams. In particular:

  • Output must not be followed directly by input without an intervening fflush() or file-positioning operation, as required by the standard.
  • Input must not be followed directly by output unless the input operation encountered end-of-file or an intervening file-positioning operation is performed.

Common positioning functions include:

  • fseek()
  • rewind()
  • fsetpos()
Do not assume that every read/write transition in an update stream is automatically valid. Follow the required sequencing rules. These positioning functions are covered in Lecture 14.5.

12. Common Mistakes and Debugging

Mistake Why It Is a Problem Correct Approach
Using "r" for a missing file. The open operation fails. Create the file first or use an appropriate creation mode.
Using "w" when preserving data is required. Existing contents are discarded. Use an appropriate non-truncating mode.
Using "a" to overwrite existing data. Writes are directed to the end. Choose an appropriate update mode and position the stream correctly.
Ignoring fopen() failure. Subsequent operations may use an invalid stream. Check for NULL.
Ignoring fclose() errors. Buffered output may not have been successfully finalized. Check the return value when reliability matters.
Switching between reading and writing incorrectly. Violates update-stream sequencing requirements. Use the required positioning or flushing operation.

13. Placement-Oriented Interview Questions

Q1. What is the difference between "w" and "a"?

Both can create a missing file. However, "w" truncates an existing file, while "a" preserves existing contents and appends new output.

Q2. What is the difference between "r" and "r+"?

"r" opens an existing file only for reading. "r+" opens an existing file for both reading and writing.

Q3. Does "w+" create a file?

Yes. It creates a missing file and opens it for reading and writing. If the file exists, its previous contents are discarded.

Q4. Does "a+" allow reading?

Yes. It allows reading and writing. However, all writes are directed to the end of the file.

Q5. Which mode is suitable for adding log entries?

"a" is commonly suitable because it preserves previous log entries and appends new ones.

Q6. Which mode opens an existing file without truncating it and permits both reading and writing?

"r+".

Q7. What happens when fopen() fails?

It returns NULL. The program should handle the failure before attempting any stream operation.

Q8. What is the purpose of the b character in a file mode?

It requests binary stream handling, avoiding text-mode translations on implementations that distinguish the two modes.

Q9. What does fclose() return?

It returns zero on success and EOF if an error occurs.

Q10. Can a file be read after opening it with "w"?

No. The "w" mode is for writing only. Use "w+" if both reading and writing are required.

16. Lecture Summary

  • fopen() opens a file and returns a stream pointer.
  • "r" opens an existing file for reading.
  • "w" opens a file for writing and truncates existing contents.
  • "a" opens a file for appending.
  • "r+", "w+" and "a+" support both reading and writing.
  • The "b" modifier requests binary mode.
  • fclose() closes the stream and may report an error.

  • Always check the return values of file operations.
