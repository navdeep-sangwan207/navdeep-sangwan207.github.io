Lecture 04: Binary File Handling

Topic: fread(), fwrite(), binary records and file copying

C Programming | Chapter 14: File Handling

1. Learning Objectives

After completing this lecture, you will be able to:

  • Understand binary files and their applications.
  • Differentiate between text and binary file handling.
  • Use fread() to read binary data.
  • Use fwrite() to write binary data.
  • Read and write arrays and structures using files.
  • Copy binary files using a buffer.
  • Handle partial reads, write failures and file errors.
  • Understand portability problems with raw structure storage.

2. What Is a Binary File?

A binary file stores information as a sequence of bytes representing the data's underlying representation.

Unlike formatted text files, binary files do not require data to be converted into human-readable characters before storage.

Examples of binary files

  • Images and audio files
  • Executable programs
  • Binary databases
  • Application-specific data files
  • Sensor data and recorded measurements

Text File vs Binary File

Text File Binary File
Stores information in a textual representation. Stores information as bytes.
Can generally be inspected using a text editor. May not be human-readable in a text editor.
Often uses formatted functions such as fprintf() and fscanf(). Commonly uses fread() and fwrite().
Numbers may occupy different amounts of space after formatting. Can store the in-memory representation directly.
Text representation can be easier to exchange across platforms. Raw binary representation may depend on the platform.
Important: Binary storage can be compact and efficient, but raw binary data is not automatically portable between different processors, compilers or operating systems.

3. Opening a Binary File

The fopen() function supports binary mode by including the character b in the mode string.

Mode Meaning
"rb" Open an existing binary file for reading.
"wb" Create or truncate a binary file for writing.
"ab" Open or create a binary file for appending.
"rb+" Open an existing binary file for reading and writing.
"wb+" Create or truncate a binary file for reading and writing.
"ab+" Open or create a binary file for reading and appending. 
FILE *fp;

fp = fopen("data.bin", "wb");

if (fp == NULL) {
    printf("Unable to open file.\n");
}

The b mode is particularly important on systems such as Windows, where text and binary streams can behave differently.

4. The fread() Function

The fread() function reads blocks of binary data from a file into memory.

Syntax

size_t fread(
    void *ptr,
    size_t size,
    size_t count,
    FILE *stream
);

Parameters

Parameter Description
ptr Pointer to the destination memory where data is stored.
size Size in bytes of each item to read.
count Maximum number of items to read.
stream File pointer associated with the opened file.

Return Value

fread() returns the number of complete items successfully read.

Interview point: fread() returns the number of complete items, not necessarily the number of bytes. If size is 1, the returned item count is also the number of bytes read.

Example

size_t items_read;

items_read = fread(
    buffer,
    sizeof(int),
    5,
    fp
);

This attempts to read five complete integer items into the memory pointed to by buffer.

If fewer than five complete integers are available, the returned value will be smaller than five. Use feof() and ferror() to determine whether the short read resulted from end-of-file or an error.

5. The fwrite() Function

The fwrite() function writes blocks of binary data from memory into a file.

Syntax

size_t fwrite(
    const void *ptr,
    size_t size,
    size_t count,
    FILE *stream
);

Parameters

Parameter Description
ptr Pointer to the source memory containing the data.
size Size in bytes of each item.
count Number of items to write.
stream File pointer associated with the output file.

Return Value

fwrite() returns the number of complete items successfully written.

size_t items_written;

items_written = fwrite(
    numbers,
    sizeof(int),
    5,
    fp
);

Check whether the returned count matches the requested count. A smaller result indicates that not all requested items were written.

6. Writing and Reading an Integer Array

This program demonstrates writing an integer array to a binary file and reading it back.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

#define COUNT 5

int main(void)
{
    int numbers[COUNT] = {10, 20, 30, 40, 50};
    int result[COUNT] = {0};

    FILE *fp;
    size_t written;
    size_t read_count;

    fp = fopen("numbers.bin", "wb");

    if (fp == NULL) {
        perror("Unable to open file for writing");
        return EXIT_FAILURE;
    }

    written = fwrite(
        numbers,
        sizeof numbers[0],
        COUNT,
        fp
    );

    if (written != COUNT) {
        fprintf(stderr, "Write operation failed.\n");
        fclose(fp);
        return EXIT_FAILURE;
    }

    if (fclose(fp) == EOF) {
        perror("Error closing output file");
        return EXIT_FAILURE;
    }

    fp = fopen("numbers.bin", "rb");

    if (fp == NULL) {
        perror("Unable to open file for reading");
        return EXIT_FAILURE;
    }

    read_count = fread(
        result,
        sizeof result[0],
        COUNT,
        fp
    );

    if (read_count != COUNT) {
        if (ferror(fp)) {
            perror("File read error");
        } else if (feof(fp)) {
            printf("End of file reached.\n");
        }

        fclose(fp);
        return EXIT_FAILURE;
    }

    if (fclose(fp) == EOF) {
        perror("Error closing input file");
        return EXIT_FAILURE;
    }

    printf("Data read from binary file:\n");

    for (size_t i = 0; i < COUNT; i++) {
        printf("%d ", result[i]);
    }

    printf("\n");

    return EXIT_SUCCESS;
}

Expected Output

Data read from binary file:
10 20 30 40 50

Explanation

  1. An integer array is initialized with five values.
  2. The file is opened using binary write mode.
  3. fwrite() stores all five integers in the file.
  4. The file is closed after writing.
  5. The file is reopened using binary read mode.
  6. fread() copies the stored integers into another array.
  7. The resulting array is displayed.
Why use sizeof numbers[0]? It gives the size of one array element. This avoids hardcoding the size of an integer and makes the code easier to maintain.

7. Writing and Reading Structures

Binary file handling can be used to store records represented by C structures.

Consider a student record containing a roll number, name and marks.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

#define COUNT 2

struct Student {
    int roll;
    char name[30];
    float marks;
};

int main(void)
{
    struct Student students[COUNT] = {
        {101, "Aman", 88.5f},
        {102, "Riya", 91.0f}
    };

    struct Student received[COUNT] = {0};

    FILE *fp;
    size_t written;
    size_t read_count;

    fp = fopen("students.bin", "wb");

    if (fp == NULL) {
        perror("File opening failed");
        return EXIT_FAILURE;
    }

    written = fwrite(
        students,
        sizeof students[0],
        COUNT,
        fp
    );

    if (written != COUNT) {
        fprintf(stderr, "Unable to write all records.\n");
        fclose(fp);
        return EXIT_FAILURE;
    }

    if (fclose(fp) == EOF) {
        perror("File closing failed");
        return EXIT_FAILURE;
    }

    fp = fopen("students.bin", "rb");

    if (fp == NULL) {
        perror("File reading failed");
        return EXIT_FAILURE;
    }

    read_count = fread(
        received,
        sizeof received[0],
        COUNT,
        fp
    );

    if (read_count != COUNT) {
        if (ferror(fp)) {
            perror("Read error");
        } else if (feof(fp)) {
            printf("Unexpected end of file.\n");
        }

        fclose(fp);
        return EXIT_FAILURE;
    }

    if (fclose(fp) == EOF) {
        perror("File closing failed");
        return EXIT_FAILURE;
    }

    printf("Student Records:\n");

    for (size_t i = 0; i < COUNT; i++) {
        printf("Roll: %d\n", received[i].roll);
        printf("Name: %s\n", received[i].name);
        printf("Marks: %.2f\n\n", received[i].marks);
    }

    return EXIT_SUCCESS;
}

Expected Output

Student Records:

Roll: 101
Name: Aman
Marks: 88.50

Roll: 102
Name: Riya
Marks: 91.00

How It Works

  • Each student record is represented by a structure.
  • The structure array contains two student records.
  • fwrite() writes the memory representation of each structure.
  • fread() retrieves the stored records into another structure array.
  • The members are accessed using the structure member operator.
Important portability limitation: Writing a structure directly with fwrite() stores its object representation, including any padding bytes. Structure layout, padding, integer sizes, floating-point representation and byte order can differ between systems and compilers. This example is suitable for learning and controlled environments, but it is not a portable file interchange format.

For portable file formats, serialize each field explicitly using defined integer widths, a specified byte order, a defined representation for other values, and a versioning strategy.

8. Understanding the Memory Transfer

Both fread() and fwrite() work with memory addresses and transfer bytes between a file stream and memory.

fwrite() data flow

Memory (Array / Structure)
           |
           | fwrite()
           v
      Binary File

fread() data flow

      Binary File
           |
           | fread()
           v
Memory (Array / Structure)

The functions do not understand the logical meaning of a structure member or array element. They transfer the requested number of bytes.

Never assume that writing a pointer variable also saves the memory it points to. Pointer values are addresses meaningful within a particular process and execution environment. Persist the pointed-to data separately instead.

9. Copying a Binary File

A common practical application of fread() and fwrite() is copying a binary file. A buffer is used to transfer data in manageable blocks.

Complete C Program

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *src;
    FILE *dst;

    unsigned char buffer[4096];
    size_t n;
    int status = EXIT_SUCCESS;

    src = fopen("source.bin", "rb");

    if (src == NULL) {
        perror("Unable to open source file");
        return EXIT_FAILURE;
    }

    dst = fopen("copy.bin", "wb");

    if (dst == NULL) {
        perror("Unable to open destination file");
        fclose(src);
        return EXIT_FAILURE;
    }

    while ((n = fread(buffer, 1, sizeof buffer, src)) > 0) {

        if (fwrite(buffer, 1, n, dst) != n) {
            perror("Write error");
            status = EXIT_FAILURE;
            break;
        }
    }

    if (ferror(src)) {
        perror("Read error");
        status = EXIT_FAILURE;
    }

    if (fclose(src) == EOF) {
        perror("Source close error");
        status = EXIT_FAILURE;
    }

    if (fclose(dst) == EOF) {
        perror("Destination close error");
        status = EXIT_FAILURE;
    }

    if (status == EXIT_SUCCESS) {
        printf("Binary file copied successfully.\n");
    }

    return status;
}

Expected Output

Binary file copied successfully.

This output assumes source.bin exists, the program has permission to read it, and the destination can be written successfully.

Explanation

  1. source.bin is opened in binary read mode.
  2. copy.bin is opened in binary write mode.
  3. fread() reads up to 4096 bytes into the buffer.
  4. fwrite() writes exactly the number of bytes read.
  5. The loop continues until no more bytes are returned.
  6. ferror() checks whether the source read encountered an error.
  7. Both files are closed, and close failures are checked.
Why use size = 1? The call fread(buffer, 1, sizeof buffer, src) reads individual bytes. Therefore, n represents the exact number of bytes read, which can be passed directly to fwrite().

10. Understanding Item Count vs Byte Count

This distinction is frequently tested in technical interviews.

Example 1: Reading integers

int arr[5];

size_t n = fread(arr, sizeof(int), 5, fp);

Here, n represents the number of complete integers read, not the number of bytes.

Example 2: Reading bytes

char buffer[100];

size_t n = fread(buffer, 1, sizeof buffer, fp);

Here, n represents the number of bytes read because each item has a size of one byte.

Expression Return count represents
fread(arr, sizeof(int), 5, fp) Complete integer items
fread(buffer, 1, 100, fp) Bytes
fwrite(arr, sizeof arr[0], 5, fp) Complete array elements written
fwrite(buffer, 1, n, fp) Bytes written

11. Common Mistakes in Binary File Handling

1. Using sizeof(pointer) instead of the data size

int arr[10];
int *ptr = arr;

/* Incorrect when intending to write all 10 integers */
fwrite(ptr, sizeof(ptr), 10, fp);

/* Correct */
fwrite(arr, sizeof arr[0], 10, fp);

sizeof(ptr) gives the size of the pointer itself, not the size of the array.

2. Not checking the return value

if (fwrite(arr, sizeof arr[0], 10, fp) != 10) {
    printf("Write operation failed.\n");
}

Always check whether the requested number of items was successfully written.

3. Assuming fread() always reads the requested count

A file may contain fewer complete items than expected. Check the returned count and inspect feof() or ferror() when appropriate.

4. Using text mode for binary data

Use rb, wb or ab when handling binary streams. Text-mode streams can perform implementation-specific text translations.

5. Assuming fread() adds a null terminator

fread() copies bytes into memory. It does not automatically append '\0' to a character buffer.

6. Assuming raw structures are portable

Raw structure storage can depend on padding, alignment, byte order and type representation.

7. Ignoring close errors

A write failure can become apparent when buffered data is flushed during fclose(). Check its return value when reliable output matters.

12. Placement-Oriented Interview Questions

Q1. What is the purpose of fread()?

Answer: fread() reads a specified number of items from a binary stream into a memory buffer.

Q2. What is the purpose of fwrite()?

Answer: fwrite() writes a specified number of items from memory into a binary stream.

Q3. What does fread() return?

Answer: It returns the number of complete items successfully read.

Q4. Does fread() return the number of bytes read?

Answer: Not necessarily. It returns the number of complete items. When size is 1, the item count equals the byte count.

Q5. What is the difference between feof() and ferror()?

Answer: feof() tests whether the end-of-file indicator is set, while ferror() tests whether the error indicator is set.

Q6. Can structures be written directly to a binary file?

Answer: Yes. fwrite() can write their object representation. However, raw structure files are generally not portable across different ABIs or systems.

Q7. Why is binary file handling useful?

Answer: It can provide efficient storage and transfer of data in a form suitable for arrays, records, images and other binary formats.

Q8. What happens if fread() reads fewer items than requested?

Answer: The returned count is smaller. The caller should use feof() and ferror() to determine whether end-of-file or a read error occurred.

Q9. Does fwrite() automatically save memory pointed to by a pointer?

Answer: No. It writes only the bytes specified by its size and count arguments from the supplied memory region.

Q10. Why should a binary file not be used as a portable structure interchange format?

Answer: Different systems can use different byte orders, type sizes, structure padding, alignment and representations.

gcc -std=c11 -Wall -Wextra -pedantic binary_file.c -o binary_file

Run on Linux or Ubuntu:

./binary_file

Run on Windows Command Prompt:

binary_file.exe
