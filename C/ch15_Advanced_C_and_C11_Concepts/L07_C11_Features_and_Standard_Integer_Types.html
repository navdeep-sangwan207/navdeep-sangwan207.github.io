Lecture 07: C11 Features and Standard Integer Types

Chapter 15 – Advanced C and C11 Concepts

Modern C programming, portable integer types, generic selection, assertions and atomic operations.

2. Introduction to C11

C11 is a major revision of the C programming language standardized as ISO/IEC 9899:2011.

It introduced improvements in type handling, compile-time checking, alignment, generic programming, multithreading support and atomic operations.

Important C11 Features

Feature Purpose
_Static_assert Compile-time condition checking.
_Generic Type-based selection of expressions.
_Alignof Determine type alignment requirements.
_Alignas Request a particular object alignment.
_Atomic and stdatomic.h Atomic objects and operations.
Anonymous structures and unions Direct access to nested members.
_Noreturn Indicate that a function does not return normally.
_Thread_local Provide thread-local storage duration.
Bounds-checking interfaces Optional library facilities with implementation support.
Some C11 facilities are optional or implementation-dependent in availability. Always check the compiler and target platform before relying on them.

3. Standard Integer Types

C provides fundamental integer types with different minimum ranges and implementation-defined sizes.

Type Purpose
char Character storage and small integer values.
short int Short integer type.
int Common integer type.
long int Integer type with at least the range of int.
long long int Extended integer type introduced in C99.
unsigned integer types Nonnegative integer values with defined modular arithmetic.

Example

#include <stdio.h>

int main(void)
{
    printf("char       = %zu bytes\n", sizeof(char));
    printf("short      = %zu bytes\n", sizeof(short));
    printf("int        = %zu bytes\n", sizeof(int));
    printf("long       = %zu bytes\n", sizeof(long));
    printf("long long  = %zu bytes\n", sizeof(long long));

    return 0;
}

The output depends on the implementation. The C standard defines minimum ranges and relationships between integer types, not one universal byte size for every type.

4. Fixed-Width Integer Types – stdint.h

The header stdint.h provides integer type definitions useful when a program requires a particular number of bits.

Important Fixed-Width Types

Type Meaning
int8_t Signed integer with exactly 8 bits, if provided.
uint8_t Unsigned integer with exactly 8 bits, if provided.
int16_t Signed integer with exactly 16 bits, if provided.
uint16_t Unsigned integer with exactly 16 bits, if provided.
int32_t Signed integer with exactly 32 bits, if provided.
uint32_t Unsigned integer with exactly 32 bits, if provided.
int64_t Signed integer with exactly 64 bits, if provided.
uint64_t Unsigned integer with exactly 64 bits, if provided.
Exact-width types such as uint32_t are optional. They are provided when the implementation supports an integer type with exactly the required width and no padding bits.

Example – Fixed-Width Types

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t sensor_value = 200;
    uint16_t adc_value = 1023;
    uint32_t counter = 100000U;
    uint64_t total = 5000000000ULL;

    printf("Sensor = %u\n", (unsigned int)sensor_value);
    printf("ADC = %u\n", (unsigned int)adc_value);
    printf("Counter = %u\n", (unsigned int)counter);
    printf("Total = %llu\n", (unsigned long long)total);

    return 0;
}
Expected Output 
Sensor = 200
ADC = 1023
Counter = 100000
Total = 5000000000

5. Least-Width and Fastest-Width Integer Types

stdint.h also provides integer types that help programmers select a minimum width or a type optimized for performance.

Least-Width Types

int_least8_t
uint_least8_t
int_least16_t
uint_least16_t
int_least32_t
uint_least32_t
int_least64_t
uint_least64_t

These types provide at least the specified number of bits.

Fastest-Width Types

int_fast8_t
uint_fast8_t
int_fast16_t
uint_fast16_t
int_fast32_t
uint_fast32_t
int_fast64_t
uint_fast64_t

These types provide at least the specified width and are selected to support efficient operations on the implementation.

Example

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int_least16_t temperature = 250;
    uint_fast32_t counter = 100000U;

    printf("Temperature = %d\n", (int)temperature);
    printf("Counter = %u\n", (unsigned int)counter);

    return 0;
}
Choose exact-width types for interfaces that require a particular representation. Choose least-width or fast-width types when their portability and performance characteristics better match the application.

UINT32_MAX = 4294967295

7. Portable Integer Input and Output – inttypes.h

Different integer types can have different underlying representations and corresponding printf format requirements.

The inttypes.h header provides format macros for standard fixed-width integer types.

Example

#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void)
{
    int32_t temperature = -25;
    uint32_t counter = 100000U;

    printf("Temperature = %" PRId32 "\n", temperature);
    printf("Counter = %" PRIu32 "\n", counter);

    return 0;
}
Expected Output 
Temperature = -25
Counter = 100000

Useful format macros include:

Macro Purpose
PRId32 Print a signed 32-bit integer.
PRIu32 Print an unsigned 32-bit integer.
PRIx32 Print a 32-bit integer in hexadecimal.
SCNd32 Scan a signed 32-bit integer.
SCNu32 Scan an unsigned 32-bit integer.

8. Boolean Type – _Bool and stdbool.h

C99 introduced the _Bool type. The header stdbool.h provides the convenient Boolean names bool, true and false.

Example

#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    bool is_ready = true;
    bool is_error = false;

    printf("Ready = %d\n", is_ready);
    printf("Error = %d\n", is_error);

    return 0;
}
Expected Output 
Ready = 1
Error = 0

A value assigned to _Bool is converted to zero if it compares equal to zero; otherwise it becomes one.

9. Generic Selection – _Generic

C11 introduced _Generic, which allows an expression to select an association based on its type at compile time.

It provides a form of type-generic programming without requiring runtime type inspection.

Syntax

_Generic(expression,
    type1: expression1,
    type2: expression2,
    default: default_expression
)

Example – Select Based on Type

#include <stdio.h>

#define TYPE_NAME(x) \
    _Generic((x), \
        int: "int", \
        float: "float", \
        double: "double", \
        char: "char", \
        default: "other type")

int main(void)
{
    int a = 10;
    float b = 3.5f;
    double c = 8.25;

    printf("%s\n", TYPE_NAME(a));
    printf("%s\n", TYPE_NAME(b));
    printf("%s\n", TYPE_NAME(c));

    return 0;
}
Expected Output 
int
float
double

Practical Applications

  • Type-specific function selection.
  • Generic utility macros.
  • Compile-time selection of type-dependent expressions.
  • Creating reusable libraries with fewer duplicated interfaces.
_Generic performs compile-time selection. It does not determine the runtime type of an arbitrary object. The controlling expression is not evaluated.

10. Compile-Time Assertions – _Static_assert

C11 introduced _Static_assert to check a condition during translation.

Syntax

_Static_assert(constant_expression, "message");

Example 1 – Validate Integer Width

#include <stdint.h>

_Static_assert(sizeof(uint32_t) * 8 == 32,
               "uint32_t must contain 32 bits");

int main(void)
{
    return 0;
}

If the condition is false, the implementation must issue a diagnostic.

Example 2 – Validate Structure Size

#include <stdint.h>

struct Packet
{
    uint8_t type;
    uint8_t flags;
    uint16_t length;
};

_Static_assert(sizeof(struct Packet) == 4,
               "Unexpected Packet structure size");

int main(void)
{
    return 0;
}

This assertion is appropriate only when the application requires that exact structure layout and the target implementation satisfies it.

_Static_assert is useful for validating assumptions about hardware interfaces, data structures and build configurations. A failed assertion prevents a successful translation.

11. Alignment Features – _Alignof and _Alignas

C11 provides standard alignment facilities for checking and requesting object alignment.

Example – Check Alignment

#include <stdio.h>
#include <stdalign.h>

int main(void)
{
    printf("int alignment = %zu\n", _Alignof(int));
    printf("double alignment = %zu\n", _Alignof(double));

    return 0;
}

Example – Request Alignment

#include <stdio.h>
#include <stdalign.h>

_Alignas(16) unsigned char buffer[64];

int main(void)
{
    printf("Buffer size = %zu\n", sizeof buffer);

    return 0;
}

_Alignas requests a specified alignment for buffer. The implementation must support the requested alignment for the declaration to be valid.

12. Atomic Operations – stdatomic.h

C11 introduced atomic types and operations through the standard header stdatomic.h.

Atomic operations are important when multiple threads access shared data.

Example – Atomic Counter

#include <stdio.h>
#include <stdatomic.h>

int main(void)
{
    atomic_int counter = ATOMIC_VAR_INIT(0);

    atomic_fetch_add(&counter, 5);
    atomic_fetch_add(&counter, 10);

    printf("Counter = %d\n",
           atomic_load(&counter));

    return 0;
}
Expected Output 
Counter = 15

Important Atomic Operations

Operation Purpose
atomic_load() Read an atomic object.
atomic_store() Write an atomic object.
atomic_fetch_add() Add a value and return the previous value.
atomic_fetch_sub() Subtract a value and return the previous value.
atomic_exchange() Replace a value and return the previous value.
atomic_compare_exchange_strong() Compare and conditionally replace an atomic value.
C11 atomic and thread facilities are optional in some implementations. Embedded compilers may have target-specific limitations. Verify support before using them.

13. Thread-Local Storage – _Thread_local

C11 introduced _Thread_local storage duration. Each thread receives its own instance of a thread-local object.

Example

#include <stdio.h>

_Thread_local int thread_counter = 0;

int main(void)
{
    thread_counter++;

    printf("Counter = %d\n", thread_counter);

    return 0;
}
Expected Output 
Counter = 1

This single-threaded example demonstrates the declaration. The per-thread behavior becomes relevant when the program uses multiple threads.

14. Anonymous Structures and Unions

C11 supports anonymous structures and unions as members of structures and unions.

Example

#include <stdio.h>

struct Device
{
    int id;

    union
    {
        unsigned int status;
        unsigned int control;
    };
};

int main(void)
{
    struct Device device;

    device.id = 1;
    device.status = 0x10U;

    printf("ID = %d\n", device.id);
    printf("Status = %X\n", device.status);

    return 0;
}
Expected Output 
ID = 1
Status = 10

The anonymous union allows direct access to its members through the containing structure.

15. Noreturn Function Specifier

C11 introduced _Noreturn to indicate that a function does not return to its caller.

Example

#include <stdio.h>
#include <stdlib.h>

_Noreturn void fatal_error(void)
{
    printf("Fatal error\n");
    exit(EXIT_FAILURE);
}

int main(void)
{
    fatal_error();
}
Expected Output 
Fatal error

C11 also provides the noreturn macro through stdnoreturn.h. In later C standards, the language spelling and header status differ, so this example is specifically for C11.

16. Optional C11 Features and Portability

Not every C11 feature is mandatory on every implementation. In particular, the C11 threads library and some atomic capabilities may be unavailable on a given target.

Check Compiler Support

#include <stdio.h>

int main(void)
{
#ifdef __STDC_VERSION__
    printf("C standard version: %ld\n",
           (long)__STDC_VERSION__);
#else
    printf("C standard version macro unavailable\n");
#endif

    return 0;
}

When compiling in C11 mode, a conforming implementation that defines this macro reports the value 201112L.

Compile in C11 Mode

gcc -std=c11 -Wall -Wextra -Wpedantic program.c -o program

Compiler support and available library facilities should be checked for the actual compiler version and target.

17. Applications in Embedded Systems

C11 features and standard integer types are useful in embedded software where precise data representation, predictable interfaces and memory control are important.

Feature Embedded Application
uint8_t Byte-oriented data and peripheral values.
uint16_t ADC samples and 16-bit data fields.
uint32_t 32-bit counters and register values.
_Static_assert Compile-time validation of structure assumptions.
_Alignas Alignment-sensitive buffers.
volatile Memory-mapped peripheral access.
Atomics Atomic shared data operations where supported.
_Generic Type-specific reusable utility macros.

18. Placement-Oriented Interview Questions

Q1. What is C11?

Answer: C11 is the ISO C language revision published in 2011.

Q2. What is stdint.h?

Answer: It provides integer type definitions such as uint8_t, int32_t and uint64_t when supported.

Q3. What is the difference between uint32_t and unsigned int?

Answer: uint32_t, when provided, is an unsigned integer type with exactly 32 bits. unsigned int has an implementation-dependent width subject to standard minimum requirements.

Q4. What is _Generic?

Answer: It is a C11 feature that selects an expression based on the type of a controlling expression at compile time.

Q5. What is _Static_assert?

Answer: It checks a constant expression during translation and requires a diagnostic if the condition is false.

Q6. What is _Alignof?

Answer: It determines the alignment requirement of a type.

Q7. What is _Alignas?

Answer: It requests a particular alignment for an object or member declaration.

Q8. What is the purpose of stdatomic.h?

Answer: It provides atomic types and operations for safe atomic access and synchronization under the C memory model.

Q9. What is the difference between int_least32_t and int_fast32_t?

Answer: int_least32_t provides at least 32 bits. int_fast32_t provides at least 32 bits using a type selected for efficient operations.

Q10. What is _Thread_local?

Answer: It specifies thread-local storage duration, giving each thread its own instance of an object.

Q11. Is uint32_t available on every C implementation?

Answer: No. Exact-width integer typedefs are optional and are provided when the implementation supports the required type.

Q12. What is the purpose of inttypes.h?

Answer: It provides portable format macros for printing and scanning standard fixed-width integer types.

19. Practical Lab Exercise

Objective

Use C11 fixed-width integer types, Boolean variables, generic selection, compile-time assertions and atomic operations in one program.

Complete C11 Program

#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <inttypes.h>
#include <stdatomic.h>

_Static_assert(sizeof(uint32_t) * 8 == 32,
               "A 32-bit unsigned type is required");

#define TYPE_NAME(x) \
    _Generic((x), \
        int: "int", \
        float: "float", \
        double: "double", \
        default: "other")

int main(void)
{
    uint8_t sensor_value = 150;
    uint16_t adc_value = 1023;
    uint32_t counter = 50000U;

    bool device_ready = true;

    atomic_int event_count = ATOMIC_VAR_INIT(0);

    atomic_fetch_add(&event_count, 1);
    atomic_fetch_add(&event_count, 1);

    printf("Sensor = %u\n", (unsigned int)sensor_value);

    printf("ADC = %u\n", (unsigned int)adc_value);

    printf("Counter = %" PRIu32 "\n", counter);

    printf("Device ready = %d\n", device_ready);

    printf("Type of counter = %s\n", TYPE_NAME(counter));

    printf("Atomic events = %d\n",
           atomic_load(&event_count));

    return 0;
}

Compile

gcc -std=c11 -Wall -Wextra -Wpedantic c11_lab.c -o c11_lab

Run

./c11_lab
Expected Output 
Sensor = 150
ADC = 1023
Counter = 50000
Device ready = 1
Type of counter = other
Atomic events = 2

Lab Observations

  1. Fixed-width integer types express data-width requirements.
  2. Boolean variables represent true and false states.
  3. _Generic selects an expression based on type.
  4. _Static_assert validates assumptions during translation.
  5. Atomic operations provide atomic access to shared values.
