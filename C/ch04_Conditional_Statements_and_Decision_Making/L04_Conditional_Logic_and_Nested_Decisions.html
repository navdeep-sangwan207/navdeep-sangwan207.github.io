2. Introduction to Conditional Logic

Conditional logic is the process of making a decision based on one or more conditions. Real-world programming problems frequently require multiple requirements to be checked before an operation can be performed.

Examples include:

  • Checking whether a candidate satisfies age and qualification requirements.
  • Validating a login using username and password conditions.
  • Checking whether a number belongs to a particular range.
  • Determining whether a triangle is valid.
  • Checking whether a device should enter a particular operating state.
  • Validating sensor readings before performing an operation.
Key Concept: A compound condition combines two or more individual conditions into one logical expression.

3. Logical Operators Used in Decision-Making

C provides three logical operators: AND, OR and NOT. They operate on scalar expressions and produce an integer result of either 0 or 1.

Operator Name Meaning
&& Logical AND True only when both operands are true.
|| Logical OR True when at least one operand is true.
! Logical NOT Reverses the truth value of its operand.

Truth Table

A B A && B A || B
0 0 0 0
0 1 0 1
1 0 0 1
1 1 1 1

NOT Operator

A !A
0 1
1 0

Example

#include <stdio.h>

int main(void)
{
    int age = 22;
    int qualification = 1;

    if (age >= 18 && qualification == 1)
    {
        printf("Requirements satisfied.\n");
    }
    else
    {
        printf("Requirements not satisfied.\n");
    }

    return 0;
}
Expected Output: 
Requirements satisfied.

Both conditions must be true because the logical AND operator is used.

4. Combining Conditions Using AND

Use logical AND when all specified requirements must be satisfied.

Example: Employee Eligibility

An employee is eligible for a particular role when age is at least 21 and experience is at least 2 years. 

#include <stdio.h>

int main(void)
{
    int age = 25;
    int experience = 3;

    if (age >= 21 && experience >= 2)
    {
        printf("Eligible for the role.\n");
    }
    else
    {
        printf("Not eligible for the role.\n");
    }

    return 0;
}
Expected Output: 
Eligible for the role.

When Both Conditions Must Be True

Age Condition Experience Condition Result
True True Eligible
True False Not eligible
False True Not eligible
False False Not eligible

5. Combining Conditions Using OR

Use logical OR when at least one of the specified conditions must be true.

Example: Discount Eligibility

A customer receives a discount if the purchase amount is at least 5000 or the customer has a membership card. 

#include <stdio.h>

int main(void)
{
    int amount = 3000;
    int membership = 1;

    if (amount >= 5000 || membership == 1)
    {
        printf("Discount applicable.\n");
    }
    else
    {
        printf("No discount.\n");
    }

    return 0;
}
Expected Output: 
Discount applicable.

The purchase amount does not meet the threshold, but the membership condition is true. Therefore, the complete OR expression is true.

6. Combining AND, OR and NOT

Complex decision-making often requires more than one logical operator in the same expression.

Example: Access Control

Access is permitted when a user is an administrator, or when the user is an employee with an active account. 

#include <stdio.h>

int main(void)
{
    int is_admin = 0;
    int is_employee = 1;
    int account_active = 1;

    if (is_admin || (is_employee && account_active))
    {
        printf("Access permitted.\n");
    }
    else
    {
        printf("Access denied.\n");
    }

    return 0;
}
Expected Output: 
Access permitted.

The employee and active-account conditions are combined using AND. The resulting condition is combined with the administrator condition using OR.

Example Using NOT

#include <stdio.h>

int main(void)
{
    int system_error = 0;

    if (!system_error)
    {
        printf("System operating normally.\n");
    }
    else
    {
        printf("System error detected.\n");
    }

    return 0;
}
Expected Output: 
System operating normally.

7. Operator Precedence in Conditional Logic

When multiple operators appear in one expression, C follows operator precedence rules.

Important precedence order:

Operator Purpose Relative Precedence
! Logical NOT Higher
<, <=, >, >= Relational comparison Below !
==, != Equality comparison Below relational operators
&& Logical AND Below equality operators
|| Logical OR Below logical AND

Example

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 5;
    int c = 20;

    if (a > b && b < c)
    {
        printf("Condition is true.\n");
    }

    return 0;
}
Expected Output: 
Condition is true.
Best Practice: Use parentheses to make complex conditions easier to understand, even when the precedence rules already determine the result.

8. Short-Circuit Evaluation

Short-circuit evaluation means that C may skip evaluating the second operand of a logical expression when the first operand already determines the result.

Logical AND (&&)

If the first operand is false, the complete AND expression is false. The second operand is not evaluated. 

#include <stdio.h>

int main(void)
{
    int x = 0;
    int y = 10;

    if (x != 0 && y / x > 2)
    {
        printf("Condition true.\n");
    }
    else
    {
        printf("Condition false.\n");
    }

    return 0;
}
Expected Output: 
Condition false.

The first condition is false. Therefore, the second operand is not evaluated, avoiding division by zero.

Logical OR (||)

If the first operand is true, the complete OR expression is true. The second operand is not evaluated. 

#include <stdio.h>

int main(void)
{
    int x = 5;
    int y = 0;

    if (x > 0 || 10 / y > 1)
    {
        printf("Condition true.\n");
    }

    return 0;
}
Expected Output: 
Condition true.

Since the first operand is true, the second operand is not evaluated.

Important: Do not rely on short-circuit behavior to justify unsafe expressions in unrelated contexts. In these examples, the logical operators guarantee that the dangerous second operand is skipped.

9. Nested Decisions vs Compound Conditions

The same logical requirement can sometimes be implemented using either nested if statements or a compound condition.

Using Nested if

#include <stdio.h>

int main(void)
{
    int age = 24;
    int has_license = 1;

    if (age >= 18)
    {
        if (has_license == 1)
        {
            printf("Allowed to drive.\n");
        }
    }

    return 0;
}

Using Compound Condition

#include <stdio.h>

int main(void)
{
    int age = 24;
    int has_license = 1;

    if (age >= 18 && has_license == 1)
    {
        printf("Allowed to drive.\n");
    }

    return 0;
}

Both programs produce:

Allowed to drive.
Nested if Compound Condition
Separates dependent decisions into different blocks. Combines requirements into one logical expression.
Useful when different actions are required at each level. Useful when all conditions lead to the same action.
Can make deep decision structures harder to read. Can become difficult to read if the expression is too long.

10. Range Checking and Boundary Conditions

Range checking verifies whether a value falls within a specified lower and upper limit.

Example: Check Whether a Number Is Between 10 and 50

#include <stdio.h>

int main(void)
{
    int number = 30;

    if (number >= 10 && number <= 50)
    {
        printf("Number is within the range.\n");
    }
    else
    {
        printf("Number is outside the range.\n");
    }

    return 0;
}
Expected Output: 
Number is within the range.

Boundary Testing

Input Expected Result
9 Outside range
10 Within range
30 Within range
50 Within range
51 Outside range
Common Mistake: Writing number >= 10 || number <= 50 for an inclusive range. That condition is true for every integer because at least one side is always true. Use AND for a value that must satisfy both limits.

11. Practical Programming Examples

Program 1: Validate Triangle Using Three Sides

Three positive side lengths form a valid triangle when the sum of any two sides is greater than the third side. 

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 6;
    int c = 7;

    if (a > 0 && b > 0 && c > 0 &&
        a + b > c && a + c > b && b + c > a)
    {
        printf("Valid triangle.\n");
    }
    else
    {
        printf("Invalid triangle.\n");
    }

    return 0;
}
Expected Output: 
Valid triangle.

Every side must be positive and all three triangle inequalities must be satisfied.

Program 2: Classify a Valid Triangle

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 5;
    int c = 8;

    if (a <= 0 || b <= 0 || c <= 0 ||
        a + b <= c || a + c <= b || b + c <= a)
    {
        printf("Invalid triangle.\n");
    }
    else if (a == b && b == c)
    {
        printf("Equilateral triangle.\n");
    }
    else if (a == b || b == c || a == c)
    {
        printf("Isosceles triangle.\n");
    }
    else
    {
        printf("Scalene triangle.\n");
    }

    return 0;
}
Expected Output: 
Isosceles triangle.

Program 3: Check Whether a Number Lies Outside a Range

#include <stdio.h>

int main(void)
{
    int temperature = 65;

    if (temperature < 20 || temperature > 40)
    {
        printf("Temperature outside normal range.\n");
    }
    else
    {
        printf("Temperature within normal range.\n");
    }

    return 0;
}
Expected Output: 
Temperature outside normal range.

Program 4: Check Multiple Admission Requirements

A candidate must score at least 60 in mathematics and at least 50 in programming. The combined score must be at least 120. 

#include <stdio.h>

int main(void)
{
    int mathematics = 70;
    int programming = 65;

    int total = mathematics + programming;

    if (mathematics >= 60 &&
        programming >= 50 &&
        total >= 120)
    {
        printf("Admission criteria satisfied.\n");
    }
    else
    {
        printf("Admission criteria not satisfied.\n");
    }

    return 0;
}
Expected Output: 
Admission criteria satisfied.

Program 5: Determine the Sign and Divisibility of a Number

#include <stdio.h>

int main(void)
{
    int number = -15;

    if (number == 0)
    {
        printf("Number is zero.\n");
    }
    else if (number > 0 && number % 2 == 0)
    {
        printf("Positive even number.\n");
    }
    else if (number > 0 && number % 2 != 0)
    {
        printf("Positive odd number.\n");
    }
    else if (number < 0 && number % 2 == 0)
    {
        printf("Negative even number.\n");
    }
    else
    {
        printf("Negative odd number.\n");
    }

    return 0;
}
Expected Output: 
Negative odd number.

12. Embedded Systems Application: Sensor Threshold Logic

Embedded applications frequently use multiple conditions to decide how a system should respond to sensor readings.

Consider a simplified temperature-monitoring system:

  • Below 20°C: low-temperature warning.
  • 20°C to 40°C: normal operating range.
  • Above 40°C: high-temperature warning.
#include <stdio.h>

int main(void)
{
    int temperature = 45;
    int sensor_valid = 1;

    if (!sensor_valid)
    {
        printf("Sensor fault.\n");
    }
    else if (temperature < 20)
    {
        printf("Low temperature warning.\n");
    }
    else if (temperature <= 40)
    {
        printf("Temperature normal.\n");
    }
    else
    {
        printf("High temperature warning.\n");
    }

    return 0;
}
Expected Output: 
High temperature warning.

The sensor-validity condition is checked first. Invalid sensor data is handled before the temperature value is used to determine the operating state.

Embedded Systems Connection: The same conditional design principles are used in battery monitoring, motor protection, over-temperature shutdown, voltage monitoring and fault detection.

13. Common Logical Programming Errors

1. Using OR Instead of AND for a Range

if (number >= 10 || number <= 50)

This does not correctly check whether a number is between 10 and 50. Use AND to require both boundaries.

2. Incorrect Negation

if (!a == b)

This is not the same as a != b. The NOT operator applies to a before the equality comparison. Write the intended comparison explicitly.

3. Missing Parentheses

if (is_admin || is_employee && active)

Although AND has higher precedence than OR, writing is_admin || (is_employee && active) makes the intended logic clearer.

4. Incorrect Boundary Operator

Use greater-than-or-equal-to when the lower boundary is included. Use strict greater-than when it is excluded.

5. Confusing Logical and Bitwise Operators

&& and || are logical operators. & and | are bitwise operators. They are not interchangeable.

6. Assuming Both Operands Always Execute

Logical AND and OR use short-circuit evaluation. The second operand may not execute.

7. Writing Overly Complex Conditions

Long conditions can be difficult to verify. Break complicated requirements into meaningful intermediate variables or nested decisions.

14. Output Prediction Problems

Problem 1: Logical AND and OR

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 10;
    int c = 15;

    if (a < b && b < c)
    {
        printf("A\n");
    }

    if (a > b || b < c)
    {
        printf("B\n");
    }

    return 0;
}

Expected Output:

A
B

Problem 2: Short-Circuit AND

#include <stdio.h>

int main(void)
{
    int x = 0;
    int result = x && (10 / x);

    printf("%d\n", result);

    return 0;
}

Expected Output:

0

Since x is zero, the second operand is not evaluated.

Problem 3: Short-Circuit OR

#include <stdio.h>

int main(void)
{
    int x = 1;
    int result = x || (10 / 0);

    printf("%d\n", result);

    return 0;
}

Expected Output:

1

The first operand is true, so the second operand is not evaluated. Therefore, division by zero does not occur.

Problem 4: Compound Condition

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;

    if (a > 5 && b < 15 || a == 10)
    {
        printf("Accepted\n");
    }
    else
    {
        printf("Rejected\n");
    }

    return 0;
}

Expected Output:

Accepted

The AND expression is evaluated before OR. The final equality condition is true, so the complete expression evaluates to true.

15. Technical Interview Questions and Answers

Q1. What is a compound condition?

It is a logical expression that combines multiple conditions using operators such as AND, OR and NOT.

Q2. What is the difference between logical AND and logical OR?

AND is true only when both operands are true. OR is true when at least one operand is true.

Q3. What is short-circuit evaluation?

It is the evaluation behavior in which the second operand of a logical AND or OR expression is skipped when the first operand determines the final result.

Q4. Which operator has higher precedence: AND or OR?

Logical AND has higher precedence than logical OR.

Q5. How do you check whether a value lies within a range?

Use two comparisons joined by logical AND, such as value >= lower && value <= upper.

Q6. Why is short-circuit evaluation important?

It can avoid unnecessary evaluation and protect later expressions from being evaluated when a prerequisite condition is not satisfied.

Q7. What is the difference between nested if and a compound condition?

Nested if uses separate decision blocks. A compound condition combines multiple requirements into one expression.

Q8. Can logical operators be used with integer variables?

Yes. Zero is false and any nonzero value is true. The result of a logical operator is either 0 or 1.

Q9. What is the difference between logical AND and bitwise AND?

Logical AND uses && and produces a Boolean-like result. Bitwise AND uses & and operates on individual bits.

Q10. How would you validate a triangle?

Check that all sides are positive and the sum of every pair of sides is greater than the remaining side.

Q11. Why should complex conditions use parentheses?

Parentheses communicate the intended grouping and make the expression easier to read and maintain.

Q12. What is a boundary-value test?

It tests values at and around the limits of a condition to identify incorrect comparison operators and range errors.
