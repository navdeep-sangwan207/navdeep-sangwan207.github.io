2. Introduction to the Conditional Operator

The conditional operator is a decision-making operator available in C. It is also called the ternary operator because it uses three operands.

Its three components are:

  • A condition to evaluate.
  • An expression selected when the condition is true.
  • An expression selected when the condition is false.

General Syntax

condition ? expression_if_true : expression_if_false;

Execution process:

  1. The condition is evaluated first.
  2. If the condition is true, the expression after ? is evaluated.
  3. If the condition is false, the expression after : is evaluated.
  4. The selected expression provides the result of the conditional expression.
Important: Only one of the second and third operands is evaluated. The unselected operand is not evaluated.

3. Basic Example

Select the greater of two numbers using the ternary operator. 

#include <stdio.h>

int main(void)
{
    int a = 20;
    int b = 15;

    int maximum = (a > b) ? a : b;

    printf("Maximum = %d\n", maximum);

    return 0;
}
Expected Output: 
Maximum = 20

Evaluation:

  • Condition: a > b
  • Since 20 is greater than 15, the condition is true.
  • The expression a is selected.
  • The value 20 is assigned to maximum.

4. Ternary Operator vs if-else

Both approaches can perform simple conditional value selection.

Using if-else

#include <stdio.h>

int main(void)
{
    int number = 7;
    int result;

    if (number % 2 == 0)
    {
        result = 1;
    }
    else
    {
        result = 0;
    }

    printf("Result = %d\n", result);

    return 0;
}

Using Ternary Operator

#include <stdio.h>

int main(void)
{
    int number = 7;

    int result = (number % 2 == 0) ? 1 : 0;

    printf("Result = %d\n", result);

    return 0;
}
Expected Output for Both Programs: 
Result = 0
if-else Ternary Operator
Uses separate statement blocks. Uses one conditional expression.
Suitable for multiple statements and complex logic. Suitable for simple value selection.
Can be easier to read for complex decisions. Can make simple assignments concise.
Does not produce a value as a single conditional expression. Produces a result from the selected operand.
Best Practice: Use the ternary operator when it improves clarity. Prefer if-else when the decision requires multiple actions or complicated branching.

6. Nested Ternary Operators

A ternary operator can be placed inside another ternary operator. This is called a nested ternary expression.

Example: Find the Largest of Three Numbers

#include <stdio.h>

int main(void)
{
    int a = 25;
    int b = 40;
    int c = 30;

    int maximum =
        (a > b)
        ? ((a > c) ? a : c)
        : ((b > c) ? b : c);

    printf("Maximum = %d\n", maximum);

    return 0;
}
Expected Output: 
Maximum = 40

Evaluation:

  1. First, compare a > b.
  2. The condition is false.
  3. Evaluate the false branch: (b > c) ? b : c.
  4. Since 40 is greater than 30, select b.
  5. The final result is 40.

Example: Classify a Number

#include <stdio.h>

int main(void)
{
    int number = 0;

    const char *result =
        (number > 0) ? "Positive" :
        (number < 0) ? "Negative" :
                       "Zero";

    printf("%s\n", result);

    return 0;
}
Expected Output: 
Zero
Readability Warning: Avoid deeply nested ternary expressions. Although they can be valid C, multiple levels of nesting make debugging and maintenance difficult. Use if-else when the logic becomes complicated.

7. Operator Precedence of the Conditional Operator

The conditional operator has a specific position in C operator precedence.

Operator Group Operators Precedence Compared with ?:
Logical AND && Higher
Logical OR || Higher
Conditional ?: Conditional level
Assignment =, +=, -= Lower

The conditional operator has lower precedence than logical OR and higher precedence than assignment operators.

Example: Conditional Operator and Logical OR

#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 1;

    int result = a || b ? 10 : 20;

    printf("%d\n", result);

    return 0;
}
Expected Output: 
10

The expression is grouped as: (a || b) ? 10 : 20. Since the OR expression is true, 10 is selected.

Use Parentheses for Clarity

int result = (a || b) ? 10 : 20;

Explicit parentheses make the intended evaluation easier to understand.

8. Associativity of the Conditional Operator

The conditional operator is right-associative. This means chained conditional expressions are grouped from right to left.

Example

#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 1;
    int c = 0;

    int result = a ? 10 : b ? 20 : 30;

    printf("%d\n", result);

    return 0;
}
Expected Output: 
20

The expression is grouped as:

a ? 10 : (b ? 20 : 30)

Since a is false, the second conditional expression is evaluated. Since b is true, the result is 20.

Interview Point: Do not confuse the right-associativity of ?: with the evaluation of every operand. Only the condition and the selected branch are evaluated.

9. Type Compatibility of Conditional Operands

The second and third operands of a conditional expression determine the type of the resulting expression according to C's type rules.

Example: Integer Result

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;

    int result = (a > b) ? a : b;

    printf("%d\n", result);

    return 0;
}
Expected Output: 
20

Example: Arithmetic Conversion

#include <stdio.h>

int main(void)
{
    int condition = 1;

    double result = condition ? 10 : 5.5;

    printf("%.1f\n", result);

    return 0;
}
Expected Output: 
10.0

The integer and floating-point operands undergo the applicable arithmetic type conversions. The selected result is represented as a double in this example.

Example: Selecting a String Literal

#include <stdio.h>

int main(void)
{
    int condition = 0;

    const char *message =
        condition ? "Success" : "Failure";

    printf("%s\n", message);

    return 0;
}
Expected Output: 
Failure

Both string literals are converted to pointers to characters in this expression. A pointer to const char is used to avoid attempting to modify the string literal.

C Language Detail: In C, unlike C++, the result of a conditional expression is not an lvalue. Therefore, do not use a conditional expression as the left operand of an assignment. 
/* Not valid C */
(condition ? a : b) = 100;

10. Side Effects and Evaluation

The selected operand of a conditional expression may contain an operation that changes a variable. The unselected operand is not evaluated.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int result;

    result = (a > 0) ? a++ : a--;

    printf("Result = %d\n", result);
    printf("a = %d\n", a);

    return 0;
}
Expected Output: 
Result = 5
a = 6

Since the condition is true, only a++ is evaluated. Its original value is selected as the expression result, and a is incremented afterward.

Avoid complicated side effects inside conditional expressions. Keep modifications to variables clear and easy to trace.

11. Common Mistakes

1. Missing the Colon

int result = (a > b) ? a;

The conditional operator requires both the true and false expressions.

2. Using Assignment Instead of Comparison

int result = (a = 10) ? 1 : 0;

This assigns 10 to a. It does not compare a with 10. Use a == 10 when equality testing is intended.

3. Overusing Nested Ternary Operators

Deeply nested expressions can become difficult to read. Use if-else when the decision has many branches.

4. Ignoring Operand Types

The selected operands must be compatible under the conditional operator's C type rules.

5. Assuming Both Branches Execute

Only the selected branch is evaluated. Side effects in the unselected branch do not occur.

6. Assuming the Result Is an Assignable Variable

A conditional expression in C does not produce an assignable lvalue.

13. Technical Interview Questions and Answers

Q1. Why is the conditional operator called ternary?

Because it uses three operands: a condition, a true expression and a false expression.

Q2. What is the syntax of the ternary operator?

condition ? expression1 : expression2.

Q3. What does the conditional operator return?

It provides the value and type determined by the selected operand and the applicable C type-conversion rules.

Q4. Is the ternary operator right-associative?

Yes. Chained conditional expressions group from right to left.

Q5. What is the precedence of the conditional operator?

It has lower precedence than logical OR and higher precedence than assignment operators.

Q6. Are both branches evaluated?

No. Only the selected branch is evaluated.

Q7. Can the ternary operator replace every if-else statement?

No. It is most appropriate for selecting a value or expression result. Multi-statement and complex decisions are generally clearer with if-else.

Q8. Can ternary operators be nested?

Yes. However, excessive nesting reduces readability.

Q9. Can a conditional expression be assigned to a variable?

Yes. Its result can be assigned to a compatible variable.

Q10. Can the result of a conditional expression be used as the left side of assignment in C?

No. The result of the conditional operator is not an lvalue in C.
