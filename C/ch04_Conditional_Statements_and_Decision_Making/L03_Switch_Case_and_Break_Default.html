2. Introduction to switch Statement

The switch statement is a multi-way selection statement in C. It allows a program to select one execution path from several alternatives based on the value of an expression.

Common applications include:

  • Menu-driven programs.
  • Simple calculators.
  • Day and month selection.
  • Command selection.
  • State or mode selection in embedded applications.
  • Handling multiple predefined options.
Key Concept: A switch statement compares the value of its controlling expression against case constant expressions and transfers control to the matching case label.

3. Syntax of switch Statement

switch (expression)
{
    case constant1:
        // Statements
        break;

    case constant2:
        // Statements
        break;

    case constant3:
        // Statements
        break;

    default:
        // Default statements
}

Components of switch

Component Purpose
switch Starts the multi-way selection statement.
Expression Provides the value used for selection.
case Defines a possible matching constant value.
break Terminates the switch statement.
default Provides an alternative when no case matches.

4. How switch Executes

  1. The controlling expression is evaluated once.
  2. Its value is compared with the case constant values.
  3. If a matching case is found, execution starts at that case label.
  4. Statements execute in sequence from that point.
  5. A break exits the switch statement.
  6. If no case matches, execution transfers to default if present.
  7. If no case matches and default is absent, the switch body is skipped.

Example: Select a Number

#include <stdio.h>

int main(void)
{
    int choice = 2;

    switch (choice)
    {
        case 1:
            printf("Selected option 1.\n");
            break;

        case 2:
            printf("Selected option 2.\n");
            break;

        case 3:
            printf("Selected option 3.\n");
            break;

        default:
            printf("Invalid option.\n");
    }

    return 0;
}
Expected Output: 
Selected option 2.

The expression evaluates to 2. Therefore, case 2 executes. The break statement terminates the switch.

5. Case Labels and Constant Expressions

A case label identifies a possible value of the switch controlling expression.

Rules for case labels

  • Case labels must use integer constant expressions.
  • Case values must be unique within the same switch statement.
  • Variables cannot be used directly as case labels.
  • Each case label ends with a colon.
  • Multiple statements can follow a case label.

Valid Example

#include <stdio.h>

#define OPTION 2

int main(void)
{
    int choice = 2;

    switch (choice)
    {
        case 1:
            printf("One\n");
            break;

        case OPTION:
            printf("Two\n");
            break;

        case 3 + 1:
            printf("Four\n");
            break;

        default:
            printf("Other\n");
    }

    return 0;
}
Expected Output: 
Two

The macro OPTION expands to the constant 2. The expression 3 + 1 is also an integer constant expression.

Invalid Example: Variable as Case Label

int choice = 2;
int option = 2;

switch (choice)
{
    case option:
        printf("Selected\n");
        break;
}

This is invalid because a case label requires an integer constant expression. The variable option is not such an expression.

Duplicate Case Values

switch (choice)
{
    case 1:
        printf("First\n");
        break;

    case 1:
        printf("Second\n");
        break;
}

This is invalid because the same case value cannot appear more than once in the same switch statement.

6. break Statement in switch

The break statement terminates the nearest enclosing switch or loop. Inside a switch, it transfers control to the first statement after the switch body.

Example With break

#include <stdio.h>

int main(void)
{
    int choice = 1;

    switch (choice)
    {
        case 1:
            printf("Option 1 selected.\n");
            break;

        case 2:
            printf("Option 2 selected.\n");
            break;

        default:
            printf("Invalid option.\n");
    }

    printf("Switch completed.\n");

    return 0;
}
Expected Output: 
Option 1 selected.
Switch completed.

After printing the first message, break exits the switch. Execution then continues with the final printf statement.

Common Error: Forgetting break can cause execution to continue into subsequent case blocks.

7. Fall-Through Behavior

Fall-through occurs when execution continues from one case into the following case because no break or other control transfer statement stops it.

Example: Missing break

#include <stdio.h>

int main(void)
{
    int choice = 1;

    switch (choice)
    {
        case 1:
            printf("One\n");

        case 2:
            printf("Two\n");

        case 3:
            printf("Three\n");
            break;

        default:
            printf("Other\n");
    }

    return 0;
}
Expected Output: 
One
Two
Three

Execution begins at case 1. Since there is no break, the statements under cases 2 and 3 also execute.

Intentional Fall-Through

Fall-through can be useful when multiple case labels should perform the same operation. 

#include <stdio.h>

int main(void)
{
    int day = 6;

    switch (day)
    {
        case 6:
        case 7:
            printf("Weekend\n");
            break;

        default:
            printf("Weekday\n");
    }

    return 0;
}
Expected Output: 
Weekend

Cases 6 and 7 share the same statements. No code executes between the two labels, so both values reach the Weekend block.

**Important:** Intentional fall-through should be clear to readers. In C11, a comment can document the intention. Do not assume the C23 fallthrough attribute is available when compiling in C11 mode.

8. default Label

The default label provides a branch that executes when none of the case values matches the switch expression.

Example

#include <stdio.h>

int main(void)
{
    int choice = 9;

    switch (choice)
    {
        case 1:
            printf("Add\n");
            break;

        case 2:
            printf("Subtract\n");
            break;

        case 3:
            printf("Multiply\n");
            break;

        default:
            printf("Invalid choice.\n");
    }

    return 0;
}
Expected Output: 
Invalid choice.

The value 9 does not match any case. Therefore, the default block executes.

Rules for default

  • A switch can contain at most one default label.
  • The default label is optional.
  • It can appear before, between or after case labels.
  • It does not require a constant value.
  • A break is commonly used at the end of its block when further fall-through is not intended.

9. Valid switch Expression Types

In C, the controlling expression of a switch must have integer type. This includes integer types and enumeration types after the required integer promotions.

Expression Type Allowed? Explanation
int Yes Integer type.
char Yes Character types undergo integer promotion.
short Yes Integer type subject to integer promotion.
enum Yes Enumeration types are permitted.
float No Floating-point type.
double No Floating-point type.
string / array No Not an integer expression.

Example: switch With char

#include <stdio.h>

int main(void)
{
    char operation = '+';

    switch (operation)
    {
        case '+':
            printf("Addition selected.\n");
            break;

        case '-':
            printf("Subtraction selected.\n");
            break;

        default:
            printf("Unknown operation.\n");
    }

    return 0;
}
Expected Output: 
Addition selected.

Invalid Example: switch With float

float value = 2.5f;

switch (value)
{
    case 2:
        printf("Two\n");
        break;
}

This is not valid C because the controlling expression of switch cannot have floating-point type.

10. switch vs if-else Ladder

Feature switch if-else ladder
Selection Matches an expression against case constants. Evaluates arbitrary scalar conditions.
Expression Integer or enumeration type after promotion. Conditions must be scalar expressions.
Range checking Not directly suited to relational ranges. Can directly check ranges.
Equality matching Designed for constant-value selection. Can compare values using relational operators.
Fall-through Possible if control is not terminated. Does not fall through between branches.
Typical use Menu choices and commands. Grading, eligibility and range-based decisions.
Selection Guideline: Use switch when selecting among discrete constant values. Use if-else when conditions involve ranges, relational comparisons or complex logical expressions.

11. Practical Programming Examples

Program 1: Simple Calculator Using switch

#include <stdio.h>

int main(void)
{
    double a = 20.0;
    double b = 5.0;
    char operation = '*';

    switch (operation)
    {
        case '+':
            printf("Result = %.2f\n", a + b);
            break;

        case '-':
            printf("Result = %.2f\n", a - b);
            break;

        case '*':
            printf("Result = %.2f\n", a * b);
            break;

        case '/':
            if (b != 0.0)
            {
                printf("Result = %.2f\n", a / b);
            }
            else
            {
                printf("Division by zero is not allowed.\n");
            }
            break;

        default:
            printf("Invalid operator.\n");
    }

    return 0;
}
Expected Output: 
Result = 100.00

The switch selects an arithmetic operation. The division case includes an additional condition to prevent division by zero.

Program 3: Menu-Driven Arithmetic Selection

#include <stdio.h>

int main(void)
{
    int choice = 1;
    int a = 15;
    int b = 5;

    printf("1. Addition\n");
    printf("2. Subtraction\n");
    printf("3. Multiplication\n");
    printf("4. Division\n");

    switch (choice)
    {
        case 1:
            printf("Sum = %d\n", a + b);
            break;

        case 2:
            printf("Difference = %d\n", a - b);
            break;

        case 3:
            printf("Product = %d\n", a * b);
            break;

        case 4:
            if (b != 0)
            {
                printf("Quotient = %d\n", a / b);
            }
            else
            {
                printf("Division by zero.\n");
            }
            break;

        default:
            printf("Invalid menu choice.\n");
    }

    return 0;
}
Expected Output: 
1. Addition
2. Subtraction
3. Multiplication
4. Division
Sum = 20

#include <stdio.h>

12. Common switch Programming Errors

1. Forgetting break

Without break, execution can continue into subsequent case blocks. Check whether fall-through is intentional.

2. Using a Variable as a Case Label

Case labels must be integer constant expressions, not ordinary runtime variables.

3. Duplicate Case Values

Two case labels in the same switch cannot have the same value after the required conversions.

4. Using Floating-Point Values

A switch expression cannot have float or double type. Use if-else for floating-point comparisons.

5. Assuming default Is Mandatory

The default label is optional. However, including it is usually good practice for handling unexpected input.

6. Confusing break With Program Termination

A break inside a switch exits the switch, not the entire program. Execution continues with the next statement.

7. Incorrect Case Syntax

A case label must end with a colon, not a semicolon. 

case 1:       // Correct
    printf("One\n");
    break;

14. Technical Interview Questions and Answers

Q1. What is a switch statement in C?

It is a multi-way selection statement that selects a control path based on the value of an integer expression.

Q2. Which data types can be used in a switch expression?

Integer types and enumeration types are permitted. The controlling expression undergoes integer promotion.

Q3. Can float or double be used in switch?

No. The controlling expression must have integer type.

Q4. What is the purpose of break?

It terminates the nearest enclosing switch or loop. In a switch, it prevents unintended execution of subsequent case statements.

Q5. What is fall-through?

It is the continuation of execution into subsequent case blocks when no control transfer statement stops it.

Q6. Is default compulsory?

No. It is optional and handles values that do not match any case label.

Q7. Can default appear before case labels?

Yes. The default label can appear anywhere inside the switch body.

Q8. Can two case labels have the same value?

No. Duplicate case values are not allowed within one switch.

Q9. Can a switch be nested inside another switch?

Yes. A switch statement can appear inside another switch or inside a conditional block.

Q10. Can a switch contain an if-else statement?

Yes. Ordinary statements, including if-else statements, can be placed inside case blocks.

Q11. Can case labels contain expressions?

Yes, provided they are valid integer constant expressions.

Q12. What is the difference between break and return?

Break exits the nearest enclosing loop or switch. Return exits the current function and optionally provides a return value.

Q13. What happens when no case matches and default is absent?

The switch body is skipped and execution continues after the switch statement.

Q14. Can multiple case labels share one block?

Yes. Multiple labels can be placed consecutively before a common statement block.

15. Multiple-Choice Questions

Q1. Which keyword is used to terminate a switch branch?

  • A. stop
  • B. break
  • C. exit
  • D. continue

Answer: B. break

Q2. Which type cannot be used as a switch controlling expression?

  • A. int
  • B. char
  • C. enum
  • D. float

Answer: D. float

Q3. How many default labels are allowed in one switch?

  • A. Zero only
  • B. One
  • C. Two
  • D. Unlimited

Answer: B. One

Q4. What happens when break is omitted?

  • A. Program always terminates.
  • B. Execution continues into subsequent statements.
  • C. A syntax error always occurs.
  • D. The switch is skipped.

Answer: B. Execution continues into subsequent statements.

Q5. Which is a valid case label?

  • A. case variable:
  • B. case 10:
  • C. case 2.5:
  • D. case a > b:

Answer: B. case 10:

17. Lecture Summary

  • switch provides multi-way selection based on an integer expression.
  • Case labels use unique integer constant expressions.
  • break terminates the nearest enclosing switch or loop.
  • Omitting break can cause fall-through.
  • Multiple case labels can share the same statement block.
  • default handles unmatched values and is optional.
  • Floating-point expressions cannot control a switch statement.
  • switch is useful for menu-driven programs and discrete choices.
  • if-else is more suitable for range-based and complex conditions.
