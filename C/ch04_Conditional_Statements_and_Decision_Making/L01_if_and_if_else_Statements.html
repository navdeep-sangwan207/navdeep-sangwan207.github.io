Chapter 4: Conditional Statements and Decision Making

Learn how to control program execution using conditions and basic branching statements in C.

1. Learning Objectives

  • Understand decision-making in programming.

  • Write programs using if and if-else statements.

2. Introduction to Decision Making

A program normally executes statements sequentially, one after another. However, many programming problems require the program to make a decision before executing a particular operation.

Examples of decision-making include:

  • Checking whether a number is positive or negative.
  • Determining whether a number is even or odd.
  • Checking whether a candidate is eligible for a particular requirement.
  • Determining whether a student has passed or failed.
  • Comparing two values to identify the larger value.

C provides conditional statements that allow a program to execute different statements depending on the result of a condition.

Important: A condition is an expression evaluated by the program. Its result determines whether a particular statement or block of statements will execute.

3. How C Evaluates Conditions

In C, an expression evaluating to zero is considered false. Any nonzero value is considered true.

Expression Result Meaning
0 False Condition is not satisfied.
1 True Condition is satisfied.
-5 True Any nonzero value is true.
10 True Any nonzero value is true.
5 > 10 False The comparison evaluates to zero.
10 > 5 True The comparison evaluates to one.

Consider the following example:

#include <stdio.h>

int main(void)
{
    if (5)
    {
        printf("Condition is true.\n");
    }

    if (0)
    {
        printf("This statement will not execute.\n");
    }

    return 0;
}
Expected Output: 
Condition is true.

The first condition contains a nonzero value, so its block executes. The second condition is zero, so its block is skipped.

4. if Statement

The if statement executes a statement or block only when its specified condition evaluates to true.

Syntax

if (condition)
{
    // Statements executed when condition is true
}

Execution Flow

  1. The condition is evaluated.
  2. If the result is nonzero, the if block executes.
  3. If the result is zero, the block is skipped.
  4. Program execution continues after the if statement.

Example: Check Whether a Number Is Positive

#include <stdio.h>

int main(void)
{
    int number = 25;

    if (number > 0)
    {
        printf("The number is positive.\n");
    }

    printf("Program completed.\n");

    return 0;
}
Expected Output: 
The number is positive.
Program completed.

Since 25 is greater than zero, the condition is true and the message inside the if block is displayed.

Example: Check Whether a Number Is Greater Than 100

#include <stdio.h>

int main(void)
{
    int number = 75;

    if (number > 100)
    {
        printf("Number is greater than 100.\n");
    }

    printf("Checking completed.\n");

    return 0;
}
Expected Output: 
Checking completed.

The condition is false, so the message inside the if block is skipped. The statement after the if block still executes.

5. if-else Statement

The if-else statement provides two alternative execution paths. One block executes when the condition is true, while the other executes when it is false.

Syntax

if (condition)
{
    // Executes when condition is true
}
else
{
    // Executes when condition is false
}

Execution Flow

  1. The condition is evaluated.
  2. If true, the if block executes.
  3. If false, the else block executes.
  4. Execution continues after the complete if-else statement.

Example: Even or Odd Number

#include <stdio.h>

int main(void)
{
    int number = 17;

    if (number % 2 == 0)
    {
        printf("Even number.\n");
    }
    else
    {
        printf("Odd number.\n");
    }

    return 0;
}
Expected Output: 
Odd number.

The modulus operator returns the remainder after division. An even integer has a remainder of zero when divided by two. Since 17 % 2 is 1, the else block executes.

Example: Pass or Fail

#include <stdio.h>

int main(void)
{
    int marks = 42;

    if (marks >= 40)
    {
        printf("Result: Pass\n");
    }
    else
    {
        printf("Result: Fail\n");
    }

    return 0;
}
Expected Output: 
Result: Pass

The condition uses the greater-than-or-equal-to operator. Therefore, a mark of exactly 40 also satisfies the condition.

6. Using Relational and Logical Operators in Conditions

Conditions commonly use relational and logical operators. These operators were introduced in Chapter 2. Here, the focus is on applying them to decision-making.

Relational Operators

Operator Meaning Example
> Greater than a > b
< Less than a < b
>= Greater than or equal to a >= b
<= Less than or equal to a <= b
== Equal to a == b
!= Not equal to a != b

Logical Operators

Operator Meaning Example
&& Logical AND a > 0 && b > 0
|| Logical OR a == 0 || b == 0
! Logical NOT !(a > b)

Example: Eligibility Using Multiple Conditions

A candidate is eligible for a particular test if their age is at least 18 and their score is at least 50. 

#include <stdio.h>

int main(void)
{
    int age = 22;
    int score = 65;

    if (age >= 18 && score >= 50)
    {
        printf("Candidate is eligible.\n");
    }
    else
    {
        printf("Candidate is not eligible.\n");
    }

    return 0;
}
Expected Output: 
Candidate is eligible.

The AND operator requires both conditions to be true. If either condition is false, the complete expression is false.

7. Statement Blocks and Braces

A statement block is a group of statements enclosed within curly braces { }. It is treated as one compound statement.

Single Statement Without Braces

if (number > 0)
    printf("Positive\n");

When braces are omitted, only the immediately following statement belongs to the if statement.

Multiple Statements With Braces

if (number > 0)
{
    printf("Positive number\n");
    printf("Number is greater than zero\n");
}
Recommended Practice: Use braces even when the condition controls only one statement. This improves readability and helps prevent accidental logic errors when additional statements are added later.

8. Practical Programming Examples

Program 1: Check Positive, Negative or Zero Using if Statements

#include <stdio.h>

int main(void)
{
    int number = -12;

    if (number > 0)
    {
        printf("Positive number.\n");
    }

    if (number < 0)
    {
        printf("Negative number.\n");
    }

    if (number == 0)
    {
        printf("Zero.\n");
    }

    return 0;
}
Expected Output: 
Negative number.

Each if statement is evaluated independently. Only the condition that matches the value of number executes its corresponding block.

Program 2: Find the Largest of Two Numbers

#include <stdio.h>

int main(void)
{
    int a = 45;
    int b = 72;

    if (a > b)
    {
        printf("%d is larger.\n", a);
    }
    else if (b > a)
    {
        printf("%d is larger.\n", b);
    }
    else
    {
        printf("Both numbers are equal.\n");
    }

    return 0;
}
Expected Output: 
72 is larger.

This example introduces the else-if form. Multiple alternatives and their detailed execution order are covered in Lecture 2.

Program 3: Check Whether a Number Is Within a Range

Check whether an integer is between 10 and 50, including both boundary values. 

#include <stdio.h>

int main(void)
{
    int number = 35;

    if (number >= 10 && number <= 50)
    {
        printf("Number is within the range.\n");
    }
    else
    {
        printf("Number is outside the range.\n");
    }

    return 0;
}
Expected Output: 
Number is within the range.

The range includes 10 and 50 because the conditions use greater-than-or-equal-to and less-than-or-equal-to operators.

9. Basic Introduction to Nested if

A nested if is an if statement placed inside another if or else block. It is useful when a second decision depends on the result of an earlier decision.

Detailed nested if-else structures and else-if ladders are covered in the next lecture.

Example: Check Eligibility in Two Steps

#include <stdio.h>

int main(void)
{
    int age = 22;
    int has_id = 1;

    if (age >= 18)
    {
        if (has_id == 1)
        {
            printf("Entry permitted.\n");
        }
    }

    return 0;
}
Expected Output: 
Entry permitted.

The inner if statement is reached only when the outer condition is true. Both conditions must be satisfied for the message to be displayed.

10. Common Errors in if and if-else Statements

Error 1: Using Assignment Instead of Equality

Incorrect:

int number = 5;

if (number = 10)
{
    printf("Condition is true.\n");
}

The expression number = 10 assigns 10 to number. Its resulting value is nonzero, so the condition is true. This is a valid C expression but is probably not the intended comparison.

Correct:

if (number == 10)
{
    printf("Number is 10.\n");
}

Error 2: Adding a Semicolon After if

Incorrect:

if (number > 0);
{
    printf("Positive number.\n");
}

The semicolon forms an empty if statement. The following block is independent and executes regardless of the condition.

Correct:

if (number > 0)
{
    printf("Positive number.\n");
}

Error 3: Missing Braces for Multiple Statements

Incorrect logic:

if (number > 0)
    printf("Positive\n");
    printf("Valid number\n");

Only the first printf statement belongs to the if. The second printf executes regardless of the condition.

Correct:

if (number > 0)
{
    printf("Positive\n");
    printf("Valid number\n");
}

Error 4: Incorrect Boundary Conditions

If the requirement says a person must be at least 18 years old, the correct comparison is age >= 18, not age > 18.

Error 5: Incorrect Use of Logical Operators

Incorrect range condition:

if (number >= 10 || number <= 50)

This condition is true for every integer because a value cannot simultaneously be less than 10 and greater than 50. Use AND to check whether a value lies inside the range.

Correct:

if (number >= 10 && number <= 50)
Important: Always translate the problem statement into its logical condition carefully. A syntactically valid expression can still implement incorrect program logic.

12. Technical Interview Questions and Answers

Q1. What is a conditional statement in C?

A conditional statement controls program execution by selecting a statement or block based on the result of a condition.

Q2. What is the purpose of the if statement?

It executes a statement or block only when the specified condition evaluates to true.

Q3. What is the difference between if and if-else?

An if statement executes its block only when the condition is true. An if-else statement provides an alternative block that executes when the condition is false.

Q4. How does C interpret true and false?

Zero represents false, while any nonzero value represents true.

Q5. Are braces compulsory in an if statement?

No. Braces can be omitted when the controlled body is a single statement. However, using braces is recommended for readability and to prevent errors.

Q6. Can an if statement exist without an else statement?

Yes. The else part is optional. If the condition is false, the controlled statement is skipped.

Q7. Can an if statement contain another if statement?

Yes. This is called a nested if statement.

Q8. What happens if a semicolon is placed immediately after if(condition)?

The semicolon creates an empty controlled statement. A following block is no longer controlled by that if statement.

Q9. What is the difference between = and ==?

The assignment operator = assigns a value. The equality operator == compares two values.

Q10. Can a nonzero negative number be used as a true condition?

Yes. Any nonzero value, including a negative value, is treated as true.

Q11. Can multiple independent if statements be used in one program?

Yes. Each if statement evaluates its own condition independently.

Q12. What is a compound statement in C?

A compound statement is a group of declarations and statements enclosed within curly braces.

13. Multiple-Choice Questions

Q1. Which value is treated as false in C?

  • A. -1
  • B. 1
  • C. 0
  • D. 10

Answer: C. 0

Q2. Which operator checks equality?

  • A. =
  • B. ==
  • C. !=
  • D. >=

Answer: B. ==

Q3. What happens when an if condition is false and there is no else?

  • A. Program terminates.
  • B. The if block is skipped.
  • C. The condition becomes true.
  • D. A compilation error occurs.

Answer: B. The if block is skipped.

Q4. Which operator checks whether a number is even?

  • A. /
  • B. *
  • C. %
  • D. &&

Answer: C. %

Q5. Which statement is recommended for a block containing multiple statements?

  • A. Use braces.
  • B. Use only commas.
  • C. Use assignment operators.
  • D. Omit the condition.

Answer: A. Use braces.
