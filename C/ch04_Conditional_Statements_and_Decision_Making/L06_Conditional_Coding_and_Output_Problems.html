Chapter 4: Conditional Statements and Decision Making

Apply conditional programming concepts to coding-round problems, debugging tasks and technical interview questions.

1. Learning Objectives

  • Apply if, if-else and else-if logic to programming problems.
  • Choose between nested decisions and compound conditions.
  • Use switch-case for appropriate multi-way selection.
  • Apply the ternary operator for simple value selection.
  • Trace conditional expressions and predict program output.
  • Debug common logical errors.
  • Test boundary values and invalid inputs.
  • Develop a systematic approach to conditional coding problems.

2. Conditional Problem-Solving Approach

Before writing a conditional program, convert the problem statement into clearly defined decision rules.

Recommended Workflow

  1. Identify the input variables.
  2. Identify valid and invalid input ranges.
  3. Extract every decision requirement.
  4. Determine whether conditions must all be true or whether any one is sufficient.
  5. Arrange conditions in a logical order.
  6. Choose the appropriate conditional construct.
  7. Test normal, boundary and invalid cases.
  8. Verify the output for each test case.
Placement Tip: Interviewers often evaluate how you interpret requirements, handle boundary conditions and test edge cases—not just whether the program works for one sample input.

3. Coding Problem 1: Find the Largest of Three Numbers

Write a program to find the largest among three integers. If multiple values are equal and largest, the program should still report the correct maximum. 

#include <stdio.h>

int main(void)
{
    int a, b, c;

    printf("Enter three numbers: ");

    if (scanf("%d %d %d", &a, &b, &c) != 3)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (a >= b && a >= c)
    {
        printf("Largest = %d\n", a);
    }
    else if (b >= a && b >= c)
    {
        printf("Largest = %d\n", b);
    }
    else
    {
        printf("Largest = %d\n", c);
    }

    return 0;
}
Sample Input: 
25 40 30
Expected Output: 
Enter three numbers: Largest = 40

Important Test Cases

Input Expected Largest
10, 20, 30 30
30, 20, 10 30
20, 30, 30 30
-5, -2, -10 -2
10, 10, 10 10

4. Coding Problem 2: Check Leap Year

A year is a leap year when it is divisible by 400, or when it is divisible by 4 but not divisible by 100. 

#include <stdio.h>

int main(void)
{
    int year;

    printf("Enter year: ");

    if (scanf("%d", &year) != 1 || year <= 0)
    {
        printf("Invalid year.\n");
        return 1;
    }

    if (year % 400 == 0 ||
        (year % 4 == 0 && year % 100 != 0))
    {
        printf("Leap year.\n");
    }
    else
    {
        printf("Not a leap year.\n");
    }

    return 0;
}
Sample Input: 
2000
Expected Output: 
Enter year: Leap year.

Boundary and Special Cases

Year Result Reason
2024 Leap year Divisible by 4, not by 100
1900 Not a leap year Divisible by 100 but not by 400
2000 Leap year Divisible by 400
2023 Not a leap year Not divisible by 4

5. Coding Problem 3: Calculate Electricity Bill

Calculate an electricity bill using the following illustrative slab rates:

Consumption Rate
First 100 units ₹1.50 per unit
Next 100 units ₹2.50 per unit
Above 200 units ₹4.00 per unit

The rates are illustrative for this programming exercise, not actual electricity tariff rates. 

#include <stdio.h>

int main(void)
{
    int units;
    double bill;

    printf("Enter electricity units: ");

    if (scanf("%d", &units) != 1 || units < 0)
    {
        printf("Invalid units.\n");
        return 1;
    }

    if (units <= 100)
    {
        bill = units * 1.50;
    }
    else if (units <= 200)
    {
        bill = 100 * 1.50 +
               (units - 100) * 2.50;
    }
    else
    {
        bill = 100 * 1.50 +
               100 * 2.50 +
               (units - 200) * 4.00;
    }

    printf("Electricity bill = %.2f\n", bill);

    return 0;
}
Sample Input: 
250
Expected Output: 
Enter electricity units: Electricity bill = 550.00

Calculation:

  • First 100 units: 100 × 1.50 = 150
  • Next 100 units: 100 × 2.50 = 250
  • Remaining 50 units: 50 × 4.00 = 200
  • Total bill = 150 + 250 + 200 = 600
Correction to verify: The expected output for 250 units is 600.00, not 550.00. Always independently verify arithmetic in coding problems.

6. Coding Problem 4: Calculate Grade Using Marks

Use the following grading criteria:

Marks Grade
90–100 A
80–89 B
70–79 C
60–69 D
40–59 E
Below 40 Fail 
#include <stdio.h>

int main(void)
{
    int marks;

    printf("Enter marks: ");

    if (scanf("%d", &marks) != 1 ||
        marks < 0 || marks > 100)
    {
        printf("Invalid marks.\n");
        return 1;
    }

    if (marks >= 90)
    {
        printf("Grade A\n");
    }
    else if (marks >= 80)
    {
        printf("Grade B\n");
    }
    else if (marks >= 70)
    {
        printf("Grade C\n");
    }
    else if (marks >= 60)
    {
        printf("Grade D\n");
    }
    else if (marks >= 40)
    {
        printf("Grade E\n");
    }
    else
    {
        printf("Fail\n");
    }

    return 0;
}
Sample Input: 
85
Expected Output: 
Enter marks: Grade B

The conditions are arranged from highest to lowest. Once a matching branch executes, the remaining branches are skipped.

7. Coding Problem 5: Menu-Driven Calculator Using switch

Implement a calculator that performs addition, subtraction, multiplication and division based on the selected operator. 

#include <stdio.h>

int main(void)
{
    double a, b;
    char operator;

    printf("Enter expression (example: 10 + 5): ");

    if (scanf("%lf %c %lf", &a, &operator, &b) != 3)
    {
        printf("Invalid input.\n");
        return 1;
    }

    switch (operator)
    {
        case '+':
            printf("Result = %.2f\n", a + b);
            break;

        case '-':
            printf("Result = %.2f\n", a - b);
            break;

        case '*':
            printf("Result = %.2f\n", a * b);
            break;

        case '/':
            if (b != 0.0)
            {
                printf("Result = %.2f\n", a / b);
            }
            else
            {
                printf("Division by zero is not allowed.\n");
            }
            break;

        default:
            printf("Invalid operator.\n");
    }

    return 0;
}
Sample Input: 
10 * 5
Expected Output: 
Enter expression (example: 10 + 5): Result = 50.00

The switch statement selects the arithmetic operation. The division branch uses an additional if statement to prevent division by zero.

8. Coding Problem 6: Validate Three Sides and Classify Triangle

#include <stdio.h>

int main(void)
{
    int a, b, c;

    printf("Enter three sides: ");

    if (scanf("%d %d %d", &a, &b, &c) != 3)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if (a <= 0 || b <= 0 || c <= 0)
    {
        printf("Invalid triangle.\n");
    }
    else if (a + b <= c ||
             a + c <= b ||
             b + c <= a)
    {
        printf("Invalid triangle.\n");
    }
    else if (a == b && b == c)
    {
        printf("Equilateral triangle.\n");
    }
    else if (a == b || b == c || a == c)
    {
        printf("Isosceles triangle.\n");
    }
    else
    {
        printf("Scalene triangle.\n");
    }

    return 0;
}
Sample Input: 
3 4 5
Expected Output: 
Enter three sides: Scalene triangle.

9. Coding Problem 7: Check Whether a Character Is a Vowel

Accept a character and determine whether it is an English alphabetic vowel. Handle uppercase and lowercase letters. 

#include <stdio.h>

int main(void)
{
    char ch;

    printf("Enter a character: ");

    if (scanf(" %c", &ch) != 1)
    {
        printf("Invalid input.\n");
        return 1;
    }

    if ((ch >= 'A' && ch <= 'Z') ||
        (ch >= 'a' && ch <= 'z'))
    {
        if (ch == 'a' || ch == 'e' ||
            ch == 'i' || ch == 'o' || ch == 'u' ||
            ch == 'A' || ch == 'E' ||
            ch == 'I' || ch == 'O' || ch == 'U')
        {
            printf("Vowel.\n");
        }
        else
        {
            printf("Consonant.\n");
        }
    }
    else
    {
        printf("Not an alphabetic character.\n");
    }

    return 0;
}
Sample Input: 
E
Expected Output: 
Enter a character: Vowel.

10. Coding Problem 8: Check Whether a Point Lies in a Quadrant

Given x and y coordinates, determine whether a point lies in one of the four quadrants or on an axis or at the origin. 

#include <stdio.h>

int main(void)
{
    int x, y;

    printf("Enter coordinates: ");

    if (scanf("%d %d", &x, &y) != 2)
    {

    }

    {
        printf("Origin.\n");
    }
    else if (x == 0)
    {
        printf("On Y-axis.\n");
    }
    else if (y == 0)
    {
        printf("On X-axis.\n");
    }
    else if (x > 0 && y > 0)
    {
        printf("First quadrant.\n");
    }
    else if (x < 0 && y > 0)
    {
        printf("Second quadrant.\n");
    }
    else if (x < 0 && y < 0)
    {
        printf("Third quadrant.\n");
    }
    else
    {
        printf("Fourth quadrant.\n");
    }

}

-5 8

11. Output Prediction Practice

Problem 1: Dangling Else Association

#include <stdio.h>

int main(void)
{
    int a = 1;
    int b = 0;

    if (a)
        if (b)
            printf("A\n");
        else
            printf("B\n");

    return 0;
}

Expected Output:

B

The else is associated with the nearest unmatched if.

Problem 2: Assignment in a Condition

#include <stdio.h>

int main(void)
{
    int x = 5;

    if (x = 0)
    {
        printf("True\n");
    }
    else
    {
        printf("False\n");
    }

    printf("%d\n", x);

    return 0;
}

Expected Output:

False
0

The expression assigns zero to x. The resulting value is zero, so the else branch executes. This is valid C but often an unintended bug.

Problem 3: Logical Operator Precedence

#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 1;
    int c = 1;

    if (a || b && c)
    {
        printf("Accepted\n");
    }
    else
    {
        printf("Rejected\n");
    }

    return 0;
}

Expected Output:

Accepted

Logical AND is evaluated before logical OR. The expression is equivalent to a || (b && c).

Problem 4: switch Fall-Through

#include <stdio.h>

int main(void)
{
    int value = 2;

    switch (value)
    {
        case 1:
            printf("One ");
        case 2:
            printf("Two ");
        case 3:
            printf("Three ");
            break;
        default:
            printf("Other");
    }

    return 0;
}

Expected Output:

Two Three

Execution starts at case 2 and continues through case 3 because there is no break after case 2.

Problem 5: Conditional Operator

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 10;

    int result = (a > b) ? a++ : b++;

    printf("%d %d\n", result, b);

    return 0;
}

Expected Output:

10 11

The condition is false, so only b is post-incremented. The expression result is the original value of b.

12. Debugging Exercises

Exercise 1: Incorrect Range Validation

Find and correct the logical error:

if (marks >= 40 || marks <= 100)
{
    printf("Valid marks");
}

Correct condition:

if (marks >= 40 && marks <= 100)
{
    printf("Valid marks");
}

If the requirement is to validate marks from 40 to 100, both conditions must be true.

Exercise 2: Incorrect Division Protection

Find the problem:

if (denominator != 0 || numerator / denominator > 2)
{
    printf("Valid");
}

Correct condition:

if (denominator != 0 && numerator / denominator > 2)
{
    printf("Valid");
}

The AND operator ensures that division is attempted only when the denominator is nonzero.

Exercise 3: Incorrect Grade Boundary

Find the problem:

if (marks > 90)
{
    printf("A");
}
else if (marks > 80)
{
    printf("B");
}

If grade A begins at 90 and grade B begins at 80, use inclusive lower boundaries and validate the maximum marks separately. 

if (marks >= 90)
{
    printf("A");
}
else if (marks >= 80)
{
    printf("B");
}

14. Choosing the Right Conditional Construct

Requirement Recommended Construct
One condition with two possible outcomes if-else
Several mutually exclusive ranges else-if ladder
Different actions based on a discrete integral value switch-case
Several requirements must be satisfied together Compound condition using AND
At least one of several alternatives is sufficient Compound condition using OR
Simple selection between two values Ternary operator
Decisions with dependent stages or separate actions Nested if

16. Technical Interview Questions

Q1. What is the difference between if-else and switch?

if-else supports general Boolean conditions, relational expressions and ranges. switch selects among constant integral or enumeration case values.

Q2. Can switch use a floating-point expression?

No. The controlling expression must have an appropriate integer type after the required integer promotions.

Q3. What happens if break is omitted in a switch case?

Execution continues into subsequent statements and case labels until a break or the end of the switch is reached.

Q4. What is the dangling else problem?

An else is associated with the nearest preceding unmatched if. Braces help make the intended structure explicit.

Q5. Why is boundary testing important?

It detects mistakes such as using greater-than instead of greater-than-or-equal-to.

Q6. Can logical expressions be used directly in if?

Yes. An if statement executes its controlled statement when its expression compares unequal to zero.

Q7. What is short-circuit evaluation?

The second operand of logical AND or OR may be skipped when the first operand determines the result.

Q8. When should you avoid nested ternary operators?

Avoid them when they make the decision logic difficult to read, understand or maintain.

Q9. What is a common logical error in range checking?

Using OR instead of AND when a value must satisfy both the lower and upper boundaries.

Q10. How should you approach an unfamiliar conditional coding problem?

Identify inputs, define decision rules, check boundaries, select the appropriate construct, implement and test normal and exceptional cases.
