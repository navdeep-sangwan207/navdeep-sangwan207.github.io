1. Learning Objectives

  • Understand the concept of nested loops.

2. What Is a Nested Loop?

A nested loop is a loop placed inside the body of another loop. The loop containing another loop is called the outer loop, while the loop inside it is called the inner loop.

General structure:

for (initialization; condition; update)
{
    // Outer loop statements

    for (initialization; condition; update)
    {
        // Inner loop statements
    }
}

For every iteration of the outer loop, the inner loop completes its own execution, unless its execution is interrupted by a control statement.

Important: The inner loop starts again from its initialization whenever execution reaches it during a new outer-loop iteration.

3. Basic Nested Loop Example

Program: Print a 3 × 3 Combination of Values

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 3; i++)
    {
        for (int j = 1; j <= 3; j++)
        {
            printf("i = %d, j = %d\n", i, j);
        }
    }

    return 0;
}
Expected Output: 
i = 1, j = 1
i = 1, j = 2
i = 1, j = 3
i = 2, j = 1
i = 2, j = 2
i = 2, j = 3
i = 3, j = 1
i = 3, j = 2
i = 3, j = 3

Execution explanation:

  1. The outer loop starts with i = 1.
  2. The inner loop runs with j = 1, 2 and 3.
  3. The inner loop terminates when j becomes 4.
  4. The outer loop updates i to 2.
  5. The inner loop starts again from j = 1.
  6. The process repeats until the outer loop terminates.

4. Inner Loop and Outer Loop Relationship

Consider the following code: 

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= 2; j++)
    {
        printf("* ");
    }

    printf("\n");
}
Output: 
* *
* *
* *
* *

The outer loop executes four times. During every outer iteration, the inner loop executes two times. Therefore, the inner loop body executes eight times.

For two independent, fully completed loops with fixed iteration counts:

Total inner-body executions = Outer iterations × Inner iterations per outer iteration.

5. Calculating the Number of Iterations

Example 1: Equal Iteration Counts

for (int i = 1; i <= 5; i++)
{
    for (int j = 1; j <= 5; j++)
    {
        printf("*");
    }
}

Outer loop iterations = 5. Inner loop iterations per outer iteration = 5.

Total executions: 5 × 5 = 25.

Example 2: Different Iteration Counts

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 4; j++)
    {
        printf("%d ", j);
    }
}

Total inner-body executions = 3 × 4 = 12.

Example 3: Variable Inner Loop Count

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= i; j++)
    {
        printf("*");
    }

    printf("\n");
}
Output: 
*
**
***
****

The inner loop executes i times during outer iteration i. Total executions are:

1 + 2 + 3 + 4 = 10.

When the inner-loop limit depends on the outer-loop variable, do not simply multiply the maximum iteration counts. Add the actual number of executions for each outer iteration.

6. Nested Loop Tracing

Consider this program:

#include <stdio.h>

int main(void)

Output:

A trace table makes it easier to follow both loop variables and predict output accurately.

7. Practical Application: Multiplication Tables

Program: Print Tables from 1 to 5

#include <stdio.h>

int main(void)
{
    for (int number = 1; number <= 5; number++)
    {
        printf("\nMultiplication Table of %d\n", number);

        for (int i = 1; i <= 10; i++)
        {
            printf("%d x %d = %d\n",
                   number, i, number * i);
        }
    }

    return 0;
}
Beginning of Expected Output: 
Multiplication Table of 1
1 x 1 = 1
1 x 2 = 2
...
1 x 10 = 10

Multiplication Table of 2
2 x 1 = 2
2 x 2 = 4
...
2 x 10 = 20

The outer loop selects the number whose table is being generated. The inner loop calculates its multiples from 1 to 10.

8. Nested Loops with Two-Dimensional Arrays

Nested loops are commonly used to process two-dimensional arrays because each element is identified by a row index and a column index.

Program: Display a Matrix

#include <stdio.h>

int main(void)
{
    int matrix[2][3] =
    {
        {10, 20, 30},
        {40, 50, 60}
    };

    for (int row = 0; row < 2; row++)
    {
        for (int col = 0; col < 3; col++)
        {
            printf("%d ", matrix[row][col]);
        }

        printf("\n");
    }

    return 0;
}
Output: 
10 20 30
40 50 60

The outer loop traverses rows, while the inner loop traverses columns within each row.

This relationship is important for array traversal, matrix addition, searching and other matrix operations. Detailed array and matrix algorithms are covered in Chapter 7.

9. Three-Level Nested Loops

A loop can contain another loop that itself contains a third loop. This is useful when processing three dimensions or combinations of three variables. 

#include <stdio.h>

int main(void)
{
    int count = 0;

    for (int i = 1; i <= 2; i++)
    {
        for (int j = 1; j <= 2; j++)
        {
            for (int k = 1; k <= 2; k++)
            {
                printf("%d %d %d\n", i, j, k);
                count++;
            }
        }
    }

    printf("Total combinations = %d\n", count);

    return 0;
}
Output: 
1 1 1
1 1 2
1 2 1
1 2 2
2 1 1
2 1 2
2 2 1
2 2 2
Total combinations = 8

Each of the three loops executes two times for every complete combination of the other loop variables. Total combinations = 2 × 2 × 2 = 8.

10. Nested Loops and Time Complexity

Time complexity describes how the number of operations grows as the input size increases.

10.1 Two Independent N-Iteration Loops

for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
    {
        // Constant-time operation
    }
}

The inner operation executes n × n times. Time complexity: O(n²).

10.2 Three Independent N-Iteration Loops

for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
    {
        for (int k = 0; k < n; k++)
        {
            // Constant-time operation
        }
    }
}

The innermost operation executes n³ times. Time complexity: O(n³).

10.3 Dependent Inner Loop

for (int i = 0; i < n; i++)
{
    for (int j = 0; j <= i; j++)
    {
        // Constant-time operation
    }
}

The total number of executions is:

1 + 2 + 3 + ... + n = n(n + 1) / 2.

Time complexity: O(n²).

Interview rule: For independent nested loops, multiply iteration counts. For dependent loops, calculate the total executions by examining how the inner-loop limit changes.

11. Introduction to Loop-Control Statements

Nested-loop behavior can be affected by statements that transfer control within or out of loops.

11.1 break

The break statement immediately terminates the nearest enclosing loop or switch statement. 

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 5; j++)
    {
        if (j == 3)
        {
            break;
        }

        printf("%d ", j);
    }

    printf("\n");
}
Output: 
1 2
1 2
1 2

The break statement terminates only the inner loop. The outer loop continues with its next iteration.

11.2 continue

The continue statement skips the remaining statements in the current iteration of the nearest enclosing loop and proceeds to its next iteration. 

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        if (j == 2)
        {
            continue;
        }

        printf("%d ", j);
    }

    printf("\n");
}
Output: 
1 3
1 3
1 3

Only the current inner-loop iteration is skipped when j equals 2. The inner loop then continues with j equal to 3.

Detailed syntax, execution rules, practical use cases and interview problems for break, continue and goto are covered in Lecture 4.

12. Common Mistakes in Nested Loops

12.1 Incorrect Inner-Loop Initialization

for (int i = 1; i <= 3; i++)
{
    int j = 1;

    for (; j <= 3; j++)
    {
        printf("%d ", j);
    }
}

This example is valid because j is initialized again whenever the outer loop body executes. If the inner-loop control variable is declared outside the outer loop and not reset, later outer iterations may behave differently.

12.2 Incorrect Inner-Loop Update

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j--)
    {
        printf("*");
    }
}

j decreases while the condition requires it to remain less than or equal to 3. The inner loop does not terminate normally.

12.3 Confusing the Loop Variables

Use different variables such as i and j for separate loop levels. This makes tracing easier and reduces accidental changes to the wrong variable.

12.4 Incorrectly Assuming One Inner Execution

The inner loop normally completes all its iterations for each outer-loop iteration. It does not execute only once unless its condition or control flow makes it do so.

13. Interview Questions and Answers

Q1. What is a nested loop?

A loop written inside another loop is called a nested loop.

Q2. How many times does the inner loop execute?

It depends on its condition and update. For a fixed inner-loop count of m and an outer-loop count of n, the inner body executes n × m times.

Q3. Does the inner loop restart for every outer iteration?

Yes, when execution reaches the inner loop again, its initialization expression is evaluated again.

Q4. What is the time complexity of two nested loops?

If both execute n times independently and their body performs constant-time work, the complexity is O(n²).

Q5. What happens when break is used inside an inner loop?

It terminates the nearest enclosing loop, which is the inner loop in this example. The outer loop can continue.

Q6. What happens when continue is used inside an inner loop?

It skips the remaining statements in the current inner-loop iteration and proceeds to the next inner-loop iteration.

Q7. Can different loop types be nested?

Yes. A for loop can contain a while loop, a while loop can contain a do-while loop, and other combinations are also valid.

Q8. Where are nested loops commonly used?

They are used in matrix processing, multi-dimensional arrays, combination generation, table generation and pattern printing.

  3. Display all row and column index combinations for a 3 × 4 grid.
  4. Calculate the sum of all elements in a two-dimensional array.
  5. Count the number of elements in a matrix that are divisible by 5.

Placement practice: For every nested-loop problem, identify the outer and inner loop, write the iteration count for each level, and calculate the total number of executions. Explain the time complexity where applicable.

15. Key Takeaways

  • A nested loop is a loop inside another loop.
  • The inner loop normally completes before the outer loop advances.
  • The inner loop's initialization is evaluated again when it is entered during a new outer iteration.
  • Fixed independent iteration counts can be multiplied to find total executions.
  • Dependent loop limits require a separate iteration count calculation.
  • Nested loops are widely used for matrix and multi-dimensional array processing.
  • Two independent loops of n iterations each commonly produce O(n²) work.
  • break and continue affect the nearest enclosing loop.
