Lecture 4: Break, Continue and Goto

Chapter 5 – Loops and Iteration

Learn how to terminate loops, skip iterations and transfer control to labelled statements in C.

1. Learning Objectives

  • Understand the purpose and syntax of break.
  • Understand how continue changes loop execution.
  • Differentiate break and continue.
  • Apply break and continue in nested loops.
  • Understand goto statements and labels.
  • Recognize appropriate and inappropriate uses of goto.
  • Trace control-transfer statements in interview problems.

2. What Are Loop-Control Statements?

Loop-control statements modify the normal execution flow of loops. Instead of always completing every iteration in sequence, a program can terminate a loop, skip part of an iteration or transfer control elsewhere.

The three statements covered here are:

  • break – terminates the nearest enclosing loop or switch.
  • continue – skips the remaining statements in the current loop iteration.
  • goto – transfers control to a labelled statement in the same function.

3. break Statement

The break statement immediately terminates the nearest enclosing loop or switch statement. Execution continues with the first statement after that construct.

Syntax

break;

Example: Stop Printing at 5

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++)
    {
        if (i == 5)
        {
            break;
        }

        printf("%d ", i);
    }

    printf("\nLoop terminated\n");

    return 0;
}
Expected Output: 
1 2 3 4
Loop terminated

Execution:

  1. The loop begins with i = 1.
  2. Values 1 through 4 are printed.
  3. When i becomes 5, the condition i == 5 is true.
  4. The break statement terminates the loop immediately.
  5. Execution continues after the loop.

4. Practical Application of break

Program: Search for a Number in an Array

When a required element is found, further searching can stop because the result is already known. 

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};
    int key = 30;
    int size = sizeof(arr) / sizeof(arr[0]);
    int found = 0;

    for (int i = 0; i < size; i++)
    {
        if (arr[i] == key)
        {
            found = 1;
            break;
        }
    }

    if (found)
    {
        printf("Element found\n");
    }
    else
    {
        printf("Element not found\n");
    }

    return 0;
}
Output: 
Element found

The loop terminates as soon as the matching element is found. This avoids unnecessary comparisons.

5. continue Statement

The continue statement skips the remaining statements in the current iteration of the nearest enclosing loop.

Control then proceeds according to the loop type:

  • for: the update expression executes, followed by condition checking.
  • while: the condition is checked again.
  • do-while: the condition is checked at the bottom of the loop.

Syntax

continue;

Example: Skip Number 5

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++)
    {
        if (i == 5)
        {
            continue;
        }

        printf("%d ", i);
    }

    printf("\n");

    return 0;
}
Expected Output: 
1 2 3 4 6 7 8 9 10

When i equals 5, the printf statement is skipped. The loop does not terminate; it proceeds with the next iteration.

6. Practical Application of continue

Program: Print Only Odd Numbers

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++)
    {
        if (i % 2 == 0)
        {
            continue;
        }

        printf("%d ", i);
    }

    printf("\n");

    return 0;
}
Output: 
1 3 5 7 9

The condition i % 2 == 0 identifies even numbers. The continue statement skips their printing.

7. break vs continue

Feature break continue
Purpose Terminates the nearest enclosing loop or switch. Skips the rest of the current loop iteration.
Loop execution Stops the selected loop. Continues with the next iteration.
Used in loops Yes Yes
Used in switch Yes No
Effect on nested loops Terminates only the nearest enclosing loop. Skips the current iteration of the nearest enclosing loop.
Remember: break means stop the nearest enclosing loop. continue means skip the current iteration of the nearest enclosing loop.

8. break and continue in Nested Loops

8.1 break in an Inner Loop

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 3; i++)
    {
        for (int j = 1; j <= 5; j++)
        {
            if (j == 3)
            {
                break;
            }

            printf("%d ", j);
        }

        printf("| ");
    }

    return 0;
}
Output: 
1 2 | 1 2 | 1 2 |

The break statement terminates the inner loop each time j reaches 3. The outer loop continues.

8.2 continue in an Inner Loop

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 2; i++)
    {
        for (int j = 1; j <= 4; j++)
        {
            if (j == 2)
            {
                continue;
            }

            printf("%d ", j);
        }

        printf("\n");
    }

    return 0;
}
Output: 
1 3 4
1 3 4

Only the inner-loop iteration where j equals 2 is skipped. All other inner-loop iterations execute.

9. Important continue Behavior in Different Loops

9.1 continue in a for Loop

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        continue;
    }

    printf("%d ", i);
}

When i equals 3, control moves to the update expression i++ and then the condition check.

9.2 continue in a while Loop

int i = 0;

while (i < 5)
{
    i++;

    if (i == 3)
    {
        continue;
    }

    printf("%d ", i);
}
Output: 
1 2 4 5

The increment occurs before continue, so the condition variable still changes. If the increment were placed after continue, this program could become an infinite loop when i equals 3.

9.3 continue in a do-while Loop

#include <stdio.h>

int main(void)
{
    int i = 0;

    do
    {
        i++;

        if (i == 3)
        {
            continue;
        }

        printf("%d ", i);

    } while (i < 5);

    return 0;
}
Output: 
1 2 4 5

In a do-while loop, continue transfers control to the condition check at the end of the loop.

10. goto Statement

The goto statement transfers execution directly to a labelled statement within the same function.

Syntax

goto label;

// Other statements

label:
    statement;

A label is an identifier followed by a colon. It identifies the destination statement.

Example: Transfer Control to a Label

#include <stdio.h>

int main(void)
{
    printf("Statement 1\n");

    goto target;

    printf("Statement 2\n");

target:
    printf("Statement 3\n");

    return 0;
}
Output: 
Statement 1
Statement 3

The goto statement transfers control to target. Statement 2 is skipped.

11. goto and Repetition

A goto statement can create repetition by transferring control to a label earlier in the same function. However, ordinary loops are generally clearer.

Example: Print Numbers Using goto

#include <stdio.h>

int main(void)
{
    int i = 1;

repeat:
    if (i > 5)
    {
        goto end;
    }

    printf("%d ", i);
    i++;

    goto repeat;

end:
    printf("\nCompleted\n");

    return 0;
}
Output: 
1 2 3 4 5
Completed

The program works, but a while or for loop expresses the same repetition more clearly.

12. Appropriate and Inappropriate Uses of goto

Why Excessive goto Is Discouraged

  • It can make control flow difficult to follow.
  • It can create tangled execution paths.
  • It can make debugging and maintenance harder.
  • It can make it difficult to reason about program state.

Limited Use: Shared Error Cleanup

In C, goto can sometimes be useful for handling multiple resource-acquisition failures while ensuring that already-acquired resources are released in the correct order. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *file = NULL;
    int *data = NULL;

    file = fopen("input.txt", "r");

    if (file == NULL)
    {
        goto cleanup;
    }

    data = malloc(10 * sizeof *data);

    if (data == NULL)
    {
        goto cleanup;
    }

    printf("Resources acquired successfully\n");

cleanup:
    free(data);

    if (file != NULL)
    {
        fclose(file);
    }

    return 0;
}

The cleanup label provides one place to release resources. Calling free(NULL) is safe, and the file is closed only if it was successfully opened.

Important: This example illustrates a limited cleanup pattern, not a recommendation to use goto for ordinary repetition or decision-making. Avoid jumps that enter the scope of variably modified objects. Use structured loops and functions where they make the control flow clearer.

13. Output Prediction Problems

Problem 1

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        break;
    }

    printf("%d ", i);
}
Output: 
1 2

Problem 2

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        continue;
    }

    printf("%d ", i);
}
Output: 
1 2 4 5

Problem 3

int i = 1;

while (i <= 5)
{
    if (i == 3)
    {
        i++;
        continue;
    }

    printf("%d ", i);
    i++;
}
Output: 
1 2 4 5

The increment before continue is essential. Without it, i would remain 3 and the loop would never progress beyond that value.

14. Common Programming Mistakes

14.1 Expecting break to Terminate Every Nested Loop

break terminates only the nearest enclosing loop or switch. It does not automatically terminate every outer loop.

14.2 Forgetting an Update Before continue

In a while or do-while loop, skipping an update can cause the loop-control variable to remain unchanged and create an infinite loop.

14.3 Using continue Outside a Loop

continue is valid only within an iteration statement. Using it outside a loop is a compilation error.

14.4 Using break Outside a Loop or switch

break is valid only within a loop or switch statement. Using it elsewhere is a compilation error.

14.5 Using goto to Create Unnecessary Complexity

Prefer loops, conditional statements and functions when they express the intended control flow clearly.

15. Interview Questions and Answers

Q1. What is the difference between break and continue?

break terminates the nearest enclosing loop or switch. continue skips the remaining statements of the current loop iteration.

Q2. Can break be used inside a switch statement?

Yes. It terminates the nearest enclosing switch statement when used within a switch case.

Q3. Can continue be used inside a switch statement?

Not to control the switch itself. It can be used in a switch nested inside a loop, in which case it applies to the nearest enclosing loop.

Q4. Does break terminate all nested loops?

No. It terminates only the nearest enclosing loop.

Q5. Where does continue transfer control in a for loop?

It transfers control to the update expression, followed by condition checking.

Q6. Where does continue transfer control in a while loop?

It transfers control to the condition check.

Q7. Where does continue transfer control in a do-while loop?

It transfers control to the condition check at the end of the loop.

Q8. What is goto in C?

goto transfers control to a labelled statement within the same function.

Q9. Can goto jump to a label in another function?

No. A goto statement can only transfer control to a label within its own function.

Q10. Is goto always prohibited in professional C?

No. Although excessive use is discouraged, limited uses such as shared error cleanup can be appropriate when they improve clarity.

16. Coding Practice Problems

  1. Print numbers from 1 to N and terminate when a specified value is reached using break.
  2. Print all odd numbers from 1 to N using continue.
  3. Search an array and terminate the search when the target is found.
  4. Skip negative values while processing an integer array.
  5. Use break in a nested loop and predict which loop terminates.
  6. Use continue in a nested loop and identify which iteration is skipped.
  7. Write a small goto-based example and rewrite it using a structured loop.
  8. Implement a shared cleanup path for two dynamically allocated resources.
Placement practice: For every problem, identify the nearest enclosing loop, determine where execution resumes and check whether all loop-control variables still progress toward termination.

17. Key Takeaways

  • break terminates the nearest enclosing loop or switch.
  • continue skips the remaining statements in the current loop iteration.
  • continue behaves differently at the control-flow level in for, while and do-while loops.
  • In nested loops, break and continue affect the nearest enclosing loop.
  • goto transfers control to a label within the same function.
  • Excessive goto usage makes programs difficult to maintain.
  • Structured loops and functions are preferred for ordinary program flow.
  • Careful tracing is essential for solving output-prediction questions.
