Chapter 2: Data Types, Variables and Operators

Lecture 3: Type Modifiers, sizeof and Type Ranges

Understand integer type modifiers, memory sizes, minimum type ranges and portable type-limit checking.

1. Learning Objectives

  • Understand signed, unsigned, short and long modifiers.
  • Identify valid combinations of integer type specifiers.
  • Use sizeof to determine object and type sizes.
  • Understand the relationship between sizeof and sizeof(char).
  • Use limits.h to examine integer ranges.
  • Use float.h to examine floating-point characteristics.
  • Understand minimum requirements versus implementation-specific sizes.
  • Write portable programs that inspect data type properties.

2. Why Are Type Modifiers Required?

C provides type modifiers to create different versions of integer types. They influence the minimum range of values that an integer type can represent.

The main integer type modifiers are:

  • signed
  • unsigned
  • short
  • long

Examples

short int small_value;
unsigned int count;
long int population;
long long int large_number;
unsigned long long int file_size;

These declarations specify different integer types. Their exact sizes and ranges depend on the C implementation, subject to the minimum requirements of the language standard.

3. signed and unsigned Modifiers

Signed Integer

A signed integer can represent negative, zero and positive values. 

signed int temperature = -15;
signed int balance = 500;

The keyword signed is optional for ordinary integer types because int is signed by default. 

int a = 100;
signed int b = 100;

Unsigned Integer

An unsigned integer represents only non-negative values. Its arithmetic follows modular arithmetic. 

unsigned int count = 100U;
unsigned long total = 50000UL;

Important Difference

Signed Type Unsigned Type
Represents negative and non-negative values. Represents non-negative values only.
Signed overflow is undefined behavior. Unsigned arithmetic wraps modulo one more than its maximum value.
Example: int value = -10; Example: unsigned int value = 10U;

4. short and long Modifiers

short int

short int is an integer type whose range is at least as wide as the minimum range required by C. 

short int temperature = 25;
short count = 100;

long int

long int provides a range at least as wide as int. 

long int population = 1000000L;
long distance = 250000L;

long long int

long long int was introduced in C99 and provides a wider minimum range than long int. 

long long int large_number = 9000000000LL;

Type Relationship

C guarantees the following ordering of minimum ranges for the standard signed integer types: 

signed char
    <= short int
    <= int
    <= long int
    <= long long int

This expresses the ordering of minimum representable ranges, not necessarily different storage sizes on every implementation.

The sizeof values of two different integer types may be equal. A longer type is not required to use more bytes than every shorter type on every platform.

6. Understanding sizeof Operator

The sizeof operator determines the size in bytes of a type or object.

Syntax

sizeof(type_name)
sizeof expression

Examples

sizeof(int)
sizeof(float)
sizeof(double)
sizeof(char)

The result of sizeof has type size_t, an unsigned integer type defined by the implementation. Use %zu to print it with printf in C99 and later.

Program: Checking Data Type Sizes

#include <stdio.h>

int main(void)
{
    printf("char: %zu bytes\n", sizeof(char));
    printf("short: %zu bytes\n", sizeof(short));
    printf("int: %zu bytes\n", sizeof(int));
    printf("long: %zu bytes\n", sizeof(long));
    printf("long long: %zu bytes\n", sizeof(long long));

    printf("float: %zu bytes\n", sizeof(float));
    printf("double: %zu bytes\n", sizeof(double));
    printf("long double: %zu bytes\n", sizeof(long double));

    return 0;
}

A common output on many modern desktop systems is:

Illustrative Output 
char: 1 bytes
short: 2 bytes
int: 4 bytes
long: 8 bytes
long long: 8 bytes
float: 4 bytes
double: 8 bytes
long double: 16 bytes

These are illustrative values only. Your compiler and target platform may produce different results.

sizeof(char) is always 1. A C byte is the size of a char object and is not necessarily eight bits.

7. sizeof with Variables and Expressions

sizeof can be applied to a variable or an expression. In most cases, the expression is not evaluated.

Example 1: sizeof Variable

#include <stdio.h>

int main(void)
{
    int number = 100;

    printf("Size of number = %zu\n", sizeof number);

    return 0;
}

Example 2: sizeof Expression

#include <stdio.h>

int main(void)
{
    int a = 10;
    double b = 20.5;

    printf("Size of a + b = %zu\n", sizeof(a + b));

    return 0;
}

The type of a + b is double, so the expression has the size of double on that implementation.

An important exception is a variable-length array: sizeof can evaluate its size expression at runtime. This exception is relevant to advanced C topics.

8. sizeof and Array Length

For an actual array object, sizeof returns the total size of the array in bytes.

Example

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    size_t total_size = sizeof numbers;
    size_t element_size = sizeof numbers[0];

    size_t count = total_size / element_size;

    printf("Array size = %zu bytes\n", total_size);
    printf("Element size = %zu bytes\n", element_size);
    printf("Number of elements = %zu\n", count);

    return 0;
}

If int occupies four bytes on the implementation, the output is: 

Array size = 20 bytes
Element size = 4 bytes
Number of elements = 5
This technique works when numbers is an actual array in the current scope. When an array is passed to a function as a parameter, it is adjusted to a pointer. sizeof on that parameter gives the pointer size, not the original array size.

Program: Displaying Integer Limits

#include <stdio.h>
#include <limits.h>

int main(void)
{
    printf("CHAR_BIT = %d\n", CHAR_BIT);

    printf("CHAR_MIN = %d\n", CHAR_MIN);
    printf("CHAR_MAX = %d\n", CHAR_MAX);

    printf("SHRT_MIN = %hd\n", SHRT_MIN);
    printf("SHRT_MAX = %hd\n", SHRT_MAX);
    printf("USHRT_MAX = %hu\n", USHRT_MAX);

    printf("INT_MIN = %d\n", INT_MIN);
    printf("INT_MAX = %d\n", INT_MAX);
    printf("UINT_MAX = %u\n", UINT_MAX);

    printf("LONG_MIN = %ld\n", LONG_MIN);
    printf("LONG_MAX = %ld\n", LONG_MAX);
    printf("ULONG_MAX = %lu\n", ULONG_MAX);

    printf("LLONG_MIN = %lld\n", LLONG_MIN);
    printf("LLONG_MAX = %lld\n", LLONG_MAX);
    printf("ULLONG_MAX = %llu\n", ULLONG_MAX);

    return 0;
}

On a common system with 8-bit bytes and conventional integer widths, some of the output is: 

CHAR_BIT = 8
CHAR_MIN = -128
CHAR_MAX = 127
SHRT_MIN = -32768
SHRT_MAX = 32767
USHRT_MAX = 65535
INT_MIN = -2147483648
INT_MAX = 2147483647
UINT_MAX = 4294967295

The remaining values depend on the implementation. Use the program rather than assuming these limits.

10. Floating-Point Limits Using float.h

The header <float.h> provides macros describing floating-point characteristics.

Important Macros

Macro Meaning
FLT_MINMinimum positive normalized float value.
FLT_MAXMaximum finite float value.
FLT_DIGMinimum decimal digits of precision for float.
FLT_EPSILONDifference between 1.0f and the next greater representable float.
DBL_MINMinimum positive normalized double value.
DBL_MAXMaximum finite double value.
DBL_DIGMinimum decimal digits of precision for double.
DBL_EPSILONDifference between 1.0 and the next greater representable double.
LDBL_MINMinimum positive normalized long double value.
LDBL_MAXMaximum finite long double value.

Program: Displaying Floating-Point Limits

#include <stdio.h>
#include <float.h>

int main(void)
{
    printf("FLT_MIN = %e\n", FLT_MIN);
    printf("FLT_MAX = %e\n", FLT_MAX);
    printf("FLT_DIG = %d\n", FLT_DIG);
    printf("FLT_EPSILON = %e\n", FLT_EPSILON);

    printf("\nDBL_MIN = %e\n", DBL_MIN);
    printf("DBL_MAX = %e\n", DBL_MAX);
    printf("DBL_DIG = %d\n", DBL_DIG);
    printf("DBL_EPSILON = %e\n", DBL_EPSILON);

    printf("\nLDBL_MIN = %Le\n", LDBL_MIN);
    printf("LDBL_MAX = %Le\n", LDBL_MAX);

    return 0;
}

Common IEEE 754 implementations often report approximately: 

FLT_DIG = 6
DBL_DIG = 15

These values are typical, not universal. Check the actual macros on your compiler.

FLT_MIN and DBL_MIN refer to the smallest positive normalized values, not the most negative values. Use the corresponding maximum macros for the largest finite positive values.

11. Difference Between sizeof and limits.h

sizeof limits.h
Determines the size of a type or object in bytes. Defines macros describing integer type limits.
Is a C operator. Is a standard header file.
Returns a value of type size_t. Provides implementation-specific limit macros.
Example: sizeof(int) Example: INT_MAX

12. Integer Range Calculations

For an unsigned integer type with N value bits, the range is: 

0 to (2^N - 1)

For a signed integer type using a conventional two's complement representation with N total bits, the range is: 

-2^(N-1) to (2^(N-1) - 1)

These formulas describe common binary representations. The portable way to obtain actual limits in a C program is to use the macros in limits.h.

Example: 8-Bit Unsigned Integer

Maximum = 2^8 - 1
        = 256 - 1
        = 255

Range = 0 to 255

Example: 8-Bit Two's Complement Signed Integer

Minimum = -2^7 = -128
Maximum =  2^7 - 1 = 127

Range = -128 to 127
Do not use these formulas as universal assumptions about every signed C implementation. C11 permits implementation-defined signed integer representations.

13. Integer Overflow and Unsigned Wraparound

Unsigned Wraparound

Unsigned arithmetic is performed modulo one more than the maximum representable value. 

#include <stdio.h>
#include <limits.h>

int main(void)
{
    unsigned int value = UINT_MAX;

    value = value + 1U;

    printf("%u\n", value);

    return 0;
}
Expected Output 
0

Adding one to UINT_MAX produces zero because unsigned arithmetic wraps modulo UINT_MAX + 1.

Signed Overflow

Signed integer overflow is undefined behavior. A program must not depend on a particular wraparound result. 

#include <stdio.h>
#include <limits.h>

int main(void)
{
    int value = INT_MAX;

    /* Do not execute signed overflow. */

    printf("Maximum int = %d\n", value);

    return 0;
}
Avoid writing INT_MAX + 1 in a signed int expression. It is not a portable way to demonstrate integer wraparound.

14. Portable Type Inspection Program

This program combines sizeof, limits.h and float.h to inspect the characteristics of the target compiler. 

#include <stdio.h>
#include <limits.h>
#include <float.h>

int main(void)
{
    printf("===== TYPE SIZES =====\n");

    printf("char: %zu\n", sizeof(char));
    printf("short: %zu\n", sizeof(short));
    printf("int: %zu\n", sizeof(int));
    printf("long: %zu\n", sizeof(long));
    printf("long long: %zu\n", sizeof(long long));

    printf("float: %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("long double: %zu\n", sizeof(long double));

    printf("\n===== INTEGER LIMITS =====\n");

    printf("CHAR_BIT: %d\n", CHAR_BIT);
    printf("INT_MIN: %d\n", INT_MIN);
    printf("INT_MAX: %d\n", INT_MAX);
    printf("UINT_MAX: %u\n", UINT_MAX);

    printf("LONG_MIN: %ld\n", LONG_MIN);
    printf("LONG_MAX: %ld\n", LONG_MAX);

    printf("\n===== FLOATING-POINT LIMITS =====\n");

    printf("FLT_MAX: %e\n", FLT_MAX);
    printf("DBL_MAX: %e\n", DBL_MAX);
    printf("FLT_DIG: %d\n", FLT_DIG);
    printf("DBL_DIG: %d\n", DBL_DIG);

    return 0;
}

Program Analysis

  • sizeof checks actual object and type sizes.
  • limits.h supplies integer range macros.
  • float.h supplies floating-point characteristics.
  • The program avoids hardcoding platform-specific assumptions.

15. Common Programming Mistakes

Mistake Correction
Assuming int is always 4 bytes. Use sizeof(int) to inspect its size.
Assuming long is always larger than int in bytes. Check sizeof and remember the standard's minimum range requirements.
Using %d to print size_t. Use %zu.
Using INT_MAX to determine unsigned int maximum. Use UINT_MAX.
Assuming float always uses IEEE binary32. Inspect implementation characteristics using float.h.
Assuming signed overflow wraps around. Avoid signed overflow; it is undefined behavior.
Assuming sizeof(char) is 8 bits. Use CHAR_BIT to determine bits per C byte.

16. Technical Interview Questions

Q1. What is the purpose of type modifiers in C?
Type modifiers create variations of integer types with different minimum ranges and representation characteristics.
Q2. What is the difference between short, int and long?
They are integer types with different minimum range requirements. Their exact sizes are implementation-dependent.
Q3. What does sizeof return?
sizeof returns the size of a type or object in bytes. Its result has type size_t.
Q4. Why should %zu be used with sizeof?
sizeof produces a value of type size_t. %zu is the corresponding printf conversion specifier in C99 and later.
Q5. What is the purpose of limits.h?
It defines macros such as INT_MIN, INT_MAX, UINT_MAX and CHAR_BIT to describe integer implementation limits.
Q6. What is the purpose of float.h?
It defines macros describing floating-point ranges, precision and other characteristics.
Q7. What is CHAR_BIT?
CHAR_BIT specifies the number of bits in one C byte, which is the size of a char object.
Q8. Why can sizeof(long) and sizeof(int) be equal?
C specifies minimum ranges and ordering requirements, not a requirement that every successive integer type must occupy more bytes.
Q9. What happens when an unsigned integer exceeds its maximum value?
Its arithmetic result wraps modulo one more than the maximum representable value.
Q10. What happens when a signed integer overflows?
Signed integer overflow results in undefined behavior in C.
Q11. What is the difference between FLT_MIN and FLT_MAX?
FLT_MIN represents the minimum positive normalized float value, whereas FLT_MAX represents the maximum finite positive float value.
Q12. Can sizeof be used to calculate the number of elements in an array?
Yes, for an actual array object in the relevant scope, divide sizeof(array) by sizeof(array[0]). This does not work the same way for an array function parameter because it is adjusted to a pointer.
