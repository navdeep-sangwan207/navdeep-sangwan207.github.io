Lecture 2: Integer, Floating-Point and Character Types

Understand how C represents numeric and character data, including signedness, precision and character encoding.

2. Integer Types in C

Integer types represent whole-number values without a fractional component. C provides several integer types with different minimum ranges and implementation-dependent storage requirements.

Integer Type Family

Type Description
char Smallest addressable character-sized integer type.
short int Short integer type.
int Standard integer type.
long int Long integer type.
long long int Extended integer type introduced in C99.

The keywords signed and unsigned can be used with integer types where permitted. Integer type modifiers and their ranges are examined in detail in Lecture 3.

Example

#include <stdio.h>

int main(void)
{
    short int small_value = 120;
    int population = 50000;
    long int distance = 100000L;
    long long int large_number = 9000000000LL;

    printf("Short = %hd\n", small_value);
    printf("Int = %d\n", population);
    printf("Long = %ld\n", distance);
    printf("Long long = %lld\n", large_number);

    return 0;
}
Expected Output 
Short = 120
Int = 50000
Long = 100000
Long long = 9000000000

Assuming the implementation supports the displayed values.

3. Signed and Unsigned Integers

Signed Integer

A signed integer type can represent negative values, zero and positive values. 

int temperature = -10;
int balance = 500;
int difference = 0;

Unsigned Integer

An unsigned integer type represents only non-negative values. Its entire value range is used for zero and positive integers. 

unsigned int count = 100;
unsigned int packets = 5000;

Example Program

#include <stdio.h>

int main(void)
{
    int signed_value = -25;
    unsigned int unsigned_value = 25U;

    printf("Signed value = %d\n", signed_value);
    printf("Unsigned value = %u\n", unsigned_value);

    return 0;
}
Expected Output 
Signed value = -25
Unsigned value = 25

Important Difference

Signed Integer Unsigned Integer
Can represent negative and non-negative values. Can represent only non-negative values.
Has a signed representation defined by the C implementation. Uses pure binary representation for its value.
Example: int value = -10; Example: unsigned int value = 10U;
Unsigned arithmetic is performed modulo one more than the maximum representable value. Signed integer overflow, however, is undefined behavior in C.

4. Binary Representation of Integers

Computers represent integer values using binary digits: 0 and 1. Each binary digit is called a bit.

Example: Decimal 13 in Binary

Binary Position Value
201
210
221
231

Therefore:

13 = 8 + 4 + 1
13 = 1101 (binary)

Unsigned Binary Values

For an unsigned type with N value bits, the representable range is: 

0 to (2^N - 1)

For example, an 8-bit unsigned integer can represent values from 0 to 255.

Signed Integer Representation

Modern general-purpose processors commonly use two's complement representation for signed integers. C11 does not require every implementation to use two's complement.

In an 8-bit two's complement representation, the bit pattern for positive 5 is: 

00000101

The corresponding representation of -5 in 8-bit two's complement is: 

11111011
Do not assume that a particular signed integer representation is required by C11. When answering standards-based questions, distinguish common processor behavior from language requirements.

5. Floating-Point Types

Floating-point types represent real-number approximations and support fractional values. C provides three standard floating-point types.

Type Description
float Basic floating-point type.
double At least as much precision as float.
long double At least as much precision as double.

Example

#include <stdio.h>

int main(void)
{
    float first = 12.5f;
    double second = 123.456789;
    long double third = 123.456789L;

    printf("Float = %.2f\n", first);
    printf("Double = %.6f\n", second);
    printf("Long double = %.6Lf\n", third);

    return 0;
}

The exact precision and representation of long double depend on the implementation.

The suffix L or l makes a floating-point literal have type long double. Use %Lf to print a long double with printf.

6. Floating-Point Representation

Floating-point numbers are commonly represented using three conceptual components:

  • Sign: Indicates the sign of the value.
  • Exponent: Determines the scale of the value.
  • Significand: Contains the significant digits.

A simplified scientific-notation representation is: 

Value = Significand × Base^Exponent

In common binary floating-point systems, the base is 2. The widely used IEEE 754 binary32 and binary64 formats have different precision and exponent ranges.

Common IEEE 754 Formats

Format Total Bits Sign Bits Exponent Bits Fraction Bits
Binary32 32 1 8 23
Binary64 64 1 11 52
These are common IEEE 754 formats, not universal C11 requirements for every float and double implementation.

7. Floating-Point Precision

Many decimal fractions cannot be represented exactly using a finite binary floating-point representation. As a result, calculations can produce small rounding differences.

Example: Floating-Point Approximation

#include <stdio.h>

int main(void)
{
    float value = 0.1f;

    printf("%.10f\n", value);

    return 0;
}

On a typical IEEE 754 binary32 implementation, the output is approximately: 

0.1000000015

The displayed result illustrates that the decimal value 0.1 is not represented exactly in this binary format.

Floating-Point Comparison

Direct equality comparisons can be unreliable when calculations involve rounding. 

#include <stdio.h>
#include <math.h>

int main(void)
{
    double a = 0.1 + 0.2;
    double b = 0.3;

    double epsilon = 1e-9;

    if (fabs(a - b) < epsilon)
    {
        printf("Values are approximately equal\n");
    }
    else
    {
        printf("Values are different\n");
    }

    return 0;
}
Expected Output on a typical IEEE 754 system 
Values are approximately equal
The appropriate tolerance depends on the scale of the values and the numerical problem. A fixed epsilon is not suitable for every floating-point comparison.

8. Character Data Type

The char type is used to store character values. It is also an integer type and can participate in arithmetic operations.

Character Declaration

char letter = 'A';
char digit = '7';
char symbol = '@';

Printing Characters

#include <stdio.h>

int main(void)
{
    char letter = 'B';

    printf("Character: %c\n", letter);
    printf("Integer value: %d\n", letter);

    return 0;
}

On an ASCII-compatible implementation: 

Character: B
Integer value: 66

The %c conversion specifier prints a character. The %d conversion specifier prints its promoted integer value when the argument is compatible with int.

9. Character Encoding

Character encoding defines how characters are represented using numeric values.

ASCII

ASCII is a character encoding that assigns numeric values to English letters, digits and control characters.

Character Decimal Value
'A'65
'B'66
'a'97
'0'48
'9'57
' '32

ASCII Character Arithmetic

#include <stdio.h>

int main(void)
{
    char ch = 'A';

    printf("Original character: %c\n", ch);
    printf("Next character: %c\n", ch + 1);

    return 0;
}
Expected Output on an ASCII-compatible implementation 
Original character: A
Next character: B

Character Set Requirement in C

C does not require ASCII. The basic execution character set includes the decimal digits, uppercase and lowercase Latin letters, and certain punctuation and control characters. The execution character set is not required to use ASCII numeric values.

C guarantees that the decimal digit characters '0' through '9' have consecutive increasing values. Do not assume the same numeric relationship for every other character.

10. Signedness of char

C provides three distinct character types:

  • char
  • signed char
  • unsigned char

Plain char has the same range and representation as either signed char or unsigned char, but which one is used is implementation-defined.

Example

#include <stdio.h>

int main(void)
{
    char normal_char = 'A';
    signed char signed_value = 100;
    unsigned char unsigned_value = 200;

    printf("Normal char: %c\n", normal_char);
    printf("Signed char: %d\n", signed_value);
    printf("Unsigned char: %u\n",
           (unsigned int)unsigned_value);

    return 0;
}
Expected Output 
Normal char: A
Signed char: 100
Unsigned char: 200

When Is unsigned char Useful?

  • Processing raw byte data.
  • Working with binary buffers.
  • Handling byte-oriented input and output.
  • Representing non-negative byte values.
When passing a possibly negative plain char value to character-classification functions such as isalpha(), first convert it to unsigned char, unless its value is EOF. These functions require an argument representable as unsigned char or equal to EOF.

11. Character Constants and Escape Sequences

Character constants use single quotation marks. Some characters are represented using escape sequences.

Escape Sequence Meaning
\nNewline
\tHorizontal tab
\rCarriage return
\\Backslash
\'Single quotation mark
\"Double quotation mark
\0Null character

Example

#include <stdio.h>

int main(void)
{
    printf("Name\tAge\n");
    printf("Alex\t25\n");

    return 0;
}
Expected Output 
Name    Age
Alex    25

12. Character Constant vs String Literal

A character constant and a string literal are different entities in C.

Character Constant String Literal
Written using single quotes. Written using double quotes.
Example: 'A' Example: "A"
Has type int in C. Is an array of char including a terminating null character.
Represents a character value. Represents a sequence of characters.

Example

#include <stdio.h>

int main(void)
{
    char letter = 'A';
    char text[] = "A";

    printf("Character = %c\n", letter);
    printf("String = %s\n", text);

    return 0;
}
Expected Output 
Character = A
String = A
A string literal contains a terminating null character. The array initialized using "A" therefore contains two char elements: 'A' and '\0'.

13. Comparing Integer and Floating-Point Types

Feature Integer Types Floating-Point Types
Values Whole-number values Values that may have fractional parts
Examples int, long, unsigned int float, double, long double
Precision Exact for representable integer values Usually approximate for many real values
Common use Counters, indexes and quantities Measurements and scientific calculations
Common output formats %d, %u, %ld, %lld %f, %e, %g
The format specifiers shown are for printf. For scanf, floating-point input uses %f for float* and %lf for double*. Do not interchange printf and scanf format rules.

14. Practical Program: Type Demonstration

This program demonstrates integer, floating-point and character variables together. 

#include <stdio.h>

int main(void)
{
    int employee_id = 105;
    unsigned int experience = 3U;

    float salary = 25000.50f;
    double annual_salary = 300006.0;

    char department = 'E';

    printf("Employee ID: %d\n", employee_id);
    printf("Experience: %u years\n", experience);
    printf("Monthly Salary: %.2f\n", salary);
    printf("Annual Salary: %.2f\n", annual_salary);
    printf("Department: %c\n", department);

    return 0;
}
Expected Output 
Employee ID: 105
Experience: 3 years
Monthly Salary: 25000.50
Annual Salary: 300006.00
Department: E

15. Common Errors and Misconceptions

Misconception or Error Correct Understanding
int is always 4 bytes. Its size is implementation-dependent, subject to C minimum requirements.
char is always signed. Plain char may be signed or unsigned.
float stores every decimal exactly. Many decimal fractions are approximated.
double is always exactly 8 bytes. Its representation and size depend on the implementation.
C always uses ASCII. C does not require ASCII execution encoding.
Signed integer overflow wraps around. Signed integer overflow is undefined behavior.
Character constants use double quotes. Character constants use single quotes.

16. Technical Interview Questions

Q1. What is the difference between signed and unsigned integers?
Signed integer types represent negative and non-negative values. Unsigned integer types represent only non-negative values.
Q2. What is the difference between float and double?
Both are floating-point types. double provides at least as much precision as float. Their exact representation depends on the implementation.
Q3. Why can floating-point calculations produce unexpected results?
Many decimal fractions cannot be represented exactly in finite binary floating-point formats. Calculations can therefore produce rounding differences.
Q4. Is char a signed or unsigned type?
Plain char has the same range and representation as either signed char or unsigned char. The choice is implementation-defined.
Q5. What is the difference between 'A' and "A"?
'A' is an integer character constant. "A" is a string literal containing an A character and a terminating null character.
Q6. What is two's complement?
It is a common method of representing signed binary integers. Negative values are represented by inverting the bits of the corresponding positive value and adding one, for a fixed-width representation.
Q7. Does C require IEEE 754 floating-point representation?
No. IEEE 754 formats are widely used, but C11 does not require every implementation to use them.
Q8. Why is unsigned char useful in embedded programming?
It is useful for byte-oriented operations, raw data buffers, communication packets and binary data processing.
Q9. What is the difference between integer and floating-point precision?
Integer types represent every value within their supported integer range exactly. Floating-point types have limited precision and approximate many real-number values.
Q10. Which type is appropriate for storing a byte?
unsigned char is commonly used for an ordinary byte buffer. C guarantees that sizeof(char) is 1, although a C byte is not necessarily eight bits. Use uint8_t from stdint.h when an exact 8-bit unsigned type is provided by the implementation.

20. Lecture Summary

  • C provides several integer types, including short, int, long and long long.
  • Signed integers represent negative and non-negative values.
  • Unsigned integers represent non-negative values.
  • Floating-point types include float, double and long double.
  • Floating-point calculations can involve rounding errors.
  • char is an integer type used for character values.
  • Plain char can be signed or unsigned depending on the implementation.
  • Character encoding is not universally ASCII.
  • Character constants and string literals are different.
  • Exact type sizes and representations must not be assumed without checking the implementation.
