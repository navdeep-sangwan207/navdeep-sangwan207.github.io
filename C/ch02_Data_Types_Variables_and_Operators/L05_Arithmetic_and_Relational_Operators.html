2. What Are Operators?

Operators are symbols that perform operations on operands. An operand may be a variable, constant or expression. 

int result = a + b;

Here, + is the operator, while a and b are operands.

This lecture focuses on two categories:

  1. Arithmetic operators
  2. Relational operators

3. Arithmetic Operators

Arithmetic operators perform mathematical calculations on numeric operands.

OperatorNameExamplePurpose
+Additiona + bAdds two operands.
-Subtractiona - bSubtracts the second operand from the first.
*Multiplicationa * bMultiplies operands.
/Divisiona / bDivides the first operand by the second.
%Remaindera % bProduces the remainder of integer division.

Example: Basic Arithmetic Operations

#include <stdio.h>

int main(void)
{
    int a = 20;
    int b = 6;

    printf("Addition = %d\n", a + b);
    printf("Subtraction = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division = %d\n", a / b);
    printf("Remainder = %d\n", a % b);

    return 0;
}
Expected Output 
Addition = 26
Subtraction = 14
Multiplication = 120
Division = 3
Remainder = 2

4. Addition Operator (+)

The addition operator adds two arithmetic operands. It can be used with integer and floating-point types. 

#include <stdio.h>

int main(void)
{
    int a = 15, b = 25;
    float x = 2.5f, y = 3.5f;

    printf("Integer sum = %d\n", a + b);
    printf("Float sum = %.2f\n", x + y);

    return 0;
}
Integer sum = 40
Float sum = 6.00

5. Subtraction Operator (-)

The subtraction operator calculates the difference between two operands. 

#include <stdio.h>

int main(void)
{
    int total = 100;
    int used = 35;

    int remaining = total - used;

    printf("Remaining = %d\n", remaining);

    return 0;
}
Remaining = 65

6. Multiplication Operator (*)

The multiplication operator calculates the product of two arithmetic operands. 

#include <stdio.h>

int main(void)
{
    int length = 12;
    int width = 5;

    int area = length * width;

    printf("Area = %d\n", area);

    return 0;
}
Area = 60
Signed integer multiplication that produces a result outside the representable range causes undefined behavior. Use appropriate types and validate ranges.

7. Division Operator (/)

The division operator divides one operand by another. Its result depends on the operand types.

Integer Division

int a = 17;
int b = 5;

printf("%d", a / b);
3

When both operands have integer types, the result is an integer. The fractional part is discarded by truncation toward zero.

Floating-Point Division

double a = 17.0;
double b = 5.0;

printf("%.2f", a / b);
3.40

Mixed-Type Division

int a = 17;
double b = 5.0;

printf("%.2f", a / b);
3.40

The integer operand is converted to double before the division.

Division by zero is undefined behavior for integer division. Do not perform a division unless the divisor is known to be nonzero. Floating-point division by zero follows floating-point rules and may produce infinity or NaN on implementations supporting those values.

8. Modulus (Remainder) Operator (%)

The remainder operator returns the remainder from integer division. Both operands must have integer types. 

#include <stdio.h>

int main(void)
{
    int a = 17;
    int b = 5;

    printf("Quotient = %d\n", a / b);
    printf("Remainder = %d\n", a % b);

    return 0;
}
Quotient = 3
Remainder = 2

Using Modulus to Check Even and Odd

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter an integer: ");

    if (scanf("%d", &number) != 1)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (number % 2 == 0)
        printf("Even number\n");
    else
        printf("Odd number\n");

    return 0;
}
A number is even when its remainder after division by 2 is zero. This test works for negative integers too.

Negative Remainder Example

#include <stdio.h>

int main(void)
{
    printf("%d\n", -17 % 5);
    printf("%d\n", 17 % -5);

    return 0;
}
-2
2

In C11, integer division truncates toward zero. The remainder has the sign of the dividend when the remainder is nonzero.

9. Unary Plus and Unary Minus

Unary operators operate on one operand.

OperatorMeaningExample
+xUnary plus; value remains unchanged after applicable promotions.int a = +5;
-xUnary minus; produces the arithmetic negation.int a = -5;
#include <stdio.h>

int main(void)

10. Relational Operators

Relational operators compare two operands. The result of a relational expression has type int and is either 1 (true) or 0 (false).

OperatorMeaningExample
==Equal toa == b
!=Not equal toa != b
>Greater thana > b
<Less thana < b
>=Greater than or equal toa >= b
<=Less than or equal toa <= b

Example: Relational Expressions

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;

    printf("a == b: %d\n", a == b);
    printf("a != b: %d\n", a != b);
    printf("a > b: %d\n", a > b);
    printf("a < b: %d\n", a < b);
    printf("a >= b: %d\n", a >= b);
    printf("a <= b: %d\n", a <= b);

    return 0;
}
a == b: 0
a != b: 1
a > b: 0
a < b: 1
a >= b: 0
a <= b: 1

11. Difference Between = and ==

These two operators are frequently confused in technical interviews and coding tests.

OperatorPurposeExample
=Assignmenta = 10;
==Equality comparisona == 10

Example

#include <stdio.h>

int main(void)
{
    int a = 10;

    if (a == 10)
        printf("Equal\n");

    return 0;
}
Equal
Writing if (a = 10) assigns 10 to a and then tests the assigned value. Since 10 is nonzero, the condition is true. Use == when comparing equality.

12. Practical Program: Find the Largest of Two Numbers

#include <stdio.h>

int main(void)
{
    int a, b;

    printf("Enter two integers: ");

    if (scanf("%d %d", &a, &b) != 2)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (a > b)
        printf("%d is greater\n", a);
    else if (b > a)
        printf("%d is greater\n", b);
    else
        printf("Both numbers are equal\n");

    return 0;
}
Sample Input

Expected Output 
25 is greater

13. Practical Program: Check Divisibility

Use the remainder operator to check whether a number is divisible by another nonzero integer. 

#include <stdio.h>

int main(void)
{
    int number, divisor;

    printf("Enter number and divisor: ");

    if (scanf("%d %d", &number, &divisor) != 2)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (divisor == 0)
    {
        printf("Divisor cannot be zero\n");
        return 1;
    }

    if (number % divisor == 0)
        printf("Divisible\n");
    else
        printf("Not divisible\n");

    return 0;
}
Sample Input 
24 6
Expected Output 
Divisible

14. Practical Program: Calculate Simple Interest

This program demonstrates arithmetic operations using floating-point values.

Formula:

Simple Interest = (Principal * Rate * Time) / 100
#include <stdio.h>

int main(void)
{
    double principal, rate, time, interest;

    printf("Enter principal, rate and time: ");

    if (scanf("%lf %lf %lf", &principal, &rate, &time) != 3)
    {
        printf("Invalid input\n");
        return 1;
    }

    interest = (principal * rate * time) / 100.0;

    printf("Simple Interest = %.2f\n", interest);

    return 0;
}
Sample Input 
10000 5 2
Expected Output 
Simple Interest = 1000.00

15. Common Mistakes and Important Rules

MistakeCorrect Understanding
Assuming 7 / 2 gives 3.5.Integer division produces 3.
Using % with floating-point operands.The remainder operator requires integer operands.
Using = for equality comparison.Use == for equality.
Assuming relational expressions return true or false words.They produce int value 1 or 0.
Dividing by zero.Check the divisor before integer division or remainder.
Ignoring signed integer overflow.Signed overflow is undefined behavior.
Assuming mathematical evaluation always avoids overflow.Choose types and validate intermediate results too.
Important C rule: Unsigned integer arithmetic is performed modulo one more than the maximum representable value. Signed integer overflow is undefined behavior.

16. Technical Interview Questions

Q1. What are arithmetic operators in C?
Arithmetic operators perform mathematical operations such as addition, subtraction, multiplication, division and remainder.
Q2. What is the difference between / and %?
The division operator calculates a quotient. The remainder operator calculates the remainder of integer division.
Q3. What is the result of 10 / 3?
The result is 3 because both operands are integers.
Q4. Can the modulus operator be used with float?
No. The % operator requires integer operands. Floating-point remainder can be calculated using functions such as fmod from math.h.
Q5. What is the result of a relational expression?
It produces an int value: 1 if the comparison is true and 0 if it is false.
Q6. What is the difference between = and ==?
= assigns a value, while == checks equality.
Q7. What happens when an integer is divided by zero?
It causes undefined behavior. The divisor must be checked before performing the operation.
Q8. What happens when a negative integer is used with %?
In C11, the remainder follows the sign of the dividend when the remainder is nonzero.
Q9. What is integer overflow?
It occurs when an arithmetic result cannot be represented by its integer type. Signed overflow is undefined behavior in C.
Q10. How can you check whether a number is even?
Use number % 2 == 0.
Q11. How can you check whether one number is divisible by another?
Check whether number % divisor == 0, after ensuring divisor is nonzero.
Q12. What is the difference between unary and binary operators?
Unary operators operate on one operand. Binary operators operate on two operands.

19. Practical Coding Exercises

20. Lecture Summary

  • Arithmetic operators perform mathematical calculations.
  • The division operator performs integer or floating-point division depending on operand types.
  • Integer division truncates toward zero.
  • The modulus operator calculates integer remainders.
  • Unary plus and minus operate on a single operand.
  • Relational operators compare two values.
  • Relational expressions produce int values 1 or 0.
  • The assignment operator = is different from equality operator ==.
  • Division by zero must be avoided for integer division and remainder.
