Lecture 4: Type Conversion and Type Casting

Understand how C converts values between data types and how to control conversions using explicit casts.

1. Learning Objectives

  • Understand type conversion in C.
  • Differentiate implicit conversion and explicit casting.
  • Understand conversion during assignment.
  • Learn integer promotions.
  • Understand usual arithmetic conversions.
  • Identify data loss and precision problems.
  • Understand signed and unsigned conversion behavior.
  • Solve type-conversion output-prediction questions.

2. What Is Type Conversion?

Type conversion is the process of converting a value from one data type to another.

For example, an integer value can be converted into a floating-point value, or a floating-point value can be converted into an integer. 

int number = 10;
double result = number;

In this example, the integer value 10 is converted to the double value 10.0 before assignment.

There are two major categories:

  1. Implicit type conversion
  2. Explicit type conversion (type casting)

3. Implicit Type Conversion

Implicit conversion occurs automatically according to the C language conversion rules. The programmer does not write a cast operator.

Example 1: Integer to Float

#include <stdio.h>

int main(void)
{
    int number = 25;
    float result = number;

    printf("Integer = %d\n", number);
    printf("Float = %.2f\n", result);

    return 0;
}
Expected Output 
Integer = 25
Float = 25.00

Example 2: Integer to Double

int a = 10;
double b = a;

The value of a is converted to double before being stored in b.

Example 3: Floating-Point to Integer

#include <stdio.h>

int main(void)
{
    double value = 15.89;
    int number = value;

    printf("%d\n", number);

    return 0;
}
Expected Output 
15

When a finite floating-point value is converted to an integer type, the fractional part is discarded by truncation toward zero, provided the resulting integer value is representable.

This is not rounding. 15.89 becomes 15, and -15.89 becomes -15. A floating-point value outside the representable range of the destination integer type causes undefined behavior.

4. Conversion During Assignment

When an expression is assigned to a variable, its value is converted to the destination type.

Example 1: Double to Int

#include <stdio.h>

int main(void)
{
    double price = 99.75;
    int amount = price;

    printf("Price = %.2f\n", price);
    printf("Amount = %d\n", amount);

    return 0;
}
Price = 99.75
Amount = 99

Example 2: Narrowing Integer Conversion

#include <stdio.h>

int main(void)
{
    int number = 300;
    unsigned char value = number;

    printf("%u\n", (unsigned int)value);

    return 0;
}

If unsigned char has a maximum value of 255, the converted value is 44 because unsigned integer conversion is performed modulo 256 in this case.

The result depends on the destination type's range. Do not assume every implementation uses an 8-bit unsigned char.

5. Widening and Narrowing Conversions

Widening Conversion

A widening conversion moves a value into a type that can represent a broader range or greater precision for the value being converted. 

int number = 100;
double result = number;

The value 100 is exactly representable as a double on conforming C implementations.

Narrowing Conversion

A narrowing conversion converts a value into a type with a smaller range or precision. 

double value = 123.456;
int number = value;

The fractional part is discarded. Other narrowing conversions can lose information or produce a different result according to the destination type.

Conversion Example Possible Effect
Widening integer to floating point int to double Usually preserves the value exactly for ordinary integer values.
Floating point to integer double to int Fractional part is discarded.
Wider integer to narrower integer int to short May produce an implementation-defined result if the value is not representable.
Double to float double to float May lose precision or range.

6. Explicit Type Casting

Explicit type casting allows the programmer to request conversion to a particular type.

Syntax

(destination_type) expression

Example 1: Double to Int

#include <stdio.h>

int main(void)
{
    double value = 45.78;

    int number = (int)value;

    printf("Original value = %.2f\n", value);
    printf("Converted value = %d\n", number);

    return 0;
}
Original value = 45.78
Converted value = 45

Example 2: Integer Division to Floating-Point Division

#include <stdio.h>

int main(void)
{
    int a = 7;
    int b = 2;

    double result = (double)a / b;

    printf("Result = %.2f\n", result);

    return 0;
}
Result = 3.50

Casting a to double causes the division to use floating-point arithmetic.

Incorrect Approach

double result = (double)(a / b);

Here a / b is evaluated first as integer division. The result is 3, which is then converted to 3.0.

The position of the cast matters. Cast an operand before the operation when you want to change the operation's arithmetic type.

7. Integer Promotions

Integer promotions are automatic conversions applied to certain integer types before many arithmetic, bitwise and other operations.

Types such as char, signed char, unsigned char, short and unsigned short are commonly promoted to int when int can represent all their values. Otherwise, they are promoted to unsigned int.

Example

#include <stdio.h>

int main(void)
{
    char a = 10;
    char b = 20;

    int result = a + b;

    printf("%d\n", result);

    return 0;
}
30

The operands are promoted before addition. The addition is normally performed as int.

Another Example: Character Arithmetic

#include <stdio.h>

int main(void)
{
    char ch = 'A';

    printf("%d\n", ch + 1);

    return 0;
}
66

This is the usual result on ASCII-compatible implementations. C does not require ASCII encoding.

Integer promotions are important in embedded C, bitwise operations and expression evaluation.

8. Usual Arithmetic Conversions

When arithmetic operators combine operands of different arithmetic types, C applies the usual arithmetic conversions to determine a common type.

Example 1: int and float

#include <stdio.h>

int main(void)
{
    int a = 10;
    float b = 2.5f;

    printf("%.2f\n", a + b);

    return 0;
}
12.50

The integer operand is converted to float for the arithmetic operation.

Example 2: int and double

#include <stdio.h>

int main(void)
{
    int a = 10;
    double b = 2.5;

    printf("%.2f\n", a + b);

    return 0;
}
12.50

The integer operand is converted to double.

Common Arithmetic Conversion Patterns

Operands Typical common type
int + int int
int + float float
int + double double
float + double double
long + int Determined by integer conversion rules; commonly long.
Mixed signed and unsigned integer expressions can produce surprising results. The exact rules depend on integer ranks and representable ranges. Do not simplify every such expression to "unsigned always wins" without checking the conversion rules.

9. Signed and Unsigned Conversions

Conversions between signed and unsigned integer types can change how a value is interpreted or represented.

Example 1: Negative Integer to Unsigned

#include <stdio.h>

int main(void)
{
    int number = -1;
    unsigned int value = number;

    printf("%u\n", value);

    return 0;
}

The conversion to unsigned int is performed modulo UINT_MAX + 1.

Expected Result 
UINT_MAX

The exact decimal value depends on the range of unsigned int on the implementation.

Example 2: Signed and Unsigned Comparison

#include <stdio.h>

int main(void)
{
    int a = -1;
    unsigned int b = 1U;

    if (a < b)
        printf("a is smaller\n");
    else
        printf("a is not smaller\n");

    return 0;
}

On a typical implementation where int and unsigned int have the same rank and corresponding range, a is converted to unsigned int for comparison. 

a is not smaller

The negative value converts to a large unsigned value, so the comparison is false on that common implementation.

Mixed signed and unsigned comparisons are a frequent source of bugs. Avoid comparing signed values with unsigned values without checking the conversion rules.

10. Type Conversion in Function Arguments

Function calls also involve conversions. Arguments are converted to the types of their corresponding parameters when a function prototype is visible.

Example

#include <stdio.h>

void display(double value)
{
    printf("%.2f\n", value);
}

int main(void)
{
    int number = 25;

    display(number);

    return 0;
}
25.00

The integer argument is converted to double for the function parameter.

11. Type Conversion in Expressions

Example 1: Integer Division

int a = 9;
int b = 4;

double result = a / b;

Both operands are integers, so division produces integer result 2. That value is then converted to double and stored as 2.0.

Correct Floating-Point Division

double result = (double)a / b;

Now the result is 2.25.

Example 2: Mixed Arithmetic

int a = 5;
float b = 2.0f;

float result = a / b;

The int operand is converted to float before division. The result is 2.5.

12. Common Type Conversion Errors

Incorrect Approach Problem Better Approach
double r = 7 / 2; Integer division occurs first. double r = 7.0 / 2;
int x = 12.9; Fractional part is discarded. Use double if fractional precision is needed.
Mixing signed and unsigned values carelessly. Unexpected comparison or arithmetic results. Use consistent integer types and explicit checks.
Assuming every cast is safe. Some conversions can lose information or cause undefined behavior. Validate destination range before conversion.
Using a cast after integer division. It cannot restore the discarded fractional part. Cast an operand before division.

13. Practical Program: Calculate Average

A common beginner mistake is dividing two integers and expecting a fractional average.

Incorrect Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 15;

    double average = (a + b) / 2;

    printf("Average = %.2f\n", average);

    return 0;
}
Average = 12.00

This example happens to produce an exact integer average. For values whose average has a fractional part, integer division would lose that fraction.

Correct Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 15;

    double average = (double)(a + b) / 2;

    printf("Average = %.2f\n", average);

    return 0;
}

To see the difference clearly, change the values to 10 and 16.

Expected Output for 10 and 16 
Average = 13.00

The next example demonstrates a fractional result more directly. 

double average = (double)(10 + 15) / 2;
printf("%.2f\n", average);
12.50

14. Technical Interview Questions

Q1. What is type conversion in C?
It is the process of converting a value from one data type to another according to C's conversion rules.
Q2. What is implicit type conversion?
It is an automatic conversion performed by the compiler without an explicit cast written by the programmer.
Q3. What is explicit type casting?
It is a conversion explicitly requested by the programmer using the syntax (type)expression.
Q4. What is the difference between widening and narrowing conversion?
Widening generally converts to a type with broader range or precision. Narrowing converts to a type with more limited range or precision and may lose information.
Q5. What are integer promotions?
Certain integer types of rank lower than int are converted to int or unsigned int before many operations.
Q6. What are the usual arithmetic conversions?
They are the rules used to convert arithmetic operands to a common type before performing an operation.
Q7. Why does 7 / 2 produce 3 instead of 3.5?
Both operands are integers, so integer division is performed and the fractional part is discarded.
Q8. How can floating-point division be obtained from integer variables?
Convert at least one operand to a floating-point type before division, for example (double)a / b.
Q9. Does explicit casting guarantee a safe conversion?
No. A cast requests a conversion but does not guarantee that the destination can represent the value. Range and precision must be considered.
Q10. What happens when a negative int is converted to unsigned int?
The result is determined modulo UINT_MAX + 1.
Q11. Why can a signed and unsigned comparison be surprising?
The usual arithmetic conversions may convert the signed operand to an unsigned type before comparison.
Q12. Does a cast change the original variable?
No. A cast produces a converted value for the expression. The original variable changes only if the result is assigned back to it.

16. Multiple-Choice Questions

Q1. Which is an example of implicit conversion?
  1. int x = (int)5.5;
  2. double x = 10;
  3. int x = (int)3.2;
  4. float x = (float)2;
Answer: B
Q2. What is the result of integer division 9 / 4?
  1. 2.25
  2. 2
  3. 3
  4. 2.5
Answer: B — 2
Q3. Which expression performs floating-point division?
  1. a / b
  2. (int)a / b
  3. (double)a / b
  4. (int)(a / b)
Answer: C
Q4. What usually happens to char operands in arithmetic expressions?
  1. They are always converted to double.
  2. They undergo integer promotion.
  3. They are always converted to long double.
  4. No conversion occurs.
Answer: B
Q5. What does explicit casting do?
  1. Changes the compiler.
  2. Requests conversion to a specified type.
  3. Always rounds a value.
  4. Prevents all data loss.
Answer: B
Q6. What happens when a finite positive floating-point value is converted to int, if representable?
  1. It is always rounded upward.
  2. It is always rounded to nearest.
  3. The fractional part is discarded.
  4. The conversion is invalid.
Answer: C

18. Lecture Summary

  • Type conversion changes a value from one data type to another.
  • Implicit conversion is performed automatically.
  • Explicit casting requests conversion using (type)expression.
  • Floating-point to integer conversion discards the fractional part.
  • Integer promotions convert certain smaller integer types before operations.
  • Usual arithmetic conversions establish a common arithmetic type.
  • Mixed signed and unsigned expressions require careful analysis.
  • Casting before division can produce floating-point division.
  • Casting after integer division cannot restore the discarded fraction.
  • Explicit casting does not guarantee a safe or lossless conversion.
