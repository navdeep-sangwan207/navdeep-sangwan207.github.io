Chapter 2: Data Types, Variables and Operators

Understand how C stores data, performs type conversions and evaluates expressions using operators.

Chapter Overview

Data types, variables and operators are fundamental to writing correct and efficient C programs. This chapter explains how data is declared, represented and manipulated in memory.

You will study fundamental data types, type modifiers, implicit and explicit conversions, arithmetic and logical operators, bitwise operations, expression evaluation and operator precedence.

Special attention is given to output-prediction questions, expression tracing, common programming mistakes and technical interview problems.

Learning Objectives

  • Understand variables, constants and fundamental C data types.
  • Differentiate integer, floating-point and character types.
  • Use signed, unsigned, short and long type modifiers.
  • Determine data sizes and ranges using sizeof and standard limits.
  • Understand implicit conversions, promotions and explicit type casting.
  • Apply arithmetic, relational, logical and assignment operators.
  • Understand prefix, postfix and conditional operators.
  • Perform bitwise operations and understand shift operators.
  • Evaluate expressions using precedence and associativity rules.
  • Solve C output-prediction and placement-oriented coding problems.

Technical Interview and Coding Round Preparation

  • Predict the output of expressions involving different data types.
  • Identify implicit conversion and integer promotion results.
  • Determine the result of arithmetic and relational expressions.
