Lecture 7: Increment, Decrement and Conditional Operators

Understand variable updates, prefix and postfix expressions, and conditional value selection.

1. Learning Objectives

  • Understand increment and decrement operators.
  • Differentiate prefix and postfix operations.
  • Understand how increment and decrement expressions are evaluated.
  • Use increment and decrement operators in loops and programs.
  • Understand the conditional or ternary operator.
  • Use nested conditional expressions appropriately.
  • Solve output-prediction and placement-oriented problems.

2. Increment Operator (++ )

The increment operator increases the value of a modifiable arithmetic object by one. 

int count = 10;

count++;

After execution, the value of count becomes 11.

There are two forms of the increment operator:

  • Prefix increment: ++count
  • Postfix increment: count++
Both forms increase the variable by one. Their difference is the value produced by the expression: prefix produces the updated value, while postfix produces the old value.

3. Prefix Increment (++variable)

In prefix increment, the variable is incremented first. The expression then produces the updated value.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int result;

    result = ++a;

    printf("a = %d\n", a);
    printf("result = %d\n", result);

    return 0;
}
a = 6
result = 6

Execution:

  1. Initially, a is 5.
  2. ++a increments a to 6.
  3. The expression produces 6.
  4. result receives 6.

4. Postfix Increment (variable++)

In postfix increment, the expression produces the original value. The variable is then incremented.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int result;

    result = a++;

    printf("a = %d\n", a);
    printf("result = %d\n", result);

    return 0;
}
a = 6
result = 5

Execution:

  1. Initially, a is 5.
  2. a++ produces the old value 5.
  3. result receives 5.
  4. a is incremented to 6.

5. Prefix vs Postfix Increment

Feature Prefix (++a) Postfix (a++)
Operation Increments the variable. Increments the variable.
Expression value Updated value. Original value.
Typical use When the updated value is needed. When the original value is needed.

Comparison Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 10;

    printf("Prefix result = %d\n", ++a);
    printf("Postfix result = %d\n", b++);

    printf("Final a = %d\n", a);
    printf("Final b = %d\n", b);

    return 0;
}
Prefix result = 11
Postfix result = 10
Final a = 11
Final b = 11

6. Decrement Operator (--)

The decrement operator decreases the value of a modifiable arithmetic object by one.

Two forms are available:

  • Prefix decrement: --a
  • Postfix decrement: a--

Prefix Decrement Example

#include <stdio.h>

int main(void)
{
    int a = 10;
    int result;

    result = --a;

    printf("a = %d\n", a);
    printf("result = %d\n", result);

    return 0;
}
a = 9
result = 9

Postfix Decrement Example

#include <stdio.h>

int main(void)
{
    int a = 10;
    int result;

    result = a--;

    printf("a = %d\n", a);
    printf("result = %d\n", result);

    return 0;
}
a = 9
result = 10

7. Increment and Decrement in Expressions

Prefix and postfix operators are frequently used in expressions. Understand the value produced by each operation before evaluating the complete expression.

Example 1: Prefix in an Expression

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = ++a + 2;

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}
a = 6
b = 8

Example 2: Postfix in an Expression

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = a++ + 2;

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}
a = 6
b = 7
Avoid expressions that modify the same variable multiple times without sequencing, such as i++ + ++i or printf("%d %d", i++, i++). These have undefined behavior in C because the modifications are unsequenced.

8. Increment and Decrement in Loops

Increment and decrement operators are commonly used to update loop-control variables.

Example: Increment in a for Loop

#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}
1 2 3 4 5

Example: Decrement in a for Loop

#include <stdio.h>

int main(void)
{
    int i;

    for (i = 5; i >= 1; i--)
    {
        printf("%d ", i);
    }

    return 0;
}
5 4 3 2 1
Prefix and postfix forms both work as loop-update expressions when their produced values are not used elsewhere in the expression.

9. Conditional Operator (?:)

The conditional operator is also known as the ternary operator because it uses three operands.

Syntax

condition ? expression_if_true : expression_if_false;

Its behavior is:

  • If the condition is true, the second operand is evaluated.
  • If the condition is false, the third operand is evaluated.
  • Only the selected operand is evaluated.

Example: Find the Larger Number

#include <stdio.h>

int main(void)
{
    int a = 25;
    int b = 40;

    int maximum = (a > b) ? a : b;

    printf("Maximum = %d\n", maximum);

    return 0;
}
Maximum = 40

10. Conditional Operator vs if-else

Both can implement decision-making logic, but their usage and expression behavior are different.

Conditional Operatorif-else Statement
Uses ?:. Uses if and else.
Produces a value from one of two expressions. Executes a selected statement or block.
Useful for short value-selection expressions. Better for complex decision-making and multiple statements.
Can be used inside a larger expression. Cannot be used as an ordinary expression.

Same Logic Using if-else

#include <stdio.h>

int main(void)
{
    int a = 25;
    int b = 40;
    int maximum;

    if (a > b)
        maximum = a;
    else
        maximum = b;

    printf("Maximum = %d\n", maximum);

    return 0;
}
Maximum = 40

11. Practical Programs Using the Conditional Operator

Program 1: Check Even or Odd

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter a number: ");

    if (scanf("%d", &number) != 1)
    {
        printf("Invalid input\n");
        return 1;
    }

    printf("%s\n",
           (number % 2 == 0) ? "Even" : "Odd");

    return 0;
}
Sample Input 
17
Expected Output 
Odd

Program 2: Find the Largest of Three Numbers

#include <stdio.h>

int main(void)
{
    int a, b, c;
    int largest;

    printf("Enter three numbers: ");

    if (scanf("%d %d %d", &a, &b, &c) != 3)
    {
        printf("Invalid input\n");
        return 1;
    }

    largest = (a > b)
              ? ((a > c) ? a : c)
              : ((b > c) ? b : c);

    printf("Largest = %d\n", largest);

    return 0;
}
Sample Input 
15 42 28
Expected Output 
Largest = 42

Program 3: Find the Absolute Value

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter an integer: ");

    if (scanf("%d", &number) != 1)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (number == (-2147483647 - 1))
    {
        printf("Absolute value is outside the int range\n");
    }
    else
    {
        int absolute = (number < 0) ? -number : number;
        printf("Absolute value = %d\n", absolute);
    }

    return 0;
}
Sample Input 
-25
Expected Output 
Absolute value = 25
The third program uses the common 32-bit int minimum value as an explicit example. The expression -2147483647 - 1 is representable when int is at least 32 bits. For fully portable range handling across implementations, use limits from <limits.h> and check INT_MIN before negation.

12. Nested Conditional Operator

A conditional operator can be placed inside another conditional operator. This is called a nested conditional expression.

Example: Grade Classification

#include <stdio.h>

int main(void)
{
    int marks = 82;

    char grade = (marks >= 90) ? 'A' :
                 (marks >= 75) ? 'B' :
                 (marks >= 60) ? 'C' : 'D';

    printf("Grade = %c\n", grade);

    return 0;
}
Grade = B

Evaluation:

  1. Check whether marks are at least 90. This is false.
  2. Check whether marks are at least 75. This is true.
  3. The selected grade is B.
Nested conditional expressions can become difficult to read. Use parentheses and clear formatting, or prefer if-else when the decision logic becomes complex.

13. Important Rules and Common Mistakes

Common MistakeCorrect Understanding
Assuming ++a and a++ always produce the same expression value. Prefix produces the updated value; postfix produces the original value.
Using increment on a constant such as ++10. Increment requires a modifiable arithmetic object.
Writing i++ + ++i. Multiple unsequenced modifications of the same scalar cause undefined behavior.
Assuming the conditional operator evaluates both result expressions. Only the selected second or third operand is evaluated.
Using deeply nested ternary expressions for complicated logic. Use clear formatting or if-else statements.
Assuming incrementing a signed integer beyond its maximum is safe. Signed integer overflow is undefined behavior.
Using ++ on a floating-point variable and expecting an integer conversion. Increment adds one in the variable's arithmetic type.

14. Technical Interview Questions

Q1. What is the increment operator in C?
The increment operator (++) increases the value of a modifiable arithmetic object by one.
Q2. What is the difference between prefix and postfix increment?
Prefix increment updates the variable and produces the new value. Postfix increment produces the old value and then updates the variable.
Q3. What is the decrement operator?
The decrement operator (--) decreases the value of a modifiable arithmetic object by one.
Q4. What is the difference between ++a and a++?
Both increment a. The difference is the value produced by the expression: ++a produces the updated value, while a++ produces the old value.
Q5. What is the ternary operator?
The conditional operator (?:) selects and evaluates one of two expressions based on a condition.
Q6. Why is it called the ternary operator?
It is called ternary because it operates on three operands: a condition, an expression for true, and an expression for false.
Q7. Can the conditional operator replace if-else?
It can replace simple if-else value-selection logic. Complex statements and multiple operations are generally clearer with if-else.
Q8. Can conditional operators be nested?
Yes. A conditional expression can be used inside another conditional expression.
Q9. What is undefined behavior in expressions involving increment?
Modifying the same scalar object multiple times without sequencing, such as i++ + ++i, causes undefined behavior in C.
Q10. Can ++ and -- be applied to floating-point variables?
Yes. They add or subtract one in the arithmetic type of the operand.
Q11. Is ++i always faster than i++?
For ordinary scalar arithmetic variables, modern compilers generally generate equivalent efficient code when the expression value is unused. The important distinction is semantic, not a guaranteed performance difference.
Q12. Which conditional operand is evaluated?
If the condition is nonzero, only the second operand is evaluated. Otherwise, only the third operand is evaluated.

18. Lecture Summary

  • Increment (++) increases a variable by one.
  • Decrement (--) decreases a variable by one.
  • Prefix increment produces the updated value.
  • Postfix increment produces the original value.
  • Prefix and postfix decrement follow the same value rules.
  • Increment and decrement operators are commonly used in loops.
  • The conditional operator uses the syntax condition ? expression1 : expression2.
  • Only the selected conditional operand is evaluated.
  • Nested conditional expressions can implement multiple choices.
  • Unsequenced modifications of the same scalar object can cause undefined behavior.
