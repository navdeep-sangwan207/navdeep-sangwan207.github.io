Learn bit-level operations and important C operators used in programming, debugging and embedded systems.

2. Introduction to Bitwise Operators

Bitwise operators perform operations on individual bits of integer operands. They are important in low-level programming, embedded systems, device drivers and hardware register manipulation.

Consider two unsigned 8-bit values:

A = 12 = 00001100
B = 10 = 00001010

A bitwise operation compares or changes the corresponding bit positions of these operands.

In C, bitwise operators require integer operands. For predictable bit manipulation, use unsigned integer types such as unsigned int or uint32_t.

3. Bitwise AND Operator (&)

The bitwise AND operator produces 1 only when both corresponding bits are 1.

ABA & B
000
010
100
111

Example

#include <stdio.h>

int main(void)
{
    unsigned int a = 12;
    unsigned int b = 10;

    printf("Result = %u\n", a & b);

    return 0;
}

Binary calculation:

  00001100
& 00001010
-----------
  00001000
Result = 8

Common Application: Checking a Bit

unsigned int value = 10;
unsigned int mask = 2;

if ((value & mask) != 0)
{
    printf("Bit is set\n");
}
else
{
    printf("Bit is clear\n");
}
Bit is set

4. Bitwise OR Operator (|)

The bitwise OR operator produces 1 when at least one of the corresponding bits is 1.

ABA | B
000
011
101
111

Example

#include <stdio.h>

int main(void)
{
    unsigned int a = 12;
    unsigned int b = 10;

    printf("Result = %u\n", a | b);

    return 0;
}
  00001100
| 00001010
-----------
  00001110
Result = 14

Common Application: Setting a Bit

unsigned int value = 8;
unsigned int mask = 2;

value = value | mask;

printf("%u\n", value);
10

5. Bitwise XOR Operator (^)

XOR produces 1 when the corresponding bits are different. It produces 0 when they are the same.

ABA ^ B
000
011
101
110

Example

#include <stdio.h>

int main(void)
{
    unsigned int a = 12;
    unsigned int b = 10;

    printf("Result = %u\n", a ^ b);

    return 0;
}
  00001100
^ 00001010
-----------
  00000110
Result = 6

Common Application: Toggle a Bit

unsigned int value = 8;
unsigned int mask = 2;

value ^= mask;

printf("%u\n", value);
10

XOR with a mask toggles the selected bit: a 0 becomes 1 and a 1 becomes 0.

6. Bitwise NOT Operator (~)

The bitwise NOT operator reverses every bit: 0 becomes 1 and 1 becomes 0. 

unsigned int a = 5;
unsigned int result = ~a;

The exact result depends on the width of unsigned int. For an unsigned type with N value bits, complementing 5 produces the maximum value minus 5.

Portable Example Using uint8_t

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t a = 5;
    uint8_t result = (uint8_t)~a;

    printf("Result = %u\n", (unsigned int)result);

    return 0;
}
Result = 250

For an 8-bit representation:

a       = 00000101
~a      = 11111010
          --------
          11111010 = 250
Small integer types such as uint8_t undergo integer promotion before the bitwise NOT operation. The explicit conversion back to uint8_t retains the lowest eight bits.

8. Left Shift Operator (<<)

The left-shift operator moves the bits of its left operand toward higher bit positions. Vacated low-order positions are filled with zero bits.

Example

#include <stdio.h>

int main(void)
{
    unsigned int value = 5;

    printf("Result = %u\n", value << 1);

    return 0;
}

Binary representation:

00000101 << 1
00001010
Result = 10

For an unsigned value, shifting left by one position is equivalent to multiplying by two when the result is interpreted within the available unsigned width.

9. Right Shift Operator (>>)

The right-shift operator moves bits toward lower positions. Vacated high-order positions are filled according to the operand's type and the C rules.

Example with an Unsigned Operand

#include <stdio.h>

int main(void)
{
    unsigned int value = 20;

    printf("Result = %u\n", value >> 2);

    return 0;
}

Binary representation of the low eight bits:

00010100 >> 2
00000101
Result = 5
Right-shifting a negative signed integer has implementation-defined behavior in C11. Use unsigned operands when predictable logical bit shifting is required.

10. Bitwise vs Logical Operators

Bitwise and logical operators look similar, but they perform different operations.

BitwiseLogical
&&&
|||
^No direct logical XOR operator
~!

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 3;

    printf("Bitwise AND = %d\n", a & b);
    printf("Logical AND = %d\n", a && b);

    return 0;
}
Bitwise AND = 1
Logical AND = 1

These particular results happen to be equal. However, the operations are not interchangeable.

Example Showing the Difference

#include <stdio.h>

int main(void)
{
    int a = 6;
    int b = 3;

    printf("Bitwise AND = %d\n", a & b);
    printf("Logical AND = %d\n", a && b);

    return 0;
}
Bitwise AND = 2
Logical AND = 1
Logical operators produce either 0 or 1. Bitwise operators operate on the individual bits of integer operands. Logical AND and OR also provide short-circuit evaluation; bitwise AND and OR do not.

11. sizeof Operator

The sizeof operator returns the size, in bytes, of a type or object. Its result has type size_t.

Syntax

sizeof(expression)
sizeof(type)

Example

#include <stdio.h>

int main(void)
{
    int a;
    double b;
    char c;

    printf("Size of int = %zu bytes\n", sizeof(a));
    printf("Size of double = %zu bytes\n", sizeof(b));
    printf("Size of char = %zu byte\n", sizeof(c));

    return 0;
}

Example output on a common implementation:

Size of int = 4 bytes
Size of double = 8 bytes
Size of char = 1 byte
The sizes of int and double are implementation-dependent. Do not assume the example sizes are guaranteed by C. sizeof(char) is always 1 by definition, although a C byte is not required to contain exactly eight bits.

sizeof Array

#include <stdio.h>

int main(void)
{
    int numbers[5];

    size_t total_size = sizeof(numbers);
    size_t element_size = sizeof(numbers[0]);
    size_t count = total_size / element_size;

    printf("Array size = %zu bytes\n", total_size);
    printf("Element size = %zu bytes\n", element_size);
    printf("Number of elements = %zu\n", count);

    return 0;
}
This array-length technique works where numbers is an actual array in the current scope. When an array is passed to a function, its parameter is adjusted to a pointer, so sizeof on that parameter gives the pointer size instead.

12. Address-of Operator (&)

The address-of operator returns the memory address of an object.

Example

#include <stdio.h>

int main(void)
{
    int number = 25;

    printf("Value = %d\n", number);
    printf("Address = %p\n", (void *)&number);

    return 0;
}
Value = 25
Address = implementation-dependent address

The actual address differs between executions and systems. The %p conversion specifier expects a void pointer argument.

13. Indirection or Dereference Operator (*)

The indirection operator accesses the object pointed to by a valid pointer.

Example

#include <stdio.h>

int main(void)
{
    int number = 25;
    int *ptr = &number;

    printf("Value = %d\n", number);
    printf("Value using pointer = %d\n", *ptr);

    *ptr = 50;

    printf("Updated value = %d\n", number);

    return 0;
}
Value = 25
Value using pointer = 25
Updated value = 50
The expression &number obtains the address of number. The expression *ptr accesses the object at the address stored in ptr. Detailed pointer concepts are covered in Chapter 9.

14. Comma Operator (,)

The comma operator evaluates its left operand first, discards that result, then evaluates its right operand. The value and type of the complete expression are those of the right operand.

Example

#include <stdio.h>

int main(void)
{
    int a, b, result;

    result = (a = 5, b = 10, a + b);

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("result = %d\n", result);

    return 0;
}
a = 5
b = 10
result = 15

The parentheses are important. In this example, the comma operators form one expression whose final value is a + b.

Do not confuse the comma operator with commas used as separators in function arguments or declarations. For example, the commas in printf("%d %d", a, b) separate function arguments; they are not comma operators.

15. Other Useful Operators and Expressions

Member Access Operators (. and ->)

The dot operator accesses a structure or union member through an object. The arrow operator accesses a member through a pointer to a structure or union. 

struct Student
{
    int id;
};

struct Student s = {101};
struct Student *ptr = &s;

printf("%d\n", s.id);
printf("%d\n", ptr->id);
101
101

Subscript Operator ([])

The subscript operator accesses an array element. 

int numbers[3] = {10, 20, 30};

printf("%d\n", numbers[1]);
20

Function Call Operator (())

Parentheses are used to call a function and provide its arguments. 

int result = add(10, 20);

Cast Operator

A cast explicitly converts an expression to a specified type. Detailed type conversion rules are covered in Lecture 4. 

double result = (double)5 / 2;

Conditional Operator (?:)

Selects one of two expressions based on a condition. This was covered in Lecture 7. 

int maximum = (a > b) ? a : b;

16. Practical Bitwise Programming Examples

Program 1: Check Whether a Number Is Even or Odd Using Bits

#include <stdio.h>

int main(void)
{
    unsigned int number = 14;

    if ((number & 1U) == 0U)
        printf("Even\n");
    else
        printf("Odd\n");

    return 0;
}
Even

The least significant bit of an unsigned integer is 0 for an even number and 1 for an odd number.

Program 2: Set, Clear and Toggle Bits

#include <stdio.h>

int main(void)
{
    unsigned int value = 8U;
    unsigned int mask = 2U;

    value |= mask;
    printf("After setting bit = %u\n", value);

    value &= ~mask;
    printf("After clearing bit = %u\n", value);

    value ^= mask;
    printf("After toggling bit = %u\n", value);

    return 0;
}
After setting bit = 10
After clearing bit = 8
After toggling bit = 10

Program 3: Extract the Lowest Four Bits

#include <stdio.h>

int main(void)
{
    unsigned int value = 45U;
    unsigned int result = value & 0x0FU;

    printf("Extracted value = %u\n", result);

    return 0;
}
Extracted value = 13

The mask 0x0F has its lowest four bits set. ANDing with this mask extracts those four bits.

Program 4: Count Set Bits Using a Loop

#include <stdio.h>

int main(void)
{
    unsigned int number = 13U;
    unsigned int count = 0U;

    while (number != 0U)
    {
        count += number & 1U;
        number >>= 1;
    }

    printf("Set bits = %u\n", count);

    return 0;
}
Set bits = 3

17. Bitwise Operators in Embedded Systems

Embedded C programs frequently use bitwise operations to control individual bits of hardware registers.

Illustrative Register Operations

#include <stdint.h>

#define BIT(n) (UINT32_C(1) << (n))

uint32_t control_register = 0U;

/* Set bit 3 */
control_register |= BIT(3);

/* Clear bit 3 */
control_register &= ~BIT(3);

/* Toggle bit 3 */
control_register ^= BIT(3);

/* Check bit 3 */
if ((control_register & BIT(3)) != 0U)
{
    /* Bit is set */
}
This is an illustrative software variable, not an actual hardware register. Real peripheral registers must be accessed using the device-specific definitions and required volatile-qualified access. Register access rules and read-modify-write limitations depend on the hardware.

Typical applications include:

  • Setting GPIO output bits.
  • Checking peripheral status flags.
  • Enabling or disabling interrupt sources.
  • Configuring communication peripherals.
  • Extracting fields from control and status registers.

18. Important Technical Interview Questions

Q1. What are bitwise operators?
Operators that perform operations on individual bits of integer operands.
Q2. What is the difference between & and &&?
& performs bitwise AND, while && performs logical AND and produces 0 or 1.
Q3. What is the difference between | and ||?
| performs bitwise OR. || performs logical OR with short-circuit evaluation.
Q4. What is the purpose of XOR?
XOR produces 1 for different corresponding bits. It is commonly used to toggle bits and solve certain bit-manipulation problems.
Q5. What does the bitwise NOT operator do?
It complements all bits of the promoted integer operand.
Q6. What is a bit mask?
A bit mask is a value designed to select, set, clear or toggle specific bit positions.
Q7. What is the sizeof operator?
It returns the size in bytes of a type or object. Its result type is size_t.
Q8. Why is %zu used with sizeof?
Because sizeof produces a value of type size_t, and %zu is the corresponding printf conversion specifier in C99 and later.
Q9. What is the address-of operator?
The & operator obtains the address of an object.
Q10. What is the indirection operator?
The unary * operator accesses the object designated by a valid pointer.
Q11. What is the comma operator?
It evaluates the left operand first, then the right operand. The complete expression has the value and type of the right operand.
Q12. Why are bitwise operators important in embedded C?
They allow individual bits in control, status and configuration registers to be inspected or modified.

22. Lecture Summary

  • Bitwise operators work on individual bits of integer operands.
  • AND checks common set bits.
  • OR sets bits present in either operand.
  • XOR identifies differing bits and can toggle bits.
  • NOT complements every bit.
  • Shift operators move bits left or right.
  • Bit masks help inspect and modify selected bits.
  • Logical operators are different from bitwise operators.
  • sizeof returns an object's or type's size in bytes.
  • Address-of obtains an object's address.
  • Indirection accesses an object through a pointer.
  • The comma operator evaluates operands from left to right and produces the right operand's value.
  • Bitwise operations are important in embedded C and low-level programming.
