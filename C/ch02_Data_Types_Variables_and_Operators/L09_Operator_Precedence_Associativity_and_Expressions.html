2. What Is an Expression in C?

An expression is a combination of operands, operators and, where required, function calls that produces a value or designates an object.

Operands can be constants, variables or other expressions. Operators specify the operation to perform.

Examples

int a = 10;
int b = 5;

a + b       // Arithmetic expression
a > b       // Relational expression
a * b + 2   // Combined expression
a = b + 3   // Assignment expression

Expressions can be simple or complex. When multiple operators occur in one expression, precedence and associativity help determine how the expression is grouped.

Types of Expressions

Expression type Example Purpose
Arithmetic a + b * c Performs mathematical operations.
Relational a > b Compares two values.
Logical a > 0 && b > 0 Combines logical conditions.
Assignment a = 20 Assigns a value to an object.
Conditional a > b ? a : b Selects one of two expressions.
Bitwise a & b Performs bit-level operations.

3. Operator Precedence

Operator precedence determines how operators are grouped when an expression contains operators with different precedence levels.

An operator with higher precedence binds more tightly than an operator with lower precedence.

Example 1: Multiplication and Addition

int result = 10 + 5 * 2;

Multiplication has higher precedence than addition.

  1. 5 * 2 = 10
  2. 10 + 10 = 20
Result: 20

Example 2: Using Parentheses

int result = (10 + 5) * 2;
  1. Evaluate the parenthesized expression: 10 + 5 = 15.
  2. Multiply: 15 * 2 = 30.
Result: 30
Important: Parentheses can explicitly control grouping. They are useful for making complex expressions easier to read and less error-prone.

5. Operator Associativity

Associativity determines how operators of the same precedence are grouped when they appear consecutively in an expression.

Associativity is especially important when an expression contains multiple operators from the same precedence level.

5.1 Left-to-Right Associativity

Operators with left-to-right associativity are grouped from the left.

int result = 20 / 5 * 2;

Division and multiplication have equal precedence and left-to-right associativity.

  1. 20 / 5 = 4
  2. 4 * 2 = 8
Result: 8

5.2 Right-to-Left Associativity

Assignment operators have right-to-left associativity.

int a, b, c;

a = b = c = 10;

The expression is grouped as:

a = (b = (c = 10));

First, c receives 10. The assignment expression produces the assigned value, which is then assigned to b and finally to a.

Values:** a = 10, b = 10, c = 10

5.3 Associativity Does Not Mean Evaluation Order

Associativity determines grouping. It does not generally guarantee that the left operand is evaluated before the right operand.

For example, a + b + c is grouped as (a + b) + c. This grouping rule does not mean every operand or subexpression must be evaluated in a left-to-right sequence.

6. Evaluating Complex Expressions

To evaluate a complex expression correctly:

  1. Identify the operators and their precedence levels.
  2. Use parentheses to understand the grouping.
  3. Apply associativity when operators have equal precedence.
  4. Check operand types and integer or floating-point conversions.
  5. Check whether the expression has any undefined behavior.

Example 1

int result = 5 + 10 * 2 - 8 / 4;

Multiplication and division are evaluated within their respective groups before addition and subtraction.

  1. 10 * 2 = 20
  2. 8 / 4 = 2
  3. 5 + 20 - 2 = 23
Result: 23

Example 2

int result = 20 - 12 / 3 * 2;

Division and multiplication have equal precedence and left-to-right associativity.

  1. 12 / 3 = 4
  2. 4 * 2 = 8
  3. 20 - 8 = 12
Result: 12

Example 3: Relational and Logical Operators

int a = 10;
int b = 5;
int result = a > 5 && b < 10;
  1. a > 5 evaluates to 1.
  2. b < 10 evaluates to 1.
  3. 1 && 1 evaluates to 1.
Result: 1

Logical operators are covered in detail in the next lecture.

7. Parentheses and Expression Clarity

Parentheses explicitly specify the grouping of an expression. They are particularly useful when multiple operators are involved.

Expression Grouping
a + b * c a + (b * c)
(a + b) * c Addition is grouped first.
a - b - c (a - b) - c
a = b = c a = (b = c)
a < b == c (a < b) == c

Practical Example

#include <stdio.h>

int main(void)
{
    int a = 4;
    int b = 6;
    int c = 2;

    int result1 = a + b * c;
    int result2 = (a + b) * c;

    printf("Result 1 = %d\n", result1);
    printf("Result 2 = %d\n", result2);

    return 0;
}
Expected Output: 
Result 1 = 16
Result 2 = 20

8. Precedence vs Associativity vs Evaluation Order

These three concepts are frequently confused in technical interviews.

Concept Meaning Example
Precedence Determines grouping between operators of different precedence. a + b * c groups multiplication first.
Associativity Determines grouping between operators of equal precedence. a - b - c groups from the left.
Evaluation order Determines when operands and subexpressions are evaluated. f() + g() does not guarantee which function is called first.
Important C rule: Do not assume that an expression is evaluated from left to right simply because its operators have left-to-right associativity.

Example: Unspecified Operand Evaluation Order

int result = function1() + function2();

C does not specify which function call must happen first. If the functions have independent behavior, this may be acceptable. If their behavior depends on a particular order, the program must be redesigned.

Undefined Behavior Example

int i = 5;
int result = i++ + i++;
This expression modifies i more than once without the required sequencing between the modifications. Its behavior is undefined in C. Do not predict a numeric output for it.

Use separate statements when an operation depends on a previous modification:

int i = 5;

int first = i++;
int second = i++;

int result = first + second;
Values: 
first = 5
second = 6
result = 11
i = 7

9. Special Cases and Common Mistakes

9.1 Confusing Assignment and Equality

int a = 10;

if (a == 10)
{
    printf("Equal\n");
}

== compares two values, whereas = assigns a value.

9.2 Confusing Bitwise and Logical Operators

Operator Operation
& Bitwise AND
&& Logical AND
| Bitwise OR
|| Logical OR

9.3 Relational Chaining

Consider:

int x = 3;
int result = 1 < x < 5;

Relational operators have left-to-right associativity, so this expression is grouped as:

(1 < x) < 5
  1. 1 < 3 produces 1.
  2. 1 < 5 produces 1.

The expression therefore produces 1, but it does not test whether x lies between 1 and 5.

To check a range, use two comparisons joined by logical AND:
x > 1 && x < 5

9.4 Floating-Point Equality

Floating-point values may contain small representation and rounding errors. Direct equality comparisons can therefore be unreliable for many calculated values.

#include <stdio.h>
#include <math.h>

int main(void)
{
    double a = 0.1 + 0.2;
    double b = 0.3;

    if (fabs(a - b) < 1e-9)
    {
        printf("Approximately equal\n");
    }
    else
    {
        printf("Not equal\n");
    }

    return 0;
}
Expected Output: 
Approximately equal

The tolerance should be selected according to the scale and precision requirements of the application.

9.5 Integer Division

int result = 7 / 2;
Result: 3

Both operands are integers, so the fractional part is discarded. To perform floating-point division, at least one operand must be floating-point:

double result = 7.0 / 2;
Result: 3.5

9.6 Division by Zero and Overflow

  • Integer division or remainder by zero has undefined behavior.
  • Signed integer overflow has undefined behavior.
  • Do not assume an expression with undefined behavior has a predictable output.

10. Comma Operator

The comma operator evaluates its left operand, sequences that evaluation before the right operand, and produces the value of the right operand.

#include <stdio.h>

int main(void)
{
    int a;

    a = (5, 10, 15);

    printf("a = %d\n", a);

    return 0;
}
Expected Output: 
a = 15

The comma operator has the lowest precedence among C operators.

Important distinction: A comma used to separate function arguments or variable declarations is not necessarily the comma operator.

For example, printf("%d %d", a, b); uses commas as argument separators. They do not form a comma expression.

11. Complete C11 Program: Expression Evaluation

This program demonstrates precedence, associativity, relational expressions, logical expressions and the comma operator.

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 5;
    int c = 2;

    int result1 = a + b * c;
    int result2 = (a + b) * c;
    int result3 = a - b - c;
    int result4 = a > b;
    int result5 = (a > b) && (b > c);

    int x;
    x = (10, 20, 30);

    printf("Result 1 = %d\n", result1);
    printf("Result 2 = %d\n", result2);
    printf("Result 3 = %d\n", result3);
    printf("Result 4 = %d\n", result4);
    printf("Result 5 = %d\n", result5);
    printf("Comma result = %d\n", x);

    return 0;
}
Expected Output: 
Result 1 = 20
Result 2 = 30
Result 3 = 3
Result 4 = 1
Result 5 = 1
Comma result = 30

Program Explanation

Variable Expression Reason Value
result1 10 + 5 * 2 Multiplication first. 20
result2 (10 + 5) * 2 Parentheses first. 30
result3 10 - 5 - 2 Left-to-right grouping. 3
result4 10 > 5 True relational expression. 1
result5 (10 > 5) && (5 > 2) Both conditions are true. 1
x (10, 20, 30) Comma expression produces its final operand's value. 30

12. Common Technical Interview Questions

Q1. What is operator precedence in C?

Operator precedence determines how operators with different precedence levels are grouped in an expression.

Q2. What is associativity?

Associativity determines how operators of equal precedence are grouped when they occur consecutively.

Q3. What is the difference between precedence and associativity?

Precedence determines grouping between operators of different levels. Associativity determines grouping between operators of the same level.

Q4. What is the difference between associativity and evaluation order?

Associativity determines expression grouping. Evaluation order determines when operands or subexpressions are evaluated. Associativity does not generally guarantee evaluation order.

Q5. Which has higher precedence: multiplication or addition?

Multiplication has higher precedence than addition.

Q6. What is the associativity of assignment operators?

Assignment operators have right-to-left associativity.

Q7. What is the result of 20 / 5 * 2?

The result is 8 because division and multiplication have equal precedence and are grouped from left to right.

Q8. What is the result of 10 + 5 * 2?

The result is 20 because multiplication is grouped before addition.

Q9. What does the comma operator return?

It evaluates its left operand first and produces the value of its right operand.

Q10. Does C evaluate all expressions from left to right?

No. C does not guarantee left-to-right evaluation for all operands. The sequencing rules depend on the operators and constructs involved.

Q11. Why should parentheses be used in complex expressions?

They make grouping explicit, improve readability and reduce mistakes when interpreting expressions.

Q12. What is undefined behavior in expression evaluation?

It occurs when a program performs an operation for which the C standard imposes no requirements, such as signed integer overflow or certain unsequenced modifications of the same scalar object.

16. Placement Preparation: Practical Points

  • Memorize the relative precedence levels of arithmetic, shift, relational, equality, bitwise and logical operators.
  • Understand left-to-right and right-to-left associativity.
  • Practice evaluating expressions manually before executing the program.
  • Do not confuse expression grouping with operand evaluation order.
  • Understand why modifying the same variable multiple times without sequencing can produce undefined behavior.
  • Pay attention to integer division and implicit type conversions.
  • Use parentheses to make complex expressions unambiguous.
  • Be prepared to explain why a particular output is produced, not merely state the result.

17. Lecture Summary

  • An expression combines operands and operators to produce a value or designate an object.
  • Operator precedence determines how operators of different levels are grouped.
  • Associativity determines how operators of the same precedence are grouped.
  • Parentheses can explicitly control expression grouping.
  • Precedence and associativity do not generally determine operand evaluation order.
  • The assignment operator has right-to-left associativity.
  • The comma operator evaluates its left operand before its right operand and produces the right operand's value.
  • Incorrect assumptions about evaluation order can cause undefined behavior.
  • Complex expressions should be evaluated carefully, considering types and sequencing rules.
Placement Tip: Expression evaluation and operator precedence are common subjects in C technical interviews and output-prediction rounds. Focus on understanding the rules rather than memorizing individual answers.
