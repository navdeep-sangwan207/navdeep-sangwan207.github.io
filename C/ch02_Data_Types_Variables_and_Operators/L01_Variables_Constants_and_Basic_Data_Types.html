Chapter 2: Data Types, Variables and Operators

Lecture 1: Variables, Constants and Basic Data Types

Learn how to declare variables, store values, define constants and select appropriate data types in C.

1. Learning Objectives

After completing this lecture, you will be able to:

  • Explain variables and their role in C programs.
  • Declare and initialize variables correctly.
  • Follow C identifier naming rules.
  • Understand fundamental data types in C.
  • Differentiate variables from constants.
  • Use const and symbolic constants appropriately.
  • Avoid common declaration and initialization errors.

2. What Is a Variable?

A variable is a named object used by a C program to store a value that can be accessed and, when permitted, modified during program execution.

Every variable has a data type. The type determines the kind of value the object can represent and how the program accesses it.

Example

#include <stdio.h>

int main(void)
{
    int age = 25;

    printf("Age = %d\n", age);

    age = 26;

    printf("Updated age = %d\n", age);

    return 0;
}
Expected Output 
Age = 25
Updated age = 26

In this program:

  • int specifies the data type.
  • age is the variable name.
  • 25 is the initial value.
  • age = 26; assigns a new value.
A variable is not necessarily a fixed physical memory address visible to the programmer. The compiler and implementation determine how an object is represented and stored.

3. Variable Declaration

Declaration introduces a variable and specifies its type. A basic variable declaration follows this syntax: 

data_type variable_name;

Examples

int age;
float temperature;
double distance;
char grade;
_Bool is_valid;

Multiple variables of the same type can be declared together:

int first_number, second_number, result;
float height, weight;

Declaration and Initialization Together

int age = 25;
float temperature = 36.5f;
double salary = 45000.75;
char grade = 'A';

Declaration introduces the object. Initialization provides its initial value as part of its definition.

4. Rules for Naming Variables

Variable names are identifiers. C follows specific rules for forming valid identifiers.

Valid Naming Rules

  • An identifier can contain letters, digits and underscores.
  • The first character must be a letter or underscore.
  • An identifier cannot begin with a digit.
  • Keywords cannot be used as identifiers.
  • Identifiers are case-sensitive.
  • Spaces and special characters such as @ and # are not allowed.

Examples

Identifier Validity Reason
total Valid Contains letters only.
student_age Valid Underscore is permitted.
value2 Valid Digits are permitted after the first character.
_count Valid Begins with an underscore.
2value Invalid Begins with a digit.
student name Invalid Contains a space.
float Invalid It is a C keyword.
total-cost Invalid Hyphen is not permitted.
Although identifiers beginning with an underscore can be valid, many underscore-prefixed names are reserved to the implementation in particular scopes. Prefer descriptive names such as total_count in application code.

Case Sensitivity

int value = 10;
int Value = 20;
int VALUE = 30;

These are three different identifiers in C because uppercase and lowercase letters are treated differently.

5. Variable Initialization and Assignment

Initialization gives an object its initial value when it is defined. Assignment stores a value in an already existing modifiable object.

Initialization

int number = 100;

Assignment

int number;
number = 100;
number = 200;

Different Initialization Styles

int first = 10;       // Ordinary initialization
int second(10);       // Not valid C syntax
int third = {10};     // Valid C initialization
int fourth = {0};     // Valid zero initialization
C does not support C++-style direct initialization such as int second(10);. Use assignment-style or brace initialization in C.

Uninitialized Variables

#include <stdio.h>

int main(void)
{
    int number;

    /* Do not read number before assigning a value. */

    number = 50;

    printf("Number = %d\n", number);

    return 0;
}

An uninitialized automatic local variable has an indeterminate value. Reading it before assigning a valid value is not safe and can result in undefined behavior.

Never assume that an uninitialized local variable automatically contains zero.

Automatic and Static Initialization

Object Default initialization behavior
Uninitialized automatic local variable Has an indeterminate value.
Uninitialized static local variable Zero-initialized.
Uninitialized global variable Zero-initialized because it has static storage duration.

6. What Is a Data Type?

A data type specifies the kind of value an object can represent and determines the operations that can be performed on it.

For example, an integer variable stores integer values, while a floating-point variable represents values that may contain fractional parts.

Fundamental Data Types in C

Data Type Purpose Example
char Stores a character value and is also an integer type. 'A'
int Represents integer values. 100
float Represents floating-point values. 12.5f
double Represents floating-point values with at least the precision of float. 125.75
_Bool Represents Boolean values 0 and 1. 1
void Represents the absence of a value or an incomplete object type. void function(void)
C11 also provides complex and imaginary arithmetic types through its language features and headers. This course first focuses on the fundamental types most frequently used in general C programming and placement interviews.

7. Integer Data Type

The int type is used to represent integer values without a fractional component.

Example

#include <stdio.h>

int main(void)
{
    int age = 25;
    int quantity = 150;
    int temperature = -5;

    printf("Age = %d\n", age);
    printf("Quantity = %d\n", quantity);
    printf("Temperature = %d\n", temperature);

    return 0;
}
Expected Output 
Age = 25
Quantity = 150
Temperature = -5

The exact size and range of int depend on the C implementation. Do not assume that every system uses exactly four bytes.

Integer type modifiers and integer ranges are covered in Lecture 3.

8. Floating-Point Data Types

Floating-point types represent values that can contain fractional parts.

float

float temperature = 36.5f;

double

double distance = 12345.6789;

Example Program

#include <stdio.h>

int main(void)
{
    float temperature = 36.5f;
    double distance = 12345.6789;

    printf("Temperature = %.1f\n", temperature);
    printf("Distance = %.4f\n", distance);

    return 0;
}
Expected Output 
Temperature = 36.5
Distance = 12345.6789

Floating-point values are approximations of real numbers in many cases. Some decimal fractions cannot be represented exactly in binary floating-point.

A floating-point literal such as 3.14 has type double by default. Use the suffix f or F to make it a float literal.

9. Character Data Type

The char type is used to store character values. A character constant is written inside single quotation marks.

Example

#include <stdio.h>

int main(void)
{
    char grade = 'A';
    char symbol = '#';

    printf("Grade = %c\n", grade);
    printf("Symbol = %c\n", symbol);

    return 0;
}
Expected Output 
Grade = A
Symbol = #

Character and Integer Relationship

In C, char is an integer type. Character constants have integer type, and character values can be used in arithmetic expressions. 

#include <stdio.h>

int main(void)
{
    char ch = 'A';

    printf("Character = %c\n", ch);
    printf("Integer value = %d\n", ch);

    return 0;
}

On an ASCII-compatible implementation, the output is: 

Character = A
Integer value = 65
The numeric value 65 for 'A' is specific to ASCII-compatible character sets. C does not require every implementation to use ASCII. Also, whether plain char behaves as signed or unsigned is implementation-defined.

10. Boolean Values in C

C11 provides the _Bool type for representing Boolean values.

  • 0 represents false.
  • 1 represents true.
  • When a value is converted to _Bool, zero becomes 0 and any nonzero value becomes 1.

Example Using _Bool

#include <stdio.h>

int main(void)
{
    _Bool is_valid = 1;
    _Bool is_complete = 0;

    printf("Valid = %d\n", is_valid);
    printf("Complete = %d\n", is_complete);

    return 0;
}
Expected Output 
Valid = 1
Complete = 0

Using bool, true and false

C11 also supports the familiar names bool, true and false through the <stdbool.h> header. 

#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    bool is_active = true;
    bool is_error = false;

    printf("Active = %d\n", is_active);
    printf("Error = %d\n", is_error);

    return 0;
}
Expected Output 
Active = 1
Error = 0

11. What Is a Constant?

A constant is a value that is not intended to change during program execution. C provides several ways to represent constant values.

Types of Constants

Constant Type Example
Integer constant 100
Floating-point constant 3.14
Character constant 'A'
String literal "Hello"

Example

#include <stdio.h>

int main(void)
{
    int count = 100;
    float price = 25.50f;
    char grade = 'A';

    printf("Count = %d\n", count);
    printf("Price = %.2f\n", price);
    printf("Grade = %c\n", grade);

    return 0;
}

12. Using const Keyword

The const qualifier makes an object non-modifiable through that particular const-qualified access.

Syntax

const data_type variable_name = value;

Example

#include <stdio.h>

int main(void)
{
    const float PI = 3.14159f;
    float radius = 5.0f;

    float area = PI * radius * radius;

    printf("Area = %.2f\n", area);

    return 0;
}
Expected Output 
Area = 78.54

The following modification is not permitted: 

const int limit = 100;

/* Invalid: attempts to modify a const object. */
limit = 200;
A const-qualified object is not automatically a C compile-time constant expression. For example, a block-scope const int generally cannot be used as the size of a standard C11 array requiring an integer constant expression.

13. Symbolic Constants Using #define

The preprocessor directive #define creates a macro. A simple object-like macro is often used to give a meaningful name to a constant value.

Syntax

#define NAME replacement_value

Example

#include <stdio.h>

#define MAX_STUDENTS 60
#define PI 3.14159

int main(void)
{
    double radius = 4.0;
    double area = PI * radius * radius;

    printf("Maximum students = %d\n", MAX_STUDENTS);
    printf("Area = %.2f\n", area);

    return 0;
}
Expected Output 
Maximum students = 60
Area = 50.27

Unlike a variable, a simple macro does not create a typed object. The preprocessor performs textual replacement before compilation.

14. Difference Between Variable and Constant

Variable Constant
Stores a value that can be modified when permitted. Represents a value that should not be modified.
Can be declared without an initializer in some contexts. const-qualified objects generally need initialization when defined.
Example: int count = 10; Example: const int limit = 100;
Assignment can change its stored value. Assignment through a const-qualified object is not permitted.

Difference Between const and #define

const #define
Uses the C type system. Uses preprocessor text substitution.
Defines a qualified object. Defines a macro replacement.
Follows C scope and declaration rules. Macro replacement is controlled by preprocessing directives.
Example: const int MAX = 100; Example: #define MAX 100

15. Complete Practical Program

The following program combines variables, different fundamental data types and constants in a simple student information example. 

#include <stdio.h>
#include <stdbool.h>

#define PASS_MARKS 40

int main(void)
{
    int roll_number = 101;
    char grade = 'A';
    float percentage = 85.5f;
    double attendance = 92.75;
    bool passed = true;

    const int maximum_marks = 100;

    printf("Student Information\n");
    printf("-------------------\n");

    printf("Roll Number: %d\n", roll_number);
    printf("Grade: %c\n", grade);
    printf("Percentage: %.2f%%\n", percentage);
    printf("Attendance: %.2f%%\n", attendance);
    printf("Passed: %d\n", passed);
    printf("Maximum Marks: %d\n", maximum_marks);
    printf("Pass Marks: %d\n", PASS_MARKS);

    return 0;
}
Expected Output 
Student Information
-------------------
Roll Number: 101
Grade: A
Percentage: 85.50%
Attendance: 92.75%
Passed: 1
Maximum Marks: 100
Pass Marks: 40

Program Explanation

  • int stores the student's roll number.
  • char stores the grade.
  • float stores the percentage.
  • double stores attendance percentage.
  • bool represents whether the student passed.
  • const defines a non-modifiable object.
  • #define creates the symbolic macro PASS_MARKS.

16. Common Programming Mistakes

Mistake Problem Correction
int 2value; Identifier begins with a digit. int value2;
int float; float is a keyword. int float_value;
char grade = "A"; Uses a string literal instead of a character constant. char grade = 'A';
int count; printf("%d", count); Reads an uninitialized automatic variable. Initialize count before reading it.
const int x = 10; x = 20; Attempts to modify a const-qualified object. Use a modifiable variable if reassignment is required.
float value = 3.14; Double literal is converted to float. Use 3.14f when a float literal is intended.

17. Technical Interview Questions

Q1. What is a variable in C?
A variable is a named object that stores a value of a specified type. Its value can be modified when the object is not const-qualified.
Q2. What is the difference between declaration and initialization?
Declaration introduces an identifier and specifies its type. Initialization provides the initial value when the object is defined.
Q3. What happens when a local variable is not initialized?
An uninitialized automatic local variable has an indeterminate value. Reading it before assigning a valid value is unsafe and can result in undefined behavior.
Q4. Is C case-sensitive?
Yes. Identifiers such as count, Count and COUNT are different.
Q5. What is the difference between float and double?
Both represent floating-point values. double has at least as much precision as float, and commonly provides greater precision and range. Exact representation characteristics depend on the implementation.
Q6. Is char an integer data type?
Yes. char is an integer type in C. It can represent character values and participates in integer promotions. Plain char may be signed or unsigned depending on the implementation.
Q7. What is the difference between const and #define?
const qualifies a typed object, whereas #define creates a preprocessor macro that performs textual replacement.
Q8. Does const mean that a variable is stored in ROM?
No. const restricts modification through a const-qualified access. It does not guarantee a particular physical memory location or storage technology.
Q9. What is the difference between 'A' and "A"?
'A' is an integer character constant. "A" is a string literal containing the character A followed by a terminating null character.
Q10. Does C automatically initialize global variables to zero?
Yes. Objects with static storage duration that are not explicitly initialized are zero-initialized.
