2. Introduction to Logical Operators

Logical operators are used to combine or reverse conditions. They are commonly used in if statements, loops and decision-making expressions.

OperatorNamePurpose
&&Logical ANDTrue only when both operands are true.
||Logical ORTrue when at least one operand is true.
!Logical NOTReverses the truth value of an operand.
In C, zero represents false and any nonzero scalar value represents true when used as a condition. Logical operators produce an int result of either 0 or 1.

3. Logical AND Operator (&&)

The logical AND operator returns 1 only when both operands are nonzero. Otherwise, it returns 0.

Truth Table

ABA && B
000
010
100
111

Example

#include <stdio.h>

int main(void)
{
    int age = 25;
    int has_id = 1;

    if (age >= 18 && has_id == 1)
        printf("Entry allowed\n");
    else
        printf("Entry denied\n");

    return 0;
}
Entry allowed

Both conditions must be true for the entry to be allowed.

4. Logical OR Operator (||)

The logical OR operator returns 1 when at least one operand is nonzero. It returns 0 only when both operands are zero.

Truth Table

ABA || B
000
011
101
111

Example

#include <stdio.h>

int main(void)
{
    int is_weekend = 1;
    int is_holiday = 0;

    if (is_weekend || is_holiday)
        printf("Day off\n");
    else
        printf("Working day\n");

    return 0;
}
Day off

Either condition being true is sufficient.

5. Logical NOT Operator (!)

The logical NOT operator reverses the truth value: a true operand becomes 0, and a false operand becomes 1.

A!A
01
10

Example

#include <stdio.h>

int main(void)
{
    int is_logged_in = 0;

    if (!is_logged_in)
        printf("Please log in\n");
    else
        printf("Welcome\n");

    return 0;
}
Please log in

6. Combining Multiple Conditions

Logical operators can be combined to implement real-world decision rules.

Example: Eligibility Check

#include <stdio.h>

int main(void)
{
    int age;
    int marks;

    printf("Enter age and marks: ");

    if (scanf("%d %d", &age, &marks) != 2)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (age >= 18 && marks >= 60)
        printf("Eligible\n");
    else
        printf("Not eligible\n");

    return 0;
}
Sample Input 
21 75
Expected Output 
Eligible

Both conditions must be satisfied.

7. Short-Circuit Evaluation

C uses short-circuit evaluation for the logical AND and logical OR operators. The second operand is not evaluated when its value cannot change the result.

Short-Circuit AND

If the first operand of && is false, the second operand is not evaluated. 

#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 10;

    if (a != 0 && b / a > 1)
        printf("Condition true\n");
    else
        printf("Condition false\n");

    return 0;
}
Condition false

Since a != 0 is false, the division b / a is not evaluated. This avoids integer division by zero.

Short-Circuit OR

If the first operand of || is true, the second operand is not evaluated. 

#include <stdio.h>

int main(void)
{
    int a = 1;
    int b = 0;

    if (a != 0 || b / a > 1)
        printf("Condition true\n");

    return 0;
}
Condition true
Short-circuit evaluation is particularly important when checking pointers, array indexes, divisors and other values that must be validated before use.

8. Difference Between Logical and Bitwise Operators

Logical and bitwise operators use different rules. Do not confuse && with &, or || with |.

Logical OperatorBitwise OperatorDifference
&& & Logical AND evaluates truth values and short-circuits. Bitwise AND operates on integer bits.
|| | Logical OR evaluates truth values and short-circuits. Bitwise OR operates on integer bits.
! ~ Logical NOT reverses truth. Bitwise complement reverses integer bits.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 3;

    printf("Logical AND = %d\n", a && b);
    printf("Bitwise AND = %d\n", a & b);

    return 0;
}
Logical AND = 1
Bitwise AND = 1

Both operands are nonzero, so logical AND gives 1. Their binary representations are 0101 and 0011; bitwise AND produces 0001, which is decimal 1.

9. Assignment Operator (=)

The assignment operator stores the value of an expression in a modifiable object. 

int number;

number = 100;

The variable number receives the value 100.

Assignment Expression

int a, b;

a = b = 20;

Assignment operators associate from right to left. The value 20 is assigned to b, and then the resulting value is assigned to a.

Example

#include <stdio.h>

int main(void)
{
    int a, b;

    a = b = 20;

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}
a = 20
b = 20

10. Compound Assignment Operators

Compound assignment operators combine an operation with assignment. They provide a shorter way to update the value of a variable.

OperatorEquivalent FormMeaning
+=a = a + bAdd and assign
-=a = a - bSubtract and assign
*=a = a * bMultiply and assign
/=a = a / bDivide and assign
%=a = a % bRemainder and assign
&=a = a & bBitwise AND and assign
|=a = a | bBitwise OR and assign
^=a = a ^ bBitwise XOR and assign
<<=a = a << bLeft shift and assign
>>=a = a >> bRight shift and assign

Example: Arithmetic Compound Assignment

#include <stdio.h>

int main(void)
{
    int a = 10;

    a += 5;
    printf("After += : %d\n", a);

    a -= 3;
    printf("After -= : %d\n", a);

    a *= 2;
    printf("After *= : %d\n", a);

    a /= 4;
    printf("After /= : %d\n", a);

    a %= 3;
    printf("After %%= : %d\n", a);

    return 0;
}
After += : 15
After -= : 12
After *= : 24
After /= : 6
After %= : 0

11. Important Difference: Compound Assignment and Simple Assignment

Compound assignment evaluates its left operand only once. This can matter when the left operand is an expression with side effects.

For ordinary variables, these forms are commonly equivalent: 

a += 5;
a = a + 5;

However, compound assignment also performs the conversion back to the type of the left operand.

Example

#include <stdio.h>

int main(void)
{
    int a = 5;

    a *= 2 + 3;

    printf("%d\n", a);

    return 0;
}
25

The expression on the right is evaluated as 2 + 3, and then a is multiplied by 5.

12. Practical Program: Validate a Login Condition

Use logical AND and NOT to check whether a user has entered the correct credentials. 

#include <stdio.h>

int main(void)
{
    int entered_id;
    int entered_pin;

    const int correct_id = 1001;
    const int correct_pin = 4321;

    printf("Enter ID and PIN: ");

    if (scanf("%d %d", &entered_id, &entered_pin) != 2)
    {
        printf("Invalid input\n");
        return 1;
    }

    if (entered_id == correct_id &&
        entered_pin == correct_pin)
    {
        printf("Login successful\n");
    }
    else
    {
        printf("Invalid credentials\n");
    }

    return 0;
}
Sample Input 
1001 4321
Expected Output 
Login successful

13. Practical Program: Update an Account Balance

Use compound assignment operators to update an account balance after deposits and withdrawals. 

#include <stdio.h>

int main(void)
{
    double balance = 5000.0;
    double deposit = 1500.0;
    double withdrawal = 1000.0;

    balance += deposit;
    balance -= withdrawal;

    printf("Final balance = %.2f\n", balance);

    return 0;
}
Final balance = 5500.00

14. Common Mistakes and Important Rules

Incorrect UnderstandingCorrect Rule
Using & instead of && for logical conditions.Use logical AND for combining conditions.
Assuming both operands always execute.Logical AND and OR use short-circuit evaluation.
Using ! as bitwise complement.! is logical NOT; ~ is bitwise complement.
Confusing = and ==.Assignment and equality comparison are different operations.
Assuming compound assignment is identical in every context to a simple rewrite.Compound assignment evaluates the left operand only once and converts the result back to its type.
Writing complex expressions with multiple modifications of the same variable.Use separate statements to make evaluation well-defined and clear.

15. Technical Interview Questions

Q1. What are logical operators in C?
Logical operators combine or reverse conditions. The three operators are &&, || and !.
Q2. What is the result of a logical expression?
It produces an int value: 1 for true and 0 for false.
Q3. What is short-circuit evaluation?
It means the second operand is skipped when the first operand already determines the result of a logical AND or OR expression.
Q4. What is the difference between && and &?
&& is logical AND and uses short-circuit evaluation. & is bitwise AND for integer operands.
Q5. What is the difference between || and |?
|| is logical OR and uses short-circuit evaluation. | is bitwise OR for integer operands.
Q6. What is the purpose of the logical NOT operator?
It reverses the truth value of an operand.
Q7. What is an assignment operator?
It stores the value of an expression in a modifiable object.
Q8. What are compound assignment operators?
They combine an operation and assignment, such as +=, -=, *=, /= and %=.
Q9. Why is short-circuit evaluation useful?
It can prevent unsafe expressions from being evaluated, such as checking a divisor before division or checking a pointer before dereferencing it.
Q10. Does C have a separate Boolean type?
C99 and later provide the _Bool type. C11 also provides bool through the <stdbool.h> header. Logical operators still produce int results.
Q11. What is the difference between a = b and a += b?
a = b replaces a with b. a += b adds b to the current value of a and stores the result in a.
Q12. Can assignment operators be chained?
Yes. Assignment operators associate from right to left, so a = b = 10 assigns 10 to both variables.
