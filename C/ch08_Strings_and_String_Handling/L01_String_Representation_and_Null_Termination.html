Lecture 1: String Representation and Null Termination

Understand how strings are represented in C using character arrays, how the null character marks the end of a string, and how string memory is organized.

1. Learning Objectives

  • Understand the meaning of a string in C.
  • Understand the relationship between strings and character arrays.
  • Learn the role of the null character '\0'.
  • Understand how strings occupy memory.
  • Differentiate string length and array capacity.
  • Identify valid and invalid string representations.
  • Understand common null-termination errors.
  • Analyze basic string-related output questions.

2. What Is a String in C?

A string in C is a sequence of characters terminated by a special character called the null character.

Unlike some other programming languages, C does not provide a separate built-in string data type. Strings are represented using arrays of characters.

Example

char name[] = "HELLO";

This declaration creates a character array containing the characters H, E, L, L, O followed by the null character. 

Index:       0    1    2    3    4    5

Character:   H    E    L    L    O   '\0'
The null character tells string-processing functions where the string ends.

3. Understanding the Null Character

The null character is written as: 

'\0'

Its value is zero. It marks the end of a C string.

A null character is not the same as the character digit '0'.

Representation Meaning Value
'\0' Null character 0
'0' Character digit zero 48 in ASCII
0 Integer zero 0

The numeric value 48 for '0' is the ASCII value, which is also the value on common ASCII-compatible C implementations.

Example Program

#include <stdio.h>

int main(void)
{
    char text[] = {'C', 'O', 'D', 'E', '\0'};

    printf("%s\n", text);

    return 0;
}
Expected Output: 
CODE

4. Character Array vs String

Every C string is stored in a character array or another suitable character sequence, but not every character array is necessarily a valid string.

Character Array

char data[4] = {'C', 'O', 'D', 'E'};

This array contains four characters but no null terminator. Therefore, it is not a valid C string.

Valid String

char data[5] = {'C', 'O', 'D', 'E', '\0'};

This array contains four visible characters and one terminating null character.

Passing a non-null-terminated character array to functions such as printf with the %s format specifier can cause undefined behavior.

5. String Declaration and Memory Representation

Consider the following declaration: 

char name[] = "CAT";

The compiler allocates enough storage for the characters and the terminating null character.

Index Stored Character Purpose
0 'C' First character
1 'A' Second character
2 'T' Third character
3 '\0' String terminator

The array has four elements, even though the visible string length is three.

6. String Length vs Array Capacity

These two concepts are important in C programming.

  • String length: Number of characters before '\0'.
  • Array capacity: Total number of elements allocated in the array.

Example

char city[20] = "DELHI";
Property Value
Visible characters 5
String length 5
Array capacity 20 characters
Null terminator position Index 5
Remaining array elements 14

The remaining elements are initialized to zero because the array has an initializer and unspecified elements are zero-initialized.

7. String Initialization Methods

Method 1: String Literal

char name[] = "RAHUL";

The compiler automatically includes the terminating null character.

Method 2: Character-by-Character Initialization

char name[] = {'R', 'A', 'H', 'U', 'L', '\0'};

The programmer explicitly provides the null character.

Method 3: Fixed-Size Array

char name[10] = "RAHUL";

The array has ten elements. The remaining elements are zero-initialized.

This declaration does not provide enough storage: 
char name[5] = "RAHUL";
Five visible characters require six array elements when the terminating null character is included.

8. The Difference Between '\0' and '\n'

Both are escape sequences, but they perform different functions.

Escape Sequence Meaning
'\0' Null character; terminates a C string.
'\n' Newline character; moves output to the next line.
'\t' Horizontal tab character.
'\\' Backslash character.

Example

#include <stdio.h>

int main(void)
{
    char text[] = "HELLO\nWORLD";

    printf("%s", text);

    return 0;
}
Expected Output: 
HELLO
WORLD

The newline character is part of the string. It does not terminate the string.

9. String Traversal and Null Termination

A string can be traversed one character at a time until the null character is encountered.

Example Program

#include <stdio.h>

int main(void)
{
    char name[] = "EMBEDDED";

    int i = 0;

    while (name[i] != '\0')
    {
        printf("%c\n", name[i]);

        i++;
    }

    return 0;
}
Expected Output: 
E
M
B
E
D
D
E
D

The loop stops when it reaches '\0'. This is the basic mechanism used in many C string-processing operations.

10. String Literals and Character Arrays

A string literal can initialize a character array: 

char message[] = "HELLO";

In this case, the array contains a modifiable copy of the literal's characters.

A pointer can also refer to a string literal: 

const char *message = "HELLO";

The pointer refers to a string literal. The const qualifier prevents modification through this pointer.

Do not attempt to modify a string literal. Modifying a string literal has undefined behavior. Use a character array when the contents must be changed.

11. Common Null-Termination Errors

Error 1: Missing Null Character

char text[3] = {'C', 'A', 'T'};

This is a character array, not a null-terminated string.

Error 2: Insufficient Array Capacity

char name[4] = "CODE";

Four visible characters need five elements when the null character is included.

Error 3: Writing Beyond Array Bounds

char name[5] = "CAT";

name[5] = '\0';

Valid indexes are 0 through 4. Index 5 is outside the array.

Error 4: Overwriting the Terminator

char name[] = "CAT";

name[3] = 'X';

This replaces the terminating null character. The array no longer contains a valid null-terminated string.

12. Output Prediction and Interview Questions

Question 1

#include <stdio.h>

int main(void)
{
    char text[] = "C";

    printf("%zu\n", sizeof(text));

    return 0;
}
Answer: 
2
The array contains 'C' and '\0'.

Question 2

#include <stdio.h>

int main(void)
{
    char text[] = {'A', 'B', '\0', 'C'};

    printf("%s\n", text);

    return 0;
}
Answer: 
AB
String processing stops at the first null character.

Question 3

#include <stdio.h>

int main(void)
{
    char text[8] = "HELLO";

    printf("%zu\n", sizeof(text));

    return 0;
}
Answer: 
8
sizeof reports the total array capacity in bytes. A char occupies one byte in C.

13. Coding Practice

  1. Declare a character array and initialize it as a valid string.
  2. Store a string using individual character initialization.
  3. Print every character of a string using a loop.
  4. Count the characters until the null terminator is reached.
  5. Display the ASCII-compatible integer values of each character.
  6. Demonstrate the difference between array capacity and string length.
  7. Write a program that checks whether a character array contains a null terminator within its capacity.
For the final practice problem, use a bounded loop that checks only valid array indexes. Do not read beyond the allocated array.

14. Lecture Summary

  • C strings are represented using character sequences.
  • A valid C string ends with the null character '\0'.
  • The null character occupies one array element.
  • String length excludes the terminating null character.
  • Array capacity includes all allocated elements.
  • A character array without a null terminator is not automatically a string.
  • String literals must not be modified.
  • Incorrect null termination can cause undefined behavior.
