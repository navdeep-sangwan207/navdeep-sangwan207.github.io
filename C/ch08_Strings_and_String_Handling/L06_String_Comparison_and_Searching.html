Lecture 6: String Comparison and Searching

Learn how to compare strings, identify matching characters, search for substrings and implement basic searching algorithms using C11.

1. Learning Objectives

  • Understand lexicographical string comparison.
  • Compare strings using strcmp() and strncmp().
  • Understand case-sensitive string comparison.
  • Implement string comparison manually.
  • Search for characters using strchr() and strrchr().
  • Search for substrings using strstr().
  • Implement character and substring searching manually.
  • Understand basic string-matching algorithms.
  • Solve placement-oriented comparison and searching problems.

2. Understanding String Comparison

String comparison determines whether two strings are equal or which string comes first according to lexicographical ordering.

Examples

String 1 String 2 Relationship
APPLE APPLE Equal
APPLE BANANA APPLE compares less
CAT CAR CAT compares greater
HELLO HELLO123 HELLO compares less

Comparison proceeds character by character until a difference is found or both strings reach their null terminators.

3. strcmp() – Comparing Complete Strings

strcmp() compares two null-terminated strings lexicographically.

Syntax

int strcmp(const char *str1, const char *str2);

Return Values

Result Meaning
0 Both strings are equal.
Less than 0 The first string compares less than the second.
Greater than 0 The first string compares greater than the second.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[] = "APPLE";
    char second[] = "BANANA";

    int result = strcmp(first, second);

    if (result == 0)
    {
        printf("Strings are equal.\n");
    }
    else if (result < 0)
    {
        printf("First string is smaller.\n");
    }
    else
    {
        printf("First string is greater.\n");
    }

    return 0;
}
Expected Output: 
First string is smaller.
Do not assume strcmp() returns exactly -1 or 1. Only the sign of a nonzero return value is guaranteed to indicate the comparison result.

4. How Lexicographical Comparison Works

Consider the following strings: 

String 1:  COMPUTER
String 2:  COMPANY

The comparison proceeds character by character:

Position String 1 String 2 Result
0 C C Equal
1 O O Equal
2 M M Equal
3 P P Equal
4 U A Different

The comparison is determined at the first differing character. For the basic execution character set, uppercase letters have increasing character codes from A through Z.

Lexicographical comparison is based on character values, not on dictionary meaning or string length alone.

5. strncmp() – Comparing a Limited Number of Characters

strncmp() compares at most n characters of two strings.

Syntax

int strncmp(const char *str1,
            const char *str2,
            size_t n);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[] = "EMBEDDED";
    char second[] = "EMBED";

    if (strncmp(first, second, 5) == 0)
    {
        printf("First five characters match.\n");
    }
    else
    {
        printf("First five characters do not match.\n");
    }

    return 0;
}
Expected Output: 
First five characters match.

strncmp() is useful when only a fixed prefix needs to be compared, such as checking a command name or protocol prefix.

6. Case-Sensitive String Comparison

Standard strcmp() comparison is case-sensitive. Uppercase and lowercase characters are treated as different character values.

Example

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[] = "Linux";
    char second[] = "LINUX";

    if (strcmp(first, second) == 0)
    {
        printf("Strings are equal.\n");
    }
    else
    {
        printf("Strings are different.\n");
    }

    return 0;
}
Expected Output: 
Strings are different.

Case-Insensitive Comparison Using Standard C

C11 does not provide a universally available standard strcmp_ignore_case() function. A portable approach is to convert characters to a common case before comparing them. 

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int equal_ignore_case(const char *a, const char *b)
{
    while (*a != '\0' && *b != '\0')
    {
        unsigned char ca = (unsigned char)*a;
        unsigned char cb = (unsigned char)*b;

        if (tolower(ca) != tolower(cb))
        {
            return 0;
        }

        a++;
        b++;
    }

    return *a == '\0' && *b == '\0';
}

int main(void)
{
    char first[] = "Linux";
    char second[] = "LINUX";

    if (equal_ignore_case(first, second))
    {
        printf("Strings match ignoring case.\n");
    }
    else
    {
        printf("Strings are different.\n");
    }

    return 0;
}
Expected Output: 
Strings match ignoring case.
The unsigned char conversion before calling tolower() is important. The ctype functions require either EOF or a value representable as unsigned char.

7. Manual Implementation of strcmp()

String comparison can be implemented without using strcmp().

Algorithm

  1. Start at the first character of both strings.
  2. Compare the corresponding characters.
  3. If they differ, return their difference.
  4. If both are equal to '\0', the strings are equal.
  5. Otherwise, move to the next character.

Program

#include <stdio.h>

int compare_strings(const char *a, const char *b)
{
    while (*a == *b)
    {
        if (*a == '\0')
        {
            return 0;
        }

        a++;
        b++;
    }

    return (unsigned char)*a - (unsigned char)*b;
}

int main(void)
{
    char first[] = "APPLE";
    char second[] = "APRICOT";

    int result = compare_strings(first, second);

    if (result == 0)
    {
        printf("Strings are equal.\n");
    }
    else if (result < 0)
    {
        printf("First string is smaller.\n");
    }
    else
    {
        printf("First string is greater.\n");
    }

    return 0;
}
Expected Output: 
First string is smaller.

The implementation compares characters as unsigned char values, consistent with the requirements for byte-based string comparison.

Complexity

  • Time complexity: O(n) in the worst case.
  • Auxiliary space: O(1).

8. Searching for a Character Using strchr()

strchr() searches for the first occurrence of a specified character in a string.

Syntax

char *strchr(const char *str, int character);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    char *result = strchr(str, 'G');

    if (result != NULL)
    {
        printf("Character found: %c\n", *result);
        printf("Position: %td\n", result - str);
    }
    else
    {
        printf("Character not found.\n");
    }

    return 0;
}
Expected Output: 
Character found: G
Position: 3

strchr() returns a pointer to the first matching character. If the character is not found, it returns NULL.

9. Searching for the Last Character Using strrchr()

strrchr() searches for the last occurrence of a specified character.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    char *result = strrchr(str, 'M');

    if (result != NULL)
    {
        printf("Last occurrence position: %td\n",
               result - str);
    }
    else
    {
        printf("Character not found.\n");
    }

    return 0;
}
Expected Output: 
Last occurrence position: 8

The position is zero-based. The first M is at index 6 and the last M is at index 8.

10. Searching for a Substring Using strstr()

strstr() searches for the first occurrence of one string inside another.

Syntax

char *strstr(const char *main_string,
             const char *substring);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "Embedded C Programming";

    char *result = strstr(text, "C Programming");

    if (result != NULL)
    {
        printf("Substring found.\n");
        printf("Position: %td\n", result - text);
    }
    else
    {
        printf("Substring not found.\n");
    }

    return 0;
}
Expected Output: 
Substring found.
Position: 10

strstr() returns a pointer to the beginning of the first matching substring, or NULL if no match is found.

An empty substring is considered to match at the beginning of the main string.

11. Manual Character Searching

Character searching can be implemented by traversing the string and checking each character against the target.

Program: Find the First Occurrence

#include <stdio.h>

int main(void)
{
    char str[] = "MICROCONTROLLER";
    char target = 'O';

    int i = 0;
    int position = -1;

    while (str[i] != '\0')
    {
        if (str[i] == target)
        {
            position = i;
            break;
        }

        i++;
    }

    if (position != -1)
    {
        printf("Character found at index %d\n", position);
    }
    else
    {
        printf("Character not found.\n");
    }

    return 0;
}
Expected Output: 
Character found at index 6

This is a linear search through the string.

Complexity

  • Time complexity: O(n).
  • Auxiliary space: O(1).

12. Manual Substring Searching

A substring search can be implemented by checking whether the pattern matches at each possible starting position in the main string.

Example

Main string:  EMBEDDED SYSTEMS

Pattern:      SYSTEMS

Result:       Match found

Program: Naive Substring Search

#include <stdio.h>
#include <string.h>

int find_substring(const char *text, const char *pattern)
{
    size_t text_length = strlen(text);
    size_t pattern_length = strlen(pattern);

    if (pattern_length == 0)
    {
        return 0;
    }

    if (pattern_length > text_length)
    {
        return -1;
    }

    for (size_t i = 0;
         i <= text_length - pattern_length;
         i++)
    {
        size_t j = 0;

        while (j < pattern_length &&
               text[i + j] == pattern[j])
        {
            j++;
        }

        if (j == pattern_length)
        {
            return (int)i;
        }
    }

    return -1;
}

int main(void)
{
    char text[] = "EMBEDDED SYSTEMS";
    char pattern[] = "SYSTEMS";

    int position = find_substring(text, pattern);

    if (position != -1)
    {
        printf("Pattern found at index %d\n", position);
    }
    else
    {
        printf("Pattern not found.\n");
    }

    return 0;
}
Expected Output: 
Pattern found at index 9

How the Algorithm Works

  1. Calculate the lengths of the text and pattern.
  2. Try each valid starting position in the text.
  3. Compare the pattern characters with the text characters.
  4. If every pattern character matches, return the starting index.
  5. If no match is found, return -1.

Complexity Analysis

Let n be the text length and m be the pattern length.

  • Worst-case time complexity: O(n × m).
  • Auxiliary space complexity: O(1).
This implementation returns the starting position as int. It is suitable for ordinary practical input sizes. For very large strings, a size_t-based result representation should be used instead.

13. Counting Occurrences of a Character

Another common interview problem is finding how many times a particular character appears in a string.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";
    char target = 'M';

    int count = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        if (str[i] == target)
        {
            count++;
        }
    }

    printf("Character '%c' occurs %d times.\n",
           target, count);

    return 0;
}
Expected Output: 
Character 'M' occurs 2 times.

15. Common Mistakes and Interview Traps

  • Using == to compare string contents.
  • Assuming strcmp() returns only -1, 0 or 1.
  • Forgetting that strcmp() is case-sensitive.
  • Assuming strncmp() compares the complete strings.
  • Not checking whether strchr() returns NULL.
  • Confusing the first and last occurrence searches.
  • Using strstr() without understanding its returned pointer.
  • Searching an array that is not a valid null-terminated string.
  • Forgetting that string positions start at index zero.
  • Ignoring empty-pattern behavior in substring searching.
