2. Understanding Character Frequency

Character frequency means the number of times a particular character occurs in a string.

Example

String: PROGRAMMING

Character     Frequency
P             1
R             2
O             1
G             2
A             1
M             2
I             1
N             1

Frequency counting is useful in:

  • Duplicate character detection.
  • Anagram checking.
  • Finding repeated elements.
  • Text analysis and data processing.
  • Interview coding problems.

3. Counting Frequency of a Character

A simple loop can count how many times a particular character appears in a string.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";
    char target = 'R';

    int count = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        if (str[i] == target)
        {
            count++;
        }
    }

    printf("Frequency of %c = %d\n", target, count);

    return 0;
}
Expected Output: 
Frequency of R = 2

Complexity

  • Time complexity: O(n).
  • Auxiliary space: O(1).

4. Frequency Array Technique

Instead of counting one character at a time, we can maintain an array that stores the frequency of every possible character value.

For a basic ASCII-oriented example, an array of 256 integers can store frequencies for byte values from 0 to 255.

Example

int frequency[256] = {0};

When a character occurs, increment the corresponding array element: 

frequency[(unsigned char)str[i]]++;
Casting to unsigned char ensures the array index is in the range 0 to UCHAR_MAX. This example assumes an 8-bit byte.

Program: Count All Character Frequencies

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    printf("Character frequencies:\n");

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > 0)
        {
            printf("%c = %d\n", i, frequency[i]);
        }
    }

    return 0;
}
Expected Output: 
Character frequencies:
A = 1
G = 2
I = 1
M = 2
N = 1
O = 1
P = 1
R = 2

Complexity

  • Frequency calculation: O(n).
  • Frequency array traversal: O(256), a constant.
  • Auxiliary space: O(256), a constant for this implementation.

5. What Is an Anagram?

Two strings are anagrams if they contain exactly the same characters with the same frequencies, regardless of their order.

Examples

String 1 String 2 Result
LISTEN SILENT Anagrams
EARTH HEART Anagrams
CAT ACT Anagrams
APPLE APPLY Not anagrams

Anagrams must have:

  • The same length.
  • The same characters.
  • The same frequency for every character.

6. Checking Anagrams Using Frequency Arrays

Frequency arrays provide an efficient way to check whether two strings are anagrams.

Algorithm

  1. Calculate the lengths of both strings.
  2. If lengths differ, they cannot be anagrams.
  3. Initialize a frequency array with zeros.
  4. Increment frequencies for the first string.
  5. Decrement frequencies for the second string.
  6. If every frequency is zero, the strings are anagrams.

Program: ASCII Case-Sensitive Anagram Check

#include <stdio.h>
#include <string.h>

int are_anagrams(const char a[], const char b[])
{
    int frequency[256] = {0};

    if (strlen(a) != strlen(b))
    {
        return 0;
    }

    for (int i = 0; a[i] != '\0'; i++)
    {
        frequency[(unsigned char)a[i]]++;
        frequency[(unsigned char)b[i]]--;
    }

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] != 0)
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    char first[] = "LISTEN";
    char second[] = "SILENT";

    if (are_anagrams(first, second))
    {
        printf("Strings are anagrams.\n");
    }
    else
    {
        printf("Strings are not anagrams.\n");
    }

    return 0;
}
Expected Output: 
Strings are anagrams.

Complexity Analysis

  • Time complexity: O(n + 256), effectively O(n).
  • Auxiliary space: O(256), effectively O(1).
This implementation is case-sensitive and compares every character exactly. It assumes an 8-bit byte and uses a 256-element frequency array.

7. Case-Insensitive Anagram Checking

Sometimes uppercase and lowercase characters should be treated as equivalent.

Example

String 1: Listen
String 2: SILENT

Result: Anagrams when case is ignored.

Program

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int are_anagrams_ignore_case(const char a[], const char b[])
{
    int frequency[256] = {0};

    if (strlen(a) != strlen(b))
    {
        return 0;
    }

    for (int i = 0; a[i] != '\0'; i++)
    {
        unsigned char ca = (unsigned char)a[i];
        unsigned char cb = (unsigned char)b[i];

        ca = (unsigned char)tolower(ca);
        cb = (unsigned char)tolower(cb);

        frequency[ca]++;
        frequency[cb]--;
    }

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] != 0)
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    char first[] = "Listen";
    char second[] = "SILENT";

    if (are_anagrams_ignore_case(first, second))
    {
        printf("Anagrams ignoring case.\n");
    }
    else
    {
        printf("Not anagrams.\n");
    }

    return 0;
}
Expected Output: 
Anagrams ignoring case.
This approach uses the current C locale's character conversion rules. It is not a complete Unicode-aware anagram implementation.

8. Finding Duplicate Characters

A duplicate character is a character that appears more than once in a string.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];
        frequency[ch]++;
    }

    printf("Duplicate characters:\n");

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > 1)
        {
            printf("%c occurs %d times\n",
                   i, frequency[i]);
        }
    }

    return 0;
}
Expected Output: 
Duplicate characters:
G occurs 2 times
M occurs 2 times
R occurs 2 times

9. Finding the First Non-Repeating Character

A non-repeating character occurs exactly once in a string.

The first non-repeating character is the first character from left to right whose frequency is one.

Example

Input:  PROGRAMMING

P = 1
R = 2
O = 1
G = 2
A = 1
M = 2
I = 1
N = 1

First non-repeating character: P

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int found = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (frequency[ch] == 1)
        {
            printf("First non-repeating character: %c\n",
                   str[i]);

            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("No non-repeating character found.\n");
    }

    return 0;
}
Expected Output: 
First non-repeating character: P

Complexity

  • Time complexity: O(n + 256), effectively O(n).
  • Auxiliary space: O(256), effectively O(1).

10. Finding the First Repeating Character

The first repeating character is the first character encountered from left to right whose frequency is greater than one.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "ABCADE";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int found = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (frequency[ch] > 1)
        {
            printf("First repeating character: %c\n",
                   str[i]);

            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("No repeating character found.\n");
    }

    return 0;
}
Expected Output: 
First repeating character: A

11. Finding the Most Frequently Occurring Character

This problem requires identifying the character with the highest frequency.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "MISSISSIPPI";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int maximum = 0;
    unsigned char result = '\0';

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > maximum)
        {
            maximum = frequency[i];
            result = (unsigned char)i;
        }
    }

    if (maximum > 0)
    {
        printf("Most frequent character: %c\n", result);
        printf("Frequency: %d\n", maximum);
    }
    else
    {
        printf("String is empty.\n");
    }

    return 0;
}
Expected Output: 
Most frequent character: I
Frequency: 4

If multiple characters have the same maximum frequency, this implementation selects the one with the smallest unsigned character value.

12. Removing Duplicate Characters

Removing duplicates means retaining only the first occurrence of each character while preserving the original order.

Example

Input:  PROGRAMMING
Output: PROGAMIN

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int seen[256] = {0};

    int read = 0;
    int write = 0;

    while (str[read] != '\0')
    {
        unsigned char ch = (unsigned char)str[read];

        if (!seen[ch])
        {
            seen[ch] = 1;
            str[write] = str[read];
            write++;
        }

        read++;
    }

    str[write] = '\0';

    printf("After removing duplicates: %s\n", str);

    return 0;
}
Expected Output: 
After removing duplicates: PROGAMIN

Complexity

  • Time complexity: O(n + 256), effectively O(n).
  • Auxiliary space: O(256), effectively O(1).

13. Character Frequency Using Sorting

Another approach to anagram checking is sorting both strings and comparing the resulting sequences.

Basic Approach

  1. Check whether the string lengths are equal.
  2. Sort the characters in both strings.
  3. Compare the sorted strings using strcmp().
  4. If they are equal, the original strings are anagrams.
This method is useful for understanding how sorting can solve anagram problems. Its time complexity depends on the sorting algorithm. A frequency array is generally more efficient for a fixed, small character set.

14. Frequency Counting vs Sorting

Approach Typical Time Complexity Additional Space
Frequency array O(n + k) O(k)
Comparison-based sorting O(n log n) Depends on sorting algorithm
Nested-loop frequency counting O(n²) O(1)

Here, n is the string length and k is the size of the supported character set.

15. Common Mistakes and Interview Traps

  • Checking only string lengths when detecting anagrams.
  • Ignoring character frequencies.
  • Forgetting that uppercase and lowercase characters differ.
  • Using a frequency array without checking the valid index range.
  • Failing to initialize the frequency array to zero.
  • Confusing the first repeating character with the first character that repeats later.
  • Assuming the first non-repeating character is always at index zero.
  • Overwriting characters before they have been processed.
  • Assuming ASCII frequency counting supports complete Unicode text.
