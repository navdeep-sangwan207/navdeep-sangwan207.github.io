Lecture 3: String Traversal and Length

Learn to access string characters, traverse character arrays, calculate string length manually and use standard library functions in C.

1. Learning Objectives

  • Understand how string characters are stored in memory.
  • Access individual characters using array indexing.
  • Traverse a string using loops.
  • Understand the role of the null terminator.
  • Calculate string length manually.
  • Use strlen() from the C standard library.
  • Traverse strings using pointers.
  • Solve common string traversal interview problems.

2. Understanding String Storage

A C string is stored as a sequence of characters ending with the null character '\0'.

Example

char str[] = "HELLO";

The array contains the following elements:

Index:       0     1     2     3     4      5

Character:  'H'   'E'   'L'   'L'   'O'    '\0'

The characters are stored at consecutive array positions. The null terminator indicates where the string ends.

The string "HELLO" has a length of 5 characters, but its array requires 6 elements to store the terminating '\0'.

3. Accessing Individual Characters

Each character in a string can be accessed using its array index.

Syntax

string_name[index];

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "EMBEDDED";

    printf("First character: %c\n", str[0]);
    printf("Third character: %c\n", str[2]);
    printf("Last character: %c\n", str[7]);

    return 0;
}
Expected Output: 
First character: E
Third character: B
Last character: D

Array indexing starts from zero. Therefore, the first character is at index 0.

4. Traversing a String Using a for Loop

String traversal means visiting each character sequentially, starting from the first character and continuing until the null terminator.

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int i;

    for (i = 0; str[i] != '\0'; i++)
    {
        printf("%c\n", str[i]);
    }

    return 0;
}
Expected Output: 
P
R
O
G
R
A
M
M
I
N
G

How the Loop Works

  1. Initialize the index i to zero.
  2. Check whether str[i] is different from '\0'.
  3. Print the current character.
  4. Increment the index.
  5. Stop when the null terminator is reached.
The condition str[i] != '\0' is fundamental to string traversal. It prevents the loop from treating characters beyond the string as part of the string.

5. Traversing a String Using a while Loop

The same operation can be performed using a while loop. 

#include <stdio.h>

int main(void)
{
    char str[] = "LINUX";

    int i = 0;

    while (str[i] != '\0')
    {
        printf("%c ", str[i]);
        i++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
L I N U X

The loop terminates when the current array element contains '\0'.

6. Calculating String Length Manually

String length is the number of characters before the null terminator. The null terminator itself is not included.

Logic

  1. Initialize a counter to zero.
  2. Traverse the string from the first character.
  3. Increment the counter for every non-null character.
  4. Stop when '\0' is encountered.
  5. The counter contains the string length.

Program: Find String Length Without strlen()

#include <stdio.h>

int main(void)
{
    char str[] = "EMBEDDED";

    int i = 0;
    int length = 0;

    while (str[i] != '\0')
    {
        length++;
        i++;
    }

    printf("String: %s\n", str);
    printf("Length: %d\n", length);

    return 0;
}
Expected Output: 
String: EMBEDDED
Length: 8

Complexity Analysis

Complexity Explanation
Time O(n), because each character is visited once.
Auxiliary Space O(1), because only a fixed number of variables are used.

7. Using strlen() Function

The C standard library provides strlen() to calculate the length of a null-terminated string.

Header File

#include <string.h>

Syntax

strlen(string_name);

strlen() returns the number of characters before the terminating null character. Its return type is size_t.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    size_t length = strlen(str);

    printf("String: %s\n", str);
    printf("Length: %zu\n", length);

    return 0;
}
Expected Output: 
String: PROGRAMMING
Length: 11
Use %zu to print a size_t value correctly. The strlen() function does not count '\0'.

8. Difference Between strlen() and sizeof()

strlen() calculates the length of a string, whereas sizeof() gives the size in bytes of its operand.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";

    printf("strlen: %zu\n", strlen(str));
    printf("sizeof: %zu\n", sizeof(str));

    return 0;
}
Expected Output: 
strlen: 5
sizeof: 6

Comparison

Feature strlen() sizeof()
Purpose Calculates string length. Calculates object size in bytes.
Header string.h No special header required.
Counts '\0' No Includes it when it is part of the array.
Return type size_t size_t
Operation Examines characters until '\0'. Determines operand size.

Important: Array Versus Pointer

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";
    const char *ptr = "HELLO";

    printf("Array sizeof: %zu\n", sizeof(str));
    printf("Array strlen: %zu\n", strlen(str));

    printf("Pointer sizeof: %zu\n", sizeof(ptr));
    printf("Pointer strlen: %zu\n", strlen(ptr));

    return 0;
}

The array size is the size of the complete array, including its null terminator. The pointer size is the size of the pointer object, which depends on the implementation. strlen() examines the string in either case.

Do not use sizeof(pointer) to determine the length or capacity of the string it points to.

9. Traversing a String Using Pointers

A pointer can access string characters by pointing to the first element and moving forward until the null terminator is reached.

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "POINTER";

    char *ptr = str;

    while (*ptr != '\0')
    {
        printf("%c ", *ptr);
        ptr++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
P O I N T E R

Explanation

  • ptr initially points to str[0].
  • *ptr accesses the character at the current address.
  • ptr++ advances the pointer to the next character.
  • The loop stops at '\0'.
Pointer-based string traversal is especially useful when working with function arguments, string processing and low-level C programming.

10. Counting Vowels in a String

This is a common beginner-to-intermediate coding problem that combines string traversal and conditional logic.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "EMBEDDED SYSTEMS";

    int i = 0;
    int count = 0;

    while (str[i] != '\0')
    {
        char ch = str[i];

        if (ch == 'a' || ch == 'e' || ch == 'i' ||
            ch == 'o' || ch == 'u' ||
            ch == 'A' || ch == 'E' || ch == 'I' ||
            ch == 'O' || ch == 'U')
        {
            count++;
        }

        i++;
    }

    printf("String: %s\n", str);
    printf("Vowel count: %d\n", count);

    return 0;
}
Expected Output: 
String: EMBEDDED SYSTEMS
Vowel count: 5

11. Counting Characters in a String

The following program counts the total number of characters, excluding the null terminator. 

#include <stdio.h>

int main(void)
{
    char str[] = "C PROGRAMMING";

    int i = 0;
    int letters = 0;
    int spaces = 0;

    while (str[i] != '\0')
    {
        if (str[i] == ' ')
        {
            spaces++;
        }
        else
        {
            letters++;
        }

        i++;
    }

    printf("Non-space characters: %d\n", letters);
    printf("Spaces: %d\n", spaces);
    printf("Total length: %d\n", i);

    return 0;
}
Expected Output: 
Non-space characters: 12
Spaces: 1
Total length: 13

Here, the variable i also represents the total string length because it advances once for every character before '\0'.

12. Reversing the Display Order of a String

A string can be displayed in reverse order by first finding its length and then accessing characters from the last position to the first.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";

    size_t length = strlen(str);

    printf("Original: %s\n", str);
    printf("Reverse: ");

    for (size_t i = length; i > 0; i--)
    {
        printf("%c", str[i - 1]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Original: HELLO
Reverse: OLLEH

This program reverses only the display order. It does not modify the original character array.

13. Common Mistakes in String Traversal

  • Starting array traversal from index 1 instead of index 0.
  • Using an incorrect termination condition.
  • Forgetting to stop at '\0'.
  • Counting the null terminator as a character.
  • Using strlen() on an array that is not properly null-terminated.
  • Using sizeof(pointer) as the string length.
  • Accessing array positions outside the valid bounds.
  • Using an incorrect format specifier for size_t.
strlen() requires a valid null-terminated string. Calling it on an array without a terminating null character can result in undefined behavior.
