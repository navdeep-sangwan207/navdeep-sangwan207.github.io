Lecture 2: String Declaration, Initialization and Input

Learn how to declare and initialize character arrays, accept strings from users, handle spaces and use safe input techniques in C programming.

1. Learning Objectives

  • Declare character arrays for storing strings.
  • Initialize strings using literals and character lists.
  • Understand array capacity and null termination.
  • Read strings using scanf().
  • Understand the limitations of %s.
  • Read strings containing spaces using fgets().
  • Handle newline characters and input failures.
  • Validate string input and avoid buffer overflow.

2. Declaring a String

A string is stored in a character array. The array must have enough elements to store all characters and the terminating null character.

Syntax

char string_name[array_size];

Example

char name[20];

This creates an array with capacity for 20 characters. A null-terminated string stored in it can contain at most 19 ordinary single-byte characters.

One array element must be reserved for '\0' when storing a valid C string.

3. Initializing a String

Method 1: Using a String Literal

char name[] = "NAVDEEP";

The compiler determines the array size and includes the terminating null character automatically.

Method 2: Specifying Array Size

char name[15] = "NAVDEEP";

The array contains 15 elements. The remaining elements are initialized to zero.

Method 3: Character-by-Character Initialization

char name[] = {
    'N', 'A', 'V', 'D', 'E', 'E', 'P', '\0'
};

Method 4: Empty String Initialization

char name[20] = "";

The first element is initialized to '\0', so the array initially represents an empty string.

Complete Program

#include <stdio.h>

int main(void)
{
    char first[] = "C PROGRAMMING";

    char second[20] = "EMBEDDED";

    char third[] = {
        'L', 'I', 'N', 'U', 'X', '\0'
    };

    char fourth[10] = "";

    printf("%s\n", first);
    printf("%s\n", second);
    printf("%s\n", third);
    printf("%s\n", fourth);

    return 0;
}
Expected Output: 
C PROGRAMMING
EMBEDDED
LINUX

4. Reading a String Using scanf()

The %s format specifier can read a sequence of non-whitespace characters into a character array.

Syntax

scanf("%s", name);

The array name is used directly because it automatically converts to a pointer to its first element in this function call.

Example Program

#include <stdio.h>

int main(void)
{
    char name[30];

    printf("Enter your name: ");

    if (scanf("%29s", name) != 1)
    {
        printf("Input error.\n");
        return 1;
    }

    printf("Name: %s\n", name);

    return 0;
}
Sample Input: 
Navdeep
Expected Output: 
Enter your name: Navdeep
Name: Navdeep

Why Use %29s?

The array capacity is 30. Therefore, scanf should read at most 29 input characters, leaving one position for the terminating null character.

Avoid using unbounded %s with a fixed-size character array. If the input is longer than the available storage, it can cause a buffer overflow.

5. Limitation of scanf() with %s

The %s conversion stops when it encounters whitespace, such as a space, tab or newline.

Example

#include <stdio.h>

int main(void)
{
    char name[40];

    printf("Enter full name: ");

    if (scanf("%39s", name) != 1)
        return 1;

    printf("Stored string: %s\n", name);

    return 0;
}
Sample Input: 
Navdeep Sangwan
Expected Output: 
Enter full name: Navdeep Sangwan
Stored string: Navdeep

Only the first word is stored. The remaining input stays in the input stream.

Use fgets() when you need to read a complete line containing spaces.

6. Reading a String Using fgets()

fgets() reads a line of input, including spaces, until a newline is encountered, the specified capacity is reached, or end-of-file occurs.

Syntax

fgets(string_name, array_size, stdin);

Parameters:

  • string_name: Destination character array.
  • array_size: Maximum number of characters including the terminator.
  • stdin: Standard input stream.

Example Program

#include <stdio.h>

int main(void)
{
    char name[50];

    printf("Enter your full name: ");

    if (fgets(name, sizeof(name), stdin) == NULL)
    {
        printf("Input error or end of input.\n");
        return 1;
    }

    printf("Full name: %s", name);

    return 0;
}
Sample Input: 
Navdeep Sangwan
Expected Output: 
Enter your full name: Navdeep Sangwan
Full name: Navdeep Sangwan

Unlike scanf("%s", ...), fgets() can preserve spaces within the input line.

7. Understanding the Newline Stored by fgets()

If the newline character fits in the destination array, fgets() stores it before the terminating null character.

Example

If the user enters CAT and presses Enter, the resulting array can contain: 

Index:       0     1     2     3      4

Character:  'C'   'A'   'T'   '\n'   '\0'

The newline is part of the string. It can be removed when the application does not need it.

Removing the Newline

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];

    printf("Enter name: ");

    if (fgets(name, sizeof(name), stdin) == NULL)
        return 1;

    name[strcspn(name, "\n")] = '\0';

    printf("Name: %s\n", name);

    return 0;
}
Sample Input: 
Navdeep Sangwan
Expected Output: 
Enter name: Navdeep Sangwan
Name: Navdeep Sangwan

strcspn() returns the position of the first newline, or the string length if no newline exists. Assigning '\0' at that position removes the newline when present.

8. Handling Input Left Behind by scanf()

A common problem occurs when scanf() reads a value but leaves the newline in the input stream.

Problem Example

#include <stdio.h>

int main(void)
{
    int age;
    char name[50];

    printf("Enter age: ");

    if (scanf("%d", &age) != 1)
        return 1;

    printf("Enter name: ");

    if (fgets(name, sizeof(name), stdin) == NULL)
        return 1;

    printf("Age: %d\n", age);
    printf("Name: %s", name);

    return 0;
}

After scanf() reads the integer, the newline typed after the number may remain in the input stream. fgets() can then read that newline immediately.

Corrected Version

#include <stdio.h>
#include <string.h>

int main(void)
{
    int age;
    char name[50];

    printf("Enter age: ");

    if (scanf("%d", &age) != 1)
    {
        printf("Invalid age input.\n");
        return 1;
    }

    /* Consume the remainder of the input line */
    int ch;

    while ((ch = getchar()) != '\n' && ch != EOF)
    {
        /* Discard remaining characters */
    }

    printf("Enter full name: ");

    if (fgets(name, sizeof(name), stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    name[strcspn(name, "\n")] = '\0';

    printf("Age: %d\n", age);
    printf("Name: %s\n", name);

    return 0;
}
Sample Input: 
25
Navdeep Sangwan
Expected Output: 
Enter age: 25
Enter full name: Navdeep Sangwan
Age: 25
Name: Navdeep Sangwan
The loop discards the rest of the current input line. It is appropriate when the application expects one value per line. Do not use it if additional data on the same line must be preserved.

9. Handling Long Input Lines

fgets() reads at most one less than the destination array capacity, so an excessively long line may be only partially stored.

If a complete line is required, the program should detect whether the newline was read and decide how to handle the remaining characters.

Example: Detecting a Truncated Line

#include <stdio.h>
#include <string.h>

int main(void)
{
    char input[10];

    printf("Enter text: ");

    if (fgets(input, sizeof(input), stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    size_t length = strlen(input);

    if (length > 0 && input[length - 1] == '\n')
    {
        input[length - 1] = '\0';
        printf("Complete line received: %s\n", input);
    }
    else
    {
        int ch;

        while ((ch = getchar()) != '\n' && ch != EOF)
        {
            /* Discard remaining input */
        }

        printf("Input line exceeded the available capacity.\n");
    }

    return 0;
}
Sample Input: 
EMBEDDED
Expected Output: 
Enter text: EMBEDDED
Complete line received: EMBEDDED

The array has capacity for nine input characters plus the terminating null character? No. Its capacity is ten total elements, so fgets() can store at most nine input characters plus '\0'. A newline also consumes one of those input positions.

11. Using getchar() for Character Input

getchar() reads one character from standard input. It can be useful when accepting a single character or processing input one character at a time.

Example Program

#include <stdio.h>

int main(void)
{
    char name[50];

    int i = 0;
    int ch;

    printf("Enter a word: ");

    while ((ch = getchar()) != '\n' &&
           ch != EOF &&
           i < 49)
    {
        name[i] = (char)ch;
        i++;
    }

    name[i] = '\0';

    printf("Stored input: %s\n", name);

    return 0;
}
Sample Input: 
EMBEDDED
Expected Output: 
Enter a word: EMBEDDED
Stored input: EMBEDDED

getchar() returns an int rather than char so that it can represent every unsigned-char value as well as the special EOF value.

This example reads at most 49 characters. If more characters are entered, the remainder is left in the input stream. Production input routines should define how that remaining input is handled.

12. Input Validation and Safe String Input

A reliable string-input routine should consider:

  • Whether input was successfully received.
  • Whether the input fits into the destination array.
  • Whether a newline is present.
  • Whether the string should allow spaces.
  • Whether empty input is permitted.

Example: Read and Validate a Non-Empty Line

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];

    printf("Enter your name: ");

    if (fgets(name, sizeof(name), stdin) == NULL)
    {
        printf("Unable to read input.\n");
        return 1;
    }

    size_t length = strlen(name);

    if (length > 0 && name[length - 1] == '\n')
    {
        name[length - 1] = '\0';
    }
    else if (!feof(stdin))
    {
        int ch;

        while ((ch = getchar()) != '\n' && ch != EOF)
        {
            /* Discard excess input */
        }

        printf("Input is too long.\n");
        return 1;
    }

    if (name[0] == '\0')
    {
        printf("Name cannot be empty.\n");
        return 1;
    }

    printf("Accepted name: %s\n", name);

    return 0;
}
Sample Input: 
Navdeep Sangwan
Expected Output: 
Enter your name: Navdeep Sangwan
Accepted name: Navdeep Sangwan

This example accepts a non-empty line that fits in the array. It rejects an overlong line when the newline is not received in the buffer.

13. Common String Input Mistakes

  • Using unbounded %s with a fixed-size array.
  • Expecting scanf("%s", ...) to read spaces.
  • Forgetting that fgets() may store '\n'.
  • Ignoring the return value of fgets().
  • Using an incorrect array capacity.
  • Mixing scanf() and fgets() without handling the remaining input.
  • Assuming fgets() always reads the complete line.
  • Using gets(), which was removed from the C standard because it cannot limit input length.
  • Forgetting to reserve space for '\0'.
Never use gets() in C programs. Use fgets() with the actual destination array capacity instead.

16. Lecture Summary

  • Strings are stored in character arrays.
  • String declarations must provide sufficient capacity.
  • String literals automatically include a null terminator.
  • scanf("%s", ...) reads a single non-whitespace sequence.
  • Use a field width with %s to limit input.
  • fgets() is suitable for reading lines containing spaces.
  • fgets() may store the newline character.
  • getchar() reads one character and returns int.
  • Always check input-function return values.
  • Never use gets() because it cannot protect the destination buffer.
