3. Frequently Asked Technical Interview Questions

Q1. What is a string in C?

A string is a sequence of characters terminated by the null character '\0'. C does not have a separate built-in string data type.

Q2. What is the difference between a character and a string?

char ch = 'A';
char str[] = "A";
  • ch stores one character.
  • str stores two array elements: 'A' and '\0'.

Q3. Why is the null terminator important?

String-processing functions use '\0' to identify where a string ends. Without a valid terminator within the array, operations expecting a string may read beyond the array boundaries.

Q4. What is the difference between sizeof() and strlen()?

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";

    printf("sizeof = %zu\n", sizeof(str));
    printf("strlen = %zu\n", strlen(str));

    return 0;
}
Expected Output: 
sizeof = 6
strlen = 5

sizeof() returns the size in bytes of the array object in this example. strlen() counts characters before the null terminator.

Q5. What is the difference between strcpy() and strncpy()?

  • strcpy() copies the source including its null terminator.
  • strncpy() copies at most n characters.
  • strncpy() does not guarantee null termination if the source length is at least n.
  • Neither function automatically verifies destination capacity.

Q6. Why can we not compare strings using ==?

When character arrays are used in an expression, they generally convert to pointers to their first elements. Comparing these pointers does not compare the string contents. 

if (strcmp(str1, str2) == 0)
{
    printf("Equal strings");
}

Q7. Can a string be modified through a pointer?

A pointer to a modifiable character array can be used to modify its characters. A pointer to a string literal must not be used to modify the literal.

Q8. What is a buffer overflow in string handling?

Buffer overflow occurs when an operation writes beyond the allocated memory capacity of an array. It can corrupt adjacent data and cause undefined behavior.

4. Coding Problem 1: Reverse a String

Reverse a string in place without creating another character array.

Program

#include <stdio.h>

void reverse_string(char str[])
{
    int left = 0;
    int right = 0;

    while (str[right] != '\0')
    {
        right++;
    }

    right--;

    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }
}

int main(void)
{
    char str[] = "INTERVIEW";

    reverse_string(str);

    printf("Reversed: %s\n", str);

    return 0;
}
Expected Output: 
Reversed: WEIVRETNI

Time: O(n). Auxiliary space: O(1).

5. Coding Problem 2: Check Whether Two Strings Are Anagrams

Two strings are anagrams when they contain the same characters with identical frequencies.

Program

#include <stdio.h>
#include <string.h>

int are_anagrams(const char a[], const char b[])
{
    int frequency[256] = {0};

    if (strlen(a) != strlen(b))
    {
        return 0;
    }

    for (int i = 0; a[i] != '\0'; i++)
    {
        frequency[(unsigned char)a[i]]++;
        frequency[(unsigned char)b[i]]--;
    }

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] != 0)
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    char a[] = "LISTEN";
    char b[] = "SILENT";

    printf("%s\n",
           are_anagrams(a, b) ? "Anagrams" : "Not anagrams");

    return 0;
}
Expected Output: 
Anagrams

Time: O(n + 256), effectively O(n). Auxiliary space: O(256), effectively O(1). This solution assumes an 8-bit byte.

6. Coding Problem 3: Find the First Non-Repeating Character

Find the first character that occurs exactly once in a string.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "SWISS";

    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int found = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (frequency[ch] == 1)
        {
            printf("First unique character: %c\n", str[i]);
            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("No unique character found.\n");
    }

    return 0;
}
Expected Output: 
First unique character: W

Time: O(n + 256), effectively O(n).

7. Coding Problem 4: Check Whether a String Is a Palindrome

A palindrome reads the same from left to right and right to left.

Program

#include <stdio.h>

int is_palindrome(const char str[])
{
    int left = 0;
    int right = 0;

    while (str[right] != '\0')
    {
        right++;
    }

    right--;

    while (left < right)
    {
        if (str[left] != str[right])
        {
            return 0;
        }

        left++;
        right--;
    }

    return 1;
}

int main(void)
{
    char str[] = "MADAM";

    if (is_palindrome(str))
    {
        printf("Palindrome\n");
    }
    else
    {
        printf("Not a palindrome\n");
    }

    return 0;
}
Expected Output: 
Palindrome

8. Coding Problem 5: Remove Duplicate Characters

Remove repeated characters while preserving the first occurrence and original order.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";
    int seen[256] = {0};

    int read = 0;
    int write = 0;

    while (str[read] != '\0')
    {
        unsigned char ch = (unsigned char)str[read];

        if (!seen[ch])
        {
            seen[ch] = 1;
            str[write++] = str[read];
        }

        read++;
    }

    str[write] = '\0';

    printf("Result: %s\n", str);

    return 0;
}
Expected Output: 
Result: PROGAMIN

9. Coding Problem 6: Count Words in a String

Count words separated by one or more whitespace characters. A word is a maximal sequence of non-whitespace characters.

Program

#include <stdio.h>
#include <ctype.h>

int count_words(const char str[])
{
    int count = 0;
    int inside_word = 0;

    for (int i = 0; str[i] != '\0'; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (isspace(ch))
        {
            inside_word = 0;
        }
        else if (!inside_word)
        {
            count++;
            inside_word = 1;
        }
    }

    return count;
}

int main(void)
{
    char str[] = "C Programming for Embedded Systems";

    printf("Word count = %d\n", count_words(str));

    return 0;
}
Expected Output: 
Word count = 5

Time: O(n). Auxiliary space: O(1). The isspace() argument is safely converted to unsigned char.

10. Coding Problem 7: Find the Longest Word

Find the longest word in a sentence where words are separated by whitespace.

Program

#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char str[] = "C programming builds strong fundamentals";

    int current_start = 0;
    int current_length = 0;

    int best_start = 0;
    int best_length = 0;

    for (int i = 0; ; i++)
    {
        unsigned char ch = (unsigned char)str[i];

        if (str[i] != '\0' && !isspace(ch))
        {
            if (current_length == 0)
            {
                current_start = i;
            }

            current_length++;
        }
        else
        {
            if (current_length > best_length)
            {
                best_length = current_length;
                best_start = current_start;
            }

            current_length = 0;

            if (str[i] == '\0')
            {
                break;
            }
        }
    }

    printf("Longest word: ");

    for (int i = 0; i < best_length; i++)
    {
        putchar(str[best_start + i]);
    }

    putchar('\n');

    printf("Length: %d\n", best_length);

    return 0;
}
Expected Output: 
Longest word: fundamentals
Length: 13

11. Coding Problem 8: Find the Most Frequent Character

Program

#include <stdio.h>

int main(void)
{
    char str[] = "MISSISSIPPI";
    int frequency[256] = {0};

    for (int i = 0; str[i] != '\0'; i++)
    {
        frequency[(unsigned char)str[i]]++;
    }

    int max_frequency = 0;
    int result = -1;

    for (int i = 0; i < 256; i++)
    {
        if (frequency[i] > max_frequency)
        {
            max_frequency = frequency[i];
            result = i;
        }
    }

    if (result != -1)
    {
        printf("Most frequent character: %c\n", result);
        printf("Frequency: %d\n", max_frequency);
    }
    else
    {
        printf("Empty string.\n");
    }

    return 0;
}
Expected Output: 
Most frequent character: I
Frequency: 4

12. Coding Problem 9: Check Whether One String Is a Rotation of Another

A string is a rotation of another if characters can be shifted cyclically to produce the second string.

Example

String 1: ABCD
String 2: CDAB

Result: Rotation

Program

#include <stdio.h>
#include <string.h>

int is_rotation(const char a[], const char b[])
{
    char combined[202];
    size_t length = strlen(a);

    if (length != strlen(b))
    {
        return 0;
    }

    if (length == 0)
    {
        return 1;
    }

    if (length > (sizeof(combined) - 1) / 2)
    {
        return 0;
    }

    strcpy(combined, a);
    strcat(combined, a);

    return strstr(combined, b) != NULL;
}

int main(void)
{
    char first[] = "ABCD";
    char second[] = "CDAB";

    if (is_rotation(first, second))
    {
        printf("Rotation\n");
    }
    else
    {
        printf("Not a rotation\n");
    }

    return 0;
}
Expected Output: 
Rotation
This demonstration uses a fixed buffer and checks its capacity before concatenation. It supports strings of at most 100 characters in this example.

The core observation is that a rotation of a string must appear as a substring of the original string concatenated with itself.

13. Coding Problem 10: Find the First Occurrence of a Substring

Implement a basic substring search without using strstr().

Program

#include <stdio.h>

int find_substring(const char text[], const char pattern[])
{
    if (pattern[0] == '\0')
    {
        return 0;
    }

    for (int i = 0; text[i] != '\0'; i++)
    {
        int j = 0;

        while (pattern[j] != '\0' &&
               text[i + j] != '\0' &&
               text[i + j] == pattern[j])
        {
            j++;
        }

        if (pattern[j] == '\0')
        {
            return i;
        }
    }

    return -1;
}

int main(void)
{
    char text[] = "MICROCONTROLLER";
    char pattern[] = "CONTROL";

    int position = find_substring(text, pattern);

    if (position != -1)
    {
        printf("Substring found at index %d\n", position);
    }
    else
    {
        printf("Substring not found.\n");
    }

    return 0;
}
Expected Output: 
Substring found at index 5

Worst-case time complexity: O(n × m), where n is the text length and m is the pattern length. Auxiliary space: O(1).

15. Debugging Questions

Problem 1: Missing Null Terminator

char destination[5];

destination[0] = 'H';
destination[1] = 'E';
destination[2] = 'L';
destination[3] = 'L';
destination[4] = 'O';

printf("%s", destination);

What is wrong?

No space is available for the null terminator. Passing this array to %s can cause an out-of-bounds read because it is not a valid null-terminated string.

Correction:

char destination[6] = "HELLO";

Problem 2: Modifying a String Literal

char *ptr = "HELLO";

ptr[0] = 'Y';

What is wrong?

Modifying a string literal causes undefined behavior.

Correction:

char ptr[] = "HELLO";

ptr[0] = 'Y';

Problem 3: Incorrect String Comparison

char a[] = "C";
char b[] = "C";

if (a == b)
{
    printf("Equal");
}

What is wrong?

The arrays are distinct objects. In this expression, they decay to pointers to their first elements. Pointer equality does not compare their contents.

Correction:

#include <string.h>

if (strcmp(a, b) == 0)
{
    printf("Equal");
}

16. Important Complexity Revision

Problem Typical Time Complexity
String length O(n)
String reversal O(n)
Palindrome checking O(n)
Character frequency counting O(n + k)
Anagram checking using frequency array O(n + k)
Duplicate removal using a lookup array O(n + k)
Character search O(n)
Naive substring search O(n × m)
Word counting O(n)

Here, n is the string length, m is the pattern length and k is the size of the character set.

19. Suggested Coding Round Strategy

  1. Understand the problem: Identify inputs, outputs and constraints.
  2. Check edge cases: Consider empty strings, one-character strings, repeated characters and different lengths.
  3. Select a data structure: Choose arrays, pointers or frequency tables.
  4. Develop the algorithm: Write the steps before coding.
  5. Implement in C11: Use correct array boundaries and null termination.
  6. Test thoroughly: Try normal, boundary and invalid inputs.
  7. Analyze complexity: Explain time and auxiliary space.
