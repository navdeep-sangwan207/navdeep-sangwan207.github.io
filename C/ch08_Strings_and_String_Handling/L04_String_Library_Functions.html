Lecture 4: String Library Functions

Learn how to use standard C string functions for measuring, copying, concatenating, comparing and searching strings.

1. Learning Objectives

  • Understand the purpose of the string.h header file.
  • Calculate string length using strlen().
  • Copy strings using strcpy() and strncpy().
  • Join strings using strcat() and strncat().
  • Compare strings using strcmp() and strncmp().
  • Search for characters using strchr().
  • Search for substrings using strstr().
  • Understand return values and destination-buffer requirements.
  • Apply string functions in practical coding problems.

2. Introduction to string.h

The C standard library provides several functions for operating on null-terminated strings. These functions are declared in the string.h header file.

Header File

#include <string.h>

Common String Functions

Function Purpose
strlen() Calculate string length.
strcpy() Copy one string into another.
strncpy() Copy up to a specified number of characters.
strcat() Append one string to another.
strncat() Append up to a specified number of characters.
strcmp() Compare two strings.
strncmp() Compare up to a specified number of characters.
strchr() Find the first occurrence of a character.
strrchr() Find the last occurrence of a character.
strstr() Find the first occurrence of a substring.
These functions generally expect valid null-terminated strings. The destination arrays used for copying and concatenation must have sufficient capacity.

3. strlen() – Finding String Length

strlen() returns the number of characters before the terminating null character.

Syntax

size_t strlen(const char *str);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[] = "NAVDEEP";

    size_t length = strlen(name);

    printf("String: %s\n", name);
    printf("Length: %zu\n", length);

    return 0;
}
Expected Output: 
String: NAVDEEP
Length: 7

The null character is not included in the returned length.

4. strcpy() – Copying a String

strcpy() copies a source string, including its terminating null character, into a destination character array.

Syntax

strcpy(destination, source);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "EMBEDDED C";
    char destination[30];

    strcpy(destination, source);

    printf("Source: %s\n", source);
    printf("Destination: %s\n", destination);

    return 0;
}
Expected Output: 
Source: EMBEDDED C
Destination: EMBEDDED C

Important Points

  • The source must be a valid null-terminated string.
  • The destination must have sufficient capacity.
  • The source and destination must not overlap.
  • strcpy() does not check destination capacity.
If the destination array is too small, strcpy() can write beyond its boundaries and cause undefined behavior.

5. strncpy() – Copying a Limited Number of Characters

strncpy() copies at most a specified number of characters from the source.

Syntax

strncpy(destination, source, n);

If the source is shorter than n, the remaining destination positions are filled with null characters. If the source contains at least n characters, the destination is not automatically null-terminated.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "PROGRAMMING";
    char destination[20];

    strncpy(destination, source, 5);
    destination[5] = '\0';

    printf("Copied string: %s\n", destination);

    return 0;
}
Expected Output: 
Copied string: PROGR
strncpy() is not automatically a safe string-copy function. It may leave the destination without a null terminator when the source length is at least n. Ensure the destination is properly terminated.

6. strcat() – Concatenating Strings

strcat() appends the source string to the end of the destination string.

Syntax

strcat(destination, source);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "HELLO ";
    char second[] = "WORLD";

    strcat(first, second);

    printf("Combined string: %s\n", first);

    return 0;
}
Expected Output: 
Combined string: HELLO WORLD

How It Works

  1. The destination initially contains "HELLO ".
  2. strcat() locates the destination's null terminator.
  3. The source characters are copied from that position.
  4. A new null terminator is written after the appended characters.
The destination array must have enough remaining capacity for its existing contents, the appended source and the final null terminator.

7. strncat() – Limited String Concatenation

strncat() appends at most n characters from the source string and then adds a terminating null character.

Syntax

strncat(destination, source, n);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "EMBEDDED ";
    char second[] = "SYSTEMS";

    strncat(first, second, 3);

    printf("Result: %s\n", first);

    return 0;
}
Expected Output: 
Result: EMBEDDED SYS

Here, only the first three characters of the source string are appended.

strncat() limits the number of source characters appended, not the total destination capacity. The destination must still have sufficient space.

8. strcmp() – Comparing Two Strings

strcmp() compares two strings lexicographically using the values of their characters.

Syntax

strcmp(string1, string2);

Return Values

Return Value Meaning
0 Both strings are equal.
Negative value The first string compares less than the second.
Positive value The first string compares greater than the second.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[] = "APPLE";
    char second[] = "APPLE";
    char third[] = "BANANA";

    if (strcmp(first, second) == 0)
    {
        printf("First and second strings are equal.\n");
    }

    if (strcmp(first, third) < 0)
    {
        printf("APPLE comes before BANANA.\n");
    }

    return 0;
}
Expected Output: 
First and second strings are equal.
APPLE comes before BANANA.
Do not assume strcmp() returns exactly -1 or 1. Only the sign of a nonzero result is meaningful.

9. Why Cannot We Compare Strings Using ==?

In C, arrays cannot be compared directly using ==. When used in an expression, character arrays generally convert to pointers to their first elements. The comparison then checks pointer addresses rather than string contents.

Incorrect Approach

char first[] = "HELLO";
char second[] = "HELLO";

if (first == second)
{
    printf("Equal");
}

This does not compare the characters stored in the two arrays.

Correct Approach

if (strcmp(first, second) == 0)
{
    printf("Strings are equal.");
}
Use strcmp() for comparing string contents. Use pointer comparison only when you actually intend to compare addresses.

10. strncmp() – Comparing Limited Characters

strncmp() compares at most n characters from two strings.

Syntax

strncmp(string1, string2, n);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[] = "EMBEDDED";
    char second[] = "EMBED";

    if (strncmp(first, second, 5) == 0)
    {
        printf("First five characters are equal.\n");
    }
    else
    {
        printf("Strings differ in the first five characters.\n");
    }

    return 0;
}
Expected Output: 
First five characters are equal.

11. strchr() – Searching for a Character

strchr() searches a string for the first occurrence of a specified character.

Syntax

strchr(string, character);

It returns a pointer to the first matching character or NULL if the character is not found.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    char *result = strchr(str, 'G');

    if (result != NULL)
    {
        printf("Character found: %c\n", *result);
        printf("Remaining string: %s\n", result);
    }
    else
    {
        printf("Character not found.\n");
    }

    return 0;
}
Expected Output: 
Character found: G
Remaining string: GRAMMING

12. strrchr() – Searching from the End

strrchr() locates the last occurrence of a specified character in a string.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    char *result = strrchr(str, 'M');

    if (result != NULL)
    {
        printf("Last occurrence: %c\n", *result);
        printf("Remaining string: %s\n", result);
    }

    return 0;
}
Expected Output: 
Last occurrence: M
Remaining string: MING

13. strstr() – Searching for a Substring

strstr() searches for the first occurrence of one string inside another string.

Syntax

strstr(main_string, substring);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char sentence[] = "C Programming Language";

    char *result = strstr(sentence, "Programming");

    if (result != NULL)
    {
        printf("Substring found.\n");
        printf("Matched text: %s\n", result);
    }
    else
    {
        printf("Substring not found.\n");
    }

    return 0;
}
Expected Output: 
Substring found.
Matched text: Programming Language

strstr() returns a pointer to the first character of the matching substring. It returns NULL if no match exists.

14. Practical Example: Username Comparison

String comparison is frequently used in programs that validate user-entered identifiers.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char stored_user[] = "admin";
    char entered_user[30];

    printf("Enter username: ");

    if (scanf("%29s", entered_user) != 1)
    {
        printf("Input error.\n");
        return 1;
    }

    if (strcmp(stored_user, entered_user) == 0)
    {
        printf("Username matched.\n");
    }
    else
    {
        printf("Invalid username.\n");
    }

    return 0;
}
Sample Input: 
admin
Expected Output: 
Enter username: admin
Username matched.
This example demonstrates string comparison only. Real authentication systems must use appropriate credential storage and security mechanisms.

15. String Library Function Comparison

Function Operation Important Requirement
strlen() Measures length Valid null-terminated source
strcpy() Copies string Destination must fit entire string
strncpy() Copies limited characters May not append null terminator
strcat() Appends string Destination must have sufficient remaining capacity
strncat() Appends limited characters Destination must still have sufficient capacity
strcmp() Compares strings Both strings must be valid
strncmp() Compares limited characters Compares at most n characters
strchr() Searches for character Returns pointer or NULL
strrchr() Searches last character occurrence Returns pointer or NULL
strstr() Searches for substring Returns pointer or NULL

16. Common Mistakes and Interview Traps

  • Using strcpy() without checking destination capacity.
  • Assuming strncpy() always null-terminates its destination.
  • Using strcat() without enough remaining array capacity.
  • Assuming strcmp() returns only -1, 0 or 1.
  • Comparing string contents using ==.
  • Forgetting to check search-function results against NULL.
  • Calling strlen() on an unterminated character array.
  • Assuming string comparisons are case-insensitive.
C string comparison is case-sensitive. For example, "Linux" and "LINUX" are not equal according to strcmp().
