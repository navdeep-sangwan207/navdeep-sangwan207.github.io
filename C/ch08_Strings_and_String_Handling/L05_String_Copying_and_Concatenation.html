Lecture 5: String Copying and Concatenation

Learn how to copy strings, append strings, manage destination-buffer capacity and implement copying and concatenation operations using C11.

1. Learning Objectives

  • Understand string copying and concatenation.
  • Use strcpy() to copy complete strings.
  • Understand the limitations of strncpy().
  • Use strcat() and strncat() to join strings.
  • Calculate destination capacity before copying or appending.
  • Implement string copying manually.
  • Implement string concatenation manually.
  • Understand overlapping source and destination restrictions.
  • Solve placement-oriented string manipulation problems.

2. Understanding String Copying

String copying means transferring the characters of one string into another character array, including the terminating null character.

Example

char source[] = "HELLO";
char destination[20];

strcpy(destination, source);

Before copying:

source:      H  E  L  L  O  \0

destination: Uninitialized array

After copying:

source:      H  E  L  L  O  \0

destination: H  E  L  L  O  \0
The source string remains unchanged. The destination receives its own copy of the string characters.

3. strcpy() – Copying a Complete String

strcpy() copies the source string, including its terminating null character, into the destination array.

Syntax

strcpy(destination, source);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "EMBEDDED C";
    char destination[30];

    strcpy(destination, source);

    printf("Source: %s\n", source);
    printf("Copied string: %s\n", destination);

    return 0;
}
Expected Output: 
Source: EMBEDDED C
Copied string: EMBEDDED C

Important Conditions

  • The source must be null-terminated.
  • The destination must have enough space for all source characters and '\0'.
  • The source and destination must not overlap.
strcpy() does not check the destination array size. Insufficient capacity causes undefined behavior.

4. Calculating Required Buffer Capacity

Before copying a string, calculate how much destination storage is required.

Example

char source[] = "PROGRAMMING";

The string contains 11 characters. One additional element is required for '\0'. 

Required capacity = String length + 1

                  = 11 + 1

                  = 12 elements

Correct Destination

char destination[12];

strcpy(destination, source);

Insufficient Destination

char destination[10];

strcpy(destination, source);  /* Undefined behavior */
Always ensure destination capacity is at least strlen(source) + 1 before copying a valid null-terminated string.

5. strncpy() – Limited String Copying

strncpy() copies at most n characters from the source into the destination.

Syntax

strncpy(destination, source, n);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "PROGRAMMING";
    char destination[20];

    strncpy(destination, source, 5);
    destination[5] = '\0';

    printf("Copied string: %s\n", destination);

    return 0;
}
Expected Output: 
Copied string: PROGR

Important Behavior

Condition Behavior
Source length is less than n Remaining destination positions are padded with '\0'.
Source length is at least n No terminating null character is guaranteed.
n is zero No characters are copied.
strncpy() is not automatically a safe replacement for strcpy(). When copying a truncated string, explicitly ensure null termination if the result will be used as a C string.

6. Manual Implementation of String Copying

String copying can be implemented without strcpy() by copying characters one at a time until the null terminator is reached.

Algorithm

  1. Initialize an index to zero.
  2. Read the current source character.
  3. Copy it into the corresponding destination position.
  4. Continue until the null character is copied.

Program

#include <stdio.h>

int main(void)
{
    char source[] = "EMBEDDED";
    char destination[20];

    int i = 0;

    while ((destination[i] = source[i]) != '\0')
    {
        i++;
    }

    printf("Source: %s\n", source);
    printf("Destination: %s\n", destination);

    return 0;
}
Expected Output: 
Source: EMBEDDED
Destination: EMBEDDED

Complexity Analysis

Complexity Value
Time O(n)
Auxiliary Space O(1), excluding the destination array.

7. Understanding String Concatenation

String concatenation means joining two strings into a single string.

Example

First string:  "HELLO "

Second string: "WORLD"

Result:        "HELLO WORLD"

The source string is appended after the existing characters in the destination string.

The original null terminator of the destination is replaced by the first appended character. A new null terminator is written at the end.

8. strcat() – Concatenating Two Strings

strcat() appends the source string to the end of the destination string.

Syntax

strcat(destination, source);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "HELLO ";
    char second[] = "WORLD";

    strcat(first, second);

    printf("Combined string: %s\n", first);

    return 0;
}
Expected Output: 
Combined string: HELLO WORLD

Required Capacity

Destination initial length = 6
Source length              = 5
Null terminator            = 1

Required capacity          = 6 + 5 + 1

                            = 12 elements

The declared destination array has 30 elements, so there is enough capacity for the result.

9. strncat() – Limited Concatenation

strncat() appends at most n characters from the source string to the destination.

Syntax

strncat(destination, source, n);

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char first[30] = "C PROGRAMMING ";
    char second[] = "LANGUAGE";

    strncat(first, second, 4);

    printf("Result: %s\n", first);

    return 0;
}
Expected Output: 
Result: C PROGRAMMING LANG

Only the first four characters of the source string are appended.

The third argument limits appended source characters, not total destination size. The destination must have enough space for its existing contents, appended characters and the final '\0'.

10. Manual Implementation of String Concatenation

Concatenation can be implemented using two loops: one to locate the destination terminator and another to copy the source string.

Algorithm

  1. Initialize an index to zero.
  2. Move the index to the end of the destination string.
  3. Copy source characters starting from that position.
  4. Continue until the source null terminator is copied.

Program

#include <stdio.h>

int main(void)
{
    char first[30] = "EMBEDDED ";
    char second[] = "SYSTEMS";

    int i = 0;
    int j = 0;

    /* Find the end of the first string */
    while (first[i] != '\0')
    {
        i++;
    }

    /* Append the second string */
    while ((first[i] = second[j]) != '\0')
    {
        i++;
        j++;
    }

    printf("Combined string: %s\n", first);

    return 0;
}
Expected Output: 
Combined string: EMBEDDED SYSTEMS

The destination array must have sufficient capacity for both strings and the final null terminator.

11. Safe Copying Using Explicit Capacity Checks

A reliable program should check destination capacity before copying a string.

Example Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char source[] = "MICROCONTROLLER";
    char destination[20];

    size_t source_length = strlen(source);
    size_t destination_capacity = sizeof(destination);

    if (source_length + 1 <= destination_capacity)
    {
        memcpy(destination, source, source_length + 1);

        printf("Copied successfully: %s\n", destination);
    }
    else
    {
        printf("Destination capacity is insufficient.\n");
    }

    return 0;
}
Expected Output: 
Copied successfully: MICROCONTROLLER

memcpy() copies a specified number of bytes. Here, the count includes the terminating null character.

memcpy() is declared in string.h. The source and destination regions must not overlap. For overlapping regions, memmove() is the appropriate byte-copying function.

12. Building a Reusable String Copy Function

A custom function can accept the destination capacity and report whether the copy succeeded.

Program

#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool copy_string(char *destination,
                 size_t capacity,
                 const char *source)
{
    size_t length = strlen(source);

    if (length + 1 > capacity)
    {
        return false;
    }

    memcpy(destination, source, length + 1);

    return true;
}

int main(void)
{
    char source[] = "DEVICE DRIVER";
    char destination[30];

    if (copy_string(destination,
                    sizeof(destination),
                    source))
    {
        printf("Copy successful: %s\n", destination);
    }
    else
    {
        printf("Destination too small.\n");
    }

    return 0;
}
Expected Output: 
Copy successful: DEVICE DRIVER

This function assumes source is a valid null-terminated string and that the source and destination do not overlap.

13. Copying Versus Concatenation

Feature Copying Concatenation
Purpose Transfer a string into another array. Append one string to another.
Standard function strcpy() strcat()
Limited function strncpy() strncat()
Existing destination content Replaced. Preserved and extended.
Capacity requirement Source length + 1. Destination length + source length + 1.

14. Common Mistakes and Interview Traps

  • Copying a string into an undersized array.
  • Forgetting the null terminator while calculating capacity.
  • Assuming strncpy() always terminates the destination.
  • Using strcat() without checking remaining capacity.
  • Assuming strncat() limits the total destination size.
  • Passing overlapping source and destination arrays to strcpy() or strcat().
  • Using an uninitialized destination as a strcat() destination.
  • Forgetting to initialize the destination before concatenation.
  • Using a source pointer that does not point to a valid string.
strcpy(), strncpy(), strcat() and strncat() have important capacity and termination requirements. A function name containing "n" does not automatically make an operation fully safe.

17. Lecture Summary

  • String copying transfers characters and the null terminator.
  • strcpy() copies a complete string.
  • strncpy() copies a limited number of characters but may not terminate the result.
  • strcat() appends one string to another.
  • strncat() appends a limited number of source characters.
  • Destination capacity must always be checked.
  • Manual copying and concatenation use character-by-character traversal.
  • Overlapping memory regions require special consideration.
  • These operations are important in embedded C, system programming and placement coding rounds.
