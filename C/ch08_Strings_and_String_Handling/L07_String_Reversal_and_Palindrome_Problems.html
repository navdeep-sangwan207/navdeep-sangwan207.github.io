2. What Is String Reversal?

String reversal means arranging the characters of a string in the opposite order.

Example

Original String Reversed String
HELLO OLLEH
EMBEDDED DEDDEBME
PROGRAM MARGORP

A common approach is to exchange the first and last characters, then move toward the center of the string.

3. Two-Pointer Technique

The two-pointer technique uses two indexes to process a sequence from opposite directions.

  • Initialize the left pointer at index 0.
  • Initialize the right pointer at the last character.
  • Exchange the characters at both positions.
  • Move the left pointer forward.
  • Move the right pointer backward.
  • Continue until both pointers meet or cross.

Example: Reversing HELLO

Initial:   H E L L O
           ^       ^
           L       R

Step 1:    O E L L H
             ^   ^

Step 2:    O L L E H
               ^ ^
               
Final:     O L L E H
The two-pointer technique is frequently used in array and string interview problems.

4. Reversing a String Using a Loop

The simplest in-place method swaps characters from both ends of the same character array.

Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[] = "HELLO";

    size_t left = 0;
    size_t right = strlen(str);

    if (right > 0)
    {
        right--;

        while (left < right)
        {
            char temp = str[left];

            str[left] = str[right];
            str[right] = temp;

            left++;
            right--;
        }
    }

    printf("Reversed string: %s\n", str);

    return 0;
}
Expected Output: 
Reversed string: OLLEH

Complexity Analysis

  • Time complexity: O(n).
  • Auxiliary space: O(1).

The original character array is modified directly. No second array is required.

5. Reversing a String Without strlen()

In coding interviews, you may be asked to implement string reversal without using string library functions.

Program

#include <stdio.h>

int main(void)
{
    char str[] = "PROGRAMMING";

    int length = 0;

    while (str[length] != '\0')
    {
        length++;
    }

    int left = 0;
    int right = length - 1;

    while (left < right)
    {
        char temp = str[left];

        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }

    printf("Reversed string: %s\n", str);

    return 0;
}
Expected Output: 
Reversed string: GNIMMARGORP
This implementation performs both length calculation and reversal in linear time. Its auxiliary space complexity is O(1).

6. Reversing a String Into Another Array

Sometimes the original string must remain unchanged. In that case, store the reversed characters in another array.

Program

#include <stdio.h>
#include <string.h>

int main(void)
{
    char original[] = "EMBEDDED";
    char reversed[sizeof(original)];

    size_t length = strlen(original);

    for (size_t i = 0; i < length; i++)
    {
        reversed[i] = original[length - 1 - i];
    }

    reversed[length] = '\0';

    printf("Original: %s\n", original);
    printf("Reversed: %s\n", reversed);

    return 0;
}
Expected Output: 
Original: EMBEDDED
Reversed: DEDDEBME

This method requires O(n) additional space for the destination array.

7. What Is a Palindrome?

A palindrome is a sequence that reads the same forward and backward under the comparison rules being used.

Examples

String Reverse Palindrome?
MADAM MADAM Yes
LEVEL LEVEL Yes
RADAR RADAR Yes
HELLO OLLEH No

Palindrome checking can be performed by comparing characters from both ends without creating a reversed copy.

8. Checking a Palindrome Using Two Pointers

Algorithm

  1. Find the length of the string.
  2. Initialize left at the first character.
  3. Initialize right at the last character.
  4. Compare the characters at both positions.
  5. If they differ, the string is not a palindrome.
  6. Otherwise, move both pointers toward the center.
  7. If every pair matches, the string is a palindrome.

Program

#include <stdio.h>
#include <string.h>

int is_palindrome(const char str[])
{
    size_t left = 0;
    size_t length = strlen(str);

    if (length == 0)
    {
        return 1;
    }

    size_t right = length - 1;

    while (left < right)
    {
        if (str[left] != str[right])
        {
            return 0;
        }

        left++;
        right--;
    }

    return 1;
}

int main(void)
{
    char str[] = "MADAM";

    if (is_palindrome(str))
    {
        printf("Palindrome string.\n");
    }
    else
    {
        printf("Not a palindrome.\n");
    }

    return 0;
}
Expected Output: 
Palindrome string.

Complexity

  • Time complexity: O(n).
  • Auxiliary space: O(1).

9. Case-Insensitive Palindrome Checking

In some problems, uppercase and lowercase characters should be treated as equivalent.

For example, "Madam" should be considered a palindrome even though M and m have different character values.

Program Using tolower()

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int is_palindrome_ignore_case(const char str[])
{
    size_t left = 0;
    size_t length = strlen(str);

    if (length == 0)
    {
        return 1;
    }

    size_t right = length - 1;

    while (left < right)
    {
        unsigned char a = (unsigned char)str[left];
        unsigned char b = (unsigned char)str[right];

        if (tolower(a) != tolower(b))
        {
            return 0;
        }

        left++;
        right--;
    }

    return 1;
}

int main(void)
{
    char str[] = "Madam";

    if (is_palindrome_ignore_case(str))
    {
        printf("Palindrome ignoring case.\n");
    }
    else
    {
        printf("Not a palindrome.\n");
    }

    return 0;
}
Expected Output: 
Palindrome ignoring case.
This uses the current C locale's character conversion rules. It does not implement full Unicode case folding.

10. Palindrome Checking While Ignoring Spaces and Punctuation

Some interview problems ask whether a sentence is a palindrome after ignoring spaces, punctuation and letter case.

Example

Input:
A man, a plan, a canal: Panama

Normalized comparison:
amanaplanacanalpanama

Result:
Palindrome

Program

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int is_alphanumeric_palindrome(const char str[])
{
    size_t left = 0;
    size_t right = strlen(str);

    if (right == 0)
    {
        return 1;
    }

    right--;

    while (left < right)
    {
        while (left < right &&
               !isalnum((unsigned char)str[left]))
        {
            left++;
        }

        while (left < right &&
               !isalnum((unsigned char)str[right]))
        {
            right--;
        }

        unsigned char a = (unsigned char)str[left];
        unsigned char b = (unsigned char)str[right];

        if (tolower(a) != tolower(b))
        {
            return 0;
        }

        left++;
        right--;
    }

    return 1;
}

int main(void)
{
    char str[] = "A man, a plan, a canal: Panama";

    if (is_alphanumeric_palindrome(str))
    {
        printf("Palindrome sentence.\n");
    }
    else
    {
        printf("Not a palindrome sentence.\n");
    }

    return 0;
}
Expected Output: 
Palindrome sentence.

This implementation skips characters that are not alphanumeric and compares the remaining characters without considering case.

11. Recursive String Reversal

Recursion can also reverse a string by swapping the characters at both ends and recursively processing the remaining inner portion.

Program

#include <stdio.h>
#include <string.h>

void reverse_recursive(char str[], size_t left, size_t right)
{
    if (left >= right)
    {
        return;
    }

    char temp = str[left];

    str[left] = str[right];
    str[right] = temp;

    reverse_recursive(str, left + 1, right - 1);
}

int main(void)
{
    char str[] = "COMPUTER";

    size_t length = strlen(str);

    if (length > 0)
    {
        reverse_recursive(str, 0, length - 1);
    }

    printf("Reversed string: %s\n", str);

    return 0;
}
Expected Output: 
Reversed string: RETUPMOC

Complexity

  • Time complexity: O(n).
  • Auxiliary call-stack space: O(n).
Recursive solutions consume stack space. For very long strings, an iterative approach is generally preferable.

12. Checking Whether Two Strings Are Reverse of Each Other

Another common problem is checking whether the second string is the reverse of the first.

Program

#include <stdio.h>
#include <string.h>

int are_reverse(const char a[], const char b[])
{
    size_t length_a = strlen(a);
    size_t length_b = strlen(b);

    if (length_a != length_b)
    {
        return 0;
    }

    for (size_t i = 0; i < length_a; i++)
    {
        if (a[i] != b[length_a - 1 - i])
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    char first[] = "HELLO";
    char second[] = "OLLEH";

    if (are_reverse(first, second))
    {
        printf("Strings are reverses of each other.\n");
    }
    else
    {
        printf("Strings are not reverses.\n");
    }

    return 0;
}
Expected Output: 
Strings are reverses of each other.

Complexity

  • Time complexity: O(n).
  • Auxiliary space: O(1).

13. Common Mistakes

  • Reversing the null terminator along with the characters.
  • Using an incorrect last index.
  • Accessing str[length] as if it were the last character.
  • Forgetting to terminate a destination string with '\0'.
  • Modifying a string literal instead of a writable character array.
  • Using two pointers without checking their stopping condition.
  • Ignoring uppercase and lowercase differences in palindrome problems.
  • Forgetting to skip punctuation and spaces when required.
  • Using recursion for very large strings without considering stack usage.
