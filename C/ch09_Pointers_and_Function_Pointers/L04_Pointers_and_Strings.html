Lecture 04: Pointers and Strings

Understand character pointers, string literals, character arrays, pointer-based traversal, string manipulation and safe string handling.

1. Learning Objectives

  • Understand how strings are represented in C memory.
  • Use character pointers to access strings.
  • Differentiate character arrays from character pointers.
  • Understand string literals and their restrictions.
  • Traverse strings using pointer arithmetic.
  • Pass strings to functions using pointers.
  • Modify character arrays safely.
  • Implement common string operations using pointers.
  • Avoid buffer overflows and invalid memory access.

2. Understanding Strings in C

C does not have a separate built-in string data type. A string is represented as an array of characters terminated by a null character, '\0'.

Example

char str[] = "HELLO";

The array contains six elements:

Index Character
0H
1E
2L
3L
4O
5\0

The null character marks the end of the string. It is not the same as the NULL pointer macro.

3. What Is a Character Pointer?

A character pointer is a pointer variable whose pointed-to type is char. It can point to a character or to the first character of a string.

Syntax

char *ptr;

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "HELLO";

    char *ptr = str;

    printf("%s\n", ptr);

    return 0;
}
Expected Output: 
HELLO

The array expression str is converted to a pointer to its first element in this initialization.

4. Character Array vs Character Pointer

A character array stores the characters themselves. A character pointer stores an address.

Character Array

char str[] = "HELLO";

Character Pointer

const char *ptr = "HELLO";
Feature Character Array Character Pointer to Literal
Storage Array stores character elements. Pointer stores an address.
Character modification Allowed within the array bounds. Not allowed through this const-qualified pointer.
Reassignment Array cannot be reassigned. Pointer can be reassigned.
Typical use Modifiable string storage. Read-only string access.

Example: Modifying an Array

#include <stdio.h>

int main(void)
{
    char str[] = "HELLO";

    str[0] = 'Y';

    printf("%s\n", str);

    return 0;
}
Expected Output: 
YELLO

5. String Literals and Pointer Safety

A string literal such as "HELLO" has static storage duration. Attempting to modify a string literal results in undefined behavior.

Correct Declaration

const char *ptr = "HELLO";

The const qualifier prevents modification of the characters through ptr.

Incorrect Practice

char *ptr = "HELLO";

ptr[0] = 'Y';   // Undefined behavior
Do not modify string literals. Use a character array when a string must be changed.

6. Accessing Individual Characters Using Pointers

The dereference operator can access the character stored at the address held by a character pointer.

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "COMPUTER";

    char *ptr = str;

    printf("First character = %c\n", *ptr);

    printf("Third character = %c\n", *(ptr + 2));

    printf("Sixth character = %c\n", *(ptr + 5));

    return 0;
}
Expected Output: 
First character = C
Third character = M
Sixth character = T

Pointer arithmetic advances by character elements. Since sizeof(char) is defined as 1, each increment moves to the next character.

7. Traversing a String Using Pointer Increment

A string can be traversed by incrementing a character pointer until the null terminator is encountered.

Example Program

#include <stdio.h>

int main(void)
{
    char str[] = "EMBEDDED";

    char *ptr = str;

    while (*ptr != '\0')
    {
        printf("%c ", *ptr);
        ptr++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
E M B E D D E D

The loop terminates when the pointer reaches the null character.

8. Finding String Length Using Pointers

String length can be calculated by counting characters until '\0' is encountered.

Example Program

#include <stdio.h>

size_t string_length(const char *str)
{
    size_t length = 0;

    while (str[length] != '\0')
    {
        length++;
    }

    return length;
}

int main(void)
{
    char text[] = "POINTER";

    printf("Length = %zu\n", string_length(text));

    return 0;
}
Expected Output: 
Length = 7

Time complexity: O(n). Auxiliary space: O(1).

This function assumes str points to a valid, null-terminated string. A NULL pointer or an unterminated character array must not be passed.

9. Passing Strings to Functions Using Pointers

A string can be passed to a function using a character pointer. A const-qualified parameter is appropriate when the function only reads the string.

Example Program

#include <stdio.h>

void display_string(const char *str)
{
    printf("String = %s\n", str);
}

int main(void)
{
    char text[] = "C PROGRAMMING";

    display_string(text);

    return 0;
}
Expected Output: 
String = C PROGRAMMING

The function receives a pointer to the first character. The array is not copied into the function.

10. Modifying a String Through a Pointer

A pointer can modify an array when it points to writable character storage.

Example Program

#include <stdio.h>

void convert_to_uppercase(char *str)
{
    while (*str != '\0')
    {
        if (*str >= 'a' && *str <= 'z')
        {
            *str = *str - ('a' - 'A');
        }

        str++;
    }
}

int main(void)
{
    char text[] = "embedded c";

    convert_to_uppercase(text);

    printf("%s\n", text);

    return 0;
}
Expected Output: 
EMBEDDED C

The function modifies the original array because the pointer refers to its elements.

This example uses the basic English alphabet. For locale-aware character conversion, use functions such as toupper() with an unsigned-char conversion where required.

11. Copying a String Using Pointers

A source string can be copied into a destination array using pointer traversal.

Example Program

#include <stdio.h>
#include <stddef.h>

int copy_string(char *destination,
                size_t capacity,
                const char *source)
{
    size_t i = 0;

    if (destination == NULL || source == NULL ||
        capacity == 0)
    {
        return 0;
    }

    while (source[i] != '\0')
    {
        if (i >= capacity - 1)
        {
            destination[i] = '\0';
            return 0;
        }

        destination[i] = source[i];
        i++;
    }

    destination[i] = '\0';

    return 1;
}

int main(void)
{
    char source[] = "MICROCONTROLLER";
    char destination[30];

    if (copy_string(destination,
                    sizeof destination,
                    source))
    {
        printf("Copied string = %s\n", destination);
    }
    else
    {
        printf("Destination too small\n");
    }

    return 0;
}
Expected Output: 
Copied string = MICROCONTROLLER

Time complexity: O(n). Auxiliary space: O(1). The destination capacity includes space for the terminating null character.

This implementation assumes the source and destination do not overlap. Overlapping copies require a different strategy.

12. Comparing Two Strings Using Pointers

Two strings can be compared character by character until a mismatch or the end of both strings.

Example Program

#include <stdio.h>

int compare_strings(const char *a, const char *b)
{
    while (*a != '\0' && *a == *b)
    {
        a++;
        b++;
    }

    return (unsigned char)*a - (unsigned char)*b;
}

int main(void)
{
    char first[] = "EMBEDDED";
    char second[] = "EMBEDDED";

    if (compare_strings(first, second) == 0)
    {
        printf("Strings are equal\n");
    }
    else
    {
        printf("Strings are different\n");
    }

    return 0;
}
Expected Output: 
Strings are equal

Time complexity: O(n) in the worst case. Auxiliary space: O(1).

The function follows the same comparison principle as strcmp(), assuming both arguments point to valid null-terminated strings.

13. Reversing a String Using Two Pointers

Two pointers can be used to reverse a writable character array in place.

Example Program

#include <stdio.h>

void reverse_string(char *str)
{
    char *left = str;
    char *right = str;

    while (*right != '\0')
    {
        right++;
    }

    if (right == left)
    {
        return;
    }

    right--;

    while (left < right)
    {
        char temp = *left;

        *left = *right;
        *right = temp;

        left++;
        right--;
    }
}

int main(void)
{
    char text[] = "POINTER";

    reverse_string(text);

    printf("Reversed = %s\n", text);

    return 0;
}
Expected Output: 
Reversed = RETNIOP

Time complexity: O(n). Auxiliary space: O(1). The input must be a writable null-terminated array.

14. Array of String Pointers

An array of character pointers can store addresses of multiple strings.

Example

#include <stdio.h>

int main(void)
{
    const char *languages[] = {
        "C",
        "C++",
        "Python",
        "Java"
    };

    int count = sizeof(languages) / sizeof(languages[0]);

    for (int i = 0; i < count; i++)
    {
        printf("%s\n", languages[i]);
    }

    return 0;
}
Expected Output: 
C
C++
Python
Java

Each array element is a pointer to const char. The strings are not copied into separate fixed-size character arrays by this declaration.

15. Pointer to Pointer for Strings

A pointer to pointer is useful when working with arrays of string pointers or when a function needs to modify a caller's pointer variable.

Example Program

#include <stdio.h>

int main(void)
{
    const char *languages[] = {
        "C",
        "C++",
        "Java"
    };

    const char **ptr = languages;

    printf("%s\n", *ptr);

    ptr++;

    printf("%s\n", *ptr);

    ptr++;

    printf("%s\n", *ptr);

    return 0;
}
Expected Output: 
C
C++
Java

ptr points to an element of the languages array. Each element itself is a pointer to const char.

16. Pointer to String vs Array of Strings

Declaration Meaning
char str[] = "HELLO"; Character array containing a writable copy of the string.
const char *ptr = "HELLO"; Pointer to the first character of a string literal, accessed as const.
char *arr[3]; Array of three pointers to char.
char arr[3][20]; Two-dimensional character array with three rows of twenty characters each.
const char **ptr; Pointer to a pointer to const char.

17. Pointer and String Memory Safety

Important Rules

  • Always ensure a string has a terminating '\0' before using string functions.
  • Do not modify string literals.
  • Ensure destination arrays have sufficient capacity.
  • Do not dereference NULL pointers.
  • Do not access memory after its lifetime ends.
  • Do not move a pointer outside its permitted array range.
  • Use const char * when a function only reads a string.
  • Use char * when a function must modify writable character storage.
A pointer does not contain the length or capacity of the character array it points to. Pass the capacity separately whenever a function writes into a destination buffer.

22. Key Takeaways

  • C strings are null-terminated character sequences.
  • A character pointer stores an address, not the string length.
  • Character arrays provide writable string storage.
  • String literals must not be modified.
  • const char * is suitable for read-only string access.
  • Pointer increment can traverse a string character by character.
  • Strings can be passed to functions using character pointers.
  • Two-pointer techniques are useful for string reversal and comparison.
  • Destination capacity must be considered during string copying.
  • Pointer validity and string termination must always be respected.
Placement preparation target: Be able to explain character arrays versus character pointers, trace pointer-based string traversal, write string operations using pointers, and identify unsafe string handling.
