Lecture 01: Pointer Fundamentals and Address Operators

Understand memory addresses, pointer variables, address-of operator, dereferencing and the relationship between variables and pointers.

  • Understand why pointers are required in C.

  • Learn memory addresses and address representation.
  • Declare pointer variables using the correct syntax.
  • Use the address-of operator (&).

  • Read and modify values through pointers.

  • Write basic pointer-based C11 programs.

2. What Is a Pointer?

A pointer is a variable whose value is used to refer to an object or function. In ordinary object-pointer usage, it stores the address of an object in memory.

Unlike a normal variable, which directly stores a data value, a pointer stores an address that can be used to access another variable.

Normal Variable

int number = 100;

The variable number stores the integer value 100.

Pointer Variable

int *ptr = &number;

The pointer ptr stores the address of number.

Remember: A pointer is not the data stored in the target variable. It holds a value that identifies where that object can be accessed.

3. Understanding Memory Addresses

When a program executes, its objects are stored in memory according to their storage duration and implementation requirements.

Each byte in a conventional byte-addressed memory has an address. A variable occupies one or more bytes depending on its type and implementation.

Example

int number = 25;

Suppose the implementation places number at address 1000. This is only an illustrative address, not a guaranteed address.

Item Illustrative Value
Variable name number
Stored value 25
Illustrative address 1000

The actual address and object size depend on the compiler, platform and execution environment.

Do not assume that an integer always occupies four bytes or that variables always receive predictable memory addresses.

4. Address-of Operator (&)

The address-of operator & returns the address of an object when applied to an appropriate object expression.

Syntax

&variable_name

Example Program

#include <stdio.h>

int main(void)
{
    int number = 50;

    printf("Value of number = %d\n", number);
    printf("Address of number = %p\n", (void *)&number);

    return 0;
}
Sample Output: 
Value of number = 50
Address of number = 0x7ffe1234

The address shown is illustrative. Your system will display a different address.

Important Points

  • &number gives the address of number.
  • The result is suitable for initialization of a compatible pointer.
  • %p is the standard printf conversion specifier for a pointer.
  • Convert an object pointer to void * when passing it to %p.

5. Pointer Declaration

A pointer must be declared with a type that describes the type of object it can point to.

Syntax

data_type *pointer_name;

Examples

int *ptr;
char *ch_ptr;
float *float_ptr;
double *double_ptr;
Declaration Pointer Target Type
int *ptr; int
char *ptr; char
float *ptr; float
double *ptr; double

Important Declaration Rule

int *p1, *p2;
int *p3, value;

In the first declaration, p1 and p2 are pointers to int. In the second declaration, p3 is a pointer to int, while value is a normal int.

6. Initializing a Pointer

A pointer should be initialized with a valid address before it is dereferenced.

Example

#include <stdio.h>

int main(void)
{
    int number = 100;

    int *ptr = &number;

    printf("Number = %d\n", number);
    printf("Pointer address = %p\n", (void *)ptr);

    return 0;
}
Sample Output: 
Number = 100
Pointer address = 0x7ffe1234

The address is system-dependent.

What Happens Internally?

  1. An integer object named number is created.
  2. The value 100 is stored in that object.
  3. The address of number is obtained using &.
  4. The pointer ptr is initialized with that address.

7. Dereference Operator (*)

The dereference operator * accesses the object referred to by a valid pointer.

Syntax

*pointer_name

Example

#include <stdio.h>

int main(void)
{
    int number = 75;

    int *ptr = &number;

    printf("Value using variable = %d\n", number);
    printf("Value using pointer = %d\n", *ptr);

    return 0;
}
Expected Output: 
Value using variable = 75
Value using pointer = 75

Both expressions access the same integer object: number and *ptr.

Important distinction: In a declaration such as int *ptr, the * indicates that ptr is a pointer to int. In an expression such as *ptr, it is the dereference operator.

8. Modifying a Variable Through a Pointer

A pointer can be used to modify its target object when the target is a modifiable object.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 10;

    int *ptr = &number;

    printf("Before modification = %d\n", number);

    *ptr = 200;

    printf("After modification = %d\n", number);

    return 0;
}
Expected Output: 
Before modification = 10
After modification = 200

Explanation

  1. number initially stores 10.
  2. ptr points to number.
  3. *ptr accesses the object number.
  4. Assigning 200 to *ptr changes number.

9. Relationship Between a Variable and Its Pointer

Consider the following program:

#include <stdio.h>

int main(void)
{
    int value = 40;
    int *ptr = &value;

    printf("value = %d\n", value);
    printf("*ptr = %d\n", *ptr);

    printf("&value = %p\n", (void *)&value);
    printf("ptr = %p\n", (void *)ptr);

    return 0;
}

Since ptr was initialized using &value, ptr and &value represent the same address. Dereferencing ptr accesses value.

Expression Meaning
value Value stored in the integer object.
&value Address of the integer object.
ptr Address stored in the pointer.
*ptr Value of the object pointed to by ptr.
&ptr Address of the pointer variable itself.

10. Pointer to Different Data Types

A pointer type determines the type of object accessed through dereferencing.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 25;
    char letter = 'A';
    float decimal = 12.5f;
    double value = 45.678;

    int *p1 = &number;
    char *p2 = &letter;
    float *p3 = &decimal;
    double *p4 = &value;

    printf("Integer = %d\n", *p1);
    printf("Character = %c\n", *p2);
    printf("Float = %.2f\n", *p3);
    printf("Double = %.3f\n", *p4);

    return 0;
}
Expected Output: 
Integer = 25
Character = A
Float = 12.50
Double = 45.678

11. Pointer and Variable Size

A pointer stores an address, regardless of whether it points to an int, char, float or double. However, different pointer types are not necessarily the same size on every implementation.

Example Program

#include <stdio.h>

int main(void)
{
    int *p1;
    char *p2;
    float *p3;
    double *p4;

    printf("Size of int pointer = %zu\n", sizeof(p1));
    printf("Size of char pointer = %zu\n", sizeof(p2));
    printf("Size of float pointer = %zu\n", sizeof(p3));
    printf("Size of double pointer = %zu\n", sizeof(p4));

    return 0;
}

The sizes are implementation-dependent. Many modern systems use the same pointer size for these object pointer types, but C does not require all object pointer types to have identical representations or sizes.

Do not confuse the size of a pointer with the size of the object it points to. Use sizeof(*ptr) to obtain the size of the pointed-to type when ptr has a valid declared type.

12. Multiple Pointers to the Same Variable

More than one pointer can refer to the same object.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 500;

    int *ptr1 = &number;
    int *ptr2 = &number;

    printf("Using ptr1 = %d\n", *ptr1);
    printf("Using ptr2 = %d\n", *ptr2);

    *ptr1 = 700;

    printf("After modification = %d\n", *ptr2);

    return 0;
}
Expected Output: 
Using ptr1 = 500
Using ptr2 = 500
After modification = 700

Both pointers refer to the same object. Modifying the object through one pointer is visible when accessing it through the other.

13. Practical Example: Swap Two Variables Using Pointers

This program demonstrates how pointers can provide access to caller variables through function parameters. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Before swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    return 0;
}
Expected Output: 
Before swapping:
x = 10, y = 20
After swapping:
x = 20, y = 10

This is an introduction to pointers as function arguments. The complete treatment of pointer parameters and address passing is covered in Lecture 05.

14. Common Pointer Errors

Error 1: Dereferencing an Uninitialized Pointer

int *ptr;

*ptr = 100;   // Undefined behavior

ptr has not been initialized to refer to a valid object. Dereferencing it is invalid.

Error 2: Using an Incompatible Pointer Type

int number = 10;
float *ptr = &number;   // Incompatible pointer types

A pointer should have a compatible type for accessing the pointed-to object.

Error 3: Dereferencing NULL

int *ptr = NULL;

printf("%d", *ptr);   // Undefined behavior

NULL does not refer to a valid object. It must not be dereferenced.

Error 4: Returning the Address of a Local Variable

int *get_value(void)
{
    int number = 50;

    return &number;
}

The local object ceases to exist when the function returns. The returned pointer is therefore invalid for accessing that object.

Never dereference a pointer unless it is known to point to a live object of the appropriate type.

18. Practical Applications of Pointers

Application Pointer Usage
Dynamic memory allocation Access dynamically allocated memory.
Arrays and strings Traverse and manipulate array elements.
Data structures Connect nodes in linked lists and trees.
Embedded systems Access memory-mapped hardware registers through suitable pointer types.
System programming Work with memory buffers and operating-system interfaces.
Function arguments Allow functions to access and modify caller objects.

19. Key Takeaways

  • A pointer is an object that stores a pointer value.
  • The address-of operator & obtains an object's address.
  • The dereference operator * accesses the pointed-to object.
  • Pointer declarations specify the pointed-to type.
  • Multiple pointers can refer to the same object.
  • Pointer-based modification changes the target object.
  • Uninitialized, invalid and NULL pointers must not be dereferenced.
  • Pointer size and representation are implementation-dependent.
