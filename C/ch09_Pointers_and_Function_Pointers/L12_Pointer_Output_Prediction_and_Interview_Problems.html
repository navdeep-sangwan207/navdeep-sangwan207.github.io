2. Quick Pointer Revision

Expression Meaning
int *ptr; Pointer to int.
ptr = &x; Store the address of x.
*ptr Access the object pointed to by ptr.
ptr + 1 Advance by one int element.
ptr++ Advance the pointer by one element.
arr[i] Equivalent to *(arr + i).
int **ptr; Pointer to pointer to int.
int (*ptr)[5]; Pointer to an array of five integers.
int (*fp)(int, int); Pointer to a function returning int.

3. Output Prediction: Basic Pointers

Question 1: Dereferencing a Pointer

#include <stdio.h>

int main(void)
{
    int x = 10;
    int *ptr = &x;

    printf("%d\n", *ptr);

    return 0;
}
Expected Output: 
10

ptr stores the address of x. Dereferencing ptr accesses the value stored in x.

10. Pointer Expression Tracing

Question 20: Pointer Increment and Dereference

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30};

    int *ptr = arr;

    printf("%d\n", *ptr++);
    printf("%d\n", *ptr);

    return 0;
}
Expected Output: 
10
20

*ptr++ is equivalent to *(ptr++). The original pointer value is dereferenced, then ptr advances to the next element.

Question 21: Parentheses Change the Meaning

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30};

    int *ptr = arr;

    printf("%d\n", (*ptr)++);

    printf("%d\n", arr[0]);

    return 0;
}
Expected Output: 
10
11

(*ptr)++ increments the pointed-to integer. It does not advance the pointer.

11. Identify Undefined Behavior

In technical interviews, recognizing when a program has no defined output is just as important as calculating a valid output.

Question 22: Dereferencing an Uninitialized Pointer

int *ptr;

*ptr = 10;

Answer:

Undefined behavior. ptr has an indeterminate value and does not identify a valid object.

Question 23: Dereferencing NULL

int *ptr = NULL;

printf("%d", *ptr);

Answer:

Undefined behavior. A NULL pointer does not point to an object that can be dereferenced.

Question 24: Accessing an Array Beyond Its Bounds

int arr[3] = {10, 20, 30};

printf("%d", arr[5]);

Answer:

Undefined behavior. The index 5 is outside the valid array indices 0, 1 and 2.

Question 25: Use-After-Free

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    *ptr = 20;

    free(ptr);

    printf("%d", *ptr);
}

Answer:

Undefined behavior. The allocation has been released before the final dereference.

Question 26: Modifying a String Literal

char *ptr = "HELLO";

ptr[0] = 'Y';

Answer:

Undefined behavior. A string literal must not be modified. Use a modifiable character array when changes are required.

Do not assume that undefined behavior always produces a crash. A program may appear to work on one system and fail on another.

12. Pointer Coding Problem 1: Swap Two Numbers

Write a function that swaps two integer values using pointers. 

#include <stdio.h>

void swap(int *a, int *b)
{
    if (a == NULL || b == NULL)
    {
        return;
    }

    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    swap(&x, &y);

    printf("x = %d, y = %d\n", x, y);

    return 0;
}
Expected Output: 
x = 20, y = 10

Interview Concept: Passing addresses allows a function to modify caller-owned objects.

13. Pointer Coding Problem 2: Find Maximum Element

Find the maximum element of an array using pointer traversal. 

#include <stdio.h>
#include <stddef.h>

int find_max(const int *arr, size_t size, int *result)
{
    if (arr == NULL || result == NULL || size == 0)
    {
        return 0;
    }

    int maximum = *arr;

    for (size_t i = 1; i < size; i++)
    {
        if (*(arr + i) > maximum)
        {
            maximum = *(arr + i);
        }
    }

    *result = maximum;

    return 1;
}

int main(void)
{
    int arr[] = {12, 45, 8, 67, 23};
    int maximum;

    size_t size = sizeof arr / sizeof arr[0];

    if (find_max(arr, size, &maximum))
    {
        printf("Maximum = %d\n", maximum);
    }

    return 0;
}
Expected Output: 
Maximum = 67

Interview Concept: Pointer traversal and input validation.

14. Pointer Coding Problem 3: Reverse an Array

Reverse an integer array in place using two pointers. 

#include <stdio.h>
#include <stddef.h>

void reverse_array(int *arr, size_t size)
{
    if (arr == NULL || size < 2)
    {
        return;
    }

    int *left = arr;
    int *right = arr + size - 1;

    while (left < right)
    {
        int temp = *left;

        *left = *right;
        *right = temp;

        left++;
        right--;
    }
}

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    size_t size = sizeof arr / sizeof arr[0];

    reverse_array(arr, size);

    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
50 40 30 20 10

Interview Concept: Two-pointer technique and in-place array manipulation.

15. Pointer Coding Problem 4: String Length Without strlen()

Calculate the length of a string using pointer traversal. 

#include <stdio.h>
#include <stddef.h>

size_t string_length(const char *str)
{
    const char *ptr = str;

    if (str == NULL)
    {
        return 0;
    }

    while (*ptr != '\0')
    {
        ptr++;
    }

    return (size_t)(ptr - str);
}

int main(void)
{
    const char text[] = "Embedded C";

    printf("Length = %zu\n", string_length(text));

    return 0;
}
Expected Output: 
Length = 10

Interview Concept: Null termination and pointer subtraction.

16. Pointer Coding Problem 5: Count Vowels in a String

#include <stdio.h>

int is_vowel(char ch)
{
    return ch == 'a' || ch == 'e' ||
           ch == 'i' || ch == 'o' ||
           ch == 'u' || ch == 'A' ||
           ch == 'E' || ch == 'I' ||
           ch == 'O' || ch == 'U';
}

int count_vowels(const char *str)
{
    if (str == NULL)
    {
        return 0;
    }

    int count = 0;

    while (*str != '\0')
    {
        if (is_vowel(*str))
        {
            count++;
        }

        str++;
    }

    return count;
}

int main(void)
{
    const char text[] = "Embedded Systems";

    printf("Vowels = %d\n", count_vowels(text));

    return 0;
}
Expected Output: 
Vowels = 5

Interview Concept: Character processing through pointers.

17. Pointer Coding Problem 6: Dynamic Array Allocation

Allocate memory dynamically, initialize an integer array, calculate its sum and release the allocated storage. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t count = 5;

    int *arr = malloc(count * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (size_t i = 0; i < count; i++)
    {
        arr[i] = (int)(i + 1) * 10;
    }

    int sum = 0;

    for (size_t i = 0; i < count; i++)
    {
        sum += arr[i];
    }

    printf("Sum = %d\n", sum);

    free(arr);
    arr = NULL;

    return 0;
}
Expected Output: 
Sum = 150

Interview Concept: Dynamic memory allocation, pointer access and cleanup.

18. Pointer Coding Problem 7: Find a Character in a String

Write a function that returns a pointer to the first occurrence of a character in a string. 

#include <stdio.h>

const char *find_character(const char *str, char target)
{
    if (str == NULL)
    {
        return NULL;
    }

    while (*str != '\0')
    {
        if (*str == target)
        {
            return str;
        }

        str++;
    }

    return NULL;
}

int main(void)
{
    const char text[] = "Embedded Systems";

    const char *result = find_character(text, 'S');

    if (result != NULL)
    {
        printf("Found: %s\n", result);
    }
    else
    {
        printf("Character not found\n");
    }

    return 0;
}
Expected Output: 
Found: Systems

Interview Concept: Returning a pointer into caller-owned storage. The caller must keep the original string alive while using the returned pointer.

21. Advanced Interview Discussion

Q1. Is an array name a pointer?

No. An array is an array object, not a pointer variable. In most expressions, an array expression is converted to a pointer to its first element. Important exceptions include use with sizeof and unary &.

Q2. What is the difference between int **p and int (*p)[5]?

int **p is a pointer to a pointer to int. int (*p)[5] is a pointer to an array of five integers. These types are not interchangeable.

Q3. Can pointer arithmetic be performed on void pointers?

Standard C does not define arithmetic on void pointers because void has no object size. Convert to a pointer to an appropriate object type before performing pointer arithmetic.

Q4. What happens if malloc() fails?

malloc() returns NULL when allocation fails. The program should check the result before accessing the allocated memory.

Q5. Can a pointer be used after free()?

It must not be used to access the released object. The allocation's lifetime has ended. Assigning NULL to the pointer can help prevent accidental reuse through that variable.

Q6. Why are function pointers useful in embedded systems?

They support callbacks, interrupt-related dispatch designs, driver interfaces and configurable operations. They help separate hardware-specific handling from application behavior.

22. Debugging Checklist for Pointer Programs

  • Is every pointer initialized before use?
  • Does each pointer refer to a valid object?
  • Is the object still within its lifetime?
  • Are array indices within valid bounds?
  • Is pointer arithmetic performed within the same array object or one past its end?
  • Is one-past-the-end pointer dereferencing avoided?
  • Are dynamic allocations checked for NULL?
  • Is every allocation released exactly once?
  • Are aliases managed after memory deallocation?
  • Are function pointer signatures compatible?
  • Are string literals treated as read-only?
  • Are const qualifiers used appropriately?
