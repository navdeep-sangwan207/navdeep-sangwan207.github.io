Lecture 07: Void Pointers and Const Pointers

Understand generic pointers, type conversion, pointer qualifiers, read-only access and memory-safe pointer programming in C.

1. Learning Objectives

  • Understand the purpose of void pointers.
  • Declare and initialize generic pointers.
  • Convert void pointers to object pointer types.
  • Understand why void pointers cannot be directly dereferenced.
  • Use void pointers in generic functions.
  • Understand const-qualified pointers.
  • Differentiate pointer-to-const and const-pointer declarations.
  • Apply const correctness in function parameters.
  • Identify common pointer qualification errors.

2. What Is a Void Pointer?

A void pointer is a generic object pointer that can hold the address of an object of any data type. It is declared using void *.

Syntax

void *ptr;

Unlike an int * or char *, a void pointer does not specify the type of object it points to.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 100;

    void *ptr = &number;

    printf("Address stored in pointer: %p\n", ptr);

    printf("Value = %d\n", *(int *)ptr);

    return 0;
}
Expected Output: 
Address stored in pointer: (implementation-dependent)
Value = 100

The address representation depends on the implementation. The pointer is converted to int * before the integer is accessed.

3. Why Is a Void Pointer Called a Generic Pointer?

A void pointer can store addresses of different object types without requiring a separate pointer variable for each type.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 10;
    float price = 25.5f;
    char letter = 'A';

    void *ptr;

    ptr = &number;
    printf("Integer = %d\n", *(int *)ptr);

    ptr = &price;
    printf("Float = %.2f\n", *(float *)ptr);

    ptr = &letter;
    printf("Character = %c\n", *(char *)ptr);

    return 0;
}
Expected Output: 
Integer = 10
Float = 25.50
Character = A

The correct type conversion is required before accessing the object through the void pointer.

4. Why Cannot a Void Pointer Be Directly Dereferenced?

A void pointer does not identify the type of object it points to. Therefore, the compiler cannot determine the size or type of the object to access through direct dereferencing.

Invalid Operation

int number = 50;

void *ptr = &number;

/* printf("%d", *ptr); */  // Constraint violation

Correct Operation

printf("%d", *(int *)ptr);
In C, an object pointer can be converted to void * and back to its original object pointer type. The original object type must be used correctly when accessing the stored object.

5. Pointer Arithmetic with Void Pointers

Standard C does not define arithmetic directly on void pointers because void has no object size.

Invalid Standard C11 Example

void *ptr;

/* ptr++; */  // Not valid standard C

Correct Approach Using Character Pointers

#include <stdio.h>

int main(void)
{
    int numbers[] = {10, 20, 30};

    void *ptr = numbers;

    int *int_ptr = ptr;

    printf("%d\n", *int_ptr);

    int_ptr++;

    printf("%d\n", *int_ptr);

    return 0;
}
Expected Output: 
10
20

A conversion to the appropriate object pointer type allows arithmetic according to that type's element size.

Some compilers support arithmetic on void * as an extension. Do not rely on this behavior in portable C11 programs.

6. Generic Function Using Void Pointer

A void pointer can be used to write functions that accept addresses of different object types. The function must know the actual type before accessing the object.

Example: Generic Display Function

#include <stdio.h>

enum DataType
{
    TYPE_INT,
    TYPE_FLOAT,
    TYPE_CHAR
};

void display_value(const void *data, enum DataType type)
{
    if (data == NULL)
    {
        return;
    }

    switch (type)
    {
        case TYPE_INT:
            printf("Integer = %d\n", *(const int *)data);
            break;

        case TYPE_FLOAT:
            printf("Float = %.2f\n", *(const float *)data);
            break;

        case TYPE_CHAR:
            printf("Character = %c\n", *(const char *)data);
            break;
    }
}

int main(void)
{
    int number = 100;
    float price = 15.75f;
    char grade = 'A';

    display_value(&number, TYPE_INT);
    display_value(&price, TYPE_FLOAT);
    display_value(&grade, TYPE_CHAR);

    return 0;
}
Expected Output: 
Integer = 100
Float = 15.75
Character = A

The enum tells the function which object type is being passed. This is important because void * does not carry runtime type information.

7. What Is a Const Pointer?

The const keyword can be applied to a pointer declaration to restrict modification of either the pointed-to object, the pointer itself, or both.

There are four important pointer declarations to understand.

8. Pointer to Constant Data

const int *ptr;

This is a pointer to a constant integer. The pointer can be changed to point to another integer, but the integer cannot be modified through this pointer.

Example Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;

    const int *ptr = &a;

    printf("Value = %d\n", *ptr);

    ptr = &b;

    printf("New value = %d\n", *ptr);

    /* *ptr = 50; */  // Not allowed through ptr

    return 0;
}
Expected Output: 
Value = 10
New value = 20

9. Constant Pointer to Variable Data

int *const ptr = &number;

This is a constant pointer to an integer. The pointer must be initialized during declaration and cannot be reassigned afterward. The pointed-to integer can be modified through the pointer.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 10;
    int another = 20;

    int *const ptr = &number;

    *ptr = 100;

    printf("Number = %d\n", number);

    /* ptr = &another; */  // Not allowed

    return 0;
}
Expected Output: 
Number = 100

10. Constant Pointer to Constant Data

const int *const ptr = &number;

This declaration prevents both reassignment of the pointer and modification of the pointed-to integer through that pointer.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 50;

    const int *const ptr = &number;

    printf("Value = %d\n", *ptr);

    /* *ptr = 100; */  // Not allowed
    /* ptr = NULL; */  // Not allowed

    return 0;
}
Expected Output: 
Value = 50

11. Comparison of Pointer Qualifiers

Declaration Modify Data Through Pointer? Reassign Pointer?
int *ptr Yes Yes
const int *ptr No Yes
int *const ptr Yes No
const int *const ptr No No
Remember: const applies to the type immediately to its left, or to the type immediately to its right when nothing appears on the left.

12. Passing Const Pointers to Functions

Function parameters can use const qualifiers to express whether the function is permitted to modify the pointed-to data.

Example: Read-Only Array Function

#include <stdio.h>
#include <stddef.h>

void display_array(const int *arr, size_t size)
{
    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int numbers[] = {10, 20, 30, 40};

    display_array(numbers,
                  sizeof numbers / sizeof numbers[0]);

    return 0;
}
Expected Output: 
10 20 30 40

The function can read array elements but cannot modify them through arr.

13. Const Correctness in C Programming

Const correctness means using const wherever data should not be modified through a particular pointer or function interface.

Example: Calculate Array Sum

#include <stdio.h>
#include <stddef.h>

int calculate_sum(const int *arr, size_t size)
{
    int sum = 0;

    for (size_t i = 0; i < size; i++)
    {
        sum += arr[i];
    }

    return sum;
}

int main(void)
{
    int values[] = {5, 10, 15, 20};

    size_t size = sizeof values / sizeof values[0];

    printf("Sum = %d\n", calculate_sum(values, size));

    return 0;
}
Expected Output: 
Sum = 50

The const-qualified parameter documents that calculate_sum() reads the array but does not modify its elements.

14. Const Pointers and String Literals

String literals should be accessed through pointers to const char.

Correct Declaration

const char *message = "HELLO";

The pointer can be reassigned, but the characters must not be modified through it.

Constant Pointer to a String Literal

const char *const message = "HELLO";

Neither the pointer nor the characters can be modified through this declaration.

Adding const to a pointer does not make an underlying object constant. It restricts operations through that pointer. Casting away const and modifying an object that was originally defined as const is not permitted.

15. Void Pointers and Const Qualification

A void pointer can also be const-qualified. These declarations have different meanings.

Declaration Meaning
void *ptr Pointer to an object of unspecified type.
const void *ptr Pointer to an object that cannot be modified through ptr.
void *const ptr Constant pointer to an object of unspecified type.
const void *const ptr Constant pointer to an object that cannot be modified through ptr.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 100;

    const void *ptr = &number;

    printf("Value = %d\n", *(const int *)ptr);

    return 0;
}
Expected Output: 
Value = 100

16. Practical Application: Generic Swap Function

The standard C library qsort() uses a generic comparison interface involving const void *. A similar idea can be used to exchange objects of different types when their sizes are known.

Example: Byte-by-Byte Generic Swap

#include <stdio.h>
#include <stddef.h>

void swap_bytes(void *a, void *b, size_t size)
{
    unsigned char *p = a;
    unsigned char *q = b;

    for (size_t i = 0; i < size; i++)
    {
        unsigned char temp = p[i];

        p[i] = q[i];
        q[i] = temp;
    }
}

int main(void)
{
    int x = 10;
    int y = 20;

    swap_bytes(&x, &y, sizeof x);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
Expected Output: 
x = 20
y = 10

The function uses unsigned char pointers to access the object representations byte by byte. The objects must have the same size, be valid writable objects, and not overlap.

17. Practical Applications in Embedded C

Concept Embedded Application
void * Generic buffer handling and reusable interfaces.
const void * Read-only generic data processing.
const uint32_t * Reading data through a pointer without modifying it.
volatile uint32_t * Accessing memory-mapped registers that can change independently of ordinary program flow.
volatile uint32_t *const Fixed pointer to a volatile register object.
In embedded C, volatile and const solve different problems. volatile affects how accesses are treated by the compiler, while const restricts modification through a particular access path. Neither keyword alone guarantees atomic access or thread safety.

18. Common Errors and Misconceptions

Incorrect Practice Reason Correct Approach
Dereferencing void * The pointed-to object type is not specified. Convert to the correct object pointer type first.
Adding directly to void * Not defined by standard C11. Convert to an appropriate object pointer type.
Modifying data through const int * Modification is not allowed through that pointer. Use a writable pointer when modification is intended.
Reassigning int *const The pointer itself is constant. Initialize it correctly before use.
Assuming const means global immutability Const restricts access through a qualified type. Understand the original object's type and all access paths.
Using the wrong cast for void * Incorrect type access can cause undefined behavior. Use the actual object type and valid alignment.

22. Key Takeaways

  • void * is a generic pointer to an object.
  • A void pointer must be converted to an appropriate object pointer type before dereferencing.
  • Standard C11 does not support arithmetic directly on void pointers.
  • const int * prevents modification through that pointer.
  • int *const prevents reassignment of the pointer.
  • const int *const restricts both operations.
  • Const correctness documents function interfaces and protects read-only data.
  • Generic functions often use void * together with an explicit type or size.
  • volatile and const have different purposes in embedded programming.
Placement preparation target: Be able to explain generic pointers, convert void pointers safely, distinguish all four pointer qualification forms, and solve pointer-related output and coding questions.
