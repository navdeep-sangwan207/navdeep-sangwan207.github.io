Lecture 05: Pointers as Function Arguments

Learn how to pass addresses to functions, modify caller-owned data, work with arrays through pointers, and use pointer parameters in practical C programs.

1. Learning Objectives

  • Understand how pointer arguments work in C functions.
  • Understand the difference between passing values and addresses.
  • Modify caller-owned variables through pointers.
  • Use pointers for multiple output parameters.
  • Pass arrays to functions efficiently.
  • Understand pointer parameters and const correctness.
  • Use pointers in practical embedded C programming.
  • Identify common pointer argument errors.

2. Passing Arguments to Functions

C uses pass-by-value for function arguments. This means a function receives a copy of each argument passed to it.

When a pointer is passed, the pointer value (the address) is copied. The function can use that address to access the original object.

Example: Passing a Normal Variable

#include <stdio.h>

void change_value(int x)
{
    x = 100;
}

int main(void)
{
    int number = 10;

    change_value(number);

    printf("Number = %d\n", number);

    return 0;
}
Expected Output: 
Number = 10

The function changes only its local copy of number. The original variable remains unchanged.

3. Passing an Address to a Function

To allow a function to modify a caller-owned variable, pass its address using the address operator (&).

Example Program

#include <stdio.h>

void change_value(int *ptr)
{
    *ptr = 100;
}

int main(void)
{
    int number = 10;

    change_value(&number);

    printf("Number = %d\n", number);

    return 0;
}
Expected Output: 
Number = 100

Explanation:

  1. number stores the value 10.
  2. &number obtains the address of number.
  3. The function receives a copy of that address in ptr.
  4. *ptr accesses the original variable.
  5. Assigning 100 through *ptr changes number.
C still passes the pointer by value. It is the copied address that allows the function to access the caller's object.

4. Difference Between Value and Pointer Arguments

Feature Value Argument Pointer Argument
What is passed? A copy of the value. A copy of the address.
Can modify caller's variable? Not through the local parameter. Yes, by dereferencing a valid pointer.
Function parameter int x int *ptr
Function call function(x); function(&x);

5. Swapping Two Numbers Using Pointers

A common interview problem is swapping two variables using a function. Pointer arguments allow the function to modify both original variables.

Example Program

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Before swapping: x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swapping: x = %d, y = %d\n", x, y);

    return 0;
}
Expected Output: 
Before swapping: x = 10, y = 20
After swapping: x = 20, y = 10

Time complexity: O(1). Auxiliary space: O(1).

6. Returning Multiple Results Using Pointer Arguments

A C function directly returns one value through its return statement. Pointer output parameters can be used to write additional results into caller-provided variables.

Example: Quotient and Remainder

#include <stdio.h>

int divide_numbers(int dividend,
                   int divisor,
                   int *quotient,
                   int *remainder)
{
    if (divisor == 0 ||
        quotient == NULL ||
        remainder == NULL)
    {
        return 0;
    }

    *quotient = dividend / divisor;
    *remainder = dividend % divisor;

    return 1;
}

int main(void)
{
    int q;
    int r;

    if (divide_numbers(17, 5, &q, &r))
    {
        printf("Quotient = %d\n", q);
        printf("Remainder = %d\n", r);
    }
    else
    {
        printf("Invalid arguments\n");
    }

    return 0;
}
Expected Output: 
Quotient = 3
Remainder = 2

The function returns a status value and writes two additional results through pointer arguments.

7. Passing Arrays to Functions

When an array is passed to a function, the parameter is adjusted to a pointer to its first element.

Example Program

#include <stdio.h>

void display_array(const int *arr, size_t size)
{
    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }

    printf("\n");
}

int main(void)
{
    int numbers[] = {10, 20, 30, 40, 50};

    size_t size = sizeof(numbers) / sizeof(numbers[0]);

    display_array(numbers, size);

    return 0;
}
Expected Output: 
10 20 30 40 50

The array elements are not copied when passed this way. The function receives a pointer to the first element and a separate size argument.

Inside display_array(), sizeof(arr) gives the size of the pointer parameter, not the size of the original array. Pass the element count separately.

8. Modifying Array Elements Through a Function

A function can update array elements using a pointer parameter.

Example: Multiply Every Element by Two

#include <stdio.h>

void multiply_by_two(int *arr, size_t size)
{
    for (size_t i = 0; i < size; i++)
    {
        arr[i] = arr[i] * 2;
    }
}

int main(void)
{
    int numbers[] = {1, 2, 3, 4, 5};

    size_t size = sizeof(numbers) / sizeof(numbers[0]);

    multiply_by_two(numbers, size);

    for (size_t i = 0; i < size; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
2 4 6 8 10

9. Passing Strings to Functions

Strings are passed to functions using pointers to their first character. Use const char * when the function must only read the string.

Example Program

#include <stdio.h>

void display_string(const char *str)
{
    printf("Received string: %s\n", str);
}

int main(void)
{
    char message[] = "WELCOME TO C";

    display_string(message);

    return 0;
}
Expected Output: 
Received string: WELCOME TO C

For string modification, use a writable character array and a char * parameter.

10. Using const with Pointer Arguments

The const qualifier specifies whether a function can modify the pointed-to object through a pointer.

Read-Only Pointer Parameter

void display(const int *ptr)
{
    printf("%d\n", *ptr);

    /* *ptr = 50;  Not allowed */
}

Writable Pointer Parameter

void update(int *ptr)
{
    *ptr = 50;
}
Declaration Meaning
int *ptr Pointer to a modifiable int.
const int *ptr Pointer to an int that cannot be modified through ptr.
int *const ptr Constant pointer to a modifiable int.
const int *const ptr Constant pointer to a const int.
Use const pointer parameters for input-only data. This communicates the function's intent and helps prevent accidental modification.

11. Passing a Pointer to a Function That Updates It

A normal pointer parameter is itself passed by value. Changing the local pointer does not change the caller's pointer variable.

Example Program

#include <stdio.h>

void move_pointer(int *ptr)
{
    ptr++;
}

int main(void)
{
    int numbers[] = {10, 20, 30};

    int *ptr = numbers;

    move_pointer(ptr);

    printf("%d\n", *ptr);

    return 0;
}
Expected Output: 
10

The function increments only its local copy of the pointer. The pointer in main() still points to numbers[0].

12. Modifying the Caller’s Pointer Using a Double Pointer

To modify a pointer variable belonging to the caller, pass the address of that pointer. The function receives a pointer to a pointer.

Example Program

#include <stdio.h>

void move_pointer(int **ptr)
{
    (*ptr)++;
}

int main(void)
{
    int numbers[] = {10, 20, 30};

    int *ptr = numbers;

    move_pointer(&ptr);

    printf("%d\n", *ptr);

    return 0;
}
Expected Output: 
20

The expression (*ptr)++ increments the caller's pointer variable. Parentheses are important: they ensure that the pointer is incremented, not the pointed-to integer.

13. Returning Data Through a Pointer Parameter

Pointer parameters are commonly used when a function needs to write a result into an existing variable or buffer.

Example: Find Maximum and Minimum

#include <stdio.h>
#include <stddef.h>

int find_min_max(const int *arr,
                 size_t size,
                 int *minimum,
                 int *maximum)
{
    if (arr == NULL || minimum == NULL ||
        maximum == NULL || size == 0)
    {
        return 0;
    }

    *minimum = arr[0];
    *maximum = arr[0];

    for (size_t i = 1; i < size; i++)
    {
        if (arr[i] < *minimum)
        {
            *minimum = arr[i];
        }

        if (arr[i] > *maximum)
        {
            *maximum = arr[i];
        }
    }

    return 1;
}

int main(void)
{
    int values[] = {45, 12, 78, 23, 9};

    size_t size = sizeof(values) / sizeof(values[0]);

    int minimum;
    int maximum;

    if (find_min_max(values, size, &minimum, &maximum))
    {
        printf("Minimum = %d\n", minimum);
        printf("Maximum = %d\n", maximum);
    }

    return 0;
}
Expected Output: 
Minimum = 9
Maximum = 78

Time complexity: O(n). Auxiliary space: O(1).

14. Pointer Arguments in Embedded C

Pointer arguments are widely used in embedded software because they allow functions to operate on memory-mapped registers, buffers and data structures.

Example: Update a Register Through a Pointer

#include <stdint.h>
#include <stdio.h>

void set_bits(volatile uint32_t *reg,
              uint32_t mask)
{
    *reg |= mask;
}

int main(void)
{
    volatile uint32_t simulated_register = 0x00;

    set_bits(&simulated_register, 0x05);

    printf("Register = 0x%02X\n",
           (unsigned int)simulated_register);

    return 0;
}
Expected Output: 
Register = 0x05

The example uses a normal variable to simulate a register. In real embedded hardware, a pointer may refer to a memory-mapped register address specified by the microcontroller.

Do not use arbitrary memory addresses on a desktop system. Real register addresses, access widths and volatile requirements must come from the target microcontroller datasheet.

15. Common Mistakes with Pointer Arguments

Mistake Problem Correct Practice
Passing a value instead of an address Caller variable is not modified. Pass its address when modification is required.
Dereferencing NULL Invalid memory access. Validate pointer arguments where NULL is permitted.
Forgetting array size Function may access beyond array bounds. Pass the element count separately.
Incorrect pointer level Function cannot update caller's pointer. Use a pointer to pointer when necessary.
Writing through const data Modification is rejected or violates the object's constraints. Use const for read-only parameters.
Returning address of a local variable Returned pointer becomes invalid. Use caller-provided storage or appropriate dynamic storage.

20. Key Takeaways

  • C passes all function arguments by value.
  • Passing a pointer copies an address into the function parameter.
  • Dereferencing a valid pointer can modify the caller's object.
  • Pointer parameters are useful for arrays and strings.
  • Output parameters allow functions to write additional results.
  • Pointer arithmetic on a local parameter does not update the caller's pointer.
  • A double pointer can be used to modify the caller's pointer variable.
  • Use const when a function should not modify the pointed-to data.
  • Always validate pointer and size arguments before accessing memory.
Placement preparation target: Be able to explain why C uses pass-by-value, implement swap and multiple-output functions, pass arrays safely, distinguish pointer levels, and trace pointer changes across function calls.
