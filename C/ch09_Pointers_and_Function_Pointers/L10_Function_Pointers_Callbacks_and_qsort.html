Lecture 10: Function Pointers, Callbacks and qsort()

Learn callback mechanisms, comparator functions, generic sorting with qsort(), and practical function pointer applications.

  • Understand callback functions in detail.
  • Implement callbacks using function pointers.
  • Understand the callback execution sequence.
  • Use the standard library qsort() function.
  • Write comparator functions for different data types.

  • Understand ascending and descending sorting.
  • Apply callbacks to embedded and event-driven software.

2. What Is a Callback Function?

A callback is a function passed to another function through a function pointer. The receiving function invokes the callback when a particular operation or event occurs.

The function that receives and invokes the callback is commonly called the caller or registering function. The supplied function is called the callback function.

Basic Example

#include <stdio.h>

void completed(void)
{
    printf("Task completed\n");
}

void execute_task(void (*callback)(void))
{
    printf("Executing task...\n");

    callback();
}

int main(void)
{
    execute_task(completed);

    return 0;
}
Expected Output: 
Executing task...
Task completed

The completed function is supplied to execute_task. The receiving function calls it through the callback parameter.

3. Callback Execution Flow

main()
   |
   v
execute_task(completed)
   |
   v
Execute task operation
   |
   v
callback()
   |
   v
completed()
   |
   v
Return to execute_task()
   |
   v
Return to main()

The callback is not necessarily executed immediately in every application. A receiving function may store a callback and invoke it later when an event occurs.

4. Callback with Arguments and Return Value

A callback can accept parameters and return a value. Its function pointer declaration must match the callback function's type.

Example Program

#include <stdio.h>

int square(int value)
{
    return value * value;
}

int process_value(int number, int (*operation)(int))
{
    return operation(number);
}

int main(void)
{
    int result;

    result = process_value(6, square);

    printf("Result = %d\n", result);

    return 0;
}
Expected Output: 
Result = 36

The process_value function is independent of the calculation performed by square. Another compatible callback could perform a different operation.

5. Multiple Callback Functions

Multiple functions can be supplied to the same processing interface, provided they have compatible function types.

Example: Different Calculations

#include <stdio.h>

int square(int n)
{
    return n * n;
}

int cube(int n)
{
    return n * n * n;
}

int process(int n, int (*callback)(int))
{
    return callback(n);
}

int main(void)
{
    printf("Square = %d\n", process(3, square));
    printf("Cube = %d\n", process(3, cube));

    return 0;
}
Expected Output: 
Square = 9
Cube = 27

6. What Is qsort()?

qsort() is a standard C library function declared in the stdlib.h header file. It sorts an array using a comparison function supplied through a function pointer.

Function Prototype

void qsort(
    void *base,
    size_t nmemb,
    size_t size,
    int (*compar)(const void *, const void *)
);
Parameter Meaning
base Pointer to the first element of the array.
nmemb Number of elements in the array.
size Size in bytes of each array element.
compar Pointer to the comparison function.
qsort() is a generic sorting function. It can sort arrays of different element types because the comparator interprets the elements using the appropriate type.

7. Understanding the qsort() Comparator

The comparator receives pointers to two elements. It determines their relative order.

Comparator Return Values

Return Value Meaning
Negative value First element is ordered before second.
Zero Both elements compare equal for sorting.
Positive value First element is ordered after second.

The comparator must define a consistent ordering for the elements being sorted.

8. Sorting an Integer Array in Ascending Order

Example Program

#include <stdio.h>
#include <stdlib.h>

int compare_int(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

int main(void)
{
    int numbers[] = {40, 10, 50, 20, 30};

    size_t count = sizeof numbers / sizeof numbers[0];

    qsort(numbers, count, sizeof numbers[0], compare_int);

    printf("Sorted array: ");

    for (size_t i = 0; i < count; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
Sorted array: 10 20 30 40 50

The comparator converts the generic pointers to pointers to const int and compares the integer values.

Do not implement an integer comparator as return x - y. Signed subtraction can overflow for extreme integer values. Use explicit less-than and greater-than comparisons.

9. Sorting an Integer Array in Descending Order

Reverse the comparison order to sort the array in descending order.

Example Program

#include <stdio.h>
#include <stdlib.h>

int compare_descending(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    if (x > y)
        return -1;

    if (x < y)
        return 1;

    return 0;
}

int main(void)
{
    int numbers[] = {40, 10, 50, 20, 30};

    size_t count = sizeof numbers / sizeof numbers[0];

    qsort(numbers, count, sizeof numbers[0],
          compare_descending);

    for (size_t i = 0; i < count; i++)
    {
        printf("%d ", numbers[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
50 40 30 20 10

10. Sorting an Array of Floating-Point Numbers

The same qsort() function can sort floating-point arrays by using a comparator that interprets the elements as double values.

Example Program

#include <stdio.h>
#include <stdlib.h>

int compare_double(const void *a, const void *b)
{
    double x = *(const double *)a;
    double y = *(const double *)b;

    if (x < y)
        return -1;

    if (x > y)
        return 1;

    return 0;
}

int main(void)
{
    double values[] = {4.5, 1.2, 8.7, 3.3, 2.1};

    size_t count = sizeof values / sizeof values[0];

    qsort(values, count, sizeof values[0], compare_double);

    for (size_t i = 0; i < count; i++)
    {
        printf("%.1f ", values[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
1.2 2.1 3.3 4.5 8.7

11. Sorting an Array of Strings

An array of character pointers can be sorted using qsort(). The comparator receives pointers to the array elements. Since each element is itself a character pointer, the comparator must dereference the supplied pointer correctly.

Example Program

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int compare_strings(const void *a, const void *b)
{
    const char * const *s1 = a;
    const char * const *s2 = b;

    return strcmp(*s1, *s2);
}

int main(void)
{
    const char *names[] = {
        "Linux",
        "Embedded",
        "CProgramming",
        "Kernel"
    };

    size_t count = sizeof names / sizeof names[0];

    qsort(names, count, sizeof names[0], compare_strings);

    for (size_t i = 0; i < count; i++)
    {
        printf("%s\n", names[i]);
    }

    return 0;
}
Expected Output: 
CProgramming
Embedded
Kernel
Linux

strcmp() performs lexicographical comparison. qsort() rearranges the pointer elements, not the contents of the string literals.

12. Sorting Structures Using qsort()

qsort() is also useful for sorting arrays of structures based on one or more fields.

Example: Sort Employees by Salary

#include <stdio.h>
#include <stdlib.h>

typedef struct
{
    int id;
    char name[30];
    double salary;
} Employee;

int compare_salary(const void *a, const void *b)
{
    const Employee *e1 = a;
    const Employee *e2 = b;

    if (e1->salary < e2->salary)
        return -1;

    if (e1->salary > e2->salary)
        return 1;

    return 0;
}

int main(void)
{
    Employee employees[] = {
        {101, "Aman", 35000.0},
        {102, "Ravi", 28000.0},
        {103, "Neha", 42000.0}
    };

    size_t count = sizeof employees / sizeof employees[0];

    qsort(employees, count, sizeof employees[0],
          compare_salary);

    for (size_t i = 0; i < count; i++)
    {
        printf("%d %s %.2f\n",
               employees[i].id,
               employees[i].name,
               employees[i].salary);
    }

    return 0;
}
Expected Output: 
102 Ravi 28000.00
101 Aman 35000.00
103 Neha 42000.00

The comparator accesses the salary member of each structure and establishes ascending order.

13. Sorting Structures by Multiple Fields

A comparator can use more than one field. For example, employee records can be sorted by department ID first and employee ID second.

Example Program

#include <stdio.h>
#include <stdlib.h>

typedef struct
{
    int department;
    int employee_id;
} Employee;

int compare_employee(const void *a, const void *b)
{
    const Employee *e1 = a;
    const Employee *e2 = b;

    if (e1->department < e2->department)
        return -1;

    if (e1->department > e2->department)
        return 1;

    if (e1->employee_id < e2->employee_id)
        return -1;

    if (e1->employee_id > e2->employee_id)
        return 1;

    return 0;
}

int main(void)
{
    Employee employees[] = {
        {2, 105},
        {1, 103},
        {2, 101},
        {1, 102}
    };

    size_t count = sizeof employees / sizeof employees[0];

    qsort(employees, count, sizeof employees[0],
          compare_employee);

    for (size_t i = 0; i < count; i++)
    {
        printf("Department: %d, Employee: %d\n",
               employees[i].department,
               employees[i].employee_id);
    }

    return 0;
}
Expected Output: 
Department: 1, Employee: 102
Department: 1, Employee: 103
Department: 2, Employee: 101
Department: 2, Employee: 105

14. Callback Design in Embedded Systems

Embedded systems often use callbacks to separate hardware event detection from application logic.

Example: Simulated Sensor Event

#include <stdio.h>

typedef void (*SensorCallback)(int);

void temperature_alert(int temperature)
{
    if (temperature > 40)
    {
        printf("Warning: High temperature!\n");
    }
    else
    {
        printf("Temperature is normal\n");
    }
}

void read_sensor(int value, SensorCallback callback)
{
    printf("Sensor reading = %d\n", value);

    callback(value);
}

int main(void)
{
    read_sensor(35, temperature_alert);
    read_sensor(45, temperature_alert);

    return 0;
}
Expected Output: 
Sensor reading = 35
Temperature is normal
Sensor reading = 45
Warning: High temperature!

The sensor-reading function handles the reading operation, while the callback handles the application-specific response.

In real embedded systems, a peripheral driver may invoke a registered callback when a transfer completes, a timer expires or a communication event occurs.

15. Callback Registration and Event Handling

Some APIs allow an application to register a callback once and invoke it later when an event occurs.

Example Program

#include <stdio.h>

typedef void (*EventCallback)(int);

static EventCallback registered_callback = NULL;

void register_callback(EventCallback callback)
{
    registered_callback = callback;
}

void generate_event(int event_code)
{
    if (registered_callback != NULL)
    {
        registered_callback(event_code);
    }
}

void event_handler(int event_code)
{
    printf("Event received: %d\n", event_code);
}

int main(void)
{
    register_callback(event_handler);

    generate_event(100);
    generate_event(200);

    return 0;
}
Expected Output: 
Event received: 100
Event received: 200

The callback is stored in a function pointer variable. The event generator checks that the pointer is not NULL before invoking it.

16. Important qsort() Considerations

  • Include stdlib.h to use qsort().
  • Pass the correct number of elements.
  • Pass the correct element size using sizeof.
  • Ensure the comparator interprets each element correctly.
  • Return negative, zero or positive comparison results.
  • Use a consistent ordering in the comparator.
  • Do not assume qsort() is stable.
  • Do not rely on a particular sorting algorithm or complexity from the C standard.
qsort() does not guarantee that elements with equal comparison results retain their original relative order. If stable sorting is required, use a stable sorting implementation or include an original-position field as a tie-breaker.

17. Common Mistakes

Mistake Why It Is Incorrect Correct Practice
Incorrect callback signature Function pointer type does not match. Use compatible parameter and return types.
Passing a function result instead of its address Calls the function immediately. Pass the function designator, such as callback_function.
Incorrect qsort() element size Element access may be incorrect. Use sizeof array[0].
Wrong comparator conversion Interprets memory using an incorrect type. Convert to the actual element pointer type.
Returning x - y for integers Signed subtraction may overflow. Use relational comparisons.
Assuming qsort() is stable Equal elements may change relative order. Use a stable sorting approach if required.
Calling a NULL callback Invalid function call. Check the callback pointer before calling it.
