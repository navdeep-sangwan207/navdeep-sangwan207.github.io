Lecture 02: Pointer Initialization and NULL Pointers

Learn how to initialize pointers correctly, use NULL pointers, reassign pointer addresses, perform safe pointer checks and avoid invalid memory access.

1. Learning Objectives

  • Understand why pointer initialization is necessary.
  • Initialize pointers with valid object addresses.
  • Understand null pointer constants and NULL.
  • Differentiate NULL pointers from uninitialized pointers.
  • Check pointers before dereferencing them.
  • Reassign pointers to different objects.
  • Understand pointer lifetime and validity.
  • Identify common pointer initialization errors.
  • Apply safe pointer practices in C11 programs.

2. Why Is Pointer Initialization Important?

A pointer variable stores a pointer value. If it is not initialized, its value may be indeterminate. Using such a pointer as though it refers to a valid object can result in undefined behavior.

Incorrect Example

#include <stdio.h>

int main(void)
{
    int *ptr;

    *ptr = 100;   // Invalid: ptr is uninitialized

    printf("%d\n", *ptr);

    return 0;
}
Problem: The pointer has not been assigned a valid pointer value. Dereferencing it is not safe. The program has undefined behavior.

Correct Example

#include <stdio.h>

int main(void)
{
    int number = 100;

    int *ptr = &number;

    printf("%d\n", *ptr);

    return 0;
}
Expected Output: 
100

3. Different Ways to Initialize Pointers

Method 1: Initialize During Declaration

int number = 50;

int *ptr = &number;

The pointer is initialized with the address of number at the time of declaration.

Method 2: Declare First and Initialize Later

int number = 75;

int *ptr;

ptr = &number;

The pointer receives a valid address before it is used.

Method 3: Initialize with NULL

int *ptr = NULL;

The pointer is initialized to a null pointer value. It does not point to an object.

Method 4: Reassign to Another Valid Object

int first = 10;
int second = 20;

int *ptr = &first;

ptr = &second;

After reassignment, ptr points to second instead of first.

4. Understanding NULL Pointers

A null pointer is a pointer value that is guaranteed not to compare equal to a pointer to any object or function.

NULL is a macro defined by standard headers. It represents a null pointer constant and is commonly used to initialize pointers or indicate that a pointer currently refers to no object.

Syntax

int *ptr = NULL;

Example Program

#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int *ptr = NULL;

    if (ptr == NULL)
    {
        printf("Pointer is NULL\n");
    }
    else
    {
        printf("Pointer is not NULL\n");
    }

    return 0;
}
Expected Output: 
Pointer is NULL
A NULL pointer must not be dereferenced. It should be checked or assigned a valid address before accessing an object through it.

5. NULL, 0 and '\0': Important Differences

These expressions are related to zero, but they have different meanings and should not be confused.

Expression Meaning
0 Integer constant with value zero.
NULL Macro representing a null pointer constant.
'\0' Null character used to terminate C strings.
0.0 Floating-point constant with value zero.

Examples

int number = 0;

int *ptr = NULL;

char str[] = "C";

The string array contains the characters 'C' and '\0'. The pointer ptr is a null pointer. These concepts are not interchangeable.

In pointer assignments and comparisons, prefer NULL or the null pointer constant 0. Do not confuse a null pointer with the null character used in strings.

6. Checking a Pointer Before Dereferencing

A pointer should be checked for NULL when it may legitimately contain a null pointer value.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 250;

    int *ptr = &number;

    if (ptr != NULL)
    {
        printf("Value = %d\n", *ptr);
    }
    else
    {
        printf("Invalid pointer\n");
    }

    return 0;
}
Expected Output: 
Value = 250

Shorter Pointer Check

if (ptr)
{
    printf("%d", *ptr);
}

In a condition, a null pointer evaluates as false, while a non-null pointer evaluates as true.

A non-NULL check does not prove that a pointer is valid. A dangling pointer or an arbitrary invalid pointer can also be non-NULL. Pointer validity depends on object lifetime and how the pointer was obtained.

7. Reassigning a Pointer

A pointer can be reassigned to point to another compatible object while both objects are alive.

Example Program

#include <stdio.h>

int main(void)
{
    int first = 10;
    int second = 20;

    int *ptr = &first;

    printf("Initially = %d\n", *ptr);

    ptr = &second;

    printf("After reassignment = %d\n", *ptr);

    return 0;
}
Expected Output: 
Initially = 10
After reassignment = 20

Important Observation

  • Initially, ptr stores the address of first.
  • After reassignment, ptr stores the address of second.
  • The value of first remains unchanged.
  • Reassignment changes the pointer value, not the objects themselves.

8. Setting a Pointer to NULL After Use

Assigning NULL can communicate that a pointer is no longer intended to refer to an object.

Example

#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int number = 100;

    int *ptr = &number;

    printf("Value = %d\n", *ptr);

    ptr = NULL;

    if (ptr == NULL)
    {
        printf("Pointer reset to NULL\n");
    }

    return 0;
}
Expected Output: 
Value = 100
Pointer reset to NULL

Assigning NULL to one pointer does not change other pointers that may refer to the same object. It also does not destroy or modify the target object.

9. Pointer Initialization and Storage Duration

C objects have storage durations that affect their lifetime and initialization behavior.

Object Category Initial Value Behavior
Uninitialized automatic pointer Has an indeterminate value.
Static-storage-duration pointer Initialized to a null pointer by default.
Pointer explicitly initialized with NULL Contains a null pointer value.
Pointer initialized with a valid object address Can access that object while the object remains alive and accessible.

Example: Static Pointer

#include <stdio.h>

int main(void)
{
    static int *ptr;

    if (ptr == NULL)
    {
        printf("Static pointer is NULL\n");
    }

    return 0;
}
Expected Output: 
Static pointer is NULL

Objects with static storage duration are initialized before program startup. Pointer objects without an explicit initializer receive the null pointer value.

10. Pointer Validity and Object Lifetime

A pointer is useful only when it refers to an object that is still alive and can legally be accessed through that pointer.

Example: Valid Pointer

#include <stdio.h>

int main(void)
{
    int number = 500;
    int *ptr = &number;

    printf("%d\n", *ptr);

    return 0;
}

The object number is alive while the pointer is used in main().

Example: Invalid Pointer After Object Lifetime Ends

int *create_pointer(void)
{
    int local = 100;

    return &local;
}

The local object local has automatic storage duration. Its lifetime ends when the function returns. The returned pointer cannot safely be used to access that object.

A pointer does not extend the lifetime of the object it points to.

11. Pointer Initialization with Dynamic Memory

Pointers can receive addresses returned by dynamic memory allocation functions such as malloc() and calloc().

Detailed dynamic memory allocation is covered in Chapter 12. The following example demonstrates safe initialization and checking. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d\n", *ptr);

    free(ptr);
    ptr = NULL;

    return 0;
}
Expected Output: 
Value = 100

malloc() may fail, so its return value must be checked before dereferencing the pointer. After free(), the pointer must not be used to access the released memory.

12. Common Pointer Initialization Mistakes

Mistake 1: Dereferencing an Uninitialized Pointer

int *ptr;

*ptr = 10;

Correction: Initialize ptr with the address of a suitable live object or with NULL before using it.

Mistake 2: Dereferencing NULL

int *ptr = NULL;

printf("%d", *ptr);

Correction: Check whether the pointer is NULL and ensure it points to a valid object before dereferencing.

Mistake 3: Confusing Pointer Assignment with Value Assignment

int a = 10;
int b = 20;

int *ptr = &a;

ptr = &b;

This changes the address stored in ptr. It does not copy the value of b into a.

Mistake 4: Using a Pointer After Its Target Is Destroyed

int *ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    free(ptr);
    ptr = NULL;
}

After free(), the allocated object no longer exists. Setting ptr to NULL prevents accidental use through this particular pointer variable.

Mistake 5: Assuming Non-NULL Means Valid

if (ptr != NULL)
{
    printf("%d", *ptr);
}

This check alone is insufficient if ptr is dangling or otherwise invalid. The program must also ensure the target object's lifetime and access conditions are valid.

16. Practical Applications

Application Importance of Initialization
Embedded C Ensures pointers used for hardware access refer to intended addresses.
Dynamic memory Allows allocation results to be checked before use.
Linked lists NULL can represent the absence of a next node.
Function parameters Allows functions to detect optional or absent pointer arguments.
System programming Helps prevent invalid memory access and pointer misuse.

17. Key Takeaways

  • Initialize pointers before using them.
  • Use valid object addresses for dereferencing.
  • NULL represents a null pointer value.
  • Never dereference a null pointer.
  • A non-NULL pointer is not automatically valid.
  • Pointer reassignment changes the stored address.
  • Pointer validity depends on the lifetime of the target object.
  • Check dynamic allocation results before accessing allocated memory.
  • Setting a pointer to NULL does not invalidate other aliases.
Placement preparation target: You should be able to distinguish uninitialized, NULL and valid pointers; explain pointer reassignment; identify dangling-pointer situations; and write safe pointer initialization code.
