Lecture 08: Array of Pointers and Pointer to Array

Understand pointer arrays, array pointers, multidimensional array relationships, pointer arithmetic and practical C applications.

1. Learning Objectives

  • Understand an array of pointers.
  • Declare and initialize arrays of pointers.
  • Understand a pointer to an array.
  • Differentiate the two declarations.
  • Trace pointer arithmetic involving arrays.
  • Work with arrays of strings.
  • Understand pointers to multidimensional arrays.
  • Pass arrays and pointers to functions.
  • Apply these concepts to practical programming problems.

2. Array of Pointers

An array of pointers is an array in which each element is a pointer variable.

Syntax

int *ptr[5];

This declares an array containing five pointers to integers. Each element can store the address of an integer.

Example Program

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;
    int c = 30;

    int *ptr[3];

    ptr[0] = &a;
    ptr[1] = &b;
    ptr[2] = &c;

    for (int i = 0; i < 3; i++)
    {
        printf("%d\n", *ptr[i]);
    }

    return 0;
}
Expected Output: 
10
20
30

Each array element stores an address, and dereferencing that element accesses the corresponding integer.

3. Memory Representation of an Array of Pointers

Consider the following declaration:

int a = 10;
int b = 20;
int c = 30;

int *ptr[3] = {&a, &b, &c};

The conceptual relationship is:

ptr[0] --------> a (10)
ptr[1] --------> b (20)
ptr[2] --------> c (30)
  • ptr is an array of three pointer objects.
  • ptr[0], ptr[1] and ptr[2] are separate pointer elements.
  • Each pointer can refer to a different integer object.
An array of pointers stores pointer values in consecutive array elements. The objects those pointers refer to do not have to be adjacent in memory.

4. Array of Pointers to Strings

One common use of an array of pointers is storing multiple strings.

Example Program

#include <stdio.h>

int main(void)
{
    const char *names[] = {
        "C Programming",
        "Embedded C",
        "Linux",
        "Data Structures"
    };

    int count = sizeof names / sizeof names[0];

    for (int i = 0; i < count; i++)
    {
        printf("%s\n", names[i]);
    }

    return 0;
}
Expected Output: 
C Programming
Embedded C
Linux
Data Structures

Each element points to the first character of a string literal. The const qualifier prevents modification of the literal through these pointers.

5. Modifying an Array of Pointers

Although the string literals should not be modified, the pointer elements themselves can be reassigned when the array is not const.

Example Program

#include <stdio.h>

int main(void)
{
    const char *names[] = {
        "C",
        "C++",
        "Java"
    };

    names[1] = "Python";

    for (int i = 0; i < 3; i++)
    {
        printf("%s\n", names[i]);
    }

    return 0;
}
Expected Output: 
C
Python
Java

names[1] is reassigned to point to another string literal. The original literal is not modified.

6. Pointer to an Array

A pointer to an array stores the address of an entire array rather than the address of one individual element as its declared type.

Syntax

int (*ptr)[5];

This declares ptr as a pointer to an array of five integers.

Example Program

#include <stdio.h>

int main(void)
{
    int numbers[5] = {10, 20, 30, 40, 50};

    int (*ptr)[5] = &numbers;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", (*ptr)[i]);
    }

    printf("\n");

    return 0;
}
Expected Output: 
10 20 30 40 50

ptr points to the complete array. The expression (*ptr)[i] accesses its individual elements.

7. Difference Between Array of Pointers and Pointer to Array

Declaration Meaning
int *ptr[5]; Array containing five pointers to int.
int (*ptr)[5]; Single pointer to an array of five integers.

Important Differences

Feature Array of Pointers Pointer to Array
Number of pointer objects Multiple One
Declaration int *ptr[5] int (*ptr)[5]
Stored value Each element stores an address. Pointer stores the address of an array.
Pointer arithmetic Moves between pointer elements. Moves by the size of the entire array.
Typical application Array of strings and pointer collections. Multidimensional arrays and fixed-size rows.
Parentheses change the meaning of a declaration. int *ptr[5] and int (*ptr)[5] are not equivalent.

8. Understanding Pointer Arithmetic

Pointer arithmetic depends on the type to which the pointer points.

Pointer to an Integer

int numbers[5];

int *ptr = numbers;

ptr++;

ptr advances by one integer element.

Pointer to an Array of Five Integers

int numbers[5][3];

int (*ptr)[3] = numbers;

ptr++;

ptr advances by one complete row containing three integers.

Pointer arithmetic scales according to the pointed-to type. For a pointer to an array, one increment advances by the size of that entire array.

9. Pointer to a Two-Dimensional Array

A two-dimensional array can be accessed using a pointer to an array representing one row.

Example Program

#include <stdio.h>

int main(void)
{
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    int (*ptr)[3] = matrix;

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d ", ptr[i][j]);
        }

        printf("\n");
    }

    return 0;
}
Expected Output: 
10 20 30
40 50 60

The pointer type int (*)[3] represents a pointer to a row containing three integers.

10. Array of Pointers Versus Two-Dimensional Array

An array of pointers and a two-dimensional array can both be used to represent collections of values, but their memory layouts differ.

Two-Dimensional Array

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

The integers are stored as one contiguous two-dimensional array in row-major order.

Array of Pointers

int row1[] = {1, 2, 3};
int row2[] = {4, 5, 6};

int *rows[2] = {row1, row2};

The pointer array contains two pointer elements. Each pointer refers to a separate row array.

Feature 2D Array Array of Pointers
Memory organization One contiguous array. Pointer elements plus separately stored target objects.
Row sizes Same fixed number of columns. Rows may have different lengths.
Access matrix[i][j] rows[i][j]
Pointer overhead No separate row pointer array. Requires pointer storage.

11. Jagged Arrays Using an Array of Pointers

An array of pointers can represent rows with different numbers of elements. This is often called a jagged array.

Example Program

#include <stdio.h>

int main(void)
{
    int row1[] = {10, 20};
    int row2[] = {30, 40, 50};
    int row3[] = {60, 70, 80, 90};

    int *rows[] = {row1, row2, row3};

    int lengths[] = {2, 3, 4};

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < lengths[i]; j++)
        {
            printf("%d ", rows[i][j]);
        }

        printf("\n");
    }

    return 0;
}
Expected Output: 
10 20
30 40 50
60 70 80 90

Each row has a different length. The lengths array stores the number of valid elements in each row.

12. Passing a Pointer to an Array to a Function

A pointer to an array can be used in a function parameter when the number of columns is fixed.

Example Program

#include <stdio.h>

#define COLS 3

void display_matrix(int (*matrix)[COLS], int rows)
{
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < COLS; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }
}

int main(void)
{
    int values[2][COLS] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    display_matrix(values, 2);

    return 0;
}
Expected Output: 
1 2 3
4 5 6

The function receives a pointer to an array of three integers. The row count is passed separately.

13. Passing an Array of Pointers to a Function

An array of pointers can be passed to a function using a pointer-to-pointer parameter.

Example Program

#include <stdio.h>

void display_names(const char *names[], int count)
{
    for (int i = 0; i < count; i++)
    {
        printf("%s\n", names[i]);
    }
}

int main(void)
{
    const char *names[] = {
        "Linux",
        "Embedded C",
        "C Programming"
    };

    display_names(names, 3);

    return 0;
}
Expected Output: 
Linux
Embedded C
C Programming

In a function parameter, const char *names[] is adjusted to const char **names.

14. Array of Function Pointers

An array can also store function pointers. This is useful for menu-driven programs, callback systems and operation selection.

Example Program: Calculator Operations

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operations[3])(int, int) = {
        add,
        subtract,
        multiply
    };

    int a = 20;
    int b = 5;

    printf("Addition = %d\n", operations[0](a, b));
    printf("Subtraction = %d\n", operations[1](a, b));
    printf("Multiplication = %d\n", operations[2](a, b));

    return 0;
}
Expected Output: 
Addition = 25
Subtraction = 15
Multiplication = 100

Each array element stores a function pointer with the same signature. The selected function is called through its corresponding array element.

Function pointers are covered in greater detail in the next function-pointer lectures. This example introduces their use inside arrays.

15. Declaration Reading and Operator Precedence

Correctly reading pointer declarations is essential for technical interviews.

Declaration Interpretation
int *p[5] p is an array of five pointers to int.
int (*p)[5] p is a pointer to an array of five int.
int **p p is a pointer to a pointer to int.
int (*p[5])[3] p is an array of five pointers to arrays of three int.
int *(*p)[5] p is a pointer to an array of five pointers to int.
Parentheses affect declaration interpretation. Start from the identifier and follow the declaration operators outward, considering parentheses and precedence.

16. Common Errors

Error Reason Correct Approach
Confusing int *p[5] and int (*p)[5] They represent different types. Use parentheses carefully.
Dereferencing an uninitialized pointer element The pointer does not contain a valid address. Initialize every pointer before use.
Accessing beyond an array boundary The index is outside the valid range. Check array dimensions and indices.
Using an incorrect row width Pointer arithmetic uses the declared pointed-to array size. Match the pointer-to-array type to the actual row width.
Modifying string literals String literals must not be modified. Use const char * for literal strings.
Assuming pointer arrays are contiguous target data Only the pointer elements are contiguous. Understand the separate target objects.

21. Key Takeaways

  • An array of pointers contains multiple pointer elements.
  • A pointer to an array points to one complete array object.
  • Parentheses determine the meaning of pointer declarations.
  • Pointer arithmetic depends on the pointed-to type.
  • A pointer to a row advances by one complete row.
  • An array of pointers can represent strings and jagged arrays.
  • A normal two-dimensional array stores its elements contiguously.
  • An array of function pointers can select operations dynamically.
  • Always respect array boundaries and pointer types.
Placement preparation target: Be able to distinguish array-of-pointer and pointer-to-array declarations immediately, calculate pointer arithmetic, trace 2D-array expressions, and explain memory layout in technical interviews.
