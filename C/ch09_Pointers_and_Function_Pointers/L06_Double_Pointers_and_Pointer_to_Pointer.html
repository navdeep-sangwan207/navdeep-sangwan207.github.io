Lecture 06: Double Pointers and Pointer to Pointer

Understand multiple levels of indirection, pointer-to-pointer operations, modifying caller pointers, and practical double-pointer applications.

1. Learning Objectives

  • Understand the concept of a pointer to a pointer.
  • Declare and initialize double pointers.
  • Understand single and double dereferencing.
  • Trace memory relationships between variables and pointers.
  • Modify a caller's pointer using a double pointer.
  • Use double pointers with arrays of strings.
  • Understand dynamic memory allocation through double pointers.
  • Apply double pointers in linked-list operations.
  • Identify common double-pointer errors.

2. What Is a Pointer to Pointer?

A pointer to pointer is a pointer variable that stores the address of another pointer variable. It is also called a double pointer.

Declaration

int **ptr;

Here:

  • int represents the original data type.
  • *ptr represents a pointer to int.
  • **ptr represents the integer accessed through two levels of indirection.

Basic Memory Relationship

int number = 100;

int *ptr = &number;

int **pptr = &ptr;

The relationship is:

pptr  --->  ptr  --->  number
             address     100

pptr stores the address of ptr, while ptr stores the address of number.

3. Accessing Data Using a Double Pointer

Each dereference operator removes one pointer level.

Expression Meaning
pptr Address of pointer variable ptr.
*pptr Value stored in ptr, which is the address of number.
**pptr Value of number.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 100;

    int *ptr = &number;

    int **pptr = &ptr;

    printf("Number = %d\n", number);

    printf("Using pointer = %d\n", *ptr);

    printf("Using double pointer = %d\n", **pptr);

    return 0;
}
Expected Output: 
Number = 100
Using pointer = 100
Using double pointer = 100

4. Modifying a Variable Through a Double Pointer

A double pointer can access the original variable through two levels of dereferencing.

Example Program

#include <stdio.h>

int main(void)
{
    int number = 10;

    int *ptr = &number;

    int **pptr = &ptr;

    **pptr = 500;

    printf("Number = %d\n", number);

    return 0;
}
Expected Output: 
Number = 500

The expression **pptr accesses the original integer variable. Assigning 500 changes number.

5. Pointer Levels and Data Types

Each additional pointer level requires another level of indirection.

Declaration Pointer Level Points To
int *p; Single pointer int
int **p; Double pointer Pointer to int
int ***p; Triple pointer Pointer to pointer to int

Example: Triple Pointer

#include <stdio.h>

int main(void)
{
    int number = 25;

    int *p1 = &number;
    int **p2 = &p1;
    int ***p3 = &p2;

    printf("%d\n", ***p3);

    return 0;
}
Expected Output: 
25
Triple pointers are valid C constructs, but practical programs should use only the levels of indirection needed to express the design.

6. Modifying a Pointer Using a Double Pointer

A function receiving an int * parameter gets a copy of the pointer. It cannot directly change the caller's pointer variable.

To update the caller's pointer, pass the address of that pointer using int **.

Example Program

#include <stdio.h>

void move_pointer(int **pptr)
{
    (*pptr)++;
}

int main(void)
{
    int numbers[] = {10, 20, 30};

    int *ptr = numbers;

    printf("Before = %d\n", *ptr);

    move_pointer(&ptr);

    printf("After = %d\n", *ptr);

    return 0;
}
Expected Output: 
Before = 10
After = 20

The function receives the address of the caller's pointer. The expression (*pptr)++ increments the original pointer variable.

7. Difference Between *pptr++ and (*pptr)++

Operator precedence and parentheses are important when working with double pointers.

Expression Operation
(*pptr)++ Increments the pointer stored in the object pointed to by pptr.
*pptr++ Post-increments pptr itself, while the expression accesses the pointer it previously pointed to.
**pptr Accesses the final integer value.
Do not confuse incrementing the double pointer with incrementing the single pointer it points to. These operations change different pointer variables.

8. Double Pointers with Arrays of Pointers

An array of pointers can be accessed through a pointer-to-pointer variable.

Example Program

#include <stdio.h>

int main(void)
{
    const char *names[] = {
        "Navdeep",
        "Rahul",
        "Amit",
        "Karan"
    };

    const char **ptr = names;

    for (int i = 0; i < 4; i++)
    {
        printf("%s\n", *(ptr + i));
    }

    return 0;
}
Expected Output: 
Navdeep
Rahul
Amit
Karan

names is an array of pointers to const char. ptr points to its first element.

9. Double Pointers and Function Parameters

A double pointer is useful when a function needs to update a pointer owned by the caller.

Example: Assigning a Pointer Through a Function

#include <stdio.h>

void assign_pointer(int **pptr, int *target)
{
    *pptr = target;
}

int main(void)
{
    int first = 10;
    int second = 50;

    int *ptr = &first;

    printf("Before = %d\n", *ptr);

    assign_pointer(&ptr, &second);

    printf("After = %d\n", *ptr);

    return 0;
}
Expected Output: 
Before = 10
After = 50

The function changes ptr so that it points to second instead of first.

10. Dynamic Memory Allocation Using Double Pointers

A function can allocate memory and return its address through a double-pointer output parameter.

Example Program

#include <stdio.h>
#include <stdlib.h>

int allocate_integer(int **ptr)
{
    if (ptr == NULL)
    {
        return 0;
    }

    *ptr = malloc(sizeof **ptr);

    if (*ptr == NULL)
    {
        return 0;
    }

    **ptr = 100;

    return 1;
}

int main(void)
{
    int *ptr = NULL;

    if (allocate_integer(&ptr))
    {
        printf("Value = %d\n", *ptr);

        free(ptr);
        ptr = NULL;
    }
    else
    {
        printf("Memory allocation failed\n");
    }

    return 0;
}
Expected Output: 
Value = 100

The function allocates memory and stores the resulting address in the caller's pointer variable through *ptr.

The caller remains responsible for releasing dynamically allocated memory using free().

11. Dynamic Array Allocation Through a Double Pointer

Double pointers can also be used when a function allocates an array and returns its address.

Example Program

#include <stdio.h>
#include <stdlib.h>
#include <stddef.h>

int create_array(int **arr, size_t size)
{
    if (arr == NULL || size == 0 ||
        size > (size_t)-1 / sizeof **arr)
    {
        return 0;
    }

    *arr = malloc(size * sizeof **arr);

    if (*arr == NULL)
    {
        return 0;
    }

    for (size_t i = 0; i < size; i++)
    {
        (*arr)[i] = (int)(i + 1) * 10;
    }

    return 1;
}

int main(void)
{
    int *numbers = NULL;

    size_t size = 5;

    if (create_array(&numbers, size))
    {
        for (size_t i = 0; i < size; i++)
        {
            printf("%d ", numbers[i]);
        }

        printf("\n");

        free(numbers);
        numbers = NULL;
    }
    else
    {
        printf("Allocation failed\n");
    }

    return 0;
}
Expected Output: 
10 20 30 40 50

The function checks for multiplication overflow before allocating memory. The caller must use the returned pointer only after successful allocation.

12. Double Pointers in Linked Lists

A common use of double pointers is modifying the head pointer of a linked list from inside a function.

Example: Inserting a Node at the Beginning

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int insert_at_beginning(struct Node **head, int value)
{
    if (head == NULL)
    {
        return 0;
    }

    struct Node *new_node = malloc(sizeof *new_node);

    if (new_node == NULL)
    {
        return 0;
    }

    new_node->data = value;
    new_node->next = *head;

    *head = new_node;

    return 1;
}

void display_list(const struct Node *head)
{
    while (head != NULL)
    {
        printf("%d -> ", head->data);
        head = head->next;
    }

    printf("NULL\n");
}

void free_list(struct Node *head)
{
    while (head != NULL)
    {
        struct Node *temp = head;

        head = head->next;

        free(temp);
    }
}

int main(void)
{
    struct Node *head = NULL;

    if (!insert_at_beginning(&head, 30) ||
        !insert_at_beginning(&head, 20) ||
        !insert_at_beginning(&head, 10))
    {
        printf("Insertion failed\n");

        free_list(head);

        return 1;
    }

    display_list(head);

    free_list(head);

    return 0;
}
Expected Output: 
10 -> 20 -> 30 -> NULL

The parameter struct Node **head allows the function to update the original head pointer when a new node is inserted.

13. Double Pointers and Command-Line Arguments

The main function can receive command-line arguments using a parameter declared as char **argv.

Function Signature

int main(int argc, char *argv[])

The parameter argv is adjusted to a pointer to pointer to char. It provides access to the array of argument strings.

Example Program

#include <stdio.h>

int main(int argc, char **argv)
{
    printf("Argument count = %d\n", argc);

    for (int i = 0; i < argc; i++)
    {
        printf("Argument %d = %s\n", i, argv[i]);
    }

    return 0;
}

Example execution:

./program hello C
Expected Output: 
Argument count = 3
Argument 0 = ./program
Argument 1 = hello
Argument 2 = C

The exact value of argv[0] depends on how the program is invoked by the execution environment.

14. Double Pointers in Embedded C

Double pointers are useful in embedded software when a function must update a buffer pointer, return allocated memory, or modify a data structure managed by another function.

Example: Updating a Buffer Pointer

#include <stdio.h>
#include <stddef.h>

int advance_buffer(const unsigned char **buffer,
                   size_t *remaining,
                   size_t count)
{
    if (buffer == NULL || remaining == NULL ||
        *buffer == NULL || count > *remaining)
    {
        return 0;
    }

    *buffer += count;
    *remaining -= count;

    return 1;
}

int main(void)
{
    unsigned char data[] = {10, 20, 30, 40, 50};

    const unsigned char *ptr = data;

    size_t remaining = sizeof data;

    if (advance_buffer(&ptr, &remaining, 2))
    {
        printf("Current byte = %u\n", (unsigned int)*ptr);
        printf("Remaining = %zu\n", remaining);
    }

    return 0;
}
Expected Output: 
Current byte = 30
Remaining = 3

This pattern is useful for parsing communication buffers because the function updates the caller's current position and remaining length.

15. Common Errors with Double Pointers

Error Why It Is Incorrect Correct Approach
Uninitialized double pointer Dereferencing it accesses an invalid location. Initialize it with the address of a valid pointer.
Wrong pointer level Passing int * where int ** is required. Pass the address of the pointer variable.
Incorrect dereferencing Accessing the wrong pointer level. Track each level of indirection carefully.
Memory leak Allocated memory is never released. Use free() when ownership ends.
Dereferencing NULL Pointer does not refer to a valid object. Check nullable pointer arguments.
Returning a local variable address The local object's lifetime ends when the function returns. Use caller-owned or dynamically allocated storage.

20. Key Takeaways

  • A double pointer stores the address of another pointer.
  • Each dereference removes one level of indirection.
  • **pptr accesses the final object in a two-level pointer chain.
  • A double pointer can modify the caller's pointer variable.
  • Double pointers are useful for dynamic memory allocation.
  • Arrays of string pointers can be traversed using char ** or const char ** as appropriate.
  • Linked-list operations often use pointer-to-pointer parameters.
  • Command-line arguments provide a common real-world example of double pointers.
  • Always validate pointer levels and manage allocated memory correctly.
