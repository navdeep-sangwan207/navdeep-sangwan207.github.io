Lecture 03: Pointer Arithmetic and Arrays

Understand pointer arithmetic, pointer movement, array traversal, memory relationships and pointer-based array operations in C.

1. Learning Objectives

  • Understand pointer arithmetic in C.
  • Perform pointer increment and decrement.
  • Understand pointer addition and subtraction.
  • Access array elements using pointers.
  • Understand the relationship between arrays and pointers.
  • Use pointer expressions for array traversal.
  • Understand pointer comparisons and boundaries.
  • Write pointer-based searching and array-processing programs.
  • Identify invalid pointer arithmetic operations.

2. What Is Pointer Arithmetic?

Pointer arithmetic means performing certain arithmetic operations on pointers to move between elements of an array.

Unlike ordinary integer arithmetic, pointer arithmetic takes the size of the pointed-to type into account.

Example

int arr[] = {10, 20, 30, 40};

int *ptr = arr;

ptr++;

Initially, ptr points to arr[0]. After ptr++, it points to arr[1].

If ptr points to an array element of type T, incrementing it moves it to the next T element, not simply to the next byte.

3. Pointer Increment Operator (++)

The increment operator moves a pointer to the next element of its pointed-to type.

Syntax

ptr++;

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40};

    int *ptr = arr;

    printf("First element = %d\n", *ptr);

    ptr++;

    printf("Second element = %d\n", *ptr);

    return 0;
}
Expected Output: 
First element = 10
Second element = 20

The pointer advances by one int element. The actual byte distance depends on sizeof(int).

4. Pointer Decrement Operator (--)

The decrement operator moves a pointer to the previous element of an array.

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40};

    int *ptr = &arr[3];

    printf("Current element = %d\n", *ptr);

    ptr--;

    printf("Previous element = %d\n", *ptr);

    return 0;
}
Expected Output: 
Current element = 40
Previous element = 30

5. Pointer Addition

An integer value can be added to a pointer to move it forward by a specified number of elements within the same array.

Syntax

ptr + n

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int *ptr = arr;

    printf("First element = %d\n", *ptr);

    printf("Third element = %d\n", *(ptr + 2));

    printf("Fifth element = %d\n", *(ptr + 4));

    return 0;
}
Expected Output: 
First element = 10
Third element = 30
Fifth element = 50

The expression ptr + 2 points to the element two positions after the element currently addressed by ptr.

Pointer addition does not modify ptr unless the result is assigned back to it.

6. Pointer Subtraction

Subtracting an integer from a pointer moves it backward within the same array.

Example

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int *ptr = &arr[4];

    printf("Current = %d\n", *ptr);

    printf("Previous = %d\n", *(ptr - 1));

    printf("First = %d\n", *(ptr - 4));

    return 0;
}
Expected Output: 
Current = 50
Previous = 40
First = 10

7. Difference Between Two Pointers

Two pointers pointing into the same array can be subtracted to find the number of elements between them.

Example Program

#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int *p1 = &arr[1];
    int *p2 = &arr[4];

    ptrdiff_t difference = p2 - p1;

    printf("Difference = %td\n", difference);

    return 0;
}
Expected Output: 
Difference = 3

p1 points to index 1 and p2 points to index 4. Therefore, the difference is three elements.

The subtraction result has type ptrdiff_t, defined in stddef.h. Pointer subtraction is defined when both pointers refer to elements of the same array object, or one past its end.

8. Relationship Between Arrays and Pointers

In most expressions, an array expression is converted to a pointer to its first element. This is commonly called array-to-pointer decay.

Example

int arr[] = {10, 20, 30};

int *ptr = arr;

In this initialization, arr is converted to a pointer to arr[0].

Expression Meaning
arr Usually converts to &arr[0].
&arr[0] Address of the first element.
arr[0] First array element.
*arr First array element.
arr + 1 Pointer to the second element.
*(arr + 1) Second array element.
An array is not a pointer. An array object has its own storage and size. Array-to-pointer conversion occurs in most expressions, but arrays and pointers remain different types.

9. Accessing Array Elements Using Pointers

Array indexing and pointer arithmetic are closely related.

Equivalent Expressions

arr[i]

*(arr + i)

*(ptr + i)

If ptr points to the first element of arr, these expressions access the same element.

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int *ptr = arr;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", *(ptr + i));
    }

    printf("\n");

    return 0;
}
Expected Output: 
10 20 30 40 50

10. Pointer Increment in a Loop

Instead of calculating an element address using an index, a pointer can move through the array one element at a time.

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {5, 10, 15, 20, 25};

    int *ptr = arr;
    int count = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < count; i++)
    {
        printf("%d ", *ptr);
        ptr++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
5 10 15 20 25

The pointer moves from one array element to the next during each loop iteration.

11. Pointer Comparison

Pointers into the same array can be compared relationally to determine their positions.

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40};

    int *p1 = &arr[1];
    int *p2 = &arr[3];

    if (p1 < p2)
    {
        printf("p1 is before p2\n");
    }
    else
    {
        printf("p1 is not before p2\n");
    }

    return 0;
}
Expected Output: 
p1 is before p2

Relational pointer comparisons have defined ordering behavior for pointers into the same array object, including its one-past position. Do not use them to establish a general ordering between unrelated objects.

12. Array Name vs Pointer Variable

An array name and a pointer variable are different entities, even though an array often converts to a pointer in expressions.

Example Program

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30};

    int *ptr = arr;

    printf("First element = %d\n", *arr);
    printf("Pointer element = %d\n", *ptr);

    ptr++;

    printf("After increment = %d\n", *ptr);

    return 0;
}
Expected Output: 
First element = 10
Pointer element = 10
After increment = 20

The pointer variable can be incremented. The array name cannot be assigned a new address.

Important Example

int arr[5];
int *ptr = arr;

ptr++;   // Valid when ptr remains within the array
arr++;   // Invalid: array name is not a modifiable pointer

13. Pointer Arithmetic with Different Data Types

Pointer arithmetic advances according to the size of the pointed-to type.

Example Program

#include <stdio.h>

int main(void)
{
    int numbers[] = {10, 20, 30};
    char letters[] = {'A', 'B', 'C'};

    int *ip = numbers;
    char *cp = letters;

    printf("First integer = %d\n", *ip);
    printf("First character = %c\n", *cp);

    ip++;
    cp++;

    printf("Next integer = %d\n", *ip);
    printf("Next character = %c\n", *cp);

    return 0;
}
Expected Output: 
First integer = 10
First character = A
Next integer = 20
Next character = B

Both pointers move to their respective next elements, even though the sizes of int and char may differ.

14. Important Pointer Arithmetic Rules

Operation Validity
ptr++ Valid when the resulting pointer remains within the same array or one position past its end.
ptr-- Valid when the resulting pointer remains within the array.
ptr + n Valid when the result remains within the array or one position past its end.
ptr - n Valid when the result remains within the array or one position past its end.
ptr2 - ptr1 Valid for pointers into the same array, including its one-past position, if the result is representable.
ptr1 + ptr2 Invalid: adding two pointers is not permitted.
ptr * 2 Invalid: multiplying a pointer is not permitted.
ptr / 2 Invalid: dividing a pointer is not permitted.
A pointer one position past the last array element may be formed and compared, but it must not be dereferenced.

15. One-Past-the-End Pointer

C permits forming a pointer to one position beyond the last element of an array.

Example

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30};

    int *start = arr;
    int *end = arr + 3;

    while (start < end)
    {
        printf("%d ", *start);
        start++;
    }

    printf("\n");

    return 0;
}
Expected Output: 
10 20 30

end points one position beyond the final element. The loop stops before dereferencing it.

The one-past pointer is useful for pointer-based loops and range processing. It is not a pointer to an actual array element.

16. Practical Program: Find the Sum of Array Elements Using Pointers

#include <stdio.h>

int main(void)
{
    int arr[] = {10, 20, 30, 40, 50};

    int count = sizeof(arr) / sizeof(arr[0]);
    int sum = 0;

    int *ptr = arr;

    for (int i = 0; i < count; i++)
    {
        sum += *ptr;
        ptr++;
    }

    printf("Sum = %d\n", sum);

    return 0;
}
Expected Output: 
Sum = 150

Time complexity: O(n). Auxiliary space: O(1).

17. Practical Program: Find the Maximum Element Using Pointers

#include <stdio.h>

int main(void)
{
    int arr[] = {25, 80, 15, 95, 40};

    int count = sizeof(arr) / sizeof(arr[0]);

    int *ptr = arr;
    int maximum = *ptr;

    for (int i = 1; i < count; i++)
    {
        ptr++;

        if (*ptr > maximum)
        {
            maximum = *ptr;
        }
    }

    printf("Maximum = %d\n", maximum);

    return 0;
}
Expected Output: 
Maximum = 95

Time complexity: O(n). Auxiliary space: O(1).

18. Practical Program: Search an Array Using Pointers

#include <stdio.h>

int main(void)
{
    int arr[] = {12, 24, 36, 48, 60};

    int count = sizeof(arr) / sizeof(arr[0]);
    int target = 36;

    int *ptr = arr;
    int found = 0;

    for (int i = 0; i < count; i++)
    {
        if (*ptr == target)
        {
            printf("Found at index %d\n", i);
            found = 1;
            break;
        }

        ptr++;
    }

    if (!found)
    {
        printf("Element not found\n");
    }

    return 0;
}
Expected Output: 
Found at index 2

Time complexity: O(n). Auxiliary space: O(1).

19. Common Pointer Arithmetic Errors

Error 1: Dereferencing One-Past-the-End Pointer

int arr[3] = {10, 20, 30};

int *ptr = arr + 3;

printf("%d", *ptr);   // Undefined behavior

Error 2: Moving Beyond the Permitted Array Range

int arr[3] = {10, 20, 30};

int *ptr = arr;

ptr = ptr + 5;   // Undefined behavior

Error 3: Adding Two Pointers

int *p1;
int *p2;

int *p3 = p1 + p2;   // Invalid

Error 4: Subtracting Unrelated Pointers

int a[3];
int b[3];

ptrdiff_t diff = &a[1] - &b[1];

Subtracting pointers that do not refer to the same array object, or its one-past position, has undefined behavior.

Error 5: Using an Incorrect Array Boundary

int arr[5] = {1, 2, 3, 4, 5};

for (int i = 0; i <= 5; i++)
{
    printf("%d ", arr[i]);
}

The valid indices are 0 through 4. The loop attempts to access arr[5], which is outside the array.

23. Practical Applications

Application Pointer Arithmetic Usage
Array processing Efficient traversal of array elements.

Data structures Accessing contiguous data and implementing algorithms.

24. Key Takeaways

  • Pointer arithmetic advances in units of the pointed-to type.
  • ptr++ moves to the next element.
  • ptr-- moves to the previous element.
  • Pointer addition and subtraction by integers are permitted within array boundaries.
  • Two pointers into the same array can be subtracted.
  • Array expressions usually convert to pointers to their first elements.
  • arr[i] is equivalent to *(arr + i).
  • Array names are not modifiable pointer variables.
  • One-past-the-end pointers can be formed but not dereferenced.
  • Pointer operations must respect array boundaries.
Placement preparation target: Be able to trace pointer movement, convert array indexing into pointer expressions, calculate pointer differences and identify invalid pointer arithmetic.
