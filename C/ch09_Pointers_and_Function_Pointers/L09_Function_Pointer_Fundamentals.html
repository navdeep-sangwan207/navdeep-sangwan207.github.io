2. What Is a Function Pointer?

A function pointer is a pointer that refers to a function. It allows a program to call a function indirectly through a pointer variable.

A normal function call directly specifies the function name. A function pointer allows the function to be selected and called through a variable.

Normal Function Call

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result = add(10, 20);

    printf("Result = %d\n", result);

    return 0;
}
Expected Output: 
Result = 30

Function Call Through a Pointer

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*ptr)(int, int);

    ptr = add;

    int result = ptr(10, 20);

    printf("Result = %d\n", result);

    return 0;
}
Expected Output: 
Result = 30

The pointer ptr refers to the add function. Calling ptr(10, 20) invokes that function.

3. Function Pointer Declaration Syntax

Consider this declaration:

int (*ptr)(int, int);

Interpret it as follows:

  • ptr is the pointer variable.
  • *ptr indicates that ptr is a pointer.
  • (int, int) specifies two integer parameters.
  • int before the pointer declaration is the return type.

Therefore, ptr points to a function that accepts two integers and returns an integer.

Different Function Pointer Types

Function Pointer Declaration Function Signature
int (*p)(int, int); Two int parameters, returns int.
void (*p)(void); No parameters, returns void.
float (*p)(float); One float parameter, returns float.
char (*p)(void); No parameters, returns char.
double (*p)(int, double); int and double parameters, returns double.

4. Function Name and Function Address

In most expressions, a function designator converts to a pointer to that function. Therefore, both forms below can assign the function address to a compatible function pointer. 

ptr = add;

ptr = &add;

Both assignments are valid when ptr has a compatible function pointer type.

The function name is not a normal data object. You cannot modify a function or increment a function pointer as you would an ordinary object pointer.

5. Calling a Function Through a Function Pointer

A function can be invoked using a function pointer in either of these equivalent forms: 

ptr(10, 20);

(*ptr)(10, 20);

The first form is commonly used because it is shorter and easier to read.

Example Program

#include <stdio.h>

void display(void)
{
    printf("Function called through pointer\n");
}

int main(void)
{
    void (*ptr)(void) = display;

    ptr();

    (*ptr)();

    return 0;
}
Expected Output: 
Function called through pointer
Function called through pointer

6. Function Pointer with Different Return Types

The function pointer declaration must match the function's return type and parameter types.

Example: Floating-Point Function

#include <stdio.h>

float calculate_average(float a, float b)
{
    return (a + b) / 2.0f;
}

int main(void)
{
    float (*ptr)(float, float);

    ptr = calculate_average;

    float result = ptr(12.0f, 18.0f);

    printf("Average = %.2f\n", result);

    return 0;
}
Expected Output: 
Average = 15.00

7. Passing a Function Pointer as a Function Argument

A function pointer can be passed as an argument to another function. The receiving function can then invoke the supplied function.

Example Program

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int calculate(int x, int y, int (*operation)(int, int))
{
    return operation(x, y);
}

int main(void)
{
    int result;

    result = calculate(15, 5, add);

    printf("Result = %d\n", result);

    return 0;
}
Expected Output: 
Result = 20

The calculate function receives a pointer to a function that accepts two integers and returns an integer.

8. Using typedef with Function Pointers

Complex function pointer declarations can become difficult to read. The typedef keyword provides a convenient way to create an alias for a function pointer type.

Without typedef

int (*operation)(int, int);

With typedef

typedef int (*Operation)(int, int);

Operation operation;

Example Program

#include <stdio.h>

typedef int (*Operation)(int, int);

int add(int a, int b)
{
    return a + b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    Operation operation;

    operation = add;
    printf("Addition = %d\n", operation(5, 4));

    operation = multiply;
    printf("Multiplication = %d\n", operation(5, 4));

    return 0;
}
Expected Output: 
Addition = 9
Multiplication = 20

9. Function Pointer Type Compatibility

A function pointer must have a type compatible with the function it refers to.

Valid Example

int add(int a, int b)
{
    return a + b;
}

int (*ptr)(int, int) = add;

Invalid Example

int add(int a, int b)
{
    return a + b;
}

float (*ptr)(float, float) = add;
The invalid example uses an incompatible function pointer type. Do not cast an incompatible function pointer to suppress diagnostics and then call through it. Calling through an incompatible function pointer type results in undefined behavior.

Match the return type and parameter types carefully. Function types also include important distinctions such as parameter prototypes and variadic parameters.

10. Function Pointers and Arrays

An array can store multiple function pointers. This is useful when a program needs to select one operation from several available functions.

Example Program: Operation Selection

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operations[3])(int, int) = {
        add,
        subtract,
        multiply
    };

    int a = 12;
    int b = 4;

    for (int i = 0; i < 3; i++)
    {
        printf("%d\n", operations[i](a, b));
    }

    return 0;
}
Expected Output: 
16
8
48

11. Callback Functions: Basic Introduction

A callback is a function supplied to another function through a function pointer. The receiving function invokes it when required.

Example Program

#include <stdio.h>

void success_message(void)
{
    printf("Operation completed successfully\n");
}

void perform_operation(void (*callback)(void))
{
    printf("Performing operation...\n");

    callback();
}

int main(void)
{
    perform_operation(success_message);

    return 0;
}
Expected Output: 
Performing operation...
Operation completed successfully

The perform_operation function does not need to know the internal implementation of the callback. It only needs a compatible function pointer.

Callback design is important in event-driven systems, embedded software, device drivers and library interfaces. Detailed callback patterns are covered in the next lecture.

12. Function Pointers in Embedded C

Function pointers are frequently used in embedded software to organize operations and event handling.

Typical Applications

  • Interrupt service routine registration interfaces.
  • Peripheral driver operation tables.
  • Command dispatch systems.
  • State machine transition handlers.
  • Communication protocol handlers.
  • Timer and event callback interfaces.

Example: Command Handler Selection

#include <stdio.h>

void start_command(void)
{
    printf("System started\n");
}

void stop_command(void)
{
    printf("System stopped\n");
}

void reset_command(void)
{
    printf("System reset\n");
}

int main(void)
{
    void (*commands[3])(void) = {
        start_command,
        stop_command,
        reset_command
    };

    int selected_command = 1;

    if (selected_command >= 0 &&
        selected_command < 3)
    {
        commands[selected_command]();
    }

    return 0;
}
Expected Output: 
System stopped

A command index selects a corresponding function from the function pointer array.

A real microcontroller interrupt handler must follow the compiler, architecture and interrupt controller requirements. Ordinary function pointers do not automatically make a function an interrupt service routine.

13. Function Pointer Versus Object Pointer

Feature Object Pointer Function Pointer
Points to An object or data. A function.
Example int *p; int (*p)(int);
Dereferencing Accesses the pointed-to object. Can be used to invoke the function.
Pointer arithmetic Defined for suitable object pointers within array boundaries. Not defined.
Typical application Data access and memory manipulation. Callbacks and indirect function calls.

14. Common Mistakes

Mistake Problem Correction
Missing parentheses Declaration may represent a different type. Use int (*ptr)(int, int).
Calling an uninitialized pointer Invalid function call. Initialize it with a compatible function.
Incompatible function assignment Function pointer types do not match. Match the function signature.
Incorrect parameter count Call does not match the prototype. Pass the required arguments.
Assuming function pointers support arithmetic Function pointer arithmetic is not defined by C. Use a function pointer array when selection is needed.
Calling through a cast incompatible pointer Can produce undefined behavior. Use a correctly typed function pointer.

18. Key Takeaways

  • A function pointer stores a reference to a function.
  • Its type must be compatible with the function it refers to.
  • Functions can be called indirectly through function pointers.
  • Function pointers can be passed as function arguments.
  • typedef improves readability of complex declarations.
  • Arrays of function pointers support operation selection.
  • Callbacks enable flexible and reusable program design.
  • Function pointers are widely used in embedded and systems programming.
