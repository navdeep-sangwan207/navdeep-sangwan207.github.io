1. Introduction

GPIO stands for General Purpose Input/Output. It is a basic digital interface provided by a microcontroller to communicate with external electronic devices.

A GPIO pin can generally be configured as either:

  • Input: To receive digital signals.
  • Output: To generate digital signals.

GPIO is commonly used to interface LEDs, switches, push buttons, relays, digital sensors, and other external circuits.

Learning objectives:
  • Understand the meaning of GPIO.
  • Understand digital input and output.
  • Identify GPIO applications.
  • Understand the GPIO structure of LPC2129.
  • Learn the basic GPIO programming sequence.
  • Understand GPIO pin multiplexing.

2. What Is GPIO?

GPIO is a configurable digital interface that allows a microcontroller to interact with external hardware.

The term General Purpose means that the pin can be assigned to different digital input or output tasks according to the application.

Example applications

  • Switching an LED ON or OFF.
  • Reading the state of a push button.
  • Detecting a digital sensor signal.
  • Controlling a relay through a driver circuit.
  • Generating digital control signals.

Basic GPIO concept

External Device | | GPIO Pin | | Microcontroller | | CPU / Firmware

3. Digital Input and Digital Output

GPIO pins operate with digital logic states. A digital signal is commonly represented by two logical states: LOW and HIGH.

Logic State Meaning
LOW (0) Logic zero.
HIGH (1) Logic one.

The actual voltage corresponding to these states depends on the device's electrical specifications and operating conditions.

3.1 Digital Input

When a GPIO pin is configured as an input, the microcontroller reads the digital signal applied to that pin.

Example: Reading a push button.

Push Button | v GPIO Input Pin | v Input Register | v Microcontroller | v Program Logic

The program checks the input state and performs an operation according to the detected logic level.

3.2 Digital Output

When a GPIO pin is configured as an output, the microcontroller controls its digital output state.

Example: Controlling an LED.

Microcontroller | v GPIO Output | v LED Circuit | v ON / OFF Control

The output can be changed between logic HIGH and logic LOW through suitable GPIO register operations.

4. GPIO Input vs GPIO Output

Feature GPIO Input GPIO Output
Purpose Receives digital signals. Generates digital signals.
Direction External circuit to MCU. MCU to external circuit.
Example Push button. LED control.
Configuration Input direction. Output direction.
Typical operation Read pin state. Set or clear output state.

5. GPIO in Microcontrollers

A microcontroller generally contains GPIO ports that provide multiple digital input/output pins.

GPIO pins are connected internally to the microcontroller's peripheral and bus architecture.

Basic GPIO architecture

CPU | v Internal Bus System | v GPIO Controller | +-------+-------+ | | v v Direction Data Control Registers Registers | | +-------+-------+ | v GPIO Pins | +-------+-------+ | | v v Input Devices Output Devices (Switches) (LEDs)

The GPIO controller uses configuration and data registers to manage the digital pins.

6. Introduction to LPC2129 GPIO

The LPC2129 is an ARM7TDMI-S-based microcontroller from NXP. It provides programmable GPIO functionality through its digital I/O ports.

Its GPIO pins can be used for general digital input/output or assigned to alternate peripheral functions.

GPIO ports

Port Description
Port 0 GPIO port with pins shared with alternate peripheral functions.
Port 1 GPIO port with device/package-dependent pin availability.
The LPC2129 has up to 46 GPIO pins, subject to package and pin-function availability. Always refer to the exact device datasheet for the pins available in the selected package.

7. GPIO Pin Multiplexing

In the LPC2129, many physical pins support more than one function. This is known as pin multiplexing.

A physical pin may be configured for GPIO or an alternate peripheral function such as UART, PWM, or another supported interface.

Example of pin multiplexing

Physical Pin | +-------+-------+ | | | v v v GPIO UART PWM | | | +-------+-------+ | PINSEL Configuration

The PINSEL registers select the required function for multiplexed pins.

A pin must be configured for its GPIO function before using it as a general-purpose digital input or output. A pin assigned to an alternate peripheral function cannot be assumed to operate as GPIO at the same time.

8. Important LPC2129 GPIO Registers

GPIO operation is controlled through memory-mapped registers.

Register Function
PINSEL0 / PINSEL1 / PINSEL2 Select pin functions.
IODIR Configures pin direction.
IOPIN Reads or accesses GPIO pin states.
IOSET Sets selected output bits.
IOCLR Clears selected output bits.

Basic GPIO programming sequence

  1. Select the GPIO function using PINSEL.
  2. Configure the direction using IODIR.
  3. Read input or control output using GPIO data registers.
  4. Verify program execution and register values.

The following lessons explain each register in detail.

9. GPIO Programming Fundamentals

Embedded C programs can access GPIO registers through device header files.

Device header

#include <LPC21xx.h>

This header provides register definitions for supported LPC21xx devices.

Conceptual output operation

// Configure selected pin as output
// Set the required GPIO output bit
// Clear the output bit when required

The exact register operations and pin configuration are covered in the upcoming lessons.

Use the correct GPIO port, pin number, PINSEL field, and register definition for the selected LPC2129 pin.

10. GPIO Applications in Embedded Systems

LED control

GPIO output pins can control LEDs through suitable current-limiting resistors and circuit connections.

Switch and push-button detection

GPIO input pins can detect user operations through switches and push buttons.

Relay control

A GPIO signal can control a relay through an appropriate transistor or driver circuit.

Digital sensor interfacing

Digital sensors can provide HIGH or LOW signals that can be read through GPIO inputs.

Control systems

GPIO can be used for enable signals, status indicators, fault signals, and digital control operations.

11. Advantages of GPIO

  • Simple digital hardware interface.
  • Flexible input and output configuration.
  • Useful for interfacing many external devices.
  • Direct register-level control.
  • Suitable for basic control and monitoring.
  • Reduces the need for dedicated interfaces in simple applications.

12. Common GPIO Programming Mistakes

Mistake Explanation
Incorrect PINSEL configuration The pin may remain assigned to an alternate function.
Incorrect direction An input pin may be mistakenly used as an output.
Wrong port selection The program accesses a different GPIO port.
Wrong bit position The program changes a different pin.
Incorrect electrical connection Physical circuits may not produce the expected logic state.
Ignoring pin availability Not all logical port positions are available on every package.

14. Interview Questions and Answers

Q1. What is GPIO?

GPIO stands for General Purpose Input/Output. It is a configurable digital interface used by a microcontroller to communicate with external devices.

Q2. What are the two basic GPIO modes?

Input mode and output mode.

Q3. What is a GPIO input?

It is a pin configured to receive a digital signal from an external circuit.

Q4. What is a GPIO output?

It is a pin configured to generate a digital signal for an external circuit.

Q5. What is pin multiplexing?

It is the use of a physical pin for different functions selected through configuration registers.

Q6. What is the purpose of PINSEL?

PINSEL registers select the function assigned to multiplexed pins.

Q7. What is the purpose of IODIR?

It configures GPIO pins as inputs or outputs.

Q8. What is the purpose of IOPIN?

It provides access to the GPIO pin data state.

Q9. What are IOSET and IOCLR?

They are GPIO registers used to set and clear selected output bits.

Q10. Give four applications of GPIO.

LED control, push-button detection, relay control through a driver, and digital sensor interfacing.
