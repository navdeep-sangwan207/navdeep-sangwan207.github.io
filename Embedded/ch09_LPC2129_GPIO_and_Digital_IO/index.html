1. Chapter Overview

General Purpose Input/Output (GPIO) is one of the fundamental interfaces used in embedded systems.

GPIO pins allow a microcontroller to communicate with external digital devices such as LEDs, push buttons, switches, relays, and other digital circuits.

In this chapter, we will study the LPC2129 GPIO architecture and learn how to control digital pins using its memory-mapped registers.

Important GPIO registers:
Register Purpose
PINSEL Selects the pin function.
IODIR Configures a GPIO pin as input or output.
IOPIN Reads the pin state and provides pin data access.
IOSET Sets selected output bits to logic HIGH.
IOCLR Clears selected output bits to logic LOW.

4. LPC2129 GPIO Register Summary

The LPC2129 provides GPIO functionality through Port 0 and Port 1. GPIO pins share physical pins with alternate peripheral functions, so the pin function must be selected correctly before GPIO operation.

Register Group Function Typical Registers
Pin Function Selection Selects GPIO or an alternate peripheral function. PINSEL0, PINSEL1, PINSEL2
Direction Control Configures GPIO pins as inputs or outputs. IODIR0, IODIR1
Pin Data Reads or accesses GPIO pin states. IOPIN0, IOPIN1
Output Set Sets selected output bits. IOSET0, IOSET1
Output Clear Clears selected output bits. IOCLR0, IOCLR1
Technical note: Not every bit position represents an externally available GPIO pin. Check the LPC2129 datasheet and package pin assignment before selecting a pin for a physical circuit.

8. Important Programming Notes

  • Configure the pin function before using a multiplexed pin as GPIO.
  • Configure the direction register before using a pin as an output.
  • Use IOSET and IOCLR for bit-specific output control.
  • Read input states using the appropriate GPIO pin register.
  • Use suitable current-limiting resistors and driver circuits in physical applications.
  • Check the LPC2129 pin multiplexing table before assigning peripheral or GPIO functions.
