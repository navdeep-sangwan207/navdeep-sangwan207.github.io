1. Introduction

The LPC2129 microcontroller provides General Purpose Input/Output (GPIO) functionality through two GPIO ports: Port 0 and Port 1.

Each port is organized as a group of digital input/output signals. The processor controls these signals through memory-mapped GPIO registers.

GPIO ports allow the microcontroller to interface with external devices such as LEDs, switches, push buttons, sensors, and control circuits.

Learning objectives:
  • Understand LPC2129 GPIO port organization.
  • Differentiate between Port 0 and Port 1.
  • Understand GPIO pin numbering.
  • Learn the port register organization.
  • Understand pin multiplexing.
  • Identify GPIO-related registers.
  • Understand port-level programming.

2. GPIO Port Architecture

A GPIO port is a collection of digital input/output pins controlled through a common set of registers.

The LPC2129 has two GPIO ports:

  • Port 0
  • Port 1

Basic port organization

LPC2129 | Internal Bus | +-------+-------+ | | v v GPIO Port 0 GPIO Port 1 | | +----+----+ +---+----+ | | | | v v v v Input Output Input Output Pins Pins Pins Pins

Each GPIO port has registers that control direction, read pin states, and set or clear output values.

3. LPC2129 Port 0

Port 0 provides a group of GPIO pins identified by the notation P0.0, P0.1, P0.2, and so on.

The number after the decimal point represents the bit position within the port.

Port 0 pin notation

Pin Name Port Bit Position
P0.0 Port 0 Bit 0
P0.1 Port 0 Bit 1
P0.2 Port 0 Bit 2
P0.3 Port 0 Bit 3
... ... ...
P0.31 Port 0 Bit 31

The Port 0 GPIO register interface is organized as a 32-bit register bank. This does not mean that every bit position is available as a GPIO pin on the package.

Many Port 0 pins have alternate functions. Before using a pin as GPIO, configure its function using the appropriate PINSEL register and verify the package pin mapping.

4. LPC2129 Port 1

Port 1 is the second GPIO port of the LPC2129. Its pins are identified using the notation P1.x.

Port 1 provides additional digital input/output functionality, subject to the device's pin availability and alternate-function assignments.

Port 1 pin notation

Pin Name Port Bit Position
P1.16 Port 1 Bit 16
P1.17 Port 1 Bit 17
P1.18 Port 1 Bit 18
P1.19 Port 1 Bit 19
... ... ...
P1.31 Port 1 Bit 31
Port 1 does not provide a complete set of 32 GPIO pins on the LPC2129. Only the implemented and package- available Port 1 pin positions should be treated as usable GPIO.

6. GPIO Pin Numbering

Every GPIO pin has a port number and a bit position.

For example:

  • P0.5 means Port 0, bit 5.
  • P0.10 means Port 0, bit 10.
  • P0.28 means Port 0, bit 28.
  • P1.16 means Port 1, bit 16.

Bit position representation

Port 0 Register (32 bits) Bit: 31 30 29 ... 5 4 3 2 1 0 | | | | | | | | | +---+---+--------+--+--+--+--+--+ | v P0.5 = Bit 5

The bit position determines which bit of the corresponding GPIO register is used to access a pin.

7. GPIO Register Organization

The GPIO ports are controlled through a group of memory-mapped registers.

Important registers

Register Port 0 Port 1 Purpose
Direction IODIR0 IODIR1 Input/output configuration.
Pin Data IOPIN0 IOPIN1 Accesses GPIO pin states.
Set Output IOSET0 IOSET1 Sets selected output bits.
Clear Output IOCLR0 IOCLR1 Clears selected output bits.

Register relationship

GPIO Port | +---------+---------+ | | | v v v IODIR IOPIN IOSET / IOCLR | | | v v v Direction Pin Data Output Control | | | +---------+---------+ | v GPIO Pins

8. GPIO Pin Multiplexing

LPC2129 physical pins may support multiple functions. This is called pin multiplexing.

A pin can be configured for GPIO or an alternate peripheral function depending on its PINSEL configuration.

Example

Pin Possible Function
P0.0 GPIO or TXD0
P0.1 GPIO or RXD0
P0.2 GPIO or SCL0
P0.3 GPIO or SDA0

These examples show how GPIO pins can also be assigned to peripheral functions.

Always check the exact PINSEL field and function table in the LPC2129 User Manual before configuring a physical pin. Selecting an alternate function removes its availability for ordinary GPIO use.

9. GPIO Port Programming Example

The following example demonstrates how to configure a Port 0 pin as an output and set its output bit.

Objective

Configure P0.5 as a GPIO output and set its output state.

Embedded C Program

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    // Set P0.5 output bit
    IOSET0 = (1U << 5);

    while (1)
    {
        // Maintain program execution
    }
}

Program explanation

Statement Explanation
PINSEL0 &= ~(3U << 10); Selects the GPIO function for P0.5 by clearing its two PINSEL bits.
IODIR0 |= (1U << 5); Configures P0.5 as an output.
IOSET0 = (1U << 5); Sets the P0.5 output bit.
while (1) Keeps the program running continuously.
The PINSEL0 bit-field calculation for P0.5 uses bits 11:10. Confirm the selected pin's function table and package availability before applying this example to hardware.

10. Bit Masking in GPIO

Bit masking is used to modify or examine a particular bit without unintentionally changing other bits.

Set a bit

IODIR0 |= (1U << 5);

Clear a bit

IODIR0 &= ~(1U << 5);

Test a bit

if (IOPIN0 & (1U << 5))
{
    // Bit 5 reads as logic HIGH
}

These bitwise operations are fundamental to GPIO programming and are used throughout embedded firmware.

11. Practical Applications

  • Using Port 0 pins for LED control.
  • Using GPIO inputs to read push buttons.
  • Reading digital sensor outputs.
  • Controlling external driver circuits.
  • Generating digital enable signals.
  • Monitoring digital status signals.
  • Building basic embedded control systems.

12. Common Programming Mistakes

Mistake Explanation
Using the wrong port register Port 0 and Port 1 have separate register sets.
Incorrect bit position The wrong pin may be selected.
Incorrect PINSEL configuration The pin may remain assigned to an alternate function.
Wrong direction configuration The pin may be configured as input instead of output.
Assuming all port bits are physical pins Some bit positions are not available as GPIO.
Ignoring package pin assignment The selected signal may not be available on the package.

  8. Step through the program.

Expected register-level observation

After executing the configuration statements, bit 5 of the direction register is set, and the output-set register receives a mask with bit 5 set. 

IODIR0 bit 5 = 1
IOSET0 write mask = 0x00000020
This is a software-level register observation. The simulator does not prove that an external LED is illuminated or that a physical pin has the expected voltage.

14. Interview Questions and Answers

Q1. How many GPIO ports are provided by LPC2129?

LPC2129 provides two GPIO ports: Port 0 and Port 1.

Q2. What does P0.5 represent?

It represents bit 5 of GPIO Port 0.

Q3. What does P1.20 represent?

It represents bit 20 of GPIO Port 1, subject to actual pin implementation and availability.

Q4. What is the purpose of IODIR0?

It configures the direction of Port 0 GPIO pins.

Q5. What is the purpose of IODIR1?

It configures the direction of Port 1 GPIO pins.

Q6. What is the purpose of IOSET0?

It sets selected Port 0 output bits.

Q7. What is the purpose of IOCLR1?

It clears selected Port 1 output bits.

Q8. Are all 32 bits of each port available as GPIO?

No. The actual GPIO availability depends on the device implementation, package, and pin-function assignments.

Q9. Why are PINSEL registers important?

They select the required function for multiplexed physical pins.

Q10. What is a port register?

It is a memory-mapped register used to control or access a group of GPIO pins.

17. Lesson Summary

  • LPC2129 provides GPIO Port 0 and Port 1.
  • GPIO pins are identified by port number and bit position.
  • Each port has its own direction and data registers.
  • IODIR0 and IODIR1 configure pin direction.
  • IOPIN0 and IOPIN1 provide access to pin states.
  • IOSET and IOCLR control output bits.
  • PINSEL registers select multiplexed pin functions.
  • Not all register bit positions are available as physical GPIO pins.
  • GPIO ports support digital input and output applications.
