1. Introduction

The LPC2129 provides dedicated GPIO output control registers called IOSET and IOCLR.

These registers allow an embedded C program to change the logic state of GPIO output pins.

  • IOSET: Sets selected GPIO output bits to logic HIGH.
  • IOCLR: Clears selected GPIO output bits to logic LOW.

These registers provide a convenient way to control individual pins without overwriting unrelated output states.

  • Understand the purpose of IOSET and IOCLR.
  • Understand IOSET0, IOSET1, IOCLR0, and IOCLR1.

  • Control multiple GPIO pins using masks.
  • Write Embedded C output-control programs.
  • Inspect GPIO output registers in Keil uVision.

2. What Is the IOSET Register?

IOSET is the GPIO Output Set Register.

Writing a 1 to a particular IOSET bit sets the corresponding GPIO output latch to logic HIGH.

Writing a 0 to a bit does not change the corresponding output latch.

Written Bit Effect
0 No change to the corresponding output latch.
1 Sets the corresponding output latch HIGH.
Write to IOSET | v Selected Bit = 1 | v GPIO Output Latch = HIGH | v Output Pin HIGH

3. What Is the IOCLR Register?

IOCLR is the GPIO Output Clear Register.

Writing a 1 to a particular IOCLR bit clears the corresponding GPIO output latch to logic LOW.

Writing a 0 does not change the corresponding output latch.

Written Bit Effect
0 No change to the corresponding output latch.
1 Clears the corresponding output latch LOW.
Write to IOCLR | v Selected Bit = 1 | v GPIO Output Latch = LOW | v Output Pin LOW

4. IOSET0, IOSET1, IOCLR0, and IOCLR1

LPC2129 provides separate set and clear registers for Port 0 and Port 1.

Register Port Purpose
IOSET0 Port 0 Sets selected Port 0 output bits.
IOSET1 Port 1 Sets selected Port 1 output bits.
IOCLR0 Port 0 Clears selected Port 0 output bits.
IOCLR1 Port 1 Clears selected Port 1 output bits.
The register interfaces contain 32-bit fields, but only supported GPIO pins can be used as physical outputs. Check the device pinout and alternate-function table.

5. Setting a GPIO Output HIGH

To set a GPIO output HIGH, write a mask containing 1 at the required bit position to the appropriate IOSET register.

Example: Set P0.5 HIGH

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    // Set P0.5 HIGH
    IOSET0 = (1U << 5);

    while (1)
    {
    }
}

Explanation

  1. Select GPIO function using PINSEL0.
  2. Configure P0.5 as output using IODIR0.
  3. Write a 1 at bit 5 of IOSET0.
  4. The P0.5 output latch becomes HIGH.
Important: IOSET0 is a write-one-to-set register. Use direct assignment with the required mask rather than reading it and performing a read-modify-write operation.

6. Clearing a GPIO Output LOW

To set a GPIO output LOW, write a mask containing 1 at the required bit position to the appropriate IOCLR register.

Example: Set P0.5 LOW

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    // Set P0.5 LOW
    IOCLR0 = (1U << 5);

    while (1)
    {
    }
}

Explanation

  1. Select GPIO function for P0.5.
  2. Configure the pin as output.
  3. Write a 1 at bit 5 of IOCLR0.
  4. The P0.5 output latch becomes LOW.

7. Setting and Clearing Multiple GPIO Pins

A combined bit mask can be used to control multiple GPIO output pins in one write.

Set P0.5, P0.10, and P0.28 HIGH

IOSET0 = (1U << 5)  |
         (1U << 10) |
         (1U << 28);

Set P0.5 and P0.10 LOW

IOCLR0 = (1U << 5) |
         (1U << 10);

Only the selected output bits are affected. Other output latch states remain unchanged.

8. Complete Program: Toggle a GPIO Output

The following program alternates P0.5 between HIGH and LOW using a software delay. 

#include <LPC21xx.h>

void delay(void)
{
    volatile unsigned int i;

    for (i = 0; i < 500000; i++)
    {
    }
}

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    while (1)
    {
        // Set output HIGH
        IOSET0 = (1U << 5);

        delay();

        // Set output LOW
        IOCLR0 = (1U << 5);

        delay();
    }
}

Program explanation

  1. Configure P0.5 as GPIO.
  2. Configure P0.5 as output.
  3. Set the output latch HIGH.
  4. Execute the software delay loop.
  5. Clear the output latch LOW.
  6. Execute another delay.
  7. Repeat continuously.
The delay loop is compiler- and clock-dependent. It is not a precise timing method. The Keil simulator can demonstrate program execution and register writes, but it does not confirm physical LED blinking.

9. Difference Between IOSET and IOCLR

Feature IOSET IOCLR
Purpose Set output latch HIGH. Clear output latch LOW.
Write 0 No change. No change.
Write 1 Sets selected bit. Clears selected bit.
Example IOSET0 = (1U << 5); IOCLR0 = (1U << 5);

10. Difference Between IOSET, IOCLR, and IOPIN

Register Purpose
IOPIN Reads the current GPIO pin state.
IOSET Sets selected GPIO output latch bits HIGH.
IOCLR Clears selected GPIO output latch bits LOW.
IOPIN is used to read pin state. IOSET and IOCLR are used to control GPIO output latch states.

11. Applications of IOSET and IOCLR

  • LED control.
  • Digital output generation.
  • Relay-driver control signals.
  • Buzzer control.
  • Digital enable and reset signals.
  • GPIO-based embedded control systems.
External loads such as relays, motors, and high-current LEDs require suitable driver circuitry. Do not connect them directly to a microcontroller GPIO pin unless the electrical limits and interface requirements permit it.

12. Common Programming Mistakes

  1. Not configuring the pin as output: Configure IODIR before using IOSET or IOCLR for output control.
  2. Forgetting PINSEL: Select GPIO mode before using the pin as GPIO.
  3. Using the wrong port register: Use the register corresponding to the selected GPIO port.
  4. Writing zero to set or clear: The selected action occurs when a 1 is written to the corresponding bit.
  5. Using read-modify-write on IOSET/IOCLR: These registers have write-one action semantics; write the intended mask directly.
  6. Ignoring electrical limits: Use an appropriate external driver for loads that exceed GPIO capability.

Objective: Observe GPIO output-latch changes using IOSET0 and IOCLR0.

Procedure

  1. Open the LPC2129 project in Keil uVision.
  2. Open main.c.
  3. Enter the GPIO toggle program.
  4. Build the project.
  5. Start the simulator debugger if supported.
  6. Open the Watch window.
  7. Add PINSEL0, IODIR0, IOSET0, IOCLR0, and IOPIN0.
  8. Execute the program step by step.
  9. Observe the writes to IOSET0 and IOCLR0.
  10. Inspect the current GPIO state where supported by the simulator.

Expected software-level observations

IODIR0 bit 5 = 1

IOSET0 write = 0x00000020
IOCLR0 write = 0x00000020
IOSET0 and IOCLR0 are action registers. Depending on the debugger's peripheral display, a readback may not show the same value that was written. Inspect the GPIO output state through the supported register model rather than treating the action-register write value as a persistent output state.

14. Interview Questions and Answers

Q1. What is IOSET?

IOSET is the GPIO Output Set Register used to set selected output latch bits HIGH.

Q2. What is IOCLR?

IOCLR is the GPIO Output Clear Register used to clear selected output latch bits LOW.

Q3. What happens when 1 is written to IOSET?

The corresponding output latch bit is set HIGH.

Q4. What happens when 1 is written to IOCLR?

The corresponding output latch bit is cleared LOW.

Q5. What happens when 0 is written to IOSET or IOCLR?

The corresponding output latch bit remains unchanged.

Q6. How do you set P0.5 HIGH?

IOSET0 = (1U << 5);

Q7. How do you set P0.5 LOW?

IOCLR0 = (1U << 5);

Q8. Which register configures GPIO output direction?

IODIR configures the GPIO direction.

Q9. Can multiple pins be controlled in one write?

Yes. A combined bit mask can be written to IOSET or IOCLR.

Q10. Why are IOSET and IOCLR useful?

They allow selected output latch bits to be changed without overwriting unrelated GPIO output states.

17. Lesson Summary

  • IOSET sets selected GPIO output latch bits HIGH.
  • IOCLR clears selected GPIO output latch bits LOW.
  • IOSET0 and IOCLR0 control Port 0.
  • IOSET1 and IOCLR1 control Port 1.
  • Writing 1 performs the selected set or clear action.
  • Writing 0 leaves the corresponding output latch unchanged.
  • IODIR must configure a GPIO pin as output before output control.
  • PINSEL must select GPIO functionality.
  • Bit masks allow individual or multiple pin control.
