1. Introduction

A Light Emitting Diode (LED) is a semiconductor device that emits light when forward biased. LEDs are commonly used as visual indicators in embedded systems.

An LPC2129 microcontroller can control an LED through one of its GPIO output pins.

The microcontroller changes the GPIO output state using IOSET and IOCLR registers. The electrical connection determines whether a HIGH or LOW output turns the LED on.

Learning objectives:
  • Understand LED operation.
  • Identify LED anode and cathode.
  • Understand the need for a current-limiting resistor.
  • Understand active-HIGH and active-LOW LED connections.
  • Configure LPC2129 GPIO for LED control.
  • Write Embedded C programs for LED control.
  • Understand LED control in the Keil simulator.

2. What Is an LED?

LED stands for Light Emitting Diode. It is a two-terminal semiconductor device that converts electrical energy into light.

LED terminals

Terminal Description
Anode (+) Positive terminal of the LED.
Cathode (-) Negative terminal of the LED.
LED SYMBOL Light ↗ ↗ Anode (+) ----|>|---- Cathode (-)

The LED normally emits light when its anode is at a higher potential than its cathode and sufficient forward current flows.

The longer lead is commonly the anode and the shorter lead is commonly the cathode on a new through-hole LED. Always verify the component datasheet and package markings.

3. Why Is a Current-Limiting Resistor Required?

An LED has a relatively small forward voltage drop. If it is connected directly across a voltage source without suitable current control, excessive current may flow and damage it.

A series resistor limits the current flowing through the LED.

Resistor calculation

The resistor value can be estimated using:

R = (VS - VF) / IF

Where:

  • R: Series resistance in ohms.
  • VS: Supply voltage.
  • VF: LED forward voltage.
  • IF: Desired LED forward current.

Example calculation

Assume:

  • Supply voltage = 3.3 V
  • LED forward voltage = 2.0 V
  • Desired LED current = 5 mA

Therefore:

R = (3.3 - 2.0) / 0.005

R = 1.3 / 0.005

R = 260 ohms

A standard 270-ohm resistor is a reasonable nominal choice for this example, subject to the actual LED and GPIO electrical specifications.

Always check the LPC2129 datasheet for GPIO output voltage, source/sink current limits, and total port current. Do not assume every GPIO pin can safely supply the same current.

4. Active-HIGH LED Interfacing

In an active-HIGH connection, the LED turns ON when the GPIO output is HIGH.

Connection concept

LPC2129 GPIO Output | | Current-limiting Resistor | | Anode LED Cathode | GND GPIO HIGH = LED ON GPIO LOW = LED OFF

When the GPIO pin is HIGH, current flows from the GPIO output through the resistor and LED to ground.

GPIO State LED State
HIGH ON
LOW OFF

5. Active-LOW LED Interfacing

In an active-LOW connection, the LED turns ON when the GPIO output is LOW.

Connection concept

+3.3 V | Current-limiting Resistor | | Anode LED Cathode | | LPC2129 GPIO Output GPIO LOW = LED ON GPIO HIGH = LED OFF

When the GPIO pin is LOW, it sinks current through the LED and resistor to ground. The LED turns ON.

GPIO State LED State
HIGH OFF
LOW ON
The active-LOW circuit requires the GPIO pin to sink current. Verify the pin's electrical ratings and the external circuit before implementation.

6. LPC2129 GPIO Configuration for LED

Before controlling an LED, configure the selected microcontroller pin correctly.

Configuration sequence

  1. Select GPIO function using PINSEL.
  2. Configure the pin as output using IODIR.
  3. Use IOSET to drive the output HIGH.
  4. Use IOCLR to drive the output LOW.

Example: P0.5 as an LED output

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    // Turn active-HIGH LED ON
    IOSET0 = (1U << 5);

    while (1)
    {
    }
}

This program configures P0.5 as an output and sets its output latch HIGH.

The code demonstrates the GPIO control sequence. The physical LED connection must be designed separately and must match the active-HIGH or active-LOW configuration.

7. Program: Turn LED ON and OFF

This program alternates the output state of P0.5. 

#include <LPC21xx.h>

void delay(void)
{
    volatile unsigned int i;

    for (i = 0; i < 500000; i++)
    {
    }
}

int main(void)
{
    // Configure P0.5 as GPIO
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    while (1)
    {
        // LED ON for active-HIGH wiring
        IOSET0 = (1U << 5);

        delay();

        // LED OFF for active-HIGH wiring
        IOCLR0 = (1U << 5);

        delay();
    }
}

Expected logical output sequence

GPIO P0.5:

HIGH  ----------------
      LED ON

LOW   ----------------
      LED OFF

HIGH  ----------------
      LED ON

LOW   ----------------
      LED OFF
The software delay is not a calibrated time delay. Its duration depends on compiler settings, processor clock, and instruction execution. Use a hardware timer when accurate timing is required.

8. Program: Control Three LEDs

This example uses P0.5, P0.10, and P0.28 as separate LED control outputs. 

#include <LPC21xx.h>

void delay(void)
{
    volatile unsigned int i;

    for (i = 0; i < 500000; i++)
    {
    }
}

int main(void)
{
    unsigned int led_mask;

    // Configure selected pins as GPIO
    PINSEL0 &= ~((3U << 10) |
                 (3U << 20));

    PINSEL1 &= ~(3U << 24);

    // Create output mask
    led_mask = (1U << 5)  |
               (1U << 10) |
               (1U << 28);

    // Configure all three pins as outputs
    IODIR0 |= led_mask;

    while (1)
    {
        // Turn all three LEDs ON
        IOSET0 = led_mask;

        delay();

        // Turn all three LEDs OFF
        IOCLR0 = led_mask;

        delay();
    }
}
This example assumes the selected pins are available and configured for GPIO in the target device package. Confirm the pin multiplexing and package pinout in the LPC2129 documentation before physical implementation.

9. LED Interfacing Using an External Driver

A GPIO pin should not be expected to drive every external load directly. For higher-current loads, an external transistor or suitable driver IC can be used.

Transistor-driver concept

LPC2129 GPIO | Base Resistor | Transistor Base Transistor Collector | LED + Series Resistor | Supply Transistor Emitter | GND

The GPIO output controls the transistor. The transistor switches the LED current from the external supply.

  • Reduces the current demanded from the GPIO.
  • Allows suitable external supply arrangements.
  • Provides a switching interface for larger loads.
Select the transistor, base resistor, LED resistor, and supply based on the load current and component ratings. A common ground is generally required for a non-isolated transistor interface.

10. Common Applications of LEDs in Embedded Systems

  • Power supply status indication.
  • System operating status.
  • Communication activity indication.
  • Error and fault indication.
  • Battery charging status.
  • Sensor threshold indication.
  • Debugging and firmware testing.

11. Common Mistakes in LED Interfacing

  1. Incorrect LED polarity: The LED may not conduct if connected in reverse.
  2. No current-limiting resistor: Excessive current can damage the LED or GPIO.
  3. Incorrect PINSEL configuration: The pin may remain assigned to an alternate function.
  4. Incorrect IODIR configuration: The pin must be configured as an output.
  5. Incorrect active logic: Active-LOW and active-HIGH circuits respond differently.
  6. Exceeding GPIO electrical limits: Check the device datasheet and use a suitable driver when necessary.
  7. Assuming simulator output proves physical operation: Register-level simulation does not verify actual LED current or light output.

  1. Open the LPC2129 project in Keil uVision.

  3. Build the project.
  4. Start the simulator debugger if supported.

  6. Add PINSEL0, IODIR0, IOSET0, IOCLR0, and IOPIN0.
  7. Execute the program step by step.
  8. Observe the output-control register writes.
  9. Inspect the GPIO state where the simulator provides a suitable peripheral model.

13. Interview Questions and Answers

Q1. What is an LED?

An LED is a semiconductor diode that emits light when forward biased.

Q2. What are the two terminals of an LED?

Anode and cathode.

Q3. Why is a resistor connected in series with an LED?

It limits the current through the LED and protects the LED and interfacing circuit.

Q4. What is active-HIGH LED interfacing?

The LED turns ON when the GPIO output is HIGH.

Q5. What is active-LOW LED interfacing?

The LED turns ON when the GPIO output is LOW.

Q6. Which LPC2129 registers are used for LED control?

PINSEL, IODIR, IOSET, and IOCLR registers are used for pin selection, direction, and output control.

Q7. What is the purpose of a transistor driver?

It provides a suitable switching interface when the load current is too high for direct GPIO control.

Q8. How can an LED be toggled?

Alternately write the corresponding bit mask to IOSET and IOCLR with a suitable delay or timing mechanism.

Q9. Can the Keil simulator verify actual LED brightness?

No. It can demonstrate software execution and supported register behavior, not physical light output.

Q10. Why must GPIO current limits be checked?

To prevent excessive current from damaging the microcontroller or connected components.
