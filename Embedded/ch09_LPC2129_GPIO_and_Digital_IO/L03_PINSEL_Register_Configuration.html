1. Introduction

The IODIR register is used to configure the direction of a GPIO pin in the LPC2129 microcontroller.

A GPIO pin can generally operate in one of two directions:

  • Input: The microcontroller reads an external digital signal.
  • Output: The microcontroller drives a digital signal.

The LPC2129 provides two GPIO direction registers: IODIR0 and IODIR1.

Learning objectives:
  • Understand the purpose of IODIR.
  • Understand IODIR0 and IODIR1.
  • Configure a GPIO pin as input.
  • Configure a GPIO pin as output.
  • Use bitwise operations to modify direction bits.
  • Write Embedded C programs for GPIO direction control.
  • Inspect IODIR registers in Keil uVision.

2. What Is the IODIR Register?

IODIR stands for Input/Output Direction Register.

It determines whether each configured GPIO pin functions as an input or an output.

IODIR Bit Direction
0 Input
1 Output
IODIR Register Bit | +------+------+ | | v v Bit = 0 Bit = 1 | | v v INPUT OUTPUT | | v v Read External Drive Digital Signal Signal

3. IODIR0 and IODIR1

LPC2129 has two GPIO ports, Port 0 and Port 1. Each port has a corresponding direction register.

Register Associated Port Purpose
IODIR0 Port 0 Configures the direction of supported Port 0 GPIO pins.
IODIR1 Port 1 Configures the direction of supported Port 1 GPIO pins.

These are 32-bit register interfaces. However, not every bit necessarily corresponds to a physically available GPIO pin.

The actual GPIO availability and alternate functions depend on the LPC2129 package and pin configuration.

4. IODIR Register Organization

Each bit in an IODIR register controls the direction of its corresponding GPIO pin.

Example: IODIR0

IODIR0 (32 bits) Bit 31 ........................ Bit 0 | | v v P0.31 P0.0 0 = Input 1 = Output

For example: 

IODIR0 bit 5 = 0  -> P0.5 input
IODIR0 bit 5 = 1  -> P0.5 output

Example: IODIR1

IODIR1 (32 bits) Bit 31 ........................ Bit 0 | | v v P1.31 P1.0 0 = Input 1 = Output

The same direction-bit principle applies to IODIR1, subject to the actual Port 1 pins supported by the device.

5. Configuring a GPIO Pin as Output

To configure a GPIO pin as an output, set its corresponding IODIR bit to 1.

Example: Configure P0.5 as Output

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    while (1)
    {
    }
}

Explanation

  1. Include the LPC2129 device header.
  2. Select GPIO function for P0.5 using PINSEL0.
  3. Set bit 5 of IODIR0.
  4. P0.5 is now configured as an output.
The statement IODIR0 |= (1U << 5) sets bit 5 without changing the direction configuration of other pins.

6. Configuring a GPIO Pin as Input

To configure a GPIO pin as an input, clear its corresponding IODIR bit to 0.

Example: Configure P0.6 as Input

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.6
    PINSEL0 &= ~(3U << 12);

    // Configure P0.6 as input
    IODIR0 &= ~(1U << 6);

    while (1)
    {
    }
}

Explanation

  1. Select GPIO function for P0.6.
  2. Clear bit 6 of IODIR0.
  3. P0.6 is now configured as an input.
  4. The input signal can be read using the appropriate GPIO input register.
IODIR configures direction only. It does not read the input signal. Input reading is covered in the IOPIN register lesson.

7. Bitwise Operations for IODIR

Bitwise operations allow firmware to configure individual GPIO directions without affecting other pins.

Set a bit – Output configuration

IODIR0 |= (1U << 5);

Sets bit 5 to 1, configuring P0.5 as an output.

Clear a bit – Input configuration

IODIR0 &= ~(1U << 5);

Clears bit 5 to 0, configuring P0.5 as an input.

Set multiple pins as outputs

IODIR0 |= (1U << 5) |
           (1U << 10) |
           (1U << 28);

This configures P0.5, P0.10, and P0.28 as outputs, provided those pins are selected for GPIO.

Configure multiple pins as inputs

IODIR0 &= ~((1U << 6) |
            (1U << 7));

This configures P0.6 and P0.7 as inputs.

8. Complete Example: Multiple GPIO Directions

Configure P0.5 and P0.10 as outputs, and P0.6 as an input. 

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO for P0.5, P0.6 and P0.10
    PINSEL0 &= ~((3U << 10) |
                 (3U << 12) |
                 (3U << 20));

    // Configure P0.5 and P0.10 as outputs
    IODIR0 |= (1U << 5) |
              (1U << 10);

    // Configure P0.6 as input
    IODIR0 &= ~(1U << 6);

    while (1)
    {
        // Application logic
    }
}

Expected register-level configuration

Pin IODIR Bit Direction
P0.5 1 Output
P0.6 0 Input
P0.10 1 Output

9. Difference Between PINSEL and IODIR

Feature PINSEL IODIR
Full form Pin Select Input/Output Direction
Purpose Selects pin function. Selects GPIO direction.
Configuration GPIO or alternate function. Input or output.
Typical field width Two bits per pin in PINSEL0/PINSEL1. One bit per GPIO pin.
Example Configure P0.5 as GPIO. Configure P0.5 as output.
Remember: PINSEL determines what function the pin performs. IODIR determines whether a GPIO pin is an input or output.

10. Applications of IODIR

  • Configuring LED control pins as outputs.
  • Configuring push-button pins as inputs.
  • Reading digital sensor signals.
  • Driving digital control signals.
  • Configuring relay-driver control pins.
  • Building GPIO-based embedded applications.

11. Common Programming Mistakes

  1. Forgetting PINSEL configuration: A pin may still be assigned to an alternate peripheral function.
  2. Using the wrong register: Use IODIR0 for Port 0 and IODIR1 for Port 1.
  3. Using assignment instead of masking: Direct assignment can overwrite other pin-direction settings.
  4. Confusing direction and output value: IODIR configures direction; IOSET and IOCLR control output values.
  5. Assuming every port bit is available: Check the device pinout and package documentation.

13. Interview Questions and Answers

Q1. What is IODIR?

IODIR is the Input/Output Direction Register used to configure GPIO pins as inputs or outputs.

Q2. What does IODIR bit 0 represent?

It configures the corresponding GPIO pin as an input.

Q3. What does IODIR bit 1 represent?

It configures the corresponding GPIO pin as an output.

Q4. What is the difference between IODIR0 and IODIR1?

IODIR0 controls Port 0 direction, whereas IODIR1 controls Port 1 direction.

Q5. How do you configure P0.5 as output?

IODIR0 |= (1U << 5);

Q6. How do you configure P0.5 as input?

IODIR0 &= ~(1U << 5);

Q7. Does IODIR select alternate peripheral functions?

No. PINSEL is used for pin-function selection.

Q8. Which register is used to read a GPIO input?

IOPIN is used to read the GPIO input state.

Q9. Which registers control GPIO output values?

IOSET and IOCLR control GPIO output values.

Q10. Why should bit masking be used?

It changes the required direction bit while preserving other GPIO configurations.
