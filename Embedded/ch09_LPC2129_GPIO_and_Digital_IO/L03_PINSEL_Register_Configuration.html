1. Introduction

The LPC2129 microcontroller has multiplexed pins. This means that a physical pin can support more than one function.

The function assigned to a pin is selected through pin-select registers called PINSEL registers.

These registers allow a physical pin to operate as GPIO or as an alternate peripheral signal, such as UART, I2C, SPI, PWM, or another supported function.

Learning objectives:
  • Understand pin multiplexing.
  • Understand the purpose of PINSEL registers.
  • Identify PINSEL0, PINSEL1, and PINSEL2.
  • Understand two-bit pin-function selection.
  • Calculate PINSEL bit positions.
  • Configure GPIO functions using Embedded C.
  • Inspect PINSEL register values in Keil uVision.

2. What Is Pin Multiplexing?

Pin multiplexing is a technique in which one physical microcontroller pin can perform different functions.

Instead of dedicating a separate physical pin to every peripheral, the microcontroller allows selected pins to be assigned to different internal functions.

Example

Consider LPC2129 pin P0.0. Depending on its configuration, it can be used as a GPIO signal or as a UART0 transmit signal (TXD0).

Physical Pin P0.0 | PINSEL Configuration | +---------+---------+ | | v v GPIO Mode UART Mode | | v v Digital I/O TXD0

The selected function determines which internal signal is connected to the physical pin.

A pin assigned to an alternate peripheral function is not simultaneously available as an ordinary GPIO pin.

3. Purpose of PINSEL Registers

PINSEL registers control the function selection of multiplexed pins.

The processor writes configuration values into these memory-mapped registers to select the required pin function.

Main functions

  • Select GPIO functionality.
  • Select alternate peripheral functions.
  • Configure pin assignments for supported peripherals.
  • Allow different applications to use shared physical pins.

PINSEL configuration flow

Embedded C Program | v Select Required Pin | v Calculate PINSEL Bits | v Write PINSEL Register | v Physical Pin Function | +----------+----------+ | | v v GPIO Mode Peripheral Mode

4. PINSEL Registers in LPC2129

The LPC2129 provides three main pin-function selection registers:

Register Purpose
PINSEL0 Selects functions for supported Port 0 pins in its register range.
PINSEL1 Selects functions for supported Port 0 pins in its register range.
PINSEL2 Controls additional pin-function and special configuration options defined by the device.
PINSEL0 and PINSEL1 use two-bit fields for individual multiplexed Port 0 pins. PINSEL2 has a device-specific layout and should not be treated as an ordinary two-bit-per-pin register.

5. Two-Bit Function Selection

For pins controlled by PINSEL0 and PINSEL1, each pin is generally assigned a two-bit function-selection field.

The two bits represent four possible binary combinations.

Bit Value Function Selection
00 Function 0 – GPIO.
01 Function 1 – Alternate function.
10 Function 2 – Alternate function.
11 Function 3 – Alternate function.

The exact alternate function corresponding to each selection depends on the physical pin. Always consult the LPC2129 pin function table.

Two-bit field representation

Two Bits for One Pin Bit 1 Bit 0 | | v v +---+---+ | 0 | 0 | +---+---+ | v GPIO Mode

8. PINSEL2 Register

PINSEL2 is a special pin-function configuration register in the LPC2129.

It contains device-specific configuration fields. Its layout and meaning are different from the regular two-bit fields used in PINSEL0 and PINSEL1.

Before changing PINSEL2, check the LPC2129 User Manual for the exact register definition and the meaning of each implemented bit.

Do not calculate a PINSEL2 two-bit field using the same formula used for PINSEL0 and PINSEL1. PINSEL2 has a special device-specific configuration.

9. Calculating PINSEL Bit Positions

For Port 0 pins controlled by PINSEL0 or PINSEL1, each pin has a two-bit selection field.

For P0.5

P0.5 belongs to PINSEL0. Its selection field occupies bits 11:10.

Calculation: 

Starting bit position = 2 x pin number

For P0.5:

Starting bit = 2 x 5
             = 10

Selection field = bits 11:10

For P0.10

Starting bit position = 2 x 10
                      = 20

Selection field = bits 21:20

For P0.20

P0.20 belongs to PINSEL1. Its local pin number in PINSEL1 is 20 - 16 = 4. 

Local pin number = 4

Starting bit = 2 x 4
             = 8

Selection field = bits 9:8
General calculation:
  • P0.0 to P0.15 use PINSEL0.
  • P0.16 to P0.31 use PINSEL1.
  • For PINSEL0: field start = 2 × pin number.
  • For PINSEL1: field start = 2 × (pin number − 16).

10. Configuring a Pin as GPIO

To configure a multiplexed Port 0 pin for GPIO, its two-bit function selection field must be cleared to binary 00.

Example: Configure P0.5 as GPIO

#include <LPC21xx.h>

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= (1U << 5);

    // Set P0.5 output
    IOSET0 = (1U << 5);

    while (1)
    {
    }
}

Explanation

  1. Include the LPC21xx device header.
  2. Clear bits 11:10 in PINSEL0.
  3. Configure bit 5 of IODIR0 as output.
  4. Set bit 5 through IOSET0.
  5. Keep the program running.

The expression 3U represents binary 11. Shifting it left by 10 positions creates a mask for bits 11:10. 

3U << 10

Binary mask:
00000000 00000000 00001100 00000000
This example is a register-level GPIO configuration demonstration. Verify P0.5's pin function and package availability before applying it to a physical circuit.

11. Configuring an Alternate Function

A PINSEL field can also be configured to select a peripheral function.

For example, P0.0 can be assigned to the UART0 transmit function TXD0 using the function selection defined in the LPC2129 pin table.

Example: Select TXD0 on P0.0

#include <LPC21xx.h>

int main(void)
{
    // P0.0 function field is PINSEL0[1:0].
    // Select function 01 for TXD0.
    PINSEL0 = (PINSEL0 & ~3U) | 1U;

    while (1)
    {
    }
}

This operation changes only the two function-selection bits for P0.0 and preserves the other PINSEL0 fields.

After selecting TXD0, the pin is assigned to the UART peripheral. UART configuration must also be completed before serial transmission.

12. Bit Masking Techniques

Bit masking allows firmware to modify a particular PINSEL field without overwriting unrelated pin configurations.

Clear a two-bit field

PINSEL0 &= ~(3U << 10);

Select function 01

PINSEL0 =
    (PINSEL0 & ~(3U << 10))
    | (1U << 10);

Select function 10

PINSEL0 =
    (PINSEL0 & ~(3U << 10))
    | (2U << 10);

Select function 11

PINSEL0 =
    (PINSEL0 & ~(3U << 10))
    | (3U << 10);

The binary selection values are generic. The actual alternate function associated with each value depends on the selected pin.

13. Important Precautions

  • Identify the correct physical pin before changing PINSEL.
  • Use the correct PINSEL register.
  • Calculate the correct two-bit field.
  • Preserve unrelated register fields using bit masking.
  • Check the alternate function table in the device manual.
  • Configure GPIO direction after selecting GPIO mode.
  • Do not assume PINSEL2 follows the PINSEL0/PINSEL1 layout.
  • Check whether the selected pin is available in the package.

15. Interview Questions and Answers

Q1. What is a PINSEL register?

A PINSEL register selects the function assigned to a multiplexed microcontroller pin.

Q2. What is pin multiplexing?

It allows one physical pin to support different selectable functions.

Q3. How many main PINSEL registers are provided by LPC2129?

Three: PINSEL0, PINSEL1, and PINSEL2.

Q4. How many bits are used for each pin in PINSEL0 and PINSEL1?

Two bits per pin.

Q5. What does function selection 00 represent?

It selects the GPIO function for pins controlled by the normal PINSEL0/PINSEL1 two-bit fields.

Q6. Which PINSEL register controls P0.5?

PINSEL0, using bits 11:10.

Q7. Which PINSEL register controls P0.20?

PINSEL1, using bits 9:8.

Q8. Why is bit masking used?

It allows a particular field to be changed without unnecessarily modifying other register fields.

Q9. Does PINSEL configure GPIO direction?

No. PINSEL selects the pin function. IODIR configures GPIO direction.

Q10. Does selecting TXD0 make UART transmission automatically work?

No. UART registers, baud rate, and other required settings must also be configured.
