1. Introduction

The IOPIN register is used to access the current logic state of GPIO pins in the LPC2129 microcontroller.

It allows an embedded C program to read digital input signals from external devices such as push buttons, switches, and digital sensors.

The IOPIN register can also be used to read the current GPIO pin state when the pin is configured as an output.

Learning objectives:
  • Understand the purpose of IOPIN.
  • Understand IOPIN0 and IOPIN1.
  • Read individual GPIO pin states.
  • Understand logic HIGH and logic LOW.
  • Use bitwise operators to test input pins.
  • Write switch-reading programs.
  • Inspect GPIO input values in Keil uVision.

2. What Is the IOPIN Register?

IOPIN stands for Input/Output Pin Register.

It provides access to the current logic state of the GPIO pins. Each implemented GPIO bit corresponds to a particular physical pin.

Logic State Meaning
0 Logic LOW
1 Logic HIGH
External Digital Signal | v Physical GPIO Pin | v IOPIN Register | v Embedded C Program | v Read Logic State

3. IOPIN0 and IOPIN1

LPC2129 provides GPIO input registers for Port 0 and Port 1.

Register Associated Port Purpose
IOPIN0 Port 0 Reads the current GPIO pin states of Port 0.
IOPIN1 Port 1 Reads the current GPIO pin states of Port 1.

These registers have 32-bit interfaces. Not all bit positions necessarily correspond to physically available GPIO pins.

The pin must be configured for GPIO through the appropriate PINSEL settings before using it as a GPIO input.

4. IOPIN Register Organization

Each bit in IOPIN represents the logic state of its corresponding GPIO pin.

IOPIN0

IOPIN0 (32-bit register) Bit 31 ........................ Bit 0 | | v v P0.31 P0.0 0 = LOW 1 = HIGH

IOPIN1

IOPIN1 (32-bit register) Bit 31 ........................ Bit 0 | | v v P1.31 P1.0 0 = LOW 1 = HIGH

5. Reading an Individual GPIO Pin

To read an individual pin, use a bitwise AND operation with a mask containing a 1 at the required bit position.

Example: Read P0.6

unsigned int pin_status;

pin_status = IOPIN0 & (1U << 6);

The expression creates a mask for bit 6 and checks the corresponding IOPIN0 bit.

IOPIN0 Bit 6 Result Meaning
0 0 P0.6 is LOW.
1 64 P0.6 is HIGH.
The expression returns either zero or the mask value. It does not necessarily return the normalized values 0 and 1.

6. Checking Whether a Pin Is HIGH or LOW

An if statement can be used to test the result of a bitwise AND operation.

Example

#include <LPC21xx.h>

int main(void)
{
    unsigned int pin_status;

    // Select GPIO function for P0.6
    PINSEL0 &= ~(3U << 12);

    // Configure P0.6 as input
    IODIR0 &= ~(1U << 6);

    while (1)
    {
        pin_status = IOPIN0 & (1U << 6);

        if (pin_status != 0)
        {
            // P0.6 is HIGH
        }
        else
        {
            // P0.6 is LOW
        }
    }
}

Program explanation

  1. Configure P0.6 for GPIO operation.
  2. Configure P0.6 as an input using IODIR0.
  3. Read the pin using IOPIN0.
  4. Apply a bit mask to isolate bit 6.
  5. Use an if-else statement to identify the logic state.

7. Reading Multiple GPIO Pins

Multiple GPIO input pins can be checked using a combined bit mask.

Example: Read P0.6 and P0.7

#include <LPC21xx.h>

int main(void)
{
    unsigned int input_status;

    // Select GPIO for P0.6 and P0.7
    PINSEL0 &= ~((3U << 12) |
                 (3U << 14));

    // Configure both pins as inputs
    IODIR0 &= ~((1U << 6) |
                (1U << 7));

    while (1)
    {
        input_status =
            IOPIN0 & ((1U << 6) |
                      (1U << 7));

        if (input_status == 0)
        {
            // Both inputs are LOW
        }
    }
}

This example checks whether both selected input bits are LOW. Other combinations can be tested by comparing the masked result with the corresponding mask values.

8. Push Button Input Example

A push button is a common digital input device used in embedded systems.

When a button is pressed, the input pin changes its logic state according to the circuit's pull-up or pull-down arrangement.

Push Button Circuit Concept Supply / GND | | Push Button | +---------- P0.6 | Input Configuration | IOPIN0 | Read HIGH or LOW

Example: Detect a HIGH input

#include <LPC21xx.h>

int main(void)
{
    unsigned int button;

    // Configure P0.6 as GPIO
    PINSEL0 &= ~(3U << 12);

    // Configure P0.6 as input
    IODIR0 &= ~(1U << 6);

    while (1)
    {
        button = IOPIN0 & (1U << 6);

        if (button != 0)
        {
            // Input is HIGH
        }
        else
        {
            // Input is LOW
        }
    }
}
The meaning of pressed and released depends on the actual circuit. An active-low button produces LOW when pressed, while an active-high arrangement produces HIGH when pressed. A suitable pull-up or pull-down arrangement is required to avoid a floating input.

9. Reading and Storing GPIO Input Values

The value read from IOPIN can be stored in a variable for later processing.

Example

#include <LPC21xx.h>

int main(void)
{
    unsigned int gpio_value;

    // Configure P0.6 as GPIO input
    PINSEL0 &= ~(3U << 12);
    IODIR0 &= ~(1U << 6);

    while (1)
    {
        gpio_value = (IOPIN0 >> 6) & 1U;

        // gpio_value is now 0 or 1
    }
}

Right-shifting the register value by six positions moves the selected pin bit to bit 0. The AND operation with 1U isolates that bit.

Input State gpio_value
LOW 0
HIGH 1

10. Difference Between IODIR and IOPIN

Feature IODIR IOPIN
Purpose Configures GPIO direction. Accesses current GPIO pin state.
Bit value 0 Input configuration. LOW logic state.
Bit value 1 Output configuration. HIGH logic state.
Usage Direction setup. Input reading and pin-state inspection.
IODIR determines the direction of a GPIO pin. IOPIN provides access to its current logic state.

11. Applications of IOPIN

  • Reading push-button states.
  • Reading digital switch inputs.
  • Monitoring digital sensors.
  • Checking external control signals.
  • Implementing user-input systems.
  • Developing GPIO-based control applications.

12. Common Programming Mistakes

  1. Incorrect PINSEL configuration: A pin assigned to an alternate function may not operate as GPIO.
  2. Incorrect IODIR configuration: Configure the pin as input before using it as an input.
  3. Reading the wrong port: Use IOPIN0 for Port 0 and IOPIN1 for Port 1.
  4. Incorrect bit mask: Make sure the mask corresponds to the required pin number.
  5. Ignoring active-low logic: A LOW signal may represent a pressed button.
  6. Floating input: Use a suitable pull-up or pull-down arrangement in the actual circuit.
  7. Assuming simulator input behavior: Register inspection does not establish the behavior of a physical switch circuit.

14. Interview Questions and Answers

Q1. What is IOPIN?

IOPIN is the Input/Output Pin Register used to access the current logic state of GPIO pins.

Q2. What is the purpose of IOPIN0?

It provides access to the GPIO pin states of Port 0.

Q3. What is the purpose of IOPIN1?

It provides access to the GPIO pin states of Port 1.

Q4. What does a HIGH input represent?

A HIGH input is represented by logic value 1.

Q5. What does a LOW input represent?

A LOW input is represented by logic value 0.

Q6. How do you read P0.6?

unsigned int value;
value = IOPIN0 & (1U << 6);

Q7. How do you obtain a normalized 0 or 1?

value = (IOPIN0 >> 6) & 1U;

Q8. Which register configures input direction?

IODIR is used to configure the GPIO pin as an input.

Q9. What is an active-low switch?

It is a switch arrangement in which the input becomes LOW when the switch is activated.

Q10. Why should floating inputs be avoided?

A floating input can assume an unpredictable logic state. Suitable pull-up or pull-down circuitry provides a defined default state.
