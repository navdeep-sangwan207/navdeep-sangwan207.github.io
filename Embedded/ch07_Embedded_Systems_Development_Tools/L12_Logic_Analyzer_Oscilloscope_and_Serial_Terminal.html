1. Introduction

Embedded systems contain processors, memory, sensors, communication interfaces, and electronic circuits. During development, engineers must inspect signals, measure electrical behavior, and monitor communication between devices.

Three commonly used debugging and measurement tools are:

  • Logic Analyzer
  • Oscilloscope
  • Serial Terminal

These tools help engineers identify hardware and firmware problems that may not be visible by examining source code alone.

  • Explore practical debugging scenarios for LPC2129.

2. What Is a Logic Analyzer?

A logic analyzer is an electronic measurement tool used to capture and analyze digital signals over time.

It observes whether a digital signal represents logic LOW or logic HIGH and displays transitions between these states.

Applications

  • Debugging GPIO signals.
  • Analyzing UART communication.
  • Monitoring SPI communication.
  • Inspecting I2C transactions.
  • Checking digital control signals.
  • Analyzing timing relationships between multiple signals.

Basic logic analyzer architecture

Digital Signal Inputs CH0 CH1 CH2 CH3 | | | | +----+----+----+ | v Input Conditioning | v Sampling Circuit | v Memory Buffer | v Analysis Software | v Digital Waveforms

Important features

  • Multiple digital input channels.
  • Adjustable sampling rate.
  • Trigger configuration.
  • Signal timing analysis.
  • Protocol decoding in supported tools.
  • Captured data storage and export.

3. Digital Logic Levels

A logic analyzer interprets input voltages according to its configured or specified digital input thresholds.

Logic LOW

A voltage below the applicable LOW threshold is interpreted as logic 0.

Logic HIGH

A voltage above the applicable HIGH threshold is interpreted as logic 1.

Actual logic thresholds depend on the target device and analyzer specifications. A logic analyzer does not measure an exact analog voltage waveform.

Example digital signal

HIGH ──────┐ ┌──────────┐ | | | | | | LOW └───────┘ └────── Time ------------------------>

The analyzer records the transition between LOW and HIGH and the time at which each transition occurs.

4. Sampling Rate and Timing Resolution

A logic analyzer samples digital input signals at a specified rate.

The sampling rate indicates how many samples are captured per second.

Sampling rate units

Unit Meaning
Hz Samples per second
kHz Thousand samples per second
MHz Million samples per second
GS/s Billion samples per second

Sampling interval

The time interval between consecutive samples is:

Sampling interval:

Ts = 1 / Fs

Where:

  • Ts = Sampling interval in seconds.
  • Fs = Sampling frequency in samples per second.

Example

If a logic analyzer samples at 10 MHz:

Ts = 1 / 10,000,000 = 100 ns

The analyzer takes one sample every 100 nanoseconds.

A higher sampling rate provides finer timing resolution, but it does not guarantee that every signal transition will be captured. Signal bandwidth, input characteristics, capture depth, and sampling method also matter.

5. Triggering in a Logic Analyzer

A trigger is a condition that determines when the logic analyzer starts or identifies a capture.

Common trigger types

  • Rising-edge trigger.
  • Falling-edge trigger.
  • High-level trigger.
  • Low-level trigger.
  • Pattern trigger.
  • Protocol-based trigger.

Rising-edge trigger

A rising edge occurs when a digital signal changes from logic LOW to logic HIGH.

HIGH ┌────────────── | | LOW ──────┘ Rising Edge

Falling-edge trigger

A falling edge occurs when a signal changes from logic HIGH to logic LOW.

HIGH ──────┐ | | LOW └────────────── Falling Edge

Pattern trigger

A pattern trigger activates when selected channels match a specified combination of logic states.

Example: CH0 = HIGH, CH1 = LOW, CH2 = HIGH.

6. Protocol Decoding with a Logic Analyzer

Many logic analyzers can decode communication protocols from captured digital signals.

UART decoding

A UART decoder interprets serial data using the configured baud rate, data bits, parity, and stop bits.

SPI decoding

An SPI decoder interprets clock, data, and chip-select signals according to the selected SPI mode and bit-order configuration.

I2C decoding

An I2C decoder identifies START and STOP conditions, addresses, data bytes, and acknowledgment bits.

Protocol Typical signals Useful analysis
UART TX, RX Start bit, data, parity, stop bit
SPI SCLK, MOSI, MISO, CS Clocked data transfer
I2C SCL, SDA Address, data, ACK/NACK
Protocol decoding depends on correct signal connections, voltage compatibility, sampling rate, and decoder settings.

7. What Is an Oscilloscope?

An oscilloscope is an electronic instrument used to observe and measure electrical signals as a function of time.

It displays voltage waveforms and helps engineers examine signal shape, amplitude, timing, and noise.

Applications

  • Measuring voltage levels.
  • Measuring signal frequency and period.
  • Observing PWM waveforms.
  • Checking clock signals.
  • Measuring rise and fall times.
  • Investigating noise and signal distortion.
  • Debugging power supply circuits.
  • Inspecting analog sensor signals.

Basic oscilloscope architecture

Electrical Signal | v Probe Input | v Input Attenuator | v Vertical System | v ADC / Sampling | v Acquisition Memory | v Display Processing | v Waveform Display

8. Important Oscilloscope Controls

8.1 Vertical scale

Vertical scale controls how much voltage is represented by each vertical division.

It is commonly expressed in volts per division (V/div).

8.2 Horizontal scale

Horizontal scale controls the time represented by each horizontal division.

It is commonly expressed in seconds per division (s/div), milliseconds per division (ms/div), or microseconds per division (µs/div).

8.3 Trigger control

Trigger controls stabilize the displayed waveform by selecting a condition at which acquisition is synchronized.

8.4 Probe attenuation

Oscilloscope probes may provide attenuation such as 1x or 10x. The probe setting and oscilloscope configuration must match to display correct voltage values.

Control Purpose
Volts/div Adjusts vertical voltage scale.
Time/div Adjusts horizontal time scale.
Trigger level Sets the voltage threshold for triggering.
Coupling Selects AC, DC, or ground-reference display modes where supported.
Probe factor Sets the probe attenuation factor.

9. Understanding Waveforms

A waveform represents how an electrical quantity, usually voltage, changes over time.

9.1 DC waveform

A constant DC voltage appears as a horizontal line on an oscilloscope display.

Voltage | 5V | ───────────────────────── | 0V +----------------------------> Time

9.2 Square waveform

A square wave alternates between two voltage levels. It is commonly found in digital systems and clock signals.

Voltage | HIGH | ┌──────┐ ┌──────┐ | | | | | LOW | ┘ └──────┘ └──── | +----------------------------> Time

9.3 Sine waveform

A sine wave is a periodic analog waveform commonly found in AC signals and oscillator circuits.

9.4 PWM waveform

Pulse Width Modulation is a technique in which the width of pulses is varied to control the average power delivered to a load.

HIGH | ┌────┐ ┌────┐ | | | | | LOW | ┘ └──────────┘ └──── | +----------------------------> Time Shorter ON duration

10. Important Waveform Measurements

10.1 Amplitude

Amplitude is the magnitude of a signal measured relative to a reference level.

10.2 Peak-to-peak voltage

Peak-to-peak voltage is the difference between the maximum and minimum waveform voltages.

Vpp = Vmax − Vmin

10.3 Time period

The time period is the duration of one complete waveform cycle.

10.4 Frequency

f = 1 / T

Where:

  • f = Frequency in hertz.
  • T = Time period in seconds.

Example

If the time period of a waveform is 2 ms:

T = 0.002 seconds

f = 1 / 0.002 = 500 Hz

10.5 Duty cycle

Duty cycle represents the percentage of one period for which a periodic signal remains in its active state.

Duty Cycle = (TON / T) × 100%

Where:

  • TON = ON time.
  • T = Total period.

Example

If a PWM signal has:

  • ON time = 4 ms
  • Total period = 10 ms

Duty Cycle = (4 / 10) × 100 = 40%

Oscilloscopes can measure voltage and timing characteristics directly. They are particularly useful when the actual electrical waveform matters.

11. Oscilloscope Triggering

Triggering synchronizes waveform acquisition so that a repeating signal appears stable on the display.

Edge trigger

Edge triggering starts acquisition when a signal crosses a selected voltage level in a specified direction.

  • Rising-edge trigger.
  • Falling-edge trigger.

Pulse-width trigger

Pulse-width triggering identifies pulses based on their duration.

Video trigger

Video triggering is used for supported video signal formats.

Trigger level

The trigger level is the voltage threshold at which the trigger condition is evaluated.

13. What Is a Serial Terminal?

A serial terminal is a software application used to send and receive data through a serial communication interface.

It is widely used to monitor UART communication between a microcontroller and a computer.

Common serial terminal applications

  • Displaying debug messages.
  • Sending commands to a microcontroller.
  • Monitoring sensor data.
  • Testing UART communication.
  • Inspecting device startup messages.
  • Debugging communication problems.

Serial terminal architecture

Microcontroller | | UART TX / RX | v USB-to-UART Interface | | USB | v Computer | v Serial Terminal | v Displayed Messages

A USB-to-UART adapter provides the serial interface between a computer's USB port and the target device.

14. UART Communication Parameters

The serial terminal and target microcontroller must use compatible communication settings.

14.1 Baud rate

Baud rate represents the number of signal symbols transmitted per second. In common binary UART communication, one symbol represents one bit, so the baud rate numerically equals the bit rate.

Common settings include:

  • 9600 baud
  • 19200 baud
  • 38400 baud
  • 57600 baud
  • 115200 baud

14.2 Data bits

The number of data bits transmitted in each UART frame. Eight data bits is a common setting.

14.3 Parity

Parity is an optional error-detection bit.

  • None
  • Even
  • Odd

14.4 Stop bits

Stop bits indicate the end of a UART frame. One stop bit is a common setting.

Typical UART configuration

Parameter Example setting
Baud rate 9600
Data bits 8
Parity None
Stop bits 1
Flow control None

This configuration is commonly written as 9600 8N1.

15. UART Data Frame

UART communication generally uses an asynchronous frame format.

Typical 8N1 frame

Idle Start Data Bits Stop 1 0 D0 D1 D2 D3 1 D4 D5 D6 D7

A typical UART frame contains:

  1. Idle state.
  2. Start bit.
  3. Data bits.
  4. Optional parity bit.
  5. Stop bit or bits.
UART is asynchronous: the transmitter and receiver do not share a separate clock signal. They must use compatible baud-rate and frame settings.

16. Common Serial Terminal Software

Several applications can be used to monitor and interact with serial devices.

Software Purpose
PuTTY Serial terminal and remote connection utility.
Tera Term Serial communication and terminal monitoring.
RealTerm Serial communication and binary data inspection.
Arduino Serial Monitor Serial communication monitoring for supported Arduino workflows.
CoolTerm Serial port communication and logging.

Typical serial terminal setup

  1. Connect the target UART to a compatible USB-to-UART interface.
  2. Identify the assigned serial port on the computer.
  3. Open serial terminal software.
  4. Select the correct COM port.
  5. Configure baud rate.
  6. Configure data bits, parity, and stop bits.
  7. Open the serial connection.
  8. Observe received data or transmit test commands.
On Windows, the connected USB-to-UART adapter commonly appears as a COM port in Device Manager. The exact port number depends on the computer and adapter.

18. Practical Exercise: UART Debug Message

Objective

Understand how an embedded application can send a debugging message through UART0.

Example LPC2129 code

#include <LPC21xx.h>

#define PCLK 15000000UL
#define BAUD 9600UL

void UART0_Init(void)
{
    PINSEL0 &= ~(0x0FUL);
    PINSEL0 |=  (0x05UL);

    U0LCR = 0x83;

    U0DLL = PCLK / (16UL * BAUD);
    U0DLM = 0;

    U0LCR = 0x03;
}

void UART0_TxChar(char ch)
{
    while (!(U0LSR & 0x20))
    {
    }

    U0THR = ch;
}

void UART0_TxString(const char *str)
{
    while (*str)
    {
        UART0_TxChar(*str++);
    }
}

int main(void)
{
    UART0_Init();

    UART0_TxString("LPC2129 UART0 Ready\r\n");

    while (1)
    {
    }
}

Code explanation

  • PINSEL0 selects the UART0 alternate functions on P0.0 and P0.1.
  • U0LCR configures the UART line format and divisor-latch access.
  • U0DLL and U0DLM hold the baud-rate divisor.
  • U0LSR indicates UART line status.
  • U0THR holds the transmit data.
Clock assumption: This example uses PCLK = 15 MHz and a divisor of 97 for approximately 9665 baud, rather than exactly 9600 baud. The actual baud rate should be calculated from the selected peripheral clock and divisor. For precise configuration, select a suitable divisor and fractional divider settings where applicable.

Expected result

When executed on a correctly configured LPC2129 target with a compatible serial connection, the terminal should receive: 

LPC2129 UART0 Ready

In the Keil uVision simulator, you can build and debug the program and inspect UART registers. Actual serial-terminal output requires a physical target and a supported serial interface or a separately configured peripheral simulation.

19. Logic Analyzer vs Oscilloscope vs Serial Terminal

Feature Logic Analyzer Oscilloscope Serial Terminal
Primary purpose Digital signal analysis Electrical waveform measurement Serial data communication
Input information Digital logic states Voltage over time Decoded or raw serial data
Voltage measurement Not its primary function Yes No
Protocol analysis Often supported Available on some models Serial stream monitoring
Typical use UART, SPI, I2C timing Clock, PWM, analog signals UART debugging

Which tool should be used?

  • Use a logic analyzer to inspect digital communication timing and multiple digital signals.
  • Use an oscilloscope to measure voltage levels, noise, rise time, and waveform shape.
  • Use a serial terminal to view or transmit serial communication data.

20. Practical Embedded System Debugging Scenarios

Scenario 1: UART communication is not working

Possible causes:

  • Incorrect baud rate.
  • Incorrect TX/RX connection.
  • Wrong UART pin configuration.
  • Incorrect voltage levels.
  • Incorrect parity or stop-bit settings.

Recommended tools:

  • Serial terminal.
  • Logic analyzer.
  • Oscilloscope.

Scenario 2: PWM output is incorrect

Possible causes:

  • Incorrect PWM period.
  • Incorrect duty-cycle configuration.
  • Wrong peripheral clock.
  • Incorrect pin multiplexing.

Recommended tool: Oscilloscope.

Scenario 3: I2C communication fails

Possible causes:

  • Incorrect slave address.
  • Missing pull-up resistors.
  • Incorrect bus timing.
  • Missing ACK response.

Recommended tool: Logic analyzer with I2C decoding.

Scenario 4: Analog sensor reading is unstable

Possible causes:

  • Electrical noise.
  • Unstable power supply.
  • Poor grounding.
  • Incorrect signal conditioning.

Recommended tool: Oscilloscope.

21. Measurement and Electrical Safety

  • Check the voltage rating of the instrument and probe.
  • Use probes compatible with the signal being measured.
  • Confirm the ground connection before measurement.
  • Avoid shorting adjacent pins with probe tips.
  • Use appropriate grounding and isolation techniques.
  • Never connect a grounded oscilloscope probe to a hazardous potential without understanding the measurement setup.
  • Ensure the logic analyzer input voltage is compatible with the target logic levels.
  • Do not connect RS-232 voltage levels directly to a microcontroller UART pin.
Standard bench oscilloscopes commonly have probe ground clips connected to protective earth. Incorrect grounding can create a short circuit. Use suitable differential probes or isolated measurement equipment where required.

22. Interview Questions and Answers

Q1. What is a logic analyzer?

A logic analyzer captures and analyzes digital signals over time.

Q2. What is an oscilloscope?

An oscilloscope displays electrical signals as voltage versus time.

Q3. What is the main difference between a logic analyzer and an oscilloscope?

A logic analyzer focuses on digital logic states and timing, whereas an oscilloscope measures electrical waveforms.

Q4. What is sampling rate?

It is the number of samples acquired per second.

Q5. What is a trigger?

A trigger is a condition used to synchronize or initiate signal capture.

Q6. What is an edge trigger?

It triggers on a rising or falling transition of a signal.

Q7. What is bandwidth in an oscilloscope?

Bandwidth describes the frequency range over which the oscilloscope can measure signals within its specified response limits.

Q8. What is time/div?

It is the horizontal time scale per division on an oscilloscope.

Q9. What is duty cycle?

It is the percentage of one period during which a periodic signal is active.

Q10. What is a serial terminal?

It is software used to send and receive serial data through an interface such as UART.

Q11. What does 9600 8N1 mean?

It means 9600 baud, 8 data bits, no parity, and 1 stop bit.

Q12. Why is a USB-to-UART converter used?

It provides an interface between a computer's USB port and a device's UART signals.

Q13. What is UART protocol decoding?

It is the process of interpreting captured UART signal transitions as serial data frames.

Q14. Which tool is best for checking PWM duty cycle?

An oscilloscope is commonly used to inspect PWM waveforms and measure duty cycle.

Q15. Which tool is useful for debugging I2C communication?

A logic analyzer with I2C protocol decoding is commonly used.

Q16. Why must UART baud rates match?

The receiver uses the configured baud rate to determine the timing of received bits.

Q17. What is probe attenuation?

It is the reduction factor provided by a probe, such as 10x, which must be correctly configured on the oscilloscope.

Q18. Can a serial terminal measure the electrical waveform?

No. It displays received serial data, not the analog voltage waveform.
