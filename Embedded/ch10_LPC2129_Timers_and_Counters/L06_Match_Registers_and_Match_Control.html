1. Introduction

The LPC2129 Timer 0 and Timer 1 peripherals contain match registers that allow the timer counter to detect a programmed count value. When the timer counter reaches a match value, the match logic generates an event.

The Match Control Register (MCR) determines what happens when a match occurs. Depending on the configuration, the timer can generate an interrupt, reset its counter, or stop.

Learning objectives:
  • Understand match registers MR0–MR3.
  • Identify Timer 0 and Timer 1 match registers.
  • Understand the Match Control Register.
  • Configure interrupt, reset, and stop actions.
  • Understand periodic match operation.
  • Write basic match-based timer programs.

2. What Is a Match Register?

A match register stores a 32-bit value that is continuously compared with the timer counter. When the timer counter equals the programmed match value, a match event occurs.

Each LPC2129 timer provides four match registers:

Timer 0Timer 1
T0MR0T1MR0
T0MR1T1MR1
T0MR2T1MR2
T0MR3T1MR3

The four match channels can be configured independently through the corresponding Match Control Register.

3. Match Event Architecture

Peripheral Clock | v Prescaler PR/PC | v Timer Counter TC | v +--------------------+ | Match Comparator | | | | TC == MR0 ? | | TC == MR1 ? | | TC == MR2 ? | | TC == MR3 ? | +--------------------+ | v Match Control MCR | +--------+--------+ | | | v v v Interrupt Reset Stop

The match comparator checks the timer counter against the programmed match values. When equality is detected, the corresponding match event is processed according to MCR.

4. Configuring Match Registers

Match registers are configured by writing the desired comparison value. 

// Configure Timer 0 match registers
T0MR0 = 999;
T0MR1 = 1999;
T0MR2 = 2999;
T0MR3 = 3999;

// Configure Timer 1 match registers
T1MR0 = 999;
T1MR1 = 1999;

For example, when T0TC equals T0MR0, a Timer 0 match 0 event is generated.

Writing a value into MR does not by itself select an interrupt, reset, or stop action. Those actions must be configured in MCR.

5. Match Control Register (MCR)

MCR controls the actions performed when a match occurs.

RegisterDescription
T0MCRMatch Control Register for Timer 0
T1MCRMatch Control Register for Timer 1

Three control bits are associated with each match channel:

Match Channel Interrupt Reset Stop
MR0Bit 0Bit 1Bit 2
MR1Bit 3Bit 4Bit 5
MR2Bit 6Bit 7Bit 8
MR3Bit 9Bit 10Bit 11

A control bit set to 1 enables its associated action on the corresponding match event.

6. Interrupt on Match

An interrupt can be generated when TC equals a match register value.

For Timer 0 Match 0, set bit 0 of T0MCR. 

// Configure MR0
T0MR0 = 999;

// Enable interrupt on MR0 match
T0MCR = (1U << 0);

When the match occurs, the corresponding interrupt flag is set in T0IR. The timer interrupt must also be enabled through the interrupt controller and CPU interrupt configuration before an ISR can execute.

MCR enables the timer's match interrupt request. It does not, by itself, enable the interrupt at the VIC or CPU level.

7. Reset on Match

The timer can automatically reset its counter when a match event occurs.

For Timer 0 Match 0, set bit 1 of T0MCR. 

// Configure MR0
T0MR0 = 999;

// Enable reset on MR0 match
T0MCR = (1U << 1);

When TC matches MR0, the timer counter is reset to zero. This can be used to create repeated counting periods.

8. Stop on Match

A timer can be configured to stop when a match event occurs.

For Timer 0 Match 0, set bit 2 of T0MCR. 

// Configure MR0
T0MR0 = 999;

// Enable stop on MR0 match
T0MCR = (1U << 2);

When the match occurs, the timer stops counting. The counter can be restarted through the timer control register.

9. Combining Match Actions

Multiple actions can be enabled for the same match channel.

Example: generate an interrupt and reset TC on MR0 match. 

// Enable interrupt and reset on MR0
T0MCR = (1U << 0) | (1U << 1);

Example: generate an interrupt and stop the timer on MR0 match. 

// Enable interrupt and stop on MR0
T0MCR = (1U << 0) | (1U << 2);
Reset and stop are different actions. Avoid enabling both for the same match unless the device documentation explicitly describes the intended behavior. For normal periodic operation, interrupt plus reset is a common configuration.

10. MCR Bit Calculation Example

Suppose Timer 0 Match 1 must generate an interrupt and reset the counter.

For MR1:

  • Interrupt bit = 3
  • Reset bit = 4
// Enable interrupt and reset on MR1
T0MCR = (1U << 3) | (1U << 4);

The resulting bit mask is 0x18.

For Timer 0 Match 2, interrupt and stop: 

// Enable interrupt and stop on MR2
T0MCR = (1U << 6) | (1U << 8);

The resulting bit mask is 0x140.

11. Match Registers and Interrupt Flags

When a match event occurs and the corresponding interrupt action is enabled, the timer sets the appropriate flag in its Interrupt Register.

EventInterrupt Register bit
Match 0Bit 0
Match 1Bit 1
Match 2Bit 2
Match 3Bit 3

The match interrupt flag is cleared by writing 1 to the corresponding bit. 

// Clear Timer 0 Match 0 interrupt flag
T0IR = (1U << 0);

// Clear Timer 0 Match 1 interrupt flag
T0IR = (1U << 1);
Do not use T0IR |= mask to clear a selected flag. The IR register uses write-one-to-clear behavior, so writing 1 to other already-set flags can clear them too.

12. Match Timing Calculation

Consider the project's timer configuration:

ParameterValue
PCLK15 MHz
PR14999
TC increment interval1 ms
MR0999

Starting with TC = 0, the counter needs 999 increments to reach TC = 999.

999 × 1 ms = 999 ms.

Therefore, the first equality event occurs after approximately 999 ms from the initial zero state, subject to timer clock and match-event timing.

To count 1000 TC increments from zero, use a match value of 1000. With a 1 ms TC interval, that corresponds to 1 second. The exact periodic interval should be verified against the timer's match and reset behavior.

13. Program: Timer 0 Match with Reset

Objective: Configure Timer 0 to reset TC when MR0 is reached.

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler for 1 ms tick
    T0PR = 14999;

    // Clear timer and prescale counters
    T0PC = 0;
    T0TC = 0;

    // Set match value
    T0MR0 = 999;

    // Enable reset on MR0 match
    T0MCR = (1U << 1);

    // Clear pending timer flags
    T0IR = 0x3F;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Observe T0TC in debugger
    }
}

Program explanation

  1. Timer 0 is stopped and reset.
  2. The prescaler is configured.
  3. TC and PC are initialized.
  4. MR0 is set to 999.
  5. MCR enables reset on MR0 match.
  6. Pending interrupt flags are cleared.
  7. Timer 0 is enabled.

14. Program: Timer 0 Match with Interrupt Request

This example configures the timer's match interrupt request. It does not include VIC setup or an interrupt service routine. 

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler
    T0PR = 14999;

    // Initialize counter registers
    T0PC = 0;
    T0TC = 0;

    // Configure match value
    T0MR0 = 999;

    // Enable interrupt on MR0 match
    T0MCR = (1U << 0);

    // Clear pending flags
    T0IR = 0x3F;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Timer generates a match interrupt request
        // when TC equals MR0
    }
}
A complete interrupt-driven application also requires VIC configuration, CPU interrupt enable, and a correctly implemented ISR. These topics are covered in the interrupt chapter.

15. Multiple Match Channels

Multiple match registers can be configured to generate different timer events. 

// Configure multiple match values
T0MR0 = 999;
T0MR1 = 1999;
T0MR2 = 2999;

// Enable interrupt for MR0, MR1 and MR2
T0MCR = (1U << 0) |
        (1U << 3) |
        (1U << 6);

Each match channel can generate its own interrupt request. The timer interrupt flags can be checked independently.

16. Applications of Match Registers

  • Periodic timer interrupts.
  • Generating time intervals.
  • Scheduling recurring operations.
  • Creating periodic sampling events.
  • Controlling timer counting periods.
  • Generating output transitions through external match functions.
  • Implementing time-based firmware operations.

17. Common Mistakes

  • Writing MR values without configuring MCR.
  • Using incorrect MCR bit positions.
  • Confusing match interrupt flags with match register values.
  • Assuming MCR alone enables the VIC interrupt.
  • Forgetting to clear pending interrupt flags.
  • Using an incorrect timer counter interval in calculations.
  • Assuming reset and stop actions are identical.
  • Forgetting that match values are compared against TC.

19. Interview Questions and Answers

Q1. What is a match register?

It stores a value compared against the timer counter to detect a match event.

Q2. How many match registers are available in each LPC2129 timer?

Four: MR0, MR1, MR2, and MR3.

Q3. What is the function of MCR?

MCR controls interrupt, reset, and stop actions when a match occurs.

Q4. Which MCR bit enables interrupt on MR0?

Bit 0.

Q5. Which MCR bit enables reset on MR0?

Bit 1.

Q6. Which MCR bit enables stop on MR0?

Bit 2.

Q7. Does MCR enable the VIC interrupt?

No. MCR enables the timer match interrupt request. VIC and CPU interrupt configuration are also required for ISR execution.

Q8. What happens when reset on match is enabled?

The timer counter is reset when the configured match condition occurs.

Q9. What is the difference between reset and stop on match?

Reset returns the counter to zero while allowing counting to continue. Stop halts the timer at the match event.

Q10. Can multiple match channels be used?

Yes. Each timer provides four independently configurable match channels.

22. Lesson Summary

  • Each LPC2129 timer has four match registers.
  • MR0–MR3 store comparison values.
  • MCR controls interrupt, reset, and stop actions.
  • Each match channel has three associated MCR control bits.
  • Match interrupt flags are recorded in IR.
  • Timer match interrupts also require interrupt-controller configuration.
  • Match reset can produce repeated counting intervals.
  • Match stop halts the timer when the configured event occurs.
