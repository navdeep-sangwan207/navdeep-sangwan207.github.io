1. Introduction

The LPC2129 microcontroller contains two general-purpose 32-bit timer/counter peripherals: Timer 0 and Timer 1.

These peripherals are used for time measurement, delay generation, event counting, pulse measurement, and interrupt-based applications.

Each timer has its own prescaler, counter, match registers, capture registers, and control registers.

Learning objectives:
  • Understand the LPC2129 timer architecture.
  • Identify Timer 0 and Timer 1.
  • Understand the timer clock path.
  • Study the prescaler and timer counter.
  • Understand match and capture units.
  • Study timer interrupt generation.
  • Understand timer and counter operating modes.

4. Peripheral Clock Input

The timer receives its clock from the peripheral clock system.

The peripheral clock is commonly represented as PCLK.

The configured PCLK determines the rate at which the prescaler receives clock events.

Project clock configuration

Parameter Value
FOSC 12 MHz
CCLK 60 MHz
PCLK 15 MHz
VPBDIV register encoding 0x00
Peripheral clock division ratio 4

In this project, the timer receives a peripheral clock of 15 MHz.

Always use the actual configured PCLK when calculating timer timing. Do not automatically use the CPU clock (CCLK) as the timer input frequency.

5. Prescaler Unit

The prescaler controls how frequently the timer counter is incremented.

It consists of two important registers:

  • Prescale Counter (PC)
  • Prescale Register (PR)

Working principle

  1. The prescale counter receives PCLK events.
  2. PC increases as clock events arrive.
  3. When PC reaches the programmed PR value, a timer counter increment occurs.
  4. The prescale counter is cleared for the next counting interval.

The timer counter increment frequency is:

Timer count frequency = PCLK / (PR + 1)

Example

PCLK = 15 MHz

PR = 14999

Timer count frequency = 15,000,000 / 15,000

Timer count frequency = 1,000 Hz

Therefore, the timer counter increments once every 1 millisecond.

6. Timer Counter Unit

The Timer Counter Register (TC) stores the current count value.

It is a 32-bit register and increments when the prescaler generates a timer counter enable event in timer mode.

Example sequence

Timer Event TC Value
Initial state 0
First timer increment 1
Second timer increment 2
Third timer increment 3
Fourth timer increment 4

When the timer reaches a configured match value, the match control logic determines the configured response.

7. Match Unit

The match unit compares the Timer Counter Register with one or more programmed Match Registers.

LPC2129 provides four match registers for each timer:

  • MR0
  • MR1
  • MR2
  • MR3

Match operation

Timer Counter (TC) | v +------------------+ | Match Comparator | +------------------+ | v Compare with MR0-MR3 | v Match Detected | v Configured Match Action

Depending on Match Control Register configuration, a match can:

  • Generate an interrupt.
  • Reset the timer counter.
  • Stop the timer.

Multiple actions can be configured for a match channel where supported.

8. Capture Unit

The capture unit records the current timer counter value when a selected external input event occurs.

LPC2129 provides four capture registers for each timer:

  • CR0
  • CR1
  • CR2
  • CR3

Working principle

  1. The timer runs and maintains its counter value.
  2. An external signal transition occurs on a configured capture input.
  3. The current timer count is copied into the corresponding capture register.
  4. Software can read the captured value.
Capture is useful for measuring pulse duration, input period, and frequency-related quantities.

9. Timer Interrupt Unit

The timer can generate an interrupt when a configured match or capture event occurs.

The timer interrupt status is maintained by its Interrupt Register (IR).

The interrupt request can be routed through the LPC2129 Vectored Interrupt Controller (VIC).

Timer Match / Capture Event | v +-------------------+ | Timer Interrupt | | Register (IR) | +-------------------+ | v +-------------------+ | Vectored Interrupt| | Controller (VIC) | +-------------------+ | v ARM7 CPU | v Interrupt Handler

Timer 0 and Timer 1 have separate interrupt sources. Their VIC source numbers must be configured correctly when enabling interrupt-driven programs.

10. Timer Mode and Counter Mode

Timer mode

In timer mode, the timer counter advances according to internal clock-derived events.

Applications include delay generation, periodic interrupts, and elapsed-time measurement.

Counter mode

In counter mode, the counter advances in response to qualifying transitions on a configured external counter input.

Applications include pulse counting, event measurement, and production counting.

Feature Timer Mode Counter Mode
Counting source Internal peripheral clock-derived events External input transitions
Primary purpose Time measurement Event measurement
Prescaler Used to control timer count rate Used according to counter configuration and device behavior
Example 1 ms timer increment Count sensor pulses

11. Timer Initialization Sequence

A typical timer setup follows this sequence:

  1. Configure the peripheral clock.
  2. Configure the timer input pin if capture or counter input is required.
  3. Disable or reset the timer before configuration.
  4. Configure the prescaler.
  5. Configure the match or capture settings.
  6. Clear pending timer interrupt flags.
  7. Enable the timer.
  8. Monitor the timer or handle its interrupt.

Basic register example

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler
    T0PR = 14999;

    // Clear prescale counter
    T0PC = 0;

    // Clear timer counter
    T0TC = 0;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Timer runs in hardware
    }
}
This example demonstrates basic Timer 0 initialization for a 1 ms timer counter increment with PCLK = 15 MHz. It does not configure a match event or interrupt. The timer is not guaranteed to generate a complete 1 ms application delay without additional counting or match configuration.

12. Advantages of Hardware Timers

  • Provide clock-derived time measurement.
  • Reduce the need for CPU-intensive software delay loops.
  • Support periodic interrupt generation.
  • Allow independent timer operation.
  • Support event and pulse measurement through capture and counter functions.
  • Improve the timing structure of embedded applications.
  • Support real-time task scheduling techniques.

13. Common Mistakes

  • Using CCLK instead of PCLK for timer calculations.
  • Ignoring the PR + 1 prescaler relationship.
  • Confusing the prescale counter PC with timer counter TC.
  • Forgetting to reset the timer before configuration.
  • Configuring a match value without enabling the required match action.
  • Forgetting to clear pending interrupt flags.
  • Using an incorrect capture or counter input pin configuration.
  • Assuming simulator register behavior proves physical peripheral operation.

15. Interview Questions and Answers

Q1. How many general-purpose timer/counter peripherals are available in LPC2129?

Two: Timer 0 and Timer 1.

Q2. What is the width of the LPC2129 timer counter?

The timer counter is 32-bit.

Q3. What is the function of the prescaler?

It controls the rate at which the timer counter increments.

Q4. How many match registers are available in each timer?

Four match registers: MR0, MR1, MR2, and MR3.

Q5. How many capture registers are available in each timer?

Four capture registers: CR0, CR1, CR2, and CR3.

Q6. What is the function of the Match Control Register?

It configures actions such as interrupt generation, timer reset, and timer stop on selected match events.

Q7. What is the purpose of a capture register?

It stores the timer count when a configured capture input event occurs.

Q8. What is the purpose of the timer interrupt register?

It indicates timer interrupt sources and supports clearing the corresponding flags.

Q9. Which clock is used for timer operation?

The configured peripheral clock, PCLK, is used as the clock source in timer mode.

Q10. What is the role of VIC?

The Vectored Interrupt Controller manages interrupt requests and routes enabled interrupt sources to the CPU.
