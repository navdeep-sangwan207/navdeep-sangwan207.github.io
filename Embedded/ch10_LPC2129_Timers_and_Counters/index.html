1. Chapter Overview

Timers and counters are important peripherals in embedded systems. They are used to generate accurate time intervals, measure events, schedule operations, and control time-dependent applications.

The LPC2129 provides two 32-bit general-purpose timer/counter blocks: Timer 0 and Timer 1. Each timer supports prescaling, match operations, and interrupt generation.

Chapter focus: Understand how the LPC2129 timer/counter peripherals work and how to configure them using Embedded C and Keil uVision.

5. Important LPC2129 Timer Registers

Register Function
T0TCR / T1TCR Timer Control Register – enables, disables, and resets the timer.
T0TC / T1TC Timer Counter Register – stores the current timer count.
T0PR / T1PR Prescale Register – determines the prescaler terminal count.
T0PC / T1PC Prescale Counter Register – counts peripheral clock cycles.
T0MR0–T0MR3 Timer 0 Match Registers.
T1MR0–T1MR3 Timer 1 Match Registers.
T0MCR / T1MCR Match Control Register – configures interrupt, reset, and stop actions.
T0IR / T1IR Interrupt Register – indicates timer interrupt sources and supports clearing flags.
T0CCR / T1CCR Capture Control Register – configures capture input behavior.
T0CR0–T0CR3 Timer 0 Capture Registers.
T1CR0–T1CR3 Timer 1 Capture Registers.
Timer register names and behavior should be checked against the LPC2129 User Manual and the device header file used by the Keil project.

7. LPC2129 Project Clock Reference

The following clock configuration is used as the reference for timer calculations in this learning project.

Parameter Project Value
Oscillator Frequency (FOSC) 12 MHz
CPU Clock (CCLK) 60 MHz
Peripheral Clock (PCLK) 15 MHz
VPBDIV Register Encoding 0x00
Peripheral Clock Divider Ratio 4
Timer calculation reference: Timer peripherals use the configured peripheral clock. With PCLK = 15 MHz, one peripheral clock cycle is approximately 66.67 ns.

For example, with PR = 14999, the prescaler produces one timer counter increment for every 15000 peripheral clock cycles, assuming the timer is operating in its normal timer mode.

Therefore:

Timer increment frequency = 15,000,000 / 15,000 = 1,000 Hz.

One timer counter increment occurs every 1 millisecond.
