Lesson 10

1. Introduction

This lesson provides practical programming exercises using the LPC2129 Timer 0 and Timer 1 peripherals.

The programs apply timer registers, prescalers, timer counters, match registers, match control, polling, and GPIO operations.

Learning objectives:
  • Initialize Timer 0 and Timer 1.
  • Configure the prescaler and timer counter.
  • Generate delays using match registers.
  • Use timer flags for polling.
  • Control a GPIO output using timer events.
  • Understand timer interrupt and counter-mode applications.
  • Debug timer register configuration in Keil uVision.

2. Project Clock Configuration

The examples use the following clock configuration from the LPC2129 project.

Calculation:

TC Frequency = PCLK / (PR + 1)

             = 15,000,000 / 15,000

             = 1000 Hz

TC Interval = 1 / 1000

            = 1 millisecond
These calculations assume that the timer peripheral clock is actually configured to 15 MHz. The clock setup must be completed before running the examples.

4. Exercise 1 – Timer 0 Initialization

Objective: Configure Timer 0 and start its counter.

Program

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler
    T0PR = 14999;

    // Clear prescale counter
    T0PC = 0;

    // Clear timer counter
    T0TC = 0;

    // Start Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Timer runs continuously
    }
}

Explanation

  1. T0TCR = 0x02 resets Timer 0.
  2. T0PR = 14999 configures a 1 ms counter interval for the selected PCLK.
  3. T0PC and T0TC are initialized to zero.
  4. T0TCR = 0x01 enables Timer 0.

Expected result

Timer 0 is configured and starts counting using its internal peripheral clock.

5. Exercise 2 – Read Timer Counter Value

Objective: Read the current Timer 0 counter value.

Program

#include <LPC21xx.h>

volatile unsigned int timer_value;

int main(void)
{
    T0TCR = 0x02;

    T0PR = 14999;
    T0PC = 0;
    T0TC = 0;

    T0TCR = 0x01;

    while (1)
    {
        timer_value = T0TC;
    }
}

Explanation

The program continuously reads T0TC and stores its current value in timer_value. The volatile qualifier prevents the compiler from treating this variable as an ordinary value that never changes.

Expected result

If timer peripheral simulation is supported, timer_value should reflect the changing Timer 0 counter value.

6. Exercise 3 – Generate a 10 Millisecond Delay

Objective: Generate a nominal 10 ms delay using Timer 0.

Program

#include <LPC21xx.h>

void delay_10ms(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure 1 ms TC interval
    T0PR = 14999;

    T0PC = 0;
    T0TC = 0;

    // Match after 10 counter increments
    T0MR0 = 10;

    // Interrupt flag and reset on match
    T0MCR = 0x03;

    // Clear pending timer flags
    T0IR = 0xFF;

    // Start timer
    T0TCR = 0x01;

    // Wait for MR0 match flag
    while ((T0IR & 0x01) == 0)
    {
    }

    // Clear MR0 flag
    T0IR = 0x01;

    // Stop timer
    T0TCR = 0x00;
}

int main(void)
{
    while (1)
    {
        delay_10ms();
    }
}

Expected result

The function waits for Timer 0 to reach MR0 = 10. At a nominal 1 ms counter interval, the match occurs after ten counter increments.

9. Exercise 6 – Blink an LED Using Timer Delay

Objective: Toggle an LED output at nominal one-second intervals using Timer 0.

Pin configuration:

PinFunction
P0.5LED output
LED logicActive-HIGH example

Program

#include <LPC21xx.h>

#define LED_PIN (1U << 5)

void delay_1second(void)
{
    T0TCR = 0x02;

    T0PR = 14999;
    T0PC = 0;
    T0TC = 0;

    T0MR0 = 1000;
    T0MCR = 0x03;

    T0IR = 0xFF;

    T0TCR = 0x01;

    while ((T0IR & 0x01) == 0)
    {
    }

    T0IR = 0x01;
    T0TCR = 0x00;
}

int main(void)
{
    // Select GPIO function for P0.5
    PINSEL0 &= ~(3U << 10);

    // Configure P0.5 as output
    IODIR0 |= LED_PIN;

    // Start with LED output LOW
    IOCLR0 = LED_PIN;

    while (1)
    {
        // LED ON
        IOSET0 = LED_PIN;

        delay_1second();

        // LED OFF
        IOCLR0 = LED_PIN;

        delay_1second();
    }
}

Expected result

The program alternates P0.5 between HIGH and LOW. With an appropriate active-HIGH LED circuit, this produces approximately one second ON and one second OFF.

In the Keil simulator, inspect IODIR0, IOSET0, IOCLR0, and the program execution. Do not assume that the simulator physically displays an LED lighting up.

11. Exercise 8 – Configure a Free-Running Timer

Objective: Configure Timer 0 to count continuously without a match-triggered reset.

Program

#include <LPC21xx.h>

volatile unsigned int count_value;

int main(void)
{
    // Reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler
    T0PR = 14999;

    // Initialize counter and prescale counter
    T0PC = 0;
    T0TC = 0;

    // Disable match actions
    T0MCR = 0x00;

    // Clear pending flags
    T0IR = 0xFF;

    // Enable timer
    T0TCR = 0x01;

    while (1)
    {
        // Continuously read timer counter
        count_value = T0TC;
    }
}

Expected result

Timer 0 counts continuously. The program can inspect the current count through count_value.

Because no match reset is configured, the counter continues until it is stopped, reset, or rolls over.

12. Exercise 9 – Detect a Timer Match Event

Objective: Detect an MR0 match and update a software event counter.

Program

#include <LPC21xx.h>

volatile unsigned int event_count = 0;

void wait_for_match(void)
{
    T0TCR = 0x02;

    T0PR = 14999;
    T0PC = 0;
    T0TC = 0;

    T0MR0 = 100;
    T0MCR = 0x03;

    // Clear MR0 flag
    T0IR = 0x01;

    T0TCR = 0x01;

    // Wait for MR0 event
    while ((T0IR & 0x01) == 0)
    {
    }

    // Clear the event flag
    T0IR = 0x01;

    T0TCR = 0x00;
}

int main(void)
{
    while (1)
    {
        wait_for_match();

        event_count++;
    }
}

Expected result

Each completed timer match increments event_count. The software variable can be inspected in the Watch window.

This example counts completed software delay events. It is not external pulse counting; external event counting uses counter mode and a correctly configured counter input.

13. Exercise 10 – Counter Mode Configuration

Objective: Configure Timer 0 for rising-edge counter operation and inspect the counter register.

Program

#include <LPC21xx.h>

volatile unsigned int event_count;

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Select counter mode:
    // CTCR bits 1:0 = 01
    // Rising-edge counting
    T0CTCR = 0x01;

    // Initialize counter
    T0TC = 0;
    T0PC = 0;

    // Enable counter
    T0TCR = 0x01;

    while (1)
    {
        // Read current event count
        event_count = T0TC;
    }
}

Expected result

Timer 0 is configured for rising-edge counter mode. TC stores the number of recognized external input transitions.

This is a mode-selection example, not a complete external counter interface. The counter input selection and pin multiplexing must be configured according to the LPC2129 User Manual. Keil simulator may not generate external input transitions.

15. Important Programming Notes

1. Clear timer interrupt flags correctly

// Clear MR0 flag
T0IR = (1U << 0);

Timer interrupt flags use write-one-to-clear behavior. Write the relevant bit mask directly rather than using a read-modify-write operation such as T0IR |= mask.

2. Configure MCR before starting the timer

// Enable MR0 interrupt flag and reset
T0MCR = (1U << 0) | (1U << 1);

3. Use the correct peripheral clock

Timer calculations must use PCLK, not automatically assume that CCLK and PCLK are equal.

4. Reset and initialize the timer

T0TCR = 0x02;
T0PC = 0;
T0TC = 0;
T0TCR = 0x01;

5. Understand blocking delays

Polling a timer flag in a while loop occupies the CPU until the match event occurs. For responsive applications, use timer interrupts or non-blocking timing logic.

17. Interview Questions and Answers

Q1. How do you configure an LPC2129 timer?

Stop and reset the timer, configure PR, initialize PC and TC, configure match registers and MCR if required, then enable the timer.

Q2. What is the purpose of PR?

PR determines how many peripheral clock cycles are counted before TC increments.

Q3. What is the purpose of MR0?

MR0 stores the target value compared against the timer counter.

Q4. What does MCR = 0x03 configure for MR0?

It enables the MR0 interrupt flag and resets TC on an MR0 match.

Q5. How do you clear the MR0 flag?

Write 1 to bit 0 of the timer IR register.

Q6. What is the difference between Timer 0 and Timer 1?

They are separate timer peripherals with independent register sets and configuration.

Q7. What is a free-running timer?

A timer that continues counting without being reset or stopped by a match action.

Q8. What is the difference between polling and interrupt-driven timing?

Polling repeatedly checks a status flag. Interrupt-driven timing uses an interrupt request to execute an interrupt service routine when the event occurs.

Q9. What does CTCR configure?

It selects timer mode or counter mode and the relevant counter input behavior.

Q10. Why may a timer program not behave as expected in simulation?

The simulator may not model every timer peripheral operation or external signal. Clock setup and register configuration must also be checked.

20. Keil uVision Simulator Guidelines

The LPC2129 project uses Keil uVision simulator without a physical development board.

  • Build each program and check compiler errors.
  • Use the Watch window to inspect timer registers.
  • Use breakpoints to examine initialization.
  • Inspect TC, PR, MR0, MCR, and IR.
  • Verify GPIO direction and output register writes.
  • Do not assume external signals are generated by the simulator.
The expected results in this lesson describe the intended register configuration and program behavior. They are not claims of measured hardware timing or physical LED operation.

21. Lesson Summary

  • Timer 0 and Timer 1 provide independent timer peripherals.
  • PR controls the timer counter increment interval.
  • TC stores the current count.
  • MR registers define match values.
  • MCR selects interrupt, reset, and stop actions.
  • IR stores match and capture event flags.
  • Polling can detect timer match events without using the VIC.
  • Timer interrupts support non-blocking application designs.
  • CTCR selects timer or counter operation.
  • Keil simulation must be interpreted within its peripheral-model limitations.
