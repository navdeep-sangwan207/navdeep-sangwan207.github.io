Lesson 09

1. Introduction

A microcontroller timer can operate either as a timer or as an event counter. In timer mode, the counter increments using an internal peripheral clock. In counter mode, the counter increments in response to selected external signal transitions.

The LPC2129 Timer 0 and Timer 1 peripherals support counter operation through their Timer/Counter Control Registers (CTCR).

Learning objectives:
  • Understand event counting.
  • Differentiate timer mode and counter mode.
  • Understand the CTCR register.
  • Understand external input-edge selection.
  • Configure a timer peripheral for counter operation.
  • Understand event-counting applications.

2. What Is Event Counting?

Event counting is the process of counting occurrences of an external event or signal. Each selected signal transition causes the counter to increment.

Examples include:

  • Counting objects passing a sensor.
  • Counting pulses from a rotary encoder.
  • Counting pulses from a flow sensor.
  • Counting machine operations.
  • Counting external digital pulses.

3. Timer Mode vs Counter Mode

4. Counter Mode Architecture

External Digital Signal | v Counter Input Pin | v Edge Selection | v CTCR Register | v Timer Counter TC | +---------+---------+ | | v v Match Logic Capture Logic | v Interrupt / Reset / Stop

In counter mode, selected external signal transitions provide the counting events. The CTCR register selects the counter input and the active edge.

5. Timer/Counter Control Register (CTCR)

CTCR selects whether the timer operates in timer mode or counter mode.

RegisterDescription
T0CTCRTimer 0 Timer/Counter Control Register
T1CTCRTimer 1 Timer/Counter Control Register

The CTCR contains fields for selecting timer/counter operation, counter input, and the active edge.

CTCR mode selection

CTCR bits 1:0Operation
00Timer mode
01Counter mode: rising edges
10Counter mode: falling edges
11Counter mode: both edges

The counter input selection is configured using the relevant CTCR input-selection field. Consult the LPC2129 User Manual for the exact field definition.

In counter mode, the timer prescaler is not used to divide the external event stream in the same way as timer mode. Configure the counter input and edge selection according to the device documentation.

6. External Counter Input

The counter receives an external digital signal through a pin that supports the selected timer counter input function.

The required pin must be configured through the LPC2129 pin-selection registers.

Before using a counter input:

  1. Identify the required counter input function.
  2. Check the LPC2129 pin-function table.
  3. Configure the corresponding PINSEL field.
  4. Connect a valid external digital signal.
  5. Select the input and edge in CTCR.
  6. Enable the timer peripheral.
Do not assume that a general-purpose GPIO pin automatically acts as a timer counter input. The exact pin mapping depends on the microcontroller's pin-function table and package.

7. Rising-Edge Counting

In rising-edge counting, the counter increments when the input signal changes from LOW to HIGH.

Input Signal: LOW ______ ______ ______ | | | | |_____| Rising edges: ^ ^ Counter events: +1 +1

A rising-edge counter is useful when an external sensor produces one pulse for each detected event.

8. Falling-Edge Counting

In falling-edge counting, the counter increments when the input signal changes from HIGH to LOW.

Input Signal: HIGH _____ ______ ______ | | | | |____| Falling edges: ^ ^ Counter events: +1 +1

Falling-edge counting is useful when the external event is represented by a high-to-low transition.

9. Both-Edge Counting

Both-edge counting allows the counter to respond to rising and falling transitions.

For a suitable signal, counting both edges can produce two count events per complete pulse cycle.

Both-edge counting is useful only when the application requires both transitions to be counted. It must not be confused with measuring frequency or decoding a complete quadrature encoder position.

10. Counter Configuration Steps

  1. Stop and reset the selected timer.
  2. Configure the counter input pin function.
  3. Select counter mode in CTCR.
  4. Select the required counter input.
  5. Select rising, falling, or both-edge counting.
  6. Initialize TC and PC as appropriate.
  7. Configure match or capture functions if required.
  8. Enable the timer/counter.
  9. Read TC to obtain the event count.

11. Basic CTCR Configuration Example

The following example demonstrates the mode and edge-selection concept for Timer 0. The counter input-selection field must be configured using the correct LPC2129 User Manual definition and selected pin. 

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure counter mode.
    // CTCR bits 1:0 = 01 selects rising-edge counting.
    T0CTCR = 0x01;

    // Initialize timer counter
    T0TC = 0;
    T0PC = 0;

    // Enable Timer 0 counter
    T0TCR = 0x01;

    while (1)
    {
        // Read the external event count
        unsigned int event_count = T0TC;

        (void)event_count;
    }
}
This is a register-level mode-selection example, not a complete board-ready counter application. The counter input-selection field and pin mux must be configured correctly before external events can increment TC.

12. Reading the Event Count

The timer counter register stores the current event count. 

unsigned int count;

count = T0TC;

If 25 selected input transitions have occurred since the counter was initialized, the counter value will be 25, assuming no reset or rollover has occurred.

The counter is a 32-bit register. It wraps around after reaching its maximum unsigned value and incrementing again.

13. Event Counting with a Match Register

A match register can be used to detect when a particular number of external events has been counted.

For example, if the application must detect 100 events, configure MR0 to 100 and enable the desired match action. 

// Configure event-count target
T0MR0 = 100;

// Enable match interrupt and reset
T0MCR = (1U << 0) | (1U << 1);

When the counter reaches the match value, the configured match event occurs.

The counter input and match behavior must be tested with the actual signal source. Do not assume the Keil simulator generates external counter transitions.

14. Example Applications

Object counting

A sensor produces one pulse when an object passes. The counter records the number of detected objects.

Rotary encoder pulse counting

Encoder transitions can be counted to estimate rotational movement. Direction detection requires suitable signal decoding.

Flow measurement

A flow sensor can produce pulses related to the amount of liquid passing through a pipe. The pulse count can be converted into a flow measurement using the sensor's calibration data.

Machine production counting

A sensor can generate a pulse for each completed production cycle.

15. Electrical and Signal Considerations

  • Use valid digital voltage levels for the selected input.
  • Keep the input signal within the device's electrical limits.
  • Use suitable signal conditioning where necessary.
  • Consider noise and false transitions.
  • Use hardware filtering or signal conditioning for noisy sensors.
  • Check the maximum supported input transition rate in the device documentation.
  • Ensure the signal source and microcontroller have a suitable common reference.
Mechanical switches can bounce and generate multiple transitions for one physical press. Debouncing or signal conditioning is needed when counting switch-generated events.

17. Common Mistakes

  • Leaving CTCR in timer mode.
  • Using the wrong counter input selection.
  • Forgetting to configure the pin function.
  • Selecting the wrong input edge.
  • Connecting an external signal with invalid voltage levels.
  • Ignoring noise and switch bounce.
  • Assuming the prescaler works identically in timer and counter modes.
  • Expecting the simulator to generate real external pulses.

19. Interview Questions and Answers

Q1. What is event counting?

Event counting is counting selected transitions of an external digital signal.

Q2. What is the difference between timer and counter mode?

Timer mode counts internal peripheral clock ticks, whereas counter mode counts selected external signal transitions.

Q3. Which register selects timer or counter mode?

CTCR.

Q4. Which register stores the current count?

TC.

Q5. What is rising-edge counting?

Counting transitions from LOW to HIGH.

Q6. What is falling-edge counting?

Counting transitions from HIGH to LOW.

Q7. What is the purpose of a counter input pin?

It receives the external digital signal whose selected transitions are counted.

Q8. Can a timer match register be used in counter mode?

Yes. A match register can detect when the external event count reaches a programmed value.

Q9. Why is signal conditioning important?

It reduces noise and false transitions that could produce incorrect counts.

Q10. Can a counter be used to count objects?

Yes. A suitable sensor can generate a digital pulse for each detected object.
