1. Introduction

The LPC2129 microcontroller provides two general-purpose timer/counter peripherals: Timer 0 and Timer 1.

Each timer has a dedicated set of memory-mapped registers. These registers control timer operation, counting, prescaling, matching, capture, and interrupt status.

Timer 0 registers generally use the prefix T0, while Timer 1 registers use the prefix T1.

Learning objectives:
  • Understand memory-mapped timer registers.
  • Identify Timer 0 and Timer 1 register names.
  • Understand the purpose of important timer registers.
  • Study timer control and status registers.
  • Write basic timer initialization programs.
  • Inspect timer registers in Keil uVision.

3. Interrupt Register (IR)

The Interrupt Register indicates timer interrupt conditions generated by match and capture events.

Register names:

  • T0IR – Timer 0 Interrupt Register
  • T1IR – Timer 1 Interrupt Register

Important characteristics

  • It contains interrupt flags for match and capture channels.
  • Each match channel has a corresponding interrupt flag.
  • Each capture channel has a corresponding interrupt flag.
  • Flags are cleared by writing a 1 to the corresponding bit.
// Clear Timer 0 match interrupt flag 0
T0IR = (1U << 0);

// Clear Timer 0 capture interrupt flag 0
T0IR = (1U << 4);
The timer interrupt flags use write-one-to-clear behavior. Do not use read-modify-write operations such as T0IR |= mask for clearing a selected flag, because other flags that are read as 1 may also be cleared.

4. Timer Control Register (TCR)

The Timer Control Register controls the timer's enable and reset operations.

Register names:

  • T0TCR – Timer 0 Control Register
  • T1TCR – Timer 1 Control Register

Important control bits

Bit Name Function
Bit 0 Counter Enable Enables the timer/counter when set to 1.
Bit 1 Counter Reset Resets the timer counter and prescale counter while asserted.

Example

// Stop and reset Timer 0
T0TCR = 0x02;

// Enable Timer 0
T0TCR = 0x01;

// Disable Timer 0
T0TCR = 0x00;
TCR is used to control whether the timer operates and whether its counting state is reset.

5. Timer Counter Register (TC)

The Timer Counter Register stores the current count value of the timer.

Register names:

  • T0TC – Timer 0 Counter Register
  • T1TC – Timer 1 Counter Register

The register is 32 bits wide. In timer mode, it increments when the prescaler generates a timer counter increment event.

Example

// Clear Timer 0 counter
T0TC = 0;

// Read current Timer 0 count
unsigned int count;

count = T0TC;

Illustrative counter progression

Event TC Value
Initial state0
First increment1
Second increment2
Third increment3
Fourth increment4

6. Prescale Register (PR)

The Prescale Register determines how many peripheral clock cycles are required before the timer counter increments.

Register names:

  • T0PR – Timer 0 Prescale Register
  • T1PR – Timer 1 Prescale Register

Timer counter increment frequency:

FTC = PCLK / (PR + 1)

Example

// Configure Timer 0 prescaler
T0PR = 14999;

With PCLK = 15 MHz:

FTC = 15,000,000 / (14,999 + 1)

FTC = 1,000 Hz

The timer counter increments once every 1 millisecond.

PR = 14999 means the prescaler divides the incoming clock by 15000, not by 14999.

7. Prescale Counter Register (PC)

The Prescale Counter stores the current prescaler count.

Register names:

  • T0PC – Timer 0 Prescale Counter
  • T1PC – Timer 1 Prescale Counter

The PC register increments with peripheral clock events. When the configured prescale condition is met, the timer counter increments and PC is reset. 

// Clear Timer 0 prescale counter
T0PC = 0;

// Read current prescale counter
unsigned int prescale_count;

prescale_count = T0PC;
PC and PR are different registers. PR contains the programmed prescale value, while PC tracks the current prescale counting progress.

8. Match Registers (MR0–MR3)

Each timer contains four Match Registers. These registers store values compared against the timer counter.

Timer 0 Timer 1
T0MR0T1MR0
T0MR1T1MR1
T0MR2T1MR2
T0MR3T1MR3

Example

// Configure Timer 0 Match Register 0
T0MR0 = 1000;

When T0TC reaches the configured match value, the match unit detects the equality condition. The configured match control action determines what happens next.

9. Match Control Register (MCR)

The Match Control Register determines the action performed when a match event occurs.

Register names:

  • T0MCR – Timer 0 Match Control Register
  • T1MCR – Timer 1 Match Control Register

Actions controlled by MCR

  • Generate an interrupt on match.
  • Reset the timer on match.
  • Stop the timer on match.

Each match channel has three associated control bits.

Match Channel Interrupt Bit Reset Bit Stop Bit
MR0012
MR1345
MR2678
MR391011

Example: Interrupt and reset on MR0

// Enable interrupt and reset on MR0
T0MCR = (1U << 0) | (1U << 1);

When MR0 matches TC, the timer generates an interrupt and resets the timer counter according to the configured actions.

10. Capture Control Register (CCR)

The Capture Control Register configures external capture events.

Register names:

  • T0CCR – Timer 0 Capture Control Register
  • T1CCR – Timer 1 Capture Control Register

The CCR configures:

  • Capture on rising edge.
  • Capture on falling edge.
  • Interrupt generation on capture.

Each capture channel has three associated control bits.

Capture Channel Rising Edge Falling Edge Interrupt
CR0012
CR1345
CR2678
CR391011

The capture register stores the timer count when a selected input transition occurs.

11. Capture Registers (CR0–CR3)

Each timer has four capture registers. They store the timer counter value at the configured capture event.

Timer 0 Timer 1
T0CR0T1CR0
T0CR1T1CR1
T0CR2T1CR2
T0CR3T1CR3

Example

// Read Timer 0 Capture Register 0
unsigned int captured_value;

captured_value = T0CR0;

Captured values can be compared to measure the time between external events.

12. External Match Register (EMR)

The External Match Register controls the behavior of external match output pins associated with the timer match channels.

Register names:

  • T0EMR – Timer 0 External Match Register
  • T1EMR – Timer 1 External Match Register

It includes control fields for match output pins and action selection on match events.

Depending on the configuration, an external match output can be set, cleared, toggled, or left unchanged when a match occurs.

External match output functions require the correct pin multiplexing configuration. The exact output pin assignment must be checked in the LPC2129 pin-function table before hardware use.

13. Count Control Register (CTCR)

The Count Control Register selects whether the peripheral operates in timer mode or counter mode.

Register names:

  • T0CTCR – Timer 0 Count Control Register
  • T1CTCR – Timer 1 Count Control Register

In timer mode, the timer counter is incremented by internal clock-derived events.

In counter mode, the counter is incremented by selected external input transitions.

The CTCR configuration determines the counting source and, where applicable, the selected external edge.

15. Practical Program: Timer 0 Initialization

Objective: Configure Timer 0 with a 1 millisecond timer counter increment using PCLK = 15 MHz. 

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler
    T0PR = 14999;

    // Clear prescale counter
    T0PC = 0;

    // Clear timer counter
    T0TC = 0;

    // Clear pending timer interrupt flags
    T0IR = 0x3F;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Observe T0TC in debugger
    }
}

Program explanation

  1. T0TCR = 0x02 resets Timer 0.
  2. T0PR = 14999 configures the prescaler.
  3. T0PC = 0 clears the prescale counter.
  4. T0TC = 0 clears the timer counter.
  5. T0IR = 0x3F clears the six match/capture interrupt flags.
  6. T0TCR = 0x01 enables Timer 0.
Expected configuration: T0PR = 14999, T0PC = 0 immediately after initialization, T0TC = 0, and T0TCR = 1. The counter then advances according to the configured PCLK and prescaler if the simulator models the timer.

16. Timer 0 and Timer 1 Comparison Program

The following example configures both timers with the same prescaler. 

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Stop and reset Timer 1
    T1TCR = 0x02;

    // Configure both prescalers
    T0PR = 14999;
    T1PR = 14999;

    // Clear prescale counters
    T0PC = 0;
    T1PC = 0;

    // Clear timer counters
    T0TC = 0;
    T1TC = 0;

    // Enable both timers
    T0TCR = 0x01;
    T1TCR = 0x01;

    while (1)
    {
        // Inspect T0TC and T1TC
    }
}

Both timers are configured independently. Their counter values can be inspected separately.

17. Common Mistakes

  • Using T0 register names while configuring Timer 1.
  • Confusing TC with PC.
  • Forgetting the PR + 1 relationship.
  • Writing a 1 to an interrupt flag when intending to preserve it.
  • Using an incorrect match control bit position.
  • Enabling a timer before completing its configuration.
  • Assuming a capture register stores a continuously updated value.
  • Ignoring pin multiplexing for capture and external match functions.

19. Interview Questions and Answers

Q1. What is the difference between T0 and T1 registers?

T0 registers belong to Timer 0, while T1 registers belong to Timer 1. Their functions are corresponding but their addresses are separate.

Q2. What is the function of T0TCR?

It controls Timer 0 enable and reset operations.

Q3. What is the function of T0TC?

It stores the current Timer 0 counter value.

Q4. What is the difference between PR and PC?

PR stores the programmed prescale value, while PC stores the current prescale progress.

Q5. What is the function of T0MCR?

It controls interrupt, reset, and stop actions for Timer 0 match events.

Q6. What is the purpose of T0CCR?

It configures capture events for Timer 0.

Q7. What is the function of T0IR?

It indicates Timer 0 match and capture interrupt flags.

Q8. What does T0CTCR configure?

It selects timer mode or counter mode and configures the relevant external counting source and edge.

Q9. How many match registers are available in Timer 1?

Four: T1MR0, T1MR1, T1MR2, and T1MR3.

Q10. Can Timer 0 and Timer 1 operate independently?

Yes. They have separate register sets and can be configured independently.
