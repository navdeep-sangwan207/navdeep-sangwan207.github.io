1. Introduction

The Timer Counter Register (TC) is the main counting register of the LPC2129 Timer 0 and Timer 1 peripherals. It stores the current count value and increments when the prescaler generates a timer increment event in timer mode.

The TC register is used for measuring elapsed time, generating periodic events, implementing delays, and controlling time-dependent operations.

Learning objectives:
  • Understand the Timer Counter Register.
  • Identify T0TC and T1TC.
  • Understand how TC works with PR and PC.
  • Learn timer counter increment and rollover.
  • Understand TC and match register interaction.
  • Write basic TC initialization and polling programs.

2. What Is the Timer Counter Register?

TC is a 32-bit register that stores the current timer or counter value. In timer mode, it increments according to the peripheral clock and prescaler.

RegisterDescription
T0TCTimer Counter Register for Timer 0
T1TCTimer Counter Register for Timer 1

Timer 0 and Timer 1 have independent TC registers. Configuring one timer does not automatically configure the other.

3. Position of TC in the Timer Architecture

Peripheral Clock (PCLK) | v +----------------+ | Prescaler | | PR and PC | +----------------+ | TC increment event | v +----------------+ | Timer Counter | | TC | +----------------+ | v +----------------+ | Match Logic | | MR0 to MR3 | +----------------+ | +--------+--------+ | | | v v v Interrupt Reset Stop

The prescaler determines how frequently TC increments. The match logic compares the current TC value against the programmed match registers.

4. How the Timer Counter Increments

In timer mode, the peripheral clock is supplied to the prescaler. The prescaler counts clock cycles according to PR. When the prescale condition is met, TC increments by one and PC returns to zero.

For example, if PR = 4, five peripheral clock cycles are required for one TC increment.

General relationship: TC increment frequency = PCLK / (PR + 1)

5. Timer Counter Register Configuration

TC can be initialized by writing a value to the corresponding register. 

// Clear Timer 0 counter
T0TC = 0;

// Clear Timer 1 counter
T1TC = 0;

// Read Timer 0 counter
unsigned int count0 = T0TC;

// Read Timer 1 counter
unsigned int count1 = T1TC;

The counter can be reset by software or by the configured match-control reset action.

6. Timer Counter Register and TCR

The Timer Control Register (TCR) controls whether the timer operates and whether its counting state is reset.

TCR bitFunction
Bit 0Counter enable
Bit 1Counter reset
// Reset Timer 0
T0TCR = 0x02;

// Initialize Timer 0 counter
T0TC = 0;

// Release reset and enable Timer 0
T0TCR = 0x01;

// Stop Timer 0
T0TCR = 0x00;
Keep the timer in reset while initializing its configuration registers. Release reset before enabling normal operation.

7. Timer Counter Rollover

The TC register is 32 bits wide. When it reaches its maximum unsigned value and receives another increment, it rolls over to zero, provided no configured match action changes the count first.

Maximum unsigned 32-bit value:

4,294,967,295 (0xFFFFFFFF)

Illustrative rollover:

Counter stateTC value
Before final increment0xFFFFFFFE
Final count value0xFFFFFFFF
Next increment0x00000000
A match-control reset can cause TC to return to zero earlier than the natural 32-bit rollover.

8. Timer Counter and Match Registers

The match registers store values that are compared with TC. When TC equals a match value, the timer generates a match event. 

// Configure match register 0
T0MR0 = 999;

If the prescaler produces one TC increment every 1 millisecond, the timer reaches TC = 999 after 999 increments from zero. The exact event timing depends on the initial state and the match configuration.

The Match Control Register (MCR) determines whether the match event generates an interrupt, resets TC, or stops the timer.

9. Timer Counter and Match Reset

A timer can be configured to reset its counter when a match occurs. This allows repeated counting intervals. 

// Configure a match value
T0MR0 = 999;

// Enable reset on MR0 match
T0MCR = (1U << 1);

When TC matches MR0, the configured reset action returns the timer counter to zero. The timer can then begin counting the next interval.

This example configures the reset action only. It does not enable a match interrupt. The timer must also be initialized and enabled correctly.

11. Program: Initialize and Read Timer 0 Counter

Objective: Initialize Timer 0 and read its current TC value.

#include <LPC21xx.h>

volatile unsigned int timer_count;

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler for 1 ms tick
    T0PR = 14999;

    // Clear prescale counter
    T0PC = 0;

    // Clear timer counter
    T0TC = 0;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Read current timer counter value
        timer_count = T0TC;
    }
}

Explanation

  1. Timer 0 is reset.
  2. The prescaler is configured.
  3. PC and TC are initialized to zero.
  4. Timer 0 is enabled.
  5. The program repeatedly reads T0TC.

12. Program: Poll Timer Counter for a Match

This example demonstrates polling TC until it reaches a selected count. The match register is not used in this example. 

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure 1 ms TC increment
    T0PR = 14999;

    // Clear prescale and timer counters
    T0PC = 0;
    T0TC = 0;

    // Enable Timer 0
    T0TCR = 0x01;

    // Wait until TC reaches 999
    while (T0TC < 999)
    {
        // Polling
    }

    // Stop Timer 0
    T0TCR = 0x00;

    while (1)
    {
        // Program remains here
    }
}
This is a polling demonstration. The CPU continuously checks TC, so it is not an efficient approach for applications that need to perform other work while waiting. The actual elapsed interval includes the time required for the counter to reach the selected value and the polling response.

13. Applications of Timer Counter Register

  • Measuring elapsed time.
  • Generating periodic events.
  • Creating timer-based delays.
  • Measuring pulse widths.
  • Measuring time between external events.
  • Supporting communication timing.
  • Scheduling periodic embedded tasks.

14. Common Mistakes

  • Confusing TC with the prescale counter PC.
  • Using CCLK instead of PCLK in the timer calculation.
  • Forgetting that PR + 1 determines the prescaler division.
  • Reading TC before initializing the timer.
  • Assuming a match event automatically generates an interrupt.
  • Ignoring the MCR configuration.
  • Assuming a software polling loop provides an exact real-time delay.
  • Forgetting that TC is a 32-bit register.

16. Interview Questions and Answers

Q1. What is the Timer Counter Register?

TC is a 32-bit register that stores the current timer or counter value.

Q2. What are T0TC and T1TC?

They are the Timer Counter Registers for Timer 0 and Timer 1, respectively.

Q3. How does TC increment in timer mode?

TC increments when the prescaler generates a timer counter increment event.

Q4. What is the maximum unsigned TC value?

4,294,967,295 (0xFFFFFFFF).

Q5. What happens when TC rolls over?

After the maximum 32-bit value, the counter returns to zero on the next increment, unless a configured match action changes its behavior.

Q6. Which register controls timer enable and reset?

The Timer Control Register (TCR).

Q7. How can TC be reset on a match event?

Configure the corresponding reset action in MCR.

Q8. What is the relationship between PR and TC?

PR determines how many peripheral clock cycles are required before TC increments.
