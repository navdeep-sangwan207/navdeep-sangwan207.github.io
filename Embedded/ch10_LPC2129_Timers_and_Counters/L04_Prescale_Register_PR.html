1. Introduction

The Prescale Register (PR) is an important register in the LPC2129 Timer 0 and Timer 1 peripherals. It controls how many peripheral clock cycles are counted before the Timer Counter (TC) increments.

The prescaler allows a high-frequency peripheral clock to produce a slower timer counting rate. This is useful for generating delays, periodic events, and time intervals.

Learning objectives:
  • Understand the purpose of the prescaler.
  • Identify T0PR and T1PR.
  • Understand the relationship between PR, PC, and TC.
  • Calculate timer counter frequency.
  • Configure a prescaler using Embedded C.
  • Inspect prescaler operation in Keil uVision.

2. What Is a Prescaler?

A prescaler is a clock-division mechanism. It receives clock pulses and allows the timer counter to increment only after a programmed number of clock cycles.

Without a prescaler, a timer driven by a 15 MHz peripheral clock could increment 15 million times per second. This is often too fast for convenient delay generation.

A prescaler reduces the rate at which the timer counter increments.

Peripheral Clock (PCLK) | v +------------------+ | Prescaler Logic | | PR and PC | +------------------+ | | TC increment event v +------------------+ | Timer Counter | | TC | +------------------+ | v Match / Capture / Interrupt

3. Prescale Register in LPC2129

LPC2129 provides two timer peripherals. Each timer has its own Prescale Register.

RegisterFunction
T0PRPrescale Register for Timer 0
T1PRPrescale Register for Timer 1

PR is a 32-bit register. Its programmed value determines the prescale division factor. 

// Configure Timer 0 prescaler
T0PR = 14999;

// Configure Timer 1 prescaler
T1PR = 14999;
T0PR and T1PR are independent. Changing the prescaler of Timer 0 does not automatically change the prescaler of Timer 1.

4. Prescale Counter (PC) and Prescale Register (PR)

The prescaler uses two related registers:

  • PR: Stores the programmed prescale value.
  • PC: Tracks the current prescale count.

PC increments with peripheral clock cycles. When PC reaches the programmed PR value, the timer counter increments and PC is reset to zero.

PCLK pulses | v Prescale Counter (PC) | PC reaches PR | +-------> TC increments by 1 | +-------> PC resets to 0 | v Counting repeats

Because counting begins at zero, a PR value of 9 requires 10 peripheral clock cycles for each TC increment.

5. Prescaler Formula

The timer counter increment frequency is:

TC frequency = PCLK / (PR + 1)

Where:

  • PCLK = Peripheral clock frequency in hertz.
  • PR = Programmed prescale register value.
  • TC frequency = Timer counter increment frequency.

The time between successive TC increments is:

TC increment interval = (PR + 1) / PCLK

The PR + 1 relationship is important. Do not divide PCLK by PR alone.

6. Calculation Example 1: PR = 9

Given:

  • PCLK = 1 MHz
  • PR = 9

Calculation:

TC frequency = 1,000,000 / (9 + 1)

TC frequency = 100,000 Hz

TC increment interval = 1 / 100,000

TC increment interval = 10 microseconds

7. Calculation Example 2: PR = 999

Given:

  • PCLK = 1 MHz
  • PR = 999

Calculation:

TC frequency = 1,000,000 / 1000

TC frequency = 1 kHz

Each TC increment takes 1 millisecond.

8. Calculation Example 3: User's LPC2129 Clock Configuration

Consider the clock configuration used in the LPC2129 learning project:

ParameterValue
Crystal frequency (FOSC)12 MHz
CPU clock (CCLK)60 MHz
Peripheral clock (PCLK)15 MHz
Prescale Register (PR)14999

Calculation:

TC frequency = 15,000,000 / (14,999 + 1)

TC frequency = 15,000,000 / 15,000

TC frequency = 1,000 Hz

TC increment interval = 1 millisecond

With PCLK = 15 MHz and PR = 14999, the timer counter increments once every 1 ms, assuming the timer is operating in timer mode.

9. Selecting PR for a Required Time Interval

The PR value can be calculated when the required timer counter increment interval and PCLK are known.

PR = (PCLK × required interval) − 1

For example, to obtain a 1 ms TC increment interval with PCLK = 15 MHz:

PR = (15,000,000 × 0.001) − 1

PR = 14999

This calculation determines the TC tick. It does not by itself generate a complete delay. A match event, polling loop, or interrupt-based method is also required.

10. Embedded C Program: Configure Timer 0 Prescaler

Objective: Configure Timer 0 with a 1 ms TC increment interval.

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 0
    T0TCR = 0x02;

    // Configure prescaler for 1 ms TC tick
    T0PR = 14999;

    // Clear prescale counter
    T0PC = 0;

    // Clear timer counter
    T0TC = 0;

    // Enable Timer 0
    T0TCR = 0x01;

    while (1)
    {
        // Observe T0PC and T0TC in debugger
    }
}

Program explanation

  1. T0TCR = 0x02 resets Timer 0.
  2. T0PR = 14999 configures the prescaler.
  3. T0PC = 0 clears the prescale counter.
  4. T0TC = 0 clears the timer counter.
  5. T0TCR = 0x01 enables Timer 0.
  6. The timer operates according to the peripheral clock and prescaler configuration.

11. Embedded C Program: Configure Timer 1 Prescaler

#include <LPC21xx.h>

int main(void)
{
    // Stop and reset Timer 1
    T1TCR = 0x02;

    // Configure Timer 1 prescaler
    T1PR = 14999;

    // Clear prescale counter
    T1PC = 0;

    // Clear timer counter
    T1TC = 0;

    // Enable Timer 1
    T1TCR = 0x01;

    while (1)
    {
        // Observe T1PC and T1TC in debugger
    }
}

This program configures Timer 1 independently. The same prescaler calculation applies to Timer 0 and Timer 1.

13. Applications of Prescaler

  • Generating timer counter ticks at a suitable frequency.
  • Creating millisecond and microsecond time bases.
  • Supporting periodic timer interrupts.
  • Measuring elapsed time between events.
  • Generating software-controlled delays using timer hardware.
  • Reducing the frequency of timer counter updates.

14. Common Mistakes

  • Using PR instead of PR + 1 in the calculation.
  • Using CCLK instead of PCLK in the timer calculation.
  • Confusing PR with PC.
  • Forgetting to clear PC when initializing the timer.
  • Assuming PR alone creates a delay.
  • Using a prescaler value that exceeds the register's supported range.
  • Assuming Timer 0 and Timer 1 share the same PR register.

16. Interview Questions and Answers

Q1. What is a prescaler?

A prescaler divides the incoming peripheral clock to control the rate at which the timer counter increments.

Q2. What is the function of PR?

PR stores the programmed prescale value.

Q3. What is the difference between PR and PC?

PR stores the division setting, while PC tracks the current prescale count.

Q4. What is the formula for timer counter frequency?

TC frequency = PCLK / (PR + 1).

Q5. What PR value produces a 1 ms TC interval at 15 MHz?

PR = 14999.

Q6. Does the prescaler generate a complete delay?

No. It controls the timer counter increment rate. A separate counting and event-detection method is needed to generate a delay.

Q7. Does Timer 1 have a separate prescaler?

Yes. Timer 1 uses T1PR and T1PC.

Q8. Which clock is used in the timer prescaler calculation?

The peripheral clock (PCLK).

19. Lesson Summary

  • The prescaler divides the peripheral clock before TC increments.
  • T0PR configures Timer 0 prescaling.
  • T1PR configures Timer 1 prescaling.
  • PC tracks the current prescale count.
  • TC increments after the configured prescale interval.
  • TC frequency = PCLK / (PR + 1).
  • At PCLK = 15 MHz, PR = 14999 produces a 1 ms TC interval.
  • A match or other event mechanism is needed to generate a complete delay.
