Lesson 10: CAN Bit Timing and Configuration

Understand CAN bit-rate generation, time quanta, synchronization, timing segments, sample-point selection and LPC2129 Bit Timing Register configuration using Embedded C.

After completing this lesson, you will be able to:

  • Explain synchronization and timing segments.

  • Understand Synchronization Jump Width (SJW).

  • Configure a CAN controller for a selected nominal bit rate.

2. Introduction to CAN Bit Timing

CAN bit timing determines how long each bit remains on the bus and when a CAN controller samples the bus to identify the transmitted value.

Every CAN node connected to the same network must use compatible nominal bit timing. If nodes use incompatible bit rates or unsuitable timing parameters, communication may fail.

Why Is Bit Timing Important?

  • Ensures reliable transmission and reception.
  • Allows nodes to synchronize with each other.
  • Provides a suitable bus sampling point.
  • Compensates for timing differences between nodes.
  • Helps account for propagation delay and oscillator tolerance.
CAN bit timing is not simply a baud-rate number. It includes the prescaler, synchronization segment, propagation and phase segments, sample point and synchronization jump width.

3. Nominal CAN Bit Time

One nominal CAN bit is divided into four logical segments.

|<----------- One Nominal CAN Bit Time ----------->|

+----------+----------------------+----------------+
| SYNC_SEG |        TSEG1         |     TSEG2      |
+----------+----------------------+----------------+
           |                      |
           |                      |
     Propagation Segment     Phase Segment 2
     + Phase Segment 1

                              ^
                              |
                         Sample Point

The four segments are:

  1. SYNC_SEG: Used to synchronize CAN nodes with a bus transition.
  2. PROP_SEG: Compensates for signal propagation delay in the network.
  3. PHASE_SEG1: Helps compensate for phase errors and ends at the sample point.
  4. PHASE_SEG2: Extends from the sample point to the next nominal bit boundary.

In the LPC2129 BTR, PROP_SEG and PHASE_SEG1 are represented together by the TSEG1 field.

4. Time Quantum (TQ)

Time Quantum is the basic time unit used by the CAN controller to construct a nominal CAN bit.

The LPC2129 derives the CAN clock from the VPB peripheral clock using the Baud Rate Prescaler.

Time Quantum:

TQ = (BRP + 1) / VPB Clock

Here, BRP is the value programmed into the BTR register's prescaler field.

Example

Assume:

VPB Clock = 15 MHz
BRP field = 4

TQ = (4 + 1) / 15,000,000

TQ = 5 / 15,000,000

TQ = 0.3333 microseconds

Each CAN timing segment is formed from an integer number of time quanta.

5. Baud Rate Prescaler (BRP)

The BRP field divides the VPB clock to generate the CAN time quantum.

For the LPC2129:

CAN Clock = VPB Clock / (BRP + 1)

TQ = 1 / CAN Clock

Example

For a VPB clock of 15 MHz:

BRP FieldDividerCAN ClockTQ
0115 MHz66.67 ns
127.5 MHz133.33 ns
235 MHz200 ns
453 MHz333.33 ns
9101.5 MHz666.67 ns
The BTR register stores the BRP field value, not the divider directly. A BRP field value of 4 means division by 5.

6. Synchronization Segment (SYNC_SEG)

The synchronization segment is the first part of each nominal CAN bit.

  • It is one time quantum long.
  • It provides the expected timing reference for a bit transition.
  • CAN nodes use bus transitions to synchronize their internal timing.
SYNC_SEG = 1 TQ

7. Propagation Segment (PROP_SEG)

The propagation segment compensates for the time taken by signals to travel through the CAN network.

Propagation delay can arise from:

  • Bus cable length.
  • Transceiver propagation delay.
  • Signal path delays.
  • Network topology.

The propagation segment is included within the LPC2129 TSEG1 field together with PHASE_SEG1.

8. Phase Segment 1 (PHASE_SEG1)

PHASE_SEG1 is the portion of the bit before the sample point, following the propagation segment.

  • It helps compensate for phase errors.
  • It can be lengthened during synchronization.
  • It ends at the sample point.

The LPC2129 BTR does not provide separate register fields for PROP_SEG and PHASE_SEG1. They are combined into TSEG1.

9. Phase Segment 2 (PHASE_SEG2)

PHASE_SEG2 begins at the sample point and continues to the next nominal bit boundary.

  • It provides the remaining part of the nominal bit time.
  • It can be shortened during synchronization.
  • Its programmed duration is represented by TSEG2.

10. Sample Point

The sample point is the instant when the CAN controller reads the bus state to determine whether the current bit is dominant or recessive.

It occurs at the boundary between PHASE_SEG1 and PHASE_SEG2.

Sample Point Formula

Sample Point (%) =
[(1 + TSEG1_actual) / Total TQ] x 100

For LPC2129 BTR field values:

Sample Point (%) =
[(TSEG1_field + 2) /
 (TSEG1_field + TSEG2_field + 3)] x 100

Example

TSEG1 field = 10
TSEG2 field = 2

Sample Point =
[(10 + 2) / (10 + 2 + 3)] x 100

= 12 / 15 x 100

= 80%
A sample point of 80% means the controller samples the bus after 80% of the nominal bit duration has elapsed.

11. Synchronization Jump Width (SJW)

SJW defines the maximum amount by which the controller may adjust a phase segment during resynchronization.

It helps the CAN controller compensate for phase differences caused by oscillator tolerance and propagation effects.

SJW duration = (SJW field + 1) x TQ

Example

SJW field = 1

SJW = (1 + 1) TQ

SJW = 2 TQ

For a valid timing configuration, SJW must not exceed the programmed PHASE_SEG1 or PHASE_SEG2 duration, and it must remain within the controller's supported range.

12. Total Number of Time Quanta

The nominal CAN bit consists of:

Total TQ = SYNC_SEG + TSEG1_actual + TSEG2_actual

Total TQ = 1 + TSEG1_actual + TSEG2_actual

Since the LPC2129 BTR stores TSEG1 and TSEG2 as values one less than their actual time-quantum lengths:

Total TQ =
TSEG1_field + TSEG2_field + 3

The three additional quanta represent:

  • One quantum for SYNC_SEG.
  • One quantum added to the TSEG1 field.
  • One quantum added to the TSEG2 field.

13. CAN Baud Rate Formula for LPC2129

The nominal CAN bit rate is calculated using the VPB clock, BRP, TSEG1 and TSEG2.

CAN Bit Rate =
VPB Clock /
[(BRP + 1) x (TSEG1_field + TSEG2_field + 3)]

Bit time:

Bit Time = 1 / CAN Bit Rate

Important

The BRP, TSEG1 and TSEG2 values in the formula are the actual values stored in their respective BTR fields. The formula already accounts for the hardware's plus-one encoding.

14. LPC2129 CAN Bit Timing Register (BTR)

The CAN Bit Timing Register configures the timing parameters for a CAN controller.

For CAN1, the register is CAN1BTR. For CAN2, the corresponding register is CAN2BTR.

BTR Register Field Organization

BitsFieldDescription
9:0BRPBaud Rate Prescaler
13:10ReservedMust not be written as 1
15:14SJWSynchronization Jump Width
19:16TSEG1Propagation Segment + Phase Segment 1
22:20TSEG2Phase Segment 2
23SAMSampling mode
31:24ReservedMust not be written as 1

SAM Bit

SAMOperation
0Sample the bus once per bit
1Sample the bus three times per bit

Single sampling is recommended for high-speed buses. Triple sampling is intended for lower to medium-speed applications where the additional sampling behavior is appropriate.

15. BTR Register Configuration Restrictions

The LPC2129 BTR register can be written only while the corresponding CAN controller is in Reset Mode.

  • Set the controller's Reset Mode bit before changing BTR.
  • Do not write ones into reserved BTR bits.
  • Use supported BRP, SJW, TSEG1 and TSEG2 values.
  • Ensure SJW is compatible with the phase-segment lengths.
  • Leave Reset Mode after configuration is complete.
Changing BTR while the controller is in normal operating mode is not permitted. Configure timing before starting normal CAN communication.

16. Practical Calculation: 500 kbps at 15 MHz VPB

Assume the following project configuration:

VPB Clock = 15 MHz
Required CAN Bit Rate = 500 kbps

Step 1: Select BRP

Choose BRP field = 1.

CAN Clock = 15 MHz / (1 + 1)

CAN Clock = 7.5 MHz

TQ = 1 / 7.5 MHz

TQ = 133.33 ns

Step 2: Select TSEG1 and TSEG2

Choose:

TSEG1 field = 10
TSEG2 field = 2

Actual TSEG1 = 11 TQ
Actual TSEG2 = 3 TQ

Step 3: Calculate Total TQ

Total TQ = 1 + 11 + 3

Total TQ = 15

Step 4: Calculate Bit Rate

CAN Bit Rate = 7.5 MHz / 15

CAN Bit Rate = 500,000 bits/second

CAN Bit Rate = 500 kbps

Step 5: Calculate Sample Point

Sample Point = (1 + 11) / 15 x 100

Sample Point = 80%

Step 6: Select SJW

Choose SJW field = 0.

Actual SJW = 0 + 1

SJW = 1 TQ

Step 7: Calculate BTR Value

BRP   = 1
SJW   = 0
TSEG1 = 10
TSEG2 = 2
SAM   = 0

BTR = BRP
    | (SJW   << 14)
    | (TSEG1 << 16)
    | (TSEG2 << 20)

BTR = 0x002A0001
Calculated nominal bit rate: 500 kbps

17. Understanding the Existing Project BTR Value

The project configuration previously used the following CAN BTR value:

CAN1 BTR = 0x00364004

VPB Clock = 15 MHz

Decode the value using the LPC2129 BTR field positions:

BRP   = (BTR >> 0)  & 0x3FF = 4
SJW   = (BTR >> 14) & 0x03  = 1
TSEG1 = (BTR >> 16) & 0x0F  = 6
TSEG2 = (BTR >> 20) & 0x07  = 3
SAM   = (BTR >> 23) & 0x01  = 0

Calculate the CAN clock:

CAN Clock = 15 MHz / (4 + 1)

CAN Clock = 3 MHz

Calculate total TQ:

Total TQ = 6 + 3 + 3

Total TQ = 12

Calculate nominal bit rate:

CAN Bit Rate = 3 MHz / 12

CAN Bit Rate = 250,000 bits/second

CAN Bit Rate = 250 kbps

Calculate the sample point:

Sample Point = (6 + 2) / 12 x 100

Sample Point = 66.67%

Calculate SJW:

SJW = (1 + 1) TQ

SJW = 2 TQ
Under the LPC2129 BTR field definitions, the value 0x00364004 corresponds to a nominal 250 kbps bit rate with a 66.67% sample point when VPB is 15 MHz.

18. Embedded C: Configure CAN1 Bit Timing

The following example demonstrates the register configuration sequence for the 500 kbps calculation above.

#include <LPC21xx.h>

#define CAN_RESET_MODE   (1U << 0)

#define CAN_BTR_500K     0x002A0001U

int main(void)
{
    /*
       Enter CAN1 reset mode.
       BTR can only be written in reset mode.
    */
    C1MOD = CAN_RESET_MODE;

    /*
       Configure CAN1 bit timing:
       VPB clock = 15 MHz
       Nominal bit rate = 500 kbps
       BRP field = 1
       TSEG1 field = 10
       TSEG2 field = 2
       SJW field = 0
       Single sampling
    */
    C1BTR = CAN_BTR_500K;

    /*
       Additional CAN configuration is required:
       - Pin multiplexing
       - Acceptance filter
       - Transmit/receive setup
       - Interrupt configuration if required
    */

    /*
       Leave reset mode to begin normal operation.
    */
    C1MOD = 0x00U;

    while (1)
    {
        /* CAN application processing */
    }
}
This is a focused bit-timing example. A complete CAN application must also configure the CAN pins, acceptance filter, message handling and external transceiver. Confirm that the device header uses the C1MOD and C1BTR register names; some headers use CAN1MOD and CAN1BTR.

19. Selecting the Correct CAN Bit Rate

Common nominal CAN bit rates include:

Bit RateBit DurationTypical Context
10 kbps100 µsLow-speed networks
20 kbps50 µsLow-speed networks
50 kbps20 µsLow-speed applications
100 kbps10 µsIndustrial applications
125 kbps8 µsIndustrial CAN networks
250 kbps4 µsEmbedded control
500 kbps2 µsAutomotive and industrial CAN
1 Mbps1 µsHigh-speed Classical CAN

The actual usable bit rate depends on network length, cable characteristics, transceiver propagation delay, topology and timing margins.

20. Relationship Between CAN Bit Rate and Bus Length

CAN bit rate and network length are related through signal propagation delay.

  • Higher bit rates generally require shorter bus lengths.
  • Longer networks introduce greater propagation delay.
  • Transceiver delays must be included in timing analysis.
  • Branch lengths and topology affect signal quality.
  • Termination and cable impedance must be appropriate.
A bit-rate value cannot be selected independently of the physical CAN network. Check the transceiver datasheet and applicable physical-layer specifications before finalizing the design.

21. Single Sampling and Triple Sampling

The LPC2129 BTR SAM field selects how the CAN bus is sampled.

SAM ValueSampling Behavior
0One sample per bit
1Three samples per bit

Single Sampling

  • Samples the bus once at the defined sample point.
  • Recommended for high-speed buses.

Triple Sampling

  • Samples the bus three times per bit.
  • Intended for lower to medium-speed applications.
  • Does not replace correct electrical design or termination.

22. Common Bit Timing Configuration Errors

  • Using CCLK instead of VPB clock in the calculation.
  • Forgetting the plus-one encoding of BRP.
  • Forgetting the plus-one encoding of TSEG1 and TSEG2.
  • Using an incorrect total number of time quanta.
  • Choosing an unsuitable sample point.
  • Setting SJW larger than an allowed phase segment.
  • Writing BTR outside Reset Mode.
  • Writing ones into reserved BTR bits.
  • Configuring different bit rates on nodes sharing the same CAN bus.
  • Ignoring transceiver and cable propagation delays.

24. Interview Questions and Answers

Q1. What is CAN bit timing?

It defines the duration of a CAN bit and the point at which the controller samples the bus.

Q2. What is a Time Quantum?

The basic time unit used to construct a nominal CAN bit.

Q3. What is BRP?

The Baud Rate Prescaler divides the VPB clock to generate the CAN clock.

Q4. What is SJW?

Synchronization Jump Width defines the maximum phase adjustment during resynchronization.

Q5. What is TSEG1?

It combines the propagation segment and Phase Segment 1.

Q6. What is TSEG2?

It represents Phase Segment 2, which follows the sample point.

Q7. What is the sample point?

The point where the CAN controller samples the bus to determine the bit value.

Q8. What is the purpose of the BTR register?

It configures BRP, SJW, TSEG1, TSEG2 and sampling mode.

Q9. When can BTR be written?

When the CAN controller is in Reset Mode.

Q10. What is the CAN bit-rate formula for LPC2129?

VPB clock divided by (BRP + 1) multiplied by (TSEG1 field + TSEG2 field + 3).

Q11. What is the meaning of SAM = 1?

The controller samples the bus three times per bit.

Q12. Why must CAN nodes use compatible bit timing?

To ensure that all nodes correctly interpret bit boundaries and sample transmitted data.

27. Lesson Summary

  • CAN bit timing determines bit duration and the bus sampling point.
  • One nominal bit consists of SYNC_SEG, PROP_SEG, PHASE_SEG1 and PHASE_SEG2.
  • PROP_SEG and PHASE_SEG1 are combined in the LPC2129 TSEG1 field.
  • TSEG2 represents PHASE_SEG2.
  • BRP divides the VPB clock.
  • SJW controls synchronization adjustment.
  • The sample point occurs at the end of TSEG1.
  • The BTR register configures BRP, SJW, TSEG1, TSEG2 and SAM.
  • BTR can be written only in Reset Mode.
  • Correct bit timing is essential for reliable CAN communication.
