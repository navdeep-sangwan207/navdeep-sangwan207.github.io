Chapter 08: Introduction to LPC2129

Learn the architecture, features, memory organization, pin configuration, register structure, and clock generation of the LPC2129 ARM7 microcontroller.

Course: Embedded Systems Chapter: 08 Lessons: 11 Level: Intermediate

1. Chapter Overview

The LPC2129 is an ARM7TDMI-S-based 32-bit microcontroller from NXP. It combines a processor, on-chip Flash memory, SRAM, GPIO, communication peripherals, timers, ADC, and other hardware resources in a single device.

This chapter introduces the LPC2129 microcontroller and explains its internal architecture, hardware features, memory organization, pin configuration, register organization, and clock-generation system.

It also introduces the process of creating and configuring an LPC2129 project in Keil uVision.

Chapter goal: Develop a clear understanding of the LPC2129 hardware architecture and prepare for practical peripheral programming in the following chapters.

2. Learning Objectives

After completing this chapter, you will be able to:

  • Explain the LPC2129 microcontroller architecture.
  • Identify its major features and specifications.
  • Interpret the LPC2129 internal block diagram.
  • Understand pin configuration and alternate functions.
  • Explain the memory organization of LPC2129.
  • Differentiate Flash memory and SRAM.
  • Understand the processor and peripheral registers.
  • Explain system control and peripheral clock operation.
  • Understand PLL configuration and clock generation.
  • Calculate peripheral clock frequency using VPBDIV.
  • Create and configure an LPC2129 project in Keil uVision.

6. LPC2129 Development Configuration

The following clock configuration is used as the working reference for the LPC2129 exercises in this course.

Parameter Configuration
External oscillator frequency (FOSC) 12 MHz
CPU clock frequency (CCLK) 60 MHz
Peripheral clock frequency (PCLK) 15 MHz
PLL MSEL value 4
PLL PSEL value 2
FCCO 480 MHz
VPBDIV 4 (PCLK = CCLK / 4)
Important: These are the reference configuration values used in the course exercises. Actual clock configuration must respect the LPC2129 datasheet and PLL operating limits.
