1. Introduction

The Phase-Locked Loop (PLL) is an important part of the LPC2129 clock-generation system. It allows the microcontroller to generate a higher-frequency processor clock from an external oscillator reference.

Correct PLL configuration is essential because the CPU, timers, UART, PWM, and other peripherals depend on accurate clock frequencies.

Learning objectives:
  • Understand the working principle of a PLL.
  • Understand PLL multiplier and divider settings.
  • Learn the purpose of FCCO.
  • Identify LPC2129 PLL control and status registers.
  • Understand the PLL feed sequence.
  • Learn PLL lock detection and clock connection.
  • Understand the clock configuration used in the course project.

2. What Is a Phase-Locked Loop?

A Phase-Locked Loop is an electronic control system that generates an output signal whose phase and frequency are controlled relative to a reference signal.

In a microcontroller, a PLL can generate a higher-frequency clock from a lower-frequency oscillator reference.

Basic PLL block diagram

Reference Clock | v Phase Detector | v Loop Filter | v Voltage-Controlled Oscillator | +-----------> Output Clock | v Feedback | +----> Phase Detector

This is a conceptual PLL diagram. The actual LPC2129 PLL implementation and its programming interface are defined by the device documentation.

Functions of a PLL

  • Generates a configured clock frequency.
  • Uses an external reference frequency.
  • Maintains a controlled relationship between input and output.
  • Supports the required processor operating frequency.

3. LPC2129 PLL Clock Generation

LPC2129 uses an external oscillator as the reference for its internal PLL.

External Crystal | v Oscillator Circuit | v PLL Input | v Multiplier / Divider | v PLL Output Clock | v CCLK | v VPB Clock Divider | v PCLK

The PLL configuration determines the processor clock. The VPB divider separately determines the peripheral clock relationship.

4. PLL Multiplier (MSEL)

The PLL multiplier determines how the reference frequency is multiplied when generating the processor clock.

The simplified relationship is:

\[ CCLK = FOSC \times M \]

Where M is the effective multiplier, subject to the device's PLL configuration and operating limits.

Example

FOSC = 12 MHz
Effective multiplier = 5

CCLK = 12 x 5

CCLK = 60 MHz
The effective multiplier and the encoded MSEL field are not necessarily the same number. For LPC2129, the PLLCFG register uses an encoded multiplier field. Check the exact encoding in the device user manual.

5. PLL Divider (PSEL)

The PLL also uses a divider selection associated with its internal operating frequency.

This divider is used to keep the PLL internal operating frequency within the specified range.

It must not be confused with VPBDIV, which controls the peripheral bus clock.

Important distinction

Parameter Purpose
PSEL Selects the PLL internal divider used in determining FCCO.
VPBDIV Selects the peripheral clock division ratio relative to CCLK.
PSEL is part of PLL configuration. VPBDIV is part of peripheral clock configuration. They perform different functions.

6. FCCO – PLL Current Controlled Oscillator Frequency

FCCO is the internal PLL oscillator frequency used in the PLL frequency-generation system.

For LPC2129, the relationship is:

\[ FCCO = 2 \times CCLK \times P \]

Where P is the effective PLL post-divider selected through the PSEL field.

Example

CCLK = 60 MHz
Effective P = 4

FCCO = 2 x 60 x 4

FCCO = 480 MHz

The FCCO value must remain within the PLL's specified operating range.

FCCO is an internal PLL operating frequency. It is not the same as the external oscillator frequency, CPU clock, or peripheral clock.

7. LPC2129 PLL Registers

The PLL is configured using dedicated system control registers.

Register Function
PLLCON Enables the PLL and controls its connection to the processor clock.
PLLCFG Contains the multiplier and divider configuration fields.
PLLSTAT Provides PLL status, configuration, and lock information.
PLLFEED Accepts the required feed sequence to update PLL control and configuration.

8. PLLCON Register

PLLCON controls PLL enable and connection operations.

The important control bits are:

Bit Name Function
0 PLLE Enables the PLL.
1 PLLC Connects the PLL as the processor clock source.

Typical operating states

PLLE PLLC Meaning
0 0 PLL disabled and disconnected.
1 0 PLL enabled but not connected.
1 1 PLL enabled and connected.
The PLL should be enabled and allowed to lock before it is connected as the processor clock source.

9. PLLCFG Register

PLLCFG contains the configuration fields that determine the PLL multiplier and divider selections.

Its fields are commonly described as:

  • MSEL – PLL multiplier selection.
  • PSEL – PLL divider selection.

The actual register encoding must be interpreted according to the LPC2129 user manual.

Do not write an assumed effective multiplier directly into the MSEL field. The field uses a device-defined encoding, and the effective values must be calculated from that encoding.

10. PLLSTAT Register and Lock Detection

PLLSTAT provides status information about the PLL.

One important status bit is PLOCK. It indicates whether the PLL has achieved its locked condition.

Status Meaning
PLOCK = 0 PLL has not reported lock.
PLOCK = 1 PLL reports that it is locked.

Why is lock detection important?

  • Ensures the PLL has reached its locked condition.
  • Prevents premature connection to the CPU clock.
  • Supports reliable clock initialization.

11. PLLFEED Register and Feed Sequence

After modifying PLLCON or PLLCFG, LPC2129 requires a specific feed sequence through the PLLFEED register.

The two required feed values are: 

PLLFEED = 0xAA;
PLLFEED = 0x55;

These values must be written in the required order to make the PLL configuration update effective.

Why is the feed sequence required?

The feed mechanism protects PLL control and configuration changes from accidental or incomplete writes.

The sequence must be performed as specified by the manufacturer. Writing only one feed value is insufficient.

12. PLL Configuration Procedure

A typical PLL configuration process follows these stages:

  1. Configure the PLL multiplier and divider fields.
  2. Apply the required feed sequence.
  3. Enable the PLL through PLLCON.
  4. Apply the feed sequence again.
  5. Wait until PLLSTAT indicates lock.
  6. Set the PLL connection control bit.
  7. Apply the feed sequence again.
  8. Configure the peripheral clock divider separately.
Configure PLLCFG | v PLL Feed | v Enable PLL | v PLL Feed | v Wait for PLOCK | v Connect PLL to CPU | v PLL Feed | v Configure VPBDIV

The precise startup sequence and any required oscillator or timing considerations must be checked against the LPC2129 documentation.

Calculations

These are effective PLL values for the example. The exact MSEL and PSEL register field encodings must be derived from the LPC2129 PLLCFG register definition.

14. Embedded C Example – PLL Feed Sequence

The following small example demonstrates the required feed sequence using the device header file. 

#include <LPC21xx.h>

void PLL_Feed(void)
{
    PLLFEED = 0xAA;
    PLLFEED = 0x55;
}

int main(void)
{
    // Example: issue the feed sequence
    PLL_Feed();

    while (1)
    {
        // Main application
    }
}

This example demonstrates only the feed sequence. It does not configure or enable the complete PLL.

A complete PLL initialization routine must use the correct LPC2129 PLLCFG field values, feed sequence, enable operation, lock detection, and connection procedure. Do not use this isolated example as a complete clock initialization program.

15. PLL Configuration Errors

Error Possible Result
Incorrect MSEL encoding Unexpected processor clock.
Incorrect PSEL encoding FCCO outside the intended range.
Missing feed sequence PLL changes may not take effect.
Not waiting for PLOCK PLL may be connected before lock.
Incorrect connection sequence Unreliable clock startup.
Incorrect VPBDIV setting Peripheral timing calculations become incorrect.

16. Keil uVision Simulator Activity

Use the Keil uVision simulator to inspect the software-visible PLL configuration.

  1. Open the LPC2129 project.
  2. Build the project.
  3. Start the simulator debugger.
  4. Open the Watch window.
  5. Add PLLCON, PLLCFG, PLLSTAT, and PLLFEED.
  6. Step through the PLL initialization routine.
  7. Observe the register values after each operation.
  8. Check the PLOCK status when supported by the simulator.
Simulator behavior may not reproduce every clock-startup characteristic of physical hardware. Do not interpret a simulated register value as a physical measurement of the oscillator or PLL output.

17. Interview Questions and Answers

Q1. What is PLL?

PLL stands for Phase-Locked Loop. It is used to generate a configured clock frequency from a reference signal.

Q2. What is MSEL?

MSEL is the PLL multiplier selection field.

Q3. What is PSEL?

PSEL selects the PLL internal divider used in determining FCCO.

Q4. What is FCCO?

FCCO is the internal PLL oscillator frequency.

Q5. What is the purpose of PLLCON?

It controls PLL enable and connection operations.

Q6. What is the purpose of PLLCFG?

It stores PLL multiplier and divider configuration fields.

Q7. What is PLOCK?

It is the PLL lock status indication.

Q8. Why is PLLFEED required?

It applies the required feed sequence to make PLL configuration changes effective.

Q9. What is the PLL feed sequence?

Write 0xAA followed by 0x55 to PLLFEED.

Q10. What is the difference between PSEL and VPBDIV?

PSEL controls the PLL internal divider selection, whereas VPBDIV controls the peripheral clock division ratio.

Q11. What is the configured CCLK in this course example?

60 MHz.

Q12. What is the configured PCLK in this course example?

15 MHz.
