1. Introduction

The LPC2129 is a 32-bit microcontroller based on the ARM7TDMI-S processor core. It belongs to the LPC2000 family developed by Philips Semiconductors, now part of NXP Semiconductors.

It integrates processing, memory, digital input/output, analog conversion, timers, communication interfaces, and interrupt-control hardware into a single device.

Understanding its features and specifications is important when selecting the microcontroller for an embedded application and configuring its hardware.

Learning objectives:
  • Identify the major LPC2129 hardware features.
  • Understand its processor and memory specifications.
  • Learn about its GPIO and communication interfaces.
  • Understand its timer, PWM, ADC, and interrupt features.
  • Study its clock and power-related specifications.
  • Relate device specifications to practical applications.

3. ARM7TDMI-S Processor Features

The LPC2129 uses the ARM7TDMI-S processor core, which executes the firmware instructions and controls the operation of the microcontroller.

Important processor features

  • 32-bit RISC processor architecture.
  • 32-bit general-purpose register organization.
  • ARM instruction-set support.
  • 16-bit Thumb instruction-set support.
  • Hardware multiplication support.
  • Embedded debugging support.
  • Exception and interrupt handling.
  • Three-stage instruction pipeline.

ARM and Thumb instruction sets

ARM State Thumb State
Uses 32-bit instructions. Uses 16-bit Thumb instructions.
Provides a larger instruction set. Provides more compact instruction encoding.
Useful for general processing operations. Can improve code density.
The processor architecture is studied in detail in the ARM architecture and ARM7TDMI-S chapters.

4. Memory Specifications

The LPC2129 contains on-chip Flash memory and SRAM for program storage and runtime data.

Memory Type Capacity Purpose
Flash 256 KB Stores firmware and non-volatile data.
SRAM 16 KB Stores variables, stack, and temporary data.

Flash memory

Flash memory is non-volatile. It retains its contents when the microcontroller is switched off. The application firmware is normally stored in Flash.

SRAM

SRAM is volatile memory used during program execution. It stores runtime variables, buffers, stack information, and other temporary data.

Flash and SRAM capacities are different from the address-space size of the ARM processor. The complete memory map is covered in a later lesson.

5. GPIO Features

GPIO stands for General Purpose Input/Output. The LPC2129 provides up to 46 GPIO pins, subject to package and alternate-function configuration.

GPIO operations

  • Digital input reading.
  • Digital output control.
  • LED interfacing.
  • Push-button and switch interfacing.
  • External digital signal monitoring.
  • Basic control of external digital circuits.

Example: LED control concept

LPC2129 GPIO Pin | v Current-Limiting Resistor | v LED | GND

A GPIO output can be programmed to produce a logic-high or logic-low level. The external LED circuit must be designed with suitable current limiting and pin electrical limits.

LPC2129 pins have multiplexed functions. The PINSEL registers must be configured correctly before using a pin as GPIO or as a peripheral signal.

6. Communication Interfaces

Communication peripherals allow the LPC2129 to exchange information with external devices.

6.1 UART

LPC2129 contains two UART interfaces: UART0 and UART1. They support asynchronous serial data transmission and reception.

  • UART0 transmit pin: TXD0, P0.0.
  • UART0 receive pin: RXD0, P0.1.
  • UART1 transmit pin: TXD1, P0.8.
  • UART1 receive pin: RXD1, P0.9.

UART is commonly used for serial terminals, debugging, and communication with other controllers.

6.2 I2C

The I2C interface provides two-wire synchronous serial communication using SDA and SCL signals.

It is commonly used to connect sensors, EEPROMs, real-time clocks, and other compatible devices.

6.3 SPI

SPI is a synchronous serial communication interface commonly used for high-speed communication with external peripheral devices.

6.4 CAN

The LPC2129 provides two CAN controller interfaces. CAN is commonly used in automotive and industrial communication networks.

The CAN controller handles CAN protocol functions. An external CAN transceiver is required to connect the controller to the physical differential CAN bus.
Interface Communication Type Common Application
UART Asynchronous serial Debugging and serial terminals
I2C Synchronous, two-wire Sensors and EEPROMs

7. Timer and Counter Features

LPC2129 provides two 32-bit general-purpose timer/counter units, Timer 0 and Timer 1.

Important timer functions

  • Time-delay generation.
  • Time-interval measurement.
  • Event counting.
  • Match-based interrupt generation.
  • Periodic event generation.

8. PWM Features

PWM stands for Pulse Width Modulation. It is used to control the average power delivered to a load by changing the pulse width.

LPC2129 provides six-channel PWM capability. PWM is useful for motor control and other power-control applications.

PWM parameters

  • Period: Total duration of one PWM cycle.
  • Frequency: Number of PWM cycles per second.
  • Duty cycle: Percentage of the period for which the output is active.

Duty cycle is calculated as:

\[ D = \frac{T_{ON}}{T_{PERIOD}}\times100\% \]

Example

If the output remains active for 4 ms during a 10 ms period:

\[ D = \frac{4}{10}\times100=40\% \]

The PWM duty cycle is 40%.

PWM output is a digital pulse signal. Actual motor power control requires an appropriate driver circuit and power stage.

9. ADC Features

ADC stands for Analog-to-Digital Converter. The LPC2129 includes a 10-bit ADC with multiple analog input channels.

ADC resolution

A 10-bit ADC produces:

\[ 2^{10}=1024 \]

possible digital output levels, from 0 to 1023.

Voltage conversion concept

For an ideal unipolar ADC with reference voltage \(V_{REF}\), the approximate conversion relationship is:

\[ ADC\ Code \approx \frac{V_{IN}}{V_{REF}}\times1023 \]

The exact conversion behavior and input limits depend on the ADC specifications and operating conditions.

Applications

  • Temperature measurement.
  • Voltage monitoring.
  • Sensor signal acquisition.
  • Analog control systems.
  • Measurement and instrumentation.
LPC2129 includes an ADC but does not have an integrated DAC. An external DAC is required for digital-to-analog output.

10. Interrupt Controller Features

The LPC2129 uses a Vectored Interrupt Controller (VIC) to manage interrupt requests from internal and external sources.

Important functions

  • Interrupt source management.
  • Interrupt enable and disable control.
  • Vectored interrupt handling.
  • Priority-based interrupt servicing.
  • Support for fast interrupt handling.
Peripheral Event | v Interrupt Request | v VIC | Priority Selection | v ARM7 Processor | v Interrupt Handler

The VIC reduces the software effort required to identify and service interrupt sources.

11. Clock and Operating Frequency

The LPC2129 contains a PLL that allows the processor clock to be generated from an external oscillator reference.

The device supports CPU operation up to 60 MHz, subject to the documented operating conditions.

Reference configuration used in this course

Parameter Value
External oscillator (FOSC) 12 MHz
CPU clock (CCLK) 60 MHz
Peripheral clock (PCLK) 15 MHz
VPBDIV setting 4

With CCLK at 60 MHz and the peripheral clock divider set to 4:

\[ PCLK=\frac{CCLK}{4} \] \[ PCLK=\frac{60}{4}=15\text{ MHz} \]
This is the reference configuration for the course examples. PLL register encoding and initialization must be checked against the LPC2129 user manual.

12. Power and Reset Features

Power management

The LPC2129 provides power-saving operating modes intended to reduce power consumption when the processor does not need to execute continuously.

Reset system

Reset initializes the microcontroller into a defined startup state. The startup sequence prepares the processor and system before the main application executes.

Important considerations

  • Use a suitable regulated power supply.
  • Follow the recommended reset circuit design.
  • Observe the device's electrical limits.
  • Use correct clock and startup configuration.
  • Consult the datasheet for voltage and timing requirements.

14. Common Mistakes

  1. Assuming the CPU clock and peripheral clock are always equal.
  2. Confusing Flash memory with SRAM.
  3. Assuming every physical pin is available as GPIO.
  4. Ignoring the alternate functions of multiplexed pins.
  5. Assuming a 10-bit ADC produces 1024 as its maximum output code; the maximum code is 1023.
  6. Confusing PWM output with a true analog voltage output.
  7. Assuming the CAN controller can directly drive a physical CAN bus.
  8. Assuming an ADC peripheral means the microcontroller also has a DAC.
  9. Using clock values without checking device operating limits.

15. Interview Questions and Answers

Q1. Which processor core is used in LPC2129?

ARM7TDMI-S.

Q2. What is the maximum CPU clock frequency?

Up to 60 MHz under the specified operating conditions.

Q3. How much Flash memory is available?

256 KB of on-chip Flash memory.

Q4. How much SRAM is available?

16 KB of on-chip SRAM.

Q5. How many UART interfaces are available?

Two: UART0 and UART1.

Q6. What is the ADC resolution?

10 bits, providing 1024 possible output levels.

Q7. How many general-purpose timers are available?

Two 32-bit general-purpose timer/counter units.

Q8. What is the purpose of PWM?

PWM controls the duty cycle of a digital pulse output and is used in applications such as motor control.

Q9. What does VIC stand for?

Vectored Interrupt Controller.

Q10. How many CAN controllers are available?

Two CAN controller interfaces.

Q11. Does LPC2129 have an integrated DAC?

No. An external DAC is required for digital-to-analog conversion.

Q12. What is the purpose of VPBDIV?

It selects the peripheral clock relationship to the CPU clock.

Q13. What is the purpose of the PLL?

It generates the processor clock from the external oscillator reference.

Q14. What is the difference between GPIO and PWM?

GPIO provides general digital input/output, while PWM generates a periodic pulse waveform with a controlled duty cycle.

Q15. Why are peripheral pin functions important?

Because a physical pin may support multiple functions, and the appropriate pin-selection configuration is needed to use the intended peripheral.

  • It is a 32-bit microcontroller.

  • It includes two UARTs, one I2C, one SPI, and two CAN controllers.
