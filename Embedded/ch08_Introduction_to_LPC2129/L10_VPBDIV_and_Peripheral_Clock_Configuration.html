1. Introduction

LPC2129 uses a peripheral clock system to provide timing signals to on-chip peripheral modules.

The VPBDIV register controls the relationship between the processor clock (CCLK) and the peripheral clock (PCLK).

Correct peripheral clock configuration is essential for accurate UART communication, timer operation, PWM generation, ADC timing, and other peripheral functions.

Learning objectives:
  • Understand the purpose of the VPB bus.
  • Understand the VPBDIV register.
  • Learn the available clock division settings.
  • Calculate PCLK from CCLK.
  • Understand the effect of PCLK on peripherals.
  • Configure and inspect VPBDIV in Embedded C.

2. What Is the VPB Bus?

VPB stands for VLSI Peripheral Bus. It is the peripheral bus interface used by several on-chip LPC2129 peripheral modules.

The processor communicates with peripheral registers through the microcontroller's internal bus architecture.

ARM7TDMI-S | v CCLK | v VPB Clock Divider | v PCLK | +-------+-------+ | | | v v v UART Timers Other Peripherals

Why is the VPB clock important?

  • Provides timing to VPB-connected peripherals.
  • Determines timer counter input frequency.
  • Influences UART baud-rate generation.
  • Is used in peripheral timing calculations.
  • Allows peripheral timing to differ from CPU timing.

3. CCLK and PCLK

Two important clock signals in LPC2129 are CCLK and PCLK.

Parameter Description
CCLK Clock supplied to the ARM processor core.
PCLK Clock supplied to VPB-connected peripheral modules.

Example

CCLK = 60 MHz
PCLK = 15 MHz

In this configuration, the processor operates with a 60 MHz clock while VPB-connected peripherals receive a 15 MHz clock.

Do not automatically use CCLK in every peripheral timing calculation. Check the clock source specified for the peripheral being configured.

4. VPBDIV Register

VPBDIV is an 8-bit peripheral clock divider register. Its two least significant bits select the relationship between CCLK and PCLK.

Register field

VPBDIV Register Bit: 7 6 5 4 3 2 1 0 ----------------- Reserved | VPBDIV | 1:0

The VPBDIV field is located at bits 1:0. The remaining bits are reserved.

VPBDIV settings

VPBDIV[1:0] Peripheral Clock Meaning
00 PCLK = CCLK / 4 Peripheral clock is one-fourth of CCLK.
01 PCLK = CCLK Peripheral clock equals CCLK.
10 PCLK = CCLK / 2 Peripheral clock is half of CCLK.
11 Reserved Do not use this setting.

5. VPBDIV Clock Selection

Option 1: Divide by Four

VPBDIV = 0x00;

PCLK = CCLK / 4;

The peripheral clock operates at one-fourth of the processor clock.

Option 2: Same as CCLK

VPBDIV = 0x01;

PCLK = CCLK;

The peripheral clock operates at the same frequency as the processor clock.

Option 3: Divide by Two

VPBDIV = 0x02;

PCLK = CCLK / 2;

The peripheral clock operates at half the processor clock frequency.

The register value 0x03 selects a reserved encoding. Do not use it as a divide-by-three setting.

6. PCLK Calculation Examples

Example 1: Divide by Four

7. Peripheral Clock Configuration in Embedded C

The VPBDIV register can be configured using the LPC2129 device header file.

Example 1: Configure PCLK = CCLK / 4

#include <LPC21xx.h>

int main(void)
{
    VPBDIV = 0x00;

    while (1)
    {
        // Main application
    }
}

Example 2: Configure PCLK = CCLK

#include <LPC21xx.h>

int main(void)
{
    VPBDIV = 0x01;

    while (1)
    {
        // Main application
    }
}

Example 3: Configure PCLK = CCLK / 2

#include <LPC21xx.h>

int main(void)
{
    VPBDIV = 0x02;

    while (1)
    {
        // Main application
    }
}
These examples configure only VPBDIV. They assume that the processor clock has already been configured correctly.

8. Reading the VPBDIV Register

The VPBDIV register can also be read to inspect its current configuration. 

#include <LPC21xx.h>

unsigned int Get_VPBDIV(void)
{
    return VPBDIV & 0x03;
}

int main(void)
{
    unsigned int divider_setting;

    divider_setting = Get_VPBDIV();

    while (1)
    {
        // Inspect divider_setting
    }
}

The function returns the two-bit divider selection field.

Returned Value Meaning
0 PCLK = CCLK / 4
1 PCLK = CCLK
2 PCLK = CCLK / 2
3 Reserved setting

9. Effect of PCLK on UART

UART baud-rate generation depends on the peripheral clock supplied to the UART.

With the fractional divider disabled, the simplified baud-rate equation is:

\[ Baud = \frac{PCLK}{16 \times D} \]

Where D is the UART divisor.

Example

PCLK = 15 MHz
D = 98

Baud = 15000000 / (16 x 98)

Baud = 9566.3 approximately

The actual baud rate must be calculated from the selected divisor and fractional divider configuration.

If VPBDIV changes, PCLK may change. UART baud-rate configuration must then be reviewed and recalculated.

10. Effect of PCLK on Timers

The LPC2129 timer counter uses the peripheral clock and prescaler to determine its counting rate.

The counter increment frequency is:

\[ f_{TC} = \frac{PCLK}{PR+1} \]

Example

PCLK = 15 MHz
PR = 14999

fTC = 15000000 / 15000

fTC = 1000 Hz

The timer counter increments once every millisecond.

If PCLK changes while PR remains unchanged, the timer counter frequency also changes.

11. Effect of PCLK on Other Peripherals

Peripheral Clock-related effect
UART Baud-rate generation.
Timers Counter frequency and time intervals.
PWM PWM timing and output frequency.
ADC ADC clock configuration and conversion timing.
I2C Serial clock timing configuration.
Individual peripherals may have additional clock controls, divisors, or timing limits. Always use the relevant peripheral chapter and the LPC2129 User Manual when calculating their operating parameters.

12. Course Project Clock Configuration

The following clock values are used in the LPC2129 project configuration for this course.

Parameter Value
External oscillator (FOSC) 12 MHz
Processor clock (CCLK) 60 MHz
Peripheral clock (PCLK) 15 MHz
VPBDIV register value 0x00
VPBDIV selection CCLK / 4

Configuration code

#include <LPC21xx.h>

void Peripheral_Clock_Init(void)
{
    VPBDIV = 0x00;
}

int main(void)
{
    Peripheral_Clock_Init();

    while (1)
    {
        // Application code
    }
}

With the assumed 60 MHz processor clock, the peripheral clock is: 

PCLK = 60 MHz / 4
PCLK = 15 MHz
This function configures the peripheral divider only. It does not configure the oscillator or PLL.

13. Keil uVision Simulator Activity

You can inspect VPBDIV configuration using the Keil uVision simulator.

Procedure

  1. Open the LPC2129 project.
  2. Build the project successfully.
  3. Start the simulator debugger.
  4. Open the Watch window.
  5. Add the VPBDIV register.
  6. Step through Peripheral_Clock_Init().
  7. Observe the register value.
  8. Confirm that the two least significant bits are 00.
  9. Calculate PCLK using the configured CCLK value.

Expected software-visible result

VPBDIV = 0x00
CCLK   = 60 MHz

PCLK   = 15 MHz
The calculated PCLK is based on the configured clock values. The simulator does not provide a physical measurement of the clock signal.

14. Common Mistakes

  1. Confusing PCLK with CCLK.
  2. Using the wrong VPBDIV encoding.
  3. Using the reserved VPBDIV value 0x03.
  4. Forgetting to update UART baud-rate calculations after changing PCLK.
  5. Using an old timer prescaler after changing PCLK.
  6. Assuming VPBDIV configures the PLL.
  7. Assuming all peripheral modules have identical clock requirements.
  8. Ignoring peripheral-specific maximum clock limits.

15. Interview Questions and Answers

Q1. What is VPBDIV?

VPBDIV is the peripheral bus clock divider register in LPC2129.

Q2. What does PCLK represent?

PCLK is the clock supplied to VPB-connected peripheral modules.

Q3. What is the purpose of the VPB bus?

It provides the bus interface for communication with peripheral modules.

Q4. What are the three valid VPBDIV settings?

00 for divide-by-four, 01 for the same clock as CCLK, and 10 for divide-by-two.

Q5. What happens when VPBDIV is set to 0x00?

PCLK becomes one-fourth of CCLK.

Q6. What happens when VPBDIV is set to 0x01?

PCLK becomes equal to CCLK.

Q7. What happens when VPBDIV is set to 0x02?

PCLK becomes half of CCLK.

Q8. What is the reserved VPBDIV encoding?

0x03.

Q9. Why is PCLK important for UART?

UART baud-rate generation depends on its peripheral clock.

Q10. Why is PCLK important for timers?

It determines the timer counter input frequency after prescaling.

Q11. If CCLK is 60 MHz and VPBDIV is 0x02, what is PCLK?

30 MHz.

Q12. Does VPBDIV configure the PLL?

No. It configures the peripheral clock division ratio.
