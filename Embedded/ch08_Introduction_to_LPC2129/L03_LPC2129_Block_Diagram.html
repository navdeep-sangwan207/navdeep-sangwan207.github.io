1. Introduction

A microcontroller block diagram represents the major functional units of a microcontroller and shows how they work together.

The LPC2129 is a 32-bit ARM7TDMI-S-based microcontroller. It integrates a processor core, memory, internal bus architecture, input/output interfaces, communication peripherals, timers, analog conversion, and system-control circuitry.

Understanding its block diagram helps an embedded developer understand how instructions are executed, how data moves between functional units, and how external devices communicate with the processor.

Learning objectives:
  • Understand the functional organization of LPC2129.
  • Identify the ARM7TDMI-S processor core.
  • Understand the memory subsystem and internal buses.
  • Identify the major peripheral blocks.
  • Understand clock, reset, and interrupt control.
  • Trace the flow of data through the microcontroller.

3. ARM7TDMI-S Processor Core

The ARM7TDMI-S processor is the central processing unit of LPC2129. It executes the program stored in memory and controls the operation of the peripheral devices.

Major internal components

Component Function
ALU Performs arithmetic and logical operations.
Register set Stores operands, addresses, and intermediate results.
Instruction decoder Interprets instructions fetched from memory.
Control unit Coordinates instruction execution and data movement.
Barrel shifter Supports shifting and rotation operations used by ARM instructions.
Multiplier Supports multiplication operations.

Processor operation

The processor generally performs the following instruction-cycle operations:

Instruction Fetch | v Instruction Decode | v Instruction Execute | v Result / Writeback

The ARM7TDMI-S uses a three-stage pipeline: fetch, decode, and execute. This allows different instructions to occupy different pipeline stages at the same time.

4. Memory Subsystem

The memory subsystem stores program instructions and application data.

4.1 Flash Memory

  • Non-volatile memory.
  • Stores firmware and program instructions.
  • Retains contents when power is removed.
  • On-chip capacity: 256 KB.

4.2 SRAM

  • Volatile memory.
  • Stores temporary runtime data.
  • Used for variables, stack, and buffers.
  • On-chip capacity: 16 KB.
MEMORY SUBSYSTEM | +-------+-------+ | | v v FLASH MEMORY SRAM MEMORY 256 KB 16 KB | | v v Program Runtime Code Data

Memory access example

When the processor executes a program, it fetches instructions from the program memory and uses SRAM to store temporary data. 

int main(void)
{
    unsigned int count = 10;

    count = count + 5;

    while (1)
    {
        // Application loop
    }
}

In this example, the variable count is a runtime object. Its storage location is determined by the compiler and linker.

5. Internal Bus Architecture

Internal buses provide communication paths between the processor, memory, and peripheral subsystems.

Purpose of internal buses

  • Transfer instructions and data.
  • Provide access to memory locations.
  • Allow the CPU to access peripheral registers.
  • Coordinate communication between functional units.

Basic bus concept

+----------------+ | CPU | +--------+-------+ | Internal Bus | +------------+------------+ | | v v +---------+ +------------+ | Memory | | Peripherals| +---------+ +------------+

Three common bus signal groups

Bus Purpose
Address bus Identifies the memory location or peripheral register being accessed.
Data bus Carries the data being transferred.
Control signals Indicate the type and timing of a bus operation.
This is a general explanation of bus functions. It should not be interpreted as a complete LPC2129-specific bus topology.

6. GPIO Block

The GPIO block provides digital input and output functionality.

GPIO functions

  • Read digital input signals.
  • Set digital output levels.
  • Clear output levels.
  • Control external digital circuits.
  • Interface with LEDs, switches, and logic devices.

GPIO data flow

External Switch | v GPIO Input | v LPC2129 CPU | v GPIO Output | v External LED

The processor reads the switch state and controls the output according to the firmware.

GPIO pins share functions with other peripherals. Correct PINSEL configuration is required before using the intended pin function.

7. Communication Peripheral Blocks

LPC2129 provides several communication interfaces for exchanging data with external devices.

7.1 UART0 and UART1

The UART blocks support asynchronous serial communication. They are commonly used for debugging, serial terminals, and controller-to-controller communication.

7.2 I2C

The I2C block supports two-wire communication using serial data (SDA) and serial clock (SCL).

7.3 SPI

The SPI block supports synchronous serial data transfer with external devices.

7.4 CAN controllers

The CAN controllers support communication using the Controller Area Network protocol. A physical CAN connection requires an external transceiver.

Peripheral Main purpose Example
UART Asynchronous serial data transfer Debug terminal
I2C Two-wire serial communication Temperature sensor
SPI Synchronous serial communication External memory
CAN Network-based communication Industrial controller network

8. Timer and Counter Blocks

LPC2129 contains Timer 0 and Timer 1. These are 32-bit general-purpose timer/counter units.

Timer block functions

  • Generate time delays.
  • Measure time intervals.
  • Generate match events.
  • Generate timer interrupts.
  • Count external events in counter mode.
Peripheral Clock | v Prescaler | v Timer Counter | v Match Registers | v Match Control | v Interrupt / Output

A timer can generate a periodic event that allows the processor to perform an operation at a defined interval.

9. PWM Block

The PWM block generates pulse-width-modulated output signals. These signals can be used to control external power circuits.

PWM applications

  • DC motor speed control.
  • LED brightness control.
  • Power converter control signals.
  • Actuator control.
PWM Match Registers | v PWM Controller | v PWM Output Pin | v External Driver Circuit | v Motor
The PWM peripheral generates the control waveform. It does not directly provide the power required to drive a motor.

10. ADC Block

The ADC block converts analog input voltages into digital values for processing by the CPU.

ADC operation

Analog Sensor | v Analog Input | v LPC2129 ADC | v Digital Conversion | v CPU Processing | v Application Output

The LPC2129 ADC has 10-bit resolution. Its output code ranges from 0 to 1023.

Example: for an ideal 10-bit conversion with a 3.3 V reference, an input near half the reference voltage produces a digital result near 512.

Actual ADC readings depend on the reference voltage, input range, conversion characteristics, and electrical conditions.

11. Vectored Interrupt Controller (VIC)

The VIC manages interrupt requests generated by internal peripherals and external interrupt sources.

VIC responsibilities

  • Manage interrupt sources.
  • Enable and disable interrupt channels.
  • Support interrupt priority and vector selection.
  • Provide interrupt information to the processor.
UART / Timer / External Event | v Interrupt Request | v VIC | v ARM7TDMI-S CPU | v Interrupt Handler

For example, when a timer generates an enabled interrupt request, the VIC manages the request and the processor executes the associated interrupt service routine.

12. Clock and System Control Block

The clock and system-control circuitry provides timing and initialization functions required by the microcontroller.

Important components

  • External oscillator interface.
  • Phase-Locked Loop (PLL).
  • Peripheral clock divider (VPBDIV).
  • Reset control.
  • Power management controls.

Course reference clock configuration

External Crystal 12 MHz | v PLL | v CPU Clock (CCLK) 60 MHz | v VPBDIV = 4 | v Peripheral Clock 15 MHz

The CPU and peripheral blocks use clock signals according to their operating requirements.

Clock initialization must follow the documented PLL feed sequence and lock requirements. Detailed configuration is covered later in this chapter.

13. How the Functional Blocks Work Together

Consider a temperature monitoring application using an analog temperature sensor and UART output.

System operation

  1. The clock system provides operating clocks.
  2. The CPU executes the firmware stored in Flash.
  3. The ADC receives the sensor voltage.
  4. The ADC converts the voltage into a digital value.
  5. The CPU reads and processes the conversion result.
  6. The UART transmits the calculated temperature to a terminal.
  7. A timer may periodically trigger the next measurement.
Temperature Sensor | v ADC | v ARM7TDMI-S CPU / \ / \ v v Timer UART | | v v Periodic Serial Terminal Measurement Output

This example demonstrates how multiple hardware blocks cooperate to perform one embedded application.

15. Common Mistakes

  1. Confusing the processor core with the complete microcontroller.
  2. Assuming every peripheral communicates directly with every other peripheral.
  3. Confusing Flash memory and SRAM functions.
  4. Ignoring the role of internal buses.
  5. Assuming GPIO and alternate peripheral functions can be used simultaneously on the same pin.
  6. Confusing PWM output with analog voltage generation.
  7. Assuming the VIC executes application code instead of managing interrupt requests.
  8. Assuming the simplified functional diagram represents every internal connection.

16. Interview Questions and Answers

Q1. What is a microcontroller block diagram?

It is a functional representation showing the major hardware components and their relationships.

Q2. Which processor core is used in LPC2129?

ARM7TDMI-S.

Q3. What is the purpose of the ALU?

It performs arithmetic and logical operations required by the processor.

Q4. What is the function of Flash memory?

Flash memory stores firmware and retains its contents without power.

Q5. What is the function of SRAM?

SRAM stores temporary runtime data such as variables, stack information, and buffers.

Q6. What is the purpose of the internal bus?

It provides communication paths for transferring data, addresses, and control information.

Q7. What is the function of the GPIO block?

It provides digital input and output functionality.

Q8. What is the purpose of the ADC block?

It converts analog input signals into digital values.

Q9. What is the purpose of the VIC?

It manages interrupt requests and supports vectored interrupt servicing.

Q10. What is the function of the PLL?

It generates the required processor clock from an external reference clock.

Q11. Why are timers used in embedded systems?

Timers generate delays, measure intervals, count events, and trigger periodic operations.

Q12. What is the role of PWM?

PWM generates pulse signals with controlled duty cycles for control applications.

Q13. Which peripheral is used for asynchronous serial communication?

UART.

Q14. How do the CPU and peripherals communicate?

The CPU accesses peripheral registers through the microcontroller's internal bus and memory-mapped peripheral interface.

Q15. Why is understanding the block diagram important?

It helps developers understand the hardware organization, peripheral dependencies, clocking, memory access, and data flow before writing firmware.
