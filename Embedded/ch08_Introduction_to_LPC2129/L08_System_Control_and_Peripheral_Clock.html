1. Introduction

The clock system is one of the most important parts of a microcontroller. It provides timing signals required by the CPU, memory interface, and peripheral hardware.

LPC2129 uses a clock-generation system that includes an external oscillator, Phase-Locked Loop (PLL), and peripheral clock control.

System control functions also manage important operating conditions such as reset, clock configuration, and peripheral operation.

Learning objectives:
  • Understand the LPC2129 clock system.
  • Differentiate oscillator, CCLK, and PCLK.
  • Understand the role of the PLL.
  • Learn the purpose of VPBDIV.
  • Understand peripheral clock requirements.
  • Identify important system control registers.

2. What Is a System Clock?

A system clock is a periodic timing signal used to synchronize operations inside a microcontroller.

The clock determines how frequently synchronous digital circuits can perform their operations.

Why is the clock important?

  • Controls processor operating frequency.
  • Synchronizes instruction execution.
  • Provides timing references for peripherals.
  • Determines timer counting speed.
  • Affects UART baud-rate generation.
  • Influences power consumption and performance.
Clock Signal __ __ __ __ __ | | | | | | | | | | ____| |__| |__| |__| |__| |____ One complete cycle = One clock period

Frequency is the number of clock cycles occurring per second.

\[ f = \frac{1}{T} \]

Where:

  • f = Frequency in hertz.
  • T = Time period in seconds.

For example, a 12 MHz clock has a period of approximately 83.33 nanoseconds.

3. LPC2129 Clock Architecture

LPC2129 uses an external clock source and an internal PLL-based clock-generation arrangement to obtain the processor clock.

Important clock signals

Clock Meaning
FOSC External oscillator frequency.
CCLK Processor clock frequency.
PCLK Peripheral clock supplied to the VPB peripheral bus.

4. External Oscillator

An external crystal or oscillator circuit provides the reference frequency used by the LPC2129 clock system.

The reference frequency is supplied to the internal clock-generation circuitry.

Example

Consider the following clock reference: 

FOSC = 12 MHz

This means the external reference source provides 12 million cycles per second.

The oscillator frequency is not necessarily the final processor frequency. The PLL can increase the frequency used by the CPU.

5. Phase-Locked Loop (PLL)

A Phase-Locked Loop is a clock-generation circuit used to derive a higher-frequency clock from a reference input.

LPC2129 includes a PLL that can generate the processor clock from the external oscillator reference.

Purpose of the PLL

  • Generates the required CPU clock frequency.
  • Allows the processor to operate faster than the reference oscillator.
  • Provides a configurable clock-generation arrangement.
  • Supports the processor's clock requirements.

PLL output relationship

The simplified relationship is:

\[ CCLK = FOSC \times M \]

Where M is the configured PLL multiplier, subject to the device's PLL rules and supported operating limits.

LPC2129 PLL configuration also involves the PLL divider selection, oscillator limits, and the required FCCO operating range. These details are covered in Lesson 09.

6. Processor Clock (CCLK)

CCLK is the clock supplied to the ARM7TDMI-S processor core.

It determines the processor's clock frequency and influences the rate at which the CPU performs synchronous operations.

Example clock configuration

Parameter Value
External oscillator (FOSC) 12 MHz
Processor clock (CCLK) 60 MHz

In this example, the processor clock is five times the oscillator frequency.

\[ \frac{60\text{ MHz}}{12\text{ MHz}} = 5 \]

A 60 MHz CCLK is the configured operating frequency in this course example. Always observe the device's specified operating limits and clock configuration requirements.

7. Peripheral Clock (PCLK)

PCLK is the clock supplied to peripherals connected through the VPB peripheral bus.

Many LPC2129 peripheral timing calculations use PCLK rather than CCLK.

Peripherals using PCLK

  • UART0 and UART1.
  • Timers and counters.
  • PWM.
  • ADC.
  • I2C.
  • Other VPB-connected peripherals.

Why is PCLK important?

Peripheral clock frequency affects:

  • UART baud-rate calculations.
  • Timer resolution and delay calculations.
  • PWM period and frequency.
  • Peripheral communication timing.
  • ADC clock configuration.

8. VPB Peripheral Bus

VPB stands for VLSI Peripheral Bus. It provides the interface between the processor system and several on-chip peripherals.

The peripheral clock is derived from the processor clock through the VPB clock divider configuration.

ARM7 CPU | v CCLK | v VPB Clock Divider | v PCLK | +--------+--------+ | | | v v v UART Timer PWM | v Serial Interface
PCLK and CCLK are not necessarily equal. Their relationship depends on the VPB clock divider setting.

9. VPBDIV Register

The VPBDIV register controls the relationship between CCLK and PCLK for the VPB peripheral bus.

Typical VPBDIV settings

VPBDIV Value PCLK Relationship
00 PCLK = CCLK / 4
01 PCLK = CCLK
10 PCLK = CCLK / 2
11 Reserved

Example: PCLK = 15 MHz

Given: 

CCLK   = 60 MHz
VPBDIV = 00 (binary)

Therefore:

\[ PCLK = \frac{CCLK}{4} \]

\[ PCLK = \frac{60}{4} = 15\text{ MHz} \]

The VPBDIV register uses an encoded field. The value 00 selects divide-by-four; it does not mean that the peripheral clock is zero.

10. System Control Registers

LPC2129 provides system control registers for configuring important microcontroller functions.

Register Purpose
PLLCON Controls PLL connection and enable operation.
PLLCFG Configures PLL multiplier and divider parameters.
PLLSTAT Reports PLL status and lock information.
PLLFEED Provides the required PLL feed sequence.
VPBDIV Selects the peripheral clock division ratio.
PCON Controls power-down and idle operating modes.
PCONP Controls power to supported peripheral blocks.
MAMCR Controls the Memory Accelerator Module.
MAMTIM Configures Memory Accelerator timing.
The PLL registers are discussed in detail in Lesson 09. Power control and peripheral power management are separate from selecting the VPB clock division ratio.

11. Peripheral Clock and Timer Calculation

Timer calculations depend on the peripheral clock and the prescaler configuration.

The timer counter input frequency is:

\[ f_{TC} = \frac{PCLK}{PR+1} \]

Where:

  • PCLK = Peripheral clock frequency.
  • PR = Timer prescale register value.
  • fTC = Timer counter increment frequency.

Example

PCLK = 15 MHz
PR   = 14999

fTC = 15000000 / (14999 + 1)

fTC = 1000 Hz

The timer counter increments 1000 times per second, giving a counter increment interval of 1 millisecond.

This is the clock relationship used in the course's LPC2129 timer configuration. The match value and reset behavior determine the final timer event interval.

12. Peripheral Clock and UART Baud Rate

UART baud-rate generation uses the peripheral clock as an input to its baud-rate divisor circuitry.

For LPC2129 UARTs, the baud-rate divisor is configured using divisor latch registers and the fractional divider where applicable.

For a simplified calculation with the fractional divider disabled:

\[ Baud = \frac{PCLK}{16 \times D} \]

Where D is the divisor value.

Example

PCLK = 15 MHz
Target Baud = 9600

D = 15000000 / (16 x 9600)

D = 97.65625

The integer divisor must be selected and the resulting actual baud rate calculated. The fractional divider can be used to improve baud-rate accuracy.

Do not assume that selecting a nominal divisor always produces exactly the requested baud rate. Calculate the actual baud rate using the configured divisor and fractional divider values.

13. System Clock Configuration Sequence

A typical clock initialization sequence includes:

  1. Start from the oscillator reference.
  2. Configure PLL multiplier and divider values.
  3. Enable the PLL.
  4. Perform the required PLL feed sequence.
  5. Wait until the PLL reports lock.
  6. Connect the PLL as the processor clock source.
  7. Configure the VPB peripheral clock divider.
  8. Initialize peripheral modules using the resulting clock values.
This is the conceptual sequence. The exact register values, feed sequence, oscillator startup requirements, and timing constraints must follow the LPC2129 User Manual.

You can inspect clock-related configuration in the simulator using the debugger and register windows.

Suggested activity

  2. Build the project.

A simulator register value confirms the software-visible configuration. It does not by itself verify the physical oscillator frequency or electrical clock waveform.

15. Common Clock Configuration Mistakes

  1. Confusing oscillator frequency with processor frequency.
  2. Using CCLK instead of PCLK in peripheral timing calculations.
  3. Selecting an incorrect VPBDIV setting.
  4. Failing to wait for PLL lock.
  5. Skipping the required PLL feed sequence.
  6. Using incorrect UART baud-rate calculations.
  7. Ignoring peripheral operating-frequency limits.
  8. Assuming every peripheral uses the same clock source.

16. Interview Questions and Answers

Q1. What is a system clock?

It is a periodic timing signal used to synchronize operations inside a digital system.

Q2. What is FOSC?

FOSC is the external oscillator reference frequency.

Q3. What is CCLK?

CCLK is the processor clock supplied to the ARM7TDMI-S core.

Q4. What is PCLK?

PCLK is the peripheral clock supplied to VPB-connected peripheral modules.

Q5. What is the purpose of a PLL?

It generates a configured processor clock from a reference clock.

Q6. What is VPBDIV?

VPBDIV selects the peripheral clock division ratio relative to CCLK.

Q7. If CCLK is 60 MHz and PCLK is 15 MHz, what is the divider ratio?

PCLK is one-fourth of CCLK. The divide-by-four VPBDIV setting is selected.

Q8. Why is PCLK important for UART?

PCLK is used by the UART baud-rate generation circuitry.

Q9. Why is PCLK important for timers?

It provides the timer clock input used to calculate counter timing.

Q10. What is PLL lock?

It indicates that the PLL has achieved its required locked operating condition.

Q11. What does PCONP do?

It controls power to supported peripheral blocks.

Q12. What is the difference between clock configuration and peripheral power control?

Clock configuration determines timing frequencies, while peripheral power control determines whether supported peripheral blocks receive power.

19. Lesson Summary

  • The clock system synchronizes microcontroller operations.
  • FOSC is the external oscillator reference frequency.
  • CCLK is the processor clock.
  • PCLK is the VPB peripheral clock.
  • The PLL generates a configured processor clock.
  • VPBDIV controls the CCLK-to-PCLK relationship.
  • Peripheral timing calculations commonly use PCLK.
  • PLL lock must be checked during clock initialization.
  • PCONP controls power to supported peripheral blocks.
  • Correct clock configuration is essential for reliable firmware operation.
