Lesson 02: I2C Bus Architecture

Understand the physical structure of the I2C bus, shared communication lines, open-drain signaling, pull-up resistors, bus states, and multi-device connections.

After completing this lesson, you will be able to:

  • Explain shared-bus communication.

  • Understand the I2C bus architecture in LPC2129.

2. What is I2C Bus Architecture?

I2C bus architecture describes how multiple electronic devices are physically connected and communicate using a common two-wire serial bus.

Unlike interfaces that require separate communication lines for each peripheral, I2C allows several devices to share the same SDA and SCL lines.

Each device has an address. The controller uses this address to select the intended target during a transaction.

Important concept: I2C is a shared-bus architecture. All connected devices share the same SDA and SCL electrical connections, but only the selected and authorized participants communicate during a particular transaction.

Basic Architecture

I2C Shared-Bus Architecture 
                 +------------------+
                 |  Microcontroller |
                 |     Controller   |
                 +------------------+
                       |       |
                      SDA     SCL
                       |       |
     ==================|=======|==================
                       |       |
             +---------+-------+---------+
             |         |       |         |
        +---------+ +---------+ +---------+
        | Sensor  | | EEPROM  | |   RTC   |
        | Target  | | Target  | | Target  |
        +---------+ +---------+ +---------+

       All devices share SDA and SCL.
       Each target has an address.

The controller selects a target by transmitting its address. Other devices monitor the bus but do not respond unless they recognize the address.

3. Two-Wire Bus Structure

I2C uses two primary signal lines. Both are shared between all devices connected to the bus.

Signal Full Form Purpose
SDA Serial Data Transfers address and data information.
SCL Serial Clock Synchronizes data transmission and reception.

3.1 SDA Line

SDA is the bidirectional data line. It carries:

  • Slave address bits.
  • Read/write direction information.
  • Data bytes.
  • ACK and NACK responses.

The controller and target devices can transmit on SDA at different stages of a transaction. The electrical design allows devices to pull the line LOW without actively driving it HIGH.

3.2 SCL Line

SCL is the serial clock line. It provides timing synchronization for the transfer of each bit.

  • Data is generally sampled while SCL is HIGH.
  • Data normally changes while SCL is LOW.
  • START and STOP conditions are special SDA transitions while SCL is HIGH.
In a conventional single-controller transaction, the controller generates SCL. A target can hold SCL LOW to request more time using clock stretching, where supported.

4. Open-Drain and Open-Collector Signaling

I2C uses open-drain outputs in CMOS implementations (or open-collector outputs in bipolar implementations). These outputs can pull the bus LOW but do not actively drive it HIGH.

How Open-Drain Works

An open-drain output has two logical actions:

  • Pull LOW: The output transistor conducts and connects the bus toward ground.
  • Release: The output transistor turns off, allowing the pull-up resistor to bring the bus HIGH.
Conceptual Open-Drain Bus 
             Supply Voltage
                  |
             Pull-up Resistor
                  |
                  +---------- SDA Bus
                  |
           +------+------+
           |             |
       Device A       Device B
       Output         Output

Why Open-Drain is Used

  • Allows multiple devices to share the same bus.
  • Prevents direct HIGH-versus-LOW output contention.
  • Supports wired-AND bus behavior.
  • Enables clock synchronization and arbitration mechanisms.
A device must not actively drive an I2C bus line HIGH while another device pulls it LOW. I2C electrical interfaces are designed around open-drain behavior and appropriate pull-ups.

5. Pull-Up Resistors

Pull-up resistors are connected between SDA/SCL and the bus supply voltage. They ensure that a released bus line returns to a logic HIGH state.

Why are Pull-Ups Necessary?

Since open-drain outputs can only pull the line LOW, a resistor is needed to establish the HIGH state when no device is pulling the line LOW.

Pull-Up Resistor Connection 
             VCC                 VCC
              |                   |
             R1                  R2
              |                   |
             SDA                 SCL
              |                   |
       +------+-------------------+------+
       |              I2C Bus            |
       +------+-------------------+------+
              |                   |
        +-----------+       +-----------+
        | Controller|       |  Target   |
        +-----------+       +-----------+

Pull-Up Resistor Selection

The resistor value depends on bus capacitance, supply voltage, device sink-current capability, and required rise time.

A smaller pull-up resistance produces a faster rising edge but increases the current that a device must sink when pulling the line LOW.

A larger resistance reduces LOW-state current but produces a slower rising edge.

Pull-up selection is an electrical design calculation, not a fixed universal value. Check the I2C speed mode, total bus capacitance, device limits, and applicable rise-time requirements.

Illustrative Calculation

Suppose a bus uses a 3.3 V supply and a 4.7 kΩ pull-up resistor. When the line is pulled LOW, the approximate current through that resistor is: 

I = V / R

I = 3.3 / 4700

I ≈ 0.000702 A

I ≈ 0.70 mA

This is an illustrative resistor-current calculation. The actual LOW voltage and current depend on the device's output characteristics and the complete circuit.

6. HIGH and LOW Bus States

I2C uses two logical voltage states on SDA and SCL.

Bus State Electrical Condition Meaning
HIGH All devices release the line; pull-up raises it. Logic 1
LOW At least one device pulls the line LOW. Logic 0

Bus Idle Condition

When the bus is idle, both SDA and SCL are HIGH. This indicates that no transaction is currently occupying the bus.

Idle Bus State 
SDA  ------------------------------- HIGH

SCL  ------------------------------- HIGH

             BUS IDLE

A START condition changes SDA from HIGH to LOW while SCL is HIGH. A STOP condition changes SDA from LOW to HIGH while SCL is HIGH.

These conditions are examined in detail in the next lesson.

7. Multi-Device I2C Architecture

Multiple target devices can be connected to the same SDA and SCL lines. Each target normally has a unique address on that bus.

Example: Sensor, EEPROM, and RTC

Multiple I2C Targets 
                +------------------+
                |  Microcontroller |
                |    Controller    |
                +------------------+
                         |
                  SDA and SCL Bus
                         |
         +---------------+---------------+
         |               |               |
    +---------+     +---------+     +---------+
    | Sensor  |     | EEPROM  |     |   RTC   |
    | 0x48    |     | 0x50    |     | 0x68    |
    +---------+     +---------+     +---------+

    Example 7-bit addresses only.
    Actual addresses depend on device configuration.

The controller can communicate with one target at a time by sending its address. Other targets ignore the transaction unless their address matches.

Two devices on the same bus should not use the same responding address unless the device architecture provides a way to distinguish them. Address conflicts can cause incorrect communication.

8. Bus Capacitance and Communication Speed

Every device pin, PCB track, cable, and connector adds capacitance to the I2C bus.

The pull-up resistor and total bus capacitance form an RC network. This network determines how quickly SDA and SCL rise from LOW to HIGH.

Rise-Time Relationship

A simplified RC time constant is: 

τ = R × C

Where:

  • R = effective pull-up resistance.
  • C = total bus capacitance.
  • τ = RC time constant.

A larger bus capacitance or pull-up resistance increases the rise time. This can limit the maximum reliable communication speed.

Real I2C rise time is measured using specified voltage thresholds and is not simply equal to one RC time constant. The RC relationship is useful for understanding the trend.

9. Clock Stretching

Clock stretching is a mechanism in which a target device holds SCL LOW to delay the next clock transition.

A target may use this mechanism when it needs additional time to process data or prepare a response.

Basic Operation

  1. The controller attempts to release SCL HIGH.
  2. The target continues holding SCL LOW.
  3. The controller waits while SCL remains LOW.
  4. The target releases SCL when it is ready.
  5. The bus clock continues.
Clock stretching is an I2C bus feature, but support and timeout behavior must be checked in the controller, target device, and system software.

10. Multi-Controller I2C Bus

I2C can support more than one controller on the same bus. This is commonly called a multi-controller or multi-master configuration.

If multiple controllers attempt to start communication at the same time, arbitration determines which controller continues.

Arbitration Principle

Arbitration uses the wired-AND behavior of the bus. A controller transmitting a logic HIGH releases SDA. If another controller pulls SDA LOW, the observed bus value is LOW.

A controller that transmits HIGH but observes LOW recognizes that it has lost arbitration and must stop transmitting according to the I2C protocol.

Multi-controller operation requires correct arbitration and clock synchronization behavior. Do not assume that every microcontroller peripheral or software driver supports every multi-controller configuration.

11. I2C Bus Architecture in LPC2129

The LPC2129 provides an I2C0 peripheral that communicates through the SDA0 and SCL0 pins.

Microcontroller Pin Alternate Function
P0.2 SDA0
P0.3 SCL0

Peripheral Connection

LPC2129 I2C Connection 
             LPC2129
        +----------------+
        |                |
        |   P0.2 SDA0    |---------- SDA
        |                |             |
        |   P0.3 SCL0    |---------- SCL
        |                |             |
        +----------------+       +-----------+
                                 | I2C Target|
                                 |  Device    |
                                 +-----------+

       External pull-ups connect SDA and SCL
       to the appropriate bus supply voltage.

Relevant I2C Registers

Register Purpose
I2CONSET Sets I2C control bits.
I2CONCLR Clears selected I2C control bits.
I2STAT Reports the current I2C status.
I2DAT Holds data for transmission or reception.
I2ADR Contains the local address in slave operation.
I2SCLH Configures the SCL HIGH period.
I2SCLL Configures the SCL LOW period.

The pin multiplexer must be configured for the I2C functions before the peripheral can communicate through P0.2 and P0.3.

In the user's project configuration, PCLK is 15 MHz. I2C clock timing is configured through I2SCLH and I2SCLL. Detailed calculations and register programming are covered in Lesson 06.

12. Common I2C Bus Problems

Problem Possible Cause
Bus remains LOW Device holding line LOW, short circuit, or bus fault.
Slow rising edge High bus capacitance or excessive pull-up resistance.
No ACK Incorrect address, device not powered, or wiring fault.
Intermittent communication Electrical noise, poor connections, or timing issues.
Address conflict Multiple targets respond to the same address.
Communication too fast Target or bus electrical characteristics do not support the selected speed.

13. Interview Questions and Answers

Q1. What is I2C bus architecture?

It is a shared two-wire serial bus architecture that connects multiple devices using SDA and SCL.

Q2. What are the two I2C bus lines?

SDA (Serial Data) and SCL (Serial Clock).

Q3. Why are pull-up resistors required?

Open-drain outputs can pull a line LOW but cannot actively drive it HIGH. Pull-up resistors establish the HIGH state.

Q4. What is open-drain signaling?

It is an output arrangement that can pull a signal LOW or release it, allowing the pull-up network to establish HIGH.

Q5. What is the idle state of the I2C bus?

Both SDA and SCL are HIGH.

Q6. What is bus capacitance?

It is the combined electrical capacitance of device pins, PCB tracks, cables, and connectors connected to the bus.

Q7. What is clock stretching?

It is a mechanism in which a target holds SCL LOW to delay the next clock transition.

Q8. What is arbitration?

Arbitration determines which controller continues when multiple controllers attempt to use the bus.

Q9. Which pins are used for I2C0 in LPC2129?

P0.2 is SDA0 and P0.3 is SCL0.

Q10. What happens if the pull-up resistor is too large?

The bus may have slow rising edges, potentially violating timing requirements at the selected speed.
