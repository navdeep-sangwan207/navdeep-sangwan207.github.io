Lesson 06: I2C Clock Configuration

Learn how the LPC2129 generates the I2C clock using PCLK, I2SCLH, and I2SCLL. Understand clock calculations and configure standard-mode and fast-mode communication.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Explain the role of the peripheral clock in I2C communication.
  • Understand I2C SCL clock generation.
  • Explain I2SCLH and I2SCLL registers.
  • Calculate the SCL frequency from register values.
  • Configure standard-mode I2C at 100 kHz.
  • Configure fast-mode I2C at 400 kHz.
  • Understand clock timing requirements.
  • Configure I2C clock registers using Embedded C.

2. Introduction to I2C Clock Configuration

I2C is a synchronous serial communication protocol. The SCL (Serial Clock) signal synchronizes data transmission between the controller and target devices.

In LPC2129 master operation, the I2C peripheral generates the SCL clock using the peripheral clock and programmable clock-period registers.

Why Clock Configuration Is Important

  • Determines the communication speed.
  • Ensures compatibility between controller and targets.
  • Controls the duration of SCL HIGH and LOW periods.
  • Helps satisfy the target device's timing requirements.
  • Reduces communication errors caused by unsuitable timing.
The I2C controller must not exceed the maximum clock frequency supported by any target device connected to the bus.

3. Peripheral Clock (PCLK)

PCLK is the peripheral clock supplied to the LPC2129 peripheral subsystem. The I2C clock timing is derived from this clock.

The I2C peripheral uses PCLK together with the values programmed into I2SCLH and I2SCLL.

Project Clock Configuration

Clock Frequency
FOSC 12 MHz
CCLK 60 MHz
PCLK 15 MHz

For the project configuration, the peripheral clock is one-fourth of CCLK. 

CCLK = 60 MHz

VPBDIV = 0x00

PCLK = CCLK / 4

PCLK = 60 MHz / 4

PCLK = 15 MHz
Always use the actual PCLK supplied to I2C0 when calculating its SCL timing. Do not use FOSC or CCLK directly unless they are also the actual peripheral clock.

4. I2C Clock Generation

The LPC2129 uses two programmable registers to determine the SCL HIGH and LOW periods:

  • I2SCLH – SCL HIGH period count.
  • I2SCLL – SCL LOW period count.
I2C Clock Generation 
                 Peripheral Clock
                      PCLK
                       |
                       v
              +------------------+
              | I2C Clock Timing |
              |     Circuit      |
              +------------------+
                       |
              +--------+--------+
              |                 |
              v                 v
          I2SCLH             I2SCLL
        HIGH Count          LOW Count
              |                 |
              +--------+--------+
                       |
                       v
                 SCL Output
                       |
                       v
                 I2C Bus Clock

Clock Frequency Formula

SCL Frequency = PCLK / (I2SCLH + I2SCLL)

Where:

  • PCLK is the peripheral clock frequency.
  • I2SCLH is the HIGH period count.
  • I2SCLL is the LOW period count.

The total SCL period is determined by the sum of the HIGH and LOW period counts. 

SCL Period = (I2SCLH + I2SCLL) / PCLK

5. I2SCLH Register

I2SCLH controls the HIGH period of the I2C clock. It specifies the number of peripheral clock cycles allocated to the HIGH portion of SCL.

Register Characteristics

  • 32-bit memory-mapped register.
  • Programmable HIGH period count.
  • Used to configure SCL timing.
  • Works together with I2SCLL.

Example

/* Configure SCL HIGH period */
I2SCLH = 75U;

A value of 75 allocates 75 peripheral clock counts to the programmed HIGH period.

6. I2SCLL Register

I2SCLL controls the LOW period of the I2C clock. It specifies the number of peripheral clock cycles allocated to the LOW portion of SCL.

Register Characteristics

  • 32-bit memory-mapped register.
  • Programmable LOW period count.
  • Determines SCL LOW timing.
  • Works together with I2SCLH.

Example

/* Configure SCL LOW period */
I2SCLL = 75U;
The HIGH and LOW counts do not have to be equal. Their values can be selected independently to satisfy the required SCL frequency and timing specifications.

7. SCL Waveform and Timing

An I2C clock cycle contains a HIGH period and a LOW period. Data is normally sampled while SCL is HIGH.

SCL Clock Waveform 
SCL

HIGH        +---------+          +---------+
            |         |          |         |
            |         |          |         |
LOW  -------+         +----------+         +----

            |<- tHIGH ->|
            |<--- tLOW -------->|

One complete period = tHIGH + tLOW

Timing Parameters

Parameter Description
tHIGH Minimum or programmed SCL HIGH duration.
tLOW Minimum or programmed SCL LOW duration.
tSU;DAT Data setup time before the relevant clock edge.
tHD;DAT Data hold time after the relevant clock edge.
tSU;STA START condition setup time.
tSU;STO STOP condition setup time.
Correct SCL frequency alone does not guarantee correct I2C timing. The HIGH and LOW periods, data setup and hold requirements, bus rise time, and target-device limits must also be satisfied.

8. Standard-Mode I2C (100 kHz)

Standard-mode I2C supports communication at a clock frequency up to 100 kHz.

Clock Calculation

Given:

  • PCLK = 15 MHz
  • Required SCL = 100 kHz
  • I2SCLH = I2SCLL

Using the formula:

SCL = PCLK / (I2SCLH + I2SCLL)

100,000 = 15,000,000 / (I2SCLH + I2SCLL)

I2SCLH + I2SCLL = 150

I2SCLH = 75
I2SCLL = 75

Embedded C Configuration

/* Standard-mode: nominal 100 kHz */

I2SCLH = 75U;
I2SCLL = 75U;

Expected Calculation

SCL = 15,000,000 / (75 + 75)

SCL = 100,000 Hz

SCL = 100 kHz

9. Fast-Mode I2C (400 kHz)

Fast-mode I2C supports communication at a clock frequency up to 400 kHz.

Clock Calculation

Given:

  • PCLK = 15 MHz
  • Required SCL = 400 kHz
  • I2SCLH = I2SCLL
SCL = PCLK / (I2SCLH + I2SCLL)

400,000 = 15,000,000 / (I2SCLH + I2SCLL)

I2SCLH + I2SCLL = 37.5

The register values must be integers. A suitable equal-count approximation is: 

I2SCLH = 19;
I2SCLL = 19;

SCL = 15,000,000 / (19 + 19)

SCL = 394,736.84 Hz

SCL ≈ 394.74 kHz

Embedded C Configuration

/* Fast-mode: approximately 394.74 kHz */

I2SCLH = 19U;
I2SCLL = 19U;
The equal-count example is a frequency approximation, not a complete fast-mode timing qualification. The actual HIGH and LOW periods must meet the I2C fast-mode minimum timing requirements and the LPC2129 peripheral timing constraints. Use suitable unequal counts when necessary.

10. Standard-Mode vs Fast-Mode

Feature Standard-Mode Fast-Mode
Maximum clock frequency 100 kHz 400 kHz
Clock period at maximum rate 10 µs 2.5 µs
Communication speed Lower Higher
Timing requirements Less demanding More demanding
Typical application Simple sensors and control devices Higher-throughput peripheral communication

11. Complete I2C Clock Initialization Program

The following program configures I2C0 for nominal 100 kHz operation using the project's 15 MHz PCLK. 

#include <LPC21xx.h>

#define I2C_ENABLE (1U << 6)

void I2C0_Init(void)
{
    /* Configure SDA0 and SCL0 */
    PINSEL0 &= ~(0xFU << 4);
    PINSEL0 |=  (0x5U << 4);

    /* Configure nominal 100 kHz clock */
    I2SCLH = 75U;
    I2SCLL = 75U;

    /* Enable I2C0 */
    I2CONSET = I2C_ENABLE;
}

int main(void)
{
    I2C0_Init();

    while (1)
    {
        /* Application code */
    }
}

Program Explanation

  1. Include the LPC21xx device header.
  2. Configure P0.2 and P0.3 for I2C0.
  3. Load the HIGH period count.
  4. Load the LOW period count.
  5. Set I2EN to enable I2C0.
  6. Enter the main application loop.
This program configures I2C0 timing and enables the peripheral. It does not transmit data or verify a connected target.

13. Common Clock Configuration Errors

Error Possible Cause
Incorrect SCL frequency Wrong PCLK used in calculation.
Target does not respond Configured clock exceeds target capability.
Communication errors HIGH or LOW period violates timing requirements.
Unexpected bus waveform Incorrect pin configuration or external pull-ups.
Incorrect clock calculation Using only I2SCLH or only I2SCLL.
Unreliable fast-mode operation Insufficient rise-time or unsuitable bus capacitance.

14. Interview Questions and Answers

Q1. Which registers configure the LPC2129 I2C clock?

I2SCLH and I2SCLL.

Q2. What does I2SCLH control?

It controls the SCL HIGH period.

Q3. What does I2SCLL control?

It controls the SCL LOW period.

Q4. What is the SCL frequency formula?

SCL = PCLK / (I2SCLH + I2SCLL).

Q5. What is standard-mode I2C speed?

Up to 100 kHz.

Q6. What is fast-mode I2C speed?

Up to 400 kHz.

Q7. What is the project PCLK?

15 MHz.

Q8. What are the equal HIGH and LOW counts for nominal 100 kHz with 15 MHz PCLK?

I2SCLH = 75 and I2SCLL = 75.

Q9. Why must the target device's clock limit be checked?

The target may not support the selected communication speed.

Q10. Does a correct SCL frequency guarantee reliable communication?

No. The complete timing requirements and electrical bus conditions must also be satisfied.

17. Lesson Summary

  • I2C clock generation is derived from PCLK.
  • I2SCLH controls the SCL HIGH period.
  • I2SCLL controls the SCL LOW period.
  • SCL frequency is calculated using PCLK and both period counts.
  • Standard-mode supports up to 100 kHz.
  • Fast-mode supports up to 400 kHz.
  • The project PCLK is 15 MHz.
  • Counts of 75 and 75 give nominal 100 kHz operation.
  • Electrical and timing requirements must be checked separately.
