Chapter 15: LPC2129 I2C Communication

Learn Inter-Integrated Circuit (I2C) communication, bus architecture, addressing, master and receiver operations, clock configuration, and Embedded C programming using LPC2129.

Chapter Overview

I2C (Inter-Integrated Circuit) is a synchronous serial communication protocol used to connect microcontrollers with sensors, EEPROMs, RTC modules, displays, and other peripheral devices.

This chapter introduces the I2C protocol and explains its two-wire bus architecture, START and STOP conditions, device addressing, data transfer, clock configuration, and the LPC2129 I2C controller.

You will also learn how to configure I2C registers and implement basic master-transmitter and master-receiver operations using Embedded C.

Important Technical Notes

  • LPC2129 I2C0 uses P0.2 as SDA0 and P0.3 as SCL0. Configure the appropriate pin functions before communication.
  • I2C uses open-drain/open-collector signaling and normally requires external pull-up resistors on SDA and SCL.
  • The I2C clock is configured using the SCLH and SCLL registers. Its frequency depends on PCLK and both register values.
  • The LPC2129 I2C controller uses I2CONSET, I2CONCLR, I2STAT, I2DAT, I2ADR, I2SCLH, and I2SCLL registers.
  • Keil uVision simulator support for I2C bus transactions and external devices may be limited. Register-level program execution does not prove physical bus communication.
