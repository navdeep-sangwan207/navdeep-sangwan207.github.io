Topic: ARM Architecture Generations and Technological Development

1. Introduction

ARM architecture has evolved from a relatively simple 32-bit RISC architecture into a broad family of processor architectures used in embedded systems, mobile devices, automotive electronics, networking equipment and high-performance computing.

Each generation introduced new capabilities to improve processing performance, memory management, security, power efficiency and support for different applications.

The evolution of ARM architecture is important because different ARM processor families implement different architecture versions and features.

Important: ARM architecture versions and ARM processor families are different concepts. An architecture version defines architectural features, while a processor family identifies a group of processor implementations.

2. Beginning of ARM Architecture

ARM development began at Acorn Computers in the United Kingdom during the 1980s. The objective was to develop an efficient processor using RISC design principles.

Early Development

  • ARM development started in 1983.
  • The first ARM prototype, ARM1, was completed in 1985.
  • ARM2 became an important early commercial implementation.
  • ARM processors were initially used in Acorn computer systems.
  • ARM technology later expanded into embedded and mobile applications.

The early ARM designs demonstrated that a relatively simple RISC architecture could provide efficient processing with a compact hardware implementation.

3. Historical Timeline of ARM Development

1980s – Early ARM Development

Initial ARM processor designs were developed using RISC principles. ARM1 and ARM2 were important early processors.

1990 – Advanced RISC Machines

Advanced RISC Machines Ltd was established as a separate company, supporting the growth and licensing of ARM technology.

1990s – ARM6 and ARM7 Generations

ARM processor implementations became more widely used in embedded systems and electronic devices.

Late 1990s – Thumb Technology

Thumb instruction support helped reduce program memory requirements while maintaining compatibility with the ARM execution model.

2000s – ARM9 and ARM11

More advanced pipelines, memory management capabilities and performance improvements supported increasingly complex applications.

2004 – ARM Cortex Introduction

The Cortex processor families introduced distinct application, real-time and microcontroller processor profiles.

2011 – ARMv8-A

ARMv8-A introduced AArch64, enabling 64-bit processing alongside its 32-bit execution state.

2021 – ARMv9-A

ARMv9-A extended the application processor architecture with additional security, vector-processing and computing capabilities.

4. Evolution of ARM Architecture Versions

ARM architecture versions are identified using names such as ARMv4, ARMv5, ARMv6, ARMv7, ARMv8 and ARMv9. Each version defines a set of architectural features.

Architecture Major Development General Significance
ARMv1 Initial ARM architecture. Early experimental processor design.
ARMv2 Improved early ARM instruction architecture. Used in early commercial ARM processors.
ARMv3 Introduced a 32-bit address space. Expanded memory addressing capabilities.
ARMv4 Introduced significant instruction-set improvements. Supported later ARM processor generations.
ARMv4T Added Thumb instruction set support. Used by ARM7TDMI and ARM7TDMI-S.
ARMv5 Added enhancements including improved instruction capabilities. Used by ARM9E and ARM10-family implementations.
ARMv6 Added architectural enhancements including media-processing features. Used in ARM11-family processors.
ARMv7 Introduced distinct architecture profiles. Used by Cortex-A, Cortex-R and Cortex-M generations.
ARMv8 Introduced 64-bit AArch64 in ARMv8-A. Supported modern 64-bit application processors.
ARMv9 Extended modern application architecture capabilities. Supports advanced computing and security features.
ARM architecture profiles and extensions differ by version. Not every processor implementing a particular version necessarily supports every optional feature.

5. ARM7 Architecture and Its Importance

ARM7 is an important processor family in the history of embedded systems. ARM7TDMI became widely used in microcontrollers and embedded applications.

ARM7TDMI Features

  • 32-bit ARM processor core.
  • ARMv4T architecture implementation.
  • Support for ARM and Thumb instruction sets.
  • Three-stage instruction pipeline.
  • EmbeddedICE debug support.
  • Hardware multiplier support.

Meaning of ARM7TDMI

Letter Meaning
T Thumb instruction set support.
D JTAG-based debug support.
M Enhanced multiplier.
I EmbeddedICE debug logic.
LPC2129 connection: The LPC2129 uses the ARM7TDMI-S core. Its architecture is ARMv4T, making ARM7 architecture fundamentals directly relevant to LPC2129 programming.

6. ARM9 and ARM11 Generations

6.1 ARM9

ARM9 processors introduced more advanced processor implementations compared with earlier ARM7 designs. Many ARM9 implementations used separate instruction and data paths and more advanced pipeline organization.

  • Higher performance than earlier ARM7 implementations.
  • More advanced pipeline designs.
  • Support for improved memory-system implementations.
  • Used in embedded systems and application devices.

6.2 ARM11

ARM11 processors were based on ARMv6 architecture. They introduced additional performance and architectural capabilities.

  • ARMv6 architecture family.
  • Improved processor implementation.
  • Enhanced media-processing capabilities.
  • Used in early smartphone and multimedia platforms.

7.1 Cortex-A – Application Processors

Cortex-A processors are designed for application-rich systems requiring high processing performance.

Applications:

  • Smartphones and tablets.
  • Operating-system-based computing devices.
  • Advanced multimedia systems.
  • Embedded Linux platforms.

7.2 Cortex-R – Real-Time Processors

Cortex-R processors are designed for systems that require predictable real-time response and high reliability.

Applications:

  • Automotive control systems.
  • Storage controllers.
  • Industrial control.
  • Safety-critical applications.

7.3 Cortex-M – Microcontroller Processors

Cortex-M processors are designed for microcontroller applications and embedded control systems.

Applications:

  • Sensor-based systems.
  • Industrial automation.
  • IoT devices.
  • Low-power embedded controllers.
Cortex-M processors are different from ARM7 processors. LPC2129 uses ARM7TDMI-S, not a Cortex-M core.

8. Introduction to 64-bit ARM Architecture

ARMv8-A introduced AArch64, which provides a 64-bit execution state. It also supports AArch32, a 32-bit execution state.

AArch32

AArch32 supports the 32-bit execution model used by earlier ARM application architectures and compatible implementations.

AArch64

AArch64 provides a 64-bit execution state with 64-bit general-purpose registers and an expanded architecture for modern application processors.

Feature AArch32 AArch64
Execution State 32-bit 64-bit
General-Purpose Register Width 32-bit 64-bit
Architecture Context 32-bit ARM execution. 64-bit ARM execution.
ARM7TDMI-S does not support AArch64. It is a 32-bit ARMv4T processor core.

11. Importance of ARM Architecture Evolution

Understanding ARM evolution helps embedded engineers identify the capabilities and limitations of different processor generations.

  • Selecting the correct processor for an application.
  • Understanding instruction-set compatibility.
  • Choosing suitable development tools.
  • Understanding memory-management capabilities.
  • Evaluating processing performance and power requirements.
  • Understanding differences between legacy ARM7 and modern Cortex processors.

12. Lesson Summary

  • ARM development began at Acorn Computers in the 1980s.
  • ARM architecture is based on RISC principles.
  • ARM architecture evolved through several generations.
  • ARMv4T introduced Thumb support and is implemented by ARM7TDMI-S.
  • ARM9 and ARM11 provided more advanced processor implementations.
  • Cortex families are divided into A, R and M profiles.
  • ARMv8-A introduced the AArch64 execution state.
  • ARMv9-A extends modern application processor capabilities.
  • LPC2129 uses an ARM7TDMI-S core based on ARMv4T.

13. Interview Questions and Answers

Q1. When did ARM development begin?

ARM development began at Acorn Computers in the United Kingdom during the 1980s.

Q2. What was the original name of ARM?

ARM originally stood for Acorn RISC Machine.

Q3. What is ARMv4T?

ARMv4T is an ARM architecture version that includes Thumb instruction-set support.

Q4. Which architecture does ARM7TDMI-S implement?

ARM7TDMI-S implements ARMv4T.

Q5. What is the difference between ARM7 and Cortex-M?

ARM7 is an older processor family, while Cortex-M is a family of processors designed for modern microcontroller applications.

Q6. What are the three major Cortex profiles?

Cortex-A, Cortex-R and Cortex-M.

Q7. What is AArch64?

AArch64 is the 64-bit execution state introduced with the ARMv8-A architecture.

Q8. Does LPC2129 use a Cortex-M processor?

No. LPC2129 uses the ARM7TDMI-S processor core.

Q9. Which architecture is used by ARM11 processors?

ARM11 processors implement ARMv6 architecture.

Q10. Why is ARM architecture evolution important?

It helps engineers understand processor capabilities, compatibility, performance and suitable application areas.
