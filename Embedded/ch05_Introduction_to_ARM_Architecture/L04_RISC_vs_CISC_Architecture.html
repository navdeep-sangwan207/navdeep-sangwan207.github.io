Chapter 05: Introduction to ARM Architecture

Topic: Reduced Instruction Set Computer and Complex Instruction Set Computer

1. Introduction

A processor executes instructions to perform arithmetic operations, logical operations, data transfers, and program-control operations. The design of its instruction set has a major influence on processor architecture.

Two traditional approaches to instruction-set design are:

  • RISC: Reduced Instruction Set Computer.
  • CISC: Complex Instruction Set Computer.

RISC emphasizes a relatively simple instruction set and a load/store architecture. CISC provides more complex instructions that can perform multiple operations within a single instruction.

Important: RISC and CISC describe instruction-set design philosophies. They do not mean that one type of processor is always faster or more efficient than the other.

2. What Is RISC?

RISC stands for Reduced Instruction Set Computer. It is a processor design approach that uses a relatively simple instruction set with a load/store model for accessing memory.

2.1 Main Characteristics of RISC

  • Relatively simple instruction formats.
  • A load/store architecture for ordinary data processing.
  • A comparatively large number of general-purpose registers.
  • Simple addressing modes in traditional RISC designs.
  • Instruction formats designed to support efficient decoding.
  • Architecture designed to support pipelined instruction execution.
  • Arithmetic and logical operations generally work on register operands.

2.2 Load/Store Architecture

A major feature of ARM's traditional RISC design is its load/store architecture. Data is transferred between memory and registers using load and store instructions.

↓ Load instruction
CPU Registers
↓ Arithmetic / Logical Operation
CPU Registers
↓ Store instruction
Main Memory

The processor loads data from memory into registers, performs operations on register values, and stores the result back into memory when required.

2.3 Example of RISC-Style Processing

Consider the operation: 

C = A + B;

In a simplified ARM-style assembly example: 

LDR R0, [R1]       ; Load A from memory
LDR R2, [R3]       ; Load B from memory
ADD R4, R0, R2     ; Add register values
STR R4, [R5]       ; Store result C in memory

Here, the ADD instruction operates on register operands. The memory transfers are performed separately using LDR and STR.

Remember: The register and memory addresses in this example are illustrative. Actual programs use addresses established by the compiler or programmer.

3. What Is CISC?

CISC stands for Complex Instruction Set Computer. It is a processor design approach that provides a large and feature-rich instruction set. Some instructions can perform multiple operations, including memory access and arithmetic.

3.1 Main Characteristics of CISC

  • A large and relatively complex instruction set.
  • Instructions may support multiple addressing modes.
  • Some instructions can operate directly on memory operands.
  • Instruction lengths may vary.
  • Some instructions perform multiple low-level operations.
  • Instruction execution may require different numbers of cycles.
  • Instruction decoding can be more complex.

3.2 Example of CISC-Style Processing

Consider the same operation: 

C = A + B;

A traditional CISC instruction set may provide an instruction that adds a memory operand to a register: 

MOV EAX, [A]       ; Load A into EAX
ADD EAX, [B]       ; Add memory operand B to EAX
MOV [C], EAX       ; Store result C

This example uses x86-style assembly syntax. The ADD instruction can use a memory operand directly, unlike the ordinary register-to-register arithmetic model of classic ARM.

CISC instructions do not necessarily complete in one clock cycle. Complex instructions may involve several internal operations.

5. Instruction Execution and Clock Cycles

In traditional RISC teaching models, instructions are designed to be relatively simple and regular. This can make instruction decoding and pipeline design easier.

CISC instructions may perform several internal operations. A processor can internally break a complex instruction into smaller operations, sometimes called micro-operations.

Technical clarification: It is incorrect to say that every RISC instruction executes in exactly one clock cycle or that every CISC instruction takes multiple cycles. Actual execution time depends on the processor implementation, pipeline, memory system, instruction and operating conditions.

6. Instruction Length and Code Density

Instruction length affects how much program memory is required to store machine instructions.

6.1 Traditional RISC Instruction Encoding

Many classic RISC instruction sets use regular instruction formats. Regular formats can simplify instruction fetching and decoding.

6.2 Traditional CISC Instruction Encoding

Many CISC instruction sets use variable-length instruction formats. A single instruction may encode several details, potentially reducing the number of instructions required for a particular operation.

6.3 Code Density

Code density refers to how much memory is required to represent a program.

Compact instructions can reduce program storage requirements. However, code density depends on the instruction set, compiler, program and encoding format.

ARM supports both 32-bit ARM instructions and 16-bit Thumb instructions in the ARM7TDMI-S architecture. Thumb was designed to improve code density while retaining access to ARM processor functionality.

7. Pipelining in RISC and CISC

Pipelining is a processor technique in which different stages of multiple instructions are processed concurrently.

7.1 Basic Pipeline Stages

  • Fetch: Retrieve an instruction from memory.
  • Decode: Interpret the instruction.
  • Execute: Perform the required operation.
Three-stage instruction pipeline

Instruction 1: Fetch → Decode → Execute

Instruction 2:        Fetch → Decode → Execute

Instruction 3:              Fetch → Decode → Execute

Regular instruction formats and simpler decoding can make traditional RISC architectures easier to pipeline. CISC processors can also use sophisticated pipelines. Modern CISC processors commonly translate complex instructions into simpler internal operations before execution.

8. ARM Architecture and RISC

ARM is based on RISC design principles. Its traditional instruction-set architecture uses a load/store model and general-purpose registers for data processing.

8.1 Important ARM RISC Characteristics

  • Load/store architecture.
  • Register-based arithmetic and logical operations.
  • Efficient instruction decoding in traditional ARM designs.
  • Support for pipelined instruction execution.
  • ARM and Thumb instruction sets in ARM7TDMI-S.
  • Conditional execution support in the ARM instruction set.

8.2 Example: ARM7TDMI-S

The LPC2129 microcontroller uses the ARM7TDMI-S processor core. This processor implements the ARMv4T architecture and supports both ARM and Thumb instruction states.

9. Advantages and Limitations

9.1 RISC Advantages

  • Relatively simple instruction decoding in traditional designs.
  • Load/store organization provides a clear memory-access model.
  • Regular instruction formats can support efficient pipelining.
  • Register-based operations can reduce unnecessary memory accesses.
  • Can be suitable for power- and area-conscious processor designs.

9.2 RISC Limitations

  • Some operations may require multiple instructions.
  • Program code may become longer for certain tasks.
  • Performance still depends on memory, pipeline and implementation.

9.3 CISC Advantages

  • Rich instruction sets provide many programming operations.
  • Some complex instructions can reduce the number of instructions in a program.
  • Variable-length encoding can provide compact representations.
  • Complex addressing modes can support flexible data access.

9.4 CISC Limitations

  • Instruction decoding can be more complicated.
  • Instruction execution characteristics can vary significantly.
  • Complex instruction formats can make pipeline design challenging.
  • Processor implementation may require sophisticated control logic.

10. Modern Processor Architecture: An Important Note

The traditional distinction between RISC and CISC is useful for learning processor architecture, but modern processors are more sophisticated than the basic textbook models.

  • Modern x86 processors often decode complex instructions into simpler micro-operations.
  • Modern ARM processors can use advanced pipelines, caches and out-of-order execution.
  • RISC processors may support variable-length instruction encodings.
  • Some RISC instruction sets include complex instructions or extensions.
Key concept: RISC does not automatically mean faster, and CISC does not automatically mean slower. Performance depends on the complete processor design, implementation, compiler and workload.

11. Practical Embedded Systems Relevance

Understanding RISC and CISC helps embedded engineers understand how compilers generate machine instructions and how a microcontroller executes firmware.

Practical points to remember

  1. Embedded C statements are translated into machine instructions.
  2. The compiler uses the target processor's instruction set.
  3. ARM7TDMI-S follows RISC design principles.
  4. Memory data is normally transferred through load/store instructions.
  5. Registers are used for arithmetic and logical processing.
  6. Thumb instructions can help reduce firmware code size.

In Keil uVision, you can inspect the generated assembly or disassembly to observe how C statements are translated into ARM or Thumb instructions.

12. Common Mistakes

  • Assuming every RISC instruction executes in one clock cycle.
  • Assuming every CISC instruction takes multiple clock cycles.
  • Assuming all RISC instructions have fixed-length encodings.
  • Assuming CISC processors cannot use pipelining.
  • Confusing instruction-set architecture with processor microarchitecture.
  • Assuming the number of instructions alone determines program performance.
  • Forgetting that ARM7TDMI-S supports both ARM and Thumb states.

13. Interview Questions and Answers

Q1. What is RISC?

RISC stands for Reduced Instruction Set Computer. It is a processor design approach that uses a relatively simple instruction set and commonly follows a load/store architecture.

Q2. What is CISC?

CISC stands for Complex Instruction Set Computer. It provides a relatively extensive instruction set with instructions that may perform multiple operations.

Q3. What is the main difference between RISC and CISC?

RISC generally uses simpler instructions and a load/store model, whereas CISC provides more complex instructions and may allow direct memory operands in arithmetic operations.

Q4. Is ARM a RISC architecture?

Yes. ARM follows RISC design principles, including a load/store model and register-based data processing.

Q5. What is a load/store architecture?

It is an architecture in which data is transferred between memory and registers using load and store instructions. Arithmetic and logical operations generally use register operands.

Q6. Give examples of RISC and CISC architectures.

ARM and RISC-V are examples of RISC instruction-set architectures. x86 and x86-64 are examples of CISC instruction-set architectures.

Q7. Why is RISC suitable for many embedded applications?

Its relatively simple instruction organization, register-based processing and support for efficient implementations can make it suitable for embedded applications.

Q8. What is the instruction-set architecture of LPC2129?

The LPC2129 uses the ARM7TDMI-S core implementing ARMv4T, with ARM and Thumb instruction states.

Q9. What is code density?

Code density is the amount of memory required to represent a program's machine instructions.

Q10. Does CISC mean slower than RISC?

No. Processor performance depends on the implementation, instruction execution, memory system, compiler and workload.

16. Lesson Summary

  • RISC means Reduced Instruction Set Computer.
  • CISC means Complex Instruction Set Computer.
  • RISC commonly uses a load/store architecture.
  • RISC arithmetic and logical instructions generally operate on registers.
  • CISC may provide instructions with complex operations and memory operands.
  • Instruction length, decoding and addressing modes differ across traditional designs.
  • Both RISC and CISC processors can use pipelining.
  • ARM follows RISC design principles.
