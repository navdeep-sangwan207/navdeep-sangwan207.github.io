Lesson 07: ARM Register Banks

Course: Embedded Systems – Complete Study Course

Chapter 05: Introduction to ARM Architecture

Topic: Shared Registers, Banked Registers and Exception Contexts

1. Introduction

ARM7TDMI-S supports seven processor operating modes. Each mode uses a particular view of the processor register set. Some registers are shared between modes, while selected registers have separate physical copies called banked registers.

Register banking allows the processor to switch execution modes without immediately overwriting important register values from the previous mode.

Register banking is especially useful for:

  • Interrupt processing.
  • Fast interrupt response.
  • Exception handling.
  • Separate stack management.
  • Preserving execution context.
Important: ARM7TDMI-S has 37 physical 32-bit registers in its programmer's model: 31 general-purpose registers and 6 status registers (one CPSR and five SPSRs). Only 16 general-purpose register numbers, R0–R15, are visible at a time.

2. What Is Register Banking?

Register banking is a processor architecture technique in which certain register numbers have separate physical copies for different operating modes.

When the processor changes operating mode, the corresponding banked registers become accessible automatically.

Register banking concept
User Mode: R13_usr
IRQ Mode: R13_irq
FIQ Mode: R13_fiq

Same logical register number: R13
Different physical register copies

For example, R13 is the Stack Pointer in the programmer's model. However, User Mode, IRQ Mode and FIQ Mode can each access a different physical R13 register.

3. Shared Registers

Shared registers are physical registers accessible through the same register number in multiple processor modes. They do not have separate copies for every mode.

3.1 R0–R7

R0 through R7 are shared across all seven ARM7 operating modes. They are common general-purpose registers.

3.2 R8–R12

R8 through R12 are shared across all modes except FIQ Mode. FIQ Mode has its own physical copies of R8 through R12.

4. Banked Registers in ARM7TDMI-S

ARM7TDMI-S provides additional physical copies of selected registers for different operating modes.

4.1 FIQ Mode

FIQ Mode has seven banked general-purpose registers:

  • R8_fiq
  • R9_fiq
  • R10_fiq
  • R11_fiq
  • R12_fiq
  • R13_fiq
  • R14_fiq

4.2 IRQ Mode

IRQ Mode has two banked general-purpose registers:

  • R13_irq
  • R14_irq

4.3 Supervisor Mode

  • R13_svc
  • R14_svc

4.4 Abort Mode

  • R13_abt
  • R14_abt

4.5 Undefined Mode

  • R13_und
  • R14_und

4.6 User and System Modes

User and System modes share the same physical R0–R15 register bank. System Mode does not have an additional banked general-purpose register set.

7. SPSR Banking

The Saved Program Status Register (SPSR) stores the previous CPSR value when an exception occurs.

ARM7TDMI-S has five SPSRs, one for each exception mode:

  • SPSR_fiq
  • SPSR_irq
  • SPSR_svc
  • SPSR_abt
  • SPSR_und

User Mode and System Mode do not have an SPSR.

↓ Exception entry

↓ Exception return

Each exception mode has its own SPSR. This allows the processor to preserve the status of the interrupted or previous execution context independently for each exception mode.

8. Why Does FIQ Have More Banked Registers?

FIQ is designed for fast interrupt handling. Its additional banked registers allow an FIQ handler to perform operations without immediately overwriting the shared registers used by the interrupted program.

8.1 FIQ Register Set

FIQ has private copies of R8–R14. These include five additional general-purpose registers (R8–R12), a Stack Pointer and a Link Register.

8.2 Benefits

  • Reduces register-saving overhead in suitable handlers.
  • Provides a separate stack pointer.
  • Provides a separate link register.
  • Allows fast interrupt code to use private working registers.
Example: An FIQ handler can use R8_fiq, R9_fiq and R10_fiq without modifying the corresponding shared R8, R9 and R10 registers used by the interrupted program.
FIQ banking does not eliminate all context-saving requirements. An FIQ handler must still preserve any shared registers or other state that it modifies and that must survive the interrupt.

11. Practical Embedded Systems Relevance

Register banking is important when developing interrupt-driven firmware for the LPC2129.

  • The processor uses IRQ Mode for accepted IRQ exceptions.
  • The processor uses FIQ Mode for accepted FIQ exceptions.
  • Each exception mode has its own stack pointer and link register.
  • FIQ has additional banked working registers.
  • The VIC can be configured to generate IRQ or FIQ requests.

Keil uVision Simulator Exercise

  2. Build the project and enter debug mode.
  3. Open the Registers window.
  4. Inspect the current processor mode.

  6. Study the processor state during exception entry and return.
The debugger's ability to display individual banked registers depends on its register-window features. You can study the architectural register organization without a physical board.

12. Common Mistakes

  • Assuming all registers are banked in every mode.
  • Assuming R0–R7 have separate copies for IRQ and FIQ.
  • Forgetting that R8–R12 are banked only in FIQ Mode.
  • Assuming User Mode and System Mode have different register banks.
  • Assuming User and System modes have SPSRs.
  • Confusing logical register numbers with physical register copies.
  • Assuming FIQ banking removes every need to save registers.

13. Interview Questions and Answers

Q1. What is register banking?

It is the provision of separate physical copies of selected registers for particular processor modes.

Q2. Which registers are shared across all ARM7 modes?

R0–R7 and R15.

Q3. Which registers are banked in FIQ Mode?

R8–R14.

Q4. Which registers are banked in IRQ Mode?

R13 and R14.

Q5. How many SPSRs are present in ARM7TDMI-S?

Five.

Q6. Why does FIQ have additional banked registers?

To reduce register-saving overhead and support faster interrupt handling.

Q7. Do User and System modes share registers?

Yes. They share the same general-purpose register bank.

Q8. How many physical general-purpose registers are available?

31.

Q9. How many physical registers are in the ARM7TDMI-S programmer's model, including status registers?

37.

Q10. What is the advantage of a banked stack pointer?

It allows each exception mode to use a separate stack without changing the stack pointer of another mode.
