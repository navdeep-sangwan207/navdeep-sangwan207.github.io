Topic: ARM7 Processor Modes and Privilege Levels

1. Introduction

An operating mode defines the processor's execution context, including its access privileges and the registers available to the executing program.

The ARM7TDMI-S processor used in the LPC2129 supports seven operating modes. These modes help the processor execute normal programs, handle exceptions, and respond to interrupts.

  • User Mode
  • FIQ Mode
  • IRQ Mode
  • Supervisor Mode
  • Abort Mode
  • Undefined Mode
  • System Mode
Important: ARM7TDMI-S has seven operating modes. User Mode is unprivileged. The other six modes are privileged.

2. Why Does ARM Use Different Operating Modes?

An embedded processor must perform several kinds of tasks. It executes application code, responds to interrupts, handles exceptional conditions and performs system-level operations.

Separate operating modes provide:

  • Controlled access to privileged processor operations.
  • Dedicated execution contexts for exception handling.
  • Banked registers for faster interrupt handling.
  • Separation between normal application code and system code.
  • More organized exception and interrupt processing.
Example: When an IRQ interrupt occurs, the ARM7 processor enters IRQ Mode, saves the previous processor status in the IRQ banked SPSR, and uses the IRQ banked link register to support exception return.

3. The Seven ARM7 Operating Modes

3.1 User Mode (USR)

User Mode is the normal application execution mode. It is unprivileged and is intended for running application programs.

  • Used for ordinary application execution.
  • Cannot directly perform privileged operations.
  • Has access to the common user register set.
  • Cannot directly change the processor mode through ordinary writes to CPSR control fields.

3.2 FIQ Mode (Fast Interrupt Request)

FIQ Mode is entered when the processor accepts a Fast Interrupt Request exception.

  • Designed for fast interrupt servicing.
  • Has additional banked registers.
  • Uses its own SPSR and banked link register.
  • Can reduce the need to save and restore general-purpose registers.
  • FIQ has higher priority than IRQ in the ARM7 exception-priority scheme.

3.3 IRQ Mode (Interrupt Request)

IRQ Mode is entered when the processor accepts a normal Interrupt Request exception.

  • Used for general-purpose interrupt handling.
  • Has a banked R13 (SP) and R14 (LR).
  • Has its own SPSR.
  • Supports execution of an interrupt service routine.

3.4 Supervisor Mode (SVC)

Supervisor Mode is a privileged mode entered after a Reset or when a Software Interrupt (SWI) instruction is executed. In ARMv4 terminology, SWI is the software interrupt instruction.

  • Used for system-level operations.
  • Entered after processor reset.
  • Entered when a software interrupt exception occurs.
  • Has banked R13, R14 and SPSR.

3.5 Abort Mode (ABT)

Abort Mode is entered when the processor detects certain memory access exceptions.

  • Used for handling memory access faults.
  • Includes Prefetch Abort and Data Abort handling.
  • Has banked R13, R14 and SPSR.

3.6 Undefined Mode (UND)

Undefined Mode is entered when the processor encounters an instruction that it cannot execute or recognize as a supported instruction.

  • Used for handling undefined instruction exceptions.
  • Can support software emulation of unsupported instructions.
  • Has banked R13, R14 and SPSR.

3.7 System Mode (SYS)

System Mode is a privileged mode that uses the same general-purpose register bank as User Mode.

  • Used for privileged application or operating-system code.
  • Shares the User Mode register bank.
  • Does not have a separate banked SPSR.
  • Provides privileged execution without switching to an exception mode.

5. Privileged and Unprivileged Modes

5.1 Unprivileged Mode

User Mode is the only unprivileged operating mode in ARM7TDMI-S. It restricts access to certain processor control operations.

5.2 Privileged Modes

FIQ, IRQ, Supervisor, Abort, Undefined and System modes are privileged. They can access processor control operations that are restricted in User Mode.

Interview point: System Mode is privileged, but it shares the User Mode register bank. It does not have a separate SPSR.

6. Banked Registers

Banked registers are registers that have separate physical copies for particular processor modes. When the processor changes mode, the appropriate register bank becomes visible.

Banking helps preserve execution context and can reduce the number of register-saving operations required during exception handling.

6.1 Common Registers

The ARM7 programmer's register set contains R0 through R15:

  • R0–R12: General-purpose registers.
  • R13: Stack Pointer (SP).
  • R14: Link Register (LR).
  • R15: Program Counter (PC).

6.2 Mode-Specific Register Banking

Each exception mode also has its own Saved Program Status Register (SPSR), except User and System modes.

6.3 Why Does FIQ Have More Banked Registers?

FIQ Mode has additional banked registers R8–R14. This gives a fast interrupt handler more private registers, reducing the need to save and restore shared registers in many situations.

Example: An FIQ handler can use its banked R8_fiq through R14_fiq registers without immediately overwriting the corresponding User Mode registers.

8. How Does the Processor Change Operating Modes?

The ARM processor can change operating modes as a result of exceptions or through privileged software operations.

Examples

  • Reset causes entry into Supervisor Mode.
  • An accepted IRQ causes entry into IRQ Mode.
  • An accepted FIQ causes entry into FIQ Mode.
  • A software interrupt causes entry into Supervisor Mode.
  • A Data Abort causes entry into Abort Mode.
  • An undefined instruction causes entry into Undefined Mode.
When an exception occurs, the processor saves the previous CPSR into the SPSR of the exception mode and updates the CPSR to reflect the new mode and exception-control state.

9. CPSR Mode Bits

The Current Program Status Register (CPSR) contains processor status and control information. Its lower five bits, M[4:0], identify the current operating mode.

ModeM[4:0]
User10000
FIQ10001
IRQ10010
Supervisor10011
Abort10111
Undefined11011
System11111

These are the ARM7TDMI mode encodings. The CPSR also contains condition flags and interrupt-mask and instruction-state control bits.

Do not confuse operating-mode bits with the ARM/Thumb state bit. The T bit identifies the instruction state, while M[4:0] identifies the operating mode.

10. ARM Operating Modes and Interrupt Handling

IRQ and FIQ modes are especially important in embedded systems because they provide dedicated contexts for interrupt service routines.

10.1 IRQ Mode

IRQ is used for general interrupt processing. When an IRQ is accepted, the processor switches to IRQ Mode and begins exception handling through the IRQ vector.

10.2 FIQ Mode

FIQ is designed for faster interrupt response. Its additional banked registers help reduce context-saving overhead.

The LPC2129 includes a Vectored Interrupt Controller (VIC). Its interrupt sources can be configured to generate IRQ or FIQ requests to the ARM7 core.

12. Common Mistakes

  • Assuming all seven operating modes are privileged.
  • Forgetting that User Mode is unprivileged.
  • Assuming System Mode has a separate SPSR.
  • Confusing IRQ and FIQ.
  • Assuming all modes have separate copies of R0–R12.
  • Confusing CPSR mode bits with the Thumb state bit.
  • Assuming an interrupt handler automatically preserves every register it uses.

13. Interview Questions and Answers

Q1. How many operating modes are available in ARM7TDMI-S?

Seven operating modes.

Q2. Which ARM7 mode is unprivileged?

User Mode.

Q3. Which mode is entered after reset?

Supervisor Mode.

Q4. Which mode is used for fast interrupt handling?

FIQ Mode.

Q5. Which mode is used for general interrupt handling?

IRQ Mode.

Q6. Which mode has the maximum number of banked general-purpose registers?

FIQ Mode.

Q7. What is a banked register?

A banked register is a separate physical register copy associated with a particular processor mode.

Q8. What is the purpose of SPSR?

It stores the previous CPSR value when an exception is entered, allowing processor status to be restored during exception return.

Q9. Does System Mode have its own SPSR?

No. System Mode shares the User Mode register bank and has no separate SPSR.

Q10. Which register identifies the current ARM operating mode?

The M[4:0] bits of the CPSR.
