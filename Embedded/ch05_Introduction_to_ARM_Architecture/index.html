Chapter 05: Introduction to ARM Architecture

Course: Embedded Systems – Complete Study Course

Part 3: ARM7 Microprocessor Architecture

Total Lessons: 10

Learn ARM processor fundamentals, architecture evolution, processor families, operating modes, registers, pipelines and instruction sets.

Chapter Overview

ARM (Advanced RISC Machines) processors are widely used in embedded systems, mobile devices, automotive electronics, industrial control systems and many other applications.

This chapter introduces ARM processor architecture and its development. It explains the RISC design philosophy, ARM processor families, operating modes, register organization, pipeline architecture and instruction set fundamentals.

Connection to LPC2129: The NXP LPC2129 microcontroller uses an ARM7TDMI-S processor core based on the ARMv4T architecture. Understanding ARM fundamentals will help you study its internal architecture and programming model in the following chapters.

Learning Objectives

After completing this chapter, you will be able to:

  • Explain ARM processors and ARM architecture.
  • Describe the evolution of ARM architecture.
  • Identify major ARM processor families.
  • Compare RISC and CISC architectures.
  • Explain ARM processor operating modes.
  • Understand ARM register organization and register banking.
  • Explain the ARM instruction pipeline.
  • Identify the basic ARM and Thumb instruction sets.
  • Understand ARM architecture versions and their features.
  • Relate ARM architecture concepts to the LPC2129 microcontroller.
