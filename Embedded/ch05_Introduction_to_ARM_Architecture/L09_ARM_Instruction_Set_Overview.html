1. Introduction to ARM Instruction Set

An instruction set is the collection of machine-level operations that a processor can understand and execute.

The ARM7TDMI-S processor supports the ARM instruction set and the original Thumb instruction set. These instruction sets allow programmers to perform arithmetic, logical operations, memory transfers, branching, comparisons and processor control.

The ARM instruction set is based on a load/store architecture: most arithmetic and logical operations work on registers, while separate load and store instructions transfer data between registers and memory.

Important: ARM7TDMI-S implements the ARMv4T architecture. Its ARM-state instructions are 32 bits wide, and its original Thumb-state instructions are 16 bits wide.

3. ARM Instruction Format

In ARM state, each standard ARM instruction is 32 bits wide. The instruction contains fields that identify the operation, registers, operand information and optional condition.

The exact bit positions and meanings depend on the instruction format. For example, data-processing instructions and load/store instructions use different encoding formats.

Example Assembly Instruction

ADD R0, R1, R2

Meaning:

  • R1 contains the first operand.
  • R2 contains the second operand.
  • The processor adds both values.
  • The result is stored in R0.

4.3 Example: Arithmetic and Logical Operations

    MOV R1, #10
    MOV R2, #5

    ADD R0, R1, R2     ; R0 = 15
    SUB R3, R1, R2     ; R3 = 5
    AND R4, R1, R2     ; Bitwise AND
    ORR R5, R1, R2     ; Bitwise OR
    EOR R6, R1, R2     ; Bitwise XOR
Expected register values:
  • R0 = 15
  • R3 = 5
  • R4 = 0
  • R5 = 15
  • R6 = 15
The bitwise results assume the initial values R1 = 10 and R2 = 5.

5. Multiply Instructions

ARM7TDMI-S provides instructions for multiplication and multiply-accumulate operations.

InstructionMeaning
MULMultiply two register operands
MLAMultiply two operands and add an accumulator value
UMULLUnsigned long multiply producing a 64-bit result
UMLALUnsigned multiply-accumulate producing a 64-bit result
SMULLSigned long multiply producing a 64-bit result
SMLALSigned multiply-accumulate producing a 64-bit result

Example

    MOV R1, #6
    MOV R2, #4

    MUL R0, R1, R2

Result: R0 = 24.

    MOV R1, #6
    MOV R2, #4
    MOV R3, #10

    MLA R0, R1, R2, R3

Result: R0 = (6 × 4) + 10 = 34.

6. Load and Store Instructions

ARM uses load and store instructions to transfer data between memory and processor registers.

6.1 Load Instructions

  • LDR – Load a 32-bit word.
  • LDRB – Load an unsigned byte and zero-extend it.
  • LDRH – Load an unsigned halfword and zero-extend it.
  • LDRSB – Load a signed byte and sign-extend it.
  • LDRSH – Load a signed halfword and sign-extend it.

6.2 Store Instructions

  • STR – Store a 32-bit word.
  • STRB – Store a byte.
  • STRH – Store a halfword.

Example

    LDR R0, =0x40000000
    MOV R1, #25
    STR R1, [R0]

    LDR R2, [R0]

The example loads an address into R0, stores the value 25 at that address, and then loads the stored word into R2.

The address 0x40000000 is used here only as an illustrative address. Real peripheral addresses must be taken from the specific microcontroller memory map. Do not execute this example against an arbitrary address without checking the target device documentation.

7. Branch Instructions

Branch instructions change the normal sequential flow of program execution.

InstructionPurpose
BBranch to a target address
BLBranch with link; saves return information in LR
BXBranch and exchange instruction-set state
BLXBranch with link and exchange, where supported by the architecture

Example: Branch

    MOV R0, #10
    B   NEXT

    MOV R0, #20

NEXT:
    MOV R1, #30

The branch transfers execution to NEXT. The sequential instruction that sets R0 to 20 is skipped.

Example: Subroutine Call

    BL  ADD_NUMBERS

    ; Execution continues here after return

ADD_NUMBERS:
    ADD R0, R1, R2
    BX  LR

BL stores the return address in the Link Register. BX LR returns to the caller in the appropriate instruction state.

The original ARM7TDMI-S supports BX for ARM/Thumb state exchange. Do not assume the later BLX instruction is available on ARMv4T; BLX was introduced in later ARM architecture revisions.

8. Comparison Instructions

Comparison instructions evaluate operands and update the condition flags in CPSR. They do not normally store an arithmetic result in a general-purpose destination register.

InstructionPurpose
CMPCompare by subtraction
CMNCompare by addition
TSTTest bits using AND
TEQTest equivalence using XOR

Example

    MOV R0, #10
    MOV R1, #10

    CMP R0, R1
    BEQ EQUAL

    MOV R2, #0
    B END

EQUAL:
    MOV R2, #1

END:

CMP updates the condition flags. BEQ branches when the Zero flag is set, indicating equal operands in this example.

If R0 equals R1, R2 becomes 1. Otherwise, R2 becomes 0.

10. Shift and Rotate Operations

ARM data-processing instructions can use shifted register operands. The barrel shifter supports efficient shifting and rotation operations.

OperationMeaning
LSLLogical Shift Left
LSRLogical Shift Right
ASRArithmetic Shift Right
RORRotate Right
RRXRotate Right with Extend

Example

    MOV R0, #4
    MOV R1, R0, LSL #2

R1 = 4 × 2² = 16.

Shifts are useful in bit manipulation, arithmetic scaling, peripheral register operations and efficient low-level code.

11. Status Register Instructions

The ARM7 processor uses the Current Program Status Register (CPSR) and Saved Program Status Registers (SPSRs) to maintain processor status information.

InstructionPurpose
MRSTransfer CPSR or SPSR contents to a general-purpose register
MSRTransfer selected fields from a register or immediate value to CPSR or SPSR

Example

    MRS R0, CPSR

This copies the CPSR value into R0.

Writing CPSR control fields can change processor mode and interrupt-mask settings. Such operations require privileged access and careful handling.

12. Software Interrupt Instruction

The SWI instruction, also called Software Interrupt, causes a software-generated exception.

When SWI executes, the processor enters Supervisor Mode and begins exception processing using the software interrupt exception mechanism.

Example

    SWI 0x01

The immediate value is part of the SWI instruction and can be examined by the exception handler to identify the requested software service.

SWI is the ARMv4T-era terminology used by ARM7TDMI-S. Later ARM architectures and toolchains commonly use the term SVC for the corresponding instruction concept.

13. ARM Load/Store Architecture

ARM follows a load/store architecture. Arithmetic and logical operations normally use register operands rather than directly operating on memory locations.

16. Common Mistakes

  • Confusing ARM instructions with C language statements.
  • Assuming arithmetic instructions normally operate directly on memory.
  • Confusing LDR with STR.
  • Assuming CMP stores the subtraction result in a destination register.
  • Forgetting that conditional instructions depend on CPSR flags.
  • Confusing BL with B.
  • Assuming all later ARM instructions are supported by ARMv4T.
  • Assuming original Thumb instructions are 32 bits wide.
  • Writing privileged CPSR control fields without checking the processor mode.

17. Interview Questions and Answers

Q1. What is an instruction set?

It is the collection of machine instructions supported by a processor.

Q2. Which architecture does ARM7TDMI-S implement?

ARMv4T.

Q3. What is a data-processing instruction?

An instruction that performs arithmetic, logical or related register operations.

Q4. What is the difference between LDR and STR?

LDR transfers data from memory to a register; STR transfers data from a register to memory.

Q5. What does BL do?

It branches to a subroutine and saves return information in LR.

Q6. What is the purpose of CMP?

It compares operands by subtraction and updates condition flags.

Q7. What is the purpose of MRS?

It reads CPSR or SPSR into a general-purpose register.

Q8. What does SWI do?

It generates a software interrupt exception.

Q9. What is the difference between ARM and original Thumb instruction widths?

ARM instructions are 32 bits; original Thumb instructions are 16 bits.

Q10. What is the purpose of BX?

It branches to an address and can exchange between ARM and Thumb states.
