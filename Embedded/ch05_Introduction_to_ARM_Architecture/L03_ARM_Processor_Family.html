Topic: ARM Processor Generations, Families and Applications

1. Introduction to ARM Processor Families

ARM processors are available in different families designed for different computing requirements. Some are intended for simple embedded control, while others are designed for real-time processing, mobile computing and high-performance applications.

ARM processor families have evolved over several generations. Important families include ARM7, ARM9, ARM10, ARM11 and the modern Cortex processor families.

Each family may contain multiple processor models with different performance, memory-system and peripheral-interface capabilities.

Important: A processor family is not the same as an architecture version. A processor family identifies related processor implementations, whereas an architecture version defines the instruction set and architectural behavior.

3. ARM7 Processor Family

ARM7 is one of the important early ARM processor families. It became widely used in embedded systems because of its relatively simple architecture and efficient implementation.

3.1 ARM7TDMI

ARM7TDMI is a popular processor core implementing the ARMv4T architecture.

3.2 Main Features

  • 32-bit RISC processor core.
  • Three-stage instruction pipeline.
  • ARM and Thumb instruction-set support.
  • EmbeddedICE debugging support.
  • JTAG-based debugging interface.
  • Hardware multiplier.
  • Suitable for embedded control applications.

3.3 Applications

  • Industrial controllers.
  • Embedded control systems.
  • Communication devices.
  • Consumer electronics.
  • Legacy automotive electronics.
LPC2129 connection: The NXP LPC2129 uses an ARM7TDMI-S core. Therefore, ARM7 architecture is the primary processor architecture studied in the practical LPC2129 portion of this course.

4. ARM9 Processor Family

ARM9 is a family of processor implementations that provides improved performance and more advanced pipeline and memory-system designs compared with early ARM7 implementations.

4.1 Main Features

  • More advanced pipeline implementations.
  • Separate instruction and data paths in common ARM9 designs.
  • Improved memory-system performance.
  • Support for different cache and memory-management configurations.
  • Used in embedded and application-oriented systems.

4.2 Examples

  • ARM920T.
  • ARM922T.
  • ARM926EJ-S.

4.3 Applications

  • Network equipment.
  • Multimedia devices.
  • Embedded Linux systems.
  • Advanced embedded controllers.

5. ARM10 Processor Family

ARM10 is a processor family developed to provide higher performance and more advanced processing capabilities than earlier ARM implementations.

5.1 Main Features

  • Advanced pipeline organization.
  • Improved instruction execution performance.
  • Enhanced memory-system support.
  • Support for advanced processor implementations.

5.2 Example

ARM1020E is an example of an ARM10-family processor.

5.3 Applications

  • High-performance embedded systems.
  • Networking equipment.
  • Advanced computing applications.

6. ARM11 Processor Family

ARM11 is a family of processors based on the ARMv6 architecture. It introduced additional architectural and implementation improvements for more demanding embedded and multimedia applications.

6.1 Main Features

  • ARMv6 architecture.
  • Improved processor performance.
  • Enhanced media-processing capabilities.
  • Advanced pipeline implementations.
  • Support for cache and memory-management features in suitable models.

6.2 Examples

  • ARM1136J-S.
  • ARM1176JZF-S.

6.3 Applications

  • Early smartphone platforms.
  • Multimedia devices.
  • Consumer electronics.
  • Embedded computing systems.

7. ARM Cortex Processor Families

Cortex is a major ARM processor family classification introduced to address different application requirements. It includes three principal profiles: Cortex-A, Cortex-R and Cortex-M.

7.1 Cortex-A – Application Profile

Cortex-A processors are designed for systems requiring high processing performance and support for rich operating systems and applications.

Features:

  • High-performance processor implementations.
  • Memory-management unit support in relevant models.
  • Advanced cache and memory-system architecture.
  • Support for operating systems such as Linux and Android on suitable platforms.

Applications:

  • Smartphones.
  • Tablets.
  • Single-board computers.
  • Embedded Linux platforms.
  • Application processors.

7.2 Cortex-R – Real-Time Profile

Cortex-R processors are designed for applications requiring predictable response times and high reliability.

Features:

  • Real-time processing capabilities.
  • Deterministic response features.
  • High reliability and safety-oriented capabilities in suitable implementations.
  • Specialized memory-system support.

Applications:

  • Automotive control systems.
  • Industrial control.
  • Storage controllers.
  • Safety-related embedded systems.

7.3 Cortex-M – Microcontroller Profile

Cortex-M processors are designed specifically for microcontroller and embedded control applications.

Features:

  • Designed for microcontroller systems.
  • Efficient interrupt handling.
  • Low-power implementation options.
  • Compact processor architecture.
  • Suitable for real-time embedded applications.

Applications:

  • IoT devices.
  • Sensor-based systems.
  • Industrial automation.
  • Consumer electronics.
  • Motor-control systems.

10. Selecting an ARM Processor Family

Selecting a processor depends on the requirements of the target application.

Requirement Suitable Family
Simple embedded control Cortex-M or an appropriate legacy microcontroller core.
High-performance application processing Cortex-A.
Predictable real-time response Cortex-R or an appropriate real-time MCU.
Legacy LPC2129 development ARM7TDMI-S.

Important Selection Factors

  • Required processing performance.
  • Power consumption.
  • Memory capacity.
  • Real-time requirements.
  • Peripheral availability.
  • Security and reliability requirements.
  • Software and development-tool support.
  • Cost and product lifecycle.

11. ARM Processor Family Used in LPC2129

The LPC2129 belongs to the family of ARM-based microcontrollers using the ARM7TDMI-S processor core.

Important Characteristics

  • 32-bit processor core.
  • ARMv4T architecture.
  • ARM and Thumb instruction-set support.
  • Three-stage pipeline.
  • Integrated memory and peripheral controllers in the microcontroller.
The LPC2129 is a microcontroller, not simply an ARM7 processor. It integrates the ARM7TDMI-S core with on-chip memory and peripheral hardware.

12. Lesson Summary

  • ARM has several processor families designed for different applications.
  • ARM7 is an important traditional embedded processor family.
  • ARM9 and ARM10 introduced more advanced processor implementations.
  • ARM11 implements ARMv6 architecture.
  • Cortex-A is designed for application processing.
  • Cortex-R is designed for real-time processing.
  • Cortex-M is designed for microcontroller applications.
  • ARM7TDMI-S is used in the LPC2129 microcontroller.

13. Interview Questions and Answers

Q1. Name the major traditional ARM processor families.

ARM7, ARM9, ARM10 and ARM11 are important traditional ARM processor families.

Q2. Which ARM processor core is used in LPC2129?

ARM7TDMI-S.

Q3. What is the difference between ARM7 and ARM9?

ARM9 implementations generally provide more advanced pipelines and memory-system capabilities than early ARM7 implementations.

Q4. Which architecture is used by ARM11?

ARM11 processors implement ARMv6 architecture.

Q5. What are the three Cortex processor profiles?

Cortex-A, Cortex-R and Cortex-M.

Q6. Which Cortex profile is suitable for application processors?

Cortex-A.

Q7. Which Cortex profile targets real-time systems?

Cortex-R.

Q8. Which Cortex profile is designed for microcontrollers?

Cortex-M.

Q9. What is the difference between a processor family and an architecture version?

A processor family groups related hardware implementations. An architecture version specifies the architectural instruction set and behavior.

Q10. Is LPC2129 based on Cortex-M?

No. It uses the ARM7TDMI-S processor core.
