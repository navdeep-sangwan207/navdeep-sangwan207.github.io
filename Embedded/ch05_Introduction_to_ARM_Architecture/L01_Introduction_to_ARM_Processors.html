Topic: ARM Processor Fundamentals and Architecture

1. Introduction to ARM Processors

ARM processors are a family of processors based on the ARM (Advanced RISC Machine) architecture. They are widely used in embedded systems, smartphones, automotive electronics, industrial controllers and consumer electronic devices.

ARM architecture is based on the RISC (Reduced Instruction Set Computer) design philosophy. It emphasizes efficient instruction execution, a relatively simple instruction architecture and efficient use of hardware resources.

ARM-based processors are designed and implemented by semiconductor companies using ARM architecture and processor IP licensed from Arm.

Important: ARM is an architecture and processor technology ecosystem. It is not the name of a single microcontroller or a single processor model.

2. What is ARM?

ARM originally stood for Acorn RISC Machine. The name later became Advanced RISC Machines. Today, ARM is commonly used as the name of the processor architecture and technology associated with Arm.

ARM architecture defines how a processor behaves from the programmer's perspective. It specifies features such as:

  • Instruction set and instruction formats.
  • Programmer-visible registers.
  • Processor operating modes and privilege levels.
  • Memory access and data processing behavior.
  • Exception and interrupt handling mechanisms.
  • Memory and system architecture features.

ARM Architecture vs ARM Processor

ARM Architecture ARM Processor
Defines the processor's instruction set and architectural behavior. Implements a particular ARM architecture.
Describes programmer-visible features. Contains physical hardware circuits.
Example: ARMv4T. Example: ARM7TDMI-S.

3. Brief History of ARM

ARM development began at Acorn Computers in the United Kingdom during the 1980s. The first ARM processor was developed as a RISC-based processor for computer systems.

  • 1980s: Initial ARM processor development.
  • 1985: ARM1 prototype was developed.
  • 1990: Advanced RISC Machines Ltd was established.
  • 1990s: ARM processors expanded into embedded applications.
  • 2000s: ARM became widely adopted in mobile and consumer electronics.
  • Modern era: ARM technology is used in mobile, automotive, IoT, networking and computing platforms.
The next lesson, Evolution of ARM Architecture, explains the development of ARM architecture versions in greater detail.

4. ARM and RISC Architecture

ARM processors are traditionally associated with the RISC design philosophy. RISC stands for Reduced Instruction Set Computer.

RISC architecture aims to provide an efficient instruction set and predictable instruction execution behavior. It commonly uses load/store architecture, where data processing instructions operate on registers and separate instructions access memory.

Important RISC Characteristics

  • Load/store-based memory access.
  • Large general-purpose register set.
  • Simple and efficient instruction formats in traditional RISC designs.
  • Efficient instruction decoding.
  • Pipeline-friendly instruction execution.
  • Compiler-friendly instruction architecture.
Note: Modern ARM architectures have evolved considerably. Not every modern ARM instruction has the same simple characteristics as early ARM instructions.

5. Basic Working of an ARM Processor

An ARM processor executes a program by repeatedly fetching, decoding and executing instructions. The processor uses registers, an arithmetic logic unit and control circuitry to perform these operations.

Result Stored in Register or Memory

Basic Instruction Execution Steps

  1. Fetch: The processor reads an instruction from memory.
  2. Decode: The instruction is interpreted by the processor.
  3. Execute: The required operation is performed.
  4. Write Back: The result is stored in a register or memory as required.

These stages form the basic instruction execution process. Actual pipeline organization and timing depend on the processor implementation.

6. Main Components of an ARM Processor

6.1 Arithmetic Logic Unit (ALU)

The ALU performs arithmetic and logical operations such as addition, subtraction, AND, OR, XOR and comparisons.

6.2 Register Bank

Registers are small, high-speed storage locations inside the processor. They hold operands, addresses, intermediate results and processor state information.

6.3 Control Unit

The control unit coordinates instruction decoding, data movement and execution operations.

6.4 Program Counter (PC)

The Program Counter identifies the address associated with the next instruction to be fetched. Its exact visible behavior depends on the ARM architecture state.

6.5 Instruction Decoder

The instruction decoder interprets machine instructions and generates the internal control operations required to execute them.

6.6 Memory Interface

The memory interface allows the processor to fetch instructions and access data from memory and connected system components.

7. Important Features of ARM Processors

  • RISC-based design: ARM architecture originated from RISC principles.
  • Register-based processing: General-purpose registers are used for data operations.
  • Load/store architecture: Memory is accessed through dedicated load and store instructions in traditional ARM instruction sets.
  • Pipeline support: Instructions can be processed through multiple execution stages.
  • Low-power implementations: Many ARM processor designs target power-efficient applications.
  • Scalability: ARM technology is used in small embedded devices and high-performance computing systems.
  • Multiple architecture versions: ARM has developed several architecture generations with different capabilities.

9. ARM Processor vs Microcontroller

An ARM processor is a CPU core or processor implementation. A microcontroller is an integrated device that typically combines a processor core, memory and peripherals on one chip.

ARM Processor Microcontroller
Performs instruction execution and processing. Provides a complete control-oriented computing system.
May be used as a core inside a microcontroller or application processor. Usually integrates CPU, memory and peripherals.
Does not necessarily include all application peripherals. Commonly includes GPIO, timers, UART, ADC and other peripherals.
Example: ARM7TDMI-S core. Example: NXP LPC2129 microcontroller.
Important distinction: ARM7TDMI-S is the processor core. LPC2129 is the microcontroller that integrates this core with memory, peripheral interfaces and other system components.

10. ARM Processor Used in LPC2129

The NXP LPC2129 microcontroller is based on the ARM7TDMI-S processor core. It implements the ARMv4T architecture and supports both ARM and Thumb instruction sets.

13. Interview Questions and Answers

Q1. What is ARM?

ARM is a family of processor architectures based on Reduced Instruction Set Computer principles.

Q2. What does ARM stand for historically?

ARM originally stood for Acorn RISC Machine and later became Advanced RISC Machines.

Q3. What is RISC?

RISC stands for Reduced Instruction Set Computer. It emphasizes an efficient instruction set and register-based processing.

Q4. What is the difference between ARM architecture and processor?

Architecture defines the instruction set and programmer-visible behavior, whereas a processor is a hardware implementation of an architecture.

Q5. Which ARM core is used in LPC2129?

LPC2129 uses the ARM7TDMI-S processor core.

Q6. Which architecture version does ARM7TDMI-S implement?

ARM7TDMI-S implements ARMv4T.

Q7. What is a register?

A register is a small, high-speed storage location inside a processor used to hold data, addresses or processor state information.

Q8. What is a pipeline?

A pipeline is a processor technique that overlaps different stages of instruction processing to improve instruction throughput.

Q9. What is the difference between a processor and a microcontroller?

A processor performs instruction execution, while a microcontroller generally integrates a processor, memory and peripherals on a single chip.

Q10. What are ARM and Thumb instruction sets?

They are instruction-set states supported by certain ARM architectures. ARM7TDMI-S supports 32-bit ARM instructions and 16-bit Thumb instructions.
