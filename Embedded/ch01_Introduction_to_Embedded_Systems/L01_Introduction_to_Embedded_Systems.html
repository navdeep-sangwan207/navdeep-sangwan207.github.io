Chapter 01 – Introduction to Embedded Systems

Level: Beginner | Subject: Embedded Systems

1. Introduction

An embedded system is a combination of hardware and software designed to perform a specific function or a dedicated set of functions within a larger electrical or electronic system.

Unlike a general-purpose computer, which can execute many different applications, an embedded system is usually developed for a particular application and operates according to predefined requirements.

Embedded systems are found in everyday devices such as washing machines, microwave ovens, automobiles, digital cameras, printers, medical equipment, and industrial automation systems.

Definition: An embedded system is a dedicated computing system integrated into a product or machine to monitor, control, or perform a specific function.

Why Are Embedded Systems Used?

  • To automate specific operations.
  • To monitor physical parameters such as temperature and pressure.
  • To control motors, displays, sensors, and actuators.
  • To provide fast and predictable responses.
  • To reduce system size, cost, and power consumption.
  • To improve accuracy, reliability, and efficiency.

2. Basic Concept of an Embedded System

An embedded system receives information from its environment, processes that information using a processor or controller, and produces an appropriate output.

For example, an automatic temperature-control system continuously measures temperature and switches a cooling device ON or OFF according to a predefined condition.

Basic Embedded System Operation

Input Devices / Sensors
↓
Processor / Microcontroller
↓
Output Devices / Actuators

Power Supply supports the complete system.

Basic Working Sequence

  1. Input: A sensor or input device detects a physical condition.
  2. Processing: The processor reads and processes the input.
  3. Decision: The program determines the required action.
  4. Output: An actuator or output device performs the action.

3. Main Components of an Embedded System

An embedded system consists of several hardware and software components that work together.

3.1 Hardware Components

1. Processor / Controller

Executes instructions and controls the operation of the embedded system.

Examples: ARM7, LPC2129, AVR, PIC.

2. Memory

Stores program instructions, configuration data, and temporary processing information.

Examples: ROM, RAM, Flash.

3. Input Devices

Provide information or commands to the embedded system.

Examples: Switches, keypads, sensors.

4. Output Devices

Display information or perform physical actions.

Examples: LEDs, LCDs, motors, relays.

5. Communication Interfaces

Exchange information with other electronic devices.

Examples: UART, SPI, I2C, CAN.

6. Power Supply

Provides the required electrical energy to the processor and other system components.

Examples: Batteries and regulated DC supplies.

3.2 Software Components

  • Firmware: Program stored in non-volatile memory that controls system operation.
  • Device Drivers: Software modules that control and communicate with hardware peripherals.
  • Application Software: Implements the specific function of the product.
  • Real-Time Operating System (RTOS): Manages tasks, scheduling, timing, and system resources when required.
Note: Not every embedded system requires an RTOS. Small microcontroller applications can operate using a simple main loop and interrupt service routines.

5. Working Principle of an Embedded System

Consider a temperature-controlled fan as an example. The system uses a temperature sensor, a microcontroller, and a fan connected through a suitable driver circuit.

Working Steps

  1. The temperature sensor measures the surrounding temperature.
  2. The sensor signal is converted into a form the controller can read.
  3. The microcontroller processes the measured value.
  4. The program compares the temperature with a predefined threshold.
  5. If the temperature exceeds the threshold, the controller activates the fan driver.
  6. When the temperature falls below the required level, the controller reduces or switches off the fan.
Example: If the temperature threshold is 30°C, the fan can be programmed to turn ON above 30°C and turn OFF below a selected lower threshold.

Using separate ON and OFF thresholds is called hysteresis. It helps prevent rapid switching when the measured temperature fluctuates around a single threshold.

7. Embedded System Example Using LPC2129

The LPC2129 is an ARM7TDMI-S based microcontroller that can be used to develop embedded applications. It integrates a processor, memory, GPIO, timers, UART, ADC, and other peripheral interfaces.

Example: LED Blinking System

A simple embedded system can use the LPC2129 to switch an LED ON and OFF through a GPIO pin.

Hardware Configuration

  • Microcontroller: LPC2129
  • Output: LED
  • GPIO pin: P0.5
  • Software: Embedded C
  • Development environment: Keil uVision

Embedded C Program

#include <LPC21xx.h>

void delay(void)
{
    unsigned int i;

    for(i = 0; i < 500000; i++);
}

int main(void)
{
    // Configure P0.5 as GPIO output
    IO0DIR |= (1U << 5);

    while(1)
    {
        // Turn LED ON
        IO0SET = (1U << 5);

        delay();

        // Turn LED OFF
        IO0CLR = (1U << 5);

        delay();
    }
}

Program Explanation

  • #include <LPC21xx.h> includes the LPC2129 register definitions supplied by the device header.
  • IO0DIR configures the direction of Port 0 pins.
  • IO0DIR |= (1U << 5) configures P0.5 as an output.
  • IO0SET sets the selected GPIO output bit.
  • IO0CLR clears the selected GPIO output bit.
  • delay() provides a simple software delay.
  • while(1) repeats the LED ON/OFF operation continuously.
Important: This is an introductory, illustrative GPIO program. The pin must be configured for GPIO through the appropriate PINSEL settings if its default or current configuration selects another function. LED polarity and external connection also determine whether setting the pin turns the LED ON. The software delay is not a calibrated time delay.

Expected Result

  • The program configures P0.5 as an output.
  • The output is set HIGH and then cleared LOW repeatedly.
  • An LED connected appropriately to P0.5 should blink when the target hardware and circuit support the operation.

Keil Simulator: You can inspect the GPIO register operations and program execution in the simulator. Actual LED illumination requires physical hardware and a suitable LED circuit.

8. Advantages of Embedded Systems

  • Dedicated and optimized functionality.
  • Compact size and low hardware cost for many applications.
  • Efficient power consumption in appropriately designed systems.
  • Fast and predictable response where required.
  • High reliability when properly engineered and tested.
  • Easy integration into larger products and machines.
  • Can operate automatically with minimal user interaction.

9. Limitations of Embedded Systems

  • Limited memory and processing resources in many microcontrollers.
  • Application-specific hardware and software may be difficult to reuse.
  • Debugging can be challenging, especially in real-time systems.
  • Hardware upgrades may be difficult after product deployment.
  • Software errors can affect the operation of the complete product.
  • Security and safety requirements can increase development complexity.

11. Interview Questions and Answers

Q1. What is an embedded system?

An embedded system is a dedicated computing system designed to perform a specific function within a larger product or machine.

Q2. What are the main components of an embedded system?

Processor or controller, memory, input devices, output devices, communication interfaces, power supply, and embedded software.

Q3. What is firmware?

Firmware is software stored in non-volatile memory that controls the operation of an embedded device.

Q4. What is the difference between a microprocessor and a microcontroller?

A microprocessor generally requires external memory and peripheral components, whereas a microcontroller integrates a processor, memory, and peripherals on a single chip.

Q5. Does every embedded system require an RTOS?

No. Simple embedded systems can operate using a superloop and interrupts without an RTOS.

Q6. Give five examples of embedded systems.

Washing machines, microwave ovens, automotive ECUs, digital thermometers, and traffic-light controllers.

Q7. What is the role of a sensor in an embedded system?

A sensor detects a physical parameter such as temperature, pressure, light, or motion and provides a corresponding signal to the system.

Q8. What is an actuator?

An actuator converts a control signal into a physical action, such as motor movement or valve operation.

12. Multiple Choice Questions (MCQs)

1. An embedded system is primarily designed to:

  1. Perform every possible computing task
  2. Perform a specific function
  3. Replace all desktop computers
  4. Store unlimited data
Correct Answer: B – Perform a specific function.

2. Which component executes program instructions?

  1. Sensor
  2. Actuator
  3. Processor
  4. Power supply
Correct Answer: C – Processor.

3. Which memory is commonly used to store embedded firmware?

  1. RAM
  2. Flash memory
  3. Cache only
  4. Register only
Correct Answer: B – Flash memory.

4. Which of the following is an input device?

  1. LED
  2. Motor
  3. Temperature sensor
  4. Relay
Correct Answer: C – Temperature sensor.

5. Which of the following is a communication interface?

  1. UART
  2. LED
  3. Relay
  4. Battery
Correct Answer: A – UART.

14. Lesson Summary

  • An embedded system is designed for a specific application or set of functions.
  • It combines hardware and software to perform dedicated operations.
  • Its major components include a processor, memory, input/output devices, and communication interfaces.
  • Sensors provide information, while actuators perform physical actions.
  • Firmware controls the embedded system's operation.
  • Embedded systems are used in automotive, industrial, healthcare, consumer, and communication applications.
  • The LPC2129 is an example of a microcontroller used for embedded system development.
