Lesson 06: ADC Channel Selection and Pin Configuration

Chapter 13: LPC2129 ADC and DAC

Learn the four analog input channels, physical pin mapping, PINSEL1 configuration and ADC channel selection.

1. Introduction

The LPC2129 contains a single 10-bit successive-approximation ADC with four multiplexed analog input channels.

These channels allow the microcontroller to measure analog voltage signals from up to four different input pins.

The four ADC input channels are:

  • AIN0 - Analog Input 0
  • AIN1 - Analog Input 1
  • AIN2 - Analog Input 2
  • AIN3 - Analog Input 3
The four inputs share one ADC conversion unit. The ADC selects an input channel through the SEL field of ADCR. It is not a pair of independent ADC0 and ADC1 peripherals.

The ADC input voltage range is specified in the LPC2129 datasheet. The original device documentation specifies a 0 V to 3 V measurement range. Do not assume that the full 3.3 V digital supply is automatically a valid measurement range.

3. Analog Input Multiplexer

The ADC contains an input multiplexer that connects one selected analog input channel to the conversion circuit.

Since the LPC2129 has four input channels but one ADC conversion unit, the multiplexer selects which input is measured.

Why is a Multiplexer Required?

  • It allows one ADC unit to measure multiple analog signals.
  • It reduces the need for separate ADC conversion hardware.
  • Software can select the input channel required by the application.
  • Multiple sensor signals can be measured sequentially.

4. PINSEL1 Register

The PINSEL1 register controls alternate functions of Port 0 pins P0.16 to P0.31.

The ADC-capable pins P0.27 to P0.30 have two-bit function-selection fields in PINSEL1.

Pin PINSEL1 Bits ADC Function Selection
P0.27 23:22 01 - AIN0
P0.28 25:24 01 - AIN1
P0.29 27:26 01 - AIN2
P0.30 29:28 01 - AIN3

Pin Function Selection Values

The two-bit function field uses these values:

Value Function
00 GPIO
01 ADC analog input function
10 Timer capture input
11 Timer match output
Important: The LPC2129 documentation states that its analog inputs remain connected to their pins regardless of the selected digital/alternate pin function. Therefore, selecting the ADC function in PINSEL1 is not mandatory just to obtain an ADC reading. It is useful to understand the pin's alternate-function configuration.

5. Configuring AIN0 Using PINSEL1

P0.27 is associated with AIN0. Its function-selection field is PINSEL1 bits 23:22.

To select the AIN0 function:

PINSEL1 &= ~(3U << 22);
PINSEL1 |=  (1U << 22);

Explanation:

  • 3U << 22 creates a mask for bits 23:22.
  • The first statement clears the selected field.
  • The second statement writes 01 to that field.

6. Configuring AIN1 Using PINSEL1

P0.28 is associated with AIN1. Its function-selection field is PINSEL1 bits 25:24. 

PINSEL1 &= ~(3U << 24);
PINSEL1 |=  (1U << 24);

This selects the AIN1 alternate function in the corresponding PINSEL1 field.

7. Configuring AIN2 Using PINSEL1

P0.29 is associated with AIN2. Its function-selection field is PINSEL1 bits 27:26. 

PINSEL1 &= ~(3U << 26);
PINSEL1 |=  (1U << 26);

8. Configuring AIN3 Using PINSEL1

P0.30 is associated with AIN3. Its function-selection field is PINSEL1 bits 29:28. 

PINSEL1 &= ~(3U << 28);
PINSEL1 |=  (1U << 28);
P0.30 also has external interrupt and timer capture functions. Selecting one alternate digital function affects the other digital functions on that pin. The ADC analog input remains connected as documented.

9. ADC Channel Selection Through ADCR

The SEL field of the LPC2129 ADC Control Register (ADCR) selects the analog input channels.

For the LPC2129, bits 3:0 are used for the four available ADC channels.

ADCR SEL Bit Selected Input
Bit 0 AIN0
Bit 1 AIN1
Bit 2 AIN2
Bit 3 AIN3

Select AIN0

ADCR = (1U << 0);

Select AIN1

ADCR = (1U << 1);

Select AIN2

ADCR = (1U << 2);

Select AIN3

ADCR = (1U << 3);
The SEL field is different from the PINSEL1 field. SEL chooses the ADC channel for conversion, whereas PINSEL1 configures the alternate digital function associated with the physical Port 0 pin.

10. Selecting Multiple ADC Channels

The ADC supports burst conversion of one or multiple selected inputs. Multiple channel bits can be set in the SEL field when using the appropriate conversion mode.

Select AIN0 and AIN1

ADCR = (1U << 0) | (1U << 1);

Select All Four Channels

ADCR = 0x0FU;

The selected inputs can then be converted according to the ADC operating mode. In burst mode, the ADC repeatedly converts the selected channels.

Multiple channel selection does not mean that all four analog inputs are converted simultaneously. They share the ADC conversion hardware.

11. Complete Pin and Channel Configuration Example

The following example configures all four ADC-capable pins for their documented AIN alternate functions and selects AIN0 in the ADC control register. 

#include <LPC21xx.h>

#define ADC_AIN0   (1U << 0)

void ADC_Pin_Config(void)
{
    /*
       P0.27 = AIN0
       P0.28 = AIN1
       P0.29 = AIN2
       P0.30 = AIN3

       PINSEL1 fields:
       P0.27 = bits 23:22
       P0.28 = bits 25:24
       P0.29 = bits 27:26
       P0.30 = bits 29:28
    */

    PINSEL1 &= ~(0xFFU << 22);

    PINSEL1 |=  (1U << 22);
    PINSEL1 |=  (1U << 24);
    PINSEL1 |=  (1U << 26);
    PINSEL1 |=  (1U << 28);
}

void ADC_Select_AIN0(void)
{
    /*
       Select channel 0.
       Other ADCR configuration fields
       are handled in the ADC initialization.
    */

    ADCR &= ~0x0FU;
    ADCR |= ADC_AIN0;
}

int main(void)
{
    ADC_Pin_Config();

    ADC_Select_AIN0();

    while (1)
    {
        /*
           Conversion start, completion checking
           and result reading are covered in
           the following lessons.
        */
    }
}
This is a pin and channel selection example only. It does not configure the complete ADC clock, power state, conversion start or result reading.

12. Analog Input Voltage Requirements

An ADC measures an analog voltage relative to its analog reference and ground.

The LPC2129 datasheet specifies a 0 V to 3 V measurement range for the ADC.

Input Voltage Examples

Input Voltage Expected ADC Behavior
0 V Near minimum conversion code.
0.5 V Low digital conversion value.
1.5 V Approximately half-scale.
2.5 V High digital conversion value.
3 V Near full-scale conversion code.
Approximate ADC Code = (Vin / Vref) × 1023

For a nominal 3 V measurement range, an input near 1.5 V produces a result close to half-scale.

The ADC analog supply and ground must be connected correctly. Do not exceed the specified analog input voltage or device absolute maximum ratings.

Temperature Sensor

An analog temperature sensor can be connected to AIN1, provided its output voltage remains within the permitted ADC input range.

Battery Voltage Measurement

A suitable resistor divider can scale a battery voltage to the ADC input range.

A resistor divider must be designed so that the ADC input never exceeds the allowed voltage. Consider resistor tolerances, source impedance and protection requirements.

14. Common Programming Mistakes

  • Assuming LPC2129 has ADC0 and ADC1 peripherals.
  • Using AD0CR instead of the LPC2129 ADCR register.
  • Assuming the LPC2129 has eight ADC channels.
  • Confusing PINSEL1 pin-function bits with ADCR channel-selection bits.
  • Selecting a channel that does not exist on the device.
  • Applying voltage above the permitted analog input range.
  • Using P0.27 to P0.30 for another digital function without considering pin multiplexing.
  • Assuming that multiple selected channels convert simultaneously.
  • Forgetting to configure the ADC operating clock.

16. Interview Questions and Answers

Q1. How many ADC channels are available in LPC2129?

Four channels: AIN0, AIN1, AIN2 and AIN3.

Q2. What is the resolution of the LPC2129 ADC?

10 bits.

Q3. Which pin is connected to AIN0?

P0.27.

Q4. Which pin is connected to AIN3?

P0.30.

Q5. Which register selects the ADC channel?

The SEL field of ADCR.

Q6. Which register controls the alternate functions of P0.27 to P0.30?

PINSEL1.

Q7. Is PINSEL1 configuration mandatory for ADC input reading?

No. The analog input is always connected to its pin. PINSEL1 controls the digital and alternate pin functions.

Q8. What is the purpose of the ADC input multiplexer?

It connects the selected analog input channel to the shared ADC conversion circuit.

Q9. Can all four channels be converted simultaneously?

No. The four channels share one ADC conversion unit.

19. Lesson Summary

  • LPC2129 has one 10-bit ADC with four multiplexed channels.
  • AIN0 is connected to P0.27.
  • AIN1 is connected to P0.28.
  • AIN2 is connected to P0.29.
  • AIN3 is connected to P0.30.
  • PINSEL1 controls alternate digital functions of these pins.
  • Analog inputs remain connected to the ADC regardless of digital pin-function selection.
  • ADCR SEL bits 3:0 select the ADC channel or channels.
  • The ADC input multiplexer connects a selected input to the conversion circuit.
  • The four channels share one ADC conversion unit.
