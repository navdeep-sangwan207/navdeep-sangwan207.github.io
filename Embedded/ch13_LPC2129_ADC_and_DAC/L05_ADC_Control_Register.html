Lesson 05: ADC Control Register

Chapter 13: LPC2129 ADC and DAC

Understand ADC control register fields and configure conversion operation using Embedded C.

1. Introduction

The ADC Control Register configures and controls the Analog-to-Digital Converter peripheral in the LPC2129.

The LPC2129 provides two ADC peripherals:

  • AD0CR: ADC0 Control Register.
  • AD1CR: ADC1 Control Register.

These registers allow the embedded application to select an analog input channel, configure the ADC clock, select conversion behavior and start a conversion.

AD0CR and AD1CR have corresponding control functions. The register selected depends on whether ADC0 or ADC1 is being configured.

2. ADC Control Register Structure

The ADC Control Register is a 32-bit memory-mapped register. Its fields control channel selection, clock division, burst operation, conversion clock selection, power state and conversion start conditions.

AD0CR / AD1CR Bit Fields

Bit Position Field Function
7:0 SEL Selects ADC input channels.
15:8 CLKDIV Configures the ADC clock divider.
16 BURST Enables or disables burst conversion mode.
19:17 CLKS Selects conversion clock cycles and affects conversion resolution.
20 Reserved Reserved bit.
21 PDN Controls ADC operational power state.
23:22 Reserved Reserved bits.
26:24 START Selects the conversion start condition.
27 EDGE Selects the external trigger edge when applicable.
31:28 Reserved Reserved bits.
Reserved bits must be kept at their documented reset or required values. Do not use them as general-purpose configuration fields.

3. SEL – Channel Selection Bits

The SEL field occupies bits 7:0 of AD0CR or AD1CR. It selects which ADC input channel or channels are included in conversion operation.

Each bit corresponds to one ADC channel:

Bit Selected Channel
Bit 0Channel 0
Bit 1Channel 1
Bit 2Channel 2
Bit 3Channel 3
Bit 4Channel 4
Bit 5Channel 5
Bit 6Channel 6
Bit 7Channel 7

Example: Select Channel 0

AD0CR = (1U << 0);

Example: Select Channel 5

AD0CR = (1U << 5);

Example: Select Channels 0 and 5

AD0CR = (1U << 0) | (1U << 5);
In software-controlled conversion, selecting one channel is the usual approach when measuring one analog signal. Multiple selected channels are particularly relevant to burst conversion mode.

4. CLKDIV – ADC Clock Divider

The CLKDIV field occupies bits 15:8. It divides the peripheral clock to generate the ADC clock.

ADC Clock = PCLK / (CLKDIV + 1)

The ADC clock must remain within the operating frequency specified by the LPC2129 datasheet.

Example Using the Project Clock

Given:

  • CCLK = 60 MHz
  • VPBDIV = 0x00
  • PCLK = 15 MHz
  • CLKDIV = 3
ADC Clock = 15 MHz / (3 + 1)
ADC Clock = 3.75 MHz

Embedded C Configuration

#define ADC_CLKDIV  3U

AD0CR = (ADC_CLKDIV << 8);
The divider value is selected according to the permitted ADC clock frequency. The example uses a 15 MHz PCLK and produces a 3.75 MHz ADC clock. Always verify the device's maximum ADC clock specification and conversion timing.

5. BURST – Burst Conversion Mode

The BURST bit is bit 16 of the ADC Control Register. It selects between software-started conversion and continuous conversion behavior.

BURST Bit Operation
0 Conversions are controlled using the START field.
1 Repeated conversions are performed on the selected channels.

Software-Controlled Conversion

AD0CR &= ~(1U << 16);

Burst Mode

AD0CR |= (1U << 16);
In burst mode, the ADC repeatedly converts the selected channels. The START field is not used to initiate each individual conversion in this mode.
Burst mode is not appropriate when the application needs a single explicitly timed conversion. Consider power consumption, conversion rate and result handling when selecting this mode.

6. CLKS – Conversion Clock Selection

The CLKS field occupies bits 19:17. It selects the number of ADC clock cycles used for conversion.

The conversion clock selection also affects the effective conversion resolution. The full 10-bit result requires the documented full-resolution setting.

CLKS Value ADC Clocks Nominal Resolution
0001110 bits
001109 bits
01098 bits
01187 bits
10076 bits
10165 bits
11054 bits
11143 bits

Full 10-bit Resolution

AD0CR &= ~(7U << 17);

This clears the CLKS field and selects the 11-clock conversion setting.

Selecting fewer conversion clocks reduces the nominal resolution. For ordinary 10-bit ADC measurements, use the full-resolution setting unless a different mode is specifically required.

7. PDN – Power-Down Control

The PDN bit is bit 21 of the ADC Control Register. It controls whether the ADC is in its operational or power-down state.

PDN Bit ADC State
0 Power-down state.
1 Operational state.

Power Up ADC

AD0CR |= (1U << 21);

Power Down ADC

AD0CR &= ~(1U << 21);
Set PDN to 1 when the ADC must operate. Power-down configuration is useful when the ADC is not required and the application needs to reduce peripheral power.

8. START – Conversion Start Control

The START field occupies bits 26:24. It determines how a conversion is initiated when burst mode is disabled.

START Value Function
000 No conversion start.
001 Start conversion immediately.
010–111 Start conversion using selected external hardware trigger conditions.

Start Conversion Immediately

AD0CR &= ~(7U << 24);
AD0CR |=  (1U << 24);

The value 001 in the START field requests an immediate conversion.

Return START Field to Idle

AD0CR &= ~(7U << 24);
External trigger selections depend on the ADC instance and the corresponding capture or match input. Verify the exact trigger mapping and pin configuration in the LPC2129 user manual before using an external trigger.

9. EDGE – External Trigger Edge Selection

The EDGE bit is bit 27. It is used with applicable external hardware-trigger configurations to select the triggering edge.

EDGE Bit Trigger Edge
0 Rising edge.
1 Falling edge.

A rising edge is a transition from logic LOW to logic HIGH. A falling edge is a transition from logic HIGH to logic LOW.

Rising Edge

LOW   ↗   HIGH


Falling Edge

HIGH   ↘   LOW

EDGE is relevant to external trigger operation. It is not required for the immediate software-start example in this lesson.

10. Configuring AD0CR for Channel 0

The following example configures ADC0 for channel 0, a suitable ADC clock divider, full-resolution conversion and software-controlled immediate conversion.

Configuration Values

Field Configuration
SEL Channel 0
CLKDIV 3
BURST 0
CLKS 000
PDN 1
START 001 for immediate start 
#include <LPC21xx.h>

#define ADC_CHANNEL_0  (1U << 0)
#define ADC_CLKDIV     3U

void ADC0_Init(void)
{
    AD0CR = 0;

    AD0CR =
        ADC_CHANNEL_0 |
        (ADC_CLKDIV << 8) |
        (1U << 21);
}

void ADC0_StartConversion(void)
{
    AD0CR &= ~(7U << 24);
    AD0CR |=  (1U << 24);
}

int main(void)
{
    ADC0_Init();

    while (1)
    {
        ADC0_StartConversion();

        /*
           Conversion completion checking and
           result reading are covered in later lessons.
        */
    }
}
This is a control-register configuration example, not a complete measurement application. It does not wait for conversion completion or read the result. Those operations are covered in Lessons 06–08.

11. Constructing the AD0CR Value

Register fields can be combined using bitwise OR. For the example configuration:

  • Channel 0 = 0x00000001
  • CLKDIV = 3, shifted by 8 = 0x00000300
  • PDN = bit 21 = 0x00200000
AD0CR = 0x00000001
| 0x00000300
| 0x00200000
= 0x00200301

This value configures ADC0 for channel 0, CLKDIV 3 and operational power state. The START field remains zero until the software requests conversion.

12. Common Programming Mistakes

  • Using the wrong ADC control register.
  • Selecting an ADC channel without configuring its pin function.
  • Using a clock divider that produces an ADC clock above the permitted limit.
  • Forgetting to set PDN to 1.
  • Using burst mode when single software-controlled conversion is required.
  • Choosing a reduced-resolution CLKS setting unintentionally.
  • Starting conversion before completing ADC configuration.
  • Assuming that setting START means conversion has already completed.
  • Ignoring the ADC result status and completion indication.

14. Interview Questions and Answers

Q1. What is the purpose of AD0CR?

It configures and controls the ADC0 peripheral.

Q2. What is the SEL field?

It selects the ADC input channel or channels.

Q3. What is the function of CLKDIV?

It divides PCLK to generate the ADC clock.

Q4. What does BURST = 1 mean?

It enables repeated conversions on selected channels.

Q5. What is the purpose of CLKS?

It selects the number of ADC clock cycles used for conversion and affects nominal conversion resolution.

Q6. What does PDN = 1 indicate?

The ADC is in its operational state.

Q7. What does START = 001 do?

It requests an immediate software-started conversion.

Q8. What is the purpose of EDGE?

It selects the triggering edge for applicable external-trigger conversion modes.

Q9. What is the ADC clock when PCLK is 15 MHz and CLKDIV is 3?

3.75 MHz.

17. Lesson Summary

  • AD0CR controls ADC0 and AD1CR controls ADC1.
  • SEL bits 7:0 select input channels.
  • CLKDIV bits 15:8 configure ADC clock division.
  • BURST bit 16 enables repeated conversion mode.
  • CLKS bits 19:17 select conversion clock cycles.
  • PDN bit 21 controls the ADC operational power state.
  • START bits 26:24 select conversion start conditions.
  • EDGE bit 27 selects an applicable external trigger edge.
  • The ADC clock must remain within the specified device limits.
