Lesson 09: DAC Fundamentals and Applications

Chapter 13: LPC2129 ADC and DAC

Understand digital-to-analog conversion, DAC resolution, output voltage calculations, DAC architectures and external DAC interfacing in embedded systems.

1. Introduction to DAC

A Digital-to-Analog Converter (DAC) is an electronic circuit that converts a digital input value into a corresponding analog voltage or current.

Microcontrollers and processors work internally with digital data. However, many real-world applications require continuously varying analog signals.

A DAC converts digital information into an analog output that can be used by external circuits.

Examples of DAC Applications

  • Audio signal generation.
  • Analog waveform generation.
  • Motor speed reference generation.
  • Programmable voltage generation.
  • Industrial process control.
  • Signal generation for instrumentation.
The LPC2129 microcontroller contains an ADC but does not provide an on-chip DAC. DAC functionality must therefore be implemented using an external DAC IC, PWM with filtering, or another suitable external circuit.

2. Basic Working Principle of DAC

A DAC receives a binary digital value and generates an analog output proportional to that value.

Digital Input

↓
DAC Converter

↓
Analog Output

↓
Analog Circuit / Load

Example

Consider a 4-bit DAC with a 5 V reference voltage. Its digital input can range from 0000 to 1111.

Digital Input Decimal Value Approximate Output
0000 0 0 V
0001 1 0.333 V
0010 2 0.667 V
0100 4 1.333 V
1000 8 2.667 V
1111 15 5 V

These values use an endpoint-scaled ideal transfer convention. Actual DAC output codes depend on the DAC's specified transfer function.

3. DAC Resolution

DAC resolution represents the number of discrete output levels that a DAC can generate.

It depends on the number of digital input bits.

Number of Output Codes = 2N

Where N is the DAC resolution in bits.

Resolution Number of Codes Digital Code Range
4-bit 16 0–15
8-bit 256 0–255
10-bit 1024 0–1023
12-bit 4096 0–4095
16-bit 65536 0–65535

Example

An 8-bit DAC has:

Number of Codes = 28 = 256
Minimum Code = 0
Maximum Code = 255

Increasing the resolution provides more output levels and smaller voltage steps.

4. DAC Output Voltage Calculation

For an ideal unipolar DAC using the endpoint-scaled convention, the output voltage is calculated as:

VOUT = (Digital Code / (2N - 1)) × VREF

Where:

  • VOUT = Analog output voltage.
  • Digital Code = Input binary value converted to decimal.
  • N = DAC resolution.
  • VREF = Reference voltage.

Example 1: 8-bit DAC

Given:

  • Resolution = 8 bits.
  • Digital input = 128.
  • Reference voltage = 5 V.
VOUT = (128 / 255) × 5
VOUT ≈ 2.51 V

Example 2: 12-bit DAC

Given:

  • Resolution = 12 bits.
  • Digital input = 2048.
  • Reference voltage = 3.3 V.
VOUT = (2048 / 4095) × 3.3
VOUT ≈ 1.6504 V
Some DAC datasheets define output as Code × VREF / 2N, rather than using 2N - 1. Always use the transfer equation specified by the selected DAC datasheet.

5. DAC Step Size

Step size is the approximate change in analog output when the digital input increases by one.

Step Size = VREF / (2N - 1)

Example: 8-bit DAC with 5 V Reference

Step Size = 5 / 255
Step Size ≈ 19.61 mV

Each increment in the digital input increases the ideal output by approximately 19.61 mV under this transfer convention.

Effect of Resolution

  • Higher resolution produces smaller voltage steps.
  • Smaller steps provide finer output control.
  • Actual accuracy also depends on DAC specifications.

6. Types of DAC Architectures

1. Binary Weighted Resistor DAC

A binary weighted resistor DAC uses resistors with binary-related values to generate an analog output from digital input bits.

  • Uses weighted resistor branches.
  • Can be implemented with an operational amplifier.
  • Requires a wide range of accurate resistor values.
  • High-resolution implementation can be difficult.

2. R-2R Ladder DAC

An R-2R ladder DAC uses a resistor network containing only two resistor values: R and 2R.

  • Uses repeated R and 2R resistor sections.
  • Provides binary-weighted contributions.
  • Requires fewer distinct resistor values.
  • Suitable for integrated DAC implementations.

3. Current Steering DAC

A current steering DAC uses controlled current sources that are switched according to digital input bits.

  • Provides fast conversion.
  • Used in high-speed signal generation.
  • Requires accurate current-source matching.
  • Common in communication and instrumentation systems.

4. PWM-Based DAC

Pulse Width Modulation (PWM) can generate an approximate analog voltage by varying the duty cycle of a digital output and passing it through a low-pass filter.

↓
Low-Pass Filter

↓
Smoothed Analog Voltage

PWM is not a true DAC conversion method. It produces an averaged voltage that depends on duty cycle, switching frequency and filter design.

8. DAC Interfacing with a Microcontroller

Since the LPC2129 does not contain an on-chip DAC, an external DAC IC is required when a dedicated analog output is needed.

The microcontroller sends digital data to the external DAC through an interface such as:

  • SPI – Serial Peripheral Interface.
  • I2C – Inter-Integrated Circuit.
  • Parallel GPIO interface.
LPC2129

↓
SPI / I2C / Parallel Data

↓
External DAC IC

↓
Analog Output

Important Interfacing Requirements

  • Check the DAC supply voltage and logic-level compatibility.
  • Configure the communication interface correctly.
  • Use the DAC's specified reference voltage.
  • Observe the digital input format and data alignment.
  • Provide suitable output buffering if required.
  • Follow the DAC datasheet for timing and control signals.

10. DAC Output Voltage Calculation – MCP4921

The MCP4921 provides a 12-bit digital input. Its ideal output depends on the reference voltage, gain configuration and input code.

For the normal gain setting, the ideal output transfer is approximately:

VOUT = VREF × D / 4096

Where:

  • VREF = External reference voltage.
  • D = 12-bit input code, from 0 to 4095.

Example

Given:

  • Reference voltage = 4.096 V.
  • Digital input code = 2048.
  • Gain = 1x.
VOUT = 4.096 × 2048 / 4096
VOUT = 2.048 V

The actual output is also subject to the DAC's electrical specifications, reference accuracy and output loading.

11. Generating Analog Output Using PWM

A microcontroller without an integrated DAC can generate an approximate analog voltage using PWM and a low-pass filter.

For an ideal PWM signal switching between 0 V and VDD, the average output is:

VAVG = Duty Cycle × VDD

Example

Given:

  • Supply voltage = 3.3 V.
  • PWM duty cycle = 50%.
VAVG = 0.5 × 3.3
VAVG = 1.65 V

Embedded C Concept

unsigned int duty_percent = 50;

/*
   Configure the LPC2129 PWM peripheral
   and set the appropriate match value
   according to the PWM period.
*/

PWM_MATCH_VALUE =
    (PWM_PERIOD * duty_percent) / 100U;

The variable and register names above are illustrative. Actual LPC2129 PWM register configuration is covered in Chapter 14.

A low-pass filter is required to smooth the PWM waveform. Filter cutoff frequency, ripple, load current and response time determine the quality of the approximate analog output.

12. DAC Applications

1. Audio Signal Generation

DACs convert digital audio samples into analog signals that can be amplified and played through speakers or headphones.

2. Function Generator

A microcontroller can send digital samples to a DAC to generate sine, square or triangular waveforms.

3. Motor Control

DAC output can provide an analog reference voltage to a motor-control circuit or drive controller.

4. Industrial Automation

DACs can generate analog control signals for actuators, valves and instrumentation systems.

5. Programmable Power Supply

A DAC can generate a reference voltage used by a voltage-control circuit.

6. Sensor Signal Simulation

DAC output can provide controlled analog signals for testing and calibration systems.

14. Common DAC Design Mistakes

  • Using an incorrect DAC resolution in voltage calculations.
  • Ignoring the DAC's actual transfer-function equation.
  • Using an incorrect reference voltage.
  • Exceeding the DAC supply or output voltage limits.
  • Ignoring logic-level compatibility between MCU and DAC.
  • Configuring the wrong SPI clock mode or data format.
  • Ignoring DAC settling time.
  • Driving a heavy load directly from an output not designed for it.
  • Ignoring output filtering when using PWM as an approximate DAC.
  • Assuming the LPC2129 has a built-in DAC peripheral.

16. Interview Questions and Answers

Q1. What is a DAC?

A DAC converts digital input data into an analog voltage or current.

Q2. What determines DAC resolution?

The number of digital input bits.

Q3. How many output codes are available in an 8-bit DAC?

256 codes, ranging from 0 to 255.

Q4. What is an R-2R ladder DAC?

A DAC architecture using a resistor network with two resistor values, R and 2R.

Q5. What is settling time?

The time required for the DAC output to reach and remain within a specified error band after an input change.

Q6. Does LPC2129 contain an on-chip DAC?

No. It contains an ADC but no dedicated on-chip DAC.

Q7. How can LPC2129 generate an approximate analog voltage?

By using PWM followed by an appropriate low-pass filter.

Q8. What is the purpose of a DAC reference voltage?

It establishes the voltage scale for the analog output.

Q9. What is an R-2R ladder advantage?

It uses only two resistor values, simplifying resistor matching and implementation.

Q10. Name an external DAC that can communicate over SPI.

MCP4921 is one example.

20. Lesson Summary

  • DAC converts digital data into analog voltage or current.
  • DAC resolution determines the number of output codes.
  • Output voltage depends on digital code and reference voltage.
  • Step size describes the change between adjacent output levels.
  • Common architectures include binary weighted, R-2R and current steering.
  • PWM with a low-pass filter can generate an approximate analog voltage.
  • DAC performance depends on accuracy, linearity, settling time and other parameters.
  • LPC2129 does not provide an on-chip DAC.
  • An external DAC can be connected through SPI, I2C or parallel GPIO.
  • MCP4921 is an example of an external 12-bit SPI DAC.
