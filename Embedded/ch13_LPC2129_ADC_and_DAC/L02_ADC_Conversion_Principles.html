1. Introduction to ADC Conversion

An Analog-to-Digital Converter converts a continuously varying analog input signal into a digital representation that can be processed by a microcontroller.

Since an analog signal can vary continuously in both time and amplitude, it must be represented using discrete samples and discrete digital levels.

The basic ADC conversion process consists of:

  1. Sampling
  2. Quantization
  3. Encoding

2. Sampling

Sampling is the process of measuring the instantaneous amplitude of an analog signal at specific time intervals.

The ADC does not continuously process every possible value of the input signal. Instead, it takes measurements at selected time instants.

Sampling Example

Consider an analog signal whose voltage changes with time. Sampling measures its voltage at regular intervals.

Analog Signal and Sampled Values

Blue: continuous analog signal. Orange: sample points.

Sampling Frequency

Sampling frequency is the number of samples taken per second. It is measured in Hertz (Hz).

Sampling Frequency (fs) = 1 / Sampling Period (Ts)

Where:

  • fs: Sampling frequency in samples per second.
  • Ts: Time interval between consecutive samples.

Example

If an ADC takes one sample every 1 millisecond:

Ts = 1 ms = 0.001 seconds
fs = 1 / 0.001 = 1000 Hz

The sampling frequency is 1 kHz.

Sampling frequency determines how frequently the input signal is measured. It is different from ADC conversion resolution.

3. Nyquist Sampling Theorem

The Nyquist sampling theorem states that a band-limited signal must be sampled at a frequency greater than twice its highest frequency component for ideal reconstruction.

fs > 2 x fmax

Where:

  • fs: Sampling frequency.
  • fmax: Highest frequency component of the input signal.

Example

Suppose the highest frequency component of a signal is 5 kHz.

Minimum theoretical sampling rate = 2 x 5 kHz
= 10 kHz

In practical systems, a sampling frequency above the Nyquist rate is selected, and an analog anti-aliasing low-pass filter is commonly used before the ADC input.

Sampling at or below the Nyquist limit can cause aliasing, where higher-frequency signal components appear as incorrect lower-frequency components in the sampled data.

4. Quantization

Quantization is the process of mapping each sampled analog amplitude to one of a finite number of discrete amplitude levels.

An analog voltage can have many possible values, but an ADC with a fixed resolution can represent only a limited number of digital codes.

5. Quantization Step Size

Quantization step size is the approximate voltage interval represented by one digital step.

For an ideal N-bit ADC with reference range from 0V to Vref, the code spacing is commonly expressed as:

Code Spacing = Vref / (2N - 1)

The quantization bin width is commonly approximated by:

Quantization Bin Width ≈ Vref / 2N
These expressions describe two closely related conventions. The first describes spacing between ideal output code levels when codes run from 0 to 2N-1. The second describes the approximate width of each quantization interval. Always use the ADC's specified transfer function when calculating exact voltage thresholds.

Example: 10-bit ADC

Assume:

  • Resolution = 10 bits
  • Reference voltage = 3.3V
Number of Codes = 210 = 1024
Code Spacing = 3.3 / 1023
≈ 3.2267 mV
Approximate Quantization Bin Width = 3.3 / 1024
≈ 3.2227 mV

6. Encoding

Encoding is the process of representing the quantized level as a digital binary code.

For example, a 3-bit ADC can represent eight levels using binary values from 000 to 111.

The microcontroller reads the resulting digital code from the ADC result register and uses it in its application.

7. Complete ADC Conversion Process

The complete conversion process can be summarized as follows:

  1. An analog voltage is applied to the ADC input.
  2. The ADC samples the input at a particular time.
  3. The sampled voltage is mapped to a discrete quantization level.
  4. The quantized level is represented by a binary code.
  5. The digital result becomes available to the microcontroller.

8. ADC Conversion Example

Consider an ideal 10-bit ADC with:

  • Reference voltage = 3.3V
  • Input voltage = 1.65V
  • Digital codes = 0 to 1023

Using the ideal endpoint-scaled conversion estimate:

Digital Code ≈ (Vin / Vref) x 1023
Digital Code ≈ (1.65 / 3.3) x 1023
≈ 511.5

The output is approximately 512, subject to the converter's quantization thresholds and transfer characteristics.

Converting Digital Code Back to Voltage

Vin ≈ (Digital Code / 1023) x Vref

For a result of 512:

Vin ≈ (512 / 1023) x 3.3
≈ 1.652V

9. ADC Conversion Time

ADC conversion time is the time required by the converter to complete a conversion and make the digital result available.

It depends on the ADC architecture, ADC clock frequency, conversion settings and the device specifications.

The sampling period and conversion time are not the same:

  • Sampling period: Time between successive samples.
  • Conversion time: Time needed to produce a digital result from a sample.
In a real application, the ADC must complete its conversion before software reads the result. The permitted ADC clock and conversion timing must follow the LPC2129 datasheet.

10. Factors Affecting ADC Accuracy

  • Resolution: Determines the number of available digital codes.
  • Reference voltage: Errors in the reference affect voltage measurements.
  • Noise: Electrical noise can cause fluctuating readings.
  • Input impedance: The signal source must drive the ADC input appropriately.
  • Sampling rate: Must be appropriate for the signal bandwidth.
  • Quantization error: Results from mapping continuous values to discrete levels.
  • ADC nonlinearity: Actual conversion may deviate from an ideal straight-line response.
  • Signal conditioning: Filtering and scaling may be necessary before conversion.

12. Interview Questions and Answers

Q1. What are the three basic ADC conversion stages?

Sampling, quantization and encoding.

Q2. What is sampling?

Sampling measures the amplitude of an analog signal at selected time instants.

Q3. What is quantization?

Quantization maps sampled amplitudes to a finite set of discrete levels.

Q4. What is encoding?

Encoding represents the selected quantization level as a digital binary code.

Q5. What is sampling frequency?

It is the number of samples taken per second, measured in Hertz.

Q6. State the Nyquist sampling theorem.

For ideal reconstruction of a band-limited signal, its sampling frequency must be greater than twice its highest frequency component.

Q7. What is aliasing?

Aliasing is distortion caused by insufficient sampling, in which frequency components appear at incorrect lower frequencies.

Q8. What is quantization error?

It is the difference between the actual sampled value and the value represented by the selected quantization level.

Q9. What is ADC conversion time?

It is the time required to complete a conversion and produce the digital result.

15. Lesson Summary

  • ADC converts analog input signals into digital data.
  • The three basic stages are sampling, quantization and encoding.
  • Sampling measures the input at selected time intervals.
  • Quantization maps sampled values to discrete amplitude levels.
  • Encoding represents quantized levels as binary codes.
  • Sampling frequency is measured in Hertz.
  • The Nyquist theorem relates sampling frequency to signal bandwidth.
  • Aliasing can occur when sampling is insufficient.
  • ADC resolution determines the number of available output codes.
