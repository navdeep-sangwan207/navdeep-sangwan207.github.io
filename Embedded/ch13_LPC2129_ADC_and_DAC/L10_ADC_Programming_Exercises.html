5. Exercise 3 – Read ADC Conversion Result

Objective: Start a conversion and extract the 10-bit result.

Program

#include <LPC21xx.h>

#define ADC_DONE (1U << 31)

volatile unsigned int adc_result;

int main(void)
{
    unsigned int adc_data;

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    ADCR = (1U << 0) |
           (3U << 8) |
           (1U << 21);

    while (1)
    {
        /* Start immediate conversion */

        ADCR &= ~(7U << 24);
        ADCR |=  (1U << 24);

        /* Wait for conversion completion */

        do
        {
            adc_data = ADDR;

        } while ((adc_data & ADC_DONE) == 0);

        /* Extract 10-bit result */

        adc_result =
            (adc_data >> 6) & 0x3FFU;
    }
}

Expected Result

The program repeatedly converts AIN0 and stores the 10-bit result in adc_result.

ADC Result Range = 0 to 1023

6. Exercise 4 – Convert ADC Result into Voltage

Objective: Calculate analog voltage from the ADC result.

Program

#include <LPC21xx.h>

#define ADC_DONE (1U << 31)

volatile unsigned int adc_result;
volatile float input_voltage;

int main(void)
{
    unsigned int adc_data;

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    ADCR = (1U << 0) |
           (3U << 8) |
           (1U << 21);

    while (1)
    {
        ADCR &= ~(7U << 24);
        ADCR |=  (1U << 24);

        do
        {
            adc_data = ADDR;

        } while ((adc_data & ADC_DONE) == 0);

        adc_result =
            (adc_data >> 6) & 0x3FFU;

        input_voltage =
            ((float)adc_result / 1023.0f) * 3.0f;
    }
}

Expected Result – Illustrative Example

Assume the ADC result is 512 and the reference is 3.0 V.

Vin = (512 / 1023) × 3.0
Vin ≈ 1.501 V

The calculated value is stored in input_voltage.

7. Exercise 5 – Read AIN1

Objective: Configure the second ADC channel.

Program

#include <LPC21xx.h>

int main(void)
{
    unsigned int adc_data;
    volatile unsigned int adc_result;

    /* Configure P0.28 as AIN1 */

    PINSEL1 &= ~(3U << 24);
    PINSEL1 |=  (1U << 24);

    /* Select AIN1 */

    ADCR = (1U << 1) |
           (3U << 8) |
           (1U << 21);

    while (1)
    {
        ADCR &= ~(7U << 24);
        ADCR |=  (1U << 24);

        do
        {
            adc_data = ADDR;

        } while ((adc_data & (1U << 31)) == 0);

        adc_result =
            (adc_data >> 6) & 0x3FFU;
    }
}

Expected Result

  • P0.28 is configured as AIN1.
  • ADC channel 1 is selected.
  • The conversion result is stored in adc_result.

9. Exercise 7 – Create a Reusable ADC Function

Objective: Develop a reusable function for reading any LPC2129 ADC channel.

Program

#include <LPC21xx.h>

#define ADC_DONE (1U << 31)

void ADC_Init(void)
{
    /* Configure AIN0 */

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    /* Power up ADC */

    ADCR = (1U << 0) |
           (3U << 8) |
           (1U << 21);
}

unsigned int ADC_Read(unsigned int channel)
{
    unsigned int adc_data;

    /* Select one channel */

    ADCR &= ~0xFFU;
    ADCR |= (1U << channel);

    /* Start conversion */

    ADCR &= ~(7U << 24);
    ADCR |=  (1U << 24);

    /* Wait for completion */

    do
    {
        adc_data = ADDR;

    } while ((adc_data & ADC_DONE) == 0);

    return (adc_data >> 6) & 0x3FFU;
}

int main(void)
{
    volatile unsigned int result;

    ADC_Init();

    while (1)
    {
        result = ADC_Read(0);
    }
}
This is a reusable software example for channel selection. Before using it for AIN1, AIN2 or AIN3, configure the corresponding pin's analog function. Do not switch channels while a conversion is active.

11. Exercise 9 – Detect an ADC Overrun

Objective: Understand the overrun status bit.

In the original LPC2129 ADDR register, bit 30 indicates an overrun condition.

Program Fragment

if (adc_data & (1U << 30))
{
    /* ADC overrun detected */
}
else
{
    /* No overrun indicated */
}

Expected Result

The program checks whether the overrun flag is set in the captured ADC data register value.

An overrun indicates that a previous conversion result was not read before a subsequent result replaced it. Its exact behavior depends on the ADC operating mode and device revision.

15. Interview Questions and Answers

Q1. What is the resolution of LPC2129 ADC?

10 bits.

Q2. How many ADC channels are available on LPC2129?

Four channels: AIN0, AIN1, AIN2 and AIN3.

Q3. Which register controls ADC conversion?

ADCR.

Q4. Which register contains the original ADC result?

ADDR.

Q5. What is the maximum ADC clock?

4.5 MHz.

Q6. What does the DONE flag indicate?

It indicates completion of the ADC conversion.

Q7. What is the purpose of the SEL field?

It selects the ADC input channel.

Q8. How is the 10-bit result extracted?

Using (ADDR >> 6) & 0x3FF.

Q9. Does LPC2129 contain an on-chip DAC?

No. An external DAC or filtered PWM output is needed.

Q10. What is burst mode?

It enables repeated ADC conversions without software starting each individual conversion.
