Lesson 03: ADC Resolution and Quantization

Chapter 13: LPC2129 ADC and DAC

Understand ADC resolution, digital output levels, LSB size, voltage resolution and quantization error.

1. Introduction

ADC resolution describes how many discrete digital values an Analog-to-Digital Converter can produce from its analog input range.

Resolution is normally expressed in bits. A higher-resolution ADC can represent smaller changes in input voltage, assuming the same reference voltage and an ideal converter.

The LPC2129 contains a 10-bit ADC. Therefore, its conversion result can represent 1024 possible digital codes.

Resolution determines the number of available digital codes. It does not, by itself, guarantee measurement accuracy.

2. What is ADC Resolution?

ADC resolution is the number of binary bits used to represent the converted analog input.

Each additional bit doubles the number of available digital output codes.

Number of Digital Codes = 2N

Where N is the ADC resolution in bits.

Examples of ADC Resolution

ADC Resolution Number of Codes Digital Code Range
8-bit 256 0 to 255
10-bit 1024 0 to 1023
12-bit 4096 0 to 4095
16-bit 65536 0 to 65535

3. Digital Output Levels

An ADC converts the input voltage into one of its available digital codes.

For an N-bit ADC, the digital output ranges from zero to one less than the total number of codes.

Maximum Digital Code = 2N - 1

Example: 3-bit ADC

A 3-bit ADC produces eight possible digital codes.

4. Voltage Resolution and LSB Size

Voltage resolution describes the approximate voltage represented by one least significant bit (LSB).

For an ideal N-bit ADC whose output codes span 0 through 2N-1, the spacing between adjacent ideal code levels is:

Code Spacing = Vref / (2N - 1)

The approximate quantization bin width is:

Quantization Bin Width ≈ Vref / 2N
These are related but different conventions. Code spacing describes the difference between adjacent ideal output levels. Quantization bin width describes the input interval assigned to a code in an ideal uniform quantizer. Use the device transfer characteristics for exact thresholds.

Example: 10-bit ADC with 3.3V Reference

Given:

  • Resolution = 10 bits
  • Reference voltage = 3.3V
  • Number of codes = 1024
  • Maximum code = 1023

Code spacing:

3.3 / 1023 = 0.0032267V
≈ 3.2267 mV

Approximate quantization bin width:

3.3 / 1024 = 0.0032227V
≈ 3.2227 mV

5. Least Significant Bit (LSB)

LSB stands for Least Significant Bit. It is the rightmost bit in a binary number and represents the smallest binary place value.

In ADC terminology, one LSB is also commonly used to describe one digital code step or its corresponding voltage increment.

Example

Binary Number: 101101

Bit positions:
5 4 3 2 1 0

LSB = rightmost bit = 1

For a 10-bit ADC with a 3.3V reference, one ideal code spacing is approximately 3.2267 mV.

A smaller LSB voltage means the converter can distinguish smaller input-voltage changes in its ideal transfer function.

6. Quantization

Quantization is the process of assigning a sampled analog voltage to one of a finite number of digital output levels.

Since the input voltage can vary continuously but the ADC output has a limited number of codes, the converted value is an approximation of the sampled input.

Example

Suppose the voltage corresponding to an input sample falls between two adjacent quantization levels. The ADC assigns it to one of the available codes according to its transfer characteristics and threshold boundaries.

7. Quantization Error

Quantization error is the difference between the actual sampled analog input and the voltage represented by the selected digital output code.

Quantization Error = Sampled Input - Reconstructed Value

For an ideal uniform quantizer with rounding to the nearest level, the quantization error is commonly bounded by:

-0.5 LSB ≤ Error ≤ +0.5 LSB

This ideal bound assumes that the converter uses the corresponding nearest-level quantization convention. Actual ADC errors may also include offset, gain, nonlinearity and noise.

Example

Assume:

  • One LSB = 3.2267 mV
  • Ideal rounding quantizer
Maximum Ideal Quantization Error
= 0.5 x 3.2267
≈ 1.6134 mV
Quantization error is inherent in finite-resolution conversion. It is not the same as electrical noise or total ADC measurement error.

8. Effect of Increasing ADC Resolution

Increasing ADC resolution increases the number of output codes and reduces the ideal voltage represented by each code for the same reference range.

Resolution Codes Approximate Bin Width at 3.3V
8-bit 256 12.89 mV
10-bit 1024 3.22 mV
12-bit 4096 0.806 mV
16-bit 65536 0.0504 mV
Higher resolution improves the potential granularity of measurement. It does not automatically provide higher absolute accuracy or more effective noise-free bits.

9. LPC2129 ADC Resolution

The LPC2129 contains a 10-bit ADC. Therefore, each conversion result represents one of 1024 possible digital codes.

Important Values

Parameter Value
ADC Resolution 10 bits
Number of Codes 1024
Minimum Code 0
Maximum Code 1023
Result Width 10 significant conversion bits within the result register

Voltage Calculation Example

Assume a 3.3V reference and an ADC result of 512. Using the ideal endpoint-scaled approximation:

Vin ≈ (ADC Result / 1023) x Vref
Vin ≈ (512 / 1023) x 3.3
Vin ≈ 1.652V

This is an approximate reconstructed voltage. The actual voltage threshold associated with a code depends on the ADC transfer function.

10. Embedded C: ADC Resolution Calculations

The following standalone C program demonstrates how to calculate the number of ADC codes, code spacing and an approximate input voltage. 

#include <stdio.h>

int main(void)
{
    unsigned int resolution = 10;
    unsigned int adc_result = 512;

    float reference_voltage = 3.3f;
    unsigned int number_of_codes;

    float code_spacing;
    float measured_voltage;

    number_of_codes = 1U << resolution;

    code_spacing = reference_voltage /
                   (number_of_codes - 1U);

    measured_voltage =
        ((float)adc_result / (number_of_codes - 1U))
        * reference_voltage;

    printf("ADC Resolution: %u bits\n", resolution);

    printf("Number of Codes: %u\n",
           number_of_codes);

    printf("Maximum Code: %u\n",
           number_of_codes - 1U);

    printf("Code Spacing: %.6f V\n",
           code_spacing);

    printf("Approximate Input Voltage: %.3f V\n",
           measured_voltage);

    return 0;
}

Expected Result

ADC Resolution: 10 bits
Number of Codes: 1024
Maximum Code: 1023
Code Spacing: 0.003226 V
Approximate Input Voltage: 1.652 V
This is a calculation demonstration using standard C. It does not access the LPC2129 ADC peripheral. Actual ADC register programming is covered in later lessons.

11. Factors Affecting Effective ADC Performance

  • Reference accuracy: Reference-voltage error directly affects voltage calculations.
  • Input noise: Noise may cause the ADC code to fluctuate.
  • Offset error: Shifts the conversion transfer characteristic.
  • Gain error: Changes the conversion scale.
  • INL: Integral nonlinearity measures deviation from an ideal transfer line.
  • DNL: Differential nonlinearity measures variation in adjacent code widths.
  • Source impedance: An unsuitable signal source may prevent accurate acquisition.
  • PCB layout: Poor grounding and noise coupling can degrade measurements.

12. Interview Questions and Answers

Q1. What is ADC resolution?

It is the number of bits used to represent the ADC's digital output.

Q2. How many codes are available in a 10-bit ADC?

1024 codes, from 0 to 1023.

Q3. What is LSB?

LSB is the least significant bit. In ADC applications, it also commonly refers to one digital code step.

Q4. What is voltage resolution?

It describes the approximate input-voltage change represented by one ADC code step.

Q5. What is quantization error?

It is the difference between the sampled input value and the value represented by the quantized output.

Q6. Does higher resolution guarantee higher accuracy?

No. Accuracy also depends on reference voltage, noise, offset, gain, linearity and other error sources.

Q7. What is the maximum digital code of a 10-bit ADC?

1023.

Q8. What is the ADC resolution of LPC2129?

10 bits.

Q9. What are INL and DNL?

INL measures deviation from an ideal transfer line. DNL measures the deviation of individual code widths from the ideal code width.
