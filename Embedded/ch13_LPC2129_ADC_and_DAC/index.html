Chapter 13: LPC2129 ADC and DAC

Learn analog-to-digital conversion, ADC architecture, control and result registers, channel configuration, Embedded C programming, and digital-to-analog conversion fundamentals.

Chapter Overview

Embedded systems often interact with analog signals from sensors, measurement circuits, and other electronic devices. Since a microcontroller processes digital data, analog signals must be converted into digital values before they can be processed by software.

This chapter explains the principles of Analog-to-Digital Conversion (ADC), its resolution, quantization, LPC2129 ADC architecture, control registers, channel selection, result registers, and ADC programming using Embedded C.

The chapter also introduces Digital-to-Analog Conversion (DAC), its operating principles, characteristics, and applications.

Hardware Note: The LPC2129 provides an on-chip ADC but does not contain an on-chip DAC. DAC concepts are covered for general understanding and for interfacing external DAC devices.

Learning Objectives

After completing this chapter, you will be able to:

  • Understand the purpose of ADC and DAC in embedded systems.
  • Explain the ADC conversion process and its operating principles.
  • Understand ADC resolution, quantization, and conversion error.
  • Describe the LPC2129 ADC architecture and its channels.
  • Configure the ADC using the control register.
  • Select ADC channels and configure the required pins.
  • Understand ADC status and conversion result registers.
  • Write Embedded C programs to perform ADC conversions.
  • Calculate digital output values from analog input voltages.
  • Understand DAC operation and external DAC applications.

Practical Learning Environment

Microcontroller: LPC2129 (ARM7TDMI-S)
Programming Language: Embedded C
IDE: Keil µVision
Simulation: Keil µVision Simulator
Project Peripheral Clock: 15 MHz
ADC Input Examples: ADC channel 0 and ADC channel 5

Practical exercises use register-level programming and ADC configuration. The project clock and ADC clock divider must be configured according to the LPC2129 datasheet requirements.

Simulator observations should be distinguished from measurements performed on a physical microcontroller and analog input circuit.
