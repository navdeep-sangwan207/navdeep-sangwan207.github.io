Lesson 08: ADC Programming Using Embedded C

Chapter 13: LPC2129 ADC and DAC

Learn how to initialize the ADC, configure its clock, start conversions, read digital results and calculate analog voltage using Embedded C.

1. Introduction

The Analog-to-Digital Converter (ADC) allows the LPC2129 microcontroller to measure analog voltage signals and convert them into digital values.

Embedded C is used to configure the ADC registers, select an analog input channel, start conversion and read the converted result.

Typical ADC programming tasks include:

  • Configuring the analog input pin.
  • Selecting an ADC channel.
  • Setting the ADC clock divider.
  • Powering up the ADC.
  • Starting an ADC conversion.
  • Checking conversion completion.
  • Extracting the 10-bit result.
  • Calculating the corresponding input voltage.
The examples in this lesson use the original LPC2129 register interface: ADCR and ADDR. The /01 device revision adds dedicated ADC result registers. Check the exact device revision and header file before using revision-specific register names.

3. ADC Registers Used in Programming

The original LPC2129 ADC programming interface uses two primary registers.

Register Address Purpose
ADCR 0xE0034000 Controls ADC channel selection, clock divider, power and conversion start.
ADDR 0xE0034004 Contains the ADC result and conversion status flags.

Important ADCR Fields

Bits Field Purpose
7:0 SEL Selects analog input channel.
15:8 CLKDIV Divides PCLK to generate ADC clock.
16 BURST Selects burst or software-controlled conversion.
19:17 CLKS Selects conversion clocks and resolution in burst mode.
21 PDN Enables ADC operation.
26:24 START Controls conversion start.
27 EDGE Selects edge for hardware-triggered conversion.

Important ADDR Fields

Bit Range Field Purpose
15:6 RESULT 10-bit ADC result.
26:24 CHN Channel identification.
30 OVRUN Overrun indication.
31 DONE Conversion completion flag.

4. ADC Clock Configuration

The ADC requires a suitable conversion clock. The ADC clock is derived from the peripheral clock using the CLKDIV field.

ADC Clock = PCLK / (CLKDIV + 1)

The ADC clock must not exceed 4.5 MHz. A fully accurate 10-bit conversion requires 11 ADC clock cycles.

Example Using the Project Clock

Given:

  • CCLK = 60 MHz
  • PCLK = 15 MHz
  • Maximum ADC clock = 4.5 MHz

Choose CLKDIV = 3.

ADC Clock = 15 MHz / (3 + 1)
ADC Clock = 3.75 MHz

This is below the maximum specified ADC clock.

Conversion Time

Conversion Time = 11 / ADC Clock
= 11 / 3.75 MHz
≈ 2.93 microseconds
The clock divider value is written into ADCR bits 15:8. For CLKDIV = 3, the field value is 0x03.

5. ADC Channel Selection

The LPC2129 provides four ADC input channels. The SEL field in ADCR selects the channel to be converted.

Channel Input Pin SEL Value
AIN0 P0.27 0x01
AIN1 P0.28 0x02
AIN2 P0.29 0x04
AIN3 P0.30 0x08

Select AIN0

ADCR = 0x01U;

Select AIN1

ADCR = 0x02U;

Select AIN2

ADCR = 0x04U;

Select AIN3

ADCR = 0x08U;
In software-controlled conversion mode, select exactly one channel at a time. Multiple channel selection is used for burst scanning.

6. ADC Pin Configuration

The analog input pins are connected to the ADC independently of their digital pin-function selection. However, selecting the AIN function disables the digital receiver and improves conversion accuracy.

The four ADC pins are P0.27, P0.28, P0.29 and P0.30. Their function fields are controlled by PINSEL1.

AIN0 – P0.27

PINSEL1 &= ~(3U << 22);
PINSEL1 |=  (1U << 22);

AIN1 – P0.28

PINSEL1 &= ~(3U << 24);
PINSEL1 |=  (1U << 24);

AIN2 – P0.29

PINSEL1 &= ~(3U << 26);
PINSEL1 |=  (1U << 26);

AIN3 – P0.30

PINSEL1 &= ~(3U << 28);
PINSEL1 |=  (1U << 28);
PINSEL1 configuration is recommended for accurate analog measurement because it disables the digital input receiver on the selected analog pin.

7. ADC Initialization

ADC initialization prepares the peripheral before a conversion is started.

The initialization includes:

  1. Configuring the analog input pin.
  2. Selecting the ADC channel.
  3. Configuring CLKDIV.
  4. Disabling burst mode for software-controlled conversion.
  5. Powering up the ADC.
  6. Leaving START at zero until a conversion is requested.

Initialization Function

#include <LPC21xx.h>

#define ADC_CHANNEL_0  (1U << 0)
#define ADC_CLKDIV     3U

void ADC_Init(void)
{
    /* Configure P0.27 as AIN0 */

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    /*
       Configure ADC:
       SEL    = AIN0
       CLKDIV = 3
       BURST  = 0
       PDN    = 1
       START  = 000
    */

    ADCR = ADC_CHANNEL_0 |
           (ADC_CLKDIV << 8) |
           (1U << 21);
}

After initialization, the ADC is powered up and configured for software-controlled conversion.

8. Starting ADC Conversion

The START field occupies ADCR bits 26:24. In software-controlled mode, the value 001 starts an immediate conversion.

START Value Function
000 No conversion start.
001 Start conversion immediately.
010–111 Hardware-triggered conversion selections.

Start AIN0 Conversion

ADCR &= ~(7U << 24);
ADCR |=  (1U << 24);

The first statement clears the START field. The second writes 001 to initiate conversion.

Writing ADCR while a conversion is in progress can affect the current conversion. In normal software-controlled operation, wait for completion before starting the next conversion.

9. Checking Conversion Completion

The DONE flag is bit 31 of ADDR. It becomes 1 when the ADC conversion is complete. 

while ((ADDR & (1U << 31)) == 0)
{
    /* Wait for ADC conversion */
}

This technique is called polling. The processor repeatedly checks the DONE flag until the ADC completes its conversion.

Reading ADDR clears DONE. Therefore, store the register value when reading it so that the conversion result is not lost.

10. Reading the ADC Result

The 10-bit conversion result occupies bits 15:6 of ADDR.

Result Extraction

unsigned int adc_data;
unsigned int adc_result;

adc_data = ADDR;

adc_result = (adc_data >> 6) & 0x3FFU;

Explanation:

  • Read the complete ADC data register.
  • Shift the result field right by six positions.
  • Mask the value with 0x3FF to retain ten bits.
ADC Result = (ADDR >> 6) & 0x3FF

11. Converting ADC Result into Voltage

The ADC result represents the analog input voltage relative to the ADC reference voltage.

Vin ≈ (ADC Result / 1023) × VREF

Example

Assume:

  • ADC result = 512
  • Reference voltage = 3.0 V
Vin = (512 / 1023) × 3.0
Vin ≈ 1.501 V

Embedded C Code

float ADC_To_Voltage(unsigned int result)
{
    return ((float)result / 1023.0f) * 3.0f;
}
The reference voltage in the program must match the actual analog reference used by the circuit. The LPC2129 ADC measurement range is 0 V to 3 V.

12. Complete ADC Program – Read AIN0

This program initializes the LPC2129 ADC, starts a conversion on AIN0, waits for completion and stores the digital result and calculated voltage. 

#include <LPC21xx.h>

#define ADC_CHANNEL_0  (1U << 0)
#define ADC_CLKDIV     3U
#define ADC_DONE       (1U << 31)

volatile unsigned int adc_result = 0;
volatile float input_voltage = 0.0f;

void ADC_Init(void)
{
    /* Configure P0.27 as AIN0 */

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    /* Configure ADC */

    ADCR = ADC_CHANNEL_0 |
           (ADC_CLKDIV << 8) |
           (1U << 21);
}

unsigned int ADC_Read(void)
{
    unsigned int adc_data;

    /* Start immediate conversion */

    ADCR &= ~(7U << 24);
    ADCR |=  (1U << 24);

    /* Wait for conversion completion */

    do
    {
        adc_data = ADDR;

    } while ((adc_data & ADC_DONE) == 0);

    /* Extract 10-bit result */

    return (adc_data >> 6) & 0x3FFU;
}

float ADC_To_Voltage(unsigned int result)
{
    return ((float)result / 1023.0f) * 3.0f;
}

int main(void)
{
    ADC_Init();

    while (1)
    {
        adc_result = ADC_Read();

        input_voltage =
            ADC_To_Voltage(adc_result);
    }
}

Program Explanation

  1. ADC_Init() configures the AIN0 pin and ADC.
  2. ADC_Read() starts a conversion.
  3. The program polls ADDR until DONE becomes 1.
  4. The result is extracted from bits 15:6.
  5. ADC_To_Voltage() calculates the approximate input voltage.
  6. The main loop repeatedly measures the analog input.

13. Reading Different ADC Channels

The same conversion function can be used for AIN1, AIN2 and AIN3 by changing the SEL field.

Generic ADC Channel Selection

void ADC_Select_Channel(unsigned int channel)
{
    /* Select one of four available channels */

    ADCR &= ~0xFFU;

    ADCR |= (1U << channel);
}

The function expects a channel number from 0 to 3. It updates the SEL field while preserving the other ADC configuration fields.

Example Usage

ADC_Select_Channel(0);  /* AIN0 */
ADC_Select_Channel(1);  /* AIN1 */
ADC_Select_Channel(2);  /* AIN2 */
ADC_Select_Channel(3);  /* AIN3 */
Configure the corresponding physical pin's analog function for accurate measurements. Do not change the channel while a conversion is in progress.

14. ADC Programming Using Burst Mode

Burst mode allows the ADC to perform repeated conversions automatically.

It can scan one or multiple selected channels without requiring software to start each conversion.

Important Burst Mode Fields

Field Function
SEL Selects the input channels to scan.
BURST Enables repeated conversions.
CLKS Selects conversion clocks and result accuracy.
PDN Enables ADC operation.

Example: Burst Conversion on AIN0

ADCR = (1U << 0)  |   /* Select AIN0 */
       (3U << 8)  |   /* CLKDIV = 3 */
       (1U << 16) |   /* Burst mode */
       (1U << 21);    /* ADC powered up */

With BURST enabled, the ADC repeatedly converts the selected input.

In burst mode, the CLKS field controls the number of conversion clocks and the effective resolution. Do not assume that every burst configuration automatically provides a full 10-bit result. Software must also monitor result updates and overrun conditions.

15. ADC Applications

1. Potentiometer Measurement

A potentiometer provides an adjustable analog voltage that can be read through an ADC channel.

2. Temperature Measurement

An analog temperature sensor can provide a voltage proportional to temperature. The ADC converts this voltage into a digital value.

3. Battery Voltage Monitoring

A resistor divider scales the battery voltage into the permitted ADC input range.

4. Light Intensity Measurement

A light-dependent resistor circuit can generate a varying analog voltage for ADC measurement.

5. Industrial Sensor Monitoring

Analog pressure, temperature and position sensors can be connected through suitable signal-conditioning circuits.

16. Common Programming Mistakes

  • Using an incorrect ADC channel selection value.
  • Forgetting to power up the ADC using PDN.
  • Configuring an ADC clock above 4.5 MHz.
  • Starting a new conversion before the previous one completes.
  • Reading ADDR without checking the DONE flag.
  • Extracting the result without shifting right by six bits.
  • Using an incorrect result mask.
  • Using a reference voltage that does not match the circuit.
  • Applying an input voltage above the specified ADC range.
  • Ignoring the effect of a digital input receiver on conversion accuracy.
  • Using revision-specific ADC registers with an incompatible device header.

18. Interview Questions and Answers

Q1. Which register controls the LPC2129 ADC?

ADCR.

Q2. Which register contains the ADC result in the original LPC2129?

ADDR.

Q3. What is the resolution of the LPC2129 ADC?

10 bits.

Q4. What is the maximum ADC clock frequency?

4.5 MHz.

Q5. What does the PDN bit do?

It powers up the ADC when set to 1.

Q6. What does the START field do?

It controls when an ADC conversion begins.

Q7. What is the purpose of the DONE flag?

It indicates that an ADC conversion has completed.

Q8. How do you extract the ADC result?

Shift ADDR right by six bits and mask with 0x3FF.

Q9. What is burst mode?

It is an operating mode in which the ADC repeatedly converts selected input channels.

Q10. Why is polling used in ADC programming?

Polling allows software to wait until the DONE flag indicates conversion completion.
