Lesson 04: LPC2129 ADC Architecture

Chapter 13: LPC2129 ADC and DAC

Study ADC hardware organization, analog input channels, clock configuration, conversion control and result storage.

1. Introduction

The LPC2129 is an ARM7TDMI-S based microcontroller that includes an integrated Analog-to-Digital Converter (ADC). The ADC allows the microcontroller to measure external analog voltage signals.

These signals may come from sensors, potentiometers, voltage-monitoring circuits and other analog sources.

The ADC converts the selected analog input into a 10-bit digital result that can be read by the embedded application.

The LPC2129 has a 10-bit ADC with two ADC peripherals, commonly designated ADC0 and ADC1, each providing multiple analog input channels. Consult the device pin table when selecting a physical input pin.

2. LPC2129 ADC Features

Feature Description
ADC Resolution 10-bit
ADC Peripherals ADC0 and ADC1
Channels Multiple analog input channels per ADC peripheral
Conversion Control Software-controlled and supported hardware trigger options
Result Storage Dedicated channel result registers
Clock Configuration ADC clock divider configuration
Programming Interface Memory-mapped peripheral registers
ADC clock configuration must satisfy the maximum ADC clock specification in the LPC2129 datasheet. The peripheral clock must not automatically be assumed to be a valid ADC clock.

4. ADC0 and ADC1 Peripherals

The LPC2129 provides two ADC peripheral blocks. They are identified as ADC0 and ADC1.

Each ADC peripheral has its own control and result registers. Software selects the required channel and starts the conversion using the appropriate control register.

Peripheral Control Register Global Data Register
ADC0 AD0CR AD0GDR
ADC1 AD1CR AD1GDR

Each channel also has a corresponding data register. These registers are used to obtain the conversion result and status information for individual channels.

ADC0 and ADC1 are separate peripheral instances. Do not confuse an ADC channel number with the ADC peripheral number. For example, AD0.5 means channel 5 of ADC0.

5. Analog Input Channels

An ADC channel is an individual analog input path through which a voltage signal is measured.

The LPC2129 supports multiple ADC input channels across ADC0 and ADC1. Each channel is associated with a physical microcontroller pin.

Channel Selection

Software selects the required ADC channel through the channel-selection bits of the corresponding ADC control register.

Examples of channel naming:

  • AD0.0 - ADC0 channel 0.
  • AD0.1 - ADC0 channel 1.
  • AD0.2 - ADC0 channel 2.
  • AD1.0 - ADC1 channel 0.
  • AD1.1 - ADC1 channel 1.
The exact channel-to-pin mapping must be checked in the LPC2129 pin-connectivity table. A pin may also have alternative digital or peripheral functions.

6. ADC Input Signal Requirements

The analog voltage applied to an ADC input must remain within the permitted input range specified by the device.

The ADC input should not be driven beyond the absolute maximum ratings or normal operating limits.

Input Considerations

  • Use an appropriate analog input pin.
  • Configure the pin for its ADC function.
  • Ensure that the input voltage is within the permitted range.
  • Provide a suitable analog ground reference.
  • Consider input source impedance.
  • Use filtering or signal conditioning where required.
  • Avoid applying negative or excessive input voltages.
Do not assume that every LPC2129 GPIO pin accepts an analog input. Only pins with the documented ADC function can be used for ADC conversion.

The ADC clock divider must then be configured so that the ADC clock remains within the device's specified limit.

The ADC clock divider is configured separately from VPBDIV. VPBDIV controls the peripheral clock, not the ADC conversion clock directly.

8. ADC Control and Result Registers

ADC operation is controlled through memory-mapped registers. The important registers include:

Register Purpose
AD0CR ADC0 control register.
AD1CR ADC1 control register.
AD0GDR ADC0 global data register.
AD1GDR ADC1 global data register.
AD0DR0 - AD0DR7 ADC0 channel data registers.
AD1DR0 - AD1DR7 ADC1 channel data registers.
AD0INTEN ADC0 interrupt enable register.
AD1INTEN ADC1 interrupt enable register.

The detailed bit-level operation of these registers is covered in the following lessons.

9. ADC Conversion Sequence

A typical software-controlled ADC conversion follows these steps:

  1. Select the required ADC input pin.
  2. Configure the pin's function through the pin-selection register.
  3. Configure the ADC peripheral clock divider.
  4. Select the desired ADC channel.
  5. Configure the ADC control register.
  6. Start a conversion.
  7. Wait for conversion completion or handle its interrupt.
  8. Read the digital result from the result register.

13. Interview Questions and Answers

Q1. What is the ADC resolution of LPC2129?

The LPC2129 ADC has 10-bit resolution.

Q2. What are ADC0 and ADC1?

They are the two ADC peripheral instances provided by the LPC2129.

Q3. What is the function of AD0CR?

It configures and controls ADC0 operation.

Q4. What is the function of AD0GDR?

It provides global ADC0 conversion result and status information.

Q5. Why is ADC clock configuration necessary?

The ADC requires a clock within its specified operating range to perform conversions correctly.

Q6. What is the difference between PCLK and ADC clock?

PCLK is the peripheral bus clock. The ADC clock is derived from the peripheral clock using ADC-specific divider configuration.

Q7. Why is pin configuration necessary?

The selected physical pin must be configured for its analog ADC function before it can be used for conversion.

Q8. Does LPC2129 have an internal DAC?

No. It provides ADC functionality but no on-chip DAC.

16. Lesson Summary

  • LPC2129 provides ADC0 and ADC1 peripheral instances.
  • The ADC provides 10-bit conversion results.
  • Analog input channels are associated with specific physical pins.
  • AD0CR and AD1CR control their respective ADC peripherals.
  • AD0GDR and AD1GDR provide global conversion information.
  • ADC clock configuration is derived from PCLK.
  • Pin configuration is required before using an analog input.
  • ADC results are read by the ARM7 processor.
  • LPC2129 does not contain an on-chip DAC.
