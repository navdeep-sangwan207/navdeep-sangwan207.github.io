Lesson 01: Introduction to ADC and DAC

Chapter 13: LPC2129 ADC and DAC

Understand analog signals, digital signals, Analog-to-Digital Conversion and Digital-to-Analog Conversion.

1. Introduction

Embedded systems interact with the physical world through sensors, switches, motors, displays and other electronic devices. Many physical quantities, such as temperature, pressure, light intensity and sound, are represented by analog electrical signals.

However, microcontrollers process information internally in digital form. Therefore, conversion between analog and digital signals is important in embedded system design.

Two important conversion techniques are:

  • ADC: Analog-to-Digital Converter.
  • DAC: Digital-to-Analog Converter.
ADC converts an analog input into a digital value that a microcontroller can process. DAC converts digital data into an analog output signal.

2. Analog Signals

An analog signal is a continuous signal that can have a range of values over time. It represents physical quantities through continuously varying voltage or current.

Examples of Analog Signals

  • Temperature sensor output voltage.
  • Light sensor output.
  • Microphone audio signal.
  • Pressure sensor output.
  • Potentiometer voltage.
  • Battery voltage measurement.

Example

Suppose a sensor produces an output voltage between 0V and 3.3V. As the measured physical quantity changes, its output voltage also changes continuously within its operating range.

Analog Signal Representation

Continuous variation of voltage with time

Characteristics of Analog Signals

  • Continuous in amplitude.
  • Can represent a wide range of physical quantities.
  • May be affected by electrical noise.
  • Often require signal conditioning before conversion.

3. Digital Signals

A digital signal represents information using discrete values. In a binary digital system, information is represented using two logic states:

  • Logic 0: LOW state.
  • Logic 1: HIGH state.

Digital systems use binary digits (bits) to represent numbers, instructions and measured information.

Digital Signal Representation

Discrete HIGH and LOW logic levels

Characteristics of Digital Signals

  • Represent information using discrete values.
  • Easy for microcontrollers to process and store.
  • Can be processed using digital logic circuits.
  • Digital data can be transmitted and reproduced reliably.

4. What is ADC?

ADC stands for Analog-to-Digital Converter. It is an electronic circuit that converts an analog input voltage into a corresponding digital number.

A microcontroller cannot directly perform ordinary digital calculations on a continuously varying analog voltage. An ADC provides a digital representation of that voltage.

Example of ADC Conversion

Consider an ideal 10-bit ADC with a reference voltage of 3.3V. Its digital output has 1024 possible codes, ranging from 0 to 1023.

For an input voltage of approximately 1.65V:

Digital Code = (Vin / Vref) x 1023
Digital Code = (1.65 / 3.3) x 1023
Digital Code = 511.5

The actual ADC result will be an integer near 511 or 512, depending on the converter's transfer characteristics and quantization behavior.

The ADC output is a digital representation of the input voltage, not the voltage itself. The software can calculate an approximate voltage from the conversion result.

5. What is DAC?

DAC stands for Digital-to-Analog Converter. It converts a digital input value into a corresponding analog voltage or current.

DACs are used when a digital system needs to generate an analog signal for an external circuit or device.

Digital Input
→
DAC
→

Example of DAC Conversion

Consider an ideal 10-bit DAC with a 3.3V reference. A digital input code controls the generated analog output.

Ideal DAC Output = (Digital Code / 1023) x Vref

For a digital input code of 512:

Vout = (512 / 1023) x 3.3
Vout ≈ 1.652V

The actual output depends on the DAC architecture, reference voltage, output circuitry and electrical loading.

6. Difference Between ADC and DAC

Parameter ADC DAC
Full Form Analog-to-Digital Converter Digital-to-Analog Converter
Conversion Analog to digital Digital to analog
Input Analog voltage or current Digital data
Output Digital number Analog voltage or current
Purpose Measure real-world signals Generate analog signals
Applications Sensor measurement Audio and analog control

7. ADC and DAC in LPC2129

The LPC2129 is an ARM7TDMI-S based microcontroller from NXP. It provides an integrated ADC peripheral for converting external analog input signals into digital values.

LPC2129 ADC Features

  • 10-bit ADC resolution.
  • Multiple analog input channels.
  • ADC conversion controlled through peripheral registers.
  • Conversion results stored in ADC result registers.
  • Supports software-controlled conversion.
  • ADC clock must be configured within the device limits.
Hardware distinction: LPC2129 provides an on-chip ADC but does not provide an on-chip DAC. Do not confuse ADC input channels with DAC output channels.

8. Applications of ADC and DAC

ADC Applications

  • Temperature measurement systems.
  • Battery voltage monitoring.
  • Light intensity measurement.
  • Industrial sensor monitoring.
  • Pressure and humidity measurement.
  • Data acquisition systems.
  • Analog feedback in control systems.

DAC Applications

  • Audio signal generation.
  • Waveform generation.
  • Analog reference voltage generation.
  • Programmable voltage sources.
  • Analog control systems.
  • Signal generation equipment.

10. Interview Questions and Answers

Q1. What is ADC?

ADC is an electronic converter that changes an analog input signal into a digital representation.

Q2. What is DAC?

DAC converts digital data into a corresponding analog voltage or current.

Q3. Why is ADC required in a microcontroller?

It allows the microcontroller to process analog signals from sensors and other external sources.

Q4. What is the resolution of the LPC2129 ADC?

The LPC2129 ADC has a resolution of 10 bits.

Q5. How many output codes are possible with a 10-bit ADC?

There are 210 = 1024 possible codes, ranging from 0 to 1023.

Q6. Does LPC2129 have an internal DAC?

No. It has an on-chip ADC but no on-chip DAC. An external DAC is required for analog output generation.

Q7. What is a reference voltage?

It is the voltage reference used to determine the conversion range and scaling of an ADC or DAC.

Q8. What is the difference between analog and digital signals?

Analog signals vary continuously, whereas digital signals represent information using discrete values.

13. Lesson Summary

  • Analog signals represent continuously varying physical quantities.
  • Digital signals represent information using discrete values.
  • ADC converts analog signals into digital data.
  • DAC converts digital data into analog signals.
