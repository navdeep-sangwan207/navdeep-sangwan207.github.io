Lesson 07: ADC Conversion and Result Registers

Chapter 13: LPC2129 ADC and DAC

Understand ADC conversion completion, data registers, DONE flags, overrun detection and digital result extraction.

1. Introduction

After an analog voltage is converted into a digital value, the ADC stores the result in its data register.

The ARM7 processor reads this register to obtain the measured digital value.

The LPC2129 ADC provides a 10-bit conversion result. The result is stored in a specific field of the ADC data register.

The ADC result is not stored as a simple 10-bit value starting at bit 0. It occupies bits 15:6 of the ADC data register. Software must shift and mask the register value to extract it.

2. ADC Register Architecture

The ADC register implementation depends on the LPC2129 device revision.

Legacy LPC2129 and LPC2129/00

The original and /00 versions use a shared ADC data register named ADDR.

Register Address Purpose
ADCR 0xE0034000 ADC control register.
ADDR 0xE0034004 ADC conversion result and status.

Enhanced LPC2129/01

The enhanced /01 version provides additional ADC result and status registers.

Register Address Purpose
ADCR 0xE0034000 ADC control register.
ADGDR 0xE0034004 Global ADC result register.
ADINTEN 0xE003400C ADC interrupt enable register.
ADDR0 0xE0034010 Channel 0 result.
ADDR1 0xE0034014 Channel 1 result.
ADDR2 0xE0034018 Channel 2 result.
ADDR3 0xE003401C Channel 3 result.
ADSTAT 0xE0034030 ADC status register.
Do not assume that every LPC2129 has ADDR0–ADDR3, ADGDR, ADSTAT and ADINTEN. These additional registers belong to the enhanced /01 version. Check the exact device marking and applicable datasheet.

3. ADC Data Register Format

The legacy ADDR register and the enhanced result registers use the same general result and status bit arrangement.

4. RESULT Field

The RESULT field occupies bits 15:6 of the ADC data register. It contains the digital value produced by the ADC.

Since the LPC2129 ADC has 10-bit resolution, the result ranges from 0 to 1023.

Input Condition Approximate Result
Near 0 V 0
Near one-quarter of reference 256
Near half of reference 512
Near three-quarters of reference 767
Near full reference 1023

Extracting the RESULT Field

adc_result = (adc_data >> 6) & 0x3FF;

Explanation:

  • adc_data >> 6 moves bits 15:6 into positions 9:0.
  • & 0x3FF keeps only the lower 10 bits.
  • The resulting value is the ADC conversion result.
ADC Result = (ADC Data Register >> 6) & 0x3FF

5. DONE Flag

DONE is bit 31 of the ADC data register. It indicates whether a conversion has completed.

DONE Bit Meaning
0 Conversion has not completed.
1 Conversion has completed.

Checking DONE

if (adc_data & (1U << 31))
{
    /* Conversion completed */
}

In software-controlled conversion mode, the processor can poll the DONE flag until it becomes 1.

Reading the data register clears its DONE flag. Writing ADCR also clears the DONE flag and initiates the new conversion if the START field requests it.

6. OVERRUN Flag

OVERRUN is bit 30 of the ADC data register. It is relevant when burst conversion is used.

In burst mode, the ADC can produce new results while software is still processing earlier results. If an earlier result is overwritten before software reads it, the OVERRUN flag indicates that data was lost.

OVERRUN Bit Meaning
0 No reported result overrun.
1 One or more conversion results were overwritten.

Checking OVERRUN

if (adc_data & (1U << 30))
{
    /* ADC result overrun detected */
}
Reading the applicable ADC data register clears its overrun indication. Software should read results at a rate appropriate for the conversion rate.

7. CHN – Channel Identification

The CHN field occupies bits 26:24 in the global data register format.

It identifies the channel associated with the most recent conversion result.

CHN Value Channel
000 AIN0
001 AIN1
010 AIN2
011 AIN3

Extracting Channel Number

channel = (adc_data >> 24) & 0x07;

This is particularly useful when multiple channels are selected in burst mode.

8. Legacy ADDR Register

In the original LPC2129 and LPC2129/00, the ADC data register is named ADDR.

It contains the result, DONE flag, OVERRUN flag and channel identification for the most recent conversion.

Register Address
ADDR 0xE0034004

Reading ADDR

unsigned int adc_data;
unsigned int adc_result;

adc_data = ADDR;

if (adc_data & (1U << 31))
{
    adc_result = (adc_data >> 6) & 0x3FF;
}
In the legacy version, ADDR is shared by the selected ADC conversion. Reading it clears the DONE flag. The result is not stored in separate ADDR0–ADDR3 registers.

9. Enhanced ADDR0–ADDR3 Registers

The enhanced LPC2129/01 provides dedicated data registers for its four ADC channels.

Register Channel Address
ADDR0 AIN0 0xE0034010
ADDR1 AIN1 0xE0034014
ADDR2 AIN2 0xE0034018
ADDR3 AIN3 0xE003401C

Reading Channel 0

unsigned int adc_data;
unsigned int adc_result;

adc_data = ADDR0;

if (adc_data & (1U << 31))
{
    adc_result = (adc_data >> 6) & 0x3FF;
}

Reading Channel 1

adc_data = ADDR1;

if (adc_data & (1U << 31))
{
    adc_result = (adc_data >> 6) & 0x3FF;
}
Dedicated result registers reduce the need for software to identify which channel produced the latest result. Each channel has its own result and status fields.

10. ADGDR – ADC Global Data Register

ADGDR is available on the enhanced LPC2129/01. It contains information about the most recent ADC conversion.

Bits Field Function
15:6 RESULT Most recent ADC result.
26:24 CHN Channel that produced the result.
30 OVERRUN Result overwrite indication.
31 DONE Conversion completion flag.

Reading ADGDR

unsigned int adc_data;
unsigned int adc_result;
unsigned int channel;

adc_data = ADGDR;

if (adc_data & (1U << 31))
{
    adc_result = (adc_data >> 6) & 0x3FF;
    channel = (adc_data >> 24) & 0x07;
}

The global register provides the latest conversion result, while the channel field identifies the corresponding input.

11. ADSTAT – ADC Status Register

ADSTAT is available on the enhanced /01 version. It provides status information for all ADC channels.

Bits Field Meaning
3:0 DONE0–DONE3 Completion flags for AIN0–AIN3.
11:8 OVERRUN0–OVERRUN3 Overrun flags for AIN0–AIN3.
16 ADINT ADC interrupt status.

Checking Channel 0 Completion

if (ADSTAT & (1U << 0))
{
    /* Channel 0 conversion completed */
}

Checking Channel 1 Completion

if (ADSTAT & (1U << 1))
{
    /* Channel 1 conversion completed */
}
ADSTAT is read-only. The individual DONE and OVERRUN indications are mirrored from the channel result registers. Reading the associated data register clears its flags.

12. ADC Conversion Completion Sequence

In software-controlled conversion mode, the basic conversion sequence is:

Configure ADCR

↓
Start Conversion

↓
ADC Performs Conversion

↓
DONE = 1

↓
Read ADC Data Register

↓
Extract 10-bit Result

The processor can use polling to wait for DONE or, on the enhanced version, use the supported ADC interrupt mechanism.

13. Calculating Analog Voltage from ADC Result

The ADC result represents the input voltage as a fraction of the analog reference voltage.

Vin ≈ (ADC Result / 1023) × VREF

Example

Given:

  • ADC result = 512
  • VREF = 3.0 V
  • Resolution = 10 bits
Vin ≈ (512 / 1023) × 3.0
Vin ≈ 1.501 V

Embedded C Calculation

unsigned int adc_result = 512;
float reference_voltage = 3.0f;
float input_voltage;

input_voltage =
    ((float)adc_result / 1023.0f)
    * reference_voltage;

The calculated value is an approximation. Actual measurement accuracy depends on the analog reference, input circuitry and ADC performance.

14. Complete Software-Controlled Conversion Example

The following example demonstrates the general programming sequence for the legacy LPC2129 register set. 

#include <LPC21xx.h>

#define ADC_CHANNEL_0  (1U << 0)
#define ADC_CLKDIV     3U

volatile unsigned int adc_result = 0;
volatile float input_voltage = 0.0f;

int main(void)
{
    unsigned int adc_data;

    /*
       Configure AIN0 pin function.
       P0.27 uses PINSEL1 bits 23:22.
    */

    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    /*
       Configure ADC:
       Channel 0
       CLKDIV = 3
       BURST = 0
       CLKS = 000
       PDN = 1
       START = 000 initially
    */

    ADCR = ADC_CHANNEL_0 |
           (ADC_CLKDIV << 8) |
           (1U << 21);

    while (1)
    {
        /*
           Start immediate conversion.
        */

        ADCR &= ~(7U << 24);
        ADCR |=  (1U << 24);

        /*
           Wait for conversion completion.
           Reading ADDR clears DONE.
        */

        do
        {
            adc_data = ADDR;

        } while ((adc_data & (1U << 31)) == 0);

        /*
           Extract 10-bit result.
        */

        adc_result =
            (adc_data >> 6) & 0x3FFU;

        /*
           Convert digital result into voltage.
        */

        input_voltage =
            ((float)adc_result / 1023.0f)
            * 3.0f;
    }
}
This example uses the legacy ADDR register. It is not intended to be compiled unchanged for every LPC2129/01 device header. For the enhanced version, use the appropriate ADGDR or ADDRn register and the corresponding status handling.

15. Common Programming Mistakes

  • Reading the result before conversion completion.
  • Extracting the result without shifting right by 6.
  • Using an incorrect result mask instead of 0x3FF.
  • Forgetting that DONE is bit 31.
  • Ignoring OVERRUN during burst conversion.
  • Confusing the global data register with dedicated channel registers.
  • Using enhanced ADC registers on a legacy device.
  • Assuming ADSTAT exists on every LPC2129 revision.
  • Reading the data register and then expecting DONE to remain set.
  • Using the wrong reference voltage in voltage calculations.

17. Interview Questions and Answers

Q1. Which register contains the ADC result in the legacy LPC2129?

ADDR.

Q2. What is the address of ADDR?

0xE0034004.

Q3. Which bits contain the 10-bit ADC result?

Bits 15:6.

Q4. What is the DONE flag?

Bit 31, indicating conversion completion.

Q5. What is the OVERRUN flag?

Bit 30, indicating overwritten conversion data in burst mode.

Q6. How do you extract the ADC result?

Shift the data register right by 6 and mask it with 0x3FF.

Q7. What is the purpose of ADGDR?

It provides the most recent ADC result and associated status information on the enhanced version.

Q8. What is the purpose of ADDR0?

It stores the latest completed conversion result for channel 0 on the enhanced version.

Q9. What is ADSTAT?

It provides the DONE and OVERRUN status flags for individual ADC channels on the enhanced version.

20. Lesson Summary

  • ADC data registers store the converted digital result.
  • The 10-bit RESULT field occupies bits 15:6.
  • DONE is bit 31.
  • OVERRUN is bit 30.
  • CHN occupies bits 26:24 in the global data format.
  • The result is extracted using a right shift of 6 and mask 0x3FF.
  • Legacy LPC2129 uses the shared ADDR register.
  • Enhanced LPC2129/01 provides ADGDR, ADSTAT and ADDR0–ADDR3.
  • Reading the applicable result register clears its DONE indication.
  • The extracted ADC result can be converted into an approximate voltage.
