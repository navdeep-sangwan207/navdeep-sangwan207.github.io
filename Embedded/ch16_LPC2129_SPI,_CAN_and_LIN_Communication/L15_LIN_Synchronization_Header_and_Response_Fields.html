After completing this lesson, you will be able to:

2. Why Synchronization Is Required

LIN communication uses asynchronous serial transmission. The master and slave nodes have their own clock sources, and their clock frequencies may differ slightly.

Synchronization helps slave nodes determine the timing of the incoming communication so that they can correctly receive the transmitted bits.

Reasons for Synchronization

  • Microcontrollers may use different clock sources.
  • Oscillator frequencies have tolerances.
  • Clock drift can affect serial data reception.
  • Correct bit timing is required to identify data bits accurately.
Key concept: The LIN sync field allows a slave node to estimate the bit time from the master transmission.

3. LIN Bit Time and Baud Rate

Bit time is the time required to transmit one bit on the LIN bus.

The relationship between baud rate and bit time is:

Bit Time = 1 / Baud Rate

Example

Assume a LIN communication speed of 19,200 bits per second.

Baud Rate = 19,200 bits/second

Bit Time = 1 / 19,200

         = 0.00005208 seconds

         = 52.08 microseconds (approximately)
Baud RateApproximate Bit Time
9,600 bps104.17 µs
19,200 bps52.08 µs
20,000 bps50 µs

LIN supports communication rates up to 20 kbit/s.

4. LIN Header Overview

The header is transmitted by the master task at the beginning of every scheduled frame.

It contains three fields:

+-------------+-------------+------------------+
| Break Field | Sync Field  | Protected ID     |
+-------------+-------------+------------------+
                    HEADER
FieldFunction
BreakIndicates the beginning of a frame.
SyncProvides timing information for synchronization.
Protected IDIdentifies the frame and includes parity protection.

5. Break Field and Break Delimiter

The break field is a special dominant-level signal transmitted by the master before the sync field.

Functions

  • Indicates the beginning of a LIN frame.
  • Allows slave nodes to detect a new frame.
  • Separates frame-level communication from normal UART character reception.

Break Delimiter

The break delimiter is the recessive-level interval that follows the dominant break field. It separates the break from the sync byte.

LIN BUS SIGNAL (CONCEPTUAL)

Dominant level
     |
     |<------ BREAK ------>|
     ______________________
                           |
                           |  Delimiter
                           |___________
                                       |
                                       | Sync field
In LIN, the break field is longer than a normal UART character. Its minimum length and delimiter timing are specified by the LIN protocol.

6. Sync Field and Baud-Rate Synchronization

The sync field is an 8-bit byte with a fixed value of 0x55.

Hexadecimal: 0x55

Binary:      01010101

Why Is 0x55 Used?

The alternating pattern creates regular transitions on the bus. Slave nodes can measure the timing between transitions to estimate the master bit time.

Synchronization Process

  1. The master transmits the break field.
  2. The master transmits the sync byte 0x55.
  3. The slave detects the transitions in the sync pattern.
  4. The slave measures the timing of the received signal.
  5. The slave adjusts its receive timing as supported by its LIN implementation.
Sync Byte: 0 1 0 1 0 1 0 1
           | | | | | | | |
           Transitions provide timing information

7. Protected Identifier Field

The protected identifier follows the sync field. It tells the nodes which frame is being transmitted.

+--------------------------------+
| ID5 ID4 ID3 ID2 ID1 ID0 | P1 P0 |
+--------------------------------+
          6-bit ID          2 parity bits

Identifier Information

  • The frame identifier contains six bits.
  • Two parity bits protect the identifier.
  • The complete protected identifier is eight bits.
  • Nodes use the identifier to determine the meaning and handling of the frame.

Parity Equations

P0 = ID0 XOR ID1 XOR ID2 XOR ID4

P1 = NOT (ID1 XOR ID3 XOR ID4 XOR ID5)

The protected identifier is transmitted as part of the master header.

The protected identifier is not the same as a CAN identifier. LIN uses a 6-bit frame ID with two parity bits in the PID.

8. LIN Response Field

After the master transmits the header, the response section is transmitted by the designated publisher.

The response contains:

  1. Data field.
  2. Checksum field.
+--------------------------------+
|          DATA FIELD            |
+--------------------------------+
|          CHECKSUM              |
+--------------------------------+
             RESPONSE

Response Characteristics

  • The publisher is defined for each frame in the network configuration.
  • The publisher can be the master or a slave node.
  • Subscribers receive the response from the LIN bus.
  • The response contains up to eight data bytes in LIN 2.x.
  • The checksum is used for error detection.

9. Data Field Timing and Transmission

The data field consists of UART-style serial data bytes transmitted by the publisher.

Each data byte contains eight data bits and is transmitted using the configured LIN serial format.

Example

Suppose a vehicle door-control node publishes three bytes:

ByteValueExample Meaning
Data 10x01Door open status
Data 20x00Window motor stopped
Data 30x64Motor command value

The receiving nodes interpret these bytes according to the signal definitions in the LIN network configuration.

10. Checksum Field Timing and Validation

The checksum is the final field of the LIN response.

Checksum Functions

  • Provides error detection for received data.
  • Allows receiving nodes to validate the response.
  • Helps identify corrupted transmissions.

Checksum Types

TypeCoverage
ClassicData bytes only.
EnhancedProtected identifier and data bytes.

Diagnostic frames use classic checksum. The detailed calculation method is covered in Lesson 17.

The master controls when the frame begins, while the designated publisher provides the response. All connected nodes observe the bus communication.

12. LIN Timing Example

Consider a LIN bus operating at 19.2 kbit/s.

Baud Rate = 19,200 bits/s

Bit Time = 1 / 19,200

         ≈ 52.08 µs

One 8-bit UART character:
8 data bits + start bit + stop bit

Total = 10 bit times

Character time ≈ 10 × 52.08 µs

               ≈ 520.8 µs

This example illustrates the approximate duration of one 8N1 UART character, excluding any additional protocol-specific timing.

Actual LIN frame duration also depends on break timing, delimiter timing, number of response bytes, inter-byte spacing and protocol timing requirements.

13. LPC2129 UART-Based LIN Synchronization

The LPC2129 does not have a dedicated LIN controller. Its UART can be used in a firmware-based LIN implementation with an external LIN transceiver.

Firmware Tasks

  • Configure the UART baud rate.
  • Generate or detect the break field.
  • Transmit or receive the 0x55 sync byte.
  • Receive and validate the protected identifier.
  • Transmit or receive response data.
  • Calculate and validate the checksum.

16. Interview Questions and Answers

Q1. Why does LIN require synchronization?

Answer: Synchronization helps slave nodes determine the master's bit timing and receive serial data reliably.

Q2. What is the LIN sync byte?

Answer: The sync byte is 0x55, which has an alternating bit pattern.

Q3. What is the function of the break field?

Answer: It indicates the start of a new LIN frame.

Q4. What is a break delimiter?

Answer: It is the recessive-level interval following the dominant break field and preceding the sync field.

Q5. What are the fields of the LIN header?

Answer: Break, sync and protected identifier.

Q6. What are the fields of the LIN response?

Answer: Data and checksum.

Q7. What is the maximum LIN communication speed?

Answer: The commonly specified maximum LIN bit rate is 20 kbit/s.

Q8. Who controls LIN frame timing?

Answer: The master task controls frame initiation and scheduling.

Q9. Can the slave transmit whenever it wants?

Answer: In normal scheduled LIN communication, a slave transmits its response only when the master sends the corresponding header.

Q10. Can UART alone connect an LPC2129 to the LIN bus?

Answer: No. An external LIN transceiver is required for physical bus interfacing.

17. Lesson Summary

  • LIN synchronization supports reliable serial communication.
  • Bit time is the reciprocal of baud rate.
  • The master transmits the header.
  • The header contains break, sync and protected identifier fields.
  • The sync byte is 0x55.
  • The protected identifier contains six ID bits and two parity bits.
  • The response contains data and checksum fields.
  • The publisher may be the master or a slave node.
  • LPC2129 requires UART-based firmware and an external LIN transceiver for a LIN implementation.
