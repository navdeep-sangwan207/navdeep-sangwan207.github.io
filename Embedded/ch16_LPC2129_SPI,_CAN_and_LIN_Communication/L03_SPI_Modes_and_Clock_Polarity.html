Lesson 03: SPI Modes and Clock Polarity

Understand clock polarity, clock phase, sampling edges, shifting edges and the four SPI communication modes.

2. Introduction to SPI Clock Modes

SPI communication uses a clock signal called SCLK to synchronize data transmission and reception.

The clock signal determines when data changes and when the receiving device samples the data.

Different SPI peripherals may require different clock configurations. To support these requirements, SPI uses two important parameters:

  • CPOL: Clock Polarity.
  • CPHA: Clock Phase.

The combination of these two parameters defines four standard SPI modes.

Both the controller and peripheral must use compatible clock polarity and phase settings for reliable communication.

3. Clock Polarity (CPOL)

CPOL stands for Clock Polarity. It determines the idle logic level of the SPI clock when no clock pulses are being generated.

CPOL = 0

When CPOL is zero, SCLK remains LOW during the idle state.

CPOL = 0: Clock Idle LOW 
SCLK

HIGH       +---+       +---+
           |   |       |   |
LOW  ------+   +-------+   +------
       Idle   Clock    Clock  Idle

CPOL = 1

When CPOL is one, SCLK remains HIGH during the idle state.

CPOL = 1: Clock Idle HIGH 
SCLK

HIGH  -----+   +-------+   +------
           |   |       |   |
LOW        +---+       +---+
       Idle   Clock    Clock  Idle
CPOL Clock Idle State
0 LOW
1 HIGH

4. Clock Phase (CPHA)

CPHA stands for Clock Phase. It determines which clock edge is used for sampling data.

SPI transfers data using clock transitions. Depending on CPHA, data is sampled on either the first or second clock edge of each bit period.

CPHA = 0

When CPHA is zero, data is sampled on the first clock edge.

  • Data is normally prepared before the first sampling edge.
  • The first edge is the sampling edge.
  • The second edge is the shifting or data-change edge.

CPHA = 1

When CPHA is one, data is sampled on the second clock edge.

  • The first edge is the shifting or data-change edge.
  • The second edge is the sampling edge.
  • Data must be stable around the sampling edge.
CPHA Sampling Edge
0 First clock edge
1 Second clock edge
First and second edges are counted from the beginning of the clock cycle. Whether the first edge is rising or falling depends on CPOL.

5. Rising Edge and Falling Edge

A clock signal changes between LOW and HIGH. These transitions are called clock edges.

Rising Edge

A rising edge occurs when the clock changes from LOW to HIGH.

Rising Edge 
HIGH           |
               |
LOW  ----------+---------
               ^
           Rising Edge

Falling Edge

A falling edge occurs when the clock changes from HIGH to LOW.

Falling Edge 
HIGH  ----------+
               |
LOW            |
               v
           Falling Edge

The first and second edges for each SPI mode are:

CPOL First Edge Second Edge
0 Rising Falling
1 Falling Rising

6. SPI Mode Configuration

SPI mode is determined by combining CPOL and CPHA. There are four standard combinations.

SPI Mode CPOL CPHA Clock Idle Sampling Edge
Mode 0 0 0 LOW Rising
Mode 1 0 1 LOW Falling
Mode 2 1 0 HIGH Falling
Mode 3 1 1 HIGH Rising
Remember:
CPOL determines the idle clock level.
CPHA determines whether sampling occurs on the first or second clock edge.

7. SPI Mode 0

Mode 0: CPOL = 0 and CPHA = 0.

  • Clock idle state is LOW.
  • First edge is rising.
  • Data is sampled on the rising edge.
  • Data changes on the falling edge.
Mode 0 Timing Concept 
SCLK       __/‾\__/‾\__/‾\__/‾\__

Sampling      ^     ^     ^     ^
Edge        Rising Rising Rising Rising

Data       --D7----D6----D5----D4--
            Stable around sampling

Mode 0 is a commonly used SPI mode. However, the required mode must always be obtained from the peripheral datasheet.

8. SPI Mode 1

Mode 1: CPOL = 0 and CPHA = 1.

  • Clock idle state is LOW.
  • First edge is rising.
  • Data changes on the rising edge.
  • Data is sampled on the falling edge.

9. SPI Mode 2

Mode 2: CPOL = 1 and CPHA = 0.

  • Clock idle state is HIGH.
  • First edge is falling.
  • Data is sampled on the falling edge.
  • Data changes on the rising edge.

Mode 3: CPOL = 1 and CPHA = 1.

12. Data Sampling and Data Shifting

SPI data transfer requires the transmitter to present a stable data bit and the receiver to sample that bit at the appropriate clock edge.

Data Sampling

Sampling means reading the logic value present on the data line at the configured sampling edge.

Data Shifting

Shifting means moving the next data bit into position for transmission or reception.

Sampling and Shifting Concept 
First Edge:
    One device samples the current data bit
    or the data is prepared, depending on CPHA.

Second Edge:
    The complementary operation takes place.

Next Clock Cycle:
    The next bit is transferred.
The transmitter must satisfy the receiver's setup-time and hold-time requirements. Correct CPOL and CPHA configuration ensures that both devices agree on the intended sampling edge.

13. Selecting the Correct SPI Mode

The SPI mode should be selected using the peripheral datasheet rather than guessing.

Selection Procedure

  1. Open the peripheral datasheet.
  2. Find the SPI timing or serial interface section.
  3. Identify the clock idle polarity.
  4. Identify the data sampling edge.
  5. Determine CPOL and CPHA.
  6. Configure the controller accordingly.
  7. Verify the waveform if hardware is available.

Example

Suppose a peripheral requires: 

Clock idle state = HIGH
Data sampled on the first clock edge

Therefore: 

CPOL = 1
CPHA = 0

SPI Mode = Mode 2

14. Clock Frequency and Timing

CPOL and CPHA define the clock relationship, but the clock frequency must also be selected correctly.

The peripheral datasheet specifies the maximum supported SPI clock frequency and timing requirements.

Example Calculation

SPI Clock Frequency = 2 MHz

Clock Period = 1 / 2,000,000

Clock Period = 0.5 microseconds

For an 8-bit transfer:

Ideal transfer time = 8 x 0.5 microseconds

                    = 4 microseconds

The actual transaction can take longer because of chip-select setup and hold times, controller overhead and peripheral processing delays.

16. LPC2129 SPI Programming Context

The LPC2129 SPI peripheral provides configuration options for controlling the clock and data transfer. The SPI control register includes fields that determine the clock polarity and phase.

The classic LPC2129 SPI peripheral uses these registers:

  • SPCR – SPI Control Register.
  • SPSR – SPI Status Register.
  • SPDR – SPI Data Register.
  • SPCCR – SPI Clock Counter Register.
  • SPINT – SPI Interrupt Flag Register.
The LPC2129 legacy SPI peripheral's register encoding should not be confused with SSP register configuration. Exact CPOL and CPHA bit positions and values will be covered with the LPC2129 register architecture in Lesson 04.

In Keil uVision simulator-only practice, you can study the register configuration and program execution. Actual clock waveforms and communication with an external SPI peripheral cannot be assumed unless the selected simulator model explicitly supports them.

17. Interview Questions and Answers

Q1. What is CPOL?

CPOL is Clock Polarity. It determines the idle logic level of the SPI clock.

Q2. What is CPHA?

CPHA is Clock Phase. It determines whether data is sampled on the first or second clock edge.

Q3. How many standard SPI modes exist?

There are four standard SPI modes.

Q4. What are the CPOL and CPHA values for Mode 0?

CPOL = 0 and CPHA = 0.

Q5. What are the CPOL and CPHA values for Mode 1?

CPOL = 0 and CPHA = 1.

Q6. What are the CPOL and CPHA values for Mode 2?

CPOL = 1 and CPHA = 0.

Q7. What are the CPOL and CPHA values for Mode 3?

CPOL = 1 and CPHA = 1.

Q8. What is the idle clock state in Mode 3?

HIGH.

Q9. On which edge does Mode 2 sample data?

On the first edge, which is the falling edge.

Q10. How do you select the correct SPI mode?

Check the peripheral datasheet for clock polarity and data sampling requirements.

Q11. What happens if CPOL and CPHA are configured incorrectly?

The receiver may sample data at the wrong time, resulting in corrupted or unreliable communication.

Q12. What is the difference between sampling and shifting?

Sampling reads the data bit; shifting moves the next bit into position for transfer.
