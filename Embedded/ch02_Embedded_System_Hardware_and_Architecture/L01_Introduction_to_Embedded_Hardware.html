Introduction to Embedded Hardware

Chapter 2: Embedded System Hardware and Architecture

Lesson 01: Understanding the physical components of embedded systems

1. Introduction

Embedded hardware refers to the physical electronic components used to build an embedded system. These components work together to receive input, process information, store data and generate the required output.

An embedded system may contain a microcontroller or microprocessor, memory devices, input/output circuits, sensors, actuators, communication interfaces, clock circuits and a power supply.

The hardware provides the physical platform on which embedded software or firmware executes.

Definition: Embedded hardware is the collection of electronic and electromechanical components that implement the physical functions of an embedded system.

Examples

  • Microcontroller inside a washing machine.
  • Processor and memory inside an automotive control unit.
  • Temperature sensor and control circuit in an air conditioner.
  • Microcontroller-based digital energy meter.
  • Electronic control hardware in an industrial automation system.

2. Hardware and Firmware Relationship

Embedded hardware and firmware are two essential parts of an embedded system. They perform different but complementary roles.

Hardware

  • Consists of physical electronic components.
  • Provides processing, storage and input/output facilities.
  • Connects the system to the physical environment.
  • Determines electrical and hardware-level capabilities.

Firmware

  • Consists of software designed for a specific embedded device.
  • Controls the operation of hardware peripherals.
  • Processes input data and makes control decisions.
  • May be stored in Flash memory or other non-volatile memory.

Important: Firmware cannot directly perform physical actions. It uses processor instructions and hardware peripherals to control external electronic devices.

3. Major Components of Embedded Hardware

An embedded system can contain several hardware subsystems. The exact components depend on the application's requirements.

3.1 Processing Unit

The processing unit executes instructions and controls the operation of the embedded system.

Common processing devices include:

  • Microcontrollers (MCUs).
  • Microprocessors (MPUs).
  • Digital Signal Processors (DSPs).
  • Application-specific integrated circuits (ASICs).
  • Field-Programmable Gate Arrays (FPGAs).

For example, the LPC2129 uses an ARM7TDMI-S processor core.

3.2 Memory Unit

Memory stores program instructions, configuration information and temporary data.

  • ROM: Non-volatile memory used for permanent information.
  • Flash: Non-volatile memory commonly used to store firmware.
  • RAM: Volatile memory used for variables, stack and runtime data.
  • EEPROM: Non-volatile memory used for data that may need to be updated.

3.3 Input Unit

Input hardware allows an embedded system to receive information from the user or surrounding environment.

  • Push buttons and switches.
  • Temperature sensors.
  • Pressure sensors.
  • Light sensors.
  • Keypads and digital input devices.

3.4 Output Unit

Output hardware communicates system status or performs physical actions.

  • LED indicators.
  • LCD and seven-segment displays.
  • Buzzers and speakers.
  • Relays.
  • Motors and other actuators.

3.5 Communication Interfaces

Communication interfaces allow the processor to exchange information with other devices and systems.

  • UART – Universal Asynchronous Receiver/Transmitter.
  • SPI – Serial Peripheral Interface.
  • I2C – Inter-Integrated Circuit.
  • CAN – Controller Area Network.
  • USB, Ethernet and wireless interfaces where supported.

3.6 Clock Circuit

The clock circuit provides timing signals required by the processor and other synchronous hardware components. A clock source may be an external crystal, oscillator or an internal oscillator, depending on the device.

3.7 Reset Circuit

The reset circuit places the processor into a known initial state. Reset may occur during power-up, through an external reset signal or through an internal reset mechanism.

3.8 Power Supply

The power supply provides the voltage and current required by the embedded hardware.

  • Battery supplies.
  • AC-to-DC power converters.
  • Voltage regulators.
  • DC-to-DC converters.
  • Power management circuits.

4. Basic Embedded Hardware Architecture

A basic embedded system follows an input-processing-output architecture. The input unit receives information, the processor executes the control program, and the output unit produces the required response.

5. Internal and External Hardware Components

Hardware components can also be classified according to whether they are integrated inside the main processing device or connected externally.

Internal Components External Components
CPU core External sensors
Internal Flash memory External memory devices
Internal SRAM LCD display modules
GPIO controllers Motors and relays
Timers and counters External communication modules
UART, SPI and I2C controllers Signal-conditioning circuits
The distinction depends on the particular microcontroller. Some devices integrate many peripherals, while others require external components to provide the same functionality.

6. Example: LPC2129 Embedded Hardware

The LPC2129 is an ARM7-based microcontroller used in embedded control applications. It integrates a processor core, memory and several peripheral controllers on a single chip.

Major LPC2129 Hardware Features

  • ARM7TDMI-S processor core.
  • On-chip Flash program memory.
  • On-chip SRAM.
  • GPIO ports.
  • Timer and counter peripherals.
  • UART0 and UART1 serial interfaces.
  • I2C and SPI interfaces.
  • ADC peripheral.
  • PWM controller.
  • CAN controllers.
  • Vectored Interrupt Controller (VIC).

Example Applications

  1. Reading a temperature sensor through the ADC.
  2. Controlling an LED through a GPIO pin.
  3. Sending debugging information through UART0.
  4. Generating a periodic event using a hardware timer.
  5. Controlling motor speed using PWM.
  6. Exchanging data with an external device through I2C or SPI.
Hardware design consideration: The LPC2129 provides peripheral controllers, but external components may still be necessary. For example, a physical CAN network requires a CAN transceiver, and a motor generally requires a suitable driver circuit.

7. Role of Hardware in Embedded System Operation

A typical embedded system operates through the following sequence:

  1. Power-up: The power supply provides the required operating voltage.
  2. Reset: The processor enters a known initial state.
  3. Program execution: The processor starts executing firmware.
  4. Input acquisition: Sensors and switches provide input data.
  5. Data processing: The CPU processes the input according to the program.
  6. Output control: Peripheral circuits drive the required outputs.
  7. Communication: The system exchanges information with other devices when required.
Example: In an automatic temperature-control system, a sensor provides temperature information, the processor compares it with a configured threshold, and an output circuit controls a fan or relay.

8. Hardware Design Considerations

Selecting and designing embedded hardware requires consideration of several engineering parameters.

  • Processing performance: CPU speed and processing capability.
  • Memory capacity: Flash and RAM requirements.
  • Power consumption: Energy efficiency and battery life.
  • Operating voltage: Electrical compatibility of components.
  • Peripheral requirements: Required communication and control interfaces.
  • Environmental conditions: Temperature, vibration, humidity and electrical noise.
  • Reliability: Stable operation under expected conditions.
  • Cost and size: Manufacturing cost and physical dimensions.

9. Common Mistakes

  • Confusing embedded hardware with embedded firmware.
  • Assuming every embedded system requires an external microprocessor.
  • Assuming all microcontrollers have identical peripheral features.
  • Ignoring voltage and current requirements when connecting external devices.
  • Connecting motors directly to GPIO pins without a suitable driver.
  • Assuming a communication controller alone provides the complete physical communication interface.
  • Ignoring clock and reset requirements during hardware design.

10. Interview Questions and Answers

Q1. What is embedded hardware?

Embedded hardware is the collection of physical electronic components used to implement an embedded system.

Q2. What are the major components of embedded hardware?

The major components include a processing unit, memory, input/output interfaces, communication peripherals, clock circuit, reset circuit and power supply.

Q3. What is the function of a processing unit?

It executes program instructions, processes data and controls the operation of the embedded system.

Q4. What is the difference between hardware and firmware?

Hardware consists of physical electronic components, whereas firmware is the embedded software that controls those components.

Q5. What is the function of memory in an embedded system?

Memory stores program instructions, configuration data and temporary runtime information.

Q6. Why is a clock circuit required?

It provides timing signals that synchronize processor operations and other synchronous hardware functions.

Q7. What is the function of a reset circuit?

It initializes the processor and places the system into a known starting state.

Q8. Name some communication interfaces used in embedded systems.

UART, SPI, I2C, CAN, USB and Ethernet are examples of communication interfaces.

Q9. What is the role of a sensor?

A sensor detects a physical quantity and converts it into an electrical signal that can be processed by the system.

Q10. Which processor core is used in the LPC2129?

The LPC2129 uses an ARM7TDMI-S processor core.

13. Lesson Summary

  • Embedded hardware consists of physical electronic components.
  • The processing unit executes firmware instructions.
  • Memory stores program code and runtime data.
  • Input and output circuits connect the system to its environment.
  • Communication interfaces enable data exchange.
  • Clock and reset circuits support reliable processor operation.
  • Power supply circuits provide the required electrical energy.
  • The LPC2129 integrates an ARM7TDMI-S core, memory and multiple peripherals.
Learning Outcome: You should now be able to identify the major hardware components of an embedded system and explain how they work together to perform a dedicated application.
