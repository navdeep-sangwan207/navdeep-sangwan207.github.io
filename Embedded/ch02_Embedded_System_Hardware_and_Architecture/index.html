Chapter Overview

Embedded system hardware consists of the physical electronic components that work together to perform a dedicated function. These components include processors, memory, input/output interfaces, sensors, actuators, communication buses, clock circuits and power supplies.

This chapter explains the internal hardware organization of embedded systems, the functions of individual components and how these components communicate with one another. It also introduces the architecture of a microcontroller-based system using the LPC2129 as a practical reference.

Learning Objectives

After completing this chapter, you will be able to:

  • Explain the meaning and role of embedded system hardware.
  • Differentiate between microprocessors and microcontrollers.
  • Understand CPU architecture and its major components.
  • Explain ROM, RAM, Flash and other memory technologies.
  • Understand processor registers and register organization.
  • Describe address, data and control buses.
  • Explain clock generation and reset circuits.
  • Understand GPIO ports and digital input/output operations.
  • Identify sensors, actuators and their interfaces.
  • Interpret a basic embedded system block diagram.
