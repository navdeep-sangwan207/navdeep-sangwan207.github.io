Microprocessor vs Microcontroller

Chapter 2: Embedded System Hardware and Architecture

Lesson 02: Architectural differences and applications

1. Introduction

Microprocessors and microcontrollers are important processing devices used in electronic and computing systems. Both execute program instructions and process data, but they differ in their architecture, peripheral integration, memory organization, power consumption and applications.

A microprocessor is primarily a processing unit that generally relies on external memory and peripheral controllers to build a complete system. A microcontroller integrates a processor, memory and various peripheral controllers into a single integrated circuit.

Basic distinction: A microprocessor generally requires more external components to build a complete system, whereas a microcontroller integrates many essential system components into one chip.

2. What is a Microprocessor?

A microprocessor is a programmable semiconductor device that contains a Central Processing Unit (CPU) on a single integrated circuit.

It performs arithmetic, logical, control and data-processing operations by executing instructions stored in memory.

A typical microprocessor-based system uses external memory, input/output controllers and other support circuits.

Major Components

  • Arithmetic Logic Unit (ALU): Performs arithmetic and logical operations.
  • Control Unit: Coordinates instruction execution.
  • Registers: Store temporary data, addresses and processor state.
  • Internal buses: Transfer information between CPU components.
  • Bus interface: Communicates with external memory and peripherals.

A microprocessor-based system is not necessarily a desktop computer. Microprocessors are also used in industrial systems, communication equipment and embedded computing platforms.

3. What is a Microcontroller?

A microcontroller is a programmable integrated circuit that combines a processor core, memory and peripheral interfaces in a single chip.

It is designed to control specific operations in electronic devices and embedded applications.

Major Components

  • CPU: Executes program instructions.
  • Flash or ROM: Stores firmware.
  • RAM: Stores temporary variables and runtime data.
  • GPIO: Provides digital input and output.
  • Timers and Counters: Generate timing events and count signals.
  • ADC: Converts analog input signals into digital values.
  • Communication Interfaces: UART, SPI, I2C and other interfaces, depending on the device.
  • Interrupt Controller: Manages interrupt requests.

4. Microprocessor vs Microcontroller: Architecture

The most important difference is the level of integration. A microprocessor primarily provides the CPU, while a microcontroller integrates the CPU with memory and peripheral controllers.

Feature Microprocessor Microcontroller
Basic structure Primarily a CPU CPU with memory and peripherals
Memory Usually external memory is required Typically includes on-chip memory
GPIO Usually provided through external controllers or integrated platform peripherals Commonly integrated on-chip
Timers May require external or platform-specific timer controllers Commonly integrated on-chip
ADC Often requires an external ADC or another integrated subsystem May be integrated on-chip
System complexity Often requires additional hardware Often simpler for dedicated control applications
Power consumption Depends on the processor and complete platform; often higher in complex systems Often optimized for low-power control applications
Processing capability Often designed for high-performance computing Designed for a range of dedicated control and processing tasks
Typical applications Computers, application processors and computing platforms Appliances, controllers and embedded devices
These are general architectural tendencies, not absolute rules. Modern microprocessors may integrate memory controllers, graphics and many peripherals. Some microcontrollers also provide substantial processing performance.

5. Memory Organization

Microprocessor-Based System

In a conventional microprocessor-based system, program memory and data memory are often implemented using external memory devices connected to the processor through system buses.

  • External RAM stores temporary data.
  • External ROM or Flash stores program code.
  • Memory controllers manage access to memory devices.

Microcontroller-Based System

A microcontroller commonly integrates program memory and data memory on the same chip as the processor.

  • On-chip Flash stores firmware.
  • On-chip SRAM stores variables and runtime data.
  • Some devices provide EEPROM or other non-volatile storage.
Example: The LPC2129 includes on-chip Flash program memory and SRAM. The processor accesses these resources as part of its memory system.

6. Peripheral Integration

Peripheral integration is another major difference between microprocessors and microcontrollers.

Microprocessor

Depending on the platform, additional controllers may be required for GPIO, timers, serial communication, storage and other functions.

Microcontroller

Many peripherals are integrated into the same chip. The firmware can configure these peripherals through their hardware registers.

Peripheral Purpose
GPIO Digital input and output operations
Timer Time measurement and periodic events
UART Asynchronous serial communication
SPI Synchronous serial communication
I2C Two-wire serial communication
ADC Analog-to-digital conversion
PWM Pulse-width modulation
Interrupt Controller Interrupt request management

7. Advantages and Limitations

Microprocessor Advantages

  • Suitable for complex and computationally intensive applications.
  • Can support large memory configurations.
  • Can run sophisticated operating systems on suitable platforms.
  • Offers flexibility in selecting external memory and peripherals.

Microprocessor Limitations

  • May require additional external components.
  • System design can be more complex.
  • PCB size and total system cost may increase.
  • Power requirements may be higher for complex computing platforms.

Microcontroller Advantages

  • High integration of processing, memory and peripherals.
  • Suitable for dedicated control applications.
  • Often has lower system cost and smaller circuit size.
  • Many devices provide low-power operating modes.
  • Convenient access to integrated peripherals through hardware registers.

Microcontroller Limitations

  • On-chip memory may be limited.
  • Processing resources may be insufficient for demanding applications.
  • Peripheral availability depends on the selected device.
  • Expanding memory and hardware resources may require external components.

9. Example: LPC2129 as a Microcontroller

The NXP LPC2129 is an example of a microcontroller because it integrates an ARM7TDMI-S processor core, memory and peripheral controllers within one device.

Important Integrated Resources

  • ARM7TDMI-S 32-bit processor core.
  • On-chip Flash memory.
  • On-chip SRAM.
  • GPIO ports.
  • Timers and counters.
  • UART0 and UART1.
  • I2C and SPI interfaces.
  • ADC channels.
  • PWM peripheral.
  • CAN controllers.
  • Vectored Interrupt Controller.

Example Application: LED Control

Consider a microcontroller-based system that controls an LED. The firmware configures a GPIO pin as an output and changes its output state.

Hardware connections:

  • LPC2129 microcontroller.
  • GPIO output pin.
  • Current-limiting resistor.
  • LED and suitable supply/ground connections.

Example Embedded C program:

#include <LPC21xx.h>

int main(void)
{
    /* Configure P0.10 as GPIO output */
    PINSEL0 &= ~(3U << 20);

    /* Configure P0.10 as output */
    IODIR0 |= (1U << 10);

    /* Set P0.10 high */
    IOSET0 = (1U << 10);

    while (1)
    {
        /* Maintain output state */
    }
}

Program Explanation

  • #include <LPC21xx.h> provides LPC21xx register definitions.
  • PINSEL0 selects the pin function.
  • IODIR0 configures the pin direction.
  • IOSET0 sets the selected output bit high.
  • The infinite loop keeps the program running.
Expected register-level result: P0.10 is configured as GPIO output and its output latch is set high. In Keil uVision Simulator, the register values can be inspected. Actual LED illumination requires suitable physical hardware and electrical connections.
This example uses P0.10, which is selected through PINSEL0. Verify the device pin multiplexing and external circuit connections before using the program on a physical board.

10. How to Select Between Them

Selecting a microprocessor or microcontroller depends on the requirements of the application.

Choose a Microcontroller When:

  • The application performs dedicated control operations.
  • Integrated GPIO and peripheral interfaces are required.
  • Low power consumption is important.
  • Small circuit size and cost are priorities.
  • The memory and processing requirements fit the selected device.

Choose a Microprocessor When:

  • The application requires substantial processing performance.
  • Large memory capacity is necessary.
  • A complex operating system is required.
  • Advanced computing, multimedia or networking workloads are involved.
  • The design benefits from a flexible external hardware platform.
Design principle: Select the processor architecture according to the application's processing, memory, peripheral, power, cost and reliability requirements.

11. Interview Questions and Answers

Q1. What is a microprocessor?

A microprocessor is a programmable integrated circuit containing a CPU that executes instructions and processes data.

Q2. What is a microcontroller?

A microcontroller is an integrated circuit that combines a processor core, memory and peripheral interfaces.

Q3. What is the main difference between a microprocessor and a microcontroller?

A microprocessor primarily provides the CPU, whereas a microcontroller integrates the CPU, memory and peripherals in a single chip.

Q4. Why are microcontrollers widely used in embedded systems?

They integrate essential processing, memory and peripheral resources, making them suitable for compact dedicated control applications.

Q5. Can a microprocessor be used in an embedded system?

Yes. Microprocessors are used in embedded computing platforms that require higher processing performance or more extensive memory resources.

Q6. Does every microcontroller contain an ADC?

No. ADC availability depends on the specific microcontroller.

Q7. Which processor core is used in the LPC2129?

The LPC2129 uses the ARM7TDMI-S processor core.

Q8. Can a microcontroller run an operating system?

Yes. Suitable microcontrollers can run an RTOS or other supported operating systems, depending on their processing resources and memory capacity.

Q9. What is peripheral integration?

Peripheral integration means including functional hardware blocks such as GPIO, timers and communication controllers within the same integrated circuit as the processor.

Q10. Which is better for motor control: a microprocessor or microcontroller?

A microcontroller is commonly suitable for dedicated motor control because it often integrates timers, PWM, GPIO and interrupt facilities. The final selection depends on performance and control requirements.
