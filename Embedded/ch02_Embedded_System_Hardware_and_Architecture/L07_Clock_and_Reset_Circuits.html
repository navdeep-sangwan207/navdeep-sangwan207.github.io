Clock and Reset Circuits

Chapter 2: Embedded System Hardware and Architecture

Lesson 07: Clock generation and reset mechanisms

1. Introduction

Clock and reset circuits are essential components of digital embedded systems. The clock provides timing synchronization, while the reset circuit initializes the processor and other hardware components into a known state.

Without a reliable clock, synchronous digital circuits cannot perform operations at the intended rate. Without a proper reset mechanism, a processor may begin execution with undefined or inconsistent hardware states.

Clock: A periodic timing signal used to coordinate operations in digital circuits.

Reset: A control mechanism that initializes a processor or digital system into a predefined state.

2. What Is a Clock Signal?

A clock signal is a periodic digital waveform that alternates between logic HIGH and logic LOW states. It provides timing references for synchronous operations.

Clock Waveform

Figure: Periodic digital clock waveform

Important Clock Parameters

  • Frequency: Number of clock cycles per second.
  • Period: Time required to complete one cycle.
  • Duty cycle: Percentage of one period for which the signal remains HIGH.
  • Amplitude: Voltage difference between the signal levels.
  • Rise time: Time taken for the signal to transition from LOW to HIGH.
  • Fall time: Time taken for the signal to transition from HIGH to LOW.

3. Clock Frequency and Time Period

Clock frequency and clock period are inversely proportional.

Formula:

Frequency: f = 1 / T

Time period: T = 1 / f

Where f is frequency in hertz (Hz) and T is period in seconds.

Example 1: 1 MHz Clock

Frequency = 1 MHz

         = 1,000,000 Hz

Time period = 1 / 1,000,000

            = 1 microsecond

Example 2: 12 MHz Clock

Frequency = 12 MHz

Time period = 1 / 12,000,000

            = 83.33 nanoseconds (approximately)

Example 3: 60 MHz Clock

Frequency = 60 MHz

Time period = 1 / 60,000,000

            = 16.67 nanoseconds (approximately)

Duty Cycle

Duty cycle represents the percentage of one clock period during which the signal remains HIGH. 

Duty Cycle = (HIGH Time / Total Period) × 100

Example:

HIGH Time = 5 microseconds
LOW Time  = 5 microseconds

Total Period = 10 microseconds

Duty Cycle = (5 / 10) × 100

           = 50%

4. Why Does an Embedded System Need a Clock?

The clock provides a common timing reference for digital operations.

Major Functions

  • Synchronizes processor operations.
  • Controls instruction execution timing.
  • Provides timing references for counters and timers.
  • Supports communication interfaces.
  • Controls internal peripheral operation rates.
  • Helps coordinate data transfers.

5. Clock Sources

An embedded system can use different sources to generate its clock signal.

5.1 Internal RC Oscillator

An internal RC oscillator uses resistor-capacitor based circuitry to generate a clock signal.

Advantages:

  • Integrated inside the microcontroller.
  • Requires fewer external components.
  • Can reduce system cost.
  • Often suitable for applications with moderate timing requirements.

Limitations:

  • Frequency accuracy may be lower than a crystal reference.
  • Frequency can vary with temperature and supply voltage.

5.2 External Crystal Oscillator

A crystal oscillator uses the mechanical resonance of a quartz crystal to produce a stable frequency.

Advantages:

  • Good frequency stability.
  • Suitable for accurate timing applications.
  • Useful for communication interfaces requiring precise clock references.

Limitations:

  • Requires external components in many designs.
  • Startup time must be considered.
  • PCB layout and load capacitance affect performance.

5.3 External Clock Generator

An external oscillator module can provide a clock signal directly to a microcontroller clock input.

It is useful when a system requires a particular frequency or a clock source shared by multiple devices.

5.4 PLL-Based Clock Generation

A Phase-Locked Loop (PLL) is used to generate a higher-frequency clock from a reference clock.

The PLL adjusts its output frequency so that it maintains a defined phase and frequency relationship with its reference.

6. Crystal Oscillator Frequency

A crystal oscillator is selected according to the frequency requirements of the microcontroller and its peripherals.

Common Crystal Frequencies

The selected crystal frequency must satisfy the microcontroller's electrical specifications and clock configuration limits.

7. Clock Multiplication and Division

Microcontrollers may use clock multiplication and division to generate the required operating frequencies.

Clock Multiplication

A PLL can multiply the reference frequency to produce a higher processor clock frequency.

Clock Division

A clock divider reduces a clock frequency to generate a slower clock for a processor domain or peripheral.

Example: 12 MHz to 60 MHz

Input clock = 12 MHz

PLL multiplication factor = 5

Output clock = 12 × 5

              = 60 MHz
This is a simplified mathematical example. Real PLL configurations use device-specific equations, divider values, lock requirements and operating limits.

CPU Clock and Peripheral Clock

A microcontroller may operate its CPU and peripherals at different clock frequencies. 

CPU Clock (CCLK) = 60 MHz

Peripheral Clock (PCLK) = 15 MHz

PCLK / CCLK = 15 / 60

            = 1 / 4

The CPU operates at 60 MHz, while the peripheral clock domain operates at 15 MHz in this example.

8. Clock Configuration in LPC2129

The LPC2129 uses an external clock reference and an internal PLL-based clock-generation mechanism. Its clock configuration determines the processor and peripheral operating frequencies.

Important Clock Parameters

Parameter Meaning
FOSC Oscillator frequency.
CCLK Processor clock frequency.
PCLK Peripheral clock frequency.
PLLCON PLL control register.
PLLCFG PLL configuration register.
PLLSTAT PLL status register.
PLLFEED PLL feed register.
VPBDIV Peripheral clock divider control.

Example Clock Configuration

External Oscillator (FOSC) = 12 MHz

CPU Clock (CCLK) = 60 MHz

Peripheral Clock (PCLK) = 15 MHz

VPBDIV = 4

PCLK = CCLK / 4

     = 60 MHz / 4

     = 15 MHz

The PLL configuration must be selected according to the LPC2129 PLL limits and the required clock frequency.

In the LPC2129, the PLL uses device-specific MSEL and PSEL settings. The PLL configuration must also satisfy the permitted FCCO frequency range.

Why Is PCLK Important?

Many LPC2129 peripherals use PCLK for timing. For example:

  • UART baud-rate generation.
  • Timer and counter operation.
  • I2C clock generation.
  • Other peripheral timing calculations.
Incorrect PCLK configuration can cause incorrect UART baud rates, timer intervals and peripheral communication timing.

9. What Is a Reset Circuit?

A reset circuit initializes the microcontroller when power is applied or when a reset event occurs.

Reset places the processor into a defined startup state so that it can begin executing its startup sequence.

Functions of Reset

  • Initializes the processor.
  • Places important control logic into reset states.
  • Sets the processor to its defined startup mode.
  • Allows the startup code to execute correctly.
  • Helps recover from certain system faults.
Reset does not necessarily erase program memory. It initializes processor and peripheral state according to the device's reset specification.

10. Types of Reset

10.1 Power-On Reset (POR)

Power-On Reset occurs when the system supply voltage is applied. It keeps the processor in reset until the supply and required startup conditions are sufficiently stable.

10.2 External Reset

An external reset signal is applied through a reset input pin. A push button or external reset supervisor may be used.

10.3 Watchdog Reset

A watchdog timer can reset the processor if the application fails to service the watchdog within the configured time.

10.4 Software Reset

Some microcontrollers provide a mechanism for software to request a system reset.

Reset Type Trigger Typical Purpose
Power-On Reset Power application Initial startup
External Reset Reset input signal Manual or external recovery
Watchdog Reset Watchdog timeout Recovery from software failure
Software Reset Software request Controlled restart where supported
Reset mechanisms and their availability differ between microcontrollers. Always consult the relevant device datasheet and user manual.

11. Power-On Reset Circuit

A power-on reset circuit ensures that the processor does not begin normal operation before the supply voltage has reached an acceptable level.

Basic RC Reset Concept

A resistor-capacitor network can generate a delayed reset transition during power-up in a suitable reset-input configuration.

Conceptual RC Reset Circuit

Conceptual diagram: Exact component connections and reset polarity depend on the target MCU.

Working Principle

  1. Power is applied to the circuit.
  2. The capacitor initially holds the reset node in its initial condition.
  3. The capacitor charges through the resistor.
  4. The reset input changes state after the RC transition.
  5. The processor can begin normal startup when reset is released and other startup requirements are satisfied.
A simple RC circuit is not a universal replacement for a dedicated reset supervisor. Supply ramps, brownouts, noise, input thresholds and reset pulse width must be considered.

12. Reset Timing and Sequencing

Reset timing defines when the processor enters reset and when it is allowed to begin execution.

Typical Startup Sequence

  1. Power supply begins rising.
  2. Reset circuit holds the processor in reset.
  3. Supply voltage becomes stable.
  4. Clock source starts and becomes stable.
  5. Required clock configuration is established.
  6. Reset is released according to the device specifications.
  7. Processor begins executing its startup code.

13. Brownout Detection and Reset

A brownout occurs when the supply voltage falls below the required operating level but does not completely disappear.

If the processor continues operating at an insufficient supply voltage, incorrect execution or unpredictable behavior may occur.

Brownout Detection

A brownout detector monitors the supply voltage. When the voltage falls below a configured threshold, the system can hold the processor in reset or generate an appropriate warning.

Why Is It Important?

  • Protects against operation below valid voltage limits.
  • Reduces the risk of corrupted operations.
  • Improves system reliability during supply disturbances.
  • Supports controlled recovery after voltage returns.

15. Practical Example: LPC2129 Clock Configuration

Consider an LPC2129 development configuration with the following clock values: 

External Oscillator (FOSC) = 12 MHz

CPU Clock (CCLK) = 60 MHz

Peripheral Clock (PCLK) = 15 MHz

VPBDIV = 4

PCLK = CCLK / 4

     = 60 / 4

     = 15 MHz

Practical Checks

  1. Confirm the oscillator frequency used by the project.
  2. Check PLL multiplier and divider configuration.
  3. Confirm the PLL lock status before relying on its output.
  4. Verify peripheral clock divider settings.
  5. Use the correct PCLK when calculating timer and UART settings.
In Keil uVision simulator-only work, inspect available registers and clock-related configuration where supported. Do not assume the simulator reproduces physical oscillator startup, supply ramp behavior or external reset circuitry.

16. Interview Questions and Answers

Q1. What is a clock signal?

A periodic signal that provides timing synchronization for digital circuits.

Q2. What is clock frequency?

The number of complete clock cycles per second, measured in hertz.

Q3. What is the relationship between frequency and period?

They are inversely proportional: f = 1/T.

Q4. What is a crystal oscillator?

An oscillator that uses the resonance of a quartz crystal to generate a stable frequency.

Q5. What is a PLL?

A Phase-Locked Loop is a feedback system used to generate or synchronize clock frequencies relative to a reference.

Q6. What is CCLK?

CCLK represents the CPU clock frequency in the LPC2129 clock configuration.

Q7. What is PCLK?

PCLK represents the peripheral clock frequency used by peripheral timing circuits.

Q8. What is Power-On Reset?

It initializes the system when power is applied and helps prevent execution before valid startup conditions are reached.

Q9. What is a watchdog reset?

A reset generated when the watchdog timer expires because the application has failed to service it in time.

Q10. What is brownout detection?

It detects when supply voltage falls below a specified operating threshold.

Q11. Why is reset sequencing important?

It ensures that the processor starts only after the required power and clock conditions are met.

Q12. What happens if PCLK is configured incorrectly?

Peripheral timing calculations may become incorrect, affecting UART baud rates, timers and other peripheral functions.

19. Lesson Summary

  • A clock provides timing synchronization for digital circuits.
  • Clock frequency is measured in hertz.
  • Clock period is the inverse of frequency.
  • Clock sources include RC oscillators, crystal oscillators and external clock generators.
  • A PLL can generate a higher-frequency clock from a reference.
  • Clock dividers generate lower-frequency clock domains.
  • CCLK represents the CPU clock in LPC2129.
  • PCLK represents the peripheral clock.
  • Reset initializes the processor and relevant hardware.
  • Common reset types include power-on, external, watchdog and software reset.
  • Brownout detection helps protect against insufficient supply voltage.
  • Correct clock and reset sequencing improves system reliability.
