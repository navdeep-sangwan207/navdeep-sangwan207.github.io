Lesson 03: Internal organization and operation of a CPU

1. Introduction

The Central Processing Unit (CPU) is the primary processing component of a computer or embedded system. It executes instructions, performs arithmetic and logical operations, controls data movement and coordinates the operation of other hardware components.

The CPU works with memory and input/output peripherals to execute the application program stored in the system.

Definition: The CPU is a programmable processing unit that fetches, decodes and executes instructions to perform the operations required by a computer or embedded system.

Major Functions of a CPU

  • Fetches instructions from memory.
  • Decodes instructions to determine the required operation.
  • Performs arithmetic and logical operations.
  • Controls data transfer between registers, memory and peripherals.
  • Updates processor status information.
  • Responds to interrupts and exceptions.
  • Controls the sequence of program execution.

2. Basic CPU Architecture

A CPU consists of several internal functional units that cooperate to execute instructions.

Major CPU Components

  2. Control Unit (CU).
  3. Register Set.

3. Arithmetic Logic Unit (ALU)

The Arithmetic Logic Unit is the CPU component responsible for performing arithmetic and logical operations on data.

3.1 Arithmetic Operations

  • Addition.
  • Subtraction.
  • Increment.
  • Decrement.
  • Arithmetic comparisons.

3.2 Logical Operations

  • AND.
  • OR.
  • XOR.
  • NOT.
  • Bitwise operations.

3.3 Shift Operations

  • Logical shift left.
  • Logical shift right.
  • Arithmetic shift right.
  • Rotate operations, where supported by the instruction set.

Example: Addition

Suppose the CPU needs to add two numbers: 

A = 10
B = 20

RESULT = A + B

RESULT = 30

The ALU performs the addition operation and makes the result available to the processor for storage or further processing.

Example: Logical AND

  1100
AND 1010
--------
  1000

The logical AND operation produces a 1 only when both corresponding input bits are 1.

Important: Depending on the CPU architecture, arithmetic and logical operations may update status flags such as Zero, Carry, Negative and Overflow.

4. Control Unit (CU)

The Control Unit coordinates the activities of the CPU. It interprets instructions and generates control signals required to perform the specified operations.

Functions of the Control Unit

  • Fetches instructions from memory.
  • Decodes the instruction operation.
  • Controls data movement between registers and other units.
  • Coordinates ALU operations.
  • Controls memory read and write operations.
  • Maintains the correct sequence of instruction execution.
  • Coordinates processor response to interrupts and exceptions.

Instruction Decoding Example

Consider an instruction that adds two registers: 

ADD R0, R1, R2

In an ARM-style assembly instruction, this represents an operation that adds the contents of R1 and R2 and stores the result in R0.

The control logic coordinates the following activities:

  1. Obtains the instruction.
  2. Decodes the ADD operation.
  3. Identifies the source registers R1 and R2.
  4. Routes their values to the ALU.
  5. Controls the addition operation.
  6. Stores the result in R0.

5. CPU Registers

Registers are small, high-speed storage locations inside the processor. They hold data, addresses, instructions and processor control information required during execution.

Common Types of Registers

Register Function
Program Counter (PC) Holds the address associated with the next instruction to execute.
Instruction Register (IR) Holds the current instruction in architectures that use an explicit instruction register.
General-Purpose Registers Store temporary data, operands and intermediate results.
Status Register Stores processor condition flags and control state.
Stack Pointer (SP) Holds the address used to manage the processor stack.
Link Register (LR) Stores a return address during subroutine calls in architectures such as ARM.
Memory Address Register (MAR) Represents an address used for a memory operation in a simplified CPU model.
Memory Data Register (MDR) Represents data being transferred to or from memory in a simplified CPU model.
MAR, MDR and IR are useful conceptual registers in basic computer architecture. They are not necessarily exposed as named programmer-visible registers in every processor.

The detailed register organization of the ARM7 processor will be covered in the ARM architecture chapters.

Common Operations

  • Returning ALU results to registers.
  • Transferring instructions and data between CPU and memory.

7. Instruction Execution Cycle

The CPU executes a program by repeatedly processing instructions. This process is commonly explained through the fetch-decode-execute cycle.

7.1 Fetch

The processor obtains the next instruction from memory using the instruction address associated with the Program Counter.

7.2 Decode

The instruction is interpreted to identify the operation, operands and addressing information.

7.3 Execute

The processor performs the required operation, such as arithmetic, logical processing, data movement or branching.

7.4 Store or Write Back

When required, the result is written to a destination register or memory location.

Instruction Execution Cycle

Fetch
↓
Decode
↓
Execute
↓
Write Back
↓
Next Instruction
The exact instruction execution stages depend on the processor architecture. Some instructions do not require a separate write-back stage, and pipelined CPUs overlap different stages of multiple instructions.

8. Clock and CPU Performance

The processor clock provides timing signals that coordinate internal CPU operations.

Clock frequency is commonly measured in Hertz (Hz). One megahertz (MHz) represents one million cycles per second.

Example

Consider a processor operating at a clock frequency of 60 MHz.

Number of clock cycles per second: 

Frequency = 60 MHz

Frequency = 60 × 10^6 cycles/second

            = 60,000,000 cycles/second

The clock period is the reciprocal of frequency:

\[ T = \frac{1}{f} \]

For a 60 MHz clock:

\[ T = \frac{1}{60 \times 10^6} \] \[ T \approx 16.67\text{ ns} \]
A CPU clock frequency does not directly tell us how many instructions are executed per second. Instruction execution time also depends on the architecture, pipeline, memory access, instruction type and other factors.

9. Pipelining in CPU Architecture

Pipelining is a CPU implementation technique in which instruction processing is divided into stages. Different instructions can occupy different stages at the same time.

Without Pipelining

In a simple non-overlapped model, the processor completes one instruction's stages before starting the next instruction.

With Pipelining

The processor overlaps instruction stages. While one instruction is being executed, another may be decoded and a further instruction may be fetched.

Conceptual Three-Stage Pipeline

Clock Cycle Stage 1 Stage 2 Stage 3
1 Fetch I1 - -
2 Fetch I2 Decode I1 -
3 Fetch I3 Decode I2 Execute I1
4 Fetch I4 Decode I3 Execute I2

Pipelining can improve instruction throughput, although branches, data dependencies and memory delays can reduce its effectiveness.

LPC2129 connection: The ARM7TDMI-S processor core used in the LPC2129 employs a three-stage pipeline: Fetch, Decode and Execute. The ARM7 architecture is discussed in greater detail in Chapter 5 and Chapter 6.

10. Types of CPU Architectures

10.1 Von Neumann Architecture

In Von Neumann architecture, instructions and data share a common memory space and typically use a common communication path to access memory.

10.2 Harvard Architecture

In Harvard architecture, instruction memory and data memory use separate memory spaces and separate access paths.

Harvard Architecture

Instruction Memory

10.3 Modified Harvard Architecture

Modified Harvard architectures combine aspects of both approaches. They may use separate instruction and data paths internally while providing a unified address space or other shared-memory features.

The distinction between Von Neumann and Harvard architecture concerns memory organization and access paths. It is not simply a distinction between microprocessors and microcontrollers.

11. CPU Architecture in the LPC2129

The LPC2129 uses the ARM7TDMI-S processor core, which is based on a 32-bit ARM architecture.

  • General-purpose register organization.

12. Common Mistakes

  • Confusing the CPU with the complete microcontroller.
  • Assuming the ALU controls the entire processor.
  • Confusing registers with RAM memory.
  • Assuming every instruction requires the same number of clock cycles.
  • Assuming higher clock frequency always means better performance.
  • Assuming pipelining makes every individual instruction execute in one cycle.
  • Confusing Von Neumann and Harvard architecture with microprocessor and microcontroller classifications.

13. Interview Questions and Answers

Q1. What is a CPU?

The CPU is the processing unit that executes instructions and controls system operations.

Q2. What are the major components of a CPU?

The major functional components include the ALU, Control Unit, registers, internal data paths and instruction execution logic.

Q3. What is the function of an ALU?

The ALU performs arithmetic, logical, comparison and related data-processing operations.

Q4. What is the function of the Control Unit?

It decodes instructions and generates control signals to coordinate processor operations.

Q5. What is a register?

A register is a small, high-speed storage location inside the processor.

Q6. What is the Program Counter?

The Program Counter holds the address associated with the next instruction to execute.

Q7. Explain the instruction execution cycle.

It is the process of fetching, decoding and executing instructions, followed by result storage when required.

Q8. What is pipelining?

Pipelining overlaps the stages of multiple instructions to improve processor instruction throughput.

Q9. What is the difference between Von Neumann and Harvard architecture?

Von Neumann architecture uses a shared memory organization for instructions and data, while Harvard architecture uses separate instruction and data memory paths.

Q10. Which pipeline is used in ARM7TDMI-S?

ARM7TDMI-S uses a three-stage pipeline consisting of Fetch, Decode and Execute.

Q11. What is a status register?

A status register stores processor state and condition information, such as arithmetic flags.

Q12. What is clock frequency?

Clock frequency is the number of clock cycles generated per second, measured in Hertz.

14. Multiple Choice Questions (MCQs)

1. Which CPU component performs arithmetic operations?
  1. Control Unit
  2. ALU
  3. Memory Unit
  4. Power Supply

Answer: B. ALU

2. Which component coordinates instruction execution?
  1. ALU
  2. Control Unit
  3. RAM
  4. GPIO

Answer: B. Control Unit

3. Which register holds the next instruction address?
  1. SP
  2. PC
  3. LR
  4. R0

Answer: B. PC

4. Which stage follows instruction fetch?
  1. Decode
  2. Reset
  3. Power-up
  4. Shutdown

Answer: A. Decode

5. How many stages are present in the basic ARM7TDMI-S pipeline?
  1. Two
  2. Three
  3. Five
  4. Seven

Answer: B. Three

6. Which architecture separates instruction and data memory paths?
  1. Von Neumann
  2. Harvard
  3. Serial
  4. Parallel

Answer: B. Harvard

7. What is the clock period at 10 MHz?
  1. 1 second
  2. 1 millisecond
  3. 100 nanoseconds
  4. 10 microseconds

Answer: C. 100 nanoseconds

8. Which register commonly stores a subroutine return address in ARM?
  1. LR
  2. SP
  3. PC only
  4. MAR

Answer: A. LR

9. What is the main benefit of pipelining?
  1. Reduced memory size
  2. Improved instruction throughput
  3. Elimination of all branches

Answer: B. Improved instruction throughput

10. Which component stores temporary operands during CPU execution?

  2. Power supply
  3. Crystal oscillator
  4. External sensor

Answer: A. Registers
