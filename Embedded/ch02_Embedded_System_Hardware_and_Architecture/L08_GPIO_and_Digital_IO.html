1. Introduction to GPIO

GPIO stands for General Purpose Input/Output. GPIO pins are configurable digital pins available on microcontrollers and other digital devices.

These pins allow a microcontroller to communicate with external devices such as switches, LEDs, sensors, relays, displays and other digital circuits.

GPIO: A programmable digital interface that allows a microcontroller to receive input signals or generate output signals.

Examples of GPIO Applications

  • Controlling an LED.
  • Reading a push button.
  • Monitoring a digital sensor output.
  • Controlling a relay through a suitable driver.
  • Generating digital control signals.
  • Interfacing with switches and keypads.

2. GPIO Input and Output

A GPIO pin can generally be configured as either a digital input or a digital output, subject to the microcontroller's pin multiplexing and electrical specifications.

2.1 Digital Input

In digital input mode, the microcontroller reads the logic level applied to the pin.

  • Logic LOW represents binary 0.
  • Logic HIGH represents binary 1.

A push button or digital sensor can provide an input signal to the microcontroller.

2.2 Digital Output

In digital output mode, the microcontroller drives the GPIO pin to a logic HIGH or logic LOW state.

  • Logic HIGH produces the specified output-high voltage.
  • Logic LOW produces the specified output-low voltage.

A GPIO output can control an LED through an appropriate current-limiting resistor.

3. Digital Logic Levels

Digital circuits represent information using two logical states: LOW and HIGH.

Logic State Binary Value Meaning
LOW 0 Logic zero
HIGH 1 Logic one
The actual voltage representing HIGH or LOW depends on the microcontroller's electrical specifications. Do not assume that every GPIO pin uses 5 V logic.

Input Voltage Considerations

  • VIH: Minimum voltage recognized as logic HIGH.
  • VIL: Maximum voltage recognized as logic LOW.
  • VOH: Minimum guaranteed output voltage for HIGH.
  • VOL: Maximum guaranteed output voltage for LOW.

These values are important when connecting devices that operate at different logic-voltage levels.

4. GPIO Pin Configuration

A microcontroller GPIO pin must be configured correctly before it is used.

Common Configuration Steps

  1. Select GPIO function if the pin supports alternate functions.
  2. Configure the pin as input or output.
  3. Configure pull-up or pull-down behavior if supported and required.
  4. Read the input state or write the output state.

5. GPIO Direction Control

Direction control determines whether a GPIO pin receives an external signal or generates an output.

Input Configuration

An input pin is configured so that the processor can sample the external logic level.

Output Configuration

An output pin is configured so that the processor can drive the pin HIGH or LOW.

Configuration Direction Typical Application
Input External device to MCU Push button, digital sensor
Output MCU to external device LED control, driver control

6. Pull-Up and Pull-Down Resistors

Digital input pins should not be left floating when a defined logic state is required. A floating input can pick up noise and produce unpredictable readings.

6.1 Pull-Up Resistor

A pull-up resistor connects an input signal to the positive supply through a resistor. It keeps the input at a defined HIGH level when no external device pulls it LOW.

Pull-Up Resistor Concept

When the switch is open, the input is pulled HIGH. When the switch closes to ground, the input becomes LOW.

6.2 Pull-Down Resistor

A pull-down resistor connects the input signal to ground through a resistor. It keeps the input at a defined LOW level when no external device drives it HIGH.

Pull-Down Resistor Concept

When the switch is open, the input is pulled LOW. When the switch closes to VCC, the input becomes HIGH.

Pull-Up vs Pull-Down

Feature Pull-Up Pull-Down
Connection Input to VCC through resistor Input to GND through resistor
Default state HIGH LOW
Switch action Can pull input LOW Can drive input HIGH
Purpose Prevent floating input Prevent floating input
Pull-up and pull-down arrangements must be designed for the input voltage limits and the available internal or external resistor options.

7. GPIO Pin Multiplexing

Many microcontroller pins support multiple functions. This feature is called pin multiplexing.

A single physical pin may support GPIO as well as alternate peripheral functions such as UART, SPI, I2C, PWM or external interrupt signals.

Pin Multiplexing Concept

Physical MCU Pin
↓
GPIO
UART
PWM
Other Function

Configuration logic selects the required function.

Why Is Pin Multiplexing Important?

  • Reduces the number of physical pins required.
  • Allows one pin to serve different functions in different designs.
  • Requires correct pin-function configuration.
  • Prevents unintended conflicts between peripheral functions.
A pin configured for UART or another alternate function may not operate as an ordinary GPIO pin. The pin-selection register must be configured according to the device documentation.

8. GPIO Architecture in LPC2129

The LPC2129 provides GPIO functionality through its port pins. GPIO access is controlled through dedicated registers.

LPC2129 GPIO programming requires attention to pin-function selection and port direction.

Important LPC2129 GPIO Registers

Register Function
PINSEL0 Selects functions for supported pins.
PINSEL1 Selects functions for supported pins.
IODIR Configures pin direction.
IOPIN Reads the pin state and reflects port pin levels.
IOSET Sets selected output bits HIGH.
IOCLR Clears selected output bits LOW.
LPC2129 uses separate GPIO register banks for Port 0 and Port 1. The applicable register and pin number must be selected according to the target pin.

GPIO Programming Sequence

  1. Identify the required physical pin.
  2. Check its alternate-function mapping.
  3. Configure PINSEL0 or PINSEL1 for GPIO where applicable.
  4. Set the corresponding IODIR bit.
  5. Use IOPIN, IOSET or IOCLR as appropriate.

9. GPIO Direction Register (IODIR)

The IODIR register controls whether each GPIO pin is configured as an input or output.

In LPC2129 GPIO programming:

  • IODIR bit = 0: Input.
  • IODIR bit = 1: Output.

Example: Configure P0.5 as Output

#include <LPC21xx.h>

int main(void)
{
    IODIR0 |= (1U << 5);

    while (1)
    {
        // P0.5 is configured as output
    }
}

Explanation:

  • IODIR0 is the Port 0 direction register.
  • 1U << 5 creates a mask for bit 5.
  • The OR operation sets bit 5 without changing other direction bits.

Example: Configure P0.8 as Input

#include <LPC21xx.h>

int main(void)
{
    IODIR0 &= ~(1U << 8);

    while (1)
    {
        // P0.8 is configured as input
    }
}

10. GPIO Input Register (IOPIN)

IOPIN is used to read the current logic levels present on the GPIO port pins.

Example: Read P0.8

#include <LPC21xx.h>

int main(void)
{
    unsigned int input_state;

    IODIR0 &= ~(1U << 8);

    while (1)
    {
        input_state = (IOPIN0 >> 8) & 1U;

        if (input_state == 1U)
        {
            // Input is HIGH
        }
        else
        {
            // Input is LOW
        }
    }
}

Explanation

  1. Configure P0.8 as an input.
  2. Read the Port 0 input register.
  3. Shift bit 8 to bit position 0.
  4. Mask the result with 1 to extract the pin state.
The input state depends on the external circuit, pin configuration and electrical conditions. A floating input may produce an unstable reading.

11. GPIO Output Registers (IOSET and IOCLR)

11.1 IOSET

IOSET sets selected GPIO output bits to logic HIGH. 

IOSET0 = (1U << 5);

This sets Port 0 bit 5 HIGH without requiring a read-modify-write operation on the output port.

11.2 IOCLR

IOCLR clears selected GPIO output bits to logic LOW. 

IOCLR0 = (1U << 5);

This clears Port 0 bit 5 LOW.

Comparison

Register Operation
IOSET Sets selected output bits HIGH.
IOCLR Sets selected output bits LOW.
IOPIN Reads the current pin levels.
IODIR Controls input/output direction.
IOSET and IOCLR are used to modify output states. They do not replace the need to configure the corresponding pins as GPIO outputs.

12.3 Relay Interfacing

A relay can be controlled through a suitable transistor or driver circuit. A GPIO pin should not directly drive a relay coil unless the device specifications explicitly permit it.

Inductive loads require suitable protection, such as a flyback diode for a DC relay coil, where appropriate to the driver circuit.

13. GPIO Electrical Characteristics

GPIO pins have electrical limits that must be considered during hardware design.

Important Parameters

  • Maximum input voltage.
  • Minimum and maximum input logic thresholds.
  • Output HIGH and LOW voltage levels.
  • Maximum source and sink current.
  • Input leakage current.
  • Pin capacitance.
  • ESD protection ratings.

Source and Sink Current

Source current flows from the GPIO output pin toward an external load.

Sink current flows from an external supply through the load into a GPIO pin that is driving LOW.

Always follow the LPC2129 datasheet's per-pin and total-port current limits. Do not select an LED resistor or external load based only on the supply voltage.

14. GPIO vs Dedicated Peripheral Pins

GPIO Function Peripheral Function
General digital input/output Specialized hardware operation
Controlled by GPIO registers Controlled by peripheral registers
Used for switches and LEDs Used for UART, SPI, I2C and PWM
Usually controlled by software May use dedicated hardware logic

A pin can support both GPIO and a peripheral function, but the selected pin function determines which hardware block controls its behavior.

15. Common GPIO Programming Mistakes

  • Forgetting to configure the pin direction.
  • Using the wrong port number or bit position.
  • Ignoring pin multiplexing.
  • Leaving an input pin floating.
  • Connecting an LED without a suitable current-limiting resistor.
  • Exceeding GPIO current or voltage limits.
  • Using IOSET or IOCLR before configuring output direction.
  • Assuming a simulator reproduces actual electrical behavior.
  • Using a peripheral pin as GPIO without checking PINSEL configuration.

16. Interview Questions and Answers

Q1. What is GPIO?

GPIO is a configurable digital interface used to communicate with external hardware.

Q2. What is the difference between digital input and output?

Input reads an external logic state, whereas output drives a logic state to an external circuit.

Q3. What is a floating input?

An input without a defined logic level. It may respond unpredictably to noise.

Q4. Why are pull-up and pull-down resistors used?

They establish a defined default logic state for an input pin.

Q5. What is pin multiplexing?

It allows a physical pin to perform different functions selected through configuration.

Q6. What is IODIR in LPC2129?

It is the GPIO direction register. A bit value of 1 selects output and 0 selects input.

Q7. What is IOPIN?

It is used to read the current logic levels of GPIO port pins.

Q8. What is the purpose of IOSET?

It sets selected GPIO output bits HIGH.

Q9. What is the purpose of IOCLR?

It clears selected GPIO output bits LOW.

Q10. Can a GPIO pin directly drive a relay?

Generally, a GPIO pin should control a suitable transistor or driver circuit rather than directly supplying relay-coil current.

Q11. What is the difference between source and sink current?

Source current flows out of the GPIO pin; sink current flows into the GPIO pin.

Q12. Why is PINSEL important in LPC2129?

It selects the required function for pins that support alternate peripheral functions.
