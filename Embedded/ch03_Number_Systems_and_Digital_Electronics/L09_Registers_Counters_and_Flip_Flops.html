Lesson 09: Registers, Counters and Flip-Flops

Study the fundamental storage and counting elements of digital electronics, including flip-flop types, register organization, shift registers, counter architectures and their applications in microcontrollers and embedded systems.

1. Introduction

Registers, counters and flip-flops are important building blocks of sequential digital circuits. They store binary information and help digital systems process data in a controlled sequence.

  • Flip-flop: Stores one bit of binary information.
  • Register: Stores a group of binary bits.
  • Counter: Changes its stored state according to clock pulses or other triggering events.

2. Flip-Flop Fundamentals

A flip-flop is a bistable sequential circuit capable of storing one binary bit. It has two stable output states: 0 and 1.

Common outputs are:

  • Q – Normal output.
  • Q̅ – Complementary output.

In a conventional edge-triggered flip-flop, the stored state changes in response to a specified clock edge.

Important characteristics

  • Stores one bit of information.
  • Has two stable states.
  • Can be edge-triggered.
  • May include asynchronous set and reset inputs.
  • Used to construct registers and counters.

3. SR Flip-Flop

SR stands for Set-Reset. An SR flip-flop has two control inputs: S and R.

Truth Table

For a common active-high clocked SR implementation, the following table describes the operation at the active clock edge.

SRNext QOperation
00QHold
010Reset
101Set
11InvalidForbidden condition
The active-high SR table has a forbidden S=R=1 condition. NAND-based active-low implementations use a different input convention.

Applications

  • Basic storage circuits.
  • Control logic.
  • Set-reset control systems.

4. JK Flip-Flop

The JK flip-flop is a modified SR flip-flop. It removes the forbidden input combination by introducing a toggle operation.

Truth Table

JKNext QOperation
00QHold
010Reset
101Set
11Q̅Toggle

Characteristic Equation

Q(next) = J·Q̅ + K̅·Q

Applications

  • Binary counters.
  • Frequency division.
  • Sequential control circuits.

5. D Flip-Flop

D stands for Data or Delay. A D flip-flop stores the value present at its data input when the active clock edge occurs.

Truth Table

DNext QOperation
00Store 0
11Store 1

Characteristic Equation

Q(next) = D

Applications

  • Data registers.
  • Pipeline storage.
  • State machines.
  • Digital synchronization circuits.

6. T Flip-Flop

T stands for Toggle. A T flip-flop changes its output state when T is 1 at the active clock edge.

Truth Table

TCurrent QNext QOperation
000Hold
011Hold
101Toggle
110Toggle

Characteristic Equation

Q(next) = T XOR Q

Applications

  • Binary counters.
  • Frequency division.
  • Toggle circuits.

8. Registers

A register is a group of flip-flops connected together to store a multi-bit binary value.

Each flip-flop stores one bit. Therefore, an n-bit register generally uses n storage flip-flops.

10. Shift Registers

A shift register is a sequential circuit that moves stored binary data from one flip-flop stage to another in response to clock pulses.

Right Shift Example

Assume a 4-bit register initially contains 1011. With a serial input of 0, a right shift can produce the following sequence, assuming the new bit enters the most significant position.

StageRegister Contents
Initial1011
After 1 shift0101
After 2 shifts0010
After 3 shifts0001

Types of Shift Registers

  • Right-shift register.
  • Left-shift register.
  • Bidirectional shift register.
  • Universal shift register.

Applications

  • Serial communication.
  • Data conversion.
  • Digital delay circuits.
  • Temporary data storage.
  • Hardware data manipulation.

11. Universal Shift Register

A universal shift register supports multiple operations through control inputs.

Depending on its design, it can:

  • Hold the current data.
  • Shift data left.
  • Shift data right.
  • Load data in parallel.

It is called universal because it combines several register operations in one circuit.

12. Counters

A counter is a sequential circuit that advances through a defined sequence of binary states in response to clock pulses or triggering events.

Characteristics

  • Contains flip-flops.
  • Stores the current count.
  • Changes state according to a defined sequence.
  • Can count upward or downward.
  • Can be synchronous or asynchronous.

Maximum Number of States

Number of states = 2^n

where n = number of flip-flops

For a 4-bit binary counter:

Number of states = 2^4 = 16

Count range = 0 to 15

13. Asynchronous (Ripple) Counter

An asynchronous counter is a counter in which the external clock is applied to the first flip-flop. The output of one stage triggers the next stage.

It is also called a ripple counter because state transitions propagate through successive stages.

Characteristics

  • Only the first stage receives the external clock directly.
  • Each subsequent stage is triggered by the preceding stage.
  • Propagation delays accumulate across stages.
  • Its design is relatively simple.

Applications

  • Simple event counters.
  • Frequency division.
  • Low-speed counting circuits.
Ripple counters may experience temporary intermediate states during transitions because the flip-flops do not change simultaneously.

14. Synchronous Counter

A synchronous counter applies the same clock signal to all flip-flops. The required next-state logic determines which bits change at each clock edge.

Characteristics

  • All flip-flops share a common clock.
  • State transitions occur together at the active clock edge.
  • Suitable for higher-speed counter designs than comparable ripple structures.
  • Requires additional combinational logic for state control.

Applications

  • Digital timers.
  • High-speed event counters.
  • Processor control circuits.
  • Digital measurement systems.

17. Up/Down Counter

An up/down counter can count in either direction. A direction-control input determines whether the count increases or decreases.

Direction ControlOperation
0Count down
1Count up

The exact direction-control polarity depends on the counter design.

Applications

  • Position control systems.
  • Digital measurement equipment.
  • Production counters.
  • Elevator control systems.

18. Mod-N Counter

A Mod-N counter has N distinct states before its sequence repeats.

For example, a Mod-10 counter has ten states, usually representing decimal values 0 through 9.

Number of Flip-Flops

The minimum number of flip-flops required for a Mod-N counter is:

n = ceiling(log2 N)

For a Mod-10 counter:

2^3 = 8  (not sufficient)
2^4 = 16 (sufficient)

Required flip-flops = 4

Applications

  • Digital clocks.
  • Frequency division.
  • Decimal counting systems.
  • Digital measurement equipment.

19. Ring Counter

A ring counter is a shift-register-based counter in which the output of the last flip-flop is fed back to the input of the first flip-flop.

A common four-bit ring counter sequence, starting with 0001, is:

Clock PulseState
00001
10010
20100
31000
40001

A standard n-stage ring counter uses n flip-flops and has n valid states in its normal one-hot sequence.

20. Johnson Counter

A Johnson counter is a shift-register counter in which the complemented output of the last flip-flop is fed back to the first flip-flop.

An n-stage Johnson counter can produce up to 2n distinct states in its normal sequence.

21. Frequency Division Using Flip-Flops

A toggle flip-flop can divide the input clock frequency by two when configured to toggle on every active clock edge.

Output frequency = Input frequency / 2

For a chain of n ideal divide-by-two stages:

Output frequency = Input frequency / 2^n

Example: A 1 MHz clock passing through three divide-by-two stages produces:

1 MHz / 2^3 = 125 kHz
Actual hardware timing also depends on flip-flop propagation delay, clock limits and circuit loading.

22. Timing Parameters

1. Setup Time

The minimum time data must remain stable before the active clock edge.

2. Hold Time

The minimum time data must remain stable after the active clock edge.

3. Propagation Delay

The time taken for a change at the input to affect the output.

4. Clock-to-Q Delay

The delay between the active clock edge and the corresponding output transition.

5. Clock Period

The time required for one complete clock cycle.

Clock frequency = 1 / Clock period

23. Registers and Counters in Microcontrollers

Microcontrollers contain several types of registers and counter-based hardware peripherals.

CPU Registers

Processor registers hold operands, addresses, instruction-related information and temporary data.

Peripheral Registers

Memory-mapped peripheral registers configure and control hardware modules such as GPIO, UART, timers and ADCs.

Timer/Counter Hardware

Timer/counter peripherals count internal clock events or selected external events. They are used for time measurement, periodic interrupts and event counting.

In the LPC2129, timer/counter peripherals use registers such as T0TC, T0PR, T0MR0 and T0IR. These are microcontroller peripheral registers, not external flip-flop circuits that need to be manually connected.

Embedded Applications

  • Generating periodic interrupts.
  • Measuring elapsed time.
  • Counting external events.
  • Generating PWM signals.
  • Managing serial communication.

24. Common Mistakes

  • Confusing a flip-flop with a multi-bit register.
  • Assuming all flip-flops are level-sensitive.
  • Confusing the JK toggle condition with the SR forbidden condition.
  • Mixing up serial and parallel register operations.
  • Assuming a ripple counter changes all bits simultaneously.
  • Using 2n instead of 2n for the state count of an n-bit binary counter.
  • Forgetting that a Mod-N counter requires at least ceiling(log2 N) flip-flops.
  • Confusing a ring counter with a Johnson counter.
  • Ignoring setup time, hold time and propagation delay.

25. Interview Questions and Answers

Q1. What is a flip-flop?

A bistable sequential circuit that stores one bit of binary information.

Q2. What is a register?

A group of flip-flops used to store multiple bits.

Q3. What is the difference between a latch and a flip-flop?

A latch is level-sensitive, whereas a conventional flip-flop is edge-triggered.

Q4. Which flip-flop is commonly used in data registers?

The D flip-flop.

Q5. What is the toggle condition of a JK flip-flop?

J=1 and K=1.

Q6. What is a shift register?

A group of storage elements that shifts binary data between stages.

Q7. What is a synchronous counter?

A counter in which all flip-flops receive a common clock signal.

Q8. What is an asynchronous counter?

A counter in which subsequent stages are triggered by preceding stages.

Q9. How many states can a 5-bit binary counter represent?

25 = 32 states.

Q10. What is a Mod-10 counter?

A counter that has ten distinct states before repeating.

Q11. What is a ring counter?

A shift-register counter in which the last stage output is fed back to the first stage input.

Q12. What is a Johnson counter?

A shift-register counter in which the complemented last-stage output is fed back to the first stage.

Q13. What is frequency division?

The process of producing an output signal with a lower frequency than the input signal.

Q14. What is setup time?

The minimum time data must be stable before the active clock edge.

Q15. What is hold time?

The minimum time data must remain stable after the active clock edge.

28. Lesson Summary

  • A flip-flop stores one bit of information.
  • SR, JK, D and T are common flip-flop types.
  • A register combines flip-flops to store multiple bits.
  • Shift registers transfer data between storage stages.
  • Synchronous counters use a common clock for all stages.
  • Asynchronous counters use ripple triggering between stages.
  • Up counters increase their count; down counters decrease it.
  • Mod-N counters repeat after N states.
  • Ring and Johnson counters generate specific state sequences.
  • Flip-flops and counters are important components of digital and embedded hardware.
