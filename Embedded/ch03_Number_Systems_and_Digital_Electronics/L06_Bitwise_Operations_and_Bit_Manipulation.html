Lesson 06: Bitwise Operations and Bit Manipulation

Learn bitwise operators, binary masks, bit setting, clearing, toggling, testing and register-level operations used in embedded systems and microcontrollers.

1. Introduction to Bitwise Operations

A bitwise operation performs a logical or shifting operation directly on the individual bits of an integer value.

Embedded systems frequently use bitwise operations to control hardware registers, configure GPIO pins, enable peripherals and manipulate status flags.

The main bitwise operators in C are:

  • Bitwise AND (&)
  • Bitwise OR (|)
  • Bitwise XOR (^)
  • Bitwise NOT (~)
  • Left shift (<<)
  • Right shift (>>)

2. Bitwise AND Operator (&)

The bitwise AND operator compares corresponding bits of two operands.

The output bit is 1 only when both input bits are 1.

Truth Table

ABA & B
000
010
100
111

Example

    1100
AND 1010
--------
    1000

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t a = 12;
    uint8_t b = 10;

    uint8_t result = a & b;

    while (1)
    {
        /* Inspect result in debugger */
    }
}

Expected result: 12 AND 10 = 8.

Binary result: 1100 AND 1010 = 1000.

Applications

  • Testing whether a particular bit is set.
  • Extracting selected bits from a register.
  • Creating masked values.

3. Bitwise OR Operator (|)

The bitwise OR operator compares corresponding bits of two operands.

The output bit is 1 when at least one input bit is 1.

    }

Binary result: 1100 OR 1010 = 1110.

Applications

  • Combining bit flags.
  • Enabling multiple configuration options.

5. Bitwise NOT Operator (~)

The bitwise NOT operator inverts every bit of its operand.

  • 0 becomes 1.
  • 1 becomes 0.

Example: 8-bit inversion

Original:  00001111
NOT:       11110000

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t a = 0x0F;
    uint8_t result = (uint8_t)(~a);

    while (1)
    {
        /* Inspect result in debugger */
    }
}

Expected result:

a      = 00001111
result = 11110000
Hex    = 0xF0
In C, small integer types such as uint8_t are usually promoted to int before the ~ operation. Casting the result back to uint8_t keeps only the lower eight bits.

6. Bitwise Left Shift (<<)

The left shift operator moves the bits of an operand toward the most significant bit by a specified number of positions.

For unsigned values, zero bits are introduced from the right.

Example: Shift 00000101 left by one position.

Original:    00000101
Left shift:  00001010

Decimal: 5 becomes 10.

Example: Shift by two positions.

Original:     00000101
Left shift 2: 00010100

Decimal: 5 becomes 20.

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t value = 5;
    uint8_t result = (uint8_t)(value << 2);

    while (1)
    {
        /* Inspect result */
    }
}

Expected result: 20.

Left shifting a value is not universally interchangeable with multiplication. Use unsigned operands, ensure the shift count is valid and ensure the mathematical result fits the intended type.

7. Bitwise Right Shift (>>)

The right shift operator moves bits toward the least significant bit by a specified number of positions.

For unsigned operands, zeros are introduced from the left.

Example: Shift 00010100 right by two positions.

Original:     00010100
Right shift:  00000101

Decimal: 20 becomes 5.

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t value = 20;
    uint8_t result = (uint8_t)(value >> 2);

    while (1)
    {
        /* Inspect result */
    }
}

Expected result: 5.

For unsigned values, right shift introduces zero bits. For negative signed values, right shift behavior is implementation-defined in C, so unsigned types are preferable for bit manipulation.

8. Bit Masks

A bit mask is a binary pattern used to select, set, clear or test particular bits in a value or hardware register.

Bit masks are essential in embedded C programming.

Example: Create a mask for bit 3

Mask = 1U << 3

Binary mask = 00001000

Bit positions are counted from zero, starting at the least significant bit.

9. Setting a Bit

Setting a bit means changing its value to 1 without changing the other bits.

Formula

register_value = register_value | (1U << bit_position);

Alternatively, use the compound assignment operator:

register_value |= (1U << bit_position);

Example: Set bit 2

Original:  00001001
Mask:      00000100
           --------
OR result: 00001101

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t reg = 0x09;

    reg |= (uint8_t)(1U << 2);

    while (1)
    {
        /* Inspect reg */
    }
}

Expected result: reg = 0x0D.

10. Clearing a Bit

Clearing a bit means changing its value to 0 without changing the other bits.

Formula

register_value =
    register_value & ~(1U << bit_position);

Alternatively:

register_value &= ~(1U << bit_position);

Example: Clear bit 2

Original:  00001101
Mask:      00000100
Inverted:  11111011
           --------
AND result:00001001

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t reg = 0x0D;

    reg &= (uint8_t)~(1U << 2);

    while (1)
    {
        /* Inspect reg */
    }
}

Expected result: reg = 0x09.

11. Toggling a Bit

Toggling means changing a bit from 0 to 1 or from 1 to 0.

Formula

register_value ^= (1U << bit_position);

Example: Toggle bit 1

Original:  00001001
Mask:      00000010
           --------
XOR result:00001011

If bit 1 was already 1, toggling it would change it to 0.

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t reg = 0x09;

    reg ^= (uint8_t)(1U << 1);

    while (1)
    {
        /* Inspect reg */
    }
}

Expected result: reg = 0x0B.

12. Testing a Bit

Testing a bit means checking whether a particular bit is set or cleared.

Formula

if (register_value & (1U << bit_position))
{
    /* Bit is set */
}
else
{
    /* Bit is clear */
}

Example: Test bit 3

Register: 00001000
Mask:     00001000
          --------
AND:      00001000

The result is non-zero, so bit 3 is set.

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t reg = 0x08;
    uint8_t bit_status;

    bit_status = (reg & (1U << 3)) ? 1U : 0U;

    while (1)
    {
        /* Inspect bit_status */
    }
}

Expected result: bit_status = 1.

14. Extracting a Bit Field

A bit field is a group of adjacent bits within a register or integer value.

To extract a field, shift it to the right and apply a mask.

Example: Extract bits 4 to 6

Register: 01110000

Shift right by 4:
00000111

Apply mask 00000111:
00000111

Embedded C Example

#include <stdint.h>

int main(void)
{
    uint8_t reg = 0x70;
    uint8_t field;

    field = (uint8_t)((reg >> 4) & 0x07U);

    while (1)
    {
        /* Inspect field */
    }
}

Expected result: field = 7.

15. Bit Manipulation in LPC2129

The LPC2129 microcontroller uses memory-mapped registers to control its peripherals. Bitwise operations are commonly used to configure these registers.

For example, GPIO direction can be configured through the IODIR register.

Conceptual example: Configure GPIO direction

#include <LPC21xx.h>

int main(void)
{
    /* Configure P0.5 as GPIO */
    PINSEL0 &= ~(3U << 10);

    /* Configure P0.5 as output */
    IODIR0 |= (1U << 5);

    while (1)
    {
        /* Inspect GPIO registers in debugger */
    }
}

Register-level effect:

  • The two PINSEL0 bits corresponding to P0.5 are cleared to select GPIO function.
  • Bit 5 of IODIR0 is set to configure P0.5 as an output.
This example demonstrates register configuration. In the Keil simulator, inspect the register values. A register change alone does not demonstrate physical LED operation.

16. Important Precautions in Register Bit Manipulation

  • Use unsigned constants such as 1U when constructing masks.
  • Make sure the shift count is smaller than the width of the promoted left operand.
  • Use the correct register width and bit positions.
  • Check the microcontroller datasheet before modifying hardware registers.
  • Some hardware registers contain write-one-to-clear or other special bits; ordinary read-modify-write operations may be unsafe for them.
  • Use appropriate critical sections or atomic hardware operations when an interrupt can modify the same register.
  • Do not assume every register supports both reading and writing.

17. Common Mistakes

  • Confusing logical AND (&&) with bitwise AND (&).
  • Confusing logical OR (||) with bitwise OR (|).
  • Using OR when clearing a bit instead of AND with an inverted mask.
  • Using AND when setting a bit instead of OR.
  • Using XOR without realizing that it toggles an already-set bit to zero.
  • Counting bit positions from 1 instead of 0.
  • Using signed values for bit manipulation without considering promotions and shifting rules.
  • Performing unsafe read-modify-write operations on special hardware registers.

18. Interview Questions and Answers

Q1. What are bitwise operators?

Operators that perform operations on individual bits of integer operands.

Q2. What is the difference between bitwise AND and logical AND?

Bitwise AND operates on individual bits, while logical AND evaluates conditions and produces a logical result.

Q3. How do you set bit 5?

reg |= (1U << 5);

Q4. How do you clear bit 3?

reg &= ~(1U << 3);

Q5. How do you toggle bit 2?

reg ^= (1U << 2);

Q6. How do you test bit 7?

if (reg & (1U << 7))
{
    /* Bit is set */
}

Q7. What is a bit mask?

A binary pattern used to select or modify specific bits.

Q8. What does left shifting by one generally do to an unsigned value?

It moves the bits one position to the left, inserting zero at the right. If the mathematical result fits, it corresponds to multiplication by 2.

Q9. Why are bitwise operators important in embedded systems?

They provide efficient control of hardware registers, peripheral configuration and status flags.

Q10. What is the difference between setting and toggling a bit?

Setting always makes the selected bit 1. Toggling reverses its current value.

21. Lesson Summary

  • Bitwise operators work directly on binary bits.
  • AND is used for masking and testing bits.
  • OR is used for setting bits.
  • XOR is used for toggling bits.
  • NOT inverts all bits.
  • Left and right shifts move bits between positions.
  • Bit masks select specific bits or fields.
  • Setting, clearing, toggling and testing are fundamental embedded programming techniques.
  • Hardware register manipulation requires knowledge of the microcontroller datasheet and register behavior.
