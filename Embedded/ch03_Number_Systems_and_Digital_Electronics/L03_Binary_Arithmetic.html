Lesson 03: Binary Arithmetic

Understand binary addition, subtraction, multiplication, division, carry, borrow and arithmetic operations used in digital electronics and embedded systems.

1. Introduction to Binary Arithmetic

Binary arithmetic is the process of performing mathematical operations using the binary number system, which has only two digits: 0 and 1.

Digital computers and microcontrollers perform arithmetic operations using binary data inside their Arithmetic Logic Unit (ALU).

The main binary arithmetic operations are:

  • Binary addition
  • Binary subtraction
  • Binary multiplication
  • Binary division
Binary Arithmetic Processing

Binary operands → Arithmetic Logic Unit (ALU) → Binary result

2. Basic Binary Addition Rules

Binary addition follows four basic rules.

OperationResult
0 + 00
0 + 11
1 + 01
1 + 110 (sum 0, carry 1)

When adding two 1s, the result is binary 10. The 0 is written in the current column, and the carry 1 is added to the next column.

Example 1: Add (101)2 and (011)2.

     101
   + 011
   -----
    1000

Verification: 5 + 3 = 8.

Example 2: Add (1101)2 and (1011)2.

      1101
    + 1011
    ------
     11000

Verification: 13 + 11 = 24.

3. Binary Addition with Carry

A carry occurs when the sum of the bits in a column is greater than 1.

Example: Add 1111 and 0001.

       1111
     + 0001
     ------
      10000

The addition produces a fifth bit. This is a carry out of the most significant bit when the operands are treated as four-bit unsigned numbers.

A carry out is not automatically the same as signed overflow. Carry and overflow are different status conditions.

4. Binary Subtraction Rules

Binary subtraction uses the following rules.

OperationResult
0 − 00
1 − 01
1 − 10
0 − 11, with a borrow

When subtracting 1 from 0, borrow 1 from the next higher bit. In binary, the borrowed value represents 2 in the current column.

Example 1: Subtract 0011 from 1000.

      1000
    - 0011
    ------
      0101

Verification: 8 − 3 = 5.

Example 2: Subtract 0101 from 1100.

      1100
    - 0101
    ------
      0111

Verification: 12 − 5 = 7.

5. Borrow in Binary Subtraction

A borrow is required when the bit being subtracted is greater than the bit from which it is subtracted.

Example: 10000 − 00001

      10000
    - 00001
    -------
      01111

Verification: 16 − 1 = 15.

The borrow propagates through the zero bits until a 1 is found.

Borrow is a concept in subtraction. In processor status registers, subtraction may instead be represented using carry and no-borrow conventions, depending on the processor architecture.

6. Binary Multiplication

Binary multiplication follows four basic rules.

OperationResult
0 × 00
0 × 10
1 × 00
1 × 11

Binary multiplication works similarly to decimal long multiplication. Each partial product is shifted according to the position of the multiplier bit.

Example: Multiply (101)2 by (11)2.

        101
      ×  11
      -----
        101
       1010
      -----
       1111

Verification: 5 × 3 = 15.

Another Example: Multiply (110)2 by (101)2.

        110
      × 101
      -----
        110
       000
      11000
      -----
      11110

Verification: 6 × 5 = 30.

7. Binary Division

Binary division follows the same long-division principle as decimal division.

The basic rules for dividing individual bits are:

OperationResult
0 ÷ 10
1 ÷ 11
0 ÷ 0Undefined
1 ÷ 0Undefined

Division by zero is undefined.

Example 1: Divide (1100)2 by (10)2.

1100 ÷ 10 = 110

Verification: 12 ÷ 2 = 6.

Example 2: Divide (1111)2 by (11)2.

1111 ÷ 11 = 101

Verification: 15 ÷ 3 = 5.

9. Fixed-Width Binary Arithmetic

Digital processors generally operate on fixed-width data such as 8-bit, 16-bit or 32-bit values.

For an n-bit unsigned number, the representable range is:

0 to (2n − 1)

WidthUnsigned range
4-bit0 to 15
8-bit0 to 255
16-bit0 to 65,535
32-bit0 to 4,294,967,295

Example: Four-bit addition

    1111   (15)
  + 0001   (1)
  ------
   10000   (16)

In a four-bit destination, only the lower four bits are retained:

Result = 0000
Carry out = 1

The mathematical result is 16, but it cannot be represented as a four-bit unsigned value.

10. Carry Flag and Overflow Flag

Processors maintain status flags that provide information about arithmetic results.

Carry Flag (C)

The carry flag indicates a carry out from the most significant bit in an addition operation. Its interpretation in subtraction depends on the processor's instruction-set convention.

Overflow Flag (V)

The signed overflow flag indicates that a signed arithmetic result is outside the range representable by the chosen bit width.

Example: Four-bit signed addition

Using four-bit two's complement representation:

  0111  (+7)
+ 0011  (+3)
------
  1010

The mathematical result is +10, but a four-bit signed number can represent only −8 to +7.

The resulting bit pattern 1010 represents −6 in four-bit two's complement. Signed overflow has occurred.

A carry flag and an overflow flag answer different questions. Carry concerns unsigned arithmetic; overflow concerns signed arithmetic.

12. Binary Arithmetic in Embedded Systems

Binary arithmetic is used throughout embedded software and microcontroller hardware.

  • Adding and subtracting sensor values.
  • Calculating timer intervals and counters.
  • Updating memory addresses and pointers.
  • Computing PWM periods and duty-cycle values.
  • Processing ADC conversion results.
  • Performing checksums and data calculations.
  • Managing counters, indexes and communication data.

Example: ADC Value Calculation

An unsigned 10-bit ADC produces values from 0 to 1023.

If the digital result is 512, its binary representation is:

512 decimal = 1000000000 binary

For a 10-bit ADC, the output code uses ten bits.

13. Common Mistakes

  • Forgetting to include the carry from the previous column.
  • Incorrectly borrowing across multiple zero bits.
  • Misaligning partial products during multiplication.
  • Reading the quotient or remainder incorrectly during division.
  • Ignoring the fixed width of a processor register.
  • Confusing carry with signed overflow.
  • Assuming every processor implements multiplication and division in the same way.
  • Failing to verify the binary answer using decimal arithmetic.

14. Interview Questions and Answers

Q1. What is binary arithmetic?

It is the process of performing mathematical operations using binary digits 0 and 1.

Q2. What is the result of 1 + 1 in binary?

10, where the sum bit is 0 and the carry bit is 1.

Q3. What is a carry?

A carry is generated when a binary addition column produces a value that exceeds one bit.

Q4. What is a borrow?

A borrow occurs when the current bit being subtracted is smaller than the corresponding subtrahend bit.

Q5. What is the result of 101 × 11?

1111 in binary, which is 15 in decimal.

Q6. What is the result of 1100 ÷ 10?

110 in binary, which is 6 in decimal.

Q7. What is the range of an 8-bit unsigned number?

0 to 255.

Q8. What is an ALU?

An Arithmetic Logic Unit performs arithmetic and logical operations inside a processor.

Q9. What is the difference between carry and overflow?

Carry indicates an unsigned carry out, whereas overflow indicates that a signed result is outside its representable range.

Q10. Why is binary arithmetic important in microcontrollers?

It is used for calculations, register operations, counters, timer configuration and processing digital data.

17. Practical Embedded Systems Connection

In an embedded C program, arithmetic operations are performed on integer values represented in binary.

Example: Adding Two Integer Values

#include <stdint.h>

int main(void)
{
    uint8_t a = 10;
    uint8_t b = 20;

    uint16_t result = (uint16_t)a + b;

    while (1)
    {
        /* Inspect result in the debugger */
    }
}

Expected result:

a      = 10
b      = 20
result = 30

The variables contain integer values. The processor performs the required binary arithmetic internally.

In Keil uVision simulator, inspect the variables in the debugger. This example demonstrates software arithmetic; it does not require physical LPC2129 hardware.

18. Lesson Summary

  • Binary arithmetic uses only 0 and 1.
  • Binary addition may generate a carry.
  • Binary subtraction may require a borrow.
  • Binary multiplication uses shifted partial products.
  • Binary division follows the long-division method.
  • Processors perform arithmetic using their ALU and related execution hardware.
  • Fixed-width arithmetic has a limited representable range.
  • Carry and signed overflow are different conditions.
  • Binary arithmetic is fundamental to embedded programming and digital hardware.
