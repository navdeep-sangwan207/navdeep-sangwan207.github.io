Lesson 07: Logic Gates and Boolean Algebra

Understand digital logic gates, truth tables, Boolean expressions, fundamental Boolean laws and logic simplification used in digital electronics and embedded systems.

1. Introduction to Digital Logic

Digital electronics is based on two logic states: 0 and 1. These states are commonly associated with LOW and HIGH voltage levels in a digital circuit.

A logic gate is an electronic circuit that performs a logical operation on one or more binary inputs and produces a binary output.

Logic gates are the fundamental building blocks of:

  • Microprocessors and microcontrollers.
  • Arithmetic Logic Units (ALUs).
  • Memory circuits.
  • Control circuits.
  • Digital communication systems.
  • Embedded system hardware.

A logic 1 does not always mean exactly 5 V, and a logic 0 does not always mean exactly 0 V. The accepted voltage ranges depend on the circuit technology and supply voltage.

11. Universal Logic Gates

NAND and NOR are called universal gates because they can independently implement all basic logic operations.

Implementing NOT using NAND

Connect both inputs of a NAND gate to the same input.

Y = (A · A)̅
Y = A̅

Implementing AND using NAND

First generate NAND, then invert its output using another NAND gate.

X = (A · B)̅
Y = (X · X)̅
Y = A · B

Implementing OR using NAND

Use De Morgan's theorem:

A + B = (A̅ · B̅)̅

Generate A̅ and B̅ using NAND gates, then combine them using a NAND gate.

Implementing NOR using NOR

Connect both inputs of a NOR gate to the same input to create an inverter.

Y = (A + A)̅
Y = A̅
Universal gates are important in digital circuit design because they allow complete logic functions to be implemented using a single gate type.

12. Introduction to Boolean Algebra

Boolean algebra is a mathematical system used to represent and simplify logical expressions.

It uses two values:

  • 1 – True

Boolean variables are represented using letters such as A, B, C and Y.

13. Fundamental Boolean Laws

1. Identity Law

A + 0 = A
A · 1 = A

2. Null or Domination Law

A + 1 = 1
A · 0 = 0

3. Idempotent Law

A + A = A
A · A = A

4. Complement Law

A + A̅ = 1
A · A̅ = 0

5. Involution Law

(A̅)̅ = A

6. Commutative Law

A + B = B + A
A · B = B · A

7. Associative Law

(A + B) + C = A + (B + C)
(A · B) · C = A · (B · C)

8. Distributive Law

A · (B + C) = A·B + A·C
A + (B·C) = (A+B)(A+C)

9. Absorption Law

A + A·B = A
A · (A+B) = A

14. De Morgan's Theorems

De Morgan's theorems are important Boolean identities used to simplify logic expressions and convert between AND, OR and complemented operations.

First theorem

(A · B)̅ = A̅ + B̅

The complement of an AND operation is equivalent to the OR of the complemented inputs.

Second theorem

(A + B)̅ = A̅ · B̅

The complement of an OR operation is equivalent to the AND of the complemented inputs.

Example

Y = (A · B)̅

Using De Morgan's theorem:

Y = A̅ + B̅
When applying De Morgan's theorem, complement every variable and change AND to OR, or OR to AND.

15. Simplification of Boolean Expressions

Boolean simplification reduces the number of logic operations and can reduce hardware complexity.

Example 1

Y = A + A·B

Using absorption law:

Y = A

Example 2

Y = A·1 + B·0

Using identity and null laws:

Y = A + 0

Y = A

Example 3

Y = A·B + A·B̅

Take A common:

Y = A(B + B̅)

Using complement law:

Y = A·1

Y = A

Example 4

Y = (A + B)·(A + B̅)

Using distributive identity:

Y = A + B·B̅

Using complement law:

Y = A + 0

Y = A

16. Sum of Products and Product of Sums

Sum of Products (SOP)

An SOP expression consists of multiple AND terms combined using OR.

Y = A̅B + AB̅

This expression represents XOR.

Product of Sums (POS)

A POS expression consists of OR terms combined using AND.

Y = (A + B)(A̅ + B̅)

This expression also represents XOR.

SOP and POS are standard forms used in combinational logic design. Karnaugh maps and other Boolean minimization techniques are commonly used to obtain simpler expressions.

17. Applications in Embedded Systems

1. GPIO Control

Logic operations are used to set, clear and test microcontroller GPIO register bits.

2. Peripheral Control

Logic gates are used within digital peripheral circuits for control and signal processing.

3. Arithmetic Logic Unit

An ALU uses logic circuits to perform arithmetic and logical operations.

4. Digital Comparators

XOR and XNOR logic can be used to compare binary bits and determine whether values match.

5. Control Systems

AND, OR and NOT operations can represent conditions for alarms, motor control and safety interlocks.

6. Memory and Data Processing

Logic circuits form part of memory decoders, data paths and control logic in digital processors.

18. Common Mistakes

  • Confusing AND with OR truth tables.
  • Forgetting that NAND is the complement of AND.
  • Forgetting that NOR is the complement of OR.
  • Confusing XOR with OR: XOR produces 0 when both inputs are 1.
  • Applying De Morgan's theorem without complementing every variable.
  • Confusing Boolean addition with ordinary arithmetic addition.
  • Using Boolean identities without checking operator precedence and parentheses.

19. Interview Questions and Answers

Q1. What is a logic gate?

A logic gate is a digital circuit that performs a logical operation on binary inputs and produces a binary output.

Q2. What are the three basic logic gates?

AND, OR and NOT.

Q3. Why is NAND called a universal gate?

Because any Boolean function can be implemented using only NAND gates.

Q4. What is the difference between XOR and XNOR?

XOR produces 1 when inputs differ. XNOR produces 1 when inputs are equal.

Q5. State De Morgan's theorems.

(A·B)̅ = A̅+B̅ and (A+B)̅ = A̅·B̅.

Q6. What is Boolean algebra?

It is a mathematical system used to represent and simplify logical expressions involving binary values.

Q7. What is an inverter?

An inverter is a NOT gate that produces the complement of its input.

Q8. What is a truth table?

A table that lists all possible input combinations and their corresponding output values.

Q9. What is the absorption law?

A + A·B = A and A·(A+B) = A.

Q10. Why is Boolean simplification useful?

It reduces the complexity of digital logic circuits and may reduce the number of gates required.

22. Lesson Summary

  • Logic gates are fundamental building blocks of digital electronics.
  • AND, OR and NOT are basic logic gates.
  • NAND and NOR are universal gates.
  • XOR detects different input states, while XNOR detects equal input states.
  • Truth tables describe the output for every input combination.
  • Boolean algebra provides rules for simplifying logic expressions.
  • De Morgan's theorems are used to transform complemented logic expressions.
  • Logic gates are used in processors, controllers, memory and digital control circuits.
