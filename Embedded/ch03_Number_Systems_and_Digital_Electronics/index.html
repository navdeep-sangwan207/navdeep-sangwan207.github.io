Chapter 03: Number Systems and Digital Electronics

Learn number systems, conversions, binary arithmetic, data representation, bit manipulation, logic gates and fundamental digital electronic circuits used in embedded systems.

Chapter: 03
Total Lessons: 9
Level: Beginner to Intermediate

Chapter Overview

Digital electronics forms the foundation of modern embedded systems. Microcontrollers and processors internally represent and process information using binary data.

This chapter introduces number systems, number conversions, binary arithmetic, signed and unsigned data representation, bitwise operations and digital logic circuits.

It also explains combinational and sequential circuits, registers, counters and flip-flops that are essential for understanding microcontroller architecture and digital hardware.

Learning Objectives

  • Understand binary, octal, decimal and hexadecimal number systems.
  • Convert numbers between different number systems.
  • Perform binary addition, subtraction, multiplication and division.
  • Understand 1's complement and 2's complement representations.
  • Differentiate between signed and unsigned data.
  • Perform bitwise operations and bit manipulation.
  • Understand logic gates and Boolean algebra.
  • Differentiate between combinational and sequential circuits.
  • Understand registers, counters and flip-flops.

Chapter Lessons

  • L01 – Binary, Octal, Decimal and Hexadecimal Introduction to positional number systems, base values, digits and representation of numbers in digital systems.
  • L02 – Number System Conversions Conversion methods between binary, octal, decimal and hexadecimal number systems, including fractional values.
  • L03 – Binary Arithmetic Binary addition, subtraction, multiplication, division, carry, borrow and arithmetic operations.
  • L04 – 1's and 2's Complement Complement representation, finding 1's and 2's complement and performing subtraction using complements.
  • L05 – Signed and Unsigned Data Representation Unsigned binary representation, signed magnitude, 1's complement, 2's complement and integer ranges.
  • L06 – Bitwise Operations and Bit Manipulation Bitwise AND, OR, XOR, NOT, left shift, right shift, setting, clearing, toggling and testing individual bits.
  • L07 – Logic Gates and Boolean Algebra AND, OR, NOT, NAND, NOR, XOR and XNOR gates, truth tables, Boolean expressions and Boolean laws.
  • L08 – Combinational and Sequential Circuits Combinational logic, sequential logic, adders, multiplexers, decoders and memory-based circuits.
  • L09 – Registers, Counters and Flip-Flops SR, JK, D and T flip-flops, registers, shift registers, asynchronous counters and synchronous counters.

Practical Applications in Embedded Systems

  • Understanding hexadecimal microcontroller register values.
  • Configuring GPIO pins using bitwise operations.
  • Setting and clearing individual peripheral control bits.
  • Understanding binary data stored in memory.
  • Interpreting signed and unsigned sensor values.
  • Understanding digital logic inside microcontrollers.
  • Understanding hardware registers and counters.
  • Developing a foundation for Embedded C programming.

Expected Learning Outcomes

  • Represent values in binary, octal, decimal and hexadecimal.
  • Convert numbers accurately between different bases.
  • Perform basic binary arithmetic operations.
  • Explain signed and unsigned integer representations.
  • Write expressions using bitwise operators in C.
  • Analyze basic digital logic circuits.
  • Explain the operation of flip-flops, registers and counters.
  • Apply number-system and digital-logic concepts to embedded programming.

Chapter Completion Checklist

  • Complete all 9 lessons.
  • Practice number-system conversion problems.
  • Solve binary arithmetic exercises.
  • Practice bitwise operations using C expressions.
  • Draw truth tables for basic logic gates.
  • Study flip-flops, registers and counters.
  • Attempt the exercises and interview questions in each lesson.
Important: Number systems and bit manipulation are especially important for Embedded C programming. These concepts will be used when configuring microcontroller registers, controlling GPIO pins and working with peripheral hardware.
