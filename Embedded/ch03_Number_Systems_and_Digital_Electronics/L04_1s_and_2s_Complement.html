Lesson 04: 1's and 2's Complement

Learn how digital systems represent negative binary numbers and perform subtraction using 1's complement and 2's complement arithmetic.

1. Introduction to Complements

A complement is a method used in digital systems to represent negative numbers and simplify arithmetic operations.

Computers and microcontrollers use binary arithmetic. However, they must also represent negative values and perform subtraction efficiently.

Two important complement systems are:

  • 1's complement
  • 2's complement

2's complement is the most widely used representation for signed integers in modern processors and microcontrollers.

2. 1's Complement

The 1's complement of a binary number is obtained by changing every 0 into 1 and every 1 into 0.

In other words, invert every bit.

Rules

  • 0 becomes 1.
  • 1 becomes 0.

Example 1: Find the 1's complement of 1010.

Original number : 1010
1's complement : 0101

Example 2: Find the 1's complement of 11001010.

Original number : 11001010
1's complement : 00110101
The bit width must remain unchanged. For an 8-bit number, the 1's complement is also an 8-bit number.

3. 2's Complement

The 2's complement of a binary number is obtained by adding 1 to its 1's complement.

Formula

2's Complement = 1's Complement + 1

Steps

  1. Write the binary number using the required bit width.
  2. Invert every bit to obtain the 1's complement.
  3. Add 1 to the inverted number.

Example 1: Find the 2's complement of 0101.

Original number : 0101
1's complement : 1010
Add 1          : 0001
                 ----
2's complement: 1011

Example 2: Find the 2's complement of 00110100.

Original number : 00110100
1's complement : 11001011
Add 1          : 00000001
                 --------
2's complement: 11001100

4. Difference Between 1's and 2's Complement

5. Signed Number Representation Using 1's Complement

In 1's complement representation, the most significant bit (MSB) indicates the sign:

  • MSB = 0: positive number.
  • MSB = 1: negative number.

A negative number is represented by taking the 1's complement of the corresponding positive number at the same bit width.

Example: Represent +5 and −5 using 4 bits.

+5 = 0101

-5 = 1010

Here, 1010 is obtained by inverting 0101.

Range of an n-bit 1's complement number

−(2n−1 − 1) to +(2n−1 − 1)

For 4 bits, the range is −7 to +7.

1's complement has both positive zero (0000) and negative zero (1111) in a 4-bit representation.

6. Signed Number Representation Using 2's Complement

In 2's complement representation, the MSB indicates the sign:

  • MSB = 0: non-negative number.
  • MSB = 1: negative number.

To represent a negative number, take the 2's complement of its positive magnitude using the same bit width.

Example: Represent +5 and −5 using 4 bits.

+5 = 0101

Invert bits:
     1010

Add 1:
     1011

-5 = 1011

Range of an n-bit 2's complement number

−2n−1 to +(2n−1 − 1)

7. Why 2's Complement Is Widely Used

2's complement simplifies signed arithmetic in digital hardware.

  • Only one representation of zero is required.
  • Addition and subtraction can use the same binary adder circuitry.
  • There is no end-around carry requirement.
  • It provides a convenient fixed-width signed representation.
In a typical two's complement system, the same adder hardware can perform subtraction by complementing one operand and adding 1.

8. Subtraction Using 1's Complement

Subtraction can be performed by adding the 1's complement of the subtrahend to the minuend.

Procedure

  1. Write both numbers using the same bit width.
  2. Find the 1's complement of the subtrahend.
  3. Add it to the minuend.
  4. If a carry is generated, add that carry to the least significant bit. This is called end-around carry.
  5. If no carry is generated, the result is negative and is represented in 1's complement form.

Example: Calculate 9 − 5 using 4-bit 1's complement.

9 = 1001
5 = 0101

1's complement of 5:
    1010

Add:
    1001
  + 1010
  ------
   10011

End-around carry:
    0011
  + 0001
  ------
    0100

Result = 0100 = +4

Example: Calculate 5 − 9 using 4-bit 1's complement.

5 = 0101
9 = 1001

1's complement of 9:
    0110

Add:
    0101
  + 0110
  ------
    1011

No carry is generated.

1's complement of 1011:
    0100

Result = -0100 = -4

9. Subtraction Using 2's Complement

2's complement subtraction is performed by adding the 2's complement of the subtrahend to the minuend.

Procedure

  1. Write both operands using the same bit width.
  2. Find the 2's complement of the subtrahend.
  3. Add it to the minuend.
  4. Discard any carry out beyond the fixed bit width.
  5. Interpret the remaining bits as a signed 2's complement result.

Example 1: Calculate 9 − 5 using 4-bit 2's complement.

9 = 1001
5 = 0101

2's complement of 5:
1's complement = 1010
Add 1          = 0001
                 ----
2's complement = 1011

Add:
    1001
  + 1011
  ------
   10100

Discard carry out:
    0100

Result = +4

Example 2: Calculate 5 − 9 using 4-bit 2's complement.

5 = 0101
9 = 1001

2's complement of 9:
1's complement = 0110
Add 1          = 0001
                 ----
2's complement = 0111

Add:
    0101
  + 0111
  ------
    1100

Result = 1100

Since MSB = 1, result is negative.

2's complement of 1100:
Invert = 0011
Add 1  = 0001
         ----
         0100

Result = -4

10. Detecting Negative Numbers

In a fixed-width 2's complement signed representation, the MSB indicates whether the value is negative.

Binary value4-bit signed value
00000
0001+1
0101+5
0111+7
1000−8
1011−5
1111−1
The MSB is a sign indicator only when the bit pattern is interpreted as a signed two's complement value. The same bit pattern can represent a different unsigned value.

11. Important Special Case: Most Negative Number

In an n-bit two's complement system, the most negative number is −2n−1.

For an 8-bit signed value:

10000000 = -128

Its positive counterpart, +128, cannot be represented in an 8-bit signed value because the maximum is +127.

Therefore, negating the most negative value in the same signed width cannot produce a representable positive result.

12. 1's and 2's Complement in Embedded Systems

Complement arithmetic is important in embedded systems because processors work with fixed-width binary values.

  • Representing negative sensor readings.
  • Performing signed addition and subtraction.
  • Calculating differences between measured values.
  • Handling signed timer offsets and counters.
  • Processing signed ADC measurements when the system uses an appropriate signed representation.
  • Understanding processor status flags and arithmetic instructions.

Example: Signed arithmetic in Embedded C

#include <stdint.h>

int main(void)
{
    int8_t temperature_a = 25;
    int8_t temperature_b = -10;

    int16_t difference;

    difference = temperature_a - temperature_b;

    while (1)
    {
        /* Inspect difference in the debugger */
    }
}

Expected result:

temperature_a = 25
temperature_b = -10
difference    = 35

The C language uses signed integer representations supported by the implementation. Modern embedded ARM toolchains use two's complement representation.

In Keil uVision, inspect the signed variables in the debugger. This is a software demonstration and does not require physical hardware.

13. Common Mistakes

  • Changing the bit width while calculating a complement.
  • Forgetting to add 1 after finding the 1's complement when calculating 2's complement.
  • Forgetting the end-around carry in 1's complement subtraction.
  • Adding the end-around carry in 2's complement subtraction instead of discarding the carry out.
  • Reading a negative two's complement value as an unsigned number.
  • Assuming the positive and negative ranges are symmetrical in two's complement.
  • Ignoring signed overflow.

14. Interview Questions and Answers

Q1. What is 1's complement?

It is obtained by inverting every bit of a binary number.

Q2. What is 2's complement?

It is obtained by adding 1 to the 1's complement of a binary number.

Q3. How is −5 represented in 8-bit two's complement?

+5 = 00000101
Invert = 11111010
Add 1  = 00000001
         --------
-5     = 11111011

Q4. Why is 2's complement preferred?

It provides one zero representation and simplifies addition and subtraction hardware.

Q5. What is the 8-bit signed two's complement range?

−128 to +127.

Q6. What is end-around carry?

It is the process of adding the carry out back to the least significant bit in 1's complement addition.

Q7. How is subtraction performed using 2's complement?

Add the 2's complement of the subtrahend to the minuend and discard the carry out beyond the fixed width.

Q8. How many representations of zero exist in 1's complement?

Two: positive zero and negative zero.

Q9. How many representations of zero exist in 2's complement?

One: all bits are zero.

Q10. What is the 2's complement of 1000 in 4 bits?

1000. It is the most negative 4-bit two's complement value, and its negation is not representable in the same width.

17. Lesson Summary

  • 1's complement is obtained by inverting all bits.
  • 2's complement is obtained by adding 1 to the 1's complement.
  • Both methods can represent negative binary numbers.
  • 1's complement has two representations of zero.
  • 2's complement has only one representation of zero.
  • 2's complement is widely used in modern processors.
  • Subtraction can be performed using complement addition.
  • Fixed-width representation determines the valid signed range.
  • Signed overflow must be distinguished from unsigned carry.
