Lesson 08: Combinational and Sequential Circuits

Learn how digital circuits process binary inputs, store information and perform time-dependent operations using combinational logic, latches, flip-flops, registers and counters.

1. Introduction to Digital Circuits

Digital circuits are electronic circuits that operate using discrete logic states, typically represented by binary values 0 and 1.

Digital circuits are broadly classified into two categories:

  • Combinational circuits: Output depends only on the present input values.
  • Sequential circuits: Output depends on present inputs and the previously stored state.

2. Combinational Circuits

A combinational circuit is a digital logic circuit in which the output depends only on the current combination of inputs.

It does not have memory elements to store previous input states.

Characteristics

  • Output depends on present inputs only.
  • No internal state is stored.
  • Does not require a clock for its logical operation.
  • Built using logic gates.
  • Propagation delay exists because signals require time to pass through gates.

Examples

  • Adders and subtractors.
  • Multiplexers and demultiplexers.
  • Encoders and decoders.
  • Comparators.
  • Code converters.

3. Sequential Circuits

A sequential circuit is a digital circuit whose output depends on both present inputs and the previously stored state.

It contains memory elements such as latches or flip-flops.

Characteristics

  • Output depends on present inputs and stored state.
  • Contains memory elements.
  • May be clock-driven or asynchronous.
  • Used for storing and processing information over time.
  • Commonly used in controllers, registers and counters.

Examples

  • Latches and flip-flops.
  • Registers.
  • Counters.
  • Shift registers.
  • Finite State Machines (FSMs).

5. Half Adder

A half adder is a combinational circuit that adds two single-bit binary inputs and generates Sum and Carry outputs.

Inputs and Outputs

  • A – First binary input.
  • B – Second binary input.
  • Sum – Result bit.
  • Carry – Carry generated by addition.

Boolean Expressions

Sum   = A XOR B
Carry = A AND B

Truth Table

ABSumCarry
0000
0110
1010
1101
A half adder cannot accept a carry input from a previous stage. A full adder is used when an incoming carry must be included.

6. Full Adder

A full adder is a combinational circuit that adds three single-bit inputs: A, B and Carry-in (Cin).

Inputs and Outputs

  • A – First input bit.
  • B – Second input bit.
  • Cin – Carry input.
  • Sum – Result bit.
  • Cout – Carry output.

Boolean Expressions

Sum = A XOR B XOR Cin

Cout = (A AND B) OR
       (Cin AND (A XOR B))

  • Binary addition circuits.
  • Arithmetic Logic Units.
  • Multi-bit adders.
  • Digital processors.

9. Encoder

An encoder is a combinational circuit that converts an active input line into a coded binary output.

A simple 4-to-2 encoder has four input lines and two output bits, assuming exactly one input is active at a time.

11. Comparator

A digital comparator compares two binary values and determines whether they are equal or which one is greater.

A one-bit comparator has inputs A and B and can produce three outputs:

  • A greater than B.
  • A equal to B.

12. Memory Elements in Sequential Circuits

Sequential circuits require memory elements to retain information about previous states.

Two important types are:

  • Latches.
  • Flip-flops.

Both can store one binary bit, but they differ in how their inputs control state changes.

13. Latches

A latch is a level-sensitive storage element. Its output can respond to input changes while its enable condition is active.

SR Latch

An SR latch has two control inputs:

  • S – Set.
  • R – Reset.

For a conventional active-high NOR-based SR latch:

SRNext State QOperation
00Previous QHold
010Reset
101Set
11InvalidForbidden condition
The invalid condition shown here applies to the active-high NOR-based SR latch. A NAND-based active-low SR latch has a different input convention.

Applications

  • Temporary data storage.
  • Control circuits.
  • Asynchronous digital logic.

14. Flip-Flops

A flip-flop is a bistable storage element that stores one bit of information. In common synchronous designs, its state changes in response to a specified clock edge.

The JK flip-flop is an improved form of the SR flip-flop. It eliminates the forbidden input condition by defining a toggle operation.

17. D Flip-Flop

A D flip-flop stores the value present at its D input at the active clock edge.

Characteristic Equation

Q(next) = D

Operation

  • When the active clock edge occurs, the D input is sampled.
  • The sampled value is stored at Q.
  • The stored value remains until a later active clock edge or an applicable asynchronous control action.

Applications

  • Data registers.
  • Pipeline stages.
  • State storage.
  • Digital synchronization circuits.

18. T Flip-Flop

A T flip-flop toggles its output when T is 1 at the active clock edge. When T is 0, it holds its previous state.

Truth Table

TNext QOperation
0QHold
1Q̅Toggle

Characteristic Equation

Q(next) = T XOR Q

Applications

  • Binary counters.
  • Frequency division.
  • Toggle control circuits.

19. Clock Signal and Triggering

A clock signal is a periodic digital waveform used to coordinate state changes in synchronous sequential circuits.

Important Clock Terms

  • Clock period: Time taken for one complete clock cycle.
  • Clock frequency: Number of cycles per second.
  • Rising edge: Transition from LOW to HIGH.
  • Falling edge: Transition from HIGH to LOW.
  • Duty cycle: Percentage of a clock period for which the signal remains HIGH.

Frequency and Period

Frequency: f = 1 / T

Period:    T = 1 / f

For a 1 MHz clock:

f = 1,000,000 Hz

T = 1 / 1,000,000
  = 1 microsecond

Edge Triggering

  • Positive-edge triggered: responds to the rising clock edge.
  • Negative-edge triggered: responds to the falling clock edge.

20. Registers

A register is a group of flip-flops used to store multiple bits of binary information.

A register containing eight flip-flops can store eight bits.

Types of Registers

  • Parallel-in Parallel-out (PIPO).
  • Serial-in Serial-out (SISO).
  • Serial-in Parallel-out (SIPO).
  • Parallel-in Serial-out (PISO).

Applications

  • Temporary data storage.
  • CPU registers.
  • Data transfer.
  • Serial communication.
  • Data buffering.

22. Counters

A counter is a sequential circuit that moves through a defined sequence of binary states in response to clock pulses.

Types of Counters

  • Up counter: Counts in increasing order.
  • Down counter: Counts in decreasing order.
  • Up/Down counter: Supports both directions.
  • Asynchronous counter: Clocking propagates through successive flip-flop stages.
  • Synchronous counter: Flip-flops share a common clock signal.

23. Timing Concepts in Sequential Circuits

Correct operation of synchronous circuits depends on timing requirements.

Setup Time

The minimum time for which data must remain stable before the active clock edge.

Hold Time

The minimum time for which data must remain stable after the active clock edge.

Propagation Delay

The time between a change at a circuit input and the resulting change at its output.

Clock-to-Q Delay

The time between the active clock edge and the corresponding change at the flip-flop output.

Violating setup or hold requirements can cause metastability or incorrect state capture. Synchronizer circuits are used when asynchronous signals enter synchronous digital systems.

24. Applications in Embedded Systems

  • GPIO: Digital input and output circuits use combinational and sequential logic.
  • Timers and counters: Count clock cycles and external events.
  • UART: Shift registers and control state machines support serial data transmission and reception.
  • SPI: Shift registers transfer data serially.
  • CPU: Registers store operands, addresses and processor state.
  • Control units: Sequential logic controls the order of processor operations.
  • Interrupt controllers: Logic circuits manage interrupt requests and priority.
  • Digital measurement: Counters and registers help capture and process events.

25. Common Mistakes

  • Assuming that combinational circuits store previous inputs.
  • Assuming all sequential circuits require a clock; asynchronous sequential circuits also exist.
  • Confusing a latch with an edge-triggered flip-flop.
  • Forgetting the carry input of a full adder.
  • Confusing a multiplexer with a demultiplexer.
  • Confusing an encoder with a decoder.
  • Ignoring setup time and hold time requirements.
  • Assuming all flip-flops have identical triggering and asynchronous control behavior.

26. Interview Questions and Answers

Q1. What is a combinational circuit?

A circuit whose output depends only on its present inputs.

Q2. What is a sequential circuit?

A circuit whose output depends on present inputs and previously stored state.

Q3. What is the main difference between a latch and a flip-flop?

A latch is level-sensitive, whereas a conventional flip-flop is edge-triggered.

Q4. What is a half adder?

A combinational circuit that adds two single-bit inputs and produces Sum and Carry outputs.

Q5. What is a full adder?

A circuit that adds two input bits and an incoming carry bit.

Q6. What is a multiplexer?

A circuit that selects one of several data inputs and sends it to one output.

Q7. What is a decoder?

A circuit that converts a binary input code into a corresponding output line.

Q8. What is a D flip-flop?

A storage element that captures its D input at the active clock edge.

Q9. What is a shift register?

A sequential circuit that stores and shifts binary data.

Q10. What is a counter?

A sequential circuit that advances through a sequence of states in response to clock pulses.

Q11. What is setup time?

The minimum time data must be stable before the active clock edge.

Q12. What is hold time?

The minimum time data must remain stable after the active clock edge.

Q13. What is a synchronous counter?

A counter in which all flip-flops receive a common clock signal.

Q14. What is a register?

A group of flip-flops used to store a multi-bit binary value.

Q15. How many states can an n-bit counter represent?

It can represent up to 2n distinct states.

27. Multiple Choice Questions

1. Which circuit depends only on present inputs?

  • A. Sequential
  • B. Combinational
  • C. Counter
  • D. Register

Answer: B. Combinational

2. Which circuit stores previous state information?

  • A. Decoder
  • B. Multiplexer
  • C. Sequential
  • D. Comparator

Answer: C. Sequential

3. How many flip-flops are needed to store 8 bits?

  • A. 4
  • B. 8
  • C. 16
  • D. 2

Answer: B. 8

4. Which circuit adds two bits and a carry input?

  • A. Half adder
  • B. Full adder
  • C. Decoder
  • D. Comparator

Answer: B. Full adder

5. Which circuit selects one of several inputs?

  • A. MUX
  • B. DEMUX
  • C. Encoder
  • D. Counter

Answer: A. MUX

6. Which device is level-sensitive?

  • A. D flip-flop
  • B. Latch
  • C. Binary counter
  • D. Register

Answer: B. Latch

7. Which flip-flop toggles when both J and K are 1?

  • A. D
  • B. SR
  • C. JK
  • D. None

Answer: C. JK

8. What does a demultiplexer do?

  • A. Selects one input
  • B. Routes one input to a selected output
  • C. Stores data
  • D. Counts pulses

Answer: B. Routes one input to a selected output

9. What is the maximum number of states in a 4-bit binary counter?

  • A. 4
  • B. 8
  • C. 16
  • D. 32

Answer: C. 16

10. Which timing parameter specifies data stability before a clock edge?

  • A. Hold time
  • B. Setup time
  • C. Propagation delay
  • D. Clock period

29. Lesson Summary

  • Digital circuits are classified as combinational and sequential.
  • Combinational circuits depend on present inputs.
  • Sequential circuits depend on present inputs and stored state.
  • Half adders and full adders perform binary addition.
  • Multiplexers select data, while demultiplexers distribute data.
  • Encoders and decoders perform code conversion.
  • Latches and flip-flops store binary information.
  • Registers and shift registers store and transfer data.
  • Counters move through a sequence of binary states.
  • Clock timing and setup/hold requirements are important in synchronous circuits.
