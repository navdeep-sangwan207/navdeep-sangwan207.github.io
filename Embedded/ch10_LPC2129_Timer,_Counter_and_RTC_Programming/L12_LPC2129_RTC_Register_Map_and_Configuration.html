2. Introduction to RTC Register Architecture

The LPC2129 RTC is controlled through memory-mapped registers. Each register is assigned a fixed address in the microcontroller's peripheral address space.

Embedded C programs communicate with the RTC by reading from and writing to these registers.

The RTC register architecture is divided into four functional groups:

  1. Miscellaneous Register Group
  2. Time Counter Group
  3. Alarm Register Group
  4. Reference Clock Divider Register Group
Important: RTC registers are memory-mapped peripheral registers. Their addresses and access permissions must be respected. A read-only register must not be treated as a writable configuration register.

4. Miscellaneous Register Group

The miscellaneous register group contains the main RTC control, status, interrupt and consolidated-time registers.

4.1 Interrupt Location Register (ILR)

Address: 0xE0024000

ILR identifies the RTC interrupt source. It also provides the mechanism for clearing the corresponding RTC interrupt status.

Bit Symbol Description
0 RTCCIF Counter Increment Interrupt Flag
1 RTCALF Alarm Interrupt Flag

Writing a logic one to the relevant bit clears the corresponding interrupt flag. Writing zero has no effect. 

/* Clear Counter Increment Interrupt */
ILR = 0x01;

/* Clear Alarm Interrupt */
ILR = 0x02;

/* Clear both RTC interrupt flags */
ILR = 0x03;

4.2 Clock Tick Counter (CTC)

Address: 0xE0024004

CTC is a read-only register associated with the RTC clock divider. It counts the reference clock ticks before the seconds counter advances.

  • Bits 15:1 contain the clock tick counter.
  • Bit 0 is reserved.
  • 32,768 reference clock ticks correspond to one second.
unsigned int tick_value;

tick_value = CTC;
CTC is not a general-purpose timer counter. It is part of the RTC clock-generation and timekeeping mechanism. It is read-only and is reset through the RTC CCR.

4.3 Clock Control Register (CCR)

Address: 0xE0024008

CCR controls the operation of the RTC clock divider and time counters.

Bit Symbol Function
0 CLKEN Enables or disables the time counters.
1 CTCRST Resets the Clock Tick Counter while set.
3:2 CTTEST Test control bits; keep zero during normal operation.
7:4 Reserved Do not write ones to reserved bits.

Important control operations:

/* Disable RTC time counters */
CCR = 0x00;

/* Hold CTC in reset */
CCR = 0x02;

/* Release CTC reset */
CCR = 0x00;

/* Enable RTC time counters */
CCR = 0x01;
Configuration rule: The time counters must be disabled before initializing their values. CTCRST controls the clock tick counter; it does not replace the CLKEN control bit.

4.4 Counter Increment Interrupt Register (CIIR)

Address: 0xE002400C

CIIR selects which time counter increments can generate RTC counter-increment interrupts.

Bit Symbol Interrupt event
0IMSECSeconds increment
1IMMINMinutes increment
2IMHOURHours increment
3IMDOMDay of month increment
4IMDOWDay of week increment
5IMDOYDay of year increment
6IMMONMonth increment
7IMYEARYear increment
/* Enable interrupt on seconds increment */
CIIR = 0x01;

/* Disable all counter-increment interrupts */
CIIR = 0x00;

4.5 Alarm Mask Register (AMR)

Address: 0xE0024010

AMR determines which alarm fields participate in the RTC alarm comparison.

Bit Alarm field When bit is 1
0SecondsSeconds comparison masked
1MinutesMinutes comparison masked
2HoursHours comparison masked
3Day of monthDay-of-month comparison masked
4Day of weekDay-of-week comparison masked
5Day of yearDay-of-year comparison masked
6MonthMonth comparison masked
7YearYear comparison masked

When an AMR bit is zero, the corresponding alarm field participates in the comparison. All non-masked alarm fields must match their current time counters for the alarm condition to occur. 

/* Mask all alarm fields: alarm disabled */
AMR = 0xFF;

/* Compare seconds only */
AMR = 0xFE;

Important: CTIME0, CTIME1 and CTIME2 are read-only. They are used for reading consolidated time information. To initialize or update the RTC, use the individual time counter registers.

5.4 Extracting Time Fields Using Bitwise Operators

unsigned int time0;

unsigned int seconds;
unsigned int minutes;
unsigned int hours;
unsigned int day_of_week;

time0 = CTIME0;

seconds      = time0 & 0x3F;
minutes      = (time0 >> 8) & 0x3F;
hours        = (time0 >> 16) & 0x1F;
day_of_week  = (time0 >> 24) & 0x07;

This is an important embedded programming technique: extracting multiple fields from one memory-mapped register using bitwise shifts and masks.

8. RTC Prescaler Register Group

The RTC prescaler converts the peripheral clock frequency into the reference clock required by the RTC.

Register Address Width Function
PREINT 0xE0024080 13 bits Integer portion of prescaler
PREFRAC 0xE0024084 15 bits Fractional portion of prescaler

8.1 Prescaler Equations

The integer portion is calculated using:

PREINT = INT(PCLK / 32768) - 1

The fractional portion is calculated using:

PREFRAC = PCLK - ((PREINT + 1) * 32768)

These calculations must use the actual RTC peripheral clock frequency, not the CPU clock frequency.

8.2 Example: Calculate Prescaler Values for LPC2129

Given the project clock configuration:

ParameterValue
Crystal frequency (FOSC)12 MHz
CPU clock (CCLK)60 MHz
Peripheral clock (PCLK)15 MHz
RTC reference frequency32,768 Hz

Step 1: Calculate PREINT

PREINT = INT(15000000 / 32768) - 1

PREINT = 457 - 1

PREINT = 456

Step 2: Calculate PREFRAC

PREFRAC = 15000000 - ((456 + 1) * 32768)

PREFRAC = 15000000 - 14974976

PREFRAC = 25024

Final configuration:

RegisterValueHexadecimal
PREINT4560x01C8
PREFRAC250240x61C0
Engineering note: The fractional prescaler distributes additional PCLK cycles among reference-clock periods. Individual periods can therefore differ by one PCLK cycle, while the average output provides 32,768 reference ticks per second.

9. RTC Register Configuration Using Embedded C

In this section, we create register definitions and a basic initialization function. The program configures the RTC prescaler for PCLK = 15 MHz.

9.1 Register Definitions

The following definitions use the LPC2129 RTC memory-mapped addresses. 

#include <LPC21xx.h>

#define RTC_ILR       (*((volatile unsigned long *)0xE0024000))
#define RTC_CTC       (*((volatile unsigned long *)0xE0024004))
#define RTC_CCR       (*((volatile unsigned long *)0xE0024008))
#define RTC_CIIR      (*((volatile unsigned long *)0xE002400C))
#define RTC_AMR       (*((volatile unsigned long *)0xE0024010))

#define RTC_CTIME0    (*((volatile unsigned long *)0xE0024014))
#define RTC_CTIME1    (*((volatile unsigned long *)0xE0024018))
#define RTC_CTIME2    (*((volatile unsigned long *)0xE002401C))

#define RTC_SEC       (*((volatile unsigned long *)0xE0024020))
#define RTC_MIN       (*((volatile unsigned long *)0xE0024024))
#define RTC_HOUR      (*((volatile unsigned long *)0xE0024028))
#define RTC_DOM       (*((volatile unsigned long *)0xE002402C))
#define RTC_DOW       (*((volatile unsigned long *)0xE0024030))
#define RTC_DOY       (*((volatile unsigned long *)0xE0024034))
#define RTC_MONTH     (*((volatile unsigned long *)0xE0024038))
#define RTC_YEAR      (*((volatile unsigned long *)0xE002403C))

#define RTC_PREINT    (*((volatile unsigned long *)0xE0024080))
#define RTC_PREFRAC   (*((volatile unsigned long *)0xE0024084))

9.2 RTC Prescaler Initialization Function

void RTC_ConfigurePrescaler(void)
{
    /* Disable time counters before configuration */
    RTC_CCR = 0x00;

    /* Configure prescaler for PCLK = 15 MHz */
    RTC_PREINT  = 456;
    RTC_PREFRAC = 25024;

    /* Reset the RTC clock tick counter */
    RTC_CCR = (1U << 1);

    /* Release clock tick counter reset */
    RTC_CCR = 0x00;

    /* Enable RTC time counters */
    RTC_CCR = (1U << 0);
}

9.3 Complete Configuration Test Program

This program configures the RTC prescaler, enables the time counters and continuously reads the consolidated time registers for debugging. 

#include <LPC21xx.h>

#define RTC_CCR       (*((volatile unsigned long *)0xE0024008))
#define RTC_CTIME0    (*((volatile unsigned long *)0xE0024014))
#define RTC_CTIME1    (*((volatile unsigned long *)0xE0024018))
#define RTC_CTIME2    (*((volatile unsigned long *)0xE002401C))
#define RTC_PREINT    (*((volatile unsigned long *)0xE0024080))
#define RTC_PREFRAC   (*((volatile unsigned long *)0xE0024084))

volatile unsigned long time0_value;
volatile unsigned long time1_value;
volatile unsigned long time2_value;

volatile unsigned int seconds;
volatile unsigned int minutes;
volatile unsigned int hours;
volatile unsigned int day_of_week;

void RTC_Configure(void)
{
    /* Stop RTC time counters */
    RTC_CCR = 0x00;

    /* Configure prescaler for 15 MHz PCLK */
    RTC_PREINT  = 456;
    RTC_PREFRAC = 25024;

    /* Reset clock tick counter */
    RTC_CCR = 0x02;

    /* Release clock tick counter reset */
    RTC_CCR = 0x00;

    /* Enable RTC counters */
    RTC_CCR = 0x01;
}

void RTC_ReadTime(void)
{
    time0_value = RTC_CTIME0;
    time1_value = RTC_CTIME1;
    time2_value = RTC_CTIME2;

    seconds = time0_value & 0x3F;

    minutes = (time0_value >> 8) & 0x3F;

    hours = (time0_value >> 16) & 0x1F;

    day_of_week = (time0_value >> 24) & 0x07;
}

int main(void)
{
    RTC_Configure();

    while (1)
    {
        RTC_ReadTime();

        /* Inspect variables in Keil Watch Window */
    }
}
Important implementation note: This is a configuration and register-inspection exercise. It does not initialize a known calendar date or time. That operation is covered in Lesson 14. The RTC must also receive a valid clock configuration for the actual PCLK used by the application.

11. Debugging and Troubleshooting

Problem Possible reason Suggested check
RTC does not advance CLKEN is not set. Inspect CCR bit 0.
RTC counters cannot be initialized Time counters are enabled. Clear CLKEN before initialization.
RTC timing is incorrect Wrong PCLK or prescaler values. Recalculate PREINT and PREFRAC.
CTC remains reset CTCRST remains set. Clear CCR bit 1 after resetting CTC.
Unexpected time values RTC counters were not initialized. Initialize the complete calendar in the next practical lesson.
Unexpected alarm behaviour Incorrect AMR configuration. Check the alarm comparison mask.
Compilation errors Incorrect device header or register definitions. Verify target selection and header file.

12. Important RTC Usage Limitations

  • The RTC uses PCLK for its clocking arrangement.
  • Changing the peripheral clock or RTC prescaler during operation can introduce timekeeping errors.
  • Interrupting PCLK interrupts normal RTC time progression.
  • The LPC2129 does not provide independent RTC time retention through a dedicated backup battery supply in the manner of an external battery-backed RTC.
  • Loss of chip power results in loss of RTC register contents.
  • Power-down operation can cause a lapse in time updates.
Design consideration: For applications requiring continuous calendar time during complete MCU power loss, evaluate an external battery-backed RTC device or another appropriate time-retention solution.

13. Placement-Oriented Interview Questions

Q1. What is the base address of the LPC2129 RTC?

The RTC register group begins at 0xE0024000.

Q2. What is the purpose of the ILR register?

ILR identifies the counter-increment or alarm interrupt source and clears the corresponding interrupt flag when the relevant bit is written with one.

Q3. What is the difference between CTC and SEC?

CTC counts reference clock ticks before a seconds update. SEC stores the current seconds value from 0 to 59.

Q4. What does CLKEN do?

CLKEN enables the RTC time counters when set and disables them when cleared.

Q5. Why must the RTC counters be disabled before initialization?

Disabling the counters allows software to initialize the time and calendar values without the hardware simultaneously updating them.

Q6. What is the purpose of CTCRST?

CTCRST resets the RTC Clock Tick Counter while the reset bit remains set.

Q7. What is the difference between CTIME0 and SEC?

CTIME0 is a read-only consolidated register containing seconds, minutes, hours and day of week. SEC is an individual writable seconds counter.

Q8. Why are PREINT and PREFRAC required?

They configure the integer and fractional portions of the reference clock divider to generate the required 32.768 kHz RTC reference.

Q9. What is the purpose of AMR?

AMR determines which alarm fields are included in the alarm comparison.

Q10. Why should reserved bits not be written as ones?

Reserved bits are not intended for normal application control. Writing ones to them can produce undefined or device-dependent behaviour.

Q11. Calculate PREINT and PREFRAC for a PCLK of 15 MHz.

PREINT = 456 and PREFRAC = 25024.

Q12. Why is volatile used in register definitions?

Volatile tells the compiler that the register value can change independently of normal program execution and that accesses must not be optimized away as ordinary variable accesses.
