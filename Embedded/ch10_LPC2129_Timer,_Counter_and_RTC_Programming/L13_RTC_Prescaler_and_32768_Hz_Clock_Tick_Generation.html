2. Introduction to RTC Clock Generation

The Real-Time Clock requires a reference clock to maintain time and calendar information. The LPC2129 RTC uses its peripheral clock (PCLK) as the input to its reference clock divider.

The divider generates an average reference frequency of 32,768 Hz for the RTC clock tick counter.

The RTC uses this reference to generate the one-second timing required for updating its time counters.

Important: The LPC2129 RTC reference clock divider is based on PCLK. Do not assume that the RTC automatically receives an independent 32.768 kHz crystal input.

3. Why 32.768 kHz?

The frequency 32.768 kHz is widely used in RTC designs because it is a power of two. 

32.768 kHz = 32,768 Hz

32,768 = 2^15

A binary divider can divide this frequency by 32,768 to obtain one pulse per second. 

Output frequency = Input frequency / Division factor

Output frequency = 32,768 / 32,768

Output frequency = 1 Hz

One hertz represents one cycle per second. The RTC timekeeping logic uses the resulting one-second timing to advance the seconds counter.

3.1 Relationship Between Frequency and Period

The relationship between frequency and time period is:

T = 1 / f

For a 32,768 Hz reference:

T = 1 / 32768

T = 0.000030517578125 seconds

T = approximately 30.5176 microseconds

Therefore, the RTC receives 32,768 reference clock cycles over one second.

4. LPC2129 RTC Clock Divider Architecture

The RTC reference clock divider contains two principal components:

  • 13-bit integer prescaler counter
  • 15-bit fractional prescaler counter

The integer counter determines the normal number of PCLK cycles in each prescaler output period. The fractional logic adds an extra PCLK cycle to selected periods.

5. RTC Prescaler Registers

5.1 Prescaler Integer Register (PREINT)

Address: 0xE0024080

Bit range Description
12:0 13-bit integer prescaler value
15:13 Reserved

PREINT stores the integer part of the RTC reference clock divider configuration.

5.2 Prescaler Fraction Register (PREFRAC)

Address: 0xE0024084

Bit range Description
14:0 15-bit fractional prescaler value
15 Reserved

PREFRAC stores the remainder that cannot be represented by the integer prescaler value alone.

Register width: PREINT is 13 bits and PREFRAC is 15 bits. Do not write values outside their implemented bit ranges. Reserved bits must not be written as ones.

6. Prescaler Calculation Equations

The LPC2129 reference manual defines the calculations as follows.

6.1 Integer Prescaler Calculation

PREINT = INT(PCLK / 32768) - 1

INT represents the integer part of the division. The result is reduced by one because the counter uses the programmed value as a reload count.

6.2 Fractional Prescaler Calculation

PREFRAC = PCLK - ((PREINT + 1) * 32768)

PREFRAC stores the remaining PCLK cycles after calculating the integer portion.

6.3 Combined Relationship

PCLK = ((PREINT + 1) * 32768) + PREFRAC

This equation is useful for checking whether the calculated integer and fractional values correctly represent the configured PCLK.

Minimum clock requirement: The LPC2129 RTC prescaler requires a valid PCLK frequency supported by the device. The reference manual specifies PREINT must be at least 1. Check the device clock limits before selecting a PCLK value.

8. Why Is the Fractional Prescaler Required?

Consider the 15 MHz PCLK example. Dividing PCLK by 32,768 does not produce an integer number of PCLK cycles for every reference clock period.

The integer divider alone would produce: 

PREINT + 1 = 457 PCLK cycles

However, the exact average number of PCLK cycles required for each reference clock period is: 

15000000 / 32768

= 457.763671875 PCLK cycles

A physical clock period cannot contain a fractional PCLK cycle. The hardware therefore distributes additional PCLK cycles among selected output periods.

8.1 How Fractional Correction Works

The fractional counter and combination logic determine which prescaler periods are extended by one PCLK cycle. The additional cycles are distributed as evenly as possible.

For PCLK = 15 MHz:

Normal prescaler period = PREINT + 1

Normal period = 457 PCLK cycles

Extended period = 458 PCLK cycles

Fractional value = 25024

Therefore, some reference clock periods use 457 PCLK cycles and selected periods use 458 PCLK cycles. The fractional logic distributes these longer periods to achieve the required average frequency.

The RTC reference clock is not necessarily a perfectly uniform pulse train at the PCLK-cycle level. Its average frequency is 32,768 Hz. This small period variation is known as clock jitter.

9. Understanding the Integer and Fractional Counters

9.1 Integer Counter

The 13-bit integer counter counts down using the programmed PREINT value. When it reaches underflow, it reloads and produces the next prescaler event.

9.2 Fractional Counter

The 15-bit fractional counter determines when an additional PCLK cycle must be inserted.

Each bit in the fractional value represents a fractional contribution. The hardware uses combination logic to distribute the longer periods across the output clock cycles.

10. Relationship Between Prescaler and Clock Tick Counter

The prescaler generates the RTC reference clock. The Clock Tick Counter (CTC) receives the reference clock and counts its ticks.

The CTC register is located at: 

CTC address = 0xE0024004

The RTC uses 32,768 reference clock ticks for one second of timekeeping.

When the required reference ticks have elapsed, the RTC updates the seconds counter and associated timekeeping logic.

11. Register-Level Embedded C Programming

11.1 RTC Register Definitions

#include <LPC21xx.h>

#define RTC_CCR       (*((volatile unsigned long *)0xE0024008))
#define RTC_CTC       (*((volatile unsigned long *)0xE0024004))
#define RTC_PREINT    (*((volatile unsigned long *)0xE0024080))
#define RTC_PREFRAC   (*((volatile unsigned long *)0xE0024084))

11.2 Prescaler Configuration Function

void RTC_ConfigurePrescaler(void)
{
    /* Disable RTC time counters */
    RTC_CCR = 0x00;

    /* Configure integer prescaler */
    RTC_PREINT = 456;

    /* Configure fractional prescaler */
    RTC_PREFRAC = 25024;

    /* Reset Clock Tick Counter */
    RTC_CCR = (1U << 1);

    /* Release CTC reset */
    RTC_CCR = 0x00;

    /* Enable RTC time counters */
    RTC_CCR = (1U << 0);
}

11.3 Program Explanation

  1. Disable the RTC time counters.
  2. Write the calculated integer value to PREINT.
  3. Write the fractional remainder to PREFRAC.
  4. Set CTCRST to reset the clock tick counter.
  5. Clear CTCRST to release the reset.
  6. Set CLKEN to enable the time counters.
Do not repeatedly write the reset bit in the main loop. Reset the CTC during initialization, then allow the RTC to operate normally.

12. Complete Practical Program: RTC Prescaler Configuration

Objective: Configure the LPC2129 RTC prescaler for a 15 MHz PCLK and inspect the configuration values during simulation.

Complete Embedded C Program

#include <LPC21xx.h>

/* RTC register definitions */

#define RTC_CCR       (*((volatile unsigned long *)0xE0024008))
#define RTC_CTC       (*((volatile unsigned long *)0xE0024004))

#define RTC_PREINT    (*((volatile unsigned long *)0xE0024080))
#define RTC_PREFRAC   (*((volatile unsigned long *)0xE0024084))

/* Debug variables */

volatile unsigned long debug_preint;
volatile unsigned long debug_prefrac;
volatile unsigned long debug_ctc;
volatile unsigned long debug_ccr;

void RTC_ConfigurePrescaler(void)
{
    /* Disable RTC time counters */
    RTC_CCR = 0x00;

    /* Configure prescaler for 15 MHz PCLK */
    RTC_PREINT = 456;
    RTC_PREFRAC = 25024;

    /* Reset RTC Clock Tick Counter */
    RTC_CCR = 0x02;

    /* Release CTC reset */
    RTC_CCR = 0x00;

    /* Enable RTC time counters */
    RTC_CCR = 0x01;
}

int main(void)
{
    RTC_ConfigurePrescaler();

    while (1)
    {
        /* Read prescaler configuration */
        debug_preint = RTC_PREINT;
        debug_prefrac = RTC_PREFRAC;

        /* Read RTC clock tick counter */
        debug_ctc = RTC_CTC;

        /* Read RTC control register */
        debug_ccr = RTC_CCR;
    }
}

13. Practical Exercise: Calculate Prescaler Values in C

In this exercise, calculate PREINT and PREFRAC programmatically instead of writing fixed values.

Complete Calculation Program

#include <stdio.h>

#define RTC_REFERENCE_HZ 32768UL
#define PCLK_HZ          15000000UL

int main(void)
{
    unsigned long preint;
    unsigned long prefrac;

    preint = (PCLK_HZ / RTC_REFERENCE_HZ) - 1;

    prefrac = PCLK_HZ -
              ((preint + 1) * RTC_REFERENCE_HZ);

    printf("PCLK    = %lu Hz\n", PCLK_HZ);

    printf("PREINT  = %lu\n", preint);

    printf("PREFRAC = %lu\n", prefrac);

    printf("PREINT HEX  = 0x%lX\n", preint);

    printf("PREFRAC HEX = 0x%lX\n", prefrac);

    return 0;
}

Expected Console Output

PREINT HEX  = 0x1C8

16. Common Prescaler Configuration Errors

Error Reason Correction
Using CCLK instead of PCLK Incorrect clock source used in calculation. Use the actual peripheral clock frequency.
Using 32768 - 1 as the reference frequency Incorrect divider equation. Use 32768 in both equations.
Ignoring PREFRAC Fractional remainder is not configured. Calculate and write PREFRAC.
Incorrect integer rounding Using round() instead of integer truncation. Use the integer part of PCLK / 32768.
Writing values while RTC is running Unsafe configuration sequence. Disable time counters before reconfiguration.
Wrong register address Incorrect peripheral register definition. Verify the RTC register map.
Wrong PCLK assumption VPBDIV or PLL configuration differs from the expected setting. Verify the actual clock configuration.

18. Placement-Oriented Interview Questions

Q1. Why does the LPC2129 RTC use a 32.768 kHz reference?

It is a power-of-two frequency equal to 215, making it suitable for generating a one-second timing reference through binary division.

Q2. What are PREINT and PREFRAC?

PREINT stores the integer portion of the RTC prescaler configuration. PREFRAC stores the fractional remainder.

Q3. Why is the fractional prescaler needed?

Because PCLK divided by 32,768 is not always an integer. The fractional logic distributes additional PCLK cycles to achieve the required average output frequency.

Q4. Calculate the prescaler for PCLK = 15 MHz.

PREINT = 456 and PREFRAC = 25024.

Q5. What is clock jitter in the RTC prescaler?

Some reference clock periods are one PCLK cycle longer than others. This variation in individual clock periods is known as jitter.

Q6. What is the function of the 13-bit integer counter?

It determines the normal number of PCLK cycles in the prescaler output period.

Q7. What is the function of the 15-bit fractional counter?

It determines when additional PCLK cycles are inserted to compensate for the fractional remainder.

Q8. What happens if the wrong PCLK value is used?

The prescaler will generate an incorrect average reference frequency, causing RTC timekeeping errors.

Q9. What is the relationship between CTC and the prescaler?

The prescaler generates the reference clock that drives the RTC Clock Tick Counter.

Q10. Does the RTC prescaler use the timer PR register?

No. The RTC uses its own PREINT and PREFRAC registers. Timer0 and Timer1 use their separate prescaler registers.
