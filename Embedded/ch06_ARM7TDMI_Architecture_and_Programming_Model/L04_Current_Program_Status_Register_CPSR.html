Current Program Status Register (CPSR)

Course: Embedded Systems – Complete Study Course

Chapter 06: ARM7TDMI Architecture and Programming Model

Lesson 04

1. Introduction

The Current Program Status Register (CPSR) is a 32-bit register in the ARM7TDMI processor. It stores information about the current processor state, including arithmetic condition flags, processor operating mode, interrupt mask settings, and instruction-set state.

The processor updates some CPSR bits automatically when instructions that affect condition flags are executed. Other bits control how the processor operates.

Why is CPSR important? CPSR allows the processor to evaluate conditional instructions, identify its current operating mode, control IRQ/FIQ exceptions, and distinguish ARM state from Thumb state.

3. Condition Flags (N, Z, C, V)

The four condition flags occupy bits 31 to 28. They provide information about the result of arithmetic and logical operations.

3.1 Negative Flag (N)

  • Located at bit 31.
  • Indicates whether the result has its most significant bit set.
  • For a 32-bit signed result, this normally indicates a negative value.

Example: a result of 0xFFFFFFFF has N = 1.

3.2 Zero Flag (Z)

  • Located at bit 30.
  • Set to 1 when the result is zero.
  • Cleared to 0 when the result is non-zero.

Example: 5 − 5 = 0, therefore Z = 1.

3.3 Carry Flag (C)

  • Located at bit 29.
  • For addition, it can indicate a carry out of the most significant bit.
  • For subtraction, C = 1 indicates no borrow.
  • For shift operations, it can contain the last bit shifted out.

3.4 Overflow Flag (V)

  • Located at bit 28.
  • Indicates signed arithmetic overflow.
  • Occurs when a signed result cannot be represented in the available bit width.

Example: Condition flags in assembly

        MOV     R0, #5
        MOV     R1, #5

        SUBS    R2, R0, R1

The S suffix requests an update of the condition flags. Since 5 − 5 = 0, the Zero flag is set.

FlagExpected valueReason
N0Result is not negative
Z1Result is zero
C1Subtraction required no borrow
V0No signed overflow

4. Interrupt Mask Bits (I and F)

The CPSR contains two interrupt mask bits that control whether IRQ and FIQ exceptions are permitted.

BitNameFunction
7IIRQ disable mask
6FFIQ disable mask

IRQ mask

  • I = 0: IRQ is not masked by this bit.
  • I = 1: IRQ is masked.

FIQ mask

  • F = 0: FIQ is not masked by this bit.
  • F = 1: FIQ is masked.
Setting an interrupt mask does not erase an interrupt request. It prevents the corresponding exception from being taken while the mask remains set. Other interrupt-controller and processor conditions also affect interrupt handling.

Example: Interrupt mask combinations

IFMeaning
00IRQ and FIQ are both unmasked
10IRQ masked; FIQ unmasked
01IRQ unmasked; FIQ masked
11Both IRQ and FIQ masked

5. ARM/Thumb State Bit (T)

Bit 5 of CPSR selects the processor instruction-set state. ARM7TDMI supports both ARM and Thumb instruction sets.

T bitProcessor stateInstruction width
0ARM state32-bit ARM instructions
1Thumb state16-bit Thumb instructions

ARM state

  • Uses the ARM instruction set.
  • ARM instructions are 32 bits wide.
  • Supports conditional execution through condition codes in many instructions.

Thumb state

  • Uses the original ARMv4T Thumb instruction set.
  • Thumb instructions are 16 bits wide.
  • Provides more compact code in memory.
The processor executes instructions according to its current state. It does not interpret ARM and Thumb instruction encodings simultaneously. State transitions are performed through supported architectural mechanisms, such as an appropriate branch exchange instruction or exception return.

6. Processor Mode Bits (M[4:0])

Bits 4 to 0 identify the current ARM7TDMI processor mode. The processor supports seven operating modes.

ModeBinary valueHex valuePurpose
User100000x10Normal application execution
FIQ100010x11Fast interrupt handling
IRQ100100x12Normal interrupt handling
Supervisor (SVC)100110x13Operating-system and reset-related privileged execution
Abort101110x17Memory access fault handling
Undefined110110x1BUndefined instruction handling
System111110x1FPrivileged mode using the User register bank

User mode

User mode is the normal, unprivileged execution mode. It restricts access to certain processor control operations.

System mode

System mode is privileged but uses the same general-purpose register bank as User mode. It is useful for operating-system tasks that require privileged access.

Exception modes

FIQ, IRQ, Supervisor, Abort, and Undefined are exception modes. Each has its own banked stack pointer and link register. Each exception mode also has its own Saved Program Status Register (SPSR).

7. CPSR and SPSR Relationship

CPSR represents the current processor status. SPSR stores a saved copy of the CPSR when the processor enters an exception mode.

Normal program execution
CPSR = Current processor status

Exception occurs
CPSR contents are copied into the SPSR of the exception mode

Processor enters exception mode
CPSR control fields are updated for exception handling

Exception handler executes
Saved status can be restored during exception return

User and System modes do not have an SPSR. The five exception modes each have their own SPSR.

8. Reading the CPSR Using MRS

The MRS instruction transfers the contents of a status register into a general-purpose register. 

        MRS     R0, CPSR

Explanation:

  • MRS means Move to Register from Status Register.
  • R0 receives the current CPSR value.
  • The CPSR is not modified by this instruction.

Example: Inspecting CPSR fields

        MRS     R0, CPSR

        ; Extract processor mode bits
        AND     R1, R0, #0x1F

        ; Extract T state bit
        AND     R2, R0, #0x20

        ; Extract IRQ mask bit
        AND     R3, R0, #0x80

After execution, R1 contains the mode field, R2 contains the T-bit field, and R3 contains the IRQ mask bit in its original bit position.

9. Writing CPSR Using MSR

The MSR instruction transfers a value into selected fields of a status register. 

        MSR     CPSR_c, R0

Here, the suffix _c selects the control field of CPSR. The control field includes the interrupt masks, state bit, and processor mode bits.

Other field selectors include:

  • _f – flag field.
  • _s – status field.
  • _c – control field.
  • _all – all fields, subject to architectural permissions.
Important: Writing CPSR control fields is a privileged operation subject to ARM architectural restrictions. User mode cannot freely change processor mode or interrupt masks. Do not use arbitrary CPSR writes as ordinary application code. Mode transitions and exception returns must follow the ARM architecture rules.

10. CPSR in Exception Handling

When an exception occurs, the processor performs architectural actions that include saving the previous CPSR in the SPSR of the destination exception mode.

  1. The processor detects an exception request or condition.
  2. The current CPSR is copied into the destination mode's SPSR.
  3. The processor switches to the corresponding exception mode.
  4. The processor updates relevant control bits and selects the exception vector.
  5. The exception handler executes.
  6. The handler returns using an appropriate exception-return mechanism.

Restoring the saved status is important because the interrupted program must resume with its previous mode, state, and condition flags.

11. Practical ARM Assembly Example

The following example demonstrates reading CPSR and extracting the condition flags and processor mode. 

        AREA    CPSR_DEMO, CODE, READONLY
        ENTRY

START
        MRS     R0, CPSR

        ; Extract N, Z, C and V flags
        MOV     R1, R0, LSR #28
        AND     R1, R1, #0xF

        ; Extract processor mode
        AND     R2, R0, #0x1F

STOP
        B       STOP

        END

Expected observations

  • R0 contains the CPSR value read by MRS.
  • R1 contains the four condition flag bits in its low-order bits.
  • R2 contains the processor mode value.
  • The program remains in the STOP loop.
In Keil uVision Simulator, inspect R0, R1, R2 and CPSR in the register window while stepping through the program. The exact initial CPSR value depends on the simulated startup and execution configuration.

12. Applications of CPSR

  • Conditional instruction execution.
  • Checking arithmetic results.
  • IRQ and FIQ interrupt masking.
  • ARM and Thumb state management.
  • Processor mode identification.
  • Exception entry and return.
  • Operating-system context management.
  • Low-level processor debugging.

13. Common Mistakes

  1. Confusing CPSR with SPSR.
  2. Assuming all CPSR bits are condition flags.
  3. Reversing the meanings of I and F bits.
  4. Assuming T = 1 means ARM state.
  5. Assuming User mode can freely modify control fields.
  6. Assuming User and System modes have separate general-purpose register banks.
  7. Assuming every processor mode has an SPSR.
  8. Confusing ARM7TDMI architecture features with later ARM architecture extensions.

14. Interview Questions and Answers

Q1. What is CPSR?

CPSR is a 32-bit Current Program Status Register that stores condition flags, processor mode, interrupt masks, and ARM/Thumb state.

Q2. How many condition flags are present in ARM7TDMI CPSR?

Four: N, Z, C, and V.

Q3. What does the N flag indicate?

It indicates that the result's most significant bit is set.

Q4. What is the purpose of the Z flag?

It indicates whether an operation produced a zero result.

Q5. What is the difference between C and V?

C indicates carry or no-borrow information depending on the operation, while V indicates signed arithmetic overflow.

Q6. What is the function of the I bit?

It masks IRQ interrupts when set to 1.

Q7. What is the function of the F bit?

It masks FIQ interrupts when set to 1.

Q8. What does the T bit control?

It selects ARM state or Thumb state.

Q9. Which instruction reads CPSR?

MRS is used to read CPSR into a general-purpose register.

Q10. Which instruction writes CPSR?

MSR writes selected status-register fields, subject to permissions.

Q11. What is the relationship between CPSR and SPSR?

CPSR holds the current processor status. SPSR saves a copy of CPSR when entering an exception mode.

Q12. How many SPSRs are available in ARM7TDMI?

Five, one for each exception mode.
