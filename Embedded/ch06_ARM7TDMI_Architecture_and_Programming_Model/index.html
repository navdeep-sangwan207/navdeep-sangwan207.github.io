Chapter 6: ARM7TDMI Architecture and Programming Model

Study the internal architecture, register organization, processor status registers, operating modes, instruction states, pipeline, exception handling and memory interface of the ARM7TDMI processor.

Chapter Overview

ARM7TDMI is a 32-bit RISC processor core based on the ARMv4T architecture. It supports both the 32-bit ARM instruction set and the 16-bit Thumb instruction set.

This chapter explains the ARM7TDMI processor's internal organization and programming model. It covers the general-purpose registers, Current Program Status Register (CPSR), Saved Program Status Registers (SPSRs), processor modes, exception processing, instruction states and three-stage pipeline.

Understanding these concepts provides the architectural foundation for programming ARM7-based microcontrollers such as the LPC2129.

Learning Focus: Understand how the ARM7TDMI processor executes instructions, manages registers, changes processor modes and handles exceptions.
