Lesson 07: PWM Programming Using Embedded C

Learn how to initialize the LPC2129 PWM peripheral, configure PWM registers, generate PWM signals, and dynamically modify duty cycles using Embedded C.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand the PWM programming sequence.
  • Configure the PWM prescaler and timer.
  • Configure MR0 and channel match registers.
  • Enable PWM output channels through PWMPCR.
  • Use PWMLER to latch match-register values.
  • Generate PWM using LPC2129 Embedded C.
  • Modify PWM duty cycle during program execution.
  • Configure multiple PWM channels.
  • Debug PWM register settings using Keil uVision.

2. PWM Programming Overview

The LPC2129 PWM peripheral generates periodic digital waveforms using hardware timer and match-register logic. Once configured, the peripheral generates the waveform without requiring software to toggle the output pin for every transition.

3. Required Header File

LPC2129 programs commonly use the device header file provided by the Keil device support package.

#include <LPC21xx.h>

This header provides symbolic register names such as:

  • PWMTCR
  • PWMPR
  • PWMMR0 to PWMMR6
  • PWMMCR
  • PWMPCR
  • PWMLER
  • PWMIR
Header-file availability and register definitions depend on the installed LPC21xx device support package. Confirm that the selected Keil target is LPC2129.

5. PWM Timer Clock Configuration

The PWM timer receives the peripheral clock (PCLK). PWMPR controls the timer counter increment interval.

Timer Tick Frequency = PCLK / (PWMPR + 1)
Timer Tick Interval = (PWMPR + 1) / PCLK

Example Using Your Clock Configuration

  • CCLK = 60 MHz
  • PCLK = 15 MHz
  • Required timer tick = 1 MHz
PWMPR = (15 MHz / 1 MHz) - 1 = 14
PWMPR = 14U; PWMPC = 0U; PWMTC = 0U;
PWMTC increments at a nominal rate of 1 MHz, corresponding to a 1 microsecond timer tick.

6. PWM Period Configuration

MR0 determines the common PWM period. The MR0 reset action in PWMMCR makes the counter restart at the period match.

PWM Period ≈ MR0 × Timer Tick Interval
PWM Frequency ≈ PCLK / [(PWMPR + 1) × MR0]

Example: 1 kHz PWM

For a 1 microsecond timer tick:

MR0 = 1 ms / 1 µs = 1000
PWMMR0 = 1000U; /* Interrupt disabled, reset on MR0 match */ PWMMCR = (1U << 1);

7. PWM Duty Cycle Configuration

In single-edge mode, the channel match value determines the falling-edge position within the period.

Duty Cycle ≈ (Channel Match / MR0) × 100

PWMMR0 = 1000U; PWMMR1 = 500U;

The nominal PWM1 duty cycle is 50%.

8. Enabling PWM Output

PWMPCR controls which PWM channels are enabled. Bits 9 to 14 enable PWM1 to PWM6.

BitOutput
9PWM1
10PWM2
11PWM3
12PWM4
13PWM5
14PWM6

Enable PWM1

PWMPCR = (1U << 9);

Enable PWM1, PWM2, and PWM3

PWMPCR = (1U << 9) | (1U << 10) | (1U << 11);
PWMPCR enables the peripheral output function. The corresponding physical pin must also be selected through PINSEL. The exact PWM output pin assignment must be checked in the LPC2129 pin-multiplexing table.

Example: Latch MR0 and MR1

PWMLER = (1U << 0) | (1U << 1);

Example: Latch MR0 to MR3

PWMLER = 0x0FU;
Write all new match values first, then set the relevant PWMLER bits. The peripheral transfers the values at the appropriate PWM latch boundary.

10. PWMTCR Configuration

PWMTCR controls the PWM timer and PWM operating mode.

BitFunction
Bit 0Counter enable
Bit 1Counter reset
Bit 3PWM mode enable

Reset PWM Counter

PWMTCR = (1U << 1);

Enable Counter and PWM Mode

PWMTCR = (1U << 0) | (1U << 3);
Bit 1 is a reset control. It should be released when normal counting is started. Writing 0x09 enables the counter and PWM mode without keeping the counter in reset.

11. Program 1: Generate PWM1 at 1 kHz and 50% Duty Cycle

Objective

Configure PWM1 for a nominal 1 kHz frequency and approximately 50% duty cycle.

Program

#include <LPC21xx.h> void PWM1_Init(void) { /* Reset PWM counter */ PWMTCR = (1U << 1); /* Configure timer tick */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Period and duty cycle */ PWMMR0 = 1000U; PWMMR1 = 500U; /* Reset counter on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM1 output */ PWMPCR = (1U << 9); /* Latch MR0 and MR1 */ PWMLER = 0x03U; /* Enable PWM counter and PWM mode */ PWMTCR = 0x09U; } int main(void) { PWM1_Init(); while (1) { } }

12. Program 2: Change PWM Duty Cycle

Objective

Change the PWM1 duty cycle while keeping the PWM frequency unchanged.

Program

#include <LPC21xx.h> void PWM1_Init(void) { PWMTCR = (1U << 1); PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; PWMMR0 = 1000U; PWMMR1 = 250U; PWMMCR = (1U << 1); PWMPCR = (1U << 9); PWMLER = 0x03U; PWMTCR = 0x09U; } void PWM1_SetDuty(unsigned int duty) { if (duty > 100U) { duty = 100U; } PWMMR1 = (PWMMR0 * duty) / 100U; /* Latch new MR1 value */ PWMLER = (1U << 1); } int main(void) { PWM1_Init(); while (1) { PWM1_SetDuty(25U); } }

Program Explanation

  • MR0 remains fixed at 1000.
  • The duty argument is limited to 100%.
  • MR1 is calculated from the required duty percentage.
  • PWMLER requests the MR1 update.
This example repeatedly writes the same value. In an application, call PWM1_SetDuty() when a new duty-cycle command is received rather than on every loop iteration. For guaranteed glitch-free operation, coordinate updates with the PWM period and verify valid endpoint behavior.

13. Program 3: Multiple PWM Channels

Objective

Configure PWM1, PWM2, and PWM3 with different duty cycles while using a common PWM frequency.

#include <LPC21xx.h> void PWM_Multi_Init(void) { /* Reset PWM counter */ PWMTCR = (1U << 1); /* 1 MHz timer tick */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Common period */ PWMMR0 = 1000U; /* Different channel match values */ PWMMR1 = 250U; PWMMR2 = 500U; PWMMR3 = 750U; /* Reset on MR0 */ PWMMCR = (1U << 1); /* Enable PWM1, PWM2, PWM3 */ PWMPCR = (1U << 9) | (1U << 10) | (1U << 11); /* Latch MR0 through MR3 */ PWMLER = 0x0FU; /* Start PWM */ PWMTCR = 0x09U; } int main(void) { PWM_Multi_Init(); while (1) { } }

14. Program 4: Stop and Restart PWM

Objective

Understand how the PWM timer can be stopped and restarted through PWMTCR.

#include <LPC21xx.h> void PWM_Stop(void) { /* Disable PWM counter */ PWMTCR = (1U << 3); } void PWM_Start(void) { /* Enable counter and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); }
This example demonstrates timer control. For an actual application, define the desired output state during stopping and restarting, and verify the peripheral's output behavior in the device manual.

15. PWM Interrupt Overview

The PWM peripheral can generate an interrupt when a configured match event occurs.

The main registers involved are:

  • PWMMCR: enables interrupt action for selected match events.
  • PWMIR: contains match interrupt flags.
  • VIC: routes the PWM interrupt to the ARM7 interrupt system.

Clear PWM Match Interrupt Flag

/* Clear MR0 interrupt flag */ PWMIR = (1U << 0);
PWM interrupt programming also requires the appropriate VIC source configuration and an interrupt service routine. This lesson focuses on PWM output programming; detailed interrupt architecture is covered in Chapter 11.

16. PWM Pin Configuration

The PWM peripheral output must be routed to a physical microcontroller pin using the pin-function selection registers.

  1. Identify the required PWM channel.
  2. Consult the LPC2129 pin-multiplexing table.
  3. Identify the corresponding PINSEL register and field.
  4. Select the PWM alternate function.
  5. Enable the output channel through PWMPCR.
Do not assume that enabling PWM1 in PWMPCR automatically configures its physical pin. The PINSEL configuration is a separate requirement. Verify the exact pin mapping for the LPC2129 package before connecting hardware.

18. Common Programming Errors

  • Using the wrong peripheral clock frequency.
  • Incorrect PWMPR calculation.
  • Incorrect MR0 period calculation.
  • Forgetting to configure MR0 reset action.
  • Forgetting to enable the PWM output in PWMPCR.
  • Forgetting to latch match values through PWMLER.
  • Forgetting PWM mode enable in PWMTCR.
  • Forgetting the physical pin's PINSEL configuration.
  • Using invalid channel match values.
  • Assuming PWM output can directly drive a motor.

19. Interview Questions and Answers

Q1. Which header file is commonly used for LPC2129 programming?

LPC21xx.h, provided by the device support package.

Q2. Which register controls PWM timer enable?

PWMTCR.

Q3. Which register controls the PWM period?

PWMMR0.

Q4. Which register enables PWM output channels?

PWMPCR.

Q5. Which register latches match values?

PWMLER.

Q6. What is the timer tick with PCLK = 15 MHz and PWMPR = 14?

1 microsecond.

Q7. What is the nominal frequency when MR0 = 1000 and the timer tick is 1 microsecond?

Approximately 1 kHz.

Q8. How can duty cycle be changed without changing frequency?

Modify the channel match value while keeping MR0 and PWMPR unchanged.

Q9. Why is PINSEL required?

It selects the alternate PWM peripheral function on the physical pin.

Q10. Why is a motor driver needed?

The MCU pin cannot supply the motor's required voltage and current. A suitable external driver stage is needed.

22. Lesson Summary

  • LPC2129 PWM can be programmed using Embedded C and peripheral registers.
  • PWMPR controls the timer tick interval.
  • MR0 determines the common PWM period.
  • MR1 to MR6 determine channel edge positions.
  • PWMMCR controls match actions.
  • PWMPCR enables PWM outputs and selects double-edge operation.
  • PWMLER synchronizes match-register updates.
  • PWMTCR enables the PWM timer and PWM mode.
  • PINSEL must be configured separately for physical PWM pins.
