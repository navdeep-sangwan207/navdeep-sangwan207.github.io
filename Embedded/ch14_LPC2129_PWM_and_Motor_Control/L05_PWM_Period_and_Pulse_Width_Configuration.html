Lesson 05: PWM Period and Pulse Width Configuration

Learn how to configure PWM frequency, period, pulse width, and duty cycle using the LPC2129 PWM peripheral.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand PWM period and pulse width.
  • Calculate PWM frequency from the peripheral clock.
  • Configure the PWM prescaler.
  • Calculate the required MR0 value.
  • Calculate channel match values for different duty cycles.
  • Configure PWM registers using Embedded C.
  • Change PWM duty cycle while keeping frequency constant.
  • Identify common PWM configuration errors.

2. PWM Period

A PWM period is the time required to complete one full PWM cycle. It includes the HIGH interval and the LOW interval. 

        One complete PWM period

        HIGH             LOW
      ┌─────────┐
      │         │
──────┘         └────────────────────
      |         |                    |
      |<-- HIGH -->|<----- LOW ------>|
      |<---------- Period ---------->|
Definition: PWM period is the total time for one complete repetition of the PWM waveform.
PWM Period = 1 / PWM Frequency

Example

If PWM frequency is 1 kHz:

Period = 1 / 1000 = 0.001 seconds = 1 ms

3. PWM Pulse Width

Pulse width is the time for which the PWM signal remains HIGH during one PWM period. 

      25% Duty Cycle

      HIGH        LOW
      ┌───┐
      │   │
──────┘   └──────────────────────────
      |   |                          |
      |   |<--------- 75% ---------->|
      |<--25%-->|
      |<--------- 100% Period ------>|

Pulse width is important in applications such as motor speed control, LED brightness control, and switching power supplies.

4. Duty Cycle

Duty cycle represents the percentage of the total PWM period during which the signal remains HIGH.

Duty Cycle = (HIGH Time / PWM Period) × 100

5. PWM Clock and Prescaler Calculation

The PWM peripheral uses PCLK as its input clock. The PWM prescaler determines how many PCLK cycles occur before PWMTC increments.

Timer Tick Frequency = PCLK / (PWMPR + 1)
Timer Tick Interval = (PWMPR + 1) / PCLK

Example: Generate a 1 MHz Timer Tick

Given:

  • PCLK = 15 MHz
  • Required timer tick = 1 MHz
PWMPR + 1 = 15 MHz / 1 MHz = 15
PWMPR = 14
PWMPR = 14U;
PWMTC increments once every 1 microsecond.

6. PWM Period Configuration Using MR0

MR0 establishes the PWM period. The PWM match-control register must be configured to reset the counter when MR0 matches.

Nominal PWM Period = MR0 × Timer Tick Interval
PWM Frequency ≈ PCLK / [(PWMPR + 1) × MR0]

Example: Configure 1 kHz PWM

Given:

  • PCLK = 15 MHz
  • PWMPR = 14
  • Timer tick = 1 µs
  • Required frequency = 1 kHz

Required period:

Period = 1 / 1000 = 1 ms

Required match value:

MR0 = 1 ms / 1 µs = 1000
PWMPR = 14U; PWMMR0 = 1000U; PWMMCR = (1U << 1);
The MR0 reset action is essential for continuous period generation. The equations give nominal timing; verify exact boundary behavior against the LPC2129 PWM peripheral documentation.

7. Pulse Width Configuration Using Channel Match Registers

In single-edge mode, the channel match register determines the falling-edge position within the period.

Channel Match Value ≈ (Duty Cycle / 100) × MR0

Example 1: 25% Duty Cycle

MR1 = 0.25 × 1000 = 250
PWMMR0 = 1000U; PWMMR1 = 250U;

Example 2: 50% Duty Cycle

MR1 = 0.50 × 1000 = 500
PWMMR0 = 1000U; PWMMR1 = 500U;

Example 3: 75% Duty Cycle

MR1 = 0.75 × 1000 = 750
PWMMR0 = 1000U; PWMMR1 = 750U;
These examples assume normal single-edge operation. A channel match should be within the valid period range. Exact endpoint behavior is device-specific.

8. Complete PWM Configuration Example

This example configures PWM1 with a nominal frequency of 1 kHz and a duty cycle of 25%.

#include <LPC21xx.h> void PWM1_Init(void) { /* Reset PWM peripheral counter */ PWMTCR = (1U << 1); /* Configure prescaler for 1 MHz timer tick */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Configure period */ PWMMR0 = 1000U; /* Configure PWM1 pulse width */ PWMMR1 = 250U; /* Reset PWM counter on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM1 output */ PWMPCR = (1U << 9); /* Latch period and pulse-width values */ PWMLER = (1U << 0) | (1U << 1); /* Enable counter and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); } int main(void) { PWM1_Init(); while (1) { /* PWM is generated by peripheral hardware */ } }

Program Explanation

  1. Reset the PWM timer.
  2. Configure the prescaler for a 1 MHz timer tick.
  3. Set MR0 to 1000 for a nominal 1 ms period.
  4. Set MR1 to 250 for approximately 25% duty cycle.
  5. Configure counter reset on MR0 match.
  6. Enable PWM1 output.
  7. Latch MR0 and MR1.
  8. Enable PWM timer and PWM mode.
The physical PWM output pin must be configured through PINSEL separately. Select the correct PWM1 pin using the LPC2129 pin-multiplexing table. This program does not configure a motor driver or external load.

9. Changing Duty Cycle Without Changing Frequency

A common PWM application requires changing the duty cycle while maintaining a constant frequency.

To achieve this:

  • Keep PWMPR unchanged.
  • Keep MR0 unchanged.
  • Modify the channel match register.
  • Set the corresponding PWMLER bit.

Example: Change PWM1 Duty Cycle to 60%

void PWM1_SetDuty60(void) { PWMMR1 = 600U; /* Request MR1 update */ PWMLER = (1U << 1); }

With MR0 = 1000, the new channel match value represents approximately 60% duty cycle.

The new match value is transferred at the PWM latch boundary. Avoid changing MR0 and channel match values independently if a coordinated period/duty update is required; latch all affected registers together.

11. PWM Configuration for Multiple Channels

LPC2129 PWM supports multiple output channels. In single-edge mode, each channel can have a different pulse width while sharing the common MR0 period.

Example: Three PWM Channels

/* Common period */ PWMMR0 = 1000U; /* PWM channel match values */ PWMMR1 = 250U; /* PWM1: 25% */ PWMMR2 = 500U; /* PWM2: 50% */ PWMMR3 = 750U; /* PWM3: 75% */ /* Reset on MR0 */ PWMMCR = (1U << 1); /* Enable PWM1, PWM2 and PWM3 */ PWMPCR = (1U << 9) | (1U << 10) | (1U << 11); /* Latch MR0 to MR3 */ PWMLER = 0x0FU;
Channel Match Register Duty Cycle
PWM1MR1 = 25025%
PWM2MR2 = 50050%
PWM3MR3 = 75075%

All three channels use the same nominal 1 kHz period but have different duty cycles.

The code demonstrates register configuration. Configure the correct pin functions for each enabled channel before using the outputs on physical hardware.

12. Practical Applications

  • DC motor speed control: Adjust average motor voltage through a suitable driver.
  • LED brightness: Change the duty cycle to control average LED current.
  • Power converters: Generate switching control pulses.
  • Heater control: Control delivered power using an appropriate switching stage.
  • Servo control: Generate pulses with application-specific timing requirements.

14. Common Mistakes

  • Using CCLK instead of PCLK in PWM calculations.
  • Forgetting that the prescaler divides by PWMPR + 1.
  • Using an incorrect MR0 value for the desired frequency.
  • Using a channel match value outside the period range.
  • Forgetting the MR0 reset action in PWMMCR.
  • Forgetting to enable the channel in PWMPCR.
  • Forgetting to latch updated match values through PWMLER.
  • Assuming a register change immediately changes the physical output.
  • Trying to drive a motor directly from an MCU pin.

15. Interview Questions and Answers

Q1. What is PWM period?

The total time required for one complete PWM cycle.

Q2. What is pulse width?

The duration for which the PWM signal remains HIGH in a cycle.

Q3. What is duty cycle?

The percentage of the PWM period during which the signal remains HIGH.

Q4. Which register controls the PWM period?

PWMMR0.

Q5. Which register controls the PWM1 pulse-width match?

PWMMR1 in single-edge mode.

Q6. How is timer tick frequency calculated?

PCLK divided by PWMPR plus one.

Q7. How can duty cycle be changed without changing frequency?

Keep MR0 and PWMPR unchanged, modify the channel match register, and request the update through PWMLER.

Q8. What is the purpose of PWMLER?

It synchronizes new match-register values with the PWM peripheral.

Q9. Can multiple PWM channels have different duty cycles?

Yes. In single-edge mode, multiple channels can share MR0 while using separate channel match values.

Q10. Why is a motor driver required?

An MCU output pin cannot safely supply the voltage and current required by a motor. A suitable driver stage is required.

18. Lesson Summary

  • PWM period is the duration of one complete cycle.
  • Pulse width is the HIGH duration.
  • Duty cycle is the percentage of the period spent HIGH.
  • PWMPR determines the timer tick interval.
  • MR0 determines the common PWM period.
  • Channel match registers determine output edge positions.
  • PWMMCR configures match actions.
  • PWMLER synchronizes match-register updates.
  • Multiple channels can share a period and have different duty cycles.
