Lesson 06: PWM Single-Edge and Double-Edge Control

Understand the two PWM edge-generation modes supported by the LPC2129 PWM peripheral and configure output channels using match registers and PWMPCR.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Explain single-edge PWM generation.
  • Explain double-edge PWM generation.
  • Compare single-edge and double-edge operation.
  • Understand the PWMPCR double-edge control bits.
  • Identify the match-register pairs used by each channel.
  • Calculate pulse positions and duty cycle.
  • Configure PWM output channels in Embedded C.
  • Understand practical applications of both modes.

2. Introduction to PWM Edge Control

A PWM waveform consists of HIGH and LOW intervals. The transitions between these intervals are called edges.

  • Rising edge: Signal changes from LOW to HIGH.
  • Falling edge: Signal changes from HIGH to LOW.
LOW  _______                 _______
            |               |
            |               |
            └───────────────┘
            Rising edge     Falling edge

The LPC2129 PWM peripheral supports single-edge and double-edge output control. These modes determine how the match registers position the output transitions within a PWM period.

3. Single-Edge PWM

Definition: In single-edge PWM mode, the PWM period is common to the enabled outputs. The channel match register determines the falling-edge position of each output.

MR0 establishes the period. At the start of a new PWM period, the single-edge PWM outputs are set HIGH. Their corresponding channel match events clear the outputs.

Characteristics

  • MR0 defines the common PWM period.
  • Each channel has its own falling-edge match position.
  • Multiple channels can operate at the same frequency.
  • Different channels can have different duty cycles.
  • Single-edge mode is suitable for many motor and LED applications.

4. Double-Edge PWM

Definition: Double-edge PWM allows the rising and falling edges of a PWM output to be positioned independently within the common PWM period.

In double-edge mode, two match registers are used for a channel. One match event controls one edge, and the other match event controls the opposite edge. 

Example: Double-edge PWM

Period: MR0 = 1000

Timer count:
0        200                  600       1000
|---------|--------------------|----------|

PWM output:
_________┌────────────────────┐__________
         ^                    ^
         |                    |
      Rising edge          Falling edge

Unlike single-edge mode, the pulse does not necessarily begin at the start of the period. Its position can be moved within the period by changing the two channel match values.

PWM1 cannot be independently configured for double-edge operation because MR0 is reserved for the common PWM period. Double-edge capability is available for PWM2 through PWM6.

A double-edge control bit selects double-edge operation for its corresponding channel. A zero selects single-edge operation. Output enable and edge-mode selection are separate controls.

7. Configuring Single-Edge PWM

The following example configures PWM1, PWM2, and PWM3 in single-edge mode.

#include <LPC21xx.h> void PWM_SingleEdge_Init(void) { /* Reset PWM peripheral */ PWMTCR = (1U << 1); /* PCLK = 15 MHz; timer tick = 1 MHz */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Common PWM period */ PWMMR0 = 1000U; /* Channel match values */ PWMMR1 = 250U; PWMMR2 = 500U; PWMMR3 = 750U; /* Reset counter on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM1, PWM2 and PWM3 */ PWMPCR = (1U << 9) | (1U << 10) | (1U << 11); /* Latch MR0, MR1, MR2 and MR3 */ PWMLER = 0x0FU; /* Enable PWM counter and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); } int main(void) { PWM_SingleEdge_Init(); while (1) { } }

8. Configuring Double-Edge PWM

The following example demonstrates the register setup for double-edge operation on PWM2.

#include <LPC21xx.h> void PWM2_DoubleEdge_Init(void) { /* Reset PWM peripheral */ PWMTCR = (1U << 1); /* Configure 1 MHz timer tick */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Common PWM period */ PWMMR0 = 1000U; /* PWM2 edge positions */ PWMMR1 = 200U; PWMMR2 = 600U; /* Reset on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM2 and select double-edge mode */ PWMPCR = (1U << 10) | (1U << 2); /* Latch MR0, MR1 and MR2 */ PWMLER = (1U << 0) | (1U << 1) | (1U << 2); /* Enable PWM timer and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); } int main(void) { PWM2_DoubleEdge_Init(); while (1) { } }

Program Explanation

  1. Reset the PWM peripheral.
  2. Configure the prescaler for a 1 MHz timer tick.
  3. Set MR0 to establish the PWM period.
  4. Set MR1 and MR2 as the two PWM2 edge positions.
  5. Configure MR0 reset action.
  6. Set PWMPCR bit 10 to enable PWM2.
  7. Set PWMPCR bit 2 to select double-edge mode for PWM2.
  8. Latch MR0, MR1, and MR2.
  9. Enable PWM timer and PWM mode.
The example demonstrates register selection and match pairing. Before using it on hardware, verify edge ordering, output polarity, and valid match-value ranges against the LPC2129 PWM chapter. Configure the PWM2 pin function separately through PINSEL.

9. Double-Edge Configuration for Multiple Channels

Double-edge mode can be selected independently for PWM2 through PWM6, subject to the shared match-register arrangement.

/* Common period */ PWMMR0 = 1000U; /* PWM2 edge pair */ PWMMR1 = 200U; PWMMR2 = 600U; /* PWM3 edge pair */ PWMMR2 = 250U; PWMMR3 = 700U; /* Select PWM2 and PWM3 double-edge modes */ PWMPCR = (1U << 10) | (1U << 11) | (1U << 2) | (1U << 3);
Adjacent channels share match registers in double-edge mode. For example, MR2 participates in the match pair for PWM2 and PWM3. Therefore, do not treat the match values of adjacent double-edge channels as independent. Plan all channel match values together and verify the permitted combinations in the NXP user manual.

10. Applications of Single-Edge PWM

  • DC motor speed control.
  • LED brightness control.
  • Switching power supply control.
  • Heater power regulation.
  • General-purpose PWM output generation.

11. Applications of Double-Edge PWM

  • Pulse-position control.
  • Applications requiring independently positioned pulse edges.
  • Specialized switching waveform generation.
  • Timing-sensitive control signals.

13. Common Mistakes

  • Confusing single-edge and double-edge match-register usage.
  • Trying to configure PWM1 for independent double-edge operation.
  • Enabling an output without configuring its pin function.
  • Forgetting the corresponding PWMLER bits.
  • Using the same match register without considering adjacent channel pairing.
  • Changing match values without checking their order and valid range.
  • Assuming output enable alone selects double-edge mode.
  • Assuming the Keil simulator always displays physical PWM waveforms.

14. Interview Questions and Answers

Q1. What is single-edge PWM?

Single-edge PWM uses a common period boundary and one channel match value to position the channel's falling edge.

Q2. What is double-edge PWM?

Double-edge PWM uses two match values to position the rising and falling edges independently within a period.

Q3. Which register selects double-edge operation?

PWMPCR.

Q4. Which channels support double-edge mode?

PWM2 through PWM6.

Q5. Why is PWM1 not independently double-edge controlled?

MR0 is reserved for the common PWM period, so PWM1 does not have its own independent pair of match registers.

Q6. Which PWMPCR bit selects double-edge mode for PWM2?

Bit 2.

Q7. Which PWMPCR bit enables PWM2 output?

Bit 10.

Q8. Why are match registers shared in double-edge mode?

The peripheral uses adjacent match-register pairs for edge positioning. This creates shared register usage between neighboring channels.

Q9. Can PWM2 and PWM3 use double-edge mode simultaneously?

Their double-edge selection bits can be enabled, but their adjacent match-register pairing shares MR2. The desired edge values must therefore be planned together and checked for a valid configuration.

Q10. What is the purpose of PWMLER?

It requests synchronized transfer of new match-register values into the active PWM registers.

17. Lesson Summary

  • Single-edge PWM uses one channel match value for the falling edge.
  • Double-edge PWM uses two match values for two independently positioned edges.
  • MR0 establishes the common PWM period.
  • PWM1 supports single-edge operation only.
  • PWM2 through PWM6 support double-edge operation.
  • PWMPCR controls output enable and double-edge selection.
  • PWMLER synchronizes match-register updates.
  • Adjacent channels can share match registers in double-edge mode.
