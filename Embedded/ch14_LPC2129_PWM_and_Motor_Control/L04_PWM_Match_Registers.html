Lesson 04: PWM Match Registers

Understand how LPC2129 PWM match registers control the PWM period, output pulse width, edge positions, and match-related actions.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Explain the purpose of PWM match registers.
  • Identify the functions of PWMMR0 to PWMMR6.
  • Understand how MR0 determines the PWM period.
  • Calculate PWM frequency using the timer tick and MR0.
  • Calculate duty cycle using a channel match value.
  • Understand match events and their control actions.
  • Explain match-register pairings in single-edge and double-edge modes.
  • Program basic match-register values in Embedded C.

2. Introduction to PWM Match Registers

Match registers are programmable registers used by the LPC2129 PWM peripheral to determine when specific events occur during a PWM cycle.

The PWM timer counter (PWMTC) continuously increments according to the peripheral clock and prescaler. Its current value is compared with the programmed match register values.

Definition: A PWM match register stores a timer count value. When PWMTC reaches that value, the PWM peripheral recognizes a match event and performs the configured action.

The LPC2129 provides seven match registers: PWMMR0, PWMMR1, PWMMR2, PWMMR3, PWMMR4, PWMMR5, and PWMMR6.

Each match register can be compared against PWMTC. The result of a match is used by the PWM control logic and the match-control configuration.

4. PWMMR0 – PWM Period Register

PWMMR0 is the primary period match register. It establishes the timer count at which the PWM cycle is restarted when the MR0 reset action is enabled.

The timer counter counts upward. When PWMTC matches MR0, the configured reset action resets the counter and begins another PWM period.

Example

PWMMR0 = 1000U; PWMMCR = (1U << 1); /* Reset PWMTC on MR0 match */

If the timer tick interval is 1 microsecond, MR0 = 1000 gives a nominal PWM period of approximately 1 millisecond.

PWM Period ≈ MR0 × Timer Tick Interval
PWM Frequency ≈ 1 / PWM Period
The equations describe the nominal timer-count relationship. Exact boundary timing depends on the counter's starting state and the peripheral's match/reset sequence.

5. PWMMR1 to PWMMR6 – Channel Match Registers

The channel match registers determine the positions of PWM output transitions within the period.

In single-edge mode, MR0 establishes the beginning of each PWM cycle. The corresponding channel match register determines when the output becomes LOW.

Register Single-Edge Channel Function
PWMMR1 PWM1 Sets PWM1 falling-edge position.
PWMMR2 PWM2 Sets PWM2 falling-edge position.
PWMMR3 PWM3 Sets PWM3 falling-edge position.
PWMMR4 PWM4 Sets PWM4 falling-edge position.
PWMMR5 PWM5 Sets PWM5 falling-edge position.
PWMMR6 PWM6 Sets PWM6 falling-edge position.
In double-edge mode, channels 2 to 6 use two match values to define their two edge positions. MR0 remains reserved for the common PWM period. PWM1 does not support independent double-edge positioning.

6. Match Event Operation

A match event occurs when the timer counter reaches the value stored in a match register.

For example, if:

  • PWMTC starts at zero.
  • PWMMR0 = 1000.
  • PWMMR1 = 250.

The PWM1 match event occurs when the timer reaches 250, and the MR0 period event occurs when the timer reaches 1000. 

Timer count:

0             250                         1000
|--------------|----------------------------|
               ^                            ^
               |                            |
          MR1 match                      MR0 match
          PWM1 LOW                       Period reset

PWM1 output:

HIGH           LOW
|--------------|----------------------------|
      250 counts       Remaining period

This illustrates the basic single-edge concept. The exact output transition behavior is controlled by the PWM peripheral's match and output-control logic.

7. PWM Match Control Register (PWMMCR)

PWMMCR determines whether a match event generates an interrupt, resets the timer, or stops the timer.

Match Interrupt Reset Stop
MR0Bit 0Bit 1Bit 2
MR1Bit 3Bit 4Bit 5
MR2Bit 6Bit 7Bit 8
MR3Bit 9Bit 10Bit 11
MR4Bit 12Bit 13Bit 14
MR5Bit 15Bit 16Bit 17
MR6Bit 18Bit 19Bit 20

Example 1: Reset on MR0 Match

PWMMCR = (1U << 1);

Example 2: Interrupt and Reset on MR0 Match

PWMMCR = (1U << 0) | (1U << 1);

Example 3: Stop on MR0 Match

PWMMCR = (1U << 2);
For continuous PWM operation, resetting the counter on MR0 is commonly used. Enabling the stop action on MR0 instead stops the timer when that match occurs.

8. PWM Period and Frequency Calculation

The timer tick interval is determined by PCLK and PWMPR.

Timer Tick = (PWMPR + 1) / PCLK

The nominal PWM period is then determined by the MR0 count value.

PWM Period ≈ MR0 × Timer Tick
PWM Frequency ≈ PCLK / [(PWMPR + 1) × MR0]

Numerical Example

Given:

  • PCLK = 15 MHz.
  • PWMPR = 14.
  • PWMMR0 = 1000.

Timer tick frequency:

15,000,000 / 15 = 1,000,000 Hz

Timer tick interval:

1 / 1,000,000 = 1 µs

Nominal PWM period:

1000 × 1 µs = 1 ms

Nominal PWM frequency:

1 / 0.001 = 1000 Hz = 1 kHz
The configuration produces a nominal 1 kHz PWM period.

9. Duty Cycle Calculation Using Match Registers

Duty cycle is the percentage of one PWM period during which the output remains HIGH.

Duty Cycle = (HIGH Time / Total Period) × 100

In single-edge mode, when MR0 defines the period and the channel match register defines the falling edge:

Duty Cycle ≈ (Channel Match / MR0) × 100

Example 1: 25% Duty Cycle

PWMMR0 = 1000U; PWMMR1 = 250U;
Duty Cycle ≈ (250 / 1000) × 100 = 25%

Example 2: 50% Duty Cycle

PWMMR0 = 1000U; PWMMR1 = 500U;
Duty Cycle ≈ (500 / 1000) × 100 = 50%

Example 3: 75% Duty Cycle

PWMMR0 = 1000U; PWMMR1 = 750U;
Duty Cycle ≈ (750 / 1000) × 100 = 75%
These calculations assume normal single-edge operation and a channel match value between zero and the period match. Boundary values and special output states should be checked against the device manual.

10. Match Register Updates and PWMLER

When software changes a match-register value, the new value must be transferred into the active PWM match register using the corresponding PWMLER bit.

This mechanism allows updates to occur at a controlled PWM boundary rather than changing the active timing in the middle of a cycle.

Example: Change PWM1 Duty Cycle

/* Existing period */ PWMMR0 = 1000U; /* New PWM1 pulse-width match */ PWMMR1 = 600U; /* Request MR1 update */ PWMLER = (1U << 1);

The new MR1 value is requested for transfer at the appropriate PWM latch point.

If multiple match values must change together, write all required values first and then set all corresponding latch bits in one PWMLER write.

11. Single-Edge and Double-Edge Match Pairing

Single-Edge Mode

In single-edge mode, MR0 defines the common period and each enabled channel uses its corresponding match register to determine the falling-edge position.

Double-Edge Mode

In double-edge mode, the PWM output can have independently positioned rising and falling edges within a PWM period. This is useful when pulse placement must be controlled separately from the period boundary.

Channel Single-Edge Match Double-Edge Match Pair
PWM1MR1Not independently supported
PWM2MR2MR1 and MR2
PWM3MR3MR2 and MR3
PWM4MR4MR3 and MR4
PWM5MR5MR4 and MR5
PWM6MR6MR5 and MR6

The double-edge match pairing uses adjacent match registers. The exact output transition behavior and edge ordering must be configured according to the PWM peripheral specification.

12. Embedded C Program: Configure PWM1 Match Values

The following example configures PWM1 for a nominal 1 kHz output with approximately 25% duty cycle.

#include <LPC21xx.h> void PWM1_Init(void) { /* Reset PWM timer */ PWMTCR = (1U << 1); /* Configure 1 MHz timer tick */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Configure period and pulse width */ PWMMR0 = 1000U; PWMMR1 = 250U; /* Reset counter on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM1 output */ PWMPCR = (1U << 9); /* Latch MR0 and MR1 */ PWMLER = (1U << 0) | (1U << 1); /* Enable timer and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); } int main(void) { PWM1_Init(); while (1) { /* PWM hardware controls the output */ } }

Program Explanation

  1. Reset the PWM timer.
  2. Configure PWMPR for a 1 MHz timer tick.
  3. Set MR0 to 1000 for the nominal period.
  4. Set MR1 to 250 for the PWM1 falling-edge position.
  5. Configure MR0 reset action in PWMMCR.
  6. Enable PWM1 through PWMPCR.
  7. Request MR0 and MR1 latch updates.
  8. Enable the PWM timer and PWM mode.
This is a peripheral-register example. Configure the correct PWM1 pin function through PINSEL before expecting the waveform on a physical pin. The exact pin assignment must be checked against the LPC2129 pin-multiplexing table.

13. Practical Applications of Match Registers

  • DC motor speed control using PWM duty-cycle adjustment.
  • LED brightness control.
  • Power converter switching control.
  • Servo control pulse generation, subject to timing requirements.
  • Multiple PWM output generation with different pulse widths.
  • Controlled pulse positioning in embedded applications.
A microcontroller PWM pin cannot drive a motor directly. Physical motor control requires an appropriate driver stage, external power supply, and protection circuitry.

15. Common Mistakes

  • Using CCLK instead of PCLK for timer calculations.
  • Ignoring the PWMPR + 1 relationship.
  • Programming MR0 without enabling its reset action.
  • Using a channel match value greater than the period value.
  • Forgetting to enable the PWM channel in PWMPCR.
  • Forgetting to set the relevant PWMLER latch bit.
  • Confusing match-register values with microseconds without calculating the timer tick.
  • Assuming all channels support double-edge operation independently.
  • Assuming PWM register configuration automatically selects the physical output pin.

16. Interview Questions and Answers

Q1. How many match registers are available in LPC2129 PWM?

Seven match registers, MR0 through MR6.

Q2. What is the main purpose of MR0?

MR0 establishes the PWM period and repetition rate.

Q3. Which register determines the PWM1 falling edge in single-edge mode?

PWMMR1.

Q4. What happens when PWMTC equals MR0?

The MR0 match event occurs. The configured match-control action can reset the counter, generate an interrupt, or stop the timer.

Q5. Which register controls match actions?

PWMMCR.

Q6. Which register enables PWM output channels?

PWMPCR.

Q7. What is the purpose of PWMLER?

It requests synchronized transfer of new match-register values.

Q8. How is PWM frequency calculated?

First calculate the timer tick from PCLK and PWMPR. Then calculate the nominal period using MR0 and take its reciprocal.

Q9. Can PWM1 use independent double-edge positioning?

No. MR0 is reserved for the common PWM period, so PWM1 does not have the independent double-edge match pair available to channels 2 through 6.

Q10. Why are match-register updates latched?

To synchronize new timing values with a PWM cycle boundary and avoid unintended mid-cycle changes.
