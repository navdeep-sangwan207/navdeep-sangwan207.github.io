Lesson 03: LPC2129 PWM Architecture

Understand the internal architecture of the LPC2129 PWM peripheral, including its prescaler, timer counter, match registers, PWM control logic, latch enable mechanism, and output channels.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Explain the architecture of the LPC2129 PWM peripheral.
  • Understand the relationship between PCLK, PWMPR, PWMPC, and PWMTC.
  • Identify the functions of match registers MR0 to MR6.
  • Understand the PWM Match Control Register.
  • Explain the roles of PWMPCR and PWMLER.
  • Understand the six PWM output channels.
  • Describe the basic PWM initialization sequence.
  • Inspect PWM registers during Keil uVision debugging.

2. Introduction to LPC2129 PWM Architecture

The LPC2129 microcontroller contains a dedicated Pulse Width Modulator peripheral. It is based on the standard timer architecture and uses a 32-bit timer counter, a programmable prescaler, seven match registers, and PWM output-control logic.

The peripheral generates up to six PWM output channels. The PWM hardware controls the output transitions using match events, reducing the need for software to toggle GPIO pins continuously.

Definition: The LPC2129 PWM peripheral is a hardware timing and output control unit that generates periodic pulse-width-modulated signals using timer counting and match-register comparisons.

Main Architectural Blocks

  • Peripheral clock input (PCLK).
  • Prescale Register (PWMPR).
  • Prescale Counter (PWMPC).
  • Timer Counter (PWMTC).
  • Match Registers (PWMMR0 to PWMMR6).
  • Match Control Register (PWMMCR).
  • PWM Control Register (PWMPCR).
  • PWM Latch Enable Register (PWMLER).
  • PWM output logic and pin multiplexing.

4. Peripheral Clock (PCLK)

The PWM peripheral receives its timing reference from the peripheral clock, PCLK.

The timer counter does not necessarily increment on every PCLK cycle. Its increment rate is controlled by the prescaler.

In your LPC2129 clock configuration:

  • Oscillator frequency (FOSC) = 12 MHz.
  • CPU clock (CCLK) = 60 MHz.
  • Peripheral clock (PCLK) = 15 MHz.
  • Peripheral clock divider ratio = 4.
PCLK = 60 MHz / 4 = 15 MHz

Therefore, the PWM prescaler receives a 15 MHz clock in this configuration.

Important: PCLK is the input clock to the PWM timing section. It is not necessarily the final PWM output frequency. The prescaler and match-register period determine the PWM timing.

5. Prescaler and Prescale Counter

5.1 PWM Prescale Register (PWMPR)

PWMPR determines how many PCLK cycles are counted before the PWM timer counter is incremented.

PWMTC increment interval = (PWMPR + 1) / PCLK

For a PCLK of 15 MHz and PWMPR = 14:

Timer tick frequency = 15 MHz / (14 + 1) = 1 MHz
The PWM timer counter increments once every 1 microsecond.

5.2 PWM Prescale Counter (PWMPC)

PWMPC is the internal prescale counter. It increments with the peripheral clock and is compared against PWMPR. When the prescale count reaches the programmed value, the timer counter is incremented and the prescale counter starts another counting interval.

Example: PWMPR = 4

PCLK cycles:       0   1   2   3   4   5   6 ...
Prescale count:    0   1   2   3   4   0   1 ...
Timer counter:     0   0   0   0   0   1   1 ...
                                      ^
                              Timer increments

The timer counter increments once for every PWMPR + 1 peripheral clock cycles.

6. PWM Timer Counter (PWMTC)

PWMTC is a 32-bit counter used to track PWM timing. It increments according to the prescaler configuration.

The value of PWMTC is continuously compared with the programmed match-register values.

Main Functions

  • Provides the timing reference for PWM generation.
  • Increments according to PWMPR and PWMPC.
  • Is compared with match registers MR0 to MR6.
  • Can be reset by a configured match event.
  • Can be enabled or reset through PWMTCR.

PWM Timer Control Register (PWMTCR)

Bit Symbol Function
0 Counter Enable Enables the PWM timer counter and prescale counter.
1 Counter Reset Resets PWMTC and PWMPC while asserted.
2 Reserved Do not write a 1 to reserved bits.
3 PWM Enable Enables PWM mode.

Common configurations:

PWMTCR = 0x02
Reset PWM timer and prescale counter
PWMTCR = 0x09
Enable counter and PWM mode
The reset bit must be released after initialization. Do not leave PWMTCR bit 1 set when expecting the counter to run.

7. PWM Match Registers (PWMMR0 to PWMMR6)

The LPC2129 PWM peripheral contains seven 32-bit match registers. The timer counter value is continuously compared against these registers.

When PWMTC equals a match-register value, the corresponding match event can control a PWM output and may also generate an interrupt, reset the timer, or stop it if configured.

Register Main PWM Function
PWMMR0 Defines the PWM cycle rate and starts a new cycle.
PWMMR1 Controls PWM1 edge and can participate in PWM2 double-edge control.
PWMMR2 Controls PWM2 edge and can participate in PWM3 double-edge control.
PWMMR3 Controls PWM3 edge and can participate in PWM4 double-edge control.
PWMMR4 Controls PWM4 edge and can participate in PWM5 double-edge control.
PWMMR5 Controls PWM5 edge and can participate in PWM6 double-edge control.
PWMMR6 Controls the PWM6 edge.
Important relationship: MR0 establishes the common PWM repetition rate. The remaining match registers determine the edge positions for the individual PWM outputs.

In single-edge mode, MR0 sets the beginning of each PWM cycle and the corresponding channel match register determines when that output goes LOW.

In double-edge mode, two match registers are used to determine the two edge positions of a channel. PWM1 cannot provide an independently positioned double-edge waveform because MR0 is already used for the period.

8. PWM Match Control Register (PWMMCR)

PWMMCR controls what happens when the PWM timer counter matches one of the match registers.

For each match register, three control bits are provided:

  • Interrupt: Generates an interrupt on match.
  • Reset: Resets the PWM timer counter on match.
  • Stop: Stops the PWM timer and prescale counter on match.

Example: Reset PWMTC on MR0 Match

PWMMCR = (1U << 1);

This enables the reset action when MR0 matches PWMTC. It does not enable an interrupt.

For continuous PWM generation, the MR0 reset action is normally enabled so the timer begins another PWM cycle after reaching the period match.

9. PWM Control Register (PWMPCR)

PWMPCR controls which PWM output channels are enabled and selects single-edge or double-edge operation for channels that support the selection.

PWMPCR also contains selection bits for PWM channels 2 to 6. These bits select whether the corresponding output uses single-edge or double-edge control.

PWM1 does not have an independent double-edge selection because MR0 is used to define the PWM period. The detailed channel behavior is covered in Lesson 06.

10. PWM Latch Enable Register (PWMLER)

PWMLER controls when newly written match-register values become active.

The PWM peripheral uses shadow registers so that a new period or pulse-width value can be transferred at a controlled point in the PWM cycle.

This prevents an update from changing the output at an arbitrary point in the current cycle and producing an unintended pulse.

Bit Function
0Latch new MR0 value
1Latch new MR1 value
2Latch new MR2 value
3Latch new MR3 value
4Latch new MR4 value
5Latch new MR5 value
6Latch new MR6 value

Example

PWMMR0 = 1000U; PWMMR1 = 250U; /* Request transfer of new MR0 and MR1 values */ PWMLER = (1U << 0) | (1U << 1);

The latch request allows the new match values to take effect at the PWM update boundary. Software should write the new values first and then set the corresponding PWMLER bits.

11. PWM Output Channels

The LPC2129 PWM peripheral provides six output channels: PWM1, PWM2, PWM3, PWM4, PWM5, and PWM6.

Channel Output Single-Edge Match
1PWM1MR0 sets; MR1 clears
2PWM2MR0 sets; MR2 clears
3PWM3MR0 sets; MR3 clears
4PWM4MR0 sets; MR4 clears
5PWM5MR0 sets; MR5 clears
6PWM6MR0 sets; MR6 clears

In single-edge mode, the outputs normally become HIGH at the beginning of each PWM period and become LOW when their individual match event occurs.

The table describes single-edge operation. In double-edge mode, the match-register pairings differ. Refer to the PWM channel selection rules in Lesson 06.

12. PWM Timing Example Using Project Clock

Use the following project clock and timer configuration:

  • PCLK = 15 MHz.
  • PWMPR = 14.
  • Timer counter tick frequency = 1 MHz.
  • Timer counter tick interval = 1 microsecond.
  • PWMMR0 = 1000.
  • PWMMR1 = 250.

Step 1: Calculate Timer Tick Frequency

fTC = 15 MHz / (14 + 1) = 1 MHz

Step 2: Calculate Timer Tick Interval

Ttick = 1 / 1 MHz = 1 µs

Step 3: Calculate Nominal PWM Period

TPWM ≈ 1000 × 1 µs = 1 ms

Step 4: Calculate Nominal Frequency

fPWM ≈ 1 / 1 ms = 1 kHz

Step 5: Calculate PWM1 Duty Cycle

Duty Cycle ≈ (250 / 1000) × 100 = 25%
Nominal result: The example is configured for approximately 1 kHz PWM with a 25% HIGH duty cycle on PWM1.

The exact period follows the peripheral's timer and match event sequencing. The calculation above is the nominal timer-count relationship used for configuration.

13. Basic PWM Initialization Program

The following example demonstrates the main PWM register configuration sequence for PWM1 in single-edge mode.

#include <LPC21xx.h> void PWM_Init(void) { /* Stop and reset PWM timer */ PWMTCR = (1U << 1); /* Configure prescaler: PCLK = 15 MHz PWMPR = 14 Timer tick = 1 MHz */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* Set PWM period */ PWMMR0 = 1000U; /* PWM1 pulse width match */ PWMMR1 = 250U; /* Reset timer on MR0 match */ PWMMCR = (1U << 1); /* Single-edge mode: PWM1 output enable is PCR bit 9 */ PWMPCR = (1U << 9); /* Latch MR0 and MR1 */ PWMLER = (1U << 0) | (1U << 1); /* Enable PWM timer and PWM mode */ PWMTCR = (1U << 0) | (1U << 3); } int main(void) { PWM_Init(); while (1) { /* PWM is generated by the hardware peripheral */ } }

Program Explanation

  1. PWMTCR resets the timer and prescale counter.
  2. PWMPR sets the timer counter increment interval.
  3. PWMPC and PWMTC are initialized to zero.
  4. PWMMR0 defines the nominal PWM period.
  5. PWMMR1 defines the PWM1 falling-edge position in single-edge mode.
  6. PWMMCR resets the counter when MR0 matches.
  7. PWMPCR enables PWM1 output.
  8. PWMLER requests transfer of the new match values.
  9. PWMTCR enables the timer and PWM mode.
Pin configuration requirement: This example shows the peripheral-register configuration. The physical PWM1 output pin must also be selected through the appropriate PINSEL field for the exact LPC2129 package and pin assignment. Pin multiplexing is covered separately in the pin-configuration lesson. Do not assume that enabling PWMPCR alone connects the signal to a package pin.
Keil simulator limitation: This program demonstrates register configuration. Whether PWMTC, match logic, and PWM output waveforms are simulated depends on the selected Keil device model. Do not treat successful compilation or register writes as proof of a physical PWM waveform.

16. Common Configuration Mistakes

  • Using CCLK instead of PCLK in the PWM timer calculation.
  • Forgetting the prescaler relationship PWMPR + 1.
  • Setting MR0 but not enabling reset on MR0 match.
  • Forgetting to enable PWM mode using PWMTCR bit 3.
  • Forgetting to enable the required output channel in PWMPCR.
  • Not setting the corresponding PWMLER latch bit.
  • Using an incorrect PWM output pin function in PINSEL.
  • Programming a channel match value greater than the period match.
  • Assuming the Keil simulator necessarily models the PWM output.

17. Interview Questions and Answers

Q1. How many PWM output channels are available in LPC2129?

LPC2129 provides six PWM output channels.

Q2. What is the function of PWMPR?

PWMPR determines how many PCLK cycles are counted before PWMTC increments.

Q3. What is PWMPC?

PWMPC is the prescale counter that counts peripheral clock cycles up to the prescaler value.

Q4. What is PWMTC?

PWMTC is the 32-bit timer counter used as the timing reference for PWM match events.

Q5. What is the function of MR0?

MR0 defines the common PWM repetition rate by controlling the timer cycle reset.

Q6. What is the function of PWMMCR?

PWMMCR configures interrupt, reset, and stop actions for match events.

Q7. What is the purpose of PWMPCR?

PWMPCR enables PWM outputs and selects single-edge or double-edge control for applicable channels.

Q8. What is the function of PWMLER?

PWMLER requests that new match-register values be transferred from shadow registers at a controlled PWM update point.

Q9. Why is hardware PWM preferred for motor control?

It generates consistent timing with less CPU involvement than repeatedly toggling GPIO pins in software.

Q10. Why is PINSEL configuration required?

PINSEL connects the selected physical microcontroller pin to its PWM peripheral function.
