3. Important PWM Formulas

Timer Tick Frequency = PCLK / (PWMPR + 1)
Timer Tick Interval = (PWMPR + 1) / PCLK
PWM Frequency ≈ PCLK / [(PWMPR + 1) × MR0]
Duty Cycle ≈ (Channel Match / MR0) × 100
Pulse Width ≈ Channel Match × Timer Tick Interval

Project Clock Configuration

  • CCLK = 60 MHz
  • PCLK = 15 MHz
  • PWMPR = 14
  • Timer tick = 1 µs
  • MR0 = 1000
The nominal PWM frequency is 1 kHz. The nominal period is 1 ms.
These are nominal calculations using the configured timer interval. Exact boundary behavior and output pulse timing should be checked against the LPC2129 user manual.

8. Exercise 5: Change Duty Cycle Dynamically

Objective: Write a reusable function to change the PWM1 duty cycle.

#include <LPC21xx.h> #define PWM_PERIOD 1000U void PWM1_Init(void) { PWMTCR = (1U << 1); PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; PWMMR0 = PWM_PERIOD; PWMMR1 = 500U; PWMMCR = (1U << 1); PWMPCR = (1U << 9); PWMLER = 0x03U; PWMTCR = 0x09U; } void PWM1_SetDuty(unsigned int duty) { if (duty > 100U) duty = 100U; PWMMR1 = (PWM_PERIOD * duty) / 100U; PWMLER = (1U << 1); } int main(void) { PWM1_Init(); while (1) { /* Change this command for testing */ PWM1_SetDuty(25U); } }

11. Exercise 8: Configure PWM Double-Edge Mode

Objective: Understand the register configuration for PWM2 double-edge operation.

In the LPC2129 PWM peripheral, PWM2 double-edge operation uses MR1 and MR2 to define its two edge positions. PWM2's double-edge control is selected using PWMPCR bit 2.

#include <LPC21xx.h> int main(void) { PWMTCR = (1U << 1); PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; PWMMR0 = 1000U; /* PWM2 edge positions */ PWMMR1 = 200U; PWMMR2 = 600U; PWMMCR = (1U << 1); /* Enable PWM2 output and double-edge mode */ PWMPCR = (1U << 10) | (1U << 2); /* Latch MR0, MR1 and MR2 */ PWMLER = 0x07U; PWMTCR = 0x09U; while (1) { } }
The example illustrates the PWM2 register relationship. Check the LPC2129 manual for valid edge ordering, match-register sharing, and the selected output pin. MR2 is also used by the PWM3 channel, so simultaneous channel configurations must be planned carefully.

12. Exercise 9: PWM-Based DC Motor Control

Objective: Configure PWM1 for motor-driver control.

#include <LPC21xx.h> #define PWM_PERIOD 1000U void PWM1_Init(void) { PWMTCR = (1U << 1); PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; PWMMR0 = PWM_PERIOD; PWMMR1 = 500U; PWMMCR = (1U << 1); PWMPCR = (1U << 9); PWMLER = 0x03U; PWMTCR = 0x09U; } void Motor_SetDuty(unsigned int duty) { if (duty > 100U) duty = 100U; PWMMR1 = (PWM_PERIOD * duty) / 100U; PWMLER = (1U << 1); } int main(void) { PWM1_Init(); while (1) { Motor_SetDuty(50U); } }

Expected configuration: PWM1 at approximately 1 kHz and 50% duty cycle.

This program configures the MCU PWM peripheral. It does not drive a physical motor by itself. A suitably rated external motor driver, motor supply, protection components, and correct pin configuration are required.

15. Common PWM Programming Errors

  • Incorrect PCLK value.
  • Incorrect prescaler calculation.
  • Incorrect PWM period match value.
  • Incorrect channel match value.
  • Forgetting to reset the PWM counter before initialization.
  • Forgetting to configure MR0 reset action.
  • Forgetting to enable the PWM output channel.
  • Forgetting to latch match-register updates.
  • Forgetting to enable PWM mode.
  • Forgetting the physical pin's PINSEL configuration.
  • Using incompatible match-register assignments in double-edge mode.
  • Connecting a motor directly to an MCU output.

17. Interview Questions and Answers

Q1. What is the purpose of PWMPR?

It divides the peripheral clock to control the PWM timer increment rate.

Q2. Which register determines the PWM period?

PWMMR0.

Q3. Which register enables PWM output channels?

PWMPCR.

Q4. What is the purpose of PWMLER?

It requests transfer of new match-register values into the active PWM registers.

Q5. What does PWMTCR bit 3 do?

It enables PWM mode.

Q6. What does PWMMCR bit 1 do for MR0?

It resets the PWM counter on an MR0 match.

Q7. What is the difference between single-edge and double-edge PWM?

Single-edge operation uses one channel match to define the pulse edge, while double-edge operation uses two match positions to control both edges of a channel's pulse.

Q8. Why is PWM used in motor control?

It provides efficient control of average motor drive using switching.

Q9. Why is a motor driver necessary?

It provides the power-switching capability required by the motor.

Q10. Can Keil simulator prove actual motor speed?

No. Actual motor RPM requires hardware and a speed-measurement method.
