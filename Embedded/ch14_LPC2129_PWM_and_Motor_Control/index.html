Chapter 14: LPC2129 PWM and Motor Control

Learn Pulse Width Modulation, LPC2129 PWM architecture, match registers, PWM period configuration, single-edge and double-edge operation, Embedded C programming, and DC motor speed control.

Chapter Overview

Pulse Width Modulation (PWM) is a digital control technique used to regulate the average power delivered to a load. It is widely used in embedded systems for motor speed control, LED brightness control, power regulation, and actuator control.

In this chapter, you will study the PWM peripheral of the LPC2129 microcontroller and learn how to configure PWM period, duty cycle, match registers, and output control using Embedded C.

Learning Objectives

After completing this chapter, you should be able to:

  • Explain the concept and applications of PWM.
  • Understand PWM frequency and duty cycle.
  • Calculate PWM period and pulse width.
  • Describe the LPC2129 PWM peripheral architecture.
  • Understand PWM match registers MR0 to MR6.
  • Configure PWM period and pulse width.
  • Differentiate single-edge and double-edge PWM.
  • Write Embedded C programs for PWM generation.
  • Understand PWM-based DC motor speed control.
  • Debug PWM register configurations using Keil uVision.

Important Technical Notes

  • PWM frequency and duty cycle are separate parameters: frequency determines the repetition rate, while duty cycle determines the ON-time percentage.
  • LPC2129 PWM configuration requires appropriate match registers, PWM control registers, latch enable settings, and pin-function selection.
  • A microcontroller GPIO/PWM output cannot directly drive a DC motor. Use a suitable motor driver or power stage.
  • A physical motor circuit may require an external supply, flyback protection, and appropriate current handling.
