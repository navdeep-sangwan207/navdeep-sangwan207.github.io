Lesson 08: DC Motor Speed Control Using PWM

Learn how PWM controls the average voltage applied to a DC motor, how motor drivers interface with the LPC2129, and how to implement speed-control programs using Embedded C.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand PWM-based motor speed control.
  • Calculate PWM duty cycle and average motor voltage.
  • Understand the purpose of a motor-driver circuit.
  • Differentiate between MOSFET drivers and H-bridge drivers.
  • Interface a motor driver with an LPC2129 PWM output.
  • Write Embedded C programs for motor speed control.
  • Understand motor direction and speed control.
  • Identify electrical protection requirements.

2. Introduction to DC Motors

A DC motor is an electromechanical device that converts electrical energy into rotational mechanical energy. It operates using the interaction between magnetic fields and current-carrying conductors.

DC Motor: A motor that operates from a direct-current electrical supply and produces rotational motion.

Basic Motor Components

  • Stator: Stationary magnetic field structure.
  • Rotor or armature: Rotating part of the motor.
  • Windings: Conductors carrying current.
  • Commutator: Reverses armature current in a brushed motor.
  • Brushes: Provide electrical contact to the rotating commutator.
  • Shaft: Transfers mechanical rotation to the load.

3. Why Is Motor Speed Control Required?

Many embedded applications require variable motor speed rather than continuous operation at full speed.

Applications

  • Robotics and mobile robots.
  • Conveyor belt systems.
  • Electric fans and blowers.
  • Automated machines.
  • Small electric vehicles.
  • Industrial automation.
  • Battery-operated equipment.

Common Speed-Control Methods

  1. Variable armature voltage control.
  2. Field-current control, where applicable.
  3. Pulse Width Modulation (PWM).

PWM is widely used in embedded systems because it provides efficient electronic control of motor power.

4. Principle of PWM-Based Motor Speed Control

PWM controls the average voltage applied to the motor by rapidly switching the motor supply ON and OFF.

Operating principle: A higher PWM duty cycle generally produces a higher average motor voltage and can increase motor speed under comparable operating conditions.

5. Duty Cycle and Average Motor Voltage

The duty cycle represents the percentage of each PWM period during which the switching output is active.

Duty Cycle (%) = (TON / T) × 100

For an ideal switching stage with a 12 V motor supply:

Average Applied Voltage ≈ Duty Cycle × Supply Voltage
Duty Cycle Motor Supply Ideal Average Voltage
25%12 V3 V
50%12 V6 V
75%12 V9 V
100%12 V12 V
These are ideal average-voltage values for a simple switching arrangement. Actual motor terminal voltage, current, torque, and speed depend on the driver topology, motor back EMF, winding resistance and inductance, load, supply voltage, and switching losses.

6. Relationship Between PWM Duty Cycle and Motor Speed

Increasing the duty cycle generally increases the average voltage applied to a DC motor. This can increase motor speed when the load and supply conditions remain comparable.

Duty CycleExpected Behaviour
0%Motor drive is normally OFF
25%Lower average drive
50%Medium average drive
75%Higher average drive
100%Continuous ON drive
Duty cycle does not directly specify motor RPM. The relationship between duty cycle and speed is affected by load torque, motor characteristics, driver voltage drop, supply voltage, and operating conditions.

7. Why a Motor Driver Is Required

An LPC2129 GPIO or PWM pin is a logic-level control output. It cannot directly supply the voltage and current required by most DC motors.

Important: Never connect a DC motor directly to an LPC2129 GPIO or PWM pin. Motor startup current, inductive voltage transients, and electrical noise can damage the MCU.

Functions of a Motor Driver

  • Provides the required motor current.
  • Interfaces low-voltage MCU signals with the motor supply.
  • Controls motor switching.
  • Supports direction control when an H-bridge is used.
  • Provides a suitable path for inductive current.

H-Bridge Functions

  • Forward rotation.
  • Reverse rotation.
  • Coasting, depending on driver control logic.
  • Braking, depending on driver control logic.
  • PWM-based speed control.
H-bridge switching requires suitable dead time or interlocking where applicable. Simultaneously turning on the high-side and low-side switches of the same bridge leg can cause shoot-through and damage.

10. LPC2129 PWM Configuration for Motor Control

The LPC2129 PWM peripheral generates the control waveform. The selected PWM output is connected to the logic input of a suitable motor driver.

Example Clock Configuration

  • CCLK = 60 MHz
  • PCLK = 15 MHz
  • PWMPR = 14
  • Timer tick = 1 MHz
  • MR0 = 1000
PWM Frequency ≈ 15 MHz / [(14 + 1) × 1000] = 1 kHz

11. Program 1: Initialize PWM for DC Motor Control

Objective

Configure PWM1 with a nominal 1 kHz frequency and 50% duty cycle.

Program

#include <LPC21xx.h> void PWM1_Init(void) { /* Reset PWM counter */ PWMTCR = (1U << 1); /* PCLK = 15 MHz; timer tick = 1 MHz */ PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; /* 1 kHz period */ PWMMR0 = 1000U; /* 50% duty cycle */ PWMMR1 = 500U; /* Reset on MR0 match */ PWMMCR = (1U << 1); /* Enable PWM1 */ PWMPCR = (1U << 9); /* Latch MR0 and MR1 */ PWMLER = 0x03U; /* Enable counter and PWM mode */ PWMTCR = 0x09U; } int main(void) { PWM1_Init(); while (1) { } }

12. Program 2: Change Motor Speed Using Duty Cycle

Objective

Change the PWM duty cycle through a software function. The motor driver receives the PWM signal and controls the motor power.

Program

#include <LPC21xx.h> #define PWM_PERIOD 1000U void PWM1_Init(void) { PWMTCR = (1U << 1); PWMPR = 14U; PWMPC = 0U; PWMTC = 0U; PWMMR0 = PWM_PERIOD; PWMMR1 = 500U; PWMMCR = (1U << 1); PWMPCR = (1U << 9); PWMLER = 0x03U; PWMTCR = 0x09U; } void Motor_SetSpeed(unsigned int duty) { if (duty > 100U) { duty = 100U; } PWMMR1 = (PWM_PERIOD * duty) / 100U; /* Request MR1 update */ PWMLER = (1U << 1); } int main(void) { PWM1_Init(); while (1) { Motor_SetSpeed(25U); } }

Explanation

  1. PWM1 is initialized with a fixed period.
  2. Motor_SetSpeed() receives a percentage value.
  3. The function limits the input to 100%.
  4. The match value is calculated from the duty percentage.
  5. PWMLER requests the updated match value.
This program demonstrates software duty-cycle configuration. It does not measure actual motor RPM or automatically regulate speed against changing loads.

14. Motor Direction Control Using an H-Bridge

An H-bridge driver can reverse the polarity applied across a DC motor. Two logic inputs commonly select direction, although the exact truth table depends on the driver IC.

IN1IN2Typical Function
10Forward
01Reverse
00Coast or standby, depending on driver
11Brake or another driver-specific state
The table is a common H-bridge logic example, not a universal truth table. Always follow the selected motor-driver datasheet.

Example GPIO Direction Function

This example assumes P0.6 and P0.7 are connected to IN1 and IN2 of a suitable motor-driver module.

#include <LPC21xx.h> #define IN1 (1U << 6) #define IN2 (1U << 7) void Motor_Direction_Init(void) { /* Select GPIO function for P0.6 and P0.7 */ PINSEL0 &= ~((3U << 12) | (3U << 14)); /* Configure as outputs */ IODIR0 |= IN1 | IN2; /* Initially both direction inputs LOW */ IOCLR0 = IN1 | IN2; } void Motor_Forward(void) { IOSET0 = IN1; IOCLR0 = IN2; } void Motor_Reverse(void) { IOCLR0 = IN1; IOSET0 = IN2; } void Motor_Stop_Command(void) { IOCLR0 = IN1 | IN2; }
This direction example does not implement a complete safe motor-control state machine. Disable PWM before changing direction, observe the driver's required dead time and braking rules, and re-enable PWM only after the direction inputs are safely established.

16. Motor Speed Measurement

A motor speed sensor can provide feedback to the LPC2129. Common methods include:

  • Optical encoder.
  • Hall-effect sensor.
  • Magnetic encoder.
  • Tachometer output.

RPM Calculation

RPM = (Pulse Count × 60) / (Pulses Per Revolution × Time in Seconds)

Example

Suppose an encoder generates 20 pulses per revolution. If 100 pulses are counted in one second:

RPM = (100 × 60) / (20 × 1) = 300 RPM

This calculation assumes the stated pulse count is the number of pulses per mechanical revolution at the point being measured. Encoder quadrature decoding and gear ratios may change the effective pulse count.

17. Motor Protection and Electrical Considerations

  • Use a driver rated for motor supply voltage and stall current.
  • Provide suitable flyback or recirculation paths for inductive current.
  • Use appropriate supply decoupling near the driver.
  • Keep motor-current paths separate from sensitive logic paths where practical.
  • Use a suitable common reference between MCU and driver logic when required.
  • Check driver thermal limits and PCB current capacity.
  • Protect the MCU from motor supply transients and ground disturbances.
  • Use current limiting or overcurrent protection where appropriate.
  • Verify PWM frequency compatibility with the motor and driver.
A brushed DC motor is an inductive load. Do not omit the driver manufacturer's recommended flyback, recirculation, and transient-protection circuitry.

19. Common Mistakes

  • Connecting the motor directly to the MCU pin.
  • Ignoring motor startup and stall current.
  • Using an unsuitable MOSFET or motor-driver IC.
  • Forgetting to configure the PWM pin function.
  • Using incorrect PWM period or duty-cycle values.
  • Forgetting to latch updated match values.
  • Assuming motor RPM is directly proportional to duty cycle.
  • Reversing direction without considering driver safety.
  • Ignoring inductive-current protection.
  • Confusing open-loop PWM control with closed-loop speed regulation.

20. Interview Questions and Answers

Q1. What is PWM-based motor speed control?

It is a method of controlling average motor drive by changing the duty cycle of a switching waveform.

Q2. What happens when duty cycle increases?

Average applied voltage generally increases, which can increase motor speed under comparable load and supply conditions.

Q3. Why is a motor driver required?

The MCU output cannot supply the voltage and current required by most motors. A driver provides the power switching interface.

Q4. What is an H-bridge?

An H-bridge is a switching circuit used to reverse voltage polarity across a DC motor.

Q5. What is open-loop motor control?

It controls motor drive without measuring actual motor speed.

Q6. What is closed-loop motor control?

It measures actual motor speed and adjusts the control output using feedback.

Q7. Which sensors can measure motor speed?

Optical encoders, Hall-effect sensors, and tachometers.

Q8. What is stall current?

It is the motor current under a condition where the rotor is not rotating while the motor is energized.

Q9. Why is inductive protection required?

Motor winding current cannot change instantaneously. Suitable recirculation or clamp paths protect switching devices from voltage transients.

Q10. Does a 50% duty cycle always produce 50% of rated RPM?

No. Motor speed depends on supply voltage, motor characteristics, load torque, driver losses, and operating conditions.
