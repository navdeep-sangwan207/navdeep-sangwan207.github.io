1. Introduction

An external interrupt is generated by an external electrical signal connected to a microcontroller input pin.

External interrupts allow the microcontroller to respond to events such as a push button press, sensor output, digital signal transition, or an external device request.

The LPC2129 provides four external interrupt inputs:

  • EINT0
  • EINT1
  • EINT2
  • EINT3

2. What Is an External Interrupt?

An external interrupt is a hardware event generated outside the microcontroller. The external signal is applied to a pin configured for an interrupt function.

Examples

  • A push button generates an interrupt when pressed.
  • A sensor produces a pulse when an event occurs.
  • An external controller requests service.
  • A digital signal changes from LOW to HIGH.

3. LPC2129 External Interrupt Inputs

The LPC2129 supports four external interrupt inputs. Each input has a corresponding interrupt flag and configuration bits.

External interrupt Flag bit in EXTINT Configuration bits
EINT0 Bit 0 EXTMODE[0], EXTPOLAR[0]
EINT1 Bit 1 EXTMODE[1], EXTPOLAR[1]
EINT2 Bit 2 EXTMODE[2], EXTPOLAR[2]
EINT3 Bit 3 EXTMODE[3], EXTPOLAR[3]
Each external interrupt can be configured independently for edge-sensitive or level-sensitive operation.

4. Pin Multiplexing for External Interrupts

LPC2129 pins have multiple functions. A physical pin must be configured for the required external interrupt function using the PINSEL registers.

The exact pin assignment must be taken from the LPC2129 pin-function table. Do not assume that an EINT number is the same as its GPIO pin number.

Pin configuration procedure

  1. Identify the selected EINT function in the device pin-function table.
  2. Find the corresponding PINSEL register and field.
  3. Configure the pin for the EINT function.
  4. Configure the external interrupt trigger mode.
  5. Configure the interrupt polarity.
  6. Clear any stale interrupt flag.
  7. Enable the interrupt source through the VIC.
Do not copy a PINSEL bit mask from a different LPC21xx device or development board. Pin multiplexing must be verified against the LPC2129 datasheet and the package-specific pin table.

5. External Interrupt Triggering Modes

The LPC2129 supports two types of external interrupt triggering:

  • Edge-sensitive triggering.
  • Level-sensitive triggering.

5.1 Edge-sensitive triggering

An edge-triggered interrupt is generated when the input signal changes state.

Two edge options are available:

  • Rising edge: LOW to HIGH transition.
  • Falling edge: HIGH to LOW transition.

6. EXTMODE Register

The EXTMODE register selects whether each external interrupt uses edge-sensitive or level-sensitive triggering.

Bit External interrupt Value 0 Value 1
0 EINT0 Level-sensitive Edge-sensitive
1 EINT1 Level-sensitive Edge-sensitive
2 EINT2 Level-sensitive Edge-sensitive
3 EINT3 Level-sensitive Edge-sensitive

Example: Configure EINT0 as edge-sensitive

#include <LPC21xx.h>

void Configure_EINT0_Edge_Mode(void)
{
    EXTMODE |= (1U << 0);
}

Setting bit 0 selects edge-sensitive operation for EINT0.

Example: Configure EINT0 as level-sensitive

void Configure_EINT0_Level_Mode(void)
{
    EXTMODE &= ~(1U << 0);
}

7. EXTPOLAR Register

The EXTPOLAR register selects the active polarity of an external interrupt.

Its meaning depends on the trigger mode selected through EXTMODE.

Trigger mode EXTPOLAR bit = 0 EXTPOLAR bit = 1
Edge-sensitive Falling edge Rising edge
Level-sensitive Low level High level

Example: EINT0 rising-edge configuration

void Configure_EINT0_Rising_Edge(void)
{
    /* Select edge-sensitive mode */
    EXTMODE |= (1U << 0);

    /* Select rising-edge polarity */
    EXTPOLAR |= (1U << 0);
}

Example: EINT0 falling-edge configuration

void Configure_EINT0_Falling_Edge(void)
{
    /* Select edge-sensitive mode */
    EXTMODE |= (1U << 0);

    /* Select falling-edge polarity */
    EXTPOLAR &= ~(1U << 0);
}

8. EXTINT Register

EXTINT stores the interrupt flags for EINT0 to EINT3.

Bit Flag
0EINT0 interrupt flag
1EINT1 interrupt flag
2EINT2 interrupt flag
3EINT3 interrupt flag

Reading an interrupt flag

unsigned int eint0_flag;

eint0_flag = EXTINT & (1U << 0);

Clearing the EINT0 flag

EXTINT = (1U << 0);
EXTINT uses write-one-to-clear flag semantics. Write a 1 to the flag bit that must be cleared. Do not use read-modify-write operations such as EXTINT |= mask, because that can clear other flags that were already set.

10. External Interrupt Configuration Sequence

A typical external interrupt setup involves:

  1. Configure the selected pin through PINSEL.
  2. Configure EXTMODE.
  3. Configure EXTPOLAR.
  4. Clear the relevant EXTINT flag.
  5. Configure the VIC interrupt type using VICIntSelect.
  6. Assign a vector slot if vectored IRQ handling is used.
  7. Set the vector handler address.
  8. Enable the source using VICIntEnable.
  9. Enable processor IRQ handling when appropriate.
  10. Implement the ISR and clear the peripheral interrupt flag.
The peripheral interrupt configuration, VIC configuration, and ARM processor exception configuration are separate stages. All must be correct for a complete interrupt application.

11. Example: EINT0 Rising-Edge Configuration

The following example configures the external interrupt control registers for EINT0 rising-edge operation. 

#include <LPC21xx.h>

void Configure_EINT0(void)
{
    /* Select edge-sensitive triggering */
    EXTMODE |= (1U << 0);

    /* Select rising-edge triggering */
    EXTPOLAR |= (1U << 0);

    /* Clear any pending EINT0 flag */
    EXTINT = (1U << 0);
}

int main(void)
{
    Configure_EINT0();

    while (1)
    {
        /* Main application */
    }
}

Explanation

  • EXTMODE bit 0 selects edge-sensitive operation.
  • EXTPOLAR bit 0 selects rising-edge polarity.
  • EXTINT bit 0 is cleared using write-one-to-clear.
  • The example does not configure the pin mux or VIC.
  • No ISR is installed in this example.

12. Example: Enabling EINT0 Through the VIC

The following example illustrates the VIC source enable and vector assignment. It assumes that the pin mux and external interrupt configuration have already been completed. 

#include <LPC21xx.h>

#define EINT0_SOURCE 14U
#define VECTOR_ENABLE (1U << 5)

void EINT0_ISR(void);

void Configure_EINT0_VIC(void)
{
    /* Select IRQ rather than FIQ */
    VICIntSelect &= ~(1U << EINT0_SOURCE);

    /* Assign EINT0 to vectored slot 0 */
    VICVectCntl0 =
        VECTOR_ENABLE | EINT0_SOURCE;

    /* Set the handler address */
    VICVectAddr0 = (unsigned int)EINT0_ISR;

    /* Enable the EINT0 source in the VIC */
    VICIntEnable = (1U << EINT0_SOURCE);
}

void EINT0_ISR(void)
{
    /* Acknowledge the external interrupt */
    EXTINT = (1U << 0);

    /* Complete VIC interrupt handling */
    VICVectAddr = 0;
}

int main(void)
{
    Configure_EINT0_VIC();

    while (1)
    {
    }
}
This is an illustrative register-level example, not a complete compiler-ready interrupt application. The actual ISR declaration and exception return must follow the Keil toolchain's IRQ-handler convention. The external pin mux and trigger configuration must also be completed. A complete application must account for processor IRQ masking and startup configuration.

13. Edge-triggered vs Level-triggered Interrupts

Feature Edge-triggered Level-triggered
Detection Detects a signal transition. Detects an active logic level.
Trigger conditions Rising or falling edge. High or low level.
Signal behavior Responds to an edge event. Can remain active while the level persists.
Typical use Pulse or transition detection. Devices that hold a request active until serviced.
Important consideration Very short pulses may be missed if not captured reliably. The active level must be deasserted to prevent repeated requests.

15. Common Mistakes

Mistake Correct approach
Using a GPIO function instead of EINT. Configure the correct pin multiplexing function.
Confusing edge and level triggering. Configure EXTMODE correctly.
Selecting the wrong polarity. Configure EXTPOLAR for the intended signal.
Using EXTINT |= mask. Clear flags using direct write-one-to-clear assignment.
Enabling VIC without configuring the peripheral. Configure the external interrupt controller and VIC.
Forgetting the ISR acknowledgement. Clear the peripheral flag and complete VIC handling.
Assuming simulator behavior proves electrical operation. Distinguish register-level simulation from physical signal testing.

16. Interview Questions and Answers

Q1. What is an external interrupt?

It is an interrupt request generated by an external electrical signal connected to a microcontroller pin.

Q2. How many external interrupt inputs are available in LPC2129?

Four: EINT0, EINT1, EINT2 and EINT3.

Q3. What is EXTMODE?

It selects edge-sensitive or level-sensitive triggering.

Q4. What is EXTPOLAR?

It selects rising/falling edge or high/low active level, depending on the selected trigger mode.

Q5. What is EXTINT?

It contains the external interrupt flags for EINT0 to EINT3.

Q6. How do you clear an external interrupt flag?

Write 1 to the corresponding EXTINT flag bit.

Q7. What is edge triggering?

It detects a transition from one logic state to another.

Q8. What is level triggering?

It detects an active HIGH or LOW input level.

Q9. Why is pin multiplexing necessary?

The physical pin must be configured for its external interrupt function rather than another alternate function.

Q10. What is the role of the VIC?

It manages interrupt requests and routes enabled interrupt sources to the processor.

Q11. Why must the external interrupt flag be cleared?

Clearing the flag acknowledges the peripheral interrupt event and prevents a stale pending request from remaining active.

Q12. Can external interrupts be used for push buttons?

Yes. A button can generate an interrupt on a configured edge or active level. Hardware or software debouncing may be required.
