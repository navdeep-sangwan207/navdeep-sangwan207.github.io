1. Introduction

The Vectored Interrupt Controller (VIC) of the LPC2129 uses memory-mapped registers to manage interrupt requests from internal peripherals and external interrupt sources.

These registers allow the programmer to inspect interrupt status, enable or disable sources, select IRQ or FIQ handling, configure vectored IRQ slots, and provide interrupt handler addresses.

Learning objectives
  • Understand the VIC register organization.
  • Study interrupt status registers.
  • Understand IRQ and FIQ source selection.
  • Learn interrupt enable and disable operations.
  • Study vectored address and control registers.
  • Understand the default vector register.
  • Understand VIC interrupt completion.

2. VIC Register Organization

The VIC contains several groups of registers. Each group performs a specific interrupt management function.

Register group Purpose
Interrupt status Reports raw, IRQ, and FIQ interrupt status.
Interrupt selection Assigns interrupt sources to IRQ or FIQ.
Interrupt enable Enables or disables interrupt sources.
Vectored control Configures the 16 vectored IRQ slots.
Vector address Stores handler addresses.
Default vector Stores the fallback IRQ handler address.

3. VIC Interrupt Status Registers

3.1 VICRawIntr

VICRawIntr reports the raw interrupt request status from interrupt sources. It is useful for examining requests before considering the VIC enable and IRQ/FIQ selection configuration.

3.2 VICIRQStatus

VICIRQStatus reports interrupt sources currently contributing to the IRQ request path.

3.3 VICFIQStatus

VICFIQStatus reports interrupt sources currently contributing to the FIQ request path.

Register Information provided
VICRawIntr Raw interrupt request status.
VICIRQStatus Active IRQ status.
VICFIQStatus Active FIQ status.

Example: Reading interrupt status

#include <LPC21xx.h>

unsigned int raw_status;
unsigned int irq_status;
unsigned int fiq_status;

void Read_VIC_Status(void)
{
    raw_status = VICRawIntr;
    irq_status = VICIRQStatus;
    fiq_status = VICFIQStatus;
}

int main(void)
{
    Read_VIC_Status();

    while (1)
    {
        /* Inspect variables in debugger */
    }
}

This program reads the status registers and stores their values in variables. It does not generate an interrupt.

4. VICIntSelect Register

VICIntSelect determines whether an interrupt source is assigned to IRQ or FIQ handling.

Each bit corresponds to one interrupt source.

Bit value Meaning
0 Interrupt source assigned to IRQ.
1 Interrupt source assigned to FIQ.

Example: Assign Timer 0 to IRQ

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Select_Timer0_IRQ(void)
{
    VICIntSelect &= ~(1U << TIMER0_SOURCE);
}

int main(void)
{
    Select_Timer0_IRQ();

    while (1)
    {
    }
}

Example: Assign Timer 0 to FIQ

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Select_Timer0_FIQ(void)
{
    VICIntSelect |= (1U << TIMER0_SOURCE);
}

int main(void)
{
    Select_Timer0_FIQ();

    while (1)
    {
    }
}
These examples demonstrate the selection bit operation. They do not configure Timer 0, enable its interrupt, or configure the ARM7 exception handler.

5. VICIntEnable Register

VICIntEnable is used to enable selected interrupt sources in the VIC.

Writing a 1 to a bit enables the corresponding interrupt source.

Example: Enable Timer 0 interrupt

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Enable_Timer0_Interrupt(void)
{
    VICIntEnable = (1U << TIMER0_SOURCE);
}

int main(void)
{
    Enable_Timer0_Interrupt();

    while (1)
    {
    }
}

The expression (1U << TIMER0_SOURCE) creates a mask for the Timer 0 source bit.

VICIntEnable is a write-one-to-enable register. Writing a zero to another bit does not disable an already enabled source. Use VICIntEnClr for disabling.

6. VICIntEnClr Register

VICIntEnClr is used to disable selected interrupt sources.

Writing a 1 to a bit disables the corresponding source. Writing zero leaves the corresponding enable state unchanged.

Example: Disable Timer 0 interrupt

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Disable_Timer0_Interrupt(void)
{
    VICIntEnClr = (1U << TIMER0_SOURCE);
}

int main(void)
{
    Disable_Timer0_Interrupt();

    while (1)
    {
    }
}

Enable and disable comparison

Register Operation
VICIntEnable Write 1 to enable selected source.
VICIntEnClr Write 1 to disable selected source.
Do not treat VICIntEnClr as a normal read-modify-write register. Use a direct mask assignment to disable the intended source.

7. VICVectCntl Registers

The VIC provides 16 vector control registers: 

VICVectCntl0
VICVectCntl1
VICVectCntl2
...
VICVectCntl15

Each control register configures one vectored IRQ slot.

General bit organization

Bits Function
Bit 5 Enable the vectored IRQ slot.
Bits 4:0 Select the interrupt source number.

Example: Configure slot 0

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U
#define VIC_SLOT_ENABLE (1U << 5)

void Configure_Timer0_Vector_Slot(void)
{
    VICVectCntl0 =
        VIC_SLOT_ENABLE | TIMER0_SOURCE;
}

int main(void)
{
    Configure_Timer0_Vector_Slot();

    while (1)
    {
    }
}

This configures slot 0 to select the Timer 0 source, assuming the source number has been verified for the selected device.

Configuring a vector slot does not enable the peripheral interrupt by itself. The source must also be enabled in the VIC and configured in its peripheral.

8. VICVectAddr Registers

The VIC provides 16 vectored address registers: 

VICVectAddr0
VICVectAddr1
VICVectAddr2
...
VICVectAddr15

Each register stores the address of the interrupt handler associated with its corresponding vectored IRQ slot.

Example: Assign an ISR address

#include <LPC21xx.h>

void Timer0_ISR(void);

void Configure_Vector_Address(void)
{
    VICVectAddr0 = (unsigned int)Timer0_ISR;
}

void Timer0_ISR(void)
{
    /*
     * Peripheral service code belongs here.
     * Use the compiler's supported ISR
     * convention and proper VIC completion.
     */

    VICVectAddr = 0;
}

int main(void)
{
    Configure_Vector_Address();

    while (1)
    {
    }
}
This is an illustrative register assignment. A production ISR requires the correct compiler-specific interrupt declaration or assembly wrapper, correct peripheral flag handling, and appropriate exception return. Verify pointer width and register definitions in the selected toolchain.

9. VICVectAddr Register

VICVectAddr has an important role in vectored interrupt handling.

When the processor enters the IRQ handler, software can read VICVectAddr to obtain the selected vectored handler address. Writing to VICVectAddr is also used to signal completion of VIC interrupt handling.

Interrupt completion

VICVectAddr = 0;

This write is commonly used at the end of a VIC-managed IRQ service routine to indicate that the current interrupt service has completed.

Writing zero to VICVectAddr does not clear the peripheral's interrupt flag. The peripheral interrupt condition must be acknowledged separately according to its own register requirements.

10. VICDefVectAddr Register

VICDefVectAddr stores the address of the default IRQ handler.

It is used when an IRQ request is not dispatched through an enabled vectored IRQ slot.

Example

#include <LPC21xx.h>

void Default_IRQ_Handler(void);

void Configure_Default_Vector(void)
{
    VICDefVectAddr =
        (unsigned int)Default_IRQ_Handler;
}

void Default_IRQ_Handler(void)
{
    /*
     * Identify and service the interrupt
     * source using the appropriate logic.
     */
    VICVectAddr = 0;
}

The example illustrates the register assignment. A complete default IRQ handler must also follow the processor and compiler's exception handling requirements.

12. Understanding a VIC Source Mask

The VIC uses one bit for each interrupt source. A bit mask can be created by shifting 1 to the source number. 

unsigned int mask;

mask = (1U << 4);

If the selected source number is 4, the resulting binary mask is: 

00000000 00000000 00000000 00010000

This mask can be used to enable, disable, or inspect the corresponding interrupt source, depending on the VIC register being accessed.

Checking an IRQ status bit

if (VICIRQStatus & (1U << 4))
{
    /* Source 4 is represented in IRQ status */
}

13. VIC Configuration Sequence

Configure Peripheral Interrupt
↓
Clear Pending Peripheral Status
↓
Select IRQ or FIQ
↓
Configure Vector Control and Address
↓
Enable VIC Source
↓
Allow Processor Interrupt Handling
↓
Execute ISR and Complete VIC Handling

This sequence gives the general configuration order. The exact steps depend on the peripheral and the selected interrupt type.

14. Common Programming Mistakes

Mistake Correct practice
Using VICIntEnable to disable a source. Use VICIntEnClr.
Confusing source number and slot number. Use the source number in the slot control field.
Configuring a slot without an address. Assign the appropriate handler address.
Forgetting the peripheral interrupt flag. Clear or acknowledge the peripheral condition correctly.
Assuming VICVectAddr = 0 clears every interrupt. It completes VIC handling; peripheral flags are separate.
Enabling the source before initializing its ISR. Configure the handler and peripheral before enabling the source.

15. Interview Questions and Answers

Q1. What is VICIntSelect?

It selects whether each interrupt source is assigned to IRQ or FIQ.

Q2. What is VICIntEnable?

It enables selected interrupt sources in the VIC.

Q3. What is VICIntEnClr?

It disables selected interrupt sources.

Q4. What is VICRawIntr?

It reports raw interrupt request status.

Q5. What is VICIRQStatus?

It reports active IRQ status.

Q6. What is VICFIQStatus?

It reports active FIQ status.

Q7. How many VICVectCntl registers are available?

There are 16 vector control registers.

Q8. What is the purpose of VICVectAddr0?

It stores the handler address for vectored IRQ slot 0.

Q9. What is VICDefVectAddr?

It stores the default IRQ handler address.

Q10. Why is VICVectAddr written at the end of an ISR?

It is used to signal completion of VIC-managed interrupt handling.

Q11. Does VICVectAddr clear the peripheral interrupt flag?

No. The peripheral's interrupt status must be acknowledged separately.

Q12. What is the function of VICVectCntl?

It enables a vectored slot and selects the interrupt source assigned to it.
