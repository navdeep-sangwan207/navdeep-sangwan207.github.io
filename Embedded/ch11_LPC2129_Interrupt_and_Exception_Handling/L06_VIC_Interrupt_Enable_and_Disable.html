1. Introduction

The LPC2129 Vectored Interrupt Controller (VIC) allows software to enable and disable individual interrupt sources.

Interrupt enabling determines whether a peripheral request is allowed through the VIC interrupt control path. Disabling a source prevents that source from generating a new VIC IRQ or FIQ request.

Correct interrupt configuration is important in embedded systems because multiple peripherals may generate interrupt requests at the same time.

Learning objectives
  • Understand interrupt source enabling.
  • Understand interrupt source disabling.
  • Use VICIntEnable and VICIntEnClr.
  • Configure IRQ and FIQ selection.
  • Understand processor interrupt masking.
  • Write basic VIC configuration programs.
  • Identify common interrupt configuration mistakes.

2. Why Enable and Disable Interrupts?

A microcontroller may contain several peripherals that generate interrupt requests. However, an application may not need every interrupt source at every moment.

Reasons to enable an interrupt

  • Respond to timer match events.
  • Receive UART data without continuous polling.
  • Detect external hardware events.
  • Respond to ADC conversion completion.
  • Handle communication peripheral events.

Reasons to disable an interrupt

  • Prevent unnecessary interrupt processing.
  • Temporarily stop a peripheral interrupt source.
  • Perform controlled initialization.
  • Prevent repeated handling while reconfiguring a peripheral.
  • Reduce interrupt activity when a feature is not required.

3. VIC Registers Used for Enabling and Disabling

Register Function
VICIntEnable Enables selected interrupt sources.
VICIntEnClr Disables selected interrupt sources.
VICIntSelect Selects IRQ or FIQ classification for each source.
VICIRQStatus Reports active IRQ status.
VICFIQStatus Reports active FIQ status.
VICRawIntr Reports raw interrupt requests.
The enable and disable registers use write-one control semantics. Direct mask assignments are preferred.

4. Enabling an Interrupt Source

To enable an interrupt source, write a 1 to the corresponding bit in VICIntEnable.

General expression

VICIntEnable = (1U << source_number);

The left shift places the 1 in the position corresponding to the selected interrupt source.

Example: Enable Timer 0

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Enable_Timer0(void)
{
    VICIntEnable = (1U << TIMER0_SOURCE);
}

int main(void)
{
    Enable_Timer0();

    while (1)
    {
    }
}

This example enables the VIC source associated with Timer 0, assuming the source number is verified against the LPC2129 interrupt table.

Enabling a VIC source does not configure the timer itself. Timer match registers, match control, interrupt flags, and the ISR must be configured separately.

5. Enabling Multiple Interrupt Sources

Multiple interrupt sources can be enabled by combining their bit masks.

Example: Enable Timer 0 and Timer 1

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U
#define TIMER1_SOURCE 5U

void Enable_Timers(void)
{
    unsigned int mask;

    mask = (1U << TIMER0_SOURCE) |
           (1U << TIMER1_SOURCE);

    VICIntEnable = mask;
}

int main(void)
{
    Enable_Timers();

    while (1)
    {
    }
}

The resulting mask contains a 1 in the Timer 0 and Timer 1 source positions.

6. Disabling an Interrupt Source

To disable an interrupt source, write a 1 to its corresponding bit in VICIntEnClr.

General expression

VICIntEnClr = (1U << source_number);

Example: Disable Timer 0

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Disable_Timer0(void)
{
    VICIntEnClr = (1U << TIMER0_SOURCE);
}

int main(void)
{
    Disable_Timer0();

    while (1)
    {
    }
}
VICIntEnClr is not a conventional enable-state variable. Writing a 1 clears the corresponding enable bit. Writing zero leaves that source's enable state unchanged.

7. Disabling Multiple Interrupt Sources

Multiple sources can be disabled using a combined bit mask.

Example: Disable Timer 0 and Timer 1

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U
#define TIMER1_SOURCE 5U

void Disable_Timers(void)
{
    unsigned int mask;

    mask = (1U << TIMER0_SOURCE) |
           (1U << TIMER1_SOURCE);

    VICIntEnClr = mask;
}

int main(void)
{
    Disable_Timers();

    while (1)
    {
    }
}

8. Enable and Disable Comparison

Operation Register Write operation
Enable source 4 VICIntEnable Write 0x00000010
Disable source 4 VICIntEnClr Write 0x00000010
Enable sources 4 and 5 VICIntEnable Write 0x00000030
Disable sources 4 and 5 VICIntEnClr Write 0x00000030

The same bit mask is used, but the destination register determines whether the operation enables or disables the selected sources.

9. IRQ and FIQ Source Selection

VICIntSelect determines whether an interrupt source is assigned to IRQ or FIQ.

Bit value Interrupt classification
0 IRQ
1 FIQ

Configure Timer 0 as IRQ

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Configure_Timer0_IRQ(void)
{
    VICIntSelect &= ~(1U << TIMER0_SOURCE);
}

Configure Timer 0 as FIQ

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

void Configure_Timer0_FIQ(void)
{
    VICIntSelect |= (1U << TIMER0_SOURCE);
}
IRQ/FIQ selection and interrupt enabling are separate operations. Selecting FIQ does not automatically enable the source.

10. Processor Interrupt Masking

The ARM7 processor also provides interrupt mask bits in the CPSR (Current Program Status Register).

These mask bits control whether the processor accepts IRQ and FIQ exceptions.

CPSR bit Function
Bit 7 – I IRQ mask bit.
Bit 6 – F FIQ mask bit.

Important distinction

  • VICIntEnable controls whether a source is enabled in the VIC.
  • VICIntEnClr disables a selected source in the VIC.
  • CPSR I controls processor acceptance of IRQ exceptions.
  • CPSR F controls processor acceptance of FIQ exceptions.
A source can be enabled in the VIC while the processor masks the associated exception. VIC source enabling and processor exception masking are separate layers of interrupt control.

11. Peripheral Interrupt Enable vs VIC Enable

Interrupt handling usually requires configuration at both the peripheral and VIC levels.

Peripheral-level configuration VIC-level configuration
Configure the timer match event. Enable the Timer 0 source.
Enable the timer interrupt action. Configure IRQ/FIQ selection.
Clear the timer interrupt flag. Configure the vector slot and handler address.
Peripheral Configuration
↓
Peripheral Generates Interrupt Request
↓
VIC Source Enabled
↓
Processor Accepts IRQ or FIQ
↓
Interrupt Service Routine

12. Safe Interrupt Configuration Sequence

A safe configuration sequence prevents unexpected interrupt execution while the peripheral and handler are being initialized.

  1. Disable the selected VIC source during initialization.
  2. Configure the peripheral registers.
  3. Clear pending peripheral interrupt flags.
  4. Configure the IRQ/FIQ selection.
  5. Configure the vector control and handler address if using vectored IRQ.
  6. Enable the peripheral interrupt condition.
  7. Enable the source in the VIC.
  8. Ensure the processor interrupt mask permits the intended exception.
The exact order of peripheral interrupt enable and flag clearing depends on the peripheral. Follow its register documentation to avoid a pending request immediately after enabling.

13. Example: Enable and Disable Timer 0 Source

The following program demonstrates how to enable and disable a VIC source. It does not configure Timer 0 itself. 

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U
#define TIMER0_MASK (1U << TIMER0_SOURCE)

void Timer0_VIC_Enable(void)
{
    VICIntEnable = TIMER0_MASK;
}

void Timer0_VIC_Disable(void)
{
    VICIntEnClr = TIMER0_MASK;
}

int main(void)
{
    Timer0_VIC_Enable();

    /*
     * Inspect the VIC configuration
     * using the debugger.
     */

    Timer0_VIC_Disable();

    while (1)
    {
    }
}

Program explanation

  • TIMER0_SOURCE identifies the Timer 0 source.
  • TIMER0_MASK creates its bit mask.
  • Timer0_VIC_Enable() enables the source.
  • Timer0_VIC_Disable() disables the source.

The program is intended for register-level learning. It does not demonstrate a complete Timer 0 interrupt service routine.

14. Common Mistakes

Mistake Correct approach
Using VICIntEnable to disable a source. Use VICIntEnClr.
Assuming VIC enable configures the peripheral. Configure the peripheral interrupt separately.
Confusing IRQ/FIQ selection with source enabling. Configure VICIntSelect and VICIntEnable separately.
Ignoring CPSR interrupt masks. Check processor exception mask state.
Clearing only the VIC state. Acknowledge the peripheral interrupt condition correctly.
Using an incorrect interrupt source number. Verify the LPC2129 interrupt source table.

15. Interview Questions and Answers

Q1. Which register enables a VIC interrupt source?

VICIntEnable.

Q2. Which register disables a VIC interrupt source?

VICIntEnClr.

Q3. How is an interrupt source enabled?

Write a 1 to its corresponding bit in VICIntEnable.

Q4. How is an interrupt source disabled?

Write a 1 to its corresponding bit in VICIntEnClr.

Q5. What is VICIntSelect?

It selects IRQ or FIQ classification for an interrupt source.

Q6. Does enabling a VIC source configure the peripheral?

No. The peripheral must be configured separately to generate an interrupt.

Q7. What does CPSR I bit control?

It masks IRQ exceptions at the processor.

Q8. What does CPSR F bit control?

It masks FIQ exceptions at the processor.

Q9. Can a VIC source be enabled while IRQ is masked?

Yes. The VIC source can be enabled, but the processor will not accept the IRQ exception while the IRQ mask remains set.

Q10. Why should pending flags be cleared?

A stale peripheral interrupt condition can cause an interrupt request as soon as the source is enabled.

19. Lesson Summary

  • VICIntEnable enables selected interrupt sources.
  • VICIntEnClr disables selected interrupt sources.
  • VICIntSelect assigns sources to IRQ or FIQ.
  • Peripheral interrupt configuration is separate from VIC configuration.
  • CPSR I masks IRQ exceptions.
  • CPSR F masks FIQ exceptions.
  • Pending peripheral flags must be handled correctly.
  • Safe initialization helps prevent unexpected interrupt execution.
