Chapter Overview

Interrupts allow a microcontroller to respond to important events without continuously checking every peripheral. When an enabled interrupt request occurs, the processor temporarily changes its normal execution flow and transfers control to an Interrupt Service Routine (ISR).

This chapter explains ARM7 exception handling, the LPC2129 Vectored Interrupt Controller (VIC), interrupt control registers, interrupt priority, external interrupts, and timer interrupt programming using Embedded C.

Practical focus: Configure interrupt sources, enable and disable interrupts, understand VIC vector slots, respond to external events, and implement timer-based interrupt applications.

Learning Objectives

After completing this chapter, you will be able to:

  • Explain interrupts and exceptions in embedded systems.
  • Differentiate polling and interrupt-driven programming.
  • Understand ARM7 exception modes and exception vectors.
  • Explain the architecture of the LPC2129 VIC.
  • Identify VIC interrupt control and status registers.
  • Enable and disable individual interrupt sources.
  • Understand interrupt priority and vectored slot allocation.
  • Configure external interrupt inputs EINT0 to EINT3.
  • Implement timer-based interrupt programs.
  • Write efficient and reliable interrupt service routines.
