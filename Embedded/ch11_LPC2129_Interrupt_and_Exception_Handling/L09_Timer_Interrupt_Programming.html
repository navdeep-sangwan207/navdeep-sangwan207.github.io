1. Introduction

A timer interrupt is generated when a hardware timer reaches a configured match condition. The timer can notify the processor without requiring the main program to continuously check the timer register.

The LPC2129 provides two 32-bit timer peripherals, Timer 0 and Timer 1. Each timer supports match registers that can generate interrupt requests.

These requests can be routed through the Vectored Interrupt Controller (VIC) to the ARM7 processor.

Learning objectives
  • Understand timer-generated interrupts.
  • Configure Timer 0 and Timer 1.
  • Understand MR0–MR3 match registers.
  • Configure the Match Control Register.
  • Enable timer interrupts through the VIC.
  • Write a timer interrupt service routine.
  • Clear timer interrupt flags correctly.
  • Develop periodic interrupt applications.

2. What Is a Timer Interrupt?

A timer interrupt is a hardware-generated request that occurs when a timer reaches a programmed condition.

For example, Timer 0 can be configured to generate an interrupt after a specified number of timer counter increments.

Example

Suppose the timer counter increments every 1 millisecond. If the match register is configured for 1000 increments and the timer resets on the match, a periodic event can be generated approximately every second.

3. LPC2129 Timer Interrupt Sources

Timer 0 and Timer 1 have separate interrupt sources connected to the VIC.

Peripheral VIC source number Timer registers
Timer 0 4 T0IR, T0TCR, T0TC, T0PR, T0MR0–T0MR3, T0MCR
Timer 1 5 T1IR, T1TCR, T1TC, T1PR, T1MR0–T1MR3, T1MCR
Timer 0 and Timer 1 are independent peripherals. Each has its own counter, prescaler, match registers, interrupt flags and control registers.

4. Important Timer Registers

Register Purpose
T0TCR / T1TCR Controls timer enable and reset.
T0TC / T1TC Contains the current timer counter value.
T0PR / T1PR Sets the prescaler division value.
T0PC / T1PC Contains the current prescaler counter value.
T0MR0–MR3 / T1MR0–MR3 Stores timer match values.
T0MCR / T1MCR Selects interrupt, reset and stop actions on match.
T0IR / T1IR Contains timer interrupt flags.

5. Prescaler and Timer Counter Calculation

The prescaler divides the peripheral clock before the timer counter increments.

Timer counter frequency:

TC Frequency = PCLK / (PR + 1)

Time between timer counter increments:

TC Increment Interval = (PR + 1) / PCLK

Example using the project clock settings

  • FOSC = 12 MHz
  • CCLK = 60 MHz
  • PCLK = 15 MHz
  • PR = 14999

Calculation:

TC Frequency = 15,000,000 / (14999 + 1)

             = 15,000,000 / 15,000

             = 1000 Hz

Therefore:

TC Increment Interval = 1 / 1000

                      = 0.001 seconds

                      = 1 millisecond
With PCLK = 15 MHz and PR = 14999, the timer counter increments once every nominal 1 millisecond.

6. Match Registers

Each LPC2129 timer has four match registers: MR0, MR1, MR2 and MR3.

The timer continuously compares its counter value with the programmed match values.

Register Function
MR0Match channel 0
MR1Match channel 1
MR2Match channel 2
MR3Match channel 3

Example

T0MR0 = 1000;

This configures match channel 0 to compare the Timer 0 counter against the value 1000.

When the counter reaches the programmed match value, the selected match actions in T0MCR can occur.

7. Match Control Register (MCR)

The Match Control Register determines what happens when a timer counter matches a match register.

For each match channel, three control bits are available:

Action MR0 bits MR1 bits MR2 bits MR3 bits
Interrupt on match Bit 0 Bit 3 Bit 6 Bit 9
Reset on match Bit 1 Bit 4 Bit 7 Bit 10
Stop on match Bit 2 Bit 5 Bit 8 Bit 11

MR0 interrupt enable

T0MCR = (1U << 0);

MR0 interrupt and reset enable

T0MCR = (1U << 0) | (1U << 1);

The second configuration generates an interrupt request and resets the timer counter when MR0 matches.

For periodic timer operation, the interrupt and reset actions are commonly enabled together. The stop action should not be enabled when continuous periodic operation is required.

8. Timer Interrupt Flag Register (IR)

The Interrupt Register stores the pending match and capture interrupt flags.

Bit Flag
0MR0 interrupt flag
1MR1 interrupt flag
2MR2 interrupt flag
3MR3 interrupt flag
4–7Capture interrupt flags CR0–CR3

Check the MR0 flag

if (T0IR & (1U << 0))
{
    /* MR0 match flag is set */
}

Clear the MR0 flag

T0IR = (1U << 0);
Timer IR flags use write-one-to-clear semantics. Write 1 to the flag that must be cleared. Avoid using T0IR |= mask because it may clear other flags that are already set.

9. VIC Configuration for Timer 0

The Timer 0 interrupt request is connected to VIC source number 4.

Important VIC registers:

  • VICIntEnable: enables an interrupt source.
  • VICIntSelect: selects IRQ or FIQ routing.
  • VICVectCntl0: configures vectored slot 0.
  • VICVectAddr0: stores the handler address for slot 0.
  • VICVectAddr: used to signal completion of a vectored IRQ.

Example configuration

#define TIMER0_SOURCE 4U

VICIntSelect &= ~(1U << TIMER0_SOURCE);

VICVectCntl0 = (1U << 5) | TIMER0_SOURCE;

VICVectAddr0 = (unsigned int)Timer0_ISR;

VICIntEnable = (1U << TIMER0_SOURCE);
The example assigns Timer 0 to vectored IRQ slot 0. The source number is 4; the slot number is 0. These values represent different things.

10. Interrupt Service Routine (ISR)

An Interrupt Service Routine is a function executed when the processor accepts an interrupt request.

A timer ISR commonly performs these operations:

  1. Identify the interrupt source.
  2. Acknowledge the timer interrupt flag.
  3. Update a counter or set an event flag.
  4. Complete VIC interrupt handling.
  5. Return from the interrupt using the compiler's correct IRQ convention.

Illustrative Timer 0 ISR

volatile unsigned int timer0_events = 0;

__irq void Timer0_ISR(void)
{
    /* Acknowledge Timer 0 MR0 interrupt */
    T0IR = (1U << 0);

    /* Record the event */
    timer0_events++;

    /* Complete VIC interrupt handling */
    VICVectAddr = 0;
}
The __irq keyword is a Keil ARM compiler convention. If using a different compiler, use that toolchain's interrupt-handler syntax and return convention. Do not mix normal C function calling conventions with an IRQ handler.

11. Complete Program: Timer 0 Interrupt

This example configures Timer 0 to generate a periodic interrupt after approximately 1000 timer counter increments.

Project clock configuration

  • PCLK = 15 MHz
  • PR = 14999
  • Timer counter increment interval = 1 ms
  • MR0 = 1000
  • Expected nominal match interval = 1 second
#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

volatile unsigned int timer0_events = 0;

__irq void Timer0_ISR(void)
{
    /* Clear Timer 0 Match 0 interrupt flag */
    T0IR = (1U << 0);

    /* Count timer interrupt events */
    timer0_events++;

    /* Signal completion to the VIC */
    VICVectAddr = 0;
}

void Timer0_Interrupt_Init(void)
{
    /* Stop and reset Timer 0 */
    T0TCR = 0x02;

    /* Configure prescaler for 1 ms TC increments */
    T0PR = 14999;

    /* Clear prescaler and timer counter */
    T0PC = 0;
    T0TC = 0;

    /* Configure Match Register 0 */
    T0MR0 = 1000;

    /* MR0 interrupt and reset on match */
    T0MCR = 0x03;

    /* Clear any previous MR0 interrupt flag */
    T0IR = (1U << 0);

    /* Route Timer 0 to IRQ */
    VICIntSelect &= ~(1U << TIMER0_SOURCE);

    /* Assign Timer 0 to vectored slot 0 */
    VICVectCntl0 =
        (1U << 5) | TIMER0_SOURCE;

    /* Install the interrupt handler */
    VICVectAddr0 = (unsigned int)Timer0_ISR;

    /* Enable Timer 0 interrupt source */
    VICIntEnable = (1U << TIMER0_SOURCE);

    /* Start Timer 0 */
    T0TCR = 0x01;
}

int main(void)
{
    Timer0_Interrupt_Init();

    while (1)
    {
        /* Main application continues here */
    }
}

Program explanation

Statement Purpose
T0TCR = 0x02 Resets Timer 0.
T0PR = 14999 Sets a 1 ms timer counter increment interval at 15 MHz PCLK.
T0MR0 = 1000 Sets the match value to 1000.
T0MCR = 0x03 Enables MR0 interrupt and reset on match.
T0IR = 1 Clears the MR0 interrupt flag.
VICVectCntl0 Assigns Timer 0 to vectored slot 0.
VICIntEnable Enables Timer 0 at the VIC.
T0TCR = 0x01 Starts Timer 0.
Expected logical behavior: The timer counter advances using the configured prescaler. When TC reaches MR0, the match interrupt flag is set, the counter is reset, and the processor services the interrupt if the interrupt path is enabled and unmasked. The ISR increments timer0_events.

12. Main Program and ISR Cooperation

The ISR should perform only short, time-critical operations. The main program can process events recorded by the ISR.

Example

#include <LPC21xx.h>

#define TIMER0_SOURCE 4U

volatile unsigned int timer0_events = 0;

__irq void Timer0_ISR(void)
{
    T0IR = (1U << 0);

    timer0_events++;

    VICVectAddr = 0;
}

void Timer0_Init(void)
{
    T0TCR = 0x02;
    T0PR = 14999;
    T0PC = 0;
    T0TC = 0;

    T0MR0 = 1000;
    T0MCR = 0x03;

    T0IR = (1U << 0);

    VICIntSelect &= ~(1U << TIMER0_SOURCE);
    VICVectCntl0 = 0x20 | TIMER0_SOURCE;
    VICVectAddr0 = (unsigned int)Timer0_ISR;

    VICIntEnable = (1U << TIMER0_SOURCE);

    T0TCR = 0x01;
}

int main(void)
{
    unsigned int processed_events = 0;

    Timer0_Init();

    while (1)
    {
        if (timer0_events != processed_events)
        {
            processed_events = timer0_events;

            /* Perform application work here */
        }
    }
}
For a production application, shared multi-byte data and read-modify-write operations must be protected appropriately against concurrent ISR access. volatile prevents certain compiler optimizations; it does not make compound operations atomic.

13. Timer 1 Interrupt Programming

Timer 1 uses a register set similar to Timer 0. Its VIC source number is 5.

Important differences

Timer 0 Timer 1
T0TCRT1TCR
T0TCT1TC
T0PRT1PR
T0MR0T1MR0
T0MCRT1MCR
T0IRT1IR
VIC source 4VIC source 5

Timer 1 initialization example

#include <LPC21xx.h>

#define TIMER1_SOURCE 5U

void Timer1_Init(void)
{
    /* Reset Timer 1 */
    T1TCR = 0x02;

    /* Configure 1 ms timer counter increments */
    T1PR = 14999;
    T1PC = 0;
    T1TC = 0;

    /* Set match value */
    T1MR0 = 1000;

    /* Interrupt and reset on MR0 match */
    T1MCR = 0x03;

    /* Clear previous MR0 flag */
    T1IR = (1U << 0);

    /* Configure Timer 1 as IRQ source */
    VICIntSelect &= ~(1U << TIMER1_SOURCE);

    /* Assign Timer 1 to slot 0 */
    VICVectCntl0 =
        (1U << 5) | TIMER1_SOURCE;

    /* Enable Timer 1 interrupt source */
    VICIntEnable = (1U << TIMER1_SOURCE);

    /* Start Timer 1 */
    T1TCR = 0x01;
}
This is an initialization outline. A complete Timer 1 application must install its own compiler-compatible ISR and configure the corresponding VIC vector address.

14. Timer Interrupt Timing Example

Consider the following configuration:

Parameter Value
PCLK15 MHz
PR14999
TC increment interval1 ms
MR01000
MCR0x03

The timer starts with TC = 0. With reset-on-match enabled, it counts through 1000 increments before reaching the match value. 

TC increment interval = 1 ms

Number of increments = 1000

Nominal match interval = 1000 x 1 ms

                       = 1000 ms

                       = 1 second
The calculated interval describes the timer match period. The actual time between ISR executions also includes interrupt latency and processor service time.

15. Polling vs Timer Interrupt

Feature Polling Timer interrupt
CPU operation Repeatedly checks timer status. Responds when an interrupt is accepted.
CPU availability Can consume processing time. Main program can perform other work.
Response Depends on polling frequency. Depends on interrupt latency and masking.
Implementation Usually simpler. Requires interrupt configuration and ISR.
Typical application Simple status monitoring. Periodic events and time-critical tasks.

16. Best Practices for Timer ISRs

  • Keep the ISR short and predictable.
  • Clear the timer peripheral interrupt flag correctly.
  • Complete VIC handling according to the interrupt architecture.
  • Use volatile for variables shared with the main program where appropriate.
  • Avoid long delay loops inside an ISR.
  • Avoid blocking UART or I2C operations inside an ISR.
  • Protect shared data when atomic access is required.
  • Choose timer match values based on the actual PCLK.
  • Check interrupt masking and priority configuration.
  • Verify the compiler-specific interrupt function declaration.

17. Common Programming Mistakes

Mistake Correct approach
Forgetting to configure PR. Calculate and configure the prescaler for the required timer tick.
Forgetting MCR interrupt enable. Set the appropriate interrupt-on-match bit.
Forgetting the VIC source number. Use Timer 0 source 4 and Timer 1 source 5.
Enabling the VIC without a handler. Install a valid vector address and handler.
Not clearing the timer flag. Write 1 to the appropriate IR flag bit.
Using T0IR |= mask. Use direct write-one-to-clear assignment.
Forgetting VIC completion. Complete vectored IRQ handling using the VIC protocol.
Using an incorrect ISR declaration. Use the correct compiler-specific IRQ convention.
Assuming the timer period equals ISR execution time. Account for interrupt latency and execution time.

18. Interview Questions and Answers

Q1. What is a timer interrupt?

It is an interrupt generated when a timer reaches a programmed condition, such as a match-register value.

Q2. How many timers are available in LPC2129?

Two: Timer 0 and Timer 1.

Q3. What is the purpose of a match register?

It stores a value that is compared with the timer counter.

Q4. What is the purpose of MCR?

It selects interrupt, reset and stop actions when a match occurs.

Q5. What is the purpose of T0IR?

It stores Timer 0 interrupt flags for match and capture events.

Q6. How do you clear the MR0 interrupt flag?

Write 1 to bit 0 of T0IR.

Q7. What is the VIC source number for Timer 0?

Source number 4.

Q8. What is the VIC source number for Timer 1?

Source number 5.

Q9. What is an ISR?

An Interrupt Service Routine is a function executed in response to an accepted interrupt request.

Q10. Why should an ISR be short?

A short ISR reduces interrupt latency and allows other application work and pending interrupts to be handled more efficiently.

Q11. What is the purpose of VICVectAddr?

Writing to VICVectAddr signals completion of vectored IRQ handling.

Q12. Can Timer 0 generate periodic interrupts?

Yes. Configure a match register, enable interrupt and reset-on-match actions, and configure the VIC.
