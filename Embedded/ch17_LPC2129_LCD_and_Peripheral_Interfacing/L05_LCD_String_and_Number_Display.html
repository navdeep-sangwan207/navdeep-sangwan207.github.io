2. Introduction to LCD Character Display

A character LCD displays information by receiving character codes from a microcontroller. The LPC2129 sends these codes through its GPIO interface.

Common display operations include:

  • Displaying a fixed message.
  • Displaying a variable string.
  • Displaying an integer value.
  • Displaying a sensor measurement.
  • Updating a status message.
  • Displaying a value with a unit such as V, A, °C or %.

3. Displaying a Single Character

A single character can be displayed by sending its character code to the LCD Data Register.

For example, uppercase A has the ASCII-compatible value 0x41.

LCD_Command(0x80);  /* Row 1, column 1 */
LCD_Data('A');

The command positions the cursor, and the data function sends the character to the LCD.

RS=0 selects command mode. RS=1 selects character-data mode. The RW signal is LOW for a write operation.

4. Displaying a String

A string is a sequence of characters stored in a character array and terminated by the null character '\0'.

Example String

char message[] = "HELLO";

LCD_Command(0x80);

for (unsigned int i = 0; message[i] != '\0'; i++)
{
    LCD_Data(message[i]);
}

How It Works

  1. The cursor is positioned at the first row.
  2. The first character is read from the string.
  3. The character is transferred to the LCD.
  4. The LCD advances its address according to entry mode.
  5. The process continues until the null terminator is reached.

Expected Display

HELLO

5. Creating a Reusable LCD String Function

Instead of writing a loop every time, a reusable function can display any null-terminated string. 

void LCD_String(const char *str)
{
    while (*str != '\0')
    {
        LCD_Data((unsigned char)*str);
        str++;
    }
}

Function Usage

LCD_Command(0x80);
LCD_String("EMBEDDED SYSTEMS");

LCD_Command(0xC0);
LCD_String("LPC2129");

Expected display:

EMBEDDED SYSTEMS
LPC2129
A 16x2 LCD has 16 character positions on each row. A longer string may continue into the next DDRAM address, but its visible placement depends on the controller's address mapping and display configuration. For predictable layouts, limit each row to 16 characters.

6. Cursor Positioning on a 16x2 LCD

The Set DDRAM Address command selects the display-memory position where the next character will be written.

PositionDDRAM AddressCommand
Row 1, column 10x000x80
Row 1, column 160x0F0x8F
Row 2, column 10x400xC0
Row 2, column 160x4F0xCF

Reusable Cursor Function

void LCD_SetCursor(unsigned char row,
                   unsigned char column)
{
    unsigned char address;

    if (row == 0U)
    {
        address = 0x00U + column;
    }
    else
    {
        address = 0x40U + column;
    }

    LCD_Command(0x80U | address);
}

Example:

LCD_SetCursor(0U, 0U);
LCD_String("VOLTAGE");

LCD_SetCursor(1U, 0U);
LCD_String("12.5 V");
This example assumes zero-based row and column values. A production function should validate that row is 0 or 1 and column is between 0 and 15 before calculating the address.

7. Displaying an Unsigned Integer

An integer is stored in binary form inside the microcontroller. A character LCD requires character codes, so the number must be converted into decimal digits.

For example:

  • Integer value: 1234
  • Decimal digits: 1, 2, 3 and 4
  • Character sequence: "1234"

Integer-to-String Conversion

void LCD_PrintUnsigned(unsigned int number)
{
    char buffer[10];
    unsigned int i = 0U;

    if (number == 0U)
    {
        LCD_Data('0');
        return;
    }

    while (number > 0U)
    {
        buffer[i++] = (char)('0' + (number % 10U));
        number /= 10U;
    }

    while (i > 0U)
    {
        LCD_Data(buffer[--i]);
    }
}

Example Usage

LCD_Command(0x80);
LCD_String("COUNT:");

LCD_PrintUnsigned(1234U);

Expected display:

COUNT:1234

Explanation

  • number % 10U extracts the last decimal digit.
  • number / 10U removes the last digit.
  • Digits are initially stored in reverse order.
  • The buffer is read backwards to display the correct number.

8. Displaying a Signed Integer

A signed integer can be positive, negative or zero. The minus sign must be displayed separately from the magnitude. 

void LCD_PrintSigned(int number)
{
    unsigned int magnitude;

    if (number < 0)
    {
        LCD_Data('-');

        /* Avoid direct negation of the most-negative int */
        magnitude = 0U - (unsigned int)number;
    }
    else
    {
        magnitude = (unsigned int)number;
    }

    LCD_PrintUnsigned(magnitude);
}

Example

LCD_Command(0x80);
LCD_String("TEMP:");

LCD_PrintSigned(-25);

Expected display:

TEMP:-25
The unsigned conversion technique avoids directly negating the most-negative signed integer, which may overflow. The code assumes the usual LPC2129 ARM C implementation where int is 32 bits.

9. Displaying a Floating-Point Value

Floating-point values contain a fractional part. They can be displayed by separating the integer and fractional components or by using a formatted conversion function.

Example

Suppose the measured voltage is 3.30 V.

float voltage = 3.30f;

/* Example only: formatted output */
printf("Voltage: %.2f V", voltage);

The printf() statement formats the number, but it does not automatically send the output to the LCD. The formatted string must be transferred through the LCD data function.

Fixed-Point Alternative

In small embedded applications, fixed-point arithmetic can reduce floating-point library requirements. 

unsigned int voltage_centi = 330U;

/* Display 3.30 */
LCD_PrintUnsigned(voltage_centi / 100U);
LCD_Data('.');

LCD_Data('0' + ((voltage_centi / 10U) % 10U));
LCD_Data('0' + (voltage_centi % 10U));

Expected output:

3.30
The fixed-point value 330 represents 3.30 when the scale factor is 100. This approach is useful for displaying sensor values, voltages, currents and temperatures.

10. Displaying ADC Readings

An ADC converts an analog input voltage into a digital result. The result can be converted into a voltage and displayed on the LCD.

For an ideal 10-bit ADC using a 3.3 V reference:

Approximate voltage = (ADC result / 1023) × 3.3 V

Example:

  • ADC result = 512
  • Reference voltage = 3.3 V
  • Approximate voltage = 1.652 V

Fixed-Point Voltage Conversion

unsigned int adc_result = 512U;
unsigned int voltage_mV;

voltage_mV = (adc_result * 3300U) / 1023U;

/* Display voltage in millivolts */
LCD_Command(0x80);
LCD_String("ADC:");

LCD_Command(0xC0);
LCD_PrintUnsigned(voltage_mV);
LCD_String(" mV");

Expected approximate display: 

ADC:
1652 mV
Use the actual ADC reference voltage and input scaling for the hardware design. This calculation assumes a 3.3 V reference and a 10-bit result. It is a mathematical display example, not a physical ADC measurement.

11. Clearing Old Characters and Formatting Rows

When a shorter string replaces a longer string, leftover characters may remain on the LCD.

Example Problem

Previous: TEMPERATURE:125
New:      TEMP:25

If the new string does not overwrite the old characters, the display may show unwanted trailing digits.

Solution: Write Spaces After the New Text

LCD_Command(0x80);
LCD_String("TEMP:25       ");

Alternative: Clear the Entire Display

LCD_Command(0x01);
/* Wait for clear execution time */
LCD_Command(0x80);
LCD_String("TEMP:25");
Repeatedly clearing the entire LCD can cause visible flicker. For frequently updated values, overwrite a fixed-width field with spaces or use a dedicated field-formatting function.

12. Complete LCD Display Driver Example

This program combines GPIO initialization, command transfer, data transfer, string display and unsigned integer conversion. It uses the course's 8-bit LCD pin mapping. 

#include <LPC21xx.h>

#define LCD_RS   (1U << 10)
#define LCD_RW   (1U << 12)
#define LCD_EN   (1U << 13)

#define LCD_DATA_MASK (0xFFU << 15)
#define LCD_ALL_MASK  (LCD_RS | LCD_RW | LCD_EN | LCD_DATA_MASK)

void Delay_Loop(volatile unsigned int count)
{
    while (count--)
    {
        /* Uncalibrated demonstration delay */
    }
}

void LCD_GPIO_Init(void)
{
    PINSEL0 &= ~((3U << 20) |
                 (3U << 24) |
                 (3U << 26) |
                 (3U << 30));

    PINSEL1 &= ~0x3FFFU;

    IODIR0 |= LCD_ALL_MASK;
    IOCLR0 = LCD_ALL_MASK;
}

void LCD_WriteBus(unsigned char value)
{
    IOCLR0 = LCD_DATA_MASK;
    IOSET0 = ((unsigned int)value << 15);
}

void LCD_EnablePulse(void)
{
    IOSET0 = LCD_EN;
    Delay_Loop(10U);
    IOCLR0 = LCD_EN;
    Delay_Loop(10U);
}

void LCD_Command(unsigned char command)
{
    IOCLR0 = LCD_RS | LCD_RW;
    LCD_WriteBus(command);
    LCD_EnablePulse();

    /* Placeholder: use datasheet-compliant execution timing */
    Delay_Loop(5000U);
}

void LCD_Data(unsigned char data)
{
    IOSET0 = LCD_RS;
    IOCLR0 = LCD_RW;
    LCD_WriteBus(data);
    LCD_EnablePulse();

    /* Placeholder: use datasheet-compliant execution timing */
    Delay_Loop(5000U);
}

void LCD_String(const char *str)
{
    while (*str != '\0')
    {
        LCD_Data((unsigned char)*str);
        str++;
    }
}

void LCD_PrintUnsigned(unsigned int number)
{
    char buffer[10];
    unsigned int i = 0U;

    if (number == 0U)
    {
        LCD_Data('0');
        return;
    }

    while (number > 0U)
    {
        buffer[i++] = (char)('0' + (number % 10U));
        number /= 10U;
    }

    while (i > 0U)
    {
        LCD_Data((unsigned char)buffer[--i]);
    }
}

void LCD_Init(void)
{
    Delay_Loop(50000U);

    LCD_Command(0x38U);
    LCD_Command(0x0CU);
    LCD_Command(0x06U);
    LCD_Command(0x01U);

    /* Longer clear-display wait; calibrate for the controller */
    Delay_Loop(50000U);
}

int main(void)
{
    LCD_GPIO_Init();
    LCD_Init();

    LCD_Command(0x80U);
    LCD_String("COUNT:");

    LCD_PrintUnsigned(1234U);

    LCD_Command(0xC0U);
    LCD_String("LPC2129 LCD");

    while (1)
    {
    }
}

Expected Display

COUNT:1234
LPC2129 LCD
The delay loop is illustrative and not calibrated. A real LCD driver must use verified timing. The program also assumes an 8-bit HD44780-compatible LCD and the pin mapping in this course.

14. Common Programming Mistakes

  • Sending a character while RS is LOW.
  • Sending a command while RS is HIGH.
  • Forgetting the null terminator in a string.
  • Displaying more than 16 characters without planning the layout.
  • Using an incorrect DDRAM address for the second row.
  • Forgetting to convert numbers into character digits.
  • Leaving old characters visible after updating a shorter value.
  • Using uncalibrated delays in a real application.
  • Assuming printf() sends data directly to the LCD.
  • Using a floating-point format without checking compiler library support.

15. Interview Questions and Answers

Q1. How is a string displayed on an LCD?

Send each character in the null-terminated string using the LCD data function.

Q2. What is the purpose of the null character?

It marks the end of a C string.

Q3. Why must an integer be converted before display?

The LCD expects character codes, whereas an integer is stored as a binary numeric value.

Q4. How can an integer be converted into decimal digits?

Repeatedly divide by 10 and extract each remainder, then output the digits in reverse order.

Q5. How can a negative number be displayed?

Display a minus sign and then display the magnitude of the number.

Q6. Why can old characters remain after a display update?

The new string may be shorter than the previous string and may not overwrite every old position.

Q7. How do you position the cursor at row two, column one?

Send command 0xC0 on a typical HD44780-compatible 16x2 LCD.

Q8. Can printf() directly display a number on an LCD?

No. Its formatted output must be directed to an LCD output function or buffer.

Q9. What is fixed-point representation?

It stores a scaled integer to represent a fractional value without requiring floating-point arithmetic.

Q10. Why should an LCD not be cleared on every update?

Frequent clearing can cause visible flicker and unnecessary display delays.

16. Multiple-Choice Questions

1. Which character terminates a C string?

A. Space

B. '\n'

C. '\0'

D. '\t'

Answer: C. '\0'

2. Which command selects the first position of row two?

A. 0x80

B. 0xC0

C. 0x01

D. 0x06

Answer: B. 0xC0

3. Which operator extracts the last decimal digit?

A. /

B. *

C. %

D. &

Answer: C. %

4. What does number / 10 do for an unsigned integer?

A. Adds a digit

B. Removes the last decimal digit

5. Why is a number converted before display?

A. LCD accepts only floating point
