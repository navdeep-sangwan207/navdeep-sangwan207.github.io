2. What Does 16x2 LCD Mean?

A 16x2 LCD is a character display module containing two visible rows, with 16 character positions in each row.

  • Number of rows: 2
  • Characters per row: 16
  • Total visible character positions: 32
  • Typical character matrix: 5 columns × 8 dots per character

Each character is represented by a character code. The LCD controller uses its character-generation circuitry to convert that code into a dot pattern for display.

3.1 LCD Controller

The LCD controller receives instructions and character data from the microcontroller. It manages the display state, cursor position, memory access and character output.

3.2 Instruction Register (IR)

The instruction register receives commands from the microcontroller. Examples include:

  • Clear display.
  • Return cursor to home position.
  • Set entry mode.
  • Set display control.
  • Set DDRAM address.

3.3 Data Register (DR)

The data register is used to transfer character codes to or from the LCD's data memory. A character code written to the data register can be stored in DDRAM at the current address.

3.4 Address Counter (AC)

The address counter holds the address used for DDRAM or CGRAM access. It is updated according to the selected instruction and entry mode.

3.5 Character Generator

The character generator produces the dot patterns corresponding to character codes. Predefined patterns are generally stored in CGROM, while user-defined character patterns can be stored in CGRAM.

4. LCD Memory Organization

4.1 DDRAM – Display Data RAM

DDRAM stores the character codes associated with display positions. For the common HD44780-compatible 16x2 module, the visible positions are normally mapped as follows:

Display Position DDRAM Address
First row, first character0x00
First row, sixteenth character0x0F
Second row, first character0x40
Second row, sixteenth character0x4F
To position the cursor at the beginning of the first row, the commonly used command is 0x80 (set DDRAM address 0x00). For the beginning of the second row, the commonly used command is 0xC0 (set DDRAM address 0x40).

These commands combine the DDRAM-address instruction bit with the desired address. The mapping shown is typical for a standard 16x2 HD44780-compatible module; verify the controller documentation for other modules.

4.2 CGROM – Character Generator ROM

CGROM stores predefined character patterns, such as letters, digits and commonly supported symbols.

4.3 CGRAM – Character Generator RAM

CGRAM stores custom character patterns created by the programmer. On a common HD44780-compatible controller, up to eight custom 5x8 characters can be stored at one time.

CGRAM is useful when an application needs special symbols that are not available in the predefined character set. The exact character encoding and available symbols depend on the controller's character ROM.
Memory Purpose Typical Use
DDRAM Stores display character codes Text shown on the LCD
CGROM Stores predefined character patterns Letters, digits and symbols
CGRAM Stores custom character patterns User-defined icons and symbols

Power and Contrast Connections

  • VSS is normally connected to ground.
  • VDD is connected to the supply specified by the LCD datasheet.
  • V0/VEE is used to adjust character contrast.
  • A potentiometer is commonly used for contrast adjustment.
  • Backlight pins must be connected according to the module's electrical specifications.
Do not assume every LCD module uses the same supply voltage or backlight current. Check the specific module datasheet and use a suitable current-limiting arrangement where required.

6. RS – Register Select Pin

The RS pin selects which internal LCD register receives the microcontroller's operation.

RS Level Selected Operation
0 Instruction/command register
1 Data register

Example

  • To clear the display, RS is LOW.
  • To display the character 'A', RS is HIGH.
/* Select command register */
IOCLR0 = (1U << 10);

/* Select data register */
IOSET0 = (1U << 10);

7. RW – Read/Write Pin

The RW pin selects whether the LCD controller performs a read or write operation.

RW Level Operation
0 Write to LCD
1 Read from LCD

Write Operation

When RW is LOW, the microcontroller can send commands or character data to the LCD.

Read Operation

When RW is HIGH, the microcontroller can read information from the LCD data bus. Depending on RS, this can include status information or display data.

In this course's basic write-only interface, RW is controlled through P0.12 and held LOW during writes. It can alternatively be connected permanently to ground if LCD read operations are not required.

8. EN – Enable Pin

The Enable pin controls the LCD data-transfer operation. The microcontroller places the required control and data signals on the LCD interface and applies the enable pulse.

Basic Write Sequence

  1. Set RS according to command or data mode.
  2. Set RW LOW for writing.
  3. Place the byte on D0-D7 in 8-bit mode.
  4. Ensure the required setup time.
  5. Apply the enable pulse.
  6. Allow the required hold and execution time.

The actual enable pulse width and data setup/hold times must follow the LCD controller datasheet. Do not assume an arbitrary pulse width is valid for every module.

9. Data Pins D0-D7

The data pins carry commands, character codes and, when reading is enabled, information from the LCD controller.

8-Bit Mode

All eight data pins D0-D7 are used. One complete byte is transferred during each bus operation.

4-Bit Mode

Only D4-D7 are used. A byte is transferred in two portions:

  1. Upper four bits are transferred first.
  2. Lower four bits are transferred second.
The LCD data pins must be connected in the correct bit order. For example, D0 must connect to the microcontroller signal intended to carry bit 0, not bit 7.

GPIO Direction Configuration

All selected LCD pins are configured as outputs using IODIR0. 

#include <LPC21xx.h>

#define LCD_RS   (1U << 10)
#define LCD_RW   (1U << 12)
#define LCD_EN   (1U << 13)

#define LCD_DATA_MASK (0xFFU << 15)

#define LCD_CONTROL_MASK (LCD_RS | LCD_RW | LCD_EN)
#define LCD_ALL_MASK (LCD_CONTROL_MASK | LCD_DATA_MASK)

void LCD_Pin_Init(void)
{
    /* P0.10, P0.12 and P0.13 as GPIO */
    PINSEL0 &= ~((3U << 20) |
                 (3U << 24) |
                 (3U << 26));

    /* P0.15 as GPIO */
    PINSEL0 &= ~(3U << 30);

    /* P0.16 to P0.22 as GPIO */
    PINSEL1 &= ~(0x3FFFU);

    /* Set LCD interface pins as outputs */
    IODIR0 |= LCD_ALL_MASK;

    /* Initialize output states */
    IOCLR0 = LCD_ALL_MASK;
}

int main(void)
{
    LCD_Pin_Init();

    while (1)
    {
        /* LCD communication will be implemented
           in the following lessons. */
    }
}

Code Explanation

  • The macros define the control signals and data bus mask.
  • PINSEL0 fields are cleared for the selected lower Port 0 pins.
  • PINSEL1 fields are cleared for P0.16 to P0.22.
  • IODIR0 configures all LCD interface pins as outputs.
  • IOCLR0 initializes the output signals LOW.
This initialization assumes the listed pins are reserved for the LCD. It changes their pin-function selection and output direction. Do not use these same pins simultaneously for UART, SPI, I2C, LEDs or other peripherals without redesigning the pin assignment.

13. Interview Questions and Answers

Q1. What is the function of DDRAM?

DDRAM stores character codes associated with the LCD display positions.

Q2. What is CGROM?

CGROM stores predefined character patterns used by the LCD controller.

Q3. What is CGRAM?

CGRAM stores custom character patterns created by the programmer.

Q4. What is the function of the LCD address counter?

It holds the current memory address used for DDRAM or CGRAM access.

Q5. What is the purpose of the contrast pin?

It adjusts the visibility of characters against the LCD background.

Q6. Which LCD pin selects command or data mode?

RS, or Register Select.

Q7. Which LCD pins carry character data in 8-bit mode?

D0 through D7.

Q8. What is the typical DDRAM address of the first position in row two?

0x40 for a common HD44780-compatible 16x2 module.

Q9. How many custom 5x8 characters can a typical HD44780 controller store simultaneously?

Eight, using its CGRAM.

Q10. Which LPC2129 register controls GPIO direction?

IODIR0 controls the direction of Port 0 pins.

17. Lesson Summary

  • A 16x2 LCD contains two rows with 16 character positions per row.
  • The LCD controller manages commands, data, memory and display operations.
  • DDRAM stores character codes for display positions.
  • CGROM stores predefined character patterns.
  • CGRAM stores user-defined character patterns.
  • RS selects command or data mode.
  • RW selects read or write operation.
  • EN controls data transfer.
  • V0/VEE adjusts display contrast.
  • The LPC2129 uses PINSEL0, PINSEL1 and IODIR0 for the selected LCD GPIO pins.
