2. Introduction to Sensors

A sensor is a device that detects a physical quantity and converts it into an electrical signal that can be measured or processed by an electronic system.

Common physical quantities measured by sensors include:

  • Temperature.
  • Pressure.
  • Light intensity.
  • Humidity.
  • Distance and position.
  • Motion and acceleration.
  • Sound and vibration.
  • Gas concentration.
In an embedded system, a sensor provides information about the physical environment. The microcontroller reads the sensor signal, processes the measurement and performs an appropriate action.

4. Classification of Sensors

4.1 Analog Sensors

An analog sensor produces a continuously varying output voltage or current corresponding to the measured physical quantity.

Examples:

  • LM35 temperature sensor.
  • Analog light sensor circuits.
  • Potentiometric position sensors.
  • Analog pressure sensors.
  • Analog gas-sensor modules.

4.2 Digital Sensors

A digital sensor provides a digital output or communicates measurement data through a digital communication interface.

Examples:

  • Digital temperature sensors.
  • Digital humidity sensors.
  • Digital proximity sensors.
  • Digital motion sensors.
  • I2C and SPI sensor modules.

6. LPC2129 ADC for Analog Sensor Interfacing

The LPC2129 includes a 10-bit successive-approximation ADC with four analog input channels: AIN0, AIN1, AIN2 and AIN3.

The 10-bit ADC produces:

Number of ADC codes = 2^10
                    = 1024

Minimum code = 0
Maximum code = 1023

The ADC converts an analog input voltage into a digital result. The microcontroller then uses the result to calculate the corresponding sensor measurement.

ADC ChannelLPC2129 Pin
AIN0P0.27
AIN1P0.28
AIN2P0.29
AIN3P0.30
The ADC input voltage must remain within the permitted analog input range and must not exceed the specified V_DDA limit. Do not assume that a digital pin's voltage tolerance also applies to its analog input path.

7. ADC Conversion Formula

For an ideal 10-bit ADC using a 3.3 V reference, an approximate endpoint-scaled voltage calculation is: 

Measured Voltage =
    (ADC Result / 1023) × VREF

Example: if the ADC result is 512:

ADC Result = 512
VREF       = 3.3 V

Voltage = (512 / 1023) × 3.3

        ≈ 1.652 V
This is an approximate conversion formula. Actual accuracy depends on ADC reference voltage, offset and gain errors, input noise, sensor tolerances and calibration.

8. Example: LM35 Temperature Sensor

The LM35 is an analog temperature sensor whose nominal output scaling is 10 mV per degree Celsius. 

LM35 Output Voltage = Temperature × 10 mV

Temperature (°C) = Sensor Voltage (mV) / 10

Example:

TemperatureNominal LM35 Output
0°C0 mV
25°C250 mV
50°C500 mV
75°C750 mV
100°C1000 mV

If the measured sensor voltage is 0.25 V: 

Temperature = 0.25 / 0.010

            = 25°C
Check the exact LM35 variant, supply requirements, output range, accuracy and operating conditions in its datasheet. Do not apply a negative sensor voltage to the LPC2129 ADC input.

Connection Considerations

  • Connect the sensor output to the selected analog input.
  • Connect sensor ground to the appropriate system ground.
  • Provide the sensor with its specified supply voltage.
  • Configure the corresponding PINSEL field for ADC operation.
  • Configure the ADC clock within the device specification.
  • Use filtering or buffering when required.

10. ADC Pin Configuration for AIN0

For the LPC2129, AIN0 is available on P0.27. Its function is selected through PINSEL1 bits 23:22. 

/* Select AIN0 function on P0.27 */
PINSEL1 &= ~(3U << 22);
PINSEL1 |=  (1U << 22);

The two-bit field is set to 01 to select the AIN0 function on this pin.

11. ADC Initialization for Sensor Measurement

The following example uses the legacy LPC2129 ADC register interface with ADCR and ADDR. 

#include <LPC21xx.h>

#define ADC_CLKDIV 3U
#define ADC_PDN    (1U << 21)
#define ADC_START  (1U << 24)
#define ADC_DONE   (1U << 31)

void ADC_Init(void)
{
    /* Configure P0.27 as AIN0 */
    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    /*
     * PCLK = 15 MHz
     * CLKDIV = 3
     * ADC clock = 15 MHz / 4 = 3.75 MHz
     */
    ADCR = (1U << 0) |
           (ADC_CLKDIV << 8) |
           ADC_PDN;
}
The ADC clock must not exceed the device's specified maximum. For the 15 MHz peripheral clock used in this course, CLKDIV=3 produces a 3.75 MHz ADC clock.

12. Reading an Analog Sensor

The following function starts an AIN0 conversion, waits for completion and extracts the 10-bit result. 

unsigned int ADC_Read_AIN0(void)
{
    unsigned int result;

    /* Start an immediate conversion */
    ADCR &= ~(7U << 24);
    ADCR |= ADC_START;

    /* Wait for conversion completion */
    do
    {
        result = ADDR;
    }
    while ((result & ADC_DONE) == 0U);

    /* Extract RESULT bits [15:6] */
    return ((result >> 6) & 0x3FFU);
}

The function returns a value from 0 to 1023. This value can then be converted into voltage and subsequently into the physical measurement represented by the sensor.

This example uses the legacy LPC2129 ADCR/ADDR interface. ADC peripheral simulation and analog stimulus support depend on the selected Keil device model. Do not assume the simulator automatically provides a changing analog input.

13. Converting ADC Reading into Sensor Voltage

float ADC_To_Voltage(unsigned int adc_result)
{
    return ((float)adc_result * 3.3f) / 1023.0f;
}

This function converts the ADC result into an approximate voltage using a 3.3 V reference. Replace 3.3 V with the actual reference voltage used by the ADC system.

14. Complete LM35 Temperature Measurement Example

This program reads AIN0, converts the ADC result into voltage and calculates an approximate LM35 temperature. 

#include <LPC21xx.h>

#define ADC_CLKDIV 3U
#define ADC_PDN    (1U << 21)
#define ADC_START  (1U << 24)
#define ADC_DONE   (1U << 31)

#define VREF 3.3f
#define ADC_MAX 1023.0f
#define LM35_SCALE 0.010f

void ADC_Init(void)
{
    PINSEL1 &= ~(3U << 22);
    PINSEL1 |=  (1U << 22);

    ADCR = (1U << 0) |
           (ADC_CLKDIV << 8) |
           ADC_PDN;
}

unsigned int ADC_Read_AIN0(void)
{
    unsigned int data;

    ADCR &= ~(7U << 24);
    ADCR |= ADC_START;

    do
    {
        data = ADDR;
    }
    while ((data & ADC_DONE) == 0U);

    return ((data >> 6) & 0x3FFU);
}

float ADC_To_Voltage(unsigned int result)
{
    return ((float)result * VREF) / ADC_MAX;
}

float LM35_GetTemperature(float voltage)
{
    return voltage / LM35_SCALE;
}

int main(void)
{
    unsigned int adc_value;
    float sensor_voltage;
    float temperature;

    ADC_Init();

    while (1)
    {
        adc_value = ADC_Read_AIN0();

        sensor_voltage = ADC_To_Voltage(adc_value);

        temperature = LM35_GetTemperature(sensor_voltage);

        /*
         * Use temperature for display,
         * threshold comparison or logging.
         */
    }
}

Program Operation

  1. Configure P0.27 for AIN0.
  2. Initialize the ADC peripheral.
  3. Start an ADC conversion.
  4. Wait for the DONE flag.
  5. Extract the 10-bit ADC result.
  6. Calculate the sensor voltage.
  7. Convert the voltage into temperature.
  8. Use the measurement in the application.
The example assumes a nominal 3.3 V ADC reference and an LM35 output compatible with the selected ADC input. It does not include calibration, noise filtering, timeout handling or sensor-disconnection detection. The floating-point calculation is illustrative and may require optimization in a resource- constrained embedded application.

15. Digital Sensor Interfacing Using GPIO

Some sensors provide a simple HIGH or LOW output. Such sensors can be connected to a digital GPIO input if their output voltage, current and electrical interface are compatible with the LPC2129.

Examples include:

  • Digital proximity switches.
  • Limit switches.
  • Digital motion detector modules.
  • Comparator-based light detection modules.
  • Digital threshold output modules.

Example: Digital Sensor on P0.6

#include <LPC21xx.h>

#define SENSOR_PIN (1U << 6)

void Sensor_GPIO_Init(void)
{
    /* Select GPIO on P0.6 */
    PINSEL0 &= ~(3U << 12);

    /* Configure as input */
    IODIR0 &= ~SENSOR_PIN;
}

unsigned int Sensor_Read(void)
{
    return ((IOPIN0 >> 6) & 1U);
}

int main(void)
{
    unsigned int sensor_state;

    Sensor_GPIO_Init();

    while (1)
    {
        sensor_state = Sensor_Read();

        if (sensor_state == 1U)
        {
            /* Sensor output is HIGH */
        }
        else
        {
            /* Sensor output is LOW */
        }
    }
}
The program interprets HIGH as detected and LOW as not detected only as an example. Actual sensor output polarity depends on the module. Some sensors are active-LOW or use open-collector outputs that require suitable pull-up circuitry.

17. Signal Conditioning

Signal conditioning modifies a sensor signal so that it can be measured reliably by the microcontroller.

Common Signal-Conditioning Operations

  • Amplification: increases a low-level signal.
  • Attenuation: reduces a signal that exceeds the ADC input range.
  • Filtering: reduces unwanted frequency components and noise.
  • Level shifting: adjusts the voltage range.
  • Isolation: separates electrical domains when required.
  • Buffering: reduces loading on the sensor output.
  • Linearization: compensates for nonlinear sensor response.

18. Noise Filtering and Averaging

Analog sensor signals may contain electrical noise. A simple software technique is to take multiple ADC samples and calculate their average. 

unsigned int ADC_ReadAverage(unsigned int samples)
{
    unsigned long sum = 0U;
    unsigned int i;

    if (samples == 0U)
    {
        return 0U;
    }

    for (i = 0U; i < samples; i++)
    {
        sum += ADC_Read_AIN0();
    }

    return (unsigned int)(sum / samples);
}

Averaging can reduce uncorrelated random noise, but it does not remove all errors. It can also slow the response to a changing signal.

Other Filtering Methods

  • Moving average filter.
  • First-order low-pass digital filter.
  • Median filter for impulse noise.
  • Analog RC low-pass filter before the ADC.

19. Sensor Calibration

Calibration compares sensor readings against a known reference and determines the correction needed to improve measurement accuracy.

Two-Point Linear Calibration

If a sensor system has an approximately linear response, two reference points can be used to calculate slope and offset. 

Measured Quantity = Slope × ADC Value + Offset

Slope =
    (Reference_2 - Reference_1) /
    (ADC_2 - ADC_1)

Offset =
    Reference_1 - (Slope × ADC_1)

Calibration should be performed across the intended operating range and repeated when drift or environmental changes require it.

20. Sensor Threshold Detection

An embedded system can compare a measured sensor value against a predefined threshold and activate an output. 

if (temperature >= 50.0f)
{
    /* Activate alarm */
}
else
{
    /* Deactivate alarm */
}

Hysteresis

If the sensor value fluctuates around a single threshold, the output may switch rapidly between ON and OFF. Hysteresis uses separate activation and deactivation thresholds. 

if (temperature >= 50.0f)
{
    alarm_state = 1U;
}
else if (temperature <= 47.0f)
{
    alarm_state = 0U;
}

Between 47°C and 50°C, the previous alarm state is retained. This reduces unnecessary switching near the threshold.

22. Sensor-Based Embedded Applications

Temperature Monitoring

An analog temperature sensor feeds the ADC. The microcontroller calculates temperature and displays it on an LCD.

Automatic Lighting

A light sensor measures ambient illumination. The microcontroller compares the reading against a threshold and controls a lighting driver.

Object Detection

A digital proximity sensor provides a logic output. The microcontroller reads the input and controls an alarm or actuator.

Environmental Monitoring

Digital temperature and humidity sensors communicate with the microcontroller through I2C or another supported interface.

23. Interview Questions and Answers

Q1. What is a sensor?

A sensor detects a physical quantity and converts it into a measurable electrical signal.

Q2. What is the difference between an analog and digital sensor?

An analog sensor provides a continuously varying signal, while a digital sensor provides logic states or encoded digital measurement data.

Q3. What is sensitivity?

Sensitivity describes the change in sensor output for a change in the measured input quantity.

Q4. What is the resolution of the LPC2129 ADC?

The ADC resolution is 10 bits, providing 1024 possible codes.

Q5. How many ADC channels are available on the LPC2129?

The LPC2129 provides four analog input channels: AIN0 to AIN3.

Q6. What is signal conditioning?

It prepares a sensor signal for reliable measurement through operations such as amplification, filtering and level adjustment.

Q7. What is sensor calibration?

Calibration compares sensor measurements with known references and determines correction factors.

Q8. Why is averaging used in sensor measurement?

Averaging can reduce the effect of uncorrelated random noise across multiple samples.

Q9. What is hysteresis?

Hysteresis uses different activation and deactivation thresholds to prevent rapid switching near a single threshold.

Q10. Why must ADC input voltage be limited?

To keep the input within the specified analog electrical limits and prevent inaccurate measurements or device damage.
