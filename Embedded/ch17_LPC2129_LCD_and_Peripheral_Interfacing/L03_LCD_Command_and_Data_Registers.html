1. Learning Objectives

After completing this lesson, you will be able to:

  • Differentiate between command transfer and character-data transfer.

  • Use command and data functions in Embedded C.
  • Understand how LCD commands are transferred through LPC2129 GPIO.

2. Introduction to LCD Registers

A standard HD44780-compatible LCD controller provides two main register-selection paths:

  • Instruction Register (IR): Receives commands that control the LCD.
  • Data Register (DR): Transfers character data to or from the LCD.

The RS control signal selects which register is accessed. The RW signal selects whether the operation is a read or a write.

↓ RS, RW, EN and D0-D7

3. Instruction Register (IR)

The Instruction Register receives commands from the microcontroller. These commands control the operation and configuration of the LCD.

Examples of instruction operations include:

  • Clear the display.
  • Return the cursor to the home position.
  • Set the interface data length.
  • Select the number of display lines.
  • Control the display, cursor and blinking.
  • Set the entry mode.
  • Set the DDRAM or CGRAM address.

Command Transfer Conditions

SignalLevelMeaning
RS0Select instruction register
RW0Write command
ENPulseLatch the command transfer

For example, to clear the display, the microcontroller places 0x01 on the data bus while RS=0 and RW=0, then performs the required enable pulse.

4. Data Register (DR)

The Data Register is used to transfer character codes between the microcontroller and the LCD controller.

When the microcontroller writes a character code, the LCD controller stores it at the current DDRAM address and displays the corresponding character according to the display configuration.

Data Transfer Conditions

SignalLevelMeaning
RS1Select data register
RW0Write character data
ENPulseLatch the data transfer

Example: Sending Character A

In the commonly used ASCII-compatible character set, uppercase A has the hexadecimal code 0x41. 

RS = 1;
RW = 0;
DATA = 0x41;

/* Apply the required EN pulse */

The LCD controller interprets the received byte as character data, not as an instruction.

5. Difference Between Command and Data Registers

Feature Instruction Register Data Register
Purpose Controls LCD operation Transfers character data
RS signal 0 1
Typical write operation Command transfer Character transfer
Example 0x01 – Clear display 0x41 – Character A
Effect Changes controller configuration or state Writes character data into display memory
The LCD has separate instruction and data access paths selected by RS. The microcontroller does not normally access these internal registers as memory-mapped LPC2129 registers. It selects them using the LCD control pins.

6. RW Signal and LCD Read Operations

The RW signal determines the direction of communication.

RS RW Operation
00Write instruction
10Write character data
01Read busy flag and address counter
11Read data from DDRAM or CGRAM

Busy Flag

The busy flag indicates whether the LCD controller is executing an operation. In the common HD44780-compatible interface, it is read from data-bus bit D7 when RS=0 and RW=1.

  • BF = 1: Controller is busy.
  • BF = 0: Controller is ready for another instruction or data transfer.
If RW is connected permanently to ground, the microcontroller cannot read the busy flag. In that write-only arrangement, software must provide delays that satisfy the LCD controller's execution-time requirements.

8. Clear Display Command – 0x01

The Clear Display command clears the visible display contents by writing spaces to the display positions and returns the address counter to the home position.

Command Details

  • Hexadecimal value: 0x01
  • RS = 0
  • RW = 0
  • Data bus = 0x01
LCD_RS = 0;
LCD_RW = 0;
LCD_DATA = 0x01;

9. Return Home Command – 0x02

The Return Home command moves the cursor to the beginning of the first row and restores the display shift to its home position.

  • Command value: 0x02
  • RS = 0
  • RW = 0
  • Cursor address returns to DDRAM address 0x00.

Unlike Clear Display, Return Home does not erase the stored character data from DDRAM.

10. Entry Mode Set Command

The Entry Mode Set command determines how the address counter changes after a character is written and whether the display shifts.

The command format is:

0 0 0 0 0 1 I/D S
Bit Name Function
I/DIncrement/Decrement1 = increment address; 0 = decrement address.
SShift1 = shift display; 0 = no display shift.

Common Entry Mode Commands

CommandMeaning
0x06Increment address, no display shift
0x04Decrement address, no display shift
0x07Increment address and shift display
0x05Decrement address and shift display
The most common setting is 0x06. It advances the cursor position after each character write without shifting the visible display.

11. Display Control Command

The Display Control command controls the display, cursor and cursor blinking.

Command format:

13. Set DDRAM Address Command

The Set DDRAM Address command moves the cursor to a specified display-memory location.

For the common HD44780-compatible 16x2 arrangement:

PositionDDRAM AddressCommand
Row 1, column 10x000x80
Row 1, column 50x040x84
Row 2, column 10x400xC0
Row 2, column 50x440xC4

The command is formed by setting bit 7 and placing the address in bits 6:0.

LCD_Command(0x80);  /* First row, first position */
LCD_Command(0xC0);  /* Second row, first position */

14. Command and Data Transfer Using LPC2129

The LPC2129 uses GPIO signals to select the LCD register and place the command or data byte on the data bus.

Project Signal Definitions

#include <LPC21xx.h>

#define LCD_RS   (1U << 10)
#define LCD_RW   (1U << 12)
#define LCD_EN   (1U << 13)

#define LCD_DATA_MASK (0xFFU << 15)

Writing a Byte to the LCD Data Bus

void LCD_WriteBus(unsigned char value)
{
    /* Clear previous data output */
    IOCLR0 = LCD_DATA_MASK;

    /* Place the new byte on P0.15 to P0.22 */
    IOSET0 = ((unsigned int)value << 15);
}

Writing a Command

void LCD_Command(unsigned char command)
{
    /* Select instruction register */
    IOCLR0 = LCD_RS;

    /* Select write operation */
    IOCLR0 = LCD_RW;

    /* Place command on data bus */
    LCD_WriteBus(command);

    /* Generate enable pulse */
    IOSET0 = LCD_EN;

    /* Datasheet-compliant enable timing is required */

    IOCLR0 = LCD_EN;

    /* Wait for the command execution time */
}

Writing Character Data

void LCD_Data(unsigned char data)
{
    /* Select data register */
    IOSET0 = LCD_RS;

    /* Select write operation */
    IOCLR0 = LCD_RW;

    /* Place character code on data bus */
    LCD_WriteBus(data);

    /* Generate enable pulse */
    IOSET0 = LCD_EN;

    /* Datasheet-compliant enable timing is required */

    IOCLR0 = LCD_EN;

    /* Wait for the data-write execution time */
}
These functions illustrate register selection and bus operation. The enable pulse and execution delays are intentionally not calibrated here. A working driver must implement timing according to the exact LCD controller datasheet. Lesson 04 develops initialization and command sequencing.

Code Explanation

  • LCD_WriteBus() places an 8-bit value on P0.15–P0.22.
  • LCD_Command() sets RS=0 and RW=0.
  • LCD_Data() sets RS=1 and RW=0.
  • Both functions use the same data bus.
  • EN controls the transfer into the LCD controller.

15. Complete Command and Data Demonstration

The following program demonstrates GPIO initialization and the separation between command and character-data operations. It is not yet a complete timed LCD driver. 

#include <LPC21xx.h>

#define LCD_RS   (1U << 10)
#define LCD_RW   (1U << 12)
#define LCD_EN   (1U << 13)

#define LCD_DATA_MASK (0xFFU << 15)
#define LCD_ALL_MASK (LCD_RS | LCD_RW | LCD_EN | LCD_DATA_MASK)

void LCD_GPIO_Init(void)
{
    PINSEL0 &= ~((3U << 20) |
                 (3U << 24) |
                 (3U << 26) |
                 (3U << 30));

    PINSEL1 &= ~0x3FFFU;

    IODIR0 |= LCD_ALL_MASK;
    IOCLR0 = LCD_ALL_MASK;
}

void LCD_WriteBus(unsigned char value)
{
    IOCLR0 = LCD_DATA_MASK;
    IOSET0 = ((unsigned int)value << 15);
}

void LCD_Command(unsigned char command)
{
    IOCLR0 = LCD_RS | LCD_RW;
    LCD_WriteBus(command);

    IOSET0 = LCD_EN;
    /* Add required enable timing */
    IOCLR0 = LCD_EN;

    /* Add command execution delay */
}

void LCD_Data(unsigned char data)
{
    IOSET0 = LCD_RS;
    IOCLR0 = LCD_RW;
    LCD_WriteBus(data);

    IOSET0 = LCD_EN;
    /* Add required enable timing */
    IOCLR0 = LCD_EN;

    /* Add data execution delay */
}

int main(void)
{
    LCD_GPIO_Init();

    /* Demonstration of register selection */
    LCD_Command(0x38);
    LCD_Command(0x0C);
    LCD_Command(0x06);
    LCD_Command(0x01);

    LCD_Data('A');

    while (1)
    {
    }
}
The program demonstrates the command/data distinction. Because it does not implement the required power-up wait and calibrated LCD timing, it must not be treated as a complete working display driver. The next lesson covers the initialization sequence.

16. Common Mistakes

  • Using RS=1 when sending a command.
  • Using RS=0 when sending character data.
  • Leaving RW HIGH during a write operation.
  • Sending a command before the LCD is initialized.
  • Ignoring the execution time of Clear Display and Return Home.
  • Using an incorrect DDRAM address.
  • Mixing 4-bit and 8-bit transfer methods.
  • Failing to configure the LPC2129 GPIO pins.
  • Assuming the command/data functions alone guarantee correct timing.

17. Interview Questions and Answers

Q1. What is the purpose of the LCD Instruction Register?

It receives commands that configure and control the LCD.

Q2. What is the purpose of the LCD Data Register?

It transfers character data between the microcontroller and the LCD controller.

Q3. Which RS value selects the instruction register?

RS=0.

Q4. Which RS value selects the data register?

RS=1.

Q5. What is the command to clear the display?

0x01.

Q6. What is the command for display ON and cursor OFF?

0x0C.

Q7. What does command 0x06 do?

It selects incrementing address mode without display shifting.

Q8. What does command 0x38 configure?

It selects an 8-bit interface, two-line mode and a 5x8 font.

Q9. How is the cursor moved to the beginning of the second row?

Send command 0xC0 on a typical HD44780-compatible 16x2 module.

Q10. What is the busy flag?

It indicates whether the LCD controller is executing an operation.

21. Lesson Summary

  • The LCD instruction register receives commands.
  • The LCD data register transfers character codes.
  • RS=0 selects command access; RS=1 selects data access.
  • RW=0 selects a write operation; RW=1 selects a read operation.
  • The busy flag indicates controller execution status.
  • 0x01 clears the display.
  • 0x02 returns the cursor to home.
  • 0x06 selects incrementing entry mode without display shift.
  • 0x0C turns the display on and cursor off.
  • 0x38 selects an 8-bit, two-line, 5x8 font configuration.
  • LCD timing must follow the controller datasheet.
