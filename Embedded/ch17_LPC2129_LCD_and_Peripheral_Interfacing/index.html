Chapter Overview

Peripheral interfacing is an essential part of embedded system development. A microcontroller communicates with external devices through GPIO pins and suitable hardware interfaces.

In this chapter, you will study character LCD operation, keypad input, seven-segment displays, buzzers, relays and sensor interfacing. You will also learn how to combine multiple peripherals in practical embedded applications.

Practical focus: The examples use the LPC2129 GPIO architecture and Embedded C. Hardware connections, voltage requirements and external driver circuits must be considered when implementing these projects.

Learning Objectives

After completing this chapter, you should be able to:

  • Explain the working principle of character LCD modules.
  • Identify the pins and internal architecture of a 16x2 LCD.
  • Differentiate between LCD command and data operations.
  • Initialize an LCD and display characters, strings and numbers.
  • Interface a matrix keypad and identify pressed keys.
  • Interface and control a seven-segment display.
  • Control buzzers and relays using suitable driver circuits.
  • Interface external sensors with the LPC2129.
  • Develop small applications using multiple peripherals.

LPC2129 Hardware and Programming Notes

  • Configure the required pin functions through PINSEL0 and PINSEL1 before using the pins as GPIO.
  • Configure GPIO direction using IODIR0 and control outputs using IOSET0 and IOCLR0.
  • Read digital input states through IOPIN0.
  • Use suitable current-limiting resistors and driver circuits wherever required.
  • Do not connect a relay coil, motor or other high-current load directly to a microcontroller GPIO pin.
  • Check peripheral voltage levels and the electrical specifications of the exact LCD, sensor and external device.
LCD pin configuration reference: The project wiring uses RS on P0.10, RW on P0.12, EN on P0.13 and LCD data lines D0-D7 on P0.15-P0.22. This is an 8-bit data-bus arrangement. Verify pin multiplexing and avoid conflicts with other peripherals using the same GPIO pins.
Keil uVision simulator note: The programming exercises can be used to study GPIO configuration and program execution. Visible LCD output, keypad activity, sensor signals, relay operation and other external device behavior depend on the simulator model. Register-level execution does not prove physical hardware operation.
