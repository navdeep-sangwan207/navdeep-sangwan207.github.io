1. Introduction

The LPC2129 microcontroller provides UART0 and UART1 for asynchronous serial communication. Before using either UART, the corresponding microcontroller pins must be configured for their alternate UART functions.

The LPC2129 pins are multiplexed. A single physical pin can support GPIO and other peripheral functions. The PINSEL0 register selects the required function for the relevant pins.

  • Understand the PINSEL0 register.

2. What Is Pin Multiplexing?

Pin multiplexing allows one physical microcontroller pin to perform different functions depending on the selected configuration.

For example, LPC2129 pin P0.0 can be used as:

  • GPIO pin P0.0
  • UART0 transmit pin TXD0
  • Another alternate peripheral function, as defined in the device pin-function table.

Only one selected function is active on a pin at a time.

3. PINSEL0 Register

PINSEL0 is a 32-bit pin-function selection register. It controls the functions of Port 0 pins P0.0 through P0.15.

Each pin is generally controlled by a two-bit field in PINSEL0.

Two-bit valueSelection
00GPIO function
01First alternate function
10Second alternate function
11Third alternate function
The meaning of 01, 10 and 11 depends on the individual pin. Always consult the LPC2129 pin-function table before selecting an alternate function.

4. UART0 Pin Assignments

UART0 uses the following Port 0 pins:

Physical pinUART functionPINSEL0 fieldSelection
P0.0TXD0[1:0]01
P0.1RXD0[3:2]01

4.1 Configure P0.0 as TXD0

P0.0 is controlled by PINSEL0 bits 1:0.

PINSEL0 &= ~(3U << 0);
PINSEL0 |=  (1U << 0);

4.2 Configure P0.1 as RXD0

P0.1 is controlled by PINSEL0 bits 3:2.

PINSEL0 &= ~(3U << 2);
PINSEL0 |=  (1U << 2);

4.3 Complete UART0 pin configuration

#include <LPC21xx.h>

void UART0_Pin_Init(void)
{
    /* P0.0 = TXD0 */
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    /* P0.1 = RXD0 */
    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);
}

int main(void)
{
    UART0_Pin_Init();

    while (1)
    {
    }
}

Expected result: PINSEL0 bits [1:0] and [3:2] are both set to 01.

6. Understanding Bit Manipulation

PINSEL0 configuration commonly uses bitwise AND, OR and NOT operations.

6.1 Clear a two-bit field

PINSEL0 &= ~(3U << 0);

This clears bits 1:0 without changing the other PINSEL0 fields.

6.2 Select the alternate function

PINSEL0 |= (1U << 0);

This sets bit 0 while bit 1 remains cleared, producing the field value 01.

6.3 General formula

PINSEL0 &= ~(3U << (2U * pin_number));
PINSEL0 |=  (function_value << (2U * pin_number));

This formula illustrates how a two-bit PINSEL0 field can be selected. Use the correct function value for the particular pin according to the datasheet.

7. Configuring Both UART0 and UART1

Both UARTs can be configured at the same time because they use different pins.

#include <LPC21xx.h>

void UART0_Pin_Init(void)
{
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);
}

void UART1_Pin_Init(void)
{
    PINSEL0 &= ~(3U << 16);
    PINSEL0 |=  (1U << 16);

    PINSEL0 &= ~(3U << 18);
    PINSEL0 |=  (1U << 18);
}

int main(void)
{
    UART0_Pin_Init();
    UART1_Pin_Init();

    while (1)
    {
    }
}

Expected result

  • P0.0 is configured as TXD0.
  • P0.1 is configured as RXD0.
  • P0.8 is configured as TXD1.
  • P0.9 is configured as RXD1.

This program only configures the pin functions. UART baud rate, frame format and transmitter/receiver operation must be initialized separately.

8. UART Pin Connection

For communication between two UART devices, the transmit and receive signals are normally crossed.

UART Device-to-Device Connection

LPC2129 Device AConnectionDevice B
TXD──────────→RXD
RXD←──────────TXD
GND────────────GND

Both devices must use compatible baud rates, data-bit lengths, parity settings and stop-bit configurations.

LPC2129 UART pins use logic-level signals. They must not be connected directly to traditional RS-232 voltage-level interfaces. Use a suitable RS-232 transceiver such as a MAX232-compatible device when connecting to an RS-232 port. For USB serial communication, use a compatible USB-to-UART adapter.

9. UART Pin Configuration vs UART Initialization

Pin configuration and UART initialization are separate operations.

OperationPurposeRelated registers
Pin configurationSelects TXD and RXD functions on physical pins.PINSEL0
Baud-rate configurationSets serial communication speed.DLL, DLM, FDR
Frame configurationSets data bits, parity and stop bits.LCR
Transmit operationSends data.THR, LSR
Receive operationReads incoming data.RBR, LSR
Interrupt configurationEnables selected UART interrupt events.IER, IIR, VIC
Correct PINSEL0 configuration does not automatically configure the baud rate or start serial communication. All required UART settings must be initialized separately.

11. Common Mistakes

  • Configuring P0.0 and P0.1 when UART1 is required.
  • Using the wrong bit positions for P0.8 and P0.9.
  • Forgetting to clear the two-bit field before setting a new function.
  • Assuming every pin uses the same alternate-function selection value.
  • Overwriting unrelated PINSEL0 fields.
  • Assuming pin configuration automatically sets the baud rate.
  • Connecting UART TXD directly to an RS-232 voltage-level port.
  • Forgetting the common ground requirement for typical logic-level UART connections.

12. Interview Questions and Answers

Q1. What is pin multiplexing?

It is a feature that allows a physical microcontroller pin to perform different functions selected through configuration registers.

Q2. Which register configures UART0 pins in LPC2129?

PINSEL0.

Q3. Which pins are used by UART0?

P0.0 is TXD0 and P0.1 is RXD0.

Q4. Which pins are used by UART1?

P0.8 is TXD1 and P0.9 is RXD1.

Q5. How many bits are used to select a pin function in PINSEL0?

Two bits per pin.

Q6. What does the value 00 represent in a PINSEL0 field?

GPIO function.

Q7. Why should a PINSEL0 field be cleared before setting its value?

To ensure that the field contains the intended function selection without unwanted previous bits.

Q8. Can UART0 and UART1 be configured simultaneously?

Yes. They use separate pin groups.

Q9. Does PINSEL0 configure the UART baud rate?

No. Baud-rate configuration uses the UART divisor and fractional-divider registers.

Q10. Can LPC2129 TXD be connected directly to an RS-232 port?

No. A suitable RS-232 level-translator/transceiver is required.

15. Lesson Summary

  • LPC2129 pins support multiple selectable functions.
  • PINSEL0 configures P0.0 through P0.15.
  • Each PINSEL0 pin field uses two bits.
  • UART0 uses P0.0 TXD0 and P0.1 RXD0.
  • UART1 uses P0.8 TXD1 and P0.9 RXD1.
  • Both UARTs can be configured simultaneously.
  • PINSEL0 selects pin functions; UART registers configure serial operation.
  • Logic-level UART and RS-232 voltage levels require appropriate interfacing.
