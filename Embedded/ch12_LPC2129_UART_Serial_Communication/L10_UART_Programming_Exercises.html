1. Introduction

This lesson provides practical programming exercises for UART communication using the LPC2129 microcontroller and Embedded C.

The exercises progress from basic UART configuration to complete serial communication applications.

Learning objectives
  • Configure UART0 and UART1.
  • Calculate and configure baud rates.
  • Transmit individual characters and strings.
  • Receive serial data.
  • Implement an echo application.
  • Understand UART FIFO operation.
  • Configure UART interrupts.
  • Debug UART programs using Keil uVision.
  • Identify common serial communication errors.

3. Project Clock Configuration

The following exercises use the established LPC2129 project clock configuration.

Clock parameterValue
Oscillator frequency12 MHz
CPU clock (CCLK)60 MHz
Peripheral clock (PCLK)15 MHz

UART baud-rate generation uses PCLK.

Baud-rate formula

Without fractional adjustment:

Baud Rate = PCLK / (16 × Divisor)

With fractional adjustment:

Baud Rate =
PCLK / [16 × Divisor × (1 + DIVADDVAL / MULVAL)]

Where:

  • Divisor = 256 × DLM + DLL.
  • DIVADDVAL is the fractional divider addition value.
  • MULVAL is the fractional divider multiplier value.

4. Common UART0 Initialization Function

The following initialization function is reused in the exercises.

#include <LPC21xx.h>

void UART0_Init(void)
{
    /* Select TXD0 on P0.0 */
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    /* Select RXD0 on P0.1 */
    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);

    /* Enable divisor latch access */
    U0LCR = 0x83;

    /* Baud-rate divisor */
    U0DLM = 0x00;
    U0DLL = 0x47;
    U0FDR = 0x83;

    /* 8 data bits, no parity, one stop bit */
    U0LCR = 0x03;

    /* Enable and reset FIFOs */
    U0FCR = 0x07;
}
The fractional divider settings produce approximately 9603 baud with PCLK = 15 MHz. The actual communication rate must be compatible with the connected device.

6. Exercise 2 – Transmit a Single Character

Objective: Transmit the character A using UART0 polling. Program: 
#include <LPC21xx.h>

void UART0_Init(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;
}

void UART0_TxChar(unsigned char ch)
{
    while ((U0LSR & (1U << 5)) == 0)
    {
    }

    U0THR = ch;
}

int main(void)
{
    UART0_Init();

    while (1)
    {
        UART0_TxChar('A');
    }
}
Expected result:

The program repeatedly sends the character A through the UART0 transmit path. A connected serial receiver or supported simulator terminal is required to observe the character.

7. Exercise 3 – Transmit a String

Objective: Transmit a message through UART0. Program: 
#include <LPC21xx.h>

void UART0_Init(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;
}

void UART0_TxChar(unsigned char ch)
{
    while ((U0LSR & (1U << 5)) == 0)
    {
    }

    U0THR = ch;
}

void UART0_TxString(const char *str)
{
    while (*str != '\0')
    {
        UART0_TxChar((unsigned char)*str);
        str++;
    }
}

int main(void)
{
    UART0_Init();

    UART0_TxString("Welcome to Embedded Systems\r\n");

    while (1)
    {
    }
}
Expected result: 
Welcome to Embedded Systems

The string is transmitted once after initialization.

8. Exercise 4 – Receive a Character

Objective: Receive one character through UART0. Program: 
#include <LPC21xx.h>

void UART0_Init(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;
}

unsigned char UART0_RxChar(void)
{
    while ((U0LSR & 0x01U) == 0)
    {
    }

    return (unsigned char)U0RBR;
}

int main(void)
{
    unsigned char received;

    UART0_Init();

    while (1)
    {
        received = UART0_RxChar();
    }
}
Expected result:

The CPU waits until a character arrives, then reads it from U0RBR and stores it in the variable received.

9. Exercise 5 – UART Echo Program

Objective: Receive a character and transmit the same character back. Program: 
#include <LPC21xx.h>

void UART0_Init(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;
    U0FCR = 0x07;
}

int main(void)
{
    unsigned char data;

    UART0_Init();

    while (1)
    {
        while ((U0LSR & 0x01U) == 0)
        {
        }

        data = (unsigned char)U0RBR;

        while ((U0LSR & (1U << 5)) == 0)
        {
        }

        U0THR = data;
    }
}
Expected result:

Every received character is transmitted back to the sender.

10. Exercise 6 – Check UART Error Flags

Objective: Read the UART line status register and identify receiver errors. Program: 
#include <LPC21xx.h>

volatile unsigned int uart_errors;

void UART0_CheckErrors(void)
{
    unsigned int status;

    status = U0LSR;

    uart_errors = status & 0x1EU;
}

int main(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;

    while (1)
    {
        UART0_CheckErrors();
    }
}
Expected result:

The variable uart_errors stores the receiver error-status bits observed in LSR bits 1 through 4.

This exercise demonstrates status inspection. It does not inject errors into the UART or guarantee that the simulator will generate error conditions.

13. Exercise 9 – Enable UART0 Receive Interrupt

Objective: Enable UART0 receive data interrupts and configure the VIC. Program: 
#include <LPC21xx.h>

#define UART0_SOURCE 6U

volatile unsigned char received_data;
volatile unsigned int data_received = 0;

void UART0_ISR(void) __irq
{
    unsigned int iir;

    while (1)
    {
        iir = U0IIR;

        if (iir & 0x01U)
        {
            break;
        }

        if ((iir & 0x0EU) == 0x04U ||
            (iir & 0x0EU) == 0x0CU)
        {
            while (U0LSR & 0x01U)
            {
                received_data = (unsigned char)U0RBR;
                data_received++;
            }
        }
        else
        {
            break;
        }
    }

    VICVectAddr = 0;
}

int main(void)
{
    PINSEL0 &= ~0x0FU;
    PINSEL0 |= 0x05U;

    U0LCR = 0x83;
    U0DLM = 0;
    U0DLL = 0x47;
    U0FDR = 0x83;
    U0LCR = 0x03;

    U0FCR = 0x07;

    U0IER = (1U << 0);

    VICIntSelect &= ~(1U << UART0_SOURCE);

    VICVectAddr0 = (unsigned int)UART0_ISR;
    VICVectCntl0 = (1U << 5) | UART0_SOURCE;

    VICIntEnable = (1U << UART0_SOURCE);

    while (1)
    {
        /* Main application */
    }
}
Expected result:

When supported receive data interrupts occur, the ISR reads the received characters and updates the data counter.

This is a focused receive-interrupt exercise. A complete application should also handle receive line-status errors, buffer incoming data, and define overflow handling. The example uses the Keil ARM compiler's __irq convention.

16. UART Calculation Exercises

Question 1

Calculate the bit duration at 9600 baud.

Solution:

Bit duration = 1 / Baud rate
             = 1 / 9600
             = 104.17 microseconds

Question 2

Calculate the duration of one 8N1 frame at 9600 baud.

Solution:

8N1 frame = 1 start + 8 data + 1 stop
          = 10 bits

Frame duration = 10 / 9600
               = 1.0417 milliseconds

Question 3

Calculate the ideal maximum payload throughput for 8N1 at 9600 baud.

Solution:

Payload bits per frame = 8

Frames per second = 9600 / 10
                  = 960

Payload throughput = 960 bytes/second

Question 4

What is the role of PCLK in UART baud-rate generation?

Answer: PCLK provides the UART peripheral clock used by the baud-rate generator.
