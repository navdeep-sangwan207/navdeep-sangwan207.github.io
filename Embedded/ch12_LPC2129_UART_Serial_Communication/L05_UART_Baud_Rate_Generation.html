1. Introduction

Baud-rate generation is an important part of UART communication. The baud rate determines the speed at which serial symbols are transmitted and received.

The LPC2129 UART peripheral generates the required serial timing using the peripheral clock (PCLK), divisor latch registers and fractional divider configuration.

The main registers involved are:

  • DLL – Divisor Latch Low.
  • DLM – Divisor Latch High.
  • FDR – Fractional Divider Register.
  • LCR – Line Control Register.
Learning objectives
  • Understand baud rate and bit duration.
  • Understand the relationship between PCLK and UART baud rate.
  • Calculate the divisor latch value.
  • Understand DLL and DLM.
  • Understand the fractional divider and FDR.
  • Understand the DLAB bit.
  • Calculate UART settings for 9600 and 115200 baud.
  • Write a UART baud-rate initialization program.

2. What Is Baud Rate?

Baud rate represents the number of signal symbols transmitted per second.

In conventional binary UART communication, one symbol represents one bit. Therefore, the numerical baud rate and bit rate are normally equal.

Baud rateApproximate bit duration
9600104.17 microseconds
1920052.08 microseconds
3840026.04 microseconds
5760017.36 microseconds
1152008.68 microseconds

Bit duration formula

Bit Duration = 1 / Baud Rate

For 9600 baud:

Bit duration = 1 / 9600 = approximately 104.17 microseconds.

For 115200 baud:

Bit duration = 1 / 115200 = approximately 8.68 microseconds.

3. Role of Peripheral Clock (PCLK)

The UART baud-rate generator uses the peripheral clock as its timing source.

In the LPC2129 project configuration used in this course:

ClockValue
Oscillator frequency (FOSC)12 MHz
CPU clock (CCLK)60 MHz
Peripheral clock (PCLK)15 MHz
VPBDIV setting0x00 (CCLK/4)

The UART baud-rate calculation must use PCLK, not automatically the CPU clock or oscillator frequency.

For this project, use PCLK = 15,000,000 Hz in the UART calculations. If the clock configuration changes, the UART divisor must be recalculated.

4. Basic UART Baud-Rate Formula

When the fractional divider is disabled, the UART baud rate is calculated using:

Baud Rate = PCLK / (16 × Divisor)

Where:

  • PCLK is the peripheral clock frequency.
  • Divisor is the combined value stored in DLL and DLM.

The combined divisor is:

Divisor = (256 × DLM) + DLL

Rearranging the baud-rate equation:

Divisor = PCLK / (16 × Baud Rate)

5. DLL and DLM Registers

The divisor latch registers store the integer divisor used by the UART baud-rate generator.

RegisterFunction
DLLStores the lower 8 bits of the divisor.
DLMStores the upper 8 bits of the divisor.

Together, DLL and DLM form a 16-bit divisor value.

Example

Suppose the divisor is 300 decimal.

  • 300 decimal = 0x012C hexadecimal.
  • DLL = 0x2C.
  • DLM = 0x01.

The combined value is:

(256 × 1) + 44 = 300

6. DLAB – Divisor Latch Access Bit

DLL and DLM share register addresses with other UART registers. The DLAB bit in the Line Control Register controls which registers are accessible at those addresses.

DLAB is bit 7 of LCR.

DLABRegister access
0Normal access to RBR/THR and IER.
1Access to DLL and DLM at the corresponding register addresses.

Enable divisor latch access

U0LCR |= (1U << 7);

Disable divisor latch access

U0LCR &= ~(1U << 7);
After programming DLL and DLM, clear DLAB before using normal receive, transmit and interrupt-enable register access.

7. Fractional Divider Register (FDR)

The LPC2129 UART baud-rate generator supports fractional adjustment through the Fractional Divider Register, where implemented by the device revision and peripheral configuration.

The FDR contains two important fields:

BitsFieldFunction
[3:0]DIVADDVALFractional divider addition value.
[7:4]MULVALFractional divider multiplier value.
[31:8]ReservedDo not write ones to reserved bits.

Valid configuration conditions

  • 1 ≤ MULVAL ≤ 15.
  • 0 ≤ DIVADDVAL ≤ 14.
  • DIVADDVAL must be smaller than MULVAL.
  • MULVAL must not be zero.

When DIVADDVAL is zero, the fractional adjustment is disabled.

FDR value calculation

FDR = (MULVAL × 16) + DIVADDVAL

For example, if MULVAL = 8 and DIVADDVAL = 3:

FDR = (8 × 16) + 3 = 131 decimal = 0x83.

8. Complete Baud-Rate Formula with Fractional Divider

When fractional adjustment is used, the baud rate is calculated as:

Baud Rate = PCLK / [16 × Divisor × (1 + DIVADDVAL/MULVAL)]

Where:

  • Divisor = (256 × DLM) + DLL.
  • DIVADDVAL is the FDR fractional addition value.
  • MULVAL is the FDR multiplier value.

The fractional factor adjusts the effective divisor to obtain a baud rate closer to the desired value.

The fractional divider improves baud-rate accuracy when the basic integer divisor cannot represent the required baud rate closely enough.

9. Baud-Rate Calculation – 9600 Baud

Given:

  • PCLK = 15 MHz.
  • Desired baud rate = 9600.

Step 1: Calculate the ideal divisor without fractional adjustment

Divisor = 15,000,000 / (16 × 9600)

Divisor = 97.65625.

The nearest integer divisor is 98.

Step 2: Calculate the actual baud rate without FDR adjustment

Actual baud rate = 15,000,000 / (16 × 98)

Actual baud rate = approximately 9566.33 baud.

Error = approximately -0.351%.

Step 3: Improve accuracy using fractional adjustment

One valid configuration is:

Register fieldValue
DLM0x00
DLL71 decimal = 0x47
MULVAL8
DIVADDVAL3
FDR0x83

Actual baud rate:

15,000,000 / [16 × 71 × (1 + 3/8)]

Actual baud rate ≈ 9603.07 baud.

Percentage error ≈ +0.032%.

Improved accuracy

This fractional configuration produces a baud rate much closer to 9600 than the integer-only configuration.

11. UART0 Baud-Rate Initialization Program

Objective: Configure UART0 for approximately 9600 baud using the 15 MHz PCLK and fractional divider.

#include <LPC21xx.h>

void UART0_Init(void)
{
    /* Configure UART0 pins */
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);

    /* Enable access to divisor latches */
    U0LCR = 0x83;

    /*
       DLAB = 1
       8 data bits
       1 stop bit
       No parity
    */

    /* Configure divisor */
    U0DLM = 0x00;
    U0DLL = 0x47;

    /* Configure fractional divider */
    U0FDR = 0x83;

    /* Disable divisor latch access */
    U0LCR = 0x03;
}

int main(void)
{
    UART0_Init();

    while (1)
    {
    }
}

Register configuration

RegisterValuePurpose
U0LCR0x83DLAB enabled; 8-bit data, one stop bit, no parity.
U0DLM0x00Divisor high byte.
U0DLL0x47Divisor low byte = 71.
U0FDR0x83MULVAL = 8, DIVADDVAL = 3.
U0LCR0x03DLAB disabled; normal register access.

Expected result

  • UART0 pin functions are selected.
  • UART0 is configured for 8N1 framing.
  • The calculated baud rate is approximately 9603.07 baud.
  • The program remains in the infinite loop.
This program configures the UART but does not transmit a character. A separate transmit routine is required. Confirm that the selected LPC2129 device header and hardware revision support the FDR register before using this configuration.

12. UART1 Baud-Rate Initialization Program

Objective: Configure UART1 for approximately 9600 baud using the same PCLK and divisor settings.

#include <LPC21xx.h>

void UART1_Init(void)
{
    /* Configure UART1 pins */
    PINSEL0 &= ~(3U << 16);
    PINSEL0 |=  (1U << 16);

    PINSEL0 &= ~(3U << 18);
    PINSEL0 |=  (1U << 18);

    /* Enable divisor latch access */
    U1LCR = 0x83;

    /* Configure divisor */
    U1DLM = 0x00;
    U1DLL = 0x47;

    /* Configure fractional divider */
    U1FDR = 0x83;

    /* Disable divisor latch access */
    U1LCR = 0x03;
}

int main(void)
{
    UART1_Init();

    while (1)
    {
    }
}

Expected result: UART1 is configured for approximately 9603.07 baud with 8N1 framing.

13. Important Programming Precautions

  • Use the correct peripheral clock value in the calculation.
  • Set DLAB before writing DLL and DLM.
  • Clear DLAB after configuring the divisor.
  • Keep DIVADDVAL smaller than MULVAL.
  • Do not set MULVAL to zero.
  • Do not modify FDR while transmitting or receiving data.
  • When fractional adjustment is active and DLM is zero, ensure DLL is at least 3.
  • Check the exact UART register availability in the LPC2129 device documentation.
  • Ensure both communicating devices use compatible baud-rate and frame settings.

14. Baud-Rate Error

The actual baud rate may differ slightly from the desired baud rate because the divisor settings are discrete.

Error (%) = [(Actual − Desired) / Desired] × 100

The absolute percentage error is useful when comparing different divisor configurations.

Desired baudConfigurationCalculated baudApproximate absolute error
9600Integer divisor 989566.330.351%
9600DLL 71, FDR 0x839603.070.032%
115200Integer divisor 8117187.51.725%
115200DLL 6, FDR 0xE5115131.580.059%

These calculations assume an exact 15 MHz PCLK. Actual hardware baud-rate accuracy also depends on clock-source tolerance and the receiving device's timing tolerance.

16. Common Mistakes

  • Using CCLK instead of PCLK in the baud-rate formula.
  • Forgetting the factor of 16 in the divisor calculation.
  • Writing DLL and DLM while DLAB is cleared.
  • Leaving DLAB enabled after initialization.
  • Using an invalid MULVAL or DIVADDVAL combination.
  • Changing FDR while serial communication is active.
  • Assuming the nearest integer divisor always gives an acceptable error.
  • Using different baud-rate settings at the two ends of a serial link.
  • Assuming the simulator's register view proves physical UART communication.

17. Interview Questions and Answers

Q1. What is baud rate?

Baud rate is the number of signal symbols transmitted per second. In ordinary binary UART communication, one symbol represents one bit.

Q2. Which clock is used for UART baud-rate generation?

The peripheral clock (PCLK).

Q3. What is the basic UART baud-rate formula?

Baud rate = PCLK / (16 × Divisor), when fractional adjustment is disabled.

Q4. What is the function of DLL?

DLL stores the lower eight bits of the divisor.

Q5. What is the function of DLM?

DLM stores the upper eight bits of the divisor.

Q6. What is DLAB?

DLAB is bit 7 of LCR. It selects access to divisor latch registers.

Q7. What is the purpose of FDR?

FDR provides fractional adjustment to the baud-rate generator.

Q8. What is MULVAL?

MULVAL is the fractional divider multiplier field in FDR.

Q9. What is DIVADDVAL?

DIVADDVAL is the fractional divider addition field in FDR.

Q10. Why is fractional adjustment useful?

It can reduce baud-rate error when the integer divisor alone cannot produce a sufficiently accurate baud rate.

Q11. What happens when DIVADDVAL is zero?

The fractional divider does not alter the baud rate.

Q12. Should FDR be changed during active communication?

No. Changing it during transmission or reception can corrupt or lose data.
