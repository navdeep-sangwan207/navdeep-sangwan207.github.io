1. Introduction

The Line Control Register (LCR) is an important configuration register in the LPC2129 UART peripheral.

It controls the format of transmitted and received serial data. Using LCR, software can configure:

  • Number of data bits.
  • Number of stop bits.
  • Parity generation and checking.
  • Parity type.
  • Break transmission control.
  • Divisor Latch Access Bit (DLAB).
Learning objectives
  • Understand the LCR register organization.
  • Understand all LCR bit fields.
  • Configure 5-, 6-, 7- and 8-bit data formats.
  • Select one or two stop bits.
  • Configure parity settings.
  • Understand break control and DLAB.
  • Write practical LCR configuration programs.

3. Word Length Selection (Bits 1:0)

Bits 1 and 0 select the number of data bits transmitted or received in each UART character.

Bits 1:0Data bitsExplanation
005 bitsFive data bits per character.
016 bitsSix data bits per character.
107 bitsSeven data bits per character.
118 bitsEight data bits per character.

Example: Select 8-bit data

U0LCR = 0x03;

Binary representation of 0x03:

00000011

Bits 1:0 = 11, selecting eight data bits.

Example: Select 7-bit data

U0LCR = 0x02;

Bits 1:0 = 10, selecting seven data bits.

4. Stop Bit Selection (Bit 2)

The stop bit indicates the end of a UART character frame.

Bit 2Stop-bit configuration
0One stop bit.
1Two stop bits for 6-, 7- or 8-bit data; 1.5 stop-bit periods for 5-bit data.

Example: One stop bit

U0LCR &= ~(1U << 2);

Example: Two stop bits

U0LCR |= (1U << 2);
For 5-bit word length, setting the stop-bit select bit produces 1.5 stop-bit periods rather than two full stop bits.

5. Parity Enable (Bit 3)

Parity is a basic error-detection mechanism used in serial communication.

Bit 3Function
0Parity disabled.
1Parity enabled.

When parity is enabled, the UART adds a parity bit to the transmitted frame and checks the received parity bit.

Example: Disable parity

U0LCR &= ~(1U << 3);

Example: Enable parity

U0LCR |= (1U << 3);

6. Parity Selection (Bit 4)

Bit 4 selects the parity type when parity is enabled and stick parity is disabled.

Bit 4Parity type
0Odd parity.
1Even parity.

Odd parity

The total number of logic 1 bits in the data and parity bit is odd.

Example: Data bits 00000101 contain two logic 1 bits. The odd parity bit is 1, making the total number of ones three.

Even parity

The total number of logic 1 bits in the data and parity bit is even.

Example: Data bits 00000101 contain two logic 1 bits. The even parity bit is 0, keeping the total number of ones at two.

7. Stick Parity (Bit 5)

Stick parity is a special parity mode controlled by bit 5.

Bit 5Mode
0Normal parity operation.
1Stick parity operation.

When stick parity is enabled, the parity bit is forced to a selected fixed value rather than being calculated from the data bits.

The combination of parity enable, parity select and stick parity determines the transmitted parity behavior.

Bits 5:3Configuration
000Parity disabled.
011Odd parity.
111Even parity.
101Forced logic 1 parity.
111Note: stick parity combinations must be interpreted with all three bits, not parity enable alone.
The exact stick-parity truth table should be checked against the LPC2129 UART LCR description. For ordinary embedded UART communication, parity is commonly disabled or configured as normal odd/even parity.

8. Break Control (Bit 6)

Bit 6 controls break transmission.

Bit 6Function
0Normal serial transmission.
1Break condition is forced on the TXD output.

A break condition holds the serial output in the spacing state (logic LOW) for longer than a normal character frame.

Enable break control

U0LCR |= (1U << 6);

Disable break control

U0LCR &= ~(1U << 6);
Break control is a special signaling function. Do not leave it enabled during normal data transmission.

9. Divisor Latch Access Bit – DLAB (Bit 7)

DLAB selects access to the baud-rate divisor latch registers.

DLABRegister access
0Normal access: RBR/THR and IER.
1Divisor access: DLL and DLM.

Enable DLAB

U0LCR |= (1U << 7);

Disable DLAB

U0LCR &= ~(1U << 7);

Why is DLAB required?

Several UART registers share the same register address locations. DLAB determines which register is accessed at the relevant addresses.

Always clear DLAB after writing DLL and DLM. Otherwise, software accesses to the normal transmit, receive and interrupt-enable registers may access the divisor latches instead.

10. UART Frame Format – 8N1

A common UART configuration is 8N1:

  • 8 data bits.
  • N = No parity.
  • 1 stop bit.

8N1 UART Frame

StartDataParityStop
08 bitsNone1

One start bit + eight data bits + one stop bit = 10 bits per character.

8N1 LCR value

U0LCR = 0x03;

Binary: 00000011.

  • Bits 1:0 = 11 → 8 data bits.
  • Bit 2 = 0 → one stop bit.
  • Bit 3 = 0 → parity disabled.
  • Bit 7 = 0 → normal register access.

12. Practical Program – Configure UART0 for 8N1

Objective: Configure UART0 for eight data bits, no parity and one stop bit.

#include <LPC21xx.h>

void UART0_Pin_Init(void)
{
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);
}

void UART0_Line_Init(void)
{
    /* 8 data bits, no parity, one stop bit */
    U0LCR = 0x03;
}

int main(void)
{
    UART0_Pin_Init();
    UART0_Line_Init();

    while (1)
    {
    }
}

Expected result

  • UART0 TXD0 and RXD0 pin functions are selected.
  • U0LCR contains 0x03.
  • UART0 is configured for 8N1 framing.

Expected result

15. Complete UART0 Configuration – Baud Rate and Frame Format

Objective: Configure UART0 for approximately 9600 baud and 8N1 using the 15 MHz PCLK configuration.

#include <LPC21xx.h>

void UART0_Init(void)
{
    /* Configure UART0 pins */
    PINSEL0 &= ~(3U << 0);
    PINSEL0 |=  (1U << 0);

    PINSEL0 &= ~(3U << 2);
    PINSEL0 |=  (1U << 2);

    /* Enable divisor latch access */
    U0LCR = 0x83;

    /* Baud-rate divisor */
    U0DLM = 0x00;
    U0DLL = 0x47;

    /* Fractional divider */
    U0FDR = 0x83;

    /* Configure 8N1 and clear DLAB */
    U0LCR = 0x03;
}

int main(void)
{
    UART0_Init();

    while (1)
    {
    }
}

Expected result

RegisterExpected value
U0DLL0x47
U0DLM0x00
U0FDR0x83
U0LCR0x03

The calculated baud rate is approximately 9603.07 baud, with 8N1 framing.

17. Common Mistakes

  • Selecting the wrong word length bits.
  • Enabling parity unintentionally.
  • Confusing odd parity and even parity.
  • Assuming the stop-bit select bit always means two full stop bits.
  • Forgetting to clear DLAB after divisor configuration.
  • Leaving break control enabled during normal communication.
  • Using an incorrect LCR value for the required frame format.
  • Configuring only one UART while using the other peripheral.
  • Using different frame formats at the transmitter and receiver.

18. Interview Questions and Answers

Q1. What is the function of LCR?

It configures UART character format, parity, stop bits, break control and divisor latch access.

Q2. Which LCR bits select the word length?

Bits 1 and 0.

Q3. What does LCR value 0x03 represent?

Eight data bits, no parity and one stop bit, with DLAB cleared.

Q4. Which bit selects the stop-bit configuration?

Bit 2.

Q5. Which bit enables parity?

Bit 3.

Q6. Which bit selects even or odd parity?

Bit 4, when normal parity is enabled.

Q7. What is stick parity?

It forces the parity bit to a fixed value rather than calculating it from the data bits.

Q8. What is the function of break control?

It forces the TXD output to the break signaling state.

Q9. What is DLAB?

It controls access to DLL and DLM instead of the normal RBR/THR and IER register locations.

Q10. What is 8N1?

Eight data bits, no parity and one stop bit.

21. Lesson Summary

  • LCR configures UART character format.
  • Bits 1:0 select 5-, 6-, 7- or 8-bit data.
  • Bit 2 selects the stop-bit configuration.
  • Bit 3 enables parity.
  • Bit 4 selects odd or even parity in normal parity mode.
  • Bit 5 controls stick parity.
  • Bit 6 controls break transmission.
  • Bit 7 is DLAB.
  • 8N1 is configured using LCR = 0x03.
  • DLAB must be cleared after divisor programming.
