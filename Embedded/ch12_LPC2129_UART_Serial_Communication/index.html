1. Chapter Overview

UART (Universal Asynchronous Receiver/Transmitter) is a serial communication interface used to exchange data between embedded systems and external devices.

The LPC2129 microcontroller provides two UART peripherals, UART0 and UART1. These peripherals support asynchronous serial communication and are commonly used for debugging, terminal communication, device configuration and data exchange.

This chapter explains UART architecture, TXD and RXD pin configuration, baud-rate generation, line control, transmit and receive registers, and interrupt-driven UART programming.

Practical focus: UART0 and UART1 programming using Embedded C and the LPC2129 register model, with Keil uVision simulator-based learning.

5. LPC2129 UART Register Overview

Register Purpose
U0RBR / U1RBR Receive Buffer Register
U0THR / U1THR Transmit Holding Register
U0DLL / U1DLL Divisor Latch Low
U0DLM / U1DLM Divisor Latch High
U0IER / U1IER Interrupt Enable Register
U0IIR / U1IIR Interrupt Identification Register
U0FCR / U1FCR FIFO Control Register
U0LCR / U1LCR Line Control Register
U0LSR / U1LSR Line Status Register
U0SCR / U1SCR Scratch Pad Register
U0TER / U1TER Transmit Enable Register
Several UART registers share the same address and are selected using the DLAB bit in the Line Control Register. Always follow the register access rules in the LPC2129 user manual.
