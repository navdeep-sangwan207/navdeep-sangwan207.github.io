1. Introduction

Hardware register programming is a fundamental technique in embedded systems development. It allows firmware to configure and control the internal peripherals of a microcontroller.

A microcontroller contains several registers associated with its CPU, memory system and peripheral modules. Embedded C programs access these registers to configure hardware functions and exchange information with peripheral devices.

For example, a GPIO direction register determines whether a pin operates as an input or output, while an output register controls the corresponding output state.

Definition: Hardware register programming is the process of configuring and controlling microcontroller hardware by reading from and writing to its control, status and data registers.

2. What Is a Hardware Register?

A hardware register is a storage location used by a processor or peripheral module to hold control information, status information or data.

Registers are generally implemented inside the microcontroller and are accessed through defined addresses or processor instructions.

Examples of Hardware Registers

  • GPIO direction register.
  • GPIO input/output register.
  • Timer control register.
  • UART control register.
  • ADC control register.
  • Interrupt enable register.
  • System clock control register.

3. Types of Registers in a Microcontroller

3.1 CPU Registers

CPU registers are located inside the processor core. They are used during instruction execution and program operation.

Examples include:

  • General-purpose registers.
  • Program Counter (PC).
  • Stack Pointer (SP).
  • Link Register (LR).
  • Current Program Status Register (CPSR) in ARM processors.

3.2 Peripheral Registers

Peripheral registers are associated with hardware modules such as GPIO, timers, UART, ADC and I2C.

3.3 Control Registers

Control registers configure the operating mode and behavior of hardware modules.

3.4 Status Registers

Status registers provide information about the current condition of a peripheral or operation.

3.5 Data Registers

Data registers store information transmitted to or received from a peripheral.

Register Type Purpose Example
CPU Register Processor execution Program Counter
Control Register Hardware configuration Timer Control Register
Status Register Hardware status UART Line Status Register
Data Register Data transfer UART Transmit Register

4. Special Function Registers (SFRs)

Special Function Registers are hardware registers used to control and monitor specific microcontroller functions.

They are commonly associated with peripheral modules and system control features.

Examples in LPC2129

Register Function
PINSEL0 Selects functions for Port 0 pins 0 to 15.
PINSEL1 Selects functions for Port 0 pins 16 to 31.
IODIR0 Configures Port 0 pin directions.
IOPIN0 Reads or accesses Port 0 pin states.
IOSET0 Sets Port 0 output bits.
IOCLR0 Clears Port 0 output bits.
T0TCR Controls Timer 0 operation.
U0LCR Controls UART0 line configuration.
Note: The register names above are LPC2129 device-specific. Always refer to the microcontroller user manual for register addresses, bit fields and access behavior.

5. Register Organization and Bit Fields

A hardware register consists of individual bits. Each bit or group of bits may control a particular hardware function.

For example, a 32-bit GPIO direction register contains one direction-control bit for each Port 0 pin.

Example: 8-Bit Register

Bit 7 Bit 6 Bit 5 Bit 4 Bit 3 Bit 2 Bit 1 Bit 0

Example: 32-Bit LPC2129 Register

LPC2129 peripheral registers are generally 32 bits wide. A 32-bit register contains bit positions from 0 to 31.

If a particular bit is set to 1, it may enable a function, select an operating mode or represent a logic HIGH state, depending on the register.

A register's meaning is defined by its datasheet or user manual. A bit value of 1 does not always mean "enabled"; some fields use active-low or other encodings.

6. Accessing Hardware Registers in Embedded C

In Embedded C, hardware registers are commonly accessed using device header files supplied by the microcontroller manufacturer or development toolchain.

For LPC2129 projects, a typical device header is: 

#include <LPC21xx.h>

This header provides register definitions and other device-specific declarations.

Example: Register Access

#include <LPC21xx.h>

int main(void)
{
    IODIR0 = 0x00000400U;

    IOSET0 = 0x00000400U;

    while (1)
    {
    }
}

The first statement writes a value to the GPIO direction register, configuring P0.10 as an output while configuring the other Port 0 pins as inputs.

The second statement sets the output latch for P0.10 HIGH.

Important: Assigning a complete value to a register can change multiple bit fields. In practical firmware, use read-modify-write operations when preserving unrelated configuration bits is required.

7. Register Read and Write Operations

7.1 Writing to a Register

A write operation sends a value to a hardware register to configure or control a peripheral. 

IODIR0 = 0x00000400U;

7.2 Reading from a Register

A read operation obtains the current value of a register. 

unsigned int value;

value = IOPIN0;

7.3 Modifying Selected Bits

The bitwise OR operator can set selected bits without changing the other bits in a normal read-modify-write register. 

IODIR0 |= (1U << 10);

This sets bit 10 of IODIR0 while preserving the other bits read from the register.

8. Understanding Register Addresses

Memory-mapped peripheral registers are assigned specific addresses in the microcontroller's address space.

The processor uses these addresses to access hardware registers through load and store operations.

The exact register address depends on the microcontroller's memory map.

Important: Never assume a register address based only on its name. Use the LPC2129 memory map and register description from the official documentation.

9. Register Access Using Bit Masks

A bit mask is a value used to select particular bits within a register.

Setting Bit 10

IODIR0 |= (1U << 10);

Clearing Bit 10

IODIR0 &= ~(1U << 10);

Testing Bit 10

if (IODIR0 & (1U << 10))
{
    /* Bit 10 is set */
}

These operations are based on bitwise operators and are frequently used in embedded firmware.

Detailed bit setting, clearing, toggling and testing techniques are covered in Lesson 05.

10. Practical Example: Configure P0.10 as Output

Objective

To configure LPC2129 pin P0.10 as a GPIO output and set its output latch HIGH using hardware register programming.

Program

#include <LPC21xx.h>

int main(void)
{
    /* Select GPIO function for P0.10 */
    PINSEL0 &= ~(3U << 20);

    /* Configure P0.10 as output */
    IODIR0 |= (1U << 10);

    /* Set P0.10 HIGH */
    IOSET0 = (1U << 10);

    while (1)
    {
        /* Continuous execution */
    }
}

Step-by-Step Explanation

  1. Include the device header: Provides LPC2129 register definitions.
  2. Configure PINSEL0: Clears the two function-selection bits for P0.10 so that it operates as GPIO.
  3. Configure IODIR0: Sets bit 10 to configure P0.10 as an output.
  4. Write to IOSET0: Sets the output latch for P0.10 HIGH.
  5. Enter the infinite loop: Keeps the firmware running.

Expected Result

  • PINSEL0 bits 21:20 are cleared.
  • IODIR0 bit 10 becomes 1.
  • IOSET0 is written with bit 10 set.
  • The output latch is configured HIGH.

In Keil uVision, inspect the relevant register values using the debugger. This verifies register-level program behavior, not the electrical state of an external LED circuit.

11. Register Access Precautions

  1. Check register access type: Registers may be read-only, write-only or read/write.
  2. Understand reserved bits: Reserved bits must be handled according to the device documentation.
  3. Check write behavior: Some status registers use write-one-to-clear or other special semantics.
  4. Preserve unrelated bits: Avoid overwriting other peripheral configurations.
  5. Check pin multiplexing: Configure PINSEL registers correctly before using pins as GPIO.
  6. Use appropriate data types: Use unsigned types of suitable width for register operations.
  7. Check hardware documentation: Follow the official register descriptions.

12. Common Errors in Hardware Register Programming

Error Possible Consequence Correction
Incorrect bit position Wrong pin or peripheral is configured. Verify bit positions in the manual.
Wrong register Unexpected hardware behavior. Verify the peripheral register name.
Incorrect pin function GPIO does not operate as expected. Configure PINSEL correctly.
Full register overwrite Other configuration bits may change. Use suitable bit masks.
Ignoring special write behavior Status flags may be changed unexpectedly. Check register access semantics.

13. Interview Questions and Answers

Q1. What is a hardware register?

A hardware register is a storage location used by the CPU or a peripheral to hold control, status or data information.

Q2. What is an SFR?

An SFR is a Special Function Register used to configure or monitor a particular microcontroller function.

Q3. What is the difference between CPU registers and peripheral registers?

CPU registers support processor execution, whereas peripheral registers control or monitor hardware modules such as GPIO and UART.

Q4. What is a register bit mask?

A bit mask is a binary value used to select particular bits in a register for manipulation or testing.

Q5. What does IODIR0 do in LPC2129?

It configures the direction of Port 0 pins. A direction bit of 1 selects output, while 0 selects input.

Q6. What is the purpose of IOSET0?

It sets selected Port 0 output bits to logic HIGH.

Q7. What is the purpose of IOCLR0?

It clears selected Port 0 output bits to logic LOW.

Q8. Why are device header files used?

They provide hardware register definitions, bit-field declarations and other device-specific information.

Q9. What is a read-modify-write operation?

It reads a register, modifies selected bits and writes the resulting value back.

Q10. Why should register access behavior be checked?

Different registers may have special read and write semantics. Incorrect access can cause unexpected peripheral behavior.

16. Lesson Summary

  • Hardware registers control and monitor microcontroller resources.
  • Special Function Registers are associated with specific hardware functions.
  • Registers contain individual bits and bit fields.
  • Device header files provide register definitions.
  • Read and write operations are used to interact with registers.
  • Bit masks allow selected register bits to be manipulated.
  • LPC2129 GPIO uses PINSEL, IODIR, IOPIN, IOSET and IOCLR registers.
  • Register access must follow the hardware documentation.
