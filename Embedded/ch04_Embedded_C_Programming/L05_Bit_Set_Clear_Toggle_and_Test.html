1. Introduction

Bit manipulation is an important technique in Embedded C programming. It allows a programmer to modify or examine individual bits of a variable or hardware register.

Microcontroller peripherals contain control, status and data registers. Each bit in these registers may control a specific hardware function.

For example, individual bits can be used to configure GPIO pins, enable interrupts, select communication modes and check peripheral status.

Definition: Bit manipulation is the process of setting, clearing, toggling, testing or modifying individual bits using bitwise operators.

2. Binary Representation of Data

Digital processors operate using binary data. A binary digit is called a bit and can have only two possible values: 0 or 1.

An 8-bit value contains eight individual bits. 

Binary:  1 0 1 0 0 1 0 1
Bit:     7 6 5 4 3 2 1 0
Bit Position Bit Value Decimal Weight

The rightmost bit is bit 0, also called the Least Significant Bit (LSB). The leftmost bit is the Most Significant Bit (MSB).

3. Bitwise Operators in C

C provides bitwise operators to perform operations on individual bits of integer values.

Operator Name Purpose
& Bitwise AND Used to mask or test bits.
| Bitwise OR Used to set selected bits.
^ Bitwise XOR Used to toggle selected bits.
~ Bitwise NOT Inverts the bits.
<< Left Shift Shifts bits towards the MSB.
>> Right Shift Shifts bits towards the LSB.

4. Creating a Bit Mask

A bit mask is a binary value used to select particular bits during a bitwise operation.

The expression below creates a mask with only bit 3 set. 

1U << 3

Binary representation using 8 bits:

00001000

Similarly, the following expression creates a mask for bit 5. 

1U << 5
00100000
General Formula: 
BIT_MASK = 1U << bit_position;
The unsigned constant helps avoid signed-shift complications. Ensure the shift count is less than the width of the left operand.

5. Setting a Bit

Setting a bit means changing its value to 1 without affecting the other bits.

The bitwise OR operator (|) is used for this operation.

Syntax

REGISTER |= (1U << bit_position);

Example

unsigned int reg = 0x00;

reg |= (1U << 3);

Binary operation:

Before: 00000000
Mask:   00001000
        --------
After:  00001000

Bit 3 becomes 1, while all other bits retain their previous values.

Setting Multiple Bits

reg |= (1U << 2) | (1U << 5);

This sets bit 2 and bit 5 in the register.

6. Clearing a Bit

Clearing a bit means changing its value to 0 without modifying the other bits.

The bitwise AND operator (&) and bitwise NOT operator (~) are used together.

Syntax

REGISTER &= ~(1U << bit_position);

Example

unsigned int reg = 0xFF;

reg &= ~(1U << 3);

Binary operation using 8 bits:

Before: 11111111
Mask:   00001000
NOT:    11110111
        --------
After:  11110111

Bit 3 becomes 0. All other bits remain unchanged.

7. Toggling a Bit

Toggling means changing a bit from 0 to 1 or from 1 to 0.

The bitwise XOR operator (^) is used for toggling.

Syntax

REGISTER ^= (1U << bit_position);

Example

unsigned int reg = 0x00;

reg ^= (1U << 2);
reg ^= (1U << 2);

Binary operation:

Initial: 00000000

First toggle:
         00000100

Second toggle:
         00000000

The first operation sets bit 2. The second operation clears it.

XOR with 0 preserves a bit. XOR with 1 reverses a bit.

8. Testing a Bit

Testing a bit means checking whether its value is 0 or 1 without modifying the original value.

The bitwise AND operator (&) is used to test a particular bit.

Syntax

if (REGISTER & (1U << bit_position))
{
    /* Bit is set */
}
else
{
    /* Bit is clear */
}

Example

unsigned int reg = 0x08;

if (reg & (1U << 3))
{
    /* Bit 3 is set */
}

Binary operation:

Register: 00001000
Mask:     00001000
          --------
Result:   00001000

Since the result is non-zero, bit 3 is set.

Testing Whether a Bit Is Clear

if ((reg & (1U << 3)) == 0U)
{
    /* Bit 3 is clear */
}

9. Comparison of Set, Clear, Toggle and Test

Operation Expression Effect
Set reg |= mask; Selected bit becomes 1.
Clear reg &= ~mask; Selected bit becomes 0.
Toggle reg ^= mask; Selected bit is inverted.
Test reg & mask Checks selected bit.

10. Practical Embedded C Program

Objective

To perform set, clear, toggle and test operations on individual bits of a software variable.

Program

#include <stdio.h>

int main(void)
{
    unsigned int reg = 0x00U;

    /* Set bit 3 */
    reg |= (1U << 3);

    printf("After setting bit 3: 0x%02X\n", reg);

    /* Set bit 5 */
    reg |= (1U << 5);

    printf("After setting bit 5: 0x%02X\n", reg);

    /* Clear bit 3 */
    reg &= ~(1U << 3);

    printf("After clearing bit 3: 0x%02X\n", reg);

    /* Toggle bit 5 */
    reg ^= (1U << 5);

    printf("After toggling bit 5: 0x%02X\n", reg);

    /* Test bit 3 */
    if (reg & (1U << 3))
    {
        printf("Bit 3 is SET\n");
    }
    else
    {
        printf("Bit 3 is CLEAR\n");
    }

    return 0;
}

Expected Result

After setting bit 3: 0x08
After setting bit 5: 0x28
After clearing bit 3: 0x20
After toggling bit 5: 0x00
Bit 3 is CLEAR
Result: The program successfully demonstrates all four bit manipulation operations.

11. Bit Manipulation with LPC2129 GPIO Registers

The LPC2129 GPIO peripheral provides registers for controlling individual port pins.

Register Purpose
PINSEL0 Selects the function of pins associated with this register.
IODIR0 Configures Port 0 pin directions.
IOPIN0 Reads the Port 0 pin states and provides port-pin access.
IOSET0 Sets selected Port 0 output latch bits.
IOCLR0 Clears selected Port 0 output latch bits.

Example 1: Set P0.5 HIGH

IOSET0 = (1U << 5);

Example 2: Set P0.5 LOW

IOCLR0 = (1U << 5);

Example 3: Configure P0.5 as Output

IODIR0 |= (1U << 5);

Example 4: Read P0.5

if (IOPIN0 & (1U << 5))
{
    /* Pin input level reads HIGH */
}
else
{
    /* Pin input level reads LOW */
}
Important: Before using P0.5 as GPIO, configure its pin function appropriately through PINSEL0. IOSET0 and IOCLR0 are write-one action registers: write the required mask directly. Do not use read-modify-write expressions such as IOSET0 |= mask.

12. Complete LPC2129 GPIO Example

Objective

Configure P0.5 as a GPIO output, set it HIGH, clear it, and inspect the corresponding registers in Keil uVision.

Program

#include <LPC21xx.h>

int main(void)
{
    /* Select GPIO function for P0.5 */
    PINSEL0 &= ~(3U << 10);

    /* Configure P0.5 as output */
    IODIR0 |= (1U << 5);

    /* Set P0.5 HIGH */
    IOSET0 = (1U << 5);

    /* Clear P0.5 */
    IOCLR0 = (1U << 5);

    while (1)
    {
        /* Program remains active */
    }
}

Execution Explanation

  1. PINSEL0 selects GPIO functionality for P0.5.
  2. IODIR0 bit 5 is set to configure output direction.
  3. IOSET0 is written with bit 5 set.
  4. IOCLR0 is written with bit 5 set to clear the output latch.
  5. The program enters the infinite loop.

Expected Register-Level Result

  • P0.5 is selected for GPIO functionality.
  • IODIR0 bit 5 is set to 1.
  • The output latch is finally cleared by IOCLR0.
In Keil uVision, step through the program and inspect the register values. The final output latch state should be LOW. This is a register-level simulation exercise, not a physical LED test.

13. Common Mistakes in Bit Manipulation

Mistake Correct Approach
Using OR to clear a bit. Use AND with the inverted mask.
Using AND to toggle a bit. Use XOR.
Using assignment instead of compound OR. Use reg |= mask when other bits must be preserved.
Using an incorrect bit position. Check the device register and pin documentation.
Using signed constants carelessly in shifts. Use appropriately typed unsigned constants.
Using read-modify-write on action registers. Follow the peripheral's specified write semantics.
Assuming volatile makes operations atomic. Use suitable synchronization or atomic mechanisms when required.

14. Interview Questions and Answers

Q1. What is bit manipulation?

Bit manipulation is the process of changing or checking individual bits using bitwise operators.

Q2. Which operator is used to set a bit?

The bitwise OR operator (|) is used to set selected bits.

Q3. How do you clear a particular bit?

Use the bitwise AND operator with the complemented bit mask: reg &= ~(1U << n);

Q4. Which operator is used to toggle a bit?

The bitwise XOR operator (^).

Q5. How do you test whether a bit is set?

Use reg & (1U << n) and check whether the result is non-zero.

Q6. What is a bit mask?

A bit mask is a binary value used to select specific bits during a bitwise operation.

Q7. What is the difference between bitwise AND and logical AND?

Bitwise AND operates on individual bits. Logical AND evaluates truth values and produces either 0 or 1.

Q8. Why is bit manipulation important in Embedded C?

It allows efficient control and inspection of individual hardware register bits.

Q9. What happens when a bit is XORed with 1?

Its value is inverted: 0 becomes 1 and 1 becomes 0.

Q10. Can a bitwise operation modify a hardware register?

Yes, if the register is accessed through a suitable memory-mapped definition and the operation is permitted by the hardware's register semantics.

17. Lesson Summary

  • Bit manipulation is essential for hardware register programming.
  • OR is used to set selected bits.
  • AND with an inverted mask is used to clear selected bits.
  • XOR is used to toggle selected bits.
  • AND is used to test selected bits.
  • Left shifting helps generate bit masks.
  • LPC2129 GPIO registers support individual pin control.
  • Register access must follow the hardware-defined semantics.
