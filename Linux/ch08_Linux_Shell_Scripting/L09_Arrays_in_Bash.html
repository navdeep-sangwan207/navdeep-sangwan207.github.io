Arrays in Bash

Storing and Managing Multiple Values in Shell Scripts

1. Introduction to Arrays

An array is a data structure used to store multiple values in a single variable. Each element can be accessed using its index or key.

Without arrays, we might need separate variables to store multiple values. Arrays allow us to organize related data efficiently.

Example Without an Array

name1="Navdeep" name2="Rahul" name3="Amit" echo "$name1" echo "$name2" echo "$name3"

Example Using an Array

names=("Navdeep" "Rahul" "Amit") echo "${names[0]}" echo "${names[1]}" echo "${names[2]}"

Output

Navdeep
Rahul
Amit
Explanation: The array names stores three values. Each value is accessed using its index.

2. Types of Arrays in Bash

Bash mainly supports two types of arrays:

Array Type Description Index
Indexed Array Stores values using numeric indexes. Integer indexes
Associative Array Stores values using named keys. String keys
Note: Indexed arrays are supported in Bash. Associative arrays require Bash 4.0 or later.

3. Creating an Indexed Array

An indexed array stores values using numeric indexes. Bash array indexes normally begin at zero.

Method 1: Direct Array Assignment

#!/bin/bash numbers=(10 20 30 40 50) echo "${numbers[0]}" echo "${numbers[1]}" echo "${numbers[2]}"

Output

10
20
30

Method 2: Assigning Individual Elements

#!/bin/bash numbers[0]=100 numbers[1]=200 numbers[2]=300 echo "${numbers[0]}" echo "${numbers[1]}" echo "${numbers[2]}"

Output

100
200
300

Method 3: Using the declare Command

#!/bin/bash declare -a fruits fruits[0]="Apple" fruits[1]="Mango" fruits[2]="Orange" echo "${fruits[0]}"

Output

Apple

The declare -a command explicitly declares an indexed array.

4. Accessing Array Elements

Individual elements are accessed using the array name followed by an index inside square brackets.

Syntax

${array_name[index]}

Example

#!/bin/bash colors=("Red" "Green" "Blue" "Yellow") echo "First color: ${colors[0]}" echo "Second color: ${colors[1]}" echo "Third color: ${colors[2]}" echo "Fourth color: ${colors[3]}"

Output

First color: Red
Second color: Green
Third color: Blue
Fourth color: Yellow
Important: Use curly braces when expanding array elements, such as ${colors[0]}.

5. Displaying All Array Elements

Use ${array_name[@]} or ${array_name[*]} to expand all array elements.

Example

#!/bin/bash subjects=("C" "C++" "Linux" "Embedded C") echo "All subjects: ${subjects[@]}"

Output

All subjects: C C++ Linux Embedded C

Difference Between @ and *

Expression Meaning
${array[@]} Expands all elements individually.
${array[*]} Expands all elements together.
"${array[@]}" Preserves each element as a separate quoted word.
"${array[*]}" Expands all elements as one quoted word, joined by the first character of IFS.
Example: For processing array elements individually, prefer "${array[@]}".

6. Finding the Length of an Array

The expression ${#array_name[@]} returns the number of assigned elements in an array.

Syntax

${#array_name[@]}

Example

#!/bin/bash languages=("C" "C++" "Python" "Java" "Bash") echo "Number of elements: ${#languages[@]}"

Output

Number of elements: 5
Note: Array length is the number of assigned elements, not necessarily the highest index plus one. Bash arrays can have gaps in their indexes.

7. Updating Array Elements

An existing array element can be modified by assigning a new value to its index.

Example

#!/bin/bash fruits=("Apple" "Mango" "Orange") echo "Before update: ${fruits[1]}" fruits[1]="Banana" echo "After update: ${fruits[1]}"

Output

Before update: Mango
After update: Banana

8. Adding Elements to an Array

Use the += operator to append new elements to an indexed array.

Example

#!/bin/bash numbers=(10 20 30) numbers+=(40 50) echo "Updated array: ${numbers[@]}"

Output

Updated array: 10 20 30 40 50

Adding an Element at a Specific Index

#!/bin/bash numbers=(10 20 30) numbers[5]=60 echo "Element at index 5: ${numbers[5]}" echo "Number of elements: ${#numbers[@]}"

Output

Element at index 5: 60
Number of elements: 4

The indexes 3 and 4 remain unassigned. The array contains four assigned elements at indexes 0, 1, 2 and 5.

9. Removing Array Elements

Use the unset command to remove an array element or the entire array.

Removing a Specific Element

#!/bin/bash fruits=("Apple" "Mango" "Orange") unset 'fruits[1]' echo "Remaining elements: ${fruits[@]}" echo "Number of elements: ${#fruits[@]}"

Output

Remaining elements: Apple Orange
Number of elements: 2

Removing the Entire Array

#!/bin/bash fruits=("Apple" "Mango" "Orange") unset fruits echo "Array removed"

Output

Array removed
Note: Removing an element does not automatically renumber the remaining indexed elements.

10. Iterating Through Arrays Using Loops

A loop can process each array element one at a time. The for loop is commonly used for this purpose.

Example 1: Using a for-in Loop

#!/bin/bash fruits=("Apple" "Mango" "Orange") for fruit in "${fruits[@]}" do echo "$fruit" done

Output

Apple
Mango
Orange

Example 2: Displaying Index and Value

#!/bin/bash languages=("C" "C++" "Bash") for index in "${!languages[@]}" do echo "Index: $index, Value: ${languages[index]}" done

Output

Index: 0, Value: C
Index: 1, Value: C++
Index: 2, Value: Bash

The expression ${!languages[@]} expands to the assigned indexes of the array.

11. Associative Arrays in Bash

An associative array stores values using named keys instead of numeric indexes.

Associative arrays are useful when data is stored as key-value pairs, such as employee details, configuration settings and product information.

Declaring an Associative Array

declare -A array_name

Example: Employee Details

#!/bin/bash declare -A employee employee[name]="Navdeep" employee[department]="Electronics" employee[experience]="4 months" echo "Name: ${employee[name]}" echo "Department: ${employee[department]}" echo "Experience: ${employee[experience]}"

Output

Name: Navdeep
Department: Electronics
Experience: 4 months
Important: Declare an associative array with declare -A before assigning its elements. Associative arrays require Bash 4.0 or later.

12. Accessing Associative Array Elements

Associative array elements are accessed using their corresponding keys.

Example

#!/bin/bash declare -A student student[name]="Rahul" student[course]="Linux" student[duration]="6 months" echo "Student: ${student[name]}" echo "Course: ${student[course]}" echo "Duration: ${student[duration]}"

Output

Student: Rahul
Course: Linux
Duration: 6 months

Displaying All Keys

#!/bin/bash declare -A student student[name]="Rahul" student[course]="Linux" student[duration]="6 months" echo "Keys: ${!student[@]}"

Possible Output

Keys: course name duration

Associative array key order is not guaranteed.

Displaying All Values

#!/bin/bash declare -A student student[name]="Rahul" student[course]="Linux" student[duration]="6 months" echo "Values: ${student[@]}"

Possible Output

Values: Linux Rahul 6 months
Note: For associative arrays, use "${!array[@]}" to access keys and "${array[@]}" to access values. Their iteration order is not guaranteed.

13. Practical Array Operations

Program 1: Calculate the Sum of Array Elements

#!/bin/bash numbers=(10 20 30 40 50) sum=0 for number in "${numbers[@]}" do sum=$((sum + number)) done echo "Sum = $sum"

Output

Sum = 150

Program 2: Find the Largest Array Element

#!/bin/bash numbers=(12 45 23 67 34) largest=${numbers[0]} for number in "${numbers[@]}" do if [ "$number" -gt "$largest" ]; then largest=$number fi done echo "Largest number = $largest"

Output

Largest number = 67

Program 3: Search for an Element

#!/bin/bash numbers=(10 20 30 40 50) search=30 found=0 for number in "${numbers[@]}" do if [ "$number" -eq "$search" ]; then found=1 break fi done if [ "$found" -eq 1 ]; then echo "$search found in array" else echo "$search not found in array" fi

Output

30 found in array

Program 4: Reverse an Array

#!/bin/bash numbers=(10 20 30 40 50) for (( i=${#numbers[@]}-1; i>=0; i-- )) do echo "${numbers[i]}" done

Output

50
40
30
20
10

Program 5: Count Even and Odd Numbers

#!/bin/bash numbers=(10 15 20 25 30 35) even=0 odd=0 for number in "${numbers[@]}" do if [ $((number % 2)) -eq 0 ]; then even=$((even + 1)) else odd=$((odd + 1)) fi done echo "Even numbers: $even" echo "Odd numbers: $odd"

Output

Even numbers: 3
Odd numbers: 3

14. Important Array Syntax Reference

Syntax Purpose
arr=(10 20 30) Create an indexed array.
arr[0]=10 Assign an element at index 0.
${arr[0]} Access an element.
${arr[@]} Expand all values.
${#arr[@]} Count assigned elements.
${!arr[@]} Display assigned indexes.
arr+=(40 50) Append elements.
unset 'arr[1]' Remove an element.
unset arr Remove the entire array.
declare -A arr Declare an associative array.

16. Interview Questions and Answers

Q1. What is an array in Bash?

Answer: An array is a variable that stores multiple values under one name.

Q2. What are the types of arrays in Bash?

Answer: Indexed arrays and associative arrays.

Q3. What is the starting index of an indexed array?

Answer: The default first index is zero.

Q4. How do you declare an indexed array?

Answer: Use declare -a or assign values using array=(...).

Q5. How do you access the first element?

Answer: Use ${array[0]}.

Q6. How do you display all array elements?

Answer: Use ${array[@]} or ${array[*]}.

Q7. How do you find the length of an array?

Answer: Use ${#array[@]}.

Q8. What is an associative array?

Answer: An associative array stores values using named keys rather than numeric indexes.

Q9. Which command declares an associative array?

Answer: declare -A array_name.

Q10. How do you remove an array element?

Answer: Use unset 'array[index]'.

Q11. How do you append elements to an array?

Answer: Use the += operator.

Q12. Can arrays contain strings and numbers?

Answer: Yes. Bash arrays can contain strings, numbers and other text values. Bash does not enforce a fixed element data type.

Q1. Which syntax creates an indexed array?

A. arr={10,20,30}
B. arr=(10 20 30)
C. arr=[10,20,30]

Answer: B. arr=(10 20 30)

Q2. What is the index of the first element?

Answer: C. 0

Q3. Which expression displays all array elements?

A. ${arr[0]}

D. $arr

Answer: B. ${arr[@]}

Q4. Which expression gives the number of assigned elements?

A. ${arr[0]}
B. ${!arr[@]}
C. ${#arr[@]}
D. ${arr[*]}

Answer: C. ${#arr[@]}

Q5. Which command declares an associative array?

A. declare -a
B. declare -A

D. unset -A

Answer: B. declare -A

Q6. Which command removes an individual element?

A. delete
B. remove

D. clear

Answer: C. unset

Q7. Which expression displays the assigned indexes?

A. ${!arr[@]}
B. ${#arr[@]}
C. ${arr[0]}

Answer: A. ${!arr[@]}

18. Lesson Summary

  • Arrays store multiple values under one variable name.
  • Bash supports indexed and associative arrays.
  • Indexed arrays use numeric indexes starting at zero by default.
  • Use ${array[index]} to access an element.
  • Use ${array[@]} to expand all elements.
  • Use ${#array[@]} to count assigned elements.
  • Use += to append new elements.
  • Use unset to remove elements or entire arrays.
  • Use loops to process array elements.
  • Use declare -A to create associative arrays.
