1. Introduction to Shell Variables

A variable is a named storage location used to hold a value that can be accessed and used during script execution. In Bash, variables can store text, numbers, command output and other data.

Definition: A shell variable is a named parameter that stores a value for use by shell commands and scripting instructions.

Example

#!/bin/bash name="Navdeep" echo "$name"
Output:
Navdeep

Here, name is the variable and Navdeep is its assigned value.

2. Declaring and Assigning Variables

In Bash, a variable can be created simply by assigning a value to its name. A separate declaration statement is generally not required.

Syntax

variable_name=value

Examples

name="Navdeep" age=25 city="Chandigarh" course="Embedded Systems"

These statements assign values to four different variables.

Important: Do not put spaces around the assignment operator (=).

Incorrect Assignment

name = "Navdeep"

Bash interprets this as an attempt to execute a command named name, rather than assign a value.

Correct Assignment

name="Navdeep"

3. Accessing Variable Values

The dollar sign ($) is used to access the value stored in a shell variable.

Syntax

$variable_name ${variable_name}

Example

#!/bin/bash name="Navdeep" course="Linux Shell Scripting" echo $name echo $course echo "Name: $name" echo "Course: $course"
Output:
Navdeep Linux Shell Scripting Name: Navdeep Course: Linux Shell Scripting

Using Curly Braces

Curly braces clearly identify the variable name. They are especially useful when additional characters immediately follow a variable.

name="Linux" echo "${name}Programming"
Output:
LinuxProgramming
Without braces, Bash may interpret the following characters as part of the variable name.

4. Variable Naming Rules

Bash variable names must follow certain naming rules.

Rules

  • Variable names can contain letters, digits and underscores.
  • A variable name cannot begin with a digit.
  • Spaces are not allowed in variable names.
  • Special characters such as hyphens should not be used in ordinary variable names.
  • Variable names are case-sensitive.
  • Reserved shell keywords should not be used as variable names.

Valid Variable Names

name="Navdeep" user_name="Navdeep" age=25 total_marks=450 _count=10 course1="Bash"

Invalid or Problematic Variable Names

2name="Navdeep" user-name="Navdeep" user name="Navdeep"
Variable Valid? Reason
name Yes Contains letters.
user_name Yes Underscore is allowed.
age25 Yes Digits are allowed after the first character.
2name No Cannot begin with a digit.
user-name No Hyphen is not allowed in an ordinary variable name.
user name No Contains a space.

5. Case Sensitivity in Variables

Bash variable names are case-sensitive. Uppercase and lowercase names represent different variables.

Example

#!/bin/bash name="Navdeep" NAME="Sangwan" echo "$name" echo "$NAME"
Output:
Navdeep Sangwan

Here, name and NAME are two separate variables.

6. Types of Quoting in Bash

Quoting controls how Bash interprets text, variable references and special characters.

A. Double Quotes

Double quotes preserve most characters literally while allowing variable expansion and command substitution.

name="Navdeep" echo "Welcome $name"
Output:
Welcome Navdeep

B. Single Quotes

Single quotes preserve the enclosed characters literally. Variables inside single quotes are not expanded.

name="Navdeep" echo 'Welcome $name'
Output:
Welcome $name

C. No Quotes

Unquoted variable expansions can undergo word splitting and pathname expansion. This can produce unexpected results when values contain spaces or wildcard characters.

name="Linux Programming" echo $name
Typical output:
Linux Programming
Best practice: Prefer "$variable" when using variable values, unless you intentionally need word splitting or pathname expansion.

Comparison

Quoting Variable Expansion Typical Use
Double quotes Yes Text containing variables.
Single quotes No Literal text.
No quotes Yes When splitting or wildcard expansion is intentional.

7. Using Variables with echo

The echo command displays text and variable values on the terminal.

Example

#!/bin/bash first_name="Navdeep" last_name="Sangwan" echo "First Name: $first_name" echo "Last Name: $last_name" echo "Full Name: ${first_name} ${last_name}"
Output:
First Name: Navdeep Last Name: Sangwan Full Name: Navdeep Sangwan

8. Accepting Input Using read

The read command accepts input from the keyboard and stores it in a variable.

Syntax

read variable_name

Example

#!/bin/bash echo "Enter your name:" read name echo "Welcome, $name"
Example interaction:
Enter your name: Navdeep Welcome, Navdeep

Using read with a Prompt

#!/bin/bash read -p "Enter your city: " city echo "Your city is $city"
Example interaction:
Enter your city: Chandigarh Your city is Chandigarh

Reading Multiple Variables

#!/bin/bash read -p "Enter first name and city: " name city echo "Name: $name" echo "City: $city"
Example interaction:
Enter first name and city: Navdeep Chandigarh Name: Navdeep City: Chandigarh
When multiple variables are read, Bash assigns input fields to the variables in order. The final variable receives any remaining input.

9. Assigning Command Output to Variables

Bash supports command substitution. It allows the output of a command to be stored in a variable.

Syntax

variable=$(command)

Example 1: Store Current Date

#!/bin/bash current_date=$(date) echo "Current Date: $current_date"

Example 2: Store Current Directory

#!/bin/bash current_directory=$(pwd) echo "Current Directory: $current_directory"

Example 3: Store Username

#!/bin/bash current_user=$(whoami) echo "Current User: $current_user"

Alternative Backtick Syntax

current_date=`date` echo "$current_date"
Best practice: Prefer $(command) over backticks because it is easier to read and supports nesting more clearly.

10. Read-Only Variables

A read-only variable is a variable whose value cannot be changed after it has been declared read-only.

Syntax

readonly variable_name=value

Example

#!/bin/bash readonly PI=3.14159 echo "Value of PI: $PI"
Output:
Value of PI: 3.14159

Attempt to Modify a Read-Only Variable

PI=3.14
Typical Bash error:
bash: PI: readonly variable

You can also use the declare -r command to create a read-only variable.

declare -r MAX_LIMIT=100

11. Local Variables in Functions

A local variable is a variable whose scope is limited to the function in which it is declared.

Bash uses the local keyword to declare function-local variables.

Example

#!/bin/bash show_message() { local message="Hello from function" echo "$message" } show_message
Output:
Hello from function
The local keyword is used inside Bash functions. It is not part of portable POSIX shell syntax.

12. Displaying and Removing Variables

Display a Variable

name="Navdeep" echo "$name"

Display Variable Attributes

declare -p name

Display All Shell Variables

set

The set command without arguments displays shell variables, functions and other shell information. Its output can be lengthy.

Remove a Variable Using unset

name="Navdeep" unset name echo "$name"
Output:

No value is displayed because the variable has been removed.

Important: The unset command removes a variable from the current shell environment. It does not delete a file or directory.

13. Shell Variables and Environment Variables

A shell variable normally belongs to the current shell. An environment variable is exported so that child processes can inherit it.

Example: Ordinary Shell Variable

name="Navdeep" bash -c 'echo "$name"'

In a normal Bash session, the child Bash process does not inherit name as an environment variable.

Example: Exported Variable

name="Navdeep" export name bash -c 'echo "$name"'
Output:
Navdeep

The exported variable is available to the child Bash process through its environment.

Important distinction: Every environment variable is available as a shell variable in the receiving shell, but not every shell variable is automatically exported to child processes.

Environment variables are covered in detail in the next lesson.

18. Interview Questions and Answers

Q1. What is a shell variable?

A shell variable is a named parameter used to store a value for use in shell commands and scripts.

Q2. How do you declare a variable in Bash?

Assign a value using the syntax variable_name=value.

Q3. Why should spaces not be used around the assignment operator?

Bash interprets spaces as command and argument separators. Therefore, name = value is not a variable assignment.

Q4. How do you access a variable?

Use the dollar sign, for example $name or ${name}.

Q5. Are Bash variable names case-sensitive?

Yes. For example, name and NAME are separate variables.

Q6. What is the difference between single and double quotes?

Single quotes prevent variable expansion. Double quotes allow variable expansion and command substitution.

Q7. What is the purpose of read?

The read command accepts input and stores it in one or more shell variables.

Q8. What is command substitution?

Command substitution captures the output of a command. It is commonly written as $(command).

Q9. What is a read-only variable?

It is a variable whose value cannot be modified after it has been marked read-only.

Q10. What is the purpose of unset?

The unset command removes a variable or function from the current shell environment.

Q11. What is a local variable?

A local variable is limited to the function in which it is declared using the local keyword.

Q12. What is the difference between a shell variable and an environment variable?

A shell variable normally belongs to the current shell. An environment variable is exported so child processes can inherit it.

19. Multiple Choice Questions (MCQs)

Q1. Which symbol is used to access a variable in Bash?

  1. #
  2. $
  3. @
  4. %

Correct Answer: B. $

Q2. Which is the correct variable assignment?

  1. name = "Linux"
  2. name="Linux"
  3. name: "Linux"
  4. name == "Linux"

Correct Answer: B. name="Linux"

Q3. Which variable name is valid?

  1. 2name
  2. user-name
  3. user_name
  4. user name

Correct Answer: C. user_name

Q4. Which command accepts user input?

  1. echo
  2. read
  3. pwd
  4. date

Correct Answer: B. read

Q5. Which quoting method prevents variable expansion?

  1. Double quotes
  2. Single quotes
  3. No quotes
  4. Curly braces

Correct Answer: B. Single quotes

Q6. Which command removes a variable?

  1. remove
  2. delete
  3. unset
  4. clear

Correct Answer: C. unset

Q7. Which command creates a read-only variable?

  1. readonly
  2. unset
  3. remove
  4. export

Correct Answer: A. readonly

Q8. Which syntax performs command substitution?

  1. ${command}
  2. $(command)
  3. [command]
  4. {command}

Correct Answer: B. $(command)

Q9. Which keyword declares a function-local variable in Bash?

  1. global
  2. static
  3. local
  4. private

Correct Answer: C. local

Q10. Which command exports a variable to child processes?

  1. unset
  2. export
  3. read
  4. pwd

Correct Answer: B. export

20. Lesson Summary

  • Variables store values used by Bash scripts.
  • Assign values using name=value.
  • Use $name or ${name} to access values.
  • Variable names are case-sensitive.
  • Single quotes prevent variable expansion; double quotes allow it.
  • Use read to accept keyboard input.
  • Use $(command) for command substitution.
  • Use readonly to prevent reassignment.
  • Use local to declare function-local variables.
  • Use export to pass variables to child processes.
  • Use unset to remove a variable.
