Chapter 8: Linux Shell Scripting

Linux Programming | Shell and Bash Scripting

Chapter Overview

Shell scripting allows users to automate tasks and execute multiple Linux commands through script files. It is an important skill for Linux system administration, automation, and systems programming.

In this chapter, you will learn Bash scripting fundamentals, variables, environment variables, command-line arguments, conditional statements, loops, functions, arrays, file tests, arithmetic operations, and error handling. You will also practise practical shell scripting programs.
