Environment Variables in Linux

Understanding, viewing, creating and managing environment variables in Bash

Home Linux Course Chapter 8

Learning Objectives

After completing this lesson, you will be able to:

  • Understand environment variables in Linux.
  • Differentiate shell variables from environment variables.
  • Identify commonly used predefined environment variables.
  • Display environment variables using env and printenv.
  • Create and export environment variables.
  • Understand the purpose of the PATH variable.
  • Modify and remove environment variables.
  • Understand how child processes inherit environment variables.

1. Introduction to Environment Variables

An environment variable is a named value maintained in a process environment. It provides configuration information to programs and processes running in Linux.

Environment variables are commonly used to store information such as:

  • Current user's home directory.
  • Current username.
  • Default shell location.
  • Current working directory.
  • Directories searched for executable commands.
  • Application configuration settings.

Example

echo "$HOME" echo "$USER" echo "$SHELL"

These commands display the values of three commonly used environment variables.

Important: Environment variables are normally inherited by child processes created by a process. A variable that exists only as an ordinary shell variable is not automatically inherited.

2. Shell Variables vs Environment Variables

Shell variables are variables maintained by the current shell. Environment variables are variables exported into the environment so that child processes can inherit them.

Feature Shell Variable Environment Variable
Scope Current shell Current process and inherited child processes
Creation name=value export name=value
Child process inheritance Not inherited automatically Inherited by child processes
Viewing set env or printenv

Example: Shell variable

course="Linux Programming" echo "$course" bash -c 'echo "$course"'
Expected output:
Linux Programming
The child Bash process does not inherit the unexported shell variable.

Example: Environment variable

export course="Linux Programming" bash -c 'echo "$course"'
Expected output:
Linux Programming
The export command marks the variable for inclusion in the environment of subsequently started child processes.

3. Common Environment Variables

Linux provides several predefined environment variables. Their values may differ between users and systems.

Variable Purpose Example
HOME Current user's home directory /home/navdeep
USER Current username navdeep
SHELL Configured login shell path /bin/bash
PATH Directories searched for executable commands /usr/bin:/bin
PWD Current working directory /home/navdeep
OLDPWD Previous working directory /home
LANG Locale and language settings en_US.UTF-8
TERM Terminal type information xterm-256color

Display individual variables

echo "$HOME" echo "$USER" echo "$SHELL" echo "$PATH" echo "$PWD" echo "$OLDPWD" echo "$LANG" echo "$TERM"
Note: The examples in the table are illustrative. Actual values depend on the Ubuntu installation, user account, terminal and system configuration. Some variables may be unset in particular environments.

4. Displaying Environment Variables Using env

The env command displays the environment variables available to the current process.

Syntax

env

Example

env

The command prints environment entries in the form NAME=value.

Example output (system-dependent):
HOME=/home/navdeep USER=navdeep SHELL=/bin/bash LANG=en_US.UTF-8 PWD=/home/navdeep
Your actual output will contain additional variables and may use different values.

Using env to run a command with a temporary variable

env COURSE="Embedded Systems" bash -c 'echo "$COURSE"'
Expected output:
Embedded Systems

The variable is supplied to the environment of the command without permanently changing the current shell's variables.

5. Displaying Variables Using printenv

The printenv command displays environment variables. It can display all environment variables or a selected variable.

Display all environment variables

printenv

Display a specific variable

printenv HOME printenv USER printenv SHELL printenv PATH
Example output (system-dependent):
/home/navdeep navdeep /bin/bash /usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin

Display multiple selected variables

printenv HOME USER SHELL
If a requested variable is not present in the environment, printenv does not print a value for it. Its exit status can indicate that a requested variable was not found.

6. Understanding the PATH Variable

The PATH environment variable contains a colon-separated list of directories. When you enter a command without specifying its path, the shell searches these directories for an executable with that name.

Display PATH

echo "$PATH"

Example format:

/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

Display each PATH directory on a separate line

echo "$PATH" | tr ':' '\n'

Temporarily add a directory to PATH

PATH="$PATH:$HOME/my_scripts" export PATH

Now the shell can search the my_scripts directory when resolving commands by name.

Warning: Avoid replacing PATH with an incomplete value. Removing standard system directories can prevent commands from being found. The example above appends a directory while preserving the existing PATH.

Check the location of a command

command -v ls command -v bash command -v gcc

The output identifies the command location or indicates that the command is unavailable. Results depend on installed software and PATH.

7. Creating Environment Variables Using export

The export command marks a shell variable for inclusion in the environment of subsequently executed child processes.

Syntax

export VARIABLE_NAME=value

Example 1: Create and export a variable

export COURSE="Embedded Systems" echo "$COURSE" printenv COURSE
Expected output:
Embedded Systems Embedded Systems

Example 2: Export an existing shell variable

STUDENT="Navdeep" export STUDENT printenv STUDENT
Expected output:
Navdeep

Example 3: Export multiple variables

export NAME="Navdeep" CITY="Chandigarh" printenv NAME printenv CITY
Expected output:
Navdeep Chandigarh

8. Modifying Environment Variables

An exported variable can be assigned a new value in the current shell. Its exported status is retained.

Example

export COURSE="Linux" echo "$COURSE" COURSE="Embedded Systems" echo "$COURSE" bash -c 'echo "$COURSE"'
Expected output:
Linux Embedded Systems Embedded Systems

The updated value is inherited by the child process because the variable remains exported.

9. Removing Environment Variables Using unset

The unset command removes a variable from the current shell.

Syntax

unset VARIABLE_NAME

Example

export COURSE="Linux Programming" echo "$COURSE" unset COURSE echo "$COURSE" printenv COURSE
Expected behavior:
Linux Programming
The later commands produce no value because the variable has been removed from the current shell environment.
Important: Unsetting a variable in a shell does not remove copies already inherited by previously started child processes.

10. Environment Variables and Child Processes

A child process normally inherits a copy of its parent's exported environment variables when it is created.

Practical demonstration

export DEPARTMENT="Electronics" bash -c 'echo "Department: $DEPARTMENT"'
Expected output:
Department: Electronics

Modify a variable inside the child process

export DEPARTMENT="Electronics" bash -c 'DEPARTMENT="Computer Science"; echo "Child: $DEPARTMENT"' echo "Parent: $DEPARTMENT"
Expected output:
Child: Computer Science Parent: Electronics

The child receives its own environment copy. Changing its variable does not automatically change the parent's variable.

11. Making Environment Variables Persistent

Variables exported directly in a terminal session normally remain available only for that shell session and its child processes.

To configure variables automatically for future Bash sessions, you can place export statements in an appropriate shell startup file.

Common Bash configuration files

File Purpose
~/.bashrc Commands and settings for interactive non-login Bash shells.
~/.profile User login-shell configuration, commonly used for login environment settings.
/etc/environment System-wide environment assignments managed by the system's environment configuration mechanism. It is not a Bash script.

Example: Add a variable to .bashrc

nano ~/.bashrc

Add this line at the end of the file:

export COURSE="Embedded Systems"

Save the file, then reload it in the current Bash session:

source ~/.bashrc

Verify:

echo "$COURSE"
Expected output:
Embedded Systems
Important: Use the correct startup file for the type of shell being configured. Editing ~/.bashrc is suitable for interactive Bash shells, but it is not a universal method for setting variables for every program or service.

12. Practical Lab Exercises

Lab 1: Display system environment information

Objective: Display commonly used environment variables.

Program:

#!/bin/bash echo "Home Directory: $HOME" echo "Username: $USER" echo "Shell: $SHELL" echo "Working Directory: $PWD" echo "Language: $LANG"

Run:

chmod +x environment_info.sh ./environment_info.sh

Expected Result: The script displays the environment information for the current user and session. Values depend on the system.

Lab 2: Create and export a course variable

Objective: Create an environment variable and access it from a child process.

#!/bin/bash export COURSE="Embedded Systems" echo "Parent Process: $COURSE" bash -c 'echo "Child Process: $COURSE"'

Expected Result:

Parent Process: Embedded Systems Child Process: Embedded Systems

Lab 3: Display PATH directories

Objective: Display the directories stored in PATH.

#!/bin/bash echo "Directories in PATH:" echo "$PATH" | tr ':' '\n'

Expected Result: Each PATH directory is displayed on a separate line. The exact directories depend on your Ubuntu configuration.

13. Common Mistakes

Mistake Correct approach
Assuming every shell variable is inherited by child processes. Use export when inheritance is required.
Using printenv to display an unexported shell variable. Use echo "$variable" or export it first.
Overwriting PATH with an incomplete directory list. Append to the existing PATH when appropriate.
Assuming environment variable values are identical on all Linux systems. Check actual values using printenv.
Expecting a child process to modify its parent's environment. Remember that child processes receive their own environment copy.

14. Interview Questions and Answers

Q1. What is an environment variable?

Answer: An environment variable is a named value in a process environment that supplies configuration information to programs and processes.

Q2. What is the difference between a shell variable and an environment variable?

Answer: A shell variable belongs to the current shell. An environment variable is exported and can be inherited by child processes.

Q3. What is the purpose of the export command?

Answer: The export command marks a variable for inclusion in the environment of subsequently started child processes.

Q4. What is the purpose of PATH?

Answer: PATH contains directories that the shell searches when locating executable commands entered without an explicit path.

Q5. What is the difference between env and printenv?

Answer: Both can display environment information. env can also execute a command with a modified environment, while printenv is primarily used to display environment variable values.

Q6. What does HOME represent?

Answer: HOME normally contains the path of the current user's home directory.

Q7. Can a child process modify its parent's environment variable?

Answer: No. A child process receives its own environment copy. Its changes do not automatically modify the parent process.

Q8. How can you make a variable available in future interactive Bash sessions?

Answer: Add an appropriate export statement to a Bash startup file such as ~/.bashrc, then reload it or start a new applicable shell session.

Q9. What is the purpose of unset?

Answer: It removes a variable from the current shell and its environment if it was exported.

Q10. What does printenv HOME display?

Answer: It displays the value of the HOME environment variable, if it is set.

15. Multiple Choice Questions (MCQs)

Q1. Which command displays environment variables?

A. mkdir
B. env
C. cd
D. rm

Answer: B. env

Q2. Which command exports a variable?

A. export
B. unset
C. pwd
D. clear

Answer: A. export

Q3. Which variable stores the user's home directory?

A. PATH
B. USER
C. HOME
D. TERM

Answer: C. HOME

Q4. Which variable contains executable search directories?

A. PWD
B. PATH
C. LANG
D. SHELL

Answer: B. PATH

Q5. Which command displays the value of a selected environment variable?

A. printenv HOME
B. mkdir HOME
C. rm HOME
D. cd HOME

Answer: A. printenv HOME

Q6. Which command removes an environment variable from the current shell?

A. export
B. unset
C. env
D. echo

Answer: B. unset

Q7. Which file commonly configures interactive non-login Bash shells?

A. /etc/passwd
B. ~/.bashrc
C. /etc/hosts
D. /bin/bash

Answer: B. ~/.bashrc

Q8. What happens when an exported variable is inherited by a child process?

A. It is automatically deleted
B. It is copied into the child's environment
C. It becomes readonly
D. It changes the parent's value

Answer: B. It is copied into the child's environment

16. Lesson Summary

  • Environment variables provide configuration information to processes.
  • Shell variables are not automatically inherited by child processes.
  • export marks variables for inheritance by subsequently started child processes.
  • env displays environment entries and can run commands with a modified environment.
  • printenv displays environment variables.
  • HOME, USER, SHELL, PATH and PWD are commonly used environment variables.
  • PATH controls where the shell searches for executable commands.
  • unset removes a variable from the current shell.
  • Bash startup files can configure variables for future shell sessions.
