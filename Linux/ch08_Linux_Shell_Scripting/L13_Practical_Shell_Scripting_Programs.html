1. Creating and Running Bash Scripts

A shell script is a text file containing Linux commands and Bash programming statements. It can automate tasks that would otherwise require repeated manual commands.

Step 1: Create a Script

nano hello.sh

Step 2: Write the Program

#!/bin/bash echo "Welcome to NS Learning Hub" echo "Learning Linux Shell Scripting"

Step 3: Save and Exit Nano

Press Ctrl + O, Enter, and then Ctrl + X.

Step 4: Give Execute Permission

chmod +x hello.sh

Step 5: Execute the Script

./hello.sh

Output

Welcome to NS Learning Hub
Learning Linux Shell Scripting
You can also run a script using bash hello.sh. This invokes Bash directly and does not require the script's execute permission.

3. Program: Add Two Numbers

Objective: Accept two integers from the user and calculate their sum.

Program

#!/bin/bash read -p "Enter first number: " a read -p "Enter second number: " b if [[ ! "$a" =~ ^-?[0-9]+$ || ! "$b" =~ ^-?[0-9]+$ ]]; then echo "Error: Please enter valid integers" exit 1 fi sum=$((a + b)) echo "Sum = $sum"

Output

Enter first number: 25
Enter second number: 15
Sum = 40
read accepts input, and $((a + b)) performs integer arithmetic. The regular expression allows positive and negative integers.

4. Program: Check Even or Odd

Objective: Determine whether an integer is even or odd.

Program

#!/bin/bash read -p "Enter an integer: " number if [[ ! "$number" =~ ^-?[0-9]+$ ]]; then echo "Error: Enter a valid integer" exit 1 fi if (( number % 2 == 0 )); then echo "$number is Even" else echo "$number is Odd" fi

5. Program: Find the Largest of Three Numbers

Objective: Compare three integers and display the largest value.

Program

#!/bin/bash read -p "Enter first number: " a read -p "Enter second number: " b read -p "Enter third number: " c if [[ ! "$a" =~ ^-?[0-9]+$ || ! "$b" =~ ^-?[0-9]+$ || ! "$c" =~ ^-?[0-9]+$ ]]; then echo "Error: Enter valid integers" exit 1 fi if (( a >= b && a >= c )); then largest=$a elif (( b >= a && b >= c )); then largest=$b else largest=$c fi echo "Largest number = $largest"

Output

Enter first number: 45
Enter second number: 78
Enter third number: 32
Largest number = 78

6. Program: Simple Calculator

Objective: Perform addition, subtraction, multiplication and integer division.

Program

#!/bin/bash read -p "Enter first number: " a read -p "Enter second number: " b if [[ ! "$a" =~ ^-?[0-9]+$ || ! "$b" =~ ^-?[0-9]+$ ]]; then echo "Error: Enter valid integers" exit 1 fi echo "1. Addition" echo "2. Subtraction" echo "3. Multiplication" echo "4. Division" read -p "Choose an operation: " choice case "$choice" in 1) echo "Result = $((a + b))" ;; 2) echo "Result = $((a - b))" ;; 3) echo "Result = $((a * b))" ;; 4) if (( b == 0 )); then echo "Error: Division by zero" exit 1 fi echo "Result = $((a / b))" ;; *) echo "Invalid choice" exit 1 ;; esac

Output

Enter first number: 20
Enter second number: 5
1. Addition
2. Subtraction
3. Multiplication
4. Division
Choose an operation: 3
Result = 100
Bash integer division discards the fractional part. For decimal calculations, use a utility such as bc when installed.

7. Program: Calculate Factorial

Objective: Calculate the factorial of a non-negative integer using a loop.

Program

#!/bin/bash read -p "Enter a non-negative integer: " number if [[ ! "$number" =~ ^[0-9]+$ ]]; then echo "Error: Enter a non-negative integer" exit 1 fi if (( number > 20 )); then echo "Error: Enter a number between 0 and 20" exit 1 fi factorial=1 for (( i=1; i<=number; i++ )) do factorial=$((factorial * i)) done echo "Factorial of $number = $factorial"

Output

Enter a non-negative integer: 5
Factorial of 5 = 120
Factorial is calculated as:

5! = 5 × 4 × 3 × 2 × 1 = 120

The factorial of 0 is 1. The program limits input to 20 so the result fits in Bash's usual signed 64-bit integer arithmetic.

9. Program: Check Prime Number

Objective: Determine whether a non-negative integer is a prime number.

Program

#!/bin/bash read -p "Enter a non-negative integer: " number if [[ ! "$number" =~ ^[0-9]+$ ]]; then echo "Error: Enter a non-negative integer" exit 1 fi if (( number < 2 )); then echo "$number is not a prime number" exit 0 fi is_prime=1 for (( i=2; i*i<=number; i++ )) do if (( number % i == 0 )); then is_prime=0 break fi done if (( is_prime == 1 )); then echo "$number is a prime number" else echo "$number is not a prime number" fi

Output 1

Enter a non-negative integer: 13
13 is a prime number

Output 2

Enter a non-negative integer: 12
12 is not a prime number
A prime number has exactly two positive factors: 1 and itself. The program checks divisors up to the square root of the number.

10. Program: Reverse a String

Objective: Reverse a string using a Bash loop.

Program

#!/bin/bash read -r -p "Enter a string: " text reverse="" for (( i=${#text}-1; i>=0; i-- )) do reverse+="${text:i:1}" done echo "Original String: $text" echo "Reversed String: $reverse"

Output

Enter a string: Linux
Original String: Linux
Reversed String: xuniL
This character-by-character example is intended for basic ASCII text. Bash string indexing does not reliably reverse arbitrary multi-byte Unicode text as individual user-perceived characters.

12. Program: Find the Sum of Array Elements

Objective: Store numbers in an array and calculate their total.

Program

#!/bin/bash numbers=(10 20 30 40 50) sum=0 for number in "${numbers[@]}" do sum=$((sum + number)) done echo "Array Elements: ${numbers[*]}" echo "Sum = $sum"

Output

Sum = 150

13. Program: Display Command-Line Arguments

Objective: Accept values from the command line and display them.

Program

#!/bin/bash echo "Script Name: $0" echo "First Argument: ${1-}" echo "Second Argument: ${2-}" echo "Total Arguments: $#" echo "All Arguments:" for argument in "$@" do echo "$argument" done

Execute the Script

bash arguments.sh Linux Embedded Systems

Output

Script Name: arguments.sh
First Argument: Linux
Second Argument: Embedded
Total Arguments: 3
All Arguments:
Linux
Embedded
Systems
  • $0 represents the script name.
  • $1 represents the first argument.
  • $# represents the number of arguments.
  • "$@" expands to all arguments as separate words.

16. Program: Read a File Line by Line

Objective: Read and display each line from a text file.

First Create a File

nano students.txt

Enter the following data:

Aman Rohit Navdeep Rahul

Bash Program

#!/bin/bash filename="students.txt" if [[ ! -f "$filename" ]]; then echo "Error: File not found" exit 1 fi while IFS= read -r line || [[ -n "$line" ]] do echo "Student: $line" done < "$filename"

Output

Student: Aman
Student: Rohit
Student: Navdeep
Student: Rahul
IFS= read -r reads each line without trimming leading or trailing whitespace or interpreting backslashes. The final condition also handles a last line that does not end with a newline character.

17. Program: Backup a Directory

Objective: Create a compressed archive of a directory.

Program

#!/bin/bash source_dir="Linux" backup_file="Linux_backup.tar.gz" if [[ ! -d "$source_dir" ]]; then echo "Error: Source directory not found" exit 1 fi if tar -czf "$backup_file" "$source_dir"; then echo "Backup created successfully: $backup_file" else echo "Error: Backup creation failed" exit 1 fi

Output

Backup created successfully: Linux_backup.tar.gz

The output is shown when the source directory exists and the archive command succeeds.

tar -czf creates a gzip-compressed tar archive. Check available disk space and ensure that the destination is writable.

18. Program: System Information Report

Objective: Display basic system information and save it to a report file.

Program

#!/bin/bash report="system_report.txt" { echo "SYSTEM INFORMATION REPORT" echo "-------------------------" echo "Date: $(date)" echo "Hostname: $(hostname)" echo "Current User: $USER" echo "Kernel Information:" uname -a echo echo "Disk Usage:" df -h / } > "$report" if [[ $? -eq 0 ]]; then echo "Report created: $report" else echo "Error: Report creation failed" exit 1 fi

Output

Report created: system_report.txt

The report contains system details that depend on the Ubuntu environment.

The redirection creates or truncates the report file before the commands inside the group execute. In more advanced scripts, check each important command individually when complete failure detection is required.

20. Program: Simple Log File with Timestamp

Objective: Append messages with timestamps to a log file.

Program

#!/bin/bash log_file="activity.log" write_log() { local message="$1" printf '[%s] %s\n' "$(date '+%Y-%m-%d %H:%M:%S')" "$message" >> "$log_file" } write_log "Script started" write_log "System check completed" write_log "Script finished" echo "Log entries added to $log_file"

Possible Log Contents

[2026-11-05 10:00:00] Script started
[2026-11-05 10:00:01] System check completed
[2026-11-05 10:00:02] Script finished

The timestamp values above are illustrative. Actual timestamps are generated when the script runs.

22. Best Practices for Shell Scripting

  • Always start Bash scripts with #!/bin/bash when Bash is the intended interpreter.
  • Use meaningful variable and function names.
  • Quote variables when handling filenames and text.
  • Validate user input before processing it.
  • Check important commands for failure.
  • Use functions to avoid repeated code.
  • Use comments to explain complex operations.
  • Use appropriate exit statuses.
  • Use safe file-handling practices.
  • Test scripts with normal, invalid and boundary inputs.
  • Use ShellCheck to identify common shell scripting problems.
Avoid using rm -rf with unchecked variables or user-supplied paths. Validate paths carefully before performing destructive file operations.

23. Debugging Shell Scripts

Bash provides options that help identify problems during script execution.

Command Purpose
bash -n script.sh Checks syntax without executing the script.
bash -x script.sh Displays commands as Bash executes them.
shellcheck script.sh Checks for common shell scripting issues, if ShellCheck is installed.

Example

bash -n hello.sh bash -x hello.sh
Debugging output can reveal variable values and command arguments. Avoid exposing passwords, tokens or other sensitive information when tracing scripts.

24. Interview Questions and Answers

Q1. What is a shell script?

Answer: A shell script is a text file containing commands and shell programming statements.

Q2. What is a shebang?

Answer: The first line beginning with #! identifies the interpreter used to execute a script directly.

Q3. How do you execute a shell script?

Answer: Use bash script.sh or make it executable with chmod +x and run ./script.sh.

Q4. What is the purpose of read?

Answer: It reads input from the user or another input stream and assigns it to variables.

Q5. What is a case statement?

Answer: It selects a command block based on pattern matching against a value.

Q6. What is an array in Bash?

Answer: It is a variable structure that stores multiple indexed values.

Q7. What is a function?

Answer: A function is a reusable block of commands that performs a particular task.

Q8. What is command substitution?

Answer: It captures the standard output of a command using $(command).

Q9. How do you check whether a file exists?

Answer: Use a file test such as [[ -f "$filename" ]].

Q10. What is the purpose of ShellCheck?

Answer: It is a static analysis tool that identifies common shell scripting errors and portability issues.
