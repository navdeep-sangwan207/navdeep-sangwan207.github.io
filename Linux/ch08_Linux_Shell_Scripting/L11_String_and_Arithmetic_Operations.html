String and Arithmetic Operations

Manipulating Text and Performing Calculations in Bash

1. Introduction to String Operations

A string is a sequence of characters. It can contain letters, numbers, spaces and special characters.

Bash supports string operations through variable expansion, parameter expansion and commands such as expr and printf.

Example: Declaring String Variables

#!/bin/bash name="Navdeep" course="Linux Programming" echo "$name" echo "$course"

Output

Navdeep
Linux Programming
String assignments must not contain spaces around the equals sign. Write name="Navdeep", not name = "Navdeep".

2. String Concatenation

Concatenation means joining two or more strings to create a single string.

Syntax

result="${string1}${string2}"

Example 1: Joining Two Strings

#!/bin/bash first="Hello" second="World" result="$first $second" echo "$result"

Output

Hello World

Example 2: Joining Strings Without a Space

#!/bin/bash first="Embedded" second="Systems" result="${first}${second}" echo "$result"

Output

EmbeddedSystems

Example 3: Building a Full Name

#!/bin/bash first_name="Rahul" last_name="Sharma" full_name="$first_name $last_name" echo "Full Name: $full_name"

Output

Full Name: Rahul Sharma

3. Finding String Length

Bash provides the ${#variable} expansion to calculate the length of a string.

Syntax

length=${#variable}

Example

#!/bin/bash name="Navdeep" length=${#name} echo "Name: $name" echo "Length: $length"

Output

Name: Navdeep
Length: 7
Explanation: The string "Navdeep" contains seven characters. The expression ${#name} returns the number of characters.

4. Extracting a Substring

Substring expansion extracts a portion of a string using a starting position and an optional length.

Syntax

${variable:offset:length}
  • variable: The original string.
  • offset: Starting position, beginning at zero.
  • length: Number of characters to extract (optional).

Example 1: Extract Characters

#!/bin/bash text="Linux Programming" result=${text:0:5} echo "$result"

Output

Linux

Example 2: Extract from a Specific Position

#!/bin/bash text="Embedded" result=${text:2:4} echo "$result"

Output

bedd

Example 3: Extract from the End

#!/bin/bash text="Programming" result=${text: -3} echo "$result"

Output

ing
The space before -3 is intentional. It distinguishes a negative offset from other parameter expansion syntax.

5. Replacing Text in a String

Bash parameter expansion can replace matching text within a string.

Syntax Purpose
${var/old/new} Replace the first matching occurrence.
${var//old/new} Replace all matching occurrences.

Example 1: Replace First Occurrence

#!/bin/bash text="Linux Linux Linux" result=${text/Linux/Ubuntu} echo "$result"

Output

Ubuntu Linux Linux

Example 2: Replace All Occurrences

#!/bin/bash text="Linux Linux Linux" result=${text//Linux/Ubuntu} echo "$result"

Output

Ubuntu Ubuntu Ubuntu

6. Removing Parts of a String

Bash provides parameter expansion patterns for removing matching prefixes and suffixes.

Syntax Description
${var#pattern} Remove the shortest matching prefix.
${var##pattern} Remove the longest matching prefix.
${var%pattern} Remove the shortest matching suffix.
${var%%pattern} Remove the longest matching suffix.

Example 1: Remove a Prefix

#!/bin/bash file="report_backup.txt" result=${file#*_} echo "$result"

Output

backup.txt

Example 2: Remove a File Extension

#!/bin/bash file="program.c" result=${file%.c} echo "$result"

Output

program

7. String Comparison

String comparison is used to determine whether two strings are equal or whether a string is empty.

Operator Meaning
= Strings are equal.
!= Strings are not equal.
-z String has zero length.
-n String has non-zero length.

Example 1: Compare Two Strings

#!/bin/bash password="linux123" if [ "$password" = "linux123" ]; then echo "Strings are equal" else echo "Strings are different" fi

Output

Strings are equal

Example 2: Check an Empty String

#!/bin/bash name="" if [ -z "$name" ]; then echo "String is empty" else echo "String is not empty" fi

Output

String is empty

Example 3: Check a Non-Empty String

#!/bin/bash name="Navdeep" if [ -n "$name" ]; then echo "String contains data" fi

Output

String contains data

8. Introduction to Arithmetic Operations

Arithmetic operations in Bash are used to perform mathematical calculations such as addition, subtraction, multiplication, division and modulus.

Bash supports integer arithmetic using arithmetic expansion with $(( expression )).

Syntax

result=$((expression))

Example

#!/bin/bash a=10 b=5 result=$((a + b)) echo "Result: $result"

Output

Result: 15

9. Arithmetic Operators in Bash

Operator Operation Example
+Addition10 + 5 = 15
-Subtraction10 - 5 = 5
*Multiplication10 * 5 = 50
/Integer division10 / 5 = 2
%Modulus (remainder)10 % 3 = 1
**Exponentiation2 ** 3 = 8

Example: Perform All Basic Arithmetic Operations

#!/bin/bash a=20 b=6 echo "Addition: $((a + b))" echo "Subtraction: $((a - b))" echo "Multiplication: $((a * b))" echo "Division: $((a / b))" echo "Modulus: $((a % b))" echo "Power: $((a ** 2))"

Output

Addition: 26
Subtraction: 14
Multiplication: 120
Division: 3
Modulus: 2
Power: 400
Bash integer division discards the fractional part. For example, 20 / 6 produces 3, not 3.333....

10. Increment and Decrement Operators

Increment increases an integer by one. Decrement decreases an integer by one.

Operator Meaning
((a++))Post-increment.
((++a))Pre-increment.
((a--))Post-decrement.
((--a))Pre-decrement.

Example 1: Increment

#!/bin/bash a=10 ((a++)) echo "Value: $a"

Output

Value: 11

Example 2: Decrement

#!/bin/bash a=10 ((a--)) echo "Value: $a"

Output

Value: 9

Example 3: Compound Assignment

#!/bin/bash a=10 ((a += 5)) echo "After addition: $a" ((a -= 3)) echo "After subtraction: $a" ((a *= 2)) echo "After multiplication: $a"

Output

After addition: 15
After subtraction: 12
After multiplication: 24

11. Arithmetic Using let

The let builtin evaluates arithmetic expressions and assigns the result to variables.

Syntax

let variable=expression

Example

#!/bin/bash a=15 b=5 let sum=a+b let difference=a-b echo "Sum: $sum" echo "Difference: $difference"

Output

Sum: 20
Difference: 10
Arithmetic expressions passed to let are evaluated as shell arithmetic. For clarity and readability, $((...)) is generally preferred for assigning arithmetic results.

12. Arithmetic Using expr

The expr command evaluates expressions and prints their result. Spaces between operands and operators are required.

Example 1: Addition

#!/bin/bash a=10 b=5 result=$(expr "$a" + "$b") echo "Sum: $result"

Output

Sum: 15

Example 2: Multiplication

#!/bin/bash a=10 b=5 result=$(expr "$a" \* "$b") echo "Product: $result"

Output

Product: 50
The multiplication symbol must be escaped as \* when used with expr, because an unquoted asterisk can be interpreted as a pathname wildcard by the shell.

In modern Bash scripts, arithmetic expansion is usually simpler than using expr.

13. Reading Numbers from the User

The read command accepts input from the user. The entered values can then be used in arithmetic expressions.

Example: Add Two Numbers

#!/bin/bash read -p "Enter first number: " a read -p "Enter second number: " b sum=$((a + b)) echo "Sum: $sum"

Sample Output

Enter first number: 25
Enter second number: 15
Sum: 40

Example: Calculate the Area of a Rectangle

#!/bin/bash read -p "Enter length: " length read -p "Enter width: " width area=$((length * width)) echo "Area of rectangle: $area"

Sample Output

Enter length: 10
Enter width: 5
Area of rectangle: 50

14. Floating-Point Arithmetic

Bash's built-in arithmetic supports integers, not ordinary floating-point calculations.

For decimal calculations, tools such as bc can be used.

Example 1: Decimal Addition Using bc

#!/bin/bash result=$(echo "10.5 + 5.2" | bc) echo "Result: $result"

Output

Result: 15.7

Example 2: Division with Decimal Places

#!/bin/bash result=$(echo "scale=2; 10 / 3" | bc) echo "Result: $result"

Output

Result: 3.33
Note: Install bc on Ubuntu if it is not already available:
sudo apt update sudo apt install bc
The scale setting controls the number of decimal places in division results.

15. Practical Shell Programs

Program 1: Simple Calculator

#!/bin/bash read -p "Enter first number: " a read -p "Enter second number: " b echo "1. Addition" echo "2. Subtraction" echo "3. Multiplication" echo "4. Division" read -p "Choose operation: " choice case $choice in 1) echo "Result: $((a + b))" ;; 2) echo "Result: $((a - b))" ;; 3) echo "Result: $((a * b))" ;; 4) if ((b != 0)); then echo "Result: $((a / b))" else echo "Error: Division by zero" fi ;; *) echo "Invalid choice" ;; esac

Sample Output

Enter first number: 20
Enter second number: 5
1. Addition
2. Subtraction
3. Multiplication
4. Division
Choose operation: 3
Result: 100

Program 2: Count Characters in a String

#!/bin/bash read -p "Enter a string: " text length=${#text} echo "Number of characters: $length"

Sample Output

Enter a string: Embedded Systems
Number of characters: 16

Program 3: Reverse a String

#!/bin/bash read -p "Enter a string: " text reverse="" for ((i=${#text}-1; i>=0; i--)) do reverse+="${text:i:1}" done echo "Original: $text" echo "Reversed: $reverse"

Sample Output

Enter a string: Linux
Original: Linux
Reversed: xuniL

Program 4: Calculate Simple Interest

#!/bin/bash read -p "Enter principal: " p read -p "Enter rate: " r read -p "Enter time: " t interest=$(echo "scale=2; $p * $r * $t / 100" | bc) echo "Simple Interest: $interest"

Sample Output

Enter principal: 10000
Enter rate: 5
Enter time: 2
Simple Interest: 1000.00

Program 5: Check Whether a Number Is Even or Odd

#!/bin/bash read -p "Enter an integer: " number if ((number % 2 == 0)); then echo "Even number" else echo "Odd number" fi

Sample Output

Enter an integer: 17
Odd number
These arithmetic examples expect valid integer input unless they explicitly use bc. User input should be validated before performing calculations in production scripts.

16. Important Differences

Method Purpose Typical Use
${#var} String length Count characters
${var:offset:length} Substring extraction Extract part of text
${var/old/new} String replacement Modify text
$((expression)) Integer arithmetic Calculations
let Evaluate arithmetic Update integer variables
expr Evaluate expressions Legacy arithmetic scripts
bc Decimal calculations Floating-point arithmetic

18. Interview Questions and Answers

Q1. What is a string in Bash?

Answer: A string is a sequence of characters stored in a variable.

Q2. How do you concatenate two strings?

Answer: Use variable expansion, for example result="$a$b".

Q3. How do you find the length of a string?

Answer: Use ${#variable}.

Q4. What is substring extraction?

Answer: It extracts part of a string using an offset and optionally a length.

Q5. What is the difference between ${var/old/new} and ${var//old/new}?

Answer: The first replaces the first matching occurrence; the second replaces all matching occurrences.

Q6. How is arithmetic performed in Bash?

Answer: Arithmetic can be performed using $((expression)), ((expression)) or let.

Q7. Does Bash support floating-point arithmetic directly?

Answer: Bash's built-in arithmetic is integer-based. Tools such as bc can perform decimal calculations.

Q8. What is the modulus operator?

Answer: The % operator returns the remainder after integer division.

Q9. What is the difference between ++a and a++?

Answer: Prefix increment changes the value before the expression result is used; postfix increment changes it after the current value is evaluated.

Q10. What is the purpose of expr?

Answer: It evaluates expressions and prints their results. It is an older method compared with Bash arithmetic expansion.
