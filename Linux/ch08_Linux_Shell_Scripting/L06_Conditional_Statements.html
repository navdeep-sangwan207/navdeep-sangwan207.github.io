Conditional Statements in Shell Scripting

Decision-making using if, else, comparison operators and case statements

1. Introduction to Conditional Statements

Conditional statements are decision-making structures used to execute different commands depending on whether a condition is true or false.

They help a Bash script make decisions based on:

  • Numeric values.
  • String comparisons.
  • User input.
  • File and directory properties.
  • Command exit status.
  • Multiple conditions.

Real-world example

Suppose a program checks a student's examination marks:

  • If marks are 40 or above, display Pass.
  • Otherwise, display Fail.

Conditional statements allow the script to implement this decision automatically.

2. if Statement

The if statement executes commands when a specified condition is true.

Syntax

if [ condition ] then commands fi

Here:

  • if starts the conditional statement.
  • [ condition ] evaluates the condition.
  • then begins the commands to execute when the condition succeeds.
  • fi ends the if statement.

Example: Check whether a number is positive

#!/bin/bash num=10 if [ "$num" -gt 0 ] then echo "Number is positive" fi

Run:

bash positive.sh
Expected output:
Number is positive

3. if-else Statement

The if-else statement selects one of two execution paths.

Syntax

if [ condition ] then commands_if_true else commands_if_false fi

Example: Check even or odd

#!/bin/bash read -r -p "Enter a number: " num if (( num % 2 == 0 )) then echo "Even number" else echo "Odd number" fi

Example execution:

Enter a number: 8 Even number

Another example:

Enter a number: 7 Odd number
Note: The arithmetic condition (( expression )) is a Bash arithmetic command. The examples using it assume the input is a valid integer.

4. if-elif-else Statement

The if-elif-else structure checks multiple conditions in sequence. The first successful condition determines which block executes.

Syntax

if [ condition1 ] then commands elif [ condition2 ] then commands elif [ condition3 ] then commands else commands fi

Example: Grade calculation

#!/bin/bash read -r -p "Enter marks: " marks if (( marks < 0 || marks > 100 )) then echo "Invalid marks" elif (( marks >= 90 )) then echo "Grade A" elif (( marks >= 75 )) then echo "Grade B" elif (( marks >= 60 )) then echo "Grade C" elif (( marks >= 40 )) then echo "Grade D" else echo "Fail" fi

Example execution:

Enter marks: 85 Grade B
Conditions are evaluated from top to bottom. Once a condition is true, the remaining branches are skipped.

5. Nested if Statement

A nested if statement is an if statement placed inside another if statement.

Syntax

if [ condition1 ] then if [ condition2 ] then commands else commands fi else commands fi

Example: Check positive even number

#!/bin/bash read -r -p "Enter a number: " num if (( num > 0 )) then if (( num % 2 == 0 )) then echo "Positive even number" else echo "Positive odd number" fi else echo "Number is not positive" fi

Example execution:

Enter a number: 12 Positive even number

6. Numeric Comparison Operators

Bash provides numeric comparison operators for comparing integer values inside test expressions.

Operator Meaning Equivalent
-eq Equal to ==
-ne Not equal to !=
-gt Greater than >
-lt Less than <
-ge Greater than or equal to >=
-le Less than or equal to <=

Example

#!/bin/bash a=20 b=10 if [ "$a" -gt "$b" ] then echo "A is greater than B" fi if [ "$a" -eq 20 ] then echo "A is equal to 20" fi
Expected output:
A is greater than B A is equal to 20
These -eq, -ne, -gt, -lt, -ge and -le operators are for integer comparisons, not general floating-point comparison.

7. String Comparison Operators

String comparison operators compare text values.

Operator Meaning
= or == Strings are equal.
!= Strings are not equal.
-z String length is zero.
-n String length is non-zero.

Example: Compare two strings

#!/bin/bash name1="Linux" name2="Linux" if [ "$name1" = "$name2" ] then echo "Both strings are equal" else echo "Strings are different" fi
Expected output:
Both strings are equal

Example: Check whether a string is empty

#!/bin/bash read -r -p "Enter your name: " name if [ -z "$name" ] then echo "Name is empty" else echo "Name is $name" fi

Example execution:

Enter your name: Name is empty

This example assumes the user presses Enter without entering text.

Always quote variables in string tests, such as [ "$name" = "Linux" ]. This avoids problems when the value is empty or contains spaces.

8. Logical Operators

Logical operators combine multiple conditions.

Operator Meaning
&& Logical AND – both conditions must be true.
|| Logical OR – at least one condition must be true.
! Logical NOT – reverses a condition.

Example: AND operator

#!/bin/bash age=25 if [[ "$age" -ge 18 && "$age" -le 60 ]] then echo "Age is within the specified range" fi
Expected output:
Age is within the specified range

Example: OR operator

#!/bin/bash day="Sunday" if [[ "$day" == "Saturday" || "$day" == "Sunday" ]] then echo "Weekend" else echo "Weekday" fi
Expected output:
Weekend

Example: NOT operator

#!/bin/bash file="missing.txt" if [[ ! -e "$file" ]] then echo "File does not exist" fi

Expected output:

File does not exist

The output assumes missing.txt does not exist in the current directory.

9. File-Test Operators

File-test operators check whether files and directories exist and examine their properties.

Operator Meaning
-e Path exists.
-f Regular file exists.
-d Directory exists.
-r Path is readable.
-w Path is writable.
-x Path is executable or searchable.
-s File exists and has a size greater than zero.
-L Path is a symbolic link.

Example: Check whether a file exists

#!/bin/bash read -r -p "Enter filename: " filename if [ -e "$filename" ] then echo "Path exists" else echo "Path does not exist" fi

Example: Check whether a directory exists

#!/bin/bash if [ -d "$HOME" ] then echo "Home directory exists" else echo "Home directory not found" fi

Expected output:

Home directory exists

Example: Check file permissions

#!/bin/bash file="script.sh" if [ -r "$file" ] then echo "File is readable" fi if [ -w "$file" ] then echo "File is writable" fi if [ -x "$file" ] then echo "File is executable" fi
The output depends on whether the file exists and on the current user's permissions.

10. case Statement

The case statement is used when a script needs to select one action from multiple possible choices.

Syntax

case "$variable" in pattern1) commands ;; pattern2) commands ;; *) default_commands ;; esac

Here:

  • case begins the selection statement.
  • Each pattern is matched against the variable value.
  • ) separates a pattern from its commands.
  • ;; ends a case branch.
  • * acts as a default pattern.
  • esac ends the case statement.

Example: Simple calculator menu

#!/bin/bash echo "1. Addition" echo "2. Subtraction" echo "3. Multiplication" echo "4. Division" read -r -p "Enter your choice: " choice case "$choice" in 1) echo "You selected Addition" ;; 2) echo "You selected Subtraction" ;; 3) echo "You selected Multiplication" ;; 4) echo "You selected Division" ;; *) echo "Invalid choice" ;; esac

Example execution:

1. Addition 2. Subtraction 3. Multiplication 4. Division Enter your choice: 1 You selected Addition

Example: Multiple patterns

#!/bin/bash read -r -p "Enter a character: " ch case "$ch" in [aAeEiIoOuU]) echo "Vowel" ;; [a-zA-Z]) echo "Consonant" ;; *) echo "Not an alphabet" ;; esac

Example execution:

Enter a character: A Vowel
This example expects a single alphabetic character. Bash case patterns support shell pattern matching, not full regular-expression matching.

11. Difference Between [ ] and [[ ]]

Bash supports both the [ ] test command and the [[ ]] conditional expression.

Feature [ ] [[ ]]
Type Traditional test command Bash conditional expression
Word splitting and pathname expansion Can occur if values are not quoted Not performed on words inside the expression
Logical operators Commonly use separate tests or -a and -o Supports && and || directly
Pattern matching Limited Supports pattern matching with ==

Example using [ ]

name="Linux" if [ "$name" = "Linux" ] then echo "Match found" fi

Example using [[ ]]

name="Linux" if [[ "$name" == L* ]] then echo "Name starts with L" fi
Recommendation: Use [[ ]] for Bash-specific scripts when its features are useful. Use [ ] when writing portable POSIX shell scripts.

12. Practical Lab Exercises

Lab 1: Check positive, negative or zero

Objective: Use conditional statements to classify an integer.

#!/bin/bash read -r -p "Enter a number: " num if (( num > 0 )) then echo "Positive number" elif (( num < 0 )) then echo "Negative number" else echo "Zero" fi

Example execution:

Enter a number: -5 Negative number

Lab 2: Find the largest of two numbers

Objective: Compare two integer values.

#!/bin/bash read -r -p "Enter first number: " a read -r -p "Enter second number: " b if (( a > b )) then echo "$a is larger" elif (( b > a )) then echo "$b is larger" else echo "Both numbers are equal" fi

Example execution:

Enter first number: 25 Enter second number: 40 40 is larger

Lab 3: Check file or directory

Objective: Identify whether a given path is a file or directory.

#!/bin/bash read -r -p "Enter path: " path if [ -f "$path" ] then echo "Regular file" elif [ -d "$path" ] then echo "Directory" elif [ -e "$path" ] then echo "Path exists but is not a regular file or directory" else echo "Path does not exist" fi

Lab 4: Menu-driven calculator

Objective: Perform arithmetic operations using a case statement.

#!/bin/bash read -r -p "Enter first integer: " a read -r -p "Enter second integer: " b echo "1. Addition" echo "2. Subtraction" echo "3. Multiplication" echo "4. Division" read -r -p "Enter choice: " choice case "$choice" in 1) echo "Result: $((a + b))" ;; 2) echo "Result: $((a - b))" ;; 3) echo "Result: $((a * b))" ;; 4) if (( b != 0 )) then echo "Result: $((a / b))" else echo "Error: Division by zero" fi ;; *) echo "Invalid choice" ;; esac
These arithmetic labs expect valid integer input. Bash integer arithmetic performs integer division, so a result such as 7 / 2 is 3, not 3.5.

13. Common Mistakes

Mistake Correct Approach
Forgetting spaces inside [ ]. Write [ "$a" -gt "$b" ].
Forgetting then. Use then after the condition.
Forgetting fi. Close every if statement with fi.
Using numeric operators for strings. Use string operators such as = and !=.
Using string operators for numeric comparisons. Use -eq, -gt, -lt and related operators.
Forgetting ;; in a case branch. End each ordinary case branch with ;;.
Using esac incorrectly. Use esac to close the case statement.

14. Interview Questions and Answers

Q1. What are conditional statements?

Answer: Conditional statements control program execution based on whether specified conditions are true or false.

Q2. What is the purpose of an if statement?

Answer: It executes a block of commands when its condition succeeds.

Q3. What is the difference between if and if-else?

Answer: An if statement has a true-condition branch. An if-else statement provides separate branches for true and false conditions.

Q4. What is a nested if statement?

Answer: It is an if statement placed inside another if statement.

Q5. What is the purpose of elif?

Answer: It checks additional conditions when earlier conditions are false.

Q6. What is the difference between -eq and =?

Answer: -eq compares integer values, while = compares strings inside a test expression.

Q7. What is the purpose of the case statement?

Answer: It selects and executes a matching command block from multiple patterns.

Q8. What does -f check?

Answer: It checks whether a path refers to an existing regular file.

Q9. What does -d check?

Answer: It checks whether a path refers to an existing directory.

Q10. What is the difference between [ ] and [[ ]]?

Answer: [ ] is the traditional test command, while [[ ]] is a Bash conditional expression with additional features such as pattern matching and direct logical operators.

16. Lesson Summary

  • Conditional statements implement decision-making in Bash scripts.
  • if executes commands when a condition succeeds.
  • if-else provides two execution paths.
  • elif checks additional conditions.
  • Nested if statements place one conditional inside another.
  • Numeric operators include -eq, -ne, -gt, -lt, -ge and -le.
  • String operators include =, !=, -z and -n.
  • Logical operators include &&, || and !.
  • File-test operators check file and directory properties.
  • The case statement selects commands based on pattern matching.
