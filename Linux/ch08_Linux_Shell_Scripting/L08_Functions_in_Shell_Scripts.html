Functions in Shell Scripts

Organizing Bash Scripts into Reusable Blocks of Code

Home Linux Course Chapter 8

Learning Objectives

  • Understand functions in Bash scripting.
  • Learn how to define and call functions.
  • Pass arguments to functions.
  • Understand local and global variables.
  • Learn how to return status codes from functions.
  • Create reusable shell-script programs.

1. Introduction to Functions

A function is a named block of commands that performs a particular task. Functions help divide a large shell script into smaller, reusable sections.

Instead of writing the same commands repeatedly, we can define them inside a function and call that function whenever required.

Advantages of Functions

  • Code reusability: Write once and use multiple times.
  • Modularity: Divide a large script into smaller parts.
  • Readability: Make scripts easier to understand.
  • Maintenance: Modify a task in one place.
  • Debugging: Identify problems more easily.
Example: A function named show_message can display a message whenever it is called in a script.

2. Defining a Function

Bash supports two common ways to define a function.

Method 1: Using the function name followed by parentheses

function_name() { commands }

Method 2: Using the function keyword

function function_name { commands }

Both forms are valid in Bash.

Example: Defining a Simple Function

#!/bin/bash show_message() { echo "Welcome to Linux Shell Scripting!" } show_message

Output

Welcome to Linux Shell Scripting!

Explanation:

  1. show_message() defines the function.
  2. The echo command is the function body.
  3. show_message calls the function.
Note: Define a function before calling it in a normal sequential shell script. Bash executes the commands in the order they appear.

3. Calling a Function

A function is executed by writing its name. Parentheses are not required when calling a Bash function.

Example: Calling a Function Multiple Times

#!/bin/bash greet() { echo "Hello! Welcome." } greet greet greet

Output

Hello! Welcome.
Hello! Welcome.
Hello! Welcome.

The same function is called three times without repeating its internal command.

4. Passing Arguments to Functions

Bash functions can receive arguments in the same way as shell scripts. Arguments are accessed using positional parameters.

Parameter Meaning
$1 First argument passed to the function.
$2 Second argument passed to the function.
$3 Third argument passed to the function.
$# Number of arguments passed to the function.
$@ All arguments passed to the function.
$* All arguments as a single word when quoted.

Example: Function with Two Arguments

#!/bin/bash display_name() { echo "First Name: $1" echo "Last Name: $2" } display_name Navdeep Sangwan

Output

First Name: Navdeep
Last Name: Sangwan

Here, Navdeep is received as $1 and Sangwan is received as $2.

Example: Displaying All Function Arguments

#!/bin/bash show_arguments() { echo "Number of arguments: $#" echo "All arguments:" for item in "$@" do echo "$item" done } show_arguments Linux Shell Scripting Ubuntu

Output

Number of arguments: 4
All arguments:
Linux
Shell
Scripting
Ubuntu
Important: Inside a function, positional parameters refer to the function's arguments. They are separate from the script's positional parameters. Use shift carefully if you need to change them.

5. Local and Global Variables in Functions

Global Variables

A global variable is available throughout the current shell execution environment, including inside functions, unless it is shadowed by a local variable.

#!/bin/bash name="Navdeep" show_name() { echo "Name: $name" } show_name

Output

Name: Navdeep

Local Variables

A local variable is declared using the local keyword inside a function. It is available within that function and its execution context.

#!/bin/bash show_details() { local city="Chandigarh" echo "City: $city" } show_details

Output

City: Chandigarh

Example: Local Variable Does Not Replace Global Variable

#!/bin/bash name="Global Name" show_name() { local name="Local Name" echo "Inside function: $name" } show_name echo "Outside function: $name"

Output

Inside function: Local Name
Outside function: Global Name
Explanation: The local variable name temporarily shadows the global variable with the same name inside the function. The global value remains unchanged.

6. Returning Values from Functions

Bash functions use the return statement to provide an exit status. The status is an integer from 0 to 255.

Return Status Meaning
0 Success.
Non-zero Failure or another status condition.

Example: Returning a Status Code

#!/bin/bash check_number() { if [ "$1" -gt 0 ]; then return 0 else return 1 fi } check_number 10 if [ $? -eq 0 ]; then echo "Positive number" else echo "Not a positive number" fi

Output

Positive number

The special variable $? stores the exit status of the most recently executed command or function. Therefore, check it immediately after the function call.

Important: The Bash return statement does not return an arbitrary string or a general numeric result. To produce data, use echo or another output method and capture it with command substitution.

Example: Returning a Calculated Value Using Echo

#!/bin/bash add_numbers() { local result=$(( $1 + $2 )) echo "$result" } sum=$(add_numbers 20 30) echo "Sum = $sum"

Output

Sum = 50

The function prints the calculated value. Command substitution $(...) captures that output and stores it in the variable sum.

7. Functions with Conditional Statements

Functions can contain conditional statements such as if, elif and else.

Example: Even or Odd Number

#!/bin/bash check_even_odd() { if [ $(( $1 % 2 )) -eq 0 ]; then echo "$1 is Even" else echo "$1 is Odd" fi } check_even_odd 12 check_even_odd 7

Output

12 is Even
7 is Odd

8. Functions with Loops

Loops can be used inside functions to perform repetitive tasks.

Example: Display Numbers from 1 to N

#!/bin/bash display_numbers() { local i for (( i=1; i<=$1; i++ )) do echo "$i" done } display_numbers 5

Output

1
2
3
4
5

9. Recursive Functions

A recursive function is a function that calls itself. Recursion is useful for solving problems that can be divided into smaller versions of the same problem.

Example: Factorial Using Recursion

#!/bin/bash factorial() { local n=$1 if [ "$n" -le 1 ]; then echo 1 else local previous previous=$(factorial $((n - 1))) echo $((n * previous)) fi } result=$(factorial 5) echo "Factorial = $result"

Output

Factorial = 120
Note: Recursive functions must have a base condition to stop recursion. Without it, the function may continue until the system reaches its resource limits.

10. Practical Shell Script Programs

Program 1: Addition Using a Function

#!/bin/bash addition() { local sum=$(( $1 + $2 )) echo "Addition = $sum" } addition 15 25

Output

Addition = 40

Program 2: Find the Largest of Two Numbers

#!/bin/bash find_largest() { if [ "$1" -gt "$2" ]; then echo "$1 is largest" elif [ "$2" -gt "$1" ]; then echo "$2 is largest" else echo "Both numbers are equal" fi } find_largest 45 30

Output

45 is largest

Program 3: Check Whether a File Exists

#!/bin/bash check_file() { if [ -f "$1" ]; then echo "File exists" else echo "File does not exist" fi } check_file "sample.txt"

Possible Output

File exists

The output depends on whether sample.txt exists in the current working directory.

Program 4: Simple Calculator Using Functions

#!/bin/bash add() { echo $(( $1 + $2 )) } subtract() { echo $(( $1 - $2 )) } multiply() { echo $(( $1 * $2 )) } divide() { if [ "$2" -eq 0 ]; then echo "Error: Division by zero" else echo $(( $1 / $2 )) fi } echo "Addition: $(add 20 10)" echo "Subtraction: $(subtract 20 10)" echo "Multiplication: $(multiply 20 10)" echo "Division: $(divide 20 10)"

Output

Addition: 30
Subtraction: 10
Multiplication: 200
Division: 2
Note: Bash integer arithmetic does not perform floating-point division. For example, 5 divided by 2 produces 2, not 2.5.

11. Function Scope and Important Rules

Concept Description
Function definition Creates a reusable block of commands.
Function call Executes the function by its name.
Arguments Pass information to a function.
Local variable Declared using the local keyword.
Global variable Available throughout the current shell environment.
return Sets the function's exit status.
echo Writes output that can be captured by command substitution.
Recursion A function calling itself.
Important: A function called inside command substitution, such as result=$(my_function), normally executes in a subshell. Changes to ordinary shell variables inside that function will not update the parent shell's variables.

13. Interview Questions and Answers

Q1. What is a function in Bash?

Answer: A function is a named block of commands used to perform a specific task. It improves code reusability and modularity.

Q2. How do you define a function in Bash?

Answer: A function can be defined using function_name() { commands; } or function function_name { commands; }.

Q3. How do you call a function?

Answer: Write the function name without parentheses.

Q4. How are arguments passed to a function?

Answer: Arguments are written after the function name and accessed using positional parameters such as $1, $2 and $3.

Q5. What is the purpose of the local keyword?

Answer: It declares a variable whose scope is limited to the function in which it is declared.

Q6. What does return do in a Bash function?

Answer: It sets the function's exit status, usually from 0 to 255. Zero conventionally indicates success.

Q7. How can a function produce a calculated value?

Answer: It can print the value using echo, and the caller can capture it using command substitution.

Q8. What is recursion?

Answer: Recursion occurs when a function calls itself. A base condition is required to stop it.

Q9. What is the difference between local and global variables?

Answer: A local variable is limited to its function scope, whereas a global variable is available throughout the current shell environment.

Q10. Can a Bash function call another function?

Answer: Yes. A function can call another function, provided that the called function has been defined.

14. Multiple Choice Questions (MCQs)

Q1. Which symbol is used to define a Bash function?

A. []
B. ()
C. <>
D. ##

Answer: B. ()

Q2. Which keyword declares a local variable?

A. global
B. var
C. local
D. static

Answer: C. local

Q3. Which parameter represents the first function argument?

A. $0
B. $1
C. $#
D. $@

Answer: B. $1

Q4. What does return 0 normally indicate?

A. Failure
B. Success
C. Infinite loop
D. Variable declaration

Answer: B. Success

Q5. Which variable stores the previous command's exit status?

A. $#
B. $@
C. $?
D. $$

Answer: C. $?

Q6. What is a recursive function?

A. A function that calls itself
B. A function without arguments
C. A function that only prints text
D. A function that cannot return

Answer: A. A function that calls itself

Q7. Which command can capture a function's printed output?

A. unset
B. $(function_name)
C. chmod
D. pwd

Answer: B. Command substitution

15. Lesson Summary

  • Functions are reusable blocks of Bash commands.
  • Functions are defined using a name and parentheses or the function keyword.
  • Call a function by writing its name.
  • Pass arguments using positional parameters such as $1 and $2.
  • Use local to declare function-local variables.
  • Use return to set an exit status.
  • Use echo and command substitution to capture calculated values.
  • Functions can contain conditions, loops and recursive calls.
