1. Introduction to Shell Scripting

Shell scripting is a method of writing a sequence of Linux commands in a file so that they can be executed automatically by a shell interpreter.

Instead of entering commands one by one in the terminal, a user can write multiple commands in a script file and execute them together.

Definition: A shell script is a text file containing shell commands, instructions, and optional programming constructs that are interpreted and executed by a shell.

Example: Manual Command Execution

Suppose you want to perform these operations in Linux:

pwd date whoami ls

You normally type each command separately into the terminal. If you need to perform these operations repeatedly, you can save them in a shell script.

Example: Using a Shell Script

#!/bin/bash pwd date whoami ls

The commands are stored in a single file and executed together when the script runs.

2. What Is a Shell?

A shell is a command-line interpreter that provides an interface between the user and the operating system. It accepts commands, interprets them, and requests the operating system to perform the required operations.

Basic Working of a Shell

User | v Shell (Command Interpreter) | v Operating System / Kernel | v System Resources

For example, when you enter:

ls

The shell processes the command, runs the appropriate program, and displays the directory contents.

Functions of a Shell

  • Accepts commands from the user.
  • Interprets and executes commands.
  • Supports variables and command substitution.
  • Provides input and output redirection.
  • Supports pipelines between commands.
  • Provides programming features such as conditions and loops.
  • Allows automation through shell scripts.

3. Shell vs Shell Scripting

Shell Shell Scripting
A command interpreter. A method of writing instructions in a script file.
Commands are commonly entered interactively. Commands are stored in a file for execution.
Used for direct interaction with Linux. Used for automation and repetitive tasks.
Example: Entering ls in a terminal. Example: Saving ls inside a Bash script.
Remember: The shell is the interpreter. Shell scripting is the technique of using that interpreter to execute instructions stored in a script.

4. Types of Linux Shells

Linux supports different shells. Each shell provides a command-line environment with its own features and syntax.

Shell Name Description
sh Bourne Shell A traditional Unix shell and a common scripting portability target.
bash Bourne Again Shell A widely used Linux shell with scripting features and command-line editing.
csh C Shell A shell with syntax influenced by the C programming language.
ksh Korn Shell A Unix shell with scripting and interactive features.
zsh Z Shell An advanced shell with powerful completion and customization features.
fish Friendly Interactive Shell A user-friendly shell with interactive features and its own scripting syntax.
Important: This chapter primarily uses Bash scripting. Bash scripts should be executed using Bash when they contain Bash-specific syntax.

5. Introduction to Bash

Bash stands for Bourne Again Shell. It is a widely used command-line shell and scripting language in Linux systems.

Bash is based on the traditional Bourne shell and provides additional features for interactive command execution and automation.

Important Bash Features

  • Variables and environment variables.
  • Conditional statements such as if and case.
  • Loops such as for, while and until.
  • Functions and arrays.
  • Command-line argument handling.
  • Input and output redirection.
  • Pipelines and command substitution.
  • Error handling and exit status checking.

Check the Installed Bash Version

bash --version

Check the Current Shell

echo "$SHELL"
Example output:
/bin/bash

This commonly indicates that Bash is configured as the user's login shell. It does not necessarily identify the shell currently executing the command.

Check the Current Shell Process

ps -p $$ -o comm=

This command displays the command name of the process associated with the current shell's process ID.

6. What Is a Shell Script File?

A shell script is normally stored as a plain-text file. The file commonly uses the .sh extension, although Bash does not require this extension.

Example Filename

first_script.sh

Common Components of a Shell Script

  1. Shebang: Identifies the interpreter when the script is executed directly.
  2. Comments: Explain the purpose of the script.
  3. Commands: Perform operations in Linux.
  4. Variables: Store values for later use.
  5. Control statements: Control program execution.

Example Script Structure

#!/bin/bash # This is a sample shell script echo "Welcome to Linux Shell Scripting" date pwd

7. Understanding the Shebang (#!)

The shebang is a special character sequence written at the beginning of a script file. It starts with:

#!

It tells the operating system which interpreter should execute the script when the file is launched directly.

Example

#!/bin/bash

This specifies Bash as the interpreter.

Other Shebang Examples

#!/bin/sh #!/usr/bin/python3 #!/usr/bin/env bash
Shebang Purpose
#!/bin/bash Uses Bash at the specified path.
#!/bin/sh Uses the shell available at /bin/sh.
#!/usr/bin/env bash Uses env to locate Bash through the PATH environment variable.
Important: A shebang is interpreted when the script is executed directly. If you explicitly run bash script.sh, Bash executes the file, regardless of its shebang line.

8. Basic Structure of a Bash Script

Consider the following simple Bash script:

#!/bin/bash # Display a welcome message echo "Welcome to NS Learning Hub" # Display the current user whoami # Display the current date date # Display the current directory pwd

Explanation

Statement Purpose
#!/bin/bash Specifies Bash as the interpreter for direct execution.
# comment Provides information; it is not executed as a command.
echo Displays text or values.
whoami Displays the effective username.
date Displays the system date and time.
pwd Displays the current working directory.

9. How a Shell Script Works

A shell script is processed by an interpreter. The interpreter reads the script and executes its commands.

Execution Flow

Create a shell script | v Write shell commands | v Save the script file | v Select an interpreter | v Execute the script | v Commands are processed | v Display results

Example

#!/bin/bash echo "Step 1" echo "Step 2" echo "Step 3"
Output:
Step 1 Step 2 Step 3

The commands execute in sequence unless control-flow statements, errors, or explicit termination change the normal execution path.

10. Why Is Shell Scripting Used?

Shell scripting is useful when the same set of commands must be executed repeatedly or when multiple operations need to be performed automatically.

Major Applications

  • Task automation: Automating repetitive Linux commands.
  • File management: Creating, copying, moving and deleting files.
  • System administration: Managing users, processes and system resources.
  • Log management: Searching and processing system log files.
  • Backup operations: Automating backup and archiving tasks.
  • Software development: Automating builds, tests and development workflows.
  • Embedded Linux: Automating startup tasks and system operations.
  • Monitoring: Checking disk space, memory usage and running processes.

11. Advantages and Limitations

Advantages

  • Reduces repetitive manual work.
  • Combines multiple commands into one script.
  • Easy to create and modify using text editors.
  • Useful for system administration and automation.
  • Supports variables, conditions, loops and functions.
  • Integrates with existing Linux command-line utilities.

Limitations

  • Generally slower than compiled programs for computation-intensive tasks.
  • Complex scripts can become difficult to maintain.
  • Shell syntax and behavior can differ between shells.
  • Scripts may require modification when moved between different environments.
  • Incorrect command handling can cause unintended system changes.
Engineering perspective: Shell scripting is especially useful for automation and system-level operations. For complex algorithms, performance-critical applications and embedded firmware, languages such as C and C++ are generally more suitable.

12. Practical Lab 1: Create Your First Shell Script

Objective: Create and execute a basic Bash script in Ubuntu Linux.

Step 1: Open the Terminal

Use the Ubuntu terminal.

Step 2: Create a Script File

nano first_script.sh

Step 3: Write the Following Code

#!/bin/bash echo "Welcome to NS Learning Hub" echo "Learning Linux Shell Scripting" echo "My first Bash script" date whoami pwd

Step 4: Save the File

In Nano, press Ctrl + O, then Enter to save. Press Ctrl + X to exit.

Step 5: Give Execute Permission

chmod +x first_script.sh

Step 6: Execute the Script

./first_script.sh
Expected output (date, username and directory will vary):
Welcome to NS Learning Hub Learning Linux Shell Scripting My first Bash script [Current date and time] [Current username] [Current working directory]

Alternative Execution Method

bash first_script.sh

This method runs the script using Bash without requiring execute permission on the script file.

Observation: Both execution methods can run this Bash script. Direct execution uses the shebang to select the interpreter, while the second method explicitly invokes Bash.

15. Interview Questions and Answers

Q1. What is shell scripting?

Shell scripting is the process of writing shell commands in a file and executing them through a shell interpreter to automate tasks.

Q2. What is a shell?

A shell is a command-line interpreter that accepts commands and provides an interface between the user and the operating system.

Q3. What is Bash?

Bash stands for Bourne Again Shell. It is a widely used Linux shell that supports interactive command execution and shell scripting.

Q4. What is the purpose of the shebang?

The shebang specifies the interpreter used when a script is executed directly, for example, #!/bin/bash.

Q5. Is the .sh extension compulsory?

No. It is a common naming convention, but Bash does not require a particular file extension.

Q6. How do you execute a shell script?

A script can be executed using bash script.sh or, after granting execute permission, using ./script.sh.

Q7. What is the difference between Bash and sh?

Bash is an extended shell with additional features. The name sh commonly refers to a traditional Bourne-style shell or a system-provided shell interface. On Ubuntu, /bin/sh is commonly linked to dash rather than Bash.

Q8. Can shell scripts execute Linux commands?

Yes. Shell scripts can execute external Linux commands and use shell built-ins such as echo, cd and read.

Q9. Why is shell scripting important for system administrators?

It helps automate system maintenance, file operations, backups, monitoring and other repetitive tasks.

Q10. Is shell scripting useful in Embedded Linux?

Yes. It is used for startup automation, system configuration, service management, testing and other system-level tasks.
