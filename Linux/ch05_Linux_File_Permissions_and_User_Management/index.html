Chapter 5: Linux File Permissions and User Management

Understanding Access Control, Permissions, Users and Groups in Linux

Chapter Overview

Linux is a multi-user operating system that provides a permission-based security mechanism to control access to files and directories. File permissions determine which users can read, write or execute files and directories.

In this chapter, you will learn about Linux users and groups, file permissions, read-write-execute permissions, the chmod command, ownership management using chown and chgrp, umask, sudo, the root user, and user and group administration commands.
