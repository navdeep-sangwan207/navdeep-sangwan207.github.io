1. Introduction to User Management

Linux is a multi-user operating system. It allows multiple users to access the same system while maintaining separate accounts and permissions.

User management is the process of creating, modifying, deleting and maintaining user accounts in a Linux operating system.

Why Is User Management Important?

  • Provides individual login accounts.
  • Controls access to files and directories.
  • Protects system resources.
  • Allows administrators to assign privileges.
  • Supports multi-user environments.
Every Linux user account has a unique user ID (UID). Groups provide a convenient way to manage permissions for multiple users.

2. Important User Management Files

Linux stores user and group account information in several system configuration files.

File Purpose
/etc/passwd Stores user account information.
/etc/shadow Stores protected password information and password-aging data.
/etc/group Stores group account information.
/etc/gshadow Stores protected group administration information.

View User Information

cat /etc/passwd

View Group Information

cat /etc/group
Avoid displaying or sharing /etc/shadow and /etc/gshadow contents unnecessarily. These files contain protected security information.

3. Creating a New User

The useradd command creates a new user account.

Syntax

sudo useradd [OPTIONS] USERNAME

Example 1: Create a User

sudo useradd student1

This creates a user account named student1. Depending on the system configuration, a home directory may not be created automatically.

Example 2: Create a User with a Home Directory

sudo useradd -m student1

The -m option creates the user's home directory if it does not already exist.

Example 3: Specify a Login Shell

sudo useradd -m -s /bin/bash student2

This creates student2 with a home directory and Bash as the login shell.

Example 4: Specify a Home Directory

sudo useradd -m -d /home/projectuser projectuser

The -d option specifies the home directory path.

Ubuntu also provides the interactive adduser command, which guides administrators through account creation.

4. Setting a User Password

The passwd command is used to set or change user passwords.

Syntax

sudo passwd USERNAME

Example

sudo passwd student1

The system prompts the administrator to enter and confirm a new password for student1.

Change Your Own Password

passwd

Check Password Status

sudo passwd -S student1

Displays password status information for the specified account.

Never store passwords in plain-text files or share them with unauthorized users.

5. Modifying an Existing User

The usermod command is used to modify an existing user account.

Syntax

sudo usermod [OPTIONS] USERNAME

1. Change the Username

sudo usermod -l newname oldname

Changes the login name from oldname to newname.

2. Change the Home Directory

sudo usermod -d /home/newhome -m student1

Changes the home directory path and moves the contents of the previous home directory to the new location.

3. Change the Login Shell

sudo usermod -s /bin/bash student1

Sets Bash as the login shell.

4. Add a User to a Supplementary Group

sudo usermod -aG developers student1

Adds student1 to the developers group.

5. Lock a User Account

sudo usermod -L student1

Locks the account password by adding a lock marker to the password field.

6. Unlock a User Account

sudo usermod -U student1

Unlocks the account password, subject to other account restrictions.

The -a option must be used with -G when adding supplementary groups. Omitting -a can replace the existing supplementary group list.

6. Deleting a User Account

The userdel command deletes a user account.

Syntax

sudo userdel USERNAME

Example 1: Delete a User

sudo userdel student1

Removes the account entry. The user's home directory and other files are not automatically removed by this command.

Example 2: Delete a User and Home Directory

sudo userdel -r student1

The -r option also removes the user's home directory and mail spool when applicable.

Deleting a user with -r is potentially destructive. Back up required data and verify the username before executing it. Files owned by the user outside the home directory may remain.

7. Creating a Group

The groupadd command creates a new group.

Syntax

sudo groupadd GROUPNAME

Example

sudo groupadd developers

Creates a group named developers.

Specify a Group ID

sudo groupadd -g 2001 developers

The -g option specifies the group's GID.

Verify the Group

getent group developers
Example output:
developers:x:2001:

The exact GID depends on the system and whether the requested ID is available.

8. Adding Users to Groups

A user can belong to a primary group and multiple supplementary groups.

Add a User to a Supplementary Group

sudo usermod -aG developers student1

Adds student1 to the developers group without removing existing supplementary group memberships.

Alternative: gpasswd

sudo gpasswd -a student1 developers

Adds student1 to the developers group.

Verify Group Membership

groups student1 id student1
A user may need to log out and log in again for a new group membership to be reflected in a newly created login session.

9. Removing Users from Groups

The gpasswd -d command removes a user from a supplementary group.

Syntax

sudo gpasswd -d USERNAME GROUPNAME

Example

sudo gpasswd -d student1 developers

Removes student1 from the developers group.

Verify the Change

groups student1
Removing a user from a group does not automatically terminate existing processes or sessions that already have that group's credentials.

10. Deleting a Group

The groupdel command deletes a group.

Syntax

sudo groupdel GROUPNAME

Example

sudo groupdel developers

Deletes the developers group if the system permits the operation.

A group generally cannot be deleted while it is the primary group of an existing user. Check group memberships before deleting it.

11. Important User Management Commands

Command Purpose
useradd Create a user account.
adduser Interactive user creation utility on Ubuntu.
usermod Modify an existing user account.
userdel Delete a user account.
passwd Set or change a password.
groupadd Create a group.
groupmod Modify a group.

gpasswd Administer group membership and passwords.
groups Display group memberships.
id Display UID, GID and group information.
getent Retrieve account information from configured databases.

12. Modifying a Group

The groupmod command is used to modify group information.

Change Group Name

sudo groupmod -n newgroup oldgroup

Change Group ID

sudo groupmod -g 3001 developers

Changes the GID of the developers group to 3001, provided the ID is available.

Changing a group's GID does not necessarily update ownership metadata on existing files. Review affected files and permissions after a GID change.

13. Checking User Account Information

1. Display Current Username

whoami

2. Display UID and GID

id

3. Display Information for a Specific User

id student1

4. Display User's Groups

groups student1

5. Search for a User in the Account Database

getent passwd student1

6. Search for a Group

getent group developers

7. Display User Login Information

who w

These commands provide information about logged-in users and their sessions.

14. Account Locking and Expiration

Lock a User Password

sudo passwd -l student1

Unlock a User Password

sudo passwd -u student1

Set Account Expiration Date

sudo usermod -e 2027-12-31 student1

Sets an account expiration date. The date is an example and should be replaced with the required date.

Display Account Expiration Information

sudo chage -l student1

Set Password Aging Information

sudo chage -M 90 student1

Sets the maximum password age to 90 days.

Locking a password is not the same as disabling every possible login method. SSH keys, other authentication mechanisms and account policies may need separate consideration.

15. Practical Lab: Complete User and Group Management

Objective: Create a user and group, assign group membership, verify account information, and remove the test accounts safely.

Step 1: Create a Group

sudo groupadd labgroup

Step 2: Create a User with a Home Directory

sudo useradd -m -s /bin/bash labuser

Step 3: Set the User Password

sudo passwd labuser

Enter and confirm a password when prompted.

Step 4: Add the User to the Group

sudo usermod -aG labgroup labuser

Step 5: Verify the User

id labuser

Step 6: Verify Group Membership

groups labuser
Expected observation: labuser should appear as a member of labgroup. UID and GID values will depend on your system.

Step 7: Verify the Home Directory

ls -ld /home/labuser

Step 8: Display User Database Entry

getent passwd labuser

Step 9: Remove the User

sudo userdel -r labuser

Step 10: Remove the Group

sudo groupdel labgroup

Step 11: Verify Removal

getent passwd labuser getent group labgroup
Expected observation: No matching account entries should be returned after successful removal.
Perform this lab with test account names only. Never delete your own active account or an important system account. Check every command before pressing Enter.

16. Common Errors and Troubleshooting

1. Permission Denied

User management commands generally require administrative privileges.

sudo useradd username

2. User Already Exists

Check whether the username is already present.

getent passwd username

3. Group Already Exists

Verify the group before creating it again.

getent group groupname

4. User Is Not Added to the Expected Group

Verify the supplementary group list.

id username groups username

5. Existing Group Membership Was Lost

When using usermod -G, omitting -a can replace the existing supplementary groups. Use the following form to append a group:

sudo usermod -aG groupname username

17. Interview Questions and Answers

Q1. What is user management in Linux?

It is the process of creating, modifying, deleting and maintaining user accounts.

Q2. Which command creates a user?

useradd.

Q3. Which command modifies a user?

usermod.

Q4. Which command deletes a user?

userdel.

Q5. Which command creates a group?

groupadd.

Q6. Which command deletes a group?

groupdel.

Q7. What is the difference between a primary and supplementary group?

A primary group is the user's main group association, while supplementary groups provide additional group memberships and associated access rights.

Q8. Which file stores user account information?

/etc/passwd.

Q9. Which file stores protected password information?

/etc/shadow.

Q10. What does usermod -aG do?

It appends the specified supplementary group to the user's existing group list.

Q11. Which command displays a user's UID and GID?

id username.

Q12. Which command changes a user's password?

passwd.

Q13. What does userdel -r do?

Deletes the user account and also removes the user's home directory and mail spool when applicable.

Q14. What is the purpose of groupmod?

It modifies group information, such as its name or GID.

Q15. What is the purpose of getent?

It retrieves account information from configured system databases.
