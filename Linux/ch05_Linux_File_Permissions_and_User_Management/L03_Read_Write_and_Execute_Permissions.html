LINUX PROGRAMMING • CHAPTER 5 • LESSON 3

Read, Write and Execute Permissions

Understanding Permission Symbols, Numeric Values and Access Rules

Home Linux Course Chapter 5

Learning Objectives

After completing this lesson, you will be able to:

  • Understand read, write and execute permissions in detail.
  • Explain file permissions and directory permissions separately.
  • Understand symbolic and numeric permission values.
  • Calculate permission values using binary and octal notation.
  • Interpret common permission combinations.
  • Understand how directory permissions affect file operations.
  • Identify permission-related errors in Linux.

1. Introduction

Linux uses three basic permissions to control access to files and directories:

  • Read (r): Allows reading information.
  • Write (w): Allows modifying information.
  • Execute (x): Allows execution of a file or traversal of a directory.

Each permission can be assigned independently to the owner, group and others.

A permission string contains nine basic permission characters, divided into three groups of three: owner, group and others.

2. Read Permission (r)

Read permission allows a user to view or read the contents of a regular file.

Property Value
Symbol r
Numeric value 4
Binary value 100

Example

cat notes.txt

If the current process has read permission on notes.txt, the file contents can be displayed.

Read Permission on a Directory

Read permission on a directory allows a user to list the names of entries inside that directory.

ls project
Read permission on a directory does not by itself guarantee that the user can access or inspect the contents of every listed entry. Directory execute permission is generally also needed for traversal.

3. Write Permission (w)

Write permission allows a user to modify the contents of a regular file.

Property Value
Symbol w
Numeric value 2
Binary value 010

Example

echo "Linux Operating System" >> notes.txt

This command appends text to the file when the process has the necessary write permission.

Write Permission on a Directory

Write permission on a directory allows a user to create, delete or rename directory entries, provided the required directory search permission and other restrictions are satisfied.

touch project/newfile.txt rm project/oldfile.txt
Important: Deleting a file is generally controlled by permissions on its parent directory, not simply by write permission on the file itself. Sticky-bit rules and other restrictions can also apply.

4. Execute Permission (x)

Execute permission allows a user to execute a regular file as a program or script, when the file format and execution environment permit it.

Property Value
Symbol x
Numeric value 1
Binary value 001

Example

./script.sh

The script can be executed directly if it has execute permission, a valid interpreter declaration or executable format, and the required access.

Execute Permission on a Directory

Execute permission on a directory is also called search or traversal permission.

It allows a user to:

  • Access entries by name inside the directory.
  • Traverse the directory as part of a path.
  • Access files when the other required permissions are available.
cd project ls -l project/notes.txt
Directory execute permission does not mean that the directory itself is executed like a program. It means that the directory can be searched or traversed.

5. Permission Values in Linux

Linux represents the three basic permissions using numeric values.

Permission Symbol Numeric Value Binary Value
Read r 4 100
Write w 2 010
Execute x 1 001
No permission - 0 000

How Numeric Values Work

The numeric permission value for one category is calculated by adding the values of its enabled permissions.

Example: Read + Write = 4 + 2 = 6
Permissions Calculation Numeric Value
--- 0 0
--x 1 1
-w- 2 2
-wx 2 + 1 3
r-- 4 4
r-x 4 + 1 5
rw- 4 + 2 6
rwx 4 + 2 + 1 7

6. Understanding Octal Permission Notation

Linux commonly represents permissions using three octal digits. Each digit describes the permissions for one category.

chmod 754 filename

The three digits represent:

7 5 4 Owner Group Others
Category Value Calculation Permission
Owner 7 4 + 2 + 1 rwx
Group 5 4 + 1 r-x
Others 4 4 r--
Result:
754 = rwxr-xr--
The owner can read, write and execute. The group can read and execute. Others can read only.

Another Example: 644

6 = 4 + 2 = rw- 4 = 4 = r-- 4 = 4 = r-- 644 = rw-r--r--

This is a common permission setting for regular files that should be writable by their owner and readable by the group and others.

7. Common Permission Combinations

Numeric Symbolic Meaning
777 rwxrwxrwx All categories have all three permissions.
755 rwxr-xr-x Owner has full permissions; group and others can read and execute.
700 rwx------ Only the owner has permissions.
644 rw-r--r-- Owner can read and write; group and others can read.
600 rw------- Only the owner can read and write.
444 r--r--r-- All categories can read only.
000 ---------- No basic permissions are granted to these categories.
Security Note: Permission 777 grants read, write and execute permissions to everyone in the basic permission model. Avoid using it unnecessarily, especially on important system files and directories.

8. Binary Representation of Permissions

Each permission category uses three bits. The bits represent read, write and execute.

Read = 100 Write = 010 Execute = 001

When permissions are combined, the binary bits are added positionally.

Example: rwx

Read Write Execute 1 1 1 Binary: 111 Octal: 7

Example: r-x

Read Write Execute 1 0 1 Binary: 101 Octal: 5

Example: rw-

Read Write Execute 1 1 0 Binary: 110 Octal: 6
Three permission bits form one binary digit group. Each group corresponds to one octal digit from 0 through 7.

9. Permission-Related Errors

1. Permission Denied

cat private.txt
cat: private.txt: Permission denied

This error occurs when the process does not have the required access permission or another security restriction prevents access.

2. Cannot Execute a Script

./script.sh

If execute permission is missing, the shell may report a permission-related error.

3. Cannot Access a Directory

cd restricted_directory

Directory traversal requires execute permission on the directory and on relevant parent directories.

10. Practical Lab: Understand Permission Values

Objective: To inspect permission values and understand the relationship between symbolic and numeric notation.

Step 1: Create a Lab Directory

mkdir permission_practice cd permission_practice

Step 2: Create a File

touch sample.txt

Step 3: Inspect Default Permissions

ls -l sample.txt stat sample.txt

Step 4: Set Permission 644

chmod 644 sample.txt

Step 5: Verify Permissions

ls -l sample.txt
Expected permission string:
-rw-r--r--

Step 6: Set Permission 600

chmod 600 sample.txt

Step 7: Verify Again

stat sample.txt
Expected permission mode:
600 / -rw-------

Step 8: Create a Script

echo '#!/bin/bash' > test.sh echo 'echo Linux Permissions' >> test.sh

Step 9: Inspect Script Permissions

ls -l test.sh

Step 10: Run the Script Through Bash

bash test.sh
Expected Output:
Linux Permissions

Running a script using bash test.sh invokes Bash to read the script. Direct execution using ./test.sh additionally requires execute permission on the script and directory traversal permissions.

Step 11: Add Execute Permission

chmod 755 test.sh

Step 12: Execute the Script Directly

./test.sh
Expected Output:
Linux Permissions

11. Interview Questions and Answers

Q1. What are the three basic Linux permissions?

Read, write and execute.

Q2. What is the numeric value of read permission?

4.

Q3. What is the numeric value of write permission?

2.

Q4. What is the numeric value of execute permission?

1.

Q5. What does permission 755 mean?

The owner has read, write and execute permissions. Group and others have read and execute permissions.

Q6. What does permission 644 mean?

The owner can read and write. Group and others can read only.

Q7. What is the difference between file and directory execute permission?

For a regular file, execute permission allows execution when applicable. For a directory, it allows search and traversal.

Q8. What does permission 600 mean?

The owner can read and write. Group and others have no basic permissions.

Q9. What is the octal value of rwxr-xr--?

754.

Q10. Can a file be deleted if it is not writable?

Yes. Deletion generally depends on permissions on the parent directory, not write permission on the file itself. Additional restrictions may apply.

13. Lesson Summary

  • Read permission is represented by r and has numeric value 4.
  • Write permission is represented by w and has numeric value 2.
  • Execute permission is represented by x and has numeric value 1.
  • Directory read permission allows listing directory entries.
  • Directory write permission allows changing directory entries, subject to other rules.
  • Directory execute permission allows traversal and searching.
  • Three octal digits represent owner, group and others.
  • Permission 755 represents rwxr-xr-x.
  • Permission 644 represents rw-r--r--.
  • Permission 600 represents rw-------.
  • Binary permission bits can be converted into octal values.
Key Concept to Remember: Read = 4, Write = 2 and Execute = 1. Add the values for each permission category to calculate its octal digit.
