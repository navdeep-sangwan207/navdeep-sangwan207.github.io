chown and chgrp Commands

Managing File and Directory Ownership in Linux

Home Linux Course Chapter 5

Learning Objectives

After completing this lesson, you will be able to:

  • Understand file ownership in Linux.
  • Identify the owner and group of a file.
  • Use the chown command to change ownership.
  • Use the chgrp command to change group ownership.
  • Change both owner and group using chown.
  • Apply ownership changes recursively.
  • Verify ownership using ls -l and stat.
  • Understand the permissions required to change ownership.

1. Introduction to File Ownership

Every Linux file and directory has an associated owner and group. These ownership details are used by the Linux permission system to determine access.

The owner identifies the user account associated with the file. The group identifies the group associated with that file.

Example

-rw-r--r-- 1 navdeep developers 1200 Nov 5 10:30 notes.txt
Information Value
File name notes.txt
Owner navdeep
Group developers
Permissions rw-r--r--
The owner and group are separate from the permission bits. Changing ownership does not automatically assign a new permission mode.

2. Viewing File Ownership

Before changing ownership, you should inspect the current owner and group of the file.

Using ls -l

ls -l notes.txt
Example Output:
-rw-r--r-- 1 navdeep developers 1200 Nov 5 10:30 notes.txt

Here, navdeep is the owner and developers is the group.

Using stat

stat notes.txt

The stat command displays detailed metadata, including numeric user ID (UID), group ID (GID), and their corresponding account names when available.

Checking the Current User

whoami

Checking User and Group IDs

id
Linux stores ownership using numeric UID and GID values. Account names shown by commands are human-readable representations of those IDs.

3. chown Command

The chown command is used to change the owner of a file or directory. It can also change the associated group.

chown stands for change owner.

Syntax

chown [OPTIONS] OWNER FILE

Example

sudo chown navdeep notes.txt

This changes the owner of notes.txt to the user navdeep.

Changing file ownership usually requires administrative privileges. A normal user can generally change ownership only under restricted conditions; use sudo when authorized.

4. Changing File Owner Using chown

Example 1: Change Owner of a File

sudo chown user1 notes.txt

Changes the owner of notes.txt to user1.

Example 2: Change Owner of Multiple Files

sudo chown user1 file1.txt file2.txt

Changes the owner of both files to user1.

Example 3: Change Owner of a Directory

sudo chown user1 project

Changes the owner of the directory itself. It does not automatically change ownership of the directory's contents.

Example 4: Change Owner Recursively

sudo chown -R user1 project

Changes the owner of the directory and its contents recursively.

5. Changing Group Ownership Using chown

The chown command can also change the group associated with a file.

Syntax

sudo chown :GROUP FILE

Example

sudo chown :developers notes.txt

Changes the group ownership of notes.txt to developers while keeping the current owner unchanged.

Changing Both Owner and Group

sudo chown user1:developers notes.txt

This changes the owner to user1 and the group to developers.

Recursive Ownership Change

sudo chown -R user1:developers project

Changes both owner and group for the directory and its contents recursively.

Always verify the target path before using recursive ownership changes. An incorrect path can affect many files and directories.

6. chgrp Command

The chgrp command is used to change the group ownership of a file or directory.

chgrp stands for change group.

Syntax

chgrp [OPTIONS] GROUP FILE

Example

sudo chgrp developers notes.txt

Changes the group ownership of notes.txt to developers.

The chgrp command changes group ownership. It does not change the file's user owner.

7. Changing Group Ownership Using chgrp

Example 1: Change Group of a File

sudo chgrp developers notes.txt

Example 2: Change Group of Multiple Files

sudo chgrp developers file1.txt file2.txt

Example 3: Change Group of a Directory

sudo chgrp developers project

Example 4: Change Group Recursively

sudo chgrp -R developers project

The recursive option changes the group ownership of the directory and its contents.

8. Important Options of chown and chgrp

Option Purpose Example
-R Apply ownership changes recursively. chown -R user1 folder
-v Display a message for each processed file. chown -v user1 file.txt
-c Report only when a change is made. chgrp -c group1 file.txt
--reference Use another file's owner and group as the reference. chown --reference=source.txt target.txt

Example: Verbose Mode

sudo chown -v user1 notes.txt

Example: Reference Mode

sudo chown --reference=source.txt target.txt

The target file receives the same owner and group as the reference file.

9. Difference Between chown and chgrp

Feature chown chgrp
Full form Change owner Change group
Changes user owner Yes No
Changes group owner Yes Yes
Can change both together Yes No
Recursive option -R -R
Remember: Use chown to change the user owner or both owner and group. Use chgrp specifically to change group ownership.

10. Permissions Required to Change Ownership

Linux restricts ownership changes to protect system security.

  • Changing a file's owner normally requires administrative privileges.
  • A user may change a file's group only when permitted by the system's ownership and group rules.
  • Changing ownership does not automatically change the file's permission bits.
  • Ownership changes may affect special permission bits and file security attributes.

Using sudo

sudo chown user1 notes.txt sudo chgrp developers notes.txt
Use sudo only when you have authorization. Avoid changing ownership of system files unless you understand the consequences.

11. Practical Lab: Managing Ownership

Objective: To inspect and change file ownership and group ownership in Ubuntu.

Step 1: Check Current User

whoami id

Step 2: Create a Lab Directory

mkdir ownership_lab cd ownership_lab

Step 3: Create Files

touch notes.txt touch project.txt

Step 4: Inspect Ownership

ls -l stat notes.txt

Step 5: Check Available Users

getent passwd

Step 6: Check Available Groups

getent group

Step 7: Change Owner

If an existing test account named user1 is available, run:

sudo chown user1 notes.txt

Step 8: Change Group

If a group named developers exists, run:

sudo chgrp developers notes.txt

Step 9: Change Both Owner and Group

sudo chown user1:developers project.txt

Step 10: Verify Changes

ls -l stat notes.txt stat project.txt
If user1 or developers does not exist on your Ubuntu installation, these example commands will fail. Use account and group names that actually exist, or create test accounts and groups in a controlled lab environment.

Step 11: Test Recursive Ownership

mkdir -p project/subfolder touch project/file1.txt touch project/subfolder/file2.txt

After creating a test user and group, use:

sudo chown -R user1:developers project

Step 12: Verify Recursive Changes

ls -lR project
Expected Result: You should be able to identify the owner and group of each file and directory from the command output.

12. Common Errors and Troubleshooting

1. Invalid User

sudo chown unknownuser notes.txt

This fails if the specified user does not exist. Check available accounts using:

getent passwd unknownuser

2. Invalid Group

sudo chgrp unknowngroup notes.txt

Check whether the group exists:

getent group unknowngroup

3. Permission Denied

The current user may not have sufficient privileges to change ownership.

4. Incorrect File Path

If the target file does not exist at the specified path, the command cannot change its ownership.

Always check the username, group name and file path before running ownership commands.

13. Interview Questions and Answers

Q1. What is the chown command?

It changes the owner of a file or directory and can also change its group.

Q2. What is the chgrp command?

It changes the group ownership of a file or directory.

Q3. What does chown stand for?

Change owner.

Q4. What does chgrp stand for?

Change group.

Q5. How do you change both owner and group?

Use sudo chown user:group file.

Q6. What does chown -R do?

It changes ownership recursively for a directory and its contents.

Q7. Does chgrp change the user owner?

No. It changes only group ownership.

Q8. Which command displays file ownership?

ls -l or stat.

Q9. What is UID?

UID is the numeric user identifier assigned to a Linux user account.

Q10. What is GID?

GID is the numeric group identifier assigned to a Linux group.

14. Multiple Choice Questions (MCQs)

Q1. Which command changes file ownership?

A. chmod
B. chown
C. pwd
D. touch

Correct Answer: B. chown

Q2. Which command changes group ownership?

A. chgrp
B. chmod
C. mkdir
D. cat

Correct Answer: A. chgrp

Q3. What does chown user:group file do?

A. Changes permissions
B. Changes owner and group
C. Deletes the file
D. Displays file contents

Correct Answer: B. Changes owner and group

Q4. Which option performs recursive ownership changes?

A. -v
B. -c
C. -R
D. -l

Correct Answer: C. -R

Q5. What is UID?

A. User ID
B. Group ID
C. File ID
D. Directory ID

Correct Answer: A. User ID

Q6. What is GID?

A. User ID
B. Group ID
C. File size
D. Permission mode

Correct Answer: B. Group ID

Q7. Which command displays ownership information?

A. ls -l
B. clear
C. cd
D. echo

Correct Answer: A. ls -l

Q8. Which command changes only the group ownership?

A. chown
B. chgrp
C. chmod
D. whoami

Correct Answer: B. chgrp

Q9. Which command displays detailed file metadata?

A. stat
B. rm
C. mv
D. pwd

Correct Answer: A. stat

Q10. Which command changes the owner and group recursively?

A. chmod -R 755 folder
B. sudo chown -R user:group folder
C. chgrp folder
D. ls -R folder

Correct Answer: B. sudo chown -R user:group folder

15. Lesson Summary

  • Every Linux file and directory has an owner and group.
  • chown changes the user owner and can also change group ownership.
  • chgrp changes group ownership only.
  • Use chown user:group file to change both together.
  • The -R option applies changes recursively.
  • Use ls -l and stat to inspect ownership.
  • UID identifies a user account numerically.
  • GID identifies a group numerically.
  • Ownership changes generally require appropriate privileges.
  • Changing ownership is different from changing permissions.
Key Concept to Remember: chmod changes permissions, chown changes ownership, and chgrp changes group ownership.
