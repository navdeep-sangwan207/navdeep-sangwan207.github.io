chmod Command

Changing File and Directory Permissions in Linux

Home Linux Course Chapter 5

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the chmod command.
  • Use chmod with symbolic permission notation.
  • Use chmod with numeric or octal notation.
  • Add, remove and assign permissions.
  • Change permissions for files and directories.
  • Apply permissions recursively.
  • Verify permission changes using Linux commands.

1. Introduction to chmod

The chmod command is used to change the permissions of files and directories in Linux.

The word chmod comes from change mode. It modifies the permission bits associated with a filesystem object.

Why Is chmod Used?

  • To allow or prevent file access.
  • To make scripts executable.
  • To restrict access to private files.
  • To control permissions for groups and other users.
  • To manage access to directories.
Example: A newly created shell script may not have execute permission. The chmod command can add execute permission so that it can be run directly.

2. chmod Command Syntax

chmod [OPTIONS] MODE FILE
Component Description
chmod Command used to change permissions.
OPTIONS Optional command options.
MODE New permissions or permission changes.
FILE File or directory whose permissions are changed.

Example

chmod 755 script.sh

This assigns permission mode 755 to script.sh.

3. Two Methods of Using chmod

The chmod command supports two commonly used permission notation methods.

Method Description Example
Symbolic notation Uses letters and operators to change permissions. chmod u+x file.sh
Numeric notation Uses octal digits to assign permissions. chmod 755 file.sh

4. Symbolic Mode

Symbolic mode uses letters to identify permission categories and permission types.

Permission Categories

Symbol Meaning
u Owner / user
g Group
o Others
a All categories: owner, group and others

Permission Operators

Operator Meaning
+ Add the specified permission.
- Remove the specified permission.
= Set the specified permission exactly for the selected category.

Permission Letters

Symbol Permission
r Read
w Write
x Execute
Symbolic mode structure:
chmod CATEGORY OPERATOR PERMISSION FILE

5. Adding Permissions Using +

The plus operator adds the specified permissions without removing other existing permissions.

Example 1: Add Execute Permission to Owner

chmod u+x script.sh

Adds execute permission for the owner of script.sh.

Example 2: Add Write Permission to Group

chmod g+w notes.txt

Adds write permission for the group.

Example 3: Add Read Permission to Others

chmod o+r notes.txt

Adds read permission for others.

Example 4: Add Execute Permission to Everyone

chmod a+x script.sh

Adds execute permission to owner, group and others.

6. Removing Permissions Using -

The minus operator removes the specified permissions while keeping other permissions unchanged.

Example 1: Remove Write Permission from Owner

chmod u-w notes.txt

Example 2: Remove Execute Permission from Group

chmod g-x script.sh

Example 3: Remove Read Permission from Others

chmod o-r notes.txt

Example 4: Remove Write Permission from Everyone

chmod a-w notes.txt
The minus operator removes only the specified permission. It does not automatically remove the other permission types.

7. Assigning Exact Permissions Using =

The equals operator sets the permissions for the selected category to exactly the specified permission set.

Example 1: Set Owner to Read and Write Only

chmod u=rw notes.txt

Example 2: Set Group to Read Only

chmod g=r notes.txt

Example 3: Remove All Permissions from Others

chmod o= notes.txt

Example 4: Set Different Permissions for All Categories

chmod u=rwx,g=rx,o=r file.sh
Resulting permissions:
rwxr-xr--

The equals operator replaces the permission set for the selected category rather than simply adding or removing one permission.

8. Numeric Mode

Numeric mode uses octal numbers to assign permissions to owner, group and others.

Permission Value
Read (r) 4
Write (w) 2
Execute (x) 1
No permission 0

Example 1: Permission 755

chmod 755 script.sh
755 = rwxr-xr-x
Owner: Read, write and execute. Group: Read and execute. Others: Read and execute.

Example 2: Permission 644

chmod 644 notes.txt
644 = rw-r--r--
Owner: Read and write. Group: Read only. Others: Read only.

Example 3: Permission 600

chmod 600 private.txt
600 = rw-------
Owner: Read and write. Group: No permissions. Others: No permissions.

Example 4: Permission 700

chmod 700 private_directory
700 = rwx------
Owner: Read, write and execute. Group: No permissions. Others: No permissions.

9. Important chmod Options

Option Purpose Example
-R Apply changes recursively to directories and their contents. chmod -R 755 folder
-v Display a message for each processed file. chmod -v 644 file.txt
-c Report only when a change is made. chmod -c 644 file.txt
--reference Use another file's mode as the permission reference. chmod --reference=source.txt target.txt

Recursive Permission Change

chmod -R 755 project

This applies mode 755 recursively to the directory and its contents.

Important: Recursive chmod applies the same permission mode to files and directories. This may give execute permission to regular files that should not be executable. Use recursive permission changes carefully.

10. Verifying Permission Changes

After using chmod, inspect the permissions to confirm that the changes were applied.

Using ls -l

ls -l notes.txt

Using stat

stat notes.txt

Example

chmod 640 notes.txt ls -l notes.txt
Example Output:
-rw-r----- 1 navdeep navdeep 0 Nov 5 10:30 notes.txt

The permission mode 640 means:

  • Owner: Read and write.
  • Group: Read only.
  • Others: No permissions.

11. Practical Lab: Using chmod

Objective: To change file and directory permissions using symbolic and numeric modes.

Step 1: Create a Working Directory

mkdir chmod_lab cd chmod_lab

Step 2: Create Files

touch notes.txt touch script.sh

Step 3: Check Initial Permissions

ls -l

Step 4: Add Execute Permission to Owner

chmod u+x script.sh

Step 5: Verify the Change

ls -l script.sh

Step 6: Add Read Permission to Others

chmod o+r notes.txt

Step 7: Remove Write Permission from Group

chmod g-w notes.txt

Step 8: Assign Numeric Permission 644

chmod 644 notes.txt

Step 9: Verify Numeric Permissions

stat notes.txt

Observe the message displayed when the permission mode changes.

Perform these exercises using your Ubuntu terminal inside VirtualBox. The output may vary depending on your username, file ownership and initial permissions.

12. Common Mistakes and Precautions

1. Confusing Numeric Values

Remember that read is 4, write is 2 and execute is 1. Each category gets a separate digit.

2. Using the Wrong Category

The symbols u, g and o represent owner, group and others. Select the correct category before changing permissions.

3. Using Recursive Mode Carelessly

Applying one mode recursively can unintentionally make regular files executable or change directory permissions in an unsuitable way.

4. Assuming chmod Changes Ownership

chmod changes permissions. It does not change the file owner or group.

Do not use chmod 777 as a routine solution to permission errors. First identify the actual permission or ownership problem.

13. Interview Questions and Answers

Q1. What is the chmod command?

chmod is a Linux command used to change the permissions of files and directories.

Q2. What does chmod stand for?

Change mode.

Q3. What are the two common chmod modes?

Symbolic mode and numeric mode.

Q4. What does chmod u+x file.sh do?

It adds execute permission for the file owner.

Q5. What does chmod g-w file.txt do?

It removes write permission from the group.

Q6. What does chmod 755 mean?

Owner has full permissions; group and others have read and execute permissions.

Q7. What is the purpose of chmod -R?

It applies permission changes recursively to a directory and its contents.

Q8. What is the difference between + and - in symbolic mode?

Plus adds permissions; minus removes permissions.

Q9. What does the equals operator do?

It assigns the specified permission set exactly to the selected category.

Q10. Does chmod change file ownership?

No. chmod changes permissions, while chown is used to change ownership.

15. Lesson Summary

  • chmod is used to change file and directory permissions.
  • Symbolic mode uses u, g, o and a.
  • The plus operator adds permissions.
  • The minus operator removes permissions.
  • The equals operator sets an exact permission set.
  • Numeric mode uses octal values from 0 to 7 for each category.
  • chmod 755 assigns rwxr-xr-x.
  • chmod 644 assigns rw-r--r--.
  • chmod 600 assigns rw-------.
  • The -R option applies changes recursively.
  • Use ls -l and stat to verify permission changes.
Key Concept to Remember: Use symbolic mode when you want to add or remove specific permissions. Use numeric mode when you want to assign a complete permission set.
