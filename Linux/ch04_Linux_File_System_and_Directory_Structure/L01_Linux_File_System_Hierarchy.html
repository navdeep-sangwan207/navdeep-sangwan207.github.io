Linux File System Hierarchy

Understanding the Linux directory structure and Filesystem Hierarchy Standard (FHS)

1. Introduction to the Linux File System

A file system is a method used by an operating system to organize, store, retrieve and manage files and directories on a storage device.

Linux uses a hierarchical file system structure. Files and directories are organized in a tree-like arrangement that begins from a single starting directory called the root directory (/).

Unlike Windows, which commonly uses drive letters such as C:, D: and E:, Linux organizes its directory structure under one root.

Important concept: In Linux, everything is organized under the root directory. Different storage devices and partitions can be mounted at different locations within this directory hierarchy.

2. What is the Filesystem Hierarchy Standard (FHS)?

The Filesystem Hierarchy Standard (FHS) is a set of guidelines that describes the recommended directory structure and directory purposes in Linux and other Unix-like operating systems.

FHS helps software developers, system administrators and users understand where different types of files should normally be stored.

Main objectives of FHS

  • Provide a consistent directory structure.
  • Separate system files from user files.
  • Organize executable programs, libraries and configuration files.
  • Make Linux systems easier to maintain and administer.
  • Improve compatibility between Linux distributions.
Note: Linux distributions may differ in implementation. FHS describes conventions and expected purposes; it does not mean every system must have exactly the same directory contents.

3. Linux Directory Hierarchy

The following tree shows many important directories commonly found in a Linux system such as Ubuntu.

/ ├── bin ├── boot ├── dev ├── etc ├── home │ ├── user1 │ └── user2 ├── lib ├── lib64 ├── media ├── mnt ├── opt ├── proc ├── root ├── run ├── sbin ├── srv ├── sys ├── tmp ├── usr │ ├── bin │ ├── include │ ├── lib │ ├── local │ └── share └── var ├── cache ├── log ├── mail └── tmp

Each directory has a specific purpose. Some contain programs, some contain configuration files, and others store user data, device information or system logs.

The tree is a simplified illustration. Actual directory contents vary by Linux distribution, installed software and system configuration.

4. Important Linux Directories and Their Functions

4.1 Root Directory (/)

The root directory is the top-level directory of the Linux file system. All other directories and files are located below it.

It is represented by a forward slash (/). It should not be confused with the root user account or the /root home directory.

4.2 /bin – Essential User Commands

Traditionally, /bin contains essential executable commands needed for basic system operation and user activities.

Examples include:

ls cp mv cat echo

4.3 /sbin – System Administration Commands

Traditionally, /sbin contains essential system administration utilities used for system management and maintenance.

Examples include:

fsck reboot shutdown

4.4 /boot – Boot Files

The /boot directory contains files required during the Linux boot process.

Common contents include:

  • Linux kernel images.
  • Initial RAM file system images (initramfs).
  • Bootloader-related files and configuration.

4.5 /dev – Device Files

The /dev directory contains device files that provide interfaces to devices and certain kernel facilities.

Examples:

/dev/sda /dev/null /dev/tty /dev/zero
Linux uses a device-file interface for many hardware devices. Device nodes are not ordinary copies of device data; they provide interfaces through which programs can interact with devices or kernel services.

4.6 /etc – Configuration Files

The /etc directory stores system-wide configuration files.

Examples:

/etc/passwd /etc/hostname /etc/hosts /etc/fstab

4.7 /home – User Home Directories

The /home directory contains personal directories for regular users. Each user generally has a separate home directory.

Example:

/home/navdeep /home/student

A user's documents, downloads, desktop files and personal configuration are commonly stored inside their home directory.

4.8 /lib and /lib64 – Essential Libraries

These directories traditionally contain essential shared libraries and kernel-related modules needed by programs and system utilities.

The exact arrangement depends on the system architecture and distribution.

4.9 /media – Removable Media Mount Points

The /media directory is commonly used for automatically mounted removable storage devices, such as USB drives and optical media.

4.10 /mnt – Temporary Mount Point

The /mnt directory is traditionally used by administrators as a temporary mount point for file systems.

4.11 /opt – Optional Application Software

The /opt directory is intended for optional application software and additional software packages.

4.12 /proc – Process and Kernel Information

The /proc directory is a virtual file system that exposes information about running processes and kernel parameters.

Examples:

/proc/cpuinfo /proc/meminfo /proc/uptime /proc/version
Files inside /proc are generally generated dynamically by the kernel. They do not behave like ordinary files stored permanently on a disk.

4.13 /root – Root User's Home Directory

The /root directory is the home directory of the root user, which is the system's administrative account.

Remember the difference:
  • / – Root of the entire file system.
  • /root – Home directory of the root user.

4.14 /run – Runtime Data

The /run directory stores temporary runtime information about processes and services. Its contents are generally cleared during system startup.

4.15 /srv – Service Data

The /srv directory is intended for data served by system services, such as web or file-sharing services.

4.16 /sys – Kernel and Device Information

The /sys directory is a virtual file system, commonly called sysfs. It exposes information about devices, drivers and kernel subsystems.

4.17 /tmp – Temporary Files

The /tmp directory is used by applications and users to store temporary files.

Temporary files may be deleted automatically during a reboot or according to system cleanup policies. Do not use /tmp for important permanent data.

4.18 /usr – User Applications and Shared Resources

The /usr directory contains many user-space programs, libraries, documentation and shared resources.

Directory Purpose
/usr/bin Most user commands and application executables.
/usr/sbin Many system administration utilities.
/usr/lib Libraries and supporting files for programs.
/usr/include Header files used during software development.
/usr/share Architecture-independent shared data and documentation.
/usr/local Software installed locally by the system administrator.

4.19 /var – Variable Data

The /var directory stores data that changes frequently while the system is running.

Directory Purpose
/var/log System and application log files.
/var/cache Application cache data.
/var/mail Traditional user mail storage.
/var/tmp Temporary files intended to persist longer than /tmp.

5. Important Difference Between /bin and /usr/bin

Traditionally, /bin contained essential commands required for basic system operation, while /usr/bin contained many other user commands and applications.

Modern Ubuntu installations commonly use a merged-/usr layout. In this arrangement, directories such as /bin, /sbin and /lib may be symbolic links to their corresponding locations under /usr.

/bin → /usr/bin /sbin → /usr/sbin /lib → /usr/lib
Do not assume that /bin and /usr/bin are always physically separate directories. Check your actual Ubuntu installation.

6. Linux File System vs Windows File System

Feature Linux Windows
Starting point Root directory (/) Drive letters such as C: and D:
Path separator Forward slash (/) Backslash (\)
Home directory /home/username C:\Users\username
Configuration Commonly stored under /etc Various locations, including Registry and configuration files
Case sensitivity Normally case-sensitive Usually case-insensitive by default

7. Exploring the File System Using Commands

Command 1: pwd

Displays the current working directory.

pwd
Example output: 
/home/navdeep

Command 2: ls

Lists files and directories in the current location.

ls ls / ls -l / ls -a /

Command 3: ls -la

Displays detailed information, including hidden entries.

ls -la /

Command 4: tree

Displays directories and files in a tree-like format.

tree /
The tree command may not be installed by default. If it is missing, install it using sudo apt install tree. Avoid running an unrestricted tree command on the entire root directory when only a small view is needed.

Command 5: df -h

Displays mounted file systems and their disk space usage in readable units.

df -h

Command 6: find

Searches for files and directories within a specified location.

find /home -name "*.txt"

Command 7: du -sh

Displays the total disk usage of a specified directory.

du -sh /home

Objective: Explore important directories in Ubuntu using terminal commands.

Step 1: Open the Ubuntu Terminal

Start your Ubuntu virtual machine in VirtualBox and open the terminal using Ctrl + Alt + T.

Step 2: Display the Current Directory

pwd

Step 3: Display Root Directory Contents

ls /

Step 4: Explore the /etc Directory

ls /etc

Step 5: Explore the /home Directory

ls /home

Step 6: Display CPU Information

cat /proc/cpuinfo

Step 7: Display Memory Information

cat /proc/meminfo

Step 8: Check Disk Space

df -h

Step 9: Check Directory Size

Expected Result:
  • Identify the root directory and its major subdirectories.
  • View system configuration files in /etc.
  • Identify user directories in /home.
  • Read CPU and memory information from /proc.
  • Check disk space and directory size.

10. Interview Questions and Answers

Q1. What is the Linux file system hierarchy?

It is a tree-like directory structure that starts from the root directory (/) and organizes files and directories.

Q2. What is FHS?

FHS stands for Filesystem Hierarchy Standard. It defines conventions for the organization and purpose of directories in Linux systems.

Q3. What is the purpose of the /etc directory?

It stores system-wide configuration files.

Q4. What is the difference between /root and /?

/ is the root of the entire file system, whereas /root is the home directory of the root administrative user.

Q5. What is stored in /proc?

/proc is a virtual file system that provides process and kernel information.

Q6. What is the purpose of /dev?

It contains device files that provide interfaces to devices and certain kernel facilities.

Q7. What is the difference between /tmp and /var/tmp?

Both store temporary data. /var/tmp is generally intended for temporary files that persist longer than files in /tmp.

Q8. What is stored in /var/log?

It stores system and application log files.

Q9. What is the purpose of /usr?

It contains many user-space programs, libraries, documentation and shared resources.

Q10. What is the difference between /media and /mnt?

/media is commonly used for removable media mount points, while /mnt is traditionally used as a temporary mount point by administrators.

12. Lesson Summary

  • Linux uses a hierarchical file system structure.
  • The root directory (/) is the starting point of the hierarchy.
  • FHS defines conventions for Linux directory organization.
  • /etc stores configuration files.
  • /home stores regular users' home directories.
  • /dev provides device-file interfaces.
  • /proc and /sys expose virtual kernel and system information.
  • /usr contains user-space programs and shared resources.
  • /var stores frequently changing data such as logs.
  • Commands such as pwd, ls, find, df and du help explore the file system.
