Chapter 4: Linux File System and Directory Structure

Understanding Linux Directories, File Organization, Metadata and Links

Chapter Overview

The Linux file system provides a hierarchical structure for organizing files and directories. Every file and directory is located within a common directory tree that begins at the root directory (/).

In this chapter, you will learn about the Linux file system hierarchy, important directories, absolute and relative paths, file types, hidden files, metadata, inodes, hard links, symbolic links and file-searching utilities.
