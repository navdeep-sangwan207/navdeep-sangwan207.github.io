1. Introduction to File Searching in Linux

Linux provides several commands to search for files and directories. These commands help users locate data in large directory structures without manually checking every folder.

Two commonly used file-searching commands are:

  • find: Searches directory hierarchies by examining files and directories.
  • locate: Searches a previously created database of file paths.
Important Concept: The find command searches the specified directory hierarchy directly, while locate normally searches a database that may need updating.

2. The find Command

Definition

The find command searches for files and directories within a specified directory hierarchy. It supports different search conditions such as name, file type, size, permissions and modification time.

Basic Syntax

find [PATH] [EXPRESSION]

Where:

  • PATH specifies the starting directory.
  • EXPRESSION specifies the search conditions and optional actions.

Example 1: Search in the Current Directory

find .

The dot (.) represents the current working directory. The command displays entries found in the current directory hierarchy.

Example 2: Search from the Root Directory

find / -name "report.txt"

This searches for entries named report.txt starting from the root directory.

Searching the entire root file system may produce permission errors and take time. Use a suitable starting directory when possible.

3. Searching Files by Name

The -name option searches for a filename using a case-sensitive pattern.

Example 1: Search for an Exact Filename

find . -name "notes.txt"

Example 2: Search for All HTML Files

find . -name "*.html"

Example 3: Case-Insensitive Search

find . -iname "notes.txt"

The -iname option performs a case-insensitive filename search.

Example 4: Search for Files Beginning with a Letter

find . -name "L01*"
Possible Output:
./chapter1/L01_Introduction.html ./chapter2/L01_Linux_Basics.html
Wildcard Symbols:
  • * matches zero or more characters.
  • ? matches one character.
Quotation marks prevent the shell from expanding the wildcard before find receives it.

4. Searching by File Type

The -type option searches for a particular type of file-system entry.

Option Meaning
-type f Regular files
-type d Directories
-type l Symbolic links
-type c Character device files
-type b Block device files
-type p Named pipes (FIFOs)
-type s Socket files

Example 1: Find Regular Files

find . -type f

Example 2: Find Directories

find . -type d

Example 3: Find Symbolic Links

find . -type l

Example 4: Find Only HTML Files

find . -type f -name "*.html"

5. Searching by File Size

The -size option searches for files based on their size.

Unit Meaning
c Bytes
k 1024-byte units
M 1024-kilobyte units
G 1024-megabyte units

Example 1: Find Files Larger Than 10 MB

find . -type f -size +10M

Example 2: Find Files Smaller Than 1 MB

find . -type f -size -1M

Example 3: Find Files Exactly 100 Bytes in Size

find . -type f -size 100c
Note: GNU find rounds size comparisons to units when using suffixes such as M and k. Use c when you need byte-based comparisons.

6. Searching by Modification Time

Linux can search for files based on when their contents were last modified.

The -mtime option uses periods of 24 hours. The -mmin option uses minutes.

Example 1: Files Modified Within the Last 24 Hours

find . -type f -mtime -1

Example 2: Files Modified More Than 7 Days Ago

find . -type f -mtime +7

Example 3: Files Modified Within the Last 30 Minutes

find . -type f -mmin -30

Example 4: Files Modified More Than 60 Minutes Ago

find . -type f -mmin +60
Understanding Time Expressions:
  • -1 means less than one complete 24-hour period.
  • +7 means more than seven complete 24-hour periods.
  • 1 means the one-day range used by the find time test.

7. Searching by Permissions

The -perm option searches for files with specified permission bits.

Example 1: Find Files with Exact Permission 644

find . -type f -perm 644

Example 2: Find Files with Permission 777

find . -type f -perm 777

Example 3: Find Files with Any Execute Permission

find . -type f -perm /111

The /111 form matches files having at least one execute permission bit set for the owner, group or others.

8. Combining Search Conditions

The find command allows multiple conditions to be combined in one search.

Example 1: Find HTML Files in the Current Directory Tree

find . -type f -name "*.html"

Example 2: Find Text Files Larger Than 1 MB

find . -type f -name "*.txt" -size +1M

Example 3: Find Empty Files

find . -type f -empty

Example 4: Find Empty Directories

find . -type d -empty

Example 5: Exclude a Directory

find . -path "./backup" -prune -o -type f -print

This example excludes the backup directory from the search and prints matching regular files elsewhere in the directory tree.

9. Performing Actions with find

The find command can perform actions on matching entries.

Example 1: Display Matching Files

find . -type f -name "*.txt" -print

Example 2: Execute a Command on Each Result

find . -type f -name "*.txt" -exec file {} \;

Here:

  • -exec executes a command for each matching entry.
  • {} represents the current matched pathname.
  • \; marks the end of the command.

Example 3: Execute a Command on Multiple Results

find . -type f -name "*.txt" -exec file {} +

The + form passes multiple matched pathnames to each command invocation where possible.

Safety Warning: Commands such as rm can permanently remove files. First inspect the search results before performing destructive actions. Avoid running deletion commands on broad paths without understanding their effect.

10. The locate Command

Definition

The locate command searches for file and directory pathnames using a database of previously indexed paths.

Because it searches a database instead of examining every directory during each query, it is often faster than find for simple pathname searches.

Basic Syntax

locate [OPTION] PATTERN

Example 1: Search for a File

locate notes.txt
Possible Output:
/home/user/documents/notes.txt /home/user/backup/notes.txt

Example 2: Search for HTML Files

locate "*.html"

Example 3: Case-Insensitive Search

locate -i notes.txt

Example 4: Limit the Number of Results

locate -n 10 notes.txt

The -n option limits the number of results displayed.

Example 5: Search for an Exact Basename

locate -b '\notes.txt'

The -b option searches the basename portion of a path. The backslash before the pattern prevents special pattern characters from being interpreted as wildcards.

11. Understanding the locate Database

The locate command normally searches a database containing indexed file paths. This database is updated periodically by a scheduled system service or manually using an appropriate update command.

Updating the Database

sudo updatedb

The updatedb command refreshes the file-path database used by compatible locate implementations.

Searching After Updating

sudo updatedb locate notes.txt
Important: On Ubuntu, the locate utility may be provided by plocate or another package. The update command and database management can depend on the installed implementation.

Installing locate on Ubuntu

If the command is not installed, you can install the commonly used plocate package:

sudo apt update sudo apt install plocate

After installation, update its database:

sudo updatedb

12. Difference Between find and locate

Feature find locate
Search Method Examines the directory hierarchy Searches an indexed pathname database
Speed Can be slower on large directory trees Often faster for simple pathname searches
Database Does not require a pathname database Requires an indexed database
Recent Files Can find recently created entries May not find entries missing from the database
Search Conditions Supports name, type, size, permissions, time and more Primarily searches indexed pathnames
Basic Command find . -name "file.txt" locate file.txt
Key Difference: Use find when you need current directory information and advanced search conditions. Use locate when you want a quick pathname search using its indexed database.

14. Practical Lab 2: Searching with locate

Objective: To search for file paths using the locate database.

Step 1: Install the package if required

sudo apt update sudo apt install plocate

Step 2: Update the database

sudo updatedb

Step 3: Search for a file

locate notes.txt

Step 4: Search for HTML files

locate "*.html"

Step 5: Limit the results

locate -n 5 "*.html"
If a newly created file does not appear in the results, update the database and search again. Database access restrictions may also affect which paths are indexed or displayed.

15. Common Errors and Precautions

1. Permission Denied

A normal user may not have permission to search some directories. Choose an accessible search path or use elevated privileges only when necessary.

2. locate Command Not Found

The locate package may not be installed. Install plocate or the appropriate locate package for your Linux distribution.

3. locate Does Not Find a New File

The file may not yet be included in the pathname database. Update the database with sudo updatedb where supported.

4. Incorrect Filename Pattern

Check the spelling, capitalization and wildcard pattern. Linux filenames are generally case-sensitive.

5. Searching the Entire File System

Searching from / can take time and may generate permission errors. Start from a narrower directory whenever possible.

18. Lesson Summary

  • The find command searches directory hierarchies.
  • The locate command searches an indexed pathname database.
  • -name searches filenames with case sensitivity.
  • -iname searches filenames without case sensitivity.
  • -type f searches regular files.
  • -type d searches directories.
  • -size searches by file size.
  • -mtime and -mmin search by modification age.
  • -perm searches by file permissions.
  • updatedb refreshes the locate database where supported.
Key Concept to Remember: Use find for direct and condition-based directory searches. Use locate for quick searches through an indexed database of file paths.
