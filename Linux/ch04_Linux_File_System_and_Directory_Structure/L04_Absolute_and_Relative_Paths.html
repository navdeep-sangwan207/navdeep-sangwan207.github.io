LINUX PROGRAMMING • CHAPTER 4 • LESSON 4

Absolute and Relative Paths

Understanding file and directory locations in Linux

Home Linux Course Chapter 4

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the meaning of a file path in Linux.
  • Differentiate between absolute and relative paths.
  • Use special path symbols such as /, ., .. and ~.
  • Navigate directories using path expressions.
  • Work with directory and file names containing spaces.
  • Use paths with Linux commands such as cd, ls, cp and mv.

1. Introduction to Linux Paths

A path is the location of a file or directory in the Linux file system. It tells the operating system where a particular file or directory is located.

Linux organizes files and directories in a hierarchical structure that begins with the root directory (/).

Example directory structure

/ ├── home │ └── user │ ├── Documents │ │ └── notes.txt │ └── Downloads ├── etc ├── var └── usr

In this structure, the file notes.txt is located inside Documents, which is inside user, which is inside home.

Example path:
/home/user/Documents/notes.txt
This path identifies the exact location of notes.txt.

2. Absolute Path

An absolute path specifies the complete location of a file or directory starting from the root directory (/).

Characteristics

  • Always begins with a forward slash (/).
  • Starts from the root directory.
  • Does not depend on the current working directory.
  • Identifies a location from the top of the file system hierarchy.

Examples

/home/user /home/user/Documents /home/user/Documents/notes.txt /etc/hostname /var/log

Example using cd

cd /home/user/Documents pwd
Possible output:
/home/user/Documents

The cd command moves to the directory specified by the absolute path. The pwd command displays the current working directory.

Example using ls

ls /home/user/Documents

This command lists the contents of Documents without requiring you to first move into that directory.

3. Relative Path

A relative path specifies the location of a file or directory in relation to the current working directory.

Characteristics

  • Does not begin with a forward slash (/).
  • Depends on the current working directory.
  • Can use directory names and special symbols such as . and ..
  • Can be shorter than an absolute path.

Example directory structure

/home/user/ ├── Documents/ │ ├── notes.txt │ └── report.txt └── Downloads/

Assume the current working directory is:

/home/user

The following relative path identifies the Documents directory:

Documents

Example using cd

pwd cd Documents pwd
Possible output:
/home/user /home/user/Documents

The command cd Documents moves into the Documents directory relative to the current working directory.

Example using cat

cat Documents/notes.txt

This displays the contents of notes.txt using a relative path, assuming the current directory is /home/user.

4. Special Path Symbols

Linux provides special symbols that make navigating the file system easier.

Symbol Meaning Example
/ Root directory /home/user
. Current directory ./notes.txt
.. Parent directory ../Documents
~ Current user's home directory ~/Downloads
- Previous working directory when used with cd cd -

4.1 Current Directory (.)

A single dot (.) represents the current working directory.

ls . cp ./notes.txt ./backup.txt

The first command lists the current directory. The second copies notes.txt from the current directory to a new file named backup.txt in the same directory.

4.2 Parent Directory (..)

Two dots (..) represent the parent directory of the current working directory.

cd .. pwd

This moves one directory level upward and displays the new current working directory.

Moving up multiple levels

cd ../.. cd ../../..

Each .. moves one directory level upward. Therefore, ../.. moves two levels upward.

4.3 Home Directory (~)

The tilde symbol (~) represents the current user's home directory when expanded by the shell.

cd ~ pwd

You can also access a directory inside your home directory:

cd ~/Documents ls ~/Downloads
Important: In an ordinary unquoted shell command, the shell expands ~ to the current user's home directory. If you write "~" inside quotes, the tilde is treated as a literal character rather than being expanded.

4.4 Previous Directory (-)

The command cd - switches to the previous working directory.

cd /home/user/Documents cd /var/log cd -

The final command returns to the previous directory, which was /home/user/Documents.

5. Difference Between Absolute and Relative Paths

Feature Absolute Path Relative Path
Starting point Root directory Current working directory
Begins with / Yes Normally no
Depends on current directory No Yes
Length Often longer Often shorter
Example /home/user/Documents Documents
Both absolute and relative paths can identify the same file or directory. The correct path depends on the current working directory and the location being accessed.

6. Working with Paths Using Linux Commands

Many Linux commands accept either absolute or relative paths.

Using pwd

pwd

Displays the absolute path of the current working directory.

Using cd

cd /home/user/Documents cd Downloads cd .. cd ~

The cd command supports both absolute and relative paths.

Using ls

ls /etc ls Documents ls ../Downloads

The ls command can list directories using different types of paths.

Using cp

cp /home/user/Documents/notes.txt /home/user/Downloads/ cp notes.txt backup.txt

The first example uses absolute paths. The second example uses relative paths and assumes notes.txt is in the current working directory.

Using mv

mv /home/user/Documents/report.txt /home/user/Downloads/ mv report.txt final_report.txt

The mv command moves files or renames them. The paths determine the source and destination.

7. Paths Containing Spaces

Linux allows spaces in file and directory names. However, the shell normally treats spaces as separators between command arguments.

Example directory

/home/user/My Documents/notes.txt

To access this path correctly, enclose the path in quotes or escape the space.

Method 1: Using quotation marks

cd "/home/user/My Documents" ls "/home/user/My Documents"

Method 2: Using a backslash

cd /home/user/My\ Documents ls /home/user/My\ Documents
Common mistake: Writing cd /home/user/My Documents without quotes or escaping the space causes the shell to interpret the path as separate arguments.

8. Case Sensitivity in Linux Paths

Linux file names and paths are case-sensitive in typical Linux file systems.

For example, these are different names:

Documents documents DOCUMENTS

If the actual directory is Documents, the following command may fail:

cd documents
Always check the exact spelling and capitalization of file and directory names when entering paths.

9. Practical Examples

Example 1: Navigate to Documents using an absolute path

cd /home/user/Documents pwd

Moves directly to Documents using its complete path.

Example 2: Navigate to Downloads using a relative path

Assume the current directory is /home/user.

cd Downloads pwd

Moves into Downloads relative to the current directory.

Example 3: Move to the parent directory

cd .. pwd

Moves one level upward.

Example 4: Access a file in another directory

Assume the current directory is /home/user.

cat Documents/notes.txt

Displays the file without changing the current directory.

Example 5: Copy a file using an absolute destination

cp Documents/notes.txt /home/user/Downloads/

Copies notes.txt from Documents into Downloads.

Example 6: Return to the previous directory

cd /etc cd /var/log cd - pwd

The cd - command returns to /etc in this example.

10. Practical Lab Exercises

Lab 1: Identify the current directory

Objective: Display the current working directory.

pwd

Expected Result: The terminal displays the absolute path of the current directory.

Lab 2: Navigate using an absolute path

Objective: Move to the Documents directory.

cd ~/Documents pwd

Expected Result: The terminal displays the Documents directory path inside your home directory.

Lab 3: Navigate using a relative path

Objective: Move from the home directory into Downloads.

cd ~ cd Downloads pwd

Expected Result: The terminal displays the Downloads directory path.

Lab 4: Move to the parent directory

Objective: Move one directory level upward.

cd .. pwd

Expected Result: The terminal displays the parent directory.

Lab 5: Create and access a directory using a relative path

Objective: Create a practice directory and enter it.

cd ~ mkdir Linux_Practice cd Linux_Practice pwd

Expected Result: Linux_Practice is created inside the home directory, and the terminal enters it.

Lab 6: Work with a directory containing spaces

Objective: Create and access a directory with a space in its name.

cd ~ mkdir "My Linux Notes" cd "My Linux Notes" pwd

Expected Result: The terminal enters the My Linux Notes directory.

11. Common Errors and Troubleshooting

Error Possible Cause Solution
No such file or directory Incorrect path or missing file Check the path and file name.
Not a directory Trying to use cd with a regular file Specify a directory instead.
Permission denied Insufficient access permissions Check permissions and user access.
Command interprets spaces incorrectly Path is not quoted or escaped Use quotes or backslashes.
Path not found due to capitalization Linux is case-sensitive Use the exact name.

Useful troubleshooting commands

pwd ls ls -l ls -ld /path/to/directory cd /path/to/directory

These commands help identify the current location, inspect directory contents and check whether a path refers to an existing directory.

12. Interview Questions

Q1. What is a path in Linux?

A path is the location of a file or directory in the Linux file system.

Q2. What is an absolute path?

An absolute path specifies the complete location of a file or directory starting from the root directory (/).

Q3. What is a relative path?

A relative path specifies a file or directory location with respect to the current working directory.

Q4. What is the difference between / and ~?

/ represents the root directory, whereas ~ represents the current user's home directory when expanded by the shell.

Q5. What does .. represent?

It represents the parent directory of the current directory.

Q6. What does . represent?

It represents the current directory.

Q7. Which command displays the current working directory?

The pwd command.

Q8. Is an absolute path dependent on the current directory?

No. An absolute path starts from the root directory.

Q9. How can you access a path containing spaces?

Use quotation marks around the path or escape spaces using a backslash.

Q10. What does cd - do?

It switches to the previous working directory.

13. Multiple Choice Questions (MCQs)

Q1. Which symbol represents the root directory?

  1. ~
  2. /
  3. .
  4. ..

Correct Answer: B. /

Q2. Which path is an absolute path?

  1. Documents/notes.txt
  2. ../Downloads
  3. /home/user/Documents
  4. ./notes.txt

Correct Answer: C. /home/user/Documents

Q3. Which symbol represents the parent directory?

  1. .
  2. ..
  3. /
  4. ~

Correct Answer: B. ..

Q4. Which command displays the current working directory?

  1. ls
  2. cd
  3. pwd
  4. mkdir

Correct Answer: C. pwd

Q5. What does ~ represent?

  1. Root directory
  2. Parent directory
  3. Home directory
  4. Current directory

Correct Answer: C. Home directory

Q6. Which command moves to the parent directory?

  1. cd .
  2. cd ..
  3. cd /
  4. pwd ..

Correct Answer: B. cd ..

Q7. Which command returns to the previous working directory?

  1. cd ~
  2. cd /
  3. cd -
  4. cd ..

Correct Answer: C. cd -

Q8. Which is a valid way to access a directory named My Documents?

  1. cd My Documents
  2. cd "My Documents"
  3. cd My/Documents
  4. cd My-Documents

Correct Answer: B. cd "My Documents"

14. Lesson Summary

  • A path identifies the location of a file or directory.
  • An absolute path starts from the root directory (/).
  • A relative path starts from the current working directory.
  • The symbol . represents the current directory.
  • The symbol .. represents the parent directory.
  • The symbol ~ represents the current user's home directory when shell-expanded.
  • The command cd - returns to the previous working directory.
  • Paths containing spaces should be quoted or escaped.
  • Linux paths are case-sensitive in typical Linux file systems.
  • Commands such as cd, ls, cp and mv accept paths.
Key Concept: Absolute paths start from the root directory, while relative paths are interpreted from the current working directory.
