Home Directory (/home)

Understanding user home directories, personal files and the home shortcut (~)

Home Linux Course Chapter 4

Learning Objectives

After completing this lesson, you will be able to:

  • Define the Linux home directory.
  • Understand the purpose of /home.
  • Identify individual user home directories.
  • Understand the difference between /home and /root.
  • Use the tilde (~) shortcut to access your home directory.
  • Navigate and manage files inside a home directory.
  • Understand hidden files and user-specific configuration.
  • Check home directory ownership and permissions.

1. Introduction to the Home Directory

A home directory is a personal directory assigned to a user in a Linux operating system. It provides a location where users can store their personal files, documents and configuration data.

In most Linux distributions, regular users' home directories are located inside the /home directory.

Example

/ └── home ├── navdeep ├── student └── developer

In this example, navdeep, student and developer are separate user home directories.

Important: The path /home is generally the parent directory for regular users' home directories. A user's actual home directory may be /home/username.

2. Purpose of the Home Directory

The home directory provides each user with a separate workspace. Users can manage their own files without storing everything directly in system directories.

Main purposes

  • Personal files: Stores documents, images, videos and other files.
  • Downloads: Stores downloaded files.
  • Application settings: Stores user-specific application configuration.
  • Development work: Stores source code, projects and scripts.
  • Shell configuration: Stores files such as .bashrc.
  • User separation: Provides separate workspaces for different users.

3. Structure of a User Home Directory

A typical Ubuntu user home directory may contain folders and hidden configuration files.

/home/navdeep ├── Desktop ├── Documents ├── Downloads ├── Music ├── Pictures ├── Public ├── Templates ├── Videos ├── .bashrc ├── .profile └── .config

The exact folders depend on the Ubuntu installation, desktop environment and user configuration.

Directory/File Purpose
Desktop Files and shortcuts displayed on the desktop.
Documents Personal documents.
Downloads Downloaded files.
Pictures Image files.
Videos Video files.
.bashrc Bash shell configuration for interactive non-login shells.
.profile User login shell environment configuration.
.config Application-specific user configuration.

4. Difference Between /home and /root

Both /home and /root are directories, but they serve different purposes.

Feature /home /root
Purpose Parent directory for regular users' home directories. Home directory of the root user.
Users Regular user accounts. Root administrative account.
Example /home/navdeep /root
Access Normally accessible to the respective user. Usually restricted to root.
Do not confuse the root directory (/), the root user's home directory (/root), and regular users' home directories (/home/username). These are three different locations.

5. The Tilde (~) Shortcut

Linux uses the tilde character (~) as a shell shortcut for the current user's home directory.

For example, if the current user is navdeep:

~

It represents:

/home/navdeep

Command 1: cd ~

Moves to the current user's home directory.

cd ~ pwd
Example output: 
/home/navdeep

Command 2: cd

Running cd without an argument normally takes the user to their home directory.

cd pwd

Command 3: cd ~/Downloads

Moves to the Downloads directory inside the current user's home directory.

cd ~/Downloads pwd
Example output: 
/home/navdeep/Downloads

Command 4: ls ~

Lists the contents of the current user's home directory.

ls ~

6. Important Commands for Working with Home Directories

Command 1: pwd

Displays the current working directory.

pwd

Command 2: echo $HOME

Displays the HOME environment variable.

echo $HOME
Example output: 
/home/navdeep

Command 3: ls -la ~

Displays detailed information about the home directory, including hidden files.

ls -la ~

Command 4: mkdir

Creates a new directory inside the home directory.

mkdir ~/Linux_Practice

Command 5: touch

Creates an empty file.

touch ~/Linux_Practice/notes.txt

Command 6: cd

Moves into a directory.

cd ~/Linux_Practice

Command 7: cp

Copies a file.

cp notes.txt notes_backup.txt

Command 8: mv

Renames or moves a file.

mv notes_backup.txt backup.txt

Command 9: rm

Removes a file.

rm backup.txt
The rm command deletes files. Check the path and filename before executing it. Avoid using recursive deletion commands on important directories.

7. Hidden Files in the Home Directory

Linux allows files and directories to be hidden by starting their names with a dot (.).

Examples:

.bashrc .profile .config .local .ssh

These files and directories are commonly used for user-specific configuration, application data and shell settings.

List normal files

ls ~

List hidden files

ls -a ~

Display detailed information including hidden files

ls -la ~
A filename beginning with a dot is hidden from normal ls output. It is not encrypted or protected automatically.

8. Home Directory Permissions and Ownership

Each home directory normally belongs to its respective user. Permissions determine which users can read, write or access it.

Check ownership and permissions

ls -ld ~
Example output: 
drwxr-x---  25 navdeep navdeep 4096 Nov  5 06:00 /home/navdeep

The example is illustrative. Your actual username, group, permissions and directory information may differ.

Check the current username

whoami

Display user identity and groups

id

Display the home directory path

echo $HOME
Linux permissions are important for protecting personal files. A user normally has permission to manage their own home directory, while access by other users depends on the directory's permissions.

9. Home Directory and Environment Variables

Environment variables store information that programs and shell processes can use.

The HOME variable normally stores the path of the current user's home directory.

Display HOME

echo $HOME

Display the current user

echo $USER

Display the current shell

echo $SHELL

Display multiple environment variables

printenv HOME printenv USER printenv SHELL
HOME is an environment variable. The tilde (~) is expanded by the shell to the current user's home directory. They are related, but they are not the same type of thing.

10. Practical Lab – Create and Manage Files in Your Home Directory

Objective: Create directories and files, navigate through them and manage personal data.

Step 1: Open Ubuntu Terminal

Open your Ubuntu virtual machine and start the terminal.

Step 2: Display the Home Directory

echo $HOME

Step 3: Move to the Home Directory

cd ~ pwd

Step 4: List Home Directory Contents

ls -la

Step 5: Create a Practice Directory

mkdir Linux_Practice

Step 6: Enter the Practice Directory

cd Linux_Practice

Step 7: Create Two Files

touch notes.txt touch commands.txt

Step 8: List the Files

ls -l

Step 9: Add Text to a File

echo "Linux File System Practice" > notes.txt

Step 10: Read the File

cat notes.txt
Expected output: 
Linux File System Practice

Step 11: Create a Backup

cp notes.txt notes_backup.txt

Step 12: Rename the Backup

mv notes_backup.txt backup.txt

Step 13: Verify the Final Files

ls -l
Expected Result:
  • A Linux_Practice directory is created inside your home directory.
  • Two text files are created.
  • Text is written to notes.txt.
  • A backup file is copied and renamed.
  • You can view and verify the created files.

12. Interview Questions and Answers

Q1. What is a home directory in Linux?

A home directory is a personal directory assigned to a user for storing files, application settings and personal data.

Q2. Where are regular users' home directories commonly located?

They are commonly located under /home, for example /home/navdeep.

Q3. What does the tilde (~) represent?

It is a shell shortcut that represents the current user's home directory.

Q4. What is the difference between /home and /root?

/home contains regular users' home directories, while /root is the home directory of the root administrative user.

Q5. Which command displays the HOME environment variable?

echo $HOME

Q6. Which command moves to the home directory?

cd ~ or simply cd.

Q7. What are hidden files in Linux?

Files whose names begin with a dot (.) are hidden from normal directory listings.

Q8. Which command displays hidden files?

ls -a displays hidden entries.

Q9. What is the purpose of .bashrc?

It contains Bash configuration commands that are normally read when an interactive non-login Bash shell starts.

Q10. Which command displays the current user's identity?

whoami displays the effective username.

14. Lesson Summary

  • A home directory is a personal workspace assigned to a user.
  • Regular users' home directories are commonly stored under /home.
  • /root is the home directory of the root administrative user.
  • The tilde (~) represents the current user's home directory in the shell.
  • The HOME environment variable stores the user's home directory path.
  • Hidden files begin with a dot (.).
  • .bashrc stores interactive Bash shell configuration.
  • Permissions control access to home directory files.
  • Commands such as mkdir, touch, cp, mv and cat help manage personal files.
