Root Directory (/)

Understanding the top-level directory and its role in Linux

Home Linux Course Chapter 4

Learning Objectives

After completing this lesson, you will be able to:

  • Define the Linux root directory (/).
  • Understand the hierarchical structure below /.
  • Differentiate between /, /root and /home.
  • Navigate to the root directory using terminal commands.
  • Understand absolute paths that begin with /.
  • Identify important top-level directories.
  • Understand basic permissions and safe root-directory operations.

1. Introduction to the Root Directory

The root directory is the top-level directory in a Linux file system. It is represented by a single forward slash (/).

Every file and directory in the Linux directory hierarchy exists under this starting point. Other directories, such as /home, /etc, /usr and /var, are located inside the root hierarchy.

Important: The root directory (/) is the starting point of the entire file system. It is not the same as the root user's home directory (/root).

Example

/ ├── home ├── etc ├── usr ├── var ├── boot ├── dev └── root

In this simplified tree, all displayed directories are directly below the root directory.

2. Why is the Root Directory Important?

The root directory provides a common starting point for organizing the complete Linux file system.

Main functions

  • Central organization: Provides a single starting point for all directories.
  • System operation: Contains essential directories required by the operating system.
  • File access: Allows users and programs to access files using absolute paths.
  • Storage management: Provides locations where separate file systems can be mounted.
  • System administration: Organizes configuration, programs, logs and device interfaces.

3. Understanding Directories Under /

The root directory contains several important directories. Each directory has a defined purpose in the Linux system.

Directory Purpose
/bin Essential user command executables; commonly part of merged-/usr on modern Ubuntu.
/boot Kernel and boot-related files.
/dev Device-file interfaces.
/etc System-wide configuration files.
/home Home directories of regular users.
/lib Essential shared libraries and kernel-related modules; often linked into /usr.
/media Common mount location for removable media.
/mnt Traditional temporary mount point.
/opt Optional application software.
/proc Virtual process and kernel information.
/root Home directory of the root user.
/run Runtime information for processes and services.
/sbin System administration utilities; commonly part of merged-/usr.
/srv Data served by system services.
/sys Virtual kernel, device and driver information.
/tmp Temporary files.
/usr User-space applications, libraries and shared resources.
/var Variable data, including logs and caches.

4. Difference Between /, /root and /home

These three paths are important and should not be confused.

Path Meaning Example
/ Root of the entire file system. /etc, /usr, /home
/root Home directory of the root administrative user. /root/.bashrc
/home Parent directory for regular users' home directories. /home/navdeep
Common interview question: Is /root the same as /?

No. The path / represents the top-level file system directory, while /root is a directory under / that belongs to the root user.

5. Absolute Paths Starting from /

An absolute path specifies the complete location of a file or directory starting from the root directory.

Every absolute path in Linux begins with a forward slash (/).

Examples of absolute paths

/home/navdeep /etc/hostname /var/log /usr/bin /boot

Example: Access a configuration file

cat /etc/hostname

This command reads the hostname file using its absolute path.

Example: List the root directory

ls /
Example output: 
bin  boot  dev  etc  home  lib  media  mnt
opt  proc  root  run  sbin  srv  sys  tmp  usr  var

Actual output may differ depending on the Ubuntu version and installed software.

6. Navigating to the Root Directory

Command 1: cd /

Changes the current working directory to /.

cd /

Command 2: pwd

Displays the current working directory.

pwd
Output: 
/

Command 3: ls /

Lists the entries directly inside the root directory.

ls /

Command 4: ls -la /

Displays detailed information about entries in the root directory, including hidden entries.

ls -la /

Command 5: stat /

Displays metadata about the root directory.

stat /

7. Root Directory Permissions

Linux uses file permissions to control who can read, write or execute files and directories.

The root directory is normally owned by the root user and root group. Regular users generally have permission to read and traverse it, but cannot freely create, delete or modify entries directly under /.

Check permissions

ls -ld /
Example output: 
drwxr-xr-x  20 root root 4096 Nov  5 06:00 /

The exact permissions, directory count, size and date may vary.

Understanding permission symbols

Symbol Meaning
d Directory
r Read permission
w Write permission
x Execute permission; for directories, it allows traversal.
- Permission not granted
For a directory, read permission allows listing its entries, write permission allows modifying entries subject to other permission rules, and execute permission allows traversing it.

8. Mounting File Systems Under /

Linux uses a unified directory hierarchy. Separate partitions, storage devices and network file systems can be attached to directories called mount points.

For example:

/ ├── home ├── boot ├── etc ├── media │ └── usb-drive └── mnt └── data

A USB drive may be mounted under /media, while an administrator may mount another file system under /mnt/data.

View mounted file systems

findmnt

Display disk usage

df -h
A mount point is an existing directory where another file system becomes accessible. The mounted file system's contents appear through that directory.

9. Practical Lab – Exploring the Root Directory

Objective: Navigate the root directory and examine its contents and permissions.

Step 1: Open Ubuntu Terminal

Start Ubuntu in VirtualBox and open the terminal.

Step 2: Move to the Root Directory

cd /

Step 3: Verify the Current Location

pwd

Step 4: List Root Directory Entries

Step 5: Display Detailed Information

ls -la /

Step 6: Check Root Directory Permissions

ls -ld /

Step 7: Inspect the Root User's Home Directory

ls -ld /root

You may not be allowed to list the contents of /root as a regular user. That is expected on a normally configured system.

Step 8: Check Mounted File Systems

findmnt

Step 9: Check Disk Space

Expected Result:
  • Successfully navigate to /.
  • Display entries under the root directory.
  • Understand the permissions of / and /root.
  • View mounted file systems.
  • Identify the difference between / and /root.

10. Practical Exercise

Complete these tasks in your Ubuntu terminal:

  1. Navigate to / using the cd command.
  2. Verify your current location using pwd.
  3. List all entries in /.
  4. Display detailed information about /etc.
  5. Check the permissions of / using ls -ld /.
  6. Check the permissions of /root using ls -ld /root.
  7. Read the hostname using cat /etc/hostname.
  8. Display the mounted file systems using findmnt.
  9. Check disk usage using df -h.
  10. Identify the absolute path of your home directory using pwd after running cd ~.
Safety: Do not experiment with deleting or modifying system directories under /. Avoid commands such as rm -rf /*. Such commands can destroy the operating system and user data.

11. Interview Questions and Answers

Q1. What is the root directory in Linux?

The root directory (/) is the top-level directory from which the entire Linux file system hierarchy begins.

Q2. Is the root directory the same as the root user?

No. The root directory is a file system location, while the root user is the administrative account.

Q3. What is the difference between / and /root?

/ is the top-level directory, whereas /root is the home directory of the root user.

Q4. Which command moves to the root directory?

cd / changes the current working directory to /.

Q5. Which command displays the current directory?

pwd displays the current working directory.

Q6. What is an absolute path?

An absolute path specifies the complete location of a file or directory starting from /.

Q7. Why is the root directory important?

It provides the starting point for the Linux file system and organizes all system and user directories.

Q8. What is a mount point?

A mount point is a directory where another file system is attached and made accessible.

Q9. Which command displays root directory permissions?

ls -ld / displays the metadata and permissions of /.

Q10. Can a regular user modify files directly under /?

Normally, a regular user cannot modify entries directly under / because write permission is generally restricted to the root user.

12. Multiple Choice Questions (MCQs)

Q1. Which symbol represents the Linux root directory?

  1. ~
  2. /
  3. .
  4. ..

Correct Answer: B – /

Q2. Which directory is the home directory of the root user?

  1. /home
  2. /etc
  3. /root
  4. /usr

Correct Answer: C – /root

Q3. Which command moves to the root directory?

  1. cd ~
  2. cd ..
  3. cd /
  4. pwd

Correct Answer: C – cd /

Q4. Which command displays the current working directory?

  1. ls
  2. pwd
  3. mkdir
  4. touch

Correct Answer: B – pwd

Q5. Which of the following is an absolute path?

  1. documents/file.txt
  2. ../file.txt
  3. /home/user/file.txt
  4. ./file.txt

Correct Answer: C – /home/user/file.txt

Q6. Which command displays detailed information about /?

  1. ls -ld /
  2. pwd /
  3. cd -l /
  4. mkdir /

Correct Answer: A – ls -ld /

Q7. Which directory is commonly used as a mount point for removable media?

  1. /etc
  2. /media
  3. /proc
  4. /var

Correct Answer: B – /media

Q8. Which command displays mounted file systems?

  1. findmnt
  2. touch
  3. echo
  4. clear

Correct Answer: A – findmnt

Q9. Which user normally owns the root directory?

  1. guest
  2. nobody
  3. root
  4. student

Correct Answer: C – root

Q10. Which command displays disk space usage?

  1. df -h
  2. pwd
  3. cd /
  4. echo

Correct Answer: A – df -h

13. Lesson Summary

  • The root directory (/) is the top-level directory in Linux.
  • All Linux files and directories are organized under /.
  • /root is the home directory of the root user.
  • /home contains home directories of regular users.
  • Absolute paths begin with a forward slash.
  • cd / moves to the root directory.
  • pwd displays the current working directory.
  • ls -ld / displays root directory permissions.
  • Mount points allow separate file systems to be accessed within the directory hierarchy.
  • System directories should not be modified or deleted carelessly.
