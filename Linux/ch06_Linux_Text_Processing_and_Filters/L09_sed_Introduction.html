1. Introduction to the sed Command

sed stands for Stream Editor. It is a command-line text-processing utility used to search, replace, insert, delete and transform text.

sed processes input text line by line. It reads input, applies editing commands and normally sends the resulting text to standard output.

Common applications include:

  • Replacing words or characters.
  • Removing unwanted lines.
  • Displaying selected lines.
  • Editing configuration files.
  • Performing automated text transformations.
  • Processing text files in shell scripts.

Basic Syntax

sed [OPTIONS] 'COMMAND' FILE

Another common form uses a pipe:

command | sed 'COMMAND'

Example

echo "Linux is powerful" | sed 's/powerful/useful/'
Output:
Linux is useful
Explanation: sed searches for the word powerful and replaces its first occurrence on the line with useful.

2. Understanding Stream Editing

A stream is a continuous flow of input data. sed reads this data and applies editing instructions without requiring the original file to be changed.

Basic processing flow:

Input Text | v Read a Line | v Apply sed Editing Command | v Produce Modified Line | v Standard Output
By default, sed does not modify the original file. It prints the edited result to standard output. To change the original file, use the -i option carefully.

3. Substitution Command (s)

The substitution command is one of the most frequently used features of sed.

Syntax

sed 's/old_text/new_text/' filename

Here:

  • s means substitute.
  • old_text is the search pattern.
  • new_text is the replacement text.

Example 1: Replace a Word

echo "Linux is easy" | sed 's/easy/simple/'
Output:
Linux is simple

Example 2: Replace a Name

echo "My name is Rahul" | sed 's/Rahul/Navdeep/'
Output:
My name is Navdeep

Example 3: Replace a Number

echo "Employee ID: 1001" | sed 's/1001/2001/'
Output:
Employee ID: 2001
By default, the substitution command replaces only the first matching occurrence on each line.

4. Global Replacement (g)

The g flag replaces all matching occurrences on each line instead of only the first occurrence.

Syntax

sed 's/old_text/new_text/g' filename

Example 1: Replace Every Occurrence

echo "Linux is easy and Linux is useful" | sed 's/Linux/Ubuntu/g'
Output:
Ubuntu is easy and Ubuntu is useful

Example 2: Compare Without and With g

echo "cat cat cat" | sed 's/cat/dog/'
Output without g:
dog cat cat
echo "cat cat cat" | sed 's/cat/dog/g'
Output with g:
dog dog dog

5. Case-Insensitive Replacement (i)

The i flag makes a substitution pattern case-insensitive in GNU sed.

Example

echo "Linux linux LINUX" | sed 's/linux/Ubuntu/gi'
Output:
Ubuntu Ubuntu Ubuntu

The pattern linux matches Linux, linux and LINUX.

6. Working with Line Numbers

sed can select lines using their line numbers. This is useful when only particular lines need to be displayed, deleted or modified.

Example File

cat > students.txt << 'EOF' Amit Ravi Neha Priya Karan EOF

Example 1: Display a Specific Line

sed -n '2p' students.txt
Output:
Ravi

Example 2: Display Lines 2 to 4

sed -n '2,4p' students.txt
Output:
Ravi Neha Priya

Example 3: Display the First Line

sed -n '1p' students.txt
Output:
Amit

Example 4: Display the Last Line

sed -n '$p' students.txt
Output:
Karan
Explanation:
  • -n suppresses automatic printing.
  • p prints the selected line.
  • $ represents the last line.
  • 2,4p prints lines 2 through 4.

7. Deleting Lines (d)

The d command deletes selected lines from the output stream.

Example 1: Delete a Specific Line

sed '2d' students.txt
Output:
Amit Neha Priya Karan

Example 2: Delete Lines 2 to 4

sed '2,4d' students.txt
Output:
Amit Karan

Example 3: Delete the First Line

sed '1d' students.txt

Example 4: Delete the Last Line

sed '$d' students.txt
The d command removes lines from sed's output stream. It does not permanently delete those lines from the original file unless you save the result back to a file or use in-place editing.

8. Printing Lines (p)

The p command prints selected lines. It is commonly used with the -n option.

Example 1: Print Every Line Containing Linux

sed -n '/Linux/p' students.txt

This example prints lines containing the word Linux. If the file has no such line, there is no output.

Example 2: Print Lines Containing a Pattern

cat > systems.txt << 'EOF' Linux is open source Windows is widely used Linux supports shell scripting Ubuntu is Linux based EOF sed -n '/Linux/p' systems.txt
Output:
Linux is open source Linux supports shell scripting

9. Deleting Lines by Pattern

sed can identify lines containing a particular pattern and delete those lines.

Example 1: Delete Lines Containing Windows

sed '/Windows/d' systems.txt
Output:
Linux is open source Linux supports shell scripting Ubuntu is Linux based

Example 2: Delete Empty Lines

sed '/^$/d' file.txt

The pattern ^$ matches an empty line. The d command removes those lines from the output.

Example 3: Delete Lines Starting with #

sed '/^#/d' config.txt

This removes lines beginning with the # character.

10. In-Place Editing (-i)

The -i option allows sed to modify a file directly instead of only printing the result.

Example File

cat > data.txt << 'EOF' Linux is easy Linux is useful Linux is powerful EOF

Example 1: Replace Text in the Original File

sed -i 's/Linux/Ubuntu/g' data.txt

Verify the Changes

cat data.txt
Output:
Ubuntu is easy Ubuntu is useful Ubuntu is powerful

Example 2: Create a Backup Before Editing

sed -i.bak 's/Ubuntu/Linux/g' data.txt

This modifies data.txt and creates a backup file named data.txt.bak containing the previous version.

Warning: The -i option changes the file directly. Always check the command and consider creating a backup before editing important files.

11. Using sed with Regular Expressions

sed supports regular expressions for matching text patterns. This makes it useful for more advanced text processing.

Pattern Meaning
^ Beginning of a line.
$ End of a line.
. Any single character.
* Zero or more occurrences of the preceding expression.
[0-9] Any digit from 0 to 9.
[a-z] A lowercase English letter in the specified range.
[^0-9] Any character except a digit.

Example 1: Match Lines Starting with Linux

sed -n '/^Linux/p' systems.txt

Example 2: Match Lines Ending with Used

sed -n '/used$/p' systems.txt

Example 3: Replace All Digits with X

echo "Employee123" | sed 's/[0-9]/X/g'
Output:
EmployeeXXX
Basic sed regular expressions have some syntax differences from extended regular expressions. GNU sed supports the -E option for extended regular expressions.

12. Using a Different Delimiter

The slash character / is commonly used as a delimiter in sed substitution commands. When the search text contains a slash, another delimiter can make the command easier to read.

Example: Replace a Directory Path

echo "/home/user/documents" | sed 's#/home/user#/home/navdeep#'
Output:
/home/navdeep/documents

Here, # is used instead of / as the substitution delimiter.

13. Useful sed Commands and Options

Command / Option Purpose Example
s Substitute text. sed 's/old/new/'
g Replace all matches on each line. sed 's/a/b/g'
p Print selected lines. sed -n '2p'
d Delete selected lines. sed '2d'
-n Suppress automatic printing. sed -n '1,3p'
-i Edit file in place. sed -i 's/a/b/' file
-E Use extended regular expressions in GNU sed. sed -E 's/[0-9]+/X/'

15. Difference Between tr and sed

Feature tr sed
Full Form Translate Stream Editor
Main Purpose Character-level processing. Line-based text editing.
Character Replacement Yes. Yes.
Word or Pattern Replacement No. Yes.
Delete Selected Lines No. Yes.
Regular Expressions No. Yes.
In-Place File Editing No built-in option. Supported with -i.
Remember: Use tr for simple character transformations. Use sed when you need to search, replace, select or delete text patterns and lines.

16. Interview Questions and Answers

Q1. What is sed?

Answer: sed is a stream editor used to perform text transformations such as searching, replacing and deleting lines.

Q2. What does sed stand for?

Answer: Stream Editor.

Q3. What is the basic syntax of sed?

Answer: sed [OPTIONS] 'COMMAND' FILE.

Q4. What does the s command do?

Answer: It substitutes matching text with replacement text.

Q5. What is the purpose of the g flag?

Answer: It replaces all matching occurrences on each line.

Q6. What is the purpose of -n?

Answer: It suppresses automatic printing of lines.

Q7. What does the p command do?

Answer: It prints selected lines.

Q8. What does the d command do?

Answer: It deletes selected lines from the output stream.

Q9. What is the purpose of -i?

Answer: It edits a file in place.

Q10. Does sed modify the original file by default?

Answer: No. By default, sed prints the processed result to standard output.

Q11. How can you display only line 5?

Answer: Use sed -n '5p' filename.

Q12. How can you delete empty lines?

Answer: Use sed '/^$/d' filename.

18. Lesson Summary

  • sed stands for Stream Editor.
  • It processes text line by line.
  • s performs substitution.
  • g replaces all matches on each line.
  • i performs case-insensitive matching in GNU sed.
  • p prints selected lines.
  • d deletes selected lines from the output.
  • -n suppresses automatic printing.
  • -i edits a file in place.
  • sed supports regular expressions and line addressing.
Practical Importance: sed is widely used in Linux administration, shell scripting, configuration file editing, log processing and automated text manipulation.
