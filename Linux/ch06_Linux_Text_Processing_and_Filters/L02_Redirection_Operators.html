LINUX PROGRAMMING • CHAPTER 6 • LESSON 2

Redirection Operators

Managing Input, Output and Error Streams in Linux

Home Linux Course Chapter 6

Learning Objectives

After completing this lesson, you will be able to:

  • Understand input and output redirection in Linux.
  • Use the greater-than and less-than operators.
  • Differentiate between overwriting and appending output.
  • Redirect standard output and standard error independently.
  • Combine stdout and stderr into one destination.
  • Use the null device to discard unwanted output.
  • Understand here-documents and here-strings.

1. Introduction to Redirection

In Linux, redirection is a mechanism that changes the default source or destination of a command's input and output streams.

Normally, commands receive input from the terminal and display output or error messages on the terminal. Redirection allows these streams to be connected to files or other destinations.

Example:
echo "Hello Linux" > output.txt
Instead of displaying the message on the terminal, this command writes it to output.txt.

Redirection is useful for saving command results, processing files, recording errors, and automating shell scripts.

2. Redirection Operators

Linux provides different operators to redirect standard input, standard output, and standard error.

Operator Purpose
> Redirect stdout to a file, overwriting its contents.
>> Append stdout to a file.
< Read stdin from a file.
2> Redirect stderr to a file, overwriting it.
2>> Append stderr to a file.
&> Redirect stdout and stderr to the same file in Bash.
<< Provide multiple lines of input using a here-document.
<<< Provide a single string as input using a here-string in Bash.

3. Output Redirection ( > )

The greater-than operator redirects standard output to a file. If the file does not exist, it is created. If it already exists, its previous contents are overwritten.

Syntax

command > filename

Example 1: Redirect echo Output

echo "Welcome to Linux" > output.txt

This command writes the text into output.txt.

Example 2: Display the File Contents

cat output.txt
Output:
Welcome to Linux

Example 3: Overwrite Existing Contents

echo "First line" > data.txt echo "Second line" > data.txt cat data.txt
Output:
Second line
Warning: The > operator overwrites the existing file contents. Use it carefully when working with important data.

4. Append Redirection ( >> )

The double greater-than operator appends standard output to the end of a file without deleting its existing contents.

Syntax

command >> filename

Example 1: Create a File

echo "Linux Basics" > notes.txt

Example 2: Append More Text

echo "Linux Commands" >> notes.txt echo "Shell Scripting" >> notes.txt

Example 3: Display File Contents

cat notes.txt
Output:
Linux Basics Linux Commands Shell Scripting
Use > to overwrite a file and >> to append data.

5. Input Redirection ( < )

The less-than operator redirects standard input from a file instead of the keyboard or terminal.

Syntax

command < filename

Example 1: Create an Input File

echo "Learning Linux" > input.txt echo "Understanding redirection" >> input.txt

Example 2: Read the File Using Input Redirection

cat < input.txt
Output:
Learning Linux Understanding redirection

Example 3: Count Words from a File

wc -w < input.txt
Example Output:
4

The output shows the word count. Because input was redirected, wc does not need a filename argument.

6. Standard Error Redirection ( 2> )

The 2> operator redirects standard error to a file. It is useful for saving error messages separately from normal output.

Syntax

command 2> error.txt

Example 1: Redirect an Error Message

ls /nonexistent_directory 2> error.txt

The error message is written to error.txt instead of being displayed on the terminal.

Example 2: Read the Error File

cat error.txt
Example Output:
ls: cannot access '/nonexistent_directory': No such file or directory

Example 3: Append Error Messages

ls /wrong_path 2>> error.txt

This appends the new error message to error.txt without overwriting its existing contents.

7. Redirecting Standard Output and Standard Error Together

Sometimes both normal output and error messages need to be saved in the same file.

Method 1: Bash &> Operator

command &> output.txt

In Bash, this redirects both stdout and stderr to output.txt, overwriting the file.

Example

ls /etc /wrong_directory &> result.txt

Normal output and the error message are both redirected to result.txt.

Method 2: Standard Shell Redirection

command > output.txt 2>&1

This redirects stdout to output.txt and then redirects stderr to the same destination as stdout.

Example

ls /etc /wrong_directory > result.txt 2>&1

Append Both Streams

command >> output.txt 2>&1

This appends both standard output and standard error to the file.

Important: Redirection order matters. In command > output.txt 2>&1, stderr is directed to the destination already assigned to stdout.

8. Discarding Output Using /dev/null

Linux provides a special device file called /dev/null. Data written to this device is discarded.

It is commonly used when command output or error messages are not required.

Example 1: Discard Standard Output

ls /etc > /dev/null

The normal directory listing is discarded.

Example 2: Discard Standard Error

ls /wrong_directory 2> /dev/null

The error message is discarded.

Example 3: Discard Both Streams

command > /dev/null 2>&1

Both standard output and standard error are discarded.

/dev/null is often called the null device or a data sink.

9. Here-Document ( << )

A here-document provides multiple lines of input directly to a command or program through standard input.

Syntax

command << DELIMITER line 1 line 2 DELIMITER

The delimiter marks the beginning and end of the input. It must appear by itself on the closing line.

Example: Using cat

cat << EOF Welcome to Linux Learning text processing NS Learning Hub EOF
Output:
Welcome to Linux Learning text processing NS Learning Hub

The text between the two EOF markers is passed to cat as standard input.

Quoted Delimiter

cat << 'EOF' The value of $HOME is not expanded here. EOF

Quoting the delimiter prevents parameter and command expansion in the here-document body in Bash.

10. Here-String ( <<< )

A here-string supplies a single string as standard input to a command. It is supported by Bash and some other shells.

Syntax

command <<< "text"

Example 1: Count Words

wc -w <<< "Linux is powerful"
Example Output:
3

Example 2: Convert Text to Uppercase

tr 'a-z' 'A-Z' <<< "hello linux"
Output:
HELLO LINUX

11. Important Redirection Operators Summary

Command Meaning
command > file Redirect stdout and overwrite file.
command >> file Append stdout to file.
command < file Read stdin from file.
command 2> file Redirect stderr and overwrite file.
command 2>> file Append stderr to file.
command &> file Redirect stdout and stderr in Bash.
command > file 2>&1 Redirect both streams to the same file.
command > /dev/null Discard stdout.
command 2> /dev/null Discard stderr.
command << EOF Provide multiple lines through a here-document.
command <<< "text" Provide a string through a here-string.

13. Common Mistakes and Precautions

  • Using > instead of >> when existing file contents must be preserved.
  • Using 1> when the intention is to redirect standard error.
  • Forgetting that stderr uses file descriptor 2.
  • Using the wrong order in combined redirection.
  • Assuming <<< works in every shell; it is a Bash feature and is not POSIX shell syntax.
  • Accidentally overwriting important files.
Important: The command command 2>&1 > file is not equivalent to command > file 2>&1. Redirections are processed from left to right.

14. Interview Questions and Answers

Q1. What is redirection in Linux?

Answer: Redirection changes the default input or output destination of a command.

Q2. What does the > operator do?

Answer: It redirects standard output to a file and overwrites the file's existing contents.

Q3. What is the difference between > and >>?

Answer: > overwrites a file, whereas >> appends data to the end of a file.

Q4. What does the < operator do?

Answer: It redirects standard input from a file.

Q5. What is the purpose of 2>?

Answer: It redirects standard error to a file.

Q6. What does 2>> do?

Answer: It appends standard error messages to a file.

Q7. What does 2>&1 mean?

Answer: It redirects standard error to the current destination of standard output.

Q8. What is /dev/null?

Answer: It is a special device file that discards data written to it.

Q9. What is a here-document?

Answer: It provides multiple lines of input directly to a command using the << operator.

Q10. What is a here-string?

Answer: It supplies a single string as standard input using the <<< operator in Bash.

  • 2> redirects stderr to a file.
  • 2>> appends stderr to a file.
