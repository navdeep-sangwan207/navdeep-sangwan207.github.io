tr Command

Translating, Deleting and Squeezing Characters in Linux

Home Linux Course Chapter 6

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose and working of the tr command.
  • Translate lowercase characters into uppercase and vice versa.
  • Replace one set of characters with another.
  • Delete selected characters from input.
  • Squeeze repeated characters.
  • Use character classes and ranges.
  • Combine tr with pipes and other Linux commands.

1. Introduction to the tr Command

The tr command stands for translate. It is a Linux command-line utility used to translate, delete or squeeze characters from standard input.

Common applications include:

  • Converting lowercase letters into uppercase.
  • Converting uppercase letters into lowercase.
  • Replacing one character with another.
  • Removing unwanted characters.
  • Reducing repeated spaces or characters.
  • Preparing text for further processing.

Basic Syntax

tr [OPTION] SET1 [SET2]

The tr command normally reads data from standard input and writes the processed result to standard output.

Important: tr does not normally accept a filename as a positional input argument. Use input redirection or a pipe to provide file contents.

Example: Using echo with tr

echo "linux command" | tr 'a-z' 'A-Z'
Output:
LINUX COMMAND

2. Translating Characters

Character translation replaces characters from SET1 with corresponding characters from SET2.

Syntax

tr 'SET1' 'SET2'

Example 1: Lowercase to Uppercase

echo "hello linux" | tr 'a-z' 'A-Z'
Output:
HELLO LINUX

Example 2: Uppercase to Lowercase

echo "HELLO LINUX" | tr 'A-Z' 'a-z'
Output:
hello linux

Example 3: Replace Spaces with Underscores

echo "Linux Operating System" | tr ' ' '_'
Output:
Linux_Operating_System

Example 4: Replace Digits with X

echo "Room 204 and Room 305" | tr '0-9' 'X'
Output:
Room XXX and Room XXX
When SET2 is shorter than SET1, tr normally reuses the final character of SET2 for the remaining characters in SET1. The example above therefore replaces every digit with X.

3. Using Character Classes

Character classes allow tr to work with predefined groups of characters instead of writing every character manually.

Character Class Meaning
[:lower:] Lowercase letters.
[:upper:] Uppercase letters.
[:digit:] Digits from 0 to 9.
[:alpha:] Alphabetic characters.
[:alnum:] Letters and digits.
[:space:] Whitespace characters.
[:punct:] Punctuation characters.

Example 1: Convert Lowercase to Uppercase

echo "linux programming" | tr '[:lower:]' '[:upper:]'
Output:
LINUX PROGRAMMING

Example 2: Convert Uppercase to Lowercase

echo "LINUX PROGRAMMING" | tr '[:upper:]' '[:lower:]'
Output:
linux programming

Example 3: Replace Digits with Asterisks

echo "Employee ID 12345" | tr '[:digit:]' '*'
Output:
Employee ID *****

4. Deleting Characters (-d)

The -d option deletes all characters belonging to the specified set.

Syntax

tr -d 'SET'

Example 1: Delete All Digits

echo "Linux123System456" | tr -d '0-9'
Output:
LinuxSystem

Example 2: Delete Spaces

echo "Linux Operating System" | tr -d ' '
Output:
LinuxOperatingSystem

Example 3: Delete Vowels

echo "Operating System" | tr -d 'aeiouAEIOU'
Output:
pr tng Systm

Example 4: Delete Punctuation

echo "Hello, Linux! Welcome." | tr -d '[:punct:]'
Output:
Hello Linux Welcome

5. Squeezing Repeated Characters (-s)

The -s option squeezes repeated occurrences of characters in the specified set into a single occurrence.

Syntax

tr -s 'SET'

Example 1: Remove Repeated Spaces

echo "Linux Operating System" | tr -s ' '
Output:
Linux Operating System

Example 2: Squeeze Repeated Letters

echo "Hellooo Liiinux" | tr -s 'o i'
Output:
Helo Linux

Example 3: Squeeze Repeated Newline Characters

printf 'Linux\n\n\nSystem\n\n' | tr -s '\n'
Output:
Linux System
Note: tr -s only squeezes characters included in the specified set. It does not automatically remove all repeated characters.

6. Complementing a Character Set (-c)

The -c option complements the specified character set. It allows operations on characters that are not included in the specified set.

Example 1: Replace Non-Alphanumeric Characters

echo "Linux@123 System!" | tr -c '[:alnum:]\n' '_'
Output:
Linux_123_System_

Here, letters, digits and newline characters are preserved. Other characters are replaced with underscores.

Example 2: Keep Only Digits

echo "Room 204, Block 5" | tr -cd '0-9\n'
Output:
2045
Explanation: -c selects characters outside the specified set, while -d deletes those selected characters. Therefore, -cd keeps the specified digits and newline characters.

7. Combining tr Options

The tr command supports combining options such as -d, -s and -c.

Example 1: Delete Digits and Squeeze Spaces

echo "Linux 123 System 456" | tr -d '0-9' | tr -s ' '
Output:
Linux System

Example 2: Convert to Uppercase and Remove Digits

echo "Linux123 programming456" | tr '[:lower:]' '[:upper:]' | tr -d '0-9'
Output:
LINUX PROGRAMMING

Example 3: Replace Spaces with Newlines

echo "Linux Shell Scripting" | tr ' ' '\n'
Output:
Linux Shell Scripting

8. Using tr with Files

Since tr reads standard input, input redirection is used to process an existing file.

Example 1: Create a Text File

cat > sample.txt << 'EOF' linux is an operating system command line tools are useful text processing is important EOF

Example 2: Convert File Contents to Uppercase

tr '[:lower:]' '[:upper:]' < sample.txt
Output:
LINUX IS AN OPERATING SYSTEM COMMAND LINE TOOLS ARE USEFUL TEXT PROCESSING IS IMPORTANT

Example 3: Save Converted Output

tr '[:lower:]' '[:upper:]' < sample.txt > uppercase.txt cat uppercase.txt

This stores the converted text in uppercase.txt.

Example 4: Remove Digits from a File

tr -d '0-9' < sample.txt

This displays the file contents after deleting digits.

Important: Use a different output filename when redirecting transformed input. A command such as tr ... < sample.txt > sample.txt can truncate the file before tr reads it.

9. Common Character Sets and Escape Sequences

Expression Meaning
a-z Lowercase English letters.
A-Z Uppercase English letters.
0-9 Digits.
\n Newline character.
\t Tab character.
[:space:] Whitespace character class.
[:digit:] Digit character class.
[:alpha:] Alphabetic character class.
Character ranges such as a-z can depend on the active locale. Character classes such as [:lower:] and [:upper:] are useful for locale-aware character processing.

10. Important tr Options

Option Purpose Example
-d Delete selected characters. tr -d '0-9'
-s Squeeze repeated selected characters. tr -s ' '
-c Complement the specified set. tr -cd '0-9'

GNU tr also supports --truncate-set1, which truncates SET1 to the length of SET2 during translation.

12. Common Mistakes

Mistake Correction
Using tr with a filename as if it were a file-processing command. Use input redirection or a pipe.
Confusing -d with -s. -d deletes characters; -s squeezes repeated characters.
Using the wrong character range. Check the SET1 and SET2 values carefully.
Expecting tr to replace complete words. tr works on individual characters, not words or regular expressions.
Overwriting the input file using the same redirection target. Write output to a different file.
Assuming tr understands quoted CSV fields. Use a CSV-aware tool for structured CSV data.

13. Interview Questions and Answers

Q1. What is the tr command?

Answer: tr is a Linux utility used to translate, delete and squeeze characters from standard input.

Q2. What does tr stand for?

Answer: Translate.

Q3. How do you convert lowercase letters to uppercase?

Answer: Use tr 'a-z' 'A-Z' or tr '[:lower:]' '[:upper:]'.

Q4. What is the purpose of the -d option?

Answer: It deletes characters belonging to the specified set.

Q5. What is the purpose of the -s option?

Answer: It squeezes repeated occurrences of selected characters into one occurrence.

Q6. What does the -c option do?

Answer: It complements the specified character set.

Q7. Does tr directly accept a filename?

Answer: No. It normally reads from standard input. Use input redirection or a pipe.

Q8. How can you remove all digits from a string?

Answer: Use tr -d '0-9'.

Q9. How can you replace spaces with underscores?

Answer: Use tr ' ' '_'.

Q10. Can tr replace complete words?

Answer: No. tr operates on individual characters. Use tools such as sed for text-pattern replacement.

15. Lesson Summary

  • tr translates, deletes and squeezes characters.
  • tr 'a-z' 'A-Z' converts lowercase to uppercase.
  • tr 'A-Z' 'a-z' converts uppercase to lowercase.
  • tr -d deletes selected characters.
  • tr -s squeezes repeated selected characters.
  • tr -c complements a character set.
  • [:digit:] represents digits.
  • [:lower:] represents lowercase letters.
  • [:upper:] represents uppercase letters.
  • tr reads standard input and can be combined with pipes and redirection.
Practical Importance: The tr command is useful in shell scripting, text normalization, character conversion, cleaning command output and preparing data for further processing.
