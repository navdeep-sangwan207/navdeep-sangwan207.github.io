sort and uniq Commands

Sorting Text and Removing Duplicate Lines in Linux

1. Introduction to the sort Command

The sort command is a Linux utility used to arrange lines of text in a particular order. By default, it sorts lines according to their character-based order.

It is useful for:

  • Arranging names alphabetically.
  • Sorting numbers.
  • Organizing records and text files.
  • Preparing data for duplicate removal.
  • Processing command output and log files.

Basic Syntax

sort [options] filename

Explanation:

  • sort – command used to arrange lines.
  • options – control the sorting method.
  • filename – input file to be sorted.

Example

cat > names.txt << 'EOF' Ravi Amit Neha Priya Rahul EOF sort names.txt
Output:
Amit Neha Priya Rahul Ravi

The original file is not changed. The sorted result is displayed on the terminal.

2. Important sort Options

Option Purpose Example
-r Sort in reverse order. sort -r names.txt
-n Sort numerically. sort -n numbers.txt
-u Output one line for each equal sorting key. sort -u names.txt
-f Ignore case differences while sorting. sort -f names.txt
-k Sort using a specified field or key. sort -k 2 data.txt
-t Specify the field separator. sort -t ',' -k 2 data.csv
-o Write sorted output to a file. sort -o result.txt names.txt
-c Check whether input is already sorted. sort -c names.txt
-M Sort month names by calendar order. sort -M months.txt

3. Sorting in Different Orders

3.1 Alphabetical Sorting

sort names.txt

Arranges lines in the default character-based order.

3.2 Reverse Sorting

sort -r names.txt
Example output:
Rahul Priya Neha Ravi Amit

The -r option reverses the sorting order.

3.3 Case-Insensitive Sorting

cat > case.txt << 'EOF' banana Apple cherry apple Banana EOF sort -f case.txt

The -f option ignores case differences when comparing lines.

3.4 Sorting Numbers

Create a file containing numbers:

cat > numbers.txt << 'EOF' 100 20 3 45 9 EOF

Run a normal sort:

sort numbers.txt
Output:
100 20 3 45 9

This is character-based sorting, not numerical sorting.

Now use numerical sorting:

sort -n numbers.txt
Output:
3 9 20 45 100
Important: Use -n when sorting ordinary numeric values. Without it, values may be ordered according to their textual representation.

3.5 Reverse Numerical Sorting

sort -nr numbers.txt
Output:
100 45 20 9 3

4. Sorting Using Fields and Columns

The -k option allows sorting based on a particular field in each line. The -t option specifies the character separating fields.

Example 1: Sorting by Second Field

cat > employees.txt << 'EOF' 101 Ravi 25000 102 Amit 18000 103 Neha 30000 104 Priya 22000 EOF sort -k 2 employees.txt

This sorts the records using the second field, which contains employee names.

Example 2: Sorting by Salary Numerically

sort -k 3 -n employees.txt
Output:
102 Amit 18000 104 Priya 22000 101 Ravi 25000 103 Neha 30000

Example 3: Sorting CSV Data

cat > employees.csv << 'EOF' 101,Ravi,25000 102,Amit,18000 103,Neha,30000 104,Priya,22000 EOF sort -t ',' -k 3,3n employees.csv

Explanation:

  • -t ',' sets the comma as the field separator.
  • -k 3,3n sorts using the third field numerically.
The sort field options shown here use GNU sort syntax, as commonly available in Ubuntu.

5. Saving Sorted Output

The -o option writes sorted output to a specified file.

sort -o sorted_names.txt names.txt

Display the result:

cat sorted_names.txt

You can also use output redirection:

sort names.txt > sorted_names.txt
Warning: Avoid using sort names.txt > names.txt. The shell may truncate the input file before sort reads it. Use a different output file or the appropriate -o option instead.

6. Introduction to the uniq Command

The uniq command is used to detect, remove or count repeated adjacent lines in text input.

It is commonly used for:

  • Removing consecutive duplicate lines.
  • Counting repeated lines.
  • Displaying only duplicate lines.
  • Displaying only unique lines.
  • Analyzing repeated entries in files and logs.

Basic Syntax

uniq [options] input_file [output_file]

Example

cat > fruits.txt << 'EOF' Apple Apple Banana Banana Orange Apple EOF uniq fruits.txt
Output:
Apple Banana Orange Apple

uniq removes adjacent duplicate lines. The final Apple remains because it is not adjacent to the first Apple group.

Important: uniq does not automatically remove duplicates that appear in different locations in a file.

7. Important uniq Options

Option Purpose Example
-c Count occurrences of each adjacent line group. uniq -c fruits.txt
-d Display only repeated adjacent lines. uniq -d fruits.txt
-u Display only lines that occur once in their group. uniq -u fruits.txt
-i Ignore case differences when comparing lines. uniq -i fruits.txt
-D Display all lines from repeated groups. uniq -D fruits.txt

7.1 Count Duplicate Lines (-c)

uniq -c fruits.txt
Output:
2 Apple 2 Banana 1 Orange 1 Apple

7.2 Display Only Duplicate Lines (-d)

uniq -d fruits.txt
Output:
Apple Banana

7.3 Display Only Non-Repeated Lines (-u)

uniq -u fruits.txt
Output:
Orange Apple

Here, the final Apple appears only once in its adjacent group.

7.4 Ignore Case (-i)

cat > case_fruits.txt << 'EOF' Apple apple Banana BANANA EOF uniq -i case_fruits.txt

Adjacent lines that differ only in letter case are treated as equivalent for comparison.

8. Difference Between sort and uniq

sort uniq
Arranges lines in a specified order. Processes adjacent duplicate lines.
Can sort alphabetically or numerically. Can remove or count repeated adjacent lines.
Uses options such as -n, -r and -k. Uses options such as -c, -d and -u.
Does not remove duplicates by default. Removes adjacent duplicates by default.
Often prepares data for uniq. Often follows sort in a pipeline.

9. Combining sort and uniq

Since uniq works on adjacent duplicate lines, sort is commonly used before uniq to bring equal lines together.

Example: Remove All Duplicate Entries

sort fruits.txt | uniq

Explanation:

  1. sort fruits.txt arranges identical entries together.
  2. The pipe sends the sorted output to uniq.
  3. uniq removes adjacent duplicate lines.
Example output:
Apple Banana Orange

Count All Occurrences

sort fruits.txt | uniq -c

Display Only Duplicate Entries

sort fruits.txt | uniq -d

Display Only Entries That Occur Once

sort fruits.txt | uniq -u

Sort and Remove Duplicates in One Command

sort -u fruits.txt
Note: sort -u sorts the input and produces one output line for each equal sorting key. It is a convenient alternative when you need sorted, deduplicated output.

10. Using sort and uniq with Pipes

Example 1: Count Repeated Words

cat words.txt | sort | uniq -c

Example 2: Find Frequently Repeated Entries

sort words.txt | uniq -c | sort -nr

This command:

  1. Sorts the input lines.
  2. Counts adjacent repeated lines.
  3. Sorts the counts numerically in reverse order.

Example 3: Process Log Entries

grep -i "error" system.log | sort | uniq -c

This searches for error messages, sorts matching lines and counts repeated adjacent entries.

Example 4: Find Unique Usernames

sort usernames.txt | uniq

This displays each distinct username once, in sorted order.

12. Common Mistakes

Mistake Correction
Using sort without -n for numeric values. Use sort -n for numerical sorting.
Expecting uniq to remove duplicates anywhere in a file. Use sort file | uniq to group duplicates first.
Using uniq -c without sorting when counting all repeated entries. Use sort file | uniq -c.
Assuming sort changes the original file. Use -o or redirection to save output.
Confusing sort -u with uniq -u. sort -u removes duplicate sorting keys; uniq -u displays lines occurring once in each adjacent group.

13. Interview Questions and Answers

Q1. What is the sort command?

Answer: sort is a Linux command used to arrange lines of text in a specified order.

Q2. What is the default sorting behaviour of sort?

Answer: It sorts lines according to their character-based order under the active locale.

Q3. Which option is used for numerical sorting?

Answer: The -n option.

Q4. What is the purpose of sort -r?

Answer: It sorts lines in reverse order.

Q5. What is the uniq command?

Answer: uniq is used to remove, count or display repeated adjacent lines.

Q6. Why is sort commonly used before uniq?

Answer: Because uniq normally processes adjacent duplicate lines. Sorting groups equal lines together.

Q7. What does uniq -c do?

Answer: It displays each adjacent line group along with its count.

Q8. What is the difference between uniq -d and uniq -u?

Answer: -d displays repeated groups, while -u displays groups occurring only once.

Q9. What does sort -u do?

Answer: It sorts input and outputs one line for each equal sorting key.

Q10. How can you count duplicate entries in a file?

Answer: Use sort filename | uniq -c.

15. Lesson Summary

  • sort arranges lines in a specified order.
  • sort -r sorts in reverse order.
  • sort -n performs numerical sorting.
  • sort -f ignores case differences while sorting.
  • sort -k selects a field or key for sorting.
  • sort -t specifies the field separator.
  • sort -u produces sorted output without duplicate sorting keys.
  • uniq processes adjacent duplicate lines.
  • uniq -c counts adjacent line groups.
  • uniq -d displays repeated groups.
  • uniq -u displays groups occurring only once.
  • sort file | uniq sorts and removes duplicate lines.
Practical Importance: sort and uniq are useful for text processing, log analysis, data organization, shell scripting and Linux system administration. They are frequently combined with grep, cut, wc and other command-line utilities.
