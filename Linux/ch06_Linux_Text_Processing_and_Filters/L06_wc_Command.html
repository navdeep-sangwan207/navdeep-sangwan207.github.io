The wc Command

Counting Lines, Words, Characters and Bytes in Linux

Home Linux Course Chapter 6

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the wc command.
  • Count lines, words, bytes and characters in files.
  • Use important wc options.
  • Count information from multiple files.
  • Use wc with pipes and other Linux commands.
  • Apply wc in shell scripting and practical text processing.

1. Introduction to the wc Command

The wc command is a Linux utility used to count lines, words, bytes and characters in a file or input stream.

The name wc stands for word count. It is commonly used to analyse text files, source code, log files and command output.

Basic Syntax

wc [options] filename

Explanation:

  • wc – command used for counting.
  • options – specify what should be counted.
  • filename – file to analyse.

Example

cat > notes.txt << 'EOF' Linux is an operating system. It supports multiple users. Linux is widely used in servers. EOF wc notes.txt
Example output:
3 13 84 notes.txt

The default output contains:

  1. Number of lines.
  2. Number of words.
  3. Number of bytes.
  4. Filename.
The exact counts depend on the file contents and line-ending format. The output shown above is illustrative.

2. Important wc Options

Option Purpose Example
-l Count newline characters (commonly used to count lines). wc -l notes.txt
-w Count words. wc -w notes.txt
-c Count bytes. wc -c notes.txt
-m Count characters. wc -m notes.txt
-L Display the length of the longest line in characters. wc -L notes.txt
These options are available in GNU wc, which is commonly used in Ubuntu Linux.

3. Counting Lines (-l)

The -l option counts newline characters. For ordinary text files ending each line with a newline, this gives the number of lines.

Syntax

wc -l filename

Example

wc -l notes.txt
Example output:
3 notes.txt

This indicates that the file contains three newline-terminated lines.

Important: wc -l counts newline characters, not abstract text lines. A final line without a terminating newline may not be included in the count.

4. Counting Words (-w)

The -w option counts words in a file. A word is generally a sequence of non-whitespace characters separated by whitespace.

Syntax

wc -w filename

Example

wc -w notes.txt
Example output:
13 notes.txt

The output represents the number of words in the file.

5. Counting Bytes (-c)

The -c option counts the total number of bytes in a file.

Syntax

wc -c filename

Example

wc -c notes.txt
Example output:
84 notes.txt

Bytes represent the amount of encoded data stored in the file. A character may occupy one or more bytes depending on its encoding.

6. Counting Characters (-m)

The -m option counts characters rather than bytes.

Syntax

wc -m filename

Example

wc -m notes.txt

The output gives the character count according to the active character encoding and locale.

Difference between bytes and characters:
  • wc -c counts bytes.
  • wc -m counts characters.
For ASCII text, one character generally occupies one byte. In UTF-8, some characters occupy multiple bytes.

7. Finding the Longest Line (-L)

The -L option displays the length of the longest line in the file, measured in characters.

Syntax

wc -L filename

Example

wc -L notes.txt

The output is a number representing the length of the longest line.

This option can help analyse source code, text files and log entries.

8. Using Multiple Options Together

You can combine options to count more than one type of information.

Example 1: Count Lines and Words

wc -lw notes.txt

Example 2: Count Lines, Words and Bytes

wc -lwc notes.txt

Example 3: Count Characters and Lines

wc -lm notes.txt
The order of options in a combined command does not change the meaning of the individual options.

9. Counting Multiple Files

wc can accept multiple filenames and display the counts for each file, followed by a total.

Example

wc notes.txt students.txt
Example output:
3 13 84 notes.txt 5 10 65 students.txt 8 23 149 total

The final line displays the combined totals.

Count Lines in Multiple Files

wc -l *.txt

This counts newline characters in all files matching *.txt in the current directory.

Count Words in Multiple Files

wc -w *.txt

10. Using wc with Pipes

wc can receive input from another command through a pipe. This allows counting command output without creating a separate file.

Example 1: Count Files and Directories

ls | wc -l

Counts the number of output lines produced by ls. This is commonly used as a quick count of visible entries, but it is not a reliable general-purpose filesystem inventory.

Example 2: Count Matching Lines

grep "Linux" notes.txt | wc -l

Counts the number of lines containing Linux.

Example 3: Count Running Processes

ps -e | wc -l

Counts the output lines from the process listing, including its header line when present.

Example 4: Count Words from a Command

cat notes.txt | wc -w

Counts words from the contents of notes.txt.

When counting a file directly, prefer wc -w notes.txt instead of cat notes.txt | wc -w. The direct form avoids an unnecessary process.

11. Counting Lines in Source Code

wc is frequently used by programmers to estimate the number of lines in source code files.

Count Lines in a C File

wc -l main.c

Count Lines in Multiple C Files

wc -l *.c

Count Lines in C and Header Files

wc -l *.c *.h

Count Lines in a Directory Recursively

find . -type f -name "*.c" -exec wc -l {} +

This finds C source files below the current directory and runs wc on them.

The line count includes blank lines and comment lines. It is not the same as the number of executable statements or logical lines of code.

13. Common Mistakes

Mistake Correction
Using wc without understanding its default output. Remember that default output contains lines, words and bytes.
Using -c to count characters. Use -m for characters and -c for bytes.
Assuming wc -l always counts every visible text line. It counts newline characters; a final unterminated line may not be counted.
Using wc -w to count only spaces. It counts whitespace-separated words.
Assuming source-code line counts equal executable statements. Blank lines and comments are included in ordinary line counts.

14. Interview Questions and Answers

Q1. What is the wc command?

Answer: wc is a Linux utility used to count lines, words, bytes and characters.

Q2. What is the full form of wc?

Answer: Word Count.

Q3. Which option counts lines?

Answer: -l.

Q4. Which option counts words?

Answer: -w.

Q5. What is the difference between wc -c and wc -m?

Answer: -c counts bytes, while -m counts characters.

Q6. What does wc -L display?

Answer: The length of the longest line.

Q7. Can wc process multiple files?

Answer: Yes. It displays counts for each file and a combined total.

Q8. Can wc receive input through a pipe?

Answer: Yes. wc can count data received from another command through standard input.

Q9. How can you count lines containing a specific word?

Answer: Use grep "word" filename | wc -l.

Q10. Does wc -l count blank lines?

Answer: Yes, blank lines terminated by newline characters contribute to the count.
