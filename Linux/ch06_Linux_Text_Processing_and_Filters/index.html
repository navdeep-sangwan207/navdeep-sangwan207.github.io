Linux Programming Course | NS Learning Hub

Chapter Overview

Text processing is an important part of Linux system administration and shell scripting. Linux provides several commands and utilities to read, search, filter, transform, and manipulate text data.

In this chapter, you will learn standard input and output, redirection, pipes, and commonly used text-processing commands such as grep, sort, uniq, wc, cut, paste, tr, sed, and awk.
