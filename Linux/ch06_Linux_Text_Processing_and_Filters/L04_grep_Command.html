The grep Command

Searching Text Patterns in Files and Command Output

  • Search for words and patterns in text files.
  • Use grep options such as -i, -n, -v, -r and -w.
  • Search multiple files and directories.
  • Use grep with pipes and other Linux commands.
  • Understand basic regular expressions used with grep.

1. Introduction to grep

grep is a Linux command-line utility used to search for lines that match a specified text pattern in files or input received from another command.

It is commonly used for searching log files, configuration files, source code, command output and other text-based information.

Full form: grep is commonly expanded as "Global Regular Expression Print". It searches input for matching patterns and displays matching lines.

Basic Syntax

grep [options] "pattern" filename

Explanation:

  • grep – command used for searching.
  • options – control how the search is performed.
  • pattern – word, text or regular expression to search.
  • filename – file in which the search is performed.

Example

grep "Linux" notes.txt

This command searches for the text Linux in notes.txt.

Example output:
Linux is an open-source operating system. Linux supports multiple users.
Only lines containing the matching text are displayed.

2. Creating a Sample Text File

Before practising grep, create a sample file.

cat > notes.txt << 'EOF' Linux is an open-source operating system. Linux supports multiple users. Ubuntu is a Linux distribution. The kernel manages system resources. Embedded Linux is used in many devices. Windows is another operating system. EOF

Display the file contents:

cat notes.txt
Output:
Linux is an open-source operating system. Linux supports multiple users. Ubuntu is a Linux distribution. The kernel manages system resources. Embedded Linux is used in many devices. Windows is another operating system.

3. Basic Text Searching

Search for a Word

grep "Linux" notes.txt

Displays every line containing the word or text pattern Linux.

Search for a Word in Multiple Files

grep "Linux" notes.txt another.txt

Searches for the pattern in both files.

Search in All Files Matching a Pattern

grep "Linux" *.txt

Searches for Linux in all text files in the current directory whose names end with .txt.

Note: The shell expands *.txt into matching filenames before grep receives the arguments.

4. Important grep Options

Option Purpose Example
-i Ignore uppercase and lowercase differences. grep -i "linux" notes.txt
-n Display matching line numbers. grep -n "Linux" notes.txt
-v Display lines that do not match. grep -v "Linux" notes.txt
-c Count matching lines in each file. grep -c "Linux" notes.txt
-l Display filenames containing matches. grep -l "Linux" *.txt
-w Match whole words. grep -w "Linux" notes.txt
-x Match an entire line. grep -x "Linux" notes.txt
-o Display only the matching part. grep -o "Linux" notes.txt
-r Search recursively in directories. grep -r "Linux" ./
-h Suppress filenames in output. grep -h "Linux" *.txt
-A N Display N lines after a match. grep -A 2 "Linux" notes.txt
-B N Display N lines before a match. grep -B 2 "Linux" notes.txt
-C N Display N lines before and after a match. grep -C 2 "Linux" notes.txt

5. Understanding Important Options with Examples

5.1 Case-Insensitive Search (-i)

grep -i "linux" notes.txt

Matches Linux, LINUX, linux and other combinations of uppercase and lowercase letters.

5.2 Display Line Numbers (-n)

grep -n "Linux" notes.txt
Example output:
1:Linux is an open-source operating system. 2:Linux supports multiple users. 5:Embedded Linux is used in many devices.

5.3 Invert the Search (-v)

grep -v "Linux" notes.txt

Displays lines that do not contain the pattern.

5.4 Count Matching Lines (-c)

grep -c "Linux" notes.txt
Output:
3
The number represents matching lines, not necessarily the total number of occurrences of the word.

5.5 Match Whole Words (-w)

grep -w "Linux" notes.txt

This matches Linux as a whole word. It does not match the word as part of Linux-based or EmbeddedLinux in the same way as a general substring search.

5.6 Display Only Matching Text (-o)

grep -o "Linux" notes.txt
Output:
Linux Linux Linux

5.7 Recursive Search (-r)

grep -r "Linux" ./

Searches files under the current directory and its subdirectories.

The recursive option can search many files. Use it from the intended directory to avoid unnecessary output.

5.8 Display Lines Around a Match

grep -A 2 "kernel" notes.txt grep -B 2 "kernel" notes.txt grep -C 2 "kernel" notes.txt
  • -A 2 – two lines after the matching line.
  • -B 2 – two lines before the matching line.
  • -C 2 – two lines before and after the matching line.

6. Searching with Regular Expressions

A regular expression (regex) is a pattern used to describe a set of matching strings. grep supports regular-expression searching.

6.1 Search Lines Beginning with a Pattern (^)

grep "^Linux" notes.txt

The caret ^ matches the beginning of a line.

6.2 Search Lines Ending with a Pattern ($)

grep "devices\.$" notes.txt

The dollar sign $ matches the end of a line. The backslash before the dot makes it a literal full stop.

6.3 Search for a Single Character Using (.)

grep "Linu." notes.txt

The dot . matches any single character except a newline.

6.4 Search for Either of Two Patterns

grep -E "Linux|Ubuntu" notes.txt

The pipe symbol inside an extended regular expression means OR. This searches for lines containing either Linux or Ubuntu.

6.5 Search for Lines Containing Digits

grep -E "[0-9]" notes.txt

[0-9] matches any single digit from 0 to 9.

6.6 Extended Regular Expressions (-E)

grep -E "Linux|Ubuntu" notes.txt

The -E option enables extended regular expressions. It supports operators such as +, ?, | and parentheses without requiring a backslash before them.

Note: Basic grep uses basic regular expressions by default. The -E option enables extended regular expressions.

7. Using grep with Pipes

grep can receive input from another command through a pipe. This is useful when searching command output instead of a file.

Example 1: Search Running Processes

ps aux | grep "bash"

Displays process-list lines containing the text bash.

Example 2: Search Files in a Directory

ls -l | grep ".txt"

Filters the output of ls -l to show lines containing .txt.

Example 3: Search System Information

uname -a | grep "Linux"

Searches the output of uname -a for Linux.

Example 4: Search Log Messages

cat system.log | grep -i "error"

Displays lines containing the word error, without case sensitivity.

You can also avoid an unnecessary cat process by writing grep -i "error" system.log directly.

8. Searching in Linux Log Files

Linux system logs contain information about system activity, services, errors and troubleshooting events. grep helps locate relevant messages quickly.

Search for Error Messages

grep -i "error" /var/log/syslog

Search for Warning Messages

grep -i "warning" /var/log/syslog

Search for Failed Login Messages

grep -i "failed" /var/log/auth.log
Important: Log file names and availability depend on the Linux distribution and logging configuration. Some files may require administrator privileges. For example: sudo grep -i "error" /var/log/syslog.

9. grep Exit Status

grep returns an exit status that indicates the result of a search.

Exit Status Meaning
0 At least one matching line was found.
1 No matching lines were found.
2 An error occurred, such as an unreadable file or invalid pattern.

Check Exit Status

grep "Linux" notes.txt echo $?

The $? shell variable contains the exit status of the most recently executed command.

11. Common grep Mistakes

Mistake Correction
Using grep Linux without specifying a file or input. Provide a filename or pipe input to grep.
Forgetting case sensitivity. Use -i when case-insensitive search is needed.
Using -c to count every occurrence. -c counts matching lines, not all occurrences.
Using -r from an unintended directory. Run recursive searches from the correct directory.
Using special regex characters without understanding them. Escape characters when you need their literal meaning.

12. Interview Questions and Answers

Q1. What is grep in Linux?

Answer: grep is a command-line utility used to search text files or input streams for lines matching a specified pattern.

Q2. What is the basic syntax of grep?

Answer: grep [options] "pattern" filename.

Q3. What is the use of grep -i?

Answer: It performs a case-insensitive search.

Q4. What is the use of grep -n?

Answer: It displays matching lines with their line numbers.

Q5. What does grep -v do?

Answer: It displays lines that do not match the specified pattern.

Q6. What is the difference between grep -c and grep -o?

Answer: -c counts matching lines, while -o displays only the matching portions of lines.

Q7. What is recursive searching in grep?

Answer: Recursive searching checks files inside a directory and its subdirectories. The -r option performs this operation.

Q8. Can grep be used with pipes?

Answer: Yes. grep can filter the output of another command using the pipe operator.

Q9. What is a regular expression?

Answer: A regular expression is a pattern used to describe and search for matching text.

Q10. What does grep -E do?

Answer: It enables extended regular expressions, supporting additional pattern operators.

14. Lesson Summary

  • grep searches text using patterns.
  • -i performs case-insensitive searches.
  • -n displays line numbers.
  • -v displays non-matching lines.
  • -c counts matching lines.
  • -w searches for whole words.
  • -r searches directories recursively.
  • -A, -B and -C display context around matching lines.
  • -E enables extended regular expressions.
  • grep can be combined with other commands using pipes.
Practical Importance: grep is widely used in Linux administration, shell scripting, software development, log analysis and troubleshooting. It is an important tool for Linux and Systems Software Engineering.
