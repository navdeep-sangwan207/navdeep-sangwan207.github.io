Introduction to awk

1. Introduction to the awk Command

awk is a powerful text-processing and data-extraction utility used in Linux and Unix-like systems. It is especially useful for processing structured text containing rows and columns.

awk reads input records, divides each record into fields, applies specified patterns and actions, and produces output.

Common applications include:

  • Extracting selected columns from files.
  • Filtering records based on conditions.
  • Performing calculations on numeric data.
  • Counting records and fields.
  • Generating reports from text files.
  • Processing log files and command output.
  • Automating data-processing tasks in shell scripts.

Basic Syntax

awk 'pattern { action }' filename

Another common form uses a pipe:

command | awk 'pattern { action }'

Simple Example

echo "Linux is powerful" | awk '{ print $1 }'
Output:
Linux
Explanation: awk divides the input line into fields. The variable $1 represents the first field, so only Linux is displayed.

2. Understanding Records and Fields

awk processes text using two important concepts: records and fields.

Records

A record is a unit of input data. By default, each input line is treated as one record.

Fields

A field is an individual part of a record. By default, awk separates fields using runs of whitespace.

Example

echo "101 Rahul 85" | awk '{ print $1, $2, $3 }'
Output:
101 Rahul 85

Field positions:

Field Variable Value Description
$1 101 First field.
$2 Rahul Second field.
$3 85 Third field.
$0 101 Rahul 85 Entire current record.
Remember: $0 represents the complete current record, while $1, $2 and $3 represent individual fields.

3. Printing Fields Using print

The print statement displays data selected from the input record.

Example 1: Print the First Field

echo "101 Rahul 85" | awk '{ print $1 }'
Output:
101

Example 2: Print the Second Field

echo "101 Rahul 85" | awk '{ print $2 }'
Output:
Rahul

Example 3: Print the First and Third Fields

echo "101 Rahul 85" | awk '{ print $1, $3 }'
Output:
101 85

Example 4: Print the Entire Record

echo "101 Rahul 85" | awk '{ print $0 }'
Output:
101 Rahul 85

Example 5: Print All Fields

echo "101 Rahul 85" | awk '{ print $1, $2, $3 }'
Output:
101 Rahul 85

4. Working with Text Files

awk can read text files directly and extract selected information from each line.

Create a Sample File

cat > students.txt << 'EOF' 101 Rahul 85 102 Neha 92 103 Amit 78 104 Priya 88 105 Karan 95 EOF

Example 1: Display All Student Names

awk '{ print $2 }' students.txt
Output:
Rahul Neha Amit Priya Karan

Example 2: Display Student IDs

awk '{ print $1 }' students.txt
Output:
101 102 103 104 105

Example 3: Display Names and Marks

awk '{ print $2, $3 }' students.txt
Output:
Rahul 85 Neha 92 Amit 78 Priya 88 Karan 95

Example 4: Add a Heading

awk 'BEGIN { print "STUDENT REPORT" } { print $1, $2, $3 }' students.txt
Output:
STUDENT REPORT 101 Rahul 85 102 Neha 92 103 Amit 78 104 Priya 88 105 Karan 95

5. Built-in Variables in awk

awk provides built-in variables that store information about the current input record and processing environment.

Variable Meaning
NR Total record number processed so far.
FNR Record number in the current input file.
NF Number of fields in the current record.
FS Input field separator.
OFS Output field separator.
RS Input record separator.
ORS Output record separator.
FILENAME Name of the current input file.

Example 1: Display Record Numbers

awk '{ print NR, $0 }' students.txt
Output:
1 101 Rahul 85 2 102 Neha 92 3 103 Amit 78 4 104 Priya 88 5 105 Karan 95

Example 2: Display Number of Fields

awk '{ print NF }' students.txt
Output:
3 3 3 3 3

Example 3: Display Record Number and Field Count

awk '{ print "Record:", NR, "Fields:", NF }' students.txt
Output:
Record: 1 Fields: 3 Record: 2 Fields: 3 Record: 3 Fields: 3 Record: 4 Fields: 3 Record: 5 Fields: 3

Example 4: Display the Last Field

awk '{ print $NF }' students.txt
Output:
85 92 78 88 95
Explanation: $NF refers to the value of the final field in the current record. It is useful when the number of fields may vary.

6. Field Separators (FS and OFS)

By default, awk separates fields using whitespace. You can change the input field separator using FS or the -F command-line option.

Example File: Comma-Separated Data

cat > employees.csv << 'EOF' 101,Rahul,Developer,30000 102,Neha,Tester,28000 103,Amit,Engineer,35000 104,Priya,Manager,45000 EOF

Example 1: Use -F to Set a Comma Separator

awk -F ',' '{ print $2 }' employees.csv
Output:
Rahul Neha Amit Priya

Example 2: Display Employee Name and Salary

awk -F ',' '{ print $2, $4 }' employees.csv
Output:
Rahul 30000 Neha 28000 Amit 35000 Priya 45000

Example 3: Change the Output Separator

awk -F ',' 'BEGIN { OFS=" | " } { print $1, $2, $4 }' employees.csv
Output:
101 | Rahul | 30000 102 | Neha | 28000 103 | Amit | 35000 104 | Priya | 45000
Important: awk's -F option is useful for simple delimiter-separated text. It is not a complete CSV parser and does not correctly handle every CSV feature, such as quoted fields containing commas.

7. Filtering Records Using Conditions

awk can select records based on conditions. Only records satisfying the specified condition are processed by the associated action.

Example 1: Display Students Scoring More Than 85

awk '$3 > 85 { print $2, $3 }' students.txt
Output:
Neha 92 Priya 88 Karan 95

Example 2: Display Students Scoring Less Than 85

awk '$3 < 85 { print $2, $3 }' students.txt
Output:
Amit 78

Example 3: Display Students Scoring Exactly 85

awk '$3 == 85 { print $2, $3 }' students.txt
Output:
Rahul 85

Example 4: Display Students Scoring at Least 90

awk '$3 >= 90 { print $2, $3 }' students.txt
Output:
Neha 92 Karan 95

Common Comparison Operators

Operator Meaning
==Equal to.
!=Not equal to.
>Greater than.
<Less than.
>=Greater than or equal to.
<=Less than or equal to.

8. BEGIN and END Blocks

awk supports special blocks called BEGIN and END.

BEGIN Block

The BEGIN block runs once before awk starts processing the input records.

END Block

The END block runs once after all input records have been processed.

Example 1: Display a Heading and Footer

awk 'BEGIN { print "STUDENT DETAILS" } { print $1, $2, $3 } END { print "END OF REPORT" }' students.txt
Output:
STUDENT DETAILS 101 Rahul 85 102 Neha 92 103 Amit 78 104 Priya 88 105 Karan 95 END OF REPORT

Example 2: Count Total Records

awk 'END { print "Total Students:", NR }' students.txt
Output:
Total Students: 5

9. Arithmetic Operations in awk

awk supports arithmetic operations. These are useful when processing numeric fields such as marks, salaries, quantities and measurements.

Operator Operation
+Addition.
-Subtraction.
*Multiplication.
/Division.
%Remainder.

Example 1: Add Two Numbers

echo "10 20" | awk '{ print $1 + $2 }'
Output:
30

Example 2: Calculate Total Marks

echo "80 90 70" | awk '{ print $1 + $2 + $3 }'
Output:
240

Example 3: Calculate Average Marks

echo "80 90 70" | awk '{ print ($1 + $2 + $3) / 3 }'
Output:
80

Example 4: Calculate Total Salary

awk -F ',' '{ total += $4 } END { print "Total Salary:", total }' employees.csv
Output:
Total Salary: 138000

10. Using Variables in awk

awk supports user-defined variables that can store values during processing.

Example 1: Count Records

awk '{ count++ } END { print "Total Records:", count }' students.txt
Output:
Total Records: 5

Example 2: Calculate Total Marks

awk '{ total += $3 } END { print "Total Marks:", total }' students.txt
Output:
Total Marks: 438

Example 3: Calculate Average Marks

awk '{ total += $3 } END { if (NR > 0) print "Average:", total / NR }' students.txt
Output:
Average: 87.6

Example 4: Count Students Scoring Above 85

awk '$3 > 85 { count++ } END { print "Students above 85:", count }' students.txt
Output:
Students above 85: 3

11. Formatting Output Using printf

awk supports printf for formatted output. It allows control over alignment, width and decimal places.

Example 1: Display Student Details in Columns

awk '{ printf "%-10s %-10s %s\n", $1, $2, $3 }' students.txt
Output:
101 Rahul 85 102 Neha 92 103 Amit 78 104 Priya 88 105 Karan 95

Example 2: Display Average with Two Decimal Places

echo "80 85 90" | awk '{ avg = ($1+$2+$3)/3; printf "Average: %.2f\n", avg }'
Output:
Average: 85.00
Common printf format specifiers:
  • %s – String.
  • %d – Integer.
  • %f – Floating-point number.
  • %.2f – Floating-point number with two decimal places.
  • \n – Newline.

12. Using awk with Pipes

awk can receive input from other Linux commands through pipelines. This is useful when extracting information from command output.

Example 1: Display Current Username

whoami | awk '{ print $1 }'

Expected result: The current username.

Example 2: Display Selected Columns from ls -l

ls -l | awk '{ print $1, $3, $9 }'

This displays selected fields from the long listing. The exact output depends on the files and directories present.

Example 3: Count Lines Using awk

cat students.txt | awk 'END { print NR }'
Output:
5

Example 4: Combine grep and awk

grep "Linux" systems.txt | awk '{ print $1, $2 }'

grep first selects lines containing Linux. awk then extracts the first two fields.

13. Useful awk Operators and Special Variables

Logical Operators

Operator Meaning
&&Logical AND.
||Logical OR.
!Logical NOT.

Example: Students Scoring Between 80 and 95

awk '$3 >= 80 && $3 <= 95 { print $2, $3 }' students.txt
Output:
Rahul 85 Neha 92 Priya 88 Karan 95

Example: Students Scoring Below 80 or Above 90

awk '$3 < 80 || $3 > 90 { print $2, $3 }' students.txt
Output:
Neha 92 Amit 78 Karan 95

14. Common awk Options

Option Purpose Example
-F Specify input field separator. awk -F ',' '{print $1}' file
-f Read awk program from a script file. awk -f script.awk data.txt
-v Assign a variable before program execution. awk -v x=10 'BEGIN {print x}'

Example 1: Assign a Variable with -v

awk -v threshold=85 '$3 > threshold { print $2, $3 }' students.txt
Output:
Neha 92 Priya 88 Karan 95

Example 2: Run an awk Script File

Create a file named report.awk:

BEGIN { print "STUDENT REPORT" } { print $2, $3 } END { print "REPORT COMPLETED" }

Run the script:

awk -f report.awk students.txt

16. Difference Between grep, sed and awk

Feature grep sed awk
Main Purpose Search text patterns. Edit and transform text. Process fields and records.
Pattern Matching Yes. Yes. Yes.
Text Replacement Not its primary purpose. Yes. Yes, using expressions and assignments.
Field Processing Limited. Possible but less convenient. Built-in field processing.
Arithmetic No built-in arithmetic processing. Limited. Yes.
Report Generation Limited. Possible. Very useful.
Remember:
  • grep is mainly used to search.
  • sed is mainly used to edit and transform text.
  • awk is especially useful for field processing, calculations and report generation.

17. Interview Questions and Answers

Q1. What is awk?

Answer: awk is a text-processing utility used to extract fields, filter records, perform calculations and generate reports.

Q2. What is the basic syntax of awk?

Answer: awk 'pattern { action }' filename.

Q3. What does $0 represent?

Answer: The entire current input record.

Q4. What does $1 represent?

Answer: The first field of the current record.

Q5. What is NR?

Answer: NR represents the total record number processed so far.

Q6. What is NF?

Answer: NF represents the number of fields in the current record.

Q7. What is FS?

Answer: FS is the input field separator.

Q8. What is OFS?

Answer: OFS is the output field separator.

Q9. What is the purpose of BEGIN?

Answer: BEGIN executes once before input record processing starts.

Q10. What is the purpose of END?

Answer: END executes once after all input records have been processed.

Q11. How do you specify a comma as a field separator?

Answer: Use awk -F ','.

Q12. What is the purpose of printf?

Answer: printf generates formatted output with control over alignment and number formatting.

Q13. What does $NF represent?

Answer: It represents the last field in the current record.

Q14. What is the difference between NR and FNR?

Answer: NR counts records across all input files, while FNR counts records within the current file.
