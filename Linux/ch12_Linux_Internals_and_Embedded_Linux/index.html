Chapter 12: Linux Internals and Embedded Linux

Understand Linux kernel internals, device drivers and embedded Linux development.

Chapter Overview

This chapter introduces the internal architecture of the Linux operating system and its application in embedded systems. You will study kernel architecture, user space, kernel space, kernel modules, interrupts, memory management, virtual memory, device files and device drivers.

The chapter also introduces Embedded Linux development, cross-compilation, Buildroot, Yocto and the Embedded Linux boot process.
