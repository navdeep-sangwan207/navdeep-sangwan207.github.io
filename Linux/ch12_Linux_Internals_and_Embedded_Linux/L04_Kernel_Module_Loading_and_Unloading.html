Kernel Module Loading and Unloading

Learn how to insert, remove, inspect and troubleshoot Linux kernel modules using practical commands and a simple example module.

1. Introduction

Linux supports loadable kernel modules that can extend kernel functionality while the system is running.

A module can be inserted into the running kernel when required and removed when it is no longer needed, provided that it is not in use and the kernel permits its removal.

Definition: Kernel module loading is the process of inserting a compiled module into the running Linux kernel. Kernel module unloading is the process of removing a loaded module from the kernel.

2. Important Kernel Module Commands

Command Purpose
lsmod Lists loaded kernel modules.
insmod Inserts a specified module file.
rmmod Requests removal of a loaded module.
modprobe Loads or removes modules and handles dependencies.
modinfo Displays module metadata.
depmod Generates module dependency information.

3. Understanding insmod

The insmod command inserts a specified kernel module file into the running kernel.

Syntax

sudo insmod module_name.ko

Example

sudo insmod hello_module.ko

The module file must exist at the specified path and must be compatible with the running kernel.

Important Points

  • insmod accepts a module file path.
  • It does not automatically resolve module dependencies.
  • Administrative privileges are normally required.
  • The module must be built for a compatible kernel.

4. Understanding rmmod

The rmmod command requests removal of a loaded kernel module.

Syntax

sudo rmmod module_name

Example

sudo rmmod hello_module

Normally, the .ko extension is not included in the module name supplied to rmmod.

Reasons Module Removal May Fail

  • The module is currently in use.
  • Other modules depend on it.
  • The module does not support unloading.
  • The kernel or security policy prevents removal.
  • The module name is incorrect.

5. Understanding modprobe

modprobe is a module-management utility that uses installed module information and dependency data to load or remove modules.

Load a Module

sudo modprobe module_name

Remove a Module

sudo modprobe -r module_name

Example

sudo modprobe loop

This requests loading of the loop module if it is available and not already loaded.

Advantages of modprobe

  • Automatically handles module dependencies.
  • Uses the installed module database.
  • Supports module removal.
  • Supports module options.
  • Provides useful diagnostics when loading fails.
For normal administration, modprobe is generally preferred over manually inserting a module with insmod because it handles dependencies.

6. Difference Between insmod and modprobe

insmod modprobe
Loads a specified module file. Loads a module by name using installed module information.
Does not automatically resolve dependencies. Normally resolves dependencies.
Requires a module file path. Usually accepts a module name.
Useful for direct module insertion during development. Preferred for routine module management.

7. Checking Whether a Module Is Loaded

Using lsmod

lsmod

Search for a Specific Module

lsmod | grep loop

Using /proc/modules

cat /proc/modules

Both lsmod and /proc/modules provide information about modules currently loaded into the running kernel.

8. Inspecting Module Information

Before loading a module, inspect its metadata using modinfo.

Syntax

modinfo module_name

Example

modinfo loop

Common fields include filename, description, author, license, dependencies and vermagic.

Check Module Dependencies

modprobe --show-depends loop

9. Kernel Module Directory

Linux stores installed kernel modules in version-specific directories. 

/lib/modules/<kernel-version>/

Find the Running Kernel Version

uname -r

List the Module Directory

ls /lib/modules/$(uname -r)/

Find Module Files

find /lib/modules/$(uname -r) \
-type f -name '*.ko*' | head

Module files may be compressed, depending on the distribution and kernel packaging.

10. Understanding depmod

The depmod utility analyzes available kernel modules and generates dependency information.

Update Module Dependency Information

sudo depmod -a

This command scans installed modules for the relevant kernel version and updates dependency metadata.

Common Dependency Files

  • modules.dep
  • modules.dep.bin
  • modules.alias
  • modules.symbols

These files help module-management utilities locate modules and resolve dependencies.

11. Creating a Simple Kernel Module

We will create a basic Hello World kernel module using C. It prints messages when loaded and unloaded.

Kernel module development should be performed inside your Ubuntu VirtualBox guest. Take a VirtualBox snapshot before testing. Do not experiment with untrusted modules on your main Windows system.

Step 1: Install Required Packages

sudo apt update
sudo apt install build-essential linux-headers-$(uname -r)

If matching headers are unavailable, check the installed kernel and Ubuntu package repositories before proceeding.

Step 2: Create a Working Directory

mkdir ~/kernel_module_lab
cd ~/kernel_module_lab

Step 3: Create the C Source File

nano hello_module.c

Step 4: Write the Kernel Module Code

#include <linux/init.h>
#include <linux/module.h>
#include <linux/kernel.h>

MODULE_LICENSE("GPL");
MODULE_AUTHOR("NS Learning Hub");
MODULE_DESCRIPTION("Simple Hello World Kernel Module");
MODULE_VERSION("1.0");

static int __init hello_init(void)
{
    pr_info("Hello: Kernel module loaded\n");

    return 0;
}

static void __exit hello_exit(void)
{
    pr_info("Hello: Kernel module unloaded\n");
}

module_init(hello_init);
module_exit(hello_exit);

Code Explanation

Function / Macro Purpose
module_init() Registers the module initialization function.
module_exit() Registers the module cleanup function.
__init Marks initialization code.
__exit Marks cleanup code.
pr_info() Writes an informational message to the kernel log.
MODULE_LICENSE() Declares the module license.

Step 5: Create a Makefile

nano Makefile

Enter the following lines. The command line must begin with a TAB character.

obj-m += hello_module.o

KDIR := /lib/modules/$(shell uname -r)/build
PWD := $(shell pwd)

all:
	make -C $(KDIR) M=$(PWD) modules

clean:
	make -C $(KDIR) M=$(PWD) clean

Step 6: Compile the Module

make

If the build succeeds, a file named hello_module.ko should be generated.

Step 7: Inspect the Module

ls -l
modinfo hello_module.ko

Step 8: Load the Module

sudo insmod hello_module.ko

Step 9: Verify the Module

lsmod | grep hello_module

Step 10: View Kernel Messages

sudo dmesg | tail -n 20

Look for the message: 

Hello: Kernel module loaded

Step 11: Unload the Module

sudo rmmod hello_module

Step 12: Verify Removal

lsmod | grep hello_module
sudo dmesg | tail -n 20

Look for the message: 

Hello: Kernel module unloaded

Step 13: Clean Build Files

make clean
Expected Result: The module compiles into hello_module.ko, loads successfully, prints a kernel log message, unloads successfully and prints its cleanup message.

12. Understanding Kernel Logs

Kernel modules commonly use printk() or pr_info() to write messages to the kernel log.

View Recent Kernel Messages

dmesg | tail

Follow Kernel Messages

sudo dmesg -w

Press Ctrl+C to stop following the messages.

Access to kernel logs may be restricted by system permissions.

13. Common Kernel Module Errors

Error / Symptom Possible Cause
Module not found Incorrect file path or missing installed module.
Invalid module format Kernel version, ABI or build mismatch.
Unknown symbol Missing dependency or unavailable kernel symbol.
Operation not permitted Insufficient privileges or security restrictions.
Module is in use Another component or device is using the module.
Required key not available Module signature verification or Secure Boot policy issue.

Check Kernel Version

uname -r

Check Module Metadata

modinfo hello_module.ko

Check Kernel Logs

sudo dmesg | tail -n 40
Do not disable Secure Boot or kernel signature verification as a first troubleshooting step. First identify the exact module-loading error and the applicable security policy.

15. Interview Questions and Answers

Q1. Which command inserts a kernel module?

insmod inserts a specified module file.

Q2. Which command removes a kernel module?

rmmod requests removal of a loaded module.

Q3. What is the difference between insmod and modprobe?

insmod inserts a specified file directly. modprobe uses module dependency information and normally loads required dependencies.

Q4. How do you check whether a module is loaded?

Use lsmod or inspect /proc/modules.

Q5. What is a Makefile used for in kernel module development?

It defines the build instructions used to compile the module against the appropriate kernel build tree.

Q6. What is module_init()?

It registers the function that executes when the module is initialized.

Q7. What is module_exit()?

It registers the cleanup function called when an unloadable module is removed.

Q8. What does pr_info() do?

It writes an informational message to the kernel logging system.

Q9. Why must kernel headers match the running kernel?

The headers and build files provide the interfaces and configuration needed to build a compatible external module.

Q10. What is depmod?

depmod generates dependency information for installed kernel modules.

Q11. Why might rmmod fail?

A module may be in use, have active dependencies or otherwise be unavailable for unloading.

Q12. What is an invalid module format error?

It commonly indicates that the module does not match the running kernel's expected format or compatibility requirements.
