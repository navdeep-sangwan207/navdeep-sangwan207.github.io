Process ID and Parent Process ID

Understanding Process Identification and Parent-Child Relationships

  • Understand Process ID (PID).
  • Understand Parent Process ID (PPID).
  • Identify processes using their PID and PPID.
  • Understand parent-child process relationships.

  • Retrieve process identification information from a C program.

1. What is a Process ID (PID)?

A Process ID (PID) is a unique numerical identifier assigned by the Linux kernel to a process. The PID helps the operating system identify and manage individual processes.

Definition: PID stands for Process ID. It is a numerical identifier used by Linux to distinguish one process from another.

Example

Suppose you open a terminal and execute the following command:

ps
Example Output: 
    PID TTY          TIME CMD
   1250 pts/0    00:00:00 bash
   1305 pts/0    00:00:00 ps

In this example:

  • 1250: PID of the Bash shell.
  • 1305: PID of the ps command.

These are illustrative values. Actual PIDs vary from system to system.

2. What is a Parent Process ID (PPID)?

A Parent Process ID (PPID) is the PID of the process that created another process.

When one process creates another process, the newly created process is called the child process, and the process that created it is called the parent process.

Definition: PPID stands for Parent Process ID. It identifies the parent process of a particular process.

Example

Consider a terminal shell that starts a command such as ls.

bash | +---- ls

In this simplified example:

  • Bash is the parent process.
  • ls is the child process.
  • The PID of Bash is the PPID of ls.
Important: A shell normally creates a child process for an external command. Some shell built-in commands, such as cd, execute directly inside the shell and do not require a separate child process.

3. Difference Between PID and PPID

PID PPID
Stands for Process ID. Stands for Parent Process ID.
Identifies the current process. Identifies the parent of the current process.
Assigned to a process by the kernel. Represents the PID of its parent process.
Used to refer to a specific process. Used to understand process relationships.
Can be displayed using commands such as ps. Can be displayed using commands such as ps.

Example Process Information

PID     PPID    COMMAND
1000    900     bash
1050    1000    sleep

Here:

  • Process 1000 has parent process 900.
  • Process 1050 has parent process 1000.
  • Process 1000 is the parent of process 1050.

4. Parent-Child Process Relationship

Linux supports a hierarchical relationship between processes. A process can create multiple child processes, and a child process can create its own child processes.

Example Process Tree

systemd (PID 1) | +---- login process | | | +---- bash | | | +---- command | | | +---- another command | +---- background service

This is a simplified illustration. Actual process trees depend on the Linux distribution, login method and services.

Important Points

  • One parent can create multiple child processes.
  • Every process has its own PID.
  • A child process records its parent PID.
  • A process can become the parent of another process.
  • When a parent exits, surviving child processes may be reparented to another process, commonly PID 1 or a configured child subreaper.

5. PID 1 in Linux

PID 1 is a special process in a Linux system. It is the first userspace process started by the kernel during normal system startup.

On many modern Linux distributions, PID 1 is systemd. Other systems may use a different init implementation.

Responsibilities of the Init Process

  • Starts and manages system services.
  • Coordinates system initialization.
  • Helps manage system startup tasks.
  • Adopts orphaned processes when appropriate.
  • Collects the exit status of child processes it manages.

Check PID 1

ps -p 1 -o pid,ppid,comm,args
Illustrative Output: 
PID  PPID  COMMAND  COMMAND
1    0     systemd  /sbin/init
Note: The command and arguments shown for PID 1 depend on the Linux distribution and environment. In containers, PID 1 may be an application or another process rather than systemd.

6. Commands to Display PID and PPID

Command 1: ps

The ps command displays process information.

ps -ef

This displays processes in a full-format listing, including PID and PPID.

Command 2: Display PID and PPID Columns

ps -eo pid,ppid,comm
Example Output: 
    PID    PPID COMMAND
      1       0 systemd
    850       1 sshd
   1250     850 bash
   1305    1250 ps

Explanation:

  • -e selects all processes.
  • -o specifies the output columns.
  • pid displays the process ID.
  • ppid displays the parent process ID.
  • comm displays the command name.

Command 3: Display Current Shell PID

echo $$

The special shell variable $$ expands to the PID of the current shell.

Command 4: Display Parent Shell PID

echo $PPID

In Bash, $PPID contains the parent PID of the current shell.

Note: These are shell variables, not ordinary Linux commands. Their values depend on the shell process and its execution context.

Command 5: Find PID Using pgrep

pgrep bash

Displays the PIDs of processes whose names match Bash.

Command 6: Find PID Using pidof

pidof bash

Displays the PIDs of running processes matching the specified program name, when available.

Command 7: Display Process Tree

pstree -p

Displays a process tree with process IDs.

7. Process Identification Using /proc

Linux provides a virtual filesystem called /proc. It exposes information about running processes and kernel information.

Each running process normally has a directory named after its PID inside /proc.

Example

ls /proc

You may see numeric directory names such as: 

1
2
100
850
1250

These numeric directories represent process IDs. The /proc filesystem also contains other system information and non-process entries.

Check a Particular Process

cat /proc/$$/status

This displays status information for the current shell process.

Find PID and PPID in Status Information

grep -E '^(Name|Pid|PPid):' /proc/$$/status
Example Output: 
Name:   bash
Pid:    1250
PPid:   1200

The values above are illustrative. Your system will display its actual process information.

8. PID and PPID in C Programming

Linux provides system calls that allow a C program to obtain its own process ID and parent process ID.

Functions

Function Purpose
getpid() Returns the PID of the calling process.
getppid() Returns the PPID of the calling process.

C Program

#include <stdio.h> #include <unistd.h> int main(void) { printf("Process ID (PID): %ld\n", (long)getpid()); printf("Parent Process ID (PPID): %ld\n", (long)getppid()); return 0; }

Compile and Run

gcc process_id.c -o process_id ./process_id
Example Output: 
Process ID (PID): 2450
Parent Process ID (PPID): 2100
Note: PID and PPID values will change between executions. The parent process depends on how the program was started.

9. Important Concepts: Orphan and Zombie Processes

Orphan Process

An orphan process is a child process whose original parent has terminated while the child is still running.

Linux reparents the child to an appropriate process, commonly PID 1 or a process configured as a child subreaper.

Zombie Process

A zombie process is a process that has terminated, but whose parent has not yet collected its termination status using wait() or a related system call.

Remember:
  • An orphan process is still running after its parent exits.
  • A zombie process has already terminated but still has an entry in the process table until its exit status is collected.

11. Interview Questions and Answers

Q1. What is PID in Linux?

Answer: PID stands for Process ID. It is a numerical identifier assigned to a process by the Linux kernel.

Q2. What is PPID?

Answer: PPID stands for Parent Process ID. It identifies the parent process of a process.

Q3. Which command displays PID and PPID?

Answer: The command ps -eo pid,ppid,comm displays PID, PPID and command name.

Q4. What is PID 1?

Answer: PID 1 normally identifies the first userspace process started by the kernel during system startup.

Q5. How can you display the PID of the current shell?

Answer: Use echo $$ in the shell.

Q6. How can you display the parent PID of the current shell?

Answer: In Bash, use echo $PPID.

Q7. What is a parent process?

Answer: A parent process is a process that creates another process.

Q8. What is a child process?

Answer: A child process is a process created by another process.

Q9. Which C function returns the current process ID?

Answer: The getpid() function returns the PID of the calling process.

Q10. Which C function returns the parent process ID?

Answer: The getppid() function returns the PPID of the calling process.

Q11. What is an orphan process?

Answer: An orphan process is a child process that continues running after its original parent terminates.

Q12. What is a zombie process?

Answer: A zombie is a terminated process whose exit status has not yet been collected by its parent.

Q1. What does PID stand for?

  1. Process Internal Data
  2. Process Identification
  3. Parent Input Device
  4. Program Instruction Data

Correct Answer: B. Process Identification

Q2. What does PPID stand for?

  1. Parent Process ID
  2. Primary Program ID
  3. Process Priority ID
  4. Program Process Input Data

Correct Answer: A. Parent Process ID

Q3. Which command displays PID and PPID?

  1. pwd
  2. mkdir
  3. ps -eo pid,ppid,comm
  4. touch

Correct Answer: C. ps -eo pid,ppid,comm

Q4. Which shell variable displays the current Bash shell PID?

  1. $HOME
  2. $$
  3. $USER
  4. $PATH

Correct Answer: B. $$

  1. getppid()
  2. fork()

Correct Answer: C. getpid()

Q6. Which process normally has PID 1?

  1. First userspace process

Correct Answer: A. First userspace process

Q7. Which command displays a process tree with PIDs?

  1. pstree -p

13. Lesson Summary

  • PID is the unique process identifier at a given time.
  • PPID identifies the parent process.
  • Processes form parent-child relationships.
  • One parent process can create multiple child processes.
  • PID 1 normally identifies the first userspace process.
  • ps displays process information.
  • pgrep and pidof help find process IDs.
  • pstree -p displays a process tree with PIDs.
  • $$ displays the current shell PID.
  • $PPID displays the parent PID in Bash.
  • getpid() and getppid() are Linux/Unix C interfaces.
  • /proc provides process-related information.
  • Orphan and zombie processes are different concepts.
