1. Introduction to Process Monitoring

Process monitoring is the activity of observing running processes and checking how they use system resources.

Linux provides several tools for process monitoring. Two commonly used tools are:

  • top: A command-line, interactive process monitor.
  • htop: An enhanced interactive process monitor.
Definition: Real-time process monitoring provides continuously refreshed information about running processes and system resource utilization.

Why Is Process Monitoring Important?

  • Identify processes consuming excessive CPU.
  • Monitor RAM and swap utilization.
  • Investigate slow system performance.
  • Identify unwanted or unresponsive processes.
  • Observe system load.
  • Monitor applications and background services.

2. Introduction to the top Command

The top command displays a continuously updated view of Linux processes and system resource usage.

Syntax

top [options]

Start top

top

The command opens an interactive monitoring screen. Process and system statistics are refreshed periodically.

Exit top

Press q
Note: The refresh interval and displayed fields may vary according to the system configuration and procps version.

3. Understanding the top Display

The top screen contains system summary information at the top and a process table below it.

Example Display

top - 10:30:20 up 2:15, 2 users, load average: 0.25, 0.40, 0.35
Tasks: 150 total, 1 running, 149 sleeping, 0 stopped, 0 zombie
%Cpu(s):  5.0 us, 2.0 sy, 0.0 ni, 92.0 id, 1.0 wa
MiB Mem :  7800 total, 4200 free, 2500 used, 1100 buff/cache
MiB Swap:  2048 total, 2048 free, 0 used

 PID USER     PR  NI    VIRT    RES    SHR S  %CPU %MEM     TIME+ COMMAND
1250 user     20   0  120000  18000   8000 S   2.0  0.2   0:02.10 bash
1400 user     20   0   50000   6000   3000 R   1.0  0.1   0:00.50 top

The values are illustrative. Your actual top display will depend on the running processes and hardware.

System Summary Fields

Field Description
up Time since the system was started.
users Number of logged-in users.
load average System load averages over 1, 5 and 15 minutes.
Tasks Summary of process and thread states as displayed by top.
%Cpu(s) CPU utilization breakdown.
MiB Mem Physical memory information.
MiB Swap Swap-space information.

4. Understanding CPU Utilization

The CPU summary in top shows how processor time is being used.

CPU Field Meaning
us Time spent executing user-space processes.
sy Time spent executing kernel code.
ni Time spent running processes with adjusted nice values.
id Idle CPU time.
wa Time spent waiting for I/O completion.
hi Time servicing hardware interrupts.
si Time servicing software interrupts.
st Time stolen by the hypervisor in a virtualized environment.
Example: If CPU idle time is 90%, the CPU is mostly idle during the measurement interval. If CPU usage is consistently high, further investigation may be required.

5. Understanding Memory Utilization

The memory section displays information about RAM and swap.

Important Memory Fields

  • Total: Total memory represented in the display.
  • Free: Memory currently unused.
  • Used: Memory used according to the displayed accounting.
  • Buff/cache: Memory used for buffers and caches.
  • Swap: Disk-backed virtual memory area used when needed.

Check Memory Using free

free -h

The -h option displays memory values in human-readable units. 

               total        used        free      shared  buff/cache   available
Mem:           7.6Gi       2.4Gi       4.0Gi       200Mi       1.2Gi       4.8Gi
Swap:          2.0Gi          0B       2.0Gi
Important: Linux uses available RAM for caching. Therefore, low free memory does not automatically indicate a memory shortage. The available-memory value is generally more useful for estimating memory that can be used by applications without swapping.

6. Understanding Process Table Columns

Column Description
PID Process identification number.
USER Owner of the process.
PR Scheduling priority shown by top.
NI Nice value.
VIRT Total virtual memory used by the process.
RES Resident physical memory used by the process.
SHR Shared memory amount reported for the process.
S Process state.
%CPU CPU utilization percentage.
%MEM Percentage of physical memory used.
TIME+ Accumulated CPU time with finer precision.
COMMAND Command name or process command line.

7. Interactive Keyboard Commands in top

The top command supports keyboard controls while its monitoring screen is active.

Key Function
q Quit top.
h or ? Display help.
k Send a signal to a selected process, usually SIGTERM by default.
r Renice a process.
P Sort by CPU utilization.
M Sort by memory utilization.
T Sort by accumulated CPU time.
1 Toggle display of individual CPU statistics.
c Toggle command name and full command-line display.
u Filter processes by user.
Space Refresh the display immediately.
d Change the refresh delay.
Caution: The k and r controls can affect running processes. Use them only when you understand the consequences and have the required permissions.

8. Running top with Options

Display Processes for a Specific User

top -u username

Replace username with the required Linux account.

Set Refresh Interval

top -d 2

Refreshes the display approximately every two seconds.

Display a Limited Number of Processes

top -n 1 -b | head -20

Takes one batch-mode update and passes its output to head, which displays the first 20 lines.

Batch Mode

top -b -n 1

Runs top in batch mode for one update. This is useful when collecting output for scripts or reports.

9. Introduction to htop

htop is an interactive process viewer that provides a more visual interface than the traditional top command.

It displays process information, CPU utilization, memory usage and other system statistics.

Features of htop

  • Color-coded CPU and memory information.
  • Interactive process selection.
  • Convenient process sorting.
  • Process tree view.
  • Mouse support in supported terminals.
  • Interactive process termination and priority controls.
  • Customizable display.
Definition: htop is an enhanced, interactive process-monitoring utility for Linux.

10. Installing htop in Ubuntu

htop may not be installed by default. Use the Ubuntu package manager to install it.

Step 1: Update Package Information

sudo apt update

Step 2: Install htop

sudo apt install htop

Step 3: Start htop

htop

Step 4: Exit htop

Press F10 or q
Note: Package availability and installation details may vary across Linux distributions. Ubuntu uses the apt package manager.

11. Working with htop

When htop starts, it displays CPU and memory information at the top and the process list below.

Common htop Keyboard Controls

Key Function
F1 Help.
F2 Setup and configuration.
F3 Search for a process.
F4 Filter processes.
F5 Toggle tree view.
F6 Choose sorting column.
F9 Send a signal to a selected process.
F10 Quit htop.
Space Tag or untag a selected process.
Terminal note: Some function keys may be intercepted by the terminal or desktop environment. Use the on-screen function-key menu or the equivalent keyboard shortcuts shown by your htop version.

12. Difference Between top and htop

top htop
Traditional process-monitoring utility. Enhanced interactive process monitor.
Usually available by default. May require installation.
Primarily keyboard-oriented interface. Supports keyboard and mouse interaction in supported terminals.
Provides process and system information. Provides a more visual representation of process and system information.
Supports interactive process management. Provides convenient interactive process management.
Simple text-based display. Color-coded and customizable display.

15. Interview Questions and Answers

Q1. What is the top command?

Answer: top is an interactive Linux utility that continuously displays process and system resource information.

Q2. What is htop?

Answer: htop is an enhanced interactive process-monitoring utility with a visual interface.

Q3. What is the difference between ps and top?

Answer: ps displays a snapshot of processes, whereas top continuously refreshes process information.

Q4. How do you exit top?

Answer: Press q.

Q5. How do you sort processes by CPU usage in top?

Answer: Press uppercase P.

Q6. How do you sort processes by memory usage in top?

Answer: Press uppercase M.

Q7. What is load average?

Answer: Load average represents the average number of tasks that are runnable or waiting in uninterruptible sleep over specified periods, commonly 1, 5 and 15 minutes.

Q8. What does CPU idle time mean?

Answer: It represents the percentage of measured CPU time during which the processor was idle.

Q9. What is swap memory?

Answer: Swap is disk-backed storage used as an extension of virtual memory when the system needs it.

Q10. How do you install htop in Ubuntu?

Answer: Use sudo apt install htop.

Q11. What does the F5 key do in htop?

Answer: It toggles the process tree view.

Q12. What does the wa field represent in top?

Answer: It represents CPU time spent waiting for I/O completion.

Q13. What is the difference between RAM and swap?

Answer: RAM is physical memory, whereas swap is disk-backed storage used for virtual memory.

Q14. What does the -d option do in top?

Answer: It sets the approximate delay between display updates.
