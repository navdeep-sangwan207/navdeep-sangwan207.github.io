Chapter 7: Linux Process Management

Understanding, Monitoring and Controlling Processes in Linux

Chapter Overview

Process management is an important part of Linux operating system administration and systems programming. A process is an instance of a running program that has its own process identification, execution state and allocated system resources.

In this chapter, you will learn about process IDs, parent process IDs, process states, process monitoring commands, foreground and background execution, job control, signals, process termination and process priorities. You will also practise commands such as ps, top, htop, jobs, bg, fg, kill, nice and renice.
