1. Introduction to a Desktop Environment

A Desktop Environment (DE) is a collection of graphical components and applications that provide a user-friendly interface for interacting with an operating system.

Instead of entering every instruction through a command-line interface, users can work with windows, menus, icons, panels, buttons and graphical applications.

Functions of a desktop environment

  • Provides a graphical user interface (GUI).
  • Manages application windows.
  • Provides a file manager.
  • Provides application launchers and menus.
  • Manages desktop settings and appearance.
  • Provides graphical tools for network and device management.
Example: When you open Ubuntu and see the desktop, application launcher, dock, settings and file manager, you are interacting with its desktop environment.

2. What is a GUI?

A Graphical User Interface (GUI) allows users to interact with a computer through graphical elements rather than typing every command.

Common GUI elements

Element Purpose
Window Displays an application or document.
Icon Graphical representation of an application, file or action.
Menu Provides a list of available commands or options.
Button Performs an action when selected.
Panel or Dock Provides access to applications and system functions.
Dialog Box Displays information or requests user input.
Pointer Indicates the current mouse position.

3. What is GNOME?

GNOME is a popular open-source desktop environment used by Ubuntu Desktop.

It provides a graphical workspace with an application overview, system controls, window management and integrated desktop applications.

Important GNOME features

  • Clean and modern desktop interface.
  • Application overview and search.
  • Workspace management.
  • System status and quick settings.
  • Keyboard shortcuts.
  • Support for extensions and customization.

GNOME Shell

GNOME Shell is the graphical shell that provides the main GNOME user interface, including the Activities overview, top bar and application switching experience.

Ubuntu uses a customized GNOME desktop experience. Its appearance and default applications may vary between Ubuntu releases.

4. Common Linux Desktop Environments

Different Linux distributions provide different desktop environments. Users can also install alternative environments when supported.

Desktop Environment Characteristics
GNOME Modern interface, application overview and workspace support.
KDE Plasma Highly customizable desktop with many configuration options.
Xfce Lightweight desktop environment.
Cinnamon Traditional desktop layout with a panel and application menu.
MATE Traditional desktop experience and relatively modest resource usage.
LXQt Lightweight Qt-based desktop environment.
A desktop environment is not the Linux kernel. The kernel manages system resources and hardware, while the desktop environment provides graphical interaction for the user.

5. Main Components of the Ubuntu Desktop

1. Top Bar

The top bar displays system information and controls, such as date, time, notifications and system status.

2. Dock

The dock provides quick access to frequently used applications and running application windows.

3. Activities Overview

The Activities overview provides access to application search, open windows and workspaces.

4. Application Grid

The application grid displays installed graphical applications and allows users to launch them.

5. System Menu and Quick Settings

This area provides controls for common system functions such as network connections, sound, power and settings.

6. Desktop Workspace

The workspace is the area where application windows are displayed and managed.

The exact position and appearance of these components may differ depending on the Ubuntu version, display configuration and desktop customization.

6. Navigating the Ubuntu Desktop

Opening the Activities Overview

  1. Move the mouse to the Activities area or press the Super key.
  2. View the open application windows.
  3. Use the search field to find applications.
  4. Select an application to open it.

Opening an application

  1. Open the application grid.
  2. Locate the required application.
  3. Click its icon.
  4. Wait for the application window to appear.

Switching between applications

You can switch between open applications using the graphical overview or keyboard shortcuts.

Alt + Tab Switch between open applications Super Open Activities overview Super + A Show applications (in common GNOME layouts) Super + L Lock the screen Ctrl + Alt + T Open Terminal (common Ubuntu shortcut)
Keyboard shortcuts can vary by Ubuntu release and user configuration. You can inspect or change them in the Keyboard settings.

7. Working with Application Windows

An application window provides an area in which a graphical program runs.

Common window operations

Operation Meaning
Open Launch an application window.
Minimize Hide a window while keeping the application running.
Maximize Expand a window to use most or all of the available screen.
Restore Return a maximized window to its previous size.
Move Change the window's screen position.
Resize Change the window dimensions.
Close Close the application window.
Shortcut: Alt + F4 commonly closes the active window.

8. Ubuntu File Manager

The file manager is a graphical application used to browse, organize and manage files and directories.

Ubuntu commonly provides the GNOME Files application, also known as Nautilus.

Common file manager functions

  • Create files and directories.
  • Open files and folders.
  • Copy and move files.
  • Rename files and directories.
  • Delete files.
  • Search for files.
  • View file properties and permissions.
  • Access removable storage.

Important directories

Directory Purpose
Home Personal files and folders.
Documents Document storage.
Downloads Downloaded files.
Pictures Image storage.
Music Audio files.
Videos Video files.

Basic file management shortcuts

Ctrl + C Copy Ctrl + X Cut Ctrl + V Paste Ctrl + A Select all Ctrl + Z Undo (where supported) F2 Rename selected item Delete Move selected item to Trash Ctrl + L Enter a location or path
Deleting a file using the graphical file manager may move it to Trash instead of permanently removing it.

9. Ubuntu System Settings

System Settings is a graphical application used to configure hardware, user accounts, network connections and desktop preferences.

Common settings categories

Setting Purpose
Wi-Fi and Network Manage network connections.
Bluetooth Manage supported Bluetooth devices.
Display Change resolution, scaling and display arrangement.
Sound Configure input and output audio devices.
Power Configure power and battery-related settings.
Mouse and Touchpad Configure pointer and touchpad behaviour.
Keyboard Configure keyboard layout and shortcuts.
Users Manage user accounts and related settings.
Appearance Customize themes, dock and desktop appearance.
Date and Time Configure time zone and clock settings.

10. Display Configuration

Display settings control how graphical content appears on the screen.

Important display settings

  • Resolution: Number of pixels displayed horizontally and vertically.
  • Scaling: Adjusts the size of interface elements.
  • Refresh Rate: Number of times the display updates per second.
  • Orientation: Landscape or portrait display arrangement.
  • Multiple Displays: Configures more than one monitor.

Checking display information using Terminal

xrandr

On X11 sessions, xrandr can display and configure supported display outputs. Its functionality is limited or different under Wayland sessions.

You can normally change basic display settings using the graphical Settings application without using terminal commands.

11. Network and Sound Settings

Network settings

Ubuntu provides graphical controls for Wi-Fi, wired Ethernet, VPN and other supported network connections.

Useful network inspection commands:

ip addr ip route ping -c 4 ubuntu.com

Sound settings

Sound settings allow users to select audio output devices, input devices and volume levels.

Useful audio inspection command:

pactl info

On modern Ubuntu desktop installations, PipeWire commonly provides the audio and media infrastructure. The command's available output depends on the audio system installed.

12. Users and Login Settings

Ubuntu supports multiple user accounts. Each account can have its own home directory, settings and permissions.

Types of user accounts

Account Type Description
Administrator Can perform authorized administrative operations.
Standard User Uses the system with normal user permissions.
System User Used by system services and applications.

Checking the current username

whoami

Checking user identity and groups

id

Listing local user accounts

cat /etc/passwd
The /etc/passwd file contains account information. It does not contain users' actual login passwords.

13. Installing Applications Using GUI

Ubuntu provides graphical software management tools that allow users to search for, install and remove applications.

Using App Center

  1. Open App Center from the application grid or dock.
  2. Search for the required application.
  3. Open its application details.
  4. Review the application information.
  5. Select Install.
  6. Authenticate if requested.
  7. Wait for installation to finish.

Common application categories

  • Development tools.
  • Internet applications.
  • Office applications.
  • Graphics and multimedia tools.
  • System utilities.
Ubuntu can also install software using the APT package manager. You will study command-line package management in later lessons.

14. Desktop Customization

Desktop customization allows users to change the appearance and behaviour of the graphical interface.

Common customization options

  • Change wallpaper.
  • Select light or dark appearance.
  • Adjust dock position and visibility.
  • Change icon and text scaling where supported.
  • Configure keyboard shortcuts.
  • Manage desktop extensions.

GNOME Extensions

GNOME Extensions add or modify desktop functionality. They can change interface behaviour, panels, menus and other desktop features.

Install extensions only from trusted sources. Extensions can access or modify parts of the desktop environment, so review their permissions and compatibility.

15. Workspaces and Multitasking

A workspace is a separate virtual desktop area used to organize application windows.

Why use workspaces?

  • Separate programming applications from browsing.
  • Organize multiple tasks.
  • Reduce desktop clutter.
  • Switch between groups of application windows.

Example workspace organization

Workspace Applications
Workspace 1 Web browser and documentation.
Workspace 2 Text editor and C/C++ development tools.
Workspace 3 Ubuntu Terminal and system monitoring tools.
Workspaces are useful when several applications need to remain open simultaneously.

16. GUI and CLI: Understanding the Difference

Linux supports both graphical and command-line interfaces. They provide different ways to interact with the operating system.

GUI CLI
Graphical User Interface Command-Line Interface
Uses windows, menus and icons. Uses text commands.
Suitable for visual interaction. Suitable for automation and precise system operations.
Often easier for beginners. Important for system administration and programming.
May require more graphical resources. Can operate without a graphical desktop.

Example: Creating a directory

Using a graphical file manager:

  1. Open the file manager.
  2. Navigate to the required location.
  3. Right-click and select New Folder, where available.
  4. Enter the folder name.

Using the command line:

mkdir Linux_Practice

Both methods create a directory. The command-line method is especially useful for scripting and automation.

17. Desktop Environment and Linux Architecture

A desktop environment is one layer of the Linux operating system experience. It works with other system components.

Component Responsibility
Hardware Physical CPU, memory, storage and devices.
Linux Kernel Manages hardware resources, processes and memory.
System Services Provide background system functionality.
Display Server / Compositor Provides graphical display and window presentation.
Desktop Environment Provides panels, menus, windows and desktop applications.
User Applications Perform tasks such as browsing, editing and programming.

X11 and Wayland

X11 (X Window System) and Wayland are technologies used to provide graphical display functionality in Linux desktop environments.

Wayland is a modern display protocol. GNOME commonly uses Mutter as its Wayland compositor. GNOME can also run using an X11 session on systems that support it.

The desktop environment, display server or protocol, window manager and Linux kernel are related but different components.

19. Interview Questions and Answers

Q1. What is a Desktop Environment?

A desktop environment is a collection of graphical components and applications that provide a graphical user interface for interacting with an operating system.

Q2. What is a GUI?

A GUI is a graphical user interface that allows users to interact with a computer through windows, icons, menus and other graphical elements.

Q3. What is GNOME?

GNOME is an open-source desktop environment used by Ubuntu Desktop.

Q4. Name some Linux desktop environments.

GNOME, KDE Plasma, Xfce, Cinnamon, MATE and LXQt are examples of Linux desktop environments.

Q5. What is GNOME Shell?

GNOME Shell provides the main graphical interface of GNOME, including application overview and window management features.

Q6. What is a file manager?

A file manager is a graphical application used to browse, organize, copy, move and delete files and directories.

Q7. What is a workspace?

A workspace is a virtual desktop area used to organize application windows and support multitasking.

Q8. What is the difference between GUI and CLI?

GUI uses graphical elements, while CLI uses text-based commands to interact with the operating system.

Q9. What are X11 and Wayland?

X11 and Wayland are technologies used for graphical display functionality in Linux desktop environments.

Q10. What is the purpose of system settings?

System settings provide graphical controls for configuring display, sound, network, users and other operating system preferences.

Q11. Is the desktop environment part of the Linux kernel?

No. The desktop environment is a separate collection of user-space components that works with the Linux kernel.

Q12. Can Linux work without a desktop environment?

Yes. Linux can operate through a command-line interface without a graphical desktop environment.
