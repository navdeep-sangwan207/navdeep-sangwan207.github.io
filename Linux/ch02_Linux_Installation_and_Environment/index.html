Chapter Overview

This chapter introduces the installation of Linux and the setup of a Linux working environment. You will learn how to install Ubuntu, use virtual machines, understand the Linux desktop environment, and work with the terminal and Bash shell.

You will also learn how to manage multiple terminal windows, execute commands in different sessions, and work more efficiently in a Linux environment.
