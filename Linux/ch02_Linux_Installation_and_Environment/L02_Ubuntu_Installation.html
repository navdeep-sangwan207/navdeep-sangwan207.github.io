Ubuntu Installation

Learn how to download, prepare, install and configure Ubuntu Linux.

Learning Objectives

After completing this lesson, you will be able to:

  • Understand Ubuntu Linux and its installation requirements.
  • Download the correct Ubuntu ISO image.

  • Create a bootable USB drive.
  • Understand Ubuntu installation options.
  • Install Ubuntu on a physical computer or virtual machine.

1. Introduction to Ubuntu

Ubuntu is a popular Linux distribution based on Debian. It is developed and maintained by Canonical and supported by a large open-source community.

Ubuntu provides a graphical desktop environment, command-line tools, package management, networking utilities and software development tools.

Why use Ubuntu?

  • Free and open-source operating system.
  • User-friendly graphical desktop.
  • Strong command-line and shell support.
  • Large software repository.
  • Suitable for C and C++ programming.
  • Useful for Linux system programming and embedded development.
  • Widely used in servers, cloud computing and development environments.
Example: Ubuntu can be used to compile C programs using GCC, develop C++ applications using G++, write shell scripts and explore Linux system programming.

2. Ubuntu Versions and Releases

Ubuntu releases new versions periodically. There are two important release categories.

Long-Term Support (LTS)

LTS releases receive a longer support period and are commonly selected for professional, educational and development systems.

Interim Releases

Interim releases are released more frequently and provide newer software and features, but have a shorter support period.

Release Type Characteristics Typical Use
LTS Longer support period and stability focus Development and production systems
Interim Shorter support period and newer features Testing newer Linux features
Note: Always check the official Ubuntu website for the current release, support dates and installation requirements.

3. System Requirements

Before installing Ubuntu, check whether the computer meets the requirements of the selected Ubuntu release.

Component What to Check
Processor Supported processor architecture, normally 64-bit x86 for standard desktop images.
RAM Enough memory for the selected desktop environment and applications.
Storage Sufficient free disk space for the OS, applications and user files.
Display Supported graphics hardware and suitable display resolution.
USB USB drive for physical installation, if required.
Internet Recommended for updates and downloading additional software.
Requirements vary by Ubuntu release. Check the official installation guide before installing.

4. Downloading Ubuntu ISO

An ISO image is a file containing the installation image of an operating system. It can be written to a USB drive or attached to a virtual machine.

Download procedure

  1. Open the official Ubuntu website.
  2. Navigate to the Ubuntu Desktop download section.
  3. Select the required release.
  4. Download the ISO image.
  5. Save the file in a known location.

Official website: Ubuntu Desktop Download

Example ISO filename:
ubuntu-24.04.x-desktop-amd64.iso

The exact filename changes with the Ubuntu release. The amd64 label refers to the 64-bit x86 architecture; it also works on compatible Intel and AMD processors.

5. Verifying the ISO Image

After downloading an ISO image, verify its checksum. This helps detect accidental corruption or incomplete downloads.

What is SHA-256?

SHA-256 is a cryptographic hash algorithm that generates a 256-bit digest from input data. The resulting checksum can be compared with the value published by Ubuntu.

Verify using Windows PowerShell

Get-FileHash "C:\Users\YourName\Downloads\ubuntu.iso" -Algorithm SHA256

Verify using Linux Terminal

sha256sum ubuntu.iso

Verification procedure

  1. Open the official Ubuntu checksum information.
  2. Find the checksum corresponding to your downloaded ISO.
  3. Calculate the local SHA-256 checksum.
  4. Compare the two values character by character.
Expected result: The calculated SHA-256 checksum should exactly match the official checksum.
A matching checksum confirms that the downloaded file matches the published checksum. It does not, by itself, prove that the source website or file is trustworthy.

6. Creating a Bootable USB Drive

A bootable USB drive contains the Ubuntu installer and allows a physical computer to start the installation environment without using its existing operating system.

Requirements

  • Ubuntu ISO image.
  • USB flash drive with sufficient capacity.
  • Bootable USB creation software.
  • A computer that supports USB booting.

Common tools

Tool Platform
Rufus Windows
balenaEtcher Windows, Linux and macOS
Startup Disk Creator Ubuntu

Creating USB using Rufus

  1. Connect the USB flash drive to the computer.
  2. Open Rufus.
  3. Select the correct USB device.
  4. Choose the downloaded Ubuntu ISO image.
  5. Use the recommended settings for the target computer.
  6. Start the writing process.
  7. Wait until Rufus completes the operation.
  8. Safely eject the USB drive.
Warning: Creating a bootable USB normally erases the existing contents of the selected USB drive. Confirm the correct drive before starting.

7. Booting from USB

After creating the bootable USB, the computer must be configured to start from it.

Boot procedure

  1. Insert the bootable USB drive.
  2. Restart the computer.
  3. Open the one-time boot menu or firmware boot settings.
  4. Select the USB device.
  5. Wait for the Ubuntu startup screen.
  6. Select the option to try or install Ubuntu, as presented.

BIOS and UEFI

BIOS and UEFI are firmware interfaces that initialize hardware and help start the operating system.

BIOS UEFI
Older firmware interface Modern firmware interface
Commonly associated with MBR booting Commonly associated with GPT and EFI booting
More limited modern firmware features Supports features such as Secure Boot
Boot-menu keys vary by computer manufacturer. Common keys include F12, F10, F9 and Esc. Check the computer manual for the correct key.

8. Ubuntu Installation Options

Ubuntu provides different installation choices depending on the installer version and the computer configuration.

Try Ubuntu

This option starts a temporary live environment. You can explore the desktop and check basic hardware compatibility without immediately installing Ubuntu on the internal disk.

Install Ubuntu

This option starts the installation process and allows Ubuntu to be installed on the selected storage device.

Installation choices

  • Install Ubuntu alongside another operating system, if supported.
  • Erase disk and install Ubuntu.
  • Manual partitioning, where available.
Important: The erase-disk option can delete existing operating systems and personal files on the selected disk. Back up important data and carefully verify the target disk before proceeding.

9. Installing Ubuntu in VirtualBox

VirtualBox allows Ubuntu to run as a guest operating system inside an existing host operating system, such as Windows.

Host OS: The operating system running directly on the physical computer.
Guest OS: The operating system running inside the virtual machine.

Requirements

  • Oracle VirtualBox installed on the host computer.
  • Ubuntu ISO image.
  • Enough available RAM and storage.
  • Hardware virtualization support enabled where required.

Step-by-step installation

  1. Download and install Oracle VirtualBox.
  2. Open VirtualBox.
  3. Click New to create a virtual machine.
  4. Enter a name such as Ubuntu.
  5. Select Linux as the operating system type.
  6. Select the appropriate Ubuntu 64-bit version.
  7. Assign suitable memory to the virtual machine.
  8. Create a virtual hard disk.
  9. Select the downloaded Ubuntu ISO as the installation medium.
  10. Start the virtual machine.
  11. Follow the Ubuntu installer instructions.
  12. Restart the virtual machine after installation.

Example virtual machine configuration

Setting Example
VM Name Ubuntu
OS Type Linux
Architecture 64-bit
RAM 4 GB, if the host has enough available memory
Virtual Disk 30–40 GB or more, depending on workload
Network NAT for basic internet access
These are example settings, not universal minimum requirements. Allocate resources according to the Ubuntu release, applications and host computer capacity.

Advantages of VirtualBox installation

  • No need to repartition the physical disk.
  • Windows and Ubuntu can run at the same time.
  • Virtual machine snapshots can help with recovery.
  • Useful for Linux programming practice.
  • Easy to create and remove test environments.

10. Ubuntu Installation Process

The exact installer screens can vary by Ubuntu release. A typical installation includes the following stages.

  1. Language selection: Select the language for the installation.
  2. Keyboard layout: Select the appropriate keyboard layout.
  3. Network configuration: Connect to a network if available.
  4. Installation type: Select the installation options presented.
  5. Disk configuration: Choose the target disk and partitioning method.
  6. User creation: Enter the user name, computer name and password.
  7. Time zone: Select the appropriate time zone.
  8. Installation: Allow the installer to copy and configure system files.
  9. Restart: Restart the computer or virtual machine when prompted.
Expected result: Ubuntu starts and displays its login screen or desktop. You can log in using the account created during installation.

11. First Boot and Initial Configuration

After installation, perform basic configuration to prepare Ubuntu for regular use.

Step 1: Update package information

sudo apt update

Downloads the latest package information from configured software repositories.

Step 2: Upgrade installed packages

sudo apt upgrade

Installs available updates for installed packages.

Step 3: Check Ubuntu version

lsb_release -a

Displays distribution information such as Ubuntu release version and codename.

Step 4: Check kernel version

uname -r

Displays the currently running Linux kernel version.

Step 5: Check system architecture

uname -m
Example output:
x86_64
This indicates a 64-bit x86 architecture.

Step 6: Check storage

df -h

Displays filesystem disk-space usage in a human-readable format.

Step 7: Check memory

free -h

Displays memory and swap usage.

12. Installing Essential Development Tools

Ubuntu can be configured for C and C++ programming and Linux systems development.

Install GCC and G++

sudo apt install build-essential

The build-essential package installs commonly required development tools, including GCC, G++ and Make.

Check GCC version

gcc --version

Check G++ version

g++ --version

Install Git

sudo apt install git

Check Git version

git --version

Install additional utilities

sudo apt install curl wget vim
Development relevance: These tools provide a foundation for learning C/C++, shell scripting, Git, Linux system programming and embedded Linux development.

13. Understanding the Ubuntu Directory Structure

Linux organizes files and directories under a single root directory represented by /.

Directory Purpose
/ Root of the filesystem hierarchy
/home Personal directories of normal users
/root Home directory of the root user
/etc System-wide configuration files
/bin Essential user command locations on systems using this layout
/usr Many user applications, libraries and shared resources
/var Variable data such as logs and caches
/tmp Temporary files
/boot Boot-related files
/dev Device files

You will study the Linux filesystem hierarchy in detail in a later chapter.

14. Common Installation Problems

Problem Possible Cause Basic Check
USB does not boot Incorrect boot order or improperly created USB Check boot menu and recreate the USB if necessary.
Installation freezes Hardware compatibility or installation-media issue Check the ISO and try another USB port or installation medium.
Insufficient disk space Not enough available storage Check the target disk and free space.
No internet connection Network or adapter configuration Check network settings and adapter status.
Virtual machine does not start Virtualization disabled or insufficient resources Check firmware virtualization settings and VM configuration.
Black screen Possible graphics compatibility issue Check graphics settings and Ubuntu troubleshooting guidance.
Do not change disk partitions or firmware settings randomly. Identify the problem and consult the official documentation before making changes that could affect existing data.

16. Interview Questions and Answers

Q1. What is Ubuntu?

Ubuntu is a Linux distribution based on Debian. It provides a complete operating system with graphical and command-line environments.

Q2. What is an ISO image?

An ISO image is a file containing a disk image, commonly used to distribute operating system installation media.

Q3. Why do we verify an ISO checksum?

To check whether the downloaded file matches the published checksum and has not been accidentally corrupted or modified.

Q4. What is a bootable USB?

A USB drive prepared with bootable installation media that can start a computer and launch an operating system installer.

Q5. What is the difference between Try Ubuntu and Install Ubuntu?

Try Ubuntu starts a temporary live environment, while Install Ubuntu starts the process of installing the operating system on a selected storage device.

Q6. What is VirtualBox?

VirtualBox is virtualization software that allows multiple operating systems to run as virtual machines on one physical computer.

Q7. What is the difference between a host OS and a guest OS?

The host OS runs on the physical computer. The guest OS runs inside a virtual machine.

Q8. What does sudo apt update do?

It refreshes the local package index using the configured software repositories.

Q9. What is the purpose of build-essential?

It installs commonly required development tools, including GCC, G++ and Make.

Q10. What is the purpose of uname -r?

It displays the version of the currently running Linux kernel.
