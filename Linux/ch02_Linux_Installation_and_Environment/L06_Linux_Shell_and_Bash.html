Linux Shell and Bash

1. What Is a Linux Shell?

A shell is a command interpreter that provides an interface between the user and the operating system.

It accepts commands from the user, interprets them and requests the operating system to perform the required operations. It can also start programs, manage processes and execute scripts.

Basic Working

User | v Shell | v Operating System | v Hardware

This is a simplified conceptual representation. The shell uses operating-system interfaces and system calls through programs and libraries to perform operations.

Functions of a Shell

  • Accepts and interprets user commands.
  • Starts and manages command execution.
  • Supports variables and environment settings.
  • Provides input and output redirection.
  • Supports pipelines and command chaining.
  • Provides programming constructs such as conditions and loops.
  • Executes shell scripts for automation.

2. Shell vs Terminal

The terminal and shell are related but perform different functions.

Terminal Shell
Provides a text-based interface. Interprets and executes commands.
Displays command output. Processes command input.
Examples: GNOME Terminal, Konsole. Examples: Bash, Zsh, Fish.
Acts as the user-facing interface. Acts as the command interpreter.
Example: GNOME Terminal is a terminal application. Bash is a shell that can run inside that terminal.

3. Types of Linux Shells

Linux and Unix-like systems support several command interpreters. Different shells provide different features and syntax.

Shell Description
sh Traditional Unix shell interface and a common name for the POSIX shell.
Bash Bourne Again Shell; widely used on Linux systems.
Dash A lightweight POSIX-compatible shell commonly used for system scripts on Ubuntu.
Zsh An interactive shell with advanced completion and customization features.
Ksh KornShell, a Unix shell with scripting features.
Fish Friendly Interactive Shell with user-friendly interactive features.
A system may have several shells installed. The shell used by a particular user depends on the account configuration and the shell started by the terminal or session.

4. Introduction to Bash

Bash stands for Bourne Again Shell. It is a widely used command interpreter for Linux and other Unix-like operating systems.

Bash is an enhanced successor to the original Bourne shell, commonly associated with the sh name.

Important Bash Features

  • Command execution.
  • Command history.
  • Command-line completion.
  • Shell variables and environment variables.
  • Aliases and functions.
  • Input and output redirection.
  • Pipelines and command chaining.
  • Conditional statements and loops.
  • Shell scripting and automation.

Check Bash Availability

bash --version
Example output:
GNU bash, version 5.x.x

The exact version depends on the installed Ubuntu release and updates.

5. Identifying the Current Shell

You can use several commands to inspect the shell environment.

5.1 Display the Shell Environment Variable

echo $SHELL

This normally displays the user's configured login shell.

Example output:
/bin/bash

5.2 Display the Current Shell Process

ps -p $$ -o comm=

This displays the name of the shell process associated with the current shell context.

5.3 Display the Shell Version

bash --version
$SHELL usually indicates the configured login shell, not necessarily the currently executing shell. The process inspection command is more useful for identifying the active shell process.

6. Shell Variables

A shell variable stores information that can be used by commands and shell scripts.

6.1 Creating a Variable

name="Linux" age=25

In Bash, do not put spaces around the assignment operator.

6.2 Accessing a Variable

Use the dollar sign $ to access a variable's value.

name="Linux" echo $name
Output:
Linux

6.3 Using Braces

Braces clearly identify the variable name when additional text follows it.

name="Linux" echo "Welcome to ${name}Programming"
Output:
Welcome to LinuxProgramming

6.4 Removing a Variable

name="Linux" unset name echo "$name"

After unset, the variable is no longer defined in the current shell.

Variable Naming Rules

  • Names can contain letters, numbers and underscores.
  • Names should not begin with a number.
  • Variable names are case-sensitive.
  • Spaces are not allowed around the assignment operator.
Bash variable names are case-sensitive. name, Name and NAME are different variables.

7. Environment Variables

An environment variable is a variable made available to child processes launched from the current shell.

Environment variables are commonly used to store configuration information such as user details, directory locations and executable search paths.

Common Environment Variables

Variable Purpose
HOME Current user's home directory.
USER Current username in common Linux environments.
PATH Directories searched when locating executable commands.
SHELL Configured login shell path in common environments.
PWD Current working directory maintained by the shell.
LANG Locale and language settings.

Display Environment Variables

echo $HOME echo $USER echo $PATH printenv

Create an Environment Variable

export COURSE="Linux Programming" echo "$COURSE"
Output:
Linux Programming

Difference Between Shell and Environment Variables

course="Linux" export course

A normal shell variable is available in the current shell. Using export marks it for inclusion in the environment of subsequently started child processes.

8. Command Substitution

Command substitution allows the output of a command to be stored in a variable or used as part of another command.

Modern Syntax

today=$(date) echo "$today"

Another Example

current_user=$(whoami) echo "Current user: $current_user"
Example output:
Current user: username

The older backtick syntax also exists:

today=`date` echo "$today"
Prefer $(command) because it is easier to read and can be nested more conveniently than backticks.

9. Quoting in Bash

Quoting controls how the shell interprets special characters, spaces and variable expansions.

9.1 Single Quotes

Single quotes preserve the literal characters inside them. Variable expansion does not occur.

name="Linux" echo '$name'
Output:
$name

9.2 Double Quotes

Double quotes preserve most characters literally but allow variable expansion and command substitution.

name="Linux" echo "Welcome to $name"
Output:
Welcome to Linux

9.3 Backslash

A backslash can escape a special character so that the shell treats it literally.

echo "The price is \$10"
Output:
The price is $10
Quoting Method Variable Expansion Purpose
Single quotes ' ' No Preserves literal text.
Double quotes " " Yes Preserves text while allowing expansion.
Backslash \ Depends on context Escapes selected special characters.

10. Aliases in Bash

An alias is a shortcut that represents a command or a sequence of command words.

Create an Alias

alias ll='ls -l'

Use the Alias

ll

The shell expands the alias into the associated command when appropriate.

Display Existing Aliases

alias

Remove an Alias

unalias ll

Make an Alias Persistent

To make an alias available in future interactive Bash sessions, add it to the user's ~/.bashrc file.

echo "alias ll='ls -l'" >> ~/.bashrc source ~/.bashrc
The source command reads and executes commands from a file in the current shell. Here, it reloads the Bash configuration without opening a new terminal.

11. Wildcards in Bash

Wildcards are special pattern characters used to match filenames and other strings.

Wildcard Meaning Example
* Matches zero or more characters. *.txt
? Matches exactly one character. file?.txt
[abc] Matches one character from the set. file[123].txt
[0-9] Matches one character in the specified range. file[0-9].txt

Examples

ls *.txt ls file?.txt ls file[123].txt

These patterns are expanded by the shell to matching filenames before the command is executed.

12. Command Chaining

Bash allows multiple commands to be connected using operators.

12.1 Semicolon (;)

Executes commands sequentially, regardless of whether the previous command succeeds.

pwd; date; whoami

12.2 AND Operator (&&)

Executes the next command only if the previous command succeeds.

mkdir Test && cd Test

12.3 OR Operator (||)

Executes the next command only if the previous command fails.

cd Test || echo "Directory not found"
Operator Behaviour
; Run commands sequentially.
&& Run the next command if the previous succeeds.
|| Run the next command if the previous fails.

13. Shell Scripts

A shell script is a text file containing shell commands that can be executed together.

Shell scripts are used to automate repetitive tasks, system administration, file operations and development workflows.

13.1 Create a Shell Script

Create a file named hello.sh.

#!/bin/bash echo "Hello, Linux!" echo "Welcome to Bash scripting."

13.2 Understanding the Script

Element Explanation
#!/bin/bash Shebang; identifies the interpreter to use when the script is executed directly.
echo Displays text on the terminal.
hello.sh Shell script filename.

13.3 Execute the Script Using Bash

bash hello.sh

13.4 Execute the Script Directly

First, grant execute permission:

chmod +x hello.sh

Then execute it:

./hello.sh
Expected output:
Hello, Linux! Welcome to Bash scripting.
The ./ prefix specifies that the script should be executed from the current directory. The current directory is not normally included in the executable search path.

14. Basic Bash Script with Variables

Create a file named system_info.sh.

#!/bin/bash username=$(whoami) current_date=$(date) echo "Linux System Information" echo "------------------------" echo "Username: $username" echo "Date: $current_date" echo "Home Directory: $HOME"

Run the Script

bash system_info.sh
Example output:
Linux System Information ------------------------ Username: username Date: Wed Nov 4 21:00:00 IST 2026 Home Directory: /home/username

Actual date, time and username depend on your system.

15. Basic Bash Script with User Input

Bash provides the read command to accept input from the user.

Create a file named user_input.sh.

#!/bin/bash echo "Enter your name:" read name echo "Welcome, $name!"

Execute the Script

bash user_input.sh
Example interaction:
Enter your name: Navdeep Welcome, Navdeep!

The read command stores the entered text in the variable named name.

16. Bash Configuration Files

Bash uses configuration files to customize its environment and interactive behaviour.

File Purpose
~/.bashrc Commonly used for interactive non-login Bash shell configuration.
~/.bash_profile Login Bash configuration file, if present.
~/.profile Common login configuration file used by some shells and login environments.
/etc/profile System-wide login shell configuration for supported shells.

View Bash Configuration

cat ~/.bashrc

Reload Bash Configuration

source ~/.bashrc
Configuration files are loaded according to the shell's login or interactive mode. They are not all automatically read every time a terminal opens.

18. Common Bash Errors

Error Possible Reason Solution
command not found Command is unavailable or misspelled. Check spelling and command availability.
bad assignment Incorrect variable assignment syntax. Remove spaces around =.
Permission denied Script lacks execute permission or access rights. Check permissions and use chmod when appropriate.
No such file or directory Incorrect filename or path. Verify the file location.
unexpected end of file Missing quote, closing statement or other syntax element. Inspect the script for incomplete syntax.
bad interpreter Invalid or unavailable interpreter path in the shebang. Check the interpreter path.

19. Interview Questions and Answers

Q1. What is a Linux shell?

A shell is a command interpreter that accepts user commands and executes them or launches other programs.

Q2. What is Bash?

Bash stands for Bourne Again Shell. It is a widely used command interpreter and scripting language.

Q3. What is the difference between a shell and a terminal?

A terminal provides the text interface, whereas a shell interprets the commands entered through that interface.

Q4. What is a shell variable?

A shell variable stores a value that can be accessed by commands and scripts in the current shell.

Q5. What is an environment variable?

An environment variable is a variable exported by a process and made available to its child processes.

Q6. What is the purpose of the PATH variable?

PATH contains a list of directories searched by the shell when locating executable commands.

Q7. What is the difference between single and double quotes in Bash?

Single quotes preserve literal text. Double quotes allow variable expansion and command substitution.

Q8. What is command substitution?

Command substitution captures the output of a command and uses it as part of another command or assignment.

Q9. What is an alias?

An alias is a shortcut representing a command or sequence of command words.

Q10. What is a shell script?

A shell script is a file containing shell commands that can be executed together to automate tasks.

Q11. What is a shebang?

A shebang is the interpreter directive at the beginning of an executable script, such as #!/bin/bash.

Q12. What is the difference between ; and &&?

A semicolon executes the next command regardless of the previous command's status. The AND operator executes the next command only if the previous command succeeds.

Q13. What is the purpose of ~/.bashrc?

It commonly stores configuration for interactive non-login Bash sessions.

Q14. Why is Bash useful in embedded systems?

Bash can automate development tasks, run build commands, organize files, execute utilities and support testing workflows on Linux-based development systems.
