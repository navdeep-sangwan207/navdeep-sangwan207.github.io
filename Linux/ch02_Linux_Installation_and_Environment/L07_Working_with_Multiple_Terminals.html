1. Introduction to Multiple Terminals

A terminal is an interface used to enter commands and interact with a Linux system. A user can open more than one terminal window or tab and execute different commands in each one.

Working with multiple terminals is useful when performing several tasks simultaneously, such as running a program, monitoring system activity and editing files.

Example Workflow

Terminal Task
Terminal 1 Compile a C program.
Terminal 2 Execute the compiled program.
Terminal 3 Monitor system processes.
Terminal 4 View application logs or edit configuration files.
Multiple terminals allow different command-line tasks to be performed independently without repeatedly stopping one task to start another.

2. Why Use Multiple Terminals?

  • Multitasking: Perform different operations simultaneously.
  • Development: Compile code in one terminal and run it in another.
  • Debugging: Monitor program output while executing tests.
  • System monitoring: Observe CPU, memory and process activity.
  • Server management: Run services and inspect logs separately.
  • Remote administration: Manage multiple remote sessions.
  • Automation: Run scripts while monitoring their output.

Example: C Programming Workflow

Terminal 1 – Compile a program:

gcc main.c -o main

Terminal 2 – Execute the program:

./main

Terminal 3 – Monitor system processes:

top

This arrangement separates compilation, program execution and system monitoring.

3. Opening Multiple Terminal Windows

Ubuntu allows users to open multiple terminal windows.

Method 1: Keyboard Shortcut

Press Ctrl + Alt + T to open a terminal. Repeat the shortcut to open another terminal window in standard Ubuntu desktop configurations.

Method 2: Applications Menu

  1. Open the Applications menu.
  2. Search for Terminal.
  3. Open the Terminal application again.

Method 3: Open a New Terminal from an Existing Terminal

On Ubuntu installations with GNOME Terminal, you can use:

gnome-terminal

This starts another GNOME Terminal window when the application is installed and available.

The exact application and command may differ between Ubuntu versions and desktop environments.

4. Working with Terminal Tabs

Terminal tabs allow multiple terminal sessions to be managed inside one application window.

Common GNOME Terminal Shortcuts

Shortcut Function
Ctrl + Shift + T Open a new terminal tab.
Ctrl + Shift + W Close the current terminal tab.
Ctrl + Page Up Move to the previous tab.
Ctrl + Page Down Move to the next tab.
Alt + 1 Select the first tab in supported configurations.

Practical Example

  1. Open the Ubuntu terminal.
  2. Press Ctrl + Shift + T to create a second tab.
  3. In the first tab, run pwd.
  4. In the second tab, run date.
  5. Switch between the tabs.
Each terminal tab normally has its own shell process and working directory. Changing directories in one tab does not automatically change the directory in another.

5. Split Terminal Panes

Some terminal applications support split panes. A split terminal displays multiple command-line areas inside one window.

For example, one pane can run a program while another displays system information.

Common Applications with Split-Pane Support

  • Tilix
  • Terminator
  • tmux
  • GNU Screen
Standard GNOME Terminal versions may not provide built-in split panes. A terminal multiplexer or another terminal application can provide this functionality.

6. Foreground and Background Processes

A process is a running instance of a program. Linux allows processes to execute in the foreground or background relative to a shell.

6.1 Foreground Process

A foreground process occupies the terminal while it is running. The shell normally waits for that process to finish before accepting another command.

sleep 30

This command runs for approximately 30 seconds. The terminal remains occupied until the command finishes or is interrupted.

6.2 Background Process

A background process runs without occupying the shell's foreground command line.

sleep 30 &

The ampersand & starts the command as a background job.

Example output:
[1] 2450

The job number and process ID shown are examples. Actual values vary.

Foreground vs Background

Foreground Background
Runs as the active foreground job. Runs as a background job.
Normally occupies the shell's input. Allows the shell to accept another command.
Started without a trailing ampersand in normal interactive usage. Can be started using &.

7. Managing Jobs

Bash provides job-control commands to manage processes started from an interactive shell.

7.1 jobs

Displays jobs associated with the current shell.

jobs

7.2 Suspend a Foreground Process

Press:

Ctrl + Z

This sends a terminal stop signal to the foreground process in normal interactive job-control usage.

7.3 bg

Resumes a stopped job in the background.

bg

7.4 fg

Brings a background or stopped job to the foreground.

fg

7.5 Select a Specific Job

jobs fg %1 bg %1

%1 identifies job number 1 in the current shell.

7.6 Stop a Foreground Process

Press Ctrl + C to send an interrupt signal to the foreground process.

Job numbers belong to the shell that started the jobs. A different terminal window normally has its own independent job list.

8. Process Management Commands

Linux provides commands for viewing and managing running processes.

8.1 ps

Displays information about processes.

ps ps aux

8.2 top

Displays processes and continuously updates system resource information.

top

Press q to quit the top interface.

8.3 pgrep

Searches for process IDs by process name or pattern.

pgrep bash

8.4 kill

Sends a signal to a process using its process ID.

kill PID

For example, to request normal termination:

kill 2450

The PID is an example. Replace it with the actual process ID.

Do not terminate unknown processes. The kill -9 command sends SIGKILL and prevents a process from performing normal cleanup. Use it only when necessary.

9. GNU Screen

GNU Screen is a terminal multiplexer. It allows multiple terminal sessions to run inside one terminal interface.

It can also keep a session running after a user disconnects from a remote terminal connection, allowing the user to reconnect later.

9.1 Install Screen

sudo apt update sudo apt install screen

9.2 Start a Screen Session

screen

9.3 Create a Named Session

screen -S mysession

9.4 Detach from a Session

Press:

Ctrl + A, then D

The session continues running in the background.

9.5 List Sessions

screen -ls

9.6 Reattach to a Session

screen -r mysession

9.7 End a Session

Inside the Screen session, type:

exit
Screen is particularly useful for long-running commands on remote Linux servers.

10. tmux – Terminal Multiplexer

tmux stands for Terminal Multiplexer. It allows multiple terminal sessions to be managed through one terminal window.

It supports sessions, windows and panes.

10.1 Install tmux

sudo apt update sudo apt install tmux

10.2 Start tmux

tmux

10.3 Create a Named Session

tmux new -s development

10.4 Detach from a Session

Press the tmux prefix key followed by d.

Ctrl + B, then D

10.5 List Sessions

tmux ls

10.6 Reattach to a Session

tmux attach -t development

10.7 Create a New Window

Press:

Ctrl + B, then C

10.8 Switch Between Windows

Use:

Ctrl + B, then N Ctrl + B, then P

N moves to the next window, while P moves to the previous window.

10.9 Split Panes

Split the current pane horizontally:

Ctrl + B, then "

Split the current pane vertically:

Ctrl + B, then %

10.10 Switch Between Panes

Press the prefix key and use the arrow keys:

Ctrl + B, then Arrow Key

10.11 Close a Pane

Type exit in the active pane or use:

Ctrl + D
tmux is widely used by Linux developers and system administrators because it provides persistent sessions, multiple windows and split panes.

11. Screen vs tmux

Feature GNU Screen tmux
Terminal multiplexing Yes Yes
Persistent sessions Yes Yes
Multiple windows Yes Yes
Split panes Yes, with its own commands Yes, with convenient pane controls
Customization Supported Extensive configuration options
Common use Persistent terminal sessions Multiplexing and terminal workflows

Both tools are useful. The choice depends on the user's workflow and preference.

12. Remote Terminal Access with SSH

SSH stands for Secure Shell. It is a network protocol used to securely access and manage remote computers.

Connect to a Remote Linux System

ssh username@192.168.1.100

Replace the username and IP address with the actual remote system details.

Example Workflow

  1. Open a terminal on the local computer.
  2. Connect to a remote Linux computer using SSH.
  3. Run commands on the remote system.
  4. Open another local terminal for a separate task if needed.
  5. Use exit to close the remote shell session.
SSH requires a reachable remote system with an SSH server configured and appropriate authentication. The example IP address is illustrative.

Perform these exercises in your Ubuntu environment.

fg

14. Common Problems and Solutions

Problem Possible Reason Solution
tmux: command not found tmux is not installed. Install it using the package manager.
screen: command not found GNU Screen is not installed. Install the screen package.
No such job Job number is incorrect or no longer exists. Check jobs in the current shell.
Session not found Incorrect session name or session has ended. Use tmux ls or screen -ls.
Permission denied Insufficient permissions. Check access permissions and user privileges.
SSH connection refused Remote SSH service may not be running or reachable. Check network access and SSH server configuration.

15. Interview Questions and Answers

Q1. Why are multiple terminals used in Linux?

They allow users to perform different command-line tasks simultaneously, such as compiling programs, running applications and monitoring system activity.

Q2. What is a terminal tab?

A terminal tab is an independent terminal session displayed within the same terminal application window.

Q3. What is a foreground process?

A foreground process is the active process associated with the shell's terminal input and output.

Q4. What is a background process?

A background process runs without occupying the shell's foreground command line.

Q5. What does the ampersand operator do?

The ampersand starts a command as a background job in an interactive shell.

Q6. What is the purpose of the jobs command?

It displays the jobs associated with the current shell.

Q7. What is the difference between fg and bg?

fg brings a job to the foreground, while bg resumes a stopped job in the background.

Q8. What does Ctrl + Z do?

It normally suspends the foreground process by sending a terminal stop signal.

Q9. What is a terminal multiplexer?

A terminal multiplexer allows multiple terminal sessions, windows or panes to be managed within a single terminal interface.

Q10. What is GNU Screen?

GNU Screen is a terminal multiplexer that supports multiple sessions and the ability to detach and reattach sessions.

Q11. What is tmux?

tmux is a terminal multiplexer that provides sessions, windows and panes.

Q12. What is SSH?

SSH is a secure network protocol used for remote command-line access and system administration.

Q13. Why are tmux and Screen useful on remote servers?

They allow terminal sessions to continue running after a network connection is disconnected, so users can reconnect to those sessions later.

Q14. What is the difference between a process ID and a job number?

A process ID identifies a process system-wide, while a job number identifies a job managed by a particular shell.
