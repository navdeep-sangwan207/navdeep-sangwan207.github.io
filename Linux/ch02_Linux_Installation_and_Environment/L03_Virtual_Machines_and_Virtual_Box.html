Virtual Machines and VirtualBox

Understand virtualization and create, configure and manage Linux virtual machines.

Learning Objectives

After completing this lesson, you will be able to:

  • Understand virtualization and virtual machines.
  • Differentiate between host and guest operating systems.
  • Understand hypervisors and their types.
  • Install and configure Oracle VirtualBox.
  • Create and manage Ubuntu virtual machines.
  • Understand virtual disks and storage allocation.
  • Configure virtual machine networking.
  • Use snapshots and VirtualBox Guest Additions.
  • Identify and troubleshoot common VM problems.

1. Introduction to Virtualization

Virtualization is a technology that allows multiple virtual computing environments to run on a single physical computer.

Instead of requiring a separate physical computer for every operating system, virtualization allows a software layer called a hypervisor to create and manage virtual machines.

Example

Suppose a physical computer runs Windows 11. Using VirtualBox, you can create a virtual machine and install Ubuntu Linux inside it.

Physical Computer: Windows 11
Virtualization Software: Oracle VirtualBox
Virtual Machine: Ubuntu Linux

Applications of virtualization

  • Running Linux on a Windows computer.
  • Testing different operating systems.
  • Software development and debugging.
  • Server consolidation.
  • Cybersecurity and isolated testing environments.
  • Learning Linux administration.
  • Testing embedded Linux development tools.

2. What is a Virtual Machine?

A Virtual Machine (VM) is a software-based computer that behaves like a physical computer.

A VM has virtual hardware such as a processor, RAM, storage, network adapter and display adapter. An operating system can be installed on this virtual hardware.

Components of a virtual machine

Component Purpose
Virtual CPU Provides virtual processor resources.
Virtual RAM Provides memory allocated from the host.
Virtual Hard Disk Stores the guest operating system and files.
Virtual Network Adapter Connects the VM to a virtual or physical network.
Virtual Display Adapter Provides graphical display functionality.
Virtual USB Controller Provides access to supported USB devices.

Virtual machine characteristics

  • Runs an independent guest operating system.
  • Uses resources allocated from the host computer.
  • Stores virtual disk data in files on the host.
  • Can be started, stopped and paused.
  • Can be copied or backed up when properly shut down.

3. Host Operating System and Guest Operating System

These two terms are important when working with virtual machines.

Host Operating System

The host OS is the operating system installed directly on the physical computer. It manages the actual hardware.

Guest Operating System

The guest OS is the operating system installed inside a virtual machine.

Host OS Guest OS
Runs on physical hardware. Runs inside a virtual machine.
Manages physical resources. Uses virtual resources assigned by the hypervisor.
Can be Windows or Linux. Can be Ubuntu, Windows or another supported OS.
Practical example: If your laptop runs Windows 11 and VirtualBox runs Ubuntu, Windows 11 is the host OS and Ubuntu is the guest OS.

4. What is a Hypervisor?

A hypervisor, also called a Virtual Machine Monitor (VMM), is the software layer responsible for creating and managing virtual machines.

It allocates virtual CPU, memory, storage and network resources to virtual machines and manages their execution.

Types of Hypervisors

Type 1: Bare-Metal Hypervisor

A Type 1 hypervisor runs directly on the physical hardware rather than on top of a general-purpose host operating system.

Examples:

  • VMware ESXi
  • Microsoft Hyper-V architecture in its hypervisor role
  • Xen

Type 2: Hosted Hypervisor

A Type 2 hypervisor runs as an application on an existing host operating system.

Examples:

  • Oracle VirtualBox
  • VMware Workstation
Type 1 Type 2
Runs directly on physical hardware. Runs on a host operating system.
Commonly used in server environments. Commonly used on desktop computers.
Designed for virtualization infrastructure. Convenient for learning and development.
VirtualBox is commonly classified as a Type 2 hosted hypervisor. Its implementation can use hardware virtualization features provided by the CPU.

5. Introduction to Oracle VirtualBox

Oracle VirtualBox is a cross-platform virtualization application that allows users to create and run virtual machines.

Features of VirtualBox

  • Supports multiple guest operating systems.
  • Provides configurable virtual hardware.
  • Supports virtual hard disks.
  • Provides virtual networking modes.
  • Supports snapshots.
  • Supports shared folders.
  • Provides USB device support, subject to configuration.
  • Supports Guest Additions for improved integration.

Official website: Oracle VirtualBox

Downloads: VirtualBox Downloads

Download VirtualBox from its official website. Check the supported host operating systems and version-specific installation instructions.

6. Hardware Virtualization

Modern processors provide hardware virtualization extensions that help hypervisors run virtual machines efficiently.

Intel VT-x

Intel Virtualization Technology (VT-x) provides processor support for hardware-assisted virtualization.

AMD-V

AMD Virtualization (AMD-V), also known as SVM in some firmware settings, provides hardware virtualization support on compatible AMD processors.

Why is virtualization support important?

  • Allows efficient execution of guest operating systems.
  • Improves VM performance and compatibility.
  • Supports modern 64-bit guest operating systems.
Virtualization may need to be enabled in the computer's BIOS/UEFI settings. The exact setting name depends on the processor and motherboard manufacturer.

7. Installing VirtualBox on Windows

Requirements

  • A supported Windows host operating system.
  • Compatible processor with virtualization support.
  • Sufficient RAM and free storage.
  • Administrator permission for installation.

Installation procedure

  1. Open the official VirtualBox download website.
  2. Download the Windows host installer.
  3. Locate the downloaded installer.
  4. Run the installer.
  5. Follow the setup wizard.
  6. Review the available installation components.
  7. Complete the installation.
  8. Restart Windows if the installer requests it.
  9. Open Oracle VirtualBox.
After installation, VirtualBox provides an interface for creating, configuring and managing virtual machines.

8. Creating a New Virtual Machine

A virtual machine must be created before installing Ubuntu inside VirtualBox.

Step-by-step procedure

  1. Open Oracle VirtualBox.
  2. Select New.
  3. Enter the virtual machine name, such as Ubuntu.
  4. Select the Ubuntu ISO image if the wizard provides this option.
  5. Choose Linux as the operating system type, if required.
  6. Select the appropriate 64-bit Ubuntu version.
  7. Configure memory allocation.
  8. Configure virtual processors.
  9. Create a virtual hard disk.
  10. Review the configuration.
  11. Finish creating the virtual machine.

Example configuration

Setting Example Value
Name Ubuntu
Type Linux
Version Ubuntu 64-bit
Memory 4 GB, if available without starving the host
Processors 2 virtual CPUs, if supported and available
Virtual Disk 40 GB example capacity
Do not allocate all the host computer's RAM or CPU cores to a virtual machine. The host operating system also needs resources to run smoothly.

9. Virtual Machine Memory and CPU Allocation

RAM Allocation

VirtualBox reserves a portion of the host computer's physical memory for the running virtual machine.

For example, if a computer has 12 GB of RAM and 4 GB is allocated to a running Ubuntu VM, that memory is reserved for the guest while it is running.

CPU Allocation

Virtual processors are presented to the guest operating system. The hypervisor schedules their execution on the host's physical processor resources.

Important: Allocating more virtual CPUs does not automatically make a VM faster. The workload, host processor, memory and other running applications affect performance.

10. Virtual Hard Disks

A virtual hard disk is a file or set of files on the host computer that acts as a storage device for a virtual machine.

Common VirtualBox disk formats

Format Description
VDI VirtualBox Disk Image, VirtualBox's native disk format.
VHD Virtual Hard Disk format.
VMDK Virtual Machine Disk format, associated with VMware.

Dynamically allocated disk

A dynamically allocated virtual disk grows as data is written to it, up to its configured maximum capacity.

Fixed-size disk

A fixed-size virtual disk generally reserves its configured capacity on the host when it is created.

Dynamic Allocation Fixed Size
Uses host storage as the guest writes data. Reserves the configured storage capacity.
Can save initial host disk space. Requires more host storage immediately.
Actual file size can increase over time. File is generally allocated to its configured size.
A virtual disk's maximum capacity is not the same as the amount of physical storage currently occupied on the host.

11. Installing Ubuntu Inside VirtualBox

After creating the VM, attach the Ubuntu ISO and start the virtual machine.

  1. Select the Ubuntu virtual machine.
  2. Open its Settings if the ISO is not already attached.
  3. Find the Storage or optical drive configuration.
  4. Select the Ubuntu ISO file as the virtual optical disk.
  5. Save the configuration.
  6. Start the virtual machine.
  7. Follow the Ubuntu installer screens.
  8. Complete installation and create a user account.
  9. Restart the virtual machine.
  10. Log in to Ubuntu.
Expected result: Ubuntu boots inside the VirtualBox window and displays its desktop environment.
If the VM returns to the installer after installation, check whether the virtual optical drive still contains the ISO. Remove or eject the installation ISO when appropriate, then reboot the VM.

12. VirtualBox Networking Modes

VirtualBox provides several networking modes that control how a virtual machine communicates with other systems.

1. NAT (Network Address Translation)

NAT allows the guest VM to access external networks through the host's network connection.

  • Useful for ordinary internet access.
  • Simple to configure.
  • Incoming connections usually require port forwarding.

2. Bridged Adapter

Bridged networking connects the VM to the physical network through the host's network adapter. The VM behaves like a separate device on that network.

  • Useful when other devices need to communicate with the VM.
  • Can obtain an IP address from the network's DHCP server.
  • Availability depends on the physical network and adapter.

3. Host-Only Adapter

Host-only networking creates a network between the host and virtual machines connected to that virtual network. It normally does not provide internet access by itself.

4. Internal Network

Internal networking allows selected virtual machines on the same internal network to communicate with one another. The host is not automatically connected to that network.

Mode Internet Access Typical Purpose
NAT Usually yes Basic guest internet access
Bridged Depends on physical network VM as a separate network device
Host-Only Not by default Host-to-VM communication
Internal Not by default VM-to-VM isolated network
Practical recommendation: NAT is a good starting point when you simply need internet access inside an Ubuntu VM.

13. VirtualBox Guest Additions

Guest Additions are additional software components installed inside a supported guest operating system to improve integration between the guest and host.

Benefits

  • Improved display resizing.
  • Better mouse pointer integration.
  • Shared clipboard support, when configured.
  • Shared folders, when configured.
  • Improved graphics integration.

Installing Guest Additions in Ubuntu

  1. Start the Ubuntu virtual machine.
  2. Open the VirtualBox Devices menu.
  3. Select Insert Guest Additions CD Image, if available.
  4. Install required build tools and kernel headers if needed.
  5. Run the Guest Additions installer according to the displayed instructions.
  6. Restart Ubuntu.

Example prerequisite command

sudo apt update sudo apt install build-essential dkms linux-headers-$(uname -r)
Guest Additions versions should be compatible with the installed VirtualBox version and guest kernel. Follow the official VirtualBox documentation if installation fails.

14. Shared Folders

Shared folders allow files to be exchanged between the host operating system and the guest operating system.

Example

Suppose Windows contains a folder named C:\LinuxShare. You can configure it as a shared folder in VirtualBox so that Ubuntu can access its contents.

Basic procedure

  1. Start the Ubuntu VM.
  2. Open VirtualBox VM settings.
  3. Select Shared Folders.
  4. Add the host folder path.
  5. Choose appropriate sharing options.
  6. Start or restart the guest if required.
  7. Access the shared folder from Ubuntu.

Example Linux command

sudo usermod -aG vboxsf $USER

This adds the current user to the VirtualBox shared-folder group when that group is available in the guest.

Log out and log in again, or restart Ubuntu, for the group membership change to take effect.

15. Snapshots

A snapshot records the state of a virtual machine at a particular point in time. It can help restore a VM to an earlier state.

Example use case

Before installing new development software or changing system configuration, take a snapshot. If the changes cause problems, you can restore the earlier VM state.

Snapshot procedure

  1. Select the virtual machine in VirtualBox.
  2. Open its Snapshots view.
  3. Create a snapshot.
  4. Enter a meaningful snapshot name.
  5. Continue working with the VM.
  6. Restore the snapshot when required.
Snapshots are not a replacement for independent backups. They may use additional storage and depend on the VM's disk and snapshot files remaining intact.

16. Starting, Pausing and Shutting Down a VM

Action Meaning
Start Starts the virtual machine.
Pause Temporarily suspends VM execution.
Resume Continues execution of a paused VM.
Save State Saves the VM's running state for later continuation.
ACPI Shutdown Requests a normal shutdown from the guest OS.
Power Off Immediately stops the VM, similar to removing power.
Avoid using Power Off during normal operation because unsaved data may be lost and filesystem corruption can occur. Prefer shutting down Ubuntu from its operating system.

17. Virtual Machines vs Physical Installation

Feature Virtual Machine Physical Installation
Hardware Uses virtual hardware. Uses physical hardware directly.
Performance Has virtualization overhead. Usually provides more direct hardware performance.
Installation Risk Usually avoids repartitioning the host disk. Disk changes can affect existing data and OS installations.
Hardware Access Some devices require passthrough or special configuration. Direct access to supported hardware.
Portability VM files can be copied to compatible hosts. Installation is tied to the physical machine.
Use Case Learning, testing and development. Daily use and workloads needing direct hardware access.
Virtual machines are especially useful for learning Linux because you can practise commands, install packages and test configuration changes without changing the main operating system installation.

18. Common VirtualBox Problems

Problem Possible Cause Suggested Check
VM does not start Virtualization setting or resource issue Check firmware settings and VM configuration.
64-bit OS option missing Virtualization unavailable or conflicting configuration Check CPU support, firmware and host virtualization software.
VM is slow Insufficient RAM or CPU resources Review resource allocation and host workload.
No internet in Ubuntu Incorrect virtual network configuration Check the network adapter and guest network settings.
Small display resolution Guest Additions not installed or configured Check Guest Additions and display settings.
Shared folder unavailable Missing Guest Additions or permissions Check shared-folder settings and group membership.
Insufficient disk space Host or virtual disk capacity exhausted Check host free space and guest filesystem usage.

20. Interview Questions and Answers

Q1. What is virtualization?

Virtualization is the technology of creating virtual computing environments using software, allowing multiple operating systems or isolated environments to share one physical computer.

Q2. What is a virtual machine?

A virtual machine is a software-based computer with virtual CPU, memory, storage and network resources.

Q3. What is a hypervisor?

A hypervisor is software that creates and manages virtual machines and allocates their resources.

Q4. What is the difference between Type 1 and Type 2 hypervisors?

A Type 1 hypervisor runs directly on physical hardware, while a Type 2 hypervisor runs on top of a host OS.

Q5. What is VirtualBox?

VirtualBox is a cross-platform virtualization application used to create and run virtual machines.

Q6. What is the difference between host OS and guest OS?

The host OS runs on the physical computer, while the guest OS runs inside a virtual machine.

Q7. What is a virtual hard disk?

A virtual hard disk is a file or group of files that provides storage to a virtual machine.

Q8. What is NAT networking?

NAT allows a guest VM to access external networks through the host's network connection.

Q9. What are Guest Additions?

Guest Additions are software components that improve integration between a supported guest OS and VirtualBox.

Q10. What is a snapshot?

A snapshot records a VM state at a particular time and can be used to restore an earlier state.

Q11. What is the difference between a dynamic and fixed virtual disk?

A dynamic disk grows as data is written, up to its maximum capacity. A fixed disk reserves its configured capacity when created.

Q12. Why should we avoid allocating all host RAM to a VM?

The host operating system also needs memory. Allocating too much to a VM can make both the host and guest slow or unstable.
