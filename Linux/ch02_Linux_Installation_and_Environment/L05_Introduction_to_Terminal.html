Introduction to Terminal

Understand the Linux terminal, command-line interface and essential commands.

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the Linux terminal and command-line interface.
  • Differentiate between terminal, shell, console and CLI.
  • Open and use the Ubuntu terminal.
  • Understand the Linux command structure.
  • Navigate directories and manage files using commands.
  • Use manual pages and command help options.
  • Understand command exit status, redirection and pipes at an introductory level.

1. What Is a Terminal?

A terminal is a text-based interface through which a user communicates with an operating system by entering commands.

Instead of performing every operation using graphical buttons and menus, a user can type commands to manage files, directories, applications and system resources.

Linux provides powerful command-line tools that are widely used in system administration, software development, automation and embedded Linux development.

Example: To display the current working directory, enter:
pwd
The terminal displays the directory path.

Terminal Interface

A terminal generally contains:

  • A command prompt where commands are entered.
  • A text area where command output is displayed.
  • A cursor indicating the current input position.
  • A command history that can help retrieve previously entered commands.

2. Terminal, Shell, Console and CLI

These terms are related, but they do not mean exactly the same thing.

Term Meaning
Terminal An interface used to enter commands and view text output.
Shell A program that interprets commands and executes them or starts other programs.
Console A system interface used for direct interaction with a computer, traditionally associated with its main system terminal.
CLI Command-Line Interface; a method of interacting with software through text commands.
Important distinction:
  • Terminal = interface.
  • Shell = command interpreter.
  • CLI = command-based interaction method.
The terminal provides the interface, while the shell processes the commands entered into it.

3. Opening the Terminal in Ubuntu

Ubuntu provides a graphical terminal application, commonly called GNOME Terminal in standard Ubuntu desktop installations.

Method 1: Keyboard Shortcut

Press:

Ctrl + Alt + T

Method 2: Applications Search

  1. Open the Applications menu.
  2. Search for Terminal.
  3. Select the Terminal application.

Method 3: Application List

Open the applications list and select Terminal if it is available.

Practical note: When using Ubuntu inside VirtualBox, open the Ubuntu virtual machine first and then use the terminal inside that Ubuntu environment.

4. Understanding the Command Prompt

When the terminal opens, it displays a prompt where you can enter commands.

username@computer:~$

The prompt commonly contains the following information:

Component Meaning
username Name of the currently logged-in user.
computer Hostname of the system.
~ Current user's home directory.
$ Common prompt symbol for a regular user.
# Common prompt symbol for the root user.
The exact prompt appearance can vary depending on the shell and its configuration. The symbols shown above are common conventions.

5. Basic Linux Command Structure

A Linux command generally follows this structure:

command [options] [arguments]
  • Command: The program or operation to execute.
  • Options: Modify how the command behaves.
  • Arguments: Provide information or targets for the command.

Example

ls -l /home
Part Value Purpose
Command ls Lists directory contents.
Option -l Displays detailed information.
Argument /home Specifies the directory to list.

Important Rules

  • Linux commands are generally case-sensitive.
  • Spaces separate command components and arguments.
  • Options commonly begin with a hyphen.
  • Some commands work without options or arguments.
Case sensitivity: ls and LS are not the same command. Linux normally recognizes them as different names.

6. Essential Terminal Commands

6.1 pwd – Print Working Directory

Displays the absolute path of the current directory.

pwd
Example output:
/home/username

6.2 ls – List Directory Contents

Displays files and directories in the current location.

ls

Useful variations:

ls -l ls -a ls -la
Command Purpose
ls Lists visible directory contents.
ls -l Displays detailed information in long format.
ls -a Displays hidden entries, including those beginning with a dot.
ls -la Displays hidden entries in long format.

6.3 cd – Change Directory

Changes the current working directory.

cd /home cd .. cd ~ cd /
Command Meaning
cd /home Moves to the /home directory.
cd .. Moves one directory level up.
cd ~ Moves to the current user's home directory.
cd / Moves to the root directory.
cd Normally moves to the current user's home directory.

6.4 mkdir – Make Directory

Creates a new directory.

mkdir Projects mkdir Linux_Notes

6.5 touch – Create an Empty File

Creates an empty file if it does not exist. If the file already exists, it updates its access and modification timestamps.

touch notes.txt

6.6 cp – Copy Files

Copies files or directories.

cp notes.txt backup.txt cp notes.txt /home/username/Documents/

To copy a directory and its contents recursively:

cp -r Projects Projects_Backup

6.7 mv – Move or Rename Files

Moves a file to another location or renames it.

mv notes.txt Documents/ mv oldname.txt newname.txt

6.8 rm – Remove Files

Removes files.

rm notes.txt

To remove an empty directory:

rmdir EmptyFolder
Important safety warning: The rm command can permanently remove files. Linux generally does not move deleted terminal files to the graphical Trash. Be especially careful with rm -r and never execute unfamiliar deletion commands without understanding their targets.

6.9 cat – Display File Contents

Displays the contents of a text file.

cat notes.txt

6.10 less – View Text Page by Page

Displays a file one screen at a time. This is useful for large files.

less largefile.txt

Useful keys inside less:

  • Space: Move forward one screen.
  • b: Move backward one screen.
  • /word: Search for a word.
  • q: Quit.

6.11 clear – Clear Terminal Screen

clear

6.12 date – Display Date and Time

date

6.13 whoami – Display Current Username

whoami

6.14 uname – Display System Information

uname uname -a

uname -a displays detailed kernel and system information.

6.15 echo – Display Text

echo "Hello Linux" echo "Welcome to the terminal"

6.16 history – Display Previously Used Commands

history

Displays commands stored in the current shell's command history.

7. Absolute and Relative Paths

A path specifies the location of a file or directory in the filesystem.

7.1 Absolute Path

An absolute path starts from the root directory, represented by /.

/home/username/Documents/notes.txt

7.2 Relative Path

A relative path specifies a location in relation to the current working directory.

Documents/notes.txt ../Downloads/file.txt
Symbol Meaning
/ Root directory.
. Current directory.
.. Parent directory.
~ Current user's home directory.

Example

Suppose the current directory is:

/home/username

To enter the Documents directory:

cd Documents

The resulting path is:

/home/username/Documents

8. Working with File and Directory Names

Linux filenames can contain spaces, but spaces must be handled correctly when entering commands.

Method 1: Use Quotation Marks

mkdir "My Projects" cd "My Projects"

Method 2: Use a Backslash

mkdir My\ Projects cd My\ Projects
Quotation marks and backslashes help the shell interpret spaces as part of a filename instead of treating them as separators between arguments. Detailed shell behaviour will be covered in Lesson 6.

9. Getting Help: man and --help

Linux provides built-in documentation for many commands.

9.1 man – Manual Pages

Displays the manual page for a command.

man ls man pwd man mkdir

Inside a manual page:

  • Press Space to move forward.
  • Press b to move backward.
  • Press q to quit.

9.2 --help Option

Many commands provide a short help message through the --help option.

ls --help mkdir --help cp --help
Difference: man generally provides detailed manual documentation, while --help usually provides a shorter command usage summary.

10. Command Exit Status

When a command finishes, it normally returns an exit status indicating whether it completed successfully.

The special parameter $? contains the exit status of the most recently completed foreground command.

pwd echo $?
Typical output:
/home/username 0
Exit Status Meaning
0 Success.
Non-zero Failure or another condition reported by the command.
An exit status of zero conventionally indicates success. The meaning of non-zero values depends on the particular command.

11. Understanding sudo

sudo allows an authorized user to run a command with elevated privileges, commonly as the root user.

Example

sudo apt update

This command runs the package-list update operation with elevated privileges.

Important Points

  • Use sudo only when elevated privileges are required.
  • Ubuntu may ask for your user password.
  • Password characters are normally not displayed while typing in the terminal.
  • Do not execute commands with sudo unless you understand what they do.
Security warning: Running an incorrect command with administrator privileges can damage the operating system or modify important system files. Avoid copying unknown commands from the internet.

12. Introduction to Input, Output and Pipes

Linux commands can read input, display output and pass data to other commands.

12.1 Output Redirection

The > operator redirects standard output to a file. It creates the file if necessary or replaces its existing contents.

echo "Hello Linux" > output.txt

The >> operator appends output to a file.

echo "Second line" >> output.txt

12.2 Input Redirection

The < operator redirects input from a file.

wc -l < output.txt

12.3 Pipe Operator

The pipe operator | sends the standard output of one command to the standard input of another command.

ls -l | less

Here, the output of ls -l is passed to less for page-by-page viewing.

Redirection and pipes are important concepts for command-line automation and shell scripting. You will use them more extensively when learning Linux Shell and Bash.

13. Useful Terminal Keyboard Shortcuts

Shortcut Function
Ctrl + Alt + T Open terminal in many Ubuntu desktop installations.
Ctrl + C Interrupt the foreground command in common terminal usage.
Ctrl + L Clear the visible terminal screen.
Ctrl + A Move cursor to the beginning of the current command line.
Ctrl + E Move cursor to the end of the current command line.
Up Arrow Recall the previous command from history.
Down Arrow Move forward through command history.
Tab Complete filenames and command names when possible.
Ctrl + Shift + C Copy selected terminal text in many graphical terminals.
Ctrl + Shift + V Paste text in many graphical terminals.
Shortcut behaviour can depend on the terminal application and desktop environment. In many terminals, Ctrl+C interrupts a running command rather than copying selected text.

15. Common Terminal Errors

Error Possible Reason Solution
command not found Command is misspelled or unavailable. Check spelling and command availability.
No such file or directory Specified file or directory does not exist. Check the path and filename.
Permission denied User lacks required permissions. Check permissions and use elevated privileges only when appropriate.
Is a directory A command expected a file but received a directory. Check the command and supplied path.
Not a directory A path component is a file rather than a directory. Verify the path structure.

16. Interview Questions and Answers

Q1. What is a Linux terminal?

A terminal is a text-based interface used to communicate with the Linux operating system by entering commands and viewing their output.

Q2. What is the difference between a terminal and a shell?

A terminal provides the user interface, while a shell interprets commands and executes them or launches other programs.

Q3. What is CLI?

CLI stands for Command-Line Interface. It allows users to interact with a computer or application through text commands.

Q4. What does pwd do?

The pwd command displays the absolute path of the current working directory.

Q5. What is the purpose of the ls command?

The ls command lists files and directories.

Q6. What is the difference between cd .. and cd ~?

cd .. moves to the parent directory, whereas cd ~ moves to the current user's home directory.

Q7. What is the difference between an absolute path and a relative path?

An absolute path starts from the root directory. A relative path is interpreted in relation to the current working directory.

Q8. What is the purpose of sudo?

sudo allows an authorized user to execute a command with elevated privileges.

Q9. What does the command man ls do?

It displays the manual documentation for the ls command.

Q10. What is the purpose of the pipe operator?

The pipe operator passes the standard output of one command as the standard input of another command.

Q11. What does an exit status of zero indicate?

It conventionally indicates that the command completed successfully.

Q12. Why is Linux considered useful for software developers?

Linux provides command-line utilities, compilers, development tools, scripting facilities and system-level access that support software development and automation.

18. Lesson Summary

  • The terminal provides a text-based interface for interacting with Linux.
  • The shell interprets commands entered through the terminal.
  • Linux commands generally follow the structure: command, options and arguments.
  • Commands such as pwd, ls and cd help navigate the filesystem.
  • Commands such as mkdir, touch, cp, mv and rm manage files and directories.
  • man and --help provide command documentation.
  • Exit status indicates the result of command execution.
  • Redirection and pipes connect commands and manage input/output.
  • sudo provides authorized elevated command execution.
