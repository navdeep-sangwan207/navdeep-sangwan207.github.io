rm Command in Linux

Removing Files and Directories

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the rm command.
  • Remove individual and multiple files.
  • Delete files using wildcard patterns.
  • Remove empty and non-empty directories.
  • Understand important options such as -i, -f, -r and -v.
  • Use safe practices when deleting files and directories.

1. Introduction to the rm Command

The rm command in Linux is used to remove files and directories from the filesystem.

The name rm comes from the word remove.

Important Safety Warning: The rm command normally removes directory entries directly. It does not move files to the graphical Trash or Recycle Bin. Deleted files may be difficult or impossible to recover. Always verify the filename and path before executing a deletion command.

2. Syntax of the rm Command

rm [OPTION] FILE

Explanation:

  • rm – Command used to remove files.
  • OPTION – Optional behaviour of the command.
  • FILE – Name or path of the file to remove.

Basic Example

rm file1.txt

This removes the file named file1.txt from the current directory.

3. Removing a Single File

To delete one file, specify its name after the rm command.

Example

touch sample.txt ls rm sample.txt ls

Explanation:

  1. touch sample.txt creates a file.
  2. ls displays the file.
  3. rm sample.txt removes the file.
  4. The final ls shows that the file is no longer listed.
Expected result:

The file sample.txt is removed from the current directory.

4. Removing Multiple Files

Multiple filenames can be provided in one rm command.

Example

rm file1.txt file2.txt file3.txt

This removes all three specified files.

Practical Example

touch a.txt b.txt c.txt ls rm a.txt b.txt c.txt ls

Expected result: All three files are removed.

Always check that the filenames are correct before removing multiple files in one command.

5. Removing Files Using Wildcards

Wildcards allow you to select files based on filename patterns. The shell expands these patterns before executing the rm command.

5.1 Asterisk (*) Wildcard

rm *.txt

Removes all matching files ending with .txt in the current directory.

5.2 Prefix Matching

rm report*

Removes entries in the current directory whose names begin with report, provided they are removable files or suitable entries.

5.3 Question Mark (?) Wildcard

rm file?.txt

Matches names such as file1.txt and fileA.txt, where ? matches one character.

Warning: Commands such as rm *.txt can remove many files at once. Use ls *.txt first to inspect the matching filenames before deleting them.

6. Removing an Empty Directory

The rm command without recursive options does not remove a directory. The rmdir command is normally used to remove an empty directory.

Using rmdir

mkdir TestFolder rmdir TestFolder

This creates an empty directory and then removes it.

Using rm with the -d Option

mkdir EmptyFolder rm -d EmptyFolder

The -d option removes an empty directory.

Remember: Both rmdir and rm -d require the directory to be empty.

7. Removing a Non-Empty Directory

To remove a directory containing files or subdirectories, use the recursive option -r or -R.

Syntax

rm -r DIRECTORY

Example

mkdir -p Projects/C touch Projects/C/main.c rm -r Projects

This removes the Projects directory and its contents, including the C subdirectory and main.c.

Critical: Recursive deletion can remove entire directory trees. Verify the path carefully before executing rm -r.

8. Important Options of the rm Command

Option Description
-i Prompts before every removal.
-I Prompts once before removing more than three files or when removing recursively.
-f Force removal; ignores nonexistent files and suppresses most prompts.
-r Removes directories and their contents recursively.
-R Same recursive behaviour as -r.
-v Displays each removal operation.
-d Removes empty directories.

8.1 Interactive Option (-i)

rm -i file1.txt

Linux asks for confirmation before removing the file.

rm: remove regular file 'file1.txt'?

Type y to confirm or n to cancel.

8.2 Interactive Option (-I)

rm -I file1.txt file2.txt file3.txt file4.txt

On GNU/Linux, this option asks for confirmation once before removing more than three files or when performing a recursive removal.

8.3 Force Option (-f)

rm -f file1.txt

Removes the file without prompting. If the file does not exist, the command does not report that as an error.

Avoid using -f when you are uncertain about the target path or filename.

8.4 Recursive Option (-r)

rm -r MyFolder

Removes the directory and its contents recursively.

8.5 Verbose Option (-v)

rm -v file1.txt
Example output:
removed 'file1.txt'

Displays the names of entries removed by the command.

8.6 Directory Option (-d)

rm -d EmptyFolder

Removes the directory only if it is empty.

9. Removing Files with Spaces in Their Names

If a filename contains spaces, use quotation marks or escape the spaces.

Method 1: Double Quotes

rm "my report.txt"

Method 2: Single Quotes

rm 'my report.txt'

Method 3: Backslash

rm my\ report.txt

10. Removing Files Using Their Paths

Relative Path

rm Documents/file1.txt

Removes file1.txt from the Documents directory relative to the current working directory.

Parent Directory Path

rm ../file1.txt

Removes file1.txt from the parent directory.

Absolute Path

rm /home/user/Documents/file1.txt

Removes the file using its complete path from the root directory.

11. Removing Hidden Files

Hidden files in Linux generally begin with a dot (.).

Example

touch .configfile ls -a rm .configfile

The ls -a command displays hidden entries. The rm command then removes the specified hidden file.

Important: Do not use broad hidden-file wildcard patterns without understanding what they match. Inspect the target entries first.

12. Difference Between rm, rmdir and unlink

Command Purpose Important Detail
rm Removes files and, with recursive options, directories. Supports options such as -i, -f and -r.
rmdir Removes empty directories. Cannot remove a non-empty directory.
unlink Removes one directory entry. Normally used to remove a single file link, not directories.

Examples

rm file.txt rmdir EmptyFolder unlink anotherfile.txt

13. Common Errors and Troubleshooting

Error 1: File Does Not Exist

rm missing.txt
rm: cannot remove 'missing.txt': No such file or directory

Solution: Check the filename and current directory using ls and pwd.

Error 2: Is a Directory

rm MyFolder
rm: cannot remove 'MyFolder': Is a directory

Solution: Use rmdir if the directory is empty, or rm -r if it contains entries and you intend to remove them.

Error 3: Directory Not Empty

rmdir Projects
rmdir: failed to remove 'Projects': Directory not empty

Solution: Inspect the directory contents. Remove the contents first if appropriate, or use recursive removal only after verifying the target.

Error 4: Permission Denied

rm protected.txt
rm: cannot remove 'protected.txt': Permission denied

Solution: Check file and parent directory permissions. Request appropriate access rather than automatically using elevated privileges.

Error 5: Cannot Remove a Write-Protected File

If a file is not writable, GNU rm may ask for confirmation when running interactively.

Solution: Check the file permissions with ls -l and confirm that you intend to remove it.

14. Important Safety Practices

  • Use pwd to verify the current directory.
  • Use ls to inspect files before deleting them.
  • Use rm -i when you want confirmation.
  • Be especially careful with rm -r.
  • Never execute unfamiliar deletion commands without understanding their paths and wildcard patterns.
  • Avoid unnecessary use of sudo rm.
  • Remember that rm does not normally send files to Trash.
Never experiment with destructive commands on important system directories. Use a practice directory inside your home directory for learning.

Objective: Remove one file using the rm command.

Expected Result: The file is removed.

Objective: Remove multiple files using one command.

touch a.txt b.txt c.txt rm a.txt b.txt c.txt ls

Expected Result: All three files are removed.

Objective: Remove all matching text files.

touch one.txt two.txt three.txt ls *.txt rm *.txt ls

mkdir -p Practice/SubFolder touch Practice/file.txt touch Practice/SubFolder/data.txt ls -R Practice rm -r Practice ls

Expected Result: Linux displays the name of the removed file.

16. Interview Questions

Q1. What is the purpose of the rm command?

It removes files and directories from the filesystem.

Q2. What is the basic syntax of rm?

rm [OPTION] FILE

Q3. Which option is used to remove directories recursively?

The -r or -R option.

Q4. What is the difference between rm and rmdir?

rm removes files and can recursively remove directories, while rmdir removes empty directories only.

Q5. What does the -i option do?

It prompts before each removal.

Q6. What does the -f option do?

It forces removal and suppresses most prompts.

Q7. What is the purpose of the -v option?

It displays each removal operation.

Q8. Can rm remove multiple files?

Yes. Multiple filenames can be supplied in one command.

Q9. Does rm move files to the Trash?

No. The normal rm command does not move files to the graphical Trash.

Q10. How do you remove an empty directory using rm?

rm -d EmptyFolder

17. Multiple Choice Questions (MCQs)

Q1. Which command removes a file?

  1. mkdir
  2. rm
  3. pwd
  4. touch

Answer: B. rm

Q2. Which option removes directories recursively?

  1. -v
  2. -i
  3. -r
  4. -d

Answer: C. -r

Q3. Which command removes an empty directory?

  1. rmdir
  2. touch
  3. pwd
  4. cat

Answer: A. rmdir

Q4. Which option prompts before every removal?

  1. -f
  2. -i
  3. -v
  4. -r

Answer: B. -i

Q5. Which option displays removed filenames?

  1. -v
  2. -f
  3. -d
  4. -I

Answer: A. -v

Q6. Which command removes all .txt files in the current directory?

  1. rm *.txt
  2. rm Documents/
  3. rmdir *.txt
  4. touch *.txt

Answer: A. rm *.txt

Q7. Which option removes an empty directory using rm?

  1. -r
  2. -d
  3. -v
  4. -f

Answer: B. -d

Q8. Does rm normally move deleted files to Trash?

  1. Yes
  2. No
  3. Only text files
  4. Only directories

Answer: B. No

18. Lesson Summary

  • rm file.txt removes a file.
  • rm file1.txt file2.txt removes multiple files.
  • rm *.txt removes matching text files.
  • rm -i prompts before each removal.
  • rm -I provides a less frequent confirmation prompt.
  • rm -f forces removal without most prompts.
  • rm -r removes directories recursively.
  • rm -v displays removal details.
  • rm -d removes empty directories.
  • rmdir removes empty directories.
Key Concept: The rm command is a powerful file-management tool. Use it carefully because deletion is not normally reversible through a Trash folder.
