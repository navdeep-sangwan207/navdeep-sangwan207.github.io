Linux Command Syntax

1. Introduction to Linux Commands

A Linux command is an instruction given to the operating system through a command-line interface (CLI) to perform a particular operation.

Commands allow users to interact with the Linux operating system, manage files and directories, inspect system information, control processes, and perform administrative tasks.

Linux commands are generally entered into a shell, such as Bash, through a terminal.

Examples of Linux Commands

pwd ls date whoami uname -a

These commands perform different operations:

Command Purpose
pwd Displays the present working directory.
ls Lists files and directories.
date Displays the system date and time.
whoami Displays the current username.
uname -a Displays detailed system information.

2. Basic Structure of a Linux Command

A typical Linux command follows this general structure:

command [options] [arguments]

The structure contains three main parts:

  1. Command: Specifies the operation to perform.
  2. Options: Modify how the command behaves.
  3. Arguments: Specify the target or input on which the command operates.

Example

ls -l /home
Part Value Meaning
Command ls Lists directory contents.
Option -l Displays detailed information.
Argument /home Specifies the directory to list.
Explanation: The command ls -l /home lists the contents of the /home directory in long-listing format.
Note: The general command structure is a learning model. Some commands do not require options or arguments. Certain commands also accept multiple arguments.

3. Command Name

The command name identifies the program or shell operation that Linux should execute.

Examples

pwd ls mkdir cp mv rm

Each command performs a different task:

  • pwd displays the current directory.
  • ls lists directory contents.
  • mkdir creates directories.
  • cp copies files and directories.
  • mv moves or renames files.
  • rm removes files and directories.
Important: A command name must be recognized by the shell. If the command is not available or cannot be found, the shell displays an error.

4. Command Options

Options are used to modify the behavior or output of a command. They are also called flags or switches.

Most commonly used Linux options begin with a hyphen (-) or two hyphens (--).

4.1 Short Options

Short options generally use a single hyphen followed by one character.

ls -l ls -a ls -h
Option Purpose
-l Displays long-format information.
-a Displays hidden files and directories.
-h Displays human-readable sizes when supported.

4.2 Long Options

Long options generally use two hyphens followed by a descriptive word.

ls --all ls --human-readable ls --help
Long Option Purpose
--all Displays hidden entries.
--human-readable Displays readable file sizes when supported.
--help Displays command usage information when supported.

4.3 Combining Short Options

Some commands allow multiple short options to be combined after a single hyphen.

ls -al

This combines -a and -l. It displays hidden entries along with detailed listing information.

Note: Combining options depends on the command's supported syntax. Not every command accepts combined options.

5. Command Arguments

An argument provides information or input to a command. It usually identifies the file, directory, user, or other object on which the command should operate.

Example 1: Listing a Directory

ls /home

Here, /home is the argument. It specifies which directory should be listed.

Example 2: Creating a Directory

mkdir Projects

Here, Projects is the argument. It specifies the name of the directory to create.

Example 3: Creating Multiple Directories

mkdir Project1 Project2 Project3

This command creates three directories in the current working directory.

Remember: Options control how a command operates, whereas arguments provide the target or input for that operation.

6. Commands with Options and Arguments

A command can contain both options and arguments. The exact order depends on the command's syntax.

Example 1

ls -l /home

Displays detailed information about the contents of the /home directory.

Example 2

mkdir -p Projects/Linux/Commands

Creates the complete directory path, including missing parent directories.

Example 3

cp -v file.txt backup.txt

Copies file.txt to backup.txt and displays the operation performed.

Important: Always check the manual page or help information when you are unsure about the order or supported options of a command.

7. Absolute and Relative Paths

A path identifies the location of a file or directory in the Linux filesystem.

7.1 Absolute Path

An absolute path specifies the complete location of a file or directory starting from the root directory (/).

ls /home/user/Documents

This command specifies the complete path to the Documents directory.

7.2 Relative Path

A relative path specifies a location in relation to the current working directory.

ls Documents

This command lists the Documents directory if it exists inside the current working directory.

Absolute Path Relative Path
Starts from the root directory (/). Starts from the current working directory.
Specifies the complete path. Specifies a path relative to the current location.
Example: /home/user/Projects Example: Projects

Special Path Symbols

Symbol Meaning
/ Root directory.
. Current directory.
.. Parent directory.
~ Current user's home directory.

8. Case Sensitivity in Linux

Linux filenames and command names are generally case-sensitive.

This means uppercase and lowercase characters are treated as different characters.

Example

ls LS

ls is the standard directory-listing command. LS is a different command name and is not normally available.

Filename Example

Report.txt report.txt REPORT.txt

These are three different filenames in a typical case-sensitive Linux filesystem.

Common mistake: Do not randomly change uppercase and lowercase letters in command names or filenames.

9. Spaces and Special Characters in Commands

Spaces normally separate command names, options, and arguments. If a filename contains spaces, it must be handled correctly.

Method 1: Use Quotes

mkdir "My Projects"

Creates a directory named My Projects.

Method 2: Use Backslash

mkdir My\ Projects

The backslash escapes the space so that the shell treats it as part of the same argument.

Method 3: Use Single Quotes

mkdir 'Linux Learning'

Single quotes preserve the enclosed text as one argument without interpreting most special characters inside it.

Tip: Use the Tab key for shell command completion. It can complete filenames and directory names and reduce typing errors.

10. Command Execution and Output

When you enter a command in the terminal and press Enter, the shell interprets the command and attempts to execute it.

Basic Execution Process

  1. Open the terminal.
  2. Type a Linux command.
  3. Press Enter.
  4. The shell processes the command.
  5. The command executes if it is valid and accessible.
  6. The output or error message is displayed.

Example

whoami
Example Output:
user

The output displays the current username. The actual username depends on your Ubuntu account.

Command Prompt Example

user@ubuntu:~$ pwd /home/user user@ubuntu:~$

In this example:

  • user represents the username.
  • ubuntu represents the hostname.
  • ~ represents the home directory.
  • $ indicates a regular user shell prompt.
  • pwd is the command entered.
Note: The exact prompt varies depending on the username, hostname, shell configuration, and current directory. The root user's traditional prompt commonly ends with #.

11. Standard Output and Standard Error

Linux programs commonly use three standard data streams:

Stream File Descriptor Purpose
Standard Input (stdin) 0 Receives input.
Standard Output (stdout) 1 Displays normal output.
Standard Error (stderr) 2 Displays error messages.

Example: Standard Output

echo "Hello Linux"
Output:
Hello Linux

Example: Redirect Standard Output

echo "Hello Linux" > output.txt

This writes the command output into output.txt, replacing its previous contents if the file exists.

Example: Redirect Standard Error

ls /directory_that_does_not_exist 2> error.txt

This redirects the error message into error.txt.

Important: Standard output and standard error are separate streams. Understanding them is useful for shell scripting, debugging, and systems programming.

12. Common Linux Command Syntax Errors

Error Incorrect Command Correct Command
Incorrect command name LS ls
Missing argument mkdir mkdir Projects
Incorrect option format ls l ls -l
Unquoted filename with spaces mkdir My Projects mkdir "My Projects"

Common Error Messages

command: command not found No such file or directory Permission denied missing operand

These errors generally indicate:

  • Command not found: The shell cannot locate the command.
  • No such file or directory: The specified path or file does not exist.
  • Permission denied: The user lacks the required access permission.
  • Missing operand: A required argument was not supplied.

13. Getting Help with Linux Commands

Linux provides documentation tools that help users understand command syntax and available options.

1. man Command

man ls

Opens the manual page for the ls command. Press q to exit the manual viewer.

2. --help Option

ls --help

Displays a summary of command usage and available options, when supported by the command.

3. type Command

type ls type cd

Displays how the current shell interprets a command name, such as an external executable, shell builtin, alias, or function.

Remember: cd is normally a shell builtin because it must change the current shell's working directory.

15. Important Interview Questions

Q1. What is a Linux command?

A Linux command is an instruction entered through a command-line interface to perform an operation in the operating system.

Q2. What is the general syntax of a Linux command?

The general syntax is: command [options] [arguments].

Q3. What is the difference between an option and an argument?

An option modifies the behavior of a command, whereas an argument provides the input or target on which the command operates.

Q4. What is the difference between short and long options?

Short options generally begin with a single hyphen and use one character, such as -l. Long options generally begin with two hyphens, such as --all.

Q5. What is an absolute path?

An absolute path specifies the complete location of a file or directory starting from the root directory.

Q6. What is a relative path?

A relative path specifies a location with respect to the current working directory.

Q7. Is Linux case-sensitive?

Yes. Linux command names and filenames are generally case-sensitive.

Q8. What is the purpose of the man command?

The man command displays manual documentation for Linux commands and other system interfaces.

Q9. What are stdin, stdout, and stderr?

They are the standard input, standard output, and standard error streams used by Linux processes.

Q10. Why is cd a shell builtin?

Because changing directories must modify the working directory of the current shell process.

17. Lesson Summary

  • Linux commands are instructions used to interact with the operating system.
  • The general command structure is command, options, and arguments.
  • Options modify command behavior.
  • Arguments provide input or identify the target of a command.
  • Short options generally use one hyphen; long options generally use two.
  • Absolute paths start from the root directory.
  • Relative paths depend on the current working directory.
  • Linux command names and filenames are generally case-sensitive.
  • Quotes and escape characters help handle spaces in filenames.
  • Linux uses stdin, stdout, and stderr for standard process communication.
  • Manual pages and help options provide command documentation.
