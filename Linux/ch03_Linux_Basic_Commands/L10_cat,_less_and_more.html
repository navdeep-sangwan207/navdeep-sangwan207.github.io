cat, less and more Commands

Displaying and Reading File Contents in Linux

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of cat, less and more.
  • Display file contents using the cat command.
  • Create and combine files using cat.
  • Read large files page by page using more and less.
  • Navigate through files using keyboard shortcuts.
  • Compare the three commands and select the appropriate one.

1. Introduction

Linux provides several commands to display and read the contents of text files directly from the terminal.

The three commonly used commands are:

  • cat – Displays or combines file contents.
  • more – Displays file contents one screen at a time.
  • less – Provides interactive navigation through file contents.
Important: These commands are frequently used by Linux administrators and software developers to inspect configuration files, source code, documentation and log files.

2. cat Command

The cat command is used to display, create, concatenate and combine file contents.

The name cat comes from concatenate.

Syntax

cat [OPTION] [FILE]

2.1 Display File Contents

To display the contents of a file, provide its filename after the cat command.

cat file.txt

Example:

cat file.txt
Example output:
Welcome to Linux. Linux is an open-source operating system. Linux supports multitasking.

2.2 Display Multiple Files

The cat command can display the contents of multiple files in sequence.

cat file1.txt file2.txt

The contents of file1.txt are displayed first, followed by the contents of file2.txt.

2.3 Create a New File Using cat

The redirection operator > can be used with cat to create a file and write content into it.

cat > newfile.txt

Type the required text in the terminal. Press Ctrl + D to finish entering the content.

Example terminal session:
cat > newfile.txt Welcome to Linux. This is my first file. Ctrl + D

Display the file:

cat newfile.txt
Welcome to Linux. This is my first file.
Important: The > operator overwrites an existing file. Existing content is replaced.

2.4 Append Content to an Existing File

Use the >> operator to append content without removing the existing content.

cat >> newfile.txt

Type additional text and press Ctrl + D when finished.

2.5 Concatenate Two Files into One

The contents of two files can be combined into a third file.

cat file1.txt file2.txt > combined.txt

This writes the contents of both source files into combined.txt in the specified order.

2.6 Display Line Numbers (-n)

cat -n file.txt
Example output:
1 Welcome to Linux. 2 Linux is open source. 3 Linux supports multitasking.

The -n option numbers all output lines, including blank lines.

2.7 Number Non-Empty Lines (-b)

cat -b file.txt

The -b option numbers only non-empty lines.

2.8 Display End-of-Line Markers (-E)

cat -E file.txt

Displays a $ symbol at the end of each line, making line endings visible.

2.9 Display Tabs (-T)

cat -T file.txt

Displays tab characters as ^I.

2.10 Display All Non-Printing Characters (-A)

cat -A file.txt

Displays non-printing characters using visible notation. This is useful for examining whitespace and line endings.

3. more Command

The more command is used to read long text files one screen at a time.

It is useful when a file contains more lines than can fit on the terminal screen.

Syntax

more [OPTION] FILE

3.1 Display a File Using more

more file.txt

The contents are displayed one screen at a time.

3.2 Navigation Keys

Key Function
Space Moves forward by one screen.
Enter Moves forward by one line.
b Moves backward by one screen in implementations that support it.
/pattern Searches forward for a pattern in common implementations.
q Quits the viewer.

3.3 Display a File with Line Numbers

more -d file.txt

The -d option provides helpful prompts and messages for navigation.

3.4 Start at a Specific Percentage

more +50% file.txt

Starts displaying the file approximately halfway through its contents.

The available options and navigation behaviour can vary slightly between implementations of more.

4. less Command

The less command is an interactive terminal pager used to view large text files.

It allows the user to move both forward and backward through the file without loading the entire file into the terminal display at once.

Syntax

less [OPTION] FILE

4.1 Display a File Using less

less file.txt

The file opens in an interactive viewing interface.

4.2 Navigation Keys

Key Function
Space Moves forward by one screen.
b Moves backward by one screen.
Enter Moves forward by one line.
k Moves up by one line.
j Moves down by one line.
g Moves to the beginning of the file.
G Moves to the end of the file.
/pattern Searches forward for a pattern.
?pattern Searches backward for a pattern.
n Moves to the next search match.
N Moves to the previous search match.
q Quits the viewer.

4.3 Search for a Word

less file.txt

Inside the viewer, type:

/Linux

Press Enter to search forward for the word Linux.

4.4 Search Backward

Inside the viewer, type:

?Linux

Press Enter to search backward.

4.5 Open at the End of a File

less +G file.txt

Opens the file with the display positioned at its end.

4.6 Display Line Numbers

less -N file.txt

Displays line numbers while viewing the file.

4.7 Follow File Changes

less +F logfile.txt

Enables follow mode, allowing you to watch new content added to the file.

Press Ctrl + C to stop following and return to normal navigation. Press q to quit.

Practical use: The less command is particularly useful for inspecting large system logs, application logs and configuration files.

5. Difference Between cat, more and less

Feature cat more less
Main purpose Display and combine file contents. Read files screen by screen. Interactive file viewing.
Screen-by-screen viewing No Yes Yes
Backward navigation No Limited or implementation-dependent Yes
Search No built-in interactive search Basic search in common implementations Forward and backward search
Large files Can produce a large amount of terminal output. Useful for page-by-page reading. Very useful for interactive reading.
Typical use Small files and combining content. Simple file paging. Detailed file inspection.
Remember: Use cat for quick display or concatenation, more for simple paging, and less for flexible navigation and searching.

6. Practical Examples

Example 1: Create and Display a File

cat > student.txt Name: Rahul Course: Linux Programming Ctrl + D cat student.txt

Expected output:

Name: Rahul Course: Linux Programming

Example 2: Append New Content

cat >> student.txt Subject: Operating System Ctrl + D cat student.txt

Expected output:

Name: Rahul Course: Linux Programming Subject: Operating System

Example 3: Combine Two Files

cat > first.txt Welcome to Linux. Ctrl + D cat > second.txt Learn Linux commands. Ctrl + D cat first.txt second.txt > combined.txt cat combined.txt

Expected output:

Welcome to Linux. Learn Linux commands.

Example 4: Display Line Numbers

cat -n student.txt

Displays the contents of student.txt with line numbers.

Example 5: Read a Large File with more

more /etc/services

Opens the system services file one screen at a time. Press Space to move forward and q to quit.

Example 6: Read a File with less

less /etc/services

Opens the file in an interactive viewer. Use arrow keys, search and navigation commands to inspect it.

Example 7: Search in a File Using less

less /etc/services

Inside the viewer, enter:

/ssh

Press Enter to find matching text.

7. Common Errors and Troubleshooting

Error 1: File Does Not Exist

cat missing.txt
cat: missing.txt: No such file or directory

Solution: Check the filename and current directory using ls and pwd.

Error 2: Permission Denied

cat protected.txt
cat: protected.txt: Permission denied

Solution: Check file permissions using ls -l and obtain appropriate access.

Error 3: File Output Is Too Long

Displaying a very large file with cat may produce more output than the terminal can conveniently show.

Solution: Use:

less largefile.txt

Error 4: Accidentally Overwriting a File

cat > existing.txt

This replaces the existing contents of the file.

Solution: Use the append operator when you want to preserve existing content:

cat >> existing.txt

9. Interview Questions

Q1. What is the purpose of the cat command?

It displays, creates and concatenates file contents.

Q2. What is the meaning of cat?

It comes from the word concatenate.

Q3. How do you display a file with line numbers?

cat -n file.txt

Q4. What is the difference between > and >>?

> redirects output and normally overwrites an existing file. >> appends output to an existing file.

Q5. What is the purpose of the more command?

It displays long files one screen at a time.

Q6. What is the purpose of the less command?

It provides interactive viewing with forward and backward navigation and search.

Q7. How do you quit less?

Press the q key.

Q8. How do you search forward in less?

Type /pattern and press Enter.

Q9. How do you move to the end of a file in less?

Press G.

Q10. Which command is generally more suitable for inspecting a large log file?

less, because it supports interactive navigation and searching.

10. Multiple Choice Questions (MCQs)

Q1. Which command displays file contents?

  1. mkdir
  2. cat
  3. mv
  4. pwd

Answer: B. cat

Q2. Which command is used to view a file page by page?

  1. more
  2. touch
  3. rm
  4. mkdir

Answer: A. more

Q3. Which command supports backward navigation through a file?

  1. cat
  2. less
  3. touch
  4. pwd

Answer: B. less

Q4. Which option numbers all output lines in cat?

  1. -b
  2. -n
  3. -E
  4. -T

Answer: B. -n

Q5. Which operator appends content to a file?

  1. >
  2. >>
  3. <
  4. |

Answer: B. >>

Q6. Which key quits the less viewer?

  1. g
  2. q
  3. n
  4. k

Answer: B. q

Q7. Which key moves to the end of a file in less?

  1. g
  2. G
  3. q
  4. b

Answer: B. G

Q8. Which command can combine two files into a third file?

  1. cat file1.txt file2.txt > combined.txt
  2. rm file1.txt file2.txt
  3. pwd file1.txt file2.txt
  4. mkdir combined.txt

Answer: A. cat file1.txt file2.txt > combined.txt

11. Lesson Summary

  • cat displays, creates and combines file contents.
  • cat -n displays line numbers for all lines.
  • cat -b numbers non-empty lines.
  • cat > file.txt creates or overwrites a file.
  • cat >> file.txt appends content.
  • more displays file contents screen by screen.
  • less provides interactive file navigation.
  • Space moves forward by a screen in more and less.
  • q quits the more and less viewers.
  • less supports forward and backward searching.
Key Concept: The cat, more and less commands are essential Linux file-viewing utilities. Understanding their differences helps you work efficiently with text files, source code and system logs.
