cd Command in Linux

Navigate Between Directories Using the Linux Terminal

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the cd command.
  • Navigate using absolute and relative paths.
  • Move to the home and parent directories.
  • Navigate using special directory symbols.
  • Use useful shortcuts and understand common errors.

1. Introduction to the cd Command

The cd command stands for Change Directory. It is used to change the current working directory in a Linux terminal.

When working in Linux, you frequently need to move between directories to access files, execute programs, and manage your projects.

cd directory_name
Explanation: The command changes the current working directory to the specified directory.

Example

pwd /home/user cd Documents pwd /home/user/Documents

Here, the current directory changes from /home/user to /home/user/Documents.

2. Syntax of the cd Command

cd [OPTIONS] [DIRECTORY]
Component Description
cd Command used to change the current directory.
OPTIONS Optional settings supported by the shell.
DIRECTORY Destination directory.
Note: The cd command is normally implemented as a shell built-in command. It changes the current directory of the running shell.

3. Basic Usage of cd

3.1 Change to a Specific Directory

cd Documents

Moves into the Documents directory located inside the current working directory.

3.2 Change to the Home Directory

cd

Running cd without an argument takes you to your home directory.

You can also use:

cd ~

The tilde symbol (~) represents the current user's home directory.

3.3 Move to the Parent Directory

cd ..

Moves one level upward from the current directory.

3.4 Move to the Root Directory

cd /

Moves directly to the root directory of the Linux filesystem.

3.5 Move to the Previous Directory

cd -

Returns to the previous working directory. The shell also displays the directory it switches to.

4. Absolute Path and Relative Path

4.1 Absolute Path

An absolute path specifies the complete location of a directory starting from the root directory (/).

cd /home/user/Documents

This command moves directly to Documents using its complete path.

Important: An absolute path starts with a forward slash (/).

4.2 Relative Path

A relative path specifies a directory location in relation to the current working directory.

cd Documents cd ../Downloads

The first command enters Documents. The second command moves one directory upward and then enters Downloads.

Absolute Path Relative Path
Starts from root (/). Starts from current directory.
Does not depend on the current directory. Depends on the current directory.
Example: /home/user Example: Documents

5. Special Directory Symbols

Linux provides special symbols that make directory navigation easier.

Symbol Meaning Example
. Current directory cd .
.. Parent directory cd ..
~ Current user's home directory cd ~
- Previous working directory cd -
/ Root directory cd /

Example: Move Multiple Levels Up

cd ../..

Moves two directory levels upward.

Example: Navigate Through Multiple Directories

cd Documents/Projects/C

Moves into the C directory through Documents and Projects, assuming this directory path exists relative to the current location.

6. Using Spaces in Directory Names

Directory names can contain spaces. In such cases, use quotation marks or escape the spaces.

Method 1: Using Double Quotes

cd "My Documents"

Method 2: Using Single Quotes

cd 'My Documents'

Method 3: Using Backslash

cd My\ Documents
Note: The backslash (\) escapes the space so the shell treats it as part of the directory name.

7. Useful cd Command Shortcuts

Command Purpose
cd Move to the home directory.
cd ~ Move to the home directory.
cd .. Move one level up.
cd ../.. Move two levels up.
cd / Move to the root directory.
cd - Switch to the previous directory.
cd ~username Move to another user's home directory, if accessible.
Important: Access to another user's home directory depends on filesystem permissions.

8. Combining cd with pwd and ls

The cd, pwd, and ls commands are frequently used together.

pwd ls cd Documents pwd ls

Explanation:

  1. pwd displays the current directory.
  2. ls displays its contents.
  3. cd Documents enters Documents.
  4. pwd confirms the new location.
  5. ls displays the contents of Documents.

9. Common Errors and Troubleshooting

9.1 No Such File or Directory

cd Projects
bash: cd: Projects: No such file or directory

Cause: The specified directory does not exist at the given location, or its name is incorrect.

Solution: Use ls to check available directory names and verify spelling.

9.2 Permission Denied

bash: cd: restricted: Permission denied

Cause: The user does not have the necessary permission to access the directory.

Solution: Check directory permissions using ls -ld directory_name.

9.3 Incorrect Directory Name

Linux filenames are case-sensitive. For example, Documents and documents are different directory names.

10. Practical Lab Exercises

Lab 1: Display Current Directory

Objective: Identify your current working directory.

pwd

Expected Result: The terminal displays the full path of the current directory.

Lab 2: Navigate to Home Directory

Objective: Move to the home directory.

cd pwd

Expected Result: The displayed path is your home directory.

Lab 3: Move to Documents

Objective: Enter the Documents directory.

cd ~/Documents pwd

Expected Result: The terminal displays the Documents directory path, if it exists.

Lab 4: Move to Parent Directory

Objective: Move one directory level upward.

cd .. pwd

Expected Result: The displayed path is one level above the previous directory.

Lab 5: Switch Between Two Directories

Objective: Use the previous-directory shortcut.

cd ~ cd /tmp cd - pwd

Expected Result: The terminal switches back to the home directory after visiting /tmp.

Lab 6: Navigate Using an Absolute Path

Objective: Move to a directory using its complete path.

cd /home pwd

Expected Result: The current working directory becomes /home.

11. Interview Questions and Answers

Q1. What is the full form of cd?

Answer: Change Directory.

Q2. What is the purpose of the cd command?

Answer: It changes the current working directory in a Linux shell.

Q3. How do you move to the home directory?

Answer: Use cd or cd ~.

Q4. How do you move one directory level up?

Answer: Use cd ...

Q5. What does cd - do?

Answer: It switches to the previous working directory.

Q6. What is the difference between absolute and relative paths?

Answer: An absolute path starts from root (/), whereas a relative path is interpreted from the current working directory.

Q7. Is cd an external Linux command?

Answer: No. It is generally a shell built-in command because it must change the working directory of the current shell process.

Q8. How do you navigate to a directory whose name contains spaces?

Answer: Use quotation marks or escape the spaces with a backslash.

12. Multiple Choice Questions (MCQs)

Q1. What does the cd command do?

  1. Creates a file
  2. Changes directory
  3. Deletes a directory
  4. Displays files

Correct Answer: B. Changes directory

Q2. Which command moves to the home directory?

  1. cd /
  2. cd ..
  3. cd ~
  4. cd -

Correct Answer: C. cd ~

Q3. Which command moves one level upward?

  1. cd .
  2. cd ..
  3. cd ~
  4. cd /

Correct Answer: B. cd ..

Q4. Which symbol represents the root directory?

  1. ~
  2. .
  3. ..
  4. /

Correct Answer: D. /

Q5. Which command returns to the previous working directory?

  1. cd -
  2. cd ..
  3. cd /
  4. cd .

Correct Answer: A. cd -

13. Lesson Summary

  • cd changes the current working directory.
  • cd ~ moves to the home directory.
  • cd .. moves one level upward.
  • cd / moves to the root directory.
  • cd - switches to the previous directory.
  • Absolute paths start from root.
  • Relative paths start from the current directory.
  • Use quotes or backslashes for directory names containing spaces.
  • Use pwd to verify your current location.
