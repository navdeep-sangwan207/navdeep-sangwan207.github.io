cp Command in Linux

Copy Files and Directories Using the Linux Terminal

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the cp command.
  • Copy files within the same directory and between directories.
  • Copy multiple files to another directory.
  • Copy directories recursively.
  • Use important cp options such as -r, -i, -v, -p and -u.
  • Understand common copying errors and troubleshoot them.

1. Introduction to the cp Command

The cp command stands for Copy. It is used to copy files and directories from one location to another in Linux.

The original file remains in its source location. The command creates a copy at the destination.

Important: The cp command copies data. Unlike mv, it does not remove the original source file after a successful copy.

Example

cp notes.txt backup.txt

Creates a copy named backup.txt from notes.txt in the current directory.

notes.txt backup.txt

Both files now exist independently. Changes made to one regular file do not automatically change the other.

2. Syntax of the cp Command

cp [OPTIONS] SOURCE DESTINATION

For copying multiple files:

cp [OPTIONS] SOURCE1 SOURCE2 ... DIRECTORY
Component Description
cp Command used to copy files and directories.
OPTIONS Optional settings controlling the copy operation.
SOURCE Original file or directory.
DESTINATION Target filename or destination directory.

3. Basic File Copying

3.1 Copy a File in the Same Directory

cp file.txt file_backup.txt

Creates file_backup.txt as a copy of file.txt.

3.2 Copy a File to Another Directory

cp notes.txt Documents/

Copies notes.txt into the Documents directory. The copied file keeps the original filename.

3.3 Copy a File with a New Name

cp notes.txt Documents/backup_notes.txt

Copies notes.txt into Documents and names the destination file backup_notes.txt.

3.4 Copy Using an Absolute Path

cp /home/user/notes.txt /tmp/

Copies notes.txt from /home/user to /tmp.

Replace user with the actual username on your Linux system.

4. Copy Multiple Files

The cp command can copy multiple source files into one destination directory.

Example

cp file1.txt file2.txt file3.txt Backup/

Copies all three files into the Backup directory.

Using Wildcards

cp *.txt Backup/

Copies all matching .txt files from the current directory into Backup.

Wildcard explanation: The asterisk (*) matches any sequence of characters. The shell expands the pattern before running cp.

Copy All C Source Files

cp *.c SourceBackup/

Copies files ending in .c into SourceBackup.

The destination directory must already exist when copying multiple source files.

5. Copy Directories

By default, cp does not copy directories. To copy a directory and its contents, use the recursive option.

5.1 -r Option: Recursive Copy

cp -r Projects Projects_Backup

Copies the Projects directory and its contents into a new directory named Projects_Backup.

Example Directory Structure

Projects/ ├── main.c ├── README.txt └── Documents/ └── notes.txt

After executing:

cp -r Projects Projects_Backup

The copied structure looks like this:

Projects_Backup/ ├── main.c ├── README.txt └── Documents/ └── notes.txt

5.2 -R Option: Recursive Copy

cp -R Projects Projects_Backup

The uppercase -R option also copies directories recursively.

GNU cp commonly supports both -r and -R for recursive copying. Their behaviour can differ in special filesystem and symbolic-link cases. Use -R when following conventional recursive-copy practice.

6. Important cp Options

Option Description Example
-r Copy directories recursively. cp -r A B
-R Copy directories recursively. cp -R A B
-i Prompt before overwriting a destination file. cp -i a.txt b.txt
-f Force copying by removing an existing destination if it cannot be opened. cp -f a.txt b.txt
-v Display each copy operation. cp -v a.txt Backup/
-p Preserve mode, ownership where permitted, and timestamps. cp -p a.txt Backup/
-u Copy only when the source is newer or the destination is missing. cp -u a.txt Backup/
-n Do not overwrite an existing destination file. cp -n a.txt b.txt
-a Archive mode; recursively copy and preserve important attributes. cp -a Projects Backup/
-b Make a backup of an existing destination before overwriting it. cp -b a.txt b.txt

6.1 -i Option: Interactive Copy

cp -i source.txt destination.txt

If destination.txt already exists, cp asks for confirmation before overwriting it.

cp: overwrite 'destination.txt'?

Enter y to confirm or n to cancel.

6.2 -f Option: Force Copying

cp -f source.txt destination.txt

Attempts to force the copy operation. It can remove an existing destination file if necessary to open it.

Use -f carefully. It can cause existing destination data to be lost.

6.3 -v Option: Verbose Output

cp -v notes.txt Backup/
'notes.txt' -> 'Backup/notes.txt'

Displays information about the copy operation.

6.4 -p Option: Preserve Attributes

cp -p notes.txt Backup/

Attempts to preserve the source file's mode, ownership where permitted, and timestamps.

6.5 -u Option: Update Only

cp -u source.txt Backup/

Copies the source if the destination does not exist or if the source is newer than the destination.

6.6 -a Option: Archive Mode

cp -a Projects Projects_Backup

Archive mode is useful for copying directory structures while preserving important file attributes and symbolic links.

7. Copy Files with Spaces in Their Names

If a filename or directory name contains spaces, use quotation marks or escape the spaces.

Method 1: Double Quotes

cp "My Notes.txt" Backup/

Method 2: Single Quotes

cp 'My Notes.txt' Backup/

Method 3: Backslash

cp My\ Notes.txt Backup/

8. Difference Between cp and mv

cp mv
Copies files and directories. Moves or renames files and directories.
Original source normally remains. Source is removed from its old location after a successful move.
Can create an additional copy. Changes the location or name of the original entry.
Directory copying requires recursive options. Can move directories without a recursive option.
Example: cp a.txt Backup/ Example: mv a.txt Backup/

9. Common Errors and Troubleshooting

9.1 No Such File or Directory

cp missing.txt Backup/
cp: cannot stat 'missing.txt': No such file or directory

Cause: The source file does not exist at the specified location.

Solution: Verify the filename and location using ls and pwd.

9.2 Is a Directory

cp Projects Backup/
cp: -r not specified; omitting directory 'Projects'

Cause: The source is a directory, but recursive copying was not requested.

Solution: Use:

cp -r Projects Backup/

9.3 Permission Denied

Cause: The user does not have sufficient permission to read the source or write to the destination.

Solution: Check file and directory permissions using ls -l.

9.4 Same File

cp notes.txt notes.txt
cp: 'notes.txt' and 'notes.txt' are the same file

Cause: The source and destination refer to the same file.

Solution: Choose a different destination filename.

9.5 Destination Is Not a Directory

When copying multiple source files, the destination must be an existing directory. Verify the destination path before copying.

10. Practical Lab Exercises

Lab 1: Copy a File

Objective: Create a file and copy it.

touch notes.txt cp notes.txt notes_backup.txt ls

Expected Result: Both notes.txt and notes_backup.txt are present.

Lab 2: Copy a File to Another Directory

Objective: Copy a file into Backup.

mkdir -p Backup touch report.txt cp report.txt Backup/ ls Backup

Expected Result: report.txt appears inside Backup.

Lab 3: Copy with a New Name

Objective: Create a renamed copy.

cp report.txt Backup/report_copy.txt ls Backup

Expected Result: Backup contains report.txt and report_copy.txt.

Lab 4: Copy Multiple Files

Objective: Copy multiple files into one directory.

touch main.c functions.c header.h mkdir -p SourceBackup cp main.c functions.c header.h SourceBackup/ ls SourceBackup

Expected Result: All three files appear inside SourceBackup.

Lab 5: Copy a Directory Recursively

Objective: Copy a complete directory structure.

mkdir -p Projects/C/Programs touch Projects/C/Programs/main.c cp -r Projects Projects_Backup ls -R Projects_Backup

Expected Result: Projects_Backup contains the same directory structure and file.

Lab 6: Use Interactive Copy

Objective: Practise overwrite confirmation.

touch first.txt second.txt cp -i first.txt second.txt

Expected Result: If second.txt already exists, cp asks whether it should be overwritten.

Lab 7: Use Verbose Copy

Objective: Display copy operation details.

cp -v first.txt Backup/

Expected Result: The terminal displays the source and destination paths.

Lab 8: Preserve File Attributes

Objective: Copy a file while preserving important attributes.

cp -p first.txt Backup/ stat first.txt Backup/first.txt

Expected Result: The destination file retains the source's mode and timestamps where supported and permitted.

11. Interview Questions and Answers

Q1. What is the full form of cp?

Answer: Copy.

Q2. What is the purpose of the cp command?

Answer: It copies files and directories from one location to another.

Q3. How do you copy a file?

Answer: Use cp source.txt destination.txt.

Q4. How do you copy a directory?

Answer: Use cp -r source_directory destination_directory.

Q5. What is the purpose of cp -i?

Answer: It prompts before overwriting an existing destination file.

Q6. What is the purpose of cp -v?

Answer: It displays information about each copy operation.

Q7. What does cp -p preserve?

Answer: It attempts to preserve file mode, ownership where permitted, and timestamps.

Q8. What is the difference between cp and mv?

Answer: cp creates a copy while retaining the original source. mv moves or renames the original entry.

Q9. What does cp -u do?

Answer: It copies when the destination is missing or older than the source.

Q10. What is archive mode in cp?

Answer: The -a option performs recursive copying while preserving important attributes and symbolic links.

12. Multiple Choice Questions (MCQs)

Q1. Which command copies a file?

  1. mv
  2. cp
  3. rm
  4. mkdir

Correct Answer: B. cp

Q2. Which option is used for recursive directory copying?

  1. -i
  2. -v
  3. -r
  4. -p

Correct Answer: C. -r

Q3. Which option prompts before overwriting?

  1. -i
  2. -f
  3. -u
  4. -a

Correct Answer: A. -i

Q4. Which option displays copy operation messages?

  1. -p
  2. -v
  3. -n
  4. -u

Correct Answer: B. -v

Q5. Which option is used for archive mode?

  1. -a
  2. -c
  3. -m
  4. -d

Correct Answer: A. -a

Q6. Which command copies a directory recursively?

  1. cp Projects Backup
  2. cp -r Projects Backup
  3. mv -r Projects Backup
  4. mkdir -r Projects Backup

Correct Answer: B. cp -r Projects Backup

Q7. Which option copies only when the source is newer or the destination is missing?

  1. -i
  2. -v
  3. -u
  4. -f

Correct Answer: C. -u

13. Lesson Summary

  • cp copies files and directories.
  • cp source destination copies a file.
  • cp -r copies directories recursively.
  • cp -i prompts before overwriting.
  • cp -v displays copy operation details.
  • cp -p attempts to preserve important file attributes.
  • cp -u copies newer source files or missing destinations.
  • cp -a performs archive-mode copying.
  • cp -n avoids overwriting existing destinations.
Placement Preparation Tip: Practise copying individual files, multiple files, and complete directory structures. Understand the difference between -r, -i, -v, -p, -u, and -a. These options are useful in Linux administration, shell scripting, and software development workflows.
