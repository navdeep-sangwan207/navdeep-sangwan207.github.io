LINUX PROGRAMMING • CHAPTER 3 • LESSON 2

pwd Command

Understand how to display and identify the current working directory.

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the meaning of the present working directory.
  • Explain the purpose and syntax of the pwd command.
  • Use pwd to display the current directory location.
  • Understand logical and physical directory paths.
  • Differentiate between pwd shell builtin and external command.
  • Use pwd in practical Linux operations and shell scripts.

1. Introduction to the pwd Command

The pwd command stands for Print Working Directory. It displays the absolute pathname of the current working directory.

The working directory is the directory in which the current shell is operating. Commands that use relative paths generally interpret those paths from this location.

Basic Command

pwd
Example Output:
/home/user

This indicates that the current working directory is /home/user.

Important: The output depends on your current directory and username. Your Ubuntu system may display a different path.

2. Syntax of the pwd Command

The general syntax is:

pwd [OPTION]

The command accepts options that control how the directory pathname is displayed.

Component Description
pwd Command name.
-L Displays the logical working directory.
-P Displays the physical working directory.

3. Basic Usage of pwd

Open the Ubuntu terminal and execute the pwd command.

pwd
Example Output:
/home/navdeep

The output shows the current directory. If you open a terminal in your home directory, the output will normally be your home directory's absolute path.

Check the Current Directory After Navigation

cd / pwd
Output:
/

The cd command changes the current directory to the root directory. The pwd command then displays /.

4. Understanding Logical and Physical Paths

Linux provides two important ways to display the current working directory: logical and physical.

4.1 Logical Path: pwd -L

The logical option displays the pathname using the shell's current directory information. It preserves symbolic-link components when the shell has maintained that logical path.

pwd -L

This is generally the default behavior of the Bash pwd builtin.

4.2 Physical Path: pwd -P

The physical option displays the actual directory path after resolving symbolic links.

pwd -P

This is useful when you need to identify the real filesystem location rather than a symbolic-link path.

Example Using a Symbolic Link

Suppose the following directories exist:

/home/user/Projects /home/user/ProjectLink

Assume ProjectLink is a symbolic link pointing to Projects. Execute:

cd /home/user/ProjectLink pwd -L pwd -P
Possible Output:
/home/user/ProjectLink /home/user/Projects

The logical output preserves the symbolic-link path, while the physical output identifies the target directory.

Note: The exact behavior can depend on the shell and how the directory was entered. The example assumes Bash has maintained the logical path.

5. pwd as a Shell Builtin and External Command

On Linux systems, pwd is commonly available in two forms:

  1. A shell builtin command.
  2. An external executable program.

5.1 Shell Builtin

Bash provides pwd as a builtin command. It can access the shell's own current working directory information.

type pwd

In Bash, the output normally identifies pwd as a shell builtin.

5.2 External Command

Many Linux distributions also provide an external pwd executable, commonly located at /usr/bin/pwd.

/usr/bin/pwd

This executes the external program directly rather than invoking Bash's builtin pwd.

Shell Builtin External Command
Part of the shell. Separate executable program.
Accesses shell-maintained directory information. Determines the working directory of the process.
Invoked using pwd in Bash. Can be invoked using /usr/bin/pwd, if available.
Systems Programming Connection: A process maintains its current working directory. The external pwd program can obtain it through the operating system's current-working-directory interface, such as the getcwd() system call or library function.

6. Important pwd Options

Command Description
pwd Displays the current working directory.
pwd -L Displays the logical working directory.
pwd -P Displays the physical working directory.
pwd --help Displays help for implementations that support it.
pwd --version Displays version information for implementations that support it.
Important: Bash's builtin pwd and the external pwd utility may support different options. If you need the external utility's help or version information, execute it explicitly, for example /usr/bin/pwd --help.

7. Using pwd with Other Linux Commands

The pwd command is frequently used with other commands to understand the current filesystem location.

Example 1: pwd and ls

pwd ls

Displays the current directory followed by its contents.

Example 2: pwd and cd

pwd cd /home pwd

Displays the directory before and after changing location.

Example 3: Store the Current Path in a Variable

CURRENT_DIR=$(pwd) echo "$CURRENT_DIR"

The command substitution executes pwd and stores its output in the shell variable CURRENT_DIR.

Example Output:
/home/user

Example 4: Display Current Directory in a Message

echo "Current directory: $(pwd)"
Example Output:
Current directory: /home/user

8. pwd in Shell Scripting

The pwd command is useful in shell scripts when a script needs to identify or display the current working directory.

Example: Simple Bash Script

Filename: current_directory.sh

#!/bin/bash echo "Current Working Directory:" pwd echo "Script execution completed."

Execute the Script

chmod +x current_directory.sh ./current_directory.sh

Expected Output

Current Working Directory: /home/user Script execution completed.

The displayed directory is the working directory from which the script is executed, not necessarily the directory containing the script file.

Important distinction: The current working directory and the script's own directory are not always the same.

9. Difference Between pwd and cd

Both commands are related to directory navigation, but they perform different operations.

pwd cd
Print Working Directory. Change Directory.
Displays the current directory. Changes the current directory.
Does not navigate to another directory. Changes the shell's working directory.
Example: pwd Example: cd /home

Practical Comparison

pwd cd /etc pwd

The first pwd displays the original location. The cd command changes the location to /etc. The second pwd displays the new location.

10. Common Mistakes and Troubleshooting

Mistake 1: Incorrect Command Spelling

pwwd

Possible Error: command not found.

Correction:

pwd

Mistake 2: Using an Unsupported Option

pwd -x

This may produce an invalid option error because -x is not a standard pwd option.

Mistake 3: Assuming pwd Displays the Script Location

pwd displays the current working directory of the shell or process, not automatically the directory where a script is stored.

Mistake 4: Confusing Logical and Physical Paths

When symbolic links are involved, pwd -L and pwd -P may display different paths.

Troubleshooting Tip: Use type pwd to identify whether Bash recognizes pwd as a builtin, and use pwd --help or the manual page to check supported syntax.

11. Practical Lab Exercises

Lab 1: Display the Current Directory

Objective: Identify the current working directory.

Commands:

pwd

Expected Result:

The terminal displays the absolute path of the current working directory.

Lab 2: Navigate and Check Directory Changes

Objective: Observe how the working directory changes.

pwd cd / pwd cd /home pwd cd ~ pwd

Expected Result:

The output should show the root directory, /home, and then the current user's home directory.

Lab 3: Compare Logical and Physical Paths

Objective: Understand symbolic-link resolution.

mkdir -p ~/Projects ln -s ~/Projects ~/ProjectLink cd ~/ProjectLink pwd -L pwd -P

Expected Result:

The logical path should normally show ProjectLink, while the physical path should show the Projects directory.

Lab Note: This exercise assumes that ~/ProjectLink does not already exist. If it does, use another unused link name.

Lab 4: Store the Directory Path

Objective: Store and display the current path.

MY_PATH=$(pwd) echo "$MY_PATH"

Expected Result:

The variable MY_PATH contains the current directory path.

Lab 5: Identify the pwd Command Type

Objective: Identify the shell builtin and external executable.

type pwd /usr/bin/pwd

Expected Result:

The first command normally identifies pwd as a Bash builtin. The second runs the external executable if it exists at that location.

12. Important Interview Questions

Q1. What is the full form of pwd?

pwd stands for Print Working Directory.

Q2. What is the purpose of the pwd command?

It displays the absolute pathname of the current working directory.

Q3. What is the syntax of pwd?

The basic syntax is pwd [OPTION].

Q4. What is the difference between pwd -L and pwd -P?

pwd -L displays the logical directory path, while pwd -P displays the physical path after resolving symbolic links.

Q5. Is pwd an internal or external command?

In Bash, pwd is a shell builtin. Many Linux systems also provide an external pwd executable.

Q6. What is the difference between pwd and cd?

pwd displays the current working directory, while cd changes the current working directory.

Q7. What does pwd display when the current directory is root?

It displays a single forward slash: /.

Q8. Can pwd be used in shell scripts?

Yes. It can display or provide the current working directory for use in shell scripts.

Q9. What is getcwd()?

getcwd() is a system interface commonly used by programs to obtain the absolute pathname of the current working directory.

Q10. Does pwd show the directory containing a script?

No. It displays the current working directory of the executing shell or process, which may differ from the script's location.

13. Multiple Choice Questions (MCQs)

Q1. What is the full form of pwd?

  1. Print Working Directory
  2. Present Working Data
  3. Program Working Directory
  4. Print Windows Directory

Answer: A. Print Working Directory

Q2. Which command displays the current directory?

  1. cd
  2. pwd
  3. ls
  4. mkdir

Answer: B. pwd

Q3. Which option displays the physical directory path?

  1. -L
  2. -P
  3. -a
  4. -l

Answer: B. -P

Q4. Which option displays the logical directory path?

  1. -P
  2. -L
  3. -r
  4. -h

Answer: B. -L

Q5. What does pwd display when the current directory is root?

  1. /home
  2. ~
  3. /
  4. root

Answer: C. /

Q6. Which command changes the current working directory?

  1. pwd
  2. cd
  3. whoami
  4. date

Answer: B. cd

Q7. Which Bash command identifies pwd as a builtin?

  1. type pwd
  2. ls pwd
  3. mkdir pwd
  4. date pwd

Answer: A. type pwd

Q8. Which system interface can obtain the current working directory?

  1. printf()
  2. getcwd()
  3. mkdir()
  4. remove()

Answer: B. getcwd()

Q9. What does pwd normally display inside a shell script?

  1. The script's filename
  2. The script's source code
  3. The current working directory
  4. The system username only

Answer: C. The current working directory

Q10. Which command executes the external pwd utility directly, if installed at that path?

  1. /usr/bin/pwd
  2. cd /usr/bin
  3. type /pwd
  4. ls -pwd

Answer: A. /usr/bin/pwd
