Clear, History and man Commands

Managing the Terminal and Accessing Linux Command Documentation

1. Introduction

Linux provides several commands to manage terminal sessions and access command documentation.

Three useful commands are:

  • clear: Clears the visible terminal screen.
  • history: Displays previously executed shell commands.
  • man: Displays manual pages containing documentation about Linux commands and system interfaces.
Example: If you forget the syntax of a command, you can use man to read its documentation. If you want to reuse a previous command, you can search your shell history.

2. clear Command

2.1 Definition

The clear command clears the visible contents of the terminal screen. It makes the terminal easier to read by removing previously displayed output from the current screen view.

2.2 Syntax

clear

2.3 Example

Execute a few commands:

pwd ls date whoami

Now clear the terminal:

clear

The visible terminal screen is cleared, and the shell prompt appears again.

2.4 Keyboard Shortcut

In many Linux terminal environments, you can also use:

Ctrl + L
Important: Clearing the terminal screen does not delete command history or remove files. Previously executed commands can still be available through the history command.

2.5 clear with Options

In many Linux environments, the clear utility supports these options:

Option Description
-x Clears the screen without clearing the terminal's scrollback buffer, where supported.
-T type Specifies the terminal type.
-V Displays version information in implementations that support it.

Example:

clear -x

3. history Command

3.1 Definition

The history command displays previously executed commands in the current shell session and, depending on shell configuration, commands saved from earlier sessions.

In Bash, command history is maintained by the shell and can be stored in a history file, commonly ~/.bash_history.

3.2 Syntax

history [OPTION] [COUNT]

3.3 Display Command History

history
Example Output:
1 pwd 2 ls 3 mkdir Linux 4 cd Linux 5 touch file.txt 6 cat file.txt 7 clear 8 date

The output contains numbered commands that were previously executed.

3.4 Display the Last 5 Commands

Specify a count after the history command:

history 5

This displays the most recent five commands available in the shell history.

3.5 Search Command History

You can search previously executed commands using grep.

history | grep ls

This displays history entries containing the text ls.

3.6 Execute a Previous Command by Number

Use an exclamation mark followed by a history number.

!3

This executes the command numbered 3 in the current history list.

Warning: History expansion executes a command, not just displays it. Check the command before using this feature, particularly if it may modify or delete files.

3.7 Execute the Previous Command

Use two exclamation marks:

!!

This repeats the immediately previous command.

3.8 Reuse the Previous Command with sudo

In Bash, you can add sudo to the previous command using:

sudo !!

This expands and executes the previous command with sudo. Use it only when administrator privileges are required and the command is understood.

3.9 Remove a History Entry

Use the history -d option followed by an entry number.

history -d 5

This deletes history entry number 5 from the current shell's history list.

The history entry number is taken from the current history output. Deleting an entry from the in-memory list does not automatically guarantee that all previously saved copies or logs are removed.

3.10 Clear the Current Shell History List

Use:

history -c

This clears the current shell's in-memory history list.

3.11 Save History to the History File

In Bash, use:

history -w

This writes the current history list to the history file, normally ~/.bash_history.

3.12 Append History to the History File

history -a

This appends commands from the current session to the history file.

3.13 Important history Options

Command Description
history Displays command history.
history 5 Displays the last five history entries.
history -c Clears the current in-memory history list.
history -d 5 Deletes a specified history entry.
history -w Writes the history list to the history file.
history -a Appends new history entries to the history file.
history -r Reads the history file and appends its entries to the current history list.
history -n Reads new entries from the history file.

4. Linux Manual System

4.1 What is a Manual Page?

A manual page, commonly called a man page, is a documentation page that explains how to use a Linux command, system call, library function or other system component.

Manual pages generally include:

  • Command name and description.
  • Syntax and usage.
  • Available options.
  • Arguments and parameters.
  • Examples and related commands.

4.2 man Command

The man command displays the manual page for a specified command or topic.

4.3 Syntax

man [OPTION] COMMAND

4.4 Display the Manual Page of ls

man ls

This opens the manual documentation for the ls command.

4.5 Display the Manual Page of mkdir

man mkdir

This displays the documentation for creating directories.

4.6 Display the Manual Page of pwd

man pwd

This displays documentation for the pwd command.

4.7 Search Manual Page Names

Use the -f option to search for a manual page by its exact name.

man -f ls

This displays a short description of the matching manual entry, if available.

4.8 Search Manual Page Descriptions

Use the -k option to search manual page names and short descriptions for a keyword.

man -k copy

This searches for manual entries related to the word copy.

Difference:
  • man -f ls searches for a manual entry with the specified name.
  • man -k copy searches manual entry names and descriptions using a keyword.

5. Sections of Linux Manual Pages

Linux manual pages are organized into numbered sections. Each section covers a different category of documentation.

Section Category Example
1 User commands man 1 ls
2 System calls man 2 open
3 Library functions man 3 printf
4 Special files and device files man 4 null
5 File formats and conventions man 5 passwd
6 Games and screensavers man 6 intro
7 Miscellaneous topics and conventions man 7 signal
8 System administration commands man 8 mount
9 Kernel routines (where available) System-dependent

5.1 Why Are Manual Sections Important?

The same name can refer to different types of documentation.

For example, printf can refer to a shell command or a C library function.

man 1 printf man 3 printf
  • man 1 printf opens the user-command documentation.
  • man 3 printf opens the C library function documentation.
Section availability depends on the installed manual-page packages and Linux distribution. Section 9 is not available on every system.

6. Navigating Manual Pages

Manual pages commonly open in a pager such as less. You can use keyboard shortcuts to navigate the documentation.

Key Function
Space Move forward one screen.
b Move backward one screen.
Enter Move forward one line.
k Move backward one line.
g Move to the beginning.
G Move to the end.
/keyword Search forward for a keyword.
?keyword Search backward for a keyword.
n Find the next search match.
N Find the previous search match.
q Quit the manual page.

Example: Search for an Option

Open the ls manual:

man ls

Inside the manual page, type:

/-l

This searches forward for the text -l. Press n to find the next match and q to exit.

7. Related Documentation Commands

7.1 whatis Command

The whatis command displays a short description of a command from the manual database.

whatis ls

It provides a brief description rather than opening the complete manual.

7.2 apropos Command

The apropos command searches manual page names and descriptions using a keyword.

apropos network

This displays manual entries related to networking.

7.3 info Command

The info command displays documentation in the GNU Info format, where documentation is available.

info ls

7.4 --help Option

Many Linux commands support --help to display a short usage guide.

ls --help mkdir --help cp --help
Command Purpose
man Displays detailed manual documentation.
whatis Displays a short description of a command.
apropos Searches manual descriptions using a keyword.
info Displays GNU Info documentation.
--help Displays a command's short usage information, when supported.

8. Practical Linux Examples

Example 1: Clear the Terminal

clear

Removes the currently visible terminal output.

Example 2: View Previous Commands

history

Displays the available command history.

Example 3: Find Previously Used Commands

history | grep mkdir

Displays history entries containing the text mkdir.

Example 4: Read Documentation for cp

man cp

Opens the manual documentation for the cp command.

Example 5: Search Documentation for File Permissions

apropos permission

Searches manual descriptions for permission-related entries.

Example 6: Display Short Command Help

chmod --help

Displays usage information for the chmod command, if supported.

9. Common Errors and Troubleshooting

Error / Problem Possible Reason Solution
command not found Command is unavailable or not installed. Check the command name and installed packages.
No manual entry Manual page is not installed or available. Check installed documentation packages.
whatis database is empty Manual database may not be built or updated. Check the system's man-db configuration.
history does not show expected commands History settings or shell session may differ. Check shell type and history configuration.
Command executed unexpectedly History expansion such as !! or !number was used. Inspect the command before executing it.

Check Your Shell

echo $SHELL

This displays the configured login shell path. Bash-specific history features may behave differently in other shells.

Check Whether a Manual Page Is Available

man ls

If the manual is unavailable, your Linux installation may not have the relevant manual-page package installed.

11. Interview Questions and Answers

Q1. What is the purpose of the clear command?

Answer: It clears the visible terminal screen.

Q2. Does clear delete command history?

Answer: No. It only clears the visible terminal output.

Q3. What is the purpose of the history command?

Answer: It displays previously executed shell commands.

Q4. How do you display the last five history entries?

Answer: history 5

Q5. How do you execute the previous command again?

Answer: Use !! in shells that support history expansion, such as Bash.

Q6. What does history -c do?

Answer: It clears the current shell's in-memory history list.

Q7. What is a man page?

Answer: A manual page is documentation that explains the usage, options and behaviour of Linux commands and system components.

Q8. How do you open the manual page of ls?

Answer: man ls

Q9. How do you exit a manual page?

Answer: Press q.

Q10. What is the difference between man and --help?

Answer: man generally provides detailed documentation, while --help generally displays a short command usage guide.

Q11. What is the purpose of apropos?

Answer: It searches manual page names and descriptions using a keyword.

Q12. What is the difference between man 1 printf and man 3 printf?

Answer: Section 1 documents the user command, while section 3 documents the C library function.
