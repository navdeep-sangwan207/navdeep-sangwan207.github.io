head and tail Commands

Viewing the Beginning and End of Files in Linux

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the head command.
  • Display the first lines or bytes of a file.
  • Understand the purpose of the tail command.
  • Display the last lines or bytes of a file.
  • Use options such as -n, -c, and -f.
  • Monitor log files using the tail command.
  • Use these commands in practical Linux tasks.

1. Introduction

Linux provides several commands for reading and examining text files. Sometimes, we do not need to display the entire contents of a large file. We may only need its first few lines or its most recent entries.

The head and tail commands help us examine the beginning and end of files.

  • head: Displays the beginning of a file.
  • tail: Displays the end of a file.
Example: If a file contains 1000 lines:
  • head normally displays lines 1–10.
  • tail normally displays lines 991–1000.

2. head Command

2.1 Definition

The head command displays the first part of a file. By default, it displays the first 10 lines.

2.2 Syntax

head [OPTION] [FILE]

Here:

  • head: Command name.
  • OPTION: Specifies how much content to display.
  • FILE: Name or path of the file.

2.3 Create a Sample File

First, create a file containing sample lines:

nano numbers.txt

Enter the following content and save the file:

Line 1: Introduction to Linux Line 2: Linux Commands Line 3: File Management Line 4: Directories Line 5: Permissions Line 6: Shell Programming Line 7: Processes Line 8: Networking Line 9: System Administration Line 10: Linux Applications Line 11: Embedded Linux Line 12: Device Drivers Line 13: Kernel Programming Line 14: Shell Scripting Line 15: Linux Projects

2.4 Display the First 10 Lines

head numbers.txt
Output:
Line 1: Introduction to Linux Line 2: Linux Commands Line 3: File Management Line 4: Directories Line 5: Permissions Line 6: Shell Programming Line 7: Processes Line 8: Networking Line 9: System Administration Line 10: Linux Applications

By default, the command displays the first 10 lines.

2.5 Display a Specific Number of Lines

Use the -n option to specify the number of lines.

head -n 5 numbers.txt
Output:
Line 1: Introduction to Linux Line 2: Linux Commands Line 3: File Management Line 4: Directories Line 5: Permissions

This command displays the first five lines.

2.6 Display the First 3 Lines

head -n 3 numbers.txt
Output:
Line 1: Introduction to Linux Line 2: Linux Commands Line 3: File Management

2.7 Alternative Syntax

You can also specify the number of lines using a negative-free numeric argument without the -n option:

head -5 numbers.txt

This displays the first five lines, just like head -n 5 numbers.txt.

2.8 Display the First Number of Bytes

The -c option displays a specified number of bytes from the beginning of a file.

head -c 20 numbers.txt

This displays the first 20 bytes of the file. The result may end in the middle of a word or line.

2.9 Display Multiple Files

The head command can display the beginning of multiple files.

head file1.txt file2.txt

It displays the first 10 lines of each file, normally with file-name headers.

2.10 Important head Options

Option Description Example
No option Displays first 10 lines head file.txt
-n Displays specified number of lines head -n 5 file.txt
-c Displays specified number of bytes head -c 20 file.txt
-q Suppresses file-name headers when displaying multiple files head -q a.txt b.txt
-v Always displays file-name headers head -v file.txt

3. tail Command

3.1 Definition

The tail command displays the last part of a file. By default, it displays the last 10 lines.

3.2 Syntax

tail [OPTION] [FILE]

3.3 Display the Last 10 Lines

tail numbers.txt
Output:
Line 6: Shell Programming Line 7: Processes Line 8: Networking Line 9: System Administration Line 10: Linux Applications Line 11: Embedded Linux Line 12: Device Drivers Line 13: Kernel Programming Line 14: Shell Scripting Line 15: Linux Projects

By default, the command displays the last 10 lines.

3.4 Display a Specific Number of Lines

Use the -n option to specify how many lines to display from the end.

tail -n 5 numbers.txt
Output:
Line 11: Embedded Linux Line 12: Device Drivers Line 13: Kernel Programming Line 14: Shell Scripting Line 15: Linux Projects

3.5 Display the Last 3 Lines

tail -n 3 numbers.txt
Output:
Line 13: Kernel Programming Line 14: Shell Scripting Line 15: Linux Projects

3.6 Alternative Syntax

You can also use a numeric argument without -n:

tail -5 numbers.txt

This displays the last five lines.

3.7 Display the Last Number of Bytes

The -c option displays a specified number of bytes from the end of a file.

tail -c 20 numbers.txt

This displays the last 20 bytes of the file.

3.8 Follow a File in Real Time

The -f option continuously monitors a file and displays new content added to it.

tail -f system.log

This command displays the last 10 lines initially and then waits for new data to be appended to the file.

Practical use: System administrators and developers use tail -f to monitor application logs, server logs and system activity.

To stop monitoring, press:

Ctrl + C

3.9 Follow a File Using -F

The -F option follows a file by name. It also retries opening the file if it is temporarily unavailable, which is useful when log files are rotated or recreated.

tail -F application.log
Note: The -f option normally follows the file descriptor, while -F follows the file name and retries when necessary. These options are commonly available in GNU/Linux.

3.10 Display Content Starting from a Specific Line

To display the file from line 5 onward, use a plus sign with -n:

tail -n +5 numbers.txt

This displays line 5 and all subsequent lines until the end of the file.

3.11 Important tail Options

Option Description Example
No option Displays last 10 lines tail file.txt
-n Displays specified number of lines tail -n 5 file.txt
-c Displays specified number of bytes tail -c 20 file.txt
-f Follows new content added to a file tail -f log.txt
-F Follows by file name and retries tail -F log.txt
-q Suppresses file-name headers for multiple files tail -q a.txt b.txt
-v Always displays file-name headers tail -v file.txt

4. Difference Between head and tail

Feature head tail
Purpose Displays beginning of a file Displays end of a file
Default output First 10 lines Last 10 lines
Line option -n -n
Byte option -c -c
Live monitoring Not normally used for this purpose -f and -F
Common application Checking file headers or initial records Checking recent entries and log files
Remember: head = beginning; tail = ending.

5. Combining head and tail with Other Commands

5.1 Using a Pipe

A pipe (|) sends the output of one command as input to another command.

cat numbers.txt | head -n 5

This displays the first five lines of the file.

5.2 Display Lines from the Middle of a File

You can combine tail and head to display a selected range of lines.

tail -n +5 numbers.txt | head -n 3

Explanation:

  1. tail -n +5 starts displaying from line 5.
  2. head -n 3 takes the first three lines of that output.
Output:
Line 5: Permissions Line 6: Shell Programming Line 7: Processes

5.3 Count Lines in a File

Use wc -l to count the number of lines in a file.

wc -l numbers.txt

This displays the total line count and the file name.

6. Practical Linux Examples

Example 1: Check the Beginning of a Configuration File

head -n 10 /etc/passwd

Displays the first 10 lines of the system account information file.

Example 2: Check Recent System Log Entries

tail -n 20 /var/log/syslog

Displays the last 20 lines of the syslog file, if it exists and you have permission to read it.

Example 3: Monitor a Log File

tail -f application.log

Continuously displays new entries appended to the application log.

Example 4: Display First 15 Lines

head -n 15 report.txt

Example 5: Display Last 7 Lines

tail -n 7 report.txt
Important: Some log files require administrator privileges. If permission is denied, use sudo only when you are authorized to access that file.

7. Common Errors and Troubleshooting

Error / Problem Possible Reason Solution
No such file or directory File does not exist or path is incorrect. Check the filename and path.
Permission denied User does not have read permission. Check file permissions and authorization.
Unexpected output Incorrect option or number of lines. Verify the command syntax.
tail -f shows no new output No new data is being appended. Check whether the application is writing to the file.

Useful Diagnostic Commands

pwd ls -l numbers.txt wc -l numbers.txt file numbers.txt

9. Interview Questions and Answers

Q1. What is the head command?

Answer: The head command displays the beginning of a file. By default, it displays the first 10 lines.

Q2. What is the tail command?

Answer: The tail command displays the end of a file. By default, it displays the last 10 lines.

Q3. How do you display the first 5 lines?

Answer: head -n 5 filename

Q4. How do you display the last 5 lines?

Answer: tail -n 5 filename

Q5. What is the purpose of the -c option?

Answer: The -c option displays a specified number of bytes from the beginning or end of a file.

Q6. What is the purpose of tail -f?

Answer: It continuously monitors a file and displays new content appended to it.

Q7. How do you stop the tail -f command?

Answer: Press Ctrl + C.

Q8. What is the difference between tail -f and tail -F?

Answer: -f follows the file descriptor by default. -F follows the file by name and retries opening it, which is useful when log files are rotated.

Q9. How can you display lines 5 to 7 of a file?

Answer: tail -n +5 filename | head -n 3

Q10. Which command is commonly used to monitor application logs?

Answer: tail -f application.log

11. Lesson Summary

  • head displays the beginning of a file.
  • tail displays the end of a file.
  • Both commands display 10 lines by default.
  • -n specifies the number of lines.
  • -c specifies the number of bytes.
  • tail -f monitors new content in a file.
  • tail -F follows a file by name and retries opening it.
  • Pipes can combine head and tail to extract a range of lines.
