Create and Remove Directories in Linux

1. Introduction to Directory Management

A directory is a filesystem object used to organize files and other directories. Linux provides commands to create, organize, and remove directories.

The two important commands are:

  • mkdir: Creates new directories.
  • rmdir: Removes empty directories.
Important: The mkdir command creates directories, whereas rmdir removes directories only when they are empty.

2. mkdir Command

The mkdir command stands for Make Directory. It is used to create new directories in Linux.

Syntax

mkdir [OPTIONS] DIRECTORY_NAME

Example 1: Create a Single Directory

mkdir Projects

Creates a directory named Projects in the current working directory.

Verify the Directory

ls
Projects

Example 2: Create Multiple Directories

mkdir C C++ Python Linux

Creates four directories in the current location.

Example 3: Create a Directory Using an Absolute Path

mkdir /home/user/Projects

Creates Projects inside /home/user, provided the parent directory exists and you have permission.

Replace user with the actual username or use a valid path from your Linux system.

3. Important mkdir Options

Option Description Example
-p Create parent directories when needed. mkdir -p A/B/C
-v Display a message for each created directory. mkdir -v Test
-m Set directory permissions during creation. mkdir -m 755 Test

3.1 -p Option: Create Parent Directories

The -p option creates missing parent directories automatically.

mkdir -p Projects/C/Programs

This command creates the following directory structure:

Projects/ └── C/ └── Programs/
If Projects or C does not exist, the command creates those directories as well.

3.2 -v Option: Verbose Output

mkdir -v Practice
mkdir: created directory 'Practice'

The -v option displays information about the directory creation operation.

3.3 -m Option: Set Permissions

mkdir -m 755 SecureProject

Creates SecureProject with the requested permissions of 755, subject to filesystem and system settings.

Permission Meaning
7 Read, write, and execute
5 Read and execute
5 Read and execute
Directory permissions have special significance: execute permission allows users to access or traverse a directory, while read permission allows listing its entries.

4. rmdir Command

The rmdir command stands for Remove Directory. It removes empty directories from the filesystem.

Syntax

rmdir [OPTIONS] DIRECTORY_NAME

Example 1: Remove an Empty Directory

mkdir Temporary rmdir Temporary

The first command creates Temporary. The second command removes it because it is empty.

Example 2: Remove Multiple Empty Directories

mkdir Test1 Test2 Test3 rmdir Test1 Test2 Test3

Removes all three directories if they are empty.

Example 3: Remove Nested Empty Directories

mkdir -p A/B/C rmdir -p A/B/C

The -p option removes the specified directory and attempts to remove its parent directories as well, provided they are empty.

The parent directories are not removed if they contain other files or directories.

5. Important rmdir Options

Option Description Example
-p Remove the specified directory and empty parent directories. rmdir -p A/B/C
-v Display a message for each removed directory. rmdir -v Test
--ignore-fail-on-non-empty Ignore failures caused by non-empty directories. rmdir --ignore-fail-on-non-empty Test

5.1 -v Option: Verbose Output

mkdir OldProject rmdir -v OldProject
rmdir: removing directory, 'OldProject'

5.2 -p Option: Remove Empty Parent Directories

mkdir -p Work/Projects/C rmdir -p Work/Projects/C

If all three directories are empty, the command removes C, Projects, and Work.

6. Difference Between mkdir and rmdir

mkdir rmdir
Creates directories. Removes empty directories.
Stands for Make Directory. Stands for Remove Directory.
Can create nested directories using -p. Can remove empty parent directories using -p.
Supports -m to set permissions. Does not use -m for permission settings.
Example: mkdir Test Example: rmdir Test

7. Removing Non-Empty Directories

The rmdir command cannot remove a directory containing files or subdirectories.

Example

mkdir Projects touch Projects/file.txt rmdir Projects
rmdir: failed to remove 'Projects': Directory not empty

The directory contains file.txt, so rmdir cannot remove it.

Important: The rm -r command can remove a directory and its contents recursively. However, it can permanently delete multiple files and directories. Use it carefully.

Example: Remove a Non-Empty Directory

rm -r Projects

Removes Projects and its contents recursively. Confirm the target path before executing this command.

8. Common Errors and Troubleshooting

8.1 File Exists

mkdir Projects
mkdir: cannot create directory 'Projects': File exists

Cause: A file or directory named Projects already exists at that location.

Solution: Use ls to inspect the existing entry or choose another name.

8.2 No Such File or Directory

mkdir A/B/C
mkdir: cannot create directory 'A/B/C': No such file or directory

Cause: The parent directories do not exist.

Solution: Use mkdir -p A/B/C.

8.3 Directory Not Empty

rmdir Projects
rmdir: failed to remove 'Projects': Directory not empty

Cause: The directory contains files or subdirectories.

Solution: Inspect its contents using ls. Remove its contents only when appropriate.

8.4 Permission Denied

Cause: The current user does not have the required permissions on the parent directory.

Solution: Check permissions using ls -ld directory_name and verify that you have the necessary access.

10. Interview Questions and Answers

Q1. What is the full form of mkdir?

Answer: Make Directory.

Q2. What is the full form of rmdir?

Answer: Remove Directory.

Q3. Which command creates a directory?

Answer: The mkdir command.

Q4. Which command removes an empty directory?

Answer: The rmdir command.

Q5. What is the purpose of mkdir -p?

Answer: It creates missing parent directories along with the requested directory.

Q6. Can rmdir remove a non-empty directory?

Answer: No. It removes only empty directories.

Q7. What is the purpose of mkdir -v?

Answer: It displays a message for each directory created.

Q8. How can you remove a directory containing files?

Answer: The rm -r command can remove a directory recursively, including its contents. It must be used carefully.

Q9. What does rmdir -p do?

Answer: It removes the specified directory and attempts to remove its empty parent directories.

Q10. Which command can set directory permissions during creation?

Answer: mkdir -m.

11. Multiple Choice Questions (MCQs)

Q1. Which command creates a directory?

  1. rmdir
  2. mkdir
  3. touch
  4. pwd

Correct Answer: B. mkdir

Q2. Which command removes an empty directory?

  1. mkdir
  2. cp
  3. rmdir
  4. ls

Correct Answer: C. rmdir

Q3. Which option creates missing parent directories?

  1. -v
  2. -m
  3. -p
  4. -l

Correct Answer: C. -p

Q4. Which option displays directory creation messages?

  1. -v
  2. -p
  3. -m
  4. -a

Correct Answer: A. -v

Q5. Can rmdir remove a directory containing files?

  1. Yes, always
  2. No
  3. Only with -v
  4. Only with -m

Correct Answer: B. No

Q6. Which command removes a directory and its contents recursively?

  1. rmdir -p
  2. mkdir -p
  3. rm -r
  4. pwd -r

Correct Answer: C. rm -r

12. Lesson Summary

  • mkdir creates new directories.
  • rmdir removes empty directories.
  • mkdir -p creates missing parent directories.
  • mkdir -v displays creation messages.
  • mkdir -m sets requested permissions during creation.
  • rmdir -p removes empty parent directories.
  • rmdir -v displays removal messages.
  • rm -r removes directories recursively, including their contents.
Placement Preparation Tip: Understand the difference between mkdir, rmdir, and rm -r. Practise creating nested directory structures and removing empty directories. These operations are frequently used in Linux administration and shell scripting.
