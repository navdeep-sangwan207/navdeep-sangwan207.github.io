mv Command in Linux

Moving and Renaming Files and Directories

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the mv command.
  • Move files from one directory to another.
  • Rename files and directories.
  • Move multiple files using one command.
  • Use important options such as -i, -f, and -v.
  • Understand the difference between cp and mv.

1. Introduction to the mv Command

The mv command in Linux is used to move files and directories from one location to another. It is also used to rename files and directories.

The name mv comes from the word move.

Important: Unlike the cp command, which creates a copy, the mv command normally transfers the original file to the new location. The original pathname no longer exists after a successful move.

2. Syntax of the mv Command

mv [OPTION] SOURCE DESTINATION

Explanation:

  • mv – Command used to move or rename.
  • OPTION – Optional behaviour of the command.
  • SOURCE – Original file or directory.
  • DESTINATION – New name or destination location.

Basic Example

mv file1.txt file2.txt

This renames file1.txt to file2.txt in the same directory.

3. Renaming a File

The mv command can rename a file by specifying its current name followed by its new name.

Example

mv old.txt new.txt

Before Execution

old.txt

After Execution

new.txt
Result: The file old.txt is renamed to new.txt. Its contents remain unchanged.

Renaming a Directory

mv old_folder new_folder

This renames the directory old_folder to new_folder.

4. Moving a File to Another Directory

To move a file, provide the source filename and the destination directory.

Example

mv file1.txt Documents/

This moves file1.txt into the Documents directory.

Moving a File Using an Absolute Path

mv file1.txt /home/user/Documents/

This moves the file to the specified absolute path, assuming that the destination directory exists and permissions allow it.

Moving and Renaming at the Same Time

mv file1.txt Documents/report.txt

This moves file1.txt into the Documents directory and gives it the new name report.txt.

5. Moving Multiple Files

The mv command can move multiple files into one destination directory.

Example

mv file1.txt file2.txt file3.txt Documents/

All three files are moved into the Documents directory.

Note: When multiple source files are specified, the final argument must be an existing destination directory.

Moving Files Using a Wildcard

mv *.txt Documents/

This moves all matching .txt files from the current directory into Documents.

Moving Files with a Specific Prefix

mv report* Documents/

This moves files and other matching entries whose names begin with report, subject to shell wildcard expansion.

6. Moving Directories

The mv command can move an entire directory, including its contents.

Example

mv Projects Documents/

This moves the complete Projects directory into Documents.

Moving a Directory to Another Location

mv Projects /home/user/Desktop/

This moves the Projects directory to the specified Desktop location.

The mv command does not require the recursive option -r to move a directory. It can move the directory and its contents directly.

7. Important Options of the mv Command

Option Description
-i Interactive mode. Asks before overwriting an existing destination.
-f Force mode. Does not prompt before overwriting.
-v Verbose mode. Displays the actions performed.
-n Do not overwrite an existing destination file.
-u Move only when the source is newer than the destination or the destination is missing.
-b Create a backup of an existing destination before overwriting it.
-t Specify the destination directory before the source files.

7.1 Interactive Option (-i)

mv -i file1.txt Documents/

If a file with the same name already exists in the destination, Linux asks for confirmation before overwriting it.

mv: overwrite 'Documents/file1.txt'?

Type y to confirm or n to cancel.

7.2 Force Option (-f)

mv -f file1.txt Documents/

Attempts to overwrite an existing destination without asking for confirmation.

Warning: Use -f carefully. An existing destination file may be replaced without an interactive confirmation.

7.3 Verbose Option (-v)

mv -v file1.txt Documents/
Example output:
renamed 'file1.txt' -> 'Documents/file1.txt'

The -v option displays the operation performed by the command.

7.4 No Overwrite Option (-n)

mv -n file1.txt Documents/

If a file with the same name already exists in the destination, the existing destination is not overwritten.

7.5 Update Option (-u)

mv -u file1.txt Documents/

Moves the source when the destination is missing or when the source is newer than the destination.

7.6 Backup Option (-b)

mv -b file1.txt Documents/

If an existing destination would be overwritten, a backup of that destination is created before replacement.

7.7 Target Directory Option (-t)

mv -t Documents/ file1.txt file2.txt

The -t option specifies the destination directory before listing the source files.

8. Moving Files with Spaces in Their Names

If a filename contains spaces, enclose the filename in quotation marks or escape the spaces using a backslash.

Method 1: Double Quotes

mv "my report.txt" Documents/

Method 2: Single Quotes

mv 'my report.txt' Documents/

Method 3: Backslash

mv my\ report.txt Documents/
Tip: Quotation marks are generally easier to read when working with filenames containing spaces.

9. Using Relative and Absolute Paths

Relative Path

mv file1.txt ../Documents/

The destination is specified relative to the current working directory.

Absolute Path

mv file1.txt /home/user/Documents/

The destination is specified using its complete path from the root directory.

Path Type Example Meaning
Relative Documents/ Path relative to the current directory.
Relative ../Documents/ Documents directory in the parent directory.
Absolute /home/user/Documents/ Complete path starting from root.

10. Difference Between cp and mv

Feature cp Command mv Command
Purpose Copies files and directories. Moves or renames files and directories.
Original file Normally remains at its original location. Normally no longer remains at its original pathname.
Creates a copy Yes. No separate copy is intended.
Rename files Can create a copy under another name. Directly renames the original pathname.
Directory operation Requires -r or -R for recursive copying. Can move directories without -r.

Example: cp

cp file1.txt Documents/

The original file remains in the current directory.

Example: mv

mv file1.txt Documents/

The file is moved to the Documents directory.

Important: When a move occurs within the same filesystem, Linux can often change directory entries without copying the file data. Moving across filesystems may require copying the data and removing the original.

11. Practical Examples

Example 1: Create a File and Rename It

touch first.txt mv first.txt second.txt ls

Expected result:

second.txt

Example 2: Create a Directory and Move a File

touch report.txt mkdir Documents mv report.txt Documents/ ls Documents/

Expected result:

report.txt

Example 3: Move Multiple Files

touch file1.txt file2.txt file3.txt mkdir Backup mv file1.txt file2.txt file3.txt Backup/ ls Backup/

Expected result:

file1.txt file2.txt file3.txt

Example 4: Rename a Directory

mkdir OldFolder mv OldFolder NewFolder ls

Expected result:

NewFolder

Example 5: Move All Text Files

mkdir TextFiles touch a.txt b.txt c.txt mv *.txt TextFiles/ ls TextFiles/

Expected result:

a.txt b.txt c.txt

12. Common Errors and Troubleshooting

Error 1: Source File Does Not Exist

mv missing.txt Documents/
mv: cannot stat 'missing.txt': No such file or directory

Solution: Check the filename and current directory using ls and pwd.

Error 2: Destination Directory Does Not Exist

mv file1.txt UnknownFolder/
mv: cannot move 'file1.txt' to 'UnknownFolder/': No such file or directory

Solution: Create the destination directory first using mkdir, or provide the correct path.

Error 3: Permission Denied

mv file1.txt /root/
mv: cannot move 'file1.txt' to '/root/file1.txt': Permission denied

Solution: Check directory permissions and ensure that you have the required access rights. Use elevated privileges only when appropriate.

Error 4: Destination Is a Directory

mv file1.txt Documents

If Documents is an existing directory, the file is moved inside it. If it is not a directory, it may be treated as the new filename.

Use a trailing slash, such as Documents/, when you specifically intend to move a file into an existing directory.

Error 5: Destination Already Exists

If the destination filename already exists, the default behaviour may overwrite it, depending on permissions and command settings.

Solution: Use -i to request confirmation or -n to avoid overwriting.

14. Interview Questions

It is used to move files and directories or rename them.

mv [OPTION] SOURCE DESTINATION

Q3. How do you rename a file in Linux?

mv old.txt new.txt

Q4. How do you move a file into a directory?

mv file.txt Documents/

It prompts the user before overwriting an existing destination.

It displays details of the operation performed.

cp copies data while mv moves or renames the original pathname.

15. Multiple Choice Questions (MCQs)

Q1. Which command is used to rename a file?

  1. cp
  2. mv
  3. mkdir
  4. pwd

Answer: B. mv

Q2. Which option prompts before overwriting?

  1. -v
  2. -f
  3. -i
  4. -u

Answer: C. -i

Q3. Which option displays the operation performed?

  1. -v
  2. -i
  3. -n
  4. -b

Answer: A. -v

Q4. Which command moves file.txt into Documents?

  1. mv Documents/ file.txt
  2. mv file.txt Documents/
  3. cp file.txt
  4. mkdir file.txt

Answer: B. mv file.txt Documents/

Q5. Which command moves all .txt files into Backup?

  1. mv *.txt Backup/
  2. mv Backup/ *.txt
  3. cp Backup/
  4. rm *.txt

Answer: A. mv *.txt Backup/

Q6. Which option prevents overwriting an existing destination?

  1. -f
  2. -n
  3. -v
  4. -b

Answer: B. -n

Q7. Is the -r option required to move a directory using mv?

  1. Yes, always
  2. No
  3. Only for empty directories
  4. Only for hidden directories

Answer: B. No

Q8. Which command renames a directory?

  1. mv Old New
  2. cp Old New
  3. touch Old New
  4. pwd Old New

Answer: A. mv Old New

16. Lesson Summary

  • mv is used to move and rename files and directories.
  • mv old.txt new.txt renames a file.
  • mv file.txt Documents/ moves a file into a directory.
  • mv *.txt Documents/ moves matching text files.
  • mv -i asks before overwriting.
  • mv -f forces an overwrite without prompting.
  • mv -v displays operation details.
  • mv -n prevents overwriting an existing destination.
  • mv -u performs an update-based move.
  • mv -t specifies the target directory.
Key Concept: The mv command changes the location or name of a filesystem entry. It is essential for Linux file and directory management.
