ls Command

Learn how to list files, directories, hidden entries, and detailed file information.

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose and syntax of the ls command.
  • List files and directories in the current location.
  • Display hidden files and directories.
  • View detailed file information using long listing format.
  • Sort directory contents by name, size, and modification time.
  • Display file sizes in human-readable format.
  • List contents of specific directories and multiple paths.
  • Understand common ls options and their practical uses.

1. Introduction to the ls Command

The ls command stands for List. It is used to display the names of files and directories in the Linux filesystem.

It is one of the most frequently used Linux commands because it helps users inspect directory contents and identify available files and folders.

Basic Command

ls
Example Output:
Desktop Documents Downloads Music Pictures Public Videos

The output shows the entries present in the current working directory. Your output may be different.

Common Uses

  • List files and directories.
  • Identify hidden files.
  • Display file permissions and ownership.
  • Check file sizes and modification times.
  • Inspect directory contents before performing operations.

2. Syntax of the ls Command

The general syntax is:

ls [OPTIONS] [FILE_OR_DIRECTORY]
Component Description
ls Command name.
OPTIONS Modify the listing format or behavior.
FILE_OR_DIRECTORY Specifies the file or directory to inspect.

Examples

ls ls -l ls -a ls /home

If no path is supplied, ls lists the contents of the current working directory.

3. Basic Usage of ls

3.1 List Current Directory

ls

Displays the names of visible files and directories in the current working directory.

3.2 List a Specific Directory

ls /home

Displays the contents of the /home directory.

3.3 List the Home Directory

ls ~

The tilde (~) represents the current user's home directory.

3.4 List Multiple Directories

ls /home /etc

Displays the contents of both directories separately.

3.5 List a Specific File

ls Documents/report.txt

Displays information about the specified file if it exists.

4. Display Hidden Files and Directories

Linux uses a leading dot (.) in a filename to identify hidden entries. These entries are not shown by a normal ls command.

Use the -a Option

ls -a

Displays all entries, including hidden files and directories. It also includes the special entries . and ...

Example Output:
. .. .bashrc .profile Desktop Documents Downloads

Use the -A Option

ls -A

Displays hidden entries but omits the special entries . and ...

Option Purpose
-a Displays all entries, including . and ...
-A Displays hidden entries except . and ...
Important: Hidden files are not necessarily protected or encrypted. They are simply omitted from normal directory listings.

5. Long Listing Format: ls -l

The -l option displays directory contents in long listing format. It provides detailed information about each entry.

ls -l

Example Output

total 12 drwxr-xr-x 2 user user 4096 Nov 4 10:30 Documents -rw-r--r-- 1 user user 120 Nov 4 09:45 report.txt drwxr-xr-x 2 user user 4096 Nov 3 16:20 Projects

Understanding the Output

Field Example Meaning
File type and permissions -rw-r--r-- Identifies the entry type and access permissions.
Link count 1 Number of hard links for a regular file.
Owner user Owner of the entry.
Group user Group associated with the entry.
Size 120 Size in bytes for a regular file.
Modification time Nov 4 09:45 Last modification timestamp shown by ls.
Name report.txt Name of the entry.
Important: A directory's size shown by ls -l is the size of its directory entry structure, not the total size of all files and subdirectories contained inside it.

6. Display Human-Readable File Sizes

By default, the long listing format generally displays regular file sizes in bytes.

The -h option displays sizes in a more readable form, such as K, M, or G.

ls -lh

Example Output

-rw-r--r-- 1 user user 1.2K Nov 4 10:00 notes.txt -rw-r--r-- 1 user user 5.4M Nov 4 10:10 video.mp4 -rw-r--r-- 1 user user 2.1G Nov 4 10:20 backup.img
Unit Meaning
K Kilobyte-scale size.
M Megabyte-scale size.
G Gigabyte-scale size.
Tip: Use ls -lh when checking the approximate sizes of files in a directory.

7. List Directories Recursively

The -R option displays the contents of directories and their subdirectories recursively.

ls -R

This lists the current directory and continues into its subdirectories.

Example

ls -R Projects
Example Output:
Projects: C Linux Projects/C: program1.c Projects/Linux: notes.txt

The output shows the contents of Projects and its nested directories.

Warning: Recursive listing can produce very large output when used on directories containing many nested files.

8. Sort Directory Contents

The ls command supports several options for changing the order in which entries are displayed.

8.1 Sort by Name

ls

By default, ls sorts entries alphabetically by name according to the current locale.

8.2 Sort by Modification Time

ls -t

Displays entries with the most recently modified entries first.

8.3 Reverse the Sorting Order

ls -r

Reverses the default sorting order.

8.4 Sort by File Size

ls -S

Sorts entries by size, with larger files first.

8.5 Sort by Extension

ls -X

Sorts entries alphabetically by extension.

Option Sorting Behavior
-t Modification time, newest first.
-r Reverse the selected sorting order.
-S File size, largest first.
-X File extension.

Combine Sorting Options

ls -ltr ls -lhS
  • ls -ltr displays detailed entries sorted by modification time in reverse order.
  • ls -lhS displays detailed information with human-readable sizes, sorted by size.

9. Display File Types and Indicators

Linux represents different filesystem objects using different file types. The ls command can help identify these types.

9.1 Classify Entries Using -F

ls -F

Adds indicators to filenames to show common file types.

Indicator Meaning
/ Directory.
* Executable file.
@ Symbolic link.
| Named pipe (FIFO).
= Socket.

9.2 Classify Entries Using -p

ls -p

Adds a slash (/) to directory names.

9.3 Display File Type Information

ls -l

The first character in the long listing indicates the file type.

Character File Type
- Regular file.
d Directory.
l Symbolic link.
c Character device.
b Block device.
p Named pipe.
s Socket.
Embedded Linux Connection: Device files such as character and block devices are important in Linux systems programming. They provide interfaces through which user-space programs can interact with device drivers.

10. Display Inode Numbers

An inode is a filesystem data structure that stores metadata about a file or directory.

The -i option displays the inode number associated with each listed entry.

ls -i
Example Output:
123456 Documents 123457 report.txt 123458 Projects

The numbers shown are illustrative. Actual inode numbers depend on the filesystem.

Combine Inode and Long Listing

ls -li

Displays inode numbers along with detailed file information.

Systems Programming Connection: Inodes are fundamental to Unix-like filesystem design. They store metadata such as file permissions, ownership, timestamps, and data block references.

11. Display Directory Contents Only

The -d option displays a directory entry itself rather than listing its contents.

ls -d /home
Output:
/home

Long Listing of a Directory Itself

ls -ld /home

Displays detailed information about the /home directory rather than listing the entries inside it.

Difference: ls /home lists the contents of /home, whereas ls -d /home lists the directory entry itself.

12. Display Quoting and Color Options

12.1 Colorized Output

ls --color=auto

Displays entries using colors when the output environment supports it.

Color settings may help distinguish directories, symbolic links, executables, and other file types.

12.2 Quote Filenames

ls -Q

Encloses filenames in double quotation marks in the output.

12.3 Display Long Names Without Truncation

ls -1

Displays one entry per line. This is useful when reading or processing directory listings.

13. Important ls Options Reference

Option Description
-l Long listing format.
-a Show all entries, including . and ...
-A Show hidden entries except . and ...
-h Human-readable sizes when used with size output.
-R List subdirectories recursively.
-t Sort by modification time.
-r Reverse sorting order.
-S Sort by file size.
-X Sort by extension.
-i Display inode numbers.
-d List directory entries themselves.
-F Append file-type indicators.
-p Append / to directory names.
-1 Display one entry per line.
-Q Enclose filenames in double quotes.

14. Common Mistakes and Troubleshooting

Mistake 1: Incorrect Command Name

LS

Linux command names are case-sensitive. Use lowercase ls.

Mistake 2: Incorrect Path

ls /home/unknown

If the specified directory does not exist, the command reports an error.

Mistake 3: Permission Denied

Some directories cannot be accessed by ordinary users. The command may display a permission error.

Mistake 4: Confusing -d with Normal Listing

ls -d Documents ls Documents

The first command displays the directory entry itself. The second displays its contents.

Mistake 5: Expecting -h to Change Every Listing

The human-readable option is most useful with long listing output, for example ls -lh.

Useful Help Commands:
ls --help man ls
Press q to exit the manual page.

16. Important Interview Questions

Q1. What is the full form of ls?

ls stands for List. It displays files and directories.

Q2. What is the basic syntax of ls?

ls [OPTIONS] [FILE_OR_DIRECTORY].

Q3. Which option displays hidden files?

The -a option displays all entries, including hidden files and directories.

Q4. What is the difference between -a and -A?

-a includes . and .., whereas -A omits these two special entries.

Q5. What is the purpose of ls -l?

It displays detailed file information, including permissions, ownership, size, and modification time.

Q6. What is the purpose of ls -lh?

It displays long listing information with human-readable file sizes.

Q7. What does ls -R do?

It recursively lists the contents of directories and their subdirectories.

Q8. What is an inode number?

An inode number identifies an inode within a filesystem. The inode stores file metadata.

Q9. What is the difference between ls /home and ls -d /home?

The first lists the contents of /home. The second lists the /home directory entry itself.

Q10. How can you sort files by size?

Use ls -S to sort entries by size, with larger entries first.
