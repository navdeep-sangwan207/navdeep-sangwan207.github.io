touch Command in Linux

Create Empty Files and Update File Timestamps

Home Linux Course Chapter 3

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of the touch command.
  • Create empty files using touch.
  • Create multiple files in a single command.
  • Understand file access and modification timestamps.
  • Update timestamps using different options.
  • Use touch in practical Linux tasks and shell scripts.

1. Introduction to the touch Command

The touch command is used to create empty files and update file timestamps in Linux.

If the specified file does not exist, touch creates an empty file. If the file already exists, touch normally updates its access time and modification time.

Important: The touch command does not normally change the contents of an existing file. It updates its timestamps.

Example

touch notes.txt ls -l notes.txt

The first command creates notes.txt if it does not already exist. The second command displays its file information.

-rw-r--r-- 1 user user 0 Nov 4 10:30 notes.txt

This is an illustrative output. The owner, permissions, and timestamp depend on your system.

2. Syntax of the touch Command

touch [OPTIONS] FILE_NAME
Component Description
touch Command used to create files or update timestamps.
OPTIONS Optional settings that control timestamp operations.
FILE_NAME Name or path of the target file.

3. Creating Files Using touch

3.1 Create a Single Empty File

touch file.txt

Creates an empty file named file.txt in the current working directory if it does not exist.

3.2 Create Multiple Files

touch file1.txt file2.txt file3.txt

Creates three empty files in one command.

3.3 Create a File in a Specific Directory

touch Documents/notes.txt

Creates notes.txt inside Documents if that directory exists and you have permission to write there.

3.4 Create a File Using an Absolute Path

touch /tmp/test.txt

Creates test.txt inside the /tmp directory.

3.5 Create Files with Different Extensions

touch program.c program.cpp script.sh notes.txt

Creates four files with different extensions. The touch command does not determine the programming language or file type from the extension.

Note: A file extension is part of the filename. Linux does not require extensions, although they are commonly used for organization.

4. Understanding File Timestamps

Linux filesystems maintain different timestamps that describe file-related events.

Timestamp Meaning
atime Last access time: when file contents were last accessed.
mtime Last modification time: when file contents were last modified.
ctime Last status-change time: when file metadata or contents changed.
Important distinction: ctime is not the file creation time. It represents the last metadata/status change time.

View Timestamps

stat file.txt

The stat command displays detailed information, including the file's access, modification, and change timestamps.

5. Important touch Options

Option Description Example
-a Change only the access time. touch -a file.txt
-m Change only the modification time. touch -m file.txt
-c Do not create a file if it does not exist. touch -c missing.txt
-t Set timestamps using a specified date and time. touch -t 202601011200 file.txt
-r Use timestamps from another reference file. touch -r source.txt target.txt
-d Specify a date and time in a readable format (GNU touch). touch -d "2026-01-01 12:00" file.txt
-h Change a symbolic link's timestamp rather than its target where supported. touch -h link

5.1 -a Option: Change Access Time

touch -a file.txt stat file.txt

Updates the access timestamp without intentionally updating the modification timestamp.

5.2 -m Option: Change Modification Time

touch -m file.txt stat file.txt

Updates the modification timestamp without intentionally updating the access timestamp.

5.3 -c Option: Do Not Create a New File

touch -c missing.txt ls missing.txt

If missing.txt does not exist, touch -c does not create it.

Note: The second command may report that the file does not exist. This is expected when the file was absent before the touch command.

5.4 -t Option: Set a Specific Timestamp

touch -t 202601011200 file.txt

Sets the access and modification timestamps to 12:00 on January 1, 2026, using the local time interpretation of the command.

The common timestamp format is:

[[CC]YY]MMDDhhmm[.ss]
Part Meaning
CC Century
YY Year
MM Month
DD Day
hh Hour
mm Minute
ss Second

5.5 -r Option: Copy Timestamps from Another File

touch -r source.txt target.txt

Sets the access and modification timestamps of target.txt to match those of source.txt.

5.6 -d Option: Specify a Readable Date

touch -d "2026-01-01 12:00" file.txt

Sets the access and modification timestamps using the specified date and time.

The -d option is available in GNU touch, commonly used on Ubuntu. Other Unix-like systems may use different syntax.

6. Difference Between Creating and Updating Files

Situation Behaviour of touch
File does not exist Creates an empty file.
File already exists Updates its access and modification timestamps by default.
Using -c on a missing file Does not create the file.
Using -m Updates the modification timestamp.
Using -a Updates the access timestamp.

7. Difference Between touch and mkdir

touch mkdir
Creates files when they do not exist. Creates directories.
Can update file timestamps. Does not serve as a timestamp update command.
Example: touch notes.txt Example: mkdir Projects

8. Common Errors and Troubleshooting

8.1 No Such File or Directory

touch Projects/notes.txt
touch: cannot touch 'Projects/notes.txt': No such file or directory

Cause: The Projects directory does not exist.

Solution: Create the directory first:

mkdir -p Projects touch Projects/notes.txt

8.2 Permission Denied

touch /root/test.txt
touch: cannot touch '/root/test.txt': Permission denied

Cause: The current user does not have permission to create files in the target location.

Solution: Use a directory where you have write permission.

8.3 Read-Only Filesystem

A read-only filesystem does not allow ordinary file creation or timestamp updates.

Solution: Check the filesystem mount status and use an appropriate writable location.

9. Practical Lab Exercises

Lab 1: Create an Empty Text File

Objective: Create a file named notes.txt.

touch notes.txt ls -l notes.txt

Expected Result: notes.txt is created with an initial size of zero bytes.

Lab 2: Create Multiple Files

Objective: Create files for different programming languages.

touch main.c main.cpp program.sh notes.txt ls

Expected Result: Four files appear in the current directory.

Lab 3: Create a File Inside a Directory

Objective: Create a source file inside a project directory.

mkdir -p Embedded/Source touch Embedded/Source/main.c ls Embedded/Source

Expected Result: main.c appears inside Embedded/Source.

Lab 4: Update Modification Time

Objective: Update the modification timestamp of a file.

touch -m notes.txt stat notes.txt

Expected Result: The modification timestamp is updated.

Lab 5: Update Access Time

Objective: Update the access timestamp.

touch -a notes.txt stat notes.txt

Expected Result: The access timestamp is updated.

Lab 6: Prevent File Creation

Objective: Use the -c option with a missing file.

touch -c absent.txt ls absent.txt

Expected Result: absent.txt is not created. The ls command reports that it cannot find the file.

Lab 7: Set a Specific Timestamp

Objective: Set a specific date and time.

touch -t 202601011200 notes.txt stat notes.txt

Expected Result: The access and modification timestamps show the specified time, subject to filesystem timestamp precision.

Lab 8: Copy Timestamps Between Files

Objective: Match the timestamps of two files.

touch source.txt touch target.txt touch -r source.txt target.txt stat source.txt target.txt

Expected Result: The access and modification timestamps of target.txt match those of source.txt.

10. Interview Questions and Answers

Q1. What is the purpose of the touch command?

Answer: It creates empty files and updates file timestamps.

Q2. Does touch delete existing file contents?

Answer: No. It normally updates timestamps without changing file contents.

Q3. What happens if a file does not exist?

Answer: touch creates an empty file, provided the parent directory exists and permissions allow it.

Q4. What is the purpose of touch -c?

Answer: It prevents touch from creating a new file if the specified file does not exist.

Q5. What does the -m option do?

Answer: It updates the file's modification timestamp.

Q6. What does the -a option do?

Answer: It updates the file's access timestamp.

Q7. What is the difference between mtime and ctime?

Answer: mtime represents the last content modification time, while ctime represents the last metadata/status change time.

Q8. Which command displays detailed file timestamps?

Answer: The stat command.

Q9. What does touch -r do?

Answer: It uses the timestamps of a reference file for the target file.

Q10. Can touch create multiple files at once?

Answer: Yes. Multiple filenames can be supplied in one command.

  • touch creates empty files when they do not exist.
