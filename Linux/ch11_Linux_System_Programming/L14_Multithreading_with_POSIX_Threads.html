Multithreading with POSIX Threads

Learn how to create, manage and synchronize multiple threads in Linux using the POSIX Threads API.

1. Introduction to Multithreading

A thread is the smallest unit of execution that can be scheduled independently within a process.

A process can contain one or multiple threads. Multiple threads within the same process share resources such as process memory and open file descriptors, while each thread has its own execution context and stack.

Definition: Multithreading is the technique of executing multiple threads within a single process.

Example

Consider a monitoring application:

  • Thread 1 reads sensor data.
  • Thread 2 processes the sensor data.
  • Thread 3 updates the user interface.
  • Thread 4 records data in a log file.

These threads belong to the same process and can perform different tasks concurrently.

2. Process vs Thread

Process Thread
An independent program in execution. An execution unit within a process.
Has its own virtual address space. Shares the process address space with other threads.
Has process-level resources. Shares many process resources.
Communication often requires IPC. Can communicate through shared process memory.
Creation generally has greater overhead. Thread creation is generally less expensive.
Process isolation provides stronger separation. A faulty thread can affect the entire process.

4. Introduction to POSIX Threads (Pthreads)

POSIX Threads, commonly called Pthreads, provide a standard API for creating and managing threads in POSIX-compliant operating systems.

Header File

#include <pthread.h>

Important Pthread Functions

Function Purpose
pthread_create() Creates a new thread.
pthread_join() Waits for a joinable thread to finish.
pthread_exit() Terminates the calling thread.
pthread_self() Returns the calling thread ID.
pthread_equal() Compares two thread IDs.
pthread_detach() Marks a thread as detached.
pthread_cancel() Requests cancellation of a thread.
pthread_mutex_init() Initializes a mutex.
pthread_mutex_lock() Locks a mutex.
pthread_mutex_unlock() Unlocks a mutex.

5. pthread_create() Function

pthread_create() creates a new thread that starts execution from a specified function.

Syntax

int pthread_create(
    pthread_t *thread,
    const pthread_attr_t *attr,
    void *(*start_routine)(void *),
    void *arg
);

Parameters

  • thread: Stores the created thread ID.
  • attr: Thread attributes; NULL selects defaults.
  • start_routine: Function executed by the new thread.
  • arg: Argument passed to the thread function.

Return Value

Returns 0 on success. On failure, it returns an error number directly rather than setting errno as a typical system call does.

6. First Multithreading Program

This program creates one new thread. Both the main thread and the new thread execute their own statements.

Program: first_thread.c

#include <stdio.h>
#include <pthread.h>

void *thread_function(void *arg)
{
    printf("Hello from the new thread\n");

    return NULL;
}

int main(void)
{
    pthread_t thread;

    if (pthread_create(&thread, NULL,
                       thread_function, NULL) != 0)
    {
        printf("Thread creation failed\n");
        return 1;
    }

    printf("Hello from the main thread\n");

    pthread_join(thread, NULL);

    printf("Thread execution completed\n");

    return 0;
}

Compile

gcc first_thread.c -o first_thread -pthread

Execute

./first_thread

Possible Output

Hello from the main thread
Hello from the new thread
Thread execution completed

The order of the first two messages is not guaranteed. The scheduler determines which thread runs first.

Important: pthread_join() ensures that the main thread waits for the created thread before continuing.

7. Creating Multiple Threads

A process can create multiple threads to perform different or repeated tasks.

Program: multiple_threads.c

#include <stdio.h>
#include <pthread.h>

void *worker(void *arg)
{
    int id = *(int *)arg;

    printf("Thread %d is running\n", id);

    return NULL;
}

int main(void)
{
    pthread_t threads[3];
    int ids[3];

    for (int i = 0; i < 3; i++)
    {
        ids[i] = i + 1;

        if (pthread_create(&threads[i], NULL,
                           worker, &ids[i]) != 0)
        {
            printf("Thread creation failed\n");
            return 1;
        }
    }

    for (int i = 0; i < 3; i++)
    {
        pthread_join(threads[i], NULL);
    }

    printf("All threads completed\n");

    return 0;
}

Compile

gcc multiple_threads.c -o multiple_threads -pthread

Possible Output

Thread 1 is running
Thread 3 is running
Thread 2 is running
All threads completed

The order of thread messages can vary because threads execute concurrently.

8. pthread_join() Function

pthread_join() waits for a specified joinable thread to terminate.

Syntax

int pthread_join(pthread_t thread, void **retval);

Parameters

  • thread: Thread to wait for.
  • retval: Receives the thread's return value; NULL if not needed.

Example

#include <stdio.h>
#include <pthread.h>

void *worker(void *arg)
{
    printf("Worker thread executing\n");

    return NULL;
}

int main(void)
{
    pthread_t t;

    pthread_create(&t, NULL, worker, NULL);

    pthread_join(t, NULL);

    printf("Main thread continues\n");

    return 0;
}

The main thread continues after the worker thread terminates.

9. pthread_exit() Function

pthread_exit() terminates the calling thread and optionally provides a return value.

Syntax

void pthread_exit(void *retval);

Example

#include <stdio.h>
#include <pthread.h>

void *worker(void *arg)
{
    printf("Worker thread executing\n");

    pthread_exit(NULL);
}

int main(void)
{
    pthread_t t;

    pthread_create(&t, NULL, worker, NULL);

    pthread_join(t, NULL);

    printf("Worker thread terminated\n");

    return 0;
}
Returning from a thread's start routine has the same thread-termination effect as calling pthread_exit() with that return value.

10. pthread_self() Function

pthread_self() returns the identifier of the calling thread.

Syntax

pthread_t pthread_self(void);

Example

#include <stdio.h>
#include <pthread.h>

void *worker(void *arg)
{
    printf("Worker thread ID: %lu\n",
           (unsigned long)pthread_self());

    return NULL;
}

int main(void)
{
    pthread_t t;

    printf("Main thread ID: %lu\n",
           (unsigned long)pthread_self());

    pthread_create(&t, NULL, worker, NULL);

    pthread_join(t, NULL);

    return 0;
}

pthread_t is an implementation-defined type. The conversion shown is suitable for common Linux implementations; portable programs should not assume pthread_t is always an unsigned long.

11. Detached Threads

A detached thread releases its thread-related resources automatically when it terminates. Another thread cannot collect its termination status using pthread_join().

Detach a Thread

int pthread_detach(pthread_t thread);

Example

#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

void *worker(void *arg)
{
    printf("Detached thread started\n");

    sleep(2);

    printf("Detached thread finished\n");

    return NULL;
}

int main(void)
{
    pthread_t t;

    if (pthread_create(&t, NULL, worker, NULL) != 0)
    {
        printf("Thread creation failed\n");
        return 1;
    }

    pthread_detach(t);

    printf("Main thread waiting briefly\n");

    sleep(3);

    return 0;
}

The main thread remains alive long enough for the detached worker to finish.

12. Race Conditions

A race condition occurs when multiple threads access shared data concurrently and the result depends on their execution timing.

Example: Shared Counter

#include <stdio.h>
#include <pthread.h>

int counter = 0;

void *increment(void *arg)
{
    for (int i = 0; i < 100000; i++)
    {
        counter++;
    }

    return NULL;
}

int main(void)
{
    pthread_t t1, t2;

    pthread_create(&t1, NULL, increment, NULL);
    pthread_create(&t2, NULL, increment, NULL);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("Counter = %d\n", counter);

    return 0;
}

The expected mathematical result is 200000. However, concurrent unsynchronized updates to counter create a data race in C. The behaviour is undefined, so the actual result cannot be relied upon.

13. Mutex (Mutual Exclusion)

A mutex is a synchronization object used to protect shared resources from simultaneous access by multiple threads.

Definition: A mutex allows only one thread at a time to hold the lock and execute a protected critical section.

Mutex Operations

  • Initialize the mutex.
  • Lock the mutex before accessing shared data.
  • Perform the critical section.
  • Unlock the mutex after completing the operation.
  • Destroy the mutex when no longer needed.

Important Functions

Function Purpose
pthread_mutex_init() Initializes a mutex.
pthread_mutex_lock() Locks a mutex.
pthread_mutex_trylock() Attempts to lock without blocking.
pthread_mutex_unlock() Unlocks a mutex.
pthread_mutex_destroy() Destroys a mutex.

14. Practical Program: Mutex-Protected Counter

This program uses a mutex to protect a shared counter from concurrent modification.

Program: mutex_counter.c

#include <stdio.h>
#include <pthread.h>

int counter = 0;

pthread_mutex_t lock;

void *increment(void *arg)
{
    for (int i = 0; i < 100000; i++)
    {
        pthread_mutex_lock(&lock);

        counter++;

        pthread_mutex_unlock(&lock);
    }

    return NULL;
}

int main(void)
{
    pthread_t t1, t2;

    if (pthread_mutex_init(&lock, NULL) != 0)
    {
        printf("Mutex initialization failed\n");
        return 1;
    }

    if (pthread_create(&t1, NULL, increment, NULL) != 0)
    {
        printf("Thread 1 creation failed\n");
        pthread_mutex_destroy(&lock);
        return 1;
    }

    if (pthread_create(&t2, NULL, increment, NULL) != 0)
    {
        printf("Thread 2 creation failed\n");
        pthread_join(t1, NULL);
        pthread_mutex_destroy(&lock);
        return 1;
    }

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("Final counter = %d\n", counter);

    pthread_mutex_destroy(&lock);

    return 0;
}

Compile

gcc mutex_counter.c -o mutex_counter -pthread

Execute

./mutex_counter

Expected Output

Final counter = 200000

The mutex ensures that only one thread updates counter at a time.

15. Deadlock in Multithreading

A deadlock occurs when two or more threads wait indefinitely for resources held by one another.

Example Situation

Thread 1                    Thread 2
   |                           |
   v                           v
Locks Mutex A              Locks Mutex B
   |                           |
   v                           v
Waits for Mutex B           Waits for Mutex A
   |                           |
   +-----------+---------------+
               |
               v
            DEADLOCK

Ways to Prevent Deadlocks

  • Acquire multiple locks in a consistent order.
  • Avoid holding locks longer than necessary.
  • Use trylock where appropriate.
  • Design clear ownership rules for shared resources.
  • Avoid unnecessary nested locking.

16. Mutex vs Semaphore

Mutex Semaphore
Primarily protects a critical section. Coordinates access or execution using a counter.
Has ownership semantics. Does not generally have mutex-style ownership.
Typically locked and unlocked by the owning thread. One thread can wait while another posts.
Useful for mutual exclusion. Useful for signaling and resource counting.

17. Thread Attributes

Thread attributes configure properties of a thread when it is created.

Important Functions

Function Purpose
pthread_attr_init() Initializes a thread attribute object.
pthread_attr_destroy() Destroys the attribute object.
pthread_attr_setdetachstate() Sets detached or joinable state.
pthread_attr_setstacksize() Sets the thread stack size.
pthread_attr_setschedpolicy() Sets the scheduling policy where permitted.

Scheduling and priority settings may require special permissions and platform-specific support.

18. Thread Cancellation

pthread_cancel() requests cancellation of a specified thread. Cancellation may be deferred until the target reaches a cancellation point.

Syntax

int pthread_cancel(pthread_t thread);

Cancellation is a request, not necessarily an immediate termination. Threads normally use deferred cancellation, and cleanup handlers can release resources when cancellation occurs.

Avoid asynchronous cancellation in ordinary application code. It can terminate a thread while it holds a mutex or is modifying shared state.

19. Thread Scheduling

Linux schedules runnable threads for CPU execution. Depending on available CPU cores, threads may run concurrently or take turns executing.

Common POSIX Scheduling Policies

Policy Description
SCHED_OTHER Normal time-sharing scheduling policy.
SCHED_FIFO Real-time first-in, first-out scheduling.
SCHED_RR Real-time round-robin scheduling.

Real-time scheduling policies may require additional privileges and careful priority design.

20. Multithreading in Embedded Linux

Multithreading is widely used in embedded Linux systems to separate tasks and improve responsiveness.

Example: Embedded Monitoring Application

  • Sensor thread: collects sensor measurements.
  • Processing thread: filters and processes measurements.
  • Communication thread: sends data over UART, TCP or another interface.
  • Logging thread: stores measurement history.
  • Control thread: performs control decisions.
Shared data must be protected using appropriate synchronization mechanisms such as mutexes, semaphores, condition variables or atomic operations.

23. Interview Questions and Answers

Q1. What is a thread?

A thread is an execution unit within a process.

Q2. What is multithreading?

Multithreading is the execution of multiple threads within one process.

Q3. What is Pthread?

Pthreads is the POSIX standard API for thread creation and management.

Q4. Which function creates a thread?

pthread_create().

Q5. What is pthread_join()?

It waits for a joinable thread to terminate and can collect its return value.

Q6. What is pthread_exit()?

It terminates the calling thread.

Q7. What is a race condition?

A race condition occurs when concurrent access to shared data makes program behaviour depend on execution timing.

Q8. What is a mutex?

A mutex is a mutual-exclusion synchronization object used to protect shared resources.

Q9. What is a detached thread?

A detached thread releases its resources automatically when it terminates and cannot be joined.

Q10. What is deadlock?

Deadlock is a condition where threads wait indefinitely for resources held by one another.

Q11. Do threads share memory?

Threads in the same process share the process address space, including global variables and heap memory, but have separate stacks and execution state.

Q12. How do you compile a Pthread program?

Use gcc with the -pthread option.

Q13. What is the difference between a process and a thread?

A process has its own virtual address space, whereas threads share the address space and many resources of their process.

Q14. Why is synchronization needed?

Synchronization prevents unsafe concurrent access and coordinates operations on shared resources.
