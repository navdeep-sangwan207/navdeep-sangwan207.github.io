Chapter 11: Linux System Programming

System Calls, Process Management, File I/O, IPC and Multithreading

Chapter Overview

Linux System Programming focuses on developing applications that interact directly with the Linux operating system through system calls and system-level interfaces.

In this chapter, you will learn about system calls, process creation and termination, the fork() and exec() families, file input/output operations, interprocess communication, pipes, shared memory, message queues, signals, semaphores and POSIX threads.

These concepts are important for Linux application development, Embedded Linux, systems software engineering and operating system-level programming.
