2. Introduction to Linux

Linux is a family of open-source, Unix-like operating systems built around the Linux kernel. It is used in desktop computers, servers, supercomputers, embedded systems, networking equipment and Internet of Things (IoT) devices.

Linux provides an environment in which users and applications can run programs, manage files, communicate with hardware and perform computing operations.

Important: Technically, Linux is the kernel. A complete Linux operating system distribution combines the kernel with system utilities, libraries, applications and other software.

3. What Is an Operating System?

An Operating System (OS) is system software that manages computer hardware and provides common services to application programs. It acts as an intermediary between applications, users and hardware.

3.1 Main Functions of an Operating System

  • Process management: Creates, schedules and terminates processes.
  • Memory management: Allocates and manages main memory.
  • File management: Organizes files, directories and storage access.
  • Device management: Coordinates hardware through device drivers.
  • Security and protection: Controls access to users and system resources.
  • User interface: Provides command-line and/or graphical interaction.

4. What Is Linux?

The Linux kernel was originally created by Linus Torvalds in 1991. It provides core operating-system functionality, including process scheduling, memory management, device-driver interfaces and system-call handling.

4.1 Important Characteristics

  • Open-source development under the applicable project licenses.
  • Multiuser and multitasking capabilities.
  • Support for a wide range of processor architectures.
  • Strong networking capabilities.
  • Command-line and graphical user environments.
  • Flexible configuration and customization.

5. Basic Components of a Linux System

5.1 Linux Kernel

The kernel is the core of the operating system. It manages CPU scheduling, memory, processes, device drivers and access to hardware resources.

5.2 System Libraries

System libraries provide reusable functions that applications can use to access operating-system services. For example, the GNU C Library (glibc) provides many standard C library and system-call interface functions on common GNU/Linux systems.

5.3 System Utilities

Utilities are programs used for tasks such as file management, user administration, process inspection and system configuration.

5.4 Shell

A shell is a command interpreter that reads commands and arranges for them to be executed. Bash is a widely used shell on Linux systems.

5.5 Application Software

Applications perform user-oriented tasks such as programming, document editing, browsing and media playback.

5.6 Simplified Linux System Structure

+--------------------------------------+ | User Applications | +--------------------------------------+ | Shell and System Utilities | +--------------------------------------+ | System Libraries | +--------------------------------------+ | Linux Kernel | +--------------------------------------+ | Hardware | +--------------------------------------+

This is a simplified conceptual view. Actual Linux systems contain additional interfaces and components, and applications can interact with the kernel through system calls.

6. How Linux Works

  1. A user enters a command or starts an application.
  2. If a command is entered in a terminal, the shell parses it and launches the requested program or performs the requested shell operation.
  3. The application uses libraries and system calls when it needs operating-system services.
  4. The kernel performs the requested operation, subject to permissions and resource availability.
  5. The application receives the result and may display it to the user.
Remember: Applications normally request privileged operating-system services through system calls. They do not directly perform unrestricted access to hardware.

7. Applications of Linux

Application Area Typical Usage
Servers and cloud Web hosting, databases, cloud infrastructure and containers.
Embedded systems Routers, industrial equipment, smart devices and development boards.
Supercomputing High-performance scientific and engineering workloads.
Networking Network appliances, gateways and communication infrastructure.
IoT and edge computing Connected devices, local processing and edge gateways.

8. Practical Linux Commands

Open your Ubuntu terminal and execute these commands to inspect basic system information.

Example 1: Display Kernel Information

uname displays system information. The -a option requests all available standard information fields.

TERMINAL COMMAND
uname -a

Example 2: Display Linux Distribution Information

The /etc/os-release file contains operating-system identification data on many Linux distributions.

TERMINAL COMMAND
cat /etc/os-release

Example 3: Display the Current Username

TERMINAL COMMAND
whoami

Example 4: Display the Current Working Directory

TERMINAL COMMAND
pwd

Example 5: Display the Machine Architecture

TERMINAL COMMAND
uname -m

9. Expected Output

The following is an illustrative example. Your username, directory, distribution version, kernel release and architecture may be different.

SAMPLE TERMINAL SESSION
$ whoami
student

$ pwd
/home/student

$ uname -m
x86_64
Note: The sample username and home directory are illustrative, not fixed Ubuntu values.

11. Interview Questions

Q1. What is Linux?

Linux is an open-source, Unix-like kernel used as the foundation of many operating-system distributions.

Q2. Who developed the Linux kernel?

Linus Torvalds originally developed the Linux kernel and announced it in 1991.

Q3. Is Linux an operating system or a kernel?

Strictly speaking, Linux is the kernel. A Linux distribution combines the kernel with utilities, libraries and applications to provide a complete operating-system environment.

Q4. What is the main function of the Linux kernel?

It manages system resources such as CPU time, memory, processes and device access, and provides system-call interfaces to user-space programs.

Q5. What is a shell in Linux?

A shell is a command interpreter that provides an interface for executing commands and shell scripts.

Q6. What is open-source software?

Open-source software is distributed under a license that grants users specified rights to inspect, use, modify and redistribute its source code.

Q7. What is Ubuntu?

Ubuntu is a popular Linux distribution based on Debian.

Q8. Where is Linux used in embedded systems?

Linux is used in network routers, gateways, industrial systems, smart devices, development boards and many IoT platforms.

13. Lesson Summary

  • Linux is an open-source, Unix-like kernel.
  • The operating system manages hardware and provides services to applications.
  • A Linux distribution combines the kernel with utilities, libraries and applications.
  • The shell provides a command-based interface to the system.
  • Linux is widely used in servers, embedded systems, networking and IoT.
  • Commands such as uname, whoami and pwd help inspect a Linux system.
