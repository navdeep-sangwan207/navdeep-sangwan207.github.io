2. Introduction to Linux

Linux is a family of open-source, Unix-like operating systems built around the Linux kernel.

It is widely used in desktop computers, servers, supercomputers, embedded systems, networking devices, smartphones and Internet of Things (IoT) devices.

Linux provides an environment in which users can execute programs, manage files, communicate with hardware and perform various computing operations.

Important: Linux technically refers to the kernel. A complete Linux operating system distribution combines the kernel with system utilities, libraries, applications and other software.

3. What is an Operating System?

An Operating System (OS) is system software that acts as an interface between computer hardware and application software.

It manages hardware resources and provides services required by application programs.

3.1 Main Functions of an Operating System

  • Process Management: Creates, schedules and terminates processes.
  • Memory Management: Allocates and manages main memory.
  • File Management: Organizes files and directories.
  • Device Management: Manages hardware devices through device drivers.
  • Security: Controls access to system resources.
  • User Interface: Provides command-line or graphical interaction.

4. What is Linux?

Linux is an open-source operating system kernel originally created by Linus Torvalds in 1991. It provides the core functionality required to manage computer hardware and system resources.

4.1 Important Characteristics

  • Open-source development.
  • Multiuser operating environment.
  • Multitasking support.
  • Portable across different hardware platforms.
  • Strong networking capabilities.
  • Support for command-line and graphical interfaces.
  • Flexible customization and configuration.

5. Basic Components of a Linux System

A complete Linux system consists of several components that work together.

5.1 Linux Kernel

The kernel is the core component of the operating system. It manages CPU scheduling, memory, device drivers, processes and hardware resources.

5.2 System Libraries

System libraries provide standard functions that application programs use to access operating system services.

5.3 System Utilities

System utilities are programs used to perform system operations such as file management, process monitoring and system configuration.

5.4 Shell

A shell is a command interpreter that accepts commands from the user and executes them. Bash is one commonly used Linux shell.

5.5 Application Software

Applications are programs used to perform specific tasks, such as text editing, programming, browsing and multimedia operations.

6. How Linux Works

  1. The user enters a command or starts an application.
  2. The shell interprets commands entered in the terminal.
  3. Applications use system libraries and system calls to request OS services.
  4. The kernel manages the required hardware and system resources.
  5. The result is returned to the application or displayed to the user.
Remember: Applications generally request kernel services through system calls. They do not directly control hardware resources.

8. Practical Linux Commands

Open your Ubuntu terminal and execute the following commands to identify basic Linux system information.

Example 1: Display Linux Kernel Information

uname -a

Purpose: Displays kernel name, hostname, kernel release, version and machine architecture.

Example 2: Display Linux Distribution Information

cat /etc/os-release

Purpose: Displays information about the installed Linux distribution.

Example 3: Display Current Username

whoami

Purpose: Displays the username of the currently logged-in user.

Example 4: Display Current Working Directory

pwd

Purpose: Displays the absolute path of the current working directory.

Example 5: Display System Architecture

uname -m

Purpose: Displays the machine hardware architecture, such as x86_64 or aarch64.

9. Expected Output

Example outputs are shown below. Actual values depend on your Ubuntu installation and system configuration.

$ whoami
student

$ pwd
/home/student

$ uname -m
x86_64
Note: The username, directory path and processor architecture shown above are illustrative. Your system may display different values.

11. Interview Questions

Q1. What is Linux?

Linux is an open-source, Unix-like operating system kernel used as the foundation of many operating system distributions.

Q2. Who developed the Linux kernel?

Linus Torvalds originally developed the Linux kernel in 1991.

Q3. Is Linux an operating system or a kernel?

Technically, Linux is the kernel. A complete Linux distribution combines it with utilities, libraries and applications to provide an operating system.

Q4. What is the main function of the Linux kernel?

It manages hardware resources, memory, processes, device drivers and communication between software and hardware.

Q5. What is a shell in Linux?

A shell is a command interpreter that allows users to interact with the operating system.

Q6. What is an open-source operating system?

It is an operating system whose source code is available under an open-source license, allowing permitted inspection, modification and redistribution.

Q7. What is Ubuntu?

Ubuntu is a popular Linux distribution based on Debian.

Q8. Where is Linux used in Embedded Systems?

Linux is used in routers, smart devices, industrial equipment, automotive systems and IoT platforms.
