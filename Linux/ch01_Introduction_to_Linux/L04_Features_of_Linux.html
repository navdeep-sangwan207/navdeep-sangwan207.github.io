1. Introduction to Linux Features

Linux is a powerful, flexible, and widely used operating-system kernel. It supports a wide range of hardware platforms and provides important facilities for managing system resources.

Linux-based operating systems are used in personal computers, servers, supercomputers, embedded systems, routers, and cloud infrastructure.

Its popularity is supported by several technical characteristics:

  • Open-source development.
  • Multiuser operation.
  • Multitasking.
  • Portability.
  • Security and permissions.
  • Powerful command-line interface.
  • Networking support.
  • Process and memory management.
  • Customizability.
Important: Linux features are provided by the kernel, system libraries, utilities, and other components of the complete Linux distribution.

2. Open-Source Operating System

Linux is developed using an open-source model. Its kernel source code is publicly available under the GNU General Public License version 2 (GPL-2.0), with specific exceptions and notices in some parts.

Developers can study the source code, modify it, and distribute modified versions under the applicable license terms.

Advantages of Open Source

  • Source code can be inspected.
  • Developers can contribute improvements.
  • Security issues can be reviewed and fixed.
  • Systems can be customized for specific requirements.
  • Organizations can build specialized Linux distributions.
Example: Embedded-system developers can configure and build a Linux kernel containing only the features and drivers required by their target hardware.

3. Multiuser Capability

Linux supports multiple user accounts. Different users can access the same computer system while maintaining separate identities and permissions.

Each user can have individual files, directories, and access rights.

Important User Categories

  • Root User: The administrative account with extensive system privileges.
  • Regular User: A standard account with permissions limited by system configuration.
  • System User: An account commonly used by system services and applications.

Commands to Check User Information

whoami

Displays the username of the currently logged-in user.

who

Displays information about users currently logged into the system.

id

Displays the current user's user ID (UID), group ID (GID), and group memberships.

Illustrative Output:
navdeep uid=1000(navdeep) gid=1000(navdeep) groups=1000(navdeep)

Actual usernames, UID values, and group information depend on your system.

4. Multitasking Capability

Multitasking is the ability of an operating system to manage multiple running tasks or processes.

Linux uses CPU scheduling to allocate processor time among runnable tasks. This allows multiple applications and background services to operate concurrently.

Examples of Multitasking

  • Playing audio while browsing the internet.
  • Downloading files while editing documents.
  • Running a background service while using the terminal.
  • Executing multiple software-development tools.

Command to Display Running Processes

ps

Displays information about processes associated with the current terminal session.

Command to Monitor Processes

top

Displays a continuously updated view of running processes and system resource usage.

Remember: A process is a running instance of a program. Linux manages processes using scheduling, memory management, and other kernel mechanisms.

5. Portability

Portability means that software can be adapted to run on different hardware platforms with relatively limited changes.

Linux supports many processor architectures, including:

  • x86 and x86-64.
  • ARM and AArch64.
  • RISC-V.
  • PowerPC.
  • s390x.

Why Portability is Important

  • Linux can run on desktop computers and servers.
  • It can be adapted for embedded devices.
  • Developers can build software for different processor architectures.
  • Organizations can reuse software across different hardware platforms.
Example: The same Linux-based software concept can be adapted for an x86-64 computer and an ARM-based embedded board, provided the required architecture-specific support is available.

6. Security and File Permissions

Linux provides security mechanisms that help control access to files, directories, processes, and system resources.

Basic Permission Types

Permission Symbol Meaning
Read r Allows reading file contents or listing directory entries.
Write w Allows modifying a file or directory entries.
Execute x Allows executing a file or accessing a directory.

Permission Categories

  • Owner: The user who owns the file.
  • Group: Users associated with the file's group.
  • Others: All other users.

Command to Display Permissions

ls -l

Example output:

-rw-r--r-- 1 navdeep navdeep 1200 Nov 03 notes.txt

In this example:

  • Owner has read and write permissions.
  • Group has read permission.
  • Others have read permission.

Command to Modify Permissions

chmod 755 script.sh

This gives the owner read, write, and execute permissions, while group and others receive read and execute permissions.

Security Note: Linux also supports additional mechanisms such as Access Control Lists (ACLs), capabilities, and mandatory access-control frameworks.

7. Powerful Command-Line Interface

Linux provides a command-line interface (CLI) that allows users to interact with the operating system through commands.

A shell interprets commands and provides features such as command execution, variables, pipelines, redirection, and scripting.

Common Linux Shells

  • Bash: Bourne Again Shell.
  • sh: A traditional Unix shell interface.
  • Zsh: Z Shell.
  • Ksh: KornShell.
  • Fish: Friendly Interactive Shell.

Useful Linux Commands

Command Purpose
pwd Display current directory.
ls List files and directories.
cd Change directory.
mkdir Create a directory.
touch Create an empty file if it does not exist.
cp Copy files or directories.
mv Move or rename files.
rm Remove files or directories.
cat Display or combine file contents.
Career Relevance: Linux command-line knowledge is essential for shell scripting, software development, system administration, embedded Linux, and device-driver development.

8. Hierarchical File-System Structure

Linux organizes files and directories in a hierarchical tree structure beginning with the root directory `/`.

Important directories include:

Directory Purpose
/ Root of the entire directory hierarchy.
/bin Essential user command binaries on systems using this layout.
/boot Boot-related files.
/dev Device files.
/etc System-wide configuration files.
/home Regular users' home directories.
/proc Virtual file system exposing process and kernel information.
/root Home directory of the root user.
/tmp Temporary files.
/usr Many user applications, libraries, and shared data.
/var Variable data such as logs and caches.
Note: Some distributions use merged directories, where paths such as `/bin` point to locations under `/usr`. The exact layout can vary.

9. Networking Support

Linux provides extensive networking capabilities for communication between computers and network devices.

Networking Features

  • TCP/IP networking.
  • Ethernet and wireless networking.
  • Routing and packet forwarding.
  • Network configuration tools.
  • Firewall support.
  • Socket programming interfaces.

Useful Networking Commands

ip addr

Displays network interfaces and IP address information.

ping google.com

Tests network connectivity by sending ICMP echo requests, if permitted by the network.

ss -tuln

Displays listening TCP and UDP sockets with numeric addresses and ports.

Technical Connection: Socket programming is an important topic in Linux systems programming. It allows applications to communicate using network protocols.

10. Memory Management

Linux manages physical memory and virtual memory to support running processes and system services.

Major Memory-Management Functions

  • Allocation and release of memory.
  • Virtual memory management.
  • Memory protection between processes.
  • Page management.
  • Memory mapping.
  • Use of swap space when configured.

Command to Display Memory Information

free -h

Displays memory and swap usage in human-readable units.

Illustrative Output:
total used free Mem: 7.7Gi 2.1Gi 3.2Gi Swap: 2.0Gi 0.0Gi 2.0Gi

These values are examples. Your system will display its own memory information.

11. Device Management

Linux manages hardware devices through device drivers and kernel subsystems.

A device driver is software that enables the operating system to communicate with a particular hardware device or device class.

Examples of Hardware Devices

  • UART controllers.
  • I2C controllers.
  • SPI controllers.
  • USB devices.
  • Network interfaces.
  • Storage devices.
  • Display and input devices.

Device Files

Linux commonly exposes devices through special files under the /dev directory.

ls /dev

This command lists device entries available on the system.

Embedded Systems Connection: Device drivers are especially important in embedded Linux development because they provide the interface between hardware peripherals and software.

12. Stability and Reliability

Linux is widely used in environments where systems are expected to operate continuously and reliably.

Factors Supporting Reliability

  • Process isolation and memory protection.
  • Structured permission mechanisms.
  • Kernel and system-service management.
  • Logging and diagnostic facilities.
  • Flexible system configuration.
  • Support for automated maintenance and monitoring.

However, reliability depends on hardware quality, software configuration, kernel version, drivers, maintenance, and workload. Linux does not automatically guarantee that every system will run without failures.

13. Customization and Flexibility

Linux can be configured for different types of users and hardware requirements.

Examples of Customization

  • Selecting a Linux distribution.
  • Choosing a desktop environment.
  • Configuring kernel features.
  • Adding or removing software packages.
  • Building custom kernels.
  • Creating minimal embedded Linux images.
Example: A desktop distribution may include a graphical interface and many applications, while an embedded Linux image may contain only the kernel, essential utilities, drivers, and application software required by the device.

16. Interview Questions

Q1. What is open-source software?

Answer: Open-source software makes its source code available under a license that permits activities such as inspection, modification, and redistribution according to its terms.

Q2. What is multitasking?

Answer: Multitasking is the ability of an operating system to manage multiple running tasks or processes.

Q3. What is a multiuser operating system?

Answer: A multiuser operating system supports multiple user accounts and controls their access to system resources.

Q4. What is portability in Linux?

Answer: Portability refers to Linux's ability to support different hardware architectures through appropriate architecture-specific code and configuration.

Q5. What is a shell?

Answer: A shell is a command interpreter that allows users to interact with the operating system.

Q6. What is a device driver?

Answer: A device driver is software that enables the operating system to communicate with hardware devices.

Q7. What is virtual memory?

Answer: Virtual memory is a memory-management technique that provides processes with virtual address spaces and maps them to physical memory as required.

Q8. What is the purpose of the chmod command?

Answer: The chmod command changes file and directory permission bits.

Q9. What is the purpose of the /dev directory?

Answer: The /dev directory contains device special files that provide interfaces to devices and certain kernel facilities.

Q10. Why is Linux useful in embedded systems?

Answer: Linux supports different processor architectures, configurable kernels, device drivers, networking, and software-development tools.

18. Lesson Summary

  • Linux follows an open-source development model.
  • It supports multiuser operation and multitasking.
  • It is portable across many processor architectures.
  • It provides security through permissions and access-control mechanisms.
  • Its command-line interface supports administration and automation.
  • It provides process and memory-management facilities.
  • It supports networking and device drivers.
  • It can be customized for desktops, servers, and embedded devices.
