1. What is Ubuntu?

Ubuntu is a popular Linux distribution based on Debian. It is developed and maintained by Canonical and a large open-source community.

Ubuntu provides a complete operating system containing the Linux kernel, system libraries, utilities, package management tools, and applications.

It is widely used for:

  • Desktop and personal computing.
  • Software development.
  • Cloud computing.
  • Servers and data centres.
  • Virtual machines.
  • Embedded Linux development.
  • Education and research.
Important: Ubuntu is a Linux distribution, not a separate operating system kernel. It uses the Linux kernel along with additional software components.

2. History of Ubuntu

Ubuntu was first released in October 2004.

It was created to provide a user-friendly Linux distribution that could be used on personal computers, servers, and other computing platforms.

Important Historical Points

Year Event
2004 Ubuntu 4.10, the first Ubuntu release, was introduced.
2005 Canonical was established by Mark Shuttleworth.
2006 Ubuntu introduced its six-month release cycle.
2010s Ubuntu expanded its presence in cloud computing and server environments.
2020s Ubuntu continued expanding support for cloud, containers, desktop, and embedded applications.
Ubuntu version numbers generally use the year and month of release. For example, Ubuntu 24.04 represents a release from April 2024.

3. Features of Ubuntu

3.1 Open Source

Ubuntu is built primarily from free and open-source software. Users can inspect and modify components according to their respective licenses.

3.2 User-Friendly Interface

Ubuntu Desktop provides a graphical environment that supports windows, menus, applications, and desktop interaction.

3.3 Security

Ubuntu provides user permissions, security updates, package verification, and other security mechanisms.

3.4 Package Management

Ubuntu uses APT and Debian package tools to install, update, and remove software.

3.5 Community Support

Ubuntu has extensive documentation, forums, and community resources.

3.6 Hardware Support

Ubuntu supports a wide range of hardware, although compatibility depends on the device, drivers, kernel version, and system configuration.

3.7 Development Tools

Ubuntu supports programming tools such as GCC, G++, GDB, Git, Python, and many development environments.

4.1 Ubuntu Desktop

4.2 Ubuntu Server

Ubuntu Server is designed for server environments and commonly uses a command-line interface by default.

5. Ubuntu Desktop Environment

Ubuntu Desktop commonly uses the GNOME desktop environment with Ubuntu-specific customization.

A desktop environment provides the graphical interface through which users interact with the operating system.

Main Desktop Components

  • Desktop: Main graphical working area.
  • Dock: Provides quick access to applications.
  • Activities Overview: Helps locate windows and applications.
  • File Manager: Used to browse files and directories.
  • Settings: Used to configure system preferences.
  • Terminal: Provides command-line access.
A desktop environment is not the Linux kernel. It is a collection of user-space graphical components that run on top of the operating system.

6. Installing Ubuntu

Ubuntu can be installed directly on a computer or used in a virtual machine.

6.1 Installation Methods

Method Description
Physical Installation Install Ubuntu directly on a computer's storage device.
Dual Boot Install Ubuntu alongside another operating system.
Virtual Machine Run Ubuntu inside software such as VirtualBox or VMware.
Live USB Run Ubuntu from a bootable USB without necessarily installing it.

6.2 Ubuntu in VirtualBox

VirtualBox allows you to run Ubuntu as a guest operating system inside Windows.

The main components are:

  • Host OS: The operating system installed on the physical computer.
  • VirtualBox: Virtualization software that creates and manages virtual machines.
  • Guest OS: Ubuntu running inside the virtual machine.
  • Virtual Hardware: Virtual CPU, RAM, storage, and network devices assigned to Ubuntu.
+------------------------------------+ | Physical Computer | | | | +------------------------------+ | | | Windows 11 | | | | Host OS | | | | | | | | +------------------------+ | | | | | VirtualBox | | | | | | | | | | | | +----------------+ | | | | | | | Ubuntu | | | | | | | | Guest OS | | | | | | | +----------------+ | | | | | +------------------------+ | | | +------------------------------+ | +------------------------------------+
Practical Connection: Running Ubuntu in VirtualBox is useful for learning Linux commands, shell scripting, C/C++ programming, and basic system administration without replacing Windows.

6.3 Basic Virtual Machine Requirements

Resource requirements depend on the Ubuntu release and workload. A practical learning virtual machine can start with:

Resource Suggested Starting Allocation
RAM 2–4 GB
Virtual CPU 2 cores, if available
Virtual Disk 25–40 GB
Network NAT for basic internet access
These are learning-oriented starting values, not official minimum requirements. Allocate resources according to your host computer's available capacity.

7. Ubuntu Login and Terminal

After Ubuntu starts, you can log in using the account configured during installation.

The terminal provides access to the Linux command line.

Opening the Terminal

  • Use the application search and type Terminal.
  • Open the Terminal application.
  • On many Ubuntu Desktop installations, press Ctrl + Alt + T.

Understanding the Terminal Prompt

user@ubuntu:~$
Part Meaning
user Current logged-in username.
ubuntu Computer hostname.
~ Current user's home directory.
$ Normal user shell prompt.

A root shell commonly uses # as its prompt character, although prompt appearance can be customized.

These commands help you navigate and work with the Ubuntu terminal.

9. Ubuntu File System Structure

Ubuntu follows the Linux Filesystem Hierarchy Standard conventions. The file system begins at the root directory, represented by /.

Important Directories

Directory Purpose
/ Root of the entire directory hierarchy.
/bin Essential user command binaries; commonly integrated with /usr/bin on modern Ubuntu systems.
/boot Bootloader-related files and kernel images.
/dev Device nodes representing devices and interfaces.
/etc System-wide configuration files.
/home Home directories of ordinary users.
/lib Essential shared libraries and kernel modules; commonly integrated with /usr/lib on modern systems.
/media Mount points commonly used for removable media.
/mnt Temporary mount points.
/opt Optional application software.
/proc Virtual file system exposing process and kernel information.
/root Home directory of the root user.
/run Runtime system data.
/tmp Temporary files.
/usr Many user applications, libraries, and shared data.
/var Variable data such as logs, caches, and spool files.

View the Root Directory

ls /

10. Package Management in Ubuntu

Package management is the process of installing, updating, configuring, and removing software.

Ubuntu uses the Debian package format, commonly represented by .deb files.

10.1 APT

APT stands for Advanced Package Tool. It provides a convenient interface for managing software packages and their dependencies.

10.2 Important APT Commands

Command Purpose
sudo apt update Refreshes package repository information.
sudo apt upgrade Upgrades installed packages where possible.
sudo apt install package Installs a package.
sudo apt remove package Removes an installed package.
sudo apt purge package Removes a package and its system configuration files managed by the package.
apt search keyword Searches package information.
apt show package Displays package information.
sudo apt autoremove Removes automatically installed packages that are no longer required.

10.3 Example: Install GCC

sudo apt update sudo apt install gcc

10.4 Example: Install Development Tools

sudo apt install build-essential

The build-essential package installs commonly needed development tools, including GCC, G++, and Make.

Remember: apt update refreshes package information. It does not itself upgrade installed software. Use apt upgrade to upgrade packages.

11. Understanding sudo and Root Access

sudo stands for "Superuser Do". It allows an authorized user to execute a command with elevated privileges.

Example

sudo apt update

This command refreshes package information using administrative privileges.

Normal User vs Root User

Normal User Root User
Has restricted permissions. Has extensive administrative privileges.
Cannot normally modify protected system files. Can modify protected system files.
Prompt commonly ends with $. Prompt commonly ends with #.
Use elevated privileges only when necessary. Incorrect administrative commands can damage the operating system or delete important data.

12. Installing C and C++ Development Tools

Ubuntu provides a complete environment for learning C and C++ programming.

Step 1: Update Package Information

Step 3: Check GCC

Step 4: Check G++

Step 5: Create a C Program

nano hello.c

Enter the following code:

gcc hello.c -o hello

Step 7: Execute the Program

./hello
Expected Output:
Hello from Ubuntu Linux!

This exercise demonstrates how Ubuntu can be used for C programming and systems development.

16. Ubuntu vs Windows

Ubuntu Windows
Linux distribution. Operating system developed by Microsoft.
Primarily uses Linux kernel. Uses Windows NT kernel architecture.
Uses APT and other supported package formats and tools. Supports installers, Microsoft Store, and package managers.
Strong command-line and open-source development ecosystem. Broad desktop software and enterprise ecosystem.
Common in servers, cloud, and embedded development. Common in desktop computing and enterprise environments.

Both operating systems are useful. The choice depends on software compatibility, development requirements, hardware, and personal preference.

18. Interview Questions and Answers

Q1. What is Ubuntu?

Ubuntu is a Debian-based Linux distribution developed by Canonical and the open-source community.

Q2. Who develops Ubuntu?

Canonical is the main company behind Ubuntu development, with contributions from the wider community.

Q3. What is APT?

APT stands for Advanced Package Tool. It is used to manage software packages on Ubuntu and other Debian-based systems.

Q4. What is the difference between Ubuntu Desktop and Ubuntu Server?

Ubuntu Desktop is designed for personal computing and normally includes a graphical desktop. Ubuntu Server is designed for server workloads and commonly uses a command-line interface by default.

Q5. What is sudo?

sudo allows an authorized user to execute commands with elevated privileges.

Q6. What is the Ubuntu root directory?

The root directory is represented by /. It is the starting point of the Linux file-system hierarchy.

Q7. What is the purpose of apt update?

It refreshes the local package index using configured software repositories.

Q8. What is the purpose of apt upgrade?

It upgrades installed packages to newer available versions according to the configured repositories and dependency rules.

Q9. What is VirtualBox?

VirtualBox is virtualization software that allows a guest operating system such as Ubuntu to run inside a host operating system such as Windows.

Q10. Why is Ubuntu useful for embedded development?

Ubuntu provides development tools, cross-compilers, debugging utilities, source-code management tools, and build systems used in embedded Linux development.
