LINUX ADMINISTRATION • CHAPTER 9 • LESSON 2

APT Package Manager

Managing Software Packages in Ubuntu and Debian-Based Linux

Home Linux Course Chapter 9

Learning Objectives

After completing this lesson, you will be able to:

  • Understand APT and its role in Linux package management.
  • Differentiate between APT and DPKG.
  • Update package repository information.
  • Upgrade installed software packages.
  • Search for and inspect available packages.
  • Install, remove and manage packages using APT.
  • Understand APT repositories and package sources.

1. Introduction to APT

APT stands for Advanced Package Tool. It is a package management system used in Debian-based Linux distributions such as Ubuntu and Debian.

APT allows users to install, update, upgrade and remove software packages from configured software repositories.

Why is APT used?

  • Install software from configured repositories.
  • Automatically resolve package dependencies.
  • Update package information.
  • Upgrade installed software.
  • Remove unnecessary packages.
  • Search for available software packages.
Example: If you want to install the curl utility on Ubuntu, you can use sudo apt install curl.

2. APT and DPKG

APT and DPKG are related but perform different roles in Debian-based package management.

APT DPKG
High-level package management tool. Low-level Debian package management tool.
Can download packages from repositories. Installs local DEB package files.
Automatically resolves dependencies. Does not automatically download missing dependencies.
Supports package searching and upgrading. Supports package installation, removal and inspection.

Example using APT

sudo apt install curl

Example using DPKG

sudo dpkg -i package.deb
APT uses DPKG as part of the underlying package management system. APT provides additional repository and dependency management features.

3. APT Command Syntax

The general syntax of an APT command is:

sudo apt [option] [command] [package-name]
Component Description
sudo Runs the command with administrative privileges.
apt Invokes the APT package management tool.
command Specifies the operation, such as install or remove.
package-name Specifies the software package to manage.

4. Updating Package Information

The apt update command downloads the latest package information from configured repositories.

sudo apt update

What happens when this command runs?

  1. APT reads the configured repository sources.
  2. It contacts the configured software repositories.
  3. It downloads updated package index information.
  4. It refreshes the local package information database.
Important: sudo apt update does not upgrade installed software. It only refreshes information about available packages and their versions.

Typical command output

Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease
Get:2 http://archive.ubuntu.com/ubuntu noble-updates InRelease
Reading package lists... Done
Building dependency tree... Done
All packages are up to date.
Illustrative output. Repository names and messages vary.

5. Upgrading Installed Packages

The apt upgrade command installs available upgrades for installed packages.

sudo apt upgrade

How it works

  1. APT checks the refreshed package information.
  2. It identifies installed packages with available upgrades.
  3. It downloads the required package files.
  4. It installs the available upgrades.

Other upgrade commands

sudo apt full-upgrade

full-upgrade can install or remove packages when required to complete a system upgrade. Review its proposed changes before confirming.

A common maintenance sequence is:
sudo apt update sudo apt upgrade
Review the list of packages to be upgraded or removed before accepting a major system upgrade. Keep important data backed up.

6. Installing Packages

The apt install command installs software packages from configured repositories.

Syntax

sudo apt install package-name

Example: Install curl

sudo apt install curl

Install multiple packages

sudo apt install curl wget git

Install a package without an interactive confirmation prompt

sudo apt install -y curl

The -y option automatically answers yes to confirmation prompts. Use it only when you understand the changes being made.

Verify installation

curl --version
curl 8.x.x
Illustrative version output; your installed version may differ.

7. Removing Packages

APT provides different commands for removing software.

Remove a package

sudo apt remove curl

Removes the installed package but generally leaves its system-wide configuration files in place.

Purge a package

sudo apt purge curl

Removes the package and its system-wide configuration files managed by the package.

Remove automatically installed unused dependencies

sudo apt autoremove

Removes packages that were automatically installed as dependencies and are no longer required.

Before confirming a removal or purge operation, inspect the list of packages APT proposes to remove. Do not remove packages simply because you do not recognize their names.

8. Searching for Packages

The apt search command searches package names and descriptions in the local package information.

Syntax

apt search keyword

Example

apt search text editor

This searches for packages related to text editors.

Search for a specific package

apt search curl
Run sudo apt update first if you want to search using recently refreshed repository information.

9. Viewing Package Information

The apt show command displays information about a package.

apt show curl

Information displayed

  • Package name
  • Package version
  • Architecture
  • Package description
  • Dependencies
  • Download size
  • Installed size
  • Repository information

Check whether a package is installed

apt list --installed

To filter the output for a particular package:

apt list --installed 2>/dev/null | grep '^curl/'
2>/dev/null redirects standard error to /dev/null, while grep filters the package list for entries beginning with curl/.

10. Downloading Packages Without Installing

The apt download command downloads a package file into the current working directory without installing it.

apt download curl

This is useful when you want to obtain a DEB package file for inspection or transfer.

The command downloads the package itself. It does not automatically download all dependency packages.

11. Important APT Commands

Command Purpose
sudo apt update Refresh package lists.
sudo apt upgrade Upgrade installed packages.
sudo apt full-upgrade Perform upgrades that may require package removals or additions.
sudo apt install pkg Install a package.
sudo apt remove pkg Remove a package.
sudo apt purge pkg Remove a package and its managed system configuration.
sudo apt autoremove Remove unused automatically installed dependencies.
apt search keyword Search for packages.
apt show pkg Display package details.
apt list --installed List installed packages.
apt download pkg Download a package without installing it.
apt policy pkg Display package versions and repository priorities.
sudo apt clean Remove downloaded package files from the local cache.
sudo apt autoclean Remove obsolete package files from the local cache.

12. APT Package Repositories

A repository is a software server or collection of servers that provides package files and package information.

APT uses configured repositories to locate and download software packages.

Common Ubuntu repository components

Component Description
Main Free and open-source software officially supported by Ubuntu.
Universe Free and open-source software maintained by the wider community.
Restricted Proprietary drivers and other software with restricted licensing.
Multiverse Software with licensing or other restrictions.

Repository configuration files

/etc/apt/sources.list /etc/apt/sources.list.d/

These locations contain APT repository configuration. Modern Ubuntu releases can also use Deb822-style .sources files.

View repository configuration files

ls /etc/apt/sources.list.d/

To inspect the traditional sources file if it exists:

cat /etc/apt/sources.list
Some modern Ubuntu installations store their default repository configuration in a file such as ubuntu.sources inside /etc/apt/sources.list.d/.

13. APT Cache

APT maintains a local cache of downloaded package files and package information.

Clean the downloaded package cache

sudo apt clean

Remove obsolete cached package files

sudo apt autoclean

View cache directory

ls /var/cache/apt/archives/
Cleaning the package cache does not uninstall software that is already installed.

14. Practical Lab Exercises

Lab 1: Update package information

Objective: Refresh the local package lists.

sudo apt update

Expected result: APT contacts configured repositories and updates package information.

Lab 2: Search for a package

Objective: Search for the curl package.

apt search curl

Expected result: A list of matching packages and descriptions is displayed.

Lab 3: Display package details

Objective: View information about curl.

apt show curl

Expected result: Package version, description, dependencies and other metadata are displayed.

Lab 4: Install curl

Objective: Install the curl utility.

sudo apt install curl

Verify:

curl --version

Lab 5: Check installed packages

apt list --installed

Expected result: A list of installed packages is displayed.

Lab 6: Check package policy

apt policy curl

Expected result: Installed version, candidate version and available repository information are displayed.

Lab 7: Remove curl after testing (optional)

sudo apt remove curl

Expected result: APT proposes removing curl and shows the packages affected. Confirm only if you want to remove it.

Do not perform package removal or system upgrades on a production machine without checking the proposed changes.

15. Interview Questions and Answers

Q1. What is APT?

APT stands for Advanced Package Tool. It manages software packages on Debian-based Linux distributions.

Q2. What is the difference between apt update and apt upgrade?

apt update refreshes package information, whereas apt upgrade installs available upgrades for installed packages.

Q3. What is the difference between APT and DPKG?

APT is a high-level package manager that works with repositories and dependencies. DPKG is a lower-level tool that manages Debian package files.

Q4. What is a Linux package repository?

It is a server or collection of servers that provides software packages and package metadata.

Q5. Which command installs a package?

sudo apt install package-name

Q6. Which command removes a package?

sudo apt remove package-name

Q7. What is the purpose of apt autoremove?

It removes automatically installed packages that are no longer needed as dependencies.

Q8. What does apt show do?

It displays package metadata such as version, description, dependencies and package size.

Q9. What is the purpose of sudo?

It allows an authorized user to execute a command with elevated privileges.

Q10. Does apt update install software updates?

No. It refreshes package information. Use sudo apt upgrade to install available package upgrades.
