Chapter 9: Linux Administration

Package Management, Disk Management, System Monitoring and Administration

Chapter Overview

Linux Administration covers the essential tasks required to install software, manage packages, monitor storage, maintain file systems and administer Linux systems.

In this chapter, you will learn package management using APT, software installation and removal, disk management, mounting and unmounting, file system monitoring, system monitoring commands, the Linux boot process, services, system logs and scheduled tasks using cron.

These concepts are important for Linux system administration, embedded Linux development, systems programming and professional IT operations.
