Introduction to Computer Networking in Linux

Understand networking fundamentals, network devices, protocols and Linux network architecture

1. What Is Computer Networking?

A computer network is a collection of two or more computing devices connected together to communicate and exchange data.

These devices communicate through wired or wireless connections using standardized communication protocols.

Examples of Computer Networking

  • Two computers sharing files over a local network.
  • A laptop accessing the internet through a Wi-Fi router.
  • A client computer communicating with a web server.
  • A Linux system connecting to another Linux machine using SSH.
  • Embedded devices sending sensor data to a remote server.

Why Is Computer Networking Required?

  • Resource Sharing: Share printers, storage and network resources.
  • Communication: Exchange messages and information.
  • File Transfer: Transfer files between computers.
  • Remote Access: Access and manage remote systems.
  • Internet Access: Connect to websites and online services.
  • Distributed Computing: Allow multiple computers to work together.
Example:

When you open a website in a browser, your computer communicates with a remote web server through a network using protocols such as TCP/IP, DNS and HTTP or HTTPS.

2. Basic Components of a Computer Network

A computer network consists of different hardware and software components that work together to enable communication.

1. Sender

The device that sends information over a network.

2. Receiver

The device that receives information from another device.

3. Transmission Medium

The medium through which data travels.

  • Ethernet cables.
  • Optical fiber cables.
  • Wireless radio signals.

4. Network Interface Card (NIC)

A Network Interface Card provides a network connection for a computer or device. It may be an Ethernet adapter or a wireless adapter.

5. Network Protocol

A network protocol defines rules for communication between devices, including data formatting, addressing and transmission behavior.

6. Network Operating System

An operating system such as Linux provides networking functionality, protocol implementations and tools for managing network communication.

3. Types of Computer Networks

1. PAN – Personal Area Network

A Personal Area Network connects devices over a short distance, generally around an individual.

Examples: Bluetooth connections between a phone, smartwatch and wireless headphones.

2. LAN – Local Area Network

A Local Area Network connects devices within a limited geographical area, such as a home, office, laboratory or building.

Examples: Computers connected to the same office Ethernet network.

3. WLAN – Wireless Local Area Network

A Wireless LAN connects devices within a local area using wireless communication, commonly Wi-Fi.

4. MAN – Metropolitan Area Network

A Metropolitan Area Network connects multiple local networks across a city or metropolitan region.

5. WAN – Wide Area Network

A Wide Area Network connects networks over large geographical distances.

Example: The internet is the largest and most familiar example of a WAN.

Network Type Coverage Example
PAN Personal short range Bluetooth devices
LAN Home, office or building Office Ethernet network
WLAN Local wireless area Wi-Fi network
MAN City or metropolitan area City-wide network
WAN Large geographical area Internet

4. Network Topologies

Network topology describes how computers and other devices are arranged and connected within a network.

1. Bus Topology

All devices share a common communication cable called the backbone.

  • Simple structure.
  • Requires less cabling in its basic form.
  • A backbone failure can affect the entire network.

2. Star Topology

All devices connect to a central device, usually a switch or hub.

  • Easy to manage.
  • Individual cable failures usually affect only one device.
  • Failure of the central device can disrupt the network.

3. Ring Topology

Devices are connected in a closed loop, with each device connected to neighboring devices.

4. Mesh Topology

Devices are connected through multiple paths. A full mesh connects each device directly to every other device.

  • Provides multiple communication paths.
  • Can offer high reliability.
  • Requires more connections and infrastructure.

5. Tree Topology

A hierarchical arrangement of networks that combines multiple star networks or network segments.

6. Hybrid Topology

A combination of two or more different network topologies.

Modern Ethernet LANs commonly use physical star or extended-star arrangements with switches. The logical data flow may be more complex than the physical layout.

5. Client-Server and Peer-to-Peer Networks

Client-Server Architecture

In a client-server network, one or more servers provide services or resources to client devices.

Client: A device or application that requests a service.

Server: A device or application that provides the requested service.

Example:

A web browser is a client. It sends a request to a web server, which processes the request and returns a response.

Peer-to-Peer (P2P) Architecture

In a peer-to-peer network, devices can communicate and share resources directly. A device may act as both a client and a server.

Feature Client-Server Peer-to-Peer
Architecture Centralized service model Distributed peer model
Management Usually centrally managed Often decentralized
Resource Sharing Through servers Directly between peers
Example Web server Peer-to-peer file sharing

6. Networking Hardware Devices

1. Network Interface Card (NIC)

A NIC provides the hardware interface through which a computer connects to a network.

It may support Ethernet or Wi-Fi connectivity.

2. Hub

A hub connects multiple Ethernet devices and forwards incoming signals to all other ports. It operates at the Physical Layer of the OSI model.

3. Switch

A network switch connects devices in a LAN and forwards Ethernet frames using MAC address information.

4. Router

A router connects different IP networks and forwards packets based on routing information.

5. Modem

A modem provides communication between a local network and an internet service provider over a supported access technology.

6. Wireless Access Point

A wireless access point allows Wi-Fi devices to connect to a wired network.

7. Repeater

A repeater regenerates or retransmits signals to extend communication distance.

Device Main Function
NIC Connects a device to a network.
Hub Repeats signals to connected ports.
Switch Forwards Ethernet frames using MAC addresses.
Router Forwards packets between IP networks.
Modem Provides access-network signaling and connectivity.
Access Point Provides wireless network access.
Repeater Regenerates or retransmits signals.

7. OSI Reference Model

The OSI (Open Systems Interconnection) model is a seven-layer reference model used to understand how network communication functions.

Each layer describes a different set of networking responsibilities.

Layer Name Main Function
7 Application Provides network services to applications.
6 Presentation Data representation, encoding and encryption-related functions.
5 Session Manages communication sessions.
4 Transport End-to-end transport and port addressing.
3 Network Logical addressing and packet routing.
2 Data Link Frames, MAC addressing and link-level delivery.
1 Physical Transmission of bits over a physical medium.

Explanation of Each Layer

Layer 1 – Physical Layer

Responsible for transmitting raw bits through physical media such as cables, fiber or radio signals.

Layer 2 – Data Link Layer

Responsible for link-level framing, MAC addressing and communication over a local network link.

Layer 3 – Network Layer

Responsible for logical addressing and routing packets between networks. IP operates at this layer.

Layer 4 – Transport Layer

Provides transport services between applications. TCP and UDP are major transport-layer protocols.

Layer 5 – Session Layer

Describes functions for establishing, managing and terminating communication sessions.

Layer 6 – Presentation Layer

Describes data representation, encoding, compression and encryption-related functions.

Layer 7 – Application Layer

Provides network communication services used by applications, such as web browsing, file transfer and name resolution.

The OSI model is a conceptual reference model. Real-world Internet protocols do not always map one-to-one to individual OSI layers.

8. TCP/IP Model

The TCP/IP model describes the architecture used by the Internet and most modern IP networks.

It is commonly presented using four layers.

TCP/IP Layer Responsibilities Examples
Application Application-level network services and protocols. HTTP, HTTPS, DNS, SSH, DHCP
Transport Communication between application processes. TCP, UDP
Internet IP addressing and packet routing. IPv4, IPv6, ICMP
Network Access Communication over the local network link. Ethernet, Wi-Fi

OSI and TCP/IP Model Comparison

OSI Model TCP/IP Model
Application Application
Presentation
Session
Transport Transport
Network Internet
Data Link Network Access
Physical
Remember:

The OSI model has seven layers, while the commonly used TCP/IP model has four layers.

9. Network Protocols

A network protocol is a set of rules that defines how devices communicate and exchange information.

Important Networking Protocols

Protocol Full Form / Purpose
IP Internet Protocol – Provides logical addressing and packet delivery across networks.
TCP Transmission Control Protocol – Provides reliable, connection-oriented byte-stream transport.
UDP User Datagram Protocol – Provides connectionless datagram transport.
HTTP Hypertext Transfer Protocol – Used for web communication.
HTTPS HTTP over TLS – Provides encrypted web communication.
FTP File Transfer Protocol – Used for file transfer.
SFTP SSH File Transfer Protocol – Secure file transfer using SSH.
SSH Secure Shell – Secure remote login and command execution.
DNS Domain Name System – Resolves domain names to resource records, commonly IP addresses.
DHCP Dynamic Host Configuration Protocol – Automatically provides IP configuration to clients.
ICMP Internet Control Message Protocol – Used for network control and diagnostic messages.
ARP Address Resolution Protocol – Resolves IPv4 addresses to link-layer addresses on a local network.
FTP and SFTP are different protocols. SFTP runs over SSH; it is not simply FTP with encryption added.

10. TCP and UDP

TCP and UDP are two major transport-layer protocols used in IP networking.

TCP – Transmission Control Protocol

TCP is a connection-oriented transport protocol. It provides a reliable, ordered byte stream between applications.

Important TCP Features

  • Connection establishment.
  • Reliable data delivery.
  • Sequence numbers and acknowledgements.
  • Retransmission of lost data.
  • Flow control and congestion control.
  • Ordered delivery of bytes to the receiving application.

UDP – User Datagram Protocol

UDP is a connectionless transport protocol that sends independent datagrams.

Important UDP Features

  • No connection establishment handshake.
  • Low protocol overhead.
  • No built-in guarantee of delivery.
  • No built-in guarantee of ordering.
  • Suitable for applications that handle timing and loss according to their requirements.

TCP vs UDP

Feature TCP UDP
Connection Connection-oriented Connectionless
Reliability Reliable byte-stream transport No built-in delivery guarantee
Ordering Ordered byte stream No built-in ordering guarantee
Overhead Generally higher Generally lower
Examples SSH, HTTPS over TCP, email protocols DNS queries commonly, real-time media and gaming applications
Practical understanding:

TCP is useful when reliable, ordered delivery is required. UDP is useful when an application prefers datagram communication and can handle loss, timing or retransmission itself.

11. IP Address

An IP address is a logical address used to identify a network interface or endpoint within an IP network.

IP addresses are used by network devices to route packets from a source to a destination.

IPv4 Address

IPv4 uses a 32-bit address, commonly written in dotted-decimal notation.

192.168.1.10

An IPv4 address contains four decimal octets separated by dots. Each octet ranges from 0 to 255.

IPv6 Address

IPv6 uses a 128-bit address and is written using hexadecimal groups separated by colons.

2001:db8:abcd:0012::1

Types of IPv4 Addresses

Type Purpose
Private IP Used within private networks.
Public IP Globally routable address space used on the public internet.
Loopback Used by a device to communicate with itself; commonly 127.0.0.1.
Link-local IPv4 addresses in 169.254.0.0/16, commonly used for local-link communication.

Private IPv4 Address Ranges

Private Range CIDR
10.0.0.0 – 10.255.255.255 10.0.0.0/8
172.16.0.0 – 172.31.255.255 172.16.0.0/12
192.168.0.0 – 192.168.255.255 192.168.0.0/16

12. MAC Address

A MAC address is a link-layer address associated with a network interface. Ethernet and Wi-Fi interfaces commonly use MAC addresses for communication on a local network link.

Example MAC Address

00:1A:2B:3C:4D:5E

A conventional Ethernet MAC address is 48 bits long and is commonly represented using six hexadecimal octets.

IP Address vs MAC Address

Feature IP Address MAC Address
Address Type Logical network-layer address Link-layer address
Purpose Identifies an endpoint for IP communication and routing. Identifies an interface on a local network link.
Common Format 192.168.1.10 00:1A:2B:3C:4D:5E
Layer OSI Layer 3 OSI Layer 2

13. Port Numbers

A port number identifies a communication endpoint associated with a transport protocol on a host.

Port numbers help the operating system deliver incoming TCP or UDP data to the correct application or service.

Port Number Range

TCP and UDP port numbers are 16-bit values ranging from 0 to 65535.

Range Category
0–1023 Well-known ports
1024–49151 Registered ports
49152–65535 Dynamic or private ports

Common Network Ports

Port Protocol / Service
20 and 21 FTP data and control (traditional active-mode FTP uses port 20 for data).
22 SSH and SFTP
23 Telnet
25 SMTP
53 DNS (UDP and TCP)
67 and 68 DHCP server and client
80 HTTP
110 POP3
123 NTP
143 IMAP
443 HTTPS
TCP and UDP maintain separate port-number spaces. A port number alone does not identify the transport protocol.

14. How Data Travels Through a Network

Consider a client computer accessing a website hosted on a remote server.

Step-by-Step Communication

  1. The user enters a website address in the browser.
  2. The client resolves the domain name using DNS if an address is not already available from a cache or another configured source.
  3. The client determines how to reach the destination IP address.
  4. If the destination is outside the local subnet, the client normally sends the packet to its configured default gateway.
  5. The transport layer establishes or uses the appropriate transport communication, such as a TCP connection.
  6. The application sends an HTTP or HTTPS request.
  7. Network devices forward packets toward the destination server.
  8. The server processes the request and sends a response.
  9. The client application receives and displays the response.
Important networking concept:

Data is encapsulated as it moves down the network stack at the sender. At the receiver, the corresponding headers are processed as data moves up the stack. This is called encapsulation and decapsulation.

Encapsulation Overview

Layer Data Unit
Application Data
Transport TCP Segment or UDP Datagram
Internet / Network IP Packet
Network Access Frame
Physical Transmission Bits

15. Introduction to Linux Networking

Linux includes a networking subsystem in its kernel. It implements network protocols, manages network interfaces and processes network packets.

Linux provides command-line utilities and configuration tools for inspecting and managing network connectivity.

Common Linux Networking Tools

Command Purpose
ip Inspect and manage interfaces, addresses and routes.
ping Test IP reachability using ICMP Echo messages.
ifconfig Legacy tool for displaying and configuring interfaces.
ss Inspect sockets and network connections.
netstat Legacy utility for network statistics and connections.
hostname Display or manage the system hostname.
ssh Connect securely to a remote system.
scp Copy files securely over SSH.
ip route Display or manage IP routing information.
getent Query system-configured name-service databases.
This chapter uses Ubuntu in VirtualBox for practical demonstrations. Some commands may require installation of additional packages or administrator privileges.

16. Practical Linux Networking Commands

1. Display Hostname

hostname

Displays the system's current hostname.

2. Display IP Addresses

ip addr show

Displays network interfaces and their configured addresses.

3. Display Network Interfaces

ip link show

Displays network interfaces and their link-layer information and state.

4. Display Routing Table

ip route show

Displays IPv4 routing information.

5. Display IPv6 Routing Table

ip -6 route show

6. Test Loopback Connectivity

ping -c 4 127.0.0.1

Sends four ICMP Echo requests to the IPv4 loopback address.

7. Test Internet Connectivity

ping -c 4 1.1.1.1

Attempts to send four ICMP Echo requests to a public IP address. Success depends on network connectivity and whether ICMP is allowed.

8. Display Network Connections

ss -tuln

Displays listening TCP and UDP sockets with numeric addresses and port numbers.

9. Display System Hostname Information

hostnamectl

Displays system hostname and related operating-system information on systemd-based systems.

10. Check DNS Name Resolution

getent hosts example.com

Queries the system's configured host-name resolution service.

Note: The public IP address used in the ping example may not respond because some networks or firewalls block ICMP. A failed ping alone does not prove that a host or application service is unavailable.

17. Network Interfaces in Linux

A network interface is a software-visible interface through which a Linux system sends and receives network traffic.

Common Interface Names

Interface Meaning
lo Loopback interface.
eth0 Traditional Ethernet interface naming.
wlan0 Traditional wireless interface naming.
enp0s3 Example predictable Ethernet interface name.
wlp2s0 Example predictable wireless interface name.

Loopback Interface

The loopback interface allows a system to communicate with itself without sending traffic over a physical network.

ip addr show lo

The common IPv4 loopback address is:

127.0.0.1

The common IPv6 loopback address is:

::1

Display All Interfaces

ip link show

Display Interface Addresses

ip address show

18. Introduction to Network Configuration in Ubuntu

Ubuntu commonly uses Netplan as a network configuration framework. Netplan generates configuration for a backend such as NetworkManager or systemd-networkd.

View Netplan Configuration Files

ls /etc/netplan/

Display a Netplan Configuration

cat /etc/netplan/*.yaml

Generate Configuration

sudo netplan generate

Apply Configuration

sudo netplan apply
Do not modify Netplan configuration files or apply network changes on a remote machine unless you understand the configuration and have a recovery method. Incorrect settings can disconnect the system from the network.
Network configuration tools depend on the Ubuntu installation type and network manager. VirtualBox guest networking may also be controlled partly by the VirtualBox adapter settings.

19. Linux Networking in VirtualBox

When Ubuntu runs inside VirtualBox, its network connection is provided through a virtual network adapter.

Common VirtualBox Network Modes

1. NAT (Network Address Translation)

The guest system accesses external networks through VirtualBox's network translation mechanism.

  • Useful for ordinary internet access from the guest.
  • Commonly works without changing the physical network configuration.
  • Inbound access from the host or external network generally requires port forwarding or another networking arrangement.

2. Bridged Adapter

The virtual machine connects to the physical network through the host's network adapter and can usually obtain its own address on that network.

3. Host-Only Adapter

Allows communication between the host computer and virtual machines on a host-only network, without automatically providing internet access.

4. Internal Network

Allows virtual machines attached to the same named internal network to communicate with one another. The host is not automatically connected to this network.

Mode Main Purpose
NAT Guest internet access through host networking.
Bridged Guest appears as a device on the physical network.
Host-Only Communication between host and guest systems.
Internal Network Communication among connected virtual machines.
Practical recommendation:

For basic Ubuntu networking exercises in VirtualBox, NAT is usually sufficient. Host-only or internal networking can be useful when practising communication between virtual machines.

22. Interview Questions and Answers

Q1. What is computer networking?

Answer: Computer networking is the process of connecting computing devices so they can exchange information and share resources using communication protocols.

Q2. What is a LAN?

Answer: LAN stands for Local Area Network. It connects devices within a limited geographical area such as a home, office or building.

Q3. What is the difference between a switch and a router?

Answer: A switch forwards frames within a local network using MAC address information. A router forwards packets between IP networks.

Q4. What is the OSI model?

Answer: The OSI model is a seven-layer reference model that describes different functions involved in network communication.

Q5. What is the TCP/IP model?

Answer: The TCP/IP model is a networking architecture commonly presented in four layers: Application, Transport, Internet and Network Access.

Q6. What is TCP?

Answer: TCP is a connection-oriented transport protocol that provides reliable and ordered byte-stream delivery.

Q7. What is UDP?

Answer: UDP is a connectionless transport protocol that provides datagram communication without built-in delivery or ordering guarantees.

Q8. What is an IP address?

Answer: An IP address is a logical address used to identify an endpoint for communication over an IP network.

Q9. What is a MAC address?

Answer: A MAC address is a link-layer address used for communication on a local network link.

Q10. What is DNS?

Answer: DNS stands for Domain Name System. It provides a distributed naming system that resolves domain names into resource records, including IP addresses.

Q11. What is the purpose of a default gateway?

Answer: A default gateway is the next-hop router used when a system needs to send traffic to a destination for which no more specific route is available.

Q12. What is the loopback address?

Answer: The common IPv4 loopback address is 127.0.0.1. It allows a system to communicate with itself.

Q13. What is the purpose of the ping command?

Answer: Ping sends ICMP Echo Requests and checks whether Echo Replies are received. It is commonly used for basic connectivity testing.

Q14. What is SSH?

Answer: SSH stands for Secure Shell. It provides encrypted remote login and command execution.

Q15. What is a network interface?

Answer: A network interface is a hardware or software interface through which a system sends and receives network traffic.

Q16. What is socket programming?

Answer: Socket programming is a programming technique used to build applications that communicate over a network using sockets.

24. Lesson Summary

  • Computer networking connects devices for communication and resource sharing.
  • PAN, LAN, WLAN, MAN and WAN are common network types.
  • Network topologies describe how network devices are connected.
  • Client-server and peer-to-peer are common network architectures.
  • Switches forward Ethernet frames, while routers forward IP packets between networks.
  • The OSI reference model contains seven layers.
  • The commonly used TCP/IP model contains four layers.
  • TCP provides reliable, ordered byte-stream transport.
  • UDP provides connectionless datagram transport.
  • IP addresses identify endpoints for IP communication.
  • MAC addresses are used for link-layer communication.
  • Port numbers identify transport-layer application endpoints.
  • Linux provides commands such as ip, ping, ss and hostname for network inspection.
  • VirtualBox supports NAT, Bridged, Host-Only and Internal Network modes.
