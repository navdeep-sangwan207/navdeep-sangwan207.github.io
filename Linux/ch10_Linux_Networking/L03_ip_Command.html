1. Introduction to the ip Command

The ip command is a modern Linux networking utility used to display and configure network interfaces, IP addresses, routing tables and other networking objects.

It is part of the iproute2 utility suite, which is commonly available on modern Linux distributions.

Why Is the ip Command Used?

  • Display network interfaces.
  • Check interface operational state.
  • Display IPv4 and IPv6 addresses.
  • Assign and remove IP addresses.
  • Enable and disable network interfaces.
  • Display and modify routing information.
  • Inspect network configuration during troubleshooting.

Basic Syntax

ip [ OPTIONS ] OBJECT COMMAND
Component Description
ip Networking utility.
OPTIONS Optional command-line options.
OBJECT Network object such as link, addr or route.
COMMAND Operation performed on the selected object.

Common Objects

Object Purpose
link Network interface properties and state.
addr IP addresses assigned to interfaces.
route IP routing table.
neigh Neighbor table, such as IPv4 ARP entries.
rule Policy routing rules.

2. Display All Network Interfaces

The ip link show command displays the network interfaces available on the Linux system.

Command

ip link show

Example Output

1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536
    link/loopback 00:00:00:00:00:00

2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    link/ether 08:00:27:12:34:56

Explanation

  • lo: Loopback interface.
  • enp0s3: Example Ethernet interface name.
  • UP: Interface is administratively enabled.
  • LOWER_UP: Lower-layer link is operational.
  • mtu: Maximum Transmission Unit.
  • link/ether: Ethernet-style MAC address.

Display Interface Names Only

ip -o link show

The -o option displays each interface on a single line.

Display a Specific Interface

ip link show dev enp0s3
The interface name enp0s3 is an example. Run ip link show first and use the actual interface name shown on your Ubuntu system.

3. Enable and Disable a Network Interface

The ip link set command changes the administrative state of a network interface.

Bring an Interface Up

sudo ip link set enp0s3 up

This enables the interface administratively.

Bring an Interface Down

sudo ip link set enp0s3 down

This disables the interface administratively.

Verify Interface State

ip link show enp0s3
Command Purpose
ip link set enp0s3 up Enable interface.
ip link set enp0s3 down Disable interface.
ip link show enp0s3 Inspect interface state.
Disabling an active network interface can disconnect your system from the network. Do not run the down command on the interface carrying an important remote session.

4. Display IP Addresses

The ip addr command displays IP addresses assigned to network interfaces.

Display All IP Addresses

ip addr show

Short Form

ip a

Display IPv4 Addresses Only

ip -4 addr show

Display IPv6 Addresses Only

ip -6 addr show

Display Addresses of a Specific Interface

ip addr show dev enp0s3

Example Output

2: enp0s3:
    inet 192.168.1.10/24
    inet6 fe80::a00:27ff:fe12:3456/64

Explanation

  • inet: IPv4 address.
  • inet6: IPv6 address.
  • /24: IPv4 network prefix length.
  • /64: IPv6 network prefix length in this example.

5. Add an IP Address to an Interface

The ip addr add command adds an IP address to a network interface.

Syntax

sudo ip addr add IP_ADDRESS/PREFIX dev INTERFACE

Example

sudo ip addr add 192.168.1.50/24 dev enp0s3

This attempts to add the IPv4 address 192.168.1.50/24 to interface enp0s3.

Verify the Address

ip addr show dev enp0s3

Add an IPv6 Address

sudo ip -6 addr add 2001:db8:1::50/64 dev enp0s3

This is an illustrative documentation-prefix address, not a normal globally routable production address.

Addresses added using the ip command are generally temporary. They may disappear after reboot or be replaced by a network management service such as NetworkManager or systemd-networkd.
Before assigning an address, verify that it belongs to the intended subnet and is not already in use. A duplicate address can disrupt network communication.

6. Remove an IP Address

The ip addr del command removes a specified IP address from a network interface.

Syntax

sudo ip addr del IP_ADDRESS/PREFIX dev INTERFACE

Example

sudo ip addr del 192.168.1.50/24 dev enp0s3

Verify Removal

ip addr show dev enp0s3

The specified address should no longer appear on the interface.

7. Display the Routing Table

A routing table contains information that Linux uses to decide where to forward IP packets.

Display IPv4 Routing Table

ip route show

Short Form

ip r

Display IPv6 Routing Table

ip -6 route show

Example Output

default via 192.168.1.1 dev enp0s3
192.168.1.0/24 dev enp0s3 proto kernel scope link

Explanation

  • default: Default route used when no more specific route matches.
  • via 192.168.1.1: Next-hop gateway.
  • dev enp0s3: Outgoing network interface.
  • 192.168.1.0/24: Connected network route.
  • scope link: Destination is directly reachable on the link.

8. Add a Default Route

The ip route add default command adds a default route through a specified gateway.

Syntax

sudo ip route add default via GATEWAY_IP dev INTERFACE

Example

sudo ip route add default via 192.168.1.1 dev enp0s3

This adds a default route using 192.168.1.1 as the next-hop gateway.

Verify the Route

ip route show
Do not add a gateway blindly. The gateway must be reachable through the selected interface and must match your actual network configuration. Adding a conflicting default route can change or interrupt connectivity.

9. Delete a Route

The ip route del command removes a route from the routing table.

Delete a Default Route

sudo ip route del default

Delete a Specific Network Route

sudo ip route del 192.168.1.0/24

Verify the Routing Table

ip route show
Removing an active default route can prevent your system from reaching networks outside the local subnet. Use these commands only in a controlled lab environment.

10. Find the Route to a Destination

The ip route get command displays the route Linux would select for a specified destination.

Syntax

ip route get DESTINATION_IP

Example

ip route get 8.8.8.8

Illustrative Output

8.8.8.8 via 192.168.1.1 dev enp0s3
    src 192.168.1.10

In this example:

  • 8.8.8.8: Destination address.
  • via 192.168.1.1: Next-hop gateway.
  • dev enp0s3: Selected interface.
  • src 192.168.1.10: Selected source address.

11. Display Neighbor Information

The ip neigh command displays the neighbor table used for address resolution on local network links.

For IPv4 Ethernet networks, this table commonly contains ARP-related mappings between IP addresses and MAC addresses. IPv6 uses Neighbor Discovery.

Display Neighbor Table

ip neigh show

Example Output

192.168.1.1 dev enp0s3 lladdr 00:11:22:33:44:55 REACHABLE

Explanation

  • 192.168.1.1: Neighbor IP address.
  • dev enp0s3: Interface used to reach the neighbor.
  • lladdr: Link-layer address, commonly a MAC address.
  • REACHABLE: Neighbor reachability is currently confirmed.

Display Neighbors for One Interface

ip neigh show dev enp0s3

Delete a Neighbor Entry

sudo ip neigh del 192.168.1.1 dev enp0s3
Neighbor states can include REACHABLE, STALE, DELAY, PROBE, FAILED and INCOMPLETE. These states describe the neighbor reachability and address-resolution process.

12. Display Network Interface Statistics

The ip -s link command displays interface statistics, including received and transmitted packets, bytes and errors.

Command

ip -s link show

Display Statistics for One Interface

ip -s link show dev enp0s3

Common Statistics

Field Meaning
RX Received traffic.
TX Transmitted traffic.
bytes Total bytes transferred.
packets Number of packets.
errors Reported receive or transmit errors.
dropped Packets dropped by the interface or networking stack.

These statistics can help identify network performance problems.

13. Useful ip Command Options

14. ip Command vs ifconfig

ifconfig is a legacy networking utility provided by the net-tools package. The ip command is the modern replacement for many of its interface and address-management functions.

Operation Modern ip Command Legacy ifconfig
Display interfaces ip link show ifconfig -a
Display IP addresses ip addr show ifconfig
Enable interface ip link set eth0 up ifconfig eth0 up
Disable interface ip link set eth0 down ifconfig eth0 down
Assign IPv4 address ip addr add 192.168.1.10/24 dev eth0 ifconfig eth0 192.168.1.10 netmask 255.255.255.0
Recommendation:

Learn and use the ip command for modern Linux network administration. The next lesson covers the ping command for testing network reachability.

Objective: Understand how to add and remove an IP address using the ip command.

Perform this lab only if you understand your VM's current network configuration. Use an unused address in the correct subnet. Do not replace or remove the existing DHCP address. Avoid changing the active network interface remotely.

Step 1: Identify Your Interface

ip -br addr

Step 2: Select an Unused Test Address

For example, in an isolated test network where the address is confirmed unused:

192.168.1.50/24

Step 3: Add the Address

sudo ip addr add 192.168.1.50/24 dev enp0s3

Step 4: Verify the Address

ip addr show dev enp0s3

sudo ip addr del 192.168.1.50/24 dev enp0s3

This lab demonstrates temporary address management. For permanent configuration, use the network configuration system appropriate to your Ubuntu installation, such as Netplan or NetworkManager.

17. Common Troubleshooting Situations

Problem 1: Network Interface Is Down

Inspect the interface:

ip link show

If appropriate, enable it:

sudo ip link set enp0s3 up

Problem 2: No IP Address Assigned

Inspect address configuration:

ip addr show

Check the DHCP or static configuration managed by your network service.

Problem 3: Default Gateway Is Missing

Inspect the route table:

ip route

Problem 4: Network Interface Has Packet Errors

Inspect interface statistics:

ip -s link show

Problem 5: Neighbor Resolution Is Failing

Inspect the neighbor table:

ip neigh show

Problem 6: Verify the Selected Route

ip route get 1.1.1.1
The ip command helps inspect the local networking configuration. It does not by itself prove that a remote host, DNS service or internet connection is working.

19. Interview Questions and Answers

Q1. What is the ip command in Linux?

Answer: It is a command-line networking utility used to inspect and manage network interfaces, IP addresses, routing tables and neighbor entries.

Q2. Which package provides the ip command?

Answer: The ip command is part of the iproute2 utility suite.

Q3. What is the difference between ip link and ip addr?

Answer: ip link manages interface-level properties and state, while ip addr displays and manages IP addresses assigned to interfaces.

Q4. How do you display all network interfaces?

Answer: Use ip link show.

Q5. How do you display IP addresses?

Answer: Use ip addr show or ip a.

Q6. How do you enable a network interface?

Answer: Use sudo ip link set INTERFACE up.

Q7. How do you disable a network interface?

Answer: Use sudo ip link set INTERFACE down.

Q8. How do you assign an IP address?

Answer: Use sudo ip addr add ADDRESS/PREFIX dev INTERFACE.

Q9. How do you remove an IP address?

Answer: Use sudo ip addr del ADDRESS/PREFIX dev INTERFACE.

Q10. How do you display the routing table?

Answer: Use ip route show.

Q11. What does ip route get do?

Answer: It shows the route and source address Linux would select for a destination.

Q12. What is the purpose of ip neigh?

Answer: It displays and manages neighbor entries used for local link-layer address resolution.

Q13. How do you display interface statistics?

Answer: Use ip -s link show.

Q14. What is the difference between ip and ifconfig?

Answer: ip is the modern iproute2 utility, while ifconfig is a legacy net-tools utility.

Q15. Are ip command configuration changes permanent?

Answer: Generally, no. Changes made directly using ip commands are runtime changes and normally do not persist after reboot. Persistent settings should be configured through the system's network management service.
