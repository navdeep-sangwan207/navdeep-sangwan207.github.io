ifconfig and netstat Commands

Inspect network interfaces, connections, listening ports and network statistics

Home Linux Course Chapter 10

Learning Objectives

After completing this lesson, you will be able to:

  • Understand the purpose of ifconfig and netstat.
  • Display network interface information using ifconfig.
  • Understand IP addresses, MAC addresses and interface statistics.
  • Enable and disable interfaces using ifconfig.
  • Display active network connections using netstat.
  • Identify listening ports and network services.
  • Display routing tables and network statistics.
  • Understand the modern alternatives to these legacy utilities.

1. Introduction to ifconfig

ifconfig stands for Interface Configuration.

It is a traditional Linux command-line utility used to display and configure network interfaces.

It belongs to the older net-tools package.

Why Is ifconfig Used?

  • Display network interface information.
  • View IPv4 addresses and network masks.
  • Inspect MAC addresses.
  • Check interface status.
  • Enable or disable interfaces.
  • Configure certain interface parameters.
  • View received and transmitted packet statistics.

Basic Syntax

ifconfig [INTERFACE] [OPTIONS]

Display Available Active Interfaces

ifconfig

When called without an interface name, ifconfig generally displays information about active interfaces.

2. Install ifconfig in Ubuntu

On many modern Ubuntu installations, ifconfig is not installed by default.

It is provided by the net-tools package.

Step 1: Update Package Lists

sudo apt update

Step 2: Install net-tools

sudo apt install net-tools

Step 3: Verify Installation

ifconfig

Check the Command Location

which ifconfig
The modern replacement for many ifconfig operations is the ip command from the iproute2 package. For new Linux administration work, prefer learning iproute2.

ifconfig

        broadcast 192.168.1.255
        ether 08:00:27:12:34:56

lo: flags=73<UP,LOOPBACK,RUNNING>  mtu 65536

Explanation of Output

Field Meaning
enp0s3 Example Ethernet interface name.

4. Display Information for a Specific Interface

Specify an interface name to display its information.

Command

ifconfig enp0s3

Replace enp0s3 with the actual interface name on your system.

Display All Interfaces, Including Inactive Ones

ifconfig -a

The -a option displays all interfaces, including those that are not currently active.

Compare the Commands

Command Purpose
ifconfig Display active interfaces.
ifconfig -a Display all interfaces.
ifconfig enp0s3 Display one specific interface.

5. Enable and Disable a Network Interface

ifconfig can change the administrative state of a network interface.

Enable an Interface

sudo ifconfig enp0s3 up

Disable an Interface

sudo ifconfig enp0s3 down

Verify the Interface

ifconfig enp0s3
Disabling an active interface can disconnect your computer from the network. Do not disable your active VirtualBox network adapter during a remote session or while depending on that connection.

6. Assign an IPv4 Address Using ifconfig

ifconfig can assign an IPv4 address and network mask to an interface.

Syntax

sudo ifconfig INTERFACE IP_ADDRESS netmask NETMASK

Example

sudo ifconfig enp0s3 192.168.1.50 netmask 255.255.255.0

This attempts to configure the interface with the specified address and subnet mask.

Verify the Configuration

ifconfig enp0s3
Use only an unused address that belongs to the correct subnet. This command does not automatically configure DNS or a default gateway. NetworkManager, Netplan or another network manager may also replace manually configured settings.

7. Change the MTU

MTU (Maximum Transmission Unit) specifies the maximum size of a network-layer packet that can be transmitted over a link without fragmentation at that layer.

Display Interface MTU

ifconfig enp0s3

Set MTU to 1400 Bytes

sudo ifconfig enp0s3 mtu 1400

This changes the MTU setting for the interface at runtime, if supported.

The usual Ethernet MTU is 1500 bytes. Do not change the MTU unless you understand the network path and its requirements. A mismatched MTU can cause connectivity problems.

8. Introduction to netstat

netstat stands for Network Statistics.

It is a traditional Linux command-line utility used to display network connections, listening sockets, routing tables and network protocol statistics.

It is part of the older net-tools package.

Why Is netstat Used?

  • Display active network connections.
  • Identify listening TCP and UDP ports.
  • View routing table information.
  • Display network interface statistics.
  • Inspect network protocol statistics.
  • Help identify which services are listening for connections.

Basic Syntax

netstat [OPTIONS]

9. Install netstat in Ubuntu

netstat is also provided by the net-tools package.

Install net-tools

sudo apt update sudo apt install net-tools

Verify Installation

netstat --version

Check the Command Location

which netstat
Modern Linux systems commonly use ss from the iproute2 package as the replacement for many netstat operations. The ip command is preferred for interface and routing configuration.

10. Display Network Connections

Use netstat without options to display network connections and listening sockets, subject to the system's available address families and implementation defaults.

Command

netstat

Display All Connections

netstat -a

The -a option displays listening and non-listening sockets.

Display Numerical Addresses

netstat -n

The -n option displays numerical addresses and port numbers instead of resolving them into hostnames or service names.

Combine Options

netstat -an

This displays network connections and listening sockets using numerical addresses.

11. Display Listening Ports

A listening socket is a socket waiting for incoming connection requests or datagrams.

Display Listening Sockets

netstat -l

Display Listening TCP Sockets

netstat -lt

Display Listening UDP Sockets

netstat -lu

Display Listening TCP and UDP Sockets

netstat -ltu

Display Numerical Listening TCP and UDP Sockets

netstat -lntu

Example Output

Proto  Recv-Q Send-Q Local Address     Foreign Address   State
tcp    0      0      0.0.0.0:22       0.0.0.0:*         LISTEN
tcp    0      0      127.0.0.1:631    0.0.0.0:*         LISTEN
udp    0      0      127.0.0.53:53    0.0.0.0:*

Explanation

  • Proto: Network protocol.
  • Recv-Q: Data received but not yet read by the application, or protocol-specific queued data.
  • Send-Q: Data queued for transmission or protocol-specific queued data.
  • Local Address: Local IP address and port.
  • Foreign Address: Remote address and port.
  • LISTEN: TCP socket is waiting for incoming connections.
The example output is illustrative. The services and ports shown on your Ubuntu system will depend on which applications and network services are running.

12. Display TCP Connections

The -t option filters the output for TCP sockets.

Display TCP Connections

netstat -t

Display All TCP Connections

netstat -at

Display Numerical TCP Connections

netstat -ant

Common TCP States

State Meaning
LISTEN Waiting for incoming TCP connections.
ESTABLISHED Connection has been established.
TIME_WAIT Connection is waiting before final local cleanup.
CLOSE_WAIT Remote side has closed its connection; local application still needs to close its socket.
SYN_SENT Connection request has been sent.
SYN_RECV Connection request has been received and is awaiting completion.

13. Display UDP Connections

The -u option filters netstat output for UDP sockets.

Display UDP Sockets

netstat -u

Display All UDP Sockets

netstat -au

Display Numerical UDP Sockets

netstat -anu

UDP is a connectionless transport protocol. It does not establish a TCP-style connection, so UDP entries do not use TCP states such as LISTEN or ESTABLISHED in the same way.

14. Display Process Information

The -p option attempts to show the process ID and program name associated with a socket.

Command

sudo netstat -tulnp

Example Output

Proto  Local Address      State    PID/Program name
tcp    0.0.0.0:22         LISTEN   850/sshd
tcp    127.0.0.1:631      LISTEN   700/cupsd

In this example, the output associates listening TCP sockets with processes.

Process information may be incomplete without sufficient privileges. Some sockets may not show a process name if the associated process cannot be identified.

15. Display the Routing Table Using netstat

netstat can also display the kernel routing table.

Command

netstat -r

Display Numerical Routing Information

netstat -rn

Example Output

Kernel IP routing table
Destination     Gateway       Genmask         Flags Iface
0.0.0.0         192.168.1.1   0.0.0.0         UG    enp0s3
192.168.1.0     0.0.0.0       255.255.255.0   U     enp0s3

Common Routing Flags

Flag Meaning
U Route is up.
G Route uses a gateway.
H Route is to a specific host.

The Iface column identifies the interface used for the route.

16. Display Network Statistics

netstat can display statistics for network protocols and interfaces.

Display Protocol Statistics

netstat -s

This displays statistics for protocols such as IP, ICMP, TCP and UDP, depending on system support.

Display Network Interface Statistics

netstat -i

Display Extended Interface Information

netstat -ie

Example Output

Kernel Interface table
Iface    MTU   RX-OK   RX-ERR  TX-OK   TX-ERR
enp0s3   1500  1200    0       850     0
lo       65536 500     0       500     0

These statistics can help identify interface errors and packet transmission problems.

17. Important netstat Options

Option Purpose
-a Display listening and non-listening sockets.
-n Display numerical addresses and ports.
-t Display TCP sockets.
-u Display UDP sockets.
-l Display listening sockets.
-p Show process information when available and permitted.
-r Display the routing table.
-s Display protocol statistics.
-i Display network interface statistics.

Useful Combined Commands

netstat -an netstat -lnt netstat -lnu netstat -tuln sudo netstat -tulnp netstat -rn netstat -s netstat -i

18. Modern Alternatives: ip and ss

ifconfig and netstat are legacy utilities. Modern Linux systems generally use iproute2 tools for interface and route management, and ss for socket inspection.

Legacy Command Modern Alternative Purpose
ifconfig ip addr Display IP addresses.
ifconfig -a ip link show Display interfaces.
ifconfig eth0 up ip link set eth0 up Enable interface.
ifconfig eth0 down ip link set eth0 down Disable interface.
netstat -tuln ss -tuln Display listening TCP and UDP sockets.
netstat -an ss -an Display socket information.
netstat -r ip route Display routing table.
netstat -s ss -s Display socket summary (not identical protocol statistics).

Useful ss Commands

Display all TCP sockets:

ss -at

Display listening TCP sockets:

ss -lt

Display listening TCP and UDP sockets:

ss -tuln

Display process information:

sudo ss -tulnp

Display a socket summary:

ss -s
Important distinction: ss -s provides a socket summary; it is not a complete replacement for all protocol counters displayed by netstat -s. For detailed protocol statistics, also consider tools such as nstat.

22. Interview Questions and Answers

Q1. What is ifconfig?

Answer: ifconfig is a legacy Linux utility used to display and configure network interfaces.

Q2. What is netstat?

Answer: netstat is a legacy network utility used to display network connections, listening sockets, routing tables and network statistics.

Q3. Which package provides ifconfig and netstat?

Answer: Both commands are provided by the net-tools package.

Q4. How do you display all interfaces using ifconfig?

Answer: Use ifconfig -a.

Q5. How do you enable an interface using ifconfig?

Answer: Use sudo ifconfig INTERFACE up.

Q6. How do you display listening TCP ports?

Answer: Use netstat -lnt.

Q7. How do you display listening UDP ports?

Answer: Use netstat -lnu.

Q8. What is a listening port?

Answer: It is a local socket endpoint waiting for incoming connections or datagrams, depending on the transport protocol.

Q9. What does netstat -p display?

Answer: It attempts to display the process ID and program name associated with sockets.

Q10. What does netstat -r display?

Answer: It displays the kernel routing table.

Q11. What is the difference between TCP and UDP sockets?

Answer: TCP is connection-oriented and maintains connection states. UDP is connectionless and does not establish TCP-style connections.

Q12. What is the modern alternative to netstat?

Answer: The ss command from the iproute2 suite is the modern alternative for many socket inspection operations.

Q13. What is the modern alternative to ifconfig?

Answer: The ip command is the modern alternative for interface and address management.

Q14. What is the purpose of netstat -n?

Answer: It displays numerical addresses and port numbers instead of resolving them into names.

Q15. Why might netstat not be available on Ubuntu?

Answer: The net-tools package may not be installed by default. It can be installed using sudo apt install net-tools.

24. Lesson Summary

  • ifconfig stands for Interface Configuration.
  • netstat stands for Network Statistics.
  • Both are traditional utilities supplied by net-tools.
  • ifconfig displays active interface information.
  • ifconfig -a displays all interfaces.
  • ifconfig INTERFACE up enables an interface.
  • ifconfig INTERFACE down disables an interface.
  • netstat -an displays network sockets using numerical addresses.
  • netstat -lnt displays listening TCP sockets.
  • netstat -lnu displays listening UDP sockets.
  • netstat -tulnp displays listening TCP/UDP sockets and associated processes when available.
  • netstat -r displays the routing table.
  • netstat -s displays protocol statistics.
  • ip and ss are preferred modern alternatives for many tasks.
