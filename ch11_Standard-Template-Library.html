1. Introduction to STL

The Standard Template Library (STL) is a collection of generic classes and functions provided by the C++ Standard Library. It helps programmers work with data structures and algorithms without implementing everything from scratch.

Main Components

  • Containers: Store and organize data.
  • Iterators: Provide a way to access and traverse elements.
  • Algorithms: Perform operations such as sorting, searching and counting.
  • Function objects: Objects that can be called like functions.
  • Adapters: Provide specialized interfaces, such as stack and queue.

2. Containers in C++

Containers store collections of objects. Choose a container according to the operations and performance requirements of your program.

  • Sequence containers: vector, array, deque, list, forward_list.
  • Associative containers: set, multiset, map, multimap.
  • Unordered associative containers: unordered_set, unordered_multiset, unordered_map, unordered_multimap.
  • Container adapters: stack, queue, priority_queue.

3. Vector

A vector is a dynamic array that can grow or shrink during program execution. It supports fast random access by index.

Example

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    numbers.push_back(40);

    for (int value : numbers) {
        cout << value << " ";
    }

    return 0;
}

Expected Output

10 20 30 40

Useful Vector Functions

  • push_back(value) — adds an element at the end.
  • pop_back() — removes the last element.
  • size() — returns the number of elements.
  • empty() — checks whether the vector is empty.
  • at(index) — accesses an element with bounds checking.
  • clear() — removes all elements.

4. Array and List

Array

std::array is a fixed-size container whose size is known at compile time.

#include <iostream>
#include <array>
using namespace std;

int main() {
    array<int, 3> values = {10, 20, 30};

    for (int value : values)
        cout << value << " ";

    return 0;
}

Output: 10 20 30

List

std::list is a doubly linked list. It supports efficient insertion and removal at known positions, but does not provide direct random access by index.

#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> values = {10, 30};

    values.push_front(5);
    values.push_back(40);

    for (int value : values)
        cout << value << " ";

    return 0;
}

Output: 5 10 30 40

5. Stack

A stack follows the LIFO principle: Last In, First Out.

Example

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << s.top() << '\n';

    s.pop();

    cout << s.top() << '\n';

    return 0;
}

Expected Output

30
20

Common operations: push(), pop(), top(), size() and empty().

Check empty() before calling top() or pop().

6. Queue and Priority Queue

Queue

A queue follows FIFO: First In, First Out.

#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    q.push(10);
    q.push(20);
    q.push(30);

    cout << q.front() << '\n';
    q.pop();
    cout << q.front() << '\n';

    return 0;
}

Output:

10
20

Priority Queue

A default priority_queue returns the largest element first.

#include <iostream>
#include <queue>
using namespace std;

int main() {
    priority_queue<int> pq;

    pq.push(10);
    pq.push(50);
    pq.push(30);

    cout << pq.top();

    return 0;
}

Output: 50

To create a min-priority queue, use priority_queue<int, vector<int>, greater<int>> and include <functional>.

7. Set and Multiset

A set stores unique keys in sorted order. A multiset allows duplicate keys and also stores them in sorted order.

Example: Set

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> values = {30, 10, 20, 10};

    for (int value : values)
        cout << value << " ";

    return 0;
}

Output: 10 20 30

Useful operations include insert(), find(), count() and erase().

8. Map and Unordered Map

A map stores key-value pairs. Keys are unique, and std::map keeps them sorted by key. An unordered_map uses hashing and does not guarantee sorted order.

Example: Student Marks

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> marks;

    marks["Aman"] = 85;
    marks["Riya"] = 92;
    marks["Karan"] = 78;

    for (const auto& item : marks) {
        cout << item.first << ": "
             << item.second << '\n';
    }

    return 0;
}

Expected Output

Aman: 85
Karan: 78
Riya: 92

Useful operations: insert(), find(), erase(), count() and at().

9. Pair

std::pair groups two values, which may have different types.

#include <iostream>
#include <utility>
#include <string>
using namespace std;

int main() {
    pair<string, int> student = {"Aman", 85};

    cout << student.first << '\n';
    cout << student.second << '\n';

    return 0;
}

Expected Output

Aman
85

10. Iterators

Iterators provide a common way to access elements in containers. Many STL algorithms use iterators to identify the range on which they operate.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> values = {10, 20, 30};

    for (vector<int>::iterator it = values.begin();
         it != values.end(); ++it) {
        cout << *it << " ";
    }

    return 0;
}

Output: 10 20 30

  • begin() — iterator to the first element.
  • end() — iterator to the position just after the last element.
  • rbegin() and rend() — reverse-iteration boundaries for supported containers.
  • cbegin() and cend() — constant iterators.

Never dereference an end() iterator; it does not refer to an element.

11. STL Algorithms

The <algorithm> header provides reusable algorithms that work with iterator ranges.

Example: Sort, Find and Count

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> values = {40, 10, 30, 20, 10};

    sort(values.begin(), values.end());

    for (int value : values)
        cout << value << " ";

    cout << "\nCount of 10: "
         << count(values.begin(), values.end(), 10);

    auto it = find(values.begin(), values.end(), 30);

    if (it != values.end())
        cout << "\n30 found";

    return 0;
}

Expected Output

10 10 20 30 40
Count of 10: 2
30 found

Important Algorithms

  • sort() — sorts a range.
  • find() — finds a value in a range.
  • count() — counts matching values.
  • reverse() — reverses a range.
  • binary_search() — searches a sorted range.
  • max_element() and min_element() — locate the maximum and minimum elements.
  • unique() — moves consecutive duplicate values to the end of the logical range; combine with erase() to remove them from a vector.

Important: binary_search() requires the range to be sorted according to the same ordering used for the search.

12. Lambda Expressions

A lambda is an anonymous function object. It can be passed to algorithms to customize their behavior.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> values = {5, 2, 8, 1};

    sort(values.begin(), values.end(),
         [](int a, int b) {
             return a > b;
         });

    for (int value : values)
        cout << value << " ";

    return 0;
}

Output: 8 5 2 1

The lambda comparator sorts values in descending order.

13. Common STL Complexity

  • vector — random access is O(1); appending is amortized O(1).
  • list — insertion or removal at a known iterator is O(1); finding a position is generally O(n).
  • set and map — search, insertion and removal are generally O(log n).
  • unordered_map and unordered_set — average lookup and insertion are O(1), but worst cases can be O(n).
  • sort() — O(n log n) comparisons for a range of n elements.
  • stack and queue — their primary insertion and removal operations are generally O(1).

These are typical complexity guarantees; actual performance also depends on the operation and container.

14. Choosing the Right Container

  • Use vector for general-purpose sequences and fast indexed access.
  • Use array when the number of elements is fixed.
  • Use list when frequent insertion and removal at known positions are important.
  • Use stack for last-in-first-out processing.
  • Use queue for first-in-first-out processing.
  • Use priority_queue when the highest-priority item must be retrieved first.
  • Use set for unique sorted values.
  • Use map for unique sorted keys and associated values.
  • Use unordered containers when hash-based lookup is suitable and sorted order is unnecessary.

The STL provides reusable containers, iterators, algorithms, function objects and adapters. Understanding their behavior, complexity and appropriate use helps produce efficient, maintainable C++ programs.
