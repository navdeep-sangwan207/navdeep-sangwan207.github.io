Chapter 1: Introduction to C++

What is C++?

C++ is a general-purpose programming language that supports procedural, object-oriented and generic programming.

First C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!" << endl;
    return 0;
}

Expected Output

Hello, World!

Explanation

  • #include <iostream>: enables standard input and output.
  • main(): the program's entry point.
  • cout: displays output.
  • return 0;: indicates successful program completion.

Practice

Write a program to print your name, qualification and career goal.

Chapter 2: Variables and Data Types

A variable stores a value that a program can use or change. Common types include int, float, double, char and bool.

#include <iostream>
using namespace std;

int main()
{
    int age = 25;
    double voltage = 3.3;
    char grade = 'A';
    bool isLearning = true;

    cout << "Age: " << age << endl;
    cout << "Voltage: " << voltage << " V" << endl;
    cout << "Grade: " << grade << endl;
    cout << "Learning: " << isLearning << endl;

    return 0;
}

Expected Output

Age: 25
Voltage: 3.3 V
Grade: A
Learning: 1

By default, a Boolean value prints as 1 for true and 0 for false.

Practice

Declare variables for temperature, current, voltage and power. Print their values with suitable units.

Chapter 3: Operators and Control Statements

Operators perform calculations and comparisons. Control statements determine which instructions execute.

#include <iostream>
using namespace std;

int main()
{
    int number = 7;

    if (number % 2 == 0)
        cout << "Even number";
    else
        cout << "Odd number";

    return 0;
}

Expected Output

Odd number

Practice

Write programs to find the largest of two numbers and print the multiplication table of a number using a loop.

Chapter 4: Functions

A function is a reusable block of code that performs a particular task. Functions help make programs easier to test and maintain.

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    cout << "Sum: " << add(10, 20) << endl;
    return 0;
}

Expected Output

Sum: 30

Practice

Write a function to calculate the square of a number, then write another function to find the factorial of a positive integer.
