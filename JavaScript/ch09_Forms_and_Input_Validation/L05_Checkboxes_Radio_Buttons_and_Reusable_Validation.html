2. Understanding Checkboxes

A checkbox is an HTML form control that allows users to select or deselect an individual option.

Multiple checkboxes can be selected simultaneously. They are commonly used for selecting skills, interests, services and preferences.

HTML Syntax

<label>
    <input type="checkbox" id="html" value="HTML">
    HTML
</label>

<label>
    <input type="checkbox" id="css" value="CSS">
    CSS
</label>

<label>
    <input type="checkbox" id="javascript" value="JavaScript">
    JavaScript
</label>

Important Checkbox Properties

Property Purpose
checked Returns true if the checkbox is selected.
value Returns the checkbox's submitted value.
disabled Determines whether the control is disabled.
name Identifies the form field when submitting data.
indeterminate Sets or reads the visual indeterminate state.

Example 1: Reading a Single Checkbox

<input type="checkbox" id="terms">
<label for="terms">Accept Terms</label>

<button id="checkButton">Check Selection</button>

<p id="result"></p>

<script>
const terms = document.getElementById("terms");
const button = document.getElementById("checkButton");
const result = document.getElementById("result");

button.addEventListener("click", function() {

    if (terms.checked) {
        result.textContent = "Terms accepted.";
    } else {
        result.textContent = "Please accept the terms.";
    }

});
</script>

Expected Behavior:

  • If the checkbox is selected, the message is "Terms accepted."
  • If it is not selected, the message asks the user to accept the terms.

Example 2: Reading Multiple Checkboxes

<label>
    <input type="checkbox" name="skills" value="HTML">
    HTML
</label>

<label>
    <input type="checkbox" name="skills" value="CSS">
    CSS
</label>

<label>
    <input type="checkbox" name="skills" value="JavaScript">
    JavaScript
</label>

<button id="showSkills">Show Skills</button>

<p id="output"></p>

<script>
const checkboxes =
    document.querySelectorAll('input[name="skills"]');

document.getElementById("showSkills")
    .addEventListener("click", function() {

        const selectedSkills = [];

        checkboxes.forEach(function(checkbox) {

            if (checkbox.checked) {
                selectedSkills.push(checkbox.value);
            }

        });

        document.getElementById("output").textContent =
            selectedSkills.length > 0
                ? selectedSkills.join(", ")
                : "No skills selected.";

    });
</script>

Example Output:

HTML, CSS, JavaScript

The output depends on which checkboxes the user selects.

3. Using querySelectorAll() for Checkboxes

The querySelectorAll() method returns a static NodeList containing all elements that match a CSS selector. 

const checkboxes =
    document.querySelectorAll('input[name="skills"]');

console.log(checkboxes.length);

If three matching checkboxes exist, the output is: 

3

Using Array.from()

A NodeList can be converted into an array to use array methods such as filter() and map(). 

const checkboxes = document.querySelectorAll(
    'input[name="skills"]'
);

const selectedSkills = Array.from(checkboxes)
    .filter(checkbox => checkbox.checked)
    .map(checkbox => checkbox.value);

console.log(selectedSkills);

Example Output:

["HTML", "JavaScript"]

Using the :checked Selector

The CSS pseudo-class :checked selects currently checked checkbox and radio controls. 

const selected = document.querySelectorAll(
    'input[name="skills"]:checked'
);

const values = Array.from(selected)
    .map(input => input.value);

console.log(values);

Only currently selected controls are included in the result.

4. Understanding Radio Buttons

A radio button allows a user to select one option from a group of mutually exclusive choices.

Radio buttons belonging to the same group should have the same name attribute.

HTML Syntax

<label>
    <input type="radio" name="gender" value="Male">
    Male
</label>

<label>
    <input type="radio" name="gender" value="Female">
    Female
</label>

<label>
    <input type="radio" name="gender" value="Other">
    Other
</label>

Important Radio Button Properties

Property Purpose
checked Indicates whether a radio button is selected.
value Contains the value submitted for the selected option.
name Groups radio buttons into a mutually exclusive set.
required Requires a selection from the radio group.

Example 3: Reading a Selected Radio Button

<label>
    <input type="radio" name="course" value="C">
    C
</label>

<label>
    <input type="radio" name="course" value="JavaScript">
    JavaScript
</label>

<button id="showCourse">Show Course</button>

<p id="result"></p>

<script>
document.getElementById("showCourse")
    .addEventListener("click", function() {

        const selectedCourse =
            document.querySelector(
                'input[name="course"]:checked'
            );

        const result = document.getElementById("result");

        if (selectedCourse) {
            result.textContent =
                "Selected course: " + selectedCourse.value;
        } else {
            result.textContent = "Please select a course.";
        }

    });
</script>

Example Output:

Selected course: JavaScript

Important Difference

  • querySelector() returns the first matching element.
  • querySelectorAll() returns all matching elements.
  • :checked filters controls based on their current selection state.

5. Validating Required Checkbox Selection

Some forms require users to select at least one checkbox from a group. For example, a user may need to select at least one programming skill.

Example 4: At Least One Checkbox Must Be Selected

const skills = document.querySelectorAll(
    'input[name="skills"]'
);

function validateSkills() {

    const selectedSkills = Array.from(skills)
        .filter(skill => skill.checked);

    if (selectedSkills.length === 0) {
        return false;
    }

    return true;
}

console.log(validateSkills());

The function returns false if no checkbox is selected. Otherwise, it returns true.

Reusable Version

function validateAtLeastOneChecked(selector) {

    const checkedItems = document.querySelectorAll(
        selector + ":checked"
    );

    return checkedItems.length > 0;
}

// Usage
const isValid = validateAtLeastOneChecked(
    'input[name="skills"]'
);

console.log(isValid);
Placement Tip: This is a common form validation problem. A clean solution uses querySelectorAll(":checked") and checks the resulting collection's length.

6. Validating Radio Button Selection

A radio group may require the user to select exactly one option. Use a shared name attribute and check whether a selected radio button exists.

Example 5: Required Radio Selection

function validateRadioGroup(groupName) {

    const selectedOption = document.querySelector(
        `input[name="${groupName}"]:checked`
    );

    return selectedOption !== null;
}

// Usage
const isValid = validateRadioGroup("course");

console.log(isValid);

The function returns true if an option is selected and false otherwise.

Getting the Selected Value

function getSelectedRadioValue(groupName) {

    const selectedOption = document.querySelector(
        `input[name="${groupName}"]:checked`
    );

    return selectedOption ? selectedOption.value : null;
}

const course = getSelectedRadioValue("course");

console.log(course);

If the user selects JavaScript, the result is: 

JavaScript

7. Using FormData with Checkboxes and Radio Buttons

The FormData API collects successful form controls and their submitted values.

Example 6: Collecting Selected Values

<form id="courseForm">

    <label>
        <input type="checkbox"
               name="skills"
               value="HTML">
        HTML
    </label>

    <label>
        <input type="checkbox"
               name="skills"
               value="CSS">
        CSS
    </label>

    <label>
        <input type="checkbox"
               name="skills"
               value="JavaScript">
        JavaScript
    </label>

    <hr>

    <label>
        <input type="radio"
               name="level"
               value="Beginner">
        Beginner
    </label>

    <label>
        <input type="radio"
               name="level"
               value="Advanced">
        Advanced
    </label>

    <button type="submit">Submit</button>

</form>

<script>
const form = document.getElementById("courseForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    const formData = new FormData(form);

    const skills = formData.getAll("skills");
    const level = formData.get("level");

    console.log("Skills:", skills);
    console.log("Level:", level);

});
</script>

Example Output:

Skills: ["HTML", "JavaScript"]
Level: "Advanced"

Only checked checkboxes and the selected radio button are included in the submitted form data.

Important: FormData.get() returns the first value associated with a name. FormData.getAll() returns all values associated with that name.

8. Validating Terms and Conditions

Registration forms often require users to accept terms and conditions before submission.

Example 7: Terms Acceptance Validation

<form id="registrationForm">

    <label>
        <input type="checkbox" id="terms">
        I accept the terms and conditions.
    </label>

    <p id="message"></p>

    <button type="submit">Register</button>

</form>

<script>
const form = document.getElementById("registrationForm");
const terms = document.getElementById("terms");
const message = document.getElementById("message");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    if (!terms.checked) {

        message.textContent =
            "You must accept the terms and conditions.";

        message.style.color = "red";

        return;
    }

    message.textContent =
        "Terms accepted. Form validation passed.";

    message.style.color = "green";

});
</script>

Expected Behavior:

  • Submission is rejected when the checkbox is not selected.
  • Submission passes this check when the checkbox is selected.

9. Reusable Validation Functions

Reusable functions reduce code duplication and make form validation easier to maintain.

Example 8: Generic Required Field Validator

function validateRequired(value) {

    return value.trim() !== "";

}

console.log(validateRequired("Navdeep"));
console.log(validateRequired(""));
console.log(validateRequired("   "));

Output:

true
false
false

Example 9: Reusable Regex Validator

function validatePattern(value, pattern) {

    return pattern.test(value);

}

const usernamePattern = /^[A-Za-z0-9_]{5,15}$/;

console.log(
    validatePattern("rahul123", usernamePattern)
);

console.log(
    validatePattern("abc", usernamePattern)
);

Output:

true
false

Example 10: Reusable Checkbox Validator

function validateCheckbox(element) {

    return element.checked;

}

const terms = document.getElementById("terms");

console.log(validateCheckbox(terms));

Example 11: Reusable Radio Group Validator

function validateRadioGroup(groupName) {

    return document.querySelector(
        `input[name="${groupName}"]:checked`
    ) !== null;

}

console.log(validateRadioGroup("gender"));

Example 12: Reusable Checkbox Group Validator

function validateCheckboxGroup(groupName, minimum = 1) {

    const selected = document.querySelectorAll(
        `input[name="${groupName}"]:checked`
    );

    return selected.length >= minimum;

}

// At least one skill must be selected.
console.log(validateCheckboxGroup("skills"));

// At least two skills must be selected.
console.log(validateCheckboxGroup("skills", 2));

These functions can be reused across multiple forms by passing the appropriate values and group names.

10. Complete Practical Example: Registration Form

This example combines text inputs, email validation, radio buttons, checkboxes, terms acceptance and reusable validation functions.

Complete HTML, CSS and JavaScript Code

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Registration Form</title>

    <style>
        body {
            font-family: Arial, sans-serif;
        }

        form {
            max-width: 450px;
            display: grid;
            gap: 12px;
        }

        input[type="text"],
        input[type="email"] {
            padding: 9px;
        }

        button {
            padding: 10px;
            background: #174ea6;
            color: white;
            border: none;
            cursor: pointer;
        }

        .error {
            color: red;
        }

        .success {
            color: green;
        }
    </style>
</head>

<body>

    <h2>Student Registration</h2>

    <form id="registrationForm" novalidate>

        <label for="name">Full Name</label>
        <input type="text" id="name">

        <label for="email">Email</label>
        <input type="email" id="email">

        <h3>Select Gender</h3>

        <label>
            <input type="radio" name="gender" value="Male">
            Male
        </label>

        <label>
            <input type="radio" name="gender" value="Female">
            Female
        </label>

        <label>
            <input type="radio" name="gender" value="Other">
            Other
        </label>

        <h3>Select Skills</h3>

        <label>
            <input type="checkbox" name="skills" value="HTML">
            HTML
        </label>

        <label>
            <input type="checkbox" name="skills" value="CSS">
            CSS
        </label>

        <label>
            <input type="checkbox" name="skills" value="JavaScript">
            JavaScript
        </label>

        <label>
            <input type="checkbox" name="skills" value="React">
            React
        </label>

        <label>
            <input type="checkbox" id="terms">
            I accept the terms and conditions.
        </label>

        <button type="submit">Register</button>

    </form>

    <p id="message"></p>

    <script>

    const form = document.getElementById("registrationForm");

    const nameInput = document.getElementById("name");
    const emailInput = document.getElementById("email");
    const terms = document.getElementById("terms");
    const message = document.getElementById("message");

    const emailPattern =
        /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

    function validateRequired(value) {
        return value.trim() !== "";
    }

    function validateEmail(value) {
        return emailPattern.test(value);
    }

    function validateRadioGroup(groupName) {

        return document.querySelector(
            `input[name="${groupName}"]:checked`
        ) !== null;

    }

    function validateCheckboxGroup(groupName, minimum = 1) {

        const selected = document.querySelectorAll(
            `input[name="${groupName}"]:checked`
        );

        return selected.length >= minimum;

    }

    function validateCheckbox(element) {
        return element.checked;
    }

    form.addEventListener("submit", function(event) {

        event.preventDefault();

        const isNameValid =
            validateRequired(nameInput.value);

        const isEmailValid =
            validateEmail(emailInput.value);

        const isGenderValid =
            validateRadioGroup("gender");

        const areSkillsValid =
            validateCheckboxGroup("skills", 1);

        const areTermsAccepted =
            validateCheckbox(terms);

        if (!isNameValid) {
            message.textContent = "Enter your name.";
            message.className = "error";
            return;
        }

        if (!isEmailValid) {
            message.textContent = "Enter a valid email.";
            message.className = "error";
            return;
        }

        if (!isGenderValid) {
            message.textContent = "Select your gender.";
            message.className = "error";
            return;
        }

        if (!areSkillsValid) {
            message.textContent = "Select at least one skill.";
            message.className = "error";
            return;
        }

        if (!areTermsAccepted) {
            message.textContent = "Accept the terms and conditions.";
            message.className = "error";
            return;
        }

        const formData = new FormData(form);

        const selectedSkills = formData.getAll("skills");
        const selectedGender = formData.get("gender");

        message.textContent =
            "Registration validation successful. " +
            "Gender: " + selectedGender +
            ". Skills: " + selectedSkills.join(", ");

        message.className = "success";

    });

    </script>

</body>
</html>

Expected Behavior

  • Name cannot be empty.
  • Email must match the basic email format.
  • One radio option must be selected.
  • At least one skill checkbox must be selected.
  • Terms and conditions must be accepted.
  • A success message appears after all validations pass.
Practical Application: This validation structure is useful for student registration, job application, course enrollment and account creation forms.

11. Common Mistakes and Debugging

Mistake Correct Approach
Reading value without checking checked. Check the checked property before using a checkbox value.
Giving radio buttons different names in one group. Use the same name attribute for mutually exclusive choices.
Using querySelector() to retrieve all selected checkboxes. Use querySelectorAll() for multiple selected elements.
Using FormData.get() for multiple checkbox values. Use getAll() when multiple values share the same name.
Checking only whether a checkbox exists. Check its checked property.
Forgetting preventDefault() in a demonstration submit handler. Prevent the default submission when handling the form entirely with JavaScript.
Assuming client-side validation is secure. Repeat validation on the server.

Important Difference: checked and value

const checkbox = document.querySelector(
    'input[name="skills"]'
);

console.log(checkbox.checked);
console.log(checkbox.value);

The checked property indicates selection state. The value property contains the configured form value. A checkbox can have a value even when it is not selected.

Important Difference: Default and Current Checked State

The checked property represents the current selection state. The defaultChecked property represents the initial checked state defined by the HTML attribute. 

<input type="checkbox" id="newsletter" checked>

<script>
const newsletter = document.getElementById("newsletter");

console.log(newsletter.checked);
console.log(newsletter.defaultChecked);
</script>

Initial Output:

true
true

If the user unchecks the box, checked becomes false, while defaultChecked remains true.

12. Placement Interview Questions and Answers

Q1. What is the difference between a checkbox and a radio button?

A checkbox allows independent selection of multiple options. A radio group allows only one selected option at a time.

Q2. What does the checked property return?

It returns a Boolean indicating whether a checkbox or radio button is currently selected.

Q3. How do you get all selected checkboxes?

Use querySelectorAll() with the :checked pseudo-class, then iterate over the returned NodeList.

Q4. How do you get the selected radio button?

Use querySelector() with a selector such as input[name="gender"]:checked.

Q5. Why should radio buttons have the same name?

The shared name groups radio buttons so the browser treats them as mutually exclusive options.

Q6. What is the difference between querySelector() and querySelectorAll()?

querySelector() returns the first matching element. querySelectorAll() returns a static NodeList of all matching elements.

Q7. How do you validate that at least one checkbox is selected?

Select checked checkboxes and verify that the collection length is greater than zero.

Q8. What is FormData.getAll()?

It returns all submitted values associated with a particular form field name.

Q9. What happens if no checkbox is selected?

An unchecked checkbox is not included in the submitted form data.

Q10. What is a reusable validation function?

It is a function designed to perform a validation task that can be called from different parts of an application without duplicating the logic.

Q11. How do you make a checkbox mandatory in HTML?

Add the required attribute to the checkbox. The browser prevents normal form submission until it is checked.

Q12. Can multiple radio buttons be selected in the same group?

No. A radio group with the same name permits only one selected option at a time.
