Lesson 1: Reading Form Values and Handling Submission

Chapter 9: Forms and Input Validation | JavaScript

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand HTML forms and their role in web applications.
  • Access form elements using JavaScript.
  • Read text, email, password and select field values.
  • Handle form submission using the submit event.
  • Prevent the browser's default form submission behavior.
  • Read multiple form values using the FormData API.
  • Process and display submitted form data.

2. Introduction to HTML Forms

An HTML form collects information from users. Forms are commonly used in registration pages, login systems, search interfaces, feedback pages and online applications.

Example of a simple HTML form:

<form id="registrationForm">

    <label for="username">Username:</label>
    <input type="text" id="username" name="username">

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <button type="submit">Register</button>

</form>

Important Form Attributes

Attribute Purpose
id Uniquely identifies an element in the document.
name Identifies a field when form data is submitted.
action Specifies the URL that receives the submitted form data.
method Specifies the HTTP method, commonly GET or POST.
type Defines the type of input control.
Important: The name attribute is essential when submitting form data through standard browser form submission or reading it using FormData.

3. Accessing Form Elements

JavaScript can access form elements through DOM methods. The most common approach is selecting the form by its ID and accessing its individual controls.

Example 1: Accessing Elements Using getElementById()

<form id="myForm">
    <input type="text" id="username" name="username">
    <input type="email" id="email" name="email">
</form>

<script>
const form = document.getElementById("myForm");

const username = document.getElementById("username");
const email = document.getElementById("email");

console.log(form);
console.log(username);
console.log(email);
</script>

Example 2: Accessing Elements Through the Form

const form = document.getElementById("myForm");

const username = form.elements["username"];
const email = form.elements["email"];

console.log(username);
console.log(email);

The form.elements collection provides access to the form's associated controls. Using their name attributes is particularly useful when working with forms.

Example 3: Accessing Form Controls Using querySelector()

const form = document.querySelector("#myForm");

const username = form.querySelector('[name="username"]');
const email = form.querySelector('[name="email"]');

console.log(username.value);
console.log(email.value);

4. Reading Form Values Using the value Property

The value property retrieves the current value entered or selected by the user in an input or select control.

Example 4: Reading Text Input

<input type="text" id="name" value="Navdeep">

<script>
const nameInput = document.getElementById("name");

console.log(nameInput.value);
</script>

Expected Output:

Navdeep

Example 5: Reading Email and Password Inputs

<input type="email" id="email" value="user@example.com">
<input type="password" id="password" value="abc123">

<script>
const email = document.getElementById("email").value;
const password = document.getElementById("password").value;

console.log(email);
console.log(password);
</script>

Expected Output:

user@example.com
abc123
Security warning: Passwords should not be logged to the console or unnecessarily displayed on the page. This example demonstrates how to read the value, not how to handle real authentication securely.

Example 6: Reading a Select Element

<select id="course">
    <option value="C">C Programming</option>
    <option value="CPP">C++ Programming</option>
    <option value="JS">JavaScript</option>
</select>

<script>
const course = document.getElementById("course");

console.log(course.value);
</script>

If the JavaScript code executes while the first option is selected, the output is: 

C

5. Understanding the Submit Event

The submit event occurs when a form is submitted. It can be triggered by:

  • Clicking a submit button.
  • Pressing Enter in certain form fields.
  • Calling form.requestSubmit() in JavaScript.

Example 7: Handling Form Submission

<form id="loginForm">
    <input type="text" name="username" id="username">
    <button type="submit">Login</button>
</form>

<script>
const form = document.getElementById("loginForm");

form.addEventListener("submit", function(event) {
    console.log("Form submitted");
});
</script>

The event listener executes when the form's submit event occurs. By default, the browser may navigate or reload the page according to the form's submission settings.

6. Preventing Default Form Submission

The preventDefault() method prevents the browser's default action associated with an event.

When used inside a form's submit event handler, it prevents the browser's normal form submission and allows JavaScript to process the form data.

Syntax

event.preventDefault();

Example 8: Preventing Page Reload

<form id="myForm">
    <input type="text" id="username" name="username">
    <button type="submit">Submit</button>
</form>

<script>
const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
    event.preventDefault();

    const username =
        document.getElementById("username").value;

    console.log("Username:", username);
});
</script>

Result:

  • The form's submit event is triggered.
  • The default browser submission is prevented.
  • JavaScript reads the username.
  • The page does not reload because of the normal form submission.
Placement concept: Explain why preventDefault() is commonly used in client-side form handling. It gives JavaScript control over validation and processing before data is sent to a server.

7. Complete Practical Example: Registration Form

This example collects a user's name, email and selected course. It prevents the default submission and displays the collected values on the same page.

Complete HTML and JavaScript Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Registration Form</title>
</head>
<body>

    <h2>Student Registration</h2>

    <form id="registrationForm">

        <label for="name">Name:</label>
        <input type="text" id="name" name="name" required>

        <br><br>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>

        <br><br>

        <label for="course">Course:</label>
        <select id="course" name="course" required>
            <option value="">Select a course</option>
            <option value="C">C Programming</option>
            <option value="CPP">C++ Programming</option>
            <option value="JavaScript">JavaScript</option>
        </select>

        <br><br>

        <button type="submit">Register</button>

    </form>

    <h3>Submitted Information</h3>
    <div id="output"></div>

    <script>
    const form =
        document.getElementById("registrationForm");

    const output =
        document.getElementById("output");

    form.addEventListener("submit", function(event) {

        event.preventDefault();

        const name =
            document.getElementById("name").value.trim();

        const email =
            document.getElementById("email").value.trim();

        const course =
            document.getElementById("course").value;

        output.textContent =
            "Name: " + name +
            " | Email: " + email +
            " | Course: " + course;

    });
    </script>

</body>
</html>

Expected Result

After entering the following information:

Field Example Value
Name Rahul
Email rahul@example.com
Course JavaScript

The page displays:

Name: Rahul | Email: rahul@example.com | Course: JavaScript

The page does not reload because the default submission behavior is prevented.

8. Introduction to the FormData API

The FormData API provides a convenient way to collect data from form controls that have a name attribute.

Syntax

const formData = new FormData(form);

Here, form is a reference to an HTML form element.

Example 9: Reading Values Using FormData

<form id="userForm">
    <input type="text" name="username" value="Rahul">
    <input type="email" name="email" value="rahul@example.com">
</form>

<script>
const form = document.getElementById("userForm");

const formData = new FormData(form);

console.log(formData.get("username"));
console.log(formData.get("email"));
</script>

Expected Output:

Rahul
rahul@example.com

Important FormData Methods

Method Description
get(name) Returns the first value associated with a field name.
getAll(name) Returns all values associated with a field name.
has(name) Checks whether a field name exists.
set(name, value) Adds or replaces a field value.
append(name, value) Adds another value under the same field name.
delete(name) Removes all values associated with a field name.
entries() Returns an iterator of key-value pairs.

Example 10: Iterating Through FormData

const form = document.getElementById("userForm");

const formData = new FormData(form);

for (const [key, value] of formData.entries()) {
    console.log(key, value);
}

Expected Output:

username Rahul
email rahul@example.com
Important: FormData includes successful form controls. Controls without a name, disabled controls and unchecked checkboxes or radio buttons are not included.

9. Practical Example: Working With Multiple Form Fields

The following example uses FormData to collect all submitted fields and display them without manually accessing each input.

Complete Code

<form id="employeeForm">

    <input type="text" name="employeeName"
           placeholder="Employee Name" required>

    <input type="email" name="employeeEmail"
           placeholder="Employee Email" required>

    <input type="text" name="department"
           placeholder="Department" required>

    <button type="submit">Submit</button>

</form>

<div id="result"></div>

<script>
const form = document.getElementById("employeeForm");
const result = document.getElementById("result");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    const formData = new FormData(form);

    const employee = Object.fromEntries(formData.entries());

    result.textContent =
        "Name: " + employee.employeeName +
        " | Email: " + employee.employeeEmail +
        " | Department: " + employee.department;

});
</script>

Object.fromEntries() converts the iterable key-value pairs into a regular JavaScript object.

Example Output:

{
    employeeName: "Amit",
    employeeEmail: "amit@example.com",
    department: "Development"
}

10. Common Mistakes and Debugging

Mistake Correct Approach
Using an incorrect element ID. Verify the ID in HTML and JavaScript.
Using innerHTML for untrusted user input. Prefer textContent for displaying plain text.
Forgetting preventDefault(). Call it when handling submission without normal navigation.
Missing name attributes. Add name attributes to controls collected through FormData.
Reading values before the DOM is available. Use a script with defer or wait for DOMContentLoaded.
Assuming client-side validation is sufficient. Validate submitted data on the server as well.

Example: Safe Display of User Input

// Avoid inserting untrusted input as HTML.
output.innerHTML = username;

// Safer for displaying plain text.
output.textContent = username;

11. Placement Interview Questions and Answers

Q1. What is an HTML form?

An HTML form is a container used to collect user input through controls such as text fields, email fields, checkboxes, radio buttons and select elements.

Q2. How do you access a form element in JavaScript?

By using DOM methods such as getElementById(), querySelector() or the form.elements collection.

Q3. What is the difference between value and textContent?

value retrieves the current value of form controls such as input and select elements. textContent reads or sets the text content of an element.

Q4. What is the submit event?

It is an event fired when a form is submitted, allowing JavaScript to validate and process the submitted data.

Q5. Why is preventDefault() used in form handling?

It prevents the browser's default form submission behavior, allowing JavaScript to process the data without normal navigation or page reload.

Q6. What is the FormData API?

FormData is a browser API used to collect form field values as key-value pairs. It is also useful for sending data through fetch() or XMLHttpRequest.

Q7. What is the difference between get() and getAll()?

get() returns the first value associated with a name, whereas getAll() returns an array containing all associated values.

Q8. Why is the name attribute important?

It identifies a form control when data is submitted using standard form submission or collected using FormData.

Q9. What is the difference between submit() and requestSubmit()?

submit() submits the form directly without triggering the submit event or performing interactive constraint validation. requestSubmit() behaves more like activating a submit button: it performs validation and dispatches the submit event when submission is allowed.

Q10. Does preventDefault() validate form data?

No. It only prevents the default browser action. Validation must be implemented separately using JavaScript or HTML constraint validation.

13. Lesson Summary

  • HTML forms collect information from users.
  • JavaScript accesses form controls through DOM methods.
  • The value property reads the current value of a control.
  • The submit event handles form submission.
  • preventDefault() prevents the browser's default submission behavior.
  • FormData collects named form controls as key-value pairs.
  • Object.fromEntries() converts iterable entries into an object.
  • Client-side validation does not replace server-side validation.
