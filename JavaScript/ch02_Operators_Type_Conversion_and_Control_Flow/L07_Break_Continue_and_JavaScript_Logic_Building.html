2. Introduction to Loop Control Statements

Loop control statements change the normal execution flow of loops. They allow a program to terminate a loop early or skip the current iteration.

JavaScript provides two important loop control statements:

Statement Purpose
break Terminates the nearest enclosing loop or switch statement.
continue Skips the remaining statements in the current loop iteration.
Important: Both statements are useful in searching, filtering, validation, data processing and nested-loop problems.

3. The break Statement

The break statement immediately terminates the nearest enclosing loop or switch statement.

After the loop terminates, execution continues with the statement immediately following that loop.

Syntax

break;

Example 1: Stop a Loop at a Specific Number

for (let i = 1; i <= 10; i++) {

    if (i === 6) {
        break;
    }

    console.log(i);
}

console.log("Loop terminated");
Expected Output: 
1
2
3
4
5
Loop terminated

When i becomes 6, the break statement terminates the loop. Numbers 6 to 10 are not printed.

Example 2: Search for an Element in an Array

let numbers = [10, 25, 30, 45, 50];
let target = 30;
let found = false;

for (let i = 0; i < numbers.length; i++) {

    if (numbers[i] === target) {
        found = true;
        console.log("Element found at index:", i);
        break;
    }
}

if (!found) {
    console.log("Element not found");
}
Expected Output: 
Element found at index: 2

Once the target is found, further comparisons are unnecessary. The break statement avoids additional iterations.

Example 3: Find the First Number Divisible by 7

for (let i = 1; i <= 50; i++) {

    if (i % 7 === 0) {
        console.log("First divisible number:", i);
        break;
    }
}
Expected Output: 
First divisible number: 7

Example 4: Stop When Invalid Data Is Found

let values = [10, 20, 30, -5, 40];

for (let i = 0; i < values.length; i++) {

    if (values[i] < 0) {
        console.log("Invalid value detected:", values[i]);
        break;
    }

    console.log("Processing:", values[i]);
}
Expected Output: 
Processing: 10
Processing: 20
Processing: 30
Invalid value detected: -5

4. The continue Statement

The continue statement skips the remaining statements in the current iteration and proceeds to the next iteration of the loop.

Syntax

continue;

Example 1: Skip a Specific Number

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}
Expected Output: 
1
2
4
5

When i becomes 3, the current iteration is skipped. The loop continues with the next value, which is 4.

Example 2: Print Only Even Numbers

for (let i = 1; i <= 10; i++) {

    if (i % 2 !== 0) {
        continue;
    }

    console.log(i);
}
Expected Output: 
2
4
6
8
10

Example 3: Skip Empty Values

let names = ["Aman", "", "Ravi", "", "Neha"];

for (let i = 0; i < names.length; i++) {

    if (names[i] === "") {
        continue;
    }

    console.log("Name:", names[i]);
}
Expected Output: 
Name: Aman
Name: Ravi
Name: Neha

Example 4: Ignore Negative Numbers

let numbers = [10, -5, 20, -3, 30];

let sum = 0;

for (let i = 0; i < numbers.length; i++) {

    if (numbers[i] < 0) {
        continue;
    }

    sum += numbers[i];
}

console.log("Sum of non-negative numbers:", sum);
Expected Output: 
Sum of non-negative numbers: 60

5. Difference Between break and continue

Feature break continue
Purpose Terminates the loop. Skips the current iteration.
Remaining iterations Not executed. Continue normally.
Loop execution Exits the nearest enclosing loop. Moves to the next iteration.
Typical application Searching for a target. Filtering unwanted values.

Compare Both Statements

Using break:

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        break;
    }

    console.log(i);
}
Output: 
1
2

Using continue:

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue;
    }

    console.log(i);
}
Output: 
1
2
4
5
Interview point: break exits the loop; continue skips only the current iteration.

6. break and continue in Different Loops

6.1 Using break in a while Loop

let i = 1;

while (i <= 10) {

    if (i === 5) {
        break;
    }

    console.log(i);
    i++;
}
Expected Output: 
1
2
3
4

6.2 Using continue in a while Loop

Be careful when using continue in a while loop. If the update statement is skipped, the loop may become infinite. 

let i = 0;

while (i < 5) {

    i++;

    if (i === 3) {
        continue;
    }

    console.log(i);
}
Expected Output: 
1
2
4
5

The update i++ occurs before the continue statement. Therefore, the loop variable still changes when the iteration is skipped.

6.3 Using continue in a for Loop

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}
Expected Output: 
1
2
4
5
In a traditional for loop, the update expression still runs after continue. In a while loop, execution jumps directly to the condition check, so manual updates must be positioned carefully.

7. Labeled Statements in JavaScript

JavaScript supports labeled statements. A label gives a name to a statement, commonly a loop, so that a labeled break or continue can control that specific enclosing statement.

Syntax

outerLoop:
for (let i = 0; i < 3; i++) {
    // Loop statements
}

Example 1: Labeled break

outerLoop:
for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (i === 2 && j === 2) {
            break outerLoop;
        }

        console.log(i, j);
    }
}

console.log("Exited outer loop");
Expected Output: 
1 1
1 2
1 3
2 1
Exited outer loop

The labeled break terminates the outer loop directly, not just the inner loop.

Example 2: Labeled continue

outerLoop:
for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {
            continue outerLoop;
        }

        console.log(i, j);
    }
}
Expected Output: 
1 1
2 1
3 1

When j becomes 2, the continue statement moves directly to the next iteration of the labeled outer loop.

Best practice: Labeled statements are valid JavaScript, but they are rarely needed in everyday frontend code. Prefer clear loop conditions, helper functions or other straightforward control-flow techniques when possible.

8. Practical Applications of Loop Control

8.1 Search and Stop at the First Match

let users = [
    { id: 101, name: "Aman" },
    { id: 102, name: "Ravi" },
    { id: 103, name: "Neha" }
];

let targetId = 102;
let matchedUser = null;

for (let i = 0; i < users.length; i++) {

    if (users[i].id === targetId) {
        matchedUser = users[i];
        break;
    }
}

if (matchedUser !== null) {
    console.log("User found:", matchedUser.name);
} else {
    console.log("User not found");
}
Expected Output: 
User found: Ravi

8.2 Filter Invalid Records

let scores = [85, -1, 90, 105, 72, -5];

for (let i = 0; i < scores.length; i++) {

    if (scores[i] < 0 || scores[i] > 100) {
        continue;
    }

    console.log("Valid score:", scores[i]);
}
Expected Output: 
Valid score: 85
Valid score: 90
Valid score: 72

8.3 Stop Processing After a Limit

let orders = [101, 102, 103, 104, 105];
let processed = 0;
let maximumOrders = 3;

for (let i = 0; i < orders.length; i++) {

    if (processed >= maximumOrders) {
        break;
    }

    console.log("Processing order:", orders[i]);
    processed++;
}
Expected Output: 
Processing order: 101
Processing order: 102
Processing order: 103

8.4 Find the First Duplicate Element

let numbers = [10, 20, 30, 20, 40];

let duplicate = null;

for (let i = 0; i < numbers.length; i++) {

    for (let j = i + 1; j < numbers.length; j++) {

        if (numbers[i] === numbers[j]) {
            duplicate = numbers[i];
            break;
        }
    }

    if (duplicate !== null) {
        break;
    }
}

if (duplicate !== null) {
    console.log("First duplicate:", duplicate);
} else {
    console.log("No duplicate found");
}
Expected Output: 
First duplicate: 20

9. JavaScript Logic Building Techniques

Logic building is the ability to convert a problem statement into a sequence of clear, executable steps.

9.1 Understand the Problem

Before writing code, identify:

  • Input values.
  • Expected output.
  • Conditions and constraints.
  • Special and boundary cases.
  • Whether a loop or conditional statement is required.

9.2 Break the Problem into Steps

Consider the problem of finding the sum of even numbers from 1 to N.

  1. Read the value of N.
  2. Initialize sum to zero.
  3. Traverse numbers from 1 to N.
  4. Check whether each number is even.
  5. Add even numbers to sum.
  6. Display the final sum.
let n = 10;
let sum = 0;

for (let i = 1; i <= n; i++) {

    if (i % 2 !== 0) {
        continue;
    }

    sum += i;
}

console.log("Sum of even numbers:", sum);
Expected Output: 
Sum of even numbers: 30

9.3 Use Dry Runs

A dry run means manually tracing the program using sample input and recording how variables change.

9.4 Test Boundary Conditions

A correct solution should be tested with more than one ordinary input.

Test case Purpose
0 Check zero handling.
1 Check the smallest positive input.
Negative number Check invalid or negative input handling.
Large number Check performance and numeric limits.
Empty array Check collection boundary handling.

9.5 Choose an Appropriate Algorithm

Before using nested loops, consider whether a simpler algorithm can solve the problem.

For example, searching for an element in an unsorted array with a loop takes O(n) time in the worst case. Searching repeatedly using nested loops may increase the time complexity unnecessarily.

10. Placement Coding Problems

Problem 1: Check Whether a Number Is Prime

A prime number is greater than 1 and has exactly two positive divisors: 1 and itself. 

let number = 29;
let isPrime = number > 1;

for (let i = 2; i * i <= number && isPrime; i++) {

    if (number % i === 0) {
        isPrime = false;
        break;
    }
}

if (isPrime) {
    console.log(number, "is prime");
} else {
    console.log(number, "is not prime");
}
Expected Output: 
29 is prime

The loop checks divisors only up to the square root of the number. Once a divisor is found, break terminates the search.

Problem 2: Find the First Missing Positive Number in a Small Range

Given an array containing positive integers, find the smallest positive integer in the range 1 to N that is missing from the array. 

let numbers = [1, 2, 4, 5, 6];
let n = 6;
let missing = -1;

for (let value = 1; value <= n; value++) {

    let found = false;

    for (let i = 0; i < numbers.length; i++) {

        if (numbers[i] === value) {
            found = true;
            break;
        }
    }

    if (!found) {
        missing = value;
        break;
    }
}

console.log("Missing number:", missing);
Expected Output: 
Missing number: 3

This straightforward solution uses nested loops. Its worst-case time complexity is O(N × M), where N is the search range and M is the array length.

Problem 3: Check Whether a Number Is a Palindrome

let number = 121;
let original = number;
let reverse = 0;

while (number > 0) {

    let digit = number % 10;

    reverse = reverse * 10 + digit;

    number = Math.floor(number / 10);
}

if (original === reverse) {
    console.log("Palindrome number");
} else {
    console.log("Not a palindrome number");
}
Expected Output: 
Palindrome number

Problem 4: Find the First Pair with a Given Sum

let numbers = [2, 7, 11, 15];
let target = 9;

let found = false;

for (let i = 0; i < numbers.length; i++) {

    for (let j = i + 1; j < numbers.length; j++) {

        if (numbers[i] + numbers[j] === target) {
            console.log("Pair:", numbers[i], numbers[j]);
            found = true;
            break;
        }
    }

    if (found) {
        break;
    }
}

if (!found) {
    console.log("No pair found");
}
Expected Output: 
Pair: 2 7

This solution demonstrates nested-loop searching and early termination. Its worst-case time complexity is O(n²).

Problem 5: Count Occurrences of a Character

let text = "javascript";
let target = "a";
let count = 0;

for (let i = 0; i < text.length; i++) {

    if (text[i] !== target) {
        continue;
    }

    count++;
}

console.log("Occurrences:", count);
Expected Output: 
Occurrences: 2

Problem 6: Find the First Non-Repeating Character

let text = "swiss";
let result = null;

for (let i = 0; i < text.length; i++) {

    let count = 0;

    for (let j = 0; j < text.length; j++) {

        if (text[i] === text[j]) {
            count++;
        }
    }

    if (count === 1) {
        result = text[i];
        break;
    }
}

if (result !== null) {
    console.log("First non-repeating character:", result);
} else {
    console.log("No non-repeating character");
}
Expected Output: 
First non-repeating character: w

This simple solution uses nested loops and has O(n²) time complexity. More efficient approaches can use a frequency map to reduce the time complexity to O(n) on average.

11. Placement Interview Questions and Answers

Q1. What is the purpose of break in JavaScript?

It terminates the nearest enclosing loop or switch statement and transfers execution to the statement following it.

Q2. What is the purpose of continue?

It skips the remaining statements in the current loop iteration and proceeds to the next iteration.

Q3. What is the main difference between break and continue?

break terminates the loop, whereas continue skips only the current iteration.

Q4. Can break be used inside a switch statement?

Yes. It is commonly used to exit a switch case and prevent unintended fall-through.

Q5. Can continue be used inside a switch statement?

Not to exit the switch itself. A continue statement must target an enclosing iteration statement. It can appear inside a switch nested within a loop and continue that loop.

Q6. What is a labeled break?

A labeled break terminates a specific labeled enclosing statement, commonly an outer loop.

Q7. What is a labeled continue?

A labeled continue skips to the next iteration of the specified labeled enclosing loop.

Q8. Can break terminate all nested loops automatically?

No. An ordinary break exits only the nearest enclosing loop. A labeled break can exit a specifically labeled outer loop.

Q9. What is the use of break in linear search?

Once the target element is found, break terminates the search loop and avoids unnecessary comparisons.

Q10. What happens if continue is used before updating a while loop variable?

The update may be skipped. If the skipped update is necessary to make the condition false, the loop may become infinite.

Q11. What is dry running?

Dry running is manually tracing a program using sample input and recording variable values and execution flow.

Q12. Why should boundary conditions be tested?

Boundary testing helps identify errors involving zero, negative values, empty collections, minimum and maximum inputs.
