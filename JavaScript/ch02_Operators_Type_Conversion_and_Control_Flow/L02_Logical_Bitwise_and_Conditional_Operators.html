2. Logical Operators

Logical operators combine conditions or reverse their Boolean results. They are commonly used in form validation, authentication, access control and application decision-making.

2.1 Logical Operator Reference

Operator Name Purpose
&& Logical AND Evaluates conditions from left to right and stops at the first falsy operand.
|| Logical OR Evaluates conditions from left to right and stops at the first truthy operand.
! Logical NOT Converts a value to Boolean and reverses the result.

2.2 Logical AND (&&)

The logical AND operator evaluates its operands from left to right. It returns the first falsy operand, or the final operand if all operands are truthy.

For Boolean operands:

A B A && B
truetruetrue
truefalsefalse
falsetruefalse
falsefalsefalse
 
let age = 25;
let hasLicense = true;

let canDrive = age >= 18 && hasLicense;

console.log(canDrive);
Expected Output: 
true

Both conditions must be truthy for the complete Boolean condition to be true.

2.3 Logical OR (||)

The logical OR operator returns the first truthy operand. If all operands are falsy, it returns the final operand.

A B A || B
truetruetrue
truefalsetrue
falsetruetrue
falsefalsefalse
 
let isAdmin = false;
let isEditor = true;

let canEdit = isAdmin || isEditor;

console.log(canEdit);
Expected Output: 
true

2.4 Logical NOT (!)

The logical NOT operator converts its operand to a Boolean value and reverses that value. 

console.log(!true);

console.log(!false);

console.log(!0);

console.log(!10);
Expected Output: 
false
true
true
false

2.5 Double NOT (!!)

Double NOT converts a value into its Boolean equivalent. 

console.log(!!1);

console.log(!!0);

console.log(!!"JavaScript");

console.log(!!"");
Expected Output: 
true
false
true
false

Truthy and falsy values are discussed in detail in Lecture 4.

3. Logical Operators with Multiple Conditions

3.1 Combining AND and OR

let age = 22;
let hasID = true;
let isGuest = false;

let allowed = (age >= 18 && hasID) || isGuest;

console.log(allowed);
Expected Output: 
true

Parentheses make the intended grouping clear. Here, the first two conditions must both be true, or the guest condition must be true.

3.2 Operator Precedence

Logical AND has higher precedence than logical OR. Parentheses should be used when they improve clarity. 

console.log(true || false && false);

console.log((true || false) && false);
Expected Output: 
true
false

3.3 Practical Form Validation

let username = "navdeep";
let password = "JavaScript123";

let isValid = username.length >= 3 &&
              password.length >= 8;

console.log("Form valid:", isValid);
Expected Output: 
Form valid: true

3.4 Access Control

let isLoggedIn = true;
let isAdmin = false;

let canAccessDashboard = isLoggedIn && isAdmin;

console.log(canAccessDashboard);
Expected Output: 
false

4. Short-Circuit Evaluation

JavaScript logical operators use short-circuit evaluation. The second operand is not evaluated when the result is already determined by the first.

4.1 AND Short-Circuiting

let result = false && console.log("Executed");

console.log(result);
Expected Output: 
false

The console.log() call is skipped because the first operand is falsy.

4.2 OR Short-Circuiting

let result = true || console.log("Executed");

console.log(result);
Expected Output: 
true

The second operand is skipped because the first operand is already truthy.

4.3 Logical Operators Return Operands

Unlike some languages, JavaScript's && and || do not always return true or false. They return one of their operand values. 

console.log("Hello" && "JavaScript");

console.log(0 && "JavaScript");

console.log("" || "Default Value");

console.log("User" || "Guest");
Expected Output: 
JavaScript
0
Default Value
User
Short-circuit evaluation is important in real frontend code. A dedicated lecture will cover practical patterns, default values and safe conditional execution.

5. Bitwise Operators

Bitwise operators work on the binary representations of numbers.

JavaScript converts Number operands to 32-bit integer representations for bitwise operations. BigInt operands support bitwise operations separately and cannot be mixed with Number operands.

5.1 Binary Representation

Consider these decimal numbers:

Decimal Binary (4-bit illustration)
50101
30011
60110
70111

5.2 Bitwise Operator Reference

Operator Name Purpose
&Bitwise ANDSets a bit if both corresponding bits are 1.
|Bitwise ORSets a bit if either corresponding bit is 1.
^Bitwise XORSets a bit if corresponding bits differ.
~Bitwise NOTInverts all bits in the 32-bit representation.
<<Left ShiftShifts bits to the left.
>>Sign-propagating Right ShiftShifts right while preserving the sign bit.
>>>Zero-fill Right ShiftShifts right and fills left bits with zero.

5.3 Bitwise AND (&)

Both bits must be 1 for the result bit to be 1.

  0101  (5)
& 0011  (3)
-------
  0001  (1)
console.log(5 & 3);

console.log(6 & 3);
Expected Output: 
1
2

5.4 Bitwise OR (|)

The result bit is 1 if at least one corresponding bit is 1. 

  0101  (5)
| 0011  (3)
-------
  0111  (7)
console.log(5 | 3);

console.log(4 | 2);
Expected Output: 
7
6

5.5 Bitwise XOR (^)

XOR produces 1 when corresponding bits are different. 

  0101  (5)
^ 0011  (3)
-------
  0110  (6)
console.log(5 ^ 3);

console.log(5 ^ 5);

console.log(7 ^ 2);
Expected Output: 
6
0
5

5.6 Bitwise NOT (~)

Bitwise NOT flips every bit in the 32-bit signed integer representation. 

console.log(~5);

console.log(~0);

console.log(~10);
Expected Output: 
-6
-1
-11
For 32-bit signed integers, ~x is equivalent to -(x + 1). This follows from two's-complement representation.

6. Bitwise Shift Operators

6.1 Left Shift (<<)

Left shift moves the bits to the left and fills the newly created rightmost positions with zeros. 

00000101  (5)
<< 1
---------
00001010  (10)
console.log(5 << 1);

console.log(5 << 2);

console.log(3 << 1);
Expected Output: 
10
20
6

6.2 Sign-Propagating Right Shift (>>)

Right shift moves bits to the right while preserving the sign bit. 

console.log(8 >> 1);

console.log(16 >> 2);

console.log(-8 >> 1);
Expected Output: 
4
4
-4

6.3 Zero-Fill Right Shift (>>>)

Zero-fill right shift moves bits to the right and fills the leftmost positions with zeros. 

console.log(8 >>> 1);

console.log(16 >>> 2);

console.log(-8 >>> 1);
Expected Output: 
4
4
2147483644
The >>> operator treats the result as an unsigned 32-bit integer. It is not supported for BigInt values.

7. Practical Bitwise Applications

7.1 Check Whether a Number Is Even

The least significant bit of an even integer is zero. Bitwise AND can test that bit. 

let number = 14;

if ((number & 1) === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}
Expected Output: 
Even

7.2 Set a Particular Bit

Bitwise OR can set a selected bit. This example sets bit position 1, counting from position 0 on the right. 

let flags = 5;

flags = flags | (1 << 1);

console.log(flags);
Expected Output: 
7

7.3 Check a Particular Bit

let flags = 5;

let isBitSet = (flags & (1 << 2)) !== 0;

console.log(isBitSet);
Expected Output: 
true

7.4 Toggle a Particular Bit

let flags = 5;

flags = flags ^ (1 << 0);

console.log(flags);
Expected Output: 
4

Bitwise operations are useful in low-level programming, compact flag storage, binary protocols and certain algorithmic problems. They are less common in everyday frontend code.

8. Conditional (Ternary) Operator

The conditional operator is the only JavaScript operator that takes three operands. It provides a concise way to select between two expressions based on a condition.

8.1 Syntax

condition ? expressionIfTrue : expressionIfFalse;

8.2 Basic Example

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);
Expected Output: 
Adult

8.3 Compare if-else and Ternary

Using if-else:

let number = 7;
let result;

if (number % 2 === 0) {
    result = "Even";
} else {
    result = "Odd";
}

console.log(result);

Using the ternary operator:

let number = 7;

let result = number % 2 === 0 ? "Even" : "Odd";

console.log(result);
Expected Output for Both: 
Odd

8.4 Ternary with Comparison

let score = 85;

let grade = score >= 90 ? "A" :
            score >= 75 ? "B" :
            score >= 60 ? "C" : "D";

console.log(grade);
Expected Output: 
B

8.5 Nested Ternary Operator

A ternary expression can be nested inside another ternary expression. 

let number = 0;

let result = number > 0 ? "Positive" :
             number < 0 ? "Negative" :
             "Zero";

console.log(result);
Expected Output: 
Zero
Avoid deeply nested ternary expressions. For complex decision-making, if-else statements are generally easier to read and maintain.

8.6 Practical Frontend Example: Login Status

let isLoggedIn = true;

let message = isLoggedIn
    ? "Welcome back!"
    : "Please log in";

console.log(message);
Expected Output: 
Welcome back!

10. Common Mistakes and Debugging

Mistake 1: Confusing && with &

&& is logical AND, while & is bitwise AND. 

console.log(5 && 3);

console.log(5 & 3);
Expected Output: 
3
1

Mistake 2: Confusing || with |

|| performs logical OR. | performs bitwise OR. 

console.log(5 || 3);

console.log(5 | 3);
Expected Output: 
5
7

Mistake 3: Expecting Logical Operators to Return Only Booleans

console.log("Hello" && 100);

console.log(0 || 50);
Expected Output: 
100
50

Mistake 4: Using Nested Ternary Excessively

Deeply nested ternary expressions reduce readability. Use if-else or switch when the decision logic becomes complicated.

Mistake 5: Mixing Number and BigInt in Bitwise Operations

// This throws a TypeError:
// console.log(5 & 3n);

// Use the same numeric type:
console.log(5n & 3n);
Expected Output: 
1n

Mistake 6: Misunderstanding Bitwise NOT

Bitwise NOT operates on a 32-bit signed representation for Number values. Therefore, ~5 returns -6, not a positive binary complement.

11. Placement Interview Questions

Q1. What are logical operators in JavaScript?

Answer: Logical operators combine or reverse conditions. The main operators are &&, || and !.

Q2. What is the difference between && and &?

Answer: && performs logical AND with short-circuit evaluation. & performs bitwise AND on integer representations.

Q3. What is short-circuit evaluation?

Answer: It is the behavior in which the second operand is skipped when the result is already determined by the first operand.

Q4. What does the || operator return?

Answer: It returns the first truthy operand, or the last operand if all operands are falsy.

Q5. What does the && operator return?

Answer: It returns the first falsy operand, or the last operand if all operands are truthy.

Q6. What is the difference between ! and !!?

Answer: ! reverses the Boolean interpretation of a value. !! converts a value to its Boolean equivalent.

Q7. What are bitwise operators?

Answer: Bitwise operators perform operations on the binary representations of integer values.

Q8. What is the difference between | and ||?

Answer: | performs bitwise OR, whereas || performs logical OR with short-circuiting.

Q9. What is the difference between << and >>?

Answer: Left shift moves bits left. Sign-propagating right shift moves bits right while preserving the sign.

Q10. What is the difference between >> and >>>?

Answer: >> preserves the sign bit, whereas >>> fills the leftmost positions with zeros and produces an unsigned 32-bit result.

Q11. What is the ternary operator?

Answer: It is a conditional operator with three operands. It selects one of two expressions based on a condition.

Q12. Is the ternary operator a replacement for if-else?

Answer: It is useful for simple conditional expressions, but complex logic is generally clearer with if-else.

Q13. What is the result of 5 & 3?

Answer: 1, because the binary representations 0101 and 0011 share only one set bit.

Q14. What is the result of 5 ^ 3?

Answer: 6, because XOR sets bits where the corresponding bits differ.

Q15. Can JavaScript bitwise operators work with BigInt?

Answer: Most bitwise operators support BigInt, but Number and BigInt operands cannot be mixed in the same bitwise operation. The unsigned right shift >>> does not support BigInt.

14. Lecture Summary

  • && performs logical AND.
  • || performs logical OR.
  • ! reverses the Boolean interpretation of a value.
  • !! converts a value to its Boolean equivalent.
  • Logical operators use short-circuit evaluation.
  • Logical operators can return operand values.
  • Bitwise operators manipulate binary representations.
  • & performs bitwise AND.
  • | performs bitwise OR.
  • ^ performs bitwise XOR.
  • ~ performs bitwise NOT.
  • <<, >> and >>> perform bit shifts.
  • The ternary operator provides conditional expressions.
  • Parentheses improve the clarity of complex expressions.
