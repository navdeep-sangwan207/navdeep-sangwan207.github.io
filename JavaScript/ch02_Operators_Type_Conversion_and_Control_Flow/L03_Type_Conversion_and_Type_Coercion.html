2. Introduction to Logical Operators

Logical operators combine or modify conditions. They are commonly used with comparison operators to make decisions in JavaScript applications.

JavaScript provides three primary logical operators:

Operator Name Purpose
&& Logical AND Combines conditions; requires both operands to be truthy.
|| Logical OR Combines conditions; requires at least one operand to be truthy.
! Logical NOT Reverses the truthiness of an operand.

3. Logical AND Operator (&&)

The logical AND operator returns a truthy result only when both operands are truthy.

3.1 AND Truth Table

Condition A Condition B A && B
truetruetrue
truefalsefalse
falsetruefalse
falsefalsefalse

3.2 Basic Example

let age = 25;

let hasLicense = true;

console.log(age >= 18 && hasLicense === true);
Expected Output: 
true

Both conditions are true, so the result is true.

3.3 One Condition Is False

let age = 16;

let hasLicense = true;

console.log(age >= 18 && hasLicense === true);
Expected Output: 
false

The first condition is false, so the entire AND expression evaluates to false.

3.4 Multiple Conditions

let marks = 75;

let attendance = 85;

let assignmentSubmitted = true;

let eligible =
    marks >= 40 &&
    attendance >= 75 &&
    assignmentSubmitted;

console.log(eligible);
Expected Output: 
true

Every condition must be truthy for this expression to produce a truthy result.

4. Logical OR Operator (||)

The logical OR operator returns a truthy result when at least one operand is truthy.

4.1 OR Truth Table

Condition A Condition B A || B
truetruetrue
truefalsetrue
falsetruetrue
falsefalsefalse

4.2 Basic Example

let isAdmin = false;

let isEditor = true;

console.log(isAdmin || isEditor);
Expected Output: 
true

4.3 Both Conditions Are False

let hasEmail = false;

let hasPhone = false;

console.log(hasEmail || hasPhone);
Expected Output: 
false

4.4 Multiple Conditions

let paymentByCard = false;

let paymentByUPI = true;

let paymentByCash = false;

let paymentAccepted =
    paymentByCard ||
    paymentByUPI ||
    paymentByCash;

console.log(paymentAccepted);
Expected Output: 
true

5. Logical NOT Operator (!)

The logical NOT operator reverses the truthiness of its operand and always returns a Boolean value.

5.1 NOT Truth Table

Input !Input
truefalse
falsetrue

5.2 Basic Example

let isLoggedIn = true;

console.log(!isLoggedIn);
Expected Output: 
false

5.3 NOT with Boolean Expressions

let age = 15;

console.log(!(age >= 18));
Expected Output: 
true

5.4 Double NOT (!!)

Double NOT converts a value into its Boolean representation. 

console.log(!!1);

console.log(!!0);

console.log(!!"Hello");

console.log(!!"");

console.log(!!null);
Expected Output: 
true
false
true
false
false
Double NOT is commonly used when a Boolean value is needed from a value that may be truthy or falsy.

6. Logical Operators with Comparison Operators

Logical operators are commonly combined with relational and equality operators.

Example 1: Age and Income Eligibility

console.log(eligible);

true

7. Boolean Logic and De Morgan's Laws

De Morgan's laws describe how NOT interacts with AND and OR.

7.1 First Law

NOT (A AND B) is equivalent to (NOT A) OR (NOT B). 

let a = true;

let b = false;

console.log(!(a && b));

console.log(!a || !b);
Expected Output: 
true
true

7.2 Second Law

NOT (A OR B) is equivalent to (NOT A) AND (NOT B). 

let a = true;

let b = false;

console.log(!(a || b));

console.log(!a && !b);
Expected Output: 
false
false
These laws are useful when simplifying complex conditions and understanding negated validation rules.

8. Logical Operators Return Values, Not Always Booleans

An important JavaScript concept is that && and || do not necessarily return true or false.

They return one of their operands according to short-circuit evaluation.

8.1 AND Returns the First Falsy Operand or the Last Operand

console.log(10 && 20);

console.log(0 && 20);

console.log("Hello" && "JavaScript");

console.log(null && "Hello");
Expected Output: 
20
0
JavaScript
null

8.2 OR Returns the First Truthy Operand or the Last Operand

console.log(10 || 20);

console.log(0 || 20);

console.log("" || "Default");

console.log(null || "Fallback");
Expected Output: 
10
20
Default
Fallback
The operators return operands, not automatically Boolean values. This behavior is important in JavaScript interviews and frontend development.

9. Short-Circuit Evaluation

Short-circuit evaluation means JavaScript may stop evaluating an expression as soon as its final result is determined.

9.1 Short-Circuit with AND

If the left operand of && is falsy, the right operand is not evaluated. 

function showMessage() {
    console.log("Function executed");
    return true;
}

console.log(false && showMessage());
Expected Output: 
false

The function is not executed because the first operand is already falsy.

9.2 Short-Circuit with OR

If the left operand of || is truthy, the right operand is not evaluated. 

function showMessage() {
    console.log("Function executed");
    return true;
}

console.log(true || showMessage());
Expected Output: 
true

9.3 Demonstrating Evaluation Order

function first() {
    console.log("First");
    return false;
}

function second() {
    console.log("Second");
    return true;
}

console.log(first() && second());
Expected Output: 
First
false

The second function is never called because the first function returns false.

Short-circuit evaluation is not an optimization detail to ignore. It affects whether functions, assignments or other side effects execute.

Form is valid

if (stock > 0 && !isDiscontinued) {
    console.log("Product Available");

    console.log("Product Unavailable");

Expected Output:

Example 4: Notification Eligibility

    console.log("Send Notification");

    console.log("Do Not Send Notification");

    console.log(user.name);
} else {
    console.log("User information unavailable");
}
Expected Output: 
User information unavailable

The AND operator prevents the property access from being attempted when user is null. Optional chaining will be covered in a later lecture.

11. Operator Precedence with Logical Operators

When multiple logical operators appear in one expression, precedence determines evaluation grouping.

Among the three operators covered here, the precedence order from highest to lowest is:

  1. Logical NOT (!)
  2. Logical AND (&&)
  3. Logical OR (||)

Example 1

console.log(true || false && false);
Expected Output: 
true

AND is evaluated before OR: true || (false && false).

Example 2

console.log(!true || false);
Expected Output: 
false

Example 3

console.log(!(true && false) || false);
Expected Output: 
true
Use parentheses when an expression is complex. They make the intended evaluation order easier to read and maintain.

12. Common Mistakes and Debugging

Mistake 1: Using Single & Instead of &&

& is bitwise AND, whereas && is logical AND. They are different operators. 

console.log(true && false);

console.log(5 & 3);
Expected Output: 
false
1

Mistake 2: Confusing OR with AND

let age = 20;

console.log(age >= 18 && age <= 30);

console.log(age < 18 || age > 30);
Expected Output: 
true
false

Mistake 3: Assuming && Always Returns Boolean

console.log("Hello" && 100);
Expected Output: 
100

Mistake 4: Assuming || Always Returns Boolean

console.log(0 || "Default Value");
Expected Output: 
Default Value

Mistake 5: Forgetting Short-Circuit Behavior

let result = false && console.log("Executed");

console.log(result);
Expected Output: 
false

The console.log call on the right is skipped.

13. Important Interview Questions

Q1. What are logical operators in JavaScript?

Answer: Operators used to combine or negate conditions. The primary operators are &&, || and !.

Q2. What is the difference between && and ||?

Answer: AND requires both operands to be truthy to return a truthy operand result. OR returns the first truthy operand or the final operand if none is truthy.

Q3. What does the ! operator do?

Answer: It converts its operand to a Boolean and reverses that Boolean value.

Q4. What is short-circuit evaluation?

Answer: JavaScript stops evaluating the remaining operands when the result of a logical expression is already determined.

Q5. Does && always return true or false?

Answer: No. It returns the first falsy operand or the last operand if all operands are truthy.

Q6. Does || always return true or false?

Answer: No. It returns the first truthy operand or the last operand if none is truthy.

Q7. What is the output of 0 || 100?

Answer: 100, because zero is falsy and 100 is truthy.

Q8. What is the output of 0 && 100?

Answer: 0, because the first operand is falsy.

Q9. What are De Morgan's laws?

Answer: They describe how negation distributes over AND and OR: !(A && B) is equivalent to (!A || !B), and !(A || B) is equivalent to (!A && !B).

Q10. What is the difference between & and &&?

Answer: & is bitwise AND, while && is logical AND with short-circuit behavior.

Q11. What is the difference between | and ||?

Answer: | is bitwise OR, whereas || is logical OR with short-circuit behavior.

Q12. Why is short-circuit evaluation useful?

Answer: It allows conditional execution and can prevent unsafe operations, such as accessing a property of null.

16. Lecture Summary

  • && is logical AND.
  • || is logical OR.
  • ! is logical NOT.
  • Logical operators can return non-Boolean operands.
  • AND stops at the first falsy operand.
  • OR stops at the first truthy operand.
  • NOT always returns a Boolean value.
  • Short-circuit evaluation can prevent unnecessary execution.
  • Logical operators are widely used in frontend validation.
  • Parentheses improve the readability of complex conditions.
