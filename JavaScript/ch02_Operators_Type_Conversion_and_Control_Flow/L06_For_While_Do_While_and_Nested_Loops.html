Master iteration, loop control and repeated execution in JavaScript.

2. Introduction to Loops

A loop is a programming construct that repeatedly executes a block of statements while a specified condition is satisfied.

Consider printing numbers from 1 to 5 without a loop:

console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

This approach works for a small number of statements, but it becomes inefficient when the same operation must be repeated hundreds or thousands of times.

Using a loop:

for (let i = 1; i <= 5; i++) {
    console.log(i);
}
Expected Output: 
1
2
3
4
5

Basic Components of a Loop

Component Purpose
Initialization Sets the starting value of the loop variable.
Condition Determines whether another iteration should execute.
Loop body Contains statements executed during each iteration.
Update Changes the loop variable to move toward termination.
Important: A loop must have a suitable termination condition. If its condition never becomes false, it may execute indefinitely.

3. The for Loop

A for loop is commonly used when the number of iterations is known or can be controlled using a counter.

Syntax

for (initialization; condition; update) {
    // Statements to execute
}

Execution Order

  1. Initialization executes once.
  2. The condition is evaluated.
  3. If true, the loop body executes.
  4. The update expression executes.
  5. The condition is checked again.
  6. The loop terminates when the condition becomes false.

Example 6: Factorial of a Number

The factorial of a positive integer is the product of all positive integers from 1 to that number.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

let number = 5;
let factorial = 1;

for (let i = 1; i <= number; i++) {
    factorial *= i;
}

console.log("Factorial:", factorial);
Expected Output: 
Factorial: 120
Boundary case: The factorial of zero is 1. The initialization factorial = 1 correctly handles this case because the loop executes zero times.

4. The while Loop

A while loop repeatedly executes a block as long as its condition remains true.

It is particularly useful when the number of iterations is not known in advance.

Syntax

initialization;

while (condition) {
    // Statements

    update;
}

Example 1: Print Numbers from 1 to 5

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
Expected Output: 
1
2
3
4
5

Example 2: Calculate Sum of Digits

A common placement problem is to calculate the sum of the digits of an integer. 

let number = 1234;
let sum = 0;

while (number > 0) {
    let digit = number % 10;
    sum += digit;
    number = Math.floor(number / 10);
}

console.log("Sum of digits:", sum);
Expected Output: 
Sum of digits: 10

Execution:

Number Extracted Digit Running Sum
1234 4 4
123 3 7
12 2 9
1 1 10

Example 3: Reverse a Number

let number = 12345;
let reverse = 0;

while (number > 0) {
    let digit = number % 10;

    reverse = reverse * 10 + digit;

    number = Math.floor(number / 10);
}

console.log("Reversed number:", reverse);
Expected Output: 
Reversed number: 54321

Example 4: Count the Number of Digits

let number = 123456;
let count = 0;

if (number === 0) {
    count = 1;
} else {
    number = Math.abs(number);

    while (number > 0) {
        count++;
        number = Math.floor(number / 10);
    }
}

console.log("Digit count:", count);
Expected Output: 
Digit count: 6
Important: When processing negative numbers, consider their absolute value if the sign is not relevant to the problem. Also handle zero explicitly in digit-counting problems.

5. The do...while Loop

The do...while loop executes its body first and checks the condition afterward.

Therefore, the loop body always executes at least once, even if the condition is initially false.

Syntax

do {
    // Statements
} while (condition);

Example 1: Basic do...while Loop

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);
Expected Output: 
1
2
3
4
5

Example 2: Condition Initially False

let number = 10;

do {
    console.log("Executed once");
} while (number < 5);
Expected Output: 
Executed once

Although number < 5 is false, the body executes once before the condition is checked.

Example 3: Input Validation Concept

A do...while loop can be used when an operation must run at least once before checking whether another attempt is needed. 

let attempts = 0;
let valid = false;

do {
    attempts++;

    if (attempts === 3) {
        valid = true;
    }

    console.log("Attempt:", attempts);

} while (!valid);

console.log("Validation completed");
Expected Output: 
Attempt: 1
Attempt: 2
Attempt: 3
Validation completed
Practical application: A do...while loop is useful for menu-driven programs and repeated operations that must execute at least once. Browser applications commonly use event-driven input handling instead of blocking input loops.

6. Comparison of for, while and do...while

Feature for while do...while
Condition check Before each iteration Before each iteration After each iteration
Minimum executions Zero Zero One
Initialization Usually in loop header Usually before loop Usually before loop
Update Usually in loop header Usually inside body Usually inside body
Typical use Counter-controlled repetition Condition-controlled repetition At-least-once execution

When Should You Use Each Loop?

  • for: When iterating a known number of times or traversing array indexes.
  • while: When repetition depends on a condition that may change during execution.
  • do...while: When the body must execute at least once before checking the condition.

7. Nested Loops

A nested loop is a loop placed inside another loop. The inner loop completes its iterations for each iteration of the outer loop.

Syntax

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 2; j++) {
        // Inner loop statements
    }

}

Example 1: Basic Nested Loop

for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 2; j++) {
        console.log("i =", i, "j =", j);
    }
}
Expected Output: 
i = 1 j = 1
i = 1 j = 2
i = 2 j = 1
i = 2 j = 2
i = 3 j = 1
i = 3 j = 2

The inner loop executes two times for each outer loop iteration. Since the outer loop executes three times, the total number of inner loop executions is:

3 × 2 = 6 iterations

Example 2: Print a Rectangle Pattern

for (let i = 1; i <= 4; i++) {
    let row = "";

    for (let j = 1; j <= 5; j++) {
        row += "* ";

}
Expected Output: 
* * * * *
* * * * *
* * * * *
* * * * *

8. Looping Through Arrays and Strings

Loops are frequently used in frontend development to process arrays of data and individual characters in strings.

Example 1: Traverse an Array Using for

let fruits = ["Apple", "Banana", "Mango", "Orange"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
Expected Output: 
Apple
Banana
Mango
Orange

Example 2: Calculate Array Sum

let numbers = [10, 20, 30, 40, 50];
let sum = 0;

for (let i = 0; i < numbers.length; i++) {
    sum += numbers[i];
}

console.log("Array sum:", sum);
Expected Output: 
Array sum: 150

Example 3: Find the Largest Array Element

let numbers = [12, 45, 7, 89, 23];

let largest = numbers[0];

for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
        largest = numbers[i];
    }
}

console.log("Largest:", largest);
Expected Output: 
Largest: 89

Example 4: Traverse a String

let text = "JAVASCRIPT";

for (let i = 0; i < text.length; i++) {
    console.log(text[i]);
}
Expected Output: 
J
A
V
A
S
C
R
I
P
T

Example 5: Count Vowels in a String

let text = "JavaScript";
let count = 0;

for (let i = 0; i < text.length; i++) {
    let character = text[i].toLowerCase();

    if (
        character === "a" ||
        character === "e" ||
        character === "i" ||
        character === "o" ||
        character === "u"
    ) {
        count++;
    }
}

console.log("Vowel count:", count);
Expected Output: 
Vowel count: 3
Frontend relevance: These patterns are useful when processing product lists, user records, search results, form data and other collections of information.

9. Common Loop Mistakes

9.1 Infinite Loop

An infinite loop occurs when the termination condition never becomes false. 

// Incorrect: i is never updated
let i = 1;

while (i <= 5) {
    console.log(i);
}

The variable i remains 1, so the condition remains true indefinitely.

Correct version:

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

9.2 Off-by-One Error

An off-by-one error occurs when a loop executes one iteration too many or too few. 

// Prints 1 to 4
for (let i = 1; i < 5; i++) {
    console.log(i);
}

// Prints 1 to 5
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

9.3 Incorrect Loop Bound for Arrays

let numbers = [10, 20, 30];

// Incorrect: accesses index 3 as well
for (let i = 0; i <= numbers.length; i++) {
    console.log(numbers[i]);
}

// Correct
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}

Array indexes start at zero. The final valid index is array.length - 1.

9.4 Modifying the Wrong Variable in Nested Loops

// Incorrect: updates outer variable
for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 2; i++) {
        console.log(i, j);
    }
}

The inner loop should update j, not i. Updating the outer variable here can cause unexpected behavior or an infinite loop.

Correct version:

for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 2; j++) {
        console.log(i, j);
    }
}

9.5 Incorrect Accumulator Initialization

// Correct for summation
let sum = 0;

// Correct for multiplication
let product = 1;

Choosing the correct initial value is important for accumulation problems.

10. Loop Performance and Time Complexity

Time complexity describes how the number of operations grows as the input size increases.

10.1 Single Loop

for (let i = 0; i < n; i++) {
    console.log(i);
}

The loop executes approximately n times. Its time complexity is O(n).

10.2 Nested Loops

for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
        console.log(i, j);
    }
}

The inner loop executes n times for each of the n outer iterations. Total operations are approximately n × n.

Time complexity: O(n²).

10.3 Two Consecutive Loops

for (let i = 0; i < n; i++) {
    console.log(i);
}

for (let j = 0; j < n; j++) {
    console.log(j);
}

Total operations are approximately n + n = 2n. Ignoring constant factors, the time complexity is O(n).

Loop Pattern Time Complexity
Single loop O(n)
Two consecutive loops O(n)
Two nested loops O(n²)
Three nested loops O(n³)
Loop that halves the input each time O(log n)
Placement tip: Nested loops are not automatically inefficient. Analyze the actual number of iterations and the input size before deciding whether a solution is efficient.

11. Placement Interview Questions and Answers

Q1. What is a loop in JavaScript?

A loop repeatedly executes a block of statements while a specified condition is satisfied.

Q2. What are the main types of loops in JavaScript?

The main loop statements include for, while and do...while. JavaScript also provides for...in, for...of and array iteration methods.

Q3. What is the difference between while and do...while?

A while loop checks its condition before executing the body. A do...while loop checks the condition after executing the body, so it executes at least once.

Q4. Can a for loop execute zero times?

Yes. If its initial condition is false, the loop body does not execute.

Q5. What is an infinite loop?

An infinite loop is a loop that does not terminate because its condition never becomes false.

Q6. What is a nested loop?

A nested loop is a loop placed inside another loop. The inner loop executes completely for each outer loop iteration.

Q7. What is an off-by-one error?

It is a loop-boundary error in which the loop executes one iteration more or one iteration fewer than intended.

Q8. What is the time complexity of two nested loops?

When both loops execute approximately n times, the time complexity is O(n²).

Q9. What is an accumulator?

An accumulator is a variable that stores a running result, such as a sum or product, during repeated execution.

Q10. What happens when a while condition is initially false?

The loop body does not execute at all.

Q11. What happens when a do...while condition is initially false?

The loop body executes once before the false condition is checked.

Q12. How do you avoid infinite loops?

Ensure that the loop has a valid termination condition and that the variables affecting the condition are updated correctly.

13. Placement Coding Exercises

Solve these problems without copying the examples above. Test your programs with normal values and boundary cases.

Exercise 1: Sum of Natural Numbers

Exercise 3: Reverse a Number

Reverse the digits of an integer using arithmetic operations and a while loop.

Exercise 4: Palindrome Number

Determine whether an integer reads the same forward and backward. For example, 121 is a palindrome, while 123 is not.

Exercise 5: Prime Number Checker

Check whether a number is prime. Optimize the divisor check by testing divisors only up to the square root of the number. Handle values below 2 correctly.

Exercise 10: Multiplication Tables

Print multiplication tables from 1 to 10 using nested loops.

Exercise 11: Find Duplicate Values

Exercise 12: Second Largest Distinct Element

Find the second largest distinct number in an array. Handle arrays with fewer than two distinct values.

Placement preparation: Give special attention to digit manipulation, prime numbers, Fibonacci series, palindrome checks, array traversal and nested-loop patterns. These exercises build the iteration skills used in coding rounds.

14. Lecture Summary

  • Loops execute statements repeatedly.
  • for is useful for counter-controlled iteration.
  • while checks its condition before execution.
  • do...while executes at least once.
  • Nested loops are useful for patterns and pair comparisons.
  • Loops can process arrays and strings.
  • Correct initialization, conditions and updates prevent errors.
  • Single loops commonly have O(n) time complexity.
  • Two full nested loops commonly have O(n²) time complexity.
