2. What Are Operators?

Operators are symbols or keywords that perform operations on values and variables.

For example, in the expression: 

let result = 10 + 20;
  • 10 and 20 are operands.
  • + is the operator.
  • 10 + 20 is an expression.
  • result stores the evaluated value.
Result: 
30

The plus operator performs both numeric addition and string concatenation.

Example 3: Number and String

console.log(10 + "20");

console.log(10 + 20 + "30");

Evaluation occurs according to operator associativity. Once a string participates in the addition operation, the result can become a string, affecting subsequent additions.

5. Increment and Decrement Operators

Increment and decrement operators change a variable's numeric value by one.

Operator Meaning Equivalent Effect
++ Increment Add 1
-- Decrement Subtract 1

5.1 Prefix Increment (++variable)

Prefix increment changes the variable first and then produces the updated value. 

let a = 10;

console.log(++a);

console.log(a);
Expected Output: 
11
11

5.2 Postfix Increment (variable++)

Postfix increment produces the old value first and then increments the variable. 

let a = 10;

console.log(a++);

console.log(a);
Expected Output: 
10
11

5.3 Prefix Decrement (--variable)

let a = 10;

console.log(--a);

console.log(a);
Expected Output: 
9
9

5.4 Postfix Decrement (variable--)

let a = 10;

console.log(a--);

console.log(a);
Expected Output: 
10
9

6. Increment and Decrement with Expressions

Prefix and postfix operations are particularly important in output-prediction questions.

Example 1

let a = 5;

let b = a++;

console.log(a);

console.log(b);
Expected Output: 
6
5

Explanation:

  1. Initially, a is 5.
  2. Postfix increment returns the old value 5.
  3. That value is assigned to b.
  4. a is then incremented to 6.

Example 2

let a = 5;

let b = ++a;

console.log(a);

console.log(b);
Expected Output: 
6
6

Example 3

let x = 10;

let result = x++ + ++x;

console.log(result);

console.log(x);
Expected Output: 
22
12

Step-by-step evaluation:

  1. x++ produces 10 and changes x to 11.
  2. ++x changes x to 12 and produces 12.
  3. The addition is 10 + 12 = 22.
Avoid writing unnecessarily complex expressions with multiple increments. They are difficult to maintain and debug.

7. Assignment Operator

The assignment operator (=) assigns a value to a variable. 

let marks;

marks = 85;

console.log(marks);
Expected Output: 
85

Assignment is an expression, so it produces the assigned value. 

let a;

let b;

console.log(a = b = 50);

console.log(a);

console.log(b);
Expected Output: 
50
50
50

Assignment operators associate from right to left. Therefore, b receives 50 first, and then a receives the value of the assignment expression.

Expected Output:

Other compound arithmetic operators generally perform numeric conversion where applicable.

Compound assignment can behave differently from simple concatenation. Always consider the type conversion rules of the underlying operation.

11. Important Interview Questions

Q1. What is the difference between / and %?

Answer: / performs division and % returns the remainder of division.

Q2. What is the difference between prefix and postfix increment?

Answer: Prefix increment changes the variable before producing its value in the expression. Postfix increment produces the old value before changing the variable.

Q3. What is the output of 10 + "20"?

Answer: "1020", because the plus operator performs string concatenation in this case.

Q4. What is the difference between = and +=?

Answer: = assigns a value, while += performs addition or string concatenation and assigns the result.

Q5. What does 2 ** 3 return?

Answer: 8, because 2 is raised to the power of 3.

Q6. What is the result of 10 % 2?

Answer: 0, because 10 is exactly divisible by 2.

Q7. What is the result of 7 / 2?

Answer: 3.5. JavaScript Number division supports fractional results.

Q8. Can the increment operator be used with strings?

Answer: Yes, if the string can be converted to a number. For example, let x = "5"; x++ changes x to the number 6. A non-numeric string produces NaN.

Q9. What is the difference between += and ++?

Answer: += adds a specified value and assigns the result. ++ increases a value by one.

Q10. Does JavaScript support exponentiation?

Answer: Yes. The ** operator performs exponentiation.
