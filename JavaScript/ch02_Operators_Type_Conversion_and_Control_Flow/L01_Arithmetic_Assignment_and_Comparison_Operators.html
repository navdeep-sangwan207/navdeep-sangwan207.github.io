2. What Are Operators?

Operators are symbols or keywords that perform operations on values and variables.

The values on which operators perform operations are called operands.

Example

let result = 10 + 5;

console.log(result);
Expected Output: 
15

In this example:

  • + is the operator.
  • 10 and 5 are operands.
  • 15 is the resulting value.

Common Categories of Operators

Category Purpose
ArithmeticMathematical calculations
AssignmentAssigning and updating values
ComparisonComparing two values
LogicalCombining or negating conditions
BitwiseOperating on binary representations
ConditionalChoosing between expressions

This lecture focuses on arithmetic, assignment and comparison operators.

4. Increment and Decrement Operators

Increment and decrement operators increase or decrease a numeric variable by one.

Operator Meaning Example
++ Increment by 1 x++
-- Decrement by 1 x--

4.1 Post-Increment (x++)

Post-increment returns the current value first and then increments the variable. 

let x = 5;

let result = x++;

console.log(result);

console.log(x);
Expected Output: 
5
6

4.2 Pre-Increment (++x)

Pre-increment increments the variable first and then returns the updated value. 

let x = 5;

let result = ++x;

console.log(result);

console.log(x);
Expected Output: 
6
6

4.3 Post-Decrement (x--)

let x = 5;

let result = x--;

console.log(result);

console.log(x);
Expected Output: 
5
4

4.4 Pre-Decrement (--x)

let x = 5;

let result = --x;

console.log(result);

console.log(x);
Expected Output: 
4
4

4.5 Combined Increment Example

let a = 5;

console.log(a++);

console.log(++a);

console.log(a);
Expected Output: 
5
7
7
Avoid writing complicated expressions with multiple increments or decrements of the same variable. Separate statements make code easier to understand and debug.

7. Equality Operators: == and ===

JavaScript provides two main equality operators: loose equality and strict equality.

7.1 Loose Equality (==)

The loose equality operator compares values after applying type conversion when required. 

console.log(5 == "5");

console.log(10 == "10");

console.log(0 == false);

console.log(1 == true);
Expected Output: 
true
true
true
true

7.2 Strict Equality (===)

The strict equality operator compares values without converting different types into one another. 

console.log(5 === "5");

console.log(10 === 10);

console.log(0 === false);

console.log(1 === true);
Expected Output: 
false
true
false
false

7.3 Loose and Strict Inequality

console.log(5 != "5");

console.log(5 !== "5");

console.log(10 != 20);

console.log(10 !== 20);
Expected Output: 
false
true
true
true
Prefer === and !== in normal application code. Loose equality can produce unexpected results when JavaScript performs type coercion.

A more detailed study of equality behavior, truthy and falsy values, and type coercion is included in Lecture 4.

8. Comparing Strings

JavaScript compares strings lexicographically, using their character values, rather than automatically interpreting them as numbers.

8.1 String Equality

console.log("JavaScript" === "JavaScript");

console.log("JavaScript" === "javascript");

console.log("Hello" == "hello");
Expected Output: 
true
false
false

8.2 String Relational Comparison

console.log("apple" < "banana");

console.log("cat" > "bat");

console.log("10" < "2");
Expected Output: 
true
true
true

The last comparison is true because both operands are strings. Their first characters are compared: "1" comes before "2".

When both operands are strings, relational comparison follows lexicographical ordering. When both are numbers, it follows numeric ordering.

10. Operator Precedence and Parentheses

Operator precedence determines the order in which operators are evaluated in an expression.

10.1 Multiplication Before Addition

let result = 10 + 5 * 2;

console.log(result);
Expected Output: 
20

Multiplication is evaluated before addition.

10.2 Using Parentheses

let result = (10 + 5) * 2;

console.log(result);
Expected Output: 
30

10.3 Assignment and Arithmetic

let result = x + 5 * 2;

console.log(result);

20

11. Common Mistakes and Debugging

Mistake 1: Confusing = with ===

let age = 25;

console.log(age === 25);

= assigns a value, while === compares values and types.

Mistake 2: Confusing ++x and x++

Pre-increment updates the variable before returning its value. Post-increment returns the old value before updating the variable.

Mistake 3: Assuming % Calculates Percentage

The % operator calculates a remainder, not a percentage. To calculate a percentage, use multiplication and division. 

let percentage = 200 * 10 / 100;

console.log(percentage);
Expected Output: 
20

Mistake 4: Using == Without Considering Types

console.log(5 == "5");

console.log(5 === "5");
Expected Output: 
true
false

Mistake 5: Incorrect String Comparison

Numeric-looking strings may be compared lexicographically when both operands are strings. Convert them to numbers when numeric comparison is intended. 

console.log("20" < "3");

console.log(Number("20") < Number("3"));
Expected Output: 
true
false

Mistake 6: Assuming Division Always Returns an Integer

console.log(7 / 2);
Expected Output: 
3.5

12. Important Placement Interview Questions

Q1. What is an operator in JavaScript?

Answer: An operator is a symbol or keyword that performs an operation on one or more operands.

Q2. What is the difference between an operator and an operand?

Answer: An operator performs an operation, while operands are the values or variables on which the operation is performed.

Q3. What is the difference between / and %?

Answer: Division (/) returns the quotient, while remainder (%) returns the remainder after division.

Q4. How can you check whether a number is even?

Answer: Check whether number % 2 === 0.

Q5. What is the difference between x++ and ++x?

Answer: Post-increment returns the original value before incrementing. Pre-increment increments first and returns the updated value.

Q6. What are compound assignment operators?

Answer: Operators such as +=, -=, *= and /= combine an arithmetic operation with assignment.

Q7. What is the difference between == and ===?

Answer: == permits type coercion when comparing values, whereas === performs strict comparison without converting different types.

Q8. What is the difference between != and !==?

Answer: != performs loose inequality comparison, while !== performs strict inequality comparison.

Q9. What is the result of 2 ** 3?

Answer: 8, because 2 is raised to the power of 3.

Q10. Does a comparison operator return a number?

Answer: No. It returns a Boolean value: true or false.

Q11. What is operator precedence?

Answer: It defines the order in which operators are evaluated within an expression.

Q12. How do you calculate a percentage in JavaScript?

Answer: Multiply the value by the percentage and divide by 100.

Q13. What does += do with strings?

Answer: It can concatenate a string with another value after the required string conversion.

Q14. How can you compare two numeric strings numerically?

Answer: Convert them into numbers using Number() before comparing them.

Q15. Which equality operator is generally preferred?

Answer: Strict equality (===) is generally preferred because it avoids unexpected type coercion.
