ES6 Overview and Modern JavaScript Features

Understand ECMAScript 2015 (ES6), modern JavaScript syntax, variable declarations, block scope, template literals, arrow functions and the features commonly used in frontend development and JavaScript interviews.

1. Learning Objectives

After completing this lecture, you should be able to:

  • Explain the relationship between JavaScript and ECMAScript.
  • Understand ES6 and its importance in modern development.
  • Differentiate between var, let and const.
  • Explain global, function and block scope.
  • Understand hoisting and the Temporal Dead Zone.
  • Use template literals and string interpolation.
  • Write and use arrow functions correctly.
  • Understand lexical this in arrow functions.
  • Recognize modern JavaScript features used in frontend applications.

2. What Is ECMAScript?

JavaScript is a programming language used to develop interactive websites and applications. ECMAScript is the language specification that defines the core features and behaviour of JavaScript.

The specification is maintained through the standardization process associated with ECMA International and TC39, the technical committee responsible for evolving ECMAScript.

JavaScript vs ECMAScript

JavaScript ECMAScript
A programming language used in browsers, servers and other environments. A standardized specification defining the language's core behaviour.
Provides practical implementations of the language. Defines syntax, data types, functions and language features.
Used to build interactive applications. Provides the standard that JavaScript implementations follow.
Interview Tip: JavaScript is the language; ECMAScript is the standard specification on which its core language features are based.

3. What Is ES6?

ES6 stands for ECMAScript 2015. It was a major update to JavaScript that introduced several important features to make code more readable, maintainable and suitable for large applications.

Important ES6 Features

  • let and const declarations.
  • Block scope.
  • Arrow functions.
  • Template literals.
  • Default parameters.
  • Rest and spread operators.
  • Destructuring assignment.
  • Classes and inheritance.
  • Modules using import and export.
  • Promises.
  • Map and Set collections.
  • Symbols and iterators.

Modern JavaScript did not stop at ES6. ECMAScript has continued evolving through annual editions, adding features such as optional chaining and nullish coalescing.

Important: ES6 and ECMAScript 2015 refer to the same major release. Features introduced in later ECMAScript editions should not automatically be described as ES6 features.

4. Variable Declarations: var, let and const

JavaScript provides three commonly used keywords for declaring variables: var, let and const. Their scope, redeclaration and reassignment behaviour differ.

4.1 var

The var keyword declares a function-scoped or globally scoped variable. 

var username = "Rahul";

console.log(username);

username = "Amit";

console.log(username);
Expected Output: 
Rahul
Amit

A variable declared using var can be reassigned and redeclared within the same scope. 

var age = 22;
var age = 25;

console.log(age);
Expected Output: 
25

4.2 let

The let keyword declares a block-scoped variable. It can be reassigned but cannot be redeclared in the same scope. 

let score = 50;

score = 80;

console.log(score);
Expected Output: 
80

Redeclaring the same variable in the same scope produces an error:

let marks = 75;

let marks = 90; // SyntaxError

4.3 const

The const keyword declares a block-scoped binding that cannot be reassigned after initialization. 

const country = "India";

console.log(country);
Expected Output: 
India

Reassignment is not allowed:

const pi = 3.14;

pi = 3.14159; // TypeError

4.4 Can a const object be modified?

Yes. const prevents reassignment of the variable binding. It does not automatically make an object or array immutable. 

const employee = {
    name: "Rahul",
    salary: 30000
};

employee.salary = 40000;

employee.department = "Development";

console.log(employee);
Expected Output: 
{
  name: "Rahul",
  salary: 40000,
  department: "Development"
}

However, assigning a completely new object to employee is not allowed. 

employee = { name: "Amit" }; // TypeError

4.5 Comparison of var, let and const

Property var let const
Scope Function or global Block Block
Redeclaration in same scope Allowed Not allowed Not allowed
Reassignment Allowed Allowed Not allowed
Initialization required No No Yes
Hoisting Initialized with undefined Uninitialized until declaration Uninitialized until declaration
Temporal Dead Zone No Yes Yes
Placement Recommendation: Prefer const by default. Use let when reassignment is required. Avoid introducing new var declarations in modern application code unless legacy behaviour is specifically needed.

5. Scope in JavaScript

Scope determines where a variable can be accessed in a program. Understanding scope is essential for debugging and writing predictable JavaScript applications.

5.1 Global Scope

A variable declared outside functions and blocks is generally accessible throughout its relevant script or module environment. 

let company = "Tech Solutions";

function displayCompany() {
    console.log(company);
}

displayCompany();
console.log(company);
Expected Output: 
Tech Solutions
Tech Solutions

5.2 Function Scope

Variables declared with var inside a function are accessible within that function. 

function calculateSalary() {
    var salary = 35000;

    console.log(salary);
}

calculateSalary();

// console.log(salary); // ReferenceError
Expected Output: 
35000

5.3 Block Scope

A block is a section of code enclosed in curly braces. Variables declared with let and const are limited to the block in which they are declared. 

{
    let city = "Chandigarh";
    const pinCode = 160001;

    console.log(city);
    console.log(pinCode);
}

// console.log(city);    // ReferenceError
// console.log(pinCode); // ReferenceError
Expected Output: 
Chandigarh
160001

5.4 var vs let inside a block

{
    var a = 10;
    let b = 20;
}

console.log(a);

// console.log(b); // ReferenceError
Expected Output: 
10

The var declaration is not restricted by the ordinary block, whereas let is block-scoped.

6. Hoisting and Temporal Dead Zone

6.1 What Is Hoisting?

Hoisting describes how JavaScript processes declarations before executing the code in their scope. It does not mean that source code is physically moved to the top.

Example using var:

console.log(value);

var value = 100;
Expected Output: 
undefined

The declaration is processed before execution, but the assignment happens at its original position.

6.2 let and const hoisting

Variables declared with let and const are also hoisted, but they remain uninitialized until their declaration is evaluated. 

console.log(price);

let price = 500; // ReferenceError

The same issue occurs with const:

console.log(rate);

const rate = 10; // ReferenceError

6.3 Temporal Dead Zone (TDZ)

The Temporal Dead Zone is the period between entering a scope and evaluating the declaration of a let or const variable. 

{
    // TDZ begins

    // console.log(amount); // ReferenceError

    let amount = 500;

    // TDZ ends

    console.log(amount);
}
Expected Output: 
500
Remember: Accessing a let or const variable before its declaration is evaluated results in a ReferenceError.

7. Template Literals

Template literals were introduced in ES6. They use backticks (`) instead of ordinary single or double quotes. They support string interpolation and multiline strings.

7.1 String Interpolation

String interpolation allows variables and expressions to be embedded inside a string using ${...}. 

const name = "Rahul";
const age = 24;

const message = `My name is ${name} and I am ${age} years old.`;

console.log(message);
Expected Output: 
My name is Rahul and I am 24 years old.

7.2 Expressions inside template literals

const a = 10;
const b = 20;

console.log(`Sum = ${a + b}`);
console.log(`Product = ${a * b}`);
Expected Output: 
Sum = 30
Product = 200

7.3 Multiline Strings

const address = `House No. 25
Sector 17
Chandigarh
India`;

console.log(address);
Expected Output: 
House No. 25
Sector 17
Chandigarh
India

7.4 Practical Frontend Example

const product = "Laptop";
const price = 55000;

const productCard = `
    Product: ${product}
    Price: ₹${price}
`;

console.log(productCard);
Expected Output: 

    Product: Laptop
    Price: ₹55000

7.5 Tagged Template Literals

A tagged template passes the template's string segments and interpolated values to a function. This is useful in specialized formatting and template-processing libraries. 

function showDetails(strings, name, role) {
    console.log(strings[0]);
    console.log(name);
    console.log(strings[1]);
    console.log(role);
    console.log(strings[2]);
}

const name = "Amit";
const role = "Frontend Developer";

showDetails`Employee ${name} works as ${role}.`;
Expected Output: 
Employee
Amit
 works as
Frontend Developer
.
Interview Tip: Template literals improve readability when constructing strings containing variables, expressions or multiple lines.

8. Arrow Functions

Arrow functions provide a shorter syntax for writing function expressions. They were introduced in ES6 and are widely used in modern JavaScript.

8.1 Traditional Function

function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
Expected Output: 
30

8.2 Equivalent Arrow Function

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 20));
Expected Output: 
30

8.3 Arrow Function with Implicit Return

When the function body contains a single expression, curly braces and the return keyword can be omitted. 

const multiply = (a, b) => a * b;

console.log(multiply(5, 4));
Expected Output: 
20

8.4 Single Parameter

const square = number => number * number;

console.log(square(6));
Expected Output: 
36

8.5 No Parameters

const greet = () => "Welcome to JavaScript";

console.log(greet());
Expected Output: 
Welcome to JavaScript

8.6 Returning an Object

When returning an object directly from an implicit-return arrow function, wrap the object literal in parentheses. 

const createEmployee = (name, salary) => ({
    name: name,
    salary: salary
});

console.log(createEmployee("Amit", 40000));
Expected Output: 
{ name: "Amit", salary: 40000 }

8.7 Arrow Functions in Array Methods

Arrow functions are frequently used with methods such as map(), filter() and forEach(). 

const numbers = [10, 20, 30, 40];

const doubled = numbers.map(number => number * 2);

console.log(doubled);
Expected Output: 
[20, 40, 60, 80]

8.8 Arrow Functions in Event Handling

const button = document.querySelector("#submitBtn");

button.addEventListener("click", () => {
    console.log("Button clicked");
});

When the user clicks the button, the callback function executes and displays the message in the browser console.

9. Arrow Functions and the this Keyword

One of the most important differences between ordinary functions and arrow functions is how they handle this.

9.1 Ordinary Function

In an ordinary function, the value of this generally depends on how the function is called. 

const employee = {
    name: "Rahul",

    showName: function() {
        console.log(this.name);
    }
};

employee.showName();
Expected Output: 
Rahul

9.2 Arrow Function and Lexical this

Arrow functions do not create their own this. They inherit it lexically from the surrounding scope. 

function Employee() {
    this.name = "Rahul";

    setTimeout(() => {
        console.log(this.name);
    }, 1000);
}

new Employee();
Expected Output after approximately one second: 
Rahul

The arrow function uses the this value from the surrounding Employee function call.

9.3 Common Mistake: Arrow Function as an Object Method

const user = {
    name: "Amit",

    showName: () => {
        console.log(this.name);
    }
};

user.showName();

This does not reliably print Amit. The arrow function does not receive this from the object method call. Its this comes from the surrounding lexical environment.

Important: Use ordinary method syntax for object methods that need this to refer to the object.

9.4 Important Arrow Function Limitations

  • Arrow functions do not have their own this.
  • They do not have their own arguments object.
  • They cannot be used as constructors with new.
  • They do not have their own super binding.
  • They do not have their own new.target.
  • They are not suitable for every object method or callback.

10. Default Parameters

Default parameters allow function parameters to have predefined values when an argument is omitted or explicitly passed as undefined. 

function greet(name = "Guest") {
    console.log(`Hello, ${name}`);
}

greet("Rahul");
greet();
Expected Output: 
Hello, Rahul
Hello, Guest

An explicitly supplied null does not activate the default value. 

function display(value = 100) {
    console.log(value);
}

display(undefined);
display(null);
Expected Output: 
100
null

11. for...of Loop

The for...of loop iterates over values produced by an iterable object, such as an array or string. 

const languages = ["JavaScript", "Python", "C++"];

for (const language of languages) {
    console.log(language);
}
Expected Output: 
JavaScript
Python
C++

Iterating over a String

const word = "JS";

for (const character of word) {
    console.log(character);
}
Expected Output: 
J
S
Difference: for...of iterates over values of an iterable. for...in iterates over enumerable property keys. For ordinary arrays, use for...of when you need the element values.

12. let vs var in Loops: Common Interview Problem

This example demonstrates why block scope matters when callbacks execute after a loop has completed.

Using var

for (var i = 1; i <= 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 1000);
}
Expected Output after approximately one second: 
4
4
4

The var variable is shared across all loop iterations. By the time the callbacks execute, the loop has completed and i has the value 4.

Using let

for (let i = 1; i <= 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 1000);
}
Expected Output after approximately one second: 
1
2
3

With let, each loop iteration has its own block-scoped binding, so each callback retains the expected value.

Frequently Asked Interview Question: Why does var print 4 three times, while let prints 1, 2 and 3?

Answer: var is function-scoped and shares one binding across the loop. let creates a separate binding for each loop iteration.

13. Modern JavaScript in Frontend Development

Modern JavaScript syntax is used extensively in frontend applications. The following example combines several features introduced in ES6.

Practical Example: Display Employee Information

const employee = {
    name: "Rahul",
    role: "Frontend Developer",
    salary: 45000
};

const getEmployeeDetails = (person) => {
    return `
        Employee Name: ${person.name}
        Role: ${person.role}
        Salary: ₹${person.salary}
    `;
};

const result = getEmployeeDetails(employee);

console.log(result);
Expected Output: 

        Employee Name: Rahul
        Role: Frontend Developer
        Salary: ₹45000

Features demonstrated:

  • const for variable declarations.
  • Object literals for structured data.
  • Arrow functions for concise function expressions.
  • Template literals for readable dynamic strings.

14. Browser Compatibility and Transpilation

Modern JavaScript features are supported by current browsers and JavaScript runtimes, but compatibility can differ across older environments.

What is a Transpiler?

A transpiler converts source code written using newer language features into code compatible with older JavaScript environments.

Babel is a commonly used JavaScript compiler that can transform modern JavaScript syntax into compatible output based on the configured target environments.

What is a Build Tool?

Build tools such as Vite and webpack help prepare application code for development and production. Depending on configuration, they can integrate transpilation, bundling and other processing.

Interview Point: Modern syntax support and API support are different concerns. A transpiler can transform syntax, but it does not automatically provide every missing browser API. Polyfills may be needed for unsupported APIs.

15. Common Mistakes and Debugging

Mistake 1: Using const without initialization

const age; // SyntaxError

Correction:

const age = 25;

Mistake 2: Reassigning const

const count = 10;
count = 20; // TypeError

Correction: Use let if reassignment is required.

Mistake 3: Accessing let before declaration

console.log(total);
let total = 100; // ReferenceError

Correction: Declare the variable before accessing it.

Mistake 4: Returning an object incorrectly

const getUser = () => {
    name: "Rahul"
};

This does not return the intended object. The braces are interpreted as a function body.

Correction:

const getUser = () => ({
    name: "Rahul"
});

Mistake 5: Using an arrow function as a constructor

const Person = (name) => {
    this.name = name;
};

const person = new Person("Rahul"); // TypeError

Correction: Use a regular function constructor or a class when creating objects with new.

16. Placement Interview Questions and Answers

Q1. What is ES6?

ES6 is the common name for ECMAScript 2015, a major JavaScript update that introduced features such as let, const, arrow functions, template literals, classes and modules.

Q2. What is the difference between JavaScript and ECMAScript?

JavaScript is the programming language, while ECMAScript is the standardized specification defining its core language features.

Q3. What is the difference between var, let and const?

var is function-scoped or global-scoped. let and const are block-scoped. let allows reassignment, whereas const does not allow reassignment.

Q4. Does const make an object immutable?

No. It prevents reassignment of the binding, but the object's properties can still be modified unless additional immutability techniques are used.

Q5. What is the Temporal Dead Zone?

It is the period from entering a scope until a let or const declaration is evaluated. Accessing the variable during this period causes a ReferenceError.

Q6. What is the difference between function scope and block scope?

Function scope limits a variable to a function. Block scope limits it to a specific block enclosed in curly braces.

Q7. What is a template literal?

A template literal is a string enclosed in backticks that supports interpolation and multiline content.

Q8. What is an arrow function?

An arrow function is a shorter function-expression syntax introduced in ES6. It also uses lexical this instead of creating its own this binding.

Q9. Can arrow functions be used as constructors?

No. Arrow functions do not have the internal constructor capability required for use with the new operator.

Q10. Why should arrow functions not always be used as object methods?

Arrow functions inherit this from their surrounding lexical scope. They do not receive this from the object method call.

Q11. What is the difference between == and ===?

The == operator performs equality comparison with type coercion when necessary. The === operator compares without performing type coercion.

Q12. What is the difference between for...of and for...in?

for...of iterates over values from an iterable. for...in iterates over enumerable property keys.

Q13. What is a transpiler?

A transpiler converts source code from one language version or syntax level into another. Babel is a popular JavaScript transpilation tool.

Q14. What happens when a function parameter is omitted?

Without a default parameter, the missing argument has the value undefined. A default parameter can provide an alternative value when the argument is omitted or explicitly undefined.

Q15. Are let and const hoisted?

Yes. Their declarations are processed when entering the scope, but they remain uninitialized in the Temporal Dead Zone until the declaration is evaluated.
