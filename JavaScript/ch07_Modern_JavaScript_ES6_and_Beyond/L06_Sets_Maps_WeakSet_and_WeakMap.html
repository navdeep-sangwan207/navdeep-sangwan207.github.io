Sets, Maps, WeakSet and WeakMap

Learn JavaScript collection objects for storing unique values, managing key-value pairs, handling object references and solving practical frontend and placement coding problems.

1. Learning Objectives

After completing this lecture, you should be able to:

  • Understand JavaScript Set and its uniqueness property.
  • Create, add, delete and search Set elements.
  • Iterate over Set values and convert between Sets and arrays.
  • Use Set for duplicate removal and membership checking.
  • Understand Map and its key-value storage mechanism.
  • Perform common Map operations and iterate over entries.
  • Differentiate Map from ordinary JavaScript objects.
  • Understand WeakSet and WeakMap and their object-reference restrictions.
  • Choose the appropriate collection for practical applications.

2. Introduction to JavaScript Collections

JavaScript provides built-in collection objects for storing and managing groups of values.

Four important collection types are:

Collection Purpose
Set Stores unique values of any type.
Map Stores key-value pairs with keys of any type.
WeakSet Stores weakly held object references.
WeakMap Stores key-value pairs with weakly held object keys.

Why Are Collections Useful?

  • Removing duplicate values from data.
  • Maintaining unique user IDs or product categories.
  • Storing lookup information efficiently.
  • Tracking objects without unnecessarily keeping them alive.
  • Managing temporary metadata associated with objects.

3. Set in JavaScript

3.1 What Is a Set?

A Set is a built-in JavaScript collection that stores unique values. Duplicate values are automatically ignored.

Syntax:

const mySet = new Set();

3.2 Creating a Set

const numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(30);

console.log(numbers);
Expected Output: 
Set(3) { 10, 20, 30 }

3.3 Creating a Set from an Array

const numbers = [10, 20, 10, 30, 20, 40];

const uniqueNumbers = new Set(numbers);

console.log(uniqueNumbers);
console.log(uniqueNumbers.size);
Expected Output: 
Set(4) { 10, 20, 30, 40 }
4

3.4 Duplicate Values Are Ignored

const languages = new Set();

languages.add("JavaScript");
languages.add("Python");
languages.add("JavaScript");
languages.add("C");

console.log(languages.size);

for (const language of languages) {
    console.log(language);
}
Expected Output: 
3
JavaScript
Python
C
Important: Set preserves insertion order. When a duplicate is added, the existing value remains in its original position.

7.1 Removing Duplicates from an Array

console.log(uniqueNumbers);
Expected Output:

const setA = new Set([1, 2, 3]);

const setA = new Set([1, 2, 3, 4]);

const setA = new Set([1, 2, 3, 4]);
const setB = new Set([3, 4, 5, 6]);

const intersection = [...setA].filter(value => setB.has(value));

console.log(intersection);
Expected Output: 
[3, 4]

8. Object Values and Set Uniqueness

Set compares objects by reference identity, not by their property contents.

8.1 Two Different Objects with the Same Properties

const set = new Set();

set.add({ name: "Rahul" });
set.add({ name: "Rahul" });

console.log(set.size);
Expected Output: 
2

The two object literals create separate object references. Therefore, both are stored in the Set.

8.2 Adding the Same Object Reference Twice

const user = { name: "Rahul" };

const users = new Set();

users.add(user);
users.add(user);

console.log(users.size);
Expected Output: 
1
Interview Point: Set uses SameValueZero equality for determining duplicate values. This means NaN is treated as equal to NaN, and positive zero and negative zero are treated as equal.

9. Map in JavaScript

9.1 What Is a Map?

A Map is a JavaScript collection that stores data in key-value pairs. Unlike ordinary object properties, Map keys can be values of any type, including objects, functions and primitive values.

Syntax:

const myMap = new Map();

9.2 Creating a Map

const student = new Map();

student.set("name", "Rahul");
student.set("age", 22);
student.set("course", "JavaScript");

    "name" => "Rahul",
    "age" => 22,
    "course" => "JavaScript"

13. Map vs Ordinary JavaScript Object

Feature Map Object
Keys Any value can be a key. Property keys are strings or symbols.
Size Provides the size property. No direct size property.
Iteration Directly iterable. Not directly iterable by default.
Insertion order Maintains insertion order. Property enumeration follows defined ordering rules.
Key types Primitive values and object references. Strings and symbols.
Common usage Dynamic key-value collections. Structured records and objects.

Example: Object

Example: Map

2
Use an ordinary object for structured records with known properties. Use Map when you need a dynamic collection, non-string keys, direct size information or frequent key-value operations.

15. WeakSet in JavaScript

15.1 What Is WeakSet?

WeakSet is a collection that stores weakly held references to objects. It is useful when an application needs to track objects without making those objects stay alive solely because they are members of the collection.

Syntax:

const weakSet = new WeakSet();

15.2 Creating a WeakSet

const weakSet = new WeakSet();

const user1 = { name: "Rahul" };
const user2 = { name: "Amit" };

weakSet.add(user1);
weakSet.add(user2);

console.log(weakSet.has(user1));
console.log(weakSet.has(user2));
Expected Output: 
true
true

15.3 WeakSet Accepts Objects

const weakSet = new WeakSet();

const user = { name: "Rahul" };

weakSet.add(user);

console.log(weakSet.has(user));
Expected Output: 
true

WeakSet does not accept primitive values such as strings, numbers or booleans.

15.4 WeakSet Methods

Method Purpose
add(object) Adds an object reference.
has(object) Checks whether an object is present.
delete(object) Removes an object reference.

15.5 Deleting an Object

const weakSet = new WeakSet();

const user = { name: "Rahul" };

weakSet.add(user);

console.log(weakSet.has(user));

weakSet.delete(user);

console.log(weakSet.has(user));
Expected Output: 
true
false

15.6 WeakSet Limitations

  • WeakSet is not iterable.
  • It does not have a size property.
  • It does not provide keys(), values() or entries().
  • It cannot be cleared using clear().
  • It stores objects and non-registered symbols that are eligible as weak keys in supporting modern JavaScript environments; ordinary primitive values such as strings and numbers are not accepted.
Important: Garbage collection is controlled by the JavaScript engine. You cannot directly determine when an object will be removed from a WeakSet.

16. Practical Applications of WeakSet

16.1 Tracking Processed Objects

const processedUsers = new WeakSet();

function processUser(user) {
    if (processedUsers.has(user)) {
        console.log("User already processed");
        return;
    }

    processedUsers.add(user);

    console.log("Processing:", user.name);
}

const user1 = { name: "Rahul" };

processUser(user1);
processUser(user1);
Expected Output: 
Processing: Rahul
User already processed

16.2 Tracking Active Objects

const activeObjects = new WeakSet();

const component = {
    id: 101,
    name: "Header"

console.log(activeObjects.has(component));

WeakSet can be useful for tracking object processing, temporary object membership and certain internal implementation details.

17. WeakMap in JavaScript

17.1 What Is WeakMap?

WeakMap stores key-value pairs in which keys are weakly held. It is useful for associating additional information with objects without making the keys stay alive solely because they are stored in the collection.

Syntax:

const weakMap = new WeakMap();

17.2 Creating a WeakMap

const weakMap = new WeakMap();

const user = { name: "Rahul" };

weakMap.set(user, "Premium User");

console.log(weakMap.get(user));
Expected Output: 
Premium User

17.3 WeakMap Requires Valid Weak Keys

const weakMap = new WeakMap();

const user = { id: 101 };

weakMap.set(user, "Admin");

console.log(weakMap.has(user));
Expected Output: 
true

Ordinary primitive values such as strings and numbers cannot be used as WeakMap keys. Objects and non-registered symbols are supported as weak keys in modern JavaScript implementations.

17.4 WeakMap Methods

Method Purpose
set(key, value) Adds or updates an entry.
get(key) Returns the associated value.
has(key) Checks whether a key exists.
delete(key) Removes an entry.

17.5 Using get(), has() and delete()

const weakMap = new WeakMap();

const user = { id: 101 };

weakMap.set(user, "Developer");

console.log(weakMap.has(user));
console.log(weakMap.get(user));

weakMap.delete(user);

console.log(weakMap.has(user));
Expected Output: 
true
Developer
false

17.6 WeakMap Limitations

  • WeakMap is not iterable.
  • It does not have a size property.
  • It does not provide keys(), values() or entries().
  • It does not support clear().
  • Its keys must be valid weak keys.

18. Practical Applications of WeakMap

18.1 Storing Private Metadata for Objects

const userMetadata = new WeakMap();

const user = {
    name: "Rahul"
};

userMetadata.set(user, {
    lastLogin: "2026-11-22",

});

console.log(userMetadata.get(user).role);
console.log(userMetadata.get(user).lastLogin);
Expected Output: 
Admin
2026-11-22

18.2 Associating Additional Data with DOM Elements

const elementData = new WeakMap();

const button = document.createElement("button");

elementData.set(button, {
    action: "submit",
    clicks: 0
});

button.addEventListener("click", () => {
    const data = elementData.get(button);

    data.clicks++;

    console.log(data.clicks);
});

This example can be executed in a browser. The WeakMap associates application data with a DOM element without adding custom properties directly to that element.

20. Time Complexity and Performance Considerations

Set and Map are designed for efficient collection operations. Their average access, insertion and deletion performance is generally expected to be sublinear, commonly close to constant time in typical implementations.

Operation Typical Average Complexity
Set add() O(1)
Set has() O(1)
Set delete() O(1)
Map set() O(1)
Map get() O(1)
Map has() O(1)
Map delete() O(1)
Technical Note: These are typical average-case expectations, not a language-level guarantee that every operation always takes constant time. Actual performance depends on the JavaScript engine, data and implementation.

21. Placement Interview Questions and Answers

Q1. What is a Set in JavaScript?

Set is a collection that stores unique values and preserves insertion order.

Q2. How do you remove duplicates from an array?

Convert the array into a Set and spread the Set back into an array: [...new Set(array)].

Q3. Does Set allow duplicate values?

No. Duplicate values according to its equality rules are stored only once.

Q4. What is a Map?

Map is a collection of key-value pairs in which keys can be values of any type.

Q5. Can an object be used as a Map key?

Yes. Map supports object references as keys. Object keys are compared by reference identity.

Q6. What is the difference between Map and Object?

Map supports keys of any type, has a direct size property and is iterable. Ordinary object property keys are strings or symbols and objects are commonly used for structured records.

Q7. What is WeakSet?

WeakSet is a collection of weakly held object references. It is not iterable and does not expose a size property.

Q8. What is WeakMap?

WeakMap stores key-value pairs with weakly held keys. It is useful for associating metadata with objects.

Q9. Why are WeakSet and WeakMap not iterable?

Their weakly held entries can disappear when objects become eligible for garbage collection. Exposing a stable iteration or size would conflict with this weak-reference behaviour.

Q10. Can WeakMap use strings as keys?

No. Ordinary strings and numbers are not valid WeakMap keys. Objects and non-registered symbols are valid weak keys in modern JavaScript.

Q11. Does Set compare objects by their contents?

No. Objects are compared by reference identity. Two different objects with identical properties are still considered different values.

Q12. Can Map contain duplicate keys?

No. Setting an existing key updates its associated value rather than creating another entry.

Q13. What is the difference between Set and WeakSet?

Set supports primitive and object values and is iterable. WeakSet stores weakly held object references and is not iterable.

Q14. What is the difference between Map and WeakMap?

Map supports any key type, iteration and size information. WeakMap uses valid weak keys and does not support iteration or a size property.

Q15. What is SameValueZero?

It is the equality algorithm used by Set and Map key comparisons. It treats NaN as equal to NaN and positive and negative zero as equal.

    return frequency;

const result = countFrequency(["A", "B", "A", "C", "B", "A"]);

for (const [key, value] of result) {
    console.log(key + ": " + value);
}
Expected Output:

B: 2

Problem 4: Find Common Elements

function findCommon(first, second) {
    const secondSet = new Set(second);

    return [...new Set(first)].filter(value =>
        secondSet.has(value)
    );
}

console.log(findCommon(
    [1, 2, 3, 4, 4],
    [3, 4, 5, 6]
));
Expected Output: 
[3, 4]

Problem 5: Check Whether Two Arrays Have the Same Unique Elements

function haveSameUniqueElements(first, second) {
    const setA = new Set(first);
    const setB = new Set(second);

    if (setA.size !== setB.size) {
        return false;
    }

    for (const value of setA) {
        if (!setB.has(value)) {
            return false;
        }
    }

    return true;
}

console.log(
    haveSameUniqueElements([1, 2, 2, 3], [3, 2, 1])
);

console.log(
    haveSameUniqueElements([1, 2], [1, 3])
);
Expected Output: 
true
false

Problem 6: Find the Most Frequent Element

function mostFrequent(array) {
    const frequency = new Map();

    let maxCount = 0;
    let result = null;

    for (const value of array) {
        const count = (frequency.get(value) ?? 0) + 1;

        frequency.set(value, count);

        if (count > maxCount) {
            maxCount = count;
            result = value;
        }
    }

    return result;
}

console.log(mostFrequent([1, 2, 2, 3, 3, 3, 4]));
Expected Output: 
3

If multiple values have the same maximum frequency, this implementation returns the one that reaches that frequency first during traversal.

25. Quick Revision

Concept Remember
Set Stores unique values.
Set size Returns the number of unique values.
Set has() Checks whether a value exists.
Map Stores key-value pairs.
Map get() Retrieves a value using its key.
Map set() Adds or updates a key-value pair.
WeakSet Stores weakly held object references.
WeakMap Stores values associated with weakly held keys.
Weak collections Not iterable and have no size property.

Set and Map are important for JavaScript coding rounds, particularly duplicate removal, frequency counting, lookup operations and collection comparisons. WeakSet and WeakMap are useful when working with object references, metadata and memory-aware application design.
