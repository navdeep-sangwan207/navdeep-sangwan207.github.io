Destructuring Arrays and Objects in Practice

Learn how to extract values from arrays and objects using destructuring assignment. Practise default values, variable renaming, nested destructuring, function parameters and real-world frontend development patterns.

1. Learning Objectives

After completing this lecture, you should be able to:

  • Understand JavaScript destructuring assignment.
  • Extract individual values from arrays.
  • Skip array elements and assign default values.
  • Use rest syntax while destructuring arrays.
  • Extract object properties into variables.
  • Rename variables during object destructuring.
  • Use default values for missing object properties.
  • Perform nested array and object destructuring.
  • Destructure function parameters.
  • Apply destructuring in frontend development and coding interviews.

2. What Is Destructuring?

Destructuring is a JavaScript assignment syntax introduced in ES6. It allows values from arrays or properties from objects to be extracted and assigned to variables.

Without Destructuring

const employee = {
    name: "Rahul",
    age: 25,
    department: "Development"
};

const name = employee.name;
const age = employee.age;
const department = employee.department;

console.log(name);
console.log(age);
console.log(department);
Expected Output: 
Rahul
25
Development

With Destructuring

const employee = {
    name: "Rahul",
    age: 25,
    department: "Development"
};

const { name, age, department } = employee;

console.log(name);
console.log(age);
console.log(department);
Expected Output: 
Rahul
25
Development

Both examples produce the same result. Destructuring provides a shorter and more readable way to extract values.

Array Destructuring Object Destructuring
Extracts values based on position. Extracts values based on property names.
Uses square brackets []. Uses curly braces {}.
Element order matters. Property order generally does not matter.

3. Array Destructuring

Array destructuring extracts elements from an array and assigns them to variables according to their positions.

3.1 Basic Array Destructuring

const languages = ["C", "C++", "JavaScript"];

const [first, second, third] = languages;

console.log(first);
console.log(second);
console.log(third);
Expected Output: 
C
C++
JavaScript

The first variable receives the first array element, the second receives the second element, and so on.

3.2 Extracting Selected Elements

You do not need to extract every element from an array. 

const numbers = [10, 20, 30, 40, 50];

const [first, second] = numbers;

console.log(first);
console.log(second);
Expected Output: 
10
20

3.3 Skipping Array Elements

Empty positions between commas allow you to skip unwanted elements. 

const values = [10, 20, 30, 40, 50];

const [first, , third, , fifth] = values;

console.log(first);
console.log(third);
console.log(fifth);
Expected Output: 
10
30
50

3.4 Default Values in Array Destructuring

A default value is used when the corresponding array element is undefined or does not exist. 

const numbers = [10];

const [a = 100, b = 200] = numbers;

console.log(a);
console.log(b);
Expected Output: 
10
200

The first value is available, so its default is not used. The second position is missing, so the default value is used.

Explicit undefined also activates the default:

const values = [undefined, null];

const [first = 10, second = 20] = values;

console.log(first);
console.log(second);
Expected Output: 
10
null

3.5 Rest Element in Array Destructuring

The rest element collects remaining array elements into a new array. 

const numbers = [10, 20, 30, 40, 50];

const [first, second, ...remaining] = numbers;

console.log(first);
console.log(second);
console.log(remaining);
Expected Output: 
10
20
[30, 40, 50]
Important Rules:
  • The rest element must be the last element in the pattern.
  • Only one rest element is allowed in a destructuring pattern.
  • The rest element collects remaining values into an array.

3.6 Swapping Variables Using Destructuring

Destructuring allows two variables to exchange values without using a temporary variable. 

let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a);
console.log(b);
Expected Output: 
20
10

3.7 Destructuring from a Function Return Value

A function can return an array, and its values can be extracted directly through destructuring. 

function calculate(a, b) {
    return [a + b, a * b];
}

const [sum, product] = calculate(5, 4);

console.log(sum);
console.log(product);
Expected Output: 
9
20

4. Object Destructuring

Object destructuring extracts properties from an object and assigns their values to variables.

4.1 Basic Object Destructuring

const student = {
    name: "Amit",
    age: 22,
    course: "JavaScript"
};

const { name, age, course } = student;

console.log(name);
console.log(age);
console.log(course);
Expected Output: 
Amit
22
JavaScript

Object destructuring uses property names rather than property positions.

4.2 Extracting Selected Properties

const product = {
    id: 101,
    name: "Laptop",
    price: 55000,
    category: "Electronics"
};

const { name, price } = product;

console.log(name);
console.log(price);
Expected Output: 
Laptop
55000

4.3 Variable Renaming

You can assign an object property to a variable with a different name using the colon syntax. 

const employee = {
    name: "Rahul",
    salary: 40000
};

const {
    name: employeeName,
    salary: monthlySalary
} = employee;

console.log(employeeName);
console.log(monthlySalary);
Expected Output: 
Rahul
40000

Here, name is the object property and employeeName is the newly declared variable.

4.4 Default Values in Object Destructuring

Default values are useful when an object does not contain a particular property or its value is undefined. 

const user = {
    name: "Amit"
};

const {
    name,
    age = 25,
    city = "Chandigarh"
} = user;

console.log(name);
console.log(age);
console.log(city);
Expected Output: 
Amit
25
Chandigarh

4.5 Renaming with Default Values

const employee = {
    name: "Rahul"
};

const {
    name: employeeName,
    department: employeeDepartment = "IT"
} = employee;

console.log(employeeName);
console.log(employeeDepartment);
Expected Output: 
Rahul
IT

4.6 Extracting Remaining Object Properties

Object rest syntax collects properties that were not explicitly extracted into a new object. 

const employee = {
    name: "Amit",
    age: 25,
    department: "Development",
    salary: 50000
};

const { name, ...otherDetails } = employee;

console.log(name);
console.log(otherDetails);
Expected Output: 
Amit
{
  age: 25,
  department: "Development",
  salary: 50000
}

The rest object contains the remaining enumerable own properties that were not extracted earlier.

5. Nested Array Destructuring

Nested destructuring extracts values from arrays that contain other arrays.

Example

const numbers = [
    [10, 20],
    [30, 40]
];

const [[a, b], [c, d]] = numbers;

console.log(a);
console.log(b);
console.log(c);
console.log(d);
Expected Output: 
10
20
30
40

Practical Example: Student Marks

const students = [
    ["Rahul", 85],
    ["Amit", 90],
    ["Priya", 95]
];

const [[firstName, firstMarks], [secondName, secondMarks]] = students;

console.log(firstName, firstMarks);
console.log(secondName, secondMarks);
Expected Output: 
Rahul 85
Amit 90

6. Nested Object Destructuring

Nested object destructuring extracts properties from objects contained inside other objects.

Example

const employee = {
    name: "Rahul",
    department: {
        name: "Development",
        location: "Chandigarh"
    }
};

const {
    name,
    department: {
        name: departmentName,
        location
    }
} = employee;

console.log(name);
console.log(departmentName);
console.log(location);
Expected Output: 
Rahul
Development
Chandigarh

Notice that the nested department object is destructured directly. The variable departmentName receives its nested name property.

Nested Destructuring with Default Values

const user = {
    name: "Amit"
};

const {
    name,
    address: {
        city = "Unknown"
    } = {}
} = user;

console.log(name);
console.log(city);
Expected Output: 
Amit
Unknown
Important: When destructuring a nested object that might be missing, provide a default object where necessary. Otherwise, destructuring a property from undefined can cause a TypeError.

7. Destructuring Function Parameters

Destructuring can be used directly in function parameters. This is particularly useful when functions receive objects containing multiple configuration values.

7.1 Object Parameter Destructuring

function displayEmployee({ name, salary }) {
    console.log(name);
    console.log(salary);
}

const employee = {
    name: "Rahul",
    salary: 45000
};

displayEmployee(employee);
Expected Output: 
Rahul
45000

7.2 Default Values in Function Parameters

function createUser({
    name = "Guest",
    role = "User"
} = {}) {
    console.log(`Name: ${name}`);
    console.log(`Role: ${role}`);
}

createUser({
    name: "Amit"
});

createUser();
Expected Output: 
Name: Amit
Role: User
Name: Guest
Role: User

The = {} provides a default empty object when no argument is supplied. The individual property defaults handle missing properties.

7.3 Array Parameter Destructuring

function calculate([a, b]) {
    return a + b;
}

console.log(calculate([10, 20]));
console.log(calculate([30, 40]));
Expected Output: 
30
70

8. Destructuring with Loops

Destructuring can make loop code cleaner when working with arrays of objects or key-value pairs.

8.1 Array of Objects

const employees = [
    { name: "Rahul", salary: 40000 },
    { name: "Amit", salary: 45000 },
    { name: "Priya", salary: 50000 }
];

for (const { name, salary } of employees) {
    console.log(`${name}: ₹${salary}`);
}
Expected Output: 
Rahul: ₹40000
Amit: ₹45000
Priya: ₹50000

8.2 Iterating over Map Entries

const employeeMap = new Map([
    ["E101", "Rahul"],
    ["E102", "Amit"],
    ["E103", "Priya"]
]);

for (const [id, name] of employeeMap) {
    console.log(`${id}: ${name}`);
}
Expected Output: 
E101: Rahul
E102: Amit
E103: Priya

9. Practical Frontend Development Applications

9.1 Extracting API Response Data

Frontend applications commonly receive structured data from APIs. Destructuring makes it easier to extract required values. 

const response = {
    status: 200,
    data: {
        id: 101,
        name: "Rahul",
        email: "rahul@example.com"
    }
};

const {
    status,
    data: {
        id,
        name,
        email
    }
} = response;

console.log(status);
console.log(id);
console.log(name);
console.log(email);
Expected Output: 
200
101
Rahul
rahul@example.com

9.2 Extracting Properties from DOM Elements

DOM elements expose properties that can be extracted using object destructuring. 

const button = document.querySelector("#submitBtn");

if (button) {
    const {
        id,
        textContent
    } = button;

    console.log(id);
    console.log(textContent);
}

If the HTML contains a button with id submitBtn, the code displays its id and text.

9.3 Destructuring Configuration Objects

const settings = {
    theme: "dark",
    language: "en",
    notifications: true
};

function initializeApp({
    theme,
    language,
    notifications
}) {
    console.log(`Theme: ${theme}`);
    console.log(`Language: ${language}`);
    console.log(`Notifications: ${notifications}`);
}

initializeApp(settings);
Expected Output: 
Theme: dark
Language: en
Notifications: true

9.4 Removing a Property from an Object Without Mutating It

Object rest destructuring can create a new object containing all properties except the ones explicitly extracted. 

const user = {
    id: 101,
    name: "Rahul",
    password: "secret123"
};

const { password, ...publicUser } = user;

console.log(publicUser);
console.log(user.password);
Expected Output: 
{ id: 101, name: "Rahul" }
secret123
Security Note: This example demonstrates object transformation only. It is not a substitute for proper server-side access control or secure handling of sensitive data.

10. Important Destructuring Rules

Rule Explanation
Array position Array destructuring assigns values according to their positions.
Object property Object destructuring uses property names.
Default value Used when the extracted value is undefined.
Variable renaming Use propertyName: newVariableName.
Array rest Collects remaining elements into an array.
Object rest Collects remaining properties into a new object.
Nested destructuring Extracts values from nested arrays and objects.
Function parameters Allows direct extraction of values from function arguments.

11. Common Mistakes and Debugging

Mistake 1: Using the wrong syntax for objects

const employee = {
    name: "Rahul"
};

const [name] = employee; // TypeError

Object destructuring requires curly braces.

Correction:

const { name } = employee;

Mistake 2: Using the wrong property name

const user = {
    username: "Amit"
};

const { name } = user;

console.log(name);
Expected Output: 
undefined

The object has a property called username, not name.

Correction:

const { username } = user;

console.log(username);

Mistake 3: Incorrect variable renaming syntax

const user = {
    name: "Rahul"
};

// const { name = username } = user; // Not renaming

Correct renaming syntax:

const { name: username } = user;

console.log(username);

Mistake 4: Destructuring a missing nested object

const user = {
    name: "Amit"
};

const {
    address: { city }
} = user; // TypeError

Correction:

const {
    address: { city } = {}
} = user;

console.log(city);
Expected Output: 
undefined

Mistake 5: Rest element in the wrong position

// Invalid syntax:
const [first, ...remaining, last] = [10, 20, 30];

The rest element must be last in the destructuring pattern.

Mistake 6: Confusing default values with null handling

const user = {
    name: null
};

const { name = "Guest" } = user;

console.log(name);
Expected Output: 
null

A default destructuring value applies to undefined, not null.

12. Placement Interview Questions and Answers

Q1. What is destructuring in JavaScript?

Destructuring is syntax that extracts values from arrays or properties from objects and assigns them to variables.

Q2. What is the difference between array and object destructuring?

Array destructuring uses positions, while object destructuring uses property names.

Q3. Can variables be renamed during object destructuring?

Yes. Use the syntax const { name: employeeName } = employee;.

Q4. What happens when a destructured property is missing?

The resulting variable is undefined unless a default value is provided.

Q5. Do default values apply to null?

No. Destructuring defaults apply when the extracted value is undefined, not when it is null.

Q6. Can we skip array elements while destructuring?

Yes. Empty positions represented by commas skip elements.

Q7. What is the rest element in destructuring?

It collects the remaining array elements or object properties into a new array or object.

Q8. Can destructuring be used in function parameters?

Yes. It allows a function to extract values directly from object or array arguments.

Q9. How can two variables be swapped using destructuring?

Use [a, b] = [b, a]; after both variables have been declared with reassignment permitted.

Q10. Can destructuring be nested?

Yes. Nested destructuring extracts values from arrays or objects that contain other arrays or objects.

Q11. Does object destructuring depend on property order?

No. It uses property names rather than property positions.

Q12. Does destructuring modify the original object?

No. Extracting properties does not itself modify the source object. However, extracted values that refer to nested objects still reference those same objects.
