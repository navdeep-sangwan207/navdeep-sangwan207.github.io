Optional Chaining and Nullish Coalescing

Learn how to safely access nested object properties, handle missing values, provide fallback values and prevent common runtime errors in modern JavaScript.

1. Learning Objectives

After completing this lecture, you should be able to:

  • Understand null and undefined in JavaScript.
  • Identify errors caused by accessing missing properties.
  • Use optional chaining with objects and nested properties.
  • Use optional chaining with arrays and function calls.
  • Understand nullish coalescing and its difference from logical OR.
  • Use nullish assignment to initialize missing values.
  • Combine optional chaining and fallback operators.
  • Apply safe property access in frontend applications and API responses.

2. Understanding null and undefined

JavaScript uses null and undefined to represent the absence of a meaningful value, but they have different meanings.

Value Meaning Example
undefined A variable has been declared but not assigned a value. let name;
null An intentional absence of an object or value. let user = null;

Example

let firstName;
let lastName = null;

console.log(firstName);
console.log(lastName);

console.log(typeof firstName);
console.log(typeof lastName);
Expected Output: 
undefined
null
undefined
object
Important: typeof null returns "object". This is a historical JavaScript behaviour, not an indication that null is an actual object.

3. Problems with Accessing Missing Properties

Consider an application that receives user information from an API. The response may not always contain every expected property.

3.1 Accessing an Existing Property

const user = {
    name: "Rahul",
    age: 25
};

console.log(user.name);
Expected Output: 
Rahul

3.2 Accessing a Missing Property

const user = {
    name: "Rahul"
};

console.log(user.email);
Expected Output: 
undefined

Accessing a missing property on an existing object normally returns undefined.

3.3 Accessing a Nested Property of undefined

const user = {
    name: "Rahul"
};

console.log(user.address.city);
Runtime Error: 
TypeError: Cannot read properties of undefined
(reading 'city')

The problem occurs because user.address is undefined. JavaScript cannot read city from an undefined value.

3.4 Traditional Conditional Checking

const user = {
    name: "Rahul"
};

let city;

if (user.address && user.address.city) {
    city = user.address.city;
} else {
    city = "Not available";
}

console.log(city);
Expected Output: 
Not available

These checks work in many situations, but deeply nested structures can make the code lengthy. Optional chaining provides a shorter alternative.

4. Optional Chaining Operator (?.)

4.1 What Is Optional Chaining?

Optional chaining, introduced in ES2020, allows safe access to a property, method or array element when the value before the operator may be null or undefined.

Syntax:

object?.property

If the value before ?. is nullish (null or undefined), the expression evaluates to undefined instead of throwing a TypeError.

4.2 Basic Optional Chaining

const user = {
    name: "Rahul"
};

console.log(user?.name);
console.log(user?.email);
Expected Output: 
Rahul
undefined

4.3 Optional Chaining with Nested Objects

const user = {
    name: "Rahul",
    address: {
        city: "Chandigarh",
        country: "India"
    }
};

console.log(user?.address?.city);
console.log(user?.address?.country);
Expected Output: 
Chandigarh
India

4.4 Handling Missing Nested Objects

const user = {
    name: "Rahul"
};

console.log(user?.address?.city);
Expected Output: 
undefined

4.5 Optional Chaining with Null

const user = null;

console.log(user?.name);
console.log(user?.address?.city);
Expected Output: 
undefined
undefined
Placement Tip: Remember that optional chaining protects access only where the ?. operator is used. It does not automatically make every later property access safe.

5. Optional Chaining with Arrays

5.1 Accessing an Array Element Safely

const users = ["Rahul", "Amit", "Priya"];

console.log(users?.[0]);
console.log(users?.[2]);
console.log(users?.[5]);
Expected Output: 
Rahul
Priya
undefined

5.2 Handling a Null Array

const users = null;

console.log(users?.[0]);
Expected Output: 
undefined

5.3 Accessing Nested Array Data

const response = {
    data: {
        users: [
            { name: "Rahul" },
            { name: "Amit" }
        ]
    }
};

console.log(response?.data?.users?.[0]?.name);
console.log(response?.data?.users?.[1]?.name);
Expected Output: 
Rahul
Amit

6. Optional Chaining with Function Calls

6.1 Optional Function Call

The optional call operator checks whether a value is nullish before attempting to call it.

Syntax:

functionName?.()

6.2 Calling an Existing Function

function greet() {
    console.log("Hello, JavaScript!");
}

greet?.();
Expected Output: 
Hello, JavaScript!

6.3 Calling an Optional Callback

function processData(callback) {
    console.log("Processing data...");

    callback?.();
}

processData(() => {
    console.log("Callback executed");
});

processData();
Expected Output: 
Processing data...
Callback executed
Processing data...

6.4 Optional Method Calls

const user = {
    name: "Rahul",

    greet() {
        console.log("Hello " + this.name);
    }
};

user.greet?.();
Expected Output: 
Hello Rahul

6.5 Important Function Call Difference

const user = {
    greet: "Hello"
};

user.greet?.();
Runtime Error: 
TypeError: user.greet is not a function

Optional call checks whether the value is nullish. It does not check whether a non-nullish value is actually callable.

6.6 Checking an Optional Method Safely

const user = {
    greet: "Hello"
};

if (typeof user.greet === "function") {
    user.greet();
} else {
    console.log("Greet method is unavailable");
}
Expected Output: 
Greet method is unavailable

7. Limitations and Common Mistakes with Optional Chaining

7.1 Optional Chaining Does Not Protect the Entire Expression

const user = {
    address: null
};

console.log(user?.address.city);
Runtime Error: 
TypeError: Cannot read properties of null
(reading 'city')

The first optional chain checks user, but address.city is still accessed normally.

Correct approach:

console.log(user?.address?.city);
Expected Output: 
undefined

7.2 Optional Chaining Cannot Be Used for Assignment

const user = {};

user?.name = "Rahul";
SyntaxError: Optional chaining cannot appear on the left-hand side of an assignment.

Correct approach:

if (user) {
    user.name = "Rahul";
}

console.log(user.name);
Expected Output: 
Rahul

7.3 Optional Chaining Cannot Be Used on Undeclared Variables

console.log(unknownUser?.name);
Runtime Error: 
ReferenceError: unknownUser is not defined

Optional chaining handles nullish values, not undeclared identifiers.

7.4 Optional Chaining Does Not Hide All Errors

It prevents property access errors caused by nullish values along an optional chain. It does not catch unrelated exceptions or validate the structure and type of received data.

8. Nullish Coalescing Operator (??)

8.1 What Is Nullish Coalescing?

The nullish coalescing operator, introduced in ES2020, provides a fallback value when the left-hand expression is null or undefined.

Syntax:

value ?? defaultValue

If the left-hand value is nullish, JavaScript returns the right-hand value. Otherwise, it returns the left-hand value.

8.2 Basic Example

let username = null;

const result = username ?? "Guest";

console.log(result);
Expected Output: 
Guest

8.3 With Undefined

let username;

const result = username ?? "Guest";

console.log(result);
Expected Output: 
Guest

8.4 With a Valid Value

const username = "Rahul";

const result = username ?? "Guest";

console.log(result);
Expected Output: 
Rahul

9. Difference Between ?? and ||

Both operators can provide fallback values, but they evaluate the left-hand value differently.

Value Using || Using ??
null Fallback value Fallback value
undefined Fallback value Fallback value
0 Fallback value 0
"" Fallback value Empty string
false Fallback value false
NaN Fallback value NaN

9.1 Example Using Logical OR

const age = 0;

const result = age || 18;

console.log(result);
Expected Output: 
18

Zero is falsy, so the logical OR operator selects the fallback value.

9.2 Example Using Nullish Coalescing

const age = 0;

const result = age ?? 18;

console.log(result);
Expected Output: 
0

Zero is not null or undefined, so the nullish coalescing operator preserves it.

9.3 Practical Comparison

const username = "";
const score = 0;
const isActive = false;

console.log(username || "Guest");
console.log(username ?? "Guest");

console.log(score || 100);
console.log(score ?? 100);

console.log(isActive || true);
console.log(isActive ?? true);
Expected Output: 
Guest

100
0

true
false
Placement Rule: Use || when all falsy values should trigger a fallback. Use ?? when only null and undefined should trigger a fallback.

10. Nullish Assignment Operator (??=)

10.1 What Is Nullish Assignment?

The nullish assignment operator assigns a value to a variable or property only when its current value is null or undefined.

Syntax:

variable ??= defaultValue;

10.2 Basic Example

let username = null;

username ??= "Guest";

console.log(username);
Expected Output: 
Guest

10.3 Existing Value Is Preserved

let username = "Rahul";

username ??= "Guest";

console.log(username);
Expected Output: 
Rahul

10.4 Zero Is Preserved

let score = 0;

score ??= 100;

console.log(score);
Expected Output: 
0

10.5 Initializing Object Properties

const settings = {
    theme: null,
    language: "en"
};

settings.theme ??= "light";
settings.language ??= "hi";

console.log(settings);
Expected Output: 
{
    theme: "light",
    language: "en"
}

10.6 Difference Between ?? and ??=

Operator Purpose
?? Returns a fallback value when the left side is nullish.
??= Assigns a fallback value when the left side is nullish.

11. Combining Optional Chaining and Nullish Coalescing

These operators are frequently used together when working with nested objects and API responses.

11.1 Accessing Nested Data with a Default Value

const user = {
    profile: {
        name: "Rahul"
    }
};

const city = user?.profile?.address?.city ?? "Unknown";

console.log(city);
Expected Output: 
Unknown

11.2 Handling Missing API Response Data

const response = {
    data: {
        user: {
            name: "Amit"
        }
    }
};

const username = response?.data?.user?.name ?? "Guest";
const email = response?.data?.user?.email ?? "Not provided";

console.log(username);
console.log(email);
Expected Output: 
Amit
Not provided

11.3 Preserving Zero Values

const product = {
    name: "Laptop",
    discount: 0
};

const discount = product?.discount ?? 10;

console.log(discount);
Expected Output: 
0

11.4 Handling Optional Arrays

const response = {
    data: null
};

const firstUser = response?.data?.users?.[0]?.name
    ?? "No user found";

console.log(firstUser);
Expected Output: 
No user found

        name: "Rahul",
        contact: {
            email: "rahul@example.com"
        }
    }

const name = user?.profile?.name ?? "Guest";
const email = user?.profile?.contact?.email
    ?? "Email unavailable";

console.log(email);
Expected Output: 
Rahul
rahul@example.com

12.2 Handling Product Information

const product = {
    name: "Laptop",
    details: {
        brand: "Dell",
        price: 55000
    }
};

const brand = product?.details?.brand ?? "Unknown";

console.log(price);
Expected Output: 
Dell
55000

12.3 Safe Event Callback Execution

function saveForm(data, onSuccess) {
    console.log("Saving form data...");

    onSuccess?.(data);
}

saveForm(
    { name: "Rahul" },
    (data) => {
        console.log("Saved:", data.name);
    }
);

saveForm({ name: "Amit" });
Expected Output: 
Saving form data...
Saved: Rahul
Saving form data...

12.4 Reading Application Settings

const settings = {
    display: {
        theme: "dark",
        fontSize: 16
    }

Expected Output: 
dark

12.5 Initializing Default Settings

const preferences = {
    theme: null,
    notifications: false,
    language: undefined
};

preferences.theme ??= "light";
preferences.notifications ??= true;
preferences.language ??= "en";

console.log(preferences);
Expected Output: 
{
    theme: "light",
    notifications: false,
    language: "en"
}

13. Important Differences and Interview Comparison

Feature Operator Behaviour
Optional chaining ?. Safely accesses a property or calls a function when the preceding value is nullish.
Nullish coalescing ?? Returns a fallback only for null or undefined.
Nullish assignment ??= Assigns a fallback only when the current value is null or undefined.
Logical OR || Returns the right operand when the left operand is falsy.

Important Operator Precedence Rule

JavaScript does not allow ?? to be directly mixed with && or || without parentheses. 

// Invalid syntax:
const result = value || defaultValue ?? "Guest";

// Valid syntax:
const result = (value || defaultValue) ?? "Guest";

// Also valid:
const result = value || (defaultValue ?? "Guest");
Interview Point: Parentheses must be used when mixing nullish coalescing with logical AND or logical OR operators.

14. Common Mistakes and Debugging

Mistake 1: Using optional chaining on an undeclared variable

console.log(user?.name);

If user has never been declared, this produces a ReferenceError. Optional chaining does not replace variable declaration or existence checks.

Mistake 2: Assuming optional chaining validates data types

const user = {
    address: 100
};

console.log(user?.address?.city);
Expected Output: 
undefined

JavaScript allows property access on many primitive values through boxing. Optional chaining is not a complete data validation mechanism.

Mistake 3: Using || when zero is meaningful

const quantity = 0;

console.log(quantity || 1);
console.log(quantity ?? 1);
Expected Output: 
1
0

Mistake 4: Assuming optional calls check function types

const callback = "done";

callback?.();
Runtime Error: A non-nullish string is not callable. Check with typeof callback === "function" when the value's type is uncertain.

Mistake 5: Mixing ?? and || without parentheses

This produces a syntax error: 

const result = value ?? fallback || "Default";

Use parentheses to make the intended evaluation explicit:

const result = (value ?? fallback) || "Default";

15. Placement Interview Questions and Answers

Q1. What is optional chaining in JavaScript?

Optional chaining uses ?. to safely access properties, elements or callable values when the preceding value may be null or undefined.

Q2. In which JavaScript version was optional chaining introduced?

It was introduced in ECMAScript 2020 (ES11).

Q3. What is nullish coalescing?

The ?? operator returns the right-hand value only when the left-hand value is null or undefined.

Q4. What is the difference between || and ???

Logical OR uses falsy-value checking, whereas nullish coalescing checks only null and undefined.

Q5. What is nullish assignment?

The ??= operator assigns a fallback value only when the existing value is null or undefined.

Q6. Can optional chaining be used with arrays?

Yes. For example, users?.[0] safely accesses the first element when users is null or undefined.

Q7. Can optional chaining be used with functions?

Yes. The syntax callback?.() calls the function if the value is not nullish. It does not verify that a non-nullish value is callable.

Q8. Can optional chaining be used on the left side of an assignment?

No. Expressions containing optional chaining cannot be assignment targets.

Q9. Does optional chaining catch all JavaScript errors?

No. It only short-circuits property access, element access or calls at a nullish optional-chain boundary. It does not replace try-catch or data validation.

Q10. Why is nullish coalescing useful in frontend development?

It provides safe default values while preserving valid values such as zero, false and empty strings.

Q11. Can ?? be mixed directly with ||?

No. Parentheses are required when mixing nullish coalescing with logical OR or logical AND.

Q12. What is the difference between null and undefined?

Undefined commonly represents an unassigned or missing value, whereas null represents an intentional absence of a value.
