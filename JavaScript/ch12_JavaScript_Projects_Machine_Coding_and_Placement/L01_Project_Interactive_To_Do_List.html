Lesson 01: Project – Interactive To-Do List

Build a practical task management application using HTML, CSS and JavaScript. Learn DOM manipulation, event handling, arrays, objects, CRUD operations and LocalStorage.

1. Learning Objectives

  • Design an interactive application using HTML and CSS.
  • Handle user input and button events using JavaScript.
  • Represent tasks using JavaScript objects.
  • Perform CRUD operations: Create, Read, Update and Delete.
  • Render elements dynamically using DOM methods.
  • Implement task completion and filtering.
  • Store tasks persistently using LocalStorage.
  • Handle invalid input and common application errors.

2. Project Requirements

The application should support the following operations:

Feature Expected Behaviour
Add Task Accept task text and add a new task.
Display Tasks Show all available tasks dynamically.
Complete Task Mark a task as completed using a checkbox.
Edit Task Modify the text of an existing task.
Delete Task Remove a task from the list.
Filter Tasks Display all, pending or completed tasks.
Persistent Storage Preserve tasks after refreshing the page.

3. Concepts Used in This Project

3.1 JavaScript Arrays

An array stores multiple task objects. Array methods such as push(), filter() and find() help manage task data.

3.2 JavaScript Objects

Each task is represented by an object containing a unique ID, task text and completion status. 

const task = {
    id: 1,
    text: "Learn JavaScript",
    completed: false
};

3.3 DOM Manipulation

document.createElement() creates HTML elements, while appendChild() inserts them into the document.

3.4 Event Handling

Event listeners respond to user actions such as clicking buttons, entering text and changing checkboxes.

3.5 LocalStorage

LocalStorage stores data as strings. JSON methods allow JavaScript objects and arrays to be converted into strings and restored later. 

// Store tasks
localStorage.setItem("tasks", JSON.stringify(tasks));

// Retrieve tasks
const savedTasks = JSON.parse(
    localStorage.getItem("tasks") || "[]"
);

4. Application Architecture

User Input
    |

The task array acts as the application's main data source. Whenever the data changes, the interface is rendered again and the updated array is saved.

<body>

<div class="container">

    <h1>My To-Do List</h1>

    <div class="input-row">
        <input type="text" id="taskInput"
               placeholder="Enter a new task"
               maxlength="200">

        <button id="addBtn">Add Task</button>
    </div>

    <div class="filters">
        <button class="filter active"
                data-filter="all">All</button>

        <button class="filter"
                data-filter="pending">Pending</button>

        <button class="filter"
                data-filter="completed">Completed</button>
    </div>

    <ul id="taskList"></ul>

    <p id="empty">No tasks available.</p>

    <p id="status"></p>

</div>

<script>
    const taskInput = document.getElementById("taskInput");
    const addBtn = document.getElementById("addBtn");
    const taskList = document.getElementById("taskList");
    const emptyMessage = document.getElementById("empty");
    const status = document.getElementById("status");
    const filterButtons =
        document.querySelectorAll(".filter");

    let tasks = [];
    let currentFilter = "all";

    // Load tasks from LocalStorage
    function loadTasks() {
        try {
            const storedTasks =
                localStorage.getItem("tasks");

            tasks = storedTasks
                ? JSON.parse(storedTasks)
                : [];

            if (!Array.isArray(tasks)) {
                tasks = [];
            }
        } catch (error) {
            console.error("Unable to load tasks:", error);
            tasks = [];
            status.textContent =
                "Saved data could not be loaded.";
        }
    }

    // Save tasks to LocalStorage
    function saveTasks() {
        try {
            localStorage.setItem(
                "tasks",
                JSON.stringify(tasks)
            );
        } catch (error) {
            console.error("Unable to save tasks:", error);
            status.textContent =
                "Unable to save tasks in browser storage.";
        }
    }

    // Add a new task
    function addTask() {
        const text = taskInput.value.trim();

        if (text === "") {
            alert("Please enter a task.");
            return;
        }

        const newTask = {
            id: Date.now(),
            text: text,
            completed: false
        };

        tasks.push(newTask);

        taskInput.value = "";

        saveTasks();
        renderTasks();
        taskInput.focus();
    }

    // Delete a task
    function deleteTask(id) {
        tasks = tasks.filter(task => task.id !== id);

        saveTasks();
        renderTasks();
    }

    // Toggle task completion
    function toggleTask(id) {
        const task = tasks.find(task => task.id === id);

        if (task) {
            task.completed = !task.completed;
        }

        saveTasks();
        renderTasks();
    }

    // Edit a task
    function editTask(id) {
        const task = tasks.find(task => task.id === id);

        if (!task) {
            return;
        }

        const updatedText = prompt(
            "Edit your task:",
            task.text
        );

        if (updatedText === null) {
            return;
        }

        if (updatedText.trim() === "") {
            alert("Task cannot be empty.");
            return;
        }

        task.text = updatedText.trim();

        saveTasks();
        renderTasks();
    }

    // Apply current filter
    function getFilteredTasks() {
        if (currentFilter === "pending") {
            return tasks.filter(task => !task.completed);
        }

        if (currentFilter === "completed") {
            return tasks.filter(task => task.completed);
        }

        return tasks;
    }

    // Render tasks dynamically
    function renderTasks() {
        taskList.replaceChildren();

        const filteredTasks = getFilteredTasks();

        filteredTasks.forEach(task => {
            const li = document.createElement("li");

            if (task.completed) {
                li.classList.add("completed");
            }

            const checkbox =
                document.createElement("input");

            checkbox.type = "checkbox";
            checkbox.checked = task.completed;
            checkbox.setAttribute(
                "aria-label",
                "Mark task as completed"
            );

            checkbox.addEventListener("change", () => {
                toggleTask(task.id);
            });

            const span = document.createElement("span");

            // textContent prevents HTML injection
            span.textContent = task.text;

            const editButton =
                document.createElement("button");

            editButton.textContent = "Edit";
            editButton.className = "edit";

            editButton.addEventListener("click", () => {
                editTask(task.id);
            });

            const deleteButton =
                document.createElement("button");

            deleteButton.textContent = "Delete";
            deleteButton.className = "delete";

            deleteButton.addEventListener("click", () => {
                deleteTask(task.id);
            });

            li.append(
                checkbox,
                span,
                editButton,
                deleteButton
            );

            taskList.appendChild(li);
        });

        emptyMessage.hidden = filteredTasks.length !== 0;

        const completedCount =
            tasks.filter(task => task.completed).length;

        const pendingCount = tasks.length - completedCount;

        status.textContent =
            `Total: ${tasks.length} | ` +
            `Pending: ${pendingCount} | ` +
            `Completed: ${completedCount}`;
    }

    // Filter button events
    filterButtons.forEach(button => {
        button.addEventListener("click", () => {
            currentFilter = button.dataset.filter;

            filterButtons.forEach(btn => {
                btn.classList.remove("active");
            });

            button.classList.add("active");

            renderTasks();
        });
    });

    // Add task events
    addBtn.addEventListener("click", addTask);

    taskInput.addEventListener("keydown", event => {
        if (event.key === "Enter") {
            addTask();
        }
    });

    // Application initialization
    loadTasks();
    renderTasks();

</script>

</body>
</html>

    7. Understanding Important Functions

    addTask()

    Reads the input, validates it, creates a task object, inserts it into the array and refreshes the interface.

    renderTasks()

    Reads the task array, creates list elements and displays the current application state.

    toggleTask()

    Finds a task by its unique ID and changes its completion status from false to true or true to false.

    editTask()

    Finds the selected task, accepts updated text and saves the modification.

    deleteTask()

    Uses filter() to create a new array excluding the task selected for deletion.

    saveTasks()

    Converts the current task array into JSON and stores it in LocalStorage.

    10. Common Mistakes and Debugging

    • Not using trim(): Inputs containing only spaces may be accepted as tasks.
    • Forgetting JSON.stringify(): LocalStorage stores strings, not JavaScript objects directly.
    • Forgetting JSON.parse(): Retrieved JSON data must be converted back into JavaScript values.
    • Incorrect task identification: Use a unique ID to update or delete the correct task.
    • Direct HTML insertion: Avoid inserting user input through innerHTML. Use textContent to prevent HTML injection.
    • Not re-rendering: Refresh the interface after changing application data.
    • Ignoring storage errors: LocalStorage operations can fail because of browser restrictions or storage limits.

    11. Placement Interview Questions and Answers

    Q1. What is DOM manipulation?

    DOM manipulation means accessing and modifying HTML elements, attributes, styles and content through JavaScript.

    Q2. What is the difference between append() and appendChild()?

    append() can insert multiple nodes and strings, whereas appendChild() appends one Node and returns the inserted node.

    Q3. Why are JavaScript objects used for tasks?

    Objects group related properties such as task ID, description and completion status into a single structured value.

    Q4. What is the difference between map() and filter()?

    map() transforms each array element and returns a new array. filter() returns a new array containing elements that satisfy a condition.

    Q5. What is LocalStorage?

    LocalStorage is browser storage that keeps string key-value pairs across page reloads and browser sessions, subject to browser storage policies.

    Q6. What is JSON.stringify()?

    It converts a JavaScript value into a JSON string.

    Q7. What is JSON.parse()?

    It parses a JSON string and converts it into a JavaScript value.

    Q8. Why should user input be displayed using textContent?

    textContent treats the input as text rather than HTML markup, helping prevent HTML injection and cross-site scripting risks.

    Q9. What is event handling?

    Event handling is the process of responding to user or browser events such as clicks, keyboard input and checkbox changes.

    Q10. What is the purpose of filter() in deleteTask()?

    It creates a new array containing every task except the one whose ID matches the selected task.

    Q11. What is the difference between == and ===?

    == performs equality comparison with type coercion where needed. === checks equality without type coercion.

    Q12. Why is a unique ID required for each task?

    It identifies the exact task to update, complete or delete, even when multiple tasks have identical text.

    Q13. What happens if JSON.parse() receives invalid JSON?

    It throws a SyntaxError. Use try/catch when parsing data that may be invalid.

    Q14. Does LocalStorage automatically store JavaScript objects?

    No. Data must be serialized, usually with JSON.stringify(), and parsed when retrieved.

    Q15. What is CRUD?

    CRUD stands for Create, Read, Update and Delete. These are the four fundamental operations for managing application data.
