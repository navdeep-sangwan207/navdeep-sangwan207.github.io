Project: Weather Application

Fetch API, Async/Await and Dynamic Data Rendering

Project Overview

Build a weather application that allows users to search for a city and retrieve its current weather information from a remote API.

Project objective: Practise HTTP requests, Fetch API, asynchronous programming, JSON processing, error handling and dynamic DOM updates.

Learning Objectives

  • Understand how client-server communication works.
  • Use Fetch API to send HTTP requests.
  • Work with Promises and async/await.
  • Convert API responses into JavaScript objects.
  • Handle network errors and invalid responses.
  • Render API data dynamically in the browser.
  • Understand API endpoints and query parameters.
  • Implement loading and error states.

Project Requirements

  1. Accept a city name from the user.
  2. Find the geographical coordinates of the city.
  3. Retrieve current weather information.
  4. Display temperature and weather conditions.
  5. Display humidity, wind speed and apparent temperature.
  6. Handle unknown city names.
  7. Display loading feedback while fetching data.
  8. Handle network and server errors.
  9. Support searches using the Enter key.

API Used in This Project

1. Geocoding API

Converts a city name into geographical coordinates. 

https://geocoding-api.open-meteo.com/v1/search?name=Delhi&count=1&language=en&format=json

2. Weather Forecast API

Retrieves current weather data using latitude and longitude. 

https://api.open-meteo.com/v1/forecast?latitude=28.61&longitude=77.20&current=temperature_2m,relative_humidity_2m,apparent_temperature,is_day,precipitation,weather_code,wind_speed_10m

These endpoints are provided by Open-Meteo. The project uses public API endpoints without an API key.

JavaScript Concepts Used

  • Fetch API: Communicates with remote servers.
  • Promises: Represents asynchronous operations.
  • async/await: Simplifies asynchronous code.
  • try...catch: Handles runtime and network errors.
  • JSON: Processes API response data.
  • DOM manipulation: Updates the interface.
  • Template literals: Build dynamic strings.
  • Destructuring: Extracts properties from objects.

Application Workflow

  1. User enters a city name.
  2. JavaScript validates the input.
  3. Geocoding API searches for the city.
  4. The API returns latitude and longitude.
  5. Weather API receives the coordinates.
  6. The weather response is converted into JSON.
  7. JavaScript extracts current weather values.
  8. The DOM is updated with weather information.
  9. Errors are displayed when a request fails.
