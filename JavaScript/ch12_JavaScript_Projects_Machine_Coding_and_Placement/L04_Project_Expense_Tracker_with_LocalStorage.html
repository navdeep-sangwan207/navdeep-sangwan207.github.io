Project: Expense Tracker

Transaction Management with JavaScript and LocalStorage

Project Overview

Build an expense tracking application that allows users to record income and expenses, calculate their current balance, filter transactions and retain data after refreshing the browser.

Project objective: Practise DOM manipulation, arrays, objects, array methods, event handling, data persistence and application state management.

Learning Objectives

  • Represent transactions using JavaScript objects.
  • Manage transaction records using arrays.
  • Calculate income, expenses and account balance.
  • Use localStorage to persist application data.
  • Implement add, delete and filter operations.
  • Render dynamic content using DOM methods.
  • Validate form inputs and handle user interactions.

Project Requirements

  1. Add income and expense transactions.
  2. Enter a description, amount, category and transaction type.
  3. Display total income, total expenses and current balance.
  4. Display all saved transactions.
  5. Delete individual transactions.
  6. Filter transactions by type.
  7. Store transaction data in localStorage.
  8. Restore saved transactions after a page reload.

JavaScript Concepts Used

  • Arrays: Store multiple transaction records.
  • Objects: Represent individual transactions.
  • Array methods: filter(), reduce(), forEach().
  • DOM: Create and update transaction elements.
  • Events: Handle form submission and deletion.
  • localStorage: Save and retrieve transaction data.
  • JSON: Convert data between strings and objects.
  • Functions: Separate application responsibilities.

Application Architecture

  1. User enters transaction details.
  2. JavaScript validates the input.
  3. A transaction object is created with a unique ID.
  4. The transaction is added to the transactions array.
  5. The updated array is saved in localStorage.
  6. The interface is re-rendered.
  7. Summary values are recalculated.
