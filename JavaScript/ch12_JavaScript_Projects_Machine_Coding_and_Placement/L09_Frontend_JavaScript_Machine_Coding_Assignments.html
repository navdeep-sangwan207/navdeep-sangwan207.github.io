2. What Is a Machine Coding Round?

A machine coding round is a practical programming assessment in which candidates are asked to build a working application or user interface within a specified time.

Unlike a theoretical interview, the candidate is expected to write executable code, demonstrate functionality and explain implementation decisions.

Typical Evaluation Areas

Area What Interviewers Evaluate
Functional correctness Whether the required features work correctly.
JavaScript fundamentals Functions, arrays, objects, events and asynchronous code.
DOM manipulation Correct creation, updating and removal of elements.
State management Whether application data remains consistent.
Code quality Readable, maintainable and reusable code.
Edge cases Handling empty inputs, invalid data and unexpected states.
Responsive design Usability across desktop and mobile screens.
Problem-solving Ability to understand requirements and select an appropriate solution.

3. How to Approach a Machine Coding Assignment

Step 1: Understand the Requirements

  • Identify all requested features.
  • Identify user inputs and expected outputs.
  • Identify required application states.
  • Clarify any ambiguous behavior before coding.

Step 2: Design the Interface

Divide the application into logical sections such as input forms, navigation, content areas, data lists and action buttons.

Step 3: Define the Data Structure

const tasks = [
    {
        id: 1,
        title: "Complete JavaScript practice",
        completed: false
    },
    {
        id: 2,
        title: "Revise DOM manipulation",
        completed: true
    }
];

Step 4: Implement Core Functionality

  • Write the essential JavaScript functions.
  • Connect controls using event listeners.
  • Update application state after user actions.
  • Render the interface from the updated state.

Step 5: Test Edge Cases

  • Empty input.
  • Duplicate records.
  • Missing data.
  • Invalid user input.
  • Repeated button clicks.
  • Empty result sets.
  • Browser refresh where persistence is required.

Step 6: Improve Code Quality

Use meaningful names, separate responsibilities into functions, avoid unnecessary global variables and keep the implementation easy to understand.

First make the core functionality correct. Then improve the interface, handle edge cases and refine the code.

Problem Statement

Beginner Arrays DOM CRUD

Create a task management application where users can add, complete and delete tasks.

Requirements

  • Prevent empty task submission.

const tasks = [];

const taskInput = document.getElementById("taskInput");
const taskList = document.getElementById("taskList");

function renderTasks() {
    taskList.innerHTML = "";

    tasks.forEach(task => {
        const li = document.createElement("li");
        li.className = "todo-item";

        if (task.completed) {
            li.classList.add("completed");
        }

        const title = document.createElement("span");
        title.textContent = task.title;

        const completeButton = document.createElement("button");
        completeButton.textContent = task.completed
            ? "Undo"
            : "Complete";

        completeButton.addEventListener("click", () => {
            task.completed = !task.completed;
            renderTasks();
        });

        const deleteButton = document.createElement("button");
        deleteButton.textContent = "Delete";

        deleteButton.addEventListener("click", () => {
            const index = tasks.findIndex(
                item => item.id === task.id
            );

            if (index !== -1) {
                tasks.splice(index, 1);
            }

            renderTasks();
        });

        li.append(title, completeButton, deleteButton);
        taskList.appendChild(li);
    });
}

function addTask() {
    const title = taskInput.value.trim();

    if (!title) {
        alert("Please enter a task.");
        return;
    }

    tasks.push({
        id: Date.now(),
        title,
        completed: false
    });

    taskInput.value = "";
    renderTasks();
}

document.getElementById("addTask")
    .addEventListener("click", addTask);

      9. Assignment 6: Debounced Search

      Problem Statement

      Intermediate setTimeout() clearTimeout() Performance

      Implement a search field that waits until the user stops typing for a specified duration before executing the search operation.

      Why Debouncing Is Required

      An input event can fire after every keystroke. Performing expensive filtering or an API request for every keystroke can cause unnecessary work.

      Complete Solution

      function debounce(callback, delay) {
    let timer;

    return function (...args) {
        clearTimeout(timer);

        timer = setTimeout(() => {
            callback.apply(this, args);
        }, delay);
    };
}

function performSearch(event) {
    console.log("Searching:", event.target.value);
}

const debouncedSearch = debounce(performSearch, 500);

document.getElementById("searchInput")
    .addEventListener("input", debouncedSearch);

      How It Works

      1. The user types into the input field.
      2. The existing timer is cleared.
      3. A new timer is created.
      4. If the user types again, the timer restarts.
      5. The callback executes after the delay without another input event.

      Concepts Tested

      • Closures.
      • Higher-order functions.
      • setTimeout().
      • clearTimeout().
      • Function context and rest parameters.

      let remainingSeconds = 60;
let timerId = null;

const display = document.getElementById("timer");

function updateTimer() {
    const minutes = Math.floor(remainingSeconds / 60);
    const seconds = remainingSeconds % 60;

    display.textContent =
        String(minutes).padStart(2, "0") + ":" +
        String(seconds).padStart(2, "0");

function startTimer() {
    if (timerId !== null || remainingSeconds === 0) {
        return;
    }

    timerId = setInterval(() => {
        remainingSeconds--;

        updateTimer();

        if (remainingSeconds === 0) {
            clearInterval(timerId);
            timerId = null;
            alert("Time is up!");
        }
    }, 1000);
}

function pauseTimer() {
    clearInterval(timerId);
    timerId = null;
}

function resetTimer() {
    pauseTimer();
    remainingSeconds = 60;
    updateTimer();
}

document.getElementById("start")
    .addEventListener("click", startTimer);

document.getElementById("pause")
    .addEventListener("click", pauseTimer);

document.getElementById("reset")
    .addEventListener("click", resetTimer);

      Problem Statement

      Build a shopping cart that allows users to add products, update quantities and remove items.

      Requirements

      • Add products to the cart.
      • Increase and decrease quantities.
      • Remove products.

      const cart = [];

function addToCart(product) {
    const existingItem = cart.find(
        item => item.id === product.id
    );

    if (existingItem) {
        existingItem.quantity++;
    } else {
        cart.push({
            ...product,
            quantity: 1
        });
    }

    renderCart();
}

function updateQuantity(id, change) {
    const item = cart.find(product => product.id === id);

    if (!item) {
        return;
    }

    item.quantity += change;

    if (item.quantity <= 0) {
        removeFromCart(id);
        return;
    }

    renderCart();
}

function removeFromCart(id) {
    const index = cart.findIndex(
        item => item.id === id
    );

    if (index !== -1) {
        cart.splice(index, 1);
    }

    renderCart();
}

function calculateTotal() {
    return cart.reduce(
        (total, item) =>
            total + item.price * item.quantity,
        0
    );
}

    if (formState.currentStep < formState.totalSteps) {
        formState.currentStep++;
        renderStep();
    }
}

function previousStep() {
    if (formState.currentStep > 1) {
        formState.currentStep--;
        renderStep();
    }
}

function updateFormState(field, value) {
    formState.values[field] = value;
}

      27. Common Machine Coding Mistakes

      1. Starting to code without understanding the complete requirements.
      2. Writing all application logic inside one large function.
      3. Modifying the original dataset unintentionally.
      4. Forgetting to validate user input.
      5. Ignoring empty states and boundary conditions.
      6. Registering duplicate event listeners.
      7. Failing to clear timers or observers when they are no longer needed.
      8. Rendering untrusted data using unsafe HTML strings.
      9. Ignoring asynchronous errors.
      10. Spending too much time on styling before functionality works.
      11. Failing to test the application after the final change.

      29. Lesson Summary

      • Machine coding rounds evaluate practical programming ability.
      • Start by understanding requirements and defining application state.
      • Use reusable functions to separate application responsibilities.
      • Practise DOM manipulation and event handling.
      • Use array methods to process application data.
