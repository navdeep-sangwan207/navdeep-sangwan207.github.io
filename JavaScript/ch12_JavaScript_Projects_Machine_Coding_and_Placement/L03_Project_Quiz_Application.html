Lesson 03: Project – Quiz Application

Build an interactive quiz application using JavaScript arrays, objects, DOM manipulation, event handling, timers, score calculation and result analysis.

1. Learning Objectives

  • Store quiz questions using arrays and objects.
  • Render questions and answer options dynamically.
  • Handle answer selection and navigation.
  • Calculate scores and display quiz results.
  • Implement a countdown timer.
  • Show correct answers and explanations.
  • Track unanswered and incorrect questions.
  • Build a reusable quiz application using modular functions.

2. Project Requirements

Feature Expected Behaviour
Question Display Display one question at a time.
Answer Selection Allow the user to select one option.
Question Navigation Move between questions without losing answers.
Score Calculation Calculate the final score using selected answers.
Timer Automatically submit when time expires.
Result Analysis Show correct, incorrect and unanswered counts.
Review Answers Display correct answers and explanations.
Restart Quiz Reset quiz state and start again.

3. JavaScript Concepts Used

3.1 Array of Objects

Questions are stored as objects inside an array. Each object contains the question, options, correct answer and explanation. 

const questions = [
    {
        question: "Which keyword declares a block-scoped variable?",
        options: ["var", "let", "function", "class"],
        answer: 1,
        explanation: "let declares a block-scoped variable."
    }
];

3.2 Array Methods

Methods such as forEach(), filter(), map() and reduce() help process question data and calculate results. 

const correctAnswers = answers.filter(
    (answer, index) => answer === questions[index].answer
);

console.log(correctAnswers.length);

3.3 DOM Manipulation

createElement(), textContent and appendChild() are used to create questions and options dynamically.

3.4 Timer Functions

setInterval() updates the countdown. clearInterval() stops the timer when the quiz finishes. 

let remainingTime = 60;

const timerId = setInterval(() => {
    remainingTime--;

    if (remainingTime <= 0) {
        clearInterval(timerId);
    }
}, 1000);

3.5 State Management

The application maintains the current question index, selected answers, remaining time and quiz status.

<script>
    // Question bank
    const questions = [
        {
            question: "Which keyword declares a block-scoped variable?",
            options: ["var", "let", "function", "class"],
            answer: 1,
            explanation: "let declares a block-scoped variable."
        },
        {
            question: "Which method converts a JSON string into an object?",
            options: [
                "JSON.stringify()",
                "JSON.parse()",
                "JSON.convert()",
                "Object.parse()"
            ],
            answer: 1,
            explanation: "JSON.parse() converts valid JSON text into a JavaScript value."
        },
        {
            question: "What does === check?",
            options: [
                "Value only",
                "Type only",
                "Value and type",
                "Object length"
            ],
            answer: 2,
            explanation: "Strict equality checks value and type without coercion."
        },
        {
            question: "Which method creates a new array by transforming elements?",
            options: ["filter()", "map()", "find()", "some()"],
            answer: 1,
            explanation: "map() transforms each element and returns a new array."
        },
        {
            question: "Which method selects an element by its ID?",
            options: [
                "querySelectorAll()",
                "getElementsByClassName()",
                "getElementById()",
                "createElement()"
            ],
            answer: 2,
            explanation: "getElementById() selects an element using its ID."
        },
        {
            question: "Which storage survives a normal browser restart?",
            options: [
                "LocalStorage",
                "SessionStorage",
                "Temporary variable",
                "Function scope"
            ],
            answer: 0,
            explanation: "LocalStorage persists across browser sessions unless cleared or removed."
        },
        {
            question: "Which keyword handles exceptions?",
            options: ["catch", "throw", "try", "All of these"],
            answer: 3,
            explanation: "try, catch and throw are used in JavaScript exception handling."
        },
        {
            question: "What does Promise.all() do?",
            options: [
                "Runs promises sequentially",
                "Waits for all promises to fulfill or rejects on the first rejection",
                "Cancels all promises",
                "Converts promises to callbacks"
            ],
            answer: 1,

        },
        {
            question: "Which event occurs when a user clicks an element?",
            options: ["change", "submit", "click", "load"],
            answer: 2,
            explanation: "The click event is triggered by a click action."
        },
        {
            question: "Which function schedules repeated execution?",
            options: [
                "setTimeout()",
                "setInterval()",
                "clearTimeout()",
                "requestAnimationFrame()"
            ],
            answer: 1,
            explanation: "setInterval() schedules a callback to run repeatedly at an approximate interval."

    ];

    const quizArea = document.getElementById("quizArea");
    const resultArea = document.getElementById("resultArea");
    const questionElement = document.getElementById("question");
    const optionsElement = document.getElementById("options");
    const questionCount = document.getElementById("questionCount");
    const timerElement = document.getElementById("timer");
    const progressBar = document.getElementById("progressBar");
    const feedback = document.getElementById("feedback");

    const previousBtn = document.getElementById("previousBtn");
    const nextBtn = document.getElementById("nextBtn");
    const submitBtn = document.getElementById("submitBtn");

    let currentIndex = 0;
    let answers = Array(questions.length).fill(null);
    let remainingTime = 120;
    let timerId = null;
    let quizFinished = false;

    // Display current question
    function renderQuestion() {
        if (quizFinished) return;

        const question = questions[currentIndex];

        questionCount.textContent =
            `Question ${currentIndex + 1} of ${questions.length}`;

        questionElement.textContent = question.question;

        optionsElement.replaceChildren();

        question.options.forEach((option, index) => {
            const button = document.createElement("button");

            button.type = "button";
            button.className = "option";
            button.textContent =
                `${String.fromCharCode(65 + index)}. ${option}`;

            if (answers[currentIndex] === index) {
                button.classList.add("selected");
            }

            button.addEventListener("click", () => {
                selectAnswer(index);
            });

            optionsElement.appendChild(button);
        });

        previousBtn.disabled = currentIndex === 0;

        nextBtn.hidden = currentIndex === questions.length - 1;

        progressBar.style.width =
            `${((currentIndex + 1) / questions.length) * 100}%`;

        feedback.textContent =
            answers[currentIndex] === null
                ? "Select one answer."
                : "Your answer has been saved.";
    }

    // Save selected answer
    function selectAnswer(index) {
        if (quizFinished) return;

        answers[currentIndex] = index;
        renderQuestion();
    }

    // Move to next question
    function nextQuestion() {
        if (currentIndex < questions.length - 1) {
            currentIndex++;
            renderQuestion();
        }
    }

    // Move to previous question
    function previousQuestion() {
        if (currentIndex > 0) {
            currentIndex--;
            renderQuestion();
        }
    }

    // Update countdown timer
    function startTimer() {
        timerElement.textContent =
            `Time: ${remainingTime}s`;

        timerId = setInterval(() => {
            remainingTime--;

            timerElement.textContent =
                `Time: ${remainingTime}s`;

            if (remainingTime <= 0) {
                finishQuiz();
            }
        }, 1000);
    }

    // Calculate and display final result
    function finishQuiz() {
        if (quizFinished) return;

        quizFinished = true;
        clearInterval(timerId);

        const correct = answers.filter(
            (answer, index) =>
                answer === questions[index].answer
        ).length;

        const attempted = answers.filter(
            answer => answer !== null
        ).length;

        const incorrect = attempted - correct;
        const unanswered = questions.length - attempted;
        const percentage = Math.round(
            (correct / questions.length) * 100
        );

        quizArea.hidden = true;
        resultArea.hidden = false;

        const resultHeading =
            document.createElement("h2");

        resultHeading.textContent = "Quiz Completed";

        const score = document.createElement("p");
        score.className = "score";
        score.textContent =
            `${correct} / ${questions.length}`;

        const percentageText = document.createElement("p");
        percentageText.textContent =
            `Percentage: ${percentage}%`;

        const summary = document.createElement("p");
        summary.textContent =
            `Attempted: ${attempted} | ` +
            `Correct: ${correct} | ` +
            `Incorrect: ${incorrect} | ` +
            `Unanswered: ${unanswered}`;

        const reviewHeading = document.createElement("h3");
        reviewHeading.textContent = "Answer Review";

        const review = document.createElement("div");
        review.className = "review";

        questions.forEach((question, index) => {
            const item = document.createElement("div");
            item.className = "review-item";

            const title = document.createElement("p");
            title.textContent =
                `${index + 1}. ${question.question}`;

            const selected = document.createElement("p");

            if (answers[index] === null) {
                selected.textContent = "Your answer: Not attempted";
                selected.className = "wrong-text";
            } else {
                selected.textContent =
                    `Your answer: ${question.options[answers[index]]}`;

                selected.className =
                    answers[index] === question.answer
                        ? "correct-text"
                        : "wrong-text";
            }

            const correctAnswer = document.createElement("p");
            correctAnswer.className = "correct-text";
            correctAnswer.textContent =
                `Correct answer: ${question.options[question.answer]}`;

            const explanation = document.createElement("p");
            explanation.textContent =
                `Explanation: ${question.explanation}`;

            item.append(
                title,
                selected,
                correctAnswer,
                explanation
            );

            review.appendChild(item);
        });

        const restartButton = document.createElement("button");
        restartButton.textContent = "Restart Quiz";
        restartButton.className = "primary";
        restartButton.addEventListener("click", restartQuiz);

        resultArea.replaceChildren(
            resultHeading,
            score,
            percentageText,
            summary,
            reviewHeading,
            review,
            restartButton
        );
    }

    // Restart the quiz
    function restartQuiz() {
        clearInterval(timerId);

        currentIndex = 0;
        answers = Array(questions.length).fill(null);
        remainingTime = 120;
        quizFinished = false;

        resultArea.replaceChildren();
        resultArea.hidden = true;
        quizArea.hidden = false;

        renderQuestion();
        startTimer();
    }

    previousBtn.addEventListener("click", previousQuestion);
    nextBtn.addEventListener("click", nextQuestion);
    submitBtn.addEventListener("click", finishQuiz);

    // Initialize application
    renderQuestion();
    startTimer();

</script>

7. Understanding Important Functions

renderQuestion()

Displays the current question, creates its answer buttons and updates the progress indicator.

selectAnswer()

Stores the selected option at the current question index. This allows answers to remain available when navigating.

startTimer()

Uses setInterval() to update the countdown and submits the quiz automatically when the timer reaches zero.

finishQuiz()

Stops the timer, calculates the score, counts unanswered questions and generates the answer review.

restartQuiz()

Resets the current question, answer array, timer and completion state before starting again.

10. Common Mistakes and Debugging

  • Incorrect answer indexing: Keep the answer array aligned with the question array.
  • Resetting answers during navigation: Store answers separately from the currently displayed question.
  • Multiple active timers: Clear the previous interval before starting a new timer.
  • Incorrect score calculation: Compare each selected answer with the correct answer at the same question index.
  • Timer continues after submission: Clear the interval when the quiz finishes.
  • Duplicate submission: Maintain a completion flag to prevent repeated scoring.
  • Unsafe dynamic HTML: Use textContent when displaying question and answer text.

11. Placement Interview Questions and Answers

Q1. What is an array of objects?

It is an array where each element is an object containing related properties. It is useful for storing structured records such as quiz questions.

Q2. How do you dynamically generate quiz options?

Use document.createElement() to create option elements, assign their text and append them to a container.

Q3. What is the difference between forEach() and map()?

forEach() executes a callback for each element and does not return a transformed array. map() returns a new array containing callback results.

Q4. How do you calculate a quiz score?

Compare the selected answer at each question index with the correct answer stored in the question object.

Q5. What is setInterval()?

setInterval() schedules a callback to execute repeatedly after approximately specified time intervals.

Q6. What is clearInterval()?

It stops a repeated callback scheduled using setInterval().

Q7. Why is clearInterval() necessary after quiz submission?

It prevents the timer from continuing to execute after the quiz has finished.

Q8. How can previous answers be preserved?

Maintain a separate answers array and store each selected option at the corresponding question index.

Q9. What is event delegation?

It uses event bubbling to handle events from child elements through a listener attached to a common parent.

Q10. What is the purpose of Array.fill()?

It fills an array with a specified value. It is useful for initializing answer slots to null.

Q11. What is the difference between null and undefined?

null represents an intentional absence of a value. undefined usually indicates that a value has not been assigned.

Q12. How do you calculate a percentage?

Divide the obtained score by the total possible score and multiply the result by 100.

Q13. Why should the quiz completion state be tracked?

It prevents multiple submissions and repeated result calculations.

Q14. What is the purpose of aria-live?

It helps assistive technologies announce updates to dynamic content, such as quiz feedback and timer messages.

Q15. How can a quiz application support random questions?

Shuffle a copy of the question array using a suitable randomization algorithm before initializing the quiz.
