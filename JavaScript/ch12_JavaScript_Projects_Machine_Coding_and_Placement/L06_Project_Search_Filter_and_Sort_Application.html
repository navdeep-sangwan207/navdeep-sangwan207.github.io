Project: Search, Filter and Sort

Product Listing Application Using JavaScript

Project Overview

Build a dynamic product listing application where users can search products by name, filter them by category and price, and sort the results according to price, name and rating.

Project objective: Practise array methods, string operations, DOM manipulation, event handling, sorting algorithms through built-in methods, and application state management.

Learning Objectives

  • Store product data using arrays of objects.
  • Implement case-insensitive text search.
  • Filter products using multiple conditions.
  • Sort products using Array.sort().
  • Use filter(), map(), and sort() effectively.
  • Handle input, change and click events.
  • Render product cards dynamically.
  • Combine multiple filters without modifying original data.

Project Requirements

  1. Display products from a JavaScript array.
  2. Search products by product name.
  3. Filter by product category.
  4. Filter by minimum and maximum price.
  5. Sort by price from low to high.
  6. Sort by price from high to low.
  7. Sort alphabetically by product name.
  8. Sort by customer rating.
  9. Display the number of matching products.
  10. Display a message when no products match.
  11. Provide a reset filters option.

JavaScript Concepts Used

  • Array of objects: Stores product records.
  • filter(): Selects matching products.
  • sort(): Orders product records.
  • map(): Transforms array values.
  • includes(): Checks whether text contains a search term.
  • toLowerCase(): Supports case-insensitive searching.
  • DOM manipulation: Displays product cards.
  • Event listeners: React to user input.
  • Spread operator: Copies arrays before sorting.

Application Workflow

  1. Define the product dataset.
  2. Read the current search and filter values.
  3. Filter products by search text.
  4. Apply category and price conditions.
  5. Sort the filtered result.
  6. Update the product cards.
  7. Display the number of matching results.
