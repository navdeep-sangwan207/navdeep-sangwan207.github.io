2. What Is Strict Mode?

Strict mode is a JavaScript execution mode that applies additional restrictions to the language.

It helps developers identify certain programming mistakes that might otherwise be silently ignored or handled unexpectedly.

Strict mode can be enabled by writing the following directive at the beginning of a script or function. 

"use strict";

Example Without Strict Mode

In a classic non-strict script, assigning a value to an undeclared variable creates a global property. 

result = 100;

console.log(result);
Expected Output in a Classic Non-Strict Script: 
100

Example With Strict Mode

"use strict";

result = 100;

console.log(result);
Expected Result: ReferenceError because result has not been declared. The console.log statement is not executed.

Strict mode helps prevent accidental creation of undeclared variables.

3. How to Enable Strict Mode

Method 1: Strict Mode for an Entire Script

"use strict";

let name = "Rahul";

console.log(name);
Expected Output: 
Rahul

Method 2: Strict Mode Inside a Function

function calculate() {
    "use strict";

    let result = 20 + 30;

    console.log(result);
}

calculate();
Expected Output: 
50

Here, strict mode applies to the function body.

Important Placement Point

The directive must appear at the beginning of the relevant script or function body, before ordinary statements. 

// Correct
"use strict";

let value = 10;


// Not a strict-mode directive
let message = "Hello";

"use strict";

console.log(message);
A "use strict" directive is recognized when it appears in the directive prologue. It should not be placed after ordinary statements.

4. Important Restrictions of Strict Mode

4.1 Undeclared Variables Are Not Allowed

"use strict";

count = 10;

console.log(count);
Error: ReferenceError. The variable count must be declared before assignment.

Correct code:

"use strict";

let count = 10;

console.log(count);
Expected Output: 
10

4.2 Duplicate Parameter Names Are Not Allowed

"use strict";

function add(a, a) {
    return a + a;
}
Error: SyntaxError because duplicate parameter names are not permitted in strict-mode function declarations.

Correct code:

"use strict";

function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
Expected Output: 
30

4.3 Deleting Variables Is Not Allowed

"use strict";

let value = 100;

delete value;
Error: SyntaxError. A declared variable cannot be deleted using the delete operator.

4.4 Writing to a Non-Writable Property

"use strict";

const user = {};

Object.defineProperty(user, "id", {
    value: 101,
    writable: false
});

user.id = 202;
Error: TypeError because the id property is not writable.

4.5 Writing to a Read-Only Object Property

"use strict";

const settings = {};

Object.defineProperty(settings, "mode", {
    value: "production",
    writable: false
});

settings.mode = "development";
Error: TypeError. Strict mode throws an error when attempting to assign to a non-writable property.

4.6 Using this in a Plain Function

"use strict";

function showThis() {
    console.log(this);
}

showThis();
Expected Output: 
undefined

In a strict-mode ordinary function call, this is undefined rather than being automatically substituted with the global object.

4.7 Octal Numeric Literals

"use strict";

let value = 010;
Error: SyntaxError. Legacy octal numeric literals are not permitted in strict mode.

Use explicit decimal or modern octal notation instead, such as 10 or 0o10.

5. Strict Mode vs Non-Strict Mode

Feature Non-Strict Script Strict Script
Undeclared assignment May create global property ReferenceError
Duplicate parameters Allowed in ordinary functions SyntaxError
Plain function this Global this value in classic browser scripts undefined
Writing to read-only property May fail silently TypeError
Deleting a variable Invalid operation SyntaxError
Legacy octal literals May be accepted SyntaxError
Modern JavaScript modules and class bodies are strict by default. You do not need to add "use strict" inside them to obtain strict-mode behavior.

6. Common JavaScript Errors

Understanding errors is important for technical interviews, coding rounds and debugging frontend applications.

6.1 SyntaxError

A SyntaxError occurs when JavaScript code violates the language grammar. 

// Missing closing parenthesis

console.log("Hello";
Error: SyntaxError.

6.2 ReferenceError

A ReferenceError occurs when an identifier cannot be resolved in the current scope, or when a lexical binding is accessed before initialization. 

console.log(userName);
Error: ReferenceError because userName has not been declared.

6.3 TypeError

A TypeError occurs when an operation is performed on a value that does not support that operation. 

let value = null;

console.log(value.name);
Error: TypeError because a property cannot be accessed on null.

6.4 RangeError

A RangeError occurs when a value is outside the permitted range for an operation. 

let numbers = new Array(-5);
Error: RangeError because an array length cannot be negative.

Common Error Comparison

Error Meaning Typical Cause
SyntaxError Invalid syntax Missing bracket or invalid declaration
ReferenceError Invalid identifier reference Using an undeclared variable
TypeError Invalid operation on a value Accessing a property on null
RangeError Value outside allowed range Negative array length

7. Debugging JavaScript in the Browser

Debugging means finding and correcting errors in a program.

Chrome Developer Tools provides several facilities for debugging JavaScript.

How to Open Developer Tools

  1. Open your HTML page in Google Chrome.
  2. Press F12 or Ctrl + Shift + I.
  3. Open the Console tab.
  4. Enter JavaScript statements to test them.
  5. Use the Sources tab to inspect and debug scripts.

7.1 console.log()

Displays values in the browser console. 

let price = 500;

console.log(price);
Console Output: 
500

7.2 console.error()

Displays an error message in the console. 

console.error("Invalid user input");

7.3 console.table()

Displays arrays and objects in a tabular format. 

const employees = [
    { id: 1, name: "Amit" },
    { id: 2, name: "Neha" }
];

console.table(employees);

7.4 console.assert()

Displays an assertion message when the supplied condition is false. 

let age = 15;

console.assert(age >= 18, "Age must be 18 or above");

7.5 debugger Statement

The debugger statement can pause execution when developer tools are open. 

let a = 10;

let b = 20;

debugger;

let result = a + b;

console.log(result);

When execution pauses, you can inspect variables, follow the call stack and execute statements step by step.

Debugging is more effective when you understand variable values, execution order, scope and error messages instead of relying only on console.log().

8. JavaScript Fundamentals: Integrated Coding Practice

Program 1: Variables and Data Types

Declare variables using let and const, then display their values and types. 

const name = "Amit";

let age = 24;

let salary = 25000;

let isEmployed = true;

console.log(name, typeof name);

console.log(age, typeof age);

console.log(salary, typeof salary);

console.log(isEmployed, typeof isEmployed);
Expected Output: 
Amit string
24 number
25000 number
true boolean

Program 2: Swap Two Variables

Swap two variables using a temporary variable. 

let a = 10;

let b = 20;

let temp = a;

a = b;

b = temp;

console.log("a =", a);

console.log("b =", b);
Expected Output: 
a = 20
b = 10

Program 3: Swap Without a Temporary Variable

let a = 10;

let b = 20;

[a, b] = [b, a];

console.log(a);

console.log(b);
Expected Output: 
20
10

This uses array destructuring assignment, which will be covered in greater detail in a later chapter.

Program 4: Check Even or Odd

let number = 17;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}
Expected Output: 
Odd

Program 5: Find the Largest of Three Numbers

let a = 25;

let b = 40;

let c = 15;

if (a >= b && a >= c) {
    console.log("Largest:", a);
} else if (b >= a && b >= c) {
    console.log("Largest:", b);
} else {
    console.log("Largest:", c);
}
Expected Output: 
Largest: 40

Program 6: Simple Calculator

let a = 20;

let b = 5;

let operator = "*";

let result;

switch (operator) {
    case "+":
        result = a + b;
        break;

    case "-":
        result = a - b;
        break;

    case "*":
        result = a * b;
        break;

    case "/":
        if (b === 0) {
            console.log("Cannot divide by zero");
        } else {
            result = a / b;
        }
        break;

    default:
        console.log("Invalid operator");
}

if (result !== undefined) {
    console.log("Result:", result);
}
Expected Output: 
Result: 100

Program 7: Validate User Age

let age = 22;

if (typeof age !== "number" ||
    !Number.isFinite(age) ||
    !Number.isInteger(age)) {

    console.log("Invalid age");

} else if (age < 0) {

    console.log("Age cannot be negative");

} else if (age >= 18) {

    console.log("Eligible");

} else {

    console.log("Not eligible");
}
Expected Output: 
Eligible

Program 8: Check Positive, Negative or Zero

let number = -12;

if (number > 0) {
    console.log("Positive");
} else if (number < 0) {
    console.log("Negative");
} else {
    console.log("Zero");
}
Expected Output: 
Negative

Program 9: Calculate Percentage

let subject1 = 80;

let subject2 = 75;

let subject3 = 90;

let total = subject1 + subject2 + subject3;

let percentage = (total / 300) * 100;

console.log("Total:", total);

console.log("Percentage:", percentage + "%");
Expected Output: 
Total: 245
Percentage: 81.66666666666667%

Program 10: Check Whether a Value Is Empty

function isEmptyValue(value) {
    return value === null ||
           value === undefined ||
           value === "";
}

console.log(isEmptyValue(null));

console.log(isEmptyValue(undefined));

console.log(isEmptyValue(""));

console.log(isEmptyValue(0));

console.log(isEmptyValue(false));
Expected Output: 
true
true
true
false
false

This function checks three explicitly defined empty cases. It does not treat zero or false as empty.

10. JavaScript Fundamentals: Interview Revision

Q1. What is JavaScript?

JavaScript is a programming language used to add dynamic behavior and application logic to web pages. It also runs on servers and other environments.

Q2. What is the difference between let, const and var?

var is function-scoped, while let and const are block-scoped. let allows reassignment, whereas const does not allow reassignment of its binding.

Q3. What are primitive data types?

string, number, bigint, boolean, undefined, symbol and null.

Q4. What is dynamic typing?

A variable can hold values of different types during program execution without an explicit type declaration.

Q5. What is the difference between primitive and reference values?

Primitive values are immutable values. Objects are mutable entities, and variables holding objects contain references to those objects.

Q6. What is strict mode?

Strict mode enables additional restrictions that help detect certain programming mistakes.

Q7. What is NaN?

NaN means Not-a-Number. It is a special numeric value used to represent an invalid numeric result.

Q8. What is the difference between == and ===?

== performs type coercion when comparing values. === compares values without that coercion.

Q9. What is undefined?

undefined commonly represents a missing or uninitialized value.

Q10. What is null?

null is an explicitly assigned primitive value representing intentional absence.
