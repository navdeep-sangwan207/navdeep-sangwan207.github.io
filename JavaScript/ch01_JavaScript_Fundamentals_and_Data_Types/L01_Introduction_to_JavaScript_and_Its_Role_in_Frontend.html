2. What is JavaScript?

JavaScript is a high-level, dynamically typed, multi-paradigm programming language. It is widely used to develop interactive websites, web applications and other software.

In frontend development, JavaScript allows a webpage to respond to user actions, change its content, validate forms, update information and communicate with web servers.

Definition: JavaScript is a programming language that adds behavior and interactivity to web pages and supports application development across browsers, servers and other runtime environments.

Example of JavaScript in a Webpage

Consider a button that displays a message when a user clicks it. HTML creates the button, CSS controls its appearance and JavaScript handles the click interaction. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>JavaScript Example</title>
</head>
<body>

    <h2>Welcome to JavaScript</h2>

    <button onclick="showMessage()">
        Click Me
    </button>

    <script>
        function showMessage() {
            alert("Hello! JavaScript is working.");
        }
    </script>

</body>
</html>
Expected Result:

1. A heading and button appear in the browser.

2. Clicking the button displays an alert message:

Hello! JavaScript is working.

3. Brief History of JavaScript

JavaScript was created by Brendan Eich in 1995 while working at Netscape. It was initially developed to bring scripting capabilities to web browsers.

Year Development
1995 JavaScript was created by Brendan Eich.
1996 JavaScript was submitted for standardization.
1997 ECMAScript 1 was standardized.
2009 ECMAScript 5 introduced several important language improvements.
2015 ECMAScript 2015 (ES6) introduced major modern JavaScript features.
Present JavaScript continues to evolve through yearly ECMAScript editions.

What is ECMAScript?

ECMAScript is the standardized specification that defines the core features and behavior of JavaScript.

JavaScript is an implementation of the ECMAScript specification along with additional host capabilities supplied by environments such as web browsers and Node.js.

Interview distinction: JavaScript is the programming language. ECMAScript is the standard that specifies its core language features.

4. Important Features of JavaScript

4.1 High-Level Language

JavaScript provides abstractions that allow developers to write application logic without manually managing ordinary memory allocation and processor instructions.

4.2 Dynamically Typed

Variables are not restricted to a single declared data type. The type of a value is determined at runtime. 

let value = 100;

console.log(value);

value = "JavaScript";

console.log(value);
Expected Output: 
100
JavaScript

4.3 Multi-Paradigm

JavaScript supports different programming styles, including:

  • Procedural programming
  • Object-oriented programming
  • Functional programming

4.4 Event-Driven Programming

JavaScript can execute functions in response to events such as mouse clicks, keyboard input, form submissions and network responses.

4.5 Asynchronous Programming

JavaScript supports asynchronous operations through callbacks, promises and async/await. These are especially useful when communicating with servers or performing delayed operations.

4.6 Cross-Platform Support

JavaScript runs in modern browsers and in other environments such as Node.js, allowing developers to create different types of applications.

4.7 Automatic Memory Management

JavaScript runtimes manage memory automatically and use garbage collection to reclaim memory that is no longer reachable by the program.

5. Difference Between HTML, CSS and JavaScript

These three technologies work together to create modern frontend applications, but each has a different responsibility.

Technology Purpose Example
HTML Defines webpage structure and content. Headings, paragraphs and buttons.
CSS Controls appearance and layout. Colors, fonts and responsive layouts.
JavaScript Implements behavior and interactivity. Click events and dynamic content.
Easy way to remember:
  • HTML = Structure
  • CSS = Presentation
  • JavaScript = Behavior

6. How JavaScript Runs in a Browser

A browser contains a JavaScript engine that executes JavaScript code. Different browsers use different JavaScript engines.

Browser JavaScript Engine
Google Chrome V8
Microsoft Edge V8
Mozilla Firefox SpiderMonkey
Safari JavaScriptCore

JavaScript Engine Responsibilities

  • Parse JavaScript source code.
  • Perform required compilation and execution steps.
  • Execute the program.
  • Manage runtime values and memory.
  • Apply optimization techniques where appropriate.

Basic Execution Flow

  1. The browser loads an HTML document.
  2. The browser processes the HTML and constructs the DOM.
  3. The browser encounters a JavaScript script.
  4. The JavaScript engine processes and executes the code.
  5. The script can interact with browser-provided APIs and the DOM.
  6. The browser displays the resulting page and responds to interactions.
Important: The JavaScript engine and the browser are not the same thing. The browser also provides host features such as the DOM, timers, networking APIs and event handling.

7. JavaScript Runtime Environments

JavaScript code needs an execution environment. A runtime provides the JavaScript engine and additional capabilities required to run applications.

Browser Runtime

Browser environments provide APIs such as:

  • DOM API for accessing and modifying webpage elements.
  • Fetch API for making network requests.
  • LocalStorage and SessionStorage for browser storage.
  • Timer APIs such as setTimeout and setInterval.
  • Browser event APIs for user interactions.

Node.js Runtime

Node.js allows JavaScript to execute outside the browser. It is commonly used for backend development, command-line applications, APIs and server-side programming.

Browser JavaScript Node.js JavaScript
Runs in a browser environment. Runs in the Node.js runtime.
Provides browser DOM APIs. Provides server-side APIs.
Used extensively for frontend behavior. Used extensively for backend development.
Uses browser security restrictions. Can access permitted system resources through Node.js APIs.

8. Practical Applications of JavaScript

8.1 Interactive Websites

JavaScript can open menus, display messages, update content and respond to user interactions.

8.2 Form Validation

It can check user input before sending information to a server. Server-side validation is still required for security.

8.3 API Integration

JavaScript can retrieve data from remote servers and display information such as weather, product listings and user profiles.

8.4 Dynamic User Interfaces

It can update page content without requiring a complete page reload for every interaction.

8.5 Web Applications

JavaScript is used to develop dashboards, task managers, shopping interfaces, interactive tools and many other applications.

9. Your First JavaScript Program

The following example displays a message in the browser developer console. 

console.log("Hello, World!");

console.log("Welcome to JavaScript");

console.log(10 + 20);
Expected Console Output: 
Hello, World!
Welcome to JavaScript
30

Understanding console.log()

console.log() is a commonly used debugging method that writes information to the developer console.

  • It can display strings.
  • It can display numbers and boolean values.
  • It can display variables and objects.
  • It helps developers inspect program execution.

Example: Displaying Variables

let studentName = "Rahul";
let age = 22;
let isLearning = true;

console.log(studentName);
console.log(age);
console.log(isLearning);
Expected Output: 
Rahul
22
true

10. Common Beginner Mistakes

Mistake 1: Confusing JavaScript with Java

JavaScript and Java are different programming languages. Their similar names do not mean they are the same language.

Mistake 2: Expecting console.log() to Display on the Webpage

console.log() writes to the developer console, not directly into the visible webpage.

Mistake 3: Assuming JavaScript Is Only for Browsers

JavaScript also runs in environments such as Node.js.

Mistake 4: Assuming All Browser APIs Are JavaScript Language Features

The DOM and Fetch API are provided by the browser environment, not by the core ECMAScript language itself.

Mistake 5: Ignoring Error Messages

Read the browser console carefully. Error messages often identify the problem and the line where it occurred.

11. Placement Interview Questions and Answers

Q1. What is JavaScript?

Answer: JavaScript is a high-level, dynamically typed programming language used to develop interactive web applications and other software.

Q2. Is JavaScript a compiled or interpreted language?

Answer: Modern JavaScript engines use a combination of interpretation, compilation and optimization. Therefore, describing JavaScript simply as an interpreted language is incomplete.

Q3. What is ECMAScript?

Answer: ECMAScript is the standardized specification that defines the core features of JavaScript.

Q4. What is the difference between Java and JavaScript?

Answer: Java is a class-based, statically typed programming language, while JavaScript is a dynamically typed language with prototype-based object behavior. They have different language designs and execution models.

Q5. What is a JavaScript engine?

Answer: A JavaScript engine is software that processes and executes JavaScript code. Examples include V8 and SpiderMonkey.

Q6. What is the difference between JavaScript and ECMAScript?

Answer: ECMAScript defines the language specification, whereas JavaScript is the language implementation and its associated ecosystem of runtime features.

Q7. Can JavaScript run outside a web browser?

Answer: Yes. Node.js and other JavaScript runtimes allow JavaScript to run outside web browsers.

Q8. What is the purpose of console.log()?

Answer: It displays information in the developer console and is commonly used for debugging.

Q9. Is JavaScript single-threaded?

Answer: JavaScript execution in a typical browser main thread is single-threaded. However, browser environments support asynchronous operations and additional execution contexts such as Web Workers.

Q10. What are the main uses of JavaScript in frontend development?

Answer: DOM manipulation, event handling, form validation, API communication, dynamic content rendering and interactive user interfaces.
