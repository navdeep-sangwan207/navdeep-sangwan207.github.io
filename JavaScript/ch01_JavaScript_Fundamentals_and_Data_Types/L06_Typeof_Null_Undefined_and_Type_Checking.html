Level: Beginner to Intermediate | Placement Preparation

1. Learning Objectives

After completing this lecture, you should be able to:

  • Use the typeof operator correctly.
  • Understand the difference between null and undefined.
  • Recognize the historical typeof null behavior.
  • Check arrays using Array.isArray().
  • Use instanceof for object type checks.
  • Understand constructor and prototype-based checks.
  • Write reusable type-checking functions.
  • Avoid common type-checking mistakes in coding rounds.

2. What Is Type Checking?

Type checking means identifying the type or category of a value before performing an operation on it.

It is important when handling user input, API responses, form data, objects and arrays.

Example

let age = 25;

console.log(typeof age);

let name = "Rahul";

console.log(typeof name);

let isActive = true;

console.log(typeof isActive);
Expected Output: 
number
string
boolean
Type checking helps prevent operations from being performed on unexpected values.

3. typeof Operator

The typeof operator returns a string describing the type of its operand.

Syntax

typeof value

typeof(value)

Both forms are valid. Parentheses are optional unless needed to control expression grouping.

Example

console.log(typeof "JavaScript");

console.log(typeof 100);

console.log(typeof 10.5);

console.log(typeof true);

console.log(typeof undefined);

console.log(typeof 100n);

4. The typeof null Problem

One of the most frequently asked JavaScript interview questions is why typeof null returns "object". 

let value = null;

console.log(typeof value);
Expected Output: 
object

This is a historical behavior retained for backward compatibility. It does not mean null is actually an object.

Interview point: null is a primitive value, even though typeof null returns "object".

How to Check null Correctly

let value = null;

console.log(value === null);
Expected Output: 
true

Use strict equality with null when you specifically need to identify the null value.

5. Difference Between null and undefined

Both null and undefined represent the absence of a meaningful value, but they are used differently.

Feature undefined null
Meaning Value not assigned or unavailable Intentional absence of value
typeof undefined object
Primitive Yes Yes
Strict comparison Different from null Different from undefined
Common use Uninitialized or missing value Explicitly empty value

Example 1: Undefined Variable

let result;

console.log(result);

console.log(typeof result);
Expected Output: 
undefined
undefined

Example 2: Explicit Null

let selectedItem = null;

console.log(selectedItem);

console.log(typeof selectedItem);
Expected Output: 
null
object

Example 3: Strict Equality

console.log(null === undefined);

console.log(null == undefined);

console.log(null === null);

console.log(undefined === undefined);
Expected Output: 
false
true
true
true

Loose equality considers null and undefined equal to each other. Strict equality does not.

Prefer === for predictable comparisons. Use == only when its coercion behavior is specifically intended.

6. Checking Arrays with Array.isArray()

Arrays are objects in JavaScript. Therefore, typeof alone cannot distinguish an array from an ordinary object.

Problem with typeof

let numbers = [10, 20, 30];

let student = {
    name: "Rahul"
};

console.log(typeof numbers);

console.log(typeof student);
Expected Output: 
object
object

Correct Method: Array.isArray()

let numbers = [10, 20, 30];

let student = {
    name: "Rahul"
};

console.log(Array.isArray(numbers));

console.log(Array.isArray(student));
Expected Output: 
true
false

Additional Examples

console.log(Array.isArray([]));

console.log(Array.isArray("JavaScript"));

console.log(Array.isArray(null));

console.log(Array.isArray({}));
Expected Output: 
true
false
false
false
For ordinary array detection, use Array.isArray() rather than typeof.

7. instanceof Operator

The instanceof operator checks whether a constructor's prototype appears in an object's prototype chain.

Syntax

object instanceof Constructor

Example 1: Array

let numbers = [10, 20, 30];

console.log(numbers instanceof Array);

console.log(numbers instanceof Object);
Expected Output: 
true
true

An array is an Array instance and also inherits through the Object prototype chain.

Example 2: Date

let today = new Date();

console.log(today instanceof Date);

console.log(today instanceof Object);
Expected Output: 
true
true

Example 3: Custom Constructor

function Employee(name) {
    this.name = name;
}

let emp = new Employee("Amit");

console.log(emp instanceof Employee);

console.log(emp instanceof Object);
Expected Output: 
true
true

Important Limitation

instanceof is not a universal type checker for every value. It can produce different results across separate JavaScript realms, such as objects created in different browser windows or frames.

Do not use instanceof Array as the general cross-realm array check. Prefer Array.isArray().

8. Checking Functions

Functions have a special typeof result: "function". 

function greet() {
    console.log("Hello");
}

let add = function(a, b) {
    return a + b;
};

console.log(typeof greet);

console.log(typeof add);
Expected Output: 
function
function

Checking Whether a Value Is Callable

function execute(callback) {
    if (typeof callback === "function") {
        callback();
    } else {
        console.log("Invalid callback");
    }
}

execute(function() {
    console.log("Task executed");
});

execute(100);
Expected Output: 
Task executed
Invalid callback

This pattern is useful when working with event handlers, callbacks and reusable functions.

9. Checking for NaN

NaN represents an invalid numeric result. It belongs to the Number type. 

let result = "Hello" * 5;

console.log(result);

console.log(typeof result);

console.log(Number.isNaN(result));
Expected Output: 
NaN
number
true

Number.isNaN() vs isNaN()

console.log(Number.isNaN("Hello"));

console.log(isNaN("Hello"));

console.log(Number.isNaN(NaN));

console.log(isNaN(NaN));
Expected Output: 
false
true
true
true

The global isNaN() function converts its argument to a number before checking it. Number.isNaN() checks whether the value is actually NaN without coercing it.

Prefer Number.isNaN() when you need a reliable check for the actual NaN value.

10. Checking Object Types

typeof can identify a general object, but it cannot distinguish all object categories. 

let student = {
    name: "Rahul"
};

let numbers = [10, 20];

let today = new Date();

console.log(typeof student);

console.log(typeof numbers);

console.log(typeof today);

console.log(Array.isArray(numbers));

console.log(student instanceof Object);

console.log(today instanceof Date);
Expected Output: 
object
object
object
true
true
true

Using Object.prototype.toString()

This method can help identify built-in object tags. 

console.log(Object.prototype.toString.call([]));

console.log(Object.prototype.toString.call({}));

console.log(Object.prototype.toString.call(new Date()));

console.log(Object.prototype.toString.call(null));
Expected Output: 
[object Array]
[object Object]
[object Date]
[object Null]

This is useful for certain built-in object checks, but it should not be treated as a universal, foolproof validation mechanism for arbitrary objects.

11. Practical Type-Checking Functions

Example 1: Check Whether a Value Is a Number

function isValidNumber(value) {
    return typeof value === "number"
        && Number.isFinite(value);
}

console.log(isValidNumber(100));

console.log(isValidNumber("100"));

console.log(isValidNumber(Infinity));

console.log(isValidNumber(NaN));
Expected Output: 
true
false
false
false

Number.isFinite() rejects NaN and positive or negative Infinity. It does not convert strings into numbers.

Example 2: Check Whether a Value Is an Array

function isArrayValue(value) {
    return Array.isArray(value);
}

console.log(isArrayValue([1, 2, 3]));

console.log(isArrayValue({}));

console.log(isArrayValue("Hello"));
Expected Output: 
true
false
false

Example 3: Check for a Non-Null Object

function isNonNullObject(value) {
    return value !== null && typeof value === "object";
}

console.log(isNonNullObject({}));

console.log(isNonNullObject([]));

console.log(isNonNullObject(null));

console.log(isNonNullObject("Hello"));

console.log(isNonNullObject(function() {}));
Expected Output: 
true
true
false
false
false

This function identifies non-null values whose typeof result is object. It intentionally excludes functions and includes arrays.

12. Common Type-Checking Mistakes

Mistake 1: Using typeof to Check an Array

let data = [10, 20];

console.log(typeof data === "array");
Output: 
false

Correct approach: 

console.log(Array.isArray(data));

Mistake 2: Treating null as an Object

let value = null;

if (typeof value === "object") {
    console.log("Object detected");
}
Output: 
Object detected

This condition also matches null because of the historical typeof behavior.

Correct approach:

if (value !== null && typeof value === "object") {
    console.log("Non-null object detected");
}

Mistake 3: Using Loose Equality Without Understanding It

console.log(0 == false);

console.log("" == false);

console.log(null == undefined);
Expected Output: 
true
true
true

Loose equality performs type coercion. Use strict equality when you want to compare values without automatic coercion.

Mistake 4: Assuming typeof Identifies Every Object

console.log(typeof []);

console.log(typeof {});

console.log(typeof new Date());
Expected Output: 
object
object
object

Use the appropriate specialized check when you need to distinguish arrays, dates or other object types.

13. Placement Interview Questions and Answers

Q1. What does typeof return?

Answer: It returns a string describing the type of the operand.

Q2. What is the output of typeof null?

Answer: "object". This is a historical JavaScript behavior. null itself is a primitive value.

Q3. How do you check whether a variable is an array?

Answer: Use Array.isArray(value).

Q4. What is the difference between typeof and instanceof?

Answer: typeof identifies broad primitive categories and functions. instanceof checks whether a constructor's prototype exists in an object's prototype chain.

Q5. Why is typeof [] equal to object?

Answer: Arrays are specialized objects in JavaScript.

Q6. How do you check null?

Answer: Use value === null.

Q7. What is the difference between isNaN() and Number.isNaN()?

Answer: isNaN() converts its argument to a number before checking. Number.isNaN() does not perform that conversion.

Q8. What does instanceof check?

Answer: It checks whether a constructor's prototype is present in the object's prototype chain.

Q9. Is null equal to undefined?

Answer: They are equal using loose equality (null == undefined), but not using strict equality (null === undefined).

Q10. How do you check whether a value is a function?

Answer: Use typeof value === "function".

Q11. Does typeof distinguish integer and decimal numbers?

Answer: No. Both return "number". JavaScript's ordinary Number type represents both.

Q12. How can you check whether a number is finite?

Answer: Use Number.isFinite(value).

Q13. What does Object.prototype.toString.call(value) do?

Answer: It returns a string containing an object tag that can help identify built-in object categories.

Q14. Can instanceof work for primitive values?

Answer: Primitive values generally do not pass ordinary instanceof checks against their wrapper constructors. Use typeof for primitive type checks.

Q15. How would you check whether a value is a non-null object?

Answer: Check that value is not null and typeof value is "object". Add a separate check if arrays must be excluded.

15. Placement-Oriented Coding Exercises

Exercise 1: Identify Data Types

Create variables containing different primitive values and display their types using typeof.

Exercise 2: Null and Undefined

Create one undefined variable and one null variable. Compare their typeof results and equality results.

Exercise 3: Array Validation

Exercise 4: Number Validation

Exercise 5: Function Validation

Exercise 6: Object Validation

Write a function that identifies non-null objects and separately identifies arrays.

Exercise 7: Type Inspector

Create a function that accepts a value and displays whether it is a string, number, boolean, array, function, null or ordinary object.

16. Lecture Summary

  • typeof returns a string describing a value's type.
  • typeof null returns "object" for historical reasons.
  • null and undefined are different primitive values.
  • Use strict equality to check null and undefined separately.
  • Use Array.isArray() to identify arrays.
  • instanceof checks the prototype chain.
  • Functions return "function" from typeof.
  • Number.isNaN() avoids automatic type coercion.
  • Number.isFinite() checks finite numeric values.
  • Type validation is important in practical application development.
