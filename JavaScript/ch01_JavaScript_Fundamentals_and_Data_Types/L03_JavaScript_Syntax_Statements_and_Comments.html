2. Understanding JavaScript Syntax

Syntax refers to the rules that define how JavaScript code must be written so that the JavaScript engine can parse it.

A JavaScript program consists of statements, expressions, declarations, operators, identifiers, literals and other language constructs.

Example

let studentName = "Rahul";

let marks = 85;

console.log(studentName);

console.log(marks);
Expected Output: 
Rahul
85

In this example:

  • let is a keyword.
  • studentName and marks are identifiers.
  • "Rahul" and 85 are literals.
  • = is an assignment operator.
  • console.log() is a method call.

3. JavaScript Statements

A statement is an instruction that JavaScript can execute. Statements form the basic building blocks of a program.

3.1 Variable Declaration Statement

let age = 22;

This statement declares a variable and initializes it.

3.2 Expression Statement

10 + 20;

console.log("Hello");

The first statement evaluates an arithmetic expression. The second statement calls a method.

3.3 Conditional Statement

let marks = 75;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}
Expected Output: 
Pass

3.4 Loop Statement

for (let i = 1; i <= 5; i++) {
    console.log(i);
}
Expected Output: 
1
2
3
4
5

3.5 Function Declaration

function greet() {
    console.log("Welcome to JavaScript");
}

greet();
Expected Output: 
Welcome to JavaScript
Remember: A statement performs an action. An expression produces a value. Some expressions can also be used as statements.

4. Expressions in JavaScript

An expression is a piece of code that evaluates to a value. Expressions can contain literals, variables, operators and function calls.

4.1 Arithmetic Expression

let result = 10 + 20;

The expression 10 + 20 evaluates to 30.

4.2 Comparison Expression

let isEligible = 25 >= 18;

console.log(isEligible);
Expected Output: 
true

4.3 String Expression

let fullName = "Amit" + " Sharma";

console.log(fullName);
Expected Output: 
Amit Sharma

4.4 Function Call Expression

function multiply(a, b) {
    return a * b;
}

let answer = multiply(5, 4);

console.log(answer);
Expected Output: 
20

5. Keywords, Identifiers and Literals

5.1 Keywords

Keywords are reserved words that have predefined meanings in JavaScript syntax. They cannot generally be used as ordinary variable or function names.

Keyword Purpose
letDeclares a block-scoped variable.
constDeclares a block-scoped binding that cannot be reassigned.
varDeclares a function-scoped or globally scoped variable.
ifStarts a conditional statement.
elseProvides an alternative conditional branch.
forCreates a loop.
whileCreates a condition-controlled loop.
functionDeclares a function.
returnReturns a value from a function.
classDeclares a class.
newCreates an object using a constructor.
tryBegins an exception-handling block.

5.2 Identifiers

Identifiers are names given to variables, functions, classes and other program elements.

Identifier Naming Rules

  • An identifier can contain letters, digits, underscores and dollar signs.
  • It cannot begin with a digit.
  • It cannot contain spaces.
  • It cannot be a reserved keyword.
  • Identifiers are case-sensitive.
  • Unicode characters are permitted, although common English naming conventions are preferred in professional projects.

Valid and Invalid Identifiers

Identifier Valid? Reason
studentName Yes Valid camelCase identifier.
_count Yes Underscore is allowed.
$price Yes Dollar sign is allowed.
marks2 Yes Digits can appear after the first character.
2marks No Cannot begin with a digit.
student name No Spaces are not allowed.
let No Reserved keyword.

5.3 Literals

A literal is a value written directly in source code. 

let name = "Rahul";

let age = 22;

let isActive = true;

let result = null;

let numbers = [10, 20, 30];

let student = {
    name: "Rahul",
    age: 22
};

Examples include string literals, numeric literals, boolean literals, null, array literals and object literals.

6. Case Sensitivity in JavaScript

JavaScript is case-sensitive. Names that differ only in capitalization are treated as different identifiers. 

let student = "Amit";

let Student = "Rahul";

let STUDENT = "Neha";

console.log(student);
console.log(Student);
console.log(STUDENT);
Expected Output: 
Amit
Rahul
Neha
Common mistake: If a variable is declared as studentName, referring to it as studentname will not access the same identifier.

7. Semicolons in JavaScript

A semicolon can explicitly terminate a JavaScript statement. JavaScript also has a feature called Automatic Semicolon Insertion (ASI).

Statements with Semicolons

let a = 10;
let b = 20;

console.log(a + b);

Statements Without Semicolons

let a = 10
let b = 20

console.log(a + b)

Both examples work because JavaScript can insert semicolons automatically where the language rules permit.

Why Explicit Semicolons Are Useful

  • They make statement boundaries clear.
  • They reduce ambiguity in certain line-break situations.
  • They support consistent coding style across teams.

Automatic Semicolon Insertion Pitfall

function getNumber() {
    return
    100;
}

console.log(getNumber());
Expected Output: 
undefined

A semicolon is automatically inserted after return in this example. The function therefore returns undefined.

Correct version:

function getNumber() {
    return 100;
}

console.log(getNumber());
Expected Output: 
100
Placement concept: Automatic Semicolon Insertion is not simply "a semicolon is added at every new line." It follows specific language rules and can change program behavior.

8. Comments in JavaScript

Comments are explanatory text in source code. They are ignored during normal JavaScript execution and help developers understand the program.

8.1 Single-Line Comments

A single-line comment begins with two forward slashes. 

// Declare a variable
let age = 22;

// Display the age
console.log(age);

8.2 Multi-Line Comments

Multi-line comments begin with /* and end with */. 

/*
    Student information program
    This program displays basic details.
*/

let name = "Rahul";
let age = 22;

console.log(name);
console.log(age);
Expected Output: 
Rahul
22

8.3 Comments for Explanations

// Calculate the total marks
let total = 80 + 75 + 90;

// Calculate the average
let average = total / 3;

console.log("Total:", total);
console.log("Average:", average);

Good Commenting Practices

  • Explain why complex logic exists, not merely what obvious code does.
  • Keep comments accurate when code changes.
  • Avoid unnecessary comments.
  • Use meaningful variable and function names.
  • Remove outdated or misleading comments.

10. Indentation and Code Formatting

Indentation and consistent formatting make code easier to read, review, debug and maintain.

Poorly Formatted Code

function calculate(a,b){
let total=a+b;
if(total>100){
console.log("High");
}else{
console.log("Low");
}
}
calculate(60,50);

Improved Formatting

function calculate(a, b) {
    let total = a + b;

    if (total > 100) {
        console.log("High");
    } else {
        console.log("Low");
    }
}

calculate(60, 50);
Expected Output: 
High

VS Code supports automatic formatting through extensions and built-in editor features. Common formatters include Prettier.

11. Common Syntax Errors and Debugging

Error 1: Missing Closing Brace

if (true) {
    console.log("Hello");

The closing brace is missing, resulting in an incomplete block and a syntax error.

Error 2: Incorrect String Quotes

let message = "Hello';

The opening and closing quotation marks do not match. Use matching quotes.

Error 3: Incorrect Variable Name

let firstName = "Amit";

console.log(firstname);

The declared variable is firstName, but the program refers to firstname. JavaScript treats these as different identifiers.

Error 4: Using an Assignment Instead of Comparison

let age = 20;

if (age = 18) {
    console.log("Condition executed");
}

The assignment operator = assigns a value. For equality comparison, use ===.

Debugging approach: Read the complete error message, locate the reported line, inspect nearby syntax and test the corrected program.

12. Complete Practical Program

Objective

Create a student result program using declarations, expressions, comments, conditional statements and console output.

Complete JavaScript Code

// Student result calculation program

const PASS_MARKS = 40;

// Student details
let studentName = "Rahul";

let subject1 = 75;
let subject2 = 80;
let subject3 = 65;

    console.log("Result: PASS");

13. Placement Interview Questions and Answers

Q1. What is JavaScript syntax?

Answer: JavaScript syntax is the set of rules that determines how valid JavaScript code must be structured.

Q2. What is the difference between a statement and an expression?

Answer: A statement is an instruction executed by the program. An expression evaluates to a value. An expression can also form part of a statement.

Q3. What is an identifier?

Answer: An identifier is a name used for variables, functions, classes and other program elements.

Q4. Is JavaScript case-sensitive?

Answer: Yes. For example, studentName and StudentName are different identifiers.

Q5. Are semicolons mandatory in JavaScript?

Answer: JavaScript supports Automatic Semicolon Insertion, so semicolons can sometimes be omitted. Explicit semicolons are commonly used for clarity and consistency.

Q6. What is Automatic Semicolon Insertion?

Answer: ASI is a language mechanism that inserts semicolons at certain positions according to JavaScript parsing rules.

Q7. What are comments?

Answer: Comments are explanatory text ignored during normal JavaScript execution. They can be single-line or multi-line.

Q8. What is a keyword?

Answer: A keyword is a reserved language word with a predefined role in JavaScript syntax.

Q9. Can an identifier start with a number?

Answer: No. An identifier cannot begin with a numeric digit.

Q10. What is camelCase?

Answer: It is a naming convention in which the first word starts with a lowercase letter and subsequent words begin with uppercase letters, such as studentName.

Q11. What happens if return is followed by a line break?

Answer: Automatic Semicolon Insertion may terminate the return statement, causing the function to return undefined instead of the value on the next line.

Q12. Why is code formatting important?

Answer: Consistent formatting improves readability, debugging, collaboration and maintainability.
