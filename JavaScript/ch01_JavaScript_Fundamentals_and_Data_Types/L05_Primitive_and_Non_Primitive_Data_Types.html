2. What Are Data Types?

A data type describes the kind of value represented by a JavaScript value. It determines which operations are meaningful and how the value behaves.

JavaScript is dynamically typed. A variable does not have to be declared with a fixed data type. Its value determines its type at runtime.

Example

let value = 100;

console.log(value);

value = "JavaScript";

console.log(value);

value = true;

console.log(value);
Expected Output: 
100
JavaScript
true

The same variable can refer to a number, a string and a boolean at different points during execution.

Important: JavaScript is dynamically typed, but individual values still have types.

4. Primitive Data Types

Primitive values are immutable values. Operations do not modify the existing primitive value; they produce or assign another value.

4.1 String

A string represents textual data. Strings can be written using single quotes, double quotes or backticks. 

let firstName = "Rahul";

let city = 'Panipat';

let message = `Welcome ${firstName}`;

console.log(firstName);
console.log(city);
console.log(message);
Expected Output: 
Rahul
Panipat
Welcome Rahul

Template Literals

Backticks allow string interpolation using ${...} and support multi-line strings. 

let name = "Amit";

let age = 24;

let introduction = `My name is ${name}
and my age is ${age}.`;

console.log(introduction);
Expected Output: 
My name is Amit
and my age is 24.

String Immutability

let text = "Hello";

text[0] = "Y";

console.log(text);
Expected Output: 
Hello

Individual characters of a string cannot be changed through indexed assignment.

4.2 Number

JavaScript uses the Number type for ordinary integers and floating-point values. It follows the IEEE 754 double-precision floating-point format. 

let age = 25;

let price = 99.99;

let temperature = -5;

console.log(age);
console.log(price);
console.log(temperature);
Expected Output: 
25
99.99
-5

Special Number Values

console.log(10 / 0);

console.log(-10 / 0);

console.log("Hello" * 5);

console.log(NaN === NaN);
Expected Output: 
Infinity
-Infinity
NaN
false

Important special values include:

  • Infinity
  • -Infinity
  • NaN — Not-a-Number
NaN is a special Number value. It is not equal to itself. Use Number.isNaN() to check whether a value is NaN.

4.3 Boolean

Boolean represents a logical value: true or false. 

let isLoggedIn = true;

let hasPermission = false;

console.log(isLoggedIn);
console.log(hasPermission);

console.log(10 > 5);
console.log(10 < 5);
Expected Output: 
true
false
true
false

Booleans are commonly used in conditions, comparisons, form validation and authentication logic.

4.4 Undefined

undefined indicates that a variable has been declared but has not yet received an assigned value. 

let result;

console.log(result);

function display() {
    let message;
    console.log(message);
}

display();
Expected Output: 
undefined
undefined

4.5 Null

null represents an intentional absence of an object value or an explicitly empty value. 

let selectedUser = null;

console.log(selectedUser);
Expected Output: 
null

A program may use null when a value is deliberately unavailable, such as when no user has been selected.

4.6 BigInt

BigInt represents integers larger than the safe integer range supported by Number. 

let largeNumber = 123456789012345678901234567890n;

console.log(largeNumber);

console.log(typeof largeNumber);
Expected Output: 
123456789012345678901234567890n
bigint

BigInt values can be created using an integer followed by n or by using BigInt().

BigInt and Number cannot be mixed directly in ordinary arithmetic operations. Convert values deliberately when combining them.

4.7 Symbol

Symbol creates a unique primitive value. Symbols are often used as unique object property keys. 

let id1 = Symbol("id");

let id2 = Symbol("id");

console.log(id1 === id2);

console.log(typeof id1);
Expected Output: 
false
symbol

Even when two symbols have the same description, they are different values.

5. Non-Primitive Data Types

Objects are used to represent collections of properties and more complex data structures. Arrays and functions are specialized object types.

5.1 Object

An object stores data as key-value properties. 

let student = {
    name: "Rahul",
    age: 22,
    course: "JavaScript"
};

console.log(student.name);

console.log(student.age);

console.log(student.course);
Expected Output: 
Rahul
22
JavaScript

Accessing Object Properties

let employee = {
    name: "Amit",
    salary: 30000
};

console.log(employee.name);

console.log(employee["salary"]);
Expected Output: 
Amit
30000

Modifying an Object

let employee = {
    name: "Amit",
    salary: 30000
};

employee.salary = 35000;

employee.department = "Development";

console.log(employee);

Objects are mutable: properties can be added, updated and deleted.

5.2 Array

An array stores an ordered collection of elements. JavaScript arrays can contain values of different types. 

let numbers = [10, 20, 30, 40];

console.log(numbers);

console.log(numbers[0]);

console.log(numbers[2]);

console.log(numbers.length);
Expected Output: 
[10, 20, 30, 40]
10
30
4

Updating an Array

let fruits = ["Apple", "Banana"];

fruits.push("Mango");

fruits[0] = "Orange";

console.log(fruits);
Expected Output: 
["Orange", "Banana", "Mango"]

Mixed Data Types in an Array

let data = [
    "Rahul",
    22,
    true,
    null
];

console.log(data);

5.3 Function

A function is a reusable block of code. Functions are callable objects in JavaScript. 

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

console.log(typeof add);
Expected Output: 
30
function

5.4 Date Object

Date is a built-in object used to work with dates and times. 

let today = new Date();

console.log(today);

console.log(typeof today);

The displayed date and time depend on the execution environment and current system clock.

6. Primitive Values vs Objects

One of the most important distinctions in JavaScript is how primitive values and objects behave when assigned to another variable.

6.1 Primitive Assignment

let a = 10;

let b = a;

b = 20;

console.log(a);

console.log(b);
Expected Output: 
10
20

The primitive value is copied. Reassigning b does not change the value held by a.

6.2 Object Assignment

let person1 = {
    name: "Rahul"
};

let person2 = person1;

person2.name = "Amit";

console.log(person1.name);

console.log(person2.name);
Expected Output: 
Amit
Amit

Both variables refer to the same object. Changing the object through person2 is visible through person1.

Important technical distinction: JavaScript passes values. When an object is assigned, the reference value is copied, so both variables can refer to the same object. JavaScript does not require a separate pass-by-reference parameter mechanism.

6.3 Reassigning an Object Variable

let first = {
    value: 10
};

let second = first;

second = {
    value: 20
};

console.log(first.value);

console.log(second.value);
Expected Output: 
10
20

Reassigning second makes it refer to a different object. It does not replace the object referenced by first.

7. Comparing Primitive and Non-Primitive Values

Primitive Comparison

let a = 100;

let b = 100;

console.log(a === b);
Expected Output: 
true

Object Comparison

let obj1 = {
    name: "Amit"
};

let obj2 = {
    name: "Amit"
};

console.log(obj1 === obj2);
Expected Output: 
false

The two objects have the same property values, but they are different object instances. Strict equality compares their identity, not their property contents.

Same Object Reference

let obj1 = {
    name: "Amit"
};

let obj2 = obj1;

console.log(obj1 === obj2);
Expected Output: 
true

8. Shallow Copy and Object Spread

The spread syntax can create a shallow copy of an array or an ordinary object.

8.1 Shallow Copy of an Object

let original = {
    name: "Rahul",
    age: 22
};

let copy = { ...original };

copy.name = "Amit";

console.log(original.name);

console.log(copy.name);
Expected Output: 
Rahul
Amit

8.2 Shallow Copy with Nested Objects

let original = {
    name: "Rahul",
    address: {
        city: "Panipat"
    }
};

let copy = { ...original };

copy.name = "Amit";

copy.address.city = "Delhi";

console.log(original.name);

console.log(original.address.city);
Expected Output: 
Rahul
Delhi

The top-level object was copied, but the nested address object is still shared by both objects.

Spread syntax performs a shallow copy, not a deep copy. Nested objects and arrays may still share references.

9. Dynamic Typing

JavaScript variables can be reassigned values of different types. 

let data = 100;

console.log(typeof data);

data = "Hello";

console.log(typeof data);

data = true;

console.log(typeof data);
Expected Output: 
number
string
boolean

This behavior is called dynamic typing. The type is associated with the value rather than permanently fixed by the variable declaration.

Why Dynamic Typing Matters

  • It makes quick prototyping convenient.
  • It allows flexible data handling.
  • It requires careful validation of input values.
  • Unexpected type changes can cause runtime bugs.

10. Complete Practical Program

Objective

Create a student record using primitive and non-primitive values. Display student details and update an array.

Complete JavaScript Code

// Student record program

const student = {
    name: "Rahul",
    age: 22,
    isEnrolled: true,

    subjects: [
        "JavaScript",
        "HTML",
        "CSS"
    ]
};

// Display student details
console.log("Name:", student.name);

console.log("Age:", student.age);

console.log("Enrolled:", student.isEnrolled);

// Display subjects
console.log("Subjects:");

student.subjects.forEach(function(subject) {
    console.log(subject);
});

// Update student information
student.age = 23;

student.subjects.push("React");

// Display updated information
console.log("Updated Age:", student.age);

console.log("Updated Subjects:", student.subjects);

Expected Output

Name: Rahul
Age: 22
Enrolled: true
Subjects:
JavaScript
HTML
CSS
Updated Age: 23
Updated Subjects: ["JavaScript", "HTML", "CSS", "React"]

Concepts Used

  • String, number and boolean values.

11. Placement Interview Questions and Answers

Q1. How many primitive data types are there in JavaScript?

Answer: Seven: string, number, boolean, undefined, null, bigint and symbol.

Q2. Is JavaScript statically typed or dynamically typed?

Answer: JavaScript is dynamically typed. A variable can refer to values of different types during program execution.

Q3. What is the difference between primitive and non-primitive values?

Answer: Primitive values are immutable values such as strings and numbers. Non-primitive values are objects, including arrays and functions, which can contain properties and mutable state.

Q4. Is an array a primitive data type?

Answer: No. An array is an object and is a specialized object used for ordered collections.

Q5. Is a function an object in JavaScript?

Answer: Yes. Functions are callable objects and can have properties.

Q6. What is the difference between undefined and null?

Answer: undefined commonly represents an uninitialized variable or missing value. null is generally assigned intentionally to represent an absent value.

Q7. Why is typeof null equal to object?

Answer: It is a long-standing historical behavior in JavaScript. null is a primitive value despite the typeof result.

Q8. What is BigInt?

Answer: BigInt is a primitive type used for integers larger than the safe integer range of Number.

Q9. What is Symbol?

Answer: Symbol creates unique primitive values, often used as object property keys.

Q10. What happens when one object is assigned to another variable?

Answer: The reference value is copied. Both variables can refer to the same object.

Q11. Are strings mutable in JavaScript?

Answer: No. Strings are immutable. String operations produce new string values.

Q12. Why does {} === {} return false?

Answer: Each object literal creates a separate object instance. Strict equality compares object identity.

Q13. What is a shallow copy?

Answer: A shallow copy creates a new top-level object while nested objects remain shared references.

Q14. What is NaN?

Answer: NaN means Not-a-Number. It is a special value of the Number type that represents an invalid numeric result.

Q15. What is the difference between Number and BigInt?

Answer: Number uses IEEE 754 double-precision floating-point representation. BigInt represents integers of arbitrary precision within implementation resource limits.

13. Placement-Oriented Coding Exercises

Exercise 1: Data Type Identification

Declare variables containing a string, number, boolean, undefined, null, BigInt, Symbol, array and object. Display each value and its type.

Exercise 2: Primitive Copying

Create two variables containing the same number. Change the second variable and verify that the first variable remains unchanged.

Exercise 3: Object References

Create an employee object and assign it to another variable. Update the salary using the second variable. Check the salary through the first variable.

Exercise 4: Array Operations

Create an array of five numbers. Add another number, update one element and display the final array.

Exercise 5: Object and Array Comparison

Create two separate objects with identical properties. Compare them using strict equality. Then assign one object to another variable and compare again.

Exercise 6: Shallow Copy

Create an object with a nested address object. Make a shallow copy using spread syntax. Update a top-level property and a nested property. Observe the difference.

Exercise 7: Student Management Record

Create an object containing student name, roll number, course, marks array and enrollment status. Calculate the total marks and average.
