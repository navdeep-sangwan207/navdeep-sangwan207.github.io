2. Software Requirements

JavaScript development does not require an expensive computer or a complex development environment. You can begin with a code editor and a modern web browser.

Software Purpose Recommended Option
Code Editor Writing and managing source code. Visual Studio Code
Web Browser Running and testing browser JavaScript. Google Chrome
Developer Tools Inspecting output, errors and execution. Chrome DevTools
File Manager Managing HTML, CSS and JS files. Windows File Explorer
Important: For the browser-based exercises in this course, you do not need to install Node.js immediately. A browser and a code editor are sufficient. Node.js will be useful when you begin server-side JavaScript and tooling.

3. Setting Up Visual Studio Code

Visual Studio Code (VS Code) is a source-code editor that provides features such as syntax highlighting, code completion, file navigation and debugging support.

Installation Steps

  1. Open the official Visual Studio Code website.
  2. Download the Windows installer.
  3. Run the installer.
  4. Follow the installation instructions.
  5. Launch Visual Studio Code.
  6. Open a folder to create your JavaScript workspace.

Official website: Visual Studio Code

Useful VS Code Features

  • Syntax highlighting for JavaScript and HTML.
  • Automatic indentation and bracket matching.
  • IntelliSense and code completion.
  • Integrated terminal.
  • File explorer and search.
  • Extensions and debugging support.

Recommended Workspace Structure

Create a folder named JavaScript_Practice and use the following directory structure: 

JavaScript_Practice/
│
├── index.html
├── style.css
└── script.js

This simple structure keeps the HTML document, stylesheet and JavaScript source code separate.

4. Creating Your First JavaScript Files

Step 1: Create index.html

Open VS Code, create a file named index.html and enter the following code: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>JavaScript Practice</title>
</head>
<body>

    <h1>JavaScript Development Setup</h1>

    <p>Open the browser console to see the output.</p>

    <script src="script.js"></script>

</body>
</html>

Step 2: Create script.js

Create another file named script.js in the same folder.

Step 3: Execute the Program

  2. Open the folder in File Explorer.
  3. Double-click index.html.
  4. The webpage opens in your browser.
  5. Open Chrome Developer Tools.
  6. Select the Console tab.
  7. Observe the JavaScript output.
Expected Console Output:

Welcome to NS Learning Hub.
Sum = 30

5. Understanding the Browser Console

The browser console is a developer tool used to execute JavaScript expressions, inspect values, display messages and investigate errors.

How to Open Chrome Developer Tools

Method Action
Keyboard shortcut Press F12.
Alternative shortcut Press Ctrl + Shift + I.
Direct console shortcut Press Ctrl + Shift + J in Chrome on Windows.
Mouse Right-click webpage → Inspect → Console.

Common Console Methods

Method Purpose
console.log() Displays general information.
console.info() Displays informational messages.
console.warn() Displays warning messages.
console.error() Displays error messages.
console.table() Displays tabular data.
console.clear() Clears the console display.
console.dir() Displays an object's properties in an interactive format.

Example: Console Methods

console.log("Normal message");

console.info("Information message");

console.warn("This is a warning");

console.error("This is an error");

let student = {
    name: "Rahul",
    age: 22,
    course: "JavaScript"
};

console.table(student);

Run this code in the browser console and observe how different console methods display information.

7. Connecting JavaScript with HTML

JavaScript can be added to an HTML document in different ways. This lecture uses an external JavaScript file because it is easier to maintain and reuse.

External JavaScript

<script src="script.js"></script>

The src attribute specifies the path to the external JavaScript file.

Script Placement

A regular script placed near the end of the body can execute after the HTML elements above it have been parsed. 

<body>

    <h1>My Webpage</h1>

    <script src="script.js"></script>

</body>

Using defer

An external classic script can use the defer attribute. The browser downloads the script while parsing HTML and executes it after HTML parsing is complete. 

<head>
    <script src="script.js" defer></script>
</head>
Placement interview concept: A deferred classic script executes after document parsing and before the DOMContentLoaded event. Deferred scripts preserve their document order.

8. Identifying Basic JavaScript Errors

The browser console helps developers identify syntax errors, runtime errors and problems with external script loading.

Example 1: Syntax Error

console.log("Hello World"

The closing parenthesis is missing. The browser reports a syntax error.

Example 2: Reference Error

console.log(student);

If student has not been declared in the accessible scope, JavaScript reports a ReferenceError.

Example 3: Incorrect File Path

<script src="scripts.js"></script>

If the actual file is named script.js, the browser cannot find scripts.js. Check the browser's Network panel and console for loading errors.

Basic Debugging Procedure

  1. Open the browser developer tools.
  2. Select the Console tab.
  3. Identify the error message.
  4. Check the file name and line number.
  5. Inspect the relevant source code.
  6. Correct the error and reload the webpage.

11. Placement Interview Questions and Answers

Q1. What is a browser console?

Answer: It is a developer tool used to execute JavaScript, inspect messages and diagnose errors.

Q2. What is VS Code?

Answer: Visual Studio Code is a source-code editor that supports programming languages, extensions, debugging and integrated terminal operations.

Q3. What is the purpose of the script tag?

Answer: The HTML script element is used to embed JavaScript code or reference an external script file.

Q4. What is the difference between inline and external JavaScript?

Answer: Inline JavaScript is written directly within an HTML event attribute, while external JavaScript is stored in a separate file and loaded using the script element's src attribute.

Q5. What does the defer attribute do?

Answer: It downloads an external classic script without blocking HTML parsing and executes it after the document has been parsed.

Q6. What is the difference between console.log() and alert()?

Answer: console.log() displays information in the developer console, while alert() displays a browser dialog to the user.

Q7. What is a syntax error?

Answer: A syntax error occurs when JavaScript code violates the language's grammatical rules and cannot be parsed successfully.

Q8. What is a runtime error?

Answer: A runtime error occurs during program execution, for example, attempting to access a property of null.

Q9. Can JavaScript execute without an HTML file?

Answer: Yes. JavaScript can execute directly in a browser console or through runtimes such as Node.js.

Q10. Why should JavaScript be placed in an external file?

Answer: External files improve code organization, maintainability, reusability and separation of concerns.
