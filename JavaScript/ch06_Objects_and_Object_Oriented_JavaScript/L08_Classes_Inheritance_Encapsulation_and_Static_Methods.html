2. What Are Classes in JavaScript?

ES6 introduced the class syntax to make object-oriented programming more convenient and readable. A class provides a structured way to define objects, constructors and methods.

JavaScript classes use the language's existing prototype-based inheritance system. They are not a separate inheritance mechanism from prototypes.

Basic Syntax

class ClassName {
    constructor(parameters) {
        // Initialize instance properties
    }

    methodName() {
        // Method implementation
    }
}

Example

class Employee {
    constructor(name, department) {
        this.name = name;
        this.department = department;
    }

    getDetails() {
        return `${this.name} works in ${this.department}`;
    }
}

const employee1 = new Employee("Rahul", "Testing");
const employee2 = new Employee("Priya", "Development");

console.log(employee1.getDetails());
console.log(employee2.getDetails());
Expected Output: 
Rahul works in Testing
Priya works in Development

3. Class Constructor

The constructor() method is a special method used to initialize a newly created class instance.

  • A class can have only one constructor method.
  • The constructor runs automatically when an instance is created with new.
  • It initializes instance properties.
  • If no constructor is written, JavaScript provides a default constructor.

Example

class Student {
    constructor(name, age, course) {
        this.name = name;
        this.age = age;
        this.course = course;
    }
}

const student1 = new Student("Aman", 22, "JavaScript");

console.log(student1.name);
console.log(student1.age);
console.log(student1.course);
Expected Output: 
Aman
22
JavaScript

Default Constructor

class Product {
    getCategory() {
        return "Electronics";
    }
}

const product = new Product();

console.log(product.getCategory());
Expected Output: 
Electronics

4. Instance Methods

Instance methods are methods defined inside a class that are available to its instances through the class prototype.

Example

class Calculator {
    add(a, b) {
        return a + b;
    }

    subtract(a, b) {
        return a - b;
    }

    multiply(a, b) {
        return a * b;
    }
}

const calculator = new Calculator();

console.log(calculator.add(10, 5));
console.log(calculator.subtract(10, 5));
console.log(calculator.multiply(10, 5));
Expected Output: 
15
5
50

Methods defined in class bodies are generally shared through the class's prototype rather than recreated for every instance.

Checking Method Sharing

class User {
    greet() {
        return "Hello";
    }
}

const user1 = new User();
const user2 = new User();

console.log(user1.greet === user2.greet);
Expected Output: 
true

5. Class Expressions

A class can also be assigned to a variable using a class expression.

Named Class Expression

const Employee = class EmployeeDetails {
    constructor(name) {
        this.name = name;
    }

    getName() {
        return this.name;
    }
};

const employee = new Employee("Rahul");

console.log(employee.getName());
Expected Output: 
Rahul

Anonymous Class Expression

const Student = class {
    constructor(name) {
        this.name = name;
    }
};

const student = new Student("Priya");

console.log(student.name);
Expected Output: 
Priya

6. Getters and Setters

Getters and setters allow controlled access to object properties.

  • get defines a getter that reads a computed or controlled value.
  • set defines a setter that handles property assignment.

Example

class User {
    constructor(name) {
        this._name = name;
    }

    get name() {
        return this._name;
    }

    set name(newName) {
        if (newName.trim() === "") {
            console.log("Name cannot be empty");
            return;
        }

        this._name = newName;
    }
}

const user = new User("Rahul");

console.log(user.name);

user.name = "Aman";

console.log(user.name);

user.name = "";
Expected Output: 
Rahul
Aman
Name cannot be empty
The underscore in _name is only a naming convention. It does not make the property private. Use private fields such as #name when actual language-enforced privacy is required.

7. Inheritance Using extends

Inheritance allows one class to reuse and extend the properties and methods of another class.

The extends keyword creates a subclass relationship.

Syntax

class Parent {
    // Parent members
}

class Child extends Parent {
    // Child members
}

Example

class Person {
    constructor(name) {
        this.name = name;
    }

    greet() {
        return `Hello, ${this.name}`;
    }
}

class Student extends Person {
    study() {
        return `${this.name} is studying`;
    }
}

const student = new Student("Aman");

console.log(student.greet());
console.log(student.study());
Expected Output: 
Hello, Aman
Aman is studying

The Student class inherits the constructor behavior and greet() method from Person.

8. Understanding super()

The super() function call invokes the constructor of the parent class.

When a derived class defines its own constructor, it must call super() before accessing this.

Example

class Person {
    constructor(name) {
        this.name = name;
    }
}

class Employee extends Person {
    constructor(name, department) {
        super(name);

        this.department = department;
    }
}

const employee = new Employee("Rahul", "Testing");

console.log(employee.name);
console.log(employee.department);
Expected Output: 
Rahul
Testing
Calling this before super() inside a derived constructor results in a ReferenceError.

9. Using super.method()

The super keyword can also access methods defined on the parent class prototype.

Example

class Animal {
    speak() {
        return "Animal makes a sound";
    }
}

class Dog extends Animal {
    speak() {
        return super.speak() + " - Dog barks";
    }
}

const dog = new Dog();

console.log(dog.speak());
Expected Output: 
Animal makes a sound - Dog barks

super.speak() calls the parent class method while preserving the current method's receiver.

10. Method Overriding

Method overriding occurs when a child class defines a method with the same name as a method inherited from its parent class.

Example

class Employee {
    getRole() {
        return "General Employee";
    }
}

class Developer extends Employee {
    getRole() {
        return "Software Developer";
    }
}

const employee = new Employee();
const developer = new Developer();

console.log(employee.getRole());
console.log(developer.getRole());
Expected Output: 
General Employee
Software Developer

The child class's implementation is selected when the method is called on a child instance.

11. Multilevel Inheritance

Multilevel inheritance occurs when a class inherits from another derived class.

Example

class Person {
    constructor(name) {
        this.name = name;
    }

    introduce() {
        return `I am ${this.name}`;
    }
}

class Employee extends Person {
    work() {
        return `${this.name} is working`;
    }
}

class Manager extends Employee {
    manage() {
        return `${this.name} manages a team`;
    }
}

const manager = new Manager("Priya");

console.log(manager.introduce());
console.log(manager.work());
console.log(manager.manage());
Expected Output: 
I am Priya
Priya is working
Priya manages a team

The Manager class inherits functionality through the chain: 

Manager
   |
   v
Employee
   |
   v
Person
   |
   v
Object.prototype

12. Encapsulation in JavaScript

Encapsulation means keeping data and the methods that operate on that data together while controlling how internal state is accessed or modified.

Modern JavaScript supports private class fields using the # prefix.

Example: Private Fields

class BankAccount {
    #balance;

    constructor(initialBalance) {
        this.#balance = initialBalance;
    }

    deposit(amount) {
        if (amount <= 0) {
            return "Invalid deposit";
        }

        this.#balance += amount;
        return "Deposit successful";
    }

    getBalance() {
        return this.#balance;
    }
}

const account = new BankAccount(1000);

console.log(account.getBalance());

console.log(account.deposit(500));

console.log(account.getBalance());

// console.log(account.#balance); // SyntaxError
Expected Output: 
1000
Deposit successful
1500

The #balance field cannot be accessed directly from outside the class body.

12.1 Private Methods

Methods can also be private by using the # prefix. 

class User {
    #password;

    constructor(password) {
        this.#password = password;
    }

    #validatePassword() {
        return this.#password.length >= 8;
    }

    checkPassword() {
        return this.#validatePassword();
    }
}

const user = new User("JavaScript123");

console.log(user.checkPassword());
Expected Output: 
true
Private fields provide language-enforced access restrictions. They are not merely hidden by naming convention.

13. Static Methods

Static methods belong to the class itself rather than individual instances.

They are defined using the static keyword and called using the class name.

Example

class MathUtility {
    static add(a, b) {
        return a + b;
    }

    static multiply(a, b) {
        return a * b;
    }
}

console.log(MathUtility.add(10, 20));
console.log(MathUtility.multiply(5, 4));
Expected Output: 
30
20

Static methods are not directly available on instances through the class prototype. 

const utility = new MathUtility();

// utility.add(10, 20); // TypeError

console.log(
    typeof MathUtility.add
);

console.log(
    typeof utility.add
);
Expected Output: 
function
undefined

14. Static Properties

Static properties store data on the class itself rather than on individual instances.

Example

class Employee {
    static company = "ABC Technologies";

    constructor(name) {
        this.name = name;
    }
}

const employee = new Employee("Rahul");

console.log(Employee.company);
console.log(employee.name);

console.log(
    Object.hasOwn(employee, "company")
);
Expected Output: 
ABC Technologies
Rahul
false

The static property belongs to the class constructor, not to each employee instance.

15. Getters, Setters and Encapsulation Together

Getters and setters can provide controlled access to private fields.

Example

class Temperature {
    #celsius;

    constructor(celsius) {
        this.celsius = celsius;
    }

    get celsius() {
        return this.#celsius;
    }

    set celsius(value) {
        if (typeof value !== "number" || !Number.isFinite(value)) {
            throw new TypeError("Temperature must be a finite number");
        }

        this.#celsius = value;
    }

    get fahrenheit() {
        return (this.#celsius * 9 / 5) + 32;
    }
}

const temperature = new Temperature(25);

console.log(temperature.celsius);
console.log(temperature.fahrenheit);

temperature.celsius = 30;

console.log(temperature.fahrenheit);
Expected Output: 
25
77
86

16. Static Methods and Inheritance

Static methods are also inherited by subclasses through the constructor inheritance chain.

Example

class Animal {
    static category() {
        return "Living organism";
    }
}

class Dog extends Animal {
}

console.log(Animal.category());
console.log(Dog.category());

const dog = new Dog();

// dog.category(); // TypeError
Expected Output: 
Living organism
Living organism

The static method is available through the subclass constructor, not as an instance method.

18. Class vs Constructor Function

JavaScript classes provide a cleaner syntax for constructor-based object creation, but they still use prototypes internally.

Constructor Function

function Person(name) {
    this.name = name;
}

Person.prototype.greet = function() {
    return `Hello, ${this.name}`;
};

const person1 = new Person("Aman");

console.log(person1.greet());

Class Syntax

class Person {
    constructor(name) {
        this.name = name;
    }

    greet() {
        return `Hello, ${this.name}`;
    }
}

const person2 = new Person("Aman");

console.log(person2.greet());
Expected Output from Each Example: 
Hello, Aman
Class Constructor Function
Uses class syntax. Uses function syntax.
Must be called with new. Can be called as a regular function, though this may be unsafe.
Class methods are non-enumerable. Methods assigned directly to the prototype are enumerable by default.
Class declarations have a temporal dead zone. Function declarations can be hoisted.
Supports private fields and static members. These features require additional patterns or modern class syntax.
Uses prototype-based inheritance. Can use prototype-based inheritance.

19. Practical Application: Bank Account System

This example combines constructors, private fields, instance methods, getters and static methods. 

class BankAccount {
    static bankName = "National Bank";

    #balance;

    constructor(accountHolder, initialBalance) {
        this.accountHolder = accountHolder;

        if (initialBalance < 0) {
            throw new RangeError("Initial balance cannot be negative");
        }

        this.#balance = initialBalance;
    }

    deposit(amount) {
        if (!Number.isFinite(amount) || amount <= 0) {
            return "Invalid deposit amount";
        }

        this.#balance += amount;

        return "Deposit successful";
    }

    withdraw(amount) {
        if (!Number.isFinite(amount) || amount <= 0) {
            return "Invalid withdrawal amount";
        }

        if (amount > this.#balance) {
            return "Insufficient balance";
        }

        this.#balance -= amount;

        return "Withdrawal successful";
    }

    get balance() {
        return this.#balance;
    }

    getAccountDetails() {
        return `${this.accountHolder}: ${this.#balance}`;
    }

    static getBankName() {
        return this.bankName;
    }
}

const account = new BankAccount("Rahul", 10000);

console.log(BankAccount.getBankName());
console.log(account.getAccountDetails());

console.log(account.deposit(2000));
console.log(account.withdraw(3000));

console.log(account.balance);
Expected Output: 
National Bank
Rahul: 10000
Deposit successful
Withdrawal successful
9000

The balance is private, transactions are validated, and the bank name is shared through a static property.

20. Common Mistakes and Debugging

Mistake 1: Forgetting new

A class constructor cannot be invoked as a regular function. Always instantiate a class using new.

Mistake 2: Forgetting super() in a Derived Constructor

If a derived class defines a constructor, it must call super() before accessing this.

Mistake 3: Accessing Private Fields Outside the Class

A private field such as #balance cannot be accessed directly from outside its declaring class body.

Mistake 4: Calling Static Methods on Instances

Static methods belong to the class constructor, not individual instances. Call them using the class name.

Mistake 5: Using Getter or Setter Like a Regular Method

class User {
    get name() {
        return "Rahul";
    }
}

const user = new User();

console.log(user.name);

Access a getter as a property, not as user.name().

Mistake 6: Defining Multiple Constructors

A class can contain only one constructor method. Use default parameters or conditional logic to handle different initialization requirements.

Mistake 7: Confusing Static and Instance Members

Instance methods are accessed through instances. Static methods are accessed through the class itself.

21. Placement Interview Questions and Answers

Q1. What is a class in JavaScript?

Answer: A class is syntax for defining constructors and methods for objects using JavaScript's prototype-based object model.

Q2. What is a constructor in a class?

Answer: It is a special method used to initialize a newly created instance.

Q3. What is inheritance?

Answer: Inheritance allows a subclass to reuse and extend the functionality of a parent class.

Q4. What is the purpose of extends?

Answer: It declares a subclass that inherits from another constructor or class.

Q5. What is super()?

Answer: It calls the parent constructor from a derived class constructor.

Q6. What is super.method()?

Answer: It invokes a method from the parent class's prototype.

Q7. What is method overriding?

Answer: It occurs when a subclass defines its own implementation of an inherited method.

Q8. What is encapsulation?

Answer: Encapsulation groups data and related methods while controlling access to internal state.

Q9. How do you create a private field in JavaScript?

Answer: Use the # prefix when declaring a class field.

Q10. What is a static method?

Answer: It is a method associated with the class itself rather than an instance.

Q11. Can static methods be inherited?

Answer: Yes. A subclass can access inherited static methods through its constructor inheritance chain.

Q12. What is the difference between a getter and a setter?

Answer: A getter handles property reads, while a setter handles property assignments.

Q13. Are JavaScript classes based on prototypes?

Answer: Yes. Class instance methods are stored on the class prototype, and class inheritance uses prototype chains.

Q14. Can a class have more than one constructor?

Answer: No. A class can define only one constructor method.

Q15. What happens if super() is not called in a derived constructor?

Answer: The derived constructor cannot access this before calling super(). If it completes without initializing the derived instance through super(), a ReferenceError occurs.

Q16. Are private fields inherited by subclasses?

Answer: A subclass instance contains the private fields declared by its parent, but subclass code cannot directly access the parent's private fields. The parent class can expose controlled access through methods or getters.
