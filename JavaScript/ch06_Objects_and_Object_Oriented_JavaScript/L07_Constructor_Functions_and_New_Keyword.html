2. What Is a Constructor Function?

A constructor function is a regular JavaScript function intended to create and initialize multiple objects with similar properties.

By convention, constructor function names begin with an uppercase letter.

Example

function Employee(name, department) {
    this.name = name;
    this.department = department;
}

const employee1 = new Employee("Rahul", "Testing");
const employee2 = new Employee("Priya", "Development");

console.log(employee1.name);
console.log(employee1.department);

console.log(employee2.name);
console.log(employee2.department);
Expected Output: 
Rahul
Testing
Priya
Development

The Employee function initializes objects. Each call using new creates a separate object with its own name and department properties.

3. Why Use Constructor Functions?

Suppose an application needs to store details for hundreds of employees. Creating each object manually would require repetitive code.

Without a Constructor

const employee1 = {
    name: "Rahul",
    department: "Testing"
};

const employee2 = {
    name: "Priya",
    department: "Development"
};

const employee3 = {
    name: "Aman",
    department: "Embedded"
};

With a Constructor

function Employee(name, department) {
    this.name = name;
    this.department = department;
}

const employee1 = new Employee("Rahul", "Testing");
const employee2 = new Employee("Priya", "Development");
const employee3 = new Employee("Aman", "Embedded");

Constructor functions provide:

  • Reusable object initialization logic.
  • Consistent object structure.
  • Less repetitive code.
  • A convenient way to create multiple related objects.

4. Understanding the new Operator

The new operator creates a new object using a constructor function.

When a function is called with new, JavaScript conceptually performs these operations:

  1. Creates a new empty object.
  2. Links the new object's internal prototype to the constructor's prototype object.
  3. Calls the constructor function with this referring to the new object.
  4. Returns the new object, unless the constructor explicitly returns another object or function.

Example

function Student(name, age) {
    this.name = name;
    this.age = age;
}

const student1 = new Student("Aman", 22);

console.log(student1);
console.log(student1.name);
console.log(student1.age);
Expected Output: 
Student { name: 'Aman', age: 22 }
Aman
22

The object representation varies between browser consoles and JavaScript runtimes.

Conceptual Representation

function Student(name, age) {
    this.name = name;
    this.age = age;
}

const student1 = new Student("Aman", 22);

/*
Conceptually:

1. Create a new object.
2. Link its prototype to Student.prototype.
3. Execute Student with this = new object.
4. Return the new object.
*/

5. Understanding this Inside a Constructor

Inside a constructor function called with new, this refers to the newly created instance.

Example

function Product(name, price) {
    this.name = name;
    this.price = price;
}

const product1 = new Product("Laptop", 55000);
const product2 = new Product("Mobile", 25000);

console.log(product1.name);
console.log(product2.name);

console.log(product1.price);
console.log(product2.price);
Expected Output: 
Laptop
Mobile
55000
25000

Each constructor call creates a separate instance. Assignments through this initialize the properties of the corresponding instance.

6. Adding Methods to Constructor Functions

Methods can be defined directly inside a constructor function.

Example

function Employee(name, salary) {
    this.name = name;
    this.salary = salary;

    this.getDetails = function() {
        return `${this.name} earns ${this.salary}`;
    };
}

const employee1 = new Employee("Rahul", 30000);
const employee2 = new Employee("Priya", 40000);

console.log(employee1.getDetails());
console.log(employee2.getDetails());

console.log(
    employee1.getDetails === employee2.getDetails
);
Expected Output: 
Rahul earns 30000
Priya earns 40000
false

Each constructor call creates a separate function object for getDetails().

This approach is simple, but it can use unnecessary memory when many instances are created. Shared methods are usually better placed on the constructor's prototype.

7. Understanding the prototype Property

Every ordinary constructible function has a prototype property that is used as the prototype of instances created with new.

This is different from the internal [[Prototype]] link of an object.

Example

function Person(name) {
    this.name = name;
}

Person.prototype.greet = function() {
    return `Hello, ${this.name}`;
};

const person1 = new Person("Aman");
const person2 = new Person("Priya");

console.log(person1.greet());
console.log(person2.greet());

console.log(person1.greet === person2.greet);
Expected Output: 
Hello, Aman
Hello, Priya
true

Both objects share the same greet() method through Person.prototype.

Inspecting the Prototype

function Person(name) {
    this.name = name;
}

const person = new Person("Rahul");

console.log(
    Object.getPrototypeOf(person) === Person.prototype
);
Expected Output: 
true

8. Constructor Property

A constructor's prototype object normally has a constructor property that points back to the constructor function.

Example

function Employee(name) {
    this.name = name;
}

const employee = new Employee("Aman");

console.log(employee.constructor === Employee);
console.log(employee.constructor.name);
Expected Output: 
true
Employee

The inherited constructor property is useful for understanding an object's constructor relationship. It should not be treated as a guaranteed type check because prototype properties can be modified or replaced.

9. The instanceof Operator

The instanceof operator checks whether a constructor's prototype property appears anywhere in an object's prototype chain.

Syntax:

object instanceof Constructor

Example

function Car(brand) {
    this.brand = brand;
}

const car1 = new Car("Toyota");

console.log(car1 instanceof Car);
console.log(car1 instanceof Object);
console.log(car1 instanceof Array);
Expected Output: 
true
true
false

Another Example

function User(name) {
    this.name = name;
}

const user = new User("Rahul");

console.log(user instanceof User);

const anotherUser = {};

console.log(anotherUser instanceof User);
Expected Output: 
true
false
instanceof is based on prototype-chain relationships, not simply on an object's property values. It can produce unexpected results across different JavaScript realms, such as separate browser windows or iframes.

10. Constructor Return Values

A constructor function normally returns the newly created object automatically when called with new.

10.1 Returning a Primitive Value

function User(name) {
    this.name = name;

    return 100;
}

const user = new User("Aman");

console.log(user.name);
console.log(typeof user);
Expected Output: 
Aman
object

An explicitly returned primitive value is ignored by the new operation.

10.2 Returning an Object

function User(name) {
    this.name = name;

    return {
        name: "Custom User"
    };
}

const user = new User("Aman");

console.log(user.name);
Expected Output: 
Custom User

When a constructor explicitly returns an object or function, that returned object becomes the result of the new expression.

11. Calling a Constructor Without new

A constructor function is still an ordinary function. Calling it without new does not create a new instance automatically.

Example: Strict Mode

"use strict";

function Employee(name) {
    this.name = name;
}

const employee = Employee("Rahul");

console.log(employee);
Expected Result: 
TypeError

In strict mode, a regular function call has this equal to undefined. Assigning this.name therefore throws an error.

Always use new when calling a constructor function intended to create an instance.

12. Constructor Function vs Factory Function

A factory function creates and returns an object directly. A constructor function is called with new and initializes the new instance.

Factory Function

function createUser(name) {
    return {
        name: name,
        greet() {
            return `Hello, ${this.name}`;
        }
    };
}

const user1 = createUser("Rahul");

console.log(user1.greet());
Expected Output: 
Hello, Rahul

Constructor Function

function User(name) {
    this.name = name;
}

User.prototype.greet = function() {
    return `Hello, ${this.name}`;
};

const user2 = new User("Priya");

console.log(user2.greet());
Expected Output: 
Hello, Priya
Factory Function Constructor Function
Usually called directly. Called using new.
Explicitly returns an object. Normally returns the newly created instance automatically.
Does not require constructor-style naming. Conventionally begins with an uppercase letter.
Can use closures for private state. Can share methods through its prototype.

13. Practical Application: Product Management

Constructor functions can initialize product objects in a simple inventory application. 

function Product(name, price, quantity) {
    this.name = name;
    this.price = price;
    this.quantity = quantity;
}

Product.prototype.getTotalValue = function() {
    return this.price * this.quantity;
};

Product.prototype.updateQuantity = function(amount) {
    this.quantity += amount;
};

const product1 = new Product("Laptop", 50000, 2);
const product2 = new Product("Keyboard", 1500, 5);

console.log(product1.getTotalValue());
console.log(product2.getTotalValue());

product1.updateQuantity(1);

console.log(product1.quantity);
console.log(product1.getTotalValue());
Expected Output: 
100000
7500
3
150000

Each product stores its own data, while all products share the same methods through Product.prototype.

14. Common Mistakes and Debugging

Mistake 1: Forgetting new

Calling a constructor without new does not create an instance. Use new ConstructorName().

Mistake 2: Using an Arrow Function as a Constructor

const User = (name) => {
    this.name = name;
};

// const user = new User("Aman"); // TypeError

Arrow functions do not have the internal construction capability required by new. Use a regular function or a class constructor.

Mistake 3: Defining Shared Methods Inside the Constructor

Defining methods inside the constructor creates a separate function for each instance. Put reusable methods on the prototype when appropriate.

Mistake 4: Replacing the Prototype Without Restoring constructor

function User(name) {
    this.name = name;
}

User.prototype = {
    greet() {
        return "Hello";
    }
};

const user = new User("Aman");

console.log(user.greet());
console.log(user.constructor === User);
Expected Output: 
Hello
false

Replacing the prototype object removes its default constructor property. If that relationship is needed, restore it explicitly. 

User.prototype = {
    constructor: User,

    greet() {
        return "Hello";
    }
};

Mistake 5: Confusing constructor with instanceof

The constructor property can be overwritten. Use instanceof when checking a known constructor's prototype-chain relationship, keeping its cross-realm limitations in mind.

15. Placement Interview Questions and Answers

Q1. What is a constructor function in JavaScript?

Answer: It is a regular function intended to initialize objects when called with the new operator.

Q2. What is the purpose of the new operator?

Answer: It creates a new object, links its prototype to the constructor's prototype object, executes the constructor with the new object as this, and returns the instance unless an object or function is explicitly returned.

Q3. What does this refer to inside a constructor called with new?

Answer: It refers to the newly created instance.

Q4. Why do constructor names begin with uppercase letters?

Answer: It is a naming convention that distinguishes constructor functions from ordinary functions. JavaScript does not enforce this convention.

Q5. What is the difference between a constructor's prototype and an object's prototype?

Answer: A constructor's prototype is a property used to establish the prototype of instances created with new. An object's internal [[Prototype]] is the actual link to its prototype object.

Q6. What is instanceof?

Answer: It checks whether a constructor's prototype appears in an object's prototype chain.

Q7. Can a constructor function return a value?

Answer: Yes. Primitive return values are ignored by new, while an explicitly returned object or function replaces the newly created instance.

Q8. Can arrow functions be used as constructors?

Answer: No. Arrow functions cannot be called with new.

Q9. Why should methods often be placed on the prototype?

Answer: All instances can share the same method instead of creating a separate function for each instance.

Q10. What is a factory function?

Answer: It is a function that creates and returns an object without requiring the new operator.

Q11. What happens if new is omitted in strict mode?

Answer: A regular constructor-function call does not create an instance. If the function assigns properties through this, it may throw a TypeError because this is undefined.

Q12. What happens when the prototype object is replaced?

Answer: New instances use the replacement prototype. Existing instances retain their previous prototype link. The replacement object may also lack the default constructor property.
