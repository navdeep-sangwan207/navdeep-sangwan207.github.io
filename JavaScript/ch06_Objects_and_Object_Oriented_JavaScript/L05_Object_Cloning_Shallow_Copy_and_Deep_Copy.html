After completing this lesson, you will be able to:

  • Understand value copying and reference copying.

  • Create shallow copies using spread syntax and Object.assign().
  • Understand how nested objects behave during shallow copying.

  • Identify limitations of JSON-based cloning.
  • Choose an appropriate copying technique for practical applications.
  • Answer common object-reference and cloning interview questions.

2. Value Types and Reference Types

JavaScript variables hold values. When a primitive value is assigned to another variable, the value is copied independently. Objects, however, are accessed through references.

2.1 Copying a Primitive Value

let first = 10;
let second = first;

second = 20;

console.log(first);
console.log(second);
Expected Output: 
10
20

Changing second does not change first. Each variable holds its own primitive value.

2.2 Assigning an Object

const first = {
    name: "Rahul",
    age: 25
};

const second = first;

second.age = 30;

console.log(first.age);
console.log(second.age);
console.log(first === second);
Expected Output: 
30
30
true

Both variables refer to the same object. Assigning first to second does not create another object.

2.3 Reference Equality

const object1 = {
    city: "Delhi"
};

const object2 = {
    city: "Delhi"
};

const object3 = object1;

console.log(object1 === object2);
console.log(object1 === object3);
Expected Output: 
false
true

Objects are compared by identity, not by comparing their property contents. Two separately created objects are different references even if their properties are identical.

3. What Is Object Cloning?

Object cloning means creating another object based on an existing object's properties.

There are two major types:

  • Shallow copy: Copies top-level properties. Nested objects remain shared references.
  • Deep copy: Recursively creates independent copies of supported nested data.
A new object reference does not automatically mean that every nested object has also been copied.

4. Shallow Copy Using Spread Syntax

The object spread syntax (...) copies an object's own enumerable properties into a new object.

Syntax:

const copiedObject = { ...originalObject };

Example 1: Copying a Flat Object

const original = {
    name: "Priya",
    age: 24,
    city: "Chandigarh"
};

const copy = { ...original };

copy.name = "Neha";
copy.age = 25;

console.log(original);
console.log(copy);
console.log(original === copy);
Expected Output: 
{
  name: "Priya",
  age: 24,
  city: "Chandigarh"
}

{
  name: "Neha",
  age: 25,
  city: "Chandigarh"
}

false

The new object has a separate top-level identity. Changing its primitive properties does not change the original.

Example 2: Adding a Property to the Copy

const original = {
    name: "Aman",
    age: 26
};

const copy = {
    ...original,
    department: "Development"
};

console.log(copy);
console.log(original);
Expected Output: 
{ name: "Aman", age: 26, department: "Development" }
{ name: "Aman", age: 26 }

5. Shallow Copy Using Object.assign()

Object.assign() can create a shallow copy by copying properties into a new empty target object.

Syntax:

const copy = Object.assign({}, original);

Example

const original = {
    product: "Laptop",
    price: 55000
};

const copy = Object.assign({}, original);

copy.price = 60000;

console.log(original.price);
console.log(copy.price);
console.log(original === copy);
Expected Output: 
55000
60000
false

Both spread syntax and Object.assign() perform shallow copying for ordinary object data.

6. The Nested Object Problem

Shallow copying does not recursively clone nested objects. It copies the nested object's reference.

Example 1: Nested Object

const original = {
    name: "Rahul",
    address: {
        city: "Delhi",
        state: "Delhi"
    }
};

const copy = { ...original };

copy.name = "Aman";
copy.address.city = "Mumbai";

console.log(original.name);
console.log(original.address.city);

console.log(copy.name);
console.log(copy.address.city);
Expected Output: 
Rahul
Mumbai
Aman
Mumbai

The top-level name property is independent. The nested address object is shared.

Example 2: Nested Array

const original = {
    name: "JavaScript",
    topics: ["Objects", "Arrays", "Functions"]
};

const copy = { ...original };

copy.topics.push("Closures");

console.log(original.topics);
console.log(copy.topics);
Expected Output: 
["Objects", "Arrays", "Functions", "Closures"]

["Objects", "Arrays", "Functions", "Closures"]

Both objects refer to the same nested array.

7. Copying Nested Objects with Spread Syntax

You can manually copy known nested levels by spreading each nested object that needs an independent copy.

Example

const original = {
    name: "Priya",
    address: {
        city: "Chandigarh",
        pin: 160001
    }
};

const copy = {
    ...original,
    address: {
        ...original.address
    }
};

copy.address.city = "Mohali";

console.log(original.address.city);
console.log(copy.address.city);
Expected Output: 
Chandigarh
Mohali

Both the outer object and the nested address object have been copied independently.

This approach must be repeated for every nested level that requires independence. It is not a general-purpose deep-copy solution for arbitrarily nested data.

8. Deep Copy Using structuredClone()

structuredClone() creates a deep copy of supported JavaScript data. It can handle nested objects, arrays, circular references, and several built-in data types.

Syntax:

const copy = structuredClone(original);

Example 1: Deep Copy of Nested Objects

const original = {
    name: "Rahul",
    address: {
        city: "Delhi",
        pin: 110001
    }
};

const copy = structuredClone(original);

copy.address.city = "Mumbai";

console.log(original.address.city);
console.log(copy.address.city);

console.log(original === copy);
console.log(original.address === copy.address);
Expected Output: 
Delhi
Mumbai
false
false

The copied outer object and nested address object have independent identities.

Example 2: Deep Copy of Nested Arrays

const original = {
    course: "JavaScript",
    chapters: [
        "Variables",
        "Functions",
        "Objects"
    ]
};

const copy = structuredClone(original);

copy.chapters.push("Closures");

console.log(original.chapters.length);
console.log(copy.chapters.length);
Expected Output: 
3
4

Example 3: Circular References

A circular reference occurs when an object refers to itself directly or indirectly. 

const original = {
    name: "Node"
};

original.self = original;

const copy = structuredClone(original);

console.log(copy.name);
console.log(copy.self === copy);
console.log(copy === original);
Expected Output: 
Node
true
false

The circular relationship is preserved inside the cloned object.

Important: structuredClone() does not clone every possible JavaScript value. Functions and DOM nodes, for example, are not structured-cloneable. Attempting to clone unsupported values can throw a DataCloneError.

9. Deep Copy Using JSON Methods

A commonly seen technique is converting an object into JSON text and parsing it back into a new object.

Syntax:

const copy = JSON.parse(JSON.stringify(original));

Example

const original = {
    name: "Aman",
    address: {
        city: "Delhi"
    },
    skills: ["C", "JavaScript"]
};

const copy = JSON.parse(JSON.stringify(original));

copy.address.city = "Mumbai";
copy.skills.push("React");

console.log(original.address.city);
console.log(original.skills);

console.log(copy.address.city);
console.log(copy.skills);
Expected Output: 
Delhi
["C", "JavaScript"]

Mumbai
["C", "JavaScript", "React"]

Limitations of JSON-Based Cloning

  • Properties with undefined values are omitted from objects.
  • Functions and symbol-keyed properties are not preserved.
  • Date objects become strings.
  • Map and Set are not preserved as their original types.
  • BigInt causes JSON serialization to throw an error.
  • Circular references cause JSON serialization to throw an error.
  • Special numeric values such as NaN and Infinity become null in JSON arrays and object values.
For supported structured data, prefer structuredClone() over the JSON workaround. JSON cloning is suitable only when the data is known to be JSON-compatible and its limitations are acceptable.

10. Comparison of Copying Techniques

Assignment (=) No No Copies the reference
Spread (...) Yes No Shallow copy
Object.assign() Yes, with a new target No Shallow copy
structuredClone() Yes Yes, for supported data Cannot clone every JavaScript value
JSON stringify/parse Yes For supported JSON data Lossy for many JavaScript values

11. Shallow Copy vs Deep Copy

Shallow Copy Deep Copy
Creates a new top-level object. Creates a new object with recursively copied supported data.
Nested objects remain shared references. Nested objects are copied independently.
Generally simpler and less expensive. Can require more processing and memory.
Useful when nested data is intentionally shared or immutable. Useful when independent nested data is required.
Examples: spread and Object.assign(). Example: structuredClone() for supported data.

12. Practical Application: Updating User Profile Data

In frontend applications, a common requirement is to create an updated object without changing the original data. 

const originalUser = {
    id: 101,
    name: "Rahul",
    profile: {
        city: "Delhi",
        skills: ["JavaScript", "HTML"]
    }
};

const updatedUser = {
    ...originalUser,
    profile: {
        ...originalUser.profile,
        city: "Chandigarh",
        skills: [
            ...originalUser.profile.skills,
            "CSS"
        ]
    }
};

console.log(originalUser.profile.city);
console.log(originalUser.profile.skills);

console.log(updatedUser.profile.city);
console.log(updatedUser.profile.skills);
Expected Output: 
Delhi
["JavaScript", "HTML"]

Chandigarh
["JavaScript", "HTML", "CSS"]

This pattern is useful when updating nested state in frontend applications. It creates new objects along the changed path while preserving unchanged data.

13. Common Mistakes and Debugging

Mistake 1: Assuming Assignment Creates a Copy

const copy = original does not clone an object. Both variables refer to the same object.

Mistake 2: Assuming Spread Syntax Performs Deep Copying

Spread syntax copies only the top-level properties. Nested objects and arrays remain shared.

Mistake 3: Assuming Object.assign() Recursively Copies Objects

Object.assign() is also a shallow-copy operation. It does not recursively clone nested structures.

Mistake 4: Using JSON Cloning for Every JavaScript Object

JSON serialization does not preserve many JavaScript types and cannot handle circular references.

Mistake 5: Forgetting to Copy Nested Levels

When using manual spread copying, every nested object that needs independence must also be copied.

Mistake 6: Assuming structuredClone() Supports Functions

Functions are not structured-cloneable. Attempting to clone an object containing an unsupported function value can throw a DataCloneError.

14. Placement Interview Questions and Answers

Q1. What is the difference between primitive and object assignment?

Answer: Primitive assignment copies the primitive value. Object assignment copies the reference to the same object.

Q2. What is object cloning?

Answer: Creating another object using the properties and data of an existing object.

Q3. What is a shallow copy?

Answer: A copy that creates a new top-level object but retains references to nested objects.

Q4. What is a deep copy?

Answer: A copy that recursively duplicates supported nested data so that changes to the copied nested structures do not affect the original.

Q5. How can you create a shallow copy using spread syntax?

Answer: Use const copy = { ...original };.

Q6. How can you create a shallow copy using Object.assign()?

Answer: Use const copy = Object.assign({}, original);.

Q7. What is the purpose of structuredClone()?

Answer: It creates a deep copy of supported structured data, including nested objects and circular references.

Q8. Why is JSON.parse(JSON.stringify()) not a perfect cloning technique?

Answer: JSON serialization does not preserve many JavaScript values and fails with circular references.

Q9. What happens when a nested object is changed after shallow copying?

Answer: The change is visible through both the original and copied objects because they share the nested object's reference.

Q10. How can you check whether two variables reference the same object?

Answer: Compare them using strict equality (===). It checks whether both references identify the same object.

Q11. Can structuredClone() clone circular references?

Answer: Yes. It preserves supported circular reference relationships.

Q12. When would you use a shallow copy instead of a deep copy?

Answer: When only top-level independence is required, when nested values are intentionally shared, or when an application uses immutable nested data.

16. Coding Exercises

Exercise 1: Create an Independent Object

Create an employee object and make a shallow copy using spread syntax. Change the copied employee's name and verify that the original name remains unchanged.

Exercise 2: Compare Object References

Create two objects with identical properties. Compare them using ===. Then assign one object to another variable and compare the references again.

Exercise 3: Demonstrate the Nested Object Problem

Create an object containing a nested address object. Make a shallow copy and change the copied address. Verify whether the original address changes.

Exercise 4: Copy Nested Objects Manually

Use nested spread syntax to create independent copies of an employee object and its address object.

Exercise 5: Deep Copy Using structuredClone()

Create an object containing nested objects and arrays. Deep-copy it and modify nested properties in the copy. Verify that the original remains unchanged.

Exercise 6: Compare JSON and structuredClone()

Create an object containing a Date, an undefined property and a nested object. Compare the results of JSON-based cloning and structuredClone().

Exercise 7: Build a Product Configuration Copy

Create a product object with specifications and a list of features. Make an independent copy and update the copied specifications and features without changing the original.

Exercise 8: Predict and Explain

Write a program using assignment, spread syntax, Object.assign() and structuredClone(). Modify top-level and nested properties and explain every output.

17. Lesson Summary

  • Primitive assignment copies a primitive value.
  • Object assignment copies a reference, not a new object.
  • Object equality checks reference identity.
  • Shallow copying creates a new top-level object.
  • Spread syntax and Object.assign() perform shallow copies.
  • Nested objects and arrays remain shared in a shallow copy.
  • Manual nested spread can copy selected nested levels.
  • structuredClone() deep-copies supported structured data.
  • structuredClone() supports circular references but not every JavaScript value.
  • JSON cloning has important data-type and circular-reference limitations.
  • Choose the copying strategy based on the data structure and application requirements.
