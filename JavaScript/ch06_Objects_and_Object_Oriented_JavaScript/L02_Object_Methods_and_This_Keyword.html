JavaScript Programming Course

Chapter 6: Objects and Object-Oriented JavaScript

Placement-Oriented Learning

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand methods and their relationship with objects.
  • Create methods using shorthand and function expressions.
  • Use the this keyword inside object methods.
  • Understand how the method invocation determines the value of this.
  • Identify problems caused by extracting methods from objects.
  • Use call(), apply() and bind().
  • Understand why arrow functions behave differently with this.

2. What Is an Object Method?

An object method is a function stored as a property of an object. Methods define the behavior or actions that an object can perform.

Example: Object with a Method

const employee = {
    name: "Rahul",
    department: "Engineering",

    displayDetails: function() {
        console.log("Name:", this.name);
        console.log("Department:", this.department);
    }
};

employee.displayDetails();
Expected Output: 
Name: Rahul
Department: Engineering

Here:

  • name and department are data properties.
  • displayDetails is a method.
  • this.name accesses the name property of the calling object.
  • employee.displayDetails() invokes the method.

3. Different Ways to Define Object Methods

3.1 Function Expression Syntax

const calculator = {
    add: function(a, b) {
        return a + b;
    },

    subtract: function(a, b) {
        return a - b;
    }
};

console.log(calculator.add(10, 5));
console.log(calculator.subtract(10, 5));
Expected Output: 
15
5

3.2 Method Shorthand Syntax

JavaScript allows methods to be defined without writing the function keyword. 

const calculator = {
    add(a, b) {
        return a + b;
    },

    multiply(a, b) {
        return a * b;
    }
};

console.log(calculator.add(4, 6));
console.log(calculator.multiply(4, 6));
Expected Output: 
10
24

3.3 Assigning a Function to an Object Property

const user = {
    name: "Amit"
};

user.greet = function() {
    console.log("Hello,", this.name);
};

user.greet();
Expected Output: 
Hello, Amit
Placement note: Method shorthand is commonly used in modern JavaScript. You should be comfortable reading both shorthand and function-expression syntax.

4. Understanding the this Keyword

The this keyword refers to the object associated with the current function invocation. In a regular object method call, it normally refers to the object before the dot. 

const student = {
    name: "Priya",
    marks: 85,

    showResult() {
        console.log(this.name);
        console.log(this.marks);
    }
};

student.showResult();
Expected Output: 
Priya
85

In the expression:

student.showResult();

student is the receiver of the method call. Therefore, this inside showResult() refers to student.

Important Rule

For regular functions, the value of this is determined by how the function is called, not simply by where it was defined.

5. this Depends on the Invocation

Example 1: Calling Through the Original Object

const person = {
    name: "Neha",

    greet() {
        console.log(this.name);
    }
};

person.greet();
Output: 
Neha

Example 2: Extracting a Method

When a method is assigned to another variable and called independently, the original object is no longer the receiver. 

"use strict";

const person = {
    name: "Neha",

    greet() {
        console.log(this.name);
    }
};

const greetFunction = person.greet;

greetFunction();
Expected Result: 
TypeError: Cannot read properties of undefined (reading 'name')

In strict mode, a regular function called without a receiver has this equal to undefined. Accessing this.name therefore causes a TypeError.

Example 3: Calling the Extracted Function with an Object

"use strict";

const person = {
    name: "Neha",

    greet() {
        console.log("Hello", this.name);
    }
};

const greetFunction = person.greet;

greetFunction.call(person);
Expected Output: 
Hello Neha

6. The call() Method

The call() method invokes a function immediately and explicitly sets its this value.

Syntax:

functionName.call(thisArg, arg1, arg2, ...);

Example

"use strict";

const employee1 = {
    name: "Rahul"
};

const employee2 = {
    name: "Priya"
};

function introduce(city, role) {
    console.log(
        this.name + " works as " + role + " in " + city
    );
}

introduce.call(employee1, "Delhi", "Developer");
introduce.call(employee2, "Pune", "Tester");
Expected Output: 
Rahul works as Developer in Delhi
Priya works as Tester in Pune

The same function is reused with different objects. The first argument determines this; subsequent arguments are passed individually.

7. The apply() Method

The apply() method is similar to call(), but it accepts function arguments as an array (or array-like object).

Syntax:

functionName.apply(thisArg, [arg1, arg2, ...]);

Example

"use strict";

const product = {
    name: "Laptop"
};

function calculatePrice(price, tax) {
    return price + (price * tax / 100);
}

const finalPrice = calculatePrice.apply(product, [50000, 18]);

console.log(product.name);
console.log("Final Price:", finalPrice);
Expected Output: 
Laptop
Final Price: 59000

The example uses product as the explicit this value, although the calculation itself does not need to access it.

8. The bind() Method

The bind() method creates and returns a new function with a permanently bound this value. It does not execute the function immediately.

Syntax:

const newFunction = functionName.bind(thisArg, arg1, ...);

Example

"use strict";

const user = {
    name: "Ankit"
};

function greet(message) {
    console.log(message + ", " + this.name);
}

const boundGreet = greet.bind(user);

boundGreet("Welcome");
boundGreet("Good morning");
Expected Output: 
Welcome, Ankit
Good morning, Ankit

Practical Example: Preserving a Method Context

"use strict";

const account = {
    owner: "Rohit",
    balance: 25000,

    showBalance() {
        console.log(this.owner + "'s balance:", this.balance);
    }
};

const displayBalance = account.showBalance.bind(account);

displayBalance();
Expected Output: 
Rohit's balance: 25000

9. Difference Between call(), apply() and bind()

Feature call() apply() bind()
Execution Immediately Immediately Returns a new function
this value Explicitly supplied Explicitly supplied Bound to supplied value
Arguments Individual arguments Array or array-like object Individual arguments; can be partially supplied
Common use Immediate function invocation Passing an argument list Preserving context for later execution

Quick Comparison

function show(a, b) {
    console.log(this.name, a, b);
}

const obj = { name: "JavaScript" };

show.call(obj, 10, 20);
show.apply(obj, [10, 20]);

const newShow = show.bind(obj, 10);
newShow(20);
Expected Output: 
JavaScript 10 20
JavaScript 10 20
JavaScript 10 20

10. Arrow Functions and this

Arrow functions do not have their own this. They inherit this lexically from the surrounding scope in which they are created.

Example 1: Arrow Function as an Object Method

const person = {
    name: "Aman",

    greet: () => {
        console.log(this.name);
    }
};

person.greet();

This does not behave like a regular object method. The arrow function does not receive person as its this value.

In a typical browser script, the surrounding top-level this may be the global object. In other execution contexts, the result can differ. Do not use an arrow function when you need the object itself as this.

Example 2: Arrow Function Inside a Regular Method

const person = {
    name: "Aman",

    greet() {
        const showName = () => {
            console.log(this.name);
        };

        showName();
    }
};

person.greet();
Expected Output: 
Aman

Here, the regular method receives person as this. The nested arrow function inherits that same this value.

Example 3: Arrow Function in a Callback

const team = {
    name: "Development Team",

    members: ["Aman", "Priya", "Rahul"],

    showMembers() {
        this.members.forEach((member) => {
            console.log(member + " - " + this.name);
        });
    }
};

team.showMembers();
Expected Output: 
Aman - Development Team
Priya - Development Team
Rahul - Development Team

The arrow callback inherits this from showMembers(), preserving access to the team object.

11. Regular Function vs Arrow Function

Feature Regular Function Arrow Function
Own this Yes; determined by invocation No; lexical this
call() / apply() Can set this Cannot change lexical this
bind() Can bind this Cannot change lexical this
Constructor with new Can be constructible when defined appropriately Cannot be used as a constructor
Typical object method Suitable when using this Usually unsuitable when this must refer to the object
Interview rule: Use regular method syntax when a method needs its own dynamic this. Use arrow functions for callbacks when inheriting the surrounding this is desirable.

12. Common Mistakes and Debugging

Mistake 1: Using an Arrow Function as an Object Method

const user = {
    name: "Ravi",
    show: () => console.log(this.name)
};

user.show();

Problem: The arrow function does not bind this to user.

Correction:

const user = {
    name: "Ravi",
    show() {
        console.log(this.name);
    }
};

user.show();

Mistake 2: Losing Context After Method Extraction

const user = {
    name: "Ravi",
    show() {
        console.log(this.name);
    }
};

const display = user.show;
display();

Problem: The detached function is no longer called through user. In strict mode, this is undefined.

Correction:

const display = user.show.bind(user);
display();

Mistake 3: Expecting bind() to Execute Immediately

const result = user.show.bind(user);

Problem: result contains a new function. The method has not yet been executed.

Correction:

const result = user.show.bind(user);
result();

Mistake 4: Confusing call() and apply()

show.call(user, [10, 20]);

This passes one array argument. It does not pass two separate arguments. Use call(user, 10, 20) or apply(user, [10, 20]).

13. Practical Example: Bank Account Object

This example combines object properties, methods and this to implement basic account operations. 

const bankAccount = {
    accountHolder: "Rahul",
    balance: 10000,

    deposit(amount) {
        if (amount > 0) {
            this.balance += amount;
            console.log("Deposited:", amount);
        } else {
            console.log("Invalid deposit amount");
        }
    },

    withdraw(amount) {
        if (amount <= 0) {
            console.log("Invalid withdrawal amount");
        } else if (amount > this.balance) {
            console.log("Insufficient balance");
        } else {
            this.balance -= amount;
            console.log("Withdrawn:", amount);
        }
    },

    showBalance() {
        console.log("Account Holder:", this.accountHolder);
        console.log("Balance:", this.balance);
    }
};

bankAccount.deposit(5000);
bankAccount.withdraw(3000);
bankAccount.showBalance();
Expected Output: 
Deposited: 5000
Withdrawn: 3000
Account Holder: Rahul
Balance: 12000

Concepts applied:

  • Object properties store account information.
  • Methods implement deposit and withdrawal operations.
  • this.balance accesses and updates the current account balance.
  • Conditional statements validate transactions.

14. Placement Interview Questions and Answers

Q1. What is an object method?

Answer: An object method is a function stored as a property of an object. It defines an action that the object can perform.

Q2. What does this refer to inside a regular object method?

Answer: In a normal method invocation such as obj.method(), this refers to obj.

Q3. Is this determined by where a function is defined?

Answer: For regular functions, generally no. It depends on the invocation pattern. Arrow functions are different because they inherit this lexically.

Q4. What happens when an object method is assigned to another variable?

Answer: The function reference is copied, but the original receiver is not preserved. A detached regular function called in strict mode has this equal to undefined.

Q5. What is the difference between call() and apply()?

Answer: Both invoke a function immediately and set its this value. call() accepts arguments individually, whereas apply() accepts an array or array-like argument list.

Q6. Does bind() execute a function?

Answer: No. It returns a new function with a bound this value and optionally pre-filled arguments.

Q7. Why should arrow functions generally not be used as object methods?

Answer: Arrow functions do not have their own this, so they do not automatically refer to the object containing them.

Q8. Can call(), apply() or bind() change this inside an arrow function?

Answer: No. Arrow functions retain their lexical this. These methods cannot replace it.

Q9. What is method shorthand?

Answer: It is a concise way of defining methods inside object literals, such as greet() { }.

Q10. What is the difference between a method and a standalone function?

Answer: A method is a function stored as an object property. The term method describes its role; the same function can behave differently depending on how it is invoked.

17. Lesson Summary

  • A method is a function stored as an object property.
  • Object methods can use shorthand or function-expression syntax.
  • In a regular method call, this usually refers to the calling object.
  • Extracting a method does not preserve its original receiver.
  • call() invokes a function with an explicitly supplied this.
  • apply() invokes a function with arguments supplied as an array-like list.
  • bind() returns a new function with a bound this.
  • Arrow functions inherit this from their surrounding lexical scope.
  • Regular methods and arrow callbacks are often a useful combination.
