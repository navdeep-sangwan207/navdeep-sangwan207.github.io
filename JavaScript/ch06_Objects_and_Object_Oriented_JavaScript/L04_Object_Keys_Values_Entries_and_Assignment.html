Placement-Oriented Learning

1. Learning Objectives

After completing this lesson, you will be able to:

  • Extract object property names using Object.keys().
  • Extract property values using Object.values().
  • Convert object properties into key-value pairs using Object.entries().
  • Convert key-value pairs back into objects using Object.fromEntries().
  • Copy and merge objects using Object.assign().
  • Understand property enumeration and iteration order.
  • Use object methods for data processing and frontend development.

2. Object.keys()

The Object.keys() method returns an array containing the names of an object's own enumerable string-keyed properties.

Syntax:

Object.keys(objectName);

Example

const employee = {
    name: "Rahul",
    age: 25,
    department: "Engineering",
    salary: 45000
};

const keys = Object.keys(employee);

console.log(keys);
Expected Output: 
["name", "age", "department", "salary"]

Using Object.keys() to Count Properties

const product = {
    id: 101,
    name: "Laptop",
    price: 55000,
    stock: 12
};

const propertyCount = Object.keys(product).length;

console.log("Total Properties:", propertyCount);
Expected Output: 
Total Properties: 4

Checking Whether an Object Is Empty

const user1 = {};
const user2 = {
    name: "Aman"
};

console.log(Object.keys(user1).length === 0);
console.log(Object.keys(user2).length === 0);
Expected Output: 
true
false

This is a common technique for checking whether an object has any own enumerable string-keyed properties.

3. Object.values()

The Object.values() method returns an array containing the values of an object's own enumerable string-keyed properties.

Syntax:

Object.values(objectName);

Example

const employee = {
    name: "Priya",
    age: 24,
    department: "Testing",
    salary: 40000
};

const values = Object.values(employee);

console.log(values);
Expected Output: 
["Priya", 24, "Testing", 40000]

Calculating the Sum of Numeric Values

const marks = {
    mathematics: 85,
    physics: 90,
    chemistry: 80
};

const totalMarks = Object.values(marks)
    .reduce((total, mark) => total + mark, 0);

console.log("Total Marks:", totalMarks);
Expected Output: 
Total Marks: 255

Finding the Highest Value

const scores = {
    student1: 78,
    student2: 92,
    student3: 85
};

const highestScore = Math.max(...Object.values(scores));

console.log("Highest Score:", highestScore);
Expected Output: 
Highest Score: 92

4. Object.entries()

The Object.entries() method returns an array containing the object's own enumerable string-keyed properties as key-value pairs.

Syntax:

Object.entries(objectName);

Example

const employee = {
    name: "Aman",
    age: 26,
    department: "Development"
};

const entries = Object.entries(employee);

console.log(entries);
Expected Output: 
[
  ["name", "Aman"],
  ["age", 26],
  ["department", "Development"]
]

Each entry is a two-element array:

  • First element: property key.
  • Second element: property value.

Iterating Through Object.entries()

const product = {
    name: "Keyboard",
    price: 1200,
    stock: 25
};

for (const [key, value] of Object.entries(product)) {
    console.log(key + ":", value);
}
Expected Output: 
name: Keyboard
price: 1200
stock: 25

The for...of loop processes each entry. Array destructuring extracts its key and value.

5. Comparing Object.keys(), Object.values() and Object.entries()

const student = {
    name: "Neha",
    age: 22,
    course: "JavaScript"
};

console.log(Object.keys(student));
console.log(Object.values(student));
console.log(Object.entries(student));
Expected Output: 
["name", "age", "course"]

["Neha", 22, "JavaScript"]

[
  ["name", "Neha"],
  ["age", 22],
  ["course", "JavaScript"]
]
Method Returns Typical Use
Object.keys() Array of property names Inspect or count properties
Object.values() Array of property values Calculate or process values
Object.entries() Array of key-value pairs Iterate over keys and values together

6. Object.fromEntries()

The Object.fromEntries() method converts an iterable of key-value pairs into an object.

Syntax:

Object.fromEntries(iterable);

Example

const entries = [
    ["name", "Rahul"],
    ["age", 25],
    ["department", "IT"]
];

const employee = Object.fromEntries(entries);

console.log(employee);
console.log(employee.name);
Expected Output: 
{
  name: "Rahul",
  age: 25,
  department: "IT"
}
Rahul

Converting an Object into Entries and Back

const original = {
    name: "Priya",
    age: 24
};

const entries = Object.entries(original);
const converted = Object.fromEntries(entries);

console.log(converted);
Expected Output: 
{ name: "Priya", age: 24 }

This technique is useful when transforming object data before creating a new object.

7. Object.assign()

The Object.assign() method copies the values of all own enumerable properties from one or more source objects into a target object.

Syntax:

Object.assign(target, source1, source2, ...);

Example 1: Copying Properties into an Empty Object

const source = {
    name: "Aman",
    age: 25
};

const target = {};

Object.assign(target, source);

console.log(target);
console.log(target === source);
Expected Output: 
{ name: "Aman", age: 25 }
false

A new target object receives the source's property values. The source and target are different objects.

Example 2: Merging Multiple Objects

const personalDetails = {
    name: "Rahul",
    age: 26
};

const professionalDetails = {
    department: "Engineering",
    salary: 50000
};

const employee = Object.assign(
    {},
    personalDetails,
    professionalDetails
);

console.log(employee);
Expected Output: 
{
  name: "Rahul",
  age: 26,
  department: "Engineering",
  salary: 50000
}

Example 3: Handling Duplicate Properties

If multiple source objects contain the same property, the value from the last source object wins. 

const defaultSettings = {
    theme: "light",
    language: "English"
};

const userSettings = {
    theme: "dark"
};

const settings = Object.assign(
    {},
    defaultSettings,
    userSettings
);

console.log(settings);
Expected Output: 
{ theme: "dark", language: "English" }

Example 4: Object.assign() Modifies the Target

const target = {
    name: "Aman",
    age: 24
};

const source = {
    age: 25,
    city: "Delhi"
};

const result = Object.assign(target, source);

console.log(target);
console.log(result === target);
Expected Output: 
{ name: "Aman", age: 25, city: "Delhi" }
true
Important: Object.assign() modifies and returns the target object. Use Object.assign({}, source) when you want a new top-level object rather than modifying the source.

8. Object.assign() and Shallow Copying

Object.assign() copies property values. When a property contains an object or array, its reference is copied rather than recursively cloning the nested value.

Example

const original = {
    name: "Priya",
    address: {
        city: "Chandigarh"
    }
};

const copy = Object.assign({}, original);

copy.name = "Neha";
copy.address.city = "Mohali";

console.log(original.name);
console.log(original.address.city);

console.log(copy.name);
console.log(copy.address.city);
Expected Output: 
Priya
Mohali
Neha
Mohali

The top-level name property is copied independently. However, both objects refer to the same nested address object.

Shallow copy and deep copy are covered in detail in the next lecture.

9. Iterating Through Object Properties

9.1 for...in Loop

The for...in loop iterates over enumerable string-keyed properties, including inherited enumerable properties. 

const employee = {
    name: "Aman",
    age: 25,
    department: "IT"
};

for (const key in employee) {
    console.log(key, employee[key]);
}
Expected Output: 
name Aman
age 25
department IT

9.2 for...of with Object.keys()

const employee = {
    name: "Priya",
    age: 24,
    department: "Testing"
};

for (const key of Object.keys(employee)) {
    console.log(key);
}
Expected Output: 
name
age
department

9.3 for...of with Object.values()

const employee = {
    name: "Priya",
    age: 24,
    department: "Testing"
};

for (const value of Object.values(employee)) {
    console.log(value);
}
Expected Output: 
Priya
24
Testing

9.4 for...of with Object.entries()

const employee = {
    name: "Priya",
    age: 24,
    department: "Testing"
};

for (const [key, value] of Object.entries(employee)) {
    console.log(key + " = " + value);
}
Expected Output: 
name = Priya
age = 24
department = Testing
Technique What it iterates Includes inherited enumerable properties?
for...in Enumerable string keys Yes
Object.keys() Own enumerable string keys No
Object.values() Values of own enumerable string keys No
Object.entries() Own enumerable string key-value pairs No
When using for...in and you only want an object's own properties, check each key using Object.hasOwn(object, key).

10. Property Enumeration Order

JavaScript has defined rules for the order in which own properties are returned by methods such as Object.keys() and Object.entries().

The general order is:

  1. Integer-index-like string keys in ascending numeric order.
  2. Other string keys in insertion order.
  3. Symbol keys in insertion order for APIs that include symbols.

Example

const data = {
    "b": "Banana",
    "2": "Two",
    "1": "One",
    "a": "Apple",
    "10": "Ten"
};

console.log(Object.keys(data));
Expected Output: 
["1", "2", "10", "b", "a"]

Integer-index-like keys are listed in ascending numeric order. Other string keys retain their insertion order.

The enumeration behavior of symbols differs from ordinary string-key enumeration. Object.keys(), Object.values() and Object.entries() do not include symbol-keyed properties.

11. Working with Non-Enumerable and Symbol Properties

11.1 Non-Enumerable Properties

A property with enumerable: false is not returned by Object.keys(), Object.values() or Object.entries(). 

const user = {
    name: "Aman"
};

Object.defineProperty(user, "password", {
    value: "secret",
    enumerable: false
});

console.log(Object.keys(user));
console.log(Object.entries(user));
Expected Output: 
["name"]
[["name", "Aman"]]

11.2 Symbol Properties

Symbols are unique primitive values that can be used as object property keys. 

const id = Symbol("id");

const user = {
    name: "Priya",
    [id]: 101
};

console.log(Object.keys(user));
console.log(Object.getOwnPropertySymbols(user));
Expected Output: 
["name"]
[Symbol(id)]

To retrieve all own keys, including non-enumerable string keys and symbols, use Reflect.ownKeys(). 

console.log(Reflect.ownKeys(user));

12. Practical Example: Dynamic Employee Report

This example uses object methods to generate a report from employee records. 

const employees = {
    employee1: {
        name: "Rahul",
        salary: 40000
    },

    employee2: {
        name: "Priya",
        salary: 45000
    },

    employee3: {
        name: "Aman",
        salary: 50000
    }
};

const employeeRecords = Object.values(employees);

console.log("Employee Report");

employeeRecords.forEach((employee) => {
    console.log(
        employee.name + " : Rs. " + employee.salary
    );
});

const totalSalary = employeeRecords.reduce(
    (total, employee) => total + employee.salary,
    0
);

console.log("Total Salary:", totalSalary);
Expected Output: 
Employee Report
Rahul : Rs. 40000
Priya : Rs. 45000
Aman : Rs. 50000
Total Salary: 135000

Concepts applied:

  • Object.values() extracts employee records.
  • forEach() processes each employee.
  • reduce() calculates total salary.
  • Object data is transformed into a report.

13. Common Mistakes and Debugging

Mistake 1: Expecting Object.keys() to Return All Properties

Object.keys() returns only own enumerable string-keyed properties. It excludes inherited, non-enumerable and symbol-keyed properties.

Mistake 2: Forgetting That Object.assign() Mutates Its Target

const target = { name: "Aman" };
const source = { age: 25 };

Object.assign(target, source);

console.log(target);

The target object itself is modified. Use an empty object as the target when you want a new top-level object.

Mistake 3: Assuming Object.assign() Performs a Deep Copy

Nested object references are copied, not recursively cloned. Changes to a shared nested object can be visible through both the original and copied objects.

Mistake 4: Using for...in Without Checking Ownership

The loop can include inherited enumerable properties. Use Object.hasOwn() when you need to filter them.

Mistake 5: Confusing Entries with Values

Object.values() returns individual values. Object.entries() returns arrays containing both keys and values.

Mistake 6: Expecting Symbols in Object.keys()

Symbol-keyed properties are excluded. Use Object.getOwnPropertySymbols() or Reflect.ownKeys() when symbols are required.

14. Placement Interview Questions and Answers

Q1. What does Object.keys() return?

Answer: An array of an object's own enumerable string-keyed property names.

Q2. What is the difference between Object.keys() and Object.values()?

Answer: Object.keys() returns property names, while Object.values() returns corresponding property values.

Q3. What does Object.entries() return?

Answer: An array of two-element arrays. Each inner array contains a property key and its value.

Q4. What is Object.fromEntries()?

Answer: It converts an iterable of key-value pairs into a new object.

Q5. What is Object.assign() used for?

Answer: It copies own enumerable properties from one or more source objects into a target object.

Q6. Does Object.assign() create a deep copy?

Answer: No. It performs a shallow copy. Nested objects and arrays retain their references.

Q7. Does Object.assign() modify the source object?

Answer: It normally reads from the source objects without modifying them. It modifies the target object.

Q8. What happens when duplicate keys are present during assignment?

Answer: Later source values overwrite earlier values in the target.

Q9. What is the difference between for...in and for...of?

Answer: for...in iterates over enumerable string property keys. for...of iterates over values supplied by an iterable.

Q10. Does Object.keys() include inherited properties?

Answer: No. It includes only the object's own enumerable string-keyed properties.

Q11. Does Object.keys() include symbol properties?

Answer: No. Symbol-keyed properties are excluded.

Q12. How can you retrieve all own keys, including symbols and non-enumerable properties?

Answer: Use Reflect.ownKeys().

17. Lesson Summary

  • Object.keys() returns own enumerable string property names.
  • Object.values() returns the corresponding property values.
  • Object.entries() returns key-value pairs.
  • Object.fromEntries() converts key-value pairs into an object.
  • Object.assign() copies properties into a target object.
  • Object.assign() performs a shallow copy.
  • for...in can include inherited enumerable properties.
  • for...of iterates over iterable values.
  • Integer-index-like string keys are enumerated before other string keys.
  • Symbol and non-enumerable properties are excluded from Object.keys(), values() and entries().
  • Reflect.ownKeys() retrieves all own string and symbol keys.
