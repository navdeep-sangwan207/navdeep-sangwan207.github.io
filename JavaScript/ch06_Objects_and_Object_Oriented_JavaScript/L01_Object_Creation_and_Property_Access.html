2. What Is an Object in JavaScript?

An object is a collection of properties. Each property consists of a key and an associated value.

Objects allow related information to be grouped together instead of storing every value in a separate variable.

Example: Without an Object

let employeeName = "Rahul";
let employeeAge = 25;
let employeeDepartment = "Engineering";
let employeeSalary = 35000;

console.log(employeeName);
console.log(employeeAge);
console.log(employeeDepartment);
console.log(employeeSalary);

Example: Using an Object

const employee = {
    name: "Rahul",
    age: 25,
    department: "Engineering",
    salary: 35000
};

console.log(employee);
Output: 
{
    name: "Rahul",
    age: 25,
    department: "Engineering",
    salary: 35000
}

Object Structure

const student = {
    name: "Amit",
    age: 22,
    course: "JavaScript"
};
Component Example Meaning
Object name student Variable referring to the object.
Property key name Identifier of a property.
Property value "Amit" Value associated with the key.
Property pair name: "Amit" A key-value pair.
Object property values can be strings, numbers, booleans, null, undefined, arrays, functions or other objects.

3. Creating Objects Using Object Literals

The object literal is the most common way to create an object in JavaScript.

Syntax

const objectName = {
    property1: value1,
    property2: value2,
    property3: value3
};

Example

const product = {
    id: 101,
    name: "Laptop",
    price: 55000,
    available: true
};

console.log(product);
Output: 
{
    id: 101,
    name: "Laptop",
    price: 55000,
    available: true
}

Creating an Empty Object

const user = {};

user.name = "Neha";
user.age = 24;

console.log(user);
Output: 
{ name: "Neha", age: 24 }

Creating Objects Using new Object()

const employee = new Object();

employee.name = "Rohit";
employee.salary = 40000;
employee.department = "Testing";

console.log(employee);
Output: 
{
    name: "Rohit",
    salary: 40000,
    department: "Testing"
}
Object literals are generally preferred for straightforward object creation because they are concise and readable.

4. Creating Objects Using Object.create()

Object.create() creates a new object using a specified object as its prototype.

Syntax

Object.create(prototypeObject);

Example

const personPrototype = {
    greet: function() {
        return "Hello!";
    }
};

const person = Object.create(personPrototype);

person.name = "Amit";

console.log(person.name);
console.log(person.greet());
Output: 
Amit
Hello!

The person object does not own the greet method. It inherits that method through its prototype.

Prototype inheritance and Object.create() are examined in detail in Lecture 6.

5. Accessing Object Properties

JavaScript provides two common ways to access object properties:

  • Dot notation
  • Bracket notation

5.1 Dot Notation

Dot notation accesses a property using its name directly after the object variable. 

const student = {
    name: "Aman",
    age: 21,
    course: "JavaScript"
};

console.log(student.name);
console.log(student.age);
console.log(student.course);
Output: 
Aman
21
JavaScript

5.2 Bracket Notation

Bracket notation accesses a property using a string or an expression inside square brackets. 

const student = {
    name: "Aman",
    age: 21,
    course: "JavaScript"
};

console.log(student["name"]);
console.log(student["age"]);
console.log(student["course"]);
Output: 
Aman
21
JavaScript

Dot Notation vs Bracket Notation

Feature Dot Notation Bracket Notation
Syntax obj.name obj["name"]
Property name Identifier syntax String or expression
Dynamic property access Not directly supported Supported
Keys with spaces Not supported Supported
Keys with hyphens Not supported as ordinary property names Supported

Accessing Properties with Special Characters

const employee = {
    "first name": "Rahul",
    "employee-id": 101,
    "department name": "Software"
};

console.log(employee["first name"]);
console.log(employee["employee-id"]);
console.log(employee["department name"]);
Output: 
Rahul
101
Software
This will cause a syntax error: 
console.log(employee.first name);
Use bracket notation when property names contain spaces or other characters that are not valid in dot notation.

6. Dynamic Property Access

Bracket notation can use a variable to determine which property should be accessed.

Example

const employee = {
    name: "Priya",
    age: 26,
    department: "Development"
};

const property = "department";

console.log(employee[property]);
Output: 
Development

Dynamic Access with User Input

const product = {
    name: "Mobile",
    price: 18000,
    brand: "Samsung"
};

function getProperty(object, key) {
    return object[key];
}

console.log(getProperty(product, "name"));
console.log(getProperty(product, "price"));
console.log(getProperty(product, "brand"));
Output: 
Mobile
18000
Samsung

Using a Variable as a Property Key

const key = "city";

const user = {
    [key]: "Chandigarh"
};

console.log(user.city);
console.log(user["city"]);
Output: 
Chandigarh
Chandigarh

The expression inside the brackets is evaluated when the object is created.

7. Adding Object Properties

New properties can be added after an object has been created.

Example

const employee = {
    name: "Ravi",
    age: 28
};

employee.salary = 45000;
employee.department = "Engineering";

console.log(employee);
Output: 
{
    name: "Ravi",
    age: 28,
    salary: 45000,
    department: "Engineering"
}

Adding Properties Using Bracket Notation

const student = {};

student["first name"] = "Anjali";
student["roll-number"] = 25;

console.log(student);
Output: 
{
    "first name": "Anjali",
    "roll-number": 25
}

8. Updating Object Properties

Assigning a new value to an existing property updates that property.

Example

const employee = {
    name: "Amit",
    salary: 30000,
    department: "Testing"
};

employee.salary = 40000;
employee.department = "Development";

console.log(employee);
Output: 
{
    name: "Amit",
    salary: 40000,
    department: "Development"
}

Update Using a Variable

const product = {
    name: "Laptop",
    price: 50000
};

const property = "price";

product[property] = 55000;

console.log(product.price);
Output: 
55000

9. Deleting Object Properties

The delete operator removes an own property from an object.

Syntax

delete objectName.propertyName;

Example

const employee = {
    name: "Neha",
    age: 25,
    salary: 35000
};

delete employee.age;

console.log(employee);
Output: 
{
    name: "Neha",
    salary: 35000
}

Deleting Using Bracket Notation

const user = {
    name: "Aman",
    "account-type": "Premium"
};

delete user["account-type"];

console.log(user);
Output: 
{ name: "Aman" }
The delete operator removes a property. It does not delete the variable holding the object. It also does not remove inherited properties from the prototype.

10. Nested Objects

An object can contain another object as a property. Such structures are called nested objects.

Example

const employee = {
    id: 101,
    name: "Rahul",

    address: {
        city: "Chandigarh",
        state: "Punjab",
        country: "India"
    },

    department: {
        name: "Engineering",
        floor: 3
    }
};

console.log(employee.name);
console.log(employee.address.city);
console.log(employee.department.name);
Output: 
Rahul
Chandigarh
Engineering

Updating Nested Properties

employee.address.city = "Mohali";
employee.department.floor = 4;

console.log(employee.address.city);
console.log(employee.department.floor);
Output: 
Mohali
4

Adding a Nested Property

employee.address.postalCode = 160001;

console.log(employee.address.postalCode);
Output: 
160001

Accessing a Deeply Nested Property

const company = {
    name: "Tech Solutions",

    office: {
        location: {
            city: "Chandigarh",
            building: {
                floor: 5
            }
        }
    }
};

console.log(company.office.location.building.floor);
Output: 
5

11. Optional Chaining Operator (?.)

Optional chaining allows safe access to nested properties when an intermediate value might be null or undefined.

Problem Without Optional Chaining

const user = {
    name: "Amit"
};

console.log(user.address.city);
Result: TypeError. The address property is undefined, so JavaScript cannot access its city property.

Solution Using Optional Chaining

const user = {
    name: "Amit"
};

console.log(user.address?.city);
console.log(user.contact?.phone);
Output: 
undefined
undefined

Optional Chaining at Multiple Levels

const employee = {
    name: "Priya",
    address: {
        city: "Delhi"
    }
};

console.log(employee.address?.city);
console.log(employee.company?.location?.city);
Output: 
Delhi
undefined

Optional Chaining with Arrays

const users = [
    { name: "Aman" },
    { name: "Neha" }
];

console.log(users[0]?.name);
console.log(users[5]?.name);
Output: 
Aman
undefined
Optional chaining does not make an undeclared variable safe. It also does not prevent errors when an existing property contains a non-null value of an incompatible type.

12. Checking Whether a Property Exists

JavaScript provides several ways to check whether an object contains a property.

12.1 Using the in Operator

const student = {
    name: "Rohit",
    age: 22
};

console.log("name" in student);
console.log("salary" in student);
Output: 
true
false

The in operator checks both own properties and properties inherited through the prototype chain.

12.2 Using Object.hasOwn()

const student = {
    name: "Rohit",
    age: 22
};

console.log(Object.hasOwn(student, "name"));
console.log(Object.hasOwn(student, "salary"));
Output: 
true
false

Object.hasOwn() checks only whether the property belongs directly to the object.

12.3 Using hasOwnProperty()

const student = {
    name: "Rohit",
    age: 22
};

console.log(student.hasOwnProperty("name"));
console.log(student.hasOwnProperty("salary"));
Output: 
true
false
Object.hasOwn() is generally preferred for checking own properties. It also works with objects that do not inherit from Object.prototype.

12.4 Checking Against undefined

const user = {
    name: "Amit",
    age: undefined
};

console.log(user.name !== undefined);
console.log(user.age !== undefined);
console.log(user.salary !== undefined);
Output: 
true
false
false
Checking against undefined cannot distinguish between a missing property and a property that exists with the value undefined. Use Object.hasOwn() when property existence itself matters.

13. Object Property Names and Reserved Words

Object property names can be identifiers, strings or computed expressions.

Using Reserved Words as Property Names

const config = {
    default: true,
    class: "premium",
    return: "success"
};

console.log(config.default);
console.log(config.class);
console.log(config.return);
Output: 
true
premium
success

Reserved words can be used as object property names in these contexts.

Numeric Property Keys

const data = {
    1: "One",
    2: "Two",
    3: "Three"
};

console.log(data[1]);
console.log(data["2"] );
Output: 
One
Two

Ordinary object property keys are strings or symbols. Numeric property names are converted to strings.

14. Objects Are Reference Types

When an object is assigned to another variable, the reference is copied rather than creating an independent object.

Example

const user1 = {
    name: "Amit",
    age: 25
};

const user2 = user1;

user2.name = "Rahul";

console.log(user1.name);
console.log(user2.name);
Output: 
Rahul
Rahul

Both variables refer to the same object. Therefore, modifying the object through either reference is visible through the other.

Comparing Two Objects

const object1 = {
    name: "Amit"
};

const object2 = {
    name: "Amit"
};

const object3 = object1;

console.log(object1 === object2);
console.log(object1 === object3);
Output: 
false
true

object1 and object2 contain the same property values but are different objects. object1 and object3 refer to the same object.

Object equality using === compares references, not the contents of two separate objects. Object copying is covered in Lecture 5.

15. Practical Example: Employee Management

The following example combines object creation, property access, updates, nested objects and property deletion. 

const employee = {
    employeeId: 101,
    name: "Rahul",
    designation: "Software Engineer",
    salary: 40000,

    contact: {
        email: "rahul@example.com",
        city: "Chandigarh"
    }
};

// Access properties
console.log("Name:", employee.name);
console.log("Salary:", employee.salary);
console.log("City:", employee.contact.city);

// Update properties
employee.salary = 45000;
employee.contact.city = "Mohali";

// Add a new property
employee.experience = 2;

// Delete a property
delete employee.designation;

// Display updated object
console.log(employee);
Output: 
Name: Rahul
Salary: 40000
City: Chandigarh

{
    employeeId: 101,
    name: "Rahul",
    salary: 45000,
    contact: {
        email: "rahul@example.com",
        city: "Mohali"
    },
    experience: 2
}

16. Common Mistakes and Debugging

Mistake 1: Using Dot Notation for Dynamic Keys

const user = {
    name: "Amit",
    age: 25
};

const key = "name";

console.log(user.key);
Output: undefined The code searches for a property literally named "key".

Correct approach:

console.log(user[key]);

Mistake 2: Accessing a Missing Nested Property

const user = {
    name: "Amit"
};

console.log(user.address.city);

This causes a TypeError because address is undefined.

Correct approach:

console.log(user.address?.city);

Mistake 3: Comparing Objects by Their Contents

const a = { value: 10 };
const b = { value: 10 };

console.log(a === b);

The result is false because the two objects have different references.

Mistake 4: Confusing Missing Properties with undefined

const user = {
    name: "Amit",
    age: undefined
};

console.log("age" in user);
console.log("salary" in user);
Output: 
true
false

A property can exist even when its value is undefined.

17. Important Interview Questions

Q1. What is an object in JavaScript?

An object is a collection of properties represented as key-value pairs. It can store data and methods.

Q2. What are the different ways to create objects?

Common approaches include object literals, new Object(), Object.create() and constructor functions or classes.

Q3. What is the difference between dot and bracket notation?

Dot notation uses an identifier directly. Bracket notation supports dynamic expressions and property names containing spaces or hyphens.

Q4. How do you add a property to an object?

Assign a value using dot or bracket notation, for example user.email = "a@example.com".

Q5. How do you delete an object property?

Use the delete operator, for example delete user.email.

Q6. Can an object contain another object?

Yes. This is called a nested object.

Q7. What is optional chaining?

Optional chaining uses ?. to safely access properties when an intermediate value may be null or undefined.

Q8. What is the difference between in and Object.hasOwn()?

The in operator checks own and inherited properties. Object.hasOwn() checks only own properties.

Q9. Are objects mutable in JavaScript?

Yes. Object properties can generally be added, changed or deleted unless restrictions such as freezing or property descriptors prevent it.

Q10. What happens when one object is assigned to another variable?

The reference is copied. Both variables can refer to the same object.

Q11. Why do two objects with identical properties compare as false?

Because === compares object references rather than comparing their property contents.

Q12. What are computed property names?

They allow expressions inside square brackets to determine property names during object creation.
