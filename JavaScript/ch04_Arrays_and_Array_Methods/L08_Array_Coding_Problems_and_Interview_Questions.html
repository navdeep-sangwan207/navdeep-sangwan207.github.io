Array coding problems become easier when you recognize the underlying problem-solving pattern instead of memorizing individual solutions.

Pattern Typical Applications
Iteration Sum, maximum, minimum and counting.
Hash Map / Frequency Counter Duplicate detection, frequency counting and two-sum.

4. Searching and Position-Based Problems

Problem 5: Find the Second-Largest Distinct Element

Find the second-largest distinct number without sorting the array.

Input: [10, 50, 20, 50, 40]

Expected Output: 40

function secondLargest(numbers) {
    let largest = -Infinity;
    let second = -Infinity;

    for (const number of numbers) {
        if (number > largest) {
            second = largest;
            largest = number;
        } else if (
            number < largest &&
            number > second
        ) {
            second = number;
        }
    }

    return second === -Infinity ? undefined : second;
}

console.log(secondLargest([10, 50, 20, 50, 40]));
Output: 
40

Time Complexity: O(n)

Space Complexity: O(1)

This solution finds the second-largest distinct value. It returns undefined if no second distinct value exists.

5. Duplicate and Frequency Problems

Problem 9: Remove Duplicate Elements

Input: [1, 2, 2, 3, 4, 4, 5]

Expected Output: [1, 2, 3, 4, 5]

function removeDuplicates(numbers) {
    return [...new Set(numbers)];
}

console.log(
    removeDuplicates([1, 2, 2, 3, 4, 4, 5])
);
Output: 
[1, 2, 3, 4, 5]

Time Complexity: O(n) average-case processing.

Space Complexity: O(n)

Alternative Without Set

function removeDuplicates(numbers) {
    const result = [];

    for (const number of numbers) {
        if (!result.includes(number)) {
            result.push(number);
        }
    }

    return result;
}

console.log(
    removeDuplicates([1, 2, 2, 3, 4, 4, 5])
);

This alternative can take O(n²) time because includes() performs a linear search for each element.

Problem 10: Find Duplicate Elements

Input: [1, 2, 3, 2, 4, 1, 5]

Expected Output: [2, 1]

function findDuplicates(numbers) {
    const seen = new Set();
    const duplicates = new Set();

    for (const number of numbers) {
        if (seen.has(number)) {
            duplicates.add(number);
        } else {
            seen.add(number);
        }
    }

    return [...duplicates];
}

console.log(
    findDuplicates([1, 2, 3, 2, 4, 1, 5])
);
Output: 
[2, 1]

Space Complexity: O(n)

function countFrequency(items) {
    const frequency = {};

    for (const item of items) {
        frequency[item] = (frequency[item] || 0) + 1;
    }

    return frequency;
}

const items = ["a", "b", "a", "c", "b", "a"];

console.log(countFrequency(items));
Output: 
{ a: 3, b: 2, c: 1 }

Time Complexity: O(n) average case.

Space Complexity: O(k), where k is the number of distinct values.

function firstNonRepeating(numbers) {

6. Two-Pointer Coding Problems

The two-pointer technique uses two indexes to process an array efficiently. The pointers may move toward each other or in the same direction.

Problem 13: Reverse an Array Without Using reverse()

Input: [1, 2, 3, 4, 5]

Expected Output: [5, 4, 3, 2, 1]

function reverseArray(numbers) {
    let left = 0;
    let right = numbers.length - 1;

    while (left < right) {
        const temp = numbers[left];

        numbers[left] = numbers[right];
        numbers[right] = temp;

        left++;
        right--;
    }

    return numbers;
}

console.log(reverseArray([1, 2, 3, 4, 5]));
Output: 
[5, 4, 3, 2, 1]

Time Complexity: O(n)

Space Complexity: O(1)

This solution modifies the original array.

Problem 14: Find a Pair with a Given Sum in a Sorted Array

Input: Array [1, 2, 4, 6, 8, 9], target 10

Expected Output: [2, 8]

function findPair(numbers, target) {
    let left = 0;
    let right = numbers.length - 1;

    while (left < right) {
        const sum = numbers[left] + numbers[right];

        if (sum === target) {
            return [numbers[left], numbers[right]];
        }

        if (sum < target) {
            left++;
        } else {
            right--;
        }
    }

    return null;
}

console.log(
    findPair([1, 2, 4, 6, 8, 9], 10)
);
Output: 
[2, 8]

Time Complexity: O(n)

Space Complexity: O(1), excluding the returned pair.

The input array must be sorted for this two-pointer approach to work correctly.

Problem 15: Move All Zeros to the End

Input: [0, 1, 0, 3, 12]

Expected Output: [1, 3, 12, 0, 0]

function moveZeros(numbers) {
    let position = 0;

    for (let i = 0; i < numbers.length; i++) {
        if (numbers[i] !== 0) {
            numbers[position] = numbers[i];
            position++;
        }
    }

    while (position < numbers.length) {
        numbers[position] = 0;
        position++;
    }

    return numbers;
}

console.log(moveZeros([0, 1, 0, 3, 12]));
Output: 
[1, 3, 12, 0, 0]

Time Complexity: O(n)

Space Complexity: O(1)

Problem 16: Merge Two Sorted Arrays

Input: [1, 3, 5] and [2, 4, 6]

Expected Output: [1, 2, 3, 4, 5, 6]

function mergeSortedArrays(a, b) {
    let i = 0;
    let j = 0;

    const result = [];

    while (i < a.length && j < b.length) {
        if (a[i] <= b[j]) {
            result.push(a[i]);
            i++;
        } else {
            result.push(b[j]);
            j++;
        }
    }

    while (i < a.length) {
        result.push(a[i]);
        i++;
    }

    while (j < b.length) {
        result.push(b[j]);
        j++;
    }

    return result;
}

console.log(
    mergeSortedArrays([1, 3, 5], [2, 4, 6])
);
Output: 
[1, 2, 3, 4, 5, 6]

Time Complexity: O(n + m)

Space Complexity: O(n + m)

7. Subarray and Sliding Window Problems

A subarray is a contiguous portion of an array. Sliding-window techniques help solve certain subarray problems without repeatedly processing the same elements.

Problem 17: Find the Maximum Sum of a Subarray of Size K

Input: Array [2, 1, 5, 1, 3, 2], k = 3

Expected Output: 9

function maxWindowSum(numbers, k) {
    if (k <= 0 || k > numbers.length) {
        return undefined;
    }

    let windowSum = 0;

    for (let i = 0; i < k; i++) {
        windowSum += numbers[i];
    }

    let maximum = windowSum;

    for (let i = k; i < numbers.length; i++) {
        windowSum += numbers[i];
        windowSum -= numbers[i - k];

        maximum = Math.max(maximum, windowSum);
    }

    return maximum;
}

console.log(
    maxWindowSum([2, 1, 5, 1, 3, 2], 3)
);
Output: 
9

The subarray [5, 1, 3] has the maximum sum of 9.

Time Complexity: O(n)

Space Complexity: O(1)

Problem 18: Find the Maximum Sum of a Contiguous Subarray

This is the classic maximum subarray problem, commonly solved using Kadane's algorithm.

Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4]

Expected Output: 6

function maxSubarraySum(numbers) {
    if (numbers.length === 0) {
        return undefined;
    }

    let currentSum = numbers[0];
    let maximumSum = numbers[0];

    for (let i = 1; i < numbers.length; i++) {
        currentSum = Math.max(
            numbers[i],
            currentSum + numbers[i]
        );

        maximumSum = Math.max(
            maximumSum,
            currentSum
        );
    }

    return maximumSum;
}

console.log(
    maxSubarraySum([-2, 1, -3, 4, -1, 2, 1, -5, 4])
);
Output: 
6

The maximum-sum subarray is [4, -1, 2, 1].

Time Complexity: O(n)

Space Complexity: O(1)

8. Missing Number and Mathematical Problems

Problem 19: Find the Missing Number from 1 to N

An array contains distinct numbers from 1 to N, with exactly one number missing.

Input: Array [1, 2, 4, 5, 6], N = 6

Expected Output: 3

function findMissingNumber(numbers, n) {
    const expectedSum = n * (n + 1) / 2;

    const actualSum = numbers.reduce((sum, value) => {
        return sum + value;
    }, 0);

    return expectedSum - actualSum;
}

console.log(
    findMissingNumber([1, 2, 4, 5, 6], 6)
);
Output: 
3

Time Complexity: O(n)

Space Complexity: O(1) auxiliary space.

This solution assumes the input contains distinct integers from 1 through N, with exactly one missing.

function findAllMissing(numbers, n) {

Problem 26: Calculate the Sum of Both Diagonals

For a square matrix, calculate the sum of the main diagonal and secondary diagonal. The center element is counted only once. 

function diagonalSum(matrix) {
    const n = matrix.length;
    let sum = 0;

    for (let i = 0; i < n; i++) {
        sum += matrix[i][i];

        if (i !== n - 1 - i) {
            sum += matrix[i][n - 1 - i];
        }
    }

    return sum;
}

const matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

console.log(diagonalSum(matrix));
Output: 
25

Time Complexity: O(n)

Space Complexity: O(1)

Main diagonal: 1 + 5 + 9 = 15. Secondary diagonal: 3 + 5 + 7 = 15. Subtract the duplicated center value 5: total = 25.

Problem 27: Rotate a Square Matrix by 90 Degrees Clockwise

function rotateMatrix(matrix) {
    const n = matrix.length;

    // Transpose the matrix.
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            const temp = matrix[i][j];

            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }

    // Reverse each row.
    for (const row of matrix) {
        row.reverse();
    }

    return matrix;
}

const matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

console.log(rotateMatrix(matrix));
Output: 
[
    [7, 4, 1],
    [8, 5, 2],
    [9, 6, 3]
]

Time Complexity: O(n²)

Space Complexity: O(1) auxiliary space.

This implementation assumes a square matrix and modifies the original matrix.

12. Time and Space Complexity Reference

Understanding complexity is important in coding interviews. It helps you compare alternative solutions and identify inefficient approaches.

Operation / Technique Typical Time Complexity
Access by index O(1)
Linear search O(n)
Find maximum or minimum O(n)
Array traversal O(n)
Frequency counting using Map O(n) average case
Set-based duplicate removal O(n) average case
Two-pointer traversal O(n)
Sliding window O(n)
Binary search on sorted array O(log n)
Comparison-based sorting Typically O(n log n) in modern implementations; ECMAScript does not mandate a complexity.
Matrix traversal O(r × c)
Complexity depends on the implementation and input assumptions. Average-case Map and Set operations are generally treated as constant-time lookups in interview analysis.

);

console.log(grouped.IT);
console.log(grouped.HR);

Compatibility: Object.groupBy() is a modern JavaScript method. For environments without support, implement grouping with reduce() or a Map.

15. Common Coding Round Mistakes

Mistake Correct Approach
Ignoring empty arrays. Define what the function should return for empty input.
Using == instead of === without considering coercion. Prefer strict equality when comparing values.
Sorting numbers without a comparator. Use a numerical comparison function.
Modifying the input unexpectedly. Use a copy when the original array must remain unchanged.
Using nested loops unnecessarily. Consider Map, Set, two pointers or sliding windows.
Forgetting duplicate values. Clarify whether the problem asks for distinct values or occurrences.
Ignoring negative numbers. Test with negative values, zero and positive values.
Assuming an array is sorted. Check the problem constraints before applying binary search or two pointers.
Returning the wrong data type. Match the exact expected output: number, array, object or boolean.
Not testing boundary cases. Test empty arrays, one element, duplicates and all-negative input.
