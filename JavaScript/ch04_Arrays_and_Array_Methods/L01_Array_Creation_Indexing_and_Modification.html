Chapter 4: Arrays and Array Methods

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand arrays and their role in JavaScript.
  • Create arrays using array literals and constructors.
  • Access array elements using zero-based indexing.
  • Find the number of elements using the length property.
  • Read and modify individual array elements.
  • Understand array references and the behavior of const arrays.
  • Identify arrays using Array.isArray().

2. What Is an Array?

An array is an ordered collection of values stored in a single variable. Instead of creating separate variables for related values, we can group them together in an array.

Without an Array

let student1 = "Amit";
let student2 = "Rahul";
let student3 = "Priya";
let student4 = "Neha";

Using an Array

let students = ["Amit", "Rahul", "Priya", "Neha"];

console.log(students);
Expected Output: 
["Amit", "Rahul", "Priya", "Neha"]

The array stores all four student names under one variable. Each value occupies a position identified by an index.

Important Characteristics

  • Array elements are ordered.
  • Array indexing starts from zero.
  • JavaScript arrays can contain different data types.
  • Arrays are dynamic and can grow or shrink.
  • Array elements can be accessed and modified individually.
  • JavaScript arrays are objects.
Placement Concept: JavaScript arrays are objects with special behavior for indexed properties and the length property. They are not fixed-size arrays like those commonly encountered in C.

3. Creating Arrays

3.1 Array Literal Syntax

The array literal is the most common and recommended way to create an array in JavaScript. 

let numbers = [10, 20, 30, 40];

let names = ["Amit", "Rahul", "Priya"];

let mixed = [10, "JavaScript", true, null];

console.log(numbers);
console.log(names);
console.log(mixed);
Expected Output: 
[10, 20, 30, 40]
["Amit", "Rahul", "Priya"]
[10, "JavaScript", true, null]

The values are separated by commas and enclosed in square brackets.

3.2 Using the Array Constructor

JavaScript also provides the Array() constructor to create arrays. 

let numbers = new Array(10, 20, 30);

console.log(numbers);
Expected Output: 
[10, 20, 30]

However, the constructor behaves differently when it receives exactly one numeric argument. 

let arr1 = new Array(5);
let arr2 = new Array("JavaScript");

console.log(arr1.length);
console.log(arr2);
Expected Output: 
5
["JavaScript"]

new Array(5) creates an array with length 5 containing empty slots. It does not create an array containing the number 5.

Common Interview Trap: new Array(5) and [5] are not equivalent. The first creates an array with five empty slots; the second creates an array with one element whose value is 5.

3.3 Using Array.of()

Array.of() creates an array using the supplied arguments as its elements. 

let numbers = Array.of(5);

console.log(numbers);
console.log(numbers.length);
Expected Output: 
[5]
1

Unlike new Array(5), Array.of(5) creates an array containing one element.

4. Array Indexing

Every array element has an index. JavaScript uses zero-based indexing, meaning the first element is stored at index 0. 

let languages = ["C", "C++", "JavaScript", "Python"];
Index Element
0 C
1 C++
2 JavaScript
3 Python

Accessing Elements

let languages = ["C", "C++", "JavaScript", "Python"];

console.log(languages[0]);
console.log(languages[1]);
console.log(languages[2]);
console.log(languages[3]);
Expected Output: 
C
C++
JavaScript
Python

Accessing the Last Element

The last element can be accessed using array[array.length - 1]. 

let marks = [75, 82, 90, 88, 95];

console.log(marks[marks.length - 1]);
Expected Output: 
95

Accessing an Invalid Index

let numbers = [10, 20, 30];

console.log(numbers[5]);
Expected Output: 
undefined

Reading an index that does not contain an element normally returns undefined. It does not automatically produce an error.

5. The length Property

The length property returns the array's length. For an ordinary dense array, this is the number of elements. 

let subjects = ["C", "C++", "JavaScript", "Linux"];

console.log(subjects.length);
Expected Output: 
4

Using length to Access the Last Element

let fruits = ["Apple", "Mango", "Orange"];

let lastFruit = fruits[fruits.length - 1];

console.log(lastFruit);
Expected Output: 
Orange

Changing the length Property

The length property is writable. Increasing it creates empty slots at the end, while decreasing it removes elements beyond the new length. 

let numbers = [10, 20, 30];

numbers.length = 5;

console.log(numbers.length);
console.log(numbers[3]);

numbers.length = 2;

console.log(numbers);
Expected Output: 
5
undefined
[10, 20]
Reducing an array's length permanently removes the elements beyond the new length. Increasing it does not fill the new positions with actual values.

6. Modifying Array Elements

Array elements can be modified by assigning a new value to an existing index.

6.1 Updating an Existing Element

let colors = ["Red", "Green", "Blue"];

colors[1] = "Yellow";

console.log(colors);
Expected Output: 
["Red", "Yellow", "Blue"]

6.2 Adding an Element at the Next Index

Assigning a value at the current length adds an element at the end of the array. 

let numbers = [10, 20, 30];

numbers[numbers.length] = 40;

console.log(numbers);
Expected Output: 
[10, 20, 30, 40]

Dedicated methods such as push() and unshift() are covered in Lesson 3.

6.3 Assigning a Value Beyond the Current Length

let numbers = [10, 20, 30];

numbers[5] = 60;

console.log(numbers);
console.log(numbers.length);
console.log(numbers[3]);
Expected Output: 
[10, 20, 30, empty × 2, 60]
6
undefined

The assignment creates empty slots at indexes 3 and 4. This is called a sparse array.

An empty slot is not the same as an explicitly stored undefined value. This distinction can affect array methods and iteration.

7. JavaScript Arrays and Data Types

JavaScript arrays can contain values of different data types. However, using a consistent data type is often easier to maintain in real applications. 

let employee = [
    101,
    "Rahul",
    35000,
    true,
    null
];

console.log(employee[0]);
console.log(employee[1]);
console.log(employee[2]);
console.log(employee[3]);
console.log(employee[4]);
Expected Output: 
101
Rahul
35000
true
null

Checking Whether a Value Is an Array

The typeof operator returns "object" for arrays. 

let numbers = [10, 20, 30];

console.log(typeof numbers);
console.log(Array.isArray(numbers));
console.log(Array.isArray({ name: "Rahul" }));
Expected Output: 
object
true
false
Interview Rule: Use Array.isArray(value) when you need to determine whether a value is an array. Do not rely on typeof value === "object".

8. const Arrays and Mutability

An array declared with const cannot be reassigned to another array. However, its elements can still be modified. 

const fruits = ["Apple", "Mango", "Orange"];

fruits[1] = "Banana";

console.log(fruits);
Expected Output: 
["Apple", "Banana", "Orange"]

Reassigning a const Array

const numbers = [10, 20, 30];

numbers = [40, 50, 60];
Result: A TypeError occurs because a variable declared with const cannot be reassigned.

Understanding the Difference

Operation Allowed?
Read an array element Yes
Modify an existing element Yes
Add an element by assigning an index Yes
Reassign the const variable No

Array Reference Behavior

Arrays are objects. When an array is assigned to another variable, the new variable refers to the same array object. 

let first = [10, 20, 30];

let second = first;

second[0] = 100;

console.log(first);
console.log(second);
Expected Output: 
[100, 20, 30]
[100, 20, 30]

Both variables refer to the same array. Therefore, modifying the array through either variable is visible through the other.

9. Practical Frontend Example

Arrays are frequently used to store product names, menu items, employee records, course lists and other application data.

Example: Managing a Course List

const courses = [
    "C Programming",
    "C++ Programming",
    "JavaScript",
    "Linux"
];

// Access individual courses
console.log("First Course:", courses[0]);

// Update a course
courses[2] = "JavaScript Programming";

// Add a course at the next index
courses[courses.length] = "React.js";

// Display the updated array
console.log("Updated Courses:", courses);

// Display total number of courses
console.log("Total Courses:", courses.length);
Expected Output: 
First Course: C Programming
Updated Courses: [
  "C Programming",
  "C++ Programming",
  "JavaScript Programming",
  "Linux",
  "React.js"
]
Total Courses: 5

This is a basic example of how frontend applications maintain and update collections of data.

10. Common Mistakes and Debugging

Mistake Correct Understanding
Accessing the first element using arr[1] Use arr[0].
Assuming arr[5] always causes an error An absent index normally returns undefined.
Assuming new Array(5) creates [5] It creates an array with five empty slots.
Assuming const makes array elements immutable const prevents reassignment, not element modification.
Using typeof to identify arrays Use Array.isArray().
Assuming an array copy is created by simple assignment Simple assignment copies the reference, not the array.

Debugging Example

let marks = [70, 80, 90];

console.log(marks[3]);

The result is undefined, because valid indexes are 0, 1 and 2. The array length is 3, but its last index is 2.

11. Placement Interview Questions

Q1. What is an array in JavaScript?

An array is an ordered collection of values stored in a single variable. Its elements are accessed using zero-based indexes.

Q2. What is the index of the first element?

The first element has index 0 because JavaScript uses zero-based indexing.

Q3. What is the output of this code? 
let arr = [10, 20, 30];

console.log(arr[3]);

Answer: undefined, because index 3 does not contain an element.

Q4. What is the difference between [5] and new Array(5)?

[5] creates an array with one element containing 5. new Array(5) creates an array with five empty slots.

Q5. What is the output? 
let arr = [10, 20, 30];

console.log(arr.length);

Answer: 3.

Q6. How can you access the last element of an array?

Use arr[arr.length - 1].

Q7. What does typeof [] return?

It returns "object". Use Array.isArray() to check whether a value is an array.

Q8. Can a const array be modified?

Yes. Its elements can be modified, but the variable cannot be reassigned to another array.

Q9. What happens when an element is assigned beyond the current array length?

The array length increases to include the assigned index. Any skipped indexes become empty slots.

Q10. What happens when one array is assigned to another variable?

Both variables refer to the same array object. It does not create an independent copy.

13. Lesson Summary

  • An array stores multiple values in an ordered collection.
  • JavaScript arrays use zero-based indexing.
  • Array literals are the preferred way to create arrays.
  • The length property gives the array length.
  • Array elements can be read and modified using indexes.
  • Assigning beyond the current length can create empty slots.
  • Array.isArray() checks whether a value is an array.
  • const prevents reassignment but does not make array elements immutable.
  • Assigning an array to another variable copies its reference.
