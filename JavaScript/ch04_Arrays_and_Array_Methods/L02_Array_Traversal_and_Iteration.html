2. What Is Array Traversal?

Array traversal is the process of accessing or processing array elements one by one.

For example, consider an array containing student marks: 

let marks = [75, 80, 92, 68, 85];

Traversal allows us to perform operations such as:

  • Display every element.
  • Calculate the sum or average of marks.
  • Count students who passed an examination.
  • Find the highest or lowest value.
  • Search for a particular value.
Traversal is a fundamental programming technique used in frontend applications, coding rounds, data processing and algorithm implementation.

3. Traversal Using the for Loop

A traditional for loop is one of the most useful ways to traverse an array. It provides direct access to the current index and allows us to control the iteration.

Syntax

for (initialization; condition; update) {
    // Statements
}

Example 1: Display All Array Elements

let fruits = ["Apple", "Mango", "Orange", "Banana"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
Expected Output: 
Apple
Mango
Orange
Banana

How the Loop Works

  1. let i = 0 initializes the index.
  2. i < fruits.length checks whether the index is valid.
  3. fruits[i] accesses the current element.
  4. i++ moves to the next index.
  5. The loop stops when the condition becomes false.

Example 2: Display Index and Value

let languages = ["C", "C++", "JavaScript"];

for (let i = 0; i < languages.length; i++) {
    console.log("Index:", i, "Value:", languages[i]);
}
Expected Output: 
Index: 0 Value: C
Index: 1 Value: C++
Index: 2 Value: JavaScript

Example 3: Calculate the Sum of Array Elements

let numbers = [10, 20, 30, 40, 50];

let sum = 0;

for (let i = 0; i < numbers.length; i++) {
    sum = sum + numbers[i];
}

console.log("Sum:", sum);
Expected Output: 
Sum: 150

Example 4: Find the Largest Number

let numbers = [45, 12, 89, 34, 67];

let largest = numbers[0];

for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
        largest = numbers[i];
    }
}

console.log("Largest:", largest);
Expected Output: 
Largest: 89

Initializing largest with the first array element is more reliable than assuming the largest value is positive or initializing it with zero.

4. Traversal Using the while Loop

A while loop repeatedly executes a block of code as long as its condition is true. It can also be used for array traversal.

Syntax

initialization;

while (condition) {
    // Statements
    update;
}

Example 1: Display Array Elements

let numbers = [10, 20, 30, 40];

let i = 0;

while (i < numbers.length) {
    console.log(numbers[i]);
    i++;
}
Expected Output: 
10
20
30
40

Example 2: Calculate the Sum

let marks = [70, 80, 90, 60];

let i = 0;
let sum = 0;

while (i < marks.length) {
    sum += marks[i];
    i++;
}

console.log("Total Marks:", sum);
Expected Output: 
Total Marks: 300
Remember to update the loop variable. If the condition never becomes false, the program can enter an infinite loop.

5. Traversal Using the for...of Loop

The for...of loop provides a convenient way to access values from an iterable object, such as an array.

Syntax

for (let value of array) {
    // Statements
}

Example 1: Display Array Values

let colors = ["Red", "Green", "Blue"];

for (let color of colors) {
    console.log(color);
}
Expected Output: 
Red
Green
Blue

In each iteration, the loop variable receives the next value from the array.

Example 2: Calculate the Total

let prices = [100, 250, 150, 300];

let total = 0;

for (let price of prices) {
    total += price;
}

console.log("Total Price:", total);
Expected Output: 
Total Price: 800

Example 3: Find Even Numbers

let numbers = [11, 20, 35, 42, 50];

for (let number of numbers) {
    if (number % 2 === 0) {
        console.log(number);
    }
}
Expected Output: 
20
42
50
Important: for...of gives you values directly, not indexes. If you need the index, use a traditional for loop or another appropriate technique.

6. Traversal Using forEach()

The forEach() method executes a callback function once for each element in an array.

Syntax

array.forEach(function(element, index, array) {
    // Statements
});

The callback receives three possible arguments:

Argument Description
element The current array element.
index The index of the current element.
array The array on which forEach() was called.

Example 1: Basic forEach()

let fruits = ["Apple", "Mango", "Orange"];

fruits.forEach(function(fruit) {
    console.log(fruit);
});
Expected Output: 
Apple
Mango
Orange

Example 2: Using the Index

let subjects = ["C", "C++", "JavaScript"];

subjects.forEach(function(subject, index) {
    console.log(index, subject);
});
Expected Output: 
0 C
1 C++
2 JavaScript

Example 3: Using an Arrow Function

let numbers = [10, 20, 30, 40];

numbers.forEach((number) => {
    console.log(number * 2);
});
Expected Output: 
20
40
60
80

Example 4: Using All Three Callback Arguments

let names = ["Amit", "Rahul", "Neha"];

names.forEach((name, index, array) => {
    console.log("Name:", name);
    console.log("Index:", index);
    console.log("Array Length:", array.length);
});

This example demonstrates how the callback receives the current value, its index and the original array.

Important Interview Point: forEach() does not return a new array. Its return value is always undefined. It is not designed to stop early using break or continue.

7. Comparing Array Iteration Techniques

Technique Accesses Can break? Typical Use
for Index and value Yes Index-based processing and full control.
while Depends on implementation Yes Condition-controlled traversal.
for...of Value Yes Simple iteration over values.
forEach() Value, index and array No Executing a callback for every element.

Which One Should You Use?

  • Use for when you need index control or early termination.
  • Use while when iteration depends on a condition.
  • Use for...of when you mainly need array values.
  • Use forEach() when you want to execute an operation for every element.

These techniques are not interchangeable in every situation. Choose based on the requirements of the operation.

8. Important Concepts: break and continue

The break and continue statements are useful when traversing arrays with traditional loops.

8.1 break Statement

The break statement immediately terminates the current loop. 

let numbers = [10, 20, 30, 40, 50];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] === 30) {
        break;
    }

    console.log(numbers[i]);
}
Expected Output: 
10
20

8.2 continue Statement

The continue statement skips the current iteration and moves to the next one. 

let numbers = [10, 20, 30, 40, 50];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] === 30) {
        continue;
    }

    console.log(numbers[i]);
}
Expected Output: 
10
20
40
50
Both break and continue can be used inside ordinary loops and for...of loops. They cannot be used to control the outer loop from inside a forEach() callback.

9. Traversing Sparse Arrays

A sparse array contains empty slots between its indexed elements. Different iteration techniques can handle these slots differently.

Example

let numbers = [10, 20, 30];

numbers[5] = 60;

console.log(numbers.length);
Expected Output: 
6

Using a Traditional for Loop

for (let i = 0; i < numbers.length; i++) {
    console.log(i, numbers[i]);
}

The loop visits every index from 0 through 5. Reading the empty slots produces undefined.

Using forEach()

numbers.forEach((value, index) => {
    console.log(index, value);
});

forEach() skips empty slots. It visits only indexes that actually have assigned elements.

Do not assume that every array iteration method handles sparse arrays identically. This distinction can matter when debugging unexpected results.

10. Practical Frontend Example

Displaying a Course List

A frontend application may store course names in an array and display them in a list. 

const courses = [
    "C Programming",
    "C++ Programming",
    "JavaScript",
    "Linux",
    "React.js"
];

const courseList = document.getElementById("courseList");

courses.forEach((course) => {
    const listItem = document.createElement("li");
    listItem.textContent = course;
    courseList.appendChild(listItem);
});

Use this complete HTML page to test the example:

11. Common Mistakes and Debugging

Mistake Correct Understanding
Using i <= arr.length Normally use i < arr.length to avoid an extra invalid index.
Forgetting to increment the index in a while loop Update the index to avoid an infinite loop.
Expecting for...of to provide indexes It provides values directly.
Trying to use break inside forEach() Use a traditional loop or for...of when early termination is needed.
Expecting forEach() to return a new array Its return value is undefined.
Ignoring empty slots in sparse arrays Understand how the selected iteration technique handles them.

12. Placement Interview Questions

Q1. What is array traversal?

Array traversal means accessing or processing array elements one by one.

Q2. Which loop is suitable when you need array indexes?

A traditional for loop provides direct control over array indexes.

Q3. What is the difference between for...of and forEach()?

for...of iterates over values and supports break. forEach() executes a callback for each present element and does not support early termination using break.

Q4. What does forEach() return?

It returns undefined, regardless of the values returned by its callback.

Q5. Can we use break inside forEach()?

No. A break statement cannot terminate the outer loop from inside the callback.

Q6. What is the purpose of continue?

It skips the remaining statements in the current iteration and proceeds to the next iteration.

Q7. What is the difference between an array value and its index?

The index represents the position of an element, while the value is the data stored at that position.

Q8. Does forEach() visit empty slots in sparse arrays?

No. It skips empty slots and calls the callback for present elements.

Q9. Which loop should you use if you need to stop when a condition is met?

Use a traditional for loop or for...of loop with break.

Q10. What is the time complexity of traversing an array of n elements?

A complete traversal takes O(n) time because each element is processed once.

14. Lesson Summary

  • Array traversal processes elements one by one.
  • A traditional for loop provides index control.
  • A while loop supports condition-controlled traversal.
  • for...of provides direct access to values.
  • forEach() executes a callback for each present element.
  • break terminates a supported loop.
  • continue skips the current iteration.
  • forEach() returns undefined and cannot be stopped using break.
  • Complete array traversal generally has O(n) time complexity.
