Chapter 4: Arrays and Array Methods

1. Learning Objectives

After completing this lesson, you will be able to:

  • Add elements at the beginning and end of an array.
  • Remove elements from the beginning and end of an array.
  • Insert and remove elements at specific positions.
  • Use the push(), pop(), shift(), unshift() and splice() methods.
  • Understand the return values of these methods.
  • Identify which methods modify the original array.
  • Apply array modification methods in practical frontend tasks.

2. Overview of Array Modification Methods

JavaScript provides built-in array methods for adding and removing elements. These methods are commonly used when managing dynamic collections of data.

Method Operation Position
push() Adds elements End
pop() Removes one element End
unshift() Adds elements Beginning
shift() Removes one element Beginning
splice() Adds, removes or replaces elements Any index
Important: All five methods modify the original array. They are known as mutating array methods.

3. push() Method

The push() method adds one or more elements to the end of an array.

Syntax

array.push(element1, element2, ...);

Example 1: Adding One Element

let fruits = ["Apple", "Mango"];

fruits.push("Orange");

console.log(fruits);
Expected Output: 
["Apple", "Mango", "Orange"]

Example 2: Adding Multiple Elements

let numbers = [10, 20, 30];

numbers.push(40, 50, 60);

console.log(numbers);
Expected Output: 
[10, 20, 30, 40, 50, 60]

Example 3: Understanding the Return Value

The push() method returns the new length of the array. 

let numbers = [10, 20, 30];

let result = numbers.push(40);

console.log(result);
console.log(numbers);
Expected Output: 
4
[10, 20, 30, 40]
Remember: push() returns the new array length, not the inserted element or the modified array.

4. pop() Method

The pop() method removes the last element from an array.

Syntax

array.pop();

Example 1: Removing the Last Element

let fruits = ["Apple", "Mango", "Orange"];

fruits.pop();

console.log(fruits);
Expected Output: 
["Apple", "Mango"]

Example 2: Getting the Removed Element

let numbers = [10, 20, 30, 40];

let removed = numbers.pop();

console.log("Removed:", removed);
console.log("Updated Array:", numbers);
Expected Output: 
Removed: 40
Updated Array: [10, 20, 30]

Example 3: Popping from an Empty Array

let numbers = [];

let result = numbers.pop();

console.log(result);
console.log(numbers.length);
Expected Output: 
undefined
0

Calling pop() on an empty array does not throw an error. It returns undefined.

5. unshift() Method

The unshift() method adds one or more elements at the beginning of an array.

Syntax

array.unshift(element1, element2, ...);

Example 1: Adding One Element

let numbers = [20, 30, 40];

numbers.unshift(10);

console.log(numbers);
Expected Output: 
[10, 20, 30, 40]

Example 2: Adding Multiple Elements

let fruits = ["Orange", "Banana"];

fruits.unshift("Apple", "Mango");

console.log(fruits);
Expected Output: 
["Apple", "Mango", "Orange", "Banana"]

Example 3: Understanding the Return Value

let numbers = [20, 30];

let result = numbers.unshift(10);

console.log(result);
console.log(numbers);
Expected Output: 
3
[10, 20, 30]

Like push(), unshift() returns the new length of the array.

6. shift() Method

The shift() method removes the first element from an array.

Syntax

array.shift();

Example 1: Removing the First Element

let fruits = ["Apple", "Mango", "Orange"];

fruits.shift();

console.log(fruits);
Expected Output: 
["Mango", "Orange"]

Example 2: Getting the Removed Element

let numbers = [10, 20, 30, 40];

let removed = numbers.shift();

console.log("Removed:", removed);
console.log("Updated Array:", numbers);
Expected Output: 
Removed: 10
Updated Array: [20, 30, 40]

Example 3: Shifting an Empty Array

let items = [];

let result = items.shift();

console.log(result);
Expected Output: 
undefined

7. splice() Method

The splice() method can remove, insert or replace elements at any position in an array.

It is one of the most important array modification methods for JavaScript coding interviews.

Syntax

array.splice(start, deleteCount, item1, item2, ...);
Parameter Description
start Index at which modification begins. Negative indexes count from the end.
deleteCount Number of elements to remove. If omitted, all elements from start onward are removed.
item1, item2, ... Optional elements inserted at the start position.

7.1 Removing Elements

To remove elements, specify the starting index and the number of elements to delete. 

let fruits = ["Apple", "Mango", "Orange", "Banana"];

let removed = fruits.splice(1, 2);

console.log("Removed:", removed);
console.log("Updated:", fruits);
Expected Output: 
Removed: ["Mango", "Orange"]
Updated: ["Apple", "Banana"]

Starting from index 1, two elements are removed.

7.2 Inserting Elements Without Removing Existing Elements

Specify a delete count of zero to insert elements without removing any existing elements. 

let fruits = ["Apple", "Orange"];

fruits.splice(1, 0, "Mango", "Banana");

console.log(fruits);
Expected Output: 
["Apple", "Mango", "Banana", "Orange"]

7.3 Replacing Elements

Specify the number of elements to remove and provide replacement values. 

let languages = ["C", "C++", "Java", "Python"];

languages.splice(2, 1, "JavaScript");

console.log(languages);
Expected Output: 
["C", "C++", "JavaScript", "Python"]

7.4 Removing All Elements from a Position

When deleteCount is omitted, all elements from the starting index to the end are removed. 

let numbers = [10, 20, 30, 40, 50];

numbers.splice(2);

console.log(numbers);
Expected Output: 
[10, 20]

7.5 Using a Negative Starting Index

A negative starting index counts backward from the end of the array. 

let numbers = [10, 20, 30, 40, 50];

numbers.splice(-2, 1);

console.log(numbers);
Expected Output: 
[10, 20, 30, 50]

7.6 Understanding the Return Value

The splice() method returns a new array containing the elements that were removed. 

let numbers = [10, 20, 30, 40];

let removed = numbers.splice(1, 2);

console.log(removed);
console.log(numbers);
Expected Output: 
[20, 30]
[10, 40]
If no elements are removed, splice() returns an empty array. It still modifies the original array if insertion takes place.

8. Difference Between shift(), pop() and splice()

Method Removal Position Return Value
pop() Last element Removed element
shift() First element Removed element
splice() Specified position Array of removed elements

Difference Between push() and unshift()

Method Insertion Position Return Value
push() End New array length
unshift() Beginning New array length

9. Time Complexity of These Methods

Understanding time complexity is important in placement coding rounds and technical interviews.

Method Typical Time Complexity Reason
push() O(1) amortized Usually adds an element at the end. Occasional resizing may take more time.
pop() O(1) Removes an element from the end.
unshift() O(n) Existing indexed elements generally need to be shifted.
shift() O(n) Remaining indexed elements generally need to be shifted.
splice() O(n) in general Elements may need to be shifted to close or open positions.
These are typical complexity estimates for JavaScript array operations, not strict guarantees about every engine implementation.

10. Practical Frontend Example

Managing a Shopping Cart

A shopping cart is a common example of a dynamic array. Products can be added, removed or inserted into the list. 

let cart = ["Laptop", "Mouse", "Keyboard"];

console.log("Initial Cart:", cart);

// Add a product
cart.push("Monitor");

console.log("After Adding:", cart);

// Remove the last product
let removed = cart.pop();

console.log("Removed Product:", removed);
console.log("Current Cart:", cart);

// Add a priority item at the beginning
cart.unshift("Laptop Bag");

console.log("After Unshift:", cart);

// Remove the first item
let firstRemoved = cart.shift();

console.log("Removed First Item:", firstRemoved);
console.log("Final Cart:", cart);
Expected Output: 
Initial Cart: ["Laptop", "Mouse", "Keyboard"]
After Adding: ["Laptop", "Mouse", "Keyboard", "Monitor"]
Removed Product: Monitor
Current Cart: ["Laptop", "Mouse", "Keyboard"]
After Unshift: ["Laptop Bag", "Laptop", "Mouse", "Keyboard"]
Removed First Item: Laptop Bag
Final Cart: ["Laptop", "Mouse", "Keyboard"]

Editing a Course List with splice()

let courses = [
    "C Programming",
    "C++",
    "Java",
    "Linux"
];

// Replace Java with JavaScript
courses.splice(2, 1, "JavaScript");

// Insert React.js at index 3
courses.splice(3, 0, "React.js");

console.log(courses);
Expected Output: 
[
    "C Programming",
    "C++",
    "JavaScript",
    "React.js",
    "Linux"
]

11. Common Mistakes and Debugging

Mistake Correct Understanding
Expecting push() to return the inserted element It returns the new array length.
Expecting pop() to return the updated array It returns the removed element.
Confusing shift() and unshift() shift() removes; unshift() adds at the beginning.
Using the wrong splice() delete count Check the starting index and number of elements to remove.
Assuming splice() returns the updated array It returns an array containing the removed elements.
Forgetting these methods mutate the original array Store a copy first if the original array must remain unchanged.

Important: splice() and delete Are Different

let numbers = [10, 20, 30];

delete numbers[1];

console.log(numbers);
console.log(numbers.length);
Expected Output: 
[10, empty, 30]
3

The delete operator removes the property at that index but does not reduce the array length. It leaves an empty slot.

In contrast: 

let numbers = [10, 20, 30];

numbers.splice(1, 1);

console.log(numbers);
console.log(numbers.length);
Expected Output: 
[10, 30]
2
For ordinary indexed-element removal, prefer splice() over delete when you want the remaining elements to shift and the array length to decrease.

12. Placement Interview Questions

Q1. What is the difference between push() and pop()?

push() adds elements at the end and returns the new length. pop() removes the last element and returns the removed value.

Q2. What is the difference between shift() and unshift()?

shift() removes the first element. unshift() adds elements at the beginning.

Q3. What does splice() do?

It adds, removes or replaces elements at specified positions in the original array.

Q4. What does push() return?

The new length of the array.

Q5. What does pop() return?

The element removed from the end of the array, or undefined if the array is empty.

Q6. What does splice() return?

An array containing the elements removed from the original array.

Q7. Does splice() modify the original array?

Yes. It directly modifies the original array.

Q8. How do you insert an element at index 2 without removing anything?

Use array.splice(2, 0, newElement).

Q9. Which of these methods can have O(n) time complexity?

shift(), unshift() and splice() generally require shifting indexed elements.

Q10. What is the difference between delete and splice()?

delete leaves an empty slot and preserves the array length. splice() removes elements and shifts the remaining elements.

14. Lesson Summary

  • push() adds elements at the end.
  • pop() removes the last element.
  • unshift() adds elements at the beginning.
  • shift() removes the first element.
  • splice() inserts, removes or replaces elements at specific positions.
  • All five methods modify the original array.
  • push() and unshift() return the new array length.
  • pop() and shift() return the removed element.
  • splice() returns an array of removed elements.
  • Beginning and middle modifications generally require shifting indexed elements.
