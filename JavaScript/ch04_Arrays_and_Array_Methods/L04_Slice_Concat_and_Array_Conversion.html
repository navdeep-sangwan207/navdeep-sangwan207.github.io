Chapter 4: Arrays and Array Methods

1. Learning Objectives

After completing this lesson, you will be able to:

  • Extract portions of arrays using slice().
  • Combine multiple arrays using concat().
  • Understand the difference between slice() and splice().
  • Create arrays using Array.from() and Array.of().
  • Convert strings, sets and iterable objects into arrays.
  • Understand shallow copying and reference behavior.
  • Apply array extraction and conversion in frontend development.

2. Understanding slice()

The slice() method extracts a portion of an array and returns it as a new array. It does not modify the original array.

Syntax

array.slice(start, end);
Parameter Description
start Index from which extraction begins. This index is included.
end Index at which extraction stops. This index is excluded.

Example 1: Extracting a Portion

let fruits = ["Apple", "Mango", "Orange", "Banana"];

let result = fruits.slice(1, 3);

console.log(result);
console.log(fruits);
Expected Output: 
["Mango", "Orange"]
["Apple", "Mango", "Orange", "Banana"]

Extraction starts at index 1 and stops before index 3. Therefore, indexes 1 and 2 are included.

Example 2: Omitting the End Parameter

let numbers = [10, 20, 30, 40, 50];

let result = numbers.slice(2);

console.log(result);
Expected Output: 
[30, 40, 50]

When the end parameter is omitted, extraction continues through the end of the array.

Example 3: Copying an Entire Array

let original = [10, 20, 30, 40];

let copied = original.slice();

console.log(copied);

console.log(original === copied);
Expected Output: 
[10, 20, 30, 40]
false

Calling slice() without arguments creates a shallow copy of the array.

Example 4: Using Negative Indexes

Negative indexes count backward from the end of the array. 

let numbers = [10, 20, 30, 40, 50];

console.log(numbers.slice(-3));
console.log(numbers.slice(-4, -1));
Expected Output: 
[30, 40, 50]
[20, 30, 40]

Example 5: Extracting the First Three Elements

let courses = [
    "C",
    "C++",
    "JavaScript",
    "Linux",
    "React"
];

let firstThree = courses.slice(0, 3);

console.log(firstThree);
Expected Output: 
["C", "C++", "JavaScript"]

3. Understanding concat()

The concat() method combines two or more arrays and returns a new array. It does not modify the original arrays.

Syntax

array1.concat(array2, array3, ...);

Example 1: Combining Two Arrays

let frontend = ["HTML", "CSS", "JavaScript"];

let backend = ["Node.js", "Express"];

let fullStack = frontend.concat(backend);

console.log(fullStack);
Expected Output: 
[
    "HTML",
    "CSS",
    "JavaScript",
    "Node.js",
    "Express"
]

Example 2: Combining Multiple Arrays

let group1 = [10, 20];
let group2 = [30, 40];
let group3 = [50, 60];

let result = group1.concat(group2, group3);

console.log(result);
Expected Output: 
[10, 20, 30, 40, 50, 60]

Example 3: Adding Individual Values

let numbers = [10, 20];

let result = numbers.concat(30, 40);

console.log(result);
console.log(numbers);
Expected Output: 
[10, 20, 30, 40]
[10, 20]

Example 4: Combining Arrays Without Modifying Them

let a = [1, 2];
let b = [3, 4];

let c = a.concat(b);

console.log(a);
console.log(b);
console.log(c);
Expected Output: 
[1, 2]
[3, 4]
[1, 2, 3, 4]
Important: concat() creates a new array. It does not automatically remove duplicate values.

4. Difference Between slice() and splice()

These two methods have similar names but perform different operations. This is a frequently tested interview topic.

Feature slice() splice()
Purpose Extracts a portion of an array. Adds, removes or replaces elements.
Modifies original array? No. Yes.
Return value Extracted array. Array of removed elements.
Parameters Start and end. Start, delete count and optional inserted elements.

Comparison Example

let a = [10, 20, 30, 40];

let result1 = a.slice(1, 3);

console.log("Slice Result:", result1);
console.log("Original after slice:", a);

let result2 = a.splice(1, 2);

console.log("Splice Result:", result2);
console.log("Original after splice:", a);
Expected Output: 
Slice Result: [20, 30]
Original after slice: [10, 20, 30, 40]
Splice Result: [20, 30]
Original after splice: [10, 40]
Do not confuse slice(), which extracts without changing the original array, with splice(), which modifies the original array.

5. Understanding Array.from()

The Array.from() method creates a new array from an iterable object or an array-like object.

Syntax

Array.from(arrayLike, mapFunction, thisArg);
Parameter Description
arrayLike An iterable or array-like object to convert.
mapFunction Optional function applied to each element.
thisArg Optional value used as this inside the mapping function.

Example 1: Converting a String into an Array

let text = "HELLO";

let result = Array.from(text);

console.log(result);
Expected Output: 
["H", "E", "L", "L", "O"]

A string is iterable. Array.from() creates an array containing its individual characters.

Example 2: Converting a Set into an Array

let values = new Set([10, 20, 20, 30, 30]);

let result = Array.from(values);

console.log(result);
Expected Output: 
[10, 20, 30]

A Set stores unique values. Converting it to an array preserves its iteration order.

Example 3: Converting an Array-Like Object

An array-like object has a length property and indexed properties, but it does not necessarily have array methods. 

let arrayLike = {
    0: "HTML",
    1: "CSS",
    2: "JavaScript",
    length: 3
};

let result = Array.from(arrayLike);

console.log(result);
Expected Output: 
["HTML", "CSS", "JavaScript"]

Example 4: Using a Mapping Function

Array.from() can transform each element while creating the new array. 

let numbers = [1, 2, 3, 4];

let result = Array.from(numbers, (number) => number * 2);

console.log(result);
Expected Output: 
[2, 4, 6, 8]

Example 5: Creating a Sequence of Numbers

let numbers = Array.from(
    { length: 5 },
    (value, index) => index + 1
);

console.log(numbers);
Expected Output: 
[1, 2, 3, 4, 5]

The array-like object provides a length of five. The mapping function uses each index to generate the corresponding value.

Placement Application: Array.from() is useful when converting DOM collections, strings, sets and array-like data into actual arrays that support array methods.

6. Understanding Array.of()

The Array.of() method creates a new array containing the arguments passed to it.

Syntax

Array.of(element1, element2, ...);

Example 1: Creating an Array

let numbers = Array.of(10, 20, 30);

console.log(numbers);
Expected Output: 
[10, 20, 30]

Example 2: Single Numeric Argument

let a = Array.of(5);
let b = new Array(5);

console.log(a);
console.log(a.length);

console.log(b);
console.log(b.length);
Expected Output: 
[5]
1
[empty × 5]
5

Array.of(5) creates an array containing the number 5. new Array(5) creates an array with five empty slots.

Example 3: Mixed Values

let data = Array.of(
    101,
    "Rahul",
    true,
    null
);

console.log(data);
Expected Output: 
[101, "Rahul", true, null]

7. Array.from() vs Array.of()

Feature Array.from() Array.of()
Purpose Creates an array from an iterable or array-like object. Creates an array from the supplied arguments.
Input Usually one source object and an optional mapping function. Zero or more individual values.
Mapping support Yes, through an optional mapping function. No built-in mapping callback.
Example Array.from("ABC") Array.of(10, 20)
Use Array.from() when converting an existing iterable or array-like source. Use Array.of() when creating an array from individual supplied values.

8. Converting DOM Collections into Arrays

In frontend development, methods such as document.querySelectorAll() return a NodeList. A NodeList is not an Array, although it is iterable and has some array-like behavior.

Example: Converting NodeList into an Array

const items = document.querySelectorAll(".course");

const itemArray = Array.from(items);

console.log(Array.isArray(items));
console.log(Array.isArray(itemArray));
Expected Output: 
false
true

Complete HTML Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>DOM Collection Conversion</title>
</head>
<body>

    <h2>Courses</h2>

    <ul>
        <li class="course">C Programming</li>
        <li class="course">JavaScript</li>
        <li class="course">Linux</li>
    </ul>

    <script>
        const items = document.querySelectorAll(".course");

        const itemArray = Array.from(items);

        itemArray.forEach((item) => {
            console.log(item.textContent);
        });
    </script>

</body>
</html>
Expected Console Output: 
C Programming
JavaScript
Linux

Converting a collection into an array allows us to use the complete range of array methods on its elements.

9. Shallow Copy and Reference Behavior

Both slice() and concat() create new arrays, but they perform shallow copying. This means nested objects are not independently copied.

Example 1: Copying an Array of Primitive Values

let original = [10, 20, 30];

let copied = original.slice();

copied[0] = 100;

console.log(original);
console.log(copied);
Expected Output: 
[10, 20, 30]
[100, 20, 30]

Changing a primitive value in the copied array does not change the corresponding value in the original array.

Example 2: Shallow Copy of Nested Objects

let original = [
    { name: "Amit" },
    { name: "Rahul" }
];

let copied = original.slice();

copied[0].name = "Neha";

console.log(original[0].name);
console.log(copied[0].name);
Expected Output: 
Neha
Neha

Both arrays refer to the same nested object. Therefore, modifying that object through one array is visible through the other.

Interview Concept: slice() and concat() create new outer arrays, not deep copies of nested objects.

10. Practical Frontend Example

Managing Course Categories

const programming = [
    "C Programming",
    "C++",
    "JavaScript"
];

const systems = [
    "Linux",
    "Embedded Systems",
    "RTOS"
];

// Combine categories
const allCourses = programming.concat(systems);

// Extract frontend-related courses
const frontendCourses = allCourses.slice(2, 3);

// Convert a string into an array
const letters = Array.from("HTML");

// Create an array from individual values
const tools = Array.of("VS Code", "Git", "Chrome");

console.log("All Courses:", allCourses);
console.log("Frontend:", frontendCourses);
console.log("Letters:", letters);
console.log("Tools:", tools);
Expected Output: 
All Courses: [
  "C Programming",
  "C++",
  "JavaScript",
  "Linux",
  "Embedded Systems",
  "RTOS"
]

Frontend: ["JavaScript"]

Letters: ["H", "T", "M", "L"]

Tools: ["VS Code", "Git", "Chrome"]

11. Common Mistakes and Debugging

Mistake Correct Understanding
Assuming slice() modifies the original array It returns a new array and leaves the original unchanged.
Including the end index in slice() The end index is excluded.
Confusing slice() and splice() slice() extracts; splice() modifies.
Expecting concat() to remove duplicates concat() combines values without automatically removing duplicates.
Using Array.from() as though it accepts individual values like Array.of() Array.from() converts an iterable or array-like source.
Assuming a shallow copy duplicates nested objects Nested objects remain shared references.
Assuming a NodeList is an Array Use Array.from() when an actual array is needed.

12. Placement Interview Questions

Q1. What is slice() in JavaScript?

slice() extracts a portion of an array and returns it as a new array without modifying the original array.

Q2. Is the end index included in slice()?

No. The start index is included, but the end index is excluded.

Q3. What does slice() return when called without arguments?

It returns a shallow copy of the entire array.

Q4. What is concat() used for?

It combines arrays or additional values and returns a new array without modifying the original arrays.

Q5. Does concat() remove duplicate elements?

No. It combines the supplied values without automatically removing duplicates.

Q6. What is the difference between slice() and splice()?

slice() extracts without modifying the original array. splice() adds, removes or replaces elements in the original array.

Q7. What is Array.from()?

It creates a new array from an iterable or array-like object. It can also apply a mapping function during conversion.

Q8. What is Array.of()?

It creates an array using the supplied arguments as its elements.

Q9. What is the difference between Array.from(5) and Array.of(5)?

Array.from(5) returns an empty array because 5 is neither iterable nor an array-like object with a length. Array.of(5) returns [5].

Q10. What is a shallow copy?

A shallow copy creates a new outer array but retains references to nested objects.

Q11. How do you convert a string into an array of characters?

Use Array.from("HELLO"), which returns an array containing the string's individual Unicode code points.

Q12. Why is Array.from() useful in frontend development?

It converts iterable and array-like collections, such as DOM NodeLists, into actual arrays.
