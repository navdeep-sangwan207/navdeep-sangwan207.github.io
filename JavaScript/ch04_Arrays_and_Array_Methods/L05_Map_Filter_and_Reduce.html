Chapter 4: Arrays and Array Methods

1. Learning Objectives

After completing this lesson, you will be able to:

  • Transform array elements using map().
  • Select elements based on conditions using filter().
  • Calculate a single accumulated result using reduce().
  • Understand callback functions and their parameters in array methods.
  • Chain multiple array methods to process data.
  • Use these methods to solve practical frontend and coding-round problems.
  • Identify common mistakes involving return values and accumulator initialization.

2. Introduction to Higher-Order Array Methods

JavaScript provides built-in array methods that accept callback functions to process array elements. Three particularly important methods are:

  • map() — transforms each element.
  • filter() — selects elements that satisfy a condition.
  • reduce() — combines elements into one accumulated result.

These methods are commonly used in frontend applications to process API responses, display product lists, calculate totals and transform application data.

Basic Comparison

Method Purpose Typical Result
map() Transform every element. New array with the same number of elements.
filter() Select matching elements. New array containing zero or more selected elements.
reduce() Accumulate values. A single accumulated result, which can be any type.

3. Understanding map()

The map() method creates a new array by applying a callback function to every element of the original array.

Syntax

array.map(callback(currentValue, index, array), thisArg);
Parameter Description
currentValue The current element being processed.
index The index of the current element.
array The original array on which map() was called.
thisArg Optional value used as this inside a non-arrow callback.

The callback's index and array parameters are optional. The method returns a new array containing the callback's returned values.

Example 1: Doubling Array Elements

let numbers = [1, 2, 3, 4, 5];

let doubled = numbers.map(function(number) {
    return number * 2;
});

console.log(doubled);
console.log(numbers);
Expected Output: 
[2, 4, 6, 8, 10]
[1, 2, 3, 4, 5]

Each element is multiplied by two. The original array remains unchanged.

Example 2: Using an Arrow Function

let numbers = [10, 20, 30, 40];

let result = numbers.map(number => number + 5);

console.log(result);
Expected Output: 
[15, 25, 35, 45]

Example 3: Converting Values to Uppercase

let names = ["amit", "rahul", "neha"];

let result = names.map(name => name.toUpperCase());

console.log(result);
Expected Output: 
["AMIT", "RAHUL", "NEHA"]

Example 4: Using the Index Parameter

let courses = ["C", "C++", "JavaScript"];

let result = courses.map((course, index) => {
    return `${index + 1}. ${course}`;
});

console.log(result);
Expected Output: 
[
    "1. C",
    "2. C++",
    "3. JavaScript"
]

Example 5: Extracting Object Properties

let students = [
    { id: 1, name: "Amit", marks: 85 },
    { id: 2, name: "Neha", marks: 92 },
    { id: 3, name: "Rahul", marks: 78 }
];

let names = students.map(student => student.name);

console.log(names);
Expected Output: 
["Amit", "Neha", "Rahul"]

Example 6: Transforming API-Like Data

const products = [
    { name: "Keyboard", price: 1200 },
    { name: "Mouse", price: 500 },
    { name: "Monitor", price: 8000 }
];

const productNames = products.map(product => ({
    productName: product.name,
    sellingPrice: product.price
}));

console.log(productNames);
Expected Output: 
[
    { productName: "Keyboard", sellingPrice: 1200 },
    { productName: "Mouse", sellingPrice: 500 },
    { productName: "Monitor", sellingPrice: 8000 }
]
Important: If a callback does not explicitly return a value, the corresponding result in the mapped array will be undefined.

4. Understanding filter()

The filter() method creates a new array containing only those elements for which the callback returns a truthy value.

Syntax

array.filter(callback(currentValue, index, array), thisArg);

Example 1: Filtering Even Numbers

let numbers = [1, 2, 3, 4, 5, 6, 7, 8];

let evenNumbers = numbers.filter(number => {
    return number % 2 === 0;
});

console.log(evenNumbers);
Expected Output: 
[2, 4, 6, 8]

Example 2: Filtering Odd Numbers

let numbers = [10, 11, 12, 13, 14, 15];

let oddNumbers = numbers.filter(number => number % 2 !== 0);

console.log(oddNumbers);
Expected Output: 
[11, 13, 15]

Example 3: Filtering Values Greater Than a Limit

let marks = [35, 45, 67, 80, 90, 28];

let passed = marks.filter(mark => mark >= 40);

console.log(passed);
Expected Output: 
[45, 67, 80, 90]

Example 4: Filtering Objects

let employees = [
    { name: "Amit", salary: 25000 },
    { name: "Neha", salary: 45000 },
    { name: "Rahul", salary: 30000 },
    { name: "Priya", salary: 60000 }
];

let result = employees.filter(employee => {
    return employee.salary >= 40000;
});

console.log(result);
Expected Output: 
[
    { name: "Neha", salary: 45000 },
    { name: "Priya", salary: 60000 }
]

Example 5: Filtering Strings by Length

let languages = [
    "C",
    "C++",
    "JavaScript",
    "Python",
    "Java"
];

let result = languages.filter(language => language.length > 3);

console.log(result);
Expected Output: 
["JavaScript", "Python", "Java"]

Example 6: Filtering Unique Values

A Set can be used together with filter() to retain the first occurrence of each value. 

let numbers = [10, 20, 10, 30, 20, 40];

let unique = numbers.filter((value, index, array) => {
    return array.indexOf(value) === index;
});

console.log(unique);
Expected Output: 
[10, 20, 30, 40]

This approach uses indexOf() to check whether the current value is appearing for the first time. For large arrays, Array.from(new Set(numbers)) is generally a more efficient and concise alternative.

Important: filter() returns an empty array when no elements satisfy the condition. It does not return null or undefined.

5. Understanding reduce()

The reduce() method processes array elements and combines them into a single accumulated result. The result may be a number, string, object, array or another data structure.

Syntax

array.reduce(callback(accumulator, currentValue, index, array), initialValue);
Parameter Description
accumulator Stores the accumulated result returned by the previous callback execution.
currentValue The current element being processed.
index The index of the current element.
array The original array on which reduce() was called.
initialValue Optional initial value for the accumulator.

Example 1: Calculating the Sum

let numbers = [10, 20, 30, 40];

let total = numbers.reduce((sum, number) => {
    return sum + number;
}, 0);

console.log(total);
Expected Output: 
100

Understanding the Execution

Iteration Accumulator Current Value New Accumulator
1 0 10 10
2 10 20 30
3 30 30 60
4 60 40 100

The initial accumulator value is zero. Each callback returns a new accumulated sum.

Example 2: Calculating the Product

let numbers = [2, 3, 4, 5];

let product = numbers.reduce((result, number) => {
    return result * number;
}, 1);

console.log(product);
Expected Output: 
120

Example 3: Finding the Maximum Value

let numbers = [15, 42, 8, 67, 23];

let maximum = numbers.reduce((max, number) => {
    return number > max ? number : max;
}, numbers[0]);

console.log(maximum);
Expected Output: 
67

This example assumes the array is non-empty. Production code should handle an empty array before using its first element as the initial value.

Example 4: Counting Occurrences

let fruits = [
    "Apple",
    "Mango",
    "Apple",
    "Banana",
    "Mango",
    "Apple"
];

let count = fruits.reduce((result, fruit) => {
    result[fruit] = (result[fruit] || 0) + 1;
    return result;
}, {});

console.log(count);
Expected Output: 
{
    Apple: 3,
    Mango: 2,
    Banana: 1
}

Example 5: Grouping Objects by a Property

const employees = [
    { name: "Amit", department: "IT" },
    { name: "Neha", department: "HR" },
    { name: "Rahul", department: "IT" },
    { name: "Priya", department: "HR" }
];

const grouped = employees.reduce((result, employee) => {
    const department = employee.department;

    if (!result[department]) {
        result[department] = [];
    }

    result[department].push(employee.name);

    return result;
}, {});

console.log(grouped);
Expected Output: 
{
    IT: ["Amit", "Rahul"],
    HR: ["Neha", "Priya"]
}

Example 6: Calculating Total Shopping Cart Value

const cart = [
    { product: "Keyboard", price: 1200, quantity: 2 },
    { product: "Mouse", price: 500, quantity: 1 },
    { product: "Monitor", price: 8000, quantity: 1 }
];

const total = cart.reduce((sum, item) => {
    return sum + item.price * item.quantity;
}, 0);

console.log("Cart Total:", total);
Expected Output: 
Cart Total: 10900
Important: Calling reduce() on an empty array without an initial value throws a TypeError. Supplying an appropriate initial value avoids this problem.

6. map() vs filter() vs reduce()

Feature map() filter() reduce()
Purpose Transform elements. Select elements. Accumulate a result.
Callback return Mapped value. Truthiness condition. Next accumulator.
Result New array. New array. Accumulated value.
Original array Not directly modified by the method. Not directly modified by the method. Not directly modified by the method.
Typical use Transforming API data. Searching or selecting records. Totals, counts and grouping.
These methods do not automatically mutate the original array. However, a callback can still mutate the original array or its nested objects if written to do so.

7. Method Chaining

Method chaining allows multiple array methods to be executed sequentially. The result of one method becomes the input to the next method.

Example 1: Filter and Then Map

let numbers = [1, 2, 3, 4, 5, 6, 7, 8];

let result = numbers
    .filter(number => number % 2 === 0)
    .map(number => number * number);

console.log(result);
Expected Output: 
[4, 16, 36, 64]

Execution:

  1. filter() selects even numbers: [2, 4, 6, 8].
  2. map() squares each selected number.

Example 2: Filter, Map and Reduce

const students = [
    { name: "Amit", marks: 85 },
    { name: "Neha", marks: 92 },
    { name: "Rahul", marks: 35 },
    { name: "Priya", marks: 78 }
];

const totalMarks = students
    .filter(student => student.marks >= 40)
    .map(student => student.marks)
    .reduce((sum, marks) => sum + marks, 0);

console.log(totalMarks);
Expected Output: 
255

The failed student is removed, the remaining marks are extracted, and their total is calculated.

Example 3: Processing Product Data

const products = [
    { name: "Keyboard", price: 1200, available: true },
    { name: "Mouse", price: 500, available: false },
    { name: "Monitor", price: 8000, available: true },
    { name: "Webcam", price: 1500, available: true }
];

const result = products
    .filter(product => product.available)
    .map(product => ({
        name: product.name,
        priceWithTax: product.price * 1.18
    }));

console.log(result);
Expected Output: 
[
    { name: "Keyboard", priceWithTax: 1416 },
    { name: "Monitor", priceWithTax: 9440 },
    { name: "Webcam", priceWithTax: 1770 }
]

8. Practical Frontend Application

Displaying Filtered and Transformed Courses

Consider an application that receives course information from an API. We want to display only available courses and transform their names for presentation. 

const courses = [
    { id: 1, name: "javascript", available: true },
    { id: 2, name: "react", available: true },
    { id: 3, name: "angular", available: false },
    { id: 4, name: "node.js", available: true }
];

const displayedCourses = courses
    .filter(course => course.available)
    .map(course => ({
        id: course.id,
        title: course.name.toUpperCase()
    }));

console.log(displayedCourses);
Expected Output: 
[
    { id: 1, title: "JAVASCRIPT" },
    { id: 2, title: "REACT" },
    { id: 4, title: "NODE.JS" }
]

In a React application, this transformed array could be used to render course cards using the map() method in JSX.

Frontend relevance: These methods are widely used for API response processing, product filtering, search results, dashboard statistics, shopping carts and dynamic UI rendering.

9. Common Mistakes and Debugging

Mistake Correct Understanding
Using map() without returning a value The corresponding mapped elements become undefined.
Using filter() without returning a condition Every callback result is undefined, so no elements pass the filter.
Expecting filter() to return a single value It always returns an array.
Forgetting the initial accumulator value Reduce may use the first element as its initial accumulator.
Calling reduce() on an empty array without an initial value It throws a TypeError.
Using map() only for side effects Use forEach() when you only need to perform an action without creating a transformed array.
Confusing the accumulator and current value The accumulator stores the result built so far; currentValue is the current array element.
Assuming these methods guarantee deep immutability Callbacks can still mutate nested objects or the original array.

10. Placement Interview Questions

Q1. What is map() in JavaScript?

map() creates a new array by applying a callback function to each element of the original array.

Q2. Does map() modify the original array?

No. The method itself creates a new array. However, the callback can still modify the original array or nested objects if explicitly written to do so.

Q3. What is filter() used for?

It creates a new array containing elements for which the callback returns a truthy value.

Q4. What happens if filter() finds no matching elements?

It returns an empty array.

Q5. What is reduce() used for?

It processes array elements and accumulates them into a single result, such as a sum, count, object or grouped collection.

Q6. What is an accumulator?

It is the value that stores the result accumulated across successive reduce() callback executions.

Q7. Is the initial value mandatory in reduce()?

No, but providing one is generally recommended. It makes the initial accumulator explicit and handles empty arrays safely when chosen appropriately.

Q8. What happens when reduce() is called on an empty array without an initial value?

JavaScript throws a TypeError.

Q9. Can reduce() return an object?

Yes. It can return numbers, strings, objects, arrays or other values depending on the accumulator.

Q10. What is method chaining?

It is the process of calling multiple methods sequentially, using one method's return value as the input to the next method.

Q11. What is the difference between map() and forEach()?

map() returns a new array containing callback results. forEach() returns undefined and is generally used for side effects.

Q12. What is the difference between map() and filter()?

map() transforms every element, while filter() selects elements according to a condition.

Q13. Can map(), filter() and reduce() be chained?

Yes. For example, filter() can select records, map() can transform them, and reduce() can calculate an aggregate result.

Q14. What is the time complexity of map() and filter()?

Both generally take O(n) time when the callback performs constant-time work for each of n elements.

Q15. What is the time complexity of reduce()?

It is generally O(n) when the callback performs constant-time work per element.

12. Lesson Summary

  • map() transforms every array element and returns a new array.
  • filter() selects elements that satisfy a condition.
  • reduce() accumulates array elements into a result.
  • Callback functions receive the current value, index and original array.
  • An initial accumulator value is generally recommended with reduce().
  • Method chaining combines multiple array-processing operations.
  • These methods are essential for frontend data processing and coding interviews.
