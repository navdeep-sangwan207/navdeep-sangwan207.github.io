Chapter 11: Fetch API, JSON, Storage and Debugging

Lesson 2: JSON Parse and Stringify Methods

Learn JSON syntax, convert JavaScript objects into JSON strings, parse JSON data, handle serialization limitations and process structured API data.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Explain JSON and its role in web applications.
  • Understand JSON syntax and supported data types.
  • Differentiate JavaScript objects from JSON strings.
  • Use JSON.stringify() to serialize data.
  • Use JSON.parse() to deserialize data.
  • Handle invalid JSON using try...catch.
  • Use replacer and reviver functions.
  • Understand serialization limitations.
  • Process nested objects and arrays.
  • Apply JSON conversion in API and browser-storage workflows.

2. What Is JSON?

JSON stands for JavaScript Object Notation. It is a lightweight, text-based data interchange format used to exchange structured information between applications.

JSON is commonly used for:

  • Communication between frontend and backend applications.
  • REST API request and response data.
  • Storing structured data in localStorage.
  • Configuration files.
  • Data exchange between different programming languages.

Example JSON data

{
    "id": 101,
    "name": "Rahul",
    "age": 24,
    "isActive": true,
    "skills": ["HTML", "CSS", "JavaScript"]
}

This JSON represents a user with an ID, name, age, active status and a list of skills.

JSON is a text format. Although its syntax resembles JavaScript object literals, JSON and JavaScript objects are not the same thing.

3. JSON Syntax Rules

Valid JSON follows specific syntax rules.

  • Object property names must use double quotes.
  • String values must use double quotes.
  • Object properties are separated by commas.
  • Arrays use square brackets.
  • Objects use curly braces.
  • JSON does not allow trailing commas.
  • JSON does not support comments.
  • JSON does not support functions or undefined values as JSON values.

Valid JSON

{
    "name": "Amit",
    "age": 25,
    "active": true,
    "address": null
}

Invalid JSON: Single quotes

{
    'name': 'Amit'
}

JSON requires double quotes for property names and string values.

Invalid JSON: Unquoted property name

{
    name: "Amit"
}

Invalid JSON: Trailing comma

{
    "name": "Amit",
    "age": 25,
}

Invalid JSON: Comments

{
    "name": "Amit"
    // User name
}
JavaScript object literals permit several constructs that JSON does not, including single-quoted strings, unquoted property names, comments and trailing commas.

JSON supports six categories of values:

Data type Example
String "JavaScript"
Number 100, 25.5

Example containing all supported types

{
    "name": "Amit",

5. JavaScript Object vs JSON String

A JavaScript object is an in-memory data structure. JSON is a textual representation that can be transmitted or stored.

JavaScript object

const user = {
    name: "Rahul",
    age: 24,
    active: true
};

console.log(user.name);

Expected output:

Rahul

JSON string

const jsonData = '{"name":"Rahul","age":24,"active":true}';

console.log(jsonData);
console.log(typeof jsonData);

Expected output:

{"name":"Rahul","age":24,"active":true}
string
JavaScript object JSON
In-memory JavaScript value. Text-based data format.
Can contain functions. Cannot represent functions.
Can contain undefined values. Does not support undefined as a JSON value.
Property names do not require quotes in object literals. Property names require double quotes.
Access properties directly. Parse the text before accessing structured values.

6. JSON.stringify()

JSON.stringify() converts a JavaScript value into a JSON string when that value can be serialized.

Syntax

JSON.stringify(value);
JSON.stringify(value, replacer);
JSON.stringify(value, replacer, space);

Parameters:

  • value: The JavaScript value to serialize.
  • replacer: An optional function or array controlling which properties are serialized.
  • space: An optional number or string controlling indentation in the output.

Example 1: Convert object into JSON string

const user = {
    name: "Rahul",
    age: 24,
    city: "Chandigarh"
};

const jsonData = JSON.stringify(user);

console.log(jsonData);
console.log(typeof jsonData);

Expected output:

{"name":"Rahul","age":24,"city":"Chandigarh"}
string

Example 2: Convert an array

const skills = [
    "HTML",
    "CSS",
    "JavaScript"
];

const jsonData = JSON.stringify(skills);

console.log(jsonData);

Expected output:

["HTML","CSS","JavaScript"]

Example 3: Pretty-print JSON

const employee = {
    id: 101,
    name: "Amit",
    department: "Development",
    salary: 40000
};

const jsonData = JSON.stringify(employee, null, 4);

console.log(jsonData);

Expected output:

{
    "id": 101,
    "name": "Amit",
    "department": "Development",
    "salary": 40000
}

The third argument, 4, requests four spaces of indentation for readability.

7. JSON.parse()

JSON.parse() converts a valid JSON string into a JavaScript value.

Syntax

JSON.parse(text);
JSON.parse(text, reviver);

Parameters:

  • text: A valid JSON string.
  • reviver: An optional function used to transform parsed values.

Example 1: Convert JSON string into object

const jsonData = '{"name":"Rahul","age":24,"city":"Chandigarh"}';

const user = JSON.parse(jsonData);

console.log(user);
console.log(user.name);
console.log(typeof user);

Expected output:

{ name: "Rahul", age: 24, city: "Chandigarh" }
Rahul
object

Example 2: Parse an array

const jsonData = '["HTML","CSS","JavaScript"]';

const skills = JSON.parse(jsonData);

console.log(skills[0]);
console.log(skills.length);

Expected output:

HTML
3

Example 3: Parse nested JSON data

const jsonData = `{
    "id": 101,
    "name": "Amit",
    "address": {
        "city": "Chandigarh",
        "country": "India"
    },
    "skills": ["C", "JavaScript", "React"]
}`;

const user = JSON.parse(jsonData);

console.log(user.address.city);
console.log(user.skills[1]);

Expected output:

Chandigarh
JavaScript

8. JSON.stringify() vs JSON.parse()

JSON.stringify() JSON.parse()
Serializes a JavaScript value. Deserializes a JSON string.
Produces a JSON string. Produces a JavaScript value.
Useful before storing or transmitting structured data. Useful after receiving or retrieving JSON text.
Can invoke a replacer function. Can invoke a reviver function.

Complete conversion workflow

const user = {
    name: "Rahul",
    age: 24
};

// JavaScript object to JSON string
const jsonData = JSON.stringify(user);

// JSON string to JavaScript object
const parsedUser = JSON.parse(jsonData);

console.log(parsedUser.name);
console.log(parsedUser.age);

Expected output:

Rahul
24

9. Handling Invalid JSON

JSON.parse() throws a SyntaxError when the supplied text is not valid JSON.

Example: Invalid JSON

const jsonData = '{"name":"Rahul",age:24}';

const user = JSON.parse(jsonData);

console.log(user);

Result:

SyntaxError: Expected property name or '}' in JSON at the position where the unquoted property appears.

The exact browser error message can vary. The important point is that invalid JSON causes JSON.parse() to throw.

Correct approach using try...catch

const jsonData = '{"name":"Rahul",age:24}';

try {
    const user = JSON.parse(jsonData);
    console.log(user);
} catch (error) {
    console.log("Invalid JSON data");
    console.log(error.name);
}

Expected output:

Invalid JSON data
SyntaxError
Always handle parsing errors when JSON comes from external sources, user input, files or browser storage.

10. The Replacer Parameter in JSON.stringify()

The replacer parameter allows you to control which properties are included in the serialized JSON string or how their values are transformed.

Example 1: Replacer array

const user = {
    name: "Rahul",
    age: 24,
    city: "Chandigarh",
    salary: 35000
};

const jsonData = JSON.stringify(
    user,
    ["name", "city"],
    4
);

console.log(jsonData);

Expected output:

{
    "name": "Rahul",
    "city": "Chandigarh"
}

Only the selected properties are included in the output.

Example 2: Replacer function

const product = {
    name: "Laptop",
    price: 50000,
    discount: 10
};

const jsonData = JSON.stringify(
    product,
    (key, value) => {
        if (key === "price") {
            return value - (value * product.discount / 100);
        }

        return value;
    },
    4
);

console.log(jsonData);

Expected output:

{
    "name": "Laptop",
    "price": 45000,
    "discount": 10
}

11. The Reviver Parameter in JSON.parse()

A reviver function allows you to transform parsed values while JSON.parse() constructs the JavaScript result.

Syntax

JSON.parse(jsonString, (key, value) => {
    return transformedValue;
});

Example: Convert a value to uppercase

const jsonData = `{
    "name": "rahul",
    "city": "chandigarh"
}`;

const user = JSON.parse(jsonData, (key, value) => {
    if (key === "name" || key === "city") {
        return value.toUpperCase();
    }

    return value;
});

console.log(user);

Expected output:

{ name: "RAHUL", city: "CHANDIGARH" }

Example: Convert ISO date strings into Date objects

const jsonData = `{
    "name": "Amit",
    "createdAt": "2026-01-15T10:30:00.000Z"
}`;

const user = JSON.parse(jsonData, (key, value) => {
    if (
        key === "createdAt" &&
        typeof value === "string"
    ) {
        return new Date(value);
    }

    return value;
});

console.log(user.createdAt instanceof Date);
console.log(user.createdAt.toISOString());

Expected output:

true
2026-01-15T10:30:00.000Z

12. Serialization Limitations

Not every JavaScript value can be represented directly in JSON. Understanding these limitations is important for API development and debugging.

1. Undefined values

const user = {
    name: "Rahul",
    age: undefined
};

console.log(JSON.stringify(user));

Expected output:

{"name":"Rahul"}

Undefined-valued object properties are omitted.

2. Functions

const user = {
    name: "Rahul",
    greet: function() {
        console.log("Hello");
    }
};

console.log(JSON.stringify(user));

Expected output:

{"name":"Rahul"}

Function-valued object properties are omitted.

3. Undefined in arrays

const values = [
    10,
    undefined,
    30
];

console.log(JSON.stringify(values));

Expected output:

[10,null,30]

Undefined array elements are serialized as null.

4. NaN and Infinity

const values = {
    first: NaN,
    second: Infinity,
    third: -Infinity
};

console.log(JSON.stringify(values));

Expected output:

{"first":null,"second":null,"third":null}

5. Date objects

const user = {
    name: "Amit",
    createdAt: new Date("2026-01-15T10:30:00.000Z")
};

console.log(JSON.stringify(user));

Expected output:

{"name":"Amit","createdAt":"2026-01-15T10:30:00.000Z"}

A Date object's toJSON() method produces an ISO-formatted string for JSON serialization. Parsing that string does not automatically recreate a Date object; use a reviver if that conversion is required.

6. BigInt

const value = {
    id: 12345678901234567890n
};

console.log(JSON.stringify(value));

Result:

TypeError: Do not know how to serialize a BigInt

BigInt is not supported directly by JSON.stringify() by default. Convert it to a string when a suitable representation is needed.

7. Circular references

const user = {
    name: "Rahul"
};

user.self = user;

console.log(JSON.stringify(user));

Result:

TypeError: Converting circular structure to JSON

JSON does not support circular object references. Use an appropriate custom serialization strategy when cyclic structures must be represented.

13. Working with Nested JSON Objects and Arrays

API responses often contain nested objects and arrays. JavaScript can access their values using property access and array indexing.

Example

const jsonData = `{
    "company": "Tech Solutions",
    "employees": [
        {
            "id": 1,
            "name": "Rahul",
            "skills": ["JavaScript", "React"]
        },
        {
            "id": 2,
            "name": "Amit",
            "skills": ["HTML", "CSS"]
        }
    ]
}`;

const company = JSON.parse(jsonData);

console.log(company.company);
console.log(company.employees[0].name);
console.log(company.employees[0].skills[1]);
console.log(company.employees[1].skills[0]);

Expected output:

Tech Solutions
Rahul
React
HTML

Iterating through parsed data

company.employees.forEach(employee => {
    console.log(employee.id, employee.name);
});

Expected output:

1 Rahul
2 Amit

14. JSON with localStorage

Browser localStorage stores string values. JSON.stringify() and JSON.parse() are commonly used to store and retrieve structured JavaScript data.

Store an object

const user = {
    name: "Rahul",
    age: 24,
    city: "Chandigarh"
};

localStorage.setItem(
    "user",
    JSON.stringify(user)
);

Retrieve an object

const storedData = localStorage.getItem("user");

if (storedData !== null) {
    const user = JSON.parse(storedData);

    console.log(user.name);
    console.log(user.age);
}

Expected output:

Rahul
24

Safe parsing from storage

function getStoredUser() {
    const storedData = localStorage.getItem("user");

    if (storedData === null) {
        return null;
    }

    try {
        return JSON.parse(storedData);
    } catch (error) {
        console.error("Stored user data is invalid:", error);
        return null;
    }
}

const user = getStoredUser();

console.log(user);
localStorage is covered in greater detail in Lesson 6. Do not store sensitive credentials or confidential data in browser storage without carefully considering the application's security requirements.

15. JSON in API Communication

JSON is commonly used as the request and response format in frontend-backend communication.

Example: Sending JSON data

const user = {
    name: "Rahul",
    email: "rahul@example.com"
};

fetch("/api/users", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "Accept": "application/json"
    },
    body: JSON.stringify(user)
})
.then(response => {
    if (!response.ok) {
        throw new Error("HTTP error: " + response.status);
    }

    return response.json();
})
.then(data => {
    console.log("Created user:", data);
})
.catch(error => {
    console.error("Request failed:", error.message);
});

JSON.stringify() converts the JavaScript object into a string for the request body.

The Fetch response's json() method reads and parses the response body as JSON.

Important distinction: JSON.parse() is a synchronous JavaScript method. response.json() is a Fetch Response method that returns a Promise because the response body is read asynchronously.

16. Common Mistakes and Debugging

Mistake 1: Parsing an ordinary JavaScript object

const user = {
    name: "Rahul"
};

JSON.parse(user);

JSON.parse() expects JSON text, not an ordinary object. Use the object directly or serialize it first.

Mistake 2: Stringifying twice

const user = {
    name: "Rahul"
};

const first = JSON.stringify(user);
const second = JSON.stringify(first);

console.log(second);

The second operation serializes an already serialized JSON string, adding another layer of quotation and escaping.

Mistake 3: Accessing parsed data before parsing

const jsonData = '{"name":"Rahul"}';

console.log(jsonData.name);

jsonData is a string. Parse it before accessing the name property.

Mistake 4: Invalid JSON syntax

Check double quotes, commas, brackets and braces when JSON.parse() throws a SyntaxError.

Mistake 5: Assuming JSON preserves every JavaScript type

Functions, undefined, BigInt and circular references require special consideration. Dates are normally serialized as strings.

Mistake 6: Forgetting error handling

Invalid JSON can cause JSON.parse() to throw. Use try...catch when parsing data from an external source.

17. Placement Interview Questions and Answers

Q1. What is JSON?

JSON is a text-based data interchange format used to exchange structured data between applications.

Q2. What is the full form of JSON?

JavaScript Object Notation.

Q3. What is JSON.stringify()?

It converts a JavaScript value into a JSON string when the value is serializable.

Q4. What is JSON.parse()?

It converts valid JSON text into a JavaScript value.

Q5. What is the difference between JSON and a JavaScript object?

JSON is a textual data format, whereas a JavaScript object is an in-memory JavaScript value.

Q6. Does JSON support functions?

No. JSON does not represent functions.

Q7. Does JSON support undefined?

No. Undefined object properties are omitted during stringification, while undefined array elements become null.

Q8. What happens when JSON.parse() receives invalid JSON?

It throws a SyntaxError.

Q9. What is serialization?

Serialization converts a data structure into a format suitable for storage or transmission.

Q10. What is deserialization?

Deserialization converts serialized data back into a usable data structure.

Q11. What is a replacer function?

It controls how values are transformed or selected during JSON.stringify().

Q12. What is a reviver function?

It transforms parsed values during JSON.parse().

Q13. Does JSON support comments?

No. Standard JSON syntax does not support comments.

Q14. Can JSON represent nested objects?

Yes. JSON supports nested objects and arrays.

Q15. Why is JSON commonly used in REST APIs?

It is lightweight, readable and supported by many programming languages.

Q16. What happens when JSON.stringify() receives BigInt?

It throws a TypeError by default unless a suitable serialization strategy is provided.

Q17. Does JSON.stringify() preserve Date objects?

No. A Date normally becomes an ISO-formatted string through its toJSON() method.

Q18. Why use JSON with localStorage?

localStorage stores strings. JSON allows structured objects and arrays to be serialized and reconstructed.
