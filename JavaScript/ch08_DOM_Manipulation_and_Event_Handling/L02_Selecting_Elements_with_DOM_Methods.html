Lesson 02: Selecting Elements with DOM Methods

Learn how to locate HTML elements using JavaScript DOM selection methods, work with collections of elements, and choose the appropriate selector for frontend development.

1. Learning Objectives

  • Understand why DOM element selection is necessary.
  • Use getElementById() to select an element by its ID.
  • Use getElementsByClassName() and getElementsByTagName().
  • Use querySelector() and querySelectorAll().
  • Understand HTMLCollection and NodeList.
  • Use CSS selectors to locate nested and specific elements.
  • Handle missing elements and common selection errors.

2. Why Do We Select DOM Elements?

JavaScript must first locate an HTML element before it can modify its content, update its style, change its attributes, or attach event listeners.

DOM selection methods are provided by the document object and other DOM elements.

Example HTML

<h1 id="heading">Welcome</h1>

<p class="message">First paragraph</p>
<p class="message">Second paragraph</p>

<button>Submit</button>

JavaScript can select the heading, paragraphs, and button using different DOM methods.

3. getElementById()

The getElementById() method selects an element using its unique ID attribute.

Syntax

document.getElementById("elementId");

Example

<h1 id="mainHeading">JavaScript DOM</h1>

<script>
    const heading = document.getElementById("mainHeading");

    console.log(heading);
    console.log(heading.textContent);
</script>
Expected Console Output: 
<h1 id="mainHeading">JavaScript DOM</h1>
JavaScript DOM

Important Characteristics

  • It searches by the element's ID.
  • It returns the matching element object.
  • If no matching element exists, it returns null.
  • IDs should be unique within an HTML document.

Handling a Missing Element

const heading = document.getElementById("missing");

if (heading !== null) {
    console.log(heading.textContent);
} else {
    console.log("Element not found");
}
Expected Output: 
Element not found

4. getElementsByClassName()

The getElementsByClassName() method returns an HTMLCollection containing elements with the specified class name.

Syntax

document.getElementsByClassName("className");

Example

<p class="message">First message</p>
<p class="message">Second message</p>
<p class="message">Third message</p>

<script>
    const messages =
        document.getElementsByClassName("message");

    console.log(messages.length);

    for (let i = 0; i < messages.length; i++) {
        console.log(messages[i].textContent);
    }
</script>
Expected Console Output: 
3
First message
Second message
Third message

Selecting Multiple Class Names

To select elements containing multiple classes, separate the class names with spaces. 

document.getElementsByClassName("card active");

This selects elements that have both the card and active classes.

Do not include the dot prefix used in CSS selectors. Use "message", not ".message".

5. getElementsByTagName()

The getElementsByTagName() method returns an HTMLCollection containing elements with the specified HTML tag name.

Syntax

document.getElementsByTagName("tagName");

Example

<h2>First Heading</h2>
<h2>Second Heading</h2>
<p>First paragraph</p>
<p>Second paragraph</p>

<script>
    const headings =
        document.getElementsByTagName("h2");

    const paragraphs =
        document.getElementsByTagName("p");

    console.log("Headings:", headings.length);
    console.log("Paragraphs:", paragraphs.length);
</script>
Expected Console Output: 
Headings: 2
Paragraphs: 2

Selecting All Elements

const allElements =
    document.getElementsByTagName("*");

console.log(allElements.length);

The asterisk selects all descendant elements of the document's root element.

6. querySelector()

The querySelector() method selects the first element matching a specified CSS selector.

Syntax

document.querySelector("CSS selector");

Examples of CSS Selectors

Selector Purpose
#heading Selects an element with ID heading.
.message Selects an element with class message.
p Selects the first paragraph element.
div p Selects the first paragraph inside a div.
input[type="text"] Selects the first text input.
.card.active Selects an element having both classes.
ul > li Selects the first li that is a direct child of a ul.

Example

<h1 id="heading">JavaScript</h1>

<p class="message">First paragraph</p>
<p class="message">Second paragraph</p>

<script>
    const heading = document.querySelector("#heading");
    const message = document.querySelector(".message");

    console.log(heading.textContent);
    console.log(message.textContent);
</script>
Expected Console Output: 
JavaScript
First paragraph
Important: querySelector() returns only the first matching element. If no element matches, it returns null.

7. querySelectorAll()

The querySelectorAll() method returns a static NodeList containing all elements matching the specified CSS selector.

Syntax

document.querySelectorAll("CSS selector");

Example

<p class="message">First message</p>
<p class="message">Second message</p>
<p class="message">Third message</p>

<script>
    const messages =
        document.querySelectorAll(".message");

    console.log(messages.length);

    messages.forEach(function (message) {
        console.log(message.textContent);
    });
</script>
Expected Console Output: 
3
First message
Second message
Third message

Selecting Multiple Types of Elements

const elements =
    document.querySelectorAll("h1, p, button");

console.log(elements.length);

This selects all h1, p, and button elements in the document.

8. HTMLCollection vs NodeList

Several DOM selection methods return collections instead of a single element. Two important collection types are HTMLCollection and NodeList.

Feature HTMLCollection NodeList
Returned by getElementsByClassName(), getElementsByTagName() querySelectorAll() returns a NodeList.
Contents Element nodes only. Can contain different node types depending on the API.
Live or Static Live. querySelectorAll() returns a static NodeList.
forEach() Not directly available as a standard HTMLCollection method. Available on modern NodeList objects.
Index access Yes. Yes.
length Yes. Yes.

Live HTMLCollection Example

<div class="item">Item 1</div>
<div class="item">Item 2</div>

<script>
    const items =
        document.getElementsByClassName("item");

    console.log(items.length);

    const newItem = document.createElement("div");
    newItem.className = "item";
    newItem.textContent = "Item 3";

    document.body.appendChild(newItem);

    console.log(items.length);
</script>
Expected Console Output: 
2
3

The HTMLCollection updates automatically when the document changes and the new element matches the collection's class filter.

Static NodeList Example

<div class="item">Item 1</div>
<div class="item">Item 2</div>

<script>
    const items =
        document.querySelectorAll(".item");

    console.log(items.length);

    const newItem = document.createElement("div");
    newItem.className = "item";
    newItem.textContent = "Item 3";

    document.body.appendChild(newItem);

    console.log(items.length);
</script>
Expected Console Output: 
2
2

The NodeList returned by querySelectorAll() remains unchanged because it is a static collection.

Not every NodeList is static. For example, childNodes returns a live NodeList. The behavior depends on the specific DOM API.

9. Iterating Over Selected Elements

Using a for Loop

const items = document.querySelectorAll(".item");

for (let i = 0; i < items.length; i++) {
    console.log(items[i].textContent);
}

Using forEach()

const items = document.querySelectorAll(".item");

items.forEach(function (item, index) {
    console.log(index, item.textContent);
});

Converting HTMLCollection into an Array

const collection =
    document.getElementsByClassName("item");

const itemsArray = Array.from(collection);

itemsArray.forEach(function (item) {
    console.log(item.textContent);
});

Array.from() creates an array from an iterable or array-like object. The resulting array can use standard array methods such as map(), filter(), and forEach().

10. Selecting Elements Inside Another Element

Selection methods can also be called on an existing element instead of the document. This is useful when working with nested components.

Example

<div id="container">
    <h2>Products</h2>
    <p class="product">Laptop</p>
    <p class="product">Keyboard</p>
</div>

<script>
    const container =
        document.getElementById("container");

    const products =
        container.querySelectorAll(".product");

    products.forEach(function (product) {
        console.log(product.textContent);
    });
</script>
Expected Console Output: 
Laptop
Keyboard

This approach limits the search to the selected container and its descendants.

11. Complete Practical Example: Product Selection

The following example demonstrates selecting multiple products and displaying their names and prices. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Product Selection</title>
</head>
<body>

    <h1 id="pageTitle">Available Products</h1>

    <div class="product">
        <h2>Laptop</h2>
        <p class="price">50000</p>
    </div>

    <div class="product">
        <h2>Keyboard</h2>
        <p class="price">1500</p>
    </div>

    <div class="product">
        <h2>Mouse</h2>
        <p class="price">800</p>
    </div>

    <script>
        const title =
            document.getElementById("pageTitle");

        const products =
            document.querySelectorAll(".product");

        console.log(title.textContent);

        products.forEach(function (product) {
            const name =
                product.querySelector("h2").textContent;

            const price =
                product.querySelector(".price").textContent;

            console.log(name + ": Rs. " + price);
        });
    </script>

</body>
</html>
Expected Console Output: 
Available Products
Laptop: Rs. 50000
Keyboard: Rs. 1500
Mouse: Rs. 800

This pattern is useful in product listings, shopping applications, dashboards, and dynamic frontend interfaces.

12. Common Mistakes and Debugging

Mistake 1: Using a CSS dot with getElementsByClassName()

// Incorrect
document.getElementsByClassName(".message");

// Correct
document.getElementsByClassName("message");

Mistake 2: Expecting querySelector() to return all matches

// Returns only the first matching element
const item = document.querySelector(".item");

// Returns all matching elements
const items = document.querySelectorAll(".item");

Mistake 3: Accessing an element that does not exist

const heading = document.querySelector("#missing");

console.log(heading.textContent);

If no element matches, querySelector() returns null. Accessing textContent on null causes a TypeError.

Safe approach

const heading = document.querySelector("#missing");

if (heading) {
    console.log(heading.textContent);
} else {
    console.log("Heading not found");
}

Mistake 4: Treating an HTMLCollection as an Array

const items =
    document.getElementsByClassName("item");

// HTMLCollection does not provide standard Array methods
const array = Array.from(items);

array.forEach(function (item) {
    console.log(item.textContent);
});

Mistake 5: Invalid CSS selector

// Invalid CSS selector
document.querySelector("##heading");

// Correct
document.querySelector("#heading");

An invalid selector passed to querySelector() or querySelectorAll() throws a SyntaxError DOMException.

13. Placement Interview Questions and Answers

Q1. What is the difference between getElementById() and querySelector()?

Answer: getElementById() selects an element by its ID. querySelector() accepts any valid CSS selector and returns the first matching element.

Q2. What is the difference between querySelector() and querySelectorAll()?

Answer: querySelector() returns the first matching element or null. querySelectorAll() returns a static NodeList of all matching elements.

Q3. What does getElementsByClassName() return?

Answer: It returns a live HTMLCollection containing matching elements.

Q4. What is an HTMLCollection?

Answer: It is an array-like collection of HTML elements. It is live, meaning its contents update automatically as matching elements change.

Q5. Is NodeList always static?

Answer: No. querySelectorAll() returns a static NodeList, while childNodes returns a live NodeList.

Q6. Can we use forEach() with NodeList?

Answer: Yes. Modern browsers support forEach() on NodeList objects.

Q7. What happens if getElementById() cannot find an element?

Answer: It returns null.

Q8. What is the advantage of querySelector()?

Answer: It supports CSS selector syntax, allowing developers to select elements by ID, class, tag, attributes, and relationships.

Q9. How can you convert an HTMLCollection into an Array?

Answer: Use Array.from(collection) or the spread operator, [...collection].

Q10. What is the difference between a live and static collection?

Answer: A live collection reflects matching DOM changes automatically. A static collection represents the elements selected at the time of the query.

Q11. Can querySelector() be called on an element?

Answer: Yes. It searches the element's descendants for the first matching element.

Q12. What error occurs when an invalid CSS selector is passed?

Answer: The browser throws a SyntaxError DOMException.

15. Lesson Summary

  • DOM selection allows JavaScript to locate HTML elements.
  • getElementById() selects one element using its ID.
  • getElementsByClassName() returns a live HTMLCollection.
  • getElementsByTagName() returns a live HTMLCollection.
  • querySelector() returns the first CSS selector match.
  • querySelectorAll() returns a static NodeList.
  • HTMLCollection and NodeList are array-like, not Arrays.
  • Array.from() converts collections into Arrays.
  • Element-level selection methods are useful for nested components.
  • Always check for null when an element might not exist.
