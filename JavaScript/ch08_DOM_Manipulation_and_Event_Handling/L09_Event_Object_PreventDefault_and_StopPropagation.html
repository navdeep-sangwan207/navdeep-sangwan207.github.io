Lesson 9: Event Object, preventDefault() and stopPropagation()

Understand event object properties, browser default actions, event propagation control and practical event-handling techniques.

2. What Is the Event Object?

When an event occurs, the browser creates an event object containing information about that event.

The event object is automatically passed to the event listener callback function.

Example

const button = document.querySelector("#myButton");

button.addEventListener("click", function (event) {
    console.log(event);
});

Here, event contains information about the click, including the target element, event type and mouse coordinates.

Using an Arrow Function

button.addEventListener("click", (event) => {
    console.log(event.type);
});
The event parameter is a normal function parameter. You can name it event, e or any other valid identifier.

3. Important Event Object Properties

Property Description
type Returns the event type, such as click or keydown.
target Identifies the element on which the event originally occurred.
currentTarget Identifies the element whose listener is currently executing.
eventPhase Indicates the current propagation phase.
bubbles Indicates whether the event bubbles.
cancelable Indicates whether the event's default action can be canceled.
defaultPrevented Indicates whether preventDefault() has canceled the default action.
isTrusted Indicates whether the event was generated by the user agent rather than dispatched through script.

Example: Inspect Event Properties

const button = document.querySelector("#myButton");

button.addEventListener("click", function (event) {
    console.log("Event Type:", event.type);
    console.log("Target:", event.target);
    console.log("Current Target:", event.currentTarget);
    console.log("Bubbles:", event.bubbles);
    console.log("Cancelable:", event.cancelable);
    console.log("Default Prevented:", event.defaultPrevented);
});

Event Propagation Phases

eventPhase Value Constant Meaning
1 Event.CAPTURING_PHASE Capturing phase
2 Event.AT_TARGET Target phase
3 Event.BUBBLING_PHASE Bubbling phase
0 Event.NONE Event is not currently being dispatched.

4. Mouse Event Properties

Mouse events provide information about pointer coordinates and mouse button interactions.

Property Description
clientX Horizontal mouse coordinate relative to the viewport.
clientY Vertical mouse coordinate relative to the viewport.
pageX Horizontal coordinate relative to the document.
pageY Vertical coordinate relative to the document.
screenX Horizontal coordinate relative to the screen.
screenY Vertical coordinate relative to the screen.
button Identifies the mouse button associated with an event such as mousedown.
buttons Indicates which mouse buttons are currently pressed.

Example: Mouse Coordinates

document.addEventListener("click", function (event) {
    console.log("Client X:", event.clientX);
    console.log("Client Y:", event.clientY);

    console.log("Page X:", event.pageX);
    console.log("Page Y:", event.pageY);
});

5. Keyboard Event Properties

Keyboard events provide information about the key pressed or released.

Property Description
key Returns the key value, such as a, Enter or ArrowUp.
code Identifies the physical keyboard key, such as KeyA or Enter.
altKey Indicates whether Alt was pressed.
ctrlKey Indicates whether Ctrl was pressed.
shiftKey Indicates whether Shift was pressed.
metaKey Indicates whether the Meta key was pressed.
repeat Indicates whether the key is being held and repeated.

Example: Keyboard Information

document.addEventListener("keydown", function (event) {
    console.log("Key:", event.key);
    console.log("Code:", event.code);

    console.log("Ctrl:", event.ctrlKey);
    console.log("Shift:", event.shiftKey);
    console.log("Alt:", event.altKey);
});

6. What Is preventDefault()?

preventDefault() is a method of the Event interface. It cancels the browser's default action associated with an event, provided that the event is cancelable.

Common Default Browser Actions

Element or Action Default Behavior
Anchor link Navigates to the specified URL.
Form submission Submits the form and may navigate or reload the page.
Checkbox Changes its checked state.
Context menu Displays the browser's context menu.
Keyboard default action Performs the associated browser action when cancelable.

Syntax

event.preventDefault();

Example: Prevent Anchor Navigation

<a href="https://example.com" id="myLink">
    Visit Website
</a>

<script>
    const link = document.getElementById("myLink");

    link.addEventListener("click", function (event) {
        event.preventDefault();

        console.log("Navigation prevented");
    });
</script>

Interactive Demonstration

Click this link

Example: Prevent Form Submission

const form = document.querySelector("#myForm");

form.addEventListener("submit", function (event) {
    event.preventDefault();

    console.log("Normal form submission prevented");
});

This is useful when a frontend application processes form data using JavaScript instead of performing a normal browser form submission.

preventDefault() does not stop event propagation. Parent event listeners may still execute.

7. Practical Example: Form Validation

A frontend application may validate user input before allowing a form to proceed.

Complete Example



const form = document.getElementById("validationForm");

const nameInput = document.getElementById("validationName");
const emailInput = document.getElementById("validationEmail");

const output = document.getElementById("validationOutput");

form.addEventListener("submit", function (event) {

    event.preventDefault();

    if (nameInput.value.trim() === "") {
        output.textContent = "Name is required";
        return;
    }

    if (emailInput.value.trim() === "") {
        output.textContent = "Email is required";
        return;
    }

    output.textContent = "Form validated successfully";
});

Expected Result

  • Submitting with an empty name displays a name error.
  • Submitting with an empty email displays an email error.
  • Entering both values displays a success message.
  • The page does not perform its normal form submission.
The browser's built-in validation may prevent the submit event from firing for invalid email input. This example demonstrates JavaScript validation for empty fields; production applications should also validate data on the server.

8. What Is stopPropagation()?

stopPropagation() is a method used to prevent an event from continuing through the DOM propagation path.

It stops the event from reaching other ancestors or descendants later in the propagation path, depending on the phase in which it is called.

Syntax

event.stopPropagation();

Example Without stopPropagation()

<div id="parent">
    Parent
    <button id="child">Click Me</button>
</div>

<script>
    const parent = document.getElementById("parent");
    const child = document.getElementById("child");

    parent.addEventListener("click", function () {
        console.log("Parent clicked");
    });

    child.addEventListener("click", function () {
        console.log("Child clicked");
    });
</script>

Expected Output

Child clicked
Parent clicked

Example With stopPropagation()

child.addEventListener("click", function (event) {
    console.log("Child clicked");

    event.stopPropagation();
});

Expected Output

Child clicked

The event does not continue bubbling to the parent.

Interactive Demonstration

Parent element
Child element

Click the child button.

The child button stops propagation, so the parent click handler does not execute.

9. What Is stopImmediatePropagation()?

stopImmediatePropagation() stops further propagation of the event and prevents other event listeners registered on the same element from executing.

Syntax

event.stopImmediatePropagation();

Example

const button = document.getElementById("myButton");

button.addEventListener("click", function (event) {
    console.log("First listener");

    event.stopImmediatePropagation();
});

button.addEventListener("click", function () {
    console.log("Second listener");
});

button.addEventListener("click", function () {
    console.log("Third listener");
});

Expected Output

First listener

The second and third listeners are not executed because the first listener called stopImmediatePropagation().

Interactive Demonstration

Click the button to test listener execution.

stopImmediatePropagation() is stronger than stopPropagation(). Use it carefully because it can prevent unrelated listeners on the same element from running.

10. preventDefault() vs stopPropagation() vs stopImmediatePropagation()

Method Purpose
preventDefault() Cancels the event's default browser action when cancelable.
stopPropagation() Stops further propagation through the DOM path.
stopImmediatePropagation() Stops propagation and prevents later listeners on the same target from executing.

Comparison Example

// Prevent default browser action
event.preventDefault();

// Stop event propagation
event.stopPropagation();

// Stop other listeners on the same target
// and further propagation
event.stopImmediatePropagation();
These methods solve different problems. Preventing a link's navigation does not automatically stop its click event from bubbling to a parent.

11. Understanding defaultPrevented and cancelable

11.1 defaultPrevented

This property indicates whether the event's default action has been canceled. 

button.addEventListener("click", function (event) {
    event.preventDefault();

    console.log(event.defaultPrevented); // true
});

11.2 cancelable

This property indicates whether preventDefault() can cancel the event's default action. 

element.addEventListener("click", function (event) {
    console.log("Cancelable:", event.cancelable);

    if (event.cancelable) {
        event.preventDefault();
    }
});
Calling preventDefault() on a non-cancelable event has no effect. It also cannot cancel a default action when called from a passive listener.

12. Practical Example: Modal Click Handling

In a modal interface, clicking the background may close the modal, while clicking inside the modal should not.

Complete Example

<div id="overlay">
    <div id="modal">
        <h2>Modal Window</h2>
        <p>Click inside this box.</p>
    </div>
</div>

<script>
    const overlay = document.getElementById("overlay");
    const modal = document.getElementById("modal");

    overlay.addEventListener("click", function () {
        console.log("Overlay clicked - close modal");
    });

    modal.addEventListener("click", function (event) {
        event.stopPropagation();

        console.log("Modal content clicked");
    });
</script>

Explanation

  • The overlay has a click listener.
  • The modal is nested inside the overlay.
  • Clicking the modal normally bubbles to the overlay.
  • stopPropagation() prevents the overlay handler from executing for clicks inside the modal.
This is a common frontend use case for controlling event propagation in modal dialogs and popups.

13. Common Mistakes and Debugging

Mistake 1: Assuming preventDefault() Stops Bubbling

button.addEventListener("click", function (event) {
    event.preventDefault();
});

This cancels the default action only. It does not stop the event from reaching parent listeners.

Mistake 2: Assuming stopPropagation() Cancels Navigation

link.addEventListener("click", function (event) {
    event.stopPropagation();
});

This stops propagation but does not cancel the anchor's default navigation action.

Mistake 3: Using stopImmediatePropagation() Unnecessarily

This can prevent other components' listeners on the same element from executing. Use stopPropagation() if only ancestor propagation needs to be stopped.

Mistake 4: Forgetting the Event Parameter

// Incorrect if event is not defined elsewhere
button.addEventListener("click", function () {
    event.preventDefault();
});

// Correct
button.addEventListener("click", function (event) {
    event.preventDefault();
});

Mistake 5: Ignoring Passive Listeners

preventDefault() cannot cancel an event from a passive listener. Remove passive: true when cancellation is genuinely required and supported for that event.

14. Placement Interview Questions and Answers

Q1. What is the JavaScript event object?

It is an object created by the browser that contains information about an event, including its type, target, propagation phase and other event-specific data.

Q2. What is preventDefault()?

It cancels the browser's default action associated with a cancelable event.

Q3. What is stopPropagation()?

It prevents the event from continuing through the DOM propagation path.

Q4. What is stopImmediatePropagation()?

It stops further propagation and prevents other listeners registered on the same target from executing.

Q5. What is the difference between preventDefault() and stopPropagation()?

preventDefault() cancels a browser default action. stopPropagation() controls event propagation through the DOM tree.

Q6. Does preventDefault() stop event bubbling?

No. It only cancels the default action. The event can still bubble to parent elements.

Q7. Does stopPropagation() prevent the default action?

No. The default browser action may still occur.

Q8. What is event.target?

It identifies the element on which the event originally occurred.

Q9. What is event.currentTarget?

It identifies the element whose event listener is currently executing.

Q10. What is event.defaultPrevented?

It returns true if preventDefault() has successfully canceled the event's default action.

Q11. What is event.cancelable?

It indicates whether the event's default action can be canceled.

Q12. What happens when preventDefault() is called inside a passive listener?

The default action cannot be canceled by that listener. The browser may issue a console warning.

Q13. How can you prevent a form from reloading the page?

Register a submit event listener and call event.preventDefault() inside it.

Q14. How can you prevent a click inside a modal from closing it?

Call stopPropagation() on the modal's click handler so the click does not reach the overlay handler.
