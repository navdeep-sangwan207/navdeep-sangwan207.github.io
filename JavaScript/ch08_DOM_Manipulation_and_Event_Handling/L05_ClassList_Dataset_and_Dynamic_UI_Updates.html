Lesson 05: classList, dataset and Dynamic UI Updates

Learn how to manipulate CSS classes, work with custom data attributes, and build interactive user interfaces using JavaScript DOM APIs.

1. Learning Objectives

  • Understand the classList property.
  • Add and remove CSS classes dynamically.
  • Toggle classes based on application state.
  • Check whether an element contains a CSS class.
  • Replace one CSS class with another.
  • Understand the className and classList differences.
  • Work with HTML data-* attributes.
  • Read and update custom data using dataset.
  • Build dynamic UI components using DOM and CSS classes.

2. What Is classList?

The classList property provides a DOMTokenList interface for managing the CSS classes associated with an HTML element.

It allows developers to add, remove, toggle, replace, and check classes without manually manipulating the complete class attribute string.

Example HTML

<div id="card" class="product active featured">
    Product Information
</div>

Accessing classList

const card = document.getElementById("card");

console.log(card.classList);

The classList object provides methods for working with individual CSS classes.

3. classList.add()

The add() method adds one or more CSS classes to an element.

Syntax

element.classList.add("className");

element.classList.add("classOne", "classTwo");

Example

<div id="message">Welcome User</div>

<script>
    const message = document.getElementById("message");

    message.classList.add("success");

    message.classList.add("highlight", "visible");

    console.log(message.className);
</script>
Expected Console Output: 
success highlight visible

Adding CSS Styling

<style>
    .success {
        color: green;
        font-weight: bold;
    }

    .highlight {
        background-color: yellow;
    }
</style>

Adding a class changes the element's styling when a corresponding CSS rule exists.

Adding an existing class does not create a duplicate. classList.add() maintains unique class tokens.

4. classList.remove()

The remove() method removes one or more CSS classes from an element.

Syntax

element.classList.remove("className");

element.classList.remove("classOne", "classTwo");

Example

<div id="box" class="active highlight visible">
    Content
</div>

<script>
    const box = document.getElementById("box");

    box.classList.remove("highlight");

    box.classList.remove("active", "visible");

    console.log(box.className);
</script>
Expected Console Output:
The class attribute becomes empty.

5. classList.toggle()

The toggle() method adds a class if it is absent and removes it if it is already present.

Syntax

element.classList.toggle("className");

Example

<div id="panel">Dashboard Panel</div>

<script>
    const panel = document.getElementById("panel");

    panel.classList.toggle("active");

    console.log(panel.classList.contains("active"));

    panel.classList.toggle("active");

    console.log(panel.classList.contains("active"));
</script>
Expected Console Output: 
true
false

toggle() with a Force Parameter

toggle() also accepts a Boolean force parameter. This makes it useful when the desired state is already known. 

element.classList.toggle("active", true);

element.classList.toggle("active", false);
Statement Behavior
toggle("active") Adds or removes the class depending on its current state.
toggle("active", true) Ensures the class is present.
toggle("active", false) Ensures the class is absent.

6. classList.contains()

The contains() method checks whether an element has a specified CSS class.

Syntax

element.classList.contains("className");

It returns true if the class exists and false otherwise.

Example

<div id="card" class="product featured">
    Product
</div>

<script>
    const card = document.getElementById("card");

    console.log(card.classList.contains("product"));

    console.log(card.classList.contains("active"));
</script>
Expected Console Output: 
true
false

Practical Conditional Usage

if (card.classList.contains("featured")) {
    console.log("Featured product");
} else {
    console.log("Regular product");
}

7. classList.replace()

The replace() method replaces an existing class with another class.

Syntax

element.classList.replace("oldClass", "newClass");

Example

<div id="notification" class="warning">
    Notification
</div>

<script>
    const notification =
        document.getElementById("notification");

    const replaced = notification.classList.replace(
        "warning",
        "success"
    );

    console.log(replaced);
    console.log(notification.className);
</script>
Expected Console Output: 
true
success

replace() returns true if the old class was found and replaced. Otherwise, it returns false.

8. classList.item() and length

DOMTokenList provides additional properties and methods that help inspect an element's CSS classes.

length

The length property returns the number of class tokens.

item(index)

The item() method returns the class token at the specified zero-based index. It returns null when the index is out of range.

Example

<div id="box" class="card active featured">
    Product Card
</div>

<script>
    const box = document.getElementById("box");

    console.log(box.classList.length);

    console.log(box.classList.item(0));

    console.log(box.classList.item(1));

    console.log(box.classList.item(5));
</script>
Expected Console Output: 
3
card
active
null

9. className vs classList

Both className and classList are used to work with an element's CSS classes, but they behave differently.

Feature className classList
Type String DOMTokenList
Read classes Returns the complete class string. Provides individual class tokens.
Add class Requires string manipulation or reassignment. Uses add().
Remove class Requires string manipulation or reassignment. Uses remove().
Toggle class No built-in toggle method. Uses toggle().
Check class String checking methods are needed. Uses contains().

className Example

const box = document.getElementById("box");

box.className = "card active";

This assignment replaces the entire class attribute value. Any previous classes not included in the new string are removed.

classList Example

const box = document.getElementById("box");

box.classList.add("active");

This adds the active class while preserving existing classes.

For most dynamic class manipulation, classList is easier to maintain and less error-prone than manually modifying className strings.

10. Understanding HTML Custom Data Attributes

HTML supports custom data attributes that begin with data-. They allow developers to attach application-specific information to HTML elements.

Syntax

<element data-name="value">

Example

<button
    id="productButton"
    data-product-id="101"
    data-product-name="Laptop"
    data-price="55000">
    View Product
</button>

Here, the button stores product-related information through custom data attributes.

Common Use Cases

  • Storing product identifiers.
  • Keeping item IDs in dynamically generated lists.
  • Associating buttons with application records.
  • Storing UI configuration values.
  • Supporting event delegation.

11. Accessing Data Attributes Using dataset

The dataset property provides access to an element's data-* attributes through a DOMStringMap.

Example

<button
    id="product"
    data-product-id="101"
    data-product-name="Laptop"
    data-price="55000">
    View Product
</button>

<script>
    const product = document.getElementById("product");

    console.log(product.dataset.productId);
    console.log(product.dataset.productName);
    console.log(product.dataset.price);
</script>
Expected Console Output: 
101
Laptop
55000

Conversion from HTML Attribute Names

HTML data attribute names use hyphens. JavaScript dataset property names use camelCase.

HTML Attribute JavaScript dataset Property
data-user-id dataset.userId
data-product-name dataset.productName
data-item-price dataset.itemPrice
data-is-active dataset.isActive

Updating Data Attributes

const product = document.getElementById("product");

product.dataset.price = "60000";

console.log(product.dataset.price);
Expected Console Output: 
60000

Creating Data Attributes Dynamically

const card = document.createElement("div");

card.dataset.productId = "202";
card.dataset.category = "Electronics";

console.log(card.getAttribute("data-product-id"));
console.log(card.getAttribute("data-category"));
Expected Console Output: 
202
Electronics
Values accessed through dataset are strings. Convert numeric or Boolean values explicitly when required.

12. Converting dataset Values

HTML data attributes are represented as strings in JavaScript. They are not automatically converted into numbers or Boolean values.

Example

<div
    id="product"
    data-price="2500"
    data-stock="true">
</div>

<script>
    const product = document.getElementById("product");

    const price = Number(product.dataset.price);

    const stock = product.dataset.stock === "true";

    console.log(price);
    console.log(typeof price);

    console.log(stock);
    console.log(typeof stock);
</script>
Expected Console Output: 
2500
number
true
boolean

Use Number(), parseInt(), parseFloat(), or explicit comparisons depending on the expected data type.

13. Dynamic UI Updates Using classList

Dynamic UI updates involve changing the appearance or visibility of webpage elements in response to application state or user actions.

Example: Show and Hide a Panel

<style>
    .hidden {
        display: none;
    }

    .panel {
        padding: 20px;
        background: #e8f0ff;
    }
</style>

<button id="toggleButton">Toggle Panel</button>

<div id="panel" class="panel">
    Dashboard Information
</div>

<script>
    const button = document.getElementById("toggleButton");
    const panel = document.getElementById("panel");

    button.addEventListener("click", function () {
        panel.classList.toggle("hidden");
    });
</script>

Every click toggles the hidden class, changing the panel's visibility.

14. Practical Example: Active Navigation Menu

A navigation menu often highlights the currently selected section. classList can manage this state. 

<style>
    .menu {
        display: flex;
        gap: 15px;
        list-style: none;
    }

    .menu li {
        padding: 10px 16px;
        cursor: pointer;
    }

    .menu .active {
        background: #174ea6;
        color: white;
        border-radius: 5px;
    }
</style>

<ul class="menu" id="menu">
    <li class="active">Home</li>
    <li>Courses</li>
    <li>Projects</li>
    <li>Contact</li>
</ul>

<script>
    const menu = document.getElementById("menu");

    const items = menu.querySelectorAll("li");

    items.forEach(function (item) {
        item.addEventListener("click", function () {

            items.forEach(function (element) {
                element.classList.remove("active");
            });

            item.classList.add("active");
        });
    });
</script>

Expected Behavior

  • Home is initially highlighted.
  • Clicking Courses highlights Courses.
  • The active class is removed from Home.
  • Only one menu item remains active.

15. Practical Example: Product Cards Using dataset

Custom data attributes can connect UI elements to application data. 

<div class="product-card"
     data-product-id="101"
     data-price="45000">

    <h3>Laptop</h3>

    <button class="view-button">
        View Details
    </button>

</div>

<script>
    const card = document.querySelector(".product-card");

    const button = card.querySelector(".view-button");

    button.addEventListener("click", function () {

        const productId = card.dataset.productId;

        const price = Number(card.dataset.price);

        console.log("Product ID:", productId);

        console.log("Price:", price);
    });
</script>
Expected Console Output after clicking: 
Product ID: 101
Price: 45000

16. Security Considerations

DOM manipulation must be performed carefully when displaying user-generated or externally supplied data.

Prefer textContent for Plain Text

const message = document.createElement("p");

message.textContent = userInput;

textContent treats the supplied value as text rather than parsing it as HTML.

Be Careful with innerHTML

container.innerHTML = userInput;

If userInput contains untrusted HTML or executable markup, inserting it using innerHTML can introduce cross-site scripting (XSS) vulnerabilities.

Use textContent for plain text. If HTML rendering is necessary, validate and sanitize untrusted HTML using an appropriate, trusted sanitization approach.

Do Not Store Sensitive Information in data-* Attributes

Data attributes are visible in the DOM and can be inspected by users through browser developer tools. Never use them to store passwords, authentication tokens, or confidential information.

17. Common Mistakes and Debugging

Mistake 1: Replacing all classes accidentally

element.className = "active";

This replaces all existing classes.

Better approach:

element.classList.add("active");

Mistake 2: Using the wrong dataset property name

<div data-user-id="10"></div>

element.dataset.user-id;

Hyphenated names are not valid dataset property access using dot notation.

Correct approach:

element.dataset.userId;

Mistake 3: Assuming dataset values are numbers

const price = element.dataset.price;

console.log(typeof price);

The result is a string.

Correct approach:

const price = Number(element.dataset.price);

Mistake 4: Using toggle() when a fixed state is required

element.classList.toggle("active");

This changes the class based on its current state. For a known desired state, use: 

element.classList.toggle("active", true);

Mistake 5: Accessing elements before they exist

const button = document.getElementById("submit");

if (button) {
    button.classList.add("ready");
}

Ensure the DOM element exists before accessing its properties or methods.

18. Placement Interview Questions and Answers

Q1. What is classList in JavaScript?

Answer: classList is a DOMTokenList interface that provides methods to manipulate an element's CSS classes.

Q2. What is the difference between className and classList?

Answer: className represents the complete class attribute as a string. classList provides methods to manage individual class tokens.

Q3. What does classList.add() do?

Answer: It adds one or more CSS classes to an element without removing existing classes.

Q4. What is the purpose of classList.toggle()?

Answer: It adds a class if absent and removes it if present. It can also accept a Boolean force parameter.

Q5. What does classList.contains() return?

Answer: It returns true if the specified class exists and false otherwise.

Q6. What does classList.replace() do?

Answer: It replaces an existing class with another class and returns a Boolean indicating whether the replacement occurred.

Q7. What are data-* attributes?

Answer: They are custom HTML attributes used to store application-specific information on elements.

Q8. What is dataset?

Answer: dataset provides JavaScript access to an element's data-* attributes through a DOMStringMap.

Q9. How is data-user-id accessed in JavaScript?

Answer: Use element.dataset.userId.

Q10. What data type does dataset return?

Answer: Dataset values are strings. Explicit conversion is required for numbers and Booleans.

Q11. What is the difference between toggle() and contains()?

Answer: toggle() changes the presence of a class, while contains() only checks whether the class exists.

Q12. Why should sensitive information not be stored in dataset?

Answer: Data attributes are visible and accessible through the DOM and developer tools. They are not a secure storage mechanism.

Q13. Why is textContent safer than innerHTML for user input?

Answer: textContent treats input as plain text instead of parsing it as HTML, reducing the risk of HTML injection and XSS.
