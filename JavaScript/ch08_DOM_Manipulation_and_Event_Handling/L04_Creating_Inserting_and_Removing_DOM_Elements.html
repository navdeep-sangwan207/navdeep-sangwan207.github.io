Lesson 04: Creating, Inserting and Removing DOM Elements

Learn how to build dynamic webpages by creating new HTML elements, inserting them into the DOM, replacing existing elements, and removing unwanted content using JavaScript.

1. Learning Objectives

  • Create HTML elements dynamically using createElement().
  • Create text nodes using createTextNode().
  • Insert elements using append(), appendChild(), and prepend().
  • Understand before(), after(), and insertBefore().
  • Replace elements using replaceWith() and replaceChild().
  • Remove elements using remove() and removeChild().
  • Move existing DOM elements and understand cloning.
  • Build dynamic lists and reusable UI components.

2. Why Create DOM Elements Dynamically?

In modern frontend applications, webpage content often changes based on user interactions or data received from APIs. Developers cannot always define every element directly in the initial HTML.

JavaScript DOM methods allow applications to create, insert, update, and remove elements while the page is running.

Practical Examples

  • Adding products to a shopping cart.
  • Displaying search results from an API.
  • Creating notifications and alert messages.
  • Adding new rows to a table.
  • Building task lists and comment sections.
  • Generating dashboard cards dynamically.

3. Creating Elements Using createElement()

The document.createElement() method creates a new HTML element. The new element exists as a DOM object but is not displayed until it is inserted into the document.

Syntax

const element = document.createElement("tagName");

Example: Creating a Paragraph

<div id="container"></div>

<script>
    const paragraph = document.createElement("p");

    paragraph.textContent = "This paragraph was created using JavaScript.";

    console.log(paragraph);
</script>

The paragraph object is created, but it is not yet part of the visible document.

Setting Attributes and Classes

const image = document.createElement("img");

image.src = "profile.jpg";
image.alt = "User profile";
image.className = "profile-image";
image.width = 150;

The created image can be inserted into the page using an insertion method.

4. Creating Text Nodes Using createTextNode()

The document.createTextNode() method creates a text node containing the specified text.

Syntax

const textNode = document.createTextNode("Text content");

Example

const paragraph = document.createElement("p");

const text = document.createTextNode(
    "Learning JavaScript DOM"
);

paragraph.appendChild(text);

console.log(paragraph.textContent);
Expected Console Output: 
Learning JavaScript DOM

The text node becomes a child of the paragraph after appendChild() is called.

5. appendChild()

The appendChild() method inserts a node as the last child of a specified parent element.

Syntax

parent.appendChild(child);

Example

<ul id="skills">
    <li>HTML</li>
    <li>CSS</li>
</ul>

<script>
    const list = document.getElementById("skills");

    const item = document.createElement("li");

    item.textContent = "JavaScript";

    list.appendChild(item);
</script>
Expected Browser Display: 
HTML
CSS
JavaScript

Important Characteristics

  • It inserts the node at the end of the parent's child list.
  • It accepts a single Node object.
  • It returns the appended node.
  • If the node already exists elsewhere in the DOM, it is moved rather than duplicated.

6. append()

The append() method inserts one or more nodes or strings at the end of an element's child list.

Syntax

parent.append(node1, node2, "text");

Example

<div id="container">
    Existing Content
</div>

<script>
    const container =
        document.getElementById("container");

    const heading = document.createElement("h2");
    heading.textContent = "New Heading";

    const paragraph = document.createElement("p");
    paragraph.textContent = "New Paragraph";

    container.append(heading, paragraph, "Additional text");
</script>

append() vs appendChild()

Feature append() appendChild()
Accepts nodes Yes Yes
Accepts strings Yes No, it requires a Node.
Multiple arguments Yes No, accepts one node.
Return value undefined Returns the appended node.

7. prepend()

The prepend() method inserts one or more nodes or strings at the beginning of an element's child list.

Syntax

parent.prepend(node1, node2, "text");

Example

<ul id="menu">
    <li>Home</li>
    <li>Services</li>
</ul>

<script>
    const menu = document.getElementById("menu");

    const item = document.createElement("li");

    item.textContent = "Dashboard";

    menu.prepend(item);
</script>
Expected Browser Display: 
Dashboard
Home
Services

8. before() and after()

The before() and after() methods insert nodes or strings immediately before or after an element as siblings.

before() Syntax

element.before(newNode);

after() Syntax

element.after(newNode);

Example

<p id="target">Target Paragraph</p>

<script>
    const target = document.getElementById("target");

    const beforeText = document.createElement("p");
    beforeText.textContent = "Before Target";

    const afterText = document.createElement("p");
    afterText.textContent = "After Target";

    target.before(beforeText);
    target.after(afterText);
</script>
Expected Browser Display: 
Before Target
Target Paragraph
After Target
before() and after() insert siblings. In contrast, prepend() and append() insert children inside an element.

9. insertBefore()

The insertBefore() method inserts a node before a specified reference child of a parent element.

Syntax

parent.insertBefore(newNode, referenceNode);

Example

<ul id="skills">
    <li>HTML</li>
    <li id="css">CSS</li>
    <li>JavaScript</li>
</ul>

<script>
    const list = document.getElementById("skills");
    const cssItem = document.getElementById("css");

    const newItem = document.createElement("li");
    newItem.textContent = "Git";

    list.insertBefore(newItem, cssItem);
</script>
Expected Browser Display: 
HTML
Git
CSS
JavaScript

Inserting at the End

list.insertBefore(newItem, null);

Passing null as the reference node inserts the new node at the end of the parent's child list.

10. Replacing Elements Using replaceWith()

The replaceWith() method replaces an element with one or more nodes or strings.

Syntax

oldElement.replaceWith(newNode);

Example

<h2 id="oldHeading">Old Heading</h2>

<script>
    const oldHeading =
        document.getElementById("oldHeading");

    const newHeading = document.createElement("h2");

    newHeading.textContent = "New Heading";

    oldHeading.replaceWith(newHeading);
</script>
Expected Browser Display: 
New Heading

11. Replacing Elements Using replaceChild()

The replaceChild() method replaces an existing child node with a new node inside a parent.

Syntax

parent.replaceChild(newNode, oldNode);

Example

<ul id="list">
    <li id="oldItem">Old Item</li>
</ul>

<script>
    const list = document.getElementById("list");
    const oldItem = document.getElementById("oldItem");

    const newItem = document.createElement("li");
    newItem.textContent = "New Item";

    list.replaceChild(newItem, oldItem);
</script>
Expected Browser Display: 
New Item

replaceWith() vs replaceChild()

Feature replaceWith() replaceChild()
Called on The element being replaced. The parent element.
Arguments One or more nodes or strings. New node followed by old node.
Return value undefined Returns the replaced old node.

12. Removing Elements Using remove()

The remove() method removes an element directly from its parent in the DOM tree.

Syntax

element.remove();

Example

<p id="message">This paragraph will be removed.</p>

<script>
    const message = document.getElementById("message");

    message.remove();
</script>

After the method runs, the paragraph is removed from the document.

13. Removing Elements Using removeChild()

The removeChild() method removes a specified child node from its parent.

Syntax

parent.removeChild(child);

Example

<ul id="skills">
    <li>HTML</li>
    <li id="css">CSS</li>
    <li>JavaScript</li>
</ul>

<script>
    const list = document.getElementById("skills");
    const cssItem = document.getElementById("css");

    const removedItem = list.removeChild(cssItem);

    console.log(removedItem.textContent);
</script>
Expected Console Output: 
CSS
Expected Browser Display: 
HTML
JavaScript

remove() vs removeChild()

Feature remove() removeChild()
Called on The element to remove. The parent element.
Argument No argument. The child node to remove.
Return value undefined Returns the removed child node.

14. Moving Existing DOM Elements

When an existing DOM node is inserted into another location, it is moved from its original parent. JavaScript does not automatically create a duplicate.

Example

<div id="container1">
    <p id="message">Hello</p>
</div>

<div id="container2"></div>

<script>
    const message = document.getElementById("message");
    const container2 = document.getElementById("container2");

    container2.appendChild(message);
</script>

The paragraph is moved from container1 to container2. It no longer remains inside its original parent.

15. Cloning DOM Elements

The cloneNode() method creates a copy of an existing DOM node.

Syntax

element.cloneNode(false);
element.cloneNode(true);
Argument Behavior
false Creates a shallow clone without child nodes.
true Creates a deep clone including descendant nodes.

Example: Deep Cloning

<div id="card">
    <h2>Product</h2>
    <p>Laptop</p>
</div>

<div id="container"></div>

<script>
    const card = document.getElementById("card");
    const container = document.getElementById("container");

    const copy = card.cloneNode(true);

    container.appendChild(copy);
</script>
cloneNode() copies DOM structure and attributes, but does not copy event listeners registered using addEventListener() or the element's JavaScript event-handler properties. Be careful with duplicated IDs when cloning elements.

16. Complete Practical Example: Dynamic Task List

This example demonstrates creating, inserting, and removing elements in a simple task list. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Dynamic Task List</title>
</head>
<body>

    <h1>My Tasks</h1>

    <ul id="taskList">
        <li>Learn HTML</li>
        <li>Learn CSS</li>
    </ul>

    <button id="addTask">Add Task</button>
    <button id="removeTask">Remove Last Task</button>

    <script>
        const taskList = document.getElementById("taskList");
        const addButton = document.getElementById("addTask");
        const removeButton = document.getElementById("removeTask");

        let taskNumber = 3;

        addButton.addEventListener("click", function () {
            const item = document.createElement("li");

            item.textContent = "Task " + taskNumber;

            taskList.appendChild(item);

            taskNumber++;
        });

        removeButton.addEventListener("click", function () {
            if (taskList.lastElementChild) {
                taskList.lastElementChild.remove();
            }
        });
    </script>

</body>
</html>

Expected Behavior

  • The initial list contains Learn HTML and Learn CSS.
  • Clicking Add Task inserts a new task at the end.
  • Each new task receives an increasing task number.
  • Clicking Remove Last Task removes the last list item.
  • The removal button does nothing when the list is empty.

This example uses addEventListener(), which is covered in detail in the event-handling lessons of this chapter.

17. DOM Insertion Methods: Quick Comparison

Method Insertion Position
appendChild() Last child of the parent.
append() At the end of the parent's child list.
prepend() At the beginning of the parent's child list.
before() Immediately before the reference element as a sibling.
after() Immediately after the reference element as a sibling.
insertBefore() Before a specified child of a parent.
replaceWith() Replaces the reference element with supplied content.

18. Common Mistakes and Debugging

Mistake 1: Creating an element but not inserting it

const heading = document.createElement("h2");

heading.textContent = "Welcome";

The element exists in memory but is not displayed because it has not been inserted into the document.

Solution:

document.body.appendChild(heading);

Mistake 2: Using the wrong parent for insertBefore()

parent.insertBefore(newNode, referenceNode);

The reference node must be a child of the specified parent. Otherwise, the browser throws a NotFoundError DOMException.

Mistake 3: Removing an element that is not a child

parent.removeChild(child);

If child is not a child of parent, removeChild() throws a NotFoundError DOMException.

Mistake 4: Trying to insert the same node twice

container1.appendChild(item);
container2.appendChild(item);

The second statement moves item into container2. It does not create a second copy.

Solution:

const copy = item.cloneNode(true);

container2.appendChild(copy);

Mistake 5: Forgetting to check whether an element exists

const list = document.getElementById("taskList");

if (list) {
    list.appendChild(document.createElement("li"));
}

Always verify that the required parent or reference element exists before using it.

19. Placement Interview Questions and Answers

Q1. How do you create an HTML element using JavaScript?

Answer: Use document.createElement("tagName").

Q2. What is the difference between append() and appendChild()?

Answer: append() accepts multiple nodes or strings and returns undefined. appendChild() accepts one node and returns the appended node.

Q3. What is the difference between append() and prepend()?

Answer: append() inserts content at the end of the child list, while prepend() inserts it at the beginning.

Q4. What is the difference between before() and prepend()?

Answer: before() inserts content as a sibling before an element. prepend() inserts content as the first child inside an element.

Q5. What does insertBefore() do?

Answer: It inserts a new node before a specified reference child of a parent.

Q6. What is the difference between remove() and removeChild()?

Answer: remove() is called directly on the element to remove. removeChild() is called on its parent and requires the child as an argument.

Q7. What is cloneNode()?

Answer: It creates a copy of a DOM node. Passing true creates a deep clone including descendants.

Q8. Does appendChild() duplicate an existing node?

Answer: No. It moves the existing node to the new parent. Use cloneNode() when a copy is required.

Q9. What is createTextNode()?

Answer: It creates a text node containing the specified string.

Q10. What happens when insertBefore() receives null as its second argument?

Answer: The new node is inserted at the end of the parent's child list.

Q11. Does cloneNode(true) copy event listeners?

Answer: No. It copies the DOM structure and attributes, but not listeners registered using addEventListener().

Q12. What error occurs if removeChild() receives a node that is not a child of the parent?

Answer: The browser throws a NotFoundError DOMException.

21. Lesson Summary

  • createElement() creates a new HTML element.
  • createTextNode() creates a text node.
  • appendChild() inserts one node as the last child.
  • append() inserts multiple nodes or strings at the end.
  • prepend() inserts content at the beginning.
  • before() and after() insert sibling content.
  • insertBefore() inserts a node before a reference child.
  • replaceWith() and replaceChild() replace existing nodes.
  • remove() and removeChild() remove DOM nodes.
  • cloneNode() creates shallow or deep copies.
  • Inserting an existing node moves it from its previous location.
  • DOM manipulation is essential for building dynamic interfaces.
