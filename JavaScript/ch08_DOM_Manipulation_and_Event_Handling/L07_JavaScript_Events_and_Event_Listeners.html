Lesson 7: JavaScript Events and Event Listeners

Understand browser events, event handling, addEventListener(), event types and practical event-driven programming.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand events in JavaScript.
  • Identify common browser and user-interaction events.
  • Register event handlers using addEventListener().
  • Handle mouse, keyboard, form and window events.
  • Use event listener options such as once and capture.
  • Remove event listeners using removeEventListener().
  • Build practical event-driven applications.

2. What Are JavaScript Events?

An event is an action or occurrence detected by the browser that JavaScript can respond to.

Events may be generated by:

  • User interactions, such as clicking a button.
  • Keyboard actions, such as pressing Enter.
  • Form interactions, such as submitting a form.
  • Browser activities, such as loading a page.
  • Changes in an element, such as an input value changing.

Example: Button Click Event

<button id="myButton">Click Me</button>

<script>
    const button = document.getElementById("myButton");

    button.addEventListener("click", function () {
        alert("Button clicked!");
    });
</script>

Explanation:

  1. The button is selected using getElementById().
  2. addEventListener() registers a click handler.
  3. When the user clicks the button, the callback executes.

3. Event Handling Methods

JavaScript provides different approaches to handling events.

3.1 Inline Event Handling

<button onclick="showMessage()">Click</button>

<script>
    function showMessage() {
        alert("Hello!");
    }
</script>

3.2 DOM Event Handler Property

const button = document.getElementById("btn");

button.onclick = function () {
    alert("Button clicked");
};

3.3 addEventListener()

const button = document.getElementById("btn");

button.addEventListener("click", function () {
    alert("Button clicked");
});
Method Characteristics
Inline HTML handler Event code is written directly in an HTML attribute.
DOM event property Assigns a handler to a property such as onclick.
addEventListener() Allows multiple listeners for the same event on an element.
Placement recommendation: Prefer addEventListener() in modern JavaScript applications. It separates HTML structure from JavaScript behavior and supports multiple listeners for the same event.

4. addEventListener() Syntax

element.addEventListener(eventType, callback, options);
Parameter Description
eventType Event name as a string, such as "click".
callback Function executed when the event occurs.
options Optional configuration for event handling.

Example

const button = document.querySelector("#submitBtn");

function handleClick() {
    console.log("Submit button clicked");
}

button.addEventListener("click", handleClick);

Using an Arrow Function

button.addEventListener("click", () => {
    console.log("Button clicked");
});

Using a Named Function

function greet() {
    console.log("Welcome to JavaScript");
}

button.addEventListener("click", greet);
Do not write greet() when passing the function reference to addEventListener(). Writing parentheses executes the function immediately instead of registering it as a callback.

5. Common JavaScript Event Types

5.1 Mouse Events

Event Description
click Element is clicked.
dblclick Element is double-clicked.
mousedown Mouse button is pressed.
mouseup Mouse button is released.
mousemove Mouse pointer moves over an element.
mouseover Pointer enters an element or one of its descendants.
mouseout Pointer leaves an element or one of its descendants.
mouseenter Pointer enters an element without bubbling.
mouseleave Pointer leaves an element without bubbling.

Example: Mouse Events

const box = document.querySelector("#box");

box.addEventListener("mouseenter", function () {
    box.style.backgroundColor = "lightblue";
});

box.addEventListener("mouseleave", function () {
    box.style.backgroundColor = "white";
});

5.2 Keyboard Events

Event Description
keydown Fires when a key is pressed down.
keyup Fires when a key is released. 
document.addEventListener("keydown", function (event) {
    console.log("Key pressed:", event.key);
});

document.addEventListener("keyup", function (event) {
    console.log("Key released:", event.key);
});
Important: The keypress event is deprecated. Use keydown and keyup for modern keyboard event handling.

5.3 Form Events

Event Description
input Fires when the value of an input changes through user interaction.
change Fires when a value change is committed.
submit Fires when a form is submitted.
focus Element receives focus.
blur Element loses focus. 
const input = document.querySelector("#username");

input.addEventListener("input", function () {
    console.log("Current value:", input.value);
});

5.4 Window and Document Events

Event Description
DOMContentLoaded HTML document has been parsed and the DOM is ready.
load Page and dependent resources have finished loading.
resize Browser viewport is resized.
scroll Document or element is scrolled. 
window.addEventListener("resize", function () {
    console.log("Window width:", window.innerWidth);
});

window.addEventListener("scroll", function () {
    console.log("Page is scrolling");
});

Move your mouse over this box

Key information appears here.

Your name will appear here.

Example 6: Focus and Blur Events

Input is not focused.

const focusInput = document.getElementById("focusInput");
const focusResult = document.getElementById("focusResult");

focusInput.addEventListener("focus", function () {
    focusResult.textContent = "Input is focused.";
});

focusInput.addEventListener("blur", function () {

Example 7: Form Submit Event

const form = document.getElementById("demoForm");
const formName = document.getElementById("formName");
const formResult = document.getElementById("formResult");

form.addEventListener("submit", function (event) {
    event.preventDefault();

    formResult.textContent =
        "Welcome, " + formName.value;
});

The submit handler uses preventDefault() to stop the browser's normal form submission. This method is covered in detail in Lesson 9.

7. Event Listener Options

The third argument of addEventListener() can be a Boolean or an options object.

7.1 once

The once option automatically removes the listener after it has executed once. 

const button = document.querySelector("#onceBtn");

button.addEventListener("click", function () {
    console.log("This message appears only once");
}, { once: true });

7.2 capture

The capture option controls whether the listener participates in the capturing phase instead of the default bubbling phase. 

element.addEventListener("click", handler, {
    capture: true
});

7.3 passive

A passive listener promises not to call preventDefault(). This can help the browser optimize certain events, particularly scrolling-related events. 

window.addEventListener("scroll", function () {
    console.log("Scrolling...");
}, {
    passive: true
});

7.4 signal

An AbortSignal can be used to remove a listener by aborting its associated controller. 

const controller = new AbortController();

button.addEventListener("click", function () {
    console.log("Button clicked");
}, {
    signal: controller.signal
});

// Remove the registered listener
controller.abort();

Options Summary

Option Purpose
capture Registers the listener for the capturing phase when true.
once Automatically removes the listener after its first execution.
passive Indicates that the listener will not cancel the event.
signal Allows removal through an AbortSignal.

8. Removing Event Listeners

removeEventListener() removes a previously registered event listener.

Syntax

element.removeEventListener(eventType, callback, options);

Example

const button = document.querySelector("#myButton");

function showMessage() {
    console.log("Button clicked");
}

// Register listener
button.addEventListener("click", showMessage);

// Remove listener
button.removeEventListener("click", showMessage);
Important: To remove a listener, use the same event type, function reference and matching capture setting. An anonymous function cannot normally be removed by writing another anonymous function with identical code.

Incorrect Approach

button.addEventListener("click", function () {
    console.log("Clicked");
});

// This does not remove the earlier anonymous function
button.removeEventListener("click", function () {
    console.log("Clicked");
});

Correct Approach

function handleClick() {
    console.log("Clicked");
}

button.addEventListener("click", handleClick);
button.removeEventListener("click", handleClick);

9. Practical Placement Example: Character Counter

Character counters are commonly used in forms, feedback applications and text input interfaces.

Complete HTML and JavaScript

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Character Counter</title>
</head>
<body>

    <h2>Feedback Form</h2>

    <textarea id="feedback"
              maxlength="100"
              placeholder="Write your feedback"></textarea>

    <p>Characters:
        <span id="count">0</span> / 100
    </p>

    <script>
        const feedback =
            document.getElementById("feedback");

        const count =
            document.getElementById("count");

        feedback.addEventListener("input", function () {
            count.textContent = feedback.value.length;
        });
    </script>

</body>
</html>

Expected Result

  • Initially, the counter displays 0 / 100.
  • When the user types 10 characters, it displays 10 / 100.
  • The browser prevents entering more than 100 characters because of maxlength.

10. Common Mistakes and Debugging

Mistake 1: Incorrect Event Name

// Incorrect
button.addEventListener("onclick", handler);

// Correct
button.addEventListener("click", handler);

addEventListener() accepts the event name without the "on" prefix.

Mistake 2: Calling Instead of Passing a Function

// Incorrect
button.addEventListener("click", handleClick());

// Correct
button.addEventListener("click", handleClick);

Mistake 3: Selecting an Element Before It Exists

// Potential problem if the script runs before the button exists
const button = document.getElementById("myButton");

button.addEventListener("click", handler);

Solutions include:

  • Place the script before the closing body tag.
  • Use the defer attribute on an external script.
  • Wait for DOMContentLoaded before selecting elements.
document.addEventListener("DOMContentLoaded", function () {
    const button = document.getElementById("myButton");

    button.addEventListener("click", function () {
        console.log("Ready");
    });
});

Mistake 4: Replacing Existing Event Handlers

// First assignment
button.onclick = function () {
    console.log("First handler");
};

// Second assignment replaces the first handler
button.onclick = function () {
    console.log("Second handler");
};

Use addEventListener() when multiple independent handlers are required.

Mistake 5: Forgetting to Remove Unnecessary Listeners

Repeatedly registering listeners can cause the same callback to execute multiple times. Avoid unnecessary registrations, especially when initializing components dynamically.

11. Placement Interview Questions and Answers

Q1. What is an event in JavaScript?

An event is an action or occurrence detected by the browser, such as a click, key press, form submission or page load. JavaScript can register handlers to respond to these events.

Q2. What is addEventListener()?

It is a DOM method used to register an event listener on an element, document or window. It supports multiple listeners for the same event type.

Q3. What is the difference between onclick and addEventListener()?

onclick is an event handler property that generally holds one handler at a time. addEventListener() allows multiple listeners and supports options such as capture, once and passive.

Q4. Can multiple event listeners be attached to one element?

Yes. Multiple listeners can be registered for the same event type using addEventListener().

Q5. What is the difference between keydown and keyup?

keydown fires when a key is pressed down. keyup fires when the key is released.

Q6. What is the difference between input and change events?

input fires as the user changes a value. change fires when a value change is committed. The exact timing depends on the form control.

Q7. What is the purpose of the once option?

It automatically removes an event listener after its first execution.

Q8. Why should named functions be used for removable listeners?

removeEventListener() needs the same function reference that was originally registered. A named function makes that reference available.

Q9. What is a passive event listener?

It is a listener registered with passive: true, indicating that it will not call preventDefault() to cancel the event.

Q10. What is the difference between mouseover and mouseenter?

mouseover bubbles and can fire when entering descendant elements. mouseenter does not bubble and fires when the pointer enters the element itself.

Q11. What is DOMContentLoaded?

It fires when the HTML document has been completely parsed and the DOM tree is ready. It does not wait for all images, stylesheets and other dependent resources to finish loading.

Q12. Can an event listener be removed automatically?

Yes. The once option removes it after one execution. An AbortSignal can also be used to remove listeners programmatically.

13. Lesson Summary

  • Events allow JavaScript to respond to browser and user actions.
  • addEventListener() is the preferred modern event registration method.
  • Common events include click, dblclick, input, change, submit, keydown and keyup.
  • Named functions make event listeners easier to remove.
  • Event listener options include capture, once, passive and signal.
  • removeEventListener() removes a registered event listener.
  • Event-driven programming is essential for interactive frontend applications.
