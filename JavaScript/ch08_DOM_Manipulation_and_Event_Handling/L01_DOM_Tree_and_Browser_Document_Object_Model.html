Lesson 01: DOM Tree and Browser Document Object Model

Understand how browsers represent HTML documents as objects and how JavaScript accesses and manipulates webpage structure through the Document Object Model.

1. Learning Objectives

  • Understand what the Document Object Model (DOM) is.
  • Understand how browsers convert HTML into a DOM tree.
  • Identify document, element, text, and attribute nodes.
  • Understand the relationship between HTML, DOM, and JavaScript.
  • Use the document object to access basic document information.
  • Inspect DOM objects using browser developer tools.

2. What Is the DOM?

The Document Object Model (DOM) is a programming interface provided by the browser that represents an HTML or XML document as a structured tree of objects called nodes.

JavaScript uses DOM APIs to access and modify webpage content, structure, and attributes. It can also create new elements, remove existing elements, and respond to user interactions.

Example

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>Learning JavaScript DOM</p>
</body>
</html>

The browser parses this HTML and creates an in-memory DOM representation. JavaScript can then access elements such as the heading and paragraph through the document object.

Important: The DOM is not the HTML source code itself. It is the browser's object-based representation of the parsed document.

3. How the Browser Creates the DOM

When a browser loads an HTML document, it parses the HTML markup and constructs a tree of nodes representing the document structure.

  1. The browser receives the HTML document.
  2. The HTML parser processes the markup.
  3. HTML elements and text are represented as DOM nodes.
  4. The browser builds the DOM tree according to document structure.
  5. JavaScript can access the resulting document through DOM APIs.

CSS is parsed separately into the CSS Object Model (CSSOM). The browser combines the DOM and CSSOM to calculate styles and construct the render tree used in rendering.

The DOM is not the same as the render tree. The render tree is a rendering-related structure and does not include every DOM node.

4. Understanding the DOM Tree

A DOM tree represents document structure using parent-child relationships. The document node is the root of the document tree, and the html element is its document element.

Example HTML

<html>
    <head>
        <title>DOM Example</title>
    </head>

    <body>
        <h1>Hello</h1>
        <p>Welcome to JavaScript</p>
    </body>
</html>

Simplified DOM tree

Document
└── html
    ├── head
    │   └── title
    │       └── "DOM Example"
    └── body
       ├── h1
       │   └── "Hello"
       └── p
          └── "Welcome to JavaScript"

Important relationships

Relationship Meaning
Parent An element or node that directly contains another node.
Child A node directly contained inside another node.
Sibling Nodes that share the same parent.
Ancestor A node higher in the tree hierarchy.
Descendant A node located anywhere below another node.

5. Types of DOM Nodes

Every DOM node has a node type. Understanding node types is useful when traversing and manipulating the DOM.

Node Type nodeType Value Description
Element 1 Represents an HTML element such as div, p, or h1.
Attribute 2 Represents an attribute node. Attribute nodes are accessed through attribute APIs.
Text 3 Represents text inside an element.
Comment 8 Represents an HTML comment.
Document 9 Represents the entire document.
Document Type 10 Represents the document type declaration.

Example: Checking Node Types

<h1 id="heading">Hello DOM</h1>

<script>
    const heading = document.getElementById("heading");

    console.log(document.nodeType);
    console.log(heading.nodeType);
    console.log(heading.firstChild.nodeType);
</script>
Expected Console Output: 
9
1
3

Explanation:

  • document is a Document node.
  • heading is an Element node.
  • Its text content is a Text node.

6. The document Object

The document object is the entry point for accessing the current HTML document through JavaScript. It provides properties and methods for working with document structure and content.

Common document properties

Property Purpose
document.title Gets or sets the document title.
document.URL Returns the document URL.
document.domain Returns the document's domain, subject to browser security restrictions and deprecation considerations.
document.documentElement Returns the root html element.
document.body Returns the body element when available.
document.head Returns the head element.
document.characterSet Returns the document character encoding.

Example: Accessing Document Information

console.log("Title:", document.title);
console.log("URL:", document.URL);
console.log("Root:", document.documentElement);
console.log("Body:", document.body);
console.log("Head:", document.head);
console.log("Encoding:", document.characterSet);

The exact output depends on the HTML page and the URL from which it is loaded.

7. Accessing HTML Elements Through JavaScript

JavaScript accesses DOM elements through the document object. Once an element is selected, its properties and methods can be used to inspect or modify it.

Complete Example: DOM Access

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>DOM Access Example</title>
</head>
<body>

    <h1 id="heading">Welcome to JavaScript</h1>

    <p id="description">Learning the DOM</p>

    <script>
        const heading = document.getElementById("heading");
        const description = document.getElementById("description");

        console.log(heading.textContent);
        console.log(description.textContent);

        heading.textContent = "DOM Programming";
    </script>

</body>
</html>

8. DOM vs HTML Source Code

HTML Source DOM
Written using HTML markup. Represented as objects and nodes.
Defines the initial document structure. Represents the browser's parsed document structure.
Can be viewed using View Page Source. Can be inspected using browser developer tools.
Does not automatically reflect JavaScript changes. Reflects changes made to the live document structure.
Interview concept: View Page Source generally displays the original server-delivered HTML, while the Elements panel in Developer Tools displays the live DOM after browser parsing and JavaScript modifications.

9. DOM and the Browser Developer Tools

Browser Developer Tools help developers inspect the DOM, debug JavaScript, monitor events, and identify webpage structure or rendering problems.

How to inspect the DOM in Chrome

  1. Open a webpage in Google Chrome.
  2. Press F12 or Ctrl + Shift + I.
  3. Select the Elements tab.
  4. Expand HTML elements to inspect the DOM tree.
  5. Select an element to inspect its attributes and styles.
  6. Open the Console tab to execute JavaScript commands.

Useful Console Commands

document
document.body
document.documentElement
document.title
document.body.innerHTML
document.body.textContent

These commands provide quick access to the current document and its content.

10. Common Mistakes and Debugging

Mistake 1: Accessing an element before it exists

<script>
    const heading = document.getElementById("heading");
    console.log(heading.textContent);
</script>

<h1 id="heading">Hello</h1>

When a script runs before the browser has parsed the heading, the selection may return null. Accessing textContent on null causes a TypeError.

Solution: Place the script after the element

<h1 id="heading">Hello</h1>

<script>
    const heading = document.getElementById("heading");
    console.log(heading.textContent);
</script>

Alternative: Use DOMContentLoaded

document.addEventListener("DOMContentLoaded", function () {
    const heading = document.getElementById("heading");

    console.log(heading.textContent);
});

Mistake 2: Confusing HTML source with the live DOM

JavaScript changes the live DOM. Such changes do not normally rewrite the original HTML source displayed by View Page Source.

Mistake 3: Confusing element nodes and text nodes

An element can contain text nodes, comments, and other elements. Use nodeType or appropriate element-specific properties when the distinction matters.

12. Placement Interview Questions and Answers

Q1. What is the DOM?

Answer: The DOM is a programming interface that represents an HTML document as a tree of objects. JavaScript uses DOM APIs to access and modify document structure, content, and attributes.

Q2. Is DOM a programming language?

Answer: No. DOM is an API specification. JavaScript is commonly used to interact with it in browsers.

Q3. What is the DOM tree?

Answer: It is a hierarchical representation of a document in which nodes are connected through parent-child relationships.

Q4. What is the document object?

Answer: It represents the current document and provides methods and properties to access and manipulate its contents.

Q5. What is the difference between DOM and HTML?

Answer: HTML is markup used to define document structure. The DOM is the browser's object-based representation of the parsed document.

Q6. What is a node in the DOM?

Answer: A node is a basic object in the document tree. Examples include document, element, text, and comment nodes.

Q7. What is the difference between an element and a node?

Answer: A node is a general DOM object category. An element is a specific type of node representing an HTML or XML element.

Q8. What is document.documentElement?

Answer: It returns the root element of the document, normally the html element in an HTML document.

Q9. What is the difference between DOM and CSSOM?

Answer: The DOM represents document structure, while the CSSOM represents CSS rules and computed style information used by the browser.

Q10. Why is DOM important in frontend development?

Answer: It allows JavaScript to create interactive interfaces by reading and modifying webpage content, responding to events, and updating the live document.

14. Lesson Summary

  • DOM stands for Document Object Model.
  • The browser creates a DOM representation by parsing HTML.
  • The DOM organizes document content into a tree of nodes.
  • Elements, text, comments, and the document are different node types.
  • The document object provides access to the current document.
  • JavaScript can inspect and modify the live DOM.
  • Browser Developer Tools help inspect and debug DOM structures.
  • Understanding DOM fundamentals is essential for interactive frontend development.
