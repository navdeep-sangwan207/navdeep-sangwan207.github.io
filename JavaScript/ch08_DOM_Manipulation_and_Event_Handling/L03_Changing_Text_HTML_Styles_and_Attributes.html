Lesson 03: Changing Text, HTML, Styles and Attributes

Learn how JavaScript dynamically updates webpage content, modifies CSS styles, changes element classes, and manages HTML attributes through DOM properties and methods.

1. Learning Objectives

  • Modify text using textContent and innerText.
  • Insert HTML using innerHTML.
  • Understand the differences between textContent, innerText, and innerHTML.
  • Change inline CSS styles using the style property.
  • Modify element classes using className.
  • Read, set, and remove HTML attributes.
  • Understand DOM properties versus HTML attributes.
  • Avoid common DOM security vulnerabilities such as XSS.

2. Changing Text Using textContent

The textContent property gets or sets the text content of an element and its descendants.

Syntax

element.textContent;
element.textContent = "New text";

Example: Updating Text

<h1 id="heading">Old Heading</h1>

<script>
    const heading = document.getElementById("heading");

    console.log(heading.textContent);

    heading.textContent = "Welcome to JavaScript DOM";
</script>
Expected Console Output: 
Old Heading
Expected Browser Display After JavaScript Runs: 
Welcome to JavaScript DOM

textContent with Nested Elements

<div id="container">
    Hello
    <strong>JavaScript</strong>
</div>

<script>
    const container =
        document.getElementById("container");

    console.log(container.textContent);
</script>

The returned text includes the text content of descendant elements. Whitespace and line breaks from the HTML source may also appear.

3. Changing Text Using innerText

The innerText property gets or sets the rendered text content of an element.

Syntax

element.innerText;
element.innerText = "New visible text";

Example

<div id="content">
    Hello
    <span style="display: none;">Hidden Text</span>
    <strong>World</strong>
</div>

<script>
    const content = document.getElementById("content");

    console.log(content.textContent);
    console.log(content.innerText);
</script>

The two properties can return different results because innerText considers rendered text and CSS visibility, whereas textContent reads text from the DOM tree.

textContent vs innerText

Feature textContent innerText
Reads text From the DOM tree. From rendered text.
Hidden text Includes text from hidden descendants. Generally excludes text that is not rendered.
CSS awareness Does not calculate rendered appearance. Considers CSS and layout.
Performance Generally more efficient. May trigger layout-related calculations.
Common use Reading or updating raw text content. Working with rendered text.
Interview point: textContent is usually preferable when you only need to read or update text. Use innerText when rendered text behavior is specifically required.

4. Changing HTML Using innerHTML

The innerHTML property gets or sets the HTML markup contained inside an element.

Syntax

element.innerHTML;
element.innerHTML = "<strong>New HTML</strong>";

Example: Inserting HTML

<div id="container">
    Original Content
</div>

<script>
    const container =
        document.getElementById("container");

    container.innerHTML =
        "<h2>Updated Content</h2>" +
        "<p>HTML inserted using JavaScript.</p>";
</script>
Expected Browser Display: 
Updated Content

HTML inserted using JavaScript.

Reading HTML Content

<div id="box">
    <strong>Hello</strong>
    <p>Welcome</p>
</div>

<script>
    const box = document.getElementById("box");

    console.log(box.innerHTML);
</script>

The result contains the HTML markup inside the div, including the strong and p tags.

textContent vs innerHTML

const box = document.getElementById("box");

box.textContent = "<strong>Hello</strong>";

This displays the characters as text rather than creating a strong element. 

box.innerHTML = "<strong>Hello</strong>";

This parses the string as HTML and creates a strong element.

Property Purpose
textContent Gets or sets text without interpreting it as HTML.
innerText Gets or sets rendered text.
innerHTML Gets or sets HTML markup inside an element.

5. Security: innerHTML and Cross-Site Scripting (XSS)

Inserting untrusted user input through innerHTML can create a Cross-Site Scripting (XSS) vulnerability.

Unsafe Example

const userInput = getUserInput();

container.innerHTML = userInput;

If userInput contains malicious HTML or event-handler attributes, the browser may interpret the injected markup in a dangerous way.

Safer Text Insertion

const userInput = getUserInput();

container.textContent = userInput;

textContent treats the supplied value as text rather than parsing it as HTML.

Security rule: Do not insert untrusted data into innerHTML. If HTML insertion is genuinely required, use a well-maintained HTML sanitization library and follow a suitable security policy.

6. Changing CSS Styles Using the style Property

Every HTML element exposes a style property that provides access to its inline CSS declarations.

Syntax

element.style.propertyName = "value";

Example

<p id="message">Hello JavaScript</p>

<script>
    const message =
        document.getElementById("message");

    message.style.color = "blue";
    message.style.backgroundColor = "lightyellow";
    message.style.fontSize = "24px";
    message.style.padding = "10px";
    message.style.borderRadius = "8px";
</script>
Expected Browser Display:

Hello JavaScript

CSS Property Naming in JavaScript

CSS properties that contain hyphens are generally written using camelCase when accessed through the style object.

CSS Property JavaScript Property
background-color backgroundColor
font-size fontSize
border-radius borderRadius
margin-top marginTop
text-align textAlign
z-index zIndex

Reading Inline Styles

const box = document.getElementById("box");

console.log(box.style.color);

The style property reads inline styles. It does not automatically return the final style applied by an external stylesheet.

Reading Computed Styles

const box = document.getElementById("box");

const styles = getComputedStyle(box);

console.log(styles.color);
console.log(styles.backgroundColor);
console.log(styles.fontSize);

getComputedStyle() returns a read-only object containing the computed CSS values for an element.

Use CSS classes for reusable styling and complex UI states. Use element.style for small, dynamic inline changes.

7. Modifying Classes Using className

The className property gets or sets the complete class attribute of an element.

Example

<div id="card" class="card">
    Product Information
</div>

<script>
    const card = document.getElementById("card");

    card.className = "card active";
</script>

The element now has two classes: card and active. Assigning className replaces the previous class string.

Adding a Class with className

const card = document.getElementById("card");

card.className += " highlighted";
Be careful when using className += because it can introduce unwanted spaces or duplicate class names. For individual class operations, classList is generally preferable.

8. Working with HTML Attributes

HTML attributes provide additional information about elements. JavaScript can read, create, modify, and remove attributes using DOM methods.

Common Attribute Methods

Method Purpose
getAttribute() Reads an attribute value.
setAttribute() Creates or updates an attribute.
removeAttribute() Removes an attribute.
hasAttribute() Checks whether an attribute exists.
toggleAttribute() Adds an attribute if absent or removes it if present.

getAttribute()

<img id="photo"
     src="photo.jpg"
     alt="Profile photo">

<script>
    const image = document.getElementById("photo");

    console.log(image.getAttribute("src"));
    console.log(image.getAttribute("alt"));
</script>
Expected Console Output: 
photo.jpg
Profile photo

setAttribute()

const image = document.getElementById("photo");

image.setAttribute("alt", "Updated profile image");
image.setAttribute("title", "User profile");

removeAttribute()

image.removeAttribute("title");

hasAttribute()

if (image.hasAttribute("alt")) {
    console.log("Alternative text exists");
} else {
    console.log("Alternative text is missing");
}

toggleAttribute()

const button = document.getElementById("submit");

button.toggleAttribute("disabled");

If the disabled attribute is absent, toggleAttribute() adds it. If it is already present, the method removes it.

9. HTML Attributes vs DOM Properties

HTML attributes are values specified in the markup. DOM properties are JavaScript-accessible properties on the corresponding element objects.

Example

<input id="username"
       value="Navdeep"
       type="text">

<script>
    const input = document.getElementById("username");

    console.log(input.getAttribute("value"));
    console.log(input.value);

    input.value = "Developer";

    console.log(input.getAttribute("value"));
    console.log(input.value);
</script>
Expected Console Output: 
Navdeep
Navdeep
Navdeep
Developer

The value attribute represents the initial/default value in this example, while the value property represents the current input value. Changing the property does not necessarily update the attribute.

HTML Attribute DOM Property
Defined in HTML markup. Exposed through the element object.
Accessed using getAttribute(). Accessed using element.propertyName.
Often represents initial configuration. May represent current runtime state.
Some attributes and properties reflect each other, but not all behave identically. Their relationship depends on the particular HTML element and property.

10. Boolean Attributes

Boolean HTML attributes represent enabled or disabled states through their presence or absence.

Examples include:

  • disabled
  • checked
  • readonly
  • required
  • multiple
  • selected

Example

<button id="submit" disabled>Submit</button>

<script>
    const button = document.getElementById("submit");

    console.log(button.disabled);

    button.disabled = false;

    console.log(button.disabled);
</script>
Expected Console Output: 
true
false

For boolean attributes, the presence of the attribute represents true, even if its written value is "false". Removing the attribute represents false.

11. Complete Practical Example: Dynamic User Profile

This example combines text updates, inline styles, class changes, and attribute modification. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Dynamic User Profile</title>

    <style>
        .profile {
            padding: 15px;
            border: 1px solid #ccc;
            border-radius: 8px;
        }

        .active {
            background-color: lightgreen;
        }
    </style>
</head>

<body>

    <div id="profile" class="profile">
        <h2 id="name">Guest User</h2>
        <p id="status">Inactive</p>
        <img id="photo"
             src="profile.jpg"
             alt="User profile">
    </div>

    <button id="updateButton">Update Profile</button>

    <script>
        const profile = document.getElementById("profile");
        const name = document.getElementById("name");
        const status = document.getElementById("status");
        const photo = document.getElementById("photo");

        name.textContent = "Navdeep";
        status.innerHTML = "<strong>Active Developer</strong>";

        profile.className = "profile active";

        profile.style.borderColor = "green";

        photo.setAttribute("alt", "Navdeep profile photo");
        photo.setAttribute("title", "Developer Profile");

        console.log(name.textContent);
        console.log(status.textContent);
        console.log(profile.getAttribute("class"));
        console.log(photo.getAttribute("alt"));
    </script>

</body>
</html>
Expected Console Output: 
Navdeep
Active Developer
profile active
Navdeep profile photo

The example demonstrates how JavaScript can update multiple parts of a user interface dynamically.

12. Common Mistakes and Debugging

Mistake 1: Using innerHTML for plain text

// Unnecessary HTML parsing
element.innerHTML = "Welcome";

// Better for plain text
element.textContent = "Welcome";

Mistake 2: Confusing innerHTML and textContent

element.textContent = "<b>Hello</b>";

The tags are displayed as text. To create HTML elements, innerHTML parses the string as markup, but it must not receive untrusted content.

Mistake 3: Incorrect CSS property naming

// Incorrect
element.style.background-color = "red";

// Correct
element.style.backgroundColor = "red";

Mistake 4: Replacing all existing classes

// Replaces the entire class attribute
element.className = "active";

This removes any existing class names. Use classList when you need to add or remove individual classes.

Mistake 5: Assuming getAttribute() always returns a string

const value = element.getAttribute("missing");

console.log(value);
Expected Output: 
null

getAttribute() returns null when the requested attribute does not exist.

Mistake 6: Treating a Boolean attribute value as a normal string

// Avoid relying on this for Boolean state
button.setAttribute("disabled", "false");

// Correct way to enable the button
button.disabled = false;

14. Placement Interview Questions and Answers

Q1. What is the difference between textContent and innerHTML?

Answer: textContent reads or updates text without parsing it as HTML. innerHTML reads or updates HTML markup inside an element.

Q2. What is the difference between innerText and textContent?

Answer: innerText considers rendered text and CSS visibility, while textContent reads text from the DOM tree.

Q3. Why can innerHTML be dangerous?

Answer: Inserting untrusted content through innerHTML can introduce XSS vulnerabilities.

Q4. How do you change the background color of an element?

Answer: Use element.style.backgroundColor = "red".

Q5. What is className?

Answer: className is a DOM property used to read or replace the complete class attribute of an element.

Q6. What does setAttribute() do?

Answer: It creates a new attribute or updates the value of an existing attribute.

Q7. What is the difference between getAttribute() and an element property?

Answer: getAttribute() reads the specified HTML attribute. An element property represents a JavaScript-accessible value or state and may differ from the original attribute.

Q8. How do you remove an HTML attribute?

Answer: Use element.removeAttribute("attributeName").

Q9. How can you check whether an attribute exists?

Answer: Use element.hasAttribute("attributeName").

Q10. What does getComputedStyle() do?

Answer: It returns a read-only object containing the computed CSS values applied to an element.

Q11. How do you enable a disabled button?

Answer: Set its disabled property to false: button.disabled = false.

Q12. What is XSS?

Answer: Cross-Site Scripting is a security vulnerability in which attacker-controlled script content is injected into a webpage and executed in a user's browser.
