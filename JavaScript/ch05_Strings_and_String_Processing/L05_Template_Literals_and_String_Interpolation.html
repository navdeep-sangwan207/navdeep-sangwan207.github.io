2. What Are Template Literals?

Template literals are a JavaScript string feature that allows developers to create strings using backticks instead of single or double quotation marks.

They provide convenient support for:

  • Variable interpolation.
  • Expression evaluation.
  • Multiline strings.
  • Dynamic text generation.
  • Tagged template processing.

Syntax

`This is a template literal`

Example

const message = `Welcome to JavaScript`;

console.log(message);
Output: 
Welcome to JavaScript
Template literals use the backtick character (`), generally located near the top-left corner of a standard keyboard.

3. Ordinary Strings Versus Template Literals

Ordinary strings use single or double quotation marks. Template literals use backticks.

Ordinary String

const name = "Navdeep";

const message = "Welcome " + name + " to JavaScript";

console.log(message);
Output: 
Welcome Navdeep to JavaScript

Template Literal

const name = "Navdeep";

const message = `Welcome ${name} to JavaScript`;

console.log(message);
Output: 
Welcome Navdeep to JavaScript
Feature Ordinary Strings Template Literals
Syntax Single or double quotes Backticks
Variable interpolation Requires concatenation Uses ${...}
Multiline strings Require escape sequences or concatenation Supported directly
Expression evaluation Not directly supported inside the string Supported inside ${...}

4. String Interpolation

String interpolation means inserting the value of a variable or expression directly into a string.

Template literals use the following syntax: 

${expression}

Example 1: Inserting a Variable

const name = "Navdeep";

const message = `Hello, ${name}!`;

console.log(message);
Output: 
Hello, Navdeep!

Example 2: Inserting Multiple Variables

const name = "Navdeep";
const course = "JavaScript";
const institute = "NS Learning Hub";

const message = `Hello ${name}, welcome to ${course} at ${institute}.`;

console.log(message);
Output: 
Hello Navdeep, welcome to JavaScript at NS Learning Hub.

Example 3: Inserting Numeric Values

const price = 1500;
const quantity = 3;

const message = `Total amount: ${price * quantity}`;

console.log(message);
Output: 
Total amount: 4500

Example 4: Inserting Boolean Values

const isLoggedIn = true;

const message = `Login status: ${isLoggedIn}`;

console.log(message);
Output: 
Login status: true

5. Expression Evaluation

Expressions inside ${...} are evaluated before the resulting string is created.

Example 1: Arithmetic Expression

const a = 10;
const b = 20;

console.log(`Sum = ${a + b}`);
console.log(`Product = ${a * b}`);
Output: 
Sum = 30
Product = 200

Example 2: Conditional Expression

const marks = 75;

const result = `Result: ${marks >= 40 ? "Pass" : "Fail"}`;

console.log(result);
Output: 
Result: Pass

Example 3: Function Call

function calculateTotal(price, quantity) {
    return price * quantity;
}

const message = `Total: ${calculateTotal(250, 4)}`;

console.log(message);
Output: 
Total: 1000

Example 4: Object Property

const student = {
    name: "Navdeep",
    marks: 85
};

const message = `${student.name} scored ${student.marks} marks.`;

console.log(message);
Output: 
Navdeep scored 85 marks.

Example 5: Array Expression

const subjects = ["C", "C++", "JavaScript"];

console.log(`First subject: ${subjects[0]}`);
console.log(`Total subjects: ${subjects.length}`);
Output: 
First subject: C
Total subjects: 3

6. Multiline Strings

Template literals allow strings to span multiple lines without explicitly using newline escape sequences.

Example 1: Multiline Text

const message = `Welcome to NS Learning Hub.
Learn programming.
Prepare for technical placements.
Build practical projects.`;

console.log(message);
Output: 
Welcome to NS Learning Hub.
Learn programming.
Prepare for technical placements.
Build practical projects.

Example 2: Multiline Address

const address = `Navdeep Sangwan
Sonipat
Haryana
India`;

console.log(address);
Output: 
Navdeep Sangwan
Sonipat
Haryana
India

Example 3: Multiline Text with Variables

const name = "Navdeep";
const course = "JavaScript";

const message = `Student: ${name}
Course: ${course}
Status: Enrolled`;

console.log(message);
Output: 
Student: Navdeep
Course: JavaScript
Status: Enrolled
Newline characters and indentation inside a template literal are preserved as part of its string value.

7. Nested Template Literals

A template literal can contain another template literal inside an interpolation expression. This is useful when generating conditional or dynamic text.

Example 1: Nested Conditional Message

const marks = 85;

const message = `Result: ${
    marks >= 90
        ? "Excellent"
        : marks >= 60
            ? "Good"
            : "Needs Improvement"
}`;

console.log(message);
Output: 
Result: Good

Example 2: Dynamic List Items

const courses = ["C", "C++", "JavaScript"];

const list = `

    
    ${courses.map(course => `
  • ${course}
    • `).join("")}


`;

console.log(list);
Output: 


    
    
  • C
  • C++
  • JavaScript
    •

The map() method creates an array of list-item strings, and join("") combines them into one string. These array methods were covered in Chapter 4.

8. Escaping Characters in Template Literals

Template literals support escape sequences. These allow special characters to be included in the resulting string.

Escape Sequence Meaning
\n Newline
\t Horizontal tab
\\ Backslash
\` Literal backtick
\$ Literal dollar sign when followed by an opening brace to avoid interpolation

Example 1: Newline Escape

const message = `Hello\nJavaScript`;

console.log(message);
Output: 
Hello
JavaScript

Example 2: Tab Escape

const message = `Name:\tNavdeep`;

console.log(message);
Output: 
Name:   Navdeep

Example 3: Including a Backtick

const message = `Use \`backticks\` for template literals.`;

console.log(message);
Output: 
Use `backticks` for template literals.

Example 4: Displaying ${...} Literally

const message = `The syntax is \${name}`;

console.log(message);
Output: 
The syntax is ${name}

9. Tagged Template Literals

A tagged template literal is a template literal preceded by a function name. The function receives the string segments and the interpolated values as arguments.

Basic Syntax

tagFunction`Hello ${name}`;

The tag function receives:

  • An array of literal string segments.
  • The interpolated values as separate arguments.

Example 1: Simple Tagged Template

function showDetails(strings, name, course) {
    console.log(strings);
    console.log(name);
    console.log(course);
}

const student = "Navdeep";
const subject = "JavaScript";

showDetails`Student: ${student}, Course: ${subject}`;
Output: 
[ "Student: ", ", Course: ", "" ]
Navdeep
JavaScript

The strings array contains the literal portions surrounding the interpolation expressions. The remaining arguments contain their evaluated values.

Example 2: Custom Formatting Tag

function formatMessage(strings, name, course) {
    return `${strings[0]}${name.toUpperCase()}${strings[1]}${course.toUpperCase()}${strings[2]}`;
}

const name = "Navdeep";
const course = "JavaScript";

const result = formatMessage`Student: ${name}, Course: ${course}`;

console.log(result);
Output: 
Student: NAVDEEP, Course: JAVASCRIPT

Example 3: Using Rest Parameters in a Tag Function

function display(strings, ...values) {
    console.log("String parts:", strings);
    console.log("Values:", values);
}

const name = "Navdeep";
const age = 25;

display`Name: ${name}, Age: ${age}`;
Output: 
String parts: ["Name: ", ", Age: ", ""]
Values: ["Navdeep", 25]
Tagged templates are useful for specialized formatting and processing. They are also used by libraries for localization, SQL query construction and styling systems.

10. Practical Application: Dynamic User Profile

Template literals are commonly used to create dynamic messages from application data. 

const user = {
    name: "Navdeep",
    role: "Frontend Developer",
    location: "India"
};

const profile = `
User Profile
------------
Name: ${user.name}
Role: ${user.role}
Location: ${user.location}
`;

console.log(profile);
Output: 

User Profile
------------
Name: Navdeep
Role: Frontend Developer
Location: India

11. Practical Application: Dynamic HTML Generation

Template literals can generate HTML strings containing dynamic application data. 

const product = {
    name: "Wireless Mouse",
    price: 799,
    category: "Electronics"
};

const card = `


    
${product.name}

    
Price: ₹${product.price}

    
Category: ${product.category}



`;

console.log(card);

The generated string can be used by a frontend application to display dynamic content.

Never insert untrusted user input directly into HTML using innerHTML. Template literals do not automatically escape HTML. Untrusted content can create cross-site scripting (XSS) vulnerabilities. Prefer textContent or safe DOM APIs for user-provided text.

12. Practical Application: Generating an Invoice

const invoice = {
    customer: "Navdeep",

    price: 1200,
    quantity: 2

const total = invoice.price * invoice.quantity;

const receipt = `

Quantity: ${invoice.quantity}
--------------------

console.log(receipt);
Output:

--------------------

Total: ₹2400

13. Template Literals and Function Return Values

Template literals can directly include the result returned by a function. 

function getFullName(firstName, lastName) {
    return `${firstName} ${lastName}`;
}

const message = `Welcome, ${getFullName("Navdeep", "Sangwan")}!`;

console.log(message);
Output: 
Welcome, Navdeep Sangwan!

14. Common Mistakes and Debugging

Mistake Correct Understanding
Using single quotes instead of backticks for interpolation. Use backticks when using ${...} interpolation.
Writing $name instead of ${name}. Interpolation requires the dollar sign and braces.
Forgetting the closing backtick. Every template literal must have matching backticks.
Using ${...} outside a template literal. Interpolation syntax belongs inside a template literal.
Assuming whitespace is automatically removed. Template literals preserve whitespace and line breaks.
Assuming template literals sanitize HTML. They only construct strings; they do not sanitize untrusted input.
Confusing a tag function with an ordinary function call. A tag function receives the literal segments and interpolated values separately.

15. Placement Interview Questions and Answers

Q1. What are template literals?

Template literals are strings written using backticks. They support interpolation, multiline strings and tagged template processing.

Q2. What is string interpolation?

It is the process of inserting variables or expressions into a string using ${...}.

Q3. What is the difference between string concatenation and interpolation?

Concatenation combines strings using operators such as +. Interpolation inserts values directly into a template literal using ${...}.

Q4. Can template literals contain multiline strings?

Yes. Line breaks are preserved directly.

Q5. Can we evaluate expressions inside template literals?

Yes. Expressions inside ${...} are evaluated and their results are inserted into the string.

Q6. Can we call functions inside template literals?

Yes. Function return values can be interpolated.

Q7. What is a tagged template literal?

It is a template literal processed by a tag function. The function receives an array of literal string segments and the interpolated values.

Q8. What does the first argument of a tag function contain?

It contains an array of literal string segments surrounding the interpolation expressions.

Q9. Are template literals automatically safe for HTML insertion?

No. They do not escape untrusted content. Unsafe HTML insertion can cause XSS vulnerabilities.

Q10. Can template literals contain nested expressions?

Yes. Expressions can include function calls, conditional expressions and nested template literals.
