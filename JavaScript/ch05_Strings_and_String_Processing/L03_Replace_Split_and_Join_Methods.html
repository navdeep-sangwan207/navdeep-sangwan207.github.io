2. replace() Method

The replace() method searches for a specified substring or pattern and returns a new string in which the first matching occurrence is replaced.

Syntax

string.replace(searchValue, newValue)
  • searchValue: A string or regular expression to find.
  • newValue: The replacement string or callback function.

Example 1: Replacing a Word

const message = "I like Java";

const result = message.replace("Java", "JavaScript");

console.log(result);
Output: 
I like JavaScript

Example 2: Replacing Only the First Occurrence

const text = "apple apple apple";

const result = text.replace("apple", "orange");

console.log(result);
Output: 
orange apple apple
When the search value is a string, replace() replaces only the first occurrence.

Example 3: Replacing a Character

const text = "2026-11-22";

const result = text.replace("-", "/");

console.log(result);
Output: 
2026/11-22

Example 4: Original String Remains Unchanged

const language = "I am learning Java";

const updated = language.replace("Java", "JavaScript");

console.log(language);
console.log(updated);
Output: 
I am learning Java
I am learning JavaScript

Strings are immutable. replace() returns a new string rather than modifying the original string.

3. replaceAll() Method

The replaceAll() method replaces every occurrence of a specified substring or matching pattern in a string.

Syntax

string.replaceAll(searchValue, newValue)

Example 1: Replacing All Occurrences

const text = "apple apple apple";

const result = text.replaceAll("apple", "orange");

console.log(result);
Output: 
orange orange orange

Example 2: Replacing All Hyphens

const phone = "98765-43210";

const formatted = phone.replaceAll("-", " ");

console.log(formatted);
Output: 
98765 43210

Example 3: Removing a Character

const text = "J-a-v-a-S-c-r-i-p-t";

const result = text.replaceAll("-", "");

console.log(result);
Output: 
JavaScript

Example 4: Replacing All Matching Digits

const text = "Room 101, Floor 2";

const result = text.replaceAll(/\d/g, "*");

console.log(result);
Output: 
Room ***, Floor *
When replaceAll() receives a regular expression, the expression must use the global flag (g). A regular expression without g causes a TypeError.

4. replace() Versus replaceAll()

Feature replace() replaceAll()
String search value Replaces first occurrence Replaces all occurrences
Regular expression Supports regular expressions Requires global flag g
Original string Unchanged Unchanged
Return value New string New string

Comparison Example

const text = "cat cat cat";

console.log(text.replace("cat", "dog"));
console.log(text.replaceAll("cat", "dog"));
Output: 
dog cat cat
dog dog dog

5. Introduction to Regular Expressions in String Replacement

A regular expression (RegExp) is a pattern used to search, match or replace text. It is particularly useful when the text to find follows a pattern rather than being one fixed substring.

5.1 Basic Regular Expression Syntax

const pattern = /abc/;

const text = "abcdef";

console.log(pattern.test(text));
Output: 
true

5.2 Common Regular Expression Symbols

Symbol Meaning Example
. Any character except line terminators by default /a.c/
\d Digit from 0 to 9 /\d/
\w ASCII letter, digit or underscore /\w/
\s Whitespace character /\s/
+ One or more occurrences /a+/
* Zero or more occurrences /a*/
? Zero or one occurrence /colou?r/
^ Beginning of input /^Java/
$ End of input /script$/
[abc] Any one character from the set /[aeiou]/
{n} Exactly n occurrences /\d{4}/

5.3 Common Regular Expression Flags

Flag Meaning
g Global matching; find all matches.
i Case-insensitive matching.
m Multiline mode for ^ and $ assertions.

Example: Case-Insensitive Replacement

const text = "Java java JAVASCRIPT";

const result = text.replace(/java/gi, "Python");

console.log(result);
Output: 
Python Python PYTHONSCRIPT

Example: Removing All Digits

const text = "JavaScript123";

const result = text.replace(/\d/g, "");

console.log(result);
Output: 
JavaScript

Example: Replacing Multiple Spaces

const text = "JavaScript    is   useful";

const result = text.replace(/\s+/g, " ");

console.log(result);
Output: 
JavaScript is useful
Regular expressions are useful for pattern-based text processing. This lecture covers only the basics needed for string operations; more advanced regular expression concepts can be studied separately.

6. Replacement Using a Callback Function

replace() and replaceAll() can accept a function instead of a fixed replacement string. The function calculates the replacement for each match.

Example 1: Replacing a Number with Its Double

const text = "Price: 100";

const result = text.replace(/\d+/, function(match) {
    return Number(match) * 2;
});

console.log(result);
Output: 
Price: 200

Example 2: Replacing Every Number

const text = "10 20 30";

const result = text.replace(/\d+/g, function(match) {
    return Number(match) + 5;
});

console.log(result);
Output: 
15 25 35

Callback Parameters

string.replace(
    pattern,
    function(match, ...arguments) {
        // Return replacement text
    }
);

Depending on the regular expression, the callback can receive the complete matched text, captured groups, match position and original input string.

Example 3: Using Match Position

const text = "cat cat";

const result = text.replace(/cat/g, function(match, index) {
    return "[" + index + ":" + match + "]";
});

console.log(result);
Output: 
[0:cat] [4:cat]

7. split() Method

The split() method divides a string into an array of substrings using a specified separator.

Syntax

string.split(separator, limit)
  • separator: The value or pattern used to divide the string.
  • limit: Optional maximum number of array elements.

Example 1: Splitting by a Space

const text = "JavaScript is powerful";

const words = text.split(" ");

console.log(words);
console.log(words.length);
Output: 
["JavaScript", "is", "powerful"]
3

Example 2: Splitting by a Comma

const fruits = "Apple,Banana,Mango,Orange";

const result = fruits.split(",");

console.log(result);
Output: 
["Apple", "Banana", "Mango", "Orange"]

Example 3: Splitting into Individual Characters

const language = "CODE";

console.log(language.split(""));
Output: 
["C", "O", "D", "E"]
split("") separates UTF-16 code units, not necessarily complete Unicode characters. For strings containing emoji or certain other Unicode characters, use Array.from() or the spread operator when code-point iteration is required.

Example 4: Using the Limit Parameter

const text = "HTML CSS JavaScript React";

console.log(text.split(" ", 2));
console.log(text.split(" ", 3));
Output: 
["HTML", "CSS"]
["HTML", "CSS", "JavaScript"]

Example 5: Splitting Using a Regular Expression

const text = "HTML,CSS;JavaScript React";

const result = text.split(/[,; ]+/);

console.log(result);
Output: 
["HTML", "CSS", "JavaScript", "React"]

8. Important split() Behavior

8.1 Empty Separator

const text = "HELLO";

console.log(text.split(""));
Output: 
["H", "E", "L", "L", "O"]

8.2 Missing Separator

const text = "JavaScript Programming";

console.log(text.split());
Output: 
["JavaScript Programming"]

8.3 Empty String

const text = "";

console.log(text.split(" "));
console.log(text.split(""));
Output: 
[""]
[]

8.4 Consecutive Separators

const text = "A,,B,C";

console.log(text.split(","));
Output: 
["A", "", "B", "C"]

Consecutive separators can create empty strings in the resulting array.

8.5 Separator at the Beginning and End

const text = ",A,B,";

console.log(text.split(","));
Output: 
["", "A", "B", ""]

9. join() Method

The join() method combines all elements of an array into a single string using a specified separator.

Syntax

array.join(separator)

If no separator is provided, a comma is used.

Example 1: Joining Array Elements

const languages = ["HTML", "CSS", "JavaScript"];

const result = languages.join();

console.log(result);
Output: 
HTML,CSS,JavaScript

Example 2: Using a Space Separator

const words = ["JavaScript", "is", "powerful"];

console.log(words.join(" "));
Output: 
JavaScript is powerful

Example 3: Using a Hyphen

const date = ["22", "11", "2026"];

console.log(date.join("-"));
Output: 
22-11-2026

Example 4: Joining with an Empty Separator

const letters = ["J", "S"];

console.log(letters.join(""));
Output: 
JS

10. split() Versus join()

Feature split() join()
Called on String Array
Purpose Divides a string Combines array elements
Returns Array String
Separator Defines where to divide Defines what to insert between elements

Example: Converting String to Array and Back

const text = "HTML CSS JavaScript";

const words = text.split(" ");

console.log(words);

const result = words.join("-");

console.log(result);
Output: 
["HTML", "CSS", "JavaScript"]
HTML-CSS-JavaScript

11. Practical Application: Formatting a Name

A frontend application may receive a name containing multiple spaces. We can normalize the spaces and combine the words into a clean display string. 

function formatName(name) {
    return name
        .trim()
        .split(/\s+/)
        .join(" ");
}

console.log(formatName("  Navdeep   Sangwan  "));
console.log(formatName("JavaScript    Developer"));
Output: 
Navdeep Sangwan
JavaScript Developer

This example combines trim(), split() and join(). The trim() method is covered in the next lecture.

12. Practical Application: Converting CSV Text into Data

A simple comma-separated string can be converted into an array using split(). 

const csvData = "101,Navdeep,Developer";

const fields = csvData.split(",");

console.log("ID:", fields[0]);
console.log("Name:", fields[1]);
console.log("Role:", fields[2]);
Output: 
ID: 101
Name: Navdeep
Role: Developer
This is suitable only for simple comma-separated data. Real CSV files may contain quoted commas, escaped quotes and line breaks. Use a proper CSV parser for production applications.

13. Practical Application: Generating a URL Slug

A slug is a URL-friendly representation of a title. The following example converts a basic title into a lowercase, hyphen-separated string. 

function createSlug(title) {
    return title
        .toLowerCase()
        .trim()
        .replace(/[^\w\s-]/g, "")
        .replace(/\s+/g, "-");
}

console.log(createSlug("JavaScript String Methods"));
console.log(createSlug("Frontend Developer Interview!"));
Output: 
javascript-string-methods
frontend-developer-interview

This is a basic ASCII-oriented slug generator. More complete implementations should also handle Unicode characters and repeated hyphens.

14. Practical Application: Masking a Phone Number

A user interface may display only the last four digits of a phone number. 

function maskPhoneNumber(phone) {
    if (!/^\d{10}$/.test(phone)) {
        return "Invalid phone number";
    }

    return phone.slice(0, 6).replace(/\d/g, "*")
        + phone.slice(-4);
}

console.log(maskPhoneNumber("9876543210"));
console.log(maskPhoneNumber("1234567890"));
Output: 
******3210
******7890

15. Common Mistakes and Debugging

Mistake Correct Understanding
Assuming replace() changes every occurrence of a string. With a string search value, it replaces only the first occurrence.
Using replaceAll() with a non-global regular expression. Regular expressions passed to replaceAll() must use g.
Assuming replace() modifies the original string. It returns a new string.
Assuming split() returns a string. It returns an array.
Assuming join() returns an array. It returns a string.
Forgetting the default join() separator. The default separator is a comma.
Using the wrong separator in split(). The separator must match the actual input format.
Assuming split("") always produces complete Unicode characters. It separates UTF-16 code units.

16. Placement Interview Questions and Answers

Q1. What is the difference between replace() and replaceAll()?

replace() with a string search value replaces the first occurrence. replaceAll() replaces every occurrence of that string.

Q2. Does replace() modify the original string?

No. It returns a new string.

Q3. What is a regular expression?

A regular expression is a pattern used to search, match or replace text.

Q4. What is the purpose of the g flag?

It enables global matching, allowing a regular expression to match all occurrences.

Q5. What is the difference between split() and join()?

split() converts a string into an array. join() combines array elements into a string.

Q6. What does split(" ") do?

It divides a string wherever a space occurs.

Q7. What does split("") do?

It divides a string into UTF-16 code units.

Q8. What is the default separator of join()?

A comma.

Q9. Can replace() accept a function?

Yes. A callback function can dynamically generate replacement text for each match.

Q10. What happens when split() is called without a separator?

It returns an array containing the entire original string as one element.

Q11. How can you remove all digits from a string?

const text = "JavaScript123";

console.log(text.replace(/\d/g, ""));
Output: 
JavaScript

Q12. How can you convert a sentence into an array of words?

const sentence = "Learn JavaScript today";

console.log(sentence.split(" "));
Output: 
["Learn", "JavaScript", "today"]

19. Lecture Summary

  • replace() replaces the first matching occurrence when given a string search value.
  • replaceAll() replaces all matching occurrences.
  • Regular expressions support pattern-based searching and replacement.
  • The g flag enables global regular expression matching.
  • Replacement callbacks allow dynamic replacement values.
  • split() converts a string into an array.
  • join() converts array elements into a string.
  • Both split() and join() accept separators.
  • These methods are useful in formatting, validation and frontend data processing.
