3. Searching Within Strings

JavaScript provides several methods to search for characters or substrings. Search methods are useful for checking user input, validating text and locating information in strings.

3.1 indexOf()

The indexOf() method returns the index of the first occurrence of a specified value. If the value is not found, it returns -1.

Syntax

string.indexOf(searchValue, fromIndex)
  • searchValue: Text or character to search for.
  • fromIndex: Optional position from which to begin searching.

Example 1: Finding a Character

const text = "JavaScript Programming";

console.log(text.indexOf("a"));
console.log(text.indexOf("S"));
console.log(text.indexOf("P"));
Output: 
1
4
11

Example 2: Searching for a Substring

const text = "Learn JavaScript Programming";

console.log(text.indexOf("JavaScript"));
console.log(text.indexOf("Programming"));
console.log(text.indexOf("Python"));
Output: 
6
17
-1

Example 3: Using fromIndex

const text = "banana";

console.log(text.indexOf("a"));
console.log(text.indexOf("a", 2));
console.log(text.indexOf("a", 3));
Output: 
1
3
3
indexOf() is case-sensitive. Searching for "java" in "JavaScript" does not find a match.

Example 4: Checking Whether a Value Exists

const email = "student@example.com";

if (email.indexOf("@") !== -1) {
    console.log("Email contains @");
} else {
    console.log("Invalid email format");
}
Output: 
Email contains @

Practical Example: File Type Validation

function checkFileType(fileName) {
    if (fileName.endsWith(".pdf")) {
        return "PDF file";
    }

    if (fileName.endsWith(".jpg")) {
        return "JPG image";
    }

8. slice()

The slice() method extracts a portion of a string and returns it as a new string. It does not modify the original string.

Syntax

string.slice(start, end)
  • start: Starting index, included in the result.
  • end: Ending index, excluded from the result.

Example 1: Extracting a Portion

const language = "JavaScript";

console.log(language.slice(0, 4));
console.log(language.slice(4, 10));
console.log(language.slice(0, 10));
Output: 
Java
Script
JavaScript

Example 2: Omitting the End Index

const language = "JavaScript";

console.log(language.slice(4));
Output: 
Script

Example 3: Negative Index

const language = "JavaScript";

console.log(language.slice(-6));
console.log(language.slice(-6, -3));
console.log(language.slice(0, -6));
Output: 
Script
Scr
Java

Example 4: Extracting the Last Four Characters

const fileName = "report.pdf";

const extension = fileName.slice(-4);

console.log(extension);
Output: 
.pdf

Important Behavior

const text = "JavaScript";

console.log(text.slice(4, 2));
console.log(text.slice(2, 4));
Output: 

va

When the normalized start position is greater than or equal to the end position, slice() returns an empty string.

9. substring()

The substring() method extracts characters between two indexes and returns a new string.

Syntax

string.substring(start, end)
  • start: Starting index, included.
  • end: Ending index, excluded.

Example 1: Basic Usage

const language = "JavaScript";

console.log(language.substring(0, 4));
console.log(language.substring(4, 10));
Output: 
Java
Script

Example 2: Reversed Arguments

const text = "JavaScript";

console.log(text.substring(4, 2));
console.log(text.substring(2, 4));
Output: 
va
va

Unlike slice(), substring() swaps the start and end positions when the first index is greater than the second.

Example 3: Negative Arguments

const text = "JavaScript";

console.log(text.substring(-4));
console.log(text.substring(0, -4));
Output: 
JavaScript

Negative arguments are treated as zero by substring(). Therefore, the second output is an empty string.

10. slice() Versus substring()

Both methods extract portions of strings, but they differ in how they handle negative indexes and reversed arguments.

Feature slice() substring()
Basic extraction Supported Supported
End index excluded Yes Yes
Negative indexes Counts from the end Treated as zero
Start greater than end Returns empty string Swaps the positions
Modifies original string No No

Comparison Example

const text = "JavaScript";

console.log(text.slice(4, 2));
console.log(text.substring(4, 2));

console.log(text.slice(-6));
console.log(text.substring(-6));
Output: 

va

JavaScript
Interview tip: Remember the negative-index behavior and reversed argument behavior. These are common output-based interview questions.

11. Deprecated Method: substr()

The substr() method extracts a substring using a starting index and a length.

Syntax

string.substr(start, length)

Example

const language = "JavaScript";

console.log(language.substr(4, 6));
console.log(language.substr(0, 4));
Output: 
Script
Java
substr() is a legacy method and is not recommended for new code. Prefer slice() or substring().

12. Practical Application: Extracting a File Extension

A frontend application may need to identify the extension of a selected file. 

function getExtension(fileName) {
    const dotIndex = fileName.lastIndexOf(".");

    if (dotIndex === -1 || dotIndex === fileName.length - 1) {
        return "No valid extension";
    }

    return fileName.slice(dotIndex);
}

console.log(getExtension("resume.pdf"));
console.log(getExtension("photo.jpg"));
console.log(getExtension("notes"));
console.log(getExtension("report."));
Output: 
.pdf
.jpg
No valid extension
No valid extension

This example combines lastIndexOf() and slice() to locate and extract the extension.

13. Practical Application: Extracting a Username from an Email

Consider an email address such as student@example.com. We can extract the portion before the @ symbol. 

function getUsername(email) {
    const atIndex = email.indexOf("@");

    if (atIndex <= 0 || atIndex === email.length - 1) {
        return "Invalid email format";
    }

    return email.slice(0, atIndex);
}

console.log(getUsername("student@example.com"));
console.log(getUsername("navdeep@gmail.com"));
console.log(getUsername("invalid-email"));
Output: 
student
navdeep
Invalid email format
This is a basic extraction example, not complete email validation. Real email validation requires additional rules.

14. Common Mistakes and Debugging

Mistake Correct Understanding
Assuming indexOf() returns false when no match exists. It returns -1.
Assuming includes() returns the matching position. It returns true or false.
Assuming indexOf() ignores letter case. String searching is case-sensitive.
Assuming lastIndexOf() returns the first match. It returns the last matching position.
Including the end index in slice(). The end index is excluded.
Assuming slice() and substring() handle negative indexes identically. They behave differently.
Assuming slice() changes the original string. It returns a new string.
Using startsWith() to check the end of a string. Use endsWith() for suffix checking.

15. Placement Interview Questions and Answers

Q1. What is the difference between indexOf() and includes()?

indexOf() returns the first matching index or -1. includes() returns a Boolean indicating whether the substring exists.

Q2. What is the difference between indexOf() and lastIndexOf()?

indexOf() finds the first occurrence, while lastIndexOf() finds the last occurrence.

Q3. Are string search methods case-sensitive?

Yes. Methods such as indexOf(), includes(), startsWith() and endsWith() are case-sensitive.

Q4. What does indexOf() return when a substring is absent?

It returns -1.

Q5. What is the purpose of startsWith()?

It checks whether a string begins with a specified substring and returns a Boolean.

Q6. What is the purpose of endsWith()?

It checks whether a string ends with a specified substring and returns a Boolean.

Q7. What is the difference between slice() and substring()?

slice() supports negative indexes and returns an empty string when the normalized start is after the end. substring() treats negative indexes as zero and swaps reversed arguments.

Q8. Does slice() modify the original string?

No. It returns a new string.

Q9. What is the difference between slice() and substr()?

slice() uses start and end indexes, while substr() uses a starting index and a length. substr() is a legacy method.

Q10. How can you extract the last three characters?

const text = "JavaScript";

console.log(text.slice(-3));
Output: 
ipt

Q11. How can you check whether a string contains a dot?

const fileName = "report.pdf";

console.log(fileName.includes("."));
Output: 
true

Q12. Can indexOf() search for a complete word?

Yes. It can search for a complete substring or a single character and returns the starting index of the first match.
