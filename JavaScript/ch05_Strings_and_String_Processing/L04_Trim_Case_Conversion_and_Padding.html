Chapter 5: Strings and String Processing

1. Learning Objectives

After completing this lecture, you will be able to:

  • Remove whitespace from strings using trim() methods.
  • Understand the difference between trim(), trimStart() and trimEnd().
  • Convert strings into uppercase and lowercase.
  • Understand case-sensitive comparisons.
  • Use locale-aware case conversion when required.
  • Pad strings from the beginning or end.
  • Format identifiers, codes and numeric values.
  • Apply string formatting in frontend development.

2. Understanding Whitespace

Whitespace refers to characters that create spacing or line breaks in text. Common examples include spaces, tabs and newline characters.

Example: Whitespace in a String

const name = "   Navdeep Sangwan   ";

console.log(name);
console.log(name.length);
Output: 
   Navdeep Sangwan
21

Unnecessary whitespace can cause problems in form input, searching, validation and data processing. JavaScript provides trim methods to handle it.

3. trim() Method

The trim() method removes whitespace from both the beginning and end of a string. It does not remove whitespace between words.

Syntax

string.trim()

Example 1: Removing Leading and Trailing Spaces

const name = "   Navdeep Sangwan   ";

const result = name.trim();

console.log(result);
console.log(result.length);
Output: 
Navdeep Sangwan
15

Example 2: Internal Spaces Remain Unchanged

const text = "   JavaScript    Programming   ";

console.log(text.trim());
Output: 
JavaScript    Programming

Example 3: Removing Tabs and Newlines

const text = "\n\t JavaScript \t\n";

const result = text.trim();

console.log(result);
console.log(result.length);
Output: 
JavaScript
10

Example 4: Original String Remains Unchanged

const text = "   Hello World   ";

const result = text.trim();

console.log(text);
console.log(result);
Output: 
   Hello World
Hello World
Strings are immutable. trim() returns a new string and does not modify the original string.

4. trimStart() Method

The trimStart() method removes whitespace only from the beginning of a string.

Syntax

string.trimStart()

Example

const text = "   JavaScript   ";

const result = text.trimStart();

console.log("[" + result + "]");
console.log(result.length);
Output: 
[JavaScript   ]
13

The leading spaces are removed, but the trailing spaces remain.

Alias: trimLeft()

const text = "   Hello";

console.log(text.trimLeft());
Output: 
Hello

trimLeft() is an alias of trimStart(). Prefer trimStart() in new code.

5. trimEnd() Method

The trimEnd() method removes whitespace only from the end of a string.

Syntax

string.trimEnd()

Example

const text = "   JavaScript   ";

const result = text.trimEnd();

console.log("[" + result + "]");
console.log(result.length);
Output: 
[   JavaScript]
13

Alias: trimRight()

const text = "Hello   ";

console.log(text.trimRight());
Output: 
Hello

trimRight() is an alias of trimEnd(). Prefer trimEnd() in new code.

6. Comparison of Trim Methods

Method Whitespace Removed Alias
trim() Beginning and end None
trimStart() Beginning only trimLeft()
trimEnd() End only trimRight()

Comparison Example

const text = "   Hello World   ";

console.log("[" + text.trim() + "]");
console.log("[" + text.trimStart() + "]");
console.log("[" + text.trimEnd() + "]");
Output: 
[Hello World]
[Hello World   ]
[   Hello World]

7. toUpperCase() Method

The toUpperCase() method converts lowercase letters in a string into uppercase.

Syntax

string.toUpperCase()

Example 1: Basic Conversion

const language = "JavaScript";

console.log(language.toUpperCase());
Output: 
JAVASCRIPT

Example 2: Mixed Case

const text = "JaVaScRiPt";

console.log(text.toUpperCase());
Output: 
JAVASCRIPT

Example 3: Original String Is Unchanged

const text = "hello";

const result = text.toUpperCase();

console.log(text);
console.log(result);
Output: 
hello
HELLO

Practical Use: Formatting a Heading

const heading = "welcome to javascript";

console.log(heading.toUpperCase());
Output: 
WELCOME TO JAVASCRIPT

8. toLowerCase() Method

The toLowerCase() method converts uppercase letters in a string into lowercase.

Syntax

string.toLowerCase()

Example 1: Basic Conversion

const language = "JAVASCRIPT";

console.log(language.toLowerCase());
Output: 
javascript

Example 2: Mixed Case

const text = "JaVaScRiPt";

console.log(text.toLowerCase());
Output: 
javascript

Example 3: Practical Case-Insensitive Comparison

const enteredRole = "  ADMIN  ";
const requiredRole = "admin";

if (enteredRole.trim().toLowerCase() === requiredRole) {
    console.log("Role matched");
} else {
    console.log("Role not matched");
}
Output: 
Role matched
Converting text to lowercase can help with case-insensitive comparisons, but it does not replace proper authentication or authorization. Never rely on a client-side role string for access control.

9. toUpperCase() Versus toLowerCase()

Feature toUpperCase() toLowerCase()
Purpose Converts letters to uppercase Converts letters to lowercase
Return value New string New string
Original string Unchanged Unchanged

Example

const text = "JavaScript";

console.log(text.toUpperCase());
console.log(text.toLowerCase());
Output: 
JAVASCRIPT
javascript

10. locale-Aware Case Conversion

JavaScript also provides locale-aware methods for converting text according to language-specific casing rules.

toLocaleUpperCase()

const text = "javascript";

console.log(text.toLocaleUpperCase("en-US"));
Output: 
JAVASCRIPT

toLocaleLowerCase()

const text = "JAVASCRIPT";

console.log(text.toLocaleLowerCase("en-US"));
Output: 
javascript

Locale-aware conversion matters for languages with special casing rules. For example, Turkish has distinct casing behavior for the letter I. 

const text = "I";

console.log(text.toLocaleLowerCase("en-US"));
console.log(text.toLocaleLowerCase("tr"));
Output: 
i
ı
Use locale-aware conversion when handling language-specific text. For ordinary English application strings, toUpperCase() and toLowerCase() are usually sufficient.

11. padStart() Method

The padStart() method adds characters to the beginning of a string until it reaches a specified target length.

Syntax

string.padStart(targetLength, padString)
  • targetLength: Desired final string length.
  • padString: Optional string used for padding. Defaults to a space.

Example 1: Padding with Zeros

const number = "42";

console.log(number.padStart(5, "0"));
Output: 
00042

Example 2: Padding with Characters

const text = "JS";

console.log(text.padStart(6, "*"));
Output: 
****JS

Example 3: Padding with a Multi-Character String

const text = "5";

console.log(text.padStart(8, "AB"));
Output: 
ABABAB5

Example 4: Target Length Already Reached

const text = "JavaScript";

console.log(text.padStart(5, "*"));
Output: 
JavaScript

If the original string is already at least as long as the target length, no padding is added.

12. padEnd() Method

The padEnd() method adds characters to the end of a string until it reaches a specified target length.

Syntax

string.padEnd(targetLength, padString)

Example 1: Padding with Zeros

const number = "42";

console.log(number.padEnd(5, "0"));
Output: 
42000

Example 2: Padding with Characters

const text = "JS";

console.log(text.padEnd(6, "*"));
Output: 
JS****

Example 3: Padding with Multiple Characters

const text = "A";

console.log(text.padEnd(7, "BC"));
Output: 
ABCBCBC

13. padStart() Versus padEnd()

Feature padStart() padEnd()
Padding direction Beginning End
Target length Final string length Final string length
Default padding Space Space
Original string Unchanged Unchanged

Comparison Example

const text = "JS";

console.log(text.padStart(6, "*"));
console.log(text.padEnd(6, "*"));
Output: 
****JS
JS****

14. Practical Application: Formatting Employee IDs

An application may require employee IDs to have a fixed number of digits. 

function formatEmployeeId(id) {
    return String(id).padStart(6, "0");
}

console.log(formatEmployeeId(25));
console.log(formatEmployeeId(1250));
console.log(formatEmployeeId(987654));
Output: 
000025
001250
987654

15. Practical Application: Normalizing Form Input

Form input may contain unnecessary spaces or inconsistent letter casing. We can normalize the value before performing basic comparisons. 

function normalizeUsername(username) {
    return username.trim().toLowerCase();
}

const enteredUsername = "  NAVDEEP  ";

console.log(normalizeUsername(enteredUsername));
Output: 
navdeep

This approach is useful for normalizing usernames when the application defines case-insensitive username comparison.

16. Practical Application: Formatting a Four-Digit PIN

Suppose a system displays numeric identifiers using exactly four characters. 

function formatPIN(pin) {
    const value = String(pin);

    if (!/^\d+$/.test(value) || value.length > 4) {
        return "Invalid PIN";
    }

    return value.padStart(4, "0");
}

console.log(formatPIN(7));
console.log(formatPIN(45));
console.log(formatPIN(1234));
console.log(formatPIN(12345));
Output: 
0007
0045
1234
Invalid PIN
Padding is a formatting operation, not security. Do not treat a padded PIN as encrypted or protected data.

17. Common Mistakes and Debugging

Mistake Correct Understanding
Assuming trim() removes spaces between words. It removes whitespace only from the beginning and end.
Using trimStart() to remove trailing spaces. Use trimEnd() for trailing whitespace.
Assuming trim() changes the original string. It returns a new string.
Assuming toUpperCase() modifies the original string. It returns a new string.
Comparing differently cased strings directly. Normalize case when the comparison should be case-insensitive.
Assuming padStart() always adds the specified number of characters. It pads until the target length is reached.
Confusing padStart() and padEnd(). One pads at the beginning; the other pads at the end.
Using numeric values directly with string methods. Convert numbers to strings when necessary using String().

18. Placement Interview Questions and Answers

Q1. What does trim() do?

It removes whitespace from the beginning and end of a string.

Q2. What is the difference between trimStart() and trimEnd()?

trimStart() removes leading whitespace, while trimEnd() removes trailing whitespace.

Q3. Does trim() remove spaces between words?

No. Internal whitespace remains unchanged.

Q4. What is the difference between toUpperCase() and toLowerCase()?

The first converts letters to uppercase, while the second converts letters to lowercase.

Q5. Are JavaScript string comparisons case-sensitive?

Yes. Direct string comparisons are case-sensitive.

Q6. What is the purpose of toLocaleLowerCase()?

It converts text to lowercase according to locale-specific casing rules.

Q7. What is padStart()?

It adds padding to the beginning of a string until the specified target length is reached.

Q8. What is padEnd()?

It adds padding to the end of a string until the specified target length is reached.

Q9. What happens if the target length is smaller than the string length?

The original string is returned without padding.

Q10. What is the default padding string?

A space character.

Q11. How do you compare two strings without considering English letter case?

const a = "JavaScript";
const b = "JAVASCRIPT";

console.log(a.toLowerCase() === b.toLowerCase());
Output: 
true

Q12. How do you format the number 25 as a six-character ID?

console.log(String(25).padStart(6, "0"));
Output: 
000025
