3. Reverse a String

Given a string, return the characters in reverse order.

Example:

Input:  "javascript"
Output: "tpircsavaj"

Approach 1: Using Built-in Methods

function reverseString(str) {
    return str.split("").reverse().join("");
}

console.log(reverseString("javascript"));
console.log(reverseString("hello"));
Output: 
tpircsavaj
olleh

This approach converts the string into an array, reverses the array and joins its elements.

Approach 2: Using a for Loop

function reverseString(str) {
    let reversed = "";

    for (let i = str.length - 1; i >= 0; i--) {
        reversed += str[i];
    }

    return reversed;
}

console.log(reverseString("hello"));
Output: 
olleh

Approach 3: Using Two Pointers

function reverseString(str) {
    const chars = str.split("");

    let left = 0;
    let right = chars.length - 1;

    while (left < right) {
        const temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;

        left++;
        right--;
    }

    return chars.join("");
}

console.log(reverseString("coding"));
Output: 
gnidoc

The two-pointer approach swaps characters from opposite ends and moves toward the center.

Complexity: The array-based approaches require O(n) time and O(n) auxiliary space. The two-pointer approach performs O(n) swaps on the character array.
These simple approaches operate on UTF-16 code units. They may not correctly reverse every Unicode string containing emoji or combined characters. Unicode-aware reversal requires grapheme-cluster handling.

4. Check Whether a String Is a Palindrome

A palindrome is a string that reads the same forward and backward.

Examples:

madam
level
radar

Approach 1: Reverse and Compare

function isPalindrome(str) {
    const reversed = str.split("").reverse().join("");

    return str === reversed;
}

console.log(isPalindrome("madam"));
console.log(isPalindrome("hello"));
Output: 
true
false

Approach 2: Two Pointers

function isPalindrome(str) {
    let left = 0;
    let right = str.length - 1;

    while (left < right) {
        if (str[left] !== str[right]) {
            return false;
        }

        left++;
        right--;
    }

    return true;
}

console.log(isPalindrome("level"));
console.log(isPalindrome("javascript"));
Output: 
true
false

Approach 3: Case-Insensitive Palindrome

function isPalindrome(str) {
    const normalized = str.toLowerCase();

    return normalized === normalized.split("").reverse().join("");
}

console.log(isPalindrome("Madam"));
console.log(isPalindrome("Level"));
Output: 
true
true

Approach 4: Ignore Spaces and Punctuation

function isPalindrome(str) {
    const normalized = str
        .toLowerCase()
        .replace(/[^a-z0-9]/g, "");

    let left = 0;
    let right = normalized.length - 1;

    while (left < right) {
        if (normalized[left] !== normalized[right]) {
            return false;
        }

        left++;
        right--;
    }

    return true;
}

console.log(isPalindrome("A man, a plan, a canal: Panama"));
console.log(isPalindrome("Hello, World!"));
Output: 
true
false
The regular expression in this example retains English letters and digits only. It is not a complete Unicode-aware normalization solution.

Complexity: O(n) time. The normalization and reverse-based approaches use O(n) additional space; the two-pointer comparison uses O(1) auxiliary space when given an already normalized string.

5. Count Vowels and Consonants

Count the number of English vowels and consonants in a given string.

Solution

function countVowelsAndConsonants(str) {
    let vowels = 0;
    let consonants = 0;

    const text = str.toLowerCase();

    for (let i = 0; i < text.length; i++) {
        const ch = text[i];

        if (ch >= "a" && ch <= "z") {
            if ("aeiou".includes(ch)) {
                vowels++;
            } else {
                consonants++;
            }
        }
    }

    return { vowels, consonants };
}

console.log(countVowelsAndConsonants("JavaScript Programming"));
Output: 
{ vowels: 6, consonants: 15 }

Spaces, numbers and punctuation are ignored. This example counts English alphabetic characters.

Complexity: O(n) time and O(1) auxiliary space.

6. Count the Frequency of Each Character

Character frequency means counting how many times each character appears in a string.

Solution Using Map

function characterFrequency(str) {
    const frequency = new Map();

    for (const ch of str) {
        frequency.set(ch, (frequency.get(ch) || 0) + 1);
    }

    return frequency;
}

const result = characterFrequency("banana");

for (const [character, count] of result) {
    console.log(character, count);
}
Output: 
b 1
a 3
n 2

Alternative: Using an Object

function characterFrequency(str) {
    const frequency = {};

    for (const ch of str) {
        frequency[ch] = (frequency[ch] || 0) + 1;
    }

    return frequency;
}

console.log(characterFrequency("apple"));
Output: 
{ a: 1, p: 2, l: 1, e: 1 }
Map is useful when character keys should be handled without object-property concerns. For arbitrary string keys in an object, Object.create(null) is another option.

Complexity: O(n) expected time and O(k) space, where k is the number of distinct characters.

7. Find the First Non-Repeating Character

Find the first character that appears exactly once.

Example:

Input:  "aabbcde"
Output: "c"

Solution Using Map

function firstNonRepeatingCharacter(str) {
    const frequency = new Map();

    for (const ch of str) {
        frequency.set(ch, (frequency.get(ch) || 0) + 1);
    }

    for (const ch of str) {
        if (frequency.get(ch) === 1) {
            return ch;
        }
    }

    return null;
}

console.log(firstNonRepeatingCharacter("aabbcde"));
console.log(firstNonRepeatingCharacter("aabb"));
Output: 
c
null

The first traversal builds the frequency table. The second traversal preserves the original character order and finds the first count of one.

Complexity: O(n) expected time and O(k) space.

8. Find Duplicate Characters

Identify characters that occur more than once.

Solution

function findDuplicates(str) {
    const frequency = new Map();
    const duplicates = [];

    for (const ch of str) {
        frequency.set(ch, (frequency.get(ch) || 0) + 1);
    }

    for (const [ch, count] of frequency) {
        if (count > 1) {
            duplicates.push(ch);
        }
    }

    return duplicates;
}

console.log(findDuplicates("programming"));
Output: 
[ 'r', 'g', 'm' ]

Map preserves insertion order, so duplicate characters are returned in the order in which they first appeared.

Complexity: O(n) expected time and O(k) space.

9. Check Whether Two Strings Are Anagrams

Two strings are anagrams if they contain the same characters with the same frequencies, regardless of order.

Examples:

"listen" and "silent"  → Anagrams
"hello" and "world"    → Not anagrams

Approach 1: Sort and Compare

function areAnagrams(str1, str2) {
    const a = str1.toLowerCase().split("").sort().join("");
    const b = str2.toLowerCase().split("").sort().join("");

    return a === b;
}

console.log(areAnagrams("listen", "silent"));
console.log(areAnagrams("hello", "world"));
Output: 
true
false

Approach 2: Frequency Counting

function areAnagrams(str1, str2) {
    if (str1.length !== str2.length) {
        return false;
    }

    const frequency = new Map();

    for (const ch of str1.toLowerCase()) {
        frequency.set(ch, (frequency.get(ch) || 0) + 1);
    }

    for (const ch of str2.toLowerCase()) {
        if (!frequency.has(ch)) {
            return false;
        }

        frequency.set(ch, frequency.get(ch) - 1);

        if (frequency.get(ch) < 0) {
            return false;
        }
    }

    return true;
}

console.log(areAnagrams("listen", "silent"));
console.log(areAnagrams("triangle", "integral"));
console.log(areAnagrams("hello", "world"));
Output: 
true
true
false

This example is case-insensitive but treats whitespace and punctuation as actual characters.

Complexity: Sorting takes O(n log n) time. Frequency counting takes O(n) expected time and O(k) space.

10. Remove Duplicate Characters

Remove repeated characters while preserving the first occurrence of each character.

Solution Using Set

function removeDuplicates(str) {
    return [...new Set(str)].join("");
}

console.log(removeDuplicates("programming"));
console.log(removeDuplicates("banana"));
Output: 
progamin
ban

Alternative: Using a Loop

function removeDuplicates(str) {
    let result = "";

    for (const ch of str) {
        if (!result.includes(ch)) {
            result += ch;
        }
    }

    return result;
}

console.log(removeDuplicates("banana"));
Output: 
ban

The Set approach takes O(n) expected time for collecting distinct characters. The includes() approach can take O(n²) time in the worst case.

11. Reverse Words in a Sentence

Reverse the order of words without reversing the characters inside each word.

Example:

Input:  "JavaScript is powerful"
Output: "powerful is JavaScript"

Solution

function reverseWords(str) {
    return str.trim().split(/\s+/).reverse().join(" ");
}

console.log(reverseWords("JavaScript is powerful"));
console.log(reverseWords("  I love coding  "));
Output: 
powerful is JavaScript
coding love I

The regular expression /\s+/ splits the string at one or more whitespace characters.

Complexity: O(n) time and O(n) additional space.

12. Count the Number of Words

Count the words in a sentence while handling repeated spaces and leading or trailing whitespace.

Solution

function countWords(str) {
    const trimmed = str.trim();

    if (trimmed === "") {
        return 0;
    }

    return trimmed.split(/\s+/).length;
}

console.log(countWords("JavaScript is powerful"));
console.log(countWords("  Learn   coding  every day "));
console.log(countWords("     "));
Output: 
3
4
0

Complexity: O(n) time and O(n) additional space.

13. Find the Longest Word in a Sentence

Return the longest word from a sentence.

Solution

function findLongestWord(sentence) {
    const words = sentence.trim().split(/\s+/);

    if (words.length === 1 && words[0] === "") {
        return "";
    }

    let longest = "";

    for (const word of words) {
        if (word.length > longest.length) {
            longest = word;
        }
    }

    return longest;
}

console.log(findLongestWord("JavaScript is a powerful language"));
console.log(findLongestWord("I love programming"));
Output: 
JavaScript
programming

If multiple words have the same maximum length, this implementation returns the first one.

Complexity: O(n) time and O(n) space for the word array.

14. Check Whether a String Contains Only Digits

Determine whether every character in a string is an ASCII decimal digit from 0 to 9.

Solution Using Regular Expression

function containsOnlyDigits(str) {
    return /^\d+$/.test(str);
}

console.log(containsOnlyDigits("123456"));
console.log(containsOnlyDigits("123a56"));
console.log(containsOnlyDigits(""));
Output: 
true
false
false

Solution Using every()

function containsOnlyDigits(str) {
    return str.length > 0 &&
        [...str].every(ch => ch >= "0" && ch <= "9");
}

console.log(containsOnlyDigits("98765"));
console.log(containsOnlyDigits("98A65"));
Output: 
true
false
The regular expression uses + rather than *. Therefore, an empty string does not count as a valid digit-only string.

15. Capitalize the First Letter of Each Word

Convert the first character of each word to uppercase and the remaining characters to lowercase.

Solution

function capitalizeWords(str) {
    return str
        .trim()
        .toLowerCase()
        .split(/\s+/)
        .map(word => word[0].toUpperCase() + word.slice(1))
        .join(" ");
}

console.log(capitalizeWords("javascript programming"));
console.log(capitalizeWords("hELLO WORLD"));
Output: 
Javascript Programming
Hello World
This is a simple English-oriented capitalization approach. It does not implement every language's title-case rules or special Unicode casing behavior.

16. Find the Most Frequent Character

Identify the character that occurs most frequently in a string.

Solution

function mostFrequentCharacter(str) {
    const frequency = new Map();

    let maxCount = 0;
    let result = null;

    for (const ch of str) {
        const count = (frequency.get(ch) || 0) + 1;

        frequency.set(ch, count);

        if (count > maxCount) {
            maxCount = count;
            result = ch;
        }
    }

    return result;
}

console.log(mostFrequentCharacter("programming"));
console.log(mostFrequentCharacter("banana"));
Output: 
r
a

If multiple characters share the highest frequency, this implementation returns the one that first reaches that frequency while traversing the string.

Complexity: O(n) expected time and O(k) space.

17. Check Whether One String Is a Rotation of Another

A string is a rotation of another string if it can be obtained by moving characters from one end to the other without changing their order.

Example:

"abcd" → "cdab"

Solution

function areRotations(str1, str2) {
    if (str1.length !== str2.length) {
        return false;
    }

    return (str1 + str1).includes(str2);
}

console.log(areRotations("abcd", "cdab"));
console.log(areRotations("abcd", "acbd"));
console.log(areRotations("abcd", "abcd"));
Output: 
true
false
true

Concatenating the original string with itself contains every possible cyclic rotation.

Complexity: The concatenation takes O(n) space. The search complexity of includes() is implementation-dependent; do not assume a universal exact bound.

18. String Compression

Compress consecutive repeated characters by representing each character followed by its count.

Example:

Input:  "aaabbcccc"
Output: "a3b2c4"

Solution

function compressString(str) {
    if (str.length === 0) {
        return "";
    }

    let result = "";
    let count = 1;

    for (let i = 1; i <= str.length; i++) {
        if (str[i] === str[i - 1]) {
            count++;
        } else {
            result += str[i - 1] + count;
            count = 1;
        }
    }

    return result;
}

console.log(compressString("aaabbcccc"));
console.log(compressString("abcd"));
console.log(compressString("aaaa"));
Output: 
a3b2c4
a1b1c1d1
a4

This implementation always includes the count, even when a character occurs only once.

Complexity: O(n) traversal time, excluding the cost of building the result string.

19. Longest Substring Without Repeating Characters

Given a string, find the length of the longest substring that contains no repeated characters.

Example:

Input:  "abcabcbb"
Output: 3

Longest substring: "abc"

Solution Using Sliding Window

function longestUniqueSubstring(str) {
    const lastSeen = new Map();

    let left = 0;
    let maxLength = 0;

    for (let right = 0; right < str.length; right++) {
        const ch = str[right];

        if (lastSeen.has(ch) && lastSeen.get(ch) >= left) {
            left = lastSeen.get(ch) + 1;
        }

        lastSeen.set(ch, right);

        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

console.log(longestUniqueSubstring("abcabcbb"));
console.log(longestUniqueSubstring("bbbbb"));
console.log(longestUniqueSubstring("pwwkew"));
Output: 
3
1
3

How the Sliding Window Works

  1. Maintain a window using left and right pointers.
  2. Expand the window by moving right.
  3. Record the most recent position of each character.
  4. If a repeated character appears inside the current window, move left beyond its previous position.
  5. Update the maximum window length.
Complexity: O(n) expected time and O(k) space, where k is the number of distinct characters encountered.
This implementation measures UTF-16 code units because it uses indexed string access. A Unicode-code-point version needs a different iteration strategy.

22. Common JavaScript String Interview Questions

Q1. Are JavaScript strings mutable?

No. Strings are immutable. String operations return new strings rather than modifying the original.

Q2. What is the difference between length and the number of visible characters?

The length property counts UTF-16 code units. Some visible Unicode characters consist of multiple code units or multiple Unicode code points.

Q3. What is the difference between slice() and substring()?

slice() supports negative indexes relative to the end. substring() treats negative values as zero and swaps the arguments when the first is greater than the second.

Q4. What does includes() return?

It returns true if the specified substring is found, otherwise false.

Q5. What is the difference between indexOf() and lastIndexOf()?

indexOf() finds the first matching position, while lastIndexOf() finds the last matching position.

Q6. What does split() do?

It divides a string into an array using a specified separator or regular expression.

Q7. What does join() do?

It combines array elements into a string using a specified separator.

Q8. What is the difference between == and ===?

== performs type coercion when necessary. === checks equality without type coercion.

Q9. What is a palindrome?

A string that reads the same forward and backward, according to the comparison rules used.

Q10. What is an anagram?

Two strings containing the same characters with identical frequencies, regardless of order.

Q11. What is a sliding window technique?

It maintains a moving range of elements and updates that range while processing the input.

Q12. What is a Map in JavaScript?

Map is a collection of key-value pairs that supports efficient insertion, lookup and deletion operations on average.

Q13. What is the difference between a substring and a subsequence?

A substring consists of contiguous characters. A subsequence preserves character order but does not require characters to be contiguous.

Q14. What is the difference between a character frequency map and a Set?

A frequency map stores how many times each character occurs. A Set stores unique values.

Q15. Why should Unicode be considered in string algorithms?

JavaScript strings use UTF-16. Some visible characters require multiple code units, so indexing and length may not match the number of user-perceived characters.
