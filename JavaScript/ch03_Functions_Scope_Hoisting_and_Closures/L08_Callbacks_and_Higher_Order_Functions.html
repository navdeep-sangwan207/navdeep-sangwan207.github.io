Lesson 8: Callbacks and Higher-Order Functions

Learn how functions can be passed as arguments, returned from other functions and used to build flexible JavaScript applications.

1. Learning Objectives

After completing this lesson, you will be able to:

  • Understand callback functions.
  • Pass functions as arguments to other functions.
  • Differentiate synchronous and asynchronous callbacks.
  • Understand higher-order functions.
  • Use callbacks with arrays and browser events.
  • Implement reusable functions using callbacks.
  • Identify callback-related problems in JavaScript interviews.

2. What Is a Callback Function?

A callback function is a function passed as an argument to another function so that it can be invoked by that receiving function.

The receiving function determines when and how the callback is executed.

Example 1: Basic Callback

function greet(name, callback) {
    console.log("Hello, " + name);

    callback();
}

function showMessage() {
    console.log("Welcome to JavaScript");
}

greet("Rahul", showMessage);
Expected Output: 
Hello, Rahul
Welcome to JavaScript

Understand the execution:

  1. showMessage is passed as an argument to greet().
  2. The greet() function receives it through the callback parameter.
  3. greet() executes callback().
  4. The showMessage() function runs.
Important: Pass showMessage when you want to provide the function itself. Writing showMessage() would execute it immediately and pass its return value instead.

Example 2: Callback with Parameters

function calculate(a, b, callback) {
    const result = a + b;

    callback(result);
}

function displayResult(value) {
    console.log("Result:", value);
}

calculate(10, 20, displayResult);
Expected Output: 
Result: 30

The receiving function passes the calculated result to the callback as an argument.

3. Passing Anonymous Functions as Callbacks

A callback does not need to have a separately declared function name. You can pass an anonymous function directly.

Example 1: Anonymous Function

function processUser(name, callback) {
    callback(name);
}

processUser("Amit", function (user) {
    console.log("User:", user);
});
Expected Output: 
User: Amit

Example 2: Arrow Function as Callback

function calculate(a, b, callback) {
    callback(a, b);
}

calculate(10, 5, (x, y) => {
    console.log("Addition:", x + y);
    console.log("Subtraction:", x - y);
});
Expected Output: 
Addition: 15
Subtraction: 5

Arrow functions are commonly used for short callbacks, especially with array methods and event handlers.

4. Synchronous Callbacks

A synchronous callback executes as part of the current function call, before that receiving function returns.

Example: Synchronous Execution

function first(callback) {
    console.log("First function started");

    callback();

    console.log("First function finished");
}

function second() {
    console.log("Callback executed");
}

first(second);

console.log("Program finished");
Expected Output: 
First function started
Callback executed
First function finished
Program finished

The callback is called directly. JavaScript executes it before continuing with the next statement in first().

Common Synchronous Callback Examples

  • Array.prototype.map()
  • Array.prototype.filter()
  • Array.prototype.forEach()
  • Array.prototype.reduce()
  • Array.prototype.sort() comparator

5. Asynchronous Callbacks

An asynchronous callback is scheduled to execute later rather than being invoked immediately as part of the receiving function's current execution.

JavaScript commonly uses asynchronous callbacks for timers, browser events and certain I/O operations.

Example 1: setTimeout()

console.log("Start");

setTimeout(function () {
    console.log("Callback executed");
}, 2000);

console.log("End");
Expected Output Order: 
Start
End
Callback executed

The callback is scheduled to run after approximately 2000 milliseconds. The actual execution may occur later depending on the event loop and available tasks.

Example 2: setInterval()

let count = 1;

const timerId = setInterval(function () {
    console.log("Count:", count);

    count++;

    if (count > 3) {
        clearInterval(timerId);
        console.log("Timer stopped");
    }
}, 1000);
Expected Output: 
Count: 1
Count: 2
Count: 3
Timer stopped

setInterval() repeatedly schedules the callback. clearInterval() stops further interval executions.

Example 3: Browser Event Callback

Browser event listeners use callbacks to execute code when an event occurs. 

const button = document.querySelector("#submitBtn");

button.addEventListener("click", function () {
    console.log("Button clicked");
});

The callback is invoked when the user clicks the button. The browser controls when the event listener is called.

The preceding browser example assumes an HTML element with id="submitBtn" exists on the page.

6. What Is a Higher-Order Function?

A higher-order function (HOF) is a function that does at least one of the following:

  • Accepts another function as an argument.
  • Returns a function as its result.

Higher-order functions are an important part of functional programming in JavaScript.

Example 1: Function Accepting Another Function

function executeOperation(a, b, operation) {
    return operation(a, b);
}

function add(x, y) {
    return x + y;
}

function multiply(x, y) {
    return x * y;
}

console.log(executeOperation(10, 5, add));
console.log(executeOperation(10, 5, multiply));
Expected Output: 
15
50

executeOperation() is a higher-order function because it accepts another function as an argument. add() and multiply() are callback functions in these calls.

Example 2: Function Returning Another Function

function multiplier(factor) {
    return function (number) {
        return number * factor;
    };
}

const double = multiplier(2);
const triple = multiplier(3);

console.log(double(10));
console.log(triple(10));
Expected Output: 
20
30

multiplier() is a higher-order function because it returns another function.

The returned functions also form closures because they retain access to the factor variable.

7. Higher-Order Array Methods

JavaScript arrays provide several higher-order methods that accept callback functions. These methods are frequently used in frontend development and coding interviews.

7.1 forEach()

forEach() executes a callback once for each array element. It does not create a new transformed array. 

const numbers = [10, 20, 30];

numbers.forEach(function (number, index) {
    console.log(index, number);
});
Expected Output: 
0 10
1 20
2 30

7.2 map()

map() creates a new array by transforming each element using the callback's return value. 

const numbers = [1, 2, 3, 4];

const squares = numbers.map(function (number) {
    return number * number;
});

console.log(squares);
console.log(numbers);
Expected Output: 
[1, 4, 9, 16]
[1, 2, 3, 4]

7.3 filter()

filter() creates a new array containing elements for which the callback returns a truthy value. 

const numbers = [10, 15, 20, 25, 30];

const evenNumbers = numbers.filter(function (number) {
    return number % 2 === 0;
});

console.log(evenNumbers);
Expected Output: 
[10, 20, 30]

7.4 reduce()

reduce() processes array elements and combines them into a single accumulated result. 

const numbers = [10, 20, 30, 40];

const total = numbers.reduce(function (accumulator, currentValue) {
    return accumulator + currentValue;
}, 0);

console.log(total);
Expected Output: 
100

7.5 sort()

sort() can accept a comparator callback to define how elements should be ordered. It sorts the original array. 

const numbers = [40, 5, 100, 25];

numbers.sort(function (a, b) {
    return a - b;
});

console.log(numbers);
Expected Output: 
[5, 25, 40, 100]

Comparison of Array Methods

Method Purpose Return Value
forEach() Execute logic for each element. undefined
map() Transform every element. New array
filter() Select matching elements. New array
reduce() Accumulate a result. Accumulated value
sort() Reorder array elements. Same array, sorted

8. Practical Frontend Development Example

Filtering Products by Price

A product listing page may need to display only products that satisfy a selected price limit. 

const products = [
    { name: "Keyboard", price: 1200 },
    { name: "Mouse", price: 500 },
    { name: "Monitor", price: 12000 },
    { name: "Headphones", price: 2500 }
];

function filterProducts(productList, callback) {
    return productList.filter(callback);
}

const affordableProducts = filterProducts(
    products,
    function (product) {
        return product.price <= 2500;
    }
);

console.log(affordableProducts);
Expected Output: 
[
  { name: "Keyboard", price: 1200 },
  { name: "Mouse", price: 500 },
  { name: "Headphones", price: 2500 }
]

The custom filterProducts() function accepts a callback and delegates the filtering operation to the array's filter() method.

Practical Applications

  • Filtering products in e-commerce applications.
  • Transforming API response data before rendering.
  • Handling button clicks and form submissions.
  • Validating user input using reusable functions.
  • Processing arrays of users, orders and products.
  • Implementing reusable utility functions.

9. Callback Hell

Callback hell refers to deeply nested callback structures that make asynchronous code difficult to read, maintain and debug.

Example: Nested Callbacks

setTimeout(function () {
    console.log("Step 1");

    setTimeout(function () {
        console.log("Step 2");

        setTimeout(function () {
            console.log("Step 3");
        }, 1000);

    }, 1000);

}, 1000);
Expected Output Order: 
Step 1
Step 2
Step 3

Each step is scheduled after the previous callback runs. The delays are approximately one second per step.

Common problems include:

  • Deeply nested code.
  • Reduced readability.
  • Difficult error handling.
  • Complicated maintenance.

Improved Approach: Named Callback Functions

function stepThree() {
    console.log("Step 3");
}

function stepTwo() {
    console.log("Step 2");

    setTimeout(stepThree, 1000);
}

function stepOne() {
    console.log("Step 1");

    setTimeout(stepTwo, 1000);
}

setTimeout(stepOne, 1000);

Named functions make this example easier to read. For more complex asynchronous workflows, JavaScript Promises and async/await provide more scalable approaches. These concepts are covered separately in the asynchronous JavaScript chapter.

10. Callback vs Higher-Order Function

Callback Function Higher-Order Function
A function passed to another function. A function that accepts or returns another function.
It is supplied to a receiving function. It receives or produces function values.
It may be executed immediately or later. It controls how an accepted callback is used or returns a function.
Example: displayResult. Example: executeOperation.

A function can be both a callback and a higher-order function in different situations. These terms describe different roles rather than mutually exclusive function types.

11. Common Mistakes and Debugging

Mistake 1: Calling a Callback Immediately

function greet(callback) {
    callback();
}

function message() {
    console.log("Hello");
}

greet(message());

This code invokes message() before greet() receives the argument. Since message() returns undefined, callback becomes undefined. Calling it then causes a TypeError.

Correct version:

greet(message);

Mistake 2: Forgetting to Return from map()

const numbers = [1, 2, 3];

const result = numbers.map(function (number) {
    number * 2;
});

console.log(result);
Expected Output: 
[undefined, undefined, undefined]

The callback uses braces but does not return a value.

Correct version:

const result = numbers.map(function (number) {
    return number * 2;
});

console.log(result);
Expected Output: 
[2, 4, 6]

Mistake 3: Expecting forEach() to Return a New Array

const numbers = [1, 2, 3];

const result = numbers.forEach(function (number) {
    return number * 2;
});

console.log(result);
Expected Output: 
undefined

forEach() ignores callback return values and itself returns undefined. Use map() when you need a transformed array.

Mistake 4: Assuming Every Callback Is Asynchronous

[1, 2, 3].forEach(function (number) {
    console.log(number);
});

console.log("Done");
Expected Output: 
1
2
3
Done

A callback is not automatically asynchronous. The receiving function determines when it executes. In this example, forEach() invokes its callbacks synchronously.

12. Placement Interview Questions and Answers

Q1. What is a callback function?

Answer: A callback is a function passed as an argument to another function so that the receiving function can invoke it.

Q2. What is a higher-order function?

Answer: A higher-order function accepts another function as an argument, returns a function, or does both.

Q3. What is the difference between synchronous and asynchronous callbacks?

Answer: A synchronous callback executes as part of the current function call. An asynchronous callback is scheduled to execute later, typically after an event, timer or asynchronous operation.

Q4. Is map() a higher-order function?

Answer: Yes. It accepts a callback function and returns a new array containing the callback's results.

Q5. What is the difference between map() and forEach()?

Answer: map() creates and returns a new array using callback return values. forEach() executes a callback for each element and returns undefined.

Q6. What is callback hell?

Answer: Callback hell is deeply nested callback code that becomes difficult to understand, maintain and debug.

Q7. Can an arrow function be used as a callback?

Answer: Yes. Arrow functions are commonly used as callbacks because they provide concise function syntax.

Q8. Does passing a function as an argument execute it immediately?

Answer: No. Passing a function reference does not execute it. The receiving function must invoke it, or otherwise arrange for its execution.

Q9. Can a callback receive arguments?

Answer: Yes. The receiving function can invoke the callback with arguments, such as a result, array element or event object.

Q10. Is reduce() a higher-order function?

Answer: Yes. It accepts a reducer callback that processes array elements and updates an accumulated value.

Q11. What is the purpose of a callback in addEventListener()?

Answer: It defines the code that the browser invokes when the specified event occurs.

Q12. How can callback hell be reduced?

Answer: Named functions can improve organization. Promises and async/await are commonly used to structure complex asynchronous operations.

14. Lesson Summary

  • A callback is a function passed to another function.
  • A receiving function decides when to invoke its callback.
  • Callbacks can be synchronous or asynchronous.
  • A higher-order function accepts or returns functions.
  • Array methods such as map(), filter() and reduce() use callbacks.
  • Browser event listeners use callbacks to handle user interactions.
  • Callback hell can make asynchronous code difficult to maintain.
  • Promises and async/await help structure complex asynchronous workflows.

Callbacks and higher-order functions are fundamental JavaScript concepts used extensively in frontend development, functional programming and technical coding interviews.
