Lecture 03: Default Parameters and Rest Parameters

JavaScript Functions | Chapter 3

1. Learning Objectives

  • Understand why default parameters are used.
  • Assign default values to function parameters.
  • Understand how undefined and null affect default parameters.
  • Use expressions and earlier parameters in default values.
  • Understand rest parameter syntax.
  • Collect variable numbers of arguments into an array.
  • Differentiate rest parameters from the arguments object.
  • Apply these features to practical JavaScript problems.

2. Why Default Parameters Are Needed

A function may be invoked without supplying values for all its parameters. In that situation, missing parameters normally receive undefined.

Example Without Default Parameters

function greet(name) {
    console.log("Hello, " + name);
}

greet("Rahul");
greet();
Expected Output: 
Hello, Rahul
Hello, undefined

We can avoid this behavior by assigning a default value to the parameter.

3. Default Parameters

A default parameter allows a function parameter to use a predefined value when the corresponding argument is omitted or explicitly supplied as undefined.

Syntax

function functionName(parameter = defaultValue) {
    // Function body
}

Example 1: Basic Default Parameter

function greet(name = "Guest") {
    console.log("Welcome, " + name);
}

greet("Amit");
greet();
Expected Output: 
Welcome, Amit
Welcome, Guest

Example 2: Default Values for Multiple Parameters

function calculateBill(price = 100, quantity = 1) {
    return price * quantity;
}

console.log(calculateBill());
console.log(calculateBill(200));
console.log(calculateBill(200, 3));
Expected Output: 
100
200
600

When only one argument is passed, the second parameter uses its default value.

4. undefined vs null in Default Parameters

Default parameter values are used when an argument is omitted or when the argument value is undefined. Explicitly passing null does not activate the default value.

Example

function display(value = "Default Value") {
    console.log(value);
}

display();
display(undefined);
display(null);
display(0);
display("");
Expected Output: 
Default Value
Default Value
null
0

The final empty string produces an empty console line.

Argument Uses Default? Reason
Omitted Yes No argument was supplied.
undefined Yes Undefined activates the default.
null No Null is an explicitly supplied value.
0 No Zero is a valid numeric value.
"" No An empty string is still a supplied value.
Interview Trap: Default parameters are not the same as using the logical OR operator. For example, value || 10 replaces zero, false and an empty string, while value = 10 as a default parameter only replaces undefined or an omitted argument.

5. Default Parameters Using Expressions

A default parameter can use an expression, not just a constant value.

Example 1: Mathematical Expression

function calculateArea(length, width = length) {
    return length * width;
}

console.log(calculateArea(5));
console.log(calculateArea(5, 3));
Expected Output: 
25
15

The default value of width uses the value of the earlier parameter length.

Example 2: Function Call as a Default Value

function getDefaultQuantity() {
    return 2;
}

function calculateTotal(price, quantity = getDefaultQuantity()) {
    return price * quantity;
}

console.log(calculateTotal(100));
console.log(calculateTotal(100, 5));
Expected Output: 
200
500

Example 3: Earlier Parameter as a Default

function createMessage(name, message = "Hello " + name) {
    return message;
}

console.log(createMessage("Rahul"));
console.log(createMessage("Amit", "Good morning Amit"));
Expected Output: 
Hello Rahul
Good morning Amit
Important: Default parameter initializers are evaluated when the function is called and only when the corresponding argument needs its default value.

6. Default Parameters and Parameter Order

Parameters with default values can be placed before or after required parameters. However, the order of arguments during invocation remains positional.

Example

function registerUser(name, role = "Student", active = true) {
    console.log("Name:", name);
    console.log("Role:", role);
    console.log("Active:", active);
}

registerUser("Rahul");
registerUser("Amit", "Developer");
registerUser("Neha", "Manager", false);
Expected Output: 
Name: Rahul
Role: Student
Active: true

Name: Amit
Role: Developer
Active: true

Name: Neha
Role: Manager
Active: false

If you want to use a later default while keeping an earlier default, you can pass undefined explicitly. 

registerUser("Karan", undefined, false);
Expected Output: 
Name: Karan
Role: Student
Active: false

7. What Are Rest Parameters?

A rest parameter allows a function to collect multiple remaining arguments into a single array. It uses three dots (...) before the parameter name.

Syntax

function functionName(...parameterName) {
    // parameterName is an array
}

Example 1: Collecting Multiple Arguments

function displayNumbers(...numbers) {
    console.log(numbers);
}

displayNumbers(10, 20, 30, 40);
Expected Output: 
[10, 20, 30, 40]

The numbers parameter receives an array containing all arguments supplied to the function.

Example 2: Calculate Sum Using Rest Parameters

function calculateSum(...numbers) {
    let sum = 0;

    for (let number of numbers) {
        sum += number;
    }

    return sum;
}

console.log(calculateSum(10, 20));
console.log(calculateSum(10, 20, 30, 40));
console.log(calculateSum());
Expected Output: 
30
100
0

Rest parameters are particularly useful when the number of arguments is not known in advance.

8. Rest Parameters with Regular Parameters

A function can have normal parameters before its rest parameter. The rest parameter collects all remaining arguments.

Example

function calculateTotal(taxRate, ...prices) {
    let subtotal = 0;

    for (let price of prices) {
        subtotal += price;
    }

    const tax = subtotal * taxRate / 100;

    return subtotal + tax;
}

console.log(calculateTotal(10, 100, 200, 300));
Expected Output: 
660

Explanation:

  • taxRate receives 10.
  • prices receives [100, 200, 300].
  • Subtotal is 600.
  • Tax is 60.
  • Total is 660.

Example: First Two Values and Remaining Values

function processNumbers(first, second, ...remaining) {
    console.log("First:", first);
    console.log("Second:", second);
    console.log("Remaining:", remaining);
}

processNumbers(10, 20, 30, 40, 50);
Expected Output: 
First: 10
Second: 20
Remaining: [30, 40, 50]

9. Rules of Rest Parameters

Rule 1: Only One Rest Parameter Is Allowed

A function cannot declare multiple rest parameters.

// Invalid
function calculate(...first, ...second) {
    // Function body
}
This produces a SyntaxError because a function can have only one rest parameter.

Rule 2: Rest Parameter Must Be Last

// Valid
function calculate(a, b, ...numbers) {
    console.log(numbers);
}

// Invalid
function calculate(...numbers, last) {
    console.log(numbers, last);
}

A rest parameter must be the final parameter in a function definition.

Rule 3: Rest Parameter Is an Array

function showValues(...values) {
    console.log(Array.isArray(values));
    console.log(values.length);
}

showValues(10, 20, 30);
Expected Output: 
true
3

10. Rest Parameters vs arguments Object

Both rest parameters and the arguments object can access multiple arguments. However, they behave differently.

Feature Rest Parameter arguments Object
Syntax ...values arguments
Data type Actual Array Array-like object
Array methods Directly supports methods such as map and reduce. Does not directly provide normal array methods.
Arrow functions Supported No own arguments object
Parameter position Declared explicitly and must be last. Available inside traditional functions.
Modern usage Preferred for collecting variable arguments. Common in older JavaScript code.

Example: Rest Parameter with reduce()

function sumNumbers(...numbers) {
    return numbers.reduce((total, number) => total + number, 0);
}

console.log(sumNumbers(10, 20, 30, 40));
Expected Output: 
100

11. Practical Applications

Example 1: Shopping Cart Total

function calculateCartTotal(discount = 0, ...prices) {
    const subtotal = prices.reduce(
        (total, price) => total + price,
        0
    );

    return subtotal - (subtotal * discount / 100);
}

console.log(calculateCartTotal(10, 100, 200, 300));
console.log(calculateCartTotal(0, 500, 250));
Expected Output: 
540
750

Example 2: Calculate Average Marks

function calculateAverage(...marks) {
    if (marks.length === 0) {
        return 0;
    }

    const total = marks.reduce(
        (sum, mark) => sum + mark,
        0
    );

    return total / marks.length;
}

console.log(calculateAverage(80, 90, 70));
console.log(calculateAverage(75, 85, 95, 65));
Expected Output: 
80
80

Example 3: Build a User Profile with Defaults

function createProfile(
    name,
    role = "Student",
    city = "Delhi"
) {
    return {
        name,
        role,
        city
    };
}

console.log(createProfile("Rahul"));
console.log(createProfile("Amit", "Developer", "Chandigarh"));
Expected Output: 
{ name: 'Rahul', role: 'Student', city: 'Delhi' }
{ name: 'Amit', role: 'Developer', city: 'Chandigarh' }

Object display formatting can vary between browser developer consoles and Node.js.

Example 4: Find the Maximum Number

function findMaximum(...numbers) {
    if (numbers.length === 0) {
        return undefined;
    }

    return Math.max(...numbers);
}

console.log(findMaximum(10, 50, 20, 80, 30));
Expected Output: 
80

Here, the rest parameter collects the arguments into an array. The spread syntax expands that array into individual arguments for Math.max().

Note: Rest parameters and spread syntax both use three dots, but their purposes are different. Rest collects values; spread expands an iterable or object in supported contexts.

12. Common Mistakes and Debugging

Mistake 1: Expecting null to Trigger a Default

function display(value = 100) {
    console.log(value);
}

display(null);

Actual Output: null. Default parameters are activated by omitted arguments or undefined, not null.

Mistake 2: Placing a Normal Parameter After Rest

// Invalid
function test(...numbers, last) {
    console.log(numbers, last);
}

Correction: Place the rest parameter last.

Mistake 3: Declaring Multiple Rest Parameters

// Invalid
function test(...first, ...second) {
    // Function body
}

Correction: Use one rest parameter and process its array as needed.

Mistake 4: Confusing Rest with Spread

// Rest: collects arguments
function add(...numbers) {
    return numbers.length;
}

// Spread: expands an array
const values = [10, 20, 30];

console.log(add(...values));
Expected Output: 
3

Mistake 5: Using || Instead of a Default Parameter

function calculate(quantity = 1) {
    return quantity;
}

console.log(calculate(0));
Expected Output: 
0

The default parameter preserves zero. A logical OR fallback would replace zero because zero is falsy.

13. Placement Interview Questions

Q1. What are default parameters in JavaScript?

Answer: Default parameters assign predefined values to function parameters when their corresponding arguments are omitted or undefined.

Q2. Does null activate a default parameter?

Answer: No. Null is an explicitly supplied value. Only an omitted argument or undefined activates the default.

Q3. Can a default parameter use another parameter?

Answer: Yes. A parameter can use an earlier parameter in its default initializer.

Q4. What is a rest parameter?

Answer: A rest parameter collects remaining arguments into an actual array using the ... syntax.

Q5. Can a function have multiple rest parameters?

Answer: No. A function can have only one rest parameter.

Q6. Where must a rest parameter be placed?

Answer: It must be the last parameter in the function definition.

Q7. What is the difference between rest parameters and arguments?

Answer: Rest parameters create an actual array from remaining arguments. The arguments object is an array-like object available in traditional functions.

Q8. Can arrow functions use rest parameters?

Answer: Yes. Arrow functions support rest parameters, although they do not have their own arguments object.

Q9. What is the difference between rest and spread syntax?

Answer: Rest collects multiple values into one array or object pattern. Spread expands an iterable or object into individual elements or properties.

Q10. What happens if a default parameter is explicitly passed undefined?

Answer: The default value is used.

Q11. When are default parameter expressions evaluated?

Answer: They are evaluated when the function is called and only when the corresponding argument is omitted or undefined.

Q12. Why are rest parameters preferred over arguments?

Answer: Rest parameters provide a clearer function signature and produce a real array that directly supports array methods.

15. Chapter Summary

  • Default parameters provide fallback values for omitted or undefined arguments.
  • Null, zero, false and empty strings do not activate default parameters.
  • Default values can use expressions and earlier parameters.
  • Rest parameters collect remaining arguments into an array.
  • Only one rest parameter is allowed per function.
  • The rest parameter must be the final parameter.
  • Rest parameters are actual arrays.
  • The arguments object is array-like and belongs to traditional functions.
  • Rest parameters are supported by both regular and arrow functions.
  • Rest collects values, while spread expands them.
Placement Tip: Practise output questions involving undefined, null, zero, default values, rest parameter ordering and array methods. These concepts are especially useful in JavaScript coding interviews and frontend development.
