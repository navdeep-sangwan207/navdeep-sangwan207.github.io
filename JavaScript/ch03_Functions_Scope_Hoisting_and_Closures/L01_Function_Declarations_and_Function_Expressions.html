Lecture 01: Function Declarations and Function Expressions

JavaScript Functions | Chapter 3

1. Learning Objectives

After completing this lecture, you will be able to:

  • Explain what a function is and why functions are used.
  • Define and invoke JavaScript functions.
  • Understand function declarations and function expressions.
  • Differentiate named and anonymous functions.
  • Understand how functions are treated as values in JavaScript.
  • Identify differences in hoisting behavior between declarations and expressions.
  • Apply functions to practical programming problems.

2. What Is a Function?

A function is a reusable block of JavaScript code designed to perform a particular task. A function can receive input, process that input and optionally return a result.

Functions help developers:

  • Avoid unnecessary code duplication.
  • Divide large programs into smaller logical units.
  • Improve code readability and maintainability.
  • Reuse the same logic at different places.
  • Make testing and debugging easier.

Example: Without a Function

console.log(10 + 20);
console.log(30 + 40);
console.log(50 + 60);

The addition logic is repeated for every calculation.

Example: Using a Function

function add(a, b) {
    console.log(a + b);
}

add(10, 20);
add(30, 40);
add(50, 60);
Expected Output: 
30
70
110

The addition logic is written once and reused by calling the function with different values.

3. Function Declaration

A function declaration, also called a function statement, defines a function using the function keyword followed by a function name.

Syntax

function functionName(parameters) {
    // Statements
}

Example 1: Simple Function Declaration

function greet() {
    console.log("Welcome to JavaScript!");
}

greet();
Expected Output: 
Welcome to JavaScript!

Explanation:

  • function is the keyword used to declare the function.
  • greet is the function name.
  • The parentheses contain the parameter list.
  • The curly braces contain the function body.
  • greet() invokes the function.

Example 2: Function with a Calculation

function calculateArea() {
    let length = 10;
    let width = 5;

    let area = length * width;

    console.log("Area:", area);
}

calculateArea();
Expected Output: 
Area: 50

Example 3: Function with a Return Statement

function calculateSquare(number) {
    return number * number;
}

let result = calculateSquare(6);

console.log(result);
Expected Output: 
36

The return statement sends a value back to the location where the function was called. Parameters and return values will be covered in detail in Lecture 02.

4. Function Expression

A function expression creates a function and assigns it to a variable or another expression. Functions are values in JavaScript, so they can be stored in variables.

Syntax

const variableName = function(parameters) {
    // Statements
};

Example 1: Function Expression

const greet = function() {
    console.log("Hello from a function expression!");
};

greet();
Expected Output: 
Hello from a function expression!

Here, the function is assigned to the variable greet. The function can be invoked using greet().

Example 2: Function Expression with a Calculation

const multiply = function(a, b) {
    return a * b;
};

let result = multiply(5, 4);

console.log("Product:", result);
Expected Output: 
Product: 20
Important: The variable multiply holds a reference to the function. Calling multiply(5, 4) invokes that function.

5. Named and Anonymous Function Expressions

5.1 Anonymous Function Expression

An anonymous function is a function without its own explicit name. It is commonly assigned to a variable or passed as an argument to another function. 

const showMessage = function() {
    console.log("Learning JavaScript");
};

showMessage();
Expected Output: 
Learning JavaScript

The function itself has no explicit name. It is accessed through the variable showMessage.

5.2 Named Function Expression

A named function expression gives the function its own name inside the expression. 

const factorial = function calculateFactorial(number) {
    if (number === 0) {
        return 1;
    }

    return number * calculateFactorial(number - 1);
};

console.log(factorial(5));
Expected Output: 
120

Here:

  • factorial is the variable holding the function.
  • calculateFactorial is the function's internal name.
  • The internal name can be used for recursion.
Important: In a named function expression, the internal function name is generally available inside the function body, not as an outer variable. For example, calculateFactorial(5) cannot normally be called directly from outside this expression.

6. Function Declaration vs Function Expression

Both approaches create callable functions, but they differ in syntax, assignment and hoisting behavior.

Feature Function Declaration Function Expression
Syntax function greet() {} const greet = function() {};
Function name Required in a normal declaration Can be anonymous or named
Variable assignment Not required Usually assigned to a variable or property
Hoisting Function declaration is available before its declaration in its scope. Depends on how the variable is declared and initialized.
Invocation Can be called before its declaration. Must be initialized before being called through its variable.
Common usage Reusable named functions. Callbacks, assigned functions and local function values.

Important Hoisting Example

A function declaration can be called before its definition:

sayHello();

function sayHello() {
    console.log("Hello!");
}
Expected Output: 
Hello!

A function expression assigned to a const variable cannot be called before initialization: 

sayHello();

const sayHello = function() {
    console.log("Hello!");
};
Expected Result: ReferenceError because the variable sayHello is accessed before initialization.

Hoisting and the Temporal Dead Zone are explained in detail in Lecture 06.

7. Functions Are First-Class Citizens

JavaScript functions are treated as first-class values. This means functions can be:

  • Assigned to variables.
  • Passed as arguments to other functions.
  • Returned from other functions.
  • Stored in arrays and objects.

Example 1: Assigning a Function to Another Variable

function greet() {
    console.log("Hello!");
}

const anotherGreet = greet;

anotherGreet();
Expected Output: 
Hello!

The assignment anotherGreet = greet copies the function reference. It does not execute the function.

Example 2: Storing Functions in an Array

function add() {
    return 10 + 20;
}

function subtract() {
    return 20 - 10;
}

const operations = [add, subtract];

console.log(operations[0]());
console.log(operations[1]());
Expected Output: 
30
10

Example 3: Passing a Function as an Argument

function executeTask(task) {
    task();
}

function displayMessage() {
    console.log("Task executed successfully");
}

executeTask(displayMessage);
Expected Output: 
Task executed successfully

Notice that displayMessage is passed without parentheses. The function reference is passed, and executeTask invokes it using task().

Passing functions as arguments is the foundation of callbacks, which are covered in Lecture 08.

8. Function Invocation vs Function Reference

One important distinction in JavaScript is the difference between referencing a function and executing it. 

function greet() {
    console.log("Good morning");
}

// Function reference
const first = greet;

// Function invocation
greet();

// Invocation through another variable
first();
Expected Output: 
Good morning
Good morning
Expression Meaning
greet References the function.
greet() Executes the function.
const x = greet; Stores the function reference in x.
const x = greet(); Executes greet and stores its return value in x.
Common mistake: Passing greet() when you intend to pass greet as a callback. The parentheses execute the function immediately.

9. Practical Programming Example

Problem: Calculate the Total Price

Write a function that calculates the total price of a product using its price and quantity. 

function calculateTotal(price, quantity) {
    const total = price * quantity;

    return total;
}

const productPrice = 250;
const productQuantity = 4;

const totalAmount = calculateTotal(
    productPrice,
    productQuantity
);

console.log("Total Amount:", totalAmount);
Expected Output: 
Total Amount: 1000

Same Problem Using a Function Expression

const calculateTotal = function(price, quantity) {
    return price * quantity;
};

const totalAmount = calculateTotal(250, 4);

console.log("Total Amount:", totalAmount);
Expected Output: 
Total Amount: 1000

Both implementations produce the same result. The difference is how the function is defined and made available.

10. Common Mistakes and Debugging

Mistake 1: Forgetting to Invoke a Function

function greet() {
    console.log("Hello");
}

greet; // Function is not executed

Correction: Use greet() to invoke the function.

Mistake 2: Calling a const Function Expression Too Early

calculate();

const calculate = function() {
    console.log("Calculating...");
};

Correction: Initialize the function expression before invoking it.

Mistake 3: Assigning the Result Instead of the Function

function greet() {
    return "Hello";
}

const message = greet();

console.log(message);

This stores the returned string, not the function itself. To store the function reference, use const message = greet;.

Mistake 4: Missing the Semicolon After a Function Expression

const greet = function() {
    console.log("Hello");
};

A function expression is part of a variable assignment. Use a semicolon to terminate the assignment statement.

11. Placement Interview Questions

Q1. What is a function in JavaScript?

Answer: A function is a reusable block of code that performs a particular task. It can accept inputs through parameters and return a result.

Q2. What is the difference between a function declaration and a function expression?

Answer: A function declaration defines a named function directly using the function keyword. A function expression creates a function as part of an expression, commonly assigning it to a variable. Function declarations are initialized during their scope's instantiation, while function expressions depend on the initialization of the variable holding them.

Q3. What is an anonymous function?

Answer: An anonymous function is a function without an explicit name. It is often assigned to a variable or passed as a callback.

Q4. What is a named function expression?

Answer: It is a function expression that gives the function an internal name. This name can be useful for recursion and debugging.

Q5. Can a function be assigned to a variable in JavaScript?

Answer: Yes. Functions are first-class values and can be assigned to variables, passed as arguments and returned from other functions.

Q6. What is the difference between greet and greet()?

Answer: greet refers to the function itself, whereas greet() invokes the function.

Q7. Can a function declaration be called before its definition?

Answer: Yes. A function declaration is initialized during scope instantiation, so it can generally be invoked before its textual declaration in the same scope.

Q8. Can a const function expression be called before initialization?

Answer: No. Accessing the const variable before initialization causes a ReferenceError because it is in the Temporal Dead Zone.

Q9. What does it mean that functions are first-class citizens?

Answer: Functions can be treated like other values. They can be stored in variables, passed to other functions, returned from functions and stored in data structures.

Q10. What is recursion?

Answer: Recursion occurs when a function calls itself to solve a smaller version of a problem. A base condition is required to stop recursive calls.

13. Chapter Summary

  • A function is a reusable block of code.
  • Function declarations define named functions directly.
  • Function expressions create functions within expressions.
  • Anonymous functions do not have an explicit name.
  • Named function expressions have an internal function name.
  • Function declarations are initialized during scope instantiation.
  • Function expressions depend on variable initialization.
  • Functions are first-class values in JavaScript.
  • Function references and function invocations are different.
  • Functions can be used for recursion and callback-based programming.
Placement Tip: Be prepared to predict the output of function declarations, function expressions and function-reference examples. Pay particular attention to hoisting behavior and the difference between passing a function reference and invoking a function.
