Lecture 02: Function Parameters, Arguments and Return Values

JavaScript Functions | Chapter 3

1. Learning Objectives

After completing this lecture, you will be able to:

  • Understand the difference between parameters and arguments.
  • Pass values to functions during function invocation.
  • Work with multiple parameters and arguments.
  • Understand how JavaScript handles missing and extra arguments.
  • Use the return statement to send results from functions.
  • Differentiate returning a value from displaying a value.
  • Understand pass-by-value behavior for primitive values and object references.
  • Write reusable functions for practical programming problems.

2. What Are Function Parameters?

Parameters are variables listed inside the parentheses of a function definition. They act as placeholders for values that the function receives when it is called.

Syntax

function functionName(parameter1, parameter2) {
    // Function body
}

Example

function greet(name) {
    console.log("Hello, " + name);
}

greet("Rahul");
Expected Output: 
Hello, Rahul

Explanation:

  • name is a parameter.
  • "Rahul" is the argument.
  • The argument value is assigned to the parameter when the function is invoked.
  • The function uses the parameter to construct the message.

3. What Are Function Arguments?

Arguments are the actual values or expressions supplied when invoking a function.

Example: Multiple Arguments

function add(a, b) {
    console.log(a + b);
}

add(10, 20);
add(50, 30);
add(100, 200);
Expected Output: 
30
80
300

The values passed during each function call are assigned to the corresponding parameters.

Parameters vs Arguments

Parameters Arguments
Declared in the function definition. Supplied during function invocation.
Act as input variables. Provide actual input values.
Example: a, b Example: 10, 20
Remember: Parameters are placeholders; arguments are the actual values passed to the function.

4. Functions with Different Numbers of Parameters

4.1 Function with One Parameter

function square(number) {
    console.log(number * number);
}

square(5);
Expected Output: 
25

4.2 Function with Multiple Parameters

function calculateTotal(price, quantity, discount) {
    const total = price * quantity - discount;

    console.log("Total:", total);
}

calculateTotal(500, 3, 100);
Expected Output: 
Total: 1400

4.3 Passing Expressions as Arguments

function multiply(a, b) {
    console.log(a * b);
}

multiply(10 + 5, 2 * 3);
Expected Output: 
90

JavaScript evaluates the argument expressions before passing their resulting values to the function.

5. Missing and Extra Arguments

JavaScript does not require the number of supplied arguments to match the number of declared parameters.

5.1 Missing Arguments

If an argument is not supplied for a parameter, that parameter receives the value undefined, unless a default parameter is specified. 

function displayDetails(name, age) {
    console.log("Name:", name);
    console.log("Age:", age);
}

displayDetails("Amit");
Expected Output: 
Name: Amit
Age: undefined

5.2 Extra Arguments

Extra arguments do not automatically produce an error. They can be accessed through the arguments object in traditional functions or through rest parameters. 

function add(a, b) {
    console.log(a + b);
}

add(10, 20, 30);
Expected Output: 
30

Only the first two arguments are used by this function. The third argument is not automatically assigned to a declared parameter.

6. The arguments Object

In non-arrow functions, JavaScript provides an arguments object containing the arguments passed to that function.

Example

function showArguments() {
    console.log(arguments);
    console.log("First:", arguments[0]);
    console.log("Second:", arguments[1]);
    console.log("Total arguments:", arguments.length);
}

showArguments(10, 20, 30);
Expected Output: 
[Arguments] { '0': 10, '1': 20, '2': 30 }
First: 10
Second: 20
Total arguments: 3

The exact formatting of the arguments object in the console can vary by JavaScript environment.

Example: Using arguments in a Calculation

function calculateSum() {
    let sum = 0;

    for (let i = 0; i < arguments.length; i++) {
        sum += arguments[i];
    }

    return sum;
}

console.log(calculateSum(10, 20, 30, 40));
Expected Output: 
100
Important: The arguments object is not available as a local arguments object inside arrow functions. Rest parameters provide a modern alternative and are covered in Lecture 03.

7. The Return Statement

The return statement terminates a function and optionally sends a value back to the code that invoked it.

Syntax

function functionName() {
    return value;
}

Example 1: Returning a Number

function add(a, b) {
    return a + b;
}

const result = add(10, 20);

console.log(result);
Expected Output: 
30

Example 2: Returning a String

function getFullName(firstName, lastName) {
    return firstName + " " + lastName;
}

const name = getFullName("Amit", "Sharma");

console.log(name);
Expected Output: 
Amit Sharma

Example 3: Returning a Boolean

function isEligible(age) {
    return age >= 18;
}

console.log(isEligible(20));
console.log(isEligible(15));
Expected Output: 
true
false

Example 4: Returning an Array

function getNumbers() {
    return [10, 20, 30, 40];
}

const numbers = getNumbers();

console.log(numbers);
console.log(numbers[2]);
Expected Output: 
[10, 20, 30, 40]
30

Example 5: Returning an Object

function createEmployee() {
    return {
        id: 101,
        name: "Rahul",
        department: "Development"
    };
}

const employee = createEmployee();

console.log(employee.name);
console.log(employee.department);
Expected Output: 
Rahul
Development

8. console.log() vs return

One of the most important concepts in JavaScript function programming is the difference between displaying a value and returning a value.

Example 1: Using console.log()

function add(a, b) {
    console.log(a + b);
}

const result = add(10, 20);

console.log("Result:", result);
Expected Output: 
30
Result: undefined

The function displays 30, but it does not return a value. Therefore, the function call evaluates to undefined.

Example 2: Using return

function add(a, b) {
    return a + b;
}

const result = add(10, 20);

console.log("Result:", result);
Expected Output: 
Result: 30
console.log() return
Displays a value in the console. Sends a value back from a function.
Does not return the displayed value. Makes the value available to the caller.
Useful for debugging and inspection. Useful for calculations and reusable logic.
Execution continues after the logging statement. Terminates the current function execution.
Placement Tip: When an interview question asks for a function that calculates or produces a result, use return unless the requirement specifically asks you to print the result.

9. Function Execution Stops at return

When JavaScript executes a return statement, the function immediately terminates. Statements after that return are not executed during that function call. 

function test() {
    console.log("First statement");

    return "Finished";

    console.log("Second statement");
}

console.log(test());
Expected Output: 
First statement
Finished

The second console.log() inside the function is unreachable during normal execution.

Returning without a Value

function display() {
    console.log("Inside function");
    return;
}

const result = display();

console.log(result);
Expected Output: 
Inside function
undefined

Function Without a return Statement

function displayMessage() {
    console.log("Welcome");
}

const result = displayMessage();

console.log(result);
Expected Output: 
Welcome
undefined
Common JavaScript Pitfall: Automatic semicolon insertion can affect return statements followed by a line break. 
function getValue() {
    return
    100;
}

console.log(getValue());
Expected Output: 
undefined

JavaScript inserts a semicolon after return in this example. The function therefore returns undefined.

Correct version:

function getValue() {
    return 100;
}

console.log(getValue());
Expected Output: 
100

10. Passing Primitive Values to Functions

JavaScript passes arguments by value. For primitive values, the function receives the value of the argument.

Example

let number = 10;

function updateValue(value) {
    value = 50;

    console.log("Inside function:", value);
}

updateValue(number);

console.log("Outside function:", number);
Expected Output: 
Inside function: 50
Outside function: 10

The parameter value receives a copy of the primitive value. Reassigning that parameter does not change the original variable number.

11. Passing Objects to Functions

When an object is passed to a function, the value being copied is a reference to that object. The parameter and the original variable can therefore refer to the same object.

Example 1: Modifying an Object Property

const employee = {
    name: "Rahul",
    salary: 30000
};

function updateSalary(person) {
    person.salary = 40000;
}

updateSalary(employee);

console.log(employee.salary);
Expected Output: 
40000

The function modifies a property of the same object. The change is visible outside the function.

Example 2: Reassigning the Object Parameter

const employee = {
    name: "Rahul",
    salary: 30000
};

function replaceEmployee(person) {
    person = {
        name: "Amit",
        salary: 50000
    };
}

replaceEmployee(employee);

console.log(employee.name);
console.log(employee.salary);
Expected Output: 
Rahul
30000

Reassigning the local parameter changes only the local reference. It does not replace the original object stored in employee.

Interview Concept: JavaScript is pass-by-value. For objects, the copied value is an object reference. This is why property modifications can affect the original object, while reassigning the parameter does not replace the caller's variable.

12. Returning Multiple Values

A JavaScript function directly returns one value. However, that value can be an array or an object containing multiple results.

Example 1: Returning an Array

function calculate(a, b) {
    const sum = a + b;
    const difference = a - b;

    return [sum, difference];
}

const result = calculate(20, 5);

console.log("Sum:", result[0]);
console.log("Difference:", result[1]);
Expected Output: 
Sum: 25
Difference: 15

Example 2: Returning an Object

function calculate(a, b) {
    return {
        sum: a + b,
        difference: a - b,
        product: a * b,
        quotient: a / b
    };
}

const result = calculate(20, 5);

console.log(result.sum);
console.log(result.difference);
console.log(result.product);
console.log(result.quotient);
Expected Output: 
25
15
100
4

Example 3: Object Destructuring

function getUser() {
    return {
        name: "Amit",
        age: 25
    };
}

const { name, age } = getUser();

console.log(name);
console.log(age);
Expected Output: 
Amit
25

13. Practical Coding Problems

Problem 1: Find the Largest of Three Numbers

Write a function that accepts three numbers and returns the largest number. 

function findLargest(a, b, c) {
    if (a >= b && a >= c) {
        return a;
    } else if (b >= a && b >= c) {
        return b;
    } else {
        return c;
    }
}

console.log(findLargest(25, 70, 45));
Expected Output: 
70

Problem 2: Check Whether a Number Is Prime

function isPrime(number) {
    if (number <= 1) {
        return false;
    }

    for (let i = 2; i * i <= number; i++) {
        if (number % i === 0) {
            return false;
        }
    }

    return true;
}

console.log(isPrime(17));
console.log(isPrime(20));
Expected Output: 
true
false

Problem 3: Calculate the Average of Three Numbers

function calculateAverage(a, b, c) {
    return (a + b + c) / 3;
}

console.log(calculateAverage(10, 20, 30));
Expected Output: 
20

Problem 4: Count the Number of Digits

function countDigits(number) {
    number = Math.abs(Math.trunc(number));

    if (number === 0) {
        return 1;
    }

    let count = 0;

    while (number > 0) {
        count++;
        number = Math.floor(number / 10);
    }

    return count;
}

console.log(countDigits(12345));
console.log(countDigits(-908));
Expected Output: 
5
3

Problem 5: Calculate Simple Interest

function calculateSimpleInterest(principal, rate, time) {
    return (principal * rate * time) / 100;
}

const interest = calculateSimpleInterest(10000, 5, 2);

console.log("Simple Interest:", interest);
Expected Output: 
Simple Interest: 1000

14. Placement Interview Questions

Q1. What is the difference between parameters and arguments?

Answer: Parameters are variables declared in the function definition. Arguments are actual values supplied when invoking the function.

Q2. What happens if fewer arguments are passed than parameters?

Answer: Parameters without corresponding arguments receive undefined, unless a default value is provided.

Q3. What happens if extra arguments are passed?

Answer: JavaScript does not automatically throw an error. Extra arguments can be accessed through the arguments object in traditional functions or rest parameters.

Q4. What is the purpose of the return statement?

Answer: It terminates function execution and optionally sends a value back to the caller.

Q5. What does a function return if no return statement is used?

Answer: It returns undefined by default.

Q6. Can a function return an object or an array?

Answer: Yes. Functions can return any JavaScript value, including numbers, strings, booleans, arrays, objects and other functions.

Q7. What is the difference between console.log() and return?

Answer: console.log() displays information in the console, whereas return sends a value back from a function.

Q8. Does return stop function execution?

Answer: Yes. Once a return statement executes, the current function invocation terminates.

Q9. Is JavaScript pass-by-reference?

Answer: No. JavaScript passes arguments by value. When an object is passed, the copied value is a reference to that object.

Q10. Can a function return multiple values?

Answer: A function directly returns one value, but that value can be an array or object containing multiple results.

Q11. What is the arguments object?

Answer: It is an array-like object available in traditional functions that contains the arguments supplied to the current function invocation.

Q12. What happens when return is followed by a newline?

Answer: Automatic semicolon insertion can insert a semicolon after return, causing the function to return undefined instead of the intended value.

16. Chapter Summary

  • Parameters are placeholders in function definitions.
  • Arguments are actual values supplied during function calls.
  • JavaScript allows missing and extra arguments.
  • Missing parameters receive undefined unless defaults are used.
  • The arguments object is available in traditional functions.
  • The return statement sends a value back to the caller.
  • A function without a return statement returns undefined.
  • console.log() displays a value but does not return it.
  • JavaScript passes arguments by value.
  • Object references allow functions to modify object properties.
  • Arrays and objects can be used to return multiple results.
Placement Tip: Practise output-prediction questions involving missing arguments, extra arguments, return statements and object modification. These concepts are frequently used in JavaScript coding and technical interviews.
