Introduction to C++ Basics

C++ is a general-purpose programming language used in software development, embedded systems, operating systems, game development, and high-performance applications.

This chapter covers the basic structure of a C++ program, input and output, variables, data types, constants, comments, and basic programming rules.

1. Structure of a C++ Program

A basic C++ program contains header files, the main function, statements, and a return statement.

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!";
    return 0;
}

Output

Hello, World!

Explanation

  • #include <iostream>: Enables standard input and output.
  • using namespace std;: Allows names such as cout to be used without writing std::.
  • int main(): The main function where program execution begins.
  • cout: Displays output on the screen.
  • return 0;: Indicates successful program completion.

2. Tokens in C++

Tokens are the smallest meaningful elements of a C++ program.

  • Keywords: Reserved words, such as int, if, and return.
  • Identifiers: Names of variables, functions, and classes.
  • Constants: Fixed values, such as 10 and 3.14.
  • Operators: Symbols that perform operations, such as + and *.
  • Punctuators: Symbols such as ;, {}, and ().

3. Variables and Identifiers

A variable is a named memory location used to store a value.

#include <iostream>
using namespace std;

int main()
{
    int age = 25;
    float height = 5.8f;
    char grade = 'A';

    cout << age << endl;
    cout << height << endl;
    cout << grade << endl;

    return 0;
}

Output

25
5.8
A

Rules for Identifiers

  • An identifier can contain letters, digits, and underscores.
  • It cannot begin with a digit.
  • Spaces are not allowed.
  • Keywords cannot be used as identifiers.
  • C++ identifiers are case-sensitive: age and Age are different.

4. Basic Data Types

Data types specify the kind of value a variable can store.

Data Type Purpose Example
int Integer values int count = 10;
float Single-precision floating-point values float price = 12.5f;
double Double-precision floating-point values double pi = 3.14159;
char A character char letter = 'A';
bool Boolean value bool ready = true;
void Represents no value or type void display();

The exact size and range of numeric types can depend on the compiler and platform. Use sizeof(type) to check the size in your environment.

5. Constants

A constant is a value that should not be changed after initialization.

#include <iostream>
using namespace std;

int main()
{
    const float PI = 3.14159f;
    int radius = 5;

    float area = PI * radius * radius;

    cout << "Area = " << area;
    return 0;
}

Output

Area = 78.5397

The const keyword prevents ordinary modification of the constant after initialization.

6. Input and Output

C++ uses cout to display output and cin to read input. 

#include <iostream>
using namespace std;

int main()
{
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "Sum = " << a + b;

    return 0;
}

Sample Input

10 20

Output

Enter two numbers: 10 20
Sum = 30
  • cin uses the extraction operator >>.
  • cout uses the insertion operator <<.
  • endl inserts a newline and flushes the output stream.

7. Comments in C++

Comments explain code and are ignored by the compiler.

// Single-line comment

/*
   Multi-line comment
   for explanations
*/

Use comments to explain the purpose of code, assumptions, or complex logic.

8. Type Conversion

Type conversion changes a value from one data type to another.

Implicit Conversion

int number = 10;
double result = number;

Explicit Conversion

double value = 9.75;
int number = static_cast<int>(value);

In the second example, number becomes 9 because conversion to int discards the fractional part.

10. Complete Practice Program

This program reads a student's marks and calculates the percentage.

#include <iostream>
using namespace std;

int main()
{
    float marks1, marks2, marks3;
    float total, percentage;

    cout << "Enter marks for three subjects: ";
    cin >> marks1 >> marks2 >> marks3;

    total = marks1 + marks2 + marks3;
    percentage = (total / 300.0f) * 100.0f;

    cout << "Total marks = " << total << endl;
    cout << "Percentage = " << percentage << "%";

    return 0;
}

Sample Input

80 75 90

Output

Enter marks for three subjects: 80 75 90
Total marks = 245
Percentage = 81.6667%
