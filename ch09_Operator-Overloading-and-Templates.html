1. Introduction

This chapter covers two important C++ features:

  • Operator overloading: Giving existing operators special behavior for user-defined types.
  • Templates: Writing generic functions and classes that work with different data types.

2. Operator Overloading

Operator overloading allows operators such as +, -, == and ++ to work with objects of a class.

For example, we can define how the + operator adds two Complex objects.

Syntax

return_type operator symbol(parameters)
{
    // Function body
}

Example: Overloading the + Operator

#include <iostream>
using namespace std;

class Complex {
public:
    int real, imag;

    Complex(int r = 0, int i = 0) {
        real = r;
        imag = i;
    }

    Complex operator+(const Complex& other) const {
        return Complex(real + other.real,
                       imag + other.imag);
    }

    void display() const {
        cout << real << " + " << imag << "i\n";
    }
};

int main() {
    Complex c1(2, 3);
    Complex c2(4, 5);

    Complex c3 = c1 + c2;
    c3.display();

    return 0;
}

Expected Output

6 + 8i

3. Types of Operator Overloading

  • Unary operators: Operate on one operand, such as unary minus (-) and increment (++).
  • Binary operators: Operate on two operands, such as +, -, *, / and ==.

Example: Overloading the == Operator

#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) : value(v) {}

    bool operator==(const Number& other) const {
        return value == other.value;
    }
};

int main() {
    Number a(10), b(10);

    if (a == b)
        cout << "Numbers are equal";
    else
        cout << "Numbers are different";

    return 0;
}

Expected Output

Numbers are equal

4. Operator Overloading Using a Friend Function

A friend function is not a member of the class, but it can access the class's private and protected members when declared as a friend.

#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) : value(v) {}

    friend Number operator+(const Number& a,
                            const Number& b);

    void display() const {
        cout << value;
    }
};

Number operator+(const Number& a, const Number& b) {
    return Number(a.value + b.value);
}

int main() {
    Number a(10), b(20);
    Number c = a + b;

    c.display();
    return 0;
}

Expected Output

30

5. Rules and Limitations

  • Only existing C++ operators can be overloaded; new operator symbols cannot be created.
  • Operator precedence and associativity cannot be changed.
  • At least one operand must be a user-defined type for an overloaded operator.
  • Operators such as ., ::, ?: and sizeof cannot be overloaded.
  • Operators such as =, [], (), and -> must be overloaded as member functions.
  • Operator overloading cannot change the number of operands an operator takes.

6. Introduction to Templates

A template allows a function or class to work with multiple data types without duplicating the same logic.

The compiler generates the appropriate specialization when the template is used with a particular type.

Types of Templates

  • Function templates
  • Class templates

7. Function Template

A function template defines a generic function that can work with different data types.

Syntax

template <typename T>
T functionName(T a, T b)
{
    // Function body
}

Example: Find the Greater Value

#include <iostream>
using namespace std;

template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << maximum(10, 20) << '\n';
    cout << maximum(3.5, 2.5) << '\n';

    return 0;
}

Expected Output

20
3.5

Note: Both arguments normally need to deduce the same T type in this example. For mixed types, use explicit conversions or a template with separate type parameters.

8. Class Template

A class template lets a class store or process data of different types.

Example: Generic Storage Class

#include <iostream>
#include <string>
using namespace std;

template <typename T>
class Storage {
private:
    T data;

public:
    Storage(T value) : data(value) {}

    T getData() const {
        return data;
    }
};

int main() {
    Storage<int> a(100);
    Storage<string> b("Hello C++");

    cout << a.getData() << '\n';
    cout << b.getData() << '\n';

    return 0;
}

Expected Output

100
Hello C++

9. Templates with Multiple Parameters

A template can accept more than one type parameter.

#include <iostream>
using namespace std;

template <typename T, typename U>
void display(T a, U b) {
    cout << a << " " << b;
}

int main() {
    display(10, 3.14);
    return 0;
}

Expected Output

10 3.14

10. Function Overloading vs Function Templates

  • Function overloading: Multiple functions share a name but have different parameter lists.
  • Function template: One generic function definition can support many types.
  • Use overloading when different types need different implementations.
  • Use templates when the same algorithm works for multiple types.

11. Advantages of Templates

  • Code reuse across data types.
  • Less duplicated code.
  • Compile-time type checking.
  • Useful for generic data structures and algorithms.
  • Foundation of many Standard Template Library (STL) components, including vector, list and map.
