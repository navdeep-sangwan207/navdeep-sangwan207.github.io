7.1 Introduction to Inheritance

Inheritance is an OOP feature that allows a new class to acquire accessible members and behavior from an existing class.

  • Base class: The class being inherited from.
  • Derived class: The class that inherits from a base class.
  • Code reuse: Common behavior can be implemented in a base class.
  • Extensibility: Derived classes can add specialized behavior.

Syntax:

class Derived : public Base
{
    // Additional members
};

7.2 Single Inheritance

Single inheritance means one derived class inherits from one base class.

Program 1: Single Inheritance

#include <iostream>
using namespace std;

class Animal
{
public:
    void eat() const
    {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal
{
public:
    void bark() const
    {
        cout << "Dog is barking" << endl;
    }
};

int main()
{
    Dog d;
    d.eat();
    d.bark();

    return 0;
}

Expected Output

Animal is eating
Dog is barking

Explanation: Dog inherits the public eat() method from Animal and defines its own bark() method.

7.3 Multilevel Inheritance

Multilevel inheritance occurs when a class derives from another derived class.

Program 2: Multilevel Inheritance

#include <iostream>
using namespace std;

class LivingThing
{
public:
    void breathe() const
    {
        cout << "Breathing" << endl;
    }
};

class Animal : public LivingThing
{
public:
    void eat() const
    {
        cout << "Eating" << endl;
    }
};

class Dog : public Animal
{
public:
    void bark() const
    {
        cout << "Barking" << endl;
    }
};

int main()
{
    Dog d;
    d.breathe();
    d.eat();
    d.bark();

    return 0;
}

Expected Output

Breathing
Eating
Barking

The inheritance chain is LivingThing → Animal → Dog.

7.4 Multiple Inheritance

Multiple inheritance allows a derived class to inherit from more than one base class.

Program 3: Multiple Inheritance

#include <iostream>
using namespace std;

class Camera
{
public:
    void takePhoto() const
    {
        cout << "Photo captured" << endl;
    }
};

class Phone
{
public:
    void makeCall() const
    {
        cout << "Calling..." << endl;
    }
};

class Smartphone : public Camera, public Phone
{
};

int main()
{
    Smartphone device;
    device.takePhoto();
    device.makeCall();

    return 0;
}

Expected Output

Photo captured
Calling...

Note: If both base classes provide members with the same name, the call may be ambiguous. You can use a qualified name such as Camera::takePhoto() to specify the intended base class.

7.5 Hierarchical Inheritance

Hierarchical inheritance occurs when multiple derived classes inherit from the same base class.

Program 4: Hierarchical Inheritance

#include <iostream>
using namespace std;

class Shape
{
public:
    void describe() const
    {
        cout << "This is a shape" << endl;
    }
};

class Circle : public Shape
{
public:
    void drawCircle() const
    {
        cout << "Drawing circle" << endl;
    }
};

class Rectangle : public Shape
{
public:
    void drawRectangle() const
    {
        cout << "Drawing rectangle" << endl;
    }
};

int main()
{
    Circle c;
    Rectangle r;

    c.describe();
    c.drawCircle();

    r.describe();
    r.drawRectangle();

    return 0;
}

Expected Output

This is a shape
Drawing circle
This is a shape
Drawing rectangle

7.6 Hybrid Inheritance

Hybrid inheritance combines multiple inheritance patterns. One common example is the diamond-shaped hierarchy.

Program 5: Diamond Problem and Virtual Inheritance

#include <iostream>
using namespace std;

class Device
{
public:
    int id = 101;
};

class Printer : virtual public Device
{
};

class Scanner : virtual public Device
{
};

class AllInOne : public Printer, public Scanner
{
};

int main()
{
    AllInOne machine;

    cout << "Device ID: " << machine.id << endl;
    return 0;
}

Expected Output

Device ID: 101

Virtual inheritance ensures that AllInOne contains one shared Device base-class subobject instead of separate copies inherited through Printer and Scanner.

7.7 Public, Protected and Private Inheritance

Inheritance mode affects how inherited public and protected members are exposed through the derived class.

  • Public inheritance: Base public members remain public, and base protected members remain protected.
  • Protected inheritance: Base public and protected members become protected in the derived class.
  • Private inheritance: Base public and protected members become private in the derived class.

Private members of a base class are not directly accessible in a derived class. They can be accessed indirectly through suitable public or protected base-class functions.

For a class, inheritance is private by default. For a struct, it is public by default.

7.8 Constructor and Destructor Order in Inheritance

Base-class construction occurs before derived-class construction. Destruction occurs in reverse order.

Program 6: Execution Order

#include <iostream>
using namespace std;

class Base
{
public:
    Base()
    {
        cout << "Base constructor" << endl;
    }

    ~Base()
    {
        cout << "Base destructor" << endl;
    }
};

class Derived : public Base
{
public:
    Derived()
    {
        cout << "Derived constructor" << endl;
    }

    ~Derived()
    {
        cout << "Derived destructor" << endl;
    }
};

int main()
{
    Derived obj;
    return 0;
}

Expected Output

Base constructor
Derived constructor
Derived destructor
Base destructor

7.9 Function Overriding

A derived class can provide its own implementation of a virtual function inherited from a base class. Use override to help the compiler verify that the function overrides a base-class virtual function.

Program 7: Function Overriding

#include <iostream>
using namespace std;

class Animal
{
public:
    virtual void sound() const
    {
        cout << "Animal sound" << endl;
    }

    virtual ~Animal() = default;
};

class Dog : public Animal
{
public:
    void sound() const override
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d;
    Animal* ptr = &d;

    ptr->sound();
    return 0;
}

Expected Output

Dog barks

The call is resolved at runtime because sound() is virtual.

7.10 Advantages and Limitations

Advantages

  • Promotes reuse of common behavior.
  • Supports runtime polymorphism.
  • Allows specialized derived classes.

Limitations

  • Deep inheritance hierarchies can be difficult to maintain.
  • Multiple inheritance may introduce ambiguity.
  • Inheritance can create tight coupling between classes.

Use inheritance when there is a genuine “is-a” relationship. For a “has-a” relationship, composition is often a better choice.
