Chapter 3: Operators in C++

Learn how operators perform arithmetic, comparisons, logical operations, assignments, and bit manipulation.

1. Introduction to Operators

An operator is a symbol that performs an operation on one or more operands. 

int a = 10;
int b = 5;
int sum = a + b;

Here, + is the operator, while a and b are operands.

2. Arithmetic Operators

Arithmetic operators perform mathematical calculations.

OperatorOperationExample
+Addition10 + 5 = 15
-Subtraction10 - 5 = 5
*Multiplication10 * 5 = 50
/Division10 / 3 = 3 for integers
%Remainder10 % 3 = 1

Example Program

#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;

    cout << "Addition: " << a + b << '\n';
    cout << "Subtraction: " << a - b << '\n';
    cout << "Multiplication: " << a * b << '\n';
    cout << "Division: " << a / b << '\n';
    cout << "Remainder: " << a % b << '\n';

    return 0;
}

Expected Output

Addition: 13
Subtraction: 7
Multiplication: 30
Division: 3
Remainder: 1

Note: Integer division discards the fractional part. Use 10.0 / 3 for floating-point division.

3. Relational Operators

Relational operators compare two values and produce a Boolean result: true or false.

OperatorMeaning
==Equal to
!=Not equal to
>Greater than
<Less than
>=Greater than or equal to
<=Less than or equal to

Example Program

#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 5;

    cout << (a > b) << '\n';
    cout << (a == b) << '\n';
    cout << (a != b) << '\n';

    return 0;
}

Expected Output

1
0
1

By default, Boolean values are displayed as 1 for true and 0 for false.

4. Logical Operators

Logical operators combine or reverse Boolean conditions.

OperatorMeaning
&&Logical AND
||Logical OR
!Logical NOT

Example Program

#include <iostream>
using namespace std;

int main() {
    int age = 25;

    cout << (age >= 18 && age <= 60) << '\n';
    cout << (age < 18 || age > 60) << '\n';
    cout << !(age >= 18) << '\n';

    return 0;
}

Expected Output

1
0
0

Logical AND requires both conditions to be true. Logical OR requires at least one condition to be true. Logical NOT reverses a Boolean value.

5. Assignment Operators

Assignment operators assign or update variable values.

OperatorExampleMeaning
=a = 5Assign 5 to a
+=a += 2a = a + 2
-=a -= 2a = a - 2
*=a *= 2a = a * 2
/=a /= 2a = a / 2
%=a %= 2a = a % 2

Example Program

#include <iostream>
using namespace std;

int main() {
    int a = 10;

    a += 5;
    cout << a << '\n';

    a -= 3;
    cout << a << '\n';

    a *= 2;
    cout << a << '\n';

    return 0;
}

Expected Output

15
12
24

6. Increment and Decrement Operators

  • ++a — Prefix increment
  • a++ — Postfix increment
  • --a — Prefix decrement
  • a-- — Postfix decrement

Example Program

#include <iostream>
using namespace std;

int main() {
    int a = 5;

    cout << ++a << '\n';
    cout << a++ << '\n';
    cout << a << '\n';

    return 0;
}

Expected Output

6
6
7

Prefix increment changes the value before it is used in the expression. Postfix increment uses the old value first and then increments it.

7. Bitwise Operators

Bitwise operators work on the individual bits of integral values. They are particularly useful in embedded systems, microcontroller registers, and low-level programming.

OperatorOperation
&Bitwise AND
|Bitwise OR
^Bitwise XOR
~Bitwise NOT
<<Left shift
>>Right shift

Example Program

#include <iostream>
using namespace std;

int main() {
    unsigned int a = 5;
    unsigned int b = 3;

    cout << (a & b) << '\n';
    cout << (a | b) << '\n';
    cout << (a ^ b) << '\n';
    cout << (a << 1) << '\n';

    return 0;
}

Expected Output

1
7
6
10

For example, 5 is 0101 and 3 is 0011 in four-bit binary notation. Their bitwise AND is 0001, which equals 1.

8. Conditional (Ternary) Operator

The ternary operator evaluates a condition and selects one of two expressions.

Syntax:

condition ? expression1 : expression2;

Example Program

#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 20;

    int larger = (a > b) ? a : b;

    cout << "Larger number: " << larger;

    return 0;
}

Expected Output

Larger number: 20

9. sizeof Operator

The sizeof operator returns the size of a type or object in bytes. 

#include <iostream>
using namespace std;

int main() {
    int number = 10;

    cout << sizeof(number) << '\n';
    cout << sizeof(double) << '\n';

    return 0;
}

The output depends on the sizes of the types in the C++ implementation. For example, an implementation commonly uses 4 bytes for int and 8 bytes for double.

10. Operator Precedence

Operator precedence determines how operators are grouped when an expression contains more than one operator. 

int result1 = 2 + 3 * 4;
int result2 = (2 + 3) * 4;

cout << result1 << '\n';
cout << result2 << '\n';

Expected Output

14
20

Multiplication has higher precedence than addition. Parentheses change the grouping and make expressions easier to understand.

11. Complete Practice Program

This program accepts two integers and demonstrates arithmetic, relational, and logical operators. 

#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two integers: ";
    cin >> a >> b;

    cout << "Addition: " << a + b << '\n';
    cout << "Subtraction: " << a - b << '\n';
    cout << "Multiplication: " << a * b << '\n';

    if (b != 0) {
        cout << "Integer division: " << a / b << '\n';
        cout << "Remainder: " << a % b << '\n';
    } else {
        cout << "Division by zero is not allowed.\n";
    }

    cout << "a greater than b: " << (a > b) << '\n';
    cout << "Both positive: "
         << (a > 0 && b > 0) << '\n';

    return 0;
}

Sample Input

10 3

Expected Output

Enter two integers: 10 3
Addition: 13
Subtraction: 7
Multiplication: 30
Integer division: 3
Remainder: 1
a greater than b: 1
Both positive: 1
