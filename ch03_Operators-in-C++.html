Chapter 3: Operators in C++

Operators are symbols used to perform calculations, comparisons, logical operations, and bit manipulation.

1. Arithmetic Operators

Arithmetic operators perform mathematical operations.

OperatorOperationExample
+Addition10 + 5 = 15
-Subtraction10 - 5 = 5
*Multiplication10 * 5 = 50
/Division10 / 3 = 3 (integers)
%Remainder10 % 3 = 1
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;

    cout << a + b << '\n';
    cout << a - b << '\n';
    cout << a * b << '\n';
    cout << a / b << '\n';
    cout << a % b << '\n';

    return 0;
}

2. Relational Operators

These operators compare two values and return a Boolean result.

  • == — Equal to
  • != — Not equal to
  • > — Greater than
  • < — Less than
  • >= — Greater than or equal to
  • <= — Less than or equal to
int a = 10, b = 5;
cout << (a > b);   // 1: true
cout << (a == b);  // 0: false

3. Logical Operators

OperatorMeaning
&&AND: both conditions must be true
||OR: at least one condition must be true
!NOT: reverses the Boolean value
int age = 25;
cout << (age >= 18 && age <= 60);

4. Assignment Operators

/=a /= 2a = a / 2

5. Increment and Decrement Operators

  • ++a — Prefix increment
  • a++ — Postfix increment
  • --a — Prefix decrement
  • a-- — Postfix decrement
int a = 5;

cout << ++a << '\n'; // 6
cout << a++ << '\n'; // 6; a becomes 7

6. Bitwise Operators

Bitwise operators work on individual bits of integral values. They are especially useful in embedded systems and microcontroller register operations.

OperatorOperation
&Bitwise AND
|Bitwise OR
^Bitwise XOR
~Bitwise NOT
<<Left shift
>>Right shift
unsigned int a = 5;  // Binary: 0101
unsigned int b = 3;  // Binary: 0011

cout << (a & b) << '\n';   // 1
cout << (a | b) << '\n';   // 7
cout << (a ^ b) << '\n';   // 6
cout << (a << 1) << '\n'; // 10

7. Conditional (Ternary) Operator

The ternary operator selects one of two expressions.

int a = 10, b = 20;
int larger = (a > b) ? a : b;

cout << larger; // 20

8. sizeof Operator

The sizeof operator returns the size of a type or object in bytes. 

int number = 10;

cout << sizeof(number) << '\n';
cout << sizeof(double) << '\n';

Actual sizes depend on the C++ implementation and type.

9. Operator Precedence

Operator precedence determines how an expression is grouped. Parentheses can make the intended order explicit. 

int result1 = 2 + 3 * 4;     // 14
int result2 = (2 + 3) * 4;   // 20

10. Practice Program

Write a program that accepts two integers and performs operations.

#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two integers: ";
    cin >> a >> b;

    cout << "Addition: " << a + b << '\n';
    cout << "Subtraction: " << a - b << '\n';
    cout << "Multiplication: " << a * b << '\n';

    if (b != 0) {
        cout << "Division: " << a / b << '\n';
        cout << "Remainder: " << a % b << '\n';
    } else {
        cout << "Cannot divide by zero.\n";
    }

    return 0;
}

11. Practice Questions

  1. Write a program to check whether a number is even or odd.
  2. Find the larger of two numbers using the ternary operator.
  3. Swap two numbers using a temporary variable.
  4. Set, clear, and toggle a bit using bitwise operators.
  5. Predict the output of expressions using operator precedence.
