Chapter 3: Operators in C++

Learn how operators perform calculations, compare values, combine conditions, manipulate bits, and assign values in C++.

1. What Is an Operator?

An operator is a symbol that performs an operation on one or more operands. 

int a = 10, b = 3;
int sum = a + b;

Here, + is the operator, and a and b are operands.

2. Arithmetic Operators

These operators perform mathematical calculations.

OperatorMeaningExampleResult
+Addition10 + 313
-Subtraction10 - 37
*Multiplication10 * 330
/Division10 / 33 (integer division)
%Remainder10 % 31

Note: Integer division discards the fractional part. Use 10.0 / 3 for floating-point division.

3. Relational Operators

Relational operators compare two values and produce a Boolean result.

OperatorMeaning
==Equal to
!=Not equal to
>Greater than
<Less than
>=Greater than or equal to
<=Less than or equal to
int a = 10, b = 5;
cout << (a > b);   // Outputs 1 (true)
cout << (a == b);  // Outputs 0 (false)

4. Logical Operators

OperatorMeaning
&&Logical AND — both conditions must be true
||Logical OR — at least one condition must be true
!Logical NOT — reverses a Boolean value
int age = 25;
cout << (age >= 18 && age <= 60);

The expression evaluates to true.

5. Assignment Operators

OperatorEquivalent form
=a = 5
+=a += 2 means a = a + 2
-=a -= 2 means a = a - 2
*=a *= 2 means a = a * 2
/=a /= 2 means a = a / 2
%=a %= 2 means a = a % 2

6. Increment and Decrement Operators

  • ++a — prefix increment
  • a++ — postfix increment
  • --a — prefix decrement
  • a-- — postfix decrement
int a = 5;
cout << ++a;  // Outputs 6
cout << a++;  // Outputs 6, then a becomes 7

Prefix changes the value before the expression is evaluated; postfix uses the old value before changing it.

7. Bitwise Operators

Bitwise operators work on individual bits of integral values. They are useful in embedded systems and register manipulation.

OperatorMeaning
&Bitwise AND
|Bitwise OR
^Bitwise XOR
~Bitwise NOT
<<Left shift
>>Right shift
unsigned int a = 5;  // Binary: 0101
unsigned int b = 3;  // Binary: 0011

cout << (a & b);   // 1
cout << (a | b);   // 7
cout << (a ^ b);   // 6
cout << (a << 1); // 10

8. Conditional (Ternary) Operator

Syntax: condition ? value_if_true : value_if_false;

int a = 10, b = 20;
int larger = (a > b) ? a : b;
cout << larger;  // Outputs 20

9. sizeof Operator

The sizeof operator gives the size of a type or object in bytes.

int number = 10;
cout << sizeof(number);
cout << sizeof(double);

The exact sizes depend on the implementation and type.

10. Operator Precedence

Precedence determines which operators are grouped first. Parentheses can make expressions clearer.

int result = 2 + 3 * 4;    // 14
int result2 = (2 + 3) * 4; // 20

Multiplication has higher precedence than addition.

11. Complete Practice Program

#include <iostream>
using namespace std;

int main()
{
    int a, b;

    cout << "Enter two integers: ";
    cin >> a >> b;

    cout << "Addition: " << a + b << '\n';
    cout << "Subtraction: " << a - b << '\n';
    cout << "Multiplication: " << a * b << '\n';

    if (b != 0)
    {
        cout << "Integer division: " << a / b << '\n';
        cout << "Remainder: " << a % b << '\n';
    }
    else
    {
        cout << "Division by zero is not allowed.\n";
    }

    cout << "a greater than b: " << (a > b) << '\n';
    cout << "Both positive: " << (a > 0 && b > 0) << '\n';

    return 0;
}

Sample Output

Enter two integers: 10 3
Addition: 13
Subtraction: 7
Multiplication: 30
Integer division: 3
Remainder: 1
a greater than b: 1
Both positive: 1

12. Practice Questions

  1. Write a program to swap two numbers using a temporary variable.
  2. Check whether a number is even or odd using the modulus operator.
  3. Find the largest of two numbers using the ternary operator.
  4. Set, clear, and toggle a bit using bitwise operators.
  5. Evaluate an expression using operator precedence and parentheses.
